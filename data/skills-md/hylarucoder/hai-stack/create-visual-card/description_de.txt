Erstellen Sie eine visuelle Karte in Zeitschriftenqualität als einzelne, eigenständige HTML-Datei (eingebettetes CSS, Swiss-Grid + Fettdruck-Designsystem), erstellen Sie dann einen Screenshot davon in einem gemeinsam nutzbaren PNG und geben Sie beide Dateien zurück. Verwenden Sie dies immer dann, wenn der Benutzer möchte, dass Inhalte in eine visuell ansprechende Karte oder ein gemeinsam nutzbares Bild umgewandelt werden – auch wenn er das Wort „Karte“ nicht sagt. Auslöser: Erstellen/Erstellen/Generieren/Entwerfen einer visuellen Karte, einer Infokarte, einer Wissenskarte, einer Zitatkarte, einer Sozialkarte, einer Zusammenfassungs-/Imbiss-/Spickzettelkarte; 信息卡, 知识卡片, 金句卡, 语录卡, 做张卡片, 设计一张卡片, 把这段内容做成卡片,把要点排成一张图, 总结成一张图, 小红书封面, 公众号封面图, 朋友圈配图. Bevorzugen Sie dies gegenüber generischen HTML-/Frontend-Kenntnissen, wenn das Ziel ein dekoratives Kartenbild ist. Wenn es sich bei dem Inhalt um einen Bericht mit mehreren Abschnitten und nicht um eine einzelne Karte handelt, verwenden Sie hai-visual-report.
