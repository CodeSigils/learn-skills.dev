Produit un rapport sur les résultats du Clean Code évalué par la gravité (高/中/低) sur 7 dimensions (dénomination, taille de la fonction/SRP, duplication/DRY, sur-ingénierie/YAGNI, nombres magiques, clarté structurelle, conventions du projet), chacune avec un emplacement et une suggestion de refactorisation préservant le comportement — sans jamais changer de fonctionnalité. À utiliser chaque fois que l'utilisateur demande une révision du code, un contrôle de qualité, des conseils de refactorisation ou une analyse de l'odeur de code/du code propre, OU pointe sur un fichier/une fonction/un diff et demande s'il est bien écrit, trop long, trop répétitif, trop conçu ou mal nommé - même avec désinvolture, et même s'il ne dit jamais "réviser" ("Je viens d'écrire ceci, regarde-le", "est-ce que ça a l'air bien avant de m'engager"). Déclencheur sur 代码体检, 代码质量, 重构检查, 代码审查, 这段代码写得怎么样,帮我看看代码有没有问题, 有没有坏味道, 这函数是不是太长了, 命名规范吗, 魔法数字,重复代码, 过度设计 et des anglais comme "ce code est-il propre", "tout code sent", "vérifiez ce fichier".
