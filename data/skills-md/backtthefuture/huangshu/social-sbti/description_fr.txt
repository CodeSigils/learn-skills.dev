Social-SBTI — Supprimez les publications publiques de X/, générez des cartes de personnalité usurpées SBTI.
Flux de travail guidé : déclencheur utilisateur → choisir la plate-forme → coller l'URL → vérification de l'état automatique / définir les informations d'identification / gratter / noter / rendre → carte de sortie.
Scènes de déclenchement :
- L'utilisateur dit "exécuter social-sbti" / "démarrer social-sbtI"
- L'utilisateur dit "analysez le SBTI de @user pour moi"
- L'utilisateur dit "utiliser social-sbtI pour analyser @user"
- L'utilisateur dit "donnez à XXX une carte de personnalité sociale SBTI"
