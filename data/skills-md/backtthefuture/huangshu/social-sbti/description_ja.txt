Social-SBTI — X / から公開投稿をスクレイピングし、SBTI のなりすましパーソナリティ カードを生成します。
ガイド付きワークフロー: ユーザートリガー → プラットフォームの選択 → URL の貼り付け → 自動ヘルスチェック / 資格情報の設定 / スクレイピング / スコア / レンダリング → カードの出力。
トリガーシーン:
- ユーザーが「social-sbti を実行」/「social-sbtI を開始」と言う
- ユーザーが「@user の SBTI を分析してください」と言う
- ユーザーが「@user を分析するには social-sbtI を使用してください」と言う
- ユーザーが「XXX にソーシャル SBTI パーソナリティ カードを与えてください」と言う
