Social-SBTI — 即刻 / X から公開投稿をスクレイピングし、パロディ SBTI パーソナリティ カードを生成します。  
ガイド付きフロー: ユーザー トリガー → プラットフォームの選択 → URL の貼り付け → 自動ヘルスチェック / 認証 / スクレイピング / スコア / レンダリング → カードの配信。  
トリガーフレーズ:  
- 「ソーシャル sbti を実行する」 / 「ソーシャル sbti を起動する」  
- 「@誰々の SBTI を分析してください」  
- 「@so-and-so で social-sbti を使用する」  
- 「XXX にソーシャル SBTI パーソナリティ カードを与えます」
