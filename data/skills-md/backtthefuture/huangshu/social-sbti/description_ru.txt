Social-SBTI — очищайте публичные сообщения от X /, генерируйте поддельные персональные карты SBTI.
Управляемый рабочий процесс: триггер пользователя → выберите платформу → вставьте URL-адрес → автоматическая проверка работоспособности / установка учетных данных / очистка / оценка / рендеринг → выходная карта.
Триггерные сцены:
- Пользователь говорит «запустить Social-sbti» / «запустить Social-sbtI».
- Пользователь говорит: «Проанализируйте для меня SBTI @user»
- Пользователь говорит: «Используйте Social-sbtI для анализа @user».
– Пользователь говорит: «Дайте XXX карточку личности социального SBTI».
