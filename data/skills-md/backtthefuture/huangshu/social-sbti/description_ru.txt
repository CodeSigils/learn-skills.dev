Social-SBTI — извлекает публичные сообщения из Jike/X и генерирует поддельную карту личности MBTI.  
Последовательность действий: пользовательские триггеры → выбор платформы → вставка URL-адреса → автоматическая проверка/извлечение учетных данных/очистка/оценка/рендеринг → карта готова.  
Триггерные фразы:  
- пользователь говорит «запустить Social-SBTI» / «Запустить Social-SBTI»  
- пользователь говорит: «Проанализируйте для меня SBTI @кого-то»  
- пользователь говорит: «Используй Social-sbti для анализа @someone»  
– пользователь говорит: «Дайте XXX персональную карточку социального MBTI».
