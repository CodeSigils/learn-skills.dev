Social-SBTI — Jike/X의 공개 게시물을 스크랩하고 스푸핑 SBTI 성격 카드를 생성합니다.
안내 흐름: 사용자 트리거 → 플랫폼 선택 → URL 붙여넣기 → 자동 확인/구성/크롤링/점수/렌더링 → 카드 준비.
트리거 문구:
- 사용자가 "social-sbti 실행" / "social-sbti 시작"이라고 말합니다.
- 사용자가 "@누군가의 SBTI를 분석해 줘"라고 말합니다.
- 사용자가 "@someone을 분석하려면 social-sbti를 사용하세요"라고 말합니다.
- 사용자가 "XXX에게 소셜 SBTI 성격 카드를 줘"라고 말합니다.
