Social-SBTI — X /의 공개 게시물을 스크랩하고 SBTI 스푸핑 성격 카드를 생성합니다.
안내식 워크플로: 사용자 트리거 → 플랫폼 선택 → URL 붙여넣기 → 자동 상태 확인/자격 증명 설정/스크래핑/점수/렌더링 → 카드 출력.
트리거 장면:
- 사용자가 "run social-sbti" / "start social-sbtI"라고 말합니다.
- 사용자가 "@user의 SBTI를 분석해 주세요"라고 말합니다.
- 사용자가 "social-sbtI를 사용하여 @user를 분석합니다"라고 말합니다.
- 사용자가 "XXX에게 소셜 SBTI 성격 카드를 줘"라고 말합니다.
