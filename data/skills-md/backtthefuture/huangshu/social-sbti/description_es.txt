Social-SBTI: elimina publicaciones públicas de X (anteriormente Twitter) y genera una tarjeta de personalidad SBTI falsa.
Flujo guiado: activadores de usuario → elegir plataforma → pegar URL → verificación automática de estado / autenticación / raspado / puntuación / renderización → tarjeta entregada.
Frases desencadenantes:
- el usuario dice "ejecutar social-sbti" / "iniciar social-sbti"
- el usuario dice "analiza el SBTI de @fulano de tal por mí"
- el usuario dice "usa social-sbti para analizar @ fulano de tal"
- el usuario dice "dale a XXX una tarjeta de personalidad social SBTI"
