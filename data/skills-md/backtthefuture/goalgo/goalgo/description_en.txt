GoalGo: Transform ordinary requests into verifiable Codex Goals by quickly restating them, asking key follow‑up questions, and accumulating answers, then launch them directly after the user confirms the final version. It applies to scenarios such as “Help me write a Goal,” “Convert the request into /goal,” “Ask me follow‑up questions to fill in the information,” “Generate and wait for my confirmation before running,” “Start goal mode,” as well as when the user replies “Start” or “Confirm launch” to a pending Goal from the previous round. By default it only designs; only after displaying the current version and receiving explicit confirmation does it invoke the Goal tool to launch.
