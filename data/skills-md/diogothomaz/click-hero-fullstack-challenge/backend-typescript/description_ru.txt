Используйте при создании или изменении серверных API с помощью TypeScript и Express. Охватывает структуру проекта, строгую конфигурацию TypeScript, экспресс-маршруты и промежуточное программное обеспечение, проверку Zod, шаблоны обработки ошибок, тестирование с помощью Vitest и проверку с помощью Biome. Также используйте при работе с файлами в каталогах src/routes/, src/middleware/, src/schemas/, src/config/, tsconfig.json или biome.json.
