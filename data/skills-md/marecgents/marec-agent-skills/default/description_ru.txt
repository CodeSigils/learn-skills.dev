Общий навык рабочего процесса по умолчанию. Когда пользователь предлагает задачу, но больше не соответствует конкретным специализированным навыкам, этот навык используется в качестве запасного варианта. Он обеспечивает стандартизированный трехэтапный рабочий процесс: во-первых, мозговой штурм для ранней концептуализации и подтверждения проекта; затем «Планирование с помощью файлов» для отслеживания задач на основе файлов; и, наконец, завершающее архивирование для создания журнала задач и очистки временных файлов. Триггерные фразы: «помоги мне сделать…», «я хочу…», «написать…», «построить…», «внедрить…», «разработать…», «завершить…», «организовать…», «проанализировать…», «обработать…», для любой задачи без четкого соответствия навыков. Если доступны мозговой штурм, планирование с помощью файлов или другие команды с косой чертой, этот рабочий процесс следует использовать предпочтительно.
