General default workflow skill. When a user proposes a task but no more specific specialized skill matches, this skill is used as a fallback. It provides a standardized three‑stage workflow: first, Brainstorming for early conceptualization and design confirmation; then, Planning with Files for file‑based task tracking; and finally, wrap‑up archiving to generate a task log and clean up temporary files. Trigger phrases: “help me make…”, “I want…”, “write a…”, “build a…”, “implement…”, “develop…”, “complete…”, “organize…”, “analyze…”, “process…”, for any task without a clear skill match. When brainstorming, planning‑with‑files, or other slash commands are available, this workflow should be used preferentially.
