Habilidad de flujo de trabajo predeterminada general. Cuando un usuario propone una tarea pero no coincide con habilidades especializadas más específicas, esta habilidad se utiliza como solución alternativa. Proporciona un flujo de trabajo estandarizado de tres etapas: primero una lluvia de ideas para la ideación preliminar y la confirmación del diseño, luego planificación con archivos para el seguimiento de tareas basadas en archivos y, finalmente, cierre y archivado para generar un registro de tareas y limpiar archivos temporales. Frases desencadenantes: ayúdame a hacer, quiero, escribir, construir, implementar, desarrollar, completar, organizar, analizar, procesar cualquier tarea sin una combinación clara de habilidades. Cuando estén disponibles comandos de barra diagonal, como lluvia de ideas y planificación con archivos, priorice el uso de este flujo de trabajo.
