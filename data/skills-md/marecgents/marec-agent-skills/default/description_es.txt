Habilidad de flujo de trabajo predeterminada general. Cuando un usuario propone una tarea pero no coincide con habilidades especializadas más específicas, esta habilidad se utiliza como alternativa. Proporciona un flujo de trabajo estandarizado de tres etapas: primero, lluvia de ideas para la conceptualización temprana y la confirmación del diseño; luego, Planificación con archivos para el seguimiento de tareas basadas en archivos; y finalmente, archivado final para generar un registro de tareas y limpiar archivos temporales. Frases desencadenantes: “ayúdame a hacer…”, “quiero…”, “escribir un…”, “construir un…”, “implementar…”, “desarrollar…”, “completar…”, “organizar…”, “analizar…”, “procesar…”, para cualquier tarea sin una habilidad clara. Cuando se encuentran disponibles la lluvia de ideas, la planificación con archivos u otros comandos de barra diagonal, este flujo de trabajo debe usarse preferentemente.
