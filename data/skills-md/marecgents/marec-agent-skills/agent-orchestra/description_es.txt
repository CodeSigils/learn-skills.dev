SKILL de colaboración entre múltiples agentes: un completo sistema de colaboración entre múltiples agentes con 251 agentes especializados que cubren 19 departamentos. Incluye un agente de programación maestra, agentes de departamento especializados y un agente de revisión. Utilice esta HABILIDAD cuando el usuario necesite completar tareas complejas, colaboración entre dominios, flujos de trabajo de múltiples etapas o tareas que involucren campos profesionales como front-end, back-end, diseño, marketing, seguridad, finanzas, SIG, juegos, etc. Incluso se deben habilitar tareas de un solo dominio con alta complejidad. Nota: No se abstenga de usarlo solo porque el usuario no menciona explícitamente "multiagente": cualquier tarea que implique múltiples habilidades o experiencia es un escenario adecuado para esta HABILIDAD.
