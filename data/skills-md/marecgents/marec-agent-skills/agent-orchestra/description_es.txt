SKILL de colaboración entre múltiples agentes: un sistema completo de múltiples agentes con 251 agentes especializados que cubren 19 departamentos. Incluye un agente de programación central, agentes departamentales especializados y un agente de revisión. Utilice esta HABILIDAD cuando el usuario necesite realizar tareas complejas, colaboración entre dominios, flujos de trabajo de múltiples etapas o tareas que involucren campos especializados como front-end, back-end, diseño, marketing, seguridad, finanzas, SIG, juegos, etc. Incluso las tareas de un solo dominio con alta complejidad deberían activarla. Nota: No omita esta HABILIDAD solo porque el usuario no mencione explícitamente “multiagente”; cualquier tarea que implique múltiples habilidades o experiencia es un escenario adecuado para esta HABILIDAD.
