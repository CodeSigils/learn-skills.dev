مهارة التعاون متعدد الوكلاء - نظام متكامل متعدد الوكلاء يضم 251 وكيلًا متخصصًا يغطون 19 قسمًا. ويشمل وكيل الجدولة المركزي، ووكلاء الإدارات المتخصصة، ووكيل المراجعة. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنجاز مهام معقدة، أو تعاون عبر المجالات، أو سير عمل متعدد المراحل، أو مهام تتضمن مجالات متخصصة مثل الواجهة الأمامية، والواجهة الخلفية، والتصميم، والتسويق، والأمن، والتمويل، ونظم المعلومات الجغرافية، والألعاب، وما إلى ذلك. حتى المهام ذات المجال الفردي ذات التعقيد العالي يجب أن تقوم بتنشيطها. ملحوظة: لا تتخطى هذه المهارة لمجرد أن المستخدم لا يذكر صراحةً "العميل المتعدد" - أي مهمة تتضمن مهارات أو خبرات متعددة تعد سيناريو مناسبًا لهذه المهارة.
