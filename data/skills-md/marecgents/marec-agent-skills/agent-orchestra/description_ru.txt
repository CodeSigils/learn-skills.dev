SKILL Multi-Agent Collaboration SKILL — полноценная мультиагентная система с 251 специализированным агентом, охватывающая 19 отделов. В его состав входят центральный агент по планированию, специализированные агенты департаментов и агент по проверке. Используйте этот НАВЫК, когда пользователю необходимо выполнить сложные задачи, междоменное сотрудничество, многоэтапные рабочие процессы или задачи, затрагивающие специализированные области, такие как интерфейсная часть, серверная часть, дизайн, маркетинг, безопасность, финансы, ГИС, игры и т. д. Его следует активировать даже для однодоменных задач высокой сложности. Примечание. Не пропускайте этот НАВЫК только потому, что пользователь явно не упоминает «многоагентность» — любая задача, требующая нескольких навыков или опыта, является подходящим сценарием для этого НАВЫКА.
