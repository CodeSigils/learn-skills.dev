Vérifiez le journal des modifications de la dernière version de DeepSeek-Reasonix, traduisez-le et résumez-le, comparez-le avec l'ancienne version et enregistrez le rapport dans ./ReasonixUpdateLog/. Utilisez cette compétence lorsque l'utilisateur mentionne « vérifier les mises à jour », « afficher le journal des modifications », « comparaison des versions », « mise à jour de Reasonix » ou « DeepSeek-Reasonix ».  
Veuillez toujours répondre dans la langue de l'utilisateur.
