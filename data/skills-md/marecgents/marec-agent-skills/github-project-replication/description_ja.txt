GitHub オープンソース プロジェクトを再現するための完全なワークフローを自動化します。ユーザーが GitHub プロジェクトを「複製」、「複製」、「再作成」、「デプロイ」、または「セットアップ」する場合、または実行/インストール/デプロイを要求する GitHub リポジトリ URL を提供する場合、この機能を使用する必要があります。プロジェクトの理解、環境構成、コードのセットアップから実行評価、反復修正に至るまでのプロセス全体の自動化をカバーします。ユーザーが単に「このプロジェクトの実行を手伝ってください」、「このリポジトリを試してください」、または「このリポジトリをデプロイしてください」と言った場合でも、この機能はトリガーされる必要があります。また、予備分析のためにブレインストーミングを呼び出したり、タスクの追跡と進捗管理のためにファイルによる計画を呼び出したりします。
