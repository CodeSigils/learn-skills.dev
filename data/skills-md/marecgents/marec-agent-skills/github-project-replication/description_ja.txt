GitHub オープンソース プロジェクトを再現するための完全なワークフローを自動化します。ユーザーが特定の GitHub プロジェクトについて「複製」、「複製」、「再作成」、「デプロイ」、または「セットアップ」に言及した場合、またはプロジェクトの実行/インストール/デプロイを要求する GitHub リポジトリ URL を提供した場合、この機能を使用する必要があります。プロジェクトの理解、環境構成、コードのセットアップから実行評価、反復修正に至るまでの全プロセスの自動化をカバーします。たとえ単に「このプロジェクトの実行を手伝ってください」、「このリポジトリを試してください」、または「このリポジトリをデプロイしてください」と言ったとしても、この機能はトリガーされるはずです。また、事前分析のためのブレーンストーミングや、タスクの追跡と進捗管理のためのファイルによる計画も呼び出されます。 

常にユーザーの言語で応答してください。
