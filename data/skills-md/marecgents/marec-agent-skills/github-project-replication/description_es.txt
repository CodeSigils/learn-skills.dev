Automatice el flujo de trabajo completo de reproducción de un proyecto de código abierto de GitHub. Cuando un usuario menciona "reproducir", "replicar", "recrear", "implementar" o "configurar" un proyecto de GitHub en particular, o proporciona una URL del repositorio de GitHub solicitando ejecutarlo, instalarlo o implementarlo, se debe utilizar esta habilidad. Abarca la automatización completa de un extremo a otro, desde la comprensión del proyecto, la configuración del entorno y la configuración del código hasta la evaluación de la ejecución y las correcciones iterativas. Incluso si el usuario solo dice "ayúdame a ejecutar este proyecto", "prueba este repositorio" o "implementa este repositorio", la habilidad debería activarse. También recurrirá a la lluvia de ideas para el análisis preliminar y la planificación con archivos para el seguimiento de tareas y la gestión del progreso.
