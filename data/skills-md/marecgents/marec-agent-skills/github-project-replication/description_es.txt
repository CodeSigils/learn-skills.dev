Automatice el flujo de trabajo completo para reproducir un proyecto de código abierto de GitHub. Cuando un usuario menciona "reproducir", "replicar", "recrear", "implementar" o "configurar" un proyecto de GitHub, o proporciona una URL del repositorio de GitHub solicitando ejecutar/instalar/implementar, se debe utilizar esta capacidad. Cubre la automatización de todo el proceso, desde la comprensión del proyecto, la configuración del entorno y la configuración del código hasta la evaluación de la ejecución y la corrección iterativa. Incluso si el usuario simplemente dice "ayúdame a ejecutar este proyecto", "prueba este repositorio" o "implementa este repositorio", esta capacidad debería activarse. También recurrirá a la lluvia de ideas para el análisis preliminar y a la planificación con archivos para el seguimiento de tareas y la gestión del progreso.

Por favor responda siempre en el idioma del usuario.
