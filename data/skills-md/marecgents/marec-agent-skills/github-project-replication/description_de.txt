Automatisieren Sie den gesamten Workflow zur Reproduktion eines GitHub-Open-Source-Projekts. Wenn ein Benutzer „reproduzieren“, „replizieren“, „neu erstellen“, „bereitstellen“ oder „einrichten“ eines GitHub-Projekts erwähnt oder eine GitHub-Repository-URL angibt, die die Ausführung/Installation/Bereitstellung anfordert, muss diese Funktion genutzt werden. Es deckt die vollständige Prozessautomatisierung ab, vom Projektverständnis über die Umgebungskonfiguration und Code-Einrichtung bis hin zur Ausführungsbewertung und iterativen Korrektur. Selbst wenn der Benutzer einfach sagt „Helfen Sie mir, dieses Projekt auszuführen“, „Probieren Sie dieses Repo aus“ oder „Stellen Sie dieses Repository bereit“, sollte diese Funktion ausgelöst werden. Außerdem wird Brainstorming zur vorläufigen Analyse und Planung mit Dateien zur Aufgabenverfolgung und Fortschrittsverwaltung aufgerufen.

Bitte antworten Sie immer in der Sprache des Benutzers.
