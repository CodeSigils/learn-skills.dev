Automatisieren Sie den gesamten Workflow zur Reproduktion eines GitHub-Open-Source-Projekts. Wenn ein Benutzer „reproduzieren“, „replizieren“, „neu erstellen“, „bereitstellen“ oder „einrichten“ eines GitHub-Projekts erwähnt oder eine GitHub-Repository-URL mit der Aufforderung zur Ausführung, Installation oder Bereitstellung angibt, muss diese Funktion genutzt werden. Es umfasst die vollständige Prozessautomatisierung vom Projektverständnis über die Umgebungskonfiguration und Codeeinrichtung bis hin zur Ausführungsbewertung und iterativen Korrektur. Selbst wenn der Benutzer einfach sagt „Helfen Sie mir, dieses Projekt auszuführen“, „Probieren Sie dieses Repo aus“ oder „Stellen Sie dieses Repository bereit“, sollte diese Funktion ausgelöst werden. Außerdem wird Brainstorming zur vorläufigen Analyse eingesetzt und Planung mit Dateien zur Aufgabenverfolgung und Fortschrittsverwaltung verwendet.
