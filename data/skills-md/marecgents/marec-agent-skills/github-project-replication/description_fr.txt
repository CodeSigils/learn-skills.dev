Automatisez le flux de travail complet de reproduction d’un projet open source GitHub. Lorsqu'un utilisateur mentionne « reproduire », « répliquer », « recréer », « déployer » ou « configurer » un projet GitHub, ou fournit une URL de référentiel GitHub demandant de l'exécuter, de l'installer ou de le déployer, cette fonctionnalité doit être utilisée. Il couvre l'intégralité de l'automatisation de bout en bout, depuis la compréhension du projet, la configuration de l'environnement et la configuration du code jusqu'à l'évaluation de l'exécution et la correction itérative. Même si l'utilisateur dit seulement « aidez-moi à exécuter ce projet », « essayez ce référentiel » ou « déployez ce référentiel », cette fonctionnalité doit être déclenchée. Il fera également appel au brainstorming pour une analyse préliminaire et à la planification avec des fichiers pour le suivi des tâches et la gestion des progrès.
