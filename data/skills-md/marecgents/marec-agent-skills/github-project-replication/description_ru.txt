Автоматизируйте весь рабочий процесс воспроизведения проекта GitHub с открытым исходным кодом. Когда пользователь упоминает «воспроизведение», «реплицирование», «воссоздание», «развертывание» или «настройку» проекта GitHub или предоставляет URL-адрес репозитория GitHub с запросом на запуск/установку/развертывание, необходимо использовать эту возможность. Он охватывает полную автоматизацию процессов: от понимания проекта, настройки среды и настройки кода до оценки выполнения и итеративного исправления. Даже если пользователь просто говорит «помогите мне запустить этот проект», «попробуйте этот репозиторий» или «разверните этот репозиторий», эта возможность должна быть активирована. Он также будет использовать мозговой штурм для предварительного анализа и планирование с использованием файлов для отслеживания задач и управления ходом выполнения.
