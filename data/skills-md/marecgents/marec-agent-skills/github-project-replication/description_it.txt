Automatizza il flusso di lavoro completo per la riproduzione di un progetto open source GitHub. Quando un utente menziona "riprodurre", "replicare", "ricreare", "distribuire" o "configurare" un progetto GitHub o fornisce un URL del repository GitHub richiedendone l'esecuzione/installazione/distribuzione, è necessario utilizzare questa funzionalità. Copre l'automazione dell'intero processo, dalla comprensione del progetto, alla configurazione dell'ambiente e all'impostazione del codice, fino alla valutazione dell'esecuzione e alla correzione iterativa. Anche se l'utente dice semplicemente "aiutami a eseguire questo progetto", "prova questo repository" o "distribuisci questo repository", questa funzionalità dovrebbe essere attivata. Utilizzerà inoltre il brainstorming per l'analisi preliminare e la pianificazione con file per il monitoraggio delle attività e la gestione dei progressi.

Si prega di rispondere sempre nella lingua dell'utente.
