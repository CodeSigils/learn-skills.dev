Улучшите внутреннюю структуру кода, сохранив при этом наблюдаемое извне поведение. Используйте для очистки с конкретной структурной целью, например, для уменьшения дублирования или сложности. Не используйте, когда основной запрос добавляет поведение, исправляет дефект, исследует причину или только проверяет изменения.
