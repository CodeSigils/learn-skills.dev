Создавайте видеозапись/закадровый звук (закадровый голос) + точно синхронизированные субтитры SRT (преобразование текста в речь/TTS). Предпочтительно: собственный файл ListenHub /v1/speech (движок предоставляет субтитры, текст = ввод оригинала, отсутствие ошибок распознавания), с облачным ASR (Groq / OpenAI Whisper) в качестве резерва + коррекция субтитров на уровне текста; один вызов одновременно создает narration-full.mp3 + narration.srt. Два триггерных сценария: 1) Пользователь имеет только устный сценарий и хочет «сделать озвучку/преобразование текста в речь/повествование + субтитры/преобразование текста в речь с субтитрами» или предоставляет рукопись (ежедневный отчет/анализ/повествование) и хочет аудиофайл + субтитры; они также могут выбрать тон голоса («изменить голос», «использовать женский голос»). 2) Любой рабочий процесс с видео, которому необходимо генерировать речь/повествование на этом этапе, выбирает его — создание видео / безликого объяснителя / видеоролика о запуске продукта и источника голоса для всех видеопродукций HyperFrames; Особенно его использует китайское повествование (встроенный TTS Kokoro в HyperFrames не поддерживает китайский язык), а предоставляемый им SRT является именно тем источником фактов, который необходим для синтезированной временной шкалы. Никакого клонирования голоса (используйте облачную TTS, поддерживающую клонирование), никакого производства видео (то есть создания видео).
