Generieren Sie Video-Voiceover/Audio (Voiceover) + zeitlich genau abgestimmte SRT-Untertitel (Text-to-Speech/TTS). Bevorzugt ist ListenHub natives /v1/speech (Engine stellt Untertitel bereit, Text = Originaleingabe, keine Erkennungsfehler), mit Cloud ASR (Groq / OpenAI Whisper) als Fallback + Untertitelkorrektur auf Textebene; Ein einzelner Aufruf erzeugt gleichzeitig narration-full.mp3 + narration.srt. Zwei Auslösertypen: 1) Der Benutzer verfügt nur über ein gesprochenes Skript und möchte „Voiceover / Text-to-Speech / Voiceover + Untertitel / Text-to-Speech mit Untertiteln machen“ oder einen Entwurf (Tagesbericht / Kommentar / Voiceover) bereitstellen und Audio + Untertitel wünschen; Sie können auch den Ton der Stimme auswählen („Stimme ändern“, „weibliche Stimme verwenden“). 2) Jeder Video-Workflow, der in diesem Schritt Sprache/Voiceover erzeugen muss, wählt ihn aus – für die Produktion von Videos, Erklärvideos ohne Gesichtserkennung, Produkteinführungsvideos und allen HyperFrames-Ausgabe-Voiceover-Quellen. Chinesischer Voiceover verwendet es insbesondere (das integrierte Kokoro TTS von HyperFrames unterstützt kein Chinesisch), und das von ihm bereitgestellte SRT ist genau die sachliche Quelle, die für die synthetisierte Zeitleiste benötigt wird. Kein Sprachklonen (verwenden Sie Cloud-TTS, das das Klonen unterstützt), keine Videoproduktion (das heißt Video produzieren).
