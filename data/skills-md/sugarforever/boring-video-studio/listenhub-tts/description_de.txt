Generieren Sie Videokommentare/Voiceover-Audio (Voiceover) + präzise getimte SRT-Untertitel (Text-to-Speech / TTS). Bevorzugt: ListenHub nativ /v1/speech (Engine stellt Untertitel bereit, Text = Eingabeoriginal, keine Erkennungsfehler), mit Cloud ASR (Groq / OpenAI Whisper) als Fallback + Untertitelkorrektur auf Textebene; Ein einzelner Aufruf erzeugt gleichzeitig narration-full.mp3 + narration.srt. Zwei Auslöseszenarien: 1) Der Benutzer verfügt nur über ein gesprochenes Skript und möchte „einen Voiceover / Text-to-Speech / Erzählung + Untertitel / Text-to-Speech mit Untertiteln erstellen“ oder er stellt ein Manuskript (Tagesbericht / Analyse / Erzählung) bereit und möchte eine Audiodatei + Untertitel; Sie können auch den Ton der Stimme auswählen („Stimme ändern“, „weibliche Stimme verwenden“). 2) Jeder Video-Workflow, der in diesem Schritt Sprache/Kommentar erzeugen muss, wählt ihn aus – zum Produzieren von Videos, Erklärvideos ohne Gesichtserkennung, Produkteinführungsvideos und der Sprachquelle aller HyperFrames-Videoproduktionen. Insbesondere in chinesischen Erzählungen wird es verwendet (das integrierte Kokoro TTS von HyperFrames unterstützt kein Chinesisch), und das von ihm bereitgestellte SRT ist genau die Faktenquelle, die für die synthetisierte Zeitleiste benötigt wird. Kein Sprachklonen (verwenden Sie Cloud-TTS, das das Klonen unterstützt), keine Videoproduktion (das heißt Video produzieren).
