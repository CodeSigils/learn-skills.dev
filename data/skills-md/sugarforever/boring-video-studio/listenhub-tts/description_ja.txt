ビデオナレーション/ナレーションオーディオ (ナレーション) + タイムラインに正確な SRT 字幕 (テキスト読み上げ / TTS) を生成します。代替としてクラウド ASR (Groq / OpenAI Whisper) を使用した ListenHub ネイティブ /v1/speech (エンジンが字幕を提供、テキスト=入力オリジナル、認識エラーなし) が推奨されます + テキストレベルの字幕修正。 1 回の呼び出しで、narration-full.mp3 + narration.srt が同時に生成されます。 2 つのトリガー タイプ: 1) ユーザーは音声テキストのみを持っており、「ナレーション / テキスト読み上げ / ナレーション + 字幕 / 字幕付きテキスト読み上げ」を希望するか、またはスクリプト (日報 / 解説 / ナレーション) を提供し、音声 + 字幕を希望します。声の音色を選択することもできます (「声を変更する」、「女性の声を使用する」)。 2) このステップで音声/ナレーションを生成する必要があるビデオ ワークフローは、それを選択します。これは、ビデオ制作、顔のない説明者、製品発表ビデオなど、すべての HyperFrames プロダクションのナレーションのソースです。特に中国語のナレーションで使用されます (HyperFrames に組み込まれている Kokoro TTS は中国語をサポートしていません)。提供される SRT は、合成されたタイムラインに必要な事実のソースです。音声クローン作成 (クローン作成をサポートするクラウド TTS を使用) やビデオ制作 (ビデオの制作) はありません。
