ビデオ ナレーション/ナレーション オーディオ (ナレーション) + 正確なタイミングでの SRT 字幕 (テキスト読み上げ / TTS) を生成します。推奨: ListenHub ネイティブ /v1/speech (エンジンが字幕を提供、テキスト = 入力オリジナル、認識エラーなし)、フォールバックとしてクラウド ASR (Groq / OpenAI Whisper) + テキストレベルの字幕修正を使用。 1 回の呼び出しで、narration-full.mp3 + narration.srt が同時に生成されます。 2 つのトリガー シナリオ: 1) ユーザーは音声スクリプトのみを持っており、「ナレーション / テキスト読み上げ / ナレーション + 字幕 / 字幕付きテキスト読み上げ」を希望するか、原稿 (日次レポート / 分析 / ナレーション) を提供し、音声ファイル + 字幕を希望します。声のトーンを選択することもできます (「声を変更する」、「女性の声を使用する」)。 2) このステップで音声/ナレーションを生成する必要があるビデオ ワークフロー (制作ビデオ、顔のない説明者、製品発表ビデオ、およびすべての HyperFrames ビデオ作品の音声ソース) が選択されます。特に中国語のナレーションで使用されます (HyperFrames に組み込まれている Kokoro TTS は中国語をサポートしていません)。提供される SRT は、合成されたタイムラインに必要な事実に基づいたソースです。音声クローン作成 (クローン作成をサポートするクラウド TTS を使用) やビデオ制作 (ビデオの制作) はありません。
