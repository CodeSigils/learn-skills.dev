Создавайте видеоролики с повествованием на основе слайдов (口播视频), где каждый слайд соответствует 1:1 одному разделу закадрового голоса. Организует «журнал-веб-ppt» (PPT) и «видео-сценарий» (сценарий + издательские материалы) с производственным рабочим процессом, ориентированным на метод. Используйте, когда пользователь хочет создать видео, в котором для объяснения темы используются слайды – например. 发布解读 / 产品评测 / 行业观察 / 技术解读 / 趋势分析. Запускается по запросам «做一期视频 + PPT», «Слайды 视频», «发布解读视频», «深度讲解视频» или аналогичным запросам на видео со структурированным повествованием.
