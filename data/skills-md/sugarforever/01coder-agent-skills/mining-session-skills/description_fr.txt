Passez en revue une session Claude Code terminée et proposez une compétence à créer, mettre à jour ou réutiliser afin qu'un travail similaire aille plus vite la prochaine fois. À utiliser lorsque l'utilisateur demande « d'exploiter une session pour des compétences », « quelle compétence peut être créée ou mise à jour à partir de la session où je… », « d'extraire une compétence de cette discussion » ou de revoir une session passée pour des flux de travail réutilisables. Fonctionne sur la démarque de session exportée depuis Claude-session-manager. Pas pour exporter/convertir des sessions (utilisez claude-session-manager) et pas pour écrire des blogs ou des TODO à partir de sessions.
