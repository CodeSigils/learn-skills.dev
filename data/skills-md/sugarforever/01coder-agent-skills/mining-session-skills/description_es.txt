Revise una sesión completa de Claude Code y proponga una habilidad para crear, actualizar o reutilizar para que un trabajo similar sea más rápido la próxima vez. Úselo cuando el usuario solicite "extraer una sesión en busca de habilidades", "qué habilidad se puede crear o actualizar desde la sesión en la que...", "extraer una habilidad de este chat" o revisar una sesión pasada para flujos de trabajo reutilizables. Opera con la rebaja de sesión exportada desde claude-session-manager. No para exportar/convertir sesiones (use claude-session-manager) y no para escribir blogs o TODOs a partir de sesiones.
