Просмотрите один завершенный сеанс Claude Code и предложите навык для создания, обновления или повторного использования, чтобы в следующий раз подобная работа выполнялась быстрее. Используйте, когда пользователь просит «извлечь в сеансе навыки», «какой навык можно создать или обновить из сеанса, в котором я…», «извлечь навык из этого чата» или просмотреть прошлый сеанс на предмет рабочих процессов, которые можно повторно использовать. Работает с экспортированной уценкой сеанса из claude-session-manager. Не для экспорта/конвертирования сессий (используйте claude-session-manager), а также для написания блогов или TODO из сессий.
