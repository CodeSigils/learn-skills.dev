قم بمراجعة جلسة Claude Code مكتملة واقترح مهارة لإنشاء أو تحديث أو إعادة استخدام بحيث يتم العمل المماثل بشكل أسرع في المرة القادمة. يُستخدم عندما يطلب المستخدم "استخراج جلسة للمهارات"، أو "ما هي المهارة التي يمكن إنشاؤها أو تحديثها من الجلسة حيث..."، أو "استخراج مهارة من هذه الدردشة"، أو لمراجعة جلسة سابقة لسير العمل القابل لإعادة الاستخدام. يعمل على تخفيض الجلسة المصدرة من claude-session-manager. ليس لتصدير/تحويل الجلسات (استخدم claude-session-manager) وليس لكتابة المدونات أو المهام من الجلسات.
