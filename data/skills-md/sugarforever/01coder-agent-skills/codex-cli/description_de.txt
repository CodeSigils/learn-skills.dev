Wird verwendet, wenn ein Agent eine Aufgabe aus einer anderen Agentenumgebung wie Claude Code, OpenClaw oder ähnlichem an die OpenAI Codex CLI delegieren muss. Behandelt die Überprüfung, ob Codex CLI installiert ist, das Ausführen einmaliger Codex-Eingabeaufforderungen mit „codex exec“, das Fortsetzen von Sitzungen, das Sammeln von Ausgaben, das Anhängen von Bildern oder Dateien als Eingabe mit „-i“/stdin und die Handhabung der Codex-Bildgenerierung, einschließlich der Suche und Meldung generierter Bilddateipfade.
