Da utilizzare quando un agente deve delegare un'attività alla CLI OpenAI Codex da un altro ambiente agente come Claude Code, OpenClaw o simili. Riguarda il controllo se la CLI del Codex è installata, l'esecuzione di richieste Codex una tantum con `codex exec`, la ripresa delle sessioni, la raccolta di output, l'allegato di immagini o file come input con `-i`/stdin e la gestione della generazione di immagini del Codex, inclusa la ricerca e il reporting dei percorsi dei file di immagine generati.
