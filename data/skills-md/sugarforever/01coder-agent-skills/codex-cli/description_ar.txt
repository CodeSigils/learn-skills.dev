يُستخدم عندما يحتاج الوكيل إلى تفويض مهمة إلى OpenAI Codex CLI من بيئة وكيل أخرى مثل Claude Code أو OpenClaw أو ما شابه. يغطي التحقق من تثبيت Codex CLI، وتشغيل مطالبات Codex لمرة واحدة باستخدام `codex exec`، واستئناف الجلسات، وجمع المخرجات، وإرفاق الصور أو الملفات كمدخلات باستخدام `-i`/stdin، والتعامل مع إنشاء صور Codex بما في ذلك البحث عن مسارات ملفات الصور التي تم إنشاؤها والإبلاغ عنها.
