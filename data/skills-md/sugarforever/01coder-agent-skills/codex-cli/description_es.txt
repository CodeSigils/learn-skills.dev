Úselo cuando un agente necesita delegar una tarea a la CLI de OpenAI Codex desde otro entorno de agente como Claude Code, OpenClaw o similar. Cubre verificar si Codex CLI está instalado, ejecutar mensajes únicos de Codex con `codex exec`, reanudar sesiones, recopilar resultados, adjuntar imágenes o archivos como entrada con `-i`/stdin y manejar la generación de imágenes de Codex, incluida la búsqueda e informes de rutas de archivos de imágenes generadas.
