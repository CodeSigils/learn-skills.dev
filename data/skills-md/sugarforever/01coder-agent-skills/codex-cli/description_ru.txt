Используйте, когда агенту необходимо делегировать задачу интерфейсу командной строки OpenAI Codex из другой среды агента, такой как Claude Code, OpenClaw или аналогичной. Охватывает проверку того, установлен ли интерфейс командной строки Кодекса, запуск одноразовых запросов Кодекса с помощью `codex exec`, возобновление сеансов, сбор выходных данных, прикрепление изображений или файлов в качестве входных данных с помощью `-i`/stdin, а также обработку создания изображений Кодекса, включая поиск и создание отчетов о путях к файлам сгенерированных изображений.
