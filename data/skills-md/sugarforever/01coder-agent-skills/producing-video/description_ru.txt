Превратите предоставленный пользователем аудиофайл с закадровым голосом + субтитры SRT в готовый MP4 с синхронизированным речевым сопровождением с помощью HyperFrames (HTML-to-video). Звук + SRT являются источником истины — сцены синхронизируются с сигналами SRT, контент считывается из SRT, а звук автоматически мультиплексируется. Используйте, когда пользователь передает mp3/wav + srt и хочет видео, говорит «把音频做成视频», «做一期视频», «audio + srt to video», «把这期早读做成视频», «преобразовать это повествование в видео» или предоставляет запись. + субтитры к пояснителю /ежедневно/解读/口播. НЕ для создания озвучки (здесь это работа пользователя) и НЕ для слайдов (используйте навык слайдов).
