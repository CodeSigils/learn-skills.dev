قم بتحويل ملف صوتي للتعليق الصوتي مقدم من المستخدم + عنوان فرعي SRT إلى ملف MP4 نهائي ومتزامن مع السرد باستخدام HyperFrames (HTML-to-video). الصوت + SRT هما مصدر الحقيقة - يتم توقيت المشاهد وفقًا لإشارات SRT، وتتم قراءة المحتوى من SRT، ويتم دمج الصوت تلقائيًا. يُستخدم عندما يقوم المستخدم بتسليم ملف mp3/wav + srt ويريد مقطع فيديو، ويقول "把音频做成视频" أو "做一期视频" أو "audio + srt to video" أو "把这期早读做成视频" أو "حول هذا السرد إلى فيديو" أو يوفر تسجيل + ترجمات لشرح / يوميا / 解读 / 口播. ليس لإنشاء التعليق الصوتي (هذه هي وظيفة المستخدم هنا) وليس لمجموعات الشرائح (استخدم مهارة الشرائح).
