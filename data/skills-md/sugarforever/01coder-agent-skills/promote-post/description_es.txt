Escribe un tweet promocional para un artículo publicado. Toma la URL de una publicación (Substack, artículo X, blog) y crea un tweet teaser que abre la historia y atrae a los lectores; no es un resumen, sino un gancho que lleva naturalmente a hacer clic en el enlace. Úselo cuando el usuario diga "promocionar esta publicación", "escriba un tweet para este artículo", "推广这篇文章", o proporcione un enlace y solicite escribir un tweet promocional.
