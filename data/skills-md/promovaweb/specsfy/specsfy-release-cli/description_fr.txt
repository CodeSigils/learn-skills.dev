Publier une version de Specsfy CLI à partir du monorepo promovaweb/specsfy, en gardant le paquet, l'exécutable, CHANGELOG.md, le commit, le tag et les versions GitHub cohérentes. Utilisez quand une personne souhaite lancer ou revenir à une version de la CLI. Ne pas utiliser les pré-versions comme des fonctionnalités permettant de mettre à jour la CLI d'un consommateur.
