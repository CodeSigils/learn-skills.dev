Pubblicare una versione è di Specsfy CLI a partire dal monorepo promovaweb/specsfy, mantenendo pacchetto, eseguibile, CHANGELOG.md, commit, tag e GitHub Release coerenti. Utilizzare quando la persona chiede di lanciare o ripristinare una versione della CLI. Non utilizzare per le versioni preliminari né solo per aggiornare la CLI di un consumatore.
