Utilice cuando el usuario pede para promover una entrada o trabajo pendiente y refinar, escribir, iniciar o consolidar una especificación nueva o adicional en Draft em `spec.md`. Use también cuando una transición automática requiera criar o completar una fuente normativa inicial. Inicializa specs en `specs/draft/` y aplica o MCR-10; Para cambiar las especificaciones aprobadas use specsfy-update-spec, para capturarlas sin problemas use specsfy-01-inbox, para refinar use specsfy-02-backlog y para revisar sin edición use specsfy-04-validate.
