Consultez la documentation officielle du projet spécifique Specsfy dans le monorepo promovaweb/specsfy. Utilisez quelque chose comme officiel quand vous avez besoin de documenter ou de spécifier, de concilier les changements transversaux, de réviser les documents/develop/context/ ou d'actualiser les guides dans docs/user/. Ne pas utiliser dans les projets des consommateurs ; Pour reconstruire la documentation d'une application, utilisez specsfy-documentator.
