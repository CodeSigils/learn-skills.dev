Führen Sie eine offizielle Dokumentation Ihres Specsfy-Projekts durch, ohne dass die Promovaweb/specsfy-Datei verwendet wird. Verwenden Sie zum Dokumentieren oder Bearbeiten von Specsfy einige offizielle Dokumente, vergleichen Sie sie mit anderen, überprüfen Sie docs/develop/context/ oder aktualisieren Sie die Anleitungen in docs/user/. Verwenden Sie keine Projekte für Verbraucher. Um die Dokumentation einer Anwendung zu rekonstruieren, verwenden Sie specsfy-documentator.
