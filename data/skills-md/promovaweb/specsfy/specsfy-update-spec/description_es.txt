Use quando o usuário esqueceu algo, quer adicionar, remover, corregir o mudar un pedido en una especificación existente que já foi definida, planejada, se está sendo implementada o foi concluída. Use también cuando una transición automática detecte cambios tardíos de comportamiento, escopo, aceite, dados, seguridad o plano. Atualiza a fonte normativa, invalida somente os gates afetados e coordina a retomada; para crear una especificación inicial use specsfy-03-specify, para decidir una ambigüedad use specsfy-02-backlog y para implementar use specsfy-07-implement.
