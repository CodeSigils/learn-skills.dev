استخدم عندما يقوم المستخدم بإنشاء شيء ما، أو إضافة أو إزالة أو تصحيح أو تعديل طلب في مواصفات موجودة تم تحديدها أو تخطيطها أو إرسالها إلى التنفيذ أو خلاصتها. استخدم أيضًا عند اكتشاف انتقال تلقائي لتأخر السلوك أو الهروب أو الثقل أو البيانات أو الأمان أو التخطيط. تحديث الخط المعياري، وإلغاء بعض البوابات المحذوفة وتنسيقها مرة أخرى؛ لإنشاء مواصفات أولية باستخدام specsfy-03-specify، لتحديد استخدام غامض specsfy-02-backlog وتنفيذ استخدام specsfy-07-implement.
