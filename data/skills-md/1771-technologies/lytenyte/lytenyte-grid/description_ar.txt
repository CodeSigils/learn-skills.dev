استخدم هذه المهارة عندما يعمل المستخدم مع LyteNyte Grid (@1771technologies/lytenyte-pro أو @1771technologies/lytenyte-core)، وهي شبكة بيانات React مقطوعة الرأس. قم بالتنشيط لمهام مثل: تثبيت الشبكة أو ترخيصها، أو تكوين الأعمدة أو الصفوف، أو إنشاء عارضي الخلايا أو محرريها، أو إضافة المرشحات أو عناصر التحكم في الفرز، أو تجميع الصفوف أو تجميعها، أو التمحور، أو التصدير إلى CSV/Excel/Parquet/Arrow، واختيار الصف، واختيار نطاق الخلية، والسمات أو التصميم، وأنماط TypeScript GridSpec، وبيانات جانب الخادم أو الشجرة، وأي مكون PRO (SmartSelect، وPillManager، وMenu، الحوار، TreeView، RowGroupCell). يتم التنشيط أيضًا عندما يصف المستخدم مشكلات الشبكة دون تسمية الحزمة - على سبيل المثال. "لن يتم تجميع الصفوف الخاصة بي"، "الخلايا غير قابلة للتحرير"، "إضافة تراكب تحميل"، "تثبيت هذا العمود"، "الفلتر لا يعمل"، "كيف يمكنني تصدير هذا الجدول"، "تحديد نطاق من الخلايا"، "نسخ الخلايا إلى الحافظة".
