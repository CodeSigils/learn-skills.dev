Utilice esta habilidad cuando el usuario esté trabajando con LyteNyte Grid (@1771technologies/lytenyte-pro o @1771technologies/lytenyte-core), una cuadrícula de datos de React sin cabeza. Actívelo para tareas como: instalar o obtener licencias de la cuadrícula, configurar columnas o filas, crear procesadores o editores de celdas, agregar filtros o controles de clasificación, agrupar o agregar filas, pivotar, exportar a CSV/Excel/Parquet/Arrow, selección de filas, selección de rango de celdas, temas o estilos, patrones de TypeScript GridSpec, datos del lado del servidor o de árbol y cualquier componente PRO (SmartSelect, PillManager, Menú, Diálogo, TreeView, CeldaGrupoFila). Actívelo también cuando el usuario describa problemas de la red sin nombrar el paquete, p. "mis filas no se agrupan", "las celdas no son editables", "agregar una superposición de carga", "fijar esta columna", "el filtro no funciona", "cómo exporto esta tabla", "selecciono un rango de celdas", "copia celdas al portapapeles".
