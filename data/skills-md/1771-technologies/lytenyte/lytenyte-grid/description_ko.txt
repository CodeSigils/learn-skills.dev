사용자가 헤드리스 React 데이터 그리드인 LyteNyte Grid(@1771technologies/lytenyte-pro 또는 @1771technologies/lytenyte-core)로 작업할 때 이 기술을 사용하세요. 그리드 설치 또는 라이센스 부여, 열 또는 행 구성, 셀 렌더러 또는 편집기 구축, 필터 또는 정렬 컨트롤 추가, 행 그룹화 또는 집계, 피벗, CSV/Excel/Parquet/Arrow로 내보내기, 행 선택, 셀 범위 선택, 테마 지정 또는 스타일 지정, TypeScript GridSpec 패턴, 서버 측 또는 트리 데이터 및 모든 PRO 구성 요소(SmartSelect, PillManager, 메뉴, 대화 상자, TreeView, RowGroupCell)와 같은 작업을 활성화합니다. 또한 사용자가 패키지 이름을 지정하지 않고 그리드 문제를 설명할 때 활성화됩니다. "내 행이 그룹화되지 않습니다", "셀을 편집할 수 없습니다", "로딩 오버레이 추가", "이 열 고정", "필터가 작동하지 않습니다", "이 테이블을 내보내는 방법", "셀 범위 선택", "셀을 클립보드에 복사".
