Use when the user wants to start a learning or study session, says "let's study", asks to learn a specific topic, or continues from a previous session. Trigger on: "let's study X", "teach me about X", "I want to learn X", "continue from last time", "let's pick up where we left off", "session time", or any message that clearly signals the user is ready to start studying. This is the core Socrates-7 skill — it runs the full Socratic teaching session from start to finish.
