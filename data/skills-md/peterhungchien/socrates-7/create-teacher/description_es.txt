Utilícelo cuando el usuario desee configurar una personalidad de profesor, configurar un perfil de alumno o inicializar el directorio de profesores para un proyecto de aprendizaje. Se activa cuando el usuario dice cosas como "configurar mi maestro", "crear una persona", "Quiero comenzar a aprender con Socrates-7", "iniciar mi configuración de aprendizaje" o "ayúdame a diseñar un maestro". Esta habilidad DEBE ejecutarse antes de que pueda comenzar cualquier sesión de enseñanza; invoquela de manera proactiva si no existe ningún maestro/directorio en el espacio de trabajo.
