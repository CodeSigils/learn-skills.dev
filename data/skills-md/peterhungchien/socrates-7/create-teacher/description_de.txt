Verwenden Sie diese Option, wenn der Benutzer eine Lehrerpersönlichkeit einrichten, ein Lernerprofil konfigurieren oder das Lehrerverzeichnis für ein Lernprojekt initialisieren möchte. Wird ausgelöst, wenn der Benutzer Dinge sagt wie „Meinen Lehrer einrichten“, „Eine Persona erstellen“, „Ich möchte mit Socrates-7 lernen“, „Meine Lerneinrichtung initialisieren“ oder „Hilf mir, einen Lehrer zu entwerfen“. Dieser Skill MUSS ausgeführt werden, bevor eine Unterrichtssitzung beginnen kann. Rufen Sie ihn proaktiv auf, wenn im Arbeitsbereich kein Lehrer-/Verzeichnis vorhanden ist.
