When the user says “update the index,” “add this to the index,” “added a new file,” “newly added a book / a note / a document,” or “the material library index needs updating,” the 【Incremental Maintenance Mode】 of this skill should be used.  
When the user says “index health check,” “index checkup,” “check the index,” “index sync,” or “fill in the index,” the 【Health‑Check Mode】 of this skill should be used, scanning all libraries ↔ INDEX to find missing or invalid entries and batch‑fill them.  

Applicable to all libraries that contain an INDEX.md: reading‑note libraries, core‑concept libraries, viral‑script libraries, 04‑Methodology repositories, and any future libraries that will be created.  

The value of the index depends on content accuracy—​the original text must be read in full before writing to the index; inferring from file names or memory will cause the index to lose its reference value.  

Even if the user only says “I added a file” or “put this in,” as long as it involves the index, this skill should be triggered.  

Do not trigger: merely browsing the index (direct Read), deepening a topic (using li‑topic), generating a script (using li‑writer).  

Use when the user adds new content to any indexed library, OR runs a global index health‑check to find missing/stale entries.
