當使用者說「update index」「add this to the index」「added a new file」「added a new book/a note/a document」或「the material library index needs updating」時，應使用此技能的增量維護模式。  
當使用者說「index health check」「index checkup」「check index」「index synchronization」或「fill missing index」時，應使用此技能的健康檢查模式，掃描所有 ↔ INDEX 的圖書館，以找出缺失或過時的條目並批次完成。  
此規則適用於所有包含 INDEX.md 的圖書館：reading‑notes library、core‑concepts library、popular‑script library、04‑methodology repository，以及未來可能建立的任何圖書館。  
索引的價值取決於內容的準確性——必須先完整閱讀原文才可寫入；僅憑檔名或印象推測會使索引失去參考價值。  
即使使用者僅說「I added a file」或「put this in」，只要涉及索引，也應觸發此技能。  
不應觸發的情況：僅瀏覽索引（直接 Read）、深化主題選擇（使用 li‑topic）、產生腳本（使用 li‑writer）。  

使用時機：使用者向任何已索引的圖書館新增內容，或執行全域索引健康檢查以找出缺失／過時條目時。  

請始終以使用者的語言回應。
