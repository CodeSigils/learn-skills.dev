사용자가 “/li”라고 말하거나 콘텐츠 생성과 관련된 요청을 했지만 의도가 모호하고 어떤 도구를 사용해야 할지 명확하지 않을 때 이 스킬을 사용합니다. li 툴박스의 주요 진입점으로서, 의도를 판단하고 적절한 전문 스킬로 라우팅합니다.

트리거하지 말 것: 사용자의 요청이 특정 li‑* 스킬과 명확히 일치할 경우(예: “write script” → li‑writer, “deepen topic” → li‑topic) 이 진입점이 아닌 해당 스킬을 직접 트리거합니다.

콘텐츠 생성이 아닌 작업에 대해서는 트리거하지 마세요. 사용자가 “/li”라고 말했거나 의도가 여러 li‑* 도구에 걸쳐 모호할 때 사용합니다.
