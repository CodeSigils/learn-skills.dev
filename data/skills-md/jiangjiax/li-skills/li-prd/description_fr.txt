Outil de génération de PRD produit. En combinant la méthodologie de l’histoire produit de « Create », le cadre de positionnement produit et les meilleures pratiques de PRD du Newsletter de Lenny, il vous aide à transformer une idée en un document de spécifications produit exécutable.

Phrases déclencheuses : /li-prd, « aide‑moi à rédiger un PRD », « générer un document d’exigences », « écrire un document produit », « transformer cette idée en PRD », « PRD hackathon », « organiser les exigences produit », « je suis sur le point de commencer, aide‑moi à clarifier les exigences ».

Même si l’utilisateur ne dit pas « PRD », tant qu’il veut organiser une idée produit dans un document exécutable, cette compétence doit être déclenchée.

NE PAS déclencher pour : génération de script de contenu, analyse de sujet, révision de données et autres tâches de création de contenu.

Veuillez toujours répondre dans la langue de l’utilisateur.
