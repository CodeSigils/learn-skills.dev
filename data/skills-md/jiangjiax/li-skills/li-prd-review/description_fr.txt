Mode Consultant Expert PRD. Trois PM/PDG bien connus agissent en tant que consultants, révisant de manière proactive le PRD, identifiant les points faibles et fournissant des suggestions d'amélioration qui peuvent être directement écrites dans le document ; l'utilisateur décide de les adopter ou non en acceptant ou en rejetant. Méthodes de déclenchement : /li-prd-review, « renforcer le PRD », « consultant expert », « aide‑moi à examiner ce PRD », « laisse un expert réviser le PRD », « quelles vulnérabilités le PRD possède‑t‑il », « aide‑moi à optimiser le PRD », « quels autres problèmes le PRD présente‑t‑il ». Même si l'utilisateur ne mentionne pas « PRD », tant qu'il souhaite qu'un rôle d'expert examine un document produit et fournisse des suggestions d'amélioration, cette compétence doit être déclenchée. NE PAS déclencher pour : les tâches de génération de PRD (utilisant li-prd), la génération de scripts de contenu, l'analyse de sujet et autres tâches de création de contenu. Veuillez toujours répondre dans la langue de l'utilisateur.
