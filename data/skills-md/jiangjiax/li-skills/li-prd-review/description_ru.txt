Режим эксперта-консультанта PRD. Три известных менеджера по проектам/генеральному директору выступают в качестве консультантов, активно проверяют PRD, выявляют слабые места и предоставляют предложения по улучшению, которые могут быть непосредственно записаны в документе; пользователь решает, принять их, приняв или отклонив.  
Триггерные фразы: /li-prd-review, «усилить PRD», «эксперт-консультант», «помогите мне посмотреть на этот PRD», «позволить эксперту рассмотреть PRD», «какие уязвимости есть у PRD», «помогите мне оптимизировать PRD», «какие еще проблемы есть у PRD».  
Даже если пользователь не упоминает «PRD», если он хочет, чтобы роль эксперта проверяла документацию по продукту и давала предложения по улучшению, этот навык должен быть задействован.  
НЕ ИСПОЛЬЗУЙТЕ для: задач создания PRD (с использованием li-prd), создания сценариев контента, анализа тем и других задач создания контента.
