When a user says “record a topic,” “new topic,” “how about this topic,” “I have an idea,” “help me note this,” or shares a rough content idea that needs assessment and recording, this skill should be used. Even if the user merely mentions a content idea in passing, the evaluation process should be proactively triggered; do not wait for the user to explicitly say “record.”

First, use the five‑dimensional logic of dbs‑content to diagnose whether the topic is worth pursuing; only if it is worthwhile should it be recorded, and then, by analogy, recommend 3–5 similar topics.

It should not be triggered for: deepening a topic to generate an outline (using li‑topic), directly writing a script (using li‑writer), or AI polishing/beautifying a topic title.

Use when the user wants to “record a topic,” “log a topic idea,” “is this topic worth doing,” or shares a rough content concept needing diagnosis and logging.

Please always respond in the user’s language.
