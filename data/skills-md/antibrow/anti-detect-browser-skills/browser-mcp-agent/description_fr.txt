Donnez à un agent IA son propre véritable navigateur sur les appels de l'outil MCP - lancer, naviguer, cliquer, remplir, capturer, extraire du texte, exécuter JS - avec une empreinte digitale de périphérique réel au niveau du noyau et un profil persistant, de sorte que la session reste connectée entre les exécutions et que les pages voient un périphérique cohérent au lieu d'une construction sans tête. Aucun code Playwright ou SDK à écrire. À utiliser lorsqu'un agent doit exploiter un site lui-même, lorsqu'une configuration d'utilisation d'un ordinateur/d'un navigateur nécessite une empreinte digitale réelle capturée plutôt qu'une empreinte synthétique, lorsque les sessions d'agent continuent de perdre leur connexion ou lors de la comparaison des services hébergés d'agent-navigateur. Également pour « Navigateur MCP », « Serveur MCP du navigateur », « Laisser mon agent naviguer sur le Web », « Contrôle du navigateur de l'agent », « MCP utilisé par le navigateur », « Navigateur utilisé par l'ordinateur », « Alternative à la base de navigateur », « Alternative au navigateur Steel », « Navigateur sans tête détecté ». Nœud (npx) ou Python ; Windows x64, macOS Intel + Apple Silicon, Linux x64/arm64. La référence SDK et REST est anti-détection du navigateur ; l'isolation des comptes est une isolation multi-comptes.
