AI エージェントに、カーネル レベルの実デバイスのフィンガープリントと永続的なプロファイルを使用して、MCP ツール呼び出し (起動、ナビゲート、クリック、入力、スクリーンショット、テキストの抽出、JS の実行) を介して独自の実際のブラウザーを提供します。これにより、セッションは実行間でログインしたままになり、ページにはヘッドレス ビルドではなく 1 つのコヒーレント デバイスが表示されます。 Playwright や SDK コードを記述する必要はありません。エージェントがサイト自体を操作する必要がある場合、コンピュータ使用/ブラウザ使用の設定で合成フィンガープリントではなくキャプチャされた実際のフィンガープリントが必要な場合、エージェント セッションでログインが失われ続ける場合、またはホストされたエージェントとブラウザのサービスを比較する場合に使用します。また、「MCP ブラウザ」、「ブラウザ MCP サーバ」、「エージェントに Web を閲覧させる」、「エージェント ブラウザ制御」、「ブラウザ使用 MCP」、「コンピュータ使用ブラウザ」、「ブラウザベース代替」、「スチール ブラウザ代替」、「ヘッドレス ブラウザ検出」についても同様です。ノード (npx) または Python; Windows x64、macOS Intel + Apple Silicon、Linux x64 / arm64。 SDK および REST リファレンスは、ブラウザの検出防止です。アカウントの分離はマルチアカウントの分離です。
