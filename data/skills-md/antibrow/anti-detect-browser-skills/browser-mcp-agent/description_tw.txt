透過 MCP 工具調用，為 AI 代理提供自己的真實瀏覽器 - 啟動、導航、單擊、填充、屏幕截圖、提取文本、運行 JS - 具有內核級真實設備指紋和持久配置文件，因此會話在運行之間保持登錄狀態，並且頁面會看到一個連貫的設備，而不是無頭構建。無需編寫劇作家或 SDK 程式碼。當代理程式應自行操作網站時、電腦使用/瀏覽器使用設定需要捕獲的真實指紋而不是合成指紋時、代理會話不斷丟失登入名稱或比較託管代理瀏覽器服務時使用。也適用於「MCP 瀏覽器」、「瀏覽器 MCP 伺服器」、「讓我的代理程式瀏覽網頁」、「代理瀏覽器控制」、「瀏覽器使用 MCP」、「電腦使用瀏覽器」、「Browserbase 替代方案」、「Steel 瀏覽器替代方案」、「偵測到無頭瀏覽器」。節點 (npx) 或 Python； Windows x64、macOS Intel + Apple Silicon、Linux x64/arm64。 SDK和REST參考是反偵測瀏覽器的；帳戶隔離是多帳戶隔離。
