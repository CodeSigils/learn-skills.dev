امنح وكيل الذكاء الاصطناعي متصفحه الحقيقي الخاص عبر استدعاءات أداة MCP - التشغيل والتنقل والنقر والتعبئة والتقاط لقطة الشاشة واستخراج النص وتشغيل JS - باستخدام بصمة جهاز حقيقي على مستوى kernel وملف تعريف مستمر، بحيث تظل الجلسة مسجلة الدخول بين عمليات التشغيل وترى الصفحات جهازًا واحدًا متماسكًا بدلاً من إنشاء بدون رأس. لا يوجد رمز Playwright أو SDK للكتابة. يُستخدم عندما يتعين على الوكيل تشغيل موقع بنفسه، أو عندما يحتاج إعداد استخدام الكمبيوتر/استخدام المتصفح إلى بصمة حقيقية تم التقاطها بدلاً من بصمة اصطناعية، أو عندما تستمر جلسات الوكيل في فقدان معلومات تسجيل الدخول الخاصة بها، أو عند مقارنة خدمات متصفح الوكيل المستضافة. أيضًا بالنسبة لـ "متصفح MCP"، و"خادم MCP للمتصفح"، و"السماح لوكيلي بتصفح الويب"، و"التحكم في متصفح الوكيل"، و"استخدام المتصفح MCP"، و"متصفح استخدام الكمبيوتر"، و"بديل قاعدة المتصفح"، و"بديل المتصفح الصلب"، و"تم اكتشاف متصفح مقطوع الرأس". العقدة (npx) أو Python؛ ويندوز x64، ماك أو إس إنتل + أبل سيليكون، لينكس x64 / أرم64. مرجع SDK وREST هو متصفح مضاد للاكتشاف؛ عزل الحساب هو عزل حسابات متعددة.
