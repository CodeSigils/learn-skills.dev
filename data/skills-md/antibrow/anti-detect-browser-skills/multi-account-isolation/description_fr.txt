La liste de contrôle complète pour empêcher que plusieurs comptes que vous possédez ou que vous êtes autorisé à exécuter ne soient corrélés à un seul opérateur - profil, cookies, adresse IP de sortie, fuseau horaire, WebRTC, métadonnées du compte, instrument de paiement, comportement - et pas seulement l'empreinte digitale du navigateur. À utiliser lorsque quelqu'un gère plusieurs comptes sociaux/marchés/publicitaires à partir d'une seule machine et veut savoir ce qui les relie réellement, pourquoi une configuration d'isolement a échoué même si l'empreinte digitale a été testée propre, comment associer un proxy persistant par compte, comment vérifier un profil avant de lui faire confiance (CreepJS, whoer, browserleaks WebRTC, pixelscan, liarjs), ou quelles couches aucun navigateur ne peut corriger - e-mail de récupération partagé, compte de paiement partagé, cadence de publication identique. Également pour « association de compte », « les comptes ont été liés », « configuration multi-comptes », « un proxy par compte », « liste de contrôle d'isolation de profil », « 账号关联 », « 防关联 », « 多账号运营 ». La couche navigateur est implémentée par la compétence anti-détection du navigateur ; Le contrôle MCP est un agent navigateur-mcp.
