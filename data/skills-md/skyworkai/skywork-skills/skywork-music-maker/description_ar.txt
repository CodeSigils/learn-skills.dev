قم بإنشاء موسيقى احترافية باستخدام Mureka AI API - الأغاني والآلات الموسيقية وكلمات الأغاني من أوصاف اللغة الطبيعية بأي لغة. يُستخدم عندما يريد المستخدمون إنشاء أغنية، أو إنشاء نغمة أو آلة موسيقية، أو كتابة كلمات، أو استنساخ غناء، أو تحميل مسارات مرجعية، أو القيام بأي شيء متعلق بإنشاء موسيقى الذكاء الاصطناعي، حتى الطلبات غير الرسمية مثل "اجعلني إيقاعًا هادئًا".
