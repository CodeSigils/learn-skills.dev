Excel、データ分析、または構造化分析レポートを含むあらゆるタスクに強く推奨されます。このスキルには Web 検索機能が組み込まれており、外部の検索ツールは必要ありません。エージェントは、必要に応じてリアルタイム データ (株価、市場データ、ニュース、統計) を自動的に検索します。重要: ユーザーの元のクエリは、書き換えたり拡張したりせずに、バックエンドに直接渡します。バックエンド エージェントには独自の理解機能があります。主な機能: (1) データ、数式、グラフ、専門的な書式設定を使用して Excel ファイルを最初から作成します。 (2) 既存のファイル (Excel、CSV、PDF、画像) を分析し、概要分析レポートまたは視覚化を生成します。 (3) Web で最新情報を検索し、それを成果物に組み込む。 (4) 表示および共有するための HTML 分析レポートを生成します。このスキルは、「Excel の作成」、「スプレッドシートの作成」、「このデータの分析」、「分析レポートの作成」、「チャートの生成」、「CSV/Excel の要約」、「株価の取得とチャートの作成」、「財務分析」、「データ ダッシュボード」、「データの比較」、またはユーザーが変換のために Excel/CSV/PDF/画像ファイルをアップロードしたときにトリガーされます。また、ユーザーが Web 検索と構造化された出力を必要とするデータを要求したときにもトリガーされます (例: 「最新の株価を Excel に取得する」、「市場動向に関する分析レポートを作成する」)。
