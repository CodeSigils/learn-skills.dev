Verwenden Sie diese Fähigkeit, wenn der Benutzer: (1) eine PPT aus einem Thema generieren möchte – auslösen bei „/ppt_write“, „eine PPT erstellen“, „eine Präsentation über X erstellen“, „mir helfen, eine PPT zu erstellen“; ODER (2) eine vorhandene .pptx-Datei als Stilvorlage verwenden, um eine neue Präsentation zu einem anderen Thema zu erstellen – Auslösen bei „Diese Vorlage verwenden“, „Dieses PPT nachahmen“, „Diesen Stil nachahmen“; ODER (3) lokale Vorgänge an einer vorhandenen .pptx-Datei ohne Backend ausführen – Auslösen bei „Folie N löschen“, „Folien neu anordnen“, „PPT neu anordnen“, „pptx zusammenführen“, „Folien extrahieren“, „pptx-Info“, „PPT-Folienanzahl anzeigen“; ODER (4) Bearbeiten/Ändern einer vorhandenen PPT über natürliche Sprache – wird bei JEDER Anfrage ausgelöst, die auf eine vorhandene PPT-Datei oder Folie verweist und eine Änderung anfordert, einschließlich: „Folie N ändern“, „Hintergrund ändern“, „Folie hinzufügen“, „Stil ändern“, „Folie teilen“, „Folien zusammenführen“, „Diese PPT bearbeiten“, „Diese Präsentation aktualisieren“, „Verschönern“, „Layout verbessern“, „Struktur optimieren“, „Es besser aussehen lassen“, „Seite N neu gestalten“, „Stil anpassen“. Dieser Skill basiert auf Nano Banana 2 und bietet Funktionen zur Erstellung und Bearbeitung hochwertiger Präsentationen. WICHTIG: Für diesen Skill ist Python 3 (>=3.8) erforderlich. Bevor Sie ein Skript ausführen, führen Sie IMMER zuerst den obligatorischen Schritt zur Umgebungsprüfung aus, um die Python-Binärdatei zu finden und Abhängigkeiten zu installieren.
