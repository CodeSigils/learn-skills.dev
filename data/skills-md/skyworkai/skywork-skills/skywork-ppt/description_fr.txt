Utilisez cette compétence lorsque l'utilisateur souhaite : (1) générer un PPT à partir d'un sujet — déclencher sur « /ppt_write », « générer un PPT », « créer une présentation sur X », « m'aider à générer un PPT » ; OU (2) utiliser un .pptx existant comme modèle de style pour générer une nouvelle présentation sur un sujet différent — déclencher sur « utiliser ce modèle », « imiter ce PPT », « imiter ce style » ; OU (3) effectuer des opérations locales sur un fichier .pptx existant sans backend — déclenchement sur « supprimer la diapositive N », « réorganiser les diapositives », « réorganiser le PPT », « fusionner pptx », « extraire les diapositives », « infos pptx », « afficher le nombre de diapositives PPT » ; OU (4) éditer/modifier un PPT existant via le langage naturel — déclencher sur TOUTE demande faisant référence à un fichier ou une diapositive PPT existant et demandant une modification, notamment : "modifier la diapositive N", "changer l'arrière-plan", "ajouter une diapositive", "changer le style", "diviser la diapositive", "fusionner les diapositives", "modifier ce PPT", "mettre à jour cette présentation", "la rendre plus belle", "améliorer le mise en page », « optimiser la structure », « l'améliorer », « redessiner la page N », « ajuster le style ». Cette compétence est basée sur Nano Banana 2 pour offrir des capacités de génération et d'édition de présentations de haute qualité. IMPORTANT : Cette compétence nécessite Python 3 (>=3.8). Avant d'exécuter un script, exécutez TOUJOURS d'abord l'étape obligatoire de vérification de l'environnement pour localiser le binaire Python et installer les dépendances.
