Используйте этот навык, когда пользователь хочет: (1) создать PPT на основе темы — вызвать «/ppt_write», «создать PPT», «создать презентацию о X», «помочь мне создать PPT»; ИЛИ (2) использовать существующий .pptx в качестве шаблона стиля для создания новой презентации по другой теме — триггер «использовать этот шаблон», «имитировать этот PPT», «имитировать этот стиль»; ИЛИ (3) выполнять локальные операции с существующим файлом .pptx без серверной части — запускать по «удалить слайд N», «изменить порядок слайдов», «изменить порядок PPT», «объединить pptx», «извлечь слайды», «информацию о pptx», «просмотреть количество слайдов PPT»; ИЛИ (4) редактировать/изменять существующий PPT с помощью естественного языка — запускать по ЛЮБОМУ запросу, который ссылается на существующий файл PPT или слайд и запрашивает изменение, включая: «изменить слайд N», «изменить фон», «добавить слайд», «изменить стиль», «разделить слайд», «объединить слайды», «отредактировать этот PPT», «обновить эту презентацию», «сделать ее более красивой», «улучшить макет», «оптимизировать структура», «улучшить внешний вид», «изменить дизайн страницы N», «отрегулировать стиль». Этот навык создан на основе Nano Banana 2 и обеспечивает возможности создания и редактирования высококачественных презентаций. ВАЖНО: для этого навыка требуется Python 3 (>=3.8). Перед запуском любого сценария ВСЕГДА сначала выполняйте обязательную проверку среды, чтобы найти двоичный файл Python и установить зависимости.
