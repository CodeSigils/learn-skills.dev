Basado en repositorios de código real, páginas de sitios web oficiales, interfaces de tiempo de ejecución, alcance del módulo y el número objetivo de derechos de autor de software, analice la dirección para el registro de derechos de autor de software (derechos de autor blandos), divida los temas registrables, verifique restricciones como logotipo, derechos de autor, archivo, capturas de pantalla y materiales de código fuente, y genere un texto principal de 30 000 a 40 000 palabras, fragmentos de código parciales, código fuente original, evidencia de captura de pantalla de la página web y un documento .docx. Úselo cuando Claude necesite preparar o dividir materiales legítimos de registro de derechos de autor de software de repositorios de códigos, páginas de productos, capturas de pantalla de la interfaz de usuario en ejecución, alcances de módulos o evidencia de fuentes.
