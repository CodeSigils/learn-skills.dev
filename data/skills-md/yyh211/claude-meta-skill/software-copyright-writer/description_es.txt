Con base en repositorios de código reales, páginas de sitios web oficiales, interfaces de tiempo de ejecución, alcances de módulos y el número objetivo de derechos de autor de software, analice la dirección de la aplicación de derechos de autor de software (derechos de autor blandos), divida los temas aplicables, verifique las restricciones en materiales como logotipo, derechos de autor, archivos, capturas de pantalla y código fuente, y genere un texto principal de 30 000 a 40 000 palabras, fragmentos de código parciales, código fuente original, evidencia de captura de pantalla de la página web y un documento .docx. Úselo cuando Claude necesite preparar o dividir materiales legítimos de registro de derechos de autor de software de repositorios de códigos, páginas de productos, capturas de pantalla de la interfaz de usuario en ejecución, alcances de módulos o evidencia de fuentes.
