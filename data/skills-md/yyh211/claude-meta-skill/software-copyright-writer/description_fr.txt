Sur la base des référentiels de code réels, des pages du site Web officiel, des interfaces d'exécution, des portées des modules et du nombre cible de droits d'auteur sur les logiciels, analysez l'orientation de l'application des droits d'auteur sur les logiciels (droit d'auteur logiciel), divisez les sujets applicables, vérifiez les contraintes sur les éléments tels que le logo, les droits d'auteur, le classement, les captures d'écran et le code source, et générez un texte principal de 30 000 à 40 000 mots, des extraits de code partiels, le code source original, des preuves de capture d'écran de page Web et un document .docx. À utiliser lorsque Claude doit préparer ou diviser des documents légitimes d'enregistrement des droits d'auteur de logiciels à partir de référentiels de codes, de pages de produits, de captures d'écran de l'interface utilisateur, de portées de modules ou de preuves sources.
