Implementa le integrazioni dei partner Trade It utilizzando modalità React connect/trade integrate o chiamate API di trading backend dirette. Da utilizzare quando viene richiesto di integrare @trade-it/react, richiedere URL di sessione Trade It, connettere intermediari come Charles Schwab, leggere conti o partecipazioni oppure creare, eseguire, annullare e monitorare operazioni da un server partner senza una modalità Trade It.
