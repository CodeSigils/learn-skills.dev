قم بتنفيذ عمليات تكامل شركاء Trade It باستخدام إما نماذج الاتصال/التجارة المضمنة من React أو استدعاءات واجهة برمجة التطبيقات للتداول الخلفي المباشر. استخدمه عندما يُطلب منك دمج @trade-it/react، أو طلب عناوين URL لجلسة Trade It، أو توصيل شركات الوساطة مثل Charles Schwab، أو قراءة الحسابات أو المقتنيات، أو إنشاء الصفقات وتنفيذها وإلغائها ومراقبتها من خادم شريك بدون نموذج Trade It.
