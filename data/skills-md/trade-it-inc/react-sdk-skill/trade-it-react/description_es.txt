Implemente integraciones de socios de Trade It utilizando modos integrados de conexión/comercio de React o llamadas API de comercio de backend directas. Úselo cuando se le solicite integrar @trade-it/react, solicitar URL de sesión de Trade It, conectar corredurías como Charles Schwab, leer cuentas o tenencias, o crear, ejecutar, cancelar y monitorear operaciones desde un servidor asociado sin un modo Trade It.
