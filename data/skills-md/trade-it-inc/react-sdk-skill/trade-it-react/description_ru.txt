Реализуйте интеграцию партнеров Trade It, используя либо встроенные модальные модули React Connect/Trade, либо прямые вызовы API для внутренней торговли. Используйте, когда вас попросят интегрировать @trade-it/react, запросить URL-адреса сеанса Trade It, подключить брокерские компании, такие как Charles Schwab, прочитать счета или активы, а также создать, выполнить, отменить и отслеживать сделки с партнерского сервера без модального окна Trade It.
