Guide les utilisateurs dans la documentation étape par étape des flux commerciaux dans EventCatalog. À utiliser lorsque l'utilisateur demande de « documenter un flux », « cartographier un processus métier », « créer un diagramme de flux », « parcourir un processus », « documenter un flux de bout en bout » ou « cartographier le fonctionnement de quelque chose dans mon architecture ».
