Создает пользовательские страницы и маршруты API внутри проекта EventCatalog (функция плана масштабирования). Создает страницы Astro и конечные точки TypeScript в папке Pages/ каталога, используя стабильный набор инструментов @catalog/layouts и @catalog/utils, подключает их к навигации и настраивает поддержку редактора. Используйте, когда пользователь просит «добавить пользовательскую страницу в мой каталог», «создать страницу группы», «добавить конечную точку API в EventCatalog», «создать пользовательскую домашнюю страницу», «добавить собственный маршрут», «запросить данные каталога с моей собственной страницы» или «расширить EventCatalog с помощью моих собственных страниц».
