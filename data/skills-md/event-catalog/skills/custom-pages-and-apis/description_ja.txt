EventCatalog プロジェクト内にカスタム ページと API ルートを構築します (スケール プラン機能)。安定した @catalog/layouts および @catalog/utils ツールキットを使用してカタログのページ/フォルダーに Astro ページと TypeScript エンドポイントを作成し、それらをナビゲーションに接続し、エディターのサポートをセットアップします。ユーザーが「カタログにカスタム ページを追加する」、「チーム ページを構築する」、「EventCatalog に API エンドポイントを追加する」、「カスタム ホームページを作成する」、「カスタム ルートを追加する」、「自分のページからカタログ データをクエリする」、または「自分のページで EventCatalog を拡張する」を要求する場合に使用します。
