Crea páginas personalizadas y rutas API dentro de un proyecto EventCatalog (función de plan de escala). Crea páginas Astro y puntos finales de TypeScript en las páginas/carpeta del catálogo utilizando el kit de herramientas estable @catalog/layouts y @catalog/utils, los conecta a la navegación y configura el soporte del editor. Úselo cuando el usuario solicite "agregar una página personalizada a mi catálogo", "crear una página de equipo", "agregar un punto final API a EventCatalog", "crear una página de inicio personalizada", "agregar una ruta personalizada", "consultar datos del catálogo desde mi propia página" o "extender EventCatalog con mis propias páginas".
