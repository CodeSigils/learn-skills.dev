EventCatalog 프로젝트 내에 사용자 정의 페이지 및 API 경로를 구축합니다(규모 계획 기능). 안정적인 @catalog/layouts 및 @catalog/utils 툴킷을 사용하여 카탈로그의 페이지/ 폴더에 Astro 페이지 및 TypeScript 엔드포인트를 생성하고 이를 탐색에 연결하고 편집기 지원을 설정합니다. 사용자가 "내 카탈로그에 사용자 정의 페이지 추가", "팀 페이지 구축", "EventCatalog에 API 엔드포인트 추가", "사용자 정의 홈페이지 생성", "사용자 정의 경로 추가", "내 페이지에서 카탈로그 데이터 쿼리" 또는 "내 페이지로 EventCatalog 확장"을 요청할 때 사용합니다.
