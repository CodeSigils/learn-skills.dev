ينشئ صفحات مخصصة ومسارات واجهة برمجة التطبيقات (API) داخل مشروع EventCatalog (ميزة خطة القياس). ينشئ صفحات Astro ونقاط نهاية TypeScript في صفحات/مجلد الكتالوج باستخدام @catalog/layouts ومجموعة أدوات @catalog/utils الثابتة، ويربطها بالتنقل، ويقوم بإعداد دعم المحرر. يُستخدم عندما يطلب المستخدم "إضافة صفحة مخصصة إلى الكتالوج الخاص بي"، أو "إنشاء صفحة فريق"، أو "إضافة نقطة نهاية API إلى EventCatalog"، أو "إنشاء صفحة رئيسية مخصصة"، أو "إضافة مسار مخصص"، أو "بيانات كتالوج الاستعلام من صفحتي الخاصة"، أو "توسيع EventCatalog بصفحاتي الخاصة".
