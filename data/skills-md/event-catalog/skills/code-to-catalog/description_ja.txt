証拠に基づいたインタビューを通じて、コードベースを EventCatalog ドキュメントに変換します。最初にコードをスキャンし、アーキテクチャ モデル (ドメイン、サービス、メッセージ、チャネル) を提案し、構造的な決定についてユーザーに問いただし、レビュー可能な計画ファイルを作成してから、カタログ ドキュメント作成者に引き渡します。ユーザーが「EventCatalog でコードベースを文書化する」、「このリポジトリをカタログに変換する」、「コードをカタログとしてモデル化する」、「アーキテクチャについて詳しく説明する」、「コードからカタログを更新する」、「カタログとコードを調整する」、または「このコードベースの文書化をどこから始めればよいか分からない」といった場合に使用します。新しいカタログだけでなく、コードから逸脱した既存のカタログの更新にも機能します。
