Transforme une base de code en documentation EventCatalog grâce à un entretien fondé sur des preuves. Scanne d'abord le code, propose un modèle architectural (domaines, services, messages, canaux), interroge l'utilisateur sur les décisions structurelles, produit un fichier plan révisable, puis passe la main au créateur de catalogue-documentation. À utiliser lorsque l'utilisateur dit "documenter ma base de code dans EventCatalog", "transformer ce dépôt en catalogue", "modéliser mon code en tant que catalogue", "faire griller mon architecture", "mettre à jour mon catalogue à partir du code", "réconcilier mon catalogue avec mon code" ou "Je ne sais pas par où commencer à documenter cette base de code". Fonctionne pour les catalogues flambant neufs ET pour la mise à jour des catalogues existants qui ont dérivé du code.
