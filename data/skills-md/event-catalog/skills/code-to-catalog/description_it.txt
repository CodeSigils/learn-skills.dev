Trasforma una base di codice nella documentazione EventCatalog attraverso un'intervista basata sull'evidenza. Esamina prima il codice, propone un modello architetturale (domini, servizi, messaggi, canali), interroga l'utente sulle decisioni strutturali, produce un file di piano rivedibile, quindi passa al creatore della documentazione-catalogo. Da utilizzare quando l'utente dice "documenta la mia base di codice in EventCatalog", "trasforma questo repository in un catalogo", "modella il mio codice come catalogo", "grigliami sulla mia architettura", "aggiorna il mio catalogo dal codice", "riconcilia il mio catalogo con il mio codice" o "non so da dove iniziare a documentare questa base di codice". Funziona con cataloghi nuovi di zecca E con l'aggiornamento di cataloghi esistenti che si sono allontanati dal codice.
