Превращает базу кода в документацию EventCatalog посредством интервью, основанного на фактических данных. Сначала сканирует код, предлагает архитектурную модель (домены, сервисы, сообщения, каналы), предлагает пользователю структурные решения, создает проверяемый файл плана, а затем передает его создателю документации-каталога. Используйте, когда пользователь говорит: «Задокументируйте мою кодовую базу в EventCatalog», «Превратите этот репозиторий в каталог», «Моделируйте мой код как каталог», «Расспросите меня о моей архитектуре», «Обновите мой каталог из кода», «Согласуйте мой каталог с моим кодом» или «Я не знаю, с чего начать документирование этой кодовой базы». Работает для совершенно новых каталогов И для обновления существующих каталогов, которые вышли из кода.
