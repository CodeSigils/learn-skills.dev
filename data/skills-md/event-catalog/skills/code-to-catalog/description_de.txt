Wandelt eine Codebasis durch ein evidenzbasiertes Interview in eine EventCatalog-Dokumentation um. Scannt zuerst den Code, schlägt ein Architekturmodell vor (Domänen, Dienste, Nachrichten, Kanäle), informiert den Benutzer über die strukturellen Entscheidungen, erstellt eine überprüfbare Plandatei und übergibt sie dann an den Katalogdokumentationsersteller. Wird verwendet, wenn der Benutzer sagt: „Meine Codebasis in EventCatalog dokumentieren“, „dieses Repo in einen Katalog umwandeln“, „meinen Code als Katalog modellieren“, „mich über meine Architektur informieren“, „meinen Katalog anhand des Codes aktualisieren“, „meinen Katalog mit meinem Code abgleichen“ oder „ich nicht weiß, wo ich mit der Dokumentation dieser Codebasis beginnen soll“. Funktioniert für brandneue Kataloge UND für die Aktualisierung bestehender Kataloge, die vom Code abgewichen sind.
