Convierte una base de código en documentación de EventCatalog a través de una entrevista basada en evidencia. Primero escanea el código, propone un modelo arquitectónico (dominios, servicios, mensajes, canales), interroga al usuario sobre las decisiones estructurales, produce un archivo de plan revisable y luego lo entrega al creador de la documentación del catálogo. Úselo cuando el usuario diga "documentar mi base de código en EventCatalog", "convertir este repositorio en un catálogo", "modelar mi código como un catálogo", "preguntarme sobre mi arquitectura", "actualizar mi catálogo desde el código", "conciliar mi catálogo con mi código" o "No sé por dónde empezar a documentar este código base". Funciona para catálogos nuevos Y para actualizar catálogos existentes que se han desviado del código.
