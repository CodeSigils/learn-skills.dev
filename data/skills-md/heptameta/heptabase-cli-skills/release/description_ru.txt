Выпустите новую версию heptabase-cli-skills, общедоступного пакета плагинов Agent Skills для Heptabase CLI. Используйте всякий раз, когда вас просят выпустить, опубликовать, отправить, пометить или обновить версию этого пакета/плагина для навыков, чтобы проверить, готов ли он к выпуску, или создать его выпуск на GitHub. Охватывает обмен версиями в манифестах плагинов, предварительную проверку, тегирование и публикацию выпуска GitHub. Не для выпуска настольного приложения Heptabase или самого двоичного файла CLI heptabase — они разрабатываются отдельно.
