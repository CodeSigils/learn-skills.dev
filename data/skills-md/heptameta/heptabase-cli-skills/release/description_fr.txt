Publiez une nouvelle version de heptabase-cli-skills, le paquet public de plug‑in Agent Skills pour le Heptabase CLI. Utilisez‑le chaque fois qu’on vous demande de publier, de mettre en ligne, de taguer ou d’augmenter la version de ce paquet/plug‑in de compétences, de vérifier s’il est prêt à être publié, ou de créer sa version GitHub. Il couvre la mise à jour de version à travers les manifestes du plug‑in, la validation préliminaire, le taggage et la publication de la release GitHub. Ce n’est pas destiné à publier l’application de bureau Heptabase ou le binaire du CLI heptabase — ceux‑ci sont versionnés séparément.
