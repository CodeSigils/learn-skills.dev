Lanza una nueva versión de heptabase-cli-skills, el paquete público de plugins Agent Skills para el Heptabase CLI. Úsalo siempre que se solicite lanzar, publicar, distribuir, etiquetar o actualizar la versión de este paquete/plugin de skills, para comprobar si está listo para su publicación o para crear su lanzamiento en GitHub. Cubre la actualización de versiones en los manifiestos de plugins, la validación previa, el etiquetado y la publicación del lanzamiento en GitHub. No es para lanzar la aplicación de escritorio de Heptabase ni el binario del CLI de heptabase — esos se versionan por separado.

Por favor, responde siempre en el idioma del usuario.
