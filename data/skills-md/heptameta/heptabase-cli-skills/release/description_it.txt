Rilascia una nuova versione di heptabase-cli-skills, il pacchetto plug-in pubblico Agent Skills per la CLI Heptabase. Utilizzare ogni volta che viene richiesto di rilasciare, pubblicare, spedire, taggare o eseguire il bumping della versione di questo pacchetto/plug-in di competenze, per verificare se è pronto per il rilascio o per creare la relativa versione GitHub. Copre la versione che si scontra con i manifest dei plugin, la convalida preliminare, il tagging e la pubblicazione della versione GitHub. Non per il rilascio dell'app desktop Heptabase o del file binario Heptabase CLI stesso: quelli hanno una versione separata.
