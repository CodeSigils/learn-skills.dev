Generar prototipos interactivos a partir de documentos del PRD. **Utilice esta habilidad cuando los usuarios necesiten crear prototipos de UI interactivos, demostraciones de navegación de varias páginas o validar rápidamente diseños de productos basados ​​en el PRD.** Escenarios desencadenantes: el usuario dice "generar prototipo", "hacer una demostración", "crear un prototipo en el que se puede hacer clic" o "convertir el PRD en páginas en las que se puede hacer clic".
