KI-Desktop-Agent – ​​steuern Sie jede App unter Windows/macOS von Ihrem OpenClaw-Agenten aus. Senden Sie Aufgaben in natürlicher Sprache an die Clawd Cursor API und sie erledigt alles: Apps öffnen, auf Schaltflächen klicken, Text eingeben, in Browsern navigieren, Formulare ausfüllen. Wenn Sie darauf klicken können, kann Ihr Agent das auch.
