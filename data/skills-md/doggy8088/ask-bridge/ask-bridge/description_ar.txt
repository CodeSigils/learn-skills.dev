الاستفادة الكاملة من مهارة الوكيل الخاصة بـ Ask-bridge CLI. استخدم Ask-bridge لتفويض أبحاث الذكاء الاصطناعي الاستكشافية منخفضة المخاطر أو التلخيص أو تحليل المستندات أو تحليل مقتطف التعليمات البرمجية أو تنظيم رسائل الخطأ أو مقارنة الحلول أو إنشاء المسودة أو التحقيقات الخلفية القابلة للتفويض إلى موقع ChatGPT أو Gemini. استخدمه عندما يحتاج Codex إلى استدعاء الذكاء الاصطناعي المستند إلى الويب عبر أمر Ask-bridge المحلي، أو الاستفادة من حصص ويب ChatGPT/Gemini، أو إرفاق ملفات أو صور، أو تبديل النماذج، أو استرداد الاستجابات، أو تنزيل الصور التي تم إنشاؤها، أو إدارة جلسات المتصفح، أو الاستعلام عن جميع معلمات Ask-bridge واستخدام الأوامر الفرعية.
