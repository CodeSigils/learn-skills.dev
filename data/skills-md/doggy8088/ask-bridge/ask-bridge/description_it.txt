Utilizza appieno la capacità agente della CLI ask-bridge. Utilizza ask-bridge per delegare la ricerca esplorativa sull'intelligenza artificiale a basso rischio, il riepilogo, l'analisi dei documenti, l'analisi degli snippet di codice, l'organizzazione dei messaggi di errore, il confronto delle soluzioni, la generazione di bozze o le indagini di background delegabili al sito Web ChatGPT o Gemini. Usalo quando Codex deve invocare un'intelligenza artificiale basata sul web tramite il comando ask-bridge locale, sfruttare le quote web ChatGPT/Gemini, allegare file o immagini, cambiare modelli, recuperare risposte, scaricare immagini generate, gestire sessioni del browser o eseguire query su tutti i parametri ask-bridge e sull'utilizzo dei sottocomandi.
