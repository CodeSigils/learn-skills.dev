Архитектура использования агентов — структурируйте контекст агента проекта по всем 
уровни для эффективной разработки с помощью ИИ. Охватывает CLAUDE.md, навыки, 
проектная документация, крючки и все артефакты, которые определяют понимание агентом 
и работает в базе кода.

Используйте при настройке или улучшении конфигурации агента проекта, когда 
контекст агента кажется раздутым или дезорганизованным при подключении к новому проекту 
для разработки с помощью ИИ или когда агент продолжает терять архитектурные 
осведомленность в середине задачи. Запускайте такие фразы, как «настроить Клода», «улучшить 
CLAUDE.md", "агент постоянно забывает", "слишком длинный контекст", "используйте 
настройка», «организовать контекст агента», «как мне структурировать свои подсказки».

Поддерживает аргументы: `/harness Audit` для оценки существующего проекта. 
контекстная архитектура, `/harness init` для настройки жгута с нуля.
