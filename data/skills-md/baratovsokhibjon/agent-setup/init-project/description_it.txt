Avvia un progetto dal modello humbeeai con la migliore corrispondenza. Elenca i repository dei modelli dell'organizzazione a livello di codice, sceglie quello che si adatta al linguaggio e allo scopo del progetto e torna al modello base quando non corrisponde nulla. Quindi adatta ogni valore specifico del modello al target. Da utilizzare quando l'utente chiede di eseguire l'inizializzazione, l'impalcatura, il bootstrap o l'impostazione di un progetto oppure di adottare un modello humilibeeai in un repository esistente. Non trasporta mai la cronologia git del modello nella destinazione.
