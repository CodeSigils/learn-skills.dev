Создайте проект на основе наиболее подходящего шаблона humbeeai. Программно выводит список репозиториев шаблонов организации, выбирает тот, который соответствует языку и цели проекта, и возвращается к базовому шаблону, когда ничего не соответствует. Затем адаптирует каждое значение, специфичное для шаблона, к цели. Используйте, когда пользователь запрашивает инициализацию, загрузку, загрузку или настройку проекта или внедрение шаблона humbeeai в существующий репозиторий. Никогда не переносит историю git шаблона в цель.
