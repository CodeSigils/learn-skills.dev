قم بتمهيد مشروع من قالب المتواضع الأكثر توافقًا. يسرد مستودعات قوالب المؤسسة برمجيًا، ويختار المستودع الذي يناسب لغة المشروع والغرض منه، ويعود إلى القالب الأساسي عندما لا يتطابق أي شيء. ثم يقوم بتكييف كل قيمة خاصة بالقالب مع الهدف. يُستخدم عندما يطلب المستخدم بدء مشروع أو دعمه أو تمهيده أو إعداده، أو اعتماد قالب متواضع في مستودع موجود. لا تحمل أبدًا سجل git للقالب إلى الهدف.
