Stellen Sie in einem geführten Durchgang einen vollständigen, sicheren Backend-Dienst bereit, indem Sie die fokussierten Fähigkeiten in der Abhängigkeitsreihenfolge orchestrieren: Bootstrap, Konfiguration, Antwort- und Fehlerkonvention, Datenspeicher, Authentifizierung, Autorisierung, API-Schlüssel, Feature-Slices, Bereinigung und Commit. Verwenden Sie diese Option, wenn Sie aufgefordert werden, aus einer Beschreibung einen neuen Dienst oder einen großen Teil davon zu erstellen, und nicht für eine einzelne isolierte Änderung.
