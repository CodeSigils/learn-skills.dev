Cree un servicio backend completo y seguro en una sola pasada orquestando las habilidades enfocadas en orden de dependencia: arranque, configuración, convención de respuesta y error, almacén de datos, autenticación, autorización, claves API, sectores de funciones, limpieza y confirmación. Úselo cuando se le solicite crear un nuevo servicio o una porción grande de uno a partir de una descripción, no para un solo cambio aislado.
