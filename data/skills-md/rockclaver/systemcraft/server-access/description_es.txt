Acceda a servidores nombrados a través de SSH utilizando un archivo de credenciales local, luego ejecute comandos de inspección seguros o comprobaciones delegadas. Úselo cuando el usuario solicite verificar un servidor por nombre, inspeccionar el estado de Docker/contenedor en una máquina remota, verificar el estado a través de SSH o usar credenciales de ~/.systemcraft/ssh/creds.yml.
