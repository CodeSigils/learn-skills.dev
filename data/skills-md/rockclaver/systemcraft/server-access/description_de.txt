Greifen Sie über SSH mit einer lokalen Anmeldeinformationsdatei auf benannte Server zu und führen Sie dann sichere Inspektionsbefehle oder delegierte Prüfungen aus. Verwenden Sie diese Option, wenn der Benutzer einen Server anhand seines Namens überprüfen, den Docker-/Containerstatus auf einem Remotecomputer überprüfen, den Zustand über SSH überprüfen oder Anmeldeinformationen von ~/.systemcraft/ssh/creds.yml verwenden möchte.
