Accedi ai server denominati tramite SSH utilizzando un file di credenziali locali, quindi esegui comandi di ispezione sicuri o controlli delegati. Da utilizzare quando l'utente chiede di controllare un server per nome, ispezionare lo stato Docker/contenitore su un computer remoto, verificare l'integrità su SSH o utilizzare le credenziali da ~/.systemcraft/ssh/creds.yml.
