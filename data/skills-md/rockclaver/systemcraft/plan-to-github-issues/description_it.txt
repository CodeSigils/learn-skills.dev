Converti un piano di implementazione a fasi (file Markdown con fasi e criteri di accettazione) in problemi GitHub, un flusso di lavoro CI che esegue test sui PR e un modello PR che associa ogni PR ai suoi criteri di accettazione. Da utilizzare quando l'utente desidera creare problemi GitHub da un piano, inviare fasi a GitHub, impostare elementi di configurazione dei criteri di accettazione o tenere traccia delle fasi del piano come problemi.
