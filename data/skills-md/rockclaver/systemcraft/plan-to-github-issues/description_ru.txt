Преобразуйте план поэтапного внедрения (файл Markdown с этапами и критериями приемки) в задачи GitHub, рабочий процесс CI, который запускает тесты на PR, и шаблон PR, который сопоставляет каждый PR с его критериями приемки. Используйте, когда пользователь хочет создавать задачи GitHub из плана, отправлять этапы в GitHub, настраивать CI критериев приемки или отслеживать этапы плана как проблемы.
