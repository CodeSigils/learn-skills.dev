Konvertieren Sie einen phasenweisen Implementierungsplan (Markdown-Datei mit Phasen und Akzeptanzkriterien) in GitHub-Issues, einen CI-Workflow, der Tests für PRs durchführt, und eine PR-Vorlage, die jede PR ihren Akzeptanzkriterien zuordnet. Verwenden Sie diese Option, wenn der Benutzer GitHub-Probleme aus einem Plan erstellen, Phasen an GitHub übertragen, Akzeptanzkriterien-CI einrichten oder Planphasen als Probleme verfolgen möchte.
