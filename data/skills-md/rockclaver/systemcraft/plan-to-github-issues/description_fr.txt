Convertissez un plan de mise en œuvre par étapes (fichier Markdown avec phases et critères d'acceptation) en problèmes GitHub, un workflow CI qui exécute des tests sur les PR et un modèle de PR qui mappe chaque PR à ses critères d'acceptation. À utiliser lorsque l'utilisateur souhaite créer des problèmes GitHub à partir d'un plan, transférer des phases vers GitHub, configurer un CI de critères d'acceptation ou suivre les phases du plan en tant que problèmes.
