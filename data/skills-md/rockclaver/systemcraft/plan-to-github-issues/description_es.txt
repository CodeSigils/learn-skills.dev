Convierta un plan de implementación por fases (archivo Markdown con fases y criterios de aceptación) en problemas de GitHub, un flujo de trabajo de CI que ejecute pruebas en RP y una plantilla de RP que asigne cada RP a sus criterios de aceptación. Úselo cuando el usuario desee crear problemas de GitHub a partir de un plan, enviar fases a GitHub, configurar CI de criterios de aceptación o realizar un seguimiento de las fases del plan como problemas.
