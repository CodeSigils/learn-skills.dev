قم بتحويل خطة التنفيذ المرحلية (ملف Markdown مع المراحل ومعايير القبول) إلى مشكلات GitHub، وسير عمل CI الذي يجري اختبارات على العلاقات العامة، وقالب العلاقات العامة الذي يعين كل علاقات عامة وفقًا لمعايير القبول الخاصة بها. يُستخدم عندما يريد المستخدم إنشاء مشكلات GitHub من خطة، أو دفع المراحل إلى GitHub، أو إعداد CI لمعايير القبول، أو تتبع مراحل الخطة كمشاكل.
