Individua file e codice utilizzando script grep e shell, mai tramite la scansione AI. Restituisce i percorsi esatti dei file e i numeri di riga in modo che l'agente possa passare direttamente alla posizione. Da utilizzare ogni volta che l'agente deve trovare una funzione, una classe, una variabile, un'importazione, un file o qualsiasi modello nella codebase. L'individuazione di codice e file deve essere sempre una chiamata a uno strumento, mai un'ipotesi dell'intelligenza artificiale.
