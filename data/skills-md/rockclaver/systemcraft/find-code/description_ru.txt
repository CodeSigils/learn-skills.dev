Находите файлы и код с помощью grep и сценариев оболочки, а не с помощью сканирования ИИ. Возвращает точные пути к файлам и номера строк, чтобы агент мог перейти непосредственно к этому местоположению. Используйте всякий раз, когда агенту необходимо найти функцию, класс, переменную, импорт, файл или любой шаблон в базе кода. Обнаружение кода и файлов всегда должно быть вызовом инструмента, а не догадкой ИИ.
