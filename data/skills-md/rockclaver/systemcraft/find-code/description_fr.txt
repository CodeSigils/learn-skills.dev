Localisez les fichiers et le code à l'aide de scripts grep et shell, jamais par analyse IA. Renvoie les chemins de fichiers et les numéros de ligne exacts afin que l'agent puisse accéder directement à l'emplacement. À utiliser chaque fois que l'agent a besoin de trouver une fonction, une classe, une variable, une importation, un fichier ou tout autre modèle dans la base de code. La découverte de code et de fichiers doit toujours être un appel d'outil, jamais une supposition de l'IA.
