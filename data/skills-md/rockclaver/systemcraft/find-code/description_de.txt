Suchen Sie Dateien und Code mithilfe von Grep- und Shell-Skripten – niemals durch KI-Scannen. Gibt genaue Dateipfade und Zeilennummern zurück, sodass der Agent direkt zum Speicherort springen kann. Verwenden Sie es immer dann, wenn der Agent eine Funktion, Klasse, Variable, einen Import, eine Datei oder ein beliebiges Muster in der Codebasis finden muss. Die Code- und Dateierkennung muss immer ein Tool-Aufruf sein, niemals eine KI-Rate.
