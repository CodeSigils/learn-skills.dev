Scrivi test automatizzati di alto valore e migliora la copertura pratica del codice ispezionando il repository, deducendo lo stack attivo e prendendo di mira prima i comportamenti rischiosi non testati. Da utilizzare quando l'utente desidera test più efficaci, una copertura di test più ampia, un'identificazione di test mancante, una scrittura di test basata sulla copertura o test di regressione per una base di codice esistente.
