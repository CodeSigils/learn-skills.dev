Construit et maintient un index `.claude/codegraph.md` d'une base de code — une carte structurée de chaque module avec un objectif, des exportations de clés et des dépendances — afin que l'agent puisse naviguer dans n'importe quel dépôt en lisant un fichier au lieu d'en analyser des dizaines. À utiliser lorsque vous commencez à travailler sur une base de code inconnue, lorsqu'on vous demande d'indexer un dépôt, lorsque les coûts de contexte sont élevés en raison d'analyses répétées ou au début de toute tâche touchant plusieurs fichiers.
