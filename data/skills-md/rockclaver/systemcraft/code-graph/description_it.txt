Costruisce e mantiene un indice `.claude/codegraph.md` di una base di codice - una mappa strutturata di ogni modulo con scopo, esportazioni chiave e dipendenze - in modo che l'agente possa navigare in qualsiasi repository leggendo un file invece di scansionarne dozzine. Da utilizzare quando si inizia a lavorare su una codebase sconosciuta, quando viene richiesto di indicizzare un repository, quando i costi di contesto sono elevati a causa di scansioni ripetute o all'inizio di qualsiasi attività che toccherà più file.
