Создает и поддерживает индекс базы кода `.claude/codegraph.md` — структурированную карту каждого модуля с назначением, экспортом ключей и зависимостями — чтобы агент мог перемещаться по любому репозиторию, читая один файл вместо сканирования десятков. Используйте при начале работы с незнакомой кодовой базой, при запросе на индексацию репозитория, когда затраты контекста высоки из-за повторных сканирований или в начале любой задачи, которая затрагивает несколько файлов.
