Crea y mantiene un índice `.claude/codegraph.md` de una base de código (un mapa estructurado de cada módulo con propósito, exportaciones clave y dependencias) para que el agente pueda navegar por cualquier repositorio leyendo un archivo en lugar de escanear docenas. Úselo cuando comience a trabajar en una base de código desconocida, cuando se le solicite indexar un repositorio, cuando los costos de contexto sean altos debido a escaneos repetidos o al comienzo de cualquier tarea que afecte a varios archivos.
