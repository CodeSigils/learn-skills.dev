Erstellt und verwaltet einen „.claude/codegraph.md“-Index einer Codebasis – eine strukturierte Karte jedes Moduls mit Zweck, Schlüsselexporten und Abhängigkeiten – sodass der Agent durch jedes Repo navigieren kann, indem er eine Datei liest, anstatt Dutzende zu scannen. Verwenden Sie diese Option, wenn Sie mit der Arbeit an einer unbekannten Codebasis beginnen, wenn Sie aufgefordert werden, ein Repo zu indizieren, wenn die Kontextkosten durch wiederholte Scans hoch sind, oder zu Beginn einer Aufgabe, die mehrere Dateien betrifft.
