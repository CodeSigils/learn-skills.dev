Diseñe e implemente puntos finales de API DRY REST consistentes para modelos de bases de datos (controladores, enrutamiento, validación, respuestas de error y utilidades compartidas) y luego genere cobertura de prueba para cada punto final. Úselo cuando el usuario solicite escribir una API, agregar puntos finales para un modelo, crear una capa REST o crear rutas CRUD.
