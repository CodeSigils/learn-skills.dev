قم بتصميم وتنفيذ نقاط نهاية DRY REST API المتسقة لنماذج قواعد البيانات - المعالجات والتوجيه والتحقق من الصحة والاستجابات للأخطاء والأدوات المساعدة المشتركة - ثم قم بإنشاء تغطية اختبار لكل نقطة نهاية. يُستخدم عندما يطلب المستخدم كتابة واجهة برمجة التطبيقات (API)، أو إضافة نقاط نهاية لنموذج، أو إنشاء طبقة REST، أو إنشاء مسارات CRUD.
