Rédigez des PRD de fonctionnalités sensibles à la mise en œuvre en ancrant les exigences dans la base de code actuelle, les modules réutilisables et les compétences/outils disponibles. À utiliser lorsque l'utilisateur souhaite un PRD pour un produit existant, demande une spécification de fonctionnalité prenant en compte la base de code ou souhaite une planification des fonctionnalités qui tient explicitement compte de l'architecture et des outils actuels.
