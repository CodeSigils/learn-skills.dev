Escriba PRD de funciones conscientes de la implementación basando los requisitos en la base de código actual, los módulos reutilizables y las habilidades/herramientas disponibles. Úselo cuando el usuario desee un PRD para un producto existente, solicite una especificación de función basada en el código o desee una planificación de funciones que tenga en cuenta explícitamente la arquitectura y las herramientas actuales.
