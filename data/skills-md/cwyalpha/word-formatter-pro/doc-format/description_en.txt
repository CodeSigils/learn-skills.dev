Official document formatting tool. Automatically formats doc/docx/wps/txt/md files according to official document layout conventions and outputs a standard docx. Supports intelligent recognition of heading levels (e.g., 一, (一), 1., (1)), titles/subtitles, attachment formatting, chart title detection, page margins, page numbers, line spacing, font size, TXT/MD blank‑line mode, custom configurations, and batch processing of tables of contents. Use this skill when you need to layout official documents, format files, unify document styles, or adjust fonts, sizes, line spacing, and margins. Keywords: official document layout, document formatting, font settings, heading hierarchy, format unification, layout tool.
