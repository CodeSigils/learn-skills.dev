Crea una knowledge base compatibile con Obsidian da fonti web pubbliche utilizzando la CLI TinyFish. Utilizza questa competenza quando un utente desidera una knowledge base di markdown di livello builder su un argomento tecnico, richiede un deposito di ricerca strutturato o desidera un argomento compilato da fonti pubbliche in tempo reale in file di markdown interconnessi. Supporta due modalità di input: solo argomento o argomento più URL iniziali. Supporta sia i flussi di lavoro di prima creazione che quelli di aggiornamento. Genera sempre index.md, source.md, audit.md e manifest.json. Crea file aggiuntivi solo quando le prove li supportano. L'output deve sintetizzare l'argomento in un modello mentale utilizzabile, non limitarsi a riassumere le pagine. Utilizza solo comandi espliciti di esecuzione dell'agente tinyfish e fonti Web pubbliche. La modalità opzionale `--trace` salva gli output grezzi di TinyFish in `_trace/` per il debug.
