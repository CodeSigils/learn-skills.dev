Cree una base de conocimientos compatible con Obsidian a partir de fuentes web públicas utilizando la CLI de TinyFish. Utilice esta habilidad cuando un usuario quiera una base de conocimientos de rebajas de nivel de constructor sobre un tema técnico, solicite una bóveda de investigación estructurada o quiera un tema compilado a partir de fuentes públicas en vivo en archivos de rebajas interconectados. Admite dos modos de entrada: solo tema o tema más URL de inicio. Admite flujos de trabajo de primera compilación y actualización. Siempre genera index.md, sources.md, audit.md y manifest.json. Crea archivos adicionales sólo cuando la evidencia los respalda. El resultado debe sintetizar el tema en un modelo mental utilizable, no simplemente resumir páginas. Utiliza comandos explícitos de ejecución del agente tinyfish y fuentes web públicas únicamente. El modo opcional `--trace` guarda los resultados sin procesar de TinyFish en `_trace/` para su depuración.
