Créez une base de connaissances compatible Obsidian à partir de sources Web publiques à l'aide de la CLI TinyFish. Utilisez cette compétence lorsqu'un utilisateur souhaite disposer d'une base de connaissances de démarque de niveau constructeur sur un sujet technique, demande un coffre-fort de recherche structuré ou souhaite qu'un sujet soit compilé à partir de sources publiques en direct dans des fichiers de démarques interconnectés. Prend en charge deux modes de saisie : sujet uniquement ou sujet plus URL de démarrage. Prend en charge les flux de travail de première génération et de mise à jour. Génère toujours index.md, sources.md, audit.md et manifest.json. Crée des fichiers supplémentaires uniquement lorsque les preuves les soutiennent. Le résultat doit synthétiser le sujet dans un modèle mental utilisable, et pas seulement résumer les pages. Utilise uniquement les commandes d'exécution explicites de l'agent Tinyfish et les sources Web publiques. Le mode `--trace` facultatif enregistre les sorties brutes de TinyFish sous `_trace/` pour le débogage.
