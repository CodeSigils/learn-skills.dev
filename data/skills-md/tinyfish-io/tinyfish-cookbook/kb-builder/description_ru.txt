Создайте совместимую с Obsidian базу знаний из общедоступных веб-источников с помощью интерфейса командной строки TinyFish. Используйте этот навык, когда пользователю нужна база знаний с уценкой профессионального уровня по технической теме, запрашивается структурированное хранилище исследований или нужна тема, скомпилированная из общедоступных источников во взаимосвязанные файлы с уценкой. Поддерживает два режима ввода: только тема или тема плюс начальные URL-адреса. Поддерживает рабочие процессы как первой сборки, так и обновления. Всегда генерирует index.md, source.md, Audit.md и манифест.json. Создает дополнительные файлы только в том случае, если это подтверждается доказательствами. Результат должен синтезировать тему в удобную мысленную модель, а не просто суммировать страницы. Использует явные команды запуска агента tinyfish и только общедоступные веб-источники. Дополнительный режим `--trace` сохраняет необработанные выходные данные TinyFish в `_trace/` для отладки.
