Stackbone 작업 영역('Stackbone dev'에서 로컬로 실행되는 심층 에이전트 또는 내구성 있는 워크플로 또는 클라우드/자체 호스트에 배포된 설치)에서 오류, 실패 또는 예상치 못한 동작을 분류할 때 이 기술을 사용하세요. SDK 오류(주변 `stackbone` 클라이언트에서 반환한 카탈로그의 { 데이터, 오류 } 봉투 코드), 컨트롤 플레인의 HTTP 4xx/5xx, 내구성 있는 실행 실패 및 시간 초과, `workflow_input_invalid`(입력이 선언된 스키마에 실패한 워크플로 시작), HITL이 두 수준 중 하나에서 멈췄습니다(`requestApproval()` 게이트에 저장된 워크플로 또는 `interruptOn`으로 게이트된 도구에서 에이전트가 `중단`을 전환함), 지속성 세션 문제(`x-stackbone-session`이 전송되지 않았거나 체크포인터 패키지가 누락되어 메모리가 유지되지 않음), 데이터베이스 느린 쿼리/인덱스 누락/pgVector 불일치, 비밀 암호 해독 오류, `stackbone.connection(id)`를 통한 커넥터 작업 실패(모호/무단 연결), 게시/빌드 실패(SDK 인라인, 기본 dep), 계층 할당량 초과 응답 및 OpenRouter 속도 제한/ 결제가 일시 중지된 상황. 다음과 같은 요청에 대해 트리거합니다. 에이전트가 작동하지 않습니다. 500이 왜 발생합니까? 이 실행이 중단되었습니다. HITL 받은 편지함은 비어 있지만 실행이 일시 중지되었습니다. 에이전트가 대화를 잊어버렸습니다. 워크플로가 내 입력을 거부했습니다. 게시에 실패했습니다. 402가 표시되는 이유는 무엇입니까? 커넥터 호출이 모호한 이유는 무엇입니까? 모델 호출이 응답을 반환하지 않습니다. 기술은 진단 명령 실행을 안내합니다. 수정 사항을 제안하지는 않습니다. 원인을 찾은 후에는 stackbone 또는 stackbone-cli 기술로 다시 전환하여 수정 사항을 구현하세요.
