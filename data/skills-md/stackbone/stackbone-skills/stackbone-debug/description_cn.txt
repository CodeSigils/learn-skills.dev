在对 Stackbone 工作区中的错误、故障或意外行为进行分类时使用此技能 - 在“stackbone dev”下本地运行的深度代理或持久工作流程，或部署到云/自主机的安装。涵盖 SDK 错误（来自环境 `stackbone` 客户端返回的目录中的 { data, error } 信封代码）、来自控制平面的 HTTP 4xx/5xx、持久运行失败和超时、`workflow_input_invalid`（输入失败其声明模式的工作流启动）、HITL 卡在任一级别（停放在 `requestApproval()` 门上的工作流，或代理在使用 `interruptOn` 门控的工具上打开“中断”），持久会话问题（由于未发送“x-stackbone-session”，或缺少检查点程序包，内存未幸存）、数据库缓慢查询/缺少索引/pgvector 不匹配、秘密解密错误、通过“stackbone.connection(id)”的连接器操作失败（不明确/未经授权的连接）、发布/构建失败（SDK 内联、本机 dep）、层配额超出响应以及 OpenRouter 速率限制/计费暂停情况。触发以下请求：我的代理无法工作、为什么是 500、此运行挂起、HITL 收件箱为空但运行已暂停、代理忘记了对话、工作流程拒绝了我的输入、发布失败、为什么我收到 402、为什么我的连接器调用不明确、模型调用没有返回响应。该技能指导诊断命令的执行；它不建议修复 - 一旦找到原因，请切换回 stackbone 或 stackbone-cli 技能来实施修复。
