Utilizza questa competenza quando guidi la CLI `stackbone` per impacchettare, sviluppare, pubblicare o utilizzare un agente su Stackbone: autenticazione con il flusso del dispositivo (login/whoami), impalcatura di una shell dello spazio di lavoro e collegamento al piano di controllo (init, facoltativamente con un primo agente/flusso di lavoro/pezzo dell'agente del flusso di lavoro), aggiunta di più pezzi offline in uno spazio di lavoro esistente (aggiungi deep-agent/aggiungi flusso di lavoro/aggiungi flusso di lavoro/agente del flusso di lavoro), collegamento di una directory esistente a un agente (collegamento), esecuzione dello sviluppo locale impilare con Studio (dev), pubblicare l'area di lavoro (pubblica), cambiare l'organizzazione attiva come agisce la CLI (uso dell'organizzazione), gestire le migrazioni del database con Drizzle (db migra su / crea / stato), leggere i metadati dell'area di lavoro in JSON (metadati), elencare i connettori disponibili e le connessioni dell'account con ID e nomi (connettori), stampare documenti in linea (documenti) e gestire un'installazione di agenti in esecuzione dalla shell, scoprendo destinazioni di installazione (agenti), ispezionando e attivando flussi di lavoro durevoli. espone (lista dei flussi di lavoro / schema / avvio), ispezione e controllo delle esecuzioni (runs), tailing logs (logs), interrogazione/esplorazione del DB dell'agente (db query / schemi / tabella), spostamento di oggetti nello store (storage), utilizzo dell'indice RAG gestito (rag), impostazione di segreti (secrets), versione del documento di configurazione e rigenerazione dei suoi tipi (config), ispezione del contratto di protocollo (contratto), decisione delle approvazioni human-in-the-loop (hitl), gestione del catalogo dei prompt (prompt) e lettura del cablaggio OpenRouter (openrouter). Attivazione di richieste quali: impalcatura di un'area di lavoro, inizializzazione di un progetto vuoto, aggiunta di un deep agent all'area di lavoro, aggiunta di un flusso di lavoro, aggiunta di un flusso di lavoro che richiama un agente (agente del flusso di lavoro), avvio dello stack di sviluppo, pubblicazione dell'area di lavoro, generazione di una migrazione, elenco delle mie organizzazioni, cambio organizzazione, elenco connettori o connessioni, visualizzazione di cosa è collegato, accesso a Stackbone, elenco degli agenti, elenco dei flussi di lavoro esposti da un'installazione, avvio di un flusso di lavoro per nome, ritenta un'esecuzione non riuscita, coda dei log, esecuzione una SELECT contro l'agente, imposta un segreto, ripristina la configurazione, approva una richiesta HITL. Per scrivere codice all'interno dell'agente con @stackbone/sdk, utilizza invece la competenza stackbone. Per la valutazione degli errori e delle esecuzioni bloccate, utilizzare la capacità di debug stackbone.
