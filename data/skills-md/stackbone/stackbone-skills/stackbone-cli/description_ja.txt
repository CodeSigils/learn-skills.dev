「stackbone」CLI を操作して Stackbone 上でエージェントをスキャフォールディング、開発、公開、または操作するときにこのスキルを使用します。デバイス フローでの認証（ログイン / whoami）、ワークスペース シェルのスキャフォールディングとコントロール プレーンへのリンク（初期化、オプションで最初のエージェント / ワークフロー / ワークフロー エージェント ピースを使用）、既存のワークスペースにオフラインでピースを追加（ディープ エージェントの追加 / ワークフローの追加 / ワークフロー エージェントの追加）、既存のディレクトリをエージェントにリンクします。 (リンク)、Studio でのローカル開発スタックの実行 (開発)、ワークスペースの公開 (公開)、CLI が機能するアクティブな組織の切り替え (組織の使用)、Drizzle によるデータベース移行の管理 (データベース移行アップ / 作成 / ステータス)、JSON でのワークスペース メタデータの読み取り (メタデータ)、ID と名前を使用した利用可能なコネクタとアカウントの接続の一覧表示 (コネクタ)、インライン ドキュメントの印刷 (ドキュメント)、シェルからの実行中のエージェント インストールの操作 — インストール ターゲットの検出(エージェント)、公開する永続ワークフローの検査とトリガー (ワークフロー リスト/スキーマ/開始)、実行の検査と制御 (実行)、ログの追跡 (ログ)、エージェント DB のクエリ/参照 (データベース クエリ/スキーマ/テーブル)、ストア内のオブジェクトの移動 (ストレージ)、マネージド RAG インデックス (ラグ) の操作、シークレット (シークレット) の設定、構成ドキュメントのバージョン管理とそのタイプの再生成(config)、プロトコル コントラクトの検査 (contract)、人間参加者の承認の決定 (hitl)、プロンプト カタログの管理 (prompts)、OpenRouter 配線の読み取り (openrouter)。次のようなリクエストでトリガーします: ワークスペースのスキャフォールディング、空のプロジェクトの初期化、ワークスペースへのディープ エージェントの追加、ワークフローの追加、エージェントを呼び出すワークフロー (ワークフロー エージェント) の追加、開発スタックの開始、ワークスペースの公開、移行の生成、組織の一覧表示、組織の切り替え、コネクタまたは接続の一覧表示、リンク内容の確認、Stackbone へのログイン、エージェントの一覧表示、インストールで公開されるワークフローの一覧表示、名前によるワークフローの開始、失敗したワークフローの再試行実行、ログの追跡、エージェントに対する SELECT の実行、シークレットの設定、構成のロールバック、HITL リクエストの承認。 @stackbone/sdk を使用してエージェント内にコードを記述する場合は、代わりに stackbone スキルを使用してください。エラーとスタック実行のトリアージには、stackbone-debug スキルを使用します。
