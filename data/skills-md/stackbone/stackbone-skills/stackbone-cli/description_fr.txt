Utilisez cette compétence lorsque vous pilotez la CLI `stackbone` pour échafauder, développer, publier ou exploiter un agent sur Stackbone : authentification avec le flux de périphérique (login / whoami), échafaudage d'un shell d'espace de travail et le lier au plan de contrôle (init, éventuellement avec un premier élément agent / workflow / workflow-agent), ajout d'éléments supplémentaires hors ligne dans un espace de travail existant (ajouter un agent profond / ajouter un workflow / ajouter un agent de workflow), lier un répertoire existant à un agent (lien), exécuter la pile de développement locale avec Studio (dév), publication de l'espace de travail (publication), changement d'organisation active en tant que CLI (utilisation de l'organisation), gestion des migrations de bases de données avec Drizzle (db migrate up / create / status), lecture des métadonnées de l'espace de travail au format JSON (métadonnées), liste des connecteurs disponibles et des connexions du compte avec les identifiants et les noms (connecteurs), impression de documents en ligne (docs) et exploitation d'une installation d'agent en cours à partir du shell - découverte des cibles d'installation (agents), inspection et déclenchement des flux de travail durables qu'il expose (liste des workflows / schéma / démarrage), inspection et contrôle des exécutions (runs), suivi des journaux (logs), interrogation/parcours de la base de données de l'agent (requête de base de données / schémas / table), déplacement d'objets dans le magasin (stockage), exploitation de l'index RAG géré (rag), définition des secrets (secrets), versionnage du document de configuration et régénération de ses types (config), inspection du contrat de protocole (contrat), décision des approbations humaines (hitl), gestion le catalogue d'invites (invites) et la lecture du câblage OpenRouter (openrouter). Déclenchez des requêtes telles que : échafauder un espace de travail, lancer un projet vide, ajouter un agent profond à mon espace de travail, ajouter un workflow, ajouter un workflow qui appelle un agent (workflow-agent), démarrer la pile de développement, publier mon espace de travail, générer une migration, lister mes organisations, changer d'organisation, lister les connecteurs ou les connexions, voir ce qui est lié, se connecter à Stackbone, lister mes agents, lister les workflows qu'une installation expose, démarrer un workflow par nom, réessayer une exécution échouée, suivre les journaux, exécuter un SELECT contre l'agent, définissez un secret, annulez la configuration, approuvez une requête HITL. Pour écrire du code dans l'agent avec @stackbone/sdk, utilisez plutôt la compétence stackbone. Pour le tri des erreurs et des exécutions bloquées, utilisez la compétence stackbone-debug.
