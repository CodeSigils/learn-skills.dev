استخدم هذه المهارة عند قيادة واجهة سطر الأوامر "stackbone" لدعم وكيل أو تطويره أو نشره أو تشغيله على Stackbone: المصادقة باستخدام تدفق الجهاز (تسجيل الدخول / whoami)، ودعم غلاف مساحة العمل وربطه بمستوى التحكم (init، اختياريًا مع وكيل أول / سير العمل / قطعة وكيل سير العمل)، وإضافة المزيد من القطع غير المتصلة بالإنترنت إلى مساحة عمل موجودة (إضافة وكيل عميق / إضافة سير عمل / إضافة وكيل سير عمل)، وربط دليل موجود بوكيل (رابط)، تشغيل حزمة التطوير المحلية باستخدام Studio (dev)، نشر مساحة العمل (نشر)، تبديل المؤسسة النشطة التي تعمل واجهة سطر الأوامر (CLI) كـ (استخدام المؤسسة)، إدارة عمليات ترحيل قاعدة البيانات باستخدام Drizzle (ترحيل قاعدة البيانات لأعلى / إنشاء / حالة)، قراءة البيانات التعريفية لمساحة العمل في JSON (بيانات التعريف)، سرد الموصلات المتاحة واتصالات الحساب بالمعرفات والأسماء (الموصلات)، وطباعة المستندات المضمنة (docs)، وتشغيل تثبيت وكيل قيد التشغيل من Shell - اكتشاف أهداف التثبيت (الوكلاء)، فحص وتشغيل سير العمل الدائم الذي يعرضه (قائمة سير العمل / المخطط / البدء)، فحص عمليات التشغيل والتحكم فيها (عمليات التشغيل)، سجلات المخلفات (السجلات)، الاستعلام/تصفح وكيل قاعدة البيانات (استعلام / مخططات / جدول قاعدة بيانات)، نقل الكائنات في المتجر (التخزين)، تشغيل فهرس RAG المُدار (خرقة)، إعداد الأسرار (الأسرار)، إصدار مستند التكوين وإعادة إنشاء أنواعه (التكوين)، فحص عقد البروتوكول (العقد)، وتحديد الموافقات البشرية (hitl)، وإدارة كتالوج المطالبة (المطالبات)، وقراءة أسلاك OpenRouter (openrouter). تشغيل طلبات مثل: دعم مساحة عمل، بدء مشروع فارغ، إضافة وكيل عميق إلى مساحة العمل الخاصة بي، إضافة سير عمل، إضافة سير عمل يستدعي وكيلًا (وكيل سير العمل)، بدء مكدس التطوير، نشر مساحة العمل الخاصة بي، إنشاء عملية ترحيل، إدراج مؤسساتي، تبديل المؤسسة، قائمة الموصلات أو الاتصالات، رؤية ما هو مرتبط، تسجيل الدخول إلى Stackbone، إدراج الوكلاء، إدراج سير العمل الذي يكشفه التثبيت، بدء سير العمل بالاسم، إعادة المحاولة الفاشلة تشغيل، ذيل السجلات، تشغيل SELECT ضد الوكيل، تعيين سر، إعادة التكوين مرة أخرى، الموافقة على طلب HITL. لكتابة التعليمات البرمجية داخل الوكيل باستخدام @stackbone/sdk، استخدم مهارة Stackbone بدلاً من ذلك. لفرز الأخطاء وعمليات التشغيل المتوقفة، استخدم مهارة تصحيح الأخطاء المكدسة.
