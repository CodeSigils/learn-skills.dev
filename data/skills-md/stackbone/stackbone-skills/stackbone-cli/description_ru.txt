Используйте этот навык при использовании CLI stackbone для формирования, разработки, публикации или управления агентом на Stackbone: аутентификация с помощью потока устройств (вход в систему / whoami), создание оболочки рабочего пространства и привязка ее к плоскости управления (инициализация, опционально с частью первого агента / рабочего процесса / агента рабочего процесса), добавление дополнительных частей в автономном режиме в существующее рабочее пространство (добавление глубокого агента / добавление рабочего процесса / добавление агента рабочего процесса), привязка существующего каталога к агенту (ссылка), запуск локального стека разработки с помощью Studio (dev), публикация рабочей области (публикация), переключение активной организации, в качестве которой выступает CLI (использование в организации), управление миграцией базы данных с помощью Drizzle (миграция базы данных вверх/создание/статус), чтение метаданных рабочей области в формате JSON (метаданные), составление списка доступных соединителей и соединений учетной записи с идентификаторами и именами (соединители), печать встроенных документов (документы) и запуск запущенной установки агента из оболочки — обнаружение целей установки (агентов), проверка и запуск устойчивые рабочие процессы, которые он предоставляет (список/схема/запуск рабочих процессов), проверка и контроль выполнения (запусков), хвостовые журналы (журналы), запрос/просмотр базы данных агента (запрос к базе данных/схемы/таблица), перемещение объектов в хранилище (хранилище), работа с управляемым индексом RAG (rag), установка секретов (секретов), управление версиями документа конфигурации и повторное создание его типов (config), проверка контракта протокола (контракт), принятие решений об одобрении человеком в цикле (hitl), управление каталогом подсказок (prompts) и чтение проводки OpenRouter (openrouter). Запуск по таким запросам, как: создание рабочей области, запуск пустого проекта, добавление глубокого агента в мою рабочую область, добавление рабочего процесса, добавление рабочего процесса, который вызывает агента (агент рабочего процесса), запуск стека разработки, публикация моего рабочего пространства, создание миграции, составление списка моих организаций, переключение организации, список соединителей или соединений, просмотр того, что связано, вход в Stackbone, список моих агентов, список рабочих процессов, которые предоставляет установка, запуск рабочего процесса по имени, повторная попытка неудачи запустить, просмотреть журналы, выполнить SELECT для агента, установить секрет, откатить конфигурацию, утвердить запрос HITL. Для написания кода внутри агента с помощью @stackbone/sdk используйте вместо этого навык stackbone. Для сортировки ошибок и зависших запусков используйте навык stackbone-debug.
