Utilice esta habilidad para GENERAR una nueva pieza de Stackbone a partir de una idea clara a través de una entrevista guiada: primero decida qué construir: un agente profundo, un flujo de trabajo duradero o un agente de flujo de trabajo (un flujo de trabajo que llama a un agente), luego amplíelo con la CLI de Stackbone y entreviste al usuario superficie por superficie. Para un agente, usted solicita sus herramientas y su sistema de aviso; para un flujo de trabajo, solicita los datos de entrada y los datos de salida (el esquema de entrada/esquema de salida); luego recorre la lista de verificación de capacidades UNA A LA VEZ: ¿necesitamos una base de datos? ¿humano al tanto? ¿TRAPO? ¿almacenamiento? ¿Una llamada de LLM? un conector? indicaciones? configuración? ¿misterios? un horario? llamar a otro agente? — y conecte solo las superficies que el usuario realmente necesita. Esta habilidad IMPULSA la entrevista y el andamiaje; delega el código real a la habilidad `stackbone` (autoría de SDK) y los comandos a la habilidad `stackbone-cli`. Activa solicitudes como: crear un nuevo agente, desarrollar un flujo de trabajo, crear un flujo de trabajo que llame a un agente, "Quiero crear un agente que...", "Necesito una canalización que tome X y devuelva Y", iniciar una nueva pieza de espacio de trabajo, generar un agente con herramientas, iniciar un nuevo proyecto de Stackbone. Para escribir el código SDK, utilice la habilidad `stackbone`; para la superficie CLI utilice `stackbone-cli`; para clasificar una ejecución fallida, utilice `stackbone-debug`.
