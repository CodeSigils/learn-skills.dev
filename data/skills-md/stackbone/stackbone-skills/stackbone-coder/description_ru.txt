Используйте этот навык, чтобы СОЗДАТЬ новую часть Stackbone на основе чистой идеи посредством управляемого интервью: сначала решите, что создавать — глубокий агент, устойчивый рабочий процесс или рабочий процесс-агент (рабочий процесс, который вызывает агента) — затем сформируйте его с помощью интерфейса командной строки stackbone и опросите пользователя поверхность за поверхностью. Для агента вы запрашиваете его инструменты и системную подсказку; для рабочего процесса вы запрашиваете входные и выходные данные (входная схема/выходная схема); затем вы проходите контрольный список возможностей ОДИН ЗА РАЗ — нужна ли нам база данных? человек в курсе? ТРЯПКА? хранилище? звонок в LLM? разъем? подсказывает? конфигурация? секреты? график? позвонить другому агенту? — и подключайте только те поверхности, которые действительно нужны пользователю. Этот навык УПРАВЛЯЕТ собеседованием и подготовкой; он делегирует реальный код навыку stackbone (разработка SDK), а команды — навыку stackbone-cli. Запуск по таким запросам: создать новый агент, создать рабочий процесс, создать рабочий процесс, который вызывает агента, «Я хочу создать агент, который…», «Мне нужен конвейер, который принимает X и возвращает Y», запускает новую часть рабочего пространства, генерирует агента с инструментами, запускает новый проект Stackbone. Для написания самого кода SDK используйте навык stackbone; для поверхности CLI используйте stackbone-cli; для сортировки неудачного запуска используйте stackbone-debug.
