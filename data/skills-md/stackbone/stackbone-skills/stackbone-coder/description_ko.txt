이 기술을 사용하여 안내된 인터뷰를 통해 깔끔한 아이디어에서 새로운 Stackbone 조각을 생성합니다. 먼저 무엇을 구축할지(딥 에이전트, 내구성 있는 워크플로 또는 워크플로 에이전트(에이전트를 호출하는 워크플로)) 결정한 다음 스택본 CLI로 이를 스캐폴드하고 표면별로 사용자 표면을 인터뷰합니다. 에이전트의 경우 도구와 시스템 프롬프트를 요청합니다. 워크플로의 경우 입력 데이터와 출력 데이터(inputSchema/outputSchema)를 요청합니다. 그런 다음 한 번에 하나씩 기능 체크리스트를 검토합니다. 데이터베이스가 필요합니까? 인간 루프? 조각? 저장? LLM 통화요? 커넥터? 프롬프트? 구성? 기미? 일정? 다른 상담원에게 전화할까? — 사용자에게 실제로 필요한 표면에만 배선합니다. 이 기술은 인터뷰와 발판을 주도합니다. 실제 코드를 'Stackbone' 기술(SDK 작성)에 위임하고 명령을 'Stackbone-cli' 기술에 위임합니다. 다음과 같은 요청에 따라 트리거합니다. 새 에이전트 구축, 워크플로 스캐폴드, 에이전트를 호출하는 워크플로 생성, "...", "X를 취하고 Y를 반환하는 파이프라인이 필요합니다", 새 작업 영역 시작, 도구를 사용하여 에이전트 생성, 새 Stackbone 프로젝트 시작. SDK 코드 자체를 작성하려면 `stackbone` 스킬을 사용하세요. CLI 표면의 경우 `stackbone-cli`를 사용하세요. 실패한 실행을 분류하려면 `stackbone-debug`를 사용하세요.
