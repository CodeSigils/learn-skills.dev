使用此技能通过引导式访谈从清晰的想法生成新的 Stackbone 片段：首先决定要构建什么 - 深度代理、持久工作流或工作流代理（调用代理的工作流） - 然后使用 Stackbone CLI 构建它并逐层访谈用户。对于代理，您需要其工具和系统提示；对于工作流程，您需要输入数据和输出数据（inputSchema / outputSchema）；然后你一次检查一个能力清单——我们需要一个数据库吗？人在循环中？抹布？贮存？ LLM 电话？连接器？提示？配置？秘密？一个时间表？打电话给另一个代理人？ - 并且仅在用户实际需要的表面上布线。这项技能驱动面试和脚手架；它将真实代码委托给“stackbone”技能（SDK 创作），并将命令委托给“stackbone-cli”技能。触发以下请求：构建新代理、构建工作流、创建调用代理的工作流、“我想要创建一个代理……”、“我需要一个接受 X 并返回 Y 的管道”、启动新的工作区片段、使用工具生成代理、启动新的 Stackbone 项目。要编写 SDK 代码本身，请使用“stackbone”技能；对于 CLI 界面，请使用“stackbone-cli”；要对失败的运行进行分类，请使用“stackbone-debug”。
