使用此技能透過引導式訪談從清晰的想法產生新的 Stackbone 片段：首先決定要建立什麼 - 深度代理、持久工作流程或工作流程代理（呼叫代理的工作流程） - 然後使用 Stackbone CLI 建立它並逐層訪談使用者。對於代理，您需要其工具和系統提示；對於工作流程，您需要輸入資料和輸出資料（inputSchema / outputSchema）；然後你一次檢查一個能力清單－我們需要一個資料庫嗎？人在循環中？抹布？貯存？ LLM 電話？連接器？提示？配置？秘密？一個時間表？打電話給另一個代理人？ - 並且僅在使用者實際需要的表面上佈線。這項技能驅動面試和鷹架；它將真實代碼委託給“stackbone”技能（SDK 創作），並將命令委託給“stackbone-cli”技能。觸發以下請求：建立新代理程式、建置工作流程、建立呼叫代理的工作流程、「我想要建立一個代理程式…」、「我需要一個接受 X 並返回 Y 的管道」、啟動新的工作區片段、使用工具產生代理、啟動新的 Stackbone 專案。要編寫 SDK 程式碼本身，請使用「stackbone」技能；對於 CLI 介面，請使用「stackbone-cli」；若要對失敗的運行進行分類，請使用「stackbone-debug」。
