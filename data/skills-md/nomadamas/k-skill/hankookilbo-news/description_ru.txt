Официальный удаленный сервер MCP Korea Ilbo (mcp.hankookilbo.com) вызывается напрямую, без аутентификации, для получения редакционных заголовков, наиболее читаемых статей, внимательно читаемых статей, последних статей, редакционных рекомендаций по конкретным разделам, поиска по темам и сегодняшнего гороскопа с упором на метаданные статьи (название, время публикации, исходная ссылка).
