Интерпретируйте названия административных районов Сеула как стандартные Place_id, используя только официально приоритетные и разрешенные окончательные псевдонимы обозначений. Один продукт ASK Seoul для прогноза погодных рисков для каждого местоположения (weather_place_risk_window) запрашивается только для чтения из размещенного прокси-сервера k-skill. Путь по умолчанию не требует ни ключа пользовательского API, ни ввода Place_id, и перед регистрацией вы можете явно выполнить локальную прямую проверку.
