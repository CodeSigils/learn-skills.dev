Интерпретируйте имя административного ключа Сеула как стандартный Place_id, используя только официальное название и разрешенный окончательный псевдоним, и запросите временное окно прогноза погодных рисков (weather_place_risk_window) для каждого местоположения в Сеуле как один продукт через размещенный прокси-сервер k-skill в режиме только для чтения. Путь по умолчанию не требует ввода ключа API пользователя или ввода Place_id, и перед регистрацией вы можете явно выполнить прямую локальную проверку.
