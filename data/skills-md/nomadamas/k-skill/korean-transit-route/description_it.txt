Instradamento del trasporto pubblico coreano porta a porta (metropolitana + autobus + piedi) tramite ODsay LIVE API con geocodifica Kakao per query da indirizzo a indirizzo. Da utilizzare quando l'utente richiede 지하철/버스/대중교통 길찾기, 환승 경로, 소요시간 o indicazioni di trasporto pubblico tra due località in Corea.
