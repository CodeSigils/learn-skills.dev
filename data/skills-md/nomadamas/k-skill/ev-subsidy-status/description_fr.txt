Le site Web intégré sur les véhicules zéro émission du ministère de l’Environnement est utilisé pour rechercher les annonces privées, les demandes, les livraisons, les numéros de livraison restants et l’état des annonces de subventions à l’achat de véhicules électriques par les gouvernements locaux coréens. Il est utilisé pour vérifier le statut des subventions restantes pour les voitures particulières électriques, les véhicules de fret électriques et les fourgonnettes électriques dans la région de l'utilisateur, si les demandes sont acceptées, les délais, l'épuisement, la budgétisation supplémentaire prévue et les montants de conversion des subventions pour des modèles spécifiques.
