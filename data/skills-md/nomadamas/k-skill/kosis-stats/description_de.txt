Durchsuchen Sie offizielle koreanische statistische Tabellen und rufen Sie Metadaten, Daten und umfangreiches Material mithilfe der offenen API KOSIS (National Statistics Portal, kosis.kr) ab, die von der National Data Agency betrieben wird. Verwenden Sie dies, wenn der Benutzer Werte offizieller koreanischer Statistiken (Bevölkerung, Haushalte, Preise, Beschäftigung usw.) anfordert, nicht zur Analyse oder Visualisierung.
