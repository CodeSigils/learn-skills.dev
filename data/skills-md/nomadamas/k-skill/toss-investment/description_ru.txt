Используя официальный открытый API Toss Securities (OAuth2), получайте информацию об учетных записях, активах, данных о ценах/предметах/рынках, а также запросы заказов через безопасный поток, доступный только для чтения. Не обходите неофициальные каналы для функций, не имеющих официальных учетных данных или не поддерживаемых официальным API.
