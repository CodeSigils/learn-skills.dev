Официальный открытый API Toss Securities (OAuth2) используется для получения информации об учетной записи, активов, данных о ценах, акциях и рынках, а также запросов заказов через безопасный поток, доступный только для чтения. Если официальные учетные данные недоступны или функция не поддерживается официальным API, к ней нельзя будет получить доступ через неофициальные обходные пути.
