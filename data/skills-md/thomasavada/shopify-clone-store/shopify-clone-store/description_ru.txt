Клонируйте общедоступную витрину магазина Shopify (каталог + внешний вид) в магазин, принадлежащий пользователю, с помощью Shopify CLI OAuth и Admin GraphQL. Пересобрать на Horizon/OS 2.0 — не воруйте исходники темы. Используйте, когда пользователь говорит: клонировать этот сайт Shopify, магазин реплик, скопировать этот бренд в мой магазин myshopify, восстановить бренд в тестовом магазине или запустить /shopify-clone-store. Никогда не коммитируйте токены.
