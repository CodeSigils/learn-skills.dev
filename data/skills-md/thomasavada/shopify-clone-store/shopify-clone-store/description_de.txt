Klonen Sie mithilfe von Shopify CLI OAuth und Admin GraphQL eine öffentliche Shopify-Storefront (Katalog + Look) in einen Shop, der dem Benutzer gehört. Neu erstellen auf Horizon/OS 2.0 – stehlen Sie nicht das Quellthema. Wird verwendet, wenn der Benutzer angibt, diese Shopify-Site zu klonen, den Shop zu replizieren, diese Marke in meinen Myshopify-Shop zu kopieren, eine Marke in einem Testshop neu zu erstellen oder /shopify-clone-store auszuführen. Legen Sie niemals Token fest.
