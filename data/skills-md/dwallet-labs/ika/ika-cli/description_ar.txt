دليل لاستخدام أداة Ika CLI لعمليات dWallet وإدارة أداة التحقق ونشر النظام وإدارة الشبكة. يُستخدم عند إنشاء dWallet المستندة إلى CLI، أو التوقيع، أو التوقيع المسبق، أو إدارة المفاتيح، أو عمليات التحقق من الصحة، أو تهيئة النظام، أو الاستعلام عن حالة شبكة Ika عبر الجهاز. تشغيل المهام التي تتضمن أوامر `ika` CLI أو عمليات dWallet CLI أو نشر نظام Ika أو تكامل أداة MCP مع Ika.
