Руководство по использованию инструмента Ika CLI для операций dWallet, управления валидаторами, развертывания системы и администрирования сети. Используйте при создании dWallet на основе CLI, подписании, предварительном подписании, управлении ключами, операциях валидатора, инициализации системы или запросе состояния сети Ika через терминал. Запускается при выполнении задач, связанных с командами CLI `ika`, операциями CLI dWallet, развертыванием системы Ika или интеграцией инструмента MCP с Ika.
