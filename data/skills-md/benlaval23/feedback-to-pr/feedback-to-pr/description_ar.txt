أضف تعليقات داخل التطبيق وحلقة تقرير الأخطاء التي تلتقط لقطة شاشة بالإضافة إلى سجلات الشبكة/وحدة التحكم، وترسل بريدًا إلكترونيًا إلى المراسل، وتطلق Cursor Cloud Agent باستخدام autoCreatePr، وترسل رسائل البريد الإلكتروني مرة أخرى عند فتح العلاقات العامة وعند دمجها. استخدمه عندما يُطلب منك إضافة تعليقات، أو الإبلاغ عن الأخطاء، أو تقارير المستخدم التي تفتح العلاقات العامة، أو أتمتة المؤشر للتعليقات، أو سير عمل التعليقات إلى العلاقات العامة.
