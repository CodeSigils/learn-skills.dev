Esamina le modifiche al codice attraverso più modelli di intelligenza artificiale prima di inviarle a revisori umani. Da utilizzare quando l'utente chiede di rivedere un ramo con agenti secondari, eseguire una revisione del codice multi-modello, ottenere feedback sulla revisione dell'intelligenza artificiale o menziona "revisionare il mio ramo", "revisione del sottoagente" o "iterare il codice".
