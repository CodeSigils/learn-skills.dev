Nuwa schafft Menschen: Geben Sie einen Namen/ein Thema oder auch nur ein vages Bedürfnis ein, führen Sie eine automatische Tiefenrecherche durch → extrahieren Sie den Denkrahmen → generieren Sie eine ausführbare Charakterfähigkeit.
Zwei Einstiegspunkte: (1) klarer Name → direkte Destillation (2) vager Bedarf → diagnostische Empfehlung → dann Destillation.
Auslöserwörter: „Fähigkeiten schaffen“, „XX destillieren“, „Nuwa“, „Menschen schaffen“, „XXs Denkweise“, „eine XX-Perspektive aufbauen“, „XXs Fähigkeiten aktualisieren“.
Auch vage Bedürfnisse lösen aus: „Ich möchte die Entscheidungsqualität verbessern“, „Gibt es eine Denkweise, die mir helfen kann…“, „Ich brauche einen Denkcoach“.
