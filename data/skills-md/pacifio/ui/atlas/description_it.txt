Atlas: un linguaggio di progettazione e un sistema di guida dell'interfaccia utente per le interfacce degli agenti. Insegna agli agenti di codifica le regole estetiche, i token, i modelli e il vocabolario di classe di un sistema di progettazione multi-superficie denso, AMOLED-nero. Gli agenti leggono queste regole e GENERANO il codice che si adatta allo stack di destinazione (shadcn, Tailwind, HTML grezzo, React, Vue, Svelte). Il file Colors_and_type.css incluso è un'implementazione di riferimento, non una dipendenza richiesta. Utilizzalo pesantemente durante la creazione di qualsiasi interfaccia utente: dashboard, interfacce di chat, pannelli di amministrazione, pagine di destinazione, schermi mobili, siti di marketing, modelli di app completi. Atlas è supponente; appoggiarsi ad esso.
