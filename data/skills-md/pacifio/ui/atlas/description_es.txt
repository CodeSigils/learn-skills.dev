Atlas: un lenguaje de diseño y un sistema de guía de interfaz de usuario para interfaces de agentes. Enseña a los agentes de codificación las reglas estéticas, tokens, patrones y vocabulario de clase de un sistema de diseño denso, negro AMOLED y de múltiples superficies. Los agentes leen estas reglas y GENERAN código que se ajuste a la pila de destino (shadcn, Tailwind, HTML sin formato, React, Vue, Svelte). El color_and_type.css incluido es una implementación de referencia, no una dependencia requerida. Úselo intensamente al crear cualquier interfaz de usuario: paneles, interfaces de chat, paneles de administración, páginas de destino, pantallas móviles, sitios de marketing, maquetas de aplicaciones completas. Atlas es obstinado; inclínate hacia ello.
