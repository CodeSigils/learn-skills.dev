Atlas - un langage de conception et un système de guide d'interface utilisateur pour les interfaces d'agent. Enseigne aux agents de codage les règles esthétiques, les jetons, les modèles et le vocabulaire de classe d'un système de conception multi-surfaces dense, noir AMOLED. Les agents lisent ces règles et GÉNÉRENT du code qui correspond à la pile cible (shadcn, Tailwind, HTML brut, React, Vue, Svelte). Le colours_and_type.css inclus est une implémentation de référence, pas une dépendance obligatoire. Utilisez-le largement lors de la création d'une interface utilisateur : tableaux de bord, interfaces de discussion, panneaux d'administration, pages de destination, écrans mobiles, sites marketing, maquettes d'applications complètes. Atlas est opiniâtre ; penchez-vous dessus.
