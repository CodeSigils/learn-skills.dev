DÉCLENCHEMENT lorsque l'utilisateur : écrit ou révise les nœuds ROS 2 (rclcpp/rclpy), crée des packages (colcon/ament), modifie les fichiers de lancement (.launch.py), configure QoS ou DDS, écrit URDF/xacro, implémente les interfaces matérielles ou les contrôleurs ros2_control, configure les pipelines Nav2/MoveIt 2, traite les données des capteurs (caméra/LiDAR/PCL), fonctionne avec Gazebo/Isaac. Sim, configure la sécurité SROS2, développe un micrologiciel micro-ROS, gère des flottes multi-robots (Open-RMF), débogue avec ros2 doctor/rosbag2, déploie via Docker/compilation croisée ou migre depuis ROS 1. NE PAS DÉCLENCHER pour les questions générales C++/Python sans rapport avec ROS 2, les middlewares non robotiques ou les tâches de développement web/mobile.
