Implementa il modello di progettazione Pipeline in Python per la trasformazione dei dati. Da utilizzare quando l'utente menziona il modello di pipeline o quando è necessaria una sequenza fissa di fasi in cui ciascuna trasforma i dati e passa a quella successiva: ETL, analisi, elaborazione dati o qualsiasi flusso di trasformazione lineare che viene eseguito fino al completamento.
