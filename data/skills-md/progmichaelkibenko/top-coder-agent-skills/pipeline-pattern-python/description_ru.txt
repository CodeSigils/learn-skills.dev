Реализует шаблон проектирования Pipeline в Python для преобразования данных. Используйте, когда пользователь упоминает шаблон конвейера или когда вам нужна фиксированная последовательность этапов, каждый из которых преобразует данные и переходит к следующему — ETL, синтаксический анализ, обработка данных или любой поток линейного преобразования, который выполняется до завершения.
