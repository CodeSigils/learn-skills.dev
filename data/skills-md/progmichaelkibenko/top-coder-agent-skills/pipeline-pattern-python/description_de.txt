Implementiert das Pipeline-Entwurfsmuster in Python für die Datentransformation. Verwenden Sie diese Option, wenn der Benutzer ein Pipeline-Muster erwähnt oder wenn Sie eine feste Abfolge von Phasen benötigen, die jeweils Daten transformieren und an die nächste weitergeben – ETL, Parsing, Datenverarbeitung oder einen beliebigen linearen Transformationsfluss, der bis zum Abschluss ausgeführt wird.
