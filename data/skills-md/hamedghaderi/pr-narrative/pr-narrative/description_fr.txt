Compétence de relations publiques à deux modes. **Mode Auteur** écrit des descriptions de requêtes d'extraction qui se lisent comme une explication, pas comme un vidage de code. Utilisez-le lorsque l'utilisateur demande à rédiger, rédiger, générer ou améliorer une description de PR / un corps de PR / une rédaction de PR, ou dit « rédiger le PR », « faire une description de PR pour cette branche », « décrire ces modifications pour examen ». **Le mode Réviseur** affiche les différences de tout PR sous la forme d'une page annotable : cliquez pour commenter les lignes, les légendes de risque facultatives rédigées par l'IA que vous triez et publie les commentaires acceptés en tant qu'examen GitHub EN ATTENTE que l'utilisateur finalise. Utilisez-le lorsque l'utilisateur dit « réviser ce PR <url> », « réviser le PR #N », « annoter ce PR » ou « réviser ma branche/modifications ». Confirmez d'abord le mode avec une question, sauf si l'utilisateur l'a déjà nommé. Prend également en charge les sous-commandes : « explain » (explique une différence dans le chat), « review-security » (mode réviseur, résultats de l'IA uniquement sur la sécurité), « summarize-changes » (résumé rapide du chat) ; une sous-commande explicite ignore la question de mode. Ne PAS utiliser pour la notation de révision de code, les messages de validation ou les notes de version.
