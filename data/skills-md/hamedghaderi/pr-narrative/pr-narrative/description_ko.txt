2가지 모드 PR 스킬. **작성자 모드**는 코드 덤프가 아닌 설명처럼 읽는 풀 요청 설명을 작성합니다. 사용자가 PR 설명/PR 본문/PR 쓰기를 작성, 초안, 생성 또는 개선하도록 요청하거나 "PR 작성", "이 분기에 대한 PR 설명 작성", "검토를 위해 이러한 변경 사항 설명"이라고 말할 때 사용합니다. **리뷰어 모드**는 모든 PR의 차이점을 주석이 달린 페이지로 렌더링합니다. 라인에서 댓글을 달려면 클릭하고, 선택적으로 선별한 AI 초안 위험 설명선을 선택하고, 사용자가 완료한 PENDING GitHub 리뷰로 허용된 댓글을 게시합니다. 사용자가 "이 PR <url> 검토", "PR #N 검토", "이 PR에 주석 달기" 또는 "내 분기/변경 사항 검토"라고 말할 때 사용하세요. 사용자가 이미 이름을 지정하지 않은 한 먼저 하나의 질문으로 모드를 확인하세요. 또한 "explain"(채팅의 차이점 설명), "review-security"(검토자 모드, 보안 전용 AI 결과), "summarize-changes"(빠른 채팅 요약) 등 하위 명령도 지원합니다. 명시적 하위 명령은 모드 질문을 건너뜁니다. 코드 검토 채점, 커밋 메시지 또는 릴리스 노트에는 사용하지 마십시오.
