Двухрежимный PR-навык. В **Авторском режиме** создаются описания пул-реквестов, которые читаются как объяснительные, а не как дамп кода. Используйте его, когда пользователь просит написать, набросать, сгенерировать или улучшить описание PR / тело PR / описание PR или говорит «напишите PR», «составьте описание PR для этой отрасли», «опишите эти изменения для ознакомления». **Режим рецензента** отображает любые различия PR в виде аннотируемой страницы: щелкайте, чтобы комментировать строки, дополнительные выноски рисков, составленные с помощью ИИ, которые вы сортируете, и публикуйте принятые комментарии как ОЖИДАЮЩУЮСЯ проверку GitHub, которую завершает пользователь. Используйте его, когда пользователь говорит: «Просмотрите этот PR <url>», «Просмотрите PR #N», «Аннотируйте этот PR» или «Просмотрите мою ветку/изменения». Сначала подтвердите режим одним вопросом, если пользователь еще не назвал его. Также поддерживаются подкоманды: «объяснять» (объясняет разницу в чате), «обзор-безопасность» (режим рецензента, выводы ИИ только по безопасности), «подводить итоги» (быстрая сводка в чате); явная подкоманда пропускает вопрос о режиме. НЕ используйте для оценки проверки кода, сообщений о фиксации или примечаний к выпуску.
