Habilidad de relaciones públicas de dos modos. **Modo de autor** escribe descripciones de solicitudes de extracción que se leen como una explicación, no como un volcado de código. Úselo cuando el usuario solicite escribir, redactar, generar o mejorar una descripción de PR/cuerpo de PR/redacción de PR, o diga "escribir el PR", "hacer una descripción de PR para esta rama", "describir estos cambios para su revisión". **Modo revisor** presenta cualquier diferencia de PR como una página anotable: haga clic para comentar en las líneas, notas de riesgo opcionales redactadas por IA que usted clasifica y publica comentarios aceptados como una revisión PENDIENTE de GitHub que finaliza el usuario. Úselo cuando el usuario diga "revisar este PR <url>", "revisar PR #N", "anotar este PR" o "revisar mi rama/cambios". Primero confirme el modo con una pregunta, a menos que el usuario ya lo haya nombrado. También admite subcomandos: "explicar" (explica una diferencia en el chat), "review-security" (modo revisor, resultados de IA solo de seguridad), "summarize-changes" (resumen rápido del chat); un subcomando explícito omite la pregunta de modo. NO lo utilice para puntuación de revisión de código, mensajes de confirmación o notas de versión.
