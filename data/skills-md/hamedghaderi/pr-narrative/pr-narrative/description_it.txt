Abilità PR a due modalità. La **modalità autore** scrive descrizioni di richieste pull che si leggono come una spiegazione, non come un dump del codice. Usalo quando l'utente chiede di scrivere, abbozzare, generare o migliorare una descrizione PR / corpo PR / resoconto PR, o dice "scrivi il PR", "crea una descrizione PR per questo ramo", "descrivi queste modifiche per la revisione". La **modalità Revisore** rende qualsiasi differenza di PR come una pagina annotabile: clicca per commentare le righe, callout di rischio redatti dall'intelligenza artificiale opzionali da valutare e pubblica i commenti accettati come una revisione GitHub IN ATTESA che l'utente finalizza. Usalo quando l'utente dice "rivedi questo PR <url>", "rivedi PR #N", "annota questo PR" o "rivedi il mio ramo/modifiche". Conferma prima la modalità con una domanda, a meno che l'utente non l'abbia già nominata. Supporta anche i sottocomandi: "explain" (spiega una differenza nella chat), "review-security" (modalità revisore, risultati AI solo sicurezza), "summarize-changes" (riepilogo chat veloce); un sottocomando esplicito salta la domanda sulla modalità. NON utilizzare per il punteggio di revisione del codice, messaggi di commit o note di rilascio.
