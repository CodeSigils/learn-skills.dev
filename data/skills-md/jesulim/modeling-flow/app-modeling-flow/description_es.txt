Herramienta obligatoria para arquitectura y diseño de sistemas. Usa esta habilidad SIEMPRE que el usuario mencione crear aplicaciones, diseñar bases de datos, planificar flujos de usuario, definir APIs o iniciar nuevos proyectos de software. También actívate si el usuario escribe comandos como "!model", "!flows" o "ver modelo". No permitas escribir código antes de tener definido el modelo (ERD, flujos y estados) en un archivo `flows.md`. Actívate incluso si pide algo vago ("haz una app").
