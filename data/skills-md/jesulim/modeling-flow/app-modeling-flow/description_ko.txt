Herramienta obligatoria para arquitectura y diseño de sistemas. Usa esta 기술은 응용 프로그램 작성, 데이터 기반 계획, 사용 계획 수립, 소프트웨어 초기 프로젝트에 대한 API 정의를 작성하는 데 사용됩니다. 사용자는 "!model", "!flows" 또는 "ver modelo"라는 명령을 사용하여 활성화할 수 있습니다. 'flows.md' 보관소에 특정 모델(ERD, flujos y estados)을 정의하는 문서는 없습니다. incluso si pide algo vago("haz una app")를 활성화하세요.
