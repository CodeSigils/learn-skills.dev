Strumenti obbligatori per l'architettura e il design dei sistemi. Usa questa abilità SIEMPRE che l'utente menziona per creare applicazioni, progettare basi di dati, pianificare flussi di utilizzo, definire API o avviare nuovi progetti software. Attivare anche se l'utente scrive comandi come "!model", "!flows" o "ver modelo". Non è consentito scrivere il codice prima di avere definito il modello (ERD, flussi e stati) in un file `flows.md`. Attivalo anche se pide algo vago ("haz una app").
