Skill Engineering: Generieren und verwalten Sie schnell den gesamten Lebenszyklus von Agent Skills wie Codex, Claude Code usw. Verwenden Sie dies, wenn der Benutzer ausdrücklich „Skill-Engineering“ oder „Skill Engineering“ erwähnt oder sagt: „Helfen Sie mir, einen Skill zu erstellen/zu ändern“, „Erstellen Sie von Anfang an gemäß Software-Engineering-Standards“, „halten Sie die Architektur elegant, wenn KI sie ändert“, „dieser Skill wird umso chaotischer, je mehr er geändert wird“, „machen Sie ihn zu einem kommerziellen oder industriellen Skill“, „von der Remote-Installation bis zum Testen, Erstellung und Closed-Loop-Verifizierung“, „Gesundheitsprüfung, Auswertung, Installation oder Fortsetzung der vorherigen Aufgabe“. Leiten Sie Anfragen, die auf Projekt-Harnesses, Claude/Codex-Einstiegspunkte, tmux oder Start-up-Selbstprüfungen beschränkt sind, nicht an diesen Skill weiter. Ermitteln Sie automatisch, ob eine Fähigkeit erforderlich ist, wählen Sie die minimale Architektur aus, generieren Sie vollständige Kandidaten, überprüfen Sie Sicherheits- und Regressionsgrenzen und bewerben Sie sich nach der Bestätigung sicher.
