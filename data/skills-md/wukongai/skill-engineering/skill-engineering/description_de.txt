Skill Engineering: Erstellen Sie schnell den Lebenszyklus von Agent Skills wie Codex, Claude Code usw. und verwalten Sie ihn vollständig. Verwenden Sie es, wenn der Benutzer ausdrücklich „Skill Engineering“ oder „Skill Engineering“ erwähnt oder sagt: „Helfen Sie mir, einen Skill zu erstellen/zu ändern“, „Erstellen Sie von Anfang an gemäß Software-Engineering-Standards“, „halten Sie die Architektur elegant, wenn sich die KI ändert“, „dieser Skill wird mit jeder Änderung chaotischer“, „machen Sie ihn zu einem kommerziellen oder industriellen Skill“, „von der Remote-Installation über die Testerstellung bis zur Überprüfung des geschlossenen Regelkreises“, „Gesundheitsprüfung, Bewertung, Installation oder Fortsetzung der vorherigen Aufgabe“. Leiten Sie Anfragen, die auf Projekt-Harness, Claude/Codex-Einstiegspunkte, tmux oder Startup-Selbstprüfung beschränkt sind, nicht an diesen Skill weiter. Ermitteln Sie automatisch, ob eine Fertigkeit erforderlich ist, wählen Sie die minimale Architektur, generieren Sie vollständige Kandidaten, überprüfen Sie Sicherheits- und Regressionsgrenzen und bewerben Sie sich nach der Bestätigung sicher.
