Estrae informazioni sull'attività dai feed degli articoli di WeChat, consente al modello di giudicare se ciascun articolo è veramente un'attività leggendo la semantica dell'articolo, scrive file JSON grezzi/attività/strutturati, esegue il rendering di Markdown rivedibile più testo pronto per il push e invia aggiornamenti ai gruppi interni di WeCom tramite robot webhook. Utilizza questa competenza ogni volta che l'utente menziona feed 公众号, 活动提取, 活动报名信息, 企业微信群推送, webhook 推送, flussi di lavoro feed-to-activity o desidera una pipeline bash/curl ripetibile che legga feeds.md e emette raw.json/activity.json/activity-structured.json/activity-structured.md/activity-push.txt.
