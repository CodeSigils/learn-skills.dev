China Platform Deep Research Engine : couvre huit plates-formes principales : Weibo, Xiaohongshu, Bilibili, Zhihu, Douyin, les comptes officiels WeChat, Baidu Search et Toutiao. La version 2.0 intègre le moteur MediaCrawler, réduisant considérablement le recours aux clés API ; L'IA synthétise et analyse les données pour générer des rapports de recherche vérifiables.
