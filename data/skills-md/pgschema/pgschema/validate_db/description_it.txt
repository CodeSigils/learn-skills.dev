Connettiti al database PostgreSQL live per convalidare i presupposti dello schema, confrontare l'output di pg_dump con quello di pgschema ed eseguire query sui cataloghi di sistema in modo interattivo. Utilizza questa competenza ogni volta che devi testare query su un database reale, verificare come PostgreSQL archivia o formatta oggetti, eseguire il debug di problemi di introspezione o controllare il comportamento specifico della versione (PostgreSQL 14-18).
