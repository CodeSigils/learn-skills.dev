Conéctese a la base de datos PostgreSQL en vivo para validar los supuestos del esquema, comparar la salida de pg_dump con la de pgschema y consultar catálogos del sistema de forma interactiva. Utilice esta habilidad siempre que necesite probar consultas en una base de datos real, verificar cómo PostgreSQL almacena o formatea objetos, depurar problemas de introspección o verificar el comportamiento específico de la versión (PostgreSQL 14-18).
