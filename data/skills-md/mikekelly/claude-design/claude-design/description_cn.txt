驱动 claude-design CLI 实现确定性、无推理的 Claude Design 同步（拉/推/列表/创建）。当您需要将 Claude Design 项目镜像到本地目录或从本地目录镜像、解析项目 UUID 或在 CI 中编写可重复同步脚本时使用，而不需要将模型推理放入循环中。至关重要的是，它让同步的设计内容（及其“.etags”基线）存在于 git 中，用于版本控制、审核和单命令恢复——云服务缺乏更改跟踪功能，因此代理无法在没有跟踪、可恢复检查点的情况下覆盖参考设计。当工作可编写脚本、可重复、CI 驱动或必须跟踪和恢复设计更改时，首选通过 DesignSync MCP 工具或 claude -p 进行路由同步。
