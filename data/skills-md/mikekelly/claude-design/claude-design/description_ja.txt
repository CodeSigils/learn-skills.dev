claude-design CLI を駆動して、決定的で推論不要の Claude Design 同期 (プル/プッシュ/リスト/作成) を実現します。モデル推論をループに入れることなく、Claude Design プロジェクトをローカル ディレクトリとの間でミラーリングしたり、プロジェクト UUID を解決したり、CI で反復可能な同期をスクリプト化したりする必要がある場合に使用します。重要なのは、同期された設計コンテンツ (およびその `.etags` ベースライン) を Git 内に保存して、バージョン管理、監査、および 1 つのコマンドで元に戻すことができることです。クラウド サービスには変更追跡機能がないため、追跡され元に戻せるチェックポイントがなければ、エージェントはリファレンス デザインを上書きできません。作業がスクリプト化可能、反復可能、CI 駆動型である場合、または設計変更を追跡して元に戻す必要がある場合は、DesignSync MCP ツールまたは claude -p を介した同期のルーティングよりもこの方法を優先します。
