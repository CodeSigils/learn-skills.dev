驅動 claude-design CLI 實現確定性、無推理的 Claude Design 同步（拉/推/列表/創建）。當您需要將 Claude Design 專案鏡像到本機目錄或從本機目錄映像、解析專案 UUID 或在 CI 中編寫可重複同步腳本時使用，而不需要將模型推理放入循環中。至關重要的是，它讓同步的設計內容（及其「.etags」基線）存在於 git 中，用於版本控制、審核和單命令恢復——雲端服務缺乏更改追蹤功能，因此代理無法在沒有追蹤、可恢復檢查點的情況下覆蓋參考設計。當工作可編寫腳本、可重複、CI 驅動或必須追蹤和恢復設計變更時，首選透過 DesignSync MCP 工具或 claude -p 進行路由同步。
