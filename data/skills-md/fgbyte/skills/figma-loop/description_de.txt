Bringt Agenten bei, mithilfe eines autonomen Taktstock-Weitergabe-Schleifenmusters iterativ Websites aus Figma-Designs zu erstellen. Verwendet Figma MCP zum Extrahieren von Designdaten und Assets und Playwriter MCP zur visuellen Überprüfung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Figma-Designs in Code konvertieren, aus einer Figma-Datei erstellen, über Figma-Komponenten iterieren oder eine Figma-zu-Code-Pipeline implementieren möchte – auch wenn er nicht ausdrücklich „figma-loop“ sagt.
