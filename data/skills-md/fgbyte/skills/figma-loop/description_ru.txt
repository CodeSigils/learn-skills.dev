Обучает агентов итеративному созданию веб-сайтов на основе проектов Figma с использованием автономного шаблона цикла передачи эстафетной палочки. Использует Figma MCP для извлечения проектных данных и ресурсов, а Playwriter MCP — для визуальной проверки. Используйте этот навык всякий раз, когда пользователь хочет преобразовать проекты Figma в код, построить из файла Figma, перебрать компоненты Figma или реализовать конвейер преобразования Figma в код — даже если он явно не говорит «figma-loop».
