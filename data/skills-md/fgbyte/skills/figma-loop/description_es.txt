Enseña a los agentes a crear sitios web de forma iterativa a partir de diseños de Figma utilizando un patrón de bucle de paso de bastón autónomo. Utiliza Figma MCP para extraer datos y activos de diseño, y Playwriter MCP para verificación visual. Utilice esta habilidad siempre que el usuario quiera convertir diseños de Figma a código, compilar a partir de un archivo Figma, iterar sobre componentes de Figma o implementar una canalización de Figma a código, incluso si no dicen explícitamente "figma-loop".
