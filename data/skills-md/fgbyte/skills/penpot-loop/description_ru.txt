Обучает агентов итеративному созданию веб-сайтов на основе проектов Penpot с использованием автономного шаблона цикла передачи эстафеты. Использует официальный сервер @penpot/mcp (исполняемый код страницы, UUID, ресурсы base64) и Playwriter для визуальной проверки. Используйте этот навык всякий раз, когда пользователь хочет преобразовать проекты Penpot в код, построить из файла Penpot, перебрать компоненты Penpot или реализовать конвейер преобразования Penpot в код — даже если он явно не говорит «penpot-loop».
