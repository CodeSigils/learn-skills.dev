Teaches agents to iteratively build websites from Penpot designs using an autonomous baton-passing loop pattern. Uses the official @penpot/mcp server (focused-page execute_code, UUIDs, base64 assets) and Playwriter for visual verification. Use this skill whenever the user wants to convert Penpot designs to code, build from a Penpot file, iterate over Penpot components, or implement a Penpot-to-code pipeline — even if they don't explicitly say "penpot-loop".
