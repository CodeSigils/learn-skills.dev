Enseña a los agentes a crear sitios web de forma iterativa a partir de diseños de Penpot utilizando un patrón de bucle de paso de bastón autónomo. Utiliza el servidor oficial @penpot/mcp (código de ejecución de página enfocada, UUID, activos base64) y Playwriter para verificación visual. Utilice esta habilidad siempre que el usuario desee convertir diseños de Penpot a código, compilar a partir de un archivo Penpot, iterar sobre componentes de Penpot o implementar una canalización de Penpot a código, incluso si no dicen explícitamente "penpot-loop".
