Bringt Agenten bei, Websites anhand von Penpot-Entwürfen mithilfe eines autonomen Taktstock-Weitergabe-Schleifenmusters iterativ zu erstellen. Verwendet den offiziellen @penpot/mcp-Server (Focused-Page-Execute-Code, UUIDs, Base64-Assets) und Playwriter zur visuellen Überprüfung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Penpot-Designs in Code konvertieren, aus einer Penpot-Datei erstellen, über Penpot-Komponenten iterieren oder eine Penpot-zu-Code-Pipeline implementieren möchte – auch wenn er nicht ausdrücklich „Penpot-Schleife“ sagt.
