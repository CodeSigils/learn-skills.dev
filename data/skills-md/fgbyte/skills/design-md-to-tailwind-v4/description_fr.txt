Convertit un fichier DESIGN.md (Google Stitch / spécification open source) en un index.css / globals.css prêt pour la production pour Tailwind CSS v4. Couvre toute la surface du jeton : couleurs (clair + foncé), échelle de typographie, familles de polices, épaisseurs de police, espacement des lettres, hauteurs de ligne, échelle d'espacement, rayon de bordure, ombres, points d'arrêt, animations et jetons de composants. Utilisez cette compétence chaque fois que l'utilisateur mentionne DESIGN.md, Stitch, les jetons de conception, globals.css, index.css, le thème Tailwind v4, @theme, ou demande de « traduire », « convertir », « exporter » ou « générer du CSS à partir de » un fichier de conception. Déclenchez également lorsque l'utilisateur colle ou télécharge un DESIGN.md et demande une configuration Tailwind.
