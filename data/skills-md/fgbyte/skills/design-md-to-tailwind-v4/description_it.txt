Converte un file DESIGN.md (Google Stitch/specifiche open source) in un file index.css/globals.css pronto per la produzione per Tailwind CSS v4. Copre l'intera superficie del token: colori (chiaro + scuro), scala tipografica, famiglie di caratteri, pesi dei caratteri, spaziatura delle lettere, altezze delle linee, scala di spaziatura, raggio del bordo, ombre, punti di interruzione, animazioni e token dei componenti. Utilizza questa competenza ogni volta che l'utente menziona DESIGN.md, Stitch, token di progettazione, globals.css, index.css, tema Tailwind v4, @theme o chiede di "tradurre", "convertire", "esportare" o "generare CSS da" un file di progettazione. Si attiva anche quando l'utente incolla o carica DESIGN.md e richiede una configurazione Tailwind.
