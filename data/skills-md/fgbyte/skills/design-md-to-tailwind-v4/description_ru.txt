Преобразует файл DESIGN.md (Google Stitch/спецификация с открытым исходным кодом) в готовый к использованию файл index.css/globals.css для Tailwind CSS v4. Охватывает всю поверхность токена: цвета (светлый + темный), типографский масштаб, семейства шрифтов, толщину шрифтов, межбуквенный интервал, высоту строк, масштаб интервалов, радиус границы, тени, точки останова, анимацию и токены компонентов. Используйте этот навык всякий раз, когда пользователь упоминает DESIGN.md, Stitch, токены дизайна, globals.css, index.css, тему Tailwind v4, @theme или просит «перевести», «конвертировать», «экспортировать» или «сгенерировать CSS из» файла дизайна. Также срабатывает, когда пользователь вставляет или загружает DESIGN.md и запрашивает настройку Tailwind.
