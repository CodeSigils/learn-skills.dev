Konvertiert eine DESIGN.md-Datei (Google Stitch/Open-Source-Spezifikation) in eine produktionsbereite index.css/globals.css für Tailwind CSS v4. Deckt die gesamte Token-Oberfläche ab: Farben (hell + dunkel), Typografieskalierung, Schriftfamilien, Schriftstärken, Buchstabenabstände, Zeilenhöhen, Abstandsskala, Rahmenradius, Schatten, Haltepunkte, Animationen und Komponenten-Tokens. Verwenden Sie diesen Skill immer dann, wenn der Benutzer DESIGN.md, Stitch, Design-Tokens, globals.css, index.css, Tailwind v4 Theme, @theme erwähnt oder eine Designdatei „übersetzen“, „konvertieren“, „exportieren“ oder „CSS daraus generieren“ möchte. Wird auch ausgelöst, wenn der Benutzer eine DESIGN.md einfügt oder hochlädt und nach einem Tailwind-Setup fragt.
