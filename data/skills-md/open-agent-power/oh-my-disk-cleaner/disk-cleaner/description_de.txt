Plattformübergreifendes Toolkit zur Speicherplatzverwaltung mit intelligenter Optimierung. ANFORDERUNGEN: Python 3.7+. UNIVERSELLE KOMPATIBILITÄT: Funktioniert mit ALLEN AI-IDEs (Cursor, Windsurf, Continue, Aider, Claude Code usw.). PLATTFORMUNABHÄNGIG: Funktioniert an jedem Standort – global, auf Projekt- oder Benutzerebene. EIGENSTÄNDIG: Keine Pip-Installation erforderlich, inklusive intelligentem Bootstrap. HAUPTMERKMALE: (1) PROGRESSIVES SCANNEN: Schnelle Probenahme (1 s) + Progressiver Modus für große Festplatten, (2) INTELLIGENTER BOOTSTRAP: Automatische Erkennung des Skill-Standorts und automatischer Import von Modulen, (3) PLATTFORMÜBERGREIFENDE CODIERUNG: Sichere Emoji-/Unicode-Verarbeitung auf allen Plattformen, (4) DIAGNOSEWERKZEUGE: check_skill.py zur schnellen Überprüfung, (5) OPTIMIERTES SCANNEN: 3-5x schneller mit os.scandir(), gleichzeitigem Scannen und intelligentem Sampling. AGENTEN-WORKFLOW: (1) Python prüfen, (2) Skill-Paket finden (über 20 Standorte werden automatisch erkannt), (3) Diagnose durchführen, (4) Progressives Scannen für große Festplatten verwenden. Im Skill-Paket sind alle Optimierungsmodule enthalten – es gehen keine Features verloren!
