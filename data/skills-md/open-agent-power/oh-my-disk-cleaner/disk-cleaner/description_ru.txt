Кроссплатформенный набор инструментов для управления дисковым пространством с интеллектуальной оптимизацией. ТРЕБОВАНИЯ: Python 3.7+. УНИВЕРСАЛЬНАЯ СОВМЕСТИМОСТЬ: работает со ВСЕМИ AI IDE (Cursor, Windsurf, Continue, Aider, Claude Code и т. д.). НЕЗАВИСИМОСТЬ ОТ ПЛАТФОРМЫ: работает в любом месте — на глобальном уровне, на уровне проекта или на уровне пользователя. АВТОНОМНОСТЬ: установка pip не требуется, включает интеллектуальную загрузку. ОСНОВНЫЕ ХАРАКТЕРИСТИКИ: (1) ПРОГРЕССИВНОЕ СКАНИРОВАНИЕ: быстрая выборка (1 с) + прогрессивный режим для больших дисков, (2) ИНТЕЛЛЕКТУАЛЬНАЯ ЗАГРУЗКА: автоматическое определение местоположения навыков и автоматический импорт модулей, (3) МЕЖПЛАТФОРМЕННОЕ КОДИРОВАНИЕ: безопасная обработка эмодзи/Юникода на всех платформах, (4) ИНСТРУМЕНТЫ ДИАГНОСТИКИ: check_skill.py для быстрой проверки, (5) ОПТИМИЗИРОВАННОЕ СКАНИРОВАНИЕ: в 3–5 раз быстрее с помощью os.scandir(), одновременное сканирование, интеллектуальная выборка. РАБОЧИЙ ПРОЦЕСС АГЕНТА: (1) Проверьте Python, (2) Найдите пакет навыков (автоматически обнаружено более 20 местоположений), (3) Запустите диагностику, (4) Используйте прогрессивное сканирование для больших дисков. Пакет навыков включает в себя все модули оптимизации – ни один функционал не потерян!
