Boîte à outils de gestion de l'espace disque multiplateforme avec optimisation intelligente. EXIGENCES : Python 3.7+. COMPATIBILITÉ UNIVERSELLE : Fonctionne avec TOUS les IDE IA (Cursor, Windsurf, Continue, Aider, Claude Code, etc.). INDÉPENDANT DE LA PLATEFORME : fonctionne à n'importe quel endroit : au niveau mondial, au niveau du projet ou de l'utilisateur. AUTONOME : aucune installation de pip nécessaire, inclut un bootstrap intelligent. CARACTÉRISTIQUES PRINCIPALES : (1) ANALYSE PROGRESSIVE : échantillon rapide (1 s) + mode progressif pour les gros disques, (2) BOOTSTRAP INTELLIGENT : détection automatique de l'emplacement des compétences et importation automatique des modules, (3) ENCODAGE MULTIPLATEFORME : gestion sécurisée des emoji/Unicode sur toutes les plateformes, (4) OUTILS DE DIAGNOSTIC : check_skill.py pour une vérification rapide, (5) OPTIMISÉ NUMÉRISATION : 3 à 5 fois plus rapide avec os.scandir(), analyse simultanée, échantillonnage intelligent. FLUX DE TRAVAIL DE L'AGENT : (1) Vérifiez Python, (2) Recherchez un package de compétences (plus de 20 emplacements détectés automatiquement), (3) Exécutez des diagnostics, (4) Utilisez l'analyse progressive des disques volumineux. Le package de compétences comprend tous les modules d'optimisation - aucune fonctionnalité n'est perdue !
