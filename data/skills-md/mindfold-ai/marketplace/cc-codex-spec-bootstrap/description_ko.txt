Trellis 코딩 사양을 부트스트래핑하기 위한 Claude Code + Codex 병렬 파이프라인. CC는 GitNexus(지식 그래프) + ABCoder(AST)를 사용하여 리포지토리를 분석하고 전체 아키텍처 컨텍스트 및 MCP 도구 지침이 포함된 Trellis 작업 PRD를 생성한 다음 Codex 에이전트가 해당 작업을 병렬로 실행하여 사양 파일을 채웁니다. 사용 시기: 코딩 지침 부트스트래핑, Trellis 사양 설정, 'codex용 부트스트랩 사양', '사양 작업 생성', 'CC + Codex 사양 파이프라인', '코드 인텔리전스를 사용하여 코딩 지침 초기화'. 또한 사용자가 다중 에이전트 사양 생성을 위해 GitNexus 또는 ABCoder MCP를 설정하려고 할 때 트리거됩니다.
