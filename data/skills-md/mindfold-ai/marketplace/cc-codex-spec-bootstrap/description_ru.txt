Параллельный конвейер Claude Code + Codex для начальной загрузки спецификаций кодирования Trellis. CC анализирует репозиторий с помощью GitNexus (граф знаний) + ABCoder (AST), создает PRD задач Trellis с полным архитектурным контекстом и инструкциями инструмента MCP, затем агенты Codex параллельно запускают эти задачи для заполнения файлов спецификаций. Используйте, когда: рекомендации по начальной загрузке кода, настройка спецификаций Trellis, «спецификации начальной загрузки для кодекса», «создание задач спецификации», «конвейер спецификаций CC + Codex», «инициализация рекомендаций по кодированию с помощью аналитики кода». Также срабатывает, когда пользователь хочет настроить GitNexus или ABCoder MCP для создания многоагентных спецификаций.
