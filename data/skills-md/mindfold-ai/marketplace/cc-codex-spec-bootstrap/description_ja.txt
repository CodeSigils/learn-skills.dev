Trellis コーディング仕様をブートストラップするための Claude Code + Codex 並列パイプライン。 CC は GitNexus (ナレッジ グラフ) + ABCoder (AST) を使用してリポジトリを分析し、完​​全なアーキテクチャ コンテキストと MCP ツール命令を含む Trellis タスク PRD を作成します。その後、Codex エージェントがこれらのタスクを並行して実行してスペック ファイルを埋めます。次の場合に使用します: コーディング ガイドラインのブートストラップ、Trellis 仕様のセットアップ、「コーデックスの仕様のブートストラップ」、「仕様タスクの作成」、「CC + Codex 仕様パイプライン」、「コード インテリジェンスを使用したコーディング ガイドラインの初期化」。ユーザーがマルチエージェント仕様生成用に GitNexus または ABCoder MCP をセットアップする場合にもトリガーされます。
