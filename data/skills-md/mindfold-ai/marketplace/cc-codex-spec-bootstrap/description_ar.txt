Claude Code + Codex خط الأنابيب المتوازي لمواصفات ترميز الشبكة. يقوم CC بتحليل الريبو باستخدام GitNexus (الرسم البياني المعرفي) + ABCoder (AST)، ويقوم بإنشاء PRDs لمهام Trellis مع سياق معماري كامل وتعليمات أداة MCP، ثم يقوم وكلاء Codex بتشغيل هذه المهام بالتوازي لملء ملفات المواصفات. يُستخدم عندما: إرشادات التمهيد للترميز، وإعداد مواصفات الشبكة، و"مواصفات التمهيد للمخطوطة"، و"إنشاء مهام المواصفات"، و"خط أنابيب مواصفات CC + Codex"، و"تهيئة إرشادات الترميز باستخدام ذكاء التعليمات البرمجية". يتم تشغيله أيضًا عندما يريد المستخدم إعداد GitNexus أو ABCoder MCP لإنشاء مواصفات متعددة الوكلاء.
