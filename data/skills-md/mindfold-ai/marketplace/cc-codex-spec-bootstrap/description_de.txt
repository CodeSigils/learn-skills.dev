Claude Code + Codex-Parallelpipeline zum Bootstrapping von Trellis-Codierungsspezifikationen. CC analysiert das Repo mit GitNexus (Knowledge Graph) + ABCoder (AST), erstellt Trellis-Aufgaben-PRDs mit vollständigem Architekturkontext und MCP-Tool-Anweisungen, dann führen Codex-Agenten diese Aufgaben parallel aus, um Spezifikationsdateien zu füllen. Verwendung bei: Bootstrapping-Codierungsrichtlinien, Einrichten von Trellis-Spezifikationen, „Bootstrap-Spezifikationen für Codex“, „Spezifikationsaufgaben erstellen“, „CC + Codex-Spezifikationspipeline“, „Codierungsrichtlinien mit Code-Intelligenz initialisieren“. Wird auch ausgelöst, wenn der Benutzer GitNexus oder ABCoder MCP für die Generierung von Multi-Agent-Spezifikationen einrichten möchte.
