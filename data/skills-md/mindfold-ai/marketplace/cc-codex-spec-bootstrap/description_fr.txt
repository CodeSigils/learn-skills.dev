Pipeline parallèle Claude Code + Codex pour amorcer les spécifications de codage Trellis. CC analyse le référentiel avec GitNexus (knowledge graph) + ABCoder (AST), crée des PRD de tâches Trellis avec un contexte architectural complet et des instructions de l'outil MCP, puis les agents Codex exécutent ces tâches en parallèle pour remplir les fichiers de spécifications. À utiliser lorsque : l'amorçage des directives de codage, la configuration des spécifications Trellis, les "spécifications d'amorçage pour le codex", la "création de tâches de spécification", le "pipeline de spécifications CC + Codex", "l'initialisation des directives de codage avec l'intelligence du code". Se déclenche également lorsque l'utilisateur souhaite configurer GitNexus ou ABCoder MCP pour la génération de spécifications multi-agents.
