Pipeline parallela Claude Code + Codex per il bootstrap delle specifiche di codifica Trellis. CC analizza il repository con GitNexus (grafo della conoscenza) + ABCoder (AST), crea PRD di attività Trellis con contesto architetturale completo e istruzioni dello strumento MCP, quindi gli agenti Codex eseguono tali attività in parallelo per riempire i file delle specifiche. Da utilizzare quando: avviare le linee guida di codifica, impostare le specifiche di Trellis, "specifiche di bootstrap per il codice", "creare attività di specifica", "pipeline delle specifiche CC + Codex", "inizializzare le linee guida di codifica con intelligenza del codice". Si attiva anche quando l'utente desidera configurare GitNexus o ABCoder MCP per la generazione di specifiche multi-agente.
