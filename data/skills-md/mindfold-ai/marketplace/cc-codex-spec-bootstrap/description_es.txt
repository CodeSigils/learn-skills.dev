Tubería paralela Claude Code + Codex para iniciar las especificaciones de codificación Trellis. CC analiza el repositorio con GitNexus (gráfico de conocimiento) + ABCoder (AST), crea PRD de tareas Trellis con contexto arquitectónico completo e instrucciones de herramientas MCP, luego los agentes Codex ejecutan esas tareas en paralelo para completar archivos de especificaciones. Úselo cuando: iniciar pautas de codificación, configurar especificaciones Trellis, 'iniciar especificaciones para códice', 'crear tareas de especificaciones', 'canalización de especificaciones CC + Codex', 'inicializar pautas de codificación con inteligencia de código'. También se activa cuando el usuario desea configurar GitNexus o ABCoder MCP para la generación de especificaciones de múltiples agentes.
