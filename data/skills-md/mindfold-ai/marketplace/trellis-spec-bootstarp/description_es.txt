Bootstrap especificaciones de codificación Trellis específicas del proyecto con un flujo de trabajo de agente único neutral para la plataforma. Úselo al crear o actualizar pautas .trellis/spec, analizar una base de código con GitNexus, ABCoder o inspección de fuente, descomponer el trabajo de especificaciones de paquetes/capas y escribir documentos de especificaciones reales respaldados por una base de código sin texto de marcador de posición.
