Проверяет недавно написанный код на соответствие рекомендациям по разработке для конкретного проекта из .trellis/spec/. Идентифицирует измененные файлы с помощью git diff, обнаруживает применимые модули спецификации, запускает проверку и проверку типов и сообщает о нарушениях правил. Используйте, когда код написан и требует проверки качества, чтобы обнаружить дрейф контекста во время длительных сеансов или перед фиксацией изменений.
