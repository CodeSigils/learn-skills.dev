Valide le code récemment écrit par rapport aux directives de développement spécifiques au projet de .trellis/spec/. Identifie les fichiers modifiés via git diff, découvre les modules de spécifications applicables, exécute lint et typecheck et signale les violations des directives. À utiliser lorsque le code est écrit et nécessite une vérification de qualité, pour détecter la dérive du contexte lors de longues sessions ou avant de valider les modifications.
