Validiert kürzlich geschriebenen Code anhand projektspezifischer Entwicklungsrichtlinien aus .trellis/spec/. Identifiziert geänderte Dateien über Git Diff, erkennt anwendbare Spezifikationsmodule, führt Lint- und Typprüfungen durch und meldet Verstöße gegen Richtlinien. Verwenden Sie diese Option, wenn Code geschrieben wird und eine Qualitätsüberprüfung erfordert, um Kontextabweichungen während langer Sitzungen oder vor dem Festschreiben von Änderungen zu erkennen.
