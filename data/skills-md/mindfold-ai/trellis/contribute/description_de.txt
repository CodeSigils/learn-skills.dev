Leitfaden für Beiträge zur Trellis-Dokumentation und zum Trellis-Marktplatz. Behandelt das Hinzufügen von Spezifikationsvorlagen, Marktplatzkenntnissen, Dokumentationsseiten und das Einreichen von PRs sowohl im Haupt-Repo als auch im Dokumentations-Repo von Trellis. Verwenden Sie diese Option, wenn jemand eine neue Spezifikationsvorlage hinzufügen, dem Marktplatz eine neue Fähigkeit hinzufügen, Dokumentationsseiten hinzufügen oder aktualisieren oder eine PR für dieses Projekt einreichen möchte.
