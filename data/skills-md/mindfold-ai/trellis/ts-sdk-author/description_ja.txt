実稼働グレードの TypeScript SDK を、pnpm monorepo 内の npm パッケージとして設計、構築、検証、公開します。ワークスペースのレイアウト、パブリック API とモジュールの境界、プラグイン拡張ポイント、ブランド型とライブラリ調整された tsconfig、tsdown バンドル (対 tsup/tsc-only/unbuild)、デュアル ESM+CJS および同形条件 (ブラウザ/ワーカー/RN/deno) を使用した package.json エクスポート、Turborepo パイプライン、Publint および @arethetypeswrong/cli 検証、リリース前の変更セットをカバーします。モード、npm dist-tags (latest/next/beta/rc/canary)、およびアルファ→ベータ→rc→安定版リリースのライフサイクル。トリガー: TS SDK のビルド、コア ライブラリの抽出、package.json エクスポート、デュアル ESM CJS、tsdown config、tsup と tsdown、publint、attw、変更セットのプレリリース、npm dist-tag、ベータから rc、カナリア リリース、pnpm ワークスペース SDK、同型 SDK、tsconfig ライブラリ、npm 来歴、TypeScript ライブラリの配布。
