Concevez, créez, vérifiez et publiez des SDK TypeScript de qualité production en tant que packages npm dans un monorepo pnpm. Couvre la disposition de l'espace de travail, les limites publiques de l'API et des modules, les points d'extension du plugin, les types de marque et tsconfig optimisés pour la bibliothèque, le regroupement tsdown (vs tsup/tsc-only/unbuild), les exportations package.json avec double ESM+CJS et conditions isomorphes (navigateur/workers/RN/deno), les pipelines Turborepo, la vérification publint et @arethetypeswrong/cli, le mode pré-version des ensembles de modifications, npm les balises dist (dernière/next/beta/rc/canary) et le cycle de vie de la version alpha→beta→rc→stable. Déclencheurs sur : créer un SDK TS, extraire la bibliothèque principale, exportations package.json, double ESM CJS, configuration tsdown, tsup vs tsdown, publint, attw, versions préliminaires des changesets, balise dist npm, version bêta vers rc, version canary, SDK d'espace de travail pnpm, SDK isomorphe, bibliothèque tsconfig, provenance npm, expédition d'une bibliothèque TypeScript.
