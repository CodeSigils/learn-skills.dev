Проектируйте, собирайте, проверяйте и публикуйте SDK TypeScript промышленного уровня в виде пакетов npm внутри монорепозитория pnpm. Охватывает макет рабочей области, общедоступный API и границы модулей, точки расширения плагинов, фирменные типы и настроенный библиотекой tsconfig, объединение tsdown (по сравнению с tsup/tsc-only/unbuild), экспорт package.json с двойным ESM+CJS и изоморфными условиями (браузер/рабочие/RN/deno), конвейеры Turborepo, проверку publint и @arethetypeswrong/cli, режим предварительного выпуска наборов изменений, npm dist-tags (latest/next/beta/rc/canary) и жизненный цикл альфа→бета→rc→стабильный выпуск. Запускается при: сборке TS SDK, извлечении базовой библиотеки, экспорте package.json, двойном ESM CJS, конфигурации tsdown, tsup vs tsdown, publint, attw, предварительной версии наборов изменений, npm dist-tag, бета-версии в rc, канареечном выпуске, SDK рабочего пространства pnpm, изоморфном SDK, библиотеке tsconfig, происхождении npm, доставке библиотеки TypeScript.
