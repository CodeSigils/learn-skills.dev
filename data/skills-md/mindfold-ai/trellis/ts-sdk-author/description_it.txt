Progetta, crea, verifica e pubblica SDK TypeScript di livello produttivo come pacchetti npm all'interno di un monorepo pnpm. Copre layout dell'area di lavoro, API pubbliche e limiti dei moduli, punti di estensione dei plugin, tipi con marchio e tsconfig ottimizzato per la libreria, raggruppamento di tsdown (rispetto a tsup/tsc-only/unbuild), esportazioni di package.json con doppio ESM+CJS e condizioni isomorfiche (browser/workers/RN/deno), pipeline Turborepo, verifica publint e @arethetypeswrong/cli, modalità di pre-rilascio dei changeset, npm dist-tag (latest/next/beta/rc/canary) e il ciclo di vita della versione alpha→beta→rc→stable. Si attiva su: creazione di un SDK di TS, estrazione della libreria core, esportazioni di package.json, doppio ESM CJS, configurazione di tsdown, tsup vs tsdown, publint, attw, prerelease di changeset, npm dist-tag, beta in rc, versione canary, pnpm workspace SDK, isomorphic SDK, libreria tsconfig, provenienza npm, spedizione di una libreria TypeScript.
