أنماط تصميم Python للبرامج النصية والأدوات المساعدة لـ CLI - تطوير النوع الأول، والوحدات النمطية العميقة، وإدارة التعقيد، والأعلام الحمراء. يُستخدم عند قراءة ملفات Python أو كتابتها أو مراجعتها أو إعادة هيكلتها، خاصة في .trellis/scripts/ أو أي سياق سطر أوامر/برمجة نصية. قم بالتنشيط أيضًا عند التخطيط لبنية الوحدة، أو تحديد مكان وضع التعليمات البرمجية الجديدة، أو إجراء مراجعة التعليمات البرمجية.
