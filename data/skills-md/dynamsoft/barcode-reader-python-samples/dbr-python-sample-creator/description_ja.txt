Dynamsoft Barcode Reader SDK (`dynamsoft_barcode_reader_bundle` パッケージ) を使用して Python サンプル コードを実装する場合に使用します。このスキルは、1D バーコード、QR コード、PDF417、DataMatrix、DPM バーコード、および DBR Python Edition で構築されたその他のバーコード デコード シナリオを含む、すべてのバーコード読み取りユース ケースをカバーします。ユーザーがバーコード読み取り、Dynamsoft によるバーコード スキャン、バーコード デコードのために Dynamsoft Barcode Reader、DBR、`dynamsoft_barcode_reader_bundle`、`CaptureVisionRouter` について言及する場合、または画像を処理してバーコードを抽出する Python サンプルを作成したい場合には、このスキルを使用します。
