Используйте при реализации примера кода Python с помощью Dynamsoft Barcode Reader SDK (пакет dynamsoft_barcode_reader_bundle). Этот навык охватывает все варианты использования чтения штрих-кодов, включая 1D-штрих-коды, QR-коды, PDF417, DataMatrix, штрих-коды DPM и любые другие сценарии декодирования штрих-кодов, созданные на основе DBR Python Edition. Используйте этот навык всякий раз, когда пользователь упоминает Dynamsoft Barcode Reader, DBR, `dynamsoft_barcode_reader_bundle`, `CaptureVisionRouter` для чтения штрих-кода, сканирования штрих-кода с помощью Dynamsoft, декодирования штрих-кода или хочет создать образец Python, который обрабатывает изображения для извлечения штрих-кодов.
