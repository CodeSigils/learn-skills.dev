À utiliser lors de l'implémentation d'un exemple de code Python à l'aide du SDK Dynamsoft Barcode Reader (package `dynamsoft_barcode_reader_bundle`). Cette compétence couvre tous les cas d'utilisation de la lecture de codes-barres, y compris les codes-barres 1D, les codes QR, PDF417, DataMatrix, les codes-barres DPM et tout autre scénario de décodage de codes-barres basé sur DBR Python Edition. Utilisez cette compétence chaque fois que l'utilisateur mentionne Dynamsoft Barcode Reader, DBR, `dynamsoft_barcode_reader_bundle`, `CaptureVisionRouter` pour la lecture de codes-barres, la numérisation de codes-barres avec Dynamsoft, le décodage de codes-barres ou souhaite créer un échantillon Python qui traite des images pour extraire des codes-barres.
