Úselo al implementar código de muestra de Python utilizando el SDK de Dynamsoft Barcode Reader (paquete `dynamsoft_barcode_reader_bundle`). Esta habilidad cubre todos los casos de uso de lectura de códigos de barras, incluidos códigos de barras 1D, códigos QR, PDF417, DataMatrix, códigos de barras DPM y cualquier otro escenario de decodificación de códigos de barras creado en DBR Python Edition. Utilice esta habilidad siempre que el usuario mencione Dynamsoft Barcode Reader, DBR, `dynamsoft_barcode_reader_bundle`, `CaptureVisionRouter` para lectura de códigos de barras, escaneo de códigos de barras con Dynamsoft, decodificación de códigos de barras o quiera crear una muestra de Python que procese imágenes para extraer códigos de barras.
