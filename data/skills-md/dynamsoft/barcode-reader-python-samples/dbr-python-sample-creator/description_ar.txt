يُستخدم عند تنفيذ نموذج التعليمات البرمجية لـ Python باستخدام Dynamsoft Barcode Reader SDK (حزمة `dynamsoft_barcode_reader_bundle`). تغطي هذه المهارة جميع حالات استخدام قراءة الباركود بما في ذلك الرموز الشريطية أحادية الأبعاد، ورموز QR، وPDF417، وDataMatrix، والرموز الشريطية DPM، وأي سيناريو آخر لفك تشفير الباركود مبني على إصدار DBR Python. استخدم هذه المهارة عندما يذكر المستخدم Dynamsoft Barcode Reader، أو DBR، أو `dynamsoft_barcode_reader_bundle`، أو `CaptureVisionRouter` لقراءة الرمز الشريطي، أو مسح الرمز الشريطي باستخدام Dynamsoft، أو فك تشفير الرمز الشريطي، أو يريد إنشاء نموذج Python الذي يعالج الصور لاستخراج الرموز الشريطية.
