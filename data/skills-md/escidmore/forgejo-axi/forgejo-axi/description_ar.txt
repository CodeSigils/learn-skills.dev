تشغيل Forgejo عبر واجهة سطر الأوامر forgejo-axi – طلبات السحب، القضايا وتاريخ المحتوى، تشغيلات Actions، العلامات، هوية المستودع، حالة المضيف، واستدعاءات API الخام v1. استخدمها كلما كانت المهمة تتعامل مع مضيف Forgejo: العثور على طلبات السحب أو مراجعتها، فحص تاريخ التعديل، الدمج مع رأس متوقع، إنشاء أو تحديث القضايا، فحص تشغيلات Actions، أو إدارة علامات المستودع.
