Utilice Shanxi Securities Tushare (sxsc_tushare) para obtener datos históricos estructurados profesionales del mercado financiero. Características: los datos son T‑1 día (sin cotizaciones en tiempo real) y el formato de datos es adecuado para el procesamiento y la exportación por lotes. Condiciones de activación: el usuario menciona tushare, sxsc_tushare, Shanxi Securities tushare, extracción por lotes de cotizaciones históricas, exportación por lotes de estados financieros, preparación de datos de backtesting, exportación de datos CSV/Parquet, datos macro históricos (CPI/PPI/PMI/financiamiento social/tasas de interés), acciones constituyentes del índice, clasificación industrial Shenwan/CITIC, comparación horizontal de múltiples instrumentos, datos de bonos convertibles, datos de futuros, datos de bonos, flujos de capital históricos, históricos Líneas K, estadísticas de límite alcista/límite descendente, dividendos y acciones de bonificación, desbloqueo de acciones restringidas, historial de valor neto del fondo, datos de acciones de Hong Kong, rendimientos de bonos gubernamentales, tasas Shibor, información de suspensión/reanudación, las diez principales acciones negociadas en Shanghai‑Shenzhen Stock Connect, o frases como “extraer datos”, “exportar CSV”, “obtener lotes”, “comparar varias empresas”, etc. Escenarios aplicables: adquisición por lotes de datos históricos, análisis financiero, preparación de tablas de datos de backtesting, generación de informes de investigación.
