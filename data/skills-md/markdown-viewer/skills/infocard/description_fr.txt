Créez des cartes d'information de style éditorial en utilisant HTML/CSS intégré directement dans Markdown. Idéal pour les résumés de connaissances, les faits saillants des données, les aperçus de sujets, les annonces d'événements et les cartes de contenu avec une typographie et une mise en page de qualité magazine. PAS pour les diagrammes d'architecture (utilisez l'architecture), les organigrammes (utilisez sirène) ou la visualisation de données (utilisez Vega).
