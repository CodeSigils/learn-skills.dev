قم بإنشاء رسوم تخطيطية لهندسة الأمان باستخدام بناء جملة PlantUML مع أيقونات استنسل الهوية والتشفير وجدار الحماية والتوافق. الأفضل لتدفقات IAM، وبنيات الثقة المعدومة، وخطوط التشفير، وتدقيق الامتثال، واكتشاف التهديدات. ليس للأشعة تحت الحمراء السحابية العامة (استخدم المهارات السحابية) أو المخططات الانسيابية البسيطة (استخدم حورية البحر).
