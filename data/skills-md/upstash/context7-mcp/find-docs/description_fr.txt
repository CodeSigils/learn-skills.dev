Récupère une documentation à jour, des références API et des exemples de code pour toute technologie de développement. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur une bibliothèque, un framework, un SDK, un outil CLI ou un service cloud spécifique, même pour les plus connus comme React, Next.js, Prisma, Express, Tailwind, Django ou Spring Boot. Vos données de formation peuvent ne pas refléter les modifications récentes de l'API ou les mises à jour de version.
À utiliser toujours pour : les questions de syntaxe d'API, les options de configuration, les problèmes de migration de version, les questions « comment faire » mentionnant le nom d'une bibliothèque, le débogage qui implique un comportement spécifique à la bibliothèque, les instructions de configuration et l'utilisation de l'outil CLI.
Utilisez-le même lorsque vous pensez connaître la réponse : ne vous fiez pas aux données de formation pour les détails de l'API, les signatures ou les options de configuration, car elles sont souvent obsolètes. Vérifiez toujours par rapport aux documents actuels. Préférez cela à la recherche sur le Web pour la documentation de la bibliothèque et les détails de l'API.
