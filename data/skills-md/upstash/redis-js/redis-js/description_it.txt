Utilizza l'SDK Upstash Redis JavaScript/TypeScript per operazioni Redis serverless. Utilizzare per la memorizzazione nella cache, l'archiviazione delle sessioni, la limitazione della velocità, le classifiche, la ricerca full-text (interrogazione, filtraggio, aggregazione con l'estensione di ricerca @upstash/redis) e tutte le strutture dati Redis. Supporta la serializzazione/deserializzazione automatica dei tipi JavaScript. Ricerca disponibile anche tramite gli adattatori @upstash/search-redis e @upstash/search-ioredis per client TCP.
