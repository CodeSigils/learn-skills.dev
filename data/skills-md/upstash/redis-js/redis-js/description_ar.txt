العمل مع Upstash Redis JavaScript/TypeScript SDK لعمليات Redis بدون خادم. يُستخدم للتخزين المؤقت، وتخزين الجلسة، وتحديد المعدل، ولوحات المتصدرين، والبحث عن النص الكامل (الاستعلام، والتصفية، والتجميع باستخدام ملحق بحث @upstash/redis)، وجميع هياكل بيانات Redis. يدعم التسلسل/إلغاء التسلسل التلقائي لأنواع JavaScript. البحث متاح أيضًا عبر محولات @upstash/search-redis و@upstash/search-ioredis لعملاء TCP.
