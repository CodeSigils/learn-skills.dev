Trabaje con el SDK de JavaScript/TypeScript de Upstash Redis para operaciones de Redis sin servidor. Úselo para almacenamiento en caché, almacenamiento de sesiones, limitación de velocidad, tablas de clasificación, búsqueda de texto completo (consulta, filtrado, agregación con la extensión de búsqueda @upstash/redis) y todas las estructuras de datos de Redis. Admite la serialización/deserialización automática de tipos de JavaScript. La búsqueda también está disponible a través de los adaptadores @upstash/search-redis y @upstash/search-ioredis para clientes TCP.
