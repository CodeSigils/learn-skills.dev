Используйте Upstash Redis JavaScript/TypeScript SDK для бессерверных операций Redis. Используйте для кэширования, хранения сеансов, ограничения скорости, списков лидеров, полнотекстового поиска (запрос, фильтрация, агрегирование с расширением поиска @upstash/redis) и всех структур данных Redis. Поддерживает автоматическую сериализацию/десериализацию типов JavaScript. Поиск также доступен через адаптеры @upstash/search-redis и @upstash/search-ioredis для TCP-клиентов.
