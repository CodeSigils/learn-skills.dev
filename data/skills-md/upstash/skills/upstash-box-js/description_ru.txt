Работайте с @upstash/box TypeScript/JavaScript SDK для изолированных облачных контейнеров с агентами искусственного интеллекта, оболочкой, файловой системой и git. Используйте при сборке с помощью Upstash Box, создании изолированных сред, запуске ИИ-агентов в контейнерах или оркестрации параллельных блоков.
