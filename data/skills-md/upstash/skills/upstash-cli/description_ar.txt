قم بتشغيل Upstash CLI (`upstash`) مقابل Upstash Developer API لـ Redis وVector وSearch وQStash والفرق. يُستخدم عند إدراج أو إدارة قواعد البيانات، أو النسخ الاحتياطية، أو فهارس المتجهات/البحث، أو مثيلات QStash، أو أعضاء الفريق، أو الإحصائيات، أو أي أتمتة Upstash غير تفاعلية مع مخرجات JSON والأوامر الطرفية.
