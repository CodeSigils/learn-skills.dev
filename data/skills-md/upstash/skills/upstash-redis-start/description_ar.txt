قم بتوفير قاعدة بيانات Upstash Redis بدون تكوين وبدون اشتراك لوكيل الذكاء الاصطناعي عبر POST واحد إلى `https://upstash.com/start-redis`. يُستخدم عندما يحتاج الوكيل إلى مسح Redis للذاكرة قصيرة المدى أو سجل المحادثات أو قوائم انتظار عمل الوكيل الفرعي أو الاستدعاء المُصنف ولم يقدم المستخدم بيانات الاعتماد. تعيش قاعدة البيانات لمدة 3 أيام ما لم يطالب بها المستخدم.
