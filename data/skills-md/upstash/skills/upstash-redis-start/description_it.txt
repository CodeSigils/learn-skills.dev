Fornisci un database Upstash Redis senza configurazione e senza registrazione per un agente AI tramite un singolo POST su "https://upstash.com/start-redis". Da utilizzare quando un agente ha bisogno di Redis zero per la memoria a breve termine, la cronologia delle conversazioni, le code di lavoro degli agenti secondari o il richiamo classificato e l'utente non ha fornito le credenziali. Il database dura 3 giorni a meno che l'utente non lo reclami.
