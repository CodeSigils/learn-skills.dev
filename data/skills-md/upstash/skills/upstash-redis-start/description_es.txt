Proporcione una base de datos Upstash Redis sin configuración ni registro para un agente de IA mediante una única POST en `https://upstash.com/start-redis`. Úselo cuando un agente necesita Redis temporal para memoria a corto plazo, historial de conversaciones, colas de trabajo de subagente o recuperación clasificada y el usuario no ha proporcionado credenciales. La base de datos vive 3 días a menos que el usuario la reclame.
