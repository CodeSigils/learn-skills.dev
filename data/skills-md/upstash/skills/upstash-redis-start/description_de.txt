Stellen Sie eine Upstash Redis-Datenbank ohne Konfiguration und ohne Anmeldung für einen KI-Agenten über einen einzigen POST an „https://upstash.com/start-redis“ bereit. Verwenden Sie diese Option, wenn ein Agent Scratch Redis für das Kurzzeitgedächtnis, den Konversationsverlauf, die Arbeitswarteschlangen von Subagenten oder den Ranglistenrückruf benötigt und der Benutzer keine Anmeldeinformationen angegeben hat. Die Datenbank bleibt 3 Tage bestehen, es sei denn, der Benutzer beansprucht sie.
