Provisionnez une base de données Upstash Redis sans configuration et sans inscription pour un agent IA via un seul POST sur « https://upstash.com/start-redis ». À utiliser lorsqu'un agent a besoin de Scratch Redis pour la mémoire à court terme, l'historique des conversations, les files d'attente de travail des sous-agents ou le rappel classé et que l'utilisateur n'a pas fourni d'informations d'identification. La base de données dure 3 jours à moins que l'utilisateur ne la réclame.
