Предоставьте базу данных Upstash Redis без настройки и регистрации для агента ИИ с помощью одного POST-запроса на https://upstash.com/start-redis. Используйте, когда агенту требуется чистый Redis для кратковременной памяти, истории разговоров, рабочих очередей субагента или ранжированного отзыва, а пользователь не предоставил учетные данные. База данных живет 3 дня, если пользователь не затребует ее.
