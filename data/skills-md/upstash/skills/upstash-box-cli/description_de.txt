Steuern Sie eine Upstash-Box (einen Remote-Sandbox-Arbeitsbereich) vom Terminal aus mit der „Box“-CLI. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Befehle auszuführen, Dateien zu bearbeiten, Repositorys zu klonen, Builds oder Tests auszuführen, eine öffentliche URL zu veröffentlichen oder andere Arbeiten in einer Box statt auf diesem Computer auszuführen.
