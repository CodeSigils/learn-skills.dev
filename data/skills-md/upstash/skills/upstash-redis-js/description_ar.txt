العمل مع Upstash Redis TypeScript/JavaScript SDK لعمليات Redis بدون خادم. يُستخدم للتخزين المؤقت، وتخزين الجلسة، وتحديد المعدل، ولوحات المتصدرين، والبحث عن النص الكامل (الاستعلام، والتصفية، والتجميع) باستخدام Upstash Redis Search (يختلف عن FT.SEARCH العادي)، وجميع هياكل بيانات Redis. يدعم التسلسل/إلغاء التسلسل التلقائي لأنواع JavaScript. يتوفر أيضًا Upstash Redis Search عبر محولات @upstash/search-redis و@upstash/search-ioredis لعملاء TCP.
