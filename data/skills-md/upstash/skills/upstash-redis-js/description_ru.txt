Работайте с Upstash Redis TypeScript/JavaScript SDK для бессерверных операций Redis. Используйте для кэширования, хранения сеансов, ограничения скорости, списков лидеров, полнотекстового поиска (запросов, фильтрации, агрегирования) с помощью Upstash Redis Search (отличается от обычного FT.SEARCH) и всех структур данных Redis. Поддерживает автоматическую сериализацию/десериализацию типов JavaScript. Upstash Redis Search также доступен через адаптеры @upstash/search-redis и @upstash/search-ioredis для TCP-клиентов.
