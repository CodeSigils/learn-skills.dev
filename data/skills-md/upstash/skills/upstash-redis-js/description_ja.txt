サーバーレス Redis 操作には、Upstash Redis TypeScript/JavaScript SDK を使用します。キャッシュ、セッション ストレージ、レート制限、リーダーボード、Upstash Redis Search (通常の FT.SEARCH とは異なります) による全文検索 (クエリ、フィルタリング、集計)、およびすべての Redis データ構造に使用します。 JavaScript タイプの自動シリアル化/逆シリアル化をサポートします。 Upstash Redis Search は、TCP クライアント用の @upstash/search-redis アダプターおよび @upstash/search-ioredis アダプター経由でも利用できます。
