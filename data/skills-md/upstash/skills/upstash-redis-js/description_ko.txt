서버리스 Redis 작업을 위해 Upstash Redis TypeScript/JavaScript SDK를 사용하세요. Upstash Redis Search(일반 FT.SEARCH와 다름)를 통한 캐싱, 세션 저장, 속도 제한, 리더보드, 전체 텍스트 검색(쿼리, 필터링, 집계) 및 모든 Redis 데이터 구조에 사용됩니다. JavaScript 유형의 자동 직렬화/역직렬화를 지원합니다. Upstash Redis Search는 TCP 클라이언트용 @upstash/search-redis 및 @upstash/search-ioredis 어댑터를 통해서도 사용할 수 있습니다.
