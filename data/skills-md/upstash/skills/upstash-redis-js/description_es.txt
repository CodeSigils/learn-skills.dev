Trabaje con el SDK Upstash Redis TypeScript/JavaScript para operaciones de Redis sin servidor. Úselo para almacenamiento en caché, almacenamiento de sesiones, limitación de velocidad, tablas de clasificación, búsqueda de texto completo (consulta, filtrado, agregación) con Upstash Redis Search (diferente de FT.SEARCH normal) y todas las estructuras de datos de Redis. Admite la serialización/deserialización automática de tipos de JavaScript. Upstash Redis Search también está disponible a través de adaptadores @upstash/search-redis y @upstash/search-ioredis para clientes TCP.
