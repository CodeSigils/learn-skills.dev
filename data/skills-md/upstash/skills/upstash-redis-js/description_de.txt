Arbeiten Sie mit dem Upstash Redis TypeScript/JavaScript SDK für serverlose Redis-Vorgänge. Verwendung für Caching, Sitzungsspeicherung, Ratenbegrenzung, Bestenlisten, Volltextsuche (Abfragen, Filtern, Aggregieren) mit Upstash Redis Search (anders als reguläre FT.SEARCH) und alle Redis-Datenstrukturen. Unterstützt die automatische Serialisierung/Deserialisierung von JavaScript-Typen. Upstash Redis Search ist auch über die Adapter @upstash/search-redis und @upstash/search-ioredis für TCP-Clients verfügbar.
