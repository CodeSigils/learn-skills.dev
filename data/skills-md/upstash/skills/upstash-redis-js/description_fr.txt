Travaillez avec le SDK Upstash Redis TypeScript/JavaScript pour les opérations Redis sans serveur. À utiliser pour la mise en cache, le stockage de session, la limitation de débit, les classements, la recherche en texte intégral (requête, filtrage, agrégation) avec Upstash Redis Search (différent de FT.SEARCH classique) et toutes les structures de données Redis. Prend en charge la sérialisation/désérialisation automatique des types JavaScript. Upstash Redis Search est également disponible via les adaptateurs @upstash/search-redis et @upstash/search-ioredis pour les clients TCP.
