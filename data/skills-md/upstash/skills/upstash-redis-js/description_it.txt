Utilizza l'SDK Upstash Redis TypeScript/JavaScript per operazioni Redis serverless. Utilizzare per la memorizzazione nella cache, l'archiviazione delle sessioni, la limitazione della velocità, le classifiche, la ricerca full-text (query, filtraggio, aggregazione) con Upstash Redis Search (diverso dal normale FT.SEARCH) e tutte le strutture dati Redis. Supporta la serializzazione/deserializzazione automatica dei tipi JavaScript. Upstash Redis Search è disponibile anche tramite gli adattatori @upstash/search-redis e @upstash/search-ioredis per client TCP.
