Сократовская отладка с двумя явными режимами: режим отладки (опрос первопричин) и режим трассировки (свидетельства только для чтения для определений/ссылки/вызывающие абоненты/тесты/импорты). Используйте, когда: «отладить это», «почему X не работает», «отследить этот сбой», «где это используется», «сопоставить вызывающие абоненты».
