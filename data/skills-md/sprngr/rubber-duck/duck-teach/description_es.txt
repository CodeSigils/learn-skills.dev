Genere tutoriales y ejemplos de código utilizando un formato estandarizado (Qué -> Por qué -> Ejemplo -> Errores -> Ver también). Escalas de profundidad con solicitud: "muéstrame" = fragmento, "enseñame" = completo, "guíame" = paso a paso. Busque primero la base de código; Prefiero el uso real del proyecto. Úselo cuando: "enséñeme X", "muéstreme X", "cómo funciona X".
