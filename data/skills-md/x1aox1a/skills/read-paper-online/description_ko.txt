HuggingFace Papers API 및 arxiv2md를 사용하여 온라인으로 학술 논문을 검색하고 찾아보고 읽으세요.
트리거 시기: 사용자가 온라인으로 논문 검색을 요청하고, 최근 논문을 찾고, 주제에 대한 논문을 검색하고,
arXiv/HuggingFace에서 논문을 검색하고, 연구 분야의 새로운 소식을 확인하고, HuggingFace 일간지를 검색하고,
특정 논문(저자, 초록, 키워드, github)에 대한 자세한 정보 얻기, 논문 전문 읽기
온라인으로 arXiv ID를 사용하거나 마크다운으로 논문을 다운로드하세요.
다음의 경우에는 트리거하지 마십시오: 사용자가 로컬 문서 폴더 또는 이미 로컬로 다운로드한 문서를 읽으려는 경우
(read-paper-local 스킬 사용), Zotero로 논문 가져오기(zotero-connector 스킬 사용),
또는 로컬 PDF를 변환합니다(pdf-to-markdown 기술 사용).
