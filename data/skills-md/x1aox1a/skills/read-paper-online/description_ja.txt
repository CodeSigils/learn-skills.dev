HuggingFace Papers API と arxiv2md を使用して、オンラインで学術論文を検索、閲覧、および読み取ります。
トリガーのタイミング: ユーザーがオンラインでの論文の検索、最近の論文の検索、特定のトピックに関する論文の検索を要求した場合、
arXiv/HuggingFace で論文を検索し、研究分野の最新情報を確認し、HuggingFace の日刊紙を閲覧し、
特定の論文に関する詳細情報 (著者、要約、キーワード、github) を取得し、論文の全文を読む
オンラインの arXiv ID で、またはマークダウンとして論文をダウンロードします。
次の場合はトリガーしないでください: ユーザーがローカルの用紙フォルダー、または既にローカルにダウンロードされた用紙を読みたい場合
(read-paper-local スキルを使用)、論文を Zotero にインポート (zotero-connector スキルを使用)、
またはローカル PDF を変換します (pdf-to-markdown スキルを使用します)。
