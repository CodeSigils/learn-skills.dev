Cree imágenes WebGL pequeñas y siempre activas (avatares de identidad, orbes ambientales, superficies de vidrio y iridiscentes, texturas animadas) que se envíen dentro de la interfaz de usuario de una aplicación web normal sin afectar el rendimiento, la accesibilidad, el SSR o el diseño. Úselo siempre que se agregue un elemento decorativo basado en sombreador, GLSL o lienzo a la interfaz de usuario de un producto, especialmente uno representado muchas veces por página o por lista; al revisar u optimizar uno; o al depurar uno que se muestra borroso, con alias, completamente negro o pinta sobre la interfaz de usuario circundante en máquinas sin aceleración de hardware.
