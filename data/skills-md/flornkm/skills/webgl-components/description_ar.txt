أنشئ مرئيات WebGL صغيرة تعمل دائمًا (الصور الرمزية للهوية، والأجرام السماوية المحيطة، والأسطح الزجاجية والقزحية، والأنسجة المتحركة) التي يتم شحنها داخل واجهة مستخدم تطبيق ويب عادية دون الإضرار بالأداء أو إمكانية الوصول أو SSR أو التخطيط. يُستخدم عند إضافة عنصر زخرفي يعتمد على التظليل أو GLSL أو لوحة قماشية إلى واجهة مستخدم المنتج، خاصة تلك التي يتم عرضها عدة مرات لكل صفحة أو لكل قائمة؛ عند مراجعة واحدة أو تحسينها؛ أو عند تصحيح الأخطاء التي تجعل واجهة المستخدم ضبابية أو مستعارة أو سوداء بالكامل أو ترسم فوق واجهة المستخدم المحيطة على الأجهزة دون تسريع الأجهزة.
