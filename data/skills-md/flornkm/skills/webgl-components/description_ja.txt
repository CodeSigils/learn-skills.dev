パフォーマンス、アクセシビリティ、SSR、レイアウトを損なうことなく、通常の Web アプリ UI 内に組み込まれる小さな常時オンの WebGL ビジュアル (アイデンティティ アバター、アンビエント オーブ、ガラスと虹色のサーフェス、アニメーション テクスチャ) を構築します。シェーダー、GLSL、またはキャンバス駆動の装飾要素が製品 UI に追加される場合、特にページまたはリストごとに何度もレンダリングされる装飾要素を使用します。レビューまたは最適化するとき。または、ハードウェア アクセラレーションのないマシン上で、ぼやけたり、エイリアスが発生したり、真っ黒になったり、周囲の UI をペイントしたりするものをデバッグする場合です。
