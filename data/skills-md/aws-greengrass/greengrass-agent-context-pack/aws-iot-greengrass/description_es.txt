Guía a los agentes de IA a través de la configuración de AWS IoT Greengrass (Nucleus y Lite) en entornos en contenedores, la creación e implementación de componentes de IoT personalizados, la migración de funciones V1 Lambda a componentes V2 y la resolución de problemas comunes. Cubre tanto el tiempo de ejecución completo de Nucleus basado en Java como el tiempo de ejecución ligero de Nucleus Lite basado en C para dispositivos restringidos.
