يرشد وكلاء الذكاء الاصطناعي من خلال إعداد AWS IoT Greengrass (Nucleus وLite) في بيئات حاويات، وإنشاء مكونات IoT مخصصة ونشرها، وترحيل وظائف V1 Lambda إلى مكونات V2، واستكشاف المشكلات الشائعة وإصلاحها. يغطي كلاً من وقت تشغيل Nucleus الكامل المستند إلى Java ووقت تشغيل Nucleus Lite خفيف الوزن المستند إلى C للأجهزة المقيدة.
