Guida gli agenti AI attraverso la configurazione di AWS IoT Greengrass (Nucleus e Lite) in ambienti containerizzati, la creazione e la distribuzione di componenti IoT personalizzati, la migrazione delle funzioni Lambda V1 ai componenti V2 e la risoluzione dei problemi comuni. Copre sia il runtime completo di Nucleus basato su Java che il runtime leggero di Nucleus Lite basato su C per dispositivi vincolati.
