Помогает агентам искусственного интеллекта настраивать AWS IoT Greengrass (Nucleus и Lite) в контейнерных средах, создавать и развертывать пользовательские компоненты Интернета вещей, мигрировать функции Lambda версии 1 в компоненты версии 2 и устранять распространенные проблемы. Охватывает как полную среду выполнения Nucleus на основе Java, так и облегченную среду выполнения Nucleus Lite на основе C для устройств с ограниченными возможностями.
