Guide les agents IA dans la configuration d'AWS IoT Greengrass (Nucleus et Lite) dans des environnements conteneurisés, la création et le déploiement de composants IoT personnalisés, la migration des fonctions Lambda V1 vers les composants V2 et le dépannage des problèmes courants. Couvre à la fois le runtime Nucleus complet basé sur Java et le runtime Nucleus Lite léger basé sur C pour les appareils contraints.
