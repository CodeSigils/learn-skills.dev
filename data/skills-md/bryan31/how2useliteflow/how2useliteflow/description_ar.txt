يتم تمكينه عندما يذكر المستخدم LiteFlow (محرك قاعدة Java خفيف الوزن/إطار عمل تنسيق الأعمال). يغطي: المكونات، قواعد EL (THEN/WHEN/IF/SWITCH/FOR/WHILE/ITERATOR، وما إلى ذلك)، والسياق، ومكونات البرنامج النصي، ومصادر تكوين القاعدة، وعناصر التكوين، والمنفذين، وتنسيق AI Agent (ReAct Agent / liteflow-react-agent)، والاختبار والتصحيح، وتفاصيل التعليمات البرمجية المصدر.
