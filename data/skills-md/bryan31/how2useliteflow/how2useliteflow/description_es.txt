Cuando los usuarios mencionen LiteFlow (un marco de orquestación empresarial/motor de reglas Java ligero), habilítelo. La cobertura incluye: componentes, reglas EL (ENTONCES/CUÁNDO/IF/SWITCH/FOR/WHILE/ITERATOR, etc.), contexto, componentes de script, fuentes de configuración de reglas, elementos de configuración, ejecutores, orquestación del agente AI (ReAct Agent / liteflow‑react‑agent), pruebas y depuración, y detalles del código fuente.
