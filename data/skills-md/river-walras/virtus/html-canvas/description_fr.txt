Générez un artefact HTML riche et autonome pour les spécifications, les révisions de code, les conceptions, les rapports ou les éditeurs personnalisés. À utiliser lorsque l'utilisateur demande un "fichier HTML/artefact/explication/rapport/terrain de jeu", souhaite un livrable visuel partageable au lieu d'une démarque, ou demande de "créer un document lourd en canevas/tableau de bord/diagramme". Les expressions de déclenchement incluent « créer un code HTML », « artefact html », « canevas html », « rapport html », « explicatif html », « terrain de jeu html », « spécifications visuelles », « maquette html ».
