قم بإنشاء قطعة HTML غنية ومكتفية بذاتها للمواصفات أو مراجعات التعليمات البرمجية أو التصميمات أو التقارير أو المحررين المخصصين. يُستخدم عندما يطلب المستخدم "ملف HTML/قطعة أثرية/مفسر/تقرير/ساحة لعب"، أو يريد تسليمًا مرئيًا قابلاً للمشاركة بدلاً من تخفيض السعر، أو يطلب "إنشاء مستند مثقل بالقماش/لوحة المعلومات/الرسم التخطيطي". تتضمن عبارات التشغيل "إنشاء HTML"، و"قطعة أثرية html"، و"لوحة html"، و"تقرير html"، و"شرح html"، و"ملعب html"، و"المواصفات المرئية"، و"نموذج HTML بالحجم الطبيعي".
