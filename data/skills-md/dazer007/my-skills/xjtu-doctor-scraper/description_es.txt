Una habilidad especializada para extraer la lista de médicos del sitio web oficial del Primer Hospital Afiliado de la Universidad Xi'an Jiaotong. Condición de activación: cuando el usuario solicita rastrear información de médicos, listas de expertos o médicos de departamento de este hospital. Esta habilidad proporciona un flujo de trabajo completo para extraer listados de médicos del sitio web del XJTU First Affiliated Hospital, incluido el descubrimiento de la estructura de URL, el análisis de API, el rastreo por lotes y la salida CSV.
