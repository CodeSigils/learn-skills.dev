تصميم وكتابة والتحقق من صحة وحزم مهارات الوكيل الكاملة (حزم SKILL.md) لوكلاء ترميز الذكاء الاصطناعي مثل Claude Code وOpenCode وCodex وCursor وأي وكيل آخر يتبع مواصفات مهارات الوكيل (agentskills.io). استخدم هذا عندما يريد المستخدم إنشاء مهارة جديدة، أو تحويل سير عمل أو مجموعة من التعليمات إلى مهارة قابلة لإعادة الاستخدام، أو تحسين SKILL.md موجود أو إعادة هيكلته، أو إضافة نصوص برمجية/مراجع/أصول إلى مهارة، أو التحقق من صحة المادة الأساسية للمهارة وبنيتها، أو حزم مهارة للتوزيع - حتى لو قالوا فقط "اجعل هذا قابلاً للتكرار" أو "حول هذا إلى شيء يمكن لوكيلي إعادة استخدامه".
