Diseñe, escriba, valide y empaquete Agent Skills completos (paquetes SKILL.md) para agentes de codificación de IA como Claude Code, OpenCode, Codex, Cursor y cualquier otro agente que siga la especificación Agent Skills (agentskills.io). Úselo siempre que el usuario quiera crear una nueva habilidad, convertir un flujo de trabajo o un conjunto de instrucciones en una habilidad reutilizable, mejorar o refactorizar un SKILL.md existente, agregar scripts/referencias/activos a una habilidad, validar el contenido y la estructura de una habilidad, o empaquetar una habilidad para su distribución, incluso si simplemente dicen "hacer esto repetible" o "convertir esto en algo que mi agente pueda reutilizar".
