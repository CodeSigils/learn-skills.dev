Entwerfen, schreiben, validieren und verpacken Sie vollständige Agent Skills (SKILL.md-Bundles) für KI-Codierungsagenten wie Claude Code, OpenCode, Codex, Cursor und alle anderen Agenten, die der Agent Skills-Spezifikation (agentskills.io) folgen. Verwenden Sie dies immer dann, wenn der Benutzer einen neuen Skill erstellen, einen Workflow oder eine Reihe von Anweisungen in einen wiederverwendbaren Skill umwandeln, ein vorhandenes SKILL.md verbessern oder umgestalten, einem Skill Skripte/Referenzen/Assets hinzufügen, den Inhalt und die Struktur eines Skills validieren oder einen Skill für die Verteilung verpacken möchte – selbst wenn er nur sagt: „Machen Sie dies wiederholbar“ oder „verwandeln Sie dies in etwas, das mein Agent wiederverwenden kann“.
