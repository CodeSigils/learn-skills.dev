اكتشف والعثور على وقارن ومراجعة وإصلاح وتكييف وتصميم حلقات وكيل الذكاء الاصطناعي القابلة للتكرار باستخدام مشغلات وإجراءات وتحقق وشروط إيقاف وحواجز حماية وعمليات تسليم واضحة. يُستخدم عندما يطلب المستخدم تحليل قاعدة تعليمات برمجية للحلقات المحتملة، أو استخراج سجل سلسلة الترميز للعمل المنجز أكثر من مرة، أو تحويل العمل الهندسي المتكرر إلى حلقة، أو العثور على حلقة منشورة أو التوصية بها، أو إنشاء سير عمل وكيل متكرر أو إيقاع أتمتة، أو تحويل النتيجة إلى حلقة جاهزة للنسخ محدودة، أو مراجعة حلقة موجودة للتحقق من الضعف، أو السلطة غير الآمنة، أو التكرار غير المحدود، أو الحالة القديمة، أو سلوك التوقف غير الواضح.
