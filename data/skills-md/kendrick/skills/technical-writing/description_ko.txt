개발자 대면 작성을 위한 계층화된 산문 표준: 이미 존재하는 README 내의 산문을 포함하여 커밋 메시지, 코드 주석, PR 설명, API 참조, 변경 집합 및 기타 기술 문서입니다. 커밋 메시지 작성 또는 검토, 코드 주석 초안 작성 또는 감사, PR 설명 또는 개발자 문서 다듬기에 사용됩니다. Diátaxis 문서 모드, Google 개발자 스타일, STE 문장 원칙, 글로벌 영어 등 적용되는 레이어의 이름을 지정하는 프로필에 각 아티팩트 유형을 전달하고 모든 초안은 산문 감사로 마무리됩니다. 대화식 답변이나 코드 자체용이 아니며 사람에게 전달된 내용에는 절대 사용되지 않습니다. 이메일, DM 및 기타 메시지는 설정 자체 음성 프로세스로 라우팅되며, 이는 산문 감사를 계층화하는 대신 대체합니다. 전체 README를 작성하는 것은 readme-coauthorship에 속하고 제안서와 사양은 doc-coauthoring에 속합니다. 이 기술은 문서 구조 워크플로가 아닌 산문 스타일을 제어합니다.
