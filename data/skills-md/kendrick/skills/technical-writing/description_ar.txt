معيار النثر ذو الطبقات للكتابة التي تواجه المطورين: رسائل الالتزام، وتعليقات التعليمات البرمجية، وأوصاف العلاقات العامة، ومرجع واجهة برمجة التطبيقات، ومجموعات التغييرات، والمستندات الفنية الأخرى، بما في ذلك النثر داخل ملف README الموجود بالفعل. يُستخدم عند كتابة أو مراجعة رسالة التزام، أو صياغة تعليقات التعليمات البرمجية أو تدقيقها، أو وصف العلاقات العامة، أو تلميع وثائق المطور. يُرسل كل نوع من أنواع القطع الأثرية إلى ملف تعريف يُسمي الطبقات التي تنطبق - أوضاع مستند Diátaxis، وأسلوب مطور Google، ومبادئ جملة STE، والإنجليزية العالمية - وتنتهي كل مسودة بمراجعة نثرية. ليس للإجابات التحادثية، وليس للكود نفسه، وليس لأي شيء موجه إلى شخص ما: يتم توجيه رسائل البريد الإلكتروني والرسائل المباشرة والرسائل الأخرى إلى العملية الصوتية الخاصة بالإعداد، والتي تحل محل التدقيق النثري بدلاً من وضعها في طبقات. إن تأليف ملف README بالكامل ينتمي إلى التأليف التمهيدي المشترك، والمقترحات والمواصفات تنتمي إلى التأليف المشترك للمستندات. تتحكم هذه المهارة في أسلوب النثر، وليس في سير عمل بنية المستند.
