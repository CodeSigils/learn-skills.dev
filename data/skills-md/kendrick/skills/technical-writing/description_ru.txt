Многоуровневый стандарт написания для разработчиков: сообщения о фиксации, комментарии к коду, PR-описания, ссылки на API, наборы изменений и другая техническая документация, включая текст в уже существующем README. Используйте при написании или просмотре сообщения о фиксации, составлении или проверке комментариев к коду, описании PR или доработке документации для разработчиков. Отправляет каждый тип артефакта в профиль, в котором указано, какие слои применяются — режимы документа Diátaxis, стиль разработчика Google, принципы предложения STE, глобальный английский — и каждый черновик завершается проверкой текста. Ни для разговорных ответов, ни для самого кода, ни для чего-либо, адресованного человеку: электронные письма, личные сообщения и другие сообщения направляются в собственный голосовой процесс установки, который заменяет аудит прозы, а не наслаивает его. Создание всего README относится к соавторству readme, а предложения и спецификации - к соавторству документов. Этот навык определяет стиль прозы, а не рабочие процессы структуры документа.
