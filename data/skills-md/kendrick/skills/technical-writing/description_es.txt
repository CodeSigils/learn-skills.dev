Estándar de prosa en capas para escritura dirigida a desarrolladores: mensajes de confirmación, comentarios de código, descripciones de relaciones públicas, referencias de API, conjuntos de cambios y otros documentos técnicos, incluida la prosa dentro de un README que ya existe. Úselo al escribir o revisar un mensaje de confirmación, redactar o auditar comentarios de código, describir un PR o pulir la documentación del desarrollador. Distribuye cada tipo de artefacto a un perfil que nombra qué capas se aplican (modos de documento Diátaxis, estilo de desarrollador de Google, principios de oraciones STE, inglés global) y cada borrador finaliza con una auditoría de prosa. No para respuestas conversacionales, no para el código en sí y nunca para nada dirigido a una persona: correos electrónicos, mensajes directos y otros mensajes se dirigen al propio proceso de voz de la configuración, que reemplaza la auditoría de prosa en lugar de superponerla. La creación de un README completo pertenece a la coautoría del archivo Léame, y las propuestas y especificaciones a la coautoría de documentos. Esta habilidad gobierna el estilo de la prosa, no los flujos de trabajo de la estructura del documento.
