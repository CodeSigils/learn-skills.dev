開発者向けの文章の階層化標準: コミット メッセージ、コード コメント、PR 説明、API リファレンス、変更セット、および既存の README 内の散文を含むその他の技術ドキュメント。コミット メッセージの作成またはレビュー、コード コメントの下書きまたは監査、PR の説明、または開発者ドキュメントの完成度を高めるときに使用します。各アーティファクト タイプを、適用するレイヤー (Diátaxis ドキュメント モード、Google 開発者スタイル、STE 文原則、グローバル英語) を指定するプロファイルにディスパッチし、すべてのドラフトは散文監査で終了します。会話の回答やコード自体、そして個人に宛てられたものは決して対象外です。電子メール、DM、その他のメッセージはセットアップ独自の音声プロセスにルーティングされ、散文監査を重ね合わせるのではなく置き換えます。 README 全体の作成は readme-coauthorship に属し、提案書と仕様書は doc-coauthoring に属します。このスキルは文書構造のワークフローではなく、散文のスタイルを決定します。
