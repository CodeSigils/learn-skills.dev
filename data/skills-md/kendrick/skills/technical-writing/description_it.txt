Standard in prosa a più livelli per la scrittura rivolta agli sviluppatori: messaggi di commit, commenti sul codice, descrizioni PR, riferimento API, set di modifiche e altri documenti tecnici, inclusa la prosa all'interno di un README già esistente. Da utilizzare durante la scrittura o la revisione di un messaggio di commit, la stesura o il controllo di commenti sul codice, la descrizione di una PR o il perfezionamento della documentazione dello sviluppatore. Invia ciascun tipo di artefatto a un profilo che indica quali livelli applicare (modalità documento Diátaxis, stile sviluppatore Google, principi della frase STE, inglese globale) e ogni bozza termina con un controllo in prosa. Non per le risposte colloquiali, non per il codice stesso e mai per qualcosa indirizzato a una persona: e-mail, messaggi diretti e altri messaggi vengono instradati al processo vocale proprio del setup, che sostituisce l'audit in prosa anziché sovrapporsi ad esso. La creazione di un intero file README appartiene alla creazione condivisa dei file readme, mentre le proposte e le specifiche appartengono alla creazione condivisa dei documenti. Questa abilità governa lo stile di prosa, non i flussi di lavoro della struttura dei documenti.
