Завершите установку пакета линейного отслеживания после того, как будут получены навыки: напишите постоянные правила (Линейное = источник истины по умолчанию для каждого сеанса) и проверьте аутентификацию Linear MCP. Опционально предложите автоматизацию монитора курсора. Используйте, когда пользователь говорит «завершить линейную установку», «завершить установку с линейным отслеживанием», «завершить настройку после добавления навыков» или сразу после установки пакета.
