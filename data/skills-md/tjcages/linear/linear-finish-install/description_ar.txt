قم بإنهاء تثبيت حزمة التتبع الخطي بعد وجود المهارات: اكتب القواعد الدائمة (الخطي = المصدر الافتراضي للحقيقة في كل جلسة) وتحقق من مصادقة Linear MCP. عرض اختياري أتمتة مراقبة المؤشر. يُستخدم عندما يقول المستخدم "إنهاء التثبيت الخطي"، أو "إنهاء تثبيت التتبع الخطي"، أو "إكمال الإعداد بعد إضافة المهارات"، أو مباشرة بعد تثبيت الحزمة.
