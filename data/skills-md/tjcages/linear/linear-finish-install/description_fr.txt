Terminez l'installation du pack de suivi linéaire une fois les compétences présentes : écrivez des règles permanentes (Linéaire = source de vérité par défaut à chaque session) et vérifiez l'authentification MCP linéaire. Proposez en option l'automatisation du moniteur de curseur. À utiliser lorsque l'utilisateur dit « terminer l'installation linéaire », « terminer l'installation du suivi linéaire », « terminer la configuration après l'ajout de compétences » ou juste après l'installation du pack.
