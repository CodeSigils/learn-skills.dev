Disciplina della sessione lineare sempre attiva e soft nudge una tantum per repository non tracciati. Da utilizzare ogni volta che si svolge un lavoro non banale in un repository che dispone già di un protocollo di tracciamento lineare in CLAUDE.md, AGENTS.md o .cursor/rules; o quando si apre/si lavora in un repository senza protocollo e senza file .linear-tracking-skip (chiedere una volta di eseguire linear-setup). Applica la ricerca prima della creazione, il ciclo di vita e il Close-the-Loop. NON per esecuzioni di bootstrap, sincronizzazione o monitoraggio complete.
