Загрузите или расширите правильное отслеживание линейного проекта — методологию, а не API CRUD. Используйте, когда пользователь просит настроить линейное отслеживание, отслеживать этот проект в линейном режиме, добавить это репо в линейное, заполнить историю, подготовиться к отслеживанию или дать согласие после мягкого подталкивания от линейной дисциплины. Привязка к Полярной звезде, заполнение доказательствами, проводка заблокирована, устанавливается дисциплина по каждому репо. НЕ для создания/комментирования разовой проблемы — Linear MCP справится с этим.
