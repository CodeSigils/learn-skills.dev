iOS アプリ プロジェクトをスキャンして App Store の拒否リスクを調べます。ソースコードを直接読み取ります。やり取りは必要ありません。バイブコーダーと開発者を自動検出し、言語を適応させます。ビルド中のアプリを検出し、モードを切り替える前に質問します。リスク登録、動的なコピー＆ペーストによる修正による詳細な調査結果、レビュー担当者のエクスペリエンス チェックリスト、App Store Connect のレビュー担当者メモの草案、およびスキャン後の手動チェックリストを出力します。
明示的に質問されていなくても、次のいずれかに対してこのスキルをトリガーします: 「アプリを監査する」 / 「アプリの準備はできていますか」 / 「送信しようとしています」 / 「まもなく送信します」 / 「リリースしようとしています」 / 「出荷準備完了」 / 「App Store レビュー」 / 「拒否され続ける」 / 「拒否されました」 / 「拒否」 / 「App Store Connect」 / 「TestFlight」 / 「レビューのために送信」 / 「事前送信」 / 「アプリレビュー」 / 「初めてのアプリ」 / 「これまでに一度も提出したことがない」 / 「なぜ Apple が拒否したのか」 / 「何を修正する必要があるか」 / 「これは起動する準備ができていますか」。また、iOS アプリで作業しており、ユーザーがリリースに近づいていると思われる場合にも、プロアクティブにトリガーします。
