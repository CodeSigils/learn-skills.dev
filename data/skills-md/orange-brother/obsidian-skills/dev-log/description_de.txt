Erstellen Sie eine retrospektive Obsidian-Notiz aus einer Entwicklungsaufgabe. Verwenden Sie diese Option, wenn der Benutzer eine abgeschlossene Aufgabe, Funktion oder Bugfix als Retrospektivnotiz dokumentieren möchte.
