Créez une note Obsidian rétrospective à partir d'une tâche de développement. Étant donné un nom de tâche et un bref historique, l'IA collecte le contexte git et le code, interroge l'utilisateur sur les décisions et les informations, et écrit un journal de démarque structuré dans le coffre-fort. À utiliser lorsque l'utilisateur souhaite documenter une tâche, une fonctionnalité ou une correction de bug terminée sous forme de note rétrospective.
