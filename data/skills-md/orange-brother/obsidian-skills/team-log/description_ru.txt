Создайте журнал работы для всей команды на основе задачи разработки и отправьте его непосредственно в общий репозиторий GitHub через gh CLI. Автоматически собирает контекст git и задает 2–3 конкретных вопроса для еженедельного анализа командой. Используйте, когда пользователь хочет поделиться со своей командой тем, над чем он работал.
