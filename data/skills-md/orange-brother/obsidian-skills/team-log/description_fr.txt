Créez un journal de travail d'équipe à partir d'une tâche de développement et transférez-le directement vers un référentiel GitHub partagé via gh CLI. Collecte automatiquement le contexte git et pose 2 à 3 questions ciblées pour un examen hebdomadaire par l'équipe. À utiliser lorsque l'utilisateur souhaite partager ce sur quoi il a travaillé avec son équipe.
