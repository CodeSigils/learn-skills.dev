À utiliser lors de l'écriture ou de l'exécution de commandes, de scripts ou de pipelines Nushell - via le serveur Nushell MCP (mcp__nushell__evaluate), via Bash (nu -c) ou dans des fichiers de script .nu. À utiliser également lorsque vous travaillez avec des données structurées (JSON, YAML, TOML, CSV, Parquet, SQLite), effectuez une analyse ou une exploration de données ad hoc, ou lorsque le shell de l'utilisateur est Nushell.
