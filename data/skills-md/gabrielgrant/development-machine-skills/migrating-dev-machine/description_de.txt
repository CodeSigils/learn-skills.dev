Migriert eine vorhandene Entwicklungsmaschine in das verwaltete Muster – entweder direkt auf derselben Maschine oder von einem alten Server auf einen neuen (Bestandsaufnahme, gestaffelte Home-Kopie, Drei-Wege-Dotfile-Zusammenführung, selektive Neuinstallation von Paketen). Verwenden Sie diese Option, wenn Sie auf einen neuen Server/eine neue VM wechseln, Ubuntu durch Neuaufbau aktualisieren, server-config/chezmoi/devbox auf einer Maschine übernehmen, die bereits über einen Status verfügt, oder eine alte Box außer Betrieb nehmen.
