Configure et utilise des environnements de développement par dépôt sur une machine de développement gérée : superpositions Devbox personnelles pour les dépôts tiers, activation automatique de direnv et exécution de direnv pour les agents de codage et les lancements non interactifs. À utiliser lors du démarrage d'un travail dans une caisse, du clonage d'un dépôt, du lancement d'un agent (claude/codex) dans un projet, lorsque des outils manquent dans un dépôt ou lorsqu'un dépôt manque de configuration devbox/devcontainer qui ne doit pas être validée en amont.
