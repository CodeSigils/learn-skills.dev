Richtet Pro-Repo-Entwicklungsumgebungen auf einem verwalteten Entwicklungscomputer ein und verwendet diese – persönliche Devbox-Overlays für Drittanbieter-Repos, direnv-Autoaktivierung und direnv exec für Codierungsagenten und nicht interaktive Starts. Verwenden Sie diese Option, wenn Sie mit der Arbeit in einem Checkout beginnen, ein Repo klonen, einen Agenten (Claude/Codex) innerhalb eines Projekts starten, wenn Tools in einem Repo fehlen oder wenn einem Repo eine Devbox-/Devcontainer-Konfiguration fehlt, die nicht im Upstream festgeschrieben werden sollte.
