Configura e utilizza ambienti di sviluppo per repository su una macchina di sviluppo gestita: overlay Devbox personali per repository di terze parti, attivazione automatica di direnv e direnv exec per agenti di codifica e lanci non interattivi. Da utilizzare quando si inizia a lavorare in un checkout, si clona un repository, si avvia un agente (claude/codex) all'interno di un progetto, quando mancano strumenti in un repository o quando in un repository manca la configurazione devbox/devcontainer che non dovrebbe essere impegnata a monte.
