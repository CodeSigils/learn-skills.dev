Настраивает и использует среды разработки для каждого репозитория на управляемой машине разработки — персональные оверлеи Devbox для сторонних репозиториев, автоматическую активацию direnv и direnv exec для агентов кодирования и неинтерактивных запусков. Используйте при начале работы с оформлением заказа, клонировании репозитория, запуске агента (claude/codex) внутри проекта, когда в репозитории отсутствуют инструменты или когда в репозитории отсутствует конфигурация devbox/devcontainer, которую не следует фиксировать в исходной версии.
