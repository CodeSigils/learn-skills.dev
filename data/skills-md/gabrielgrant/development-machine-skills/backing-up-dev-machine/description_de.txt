Sicherung und Wiederherstellung für die Persistent-State-Schicht einer verwalteten Entwicklungsmaschine – was gesichert werden soll, was stattdessen neu erstellt werden soll und wie die Reihenfolge wiederhergestellt werden soll. Verwenden Sie diese Option beim Einrichten von Backups, vor riskanten Änderungen oder Migrationen, wenn Sie gefragt werden, was verloren gehen würde, wenn die Maschine ausfällt, oder beim Wiederherstellen des Agentenstatus, von Repos oder Containerdaten.
