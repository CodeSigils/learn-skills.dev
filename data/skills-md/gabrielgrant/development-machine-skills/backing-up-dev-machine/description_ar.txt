النسخ الاحتياطي والاستعادة لطبقة الحالة المستمرة لجهاز التطوير المُدار — ما يجب نسخه احتياطيًا، وما يجب إعادة بنائه بدلاً من ذلك، واستعادة النظام. استخدمه عند إعداد النسخ الاحتياطية، قبل إجراء تغييرات أو عمليات ترحيل محفوفة بالمخاطر، أو عند السؤال عما سيتم فقده في حالة توقف الجهاز، أو عند استعادة حالة الوكيل أو عمليات إعادة الشراء أو بيانات الحاوية.
