Загружает новую машину с Ubuntu в шаблон управляемой машины разработчика (etckeeper, репозиторий конфигурации сервера с манифестом пакета хоста, загрузчики точечных файлов chezmoi, Devbox Global, direnv). Используйте при настройке нового сервера разработки или виртуальной машины с нуля или при запросе «настроить этот компьютер», «загрузить блок разработки» или установить базовые инструменты при чистой установке. Для машин с существующим состоянием вместо этого используйте migrating-dev-machine.
