新しい Ubuntu マシンを管理対象の開発マシン パターン (etckeeper、ホスト パッケージ マニフェストを含むサーバー設定リポジトリ、chezmoi ドットファイル ローダー、Devbox Global、direnv) にブートストラップします。新しい開発サーバー/VM を最初からセットアップする場合、または「このマシンをセットアップする」、「開発ボックスをブートストラップする」、またはクリーン インストールでベースライン ツールをインストールするように求められた場合に使用します。既存の状態のマシンの場合は、代わりに migating-dev-machine を使用してください。
