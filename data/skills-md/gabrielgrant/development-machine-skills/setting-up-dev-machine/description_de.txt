Bootstrapt eine neue Ubuntu-Maschine in das verwaltete Dev-Machine-Muster (etckeeper, Server-Config-Repo mit Host-Paketmanifest, Chezmoi-Dotfile-Loader, Devbox Global, direnv). Verwenden Sie diese Option, wenn Sie einen neuen Entwicklungsserver/eine neue VM von Grund auf einrichten oder wenn Sie aufgefordert werden, „diese Maschine einzurichten“, „die Entwicklungsbox zu booten“ oder die Basistools bei einer Neuinstallation zu installieren. Für Maschinen mit vorhandenem Status verwenden Sie stattdessen migrating-dev-machine.
