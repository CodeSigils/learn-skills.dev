Amorce une nouvelle machine Ubuntu dans le modèle de machine de développement géré (etckeeper, dépôt de configuration de serveur avec manifeste de package hôte, chargeurs de fichiers chezmoi dotfile, Devbox Global, direnv). À utiliser lors de la configuration d'un nouveau serveur de développement/VM à partir de zéro, ou lorsqu'on vous demande de « configurer cette machine », de « démarrer la boîte de développement » ou d'installer les outils de base sur une nouvelle installation. Pour les machines avec un état existant, utilisez plutôt migrateing-dev-machine.
