Inicia una nueva máquina Ubuntu en el patrón de máquina de desarrollo administrada (etckeeper, repositorio de configuración del servidor con manifiesto del paquete host, cargadores de archivos de puntos chezmoi, Devbox Global, direnv). Úselo al configurar un nuevo servidor de desarrollo/VM desde cero, o cuando se le solicite "configurar esta máquina", "iniciar la caja de desarrollo" o instalar las herramientas básicas en una instalación limpia. Para máquinas con estado existente, utilice migring-dev-machine en su lugar.
