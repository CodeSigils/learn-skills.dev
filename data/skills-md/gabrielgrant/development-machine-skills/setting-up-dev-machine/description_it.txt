Avvia una nuova macchina Ubuntu nel modello dev-machine gestito (etckeeper, repository di configurazione server con manifest del pacchetto host, caricatori dotfile chezmoi, Devbox Global, direnv). Da utilizzare quando si configura da zero un nuovo server di sviluppo/VM o quando viene richiesto di "configurare questa macchina", "avviare la casella di sviluppo" o installare gli strumenti di base su un'installazione pulita. Per le macchine con stato esistente, utilizzare invece migrating-dev-machine.
