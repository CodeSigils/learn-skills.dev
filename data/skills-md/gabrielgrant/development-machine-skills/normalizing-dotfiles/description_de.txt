Triage nach vom Installationsprogramm geschriebenen oder ungeklärten Dotfile-Änderungen auf einem verwalteten Entwicklungscomputer – klassifizieren Sie jede Änderung, akzeptieren Sie sie, organisieren Sie sie in einem verwalteten Snippet neu oder lehnen Sie sie ab. Wird verwendet, wenn Chezmoi Diff fehlerhaft ist, wenn ein Installationsprogramm Zeilen an .bashrc/.profile angehängt hat, wenn doppelte PATH-Einträge angezeigt werden oder wenn entschieden wird, ob eine Dotfile-Änderung in Git gehört.
