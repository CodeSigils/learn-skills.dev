فرز تغييرات ملفات النقاط المكتوبة أو غير المبررة بواسطة أداة التثبيت على جهاز تطوير مُدار - قم بتصنيف كل تغيير، ثم قبوله، أو إعادة تنظيمه في مقتطف مُدار، أو رفضه. يُستخدم عندما يكون chezmoi diff متسخًا، أو عندما يقوم المثبت بإلحاق أسطر بـ .bashrc/.profile، أو عندما تظهر إدخالات PATH مكررة، أو عند تحديد ما إذا كان تغيير ملف النقاط ينتمي إلى git.
