Стандартный стек технологий FMC для гео-тяжелых React SPA: Bun/Vite, React 19, TanStack, карты, стили, выравнивание редактора TypeScript/CLI, шаблоны tsconfig, целевые клиентские списки браузеров и когда выбирать родственные навыки. Используйте при создании нового приложения, оценке библиотек, изменении поддерживаемых браузеров или проверке совместимости, а также при принятии решений по стеку/архитектуре существующих приложений.
