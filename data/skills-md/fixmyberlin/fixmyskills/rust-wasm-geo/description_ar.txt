Rust/WASM Geo لتطبيقات React ذات الوزن الجغرافي الثقيل FixMyBerlin FMC: متى تترك Turf لـ WASM، واختيار الصناديق (geo، rstar، fast_paths، osm-reader، i_overlay، ...)، حدود Wasm-bindgen، وتكامل Vite لـ SPAs وTanStack Start. يُستخدم عند إضافة صناديق WASM الجغرافية، أو تحديد ملفات تعريف العشب البطيء، أو OSM/التوجيه/التزامن الزمني، أو الفهارس المكانية، أو توصيل حزمة Wasm إلى Vite.
