Рабочий процесс FMC для завершения работы: запустить проверку выполнения, исправить сбои, выполнить фиксацию с сообщением на английском языке по умолчанию и показать черновик только тогда, когда пользователь явно не хочет фиксации. Используйте для завершения работы, выполнения проверок, подведения итогов, внесения изменений или создания коммитов.
