Examine les applications Web React pour iPad et la convivialité de l'écran tactile avec les correctifs CSS Tailwind. Audite les cibles tactiles, les échecs de survol, la mise en surbrillance de la liste de contact (concentration sur les données de l'interface utilisateur sans tête, données Radix mises en surbrillance, lignes en ligne), les bizarreries de Safari/iPadOS, la fluidité de la mise en page et les conventions de curseur FMC. À utiliser lorsque l'utilisateur demande à examiner une application pour une utilisation optimisée pour le toucher, l'iPad, la tablette ou l'écran tactile.
