Обзоры веб-приложений React для iPad и удобства использования сенсорных экранов с исправлениями Tailwind CSS. Аудит целей касания, сбоев при наведении, выделения списка касаний (фокусировка данных безголового пользовательского интерфейса, выделение данных Radix, встроенные строки), особенности Safari/iPadOS, плавность макета и соглашения о курсорах FMC. Используйте, когда пользователь просит проверить приложение на предмет использования с сенсорным экраном, iPad, планшетом или оптимизированным для сенсорного экрана.
