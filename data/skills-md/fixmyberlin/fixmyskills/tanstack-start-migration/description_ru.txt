Перенесите приложения Next.js в TanStack Start. Охватывает настройку Vite/Nitro, изоморфное выполнение, загрузчики маршрутов с помощью React Query, действия сервера → функции сервера, маршруты API и соглашения о папках FMC. Используйте при переходе с Next.js на TanStack Start, преобразовании действий сервера, getServerSideProps или маршрутов API.
