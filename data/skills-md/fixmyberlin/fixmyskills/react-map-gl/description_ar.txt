أنماط رد الفعل-map-gl/maplibre لتطبيقات FMC الجغرافية: المصدر/الطبقة التعريفية (لا تضيف أبدًا مصدرًا/addLayer)، MapProvider + useMap()، InteractiveLayerIds، المصدر/الطبقة المسطحة، الحماية المحملة بالخريطة، معالجات أحداث الخريطة (لا تستخدم التأثير)، حالة خريطة URL، الحالة الأولية للعرض، المؤشر، حالة الميزة، الصور المفقودة. يُستخدم عند إنشاء أو مراجعة مكونات الخريطة أو الطبقات أو معالجات النقر/التمرير أو setFeatureState أو مزامنة عنوان URL للخريطة في تطبيقات TanStack Start / Vite. التنفيذ المرجعي: tilda-geo/app.
