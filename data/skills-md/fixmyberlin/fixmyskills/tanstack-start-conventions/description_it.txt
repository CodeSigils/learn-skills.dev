Convenzioni TanStack Start e router per FixMyBerlin/FMC: layout delle cartelle delle app, percorsi sottili, suffissi di file client/server, caricatori rispetto a React Query, SSR selettivo, componenti server sperimentali (RSC), serializzazione della ricerca del router (URL di condivisione puliti) e convalida del parametro/ricerca del percorso UI rispetto all'API. Da utilizzare durante lo scaffolding o il refactoring della struttura app/src, lavorando su percorsi TanStack Start, funzioni server, caricatori, router.tsx parseSearch/stringifySearch, renderServerComponent, createCompositeComponent, validateSearch o percorsi API in rotte/api/.
