اصطلاحات TanStack Start وRouter لـ FixMyBerlin/FMC: تخطيط مجلد التطبيق، والمسارات الرفيعة، ولاحقات ملفات العميل/الخادم، وأدوات التحميل مقابل React Query، وSSR الانتقائي، ومكونات الخادم التجريبية (RSC)، وتسلسل بحث جهاز التوجيه (عناوين URL للمشاركة النظيفة)، والتحقق من صحة معلمات/بحث واجهة المستخدم مقابل واجهة برمجة التطبيقات. يُستخدم عند السقالات أو إعادة هيكلة بنية التطبيق/src، أو العمل على مسارات TanStack Start، أو وظائف الخادم، أو أدوات التحميل، أو router.tsx parseSearch/stringifySearch، أو renderServerComponent، أو createCompositeComponent، أو validateSearch، أو مسارات API ضمن المسارات/api/.
