Соглашения TanStack Start и Router для FixMyBerlin/FMC: макет папки приложения, тонкие маршруты, суффиксы файлов клиент/сервер, загрузчики и React Query, выборочный SSR, экспериментальные серверные компоненты (RSC), сериализация поиска маршрутизатора (чистые общие URL-адреса) и проверка параметров/поиска маршрута пользовательского интерфейса и API. Используйте при создании шаблонов или рефакторинге структуры приложения/источника, работе с маршрутами TanStack Start, серверными функциями, загрузчиками, router.tsx parseSearch/stringifySearch, renderServerComponent, createCompositeComponent, validateSearch или маршрутами API в маршрутах/api/.
