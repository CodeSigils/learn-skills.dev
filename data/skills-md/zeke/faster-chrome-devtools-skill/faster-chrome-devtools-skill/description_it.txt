Ispeziona, esegui il debug e automatizza Chrome direttamente tramite il Chrome DevTools Protocol (CDP). Utilizza questa abilità ogni volta che un'attività richiede un vero browser Web: apri un URL, naviga tra le pagine, acquisisci uno screenshot di una pagina Web, leggi il DOM o l'albero di accessibilità, fai clic sui pulsanti, compila e invia moduli, digita testo, attendi elementi, analizza il contenuto della pagina, valuta JavaScript su una pagina o controlla gli errori della console e le richieste di rete non riuscite. Funziona con Chrome locale dell'utente o con un endpoint di rendering del browser Cloudflare remoto su WebSocket. Rilevante per l'automazione del browser, il web scraping, gli screenshot delle pagine, i controlli dell'interfaccia utente end-to-end e l'ispezione di DevTools. Non è richiesto alcun MCP, Burattinaio o Drammaturgo di Chrome DevTools.
