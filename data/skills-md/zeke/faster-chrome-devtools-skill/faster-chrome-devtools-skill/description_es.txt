Inspeccione, depure y automatice Chrome directamente a través del protocolo Chrome DevTools (CDP). Utilice esta habilidad siempre que una tarea necesite un navegador web real: abra una URL, navegue por páginas, tome una captura de pantalla de una página web, lea el DOM o el árbol de accesibilidad, haga clic en botones, complete y envíe formularios, escriba texto, espere elementos, extraiga el contenido de la página, evalúe JavaScript en una página o verifique errores de la consola y solicitudes de red fallidas. Funciona con el Chrome local del usuario o con un punto final remoto de representación del navegador Cloudflare a través de WebSocket. Relevante para la automatización del navegador, el web scraping, las capturas de pantalla de páginas, las comprobaciones de la interfaz de usuario de un extremo a otro y la inspección de DevTools. No se requiere Chrome DevTools MCP, Puppeteer o Playwright.
