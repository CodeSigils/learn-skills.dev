Überprüfen, debuggen und automatisieren Sie Chrome direkt über das Chrome DevTools Protocol (CDP). Verwenden Sie diese Fähigkeit immer dann, wenn eine Aufgabe einen echten Webbrowser erfordert: Öffnen Sie eine URL, navigieren Sie durch Seiten, machen Sie einen Screenshot einer Webseite, lesen Sie das DOM oder den Barrierefreiheitsbaum, klicken Sie auf Schaltflächen, füllen Sie Formulare aus und senden Sie sie, geben Sie Text ein, warten Sie auf Elemente, scannen Sie Seiteninhalte, bewerten Sie JavaScript auf einer Seite oder überprüfen Sie Konsolenfehler und fehlgeschlagene Netzwerkanforderungen. Funktioniert mit dem lokalen Chrome des Benutzers oder einem Remote-Cloudflare-Browser-Rendering-Endpunkt über WebSocket. Relevant für Browser-Automatisierung, Web-Scraping, Seiten-Screenshots, End-to-End-UI-Prüfungen und DevTools-Inspektion. Kein Chrome DevTools MCP, Puppeteer oder Playwright erforderlich.
