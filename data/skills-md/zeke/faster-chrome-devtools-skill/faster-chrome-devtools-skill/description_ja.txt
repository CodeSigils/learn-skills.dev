Chrome DevTools Protocol (CDP) を通じて Chrome を直接検査、デバッグ、自動化します。タスクで実際の Web ブラウザが必要な場合は常に、このスキルを使用します。URL を開く、ページを移動する、Web ページのスクリーンショットを撮る、DOM またはアクセシビリティ ツリーを読み取る、ボタンをクリックする、フォームに入力して送信する、テキストを入力する、要素を待機する、ページ コンテンツを取得する、ページ上の JavaScript を評価する、コンソール エラーと失敗したネットワーク リクエストを確認するなどです。ユーザーのローカル Chrome または WebSocket 経由のリモート Cloudflare ブラウザ レンダリング エンドポイントに対して機能します。ブラウザの自動化、Web スクレイピング、ページのスクリーンショット、エンドツーエンドの UI チェック、DevTools 検査に関連します。 Chrome DevTools MCP、Puppeteer、または Playwright は必要ありません。
