Проверяйте, отлаживайте и автоматизируйте Chrome напрямую через протокол Chrome DevTools (CDP). Используйте этот навык всякий раз, когда для задачи требуется настоящий веб-браузер: откройте URL-адрес, перемещайтесь по страницам, сделайте снимок экрана веб-страницы, прочитайте DOM или дерево доступности, нажимайте кнопки, заполняйте и отправляйте формы, вводите текст, ожидайте элементов, очищайте содержимое страницы, оценивайте JavaScript на странице или проверяйте ошибки консоли и неудачные сетевые запросы. Работает с локальным Chrome пользователя или с удаленной конечной точкой рендеринга браузера Cloudflare через WebSocket. Относится к автоматизации браузера, очистке веб-страниц, скриншотам страниц, сквозным проверкам пользовательского интерфейса и проверке DevTools. Никаких Chrome DevTools MCP, Puppeteer или Playwright не требуется.
