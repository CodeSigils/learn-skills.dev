يمكنك فحص Chrome وتصحيح أخطائه وتشغيله تلقائيًا من خلال بروتوكول Chrome DevTools (CDP). استخدم هذه المهارة عندما تحتاج المهمة إلى متصفح ويب حقيقي: افتح عنوان URL، أو تصفح الصفحات، أو التقط لقطة شاشة لصفحة ويب، أو اقرأ DOM أو شجرة إمكانية الوصول، أو انقر على الأزرار، أو املأ النماذج وأرسلها، أو اكتب نصًا، أو انتظر العناصر، أو استخرج محتوى الصفحة، أو قم بتقييم JavaScript على الصفحة، أو تحقق من أخطاء وحدة التحكم وطلبات الشبكة الفاشلة. يعمل ضد Chrome المحلي للمستخدم أو نقطة نهاية عرض متصفح Cloudflare البعيدة عبر WebSocket. ذات صلة بأتمتة المتصفح، وتجميع الويب، ولقطات شاشة الصفحة، وعمليات فحص واجهة المستخدم الشاملة، وفحص DevTools. لا يلزم استخدام Chrome DevTools MCP أو محرك الدمى أو الكاتب المسرحي.
