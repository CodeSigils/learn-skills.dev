Inspectez, déboguez et automatisez Chrome directement via le protocole Chrome DevTools (CDP). Utilisez cette compétence chaque fois qu'une tâche nécessite un véritable navigateur Web : ouvrez une URL, parcourez des pages, prenez une capture d'écran d'une page Web, lisez le DOM ou l'arborescence d'accessibilité, cliquez sur des boutons, remplissez et soumettez des formulaires, saisissez du texte, attendez des éléments, récupérez le contenu d'une page, évaluez JavaScript sur une page ou vérifiez les erreurs de la console et les requêtes réseau ayant échoué. Fonctionne avec Chrome local de l'utilisateur ou avec un point de terminaison de rendu de navigateur Cloudflare distant via WebSocket. Pertinent pour l'automatisation du navigateur, le web scraping, les captures d'écran de pages, les vérifications de l'interface utilisateur de bout en bout et l'inspection des DevTools. Aucun Chrome DevTools MCP, Puppeteer ou Playwright n'est requis.
