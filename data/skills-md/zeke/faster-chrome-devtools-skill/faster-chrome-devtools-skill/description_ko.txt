Chrome DevTools Protocol(CDP)을 통해 직접 Chrome을 검사, 디버그, 자동화하세요. 작업에 실제 웹 브라우저가 필요할 때마다 이 기술을 사용하십시오. URL 열기, 페이지 탐색, 웹 페이지 스크린샷 찍기, DOM 또는 접근성 트리 읽기, 버튼 클릭, 양식 채우기 및 제출, 텍스트 입력, 요소 대기, 페이지 콘텐츠 스크랩, 페이지에서 JavaScript 평가, 콘솔 오류 및 실패한 네트워크 요청 확인 등이 가능합니다. WebSocket을 통해 사용자의 로컬 Chrome 또는 원격 Cloudflare Browser Rendering 엔드포인트에 대해 작동합니다. 브라우저 자동화, 웹 스크래핑, 페이지 스크린샷, 엔드투엔드 UI 검사 및 DevTools 검사와 관련됩니다. Chrome DevTools MCP, Puppeteer 또는 Playwright가 필요하지 않습니다.
