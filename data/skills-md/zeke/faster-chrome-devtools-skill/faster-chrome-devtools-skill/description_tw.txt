直接透過 Chrome 開發工具協定 (CDP) 檢查、調試和自動化 Chrome。每當任務需要真正的 Web 瀏覽器時，請使用此技能：打開 URL、導航頁面、截取網頁螢幕截圖、讀取 DOM 或可訪問性樹、單擊按鈕、填寫和提交表單、鍵入文字、等待元素、抓取頁面內容、評估頁面上的 JavaScript，或檢查控制台錯誤和失敗的網頁請求。透過 WebSocket 針對使用者的本機 Chrome 或遠端 Cloudflare 瀏覽器渲染端點進行工作。與瀏覽器自動化、網頁抓取、頁面螢幕截圖、端到端 UI 檢查和 DevTools 檢查相關。無需 Chrome DevTools MCP、Puppeteer 或 Playwright。
