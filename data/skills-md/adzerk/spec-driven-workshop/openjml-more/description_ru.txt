Напишите спецификации JML (язык моделирования Java) для программ Java и проверьте их с помощью OpenJML. Охватывает полный рабочий процесс: написание спецификаций, выполнение статической проверки (ESC) и проверки утверждений во время выполнения (RAC), интерпретацию результатов проверки и отладку сбоев.
