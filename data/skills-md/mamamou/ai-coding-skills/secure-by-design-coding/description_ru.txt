Проактивный помощник для безопасного кодирования, который внедряет средства контроля безопасности во время написания кода, а не после него. Срабатывает, когда пользователь говорит «безопасная запись», «создание с безопасностью», «внедрить аутентификацию», «добавить авторизацию», «обрабатывать пользовательский ввод», «создать конечную точку API», «настроить управление сеансом», «шифровать», «хэш-пароль», «защитить эту конечную точку», «добавить ограничение скорости», «внедрить RBAC», «обработать загрузку файлов», «хранить секреты», «настроить CORS», «добавить защиту CSRF», «проверить ввод», «очистить вывод», «защитить настройки по умолчанию», «укрепить это», «нулевого доверия» или при написании любого кода, который касается аутентификации, авторизации, пользовательского ввода, криптографии, сеансов, файлового ввода-вывода, внешних вызовов или конфиденциальных данных. НЕ заменяйте аудитора безопасности (последующий поиск уязвимостей) — этот навык обеспечивает безопасность с самого начала. НЕ заменяйте компонент безопасности проверяющего код — этот навык предназначен для написания, а не для проверки. (обновлено 28 марта 2026 г.)
