GitButler を使用して、コミット、プッシュ、ブランチ、およびバージョン管理を管理します。コミット、選択的なダーティ ファイルまたはハンク コミット、ブランチ、差分、PR、履歴編集、スカッシュ、修正、元に戻す、マージ、適用、および適用解除に使用します。選択したダーティ ファイルまたはハンクについては、「but diff」を使用して検査します。コミット順序、ブランチ/スタックの配置、競合の概要にはコンパクトな「but status」を使用します。ファイル/ハンク ID またはコミットごとのファイルの詳細が重要な場合は、「but status -fv」を使用してください。 git write コマンドを置き換えます。
