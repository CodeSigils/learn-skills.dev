الالتزام بالتحكم في الإصدار ودفعه وتفرعه وإدارته باستخدام GitButler. يستخدم للالتزامات، أو الملفات القذرة الانتقائية أو الالتزامات الكبيرة، أو الفروع، أو الاختلافات، أو العلاقات العامة، أو تعديلات التاريخ، أو السحق، أو التعديل، أو التراجع، أو الدمج، أو التطبيق، أو عدم التطبيق. بالنسبة للملفات أو الكتل القذرة المحددة، قم بفحصها باستخدام `but diff`؛ استخدم "لكن الحالة" المضغوطة لأمر الالتزام أو وضع الفرع/المكدس أو نظرة عامة على التعارض؛ استخدم "لكن الحالة -fv" عندما تكون معرفات الملف/القطعة الكبيرة أو تفاصيل الملف لكل التزام مهمة. يستبدل أوامر الكتابة git.
