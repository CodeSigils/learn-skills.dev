Validez, poussez, créez des branches et gérez le contrôle de version avec GitButler. À utiliser pour les validations, les validations sélectives de fichiers sales ou de morceaux, les branches, les différences, les PR, les modifications d'historique, les écrasements, les modifications, l'annulation, la fusion, l'application et la désapplication. Pour les fichiers ou morceaux sales sélectionnés, inspectez avec « mais diff » ; utilisez compact « mais statut » pour l'ordre de validation, le placement de branche/pile ou l'aperçu des conflits ; utilisez « mais status -fv » lorsque les identifiants de fichiers/morceaux ou les détails de fichiers par validation sont importants. Remplace les commandes git write.
