Effettua il commit, il push, il branch e la gestione del controllo della versione con GitButler. Utilizzare per commit, commit selettivi di file sporchi o blocchi, rami, differenze, PR, modifiche della cronologia, schiacciamenti, modifiche, annullamento, unione, applicazione e annullamento dell'applicazione. Per file o pezzi sporchi selezionati, ispeziona con "but diff"; utilizzare il compatto `but status` per l'ordine di commit, il posizionamento di rami/stack o la panoramica dei conflitti; utilizzare `but status -fv` quando sono importanti gli ID di file/hunk o i dettagli del file per commit. Sostituisce i comandi git write.
