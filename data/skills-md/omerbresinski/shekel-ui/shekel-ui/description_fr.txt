Système de conception pour créer des applications Web chaleureuses de style éditorial. Dispositions de grille scellées, typographie Newsreader/Nunito Sans/Cascadia Code, jetons de couleur oklch et modèles de composants détaillés. Étend shadcn/ui. À utiliser lors de la création ou de la modification d'une interface utilisateur : tableaux de bord, vues maître-détails, tableaux, graphiques ou toute application Web.
