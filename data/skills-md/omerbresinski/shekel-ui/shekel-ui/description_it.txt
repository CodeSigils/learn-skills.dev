Sistema di progettazione per la creazione di applicazioni web accattivanti in stile editoriale. Layout a griglia sigillati, tipografia del codice Newsreader/Nunito Sans/Cascadia, gettoni di colore oklch e modelli di componenti dettagliati. Estende shadcn/ui. Da utilizzare durante la creazione o la modifica di qualsiasi interfaccia utente: dashboard, viste master-detail, tabelle, grafici o qualsiasi applicazione web.
