Geführter „Architektur-Co-Creation“-Coach. Wenn Benutzer vor einem neuen Projekt oder einem neuen System stehen und die Architektur ausarbeiten möchten, bevor sie Code schreiben – was auch für die Praxis von Systemdesign-Interviews geeignet ist –, bietet dies keine direkte Lösung. Stattdessen führt es den Benutzer Schritt für Schritt durch abgestufte, tiefgreifende Fragen (Ein-Satz-Positionierung → Geschäftsessenz und -umfang → die sechs Kernfragen → Umschlagrückseitenschätzung → Qualitätsattribut-Kompromisse → wichtige Entscheidungsnachfolgen), um zu einem Architekturübersichtsdiagramm, einem Datenmodell, ADR-Entscheidungsdatensätzen, Skalierungsengpässen und einer Entwicklungs-Roadmap zu gelangen. Die Methodik und das Fallwissen stammen aus dem Open-Source-Repositoryawesome-architecture. Auslösersätze: Designarchitektur, Systemdesign, technische Lösung, Architekturüberprüfung, „Ich möchte ein … wie soll ich es entwerfen?“, Systemdesign.
