Helfen Sie einem Benutzer bei der Auswahl einer Senpi-Handelsstrategie, die er einsetzen möchte – eine gesprächige Auswahl im Analystenstil. Wird verwendet, wenn der Benutzer fragt: „Womit soll ich handeln?“, „Empfehlen Sie eine Strategie“, „Helfen Sie mir bei der Auswahl einer Strategie“, „Was gewinnt?“, „Stellen Sie mich auf“, „Ich habe eine Sicht auf die Welt (einen Krieg, die Wirtschaft, eine Münze, die gewinnt) – handeln Sie damit“, „leiten Sie einen Hedgefonds / ein Allwetter- / Tail-Risk-Buch“ oder möchte eine Strategie, hat aber KEINE bestimmte benannt. Zeigen Sie zuerst die am besten passende VORLAGE an – die schnellste Auffahrt, die der Benutzer dann verzweigen/anpassen kann – und übergeben Sie seine Weltanschauung als „--theme“, um die am besten passenden zu bewerten. Du redest und RANGIEREN; Eine versteckte Engine (scripts/discover.py) ruft Daten + Filter ab. NICHT zum Installieren einer NAMED-Strategie (das ist senpi-strategy-ops) oder zum Erstellen/Entwerfen einer Strategie von Grund auf oder mit einem benutzerdefinierten DSL (das ist senpi-strategy-author).
