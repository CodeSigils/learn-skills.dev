Configurez, déployez et gérez Senpi Trading Runtime (plugin OpenClaw @senpi-ai/runtime) pour un suivi automatisé de la position en chaîne avec une protection stop-loss suiveur DSL. À utiliser lorsqu'un utilisateur doit créer ou modifier des fichiers YAML d'exécution, configurer les paramètres du moteur de sortie DSL (Dynamic Stop-Loss) (phases, niveaux, coupes basées sur le temps), configurer le scanner position_tracker pour surveiller les positions d'un portefeuille sur Hyperliquid, installer/répertorier/supprimer les environnements d'exécution via CLI ou inspecter les positions suivies par DSL. Le runtime ne crée PAS de portefeuilles stratégiques ; créez/obtenez d'abord le portefeuille de stratégie via Senpi MCP, puis liez ce portefeuille existant dans l'environnement d'exécution YAML. Se déclenche sur les mentions de senpi, du runtime Senpi, de la sortie DSL, des niveaux stop-loss, du suivi de position, du trailing stop, d'openclaw senpi, dsl_preset ou de la configuration de la stratégie YAML."
