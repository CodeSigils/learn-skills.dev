Senpi Trading Runtime (OpenClaw プラグイン @senpi-ai/runtime) を設定、展開、管理して、DSL トレーリング ストップロス保護を備えた自動オンチェーン ポジション追跡を実現します。ユーザーがランタイム YAML ファイルの作成または変更、DSL (ダイナミック ストップロス) 出口エンジン パラメーター (フェーズ、層、時間ベースのカット) の構成、Hyperliquid 上のウォレットのポジションを監視するためのposition_tracker スキャナーの設定、CLI 経由でランタイムのインストール/リスト/削除、または DSL 追跡ポジションの検査が必要な場合に使用します。ランタイムはストラテジーウォレットを作成しません。まず Senpi MCP 経由でストラテジーウォレットを作成/取得し、次にその既存のウォレットをランタイム YAML でリンクします。 senpi、Senpi ランタイム、DSL exit、ストップロス層、ポジション トラッカー、トレーリング ストップ、openclaw senpi、dsl_preset、またはストラテジー YAML 設定の言及によってトリガーされます。
