Configure, implemente y administre Senpi Trading Runtime (complemento OpenClaw @senpi-ai/runtime) para el seguimiento automatizado de posiciones en la cadena con protección DSL trailing stop-loss. Úselo cuando un usuario necesita crear o modificar archivos YAML en tiempo de ejecución, configurar los parámetros del motor de salida DSL (Dynamic Stop-Loss) (fases, niveles, cortes basados ​​en tiempo), configurar el escáner position_tracker para monitorear las posiciones de una billetera en Hyperliquid, instalar/enumerar/eliminar tiempos de ejecución a través de CLI o inspeccionar posiciones rastreadas por DSL. El tiempo de ejecución NO crea carteras estratégicas; Primero cree/obtenga la billetera de estrategia a través de Senpi MCP, luego vincule esa billetera existente en YAML en tiempo de ejecución. Se activa al mencionar senpi, tiempo de ejecución de Senpi, salida de DSL, niveles de stop-loss, rastreador de posición, stop dinámico, openclaw senpi, dsl_preset o configuración de estrategia YAML.
