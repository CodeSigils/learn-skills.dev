Настраивайте, развертывайте и управляйте средой Senpi Trading Runtime (плагин OpenClaw @senpi-ai/runtime) для автоматического отслеживания позиций в цепочке с защитой скользящего стоп-лосса DSL. Используйте, когда пользователю необходимо создать или изменить файлы YAML времени выполнения, настроить параметры механизма выхода DSL (динамический стоп-лосс) (фазы, уровни, сокращения по времени), настроить сканер Position_tracker для мониторинга позиций кошелька в Hyperliquid, установить/списать/удалить среды выполнения через CLI или проверить позиции, отслеживаемые DSL. Среда выполнения НЕ создает стратегические кошельки; Сначала создайте/получите стратегический кошелек через Senpi MCP, а затем свяжите этот существующий кошелек в YAML во время выполнения. Срабатывает при упоминании senpi, среды выполнения Senpi, выхода DSL, уровней стоп-лосса, отслеживания позиций, трейлинг-стопа, openclaw senpi, dsl_preset или конфигурации стратегии YAML».
