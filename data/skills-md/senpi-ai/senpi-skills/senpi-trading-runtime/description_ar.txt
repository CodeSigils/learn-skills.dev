قم بتكوين ونشر وإدارة Senpi Trading Runtime (المكون الإضافي OpenClaw @senpi-ai/runtime) لتتبع المراكز تلقائيًا على السلسلة مع حماية وقف الخسارة لـ DSL. يُستخدم عندما يحتاج المستخدم إلى إنشاء ملفات YAML لوقت التشغيل أو تعديلها، أو تكوين معلمات محرك الخروج DSL (إيقاف الخسارة الديناميكي) (المراحل، والطبقات، والتخفيضات المستندة إلى الوقت)، وإعداد الماسح الضوئي Position_tracker لمراقبة مواضع المحفظة على Hyperliquid، أو تثبيت/قائمة/حذف أوقات التشغيل عبر CLI، أو فحص المواضع التي يتم تتبعها بواسطة DSL. وقت التشغيل لا ينشئ محافظ استراتيجية؛ قم بإنشاء/احصل على محفظة الإستراتيجية عبر Senpi MCP أولاً، ثم قم بربط تلك المحفظة الموجودة في وقت التشغيل YAML. يتم تشغيله عند الإشارة إلى senpi، أو وقت تشغيل Senpi، أو خروج DSL، أو مستويات إيقاف الخسارة، أو متعقب المراكز، أو الإيقاف المتحرك، أو openclaw senpi، أو dsl_preset، أو تكوين إستراتيجية YAML."
