Configura, distribuisci e gestisci Senpi Trading Runtime (plug-in OpenClaw @senpi-ai/runtime) per il monitoraggio automatizzato della posizione sulla catena con protezione trailing stop-loss DSL. Da utilizzare quando un utente deve creare o modificare file YAML runtime, configurare i parametri del motore di uscita DSL (Dynamic Stop-Loss) (fasi, livelli, tagli basati sul tempo), impostare lo scanner position_tracker per monitorare le posizioni di un portafoglio su Hyperliquid, installare/elencare/eliminare runtime tramite CLI o ispezionare le posizioni tracciate DSL. Il runtime NON crea portafogli strategici; crea/ottieni prima il portafoglio strategico tramite Senpi MCP, quindi collega il portafoglio esistente in YAML runtime. Si attiva su menzioni di senpi, runtime Senpi, uscita DSL, livelli stop-loss, tracker di posizione, trailing stop, openclaw senpi, dsl_preset o configurazione YAML della strategia."
