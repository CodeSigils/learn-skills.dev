Разверните/мониторьте/закройте торговую стратегию NAMED Senpi. Используйте, когда пользователь называет стратегию для запуска — «установить паука», «развернуть полярную», «настроить кадьяк», «запустить стратегию паука», «действительна ли моя стратегия?», «что я использую», «перечислить мои стратегии» (→ status.py), «защищены ли мои позиции? / есть ли у них стоп-лосс (DSL)?», «остановить/закрыть/удалить полярную» — и для удаления, например «закрыть все стратегии», «вернуть средства в основную», «снести все» (→ close.py --все). ВСЕГДА отключайте файл close.py, а не необработанный файл Strategy_close (который ухудшает работу среды выполнения). Стратегия — это ПАКЕТ (strategy.yaml + один runtime.yaml на каждый экземпляр + сканеры/), который среда выполнения контролирует в процессе — без демона сканера. Deploy.py выполняет три возобновляемых шага (создание → время выполнения → проверка); close.py срывается (остановка выполнения + Strategy_close → выравнивает позиции, возвращает средства). Идентификатор (паук, поляр, кадьяк) — это папка пакета. НЕ для выбора КАКОЙ стратегии (senpi-strategy-discover) или ее создания/редактирования (senpi-strategy-author).
