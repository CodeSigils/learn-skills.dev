Déployer/surveiller/clôturer une stratégie de trading NAMED Senpi. À utiliser lorsque l'utilisateur nomme une stratégie à exécuter — « installer spider », « déployer polar », « configurer kodiak », « exécuter la stratégie spider », « ma stratégie est-elle en ligne ? », « qu'est-ce que j'exécute », « lister mes stratégies » (→ status.py), « mes positions sont-elles protégées ? --tous). TOUJOURS détruire via close.py, jamais une stratégie_close brute (qui bloque le runtime). Une stratégie est un PACKAGE (strategy.yaml + un runtime.yaml par instance + scanners/) que le runtime supervise en cours de processus – pas de démon scanner. déployer.py exécute trois étapes pouvant être reprises (créer → exécution → vérifier) ; close.py démolit (stop runtime + stratégie_close → aplatit les positions, restitue les fonds). L'identifiant (spider, polar, kodiak) est le dossier du package. PAS pour choisir QUELLE stratégie (senpi-strategy-discover) ou en construire/éditer une (senpi-strategy-author).
