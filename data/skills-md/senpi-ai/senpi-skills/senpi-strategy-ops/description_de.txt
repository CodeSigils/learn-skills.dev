Implementieren/überwachen/schließen Sie eine NAMED Senpi-Handelsstrategie. Wird verwendet, wenn der Benutzer eine auszuführende Strategie benennt – „Spider installieren“, „Polar bereitstellen“, „Kodiak einrichten“, „Spider-Strategie ausführen“, „Ist meine Strategie aktiv?“, „Was führe ich aus“, „Meine Strategien auflisten“ (→ status.py), „Sind meine Positionen geschützt? / Haben sie einen Stop-Loss (DSL)?“, „Polar stoppen/schließen/deinstallieren“ – und für Teardowns wie „Alle Strategien schließen“, „Gelder an Main zurückgeben“, „Alles abreißen“ (→ close.py). --alle). IMMER über close.py herunterfahren, niemals über ein rohes strategy_close (das die Laufzeit blockiert). Eine Strategie ist ein PAKET (strategy.yaml + eine runtime.yaml pro Instanz + scanners/), das die Laufzeit im Prozess überwacht – kein Scanner-Daemon. Deploy.py führt drei wiederaufnehmbare Schritte aus (Erstellen → Laufzeit → Verifizieren). close.py bricht ab (Stopp-Laufzeit + strategy_close → glättet Positionen, gibt Geld zurück). Die ID (Spider, Polar, Kodiak) ist der Paketordner. NICHT, um WELCHE Strategie auszuwählen (senpi-strategy-discover) oder eine zu erstellen/bearbeiten (senpi-strategy-author).
