Implementar / monitorear / cerrar una estrategia comercial NOMBRE Senpi. Úselo cuando el usuario nombra una estrategia para ejecutar: "instalar spider", "implementar polar", "configurar kodiak", "ejecutar la estrategia spider", "¿está activa mi estrategia?", "¿qué estoy ejecutando", "enumerar mis estrategias" (→ status.py), "¿están protegidas mis posiciones? / ¿tienen un stop-loss (DSL)?", "detener/cerrar/desinstalar polar" - y para desmontajes como "cerrar todas las estrategias", "devolver fondos al principal", "derribar todo" (→ close.py --todos). SIEMPRE derribe a través de close.py, nunca una estrategia_close sin formato (que bloquea el tiempo de ejecución). Una estrategia es un PAQUETE (strategy.yaml + un runtime.yaml por instancia + escáneres/) que el tiempo de ejecución supervisa en el proceso, sin demonio de escáner. implementar.py ejecuta tres pasos reanudables (crear→tiempo de ejecución→verificar); close.py se derriba (detiene el tiempo de ejecución + estrategia_cierre → aplana posiciones, devuelve fondos). La identificación (spider, polar, kodiak) es la carpeta del paquete. NO para elegir QUÉ estrategia (senpi-estrategia-descubrir) o construir/editar una (senpi-estrategia-autor).
