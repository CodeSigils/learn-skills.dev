Sammlung von baserCMS-spezifischen Breaking Changes, Deprecations und Testinfrastrukturanpassungen für die Migration eines baserCMS-Plugins von der 5.2-Serie auf die 5.3-Serie (PHP8.5/CakePHP5.2.x-basiert, in Entwicklung). Enthält Rezepte wie „Plugin mit 5.3 kompatibel machen“, „baserCMS5.3-Migration“, „PluginCollection::create(): $config null gegeben“, „Plugin mit dem Namen (TreeBehavior+Content-Fixture)“, „validateUnique(): Argument Nr. 2 nicht übergeben (CakePHP-Doppellast des Anbieters)“, „MissingTemplateException masked by error500.php in Tests“, „BcFile-Konstruktor/delete()-Pfadargument veraltet“ usw., die bei der Migration des Plugin-Kerns und der Testinfrastruktur berücksichtigt werden müssen. Dies ist eine Fertigkeit für ein kleineres Upgrade innerhalb derselben Hauptversion (5.2→5.3); Für das große Upgrade von baserCMS4 auf 5 (vollständige Neufassung von CakePHP2 auf 5) siehe basercms‑plugin‑4‑auf‑5‑upgrade. Informationen zu PHP-Core-bezogenen Problemen finden Sie unter PHP-Migration, zu CakePHP-Core-bezogenen Problemen finden Sie unter CakePHP-Migration und zu Testausführungsverfahren finden Sie Informationen zum basercms-unittest-Skill. Wenn Sie eine neue baserCMS-Version unterstützen, fügen Sie diesem Dokument versionspezifische Einträge hinzu.
