Raccolta di modifiche sostanziali, deprecazioni e adattamenti dell'infrastruttura di test specifici di baserCMS per la migrazione di un plugin baserCMS dalla serie 5.2 alla serie 5.3 (basato su PHP8.5/CakePHP5.2.x, in fase di sviluppo). Include ricette come "Rendi il plugin compatibile con 5.3", "migrazione baserCMS5.3", "PluginCollection::create(): $config null specificato", "Il plugin denominato X è già caricato (test di integrazione)", "BcApp.testAppPluginsToLoad", "plugins.php null → []", "ClassBcCcFile... non trovato (sotto-plugin non caricato)", "Impossibile impostare il genitore di un nodo come se stesso (TreeBehavior+Content fixture)”, “validateUnique(): Argument #2 not passed (vendor's CakePHP double‑load)”, “MissingTemplateException mascherato da error500.php nei test”, “BcFile costruttore/delete() argomento del percorso deprecato”, ecc., da consultare durante la migrazione del core del plugin e dell'infrastruttura di test. Questa è un'abilità per un aggiornamento minore all'interno della stessa versione principale (5.2→5.3); per l'aggiornamento principale da baserCMS4 a 5 (riscrittura completa da CakePHP2 a 5) vedere basercms‑plugin‑4‑to‑5‑upgrade. Per le questioni relative a PHP‑core fare riferimento a php‑migration, per le questioni relative a CakePHP‑core fare riferimento a cakephp‑migration e per le procedure di esecuzione dei test fare riferimento alla competenza basercms‑unittest. Quando supporti una nuova versione di baserCMS, aggiungi voci specifiche della versione a questo documento.
