Collection de modifications de rupture, de dépréciations et d'adaptations de l'infrastructure de test spécifiques à baserCMS pour la migration d'un plugin baserCMS de la série 5.2 vers la série 5.3 (basé sur PHP8.5/CakePHP5.2.x, en cours de développement). Inclut des recettes telles que « Rendre le plugin compatible avec 5.3 », « migration baserCMS5.3 », « PluginCollection::create() : $config null donné », « Le plugin nommé X est déjà chargé (test d'intégration) », « BcApp.testAppPluginsToLoad », « plugins.php null → [] », « ClassBcCcFile… introuvable (sous-plugin non chargé) », « Impossible de définir le parent d'un nœud comme lui-même (TreeBehavior+Content luminaire)", "validateUnique() : Argument #2 not transmis (double chargement CakePHP du fournisseur)", "MissingTemplateException masqué par error500.php dans les tests", "BcFile constructor/delete() path argument obsolète", etc., à consulter lors de la migration du noyau du plugin et de l'infrastructure de test. Il s'agit d'une compétence pour une mise à niveau mineure au sein de la même version majeure (5.2→5.3) ; pour la mise à niveau majeure de baserCMS4 vers 5 (réécriture complète de CakePHP2 vers 5), voir basercms‑plugin‑4‑to‑5‑upgrade. Pour les problèmes liés à PHP-core, reportez-vous à php-migration, pour les problèmes liés à CakePHP-core, reportez-vous à cakephp-migration, et pour les procédures d'exécution de tests, reportez-vous à la compétence basercms-unittest. Lors de la prise en charge d'une nouvelle version de baserCMS, ajoutez des entrées spécifiques à la version à ce document.
