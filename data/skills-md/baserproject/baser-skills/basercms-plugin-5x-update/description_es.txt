Colección de cambios importantes, obsolescencias y adaptaciones de infraestructura de prueba específicos de baserCMS para migrar un complemento de baserCMS de la serie 5.2 a la serie 5.3 (basado en PHP8.5/CakePHP5.2.x, en desarrollo). Esta es una habilidad para una actualización menor dentro de la misma versión principal (5.2→5.3); para la actualización principal de baserCMS4 a 5 (reescritura completa de CakePHP2 a 5), ​​consulte basercms‑plugin‑4‑to‑5‑upgrade. Para problemas relacionados con PHP-core, consulte php-migration, para problemas relacionados con CakePHP-core, consulte cakephp-migration y para procedimientos de ejecución de pruebas, consulte la habilidad basercms-unittest. Cuando admita una nueva versión de baserCMS, agregue entradas específicas de la versión a este documento.
