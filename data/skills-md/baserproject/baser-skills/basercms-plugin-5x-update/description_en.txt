Collection of baserCMS‑specific breaking changes, deprecations, and test‑infrastructure adaptations for migrating a baserCMS plugin from the 5.2 series to the 5.3 series (PHP 8.5 / CakePHP 5.2.x based, under development). Includes recipes such as “Make the plugin compatible with 5.3”, “baserCMS 5.3 migration”, “PluginCollection::create(): $config null given”, “Plugin named X is already loaded (integration test)”, “BcApp.testAppPluginsToLoad”, “plugins.php null → []”, “Class BcCcFile… not found (sub‑plugin not loaded)”, “Cannot set a node’s parent as itself (TreeBehavior + Content fixture)”, “validateUnique(): Argument #2 not passed (vendor’s CakePHP double‑load)”, “MissingTemplateException masked by error500.php in tests”, “BcFile constructor/delete() path argument deprecated”, etc., to be consulted when migrating the plugin core and test infrastructure. This is a skill for a minor upgrade within the same major version (5.2 → 5.3); for the major upgrade from baserCMS 4 to 5 (full rewrite from CakePHP 2 to 5) see basercms‑plugin‑4‑to‑5‑upgrade. For PHP‑core‑related issues refer to php‑migration, for CakePHP‑core‑related issues refer to cakephp‑migration, and for test execution procedures refer to the basercms‑unittest skill. When supporting a new baserCMS version, add version‑specific entries to this document.
