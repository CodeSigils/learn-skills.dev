BaserCMS 特定的重大更改、棄用和測試框架調整的集合，用於將 baserCMS 插件從 5.2 系列遷移到 5.3 系列（基於 PHP8.5 / CakePHP5.2.x，正在開發中）。包括諸如「讓外掛程式與 5.3 相容」、「baserCMS5.3 遷移」、「PluginCollection::create(): $config null 給定」、「名為 X 的插件已載入（整合測試）」、「BcApp.testAppPluginsToLoad」、「plugins.Dphp null →」」BcApp.testAppPluginsToLoad」、「plugins.php null →」.Sphp null BFile.\php null....未找到（子外掛程式未載入）」、「無法設定節點的父級」等項目就像它本身（TreeBehavior + 內容固定裝置）」、「validateUnique()：參數 #2 未通過（供應商的 CakePHP 雙重載入）」、「MissingTemplateException 掩蓋了 error500.php 中測試函式路徑參數已棄用」等，在移動插件核心和測試框架時要參考。這是同大版本（5.2→5.3）內小更新的技能；對於baserCMS4→5的主要升級（從CakePHP2→5完全重寫），請參閱basercms-plugin-4-to-5-upgrade。 cakephp-migration 涵蓋，測試執行過程由 basercms-unittest 技能涵蓋。
