BaserCMS プラグインを 5.2 シリーズから 5.3 シリーズ (PHP8.5/CakePHP5.2.x ベース、開発中) に移行するための、baserCMS 固有の重大な変更、非推奨、およびテスト インフラストラクチャの適応のコレクション。 「プラグインを 5.3 と互換性のあるものにする」、「baserCMS5.3 への移行」、「PluginCollection::create(): $config null が指定されました」、「X という名前のプラグインはすでにロードされています (統合テスト)」、「BcApp.testAppPluginsToLoad」、「plugins.php null → []」、「ClassBcCcFile… 見つかりません (サブプラグインがロードされていません)」、「ノードの親をそれ自身として (TreeBehavior+Content fixture)」、「validateUnique(): Argument #2 not Passed (vendor's CakePHP double‑load)」、「テストの error500.php によってマスクされた MissingTemplateException」、「BcFile コンストラクター/delete() パス引数が非推奨になりました」など、プラグイン コアとテスト インフラストラクチャを移行するときに参照されます。これは、同じメジャー バージョン (5.2→5.3) 内のマイナー アップグレード用のスキルです。 BaserCMS4 から 5 へのメジャー アップグレード (CakePHP2 から 5 への完全な書き換え) については、basercms‑plugin‑4‑to‑5‑upgrade を参照してください。 PHP コア関連の問題については php-migration を参照、CakePHP コア関連の問題については Cakephp-migration を参照、テスト実行手順についてはbasercms-unittest スキルを参照してください。新しいbaserCMSバージョンをサポートする場合は、このドキュメントにバージョン固有のエントリを追加してください。
