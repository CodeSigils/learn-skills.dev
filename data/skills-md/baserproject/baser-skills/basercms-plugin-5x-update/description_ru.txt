Коллекция критических изменений, устаревших и адаптаций тестовой инфраструктуры для baserCMS для миграции плагина baserCMS из серии 5.2 в серию 5.3 (на основе PHP8.5/CakePHP5.2.x, в стадии разработки). Включает такие рецепты, как «Сделать плагин совместимым с 5.3», «миграция в baserCMS5.3», «PluginCollection::create(): задано значение $config null», «Плагин с именем X уже загружен (интеграционный тест)», «BcApp.testAppPluginsToLoad», «plugins.php null → []», «Класс BcCcFile… не найден (субплагин не загружен)», «Невозможно установить родительский элемент узла как самого себя». (TreeBehavior+Content)», «validateUnique(): Аргумент #2 не передан (двойная загрузка CakePHP поставщика)», «MissingTemplateException маскирует реальную причину теста в error500.php», «Аргумент пути конструктора BcFile / delete() устарел» и т. д., с которыми следует обращаться при миграции ядра плагина и тестовой базы. Это навык для незначительного обновления одной основной версии (5.2→5.3); для основного обновления с baserCMS4 до 5 (полная перезапись с CakePHP2 до 5) см. baseercms-plugin-4-to-5-upgrade. Проблемы, возникающие из ядра PHP, решаются с помощью php-миграции, проблемы из ядра CakePHP — с помощью Cakephp-миграции, а процедуры выполнения тестов — с помощью навыка baseercms-unittest. При поддержке новой версии baserCMS добавьте в этот документ записи, относящиеся к конкретной версии.
