Коллекция критических изменений, устаревших версий и адаптаций тестовой инфраструктуры для baserCMS для миграции плагина baserCMS из серии 5.2 в серию 5.3 (на основе PHP8.5/CakePHP5.2.x, в стадии разработки). Включает в себя такие рецепты, как «Сделать плагин совместимым с 5.3», «миграция baserCMS5.3», «PluginCollection::create(): задано значение $config null», «Плагин с именем X уже загружен (интеграционный тест)», «BcApp.testAppPluginsToLoad», «plugins.php null → []», «ClassBcCcFile… не найден (субплагин не загружен)», «Невозможно установить родительский элемент узла как сам (фиксация TreeBehavior+Content)», «validateUnique(): Аргумент #2 не передан (двойная загрузка CakePHP поставщика)», «MissingTemplateException, маскируемый error500.php в тестах», «Аргумент пути BcFile конструктора/delete() устарел» и т. д., с которыми следует обращаться при миграции ядра плагина и тестовой инфраструктуры. Это навык для незначительного обновления одной основной версии (5.2→5.3); для основного обновления с baserCMS4 до 5 (полная перезапись с CakePHP2 до 5) см. basercms-plugin-4-to-5-upgrade. Для решения проблем, связанных с ядром PHP, обратитесь к php-миграции, для проблем, связанных с ядром CakePHP, обратитесь к CakePHP-миграции, а для процедур выполнения тестов обратитесь к навыку basercms-unittest. При поддержке новой версии baserCMS добавьте в этот документ записи, относящиеся к конкретной версии.
