Коллекция шаблонов для миграции тем baserCMS4 (шаблоны/макет, элемент, шаблоны блога/страниц/почты плюс несколько помощников) в плагины тем baserCMS5. Ссылки включают в себя «перенос темы с 4 на 5», «ручные настройки после преобразования темы с помощью BcAddonMigrator», «устаревшая siteConfig[]», «устаревшая fullUrl()», «проверка методов быстрого доступа, таких как blogPosts()», «миграция шаблонов почтовых форм (серия Mailform → BcBaser mailForm)», «виджеты элементов виджета → виджет», «пустые переменные представления», «устаревшая params[Content]», «встроенная форма второго аргумента для css()/js()», «популярное изображение 404», «отсутствует базовый URL-адрес при установке в подкаталог» и т. д. Он содержит шаблоны миграции для конкретных тем (тип TH) и конкретные примеры шаблонов ошибок внешнего интерфейса, связанных с рендерингом шаблона/темы (тип F). Этот навык направлен на обнаружение и преобразование идиом 4-й серии; Полным руководством по правильному кодированию тем 5-й серии является разработка темы basercms5. Внутренний код плагина (экраны контроллера/таблицы/сущности/администратора) см. в разделе basercms-plugin-4-to-5-upgrade, процедуры для всего сайта см. в basercms4-to-5-upgrade, а для выполнения тестов см. навык basercms-unittest.
