Collection of patterns for migrating baserCMS 4 themes (templates/layout, element, Blog/Pages/Mail templates plus a few helpers) to baserCMS 5 theme plugins. References include “migrate theme from 4 to 5,” “manual tweaks after theme conversion with BcAddonMigrator,” “deprecation of siteConfig[],” “deprecation of fullUrl(),” “verification of shortcut methods like blogPosts(),” “migration of mail‑form templates (Mailform → BcBaser mailForm series),” “widget element widgets → widget,” “empty view variables,” “deprecation of params[Content],” “inline second‑argument form for css()/js(),” “featured‑image 404,” “missing base URL when installed in a subdirectory,” etc. It contains theme‑specific migration patterns (TH‑type) and concrete example patterns of front‑end display errors related to template/theme rendering (F‑type). This skill focuses on detecting and converting 4‑series idioms; the definitive guide for proper 5‑series theme coding is basercms5‑theme‑development. For plugin internal code (Controller/Table/Entity/admin screens) see basercms‑plugin‑4‑to‑5‑upgrade, for site‑wide procedures see basercms4‑to‑5‑upgrade, and for test execution see the basercms‑unittest skill.
