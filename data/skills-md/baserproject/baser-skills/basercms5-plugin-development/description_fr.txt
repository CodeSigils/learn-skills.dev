Une collection de modèles canoniques pour développer ou modifier des plugins pour baserCMS 5 (basé sur CakePHP5). Reportez-vous à des éléments tels que « Créer un plugin », « cuire avec bc_plugin », « Ajouter un écran d'administration », « Écriture d'une table/entité », « Déclarer des associations lors de l'initialisation », « validationDefault », « Distinguer l'utilisation de fetchTable et de TableRegistry », « Écriture de BcAdminForm / control() », « Élément de formulaire de recherche », « Règles de génération d'identifiant/nom de contrôle et intégration JS », « Écouteurs d'événements (par exemple, BcModelEventListener), "Enregistrement de adminNavigation", "setting.php / config.php", "Enregistrement de BcShortCode", "paginate($query)", "Redirection en retour", "Enregistrement d'appartenanceToMany avec _ids", "BcKeyValue", "Garde de réentrée dans afterSave", "$.bcUtil.adminBaseUrl", "Modèles ICU pour Time::format", "RouteBuilder dans routes.php », etc. Les règles communes concernant l'environnement, les répertoires, la dénomination, l'interdiction des hacks de base, etc. sont documentées dans le développement basercms5 ; le développement du thème se fait dans basercms5-theme-development ; la migration de la série 4 vers la série 5 s'effectue dans basercms-plugin-4-to-5-upgrade ; et l'exécution des tests et la configuration de l'infrastructure de test sont inbasercms-unittest.
