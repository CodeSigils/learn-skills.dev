مجموعة من الأنماط المهملة والتغييرات المعطلة مع وصفات الإصلاح لترقيات إصدار PHP الخاص بـ baserCMS (8.2، 8.4، 8.5، وما إلى ذلك). استخدمه عند التحقيق في تحذيرات/أخطاء الترقية التي تسببها PHP الأساسية أو إصلاحها، مثل "تحذير الإهمال الضمني الفارغ"، "تم إهمال إنشاء خاصية ديناميكية ..."، "تحذير هروب fgetcsv"، ""ReflectionProperty::setValue deprecation"،" "عمليات التحويل غير المتعارف عليها مثل (عدد صحيح)/(منطقي) مهمل"، "استخدام null كإزاحة مصفوفة مهملة"، "تم إهمال وظائف الإصدار التلقائي مثل curl_Close / imagedestroy"، وما إلى ذلك. عند دعم إصدار PHP جديد، أضف ملاحظات خاصة بالإصدار إلى هذا المستند. بالنسبة للمشكلات التي تنشأ من CakePHP نفسها، راجع مهارة ترحيل cakephp.
