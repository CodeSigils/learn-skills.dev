Коллекция шаблонов устаревших и критических изменений с рецептами исправлений для обновления baserCMS до более новых версий PHP (8.2, 8.4, 8.5 и т. д.). Используйте его в качестве справочного материала при изучении или исправлении предупреждений/ошибок обновления, возникающих в ядре PHP, таких как «неявное предупреждение об устаревании, допускающее значение NULL», «Создание динамического свойства… устарело», «предупреждение о выходе fgetcsv», «устаревшее ReflectionProperty::setValue», «нестандартные приведения типа (целое число)/(логическое значение) устарели», «использование значения null в качестве смещения массива устарело», «функции автоматического освобождения ресурсов, такие как curl_close/imagedestroy, устарели» и так далее. При поддержке новой версии PHP добавьте в этот документ примечания для конкретной версии. По вопросам, связанным с ядром CakePHP, обратитесь к специалисту по миграции cakephp.
