A collection of deprecated and breaking‑change patterns with fix recipes for baserCMS’s PHP version upgrades (8.2, 8.4, 8.5, etc.). Use it when investigating or fixing upgrade warnings/errors caused by the PHP core, such as “implicit nullable deprecation warning,” “Creation of dynamic property … is deprecated,” “fgetcsv escape warning,” “ReflectionProperty::setValue deprecation,” “non‑canonical casts like (integer)/(boolean) deprecated,” “using null as an array offset deprecated,” “automatic‑release functions such as curl_close / imagedestroy deprecated,” and so on. When supporting a new PHP version, add version‑specific notes to this document. For problems originating from CakePHP itself, refer to the cakephp‑migration skill.
