Eine Sammlung veralteter und Breaking-Change-Muster mit Korrekturrezepten für PHP-Versions-Upgrades von baserCMS (8.2, 8.4, 8.5 usw.). Verwenden Sie es, wenn Sie Upgrade-Warnungen/Fehler untersuchen oder beheben, die durch den PHP-Kern verursacht werden, wie z. B. „Warnung zur impliziten Nullable-Veraltung“, „Erstellung einer dynamischen Eigenschaft … ist veraltet“, „fgetcsv-Escape-Warnung“, „ReflectionProperty::setValue veraltet“, „nicht-kanonische Umwandlungen wie (integer)/(boolean) veraltet“, „Verwendung von Null als Array-Offset veraltet“, „Funktionen zur automatischen Freigabe“. wie „curl_close / imagedestroy deprecated“ und so weiter. Wenn Sie eine neue PHP-Version unterstützen, fügen Sie diesem Dokument versionspezifische Hinweise hinzu. Bei Problemen, die von CakePHP selbst herrühren, lesen Sie den Skill „Cakephp-Migration“.
