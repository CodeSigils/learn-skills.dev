Una raccolta di modelli obsoleti e con modifiche sostanziali con ricette di correzione per gli aggiornamenti della versione PHP di baserCMS (8.2, 8.4, 8.5, ecc.). Usatelo quando esaminate o correggete avvisi/errori di aggiornamento causati dal core PHP, come “avviso implicito di deprecazione di nullable”, “La creazione di proprietà dinamiche… è deprecato”, “avviso di escape fgetcsv”, “ReflectionProperty::setValue deprecato”, “cast non canonici come (intero)/(booleano) deprecato”, “utilizzo null come offset di array deprecato”, “funzioni di rilascio automatico come curl_close / imagedestroy deprecato" e così via. Quando supporti una nuova versione PHP, aggiungi note specifiche della versione a questo documento. Per problemi originati da CakePHP stesso, fare riferimento alla skill di migrazione di cakephp.
