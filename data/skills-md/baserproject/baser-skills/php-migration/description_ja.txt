BaserCMS の PHP バージョン アップグレード (8.2、8.4、8.5 など) の修正レシピを含む、非推奨のパターンと破壊的変更パターンのコレクション。 「暗黙的な null 許容非推奨の警告」、「動的プロパティの作成…は非推奨」、「fgetcsv エスケープ警告」、「ReflectionProperty::setValue の非推奨」、「(整数)/(ブール) などの非正規キャストは非推奨」、「配列オフセットとしての null の使用は非推奨」など、PHP コアによって引き起こされるアップグレードの警告/エラーを調査または修正するときに使用します。 「curl_close / imagedestroy などの自動解放関数は非推奨になりました」など。新しい PHP バージョンをサポートする場合は、このドキュメントにバージョン固有の注記を追加してください。 CakePHP 自体に起因する問題については、cakephp の移行スキルを参照してください。
