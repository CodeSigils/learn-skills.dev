Коллекция конкретных шаблонов перезаписи для контроллеров, таблиц, сущностей, представлений, помощников, форм, Vue и JavaScript при переносе внутреннего кода плагина из baserCMS4 (на основе CakePHP2) в baserCMS5 (на основе CakePHP5). Включает такие шаблоны, как «перенос плагина с 4 на 5», «перемещение методов admin_ в Controller/Admin», «изменение public $belongsTo/$hasMany на Initialize()», «ClassRegistry/TableRegistry», «преобразование find(all/first/list, arrays) в построитель запросов», «изменение $this->Model (null) на fetchTable», «единственное число во множественное для getControlSource», «замена $this->Form на BcAdminForm·control()», «поиск в форме поиска/ → search/», «FormHelper::create string model → null», «устаревший FormHelper::year()/month()/domId()», «шаблоны ICU для Time::format», «запрет нулевого значения в Number::format/Text::truncate», «нет автоматического IN для условий массива; null становится IS», «изменение URL-адреса администратора в Vue/JS в $.bcUtil.adminBaseUrl и пересоздание с помощью веб-пакета», «$this->data / $View->request вызывает неправильную загрузку помощника», «MissingTableClassException / MissingHelperException / Поставщик контекста не найден», «App::import внешние библиотеки, связанные с поставщиком (например, Leafo/scssphp), не перенесены в серию 5 и, следовательно, нефункциональны», и «Несовместимости PHP8 в старых встроенных библиотеках, такие как удаленная функцияeach() или неверные экранированные выражения регулярных выражений». Этот ресурс используется для систематического исправления каждой ошибки в экранах плагинов, моделях, шаблонах и дисплеях внешнего интерфейса. Навык направлен на обнаружение и преобразование идиом 4-й серии; Авторитетным руководством по правильному синтаксису 5-й серии является документация по разработке плагинов basercms5. Процедуры миграции 4→5 в масштабе всего сайта (установка, миграция БД, этапы преобразования темы/плагина, рабочий процесс Git) см. в разделе basercms4-to-5-upgrade; для темы (ориентированной на шаблоны) миграции см. basercms-theme-4-to-5-upgrade; для перехода с версии 5.2→5.3 см. basercms-plugin-5x-update; по вопросам, связанным с ядром CakePHP, см. cakephp-migration; проблемы, связанные с ядром PHP, см. в разделе php-миграция; для запуска тестов см. basercms-unittest; а для переноса надстроек настраиваемых полей для блогов и аналогичных bc-custom-content обратитесь к навыку разработки basercms5-custom-content-development.
