Коллекция конкретных шаблонов перезаписи для контроллеров, таблиц, сущностей, представлений, помощников, форм, Vue/JS при переносе внутреннего кода плагина из baserCMS4 (на основе CakePHP2) в baserCMS5 (на основе CakePHP5). Включает такие шаблоны, как «перенос плагина с 4 на 5», «методы admin_ в Controller/Admin», «public $belongsTo/$hasMany для инициализации()», «ClassRegistry/TableRegistry», «find(all/first/list, array) для построения запросов», «$this->Model (null) для fetchTable», «getControlSource в единственном числе → множественное», «$this->Form для BcAdminForm·control()», «поиск форм поиска/→search/», «FormHelper::create string model→null», «FormHelper::year()/month()/domId() устарел», «Time::format ICU шаблоны», «Number::format/Text::truncate не может быть нулевым», «условие массива IN не добавляется автоматически; ноль становится IS», «URL администратора Vue/JS для $.bcUtil.adminBaseUrl + перестройка веб-пакета», «$this->data / $View->request вызывает неправильную загрузку помощника», «MissingTableClassException / MissingHelperException / Поставщик контекста не найден», «App::import внешние библиотеки, связанные как Vendor (leafo/scssphp и т. д.), не перенесены в версию 5 и, следовательно, мертвы», «Удаление PHP8each() и неправильное экранирование регулярных выражений и т. д., старая версия встроенные библиотеки, несовместимые с PHP8» и т. д., с которыми нужно обращаться при исправлении каждой ошибки в пользовательском интерфейсе, модели, шаблоне и внешнем интерфейсе плагина одну за другой. Этот навык направлен на обнаружение и преобразование идиом 4.x; Полное руководство по правильному кодированию 5.x — basercms5-plugin-development. Шаги миграции всего сайта с 4 по 5 (установка/миграция базы данных/преобразование тем и плагинов/рабочий процесс Git) находятся в basercms4-to-5-upgrade, миграция тем (ориентированных на шаблоны) в basercms-theme-4-to-5-upgrade, миграция плагинов из 5.2→5.3 в basercms-plugin-5x-update, основные проблемы CakePHP в cakephp-migration, проблемы ядра PHP в php-migration, выполнение теста в basercms-unittest, а при переносе плагинов надстроек настраиваемых полей для блогов и т. д. в bc-custom-content см. basercms5-custom-content-development.
