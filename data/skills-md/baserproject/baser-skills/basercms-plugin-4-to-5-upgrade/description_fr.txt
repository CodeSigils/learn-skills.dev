Une collection de modèles de réécriture concrets pour les contrôleurs, tables, entités, vues, assistants, formulaires, Vue/JS lors de la migration du code de plugin interne de baserCMS4 (basé sur CakePHP2) vers baserCMS5 (basé sur CakePHP5). Inclut des modèles tels que "migrer le plugin de 4 à 5", "méthodes admin_ vers Controller/Admin", "public $belongsTo/$hasMany pour initialiser()", "ClassRegistry/TableRegistry", "find(all/first/list, array) vers le générateur de requêtes", "$this->Model (null) pour fetchTable", "getControlSource singulier→plural", "$this->Form to BcAdminForm·control()", "formulaire de recherche search/→search/", "FormHelper::create string model→null", "FormHelper::year()/month()/domId() obsolète", "Time::format ICU patterns", "Number::format/Text::troncate ne peut pas être nul", "la condition du tableau IN n'est pas automatiquement ajoutée ; null devient IS", "URL d'administrateur Vue/JS vers $.bcUtil.adminBaseUrl + reconstruction du pack Web", "$this->data / $View->request provoquant un chargement incorrect de l'assistant", "MissingTableClassException / MissingHelperException / Aucun fournisseur de contexte trouvé", "App::import de bibliothèques externes groupées en tant que fournisseur (leafo/scssphp, etc.) non portées vers la version 5 et donc mortes", "Suppression PHP8 de each() et échappement d'expressions régulières incorrect, etc., anciennes bibliothèques groupées incompatibles avec PHP8", etc., à consulter lors de la correction de chaque erreur dans un plugin. L’interface utilisateur, le modèle, le modèle et le front-end s’affichent un par un. Cette compétence se concentre sur la détection et la conversion des idiomes 4.x ; le guide définitif pour un codage 5.x correct est basercms5-plugin-development. Les étapes de migration du site entier de 4 à 5 (installation/migration de base de données/conversion de thème et de plugin/workflow Git) sont dans basercms4-to-5-upgrade, migration de thème (centrée sur les modèles) dans basercms-theme-4-to-5-upgrade, migration de plugin de 5.2→5.3 dans basercms-plugin-5x-update, problèmes CakePHP-core dans cakephp-migration, problèmes PHP-core dans php-migration, testez l'exécution dans basercms-unittest, et si vous migrez des plugins complémentaires de champs personnalisés pour les blogs, etc. vers bc-custom-content, reportez-vous à basercms5-custom-content-development.
