Процедуры и сценарии для сквозной обработки рекомендаций по безопасности репозитория baserCMS (включая GHSA и сортировку) — получение списка, проверка результатов, исправление каждой проблемы, создание частных вилок/ветвей/PR и выполнение локальной проверки. Используется при «проверке рекомендаций по безопасности», «проверке сортировки уязвимостей», «создании ветки и PR для каждой рекомендации», «объединении исправлений уязвимостей в запрос на извлечение» и т. д. Поскольку Copilot/GHA нельзя использовать в ветвях рекомендаций, локальная проверка (/code‑review·basercms‑unittest) рассматривается как правильный подход; пакет также включает в себя повторную попытку во время ожидания принудительного распространения, разделение общих файлов на фрагменты и стандартный рабочий процесс разрешения конфликтов для сохранения синхронизации с базой.
