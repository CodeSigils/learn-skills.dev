Процедуры и сценарии, обрабатывающие рекомендации по безопасности репозитория baserCMS (включая GHSA и сортировку), сквозные: получение списка → проверка результатов → исправление каждой проблемы → создание частной ветки/ветви/PR → выполнение локальной проверки. Используется для таких задач, как «проверка рекомендаций по безопасности», «проверка сортировки уязвимостей», «создание ветки и PR для каждой рекомендации» и «объединение исправлений уязвимостей в запрос на включение». Поскольку Copilot/GHA нельзя использовать в консультативных ответвлениях, рабочий процесс рассматривает локальную проверку (/code-review, basercms-unittest) как авторитетный шаг; он также включает в себя повторную попытку до тех пор, пока не будет отражено нажатие, разделение общих файлов на фрагменты и стандартное разрешение конфликтов слияния базового отслеживания.
