baserCMS 리포지토리 보안 권고(GHSA 및 심사 포함)를 엔드 투 엔드로 처리하는 절차 및 스크립트: 목록 검색 → 결과 확인 → 문제별 수정 → 프라이빗 포크/브랜치/PR 생성 → 로컬 확인 수행. "보안 권고 사항 확인", "취약성 분류 확인", "각 권고에 대한 포크 및 PR 생성", "취약성 수정 사항을 끌어오기 요청에 포함"과 같은 작업에 사용됩니다. Copilot/GHA는 자문 포크에서 사용할 수 없기 때문에 워크플로는 로컬 확인(/code-review, basercms-unittest)을 신뢰할 수 있는 단계로 처리합니다. 또한 푸시가 반영될 때까지 재시도, 공유 파일을 덩어리로 분할, 기본 추적 병합 충돌의 표준 해결이 포함됩니다.
