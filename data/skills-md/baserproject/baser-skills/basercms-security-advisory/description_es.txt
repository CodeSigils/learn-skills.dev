Procedimientos y scripts para manejar los avisos de seguridad del repositorio de baserCMS (incluidos GHSA y clasificación) en un flujo de trabajo fluido, desde recuperar la lista, verificar los hallazgos, solucionar cada problema, crear bifurcaciones/sucursales/PR privados hasta realizar la validación local. Se utiliza para tareas como "verificar avisos de seguridad", "verificar vulnerabilidades de clasificación", "bifurcar y crear relaciones públicas para cada aviso" y "agrupar correcciones de vulnerabilidades en una solicitud de extracción". Debido a que Copilot/GHA no se puede utilizar en bifurcaciones de asesoramiento, el flujo de trabajo trata la verificación local (en/code-reviewandbasercms-unittest) como el paso autorizado; también incluye reintentar mientras se espera la propagación push, dividir archivos compartidos en fragmentos y el enfoque estándar de resolución de conflictos para permanecer sincronizado con la base.
