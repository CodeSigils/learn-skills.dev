Procedimientos y scripts que manejan los avisos de seguridad del repositorio baserCMS (incluidos GHSA y clasificación) de un extremo a otro: recuperar la lista → verificar los hallazgos → solucionar por problema → crear una bifurcación/sucursal/PR privada → realizar verificación local. Se utiliza para tareas como "verificar avisos de seguridad", "verificar vulnerabilidades de clasificación", "crear una bifurcación y PR para cada aviso" y "agregar correcciones de vulnerabilidades en una solicitud de extracción". Debido a que Copilot/GHA no se puede utilizar en bifurcaciones de asesoramiento, el flujo de trabajo trata la verificación local (/code‑review, basercms‑unittest) como el paso autorizado; también incluye reintentar hasta que se refleje un envío, dividir archivos compartidos en fragmentos y la resolución estándar de conflictos de fusión de seguimiento de bases.
