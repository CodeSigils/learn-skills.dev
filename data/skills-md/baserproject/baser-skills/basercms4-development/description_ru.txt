Сборник правил разработки для проектов baserCMS 4 серии (на основе CakePHP2.10) + jQuery. На него ссылаются при проверке политики кодирования, структуры каталогов, соглашений об именах, обработки журналов/ошибок, обработки файлов только для чтения и ограничений сервера для проектов baserCMS4, включая такие элементы, как «разработка с помощью baserCMS4», «изменение плагинов 4-й серии», «написание кода CakePHP2», «контроллеры/модели/представления в приложении/плагине», «элементы темы/макеты», «использование BcBaserHelper/BcFormHelper/BcHtmlHelper», «вывод логов с помощью CakeLog», «взлом ядра lib/Baser и lib/Cake запрещен» и т. д. Для разработки baserCMS5 см. baseercms5-development, а для обновления с 4→5 см. baseercms4-to-5-upgrade.
