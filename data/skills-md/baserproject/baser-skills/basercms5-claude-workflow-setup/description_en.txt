When developing or migrating baserCMS 5 (CakePHP 5) with Claude Code, refer once beforehand to the “Recommended Workflow Environment Setup” skill (suggestion‑based; execution is opt‑in). It is consulted first when “starting development or migration of 5‑series plugins,” “trying to determine the best way to proceed,” “wanting to organize the design → plan → implementation process/environment,” “wanting to tidy permissions and proceed in Auto mode,” etc. Design is done via superpowers brainstorming, permissions are organized with permissions‑audit, then Auto mode is used, with Markdown previews of spec/plan, and the sequence of brainstorming → plan preview → spec export is “suggested” rather than enforced (the user decides whether to do it; skip if already set up). Technical rewrite patterns are basercms5-development, basercms-plugin-4-to-5-upgrade, and basercms-plugin-5x-update; refer to basercms-unittest for test execution.
