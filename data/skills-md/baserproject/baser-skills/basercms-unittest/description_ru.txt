Процедуры запуска и исследования модульных тестов baserCMS (CakePHP5/PHPUnit) в локальной среде Docker. Обратитесь к нему, если вы хотите «запустить модульные тесты», «запустить все тесты», «запустить только этот тест», «расследовать сбои теста», «запустить тесты для плагина индивидуально», «настроить тестовую среду для плагина» и т. д. Он включает в себя имена контейнеров, команды выполнения, форматирование команд для автоматического утверждения разрешений и методы агрегирования и изоляции ошибок, а также шаги по внедрению механизма выполнения модульных тестов для автономного плагина (composer.json, phpunit.xml.dist,tests/bootstrap.php, полная настройка TestApp и ловушка для контактов Phinx0.16.10).
