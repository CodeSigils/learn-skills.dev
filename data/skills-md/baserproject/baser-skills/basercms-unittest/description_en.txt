Procedures for running and investigating unit tests of baserCMS (CakePHP 5 / PHPUnit) in a local Docker environment. Refer to this when you want to “run unit tests,” “run all tests,” “run only this test,” “investigate test failures,” “run tests for a plugin individually,” “set up a test environment for a plugin,” etc. It includes container names, execution commands, command formatting for automatic permission approval, and methods for aggregating and isolating failures, as well as the steps to introduce a mechanism for executing unit tests for a plugin standalone (composer.json, phpunit.xml.dist, tests/bootstrap.php, a complete TestApp setup, and the Phinx 0.16.10 pin trap).
