Procédures pour exécuter et enquêter sur les tests unitaires de baserCMS (CakePHP5 / PHPUnit) dans un environnement Docker local. Faites-y référence lorsque vous souhaitez « exécuter des tests unitaires », « exécuter tous les tests », « exécuter uniquement ce test », « enquêter sur les échecs de test », « exécuter des tests pour un plugin individuellement », « configurer un environnement de test pour un plugin », etc. Il comprend les noms de conteneurs, les commandes d'exécution, le formatage des commandes pour l'approbation automatique des autorisations et les méthodes d'agrégation et d'isolement des échecs, ainsi que les étapes pour introduire un mécanisme d'exécution de tests unitaires pour un plugin autonome (composer.json, phpunit.xml.dist, tests/bootstrap.php, une configuration complète de TestApp et le piège à broches Phinx0.16.10).
