Procedimiento para ejecutar e investigar pruebas unitarias de baserCMS (CakePHP5/PHPUnit) en un entorno Docker local. Consúltelo cuando desee "ejecutar pruebas unitarias", "ejecutar todas las pruebas", "ejecutar solo esta prueba", "investigar fallas de las pruebas", "ejecutar pruebas para un complemento individualmente" o "agregar un entorno de prueba a un complemento". Incluye nombres de contenedores, comandos de ejecución, formato de comandos para la aprobación automática de permisos, métodos para agregar y aislar fallas y los pasos para configurar un sistema para ejecutar pruebas unitarias en un complemento de forma independiente (incluidos compositor.json, phpunit.xml.dist, tests/bootstrap.php, la TestApp completa y las trampas de phinx0.16.10).
