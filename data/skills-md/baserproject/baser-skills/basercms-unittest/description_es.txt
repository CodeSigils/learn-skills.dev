Procedimientos para ejecutar e investigar pruebas unitarias de baserCMS (CakePHP5/PHPUnit) en un entorno Docker local. Consulte esto cuando desee "ejecutar pruebas unitarias", "ejecutar todas las pruebas", "ejecutar solo esta prueba", "investigar fallas de prueba", "ejecutar pruebas para un complemento individualmente", "configurar un entorno de prueba para un complemento", etc. Incluye nombres de contenedores, comandos de ejecución, formato de comandos para la aprobación automática de permisos y métodos para agregar y aislar fallas, así como los pasos para introducir un mecanismo para ejecutar pruebas unitarias para un complemento independiente (composer.json, phpunit.xml.dist, tests/bootstrap.php, una configuración completa de TestApp y la trampa de pin Phinx0.16.10).
