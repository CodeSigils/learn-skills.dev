Verfahren zum Ausführen und Untersuchen von Unit-Tests von baserCMS (CakePHP5 / PHPUnit) in einer lokalen Docker-Umgebung. Verweisen Sie darauf, wenn Sie „Komponententests ausführen“, „alle Tests ausführen“, „nur diesen Test ausführen“, „Testfehler untersuchen“, „Tests für ein Plugin einzeln ausführen“, „eine Testumgebung für ein Plugin einrichten“ usw. möchten. Es umfasst Containernamen, Ausführungsbefehle, Befehlsformatierung für die automatische Berechtigungsgenehmigung und Methoden zum Aggregieren und Isolieren von Fehlern sowie die Schritte zur Einführung eines Mechanismus zum Ausführen von Komponententests für ein eigenständiges Plugin (composer.json, phpunit.xml.dist, tests/bootstrap.php, ein vollständiges TestApp-Setup und die Phinx0.16.10-Pin-Falle).
