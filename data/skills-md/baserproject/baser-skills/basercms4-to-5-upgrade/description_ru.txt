Набор правил и шаблонов, которым должны следовать агенты ИИ при обновлении/переносе кода и сайтов с baserCMS4 (на основе CakePHP2) на baserCMS5 (на основе CakePHP5). «Миграция с baserCMS4 на 5», «Обновление серии 4 до серии 5», «Миграция данных с помощью BcDbMigrator», «Преобразование темы/плагина с помощью BcAddonMigrator», «Переписать с CakePHP2 на CakePHP5», «Переместить методы с префиксом admin_ в Controller/Admin», «Преобразовать config/setting.php и config.php для возврата массивов», «Устареть init.php и создать PluginClass», «Создать миграционный снимок», «тема site_configs → тема сайтов», «Стандартный поток/порядок процесса миграции», «Включить плагины непосредственно в базе данных», «Применить темы непосредственно в базе данных», «Получить запрос->данные/запрос/параметры», «Устареть классов файлов/папок», «ClassRegistry → TableRegistry», «FrozenTime → DateTime», «FixtureManager → FixtureFactory», и т. д., которые будут использоваться для общей работы по обновлению 4→5. Конкретные шаблоны перезаписи для внутреннего кода плагина (Controller/Table/Entity/View/Helper/form/Vue·JS) — это inbasercms-plugin-4-to-5-upgrade, миграция темы (ориентированная на шаблоны) — inbasercms-theme-4-to-5-upgrade, миграция плагина из 5.2→5.3 — inbasercms-plugin-5x-update, изменения ядра CakePHP — incakephp-migration, изменения ядра PHP — это inphp-миграция, а при выполнении тестов используется базовый навык cms-unittestskill. Чтобы правильно написать серию target 5 (полный справочник по разработке), см. baseercms5-plugin-development/basercms5-theme-development.
