Un ensemble de règles et de modèles que les agents IA doivent suivre lors de la mise à niveau/migration du code et des sites de baserCMS4 (basé sur CakePHP2) vers baserCMS5 (basé sur CakePHP5). Inclut des éléments tels que « Migrer de baserCMS4 vers 5 », « Mise à niveau de la série 4 vers la série 5 », « Migration de données avec BcDbMigrator », « Conversion de thème/plug-in avec BcAddonMigrator », « Réécrire de CakePHP2 vers CakePHP5 », « Déplacer les méthodes avec préfixe admin_ du contrôleur vers l'administrateur », « Convertir config/setting.php et config.php pour renvoyer des tableaux », « Déprécier init.php et créez PluginClass », « Générer migration_snapshot », « thème site_configs → thème des sites », « Flux de migration standard/ordre des étapes », « Activer les plugins directement dans la base de données », « Appliquer les thèmes directement dans la base de données », « Obtenir la requête->données/requête/params », « Déprécier les classes de fichiers/dossiers », « ClassRegistry → TableRegistry », « FrozenTime → DateTime », « LuminaireManager → LuminaireFactory », etc., à référencer tout au long des travaux de mise à niveau 4 → 5.

Les modèles de réécriture spécifiques pour le code interne du plugin (Controller/Table/Entity/View/Helper/Form/Vue‑JS) se trouvent dans **basercms‑plugin‑4‑to‑5‑upgrade**, migration de thème (centrée sur les modèles) dans **basercms‑theme‑4‑to‑5‑upgrade**, migration de plugin de 5.2→5.3 dans **basercms‑plugin‑5x‑update**, modifications liées à CakePHP‑core dans **cakephp‑migration**, modifications liées à PHP‑core dans **php‑migration** et exécution des tests dans **basercms‑unittest**. La manière correcte d'écrire pour la série cible 5 (référence de développement) peut être trouvée dans **basercms5‑plugin‑development** / **basercms5‑theme‑development**.
