A collection of rules and patterns that AI agents must follow when upgrading/migrating code and sites from baserCMS 4 (based on CakePHP 2) to baserCMS 5 (based on CakePHP 5). Includes items such as “Migrate from baserCMS 4 to 5,” “Upgrade from the 4 series to the 5 series,” “Data migration with BcDbMigrator,” “Theme/plugin conversion with BcAddonMigrator,” “Rewrite from CakePHP 2 to CakePHP 5,” “Move admin_‑prefixed methods from Controller to Admin,” “Convert config/setting.php and config.php to return arrays,” “Deprecate init.php and create PluginClass,” “Generate migration_snapshot,” “site_configs theme → sites theme,” “Standard migration flow / step order,” “Enable plugins directly in the DB,” “Apply themes directly in the DB,” “Getterize request->data / query / params,” “Deprecate File/Folder classes,” “ClassRegistry → TableRegistry,” “FrozenTime → DateTime,” “FixtureManager → FixtureFactory,” etc., to be referenced throughout the 4→5 upgrade work.

Specific rewrite patterns for plugin internal code (Controller/Table/Entity/View/Helper/Form/Vue‑JS) are in **basercms‑plugin‑4‑to‑5‑upgrade**, theme (templates‑centric) migration in **basercms‑theme‑4‑to‑5‑upgrade**, plugin migration from 5.2→5.3 in **basercms‑plugin‑5x‑update**, CakePHP‑core related changes in **cakephp‑migration**, PHP‑core related changes in **php‑migration**, and test execution in **basercms‑unittest**. The correct way to write for the target 5 series (development reference) can be found in **basercms5‑plugin‑development** / **basercms5‑theme‑development**.
