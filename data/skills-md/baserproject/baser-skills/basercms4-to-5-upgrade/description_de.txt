Eine Sammlung von Regeln und Mustern, die KI-Agenten befolgen müssen, wenn sie Code und Websites von baserCMS4 (basierend auf CakePHP2) auf baserCMS5 (basierend auf CakePHP5) aktualisieren/migrieren. Enthält Elemente wie „Von baserCMS4 auf 5 migrieren“, „Upgrade von der 4er-Serie auf die 5er-Serie“, „Datenmigration mit BcDbMigrator“, „Theme-/Plugin-Konvertierung mit BcAddonMigrator“, „Umschreiben von CakePHP2 auf CakePHP5“, „Methoden mit dem Präfix „admin_“ vom Controller in den Admin verschieben“, „config/setting.php und config.php in Rückgabearrays konvertieren“, „Veraltet init.php und PluginClass erstellen“, „Migrationssnapshot generieren“, „site_configs Theme → Sites Theme“, „Standardmigrationsablauf / Schrittreihenfolge“, „Plugins direkt in der Datenbank aktivieren“, „Designs direkt in der Datenbank anwenden“, „Anfrage->Daten / Abfrage / Parameter abrufen“, „Datei-/Ordnerklassen verwerfen“, „ClassRegistry → TableRegistry“, „FrozenTime → DateTime“, „FixtureManager → FixtureFactory“, usw., die während der gesamten 4→5-Upgrade-Arbeit referenziert werden müssen.

Spezifische Rewrite-Muster für internen Plug-in-Code (Controller/Table/Entity/View/Helper/Form/Vue-JS) sind in **basercms-plugin-4-to-5-upgrade**, Theme-Migration (vorlagenzentriert) in **basercms-theme-4-to-5-upgrade**, Plugin-Migration von 5.2→5.3 in **basercms-plugin-5x-update**, Änderungen im Zusammenhang mit CakePHP-Core in **cakephp-migration**, PHP-core-bezogene Änderungen in **php-migration** und Testausführung in **basercms-unittest**. Die richtige Schreibweise für die Target 5-Serie (Entwicklungsreferenz) finden Sie in **basercms5-plugin-development** / **basercms5-theme-development**.
