Une collection de modèles de changements obsolètes et de rupture et de recettes de correctifs pour mettre à jour la version CakePHP de baserCMS (5.0 → 5.1 → 5.2…). Inclut des problèmes tels que « Alias d'association déjà défini », « Une règle de validation portant le nom existe déjà », « _Token introuvable », « en-têtes déjà envoyés », « Le plug-in nommé X est déjà chargé », « Erreurs ResultSet/PaginatedResultSet », « order()/group() obsolète », « valeurs de retour de l'écouteur d'événements obsolètes », « find('all', $options) obsolète », « Table::get array options obsolètes / arguments nommés », "exceptions sur les valeurs nulles dans les conditions du tableau", "paramètres de cache _cake_core_", "pluginBootstrap ne charge pas le paramètre .php des plugins suivants, ce qui rend Configure nul (itération en direct)", "_checkFilePath provoquant .. template MissingPluginException/500", "Racine TreeBehavior avec parent_id=null corrompant lft/rght", "Entity::set Bulk‑array obsolète", « AbstractMigration/AbstractSeed obsolète → BaseMigration/BaseSeed (cakephp/migrations 4.5+) », « config/routes.php fallbacks() donnant 404 uniquement dans les tests », « les méthodes réelles d'assistance transformées en délégation de méthode magique rendant method_exists faux (par exemple, TextHelper::truncate → is_callable check) », et ainsi de suite. Il est consulté lors de l'enquête et de la résolution de problèmes provenant du noyau CakePHP ou des packages associés. Lorsque vous prenez en charge une nouvelle version de CakePHP, ajoutez des notes spécifiques à la version à ce guide. Pour les problèmes provenant de PHP lui-même, reportez-vous aux compétences de migration php.
