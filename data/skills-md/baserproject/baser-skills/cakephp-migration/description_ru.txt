Коллекция устаревших и устаревших шаблонов изменений, а также рецептов исправлений для обновлений версий CakePHP baserCMS (5.0 → 5.1 → 5.2…). Включает такие проблемы, как «Псевдоним ассоциации уже установлен», «Правило проверки с именем уже существует», «_Token не найден», «Заголовки уже отправлены», «Плагин с именем X уже загружен», «Ошибки ResultSet/PaginatedResultSet», «order()/group() устарел», «возвращаемое значение прослушивателя событий устарело», «find('all', $options) устарел», «Table::get array‑options устарел/назван аргументы», «исключение для нулевых значений в условиях массива», «настройки кэша _cake_core_», «pluginBootstrap не читает файл settings.php последующих плагинов, поэтому параметр «Configure» имеет значение null (живая итерация)», «_checkFilePath вызывает MissingPluginException/500 для шаблона ..», «Корень TreeBehavior с родительским_id=null повреждает lft/rght», «Entity::set Bulk‑array устарел», «AbstractMigration/AbstractSeed устарел → BaseMigration/BaseSeed (cakephp/migrations4.5+)», «config/routes.php Fallbacks() выдает 404 только в тестах», «вспомогательные реальные методы становятся делегированием магических методов, метод_exists возвращает false (TextHelper::truncate → проверка is_callable)» и т. д. Обращайтесь к этому при исследовании и устранении проблем, исходящих из ядра CakePHP и связанные пакеты. При поддержке более новых версий CakePHP добавляйте в этот документ примечания для конкретной версии. По вопросам, связанным с самим PHP, обратитесь к специалистам по миграции PHP.
