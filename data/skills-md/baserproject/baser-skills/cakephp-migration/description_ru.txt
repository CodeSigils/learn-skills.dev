Коллекция устаревших шаблонов и шаблонов критических изменений, а также рецептов исправлений для обновления версии CakePHP baserCMS (5.0 → 5.1 → 5.2…). Включает такие проблемы, как «Псевдоним ассоциации уже установлен», «Правило проверки с именем уже существует», «_Token не найден», «Заголовки уже отправлены», «Плагин с именем X уже загружен», «Ошибки ResultSet/PaginatedResultSet», «order()/group() устарели», «возвращаемые значения прослушивателя событий устарели», «find('all', $options) устарели», «Параметры массива Table::get устарели/именованные аргументы», «исключения для нулевых значений в условиях массива», «настройки кэша _cake_core_», «pluginBootstrap не загружает файл settings.php последующих плагинов, что приводит к тому, что параметр Configuration становится нулевым (живая итерация)», «_checkFilePath вызывает .. шаблон MissingPluginException/500», «Корень TreeBehavior с родительским_id=null, повреждающим lft/rght», «Entity::set Bulk‑array устарел», «AbstractMigration/AbstractSeed устарела → BaseMigration/BaseSeed (cakephp/migrations 4.5+)», «config/routes.php Fallbacks() выдает 404 только в тестах», «реальные вспомогательные методы превратились в делегирование магических методов, что делает метод Method_exists ложным (например, TextHelper::truncate → проверка is_callable)» и т. д. К нему обращаются при исследовании и устранении проблем, возникающих в ядре CakePHP или связанных с ним пакетах. При поддержке новой версии CakePHP добавьте в это руководство примечания для конкретной версии. По вопросам, связанным с самим PHP, обратитесь к разделу «Навыки миграции PHP».
