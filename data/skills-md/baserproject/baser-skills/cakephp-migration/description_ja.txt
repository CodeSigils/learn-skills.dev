BaserCMS の CakePHP バージョン (5.0 → 5.1 → 5.2 …) を更新するための非推奨の破壊的変更パターンと修正レシピのコレクション。 「関連付けエイリアスはすでに設定されています」、「その名前の検証ルールはすでに存在します」、「_Token が見つかりません」、「ヘッダーはすでに送信されました」、「X という名前のプラグインはすでにロードされています」、「ResultSet/PaginatedResultSet エラー」、「order()/group() は非推奨です」、「イベントリスナーの戻り値は非推奨です」、「find('all', $options) は非推奨です」などの問題が含まれます。 「Table::get 配列オプションの非推奨/名前付き引数」、「配列条件の null 値の例外」、「_cake_core_ キャッシュ設定」、「pluginBootstrap が後続のプラグインの settings.php をロードしないため、Configure が null になる (ライブ反復)」、「_checkFilePath が原因で .. template MissingPluginException/500」、「parent_id=null の TreeBehavior ルートが破損している」 lft/rght"、"Entity::setBulk‑array は非推奨になりました"、"AbstractMigration/AbstractSeed は非推奨になりました → BaseMigration/BaseSeed (cakephp/migrations 4.5+)"、"config/routes.php fallbacks() はテストでのみ 404 を生成しました"、"ヘルパーの実際のメソッドが魔法のメソッドの委任に変わり、method_exists が false になりました" (例: TextHelper::truncate → is_callable check)」など。 CakePHP コアまたは関連パッケージに起因する問題を調査および修正するときに参照されます。新しい CakePHP バージョンをサポートする場合は、このガイドにバージョン固有のメモを追加してください。 PHP 自体に起因する問題については、php 移行スキルを参照してください。
