A collection of deprecated and breaking‑change patterns and fix recipes for updating baserCMS’s CakePHP version (5.0 → 5.1 → 5.2 …). Includes issues such as “Association alias already set”, “A validation rule with the name already exists”, “_Token not found”, “headers already sent”, “Plugin named X is already loaded”, “ResultSet/PaginatedResultSet errors”, “order()/group() deprecated”, “event‑listener return values deprecated”, “find('all', $options) deprecated”, “Table::get array options deprecated / named arguments”, “exceptions on null values in array conditions”, “_cake_core_ cache settings”, “pluginBootstrap not loading subsequent plugins’ setting.php, causing Configure to be null (live iteration)”, “_checkFilePath causing .. template MissingPluginException/500”, “TreeBehavior root with parent_id=null corrupting lft/rght”, “Entity::set bulk‑array deprecated”, “AbstractMigration/AbstractSeed deprecated → BaseMigration/BaseSeed (cakephp/migrations 4.5+)”, “config/routes.php fallbacks() yielding 404 only in tests”, “helper real methods turned into magic‑method delegation making method_exists false (e.g., TextHelper::truncate → is_callable check)”, and so on. It is consulted when investigating and fixing issues originating from the CakePHP core or related packages. When supporting a new CakePHP version, add version‑specific notes to this guide. For issues originating from PHP itself, refer to php‑migration skills.
