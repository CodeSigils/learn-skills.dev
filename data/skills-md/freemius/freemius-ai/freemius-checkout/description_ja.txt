React アプリで顧客向けの Freemius Checkout UI を構築します。これには、Checkout Provider (オーバーレイ コンテキスト)、Subscribe (サブスクリプション価格表)、Topup (1 回限り / クレジット価格表)、Paywall、およびカスタム チェックアウト ボタンが含まれます。価格設定ページ、「アップグレード」/「クレジットの購入」ボタン、オーバーレイ チェックアウト、またはペイウォールを React フロントエンドに追加するときに使用します。 React Starter Kit Checkout コンポーネントとフロントエンド Checkout SDK (`@freemius/checkout`) に加え、フロントエンドが依存するシン チェックアウト固有のバックエンド エンドポイント (購入同期の `POST /api/purchase`、`GET /api/checkout/pricing`、およびホスト型リダイレクト ハンドラー) について説明します。基礎となるチェックアウト作成および資格同期エンジンは依然として「freemius-core」に属しています。
