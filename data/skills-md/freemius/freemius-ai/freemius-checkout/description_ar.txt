أنشئ واجهة مستخدم Freemius Checkout التي تواجه العملاء في تطبيق React — موفر Checkout (سياق التراكب)، والاشتراك (جدول تسعير الاشتراك)، وشحن الرصيد (جدول تسعير الائتمان لمرة واحدة)، وجدار الدفع، وأزرار الخروج المخصصة. يُستخدم عند إضافة صفحة تسعير، أو زر "ترقية"/"شراء أرصدة"، أو سداد دفع متراكب، أو جدار حماية غير المدفوع إلى واجهة React الأمامية. يغطي مكونات React Starter Kit Checkout وCheckout SDK للواجهة الأمامية (`@freemius/checkout`)، بالإضافة إلى نقاط النهاية الخلفية الرفيعة الخاصة بالخروج التي تعتمد عليها الواجهة الأمامية (مزامنة الشراء `POST /api/purchase`، `GET /api/checkout/pricing`، ومعالج إعادة التوجيه المستضاف)؛ لا يزال المحرك الأساسي لإنشاء الخروج ومزامنة الاستحقاق ينتمي إلى "freemius-core".
