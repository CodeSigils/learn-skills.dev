Система проверки акций А (китайских акций) с использованием трехуровневой практической инвестиционной структуры:
Жесткий фильтр → 100-балльная шестимерная оценка → Купить Дисциплину.
Сканирует весь рынок акций А, устраняет некачественные акции с помощью 10 жестких фильтров,
оценивает выживших по 6 параметрам (промышленность, ров, финансы, управление, доходы акционеров, оценка),
извлекает глубокие финансовые показатели для лучших кандидатов и формирует диверсифицированный портфель
с размером позиции и правилами покупки/продажи.

Практическая система выбора акций A-share — трехуровневая структура: жесткий фильтр → 100-балльная шестимерная оценка → дисциплина покупок.
Сканирует все акции категории А, 10 препятствий с жесткой фильтрацией отсеивают компании с плохим финансовым состоянием, шестимерная 100-точечная модель определяет цели
(отраслевая динамика / конкурентный ров / финансовое качество / управленческое управление / доход акционеров / разрыв ожиданий оценки),
после глубокого анализа каждого кандидата создается отраслево диверсифицированное портфолио, включающее дисциплину покупок и триггеры продаж.
Источник данных: akshare (бесплатно, ключ API не требуется), выводит результаты JSON + визуальный отчет HTML.
