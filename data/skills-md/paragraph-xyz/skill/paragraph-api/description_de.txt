Verwenden Sie die Paragraph REST API oder das TypeScript SDK, um Beiträge, Veröffentlichungen, Abonnenten und Coins auf paragraph.com zu verwalten. Keine Installation erforderlich – nur HTTP-Anfragen oder „npm install @paragraph-com/sdk“. Wird ausgelöst, wenn der Benutzer die Paragraph-API integrieren, darauf aufbauen oder aufrufen möchte.
