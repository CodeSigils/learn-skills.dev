Используйте Paragraph REST API или TypeScript SDK для управления публикациями, публикациями, подписчиками и монетами на сайте paragraph.com. Установка не требуется — просто HTTP-запросы или `npm install @paragraph-com/sdk`. Запускается, когда пользователь запрашивает интеграцию, развитие или вызов API Paragraph.
