Steuern Sie den Desktop des Benutzers im Hintergrund – Klicken, Tippen,
Scrollen, Ziehen – ohne den Cursor oder den Tastaturfokus zu stehlen,
oder das Wechseln virtueller Desktops/Spaces. Plattformübergreifend: macOS,
Windows, Linux. Funktioniert mit jedem werkzeugfähigen Modell. Laden Sie diesen Skill
wann immer das Tool „computer_use“ verfügbar ist.
