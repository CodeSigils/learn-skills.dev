Pilotez le bureau de l'utilisateur en arrière-plan : cliquez, tapez,
faire défiler, faire glisser — sans voler le curseur, le focus clavier,
ou changer de bureau virtuel/espace. Multiplateforme : macOS,
Windows, Linux. Fonctionne avec n'importe quel modèle compatible avec les outils. Charger cette compétence
chaque fois que l'outil `computer_use` est disponible.
