Validiert lokal („robomotion validieren“) und führt dann einen Robomotion-Fluss auf einem Roboter aus („robomotion run <flow-dir>“), wobei das JSONL-Sitzungsprotokoll im Agentenmodus verfolgt wird, um eine Validierungs-→Ausführungs-→Beobachtungs-→Reparaturschleife mit begrenzten Wiederholungsversuchen zu steuern. Wird verwendet, wenn der Benutzer „Flow ausführen“, „auf Roboter X starten“, „dies auf dem Roboter auslösen“, „auf einem Roboter testen“ oder „bereitstellen und ausführen“ sagt.
