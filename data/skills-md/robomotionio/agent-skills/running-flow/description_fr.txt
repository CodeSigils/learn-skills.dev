Valide localement (« robomotion validate ») puis exécute un flux Robomotion sur un robot (« robomotion run <flow-dir>`), en suivant le journal de session JSONL en mode agent pour piloter une boucle valider → exécuter → observer → corriger avec des tentatives limitées. À utiliser lorsque l'utilisateur dit « exécuter le flux », « démarrer sur le robot X », « déclencher ceci sur le robot », « tester sur un robot » ou « déployer et exécuter ».
