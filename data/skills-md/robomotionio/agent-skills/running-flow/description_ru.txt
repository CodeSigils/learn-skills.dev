Проверяет локально («robomotion validate»), затем выполняет поток Robomotion на роботе («robomotion run <flow-dir>»), отслеживая журнал сеанса JSONL в режиме агента для запуска цикла проверки → запуска → наблюдения → исправления с ограниченными повторами. Используйте, когда пользователь говорит «запустить поток», «запустить на роботе X», «запустить это на роботе», «протестировать на роботе» или «развернуть и запустить».
