يتم التحقق محليًا (`robomotion validate`) ثم تنفيذ تدفق Robomotion على الروبوت (`robomotion run <flow-dir>`)، مع متابعة سجل جلسة JSONL في وضع الوكيل لتشغيل حلقة التحقق → التنفيذ → الملاحظة → الإصلاح مع عدد محدود من المحاولات. استخدم ذلك عندما يقول المستخدم "run the flow"، "start on robot X"، "trigger this on the robot"، "test on a robot"، أو "deploy and run".
