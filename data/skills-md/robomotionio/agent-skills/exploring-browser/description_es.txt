Explora un sitio web de forma interactiva a través del servidor robomotion-browser-mcp para descubrir selectores, registrar secuencias de acción, capturar el tráfico de la red y producir una secuencia de flujo JSON que se asigna a Robomotion SDK TypeScript. Úselo cuando el usuario diga "explore esta página", "busque el selector para X", "registre el flujo de inicio de sesión", "qué API usa esta página" o antes de escribir CUALQUIER flujo `Core.Browser.*`. Se empareja con "red inversa" cuando el tráfico capturado revela una API limpia.
