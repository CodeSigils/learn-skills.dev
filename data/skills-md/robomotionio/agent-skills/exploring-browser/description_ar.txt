يستكشف موقعًا إلكترونيًا بشكل تفاعلي عبر خادم robomotion-browser-mcp لاكتشاف المحددات، وتسجيل تسلسلات الإجراءات، والتقاط حركة المرور الشبكية، وإنتاج تسلسل تدفق JSON يتطابق مع Robomotion SDK TypeScript. يُستخدم عندما يقول المستخدم "explore this page"، أو "find the selector for X"، أو "record the login flow"، أو "what API does this page use"، أو قبل كتابة أي تدفق `Core.Browser.*`. يتكامل مع `reversing-network` عندما تكشف حركة المرور الملتقطة عن API نظيفة.

يرجى دائمًا الرد بلغة المستخدم.
