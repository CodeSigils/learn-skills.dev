يستكشف موقع ويب بشكل تفاعلي عبر خادم robomotion-browser-mcp لاكتشاف المحددات وتسجيل تسلسلات الإجراءات والتقاط حركة مرور الشبكة وإنتاج تسلسل تدفق JSON الذي يتم تعيينه إلى Robomotion SDK TypeScript. يُستخدم عندما يقول المستخدم "استكشف هذه الصفحة"، أو "ابحث عن محدد X"، أو "سجل تدفق تسجيل الدخول"، أو "ما هي واجهة برمجة التطبيقات التي تستخدمها هذه الصفحة"، أو قبل كتابة أي تدفق `Core.Browser.*`. يقترن بـ "شبكة عكسية" عندما تكشف حركة المرور الملتقطة عن واجهة برمجة تطبيقات نظيفة.
