Исследует веб-сайт в интерактивном режиме через сервер robomotion-browser-mcp для обнаружения селекторов, записи последовательностей действий, захвата сетевого трафика и создания последовательности потоков JSON, которая сопоставляется с Robomotion SDK TypeScript. Используйте, когда пользователь говорит «изучите эту страницу», «найдите селектор для X», «запишите процесс входа в систему», «какой API использует эта страница» или перед написанием ЛЮБОГО потока `Core.Browser.*`. Сопряжено с reversing-network, когда перехваченный трафик показывает чистый API.
