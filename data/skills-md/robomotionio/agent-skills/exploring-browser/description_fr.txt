Explorez un site Web de manière interactive via le serveur robomotion-browser-mcp pour découvrir des sélecteurs, enregistrer des séquences d'action, capturer le trafic réseau et produire une séquence de flux JSON qui correspond au TypeScript du SDK Robomotion. À utiliser lorsque l'utilisateur dit « explorer cette page », « trouver le sélecteur pour X », « enregistrer le flux de connexion », « quelle API cette page utilise-t-elle » ou avant d'écrire TOUT flux `Core.Browser.*`. S'associe à « reversing-network » lorsque le trafic capturé révèle une API propre.
