Esplora un sito Web in modo interattivo tramite il server robomotion-browser-mcp per scoprire selettori, registrare sequenze di azioni, acquisire traffico di rete e produrre una sequenza di flusso JSON mappata su Robomotion SDK TypeScript. Da utilizzare quando l'utente dice "esplora questa pagina", "trova il selettore per X", "registra il flusso di accesso", "quale API utilizza questa pagina" o prima di scrivere QUALSIASI flusso `Core.Browser.*`. Si accoppia con "reversing-network" quando il traffico catturato rivela un'API pulita.
