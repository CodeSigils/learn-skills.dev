robomotion-browser-mcp サーバーを介して対話的に Web サイトを探索し、セレクターを検出し、アクション シーケンスを記録し、ネットワーク トラフィックをキャプチャし、Robomotion SDK TypeScript にマップする JSON フロー シーケンスを生成します。ユーザーが「このページを探索する」、「X のセレクターを見つける」、「ログイン フローを記録する」、「このページで使用される API は何か」と言うとき、または任意の `Core.Browser.*` フローを記述する前に使用します。キャプチャされたトラフィックからクリーンな API が明らかになった場合は、「reversing-network」と組み合わせます。
