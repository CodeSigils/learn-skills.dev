Erkundet eine Website interaktiv über den robomotion-browser-mcp-Server, um Selektoren zu entdecken, Aktionssequenzen aufzuzeichnen, Netzwerkverkehr zu erfassen und eine JSON-Flusssequenz zu erstellen, die dem Robomotion SDK TypeScript zugeordnet ist. Wird verwendet, wenn der Benutzer sagt: „Diese Seite erkunden“, „den Selektor für Wird mit „reversing-network“ kombiniert, wenn der erfasste Datenverkehr eine saubere API erkennen lässt.
