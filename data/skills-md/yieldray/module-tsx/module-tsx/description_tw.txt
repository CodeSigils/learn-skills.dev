每當使用者想要在瀏覽器中執行 TypeScript、TSX 或 React 而無需建置步驟，或詢問 module-tsx 時，請使用此技能。觸發條件：「在瀏覽器中執行 TypeScript」、「無建置步驟」、「內聯 TSX」、「module-tsx」、「腳本類型 module-tsx」、「不使用捆綁器進行 React」、「編寫使用 TypeScript 進行 React 的頁面」、「瀏覽器 TypeScript」、「免建置頁碼」或任何建置頁面的頁面呈現或匯入頁面的 HTMLX / /TS 的要求/A2 程式呈現 TS 程式碼/ 1TS 的當編寫需要在瀏覽器中執行 TypeScript 或 JSX 的 HTML 時，請務必使用此技能。
