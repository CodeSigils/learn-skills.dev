Используйте этот навык всякий раз, когда пользователь хочет запустить TypeScript, TSX или React в браузере без этапа сборки или спрашивает о модуле-tsx. Запускается по: «запустить TypeScript в браузере», «без этапа сборки», «встроенный TSX», «модуль-tsx», «тип сценария модуль-tsx», «React без упаковщика», «написать страницу, использующую React с TypeScript», «браузер TypeScript», «React без сборки» или любой запрос на написание HTML-страницы, которая импортирует или отображает код TypeScript/TSX. Всегда используйте этот навык при написании HTML, который должен выполнять TypeScript или JSX в браузере.
