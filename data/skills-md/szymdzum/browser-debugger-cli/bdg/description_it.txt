Usa bdg CLI per l'automazione del browser tramite Chrome DevTools Protocol. Fornisce accesso diretto a CDP (oltre 60 domini, più di 300 metodi) per query DOM, navigazione, screenshot, controllo della rete ed esecuzione di JavaScript. Usa questa funzionalità quando devi automatizzare i browser, estrarre contenuti dinamici o interagire programmaticamente con le pagine web.
