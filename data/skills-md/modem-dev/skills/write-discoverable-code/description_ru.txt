Правила написания кода, с помощью которых агенты кодирования (и люди) могут найти и понять
текстовый поиск. Применяйте при написании или переименовании кода: функций, типов, констант,
файлы, сообщения об ошибках, комментарии к документам.

Основано на измерениях: агенты перемещаются с помощью простого текстового поиска, а не с помощью AST или
языковой сервер, поэтому каждый идентификатор является поисковым запросом, и каждый промах поиска
затраты на чтение впустую.
