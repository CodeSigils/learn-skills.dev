Regole per scrivere codice che gli agenti di codifica (e gli esseri umani) possono trovare e comprendere
ricerca in testo semplice. Applicare ogni volta che si scrive o si rinomina codice: funzioni, tipi, costanti,
file, messaggi di errore, commenti sui documenti.

Basato sulla misurazione: gli agenti navigano tramite ricerca di testo semplice, non tramite AST o
server della lingua, quindi ogni identificatore è una query di ricerca e ogni ricerca manca
costi di lettura sprecati.
