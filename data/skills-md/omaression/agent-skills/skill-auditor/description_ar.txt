قم بمراجعة جميع مهارات مساحة العمل والتعلم والذاكرة وملفات التكوين بشكل دوري للتوصية بإعادة البناء وأفكار المهارات الجديدة وتحسينات سير العمل. يتم تشغيله تلقائيًا عبر cron كل 7 أيام، أو يدويًا باستخدام "مهارات التدقيق" أو "مراجعة المهارات" أو "سلامة مساحة العمل" أو "تحسين سير العمل". يرسل التوصيات مباشرة إلى Telegram دون مطالبة المستخدم.
