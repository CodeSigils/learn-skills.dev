Astrale ドメインをエンドツーエンドで作成します。ドメインの作成、編集、レビュー、本番化、移行、最適化、保護、シミュレーション、またはデバッグ時に使用します。モデリングスキーマ。アクションとワークフローの実装。外部 API の統合。ネイティブ Astrale ドメインを選択する。ビューの設計。または、ポリシー、認証、カーネル、移行、コア データ、サンプル データ、ライブ/ランタイム ドリフトに関する推論。完全な作成、ビルド、プロトタイプ、または POC の場合は、リファレンス全体で段階的なワークフローに従います。既存ドメインの作業に焦点を当てた場合は、関連する参照にルーティングします。
