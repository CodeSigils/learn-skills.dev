Compétences du portefeuille BitMart Web3 (12 points de terminaison) : recherche de jetons, détails de la chaîne, informations sur les jetons, graphique K-Line, classement des jetons chauds, classement xStock, classement P&L Smart Money, analyse d'adresse/avoirs/historique des transactions Smart Money, solde d'adresse, adresse de transactions récentes, devis de swap, prix de lot. Toutes les API ne nécessitent pas de clé API. À utiliser lorsque les utilisateurs posent des questions sur les prix des jetons, les données de marché, le suivi intelligent de l'argent, les requêtes sur les actifs, les transactions récentes ou les cotations d'échange de jetons.
