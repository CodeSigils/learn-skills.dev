Руководства по настройке Cloudflare/cloudflare-os-starter, Cloudflare Access, Deployment.jsonc, хранилищу, искусственному интеллекту, наблюдаемости, пользовательским гейткиперам, развертыванию, проверке, устранению неполадок, откату и обновлениям закрепленных подмодулей. Используйте только для развертываний, созданных с помощью Cloudflare OS Deployment Starter, а не для отдельных извлечений Cloudflare OS.
