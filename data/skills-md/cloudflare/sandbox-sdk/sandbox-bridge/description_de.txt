Verwenden Sie diese Option, wenn Sie eine echte, laufende Sandbox-Bereitstellung über HTTP durchführen müssen – beispielsweise um SDK-Änderungen anhand eines Live-Containers zu validieren, ein vom Benutzer gemeldetes Problem zu reproduzieren oder mit der API (einschließlich FUSE-Bucket-Mounts) zu experimentieren, ohne „wrangler dev“ zu starten. Dokumentiert den Sandbox-Bridge-Worker, der über „SANDBOX_WORKER_URL“ + „SANDBOX_API_KEY“ erreichbar ist, wenn der Host sie einfügt.
