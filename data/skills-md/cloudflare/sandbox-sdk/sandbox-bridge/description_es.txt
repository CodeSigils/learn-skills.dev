Úselo cuando necesite realizar una implementación real de Sandbox en ejecución a través de HTTP, por ejemplo, para validar los cambios del SDK en un contenedor en vivo, reproducir un problema informado por el usuario o experimentar con la API (incluidos los montajes de depósitos FUSE) sin activar "wrangler dev". Documenta el trabajador del puente Sandbox accesible a través de `SANDBOX_WORKER_URL` + `SANDBOX_API_KEY` cuando el host los inyecta.
