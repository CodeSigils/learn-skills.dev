Используйте, когда вам нужно выполнить реальное развертывание в песочнице через HTTP — например, для проверки изменений SDK в реальном контейнере, воспроизведения проблемы, о которой сообщил пользователь, или экспериментирования с API (включая монтирование корзины FUSE) без запуска `wrangler dev`. Документирует рабочий мост Sandbox, доступный через `SANDBOX_WORKER_URL` + `SANDBOX_API_KEY`, когда хост внедряет их.
