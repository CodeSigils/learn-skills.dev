À utiliser lorsque vous avez besoin d'effectuer un déploiement Sandbox réel et en cours d'exécution via HTTP - par exemple pour valider les modifications du SDK par rapport à un conteneur actif, reproduire un problème signalé par l'utilisateur ou expérimenter l'API (y compris les montages de compartiment FUSE) sans lancer `wrangler dev`. Documente le pont Worker Sandbox accessible via `SANDBOX_WORKER_URL` + `SANDBOX_API_KEY` lorsque l'hôte les injecte.
