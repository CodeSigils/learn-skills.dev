Auditoría de seguridad de una base de código: aplicaciones web, API, servicios, herramientas CLI, bibliotecas, demonios y más. Úselo cuando se le solicite encontrar errores de seguridad, realizar una revisión de seguridad, auditar vulnerabilidades o realizar una prueba de penetración del código. Se centra en problemas explotables con impacto real, no en preocupaciones teóricas o comportamiento estándar de la industria.
