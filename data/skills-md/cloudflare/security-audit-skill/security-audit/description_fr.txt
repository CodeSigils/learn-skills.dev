Audit de sécurité d'une base de code : applications Web, API, services, outils CLI, bibliothèques, démons, etc. À utiliser lorsqu'on vous le demande pour rechercher des bogues de sécurité, effectuer un examen de sécurité, un audit des vulnérabilités ou un test d'intrusion du code. Se concentre sur les problèmes exploitables ayant un impact réel, et non sur des préoccupations théoriques ou un comportement standard de l'industrie.
