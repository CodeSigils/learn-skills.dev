Создает и обновляет запросы на включение GitHub для изменений в облачной документации. Загружается, когда вас попросят открыть, создать, отправить, обновить или отредактировать PR, а также написать заголовок или описание PR. Охватывает соглашения о названиях, названия ветвей, структуру тела PR и шаблон контрольного списка документации.
