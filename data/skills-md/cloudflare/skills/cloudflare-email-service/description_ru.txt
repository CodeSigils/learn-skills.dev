Отправляйте и получайте транзакционные электронные письма с помощью службы электронной почты Cloudflare (отправка электронной почты + маршрутизация электронной почты). Используйте при отправке электронной почты (привязка Workers или REST API), маршрутизации электронной почты, обработке электронной почты Agents SDK или интеграции электронной почты в любое приложение — Workers, Node.js, Python, Go и т. д. Также используйте для доставки электронной почты, SPF/DKIM/DMARC, настройки электронной почты Wrangler, инструментов электронной почты MCP или когда агенту кодирования необходимо отправлять электронные письма. Даже для простых запросов типа «добавить электронную почту в мой Worker» — этот навык содержит важные детали конфигурации.
