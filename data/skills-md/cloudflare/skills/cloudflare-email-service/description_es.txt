Envíe y reciba correos electrónicos transaccionales con el servicio de correo electrónico de Cloudflare (envío de correo electrónico + enrutamiento de correo electrónico). Úselo al crear envío de correo electrónico (enlace de Workers o API REST), enrutamiento de correo electrónico, manejo de correo electrónico del SDK de agentes o integración de correo electrónico en cualquier aplicación: Workers, Node.js, Python, Go, etc. También utilícelo para la capacidad de entrega de correo electrónico, SPF/DKIM/DMARC, configuración de correo electrónico de Wrangler, herramientas de correo electrónico de MCP o cuando un agente de codificación necesita enviar correos electrónicos. Incluso para solicitudes simples como "agregar correo electrónico a mi trabajador", esta habilidad tiene detalles de configuración críticos.
