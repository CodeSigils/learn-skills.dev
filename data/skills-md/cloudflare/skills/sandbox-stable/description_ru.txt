Используйте при создании или изменении приложений Cloudflare Sandbox в текущем стабильном пакете @cloudflare/sandbox (тег npm по умолчанию) — команды, сеансы, файлы, порты, туннели, терминалы, мосты, рабочие версии или очистка устаревших API при сохранении стабильной версии. Не для @cloudflare/sandbox@next (используйте sandbox-next) или для переноса на версию 1.0 (используйте sandbox-migrate-to-next).
