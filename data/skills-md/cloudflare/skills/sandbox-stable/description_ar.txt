يُستخدم عند إنشاء تطبيقات Cloudflare Sandbox أو تغييرها على حزمة @cloudflare/sandbox المستقرة الحالية (علامة npm الافتراضية) — الأوامر أو الجلسات أو الملفات أو المنافذ أو الأنفاق أو المحطات الطرفية أو الجسر أو الإنتاج أو تنظيف واجهة برمجة التطبيقات المهملة مع الحفاظ على الاستقرار. ليس لـ @cloudflare/sandbox@next (استخدم sandbox-next) أو للنقل إلى 1.0 (استخدم sandbox-migrate-to-next).
