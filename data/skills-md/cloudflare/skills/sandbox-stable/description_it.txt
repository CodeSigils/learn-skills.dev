Da utilizzare durante la creazione o la modifica di app Cloudflare Sandbox sull'attuale pacchetto @cloudflare/sandbox stabile (tag npm predefinito): comandi, sessioni, file, porte, tunnel, terminali, bridge, produzione o pulizia delle API deprecate rimanendo su stable. Non per @cloudflare/sandbox@next (usa sandbox-next) o per il porting alla versione 1.0 (usa sandbox-migrate-to-next).
