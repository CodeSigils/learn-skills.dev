Verwenden Sie diese Option, wenn Sie Cloudflare Sandbox-Apps auf dem aktuellen stabilen @cloudflare/sandbox-Paket (Standard-npm-Tag) erstellen oder ändern – Befehle, Sitzungen, Dateien, Ports, Tunnel, Terminals, Bridge, Produktion oder Bereinigung veralteter APIs, während Sie stabil bleiben. Nicht für @cloudflare/sandbox@next (verwenden Sie sandbox-next) oder für die Portierung auf 1.0 (verwenden Sie sandbox-migrate-to-next).
