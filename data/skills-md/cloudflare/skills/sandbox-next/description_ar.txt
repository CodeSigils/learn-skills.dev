يُستخدم عند إنشاء تطبيقات Cloudflare Sandbox أو تغييرها على @cloudflare/sandbox@next (معاينة Sandbox SDK 1.0) - تنفيذ التعليمات البرمجية، أو مشغلات الذكاء الاصطناعي، أو المترجمين الفوريين، أو المهام المشابهة لـ CI، أو المحطات الطرفية، أو الملفات، أو التحميلات، أو الأنفاق، أو معاينة عناوين URL، أو دورة الحياة، أو الأخطاء. ليس للحزمة الافتراضية الثابتة (استخدم sandbox-stable) أو للنقل الثابت إلى @next (استخدم sandbox-migrate-to-next).
