Используйте при создании или изменении приложений Cloudflare Sandbox на @cloudflare/sandbox@next (предварительная версия Sandbox SDK 1.0) — выполнение кода, средства искусственного интеллекта, интерпретаторы, CI-подобные задания, терминалы, файлы, монтирование, туннели, URL-адреса предварительного просмотра, жизненный цикл или ошибки. Не для стабильного пакета по умолчанию (используйте sandbox-stable) или для портирования стабильного пакета на @next (используйте sandbox-migrate-to-next).
