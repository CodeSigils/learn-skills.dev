À utiliser lors de la création ou de la modification d'applications Cloudflare Sandbox sur @cloudflare/sandbox@next (aperçu du SDK Sandbox 1.0) : exécution de code, exécuteurs d'IA, interprètes, tâches de type CI, terminaux, fichiers, montages, tunnels, URL d'aperçu, cycle de vie ou erreurs. Pas pour le package stable par défaut (utilisez sandbox-stable) ou pour le portage stable vers @next (utilisez sandbox-migrate-to-next).
