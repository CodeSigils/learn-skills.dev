À utiliser lors du portage d'une application Cloudflare Sandbox de stable @cloudflare/sandbox vers @cloudflare/sandbox@next (aperçu Sandbox SDK 1.0), ou lorsque l'utilisateur demande de migrer ou de mettre à niveau vers Sandbox 1.0 / @next. Pas pour le travail stable quotidien (sandbox-stable) ou les nouvelles applications @next (sandbox-next).
