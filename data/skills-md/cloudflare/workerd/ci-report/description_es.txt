Informe de estado de CI para un PR trabajador. Cubre las comprobaciones de GitHub Actions y, para los empleados de Cloudflare, el proceso interno de GitLab. Informa de aprobación/rechazo de cada trabajo, extrae detalles de los errores y ofrece volver a intentar trabajos fallidos en cualquiera de las plataformas. Cargue esta habilidad cuando el usuario pregunte sobre el estado de CI, fallas de prueba, fallas de compilación o quiera volver a intentar un trabajo de CI fallido.
