Отчет о состоянии CI для рабочего PR. Охватывает проверки действий GitHub и, для сотрудников Cloudflare, внутренний конвейер GitLab. Сообщает об успешном/неудачном выполнении каждого задания, извлекает сведения об ошибках из сбоев и предлагает повторить неудачные задания на любой платформе. Загружайте этот навык, когда пользователь спрашивает о статусе CI, ошибках тестирования, ошибках сборки или хочет повторить неудачное задание CI.
