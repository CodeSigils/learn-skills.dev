Rapport d'état CI pour un PR travailleur. Couvre les vérifications GitHub Actions et, pour les employés de Cloudflare, le pipeline GitLab interne. Rapports de réussite/d'échec pour chaque tâche, extrait les détails des erreurs des échecs et propose de réessayer les tâches instables sur l'une ou l'autre plate-forme. Chargez cette compétence lorsque l'utilisateur pose des questions sur l'état du CI, les échecs de test, les échecs de construction ou lorsqu'il souhaite réessayer une tâche CI ayant échoué.
