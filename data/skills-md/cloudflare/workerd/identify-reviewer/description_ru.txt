Идентифицирует учетную запись GitHub локального пользователя и идентификатор git перед выполнением проверки кода. Используйте этот навык в начале любой PR-проверки, проверки кода или анализа журнала коммитов, чтобы результаты можно было сформулировать с учетом собственных предыдущих комментариев, коммитов и статуса утверждения пользователя.
