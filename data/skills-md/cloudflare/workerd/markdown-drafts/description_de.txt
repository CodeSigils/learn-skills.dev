Verwenden Sie Markdown-Formatierung beim Entwerfen von Inhalten, die für externe Systeme bestimmt sind (GitHub-Probleme/PRs, Jira-Tickets, Wiki-Seiten, Designdokumente usw.), damit die Formatierung erhalten bleibt, wenn der Benutzer sie kopiert. Laden Sie diesen Skill, bevor Sie einen Entwurf erstellen, den der Benutzer an anderer Stelle einfügt.
