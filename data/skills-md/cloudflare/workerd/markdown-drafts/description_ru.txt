Используйте форматирование уценки при создании контента, предназначенного для внешних систем (запросы/запросы на GitHub, заявки Jira, вики-страницы, проектная документация и т. д.), чтобы форматирование сохранялось, когда пользователь копирует его. Загрузите этот навык перед созданием черновика, который пользователь вставит в другое место.
