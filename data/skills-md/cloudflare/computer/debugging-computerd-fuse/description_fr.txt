Déboguez Computerd en mode Real-FUSE de bout en bout sans Workerd, Vitest-Pool-Workers ou Wrangler dans la boucle. Démarrez le binaire linux-x64 dans un conteneur Docker privilégié, pilotez son point de terminaison capnweb /api à partir de Node, simulez la synchronisation côté DO à partir d'un SQLiteTestStorage et isolez les blocages liés à FUSE. Chargez lorsqu'un bug réel-FUSE se reproduit localement mais que les tests unitaires réussissent, lorsque les tests de harnais vitest se bloquent sur un conteneur réel, ou lorsque vous devez attribuer un coin à FUSE vs sync vs exec.
