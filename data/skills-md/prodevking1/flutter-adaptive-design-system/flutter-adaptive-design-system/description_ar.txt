يعمل نظام تصميم Flutter المتكيف مع النظام الأساسي على إنشاء واجهة مستخدم أصلية عالية الجودة لنظامي التشغيل iOS (Cupertino) وAndroid (المادة 3).
يُستخدم عندما: (1) إنشاء عناصر واجهة مستخدم قابلة للتكيف يتم عرضها محليًا لكل نظام أساسي، (2) إنشاء واجهة مستخدم Flutter التي تبدو وكأنها تطبيق iOS أو Android حقيقي - وليس تطبيقًا هجينًا عامًا عبر الأنظمة الأساسية، (3) إنشاء أزواج عناصر واجهة مستخدم Cupertino/Material مع واجهة برمجة تطبيقات متسقة، (4) تنفيذ التنقل التكيفي أو مربعات الحوار أو النماذج أو المدخلات أو التخطيطات، (5) إعداد أساس نظام تصميم مشروع Flutter مع اكتشاف النظام الأساسي.
