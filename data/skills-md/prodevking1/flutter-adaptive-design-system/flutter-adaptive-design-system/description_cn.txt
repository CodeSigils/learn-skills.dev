平台自适应 Flutter 设计系统为 iOS (Cupertino) 和 Android（材料 3）生成原生质量的 UI。
在以下情况下使用：(1) 创建在每个平台上本地渲染的自适应小部件，(2) 构建看起来像真正的 iOS 或 Android 应用程序的 Flutter UI，而不是通用的跨平台混合应用，(3) 使用一致的 API 生成 Cupertino/Material 小部件对，(4) 实现自适应导航、对话框、表单、输入或布局，(5) 通过平台检测设置 Flutter 项目的设计系统基础。
