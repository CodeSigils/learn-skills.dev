iOS (Cupertino) および Android (マテリアル 3) 用のネイティブ品質の UI を生成するプラットフォーム適応型 Flutter 設計システム。
次の場合に使用します: (1) プラットフォームごとにネイティブにレンダリングするアダプティブ ウィジェットを作成する、(2) 一般的なクロスプラットフォーム ハイブリッドではなく、実際の iOS または Android アプリのように見える Flutter UI を構築する、(3) 一貫した API を使用して Cupertino/マテリアル ウィジェット ペアを生成する、(4) アダプティブ ナビゲーション、ダイアログ、フォーム、入力、またはレイアウトを実装する、(5) プラットフォーム検出を使用して Flutter プロジェクトのデザイン システム基盤をセットアップする。
