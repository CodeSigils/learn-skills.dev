对任何计划、发布、产品、招聘、定价变化、战略或高风险决策进行事前分析。使用加里·克莱因 (Gary Klein) 的前瞻-后见之明方法 - 假设它在未来某个日期已经失败，然后回溯以找出每个计划特定的原因，然后制定修订计划、缓解措施、预警信号和启动前检查表。在我做出承诺之前，进行事前剖析，进行事前剖析，什么可以杀死这个，面向未来的这个，对这个计划进行压力测试，我在这里缺少什么，找到盲点，可能会出什么问题，我是否遗漏了什么，在这方面找出漏洞，这将在哪里中断。不适用于对任意想法或论点的对抗性攻击（使用 RedTeam）、当前状态的多视角辩论（使用 Council）、网络/系统漏洞测试（使用 Security）或简单的反馈/事实问题。当某人有一个具体的计划或承诺，而错误的成本很高并且决定仍然可以改变时，一定要触发。
