Realice una investigación premortem de cualquier plan, lanzamiento, producto, contratación, cambio de precios, estrategia o decisión de alto riesgo. Utiliza el método prospectivo retrospectivo de Gary Klein: supone que ya falló en una fecha futura y trabaja hacia atrás para sacar a la luz cada causa específica del plan, luego produce un plan revisado, mitigaciones, señales de alerta temprana y una lista de verificación previa al lanzamiento. UTILIZAR CUANDO premortem esto, ejecutar un premortem, qué podría matar esto, preparar esto para el futuro, probar este plan, qué me estoy perdiendo aquí, encontrar los puntos ciegos, qué podría salir mal, me estoy perdiendo algo, hacer agujeros en esto, dónde se romperá, antes de comprometerme con esto. NO PARA ataques adversarios a una idea o argumento arbitrario (use RedTeam), debate de perspectivas múltiples sobre el estado actual (use Consejo), pruebas de vulnerabilidad de red/sistema (use Seguridad) o comentarios simples/preguntas objetivas. DESARROLLAR cuando alguien tiene un plan o compromiso concreto donde el costo de equivocarse es alto y la decisión aún es modificable.
