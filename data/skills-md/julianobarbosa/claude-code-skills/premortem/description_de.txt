Führen Sie eine Vorabanalyse zu jedem Plan, jeder Einführung, jedem Produkt, jeder Einstellung, jeder Preisänderung, jeder Strategie oder jeder Entscheidung mit hohem Risiko durch. Verwendet Gary Kleins Methode der prospektiven Rückschau – gehen Sie davon aus, dass der Plan bereits zu einem späteren Zeitpunkt gescheitert ist, und arbeiten Sie rückwärts, um alle planspezifischen Ursachen aufzudecken, und erstellen Sie dann einen überarbeiteten Plan, Abhilfemaßnahmen, Frühwarnsignale und eine Checkliste vor dem Start. VERWENDEN SIE, WENN dies prämortem, führen Sie ein premortem aus, was könnte das töten, machen Sie das zukunftssicher, testen Sie diesen Plan, was übersehe ich hier, finden Sie die blinden Flecken, was könnte schief gehen, übersehe ich etwas, bohren Sie Löcher hinein, wo wird das kaputt gehen, bevor ich mich dazu verpflichte. NICHT FÜR kontroverse Angriffe auf eine willkürliche Idee oder ein beliebiges Argument (verwenden Sie RedTeam), eine multiperspektivische Debatte über den aktuellen Stand (verwenden Sie Council), Netzwerk-/Systemschwachstellentests (verwenden Sie Security) oder einfaches Feedback/sachliche Fragen. Lösen Sie das Problem aus, wenn jemand einen konkreten Plan oder eine konkrete Verpflichtung hat, bei dem die Kosten für Fehler hoch sind und die Entscheidung noch veränderbar ist.
