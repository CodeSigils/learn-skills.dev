Flujo de trabajo completo de "creación de cuadernos de temas" para Google NotebookLM: investigación web profunda, carga secuencial de fuentes (con omisiones de dominios con fallas conocidas), generación completa de artefactos de Studio y biblioteca de mensajes de chat seleccionada. Utilice esta habilidad siempre que el usuario desee crear un nuevo cuaderno de NotebookLM sobre un tema, crear un cuaderno de investigación completo desde cero, generar un cuaderno "{topic} :: docs", compilar fuentes de foros (Reddit/HN/GitHub/Discord/Quora) en un cuaderno, producir un estudio completo (audio + video + mapa mental + informes + tarjetas didácticas + cuestionario + infografía + presentación de diapositivas + tabla de datos) para un cuaderno existente o preparar indicaciones seleccionadas de NotebookLM para un tema. Activadores de frases como "crear un cuaderno en X", "crear cmux :: docs", "investigar y construir NotebookLM", "estudio completo para mi cuaderno", "estudio completo", "solicitudes de NotebookLM para el tema Y", "convertir esto en un cuaderno NotebookLM". Aplicar incluso cuando el usuario no diga explícitamente "NotebookLM"; si le piden que cree un cuaderno de investigación sobre un tema con fuentes y artefactos derivados, esta es la habilidad adecuada.
