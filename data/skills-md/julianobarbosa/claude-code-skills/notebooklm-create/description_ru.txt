Полный рабочий процесс «создания тематического блокнота» для Google NotebookLM — глубокие веб-исследования, последовательная загрузка исходного кода (с известными пропусками доменов), полная генерация артефактов Studio и тщательно подобранная библиотека подсказок для чата. Используйте этот навык всякий раз, когда пользователь хочет создать новый блокнот NotebookLM по какой-либо теме, создать полноценный исследовательский блокнот с нуля, создать блокнот «{topic} :: docs», скомпилировать источники с форумов (Reddit/HN/GitHub/Discord/Quora) в блокнот, создать полную версию Studio (аудио + видео + интеллектуальная карта + отчеты + карточки + тесты + инфографика + слайды + таблица данных) для существующего блокнота или подготовить тщательно подобранные подсказки NotebookLM для тема. Запускается по таким фразам, как «создать блокнот на X», «создать cmux::docs», «исследовать и создать NotebookLM», «полная студия для моего блокнота», «вся студия», «NotebookLM подскажет тему Y», «превратить это в блокнот NotebookLM». Применяйте даже тогда, когда пользователь явно не говорит «NotebookLM» — если вас просят собрать исследовательский блокнот по теме с исходниками и производными артефактами, это правильный навык.
