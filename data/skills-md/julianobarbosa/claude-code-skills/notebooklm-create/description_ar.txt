أكمل سير عمل "إنشاء دفتر ملاحظات للموضوع" لـ Google NotebookLM - بحث عميق على الويب، وتحميل المصدر المتسلسل (مع تخطي النطاقات الفاشلة المعروفة)، وإنشاء عناصر الاستوديو الكاملة، ومكتبة مطالبات الدردشة المنظمة. استخدم هذه المهارة عندما يريد المستخدم إنشاء دفتر ملاحظات NotebookLM جديد حول موضوع ما، أو إنشاء دفتر ملاحظات بحثي كامل من البداية، أو إنشاء دفتر ملاحظات "{topic} :: docs"، أو تجميع المصادر من المنتديات (Reddit/HN/GitHub/Discord/Quora) في دفتر ملاحظات، أو إنتاج استوديو كامل (صوت + فيديو + خريطة ذهنية + تقارير + بطاقات تعليمية + اختبار معلوماتي + مجموعة شرائح + جدول بيانات) لدفتر ملاحظات موجود، أو إعداد مطالبات NotebookLM المنسقة لـ موضوع. تشغيل عبارات مثل "إنشاء دفتر ملاحظات على X"، و"إنشاء cmux :: docs"، و"البحث وإنشاء NotebookLM"، و"استوديو كامل لدفتر الملاحظات الخاص بي"، و"الاستوديو بأكمله"، و"يطالب NotebookLM بالموضوع Y"، و"تحويل هذا إلى دفتر ملاحظات NotebookLM". تقدم بطلبك حتى عندما لا يقول المستخدم صراحةً "NotebookLM" - إذا طلب منك تجميع دفتر بحث حول موضوع يحتوي على مصادر وعناصر مشتقة، فهذه هي المهارة الصحيحة.
