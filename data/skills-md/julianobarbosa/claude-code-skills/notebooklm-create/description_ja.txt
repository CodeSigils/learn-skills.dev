Google NotebookLM の完全な「トピック ノートブック ビルド」ワークフロー — ディープウェブリサーチ、逐次ソース読み込み (既知の失敗ドメインスキップあり)、完全な Studio アーティファクト生成、厳選されたチャットプロンプトライブラリ。ユーザーがトピックに関する新しい NotebookLM ノートブックを作成する場合、完全なリサーチ ノートブックを最初から構築する場合、「{topic} :: docs」ノートブックを生成する場合、フォーラム (Reddit/HN/GitHub/Discord/Quora) からソースをノートブックにコンパイルする場合、既存のノートブック用に完全な Studio (オーディオ + ビデオ + マインド マップ + レポート + フラッシュカード + クイズ + インフォグラフィック + スライド デッキ + データ テーブル) を作成する場合、または厳選された NotebookLM を準備する場合は、このスキルを使用します。トピックの入力を求めます。 「X でノートブックを構築する」、「cmux :: docs を作成する」、「NotebookLM を調査して構築する」、「ノートブック用の完全なスタジオ」、「スタジオ全体」、「トピック Y の NotebookLM プロンプトが表示される」、「これを NotebookLM ノートブックに変える」などのフレーズでトリガーされます。ユーザーが「NotebookLM」と明示的に言わない場合でも適用します。ソースや派生成果物を含むトピックに関する研究ノートをまとめるように求められた場合、これは適切なスキルです。
