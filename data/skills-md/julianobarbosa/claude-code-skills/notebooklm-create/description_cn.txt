Google NotebookLM 的完整“主题笔记本构建”工作流程 — 深度网络研究、顺序源加载（具有已知失败的域跳过）、完整的 Studio 工件生成和精选的聊天提示库。每当用户想要针对某个主题创建新的 NotebookLM 笔记本、从头开始构建完整的研究笔记本、生成“{topic} :: docs”笔记本、将论坛 (Reddit/HN/GitHub/Discord/Quora) 的源代码编译到笔记本中、为现有笔记本生成完整的 Studio（音频 + 视频 + 思维导图 + 报告 + 抽认卡 + 测验 + 信息图 + 幻灯片 + 数据表）或为某个主题准备精选的 NotebookLM 提示时，都可以使用此技能。触发诸如“在 X 上构建笔记本”、“创建 cmux :: 文档”、“研究和构建 NotebookLM”、“我的笔记本的完整工作室”、“整个工作室”、“NotebookLM 提示主题 Y”、“将其变成 NotebookLM 笔记本”等短语。即使用户没有明确地说“NotebookLM”，也可以应用——如果他们要求您就某个主题组装一个研究笔记本，并包含来源和衍生工件，这就是正确的技能。
