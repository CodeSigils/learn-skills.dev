Workflow complet de « création de blocs-notes thématiques » pour Google NotebookLM : recherche Web approfondie, chargement séquentiel de sources (avec sauts de domaines défaillants connus), génération complète d'artefacts Studio et bibliothèque d'invites de discussion organisée. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un nouveau bloc-notes NotebookLM sur un sujet, créer un bloc-notes de recherche complet à partir de zéro, générer un bloc-notes "{topic} :: docs", compiler des sources de forums (Reddit/HN/GitHub/Discord/Quora) dans un bloc-notes, produire un studio complet (audio + vidéo + carte mentale + rapports + flashcards + quiz + infographie + diaporama + tableau de données) pour un bloc-notes existant, ou préparer des invites NotebookLM organisées pour un sujet. Se déclenche sur des phrases telles que "créer un notebook sur X", "créer cmux :: docs", "rechercher et construire NotebookLM", "studio complet pour mon notebook", "studio entier", "NotebookLM invite pour le sujet Y", "transformer ceci en un notebook NotebookLM". Appliquez-le même lorsque l'utilisateur ne dit pas explicitement « NotebookLM » — s'il vous demande d'assembler un cahier de recherche sur un sujet avec des sources et des artefacts dérivés, c'est la bonne compétence.
