قم بإنشاء ملفات justfiles وتحريرها وصيانتها باستخدام مشغل الأوامر "just". استخدم هذه المهارة كلما
يذكر المستخدم justfiles، أو مجرد وصفات، أو مجرد مشغل أوامر، أو يريد الترحيل من
Makefile/make فقط. يتم تشغيله أيضًا عندما يكون لدى المستخدم ملف justfile في مشروعه ويسأل
حول تشغيل أو تنظيم أو توثيق أوامر المشروع. يغطي الهجرة من الصنع،
تصميم الوصفة والأنماط المتغيرة وتكامل dotenv والدعم عبر الأنظمة الأساسية.
