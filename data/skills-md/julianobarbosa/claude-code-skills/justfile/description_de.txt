Erstellen, bearbeiten und verwalten Sie Justfiles mit dem „just“-Befehls-Runner. Benutze diese Fähigkeit wann immer
Der Benutzer erwähnt nur Dateien, nur Rezepte, nur Command Runner oder möchte von migrieren
Makefile/make zu einfach. Wird auch ausgelöst, wenn der Benutzer eine Justfile in seinem Projekt hat und danach fragt
über das Ausführen, Organisieren oder Dokumentieren von Projektbefehlen. Deckt die Migration von Make,
Rezeptdesign, variable Muster, Dotenv-Integration und plattformübergreifende Unterstützung.
