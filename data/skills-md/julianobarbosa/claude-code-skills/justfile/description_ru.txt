Создавайте, редактируйте и обслуживайте файлы justfile с помощью команды just. Используйте этот навык всякий раз, когда
пользователь упоминает justfiles, просто рецепты, просто средство запуска команд или хочет перейти с
Makefile/make просто. Также срабатывает, когда у пользователя есть файл justfile в его проекте и он спрашивает
о запуске, организации и документировании команд проекта. Охватывает миграцию из make,
дизайн рецептов, шаблоны переменных, интеграция с dotenv и кроссплатформенная поддержка.
