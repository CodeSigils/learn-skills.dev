Cree, edite y mantenga archivos justfiles utilizando el ejecutor de comandos `just`. Usa esta habilidad siempre que
el usuario menciona solo archivos, solo recetas, solo ejecutor de comandos o quiere migrar desde
Makefile/make para simplemente. También se activa cuando el usuario tiene un archivo justo en su proyecto y pregunta
sobre cómo ejecutar, organizar o documentar comandos del proyecto. Cubre la migración desde make,
diseño de recetas, patrones variables, integración dotenv y soporte multiplataforma.
