Настройте роли безопасности на уровне строк (RLS), безопасность на уровне объекта и перспективы для семантических моделей Power BI с помощью pbi-cli. Используйте этот навык всякий раз, когда пользователь упоминает «безопасность», «RLS», «безопасность на уровне строк», «контроль доступа», «ограничения данных», «кто может видеть», «фильтровать по пользователю», «перспективы», «ограничивать видимость» или хочет ограничить доступ к данным по роли.
