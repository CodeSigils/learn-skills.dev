Используйте при экспорте существующих ресурсов Azure в Terraform с помощью aztfexport. Триггеры по aztfexport, импорт Azure в Terraform, экспорт ресурсов Azure, перевод Azure под управление Terraform, обратное проектирование инфраструктуры Azure, загрузка IaC из живых ресурсов Azure. Охватывает режимы ресурсов, групп ресурсов и запросов.
