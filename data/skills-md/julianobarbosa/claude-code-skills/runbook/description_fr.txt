Créez ou chargez un runbook opérationnel pour un sujet donné. Recherche dans les « runbooks/ » une correspondance existante ; s'il n'y en a pas, en crée un nouveau à partir du modèle standard (Objectif / Prérequis / Étapes / Vérification / Dépannage / Dernier test). À utiliser lorsqu'on vous demande de « créer un runbook », de « charger un runbook pour X », de documenter une procédure ou de rechercher une SOP.
