Creare o caricare un runbook operativo per un determinato argomento. Cerca "runbooks/" per una corrispondenza esistente; in caso contrario, ne viene creato uno nuovo dal modello standard (Scopo/Prerequisiti/Passaggi/Verifica/Risoluzione dei problemi/Ultimo test). Utilizzare quando viene richiesto di "creare un runbook", "caricare runbook per X", documentare una procedura o cercare una SOP.
