Cree o cargue un runbook operativo para un tema determinado. Busca en `runbooks/` una coincidencia existente; si no hay ninguno, cree uno nuevo a partir de la plantilla estándar (Propósito/Requisitos previos/Pasos/Verificación/Solución de problemas/Última prueba). Úselo cuando se le solicite "crear un runbook", "cargar runbook para X", documentar un procedimiento o buscar un SOP.
