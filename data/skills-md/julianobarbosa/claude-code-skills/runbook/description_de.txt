Erstellen oder laden Sie ein operatives Runbook für ein bestimmtes Thema. Durchsucht „runbooks/“ nach einer vorhandenen Übereinstimmung; Wenn keine vorhanden ist, wird ein neues Gerüst aus der Standardvorlage erstellt (Zweck/Voraussetzungen/Schritte/Überprüfung/Fehlerbehebung/Zuletzt getestet). Verwenden Sie diese Option, wenn Sie aufgefordert werden, „ein Runbook zu erstellen“, „Runbook für X zu laden“, eine Prozedur zu dokumentieren oder eine SOP nachzuschlagen.
