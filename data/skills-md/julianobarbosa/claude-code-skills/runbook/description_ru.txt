Создайте или загрузите рабочий модуль Runbook для заданной темы. Ищет в `runbooks/` существующее совпадение; если нет, создается новый шаблон из стандартного шаблона (Цель/Предварительные условия/Шаги/Проверка/Устранение неполадок/Последнее тестирование). Используйте, когда вас просят «создать Runbook», «загрузить Runbook для X», задокументировать процедуру или найти СОП.
