قم بإنشاء أو تحميل دليل تشغيلي لموضوع معين. يبحث في `runbooks/` عن تطابق موجود؛ إذا لم يكن هناك شيء، فسيتم دعم واحدة جديدة من القالب القياسي (الغرض / المتطلبات الأساسية / الخطوات / التحقق / استكشاف الأخطاء وإصلاحها / آخر اختبار). استخدمه عندما يُطلب منك "إنشاء دليل تشغيل" أو "تحميل دليل تشغيل لـ X" أو توثيق إجراء أو البحث عن إجراء تشغيل موحد (SOP).
