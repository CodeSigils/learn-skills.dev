사용자 인터뷰, Azure 구독 매핑, IP 주소 지정 문서 통합, Microsoft 클라우드 채택 프레임워크 모범 사례 적용을 통해 Microsoft Azure Landing Zone(ALZ) Accelerator 검사 목록을 작성합니다. ALZ 배포에 준비된 완성된 Excel 체크리스트(.xlsx)를 생성합니다. 사용자가 Azure 랜딩 영역, ALZ 검사 목록, 랜딩 영역 가속기, 플랫폼 랜딩 영역 구성, ALZ 부트스트랩, 허브 및 스포크 설정, Azure 네트워크 토폴로지 계획을 언급하거나 ALZ 관련 검사 목록 또는 구성 파일을 작성하려고 할 때마다 이 기술을 사용합니다. 또한 사용자가 "Accelerator - Bootstrap", "Accelerator - Bicep" 또는 "Accelerator - Terraform"과 같은 탭이 포함된 Excel 파일을 업로드할 때도 트리거됩니다.
