Compila gli elenchi di controllo dell'acceleratore Microsoft Azure Landing Zone (ALZ) intervistando l'utente, mappando i suoi abbonamenti ad Azure, integrando la documentazione sugli indirizzi IP e applicando le best practice di Microsoft Cloud Adoption Framework. Produce un elenco di controllo Excel completato (.xlsx) pronto per la distribuzione ALZ. Usare questa competenza ogni volta che l'utente menziona Azure Landing Zone, elenco di controllo ALZ, acceleratore della zona di destinazione, configurazione della zona di destinazione della piattaforma, bootstrap ALZ, configurazione hub-and-spoke, pianificazione della topologia di rete di Azure o vuole compilare qualsiasi elenco di controllo o file di configurazione correlato ad ALZ. Si attiva anche quando l'utente carica un file Excel che contiene schede come "Accelerator - Bootstrap", "Accelerator - Bicep" o "Accelerator - Terraform".
