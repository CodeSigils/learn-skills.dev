ユーザーにインタビューし、Azure サブスクリプションをマッピングし、IP アドレス指定ドキュメントを統合し、Microsoft Cloud Adoption Framework のベスト プラクティスを適用することで、Microsoft Azure Landing Zone (ALZ) Accelerator チェックリストに記入します。 ALZ 導入の準備が完了した Excel チェックリスト (.xlsx) を作成します。ユーザーが Azure ランディング ゾーン、ALZ チェックリスト、ランディング ゾーン アクセラレータ、プラットフォーム ランディング ゾーン構成、ALZ ブートストラップ、ハブアンドスポーク セットアップ、Azure ネットワーク トポロジ計画について言及した場合、または ALZ 関連のチェックリストまたは構成ファイルに記入したい場合は、このスキルを使用します。また、ユーザーが「Accelerator - Bootstrap」、「Accelerator - Bicep」、「Accelerator - Terraform」などのタブを含む Excel ファイルをアップロードしたときにもトリガーされます。
