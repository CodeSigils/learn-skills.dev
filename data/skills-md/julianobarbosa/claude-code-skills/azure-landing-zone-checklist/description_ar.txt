قم بملء قوائم مراجعة Microsoft Azure Landing Zone (ALZ) Accelerator من خلال إجراء مقابلة مع المستخدم، وتعيين اشتراكات Azure الخاصة به، ودمج وثائق عنونة IP، وتطبيق أفضل ممارسات Microsoft Cloud Adoption Framework. يُنتج قائمة مراجعة Excel مكتملة (.xlsx) جاهزة لنشر ALZ. استخدم هذه المهارة عندما يذكر المستخدم منطقة Azure Landing Zone، أو قائمة اختيار ALZ، أو مسرع منطقة الهبوط، أو تكوين منطقة هبوط النظام الأساسي، أو ALZ bootstrap، أو إعداد المحور والتحدث، أو تخطيط هيكل شبكة Azure، أو يريد ملء أي قائمة تحقق أو ملف تكوين متعلق بـ ALZ. يتم تشغيله أيضًا عندما يقوم المستخدم بتحميل ملف Excel يحتوي على علامات تبويب مثل "Accelerator - Bootstrap"، أو "Accelerator - Bicep"، أو "Accelerator - Terraform".
