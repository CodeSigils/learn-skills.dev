Füllen Sie die Checklisten für den Microsoft Azure Landing Zone (ALZ) Accelerator aus, indem Sie den Benutzer befragen, seine Azure-Abonnements zuordnen, die IP-Adressierungsdokumentation integrieren und Best Practices des Microsoft Cloud Adoption Framework anwenden. Erstellt eine vollständige Excel-Checkliste (.xlsx), die für die ALZ-Bereitstellung bereit ist. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Azure Landing Zone, ALZ-Checkliste, Landing Zone Accelerator, Plattform-Landing-Zone-Konfiguration, ALZ-Bootstrap, Hub-and-Spoke-Einrichtung, Azure-Netzwerktopologieplanung erwähnt oder eine ALZ-bezogene Checkliste oder Konfigurationsdatei ausfüllen möchte. Wird auch ausgelöst, wenn der Benutzer eine Excel-Datei hochlädt, die Registerkarten wie „Accelerator – Bootstrap“, „Accelerator – Bicep“ oder „Accelerator – Terraform“ enthält.
