Заполните контрольные списки акселератора Microsoft Azure Landing Zone (ALZ), опросив пользователя, сопоставив его подписки Azure, интегрировав документацию по IP-адресации и применив лучшие практики Microsoft Cloud Adoption Framework. Создает заполненный контрольный список Excel (.xlsx), готовый к развертыванию ALZ. Используйте этот навык всякий раз, когда пользователь упоминает зону приземления Azure, контрольный список ALZ, ускоритель зоны приземления, конфигурацию зоны приземления платформы, начальную загрузку ALZ, звездообразную настройку, планирование топологии сети Azure или хочет заполнить любой контрольный список или файл конфигурации, связанный с ALZ. Также срабатывает, когда пользователь загружает файл Excel, содержащий такие вкладки, как «Ускоритель — Bootstrap», «Ускоритель — Бицепс» или «Ускоритель — Terraform».
