Implemente Azure Landing Zones utilizando ALZ Accelerator con AVM (módulos verificados de Azure). Utilice esta habilidad siempre que el usuario mencione Azure Landing Zones, ALZ, acelerador de zonas de aterrizaje de Azure, módulos AVM para zonas de aterrizaje, implementación de grupos de administración, redes radiales, WAN virtual, zonas de aterrizaje de plataforma o pregunte sobre Bicep vs Terraform para la infraestructura de Azure. También se activa cuando el usuario desea iniciar CI/CD para la implementación de la plataforma Azure, configurar la jerarquía de grupos de administración o implementar suscripciones a la plataforma de administración/identidad/conectividad.
