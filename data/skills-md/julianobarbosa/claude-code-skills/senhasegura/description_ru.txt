Интеграция платформы Senhasegura PAM — A2A OAuth 2.0, учетные данные PAM Core, ротация ключей SSH, интерфейс командной строки DSM для CI/CD, внешний оператор секретов (Kubernetes), MySafe и работоспособный сервер MCP. ИСПОЛЬЗУЙТЕ КОГДА senhasegura, segura, приложение A2A, DSM CLI, runb, MySafe, ExternalSecret + senhasegura, OAuth client_credentials для PAM, освобождение от хранения учетных данных, конечная точка /iso/coe/senha, подготовка SCIM. НЕ ДЛЯ HashiCorp Vault, AWS Secrets Manager, Azure Key Vault, GCP Secret Manager, 1Password или общих потоков OAuth 2.0 (используйте их напрямую).
