Senhasegura PAM 平台集成 — A2A OAuth 2.0、PAM Core 凭证、SSH 密钥轮换、适用于 CI/CD 的 DSM CLI、External Secrets Operator (Kubernetes)、MySafe 和可运行的 MCP 服务器。使用 senhasegura、segura、A2A 应用程序、DSM CLI、runb、MySafe、ExternalSecret + senhasegura、PAM 的 OAuth client_credentials、凭证保管发布、/iso/coe/senha 端点、SCIM 配置。不适用于 HashiCorp Vault、AWS Secrets Manager、Azure Key Vault、GCP Secret Manager、1Password 或通用 OAuth 2.0 流程（直接使用这些流程）。
