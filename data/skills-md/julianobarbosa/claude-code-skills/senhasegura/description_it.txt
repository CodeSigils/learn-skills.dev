DA USARE QUANDO senhasegura, segura, applicazione A2A, CLI DSM, runb, MySafe, ExternalSecret + senhasegura, OAuth client_credentials per PAM, rilascio di custodia delle credenziali, endpoint /iso/coe/senha, provisioning SCIM. NON PER HashiCorp Vault, AWS Secrets Manager, Azure Key Vault, GCP Secret Manager, 1Password o flussi OAuth 2.0 generici (utilizzarli direttamente).
