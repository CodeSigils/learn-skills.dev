Senhasegura PAM プラットフォームの統合 — A2A OAuth 2.0、PAM コア認証情報、SSH キー ローテーション、CI/CD 用の DSM CLI、外部シークレット オペレーター (Kubernetes)、MySafe、および実行可能な MCP サーバー。 senhasegura、segura、A2A アプリケーション、DSM CLI、runb、MySafe、ExternalSecret + senhasegura、PAM 用の OAuth client_credentials、資格情報保管リリース、/iso/coe/senha エンドポイント、SCIM プロビジョニングの場合に使用します。 HashiCorp Vault、AWS Secrets Manager、Azure Key Vault、GCP Secret Manager、1Password、または汎用 OAuth 2.0 フローには使用できません (これらを直接使用します)。
