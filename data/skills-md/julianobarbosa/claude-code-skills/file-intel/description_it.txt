Esegui il processore di file Gemini su qualsiasi cartella: estrae contenuti da PDF, PPTX, XLSX, DOCX, CSV, JSON e qualsiasi formato di testo, quindi genera riepiloghi pronti per Obsidian. Utilizzare quando viene richiesto di "riepilogare questa cartella", "eseguire informazioni sul file", "elaborare questi file" o viene fornito un percorso di cartella e sono necessari riepiloghi.
