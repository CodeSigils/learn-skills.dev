Запустите файловый процессор Gemini в любой папке — он извлекает содержимое из PDF, PPTX, XLSX, DOCX, CSV, JSON и любого текстового формата, а затем генерирует сводки, готовые для Obsidian. Используйте, когда вас просят «подвести итоги по этой папке», «запустить информацию о файле», «обработать эти файлы» или если указан путь к папке, и необходимы сводки.
