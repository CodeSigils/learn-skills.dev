تأليف لغة Kusto Query وتصحيح الأخطاء والتحسين والترجمة واستخدام الأدوات لـ Azure Monitor وSentinel وADX وApplication Insights. يُستخدم عندما يذكر المستخدم "KQL"، و"Kusto"، و"استعلام تحليلات السجل"، و"استعلام Sentinel"، و"استعلام البحث"، و"استعلام ADX"، و"استعلام رؤى التطبيق"، و"ترجمة SQL إلى KQL"، و"Splunk إلى KQL"، و"تحسين الاستعلام"، و"أداء KQL"، و"ملف .kql"، و"قاعدة الكشف"، و"قاعدة التحليلات"، "صيد التهديدات"، أو "استعلام مراقبة Azure"، أو "الاستعلام عن السجل"، أو "تلخيص المشغل"، أو "حيث يتم إنشاء TimeGenerated"، أو أي طلب يتضمن الاستعلام عن بيانات سجل/قياس عن بعد لـ Azure. حتى إذا لم يذكر المستخدم "KQL" بشكل صريح - إذا كان يسأل عن الاستعلام عن سجلات Azure أو الأحداث الأمنية أو بيانات القياس عن بعد، فسيتم تطبيق هذه المهارة.
