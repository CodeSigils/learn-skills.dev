Framework di hook pre-commit per l'automazione della qualità del codice multilingue. DA USARE QUANDO si imposta il pre-commit O si configurano gli hook git O si aggiungono linting O la formattazione del codice O la scansione di sicurezza O la convalida Terraform O i manifest Kubernetes O i grafici Helm O l'linting Python O la formattazione JavaScript. Gestisce .pre-commit-config.yaml, installazione hook e integrazione CI.
