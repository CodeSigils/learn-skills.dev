قم بتشغيل YouTube Music عبر اللغة الطبيعية. ابحث عن الأغاني والفنانين والألبومات وقوائم التشغيل وكلمات الأغاني والمخططات والتوصيات والتحكم في التشغيل. تصفح المكتبة الشخصية وإدارة قوائم التشغيل وتقييم المسارات وفحص معلومات الحساب. استخدم هذه المهارة عندما يسأل المستخدم عن YouTube Music، أو يريد تشغيل الموسيقى، أو إدارة قوائم التشغيل، أو البحث حسب الأغنية أو اسم الفنان، أو فحص كلمات الأغاني، أو التحكم في التشغيل.
