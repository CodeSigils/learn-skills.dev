Сквозная доставка ветки: фиксация (без атрибуции AI) → push → открыть запрос на включение → убедиться, что рабочий элемент Board существует (создать один для каждой задачи, назначенной настроенному пользователю, если таковой отсутствует) и связать его → после слияния очистить ветку и рабочее дерево. Автоматически определяет платформу удаленно — Azure Repos + Boards (azure-devops-node-api SDK; резервный вариант носителя OAuth через `az`) или GitHub (Octokit; `gh` для аутентификации). Скрипты TypeScript, запускаются через `bun`. Используйте всякий раз, когда вас просят «отправить», «отправить», «отправить эту ветку», «открыть PR», «отправить и открыть PR», «поднять PR», «доставить это», «отправить это на рассмотрение» или «создать PR и связать рабочий элемент» — а также когда прямое нажатие на основной блокируется и вместо этого изменение должно пройти через PR. Также охватывает моментальный снимок текущего состояния в виде аннотированного тега git — используйте всякий раз, когда вас просят «сохранить текущее состояние», «пометить это», «сфотографировать состояние», «создать контрольную точку», «пометить точку выпуска» или «отметить, где мы находимся» (контрольная точка git-тега, отличная от меток/тегов PR). Также открывает только что созданный (или любой) PR в выбранном профиле учетной записи браузера — используйте всякий раз, когда вас просят «открыть PR в моем браузере», «открыть его в Edge/Chrome» или «открыть PR как <аккаунт>».
