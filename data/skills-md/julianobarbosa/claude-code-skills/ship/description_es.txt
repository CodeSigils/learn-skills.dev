Entrega de rama de un extremo a otro: confirmar (sin atribución de IA) → empujar → abrir una solicitud de extracción → garantizar que exista un elemento de trabajo de la Junta (crear uno por tarea, asignado al usuario configurado, si no hay ninguno) y vincularlo → después de fusionar, limpiar la rama y el árbol de trabajo. Detecta automáticamente la plataforma desde el control remoto: Azure Repos + Boards (azure-devops-node-api SDK; respaldo de inserción de OAuth Bearer a través de `az`) o GitHub (Octokit; `gh` para autenticación). Los scripts son TypeScript y se ejecutan mediante `bun`. Úselo cuando se le solicite "enviar", "enviarlo", "enviar esta rama", "abrir un PR", "enviar y abrir un PR", "generar un PR", "entregar esto", "enviar esto para revisión" o "crear un PR y vincular el elemento de trabajo", y cuando se bloquea un envío directo al principal y el cambio debe pasar por un PR. También cubre la toma de instantáneas del estado actual como una etiqueta git anotada: utilícela cuando se le solicite "guardar el estado actual", "etiquetar esto", "capturar una instantánea del estado", "crear un punto de control", "etiquetar un punto de lanzamiento" o "marcar dónde estamos" (un punto de control de etiqueta git, distinto de las etiquetas/etiquetas PR). También abre un PR recién creado (o cualquier) en un perfil de cuenta de navegador elegido; utilícelo cuando se le solicite "abrir el PR en mi navegador", "abrirlo en Edge/Chrome" o "abrir el PR como <cuenta>".
