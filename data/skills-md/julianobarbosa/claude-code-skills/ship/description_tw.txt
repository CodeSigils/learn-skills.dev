端對端分支交付：提交（無 AI 歸屬）→ 推送 → 開啟拉取請求 → 確保 Board 工作項目存在（每個任務建立一個，分配給配置的用戶，如果沒有）並連結它 → 合併後，清理分支和工作樹。自動偵測遠端平台 — Azure Repos + Boards（azure-devops-node-api SDK；透過「az」進行 OAuth Bearer 推送回退）或 GitHub（Octokit；「gh」表示驗證）。腳本是 TypeScript，透過「bun」運行。每當被要求「發布」、「發布它」、「發布這個分支」、「開啟 PR」、「推送並開啟 PR」、「提出 PR」、「交付此」、「發送此供審核」或「建立 PR 並連結工作項目」時，以及當直接推送到主幹被阻止並且更改需要通過 PR 時，請使用。還包括將當前狀態快照為帶註釋的 git 標籤——每當被要求「保存當前狀態」、「標記此」、「快照狀態」、「建立檢查點」、「標記發佈點」或「標記我們所在的位置」時使用（git-tag 檢查點，與 PR 標籤/標籤不同）。也可以在選定的瀏覽器帳戶設定檔中開啟剛剛建立的（或任何）PR - 每當被要求「在我的瀏覽器中開啟 PR」、「在 Edge/Chrome 中開啟它」或「以 <帳戶> 身分開啟 PR」時使用。
