엔드투엔드 브랜치 전달: 커밋(AI 속성 없음) → 푸시 → 풀 요청 열기 → 보드 작업 항목이 있는지 확인하고(작업당 하나 ​​생성, 없는 경우 구성된 사용자에게 할당) 연결 → 병합 후 브랜치 및 작업 트리 정리. Azure Repos + Boards(azure-devops-node-api SDK, 'az'를 통한 OAuth Bearer 푸시 대체) 또는 GitHub(Octokit, 인증의 경우 'gh') 등 원격에서 플랫폼을 자동 감지합니다. 스크립트는 TypeScript이며 `bun`을 통해 실행됩니다. "배송", "배송", "이 브랜치 배송", "PR 열기", "PR 푸시 및 열기", "PR 올리기", "이것을 전달", "검토를 위해 보내기" 또는 "PR 생성 및 작업 항목 연결"을 요청할 때마다 그리고 메인에 대한 직접 푸시가 차단되어 변경 사항이 대신 PR을 거쳐야 하는 경우에 사용합니다. 또한 주석이 달린 git 태그로 현재 상태의 스냅샷을 다룹니다. "현재 상태 저장", "이 태그 지정", "상태 스냅샷", "체크포인트 생성", "릴리스 지점 태그 지정" 또는 "현재 위치 표시"(PR 레이블/태그와는 다른 git-tag 체크포인트)를 요청할 때마다 사용합니다. 또한 선택한 브라우저 계정 프로필에서 방금 생성된(또는 임의의) PR을 엽니다. "내 브라우저에서 PR 열기", "Edge/Chrome에서 열기" 또는 "<계정>으로 PR 열기"를 묻는 메시지가 나타날 때마다 사용합니다.
