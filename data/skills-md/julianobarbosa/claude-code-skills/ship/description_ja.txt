エンドツーエンドのブランチ配信: コミット (AI アトリビューションなし) → プッシュ → プル リクエストを開く → ボードの作業項目が存在することを確認し (タスクごとに 1 つ作成し、ない場合は構成されたユーザーに割り当てます)、リンクします → マージ後、ブランチとワークツリーをクリーンアップします。リモートからプラットフォームを自動検出します — Azure Repos + Boards (azure-devops-node-api SDK; OAuth Bearer プッシュ フォールバック (`az` 経由)) または GitHub (Octokit; 認証用の `gh`)。スクリプトは TypeScript であり、`bun` 経由で実行されます。 「出荷する」、「出荷する」、「このブランチを出荷する」、「PR を開く」、「PR をプッシュして開く」、「PR を作成する」、「これを配信する」、「これをレビュー用に送信する」、「PR を作成して作業項目をリンクする」を要求された場合、およびメインへの直接プッシュがブロックされ、変更を代わりに PR を経由する必要がある場合に使用します。また、注釈付きの git タグとして現在の状態のスナップショットを作成することについても説明します。「現在の状態を保存する」、「これにタグを付ける」、「状態のスナップショットを作成する」、「チェックポイントを作成する」、「リリース ポイントにタグを付ける」、「現在の位置をマークする」 (PR ラベル/タグとは異なる git タグ チェックポイント) を求められる場合は常に使用します。また、選択したブラウザー アカウント プロファイルで作成したばかりの (または任意の) PR を開きます。「PR をブラウザーで開く」、「Edge/Chrome で開く」、または「PR を <アカウント> として開く」ように求められた場合は常に使用します。
