تسليم الفرع من طرف إلى طرف: الالتزام (بدون إسناد الذكاء الاصطناعي) ← دفع ← فتح طلب سحب ← التأكد من وجود عنصر عمل اللوحة (إنشاء عنصر لكل مهمة، وتعيينه للمستخدم الذي تم تكوينه، إذا لم يكن هناك) وربطه → بعد الدمج، قم بتنظيف الفرع وشجرة العمل. يكتشف النظام الأساسي تلقائيًا من جهاز التحكم عن بُعد — Azure Repos + Boards (azure-devops-node-api SDK؛ OAuth Bearer دفع احتياطي عبر `az`) أو GitHub (Octokit؛ `gh` للمصادقة). البرامج النصية هي TypeScript، ويتم تشغيلها عبر `bun`. استخدم عندما يُطلب منك "شحن"، أو "شحن"، أو "شحن هذا الفرع"، أو "فتح PR"، أو "دفع وفتح PR"، أو "رفع PR"، أو "تسليم هذا"، أو "إرسال هذا للمراجعة"، أو "إنشاء PR وربط عنصر العمل" - وعندما يتم حظر الدفع المباشر إلى الرئيسي ويحتاج التغيير إلى المرور عبر PR بدلاً من ذلك. يغطي أيضًا لقطة الحالة الحالية كعلامة git مشروحة - استخدمها عندما يُطلب منك "حفظ الحالة الحالية" أو "وضع علامة على هذا" أو "لقطة للحالة" أو "إنشاء نقطة تفتيش" أو "وضع علامة على نقطة الإصدار" أو "وضع علامة على مكان تواجدنا" (نقطة تفتيش git-tag، تختلف عن تسميات/علامات العلاقات العامة). يفتح أيضًا ملف تعريف العلاقات العامة الذي تم إنشاؤه للتو (أو أي شيء) في ملف تعريف حساب المتصفح المختار - استخدمه عندما يُطلب منك "فتح الملف التعريفي في متصفحي"، أو "فتحه في Edge/Chrome"، أو "فتح الملف التعريفي كـ <حساب>".
