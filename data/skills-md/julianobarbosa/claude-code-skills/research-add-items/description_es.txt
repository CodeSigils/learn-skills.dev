Agregue nuevos elementos (objetos de investigación) al `outline.yaml` de un esquema de investigación en progreso, obtenido de su entrada directa, de un agente de búsqueda web o de ambos. Utilice mid-`/research-outline` cuando se haya dado cuenta de que la lista de elementos está incompleta (surgió un nuevo competidor, se perdió una entrada histórica importante, una categoría necesita una cobertura más amplia) antes de ejecutar `/research-deep`, de modo que los nuevos elementos sean parte del paso profundo paralelo en lugar de necesitar una ejecución por separado.
