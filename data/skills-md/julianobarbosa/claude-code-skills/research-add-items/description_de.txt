Hängen Sie neue Elemente (Forschungsobjekte) an die „outline.yaml“ einer laufenden Forschungsskizze an – die aus Ihrer direkten Eingabe, einem Web-Suchagenten oder beidem stammt. Verwenden Sie mid-`/research-outline`, wenn Sie festgestellt haben, dass die Artikelliste unvollständig ist (ein neuer Konkurrent ist aufgetaucht, ein wichtiger historischer Eintrag wurde übersehen, eine Kategorie muss breiter abgedeckt werden), bevor Sie `/research-deep` ausführen, damit die neuen Artikel Teil des parallelen Tiefendurchlaufs sind und keinen separaten Lauf erfordern.
