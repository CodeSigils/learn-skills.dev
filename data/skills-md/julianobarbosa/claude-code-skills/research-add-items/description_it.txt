Aggiungi nuovi elementi (oggetti di ricerca) a "outline.yaml" di una struttura di ricerca in corso, proveniente dal tuo input diretto, da un agente di ricerca web o da entrambi. Utilizza mid-`/research-outline` quando ti rendi conto che l'elenco degli elementi è incompleto (è emerso un nuovo concorrente, un'importante voce storica è stata persa, una categoria necessita di una copertura più ampia) prima di eseguire "/research-deep", in modo che i nuovi elementi facciano parte del passaggio profondo parallelo invece di richiedere un'esecuzione separata.
