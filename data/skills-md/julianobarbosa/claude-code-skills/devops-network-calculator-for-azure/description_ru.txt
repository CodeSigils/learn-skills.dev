Планирование сети Azure, расчет CIDR, определение размера подсети и инструмент передового опыта. Используйте этот навык всякий раз, когда пользователь задает вопросы о размере подсети, планировании CIDR, сети AKS, правилах NSG, сегментации сети, управлении IP-адресами, планировании виртуальной сети, анализе адресного пространства, обнаружении перекрытия или любой теме о сети Azure. Также срабатывает, когда пользователь упоминает сетевой калькулятор, net-calc, рассчитывает узлы, планирует подсети или спрашивает о лучших методах работы в сети Azure, даже если они явно не говорят «сетевой калькулятор».
