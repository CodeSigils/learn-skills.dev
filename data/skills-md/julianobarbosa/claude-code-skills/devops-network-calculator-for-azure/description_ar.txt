تخطيط شبكة Azure، وحساب CIDR، وحجم الشبكة الفرعية، وأداة أفضل الممارسات. استخدم هذه المهارة عندما يسأل المستخدم عن حجم الشبكة الفرعية، أو تخطيط CIDR، أو شبكة AKS، أو قواعد NSG، أو تجزئة الشبكة، أو إدارة عنوان IP، أو تخطيط VNet، أو تحليل مساحة العنوان، أو اكتشاف التداخل، أو أي موضوع لشبكات Azure. يتم التشغيل أيضًا عندما يذكر المستخدم حاسبة الشبكة، أو net-calc، أو حساب المضيفين، أو التخطيط للشبكات الفرعية، أو يسأل عن أفضل ممارسات شبكة Azure، حتى إذا لم يذكر صراحةً "حاسبة الشبكة".
