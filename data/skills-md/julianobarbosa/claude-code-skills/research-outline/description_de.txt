Starten Sie ein strukturiertes Forschungsprojekt zu einem beliebigen Thema – erstellen Sie eine erste Artikelliste und ein Forschungsfeldschema aus Modellwissen, ergänzen Sie es mit einer aktuellen Websuche und geben Sie dann „outline.yaml“ + „fields.yaml“ aus, die den Rest der Forschungspipeline steuern. Verwenden Sie diese Option, wenn Sie mit akademischer Forschung, Benchmark-Vergleichen, Technologieauswahl, Wettbewerbsanalysen, Marktscans, Literaturrecherchen oder jeder strukturierten Untersuchung beginnen, die vor tieferen Einblicken ein typisiertes Schema erfordert – selbst wenn der Benutzer nur „Lass uns X recherchieren“ sagt, ohne explizit nach einer Gliederung zu fragen.
