Запустите структурированный исследовательский проект по любой теме — сгенерируйте первоначальный список элементов и схему области исследования на основе знаний модели, дополните его актуальными данными веб-поиска, а затем создайте `outline.yaml` + `fields.yaml`, которые будут управлять остальной частью исследовательского конвейера. Используйте при начале академических исследований, сравнении эталонных показателей, выборе технологий, конкурентном анализе, сканировании рынка, обзорах литературы или любом структурированном исследовании, требующем типизированной схемы перед глубоким погружением — даже когда пользователь просто говорит «давайте исследуем X», не запрашивая явным образом схему.
