قم بتشغيل مشروع بحث منظم حول أي موضوع - قم بإنشاء قائمة عناصر أولية ومخطط لمجال البحث من المعرفة النموذجية، وأكملها ببحث الويب الحديث، ثم قم بإصدار `outline.yaml` + `fields.yaml` التي تقود بقية مسار البحث. يُستخدم عند بدء البحث الأكاديمي، أو مقارنات المعايير، أو اختيار التكنولوجيا، أو التحليل التنافسي، أو عمليات مسح السوق، أو مراجعات الأدبيات، أو أي تحقيق منظم يحتاج إلى مخطط مكتوب قبل التعمق في البحث - حتى عندما يقول المستخدم "دعونا نبحث عن X" دون أن يطلب صراحةً مخططًا تفصيليًا.
