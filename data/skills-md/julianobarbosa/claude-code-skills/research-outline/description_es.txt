Arranque un proyecto de investigación estructurado sobre cualquier tema: genere una lista de elementos iniciales y un esquema de campo de investigación a partir del conocimiento del modelo, complételo con una búsqueda web actualizada y luego emita `outline.yaml` + `fields.yaml` que impulsan el resto del proceso de investigación. Úselo al iniciar una investigación académica, comparaciones de referencia, selección de tecnología, análisis competitivo, escaneos de mercado, revisiones de literatura o cualquier investigación estructurada que necesite un esquema escrito antes de profundizar, incluso cuando el usuario simplemente dice "investiguemos X" sin pedir explícitamente un esquema.
