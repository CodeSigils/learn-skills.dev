Сканирование безопасности образов контейнеров, усиление защиты Dockerfile и управление образами ACR. Используйте при сканировании образов контейнеров на наличие уязвимостей с помощью Trivy, усилении защиты Dockerfiles (закрепление версий, среда выполнения без полномочий root, конфигурация SSH), импорте образов в реестр контейнеров Azure, чтобы избежать ограничений скорости Docker Hub, или при анализе результатов CVE. Также срабатывает, когда пользователь упоминает безопасность изображений, сканирование уязвимостей, исправление CVE, усиление защиты контейнеров, сканирование Trivy, безопасность Docker или импорт изображений ACR — даже если они явно не говорят «безопасность контейнера».
