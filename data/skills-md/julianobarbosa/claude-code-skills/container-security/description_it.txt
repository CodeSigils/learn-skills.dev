Scansione di sicurezza delle immagini del contenitore, rafforzamento dei file Docker e gestione delle immagini ACR. Da utilizzare durante la scansione delle immagini del contenitore per individuare vulnerabilità con Trivy, il rafforzamento dei Dockerfile (aggiunta di versioni, runtime non root, configurazione SSH), l'importazione di immagini nel Registro contenitori di Azure per evitare i limiti di velocità dell'hub Docker o l'analisi dei risultati CVE. Si attivano anche quando l'utente menziona la sicurezza dell'immagine, la scansione delle vulnerabilità, la correzione CVE, il rafforzamento dei contenitori, la scansione Trivy, la sicurezza Docker o l'importazione di immagini ACR, anche se non dicono esplicitamente "sicurezza dei contenitori".
