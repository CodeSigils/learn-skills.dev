Analyse de sécurité des images de conteneurs, renforcement de Dockerfile et gestion des images ACR. À utiliser lors de l'analyse des images de conteneurs à la recherche de vulnérabilités avec Trivy, du renforcement des fichiers Docker (épinglage des versions, runtime non root, configuration SSH), de l'importation d'images dans Azure Container Registry pour éviter les limites de débit de Docker Hub ou de l'analyse des résultats CVE. Se déclenche également lorsque l'utilisateur mentionne la sécurité des images, l'analyse des vulnérabilités, la correction CVE, le renforcement des conteneurs, l'analyse Trivy, la sécurité Docker ou l'importation d'images ACR, même s'il ne dit pas explicitement « sécurité des conteneurs ».
