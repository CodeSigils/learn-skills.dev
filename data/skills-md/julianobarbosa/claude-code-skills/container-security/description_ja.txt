コンテナー イメージのセキュリティ スキャン、Dockerfile の強化、ACR イメージの管理。 Trivy でコンテナー イメージの脆弱性をスキャンする場合、Dockerfile を強化する場合 (バージョンの固定、非ルート ランタイム、SSH 構成)、Docker Hub のレート制限を回避するためにイメージを Azure Container Registry にインポートする場合、または CVE の結果を分析する場合に使用します。また、ユーザーがイメージ セキュリティ、脆弱性スキャン、CVE 修復、コンテナ強化、Trivy スキャン、Docker セキュリティ、または ACR イメージ インポートに言及したときにもトリガーされます。たとえ「コンテナ セキュリティ」と明示的に言わなくても。
