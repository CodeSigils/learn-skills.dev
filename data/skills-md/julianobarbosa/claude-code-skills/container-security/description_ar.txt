فحص أمان صورة الحاوية وتقوية Dockerfile وإدارة صور ACR. يُستخدم عند فحص صور الحاويات بحثًا عن الثغرات الأمنية باستخدام Trivy، أو تقوية ملفات Dockerfiles (تثبيت الإصدارات، أو وقت التشغيل غير الجذر، أو تكوين SSH)، أو استيراد الصور إلى Azure Container Registry لتجنب حدود معدل Docker Hub، أو تحليل نتائج CVE. يتم تشغيله أيضًا عندما يذكر المستخدم أمان الصورة، أو فحص الثغرات الأمنية، أو معالجة CVE، أو تقوية الحاوية، أو فحص Trivy، أو أمان Docker، أو استيراد صور ACR - حتى لو لم يذكر "أمان الحاوية" صراحةً.
