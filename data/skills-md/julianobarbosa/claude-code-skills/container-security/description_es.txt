Escaneo de seguridad de imágenes de contenedores, refuerzo de Dockerfile y administración de imágenes ACR. Úselo al escanear imágenes de contenedores en busca de vulnerabilidades con Trivy, reforzar Dockerfiles (fijar versiones, tiempo de ejecución no raíz, configuración SSH), importar imágenes a Azure Container Registry para evitar los límites de velocidad de Docker Hub o analizar los hallazgos de CVE. También se activa cuando el usuario menciona seguridad de imágenes, escaneo de vulnerabilidades, corrección de CVE, protección de contenedores, escaneo Trivy, seguridad de Docker o importación de imágenes ACR, incluso si no dice explícitamente "seguridad de contenedores".
