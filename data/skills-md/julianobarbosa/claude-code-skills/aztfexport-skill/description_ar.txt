يُستخدم عند تصدير موارد Azure الموجودة إلى Terraform باستخدام aztfexport. المشغلات على aztfexport، واستيراد Azure إلى Terraform، وتصدير مورد Azure، وإخضاع Azure لإدارة Terraform، والهندسة العكسية للبنية التحتية لـ Azure، وتمهيد IaC من موارد Azure المباشرة. يغطي أوضاع الموارد ومجموعة الموارد والاستعلام.
