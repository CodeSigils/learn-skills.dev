قم ببناء مشاريع تقارير Power BI PBIR والتحقق من صحتها ومعاينتها وإدارتها باستخدام pbi-cli. قم باستدعاء هذه المهارة عندما يذكر المستخدم "إنشاء تقرير"، أو "تقرير جديد"، أو "PBIR"، أو "سقالة"، أو "التحقق من صحة التقرير"، أو "بنية التقرير"، أو "معاينة التقرير"، أو "معلومات التقرير"، أو "إعادة تحميل سطح المكتب"، أو "تحويل التقرير"، أو ".pbip project"، أو "مشروع التقرير"، أو يريد فهم تنسيق مجلد PBIR، أو إعداد تقرير جديد من البداية، أو العمل مع التقرير ككل. للحصول على مهام محددة، راجع أيضًا: power-bi-visuals (المخططات، الربط)، power-bi-pages (إدارة الصفحة)، power-bi-themes (الموضوعات، التنسيق)، power-bi-filters (مرشحات الصفحة/المرئية).
