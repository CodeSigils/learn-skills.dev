Échafaudez, validez, prévisualisez et gérez les projets de rapports Power BI PBIR à l'aide de pbi-cli. Invoquez cette compétence chaque fois que l'utilisateur mentionne « créer un rapport », « nouveau rapport », « PBIR », « échafaudage », « valider le rapport », « structure du rapport », « aperçu du rapport », « informations sur le rapport », « recharger le bureau », « convertir le rapport », « projet .pbip », « projet de rapport », ou souhaite comprendre le format du dossier PBIR, configurer un nouveau rapport à partir de zéro ou travailler avec le rapport dans son ensemble. Pour des tâches spécifiques, voir aussi : power-bi-visuals (graphiques, reliure), power-bi-pages (gestion des pages), power-bi-themes (thèmes, formatage), power-bi-filters (page/filtres visuels).
