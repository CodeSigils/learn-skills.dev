Rufen Sie diese Fähigkeit immer dann auf, wenn der Benutzer „Bericht erstellen“, „Neuer Bericht“, „PBIR“, „Gerüst“, „Bericht validieren“, „Berichtsstruktur“, „Vorschaubericht“, „Berichtsinformationen“, „Desktop neu laden“, „Bericht konvertieren“, „.pbip-Projekt“, „Berichtsprojekt“ erwähnt oder das PBIR-Ordnerformat verstehen, einen neuen Bericht von Grund auf erstellen oder mit dem Bericht als Ganzes arbeiten möchte. Für spezifische Aufgaben siehe auch: Power-Bi-Visuals (Diagramme, Bindung), Power-Bi-Pages (Seitenverwaltung), Power-Bi-Themes (Themen, Formatierung), Power-Bi-Filter (Seiten-/visuelle Filter).
