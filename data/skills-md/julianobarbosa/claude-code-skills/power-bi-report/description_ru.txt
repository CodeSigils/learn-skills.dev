Формируйте, проверяйте, просматривайте и управляйте проектами отчетов Power BI PBIR с помощью pbi-cli. Вызовите этот навык всякий раз, когда пользователь упоминает «создать отчет», «новый отчет», «PBIR», «скаффолд», «проверить отчет», «структуру отчета», «предварительный просмотр отчета», «информацию об отчете», «перезагрузить рабочий стол», «преобразовать отчет», «проект .pbip», «проект отчета» или хочет понять формат папки PBIR, настроить новый отчет с нуля или работать с отчетом в целом. Для конкретных задач см. также: power-bi-visuals (диаграммы, привязка), power-bi-pages (управление страницами), power-bi-themes (темы, форматирование), power-bi-filters (фильтры страниц/визуалов).
