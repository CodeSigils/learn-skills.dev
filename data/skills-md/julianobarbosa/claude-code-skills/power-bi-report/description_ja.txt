pbi-cli を使用して、Power BI PBIR レポート プロジェクトのスキャフォールディング、検証、プレビュー、管理を行います。ユーザーが「レポートの作成」、「新しいレポート」、「PBIR」、「スキャフォールド」、「レポートの検証」、「レポート構造」、「レポートのプレビュー」、「レポート情報」、「デスクトップの再読み込み」、「レポートの変換」、「.pbip プロジェクト」、「レポート プロジェクト」に言及した場合、または PBIR フォルダー形式を理解したい場合、新しいレポートを最初から設定する場合、またはレポート全体を操作する場合は、このスキルを呼び出します。特定のタスクについては、power-bi-visuals (グラフ、バインド)、power-bi-pages (ページ管理)、power-bi-主題 (テーマ、書式設定)、power-bi-filters (ページ/ビジュアル フィルター) も参照してください。
