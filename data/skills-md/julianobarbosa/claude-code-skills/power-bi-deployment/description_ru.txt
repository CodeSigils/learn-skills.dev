Импортируйте и экспортируйте форматы TMDL/TMSL, управляйте жизненным циклом модели с помощью транзакций и контролируйте версии семантических моделей Power BI с помощью pbi-cli. Вызовите этот навык всякий раз, когда пользователь упоминает «развертывание», «экспорт», «импорт», «TMDL», «TMSL», «контроль версий», «git», «резервное копирование», «миграцию», «транзакцию», «фиксацию изменений», «откат» или хочет сохранить/восстановить состояние модели.
