Комплексная методология и принципы GitOps для облачных операций. Используйте, когда (1) проектирование архитектуры GitOps для развертываний Kubernetes, (2) реализация декларативной инфраструктуры с Git как единым источником достоверной информации, (3) настройка конвейеров непрерывного развертывания с помощью ArgoCD/Flux/Kargo, (4) установление стратегий ветвления и структур репозитория, (5) устранение неполадок, сбоев синхронизации или проблем согласования, (6) оценка решений по инструментам GitOps, (7) обучение или объяснение концепций и рекомендаций GitOps, (8) Развертывание ArgoCD в Kubernetes или AKS с поддержкой Azure Arc с идентификацией рабочей нагрузки. Охватывает 4 столпа GitOps (OpenGitOps), шаблоны, антишаблоны, экосистему инструментов, интеграцию Azure Arc и руководство по эксплуатации.
