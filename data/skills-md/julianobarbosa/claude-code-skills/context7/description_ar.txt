وثائق مكتبة محدثة خاصة بالإصدار وأمثلة لأكواد العمل مصدرها مستودعات مشروع حقيقي عبر واجهة برمجة التطبيقات لتجميع وثائق context7 - تغطي أكثر من 1000 مكتبة (React وNext.js وVue وKubernetes وGo وPython وTypeScript وPrisma وTailwind والمزيد). يُستخدم عند البحث عن توقيعات واجهة برمجة التطبيقات (API)، أو مستندات إطار العمل، أو السلوك الخاص بالإصدار، أو أمثلة التعليمات البرمجية، أو تكوين المكتبة، أو أدلة الترحيل، أو قبل كتابة التعليمات البرمجية مقابل مكتبة قد تتخيلها. ليس لإعادة هيكلة التعليمات البرمجية الموجودة، أو تصحيح منطق الأعمال، أو مفاهيم البرمجة العامة، أو المكتبات التي لا يتم فهرسة context7 (استخدم بحث الويب بدلاً من ذلك). أسس الإجابات في وثائق المصدر الحقيقي لمنع واجهات برمجة التطبيقات المهلوسة.
