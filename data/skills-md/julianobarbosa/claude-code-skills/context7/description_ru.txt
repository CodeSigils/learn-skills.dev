Актуальная документация по библиотекам для конкретных версий и примеры рабочего кода, полученные из реальных репозиториев проектов через API агрегации документации Context7, охватывают более 1000 библиотек (React, Next.js, Vue, Kubernetes, Go, Python, TypeScript, Prisma, Tailwind и другие). ИСПОЛЬЗУЙТЕ ПРИ поиске подписей API, документации платформы, поведения в зависимости от версии, примеров кода, конфигурации библиотеки, руководств по миграции ИЛИ перед написанием кода для библиотеки, о которой вы, возможно, догадываетесь. НЕ ДЛЯ рефакторинга существующего кода, отладки бизнес-логики, общих концепций программирования или библиотек, которые Context7 не индексирует (вместо этого используйте веб-поиск). Обосновывает ответы в реальной исходной документации, чтобы предотвратить галлюцинации API.
