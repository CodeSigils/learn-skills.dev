Context7 ドキュメント集約 API を介して実際のプロジェクト リポジトリからソースされた最新のバージョン固有のライブラリ ドキュメントと実用的なコード サンプル — 1000 以上のライブラリ (React、Next.js、Vue、Kubernetes、Go、Python、TypeScript、Prisma、Tailwind など) をカバーします。 API シグネチャ、フレームワーク ドキュメント、バージョン固有の動作、コード サンプル、ライブラリ構成、移行ガイドを調べるとき、または推測しているライブラリに対してコードを記述する前に使用します。既存のコードのリファクタリング、ビジネス ロジックのデバッグ、一般的なプログラミング概念、またはライブラリには使用できません。Context7 はインデックスを作成しません (代わりに Web 検索を使用します)。 API の幻覚を防ぐために、実際のソース ドキュメントで答えを根拠にします。
