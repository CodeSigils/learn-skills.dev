Escriba, ejecute y optimice consultas y medidas DAX para modelos semánticos de Power BI mediante pbi-cli. Invoque esta habilidad cada vez que el usuario mencione DAX, consulte datos en Power BI, escriba cálculos, cree medidas, pregunte sobre EVALUAR, RESUMIR COLUMNAS, CALCULAR, inteligencia de tiempo o quiera analizar/agregar datos de un modelo semántico. También se invoca cuando el usuario solicita ejecutar una consulta, probar una fórmula o verificar el recuento de filas. Esta habilidad contiene orientación fundamental sobre cómo pasar expresiones DAX a través de argumentos CLI: DAX multilínea (VAR/RETURN) requiere un manejo especial.
