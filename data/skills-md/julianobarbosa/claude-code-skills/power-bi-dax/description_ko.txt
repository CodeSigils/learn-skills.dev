pbi-cli를 사용하여 Power BI 의미 체계 모델에 대한 DAX 쿼리 및 측정값을 작성, 실행 및 최적화합니다. 사용자가 DAX를 언급하거나, Power BI에서 데이터를 쿼리하거나, 계산을 작성하거나, 측정값을 생성하거나, EVALUATE, SUMMARIZECOLUMNS, CALCULATE, 시간 인텔리전스에 대해 질문하거나 의미 체계 모델에서 데이터를 분석/집계하려고 할 때마다 이 기술을 호출합니다. 또한 사용자가 쿼리 실행, 수식 테스트 또는 행 수 확인을 요청할 때 호출됩니다. 이 기술에는 CLI 인수를 통해 DAX 식을 전달하는 데 대한 중요한 지침이 포함되어 있습니다. 여러 줄 DAX(VAR/RETURN)에는 특별한 처리가 필요합니다.
