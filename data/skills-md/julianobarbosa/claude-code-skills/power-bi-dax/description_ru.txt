Создавайте, выполняйте и оптимизируйте запросы и меры DAX для семантических моделей Power BI с помощью pbi-cli. Используйте этот навык всякий раз, когда пользователь упоминает DAX, запрашивает данные в Power BI, записывает вычисления, создает показатели, задает вопросы об ОЦЕНКЕ, СУММАРИЗИРОВАТЬ СТОЛБЦЫ, РАСЧЕТЕ, анализе времени или хочет проанализировать/агрегировать данные из семантической модели. Также вызывайте, когда пользователь просит выполнить запрос, проверить формулу или проверить количество строк. Этот навык содержит важные рекомендации по передаче выражений DAX через аргументы CLI — многострочный DAX (VAR/RETURN) требует специальной обработки.
