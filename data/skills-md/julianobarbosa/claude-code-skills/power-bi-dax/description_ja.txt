pbi-cli を使用して、Power BI セマンティック モデルの DAX クエリとメジャーを作成、実行、最適化します。ユーザーが DAX について言及したり、Power BI でデータをクエリしたり、計算を書いたり、メジャーを作成したり、EVALUATE、SUMMARIZECOLUMNS、CALCULATE、タイム インテリジェンスについて質問したり、セマンティック モデルからデータを分析/集計したりするときは常に、このスキルを呼び出します。また、ユーザーがクエリの実行、式のテスト、または行数の確認を要求したときにも呼び出します。このスキルには、CLI 引数を介して DAX 式を渡すための重要なガイダンスが含まれています。複数行の DAX (VAR/RETURN) には特別な処理が必要です。
