Scrivi, esegui e ottimizza query e misure DAX per modelli semantici di Power BI utilizzando pbi-cli. Richiamare questa competenza ogni volta che l'utente menziona DAX, esegue query sui dati in Power BI, scrive calcoli, crea misure, chiede informazioni su EVALUATE, SUMMARIZECOLUMNS, CALCULATE, time intelligence o desidera analizzare/aggregare dati da un modello semantico. Richiamare anche quando l'utente chiede di eseguire una query, testare una formula o controllare il conteggio delle righe. Questa competenza contiene indicazioni critiche sul passaggio di espressioni DAX tramite argomenti CLI: DAX su più righe (VAR/RETURN) richiede una gestione speciale.
