كتابة استعلامات ومقاييس DAX وتنفيذها وتحسينها لنماذج Power BI الدلالية باستخدام pbi-cli. قم باستدعاء هذه المهارة عندما يذكر المستخدم DAX، أو يستعلم عن البيانات في Power BI، أو يكتب العمليات الحسابية، أو ينشئ المقاييس، أو يسأل عن التقييم، أو تلخيص الأعمدة، أو الحساب، أو تحليل الوقت، أو يريد تحليل/تجميع البيانات من نموذج دلالي. يتم الاستدعاء أيضًا عندما يطلب المستخدم تشغيل استعلام أو اختبار صيغة أو التحقق من عدد الصفوف. تحتوي هذه المهارة على إرشادات هامة حول تمرير تعبيرات DAX عبر وسيطات CLI - يتطلب DAX متعدد الأسطر (VAR/RETURN) معالجة خاصة.
