Schreiben, ausführen und optimieren Sie DAX-Abfragen und -Kennzahlen für semantische Power BI-Modelle mit pbi-cli. Rufen Sie diese Fähigkeit immer dann auf, wenn der Benutzer DAX erwähnt, Daten in Power BI abfragt, Berechnungen schreibt, Kennzahlen erstellt, nach EVALUATE, SUMMARIZECOLUMNS, CALCULATE oder Zeitintelligenz fragt oder Daten aus einem semantischen Modell analysieren/aggregieren möchte. Rufen Sie es auch auf, wenn der Benutzer eine Abfrage ausführen, eine Formel testen oder die Zeilenanzahl überprüfen möchte. Dieser Skill enthält wichtige Anleitungen zum Übergeben von DAX-Ausdrücken über CLI-Argumente – mehrzeiliges DAX (VAR/RETURN) erfordert eine spezielle Behandlung.
