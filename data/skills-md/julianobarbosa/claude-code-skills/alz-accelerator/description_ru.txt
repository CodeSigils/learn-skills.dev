Разверните Azure Landing Zones с помощью ускорителя ALZ с AVM (модули, проверенные Azure). Используйте этот навык всякий раз, когда пользователь упоминает зоны приземления Azure, ALZ, ускоритель зоны приземления Azure, модули AVM для зон приземления, развертывание групп управления, звездообразную сеть, виртуальную глобальную сеть, зоны приземления платформы или спрашивает о Bicep и Terraform для инфраструктуры Azure. Также срабатывает, когда пользователь хочет выполнить начальную загрузку CI/CD для развертывания платформы Azure, настроить иерархию групп управления или развернуть подписки на платформу подключения, идентификации или управления.
