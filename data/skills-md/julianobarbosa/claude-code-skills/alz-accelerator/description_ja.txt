ALZ Accelerator と AVM (Azure Verified Modules) を使用して Azure Landing Zone をデプロイします。ユーザーが Azure ランディング ゾーン、ALZ、Azure ランディング ゾーン アクセラレータ、ランディング ゾーン用の AVM モジュール、管理グループのデプロイ、ハブアンドスポーク ネットワーキング、Virtual WAN、プラットフォーム ランディング ゾーンについて言及した場合、または Azure インフラストラクチャの Bicep と Terraform について質問した場合は、このスキルを使用します。また、ユーザーが Azure プラットフォーム デプロイ用の CI/CD をブートストラップする場合、管理グループ階層を設定する場合、または接続/アイデンティティ/管理プラットフォーム サブスクリプションをデプロイする場合にもトリガーされます。
