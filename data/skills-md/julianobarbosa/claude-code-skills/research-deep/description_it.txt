Leggi uno schema di ricerca esistente e distribuisci agenti di background indipendenti per effettuare ricerche approfondite su ciascun elemento, producendo un JSON strutturato per elemento rispetto allo schema del campo condiviso. Ripristinabile, in batch, con output disabilitato per agente (ogni agente ha il proprio file di output esplicito). Da utilizzare quando sono presenti `outline.yaml` + `fields.yaml` da `/research-outline` e si desidera parallelizzare l'indagine per elemento: approfondimenti di documenti accademici, confronti di prodotti, riempimenti di benchmark, analisi competitiva multi-target. Attivalo dopo "/research-outline", prima di "/research-report".
