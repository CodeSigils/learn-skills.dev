Прочтите существующий план исследования и распределите независимых фоновых агентов для глубокого исследования каждого элемента, создавая один структурированный JSON для каждого элемента в соответствии со схемой общего поля. Возобновляемый, пакетный, с отключенным выводом для каждого агента (каждый агент имеет свой явный выходной файл). Используйте, когда имеются `outline.yaml` +`fields.yaml` из `/research-outline` и вы хотите распараллелить исследование по каждому элементу — углубленное изучение научных статей, сравнение продуктов, заполнение контрольных показателей, многоцелевой конкурентный анализ. Запустите это после `/research-outline`, перед `/research-report`.
