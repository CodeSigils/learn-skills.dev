Lesen Sie eine vorhandene Forschungsskizze und verteilen Sie unabhängige Hintergrundagenten, um jedes Element eingehend zu recherchieren und ein strukturiertes JSON pro Element anhand des gemeinsamen Feldschemas zu erstellen. Fortsetzbar, stapelweise, mit deaktivierter Ausgabe pro Agent (jeder Agent hat seine explizite Ausgabedatei). Verwenden Sie diese Option, wenn „outline.yaml“ + „fields.yaml“ aus „/research-outline“ vorhanden sind und Sie die Untersuchung pro Artikel parallelisieren möchten – detaillierte Untersuchungen zu wissenschaftlichen Arbeiten, Produktvergleiche, Benchmark-Ausfüllungen, Wettbewerbsanalysen mit mehreren Zielen. Lösen Sie dies nach „/research-outline“ und vor „/research-report“ aus.
