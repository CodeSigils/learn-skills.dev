既存の調査概要を読み、独立したバックグラウンド エージェントをファンアウトして各項目を深く調査し、共有フィールド スキーマに対して項目ごとに 1 つの構造化 JSON を生成します。再開可能、バッチ化され、エージェントごとに出力が無効になります (各エージェントには明示的な出力ファイルがあります)。 `/research-outline` の `outline.yaml` + `fields.yaml` が適切に配置されており、学術論文の詳細な調査、製品の比較、ベンチマークの入力、複数ターゲットの競合分析など、項目ごとの調査を並列化したい場合に使用します。これを「/research-outline」の後、「/research-report」の前にトリガーします。
