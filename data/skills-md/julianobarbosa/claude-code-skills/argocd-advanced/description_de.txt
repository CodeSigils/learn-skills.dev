Erweiterte ArgoCD-Operationen, die über die Kern-CLI/API hinausgehen – Multi-Cluster-ApplicationSet-Generatoren, automatisierte Image-Updates, Bootstrapping für neue Cluster und Workload-Onboarding über vorlagenbasierte ApplicationSets. VERWENDET BEI DER Arbeit mit ApplicationSet CRDs (Liste, Cluster, Git, Matrix, Merge, SCM, Pull Request, Plugin-Generatoren), beim Konfigurieren von ArgoCD Image Updater (Semver/Digest/Newest-Build-Aktualisierungsstrategien + Git-Write-Back), beim Bootstrapping eines neuen Kubernetes-Clusters in ein Multi-Repo-GitOps-Setup, beim Registrieren von Clustern mit den richtigen Labels für das ApplicationSet-Targeting, beim Onboarding einer neuen Arbeitslast über die Standard-ApplicationSet-Vorlage oder bei der Fehlerbehebung davon. Für routinemäßige App-Synchronisierungs-/Status-/Diff-Arbeiten verwenden Sie stattdessen die Kernkompetenz „argocd“.
