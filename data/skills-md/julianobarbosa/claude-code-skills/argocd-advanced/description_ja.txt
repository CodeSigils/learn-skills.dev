コア CLI/API を超えた高度な ArgoCD 操作 - マルチクラスター ApplicationSet ジェネレーター、自動イメージ更新、新しいクラスターのブートストラップ、テンプレート化された ApplicationSet を介したワークロードのオンボーディング。 ApplicationSet CRD (リスト、クラスター、git、マトリックス、マージ、SCM、プル リクエスト、プラグイン ジェネレーター) の操作、ArgoCD Image Updater の構成 (semver/digest/newest-build 更新戦略 + git ライトバック)、新しい Kubernetes クラスターをマルチリポジトリ GitOps セットアップにブートストラップする、ApplicationSet ターゲット用の適切なラベルを使用してクラスターを登録する、標準の ApplicationSet テンプレートを介して新しいワークロードをオンボードする場合に使用します。これらのいずれかのトラブルシューティングを行います。日常的なアプリの同期/ステータス/差分の作業には、代わりにコアの `argocd` スキルを使用してください。
