عمليات ArgoCD المتقدمة تتجاوز واجهة سطر الأوامر/واجهة برمجة التطبيقات الأساسية — مولدات ApplicationSet متعددة المجموعات، وتحديثات الصور التلقائية، وبدء تشغيل المجموعة الجديدة، وتأهيل عبء العمل عبر مجموعات ApplicationSets النموذجية. يُستخدم عند العمل مع ApplicationSet CRDs (قائمة، مجموعة، git، مصفوفة، دمج، SCM، طلب سحب، مولدات المكونات الإضافية)، تكوين ArgoCD Image Updater (استراتيجيات تحديث semver/digest/newest-build + git write-back)، تمهيد مجموعة Kubernetes جديدة في إعداد GitOps متعدد الريبو، وتسجيل المجموعات بالتسميات المناسبة لاستهداف ApplicationSet، وإعداد عبء عمل جديد عبر قالب ApplicationSet القياسي، أو استكشاف أخطاء أي منها وإصلاحها. بالنسبة للعمل الروتيني لمزامنة التطبيق/الحالة/الاختلاف، استخدم مهارة "argocd" الأساسية بدلاً من ذلك.
