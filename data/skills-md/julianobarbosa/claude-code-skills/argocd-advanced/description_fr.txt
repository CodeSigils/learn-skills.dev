Opérations ArgoCD avancées au-delà de la CLI/API principale : générateurs d'ApplicationSet multiclusters, mises à jour d'images automatisées, amorçage de nouveaux clusters et intégration de la charge de travail via des ApplicationSets basés sur des modèles. À UTILISER LORSQUE vous travaillez avec des CRD ApplicationSet (liste, cluster, git, matrice, fusion, SCM, pull request, générateurs de plugins), la configuration d'ArgoCD Image Updater (stratégies de mise à jour semver/digest/newest-build + écriture git), le démarrage d'un nouveau cluster Kubernetes dans une configuration GitOps multi-dépôt, l'enregistrement de clusters avec des étiquettes appropriées pour le ciblage ApplicationSet, l'intégration d'une nouvelle charge de travail via le modèle ApplicationSet standard ou le dépannage n'importe lequel d'entre eux. Pour le travail de routine de synchronisation/statut/diff d'application, utilisez plutôt la compétence de base « argocd ».
