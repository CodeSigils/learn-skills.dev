Расширенные операции ArgoCD, выходящие за рамки основного интерфейса командной строки/API — многокластерные генераторы наборов приложений, автоматическое обновление образов, загрузка нового кластера и подключение рабочей нагрузки через шаблонные наборы приложений. ИСПОЛЬЗУЕТСЯ ПРИ работе с CRD ApplicationSet (список, кластер, git, матрица, слияние, SCM, запрос на включение, генераторы плагинов), настройке средства обновления изображений ArgoCD (стратегии обновления semver/digest/newest-build + git back write), загрузке нового кластера Kubernetes в установку GitOps с несколькими репозиториями, регистрации кластеров с соответствующими метками для таргетинга ApplicationSet, внедрении новой рабочей нагрузки через стандартный шаблон ApplicationSet или устранение любой из этих неполадок. Для рутинной работы по синхронизации/статусу/разнице приложений используйте вместо этого базовый навык `argocd`.
