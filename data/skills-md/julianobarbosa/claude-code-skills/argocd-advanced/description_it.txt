Operazioni ArgoCD avanzate oltre la CLI/API principale: generatori di ApplicationSet multi-cluster, aggiornamenti automatizzati delle immagini, bootstrap di nuovi cluster e onboarding del carico di lavoro tramite ApplicationSet basati su modelli. UTILIZZARE QUANDO si lavora con i CRD di ApplicationSet (elenco, cluster, git, matrice, unione, SCM, richiesta pull, generatori di plugin), configurando ArgoCD Image Updater (strategie di aggiornamento semver/digest/newest-build + writeback git), avviando un nuovo cluster Kubernetes in una configurazione GitOps multi-repo, registrando cluster con etichette appropriate per il targeting di ApplicationSet, inserendo un nuovo carico di lavoro tramite il modello ApplicationSet standard o risolvendo qualsiasi problema questi. Per il lavoro di routine di sincronizzazione/stato/differenza delle app, utilizzare invece l'abilità principale `argocd`.
