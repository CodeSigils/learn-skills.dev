Ajoutez, configurez, liez des données et gérez en masse des visuels sur les pages de rapport Power BI PBIR à l'aide de pbi-cli. Invoquez cette compétence chaque fois que l'utilisateur mentionne « ajouter un graphique », « graphique à barres », « graphique linéaire », « carte », « KPI », « jauge », « dispersion », « visuel de tableau », « matrice », « tranche », « graphique combiné », « lier des données », « type visuel », « disposition visuelle », « redimensionner les visuels », « mettre à jour les visuels en masse », « supprimer en masse », « calculs visuels », ou souhaite placer, déplacer, lier ou supprimer un visuel sur une page de rapport. Invoquez également lorsque l'utilisateur demande quels types de visuels sont pris en charge ou comment connecter un visuel à son modèle de données.
