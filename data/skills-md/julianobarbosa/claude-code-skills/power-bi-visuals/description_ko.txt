pbi-cli를 사용하여 Power BI PBIR 보고서 페이지에서 데이터를 추가, 구성, 바인딩하고 시각적 개체를 대량 관리합니다. 사용자가 "차트 추가", "막대형 차트", "선형 차트", "카드", "KPI", "게이지", "분산형", "테이블 시각적 개체", "행렬", "슬라이서", "콤보 차트", "데이터 바인딩", "시각적 유형", "시각적 레이아웃", "시각적 크기 조정", "시각적 대량 업데이트", "대량 삭제", "시각적 계산"을 언급하거나 원할 때마다 이 기술을 호출합니다. 보고서 페이지에 시각적 개체를 배치, 이동, 바인딩 또는 제거합니다. 또한 사용자가 어떤 시각적 유형이 지원되는지 또는 시각적 개체를 데이터 모델에 연결하는 방법을 물을 때 호출합니다.
