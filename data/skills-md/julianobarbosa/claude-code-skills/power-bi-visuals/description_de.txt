Mit pbi-cli können Sie Visuals auf Power BI PBIR-Berichtsseiten hinzufügen, konfigurieren, binden und in großen Mengen verwalten. Rufen Sie diese Fähigkeit immer dann auf, wenn der Benutzer „Diagramm hinzufügen“, „Balkendiagramm“, „Liniendiagramm“, „Karte“, „KPI“, „Anzeige“, „Streuung“, „Tabellenvisual“, „Matrix“, „Slicer“, „Kombinationsdiagramm“, „Daten binden“, „Visualtyp“, „Visuallayout“, „Visuals in der Größe ändern“, „Visuals in großen Mengen aktualisieren“, „Massenlöschen“ oder „visuelle Berechnungen“ erwähnt oder ein beliebiges Visual auf einer Berichtsseite platzieren, verschieben, binden oder entfernen möchte. Rufen Sie es auch auf, wenn der Benutzer fragt, welche visuellen Typen unterstützt werden oder wie er ein visuelles Element mit seinem Datenmodell verbindet.
