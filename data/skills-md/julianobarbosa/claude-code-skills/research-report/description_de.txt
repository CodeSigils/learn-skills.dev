Fassen Sie einen abgeschlossenen Deep-Research-Lauf in einem einzigen Markdown-Bericht zusammen – vollständige Abdeckung aller definierten Felder, automatisches Überspringen unsicherer Werte und ein navigierbares Inhaltsverzeichnis mit vom Benutzer ausgewählten Zusammenfassungsspalten. Erzeugt pro Lauf ein neues „generate_report.py“ (gegen eine stabile Spezifikation) und führt es aus. Verwenden Sie es nach Abschluss von „/research-deep“, wenn Sie ein lesbares Artefakt zum Teilen, Archivieren oder Vergleichen von Elementen im ausgewählten Schema benötigen.
