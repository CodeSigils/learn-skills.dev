Erstellen und verwalten Sie die semantische Modellstruktur von Power BI mit pbi-cli – Tabellen, Spalten, Kennzahlen, Beziehungen, Hierarchien, Berechnungsgruppen und Datums-/Kalendertabellen. Rufen Sie diese Fertigkeit immer dann auf, wenn der Benutzer „Tabelle erstellen“, „Kennzahl hinzufügen“, „Spalte hinzufügen“, „Beziehung erstellen“, „Datumstabelle“, „Kalendertabelle“, „Sternschema“, „Als Datumstabelle markieren“, „Hierarchie hinzufügen“, „Berechnungsgruppe“ oder eine andere Modellierungsaufgabe sagt. Rufen Sie ihn auch auf, wenn Sie mehrere Kennzahlen gleichzeitig erstellen. Der Skill enthält wichtige Anleitungen zur Handhabung mehrzeiliger DAX-Ausdrücke.
