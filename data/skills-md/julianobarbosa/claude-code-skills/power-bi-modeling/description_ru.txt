Создавайте структуру семантической модели Power BI и управляйте ею с помощью pbi-cli — таблиц, столбцов, показателей, связей, иерархий, групп вычислений и таблиц даты/календаря. Вызовите этот навык всякий раз, когда пользователь говорит «создать таблицу», «добавить показатель», «добавить столбец», «создать связь», «таблицу дат», «таблицу календаря», «звездообразную схему», «отметить как таблицу дат», «добавить иерархию», «группу вычислений» или выполнить любую задачу построения модели. Также вызывайте при одновременном создании нескольких мер — этот навык содержит важные рекомендации по обработке многострочных выражений DAX.
