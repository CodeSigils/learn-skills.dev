pbi-cli(테이블, 열, 측정값, 관계, 계층 구조, 계산 그룹 및 날짜/달력 테이블)를 사용하여 Power BI 의미 체계 모델 구조를 만들고 관리합니다. 사용자가 "테이블 만들기", "측정값 추가", "열 추가", "관계 만들기", "날짜 테이블", "일정 테이블", "별표 스키마", "날짜 테이블로 표시", "계층 구조 추가", "계산 그룹" 또는 모델 작성 작업을 말할 때마다 이 기술을 호출합니다. 또한 한 번에 여러 측정값을 만들 때 호출합니다. 이 기술에는 여러 줄의 DAX 식 처리에 대한 중요한 지침이 포함되어 있습니다.
