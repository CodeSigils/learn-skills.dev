قم بإنشاء وإدارة بنية النموذج الدلالي Power BI باستخدام pbi-cli - الجداول والأعمدة والمقاييس والعلاقات والتسلسلات الهرمية ومجموعات الحساب وجداول التاريخ/التقويم. قم باستدعاء هذه المهارة عندما يقول المستخدم "إنشاء جدول"، أو "إضافة مقياس"، أو "إضافة عمود"، أو "إنشاء علاقة"، أو "جدول تاريخ"، أو "جدول تقويم"، أو "مخطط النجمة"، أو "وضع علامة كجدول تاريخ"، أو "إضافة تسلسل هرمي"، أو "مجموعة حسابية"، أو أي مهمة بناء نموذج. يتم الاستدعاء أيضًا عند إنشاء مقاييس متعددة مرة واحدة - تحتوي المهارة على إرشادات مهمة حول التعامل مع تعبيرات DAX متعددة الأسطر.
