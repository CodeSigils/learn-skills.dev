pbi-cli を使用して、Power BI セマンティック モデル構造 (テーブル、列、メジャー、リレーションシップ、階層、計算グループ、日付/カレンダー テーブル) を作成および管理します。ユーザーが「テーブルの作成」、「メジャーの追加」、「列の追加」、「リレーションシップの作成」、「日付テーブル」、「カレンダー テーブル」、「スター スキーマ」、「日付テーブルとしてマーク」、「階層の追加」、「計算グループ」、またはモデル構築タスクを言うたびに、このスキルを呼び出します。複数のメジャーを一度に作成するときにも呼び出します。このスキルには、複数行の DAX 式の処理に関する重要なガイダンスが含まれています。
