Installieren und verbinden Sie die Azure Cost Management App (von Microsoft Corporation) im Power BI-Dienst über Browser-Automatisierung. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer die Installation, Bereitstellung, Verbindung oder Konfiguration der Azure Cost Management-Vorlagen-App in Power BI erwähnt oder wenn er Power BI zur Kostentransparenz mit seiner EA-Registrierung (Enterprise Agreement) verbinden möchte. Wird auch ausgelöst, wenn der Benutzer in der Cost Management App „Verbinden Sie Ihre Daten“ sagt, EA-Kostendaten in Power BI einrichten möchte oder eine Registrierungsnummer mit einem Power BI-Kostenbericht verknüpfen muss.
