Установите и подключите приложение Azure Cost Management (от корпорации Microsoft) в службе Power BI с помощью автоматизации браузера. Используйте этот навык всякий раз, когда пользователь упоминает установку, развертывание, подключение или настройку приложения-шаблона Azure Cost Management в Power BI или когда он хочет подключить Power BI к своей регистрации EA (корпоративное соглашение) для отслеживания затрат. Также срабатывает, когда пользователь говорит «подключите свои данные» в приложении «Управление затратами», хочет настроить данные о расходах EA в Power BI или ему необходимо связать номер регистрации с отчетом о затратах Power BI.
