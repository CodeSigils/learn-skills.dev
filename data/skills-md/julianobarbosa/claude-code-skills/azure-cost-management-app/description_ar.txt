قم بتثبيت تطبيق Azure Cost Management App (من شركة Microsoft Corporation) وتوصيله في خدمة Power BI عبر أتمتة المتصفح. استخدم هذه المهارة عندما يذكر المستخدم تثبيت تطبيق قالب Azure Cost Management أو نشره أو توصيله أو تكوينه في Power BI، أو عندما يريد توصيل Power BI بتسجيل EA (اتفاقية المؤسسة) الخاصة به لرؤية التكلفة. يتم تشغيله أيضًا عندما يقول المستخدم "قم بتوصيل بياناتك" في تطبيق إدارة التكلفة، أو يريد إعداد بيانات تكلفة EA في Power BI، أو يحتاج إلى ربط رقم التسجيل بتقرير تكلفة Power BI.
