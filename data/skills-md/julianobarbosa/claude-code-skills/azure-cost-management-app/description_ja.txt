ブラウザー自動化を介して、Power BI サービスに Azure Cost Management アプリ (Microsoft Corporation 製) をインストールして接続します。ユーザーが Power BI での Azure Cost Management テンプレート アプリのインストール、デプロイ、接続、構成について言及する場合、またはコストを可視化するために Power BI を EA (エンタープライズ アグリーメント) 登録に接続する場合は、このスキルを使用します。また、ユーザーがコスト管理アプリで「データを接続する」と言った場合、Power BI で EA コスト データを設定したい場合、または登録番号を Power BI コスト レポートにリンクする必要がある場合にもトリガーされます。
