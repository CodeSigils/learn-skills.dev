Instale y conecte la aplicación Azure Cost Management (de Microsoft Corporation) en el servicio Power BI a través de la automatización del navegador. Utilice esta habilidad siempre que el usuario mencione la instalación, implementación, conexión o configuración de la aplicación de plantilla de Azure Cost Management en Power BI, o cuando desee conectar Power BI a su inscripción de EA (Acuerdo empresarial) para obtener visibilidad de costos. También se activa cuando el usuario dice "conectar sus datos" en la aplicación Cost Management, desea configurar los datos de costos de EA en Power BI o necesita vincular un número de inscripción a un informe de costos de Power BI.
