Installa e connetti l'app Azure Cost Management (di Microsoft Corporation) nel servizio Power BI tramite l'automazione del browser. Usare questa competenza ogni volta che l'utente menziona l'installazione, la distribuzione, la connessione o la configurazione dell'app modello di gestione dei costi di Azure in Power BI o quando vuole connettere Power BI alla registrazione EA (contratto aziendale) per la visibilità dei costi. Si attiva anche quando l'utente dice "collega i tuoi dati" nell'app di gestione dei costi, desidera configurare i dati sui costi EA in Power BI o deve collegare un numero di registrazione a un report sui costi di Power BI.
