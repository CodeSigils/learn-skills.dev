Installez et connectez l'application Azure Cost Management (par Microsoft Corporation) dans le service Power BI via l'automatisation du navigateur. Utilisez cette compétence chaque fois que l’utilisateur mentionne l’installation, le déploiement, la connexion ou la configuration de l’application modèle Azure Cost Management dans Power BI, ou lorsqu’il souhaite connecter Power BI à son inscription EA (Enterprise Agreement) pour une visibilité sur les coûts. Se déclenche également lorsque l'utilisateur dit « connecter vos données » sur l'application Cost Management, souhaite configurer les données de coût EA dans Power BI ou doit associer un numéro d'inscription à un rapport de coûts Power BI.
