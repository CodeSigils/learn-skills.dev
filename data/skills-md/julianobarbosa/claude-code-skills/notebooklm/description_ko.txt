Notebooklm-py CLI 및 Python API를 통해 Google NotebookLM에 프로그래밍 방식으로 액세스합니다. 사용자가 연구 자료에서 노트북을 만들고, 소스(URL, YouTube, PDF, 파일)를 추가하고, 오디오 개요/팟캐스트, 비디오, 슬라이드 데크, 퀴즈, 플래시카드, 인포그래픽, 보고서, 마인드 맵 또는 데이터 테이블을 생성하려고 할 때마다 이 기술을 사용하세요. 또한 사용자가 NotebookLM을 언급하거나, 문서를 팟캐스트로 변환하거나, 학습 자료를 생성하거나, NotebookLM 워크플로를 자동화하려는 경우에도 사용합니다. 명시적으로 "NotebookLM"이라고 말하지 않더라도 마찬가지입니다. 트리거 대상: 문서의 팟캐스트, 오디오 개요, NotebookLM, 노트북 연구, PDF에서 퀴즈 생성, 노트의 플래시카드, 학습 자료, 심층 오디오.
