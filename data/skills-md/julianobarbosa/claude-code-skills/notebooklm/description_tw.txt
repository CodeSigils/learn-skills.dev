透過notebooklm-py CLI 和Python API 以程式方式存取Google NotebookLM。每當用戶想要建立筆記本、新增來源（URL、YouTube、PDF、文件）、從研究資料產生音訊概述/播客、影片、投影片、測驗、抽認卡、資訊圖表、報告、心智圖或資料表時，都可以使用此技能。當使用者提到 NotebookLM、想要將文件轉換為播客、產生學習材料或自動化任何 NotebookLM 工作流程時也可以使用 - 即使他們沒有明確地說「NotebookLM」。觸發條件：來自文件的播客、音訊概述、NotebookLM、筆記本研究、從 PDF 生成測驗、從筆記中產生抽認卡、學習材料、深入音訊。
