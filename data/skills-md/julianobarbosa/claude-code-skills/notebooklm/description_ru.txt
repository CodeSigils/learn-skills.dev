Программный доступ к Google NotebookLM через интерфейс командной строки Notebooklm-py и API Python. Используйте этот навык всякий раз, когда пользователь хочет создавать блокноты, добавлять источники (URL-адреса, YouTube, PDF-файлы, файлы), создавать аудиообзоры/подкасты, видео, слайды, викторины, дидактические карточки, инфографику, отчеты, интеллект-карты или таблицы данных из своих исследовательских материалов. Также используйте, когда пользователь упоминает NotebookLM, хочет превратить документы в подкасты, создать учебные материалы или автоматизировать любой рабочий процесс NotebookLM — даже если он явно не говорит «NotebookLM». Запускается при: подкасте из документов, аудиообзоре, NotebookLM, исследованиях в блокноте, создании викторины из PDF, карточках из заметок, учебных материалах, глубоком аудиопогружении.
