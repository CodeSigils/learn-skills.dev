الوصول البرمجي إلى Google NotebookLM عبر Notebooklm-py CLI وPython API. استخدم هذه المهارة عندما يريد المستخدم إنشاء دفاتر ملاحظات، أو إضافة مصادر (عناوين URL، أو YouTube، أو ملفات PDF، أو ملفات)، أو إنشاء نظرة عامة/ملفات صوتية، أو مقاطع فيديو، أو مجموعات شرائح، أو اختبارات، أو بطاقات تعليمية، أو رسوم بيانية، أو تقارير، أو خرائط ذهنية، أو جداول بيانات من مواد البحث الخاصة بهم. يُستخدم أيضًا عندما يذكر المستخدم NotebookLM، أو يريد تحويل المستندات إلى ملفات بودكاست، أو إنشاء مواد دراسية، أو أتمتة أي سير عمل لـ NotebookLM - حتى إذا لم يذكر "NotebookLM" صراحةً. يتم التشغيل على: البودكاست من المستندات، نظرة عامة على الصوت، NotebookLM، البحث في دفتر الملاحظات، إنشاء اختبار من ملف PDF، البطاقات التعليمية من الملاحظات، مواد الدراسة، الغوص العميق في الصوت.
