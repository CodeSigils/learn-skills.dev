Acceso programático a Google NotebookLM a través de la CLI notebooklm-py y la API de Python. Utilice esta habilidad siempre que el usuario quiera crear cuadernos, agregar fuentes (URL, YouTube, PDF, archivos), generar resúmenes de audio/podcasts, videos, presentaciones de diapositivas, cuestionarios, tarjetas didácticas, infografías, informes, mapas mentales o tablas de datos a partir de sus materiales de investigación. Úselo también cuando el usuario mencione NotebookLM, quiera convertir documentos en podcasts, generar materiales de estudio o automatizar cualquier flujo de trabajo de NotebookLM, incluso si no dice explícitamente "NotebookLM". Activadores de: podcast a partir de documentos, descripción general de audio, NotebookLM, investigación en cuadernos, generación de cuestionarios a partir de PDF, tarjetas didácticas a partir de notas, materiales de estudio, audio detallado.
