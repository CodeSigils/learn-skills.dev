通过notebooklm-py CLI 和Python API 以编程方式访问Google NotebookLM。每当用户想要创建笔记本、添加源（URL、YouTube、PDF、文件）、从研究材料生成音频概述/播客、视频、幻灯片、测验、抽认卡、信息图表、报告、思维导图或数据表时，都可以使用此技能。当用户提到 NotebookLM、想要将文档转换为播客、生成学习材料或自动化任何 NotebookLM 工作流程时也可以使用 - 即使他们没有明确地说“NotebookLM”。触发条件：来自文档的播客、音频概述、NotebookLM、笔记本研究、从 PDF 生成测验、从笔记中生成抽认卡、学习材料、深入音频。
