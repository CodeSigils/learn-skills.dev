Notebooklm-py CLI および Python API を介した Google NotebookLM へのプログラムによるアクセス。ユーザーがノートブックの作成、ソース (URL、YouTube、PDF、ファイル) の追加、オーディオ概要/ポッドキャスト、ビデオ、スライドデッキ、クイズ、フラッシュカード、インフォグラフィック、レポート、マインド マップ、または研究資料からのデータ テーブルの生成を行う場合には、このスキルを使用します。また、ユーザーが NotebookLM について言及したり、文書をポッドキャストに変換したり、学習教材を生成したり、NotebookLM ワークフローを自動化したいときにも使用します (明示的に「NotebookLM」と言わなくても)。トリガー: ドキュメントからのポッドキャスト、音声の概要、NotebookLM、ノートブックの調査、PDF からのクイズの生成、メモからのフラッシュカード、学習教材、詳細な音声。
