Hängen Sie neue Felddefinitionen an die Datei „fields.yaml“ einer laufenden Forschungsskizze an – entweder über vom Benutzer bereitgestellte Eingaben oder über einen Web-Suchagenten, der gemeinsame Dimensionen in der Domäne vorschlägt. Verwenden Sie „mid-„/research-outline“, wenn Sie festgestellt haben, dass dem Schema Dimensionen fehlen (z. B. Preise, Leistung, Ökosystem, Governance), bevor Sie „/research-deep“ ausführen, damit Deep-Agents die neuen Felder beim ersten Durchgang ausfüllen, anstatt eine erneute Ausführung zu benötigen.
