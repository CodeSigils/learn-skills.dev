Agregue nuevas definiciones de campos al `fields.yaml` de un esquema de investigación en progreso, ya sea a partir de datos proporcionados por el usuario o de un agente de búsqueda web que proponga dimensiones comunes en el dominio. Utilice mid-`/research-outline` cuando se haya dado cuenta de que al esquema le faltan dimensiones (por ejemplo, precios, rendimiento, ecosistema, gobernanza) antes de ejecutar `/research-deep`, de modo que los agentes profundos llenen los nuevos campos en la primera pasada en lugar de necesitar una nueva ejecución.
