Добавляйте новые определения полей в файл fields.yaml текущего исследования — либо на основе введенных пользователем данных, либо на основе агента веб-поиска, который предлагает общие измерения в домене. Используйте Mid-`/research-outline`, если вы поняли, что в схеме отсутствуют измерения (например, цены, производительность, экосистема, управление) перед запуском `/research-deep`, чтобы глубокие агенты заполняли новые поля при первом проходе вместо необходимости повторного запуска.
