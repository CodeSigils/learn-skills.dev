Aggiungi nuove definizioni di campo a "fields.yaml" di una struttura di ricerca in corso: dall'input fornito dall'utente o da un agente di ricerca web che propone dimensioni comuni nel dominio. Utilizza mid-`/research-outline` quando ti rendi conto che allo schema mancano dimensioni (ad esempio prezzi, prestazioni, ecosistema, governance) prima di eseguire "/research-deep", in modo che gli agenti profondi riempiano i nuovi campi al primo passaggio invece di aver bisogno di una nuova esecuzione.
