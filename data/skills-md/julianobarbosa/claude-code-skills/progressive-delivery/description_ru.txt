Прогрессивная доставка на Kubernetes — канареечное и сине-зеленое развертывание с помощью Argo Rollouts, а также продвижение окружающей среды с помощью Kargo. ИСПОЛЬЗУЕТСЯ ПРИ внедрении канареечных выпусков, сине-зеленых развертываний, переключении трафика между версиями, продвижения по метрикам, дизайне AnalysisTemplate/AnalysisRun, CRD Argo Rollouts или конвейерах продвижения грузов/складов/этапов Kargo, многоэтапном продвижении в рамках разработки/промежуточного хранения/производства, интеграции ArgoCD+Kargo. Развертывания обрабатывают, КАКАЯ ревизия обслуживает трафик; Kargo обрабатывает, КАКАЯ ревизия находится в какой среде. Используйте оба вместе, когда вам нужна стратегия развертывания И продвижение в нескольких средах.
