التوثيق التلقائي للنماذج الدلالية لـ Power BI عن طريق استخراج بيانات التعريف وإنشاء الوثائق وفهرسة جميع كائنات النموذج باستخدام pbi-cli. قم باستدعاء هذه المهارة عندما يقول المستخدم "توثيق هذا النموذج"، "ما يوجد في هذا النموذج"، "إدراج كل شيء"، "قاموس البيانات"، "جرد النماذج"، "محتويات التدقيق"، "الكتالوج"، "وصف النموذج"، أو يريد فهم الكائنات الموجودة في النموذج الدلالي.
