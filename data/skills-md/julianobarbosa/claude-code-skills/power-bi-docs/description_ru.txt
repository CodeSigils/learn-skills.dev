Автоматически документируйте семантические модели Power BI, извлекая метаданные, создавая документацию и каталогизируя все объекты модели с помощью pbi-cli. Используйте этот навык всякий раз, когда пользователь говорит «задокументировать эту модель», «что в этой модели», «перечислить все», «словарь данных», «инвентаризация модели», «проверить содержимое», «каталог», «описать модель» или хочет понять, какие объекты существуют в семантической модели.
