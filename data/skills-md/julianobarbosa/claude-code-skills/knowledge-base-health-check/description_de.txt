Prüft eine lokale, von Claude verwaltete Wissensdatenbank in Simons System „/Users/simon/Claude CoWork/Knowledge Base/“. Zeigt Widersprüche zwischen Artikeln, defekten Backlinks, unbegründeten Behauptungen, veralteten Artikeln, Verstößen gegen Schreibregeln und drei vorgeschlagenen neuen Artikeln auf. Legt einen vollständigen Bericht im Ordner „Outputs/“ der KB ab, hängt einen einzeiligen CHANGELOG-Eintrag an und geht (in interaktiven Sitzungen) durch, welche Erkenntnisse in die Tat umgesetzt werden müssen. Verwenden Sie diesen Skill immer dann, wenn der Benutzer sagt: „Führen Sie eine Gesundheitsprüfung durch“, „überprüfen Sie die [Name] KB“, „überprüfen Sie meine Wissensdatenbank“, „überprüfen Sie das Wiki“, „lassen Sie uns den Gesundheitsprüfungsbericht durchgehen“ oder „führen Sie die neueste Gesundheitsprüfung durch“. Wird auch verwendet, wenn die monatlich geplante Aufgabe „Knowledge-Base-Monthly-Health-Check“ ausgelöst wird. Verwenden Sie diese Fähigkeit für jede Anfrage im Audit-Stil für einen Ordner unter „Knowledge Base/“, auch wenn der Benutzer nicht das Wort „Gesundheitsprüfung“ sagt – das Protokoll ist dasselbe.
