Verwalten Sie Power BI-Tabellenpartitionen, benannte Ausdrücke (M/Power Query-Datenquellen) und die Kalendertabellenkonfiguration mit pbi-cli. Rufen Sie diesen Skill immer dann auf, wenn der Benutzer „Partitionen“, „Datenquellen“, „M-Ausdrücke“, „Power Query“, „inkrementelle Aktualisierung“, „benannte Ausdrücke“, „Verbindungsparameter“ erwähnt oder konfigurieren möchte, wie Tabellen Daten laden. Für umfassendere Modellierungsaufgaben (Kennzahlen, Beziehungen, Hierarchien) siehe stattdessen Power-Bi-Modellierung.
