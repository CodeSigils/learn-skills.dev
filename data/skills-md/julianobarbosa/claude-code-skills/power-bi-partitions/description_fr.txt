Gérez les partitions de table Power BI, les expressions nommées (sources de données M/Power Query) et la configuration des tables de calendrier à l'aide de pbi-cli. Invoquez cette compétence chaque fois que l'utilisateur mentionne « partitions », « sources de données », « expressions M », « Power Query », « actualisation incrémentielle », « expressions nommées », « paramètres de connexion » ou souhaite configurer la manière dont les tables chargent les données. Pour des tâches de modélisation plus larges (mesures, relations, hiérarchies), consultez plutôt la bi-modélisation de puissance.
