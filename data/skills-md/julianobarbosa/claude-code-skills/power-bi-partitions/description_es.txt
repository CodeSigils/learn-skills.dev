Administre particiones de tablas de Power BI, expresiones con nombre (fuentes de datos M/Power Query) y configuración de tablas de calendario mediante pbi-cli. Invoque esta habilidad siempre que el usuario mencione "particiones", "fuentes de datos", "expresiones M", "Power Query", "actualización incremental", "expresiones con nombre", "parámetros de conexión" o quiera configurar cómo las tablas cargan datos. Para tareas de modelado más amplias (medidas, relaciones, jerarquías), consulte power-bi-modelado.
