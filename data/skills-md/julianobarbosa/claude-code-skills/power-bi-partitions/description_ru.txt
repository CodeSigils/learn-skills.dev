Управляйте разделами таблицы Power BI, именованными выражениями (источниками данных M/Power Query) и настройкой таблицы календаря с помощью pbi-cli. Вызовите этот навык всякий раз, когда пользователь упоминает «разделы», «источники данных», «M-выражения», «Power Query», «добавочное обновление», «именованные выражения», «параметры соединения» или хочет настроить способ загрузки данных в таблицы. Для более широких задач моделирования (меры, отношения, иерархии) вместо этого см. Power-bi-моделирование.
