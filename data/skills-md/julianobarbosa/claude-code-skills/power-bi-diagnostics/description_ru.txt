Устраняйте проблемы с производительностью модели Power BI, отслеживайте выполнение запросов, управляйте кэшами и проверяйте среду pbi-cli с помощью pbi-cli. Вызовите этот навык всякий раз, когда пользователь говорит «pbi не работает», «проблемы с настройкой», «не удалось подключиться», «медленный запрос», «производительность», «профилирование», «трассировка», «проверка работоспособности», «аудит модели», «настройка pbi» или обнаруживает любую ошибку pbi-cli. Это первый навык, который нужно проверить, если с pbi-cli что-то не так.
