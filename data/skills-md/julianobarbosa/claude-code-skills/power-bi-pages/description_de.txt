Verwalten Sie Power BI-Berichtsseiten und Lesezeichen – fügen Sie Seiten in PBIR-Berichten hinzu, entfernen Sie sie, konfigurieren Sie sie und ordnen Sie sie mit pbi-cli an. Rufen Sie diesen Skill immer dann auf, wenn der Benutzer „Seite hinzufügen“, „Neue Seite“, „Seite löschen“, „Seitenlayout“, „Seitengröße“, „Seitenhintergrund“, „Seite ausblenden“, „Seite anzeigen“, „Drillthrough“, „Seitenreihenfolge“, „Seitensichtbarkeit“, „Seiteneinstellungen“, „Seitennavigation“, „Lesezeichen“, „Lesezeichen erstellen“, „Lesezeichen speichern“, „Lesezeichen löschen“ erwähnt oder Lesezeichen verwalten möchte, die den Status auf Seitenebene erfassen. Rufen Sie es auch auf, wenn der Benutzer nach der Drillthrough-Konfiguration oder der Seitenbindung fragt.
