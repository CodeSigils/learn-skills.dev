Power BI 보고서 페이지 및 책갈피 관리 - pbi-cli를 사용하여 PBIR 보고서의 페이지를 추가, 제거, 구성 및 레이아웃합니다. 사용자가 "페이지 추가", "새 페이지", "페이지 삭제", "페이지 레이아웃", "페이지 크기", "페이지 배경", "페이지 숨기기", "페이지 표시", "드릴스루", "페이지 순서", "페이지 표시 유형", "페이지 설정", "페이지 탐색", "북마크", "북마크 만들기", "북마크 저장", "북마크 삭제"를 언급하거나 페이지 수준 상태를 캡처하는 북마크를 관리하려고 할 때마다 이 기술을 호출합니다. 또한 사용자가 드릴스루 구성 또는 pageBinding에 대해 묻는 경우에도 호출됩니다.
