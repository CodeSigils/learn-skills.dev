Шаблоны Python для обеспечения надежности системы — фоновые задания и очереди задач (Celery, асинхронные), устойчивость и восстановление (повторные попытки, отсрочка, тайм-ауты, автоматические выключатели благодаря стойкости) и наблюдаемость (структурированное ведение журнала через structlog, метрики, распределенная трассировка, «золотые сигналы»). ИСПОЛЬЗУЙТЕ ПРИ создании асинхронных рабочих процессов, задачах организации очередей, обработке временных сбоев сети/IO, оснащении сервисов Python для производства, разработке политик повторных попыток, настройке ведения журнала или трассировки, а также при любой комбинации этих проблем, связанных с надежностью системы. НЕ ДЛЯ языковых идиом или гигиены типов (используйте `writing-python`) или настройки проекта и управления зависимостями (используйте `uv`).
