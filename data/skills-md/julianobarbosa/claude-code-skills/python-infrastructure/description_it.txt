Modelli Python per l'affidabilità del sistema: processi in background e code di attività (Celery, asincrono), resilienza e ripristino (nuovi tentativi, backoff, timeout, interruttori automatici tramite tenacia) e osservabilità (registrazione strutturata tramite structlog, metriche, tracciamento distribuito, segnali dorati). UTILIZZARE QUANDO si creano lavoratori asincroni, si accodano attività, si gestiscono errori temporanei di rete/IO, si strumentano servizi Python per la produzione, si progettano policy di ripetizione dei tentativi, si configura registrazione o traccia o qualsiasi combinazione di questi problemi di affidabilità del sistema. NON PER idiomi linguistici o igiene dei tipi (usare `writing-python`) o impostazione del progetto e gestione delle dipendenze (usare `uv`).
