システムの信頼性のための Python パターン — バックグラウンド ジョブとタスク キュー (Celery、非同期)、回復力と回復 (再試行、バックオフ、タイムアウト、テナシティによるサーキット ブレーカー)、可観測性 (structlog による構造化ログ、メトリクス、分散トレース、ゴールデン シグナル)。非同期ワーカーの構築、タスクのキューイング、一時的なネットワーク/IO 障害の処理、実稼働用の Python サービスの計測、再試行ポリシーの設計、ログまたはトレースの構成、またはこれらのシステム信頼性に関する懸念の組み合わせを行う場合に使用します。言語のイディオムや型の衛生管理 (`writing-python` を使用)、またはプロジェクトのセットアップと依存関係の管理 (`uv` を使用) には適していません。
