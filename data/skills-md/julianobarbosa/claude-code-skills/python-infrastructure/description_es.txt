Patrones de Python para la confiabilidad del sistema: trabajos en segundo plano y colas de tareas (Celery, asíncrono), resiliencia y recuperación (reintentos, retrocesos, tiempos de espera, disyuntores mediante tenacidad) y observabilidad (registro estructurado mediante structlog, métricas, seguimiento distribuido, señales doradas). ÚSELO AL crear trabajadores asíncronos, poner en cola tareas, manejar fallas transitorias de red/IO, instrumentar servicios Python para producción, diseñar políticas de reintento, configurar registros o rastreos, o cualquier combinación de estas preocupaciones de confiabilidad del sistema. NO PARA modismos de lenguaje o higiene de tipos (use `writing-python`) o configuración de proyectos y gestión de dependencias (use `uv`).
