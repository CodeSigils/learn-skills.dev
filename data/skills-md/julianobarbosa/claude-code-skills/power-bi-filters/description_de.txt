Mit pbi-cli können Sie Filter auf Seiten- und visueller Ebene in Power BI-PBIR-Berichten hinzufügen, entfernen und verwalten. Rufen Sie diesen Skill immer dann auf, wenn der Benutzer „Filter“, „TopN-Filter“, „Top 10“, „Bottom 5“, „Filter für relatives Datum“, „letzte 30 Tage“, „Kategorialfilter“, „Werte einschließen“, „Werte ausschließen“, „Filter löschen“, „Slicer-Filter“, „Seitenfilter“, „visueller Filter“ erwähnt oder einschränken möchte, welche Daten auf einer Seite oder in einem bestimmten visuellen Element angezeigt werden.
