Guide expert des fonctionnalités et du dépannage de Clashoo. Clashoo est un plugin de gestion de proxy double cœur (mihomo/Smart/sing-box) pour OpenWrt. Utilisez ce guide pour répondre à des questions telles que « comment activer/désactiver une fonctionnalité », « pourquoi cela ne fonctionne pas », « ce que signifie une erreur de journal », « comment choisir le noyau » ou « comment configurer la Sing‑box ». Avant de répondre, lisez d'abord les directives de comportement de l'IA : reportez-vous au code source, fournissez des chemins d'opération LuCI plutôt que des commandes brutes, distinguez mihomo (YAML) de sing‑box (JSON) et examinez les journaux avant de tirer des conclusions. Les utilisateurs recherchant des informations pratiques doivent consulterreferences/*.md ; pour le dépannage ou les problèmes liés aux journaux, utilisez les sections de ce document sur l'architecture, le processus de démarrage, le pare-feu et le DNS, ainsi que les explications des erreurs de journalisation.
