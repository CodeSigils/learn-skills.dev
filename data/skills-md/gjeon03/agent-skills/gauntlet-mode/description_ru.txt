Выполните явно запрошенную задачу в режиме Gauntlet высокой надежности. Используйте, когда пользователь вызывает /gauntlet-mode с задачей, при возобновлении с помощью «продолжить», при отмене с помощью «отмены» или когда /loop вызывает «/gauntlet-mode continue». Это режим выполнения, а не генератор подсказок.
