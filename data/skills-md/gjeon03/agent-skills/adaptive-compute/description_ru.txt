Многоразовая политика маршрутизации вычислений для агентского кодирования и информационной работы. Используйте при выборе уровня модели, усилий по рассуждению, широты субагента, глубины критики, бюджета итерации или эскалации на основе фактических данных; при оптимизации стоимости токена/задержки без ущерба для важного качества; или когда другому контроллеру, например Parallel Gauntlet или Agent Relay, требуется ограниченный план вычислений. Этот навык является советником по политике, а не контролером рабочего дерева/проекта.
