سياسة توجيه الحوسبة القابلة لإعادة الاستخدام للترميز الوكيل والعمل المعرفي. يُستخدم عند اختيار مستوى النموذج، أو جهد الاستدلال، أو اتساع الوكيل الفرعي، أو عمق الناقد، أو ميزانية التكرار، أو التصعيد القائم على الأدلة؛ عند تحسين تكلفة الرمز المميز/زمن الوصول دون التضحية بالجودة المهمة؛ أو عندما تحتاج وحدة تحكم أخرى مثل Parallel Gauntlet أو Agent Relay إلى خطة حسابية محدودة. تعتبر هذه المهارة بمثابة مستشار للسياسة، وليست وحدة تحكم في شجرة العمل/المشروع.
