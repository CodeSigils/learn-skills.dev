ينسق Claude Code وCodex باعتبارهما وكيلين خارجيين حقيقيين يستخدمان مكالمات CLI منظمة مباشرة بدون رأس، وملكية الدور الواضحة، وإيصالات الاستدعاء الدائمة، واستمرارية الجلسة، وأشجار العمل المعزولة، وبوابة إكمال الوكيل المزدوج الحتمية. يُستخدم فقط عندما يستدعي المستخدم صراحةً Agent Relay أو يطلب صراحةً من Claude وCodex التعاون.
