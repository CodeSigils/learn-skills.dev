Coordina Claude Code e Codex come due agenti esterni reali utilizzando chiamate CLI headless strutturate dirette, proprietà esplicita del ruolo, ricevute di invocazione durevoli, continuità della sessione, alberi di lavoro isolati e un cancello di completamento deterministico a doppio agente. Da utilizzare solo quando l'utente richiama esplicitamente Agent Relay o chiede esplicitamente a Claude e Codex di collaborare.
