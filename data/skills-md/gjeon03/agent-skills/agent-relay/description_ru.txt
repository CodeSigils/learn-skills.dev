Координирует Claude Code и Codex как двух реальных внешних агентов, используя прямые структурированные вызовы без заголовка CLI, явное владение ролями, устойчивые уведомления о вызовах, непрерывность сеанса, изолированные рабочие деревья и детерминированный шлюз завершения с двумя агентами. Используйте только тогда, когда пользователь явно вызывает Agent Relay или явно просит Клода и Кодекс о сотрудничестве.
