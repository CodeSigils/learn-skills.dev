Проверяет и усиливает инженерные планы по стандартному контрольному списку перед их выполнением. Используйте этот навык всякий раз, когда пользователь входит в режим планирования Claude Code, просит Клода «составить план», «спланировать», «наметить подход», «разобрать его» или иным образом составляет многоэтапный инженерный план — даже если он явно не просит о проверке. Также используйте его, когда пользователь собирается приступить к сложной задаче кодирования без четкого плана, чтобы убедиться, что стандарты по-прежнему применяются. Проверяет зависимость/ валюту среды выполнения (последнюю версию LTS или текущий основной), обеспечивает режим командной работы агентов для параллельной работы, более красивую/линтерную передачу с нулевыми ошибками в качестве шлюза завершения, OpenAPI для многомодульных API, токены проектирования для любой работы с пользовательским интерфейсом/UX и списки задач уценки для сложных планов.
