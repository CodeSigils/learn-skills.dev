Metodología de replicación/clonación de sitios web. UTILIZAR CUANDO el usuario dice replicar un sitio, clonar un sitio, clonar un sitio web, copiar un sitio, imitar un sitio, crear uno basado en este sitio, reproducir un sitio, restaurar un determinado efecto de página web, eliminar este sitio y convertirlo en mío, o replicar un efecto de interacción/WebGL/Canvas/Three.js específico. Proporciona un árbol de decisiones portátil de “obtener primero el código fuente real → determinar la ruta → realizar ingeniería inversa → configurar el proyecto → reemplazar contenido”, que cubre las tres ramas principales: sitios estáticos, sitios de contenido React-Vue-Next y sitios front-end WebGL-Canvas pesados, y exige la verificación de cualquier código ejecutable que se encuentre en el análisis secundario generado por IA.
