Metodología de replicación/clonación de sitios web. UTILIZAR CUANDO el usuario dice replicar un sitio web, clonar un sitio web, copiar un sitio, imitar un sitio, crear uno basado en este sitio, reproducir un sitio, restaurar un determinado efecto de página web, mover este sitio hacia abajo y cambiarlo a mío, replicar un determinado efecto de interacción/WebGL/Canvas/Three.js. Proporcionar un árbol de decisiones portátil de “obtener primero el código fuente real → determinar la ruta → realizar ingeniería inversa → configurar el proyecto → reemplazar contenido”, que cubra tres ramas principales: sitios estáticos/sitios de contenido React-Vue-Next/sitios con mucho front-end de WebGL-Canvas, y hacer cumplir la verificación de cualquier código ejecutable en el análisis secundario generado por IA.
