À utiliser lors de TOUTE tâche impliquant Supabase. Déclencheurs : produits Supabase (base de données, authentification, fonctions Edge, temps réel, stockage, vecteurs, Cron, files d'attente) ; bibliothèques clientes et intégrations SSR (supabase-js, @supabase/ssr) dans Next.js, React, SvelteKit, Astro, Remix ; problèmes d'authentification (connexion, déconnexion, sessions, JWT, cookies, getSession, getUser, getClaims, RLS) ; Serveur Supabase CLI ou MCP ; modifications de schéma, migrations, audits de sécurité, extensions Postgres (pg_graphql, pg_cron, pg_vector).
