Reestructura, reordena y mejora las páginas de documentos de Supabase existentes en aplicaciones/documentos: claridad, texto conectivo, agrupación de secciones y brevedad. Úselo cuando se le solicite editar, reorganizar, reestructurar, ajustar la prosa o agregar pegamento entre secciones de una página que ya existe. No para borradores de funciones nuevas (use write-the-docs) ni clasificación/verificación de relaciones públicas (use review-the-docs).
