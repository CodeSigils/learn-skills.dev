Restructurez, réorganisez et améliorez les pages de documents Supabase existantes sous applications/documents : clarté, texte de connexion, regroupement de sections et brièveté. À utiliser lorsqu'on vous demande de modifier, réorganiser, restructurer, resserrer la prose ou ajouter de la colle entre les sections d'une page qui existe déjà. Pas pour les brouillons de nouvelles fonctionnalités nettes (utilisez write-the-docs) ou le tri/vérification des relations publiques (utilisez review-the-docs).
