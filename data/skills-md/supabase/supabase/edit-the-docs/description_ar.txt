إعادة هيكلة صفحات مستندات Supabase الموجودة وإعادة ترتيبها وتحسينها ضمن التطبيقات/المستندات - الوضوح والنص المتصل وتجميع الأقسام والإيجاز. استخدمه عندما يُطلب منك التحرير، أو إعادة التنظيم، أو إعادة الهيكلة، أو تشديد النثر، أو إضافة الغراء بين الأقسام الموجودة في الصفحة الموجودة بالفعل. ليس لمسودات الميزات الجديدة (استخدم كتابة المستندات) أو فرز/تحقق العلاقات العامة (استخدم مراجعة المستندات).
