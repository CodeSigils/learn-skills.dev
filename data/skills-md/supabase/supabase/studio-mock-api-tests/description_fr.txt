Tests de composants pour Supabase Studio qui simulent les requêtes API au niveau de la couche réseau avec MSW. À utiliser lors de l'écriture ou de la révision d'un test de composant qui exerce un hook ou une mutation React Query, ou lors de la migration d'un test existant hors de vi.mock('@/data/...'). Couvre le modèle customRender + addAPIMock et les pièges jsdom/MSW qui coûtent du temps de débogage réel.
