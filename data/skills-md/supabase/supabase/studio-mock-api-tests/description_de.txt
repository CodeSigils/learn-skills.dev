Komponententests für Supabase Studio, die API-Anfragen auf der Netzwerkebene mit MSW simulieren. Wird verwendet, wenn Sie einen Komponententest schreiben oder überprüfen, der einen React Query-Hook oder eine Mutation ausübt, oder wenn Sie einen vorhandenen Test von vi.mock('@/data/...') weg migrieren. Behandelt die Vorlage „customRender + addAPIMock“ und die Fallstricke von jsdom/MSW, die echte Debugging-Zeit kosten.
