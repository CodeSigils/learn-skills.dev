Тесты компонентов для Supabase Studio, которые имитируют запросы API на сетевом уровне с помощью MSW. Используйте при написании или проверке теста компонента, который использует перехват или мутацию React Query, или при переносе существующего теста из vi.mock('@/data/...'). Охватывает шаблон customRender + addAPIMock и ошибки jsdom/MSW, которые требуют реального времени отладки.
