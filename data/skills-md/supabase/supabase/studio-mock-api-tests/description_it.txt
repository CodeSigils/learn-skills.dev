Test dei componenti per Supabase Studio che simulano le richieste API a livello di rete con MSW. Da utilizzare durante la scrittura o la revisione di un test di un componente che esercita un hook o una mutazione di React Query o durante la migrazione di un test esistente da vi.mock('@/data/...'). Copre il modello customRender + addAPIMock e i trucchi jsdom/MSW che costano tempo di debug reale.
