اختبارات المكونات لـ Supabase Studio التي تسخر من طلبات واجهة برمجة التطبيقات (API) في طبقة الشبكة باستخدام MSW. يُستخدم عند كتابة أو مراجعة اختبار مكون يمارس ربط أو تغيير في React Query، أو عند ترحيل اختبار موجود بعيدًا عن vi.mock('@/data/...'). يغطي قالب customRender + addAPIMock ومشاكل jsdom/MSW التي تكلف وقتًا حقيقيًا لتصحيح الأخطاء.
