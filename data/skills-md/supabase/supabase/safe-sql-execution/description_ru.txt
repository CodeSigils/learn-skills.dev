Используйте всякий раз, когда код будет создавать, возвращать, извлекать или выполнять SQL-код, который работает с реальной базой данных Postgres пользователя, даже если запрос читается как обычная функция или исправление ошибки и никогда не содержит слов «безопасность», «внедрение» или «SafeSqlFragment». Сюда входит: написание или редактирование любой функции pg-meta, построителя запросов или конечной точки, которая создает/возвращает SQL для объектов базы данных (таблиц, представлений, функций, триггеров БД, индексов, политик RLS); интерполяция значения схемы/таблицы/столбца/поиска/параметра маршрута в текст SQL; хранение, выборка или повторный запуск SQL, который поступает из базы данных (определение политики, определение функции/представления, сохраненное содержимое фрагмента); и любое действие «Выполнить»/«Применить»/«Выполнить», которое отправляет SQL в базу данных проекта (выбор запуска редактора SQL, применение редактора политики, запуск фрагментов). Загрузите это ПЕРЕД написанием такого кода, а не только при просмотре готового диффа. Пропускайте только те изменения, которые никогда не затрагивают текст или выполнение SQL — стили, несвязанные перехватчики данных, проверка форм, не связанных с SQL, или работа с макетом пользовательского интерфейса.
