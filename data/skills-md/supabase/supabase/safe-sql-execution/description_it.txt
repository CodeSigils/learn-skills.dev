Utilizzalo ogni volta che il codice creerà, restituirà, recupererà o eseguirà SQL eseguito sul database Postgres reale di un utente, anche quando la richiesta viene letta come una normale funzionalità o correzione di bug e non dice mai "sicurezza", "iniezione" o "SafeSqlFragment". Ciò copre: scrivere o modificare qualsiasi funzione pg-meta, generatore di query o endpoint che crea/restituisce SQL per oggetti di database (tabelle, viste, funzioni, trigger DB, indici, policy RLS); interpolazione di un valore schema/tabella/colonna/ricerca/parametro percorso nel testo SQL; archiviare, recuperare o rieseguire SQL in andata e ritorno dal database (la definizione di una policy, una definizione di funzione/vista, il contenuto salvato di uno snippet); e qualsiasi azione "Esegui"/"Applica"/"Esegui" che invia SQL al database di un progetto (selezione esecuzione editor SQL, applicazione editor criteri, runner snippet). Caricalo PRIMA di scrivere tale codice, non solo quando rivedi un diff finito. Salta solo per le modifiche che non toccano mai il testo o l'esecuzione SQL: stili, hook di dati non correlati, convalida di moduli non SQL o lavoro di layout dell'interfaccia utente.
