Use whenever code will build, return, fetch, or execute SQL that runs against a user's real Postgres database — even when the request reads like an ordinary feature or bug fix and never says "security," "injection," or "SafeSqlFragment." This covers: writing or editing any pg-meta function, query builder, or endpoint that builds/returns SQL for database objects (tables, views, functions, DB triggers, indexes, RLS policies); Interpolieren eines Schema-/Tabellen-/Spalten-/Such-/Routenparameterwerts in SQL-Text; storing, fetching, or re-running SQL that round-trips from the database (a policy's definition, a function/view definition, a snippet's saved content); und jede „Ausführen“/„Anwenden“/„Ausführen“-Aktion, die SQL an die Datenbank eines Projekts sendet (SQL-Editor-Auswahl, Richtlinieneditor anwenden, Snippet-Runner). Laden Sie dies, BEVOR Sie solchen Code schreiben, nicht nur, wenn Sie ein fertiges Diff überprüfen. Überspringen Sie nur Änderungen, die niemals den SQL-Text oder die SQL-Ausführung berühren – Stil, unabhängige Daten-Hooks, Nicht-SQL-Formularvalidierung oder UI-Layoutarbeiten.
