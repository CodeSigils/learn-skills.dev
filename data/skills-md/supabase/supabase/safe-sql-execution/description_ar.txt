يُستخدم عندما يتم إنشاء تعليمات برمجية أو إرجاعها أو جلبها أو تنفيذها لـ SQL الذي يتم تشغيله على قاعدة بيانات Postgres الحقيقية للمستخدم - حتى عندما يُقرأ الطلب كميزة عادية أو إصلاح خطأ ولا يذكر أبدًا "الأمان" أو "الحقن" أو "SafeSqlFragment". يغطي هذا: كتابة أو تحرير أي وظيفة pg-meta، أو منشئ الاستعلام، أو نقطة النهاية التي تنشئ/ترجع SQL لكائنات قاعدة البيانات (الجداول، وطرق العرض، والوظائف، ومشغلات قاعدة البيانات، والفهارس، وسياسات RLS)؛ استيفاء قيمة مخطط/جدول/عمود/بحث/مسار-معلمة في نص SQL؛ تخزين أو جلب أو إعادة تشغيل SQL التي تتنقل ذهابًا وإيابًا من قاعدة البيانات (تعريف السياسة، تعريف الوظيفة/العرض، المحتوى المحفوظ للمقتطف)؛ وأي إجراء "تشغيل"/"تطبيق"/"تنفيذ" يرسل SQL إلى قاعدة بيانات المشروع (اختيار تشغيل محرر SQL، تطبيق محرر السياسة، تشغيل المقتطف). قم بتحميل هذا قبل كتابة هذا الرمز، وليس فقط عند مراجعة الفرق النهائي. يمكنك التخطي فقط للتغييرات التي لا تمس نص SQL أو التنفيذ أبدًا - التصميم، أو ربط البيانات غير ذات الصلة، أو التحقق من صحة النماذج غير SQL، أو عمل تخطيط واجهة المستخدم.
