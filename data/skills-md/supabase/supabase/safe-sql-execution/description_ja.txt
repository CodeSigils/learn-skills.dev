ユーザーの実際の Postgres データベースに対して実行される SQL をコードが構築、返し、フェッチ、または実行する場合は常に使用します。リクエストが通常の機能やバグ修正のように見え、「セキュリティ」、「インジェクション」、または「SafeSqlFragment」が決して記載されていない場合でも使用します。これには、データベース オブジェクト (テーブル、ビュー、関数、DB トリガー、インデックス、RLS ポリシー) の SQL を構築/返す pg-meta 関数、クエリ ビルダー、またはエンドポイントの作成または編集が含まれます。スキーマ/テーブル/列/検索/ルートパラメータ値を SQL テキストに挿入します。データベースから往復する SQL (ポリシーの定義、関数/ビューの定義、スニペットの保存されたコンテンツ) を保存、フェッチ、または再実行します。 SQL をプロジェクトのデータベースに送信する「実行」/「適用」/「実行」アクション (SQL エディターの実行選択、ポリシー エディターの適用、スニペット ランナー)。完成した差分を確認するときだけでなく、そのようなコードを書く前にこれをロードしてください。 SQL テキストや実行にまったく影響を与えない変更 (スタイル設定、無関係なデータ フック、SQL 以外のフォーム検証、UI レイアウト作業) の場合のみスキップしてください。
