Schreiben oder prüfen Sie die Kopie der Benutzeroberfläche (Schaltflächen, Beschriftungen, Leerzustände, Fehlermeldungen, Tooltips, Formulartext) an einer beliebigen Stelle im Monorepo. Laden Sie es, bevor Sie benutzerbezogenen Text versenden oder überprüfen – auch wenn das Kopieren für die Aufgabe nebensächlich ist, wie etwa eine neue Funktion, die Schaltflächen, Toasts, Dialoge oder Validierungsmeldungen hinzufügt.
