Scrivi, rivedi e migra le query dei log di Supabase rispetto alla tabella "logs" supportata da ClickHouse (l'endpoint di analisi "logs.all.otel"). Utilizzalo ogni volta che un'attività coinvolge Logs Explorer SQL, la mappa "log_attributes", l'esecuzione di una query su un log "source" (edge_logs, postgres_logs, auth_logs e così via), la traduzione di una vecchia query di log BigQuery "cross join unnest(metadata)" in ClickHouse o il collegamento SQL del log di analisi in "apps/studio/data/logs" e "apps/studio/components/interfaces/Settings/Logs". Raggiungilo anche quando l'utente dice semplicemente "query di log", "Esplora log" o incolla una query di log BigQuery da convertire, non solo quando nomina ClickHouse.
