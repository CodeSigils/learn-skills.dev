Используйте при написании серверного кода с помощью Supabase — Edge Functions, приложений Hono, обработчиков веб-перехватчиков или любого бэкэнда, требующего аутентификации Supabase и создания клиента. Запускается всякий раз, когда пользователь импортирует из `@supabase/server`, упоминает `supabase/server`, функции Supabase Edge или нуждается в аутентификации на стороне сервера (проверка JWT, проверка ключа API, обработка CORS) с помощью Supabase. Также срабатывает, когда вы видите устаревшие шаблоны в существующем коде — `Deno.serve`, `createClient(Deno.env.get('SUPABASE_URL'))`, импорт из `esm.sh/@supabase`, `deno.land/std` или использование `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` — они указывают код, который следует перенести в этот пакет.
