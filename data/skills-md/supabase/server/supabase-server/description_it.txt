Da utilizzare quando si scrive codice lato server con Supabase: Edge Functions, app Hono, gestori webhook o qualsiasi backend che necessita dell'autenticazione Supabase e della creazione del client. Si attiva ogni volta che l'utente importa da "@supabase/server", menziona "supabase/server", Supabase Edge Functions o necessita di autenticazione lato server (verifica JWT, convalida della chiave API, gestione CORS) con Supabase. Si attiva anche quando vedi modelli legacy nel codice esistente — `Deno.serve`, `createClient(Deno.env.get('SUPABASE_URL'))`, importazioni da `esm.sh/@supabase`, `deno.land/std` serve o utilizzo di `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY`: indicano il codice che deve essere migrato a questo pacchetto.
