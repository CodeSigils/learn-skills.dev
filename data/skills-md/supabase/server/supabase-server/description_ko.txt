Supabase(Edge Functions, Hono 앱, 웹훅 핸들러 또는 Supabase 인증 및 클라이언트 생성이 필요한 백엔드)를 사용하여 서버 측 코드를 작성할 때 사용합니다. 사용자가 `@supabase/server`에서 가져오거나 `supabase/server`, Supabase Edge Functions를 언급하거나 Supabase를 통한 서버 측 인증(JWT 확인, API 키 검증, CORS 처리)이 필요할 때마다 트리거됩니다. 또한 기존 코드에서 레거시 패턴(`Deno.serve`, `createClient(Deno.env.get('SUPABASE_URL'))`, `esm.sh/@supabase`에서 가져오기, `deno.land/std` 서브 또는 `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` 사용)을 볼 때 트리거됩니다. 이는 이 패키지로 마이그레이션해야 하는 코드를 나타냅니다.
