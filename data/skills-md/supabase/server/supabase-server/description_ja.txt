Supabase を使用してサーバー側のコードを作成するときに使用します。Edge Functions、Hono アプリ、Webhook ハンドラー、または Supabase 認証とクライアントの作成を必要とするバックエンドです。ユーザーが `@supabase/server` からインポートするとき、`supabase/server`、Supabase Edge 関数に言及するとき、または Supabase でサーバー側の認証 (JWT 検証、API キー検証、CORS 処理) を必要とするときにトリガーします。既存のコードにレガシー パターンが見つかった場合にもトリガーされます — `Deno.serve`、`createClient(Deno.env.get('SUPABASE_URL'))`、`esm.sh/@supabase`、`deno.land/std` サーブからのインポート、または `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` の使用 — これらは、これに移行する必要があるコードを示しますパッケージ。
