Úselo al escribir código del lado del servidor con Supabase: funciones Edge, aplicaciones Hono, controladores de webhooks o cualquier backend que necesite autenticación de Supabase y creación de clientes. Se activa cada vez que el usuario importa desde `@supabase/server`, menciona `supabase/server`, Supabase Edge Functions o necesita autenticación del lado del servidor (verificación JWT, validación de clave API, manejo de CORS) con Supabase. También se activa cuando ve patrones heredados en el código existente: `Deno.serve`, `createClient(Deno.env.get('SUPABASE_URL'))`, importaciones desde `esm.sh/@supabase`, servicio `deno.land/std` o uso de `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY`: estos indican código que se debe migrar a este paquete.
