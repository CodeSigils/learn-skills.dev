使用 Supabase 编写服务器端代码时使用 - Edge Functions、Hono 应用程序、webhook 处理程序或任何需要 Supabase 身份验证和客户端创建的后端。每当用户从“@supabase/server”导入、提及“supabase/server”、Supabase Edge Functions 或需要使用 Supabase 进行服务器端身份验证（JWT 验证、API 密钥验证、CORS 处理）时触发。当您在现有代码中看到旧模式时也会触发 - `Deno.serve`、`createClient(Deno.env.get('SUPABASE_URL'))`、从 `esm.sh/@supabase`、`deno.land/std` 服务导入或使用 `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` - 这些指示应迁移到此包的代码。
