استخدمه عند كتابة تعليمات برمجية من جانب الخادم باستخدام Supabase — Edge Functions، أو تطبيقات Hono، أو معالجات webhook، أو أي واجهة خلفية تحتاج إلى مصادقة Supabase وإنشاء العميل. يتم تشغيله عندما يقوم المستخدم بالاستيراد من `@supabase/server`، أو يذكر `supabase/server`، أو وظائف Supabase Edge، أو يحتاج إلى مصادقة من جانب الخادم (التحقق من JWT، أو التحقق من صحة مفتاح API، أو معالجة CORS) باستخدام Supabase. يتم تشغيلها أيضًا عندما ترى أنماطًا قديمة في التعليمات البرمجية الموجودة - `Deno.serve`، أو `createClient(Deno.env.get('SUPABASE_URL'))`، أو عمليات الاستيراد من `esm.sh/@supabase`، أو خدمة `deno.land/std`، أو استخدام `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` - تشير هذه إلى التعليمات البرمجية التي يجب أن تكون هاجر إلى هذه الحزمة.
