Verwenden Sie es, wenn Sie serverseitigen Code mit Supabase schreiben – Edge-Funktionen, Hono-Apps, Webhook-Handler oder jedes Backend, das Supabase-Authentifizierung und Client-Erstellung benötigt. Wird immer dann ausgelöst, wenn der Benutzer von „@supabase/server“ importiert, „supabase/server“ oder Supabase-Edge-Funktionen erwähnt oder eine serverseitige Authentifizierung (JWT-Überprüfung, API-Schlüsselvalidierung, CORS-Verarbeitung) mit Supabase benötigt. Wird auch ausgelöst, wenn Sie Legacy-Muster in vorhandenem Code sehen – „Deno.serve“, „createClient(Deno.env.get('SUPABASE_URL'))“, Importe von „esm.sh/@supabase“, „deno.land/std“-Serve oder Verwendung von „SUPABASE_ANON_KEY“ / „SUPABASE_SERVICE_ROLE_KEY“ – diese weisen auf Code hin, zu dem migriert werden sollte dieses Paket.
