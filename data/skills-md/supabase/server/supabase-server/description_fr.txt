À utiliser lors de l'écriture de code côté serveur avec Supabase : fonctions Edge, applications Hono, gestionnaires de webhooks ou tout backend nécessitant l'authentification Supabase et la création de client. Déclenchez chaque fois que l'utilisateur importe depuis `@supabase/server`, mentionne `supabase/server`, Supabase Edge Functions ou a besoin d'une authentification côté serveur (vérification JWT, validation de clé API, gestion CORS) avec Supabase. Déclenchez également lorsque vous voyez des modèles hérités dans le code existant — `Deno.serve`, `createClient(Deno.env.get('SUPABASE_URL'))`, importations depuis `esm.sh/@supabase`, `deno.land/std` serve ou utilisation de `SUPABASE_ANON_KEY` / `SUPABASE_SERVICE_ROLE_KEY` — ceux-ci indiquent le code qui doit être migré vers ce package.
