Этот навык следует использовать, когда пользователь просит «исправить проблемы», «оптимизировать существующий контент», «создать новый контент для видимости ИИ», «запустить Morphiq Build», «создать разметку схемы», «создать файл llms.txt», «запустить лабораторию контента» или упоминает о создании исправлений контента, создании схемы, переписывании контента для цитат ИИ или создании файлов политики. Использует приоритетную дорожную карту и создает артефакты сборки с помощью 6-этапного конвейера лаборатории контента.
