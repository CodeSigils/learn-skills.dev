Изучите общедоступную документацию API из любого пакета NuGet. Используйте, когда необходимо понять типы, методы, интерфейсы или свойства библиотеки .NET — для таких вопросов, как «какие методы есть у IChatClient», «покажите мне класс ChatOptions» или при реализации с помощью API пакета NuGet. Требуется глобальный инструмент dotnet nuget-docs.
