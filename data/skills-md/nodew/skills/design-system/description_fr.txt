Générez des jetons de conception (couleurs du thème, espacement, typographie, composants) à partir de n'importe quelle entrée : captures d'écran, invites textuelles, briefs de marque ou CSS existant. Utilise une architecture à trois couches (primitive → sémantique → composant). Prend en charge les thèmes clairs/sombres, les variables CSS et l'intégration Tailwind. Se déclenche sur les demandes de jetons de conception, de thèmes, de spécifications de composants ou de transfert de conception vers code.
