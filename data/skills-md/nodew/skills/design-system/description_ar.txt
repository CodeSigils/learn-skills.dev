قم بإنشاء رموز التصميم المميزة (ألوان السمات، والمسافات، والطباعة، والمكونات) من أي إدخال — لقطات شاشة، أو مطالبات نصية، أو ملخصات العلامة التجارية، أو CSS الموجودة. يستخدم بنية ثلاثية الطبقات (بدائية → دلالية → مكون). يدعم السمات الفاتحة/الداكنة ومتغيرات CSS وتكامل Tailwind. يتم تشغيله عند طلبات رموز التصميم المميزة أو السمات أو مواصفات المكونات أو تسليم التصميم إلى التعليمات البرمجية.
