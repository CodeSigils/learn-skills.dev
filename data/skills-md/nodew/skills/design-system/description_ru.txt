Создавайте токены дизайна (цвета темы, интервалы, типографика, компоненты) из любых входных данных — снимков экрана, текстовых подсказок, описания бренда или существующего CSS. Использует трехуровневую архитектуру (примитив → семантика → компонент). Поддерживает светлые/темные темы, переменные CSS и интеграцию Tailwind. Запускается по запросам на токены проектирования, темы, спецификации компонентов или передачу кода от дизайна.
