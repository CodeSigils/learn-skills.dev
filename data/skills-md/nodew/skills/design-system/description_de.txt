Generieren Sie Design-Tokens (Themenfarben, Abstände, Typografie, Komponenten) aus beliebigen Eingaben – Screenshots, Textaufforderungen, Markenbriefings oder vorhandenem CSS. Verwendet eine dreischichtige Architektur (primitiv → semantisch → Komponente). Unterstützt helle/dunkle Themen, CSS-Variablen und Tailwind-Integration. Wird bei Anfragen nach Design-Tokens, Designs, Komponentenspezifikationen oder der Übergabe von Design an Code ausgelöst.
