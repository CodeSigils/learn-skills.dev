قم بإنشاء نماذج أولية لواجهة المستخدم لمواقع الويب أو لوحات المعلومات أو تطبيقات سطح المكتب أو تطبيقات الهاتف المحمول باستخدام HTML وTailwindCSS. يطبق الرموز المميزة لنظام التصميم قبل إنشاء العلامات لضمان اتساقها. يتم تشغيلها عند طلبات النماذج بالحجم الطبيعي، أو الإطارات السلكية، أو مفاهيم الشاشة، أو مفاهيم الصفحة، أو النماذج الأولية للواجهة القابلة للمعاينة.
