Genera e gestisci il blocco di riepilogo del sistema in una descrizione PR: un riepilogo visivo reso da GitHub di quali primitive di sistema toccano una modifica, quanto è rischiosa e cosa è cambiato. Da utilizzare quando si pianifica una modifica non banale (modalità pianificazione), quando si crea o si aggiorna una richiesta pull (modalità riepilogo) o quando l'utente richiede un riepilogo visivo, un piano visivo, una revisione del sistema o un riepilogo PR.
