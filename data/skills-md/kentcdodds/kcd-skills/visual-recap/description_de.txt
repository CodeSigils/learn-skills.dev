Generieren und pflegen Sie den System-Recap-Block in einer PR-Beschreibung – eine von GitHub gerenderte visuelle Zusammenfassung darüber, welche Systemprimitive eine Änderung berührt, wie riskant sie ist und was sich geändert hat. Verwenden Sie diese Option, wenn Sie eine nicht triviale Änderung planen (Planmodus), eine Pull-Anfrage erstellen oder aktualisieren (Zusammenfassungsmodus) oder wenn der Benutzer eine visuelle Zusammenfassung, einen visuellen Plan, eine Systemüberprüfung oder eine PR-Zusammenfassung anfordert.
