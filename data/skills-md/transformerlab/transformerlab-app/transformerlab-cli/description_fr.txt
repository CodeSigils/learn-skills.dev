Transformer Lab CLI pour gérer les tâches de formation ML, les tâches, les fournisseurs de calcul, les modèles et les ensembles de données. À utiliser lorsque l'utilisateur a besoin de vérifier l'état d'une tâche, de diffuser des journaux, de télécharger des artefacts, de mettre en file d'attente des tâches de formation, de télécharger ou de modifier des tâches, de gérer des fournisseurs de calcul, de répertorier ou de créer des modèles, de télécharger ou de télécharger des ensembles de données, de publier des résultats de tâche, d'exécuter des boucles d'expérimentation autonomes (recherche automatique) ou d'interagir avec Transformer Lab par programme. Les déclencheurs incluent « vérifier l'état de la tâche », « télécharger les résultats », « mettre une tâche en file d'attente », « télécharger une tâche », « modifier une tâche », « lister les fournisseurs », « ajouter un fournisseur », « configurer un fournisseur », « diffuser les journaux », « ce qui est en cours d'exécution », « surveiller la formation », « ajouter une tâche », « vérifier l'état du fournisseur », « lister les modèles », « créer un modèle », « télécharger un ensemble de données », « télécharger un ensemble de données », « publier un modèle », « publier un ensemble de données », « exécuter une recherche automatique », « optimiser X dans une boucle », "configurer la recherche automatique", "/lab-autoresearch".
