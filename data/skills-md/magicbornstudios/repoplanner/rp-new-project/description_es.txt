Inicialice un nuevo proyecto o una nueva sección con la estructura de planificación de RepoPlanner. Utilice esta habilidad cuando el usuario quiera comenzar un nuevo proyecto, configurar documentos de planificación para un repositorio que aún no los tiene, agregar una nueva sección a un monorepo o crear requisitos/hoja de ruta/estado/registro de tareas. Crea la estructura .planning/ completa y el bucle de 5 documentos, formula las preguntas correctas sobre el alcance y los objetivos, genera requisitos con ID estables y produce una hoja de ruta por fases. Funciona para repositorios simples y monorepos.
