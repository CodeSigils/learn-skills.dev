Given a sentence or paragraph, locate genuine academic literature that opposes it—contrary conclusions, boundary conditions, alternative explanations, methodological critiques, replication failures. Rank the sources by threat level, and for each provide a line explaining “how it threatens this viewpoint” and “how to respond to it.” Use authentic retrieval (scimaster‑cli) underneath; never fabricate counterexamples.

**In the following situations, proactively trigger this capability**: the user wants to “pre‑empt reviewers,” “find counterexamples to this conclusion,” “see if this area is controversial,” “find research that contradicts this,” “help me attack this argument,” “assess how stable this conclusion is,” or “learn what objections exist”—even if the user doesn’t say “bear‑counter,” as long as the intent is **to find academic evidence against a viewpoint**, use this skill. bear‑support and bear‑counter work best together: run each on the same passage to see both sides simultaneously.

Not applicable for: finding supporting literature (use bear‑support), topic plagiarism checks (use bear‑scoop), concept maps (use bear‑map), tracing evolutionary histories (use bear‑trace).
