Dada una oración o un párrafo, localice literatura académica genuina que la respalde y adjunte una nota de una línea a cada referencia que describa “cómo respalda este punto de vista”. El proceso subyacente utiliza búsquedas reales (scimaster-cli) y nunca fabrica citas de memoria; si no se encuentra nada, diga honestamente que no se encontró nada.  

**En las siguientes situaciones, active esta capacidad de manera proactiva**: el usuario quiere que un punto de vista sea "más fundamentado", "más defendible", "agregar respaldo bibliográfico", "encontrar algunos artículos", "¿hay investigaciones sobre esta afirmación", "ayúdenme a verificar esta conclusión" o "los revisores dirán que no hay citas?"; incluso si el usuario no dice explícitamente "apoyo" o "encontrar literatura", siempre y cuando la intención sea **encontrar apoyo académico para un punto de vista**, use esta capacidad.  

No aplicable para: encontrar literatura contraria (usar contador de osos), verificación de plagio de temas (usar primicia de osos), mapeo conceptual (usar mapa de osos), rastrear la historia evolutiva (usar rastro de osos).
