Given a sentence or a paragraph, locate genuine academic literature that supports it, and attach a one‑line note to each reference describing “how it supports this viewpoint.” The underlying process uses real searches (scimaster‑cli) and never fabricates citations from memory—if nothing is found, honestly state that nothing was found.  

**In the following situations, proactively trigger this capability**: the user wants a viewpoint to be “more substantiated,” “more defensible,” “add literature support,” “find a few papers,” “is there research on this claim,” “help me check this conclusion,” or “will reviewers say there are no citations”—even if the user doesn’t explicitly say “bear‑support” or “find literature,” as long as the intent is **to find academic support for a viewpoint**, use this capability.  

Not applicable for: finding opposing literature (use bear‑counter), topic plagiarism checking (use bear‑scoop), concept mapping (use bear‑map), tracing evolutionary history (use bear‑trace).
