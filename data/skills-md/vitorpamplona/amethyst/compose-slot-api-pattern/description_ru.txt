Используйте при разработке или проверке повторно используемого компонента Jetpack Compose, визуальные области которого различаются в зависимости от вызывающего объекта, или когда накапливаются примитивные параметры содержимого и логические флаги формы. Навыки технического уровня — дополняют эксперта по компоновке, специфичного для кодовой базы.
