Инструмент поиска коэффициента выбросов углерода CCDB. На основе базы данных Carbonstop CCDB он запрашивает данные о коэффициентах выбросов углерода через ccdb-mcp-сервер.
Поддерживает поиск по ключевым словам для коэффициентов выбросов углерода, получение структурированных данных JSON и сравнение по нескольким ключевым словам.

**Используйте этот навык, когда**:
(1) Пользователь запрашивает коэффициенты выбросов углерода (например, «коэффициент выбросов электроэнергии», «выбросы углерода от цемента», «коэффициент выбросов природного газа» и т. д.)
(2) Пользователю необходимо выполнить расчеты выбросов углекислого газа (сначала необходимо запросить коэффициент, а затем умножить его на данные о деятельности).
(3) Пользователю необходимо сравнить коэффициенты выбросов углерода для различных источников энергии/материалов.
(4) Пользователь упоминает «CCDB», «коэффициент выбросов углерода», «коэффициент выбросов», «углеродный след», «LCA» или «коэффициент выбросов».
(5) Пользователю необходимо запросить данные о коэффициентах выбросов углерода для конкретной страны/региона или конкретного года.
