Rufen Sie YouTube-Transkripte ab, durchsuchen Sie Videos und durchsuchen Sie Kanäle oder Wiedergabelisten über den SubDownload MCP-Server. Wird immer dann verwendet, wenn der Nutzer eine YouTube-URL (youtube.com, youtu.be, Shorts) teilt, einen YouTuber oder @handle erwähnt, nach einer Playlist fragt oder ein Transkript, eine Bildunterschrift, einen Untertitel, eine Zusammenfassung oder eine Übersetzung von Videoinhalten anfordert. Ziehen Sie diese Tools immer der Beantwortung von YouTube-Fragen aus dem Gedächtnis vor.
