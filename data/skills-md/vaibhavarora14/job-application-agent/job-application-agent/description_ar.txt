يبحث عن طلبات الوظائف الخاصة بالمرشح ويقيمها ويملأها ويقدمها ويتتبعها باستخدام السيرة الذاتية التي تم التحقق منها والاستهداف القائم على الأدلة وتخزين الملفات الشخصية المحلية الآمنة وأتمتة المتصفح. يُستخدم لإعداد ملف تعريف البحث عن وظيفة أو ترحيله، أو البحث عن الأدوار النشطة، أو تقييم النشر، أو التقديم على عنوان URL أو دفعة معتمدة، أو تسجيل النتائج، أو مراجعة فعالية التطبيق.
