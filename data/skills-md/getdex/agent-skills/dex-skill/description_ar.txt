إدارة CRM الشخصي الخاص بـ Dex - البحث عن جهات الاتصال وإنشائها وتحديثها، وتسجيل ملاحظات التفاعل، وتعيين تذكيرات المتابعة، وتنظيم جهات الاتصال باستخدام العلامات والمجموعات، وإدارة الحقول المخصصة. استخدم هذه المهارة عندما يريد المستخدم: (1) البحث عن جهة اتصال أو البحث عنها، (2) إضافة تفاصيل جهة الاتصال أو تحريرها، (3) تسجيل اجتماع أو مكالمة أو ملاحظة تفاعل، (4) تعيين تذكير أو مهمة متابعة، (5) تنظيم جهات الاتصال في مجموعات أو تطبيق العلامات، (6) تتبع البيانات المخصصة باستخدام الحقول المخصصة، (7) دمج جهات الاتصال المكررة، (8) مراجعة سجل علاقاتهم أو الاستعداد لاجتماع، (9) المصادقة مع Dex عبر /dex-login، أو أي شيء آخر مهمة CRM الشخصية التي تنطوي على شبكتهم المهنية.
