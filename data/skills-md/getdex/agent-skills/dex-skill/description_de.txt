Verwalten Sie Ihr persönliches Dex-CRM – suchen, erstellen und aktualisieren Sie Kontakte, protokollieren Sie Interaktionsnotizen, richten Sie Folgeerinnerungen ein, organisieren Sie Kontakte mit Tags und Gruppen und verwalten Sie benutzerdefinierte Felder. Verwenden Sie diese Fähigkeit, wenn der Benutzer Folgendes tun möchte: (1) Einen Kontakt finden oder suchen, (2) Kontaktdetails hinzufügen oder bearbeiten, (3) Eine Besprechung, einen Anruf oder eine Interaktionsnotiz protokollieren, (4) Eine Erinnerung oder eine Folgeaufgabe festlegen, (5) Kontakte in Gruppen organisieren oder Tags anwenden, (6) Benutzerdefinierte Daten mit benutzerdefinierten Feldern verfolgen, (7) Doppelte Kontakte zusammenführen, (8) Ihren Beziehungsverlauf überprüfen oder sich auf eine Besprechung vorbereiten, (9) Sich über /dex-login oder ein anderes persönliches CRM bei Dex authentifizieren möchte Aufgabe, die ihr berufliches Netzwerk einbezieht.
