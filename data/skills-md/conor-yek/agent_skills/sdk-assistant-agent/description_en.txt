ARCS SDK / LISTENAI SDK development assistant unified entry point. Triggered whenever a user performs any development task within this SDK project, including but not limited to: driver development (LISA_DEVICE_REGISTER, API vtable, peripheral drivers, UART/SPI/I2C/GPIO/Flash/Display), build & debug (CMake compilation errors, link failures, Kconfig/menuconfig, map files, out-of-memory issues, compile/flash/serial), sample generation (how to use xxx, write a demo/sample, usage example), code review (review, check code, PR), SDK architecture issues (SYS_INIT, FreeRTOS, ELF sections, linker scripts, custom sections). Any issues involving the arcs_mini or arcs_evb boards, or CMake macros such as listenai_library or listenai_add_executable, should trigger this skill.
