ARCS SDK / LISTENAI SDK Development Assistant Unified Entry. Triggered whenever a user performs any development task within this SDK project, including but not limited to: driver development (LISA_DEVICE_REGISTER, API vtable, peripheral drivers, UART/SPI/I2C/GPIO/Flash/Display), build and debugging (CMake compilation errors, linking failures, Kconfig/menuconfig, map files, insufficient memory, compile-flash-serial), sample generation (how to use xxx, write a demo/sample, usage examples), code review (review, code check, PR), SDK architecture issues (SYS_INIT, FreeRTOS, ELF sections, linker scripts, custom sections). Any issues involving the arcs_mini or arcs_evb boards, or CMake macros such as listenai_library and listenai_add_executable, should trigger this skill.
