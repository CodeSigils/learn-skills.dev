Point d'entrée unifié de l'assistant de développement ARCS SDK / LISTENAI SDK. Déclenché chaque fois qu'un utilisateur effectue une tâche de développement dans ce projet SDK, y compris, mais sans s'y limiter : développement de pilotes (LISA_DEVICE_REGISTER, API vtable, pilotes de périphériques, UART/SPI/I2C/GPIO/Flash/Display), construction et débogage (erreurs de compilation CMake, échecs de lien, Kconfig/menuconfig, fichiers de carte, problèmes de mémoire insuffisante, compilation/flash/série), génération d'échantillons (comment utiliser xxx, écrire un démo/exemple, exemple d'utilisation), révision du code (révision, vérification du code, PR), problèmes d'architecture du SDK (SYS_INIT, FreeRTOS, sections ELF, scripts de l'éditeur de liens, sections personnalisées). Tout problème impliquant les cartes arcs_mini ou arcs_evb, ou les macros CMake telles que Listenai_library ou Listenai_add_executable, devrait déclencher cette compétence.
