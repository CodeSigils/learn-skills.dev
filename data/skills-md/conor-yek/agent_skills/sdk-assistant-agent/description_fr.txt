Point d'entrée unifié de l'assistant de développement ARCS SDK / LISTENAI SDK. Déclenché chaque fois qu'un utilisateur effectue une tâche de développement au sein de ce projet SDK, y compris, mais sans s'y limiter : le développement de pilotes (LISA_DEVICE_REGISTER, API vtable, pilotes de périphériques, UART/SPI/I2C/GPIO/Flash/Display), la construction et le débogage (erreurs de compilation CMake, échecs de lien, Kconfig/menuconfig, fichiers de carte, mémoire insuffisante, compilation-flash-serial), génération d'échantillons (comment utiliser xxx, écrire une démo/un échantillon, exemples d'utilisation), révision du code (révision, vérification du code, PR), problèmes d'architecture du SDK (SYS_INIT, FreeRTOS, sections ELF, scripts de l'éditeur de liens, sections personnalisées). Tout problème impliquant les cartes arcs_mini, arcs_evb ou les macros CMake comme Listenai_library, Listenai_add_executable devrait déclencher cette compétence.
