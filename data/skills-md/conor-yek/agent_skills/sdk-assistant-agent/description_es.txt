Punto de entrada unificado del Asistente de desarrollo ARCS SDK / LISTENAI SDK. Se activa cada vez que un usuario realiza cualquier tarea de desarrollo dentro de este proyecto SDK, que incluye, entre otros: desarrollo de controladores (LISA_DEVICE_REGISTER, API vtable, controladores periféricos, UART/SPI/I2C/GPIO/Flash/Display), compilación y depuración (errores de compilación de CMake, fallas de enlaces, Kconfig/menuconfig, archivos de mapas, falta de memoria, compilación/flash/serial), generación de ejemplos (cómo usar xxx, escribir una demostración/muestra, uso ejemplos), revisión de código (revisión, verificación de código, relaciones públicas), problemas de arquitectura del SDK (SYS_INIT, FreeRTOS, secciones ELF, scripts de enlazador, secciones personalizadas). Cualquier problema relacionado con los tableros arcs_mini, arcs_evb o macros de CMake como listeningai_library, listeningai_add_executable debería activar esta habilidad.
