Punto de entrada unificado del asistente de desarrollo ARCS SDK / LISTENAI SDK. Se activa cada vez que un usuario realiza cualquier tarea de desarrollo dentro de este proyecto SDK, que incluye, entre otros: desarrollo de controladores (LISA_DEVICE_REGISTER, API vtable, controladores periféricos, UART/SPI/I2C/GPIO/Flash/Display), compilación y depuración (errores de compilación de CMake, fallas de enlaces, Kconfig/menuconfig, archivos de mapas, problemas de falta de memoria, compilación/flash/serial), generación de muestras (cómo usar xxx, escribir un demostración/muestra, ejemplo de uso), revisión de código (revisión, verificación de código, relaciones públicas), problemas de arquitectura del SDK (SYS_INIT, FreeRTOS, secciones ELF, scripts de vinculación, secciones personalizadas). Cualquier problema relacionado con los tableros arcs_mini o arcs_evb, o macros de CMake como listeningai_library o listeningai_add_executable, debería activar esta habilidad.
