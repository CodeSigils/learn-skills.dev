ARCS SDK / LISTENAI SDK 開発アシスタントの統合エントリ ポイント。ユーザーがこの SDK プロジェクト内で開発タスクを実行するたびにトリガーされます。これには、ドライバー開発 (LISA_DEVICE_REGISTER、API vtable、周辺ドライバー、UART/SPI/I2C/GPIO/Flash/ディスプレイ)、ビルドとデバッグ (CMake コンパイル エラー、リンク障害、Kconfig/menuconfig、マップ ファイル、メモリ不足の問題、コンパイル/フラッシュ/シリアル)、サンプル生成 (xxx の使用方法、デモ/サンプル、使用例)、コード レビュー (レビュー、コードのチェック、PR)、SDK アーキテクチャの問題 (SYS_INIT、FreeRTOS、ELF セクション、リンカー スクリプト、カスタム セクション)。 arcs_mini ボードや arcs_evb ボード、または listenai_library や listenai_add_executable などの CMake マクロに関連する問題は、このスキルをトリガーする必要があります。
