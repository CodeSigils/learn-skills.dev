ARCS SDK / LISTENAI SDK 開発アシスタントの統合エントリ ポイント。ユーザーがこの SDK プロジェクトで開発タスクを実行するたびにトリガーされます。これには、ドライバー開発 (LISA_DEVICE_REGISTER、API vtable、周辺ドライバー、UART/SPI/I2C/GPIO/Flash/Display)、ビルドとデバッグ (CMake コンパイル エラー、リンク失敗、Kconfig/menuconfig、マップ ファイル、メモリ不足、コンパイル/フラッシュ/シリアル)、サンプル生成 (xxx の使用方法、デモ/サンプル、使用例)、コード レビュー (レビュー、コード インスペクション、PR)、SDK アーキテクチャの問題 (SYS_INIT、FreeRTOS、ELF セクション、リンカー スクリプト、カスタム セクション)。 arcs_mini、arcs_evb ボード、または listenai_library や listenai_add_executable などの CMake マクロに関連する問題は、このスキルをトリガーする必要があります。
