Punto di ingresso unificato dell'assistente allo sviluppo ARCS SDK / LISTENAI SDK. Si attiva ogni volta che un utente esegue qualsiasi attività di sviluppo all'interno di questo progetto SDK, incluso ma non limitato a: sviluppo di driver (LISA_DEVICE_REGISTER, API vtable, driver periferici, UART/SPI/I2C/GPIO/Flash/Display), creazione e debug (errori di compilazione CMake, errori di collegamento, Kconfig/menuconfig, file di mappa, problemi di memoria insufficiente, compilazione/flash/seriale), generazione di campioni (come utilizzare xxx, scrivere un demo/campione, esempio di utilizzo), revisione del codice (revisione, codice di controllo, PR), problemi di architettura SDK (SYS_INIT, FreeRTOS, sezioni ELF, script linker, sezioni personalizzate). Qualsiasi problema che coinvolga le schede arcs_mini o arcs_evb o le macro CMake come listenai_library o listenai_add_executable dovrebbe attivare questa abilità.
