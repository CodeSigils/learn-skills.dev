ARCS SDK / LISTENAI SDK — унифицированная точка входа для помощника по разработке. Запускается всякий раз, когда пользователь выполняет какую-либо задачу разработки в рамках этого проекта SDK, включая, помимо прочего: разработку драйверов (LISA_DEVICE_REGISTER, API vtable, драйверы периферийных устройств, UART/SPI/I2C/GPIO/Flash/Display), сборку и отладку (ошибки компиляции CMake, сбои связи, Kconfig/menuconfig, файлы карт, проблемы с нехваткой памяти, компиляцию/флеш-последовательный порт), генерацию образцов (как использовать xxx, запись демо/пример, пример использования), обзор кода (обзор, проверка кода, PR), проблемы архитектуры SDK (разделы SYS_INIT, FreeRTOS, ELF, сценарии компоновщика, пользовательские разделы). Любые проблемы, связанные с платами arcs_mini или arcs_evb или макросами CMake, такими как Listenai_library или Listenai_add_executable, должны активировать этот навык.
