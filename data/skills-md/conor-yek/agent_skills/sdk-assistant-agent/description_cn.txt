ARCS SDK/LISTENAI SDK开发助手统一入口点。每当用户在此 SDK 项目中执行任何开发任务时都会触发，包括但不限于：驱动程序开发（LISA_DEVICE_REGISTER、API vtable、外设驱动程序、UART/SPI/I2C/GPIO/Flash/Display）、构建和调试（CMake 编译错误、链接失败、Kconfig/menuconfig、映射文件、内存不足问题、编译/闪存/串行）、示例生成（如何使用 xxx、编写演示/示例、使用示例）、代码审查（审查、检查代码、PR）、SDK 架构问题（SYS_INIT、FreeRTOS、ELF 部分、链接器脚本、自定义部分）。任何涉及 arcs_mini 或 arcs_evb 板或 CMake 宏（例如listenai_library或listenai_add_executable）的问题都应该触发此技能。
