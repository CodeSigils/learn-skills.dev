نقطة دخول موحدة لمساعد تطوير ARCS SDK / LISTENAI SDK. يتم تشغيله عندما يقوم المستخدم بأي مهمة تطوير ضمن مشروع SDK هذا، بما في ذلك على سبيل المثال لا الحصر: تطوير برنامج التشغيل (LISA_DEVICE_REGISTER وAPI vtable وبرامج التشغيل الطرفية وUART/SPI/I2C/GPIO/Flash/Display)، والإنشاء والتصحيح (أخطاء تجميع CMake، وفشل الارتباط، وKconfig/menuconfig، وملفات الخريطة، ومشكلات نفاد الذاكرة، والتجميع/الفلاش/التسلسلي)، وإنشاء العينات (كيفية استخدام xxx، اكتب عرضًا توضيحيًا/عينة، مثال استخدام)، ومراجعة التعليمات البرمجية (مراجعة، والتحقق من التعليمات البرمجية، والعلاقات العامة)، ومشكلات بنية SDK (أقسام SYS_INIT، وFreeRTOS، وELF، والبرامج النصية للرابط، والأقسام المخصصة). أي مشكلات تتعلق بلوحات arcs_mini أو arcs_evb، أو وحدات ماكرو CMake مثل استمع إلى مكتبة أو استمع إلى إضافة_يمكن أن تؤدي إلى تشغيل هذه المهارة.
