Einheitlicher Einstiegspunkt für den ARCS SDK / LISTENAI SDK-Entwicklungsassistenten. Wird immer dann ausgelöst, wenn ein Benutzer eine Entwicklungsaufgabe innerhalb dieses SDK-Projekts ausführt, einschließlich, aber nicht beschränkt auf: Treiberentwicklung (LISA_DEVICE_REGISTER, API-Vtable, Peripherietreiber, UART/SPI/I2C/GPIO/Flash/Display), Build & Debug (CMake-Kompilierungsfehler, Verbindungsfehler, Kconfig/menuconfig, Kartendateien, Probleme mit nicht genügend Arbeitsspeicher, Kompilierung/Flash/seriell), Beispielgenerierung (Verwendung von xxx, Schreiben von a Demo/Beispiel, Anwendungsbeispiel), Codeüberprüfung (Überprüfung, Code prüfen, PR), SDK-Architekturprobleme (SYS_INIT, FreeRTOS, ELF-Abschnitte, Linker-Skripte, benutzerdefinierte Abschnitte). Alle Probleme mit den arcs_mini- oder arcs_evb-Boards oder CMake-Makros wie listenai_library oder listenai_add_executable sollten diesen Skill auslösen.
