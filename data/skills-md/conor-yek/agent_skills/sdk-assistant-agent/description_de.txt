Einheitlicher Einstiegspunkt für den Entwicklungsassistenten ARCS SDK / LISTENAI SDK. Wird immer dann ausgelöst, wenn ein Benutzer eine Entwicklungsaufgabe innerhalb dieses SDK-Projekts ausführt, einschließlich, aber nicht beschränkt auf: Treiberentwicklung (LISA_DEVICE_REGISTER, API-Vtable, Peripherietreiber, UART/SPI/I2C/GPIO/Flash/Display), Build und Debugging (CMake-Kompilierungsfehler, Verknüpfungsfehler, Kconfig/menuconfig, Map-Dateien, unzureichender Speicher, Kompilierungs-/Flash-/serielle Probleme), Beispielgenerierung (Verwendung von xxx, Schreiben einer Demo/eines Beispiels, Verwendung). Beispiele), Codeüberprüfung (Überprüfung, Codeinspektion, PR), SDK-Architekturprobleme (SYS_INIT, FreeRTOS, ELF-Abschnitte, Linker-Skripte, benutzerdefinierte Abschnitte). Alle Probleme im Zusammenhang mit den Board-Konfigurationen arcs_mini oder arcs_evb oder CMake-Makros wie listenai_library oder listenai_add_executable sollten diesen Skill auslösen.
