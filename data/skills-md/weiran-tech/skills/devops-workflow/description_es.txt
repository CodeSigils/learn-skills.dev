Orquestación de proceso completo de desarrollo de requisitos para proyectos monolíticos de múltiples módulos. Impulsado por una máquina de estado, programa automáticamente habilidades/agentes como discusión, archanalizador, equipo y revisor de código, vinculando las cinco etapas desde la discusión de requisitos hasta la revisión del código. Se activa cuando el usuario dice "devops-workflow", "开发流程", "需求流程" o "模块开发流程".
