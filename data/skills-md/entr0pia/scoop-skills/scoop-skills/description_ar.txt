استخدم هذه المهارة لإدارة حزم Windows عبر Scoop. قم بتشغيل هذه المهارة عندما يذكر المستخدم تثبيت البرنامج، أو عندما تحتاج إلى تنفيذ أداة CLI غير مثبتة مسبقًا على Windows ولكن قد يكون لها إصدار Windows متاح للاكتشاف أو التثبيت عبر Scoop (على سبيل المثال، git، وcurl، وneovim، وbat، وما إلى ذلك). تساعدك هذه المهارة أيضًا على اكتشاف وتنفيذ "الحشوات" (الملفات التنفيذية) المثبتة بواسطة Scoop، مما يضمن معرفة أدوات سطر الأوامر المتاحة للاستخدام.
