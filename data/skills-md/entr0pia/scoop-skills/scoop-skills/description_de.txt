Nutzen Sie diesen Skill, um Windows-Pakete über Scoop zu verwalten. Lösen Sie diesen Skill immer dann aus, wenn der Benutzer die Installation von Software erwähnt oder wenn Sie ein CLI-Tool ausführen müssen, das nicht unter Windows vorinstalliert ist, für das jedoch möglicherweise eine Windows-Version zur Erkennung oder Installation über Scoop verfügbar ist (z. B. Git, Curl, Neovim, Bat usw.). Diese Fähigkeit hilft Ihnen auch dabei, die von Scoop installierten „Shims“ (ausführbare Dateien) zu erkennen und auszuführen, um sicherzustellen, dass Sie wissen, welche Befehlszeilentools zur Verwendung verfügbar sind.
