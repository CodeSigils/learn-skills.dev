Utilisez cette compétence pour gérer les packages Windows via Scoop. Déclenchez cette compétence chaque fois que l'utilisateur mentionne l'installation d'un logiciel ou chaque fois que vous devez exécuter un outil CLI qui n'est pas préinstallé sur Windows mais qui peut avoir une version Windows disponible pour la découverte ou l'installation via Scoop (par exemple, git, curl, neovim, bat, etc.). Cette compétence vous aide également à découvrir et à exécuter les « shims » (exécutables) installés par Scoop, vous garantissant ainsi de savoir quels outils de ligne de commande sont disponibles.
