Utilice esta habilidad para administrar paquetes de Windows a través de Scoop. Active esta habilidad cada vez que el usuario mencione la instalación de software o cuando necesite ejecutar una herramienta CLI que no esté preinstalada en Windows pero que pueda tener una versión de Windows disponible para su descubrimiento o instalación a través de Scoop (por ejemplo, git, curl, neovim, bat, etc.). Esta habilidad también le ayuda a descubrir y ejecutar los "shims" (ejecutables) instalados por Scoop, lo que garantiza que sepa qué herramientas de línea de comandos están disponibles para su uso.
