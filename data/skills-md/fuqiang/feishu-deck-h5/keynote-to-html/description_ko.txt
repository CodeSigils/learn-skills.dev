Apple Keynote(`.key`) 프레젠테이션을 `deck.json` + HTML 데크로 변환합니다. 페이지별로 반복하고 각 페이지를 절대 위치의 HTML로 재구성합니다. 이미지는 `<img>`로 유지되고 텍스트는 편집 가능한 HTML, 비디오는 `<video>`로 유지됩니다. `feishu-deck-h5` 스킬과 함께 사용: 이 스킬은 `deck.json`을 생성하고 `feishu-deck-h5/deck-json/render-deck.py`는 이를 프레젠테이션 모드 크롬(← → 페이지 넘기기 / F 전체 화면 / 진행률 표시줄 / 모바일 스크롤 모드)을 사용하여 최종 HTML로 래핑합니다.

트리거 문구: "Keynote를 HTML로 변환", "키노트 가져오기", ".key를 데크로", ".pptx를 HTML로"(Keynote에서 PPTX를 열고 .key로 저장) 또는 사용자가 `.key` 파일 경로/Keynote에서 이미 열린 문서를 제공합니다.

각 슬라이드의 처리 흐름:
1. AppleScript는 슬라이드의 모든 iWork 요소와 출력(유형, 위치, 크기, 파일 이름, 텍스트, 글꼴/글꼴 크기/색상)을 열거합니다.
2. 이미지 파일 참조는 `.key` 번들의 `Data/` 디렉토리에서 확인됩니다. 먼저 정확한 접두사 일치를 시도합니다. "pasted-image.pdf"와 같은 모호한 경우에는 크기/종횡비를 기준으로 일치하는 것으로 대체됩니다.
3. 텍스트가 아닌 각 요소는 원본(x, y, w, h)에 배치된 `<img>` 또는 `<video>`가 됩니다. 각 텍스트 요소는 원래 글꼴과 글꼴 크기를 갖는 실제 HTML 요소가 됩니다.
4. 슬라이드는 `layout: "raw"`를 사용하여 `deck.json`에 기록됩니다.
5. `feishu-deck-h5/deck-json/render-deck.py`는 프레젠테이션 모드 크롬을 사용하여 HTML로 패키징합니다.

허용되는 왜곡(프로세스를 차단하지 않음):
- 사용자 정의 Keynote 글꼴(HarmonyOS / Alibaba PuHui / Founder LanTing)은 웹 안전 중국어 글꼴 스택(PingFang SC, Microsoft YaHei)으로 대체됩니다.
- 1~2개의 모호하게 붙여넣은 이미지 파일이 잘못된 소스와 일치할 수 있습니다. 기록하고 계속하세요.
- 마스터 슬라이드 배경 그라데이션은 아직 구문 분석되지 않았습니다(최선의 노력).
- 애니메이션/입장 효과는 삭제됩니다(설계상 — HTML에는 필요하지 않음).
