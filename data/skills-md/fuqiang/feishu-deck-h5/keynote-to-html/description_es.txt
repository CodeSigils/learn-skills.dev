Convierta presentaciones de Apple Keynote (`.key`) en `deck.json` + presentación HTML: itere página por página, reconstruya cada página como HTML absolutamente posicionado: las imágenes permanecen como `<img>`, el texto es texto HTML editable, los videos son `<video>`. Se usa junto con la habilidad `feishu-deck-h5`: esta habilidad produce `deck.json`, y `feishu-deck-h5/deck-json/render-deck.py` lo envuelve en el HTML final con un chrome en modo de presentación (← → cambio de página/F pantalla completa/barra de progreso/modo de desplazamiento móvil).

Frases desencadenantes: “convertir Keynote a HTML”, “importar keynote”, “.key to deck”, “.pptx a HTML” (simplemente abra el PPTX en Keynote y guárdelo como .key), o el usuario proporciona una ruta de archivo `.key`/un documento ya abierto en Keynote.

Flujo de procesamiento para cada página:
  1. AppleScript itera sobre todos los elementos de iWork en la página y genera (tipo, posición, tamaño, nombre de archivo, texto, fuente/tamaño de fuente/color).
  2. Las referencias de archivos de imagen se resuelven de acuerdo con el directorio Datos/ del paquete .key: primera coincidencia exacta de prefijo; para casos ambiguos como “imagen-pegado.pdf”, recurra a la coincidencia de tamaño/relación de aspecto.
  3. Cada elemento que no es texto se convierte en `<img>` / `<video>` en su original (x, y, w, h); cada elemento de texto se convierte en un elemento HTML real con la fuente y el tamaño de fuente originales.
  4. La página se escribe en deck.json con `layout: "raw"`.
  5. `feishu-deck-h5/deck-json/render-deck.py` lo envuelve en HTML con Chrome en modo de presentación.

Distorsiones aceptables (no dejes que bloqueen el proceso):
  • Las fuentes Keynote personalizadas (HarmonyOS / Alibaba PuHui / Founder LanTing) recurren a una pila de fuentes chinas seguras para la web (PingFang SC, Microsoft YaHei).
  • Es posible que uno o dos archivos de imágenes pegadas ambiguas coincidan con la fuente incorrecta: regístrelo y continúe.
  • Los degradados de fondo de la diapositiva maestra aún no se han analizado (mejor esfuerzo).
  • Las animaciones/efectos de entrada se descartan (por diseño: HTML no los necesita).
