Konvertieren Sie Apple Keynote-Präsentationen (`.key`) in „deck.json“ + HTML-Deck: Seite für Seite iterieren, jede Seite als absolut positioniertes HTML rekonstruieren – Bilder bleiben „<img>“, Text ist bearbeitbarer HTML-Text, Videos sind „<video>“. Wird zusammen mit dem Skill „feishu-deck-h5“ verwendet: Dieser Skill erzeugt „deck.json“ und „feishu-deck-h5/deck-json/render-deck.py“ bindet ihn in den endgültigen HTML-Code mit einem Chrom im Präsentationsmodus ein (← → Umblättern / F-Vollbild / Fortschrittsbalken / mobiler Scrollmodus).

Auslösephrasen: „Keynote in HTML konvertieren“, „Keynote importieren“, „.key in Deck“, „.pptx in HTML“ (öffnen Sie einfach das PPTX in Keynote und speichern Sie es als .key), oder der Benutzer gibt einen „.key“-Dateipfad / ein bereits geöffnetes Dokument in Keynote an.

Verarbeitungsablauf für jede Seite:
  1. AppleScript durchläuft alle iWork-Elemente auf der Seite und gibt aus (Typ, Position, Größe, Dateiname, Text, Schriftart/Schriftgröße/Farbe).
  2. Bilddateiverweise werden gemäß dem Data/-Verzeichnis des .key-Bundles aufgelöst: erste exakte Präfixübereinstimmung; Bei mehrdeutigen Fällen wie „pasted-image.pdf“ greifen Sie auf die Größen-/Seitenverhältnisanpassung zurück.
  3. Jedes Nicht-Text-Element wird im Original (x, y, w, h) zu einem „<img>“ / „<video>“; Jedes Textelement wird zu einem echten HTML-Element mit der ursprünglichen Schriftart und Schriftgröße.
  4. Die Seite wird mit „layout: „raw““ in deck.json geschrieben.
  5. „feishu-deck-h5/deck-json/render-deck.py“ verpackt es mit Chrome im Präsentationsmodus in HTML.

Akzeptable Verzerrungen (lassen Sie nicht zu, dass sie den Prozess blockieren):
  • Benutzerdefinierte Keynote-Schriftarten (HarmonyOS / Alibaba PuHui / Founder LanTing) greifen auf einen websicheren chinesischen Schriftartenstapel (PingFang SC, Microsoft YaHei) zurück.
  • Eine oder zwei mehrdeutige eingefügte Bilddateien sind möglicherweise der falschen Quelle zugeordnet – protokollieren Sie sie und fahren Sie fort.
  • Hintergrundverläufe der Masterfolie werden noch nicht analysiert (Best-Effort).
  • Animationen/Eingangseffekte werden verworfen (beabsichtigt – HTML benötigt sie nicht).
