Apple Keynote (`.key`) プレゼンテーションを `deck.json` + HTML デッキに変換します。ページごとに繰り返し、各ページを絶対位置の HTML として再構築します。画像は `<img>` のまま、テキストは編集可能な HTML テキスト、ビデオは `<video>` です。 `feishu-deck-h5` スキルと一緒に使用します。このスキルは `deck.json` を生成し、`feishu-deck-h5/deck-json/render-deck.py` はそれをプレゼンテーション モード クロム (← → ページめくり / F フルスクリーン / プログレス バー / モバイル スクロール モード) を使用して最終的な HTML にラップします。

トリガーフレーズ: 「Keynote を HTML に変換」、「Keynote をインポート」、「.key をデッキに」、「.pptx を HTML に」 (Keynote で PPTX を開いて .key として保存するだけです)、またはユーザーが「.key」 ファイル パス / Keynote ですでに開いているドキュメントを指定します。

各ページの処理の流れ：
  1. AppleScript はページ上のすべての iWork 要素を反復処理し、(タイプ、位置、サイズ、ファイル名、テキスト、フォント / フォント サイズ / 色) を出力します。
  2. イメージ ファイル参照は、.key バンドルの Data/ ディレクトリに従って解決されます。最初に正確なプレフィックス マッチングが行われます。 「貼り付けられた画像.pdf」のようなあいまいな場合は、サイズ/アスペクト比の一致に戻ります。
  3. テキスト以外の各要素は、元の (x, y, w, h) の `<img>` / `<video>` になります。各テキスト要素は、元のフォントとフォント サイズを持つ実際の HTML 要素になります。
  4. ページは`layout: "raw"`でdeck.jsonに書き込まれます。
  5. `feishu-deck-h5/deck-json/render-deck.py` は、プレゼンテーションモード Chrome を使用して HTML にラップします。

許容可能な歪み (プロセスをブロックしないようにしてください):
  • カスタム Keynote フォント (HarmonyOS / Alibaba PuHui / Founder LanTing) は、Web セーフな中国語フォント スタック (PingFang SC、Microsoft YaHei) にフォールバックします。
  • 1 つまたは 2 つのあいまいな貼り付け画像ファイルが間違ったソースに一致する可能性があります。ログに記録して続行します。
  • マスタースライドの背景のグラデーションはまだ解析されていません (ベストエフォート)。
  • アニメーション/開始エフェクトは破棄されます (仕様により、HTML では必要ありません)。
