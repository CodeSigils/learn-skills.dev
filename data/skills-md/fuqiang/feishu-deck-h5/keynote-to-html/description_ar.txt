تحويل عرض تقديمي لـ Apple Keynote ‏(`.key`) إلى `deck.json` + مجموعة HTML: قم بالتكرار عبر الشرائح واحدة تلو الأخرى، وأعد بناء كل شريحة باعتبارها HTML في موضعها المطلق - تظل الصور `<img>`، ويصبح النص نص HTML قابلاً للتحرير، وتصبح مقاطع الفيديو `<video>`. استخدمها مع مهارة `feishu-deck-h5`: تنتج هذه المهارة `deck.json`؛ يقوم `feishu-deck-h5/deck-json/render-deck.py` بتغليفه في ملف HTML نهائي باستخدام وضع العرض التقديمي chrome (← → لقلب الصفحة / F لملء الشاشة / شريط التقدم / وضع التمرير المحمول).

تشغيل العبارات: "تحويل Keynote إلى HTML"، أو "استيراد الكلمة الرئيسية"، أو ".key tock"، أو ".pptx إلى HTML" (فقط افتح PPTX في Keynote واحفظه كـ .key)، أو يوفر المستخدم مسار ملف ".key" / مستند مفتوح بالفعل في Keynote.

تدفق المعالجة لكل شريحة:
1. يتكرر AppleScript على جميع عناصر iWork الموجودة في تلك الشريحة، ويخرج (النوع والموضع والحجم واسم الملف والنص والخط / حجم الخط / اللون).
2. يتم حل مراجع ملفات الصور من دليل "Data/" الخاص بحزمة ".key": حاول أولاً إجراء مطابقة تامة للبادئة؛ بالنسبة للحالات الغامضة مثل "pasted-image.pdf" يمكنك الرجوع إلى المطابقة حسب الأبعاد/نسبة العرض إلى الارتفاع.
3. يصبح كل عنصر غير نصي `<img>` أو `<video>` موضوعًا في الأصل (x, y, w, h); يصبح كل عنصر نص عنصر HTML حقيقي بالخط الأصلي وحجم الخط.
4. تتم كتابة الشريحة في "deck.json" باستخدام "التخطيط: "raw"".
5. يقوم `feishu-deck-h5/deck-json/render-deck.py` بتغليفه في ملف HTML باستخدام وضع العرض التقديمي chrome.

التشوهات المقبولة (لا تسمح لهم بإيقاف العملية):
- تعود خطوط Keynote المخصصة (HarmonyOS، وAlibaba PuHui، وFounder LanTing، وما إلى ذلك) إلى مجموعة الخطوط الصينية الآمنة على الويب (PingFang SC، وMicrosoft YaHei).
- قد يكون هناك 1-2 من ملفات الصور الملصقة الغامضة متطابقة مع المصدر الخاطئ - قم بتسجيله وتابع.
- لا يتم تحليل تدرجات خلفية الشريحة الرئيسية (أفضل جهد فقط).
- يتم تجاهل الرسوم المتحركة / تأثيرات المدخل (حسب التصميم — لا يحتاج HTML إليها).
