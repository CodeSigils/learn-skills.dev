Abilità 总控 per mazzi HTML in stile Feishu/Lark. Utilizzare per 飞书风格 PPT, mazzo Lark,
汇报材料, 客户提案, mazzo h5, formato 16:9, generazione/modifica/convalida del mazzo HTML,
analisi del codice sorgente, pubblicazione Magic Page/Miaobi/html-box e libreria feishu-slide
importazione. I percorsi funzionano verso le sottocompetenze; la generazione è DeckJSON/render-deck per prima,
normalmente raw-first, con convalida prima del trasferimento/importazione; la pubblicazione utilizza il file
il cancello leggero di integrità degli artefatti dell'editore. Per un vero `.pptx`, usa a
Flusso di lavoro PowerPoint/keynote invece.
