Используйте этот навык только для обработки уже загруженных файлов. Не вызывайте, когда пользователь предоставляет URL-адрес. При вызове передайте полный запрос пользователя дословно в качестве аргументов — не анализируйте пути к файлам заранее и не перефразируйте их.
