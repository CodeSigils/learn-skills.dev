Extraiga datos estructurados (todos los campos disponibles con valores) de una página guardada localmente como un archivo HTML, opcionalmente siguiendo un esquema. Utilice esta habilidad sólo para procesar archivos ya descargados. No invocar cuando el usuario proporciona una URL. Al invocar, pase la solicitud completa del usuario palabra por palabra como argumentos; no analice previamente las rutas de los archivos ni las reformule.
