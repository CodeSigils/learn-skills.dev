Consulta estadísticas de uso para solicitudes de API de Zyte que ya se han enviado, incluido el costo, el volumen de solicitudes, los tiempos de respuesta, los códigos de estado, los filtros, la agrupación y la paginación. Utilice esta habilidad siempre que responder a la solicitud requiera buscar el uso registrado de la API de Zyte, el gasto, el recuento de solicitudes, los tiempos de respuesta, las estadísticas agrupadas o las estadísticas filtradas, incluida la proyección del gasto o uso futuro cuando la proyección se extrapola explícitamente del uso registrado real (por ejemplo, "según el uso de este mes hasta el momento, el gasto de fin de mes del proyecto"). No lo use cuando el usuario pregunte qué podría, generaría o podría generar una araña, un trabajo o una carga de trabajo; esas son estimaciones hipotéticas sin datos registrados para consultar, incluso si existe una araña en el proyecto. Para que una proyección califique, el usuario debe hacer referencia explícita al uso registrado pasado o actual como base. Tampoco lo utilice para la configuración del panel, la documentación, la configuración o las preguntas de ayuda de la cuenta.
