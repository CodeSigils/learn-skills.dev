Interroga le statistiche sull'utilizzo per le richieste API Zyte che sono già state inviate, inclusi costo, volume delle richieste, tempi di risposta, codici di stato, filtri, raggruppamento e impaginazione. Utilizza questa abilità ogni volta che per rispondere alla richiesta è necessario cercare l'utilizzo registrato dell'API Zyte, la spesa, i conteggi delle richieste, i tempi di risposta, le statistiche raggruppate o le statistiche filtrate, inclusa la proiezione della spesa o dell'utilizzo futuro quando la proiezione estrapola esplicitamente dall'utilizzo effettivo registrato (ad esempio "in base all'utilizzo di questo mese finora, spesa di fine mese del progetto"). Non utilizzarlo quando l'utente chiede cosa potrebbe, potrebbe o potrebbe generare uno spider, un lavoro o un carico di lavoro: si tratta di stime ipotetiche senza dati registrati da interrogare, anche se esiste uno spider nel progetto. Affinché una proiezione sia idonea, l'utente deve fare esplicitamente riferimento all'utilizzo registrato passato o attuale come base. Inoltre, non utilizzare per l'impostazione della dashboard, la documentazione, la configurazione o per domande di assistenza sull'account.
