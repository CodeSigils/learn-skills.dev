إحصائيات استخدام الاستعلام لطلبات Zyte API التي تم إرسالها بالفعل، بما في ذلك التكلفة وحجم الطلب وأوقات الاستجابة ورموز الحالة والمرشحات والتجميع وترقيم الصفحات. استخدم هذه المهارة عندما تتطلب الإجابة على الطلب البحث عن استخدام Zyte API المسجل، أو الإنفاق، أو عدد الطلبات، أو أوقات الاستجابة، أو الإحصائيات المجمعة، أو الإحصائيات المصفاة - بما في ذلك توقع الإنفاق أو الاستخدام المستقبلي عندما يستنبط الإسقاط بشكل صريح من الاستخدام الفعلي المسجل (على سبيل المثال، "استنادًا إلى استخدام هذا الشهر حتى الآن، إنفاق نهاية الشهر للمشروع"). لا تستخدمه عندما يسأل المستخدم عما قد يولده أو يمكن أن يولده عنكبوت أو وظيفة أو عبء عمل - فهذه تقديرات افتراضية بدون بيانات مسجلة للاستعلام عنها، حتى لو كان العنكبوت موجودًا في المشروع. لكي يتم تأهيل الإسقاط، يجب على المستخدم الإشارة بوضوح إلى الاستخدام المسجل السابق أو الحالي كأساس. ولا تستخدم أيضًا لإعداد لوحة المعلومات أو الوثائق أو التكوين أو أسئلة مساعدة الحساب.
