Статистика использования запросов для уже отправленных запросов API Zyte, включая стоимость, объем запросов, время ответа, коды состояния, фильтры, группировку и нумерацию страниц. Используйте этот навык всякий раз, когда для ответа на запрос требуется просмотреть зарегистрированные данные об использовании Zyte API, расходах, количестве запросов, времени ответа, сгруппированной статистике или отфильтрованной статистике, включая прогнозирование будущих расходов или использования, когда прогноз явно экстраполируется из фактического зарегистрированного использования (например, «на основе использования в этом месяце, проектные расходы на конец месяца»). Не используйте его, когда пользователь спрашивает, что может, будет или может генерировать паук, задание или рабочая нагрузка — это гипотетические оценки без записанных данных для запроса, даже если паук существует в проекте. Чтобы прогноз соответствовал критериям, пользователь должен явно указать в качестве основы прошлые или текущие зарегистрированные данные об использовании. Также не используйте его для настройки информационной панели, документации, конфигурации или вопросов, связанных с учетной записью.
