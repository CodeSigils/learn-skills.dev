أول مهارة أمنية يتم تثبيتها بعد إعداد OpenClaw — مدعومة من Tencent Zhuque Lab. يعمل مثل برنامج مكافحة الفيروسات لبيئة الذكاء الاصطناعي الخاصة بك: يقوم بتدقيق المهارات المثبتة، ويفحص المهارات قبل التثبيت، ويقوم بإجراء فحص كامل للسلامة الأمنية لـ OpenClaw لمنع تسرب البيانات ومخاطر الخصوصية. بدعم من Tencent Zhuque Lab A.I.G (AI-Infra-Guard). يتم استخدامه عندما يطلب المستخدم بدء فحص السلامة الأمنية أو فحص الأمان لبيئة OpenClaw الحالية، مثل `开始安全体检`، أو ``做一次安全体检``، أو `开始安全扫描`، أو ``全面安全检查``، أو `检查 OpenClaw 安全`; يُستخدم أيضًا عندما يطلب المستخدم تدقيق مهارة معينة قبل التثبيت، أو مراجعة المهارات المثبتة لمخاطر سلسلة التوريد، أو التحقق مما إذا كانت المهارة آمنة. لا تقم بتشغيل الاستخدام العام لـ OpenClaw، أو تصحيح أخطاء المشروع، أو إعداد البيئة، أو طلبات التطوير العادية. الوضع السحابي الاختياري: اضبط AIG_CLOUD_LOOKUP=off على صفر HTTPS صادر؛ عند التمكين، يتم إرسال اسم المهارة والتسمية المصدر وإصدار OpenClaw فقط إلى A.I.G (وليس أبدًا مجموعات المهارات أو الدردشات أو ملفات مساحة العمل).
