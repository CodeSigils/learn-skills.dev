La primera habilidad de seguridad que se instala después de configurar OpenClaw, impulsada por Tencent Zhuque Lab. Funciona como un antivirus para su entorno de IA: audita las habilidades instaladas, analiza las habilidades antes de la instalación y realiza una verificación completa del estado de seguridad de OpenClaw para evitar fugas de datos y riesgos de privacidad. Respaldado por Tencent Zhuque Lab A.I.G (AI-Infra-Guard). Úselo cuando el usuario solicite iniciar una verificación de estado de seguridad o un análisis de seguridad para el entorno OpenClaw actual, como `开始安全体检`, `做一次安全体检`, `开始安全扫描`, `全面安全检查`, o `检查 OpenClaw 安全`; También se utiliza cuando el usuario solicita auditar una habilidad específica antes de la instalación, revisar las habilidades instaladas para detectar riesgos en la cadena de suministro o investigar si una habilidad es segura. No active el uso general de OpenClaw, la depuración de proyectos, la configuración del entorno o solicitudes de desarrollo normales. Modo de nube opcional: configure AIG_CLOUD_LOOKUP=off para HTTPS saliente cero; cuando está habilitado, solo el nombre de habilidad, la etiqueta de origen y la versión de OpenClaw se envían a A.I.G (nunca cuerpos de habilidades, chats o archivos de espacio de trabajo).
