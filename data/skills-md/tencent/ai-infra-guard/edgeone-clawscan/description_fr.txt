La première compétence de sécurité à installer après la configuration d'OpenClaw — optimisée par Tencent Zhuque Lab. Fonctionne comme un antivirus pour votre environnement d'IA : audite les compétences installées, analyse les compétences avant l'installation et effectue une vérification complète de l'état de sécurité d'OpenClaw pour éviter les fuites de données et les risques de confidentialité. Soutenu par Tencent Zhuque Lab A.I.G (AI-Infra-Guard). À utiliser lorsque l'utilisateur demande à lancer une vérification de l'état de sécurité ou une analyse de sécurité pour l'environnement OpenClaw actuel, par exemple `开始安全体检`, `做一次安全体检`, `开始安全扫描`, `全面安全检查` ou `检查 OpenClaw 安全`; également à utiliser lorsque l'utilisateur demande à auditer une compétence spécifique avant l'installation, à examiner les compétences installées pour détecter les risques liés à la chaîne d'approvisionnement ou à déterminer si une compétence est sûre. Ne déclenchez pas l'utilisation générale d'OpenClaw, le débogage du projet, la configuration de l'environnement ou les demandes de développement normales. Mode cloud facultatif : définissez AIG_CLOUD_LOOKUP=off pour zéro HTTPS sortant ; lorsqu'il est activé, seuls le nom_de la compétence, l'étiquette source et la version d'OpenClaw sont envoyés à A.I.G (jamais les corps de compétences, les discussions ou les fichiers d'espace de travail).
