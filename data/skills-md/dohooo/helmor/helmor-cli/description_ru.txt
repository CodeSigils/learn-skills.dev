Используйте Helmor CLI для удаленного управления Helmor с терминала. Используйте, когда пользователь запрашивает проверку данных/настроек Helmor, управление репозиториями/рабочими пространствами/сессиями/файлами, отправку запросов агентам, список моделей, использование интеграции GitHub, проверку сценариев, миграцию из Conductor, запуск Helmor в качестве сервера MCP, создание завершений оболочки, выход из работающего приложения, проверку/установку/обновление бета-версии Helmor CLI, установку/обновление навыков Helmor через процесс бета-приложения или ему нужен справочник по командам Helmor.
