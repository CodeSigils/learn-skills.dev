Genera una suite di documentazione di progetto completa e coerente internamente: otto file di markdown standardizzati scritti in documenti/cartelle (PRD, architettura software, specifiche funzionali, architettura del database, specifiche del pannello di amministrazione, specifiche API REST, linee guida di progettazione, modello di progetto). Usalo ogni volta che l'utente desidera documentare un progetto software, avviare documenti per una base di codice nuova o esistente o produrre uno di questi documenti: un PRD, un documento di architettura, una specifica API, una progettazione di database, linee guida ingegneristiche, un progetto di progetto. Attiva frasi come "documentazione di progetto", "documenti di progettazione", "documenti specifici", "suite di documentazione", "scrivi i documenti", "documenta questa app/servizio/sistema" o una richiesta per uno solo degli otto documenti (la suite è progettata per essere generata insieme in modo che i documenti rimangano coerenti tra loro). Si attiva anche quando l'utente ha creato o descritto un progetto software nella conversazione e ora desidera che sia scritto formalmente.
