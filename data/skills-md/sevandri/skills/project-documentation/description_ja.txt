内部的に一貫した完全なプロジェクト ドキュメント スイートを生成します。8 つの標準化されたマークダウン ファイルが docs/ フォルダーに書き込まれます (PRD、ソフトウェア アーキテクチャ、機能仕様、データベース アーキテクチャ、管理パネル仕様、REST API 仕様、エンジニアリング ガイドライン、プロジェクト ブループリント)。ユーザーがソフトウェア プロジェクトを文書化する場合、新規または既存のコードベースのドキュメントをブートストラップする場合、またはこれらのドキュメント (PRD、アーキテクチャ ドキュメント、API 仕様、データベース設計、エンジニアリング ガイドライン、プロジェクト ブループリントなど) を作成する場合は常にこれを使用します。 「プロジェクト ドキュメント」、「設計ドキュメント」、「仕様ドキュメント」、「ドキュメント スイート」、「ドキュメントを作成」、「このアプリ/サービス/システムのドキュメントを作成」などのフレーズ、または 8 つのドキュメントのうち 1 つだけのリクエストをトリガーします (スイートは、ドキュメントが相互に一貫性を保つように一緒に生成されるように設計されています)。また、ユーザーが会話の中でソフトウェア プロジェクトを構築または説明していて、それを正式に文書化したい場合にもトリガーされます。
