Genere un conjunto de documentación de proyectos completo y coherente internamente: ocho archivos de rebajas estandarizados escritos en una carpeta de documentos (PRD, arquitectura de software, especificaciones funcionales, arquitectura de base de datos, especificaciones del panel de administración, especificaciones de API REST, directrices de ingeniería, plano del proyecto). Úselo siempre que el usuario quiera documentar un proyecto de software, iniciar documentos para una base de código nueva o existente, o producir cualquiera de esos documentos: un PRD, un documento de arquitectura, una especificación de API, un diseño de base de datos, pautas de ingeniería, un plano de proyecto. Active frases como "documentación del proyecto", "documentos de diseño", "documentos de especificaciones", "conjunto de documentación", "escribir los documentos", "documentar esta aplicación/servicio/sistema" o una solicitud de solo uno de los ocho documentos (el conjunto está diseñado para generarse en conjunto para que los documentos sean coherentes entre sí). También se activa cuando el usuario ha estado creando o describiendo un proyecto de software en la conversación y ahora quiere que se escriba formalmente.
