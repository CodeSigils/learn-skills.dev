قم بإنشاء مجموعة وثائق مشروع كاملة ومتسقة داخليًا - ثمانية ملفات تخفيض قياسية مكتوبة في مستندات/مجلد (PRD، بنية البرنامج، المواصفات الوظيفية، بنية قاعدة البيانات، مواصفات لوحة الإدارة، مواصفات REST API، الإرشادات الهندسية، مخطط المشروع). استخدم هذا عندما يريد المستخدم توثيق مشروع برمجي، أو مستندات التمهيد لقاعدة تعليمات برمجية جديدة أو موجودة، أو إنتاج أي من هذه المستندات - PRD، أو مستند معماري، أو مواصفات واجهة برمجة التطبيقات (API)، أو تصميم قاعدة بيانات، أو إرشادات هندسية، أو مخطط مشروع. قم بتشغيل عبارات مثل "وثائق المشروع"، أو "مستندات التصميم"، أو "مستندات المواصفات"، أو "مجموعة الوثائق"، أو "اكتب المستندات"، أو "توثيق هذا التطبيق/الخدمة/النظام"، أو طلب لواحد فقط من المستندات الثمانية (تم تصميم المجموعة ليتم إنشاؤها معًا بحيث تظل المستندات متسقة مع بعضها البعض). يتم تشغيله أيضًا عندما يقوم المستخدم بإنشاء مشروع برمجي أو وصفه في المحادثة ويريد الآن كتابته رسميًا.
