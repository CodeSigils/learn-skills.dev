Создайте полный, внутренне согласованный пакет проектной документации — восемь стандартизированных файлов уценки, записанных в папку docs/ (PRD, архитектура программного обеспечения, функциональная спецификация, архитектура базы данных, спецификация панели администратора, спецификация REST API, инженерные рекомендации, чертеж проекта). Используйте это всякий раз, когда пользователь хочет задокументировать проект программного обеспечения, подготовить документы для новой или существующей базы кода или создать любой из этих документов — PRD, документ по архитектуре, спецификацию API, проект базы данных, инженерные рекомендации, план проекта. Запускайте такие фразы, как «проектная документация», «проектная документация», «спецификация», «пакет документации», «напишите документацию», «документируйте это приложение/сервис/систему» ​​или запрос только одного из восьми документов (пакет предназначен для создания вместе, чтобы документы оставались согласованными друг с другом). Также срабатывает, когда пользователь создавал или описывал программный проект в разговоре и теперь хочет, чтобы он был официально записан.
