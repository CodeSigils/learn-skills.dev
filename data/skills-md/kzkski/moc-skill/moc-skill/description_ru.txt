Извлечение информации об объекте только для чтения из FIWARE Orion Context Broker (NGSIv2). Он активно используется, когда необходимы запросы GET к платформам интеграции данных, городской ОС, платформам умного города, данным датчиков или платформам IoT, а также при проверке списков и подсчетов объектов или исследовании API NGSIv2. Запускается запросом доступа к платформе с заголовком Fiware-Service, включающим Orion/NGSIv2/Context Broker/извлечение объекта/q-запрос/геопространственный запрос.
