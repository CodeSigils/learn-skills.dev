Recupero in sola lettura delle informazioni sull'entità da FIWARE Orion Context Broker (NGSIv2). Viene utilizzato attivamente quando sono necessarie query GET su piattaforme di integrazione dati, sistemi operativi cittadini, piattaforme smart city, dati di sensori o piattaforme IoT, nonché quando si controllano elenchi e conteggi di entità o si indaga sull'API NGSIv2. Attivato da una richiesta di accesso alla piattaforma con un'intestazione Fiware-Service, che coinvolge Orion / NGSIv2 / Context Broker / recupero di entità / query q / query geospaziale.
