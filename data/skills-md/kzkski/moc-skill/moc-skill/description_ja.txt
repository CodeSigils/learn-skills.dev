FIWARE Orion Context Broker (NGSIv2) からのエンティティ情報の読み取り専用の取得。データ統合プラットフォーム、都市 OS、スマート シティ プラットフォーム、センサー データ、IoT プラットフォームへの GET クエリが必要な場合、エンティティ リストと数を確認する場合、または NGSIv2 API を調査する場合に積極的に使用されます。これは、Orion / NGSIv2 / Context Broker / エンティティ取得 / q クエリ / 地理空間クエリの Fiware-Service ヘッダーを使用したプラットフォーム アクセスのリクエストによってトリガーされます。
