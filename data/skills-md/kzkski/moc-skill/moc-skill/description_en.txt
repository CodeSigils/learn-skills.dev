Read-only retrieval of entity information from the FIWARE Orion Context Broker (NGSIv2). It is actively used when GET queries to data integration platforms, city OS, smart city platforms, sensor data, or IoT platforms are needed, as well as when checking entity lists and counts or investigating the NGSIv2 API. Triggered by a request for platform access with a Fiware-Service header, involving Orion / NGSIv2 / Context Broker / entity retrieval / q query / geospatial query.
