Recuperación de solo lectura de información de entidad del FIWARE Orion Context Broker (NGSIv2). Se utiliza activamente cuando se necesitan consultas GET a plataformas de integración de datos, sistemas operativos urbanos, plataformas de ciudades inteligentes, datos de sensores o plataformas de IoT, así como cuando se verifican listas y recuentos de entidades o se investiga la API NGSIv2. Activado por una solicitud de acceso a la plataforma con un encabezado Fiware-Service, que involucra Orion / NGSIv2 / Context Broker / recuperación de entidades / consulta q / consulta geoespacial.
