استرجاع معلومات الكيان للقراءة فقط من FIWARE Orion context Broker (NGSIv2). يتم استخدامه بشكل نشط عند الحاجة إلى استعلامات GET لمنصات تكامل البيانات أو نظام تشغيل المدينة أو منصات المدن الذكية أو بيانات المستشعر أو منصات إنترنت الأشياء، وكذلك عند التحقق من قوائم الكيانات والتعدادات أو التحقيق في NGSIv2 API. يتم تشغيله بواسطة طلب الوصول إلى النظام الأساسي باستخدام رأس Fiware-Service، والذي يتضمن Orion / NGSIv2 / context Broker / استرجاع الكيان / استعلام q / استعلام جغرافي مكاني.
