Strumento di ricerca Baidu. Utilizza la CLI bdsearch per cercare contenuti web tramite l'API Baidu AI Search. Scenari di attivazione: richieste dell'utente di ricerca Baidu, ricerca di notizie, recupero di informazioni, tutorial, ricerca tematica, acquisizione di informazioni web pubbliche o necessità di risultati di ricerca strutturati.
