Outil de recherche Baidu. Utilisez la CLI bdsearch pour rechercher du contenu Web via l'API Baidu AI Search. Scénarios de déclenchement : l'utilisateur demande une recherche Baidu, une recherche d'actualités, une recherche d'informations, des didacticiels, une recherche thématique, l'obtention d'informations publiques sur le Web ou la nécessité de résultats de recherche structurés.
