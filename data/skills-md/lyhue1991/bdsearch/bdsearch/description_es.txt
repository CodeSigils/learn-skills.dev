Herramienta de búsqueda de Baidu. Utilice la CLI de bdsearch para buscar contenido web a través de la API de búsqueda AI de Baidu. Escenarios desencadenantes: cuando los usuarios solicitan búsquedas en Baidu, búsqueda de noticias, recuperación de información, tutoriales, investigaciones temáticas, información de páginas web públicas o resultados de búsqueda estructurados.
