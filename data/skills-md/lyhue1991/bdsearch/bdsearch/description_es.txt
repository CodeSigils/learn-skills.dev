Herramienta de búsqueda de Baidu. Utilice la CLI de bdsearch para buscar contenido web a través de la API de búsqueda AI de Baidu. Escenarios desencadenantes: el usuario solicita búsqueda en Baidu, búsqueda de noticias, recuperación de información, tutoriales, investigación temática, obtención de información web pública o necesidad de resultados de búsqueda estructurados.
