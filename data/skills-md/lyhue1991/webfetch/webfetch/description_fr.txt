Outil de scraping de contenu de pages Web. Utilisez la CLI webfetch pour récupérer le contenu d'une page Web et le convertir au format Markdown, texte ou HTML. Scénarios de déclenchement : demandes d'utilisateurs pour récupérer une page Web, obtenir le contenu d'une page Web, convertir une page Web en Markdown, convertir une page Web en texte, télécharger une page Web.
