Herramienta de extracción de contenido de páginas web. Utilice la CLI de webfetch para buscar contenido de la página web y convertirlo a formato Markdown, texto o HTML. Escenarios de activación: solicitudes de usuarios para extraer una página web, obtener contenido de la página web, convertir una página web a Markdown, convertir una página web a texto, descargar una página web.
