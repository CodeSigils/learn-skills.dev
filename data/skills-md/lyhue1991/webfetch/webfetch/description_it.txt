Strumento di scraping del contenuto della pagina Web. Utilizza la CLI webfetch per recuperare il contenuto della pagina Web e convertirlo in formato Markdown, testo o HTML. Scenari di attivazione: richieste dell'utente di raschiare una pagina Web, ottenere il contenuto di una pagina Web, convertire una pagina Web in Markdown, convertire una pagina Web in testo, scaricare una pagina Web.
