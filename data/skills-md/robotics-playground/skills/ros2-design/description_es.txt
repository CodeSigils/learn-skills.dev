Utilice esta habilidad siempre que el usuario desee crear o actualizar un paquete completo de diseño arquitectónico de ROS 2 (especificaciones por nodo, especificaciones de interfaz personalizadas, un documento de estructura de paquete y un conjunto de diagramas de flujo de datos + mapa de nodos de PlantUML) en un directorio `designs/` (o con un nombre similar) en el área de planificación del proyecto (`docs/`, `_bmad-output/planning-artifacts/`, o dondequiera que se encuentre la arquitectura). Active frases como "diseñar los nodos ROS 2", "crear documentos de diseño de nodos", "dibujar el flujo de datos/mapa de nodos", "diseñar los paquetes de colcon", "especificar los temas y servicios" o cualquier solicitud para tomar un PRD + documento de arquitectura + documento de hardware/cableado y producir el contrato de implementación con el que codificarán los agentes posteriores. También se activa cuando el usuario dice que tiene un PRD/arquitectura para un proyecto de robótica y pregunta "qué sigue" o "cómo debo estructurar la implementación". Este es el entregable previo a la implementación de carga para cualquier proyecto ROS 2 (Jazzy / Humble / Iron / Rolling).
