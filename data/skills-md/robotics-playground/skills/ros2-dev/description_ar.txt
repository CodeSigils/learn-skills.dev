إرشادات الخبراء لتطوير ROS 2 (Jazzy) في Python (rclpy) وC++ (rclcpp). يُستخدم عندما يعمل المستخدم مع عقد ROS 2، أو المواضيع، أو الخدمات، أو الإجراءات، أو جودة الخدمة، أو المعلمات، أو عقد دورة الحياة، أو المنفذين، أو مجموعات رد الاتصال، أو ملفات التشغيل، أو إنشاءات colcon/ament، أو package.xml/setup.py، أو tf2، أو URDF/Xacro، أو DDS (Fast-DDS، أو Cyclone DDS)، أو أدوات ros2 CLI (التشغيل، الإطلاق، الموضوع، العقدة، الخدمة، المعلمة، الحقيبة، الطبيب). قم أيضًا بتشغيل الإشارات الضمنية: "العقدة الخاصة بي لا يمكنها رؤية الموضوع"، "لا تصل الرسائل"، "رد الاتصال لا يتم إطلاقه"، "عدم تطابق جودة الخدمة"، "فشل بحث التحويل"، "فشل إنشاء colcon"، "ملف التشغيل لا يعمل"، "ما نوع الرسالة"، "كيف أجعل عقدتين تتحدثان"، "الروبوت لا يتحرك"، "كيفية اختبار عقدة ROS". يستخدم أيضًا لتصحيح أخطاء محاكاة ROS 2 + Gazebo - عندما يذكر المستخدم Gazebo، أو gz sim، أو ros_gz_bridge، أو use_sim_time، /clock، أو sim-to-real، أو يبلغ عن "ينحرف المسح بالليزر عندما يتحول الروبوت"، أو "تتلف الخريطة"، أو "odom غير متطابق"، أو "ينقلب الروبوت في Gazebo"، أو "المسح عالق"، أو أي حالة حيث يكون الرسم البياني ROS 2 والفيزياء لا يوافق جهاز المحاكاة - حتى لو لم يذكروا "ROS 2" بشكل صريح.
