Genere una imagen completamente nueva a partir de un mensaje de texto a través del modelo Wanxiang wan2.6-t2i en Alibaba MaaS. Úselo cuando el usuario diga "สร้างภาพ...", "วาดภาพ...", "generar una imagen de...", o solicita una nueva imagen a partir de una descripción, no para modificar una imagen que ya existe (eso es wan-image-edit).
