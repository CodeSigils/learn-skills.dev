Générez une toute nouvelle image à partir d'une invite de texte via le modèle Wanxiang wan2.6-t2i sur Alibaba MaaS. À utiliser lorsque l'utilisateur dit "สร้างภาพ...", "วาดภาพ...", "générer une image de...", ou demande une nouvelle image à partir d'une description - pas pour modifier une image qui existe déjà (c'est wan-image-edit).
