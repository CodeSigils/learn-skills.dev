Универсальный инструмент для создания снимков экрана для захвата веб-страниц, настольных приложений и изображений. Поддерживает пресеты области просмотра (мобильный/планшет/настольный компьютер), селекторы CSS, пакетный захват, автоматическую загрузку на хосты изображений и вывод уценки для PR. Используйте, когда пользователь говорит «сделать снимок экрана», «сделать снимок экрана», «сделать снимок страницы», «снимок экрана [приложения/url]», «пакетные снимки экрана», «все области просмотра» или «загрузить снимок экрана».
