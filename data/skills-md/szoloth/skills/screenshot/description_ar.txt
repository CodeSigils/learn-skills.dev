أداة لقطة شاشة عالمية لالتقاط صفحات الويب وتطبيقات سطح المكتب والصور. يدعم الإعدادات المسبقة لإطار العرض (الجوال/الكمبيوتر اللوحي/سطح المكتب)، ومحددات CSS، والتقاط الدُفعات، والتحميل التلقائي إلى مضيفي الصور، وإخراج تخفيض السعر لممثلي العلاقات العامة. يُستخدم عندما يقول المستخدم "التقاط لقطة شاشة"، أو "لقطة شاشة لهذه"، أو "التقاط الصفحة"، أو "لقطة شاشة لـ [التطبيق/عنوان URL]"، أو "لقطات شاشة مجمعة"، أو "جميع إطارات العرض"، أو "تحميل لقطة شاشة".
