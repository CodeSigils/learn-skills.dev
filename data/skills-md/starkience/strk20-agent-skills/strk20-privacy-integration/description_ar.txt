مهارة الطلب والتخطيط والتنفيذ لإضافة خصوصية STRK20 إلى مشروع Starknet. يُستخدم عندما يريد أحد المطورين إضافة الخصوصية إلى تطبيق Starknet المفتوح في هذه الجلسة - التحويلات الخاصة/المحمية، أو الأرصدة السرية، أو المدفوعات الخاصة، أو المقايضة الخاصة أو التمويل اللامركزي، أو إخفاء روابط حساب المستخدم - يذكر STRK20، أو مجمع الخصوصية، أو الحماية، أو عرض المفاتيح، أو واجهة برمجة التطبيقات لمحفظة الخصوصية، أو يريد تنفيذ STRK20_INTEGRATION_PLAN.md موجود. يتفقد اتفاقيات الريبو المفتوحة، ويجري مقابلات مع المطور، ويختار طريق التكامل الصحيح، ويكتب خطة تكامل خاصة بالريبو، وبعد موافقة المطور عليها - ينفذ الخطة مرحلة تلو الأخرى (رمز التطبيق فقط، ولا يتعاقد مع القاهرة أبدًا).
