Спрашивайте, планируйте и применяйте навыки для добавления конфиденциальности STRK20 в проект Starknet. Используйте, когда разработчик хочет добавить конфиденциальность в приложение Starknet, открытое в этом сеансе — частные/защищенные переводы, конфиденциальные балансы, частные платежи, частные обмены или DeFi, скрытие ссылок на учетные записи пользователя — упоминает STRK20, пул конфиденциальности, экранирование, ключи просмотра или API кошелька конфиденциальности или хочет выполнить существующий STRK20_INTEGRATION_PLAN.md. Проверяет открытый репозиторий, проводит собеседование с разработчиком, выбирает правильный маршрут интеграции, пишет план интеграции для конкретного репозитория и — после того, как разработчик его одобряет — выполняет план поэтапно (только код приложения, а не контракт Cairo).
