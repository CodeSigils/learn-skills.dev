Pregunte, planifique y ejecute habilidades para agregar privacidad STRK20 a un proyecto Starknet. Úselo cuando un desarrollador quiera agregar privacidad a la aplicación Starknet abierta en esta sesión (transferencias privadas/protegidas, saldos confidenciales, pagos privados, intercambios privados o DeFi, ocultar enlaces de usuario↔cuenta), menciona STRK20, grupo de privacidad, protección, claves de visualización o la API de Privacy Wallet, o quiere que se ejecute un STRK20_INTEGRATION_PLAN.md existente. Inspecciona el repositorio abierto, entrevista al desarrollador, elige la ruta de integración correcta, escribe un plan de integración específico del repositorio y, una vez que el desarrollador lo aprueba, ejecuta el plan fase por fase (solo código de aplicación, nunca contratos de Cairo).
