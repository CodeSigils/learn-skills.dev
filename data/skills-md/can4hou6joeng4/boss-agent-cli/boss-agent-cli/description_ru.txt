BOSS Zhipin (BOSS直聘) CLI для поиска вакансий для агентов искусственного интеллекта — поиск вакансий с фильтрацией благосостояния (--welfare), персонализированными рекомендациями, просмотром деталей, приветствием рекрутеров, пакетным приветствием и экспортом результатов. Весь вывод структурирован в формате JSON через стандартный вывод. Триггер: 找工作, 投简历, босс直聘, 招聘, 搜索职位, 打招呼, 福利筛选, 双休, поиск работы, подбор персонала, приветствие рекрутера, пакетное приветствие, фильтр благосостояния, БОСС Жипин.
