BOSS Zhipin (BOSS直聘) CLI di ricerca lavoro per agenti AI: cerca lavori con filtro welfare (--welfare), consigli personalizzati, visualizza dettagli, saluta i reclutatori, saluta in batch ed esporta risultati. Tutto l'output è strutturato JSON tramite stdout. Trigger: 找工作, 投简历, boss直聘, 招聘, 搜索职位, 打招呼, 福利筛选, 双休, ricerca di lavoro, reclutamento, saluto reclutatore, batch-greet, filtro welfare, BOSS Zhipin.
