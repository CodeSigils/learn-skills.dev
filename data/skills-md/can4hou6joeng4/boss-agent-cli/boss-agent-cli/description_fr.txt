CLI de recherche d'emploi BOSS Zhipin (BOSS直聘) pour les agents d'IA : recherchez des emplois avec filtrage de l'aide sociale (--welfare), recommandations personnalisées, affichage des détails, saluez les recruteurs, saluez par lots et exportez les résultats. Toutes les sorties sont structurées en JSON via stdout. Déclencheur : 找工作, 投简历, boss直聘, 招聘, 搜索职位, 打招呼, 福利筛选, 双休, recherche d'emploi, recrutement, salutation du recruteur, salutation par lots, filtre social, BOSS Zhipin.
