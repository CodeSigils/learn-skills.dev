Utilice esta habilidad cuando el usuario desee instalar, configurar, descargar o sincronizar currículums en línea para candidatos que solicitaron puestos de trabajo de reclutamiento de BOSS/Zhipin actualmente abiertos. Proporciona una configuración boss-agent-cli multiplataforma, convenciones estándar de CDP/Chrome, raíz de currículum persistente, índices JSON de trabajo/candidato, sincronización incremental completa y por trabajo y retraso aleatorio durante descargas masivas.
