Una CLI de asistencia local para BOSS Direct Recruitment dedicada a agentes de IA. Utilizando la capacidad de autodescripción del esquema jefe, stdout solo genera un sobre JSON; el modo predeterminado de bajo riesgo proporciona solo asistencia local, prioridad de solo lectura y el usuario lo activa activamente. Utilice esta habilidad cuando el usuario necesite ayuda para la búsqueda de empleo, como buscar puestos, filtrar por beneficios, organizar trabajos de candidatos, ver detalles del trabajo, etc.
