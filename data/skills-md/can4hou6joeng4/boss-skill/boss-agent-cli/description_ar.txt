واجهة CLI للمساعدة المحلية لـ BOSS Direct Recruitment مخصصة لوكلاء الذكاء الاصطناعي. باستخدام قدرة الوصف الذاتي للمخطط الرئيسي، يقوم stdout بإخراج مظروف JSON فقط؛ يوفر الوضع الافتراضي منخفض المخاطر مساعدة محلية فقط، وأولوية للقراءة فقط، ويتم تشغيله بشكل فعال بواسطة المستخدم. استخدم هذه المهارة عندما يحتاج المستخدم إلى مساعدة في البحث عن وظيفة مثل البحث عن الوظائف، والتصفية حسب المزايا، وتنظيم وظائف المرشحين، وعرض تفاصيل الوظيفة، وما إلى ذلك.
