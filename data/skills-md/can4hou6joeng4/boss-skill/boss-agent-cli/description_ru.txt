Локальный интерфейс командной строки для BOSS Direct Recruitment, предназначенный для агентов искусственного интеллекта. Используя возможность самоописания схемы босса, стандартный вывод выводит только конверт JSON; режим низкого риска по умолчанию обеспечивает только локальную помощь, приоритет только для чтения и активируется пользователем. Используйте этот навык, когда пользователю нужна помощь в поиске работы, например поиск вакансий, фильтрация по льготам, организация вакансий кандидатов, просмотр сведений о вакансии и т. д.
