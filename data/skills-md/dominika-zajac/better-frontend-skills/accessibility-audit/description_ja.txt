Chrome DevTools MCP を使用して、包括的な WCAG 指向の Web アクセシビリティ監査を実行します (Lighthouse デスクトップとモバイル、カスタム Evaluate_script ヒューリスティック、キーボード フォーカスとモーダル、A11y スナップショットと DOM のパリティ、320 ピクセルのリフロー、タッチ ターゲット、構造化マークダウン レポート)。 Web サイトのアクセシビリティ、WCAG、a11y、インクルーシブ デザイン、Lighthouse または ax の結果、スクリーン リーダーの同等性、フォーカスの可視性、または Chrome DevTools MCP 監査ワークフローを監査するときに使用します。
