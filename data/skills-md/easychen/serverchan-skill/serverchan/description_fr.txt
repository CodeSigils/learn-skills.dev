Notifications de messages push vers WeChat/App via Server Chan (Sugar). Utilisez cette compétence lorsque vous devez transmettre les résultats d'exécution, les alertes, l'état d'achèvement des tâches, etc. sur votre téléphone (Server Chan Turbo SCT et Server Chan³ SC3 sont tous deux pris en charge, automatiquement reconnus par le préfixe SendKey). Prend en charge le titre, le corps Markdown et les paramètres facultatifs tels que tags/short/channel.
