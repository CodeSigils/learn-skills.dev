Notifiche dei messaggi push a WeChat/App tramite Server Chan (Fangtang). Utilizza questa Skill quando devi inviare risultati di esecuzione, avvisi, stato di completamento delle attività, ecc. al tuo telefono (sono supportati sia Server Chan Turbo SCT che Server Chan³ SC3, riconosciuti automaticamente dal prefisso SendKey). Supporta titoli, corpo Markdown e parametri opzionali come tag, short e canale.
