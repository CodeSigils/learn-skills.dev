أرسل إشعارات الرسائل إلى WeChat/App عبر Server Chan (Fangtang). استخدم هذه المهارة عندما تحتاج إلى إرسال نتائج التنفيذ والتنبيهات وحالة إكمال المهمة وما إلى ذلك إلى هاتفك (يتم دعم كل من Server Chan Turbo SCT وServer Chan³ SC3، ويتم التعرف عليهما تلقائيًا بواسطة بادئة SendKey). وهو يدعم العنوان ونص Markdown والمعلمات الاختيارية مثل العلامات والقصيرة والقناة.
