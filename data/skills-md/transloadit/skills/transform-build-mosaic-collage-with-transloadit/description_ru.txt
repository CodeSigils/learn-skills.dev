Одноразовый мозаичный фотоколлаж (N локальных изображений -> одно изображение) с использованием официального интерфейса командной строки `@transloadit/node`. Использует эффект мозаики робота `/image/merge` для создания мозаичного макета, в котором каждая фотография остается полностью видимой, и загружает результат в явный путь вывода через `--output`.
