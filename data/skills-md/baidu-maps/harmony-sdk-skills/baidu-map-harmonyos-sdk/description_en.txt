Help develop using the Baidu Maps HarmonyOS SDK on HarmonyOS NEXT. Supports standalone packages (@bdmap/base, @bdmap/map, @bdmap/search, @bdmap/util) and combined packages (@bdmap/map_walkride_search, @bdmap/navi_map), as well as the location SDK (@bdmap/locsdk). Covers scenarios such as map display and interaction, overlay rendering, POI/AOI search, route planning, navigation, foreground/background location, and address/POI retrieval. Suitable for requirements involving HarmonyOS maps, Baidu Maps HarmonyNEXT SDK, map display, searching, route planning, navigation, and location capabilities.
