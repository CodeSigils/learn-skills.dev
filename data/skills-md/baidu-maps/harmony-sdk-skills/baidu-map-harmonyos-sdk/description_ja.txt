HarmonyOS NEXT で Baidu Maps HarmonyOS SDK を使用して開発を支援します。スタンドアロン パッケージ (@bdmap/base、@bdmap/map、@bdmap/search、@bdmap/util) と複合パッケージ (@bdmap/map_walkride_search、@bdmap/navi_map)、およびロケーション SDK (@bdmap/locsdk) をサポートします。地図の表示とインタラクション、オーバーレイ レンダリング、POI/AOI 検索、ルート計画、ナビゲーション、前景/背景の位置、住所/POI の検索などのシナリオをカバーします。 HarmonyOS マップ、Baidu Maps HarmonyNEXT SDK、地図表示、検索、ルート計画、ナビゲーション、位置情報機能などの要件に適しています。
