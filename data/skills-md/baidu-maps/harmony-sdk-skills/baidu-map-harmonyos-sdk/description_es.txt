Ayude a desarrollar utilizando el SDK de Baidu Maps HarmonyOS en HarmonyOS NEXT. Admite paquetes independientes (@bdmap/base, @bdmap/map, @bdmap/search, @bdmap/util) y paquetes combinados (@bdmap/map_walkride_search, @bdmap/navi_map), así como el SDK de ubicación (@bdmap/locsdk). Cubre escenarios como visualización e interacción de mapas, representación superpuesta, búsqueda de PDI/AOI, planificación de rutas, navegación, ubicación en primer plano/fondo y recuperación de direcciones/PDI. Adecuado para requisitos relacionados con mapas de HarmonyOS, Baidu Maps HarmonyNEXT SDK, visualización de mapas, búsqueda, planificación de rutas, navegación y capacidades de ubicación.
