Помогите разработать приложение с помощью Baidu Maps HarmonyOS SDK для HarmonyOS NEXT. Поддерживает отдельные пакеты (@bdmap/base, @bdmap/map, @bdmap/search, @bdmap/util) и комбинированные пакеты (@bdmap/map_walkride_search, @bdmap/navi_map), а также SDK местоположения (@bdmap/locsdk). Охватывает такие сценарии, как отображение и взаимодействие карты, рендеринг наложения, поиск POI/AOI, планирование маршрута, навигация, расположение на переднем/фоновом плане и получение адреса/POI. Подходит для требований, связанных с картами HarmonyOS, Baidu Maps HarmonyNEXT SDK, отображением карт, поиском, планированием маршрутов, навигацией и возможностями определения местоположения.
