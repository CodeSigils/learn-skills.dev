Mit dem Baidu Maps Agent Plan können Sie auf die nativen Funktionen von Baidu Maps für Agentenszenarien zugreifen, ohne Baidu Maps-Entwickler zu werden. Integrieren Sie sofort einsatzbereite Tools wie KI-Ortssuche, KI-Routenplanung, Geokodierung und umgekehrte Geokodierung, Wetterabfragen und andere Kartenfunktionen.
