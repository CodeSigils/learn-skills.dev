Рекомендации по интеграции и разработке Baidu Maps Android SDK. Охватывает отображение карты, жизненный цикл MapView/BaiduMap, местоположение, маркеры и наложения, поиск POI, планирование маршрута, пешеходную и велосипедную навигацию; выводит картографическое решение Android, соответствующее требованиям конфиденциальности и конфигурации AK. Используется при разработке картографических приложений для Android, интеграции Baidu Maps SDK, MapView, планирования маршрута, POI и навигации.
