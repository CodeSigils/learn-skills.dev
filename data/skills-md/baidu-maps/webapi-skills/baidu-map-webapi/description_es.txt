Guía de desarrollo de WebAPI de Baidu Maps. Utilice esta habilidad cuando escriba, revise o depure código que utilice Baidu Maps WebAPI y también cuando llame directamente a Baidu Maps API para obtener resultados. Cubre: búsqueda de ubicación en mapas, recuperación de puntos de interés, planificación de rutas, horas de salida sugeridas, predicción de duración de rutas, condiciones de tráfico en tiempo real, consultas de áreas administrativas, conversión de dirección a coordenadas, incidentes de tráfico en el camino, consultas meteorológicas, recomendaciones inteligentes de puntos de recogida, etc. Se activa automáticamente cuando los usuarios mencionan horas de salida, rutas de navegación, consultas de ubicación, conversión de coordenadas o necesidades de desarrollo relacionadas con mapas.
