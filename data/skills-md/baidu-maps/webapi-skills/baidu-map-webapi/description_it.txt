Guida allo sviluppo dell'API Web di Baidu Maps. Utilizza questa competenza durante la scrittura, la revisione o il debug del codice che utilizza l'API Web di Baidu Maps e anche quando si chiama direttamente l'API di Baidu Maps per ottenere risultati. Copre: ricerca della posizione sulla mappa, recupero dei POI, pianificazione del percorso, orari di partenza suggeriti, previsione della durata del percorso, condizioni del traffico in tempo reale, query sull'area amministrativa, conversione da indirizzo a coordinato, incidenti di traffico lungo il percorso, domande meteorologiche, raccomandazioni intelligenti sui punti di raccolta, ecc. Si attiva automaticamente quando gli utenti menzionano orari di partenza, percorsi di navigazione, query di posizione, conversione di coordinate o esigenze di sviluppo relative alla mappa.
