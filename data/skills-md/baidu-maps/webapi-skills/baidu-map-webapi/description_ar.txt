دليل تطوير WebAPI لخرائط Baidu. استخدم هذه المهارة عند كتابة أو مراجعة أو تصحيح التعليمات البرمجية التي تستخدم Baidu Maps WebAPI، وكذلك عند الاتصال مباشرة بـ Baidu Maps API للحصول على النتائج. يغطي: البحث عن موقع الخريطة، واسترجاع النقاط المهمة، وتخطيط المسار، وأوقات المغادرة المقترحة، والتنبؤ بمدة المسار، وظروف حركة المرور في الوقت الفعلي، واستعلامات المنطقة الإدارية، وتحويل العنوان إلى الإحداثيات، وحوادث المرور على طول الطريق، واستعلامات الطقس، وتوصيات نقطة الالتقاط الذكية، وما إلى ذلك. يتم تشغيله تلقائيًا عندما يذكر المستخدمون أوقات المغادرة، أو مسارات التنقل، أو استعلامات الموقع، أو تحويل الإحداثيات، أو احتياجات التطوير المتعلقة بالخريطة.
