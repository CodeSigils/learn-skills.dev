Baidu Maps WebAPI 開発ガイド。このスキルは、Baidu Maps WebAPI を使用するコードを作成、レビュー、またはデバッグする場合、および Baidu Maps API を直接呼び出して結果を取得するシナリオで使用します。対象範囲: 地図上の位置検索、POI 検索、ルート計画、推奨出発時刻、ルート所要時間予測、リアルタイムの交通状況、行政区画クエリ、住所座標変換、途中の交通事故、天気クエリ、インテリジェントな推奨ピックアップ ポイントなど。ユーザーが出発時刻、ナビゲーション ルート、位置クエリ、座標変換、または地図関連の開発ニーズに言及すると、自動的にトリガーされます。
