اكتب نثرًا باللغة التايلاندية (التوثيق الفني، والنسخة التسويقية، والشرح، ومنشورات المدونات، والترجمات) بحيث يُقرأ مثل كاتب تايلاندي حقيقي - وليس مخرجات الذكاء الاصطناعي العامة. تتجه بيانات تدريب العدادات نحو اللغة التايلاندية الرسمية المفرطة، والمفرطة في التهذيب، واللغة التايلاندية. يتم تشغيله عندما: يطلب المستخدم أي مخرجات نثرية تايلاندية غير تافهة (فقرة أو أطول - منشور مدونة، صفحة مقصودة، صفحة مستند، ملف README باللغة التايلاندية، بريد إلكتروني، إعلان، قسم)؛ يطلب المستخدم ترجمة اللغة الإنجليزية إلى التايلاندية؛ يطلب المستخدم تحرير أو إعادة كتابة أو مراجعة النثر التايلاندي الموجود؛ المحادثة باللغة التايلاندية ويطلب المستخدم تسليمًا نثريًا. لا تقم بتشغيل ما يلي: الترجمات المكونة من كلمة واحدة أو عبارة واحدة، أو تسميات الأزرار، أو معرفات الأكواد، أو سلاسل واجهة المستخدم القصيرة، أو تعليقات التعليمات البرمجية، أو ردود الدردشة التحادثية باللغة التايلاندية التي لا يمكن تسليمها نثرًا.
