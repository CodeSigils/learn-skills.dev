일반 AI 출력이 아닌 실제 태국 작가처럼 읽는 태국어 산문(기술 문서, 마케팅 카피, 설명자, 블로그 게시물, 번역)을 작성하세요. 훈련 데이터가 지나치게 격식을 차리고, 지나치게 공손하고, 차분한 태국어로 치우쳐 있는 것에 대응합니다. TRIGGER 언제: 사용자가 중요하지 않은 태국어 산문 출력(단락 이상 - 블로그 게시물, 랜딩 페이지, 문서 페이지, 태국어로 된 README, 이메일, 공지 사항, 섹션)을 요청합니다. 사용자가 영어를 태국어로 번역해 달라고 요청합니다. 사용자가 기존 태국어 산문을 편집, 재작성 또는 검토하도록 요청합니다. 대화가 태국어로 되어 있고 사용자가 산문 전달을 요청합니다. 다음의 경우에는 트리거하지 마세요: 전달 가능한 산문이 아닌 단일 단어 또는 단일 구문 번역, 버튼 라벨, 코드 식별자, 짧은 UI 문자열, 코드 주석 또는 태국어로 된 대화형 채팅 응답.
