Gravity UI デザイン システム (@gravity-ui/* パッケージの React エコシステム (uikit、チャート、テーブル、ナビゲーション、日付コンポーネント、アイコンなど)) を使用して UI を構築、修正、スタイル設定、構成します。類似したパッケージが存在する場合は正しいパッケージにルーティングし、テーマと必要な設定を適用し、コンポーネント API の発明を防ぎます。 @gravity-ui インポート、uikit、ThemeProvider、--g- CSS トークン、または、gravity-ui、гравити、дизайн-система、компоненты、далиборд、таблица、график、またはформа。
