Crea, corrige, diseña y compone la interfaz de usuario con el sistema de diseño Gravity UI: el ecosistema React de paquetes @gravity-ui/* (uikit, gráficos, tablas, navegación, componentes de fecha, íconos y más). Dirige al paquete correcto cuando existen elementos similares, aplica la temática y la configuración requerida y evita API de componentes inventados. Se aplica cuando se trabaja con @gravity-ui imports, uikit, ThemeProvider, --g- tokens CSS o cualquier mensaje (EN o RU) que mencione Gravity-ui, гравити, дизайн-система, компоненты, дашборд, таблица, график o форма.
