ينشئ واجهة المستخدم ويصلحها ويصممها وينشئها باستخدام نظام تصميم Gravity UI — نظام React البيئي لحزم @gravity-ui/* (uikit، والمخططات، والجدول، والتنقل، ومكونات التاريخ، والأيقونات، والمزيد). التوجيه إلى الحزمة الصحيحة عند وجود أشكال متشابهة، وتطبيق السمات والإعداد المطلوب، ومنع واجهات برمجة تطبيقات المكونات المخترعة. ينطبق عند العمل مع واردات @gravity-ui، أو uikit، أو ThemeProvider، أو رموز --g- CSS، أو أي مطالبة (EN أو RU) تشير إلى Gravity-ui، أو الجاذبية، أو التصميم، أو المكونات، أو لوحة البيانات، أو اللوحة، أو الرسم، أو النموذج.
