Costruisce, corregge, applica stili e compone l'interfaccia utente con il sistema di progettazione Gravity UI: l'ecosistema React di pacchetti @gravity-ui/* (uikit, grafici, tabelle, navigazione, componenti data, icone e altro). Indirizza al pacchetto corretto quando esistono dei sosia, applica i temi e la configurazione richiesta e impedisce le API dei componenti inventati. Si applica quando si lavora con importazioni @gravity-ui, uikit, ThemeProvider, token --g- CSS o qualsiasi prompt (EN o RU) che menzioni Gravity-ui, гравити, дизайн-система, компоненты, дашборд, таблица, график o forma.
