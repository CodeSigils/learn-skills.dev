Construit, corrige, stylise et compose l'interface utilisateur avec le système de conception Gravity UI - l'écosystème React de packages @gravity-ui/* (uikit, graphiques, tableau, navigation, composants de date, icônes, etc.). Achemine vers le package approprié lorsque des sosies existent, applique le thème et la configuration requise, et empêche les API de composants inventées. S'applique lorsque vous travaillez avec des importations @gravity-ui, uikit, ThemeProvider, des jetons --g- CSS ou toute invite (EN ou RU) mentionnant gravité-ui, gravité, système-système, composants, tableau de bord, tableau, graphique ou formulaire.
