المهارة الرسمية لـ twitterapi.io - الاستعلام عن بيانات Twitter/X (التغريدات والملفات الشخصية والمتابعين والبحث المتقدم والاتجاهات والمساحات والمجتمعات والقوائم) وتنفيذ إجراءات موثقة (النشر والرد والإعجاب وإعادة التغريد والمتابعة والرسالة المباشرة) عبر twitterapi.io REST API باستخدام رأس `x-api-key` واحد - بدون OAuth. يُستخدم عندما يحتاج المستخدم إلى استخراج X/Twitter أو تحليله أو مراقبته أو تشغيله تلقائيًا دون المرور عبر بوابة المطور الرسمية.
