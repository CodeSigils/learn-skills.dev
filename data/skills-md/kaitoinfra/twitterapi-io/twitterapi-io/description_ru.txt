Официальный навык для twitterapi.io — запрос данных Twitter/X (твиты, профили, подписчики, расширенный поиск, тенденции, пространства, сообщества, списки) и выполнение аутентифицированных действий (публикация, ответ, лайк, ретвит, подписка, DM) через REST API twitterapi.io с использованием одного заголовка `x-api-key` — без OAuth. Используйте, когда пользователю необходимо очистить, проанализировать, отслеживать или автоматизировать X/Twitter, не проходя через официальный портал разработчиков.
