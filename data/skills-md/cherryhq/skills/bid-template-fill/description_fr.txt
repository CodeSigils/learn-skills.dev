Moteur de remplissage de modèles de documents d'appel d'offres. Utilisé lorsque l'utilisateur demande explicitement « remplir le modèle », « rédiger une offre », « produire une offre », « générer des documents d'appel d'offres », « remplir les offres », « appliquer un modèle », « créer une offre » ou fournit un modèle DOCX anonymisé qui doit être rempli. Il analyse les espaces réservés et le texte factice dans le modèle, extrait les informations sur l'appel d'offres, rassemble les données des soumissionnaires, crée une carte de remplacement, effectue le remplissage et génère une offre terminée, prête à être soumise directement. Il couvre toutes les sections de l’offre commerciale, de l’offre technique et de la proposition tarifaire.
