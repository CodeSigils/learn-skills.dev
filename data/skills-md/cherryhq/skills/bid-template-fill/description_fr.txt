Moteur de remplissage de modèles de documents d'appel d'offres. Utilisé lorsque l'utilisateur demande explicitement « remplir le modèle », « rédiger une offre », « produire une offre », « générer un document d'appel d'offres », « remplir un document d'appel d'offres », « appliquer un modèle » ou « faire une offre » ou fournit un modèle DOCX anonymisé qui doit être rempli. Il analyse les espaces réservés et le texte factice dans le modèle, extrait les informations sur l'appel d'offres, rassemble les données des soumissionnaires, crée un mappage de remplacement, effectue le remplissage et génère un document d'appel d'offres terminé, prêt à être soumis. Il couvre toutes les sections de la proposition commerciale, de la proposition technique et du devis.
