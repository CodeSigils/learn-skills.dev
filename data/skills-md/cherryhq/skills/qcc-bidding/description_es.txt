Due diligence integral para licitaciones corporativas. Se utiliza cuando un usuario solicita explícitamente "diligencia debida sobre la empresa XX", "búsqueda de ofertas", "evaluación de proveedores", "búsqueda de oportunidades de oferta", "verificación del cumplimiento de la oferta" o "búsqueda de competidores". Node.js se conecta directamente a la API Qichacha, cubriendo seis dimensiones principales (registro empresarial, riesgo judicial, conocimientos empresariales, propiedad intelectual, directores/supervisores/ejecutivos y archivos históricos) y proporciona 70 herramientas principales para realizar ofertas.
