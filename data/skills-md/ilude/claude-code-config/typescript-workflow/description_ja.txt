Bun パッケージ マネージャーを使用した TypeScript/JavaScript プロジェクトのワークフロー ガイドライン。 `.ts`、`.tsx`、`bun`、`package.json`、TypeScript でトリガーされます。 bun run、bun install、bun add、tsconfig.json パターン、ESM/CommonJS モジュール、タイプ セーフティ、Biome フォーマット、命名規則 (PascalCase、camelCase、UPPER_SNAKE_CASE)、プロジェクト構造、エラー処理、環境変数、非同期パターン、コード品質ツールについて説明します。 TypeScript ファイル (.ts、.tsx)、JavaScript ファイル (.js、.jsx)、Bun プロジェクト、tsconfig.json、package.json、bun.lock、または Bun 固有のツールを操作する場合にアクティブ化します。
