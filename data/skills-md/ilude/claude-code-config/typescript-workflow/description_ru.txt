Рекомендации по рабочему процессу проекта TypeScript/JavaScript с использованием диспетчера пакетов Bun. Запускается по `.ts`, `.tsx`, `bun`, `package.json`, TypeScript. Охватывает запуск, установку и добавление пакетов, шаблоны tsconfig.json, модули ESM/CommonJS, безопасность типов, форматирование Biome, соглашения об именах (PascalCase, CamelCase, UPPER_SNAKE_CASE), структуру проекта, обработку ошибок, переменные среды, асинхронные шаблоны и инструменты контроля качества кода. Активируйте при работе с файлами TypeScript (.ts, .tsx), файлами JavaScript (.js, .jsx), проектами Bun, tsconfig.json, package.json, Bun.lock или инструментами, специфичными для Bun.
