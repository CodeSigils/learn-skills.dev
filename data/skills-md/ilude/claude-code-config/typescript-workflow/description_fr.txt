Directives de flux de travail du projet TypeScript/JavaScript à l'aide du gestionnaire de packages Bun. Déclencheurs sur `.ts`, `.tsx`, `bun`, `package.json`, TypeScript. Couvre l'exécution de bun, l'installation de bun, l'ajout de chignon, les modèles tsconfig.json, les modules ESM/CommonJS, la sécurité des types, le formatage du biome, les conventions de dénomination (PascalCase, camelCase, UPPER_SNAKE_CASE), la structure du projet, la gestion des erreurs, les variables d'environnement, les modèles asynchrones et les outils de qualité de code. Activez-le lorsque vous travaillez avec des fichiers TypeScript (.ts, .tsx), des fichiers JavaScript (.js, .jsx), des projets Bun, tsconfig.json, package.json, bun.lock ou des outils spécifiques à Bun.
