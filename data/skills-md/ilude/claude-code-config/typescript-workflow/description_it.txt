Linee guida per il flusso di lavoro del progetto TypeScript/JavaScript utilizzando il gestore pacchetti Bun. Trigger su `.ts`, `.tsx`, `bun`, `package.json`, TypeScript. Copre l'esecuzione di bun, l'installazione di bun, l'aggiunta di bun, i modelli tsconfig.json, i moduli ESM/CommonJS, la sicurezza dei tipi, la formattazione del bioma, le convenzioni di denominazione (PascalCase, camelCase, UPPER_SNAKE_CASE), la struttura del progetto, la gestione degli errori, le variabili di ambiente, i modelli asincroni e gli strumenti di qualità del codice. Attivalo quando lavori con file TypeScript (.ts, .tsx), file JavaScript (.js, .jsx), progetti Bun, tsconfig.json, package.json, bun.lock o strumenti specifici di Bun.
