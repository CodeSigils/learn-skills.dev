أجب عن أسئلة SolidJS 2.0 API والسلوك التجريبي، واكتب أو حرر كود SolidJS 2.0 (solid-js 2.x / next / beta). يُستخدم للأسئلة أو التنفيذ الذي يتضمن المكونات، والإشارات/التأثيرات/التجميع، والبيانات/المولدات/الإجراءات غير المتزامنة والتحميل، وواجهات برمجة التطبيقات التجريبية التي تمت إزالتها، والمخازن وطرق عرض المتجر المتداخلة، وSSR/الترطيب البطيء، ووظائف الخادم ("استخدام الخادم")، أو رمز DOM لـ Solid-js 2.x أو @solidjs/web. ليس لمشاريع Solid 1.x وليس لترحيل كود 1.x (راجع Solidjs-v2-migration).
