Répondez aux questions sur l'API SolidJS 2.0 et le comportement bêta, et écrivez ou modifiez le code SolidJS 2.0 (solid-js 2.x / next / beta). À utiliser pour les questions ou l'implémentation impliquant des composants, des signaux/effets/traitement par lots, des données/générateurs/actions asynchrones et le chargement, des API bêta supprimées, des magasins et des vues de magasin imbriquées, un SSR/hydratation paresseux, des fonctions de serveur ("utiliser le serveur") ou du code DOM pour solid-js 2.x ou @solidjs/web. Pas pour les projets Solid 1.x et pas pour la migration du code 1.x (voir solidjs-v2-migration).
