SolidJS 2.0 API およびベータ動作の質問に答え、SolidJS 2.0 コード (solid-js 2.x / next / beta) を作成または編集します。コンポーネント、シグナル/エフェクト/バッチ処理、非同期データ/ジェネレーター/アクションとロード、削除されたベータ API、ストアとネストされたストア ビュー、遅延 SSR/ハイドレーション、サーバー関数 (「サーバーの使用」)、または Solid-js 2.x または @solidjs/web の DOM コードに関連する質問または実装に使用します。 Solid 1.x プロジェクトや 1.x コードの移行には使用できません (solidjs-v2-migration を参照)。
