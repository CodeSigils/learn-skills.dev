Rispondi alle domande sull'API SolidJS 2.0 e sul comportamento beta e scrivi o modifica il codice SolidJS 2.0 (solid-js 2.x / next / beta). Utilizzare per domande o implementazioni che coinvolgono componenti, segnali/effetti/batch, dati/generatori/azioni asincroni e caricamento, API beta rimosse, negozi e visualizzazioni di negozi nidificati, SSR/idratazione pigra, funzioni server ("usa server") o codice DOM per solid-js 2.x o @solidjs/web. Non per progetti Solid 1.x e non per la migrazione del codice 1.x (vedi solidjs-v2-migration).
