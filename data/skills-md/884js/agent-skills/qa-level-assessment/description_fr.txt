Compétence qui détermine le niveau du test QA. Il évalue les risques de manière globale en combinant des descriptions d'histoires, des différences de code et un format de dialogue, et propose un niveau d'assurance qualité approprié.

Utilisé dans les situations suivantes :
- Lorsque vous souhaitez déterminer le niveau d'assurance qualité d'un PR
- Lorsque vous souhaitez juger de la nécessité d'un exécuteur de test ou d'une double vérification
- Lorsque vous souhaitez définir le niveau de révision des perspectives de test

Peut également être invoqué avec des termes tels que « détermination de l'assurance qualité », « niveau de test » ou « évaluation des risques ».
