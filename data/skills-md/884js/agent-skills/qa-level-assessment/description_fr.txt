Une compétence qui détermine le niveau du test QA. Il combine le texte de description de l'histoire, les différences de code et le format de dialogue pour évaluer de manière exhaustive les risques et proposer un niveau d'assurance qualité approprié.  
Utilisé dans les situations suivantes :  
- Lorsque vous souhaitez déterminer le niveau d'assurance qualité d'un PR  
- Lorsque vous souhaitez évaluer la nécessité d'un exécuteur de test ou d'une double vérification  
- Lorsque vous souhaitez définir le niveau de révision du point de vue test  
Il peut également être invoqué avec des termes tels que « détermination de l'assurance qualité », « niveau de test », « évaluation des risques ».
