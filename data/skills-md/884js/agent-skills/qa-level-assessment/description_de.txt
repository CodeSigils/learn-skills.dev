Fähigkeit, die das QA-Testniveau bestimmt. Es bewertet das Risiko umfassend, indem es Story-Beschreibungen, Code-Unterschiede und ein Dialogformat kombiniert, und schlägt eine geeignete Qualitätssicherungsstufe vor.

Wird in folgenden Situationen verwendet:
- Wenn Sie das QA-Niveau einer PR bestimmen möchten
- Wenn Sie die Notwendigkeit eines Testausführenden beurteilen oder noch einmal überprüfen möchten
- Wenn Sie den Grad der Überprüfung der Testperspektive festlegen möchten

Kann auch mit Begriffen wie „QA-Bestimmung“, „Teststufe“ oder „Risikobewertung“ aufgerufen werden.
