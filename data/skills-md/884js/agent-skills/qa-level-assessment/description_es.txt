Una habilidad que determina el nivel de la prueba de control de calidad. Combina texto de descripción de la historia, diferencias de código y formato de diálogo para evaluar de manera integral el riesgo y proponer un nivel de control de calidad apropiado.  
Utilizado en las siguientes situaciones:  
- Cuando desea determinar el nivel de control de calidad de un PR  
- Cuando desee evaluar la necesidad de un ejecutor de pruebas o una doble verificación  
- Cuando desee establecer el nivel de revisión del punto de vista de prueba  
También se puede invocar con términos como “determinación de calidad”, “nivel de prueba”, “evaluación de riesgos”.
