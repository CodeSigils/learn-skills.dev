Habilidad que determina el nivel de la prueba de control de calidad. Evalúa el riesgo de manera integral combinando descripciones de historias, diferencias de código y un formato de diálogo, y propone un nivel de control de calidad apropiado.

Utilizado en las siguientes situaciones:
- Cuando desea determinar el nivel de control de calidad de un PR
- Cuando desee juzgar la necesidad de un ejecutor de pruebas o una doble verificación
- Cuando desee establecer el nivel de revisión de la perspectiva de la prueba

También se puede invocar con términos como “determinación de control de calidad”, “nivel de prueba” o “evaluación de riesgos”.
