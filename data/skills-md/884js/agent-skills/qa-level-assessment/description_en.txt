A skill that determines the QA test level. It combines story description text, code diffs, and dialogue format to comprehensively evaluate risk and propose an appropriate QA level.  
Used in the following situations:  
- When you want to determine the QA level of a PR  
- When you want to assess the necessity of a test executor or double‑check  
- When you want to set the level of test‑viewpoint review  
It can also be invoked with terms such as “QA determination,” “test level,” “risk assessment.”
