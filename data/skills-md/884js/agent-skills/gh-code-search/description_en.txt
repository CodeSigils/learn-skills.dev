A skill to search for code from GitHub repositories and retrieve relevant implementations.
Used when code context from another repository is needed.
Use in the following scenarios:
- When you want to check the implementation of an API endpoint
- When you want to find request/response type definitions
- When you want to search for related backend code
- When you want to check the implementation of frontend components
- When you want to search for test code
Can also be invoked with phrases like "backend search," "frontend search," "API implementation check," "code search," or "gh search."
