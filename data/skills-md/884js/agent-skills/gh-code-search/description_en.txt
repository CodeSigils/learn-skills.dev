Skill to search code in a GitHub repository and retrieve the implementation of relevant code. Used when the code context from another repository is needed. Used in the following situations:
- When you want to check the implementation of an API endpoint
- When you want to find type definitions for request/response
- When you want to search for related backend code
- When you want to verify the implementation of a frontend component
- When you want to search for test code
It can also be invoked with terms such as “backend search,” “frontend search,” “API implementation check,” “code search,” “gh search,” etc.
