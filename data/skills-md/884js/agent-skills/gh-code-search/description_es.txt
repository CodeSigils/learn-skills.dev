Una habilidad para buscar código de un repositorio de GitHub y recuperar la implementación del código relacionado. Se utiliza cuando necesita contexto de código de otro repositorio. Aplicado en las siguientes situaciones:
- Cuando desee comprobar la implementación de un punto final API
- Cuando desee buscar definiciones de tipos para solicitudes/respuestas
- Cuando desee buscar código de backend relacionado
- Cuando deseas verificar la implementación de un componente frontend.
- Cuando quieras buscar el código de prueba.
También se puede invocar con términos como "búsqueda backend", "búsqueda frontend", "verificación de implementación de API", "búsqueda de código", "búsqueda gh", etc.
