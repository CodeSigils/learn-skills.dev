Una habilidad para buscar código de un repositorio de GitHub y recuperar implementaciones relevantes.
Se utiliza cuando se requiere contexto de código de otro repositorio.
Úselo en los siguientes escenarios:
- Cuando desee comprobar la implementación de un punto final API
- Cuando necesita encontrar definiciones de tipo de solicitud/respuesta
- Cuando desee buscar código de backend relacionado
- Cuando quieras comprobar la implementación de un componente frontend.
- Cuando quieras buscar el código de prueba.
También se puede invocar con frases como "búsqueda backend", "búsqueda frontend", "verificación de implementación de API", "búsqueda de código", "búsqueda gh".
