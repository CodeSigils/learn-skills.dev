Una habilidad para buscar código en repositorios de GitHub y recuperar implementaciones de código relevante.  
Se utiliza cuando se requiere contexto de código de otro repositorio.  
Úselo en las siguientes situaciones:  
- Cuando desee comprobar la implementación de un punto final API  
- Cuando desee encontrar definiciones de tipos de solicitud/respuesta  
- Cuando desee buscar código de backend relacionado  
- Cuando quieras comprobar la implementación de un componente frontend.  
- Cuando quieras buscar el código de prueba.  
También se puede invocar con frases como "búsqueda de backend", "búsqueda de frontend", "verificación de implementación de API", "búsqueda de código" o "búsqueda de gh".
