Una capacità di cercare codice dai repository GitHub e recuperare implementazioni rilevanti.  
Utilizzato quando è necessario il contesto del codice da un altro repository.  
Utilizzare nelle seguenti situazioni:  
- Quando vuoi verificare l'implementazione di un endpoint API  
- Quando si desidera trovare le definizioni del tipo di richiesta/risposta  
- Quando desideri cercare il codice backend correlato  
- Quando vuoi verificare l'implementazione di un componente frontend  
- Quando si desidera cercare il codice di prova  

Può anche essere richiamato con frasi come "ricerca backend", "ricerca frontend", "controllo implementazione API", "ricerca codice" o "ricerca gh".
