Una capacità di cercare codice da un repository GitHub e recuperare l'implementazione del codice correlato. Utilizzato quando è necessario il contesto del codice da un altro repository. Applicato nelle seguenti situazioni:
- Quando vuoi verificare l'implementazione di un endpoint API
- Quando si desidera trovare definizioni di tipo per richieste/risposte
- Quando desideri cercare il codice backend correlato
- Quando vuoi verificare l'implementazione di un componente frontend
- Quando si desidera cercare il codice di prova
Può anche essere invocato con termini come “ricerca backend”, “ricerca frontend”, “controllo implementazione API”, “ricerca codice”, “ricerca gh”, ecc.
