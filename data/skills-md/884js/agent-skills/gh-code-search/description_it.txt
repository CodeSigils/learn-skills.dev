Capacità di cercare codice in un repository GitHub e recuperare l'implementazione del codice pertinente. Utilizzato quando è necessario il contesto del codice da un altro repository. Utilizzato nelle seguenti situazioni:
- Quando vuoi verificare l'implementazione di un endpoint API
- Quando si desidera trovare definizioni di tipo per richiesta/risposta
- Quando desideri cercare il codice backend correlato
- Quando vuoi verificare l'implementazione di un componente frontend
- Quando si desidera cercare il codice di prova
Può anche essere richiamato con termini come “ricerca backend”, “ricerca frontend”, “controllo implementazione API”, “ricerca codice”, “ricerca gh”, ecc.
