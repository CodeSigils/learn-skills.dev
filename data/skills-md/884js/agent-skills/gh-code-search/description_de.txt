Eine Fähigkeit, nach Code aus GitHub-Repositorys zu suchen und relevante Implementierungen abzurufen.
Wird verwendet, wenn Codekontext aus einem anderen Repository benötigt wird.
Verwendung in den folgenden Szenarien:
– Wenn Sie die Implementierung eines API-Endpunkts überprüfen möchten
- Wenn Sie Anforderungs-/Antworttypdefinitionen finden möchten
- Wenn Sie nach zugehörigem Backend-Code suchen möchten
- Wenn Sie die Implementierung von Frontend-Komponenten überprüfen möchten
- Wenn Sie nach Testcode suchen möchten
Kann auch mit Phrasen wie „Backend-Suche“, „Frontend-Suche“, „API-Implementierungsprüfung“, „Code-Suche“ oder „GH-Suche“ aufgerufen werden.
