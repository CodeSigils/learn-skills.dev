Fähigkeit, Code in einem GitHub-Repository zu durchsuchen und die Implementierung des relevanten Codes abzurufen. Wird verwendet, wenn der Codekontext aus einem anderen Repository benötigt wird. Wird in folgenden Situationen verwendet:
– Wenn Sie die Implementierung eines API-Endpunkts überprüfen möchten
– Wenn Sie Typdefinitionen für Anfrage/Antwort finden möchten
- Wenn Sie nach zugehörigem Backend-Code suchen möchten
– Wenn Sie die Implementierung einer Frontend-Komponente überprüfen möchten
- Wenn Sie nach Testcode suchen möchten
Es kann auch mit Begriffen wie „Backend-Suche“, „Frontend-Suche“, „API-Implementierungsprüfung“, „Codesuche“, „GH-Suche“ usw. aufgerufen werden.
