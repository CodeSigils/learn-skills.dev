Eine Fähigkeit, Code aus einem GitHub-Repository zu durchsuchen und die Implementierung des zugehörigen Codes abzurufen. Wird verwendet, wenn Sie Codekontext aus einem anderen Repository benötigen. Wird in folgenden Situationen angewendet:
– Wenn Sie die Implementierung eines API-Endpunkts überprüfen möchten
- Wenn Sie Typdefinitionen für Anfragen/Antworten finden möchten
- Wenn Sie nach zugehörigem Backend-Code suchen möchten
– Wenn Sie die Implementierung einer Frontend-Komponente überprüfen möchten
- Wenn Sie nach Testcode suchen möchten
Es kann auch mit Begriffen wie „Backend-Suche“, „Frontend-Suche“, „API-Implementierungsprüfung“, „Code-Suche“, „GH-Suche“ usw. aufgerufen werden.
