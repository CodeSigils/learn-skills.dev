Навыки поиска кода в репозиториях GitHub и получения реализаций соответствующего кода.  
Используется, когда требуется контекст кода из другого репозитория.  
Используйте в следующих ситуациях:  
- Если вы хотите проверить реализацию конечной точки API.  
- Если вы хотите найти определения типов запроса/ответа.  
- Если вы хотите найти связанный внутренний код  
- Если вы хотите проверить реализацию компонента интерфейса  
- Когда вы хотите найти тестовый код  
Также может быть вызван с помощью таких фраз, как «поиск на внутренней стороне», «поиск на внешнем интерфейсе», «проверка реализации API», «поиск кода» или «поиск gh».
