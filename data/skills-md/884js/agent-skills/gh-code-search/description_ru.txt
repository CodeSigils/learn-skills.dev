Навыки поиска кода в репозиториях GitHub и получения соответствующих реализаций.
Используется, когда необходим контекст кода из другого репозитория.
Используйте в следующих сценариях:
- Если вы хотите проверить реализацию конечной точки API.
- Если вы хотите найти определения типов запроса/ответа.
- Если вы хотите найти связанный внутренний код
- Когда вы хотите проверить реализацию компонентов интерфейса
- Когда вы хотите найти тестовый код
Также может быть вызван с помощью таких фраз, как «поиск во внутренней части», «поиск во внешнем интерфейсе», «проверка реализации API», «поиск кода» или «поиск gh».
