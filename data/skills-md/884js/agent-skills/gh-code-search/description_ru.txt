Навык поиска кода в репозитории GitHub и получения реализации соответствующего кода. Используется, когда необходим контекст кода из другого репозитория. Используется в следующих ситуациях:
- Если вы хотите проверить реализацию конечной точки API.
- Если вы хотите найти определения типов для запроса/ответа.
- Если вы хотите найти связанный внутренний код
- Если вы хотите проверить реализацию компонента внешнего интерфейса.
- Когда вы хотите найти тестовый код
Его также можно вызвать с помощью таких терминов, как «поиск на внутренней стороне», «поиск на внешнем интерфейсе», «проверка реализации API», «поиск кода», «поиск gh» и т. д.
