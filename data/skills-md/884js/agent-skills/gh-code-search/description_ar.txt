مهارة البحث عن التعليمات البرمجية من مستودعات GitHub واسترداد التطبيقات ذات الصلة.
يُستخدم عند الحاجة إلى سياق التعليمات البرمجية من مستودع آخر.
استخدم في السيناريوهات التالية:
- عندما تريد التحقق من تنفيذ نقطة نهاية API
- عندما تريد العثور على تعريفات نوع الطلب/الاستجابة
- عندما تريد البحث عن رمز الواجهة الخلفية ذي الصلة
- عندما تريد التحقق من تنفيذ مكونات الواجهة الأمامية
- عندما تريد البحث عن رمز الاختبار
يمكن أيضًا استدعاؤها باستخدام عبارات مثل "بحث الواجهة الخلفية" أو "بحث الواجهة الأمامية" أو "التحقق من تنفيذ واجهة برمجة التطبيقات" أو "بحث التعليمات البرمجية" أو "بحث gh".
