مهارة البحث عن التعليمات البرمجية من مستودعات GitHub واسترداد تطبيقات التعليمات البرمجية ذات الصلة.  
يُستخدم عندما يكون سياق التعليمات البرمجية من مستودع آخر مطلوبًا.  
استخدم في الحالات التالية:  
- عندما تريد التحقق من تنفيذ نقطة نهاية API  
- عندما تريد العثور على تعريفات نوع الطلب/الاستجابة  
- عندما تريد البحث عن رمز الواجهة الخلفية ذي الصلة  
- عندما تريد التحقق من تنفيذ أحد مكونات الواجهة الأمامية  
- عندما تريد البحث عن رمز الاختبار  
يمكن أيضًا استدعاؤه بعبارات مثل "بحث الواجهة الخلفية" أو "بحث الواجهة الأمامية" أو "التحقق من تنفيذ واجهة برمجة التطبيقات" أو "بحث الكود" أو "بحث gh".
