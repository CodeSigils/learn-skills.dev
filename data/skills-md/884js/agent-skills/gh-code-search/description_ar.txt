مهارة البحث عن التعليمات البرمجية من مستودع GitHub واسترجاع تنفيذ التعليمات البرمجية ذات الصلة. يُستخدم عندما تحتاج إلى سياق التعليمات البرمجية من مستودع آخر. تطبق في الحالات التالية:
- عندما تريد التحقق من تنفيذ نقطة نهاية API
- عندما تريد العثور على تعريفات النوع للطلبات/الردود
- عندما تريد البحث عن رمز الواجهة الخلفية ذي الصلة
- عندما تريد التحقق من تنفيذ أحد مكونات الواجهة الأمامية
- عندما تريد البحث عن رمز الاختبار
ويمكن أيضًا استدعاؤه بمصطلحات مثل "بحث الواجهة الخلفية"، و"بحث الواجهة الأمامية"، و"التحقق من تنفيذ واجهة برمجة التطبيقات"، و"بحث الكود"، و"بحث gh"، وما إلى ذلك.
