Une compétence pour rechercher du code dans les référentiels GitHub et récupérer les implémentations du code pertinent.  
Utilisé lorsque le contexte de code d'un autre référentiel est requis.  
Utiliser dans les situations suivantes :  
- Lorsque vous souhaitez vérifier l'implémentation d'un point de terminaison API  
- Lorsque vous souhaitez rechercher des définitions de types de requêtes/réponses  
- Lorsque vous souhaitez rechercher le code backend associé  
- Lorsque vous souhaitez vérifier l'implémentation d'un composant frontend  
- Lorsque vous souhaitez rechercher du code de test  
Peut également être invoqué avec des expressions telles que « recherche backend », « recherche frontend », « vérification de l'implémentation de l'API », « recherche de code » ou « recherche gh ».
