Une compétence pour rechercher du code dans un référentiel GitHub et récupérer l'implémentation du code associé. Utilisé lorsque vous avez besoin du contexte de code d'un autre référentiel. Appliqué dans les situations suivantes :
- Lorsque vous souhaitez vérifier l'implémentation d'un point de terminaison API
- Lorsque vous souhaitez rechercher des définitions de types pour les demandes/réponses
- Lorsque vous souhaitez rechercher le code backend associé
- Lorsque vous souhaitez vérifier l'implémentation d'un composant frontend
- Lorsque vous souhaitez rechercher du code de test
Il peut également être invoqué avec des termes tels que « recherche backend », « recherche frontend », « vérification de l'implémentation de l'API », « recherche de code », « recherche gh », etc.
