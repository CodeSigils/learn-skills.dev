Genera automaticamente le competenze delle librerie di progetto da tutte le dipendenze del progetto.
Da utilizzare quando si creano competenze di documentazione per tutte le librerie in un progetto o quando l'utente desidera impostare la documentazione della libreria per il progetto corrente.
Può anche essere richiamato direttamente con "index-lib-docs", "ライブラリドキュメント生成", "依存関係ドキュメント".
