Erzeugt automatisch Projektbibliothekskenntnisse aus allen Projektabhängigkeiten.
Verwenden Sie diese Option, wenn Sie Dokumentationsfähigkeiten für alle Bibliotheken in einem Projekt erstellen oder wenn der Benutzer eine Bibliotheksdokumentation für das aktuelle Projekt einrichten möchte.
Kann auch direkt mit „index-lib-docs“, „ライブラリドキュメント生成“, „依存関係ドキュメント“ aufgerufen werden.
