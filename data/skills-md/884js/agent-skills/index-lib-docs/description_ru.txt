Автоматически генерирует навык project-libs из всех зависимостей проекта.
Используйте при создании навыков документации для всех библиотек в проекте или когда пользователь хочет настроить документацию библиотеки для текущего проекта.
Также может быть вызван напрямую с помощью "index-lib-docs", "ライブラリドキュメント生成", "依存関係ドキュメント".
