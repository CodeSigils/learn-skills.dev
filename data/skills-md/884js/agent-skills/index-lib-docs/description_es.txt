Genera automáticamente habilidades de bibliotecas de proyectos a partir de todas las dependencias del proyecto.
Úselo al crear habilidades de documentación para todas las bibliotecas de un proyecto, o cuando el usuario desee configurar la documentación de la biblioteca para el proyecto actual.
También se puede invocar directamente con "index-lib-docs", "ライブラリドキュメント生成", "依存関係ドキュメント".
