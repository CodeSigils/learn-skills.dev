Génère automatiquement la compétence project-libs à partir de toutes les dépendances du projet.
À utiliser lors de la création de compétences de documentation pour toutes les bibliothèques d'un projet ou lorsque l'utilisateur souhaite configurer la documentation de bibliothèque pour le projet en cours.
Peut également être invoqué directement avec "index-lib-docs", "ライブラリドキュメント生成", "依存関係ドキュメント".
