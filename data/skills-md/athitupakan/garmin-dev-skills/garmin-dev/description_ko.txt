Windows/macOS/Linux에서 Garmin Connect IQ 앱(시계 화면, 데이터 필드, 위젯, 장치 앱)을 구축, 실행, 패키징 및 제공하고 Garmin 공식 문서의 캐시된 미러에서 Connect IQ 개발 질문에 답변하세요. Manifest.xml에서 SDK + JDK + 프로젝트 이름 + 대상 장치를 자동 감지합니다. 머신별 구성은 없습니다. 사용자가 시뮬레이터에서 빌드, 컴파일, 실행, 푸시, 감시, .iq 패키징 또는 릴리스 바이너리 빌드를 요청할 때 호출합니다. Monkey C 빌드 오류('java 인식 안 됨', 'BUILD FAILED', 시뮬레이터 찾을 수 없음, Monkey.jungle 구문 분석 오류, 개발자_키 누락, 매니페스트.xml 문제) 문제를 해결합니다. 또는 Connect IQ 기능을 구현하는 방법, Toybox API 또는 Monkey C 구성이 작동하는 방법, 장치가 지원하는 것 등을 묻습니다. 구성 가능한 색상/데이터 필드/테마, 기기 내 설정과 휴대폰 설정, 센서, 위치, 날씨, 저장 공간, 한눈에 보기, 배경, 정보 표시, AOD, 사용자 정의 글꼴, 권한, 정글 빌드 또는 스토어/게시 규칙. 그러한 질문이 있는 경우, reference/connect-iq-docs/FIRST에서 관련 캐시된 참조를 찾아 읽고(색인 탐색 - 경로를 추측하지 않음) 인용한 다음 사용자 코드를 분석하십시오. 문서에는 코드 분석에서 누락된 플랫폼 및 장치 제약 조건이 포함되어 있습니다.
