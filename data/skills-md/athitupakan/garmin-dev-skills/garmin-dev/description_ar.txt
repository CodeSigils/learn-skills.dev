قم بإنشاء تطبيقات Garmin Connect IQ وتشغيلها وتعبئتها وشحنها (وجه الساعة، وحقل البيانات، والقطعة، وتطبيق الجهاز) على أنظمة التشغيل Windows/macOS/Linux، والإجابة على أسئلة تطوير Connect IQ من مرآة مخزنة مؤقتًا لمستندات Garmin الرسمية. يكتشف تلقائيًا SDK + JDK + اسم المشروع + الجهاز المستهدف من ملفmani.xml - لا يوجد تكوين لكل جهاز. يتم الاستدعاء عندما يطلب المستخدم إنشاء ملف .iq أو تجميعه أو تشغيله في جهاز المحاكاة أو دفعه أو مشاهدته أو حزمه أو إنشاء إصدار ثنائي؛ لاستكشاف أخطاء بناء Monkey C وإصلاحها ("لم يتم التعرف على Java"، "فشل البناء"، لم يتم العثور على جهاز المحاكاة، أخطاء تحليل Monkey.jungle، مفتاح_المطور المفقود، مشكلات Manifest.xml)؛ أو يسأل عن كيفية تنفيذ ميزة Connect IQ، أو كيفية عمل إنشاء Toybox API أو Monkey C، أو ما يدعمه الجهاز - على سبيل المثال. الألوان / حقول البيانات / السمات القابلة للتكوين، وإعدادات الجهاز مقابل إعدادات الهاتف، وأجهزة الاستشعار، والموقع، والطقس، والتخزين، واللمحات، والخلفية، والمضاعفات، وAOD، والخطوط المخصصة، والأذونات، وبناء الغابة، أو قواعد المتجر/النشر. بالنسبة لأي سؤال من هذا القبيل، ابحث عن المرجع المخزن مؤقتًا ذي الصلة واقرأه ضمن المراجع/connect-iq-docs/ FIRST (تنقل في فهارسه - لا تخمن مسارًا)، واستشهد به، وبعد ذلك فقط قم بتحليل كود المستخدم؛ تحتوي المستندات على قيود النظام الأساسي والجهاز التي يفتقدها تحليل التعليمات البرمجية.
