Créez, exécutez, empaquetez et expédiez des applications Garmin Connect IQ (cadran de montre, champ de données, widget, application pour appareil) sur Windows/macOS/Linux, ET répondez aux questions de développement Connect IQ à partir d'un miroir mis en cache des documents officiels de Garmin. Détecte automatiquement le SDK + JDK + le nom du projet + le périphérique cible à partir du manifest.xml — pas de configuration par machine. Invoquer lorsque l'utilisateur demande à créer, compiler, exécuter dans le simulateur, pousser, regarder, empaqueter un .iq ou créer un binaire de version ; pour dépanner les erreurs de construction de Monkey C (« Java non reconnu », « ÉCHEC DE LA CONSTRUCTION », simulateur introuvable, erreurs d'analyse de singe.jungle, clé de développeur manquante, problèmes de manifeste.xml) ; OU demande comment implémenter une fonctionnalité Connect IQ, comment fonctionne une API Toybox ou une construction Monkey C, ou ce qu'un appareil prend en charge - par ex. couleurs/champs de données/thèmes configurables, paramètres de l'appareil ou du téléphone, capteurs, emplacement, météo, stockage, regards, arrière-plan, complications, AOD, polices personnalisées, autorisations, construction de la jungle ou règles de stockage/publication. Pour toute question de ce type, recherchez et lisez la référence mise en cache pertinente sous references/connect-iq-docs/ FIRST (parcourez ses index - ne devinez pas un chemin), citez-la et analysez ensuite seulement le code de l'utilisateur ; les documents contiennent des contraintes de plate-forme et de périphérique qui ne sont pas prises en compte par l'analyse du code.
