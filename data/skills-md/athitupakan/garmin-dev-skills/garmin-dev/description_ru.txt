Создавайте, запускайте, упаковывайте и отправляйте приложения Garmin Connect IQ (циферблат, поле данных, виджет, приложение для устройства) в Windows/macOS/Linux, а также отвечайте на вопросы разработки Connect IQ из кэшированного зеркала официальных документов Garmin. Автоматически определяет SDK + JDK + имя проекта + целевое устройство из файла манифеста.xml — без настройки для каждого компьютера. Вызов, когда пользователь просит собрать, скомпилировать, запустить в симуляторе, отправить, просмотреть, упаковать .iq или собрать двоичный файл выпуска; для устранения ошибок сборки Monkey C («Java не распознана», «СБОРКА ОШИБКА», симулятор не найден, ошибки анализа Monkey.jungle, отсутствующий ключ разработчика, проблемы с манифестом); ИЛИ спрашивает, как реализовать функцию Connect IQ, как работает Toybox API или конструкция Monkey C или что поддерживает устройство — например. настраиваемые цвета/поля данных/темы, настройки на устройстве и на телефоне, датчики, местоположение, погода, хранилище, взгляды, фон, сложности, AOD, пользовательские шрифты, разрешения, сборка в джунглях или правила хранения/публикации. По любому такому вопросу найдите и прочитайте соответствующую кэшированную ссылку в references/connect-iq-docs/ FIRST (перемещайтесь по ее индексам — не угадывайте путь), процитируйте ее и только потом анализируйте код пользователя; в документации содержатся ограничения платформы и устройства, которые не учитываются при анализе кода.
