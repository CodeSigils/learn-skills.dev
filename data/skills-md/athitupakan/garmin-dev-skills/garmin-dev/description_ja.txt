Windows/macOS/Linux 上で Garmin Connect IQ アプリ (ウォッチフェイス、データ フィールド、ウィジェット、デバイス アプリ) を構築、実行、パッケージ化、出荷し、Garmin の公式ドキュメントのキャッシュされたミラーから Connect IQ 開発に関する質問に答えます。 Manifest.xml から SDK + JDK + プロジェクト名 + ターゲット デバイスを自動検出します。マシンごとの構成は必要ありません。ユーザーがビルド、コンパイル、シミュレーターでの実行、プッシュ、ウォッチ、.iq のパッケージ化、またはリリース バイナリのビルドを要求したときに呼び出します。 Monkey C ビルド エラー (「Java が認識されません」、「ビルド失敗」、シミュレーターが見つからない、monkey.jungle 解析エラー、developer_key の欠落、manifest.xml の問題) をトラブルシューティングします。または、Connect IQ 機能を実装する方法、Toybox API または Monkey C 構造がどのように機能するか、またはデバイスがサポートしているものを尋ねます。構成可能な色 / データ フィールド / テーマ、デバイス上と電話の設定、センサー、位置、天気、ストレージ、グランス、バックグラウンド、コンプリケーション、AOD、カスタム フォント、権限、ジャングル ビルド、またはストア / 公開ルール。このような質問がある場合は、references/connect-iq-docs/ の下にある関連するキャッシュされた参照を見つけて読み、最初に (そのインデックスに移動します。パスを推測しないでください)、引用してから、ユーザーのコードを分析してください。ドキュメントには、コード分析で見逃されるプラットフォームとデバイスの制約が記載されています。
