Authentification CLI GitHub pour les harnais d'agents d'IA locaux - PAT à granularité fine dans gitignored .github-agent.local, direnv, gh verify. À utiliser lors de la configuration de gh pour les agents, de la création de GH_TOKEN, du câblage des workflows GitHub PR/issue/CI par dépôt, ou avant toute commande gh lorsque l'authentification peut être manquante.
