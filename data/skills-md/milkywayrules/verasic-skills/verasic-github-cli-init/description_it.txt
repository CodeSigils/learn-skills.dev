Autenticazione CLI di GitHub per i cablaggi dell'agente AI locale: PAT a grana fine in gitignored .github-agent.local, direnv, gh verify. Da utilizzare durante la configurazione di gh per gli agenti, la creazione di GH_TOKEN, il cablaggio dei flussi di lavoro PR/issue/CI di GitHub per repository o prima di qualsiasi comando gh quando l'autenticazione potrebbe mancare.
