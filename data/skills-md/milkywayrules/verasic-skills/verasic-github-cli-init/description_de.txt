GitHub-CLI-Authentifizierung für lokale KI-Agent-Gebäude – feinkörniges PAT in gitignored .github-agent.local, direnv, gh verify. Verwenden Sie diese Option, wenn Sie gh für Agenten einrichten, GH_TOKEN erstellen, GitHub PR/Issue/CI-Workflows pro Repo verknüpfen oder vor jedem gh-Befehl, wenn die Authentifizierung möglicherweise fehlt.
