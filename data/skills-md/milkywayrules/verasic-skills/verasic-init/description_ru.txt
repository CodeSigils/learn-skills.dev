Настройка репозитория с первым подтверждением для установленных навыков Verasic — определяет профиль установки (курсор, агент, курсор-гибрид), печатает контрольный список и использование, затем с помощью --yes подключает загрузочную загрузку github-env и перехватчик git-commits и при необходимости извлекает Cursor UX из исходного исходного GitHub. Используйте, когда пользователь просит «инициализировать verasic», «настроить навыки verasic», «загрузить этот репозиторий для verasic» или сразу после установки через setup.sh илиkills.sh.
