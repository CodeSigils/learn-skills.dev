Confirmez d'abord la configuration du dépôt pour les compétences Verasic installées - détecte le profil d'installation (curseur, agent, curseur-hybride), imprime la liste de contrôle et l'utilisation, puis avec les fils --yes github-env bootstrap et git-commits hook et récupère éventuellement Cursor UX à partir de GitHub brut en amont. À utiliser lorsque l'utilisateur demande "initialiser verasic", "configurer les compétences verasic", "démarrer ce dépôt pour verasic", ou juste après l'installation via setup.sh ou skills.sh.
