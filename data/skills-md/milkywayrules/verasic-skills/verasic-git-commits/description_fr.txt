Convention Verasic git commit – style de message, pas de bandes-annonces co-écrites/IA, pas de langage de session IA – plus un audit de l'historique pré-push. À utiliser lors de l'écriture d'un message de validation git, lorsque l'utilisateur demande de valider les modifications ou demande de « vérifier les validations », de « vérifier les messages de validation » ou de « nettoyer l'historique des validations » avant push/PR.
