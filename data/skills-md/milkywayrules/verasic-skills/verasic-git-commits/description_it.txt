Convenzione git commit di Verasic: stile del messaggio, nessun trailer di co-autore/AI, nessun linguaggio di sessione AI, oltre a un controllo della cronologia pre-push. Da utilizzare quando si scrive un messaggio git commit, quando l'utente chiede di confermare le modifiche o di "controllare i commit", "controllare i messaggi di commit" o "pulire la cronologia dei commit" prima di eseguire push/PR.
