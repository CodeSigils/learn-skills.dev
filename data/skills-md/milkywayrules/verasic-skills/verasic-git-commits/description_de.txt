Verasische Git-Commit-Konvention – Nachrichtenstil, keine gemeinsam verfassten/KI-Trailer, keine KI-Sitzungssprache – plus eine Prüfung des Pre-Push-Verlaufs. Verwenden Sie diese Option beim Schreiben einer Git-Commit-Nachricht, wenn der Benutzer vor dem Push/PR nach einem Commit von Änderungen oder nach „Audit-Commits“, „Überprüfen von Commit-Nachrichten“ oder „Bereinigen des Commit-Verlaufs“ fragt.
