اتفاقية الالتزام Verasic git - نمط الرسالة، لا توجد مقاطع دعائية مشتركة/الذكاء الاصطناعي، لا لغة جلسة الذكاء الاصطناعي - بالإضافة إلى تدقيق سجل الدفع المسبق. يُستخدم عند كتابة أي رسالة التزام git، عندما يطلب المستخدم تنفيذ التغييرات، أو يطلب "عمليات التدقيق"، أو "التحقق من رسائل الالتزام"، أو "تنظيف سجل الالتزام" قبل الدفع/PR.
