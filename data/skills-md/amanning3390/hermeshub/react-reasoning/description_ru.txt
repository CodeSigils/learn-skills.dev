Фреймворк ReAct (Рассуждение + Действие) — чередуйте цепочку мыслей с инструментальными действиями для решения сложных задач. Устраняет галлюцинации, обосновывая каждый шаг рассуждения реальными наблюдениями. Используйте, когда агенту требуется многоэтапное рассуждение с использованием внешних инструментов: ответы на вопросы, проверка фактов, веб-навигация, интерактивное принятие решений или любая задача, в которой чистое рассуждение вызывает галлюцинации, а чистое действие не позволяет спланировать.
