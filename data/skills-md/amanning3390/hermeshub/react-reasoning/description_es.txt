Marco ReAct (Razonamiento + Actuación): entrelaza razonamiento en cadena de pensamiento con acciones de herramientas para resolver tareas complejas. Elimina las alucinaciones al basar cada paso del razonamiento en observaciones reales. Úselo cuando el agente necesite un razonamiento de varios pasos con el uso de herramientas externas: respuesta a preguntas, verificación de hechos, navegación web, toma de decisiones interactiva o cualquier tarea en la que el razonamiento puro alucine y la actuación pura no pueda planificar.
