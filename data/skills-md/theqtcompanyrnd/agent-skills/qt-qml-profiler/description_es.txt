Úselo cuando el usuario esté investigando el rendimiento de QML/Qt Quick: tanto quejas vagas ("la interfaz de usuario se siente retrasada", "esto es lento", "los fotogramas caen", "la aplicación tartamudea") como solicitudes explícitas para generar perfiles, encontrar puntos de acceso u optimizar enlaces, señales o renderizado. Ejecuta qmlprofiler en una aplicación QML 2D, analiza el seguimiento .qtd y analiza puntos de acceso con respecto al origen con resúmenes de tiempo de fotograma, memoria y caché de mapas de píxeles. NO cubre Qt Quick 3D.
