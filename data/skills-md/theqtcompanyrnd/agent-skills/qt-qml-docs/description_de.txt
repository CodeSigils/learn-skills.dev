Erstellt eine eigenständige Markdown-Referenzdokumentation für QML-Komponenten und -Anwendungen. Verwenden Sie diese Fähigkeit immer dann, wenn Sie QML-Dateien dokumentieren, API-Referenzdokumente für eine QML-Komponente oder ein QML-Modul erstellen, eine Qt Quick-Anwendung dokumentieren oder eine entwicklerorientierte Dokumentation aus .qml-Quellcode erstellen möchten. Wird ausgelöst bei: „dieses QML dokumentieren“, „Dokumente für mein QML schreiben“, „Referenzdokumente erstellen“, „QML-Komponente dokumentieren“, „QML-API-Dokumente“, „meine Qt-Quick-Komponente dokumentieren“, „meine Qt-App dokumentieren“ oder immer dann, wenn eine oder mehrere .qml-Dateien bereitgestellt werden und Dokumentation benötigt wird. Funktioniert mit einzelnen Dateien, eingefügtem Code oder ganzen Projektordnern. NICHT verwenden, wenn der Benutzer eine Ausgabe im QDoc-Format anfordert.
