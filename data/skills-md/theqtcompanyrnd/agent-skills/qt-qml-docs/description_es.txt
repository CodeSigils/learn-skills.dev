Genera documentación de referencia de Markdown independiente para componentes y aplicaciones QML. Utilice esta habilidad siempre que desee documentar archivos QML, crear documentos de referencia de API para un componente o módulo QML, documentar una aplicación Qt Quick o producir documentación para desarrolladores a partir del código fuente .qml. Activadores en: "documentar este QML", "escribir documentos para mi QML", "crear documentos de referencia", "documentar componente QML", "documentos API QML", "documentar mi componente Qt Quick", "documentar mi aplicación Qt", o en cualquier momento en que se proporcionen uno o más archivos .qml y se necesite documentación. Funciona con archivos individuales, código pegado o carpetas de proyectos completas. NO lo use si el usuario solicita una salida en formato QDoc.
