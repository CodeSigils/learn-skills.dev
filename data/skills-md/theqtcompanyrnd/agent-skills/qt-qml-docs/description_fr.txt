Génère une documentation de référence Markdown autonome pour les composants et applications QML. Utilisez cette compétence chaque fois que vous souhaitez documenter des fichiers QML, créer des documents de référence API pour un composant ou un module QML, documenter une application Qt Quick ou produire une documentation destinée aux développeurs à partir du code source .qml. Déclencheurs sur : "documenter ce QML", "écrire des documents pour mon QML", "créer des documents de référence", "documenter le composant QML", "documents de l'API QML", "documenter mon composant Qt Quick", "documenter mon application Qt", ou à chaque fois qu'un ou plusieurs fichiers .qml sont fournis et qu'une documentation est nécessaire. Fonctionne avec des fichiers uniques, du code collé ou des dossiers de projet entiers. NE PAS utiliser si l'utilisateur demande une sortie au format QDoc.
