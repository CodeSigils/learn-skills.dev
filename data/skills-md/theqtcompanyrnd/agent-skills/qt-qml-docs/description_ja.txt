QML コンポーネントおよびアプリケーション用のスタンドアロンの Markdown リファレンス ドキュメントを生成します。 QML ファイルを文書化する場合、QML コンポーネントまたはモジュールの API リファレンス ドキュメントを作成する場合、Qt Quick アプリケーションを文書化する場合、または .qml ソース コードから開発者向けのドキュメントを作成する場合は、このスキルを常に使用してください。トリガー: 「この QML をドキュメント化」、「QML のドキュメントを作成」、「リファレンス ドキュメントの作成」、「QML コンポーネントをドキュメント化」、「QML API ドキュメント」、「Qt Quick コンポーネントをドキュメント化」、「Qt アプリをドキュメント化」、または 1 つ以上の .qml ファイルが提供され、ドキュメントが必要なとき。単一のファイル、貼り付けたコード、またはプロジェクト フォルダー全体を操作します。ユーザーが QDoc 形式の出力を要求した場合は使用しないでください。
