Создает отдельную справочную документацию Markdown для компонентов и приложений QML. Используйте этот навык всякий раз, когда вам нужно документировать файлы QML, создавать справочные документы API для компонента или модуля QML, документировать приложение Qt Quick или создавать документацию для разработчиков из исходного кода .qml. Срабатывает при: «документировать этот QML», «написать документацию для моего QML», «создать справочную документацию», «документировать компонент QML», «документировать QML API», «документировать мой компонент Qt Quick», «документировать мое приложение Qt» или в любой момент, когда предоставляется один или несколько файлов .qml и необходима документация. Работает с отдельными файлами, вставленным кодом или целыми папками проекта. НЕ используйте, если пользователь запрашивает вывод в формате QDoc.
