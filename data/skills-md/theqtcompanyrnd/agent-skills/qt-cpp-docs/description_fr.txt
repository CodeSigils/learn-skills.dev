Génère une documentation de référence Markdown autonome pour tous les fichiers sources Qt/C++ : classes Qt Widgets, backends Qt Quick, modules Qt/C++, utilitaires C++ simples, structures, en-têtes de fonctions libres et points d'entrée comme main.cpp. Utilisez cette compétence pour documenter n'importe quel fichier .h ou .cpp : classes Qt, code C++ brut, utilitaires d'aide ou fichiers de démarrage d'application. Déclencheurs sur : "documenter cette classe", "écrire des documents pour mon C++", "document main.cpp", "documents de l'API C++", "documenter mon application Qt", ou chaque fois que des fichiers C++ ou d'en-tête sont fournis et qu'une documentation est nécessaire. Fonctionne avec des fichiers uniques, du code collé ou des dossiers de projet entiers. NE PAS utiliser si l'utilisateur demande une sortie au format QDoc.
