Создает автономную справочную документацию Markdown для любых исходных файлов Qt/C++ — классов Qt Widgets, бэкендов Qt Quick, модулей Qt/C++, простых утилит C++, структур, заголовков свободных функций и точек входа, таких как main.cpp. Используйте этот навык для документирования любого файла .h или .cpp: классов Qt, простого кода C++, вспомогательных утилит или файлов запуска приложений. Срабатывает при: «документировать этот класс», «написать документацию для моего C++», «документ main.cpp», «документацию C++ API», «документировать мое приложение Qt» или всякий раз, когда предоставляются C++ или файлы заголовков и необходима документация. Работает с отдельными файлами, вставленным кодом или целыми папками проекта. НЕ используйте, если пользователь запрашивает вывод в формате QDoc.
