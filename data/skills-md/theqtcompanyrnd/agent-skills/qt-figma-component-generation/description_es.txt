Extraiga metadatos de componentes de un sistema de diseño Figma y genere controles QML listos para producción. Utilice esta habilidad siempre que alguien quiera convertir componentes de Figma en archivos QML, ya sea que diga "generar componentes de Figma", "crear controles QML basados ​​en un sistema de diseño", "convertir componentes de Figma a QML", "construir la biblioteca de componentes", "extraer botón/entrada/casilla de verificación de Figma" o cualquier cosa similar. Requiere que ya existan los singletons del sistema de diseño design-tokens.json y QML (de la habilidad de extracción de tokens). Utiliza Figma MCP para inspeccionar componentes uno a la vez y asigna variantes, estados, tamaños y uso de tokens a patrones idiomáticos de Qt Quick Controls 2. Active esta habilidad en el paso de generación de componentes de cualquier flujo de trabajo del sistema de diseño QML.
