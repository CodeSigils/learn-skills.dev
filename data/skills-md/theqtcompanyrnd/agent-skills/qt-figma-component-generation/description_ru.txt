Извлекайте метаданные компонентов из системы проектирования Figma и создавайте готовые к использованию элементы управления QML. Используйте этот навык всякий раз, когда кто-то хочет превратить компоненты Figma в файлы QML — будь то «создать компоненты из Figma», «создать элементы управления QML на основе системы дизайна», «конвертировать компоненты Figma в QML», «создать библиотеку компонентов», «извлечь кнопку/ввод/флажок из Figma» или что-то подобное. Требуется, чтобы уже существовали синглтоны design-tokens.json и системы проектирования QML (на основании навыка извлечения токенов). Использует Figma MCP для проверки компонентов по одному и сопоставляет варианты, состояния, размеры и использование токенов с идиоматическими шаблонами Qt Quick Controls 2. Используйте этот навык на этапе создания компонентов любого рабочего процесса системы проектирования QML.
