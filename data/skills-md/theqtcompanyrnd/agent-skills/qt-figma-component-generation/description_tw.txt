從 Figma 設計系統中提取組件元資料並產生可用於生產的 QML 控制項。每當有人想要將 Figma 元件轉換為 QML 檔案時，無論他們說「從 Figma 產生元件」、「基於設計系統建立 QML 控制項」、「將 Figma 元件轉換為 QML」、「建立元件庫」、「從 Figma 擷取按鈕/輸入/複選框」或類似的內容，都可以使用此技能。需要 design-tokens.json 和 QML 設計系統單例已經存在（來自令牌提取技能）。使用 Figma MCP 一次檢查一個元件，並將變體、狀態、大小和令牌使用對應到慣用的 Qt Quick Controls 2 模式。在任何 QML 設計系統工作流程的元件產生步驟中觸發此技能。
