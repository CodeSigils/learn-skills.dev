Applique les meilleures pratiques QML lors de la production ou de l’utilisation du code source QML. À utiliser chaque fois que le code QML est le sujet principal : écriture, révision, correction, refactorisation, optimisation ou débogage de fichiers, composants ou liaisons QML. Ne déclenchez PAS de questions QML purement conversationnelles où aucun code n'est produit ou examiné (par exemple "expliquer comment fonctionnent les ancres").
