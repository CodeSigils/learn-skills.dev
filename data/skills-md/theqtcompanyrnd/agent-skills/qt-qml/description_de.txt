Wendet QML-Best Practices bei der Erstellung oder Arbeit mit QML-Quellcode an. Verwenden Sie es immer dann, wenn QML-Code das Hauptthema ist: Schreiben, Überprüfen, Korrigieren, Umgestalten, Optimieren oder Debuggen von QML-Dateien, Komponenten oder Bindungen. Lösen Sie NICHT bei rein konversationsbezogenen QML-Fragen aus, bei denen kein Code erstellt oder untersucht wird (z. B. „Erklären Sie, wie Anker funktionieren“).
