Wendet QML-Best Practices an, wenn QML-Quellcode erstellt oder damit gearbeitet wird. Verwenden Sie es immer dann, wenn QML-Code das Hauptthema ist: Schreiben, Überprüfen, Korrigieren, Umgestalten, Optimieren oder Debuggen von QML-Dateien, Komponenten oder Bindungen. Lösen Sie NICHT für reine QML-Konversationsfragen aus, bei denen kein Code erstellt oder untersucht wird (z. B. „Erklären Sie, wie Anker funktionieren“).
