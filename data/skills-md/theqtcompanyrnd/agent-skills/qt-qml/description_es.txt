Aplica las mejores prácticas de QML al producir o trabajar con código fuente QML. Úselo siempre que el código QML sea el tema principal: escribir, revisar, arreglar, refactorizar, optimizar o depurar archivos, componentes o enlaces QML. NO active preguntas QML puramente conversacionales en las que no se produzca ni examine ningún código (por ejemplo, "explica cómo funcionan los anclajes").
