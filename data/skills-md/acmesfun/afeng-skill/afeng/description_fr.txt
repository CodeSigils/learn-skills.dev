A-Feng 1.0 : analysez la logique métier, les limites architecturales, les styles de codage principaux et les pondérations de style de tout projet de code existant, et générez une compétence Codex dédiée qui s'adapte entièrement à ce projet. À utiliser lorsque l'utilisateur demande à créer une compétence de spécification de projet, à analyser la logique métier, à distiller le style de codage, à maintenir le code ultérieur cohérent avec le projet, à générer des normes de développement de projet, à projeter A-Feng, à écrire des spécifications basées sur le code existant et à déduire des règles de développement à partir de la base de code.
