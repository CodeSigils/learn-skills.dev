A-Feng 1.0: extraiga la lógica empresarial, los límites arquitectónicos, el estilo del código principal y los pesos de estilo de cualquier proyecto de código existente y genere una habilidad Codex dedicada que se adapte completamente a ese proyecto. Úselo cuando el usuario solicite crear una habilidad de especificación de proyecto, extraer lógica de negocios, refinar el estilo del código, mantener el código posterior consistente con el proyecto, generar estándares de desarrollo de proyectos, proyectar A-Feng, escribir especificaciones basadas en el código existente e inferir reglas de desarrollo a partir del código base.
