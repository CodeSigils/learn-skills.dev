从 UI 屏幕截图或设计模型中提取设计系统（颜色、排版、间距、阴影、半径、运动），通过与情绪/灵感图像或音乐录音的交互对话探索美学方向，生成情绪板作为精心策划的视觉拼贴画以具体化和传达设计方向，并分析从网页屏幕截图到可重复使用的 ASCII 布局蓝图的 UI 布局结构。包括运动系统提取——定义元素如何、何时以及为何以动画方式传达意义和产品个性。当用户想要为其项目建立视觉风格和动作语言、需要帮助定义设计美学、想要从现有 UI 中提取设计系统、想要定义或理解动作系统、想要创建情绪板以在正式设计之前捕获和验证美学方向，或者需要理解和重用网页布局结构时使用。当用户分享音乐录音或描述歌曲/旋律来表达他们希望其设计传达的情感时也可以使用。非常适合缺乏专业设计技能的氛围编码开发人员。
