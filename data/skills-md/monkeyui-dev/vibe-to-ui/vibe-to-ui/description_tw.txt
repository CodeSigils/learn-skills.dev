從 UI 螢幕截圖或設計模型中提取設計系統（顏色、排版、間距、陰影、半徑、運動），透過與情緒/靈感圖像或音樂錄音的交互對話探索美學方向，生成情緒板作為精心策劃的視覺拼貼畫以具體化和傳達設計方向，並分析從網頁屏幕截圖到可重複使用的 ASCII 佈局藍圖的 UI 佈局結構。包括運動系統提取——定義元素如何、何時以及為何以動畫方式傳達意義和產品個性。當使用者想要為其項目建立視覺風格和動作語言、需要幫助定義設計美學、想要從現有 UI 中提取設計系統、想要定義或理解動作系統、想要創建情緒板以在正式設計之前捕獲和驗證美學方向，或者需要理解和重用網頁佈局結構時使用。當使用者分享音樂錄音或描述歌曲/旋律來表達他們希望其設計傳達的情感時也可以使用。非常適合缺乏專業設計技能的氛圍編碼開發人員。
