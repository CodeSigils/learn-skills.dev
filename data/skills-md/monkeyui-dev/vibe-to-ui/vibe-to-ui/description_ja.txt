UI スクリーンショットまたはデザイン モックアップからデザイン システム (色、タイポグラフィ、間隔、影、半径、モーション) を抽出し、ムード/インスピレーション画像や音楽録音とのインタラクティブな会話を通じて美的方向性を探索し、厳選されたビジュアル コラージュとしてムードボードを生成してデザインの方向性を結晶化して伝達し、Web ページのスクリーンショットから UI レイアウト構造を分析して再利用可能な ASCII レイアウト ブループリントを作成します。モーション システムの抽出が含まれます。意味や製品の個性を伝えるために要素がアニメーション化する方法、タイミング、理由を定義します。ユーザーがプロジェクトのビジュアル スタイルとモーション言語を確立したい場合、デザインの美学の定義に支援が必要な場合、既存の UI からデザイン システムを抽出したい場合、モーション システムを定義または理解したい場合、正式なデザインの前に美的な方向性をキャプチャおよび検証するためにムードボードを作成したい場合、または Web ページのレイアウト構造を理解して再利用する必要がある場合に使用します。ユーザーが音楽録音を共有したり、デザインで伝えたい感情を表現するために曲やメロディーを説明したりする場合にも使用します。専門的なデザインスキルが不足しているバイブコーディング開発者に最適です。
