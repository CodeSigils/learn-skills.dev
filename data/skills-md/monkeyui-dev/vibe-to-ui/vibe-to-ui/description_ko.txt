UI 스크린샷 또는 디자인 모형에서 디자인 시스템(색상, 타이포그래피, 간격, 그림자, 반경, 모션)을 추출하고, 분위기/영감 이미지 또는 음악 녹음과의 대화형 대화를 통해 미적 방향을 탐색하고, 선별된 시각적 콜라주로 무드 보드를 생성하여 디자인 방향을 구체화하고 전달하고, 웹페이지 스크린샷의 UI 레이아웃 구조를 재사용 가능한 ASCII 레이아웃 청사진으로 분석합니다. 모션 시스템 추출이 포함되어 요소가 의미와 제품 특성을 전달하기 위해 어떻게, 언제, 왜 애니메이션화되는지 정의합니다. 사용자가 프로젝트에 대한 시각적 스타일과 모션 언어를 설정하고 싶고, 디자인 미학을 정의하는 데 도움이 필요하고, 기존 UI에서 디자인 시스템을 추출하고 싶고, 모션 시스템을 정의하거나 이해하고 싶고, 정식 디자인 전에 미적 방향을 포착하고 검증하기 위해 무드 보드를 만들고 싶거나, 웹페이지 레이아웃 구조를 이해하고 재사용해야 하는 경우에 사용합니다. 또한 사용자가 음악 녹음을 공유하거나 노래/멜로디를 설명할 때 디자인이 전달하려는 감정적인 느낌을 표현하는 데 사용합니다. 전문적인 디자인 기술이 부족한 바이브 코딩 개발자에게 이상적입니다.
