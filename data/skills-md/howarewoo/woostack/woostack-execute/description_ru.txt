Используется для выполнения утвержденного плана woostack как последовательности сложенных приращений размером с PR с помощью встроенного драйвера или драйвера, управляемого субагентом (--inline/--subagent, smart default) — реализуйте каждое приращение с помощью TDD, отмечайте флажки плана на месте, фиксируйте через woostack-commit в собственной ветке Graphite, проверяйте каждое приращение (woostack-review --fast inline; циклы субагента для каждой задачи + качество в субагенте режиме, каждый из которых перенаправляется на модель, соответствующую уровню), извлеките долговременные знания, а затем продолжите. Это фаза выполнения цикла сборки woostack (шаг 8 сборки woostack); также можно использовать автономно через /woostack-execute <путь-плана> [--inline|--subagent]. Один план для каждой спецификации, несколько PR для каждого плана. Никогда не сливается.
