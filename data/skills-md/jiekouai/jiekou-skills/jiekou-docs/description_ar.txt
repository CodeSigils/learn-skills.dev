الوثائق المرجعية لخدمة نموذج واجهة الذكاء الاصطناعي، والتي تغطي LLM API (متوافق مع OpenAI)، وواجهات برمجة تطبيقات الصور/الفيديو/الصوت، وحلول التكامل، والمصادقة/الفوترة/التسعير/تحديد المعدل، واستكشاف الأخطاء وإصلاحها. ينطبق على "كيفية دمج Interface AI في OpenAI SDK / LangChain والأدوات الأخرى؟" وفشل طلب واجهة الذكاء الاصطناعي، وما إلى ذلك.
