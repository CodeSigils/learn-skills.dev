Diseñar y crear interfaces web profesionales y distintivas, y evitar o eliminar diseños genéricos generados por IA ("baja"). Utilice esta habilidad siempre que cree o diseñe cualquier interfaz de usuario web, incluidos sitios web, páginas de destino, paneles, aplicaciones web, componentes React o Vue, páginas HTML/CSS, artefactos, prototipos y plantillas de correo electrónico. Úselo también al auditar, deshacer, revisar o rediseñar una interfaz o código base existente, cuando un diseño parece genérico, con plantilla o generado por IA, o cuando el usuario pide que algo se vea mejor, más pulido o más profesional, incluso si nunca dice la palabra diseño o slop. Cubre la dirección del diseño, la tipografía, el color, el diseño, el espaciado, el movimiento, el tono de la copia, la accesibilidad y una auditoría final anti-deslizamiento, para nuevas construcciones y para modernizar las interfaces existentes.
