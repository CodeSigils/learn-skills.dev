設計與建構專業、獨特的 Web 前端，避免或移除通用的 AI 產生設計（「slop」）。在創建或樣式化任何 Web UI 時，包括網站、登陸頁面、儀表板、Web 應用程式、React 或 Vue 元件、HTML/CSS 頁面、產出物、原型以及電子郵件範本，都要使用此技能。當審核、去 slop、檢視或重新樣式化既有前端或程式碼庫時，若設計看起來通用、模板化或是 AI 產生，或使用者要求使某物看起來更好、更精緻或更專業，即使他們從未說出「設計」或「slop」這兩個詞，也請使用此技能。涵蓋設計方向、排版、顏色、版面配置、間距、動態效果、文案語氣、可及性，以及最終的反 slop 審查，適用於新建以及改造既有前端。
