flujo de trabajo de pr-a-video: una solicitud de extracción de GitHub (URL como github.com/<propietario>/<repo>/pull/<N>, o <propietario>/<repo>#<N>, o "este PR" en un repositorio verificado) -> datos de relaciones públicas ingeridos (título, cuerpo, diferencia, confirmaciones, archivos, +/- estadísticas) -> narrator_scripts.json + audio (voz + BGM) + sección_plan.md -> video explicativo de código-diff / antes-después / impacto. La entrada es un CAMBIO DE CÓDIGO. La URL es un enlace de relaciones públicas, NO un sitio de marketing para raspar; no es un resumen de texto ni un sitio web de producto. Para obtener información que no sea de relaciones públicas (sitio del producto, sitio web general, texto del tema), consulte /hyperframes.
