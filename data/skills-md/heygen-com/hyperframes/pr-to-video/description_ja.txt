pr-to-video ワークフロー - GitHub プル リクエスト (github.com/<owner>/<repo>/pull/<N>、<owner>/<repo>#<N>、またはチェックアウトされたリポジトリ内の「この PR」などの URL) -> 取り込まれた PR ファクト (タイトル、本文、差分、コミット、ファイル、+/- 統計) -> narrator_scripts.json + オーディオ (音声 + BGM) + Section_plan.md -> コードの差分 / ビフォーアフター / 影響の説明ビデオ。入力はコード変更です。 URL は PR リンクであり、スクレイピングするマーケティング サイトではありません。テキスト概要や製品 Web サイトではありません。 PR 以外の入力 (製品サイト、一般的な Web サイト、トピック テキスト) については、/hyperframes を参照してください。
