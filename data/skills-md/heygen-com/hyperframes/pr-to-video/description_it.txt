Flusso di lavoro pr-to-video: una richiesta pull GitHub (URL come github.com/<owner>/<repo>/pull/<N> o <owner>/<repo>#<N> o "questo PR" in un repository estratto) -> fatti PR acquisiti (titolo, corpo, diff, commit, file, +/- statistiche) -> narrator_scripts.json + audio (voce + BGM) + sezione_plan.md -> video esplicativo code-diff/prima-dopo/impatto. L'input è un CAMBIO CODICE. L'URL è un collegamento PR, NON un sito di marketing da racimolare; non un brief testuale e non un sito web di prodotto. Per un input non PR (sito del prodotto, sito Web generale, testo dell'argomento), vedere /hyperframes.
