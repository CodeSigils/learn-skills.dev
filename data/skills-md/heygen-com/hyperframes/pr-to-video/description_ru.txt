Рабочий процесс pr-to-video — запрос на извлечение GitHub (URL-адрес, например github.com/<owner>/<repo>/pull/<N> или <owner>/<repo>#<N> или «этот PR» в извлеченном репозитории) -> вставленные PR-факты (заголовок, тело, разница, фиксации, файлы, +/- статистика) -> narrator_scripts.json + аудио (голос + фоновая музыка) + section_plan.md -> видео с пояснениями кода/до-после/воздействия. Ввод - ИЗМЕНЕНИЕ КОДА. URL-адрес — это PR-ссылка, а НЕ маркетинговый сайт, который можно парсить; не текстовый бриф и не сайт продукта. Для информации, не связанной с PR (сайт продукта, общий веб-сайт, текст темы), см. /hyperframes.
