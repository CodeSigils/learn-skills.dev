flux de travail pr-to-video - une demande d'extraction GitHub (URL comme github.com/<owner>/<repo>/pull/<N>, ou <owner>/<repo>#<N>, ou "ce PR" dans un dépôt extrait) -> faits PR ingérés (titre, corps, diff, commits, fichiers, +/- stats) -> narrator_scripts.json + audio (voix + BGM) + section_plan.md -> vidéo explicative code-diff / avant-après / impact. L'entrée est un CHANGEMENT DE CODE. L'URL est un lien de relations publiques, PAS un site marketing à gratter ; pas un texte bref ni un site Web de produit. Pour une entrée non PR (site produit, site Web général, texte du sujet), voir /hyperframes.
