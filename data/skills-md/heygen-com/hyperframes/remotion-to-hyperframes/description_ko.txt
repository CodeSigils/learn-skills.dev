Remotion(React 기반) 비디오 구성을 HyperFrames HTML 구성으로 변환합니다. (1) 사용자가 Remotion 소스(`useCurrentFrame`, `Sequence`, `AbsoluteFill`, `interpolate`, `spring`, `staticFile` 등을 사용하는 `.tsx` 파일)를 제공하고 이를 HyperFrames로 포팅, 변환 또는 마이그레이션하도록 요청할 때 사용합니다. (2) 사용자가 Remotion 진입점(`Root.tsx`, `Composition`)을 붙여넣고 HTML을 원합니다. (3) 사용자가 Remotion 저장소를 연결하고 이에 상응하는 HyperFrames를 요청합니다. (4) 사용자가 "내 Remotion 프로젝트 포팅", "이 Remotion 코드 번역", "HTML로 다시 작성" 또는 "Remotion 구성 요소가 있으므로 HyperFrame으로 만들어"라고 말합니다. Skill은 지원되지 않는 패턴(useState, 부작용이 있는 useEffect, 비동기 계산 메타데이터, 타사 React 구성 요소 라이브러리, `@remotion/lambda` 기능)을 감지하고 손실이 있는 변환을 시도하는 대신 런타임 상호 운용성 이스케이프 해치를 권장합니다.
