Шаблоны адаптеров API веб-анимации для HyperFrames. Используйте при создании движения element.animate(), поиска анимации currentTime, document.getAnimations(), синхронизации KeyframeEffect, режимов заливки или встроенной анимации браузера, которая должна детерминированно отображаться в HyperFrames.
