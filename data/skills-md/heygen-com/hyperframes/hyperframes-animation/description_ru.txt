Все знания по анимации для HyperFrames — правила атомарного движения, чертежи многофазных сцен, переходы сцен, более широкие методы проектирования движений и семь адаптеров среды выполнения (GSAP по умолчанию, плюс Lottie, Three.js, Anime.js, ключевые кадры CSS, API веб-анимации, TypeGPU). Используйте для любых задач, связанных с движением или анимацией: выберите 2–4 правила и составьте их, или загрузите план, или найдите API, специфичный для среды выполнения (например, GSAP Eeases/Lottie Player/Three.js Mixer). Встроенная поддержка HyperFrames: временная шкала с одной паузой, безопасная для поиска, детерминированная.
