Sämtliches Animationswissen für HyperFrames – atomare Bewegungsregeln, mehrphasige Szenenpläne, Szenenübergänge, umfassendere Motion-Design-Techniken UND die sieben Laufzeitadapter (GSAP-Standard, plus Lottie, Three.js, Anime.js, CSS-Keyframes, Web Animations API, TypeGPU). Für jede Bewegungs- oder Animationsaufgabe verwenden: Wählen Sie 2–4 Regeln aus und verfassen Sie sie, laden Sie einen Entwurf oder suchen Sie nach einer laufzeitspezifischen API (z. B. GSAP Eases / Lottie Player / Three.js Mixer). HyperFrames-nativ: einzelne pausierte Zeitleiste, suchsicher, deterministisch.
