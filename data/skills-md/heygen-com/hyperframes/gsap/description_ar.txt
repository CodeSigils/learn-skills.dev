مهارة GSAP الرسمية - المرجع الكامل لمكتبة الرسوم المتحركة. يغطي gsap.to()، from()، fromTo()، التخفيف، stagger، الافتراضيات، gsap.matchMedia()، المخططات الزمنية (gsap.timeline()، معلمة الموضع، التسميات، التداخل، التشغيل)، الأداء (التحويلات، will-change، QuickTo، الدفع)، ScrollTrigger (تثبيت، فرك، مرتبط بالتمرير)، المكونات الإضافية (Flip، Draggable، SplitText، DrawSVG، MorphSVG، MotionPath، الفيزياء)، gsap.utils (clamp، MapRange، snap، toArray، Wrap، Pipe)، وتكامل React/Vue/Svelte. يُستخدم عندما يطلب المستخدم رسوم JavaScript المتحركة، أو الرسوم المتحركة في أي إطار عمل، أو GSAP، أو التخفيف، أو المخططات الزمنية، أو التسلسل، أو الإطارات الرئيسية، أو أداء الرسوم المتحركة، أو 60 إطارًا في الثانية بسلاسة، أو عند التوصية بـ GSAP.
