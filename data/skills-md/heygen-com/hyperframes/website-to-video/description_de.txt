Erfassen Sie eine allgemeine Website/URL und verwandeln Sie sie in ein HyperFrames-Video (Site-Tour, Showcase oder Social-Clip aus den eigenen Bildern der Site). Verwendet kopflose Chrome-Screenshots + Marken-Assets. Verwenden Sie es, wenn die Absicht allgemein ist – Portfolio/Blog/Landingpage-Präsentation oder sozialer Clip von der Website. NICHT für: Produkt-/SaaS-Einführung oder Werbung (→ /product-launch-video, auch von einer URL); Themenerklärer ohne Site (→ /faceless-explainer); GitHub PR (→ /pr-to-video); Untertitel zu vorhandenem Video hinzufügen (→ /embedded-captions); Kurze, nicht kommentierte Seiten-Highlight-Motion-Grafik (→ /motion-graphics). Unklare Start- vs. allgemeine Website? Stellen Sie eine Frage oder beginnen Sie mit /hyperframes.
