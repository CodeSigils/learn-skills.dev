Cree un nuevo bloque de registro de HyperFrames (estilo de título, bloque VFX, transición, tercio inferior) o componente (efecto de texto, superposición, fragmento) y envíelo como un PR ascendente al repositorio de hiperframes. Úselo SÓLO cuando el usuario quiera CONTRIBUIR al catálogo público: para la creación de subtítulos/transiciones en el proyecto, use la habilidad "hyperframes", para instalar elementos de registro existentes, use la habilidad "hyperframes-registry".
