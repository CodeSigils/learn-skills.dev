Erstellen Sie einen neuen HyperFrames-Registrierungsblock (Beschriftungsstil, VFX-Block, Übergang, unteres Drittel) oder eine neue Komponente (Texteffekt, Overlay, Snippet) und senden Sie ihn als Upstream-PR an das Hyperframes-Repository. Verwenden Sie NUR, wenn der Benutzer einen BEITRAG zum öffentlichen Katalog leisten möchte – für die Erstellung von Untertiteln/Übergängen im Projekt verwenden Sie den Skill „Hyperframes“, für die Installation vorhandener Registrierungselemente verwenden Sie den Skill „Hyperframes-Registry“.
