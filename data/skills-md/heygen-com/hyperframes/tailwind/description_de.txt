Tailwind CSS v4.2 Browser-Laufzeitmuster für HyperFrames-Kompositionen. Verwenden Sie diese Option, wenn Sie ein Gerüst erstellen oder Projekte bearbeiten, die mit „hyperframes init --tailwind“ erstellt wurden, Tailwind-Dienstprogrammklassen in Kompositions-HTML schreiben, CSS-First-Tailwind-v4-Design-Tokens hinzufügen, die Syntax von v3 vs. v4 debuggen oder entscheiden, wann Tailwind in CSS kompiliert werden soll, anstatt die Browser-Laufzeit zu verwenden.
