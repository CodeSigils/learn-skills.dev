Шаблоны выполнения браузера Tailwind CSS v4.2 для композиций HyperFrames. Используйте при создании шаблонов или редактировании проектов, созданных с помощью `hyperframes init --tailwind`, написании служебных классов Tailwind в составе HTML, добавлении CSS-токенов темы Tailwind v4, отладке синтаксиса v3 и v4 или принятии решения о том, когда компилировать Tailwind в CSS вместо использования среды выполнения браузера.
