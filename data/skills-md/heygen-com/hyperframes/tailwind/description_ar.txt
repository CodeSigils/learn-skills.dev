أنماط وقت تشغيل المتصفح Tailwind CSS v4.2 لتركيبات HyperFrames. يُستخدم عند إنشاء مشاريع السقالات أو تحريرها باستخدام `hyperframes init --tailwind`، أو كتابة فئات الأداة المساعدة Tailwind في HTML التركيب، أو إضافة الرموز المميزة لموضوع Tailwind v4 لـ CSS-first، أو تصحيح أخطاء بناء جملة v3 مقابل v4، أو تحديد وقت تجميع Tailwind إلى CSS بدلاً من استخدام وقت تشغيل المتصفح.
