Flux de travail vidéo explicatif sans visage - texte arbitraire (article / notes / sujet / bref) -> narrator_scripts.json + audio (voix + BGM) + section_plan.md -> typographie / graphiques abstraits / diagramme / vidéo de visualisation de données. Durée typique jusqu'à ~ 3 min (sweet spot ~ 30-90 s) ; une pièce véritablement plus longue est la vidéo générale, pas ce flux de travail. Génère sa PROPRE narration (TTS) — elle ne se synchronise pas avec une voix off fournie/préenregistrée par l'utilisateur (c'est-à-dire une vidéo générale). Pas de capture de site Web, pas de captures d'écran de produits réels. Si le texte nomme un produit/son site à promouvoir, c'est/product-launch-video ; lorsque le rapport produit/sujet n'est pas clair, commencez par /hyperframes.
