Предварительная обработка ресурсов для композиций HyperFrames — преобразование текста в речь (Kokoro), транскрипция аудио/видео (Whisper) и удаление фона для прозрачных наложений (u2net). Используйте при создании закадрового голоса из текста, расшифровке речи для титров, удалении фона из видео или изображения для использования в качестве прозрачного наложения, выборе модели голоса или шепота TTS или их объединении в цепочку (TTS → расшифровка → субтитры). Каждая команда загружает свою модель при первом запуске.
