يُستخدم عندما يحتاج تكوين HyperFrames إلى إطارات رئيسية ثنائية/ثلاثية الأبعاد آمنة للبحث، أو مخططات GSAP الزمنية، أو إطارات CSS الرئيسية، أو Anime.js، أو WAAPI، أو FLIP، أو المسارات، أو الأقنعة، أو تحويل/رسم SVG، أو مسارات النص، أو العروض التوضيحية للمؤشر، أو العمق ثلاثي الأبعاد، أو تشخيصات "الإطارات التشعبية". لا تستخدمه لإستراتيجية المشهد الواسع، أو تصميم العلامة التجارية، أو مصادر الوسائط، أو التسميات التوضيحية، أو التخطيط العام للفيديو.
