Erstellen Sie eine funktionierende LiveAvatar-Demo aus einem kuratierten Katalog – klonen Sie das Referenz-Repo, installieren Sie Abhängigkeiten, stellen Sie das LiveAvatar-Konto bereit, füllen Sie die Env-Datei und übergeben Sie dann die Teile, die nur ein Mensch erledigen kann. Verwenden Sie dies, wenn: (1) der Benutzer LiveAvatar ausprobieren, testen, ansehen oder vorführen möchte, (2) der Benutzer fragt, welche LiveAvatar-Demos oder Beispiele es gibt, (3) der Benutzer einen Avatar für einen Vertriebsmitarbeiter/Lead-Qualifizierung möchte, (4) der Benutzer einen LiveKit-Agenten möchte, der einen LiveAvatar-Avatar steuert, (5) der Benutzer möchte, dass ein Avatar seinem eigenen LiveKit-Raum beitritt, (6) der Benutzer sagt: „Führen Sie die LiveAvatar-Demo aus“, „zeigen Sie mir LiveAvatar“, „holen Sie sich Ich habe mit LiveAvatar angefangen“ oder „das LiveAvatar-Beispiel klonen“ (7) Der Benutzer evaluiert LiveAvatar und möchte, dass etwas läuft, bevor er seine eigene Integration schreibt.
