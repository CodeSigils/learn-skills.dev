v3 Video Agent 파이프라인을 통해 HeyGen 발표자 비디오 생성 - 프레임 확인 처리
(가로세로 비율 보정), 신속한 엔지니어링, 아바타 해상도 및 음성 선택.
모든 HeyGen 비디오 생성에 필요합니다. 더 이상 사용되지 않는 엔드포인트를 v3으로 대체합니다.
다음과 같은 경우에 사용하세요: (1) HeyGen 비디오 생성(API 또는 기타 방법을 통해),
(2) 개인화된 영상 메시지(홍보, 업데이트, 공지, 홍보, 지식) 보내기,
(3) 사람의 얼굴을 사용하여 HeyGen 발표자가 주도하는 설명자, 튜토리얼 또는 제품 데모를 생성하고,
(4) "내가 말하는 영상을 만들어라...", "내 리드에게 비디오 보내기", "내 팀을 위한 업데이트 기록",
"영상 피치를 만들어요", "직기 스타일의 메시지를 만들어요", "이 영상에 제가 출연하고 싶어요",
"헤이젠 영상을 만들어요", "말하는 머리 영상을 만들어요".
신원 우선 HeyGen 비디오를 위해 heygen-avatar의 Avatar_id를 수락하거나 스톡 프리젠터를 사용합니다.
반복을 위해 비디오 공유 URL + HeyGen 세션 URL을 반환합니다.
체인 신호: 사용자가 동일한 요청으로 아바타를 생성/디자인하고 동영상을 만들고자 할 때,
먼저 heygen-avatar를 실행한 다음 여기로 돌아옵니다. 시청할 접속사: "그리고 나서", "그리고 즉시",
"먼저...그다음", "X하고 비디오 만들기", "[발표자]를 디자인하고 녹화" = 항상 체인입니다.
사용자가 사진을 제공하고 동영상을 원하는 경우 먼저 heygen-avatar로 라우팅하세요.
해당되지 않음: 아바타 생성 또는 신원 설정(heygen-avatar를 먼저 사용), 영화 영상
또는 발표자 없이 b-roll, 비디오 번역, TTS 전용 또는 스트리밍 아바타.
