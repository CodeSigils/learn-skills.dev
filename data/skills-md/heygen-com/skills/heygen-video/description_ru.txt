Генерация видео докладчиков HeyGen с помощью конвейера видеоагента v3 — обеспечивает проверку кадров.

Требуется для любого поколения видео HeyGen. Заменяет устаревшие конечные точки на v3.
Используйте, когда: (1) генерируете любое видео HeyGen (через API или иным образом),
(2) отправка персонализированного видеосообщения (информация, обновление, объявление, презентация, знания),
(3) создание пояснения, руководства или демонстрации продукта под руководством докладчика HeyGen с человеческим лицом,
(4) «сними видео, где я говорю...», «отправь видео моим потенциальным клиентам», «запиши обновление для моей команды»,
«создать видеоролик», «сделать сообщение в стиле ткацкого станка», «я хочу сняться в этом видео»,
«создать видео HeyGen», «сделать видео с говорящей головой».
Принимает avatar_id из heygen-avatar для видеороликов HeyGen с приоритетом идентификации или использует стандартный презентатор.
Возвращает URL-адрес общего доступа к видео + URL-адрес сеанса HeyGen для итерации.
Цепной сигнал: когда пользователь хочет создать/спроектировать аватар И сделать видео по тому же запросу,
сначала запустите heygen-avatar, а затем вернитесь сюда. Союзы для просмотра: «а потом», «и сразу»,
«сначала… потом», «Х и сними видео», «оформи [ведущего] и запиши» = всегда ЦЕПЬ.
Если пользователь предоставляет фотографию И хочет видео, сначала перейдите к heygen-avatar.
НЕ для: создания аватара или настройки личности (сначала используйте heygen-avatar), кинематографических кадров.
