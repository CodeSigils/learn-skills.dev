v3 Video Agent パイプライン経由で HeyGen アバター ビデオを作成 — アバターの解像度を処理し、
アスペクト比の補正、プロンプトエンジニアリング、音声の自動選択を行います。
HeyGen API を使用する場合に必要です (api.heygen.com)。非推奨の v1/v2 を置き換えます
最適化された v3 パイプラインを備えたエンドポイント。
次の場合に使用します: (1) HeyGen API エンドポイント (api.heygen.com) を呼び出す場合
(2) 写真から HeyGen アバターまたはデジタル ツインを作成する。
(3) パーソナライズされたビデオメッセージの作成 (アウトリーチ、売り込み、最新情報、発表、知識)、
(4) 「私のビデオを作ってください」、「私のHeyGenアバターを作成してください」、「このビデオに出演したいです」、
(5) 「リードにビデオを送信する」、「チームへの最新情報を記録する」、「織機スタイルのメッセージを作成する」、
(6) プレゼンターがユーザーまたはエージェントであるアイデンティティ優先のビデオを作成する。
対象: HeyGen API、api.heygen.com、ビデオ生成、アバター作成、音声リスト、トーキングフォト、
HeyGenアバター作成、ボイスデザイン、写真→デジタルツイン、HeyGenビデオ生成、
アイデンティティ優先のビデオ、メッセージング優先のビデオ、AI プレゼンター、トーキング ヘッド ビデオ。
対象外: 映画の B ロール、ビデオ翻訳、TTS のみ、またはストリーミング アバター。
