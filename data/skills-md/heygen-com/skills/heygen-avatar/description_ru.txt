Создайте постоянный аватар HeyGen — многоразовое лицо + голосовой идентификатор агента,
пользователь или любой персонаж с именем — на основе технологии HeyGen Avatar V.
Создание по подсказке по умолчанию (описание → HeyGen собирает); загрузка фотографий
необязательно для цифровых двойников реального человека.
Используйте, когда: (1) даете агенту лицо + голос, чтобы он мог представлять видео.
(«оживи себя», «создай свою аватарку», «подари себе аватарку»,
«оформить ведущего», «настроить аватарку», «сделаем аватарку»),
(2) пользователь хочет появляться в видео как он сам («создать мой аватар»,
«Я хочу, чтобы мое лицо было на видео», «Я цифровой двойник», «Сделай мне аватар»),
(3) создание ведущего именного персонажа («создайте аватар по имени Клео»,
«создать персонажа по имени X»), (4) установить идентичность HeyGen перед созданием видео —
правильный ПЕРВЫЙ шаг, когда аватара еще не существует.
Цепной сигнал: когда пользователь произносит одновременно действие с изображением личности/аватара И видеодействие
запрос («создайте аватар И снимите видео», «настройте личность, ЗАТЕМ создайте видео»,
«создать ведущего И сразу записать»), сначала запустите heygen-avatar, затем heygen-video.
Возвращает avatar_id + voice_id — переход непосредственно к heygen-video для создания видеороликов HeyGen.
НЕ для: создания видео (используйте heygen-video), перевода видео или задач только с TTS.
