재사용 가능한 얼굴 + 에이전트의 음성 ID인 영구 HeyGen 아바타를 만듭니다.
사용자 또는 명명된 캐릭터 - HeyGen Avatar V 기술로 구동됩니다.
기본적으로 프롬프트 기반 생성(설명 → HeyGen이 빌드함); 사진 업로드는
실제 사람 디지털 트윈의 경우 선택 사항입니다.
다음과 같은 경우에 사용하세요. (1) 상담원에게 얼굴과 음성을 제공하여 동영상을 보여줄 수 있도록 합니다.
("자신에게 생기를 불어넣으세요", "자신에게 아바타를 만들어주세요", "자신에게 아바타를 만들어주세요",
"프레젠터 디자인하기", "아바타 설정하기", "아바타를 만들자"),
(2) 사용자가 자신의 모습으로 동영상에 출연하기를 원합니다("나의 아바타 만들기",
"내 얼굴을 동영상으로 만들고 싶어요", "나의 디지털 트윈", "아바타 만들기"),
(3) 네임드 캐릭터 프리젠터 구축("클레오라는 아바타 생성",
"X라는 캐릭터를 디자인하세요"), (4) 영상을 만들기 전에 HeyGen 아이덴티티 확립 —
아직 아바타가 없을 때 올바른 첫 번째 단계입니다.
체인 신호: 사용자가 신원/아바타 작업과 비디오 작업을 동시에 말하는 경우
요청("아바타 만들기 및 비디오 만들기", "신원 설정 후 비디오 만들기",
"발표자를 디자인하고 즉시 녹화하세요.") 먼저 heygen-avatar를 실행한 다음 heygen-video를 실행하세요.
Avatar_id + voice_id를 반환합니다. HeyGen 비디오를 생성하려면 heygen-video에 직접 전달하세요.
해당되지 않음: 비디오 생성(heygen-video 사용), 비디오 번역 또는 TTS 전용 작업.
