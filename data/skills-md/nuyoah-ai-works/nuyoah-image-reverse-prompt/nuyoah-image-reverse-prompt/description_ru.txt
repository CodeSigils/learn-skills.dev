Используйте, когда пользователь предоставляет эталонное изображение и просит выполнить реверс-инжиниринг изображения, деконструировать сцену, извлечь структурные термины, проанализировать композицию, цвет и материал и сгенерировать слова-подсказки на китайском языке, которые могут напрямую создать новое изображение; явно требует калибровки этого навыка путем создания возвращаемого изображения или явно запрашивает проверку или обновление самого «Навыка обратного инжиниринга изображений Нань Юань». Обычные звонки предоставляют только структурные разбивки, эталонные образцы цветов и подсказки, которые можно копировать; они не предназначены для обхода анализа для прямого создания изображений, для рутинного редактирования изображений или для написания общих подсказок без эталонного изображения.
