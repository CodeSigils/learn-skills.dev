Se utiliza cuando el usuario proporciona una imagen de referencia y solicita aplicar ingeniería inversa a la imagen, deconstruir la escena, extraer términos estructurales, analizar la composición, el color y el material, y generar palabras clave en chino que puedan producir directamente una nueva imagen; requiere explícitamente calibrar esta habilidad generando una imagen devuelta, o solicita explícitamente verificar o actualizar la "Habilidad de ingeniería inversa de imágenes de Nan Yuan" en sí. Las llamadas ordinarias sólo ofrecen desgloses estructurales, muestras de colores de referencia e indicaciones que se pueden copiar; no son para omitir el análisis para generar imágenes directamente, para la edición de imágenes de rutina o para escribir indicaciones genéricas sin una imagen de referencia.
