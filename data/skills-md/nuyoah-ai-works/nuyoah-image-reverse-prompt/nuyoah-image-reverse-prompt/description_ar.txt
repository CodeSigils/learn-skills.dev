يُستخدم عندما يقدم المستخدم صورة مرجعية ويطلب إجراء هندسة عكسية للصورة، وتفكيك المشهد، واستخراج المصطلحات الهيكلية، وتحليل التركيب واللون والمواد، وإنشاء كلمات سريعة صينية يمكنها إنتاج صورة جديدة مباشرة؛ يتطلب صراحة معايرة هذه المهارة عن طريق إنشاء صورة تم إرجاعها، أو يطلب صراحة فحص أو تحديث "مهارة الهندسة العكسية لصور Nan Yuan" نفسها. لا تقدم الاستدعاءات العادية سوى تفاصيل هيكلية وحوامل ألوان مرجعية ومطالبات قابلة للنسخ؛ فهي ليست مخصصة لتجاوز التحليل لإنشاء الصور مباشرة، أو لتحرير الصور الروتيني، أو لكتابة مطالبات عامة بدون صورة مرجعية.
