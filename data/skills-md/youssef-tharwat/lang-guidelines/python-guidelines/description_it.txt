Applica le regole di lanugine Python (Ruff), le linee guida di progettazione (Google) e i modelli idiomatici Python (Brandon Rhodes) per tutte le generazioni e le modifiche del codice Python. Le regole devono essere applicate durante la scrittura del codice, non solo durante la revisione. Si attiva su qualsiasi attività che scriva, modifichi o effettui il refactoring del codice Python.
