Этот навык следует использовать, когда пользователь просит «запомнить контекст проекта», «сохранить данные SEO», «отслеживать ход кампании», «хранить данные ключевых слов», «управлять памятью проекта», «запомнить это для следующего раза», «сохранить данные моих ключевых слов» или «отслеживать эту кампанию». Управляет двухуровневой системой памяти (горячий кэш + холодное хранилище) для контекста проекта SEO/GEO, отслеживания ключевых слов, конкурентов, показателей и статуса кампании с помощью интеллектуального продвижения/понижения.
