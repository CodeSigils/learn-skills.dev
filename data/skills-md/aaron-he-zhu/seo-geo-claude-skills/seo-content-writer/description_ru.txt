Этот навык следует использовать, когда пользователь просит «написать SEO-контент», «создать сообщение в блоге», «написать статью», «написать контент для SEO», «проектировать оптимизированный контент», «написать практическое руководство», «создать описание продукта», «написать целевую страницу», «SEO-копирайтинг», «проектировать контент с таргетингом на [ключевое слово]» или «написать статью на 2000 слов по [теме]». Создает контент, оптимизированный по ключевым словам, с помощью 12-этапного рабочего процесса: контрольный список предварительного написания CORE-EEAT, интеграция ключевых слов, оптимизация заголовка (5 вариантов формулы), метаописание, иерархия H1/H2/H3, таргетинг избранных фрагментов, внутренние/внешние ссылки и повышение читаемости. Создает полные черновики со встроенными элементами SEO, вариантами заголовков, метаописанием, разделом часто задаваемых вопросов со схемой и контрольным списком CORE-EEAT для самостоятельной оценки. Информацию об оптимизации цитирования с помощью искусственного интеллекта см. в разделе Geo-content-Optimizer. Для обновления существующего контента см. Content-Refresher.
