Cree, configure y ejecute agentes de IA utilizando la especificación GitAgent y el tiempo de ejecución de GitClaw. Úselo cuando el usuario quiera crear un agente de IA, desarrollar una carpeta de agente, escribir SOUL.md/RULES.md/skills, ejecutar agentes con GitClaw, exportar agentes, configurar el cumplimiento, conectar aplicaciones externas, crear flujos de trabajo, configurar enlaces, administrar subagentes o cualquier cosa relacionada con GitAgent/GitClaw.
