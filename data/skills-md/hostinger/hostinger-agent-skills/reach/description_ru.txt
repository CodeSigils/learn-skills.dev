API Hostinger Reach (маркетинг по электронной почте) для управления контактами, сегментации и управления профилями. Используйте при создании или перечислении контактов, управлении сегментами контактов, фильтрации контактов по группам или статусу подписки, а также при работе с профилями электронного маркетинга.
