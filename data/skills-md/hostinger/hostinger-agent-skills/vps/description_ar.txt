Hostinger VPS API لإدارة الأجهزة الافتراضية، ومشاريع Docker، وجدران الحماية، ومفاتيح SSH، والنسخ الاحتياطية، واللقطات، وقوالب نظام التشغيل، والبرامج النصية لما بعد التثبيت، ووضع الاسترداد، ومسح البرامج الضارة، وسجلات PTR، والمقاييس. يُستخدم عند إنشاء مثيلات VPS أو إدارتها أو استكشاف أخطاءها وإصلاحها، أو نشر حاويات Docker، أو تكوين جدران الحماية، أو إدارة البنية الأساسية للخادم.
