Создавайте доступные компоненты пользовательского интерфейса с помощью компонентов React Aria. Используйте, когда разработчики упоминают React Aria, реакции-aria-компоненты, доступные компоненты или им нужны доступные примитивы без стилей. Предоставляет документацию для создания пользовательского доступного пользовательского интерфейса с помощью перехватчиков и компонентов.
