أنشئ مكونات واجهة مستخدم يمكن الوصول إليها باستخدام React Aria Components. يُستخدم عندما يذكر المطورون React Aria، أو مكونات رد الفعل، أو المكونات التي يمكن الوصول إليها، أو عندما يحتاجون إلى عناصر أولية يمكن الوصول إليها بدون نمط. يوفر وثائق لبناء واجهة مستخدم مخصصة يمكن الوصول إليها باستخدام الخطافات والمكونات.
