Этот навык следует использовать, когда пользователь запрашивает «запустить тест e2e», «тестировать clawteam», «сквозное тестирование», «команду агента тестирования», «проверить работу clawteam», «тест разработки» или хочет проверить полный жизненный цикл ClawTeam. Запускает полный комплексный тест: очистка → создание команды → создание задач с зависимостями → создание агентов → ожидание завершения → проверка результатов → очистка.
