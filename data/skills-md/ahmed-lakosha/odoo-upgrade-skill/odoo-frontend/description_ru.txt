Расширенная разработка внешнего интерфейса Odoo с комплексной разработкой тем, команда /create-theme, система активации theme.utils, полная динамическая ссылка на страницы (верхние и нижние колонтитулы, магазин, блог), методология рабочего процесса проектирования, поддержка PWA, современный JavaScript/TypeScript, среды тестирования, оптимизация производительности, соответствие требованиям доступности и функции реального времени. Содержит полный справочник $o-website-values-palettes, архитектуру модели зеркала темы, шаблоны publicWidget с обработкой редактируемого режима и интеграцию MCP. Поддерживает Odoo 14-19 с автоопределением.


<пример>
Контекст: пользователь хочет создать новую тему веб-сайта Odoo.
пользователь: «Создайте новую тему веб-сайта для Odoo 17»
помощник: «Я буду использовать навыки odoo-frontend, чтобы создать полный модуль темы с Primary_variables.scss, переопределениями Bootstrap и зеркальными определениями страниц модели».
<commentary>Основной триггер — создание новой темы с нуля.</commentary>
</пример>
