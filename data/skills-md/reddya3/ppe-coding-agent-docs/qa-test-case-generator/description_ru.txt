**НАВЫКИ РАБОЧЕГО ПРОЦЕССА** — Создавайте подробные тестовые примеры на основе тестовых сценариев. ИСПОЛЬЗОВАНИЕ ДЛЯ: расширения сценариев тестирования высокого уровня в пошаговые исполняемые тестовые сценарии; создание тестовых примеров с точными шагами, данными и ожидаемыми результатами; создание формата BDD/Gherkin; создание вариантов тестовых примеров на основе данных; построение наборов регрессий из списков сценариев. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: чтения историй Jira (используйте qa-test-planner); написание кода автоматизации; выполнение тестов. ВЫЗОВЫ: файловые инструменты (запись документов тестовых примеров).
