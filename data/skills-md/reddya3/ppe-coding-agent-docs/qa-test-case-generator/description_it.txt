**CAPEVOLEZZA DEL FLUSSO DI LAVORO** — Genera casi di test dettagliati da scenari di test. UTILIZZARE PER: espandere scenari di test di alto livello in casi di test eseguibili passo dopo passo; produrre casi di test con passaggi, dati e risultati attesi precisi; generazione del formato BDD/Gherkin; creazione di varianti di test case basate sui dati; creazione di suite di regressione da elenchi di scenari. NON UTILIZZARE PER: leggere storie di Jira (utilizzare qa-test-planner); scrivere codice di automazione; esecuzione di test. INVOCA: strumenti di file (scrivere documenti di casi di test).
