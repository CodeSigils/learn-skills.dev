**COMPÉTENCE DE WORKFLOW** — Générez des cas de test détaillés à partir de scénarios de test. UTILISER POUR : étendre des scénarios de test de haut niveau en cas de test exécutables étape par étape ; produire des cas de test avec des étapes, des données et des résultats attendus précis ; générer le format BDD/Gherkin ; créer des variantes de cas de test basées sur les données ; construire des suites de régression à partir de listes de scénarios. NE PAS UTILISER POUR : lire des histoires Jira (utilisez qa-test-planner) ; écrire du code d'automatisation ; exécuter des tests. INVOKES : outils de fichiers (rédiger des documents de cas de test).
