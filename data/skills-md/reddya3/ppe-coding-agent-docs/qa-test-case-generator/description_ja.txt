**ワークフロー スキル** — テスト シナリオから詳細なテスト ケースを生成します。用途: 高レベルのテスト シナリオをステップバイステップの実行可能なテスト ケースに拡張します。正確な手順、データ、および期待される結果を含むテスト ケースを作成します。 BDD/Gherkin フォーマットを生成します。データ駆動型のテスト ケースのバリアントを作成する。シナリオリストから回帰スイートを構築します。次の用途には使用しないでください: Jira ストーリーの読み取り (qa-test-planner を使用)。自動化コードの作成。テストを実行しています。呼び出し: ファイル ツール (テスト ケース ドキュメントの作成)。
