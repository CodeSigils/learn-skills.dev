Рабочий процесс эксперта по тестированию программного обеспечения для анализа историй Jira и разработки сценариев тестирования. Используйте, когда пользователи просят проанализировать истории, критерии приемки и требования, определить покрытие и риски, а также подготовить выходные данные сценария, готовые для последующего создания тестовых примеров.
