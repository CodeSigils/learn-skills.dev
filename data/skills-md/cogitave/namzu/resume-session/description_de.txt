Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer bestehende Entwurfs-, Architektur- oder Planungsarbeiten wieder aufnimmt oder wenn ein neuer Agent die Arbeit übernimmt und den vorherigen Kontext lokalisieren muss. Zu den Auslösern gehören Verweise auf „das letzte Mal“, „wo wir aufgehört haben“, „die <slug>-Sitzung“, „den Refactor fortsetzen“, jede Erwähnung einer Sitzungs-ID wie „ses_001“ oder Unklarheiten darüber, welche Arbeit gerade ausgeführt wird. Verwenden Sie dies immer, bevor Sie mit einer neuen Arbeit beginnen, für die möglicherweise bereits eine Sitzung geöffnet ist. Durch das Erstellen einer doppelten Sitzung geht der Kontext verloren und Entscheidungen werden fragmentiert.
