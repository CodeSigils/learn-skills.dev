Aplica la Guía de estilo de JavaScript de Airbnb al escribir código JS, JSX o TypeScript. Esta habilidad debe usarse siempre que se escriba, revise o genere código JavaScript, JSX o TypeScript para garantizar que siga los estándares de codificación de Airbnb para variables, funciones, clases, módulos, nombres, formato y patrones React/JSX.
