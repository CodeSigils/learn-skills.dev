Applique le guide de style JavaScript Airbnb lors de l'écriture de code JS, JSX ou TypeScript. Cette compétence doit être utilisée lors de l'écriture, de la révision ou de la génération de code JavaScript, JSX ou TypeScript pour garantir qu'il respecte les normes de codage d'Airbnb pour les variables, les fonctions, les classes, les modules, la dénomination, le formatage et les modèles React/JSX.
