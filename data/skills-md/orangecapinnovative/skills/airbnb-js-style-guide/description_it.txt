Applica la Guida allo stile JavaScript di Airbnb durante la scrittura di codice JS, JSX o TypeScript. Questa competenza dovrebbe essere utilizzata ogni volta che si scrive, si rivede o si genera codice JavaScript, JSX o TypeScript per garantire che segua gli standard di codifica di Airbnb per variabili, funzioni, classi, moduli, denominazione, formattazione e pattern React/JSX.
