اكتب Polars الاصطلاحية السريعة في Python باستخدام واجهة برمجة التطبيقات البطيئة، وأجب عن أسئلة اللغة الطبيعية حول البيانات في طلقة واحدة. استخدم هذه المهارة عندما تتضمن المهمة تحميل البيانات الجدولية أو الاستعلام عنها أو تحويلها أو تجميعها أو ضمها أو تحليلها (CSV أو Parquet أو NDJSON أو DataFrames). top-k، الاتجاهات، فترة بعد فترة، التوزيعات، السلاسل الزمنية، حصة الإجمالي، أو كتابة أو تصحيح الأخطاء أو تسريع كود Polars، أو ترجمة الباندا إلى Polars. ينطبق حتى عندما لا يقول المستخدم "Polars"، وهو الإعداد الافتراضي لعمل بيانات Python عندما لا يتم تحديد مكتبة dataframe. يغطي التعبيرات، ووظائف النوافذ، والتجميعات الجانبية، والانضمامات، ومحرك التدفق للبيانات الأكبر من الذاكرة، وترحيل الباندا. ليس لأحمال عمل Polars Cloud أو On-Prem أو الموزعة أو GPU.
