Lazy API を使用して Python で高速かつ慣用的な Polars を作成し、データに関する自然言語の質問に一発で答えます。タスクに表形式データ (CSV、Parquet、NDJSON、または DataFrame) のロード、クエリ、変換、集計、結合、または分析が含まれる場合は常に、このスキルを使用します。トップ K、トレンド、前期比、分布、時系列、全体シェア、または Polars コードの作成、デバッグ、高速化、またはパンダから Polars への変換。ユーザーが「Polars」と言わなくても適用され、データフレーム ライブラリが指定されていない場合の Python データ作業のデフォルトです。式、ウィンドウ関数、group-by、結合、メモリを超えるデータのストリーミング エンジン、パンダの移行について説明します。 Polars Cloud、オンプレミス、分散、または GPU ワークロードには対応しません。
