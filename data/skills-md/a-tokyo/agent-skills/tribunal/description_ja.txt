実行者 -> 検証者パネル -> コンセンサス ループを実行して、成果物を出荷前に検証します。オーケストレーターは、実装前に受け入れ基準を凍結し、実行者を派遣し、その後、台帳に記録される SHIP / SHIP_WITH_CAVETS / ITERATE / BLOCK / ESCALATE の評決に基づいて裁定された証拠に基づいたレビューのために、明示的な反対義務を負った敵対者を含む、独立した検証者からなるコンテキストの壁に囲まれたパネルを招集します。成果物の検証、計画の精査、コンセンサスレビューまたは独立したレビューの実行、実行者と検証者のループの設定、または出荷の決定のゲートを求められた場合に、コードスライス、計画、文書、監査などの成果物のマルチエージェント検証に使用します。並列サブエージェントを備えたあらゆるプラットフォームで動作します。これらがないと、連続した新しいコンテキスト セッションに低下します。単純な単一ファイルの編集や通常のコードレビューには向きません。
