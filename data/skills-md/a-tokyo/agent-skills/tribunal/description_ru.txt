Запускает цикл исполнитель -> панель верификатора -> консенсусный цикл для проверки результата перед его отправкой. Оркестратор замораживает критерии приемки перед реализацией, отправляет исполнителя, а затем созывает группу независимых проверяющих, изолированную от контекста, включая противника с явным мандатом на обязательное противодействие, для проверки, привязанной к доказательствам, на основе вердикта SHIP / SHIP_WITH_CAVEATS / ITERATE / BLOCK / ESCALATE, зарегистрированного в реестре. Используйте для многоагентной проверки любого артефакта — фрагментов кода, планов, документов, аудитов — всякий раз, когда вас просят проверить результат, проверить план, провести консенсусную проверку или независимую проверку, настроить цикл исполнитель-проверяющий или принять решение об отправке. Работает на любой платформе с параллельными субагентами; без них деградирует до последовательных сеансов со свежим контекстом. Не для тривиального редактирования одного файла или обычного обзора кода.
