Exécute une boucle de consensus faiseur -> panneau de vérification -> pour vérifier un livrable avant son expédition. Un orchestrateur gèle les critères d'acceptation avant la mise en œuvre, envoie un exécutant, puis convoque un panel de vérificateurs indépendants cloisonnés dans le contexte - y compris un adversaire avec un mandat explicite de devoir s'opposer - pour un examen ancré par des preuves attribué à un verdict SHIP / SHIP_WITH_CAVEATS / ITERATE / BLOCK / ESCALATE enregistré dans un grand livre. À utiliser pour la vérification multi-agents de tout artefact (tranches de code, plans, documents, audits) chaque fois qu'on lui demande de vérifier un livrable, de contrôler un plan, d'effectuer un examen consensuel ou un examen indépendant, de mettre en place une boucle d'acteur-vérificateur ou de prendre une décision d'expédition. Fonctionne sur n'importe quelle plateforme avec des sous-agents parallèles ; se dégrade en sessions séquentielles dans un nouveau contexte sans eux. Pas pour des modifications triviales d’un seul fichier ou une révision de code ordinaire.
