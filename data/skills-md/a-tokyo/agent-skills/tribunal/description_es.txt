Ejecuta un hacedor -> panel verificador -> bucle de consenso para verificar un entregable antes de enviarlo. Un orquestador congela los criterios de aceptación antes de la implementación, envía a un hacedor y luego convoca a un panel de verificadores independientes, incluido un adversario con un mandato explícito de oposición, para una revisión basada en evidencia adjudicada a un veredicto SHIP / SHIP_WITH_CAVEATS / ITERATE / BLOCK / ESCALATE registrado en un libro mayor. Úselo para la verificación de múltiples agentes de cualquier artefacto (porciones de código, planes, documentos, auditorías) siempre que se le solicite verificar un entregable, examinar un plan, ejecutar una revisión de consenso o una revisión independiente, configurar un circuito de hacedor-verificador o controlar una decisión de envío. Funciona en cualquier plataforma con subagentes paralelos; se degrada a sesiones secuenciales de nuevo contexto sin ellos. No apto para ediciones triviales de un solo archivo o revisión de código ordinaria.
