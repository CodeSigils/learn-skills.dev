Führt eine Doer -> Verifier-Panel -> Konsensschleife aus, um eine Lieferung zu überprüfen, bevor sie versendet wird. Ein Orchestrator friert die Akzeptanzkriterien vor der Implementierung ein, entsendet einen Macher und beruft dann ein kontextbewehrtes Gremium unabhängiger Prüfer ein – einschließlich eines Gegners mit einem ausdrücklichen Pflicht-Einspruchsmandat – für eine evidenzbasierte Überprüfung, die auf der Grundlage eines SHIP-/SHIP_WITH_CAVEATS-/ITERATE-/BLOCK-/ESCALATE-Urteils entschieden wird, das in einem Hauptbuch protokolliert wird. Verwenden Sie es für die Multi-Agent-Verifizierung beliebiger Artefakte – Code-Slices, Pläne, Dokumente, Audits – wann immer Sie aufgefordert werden, eine Leistung zu verifizieren, einen Plan zu überprüfen, eine Konsensüberprüfung oder unabhängige Überprüfung durchzuführen, eine Macher-Verifizierer-Schleife einzurichten oder eine Schiffsentscheidung zu treffen. Funktioniert auf jeder Plattform mit parallelen Subagenten; ohne sie wird zu sequentiellen Fresh-Context-Sitzungen degradiert. Nicht für triviale Einzeldateibearbeitungen oder gewöhnliche Codeüberprüfungen.
