Esegue un ciclo di esecuzione -> pannello di verifica -> consenso per verificare un risultato prima della spedizione. Un orchestratore congela i criteri di accettazione prima dell'implementazione, invia un agente, quindi convoca un gruppo di verificatori indipendenti delimitato dal contesto - incluso un avversario con un mandato esplicito di opposizione - per una revisione ancorata alle prove aggiudicata a un verdetto SHIP / SHIP_WITH_CAVEATS / ITERATE / BLOCK / ESCALATE registrato in un registro. Utilizzabile per la verifica multi-agente di qualsiasi elemento (parti di codice, piani, documenti, audit) ogni volta che viene richiesto di verificare un risultato finale, esaminare un piano, eseguire una revisione consensuale o una revisione indipendente, impostare un ciclo di verifica dell'agente o bloccare una decisione sulla nave. Funziona su qualsiasi piattaforma con subagenti paralleli; senza di essi si degrada a sessioni sequenziali di nuovo contesto. Non per banali modifiche a file singoli o per la normale revisione del codice.
