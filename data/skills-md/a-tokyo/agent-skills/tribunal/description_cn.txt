运行执行者 -> 验证者面板 -> 共识循环以在交付之前验证可交付成果。协调者在实施之前冻结验收标准，派遣执行者，然后召集一个由独立验证者组成的背景墙小组（包括具有明确的必须反对授权的对手），以进行证据锚定的审查，对记录到分类账的 SHIP / SHIP_WITH_CAVEATS / ITERATE / BLOCK / ESCALATE 判决进行裁决。用于对任何工件（代码切片、计划、文档、审计）进行多代理验证，无论何时需要验证可交付成果、审查计划、运行共识审查或独立审查、设置执行者-验证者循环或控制船舶决策。可在任何具有并行子代理的平台上工作；如果没有它们，就会降级为连续的新鲜上下文会话。不适用于琐碎的单文件编辑或普通代码审查。
