Заводские навыки, которые создают проверенные, автономно улучшаемые и проверенные навыки агентов производственного уровня. Организует пятиэтапный конвейер: интервьюирует пользователя, чтобы узнать цель и золотые стандарты, исследует материалы предметной области с параллельными субагентами, разрабатывает навык с использованием подхода «сначала дизайн», запускает автоматическое исследование для итерации против оценки LLM как судьи, основанной на золотых стандартах, и проверяет качество посредством межагентного консенсуса с «адвокатом дьявола». Используйте при создании нового навыка, создании навыка из существующих материалов или повышении качества навыка до производственного качества с помощью сравнительного анализа и автономного улучшения.
