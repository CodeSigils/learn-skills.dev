Fabrikkompetenz, die produktionstaugliche, Benchmarking-, autonom verbesserte und verifizierte Agentenfähigkeiten schafft. Orchestriert eine 5-Phasen-Pipeline: Befragen Sie den Benutzer, um Zweck und Goldstandards zu ermitteln, recherchieren Sie Domänenmaterialien mit parallelen Subagenten, entwerfen Sie die Fertigkeit mit einem Design-First-Ansatz, rufen Sie Autoresearch auf, um gegen die Goldstandard-gesteuerte LLM-als-Richter-Bewertung zu iterieren, und überprüfen Sie die Qualität durch Konsens mehrerer Agenten mit einem Teufelsanwalt. Verwenden Sie es, wenn Sie eine neue Fertigkeit aufbauen, eine Fertigkeit aus vorhandenen Materialien erstellen oder eine Fertigkeit mit Benchmarking und autonomer Verbesserung auf Produktionsqualität aufrüsten.
