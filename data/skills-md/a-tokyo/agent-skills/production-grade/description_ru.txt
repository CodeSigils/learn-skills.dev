Принципиальная инженерная позиция для кода производственного уровня. Классификация проблем (A/B/C) перед реализацией, планирование перед написанием кода, сначала простейшее правильное решение, сначала математика (закрытая форма перед циклом), алгоритмы уровня ACM, базы данных EXPLAIN-first с отдельными планами миграции данных, никогда-N+1, идемпотентная атомарная запись, сначала в реальном времени, параллельная по умолчанию, схемы с поддержкой графов, восстановление после сбоя, внутренняя проверка на границах, наблюдаемые поверхности как архитектура (SEO/a11y/perf), искусственный интеллект/LLM как типизированные конвейеры, свободная парадигма (SOLID+GoF / FP), 12-факторная, экономичная CI, хирургические PR, TDD-управляемая E2E, согласованная во время выполнения инфраструктура, устранение зависимостей, миграционный аудит, безопасность, основанная на доказательствах, проверка валюты. Сначала читает локальный репозиторий, сопоставляет соглашения, извлекает последние версии документации после отзыва по окончании обучения, доверяет навыкам коллег на своих линиях. Субстратно-агностический. Используйте для нетривиального планирования, проектирования, реализации, проверки, рефакторинга, RCA и усиления защиты унаследованного или сгенерированного кода.
