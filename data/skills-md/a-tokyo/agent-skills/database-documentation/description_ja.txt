実際のスキーマと 100% 同等に達する、根拠と検証が行われた、エンジンに依存しないデータベース ドキュメントを生成します。 LIVE データベースをグラウンド トゥルースとしてイントロスペクトし、ORM モデル、移行、生成された型、シード、およびアプリケーション クエリに対して相互検証し、ドキュメントをデータベースと比較して完全性を証明します。 ER 図 (マーメイド)、テーブルごとのデータ ディクショナリ、および機械可読な schema.json を生成します。あらゆる ORM (Prisma、TypeORM、Drizzle、Sequelize、Knex、Django、Rails) または生の SQL にわたる PostgreSQL、MySQL、SQL Server、および SQLite で動作します。データベースの文書化、ERD またはデータ ディクショナリの作成、データベース/スキーマ ドキュメントの作成、スキーマ ドリフトの監査、または既存の DB ドキュメントの更新を求められた場合に使用します。
