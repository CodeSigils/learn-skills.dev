Genere documentación de base de datos independiente del motor, fundamentada y verificada, que alcance el 100 % de paridad con el esquema real. Realiza una introspección de la base de datos LIVE como verdad básica y la valida de forma cruzada con modelos ORM, migraciones, tipos generados, semillas y consultas de aplicaciones, luego demuestra que está completa comparando los documentos con la base de datos. Produce diagramas ER (sirena), diccionarios de datos por tabla y un esquema.json legible por máquina. Funciona con PostgreSQL, MySQL, SQL Server y SQLite en cualquier ORM (Prisma, TypeORM, Drizzle, Sequelize, Knex, Django, Rails) o SQL sin formato. Úselo cuando se le solicite documentar una base de datos, producir un ERD o un diccionario de datos, escribir documentos de base de datos/esquema, auditar la deriva del esquema o actualizar documentos de base de datos existentes.
