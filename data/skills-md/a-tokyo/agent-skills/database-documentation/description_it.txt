Genera documentazione di database fondata e verificata, indipendente dal motore, che raggiunge il 100% di parità con lo schema reale. Esamina il database LIVE come verità fondamentale e lo convalida in modo incrociato rispetto a modelli ORM, migrazioni, tipi generati, seed e query applicative, quindi dimostra la completezza confrontando i documenti con il database. Produce diagrammi ER (sirena), dizionari dati per tabella e uno schema.json leggibile dalla macchina. Funziona con PostgreSQL, MySQL, SQL Server e SQLite su qualsiasi ORM (Prisma, TypeORM, Drizzle, Sequelize, Knex, Django, Rails) o SQL non elaborato. Da utilizzare quando viene richiesto di documentare un database, produrre un ERD o un dizionario dati, scrivere documenti DB/schema, controllare la deriva dello schema o aggiornare documenti DB esistenti.
