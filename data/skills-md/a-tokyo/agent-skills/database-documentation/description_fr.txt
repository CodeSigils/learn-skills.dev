Générez une documentation de base de données fondée et vérifiée, indépendante du moteur, qui atteint une parité de 100 % avec le schéma réel. Introspecte la base de données LIVE en tant que vérité terrain et la valide de manière croisée par rapport aux modèles ORM, aux migrations, aux types générés, aux graines et aux requêtes d'application, puis prouve son exhaustivité en comparant les documents à la base de données. Produit des diagrammes ER (sirène), des dictionnaires de données par table et un schéma.json lisible par machine. Fonctionne avec PostgreSQL, MySQL, SQL Server et SQLite sur n'importe quel ORM (Prisma, TypeORM, Drizzle, Sequelize, Knex, Django, Rails) ou SQL brut. À utiliser lorsqu'on vous demande de documenter une base de données, de produire un ERD ou un dictionnaire de données, d'écrire des documents de base de données/schéma, d'auditer la dérive du schéma ou d'actualiser des documents de base de données existants.
