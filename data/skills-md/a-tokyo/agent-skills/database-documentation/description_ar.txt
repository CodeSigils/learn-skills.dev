قم بإنشاء وثائق قاعدة بيانات مؤرضة وتم التحقق منها وغير مرتبطة بالمحرك والتي تصل إلى 100% من التكافؤ مع المخطط الحقيقي. يفحص قاعدة البيانات LIVE كحقيقة أساسية ويتحقق من صحتها مقابل نماذج ORM وعمليات الترحيل والأنواع التي تم إنشاؤها والبذور واستعلامات التطبيق، ثم يثبت الاكتمال عن طريق مقارنة المستندات مرة أخرى بقاعدة البيانات. يُنتج مخططات ER (حورية البحر)، وقواميس بيانات لكل جدول، وschema.json قابل للقراءة آليًا. يعمل مع PostgreSQL، وMySQL، وSQL Server، وSQLite عبر أي ORM (Prisma، وTypeORM، وDrizzle، وSequelize، وKnex، وDjango، وRails) أو SQL الخام. استخدمه عند مطالبتك بتوثيق قاعدة بيانات، أو إنتاج ERD أو قاموس بيانات، أو كتابة مستندات قاعدة البيانات/المخطط، أو تدقيق انحراف المخطط، أو تحديث مستندات قاعدة البيانات الموجودة.
