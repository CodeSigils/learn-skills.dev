產生經過驗證、與引擎無關的資料庫文檔，與真實模式達到 100% 一致。將即時資料庫作為基本事實進行內省，並根據 ORM 模型、遷移、生成的類型、種子和應用程式查詢進行交叉驗證，然後透過將文件與資料庫進行比較來證明完整性。產生 ER 圖（美人魚）、每表資料字典和機器可讀的 schema.json。可跨任何 ORM（Prisma、TypeORM、Drizzle、Sequelize、Knex、Django、Rails）或原始 SQL 與 PostgreSQL、MySQL、SQL Server 和 SQLite 搭配使用。當要求記錄資料庫、產生 ERD 或資料字典、編寫資料庫/架構文件、審核架構漂移或刷新現有資料庫文件時使用。
