Создавайте обоснованную и проверенную, независимую от механизма документацию базы данных, которая достигает 100% соответствия реальной схеме. Анализирует базу данных LIVE как достоверную информацию и перекрестно проверяет ее на соответствие моделям ORM, миграциям, сгенерированным типам, начальным значениям и запросам приложений, а затем доказывает полноту, сравнивая документы с базой данных. Создает ER-диаграммы (русалка), словари данных для каждой таблицы и машиночитаемый файл Schema.json. Работает с PostgreSQL, MySQL, SQL Server и SQLite в любом ORM (Prisma, TypeORM, Drizzle, Sequelize, Knex, Django, Rails) или необработанном SQL. Используйте, когда вас просят документировать базу данных, создать ERD или словарь данных, написать документы по базе данных/схеме, проверить изменение схемы или обновить существующие документы по базе данных.
