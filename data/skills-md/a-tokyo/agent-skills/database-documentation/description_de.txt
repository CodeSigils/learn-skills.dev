Generieren Sie eine fundierte und verifizierte, Engine-unabhängige Datenbankdokumentation, die eine 100-prozentige Parität mit dem tatsächlichen Schema erreicht. Introspiziert die LIVE-Datenbank als Grundwahrheit und validiert sie anhand von ORM-Modellen, Migrationen, generierten Typen, Seeds und Anwendungsabfragen. Anschließend prüft sie die Vollständigkeit, indem sie die Dokumente mit der Datenbank vergleicht. Erstellt ER-Diagramme (Meerjungfrau), Datenwörterbücher pro Tabelle und eine maschinenlesbare schema.json. Funktioniert mit PostgreSQL, MySQL, SQL Server und SQLite in jedem ORM (Prisma, TypeORM, Drizzle, Sequelize, Knex, Django, Rails) oder Roh-SQL. Verwenden Sie es, wenn Sie aufgefordert werden, eine Datenbank zu dokumentieren, ein ERD oder Datenwörterbuch zu erstellen, Datenbank-/Schemadokumente zu schreiben, Schemaabweichungen zu prüfen oder vorhandene Datenbankdokumente zu aktualisieren.
