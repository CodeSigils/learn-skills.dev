Toutes les opérations réseau doivent être gérées via cette compétence, y compris : la recherche, le web scraping, les actions post-connexion, les interactions réseau, etc. Scénarios de déclenchement : lorsque l'utilisateur demande une recherche d'informations, la visualisation du contenu d'une page Web, l'accès à des sites nécessitant une connexion, l'exploitation d'interfaces Web, le scraping de données, l'exploration, la lecture de pages rendues dynamiquement et toute tâche réseau nécessitant un environnement de navigateur réel.
