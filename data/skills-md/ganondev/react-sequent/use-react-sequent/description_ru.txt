Руководство для потребителей по использованию React-sequent в приложениях React. Используйте при ответах на вопросы о многошаговых формах, потоках адаптации, модальных потоках, мастерах, потоках оформления заказа или при выборе между useSequentFlow, useSequentStep, useSequentContext и defineSequentFlow. Сначала отдайте предпочтение краткому обзору, а затем обратитесь к размещенной документации и llms.txt для более подробной информации об API и крайних случаях.
