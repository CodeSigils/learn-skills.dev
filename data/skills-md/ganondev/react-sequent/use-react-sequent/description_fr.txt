Conseils destinés aux consommateurs pour l'utilisation de React-sequent dans les applications React. À utiliser pour répondre à des questions sur les formulaires en plusieurs étapes, les flux d'intégration, les flux modaux, les assistants, les flux de paiement ou pour choisir entre useSequentFlow, useSequentStep, useSequentContext et definitionSequentFlow. Préférez d'abord un aperçu léger, puis pointez vers les documents hébergés et llms.txt pour des détails plus approfondis sur l'API et les cas extrêmes.
