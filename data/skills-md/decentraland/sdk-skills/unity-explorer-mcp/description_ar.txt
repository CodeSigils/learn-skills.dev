قم بالتكرار على مشهد Decentraland SDK7 المحلي مقابل إصدار Explorer قيد التشغيل من خلال خادم التشغيل الآلي MCP الخاص به. يُستخدم عندما يطلب المستخدم رؤية مشهد في العالم أو اختباره أو التحقق منه أو التجول فيه أو التقاط لقطة شاشة أو تصحيح الأخطاء فيه، أو عندما يقوم بتسمية Explorer أو خادم MCP الخاص به، أو عندما تكون أداة `mcp__explorer__*` متاحة في الجلسة.
