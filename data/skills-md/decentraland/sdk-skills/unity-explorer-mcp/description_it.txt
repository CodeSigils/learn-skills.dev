Eseguire l'iterazione su una scena Decentraland SDK7 locale rispetto a una build Explorer in esecuzione tramite il relativo server di automazione MCP. Da utilizzare quando l'utente chiede di vedere, testare, verificare, esplorare, fare screenshot o eseguire il debug di una scena nel mondo, quando nomina Explorer o il suo server MCP o ogni volta che uno strumento `mcp__explorer__*` è disponibile nella sessione.
