Itérez sur une scène Decentraland SDK7 locale sur une version d'Explorer en cours d'exécution via son serveur d'automatisation MCP. À utiliser lorsque l'utilisateur demande à voir, tester, vérifier, parcourir, capturer ou déboguer une scène dans le monde, lorsqu'il nomme l'Explorateur ou son serveur MCP, ou chaque fois qu'un outil `mcp__explorer__*` est disponible dans la session.
