Referenz für das JSON-Format „.composite“ von Decentraland, das die anfänglichen Entitäten einer Szene in „assets/scene/main.composite“ deklariert. Verwenden Sie diese Option, wenn Sie eine main.composite-Datei erstellen oder bearbeiten oder wenn andere Fähigkeiten auf die zusammengesetzte Referenz verweisen. Informationen zum Gerüstbau eines gesamten Szenenprojekts finden Sie unter „Szene erstellen“.
