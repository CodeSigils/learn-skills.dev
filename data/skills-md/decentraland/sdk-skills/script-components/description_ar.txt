كتابة ملفات البرامج النصية .ts لمكون برنامج Creator Hub Script - فئات قائمة بذاتها مرتبطة بالكيانات الفردية. يُستخدم عندما يريد المستخدم إنشاء عنصر ذكي مخصص، أو كيان مكتوب قابل لإعادة الاستخدام، أو كتابة تعليمات برمجية يتم تشغيلها على مكون برنامج Creator Hub Script. لا تستخدمه مع كود Index.ts للمشهد العادي أو الأنظمة العالمية (راجع وقت تشغيل المشهد، والتفاعل الإضافي).
