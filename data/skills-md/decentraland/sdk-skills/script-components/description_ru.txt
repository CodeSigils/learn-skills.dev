Написание файлов сценариев .ts для компонента Creator Hub Script — автономных классов, прикрепленных к отдельным объектам. Используйте, когда пользователь хочет создать собственный смарт-элемент, объект со сценарием многократного использования или написать код, который запускается на компоненте сценария Creator Hub. НЕ используйте для обычного кода сцены index.ts или глобальных систем (см. среду выполнения сцены, добавление интерактивности).
