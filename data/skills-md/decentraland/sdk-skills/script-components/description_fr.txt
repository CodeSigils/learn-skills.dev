Écriture de fichiers de script .ts pour le composant Creator Hub Script : classes autonomes attachées à des entités individuelles. À utiliser lorsque l'utilisateur souhaite créer un élément intelligent personnalisé, une entité de script réutilisable ou écrire du code qui s'exécute sur un composant de script Creator Hub. Ne PAS utiliser pour le code de scène index.ts standard ou les systèmes globaux (voir scene-runtime, add-interactivity).
