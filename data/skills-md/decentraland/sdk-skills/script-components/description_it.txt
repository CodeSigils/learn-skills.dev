Scrittura di file script .ts per il componente Creator Hub Script: classi autonome collegate a singole entità. Da utilizzare quando l'utente desidera creare un elemento intelligente personalizzato, un'entità con script riutilizzabile o scrivere codice che viene eseguito su un componente Creator Hub Script. NON utilizzare per il codice della scena normale index.ts o per i sistemi globali (vedere scene-runtime, add-interactivity).
