Escribir archivos de script .ts para el componente Creator Hub Script: clases independientes adjuntas a entidades individuales. Úselo cuando el usuario desee crear un elemento inteligente personalizado, una entidad con secuencia de comandos reutilizable o escribir código que se ejecute en un componente de secuencia de comandos de Creator Hub. NO lo use para código index.ts de escena normal o sistemas globales (ver tiempo de ejecución de escena, agregar interactividad).
