API runtime trasversali per scene Decentraland SDK7. Da utilizzare quando l'utente necessita di lavoro asincrono (executeTask), HTTP (fetch/signedFetch) o WebSocket, timer, metadati di reame/scena, azioni limitate (movePlayerTo, teletrasporto, emote, URL esterni), ordine/priorità di esecuzione del sistema o per scrivere test di scena. NON utilizzare per l'interfaccia utente (vedi build-ui), sincronizzazione multiplayer (vedi multiplayer-sync), dati avatar/giocatore (vedi player-avatar) o input basato su polling (vedi advanced-input).
