API d'exécution transversales pour les scènes Decentraland SDK7. À utiliser lorsque l'utilisateur a besoin d'un travail asynchrone (executeTask), HTTP (fetch/signedFetch) ou WebSocket, de minuteries, de métadonnées de domaine/scène, d'actions restreintes (movePlayerTo, téléportation, emotes, URL externes), d'un ordre/priorité d'exécution du système ou d'écrire des tests de scène. Ne PAS utiliser pour l'interface utilisateur (voir build-ui), la synchronisation multijoueur (voir synchronisation multijoueur), les données avatar/joueur (voir avatar-joueur) ou la saisie basée sur un sondage (voir saisie avancée).
