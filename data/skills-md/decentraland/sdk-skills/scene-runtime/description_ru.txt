Сквозные API-интерфейсы среды выполнения для сцен Decentraland SDK7. Используйте, когда пользователю нужна асинхронная работа (executeTask), HTTP (fetch/signedFetch) или WebSocket, таймеры, метаданные области/сцены, ограниченные действия (movePlayerTo, телепорт, эмоции, внешние URL-адреса), порядок/приоритет выполнения системы или для написания тестов сцены. НЕ используйте для пользовательского интерфейса (см. build-ui), многопользовательской синхронизации (см. многопользовательскую синхронизацию), данных аватара/игрока (см. player-avatar) или ввода на основе опроса (см. расширенный ввод).
