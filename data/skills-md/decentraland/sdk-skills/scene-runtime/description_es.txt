API de tiempo de ejecución transversales para escenas Decentraland SDK7. Úselo cuando el usuario necesite trabajo asíncrono (executeTask), HTTP (fetch/signedFetch) o WebSocket, temporizadores, metadatos de reino/escena, acciones restringidas (movePlayerTo, teletransporte, emoticones, URL externas), orden/prioridad de ejecución del sistema o para escribir pruebas de escena. NO lo use para UI (ver build-ui), sincronización multijugador (ver sincronización multijugador), datos de avatar/jugador (ver player-avatar) o entrada basada en encuestas (ver entrada avanzada).
