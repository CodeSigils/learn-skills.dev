واجهات برمجة التطبيقات الشاملة لوقت التشغيل لمشاهد Decentraland SDK7. يُستخدم عندما يحتاج المستخدم إلى عمل غير متزامن (تنفيذ مهمة)، أو HTTP (جلب/توقيع جلب) أو WebSocket، أو أجهزة ضبط الوقت، أو بيانات تعريف المجال/المشهد، أو الإجراءات المقيدة (movePlayerTo، أو النقل الآني، أو الرموز التعبيرية، أو عناوين URL الخارجية)، أو ترتيب/أولوية تنفيذ النظام، أو لكتابة اختبارات المشهد. لا تستخدمه لواجهة المستخدم (راجع بناء واجهة المستخدم)، أو مزامنة اللاعبين المتعددين (راجع مزامنة اللاعبين المتعددين)، أو بيانات الصورة الرمزية/اللاعب (راجع الصورة الرمزية للاعب)، أو الإدخال المستند إلى الاستقصاء (راجع الإدخال المتقدم).
