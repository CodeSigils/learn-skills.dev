Multijugador punto a punto en Decentraland utilizando redes CRDT con syncEntity y MessageBus. Úselo cuando el usuario quiera multijugador, entidades sincronizadas, estado mundial compartido, transmisión de eventos o comunicación de jugador a jugador sin un servidor. NO lo use para almacenamiento persistente, anti-trampas o multijugador autorizado por el servidor (consulte servidor autorizado). NO lo use para la interfaz de usuario de pantalla (consulte build-ui).
