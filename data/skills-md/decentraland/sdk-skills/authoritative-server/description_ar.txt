أنشئ مشاهد Decentraland متعددة اللاعبين باستخدام خادم متعدد اللاعبين مقطوع الرأس. يُستخدم عندما يريد المستخدم وجود لاعبين موثوقين متعددين أو مكافحة الغش أو التحقق من جانب الخادم أو التخزين المستمر أو رسائل الخادم. لا تستخدمه مع CRDT متعدد اللاعبين الأساسي بدون خادم (راجع مزامنة اللاعبين المتعددين).
