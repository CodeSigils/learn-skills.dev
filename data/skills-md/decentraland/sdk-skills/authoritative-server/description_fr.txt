Créez des scènes Decentraland multijoueurs avec un serveur multijoueur sans tête. À utiliser lorsque l'utilisateur souhaite un mode multijoueur faisant autorité, un anti-triche, une validation côté serveur, un stockage persistant ou des messages serveur. Ne PAS utiliser pour le multijoueur CRDT de base sans serveur (voir synchronisation multijoueur).
