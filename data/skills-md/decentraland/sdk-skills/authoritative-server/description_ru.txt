Создавайте многопользовательские сцены Децентралэнда с помощью безголового многопользовательского сервера. Используйте, когда пользователю нужна авторитетная многопользовательская игра, защита от мошенничества, проверка на стороне сервера, постоянное хранилище или сообщения сервера. НЕ используйте для базовой многопользовательской игры CRDT без сервера (см. многопользовательскую синхронизацию).
