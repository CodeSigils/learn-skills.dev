Напишите пользовательский интерфейс сцены React-ECS, который 2D-редактор пользовательского интерфейса Creator Hub (UI Designer) сможет полностью читать и редактировать — макет файла, поверхность привязки состояния/свойств, слои стиля useInteraction, действия, варианты платформы и шаблон драйвера для анимации. Используйте, когда пользователю нужен пользовательский интерфейс, который можно редактировать в Creator Hub, он хочет создать пользовательский интерфейс для UI Designer или хочет адаптировать существующий закодированный пользовательский интерфейс, чтобы он открывался в редакторе. Для кодированного пользовательского интерфейса, не требующего редактора, используйте build-ui.
