Schreiben Sie eine React-ECS-Szenen-UI, die der 2D-UI-Editor (UI Designer) des Creator Hub vollständig lesen und bearbeiten kann – Dateilayout, die State/Requisiten-Bindungsoberfläche, useInteraction-Stilebenen, Aktionen, Plattformvarianten und das Treibermuster für Animationen. Verwenden Sie diese Option, wenn der Benutzer eine Benutzeroberfläche möchte, die im Creator Hub bearbeitet werden kann, eine Benutzeroberfläche für den UI-Designer generieren möchte oder eine vorhandene codierte Benutzeroberfläche anpassen möchte, damit sie im Editor geöffnet wird. Für eine codierte Benutzeroberfläche ohne Editor-Anforderung verwenden Sie build-ui.
