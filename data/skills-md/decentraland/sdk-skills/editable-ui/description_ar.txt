اكتب واجهة مستخدم مشهد React-ECS التي يمكن لمحرر واجهة المستخدم ثنائية الأبعاد (مصمم واجهة المستخدم) الخاص بـ Creator Hub قراءتها وتحريرها بالكامل - تخطيط الملف، وسطح ربط الحالة/الدعائم، وطبقات نمط useInteraction، والإجراءات، ومتغيرات النظام الأساسي، ونمط برنامج التشغيل للرسوم المتحركة. يُستخدم عندما يريد المستخدم واجهة مستخدم قابلة للتحرير في Creator Hub، أو يريد إنشاء واجهة مستخدم لمصمم واجهة المستخدم، أو يريد تكييف واجهة مستخدم مشفرة موجودة حتى يتم فتحها في المحرر. بالنسبة لواجهة المستخدم المشفرة دون الحاجة إلى محرر، استخدم build-ui.
