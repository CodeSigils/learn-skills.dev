Écrivez l'interface utilisateur de la scène React-ECS que l'éditeur d'interface utilisateur 2D (UI Designer) du Creator Hub peut entièrement lire et modifier : la disposition des fichiers, la surface de liaison état/accessoires, les couches de style d'utilisation d'interaction, les actions, les variantes de plate-forme et le modèle de pilote pour l'animation. À utiliser lorsque l'utilisateur souhaite une interface utilisateur modifiable dans Creator Hub, souhaite générer une interface utilisateur pour UI Designer ou souhaite adapter une interface utilisateur codée existante afin qu'elle s'ouvre dans l'éditeur. Pour une interface utilisateur codée sans exigence d’éditeur, utilisez build-ui.
