Creator Hub の 2D UI エディター (UI デザイナー) が完全に読み取りおよび編集できる React-ECS シーン UI を作成します。これには、ファイル レイアウト、状態/プロパティ バインディング サーフェス、useInteraction スタイル レイヤー、アクション、プラットフォーム バリアント、アニメーション用のドライバー パターンが含まれます。ユーザーが Creator Hub で編集可能な UI を必要とする場合、UI デザイナー用の UI を生成したい場合、またはエディターで開くように既存のコード化された UI を調整したい場合に使用します。エディター要件のないコード化された UI の場合は、build-ui を使用します。
