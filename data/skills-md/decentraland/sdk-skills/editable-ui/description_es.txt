Escriba la interfaz de usuario de escena de React-ECS que el editor de interfaz de usuario 2D de Creator Hub (UI Designer) pueda leer y editar completamente: diseño de archivos, superficie de enlace de estado/props, uso de capas de estilo de interacción, acciones, variantes de plataforma y el patrón del controlador para la animación. Úselo cuando el usuario quiera una interfaz de usuario que sea editable en Creator Hub, quiera generar una interfaz de usuario para UI Designer o quiera adaptar una interfaz de usuario codificada existente para que se abra en el editor. Para una interfaz de usuario codificada sin requisitos de editor, utilice build-ui.
