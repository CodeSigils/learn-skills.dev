Создавайте неигровых персонажей (неигровых персонажей) в сценах Децентралэнда. Два подхода: библиотека NPC Toolkit (dcl-npc-toolkit) для GLB NPC с диалогами, движением и конечными автоматами; и AvatarShape для NPC, похожих на аватары, на носимых устройствах. Используйте, когда пользователь хочет добавить NPC, владельца магазина или дающего квесты — любую неигровую сущность с поведением или диалогом. Для получения данных об игроке в реальном времени (позиция, профиль, носимые устройства) см. аватар игрока.
