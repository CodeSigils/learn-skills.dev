Aggiungi modelli 3D (.glb/.gltf) a una scena Decentraland utilizzando GltfContainer, incluse oltre 8.800 risorse gratuite dal catalogo OpenDCL. Da utilizzare quando l'utente desidera aggiungere modelli, importare file GLB, trovare risorse 3D gratuite o impostare collisori di modelli. NON utilizzare per materiali/trame (vedi rendering avanzato) o animazioni di modelli (vedi animazioni-interpolazioni).
