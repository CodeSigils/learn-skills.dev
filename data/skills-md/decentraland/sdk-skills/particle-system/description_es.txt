Emitir partículas (fuego, humo, nieve, fuegos artificiales, magia, senderos) desde una entidad en una escena Decentraland SDK7 con el componente ParticleSystem. NO lo use para movimiento de entidades de procedimiento (consulte animaciones-interpolaciones), efectos de modelo GLTF (consulte agregar-modelos 3D) o efectos de interfaz de usuario 2D (consulte build-ui).
