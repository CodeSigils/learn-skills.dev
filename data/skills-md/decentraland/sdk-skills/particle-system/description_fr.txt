Émettez des particules (feu, fumée, neige, feux d'artifice, magie, sentiers) à partir d'une entité dans une scène Decentraland SDK7 avec le composant ParticleSystem. Ne PAS utiliser pour le mouvement d'entité procédurale (voir animations-interpolations), les effets de modèle GLTF (voir add-3d-models) ou les effets d'interface utilisateur 2D (voir build-ui).
