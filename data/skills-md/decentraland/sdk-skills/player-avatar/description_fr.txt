Le joueur live dans une scène Decentraland. À utiliser lorsque l'utilisateur souhaite lire la position ou le profil du joueur, récupérer l'apparence de l'avatar pour les adresses hors scène (propriétaires de parcelles, détenteurs de NFT), déclencher des émoticônes, lire les appareils portables équipés, attacher des objets aux joueurs/avatars (éléments de jeu cosmétiques ou détenus), masquer les avatars ou désactiver les passeports dans les zones (AvatarModifierArea), ajuster la vitesse de locomotion, téléporter le joueur (movePlayerTo) ou écouter l'entrée/sortie de la scène. Ne PAS utiliser pour les personnages PNJ (voir NPC), les vérifications de portefeuille/blockchain (voir nft-blockchain), le gel des mouvements du joueur (voir entrée avancée pour InputModifier) ​​ou le mode caméra (voir contrôle de la caméra).
