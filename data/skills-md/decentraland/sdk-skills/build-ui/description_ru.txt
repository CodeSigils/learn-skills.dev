Создайте двухмерный пользовательский интерфейс экранного пространства для сцен Децентралэнда с помощью React-ECS (JSX). Создавайте HUD, меню, панели здоровья, диалоговые окна, кнопки, поля ввода и раскрывающиеся списки. Используйте, когда пользователю нужен экранный пользовательский интерфейс, меню или формы ввода. НЕ используйте для 3D-текста в мире (см. расширенный рендеринг) или кликабельных 3D-объектов (см. добавление интерактивности).
