Cree una interfaz de usuario en el espacio de pantalla 2D para escenas de Decentraland utilizando React-ECS (JSX). Cree HUD, menús, barras de salud, cuadros de diálogo, botones, entradas y menús desplegables. Úselo cuando el usuario desee una interfaz de usuario, menús o entradas de formulario en pantalla. NO lo use para texto 3D en el mundo (ver renderizado avanzado) u objetos 3D en los que se puede hacer clic (ver agregar interactividad).
