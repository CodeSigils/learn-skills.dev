Costruisci un'interfaccia utente screen-space 2D per scene Decentraland utilizzando React-ECS (JSX). Crea HUD, menu, barre della salute, finestre di dialogo, pulsanti, input e menu a discesa. Da utilizzare quando l'utente desidera l'interfaccia utente, i menu o gli input dei moduli su schermo. NON utilizzare per testo 3D nel mondo (vedi rendering avanzato) o oggetti 3D cliccabili (vedi aggiunta interattività).
