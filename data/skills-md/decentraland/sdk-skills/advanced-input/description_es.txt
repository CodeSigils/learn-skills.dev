Sondeo de entrada a nivel de sistema y control de movimiento de jugadores en Decentraland. Cubre inputSystem, InputModifier, PointerLock y PrimaryPointerInfo. Úselo cuando el usuario desee un sondeo de claves continuo, entidades controladas por WASD, para congelar al jugador durante una escena, bloqueo de cursor estilo FPS o patrones combinados de múltiples teclas. Para clics basados ​​en eventos y pasar el cursor sobre entidades, consulte agregar interactividad.
