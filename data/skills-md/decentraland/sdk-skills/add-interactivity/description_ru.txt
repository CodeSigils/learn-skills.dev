Интерактивность, управляемая событиями, для объектов Decentraland. Охватывает pointerEventsSystem, события близости, области триггеров (зоны входа/выхода), рассылку лучей и однократные нажатия клавиш на объектах. Используйте, когда пользователю нужны объекты, на которые можно щелкнуть, выделение при наведении, взаимодействие на основе близости, обнаружение входа игрока в зону, действия клавиш E/F над объектом или обнаружение попадания луча. Для опроса на системном уровне (удержание клавиш, движение WASD, блокировка курсора, InputModifier, панель действий) см. расширенный ввод. Информацию о кнопках пользовательского интерфейса экранного пространства см. в build-ui.
