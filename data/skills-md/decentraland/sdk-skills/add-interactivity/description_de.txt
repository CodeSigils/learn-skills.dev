Ereignisgesteuerte Interaktivität für Decentraland-Entitäten. Deckt pointerEventsSystem, Näherungsereignisse, Auslösebereiche (Eintritts-/Austrittszonen), Raycasting und einmalige Tastendrücke auf Entitäten ab. Verwenden Sie diese Option, wenn der Benutzer anklickbare Objekte, Hover-Hervorhebungen, näherungsbasierte Interaktionen, die Erkennung, wann ein Spieler eine Zone betritt, E/F-Tastenaktionen auf einer Entität oder die Erkennung von Strahlentreffern wünscht. Informationen zur Abfrage auf Systemebene (gehaltene Tasten, WASD-Bewegung, Cursorsperre, InputModifier, Aktionsleiste) finden Sie unter „Erweiterte Eingabe“. Informationen zu UI-Schaltflächen für den Bildschirmbereich finden Sie unter build-ui.
