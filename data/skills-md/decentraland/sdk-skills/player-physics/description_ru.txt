Применяйте физические силы к игроку в сценах Децентралэнда. Импульсы (однократные толчки), отбрасывание (отталкивание от точки с падением), непрерывные силы (аэродинамические трубы, антигравитация, подъемная сила, зависание), временные силы и поля отталкивания. Используйте, когда пользователю нужны стартовые площадки, отбрасывание при ударе, зоны ветра, гравитационные поля или подъем/плавание/зависание игрока. ЭТО также правильный навык, когда первый инстинкт агента состоит в том, чтобы изменить `Transform` на `engine.PlayerEntity`, чтобы переместить/поднять/толкнуть игрока - это НЕ работает (Player Transform управляется движком и доступен только для чтения); вместо этого используйте API физики. НЕ используйте для скорости движения игрока (см. аватар игрока AvatarLocomotionSettings) или движения платформы (см. анимацию-анимацию).
