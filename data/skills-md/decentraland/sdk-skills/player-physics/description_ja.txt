Decentraland シーンでプレイヤーに物理力を適用します。衝撃 (ワンショットの押し込み)、ノックバック (フォールオフのある点から押しのける)、継続的な力 (風洞、反重力、揚力、ホバリング)、時間制限された力、および斥力場。ユーザーが発射台、ヒット時のノックバック、風域、重力フィールド、またはプレイヤーの持ち上げ/浮遊/ホバリングを必要とする場合に使用します。これは、エージェントの最初の本能が、プレイヤーを移動/持ち上げ/押すために `engine.PlayerEntity` の `Transform` を変更することである場合にも適切なスキルです。これは機能しません (プレイヤーの Transform はエンジンによって制御され、読み取り専用です)。代わりに物理 API を使用してください。プレーヤーの移動速度 (プレーヤー アバター AvatarLocomotionSettings を参照) やプラットフォームの移動 (アニメーション トゥイーンを参照) には使用しないでください。
