Анимируйте объекты в сценах Decentraland. Воспроизводите анимацию модели GLTF с помощью Animator, создавайте процедурные движения с помощью Tween, объединяйте последовательности с помощью TweenSequence. Используйте, когда пользователь хочет анимировать, переместить, повернуть, прокрутить текстуру или создать эффекты движения. НЕ используйте для воспроизведения аудио/видео (см. аудио-видео), эмоций игрока (см. аватар игрока) или движений, управляемых физикой (см. физику игрока).
