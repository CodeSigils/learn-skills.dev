Анимируйте объекты в сценах Decentraland. Воспроизведите анимацию модели GLTF с помощью Animator, создайте процедурное движение с помощью Tween, создайте цепочку последовательностей с помощью TweenSequence. Используйте, когда пользователь хочет анимировать, переместить, повернуть, прокрутить текстуру или создать эффекты движения. НЕ используйте для воспроизведения аудио/видео (см. аудио-видео), эмоций игрока (см. аватар игрока) или движений, управляемых физикой (см. физику игрока).
