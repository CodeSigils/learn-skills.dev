Leggi, cerca, riepiloga, cita ed estrai tabelle da file PDF esistenti senza caricare l'intero file nel contesto. Utilizzare ogni volta che l'utente desidera leggere, riepilogare, cercare, analizzare o porre domande su un PDF, in particolare quelli lunghi, di grandi dimensioni, scansionati o ricchi di immagini/figure (rapporti, documenti, contratti, manuali, rendiconti finanziari, diapositive), comprese richieste come "leggi/riassumi questo PDF", "cosa mostra il grafico/la figura a pagina N" o "estrai le tabelle" e qualsiasi lavoro che coinvolga uno o più file .pdf anche quando l'utente non dice "converti". Funziona convertendo il PDF una volta in un'area di lavoro Markdown efficiente in termini di token con segnaposti di immagini ancorati alla pagina, quindi visualizzando solo le pagine necessarie per vedere una figura. Questo legge i PDF già esistenti; non crea, genera, compila, firma o esporta PDF. Preferisco piuttosto che scaricare un PDF nel contesto.
