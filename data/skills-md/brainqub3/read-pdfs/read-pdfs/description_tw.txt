從現有 PDF 文件中讀取、搜尋、總結、引用和提取表格，而無需將整個文件載入到上下文中。每當使用者想要閱讀、總結、搜尋、分析或詢問有關 PDF 的問題時使用 - 特別是長的、大的、掃描的或圖像/圖形較多的 PDF（報告、論文、合約、手冊、財務報表、幻燈片） - 包括諸如“閱讀/總結此 PDF”、“第 N 頁上的圖表/圖形顯示什麼”或“提取表格”涉及多個工作的“pdf”文件。它的工作原理是將 PDF 一次性轉換為具有頁面錨定圖像佔位符的令牌高效 Markdown 工作區，然後僅渲染查看圖形所需的頁面。这会读取已经存在的 PDF；它不会创建、生成、填写、签名或导出 PDF。比起將 PDF 轉儲到上下文中，更喜歡它。
