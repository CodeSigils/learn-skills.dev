Многоперспективный совет искусственного интеллекта, полностью работающий на параллельных субагентах Claude по собственной подписке пользователя на Claude Code — без внешних ключей API. Создаются независимые члены совета (разные личности, новые контексты, самые умные модели Клода), которые отвечают параллельно, анонимно рецензируют и ранжируют ответы друг друга, затем основная сессия синтезирует окончательный план с указанием авторства. Используйте, когда пользователь явно просит «посоветоваться с советом», «спросить совет», «узнать точку зрения других ИИ/моделей» или хочет получить несколько независимых мнений ИИ/второе мнение перед планом, проектированием или решением.
