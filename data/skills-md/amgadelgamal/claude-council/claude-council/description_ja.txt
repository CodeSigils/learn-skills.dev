マルチパースペクティブ AI カウンシルは、ユーザー自身の Claude Code サブスクリプション上の並列 Claude サブエージェントによって完全に強化されており、外部 API キーはありません。独立した評議会メンバー (独特のペルソナ、新鮮なコンテキスト、生成可能な最もスマートなクロード モデル) を生成し、並行して回答し、匿名でピアレビューし、お互いの回答をランク付けし、メイン セッションで帰属を伴う最終計画を合成します。ユーザーが「審議会に相談する」、「審議会に質問する」、「他の AI/モデルから視点を得る」ことを明示的に要求する場合、または計画、設計、または決定の前に複数の独立した AI の意見/セカンドオピニオンが必要な場合に使用します。
