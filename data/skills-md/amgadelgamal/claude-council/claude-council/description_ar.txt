مجلس الذكاء الاصطناعي متعدد وجهات النظر مدعوم بالكامل من خلال وكلاء فرعيين متوازيين لـ Claude على اشتراك Claude Code الخاص بالمستخدم - لا توجد مفاتيح API خارجية. يولد أعضاء المجلس المستقلين (شخصيات مميزة، وسياقات جديدة، وأذكى نماذج كلود القابلة للنشر) الذين يجيبون بالتوازي، ويراجعون الأقران بشكل مجهول ويصنفون إجابات بعضهم البعض، ثم تقوم الجلسة الرئيسية بتجميع خطة نهائية مع الإسناد. يُستخدم عندما يطلب المستخدم صراحةً "استشارة المجلس"، أو "استفسار المجلس"، أو "الحصول على وجهات نظر من نماذج الذكاء الاصطناعي/النماذج الأخرى"، أو يريد آراء الذكاء الاصطناعي المستقلة المتعددة/رأي ثانٍ قبل الخطة أو التصميم أو القرار.
