Навык постраничного чтения с помощью искусственного интеллекта: анализирует книги PDF/EPUB/MOBI/TXT по страницам/главам для извлечения текста, пакетно уточняет точки знаний, генерирует периодические сводки и выводит структурированные локальные заметки для чтения Markdown. Когда пользователь упоминает чтение заметок, анализ/обобщение книги, чтение и извлечение ключевых моментов, обобщение PDF/EPUB/MOBI/TXT или извлечение знаний, «помогите мне прочитать эту книгу/посмотреть эту книгу/проанализировать этот PDF-файл», подвести итог этой книги, извлечь знания из PDF/книги и т. д., следует использовать этот навык; даже если пользователь явно не упоминает «навык», если целью является создание заметок/резюме из файлов книг, его следует активировать.
