Erstellung einer Lösung für die Portfoliozuteilung von Privatfonds – umfasst die vollständige Sammlung von KYC-Fragebögen, die Schlussfolgerung des Anlegerprofils, die Portfoliozuteilung in einer Sechs-Bucket-Architektur und die Erstellung von Berichten für Abschnitt A-F. Dieser Skill muss ausgelöst werden, wenn der Benutzer „Helfen Sie mir bei der Konfiguration von Fonds“, „Empfehlen Sie ein Portfolio“, „Erstellen Sie einen Allokationsplan“, „Ich möchte eine diskretionäre Allokation“, „Wie wird dieses Geld zugewiesen“ oder „Portfolio-Investitionsberatung“ erwähnt.
