Создание плана распределения портфеля частных фондов — включает полный сбор анкет KYC, профилирование инвесторов, построение распределения по шести сегментам и создание отчетов из шести разделов A–F. Этот навык должен активироваться всякий раз, когда пользователь говорит: «Помогите мне настроить средства», «порекомендуйте портфель», «подготовьте план распределения», «я хочу произвольное распределение», «как мне распределить эти деньги» или «рекомендацию по портфелю».
