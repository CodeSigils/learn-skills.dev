Effectue une analyse avancée de SAST (Static Application Security Testing) et de conformité sur les différences de requêtes d'extraction. Identifie les véritables vulnérabilités de sécurité, les secrets et les violations de conformité réglementaire (RGPD, HIPAA, SOC2, PCI-DSS) en analysant uniquement le code modifié. Multilingue avec évaluation d’exploitabilité et cartographie CWE.
