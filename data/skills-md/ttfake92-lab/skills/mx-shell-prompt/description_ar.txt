قم بتحويل النص الكامل أو القصة أو مسودة التعليق الصوتي إلى مطالبات إنشاء فيديو سينمائية منظمة - مقسمة تلقائيًا مشهدًا تلو الآخر. الأفضل لأدوات الفيديو المنظمة السريعة مثل Seedance 2.0 وKling وJimeng (即梦). استخدم هذه المهارة عندما يقوم المستخدم بلصق نص / قصة / 口播稿 / 分镜脚本 ويريد تحويله إلى مطالبات فيديو، أو يطلب كتابة مطالبة فيديو، أو إنشاء لوحة عمل، أو تقسيم البرنامج النصي إلى لقطات، أو وصف مشهد سينمائي للفيديو AI. يحصل كل مقطع على مطالبة كاملة: 基础设定 (الشخصيات)، 道具 (الدعائم)، 场景 (مشهد)، 声音 (صوت)، 氛围与画质 (الحالة المزاجية والجودة)، 画面内容 (لقطات - متحللة تلقائيًا إلى قائمة لقطات أو لقطة طويلة، كل منها مع景别/构图/运镜). تشغيل الكلمات الرئيسية أيضًا: مطالبة الفيديو، إنشاء الفيديو، فيديو الذكاء الاصطناعي، تحويل النص إلى فيديو، لوحة القصة، 分镜، 拆分镜، 视频提示词، 视频生成، 脚本转视频، Seedance، Kling، 即梦، موجه سينمائي، قائمة اللقطات، حركة الكاميرا. قم بالتفعيل حتى لو كان لدى المستخدم فكرة تقريبية من جملة واحدة فقط - تعامل معها كقطعة واحدة وقم بتجسيدها.
