Превратите полный сценарий, историю или черновик закадрового голоса в структурированные кинематографические подсказки для создания видео, автоматически сегментированные по сценам. Лучше всего подходит для инструментов структурированного видео, таких как Seedance 2.0, Kling и Jimeng (即梦). Используйте этот навык всякий раз, когда пользователь вставляет сценарий / историю / 口播稿 / 分镜脚本 и хочет превратить его в видеоподсказку, просит написать видеоподсказку, создать раскадровку, разбить сценарий на кадры или описать кинематографическую сцену для видео AI. Каждый сегмент получает полную подсказку: 基础设定 (персонажи), 道具 (реквизит), 场景 (сцена), 声音 (звук), 氛围与画质 (настроение и качество), 画面内容 (кадры — автоматически разлагаются на список кадров или длинный дубль, каждый с景别/构图/运镜). Также активируется по ключевым словам: видеоподсказка, генерация видео, AI-видео, преобразование текста в видео, раскадровка, 分镜, 拆分镜, 视频提示词, 视频生成, 脚本转视频, Seedance, Kling, 即梦, кинематографическая подсказка, список кадров, движение камеры. Запустите триггер, даже если у пользователя есть лишь приблизительная идея из одного предложения — воспринимайте ее как один сегмент и конкретизируйте.
