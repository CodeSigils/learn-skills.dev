macOS System Migration Assistant — 2 つのフェーズ: 最初に古いシステムでインベントリ (JSON) を収集し、次にそれを新しいシステムで復元します。システムの移行、コンピュータの切り替え、OS の新規インストール、Time Machine の復元、データの移行、OS の再インストール、移行、新しい Mac のセットアップ、バックアップからの復元、バックアップ システムなどについてユーザーが言及する場合に使用します。現在のマシンが古いシステム (収集モード) であるか、新しいシステム (復元モード) であるかを自動的に検出します。前提条件: 最初に Time Machine の完全バックアップを実行します。唯一のソフトウェア依存関係は Homebrew です。
