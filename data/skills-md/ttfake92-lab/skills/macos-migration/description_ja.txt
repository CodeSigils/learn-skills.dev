macOS System Migration Assistant — 2 段階: 最初に古いシステムでインベントリ (JSON) を収集し、次に新しいシステムで復元します。システム移行、コンピュータの変更、OS の新規インストール、Time Machine リカバリ、データ移行、OS の再インストール、移行、新しい Mac のセットアップ、バックアップからの復元、バックアップ システムなどについてユーザーが言及する場合に使用します。現在のマシンが旧システム (収集モード) であるか、新システム (復元モード) であるかを自動的に検出します。前提条件: 最初に Time Machine の完全バックアップを実行します。唯一のソフトウェア依存関係は Homebrew です。
