macOS System Migration Assistant — Two phases: first collect an inventory (JSON) on the old system, then restore it on the new system. Use when the user mentions: system migration, switching computers, fresh OS install, Time Machine restore, data migration, reinstalling the OS, migration, setup new Mac, restore from backup, backup system. Automatically detects whether the current machine is the old system (collection mode) or the new system (restore mode). Prerequisite: perform a full Time Machine backup first; the only software dependency is Homebrew.
