Asistente de migración del sistema macOS: dos etapas: primero recopilar un inventario (JSON) en el sistema anterior y luego restaurarlo en el nuevo sistema. Úselo cuando el usuario mencione: migración del sistema, cambio de computadoras, instalación nueva del sistema operativo, restauración de Time Machine, migración de datos, reinstalación del sistema, migración, configuración de una nueva Mac, restauración desde una copia de seguridad, copia de seguridad del sistema. Detecta automáticamente si la máquina actual es el sistema antiguo (modo de recopilación) o el sistema nuevo (modo de restauración). Requisito previo: primero realice una copia de seguridad completa de Time Machine; la única dependencia del software es Homebrew.
