Assistente Migrazione Sistema macOS: due fasi: prima raccogli un inventario (JSON) sul vecchio sistema, poi ripristina sul nuovo sistema. Da utilizzare quando l'utente menziona: migrazione del sistema, cambio di computer, nuova installazione del sistema operativo, ripristino di Time Machine, migrazione dei dati, reinstallazione del sistema, migrazione, configurazione di un nuovo Mac, ripristino da backup, backup del sistema. Rileva automaticamente se la macchina corrente è il vecchio sistema (modalità di raccolta) o il nuovo sistema (modalità di ripristino). Prerequisito: effettuare prima un backup completo di Time Machine; l'unica dipendenza dal software è Homebrew.
