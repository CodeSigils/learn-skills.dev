macOS-Systemmigrationsassistent – ​​Zwei Phasen: Zuerst eine Bestandsaufnahme (JSON) auf dem alten System erfassen und dann auf dem neuen System wiederherstellen. Verwenden Sie diese Option, wenn der Benutzer Folgendes erwähnt: Systemmigration, Computerwechsel, Neuinstallation des Betriebssystems, Time Machine-Wiederherstellung, Datenmigration, Neuinstallation des Systems, Migration, Einrichtung eines neuen Mac, Wiederherstellung aus Backup, Backup-System. Erkennen Sie automatisch, ob es sich bei der aktuellen Maschine um das alte System (Sammelmodus) oder das neue System (Wiederherstellungsmodus) handelt. Voraussetzung: Führen Sie zuerst eine vollständige Time Machine-Sicherung durch; Die einzige Softwareabhängigkeit ist Homebrew.
