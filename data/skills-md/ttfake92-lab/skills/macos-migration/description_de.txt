macOS System Migration Assistant – Zwei Phasen: Sammeln Sie zunächst eine Bestandsaufnahme (JSON) auf dem alten System und stellen Sie sie dann auf dem neuen System wieder her. Verwenden Sie diese Option, wenn der Benutzer Folgendes erwähnt: Systemmigration, Computerwechsel, Neuinstallation des Betriebssystems, Time Machine-Wiederherstellung, Datenmigration, Neuinstallation des Betriebssystems, Migration, Einrichtung eines neuen Mac, Wiederherstellung aus Backup, Backup-System. Erkennt automatisch, ob es sich bei der aktuellen Maschine um das alte System (Sammelmodus) oder das neue System (Wiederherstellungsmodus) handelt. Voraussetzung: Führen Sie zuerst eine vollständige Time Machine-Sicherung durch; Die einzige Softwareabhängigkeit ist Homebrew.
