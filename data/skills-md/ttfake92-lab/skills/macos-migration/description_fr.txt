Assistant de migration du système macOS — Deux phases : collectez d'abord un inventaire (JSON) sur l'ancien système, puis restaurez-le sur le nouveau système. À utiliser lorsque l'utilisateur mentionne : la migration du système, le changement d'ordinateur, une nouvelle installation du système d'exploitation, la restauration de Time Machine, la migration des données, la réinstallation du système d'exploitation, la migration, la configuration d'un nouveau Mac, la restauration à partir d'une sauvegarde, le système de sauvegarde. Détecte automatiquement si la machine actuelle est l'ancien système (mode de collecte) ou le nouveau système (mode de restauration). Condition préalable : effectuez d'abord une sauvegarde complète de Time Machine ; la seule dépendance logicielle est Homebrew.
