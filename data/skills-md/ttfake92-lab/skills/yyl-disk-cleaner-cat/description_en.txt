Pixel Kitten helps you clean macOS disks, optimize space and performance. It scans developer caches, system caches, and large file downloads, provides performance and network optimization suggestions, and then opens a “pixel‑style webpage” for you to check and confirm—once confirmed, a 3D pixel kitten cleans the room in real time, and dust piles shrink in proportion to the actual deletion progress. It includes persistent memory: each cleanup’s details and your preferences are stored in ~/.disk‑cleanup‑cat/, so it understands you better next time. Use it when a user says “clean disk / clean space / disk is full / C drive is full / optimize computer / optimize performance / computer is slow / clear cache / disk cleanup / free up space.” macOS only.
