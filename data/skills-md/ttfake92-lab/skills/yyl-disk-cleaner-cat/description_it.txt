Pixel Kitten ti aiuta a pulire i dischi macOS, ottimizzare spazio e prestazioni. Esegue la scansione delle cache degli sviluppatori, delle cache di sistema e dei download di file di grandi dimensioni, fornisce suggerimenti per l'ottimizzazione delle prestazioni e della rete, quindi apre una "pagina Web in stile pixel" da controllare e confermare: una volta confermato, un gattino pixel 3D pulisce la stanza in tempo reale e i mucchi di polvere si riducono in proporzione all'effettivo progresso dell'eliminazione. Include memoria persistente: i dettagli di ogni pulizia e le tue preferenze sono archiviati in~/.disk‑cleanup‑cat/, così ti capisce meglio la prossima volta. Usalo quando un utente dice "pulisci disco / pulisci spazio / il disco è pieno / l'unità C è piena / ottimizza il computer / ottimizza le prestazioni / il computer è lento / svuota la cache / pulisci il disco / libera spazio". solo macOS.
