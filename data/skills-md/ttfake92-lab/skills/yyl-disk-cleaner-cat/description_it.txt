Pixel Kitten ti aiuta a pulire i dischi macOS, ottimizzare spazio e prestazioni. Esegue la scansione delle cache degli sviluppatori, delle cache di sistema e dei download di file di grandi dimensioni, fornisce suggerimenti per l'ottimizzazione delle prestazioni e della rete, quindi apre una "pagina Web in stile pixel" da controllare e confermare. Dopo la conferma, un gattino pixel 3D pulisce in tempo reale la stanza, con i mucchi di polvere che si restringono in base all'effettivo progresso dell'eliminazione. Mantiene una memoria continua: i dettagli di ogni pulizia e le tue preferenze sono archiviati in ~/.disk-cleanup-cat/, così ti capisce meglio la prossima volta. Usalo quando l'utente dice "pulisci disco / pulisci spazio / disco pieno / unità C piena / ottimizza il computer / ottimizza le prestazioni / il computer è lento / svuota la cache / pulisci il disco / libera spazio". solo macOS.
