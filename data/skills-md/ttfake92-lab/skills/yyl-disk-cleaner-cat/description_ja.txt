Pixel Kitten は、macOS ディスクをクリーンアップし、スペースとパフォーマンスを最適化するのに役立ちます。開発者キャッシュ、システム キャッシュ、および大きなファイルのダウンロードをスキャンし、パフォーマンスとネットワークの最適化に関する提案を提供し、チェックして確認するための「ピクセル スタイルの Web ページ」を開きます。確認すると、3D ピクセルの子猫がリアルタイムで部屋を掃除し、実際の削除の進行状況に比例して塵の山が縮小します。これには永続メモリが含まれています。各クリーンアップの詳細と設定は ~/.disk‑cleanup‑cat/ に保存されるため、次回からはよりよく理解できるようになります。ユーザーが「ディスクをクリーンアップする / スペースをクリーンアップする / ディスクがいっぱいである / C ドライブがいっぱいである / コンピュータを最適化する / パフォーマンスを最適化する / コンピュータが遅い / キャッシュをクリアする / ディスクのクリーンアップ / スペースを解放する」という場合に使用します。 macOSのみ。
