Pixel Cat は、macOS ディスクのクリーンアップ、スペースの最適化、パフォーマンスの向上に役立ちます。開発者キャッシュ、システム キャッシュ、および大きなファイルのダウンロードをスキャンし、パフォーマンスとネットワークの最適化に関する提案を提供します。その後、「ピクセル スタイル」の Web ページを開いてチェックを入れて確認します。確認すると、3D ピクセルの猫がリアルタイムで部屋を掃除し、実際の削除が進むにつれて埃の山が縮小します。これには永続メモリが含まれます。毎回クリーニングする内容と設定は ~/.disk‑cleanup‑cat/ に保存されるため、次回からはユーザーの理解が深まります。ユーザーが「ディスクをクリーンアップする / スペースを解放する / ディスクがいっぱいになる / C ドライブがいっぱいになる / コンピュータを最適化する / パフォーマンスを最適化する / コンピュータが遅い / キャッシュをクリアする / ディスクのクリーンアップ / スペースを解放する」という場合に使用します。 macOSのみ。
