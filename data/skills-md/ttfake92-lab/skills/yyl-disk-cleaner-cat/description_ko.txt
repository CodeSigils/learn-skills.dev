Pixel Kitten을 사용하면 macOS 디스크를 정리하고 공간과 성능을 최적화할 수 있습니다. 개발자 캐시, 시스템 캐시 및 대용량 파일 다운로드를 검색하고 성능 및 네트워크 최적화 제안을 제공한 다음 확인 및 확인할 수 있는 "픽셀 스타일 웹페이지"를 엽니다. 일단 확인되면 3D 픽셀 새끼 고양이가 실시간으로 방을 청소하고 실제 삭제 진행률에 비례하여 먼지 더미가 줄어듭니다. 여기에는 영구 메모리가 포함되어 있습니다. 각 정리의 세부 정보와 기본 설정은 ~/.disk‑cleanup‑cat/에 저장되므로 다음에 사용자를 더 잘 이해할 수 있습니다. 사용자가 "디스크 정리 / 공간 정리 / 디스크가 꽉 찼습니다 / C 드라이브가 꽉 찼습니다 / 컴퓨터 최적화 / 성능 최적화 / 컴퓨터가 느립니다 / 캐시 지우기 / 디스크 정리 / 공간 확보"라고 말할 때 사용하세요. macOS만 해당됩니다.
