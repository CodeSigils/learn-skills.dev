Pixel Kitten vous aide à nettoyer les disques macOS, à optimiser l'espace et les performances. Il analyse les caches des développeurs, les caches système et les téléchargements de fichiers volumineux, fournit des suggestions d'optimisation des performances et du réseau, puis ouvre une « page Web de style pixel » que vous pouvez vérifier et confirmer. Une fois confirmé, un chaton pixel 3D nettoie la pièce en temps réel et les tas de poussière diminuent proportionnellement à la progression réelle de la suppression. Il inclut une mémoire persistante : les détails de chaque nettoyage et vos préférences sont stockés dans ~/.disk‑cleanup‑cat/, afin qu'il vous comprenne mieux la prochaine fois. Utilisez-le lorsqu'un utilisateur dit « nettoyer le disque / nettoyer l'espace / le disque est plein / le lecteur C est plein / optimiser l'ordinateur / optimiser les performances / l'ordinateur est lent / vider le cache / nettoyer le disque / libérer de l'espace ». macOS uniquement.
