Pixel kitten vous aide à nettoyer les disques macOS, à optimiser l'espace et à améliorer les performances. Il analyse les caches des développeurs, les caches système et les téléchargements de fichiers volumineux, propose des suggestions d'optimisation des performances et du réseau, puis ouvre une page Web de « style pixel » que vous pouvez vérifier et confirmer. Après confirmation, un chaton pixel 3D nettoie la pièce en temps réel, les tas de poussière diminuant proportionnellement à la progression réelle de la suppression. Il dispose d'une mémoire persistante : les détails de chaque nettoyage et vos préférences sont enregistrés dans ~/.disk-cleanup-cat/, afin qu'il vous comprenne mieux la prochaine fois. Utilisez-le lorsque l'utilisateur dit « nettoyer le disque / espace libre / le disque est plein / le lecteur C est plein / optimiser l'ordinateur / optimiser les performances / l'ordinateur est lent / vider le cache / nettoyer le disque / libérer de l'espace ». macOS uniquement.
