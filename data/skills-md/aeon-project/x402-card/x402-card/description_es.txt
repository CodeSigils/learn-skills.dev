Active esta habilidad cuando el usuario exprese su intención de crear, administrar o consultar una tarjeta virtual.
Esto incluye intenciones como: - "obtener una tarjeta virtual" - "crear una tarjeta" - "estado de la tarjeta" - "configurar una tarjeta para un agente"
Además, cualquier solicitud que implique la creación de una Visa/Mastercard virtual de un solo uso financiada con criptomonedas para uso de los agentes.
