Une boucle qui améliore de manière itérative un plan de conception grâce aux révisions Copilot CLI : créer un plan → Révision Copilot → incorporer les commentaires → réexaminer, en répétant jusqu'à convergence. Le modèle de révision peut être spécifié avec --model et le niveau d'inférence avec --effort. Utiliser pour : "copilot-plan-loop", "Planification avec Copilot", "Design review loop (Copilot)", "Améliorer la précision du plan (Copilot)".
