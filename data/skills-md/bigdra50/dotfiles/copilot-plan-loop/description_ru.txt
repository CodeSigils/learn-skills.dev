Цикл, который итеративно улучшает план проектирования посредством проверок Copilot CLI: создать план → проверка второго пилота → включить обратную связь → повторная проверка, повторяя до достижения сходимости. Модель обзора может быть указана с помощью --model, а уровень вывода - с помощью --effort. Используется для: «цикл второго пилота-плана», «Планирование с помощью второго пилота», «Цикл проверки проекта (второй пилот)», «Повышение точности плана (второй пилот)».
