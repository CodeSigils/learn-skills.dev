A loop that iteratively improves a design plan through Copilot CLI reviews: create a plan → Copilot review → incorporate feedback → re‑review, repeating until convergence. The review model can be specified with --model and the inference level with --effort. Use for: “copilot-plan-loop”, “Planning with Copilot”, “Design review loop (Copilot)”, “Improve plan accuracy (Copilot)”.
