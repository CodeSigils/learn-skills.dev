Da utilizzare quando si crea un nuovo Xcode o un progetto di app mobile, si sceglie o si inserisce un ID bundle Apple/ID app, si configura un team di firma (in particolare un team personale gratuito), si configura un'app macOS che richiede autorizzazioni TCC (Accessibilità, Monitoraggio input, Registrazione schermo), si controlla un repository per perdite di identificatori o si colpiscono gli errori "Un ID app con identificatore non è disponibile" / "Impossibile registrare l'identificatore bundle".
