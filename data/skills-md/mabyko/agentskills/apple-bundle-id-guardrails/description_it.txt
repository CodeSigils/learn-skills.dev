Da utilizzare quando si crea un nuovo progetto Xcode o di app mobile, si sceglie o inserisce un bundle ID / App ID Apple, si configura un team di firma (specialmente un team personale gratuito), si imposta un’app macOS che richiede permessi TCC (Accessibilità, Monitoraggio input, Registrazione schermo), si esegue un audit di un repository per perdite di identificatori, o si incontrano gli errori “An App ID with Identifier is not available” / “Failed to register bundle identifier”.
