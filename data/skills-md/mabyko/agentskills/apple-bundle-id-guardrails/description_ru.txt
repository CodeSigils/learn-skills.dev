Используйте при создании нового проекта Xcode или мобильного приложения, выборе или вводе Apple bundle ID / App ID, настройке команды подписи (особенно бесплатной личной команды), настройке macOS‑приложения, запрашивающего разрешения TCC (Accessibility, Input Monitoring, Screen Recording), аудите репозитория на предмет утечек идентификаторов или при возникновении ошибок «An App ID with Identifier is not available» / «Failed to register bundle identifier».
