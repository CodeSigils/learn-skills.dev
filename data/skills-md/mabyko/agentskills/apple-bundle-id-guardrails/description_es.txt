Úsalo al crear un nuevo proyecto Xcode o de aplicación móvil, al elegir o introducir un ID de paquete / ID de aplicación de Apple, al configurar un equipo de firma (especialmente un equipo personal gratuito), al configurar una aplicación macOS que solicite permisos TCC (Accesibilidad, Monitoreo de entrada, Grabación de pantalla), al auditar un repositorio en busca de filtraciones de identificadores, o al encontrarse con errores como “An App ID with Identifier is not available” / “Failed to register bundle identifier”.
