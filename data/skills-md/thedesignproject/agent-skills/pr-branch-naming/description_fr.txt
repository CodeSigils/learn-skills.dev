Générez une branche au nom conventionnel et un titre PR à partir d'une description de fonctionnalité. À utiliser lorsque l'utilisateur démarre une nouvelle branche, ouvre un PR ou demande comment nommer une branche ou un PR. Se déclenche sur des expressions telles que « créer une branche », « nommer cette branche », « ouvrir un PR », « comment dois-je appeler cette branche », « titre du PR pour cela ».
