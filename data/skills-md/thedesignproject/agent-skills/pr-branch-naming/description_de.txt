Generieren Sie aus einer Funktionsbeschreibung einen Zweig mit herkömmlichem Namen und einen PR-Titel. Verwenden Sie diese Option, wenn der Benutzer eine neue Filiale startet, eine PR eröffnet oder fragt, wie eine Filiale oder PR benannt werden soll. Wird durch Ausdrücke wie „Zweig erstellen“, „Diesen Zweig benennen“, „PR eröffnen“, „Wie soll ich diesen Zweig nennen“, „PR-Titel dafür“ ausgelöst.
