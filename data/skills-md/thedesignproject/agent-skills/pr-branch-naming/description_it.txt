Genera un ramo con nome convenzionale e un titolo PR da una descrizione della funzionalità. Da utilizzare quando l'utente sta avviando un nuovo ramo, aprendo un PR o chiede come nominare un ramo o un PR. Si attiva su frasi come "crea un ramo", "dai un nome a questo ramo", "apri un PR", "come dovrei chiamare questo ramo", "titolo PR per questo".
