Utilícelo al diseñar, ampliar o auditar una biblioteca de componentes cuyo consumidor principal es un agente de IA; es decir, el sistema de diseño necesita metadatos legibles por máquina (accesorios, variantes, relaciones, tokens, antipatrones) en lugar de solo documentos en prosa. Los desencadenantes incluyen "sistema de diseño agente", "sistema de diseño para IA/Claude", "hacer que mi sistema de diseño sea legible por IA", "esquema de metadatos de componentes", "estructurar una biblioteca de interfaz de usuario para un agente" o planificar una nueva biblioteca de componentes donde el consumidor principal es un LLM. No uses esta habilidad para trabajos de sistemas de diseño puramente humanos; usa figma:figma-generate-library para eso.
