À utiliser lors de la conception, de l'échafaudage, de l'extension ou de l'audit d'une bibliothèque de composants dont le consommateur principal est un agent d'IA — c'est-à-dire que le système de conception a besoin de métadonnées lisibles par machine (accessoires, variantes, relations, jetons, anti-modèles) plutôt que uniquement de documents en prose. Les déclencheurs incluent « système de conception agent », « système de conception pour IA/Claude », « rendre mon système de conception lisible par l'IA », « schéma de métadonnées de composant », « échafauder une bibliothèque d'interface utilisateur pour un agent » ou planifier une nouvelle bibliothèque de composants où le consommateur principal est un LLM. N'utilisez pas cette compétence pour un travail de système de conception purement orienté vers l'humain - utilisez figma:figma-generate-library pour cela.
