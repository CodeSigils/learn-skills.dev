Используйте при проектировании, формировании, расширении или аудите библиотеки компонентов, основным потребителем которой является агент ИИ, т. е. системе проектирования нужны машиночитаемые метаданные (реквизиты, варианты, отношения, токены, антишаблоны), а не только прозаические документы. Триггеры включают «систему проектирования агента», «систему проектирования для ИИ/Клода», «сделать мою систему проектирования читабельной для ИИ», «схему метаданных компонента», «собрать библиотеку пользовательского интерфейса для агента» или планирование новой библиотеки компонентов, где основным потребителем является LLM. Не используйте этот навык для чисто человеческой работы с системой проектирования — используйте для этого Figma:figma-generate-library.
