Перенесите новое внутреннее приложение продукта JOYCO от плана до рабочей сборки. Сначала блокирует план (тот, который разработчик уже усовершенствовал в этом сеансе, принес из другого сеанса агента или тот, который вы составили вместе), затем запускает продуманный начальный этап — Next.js + TypeScript + Tailwind, подключенный к реестру shadcn пользовательского интерфейса JOYCO (@joyco/ui kit: компоненты, тема, шрифты из Hub.joyco.studio), конфигурацию JOYCO lint и руководство для агента текущего жгута — а затем строит приложение в соответствии с планом. Вызывается пользователем как /joyco-app <имя проекта>. Запускается при «новом приложении joyco», «начать проект joyco», «запустить внутреннее приложение joyco», «создать это как приложение joyco», «настроить joyco/ui», а также при упоминании интерфейса командной строки joyco, пространства имен @joyco илиhub.joyco.studio. НЕ используйте это для публикации автономного эксперимента (это joyco-lab) или для создания стартовой версии 3D/движения/библиотеки с помощью Joyco Create – это шаблоны экспериментов/библиотек, а не приложения продуктов.
