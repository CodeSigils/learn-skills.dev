Lleve una nueva aplicación de producto interna de JOYCO desde el plano hasta la construcción funcional. Primero bloquea un plan (uno que el desarrollador ya refinó esta sesión, traído de otra sesión de agente o uno que redactaron juntos), luego ejecuta el inicio obstinado: Next.js + TypeScript + Tailwind conectado al registro shadcn de la interfaz de usuario de JOYCO (@joyco/ui kit: componentes, tema, fuentes de hub.joyco.studio), configuración de lint de JOYCO y la guía del agente del arnés actual, y luego construye la aplicación según el plan. Invocable por el usuario como /joyco-app <nombre-proyecto>. Activadores en "nueva aplicación joyco", "iniciar un proyecto joyco", "iniciar una aplicación joyco interna", "compilar esto como una aplicación joyco", "configurar joyco/ui" y en menciones de la CLI de joyco, el espacio de nombres @joyco o hub.joyco.studio. NO use esto para publicar un experimento independiente (eso es joyco-lab) o para crear un iniciador 3D/movimiento/biblioteca a través de `joyco create`; esas son plantillas de experimento/biblioteca, no aplicaciones de productos.
