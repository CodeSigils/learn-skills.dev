新しい JOYCO 社内製品アプリを計画から実用的なビルドまで実行します。最初にプランをロックし（開発者がすでにこのセッションを調整したもの、別のエージェント セッションから持ち込んだもの、または一緒にドラフトしたもの）、独自のキックオフを実行します — Next.js + TypeScript + Tailwind を JOYCO UI shadcn レジストリ (@joyco/ui キット: コンポーネント、テーマ、フォントは Hub.joyco.studio から)、JOYCO lint 設定、および現在のハーネスのエージェント ガイダンスに接続してからビルドします。アプリを計画に取り入れます。ユーザーは /joyco-app <プロジェクト名> として呼び出し可能。 「新しい Joyco アプリ」、「Joyco プロジェクトの開始」、「内部 Joyco アプリのキックオフ」、「これを Joyco アプリとして構築」、「Joyco/ui のセットアップ」、および Joyco CLI、@joyco 名前空間、または Hub.joyco.studio への言及によってトリガーされます。これをスタンドアロンの実験 (joyco-lab) を公開したり、`joyco create` 経由で 3d/モーション/ライブラリ スターターをスキャフォールディングするために使用しないでください。これらは実験/ライブラリ テンプレートであり、製品アプリではありません。
