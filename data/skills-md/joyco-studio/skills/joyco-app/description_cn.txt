携带新的 JOYCO 内部产品应用程序从计划到工作构建。首先锁定一个计划（开发人员已经完善了此会话、从另一个代理会话带来的计划，或者您一起起草的计划），然后运行固执己见的启动 - Next.js + TypeScript + Tailwind 连接到 JOYCO UI shadcn 注册表（@joyco/ui 套件：来自 hub.joyco.studio 的组件、主题、字体）、JOYCO lint 配置和当前线束的代理指南 - 然后根据计划构建应用程序。用户可调用为 /joyco-app <项目名称>。在“新的 Joyco 应用程序”、“启动 Joyco 项目”、“启动内部 Joyco 应用程序”、“将其构建为 Joyco 应用程序”、“设置 Joyco/ui”以及提及 Joyco CLI、@joyco 命名空间或 hub.joyco.studio 时触发。请勿使用它来发布独立实验（即 Joyco-lab）或通过“joyco create”构建 3D/动作/库启动器 - 这些是实验/库模板，而不是产品应用程序。
