Créez, révisez, déboguer et optimisez les expériences de production Three.js. À utiliser pour les scènes Three.js, les moteurs de rendu React Three Fiber, WebGL ou WebGPU, les shaders GLSL, les graphiques de nœuds TSL réutilisables et les contrats de nœuds typés, les ressources glTF, le post-traitement, la coordination DOM-canvas, les performances de la boucle de rendu, les problèmes GPU à la première utilisation, l'invalidation de matériaux ou de textures, le nettoyage des ressources GPU et les régressions visuelles dans le travail Web 3D. Ne pas utiliser pour les transformations CSS 3D génériques ou les travaux de canevas 2D statiques qui n'utilisent pas de graphique de scène Three.js.
