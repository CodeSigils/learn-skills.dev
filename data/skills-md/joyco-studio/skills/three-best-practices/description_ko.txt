프로덕션 Three.js 환경을 구축, 검토, 디버그 및 최적화합니다. Three.js 장면, React Three Fiber, WebGL 또는 WebGPU 렌더러, GLSL 셰이더, 재사용 가능한 TSL 노드 그래프 및 입력된 노드 계약, glTF 자산, 사후 처리, DOM-캔버스 조정, 렌더 루프 성능, 최초 사용 GPU 장애, 재료 또는 텍스처 무효화, GPU 리소스 정리 및 3D 웹 작업의 시각적 회귀에 사용됩니다. Three.js 장면 그래프를 사용하지 않는 일반 CSS 3D 변환이나 정적 2D 캔버스 작업에는 사용하지 마세요.
