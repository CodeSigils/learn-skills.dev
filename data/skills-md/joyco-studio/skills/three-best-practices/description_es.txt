Cree, revise, depure y optimice la producción de experiencias Three.js. Úselo para escenas Three.js, renderizadores React Three Fiber, WebGL o WebGPU, sombreadores GLSL, gráficos de nodos TSL reutilizables y contratos de nodos escritos, activos glTF, posprocesamiento, coordinación de DOM a lienzo, rendimiento del bucle de renderizado, problemas de GPU de primer uso, invalidación de materiales o texturas, limpieza de recursos de GPU y regresiones visuales en trabajos web en 3D. No lo utilice para transformaciones CSS 3D genéricas ni para trabajos de lienzo 2D estático que no utilice un gráfico de escena Three.js.
