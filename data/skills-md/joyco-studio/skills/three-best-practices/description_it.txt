Crea, rivedi, esegui il debug e ottimizza le esperienze di produzione Three.js. Utilizzare per scene Three.js, renderizzatori React Three Fiber, WebGL o WebGPU, shader GLSL, grafici di nodi TSL riutilizzabili e contratti di nodi tipizzati, risorse glTF, post-elaborazione, coordinamento DOM-to-canvas, prestazioni del ciclo di rendering, intoppi GPU al primo utilizzo, invalidazione di materiali o texture, pulizia delle risorse GPU e regressioni visive nel lavoro web 3D. Non utilizzare per trasformazioni 3D CSS generiche o lavori su tela 2D statici che non utilizzano un grafico di scena Three.js.
