Utilice esta habilidad para CUALQUIER tarea que implique control de versiones jj o jujutsu. SIEMPRE se activa cuando el usuario menciona jj, jujutsu, revsets, ID de cambio, marcadores u oplog. También se activa cuando el usuario desea aplastar, dividir o reordenar las confirmaciones en una pila, escribir una consulta de revisión, absorber cambios de reparación, deshacer o restaurar una operación anterior, resolver conflictos después de cambiar la base, recuperarse de presiones forzadas, reescribir confirmaciones protegidas/inmutables, ver la evolución de los cambios (evolog) o probar enfoques paralelos. Activar incluso si "jj" no se dice explícitamente: "cambios" en lugar de "compromisos", "apilar" en lugar de "bifurcar", "absorber", "aplastar en el compromiso correcto", "deshacer mi última operación", "conflicto después de rebase" o "comparar enfoques en paralelo" son fuertes señales de jj. Esta habilidad contiene reglas críticas no obvias (como usar siempre indicadores -m) que evitan flujos de trabajo interrumpidos.
