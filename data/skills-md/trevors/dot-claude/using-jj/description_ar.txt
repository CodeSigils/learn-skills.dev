استخدم هذه المهارة في أي مهمة تتضمن التحكم في إصدار jj أو jujutsu. يتم تشغيله دائمًا عندما يذكر المستخدم jj أو jujutsu أو revsets أو تغيير المعرفات أو الإشارات المرجعية أو oplog. يتم التشغيل أيضًا عندما يريد المستخدم سحق الالتزامات أو تقسيمها أو إعادة ترتيبها في مكدس، أو كتابة استعلام revset، أو استيعاب تغييرات الإصلاح، أو التراجع عن عملية سابقة أو استعادتها، أو حل التعارضات بعد إعادة التأسيس، أو التعافي من دفعات القوة، أو إعادة كتابة الالتزامات المحمية/غير القابلة للتغيير، أو عرض تطور التغيير (evolog)، أو تجربة الأساليب المتوازية. قم بالتفعيل حتى لو لم يتم ذكر "jj" بشكل صريح - "التغييرات" بدلاً من "الالتزامات"، أو "المكدس" بدلاً من "الفرع"، أو "الاستيعاب"، أو "الاسكواش في الالتزام الصحيح"، أو "التراجع عن عمليتي الأخيرة"، أو "الصراع بعد إعادة الأساس"، أو "مقارنة الأساليب بالتوازي" هي إشارات JJ قوية. تحتوي هذه المهارة على قواعد مهمة غير واضحة (مثل استخدام العلامات -m دائمًا) والتي تمنع سير العمل المعطل.
