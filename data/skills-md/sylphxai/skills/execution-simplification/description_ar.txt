قم بتحويل مشكلات المنتج أو الهندسة أو العمليات أو الإستراتيجية أو مشكلات الدخول إلى السوق المعقدة إلى خطة تنفيذ بسيطة ذات ثوابت واضحة وحدود القرار والتسلسل والمخاطر والإجراءات التالية. يُستخدم عندما تبدو المهمة فوضوية، أو متعددة الوظائف، أو مفرطة النطاق، أو غامضة، أو عندما يطلب المستخدم التفكير النقدي، أو التبسيط، أو تحليل خارطة الطريق، أو استراتيجية تنفيذ عالية المستوى.
