تدقيق جاهزية إصدار تطبيق Windows بما في ذلك هوية المثبت/MSIX، وتوقيع التعليمات البرمجية، وسمعة SmartScreen، والخدمات، ومهام بدء التشغيل، وسلوك الدرج، وارتباطات التسجيل والملفات، والإشعارات، وتخزين بيانات الاعتماد، وAppData/ProgramData، ومطالبات جدار الحماية، والتحديث التلقائي، والتراجع، وتنظيف إلغاء التثبيت، وسجلات الأعطال، وشهادة Microsoft Store، وتشخيصات الدعم. يُستخدم عند شحن أو مراجعة التطبيقات والأدوات المساعدة لسطح مكتب Windows.
