Concevoir et auditer la résolution des litiges sur le marché pour les acheteurs, les vendeurs, les créateurs, les développeurs, les partenaires, les listes, les compétences, les applications, les services, les paiements, les remboursements, les rétrofacturations, les réclamations de qualité, les échecs de livraison, les violations de politique, les appels, les ensembles de preuves, les délais, les retenues de paiement, l'examen des fraudes, la communication et la surveillance de l'équité. À utiliser lorsque les conflits sur le marché nécessitent une résolution cohérente sans nuire à la confiance ou aux incitations.
