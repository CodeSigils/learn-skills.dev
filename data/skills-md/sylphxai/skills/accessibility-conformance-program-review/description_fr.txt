Concevoir et auditer des programmes de conformité en matière d'accessibilité pour les applications, les SaaS, les sites Web, les logiciels de bureau, les jeux, les places de marché et les outils de développement. Couvre les objectifs WCAG, VPAT/ACR, les audits, les tests de technologies d'assistance, les systèmes de conception, la gravité des problèmes, la propriété, la remédiation, les portes de publication, les preuves d'approvisionnement et la communication avec les clients. À utiliser lorsque l’accessibilité nécessite une gouvernance durable au-delà des audits ponctuels.
