Concevoir et auditer des taxonomies d'événements d'analyse pour les entonnoirs de produits, les SaaS, les applications mobiles, les jeux, les applications Web, les utilitaires de bureau, les marchés, les notifications, les paiements, l'assistance et les lancements. À utiliser lors de la définition d'événements, de propriétés, de dénomination, d'identité, d'entonnoirs, de cohortes, d'attribution, de mesures de garde-fou, de tableaux de bord ou de règles de qualité d'analyse.
