مهارة أفضل ممارسات تطوير جانغو. استخدم هذه المهارة عند العمل على مشاريع Django - بما في ذلك إنشاء النماذج، أو كتابة طرق العرض، أو إنشاء واجهات برمجة تطبيقات DRF، أو تصميم أنماط URL، أو كتابة الاختبارات، أو تكوين الإعدادات، أو التعامل مع عمليات الترحيل، أو مراجعة تعليمات Django البرمجية للتأكد من صحتها والأداء. يمكنك أيضًا طرح أسئلة حول استعلامات ORM، أو مشكلات N+1، أو تحديد_ذات الصلة/الجلب المسبق، أو المصادقة، أو الأذونات، أو البرامج الوسيطة، أو الإشارات، أو التخزين المؤقت، أو مهام Celery، أو النشر، أو Docker، أو بنية مشروع Django. إذا كانت المهمة تتضمن أي رمز Django أو Django REST Framework، فقم بتنشيط هذه المهارة على الفور.
