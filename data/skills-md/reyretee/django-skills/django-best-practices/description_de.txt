Best Practices für die Django-Entwicklung. Nutzen Sie diese Fähigkeit bei jeder Arbeit an Django-Projekten – einschließlich der Erstellung von Modellen, dem Schreiben von Ansichten, dem Erstellen von DRF-APIs, dem Entwerfen von URL-Mustern, dem Schreiben von Tests, dem Konfigurieren von Einstellungen, der Durchführung von Migrationen oder dem Überprüfen von Django-Code auf Korrektheit und Leistung. Wird auch für Fragen zu ORM-Abfragen, N+1-Problemen, select_bezogenen/prefetch_bezogenen Informationen, Authentifizierung, Berechtigungen, Middleware, Signalen, Caching, Celery-Aufgaben, Bereitstellung, Docker oder Django-Projektstruktur ausgelöst. Wenn die Aufgabe Django- oder Django REST Framework-Code umfasst, aktivieren Sie diesen Skill sofort.
