Habilidad de mejores prácticas de desarrollo de Django. Utilice esta habilidad siempre que trabaje en proyectos de Django, incluida la creación de modelos, la escritura de vistas, la creación de API DRF, el diseño de patrones de URL, la redacción de pruebas, la configuración, el manejo de migraciones o la revisión del código de Django para verificar su corrección y rendimiento. También activa preguntas sobre consultas ORM, problemas N+1, select_ related/prefetch_ related, autenticación, permisos, middleware, señales, almacenamiento en caché, tareas de Celery, implementación, Docker o estructura del proyecto Django. Si la tarea involucra algún código de Django o Django REST Framework, active esta habilidad inmediatamente.
