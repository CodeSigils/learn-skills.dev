Полноценная настройка, настройка и мастерство Claude Code. Используйте при настройке Claude Code для нового проекта, оптимизации существующей установки, настройке файлов CLAUDE.md, серверов MCP, перехватчиков, разрешений, команд агентов, навыков, плагинов, развития навыков, сред оценки или интеграции CI/CD. Запускается при: «настроить Claude Code», «настроить CLAUDE.md», «оптимизировать настройку Claude Code», «сервер MCP», «команды агентов», «перехватчики Claude Code», «разрешения Claude Code», «Claude Code CI/CD», «лучшие практики Claude Code», «улучшить мой рабочий процесс Claude Code», «развитие навыков», «фреймворк оценки», «развитие навыков» или любой вопрос о конфигурации Claude Code и архитектура. НЕ срабатывает при выполнении общих задач по кодированию, проверке кода, отладке или настройке инструментов, не связанных с Claude Code.
