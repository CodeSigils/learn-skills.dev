現在のブランチ上の 1 つの大きなコミットを、それぞれが独自に CI を渡す一連の小さなレビューサイズのコミットに置き換える場合に使用します。すべてのコミットは、従来のコミット タイプでは 100% 純粋です (リファクタリングは、動作の変更がゼロであることを意味します)。書き換え前にタイムスタンプ付きのバックアップ ブランチを自動的に作成し、元のコミットの作成者、日付、ツリーを完全に保存します。子孫のコミットは自動的に再スタックされます。トリガー: 「このコミットを分割する」、「このコミットをレビュー可能な部分に分割する」、「このコミットをセマンティック単位に分割する」、「このコミットを意味のある単位に分割する」、「分割」。複数の既存のコミットの並べ替え/スカッシュ → git rebase / コミットされていない変更の分割 → git add -p / スタックされた PR の管理 → gh-stack には使用しないでください。
