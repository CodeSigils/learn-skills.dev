À utiliser lorsque vous souhaitez remplacer un seul grand commit sur la branche actuelle, en place, par une séquence de petits commits de la taille d'une révision, dont chacun transmet le CI seul. Chaque commit est 100 % pur dans son type Conventional Commits (le refactor signifie aucun changement de comportement). Crée automatiquement une branche de sauvegarde horodatée avant la réécriture et préserve entièrement l'auteur, les dates et l'arborescence du commit d'origine. Les commits descendants sont automatiquement réempilés. Déclencheurs : "diviser ce commit", "diviser ce commit en morceaux révisables", "diviser ce commit en unités sémantiques", "diviser ce commit en unités significatives", "sculpter". Ne pas utiliser pour : réorganiser/écraser plusieurs commits existants → git rebase / diviser les modifications non validées → git add -p / gérer les PR empilés → gh-stack.
