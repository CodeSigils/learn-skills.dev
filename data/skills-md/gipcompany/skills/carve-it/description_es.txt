Úselo cuando desee reemplazar una única confirmación grande en la rama actual, en su lugar, con una secuencia de confirmaciones pequeñas del tamaño de una revisión, cada una de las cuales pasa CI por sí sola. Cada confirmación es 100% pura en su tipo de confirmaciones convencionales (refactorizar significa cero cambios de comportamiento). Crea automáticamente una rama de respaldo con marca de tiempo antes de reescribir y conserva completamente el autor, las fechas y el árbol de la confirmación original. Las confirmaciones descendientes se reapilan automáticamente. Activadores: "dividir este compromiso", "dividir este compromiso en partes revisables", "dividir este compromiso en unidades semánticas", "dividir este compromiso en unidades significativas", "tallar". No lo use para: reordenar/aplastar múltiples confirmaciones existentes → git rebase / dividir cambios no confirmados → git add -p / administrar PR apilados → gh-stack.
