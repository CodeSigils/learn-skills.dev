Используйте, если вы хотите заменить один большой коммит в текущей ветке последовательностью небольших коммитов размером с проверку, каждый из которых проходит CI самостоятельно. Каждый коммит является на 100% чистым в своем типе «Обычные коммиты» (рефакторинг означает нулевое изменение поведения). Автоматически создает резервную ветвь с отметкой времени перед перезаписью и полностью сохраняет автора, даты и дерево исходного коммита. Коммиты-потомки автоматически перегруппируются. Триггеры: «разделить этот коммит», «разбить этот коммит на проверяемые части», «разделить этот коммит на семантические единицы», «разделить этот коммит на значимые единицы», «вырезать». Не используйте для: изменения порядка/сжатия нескольких существующих коммитов → git rebase/разделения незафиксированных изменений → git add -p/управления сложенными PR → gh-stack.
