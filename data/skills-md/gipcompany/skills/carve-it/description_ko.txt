현재 분기에 있는 하나의 대규모 커밋을 각각 자체적으로 CI를 통과하는 작은 검토 크기의 커밋 시퀀스로 대체하려는 경우에 사용합니다. 모든 커밋은 기존 커밋 유형에서 100% 순수합니다(리팩터링은 동작 변경이 전혀 없음을 의미함). 다시 쓰기 전에 타임스탬프가 지정된 백업 브랜치를 자동으로 생성하고 원본 커밋의 작성자, 날짜 및 트리를 완전히 보존합니다. 하위 커밋은 자동으로 다시 스택됩니다. 트리거: "이 커밋 분할", "이 커밋을 검토 가능한 조각으로 분할", "이 커밋을 의미 단위로 분할", "이 커밋을 의미 있는 단위로 분할", "개척". 사용하지 마십시오: 여러 기존 커밋 재정렬/스쿼시 → git rebase / 커밋되지 않은 변경 사항 분할 → git add -p / 누적된 PR 관리 → gh-stack.
