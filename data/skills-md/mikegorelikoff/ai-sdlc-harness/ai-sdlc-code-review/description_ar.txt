سير عمل مراجعة كود AI SDLC. يُستخدم عندما يُطلب من مساعد الذكاء الاصطناعي مراجعة الفرق أو العلاقات العامة أو الفرع أو الالتزام أو التغييرات المرحلية أو التنفيذ المكتمل وفقًا لمتطلبات SDD والاختبارات وعقود API والأمان وانضباط النطاق. يدعم `--quick-flow` للتنفيذ السريع القائم على الافتراضات و`--full-flow` للتنفيذ المعتمد على الأسئلة.
