AI SDLC-Codeüberprüfungsworkflow. Use when an AI assistant is asked to review a diff, PR, branch, commit, staged changes, or completed implementation against SDD requirements, tests, API contracts, security, and scope discipline. Unterstützt „--quick-flow“ für eine schnelle annahmegesteuerte Ausführung und „--full-flow“ für eine fragengesteuerte verifizierte Ausführung.
