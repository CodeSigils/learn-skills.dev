استخدم ثنائي سطر الأوامر "السريالي" لتشغيل خادم SurrealDB (في الذاكرة، أو RocksDB، أو SurrealKV، أو TiKV)، وفتح SQL REPL التفاعلي أو عبر الأنابيب، واستيراد قواعد البيانات وتصديرها، والتحقق من جاهزية الخادم، وترقية الثنائي، وإصلاح التخزين، وإدارة نماذج SurrealML. استخدم هذه المهارة عندما يقوم المستخدمون بتشغيل SurrealDB أو الاتصال به أو نسخه احتياطيًا أو استعادته أو تشغيله من الجهاز. المشغلات: بداية سريالية، SQL سريالية، استيراد سريالي، تصدير سريالي، سريالي جاهز، ترقية سريالية، إصلاح سريالي، مل سريالي، SurrealDB CLI، خادم سريالي.
