Utilice el binario de línea de comandos `surreal` para ejecutar un servidor SurrealDB (en memoria, RocksDB, SurrealKV o TiKV), abra un REPL SQL interactivo o canalizado, importe y exporte bases de datos, verifique la preparación del servidor, actualice el binario, repare el almacenamiento y administre los modelos SurrealML. Utilice esta habilidad siempre que los usuarios ejecuten, se conecten, realicen copias de seguridad, restauren u operen SurrealDB desde la terminal. Activadores: inicio surrealista, sql surrealista, importación surrealista, exportación surrealista, surrealista ya listo, actualización surrealista, solución surrealista, ml surrealista, CLI de SurrealDB, servidor surrealista.
