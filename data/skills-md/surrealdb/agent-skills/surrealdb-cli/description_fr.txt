Utilisez le binaire de ligne de commande « surreal » pour exécuter un serveur SurrealDB (en mémoire, RocksDB, SurrealKV ou TiKV), ouvrir un REPL SQL interactif ou canalisé, importer et exporter des bases de données, vérifier l'état de préparation du serveur, mettre à niveau le binaire, réparer le stockage et gérer les modèles SurrealML. Utilisez cette compétence chaque fois que les utilisateurs exécutent, se connectent, sauvegardent, restaurent ou utilisent SurrealDB à partir du terminal. Déclencheurs : démarrage surréaliste, SQL surréaliste, importation surréaliste, exportation surréaliste, prêt surréaliste, mise à niveau surréaliste, correctif surréaliste, ml surréaliste, CLI SurrealDB, serveur surréaliste.
