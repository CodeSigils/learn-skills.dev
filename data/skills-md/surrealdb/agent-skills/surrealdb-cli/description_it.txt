Utilizza il file binario da riga di comando "surreal" per eseguire un server SurrealDB (in-memory, RocksDB, SurrealKV o TiKV), aprire un REPL SQL interattivo o in pipe, importare ed esportare database, verificare la disponibilità del server, aggiornare il file binario, riparare l'archiviazione e gestire modelli SurrealML. Utilizza questa competenza ogni volta che gli utenti eseguono, si connettono, eseguono il backup, ripristinano o utilizzano SurrealDB dal terminale. Trigger: inizio surreale, sql surreale, importazione surreale, esportazione surreale, isready surreale, aggiornamento surreale, correzione surreale, ml surreale, CLI SurrealDB, server surreale.
