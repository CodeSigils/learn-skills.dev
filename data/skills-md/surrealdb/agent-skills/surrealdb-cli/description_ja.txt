「surreal」コマンドライン バイナリを使用して、SurrealDB サーバー (インメモリ、RocksDB、SurrealKV、または TiKV) を実行し、対話型またはパイプされた SQL REPL を開き、データベースのインポートとエクスポート、サーバーの準備状況の確認、バイナリのアップグレード、ストレージの修復、および SurrealML モデルの管理を行います。ユーザーがターミナルから SurrealDB を実行、接続、バックアップ、復元、または操作するときは常に、このスキルを使用します。トリガー: 超現実的な開始、超現実的な SQL、超現実的なインポート、超現実的なエクスポート、超現実的な isready、超現実的なアップグレード、超現実的な修正、超現実的な ml、超現実的な DB CLI、超現実的なサーバー。
