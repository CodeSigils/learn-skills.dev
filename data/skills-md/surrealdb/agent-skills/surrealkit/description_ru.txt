Используйте SurrealKit, интерфейс командной строки SurrealDB для управления схемами и миграции, чтобы создавать проекты на основе шаблонов, синхронизировать схему в разработке, планировать и выполнять производственные развертывания (с откатом), генерировать типы JSON/TypeScript из действующей базы данных и писать декларативные наборы тестов TOML для схем, разрешений и конечных точек API. Используйте этот навык всякий раз, когда пользователи настраивают, переносят, печатают или тестируют схему SurrealDB с помощью SurrealKit.
