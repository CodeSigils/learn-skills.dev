Utilizza SurrealKit, la CLI di migrazione e gestione degli schemi di SurrealDB, per impalcare progetti da modelli, sincronizzare lo schema in fase di sviluppo, pianificare ed eseguire implementazioni di produzione (con rollback), generare tipi JSON/TypeScript da un database live e scrivere suite di test TOML dichiarativi per schemi, autorizzazioni ed endpoint API. Utilizza questa competenza ogni volta che gli utenti configurano, eseguono la migrazione, digitano o testano uno schema SurrealDB con SurrealKit.
