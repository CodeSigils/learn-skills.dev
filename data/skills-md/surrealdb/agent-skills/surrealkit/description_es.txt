Utilice SurrealKit, la CLI de migración y administración de esquemas de SurrealDB, para desarrollar proyectos a partir de plantillas, sincronizar esquemas en desarrollo, planificar y ejecutar implementaciones de producción (con reversión), generar tipos JSON/TypeScript a partir de una base de datos activa y escribir conjuntos de pruebas TOML declarativas para esquemas, permisos y puntos finales de API. Utilice esta habilidad siempre que los usuarios configuren, migren, escriban o prueben un esquema de SurrealDB con SurrealKit.
