Genere y modifique consultas SurrealQL para interactuar con las bases de datos SurrealDB. Esto incluye crear y recuperar registros, diseñar y administrar esquemas, establecer y consultar relaciones de gráficos, realizar consultas en vivo (en tiempo real) y aprovechar todas las características únicas de SurrealQL para flujos de trabajo de bases de datos avanzados. Utilice esta habilidad siempre que los usuarios necesiten escribir, adaptar o solucionar problemas de declaraciones SurrealQL.
