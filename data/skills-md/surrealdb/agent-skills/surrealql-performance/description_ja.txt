レコード ID とキーの設計、インデックス付け戦略、計算フィールド/派生フィールドを通じて、SurrealDB のパフォーマンスを最適化します。クエリが遅い場合、ローカリティおよび範囲スキャンのレコード ID を設計する場合、標準/一意/フルテキスト/ベクター インデックスのいずれかを選択する場合、EXPLAIN を使用してインデックスの使用状況を確認する場合、または計算フィールド、ビュー、またはイベントで値を事前計算するかどうかを決定する場合に使用します。トリガー: 遅いクエリ、パフォーマンス、レコード ID 設計、範囲スキャン、DEFINE INDEX、EXPLAIN、計算フィールド、FUTURE、DEFINE TABLE AS SELECT。
