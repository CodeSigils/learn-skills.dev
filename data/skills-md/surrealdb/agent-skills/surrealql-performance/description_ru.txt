Оптимизируйте производительность SurrealDB за счет идентификатора записи и дизайна ключа, стратегии индексирования и вычисляемых/производных полей. Используйте, когда запросы выполняются медленно, при разработке идентификаторов записей для сканирования локальности и диапазона, выборе между стандартными/уникальными/полнотекстовыми/векторными индексами, проверке использования индекса с помощью EXPLAIN или принятии решения о предварительном вычислении значений с помощью вычисленных полей, представлений или событий. Триггеры: медленный запрос, производительность, дизайн идентификатора записи, сканирование диапазона, DEFINE INDEX, EXPLAIN, вычисляемое поле, FUTURE, DEFINE TABLE AS SELECT.
