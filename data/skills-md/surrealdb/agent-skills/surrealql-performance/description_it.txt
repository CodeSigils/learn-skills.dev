Ottimizza le prestazioni di SurrealDB attraverso l'ID del record e la progettazione delle chiavi, la strategia di indicizzazione e i campi calcolati/derivati. Da utilizzare quando le query sono lente, quando si progettano ID record per scansioni di località e intervalli, si sceglie tra indici standard/univoci/di testo completo/vettoriali, si verifica l'utilizzo dell'indice con EXPLAIN o si decide se precalcolare valori con campi, visualizzazioni o eventi calcolati. Trigger: query lenta, prestazioni, progettazione ID record, scansione intervallo, DEFINE INDEX, EXPLAIN, campo calcolato, FUTURO, DEFINE TABLE AS SELECT.
