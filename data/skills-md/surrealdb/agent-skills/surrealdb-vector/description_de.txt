Vektorsuche mit SurrealDB unter Verwendung von HNSW-Indizes, KNN-Abfragen und Ähnlichkeitsbewertung. Verwendung beim Erstellen von Vektorindizes, beim Abfragen von Vektoren mit KNN-Distanzoperatoren, beim Erstellen semantischer Suche oder RAG-Pipelines, beim Optimieren von HNSW-Parametern (EFC, M, M0, Distanzfunktion, Typ) oder beim Implementieren von Empfehlungssystemen mit SurrealDB. Auslöser: HNSW, Vektor, Einbettung, KNN, Kosinus, Euklidisch, semantische Suche, RAG, Vektor::Entfernung.
