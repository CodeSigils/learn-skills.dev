Векторный поиск с помощью SurrealDB с использованием индексов HNSW, запросов KNN и оценки сходства. Используйте при создании векторных индексов, запросе векторов с помощью операторов расстояния KNN, построении семантического поиска или конвейеров RAG, настройке параметров HNSW (EFC, M, M0, функция расстояния, тип) или реализации систем рекомендаций с помощью SurrealDB. Триггеры: HNSW, вектор, встраивание, KNN, косинус, евклидово, семантический поиск, RAG, вектор::дистанция.
