البحث المتجه باستخدام SurrealDB باستخدام فهارس HNSW واستعلامات KNN وتسجيل التشابه. يُستخدم عند إنشاء فهارس المتجهات، أو الاستعلام عن المتجهات باستخدام مشغلي مسافة KNN، أو إنشاء بحث دلالي أو خطوط أنابيب RAG، أو ضبط معلمات HNSW (EFC، أو M، أو M0، أو وظيفة المسافة، أو النوع)، أو تنفيذ أنظمة التوصية باستخدام SurrealDB. المشغلات: HNSW، المتجه، التضمين، KNN، جيب التمام، الإقليدية، البحث الدلالي، RAG، المتجه::المسافة.
