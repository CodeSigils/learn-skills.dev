Verwendung von SurrealDB mit dem Python SDK, das sowohl den Client/Server-Modus (WebSocket) als auch den eingebetteten Modus (im Speicher oder dateibasiert) abdeckt. Verwenden Sie diese Option, wenn Sie über Python eine Verbindung zu SurrealDB herstellen, das Python-Paket surrealdb verwenden, SurrealDB eingebettet ohne Server ausführen oder CRUD-Vorgänge über Python-Code ausführen. Auslöser: surrealdb Python, Surreal(), AsyncSurreal(), Python SDK, eingebettetes SurrealDB, mem://, file://.
