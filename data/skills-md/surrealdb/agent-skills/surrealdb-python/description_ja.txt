SurrealDB を Python SDK とともに使用し、クライアント/サーバー モード (WebSocket) と組み込みモード (メモリ内またはファイルベース) の両方をカバーします。 Python から SurrealDB に接続する場合、surrealdb Python パッケージを使用する場合、サーバーなしで埋め込まれた SurrealDB を実行する場合、または Python コードから CRUD 操作を実行する場合に使用します。トリガー: surrealdb Python、Surreal()、AsyncSurreal()、Python SDK、埋め込み SurrealDB、mem://、file://。
