Utilizzo di SurrealDB con Python SDK, che copre sia la modalità client/server (WebSocket) che la modalità incorporata (in memoria o basata su file). Da utilizzare quando ci si connette a SurrealDB da Python, utilizzando il pacchetto Python surrealdb, eseguendo SurrealDB incorporato senza un server o eseguendo operazioni CRUD dal codice Python.
