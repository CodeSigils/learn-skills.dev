Uso de SurrealDB con el SDK de Python, que cubre tanto el modo cliente/servidor (WebSocket) como el modo integrado (en memoria o basado en archivos). Úselo al conectarse a SurrealDB desde Python, usar el paquete surrealdb Python, ejecutar SurrealDB integrado sin un servidor o realizar operaciones CRUD desde código Python. Activadores: surrealdb Python, Surreal(), AsyncSurreal(), Python SDK, SurrealDB integrado, mem://, file://.
