Использование SurrealDB с Python SDK, охватывающее как режим клиент/сервер (WebSocket), так и встроенный режим (в памяти или на основе файла). Используйте при подключении к SurrealDB из Python, использовании пакета Surrealdb Python, запуске SurrealDB, встроенного без сервера, или выполнении операций CRUD из кода Python. Триггеры: surrealdb Python, Surreal(), AsyncSurreal(), Python SDK, встроенная SurrealDB, mem://, file://.
