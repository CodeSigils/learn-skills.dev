Utilisation de SurrealDB avec le SDK Python, couvrant à la fois le mode client/serveur (WebSocket) et le mode embarqué (en mémoire ou basé sur fichier). À utiliser lors de la connexion à SurrealDB à partir de Python, à l'aide du package Python surrealdb, à l'exécution de SurrealDB intégré sans serveur ou à l'exécution d'opérations CRUD à partir du code Python. Déclencheurs : surrealdb Python, Surreal(), AsyncSurreal(), Python SDK, SurrealDB intégré, mem://, file://.
