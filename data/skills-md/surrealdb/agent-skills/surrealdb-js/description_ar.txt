استخدام SurrealDB من JavaScript وTypeScript مع surrealdb SDK الرسمي، الذي يغطي الاتصال (WebSocket/HTTP والمحركات المضمنة)، والمصادقة، وCRUD، والاستعلامات ذات المعلمات، والاستعلامات المباشرة. يُستخدم عند الاتصال بـ SurrealDB من Node أو Deno أو Bun أو المتصفح، باستخدام حزمة surrealdb npm، أو إجراء عمليات CRUD وفي الوقت الفعلي من كود JS/TS. المشغلات: surrealdb JS، وsurrealdb.js، وnew Surreal()، وdb.query، وdb.create، وdb.live، وTypeScript SDK، وnpm، وsurrealdb.
