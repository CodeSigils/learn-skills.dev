Использование SurrealDB из JavaScript и TypeScript с официальным SDK surrealdb, включая подключение (WebSocket/HTTP и встроенные механизмы), аутентификацию, CRUD, параметризованные запросы и живые запросы. Используйте при подключении к SurrealDB из Node, Deno, Bun или браузера, с использованием пакета surrealdb npm или при выполнении CRUD и операций в реальном времени из кода JS/TS. Триггеры: surrealdb JS, surrealdb.js, new Surreal(), db.query, db.create, db.live, TypeScript SDK, npm и surrealdb.
