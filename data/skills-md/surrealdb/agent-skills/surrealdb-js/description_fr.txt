Utilisation de SurrealDB à partir de JavaScript et TypeScript avec le SDK officiel surrealdb, couvrant la connexion (WebSocket/HTTP et moteurs intégrés), l'authentification, CRUD, les requêtes paramétrées et les requêtes en direct. À utiliser lors de la connexion à SurrealDB à partir de Node, Deno, Bun ou du navigateur, à l'aide du package surrealdb npm ou lors de l'exécution d'opérations CRUD et en temps réel à partir du code JS/TS. Déclencheurs : surrealdb JS, surrealdb.js, new Surreal(), db.query, db.create, db.live, TypeScript SDK, npm et surrealdb.
