Verwendung von SurrealDB aus JavaScript und TypeScript mit dem offiziellen surrealdb SDK, das Verbindungen (WebSocket/HTTP und eingebettete Engines), Authentifizierung, CRUD, parametrisierte Abfragen und Live-Abfragen abdeckt. Verwenden Sie diese Option, wenn Sie über Node, Deno, Bun oder den Browser eine Verbindung zu SurrealDB herstellen, das surrealdb npm-Paket verwenden oder CRUD- und Echtzeitoperationen über JS/TS-Code ausführen. Auslöser: surrealdb JS, surrealdb.js, new Surreal(), db.query, db.create, db.live, TypeScript SDK, npm und surrealdb.
