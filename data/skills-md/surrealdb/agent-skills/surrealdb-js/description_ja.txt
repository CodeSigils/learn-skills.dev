公式 surrealdb SDK を使用して JavaScript および TypeScript から SurrealDB を使用し、接続 (WebSocket/HTTP および組み込みエンジン)、認証、CRUD、パラメーター化されたクエリ、ライブ クエリをカバーします。 Node、Deno、Bun、またはブラウザから SurrealDB に接続する場合、surrealdb npm パッケージを使用する場合、または JS/TS コードから CRUD およびリアルタイム操作を実行する場合に使用します。トリガー: surrealdb JS、surrealdb.js、new Surreal()、db.query、db.create、db.live、TypeScript SDK、npm i surrealdb。
