Uso de SurrealDB desde JavaScript y TypeScript con el SDK oficial de surrealdb, que cubre conexión (WebSocket/HTTP y motores integrados), autenticación, CRUD, consultas parametrizadas y consultas en vivo. Úselo al conectarse a SurrealDB desde Node, Deno, Bun o el navegador, usando el paquete npm surrealdb o realizando operaciones CRUD y en tiempo real desde código JS/TS. Activadores: surrealdb JS, surrealdb.js, new Surreal(), db.query, db.create, db.live, TypeScript SDK, npm y surrealdb.
