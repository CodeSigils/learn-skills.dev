Безопасный Windows C: анализ пространства на диске и рабочий процесс очистки. Используйте, когда пользователь просит Кодекс просканировать, диагностировать, очистить, освободить место, удалить большие файлы, определить кандидатов на удаление или устранить проблему нехватки места на системном диске Windows, особенно C:\. В первую очередь особое внимание уделяется анализу только для чтения, классификации рисков, явному одобрению пользователя перед удалением или деинсталляцией, локальному сканированию с сохранением конфиденциальности и безопасному обращению с установщиком Windows, WinSxS, AppData, ProgramData, кэшами, личными файлами и большими данными приложений.
