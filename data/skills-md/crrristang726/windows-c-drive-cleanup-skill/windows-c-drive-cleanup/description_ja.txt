安全な Windows C: ドライブ領域の分析とクリーンアップのワークフロー。ユーザーが Codex に対して、Windows システム ドライブ (特に C:\) のスキャン、診断、クリーニング、領域の解放、大きなファイルの削除、アンインストール候補の特定、またはディスク領域不足のトラブルシューティングを依頼する場合に使用します。最初の読み取り専用分析、リスク分類、削除またはアンインストール前の明示的なユーザー承認、プライバシーを保護するローカルのみのスキャン、Windows インストーラー、WinSxS、AppData、ProgramData、キャッシュ、個人ファイル、および大規模なアプリケーション データの安全な処理を強調します。
