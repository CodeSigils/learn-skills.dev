Safe Windows C: análisis del espacio en disco y flujo de trabajo de limpieza. Úselo cuando un usuario le pide a Codex que escanee, diagnostique, limpie, libere espacio, elimine archivos grandes, identifique candidatos a desinstalación o solucione problemas de poco espacio en disco en una unidad del sistema Windows, especialmente C:\. Enfatiza primero el análisis de solo lectura, la clasificación de riesgos, la aprobación explícita del usuario antes de la eliminación o desinstalación, los análisis locales que preservan la privacidad y el manejo seguro de Windows Installer, WinSxS, AppData, ProgramData, cachés, archivos personales y datos de aplicaciones de gran tamaño.
