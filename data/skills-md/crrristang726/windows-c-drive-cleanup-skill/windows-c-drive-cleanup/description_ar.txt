نظام التشغيل Windows الآمن C: تحليل مساحة محرك الأقراص وسير عمل التنظيف. يُستخدم عندما يطلب المستخدم من Codex إجراء مسح للمساحة أو تشخيصها أو تنظيفها أو تحريرها أو إزالة الملفات الكبيرة أو تحديد المرشحين لإلغاء التثبيت أو استكشاف أخطاء مساحة القرص المنخفضة وإصلاحها على محرك أقراص نظام Windows، وخاصة C:\. يؤكد على التحليل للقراءة فقط أولاً، وتصنيف المخاطر، وموافقة المستخدم الصريحة قبل الحذف أو إلغاء التثبيت، وعمليات الفحص المحلية فقط التي تحافظ على الخصوصية، والتعامل الآمن مع Windows Installer، وWinSxS، وAppData، وProgramData، وذاكرات التخزين المؤقت، والملفات الشخصية، وبيانات التطبيقات الكبيرة.
