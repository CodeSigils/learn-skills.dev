Safe Windows C: analisi dello spazio su disco e flusso di lavoro di pulizia. Da utilizzare quando un utente chiede a Codex di scansionare, diagnosticare, pulire, liberare spazio, rimuovere file di grandi dimensioni, identificare candidati alla disinstallazione o risolvere problemi di spazio su disco insufficiente su un'unità di sistema Windows, in particolare C:\. Enfatizza innanzitutto l'analisi di sola lettura, la classificazione dei rischi, l'approvazione esplicita dell'utente prima dell'eliminazione o della disinstallazione, le scansioni solo locali nel rispetto della privacy e la gestione sicura di Windows Installer, WinSxS, AppData, ProgramData, cache, file personali e dati di applicazioni di grandi dimensioni.
