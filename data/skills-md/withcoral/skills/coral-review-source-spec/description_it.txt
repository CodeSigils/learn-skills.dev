Esamina i manifest delle fonti Coral nuovi o aggiornati e le PR delle fonti per contenuto, stile, idoneità del prodotto, ergonomia delle query, qualità della documentazione e coerenza con le fonti Coral esistenti. Da utilizzare quando al Codex viene chiesto di rivedere una directory source source/core/name o source/community/name, un file manifest.yaml o un PR GitHub che aggiunge o modifica una fonte Coral.
