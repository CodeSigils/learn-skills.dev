Diseñe, desarrolle y contribuya con un tema comunitario a openstatus (la página de estado de código abierto). Úselo siempre que el usuario quiera crear un nuevo tema, personalizar los colores de la página de estado, crear una paleta para su marca, bifurcar y contribuir a `@openstatus/theme-store` de openstatus, o mencionar colores OKLCH, variables CSS o temas.openstatus.dev. También se usa cuando el usuario pega una exportación de tema desde el explorador en vivo y quiere conectarlo al repositorio.
