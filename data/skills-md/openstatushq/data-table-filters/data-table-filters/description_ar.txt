تثبيت وتوسيع مرشحات جدول البيانات - نظام جدول بيانات React مع مرشحات متعددة الأوجه (مربع الاختيار، والإدخال، وشريط التمرير، والنطاق الزمني)، والفرز، والتمرير اللانهائي، والمحاكاة الافتراضية، وإدارة حالة BYOS. تم تسليمها كـ 11 قالب تسجيل shadcn قابل للتثبيت عبر `npx shadcn@latest add`. يُستخدم عندما: (1) تثبيت عوامل تصفية جدول البيانات من سجل shadcn، (2) إضافة كتل الامتداد (لوحة الأوامر، مرشحات الذكاء الاصطناعي، عارضات الخلايا، لوحة الأوراق، محولات المتجر، نظام المخطط، مساعدات Drizzle، طبقة الاستعلام)، (3) تكوين محولات المتجر (nuqs/zustand/الذاكرة)، (4) إنشاء مخططات الجدول من نموذج بيانات، (5) توصيل التصفية من جانب الخادم باستخدام Drizzle ORM، (6) توصيل طبقة جلب استعلام React، (7) مخططات الاستدلال التلقائي من بيانات JSON الأولية باستخدام DataTableAuto / inferSchemaFromJSON، (8) إضافة تصفية اللغة الطبيعية المدعومة بالذكاء الاصطناعي، (9) كشف الجداول كنقاط نهاية MCP لوكلاء الذكاء الاصطناعي، (10) استكشاف مشكلات التكامل وإصلاحها. يتم تشغيله عند الإشارة إلى "data-table-filters"، أو "data-table-filters.com"، أو جداول البيانات القابلة للتصفية باستخدام shadcn، أو DataTableAuto، أو الاستدلال التلقائي، أو مرشحات الذكاء الاصطناعي، أو خادم MCP، أو أي من أسماء كتل التسجيل.
