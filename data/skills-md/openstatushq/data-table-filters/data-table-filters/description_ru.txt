Устанавливайте и расширяйте data-table-filters — систему таблиц данных React с фасетными фильтрами (флажок, ввод, ползунок, временной диапазон), сортировкой, бесконечной прокруткой, виртуализацией и управлением состоянием BYOS. Поставляется в виде 11 блоков реестра shadcn, которые можно установить через npx shadcn@latest add. Используйте при: (1) установке фильтров таблиц данных из реестра shadcn, (2) добавлении блоков расширения (палитра команд, фильтры AI, средства рендеринга ячеек, панель листов, адаптеры хранилища, система схем, помощники Drizzle, слой запросов), (3) настройка адаптеров хранилища (nuqs/zustand/memory), (4) создание схем таблиц из модели данных, (5) подключение серверной фильтрации с помощью Drizzle ORM, (6) подключение React Уровень выборки запроса, (7) автоматический вывод схем из необработанных данных JSON с помощью DataTableAuto/inferSchemaFromJSON, (8) добавление фильтрации естественного языка на основе искусственного интеллекта, (9) предоставление таблиц в качестве конечных точек MCP для агентов AI, (10) устранение проблем интеграции. Срабатывает при упоминании «data-table-filters», «data-table-filters.com», фильтруемых таблиц данных с помощью shadcn, DataTableAuto, автоматического вывода, фильтров AI, сервера MCP или любого имени блока реестра.
