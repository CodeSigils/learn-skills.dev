데이터 테이블 필터 설치 및 확장 — 패싯 필터(체크박스, 입력, 슬라이더, 시간 범위), 정렬, 무한 스크롤, 가상화 및 BYOS 상태 관리를 갖춘 React 데이터 테이블 시스템입니다. `npx shadcn@latest add`를 통해 설치할 수 있는 11개의 shadcn 레지스트리 블록으로 제공됩니다. 다음 경우에 사용하십시오: (1) shadcn 레지스트리에서 데이터 테이블 필터 설치, (2) 확장 블록 추가(명령 팔레트, AI 필터, 셀 렌더러, 시트 패널, 저장소 어댑터, 스키마 시스템, Drizzle 도우미, 쿼리 레이어), (3) 저장소 어댑터 구성(nuqs/zustand/memory), (4) 데이터 모델에서 테이블 스키마 생성, (5) Drizzle ORM으로 서버 측 필터링 연결, (6) React 쿼리 연결 레이어 가져오기, (7) DataTableAuto / inferSchemaFromJSON을 사용하여 원시 JSON 데이터에서 스키마 자동 추론, (8) AI 기반 자연어 필터링 추가, (9) 테이블을 AI 에이전트의 MCP 엔드포인트로 노출, (10) 통합 문제 해결.
