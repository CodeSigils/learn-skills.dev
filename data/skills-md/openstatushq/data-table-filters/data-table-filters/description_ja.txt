data-table-filters をインストールして拡張します。ファセット フィルター (チェックボックス、入力、スライダー、タイムレンジ)、並べ替え、無限スクロール、仮想化、BYOS 状態管理を備えた React データ テーブル システムです。 「npx shadcn@latest add」経由でインストール可能な 11 個の shadcn レジストリ ブロックとして提供されます。次の場合に使用します: (1) shadcn レジストリから data-table-filters をインストールする、(2) 拡張ブロック (コマンド パレット、AI フィルター、セル レンダラー、シート パネル、ストア アダプター、スキーマ システム、Drizzle ヘルパー、クエリ レイヤー) を追加する、(3) ストア アダプターを構成する (nuqs/zustand/memory)、(4) データ モデルからテーブル スキーマを生成する、(5) Drizzle を使用してサーバー側フィルタリングを接続するORM、(6) React Query フェッチ レイヤーの接続、(7) DataTableAuto / inferSchemaFromJSON による生の JSON データからのスキーマの自動推論、(8) AI を利用した自然言語フィルタリングの追加、(9) AI エージェントの MCP エンドポイントとしてのテーブルの公開、(10) 統合の問題のトラブルシューティング。 「data-table-filters」、「data-table-filters.com」、shadcn を使用したフィルター可能なデータ テーブル、DataTableAuto、自動推論、AI フィルター、MCP サーバー、またはいずれかのレジストリ ブロック名が言及されるとトリガーされます。
