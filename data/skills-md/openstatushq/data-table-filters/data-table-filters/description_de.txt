Installieren und erweitern Sie data-table-filters – ein React-Datentabellensystem mit facettierten Filtern (Kontrollkästchen, Eingabe, Schieberegler, Zeitbereich), Sortierung, unendlichem Scrollen, Virtualisierung und BYOS-Statusverwaltung. Wird als 11 Shadcn-Registrierungsblöcke geliefert, die über „npx shadcn@latest add“ installiert werden können. Wird verwendet, wenn: (1) Datentabellenfilter aus der Shadcn-Registrierung installiert werden, (2) Erweiterungsblöcke hinzugefügt werden (Befehlspalette, AI-Filter, Zellrenderer, Blattbereich, Speicheradapter, Schemasystem, Drizzle-Helfer, Abfrageebene), (3) Speicheradapter konfiguriert werden (nuqs/zustand/memory), (4) Tabellenschemata aus einem Datenmodell generiert werden, (5) serverseitige Filterung mit Drizzle ORM verbunden wird, (6) Verbindung hergestellt wird die React Query-Abrufschicht, (7) automatisches Ableiten von Schemata aus JSON-Rohdaten mit DataTableAuto / inferSchemaFromJSON, (8) Hinzufügen von KI-gestützter Filterung in natürlicher Sprache, (9) Offenlegen von Tabellen als MCP-Endpunkte für KI-Agenten, (10) Beheben von Integrationsproblemen. Wird bei Erwähnungen von „data-table-filters“, „data-table-filters.com“, filterbaren Datentabellen mit shadcn, DataTableAuto, Auto-Infer, AI-Filtern, MCP-Server oder einem der Registrierungsblocknamen ausgelöst.
