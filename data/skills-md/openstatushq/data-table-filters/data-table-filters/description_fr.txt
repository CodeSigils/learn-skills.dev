Installez et étendez les filtres de table de données : un système de table de données React avec des filtres à facettes (case à cocher, entrée, curseur, plage de temps), un tri, un défilement infini, une virtualisation et une gestion de l'état BYOS. Livré sous forme de 11 blocs de registre shadcn installables via `npx shadcn@latest add`. À utiliser lors de : (1) l'installation de filtres de table de données à partir du registre shadcn, (2) l'ajout de blocs d'extension (palette de commandes, filtres AI, moteurs de rendu de cellules, panneau de feuille, adaptateurs de magasin, système de schéma, assistants Drizzle, couche de requête), (3) la configuration d'adaptateurs de magasin (nuqs/zustand/memory), (4) la génération de schémas de table à partir d'un modèle de données, (5) le câblage du filtrage côté serveur avec Drizzle ORM, (6) la connexion la couche de récupération React Query, (7) l'auto-inférence de schémas à partir de données JSON brutes avec DataTableAuto / inferSchemaFromJSON, (8) l'ajout d'un filtrage du langage naturel alimenté par l'IA, (9) l'exposition des tables en tant que points de terminaison MCP pour les agents IA, (10) le dépannage des problèmes d'intégration. Se déclenche sur les mentions de « data-table-filters », « data-table-filters.com », de tables de données filtrables avec shadcn, DataTableAuto, auto-infer, filtres AI, serveur MCP ou l'un des noms de blocs de registre.
