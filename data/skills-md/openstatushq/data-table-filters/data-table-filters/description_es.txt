Se activa cuando se mencionan "filtros de tabla de datos", "filtros de tabla de datos.com", tablas de datos filtrables con shadcn, DataTableAuto, autoinferencia, filtros AI, servidor MCP o cualquiera de los nombres de bloques de registro.
