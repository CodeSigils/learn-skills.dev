安装和扩展 data-table-filters — 一个 React 数据表系统，具有多面过滤器（复选框、输入、滑块、时间范围）、排序、无限滚动、虚拟化和 BYOS 状态管理。以 11 个 shadcn 注册表块形式提供，可通过“npx shadcn@latest add”安装。在以下情况下使用：(1) 从 shadcn 注册表安装数据表过滤器，(2) 添加扩展块（命令面板、AI 过滤器、单元格渲染器、工作表面板、存储适配器、模式系统、Drizzle 助手、查询层），(3) 配置存储适配器 (nuqs/zustand/memory)，(4) 从数据模型生成表模式，(5) 使用 Drizzle ORM 连接服务器端过滤，(6) 连接 React 查询获取(7) 使用 DataTableAuto / inferSchemaFromJSON 从原始 JSON 数据自动推断模式，(8) 添加 AI 支持的自然语言过滤，(9) 将表公开为 AI 代理的 MCP 端点，(10) 解决集成问题。在提及“data-table-filters”、“data-table-filters.com”、带有 shadcn、DataTableAuto、自动推断、AI 过滤器、MCP 服务器或任何注册表块名称的可过滤数据表时触发。
