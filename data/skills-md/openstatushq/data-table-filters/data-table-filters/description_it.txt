Installa ed estendi i filtri delle tabelle di dati: un sistema di tabelle di dati React con filtri sfaccettati (casella di controllo, input, dispositivo di scorrimento, intervallo temporale), ordinamento, scorrimento infinito, virtualizzazione e gestione dello stato BYOS. Fornito come 11 blocchi di registro shadcn installabili tramite `npx shadcn@latest add`. Utilizzare quando: (1) installare filtri di tabelle dati dal registro shadcn, (2) aggiungere blocchi di estensione (palette dei comandi, filtri AI, renderer di celle, pannello fogli, adattatori di negozio, sistema di schemi, helper Drizzle, livello di query), (3) configurare adattatori di negozi (nuqs/zustand/memory), (4) generare schemi di tabelle da un modello di dati, (5) collegare il filtro lato server con Drizzle ORM, (6) connettere React Livello di recupero delle query, (7) schemi di inferenza automatica da dati JSON non elaborati con DataTableAuto/inferSchemaFromJSON, (8) aggiunta di filtri in linguaggio naturale basati sull'intelligenza artificiale, (9) esposizione di tabelle come endpoint MCP per agenti AI, (10) risoluzione dei problemi di integrazione. Si attiva quando vengono menzionati "data-table-filters", "data-table-filters.com", tabelle di dati filtrabili con shadcn, DataTableAuto, auto-infer, filtri AI, server MCP o qualsiasi nome di blocco del registro.
