Cette compétence doit être utilisée lorsque l'utilisateur souhaite « se connecter à GitHub », « stocker une clé API », « obtenir des en-têtes d'authentification », « exporter les informations d'identification vers le shell », « exécuter une commande avec des clés API injectées », « enregistrer un fournisseur OAuth personnalisé », « gérer les jetons d'outil » ou « s'authentifier auprès d'une application tierce ». Déclenche également des requêtes impliquant l'authentification d'agents IA ou le stockage/récupération d'informations d'identification en toute sécurité à l'aide de la CLI authentique.
