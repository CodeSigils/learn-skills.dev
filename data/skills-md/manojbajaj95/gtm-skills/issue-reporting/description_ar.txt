يساعد المستخدمين على الإبلاغ عن المشكلات المتعلقة بمهارات GTM - نصيحة غير صحيحة، أو تنشيط معطل، أو سياق مفقود، أو سلوك غير متوقع. يرشد من خلال جمع التفاصيل الصحيحة (اسم المهارة، والموجه المستخدم، والمخرجات الفعلية مقابل المتوقعة، وملفات السياق الموجودة) وينشئ مشكلة GitHub منسقة بشكل صحيح. يُستخدم عندما يقول المستخدمون: "هذه المهارة أعطت نصيحة خاطئة"، أو "أبلغ عن خطأ"، أو "أبلغ عن مشكلة"، أو "المهارة لا تعمل"، أو "مخرجات خاطئة"، أو "لم يتم تنشيط المهارة"، أو "توصية سيئة"، أو "سلوك غير صحيح"، أو "هناك شيء معطل".
