Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer eine Präsentationsgliederung, eine Folienstruktur oder Storyboard-Folien erstellen oder eine Präsentation für einen beliebigen Kontext (Vortrag, Sitzungssaal, E-Mail-Bericht) planen möchte. Verwenden Sie es auch, wenn der Benutzer „Hilf mir, meine Präsentation zu strukturieren“, „Foliengliederung“, „Storyboard meines Decks“, „Präsentationsablauf“, „meine Folien planen“, „Schlüsselbotschaft für mein Deck“, „Pyramidenprinzip für Folien“, „welche Folien sollte ich einschließen“ oder „hilft mir, eine Geschichte mit Folien zu erzählen“ erwähnt. Dieser Skill durchläuft einen vollständigen, interaktiven Prozess in zwei Phasen: Phase 1 (Einrichtung → Kernbotschaft → Storyboard) speichert eine slide-outline.md; Phase 2 (interaktive Erstellung von Kopien pro Folie → Polieren) speichert eine slide-copy.md, die von slide-outline.md verlinkt wird. Wird auch dann ausgelöst, wenn der Benutzer nur eine vage Absicht erwähnt, wie „Ich muss meinem Team X präsentieren“ oder „Hilf mir, ein Board-Deck zusammenzustellen“.
