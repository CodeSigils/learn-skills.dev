ابحث في موضوعات YouTube، وحلل مقاطع الفيديو المنافسة، وقم بتفكيك المحتوى واسع الانتشار، واستفسر عن YouTube Data API. يُستخدم عند البحث عن موضوع فيديو قبل التخطيط، أو تحليل نصوص الفيديو بحثًا عن أنماط سريعة الانتشار، أو البحث في القنوات المنافسة، أو جلب إحصائيات الفيديو والقناة عبر YouTube Data API v3.
