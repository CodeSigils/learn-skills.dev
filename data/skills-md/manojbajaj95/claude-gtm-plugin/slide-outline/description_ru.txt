Используйте этот навык всякий раз, когда пользователь хочет создать структуру презентации, структуру слайдов, раскадровку слайдов или спланировать слайды для любого контекста (выступление, зал заседаний, отчет по электронной почте). Также используйте, когда пользователь упоминает «помогите мне структурировать мою презентацию», «контур слайда», «раскадровку моей презентации», «последовательность презентации», «планируйте мои слайды», «ключевое сообщение для моей презентации», «принцип пирамиды для слайдов», «какие слайды мне следует включить» или «помогите мне рассказать историю с помощью слайдов». Этот навык проходит полный интерактивный процесс в два этапа: Фаза 1 (настройка → ключевое сообщение → раскадровка) сохраняет слайд-outline.md; На этапе 2 (интерактивное создание копий для каждого слайда → доработка) сохраняется файл Slide-copy.md, связанный с файлом Slide-outline.md. Срабатывает, даже если пользователь упоминает только расплывчатое намерение, например «Мне нужно представить X моей команде» или «помогите мне собрать колоду на доске».
