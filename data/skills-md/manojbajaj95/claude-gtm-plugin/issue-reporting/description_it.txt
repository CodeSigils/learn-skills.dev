Aiuta gli utenti a segnalare problemi con le competenze GTM: consigli errati, attivazione interrotta, contesto mancante o comportamento imprevisto. Guida nella raccolta dei dettagli corretti (nome della competenza, prompt utilizzato, output effettivo rispetto a quello previsto, file di contesto presenti) e genera un problema GitHub formattato correttamente. Da utilizzare quando gli utenti dicono: "questa competenza ha fornito consigli errati", "segnala un bug", "segnala un problema", "la competenza non funziona", "output sbagliato", "la competenza non è stata attivata", "consiglio errato", "comportamento errato" o "qualcosa non funziona".
