Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein neues Projekt einrichten, eine Marke integrieren, bei Null beginnen, seinen Marketingkontext konfigurieren oder seinen Arbeitsbereich initialisieren möchte. Verwenden Sie dies auch, wenn der Benutzer scheinbar ganz neu anfängt und strategy/brand.md oder about/me.md noch nicht eingerichtet hat.
