转向一个高级目标（“使用损失函数在 Y 中构建 X
开发”）变成完整的、可粘贴的/目标提示加上
它驱动的线束脚手架。输出是一个单一的
文本块准备粘贴到新会话的/目标中
命令。

每当用户说出以下任一内容时加载此技能：“损失函数
development", "LFD", "/goal", "在 X 上使用循环模式",
“为 Y 设置一个损失驱动循环”，“我想用
线束工程模式”，或描述他们的一个项目
想要用损失函数循环来驱动。也加载它当
用户粘贴 /goal 提示并要求审核，或者说
“这个循环没有收敛”并且失败在于目标
规格而不是线束。

该技能是*元循环*：它产生工件
损失函数设计技能所描述的。它不
运行循环本身。输出被新的消耗
运行循环的会话。
