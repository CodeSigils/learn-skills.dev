轉向一個高階目標（“使用損失函數在 Y 中建立 X
開發」）變成完整的、可貼上的/目標提示加上
它驅動的線束腳手架。輸出是一個單一的
文字塊準備貼上到新會話的/目標中
命令。

每當用戶說出以下任一內容時載入此技能：「損失函數
development", "LFD", "/goal", "在 X 上使用迴圈模式",
“為 Y 設定一個損失驅動循環”，“我想用
線束工程模式”，或描述他們的一個項目
想要用損失函數循環來驅動。也加載它當
用戶貼上 /goal 提示並要求審核，或者說
「這個循環沒有收斂」失敗在於目標
規格而不是線束。

此技能是*元循環*：它產生工件
損失函數設計技能所描述的。它不
運行循環本身。輸出被新的消耗
運行循環的會話。
