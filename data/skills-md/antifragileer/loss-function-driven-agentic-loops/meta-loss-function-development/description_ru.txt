Превратите цель высокого уровня («постройте X в Y, используя функцию потерь
development") в полную подсказку /goal с возможностью вставки плюс
строительные леса, которыми он управляет. Выход — один
текстовый блок, готовый для вставки в /цель нового сеанса
команда.

Загружайте этот навык всякий раз, когда пользователь произносит что-либо из: «функция потери
development", "LFD", "/goal", "используйте шаблон цикла на X",
«настроить цикл с потерями для Y», «Я хочу построить Z с
«схема проектирования жгутов» или описывает проект, который они
хочу ездить с циклом функции потерь. Также загрузите его, когда
пользователь вставляет подсказку /goal и просит просмотреть или говорит
«эта петля не сходится» и неудача в цели
спецификации, а не в ремнях безопасности.

Этот навык представляет собой *мета-петлю*: он производит артефакты.
что описывает навык проектирования функции потерь. Это не
запустить сам цикл. Выход потребляется новым
сеанс, который запускает цикл.
