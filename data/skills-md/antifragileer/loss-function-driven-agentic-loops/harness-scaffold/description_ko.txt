(메타 손실 기능 개발에서) /goal 프롬프트가 주어지고
프로젝트 루트, 하네스 트리 스캐폴드: verifiers/,
도구/, 결정론적 그레이더를 사용한 설계 작업,
AGENTS.md, GOAL.md, README.md 및 보류 채점기
디렉토리. 출력은 5분 이내에 실행 가능한 프로젝트입니다.
새로운 인간이나 에이전트의 경우.

사용자가 /goal 프롬프트를 붙여 넣을 때마다 이 스킬을 로드하고
"프로젝트 비계", "하네스 설정" 또는
사용할 새로운 프로젝트 루트를 설명합니다. 다음과 같은 경우에도 로드하세요.
사용자가 새로운 디자인 작업이나 보류된 작업을 추가하려고 합니다.
기존 프로젝트에.
