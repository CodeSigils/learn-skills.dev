Dado un mensaje /objetivo (de meta-pérdida-función-desarrollo) y
una raíz del proyecto, armar el árbol de arnés: verificadores/,
instrumentos/, tareas de diseño con clasificadores deterministas,
AGENTS.md, GOAL.md, README.md y el calificador retenido
directorio. El resultado es un proyecto ejecutable en <5 minutos.
para un nuevo humano o agente.

Cargue esta habilidad cada vez que el usuario pegue un mensaje /objetivo y
dice "estructurar el proyecto", "configurar el arnés" o
describe una nueva raíz del proyecto para usar. Cárgalo también cuando
el usuario desea agregar una nueva tarea de diseño o una tarea pendiente
a un proyecto existente.

Habilidades complementarias (instalar por separado si no están presentes):
- desarrollo-de-función-meta-pérdida: produce el mensaje /objetivo
- diseño de función de pérdida: la anatomía de pérdida de 4 piezas
- ingeniería de arnés: lo que ve el agente
- cline-orchestration: el tiempo de ejecución de Cline (sustituye tu
  propio si no usa Cline)
