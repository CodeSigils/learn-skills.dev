**fake-agent** 스텁을 내부 코딩으로 구동하는 방법
손실 기능 기반 루프 내부의 에이전트. 가짜 요원
결정론적 스텁입니다. 주기 프롬프트를 다시 에코합니다.
"후보 텍스트"로 고정된 파일을
반복 디렉터리를 생성하고 결정적 JSON을 내보냅니다.
결과. 모델도 없고, 네트워크도 없고, 허술함도 없습니다.
이 어댑터는 **dogfood 테스트**용으로 존재합니다.
LFD 시스템 자체가 엔드 투 엔드(end-to-end) 작동한다는 것을
토큰을 사용하거나 실제 코딩 에이전트에 의존합니다.
결정론적 검증기를 구축할 때 이 기술을 로드하세요.
(LFD 시스템 자체 검증) 또는 테스트 시
CI의 루프/스캐폴드/파서. 다음 용도로 사용하지 마세요.
