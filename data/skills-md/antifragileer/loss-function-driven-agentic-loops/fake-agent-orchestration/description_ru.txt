Как использовать заглушку **fake-agent** в качестве внутренней кодировки
агент внутри цикла, управляемого функцией потерь. Фальшивый агент
это детерминированная заглушка: она возвращает приглашение цикла
в качестве «текста-кандидата» записывает фиксированный файл в
каталог итерации и выдает детерминированный JSON.
результат. Нет ни модели, ни сети, ни хлипкости.
Этот адаптер предназначен для **тестирования** — проверки
что сама система LFD работает сквозно без
тратя жетоны или в зависимости от реального агента кодирования.
Используйте этот навык при создании детерминированного верификатора.
(система LFD проверяет себя), или при тестировании
цикл/скаффолд/парсеры в CI. НЕ используйте его для
фактические циклы разработки.
