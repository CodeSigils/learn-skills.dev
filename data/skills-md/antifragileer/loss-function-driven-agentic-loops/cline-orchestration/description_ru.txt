Как использовать Cline CLI в качестве агента кодирования внутри
цикл, управляемый функцией потерь. Клайн — это *поверхность инструмента* агент
использует внутри цикла. Водитель (Гермес или любой другой оркестратор)
владеет циклом, функцией потерь и запуском верификатора. Клайн
владеет вызовом модели, контекстом каждой итерации, редактированием файла,
и тест выполняется внутри своей песочницы. Загружайте этот навык всякий раз, когда
запуск, мониторинг или прерывание сеанса Cline из
внутри цикла, управляемого функцией потерь. Также загружайте его при сборке
скрипт-оболочка Cline — проверенная форма вызова,
Схема NDJSON, анализатор и контракт, который должна использовать оболочка.
удовлетворить всех живущих здесь.
