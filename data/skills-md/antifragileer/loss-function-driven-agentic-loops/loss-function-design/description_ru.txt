Как спроектировать, реализовать, проверить и перебрать функции потерь
для циклов разработки агентов. Функция потерь – это
цель, против которой оптимизируется цикл — без хорошей цели,
петля закручивается по спирали или мода схлопывается. Загружайте этот навык всякий раз, когда
написание новой потери, рассмотрение потенциальной потери или диагностика
петля, которая не сходится. Компаньон-жгут-инжиниринг
навык — это половина, которую видит агент; это половина водителя
видит.
