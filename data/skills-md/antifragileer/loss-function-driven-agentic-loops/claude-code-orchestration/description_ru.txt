Как использовать Claude Code CLI (Anthropic) в качестве кодирования
агент внутри цикла, управляемого функцией потерь. Водитель
(Гермес или любой оркестратор) владеет петлей, потерей
функция, и верификатор запускается. Клод Код владеет моделью
вызов, контекст каждой итерации, редактирование файла и
тестовые запуски. Загружайте этот навык при каждом запуске, мониторинге,
или прерывание сеанса Claude Code изнутри
цикл, управляемый функцией потерь, и при построении кода Клода
скрипт-оболочка — проверенные флаги режима печати, JSON
схема вывода, синтаксический анализатор и контракт-оболочка
должен удовлетворить всех живущих здесь.
