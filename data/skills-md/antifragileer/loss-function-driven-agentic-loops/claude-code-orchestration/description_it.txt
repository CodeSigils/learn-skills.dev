Come gestire la CLI Claude Code (Anthropic) come codifica
agente all’interno di un ciclo guidato dalla funzione di perdita. L'autista
(Hermes o qualsiasi orchestratore) possiede il loop, la perdita
funzione e il verificatore viene eseguito. Claude Code possiede il modello
chiamata, il contesto per-iterazione, le modifiche del file e il file
corse di prova. Carica questa abilità ogni volta che avvii, monitorizzi,
o interrompere una sessione di Claude Code dall'interno di a
ciclo guidato dalla funzione di perdita e quando si costruisce un codice Claude
script wrapper: i flag verificati della modalità di stampa, il file JSON
schema di output, il parser e il contratto, il wrapper
deve soddisfare tutti coloro che vivono qui.
