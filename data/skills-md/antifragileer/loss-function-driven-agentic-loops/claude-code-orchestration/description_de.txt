So steuern Sie die Claude Code CLI (Anthropic) als Codierung
Agent innerhalb einer verlustfunktionsgesteuerten Schleife. Der Fahrer
(Hermes oder irgendein Orchestrator) besitzt die Schleife, den Verlust
Funktion und der Prüfer wird ausgeführt. Claude Code ist Eigentümer des Modells
Aufruf, der Kontext pro Iteration, die Dateiänderungen und die
Testläufe. Laden Sie diesen Skill jedes Mal, wenn Sie ihn starten, überwachen,
oder Unterbrechen einer Claude Code-Sitzung aus einem heraus
Verlustfunktionsgesteuerte Schleife und beim Erstellen eines Claude-Codes
Wrapper-Skript – die überprüften Druckmodus-Flags, das JSON
Ausgabeschema, der Parser und der Vertrag der Wrapper
muss alle hier lebenden zufrieden stellen.
