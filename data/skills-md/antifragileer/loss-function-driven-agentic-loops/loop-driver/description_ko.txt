손실 함수 기반 에이전트의 외부 루프 실행
주기: 반복 로그 읽기, 후보 아티팩트 쓰기,
에이전트용으로 설치하고 디자인 세트 실행, 점수, 로그
반복하고 정지 시 강제 엔트로피를 적용하고 반복합니다.

/goal 프롬프트가 세션에 붙여넣어졌을 때 로드
사용자가 "루프 실행", "사이클 시작"이라고 말합니다.
"손실을 유도"하거나 "후보를 반복"합니다. 또한
"루프가 수렴하지 않고" 실패할 때 로드
주기 선택 중입니다(목표 프롬프트나 하네스 아님).

LFD 스킬 3개 중 세 번째 : 메타-손실-함수-
개발은 /goal 프롬프트, 하네스 비계를 생성합니다.
하네스 트리를 생성하면 이 스킬이 주기를 실행합니다.

컴패니언 스킬(없을 경우 별도로 설치):
- Meta-loss-function-development: /goal 프롬프트를 생성합니다.
- Harness-scaffold: 프로젝트 트리의 발판
- 손실 함수 설계: 4부분 손실 해부학
- 하네스 엔지니어링: 에이전트가 보는 것
- cline-orchestration: Cline 런타임(대체
  Cline을 사용하지 않는 경우 자신의 것)
