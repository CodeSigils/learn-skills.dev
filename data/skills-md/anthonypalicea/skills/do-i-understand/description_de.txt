Überprüft, ob ein Entwickler eine Pull-Anfrage versteht, bevor er sie zusammenführt, insbesondere Code, den ein KI-Agent geschrieben hat. Dabei wird der Autor und nicht der Code überprüft: Er wird zu Änderungen befragt, bei denen er nicht erklären kann, was er ausliefert. Verwenden Sie diese Option immer dann, wenn jemand eine PR, einen Zweig oder ein Diff mit KI-generiertem Code öffnen, übermitteln, überprüfen oder zusammenführen möchte oder sicherstellen möchte, dass er eine Änderung vor dem Versand versteht.
