Vérifie si un développeur comprend une pull request avant de la fusionner, en particulier le code écrit par un agent IA. Il examine l'auteur plutôt que le code : il l'interroge sur les changements pour lesquels il ne peut pas expliquer ce qu'il propose. À utiliser chaque fois que quelqu'un est sur le point d'ouvrir, de soumettre, de réviser ou de fusionner un PR, une branche ou un diff contenant du code généré par l'IA, ou souhaite s'assurer qu'il comprend une modification avant l'expédition.
