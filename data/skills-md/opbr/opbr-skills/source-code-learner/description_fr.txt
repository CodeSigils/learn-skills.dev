Système d'apprentissage guidé interactif pour comprendre et reconstruire des projets de code source réels à partir de zéro. Utilisez cette compétence chaque fois qu'un programmeur souhaite apprendre le fonctionnement d'un projet en le construisant étape par étape, étudier une base de code open source, comprendre l'architecture d'un projet réel, reproduire un projet à partir de zéro ou apprendre un framework/une bibliothèque en le reconstruisant. Déclenchez cette compétence lorsque les utilisateurs disent des choses comme « aidez-moi à apprendre ce projet », « je veux comprendre comment X est construit », « expliquez-moi cette base de code », « aidez-moi à reconstruire X à partir de zéro », « apprenez-moi ce dépôt », « aidez-moi à étudier ce code source », « je veux apprendre en construisant » ou « expliquez-moi et guidez-moi tout au long de ce projet ». Déclenchez également toute combinaison de « code source » + « apprendre/étudier/comprendre/construire ». Cette compétence offre une expérience riche et basée sur les commentaires avec un suivi des progrès, des points de contrôle et une validation à chaque étape – jamais seulement une explication passive.
