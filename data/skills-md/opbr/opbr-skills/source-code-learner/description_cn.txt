交互式引导学习系统，用于从头开始理解和重建现实世界的源代码项目。每当程序员想要通过逐步构建项目来了解项目的工作原理、研究开源代码库、了解真实项目的架构、从头开始复制项目或通过重构来学习框架/库时，都可以使用此技能。当用户说“帮助我学习这个项目”、“我想了解 X 是如何构建的”、“引导我完成这个代码库”、“帮助我从头开始重建 X”、“教我这个存储库”、“帮助我研究这个源代码”、“我想通过构建来学习”或“解释并指导我完成这个项目”时，会触发此技能。还可以触发“源代码”+“学习/研究/理解/构建”的任意组合。这项技能提供了丰富的、反馈驱动的体验，包括每一步的进度跟踪、检查点和验证——而不仅仅是被动的解释。
