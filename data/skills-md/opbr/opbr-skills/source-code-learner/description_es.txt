Sistema de aprendizaje guiado interactivo para comprender y reconstruir proyectos de código fuente del mundo real desde cero. Utilice esta habilidad siempre que un programador quiera aprender cómo funciona un proyecto construyéndolo paso a paso, estudiar una base de código de fuente abierta, comprender la arquitectura de un proyecto real, replicar un proyecto desde cero o aprender un marco/biblioteca reconstruyéndolo. Active esta habilidad cuando los usuarios digan cosas como "ayúdame a aprender este proyecto", "Quiero entender cómo se construye X", "guíame a través de este código base", "ayúdame a reconstruir X desde cero", "enséñame este repositorio", "ayúdame a estudiar este código fuente", "Quiero aprender construyendo" o "explícame y guíame a través de este proyecto". También activa cualquier combinación de "código fuente" + "aprender/estudiar/comprender/construir". Esta habilidad proporciona una experiencia rica basada en comentarios con seguimiento del progreso, puntos de control y validación en cada paso, nunca solo una explicación pasiva.
