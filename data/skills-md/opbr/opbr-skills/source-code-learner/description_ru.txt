Интерактивная управляемая система обучения для понимания и восстановления реальных проектов исходного кода с нуля. Используйте этот навык всякий раз, когда программист хочет узнать, как работает проект, создавая его шаг за шагом, изучить базу кода с открытым исходным кодом, понять архитектуру реального проекта, воспроизвести проект с нуля или изучить структуру/библиотеку, реконструируя ее. Активируйте этот навык, когда пользователи говорят такие вещи, как «помогите мне изучить этот проект», «я хочу понять, как устроен X», «познакомьтесь со мной по этой кодовой базе», «помогите мне перестроить X с нуля», «научите меня этому репозиторию», «помогите мне изучить этот исходный код», «я хочу учиться, создавая» или «объясните и проведите меня через этот проект». Также триггер для любой комбинации «исходный код» + «изучать/изучать/понимать/создать». Этот навык обеспечивает богатый опыт, основанный на обратной связи, с отслеживанием прогресса, контрольными точками и проверкой на каждом этапе, а не просто пассивным объяснением.
