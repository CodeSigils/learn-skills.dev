صمم، ابنِ، راجع وصقّل واجهات الواجهة الأمامية والهواتف المحمولة للإنتاج باتجاه بصري مميز، وإرشادات نظام تصميم وتجربة مستخدم قابلة للبحث، وقواعد استجابة وإمكانية وصول، وتوصيات خاصة ببيئة التقنية، ونصّ منتج مختصر. استخدمه عند إنشاء أو تعديل الصفحات أو المكوّنات أو التخطيطات أو الأنماط أو التفاعلات أو التنقل أو الحركات أو المخططات أو الأصول البصرية أو نصوص واجهة المستخدم أو قابلية الاستخدام للواجهة الأمامية في الويب، Flutter، React Native، SwiftUI، سطح المكتب، أو واجهات مماثلة.
