Trasforma il feedback accettato sulla revisione del codice da qualsiasi sistema di revisione a cui l'agente host può accedere in un'unica regola di repository visualizzata in anteprima e leggibile dall'agente con prove durevoli e convalida dell'integrità. Utilizzare per PR GitHub, richieste di unione GitLab, richieste pull di Bitbucket, modifiche Gerrit, Azure Repos o sistemi di revisione privati; non utilizzare per revisioni generali o modifiche arbitrarie delle policy.
