Transformez les commentaires de révision de code acceptés provenant de n'importe quel système de révision auquel l'agent hôte peut accéder en une règle de référentiel prévisualisée et lisible par l'agent avec des preuves durables et une validation d'intégrité. À utiliser pour les PR GitHub, les demandes de fusion GitLab, les demandes d'extraction Bitbucket, les modifications Gerrit, Azure Repos ou les systèmes de révision privés ; ne pas utiliser à des fins de révision générale ou de modification arbitraire de politiques.
