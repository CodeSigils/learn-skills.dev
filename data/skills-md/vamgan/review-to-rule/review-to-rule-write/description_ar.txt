قم بتحويل تعليقات مراجعة التعليمات البرمجية المقبولة من أي نظام مراجعة يمكن للوكيل المضيف الوصول إليه إلى قاعدة مستودع واحدة تمت معاينتها ويمكن للوكيل قراءتها مع أدلة متينة والتحقق من صحة النزاهة. يُستخدم لـ GitHub PRs، أو طلبات دمج GitLab، أو طلبات سحب Bitbucket، أو تغييرات Gerrit، أو Azure Repos، أو أنظمة المراجعة الخاصة؛ لا تستخدم للمراجعة العامة أو التحرير التعسفي للسياسة.
