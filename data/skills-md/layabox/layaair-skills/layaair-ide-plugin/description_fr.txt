Créez des plugins (extensions) de l'éditeur LayaAir IDE. DÉCLENCHEMENT lorsque : l'utilisateur demande de créer/construire/écrire un plugin, un panneau, un panneau d'éditeur, un menu, un champ d'inspecteur, un plugin de construction, un processeur d'actifs, un éditeur personnalisé, un hook de scène, un gizmo ou toute extension d'éditeur. Se déclenche également lorsque l'utilisateur mentionne LayaAir/Laya/laya, @IEditor, @IEditorEnv, EditorPanel, panel/面板 ou souhaite étendre l'EDI. Déclencheurs chinois : 编辑器插件, 编辑器面板, 插件面板, 面板插件, 写一个面板, 写个插件. Ce projet EST l'IDE LayaAir — toute demande d'écriture d'un plugin ou d'un panneau d'éditeur dans ce référentiel doit utiliser cette compétence.
