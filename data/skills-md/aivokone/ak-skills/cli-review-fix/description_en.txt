Send code review requests to external CLI tools (Codex CLI, Gemini CLI), critically evaluate findings, fix valid issues, and present a fix report. Auto-detects context (PR, branch, uncommitted changes). Uses bundled wrapper scripts for both Codex and Gemini. For Gemini, prefers the code-review extension (interactive mode with full-file access) when installed. Run /cli-review-fix to launch all available CLIs, or /cli-review-fix codex for a specific one.
