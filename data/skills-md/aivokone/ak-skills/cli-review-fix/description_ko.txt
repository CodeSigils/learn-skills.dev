외부 CLI 도구(Codex CLI, Gemini CLI)에 코드 검토 요청을 보내고, 발견 사항을 비판적으로 평가하고, 유효한 문제를 수정하고, 수정 보고서를 제시합니다. 컨텍스트(PR, 분기, 커밋되지 않은 변경 사항)를 자동 감지합니다. Codex와 Gemini 모두에 번들 래퍼 스크립트를 사용합니다.
