コード レビュー リクエストを外部 CLI ツール (Codex CLI、Gemini CLI) に送信し、結果を批判的に評価し、有効な問題を修正し、修正レポートを提示します。コンテキスト (PR、ブランチ、コミットされていない変更) を自動検出します。 Codex と Gemini の両方にバンドルされたラッパー スクリプトを使用します。 Gemini の場合、インストール時にコードレビュー拡張機能 (フルファイル アクセスを備えた対話型モード) が優先されます。 /cli-review-fix を実行して利用可能なすべての CLI を起動するか、特定の CLI に対して /cli-review-fix コーデックスを実行します。
