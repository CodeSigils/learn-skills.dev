Отправляйте запросы на проверку кода во внешние инструменты CLI (CLI Codex, Gemini CLI), критически оценивайте результаты, исправляйте действительные проблемы и представляйте отчет об исправлениях. Автоматически определяет контекст (PR, ветка, незафиксированные изменения). Использует встроенные сценарии-оболочки как для Codex, так и для Gemini. Для Gemini предпочитает расширение проверки кода (интерактивный режим с полным доступом к файлам) при установке. Запустите /cli-review-fix, чтобы запустить все доступные интерфейсы командной строки, или код /cli-review-fix для конкретного.
