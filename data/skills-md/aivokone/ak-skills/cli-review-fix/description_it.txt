Invia richieste di revisione del codice a strumenti CLI esterni (Codex CLI, Gemini CLI), valuta criticamente i risultati, risolvi problemi validi e presenta un report di correzione. Rileva automaticamente il contesto (PR, ramo, modifiche non confermate). Utilizza script wrapper in bundle sia per Codex che per Gemini. Per Gemini, preferisce l'estensione di revisione del codice (modalità interattiva con accesso completo ai file) quando installata. Esegui /cli-review-fix per avviare tutte le CLI disponibili o il codice /cli-review-fix per una specifica.
