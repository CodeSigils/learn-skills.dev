Envoyez des demandes de révision de code à des outils CLI externes (Codex CLI, Gemini CLI), évaluez de manière critique les résultats, corrigez les problèmes valides et présentez un rapport de correctif. Détecte automatiquement le contexte (RP, branche, modifications non validées). Utilise des scripts wrapper fournis pour le Codex et Gemini. Pour Gemini, préfère l'extension de révision de code (mode interactif avec accès complet aux fichiers) une fois installée. Exécutez /cli-review-fix pour lancer toutes les CLI disponibles, ou /cli-review-fix codex pour une CLI spécifique.
