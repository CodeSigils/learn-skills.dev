Cree, edite y depure complementos de la barra de menús de SwiftBar para macOS. SIEMPRE use esta habilidad cuando el usuario quiera poner algo en la barra de menú de macOS, ya sea que diga "complemento de barra de menú", "widget de barra de estado", "elemento de barra de menú" o simplemente quiera mostrar datos en vivo, contadores, indicadores de estado o información de monitoreo en la barra superior de macOS. También activa SwiftBar, BitBar, xbar por nombre, edita o depura scripts de complementos de barra de menú existentes (.sh/.py con parámetros | y --- separadores), o cualquier solicitud para crear un script que genere líneas formateadas para una aplicación de barra de menú. Esta es la habilidad a la que recurrir cuando se trata de la personalización de la barra de menú de macOS, incluso si el usuario no menciona SwiftBar específicamente; si desea un elemento de la barra de menú basado en script en macOS, esta habilidad se aplica.
