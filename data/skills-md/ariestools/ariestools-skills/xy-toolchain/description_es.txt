Cadena de herramientas Aries Tools TypeScript utilizada por los repositorios XY, XYO y XL1. Cubre la CLI @ariestools/toolchain xy, perfiles de biblioteca y aplicación, monorepo y topología de paquete único, comportamiento del administrador de paquetes, modos de compilación xy.config.ts, configuraciones planas de ESLint por niveles, configuraciones de TypeScript de @ariestools (incluidos ambientes globales neutrales de biblioteca), @ariestools/vitest-config, Vitest, análisis de dependencia y exposición de API (roles de distribución, selección, ubicación/presencia), comprobaciones de publicación, análisis de código muerto, política de repositorio, habilidades, seguimiento del trabajo xy con GitHub Issues opcional, escritura/sincronización dual y alcance del espacio de trabajo de múltiples carpetas, y limpieza configurable (incluida la higiene completa). Úselo al configurar o mantener proyectos, seleccionar un perfil de proyecto, ejecutar o depurar comandos de compilación/lint/prueba, configurar la salida del paquete, corregir la ubicación de dependencias o la presencia requerida, validar superficies de publicación, rastrear el trabajo con xy o interpretar fallas de comandos xy.
