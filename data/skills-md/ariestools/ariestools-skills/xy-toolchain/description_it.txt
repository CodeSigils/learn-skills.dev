Toolchain Aries Tools TypeScript utilizzata dai repository XY, XYO e XL1. Copre la CLI @ariestools/toolchain xy, i profili delle librerie e delle applicazioni, la topologia monorepo e a pacchetto singolo, il comportamento del gestore dei pacchetti, le modalità di compilazione xy.config.ts, le configurazioni flat ESLint a più livelli, le configurazioni @ariestools TypeScript (incluse le globali di ambiente lib-neutral), @ariestools/vitest-config, Vitest, analisi delle dipendenze e dell'esposizione API (ruoli deplint, selezione, posizionamento/presenza), controlli di pubblicazione, analisi dei codici morti, policy del repository, competenze, monitoraggio del lavoro xy con problemi GitHub opzionali con doppia scrittura/sincronizzazione e ambito dell'area di lavoro multi-cartella e pulizia configurabile (inclusa --igiene completa). Da utilizzare durante l'impostazione o la manutenzione di progetti, la selezione di un profilo di progetto, l'esecuzione o il debug di comandi build/lint/test, la configurazione dell'output del pacchetto, la correzione del posizionamento delle dipendenze o della presenza richiesta, la convalida delle superfici di pubblicazione, il monitoraggio del lavoro con il lavoro xy o l'interpretazione degli errori dei comandi xy.
