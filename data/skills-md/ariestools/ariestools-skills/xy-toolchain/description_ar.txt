سلسلة أدوات Aries Tools TypeScript المستخدمة في مستودعات XY وXYO وXL1. يغطي @ariestools/toolchain xy CLI، وملفات تعريف المكتبة والتطبيق، وmonrepo وطوبولوجيا الحزمة الفردية، وسلوك مدير الحزم، وأوضاع الترجمة xy.config.ts، وتكوينات ESLint المسطحة، وتكوينات @ariestools TypeScript (بما في ذلك العموميات المحيطة المحايدة للمكتبة)، و@ariestools/vitest-config، وVtest، والتبعية، وتحليل التعرض لواجهة برمجة التطبيقات (أدوار delpint، اختيار، التنسيب/التواجد)، فحوصات النشر، تحليل التعليمات البرمجية الميتة، سياسة المستودع، المهارات، تتبع عمل xy مع مشكلات GitHub الاختيارية للكتابة المزدوجة/المزامنة ونطاق مساحة العمل متعدد المجلدات، والتنظيف القابل للتكوين (بما في ذلك --النظافة الكاملة). يُستخدم عند إعداد المشاريع أو صيانتها، أو تحديد ملف تعريف المشروع، أو تشغيل أو تصحيح أوامر البناء/اللينت/الاختبار، أو تكوين مخرجات الحزمة، أو إصلاح موضع التبعية أو التواجد المطلوب، أو التحقق من صحة أسطح النشر، أو تتبع العمل مع عمل xy، أو تفسير فشل أمر xy.
