Aries Tools TypeScript-Toolchain, die von XY-, XYO- und XL1-Repositorys verwendet wird. Behandelt die @ariestools/toolchain xy CLI, Bibliotheks- und Anwendungsprofile, Monorepo- und Einzelpakettopologie, Paketmanagerverhalten, xy.config.ts-Kompilierungsmodi, abgestufte ESLint-Flat-Konfigurationen, @ariestools TypeScript-Konfigurationen (einschließlich lib-neutraler Ambient Globals), @ariestools/vitest-config, Vitest, Abhängigkeits- und API-Exposure-Analyse (Deplint-Rollen, Auswahl, Platzierung/Anwesenheit), Veröffentlichungsprüfungen, toter Code Analyse, Repository-Richtlinie, Fähigkeiten, XY-Arbeitsverfolgung mit optionalem Dual-Write/Sync- und Multi-Ordner-Arbeitsbereichsbereich von GitHub Issues und konfigurierbarer Bereinigung (einschließlich --full Hygiene). Wird zum Einrichten oder Verwalten von Projekten, zum Auswählen eines Projektprofils, zum Ausführen oder Debuggen von Build-/Lint-/Testbefehlen, zum Konfigurieren der Paketausgabe, zum Korrigieren der Abhängigkeitsplatzierung oder erforderlichen Anwesenheit, zum Validieren von Veröffentlichungsoberflächen, zum Verfolgen der Arbeit mit xy-Arbeit oder zum Interpretieren von xy-Befehlsfehlern verwendet.
