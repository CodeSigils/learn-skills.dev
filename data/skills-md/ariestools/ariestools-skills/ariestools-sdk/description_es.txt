Aries Tools compartió bibliotecas de utilidades TypeScript/JavaScript del monorepo sdk-js. Cubre el conjunto @ariestools/sdk (afirmación, retraso, recuperación, hexadecimal, promesa, almacenamiento, ayudantes de zod y otros módulos), paquetes especializados (express, adaptadores de almacenamiento, subprocesos, pruebas, telemetría, autenticación criptográfica, dirección eth, píxel, motor json-rpc), convenciones de importación, pares opcionales y migración de nombres @xylabs/* retirados. Úselo al importar o elegir utilidades @ariestools/*, conectar clientes HTTP, adaptadores de almacenamiento, trabajadores, API Express o comparadores Vitest.
