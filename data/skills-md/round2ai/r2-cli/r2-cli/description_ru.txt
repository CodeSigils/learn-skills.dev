R2-CLI Инструмент с интерфейсом командной строки для торговли подержанной модной одеждой класса люкс. Он используется для авторизованного входа в систему, листинга продуктов/исключения из списков/изменений цен, а также просмотра магазинов/складов/выбранных продуктов/списков объявлений. После того как агент получает данные, он предлагает пользователю варианты завершения четырехэтапного процесса листинга. Триггерные слова: r2-cli, вход в систему, список, исключение из списка, изменение цены, продукт, товар, аутентификация, магазины, акции, листинг.
