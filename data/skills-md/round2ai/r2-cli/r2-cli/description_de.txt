R2-CLI gebrauchtes, trendiges CLI-Tool für den Luxushandel. Wird für die authentifizierte Anmeldung, Produktauflistungen/Delistings/Preisänderungen und die Anzeige von Geschäften/Lagern/ausgewählten Produkten/Angeboten verwendet. Nachdem der Agent Daten abgerufen hat, präsentiert er dem Benutzer Auswahlmöglichkeiten, um den vierstufigen Auflistungsprozess abzuschließen. Auslösewörter: r2-cli, login, list, delist, Preisänderung, Produkt, Waren, Authentifizierung, Geschäfte, Lagerbestände, Auflistung.
