يُستخدم عند إنشاء صفحات SvelteKit والمكونات القابلة لإعادة الاستخدام أو إعادة تصميمها أو تجميلها أو إعادة هيكلتها باستخدام shadcn-svelte أو Bits UI أو shadcn-svelte MCP. يتم التشغيل على الصفحات المقصودة، ولوحات المعلومات، ومواقع التسويق، وأغلفة التطبيقات، والنماذج، وأشرطة التنقل، والجداول، ومربعات الحوار، والتخطيطات سريعة الاستجابة، والسمات، واختيار الأيقونات، وطلبات تحويل فكرة أو نموذج بالحجم الطبيعي التقريبي إلى واجهة مستخدم Svelte مصقولة دون اختراع واجهات برمجة تطبيقات المكونات.
