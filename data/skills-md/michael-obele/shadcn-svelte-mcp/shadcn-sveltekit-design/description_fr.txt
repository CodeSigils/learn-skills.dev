Déclenchez sur les pages de destination, les tableaux de bord, les sites marketing, les shells d'applications, les formulaires, les barres de navigation, les tableaux, les boîtes de dialogue, les mises en page réactives, les thèmes, la sélection d'icônes et les requêtes pour transformer une idée ou une maquette approximative en une interface utilisateur Svelte raffinée sans inventer d'API de composants.
