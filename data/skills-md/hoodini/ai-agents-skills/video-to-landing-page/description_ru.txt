Превратите любое видео в кинематографическую целевую страницу с прокруткой — герой в стиле Apple, где прокрутка продвигает видимый кадр по видео. Используйте, когда пользователь предоставляет видеофайл и запрашивает «целевую страницу из этого видео», «веб-сайт с рамкой прокрутки», «сайт с прокруткой в ​​стиле Apple», «героя, который очищает видео», «например, лендинг GitHub Copilot» или любой эквивалент. Извлекает N равномерно расположенных кадров с помощью ffmpeg, создает автономную HTML-страницу с липким героем + прослушивателем прокрутки JS, который меняет местами видимый кадр при прокрутке, а также заголовок, разделы и призыв к действию ниже. Для проектов YUV.AI применяется навык yuv-design-system в неоновом режиме (розовый/голубой/белый, по умолчанию для веб-сайта YUV.AI). Палубы (фиолетовый/желтый) зарезервированы только для слайдов. Для общих/не-YUV.AI проектов выбирается подходящая палитра для исходного видео. Выходные данные — одна папка с index.html и каталогframes/ — размещайте их на любом статическом хосте.
