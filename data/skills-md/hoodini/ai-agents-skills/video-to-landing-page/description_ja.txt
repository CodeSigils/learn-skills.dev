あらゆるビデオを映画のようなスクロール駆動のランディング ページに変えます。スクロールによってビデオ内の表示フレームが進む Apple スタイルのヒーローです。ユーザーがビデオ ファイルを提供し、「このビデオからのランディング ページ」、「スクロール フレーム Web サイト」、「Apple スタイルのスクロール サイト」、「ビデオをスクラブするヒーロー」、「GitHub Copilot のランディングのような」、または同等のものを要求する場合に使用します。 ffmpeg 経由で N 個の等間隔のフレームを抽出し、スクロールに応じて表示されるフレームを入れ替えるスティッキー ヒーローと JS スクロール リスナー、さらにその下の見出し、セクション、CTA を備えた自己完結型 HTML ページを構築します。 YUV.AI プロジェクトの場合、yuv-design-system スキルをネオン モード (ピンク/シアン/白、YUV.AI Web のデフォルト) で適用します。デッキ (紫/黄色) はスライド専用に予約されています。一般/非 YUV.AI プロジェクトの場合、ソース ビデオごとに適切なパレットを選択します。出力は、`index.html` と `frames/` ディレクトリを含む 1 つのフォルダーであり、任意の静的ホストにドロップされます。
