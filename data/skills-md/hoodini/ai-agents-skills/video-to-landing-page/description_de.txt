Verwandeln Sie jedes Video in eine filmische, scrollgesteuerte Landingpage – ein Held im Apple-Stil, bei dem das Scrollen den sichtbaren Frame durch das Video vorantreibt. Wird verwendet, wenn der Benutzer eine Videodatei bereitstellt und nach „einer Landingpage aus diesem Video“, einer „Scroll-Frame-Website“, einer „Apple-ähnlichen Scroll-Site“, einem „Helden, der das Video schrubbt“, „wie der GitHub Copilot-Landingseite“ oder einem Äquivalent fragt. Extrahiert N gleichmäßig verteilte Frames über ffmpeg und erstellt eine eigenständige HTML-Seite mit einem Sticky Hero + JS-Scroll-Listener, der beim Scrollen den sichtbaren Frame austauscht, sowie Überschrift, Abschnitte und CTA unten. Wendet bei YUV.AI-Projekten den yuv-design-system-Skill im Neonmodus an (Rosa/Cyan/Weiß, Standard für YUV.AI-Web) – Decks (lila/gelb) sind nur für Folien reserviert. Wählen Sie für generische/Nicht-YUV.AI-Projekte eine geeignete Palette für das Quellvideo aus. Die Ausgabe ist ein Ordner mit „index.html“ und einem „frames/“-Verzeichnis – legen Sie es auf einem beliebigen statischen Host ab.
