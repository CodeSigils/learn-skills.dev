Convierta cualquier vídeo en una página de inicio cinematográfica basada en desplazamiento: un héroe al estilo Apple donde el desplazamiento avanza por el fotograma visible a través del vídeo. Úselo cuando el usuario proporciona un archivo de video y solicita "una página de inicio de este video", "sitio web con marco de desplazamiento", "sitio de desplazamiento estilo Apple", "héroe que borra el video", "como el inicio de GitHub Copilot" o cualquier equivalente. Extrae N marcos espaciados uniformemente a través de ffmpeg, crea una página HTML independiente con un héroe adhesivo + detector de desplazamiento JS que intercambia el marco visible a medida que se desplaza, además del título, las secciones y el CTA a continuación. Para proyectos YUV.AI, aplica la habilidad yuv-design-system en modo Neón (rosa/cian/blanco, predeterminado para YUV.AI web). Las plataformas (púrpura/amarillo) están reservadas solo para diapositivas. Para proyectos genéricos/que no sean YUV.AI, elija una paleta adecuada según el vídeo fuente. La salida es una carpeta con `index.html` y un directorio `frames/`; colóquelo en cualquier host estático.
