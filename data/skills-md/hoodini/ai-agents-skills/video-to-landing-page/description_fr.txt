Transformez n'importe quelle vidéo en une page de destination cinématographique à défilement - un héros de style Apple où le défilement fait progresser l'image visible à travers la vidéo. À utiliser lorsque l'utilisateur fournit un fichier vidéo et demande « une page de destination de cette vidéo », « un site Web à cadre de défilement », un « site de défilement de style Apple », « un héros qui nettoie la vidéo », « comme l'atterrissage de GitHub Copilot » ou tout équivalent. Extrait N cadres régulièrement espacés via ffmpeg, crée une page HTML autonome avec un héros collant + un écouteur de défilement JS qui permute le cadre visible lorsque vous faites défiler, ainsi que le titre, les sections et le CTA ci-dessous. Pour les projets YUV.AI, applique la compétence yuv-design-system en mode Néon (rose/cyan/blanc, par défaut pour le Web YUV.AI) — Les decks (violet/jaune) sont réservés aux diapositives uniquement. Pour les projets génériques/non YUV.AI, choisissez une palette appropriée en fonction de la vidéo source. La sortie est un dossier avec « index.html » et un répertoire « frames/ » — déposé sur n'importe quel hôte statique.
