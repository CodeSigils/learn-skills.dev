Создайте кинематографическую целевую страницу с прокруткой из короткого видео. Пользователь предоставляет 5–15-секундное видео (часто созданное искусственным интеллектом); этот навык извлекает каждый кадр с качеством HD JPEG, затем создает HTML-страницу с одним героем, где жест прокрутки пользователя очищает кадры на месте (сама страница никогда не прокручивается), а 5 драматических текстовых наложений плавно появляются и исчезают — заголовки Google Anton, рукописные акценты Caveat, заблокированное тело, виртуальная прокрутка. Используйте этот навык всякий раз, когда пользователь хочет «превратить это видео в целевую страницу», «сделать целевую страницу с прокруткой», «создать героя параллакса из этого клипа», «добавить новую целевую страницу в витрину паразитов», «сделать то же самое, что github/lion/hope для этого нового видео» или любой вариант, который сочетает короткий клип с драматическим повествованием, запускаемым прокруткой. Триггер, даже если пользователь говорит только «используйте мое видео для целевой страницы» — это и есть этот навык.
