Cree una página de inicio cinematográfica basada en desplazamiento a partir de un vídeo corto. El usuario proporciona un vídeo de 5 a 15 segundos (a menudo generado por IA); esta habilidad extrae cada fotograma en calidad HD JPEG, luego produce una página HTML de un solo héroe donde el gesto de desplazamiento del usuario borra los fotogramas en su lugar (la página en sí nunca se desplaza) y cinco dramáticas superposiciones de texto se funden de entrada/salida: titulares de Google Anton, acentos escritos a mano de Caveat, cuerpo bloqueado, desplazamiento virtual. Utilice esta habilidad siempre que el usuario quiera "convertir este video en una página de inicio", "crear una página de inicio con desplazamiento", "construir un héroe de paralaje a partir de este clip", "agregar una nueva página de inicio a la exhibición de parásitos", "hacer lo mismo que github/lion/hope para este nuevo video", o cualquier variante que combine un clip corto con una narración dramática activada por desplazamiento. Activar incluso si el usuario solo dice "usa mi video como página de destino": esa es esta habilidad.
