짧은 비디오로 스크롤 방식의 영화 랜딩 페이지를 구축해 보세요. 사용자는 5~15초 길이의 비디오(종종 AI로 생성)를 제공합니다. 이 기술은 모든 프레임을 HD JPEG 품질로 추출한 다음 사용자의 스크롤 제스처가 프레임을 제자리에서 스크럽하고(페이지 자체는 스크롤하지 않음) 5개의 극적인 텍스트 오버레이 크로스페이드 인/아웃(Google Anton 헤드라인, Caveat 손으로 쓴 악센트, 잠긴 본문, 가상 스크롤)이 있는 단일 히어로 HTML 페이지를 생성합니다. 사용자가 "이 비디오를 랜딩 페이지로 전환", "스크롤 스크럽 랜딩 페이지 만들기", "이 클립에서 시차 영웅 구축", "기생충 쇼케이스에 새 랜딩 페이지 추가", "이 새 비디오에 대해 github/lion/hope와 동일한 작업 수행" 또는 짧은 클립과 드라마틱한 스크롤 트리거 스토리텔링을 결합하는 변형을 원할 때마다 이 기술을 사용하십시오. 사용자가 "내 비디오를 랜딩 페이지로 사용하세요"라고만 말해도 트리거됩니다. 이것이 바로 이 기술입니다.
