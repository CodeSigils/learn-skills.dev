سحب وتحليل وإدارة وإنشاء الإعلانات التعريفية (Facebook وInstagram وMessenger وThreads وClick-to-WhatsApp) عبر واجهة API التسويق. يُستخدم عندما يذكر المستخدم إعلانات Meta/FB/IG، أو مدير الإعلانات، أو ROAS، أو CPA، أو CPM، أو CTR، أو الإنفاق الإعلاني، أو أداء الحملة أو المجموعة الإعلانية، أو التعب الإبداعي، أو التكرار، أو CTWA، أو تقسيمات الجمهور/الموضع، أو اختبارات إعلانات A/B، أو يريد إيقاف إعلان مؤقتًا، أو تغيير الميزانية، أو تكرار فائز، أو إطلاق حملة جديدة من الصفر. قم بتشغيل المصطلحات العبرية مثل prsoum bapisbook/bainstgram، prsoumut matata، بيزوفى كامبيين، prsomot، زور كامبين، هاشك كامبين، اختبار أ/ب. قم بطرح أسئلة مثل كيفية أداء إعلاناتي، وما هو التصميم الذي يفوز، وما إذا كان إعلاني مرهقًا، وما هي تكلفة الاكتساب (CPA)، وإسقاط تقرير مدته 30 يومًا، وإطلاق اختبار أ/ب للدورة التدريبية الخاصة بي، وإنشاء حملة بهذه الزوايا الثلاث. قم بالتشغيل حتى لو لم يتم إعداد المصادقة — يتم تنفيذ المهارة من خلال الإعداد لمرة واحدة. لا تستخدمه لتحليلات Instagram العضوية، أو عدد مشاهدات Reels على المنشورات غير المروج لها، أو التفاعل مع المواضيع العضوية؛ هؤلاء يحتاجون إلى Instagram Graph API.
