Extrayez, analysez, gérez et CRÉEZ des méta-annonces (Facebook, Instagram, Messenger, Threads, Click-to-WhatsApp) via l'API marketing. À utiliser lorsque l'utilisateur mentionne les publicités Meta/FB/IG, Ads Manager, ROAS, CPA, CPM, CTR, les dépenses publicitaires, les performances de la campagne ou de l'ensemble de publicités, la fatigue créative, la fréquence, le CTWA, les répartitions d'audience/emplacement, les tests publicitaires A/B, ou souhaite suspendre une publicité, modifier un budget, dupliquer un gagnant ou lancer une nouvelle campagne à partir de zéro. Déclenchez sur des termes hébreux comme פרסום בפייסבוק/באינסטגרם, פרסומות מטא, ביצועי קמפיין, Oui, c'est vrai, c'est A/B. Déclenchez des questions telles que comment fonctionnent mes annonces, quelle création est gagnante, ma publicité est-elle fatiguée, quel est mon CPA, déposez un rapport sur 30 jours, lancez un test A/B pour mon cours, créez une campagne avec ces 3 angles. Déclenchez-la même si l'authentification n'est pas configurée : la compétence parcourt une configuration unique. Ne PAS utiliser pour les analyses organiques d'Instagram, le nombre de vues Reels sur les publications non promues ou l'engagement dans les discussions organiques ; ceux-ci ont besoin de l’API Instagram Graph.
