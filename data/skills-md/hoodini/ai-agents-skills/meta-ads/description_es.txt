Extraiga, analice, administre y CREA metaanuncios (Facebook, Instagram, Messenger, Threads, Click-to-WhatsApp) a través de la API de marketing. Úselo cuando el usuario mencione anuncios Meta/FB/IG, Administrador de anuncios, ROAS, CPA, CPM, CTR, inversión publicitaria, rendimiento de campaña o conjunto de anuncios, fatiga creativa, frecuencia, CTWA, desgloses de audiencia/ubicación, pruebas de anuncios A/B, o quiera pausar un anuncio, cambiar un presupuesto, duplicar un ganador o lanzar una nueva campaña desde cero. Activar términos hebreos como פרסום בפייסבוק/באינסטגרם, פרסומות מטא, ביצועי קמפיין, פרסומות, צור קמפיין, השק קמפיין, A/B טסט. Active preguntas como cómo están funcionando mis anuncios, qué creatividad está ganando, si mi anuncio está fatigado, cuál es mi CPA, genere un informe de 30 días, inicie una prueba A/B para mi curso, cree una campaña con estos 3 ángulos. Se activa incluso si la autenticación no está configurada: la habilidad recorre una configuración única. NO lo use para análisis orgánicos de Instagram, recuentos de vistas de carretes en publicaciones no promocionadas o participación orgánica en hilos; esos necesitan la API Graph de Instagram.
