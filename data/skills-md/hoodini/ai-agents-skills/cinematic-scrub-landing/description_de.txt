Erstellen Sie eine erstklassige filmische Landingpage mit Maus-Scrub-Videohelden und markengesteuerten Erzählbogenabschnitten. Verwenden Sie diese Option immer dann, wenn der Benutzer ein Hero-Video sowie ein Produkt/Thema/eine Marke bereitstellt und eine Zielseite, eine Werbeseite, eine Produktpräsentation, eine Marketingseite oder eine Storytelling-Seite wünscht. Funktioniert für jede Sprache (RTL oder LTR – Hebräisch, Englisch, Arabisch, Spanisch, Französisch, Japanisch usw.) und jedes Thema (Lebensmittel, Technik, Tiere, Mode, Dienstleistungen, SaaS, Wildtierkampagnen, Musikveröffentlichungen, Bücher, Immobilien). Der charakteristische Effekt ist das mausgesteuerte Video-Scrubbing – das Heldenvideo erstreckt sich über die gesamte Seite als fester Hintergrund, und durch Bewegen der Maus von links nach rechts wird die Video-Timeline gescrubbt, sodass das Motiv auf den Cursor reagiert. Unterhalb des Helden tragen 4–5 völlig undurchsichtige Abschnitte jeweils ihre eigene Markenidentität (Farbe, Typografieschwerpunkt, Layoutmuster) und führen den Betrachter durch einen Erzählbogen (z. B. Sehnsucht → Freude → Nostalgie → Kontemplation → Aktion). Wird durch Ausdrücke wie „Erstelle eine Landingpage aus diesem Video“, „filmische Landingpage“, „Maus-Scrub-Held“, „Video, das dem Cursor folgt“, „Premium-Produktseite im Apple-Stil“, „das Baby-Video-Scrub-Ding“, „narrative Landingpage“, „schrubbbarer Held“, „Goldene Landing-Vorlage“, „Erstelle eine Werbeseite für diese Marke“, „Erstelle mir eine Präsentationsseite mit diesem Clip“ ausgelöst. NICHT für Parallax-Frame-Scrub-Landungen verwenden, bei denen die Seite selbst nicht scrollt (verwenden Sie stattdessen „Parallax-Landing-Page“) oder für Videobearbeitungs-/Untertitelungs-Workflows (verwenden Sie „Video-Edit“).
