Создайте премиальную кинематографическую целевую страницу с видеогероем, щелкающим мышью, и разделами повествования, ориентированными на бренд. Используйте, когда пользователь предоставляет главное видео, а также продукт/тему/бренд и хочет создать целевую страницу, промо-сайт, витрину продукта, маркетинговую страницу или сайт, рассказывающий истории. Работает для любого языка (RTL или LTR — иврит, английский, арабский, испанский, французский, японский и т. д.) и любой темы (еда, технологии, животные, мода, услуги, SaaS, кампании по защите дикой природы, музыкальные релизы, книги, недвижимость). Характерным эффектом является прокрутка видео с помощью мыши: главное видео размещается на всей странице в качестве фиксированного фона, а перемещение мыши влево-вправо очищает временную шкалу видео, чтобы объект реагировал на курсор. Под героем расположены 4–5 полностью непрозрачных секций, каждая из которых несет свою фирменную идентичность (цвет, типографские акценты, рисунок макета) и проводят зрителя по сюжетной арке (например, тоска → радость → ностальгия → созерцание → действие). Запускается по таким фразам, как «создать целевую страницу из этого видео», «кинематографическая целевая страница», «герой чистки мыши», «видео, которое следует за курсором», «страница премиум-продукта в стиле Apple», «скраб для детского видео», «повествовательная целевая страница», «чистящийся герой», «золотой целевой шаблон», «создайте промо-сайт для этого бренда», «создайте мне демонстрационную страницу с этим клипом». НЕ используйте для прокрутки кадров с параллаксом, когда сама страница не прокручивается (вместо этого используйте `parallax-landing-page`) или для рабочих процессов редактирования видео / субтитров (используйте `video-edit`).
