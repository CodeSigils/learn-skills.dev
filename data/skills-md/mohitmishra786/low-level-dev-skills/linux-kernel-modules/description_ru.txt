Навыки работы с модулями ядра Linux для написания и отладки загружаемых модулей ядра. Используйте при написании LKM с помощью Kbuild, добавлении параметров модуля, создании записей /proc и sysfs, реализации символьных устройств, отладке с помощью KGDB или ftrace или обработке подписи модулей для безопасной загрузки. Активируется при запросах о модулях ядра Linux, загружаемых модулях, Kbuild, параметрах модулей, файловой системе /proc, sysfs, символьных устройствах, KGDB или подписи модулей.
