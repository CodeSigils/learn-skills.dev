Competenza sui moduli del kernel Linux per la scrittura e il debug di moduli del kernel caricabili. Da utilizzare quando si scrivono LKM con Kbuild, si aggiungono parametri del modulo, si creano voci /proc e sysfs, si implementano dispositivi a caratteri, si esegue il debug con KGDB o ftrace o si gestisce la firma del modulo per Secure Boot. Si attiva su query su moduli del kernel Linux, moduli caricabili, Kbuild, parametri dei moduli, filesystem /proc, sysfs, dispositivi a caratteri, KGDB o firma dei moduli.
