Habilidad del módulo del kernel de Linux para escribir y depurar módulos del kernel cargables. Úselo al escribir LKM con Kbuild, agregar parámetros de módulo, crear entradas /proc y sysfs, implementar dispositivos de caracteres, depurar con KGDB o ftrace o manejar la firma de módulos para arranque seguro. Se activa ante consultas sobre módulos del kernel de Linux, módulos cargables, Kbuild, parámetros de módulo, sistema de archivos /proc, sysfs, dispositivos de caracteres, KGDB o firma de módulo.
