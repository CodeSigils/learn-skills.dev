مهارة وحدة Linux kernel لكتابة وتصحيح وحدات kernel القابلة للتحميل. يُستخدم عند كتابة LKMs باستخدام Kbuild، أو إضافة معلمات الوحدة النمطية، أو إنشاء إدخالات /proc وsysfs، أو تنفيذ أجهزة الأحرف، أو تصحيح الأخطاء باستخدام KGDB أو ftrace، أو التعامل مع توقيع الوحدة النمطية للتمهيد الآمن. يتم التنشيط عند الاستعلامات حول وحدات Linux kernel، أو الوحدات القابلة للتحميل، أو Kbuild، أو معلمات الوحدة، أو نظام الملفات /proc، أو sysfs، أو أجهزة الأحرف، أو KGDB، أو توقيع الوحدة.
