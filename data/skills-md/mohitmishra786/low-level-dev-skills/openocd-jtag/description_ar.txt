مهارة OpenOCD لتصحيح أخطاء الأجهزة المضمنة. يُستخدم عند تكوين OpenOCD لأهداف JTAG أو SWD، أو وميض البرامج الثابتة، أو توصيل GDB بأهداف معدنية عارية، أو إعداد نقاط مراقبة الأجهزة، أو استخدام J-Link مع OpenOCD. يتم التنشيط عند الاستعلامات حول OpenOCD، أو JTAG، أو SWD، أو الهدف البعيد لـ GDB، أو برمجة الفلاش، أو نقاط توقف الأجهزة، أو J-Link، أو توصيل GDB بوحدة MCU.
