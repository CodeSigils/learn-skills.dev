Руководство no_std по разработке Rust для встраиваемых и «голых» систем. Используйте при написании крейтов #![no_std], понимании ядра, alloc и std, реализации пользовательских глобальных распределителей, выборе обработчиков паники для встроенных или тестировании крейтов no_std на хосте без аппаратного обеспечения.
