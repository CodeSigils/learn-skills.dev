مهارة أمان الصدأ لسلامة سلسلة التوريد وتطوير الذاكرة الآمنة. يُستخدم عند تدقيق التبعيات مع تدقيق الشحنات، أو تطبيق السياسات مع رفض الشحنات، أو مراجعة تحذيرات RUSTSEC، أو كتابة أنماط FFI الآمنة للذاكرة، أو دمج Fuzzing وMiri في مسار مراجعة الأمان. يتم التنشيط عند الاستفسارات حول تدقيق الشحنات، أو رفض الشحنات، أو تحذيرات RUSTSEC، أو أمن سلسلة التوريد، أو Rust CVEs، أو FFI الآمن، أو التشويش من أجل الأمان.
