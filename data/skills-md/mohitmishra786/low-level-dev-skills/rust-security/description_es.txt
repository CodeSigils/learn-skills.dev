Habilidad de seguridad de Rust para la seguridad de la cadena de suministro y el desarrollo seguro de la memoria. Úselo al auditar dependencias con cargo-audit, aplicar políticas con cargo-deny, revisar avisos de RUSTSEC, escribir patrones FFI seguros para la memoria o integrar fuzzing y Miri en un proceso de revisión de seguridad. Se activa ante consultas sobre auditoría de carga, denegación de carga, avisos de RUSTSEC, seguridad de la cadena de suministro, Rust CVE, FFI segura o fuzzing para seguridad.
