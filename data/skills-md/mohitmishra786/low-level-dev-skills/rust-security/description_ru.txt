Навыки защиты от ржавчины для обеспечения безопасности цепочки поставок и разработки, безопасной для памяти. Используйте при аудите зависимостей с помощью Cargo-audit, обеспечении соблюдения политик с помощью Cargo-Deny, проверке рекомендаций RUSTSEC, написании безопасных для памяти шаблонов FFI или интеграции фаззинга и Miri в конвейер проверки безопасности. Активируется по запросам об аудите грузов, отказе от грузов, рекомендациях RUSTSEC, безопасности цепочки поставок, Rust CVE, безопасном FFI или фаззинге для обеспечения безопасности.
