Intégrez le SDK Agentforce Mobile dans une application iOS existante. Guide le consommateur à travers la découverte des cas d'utilisation, sélectionne le bon flux d'authentification (employé OAuth/JWT vs agent de service public vs invité), ajoute la dépendance SPM ou CocoaPods et échafaude les fichiers Swift pour le fournisseur d'informations d'identification, le gestionnaire AgentforceClient, l'enregistreur soutenu par OSLog, le délégué de l'interface utilisateur et un hôte de discussion SwiftUI. À utiliser lorsqu'un développeur demande « d'ajouter Agentforce », « d'intégrer le SDK Agentforce », de « configurer le chat Agentforce » ou de connecter une application iOS à un agent Salesforce.
