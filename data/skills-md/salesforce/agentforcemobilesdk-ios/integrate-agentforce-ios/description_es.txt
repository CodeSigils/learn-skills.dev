Integre el SDK móvil de Agentforce en una aplicación de iOS existente. Guía al consumidor a través del descubrimiento de casos de uso, elige el flujo de autenticación correcto (empleado OAuth/JWT versus agente de servicio público versus invitado), agrega la dependencia de SPM o CocoaPods y estructura los archivos Swift para el proveedor de credenciales, el administrador de AgentforceClient, el registrador respaldado por OSLog, el delegado de UI y un host de chat SwiftUI. Úselo cuando un desarrollador solicite "agregar Agentforce", "integrar el SDK de Agentforce", "configurar el chat de Agentforce" o conectar una aplicación de iOS a un agente de Salesforce.
