Utilisation complète d'un ordinateur de bureau pour les serveurs Linux sans tête. Bureau virtuel Xvfb + XFCE avec automatisation xdotool. 17 actions (clic, saisie, défilement, capture d'écran, glisser, etc.). Contrairement à l'outil de navigation d'OpenClaw, il fonctionne au niveau X11 afin que les sites Web ne puissent pas détecter l'automatisation. Comprend VNC pour la visualisation en direct.
