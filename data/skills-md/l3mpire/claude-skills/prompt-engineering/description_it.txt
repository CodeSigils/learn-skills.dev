Trasforma qualsiasi suggerimento approssimativo, vago o poco performante in un messaggio ottimizzato pronto per la produzione per Claude. Utilizza questa abilità ogni volta che l'utente desidera migliorare un prompt, dice "migliora questo prompt", "ottimizza questo", "il mio prompt non funziona", "scrivimi un prompt per X" o condivide qualsiasi istruzione che desidera che Claude segua in modo affidabile. Copre i prompt di sistema, i prompt dell'utente e i prompt dell'agente/flusso di lavoro. Produce sempre il prompt ottimizzato + una spiegazione chiara di ogni scelta effettuata.
