Verwandelt jede grobe, vage oder leistungsschwache Eingabeaufforderung in eine produktionsreife, optimierte Eingabeaufforderung für Claude. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine Eingabeaufforderung verbessern möchte, sagt: „Diese Eingabeaufforderung verbessern“, „optimieren“, „Meine Eingabeaufforderung funktioniert nicht“, „Schreiben Sie mir eine Eingabeaufforderung für X“ oder eine Anweisung mitteilt, die Claude zuverlässig befolgen soll. Behandelt System-Eingabeaufforderungen, Benutzer-Eingabeaufforderungen und Agenten-/Workflow-Eingabeaufforderungen. Erzeugt immer die optimierte Eingabeaufforderung und eine klare Erklärung jeder getroffenen Auswahl.
