データ型に基づいてグラフをインテリジェントに選択し、統一標準に従ってプロフェッショナルな Python matplotlib 視覚化コードを生成します。  
3 つのプロフェッショナル スタイル テンプレートをサポートします: BCG (デフォルトの緑色のミニマリスト)、The Economist (赤線 + ティールのメディア スタイル)、McKinsey (明るいシアン + ライト グレーのコンサルティング スタイル)。  
トリガーシナリオ: ユーザーがデータの視覚化、グラフの生成、プロットの描画、棒/線/円/散布/ヒートマップ チャートの作成などを行う必要がある場合。  
キーワード: 視覚化、チャート、プロット、視覚化、描画、matplotlib、データ チャート、エコノミスト スタイル、マッキンゼー スタイル、BCG スタイル
