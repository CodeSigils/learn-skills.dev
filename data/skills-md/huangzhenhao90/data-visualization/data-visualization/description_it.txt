Seleziona in modo intelligente i grafici in base ai tipi di dati e genera codice di visualizzazione professionale Python matplotlib seguendo standard unificati.  
Supporta tre modelli di stile professionale: BCG (verde minimalista predefinito), The Economist (linea rossa + stile multimediale verde acqua), McKinsey (verde acqua brillante + stile consulenza grigio chiaro).  
Scenari di attivazione: l'utente deve visualizzare dati, generare grafici, tracciare grafici, creare grafici a barre/linee/torta/dispersione/mappa termica, ecc.
