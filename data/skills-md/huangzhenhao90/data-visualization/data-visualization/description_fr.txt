Sélectionnez intelligemment les graphiques en fonction du type de données et générez un code de visualisation Python matplotlib professionnel selon une norme unifiée.  
Prend en charge trois modèles de style professionnel : BCG (minimaliste vert par défaut), The Economist (style multimédia ligne rouge + bleu sarcelle), McKinsey (style conseil cyan vif + gris clair).  
Scénarios de déclenchement : l'utilisateur a besoin de visualisation de données, de génération de graphiques, de traçage, de création de graphiques à barres/lignes/camemberts/nuages de points/carte thermique, etc.  
Mots-clés : visualisation, graphique, tracé, visualisation, dessin, matplotlib, graphique de données, style The Economist, style McKinsey, style BCG
