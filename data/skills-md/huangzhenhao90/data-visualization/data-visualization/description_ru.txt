Разумно выбирайте диаграммы на основе типа данных и создавайте профессиональный код визуализации Python matplotlib в соответствии с единым стандартом.  
Поддерживает три шаблона профессионального стиля: BCG (зеленый минималистский стиль по умолчанию), The Economist (красная линия + бирюзовый медиа-стиль), McKinsey (ярко-голубой + светло-серый стиль консультирования).  
Сценарии триггеров: пользователю нужна визуализация данных, создание диаграмм, построение графиков, создание гистограмм, линейных, круговых, точечных диаграмм, тепловых карт и т. д.  
Ключевые слова: визуализация, диаграмма, график, визуализация, рисунок, matplotlib, диаграмма данных, стиль The Economist, стиль McKinsey, стиль BCG.
