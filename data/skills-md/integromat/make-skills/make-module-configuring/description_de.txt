Diese Fähigkeit sollte beim Konfigurieren von Make-Modulparametern, beim Zuweisen von Verbindungen, beim Zuordnen von Daten zwischen Modulen, beim Einrichten von Webhooks oder Datenspeichern in Modulen, beim Arbeiten mit IML-Ausdrücken, beim Umgang mit Schlüsseln oder beim Definieren von Datenstrukturen für Moduleingänge/-ausgänge verwendet werden. Behandelt das praktische WIE der Modulkonfiguration – ergänzend zum Make-Scenario-Build, der behandelt, WELCHE Module verwendet werden sollen und WARUM.
