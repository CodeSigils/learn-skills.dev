Diese Fähigkeit sollte verwendet werden, wenn Claude eine wiederverwendbare Make API-Call-Shell erstellen oder wiederverwenden muss, indem er das richtige app-spezifische Make an API Call-Modul ermittelt, die richtige Verbindung auflöst oder anfordert, die Szenarioschnittstelle explizit festlegt, das Szenario ausführt und diese Shell als Abruftransport für E-Mail, CRM, Tickets und ähnliche SaaS-Systeme verwendet.
