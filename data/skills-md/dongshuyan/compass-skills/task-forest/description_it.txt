Mantiene una foresta di attività locale del repository o un DAG di attività per l'area di lavoro corrente. Da utilizzare quando l'utente chiede di inizializzare, aggiornare, chiudere una sessione, riepilogare le attività del progetto in evoluzione, decidere se una nuova richiesta è un'attività globale o un'attività secondaria, tenere traccia dell'avanzamento/cronologia/deviazioni/cose da fare dell'attività, esportare un grafico dell'attività HTML o fornire dati dell'attività per gap-router/local-agent-control-room. Non utilizzare per eseguire le attività stesse.
