Mantiene un bosque de tareas de repositorio local o un DAG de tareas para el espacio de trabajo actual. Úselo cuando el usuario solicita inicializar, actualizar, cerrar una sesión, resumir las tareas del proyecto en evolución, decidir si una nueva solicitud es una tarea o subtarea global, realizar un seguimiento del progreso/historial/desviaciones/todos de la tarea, exportar un gráfico de tareas HTML o proporcionar datos de tareas para el enrutador de brecha/sala de control del agente local. No lo utilice para ejecutar las tareas en sí.
