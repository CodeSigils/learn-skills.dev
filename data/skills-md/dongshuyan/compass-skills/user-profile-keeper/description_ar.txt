مهارة صيانة ملف تعريف المستخدم المحلي لـ Codex وClaude Code وOpenClaw وOpenCode وأدوات الوكلاء الأخرى. يُستخدم فقط عندما يستدعي المستخدم هذه المهارة بشكل صريح أو يطلب إنشاء ملف تعريف مستخدم محلي ثابت أو تهيئته أو تحديثه أو الاستعلام عنه أو تصحيحه أو حذفه أو تصديره أو تدقيقه. استخدم أيضًا لاستخراج تفضيلات التعاون الدائم، وعادات التعبير عن المتطلبات، وحدود القدرة، والإغفالات المتكررة، وتفضيلات المخاطر، وحدود الخصوصية، والأحداث النموذجية من الجلسة الحالية إلى بيانات ملف تعريف محلي قابلة للتدقيق والتأكيد والسحب. لا تقم بالاستدعاء التلقائي أو تحميل بيانات الملف الشخصي أو استبدال تدفق التوضيح العادي لأداة توضيح المهام.
