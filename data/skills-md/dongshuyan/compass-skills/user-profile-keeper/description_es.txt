Habilidad de mantenimiento de perfil de usuario local para Codex, Claude Code, OpenClaw, OpenCode y otros arneses de agentes. Úselo solo cuando el usuario invoque explícitamente esta habilidad o solicite crear, inicializar, actualizar, consultar, corregir, eliminar, exportar o auditar un perfil de usuario persistente local. También se utiliza para extraer preferencias de colaboración duraderas, hábitos de expresión de requisitos, límites de capacidad, omisiones recurrentes, preferencias de riesgo, límites de privacidad y eventos típicos de la sesión actual en datos de perfil local retráctiles, confirmables y auditables. No invoque automáticamente, cargue datos de perfil ni reemplace el flujo de aclaración normal del clarificador de tareas.
