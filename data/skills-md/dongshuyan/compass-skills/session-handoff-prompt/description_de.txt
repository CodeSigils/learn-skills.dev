Erstellen Sie eine prägnante Fortsetzungsaufforderung, die eine neue Agentensitzung einfügen kann, um eine lange oder beeinträchtigte Sitzung fortzusetzen. Verwenden Sie diese Option, wenn der Benutzer eine Übergabeaufforderung, eine Neustartaufforderung, eine Fortsetzungsaufforderung, eine Kontextübertragung, eine Wiederaufnahme einer neuen Sitzung oder eine kompakte Zusammenfassung zum Öffnen einer neuen Sitzung anfordert. Nicht für gewöhnliche Zusammenfassungen, die Pflege von Aufgabengesamtstrukturen, dauerhafte Aktualisierungen von Benutzerprofilen, automatische Sitzungserstellung, Codeausführung oder externe Veröffentlichung verwenden.
