Créez une invite de continuation concise dans laquelle une nouvelle session d'agent peut coller pour reprendre une session longue ou dégradée. À utiliser lorsque l'utilisateur demande une invite de transfert, une invite de redémarrage, une invite de continuation, un transfert de contexte, une reprise de nouvelle session ou un résumé compact pour l'ouverture d'une nouvelle session. Ne pas utiliser pour les résumés ordinaires, la maintenance des forêts de tâches, les mises à jour durables des profils utilisateur, la création automatique de sessions, l'exécution de code ou la publication externe.
