Creare una richiesta di continuazione concisa che una nuova sessione dell'agente possa incollare per riprendere una sessione lunga o ridotta. Da utilizzare quando l'utente richiede un prompt di trasferimento, un prompt di riavvio, un prompt di continuazione, un trasferimento di contesto, una ripresa di una nuova sessione o un riepilogo compatto per l'apertura di una nuova sessione. Non utilizzare per riepiloghi ordinari, manutenzione della foresta di attività, aggiornamenti durevoli dei profili utente, creazione automatica di sessioni, esecuzione di codice o pubblicazione esterna.
