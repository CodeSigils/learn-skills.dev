قم بإنشاء مطالبة متابعة موجزة يمكن لجلسة وكيل جديدة لصقها لاستئناف جلسة طويلة أو متدهورة. يُستخدم عندما يطلب المستخدم مطالبة بالتسليم، أو مطالبة بإعادة التشغيل، أو مطالبة بالاستمرار، أو نقل السياق، أو استئناف جلسة جديدة، أو ملخص مختصر لفتح جلسة جديدة. لا تستخدمه للملخصات العادية، أو صيانة مجموعة المهام، أو التحديثات الدائمة لملف تعريف المستخدم، أو إنشاء الجلسة تلقائيًا، أو تنفيذ التعليمات البرمجية، أو النشر الخارجي.
