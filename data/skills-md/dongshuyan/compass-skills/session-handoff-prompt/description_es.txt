Cree un mensaje de continuación conciso que una nueva sesión del agente pueda pegar para reanudar una sesión larga o degradada. Úselo cuando el usuario solicita un mensaje de transferencia, un mensaje de reinicio, un mensaje de continuación, una transferencia de contexto, una reanudación de una nueva sesión o un resumen compacto para abrir una nueva sesión. No lo utilice para resúmenes ordinarios, mantenimiento de bosques de tareas, actualizaciones duraderas de perfiles de usuario, creación automática de sesiones, ejecución de código o publicación externa.
