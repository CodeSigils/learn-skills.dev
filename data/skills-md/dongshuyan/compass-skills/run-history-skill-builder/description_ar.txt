قم بتحويل مهمة مكتملة، أو تدفق المتصفح، أو خط أنابيب المنتجات، أو تتبع استرداد الفشل، أو سير العمل المكرر بشكل متكرر إلى حزمة مهارات جديدة قابلة لإعادة الاستخدام أو خطة تصميم مهارات تمت مراجعتها. يُستخدم عندما يطلب المستخدم إنشاء مهارة جديدة من سجل التشغيل الحقيقي، أو استخراج سير عمل قابل لإعادة الاستخدام من المحادثات/السجلات/الملفات، أو تلخيص الدروس في مهارة جديدة، أو إنتاج خطة قبل كتابة الملفات. لا تستخدم لترقية مهارة موجودة أو لتنفيذ سير عمل الأعمال نفسه.
