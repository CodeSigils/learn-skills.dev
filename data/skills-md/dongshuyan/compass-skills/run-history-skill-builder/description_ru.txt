Превратите выполненную задачу, поток браузера, конвейер артефактов, трассировку восстановления после сбоя или неоднократно усовершенствованный рабочий процесс в новый многоразовый пакет навыков или проверенный план разработки навыков. Используйте, когда пользователь просит создать новый навык из реальной истории выполнения, извлечь рабочий процесс многократного использования из разговоров/журналов/файлов, обобщить уроки в новый навык или составить план перед записью файлов. Не используйте для повышения квалификации или для выполнения самого бизнес-процесса.
