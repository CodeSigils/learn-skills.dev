Verwenden Sie diese Option, wenn der Benutzer eine neue Fertigkeit aus dem tatsächlichen Laufverlauf erstellen, einen wiederverwendbaren Arbeitsablauf aus Konversationen/Protokollen/Dateien extrahieren, Lektionen in einer neuen Fertigkeit zusammenfassen oder vor dem Schreiben von Dateien einen Plan erstellen möchte. Nicht verwenden, um eine vorhandene Fertigkeit zu verbessern oder den Geschäftsablauf selbst auszuführen.
