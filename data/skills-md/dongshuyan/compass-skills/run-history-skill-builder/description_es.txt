Convierta una tarea completada, un flujo de navegador, una canalización de artefactos, un seguimiento de recuperación de fallas o un flujo de trabajo refinado repetidamente en un nuevo paquete de habilidades reutilizable o un plan de diseño de habilidades revisado. Úselo cuando el usuario solicite crear una nueva habilidad a partir del historial de ejecución real, extraer un flujo de trabajo reutilizable de conversaciones/registros/archivos, resumir lecciones en una nueva habilidad o producir un plan antes de escribir archivos. No lo utilice para mejorar una habilidad existente ni para ejecutar el flujo de trabajo empresarial en sí.
