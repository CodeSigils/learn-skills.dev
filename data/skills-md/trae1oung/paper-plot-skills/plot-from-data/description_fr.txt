Générez des figures matplotlib de qualité publication en sélectionnant un style de papier prédéfini et en remplaçant les données utilisateur.
À utiliser lorsque : l'utilisateur fournit des données (nombres, tableaux ou CSV) et souhaite un graphique dans un style académique spécifique ;
l'utilisateur demande de « tracer ces données », « créer un graphique à barres », « dessiner un graphique radar », « 用这个风格画图 », « 把我的数据画出来 » ;
ou l'utilisateur sélectionne un nom de style dans le catalogue de styles (bar_paired_delta, bar_grouped_hatch,
line_confidence_band, line_training_curve, line_loss_with_inset, scatter_tsne_cluster,
scatter_broken_axis, radar_dual_series).
