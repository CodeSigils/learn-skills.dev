Reproduzca cualquier figura de un artículo académico a partir de una imagen cargada utilizando la experiencia de estilo acumulada.
Úselo cuando: el usuario carga/adjunta una figura de papel y solicita reproducirla o recrearla;
el usuario dice "复现这个图", "reproducir este gráfico", "coincidir con esta figura", "照着这个图画";
o el usuario proporciona una figura de papel PNG/captura de pantalla y quiere el código Python matplotlib que la genera.
Incluye flujo de trabajo de análisis para detección de fuentes, extracción de colores, coincidencia de proporciones,
y mapear 8 estilos prediseñados o crear un nuevo estilo desde cero.
