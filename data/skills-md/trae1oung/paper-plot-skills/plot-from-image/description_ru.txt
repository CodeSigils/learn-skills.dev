Воспроизведите любую фигуру из академической статьи из загруженного изображения, используя накопленный опыт создания стилей.
Используйте, когда: пользователь загружает/прикрепляет бумажную фигурку и просит воспроизвести или воссоздать ее;
пользователь говорит «复现这个图», «воспроизвести этот сюжет», «сопоставить этот рисунок», «照着这个图画»;
или пользователь предоставляет бумажную фигуру PNG/скриншот и хочет, чтобы код Python matplotlib генерировал ее.
Включает в себя рабочий процесс анализа для определения шрифта, извлечения цвета, сопоставления пропорций,
и сопоставление с 8 готовыми стилями или создание нового стиля с нуля.
