Realice un seguimiento de qué pilas en una organización Pulumi utilizan un paquete específico y en qué versiones. Úselo para auditorías entre pilas, para identificar versiones de paquetes obsoletas o sin mantenimiento en muchas pilas, para encontrar pilas afectadas antes de publicar cambios importantes en un paquete de componentes o para planificar implementaciones de actualizaciones coordinadas. NO lo use para actualizar un paquete de proveedor de nube (pulumi-aws, pulumi-azure-native, pulumi-gcp, pulumi-kubernetes, etc.) en un solo proyecto; use la habilidad "provider-upgrade" en su lugar. NO lo utilice para la creación de infraestructura general, el aprovisionamiento de recursos o preguntas prácticas sobre un paquete.
