Pulumi 組織全体でどのスタックが特定のパッケージを使用し、どのバージョンで使用されているかを追跡します。クロススタック監査、多数のスタックにわたる古いパッケージ バージョンまたはメンテナンスされていないパッケージ バージョンの特定、コンポーネント パッケージに重大な変更を公開する前に影響を受けるスタックの検出、または調整されたアップグレードのロールアウトの計画に使用します。単一プロジェクト内のクラウド プロバイダー パッケージ (pulumi-aws、pulumi-azure-native、pulumi-gcp、pulumi-kubernetes など) のアップグレードには使用しないでください。代わりにスキル `provider-upgrade` を使用してください。一般的なインフラストラクチャの作成、リソースのプロビジョニング、またはパッケージに関するハウツーの質問には使用しないでください。
