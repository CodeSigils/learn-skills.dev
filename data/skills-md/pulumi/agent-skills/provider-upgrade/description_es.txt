Actualice cualquier proveedor de Pulumi a una versión más nueva y concilie la diferencia resultante. Úselo cuando los usuarios quieran mejorar o actualizar un proveedor (incluida la edición de package.json, requisitos.txt, pyproject.toml, go.mod o Pulumi.yaml para mejorar el SDK de un proveedor), verificar cambios importantes antes o durante una actualización, reparar recursos que se rompieron después de una actualización de proveedor o resolver reemplazos, creaciones o eliminaciones inesperadas en una vista previa posterior a la actualización. Se aplica a todos los proveedores (aws, azure-native, gcp, kubernetes, aws-native, cloudflare, datadog, etc.), no solo al nivel 1. NO lo use para consultar qué pilas usan qué versiones de paquete; Utilice la habilidad "uso de paquetes" para auditorías entre pilas. NO lo utilice para tareas generales de infraestructura.
