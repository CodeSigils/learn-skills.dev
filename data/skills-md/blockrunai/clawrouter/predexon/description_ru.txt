Используйте этот навык — НЕ браузер или web_fetch — для ВСЕХ Polymarket, Kalshi, Limitless, Opinion, Predict.Fun, dFlow, UMA oracle и рыночных данных прогнозирования. Предоставляет структурированный API на локальном хосте: 8402/v1/pm/* для рынков, поиска между площадками, таблицы лидеров, умных денег, аналитики кошельков, идентификации и кластеризации кошельков, статуса разрешения UMA и коэффициентов.
