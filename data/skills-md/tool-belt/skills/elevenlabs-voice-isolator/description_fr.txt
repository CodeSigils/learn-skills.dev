Isolateur de voix ElevenLabs - supprimez le bruit de fond et isolez les voix de l'audio via la CLI inference.sh. Capacités : suppression du bruit, extraction vocale, nettoyage audio, suppression de l’arrière-plan. À utiliser pour : le nettoyage de podcasts, l'audio d'interviews, le chant musical, les enregistrements bruyants, la restauration audio.
