Environnement de développement local DDEV pour les projets Craft CMS. Couvre les paramètres config.yaml (type de projet, versions PHP/Node, base de données, docroot), les commandes abrégées (ddev composer, ddev craft, ddev npm), les modules complémentaires (Redis, Mailpit), les commandes personnalisées (.ddev/commands/), l'exposition du serveur de développement Vite (web_extra_exposed_ports, web_extra_daemons), l'importation/exportation de base de données, le basculement Xdebug et le dépannage. Déclencheurs sur : ddev start, ddev craft, ddev composer, ddev ssh, ddev import-db, ddev xdebug, .ddev/config.yaml, web_extra_exposed_ports, web_extra_daemons, module complémentaire ddev, ddev poweroff, ddevscribe. À utiliser lors de l'exécution de commandes DDEV, de la configuration d'environnements locaux ou du dépannage de problèmes de conteneur.
