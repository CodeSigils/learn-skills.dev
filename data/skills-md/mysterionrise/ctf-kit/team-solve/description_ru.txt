Организуйте команду из нескольких агентов для решения задачи CTF. Используйте его, когда задача достаточно сложна и требует параллельного исследования — несколько возможных подходов, многоуровневое кодирование или неясная категория. Создает 3 специализированных товарищей по команде на основе результатов сортировки. Каждый товарищ по команде получает определенную роль в обнаруженной категории. Требуется включить команды агентов (CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1). Триггеры: «командное решение», «параллельное решение», «создать команду», «мультиагент», «использовать для этого команду».
