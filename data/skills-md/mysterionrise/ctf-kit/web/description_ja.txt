CTF Web セキュリティの課題を解決します: SQL インジェクション、XSS、認証バイパス、SSTI、パス トラバーサル、ソース コード監査。 URL、Web アプリのソース コード、または HTTP トラフィックが指定された場合に使用します。トリガー: .php .html .js ファイル、「SQL インジェクション」、「XSS」、「SSTI」、「LFI」、「RFI」、「cookie」、「JWT」、「robots.txt」、「ディレクトリ列挙」、http:// または https:// ターゲット。ツール: sqlmap、gobuster、ffuf、nikto、burpsuite。ネットワーク パケット分析には使用できません (フォレンジックを使用してください)。
