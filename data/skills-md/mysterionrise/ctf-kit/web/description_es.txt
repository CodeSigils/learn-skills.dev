Resuelva los desafíos de seguridad web de CTF: inyección SQL, XSS, omisión de autenticación, SSTI, recorrido de ruta y auditoría de código fuente. Úselo cuando se le proporcione una URL, un código fuente de una aplicación web o tráfico HTTP. Activadores: archivos .php .html .js, "inyección SQL", "XSS", "SSTI", "LFI", "RFI", "cookie", "JWT", "robots.txt", "enumeración de directorios", destinos http:// o https://. Herramientas: sqlmap, gobuster, ffuf, nikto, burpsuite. NO para análisis de paquetes de red (use análisis forense).
