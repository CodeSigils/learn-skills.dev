Risolvi le sfide della sicurezza web CTF: SQL injection, XSS, bypass dell'autenticazione, SSTI, path traversal e controllo del codice sorgente. Da utilizzare quando viene fornito un URL, un codice sorgente di un'app Web o un traffico HTTP. Trigger: file .php .html .js, "SQL injection", "XSS", "SSTI", "LFI", "RFI", "cookie", "JWT", "robots.txt", "directory enumeration", http:// o https:// target. Strumenti: sqlmap, gobuster, ffuf, nikto, burpsuite. NON per l'analisi dei pacchetti di rete (usare analisi forensi).
