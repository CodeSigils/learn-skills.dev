Résolvez les défis de sécurité Web CTF : injection SQL, XSS, contournement d'authentification, SSTI, traversée de chemin et audit du code source. À utiliser lorsqu'on vous donne une URL, le code source d'une application Web ou un trafic HTTP. Déclencheurs : fichiers .php .html .js, "injection SQL", "XSS", "SSTI", "LFI", "RFI", "cookie", "JWT", "robots.txt", "énumération de répertoire", cibles http:// ou https://. Outils : sqlmap, gobuster, ffuf, nikto, burpsuite. PAS pour l'analyse des paquets réseau (utilisez la médecine légale).
