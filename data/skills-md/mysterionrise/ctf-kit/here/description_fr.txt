Définir le contexte de compétition pour le répertoire de défis actuel. Initialise le dossier .ctf/, détecte les fichiers, devine la catégorie et enregistre les métadonnées. À utiliser lorsque vous commencez à travailler sur un nouveau défi, entrez dans un répertoire de défis ou configurez le contexte pour l'analyse de l'IA. Déclencheurs : « démarrer le défi », « définir le contexte », « initialiser le défi », « ctf ici », « commencer à travailler sur », « nouveau défi ».
