Résolvez les défis d'ingénierie inverse CTF : désassemblage, décompilation, recherche de clé/mot de passe, analyse d'algorithme et contournement anti-débogage. Utiliser lorsqu'on vous donne des binaires pour analyser statiquement - crackmes, keygens, code obscurci. Déclencheurs : fichiers .exe .elf .apk .jar .pyc, "désassembler", "décompiler", "keygen", "crackme", "trouver le mot de passe", "anti-débogage", sortie radare2/Ghidra, code assembleur. Outils : radare2, Ghidra, objdump, ltrace, strace, jadx, uncompyle6. PAS pour l'exploitation/pwn (utilisez pwn) ou le tri des logiciels malveillants (utilisez la médecine légale).
