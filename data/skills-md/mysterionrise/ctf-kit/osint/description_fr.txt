Résolvez les défis CTF OSINT (open source intelligence) : énumération des noms d'utilisateur, reconnaissance de domaine, enquête sur les réseaux sociaux, géolocalisation à partir d'images et recherche de documents publics. À utiliser lorsqu'on vous donne un nom d'utilisateur, une adresse e-mail, un domaine ou une photo pour enquêter. Déclencheurs : "trouver cette personne", "recherche de nom d'utilisateur", "qui est", "géolocalisation", "recherche d'image inversée", "EXIF GPS", "whois", "reconnaissance de domaine", "médias sociaux". Outils : sherlock, theHarvester, exiftool, whois, dig. PAS pour l'exploitation d'applications Web (utilisez le Web).
