Запросите учетную запись хранения интеграционных тестов, чтобы выяснить, почему тесты определенного навыка не пройдены. Считывает файлы результатов тестов, хранящиеся в больших двоичных объектах, и выводит сведения об ошибках. ТРИГГЕРЫ: почему происходит сбой навыков, сбои при проверке навыков, отладка тестов навыков, тесты с ошибками навыков, анализ сбоев навыков, почему тесты не выполняются для навыков, ошибки проверки навыков, исследование проблем с навыками. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: анализа отчета о запуске GitHub Actions или сравнения запусков тестов между запусками (используйте Analysis-test-run).
