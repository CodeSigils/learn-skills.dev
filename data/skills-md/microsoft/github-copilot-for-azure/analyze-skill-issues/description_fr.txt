Interrogez le compte de stockage des tests d’intégration pour découvrir pourquoi les tests d’une compétence spécifique échouent. Lit les fichiers de résultats de test stockés dans le blob et affiche les détails des erreurs. DÉCLENCHEURS : pourquoi les compétences échouent, les échecs aux tests de compétences, les tests de compétences de débogage, les tests de compétences qui échouent, analyser les échecs de compétences, pourquoi les tests échouent pour les compétences, les erreurs des tests de compétences, enquêter sur les problèmes de compétences. NE PAS UTILISER POUR : analyser un rapport d’exécution d’actions GitHub ou comparer des exécutions de tests entre les exécutions (utilisez analyser-test-run).
