استعلم عن حساب تخزين اختبار التكامل لمعرفة سبب فشل اختبارات مهارة معينة. يقرأ ملفات نتائج الاختبار المخزنة في blob ويظهر تفاصيل الخطأ. المحفزات: لماذا تفشل المهارة، وفشل اختبار المهارة، وتصحيح اختبارات المهارة، واختبارات فشل المهارة، وتحليل إخفاقات المهارة، ولماذا تفشل اختبارات المهارة، وأخطاء اختبار المهارة، والتحقيق في مشكلات المهارة. لا تستخدم من أجل: تحليل تقرير تشغيل GitHub Actions أو مقارنة عمليات التشغيل الاختبارية عبر عمليات التشغيل (استخدم تحليل اختبار التشغيل).
