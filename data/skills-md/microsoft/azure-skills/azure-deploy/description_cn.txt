对具有现有 .azure/plan.md 和基础结构文件的已准备好应用程序执行 Azure 部署。当用户要求创建新应用程序时，请勿使用此技能 - 请改用 azure-prepare。此技能运行带有内置错误恢复的 azd up、azd deploy、terraform apply 和 azdeployment 命令。需要来自 azure-prepare 的 .azure/plan.md 和来自 azure-validate 的已验证状态。时间：“运行 azd up”、“运行 azd 部署”、“执行部署”、“推送到生产”、“推送到云”、“上线”、“交付”、“bicep 部署”、“terraform 应用”、“发布到 Azure”、“在 Azure 上启动”。不要使用以下情况：“创建和部署”、“构建和部署”、“创建新应用程序”、“设置基础架构”、“使用 Terraform 创建并部署到 Azure”——对这些使用 azure-prepare。
