Ejecute implementaciones de Azure para aplicaciones YA PREPARADAS que tengan archivos .azure/plan.md y de infraestructura existentes. NO use esta habilidad cuando el usuario solicite CREAR una nueva aplicación; en su lugar, use azure-prepare. Esta habilidad ejecuta los comandos azd up, azd implementación, terraform apply y az implementación con recuperación de errores incorporada. Requiere .azure/plan.md de azure-prepare y estado validado de azure-validate.
