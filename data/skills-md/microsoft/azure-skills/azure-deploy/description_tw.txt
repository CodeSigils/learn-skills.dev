對具有現有 .azure/plan.md 和基礎結構檔案的已準備好應用程式執行 Azure 部署。當使用者要求建立新應用程式時，請勿使用此技能 - 請改用 azure-prepare。此技能執行內建錯誤復原的 azd up、azd deploy、terraform apply 和 azdeployment 指令。需要來自 azure-prepare 的 .azure/plan.md 和來自 azure-validate 的已驗證狀態。時間：「執行 azd up」、「執行 azd 部署」、「執行部署」、「推送到生產」、「推送到雲端」、「上線」、「交付」、「bicep 部署」、「terraform 應用程式」、「發佈到 Azure」、「在 Azure 上啟動」。不要使用以下情況：「建立和部署」、「建置和部署」、「建立新應用程式」、「設定基礎架構」、「使用 Terraform 建立並部署到 Azure」—對這些使用 azure-prepare。
