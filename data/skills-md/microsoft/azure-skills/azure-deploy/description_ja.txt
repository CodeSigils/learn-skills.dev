既存の .azure/plan.md およびインフラストラクチャ ファイルがある、準備済みのアプリケーションに対して Azure デプロイを実行します。ユーザーが新しいアプリケーションの作成を要求した場合は、このスキルを使用しないでください。代わりに azure-prepare を使用してください。このスキルは、組み込みのエラー回復機能を備えた azd up、azddeploy、terraform apply、および azdeployment コマンドを実行します。 azure-prepare からの .azure/plan.md と、azure-validate からの検証済みステータスが必要です。 WHEN: 「azd up の実行」、「azddeploy の実行」、「デプロイの実行」、「運用環境へのプッシュ」、「クラウドへのプッシュ」、「ライブ開始」、「出荷」、「上腕二頭筋のデプロイ」、「Terraform 適用」、「Azure への発行」、「Azure での起動」。 「作成してデプロイする」、「ビルドしてデプロイする」、「新しいアプリを作成する」、「インフラストラクチャをセットアップする」、「Terraform を使用して Azure に作成してデプロイする」場合には使用しないでください。これらには azure-prepare を使用します。
