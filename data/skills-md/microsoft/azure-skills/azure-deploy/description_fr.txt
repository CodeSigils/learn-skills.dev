Exécutez des déploiements Azure pour les applications DÉJÀ PRÉPARÉES qui disposent de fichiers .azure/plan.md et d'infrastructure existants. N'utilisez PAS cette compétence lorsque l'utilisateur demande de CRÉER une nouvelle application — utilisez plutôt azure-prepare. Cette compétence exécute les commandes azd up, azd déployer, terraform apply et az déploiement avec récupération d'erreur intégrée. Nécessite .azure/plan.md d’azure-prepare et le statut validé d’azure-validate.
