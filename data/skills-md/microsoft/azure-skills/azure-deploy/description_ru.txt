Выполняйте развертывания Azure для УЖЕ ПОДГОТОВЛЕННЫХ приложений, у которых есть существующие файлы .azure/plan.md и инфраструктуры. НЕ используйте этот навык, когда пользователь просит СОЗДАТЬ новое приложение — вместо этого используйте azure-prepare. Этот навык запускает команды azd up, azd Deploy, terraform Apply и az Deployment со встроенным восстановлением ошибок. Требуется .azure/plan.md из azure-prepare и подтвержденный статус из azure-validate. КОГДА: «запустить azd up», «запустить azd Deploy», «выполнить развертывание», «отправить в производство», «отправить в облако», «запустить в эксплуатацию», «отправить», «развертывание бицепса», «применить терраформирование», «публиковать в Azure», «запустить в Azure». НЕ ИСПОЛЬЗУЙТЕ WHEN: «создать и развернуть», «создать и развернуть», «создать новое приложение», «настроить инфраструктуру», «создать и развернуть в Azure с помощью Terraform» — используйте для них azure-prepare.
