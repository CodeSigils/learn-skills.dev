Führen Sie Azure-Bereitstellungen für BEREITS VORBEREITETE Anwendungen aus, die über vorhandene .azure/plan.md- und Infrastrukturdateien verfügen. Verwenden Sie diese Fähigkeit NICHT, wenn der Benutzer eine neue Anwendung ERSTELLEN möchte – verwenden Sie stattdessen azure-prepare. Dieser Skill führt die Befehle azd up, azdploy, terraform apply und az Deployment mit integrierter Fehlerbehebung aus. Erfordert .azure/plan.md von azure-prepare und validierten Status von azure-validate. WANN: „AZD hochfahren“, „AZD Deploy ausführen“, „Bereitstellung ausführen“, „in die Produktion pushen“, „in die Cloud pushen“, „live gehen“, „versenden“, „Bicep-Deployment“, „Terraform anwenden“, „in Azure veröffentlichen“, „in Azure starten“. NICHT VERWENDEN, WENN: „Erstellen und Bereitstellen“, „Erstellen und Bereitstellen“, „Eine neue App erstellen“, „Infrastruktur einrichten“, „Mit Terraform in Azure erstellen und bereitstellen“ – verwenden Sie hierfür azure-prepare.
