ワークロードの説明に基づいてエンタープライズ Azure インフラストラクチャを設計およびプロビジョニングします。 WAF との調整を伴うネットワーキング、アイデンティティ、セキュリティ、コンプライアンス、およびマルチリソース トポロジを計画するクラウド アーキテクトおよびプラットフォーム エンジニア向け。 Bicep または Terraform を直接生成します (azd なし)。時期: 「Azure インフラストラクチャの計画」、「Azure ランディング ゾーンの設計」、「ハブスポーク ネットワークの設計」、「マルチリージョン DR トポロジの計画」、「VNet ファイアウォールとプライベート エンドポイントの設定」、「サブスクリプション スコープの Bicep デプロイ」。アプリ中心のワークフローには azure-prepare を推奨します。
