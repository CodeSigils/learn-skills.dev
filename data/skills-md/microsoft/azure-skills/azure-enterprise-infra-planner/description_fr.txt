Architectez et provisionnez l’infrastructure Azure d’entreprise à partir des descriptions de charges de travail. Pour les architectes cloud et les ingénieurs de plate-forme qui planifient des topologies de réseau, d'identité, de sécurité, de conformité et multi-ressources avec l'alignement WAF. Génère directement Bicep ou Terraform (pas d'azd). PRÉFÉREZ Azure-prepare POUR les workflows centrés sur les applications.
