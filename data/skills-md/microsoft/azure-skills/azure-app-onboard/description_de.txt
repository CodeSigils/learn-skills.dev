End-to-End-Orchestrator: von einer Geschäftsidee, einer App-Idee oder einer vorhandenen App bis zur laufenden Azure-Bereitstellung mit Kostenschätzungen und Genehmigung vor der Bereitstellung. Analysiert Ihre App, erkennt automatisch die richtigen Azure-Dienste, erstellt ein Gerüst für Infrastrukturcode und stellt sie bereit – maßgeschneidert auf Ihre App, nicht auf eine Vorlage. Bewältigt das Verschieben vorhandener Apps nach Azure ohne Umschreiben oder mit minimalen Änderungen. WANN: Bringen Sie Ihre App zu Azure, planen Sie meine App, Kosten für die Ausführung, ist mein Code bereit für die Bereitstellung, stellen Sie meine App in der Cloud bereit, stellen Sie alle meine Dienste bereit, welche Azure-Dienste benötige ich, planen Sie meine Azure-Bereitstellung, stellen Sie meine neue App in Azure bereit, Bereitstellung mit einem Klick, ich habe eine App und möchte sie auf Azure, migriere meine App zu Azure, hilf mir beim Einstieg, erstelle eine App, noch kein Code, Starterprojekt. NICHT VERWENDEN FÜR: Ausführen von azd (verwenden Sie azure-deploy), Optimieren vorhandener Kosten (verwenden Sie azure-cost), nur Code-Bereitschaftsprüfungen (verwenden Sie azure-app-onboard-prereq).
