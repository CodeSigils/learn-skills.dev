Комплексный оркестратор: от бизнес-идеи, идеи приложения или существующего приложения до запуска развертывания Azure с сметой затрат и утверждением перед развертыванием. Анализирует ваше приложение, автоматически определяет нужные службы Azure, формирует код инфраструктуры и развертывает — с учетом вашего приложения, а не шаблона. Обеспечивает перемещение существующих приложений в Azure без переписывания или с минимальными изменениями. КОГДА: перенести ваше приложение в Azure, спланировать мое приложение, стоимость запуска, готов ли мой код к развертыванию, развернуть мое приложение в облаке, развернуть все мои службы, какие службы Azure мне нужны, спланировать развертывание Azure, развернуть мое новое приложение в Azure, развертывание одним щелчком мыши, у меня есть приложение, и я хочу, чтобы оно было в Azure, перенести мое приложение в Azure, помочь мне начать работу, создать приложение, пока нет кода, стартовый проект. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: запуска azd (используйте azure-deploy), оптимизации существующих затрат (используйте azure-cost), только проверки готовности кода (используйте azure-app-onboard-prereq).
