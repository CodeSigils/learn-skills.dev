تخطيط وإنشاء وتكوين مجموعات Azure Kubernetes Service (AKS) الجاهزة للإنتاج. يغطي قائمة مراجعة اليوم 0، واختيار SKU (تلقائي مقابل قياسي)، وخيارات الشبكات (خادم واجهة برمجة التطبيقات الخاص، وتراكب Azure CNI، وتكوين الخروج)، والأمان، والعمليات (القياس التلقائي، واستراتيجية الترقية، وتحليل التكلفة). متى: إنشاء بيئة AKS، وتوفير بيئة AKS، وتمكين إمكانية ملاحظة AKS، وتصميم شبكات AKS، واختيار AKS SKU، وتأمين AKS.
