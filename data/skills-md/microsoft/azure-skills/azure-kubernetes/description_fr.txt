Planifiez, créez et configurez des clusters Azure Kubernetes Service (AKS) prêts pour la production. Couvre la liste de contrôle du jour 0, la sélection des SKU (automatique ou standard), les options de mise en réseau (serveur API privé, Azure CNI Overlay, configuration de sortie), la sécurité et les opérations (mise à l'échelle automatique, stratégie de mise à niveau, analyse des coûts). QUAND : créer un environnement AKS, mettre à disposition l'environnement AKS, activer l'observabilité AKS, concevoir le réseau AKS, choisir le SKU AKS, sécuriser AKS.
