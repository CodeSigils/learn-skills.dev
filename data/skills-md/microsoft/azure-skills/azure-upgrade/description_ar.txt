قم بتقييم أحمال عمل Azure وترقيتها بين الخطط أو المستويات أو وحدات SKU داخل Azure. يُنشئ تقارير التقييم ويقوم بأتمتة خطوات الترقية. متى: ترقية الاستهلاك إلى الاستهلاك المرن، وترقية خطة وظائف Azure، وترحيل خطة الاستضافة، وترقية SKU للوظائف، والانتقال إلى الاستهلاك المرن، وترقية طبقة خدمة Azure، وتغيير خطة الاستضافة، وترقية خطة تطبيق الوظيفة، وترحيل خدمة التطبيقات إلى تطبيقات الحاوية.
