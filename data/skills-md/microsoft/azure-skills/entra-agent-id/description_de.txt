Stellen Sie Microsoft Entra Agent Identity Blueprints, BlueprintPrincipals und instanzspezifische Agentenidentitäten über Microsoft Graph bereit und konfigurieren Sie den OAuth 2.0-Token-Austausch (fmi_path, OBO, mandantenübergreifend) einschließlich des Microsoft Entra SDK für AgentID-Sidecar. VERWENDUNG FÜR: Agent Identity Blueprint, BlueprintPrincipal, Agent OAuth, fmi_path Token Exchange, Agent OBO, Workload Identity Federation für Agents, Polyglot Agent Auth, Microsoft.Identity.Web.AgentIdentities. NICHT VERWENDEN FÜR: Standard-Entra-App-Registrierung (verwenden Sie entra-app-registration), Azure RBAC (verwenden Sie azure-rbac), Microsoft Foundry-Agentenerstellung (verwenden Sie microsoft-foundry).
