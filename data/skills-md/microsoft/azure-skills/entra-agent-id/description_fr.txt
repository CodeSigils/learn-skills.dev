Provisionnez les plans d'identité d'agent Microsoft Entra, les BlueprintPrincipals et les identités d'agent par instance via Microsoft Graph, et configurez l'échange de jetons OAuth 2.0 (fmi_path, OBO, cross-tenant), y compris le SDK Microsoft Entra pour le side-car AgentID. UTILISER POUR : Agent Identity Blueprint, BlueprintPrincipal, agent OAuth, échange de jetons fmi_path, agent OBO, Workload Identity Federation pour les agents, authentification d'agent polyglotte, Microsoft.Identity.Web.AgentIdentities. NE PAS UTILISER POUR : l'enregistrement d'application Entra standard (utilisez entra-app-registration), Azure RBAC (utilisez azure-rbac), la création d'agent Microsoft Foundry (utilisez Microsoft-foundry).
