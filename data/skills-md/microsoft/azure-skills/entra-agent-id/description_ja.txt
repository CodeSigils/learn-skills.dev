Microsoft Graph 経由で Microsoft Entra Agent Identity ブループリント、BlueprintPrincipal、およびインスタンスごとのエージェント ID をプロビジョニングし、AgentID サイドカー用の Microsoft Entra SDK を含む OAuth 2.0 トークン交換 (fmi_path、OBO、クロステナント) を構成します。用途: エージェント ID ブループリント、BlueprintPrincipal、エージェント OAuth、fmi_path トークン交換、エージェント OBO、エージェント用 Workload Identity Federation、多言語エージェント認証、Microsoft.Identity.Web.AgentIdentities。次の用途には使用しないでください: 標準の Entra アプリ登録 (entra-app-registration を使用)、Azure RBAC (azure-rbac を使用)、Microsoft Foundry エージェントのオーサリング (microsoft-foundry を使用)。
