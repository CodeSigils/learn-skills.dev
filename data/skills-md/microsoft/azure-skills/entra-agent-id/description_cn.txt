通过 Microsoft Graph 配置 Microsoft Entra 代理身份蓝图、BlueprintPrincipals 和每个实例代理身份，并配置 OAuth 2.0 令牌交换（fmi_path、OBO、跨租户），包括适用于 AgentID sidecar 的 Microsoft Entra SDK。用于：代理身份蓝图、BlueprintPrincipal、代理 OAuth、fmi_path 令牌交换、代理 OBO、代理的工作负载身份联合、多语言代理身份验证、Microsoft.Identity.Web.AgentIdentities。请勿用于：标准 Entra 应用程序注册（使用 entra-app-registration）、Azure RBAC（使用 azure-rbac）、Microsoft Foundry 代理创作（使用 microsoft-foundry）。
