Microsoft Graph를 통해 Microsoft Entra 에이전트 ID Blueprint, BlueprintPrincipals 및 인스턴스별 에이전트 ID를 프로비저닝하고 AgentID 사이드카용 Microsoft Entra SDK를 포함한 OAuth 2.0 토큰 교환(fmi_path, OBO, 교차 테넌트)을 구성합니다. 사용 대상: 에이전트 ID Blueprint, BlueprintPrincipal, 에이전트 OAuth, fmi_path 토큰 교환, 에이전트 OBO, 에이전트용 워크로드 아이덴티티 페더레이션, 다언어 에이전트 인증, Microsoft.Identity.Web.AgentIdentities. 사용하지 마십시오: 표준 Entra 앱 등록(entra-app-registration 사용), Azure RBAC(azure-rbac 사용), Microsoft Foundry 에이전트 작성(microsoft-foundry 사용).
