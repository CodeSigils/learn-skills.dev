評估原始程式碼是否已準備好部署到 Azure - 基礎架構工作之前的檢查。評估建置運行狀況、應用程式完整性、相依性和本機服務、堆疊相容性和部署可行性。回答有關您的應用程式在部署之前需要什麼的問題 - 框架、依賴項和配置。檢查依賴項是否相容並識別部署阻礙和不受支援的框架。何時：「評估我的儲存庫」、「我的應用程式是否已準備好部署」、「我的應用程式需要部署什麼」、「部署前我需要什麼」、「我的應用程式需要什麼」、「我可以將其發送到 Azure」、「掃描我的儲存庫以查找問題」、「此應用程式是否可部署」、「檢查我的應用程式是否已準備好用於 Azure、 Dockerfile」、「什麼阻止了我的部署」、「是否存在任何阻止程式」、「我的依賴項是否存在」相容」、「Azure 是否支援我的框架」、「部署前需要更改哪些內容」、「檢查我的應用程式配置」。
