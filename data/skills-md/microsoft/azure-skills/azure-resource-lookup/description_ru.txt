Перечислите, найдите и покажите ресурсы Azure. Ответы «перечислить мои виртуальные машины», «показать мои учетные записи хранения», «перечислить веб-сайты», «найти приложения-контейнеры», «какие ресурсы у меня есть» и подобные запросы для любого типа ресурсов Azure. ИСПОЛЬЗОВАНИЕ ДЛЯ: список ресурсов, список виртуальных машин, список виртуальных машин, список учетных записей хранения, список веб-сайтов, список веб-приложений, список приложений-контейнеров, показ ресурсов, поиск ресурсов, какие ресурсы у меня есть, список ресурсов в группе ресурсов, список ресурсов в подписке, поиск ресурсов по тегу, поиск потерянных ресурсов, инвентаризация ресурсов, подсчет ресурсов по типу, запрос ресурсов между подписками, Azure Resource Graph, обнаружение ресурсов, список реестров контейнеров, список серверов SQL, список хранилищ ключей, отображение групп ресурсов, список служб приложений, поиск ресурсов подписки, поиск неприсоединённых дисков, анализ тегов. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: развертывания ресурсов (используйте azure-deploy), создания или изменения ресурсов, оптимизации затрат (используйте azure-cost-optimization), написания кода приложения, облаков, отличных от Azure.
