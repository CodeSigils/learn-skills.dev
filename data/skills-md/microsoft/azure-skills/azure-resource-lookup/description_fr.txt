Répertoriez, recherchez et affichez les ressources Azure. Répond « répertorier mes machines virtuelles », « afficher mes comptes de stockage », « répertorier les sites Web », « trouver des applications de conteneur », « de quelles ressources ai-je » et des requêtes similaires pour tout type de ressource Azure. UTILISER POUR : répertorier les ressources, répertorier les machines virtuelles, répertorier les machines virtuelles, répertorier les comptes de stockage, répertorier les sites Web, répertorier les applications Web, répertorier les applications de conteneur, afficher les ressources, rechercher des ressources, quelles ressources ai-je, répertorier les ressources dans un groupe de ressources, répertorier les ressources dans l'abonnement, rechercher des ressources par balise, rechercher des ressources orphelines, inventaire des ressources, compter les ressources par type, requête de ressources par abonnement croisé, Azure Resource Graph, découverte de ressources, répertorier les registres de conteneurs, répertorier les serveurs SQL, répertorier les coffres de clés, afficher les groupes de ressources, répertorier les services d'application, rechercher des ressources dans abonnements, recherche de disques non connectés, analyse des balises. NE PAS UTILISER POUR : le déploiement de ressources (utilisez azure-deploy), la création ou la modification de ressources, l'optimisation des coûts (utilisez azure-cost-optimization), l'écriture de code d'application, les cloud non-Azure.
