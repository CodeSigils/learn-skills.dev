Службы хранения Azure, включая хранилище BLOB-объектов, общие файловые ресурсы, хранилище очередей, хранилище таблиц и озеро данных. Предоставляет объектное хранилище, общие файловые ресурсы SMB, асинхронный обмен сообщениями, ключ-значение NoSQL и возможности анализа больших данных. Включает уровни доступа (горячий, прохладный, архивный) и управление жизненным циклом. ИСПОЛЬЗОВАНИЕ: хранилище BLOB-объектов, общие файловые ресурсы, хранилище очередей, хранилище таблиц, озеро данных, загрузка файлов, загрузка BLOB-объектов, учетные записи хранения, уровни доступа, управление жизненным циклом. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: баз данных SQL, Cosmos DB (используйте azure-prepare), обмена сообщениями с концентраторами событий или служебной шиной (используйте azure-messaging).
