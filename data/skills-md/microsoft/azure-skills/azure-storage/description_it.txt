Servizi di archiviazione di Azure tra cui archiviazione BLOB, condivisioni file, archiviazione code, archiviazione tabelle e Data Lake. Fornisce archiviazione di oggetti, condivisioni file SMB, messaggistica asincrona, valore-chiave NoSQL e funzionalità di analisi dei Big Data. Include livelli di accesso (hot, cool, archivio) e gestione del ciclo di vita. UTILIZZARE PER: archiviazione BLOB, condivisioni file, archiviazione code, archiviazione tabelle, data Lake, caricamento di file, download di BLOB, account di archiviazione, livelli di accesso, gestione del ciclo di vita. NON UTILIZZARE PER: database SQL, Cosmos DB (usare azure-prepare), messaggistica con Hub eventi o bus di servizio (usare azure-messaging).
