Azure Storage Services einschließlich Blob Storage, Dateifreigaben, Warteschlangenspeicher, Tabellenspeicher und Data Lake. Bietet Objektspeicher, SMB-Dateifreigaben, asynchrones Messaging, NoSQL-Schlüsselwert- und Big-Data-Analysefunktionen. Beinhaltet Zugriffsebenen (Hot, Cool, Archiv) und Lebenszyklusverwaltung. VERWENDUNG FÜR: Blobspeicher, Dateifreigaben, Warteschlangenspeicher, Tabellenspeicher, Data Lake, Hochladen von Dateien, Herunterladen von Blobs, Speicherkonten, Zugriffsebenen, Lebenszyklusverwaltung. NICHT VERWENDEN FÜR: SQL-Datenbanken, Cosmos DB (verwenden Sie Azure-Prepare), Messaging mit Event Hubs oder Service Bus (verwenden Sie Azure-Messaging).
