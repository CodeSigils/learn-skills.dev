خدمات تخزين Azure بما في ذلك تخزين Blob ومشاركة الملفات وتخزين قائمة الانتظار وتخزين الجداول وبحيرة البيانات. يوفر تخزين الكائنات ومشاركة ملفات SMB والمراسلة غير المتزامنة وقيمة مفتاح NoSQL وإمكانيات تحليل البيانات الضخمة. يتضمن مستويات الوصول (السريعة، الرائعة، الأرشيفية) وإدارة دورة الحياة. الاستخدام من أجل: تخزين الكائنات الثنائية كبيرة الحجم، ومشاركة الملفات، وتخزين قائمة الانتظار، وتخزين الجدول، وبحيرة البيانات، وتحميل الملفات، وتنزيل الكائنات الثنائية كبيرة الحجم، وحسابات التخزين، ومستويات الوصول، وإدارة دورة الحياة. لا تستخدمه من أجل: قواعد بيانات SQL، أو Cosmos DB (استخدم azure-prepare)، أو المراسلة باستخدام Event Hubs أو Service Bus (استخدم azure-messaging).
