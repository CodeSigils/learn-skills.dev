Services de stockage Azure, notamment le stockage Blob, les partages de fichiers, le stockage de files d'attente, le stockage de tables et Data Lake. Fournit des capacités de stockage d'objets, de partages de fichiers SMB, de messagerie asynchrone, de valeur-clé NoSQL et d'analyse Big Data. Inclut les niveaux d'accès (hot, cool, archive) et la gestion du cycle de vie. UTILISER POUR : stockage d'objets blob, partages de fichiers, stockage de files d'attente, stockage de tables, lac de données, téléchargement de fichiers, téléchargement d'objets blob, comptes de stockage, niveaux d'accès, gestion du cycle de vie. NE PAS UTILISER POUR : bases de données SQL, Cosmos DB (utilisez Azure-prepare), messagerie avec Event Hubs ou Service Bus (utilisez Azure-messaging).
