Blob Storage, 파일 공유, Queue Storage, Table Storage 및 Data Lake를 포함한 Azure Storage 서비스입니다. 객체 스토리지, SMB 파일 공유, 비동기 메시징, NoSQL 키-값 및 빅 데이터 분석 기능을 제공합니다. 액세스 계층(핫, 쿨, 보관) 및 수명 주기 관리가 포함됩니다. 사용 대상: Blob Storage, 파일 공유, 큐 스토리지, 테이블 스토리지, 데이터 레이크, 파일 업로드, Blob 다운로드, 스토리지 계정, 액세스 계층, 수명 주기 관리. 사용하지 마십시오: SQL 데이터베이스, Cosmos DB(azure-prepare 사용), Event Hubs 또는 Service Bus를 통한 메시징(azure-messaging 사용).
