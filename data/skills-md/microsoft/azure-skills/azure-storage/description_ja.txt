BLOB ストレージ、ファイル共有、キュー ストレージ、テーブル ストレージ、データ レイクなどの Azure ストレージ サービス。オブジェクト ストレージ、SMB ファイル共有、非同期メッセージング、NoSQL キーと値、およびビッグ データ分析機能を提供します。アクセス層 (ホット、クール、アーカイブ) とライフサイクル管理が含まれます。用途: BLOB ストレージ、ファイル共有、キュー ストレージ、テーブル ストレージ、データ レイク、ファイルのアップロード、BLOB のダウンロード、ストレージ アカウント、アクセス層、ライフサイクル管理。次の目的には使用しないでください: SQL データベース、Cosmos DB (azure-prepare を使用)、Event Hubs または Service Bus でのメッセージング (azure-messaging を使用)。
