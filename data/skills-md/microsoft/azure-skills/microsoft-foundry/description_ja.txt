Foundry エージェントをエンドツーエンドでデプロイ、評価、管理します: Docker ビルド、ACR プッシュ、ホスト/プロンプト エージェントの作成、コンテナーの開始、バッチ評価、プロンプトの最適化、プロンプト オプティマイザー ワークフロー、agent.yaml、トレースからのデータセットのキュレーション。用途: Foundry へのエージェントのデプロイ、ホスト型エージェント、エージェントの作成、エージェントの呼び出し、エージェントの評価、バッチ評価の実行、プロンプトの最適化、プロンプトの改善、プロンプトの最適化、プロンプトのオプティマイザー、エージェントの指示の改善、エージェントの指示の最適化、システム プロンプトの最適化、モデルのデプロイ、Foundry プロジェクト、RBAC、役割の割り当て、権限、クォータ、容量、リージョン、エージェントのトラブルシューティング、デプロイメントの失敗、トレースからのデータセットの作成、データセットのバージョニング、評価トレンド、AI サービスの作成、 Cognitive Services、Foundry リソースの作成、リソースのプロビジョニング、ナレッジ インデックス、エージェントの監視、展開、オンボード、可用性のカスタマイズ。次の用途には使用しないでください: Azure Functions、App Service、一般的な Azure デプロイ (azure-deploy を使用)、一般的な Azure prep (azure-prepare を使用)。
