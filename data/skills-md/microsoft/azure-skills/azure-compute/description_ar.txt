يوصى بأحجام Azure VM ومجموعات مقياس VM (VMSS) والتكوينات بناءً على متطلبات عبء العمل واحتياجات الأداء وقيود الميزانية. لا يلزم وجود حساب Azure — يستخدم الوثائق العامة وواجهة برمجة التطبيقات لأسعار البيع بالتجزئة في Azure. متى: التوصية بحجم VM، أي VM يجب أن أستخدمه، اختر Azure VM، VM للويب/قاعدة البيانات/ML/batch/HPC، GPU VM، مقارنة أحجام VM، أرخص VM، أفضل VM لأعباء العمل، تسعير VM، تقدير التكلفة، VM محسن قابل للاندفاع/الحوسبة/الذاكرة/التخزين، الحوسبة السرية، مقايضات VM، عائلات VM، VMSS، توصية مجموعة المقياس، مقياس تلقائي للأجهزة الافتراضية، أجهزة افتراضية متوازنة التحميل، VMSS مقابل VM، والقياس، والقياس الأفقي، والتنسيق المرن.
