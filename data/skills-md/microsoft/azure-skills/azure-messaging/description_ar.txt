استكشاف الأخطاء وإصلاحها وحل المشكلات باستخدام Azure Messaging SDK لمراكز الأحداث وحافلة الخدمة. يغطي حالات فشل الاتصال، وأخطاء المصادقة، ومشكلات معالجة الرسائل، ومشكلات تكوين SDK. متى: خطأ SDK لمركز الأحداث، مشكلة SDK لحافلة الخدمة، فشل اتصال الرسائل، خطأ AMQP، مشكلة مضيف معالج الأحداث، فقدان قفل الرسائل، مهلة الإرسال، قطع اتصال جهاز الاستقبال، استكشاف أخطاء SDK وإصلاحها، SDK للمراسلة اللازوردية، مستهلك مركز الأحداث، مشكلة قائمة انتظار ناقل الخدمة، خطأ في اشتراك الموضوع، تمكين مركز أحداث التسجيل، تسجيل ناقل الخدمة، إيفينثوب بيثون، سيرفيسبوس جافا، إيفينثوب جافا سكريبت، سيرفيسبوس دوت نت، نقطة تفتيش مركز الأحداث، مركز الأحداث لا يتلقى الرسائل، رسالة ميتة لحافلة الخدمة.
