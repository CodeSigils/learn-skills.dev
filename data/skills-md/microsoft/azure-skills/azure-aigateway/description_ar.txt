قم بتكوين Azure API Management كبوابة AI لنماذج الذكاء الاصطناعي وأدوات MCP والوكلاء. متى: التخزين المؤقت الدلالي، حد الرمز المميز، أمان المحتوى، موازنة التحميل، حوكمة نموذج الذكاء الاصطناعي، تحديد معدل MCP، اكتشاف كسر الحماية، إضافة واجهة Azure OpenAI الخلفية، إضافة نموذج AI Foundry، اختبار بوابة الذكاء الاصطناعي، سياسات LLM، تكوين الواجهة الخلفية للذكاء الاصطناعي، ومقاييس الرمز المميز، والتحكم في تكلفة الذكاء الاصطناعي، وتحويل واجهة برمجة التطبيقات إلى MCP، واستيراد OpenAPI إلى البوابة.
