Aide les utilisateurs à trouver le bon rôle Azure RBAC pour une identité avec le moins d’accès privilégié, puis à générer des commandes CLI et du code Bicep pour l’attribuer. Fournit également des conseils sur les autorisations requises pour accorder des rôles. QUAND : quel rôle dois-je attribuer, rôle de moindre privilège, rôle RBAC, rôle pour lire les blobs, rôle pour l'identité gérée, définition de rôle personnalisé, attribuer un rôle à l'identité, quel rôle dois-je accorder l'accès, autorisations pour attribuer des rôles.
