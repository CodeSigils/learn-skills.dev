Этот навык извлекает и отображает рабочие элементы, назначенные пользователю в Azure DevOps, упорядоченные по типу и отсортированные по недавно измененным. Он запрашивает имя проекта или перечисляет доступные проекты, если они не указаны, затем извлекает сведения о рабочем элементе и отображает их в отформатированной таблице с интерактивными ссылками.
