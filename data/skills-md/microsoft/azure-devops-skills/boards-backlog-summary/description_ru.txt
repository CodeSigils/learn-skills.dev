Получите невыполненную работу на уровне требований команды (элементы и ошибки невыполненной работы по продукту), отфильтрованную по активным элементам, назначенным текущему пользователю. Показывает иерархию родительских/дочерних элементов и сортировку по приоритету. Используйте этот навык, когда пользователь хочет увидеть свои элементы невыполненной работы, задания спринта или собственную работу на доске команды.
