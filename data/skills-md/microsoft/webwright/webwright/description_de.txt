Lösen Sie eine vom Benutzer festgelegte Webaufgabe im Code-as-Action-Stil, indem Sie einen lokalen Playwright-Browser durch jeweils einen Bash-Befehl steuern, Screenshots und ein Aktionsprotokoll in „final_runs/run_<id>/“ speichern und das Ergebnis visuell überprüfen. Verwenden Sie diese Option, wenn der Benutzer eine Webaufgabe (Suche, Filter, Formularausfüllung, mehrstufiger Ablauf, Datenextraktion) automatisieren möchte und wiederverwendbare Skripte sowie Screenshot-Beweise anstelle einer einmaligen Antwort wünscht.
