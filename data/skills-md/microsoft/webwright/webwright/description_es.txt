Resuelva un estilo de código como acción de tarea web especificado por el usuario ejecutando un navegador Playwright local a través de un comando bash a la vez, guardando capturas de pantalla y un registro de acciones en `final_runs/run_<id>/` y verificando visualmente el resultado. Úselo cuando el usuario solicita automatizar una tarea web (búsqueda, filtro, llenado de formularios, flujo de varios pasos, extracción de datos) y desea scripts reutilizables más evidencia de captura de pantalla en lugar de una respuesta única.
