Bonnes pratiques pour les agents Copilot Studio. Couvre le chargement du glossaire JIT (acronymes clients, terminologie), l'approvisionnement du contexte utilisateur JIT (profil M365, pays, département), le modèle d'initialisation OnActivity partagé, les redirections de sujets dynamiques avec les expressions Switch et l'empêchement des agents enfants de répondre directement aux utilisateurs. UTILISER POUR : glossaire, acronymes, contexte utilisateur, profil utilisateur, réponses adaptées au pays, initialisation JIT, approvisionnement OnActivity, conversation-init, connaissances personnalisées, redirection dynamique, Switch, BeginDialog, remplacement if/then/else, réponses d'agent enfant, paramètre d'achèvement, SendMessageTool, variables de sortie, agents connectés. NE PAS UTILISER POUR : les sources de connaissances générales (utiliser add-knowledge), la création de sujets (utiliser new-topic).
