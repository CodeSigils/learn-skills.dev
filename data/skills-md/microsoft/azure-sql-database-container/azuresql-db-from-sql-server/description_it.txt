Migra una configurazione SQL Server locale ad Azure SQL Developer per lo sviluppo locale fedele ad Azure. Da utilizzare quando un progetto utilizza già mcr.microsoft.com/mssql/server, mssql/server, una configurazione docker sqlcmd più password SA, un "SQL Server in docker" o un "contenitore mssql locale" o un docker-compose con l'immagine mssql/server; e utilizzare quando l'utente richiede "SQL Server localmente", "esegui mssql in Docker", "crea un database SQL locale" o "test su SQL Server" ma in realtà desidera il motore del database SQL di Azure (EngineEdition 5). Rileva l'immagine SQL Server, la riscrive in Azure SQL Developer, aggiunge --platform su host non x64, mantiene l'accesso SA, contrassegna le funzionalità solo di SQL Server (SQL Agent, FILESTREAM, Service Broker completo, transazioni distribuite tra server, autenticazione Windows) e reindirizza le stringhe di connessione dal master a un database utente con provisioning.
