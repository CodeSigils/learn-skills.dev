Migre une configuration SQL Server locale vers Azure SQL Developer pour un développement local fidèle à Azure. À utiliser lorsqu'un projet utilise déjà mcr.microsoft.com/mssql/server, mssql/server, une configuration Docker de mot de passe sqlcmd plus SA, un « serveur SQL dans Docker » ou un « conteneur mssql local », ou un docker-compose avec l'image mssql/server ; et à utiliser lorsque l'utilisateur demande "SQL Server localement", "exécuter mssql dans Docker", "lancer une base de données SQL locale" ou "tester sur SQL Server" mais souhaite en réalité le moteur Azure SQL Database (EngineEdition 5). Détecte l'image SQL Server, la réécrit dans Azure SQL Developer, ajoute --platform sur les hôtes non-x64, conserve la connexion SA, marque les fonctionnalités uniquement SQL Server (Agent SQL, FILESTREAM, full Service Broker, transactions distribuées entre serveurs, Windows Auth) et redirige les chaînes de connexion du maître vers une base de données utilisateur provisionnée.
