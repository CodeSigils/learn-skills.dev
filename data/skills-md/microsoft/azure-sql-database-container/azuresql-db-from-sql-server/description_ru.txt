Переносит локальную установку SQL Server в Azure SQL Developer для локальной разработки с учетом требований Azure. Используйте, если проект уже использует mcr.microsoft.com/mssql/server, mssql/server, настройку докера sqlcmd плюс SA с паролем, «SQL Server в докере» или «локальный контейнер mssql» или сборку docker с образом mssql/server; и используйте, когда пользователь запрашивает «SQL Server локально», «запустить mssql в Docker», «развернуть локальную базу данных SQL» или «протестировать SQL Server», но на самом деле ему нужен механизм базы данных SQL Azure (EngineEdition 5). Обнаруживает образ SQL Server, перезаписывает его в Azure SQL Developer, добавляет --platform на хостах, отличных от x64, сохраняет вход SA, помечает функции, доступные только для SQL Server (агент SQL, FILESTREAM, полноценный брокер служб, межсерверные распределенные транзакции, проверка подлинности Windows), и перенаправляет строки подключения от мастера к подготовленной пользовательской базе данных.
