Migra una configuración de SQL Server local a Azure SQL Developer para un desarrollo local fiel a Azure. Úselo cuando un proyecto ya use mcr.microsoft.com/mssql/server, mssql/server, una configuración de Docker con contraseña sqlcmd plus SA, un "SQL Server en Docker" o un "contenedor mssql local", o un Docker-compose con la imagen mssql/server; y utilícelo cuando el usuario solicita "SQL Server localmente", "ejecutar mssql en Docker", "activar una base de datos SQL local" o "probar con SQL Server" pero en realidad quiere el motor de base de datos Azure SQL (EngineEdition 5). Detecta la imagen de SQL Server, la reescribe en Azure SQL Developer, agrega --platform en hosts que no son x64, mantiene el inicio de sesión de SA, marca características exclusivas de SQL Server (Agente SQL, FILESTREAM, Service Broker completo, transacciones distribuidas entre servidores, autenticación de Windows) y vuelve a señalar cadenas de conexión desde la base de datos maestra a una base de datos de usuario aprovisionada.
