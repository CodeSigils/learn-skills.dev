Azure에 충실한 로컬 개발을 위해 로컬 SQL Server 설정을 Azure SQL Developer로 마이그레이션합니다. 프로젝트에서 이미 mcr.microsoft.com/mssql/server, mssql/server, sqlcmd 및 SA 암호 docker 설정, "docker의 SQL Server" 또는 "로컬 mssql 컨테이너" 또는 mssql/server 이미지가 포함된 docker-compose를 사용하는 경우에 사용합니다. 사용자가 "로컬로 SQL Server", "Docker에서 mssql 실행", "로컬 SQL 데이터베이스 가동" 또는 "SQL Server에 대해 테스트"를 요청하지만 실제로는 Azure SQL 데이터베이스 엔진(EngineEdition 5)을 원할 때 사용합니다. SQL Server 이미지를 감지하여 Azure SQL Developer에 다시 작성하고, x64가 아닌 호스트에 --platform을 추가하고, SA 로그인을 유지하고, SQL Server 전용 기능(SQL 에이전트, FILESTREAM, 전체 서비스 브로커, 서버 간 분산 트랜잭션, Windows 인증)에 플래그를 지정하고, 연결 문자열을 마스터에서 프로비전된 사용자 데이터베이스로 다시 지정합니다.
