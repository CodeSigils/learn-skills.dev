ترحيل إعداد SQL Server محلي إلى Azure SQL Developer للتطوير المحلي المتوافق مع Azure. يُستخدم عندما يستخدم المشروع بالفعل mcr.microsoft.com/mssql/server، أو mssql/server، أو إعداد عامل إرساء كلمة مرور sqlcmd بالإضافة إلى SA، أو "SQL Server في عامل الإرساء" أو "حاوية mssql محلية"، أو إنشاء عامل إرساء باستخدام صورة mssql/server؛ واستخدامها عندما يطلب المستخدم "SQL Server محليًا" أو "تشغيل mssql في Docker" أو "تدوير قاعدة بيانات SQL محلية" أو "اختبار مقابل SQL Server" ولكنه يريد في الواقع محرك قاعدة بيانات Azure SQL (EngineEdition 5). يكتشف صورة SQL Server، ويعيد كتابتها إلى Azure SQL Developer، ويضيف --platform على مضيفين غير x64، ويحتفظ بتسجيل دخول SA، ويضع علامات على ميزات SQL Server فقط (SQL Agent، وFILESTREAM، ووسيط الخدمة الكامل، والمعاملات الموزعة عبر الخادم، وWindows Auth)، ويعيد نقاط سلاسل الاتصال من قاعدة بيانات المستخدم الرئيسية إلى قاعدة بيانات المستخدم المتوفرة.
