Azure に忠実なローカル開発のために、ローカル SQL Server セットアップを Azure SQL Developer に移行します。プロジェクトがすでに mcr.microsoft.com/mssql/server、mssql/server、sqlcmd と SA パスワードの Docker セットアップ、「docker 内の SQL Server」または「ローカル mssql コンテナー」、または mssql/server イメージを使用した docker-compose を使用している場合に使用します。ユーザーが "SQL Server をローカルで"、"Docker で mssql を実行"、"ローカル SQL データベースをスピンアップ"、または "SQL Server に対してテスト" を要求したが、実際には Azure SQL Database エンジン (EngineEdition 5) が必要な場合に使用します。 SQL Server イメージを検出し、それを Azure SQL Developer に書き換え、x64 以外のホストに --platform を追加し、SA ログインを保持し、SQL Server のみの機能 (SQL エージェント、FILESTREAM、フル サービス ブローカー、クロスサーバー分散トランザクション、Windows Auth) にフラグを立て、接続文字列をマスターからプロビジョニングされたユーザー データベースに再ポイントします。
