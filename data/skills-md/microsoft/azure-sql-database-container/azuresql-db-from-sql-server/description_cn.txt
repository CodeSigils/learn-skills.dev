将本地 SQL Server 设置迁移到 Azure SQL Developer，以实现忠实于 Azure 的本地开发。当项目已使用 mcr.microsoft.com/mssql/server、mssql/server、sqlcmd 加 SA 密码 docker 设置、“docker 中的 SQL Server”或“本地 mssql 容器”或带有 mssql/server 映像的 docker-compose 时使用；当用户请求“本地 SQL Server”、“在 Docker 中运行 mssql”、“启动本地 SQL 数据库”或“针对 SQL Server 进行测试”但实际上需要 Azure SQL 数据库引擎 (EngineEdition 5) 时使用。检测 SQL Server 映像，将其重写到 Azure SQL Developer，在非 x64 主机上添加 --platform，保留 SA 登录，标记仅限 SQL Server 的功能（SQL 代理、FILESTREAM、完整 Service Broker、跨服务器分布式事务、Windows Auth），并将连接字符串从主数据库重新指向预配的用户数据库。
