Migriert ein lokales SQL Server-Setup zu Azure SQL Developer für eine Azure-treue lokale Entwicklung. Verwenden Sie diese Option, wenn ein Projekt bereits mcr.microsoft.com/mssql/server, mssql/server, ein sqlcmd plus SA-Passwort-Docker-Setup, einen „SQL Server im Docker“ oder „lokalen MSSQL-Container“ oder ein Docker-Compose mit dem MSSQL/Server-Image verwendet; und verwenden, wenn der Benutzer nach „SQL Server lokal“, „mssql in Docker ausführen“, „eine lokale SQL-Datenbank starten“ oder „gegen SQL Server testen“ fragt, aber tatsächlich die Azure SQL-Datenbank-Engine (EngineEdition 5) möchte. Erkennt das SQL Server-Image, schreibt es in Azure SQL Developer um, fügt --platform auf Nicht-x64-Hosts hinzu, behält die SA-Anmeldung bei, kennzeichnet nur SQL Server-Funktionen (SQL Agent, FILESTREAM, Full Service Broker, serverübergreifende verteilte Transaktionen, Windows Auth) und leitet Verbindungszeichenfolgen vom Master auf eine bereitgestellte Benutzerdatenbank um.
