在容器中本機執行 Azure SQL Developer（Azure SQL 資料庫引擎）（私人預覽版）：真正的 PaaS 引擎，其中 SERVERPROPERTY('EngineEdition') 傳回 5，版本為「SQL Azure」。這不是 SQL Server 映像 mcr.microsoft.com/mssql/server。當使用者想要「本機執行 Azure SQL」、「新增本機 SQL 資料庫」、「將 SQL Server 新增至我的 docker compose」、「啟動本機 mssql 容器」、「用於開發或 CI 的本機 SQL」、「使用 sqlcmd 連線」、「使用 Podman 進行 SQL」、「SQL 容器無法啟動」或詢問「連線字串是什麼」時。即使使用者沒有命名容器也可以使用。如果您打算使用 mcr.microsoft.com/mssql/server，請停止並使用此技能。中心技能：擁有撰寫、CI、播種、向量和連接字串的任務技能的共享引用和路由。
