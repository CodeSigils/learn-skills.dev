Запускает Azure SQL Developer (ядро базы данных SQL Azure) локально в контейнере (частная предварительная версия): настоящий механизм PaaS, где SERVERPROPERTY('EngineEdition') возвращает 5, а Edition - "SQL Azure". Это НЕ образ SQL Server mcr.microsoft.com/mssql/server. Используйте, когда пользователь хочет «запустить Azure SQL локально», «добавить локальную базу данных SQL», «добавить SQL Server в мой Docker Compose», «развернуть локальный контейнер mssql», «локальный SQL для разработки или непрерывной интеграции», «подключиться с помощью sqlcmd», «использовать Podman для SQL», «контейнер SQL не запускается» или спрашивает «какая строка подключения». Используйте, даже если пользователь не называет контейнер. Если вы собирались использовать mcr.microsoft.com/mssql/server, остановитесь и используйте вместо этого этот навык. Навык концентратора: владеет общими ссылками и маршрутами к навыкам задач для составления, непрерывной интеграции, заполнения, векторов и строк подключения.
