يقوم بتشغيل Azure SQL Developer (محرك قاعدة بيانات Azure SQL) محليًا في حاوية (معاينة خاصة): محرك PaaS الحقيقي حيث يُرجع SERVERPROPERTY('EngineEdition') 5 والإصدار هو 'SQL Azure'. هذه ليست صورة SQL Server mcr.microsoft.com/mssql/server. يُستخدم عندما يريد المستخدم "تشغيل Azure SQL محليًا"، أو "إضافة قاعدة بيانات SQL محلية"، أو "إضافة SQL Server إلى إنشاء عامل الإرساء الخاص بي"، أو "تدوير حاوية mssql محلية"، أو "SQL محلي للتطوير أو CI"، أو "الاتصال بـ sqlcmd"، أو "استخدام Podman for SQL"، أو "لن تبدأ حاوية SQL"، أو يسأل "ما هي سلسلة الاتصال". يُستخدم حتى عندما لا يقوم المستخدم بتسمية الحاوية. إذا كنت على وشك استخدام mcr.microsoft.com/mssql/server، فتوقف واستخدم هذه المهارة بدلاً من ذلك. المهارة المحورية: تمتلك المراجع المشتركة والمسارات إلى مهارات المهمة الخاصة بالإنشاء وCI والبذر والمتجهات وسلاسل الاتصال.
