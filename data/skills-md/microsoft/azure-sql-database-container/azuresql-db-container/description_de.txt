Führt Azure SQL Developer (die Azure SQL-Datenbank-Engine) lokal in einem Container aus (private Vorschau): die echte PaaS-Engine, bei der SERVERPROPERTY('EngineEdition') 5 zurückgibt und die Edition „SQL Azure“ ist. Dies ist NICHT das SQL Server-Image mcr.microsoft.com/mssql/server. Verwenden Sie diese Option, wenn ein Benutzer „Azure SQL lokal ausführen“, „eine lokale SQL-Datenbank hinzufügen“, „SQL Server zu meinem Docker Compose hinzufügen“, „einen lokalen MSSQL-Container hochfahren“, „lokales SQL für Entwicklung oder CI“, „mit sqlcmd verbinden“, „Podman für SQL verwenden“ möchte, „SQL-Container startet nicht“ oder fragt „Wie lautet die Verbindungszeichenfolge“. Wird auch dann verwendet, wenn der Benutzer den Container nicht benennt. Wenn Sie mcr.microsoft.com/mssql/server verwenden wollten, hören Sie auf und verwenden Sie stattdessen diesen Skill.
