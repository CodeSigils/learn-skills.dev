Esegue Azure SQL Developer (il motore del database SQL di Azure) localmente in un contenitore (anteprima privata): il vero motore PaaS in cui SERVERPROPERTY('EngineEdition') restituisce 5 e Edition è "SQL Azure". Questa NON è l'immagine di SQL Server mcr.microsoft.com/mssql/server. Da utilizzare quando un utente desidera "eseguire SQL di Azure localmente", "aggiungere un database SQL locale", "aggiungere SQL Server alla mia finestra mobile di composizione", "avviare un contenitore mssql locale", "SQL locale per sviluppo o CI", "connettersi con sqlcmd", "utilizzare Podman per SQL", "il contenitore SQL non si avvia" o chiede "qual è la stringa di connessione". Utilizzare anche quando l'utente non assegna un nome al contenitore. Se stavi per utilizzare mcr.microsoft.com/mssql/server, interrompi e utilizza invece questa competenza. Competenza hub: possiede i riferimenti e i percorsi condivisi alle competenze dell'attività per composizione, CI, seeding, vettori e stringhe di connessione.
