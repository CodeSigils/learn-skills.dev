Exécute Azure SQL Developer (le moteur Azure SQL Database) localement dans un conteneur (préversion privée) : le véritable moteur PaaS où SERVERPROPERTY('EngineEdition') renvoie 5 et Edition est 'SQL Azure'. Ce n'est PAS l'image SQL Server mcr.microsoft.com/mssql/server. À utiliser lorsqu'un utilisateur souhaite « exécuter Azure SQL localement », « ajouter une base de données SQL locale », « ajouter SQL Server à mon Docker Compose », « faire tourner un conteneur mssql local », « SQL local pour le développement ou CI », « se connecter avec sqlcmd », « utiliser Podman pour SQL », « le conteneur SQL ne démarre pas » ou demande « quelle est la chaîne de connexion ». À utiliser même lorsque l'utilisateur ne nomme pas le conteneur. Si vous étiez sur le point d'utiliser mcr.microsoft.com/mssql/server, arrêtez-vous et utilisez plutôt cette compétence. Compétence Hub : possède les références partagées et les itinéraires vers les compétences de tâche pour la composition, le CI, l'amorçage, les vecteurs et les chaînes de connexion.
