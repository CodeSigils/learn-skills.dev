Azure SQL Developer (Azure SQL Database エンジン) をコンテナー内でローカルに実行します (プライベート プレビュー)。これは、SERVERPROPERTY('EngineEdition') が 5 を返し、エディションが 'SQL Azure' である実際の PaaS エンジンです。これは SQL Server イメージ mcr.microsoft.com/mssql/server ではありません。ユーザーが「Azure SQL をローカルで実行する」、「ローカル SQL データベースを追加する」、「Docker Compose に SQL Server を追加する」、「ローカル mssql コンテナーをスピンアップする」、「開発または CI 用にローカル SQL」、「sqlcmd で接続する」、「SQL に Podman を使用する」、「SQL コンテナーが起動しない」、または「接続文字列は何ですか」を尋ねる場合に使用します。ユーザーがコンテナーに名前を付けない場合でも使用します。 mcr.microsoft.com/mssql/server を使用しようとしていた場合は、停止して代わりにこのスキルを使用してください。ハブ スキル: 共有参照を所有し、構成、CI、シード、ベクター、接続文字列のタスク スキルへのルートを保持します。
