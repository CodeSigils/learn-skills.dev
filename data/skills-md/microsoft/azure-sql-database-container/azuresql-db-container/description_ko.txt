Azure SQL Developer(Azure SQL 데이터베이스 엔진)를 컨테이너(개인 미리 보기)에서 로컬로 실행합니다. SERVERPROPERTY('EngineEdition')가 5를 반환하고 Edition이 'SQL Azure'인 실제 PaaS 엔진입니다. 이는 SQL Server 이미지 mcr.microsoft.com/mssql/server가 아닙니다. 사용자가 "Azure SQL을 로컬로 실행", "로컬 SQL 데이터베이스 추가", "Docker Compose에 SQL Server 추가", "로컬 mssql 컨테이너 가동", "개발 또는 CI용 로컬 SQL", "sqlcmd와 연결", "SQL용 Podman 사용", "SQL 컨테이너가 시작되지 않음"을 원하거나 "연결 문자열이 무엇인지" 묻는 경우에 사용합니다. 사용자가 컨테이너 이름을 지정하지 않은 경우에도 사용합니다. mcr.microsoft.com/mssql/server를 사용하려고 했다면 중지하고 대신 이 스킬을 사용하세요. 허브 기술: 작성, CI, 시드, 벡터 및 연결 문자열에 대한 작업 기술에 대한 공유 참조 및 경로를 소유합니다.
