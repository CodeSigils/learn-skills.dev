AS NVARCHAR(MAX)) AS VECTOR(n)) 插入嵌入，其中维度是文字、可插入的 embed()，因此只有云的端点发生变化，以及 CREATE VECTOR INDEX 的诚实当前状态。首先在 master 上配置 appdb，以便每个脚本都在新容器上运行。
