Crea ricerca vettoriale locale, RAG, incorporamenti e ricerca semantica in Azure SQL Developer usando il tipo VECTOR nativo e VECTOR_DISTANCE. Utilizzare quando è necessario archiviare incorporamenti, eseguire ricerche per similarità, vicino più vicino top-k, distanza coseno, generazione aumentata con recupero, "trovare documenti simili", memoria chatbot o ricerca semantica su un database SQL locale. Usarlo invece di pgvector, FAISS, Chroma, Pinecone o un archivio vettoriale separato quando i dati sono già presenti (o possono essere presenti) in Azure SQL. Copre il tipo di colonna VECTOR(n), inserendo incorporamenti con CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) dove la dimensione è letterale, un embed() collegabile in modo che cambi solo l'endpoint per il cloud e lo stato attuale onesto di CREATE VECTOR INDEX. Effettua prima il provisioning di appdb sul master in modo che ogni script venga eseguito su un nuovo contenitore.
