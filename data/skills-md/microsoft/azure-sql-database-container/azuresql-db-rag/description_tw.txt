使用本機 VECTOR 類型和 VECTOR_DISTANCE 在 Azure SQL Developer 上建立本地向量搜尋、RAG、嵌入和語義搜尋。當您需要儲存嵌入、進行相似性搜尋、top-k 最近鄰、餘弦距離、檢索增強生成、「尋找類似文件」、聊天機器人記憶體或針對本機 SQL 資料庫進行語義查找時使用。當資料已存在於（或可存在於）Azure SQL 中時，請使用此儲存而不是 pgvector、FAISS、Chroma、Pinecone 或單獨的向量儲存。涵蓋 VECTOR(n) 列類型，使用 CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) 插入嵌入，其中維度是文字、可插入的 embed()，因此只有雲的端點發生變化，以及 CREATE VECTOR INDEX 的當前誠實狀態。首先在 master 上配置 appdb，以便每個腳本都在新容器上執行。
