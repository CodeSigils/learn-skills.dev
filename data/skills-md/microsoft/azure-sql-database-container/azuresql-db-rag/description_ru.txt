Создает локальный векторный поиск, RAG, внедрения и семантический поиск в Azure SQL Developer, используя собственный тип VECTOR и VECTOR_DISTANCE. Используйте, когда вам нужно сохранить вложения, выполнить поиск по сходству, топ-k ближайших соседей, косинусное расстояние, генерацию с расширенным поиском, «найти похожие документы», память чат-бота или семантический поиск в локальной базе данных SQL. Используйте это вместо pgvector, FAISS, Chroma, Pinecone или отдельного векторного хранилища, если данные уже находятся (или могут находиться) в Azure SQL. Охватывает тип столбца VECTOR(n), вставляя внедрения с помощью CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)), где измерение является литералом, подключаемым элементом embed(), поэтому для облака изменяется только конечная точка и честное текущее состояние CREATE VECTOR INDEX. Сначала подготавливает базу данных appdb на главном сервере, чтобы каждый скрипт запускался в новом контейнере.
