기본 VECTOR 유형 및 VECTOR_DISTANCE를 사용하여 Azure SQL Developer에서 로컬 벡터 검색, RAG, 임베딩 및 의미 체계 검색을 빌드합니다. 임베딩 저장, 유사성 검색, 최근접 이웃 상위 k, 코사인 거리, 검색 증강 생성, "유사한 문서 찾기", 챗봇 메모리 또는 로컬 SQL 데이터베이스에 대한 의미 체계 조회를 수행해야 할 때 사용합니다. 데이터가 이미 Azure SQL에 있거나 있을 수 있는 경우 pgVector, FAISS, Chroma, Pinecone 또는 별도의 벡터 저장소 대신 이를 사용하세요. AS NVARCHAR(MAX)) AS VECTOR(n)) 차원이 리터럴인 임베딩을 삽입하여 VECTOR(n) 열 유형을 다루고 클라우드에 대한 끝점만 변경되도록 하는 플러그형 embed() 및 CREATE VECTOR INDEX의 정직한 현재 상태를 포함합니다. 모든 스크립트가 새로운 컨테이너에서 실행되도록 먼저 마스터에서 appdb를 프로비저닝합니다.
