ينشئ بحثًا متجهًا محليًا وRAG والتضمينات والبحث الدلالي على Azure SQL Developer باستخدام نوع VECTOR الأصلي وVECTOR_DISTANCE. استخدمه عندما تحتاج إلى تخزين التضمينات، أو إجراء بحث عن التشابه، أو أقرب جار، أو مسافة جيب التمام، أو إنشاء الاسترجاع المعزز، أو "البحث عن مستندات مماثلة"، أو ذاكرة chatbot، أو البحث الدلالي في قاعدة بيانات SQL محلية. استخدم هذا بدلاً من pgvector أو FAISS أو Chroma أو Pinecone أو مخزن متجه منفصل عندما تكون البيانات موجودة بالفعل في (أو يمكن أن توجد في) Azure SQL. يغطي نوع العمود VECTOR(n)، وإدراج التضمينات باستخدام CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) حيث يكون البعد حرفيًا، وهو تضمين قابل للتوصيل () لذلك تتغير نقطة النهاية فقط للسحابة، والحالة الحالية الصادقة لـ CREATE VECTOR INDEX. قم بتوفير تطبيق appdb على الملف الرئيسي أولاً حتى يتم تشغيل كل برنامج نصي على حاوية جديدة.
