Crée une recherche vectorielle locale, RAG, des intégrations et une recherche sémantique sur Azure SQL Developer à l'aide du type VECTOR natif et de VECTOR_DISTANCE. À utiliser lorsque vous avez besoin de stocker des intégrations, d'effectuer une recherche de similarité, le voisin le plus proche top-k, la distance cosinus, la génération augmentée par récupération, la « recherche de documents similaires », la mémoire du chatbot ou la recherche sémantique dans une base de données SQL locale. Utilisez-le à la place de pgvector, FAISS, Chroma, Pinecone ou d'un magasin de vecteurs distinct lorsque les données résident déjà (ou peuvent résider dans) Azure SQL. Couvre le type de colonne VECTOR(n), en insérant des intégrations avec CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) où la dimension est un littéral, un embed() enfichable afin que seul le point de terminaison change pour le cloud et l'état actuel honnête de CREATE VECTOR INDEX. Provisionne d'abord appdb sur master afin que chaque script s'exécute sur un nouveau conteneur.
