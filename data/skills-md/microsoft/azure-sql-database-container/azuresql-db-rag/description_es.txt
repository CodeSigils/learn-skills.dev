Crea búsqueda vectorial local, RAG, incrustaciones y búsqueda semántica en Azure SQL Developer utilizando el tipo VECTOR nativo y VECTOR_DISTANCE. Úselo cuando necesite almacenar incrustaciones, realizar búsquedas de similitud, top-k de vecinos más cercanos, distancia de coseno, generación de recuperación aumentada, "encontrar documentos similares", memoria de chatbot o búsqueda semántica en una base de datos SQL local. Utilice esto en lugar de pgvector, FAISS, Chroma, Pinecone o un almacén de vectores independiente cuando los datos ya residan (o puedan residir) en Azure SQL. Cubre el tipo de columna VECTOR(n), insertando incrustaciones con CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) donde la dimensión es literal, un embed() conectable de modo que solo el punto final cambia para la nube y el estado actual honesto de CREATE VECTOR INDEX. Aprovisiona appdb en master primero para que cada script se ejecute en un contenedor nuevo.
