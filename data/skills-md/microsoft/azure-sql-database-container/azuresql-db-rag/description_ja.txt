ネイティブ VECTOR 型と VECTOR_DISTANCE を使用して、Azure SQL Developer 上でローカル ベクター検索、RAG、埋め込み、セマンティック検索を構築します。エンベディングの保存、類似性検索、上位 K 最近傍法、コサイン距離、検索拡張生成、「類似ドキュメントの検索」、チャットボット メモリ、またはローカル SQL データベースに対するセマンティック ルックアップが必要な場合に使用します。データが既に Azure SQL に存在する (または存在できる) 場合は、pgvector、FAISS、Chroma、Pinecone、または別のベクター ストアの代わりにこれを使用します。 VECTOR(n) 列タイプをカバーし、ディメンションがリテラルである CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) による埋め込みの挿入、クラウドのエンドポイントのみが変更されるようにプラガブルな embed()、および CREATE VECTOR INDEX の正直な現在の状態をカバーします。最初にマスター上に appdb をプロビジョニングし、すべてのスクリプトが新しいコンテナー上で実行されるようにします。
