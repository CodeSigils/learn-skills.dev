Erstellt lokale Vektorsuche, RAG, Einbettungen und semantische Suche in Azure SQL Developer unter Verwendung des nativen VECTOR-Typs und VECTOR_DISTANCE. Verwenden Sie diese Funktion, wenn Sie Einbettungen speichern, eine Ähnlichkeitssuche, Top-K-Nächste-Nachbarn, Kosinus-Distanz, abrufgestützte Generierung, „Ähnliche Dokumente finden“, Chatbot-Speicher oder eine semantische Suche in einer lokalen SQL-Datenbank durchführen müssen. Verwenden Sie dies anstelle von pgvector, FAISS, Chroma, Pinecone oder einem separaten Vektorspeicher, wenn die Daten bereits in Azure SQL gespeichert sind (oder gespeichert werden können). Deckt den Spaltentyp VECTOR(n) ab und fügt Einbettungen mit CAST(CAST(? AS NVARCHAR(MAX)) AS VECTOR(n)) ein, wobei die Dimension ein Literal ist, ein steckbares embed(), sodass sich nur der Endpunkt für die Cloud ändert, und der ehrliche aktuelle Status von CREATE VECTOR INDEX. Stellt appdb zuerst auf dem Master bereit, sodass jedes Skript auf einem neuen Container ausgeführt wird.
