ローカルの Azure SQL Developer に対してデータベース スキーマの移行を実行するため、同じ移行がローカル エンジンと Azure クラウドに同様に適用されます。 「ローカル SQL に対して移行を実行する」、「スキーマをコンテナーに適用する」、「EF Core / dotnet ef データベース更新を適用する」、「Prisma 移行開発 / デプロイ」、「Alembic アップグレード ヘッド」、または DACPAC / SqlPackage をコンテナーにデプロイするように求められた場合に使用します。最初にマスター上での appdb のプロビジョニング、次にユーザー データベースへのスキーマの適用、さらにツールごとのコマンドと接続文字列の健全性について説明します。これは Azure SQL Database エンジン (EngineEdition 5) であり、SQL Server イメージではありません。スキーマ移行ツールがローカル コンテナーをターゲットとする場合は常に、このスキルを使用してください。
