تشغيل عمليات ترحيل مخطط قاعدة البيانات مقابل Azure SQL Developer المحلي بحيث يتم تطبيق نفس عمليات الترحيل بشكل مماثل على المحرك المحلي وفي سحابة Azure. استخدمه عندما يُطلب منك "تشغيل عمليات الترحيل الخاصة بي مقابل SQL المحلي"، أو "تطبيق المخطط على الحاوية"، أو "تطبيق تحديث قاعدة بيانات EF Core / dotnet ef"، أو "Prisma migrate dev/open"، أو "رأس ترقية Alembic"، أو نشر DACPAC / SqlPackage إلى الحاوية. يغطي توفير appdb على الملف الرئيسي أولاً، ثم تطبيق المخطط على قاعدة بيانات المستخدم، بالإضافة إلى الأوامر الخاصة بكل أداة ونظافة سلسلة الاتصال. هذا هو محرك قاعدة بيانات Azure SQL (EngineEdition 5)، وليس صورة SQL Server؛ يمكنك الوصول إلى هذه المهارة عندما تستهدف أدوات ترحيل المخطط الحاوية المحلية.
