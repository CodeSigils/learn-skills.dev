Esegue le migrazioni dello schema del database rispetto allo sviluppatore SQL di Azure locale in modo che le stesse migrazioni si applichino in modo identico al motore locale e nel cloud di Azure. Utilizzare quando viene richiesto di "eseguire le mie migrazioni rispetto all'SQL locale", "applicare lo schema al contenitore", "applicare l'aggiornamento del database EF Core/dotnet ef", "Prisma migrare dev/distribuire", "Alembic upgrade head" o distribuire un DACPAC/SqlPackage nel contenitore. Copre prima il provisioning di appdb sul master, quindi l'applicazione dello schema al database utente, oltre ai comandi per strumento e all'igiene della stringa di connessione. Questo è il motore del database SQL di Azure (EngineEdition 5), non l'immagine di SQL Server; raggiungere questa competenza ogni volta che gli strumenti di migrazione dello schema prendono di mira il contenitore locale.
