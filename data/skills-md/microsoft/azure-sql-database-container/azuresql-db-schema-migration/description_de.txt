Führt Datenbankschemamigrationen für den lokalen Azure SQL Developer aus, sodass dieselben Migrationen auf der lokalen Engine und in der Azure-Cloud identisch angewendet werden. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „meine Migrationen mit dem lokalen SQL auszuführen“, „Schema auf den Container anzuwenden“, „EF Core/dotnet ef-Datenbankaktualisierung anzuwenden“, „Prisma migrieren dev/deployen“, „Alembic upgrade head“ oder ein DACPAC/SqlPackage im Container bereitzustellen. Behandelt zunächst die Bereitstellung der Appdb auf dem Master, dann die Anwendung des Schemas auf die Benutzerdatenbank sowie die Befehle pro Tool und die Hygiene von Verbindungszeichenfolgen. Dies ist die Azure SQL-Datenbank-Engine (EngineEdition 5), nicht das SQL Server-Image. Greifen Sie auf diese Fähigkeit zurück, wenn Schemamigrationstools auf den lokalen Container abzielen.
