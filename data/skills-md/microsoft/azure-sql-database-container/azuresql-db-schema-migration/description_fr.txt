Exécute les migrations de schéma de base de données sur le développeur Azure SQL local afin que les mêmes migrations s'appliquent de manière identique sur le moteur local et dans le cloud Azure. À utiliser lorsqu'il est demandé d'« exécuter mes migrations sur le SQL local », « d'appliquer le schéma au conteneur », « d'appliquer la mise à jour de la base de données EF Core/dotnet ef », « Prisma migre dev/déployer », « tête de mise à niveau Alembic » ou de déployer un DACPAC/SqlPackage sur le conteneur. Couvre d'abord le provisionnement de l'appdb sur le maître, puis l'application du schéma à la base de données utilisateur, ainsi que les commandes par outil et l'hygiène des chaînes de connexion. Il s'agit du moteur Azure SQL Database (EngineEdition 5), et non de l'image SQL Server ; utilisez cette compétence chaque fois que les outils de migration de schéma ciblent le conteneur local.
