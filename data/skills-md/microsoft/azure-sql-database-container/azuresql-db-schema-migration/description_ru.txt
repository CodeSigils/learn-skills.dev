Выполняет миграцию схемы базы данных с помощью локального разработчика SQL Azure, поэтому одни и те же миграции применяются одинаково в локальном ядре и в облаке Azure. Используйте, когда вас просят «запустить мою миграцию против локального SQL», «применить схему к контейнеру», «применить обновление базы данных EF Core/dotnet ef», «Prismamigration dev/deploy», «Голова обновления Alembic» или развернуть DACPAC/SqlPackage в контейнере. Охватывает сначала подготовку базы данных appdb на главном сервере, затем применение схемы к пользовательской базе данных, а также команды для каждого инструмента и гигиену строки подключения. Это ядро ​​базы данных SQL Azure (EngineEdition 5), а не образ SQL Server; Используйте этот навык всякий раз, когда инструменты миграции схемы нацелены на локальный контейнер.
