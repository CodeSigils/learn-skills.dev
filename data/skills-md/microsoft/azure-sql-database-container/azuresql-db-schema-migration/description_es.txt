Ejecuta migraciones de esquemas de bases de datos en el desarrollador local de Azure SQL para que las mismas migraciones se apliquen de manera idéntica en el motor local y en la nube de Azure. Úselo cuando se le solicite "ejecutar mis migraciones contra el SQL local", "aplicar el esquema al contenedor", "aplicar la actualización de la base de datos EF Core/dotnet ef", "Prisma migrar desarrollo/implementar", "cabezal de actualización de Alembic" o implementar un DACPAC/SqlPackage en el contenedor. Cubre primero el aprovisionamiento de appdb en el maestro y luego la aplicación del esquema a la base de datos del usuario, además de comandos por herramienta e higiene de la cadena de conexión. Este es el motor de Azure SQL Database (EngineEdition 5), no la imagen de SQL Server; Utilice esta habilidad siempre que las herramientas de migración de esquemas apunten al contenedor local.
