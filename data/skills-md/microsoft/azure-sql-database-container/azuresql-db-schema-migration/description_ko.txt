로컬 Azure SQL Developer에 대해 데이터베이스 스키마 마이그레이션을 실행하므로 동일한 마이그레이션이 로컬 엔진과 Azure 클라우드에 동일하게 적용됩니다. "로컬 SQL에 대해 마이그레이션 실행", "컨테이너에 스키마 적용", "EF Core/dotnet ef 데이터베이스 업데이트 적용", "Prisma 마이그레이션 개발/배포", "Alembic 업그레이드 헤드" 또는 DACPAC/SqlPackage를 컨테이너에 배포하라는 메시지가 표시될 때 사용합니다. 먼저 마스터에서 appdb를 프로비저닝한 다음 사용자 데이터베이스에 스키마를 적용하고 도구별 명령 및 연결 문자열 위생을 다룹니다. 이는 SQL Server 이미지가 아닌 Azure SQL 데이터베이스 엔진(EngineEdition 5)입니다. 스키마 마이그레이션 도구가 로컬 컨테이너를 대상으로 할 때마다 이 기술에 도달하세요.
