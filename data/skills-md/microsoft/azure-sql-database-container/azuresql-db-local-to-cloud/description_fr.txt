Prouve que le code créé et testé sur le conteneur Azure SQL Database local s’exécute sans changement sur Azure SQL Database dans le cloud, seule la chaîne de connexion étant modifiée. À utiliser lorsqu'un utilisateur souhaite développer localement puis déployer sur le cloud, demande « cela fonctionnera-t-il dans Azure », « même code local et cloud », « promouvoir vers Azure SQL », « échanger la chaîne de connexion », « parité développement/production », « local vers le cloud » ou câbler SQL_CONNECTION_STRING pour une application qui doit cibler à la fois le conteneur et un serveur cloud. Utilisez-le lorsqu'une application utilise l'authentification SA locale mais a besoin de l'authentification Microsoft Entra dans le cloud. Couvre Node (mssql), .NET (Microsoft.Data.SqlClient) et Python (pyodbc). Atteignez cette compétence avant de modifier manuellement le code de l'application pour « le faire fonctionner dans Azure » ; la règle est que le code ne change pas, seule la chaîne de connexion change.
