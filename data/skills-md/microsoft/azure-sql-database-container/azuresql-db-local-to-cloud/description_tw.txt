證明針對本機 Azure SQL 資料庫容器建置和測試的程式碼在雲端中的 Azure SQL 資料庫中執行時沒有變化，僅連接字串發生了變化。當使用者想要在本地開發然後部署到雲端時使用，詢問“這是否可以在 Azure 中工作”、“本地和雲端相同的程式碼”、“升級到 Azure SQL”、“交換連接字串”、“開發/產品奇偶校驗”、“本地到雲端”，或者為必須同時面向容器和雲端伺服器的應用程式連接 SQL_CONNECTION_STRING。當應用程式使用本機 SA 驗證但需要雲端中的 Microsoft Entra 驗證時，請使用此選項。涵蓋 Node (mssql)、.NET (Microsoft.Data.SqlClient) 和 Python (pyodbc)。在手動編輯應用程式程式碼以「使其在 Azure 中運行」之前，請先掌握此技能；規則是程式碼不會改變，只有連接字串改變。
