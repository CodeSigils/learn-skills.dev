يثبت أن التعليمات البرمجية التي تم إنشاؤها واختبارها مقابل حاوية قاعدة بيانات Azure SQL المحلية تعمل دون تغيير مقابل قاعدة بيانات Azure SQL في السحابة، مع تغيير سلسلة الاتصال فقط. يُستخدم عندما يريد المستخدم التطوير محليًا ثم النشر على السحابة، ويسأل "هل سيعمل هذا في Azure"، أو "نفس الكود المحلي والسحابي"، أو "الترقية إلى Azure SQL"، أو "تبديل سلسلة الاتصال"، أو "تكافؤ التطوير/المنتج"، أو "محلي إلى السحابة"، أو توصيل SQL_CONNECTION_STRING لتطبيق يجب أن يستهدف كلاً من الحاوية وخادم السحابة. استخدم هذا عندما يستخدم أحد التطبيقات مصادقة ضمان البرنامج المحلية ولكنه يحتاج إلى مصادقة Microsoft Entra في السحابة. يغطي العقدة (mssql)، و.NET (Microsoft.Data.SqlClient)، وPython (pyodbc). يمكنك الوصول إلى هذه المهارة قبل التحرير اليدوي لرمز التطبيق "لجعله يعمل في Azure"؛ القاعدة هي أن الكود لا يتغير، فقط سلسلة الاتصال هي التي تتغير.
