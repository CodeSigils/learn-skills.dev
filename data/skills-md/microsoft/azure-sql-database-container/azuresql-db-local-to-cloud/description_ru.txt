Доказывает, что код, созданный и протестированный с использованием локального контейнера базы данных SQL Azure, работает без изменений с базой данных SQL Azure в облаке, меняется только строка подключения. Используйте его, когда пользователь хочет разработать локально, а затем развернуть его в облаке, спрашивает «будет ли это работать в Azure», «один и тот же код локально и в облаке», «перейти в Azure SQL», «поменять строку подключения», «паритет разработки и производства», «локально в облаке» или подключает SQL_CONNECTION_STRING для приложения, которое должно быть нацелено как на контейнер, так и на облачный сервер. Используйте это, если приложение использует локальную аутентификацию SA, но требует аутентификации Microsoft Entra в облаке. Охватывает Node (mssql), .NET (Microsoft.Data.SqlClient) и Python (pyodbc). Овладейте этим навыком, прежде чем вручную редактировать код приложения, чтобы «заставить его работать в Azure»; правило заключается в том, что код не меняется, меняется только строка подключения.
