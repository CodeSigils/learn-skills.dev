Dimostra che il codice creato e testato rispetto al contenitore del database SQL di Azure locale viene eseguito invariato rispetto al database SQL di Azure nel cloud, con la sola modifica della stringa di connessione. Da utilizzare quando un utente vuole sviluppare localmente e poi distribuire nel cloud, chiede "funzionerà in Azure", "stesso codice locale e cloud", "promuovere in SQL di Azure", "scambiare la stringa di connessione", "parità sviluppatore/prodotto", "da locale al cloud" o sta collegando SQL_CONNECTION_STRING per un'app che deve avere come destinazione sia il contenitore che un server cloud. Utilizzalo quando un'app usa l'autenticazione SA locale ma necessita dell'autenticazione Microsoft Entra nel cloud. Copre Node (mssql), .NET (Microsoft.Data.SqlClient) e Python (pyodbc). Ottieni questa competenza prima di modificare manualmente il codice dell'app per "farlo funzionare in Azure"; la regola è che il codice non cambia, cambia solo la stringa di connessione.
