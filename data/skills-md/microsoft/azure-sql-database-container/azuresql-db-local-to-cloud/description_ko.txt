로컬 Azure SQL Database 컨테이너에 대해 구축되고 테스트된 코드가 연결 문자열만 변경되어 클라우드의 Azure SQL Database에 대해 변경되지 않고 실행된다는 것을 증명합니다. 사용자가 로컬에서 개발한 후 클라우드에 배포하려는 경우, "Azure에서 작동할지", "동일한 코드 로컬 및 클라우드", "Azure SQL로 승격", "연결 문자열 교체", "dev/prod 패리티", "로컬에서 클라우드로"를 묻거나, 컨테이너와 클라우드 서버를 모두 대상으로 해야 하는 앱에 대해 SQL_CONNECTION_STRING을 연결할 때 사용합니다. 앱이 로컬 SA 인증을 사용하지만 클라우드에서 Microsoft Entra 인증이 필요한 경우 이 방법을 사용하세요. Node(mssql), .NET(Microsoft.Data.SqlClient) 및 Python(pyodbc)을 다룹니다. "Azure에서 작동하도록" 앱 코드를 직접 편집하기 전에 이 기술을 익히십시오. 규칙은 코드가 변경되지 않고 연결 문자열만 변경된다는 것입니다.
