ローカルの Azure SQL Database コンテナーに対してビルドおよびテストされたコードが、接続文字列のみを変更して、クラウド内の Azure SQL Database に対して変更せずに実行されることを証明します。ユーザーがローカルで開発してからクラウドにデプロイする場合、「これは Azure で機能するか」、「ローカルとクラウドで同じコード」、「Azure SQL に昇格する」、「接続文字列を交換する」、「開発/製品パリティ」、「ローカルからクラウドに」を尋ねる場合、またはコンテナーとクラウド サーバーの両方をターゲットにする必要があるアプリに SQL_CONNECTION_STRING を接続する場合に使用します。アプリがローカル SA 認証を使用しているが、クラウドで Microsoft Entra 認証が必要な場合は、これを使用します。ノード (mssql)、.NET (Microsoft.Data.SqlClient)、および Python (pyodbc) をカバーします。アプリのコードを手動で編集して「Azure で動作させる」前に、このスキルを身につけてください。ルールは、コードは変更されず、接続文字列のみが変更されるということです。
