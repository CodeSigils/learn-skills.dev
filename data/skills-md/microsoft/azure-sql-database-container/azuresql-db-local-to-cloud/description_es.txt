Demuestra que el código creado y probado en el contenedor local de Azure SQL Database se ejecuta sin cambios en Azure SQL Database en la nube, y solo cambia la cadena de conexión. Úselo cuando un usuario quiera desarrollar localmente y luego implementarlo en la nube, pregunte "¿funcionará esto en Azure", "mismo código local y en la nube", "promocionar a Azure SQL", "intercambiar la cadena de conexión", "paridad de desarrollo/producción", "local a la nube" o está conectando SQL_CONNECTION_STRING para una aplicación que debe apuntar tanto al contenedor como a un servidor en la nube. Utilícelo cuando una aplicación utilice autenticación SA local pero necesite autenticación Microsoft Entra en la nube. Cubre Node (mssql), .NET (Microsoft.Data.SqlClient) y Python (pyodbc). Obtenga esta habilidad antes de editar manualmente el código de la aplicación para "hacer que funcione en Azure"; la regla es que el código no cambia, solo la cadena de conexión.
