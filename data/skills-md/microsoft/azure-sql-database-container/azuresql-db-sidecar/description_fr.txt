Ajoute Azure SQL Developer en tant que service side-car dans une pile Docker Compose ou un conteneur de développement existant. À utiliser lors du câblage du moteur de base de données Azure SQL local dans composer ou devcontainer.json, lorsqu'une application a besoin d'un backend SQL via un nom de service (et non localhost), ou pour des invites telles que « ajouter SQL à ma composition », « ajouter un service de base de données », « dépend de la base de données », « side-car SQL devcontainer », « composer un bilan de santé pour SQL », « attendre la base de données avant de démarrer l'application ». Gère la plate-forme Linux/amd64, la connexion au registre privé, le contrôle de santé en attente de préparation et un service d'initialisation unique qui crée appdb (le moteur ne crée pas automatiquement de bases de données). Pas l'image SQL Server. Préférez ceci pour tout câblage SQL de composition ou de conteneur de développement.
