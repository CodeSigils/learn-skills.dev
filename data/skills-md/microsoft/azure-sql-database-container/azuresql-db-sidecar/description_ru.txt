Добавляет Azure SQL Developer в качестве дополнительной службы в существующий стек Docker Compose или контейнер разработки. Используйте при подключении локального ядра базы данных SQL Azure к Compose или devcontainer.json, когда приложению требуется серверная часть SQL через имя службы (не localhost) или для таких запросов, как «добавить SQL в мою композицию», «добавить службу базы данных», «база данных зависит от базы данных», «devcontainer SQL Sidecar», «составить проверку работоспособности для SQL», «дождитесь базы данных перед запуском приложения». Управляет платформой linux/amd64, входом в частный реестр, ожиданием готовности к проверке работоспособности и однократной службой инициализации, которая создает базу данных appdb (движок не создает базы данных автоматически). Не образ SQL Server. Предпочитайте это для любого подключения SQL-контейнера Compose или Dev.
