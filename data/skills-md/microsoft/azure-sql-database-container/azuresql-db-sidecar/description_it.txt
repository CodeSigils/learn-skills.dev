Aggiunge Azure SQL Developer come servizio collaterale in uno stack Docker Compose o un contenitore di sviluppo esistente. Da utilizzare quando si collega il motore del database SQL di Azure locale a compose o devcontainer.json, quando un'app necessita di un back-end SQL tramite un nome di servizio (non localhost) o per richieste come "aggiungi SQL al mio compose", "aggiungi un servizio di database", "depends_on database", "devcontainer SQL sidecar", "compose Healthcheck per SQL", "attendi il database prima di avviare l'app". Gestisce la piattaforma linux/amd64, l'accesso al registro privato, il controllo dello stato wait-until-ready e un servizio init one-shot che crea appdb (il motore non crea automaticamente i database). Non l'immagine di SQL Server. Preferisci questo per qualsiasi cablaggio SQL di composizione o Dev Container.
