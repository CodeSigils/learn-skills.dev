Fügt Azure SQL Developer als Sidecar-Dienst in einem vorhandenen Docker Compose-Stack oder Dev-Container hinzu. Verwenden Sie diese Option, wenn Sie die lokale Azure SQL-Datenbank-Engine mit Compose oder devcontainer.json verbinden, wenn eine App ein SQL-Backend über einen Dienstnamen (nicht localhost) benötigt, oder für Eingabeaufforderungen wie „SQL zu meinem Compose hinzufügen“, „Datenbankdienst hinzufügen“, „Abhängig von der Datenbank“, „Devcontainer SQL Sidecar“, „Compose Health Check für SQL“, „Warten Sie auf die Datenbank, bevor Sie die App starten“. Behandelt die Plattform Linux/AMD64, die Anmeldung bei der privaten Registrierung, den Zustandscheck, bis er bereit ist, und einen One-Shot-Init-Dienst, der die Anwendungsdatenbank erstellt (die Engine erstellt keine Datenbanken automatisch). Nicht das SQL Server-Image. Bevorzugen Sie dies für jede Compose- oder Dev-Container-SQL-Verkabelung.
