将 Azure SQL Developer 添加为现有 Docker Compose 堆栈或开发容器中的边车服务。当将本地 Azure SQL 数据库引擎连接到 compose 或 devcontainer.json 时，当应用程序需要通过服务名称（不是 localhost）的 SQL 后端时，或者出现诸如“将 SQL 添加到我的 compose”、“添加数据库服务”、“depends_on 数据库”、“devcontainer SQL sidecar”、“为 SQL 编写健康检查”、“启动应用程序之前等待数据库”等提示时，请使用。处理平台 linux/amd64、私有注册表登录、运行状况检查等待就绪以及创建 appdb 的一次性 init 服务（引擎不会自动创建数据库）。不是 SQL Server 映像。对于任何 compose 或 Dev Container SQL 连接，首选此方法。
