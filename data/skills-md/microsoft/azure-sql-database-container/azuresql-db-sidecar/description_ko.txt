기존 Docker Compose 스택 또는 Dev 컨테이너에 사이드카 서비스로 Azure SQL Developer를 추가합니다. 로컬 Azure SQL 데이터베이스 엔진을 Compose 또는 devcontainer.json에 연결할 때, 앱에 서비스 이름(localhost가 아님)을 통해 SQL 백엔드가 필요한 경우 또는 "내 작성에 SQL 추가", "데이터베이스 서비스 추가", "종속_on 데이터베이스", "devcontainer SQL 사이드카", "SQL에 대한 상태 확인 작성", "앱을 시작하기 전에 데이터베이스 대기"와 같은 프롬프트에 사용합니다. 플랫폼 linux/amd64, 개인 레지스트리 로그인, 상태 확인 대기, appdb를 생성하는 일회성 초기화 서비스(엔진은 데이터베이스를 자동 생성하지 않음)를 처리합니다. SQL Server 이미지가 아닙니다. Compose 또는 Dev Container SQL 배선에는 이 방법을 선호합니다.
