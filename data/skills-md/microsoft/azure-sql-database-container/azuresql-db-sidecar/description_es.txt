Agrega Azure SQL Developer como servicio complementario en una pila de Docker Compose o un contenedor de desarrollo existente. Úselo cuando conecte el motor local de Azure SQL Database a compose o devcontainer.json, cuando una aplicación necesite un backend SQL a través de un nombre de servicio (no localhost), o para mensajes como "agregar SQL a mi redacción", "agregar un servicio de base de datos", "depende_de la base de datos", "devcontainer SQL sidecar", "compose healthcheck for SQL", "esperar la base de datos antes de iniciar la aplicación". Maneja la plataforma Linux/AMD64, el inicio de sesión de registro privado, la verificación de estado de espera hasta que esté listo y un servicio de inicio único que crea appdb (el motor no crea bases de datos automáticamente). No la imagen de SQL Server. Prefiera esto para cualquier cableado SQL de redacción o contenedor de desarrollo.
