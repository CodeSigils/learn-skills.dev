يضيف Azure SQL Developer كخدمة جانبية في مكدس Docker Compose أو حاوية Dev الموجودة. استخدمه عند توصيل محرك قاعدة بيانات Azure SQL المحلي بالإنشاء أو devcontainer.json، عندما يحتاج التطبيق إلى واجهة SQL خلفية عبر اسم خدمة (وليس مضيف محلي)، أو للمطالبات مثل "إضافة SQL إلى الإنشاء الخاص بي"، "إضافة خدمة قاعدة بيانات"، "قاعدة بيانات تعتمد على"، "devcontainer SQL Sidecar"، "إنشاء فحص صحي لـ SQL"، "انتظر قاعدة البيانات قبل بدء تشغيل التطبيق". يتعامل مع النظام الأساسي linux/amd64، وتسجيل الدخول إلى السجل الخاص، والفحص الصحي، والانتظار حتى الاستعداد، وخدمة init لمرة واحدة التي تنشئ appdb (لا يقوم المحرك بإنشاء قواعد بيانات تلقائيًا). ليست صورة SQL Server. تفضل هذا لأي توصيلات SQL للإنشاء أو Dev Container.
