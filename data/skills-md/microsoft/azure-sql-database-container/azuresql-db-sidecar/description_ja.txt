Azure SQL Developer を既存の Docker Compose スタックまたは開発コンテナーにサイドカー サービスとして追加します。ローカルの Azure SQL Database エンジンを compose または devcontainer.json に接続する場合、アプリがサービス名 (localhost ではない) を介して SQL バックエンドを必要とする場合、または「compose に SQL を追加」、「データベース サービスを追加」、「depends_on データベース」、「devcontainer SQL サイドカー」、「SQL のヘルスチェックを作成」、「アプリを開始する前にデータベースを待機する」などのプロンプトに使用します。プラットフォーム linux/amd64、プライベート レジストリ ログイン、ヘルスチェック wait-until-ready、および appdb を作成するワンショット init サービスを処理します (エンジンはデータベースを自動作成しません)。 SQL Server イメージではありません。作成または開発コンテナの SQL 接続にはこれを優先します。
