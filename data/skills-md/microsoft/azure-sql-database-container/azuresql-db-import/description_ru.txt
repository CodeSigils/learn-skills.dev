Импортирует существующую базу данных SQL Azure или схему и данные SQL Server В локальный Azure SQL Developer с помощью SqlPackage. Используйте, когда вас просят «импортировать bacpac», «локально загрузить мою существующую базу данных», «восстановить dacpac в контейнер», «перенести мою схему продукта в контейнер разработки», «запустить мой .bacpac/.dacpac для локального механизма SQL Azure» или перенести существующую базу данных в контейнер предварительной версии. Сначала обрабатывает подготовку целевой базы данных на главном сервере, а затем запускает SqlPackage/Action:Import для подготовленной пользовательской базы данных. Используйте это для любого запроса «запустить мою реальную базу данных в контейнере» вместо написания вручную флагов SqlPackage.
