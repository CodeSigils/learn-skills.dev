Importa uno schema e i dati di un database SQL di Azure o di SQL Server esistente nello sviluppatore SQL di Azure locale utilizzando SqlPackage. Utilizzare quando viene richiesto di "importare un bacpac", "caricare il mio database esistente localmente", "ripristinare un dacpac nel contenitore", "portare il mio schema di produzione nel contenitore di sviluppo", "eseguire il mio .bacpac/.dacpac sul motore SQL di Azure locale" o migrare un database esistente nel contenitore di anteprima. Gestisce prima il provisioning del database di destinazione nel master, quindi esegue SqlPackage /Action:Import sul database utente con provisioning. Usalo per qualsiasi richiesta "ottieni il mio database reale in esecuzione nel contenitore" invece di scrivere manualmente i flag SqlPackage.
