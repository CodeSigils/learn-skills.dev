Importa un esquema y datos existentes de Azure SQL Database o SQL Server AL desarrollador local de Azure SQL mediante SqlPackage. Úselo cuando se le solicite "importar un bacpac", "cargar mi base de datos existente localmente", "restaurar un dacpac en el contenedor", "traer mi esquema de producción al contenedor de desarrollo", "ejecutar mi .bacpac/.dacpac en el motor Azure SQL local" o migrar una base de datos existente al contenedor de vista previa. Primero maneja el aprovisionamiento de la base de datos de destino en el maestro y luego ejecuta SqlPackage /Action:Import en la base de datos del usuario aprovisionada. Utilice esto para cualquier solicitud de "ejecutar mi base de datos real en el contenedor" en lugar de escribir a mano indicadores SqlPackage.
