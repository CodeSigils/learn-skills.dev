استيراد قاعدة بيانات Azure SQL موجودة أو مخطط SQL Server وبيانات إلى مطور Azure SQL المحلي باستخدام SqlPackage. يُستخدم عندما يُطلب منك "استيراد bacpac"، أو "تحميل قاعدة البيانات الحالية محليًا"، أو "استعادة dacpac إلى الحاوية"، أو "إحضار مخطط المنتج الخاص بي إلى حاوية التطوير"، أو "تشغيل .bacpac/.dacpac مقابل محرك Azure SQL المحلي"، أو ترحيل قاعدة بيانات موجودة إلى حاوية المعاينة. يعالج توفير قاعدة البيانات الهدف على المستوى الرئيسي أولاً، ثم تشغيل SqlPackage /Action:Import على قاعدة بيانات المستخدم المتوفرة. استخدم هذا لأي طلب "تشغيل قاعدة البيانات الحقيقية الخاصة بي في الحاوية" بدلاً من كتابة إشارات SqlPackage يدويًا.
