Importe un schéma et des données Azure SQL Database ou SQL Server existants DANS le développeur Azure SQL local à l’aide de SqlPackage. À utiliser lorsqu'on vous demande de « importer un bacpac », « charger ma base de données existante localement », « restaurer un dacpac dans le conteneur », « amener mon schéma de production dans le conteneur de développement », « exécuter mon .bacpac/.dacpac sur le moteur Azure SQL local » ou migrer une base de données existante dans le conteneur de prévisualisation. Gère d'abord le provisionnement de la base de données cible sur le maître, puis l'exécution de SqlPackage /Action:Import sur la base de données utilisateur provisionnée. Utilisez-le pour toute requête « faire fonctionner ma vraie base de données dans le conteneur » au lieu d'écrire manuellement des indicateurs SqlPackage.
