SqlPackage を使用して、既存の Azure SQL Database または SQL Server のスキーマとデータをローカルの Azure SQL Developer にインポートします。 「bacpac をインポートする」、「既存のデータベースをローカルにロードする」、「dacpac をコンテナーに復元する」、「prod スキーマを開発コンテナーに取り込む」、「ローカルの Azure SQL エンジンに対して .bacpac/.dacpac を実行する」、または既存のデータベースをプレビュー コンテナーに移行するように求められた場合に使用します。最初にマスター上のターゲット データベースのプロビジョニングを処理し、次にプロビジョニングされたユーザー データベースに対して SqlPackage /Action:Import を実行します。 「コンテナー内で実行されている実際のデータベースを取得する」リクエストには、SqlPackage フラグを手書きする代わりにこれを使用します。
