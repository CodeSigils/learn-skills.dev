Importiert ein vorhandenes Azure SQL-Datenbank- oder SQL Server-Schema und Daten mithilfe von SqlPackage IN den lokalen Azure SQL Developer. Wird verwendet, wenn Sie aufgefordert werden, „einen Bacpac zu importieren“, „meine vorhandene Datenbank lokal zu laden“, „einen DACPAC im Container wiederherzustellen“, „mein Produktschema in den Entwicklungscontainer zu bringen“, „mein .bacpac/.Dacpac mit der lokalen Azure SQL-Engine auszuführen“ oder eine vorhandene Datenbank in den Vorschaucontainer zu migrieren. Behandelt zuerst die Bereitstellung der Zieldatenbank auf dem Master und führt dann SqlPackage /Action:Import für die bereitgestellte Benutzerdatenbank aus. Verwenden Sie dies für jede Anforderung zum Ausführen meiner echten Datenbank im Container, anstatt SqlPackage-Flags handschriftlich zu schreiben.
