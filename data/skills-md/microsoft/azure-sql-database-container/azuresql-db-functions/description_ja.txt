Azure SQL バインディングを持つ Azure Functions を使用して、ローカルの Azure SQL Developer 上にサーバーレス API とイベント ドリブン ハンドラーを構築します。ユーザーが「SQL を介したサーバーレス API」、「データベースを使用した Azure Functions」、「SQL 入出力バインディングを使用した HTTP CRUD」、「行変更時のコードの実行」、「挿入/更新/削除への反応」、「Azure SQL でのイベント駆動型」、または「SQL トリガー関数」を必要とする場合に使用します。 Azure SQL トリガー バインディング (変更追跡によってサポートされる) は、ローカルのイベント駆動型メカニズムです。 Change Event Streaming (CES) はクラウド専用であり、ローカル コンテナーに対して実行できません。トリガーには、「SQL で開始する関数」、「SqlTrigger」、「SqlInput/SqlOutput バインディング」、「local.settings.json SqlConnectionString」が含まれます。ローカルの Azure SQL エンジンでサーバーレス エンドポイントまたは変更主導のロジックを構築する場合は、これを利用してください。
