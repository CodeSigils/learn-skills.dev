Создает бессерверный API и обработчики, управляемые событиями, на базе локального Azure SQL Developer, используя функции Azure с привязками Azure SQL. Используйте, когда пользователю нужен «бессерверный API через SQL», «Функции Azure с базой данных», «HTTP CRUD с привязками ввода-вывода SQL», «запускать код при изменении строки», «реагировать на вставки/обновления/удаления», «управляемые событиями в Azure SQL» или «триггерную функцию SQL». Привязка триггера SQL Azure (поддерживаемая отслеживанием изменений) — это локальный механизм, управляемый событиями; Потоковая передача событий изменений (CES) доступна только в облаке и не может работать в локальном контейнере. Триггеры включают «запуск функции с SQL», «SqlTrigger», «привязку SqlInput/SqlOutput», «local.settings.json SqlConnectionString». Используйте это при создании бессерверных конечных точек или логики, управляемой изменениями, в локальном механизме SQL Azure.
