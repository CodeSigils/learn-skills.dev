使用 Azure Functions 和 Azure SQL 绑定在本地 Azure SQL Developer 上构建无服务器 API 和事件驱动的处理程序。当用户需要“基于 SQL 的无服务器 API”、“带有数据库的 Azure Functions”、“带有 SQL 输入/输出绑定的 HTTP CRUD”、“行更改时运行代码”、“对插入/更新/删除做出反应”、“Azure SQL 上的事件驱动”或“SQL 触发器函数”时使用。 Azure SQL 触发器绑定（由更改跟踪支持）是本地事件驱动机制；更改事件流 (CES) 仅适用于云，无法针对本地容器运行。触发器包括“func start with SQL”、“SqlTrigger”、“SqlInput/SqlOutput 绑定”、“local.settings.json SqlConnectionString”。在本地 Azure SQL 引擎上构建无服务器端点或更改驱动的逻辑时，请实现这一点。
