Azure SQL 바인딩과 함께 Azure Functions를 사용하여 로컬 Azure SQL 개발자를 통해 서버리스 API 및 이벤트 기반 처리기를 빌드합니다. 사용자가 "SQL을 통한 서버리스 API", "데이터베이스가 포함된 Azure 함수", "SQL 입력/출력 바인딩이 포함된 HTTP CRUD", "행 변경 시 코드 실행", "삽입/업데이트/삭제에 반응", "Azure SQL의 이벤트 기반" 또는 "SQL 트리거 함수"를 원할 때 사용합니다. 변경 내용 추적을 통해 지원되는 Azure SQL 트리거 바인딩은 로컬 이벤트 기반 메커니즘입니다. CES(Change Event Streaming)는 클라우드 전용이며 로컬 컨테이너에 대해 실행할 수 없습니다. 트리거에는 "SQL로 기능 시작", "SqlTrigger", "SqlInput/SqlOutput 바인딩", "local.settings.json SqlConnectionString"이 포함됩니다. 로컬 Azure SQL 엔진에서 서버리스 엔드포인트 또는 변경 기반 논리를 구축할 때 이를 활용하세요.
