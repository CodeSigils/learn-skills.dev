Crée une API sans serveur et des gestionnaires basés sur les événements sur le développeur Azure SQL local à l'aide d'Azure Functions avec les liaisons Azure SQL. À utiliser lorsqu'un utilisateur souhaite « une API sans serveur sur SQL », « Azure Functions avec une base de données », « HTTP CRUD avec liaisons d'entrée/sortie SQL », « exécuter du code lorsqu'une ligne change », « réagir aux insertions/mises à jour/suppressions », « piloté par des événements sur Azure SQL » ou « fonction de déclenchement SQL ». La liaison de déclencheur Azure SQL (soutenue par Change Tracking) est le mécanisme local piloté par les événements ; Change Event Streaming (CES) est uniquement cloud et ne peut pas être exécuté sur le conteneur local. Les déclencheurs incluent « func start with SQL », « SqlTrigger », « liaison SqlInput/SqlOutput », « local.settings.json SqlConnectionString ». Atteignez-le lors de la création de points de terminaison sans serveur ou d’une logique basée sur les changements sur le moteur Azure SQL local.
