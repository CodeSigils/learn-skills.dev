Crea un'API serverless e gestori guidati da eventi sullo sviluppatore SQL di Azure locale usando Funzioni di Azure con le associazioni SQL di Azure. Utilizzare quando un utente desidera "un'API serverless su SQL", "Funzioni di Azure con un database", "HTTP CRUD con associazioni di input/output SQL", "eseguire codice quando una riga cambia", "reagire a inserimenti/aggiornamenti/eliminazioni", "basato su eventi su Azure SQL" o "funzione trigger SQL". L'associazione del trigger SQL di Azure (supportata dal rilevamento delle modifiche) è il meccanismo locale basato su eventi; Change Event Streaming (CES) è solo cloud e non può essere eseguito sul contenitore locale. I trigger includono "funzione avvio con SQL", "SqlTrigger", "associazione SqlInput/SqlOutput", "local.settings.json SqlConnectionString". Raggiungi questo obiettivo quando crei endpoint serverless o logica basata sulle modifiche sul motore SQL di Azure locale.
