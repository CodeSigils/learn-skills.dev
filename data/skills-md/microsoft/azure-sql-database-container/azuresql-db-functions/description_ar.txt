إنشاء واجهة برمجة تطبيقات بدون خادم ومعالجات تعتمد على الأحداث عبر مطور Azure SQL المحلي باستخدام وظائف Azure مع روابط Azure SQL. يُستخدم عندما يريد المستخدم "واجهة برمجة تطبيقات بدون خادم عبر SQL"، أو "وظائف Azure مع قاعدة بيانات"، أو "HTTP CRUD مع روابط إدخال/إخراج SQL"، أو "تشغيل التعليمات البرمجية عندما يتغير صف"، أو "التفاعل مع الإدراج/التحديثات/الحذف"، أو "المعتمد على الحدث على Azure SQL"، أو "وظيفة تشغيل SQL". إن ربط مشغل Azure SQL (المدعوم بتتبع التغيير) هو الآلية المحلية المستندة إلى الحدث؛ يعد تغيير تدفق الأحداث (CES) متاحًا على السحابة فقط ولا يمكن تشغيله على الحاوية المحلية. تتضمن المشغلات "func start with SQL"، و"SqlTrigger"، و"ربط SqlInput/SqlOutput"، و"local.settings.json SqlConnectionString". يمكنك الوصول إلى ذلك عند إنشاء نقاط نهاية بدون خادم أو منطق يحركه التغيير على محرك Azure SQL المحلي.
