使用 Azure Functions 和 Azure SQL 綁定在本機 Azure SQL Developer 上建置無伺服器 API 和事件驅動的處理程序。當使用者需要「基於 SQL 的無伺服器 API」、「帶有資料庫的 Azure Functions」、「帶有 SQL 輸入/輸出綁定的 HTTP CRUD」、「行更改時執行程式碼」、「對插入/更新/刪除做出反應」、「Azure SQL 上的事件驅動」或「SQL 觸發器函數」時使用。 Azure SQL 觸發器綁定（由變更追蹤支援）是本機事件驅動機制；變更事件流 (CES) 僅適用於雲，無法針對本機容器執行。觸發器包括「func start with SQL」、「SqlTrigger」、「SqlInput/SqlOutput 結合」、「local.settings.json SqlConnectionString」。在本機 Azure SQL 引擎上建立無伺服器端點或變更驅動的邏輯時，請實現這一點。
