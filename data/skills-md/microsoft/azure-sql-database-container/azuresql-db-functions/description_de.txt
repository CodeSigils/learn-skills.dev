Erstellt eine serverlose API und ereignisgesteuerte Handler über den lokalen Azure SQL Developer unter Verwendung von Azure Functions mit den Azure SQL-Bindungen. Verwenden Sie diese Option, wenn ein Benutzer „eine serverlose API über SQL“, „Azure Functions mit einer Datenbank“, „HTTP CRUD mit SQL-Eingabe-/Ausgabebindungen“, „Code ausführen, wenn sich eine Zeile ändert“, „auf Einfügungen/Aktualisierungen/Löschungen reagieren“, „ereignisgesteuert in Azure SQL“ oder „SQL-Triggerfunktion“ wünscht. Die Azure SQL-Triggerbindung (unterstützt durch Änderungsverfolgung) ist der lokale ereignisgesteuerte Mechanismus. Change Event Streaming (CES) ist nur in der Cloud verfügbar und kann nicht für den lokalen Container ausgeführt werden. Zu den Auslösern gehören „func start with SQL“, „SqlTrigger“, „SqlInput/SqlOutput binding“ und „local.settings.json SqlConnectionString“. Nutzen Sie dies, wenn Sie serverlose Endpunkte oder änderungsgesteuerte Logik auf der lokalen Azure SQL-Engine erstellen.
