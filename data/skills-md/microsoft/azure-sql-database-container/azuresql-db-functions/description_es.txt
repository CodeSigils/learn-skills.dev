Crea una API sin servidor y controladores controlados por eventos a través del desarrollador de Azure SQL local mediante Azure Functions con los enlaces de Azure SQL. Úselo cuando un usuario desee "una API sin servidor sobre SQL", "Azure Functions con una base de datos", "HTTP CRUD con enlaces de entrada/salida de SQL", "ejecutar código cuando cambia una fila", "reaccionar a inserciones/actualizaciones/eliminaciones", "basado en eventos en Azure SQL" o "función de activación de SQL". El enlace del desencadenador de Azure SQL (respaldado por Change Tracking) es el mecanismo local controlado por eventos; Change Event Streaming (CES) es solo en la nube y no puede ejecutarse en el contenedor local. Los activadores incluyen "inicio de función con SQL", "SqlTrigger", "enlace SqlInput/SqlOutput", "local.settings.json SqlConnectionString". Utilice esto al crear puntos finales sin servidor o lógica basada en cambios en el motor Azure SQL local.
