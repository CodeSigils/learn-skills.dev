Supporta una NUOVA app (.NET Aspire, FastAPI, Next.js, NestJS) collegata allo sviluppatore SQL di Azure locale come database di sviluppo predefinito. Da utilizzare quando si avvia/avvia/inizializza un progetto che richiede SQL Server o SQL di Azure localmente o quando si aggiunge "configura il database", "composizione docker per il database", "crea il DB locale", "stringa di connessione .env", "prima migrazione" o un livello di accesso ai dati. Utilizzare questo INVECE dell'immagine mssql/server SQL Server, perché si tratta del motore SQL di Azure (EngineEdition 5). I trigger includono "app impalcatura con SQL", "avvio locale di Azure SQL", "servizio di composizione per il database", "collegamento di Prisma/EF/SQLAlchemy/TypeORM a SQL Server". Raggiungi questo obiettivo anche quando l'utente dice solo "aggiungi un database" a un nuovo progetto.
