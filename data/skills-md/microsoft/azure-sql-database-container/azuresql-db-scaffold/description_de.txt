Stellt eine NEUE App (.NET Aspire, FastAPI, Next.js, NestJS) bereit, die als Standard-Entwicklungsdatenbank mit dem lokalen Azure SQL Developer verbunden ist. Wird zum Starten/Bootstrapping/Initialisieren eines Projekts verwendet, das SQL Server oder Azure SQL lokal benötigt, oder beim Hinzufügen von „Datenbank einrichten“, „Docker Compose für die Datenbank“, „Lokale Datenbank erstellen“, „.env-Verbindungszeichenfolge“, „erste Migration“ oder einer Datenzugriffsebene. Verwenden Sie dies STATT des SQL Server-Images „mssql/server“, da es sich hierbei um die Azure SQL-Engine (EngineEdition 5) handelt. Zu den Auslösern gehören „Gerüst-App mit SQL“, „Azure SQL lokal hochfahren“, „Dienst für die Datenbank erstellen“ und „Prisma/EF/SQLAlchemy/TypeORM mit SQL Server verbinden“. Greifen Sie dazu zu, auch wenn der Benutzer nur „Datenbank hinzufügen“ zu einem neuen Projekt sagt.
