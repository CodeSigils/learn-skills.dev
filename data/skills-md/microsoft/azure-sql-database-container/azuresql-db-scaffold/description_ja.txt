ローカルの Azure SQL Developer にデフォルトの開発データベースとして接続された新しいアプリ (.NET Aspire、FastAPI、Next.js、NestJS) をスキャフォールディングします。 SQL Server または Azure SQL をローカルで必要とするプロジェクトを開始/ブートストラップ/初期化する場合、または「データベースのセットアップ」、「データベースの docker compose」、「ローカル DB の作成」、「.env 接続文字列」、「最初の移行」、またはデータ アクセス レイヤーを追加する場合に使用します。これは Azure SQL エンジン (EngineEdition 5) であるため、mssql/server SQL Server イメージの INSTEAD を使用します。トリガーには、「SQL を使用したアプリのスキャフォールディング」、「Azure SQL をローカルでスピンアップ」、「データベースのサービスを作成」、「Prisma/EF/SQLAlchemy/TypeORM を SQL Server に接続」などが含まれます。ユーザーが新しいプロジェクトに「データベースを追加する」とだけ言った場合でも、これを実行してください。
