Создает НОВОЕ приложение (.NET Aspire, FastAPI, Next.js, NestJS), подключенное к локальному разработчику SQL Azure в качестве базы данных разработки по умолчанию. Используйте при запуске/загрузке/инициализации проекта, которому требуется SQL Server или Azure SQL локально, или при добавлении «настройка базы данных», «составление Docker для базы данных», «создание локальной базы данных», «строка подключения .env», «первая миграция» или уровень доступа к данным. Используйте это ВМЕСТО образа SQL Server mssql/server, так как это механизм Azure SQL (EngineEdition 5). Триггеры включают в себя «приложение scaffold с SQL», «локальное развертывание Azure SQL», «создание службы для базы данных», «подключение Prisma/EF/SQLAlchemy/TypeORM к SQL Server». Используйте это, даже если пользователь говорит только «добавить базу данных» в новый проект.
