建立一個新應用程式（.NET Aspire、FastAPI、Next.js、NestJS），連接到本機 Azure SQL Developer 作為其預設開發資料庫。在啟動/引導/初始化需要本機 SQL Server 或 Azure SQL 的專案時，或在新增「設定資料庫」、「docker compose for the db」、「建立本機資料庫」、「.env 連線字串」、「第一次遷移」或資料存取層時使用。使用此代替 mssql/server SQL Server 映像，因為這是 Azure SQL 引擎 (EngineEdition 5)。觸發器包括「使用 SQL 的支架應用程式」、「在本機啟動 Azure SQL」、「為資料庫編寫服務」、「將 Prisma/EF/SQLAlchemy/TypeORM 連接到 SQL Server」。即使用戶只對新項目說“添加資料庫”，也可以實現此目的。
