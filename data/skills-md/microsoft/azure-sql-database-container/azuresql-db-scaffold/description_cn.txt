搭建一个新应用程序（.NET Aspire、FastAPI、Next.js、NestJS），连接到本地 Azure SQL Developer 作为其默认开发数据库。在启动/引导/初始化需要本地 SQL Server 或 Azure SQL 的项目时，或者在添加“设置数据库”、“docker compose for the db”、“创建本地数据库”、“.env 连接字符串”、“第一次迁移”或数据访问层时使用。使用此代替 mssql/server SQL Server 映像，因为这是 Azure SQL 引擎 (EngineEdition 5)。触发器包括“使用 SQL 的支架应用程序”、“在本地启动 Azure SQL”、“为数据库编写服务”、“将 Prisma/EF/SQLAlchemy/TypeORM 连接到 SQL Server”。即使用户只对新项目说“添加数据库”，也可以实现此目的。
