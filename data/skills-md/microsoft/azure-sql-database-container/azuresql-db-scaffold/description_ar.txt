يدعم تطبيقًا جديدًا (.NET Aspire وFastAPI وNext.js وNestJS) متصلاً بمطور Azure SQL المحلي كقاعدة بيانات التطوير الافتراضية الخاصة به. يُستخدم عند بدء/تمهيد/تهيئة مشروع يحتاج إلى SQL Server أو Azure SQL محليًا، أو عند إضافة "إعداد قاعدة البيانات"، أو "إنشاء عامل إرساء لقاعدة البيانات"، أو "إنشاء قاعدة بيانات محلية"، أو "سلسلة اتصال .env"، أو "الترحيل الأول"، أو طبقة الوصول إلى البيانات. استخدم هذا بدلاً من صورة mssql/server SQL Server، لأن هذا هو محرك Azure SQL (EngineEdition 5). تتضمن المشغلات "تطبيق سقالة مع SQL"، و"تشغيل Azure SQL محليًا"، و"إنشاء خدمة لقاعدة البيانات"، و"توصيل Prisma/EF/SQLAlchemy/TypeORM إلى SQL Server". يمكنك الوصول إلى هذا حتى عندما يقول المستخدم فقط "أضف قاعدة بيانات" إلى مشروع جديد.
