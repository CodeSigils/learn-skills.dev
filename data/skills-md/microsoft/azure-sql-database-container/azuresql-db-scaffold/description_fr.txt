Élabore une NOUVELLE application (.NET Aspire, FastAPI, Next.js, NestJS) connectée au développeur Azure SQL local en tant que base de données de développement par défaut. À utiliser lors du démarrage/amorçage/initialisation d'un projet nécessitant SQL Server ou Azure SQL localement, ou lors de l'ajout de « configurer la base de données », « docker composer pour la base de données », « créer la base de données locale », « chaîne de connexion .env », « première migration » ou une couche d'accès aux données. Utilisez ceci AU LIEU de l'image mssql/server SQL Server, car il s'agit du moteur Azure SQL (EngineEdition 5). Les déclencheurs incluent « l'application d'échafaudage avec SQL », « faire tourner Azure SQL localement », « composer le service pour la base de données », « connecter Prisma/EF/SQLAlchemy/TypeORM à SQL Server ». Atteignez-le même lorsque l'utilisateur dit seulement « ajouter une base de données » à un nouveau projet.
