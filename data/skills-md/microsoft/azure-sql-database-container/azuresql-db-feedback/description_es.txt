Informa un error o envía comentarios sobre las habilidades del agente azuresql-db-* o sobre Azure SQL Developer (el motor de base de datos Azure SQL local en un contenedor, vista previa privada). Úselo cuando el usuario dice que una habilidad o el contenedor "no funcionó", tuvo un error, se comportó inesperadamente o le falta algo; y cuando dicen "informar un error", "presentar un problema", "abrir un problema de GitHub", "solicitar una función", "dar comentarios" o "avisar al equipo". Úselo también cuando usted, el agente, tuvo que desviarse de una habilidad azuresql-db-* o solucionar un defecto en una para finalizar una tarea: se trata de un error en la habilidad y vale la pena informarlo, incluso si la tarea finalmente se realizó correctamente. Decide si el problema pertenece a la HABILIDAD o al CONTENEDOR, ya que utilizan diferentes plantillas de problemas, luego crea un problema de GitHub completo y precargado a partir del contexto que ya tiene. Nunca envíe nada sin la confirmación explícita del usuario.
