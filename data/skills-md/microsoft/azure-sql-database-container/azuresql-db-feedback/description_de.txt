Meldet einen Fehler oder sendet Feedback zu den azuresql-db-*-Agent-Fähigkeiten selbst oder zu Azure SQL Developer (der lokalen Azure SQL-Datenbank-Engine in einem Container, private Vorschau). Wird verwendet, wenn der Benutzer sagt, dass ein Skill oder der Container „nicht funktioniert hat“, ein Fehler aufgetreten ist, sich unerwartet verhalten hat oder etwas fehlt; und wenn sie sagen „einen Fehler melden“, „ein Problem melden“, „ein GitHub-Problem öffnen“, „eine Funktion anfordern“, „Feedback geben“ oder „dem Team davon erzählen“. Verwenden Sie dies auch, wenn Sie als Agent von einem azuresql-db-*-Skill abweichen oder einen Fehler darin umgehen mussten, um eine Aufgabe abzuschließen: Das ist ein Fehler im Skill und es lohnt sich, ihn zu melden, selbst wenn die Aufgabe letztendlich erfolgreich war. Entscheidet, ob das Problem zum SKILL oder zum CONTAINER gehört, da diese unterschiedliche Issue-Vorlagen verwenden, und erstellt dann ein vollständig vorab ausgefülltes GitHub-Issue aus dem Kontext, den Sie bereits haben. Senden Sie niemals etwas ohne ausdrückliche Bestätigung des Benutzers.
