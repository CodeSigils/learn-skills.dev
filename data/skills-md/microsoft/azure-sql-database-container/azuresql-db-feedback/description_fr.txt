Signale un bogue ou dépose des commentaires sur les compétences de l'agent azuresql-db-* elles-mêmes ou sur Azure SQL Developer (le moteur de base de données Azure SQL local dans un conteneur, Private Preview). À utiliser lorsque l'utilisateur déclare qu'une compétence ou un conteneur "n'a pas fonctionné", a rencontré une erreur, s'est comporté de manière inattendue ou manque quelque chose ; et quand ils disent « signaler un bug », « signaler un problème », « ouvrir un problème GitHub », « demander une fonctionnalité », « donner des commentaires » ou « informer l'équipe ». À utiliser également lorsque vous, l'agent, avez dû vous écarter d'une compétence azuresql-db-* ou contourner un défaut d'une compétence pour terminer une tâche : il s'agit d'un bug dans la compétence et cela vaut la peine d'être signalé, même si la tâche a finalement réussi. Décide si le problème appartient au SKILL ou au CONTAINER, car ils utilisent des modèles de ticket différents, puis crée un ticket GitHub pré-rempli complet à partir du contexte que vous avez déjà. Ne soumet jamais rien sans confirmation explicite de l’utilisateur.
