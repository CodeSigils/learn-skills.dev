azuresql-db-* エージェント スキル自体、または Azure SQL Developer (コンテナー内のローカル Azure SQL Database エンジン、プライベート プレビュー) に関するバグを報告するか、フィードバックをファイルします。ユーザーがスキルまたはコンテナが「機能しなかった」、エラーが発生した、予期せぬ動作をした、または何かが足りないと言っている場合に使用します。そして、「バグを報告する」、「問題を報告する」、「GitHub の問題をオープンする」、「機能をリクエストする」、「フィードバックを与える」、または「チームに伝える」と言ったときも同様です。また、エージェントが、タスクを完了するために azuresql-db-* スキルから逸脱するか、スキルの欠陥を回避する必要がある場合にも使用します。これはスキルのバグであり、たとえタスクが最終的に成功したとしても、報告する価値があります。問題が SKILL に属するか CONTAINER に属するかを決定します。これは、異なる問題テンプレートを使用するためです。その後、既にあるコンテキストから完全な事前入力された GitHub 問題を構築します。ユーザーからの明示的な確認なしに何も送信しないでください。
