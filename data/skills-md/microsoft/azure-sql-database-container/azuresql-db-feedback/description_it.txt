Segnala un bug o invia feedback sulle competenze dell'agente azuresql-db-* o su Azure SQL Developer (il motore del database SQL di Azure locale in un contenitore, Anteprima privata). Da utilizzare quando l'utente afferma che una competenza o il contenitore "non ha funzionato", ha riscontrato un errore, si è comportato in modo imprevisto o manca qualcosa; e quando dicono "segnala un bug", "presenta un problema", "apri un problema su GitHub", "richiedi una funzionalità", "fornisci feedback" o "informa il team". Da utilizzare anche quando l'agente ha dovuto deviare da una competenza azuresql-db-* o aggirare un difetto in una per completare un'attività: si tratta di un bug nella competenza e vale la pena segnalarlo, anche se l'attività alla fine è riuscita. Decide se il problema appartiene alla SKILL o al CONTAINER, poiché utilizzano modelli di problemi diversi, quindi crea un problema GitHub precompilato completo dal contesto che già possiedi. Non invia mai nulla senza la conferma esplicita dell'utente.
