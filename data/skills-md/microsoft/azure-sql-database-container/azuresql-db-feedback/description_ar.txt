الإبلاغ عن خطأ أو تقديم تعليقات حول مهارات وكيل azuresql-db-* نفسها، أو حول Azure SQL Developer (محرك قاعدة بيانات Azure SQL المحلي في حاوية، معاينة خاصة). يُستخدم عندما يقول المستخدم أن إحدى المهارات أو الحاوية "لا تعمل"، أو يحدث خطأ، أو يتصرف بشكل غير متوقع، أو يفتقد شيئًا ما؛ وعندما يقولون "أبلغ عن خطأ"، أو "أرسل مشكلة"، أو "افتح مشكلة في GitHub"، أو "اطلب ميزة"، أو "قدم تعليقات"، أو "أخبر الفريق". يُستخدم أيضًا عندما يتعين عليك، بصفتك الوكيل، الانحراف عن مهارة azuresql-db-* أو حل عيب في إحدى المهارات لإنهاء مهمة: فهذا خطأ في المهارة ويستحق الإبلاغ عنه، حتى لو نجحت المهمة في النهاية. يقرر ما إذا كانت المشكلة تخص SKILL أو الحاوية، نظرًا لأنهم يستخدمون قوالب مشكلات مختلفة، ثم ينشئ مشكلة GitHub كاملة مملوءة مسبقًا من السياق الموجود لديك بالفعل. لا ترسل أبدًا أي شيء دون تأكيد صريح من المستخدم.
