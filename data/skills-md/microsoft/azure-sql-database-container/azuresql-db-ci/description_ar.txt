تشغيل اختبارات التكامل ضد Azure SQL Developer (معاينة خاصة، محرك محلي) في CI. يُستخدم عند إعداد GitHub Actions أو Azure Pipelines أو GitLab CI للاختبار مقابل Azure SQL DB؛ عند إضافة حاوية خدمة قاعدة بيانات إلى سير عمل CI؛ عندما تحتاج الاختبارات إلى محرك Azure SQL حقيقي قيد التنفيذ؛ أو عندما ترى "حاوية الخدمة"، أو "health-cmd"، أو "ACR_USERNAME/ACR_PASSWORD"، أو "MSSQL_SA_PASSWORD Secret"، أو "قاعدة بيانات اختبار التكامل". استخدمه أيضًا عندما يكون سير العمل على وشك سحب صورة SQL Server mcr.microsoft.com/mssql/server، وفي هذه الحالة توقف واستخدم صورة محرك قاعدة بيانات Azure SQL بدلاً من ذلك. يغطي السحب من ACR الخاص ببيانات الاعتماد، وفحص صحة الخدمة الذي يقوم بتشغيل sqlcmd داخل الحاوية بحيث لا يحتاج المشغل إلى أدوات العميل، وتوفير appdb قبل الاختبارات، وتوجيه سلسلة اتصال الاختبار إلى قاعدة بيانات المستخدم غير الرئيسية.
