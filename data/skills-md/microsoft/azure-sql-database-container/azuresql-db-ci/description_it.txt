Esegue test di integrazione con Azure SQL Developer (anteprima privata, motore locale) in CI. Da utilizzare durante la configurazione di GitHub Actions, Azure Pipelines o GitLab CI per testare il database SQL di Azure; quando si aggiunge un contenitore di servizi di database a un flusso di lavoro CI; quando i test necessitano di un vero motore SQL di Azure in pipeline; o quando vedi "contenitore di servizi", "health-cmd", "ACR_USERNAME/ACR_PASSWORD", "segreto MSSQL_SA_PASSWORD" o "database di test di integrazione". Da utilizzare anche quando un flusso di lavoro stava per estrarre l'immagine di SQL Server mcr.microsoft.com/mssql/server, nel qual caso arrestare e usare invece l'immagine del motore del database SQL di Azure. Riguarda l'estrazione dall'ACR privato con credenziali, il controllo dello stato del servizio che esegue sqlcmd all'interno del contenitore in modo che il runner non abbia bisogno di strumenti client, il provisioning di appdb prima dei test e il puntamento della stringa di connessione di test al database utente non master.
