Запускает интеграционные тесты с Azure SQL Developer (частная предварительная версия, локальный механизм) в CI. Используйте при настройке GitHub Actions, Azure Pipelines или GitLab CI для тестирования с помощью базы данных SQL Azure; при добавлении контейнера службы базы данных в рабочий процесс CI; когда для тестов требуется реальный механизм Azure SQL в конвейере; или когда вы видите «контейнер службы», «health-cmd», «ACR_USERNAME/ACR_PASSWORD», «секрет MSSQL_SA_PASSWORD» или «базу данных интеграционного теста». Также используйте, когда рабочий процесс собирался получить образ SQL Server mcr.microsoft.com/mssql/server, и в этом случае остановитесь и вместо этого используйте образ ядра базы данных SQL Azure. Охватывает получение данных из частного ACR с учетными данными, проверку работоспособности службы, которая запускает sqlcmd внутри контейнера, поэтому исполнителю не нужны клиентские инструменты, подготовку базы данных appdb перед тестированием и указание строки тестового подключения на пользовательскую базу данных, а не на главную.
