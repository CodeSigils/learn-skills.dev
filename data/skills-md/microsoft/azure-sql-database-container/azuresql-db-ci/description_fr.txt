Exécute des tests d'intégration avec Azure SQL Developer (Private Preview, moteur local) dans CI. À utiliser lors de la configuration de GitHub Actions, Azure Pipelines ou GitLab CI pour tester sur Azure SQL DB ; lors de l'ajout d'un conteneur de service de base de données à un workflow CI ; lorsque les tests nécessitent un véritable moteur Azure SQL dans le pipeline ; ou lorsque vous voyez "conteneur de service", "health-cmd", "ACR_USERNAME/ACR_PASSWORD", "MSSQL_SA_PASSWORD secret" ou "base de données de test d'intégration". À utiliser également lorsqu'un flux de travail était sur le point d'extraire l'image SQL Server mcr.microsoft.com/mssql/server, auquel cas arrêtez et utilisez plutôt l'image du moteur Azure SQL Database. Couvre l'extraction de l'ACR privé avec les informations d'identification, la vérification de l'état du service qui exécute sqlcmd à l'intérieur du conteneur afin que le programme d'exécution n'ait besoin d'aucun outil client, le provisionnement d'appdb avant les tests et le pointage de la chaîne de connexion de test vers la base de données utilisateur non maître.
