Ejecuta pruebas de integración contra Azure SQL Developer (Vista previa privada, motor local) en CI. Úselo al configurar GitHub Actions, Azure Pipelines o GitLab CI para realizar pruebas en Azure SQL DB; al agregar un contenedor de servicios de base de datos a un flujo de trabajo de CI; cuando las pruebas necesitan un motor Azure SQL real en proceso; o cuando vea "contenedor de servicios", "health-cmd", "ACR_USERNAME/ACR_PASSWORD", "MSSQL_SA_PASSWORD secret" o "base de datos de prueba de integración". Úselo también cuando un flujo de trabajo esté a punto de extraer la imagen de SQL Server mcr.microsoft.com/mssql/server, en cuyo caso deténgase y use la imagen del motor de Azure SQL Database. Cubre la extracción del ACR privado con credenciales, la verificación del estado del servicio que ejecuta sqlcmd dentro del contenedor para que el ejecutor no necesite herramientas de cliente, el aprovisionamiento de appdb antes de las pruebas y el apuntamiento de la cadena de conexión de prueba a la base de datos del usuario, no a la maestra.
