Führt Integrationstests für Azure SQL Developer (private Vorschau, lokale Engine) in CI aus. Verwenden Sie diese Option beim Einrichten von GitHub Actions, Azure Pipelines oder GitLab CI zum Testen mit Azure SQL DB. beim Hinzufügen eines Datenbankdienstcontainers zu einem CI-Workflow; wenn Tests eine echte Azure SQL-Engine in der Pipeline benötigen; oder wenn Sie „Dienstcontainer“, „health-cmd“, „ACR_USERNAME/ACR_PASSWORD“, „MSSQL_SA_PASSWORD Secret“ oder „Integrationstestdatenbank“ sehen. Verwenden Sie diese Option auch, wenn ein Workflow das SQL Server-Image mcr.microsoft.com/mssql/server abrufen wollte. Halten Sie in diesem Fall an und verwenden Sie stattdessen das Azure SQL-Datenbank-Engine-Image. Behandelt das Abrufen aus dem privaten ACR mit Anmeldeinformationen, die Dienstzustandsprüfung, die sqlcmd im Container ausführt, sodass der Läufer keine Client-Tools benötigt, die Bereitstellung von appdb vor Tests und das Verweisen der Testverbindungszeichenfolge auf die Benutzerdatenbank, nicht auf die Masterdatenbank.
