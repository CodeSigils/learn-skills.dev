在 CI 中針對 Azure SQL Developer（私人預覽版、本機引擎）執行整合測試。在設定 GitHub Actions、Azure Pipelines 或 GitLab CI 來測試 Azure SQL DB 時使用；將資料庫服務容器新增至 CI 工作流程時；當測試需要管道中真正的 Azure SQL 引擎時；或當您看到「服務容器」、「health-cmd」、「ACR_USERNAME/ACR_PORD」、「health-cmd。當工作流程即將拉取 SQL Server 映像 mcr.microsoft.com/mssql/server 時也可使用，在這種情況下請停止並使用 Azure SQL 資料庫引擎映像。涵蓋使用憑證從私人 ACR 中提取資料、在容器內執行 sqlcmd 的服務運行狀況檢查，以便運行程式不需要客戶端工具、在測試之前配置 appdb，以及將測試連接字串指向使用者資料庫而不是 master 資料庫。
