在 CI 中针对 Azure SQL Developer（私人预览版、本地引擎）运行集成测试。在设置 GitHub Actions、Azure Pipelines 或 GitLab CI 来测试 Azure SQL DB 时使用；将数据库服务容器添加到 CI 工作流程时；当测试需要管道中真正的 Azure SQL 引擎时；或者当您看到“服务容器”、“health-cmd”、“ACR_USERNAME/ACR_PASSWORD”、“MSSQL_SA_PASSWORD 机密”或“集成测试数据库”时。当工作流即将拉取 SQL Server 映像 mcr.microsoft.com/mssql/server 时也可使用，在这种情况下请停止并使用 Azure SQL 数据库引擎映像。涵盖使用凭据从私有 ACR 中提取数据、在容器内运行 sqlcmd 的服务运行状况检查，以便运行程序不需要客户端工具、在测试之前配置 appdb，以及将测试连接字符串指向用户数据库而不是 master 数据库。
