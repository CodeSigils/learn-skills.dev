CI에서 Azure SQL Developer(개인 미리 보기, 로컬 엔진)에 대한 통합 테스트를 실행합니다. Azure SQL DB에 대해 테스트하기 위해 GitHub Actions, Azure Pipelines 또는 GitLab CI를 설정할 때 사용합니다. CI 워크플로에 데이터베이스 서비스 컨테이너를 추가할 때 테스트에 파이프라인에 실제 Azure SQL 엔진이 필요한 경우 또는 "서비스 컨테이너", "health-cmd", "ACR_USERNAME/ACR_PASSWORD", "MSSQL_SA_PASSWORD 비밀" 또는 "통합 테스트 데이터베이스"가 표시되는 경우. 또한 워크플로가 SQL Server 이미지 mcr.microsoft.com/mssql/server를 가져오려고 할 때 사용합니다. 이 경우 중지하고 대신 Azure SQL Database 엔진 이미지를 사용합니다. 자격 증명을 사용하여 개인 ACR에서 가져오기, 실행기에 클라이언트 도구가 필요하지 않도록 컨테이너 내에서 sqlcmd를 실행하는 서비스 상태 확인, 테스트 전에 appdb 프로비저닝, 마스터가 아닌 사용자 데이터베이스에서 테스트 연결 문자열 지정 등을 다룹니다.
