CI で Azure SQL Developer (プライベート プレビュー、ローカル エンジン) に対して統合テストを実行します。 GitHub Actions、Azure Pipelines、または GitLab CI をセットアップして Azure SQL DB に対してテストするときに使用します。データベース サービス コンテナを CI ワークフローに追加するとき。テストでパイプラインに実際の Azure SQL エンジンが必要な場合。または、「サービス コンテナー」、「health-cmd」、「ACR_USERNAME/ACR_PASSWORD」、「MSSQL_SA_PASSWORD シークレット」、または「統合テスト データベース」が表示された場合。また、ワークフローが SQL Server イメージ mcr.microsoft.com/mssql/server を取得しようとしていたときにも使用します。この場合は、停止して、代わりに Azure SQL Database エンジン イメージを使用します。認証情報を使用したプライベート ACR からの取得、ランナーがクライアント ツールを必要としないようにコンテナ内で sqlcmd を実行するサービス ヘルス チェック、テスト前の appdb のプロビジョニング、マスターではなくユーザー データベースを指すテスト接続文字列について説明します。
