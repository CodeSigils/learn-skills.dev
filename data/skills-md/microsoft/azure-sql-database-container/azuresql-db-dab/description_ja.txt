Microsoft Data API Builder (DAB) を使用して、ローカルの Azure SQL Developer 上で即時のノーコード REST + GraphQL API を立ち上げます。ユーザーが「テーブルを API として公開」、「データベース上に REST API を追加」、「GraphQL API を生成」、「SQL の前に API を配置」、「コードを記述せずに CRUD API」、または「dab init / dab-config.json」を実行したい場合に使用します。また、DAB 経由でデータベースから組み込み MCP エンドポイントを提供する方法 (別個の SQL MCP サーバーではなく、API サーフェス DAB が提供します)。ユーザーが既存のテーブルではなく REST または GraphQL だけを必要とする場合は、コントローラー/ORM API を手書きするよりもこれを優先します。トリガーには、「データ API ビルダー」、「dab 開始」、「Azure SQL 経由のインスタント API」、「エンティティを REST/GraphQL として公開」が含まれます。ユーザーが「このデータベースの API をください」とだけ言った場合でも、これに手を伸ばします。
