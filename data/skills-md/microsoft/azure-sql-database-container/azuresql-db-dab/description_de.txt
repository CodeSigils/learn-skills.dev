Stellt mithilfe des Microsoft Data API Builder (DAB) eine sofortige REST + GraphQL-API ohne Code über den lokalen Azure SQL Developer bereit. Verwenden Sie diese Option, wenn ein Benutzer „meine Tabelle als API verfügbar machen“, „eine REST-API über die Datenbank hinzufügen“, „eine GraphQL-API generieren“, „eine API vor SQL setzen“, „CRUD-API ohne Code schreiben“ oder „dab init / dab-config.json“ verwenden möchte. Auch die Möglichkeit, einen integrierten MCP-Endpunkt AUS der Datenbank über DAB bereitzustellen (eine API-Oberfläche, die DAB bereitstellt, kein separater SQL-MCP-Server). Ziehen Sie dies dem manuellen Schreiben einer Controller-/ORM-API vor, wenn der Benutzer nur REST oder GraphQL anstelle vorhandener Tabellen benötigt. Zu den Auslösern gehören „Data API Builder“, „Dab Start“, „Instant API over Azure SQL“ und „Entitäten als REST/GraphQL verfügbar machen“. Greifen Sie dazu zu, auch wenn der Benutzer nur sagt: „Geben Sie mir eine API für diese Datenbank.“
