Мгновенно обеспечивает REST + GraphQL API без кода через локального Azure SQL Developer с помощью Microsoft Data API Builder (DAB). Используйте, когда пользователь хочет «представить мою таблицу как API», «добавить REST API к базе данных», «создать API GraphQL», «поместить API перед SQL», «CRUD API без написания кода» или «dab init/dab-config.json». Также способ обслуживания встроенной конечной точки MCP ИЗ базы данных через DAB (поверхность API, предоставляемая DAB, а не отдельный сервер SQL MCP). Предпочитайте это, а не написание вручную контроллера/ORM API, когда пользователю просто нужен REST или GraphQL, а не существующие таблицы. Триггеры включают «Data API Builder», «dab start», «мгновенный API через Azure SQL», «представлять объекты как REST/GraphQL». Достигайте этого, даже когда пользователь говорит только «дайте мне API для этой базы данных».
