使用 Microsoft Data API Builder (DAB) 在本地 Azure SQL Developer 上建立即时无代码 REST + GraphQL API。当用户想要“将我的表公开为 API”、“在数据库上添加 REST API”、“生成 GraphQL API”、“将 API 放在 SQL 前面”、“无需编写代码的 CRUD API”或“dab init / dab-config.json”时使用。此外，还可以通过 DAB（DAB 提供的 API 表面，而不是单独的 SQL MCP 服务器）从数据库提供内置 MCP 端点服务。当用户只需要 REST 或 GraphQL 而不是现有表时，更喜欢这种方式，而不是手写控制器/ORM API。触发器包括“数据 API 生成器”、“dab start”、“通过 Azure SQL 的即时 API”、“将实体公开为 REST/GraphQL”。即使用户只说“给我这个数据库的 API”，也可以实现这一点。
