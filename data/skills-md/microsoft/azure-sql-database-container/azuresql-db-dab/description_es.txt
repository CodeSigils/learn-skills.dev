Ofrece una API REST + GraphQL instantánea y sin código a través del desarrollador Azure SQL local mediante Microsoft Data API Builder (DAB). Úselo cuando un usuario quiera "exponer mi tabla como API", "agregar una API REST a la base de datos", "generar una API GraphQL", "poner una API delante de SQL", "API CRUD sin escribir código" o "dab init/dab-config.json". También la forma de servir un punto final MCP integrado DESDE la base de datos a través de DAB (una superficie API que DAB proporciona, no un servidor SQL MCP separado). Prefiera esto a escribir a mano un controlador/API ORM cuando el usuario solo necesita REST o GraphQL en lugar de tablas existentes. Los activadores incluyen "Data API Builder", "dab start", "API instantánea sobre Azure SQL", "exponer entidades como REST/GraphQL". Busque esto incluso cuando el usuario solo diga "dame una API para esta base de datos".
