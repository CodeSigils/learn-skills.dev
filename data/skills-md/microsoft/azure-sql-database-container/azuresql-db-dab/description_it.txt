Supporta un'API REST + GraphQL istantanea senza codice sullo sviluppatore SQL di Azure locale utilizzando Microsoft Data API Builder (DAB). Da utilizzare quando un utente desidera "esporre la mia tabella come API", "aggiungere un'API REST sul database", "generare un'API GraphQL", "mettere un'API davanti a SQL", "API CRUD senza scrivere codice" o "dab init / dab-config.json". Anche il modo di servire un endpoint MCP integrato DAL database tramite DAB (fornisce una superficie API DAB, non un server MCP SQL separato). Preferisci questo rispetto alla scrittura manuale di un controller/API ORM quando l'utente ha solo bisogno di REST o GraphQL su tabelle esistenti. I trigger includono "Data API Builder", "dab start", "API istantanea su Azure SQL", "esporre entità come REST/GraphQL". Raggiungi questo obiettivo anche quando l'utente dice solo "dammi un'API per questo database".
