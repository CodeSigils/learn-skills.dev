使用 Microsoft Data API Builder (DAB) 在本機 Azure SQL Developer 上建立即時無程式碼 REST + GraphQL API。當使用者想要「將我的表公開為 API」、「在資料庫上新增 REST API」、「產生 GraphQL API」、「將 API 放在 SQL 前面」、「無需編寫程式碼的 CRUD API」或「dab init / dab-config.json」時使用。此外，還可以透過 DAB（DAB 提供的 API 表面，而不是單獨的 SQL MCP 伺服器）從資料庫提供內建 MCP 端點服務。當使用者只需要 REST 或 GraphQL 而不是現有表時，更喜歡這種方式，而不是手寫控制器/ORM API。觸發器包括「資料 API 產生器」、「dab start」、「透過 Azure SQL 的即時 API」、「將實體公開為 REST/GraphQL」。即使用戶只說“給我這個資料庫的 API”，也可以實現這一點。
