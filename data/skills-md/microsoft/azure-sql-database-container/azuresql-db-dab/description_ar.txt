يدعم واجهة REST + GraphQL API الفورية بدون تعليمات برمجية عبر مطور Azure SQL المحلي باستخدام Microsoft Data API Builder (DAB). يُستخدم عندما يريد المستخدم "إظهار الجدول الخاص بي كواجهة برمجة تطبيقات"، أو "إضافة واجهة برمجة تطبيقات REST على قاعدة البيانات"، أو "إنشاء واجهة برمجة تطبيقات GraphQL"، أو "وضع واجهة برمجة تطبيقات أمام SQL"، أو "واجهة برمجة تطبيقات CRUD بدون كتابة تعليمات برمجية"، أو "dab init / dab-config.json". أيضًا طريقة خدمة نقطة نهاية MCP مدمجة من قاعدة البيانات عبر DAB (يوفر سطح API DAB، وليس خادم SQL MCP منفصل). تفضل ذلك على الكتابة اليدوية لوحدة التحكم/ORM API عندما يحتاج المستخدم فقط إلى REST أو GraphQL على الجداول الموجودة. تتضمن المشغلات "Data API Builder"، و"dab start"، و"واجهة برمجة التطبيقات الفورية عبر Azure SQL"، و"كشف الكيانات كـ REST/GraphQL". يمكنك الوصول إلى هذا حتى عندما يقول المستخدم فقط "أعطني واجهة برمجة التطبيقات لقاعدة البيانات هذه".
