Prend en charge une API REST + GraphQL instantanée sans code sur le développeur Azure SQL local à l'aide de Microsoft Data API Builder (DAB). À utiliser lorsqu'un utilisateur souhaite « exposer ma table en tant qu'API », « ajouter une API REST sur la base de données », « générer une API GraphQL », « placer une API devant SQL », « API CRUD sans écrire de code » ou « dab init / dab-config.json ». Également le moyen de servir un point de terminaison MCP intégré À PARTIR de la base de données via DAB (une surface API fournie par DAB, pas un serveur SQL MCP distinct). Préférez cela à l'écriture manuelle d'une API de contrôleur/ORM lorsque l'utilisateur a juste besoin de REST ou de GraphQL sur les tables existantes. Les déclencheurs incluent « Data API Builder », « dab start », « API instantanée sur Azure SQL », « exposer les entités en tant que REST/GraphQL ». Atteignez cela même lorsque l'utilisateur dit seulement "donnez-moi une API pour cette base de données".
