يجيب على أسئلة حول ما يمكن وما لا يستطيع مطور Azure SQL (المعاينة الخاصة) فعله، ولماذا يختلف عن قاعدة بيانات Azure SQL في سحابة Microsoft Azure. يُستخدم عندما يسأل المستخدم "هل يمكنني أخذ نسخة احتياطية"، أو "لماذا يفشل USE"، أو "هل X مدعوم"، أو "لماذا لا يمكنني إنشاء فهرس متجه"، أو "لماذا يحدث خطأ SSMS"، أو "لماذا لا تظهر الصورة على Docker Hub"، أو "ما هو المختلف عن السحابة"، أو يصل إلى سلوك لا يتطابق مع توقعات قاعدة بيانات Azure SQL الخاصة به. لا تستنتج من المعرفة العامة بـ SQL Server / Azure: الحاوية عبارة عن منتج معاينة خاصة به فجوات محددة ونموذج اتصال محدد. اقرأ هذه المهارة، واربط المستخدم بصفحة القيود المعروفة المباشرة للحصول على القائمة الكاملة الحالية.
