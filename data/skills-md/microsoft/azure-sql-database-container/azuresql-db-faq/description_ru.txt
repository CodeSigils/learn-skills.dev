Отвечает на вопросы о том, что может и чего не может делать Azure SQL Developer (частная предварительная версия), а также ПОЧЕМУ он отличается от базы данных SQL Azure в облаке Microsoft Azure. Используйте, когда пользователь спрашивает: «Могу ли я сделать резервную копию», «Почему происходит сбой USE», «Поддерживается ли X», «Почему я не могу создать векторный индекс», «Почему возникает ошибка SSMS», «Почему нет изображения в Docker Hub», «Чем отличается от облака» или поведение, которое не соответствует ожиданиям базы данных SQL Azure. НЕ делайте догадок на основе общих знаний SQL Server/Azure: контейнер представляет собой продукт Private Preview со специфическими пробелами и конкретной моделью подключения. Прочтите этот навык и свяжите пользователя с актуальной страницей известных ограничений для просмотра текущего полного списка.
