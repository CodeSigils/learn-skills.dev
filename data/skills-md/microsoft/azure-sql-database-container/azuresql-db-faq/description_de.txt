Beantwortet Fragen dazu, was Azure SQL Developer (Private Preview) kann und was nicht und WARUM es sich von Azure SQL Database in der Microsoft Azure-Cloud unterscheidet. Verwenden Sie diese Option, wenn ein Benutzer fragt: „Kann ich eine Sicherung erstellen“, „Warum schlägt USE fehl“, „wird X unterstützt“, „Warum kann ich keinen Vektorindex erstellen“, „Warum gibt es einen SSMS-Fehler“, „Warum befindet sich das Bild nicht auf Docker Hub“, „Was unterscheidet sich von der Cloud“ oder er trifft auf ein Verhalten, das nicht seinen Erwartungen an die Azure SQL-Datenbank entspricht. Raten Sie NICHT anhand allgemeiner SQL Server-/Azure-Kenntnisse: Der Container ist ein Private Preview-Produkt mit bestimmten Lücken und einem bestimmten Verbindungsmodell. Lesen Sie diesen Skill und verlinken Sie den Benutzer mit der Live-Seite „Bekannte Einschränkungen“, um die aktuelle vollständige Liste anzuzeigen.
