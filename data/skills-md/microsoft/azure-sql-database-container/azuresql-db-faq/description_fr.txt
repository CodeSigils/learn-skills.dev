Répond aux questions sur ce qu’Azure SQL Developer (Private Preview) peut et ne peut pas faire, et POURQUOI il diffère d’Azure SQL Database dans le cloud Microsoft Azure. À utiliser lorsqu'un utilisateur demande « puis-je effectuer une sauvegarde », « pourquoi USE échoue-t-il », « X est-il pris en charge », « pourquoi ne puis-je pas créer un index vectoriel », « pourquoi une erreur SSMS », « pourquoi l'image n'est-elle pas sur Docker Hub », « qu'est-ce qui est différent du cloud » ou rencontre un comportement qui ne correspond pas à ses attentes Azure SQL Database. Ne devinez PAS à partir des connaissances générales de SQL Server / Azure : le conteneur est un produit Private Preview avec des lacunes spécifiques et un modèle de connexion spécifique. Lisez cette compétence et associez l'utilisateur à la page en direct des limitations connues pour obtenir la liste complète actuelle.
