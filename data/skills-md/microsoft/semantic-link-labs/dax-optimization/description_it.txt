Metodologia e catalogo di regole eseguibili per la diagnosi e l'ottimizzazione delle prestazioni delle query DAX. Utilizzarlo quando si analizza una query DAX lenta, si interpretano i tempi di traccia/piani di query DAX, si riduce la cardinalità delle colonne o si estendono le regole di analisi delle prestazioni utilizzate dal widget di test DAX interattivo (sempy_labs.semantic_model.test).
