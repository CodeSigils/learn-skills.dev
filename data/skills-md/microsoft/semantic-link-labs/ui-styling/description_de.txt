Leitfaden für den visuellen Stil, die Struktur und die gemeinsamen Bausteine, die von den interaktiven UI-Tools von Semantic Link Labs (HTML-Widgets und Anywidget-basierte Widgets) verwendet werden. Verwenden Sie dies, wenn Sie eine neue interaktive Benutzeroberfläche hinzufügen, eine vorhandene ändern oder gemeinsame visuelle Komponenten hinzufügen.
