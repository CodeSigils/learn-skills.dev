Guide sur le style visuel, la structure et les blocs de construction partagés utilisés par les outils d'interface utilisateur interactifs de Semantic Link Labs (widgets HTML et widgets basés sur n'importe quel widget). Utilisez-le lors de l'ajout d'une nouvelle interface utilisateur interactive, de la modification d'une interface existante ou de l'ajout de composants visuels partagés.
