**ワークフロー スキル** - YAML 仕様、フィクスチャの分離、プラグイン可能なバリデーターを備えた構造化ベンチマークを使用して、AI エージェントのスキルを評価します。用途: 技の実行、技のヘルプ、評価の実行、ベンチマークの実行、スキルの評価、エージェントのテスト、評価スイートの生成、評価の初期化、結果の比較、エージェントのスコア付け、エージェントの評価、スキル テスト、モデル間比較。次の用途には使用しないでください: スキルのフロントマターの改善 (waza dev を使用)、新しいスキルを最初から作成する (skill-creator を使用)、トークンのカウントまたは予算のチェック (waza トークンを使用)。呼び出し: Copilot SDK エグゼキュータ、モック エンジン、コード/正規表現バリデータ。単一オペレーションの場合: 単一のベンチマークに対して waza run を直接使用します。
