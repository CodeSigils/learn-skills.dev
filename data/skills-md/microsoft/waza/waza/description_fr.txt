**COMPÉTENCE DE FLUX DE TRAVAIL** - Évaluez les compétences des agents IA à l'aide de tests structurés avec des spécifications YAML, une isolation des appareils et des validateurs enfichables. UTILISER POUR : exécuter waza, waza help, exécuter eval, exécuter un benchmark, évaluer les compétences, tester l'agent, générer une suite d'évaluation, initialiser l'évaluation, comparer les résultats, noter l'agent, évaluer l'agent, tester les compétences, comparer les modèles. NE PAS UTILISER POUR : améliorer les compétences (utiliser waza dev), créer de nouvelles compétences à partir de zéro (utiliser le créateur de compétences), compter les jetons ou vérifier le budget (utiliser les jetons waza). INVOKES : exécuteur du SDK Copilot, moteur fictif, validateurs de code/regex. POUR DES OPÉRATIONS SIMPLES : utilisez waza run directement pour un seul benchmark.
