**HABILIDADES DE FLUJO DE TRABAJO**: evalúe las habilidades de los agentes de IA utilizando puntos de referencia estructurados con especificaciones YAML, aislamiento de dispositivos y validadores conectables. USO PARA: ejecutar waza, ayuda de waza, ejecutar evaluación, ejecutar evaluación comparativa, evaluar habilidades, probar agente, generar conjunto de evaluaciones, iniciar evaluación, comparar resultados, calificar agente, evaluación de agentes, pruebas de habilidades, comparación entre modelos. NO UTILIZAR PARA: mejorar las habilidades iniciales (use waza dev), crear nuevas habilidades desde cero (use skills-creator), conteo de tokens o comprobaciones de presupuesto (use tokens waza). INVOCACIONES: Ejecutor de Copilot SDK, motor simulado, validadores de código/regex. PARA OPERACIONES ÚNICAS: utilice waza run directamente para un único punto de referencia.
