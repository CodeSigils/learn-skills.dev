**НАВЫКИ РАБОЧЕГО ПРОЦЕССА**. Оценивайте навыки ИИ-агентов, используя структурированные тесты со спецификациями YAML, изоляцию устройств и подключаемые валидаторы. ИСПОЛЬЗОВАНИЕ ДЛЯ: запуск waza, помощь waza, запуск оценки, запуск теста, оценка навыков, агент тестирования, создание пакета оценки, инициализация оценки, сравнение результатов, оценка агента, оценка агента, тестирование навыков, сравнение между моделями. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: улучшения навыков (используйте waza dev), создания новых навыков с нуля (используйте мастер-создатель), подсчета токенов или проверки бюджета (используйте токены waza). ВЫЗЫВАЕТ: исполнитель Copilot SDK, макетный движок, валидаторы кода/регулярных выражений. ДЛЯ ОДИНОЧНЫХ ОПЕРАЦИЙ: используйте waza run непосредственно для одного теста.
