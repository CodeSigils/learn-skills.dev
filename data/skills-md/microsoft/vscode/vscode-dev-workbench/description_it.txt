Da utilizzare quando l'utente desidera eseguire il server vscode.dev localmente ed esercitare il workbench di VS Code o la finestra Agenti nel browser integrato rispetto alle origini locali `microsoft/vscode`. Riguarda l'avvio del server di sviluppo, l'URL `vscode-quality=dev`, i modelli di interazione guidati dal browser e, facoltativamente, il cablaggio di un host agente fittizio locale per la finestra Agenti.
