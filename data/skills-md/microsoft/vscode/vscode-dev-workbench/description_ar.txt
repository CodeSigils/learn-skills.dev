يُستخدم عندما يريد المستخدم تشغيل خادم vscode.dev محليًا وممارسة منصة عمل VS Code أو نافذة Agents في المستعرض المدمج مقابل مصادر `microsoft/vscode` المحلية. يغطي بدء تشغيل خادم التطوير، وعنوان URL `vscode-quality=dev`، وأنماط التفاعل المستندة إلى المستعرض، وتوصيل مضيف وكيل وهمي محلي بشكل اختياري لنافذة الوكلاء.
