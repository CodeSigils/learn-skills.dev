Úselo cuando el usuario desee ejecutar el servidor vscode.dev localmente y ejercitar el banco de trabajo de VS Code o la ventana de Agentes en el navegador integrado con las fuentes locales de "microsoft/vscode". Cubre el inicio del servidor de desarrollo, la URL `vscode-quality=dev`, los patrones de interacción controlados por el navegador y, opcionalmente, el cableado de un host de agente simulado local para la ventana Agentes.
