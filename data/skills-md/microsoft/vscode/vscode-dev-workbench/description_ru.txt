Используйте, когда пользователь хочет запустить сервер vscode.dev локально и протестировать рабочую среду VS Code или окно агентов во встроенном браузере с локальными источниками `microsoft/vscode`. Охватывает запуск сервера разработки, URL-адрес vscode-quality=dev, шаблоны взаимодействия с браузером и, при необходимости, подключение локального хоста фиктивного агента для окна «Агенты».
