À utiliser lorsque l'utilisateur souhaite exécuter le serveur vscode.dev localement et exercer l'atelier VS Code ou la fenêtre Agents dans le navigateur intégré par rapport aux sources locales « microsoft/vscode ». Couvre le démarrage du serveur de développement, l'URL `vscode-quality=dev`, les modèles d'interaction pilotés par le navigateur et éventuellement le câblage d'un hôte d'agent fictif local pour la fenêtre Agents.
