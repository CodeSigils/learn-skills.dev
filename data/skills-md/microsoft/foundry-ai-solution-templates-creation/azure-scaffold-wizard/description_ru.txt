Создайте готовый к работе проект Azure с нуля для ЛЮБОГО варианта использования: чат-боты RAG, многоагентные системы, серверные части API, конвейеры данных, функции Azure, полнофункциональные веб-приложения, обучение/выводы машинного обучения или микросервисы, управляемые событиями. ИСПОЛЬЗОВАНИЕ ДЛЯ: сбора требований посредством адаптивного опроса, создания полных структур папок проекта со всеми исходными файлами, инфраструктуры Azure Bicep, azure.yaml для развертывания azd-up, настройки Docker, рабочих процессов CI/CD, README со схемами архитектуры и документации по ответственному ИИ. Создает полностью развертываемые проекты Azure, предназначенные для приложений-контейнеров Azure, Azure AI Foundry, функций Azure или машинного обучения Azure. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: изменения существующих проектов, развертывания в Azure (используйте навыки azure-deploy), управления ресурсами Azure (используйте навыки azure-prepare).
