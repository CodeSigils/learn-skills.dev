قم بدعم مشروع Azure كامل وجاهز للإنتاج من البداية لأي حالة استخدام: روبوتات الدردشة RAG، أو الأنظمة متعددة الوكلاء، أو الواجهات الخلفية لواجهة برمجة التطبيقات، أو خطوط أنابيب البيانات، أو وظائف Azure، أو تطبيقات الويب الكاملة، أو التدريب/الاستدلال على تعلم الآلة، أو الخدمات الصغيرة المستندة إلى الأحداث. الاستخدام من أجل: جمع المتطلبات من خلال الأسئلة التكيفية، وإنشاء هياكل مجلدات مشروع كاملة مع جميع الملفات المصدر، والبنية التحتية لـ Azure Bicep، وazure.yaml لنشر azd-up، وتكوين Docker، وسير عمل CI/CD، وREADME مع مخططات الهندسة المعمارية، ووثائق الذكاء الاصطناعي المسؤول. إنتاج مشاريع Azure قابلة للنشر بالكامل تستهدف Azure Container Apps أو Azure AI Foundry أو Azure Functions أو Azure ML. لا تستخدم من أجل: تعديل المشاريع الحالية، والنشر في Azure (استخدم مهارة نشر Azure)، وإدارة موارد Azure (استخدم مهارة إعداد Azure).
