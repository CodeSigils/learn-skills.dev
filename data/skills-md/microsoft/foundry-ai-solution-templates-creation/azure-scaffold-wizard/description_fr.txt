Élaborez un projet Azure complet et prêt pour la production à partir de zéro pour TOUS les cas d'utilisation : chatbots RAG, systèmes multi-agents, backends d'API, pipelines de données, Azure Functions, applications Web full-stack, formation/inférence ML ou microservices pilotés par événements. UTILISER POUR : recueillir les exigences via des questions adaptatives, générer des structures complètes de dossiers de projet avec tous les fichiers sources, l'infrastructure Azure Bicep, azure.yaml pour le déploiement azd-up, la configuration Docker, les flux de travail CI/CD, le README avec diagrammes d'architecture et la documentation sur l'IA responsable. Produit des projets Azure entièrement déployables ciblant Azure Container Apps, Azure AI Foundry, Azure Functions ou Azure ML. NE PAS UTILISER POUR : modifier des projets existants, déployer sur Azure (utiliser la compétence azure-deploy), gérer les ressources Azure (utiliser la compétence azure-prepare).
