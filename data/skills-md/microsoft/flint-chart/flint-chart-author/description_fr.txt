À utiliser lorsque : l'utilisateur demande de créer ou de restituer des graphiques avec Flint-Chart, de visualiser des données tabulaires, de générer un ChartAssemblyInput, de valider/rendre via MCP ou d'ajouter Flint à un projet JS/TS. Créez la spécification sémantique, transformez les données avant Flint si nécessaire, installez/importez Flint uniquement lorsque du code exécutable est nécessaire et réservez les ajustements de style spécifiques au backend après la compilation à partir de Flint.
