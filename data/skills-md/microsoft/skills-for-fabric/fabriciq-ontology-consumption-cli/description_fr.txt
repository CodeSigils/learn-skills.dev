Explorez les éléments de l'ontologie Fabric IQ (préversion) (en lecture seule) à partir de la CLI pour mettre à la terre un agent avant qu'il n'interroge des données. Explorez, décrivez et résumez ce qu'une ontologie expose (ses types d'entités, clés, relations et liaisons qui mappent chaque concept sur une source Lakehouse ou Eventhouse), puis acheminez la requête de données sous-jacente vers la compétence de consommation correspondante par source de données (eventhouse-consumption-cli, spark-consumption-cli, sqldw-consumption-cli). Découverte en lecture seule via Get Item Definition ; n’écrit ni ne modifie jamais une ontologie. Utilisez-le pour explorer ou résumer une ontologie, décrire son schéma et son lignage de données, créer un contexte de base d'agent ou exécuter une requête basée sur une ontologie sur les enregistrements source.
