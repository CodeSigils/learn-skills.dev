Изучите элементы онтологии Fabric IQ (предварительная версия) (только для чтения) из интерфейса командной строки, чтобы заземлить агент перед тем, как он запрашивает данные. Исследуйте, описывайте и обобщайте то, что предоставляет онтология — ее типы сущностей, ключи, связи и привязки, которые сопоставляют каждую концепцию с источником Lakehouse или Eventhouse, — а затем направляйте базовый запрос данных к соответствующему навыку потребления для каждого источника данных (eventhouse-consumption-cli, spark-consumption-cli, sqldw-consumption-cli). Обнаружение только для чтения с помощью функции «Получить определение элемента»; никогда не записывает и не изменяет онтологию. Используйте для изучения или обобщения онтологии, описания ее схемы и происхождения данных, построения контекста заземления агента или выполнения запроса на основе онтологии к исходным записям.
