从代理 CLI 环境针对 Microsoft Fabric 数据仓库和 SQL 端点执行创作 T-SQL（DDL、DML、数据摄取、事务、架构更改）。当用户想要执行以下操作时使用：(1) 从终端创建/更改/删除表，(2) 通过 CLI 插入/更新/删除/合并数据，(3) 运行 COPY INTO 或 OPENROWSET 摄取，(4) 管理事务或存储过程，(5) 执行模式演化，(6) 使用时间旅行或快照，(7) 生成 ETL/ELT shell 脚本，(8) 在 Lakehouse SQLEP 上创建视图/函数/过程。触发器：“在仓库中创建表”、“通过 T-SQL 插入数据”、“从 ADLS 加载”、“COPY INTO”、“使用 T-SQL 运行 ETL”、“更改仓库表”、“使用 T-SQL 更新插入”、“合并到仓库”、“创建 T-SQL 过程”、“仓库时间旅行”、“恢复已删除的仓库数据”、“创建仓库架构”、“部署仓库”、“事务冲突”、“快照隔离”错误”。
