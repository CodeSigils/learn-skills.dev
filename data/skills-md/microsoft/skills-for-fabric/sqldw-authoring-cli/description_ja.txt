エージェント CLI 環境から Microsoft Fabric Data Warehouse および SQL エンドポイントに対して T-SQL オーサリング (DDL、DML、データ取り込み、トランザクション、スキーマ変更) を実行します。ユーザーが次のことを行う場合に使用します: (1) ターミナルからテーブルを作成/変更/削除する、(2) CLI を介してデータを挿入/更新/削除/マージする、(3) COPY INTO または OPENROWSET 取り込みを実行する、(4) トランザクションまたはストアド プロシージャを管理する、(5) スキーマ エボリューションを実行する、(6) タイム トラベルまたはスナップショットを使用する、(7) ETL/ELT シェル スクリプトを生成する、(8) Lakehouse でビュー/関数/プロシージャを作成するSQLEP。トリガー: 「ウェアハウスにテーブルを作成」、「T-SQL 経由でデータを挿入」、「ADLS からロード」、「COPY INTO」、「T-SQL で ETL を実行」、「ウェアハウス テーブルを変更」、「T-SQL で更新挿入」、「ウェアハウスにマージ」、「T-SQL プロシージャの作成」、「ウェアハウスのタイムトラベル」、「削除されたウェアハウス データの回復」、「ウェアハウス スキーマの作成」、「ウェアハウスのデプロイ」、「トランザクションの競合」、 「スナップショット分離エラー」。
