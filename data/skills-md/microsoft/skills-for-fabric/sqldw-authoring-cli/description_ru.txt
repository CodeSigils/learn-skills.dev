Выполнение разработки T-SQL (DDL, DML, прием данных, транзакции, изменения схемы) в хранилище данных Microsoft Fabric и конечных точках SQL из агентных сред CLI. Используйте, когда пользователь хочет: (1) создавать/изменять/удалять таблицы из терминала, (2) вставлять/обновлять/удалять/объединять данные через CLI, (3) запускать прием COPY INTO или OPENROWSET, (4) управлять транзакциями или хранимыми процедурами, (5) выполнять эволюцию схемы, (6) использовать путешествия во времени или снимки, (7) генерировать сценарии оболочки ETL/ELT, (8) создавать представления/функции/процедуры в Lakehouse SQLEP. Триггеры: «создать таблицу в хранилище», «вставить данные через T-SQL», «загрузить из ADLS», «КОПИРОВАТЬ В TO», «запустить ETL с T-SQL», «изменить таблицу хранилища», «вставить с помощью T-SQL», «слить в хранилище», «создать процедуру T-SQL», «путешествие во времени в хранилище», «восстановить удаленные данные хранилища», «создать схему хранилища», «развернуть хранилище», «конфликт транзакций», «ошибка изоляции моментального снимка».
