Gestisci gli elementi dell'area di lavoro dei report di Power BI e le definizioni PBIR in Microsoft Fabric tramite la CLI "az rest" rispetto all'API REST di Fabric. Da utilizzare quando l'utente desidera: (1) caricare o pubblicare una definizione PBIR/report su Fabric, (2) ottenere o scaricare le definizioni dei report, (3) aggiornare le definizioni o le proprietà degli elementi del report, (4) elencare i report dell'area di lavoro, (5) eliminare i report. Per modificare file, pagine, elementi visivi, filtri, temi o formattazione PBIR, utilizzare "powerbi-report-authoring". Per domande aziendali sui dati dei report, utilizza "fabriciq". Trigger: caricare la definizione del report PBIR, caricare il report Power BI, scaricare la definizione PBIR, pubblicare la definizione PBIR, pubblicare il report Power BI su Fabric, gestire i report Power BI, elencare i report dell'area di lavoro.
