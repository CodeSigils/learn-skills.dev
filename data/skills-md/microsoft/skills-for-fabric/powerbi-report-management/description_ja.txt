Microsoft Fabric の Power BI レポート ワークスペース アイテムと PBIR 定義を、ファブリック REST API に対して `azrest` CLI を介して管理します。ユーザーが次のことを行う場合に使用します: (1) PBIR/レポート定義をファブリックにアップロードまたは公開する、(2) レポート定義を取得またはダウンロードする、(3) レポート項目定義またはプロパティを更新する、(4) ワークスペース レポートを一覧表示する、(5) レポートを削除する。 PBIR ファイル、ページ、ビジュアル、フィルター、テーマ、または書式設定を編集するには、「powerbi-report-authoring」を使用します。レポート データに関するビジネス上の質問には、「fabriciq」を使用します。トリガー: PBIR レポート定義のアップロード、Power BI レポートのアップロード、PBIR 定義のダウンロード、PBIR 定義の発行、Power BI レポートのファブリックへの発行、Power BI レポートの管理、ワークスペース レポートの一覧表示。
