Gérez les éléments de l'espace de travail des rapports Power BI et les définitions PBIR dans Microsoft Fabric via la CLI « az rest » par rapport à l'API REST Fabric. À utiliser lorsque l'utilisateur souhaite : (1) télécharger ou publier une définition de PBIR/de rapport sur Fabric, (2) obtenir ou télécharger des définitions de rapport, (3) mettre à jour les définitions ou les propriétés des éléments de rapport, (4) répertorier les rapports de l'espace de travail, (5) supprimer des rapports. Pour éditer des fichiers PBIR, des pages, des visuels, des filtres, des thèmes ou un formatage, utilisez « powerbi-report-authoring ». Pour les questions commerciales sur les données du rapport, utilisez « fabriciq ». Déclencheurs : télécharger la définition du rapport PBIR, télécharger le rapport Power BI, télécharger la définition PBIR, publier la définition PBIR, publier le rapport Power BI sur Fabric, gérer les rapports Power BI, répertorier les rapports d'espace de travail.
