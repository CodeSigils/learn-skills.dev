通过“az rest”CLI 根据 Fabric REST API 管理 Microsoft Fabric 中的 Power BI 报告工作区项目和 PBIR 定义。当用户想要执行以下操作时使用：(1) 将 PBIR/报告定义上传或发布到 Fabric，(2) 获取或下载报告定义，(3) 更新报告项定义或属性，(4) 列出工作区报告，(5) 删除报告。要编辑 PBIR 文件、页面、视觉效果、过滤器、主题或格式，请使用“powerbi-report-authoring”。对于有关报告数据的业务问题，请使用“fabriciq”。触发器：上传 PBIR 报告定义、上传 Power BI 报告、下载 PBIR 定义、发布 PBIR 定义、将 Power BI 报告发布到 Fabric、管理 Power BI 报告、列出工作区报告。
