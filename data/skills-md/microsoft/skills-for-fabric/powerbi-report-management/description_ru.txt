Управляйте элементами рабочей области отчетов Power BI и определениями PBIR в Microsoft Fabric с помощью интерфейса командной строки az rest с помощью API REST Fabric. Используйте, когда пользователь хочет: (1) загрузить или опубликовать определение PBIR/отчета в Fabric, (2) получить или загрузить определения отчетов, (3) обновить определения или свойства элементов отчета, (4) составить список отчетов рабочей области, (5) удалить отчеты. Для редактирования файлов PBIR, страниц, визуальных элементов, фильтров, тем или форматирования используйте powerbi-report-authoring. Для деловых вопросов по данным отчета используйте fabriciq. Триггеры: загрузка определения отчета PBIR, загрузка отчета Power BI, загрузка определения PBIR, публикация определения PBIR, публикация отчета Power BI в Fabric, управление отчетами Power BI, составление списка отчетов рабочей области.
