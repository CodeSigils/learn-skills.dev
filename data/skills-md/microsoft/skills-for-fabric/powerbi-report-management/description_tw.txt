透過「az rest」CLI 根據 Fabric REST API 管理 Microsoft Fabric 中的 Power BI 報告工作區專案和 PBIR 定義。當使用者想要執行以下操作時使用：(1) 將 PBIR/報告定義上傳或發佈到 Fabric，(2) 取得或下載報告定義，(3) 更新報告項目定義或屬性，(4) 列出工作區報告，(5) 刪除報告。若要編輯 PBIR 檔案、頁面、視覺效果、篩選器、主題或格式，請使用「powerbi-report-authoring」。對於有關報告資料的業務問題，請使用「fabriciq」。觸發器：上傳 PBIR 報表定義、上傳 Power BI 報表、下載 PBIR 定義、發佈 PBIR 定義、將 Power BI 報表發佈到 Fabric、管理 Power BI 報表、列出工作區報表。
