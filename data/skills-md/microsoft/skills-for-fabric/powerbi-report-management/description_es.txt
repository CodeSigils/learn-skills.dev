Administre elementos del espacio de trabajo de informes de Power BI y definiciones PBIR en Microsoft Fabric a través de la CLI `az rest` con la API REST de Fabric. Úselo cuando el usuario desee: (1) cargar o publicar una definición de informe/PBIR en Fabric, (2) obtener o descargar definiciones de informes, (3) actualizar definiciones o propiedades de elementos de informes, (4) enumerar informes del espacio de trabajo, (5) eliminar informes. Para editar archivos, páginas, elementos visuales, filtros, temas o formato PBIR, utilice `powerbi-report-authoring`. Para preguntas comerciales sobre datos de informes, utilice `fabriciq`. Desencadenadores: cargar la definición del informe PBIR, cargar el informe de Power BI, descargar la definición de PBIR, publicar la definición de PBIR, publicar el informe de Power BI en Fabric, administrar los informes de Power BI, enumerar los informes del espacio de trabajo.
