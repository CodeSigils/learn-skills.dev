Portieren Sie Databricks-Notebooks und -Jobs nach Microsoft Fabric. Bietet eine umfassende Tabelle zum Ersetzen von Dbutils durch Notebookutils: fs-Vorgänge (Entfernen von Bereitstellungen über OneLake-Verknüpfungen), Konvertierung von geheimen Bereichen in Key Vault-URLs, Ausführen und Beenden von Notebooks, Ersetzen von Widgets durch mit Parametern markierte Zellen und Ersetzen von Bibliotheksinstallationen durch Fabric-Umgebungen. Behandelt die dreistufige Reduzierung des Unity Catalog-Namespaces auf Lakehouse-zweistufige Schemata, die DBFS-Pfadkonvertierung in OneLake, Databricks-Jobs in Spark-Jobdefinitionen, die Entfernung von MLflow-Tracking-URIs und die Ersetzung von Photon durch Native Execution Engine. Verwenden Sie diese Option, wenn der Benutzer Folgendes möchte: (1) dbutils durch notebookutils ersetzen, (2) Unity Catalog-Namespaces auf Lakehouse-Schemas reduzieren, (3) Databricks-Jobs oder Delta Live Tables konvertieren möchte. Auslöser: „Migration von Databricks“, „Databricks zu Fabric“, „Dbutils zu Notebookutils“, „Dbutils Fabric“, „Unity-Katalogmigration“, „Dbfs zu Onelake“, „Databricks Notebook-Migration“, „Delta Live Tables Fabric“, „Photon Native Execution“.
