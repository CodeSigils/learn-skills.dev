Databricks ノートブックとジョブを Microsoft Fabric に移植します。 dbutils から Notebookutils への包括的な置換テーブルを提供します: fs 操作 (OneLake ショートカットによるマウント削除)、シークレット スコープから Key Vault URL への変換、ノートブックの実行と終了、パラメーター タグ付きセルによるウィジェットの置換、ファブリック環境によるライブラリ インストールの置換。 Unity カタログの 3 レベルの名前空間から Lakehouse の 2 レベルのスキーマへの削減、OneLake への DBFS パスの変換、Databricks ジョブから Spark ジョブ定義への変換、MLflow 追跡 URI の削除、Photon からネイティブ実行エンジンへの置換について説明します。ユーザーが次のことを行う場合に使用します: (1) dbutils を Notebookutils に置き換える、(2) Unity カタログの名前空間を Lakehouse スキーマに折りたたむ、(3) Databricks ジョブまたはデルタ ライブ テーブルを変換する。トリガー: 「databricks から移行」、「databricks からファブリック」、「dbutils から Notebookutils」、「dbutils ファブリック」、「unity カタログの移行」、「dbfs から onelake」、「databricks ノートブックの移行」、「デルタ ライブ テーブル ファブリック」、「フォトン ネイティブ実行」。
