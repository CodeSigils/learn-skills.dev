Переносите записные книжки и задания Databricks в Microsoft Fabric. Предоставляет исчерпывающую таблицу подстановки утилит для ноутбука: операции с файловой системой (удаление монтирования с помощью ярлыков OneLake), секретную область для преобразования URL-адресов Key Vault, запуск и выход из блокнота, замену виджета ячейками с тегами параметров и замену установки библиотеки с помощью среды Fabric. Охватывает сокращение трехуровневого пространства имен каталога Unity до двухуровневых схем Lakehouse, преобразование путей DBFS в OneLake, задания Databricks в определения заданий Spark, удаление URI отслеживания MLflow и замену Photon на Native Execution Engine. Используйте, когда пользователь хочет: (1) заменить dbutils на Notebookutils, (2) свернуть пространства имен каталога Unity в схемы Lakehouse, (3) преобразовать задания Databricks или дельта-живые таблицы. Триггеры: «миграция из блоков данных», «блоки данных в структуру», «dbutils в блокноты», «фабрика dbutils», «миграция каталога Unity», «dbfs в onelake», «миграция блоков данных в блокнот», «фабрика дельта-живых таблиц», «собственное выполнение Photon».
