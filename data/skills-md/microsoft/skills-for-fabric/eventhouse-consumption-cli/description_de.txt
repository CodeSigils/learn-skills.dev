Führen Sie KQL-Abfragen für Fabric Eventhouse aus, um Echtzeitinformationen und Zeitreihenanalysen zu erhalten, indem Sie „az rest“ für die Kusto REST API verwenden. Behandelt KQL-Operatoren (wo, zusammenfassen, verbinden, rendern), Eventhouse-Schemaerkennung (.show-Tabellen), Zeitreihenmuster mit bin() und Aufnahmeüberwachung. Verwenden Sie es, wenn der Benutzer Folgendes möchte:
  1. Führen Sie schreibgeschützte KQL-Abfragen für eine Eventhouse- oder KQL-Datenbank aus
  2. Entdecken Sie das Eventhouse-Tabellenschema und die Metadaten
  3. Analysieren Sie Echtzeit- oder Zeitreihendaten mit KQL-Operatoren
  4. Überwachen Sie den Zustand der Aufnahme und aktive KQL-Abfragen
  5. Exportieren Sie KQL-Ergebnisse nach JSON
