قم بتشغيل استعلامات KQL مقابل Fabric Eventhouse للحصول على معلومات في الوقت الفعلي وتحليلات السلاسل الزمنية باستخدام "az Rest" مقابل Kusto REST API. يغطي مشغلي KQL (حيث، التلخيص، الانضمام، العرض)، واكتشاف مخطط Eventhouse (إظهار الجداول)، وأنماط السلاسل الزمنية باستخدام bin()، ومراقبة الاستيعاب. استخدم عندما يريد المستخدم:
  1. قم بتشغيل استعلامات KQL للقراءة فقط مقابل Eventhouse أو قاعدة بيانات KQL
  2. اكتشف مخطط جدول Eventhouse والبيانات التعريفية
  3. تحليل البيانات في الوقت الحقيقي أو بيانات السلاسل الزمنية مع مشغلي KQL
  4. مراقبة صحة الاستيعاب واستعلامات KQL النشطة
  5. تصدير نتائج KQL إلى JSON
