Выполняйте запросы KQL к Fabric Eventhouse для получения аналитических данных в реальном времени и анализа временных рядов, используя az rest для API Kusto REST. Охватывает операторы KQL (где, суммирование, объединение, рендеринг), обнаружение схемы Eventhouse (таблицы .show), шаблоны временных рядов с помощью bin() и мониторинг приема. Используйте, когда пользователь хочет:
  1. Выполните запросы KQL только для чтения к базе данных Eventhouse или KQL.
  2. Откройте для себя схему и метаданные таблицы Eventhouse.
  3. Анализ данных в реальном времени или временных рядов с помощью операторов KQL.
  4. Отслеживайте работоспособность приема и активные запросы KQL.
  5. Экспортируйте результаты KQL в JSON.
