Реализуйте комплексные шаблоны архитектуры Medallion (Bronze/Silver/Gold) в Microsoft Fabric с помощью PySpark, Delta Lake и Fabric Pipelines. Используйте, когда пользователь хочет: (1) спроектировать озеро данных уровня Bronze/Silver/Gold, (2) настроить многоуровневое рабочее пространство с озерами для каждого уровня, (3) построить конвейеры приема-аналитики с обеспечением качества данных, (4) оптимизировать конфигурации Spark для каждого уровня медальона, (5) организовать потоки от уровня Bronze к Silver к Gold через блокноты. Триггеры: «архитектура медальона», «бронза, серебро, золото», «слои озера», «конвейер данных e2e», «сквозной дом озера», «шаблон дома озера данных», «многослойный дом озера», «построить медальон», «настроить медальон».
