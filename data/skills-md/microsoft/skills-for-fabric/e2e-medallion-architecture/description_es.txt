Implemente patrones de casa de lago de Medallion Architecture (Bronce/Plata/Oro) de un extremo a otro en Microsoft Fabric utilizando PySpark, Delta Lake y Fabric Pipelines. Úselo cuando el usuario desee: (1) diseñar una casa de lago de datos Bronce/Plata/Oro, (2) configurar un espacio de trabajo de múltiples capas con casas de lago para cada nivel, (3) crear canalizaciones de ingesta a análisis con aplicación de calidad de datos, (4) optimizar las configuraciones de Spark por capa de medallón, (5) orquestar flujos de Bronce a Plata a Oro a través de cuadernos.
