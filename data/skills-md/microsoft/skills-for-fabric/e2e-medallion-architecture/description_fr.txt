Implémentez des modèles Lakehouse de bout en bout avec l'architecture médaillon (Bronze/Argent/Or) dans Microsoft Fabric à l'aide de PySpark, Delta Lake et Fabric Pipelines. À utiliser lorsque l'utilisateur souhaite : (1) concevoir un lac de données Bronze/Argent/Or, (2) configurer un espace de travail multicouche avec des lacs pour chaque niveau, (3) créer des pipelines d'ingestion vers l'analyse avec application de la qualité des données, (4) optimiser les configurations Spark par couche médaillon, (5) orchestrer les flux Bronze vers Argent vers Or via des notebooks. Déclencheurs : « architecture médaillon », « bronze argent or », « couches Lakehouse », « pipeline de données e2e », « Lakehouse de bout en bout », « modèle de Lakehouse de données », « Lakehouse multicouche », « construire un médaillon », « médaillon de configuration ».
