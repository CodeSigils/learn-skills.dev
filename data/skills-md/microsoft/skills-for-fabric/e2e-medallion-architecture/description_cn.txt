使用 PySpark、Delta Lake 和 Fabric Pipelines 在 Microsoft Fabric 中实现端到端 Medallion 架构（铜牌/银牌/金牌）lakehouse 模式。当用户想要执行以下操作时使用：(1) 设计铜牌/银牌/金牌数据 Lakehouse，(2) 设置多层工作区，并为每层设置 Lakehouse，(3) 构建具有数据质量强制执行的摄取到分析管道，(4) 优化每个奖章层的 Spark 配置，(5) 通过笔记本编排铜牌到银牌到金牌的流程。触发器：“徽章架构”、“青铜银金”、“lakehouse 层”、“e2e 数据管道”、“端到端 Lakehouse”、“数据 Lakehouse 模式”、“多层 Lakehouse”、“构建徽章”、“设置徽章”。
