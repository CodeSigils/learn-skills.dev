Проверьте обновления рынка навыков для тканей в начале сеанса. Сравнивает локальную версию с выпусками GitHub и показывает журнал изменений, если доступны обновления. Используйте, когда пользователь хочет: (1) проверить наличие обновлений навыков, (2) узнать, что нового в навыках для ткани, (3) проверить текущую версию. Триггеры: «проверить наличие обновлений», «я в курсе», «какая версия», «обновить навыки», «показать журнал изменений».
