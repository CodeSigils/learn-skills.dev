透過 Fabric Items REST API 列出、檢查和監控 Microsoft Fabric Eventstream 即時事件攝取管道。發現跨工作區的事件流，解碼 Base64 編碼的圖形拓撲，以追蹤從來源到運算子到目標節點的事件流。驗證來源連線 ID、目標連線、保留策略（1-90 天）和吞吐量水準。當使用者想要執行以下操作時使用：(1) 列出或搜尋工作區中的 Eventstream，(2) 解碼並追蹤從來源到目標的圖形拓撲，(3) 驗證來源和目標配置，(4) 檢查保留和吞吐量設定。觸發器：「列出事件流」、「顯示事件流」、「檢查事件流」、「解釋事件流」、「事件流運行狀況」、「監視事件流」、「描述事件流」、「檢查事件流配置」、「事件流保留」。
