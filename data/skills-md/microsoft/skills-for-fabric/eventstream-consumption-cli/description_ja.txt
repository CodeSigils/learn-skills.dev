Fabric Items REST API を介して、Microsoft Fabric Eventstream リアルタイム イベント取り込みパイプラインを一覧表示、検査、監視します。ワークスペース全体でイベントストリームを検出し、base64 でエンコードされたグラフ トポロジをデコードして、ソースからオペレーターを経て宛先ノードまでのイベント フローを追跡します。ソース接続 ID、宛先配線、保持ポリシー (1 ～ 90 日)、およびスループット レベルを検証します。ユーザーが次のことを行う場合に使用します: (1) ワークスペース内のイベントストリームのリストまたは検索、(2) ソースから宛先までのグラフ トポロジのデコードとトレース、(3) ソースと宛先の構成の検証、(4) 保持およびスループットの設定の確認。トリガー: 「イベントストリームのリスト」、「イベントストリームの表示」、「イベントストリームの検査」、「イベントストリームの説明」、「イベントストリームの健全性」、「イベントストリームの監視」、「イベントストリームの説明」、「イベントストリーム構成の確認」、「イベントストリーム保持」。
