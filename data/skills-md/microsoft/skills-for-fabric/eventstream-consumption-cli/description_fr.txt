Répertoriez, inspectez et surveillez les pipelines d'ingestion d'événements en temps réel Microsoft Fabric Eventstream via l'API REST Fabric Items. Découvrez les flux d'événements dans les espaces de travail, décodez les topologies de graphiques codées en base64 pour tracer le flux d'événements depuis la source jusqu'aux nœuds de destination en passant par les opérateurs. Validez les ID de connexion source, le câblage de destination, les politiques de rétention (1 à 90 jours) et les niveaux de débit. À utiliser lorsque l'utilisateur souhaite : (1) répertorier ou rechercher des flux d'événements dans un espace de travail, (2) décoder et tracer la topologie du graphique de la source à la destination, (3) valider les configurations source et de destination, (4) vérifier les paramètres de rétention et de débit. Déclencheurs : "lister les flux d'événements", "afficher le flux d'événements", "inspecter le flux d'événements", "expliquer le flux d'événements", "état de santé du flux d'événements", "surveiller le flux d'événements", "décrire le flux d'événements", "vérifier la configuration du flux d'événements", "rétention du flux d'événements".
