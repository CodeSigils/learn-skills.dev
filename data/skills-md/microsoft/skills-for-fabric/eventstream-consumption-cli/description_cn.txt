通过 Fabric Items REST API 列出、检查和监控 Microsoft Fabric Eventstream 实时事件摄取管道。发现跨工作区的事件流，解码 Base64 编码的图形拓扑，以跟踪从源到运算符到目标节点的事件流。验证源连接 ID、目标连接、保留策略（1-90 天）和吞吐量水平。当用户想要执行以下操作时使用：(1) 列出或搜索工作区中的 Eventstream，(2) 解码并跟踪从源到目标的图形拓扑，(3) 验证源和目标配置，(4) 检查保留和吞吐量设置。触发器：“列出事件流”、“显示事件流”、“检查事件流”、“解释事件流”、“事件流运行状况”、“监视事件流”、“描述事件流”、“检查事件流配置”、“事件流保留”。
