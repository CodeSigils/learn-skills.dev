Fabric Livy セッションと PySpark/Spark SQL を使用してレイクハウス データを対話的に分析し、高度な分析、DataFrame、クロスレイクハウス結合、デルタ タイムトラベル、非構造化/JSON データを実現します。ユーザーが PySpark、Spark DataFrames、Livy セッション、または Python ベースの分析を明示的に要求する場合に使用します (単純な SQL クエリの場合ではありません)。トリガー: 「PySpark」、「Spark SQL」、「PySpark による分析」、「Spark DataFrame」、「Livy セッション」、「Python によるレイクハウス」、「PySpark 分析」、「PySpark データ品質」、「Spark によるデルタ タイムトラベル」。
