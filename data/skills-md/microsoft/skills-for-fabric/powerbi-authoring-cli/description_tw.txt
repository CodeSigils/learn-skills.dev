透過「az rest」CLI 針對 Fabric 和 Power BI REST API 在 Microsoft Fabric 工作區中建立、管理和部署 Power BI 語意模型。當使用者想要執行下列操作時使用：(1) 從 TMDL 定義檔建立語意模型，(2) 擷取或下載語意模型定義，(3) 使用修改後的 TMDL 更新語意模型定義，(4) 觸發或管理資料集刷新操作，(5) 設定資料來源、參數或權限，(6) 在管道階段之間部署語意模型。涵蓋 Fabric Items API (CRUD) 和 Power BI Datasets API（刷新、資料來源、權限）。對於唯讀 DAX 查詢，請使用「powerbi-consumation-cli」。對於細粒度的建模更改，請路由至“powerbi-modeling-mcp”。觸發器：「建立語意模型」、「上傳 TMDL」、「下載語意模型 TMDL」、「刷新資料集」、「語意模型部署管道」、「資料集權限」、「列出資料集使用者」、「語意模型創作」。
