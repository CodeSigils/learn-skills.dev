Erstellen, verwalten und stellen Sie semantische Power BI-Modelle in Microsoft Fabric-Arbeitsbereichen über die „az rest“-CLI für Fabric- und Power BI-REST-APIs bereit. Verwenden Sie diese Option, wenn der Benutzer Folgendes möchte: (1) ein semantisches Modell aus TMDL-Definitionsdateien erstellen, (2) semantische Modelldefinitionen abrufen oder herunterladen, (3) eine semantische Modelldefinition mit geändertem TMDL aktualisieren, (4) Datensatzaktualisierungsvorgänge auslösen oder verwalten, (5) Datenquellen, Parameter oder Berechtigungen konfigurieren, (6) semantische Modelle zwischen Pipeline-Stufen bereitstellen. Deckt die Fabric Items API (CRUD) und die Power BI Datasets API (Aktualisierung, Datenquellen, Berechtigungen) ab. Für schreibgeschützte DAX-Abfragen verwenden Sie „powerbi-consumption-cli“. Für feinkörnige Modellierungsänderungen leiten Sie zu „powerbi-modeling-mcp“ weiter. Auslöser: „Semantisches Modell erstellen“, „TMDL hochladen“, „Semantisches Modell TMDL herunterladen“, „Datensatz aktualisieren“, „Semantikmodell-Bereitstellungspipeline“, „Datensatzberechtigungen“, „Datensatzbenutzer auflisten“, „Erstellung semantischer Modelle“.
