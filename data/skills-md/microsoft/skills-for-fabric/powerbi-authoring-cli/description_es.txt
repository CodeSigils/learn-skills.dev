Cree, administre e implemente modelos semánticos de Power BI dentro de las áreas de trabajo de Microsoft Fabric a través de la CLI `az rest` contra las API REST de Fabric y Power BI. Úselo cuando el usuario desee: (1) crear un modelo semántico a partir de archivos de definición TMDL, (2) recuperar o descargar definiciones de modelos semánticos, (3) actualizar una definición de modelo semántico con TMDL modificado, (4) activar o administrar operaciones de actualización de conjuntos de datos, (5) configurar fuentes de datos, parámetros o permisos, (6) implementar modelos semánticos entre etapas de canalización. Cubre la API de elementos de tela (CRUD) y la API de conjuntos de datos de Power BI (actualización, orígenes de datos, permisos). Para consultas DAX de solo lectura, utilice `powerbi-consumption-cli`. Para cambios de modelado detallados, diríjase a `powerbi-modeling-mcp`. Activadores: "crear modelo semántico", "cargar TMDL", "descargar modelo semántico TMDL", "actualizar conjunto de datos", "canal de implementación del modelo semántico", "permisos del conjunto de datos", "listar usuarios del conjunto de datos", "autoría del modelo semántico".
