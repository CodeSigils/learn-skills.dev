Fabric 및 Power BI REST API에 대한 'az Rest' CLI를 통해 Microsoft Fabric 작업 영역 내에서 Power BI 의미 체계 모델을 생성, 관리 및 배포합니다. 사용자가 (1) TMDL 정의 파일에서 의미 체계 모델 생성, (2) 의미 체계 모델 정의 검색 또는 다운로드, (3) 수정된 TMDL로 의미 체계 모델 정의 업데이트, (4) 데이터세트 새로 고침 작업 트리거 또는 관리, (5) 데이터 소스, 매개변수 또는 권한 구성, (6) 파이프라인 단계 간에 의미 체계 모델 배포를 원할 때 사용합니다. CRUD(패브릭 항목 API) 및 Power BI 데이터 세트 API(새로 고침, 데이터 원본, 권한)를 다룹니다. 읽기 전용 DAX 쿼리의 경우 'powerbi-consumption-cli'를 사용하세요. 세분화된 모델링 변경을 위해서는 'powerbi-modeling-mcp'로 라우팅하세요. 트리거: "의미 체계 모델 생성", "TMDL 업로드", "의미 체계 모델 TMDL 다운로드", "데이터 세트 새로 고침", "의미 체계 모델 배포 파이프라인", "데이터 세트 권한", "데이터 세트 사용자 목록", "의미 체계 모델 작성".
