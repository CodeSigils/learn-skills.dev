Créez, gérez et déployez des modèles sémantiques Power BI dans les espaces de travail Microsoft Fabric via la CLI « az rest » sur les API REST Fabric et Power BI. À utiliser lorsque l'utilisateur souhaite : (1) créer un modèle sémantique à partir de fichiers de définition TMDL, (2) récupérer ou télécharger des définitions de modèle sémantique, (3) mettre à jour une définition de modèle sémantique avec TMDL modifié, (4) déclencher ou gérer des opérations d'actualisation d'ensemble de données, (5) configurer des sources de données, des paramètres ou des autorisations, (6) déployer des modèles sémantiques entre les étapes du pipeline. Couvre l’API Fabric Items (CRUD) et l’API Power BI Datasets (actualisation, sources de données, autorisations). Pour les requêtes DAX en lecture seule, utilisez « powerbi-consumption-cli ». Pour des modifications de modélisation plus fines, accédez à « powerbi-modeling-mcp ». Déclencheurs : "créer un modèle sémantique", "télécharger TMDL", "télécharger le modèle sémantique TMDL", "actualiser l'ensemble de données", "pipeline de déploiement de modèle sémantique", "autorisations d'ensemble de données", "lister les utilisateurs de l'ensemble de données", "création de modèle sémantique".
