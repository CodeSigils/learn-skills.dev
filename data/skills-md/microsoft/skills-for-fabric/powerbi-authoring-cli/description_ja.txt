Fabric および Power BI REST API に対して `azrest` CLI を介して、Microsoft Fabric ワークスペース内で Power BI セマンティック モデルを作成、管理、デプロイします。ユーザーが次のことを行う場合に使用します: (1) TMDL 定義ファイルからセマンティック モデルを作成する、(2) セマンティック モデル定義を取得またはダウンロードする、(3) 変更された TMDL でセマンティック モデル定義を更新する、(4) データセット更新操作をトリガーまたは管理する、(5) データ ソース、パラメーター、または権限を構成する、(6) パイプライン ステージ間でセマンティック モデルをデプロイする。 Fabric Items API (CRUD) と Power BI Datasets API (更新、データ ソース、アクセス許可) について説明します。読み取り専用の DAX クエリの場合は、「powerbi-consumption-cli」を使用します。きめ細かいモデリング変更の場合は、「powerbi-modeling-mcp」にルーティングします。トリガー: 「セマンティック モデルの作成」、「TMDL のアップロード」、「セマンティック モデル TMDL のダウンロード」、「データセットの更新」、「セマンティック モデル展開パイプライン」、「データセットのアクセス許可」、「データセット ユーザーのリスト」、「セマンティック モデルのオーサリング」。
