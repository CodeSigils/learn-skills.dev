Создавайте, управляйте и развертывайте семантические модели Power BI в рабочих пространствах Microsoft Fabric с помощью интерфейса командной строки az rest с использованием REST API Fabric и Power BI. Используйте, когда пользователь хочет: (1) создать семантическую модель из файлов определений TMDL, (2) получить или загрузить определения семантической модели, (3) обновить определение семантической модели с помощью измененного TMDL, (4) запустить или управлять операциями обновления набора данных, (5) настроить источники данных, параметры или разрешения, (6) развернуть семантические модели между этапами конвейера. Охватывает API элементов структуры (CRUD) и API наборов данных Power BI (обновление, источники данных, разрешения). Для запросов DAX только для чтения используйте powerbi-consumption-cli. Для более детальных изменений моделирования перейдите к `powerbi-modeling-mcp`. Триггеры: «создать семантическую модель», «загрузить TMDL», «загрузить семантическую модель TMDL», «обновить набор данных», «конвейер развертывания семантической модели», «разрешения набора данных», «список пользователей набора данных», «разработка семантической модели».
