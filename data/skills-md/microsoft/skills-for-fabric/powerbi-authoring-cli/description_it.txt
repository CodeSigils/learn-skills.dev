Crea, gestisci e distribuisci modelli semantici di Power BI all'interno delle aree di lavoro Microsoft Fabric tramite la CLI "az rest" rispetto alle API REST Fabric e Power BI. Utilizzare quando l'utente desidera: (1) creare un modello semantico dai file di definizione TMDL, (2) recuperare o scaricare le definizioni del modello semantico, (3) aggiornare una definizione del modello semantico con TMDL modificato, (4) attivare o gestire operazioni di aggiornamento del set di dati, (5) configurare origini dati, parametri o autorizzazioni, (6) distribuire modelli semantici tra le fasi della pipeline. Copre l'API Fabric Items (CRUD) e l'API Datasets di Power BI (aggiornamento, origini dati, autorizzazioni). Per le query DAX di sola lettura, utilizzare "powerbi-consumption-cli". Per modifiche di modellazione a grana fine, indirizzare a "powerbi-modeling-mcp". Trigger: "crea modello semantico", "carica TMDL", "scarica modello semantico TMDL", "aggiorna set di dati", "pipeline di distribuzione del modello semantico", "autorizzazioni set di dati", "elenco utenti set di dati", "creazione di modello semantico".
