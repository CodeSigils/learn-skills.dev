قم بإنشاء نماذج دلالية Power BI وإدارتها ونشرها داخل مساحات عمل Microsoft Fabric عبر واجهة سطر الأوامر "az Rest" مقابل واجهات برمجة تطبيقات Fabric وPower BI REST. يُستخدم عندما يريد المستخدم: (1) إنشاء نموذج دلالي من ملفات تعريف TMDL، (2) استرداد تعريفات النماذج الدلالية أو تنزيلها، (3) تحديث تعريف النموذج الدلالي باستخدام TMDL المعدل، (4) تشغيل عمليات تحديث مجموعة البيانات أو إدارتها، (5) تكوين مصادر البيانات أو المعلمات أو الأذونات، (6) نشر النماذج الدلالية بين مراحل التدفق. يغطي واجهة برمجة تطبيقات عناصر النسيج (CRUD) وواجهة برمجة تطبيقات Power BI Datasets (التحديث ومصادر البيانات والأذونات). بالنسبة لاستعلامات DAX للقراءة فقط، استخدم "powerbi-consumption-cli". لإجراء تغييرات دقيقة على النماذج، قم بالتوجيه إلى "powerbi-modeling-mcp". المشغلات: "إنشاء نموذج دلالي"، "تحميل TMDL"، "تنزيل النموذج الدلالي TMDL"، "تحديث مجموعة البيانات"، "خط أنابيب نشر النموذج الدلالي"، "أذونات مجموعة البيانات"، "قائمة مستخدمي مجموعة البيانات"، "تأليف النموذج الدلالي".
