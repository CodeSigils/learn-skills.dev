通过“az rest”CLI 针对 Fabric 和 Power BI REST API 在 Microsoft Fabric 工作区中创建、管理和部署 Power BI 语义模型。当用户想要执行以下操作时使用：(1) 从 TMDL 定义文件创建语义模型，(2) 检索或下载语义模型定义，(3) 使用修改后的 TMDL 更新语义模型定义，(4) 触发或管理数据集刷新操作，(5) 配置数据源、参数或权限，(6) 在管道阶段之间部署语义模型。涵盖 Fabric Items API (CRUD) 和 Power BI Datasets API（刷新、数据源、权限）。对于只读 DAX 查询，请使用“powerbi-consumation-cli”。对于细粒度的建模更改，请路由至“powerbi-modeling-mcp”。触发器：“创建语义模型”、“上传 TMDL”、“下载语义模型 TMDL”、“刷新数据集”、“语义模型部署管道”、“数据集权限”、“列出数据集用户”、“语义模型创作”。
