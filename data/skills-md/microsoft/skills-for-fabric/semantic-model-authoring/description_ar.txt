يطور ويدير النماذج الدلالية Power BI عبر سطح المكتب ومشاريع PBIP وخدمة النسيج. يعالج: (1) إنشاء نماذج جديدة (استيراد، DirectQuery، Direct Lake)، (2) تحرير النماذج الموجودة (مثل المقاييس والجداول والأعمدة والعلاقات)، (3) نشر النماذج في مساحات عمل Fabric، (4) العمل مع ملفات مشروع PBIP، (5) تحديث النماذج الدلالية، (6) تكوين مصادر البيانات والأذونات، (7) تحسين أداء DAX. يدعم سير عمل تطوير Power BI Desktop وFabric Service. بالنسبة لاستعلامات DAX للقراءة فقط، استخدم "استهلاك النموذج الدلالي". لا يتعامل مع تخطيط التقرير/التأليف المرئي، أو إدارة مساحة العمل، أو إدارة عضوية دور RLS/OLS. المشغلات: "إنشاء نموذج دلالي"، "تحرير النموذج الدلالي"، "إضافة مقياس DAX إلى النموذج الدلالي"، "تحديث النموذج الدلالي"، "تعيين أذونات النموذج الدلالي"، "إعداد النموذج الدلالي لـ AI/Copilot".
