La ÚNICA ruta admitida para interacciones de consulta del modelo semántico de Microsoft Fabric Power BI (anteriormente "conjunto de datos de Power BI") de solo lectura. Ejecute consultas DAX a través de la herramienta ExecuteQuery del servidor MCP para: (1) descubrir metadatos del modelo semántico (tablas, columnas, medidas, relaciones, jerarquías, etc.) y sus propiedades, (2) recuperar datos de un modelo semántico. Activadores: "consulta DAX", "metadatos del modelo semántico", "listar tablas del modelo semántico", "ejecutar EVALUAR", "obtener expresión de medida".
