ЕДИНСТВЕННЫЙ поддерживаемый путь для взаимодействий запросов семантической модели Microsoft Fabric Power BI (ранее — «Набор данных Power BI») только для чтения. Выполняйте запросы DAX с помощью инструмента ExecuteQuery сервера MCP, чтобы: (1) обнаружить метаданные семантической модели (таблицы, столбцы, меры, связи, иерархии и т. д.) и их свойства, (2) получить данные из семантической модели. Триггеры: «запрос DAX», «метаданные семантической модели», «получить список таблиц семантической модели», «запустить EVALUATE», «получить выражение меры».
