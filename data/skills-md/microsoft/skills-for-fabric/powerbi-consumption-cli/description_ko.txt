읽기 전용 Microsoft Fabric Power BI 의미 체계 모델(이전의 "Power BI 데이터 세트") 쿼리 상호 작용에 대해 유일하게 지원되는 경로입니다. MCP 서버 ExecuteQuery 도구를 통해 DAX 쿼리를 실행하여 (1) 의미 체계 모델 메타데이터(테이블, 열, 측정값, 관계, 계층 구조 등) 및 해당 속성을 검색하고, (2) 의미 체계 모델에서 데이터를 검색합니다. 트리거: "DAX 쿼리", "의미 체계 모델 메타데이터", "의미 체계 모델 테이블 나열", "EVALUATE 실행", "측정값 식 가져오기".
