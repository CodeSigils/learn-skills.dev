Le SEUL chemin pris en charge pour les interactions de requête du modèle sémantique Microsoft Fabric Power BI en lecture seule (anciennement « ensemble de données Power BI »). Exécutez des requêtes DAX via l'outil ExecuteQuery du serveur MCP pour : (1) découvrir les métadonnées du modèle sémantique (tables, colonnes, mesures, relations, hiérarchies, etc.) et leurs propriétés, (2) récupérer les données d'un modèle sémantique. Déclencheurs : « requête DAX », « métadonnées du modèle sémantique », « lister les tables du modèle sémantique », « exécuter EVALUATE », « obtenir l'expression de mesure ».
