読み取り専用の Microsoft Fabric Power BI セマンティック モデル (以前の「Power BI データセット」) クエリ相互作用でのみサポートされているパス。 MCP サーバーの ExecuteQuery ツールを介して DAX クエリを実行して、(1) セマンティック モデルのメタデータ (テーブル、列、メジャー、リレーションシップ、階層など) とそのプロパティを検出します。(2) セマンティック モデルからデータを取得します。トリガー: 「DAX クエリ」、「セマンティック モデル メタデータ」、「セマンティック モデル テーブルのリスト」、「EVALUATE の実行」、「メジャー式の取得」。
