L'UNICO percorso supportato per le interazioni di query del modello semantico Microsoft Fabric Power BI di sola lettura (in precedenza "set di dati di Power BI"). Eseguire query DAX tramite lo strumento ExecuteQuery del server MCP per: (1) individuare i metadati del modello semantico (tabelle, colonne, misure, relazioni, gerarchie e così via) e le relative proprietà, (2) recuperare i dati da un modello semantico. Trigger: "query DAX", "metadati del modello semantico", "elenca tabelle del modello semantico", "esegui EVALUATE", "ottieni espressione di misura".
