MCP サーバーの ExecuteQuery ツールを介して、生の DAX クエリを実行し、Microsoft Fabric Power BI セマンティック モデルのメタデータを検査します。ユーザーが作成する DAX をすでに知っている場合、EVALUATE ステートメントを実行したい場合、または INFO 関数を使用してモデルのメタデータ (テーブル、列、メジャー、リレーションシップ、階層) を検査する必要がある場合に使用します。自然言語のビジネス質問 (DAX を生成する場所) の場合は、`fabriciq` を使用します。セマンティック モデル定義を作成、デプロイ、または管理するには、`semantic-model-authoring` を使用します。トリガー: 「DAX クエリの実行」、「EVALUATE の実行」、「セマンティック モデルのメタデータ」、「セマンティック モデル テーブルの一覧表示」、「INFO.VIEW.TABLES」、「メジャー式の取得」、「DAX に対するクエリ」、「モデルのクエリ」。
