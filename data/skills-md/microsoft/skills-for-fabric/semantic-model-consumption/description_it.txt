Esegui query DAX non elaborate e controlla i metadati dei modelli semantici di Microsoft Fabric Power BI tramite lo strumento ExecuteQuery del server MCP. Da utilizzare quando l'utente conosce già il DAX da scrivere, vuole eseguire istruzioni EVALUATE o deve controllare i metadati del modello (tabelle, colonne, misure, relazioni, gerarchie) utilizzando le funzioni INFO. Per domande aziendali in linguaggio naturale (dove si genera il DAX), utilizzare "fabriciq". Per creare, distribuire o gestire le definizioni del modello semantico, utilizzare "semantic-model-authoring". Trigger: "esegui query DAX", "esegui EVALUATE", "metadati del modello semantico", "elenca tabelle del modello semantico", "INFO.VIEW.TABLES", "ottieni espressione di misura", "DAX contro", "interroga il modello".
