Führen Sie rohe DAX-Abfragen aus und überprüfen Sie Metadaten der semantischen Modelle von Microsoft Fabric Power BI über das ExecuteQuery-Tool des MCP-Servers. Verwenden Sie diese Option, wenn der Benutzer den zu schreibenden DAX bereits kennt, EVALUATE-Anweisungen ausführen möchte oder Modellmetadaten (Tabellen, Spalten, Kennzahlen, Beziehungen, Hierarchien) mithilfe von INFO-Funktionen überprüfen muss. Für Geschäftsfragen in natürlicher Sprache (bei denen Sie den DAX generieren) verwenden Sie „fabriciq“. Verwenden Sie zum Erstellen, Bereitstellen oder Verwalten semantischer Modelldefinitionen „semantic-model-authoring“. Auslöser: „DAX-Abfrage ausführen“, „BEWERTUNG ausführen“, „Metadaten des semantischen Modells“, „Tabellen des semantischen Modells auflisten“, „INFO.VIEW.TABLES“, „Maßausdruck abrufen“, „DAX gegen“, „Modell abfragen“.
