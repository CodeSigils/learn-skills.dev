通过 MCP 服务器 ExecuteQuery 工具执行原始 DAX 查询并检查 Microsoft Fabric Power BI 语义模型的元数据。当用户已经知道要编写的 DAX、想要运行 EVALUATE 语句或需要使用 INFO 函数检查模型元数据（表、列、度量、关系、层次结构）时使用。对于自然语言业务问题（生成 DAX 的位置），请使用“fabriciq”。要创建、部署或管理语义模型定义，请使用“语义模型创作”。触发器：“运行 DAX 查询”、“执行 EVALUATE”、“语义模型元数据”、“列出语义模型表”、“INFO.VIEW.TABLES”、“获取度量表达式”、“DAX 针对”、“查询模型”。
