Ejecute consultas DAX sin formato e inspeccione metadatos de modelos semánticos de Microsoft Fabric Power BI a través de la herramienta ExecuteQuery del servidor MCP. Úselo cuando el usuario ya sabe qué DAX debe escribir, desea ejecutar declaraciones EVALUATE o necesita inspeccionar los metadatos del modelo (tablas, columnas, medidas, relaciones, jerarquías) utilizando funciones INFO. Para preguntas comerciales en lenguaje natural (donde genera el DAX), utilice `fabriciq`. Para crear, implementar o gestionar definiciones de modelos semánticos, utilice "autoría de modelos semánticos". Activadores: "ejecutar consulta DAX", "ejecutar EVALUAR", "metadatos del modelo semántico", "listar tablas del modelo semántico", "INFO.VIEW.TABLES", "obtener expresión de medida", "DAX contra", "consultar el modelo".
