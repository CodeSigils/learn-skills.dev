Exécutez des requêtes DAX brutes et inspectez les métadonnées des modèles sémantiques Microsoft Fabric Power BI via l'outil ExecuteQuery du serveur MCP. À utiliser lorsque l'utilisateur connaît déjà le DAX à écrire, souhaite exécuter des instructions EVALUATE ou doit inspecter les métadonnées du modèle (tables, colonnes, mesures, relations, hiérarchies) à l'aide des fonctions INFO. Pour les questions commerciales en langage naturel (où vous générez le DAX), utilisez « fabriciq ». Pour créer, déployer ou gérer des définitions de modèles sémantiques, utilisez « semantic-model-authoring ». Déclencheurs : "exécuter une requête DAX", "exécuter EVALUATE", "métadonnées du modèle sémantique", "lister les tables du modèle sémantique", "INFO.VIEW.TABLES", "obtenir l'expression de mesure", "DAX contre", "interroger le modèle".
