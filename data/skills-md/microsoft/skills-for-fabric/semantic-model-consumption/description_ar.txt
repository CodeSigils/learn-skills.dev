قم بتنفيذ استعلامات DAX الأولية وفحص البيانات التعريفية للنماذج الدلالية لـ Microsoft Fabric Power BI عبر أداة ExecuteQuery لخادم MCP. يُستخدم عندما يعرف المستخدم بالفعل DAX المراد كتابته، أو يريد تشغيل عبارات التقييم، أو يحتاج إلى فحص بيانات تعريف النموذج (الجداول والأعمدة والمقاييس والعلاقات والتسلسلات الهرمية) باستخدام وظائف INFO. بالنسبة لأسئلة الأعمال باللغة الطبيعية (حيث تقوم بإنشاء DAX)، استخدم "fabriciq". لإنشاء تعريفات النماذج الدلالية أو نشرها أو إدارتها، استخدم "تأليف النموذج الدلالي". المشغلات: "تشغيل استعلام DAX"، "تنفيذ تقييم"، "بيانات تعريف النموذج الدلالي"، "إدراج جداول النماذج الدلالية"، "INFO.VIEW.TABLES"، "الحصول على تعبير القياس"، "DAX مقابل"، "الاستعلام عن النموذج".
