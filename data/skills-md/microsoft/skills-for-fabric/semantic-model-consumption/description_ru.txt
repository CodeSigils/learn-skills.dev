Выполняйте необработанные запросы DAX и проверяйте метаданные семантических моделей Microsoft Fabric Power BI с помощью инструмента ExecuteQuery сервера MCP. Используйте, когда пользователь уже знает DAX для записи, хочет выполнить инструкции EVALUATE или ему необходимо проверить метаданные модели (таблицы, столбцы, меры, связи, иерархии) с помощью функций INFO. Для бизнес-вопросов на естественном языке (когда вы генерируете DAX) используйте fabriciq. Для создания, развертывания или управления определениями семантической модели используйте `semantic-model-authoring`. Триггеры: «запустить запрос DAX», «выполнить EVALUATE», «метаданные семантической модели», «получить список таблиц семантической модели», «INFO.VIEW.TABLES», «получить выражение меры», «DAX против», «запросить модель».
