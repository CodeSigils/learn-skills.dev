透過 MCP 伺服器 ExecuteQuery 工具執行原始 DAX 查詢並檢查 Microsoft Fabric Power BI 語意模型的元資料。當使用者已經知道要編寫的 DAX、想要執行 EVALUATE 語句或需要使用 INFO 函數檢查模型元資料（表、列、度量、關係、層次結構）時使用。對於自然語言業務問題（產生 DAX 的位置），請使用「fabriciq」。若要建立、部署或管理語意模型定義，請使用「語意模型建立」。觸發器：「執行 DAX 查詢」、「執行 EVALUATE」、「語意模型元資料」、「列出語意模型表」、「INFO.VIEW.TABLES」、「取得度量表達式」、「DAX 針對」、「查詢模型」。
