إنشاء عناصر Fabric IQ Ontology (معاينة) وتطويرها من CLI - تحديد أنواع الكيانات والخصائص (بما في ذلك السلاسل الزمنية) وأنواع العلاقات وربطها بجداول OneLake Lakehouse (ثابتة + سلاسل زمنية) أو جداول قاعدة بيانات Eventhouse / KQL (السلاسل الزمنية فقط). يستخدم REST API لتعريف عنصر النسيج (إنشاء عنصر / تحديث تعريف العنصر) مع أجزاء "InlineBase64". يُستخدم لإنشاء عنصر نسيج الوجود؛ إضافة أو تغيير أنواع الكيانات أو الخصائص أو المفاتيح؛ إضافة خصائص وارتباطات السلاسل الزمنية؛ ربط نوع الكيان بطاولة البحيرة أو طاولة الحدث؛ إضافة أنواع العلاقات والسياقات؛ أو نشر علم الوجود النصي من المصدر. المشغلات: "إنشاء علم الوجود النسيجي"، "إضافة نوع كيان علم الوجود"، "ربط نوع الكيان ببيت البحيرة"، "ربط نوع الكيان ببيت الحدث"، "ربط السلاسل الزمنية للوجود"، "إضافة نوع علاقة علم الوجود"، "سياق علم الوجود"، "تأليف علم وجود النسيج"، "تحديث تعريف علم الوجود"
