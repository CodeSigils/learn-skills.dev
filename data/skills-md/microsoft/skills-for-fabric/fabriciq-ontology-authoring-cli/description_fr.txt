Créez et faites évoluer des éléments d'ontologie Fabric IQ (préversion) à partir de la CLI : définissez les types d'entités, les propriétés (y compris les séries temporelles), les types de relations et liez-les aux tables OneLake Lakehouse (statiques + séries temporelles) ou aux tables de base de données Eventhouse / KQL (séries temporelles uniquement). Utilise l'API REST de définition d'élément Fabric (Créer un élément / Mettre à jour la définition d'élément) avec les pièces `InlineBase64`. À utiliser pour créer un élément d'ontologie Fabric ; ajouter ou modifier des types d'entités, des propriétés ou des clés ; ajouter des propriétés et des liaisons de séries temporelles ; lier un type d'entité à une table Lakehouse ou Eventhouse ; ajouter des types de relations et des contextualisations ; ou le déploiement d'une ontologie de script à partir de la source.
