CLI から Fabric IQ オントロジー (プレビュー) アイテムを作成および展開します。エンティティ タイプ、プロパティ (時系列を含む)、関係タイプを定義し、それらを OneLake レイクハウス テーブル (静的 + 時系列) またはイベントハウス / KQL データベース テーブル (時系列のみ) にバインドします。 `InlineBase64` パーツで Fabric アイテム定義 REST API (アイテムの作成 / アイテム定義の更新) を使用します。ファブリック オントロジー アイテムの作成に使用します。エンティティ タイプ、プロパティ、またはキーを追加または変更します。 timeseries のプロパティとバインディングを追加します。エンティティ タイプをレイクハウス テーブルまたはイベントハウス テーブルにバインドします。関係タイプと文脈を追加します。またはソースからのスクリプト オントロジーの展開。トリガー: 「ファブリック オントロジーの作成」、「オントロジー エンティティ タイプの追加」、「エンティティ タイプをレイクハウスにバインド」、「エンティティ タイプをイベントハウスにバインド」、「オントロジー時系列バインディング」、「オントロジー関係タイプの追加」、「オントロジー コンテキスト化」、「ファブリック iq オントロジー オーサリング」、「オントロジー定義の更新」
