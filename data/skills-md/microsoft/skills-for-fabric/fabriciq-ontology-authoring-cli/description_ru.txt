Создавайте и развивайте элементы онтологии Fabric IQ (предварительная версия) из CLI — определяйте типы сущностей, свойства (включая временные ряды), типы отношений и привязывайте их к таблицам OneLake Lakehouse (статические + временные ряды) или таблицам базы данных Eventhouse/KQL (только временные ряды). Использует REST API определения элемента Fabric (создать элемент/обновить определение элемента) с частями InlineBase64. Используйте для создания элемента онтологии Fabric; добавлять или изменять типы, свойства или ключи объектов; добавлять свойства и привязки таймсерий; привязать тип сущности к таблице Lakehouse или Eventhouse; добавлять типы отношений и контекстуализацию; или развертывание онтологии сценария из исходного кода.
