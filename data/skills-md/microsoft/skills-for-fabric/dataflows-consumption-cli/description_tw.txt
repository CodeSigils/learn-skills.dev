通过只读 CLI 操作 (azrest/curl) 监视、检查和发现 Fabric Dataflows Gen2。列出跨工作區的資料流、解碼 Base64 定義以檢查 Power Query M 查詢和 queryMetadata.json、發現具有預設值的類型化參數、輪詢狀態刷新操作、檢索包含時間和錯誤詳細資訊的作業記錄，以及按暫存設定對查詢進行分類。當使用者想要執行下列操作時使用：(1) 列出資料流，(2) 檢查資料流定義並解碼其混搭，(3) 發現參數，(4) 檢查刷新狀態，(5) 擷取作業記錄，(6) 分析暫存設置，(7) 檢查連線和資料來源綁定。觸發器：「資料流狀態」、「刷新歷史記錄」、「資料流監視器」、「列出資料流」、「資料流參數」、「探索資料流」、「檢查資料流」、「資料流運行狀態」。
