Surveillez, inspectez et découvrez Fabric Dataflows Gen2 via des opérations CLI en lecture seule (az rest / curl). Répertoriez les flux de données dans les espaces de travail, décodez les définitions base64 pour inspecter les requêtes Power Query M et queryMetadata.json, découvrez les paramètres saisis avec les valeurs par défaut, interrogez les opérations d'actualisation pour connaître l'état, récupérez l'historique des tâches avec les détails de synchronisation et d'erreur et classez les requêtes par paramètres de transfert. À utiliser lorsque l'utilisateur souhaite : (1) répertorier les flux de données, (2) inspecter une définition de flux de données et décoder son application composite, (3) découvrir les paramètres, (4) vérifier l'état d'actualisation, (5) récupérer l'historique des tâches, (6) analyser les paramètres de transfert, (7) examiner les connexions et les liaisons de sources de données. Déclencheurs : "état du flux de données", "actualisation de l'historique", "moniteur de flux de données", "liste des flux de données", "paramètres du flux de données", "explorer le flux de données", "inspecter le flux de données", "état d'exécution du flux de données".
