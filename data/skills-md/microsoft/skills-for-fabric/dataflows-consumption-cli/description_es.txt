Supervise, inspeccione y descubra Fabric Dataflows Gen2 mediante operaciones CLI de solo lectura (az rest/curl). Enumere flujos de datos entre espacios de trabajo, decodifique definiciones base64 para inspeccionar consultas de Power Query M y queryMetadata.json, descubra parámetros escritos con valores predeterminados, sondee operaciones de actualización para determinar el estado, recupere el historial de trabajos con detalles de tiempos y errores, y clasifique consultas según la configuración provisional. Úselo cuando el usuario desee: (1) enumerar flujos de datos, (2) inspeccionar una definición de flujo de datos y decodificar su combinación, (3) descubrir parámetros, (4) verificar el estado de actualización, (5) recuperar el historial de trabajos, (6) analizar la configuración de preparación, (7) examinar conexiones y enlaces de fuentes de datos. Activadores: "estado del flujo de datos", "actualizar historial", "monitor de flujo de datos", "enumerar flujos de datos", "parámetros de flujo de datos", "explorar flujo de datos", "inspeccionar flujo de datos", "estado de ejecución de flujo de datos".
