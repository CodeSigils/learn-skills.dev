قم بمراقبة وفحص واكتشاف Fabric Dataflows Gen2 عبر عمليات CLI للقراءة فقط (az Rest / Curl). قم بإدراج تدفقات البيانات عبر مساحات العمل، وفك تشفير تعريفات base64 لفحص استعلامات Power Query M وqueryMetadata.json، واكتشاف المعلمات المكتوبة باستخدام الإعدادات الافتراضية، وعمليات تحديث الاستقصاء للحالة، واسترداد محفوظات المهام مع التوقيت وتفاصيل الأخطاء، وتصنيف الاستعلامات حسب الإعدادات المرحلية. يُستخدم عندما يريد المستخدم: (1) سرد تدفقات البيانات، (2) فحص تعريف تدفق البيانات وفك تشفير مزيجه، (3) اكتشاف المعلمات، (4) التحقق من حالة التحديث، (5) استرداد سجل المهام، (6) تحليل إعدادات التدريج، (7) فحص الاتصالات وارتباطات مصدر البيانات. المشغلات: "حالة تدفق البيانات"، "تاريخ التحديث"، "مراقبة تدفق البيانات"، "قائمة تدفقات البيانات"، "معلمات تدفق البيانات"، "استكشاف تدفق البيانات"، "فحص تدفق البيانات"، "حالة تشغيل تدفق البيانات".
