Generieren Sie visuelle Designanweisungen für Power BI-Berichte, bevor PBIR-Dateien geschrieben werden. Verwenden Sie diese Option, wenn der Benutzer: (1) Ton, Signatur, Seitenarchetypen, Diagrammtypen, Layout, Farbe, Typografie, Themenausrichtung oder Barrierefreiheitsansatz auswählen möchte, (2) einen vorhandenen Bericht neu gestalten/neu gestalten, eine Marke anwenden oder Diagramm-/Layout-Auswahlen kritisieren möchte, (3) einen Designvertrag für „powerbi-report-authoring“ erstellen möchte. Für End-to-End-Anforderungen, Genehmigungen und Build-Sequenzierung verwenden Sie „powerbi-report-planning“. Auslöser: „Power BI-Bericht entwerfen“, „Dashboard professionell aussehen lassen“, „Diagrammtyp auswählen“, „Marke auf Bericht anwenden“, „Bericht neu gestalten“, „Design-Briefing erstellen“.
