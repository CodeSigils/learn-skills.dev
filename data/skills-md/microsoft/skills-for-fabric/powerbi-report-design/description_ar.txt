قم بإنشاء إرشادات التصميم المرئي لتقرير Power BI قبل كتابة ملفات PBIR. يُستخدم عندما يريد المستخدم: (1) اختيار النغمة أو التوقيع أو النماذج الأولية للصفحة أو أنواع المخططات أو التخطيط أو اللون أو الطباعة أو اتجاه السمة أو نهج إمكانية الوصول، (2) إعادة تصميم/إعادة تصميم تقرير موجود، أو تطبيق علامة تجارية، أو اختيارات المخطط/التخطيط النقدي، (3) إنتاج عقد تصميم لـ "تأليف تقرير powerbi". للحصول على المتطلبات الشاملة والموافقة وتسلسل البناء، استخدم "تخطيط تقرير powerbi". المشغلات: "تصميم تقرير Power BI"، "جعل لوحة المعلومات تبدو احترافية"، "اختيار نوع المخطط"، "تطبيق العلامة التجارية على التقرير"، "إعادة تصميم التقرير"، "إنشاء ملخص التصميم".
