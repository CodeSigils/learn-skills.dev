透過 CLI (azrest/curl) 針對 Power BI REST 和 Fabric REST API 評估、規劃和執行資料流 Gen1 → Gen2.1 CI/CD 另存為操作。掃當使用者想要執行以下操作時使用：(1) 發現工作區或租戶中的 Gen1 資料流，(2) 評估另存為準備情況和風險訊號，(3) 將 Gen1 升級或遷移到 Gen2.1 副本，(4) 驗證另存為後資料的完整性，(5) 偵測殘留的 Gen1 參考。觸發器：「儲存 Gen1 資料流」、「轉換資料流 Gen1」、「升級資料流」、「遷移資料流」、「資料流準備就緒」、「Gen1 到 Gen2」、「資料流另存為評估」、「saveAsNativeArtifact」、「資料流另存為掃描」。
