Bewerten, planen und führen Sie CI/CD-Speichervorgänge für den Datenfluss Gen1 → Gen2.1 über CLI (az rest/curl) sowohl für Power BI REST als auch für Fabric REST APIs aus. Scannen Sie Arbeitsbereiche oder ganze Mandanten nach Gen1-Datenflüssen, bewerten Sie die Speicherbereitschaft mit sieben Risikosignalen (inkrementelle Aktualisierung, BYOSA-Speicher, Power Automate-Trigger, Pipeline-Abhängigkeiten, verknüpfte Entitäten, DirectQuery, Anrufer-nicht-Besitzer), erstellen Sie einen Save-As-Bereitschafts-Snapshot (Markdown + JSON) und rufen Sie die SaveAsNativeArtifact-API auf, um aktualisierte Gen2.1-Kopien von Gen1-Datenflüssen zu erstellen. Verwenden Sie diese Option, wenn der Benutzer: (1) Gen1-Datenflüsse in einem Arbeitsbereich oder Mandanten erkennen möchte, (2) Bereitschafts- und Risikosignale für das Speichern unter bewerten, (3) Gen1 in eine Gen2.1-Kopie aktualisieren oder migrieren möchte, (4) die Datenintegrität nach dem Speichern unter validieren möchte, (5) verbleibende Gen1-Referenzen erkennen möchte. Auslöser: „Gen1-Datenfluss speichern“, „Datenfluss Gen1 konvertieren“, „Datenfluss aktualisieren“, „Datenfluss migrieren“, „Datenflussbereitschaft“, „Gen1 zu Gen2“, „Datenfluss-Speichern-unter-Bewertung“, „saveAsNativeArtifact“, „Datenfluss-Speichern-unter-Scan“.
