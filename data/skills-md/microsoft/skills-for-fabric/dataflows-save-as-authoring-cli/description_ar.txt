تقييم وتخطيط وتنفيذ عمليات حفظ تدفق البيانات Gen1 → Gen2.1 CI/CD عبر CLI (azrest/curl) مقابل كل من Power BI REST وFabric REST APIs. قم بمسح مساحات العمل أو المستأجرين بالكامل لتدفقات بيانات Gen1، وتقييم جاهزية الحفظ باستخدام سبع إشارات مخاطر (التحديث المتزايد، وتخزين BYOSA، ومشغلات Power Automate، وتبعيات خطوط الأنابيب، والكيانات المرتبطة، وDirectQuery، والمتصل غير المالك)، وإنتاج لقطة استعداد Save-As (markdown + JSON)، واستدعاء SaveAsNativeArtifact API لإنشاء نسخ Gen2.1 تمت ترقيتها من تدفقات بيانات Gen1. يُستخدم عندما يريد المستخدم: (1) اكتشاف تدفقات بيانات Gen1 في مساحة عمل أو مستأجر، (2) تقييم جاهزية الحفظ وإشارات المخاطر، (3) ترقية Gen1 أو ترحيله إلى نسخة Gen2.1، (4) التحقق من صحة تكامل البيانات بعد الحفظ باسم، (5) اكتشاف مراجع Gen1 المتبقية. المشغلات: "حفظ تدفق بيانات Gen1"، و"تحويل تدفق بيانات Gen1"، و"ترقية تدفق البيانات"، و"ترحيل تدفق البيانات"، و"جاهزية تدفق البيانات"، و"Gen1 إلى Gen2"، و"تقييم حفظ تدفق البيانات"، و"saveAsNativeArtifact"، و"حفظ تدفق البيانات كمسح ضوئي".
