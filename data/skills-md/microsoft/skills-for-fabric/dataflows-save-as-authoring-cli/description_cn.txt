通过 CLI (azrest/curl) 针对 Power BI REST 和 Fabric REST API 评估、规划和执行数据流 Gen1 → Gen2.1 CI/CD 另存为操作。扫描工作区或整个租户的 Gen1 数据流，使用七个风险信号（增量刷新、BYOSA 存储、Power Automate 触发器、管道依赖项、链接实体、DirectQuery、调用者非所有者）评估另存为准备情况，生成另存为准备情况快照（markdown + JSON），并调用 SaveAsNativeArtifact API 创建 Gen1 数据流的升级 Gen2.1 副本。当用户想要执行以下操作时使用：(1) 发现工作区或租户中的 Gen1 数据流，(2) 评估另存为准备情况和风险信号，(3) 将 Gen1 升级或迁移到 Gen2.1 副本，(4) 验证另存为后数据的完整性，(5) 检测残留的 Gen1 引用。触发器：“保存 Gen1 数据流”、“转换数据流 Gen1”、“升级数据流”、“迁移数据流”、“数据流准备就绪”、“Gen1 到 Gen2”、“数据流另存为评估”、“saveAsNativeArtifact”、“数据流另存为扫描”。
