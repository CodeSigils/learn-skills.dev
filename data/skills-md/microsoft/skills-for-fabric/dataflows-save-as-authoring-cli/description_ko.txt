Power BI REST 및 Fabric REST API 모두에 대해 CLI(az Rest/curl)를 통해 데이터 흐름 Gen1 → Gen2.1 CI/CD 다른 이름으로 저장 작업을 평가, 계획 및 실행합니다. Gen1 데이터 흐름에 대한 작업 영역 또는 전체 테넌트를 스캔하고, 7가지 위험 신호(증분 새로 고침, BYOSA 스토리지, Power Automate 트리거, 파이프라인 종속성, 연결된 엔터티, DirectQuery, 소유자가 아닌 호출자)를 사용하여 다른 이름으로 저장 준비 상태를 평가하고, 다른 이름으로 저장 준비 스냅샷(markdown + JSON)을 생성하고, SaveAsNativeArtifact API를 호출하여 Gen1 데이터 흐름의 업그레이드된 Gen2.1 복사본을 만듭니다. 사용자가 (1) 작업 영역 또는 테넌트에서 Gen1 데이터 흐름 검색, (2) 다른 이름으로 저장 준비 상태 및 위험 신호 평가, (3) Gen1을 Gen2.1 복사본으로 업그레이드 또는 마이그레이션, (4) 다른 이름으로 저장 후 데이터 무결성 확인, (5) 잔여 Gen1 참조 검색을 원할 때 사용합니다. 트리거: "Gen1 데이터 흐름 저장", "Gen1 데이터 흐름 변환", "데이터 흐름 업그레이드", "데이터 흐름 마이그레이션", "데이터 흐름 준비", "Gen1에서 Gen2로", "데이터 흐름 다른 이름으로 저장 평가", "saveAsNativeArtifact", "데이터 흐름 다른 이름으로 저장 스캔".
