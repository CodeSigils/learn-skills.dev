Évaluez, planifiez et exécutez des opérations d'enregistrement sous CI/CD de flux de données Gen1 → Gen2.1 via CLI (az rest / curl) sur les API Power BI REST et Fabric REST. Analysez des espaces de travail ou des locataires entiers pour les flux de données Gen1, évaluez l'état de préparation à l'enregistrement sous avec sept signaux de risque (actualisation incrémentielle, stockage BYOSA, déclencheurs Power Automate, dépendances de pipeline, entités liées, DirectQuery, appelant non propriétaire), produisez un instantané de préparation à l'enregistrement sous (markdown + JSON) et invoquez l'API SaveAsNativeArtifact pour créer des copies Gen2.1 mises à niveau des flux de données Gen1. À utiliser lorsque l'utilisateur souhaite : (1) découvrir les flux de données Gen1 dans un espace de travail ou un locataire, (2) évaluer l'état de préparation à l'enregistrement sous et les signaux de risque, (3) mettre à niveau ou migrer Gen1 vers une copie Gen2.1, (4) valider l'intégrité des données après l'enregistrement sous, (5) détecter les références Gen1 résiduelles. Déclencheurs : « enregistrer le flux de données Gen1 », « convertir le flux de données Gen1 », « mettre à niveau le flux de données », « migrer le flux de données », « préparation du flux de données », « Gen1 vers Gen2 », « évaluer l'enregistrement sous le flux de données », « saveAsNativeArtifact », « analyser l'enregistrement sous le flux de données ».
