Power BI REST API と Fabric REST API の両方に対して、CLI (azrest/curl) 経由でデータフロー Gen1 → Gen2.1 CI/CD の名前を付けて保存操作を評価、計画、実行します。 Gen1 データフローのワークスペースまたはテナント全体をスキャンし、7 つのリスク シグナル (増分更新、BYOSA ストレージ、Power Automate トリガー、パイプラインの依存関係、リンクされたエンティティ、DirectQuery、呼び出し元ではない所有者) で名前を付けて保存の準備状況を評価し、名前を付けて保存の準備状況スナップショット (マークダウン + JSON) を生成し、SaveAsNativeArtifact API を呼び出して Gen1 データフローのアップグレードされた Gen2.1 コピーを作成します。ユーザーが次のことを行う場合に使用します: (1) ワークスペースまたはテナントで Gen1 データフローを検出する、(2) 名前を付けて保存の準備状況とリスク信号を評価する、(3) Gen1 を Gen2.1 コピーにアップグレードまたは移行する、(4) 名前を付けて保存後のデータ整合性を検証する、(5) 残留する Gen1 参照を検出する。トリガー: 「Gen1 データフローの保存」、「データフロー Gen1 の変換」、「データフローのアップグレード」、「データフローの移行」、「データフローの準備状況」、「Gen1 から Gen2 へ」、「データフローの名前を付けて保存評価」、「saveAsNativeArtifact」、「データフローの名前を付けて保存スキャン」。
