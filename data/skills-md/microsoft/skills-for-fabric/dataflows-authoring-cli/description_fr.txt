Créez, mettez à jour, supprimez et gérez les artefacts Fabric Dataflows Gen2 avec les définitions de mashup Power Query M via CLI (az rest / curl). Utilise az rest et curl avec l’API Fabric REST pour créer des définitions contenant des parties mashup.pq, queryMetadata.json et .platform codées en base64. Prend en charge la création de flux de données avec des définitions en ligne, la modification des requêtes mashup, la liaison des connexions, le déclenchement de tâches d'actualisation avec des remplacements de paramètres saisis et l'exportation de définitions pour CI/CD. À utiliser lorsque l'utilisateur souhaite : (1) créer un nouveau Dataflow Gen2 avec des requêtes Power Query M, (2) mettre à jour une définition d'application composite de flux de données, (3) déclencher une tâche d'actualisation de flux de données, (4) lier ou gérer des connexions de flux de données, (5) configurer CI/CD via l'exportation et l'importation de définitions, (6) supprimer un flux de données, (7) configurer des destinations intermédiaires. Déclencheurs : « créer un flux de données », « créer un flux de données », « Power Query M », « document mashup », « mettre à jour la définition du flux de données », « actualiser le flux de données », « connexion au flux de données », « flux de données ETL », « flux de données CI/CD ».
