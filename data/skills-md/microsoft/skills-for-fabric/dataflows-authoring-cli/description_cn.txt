通过 CLI (azrest/curl) 使用 Power Query M 混搭定义创建、更新、删除和管理 Fabric Dataflows Gen2 工件。针对 Fabric REST API 使用 azrest 和curl 来创作包含 base64 编码的 mashup.pq、queryMetadata.json 和 .platform 部分的定义。支持使用内联定义创建数据流、修改混搭查询、绑定连接、使用类型化参数覆盖触发执行刷新作业以及导出 CI/CD 定义。当用户想要执行以下操作时使用：(1) 使用 Power Query M 查询创建新的 Dataflow Gen2，(2) 更新数据流混搭定义，(3) 触发数据流刷新作业，(4) 绑定或管理数据流连接，(5) 通过定义导出和导入设置 CI/CD，(6) 删除数据流，(7) 配置暂存目标。触发器：“创建数据流”、“创作数据流”、“Power Query M”、“混搭文档”、“更新数据流定义”、“刷新数据流”、“数据流连接”、“ETL 数据流”、“数据流 CI/CD”。
