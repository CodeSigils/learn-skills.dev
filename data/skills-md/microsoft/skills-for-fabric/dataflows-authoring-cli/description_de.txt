Erstellen, aktualisieren, löschen und verwalten Sie Fabric Dataflows Gen2-Artefakte mit Power Query M-Mashup-Definitionen über CLI (az rest/curl). Verwendet az rest und curl für die Fabric-REST-API, um Definitionen zu erstellen, die base64-codierte mashup.pq-, queryMetadata.json- und .platform-Teile enthalten. Unterstützt das Erstellen von Datenflüssen mit Inline-Definitionen, das Ändern von Mashup-Abfragen, das Binden von Verbindungen, das Auslösen von Ausführungsaktualisierungsaufträgen mit typisierten Parameterüberschreibungen und das Exportieren von Definitionen für CI/CD. Verwenden Sie diese Option, wenn der Benutzer Folgendes tun möchte: (1) einen neuen Dataflow Gen2 mit Power Query M-Abfragen erstellen, (2) eine Datenfluss-Mashup-Definition aktualisieren, (3) einen Datenfluss-Aktualisierungsjob auslösen, (4) Datenflussverbindungen binden oder verwalten, (5) CI/CD über Definitionsexport und -import einrichten, (6) einen Datenfluss löschen, (7) Staging-Ziele konfigurieren möchte. Auslöser: „Datenfluss erstellen“, „Datenfluss erstellen“, „Power Query M“, „Mashup-Dokument“, „Datenflussdefinition aktualisieren“, „Datenfluss aktualisieren“, „Datenflussverbindung“, „ETL-Datenfluss“, „Datenfluss CI/CD“.
