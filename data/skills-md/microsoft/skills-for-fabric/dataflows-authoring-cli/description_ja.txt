CLI (azrest/curl) 経由で、Power Query M マッシュアップ定義を使用して Fabric Dataflows Gen2 アーティファクトを作成、更新、削除、管理します。 Fabric REST API に対して azrest とcurl を使用して、base64 でエンコードされた mashup.pq、queryMetadata.json、および .platform パーツを含む定義を作成します。インライン定義を使用したデータフローの作成、マッシュアップ クエリの変更、接続のバインド、型指定されたパラメーターのオーバーライドによる更新ジョブの実行のトリガー、CI/CD の定義のエクスポートをサポートします。ユーザーが次のことを行う場合に使用します: (1) Power Query M クエリを使用して新しい Dataflow Gen2 を作成する、(2) データフロー マッシュアップ定義を更新する、(3) データフロー更新ジョブをトリガーする、(4) データフロー接続をバインドまたは管理する、(5) 定義のエクスポートおよびインポートを介して CI/CD を設定する、(6) データフローを削除する、(7) ステージング先を構成する。トリガー: "データフローの作成"、"データフローの作成"、"Power Query M"、"マッシュアップ ドキュメント"、"データフロー定義の更新"、"データフローの更新"、"データフロー接続"、"ETL データフロー"、"データフロー CI/CD"。
