透過 CLI (azrest/curl) 使用 Power Query M 混搭定義建立、更新、刪除和管理 Fabric Dataflows Gen2 工件。針對 Fabric REST API 使用 azrest 和curl 來建立包含 base64 編碼的 mashup.pq、queryMetadata.json 和 .platform 部分的定義。支援使用內聯定義建立資料流、修改混搭查詢、綁定連接、使用類型化參數覆寫觸發執行刷新作業以及匯出 CI/CD 定義。當使用者想要執行以下操作時使用：(1) 使用 Power Query M 查詢建立新的 Dataflow Gen2，(2) 更新資料流混搭定義，(3) 觸發資料流刷新作業，(4) 綁定或管理資料流連接，(5) 透過定義匯出和匯入設定 CI/CD，(6) 刪除資料流，(7) 配置暫存目標。觸發器：「建立資料流」、「創作資料流」、「Power Query M」、「混搭文件」、「更新資料流定義」、「刷新資料流」、「資料流連線」、「ETL 資料流」、「資料流 CI/CD」。
