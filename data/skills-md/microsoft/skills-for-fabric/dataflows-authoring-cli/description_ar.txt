يمكنك إنشاء عناصر Fabric Dataflows Gen2 وتحديثها وحذفها وإدارتها باستخدام تعريفات Power Query M mashup عبر واجهة سطر الأوامر (az Rest / Curl). يستخدم الاستراحة az والالتفاف مقابل Fabric REST API لتأليف التعريفات التي تحتوي على أجزاء mashup.pq وqueryMetadata.json و.platform المرمزة بـ base64. يدعم إنشاء تدفقات البيانات مع التعريفات المضمنة، وتعديل استعلامات mashup، وربط الاتصالات، وتشغيل مهام التحديث التنفيذية مع تجاوزات المعلمات المكتوبة، وتصدير التعريفات لـ CI/CD. يُستخدم عندما يريد المستخدم: (1) إنشاء Dataflow Gen2 جديد باستخدام استعلامات Power Query M، (2) تحديث تعريف مزج تدفق البيانات، (3) تشغيل مهمة تحديث تدفق البيانات، (4) ربط اتصالات تدفق البيانات أو إدارتها، (5) إعداد CI/CD عبر تصدير التعريف واستيراده، (6) حذف تدفق البيانات، (7) تكوين الوجهات المرحلية. المشغلات: "إنشاء تدفق بيانات"، "تدفق بيانات المؤلف"، "Power Query M"، "مستند mashup"، "تحديث تعريف تدفق البيانات"، "تحديث تدفق البيانات"، "اتصال تدفق البيانات"، "ETL dataflow"، "dataflow CI/CD".
