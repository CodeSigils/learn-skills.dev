Создавайте, обновляйте, удаляйте артефакты Fabric Dataflows Gen2 и управляйте ими с помощью определений гибридных веб-приложений Power Query M через интерфейс командной строки (az rest/curl). Использует az rest и curl для API REST Fabric для создания определений, содержащих части mashup.pq, queryMetadata.json и .platform в кодировке Base64. Поддерживает создание потоков данных со встроенными определениями, изменение гибридных запросов, привязку соединений, запуск заданий обновления с переопределением типизированных параметров и экспорт определений для CI/CD. Используйте, когда пользователь хочет: (1) создать новый поток данных Gen2 с запросами Power Query M, (2) обновить определение гибридного приложения потока данных, (3) запустить задание обновления потока данных, (4) привязать или управлять соединениями потока данных, (5) настроить CI/CD посредством экспорта и импорта определений, (6) удалить поток данных, (7) настроить промежуточные места назначения. Триггеры: «создать поток данных», «поток данных автора», «Power Query M», «мэшап-документ», «обновить определение потока данных», «обновить поток данных», «подключение к потоку данных», «поток данных ETL», «поток данных CI/CD».
