CLI(az Rest/curl)를 통해 파워 쿼리 M 매시업 정의를 사용하여 Fabric Dataflows Gen2 아티팩트를 생성, 업데이트, 삭제 및 관리합니다. Fabric REST API에 대해 az Rest 및 Curl을 사용하여 base64로 인코딩된 mashup.pq, queryMetadata.json 및 .platform 부분이 포함된 정의를 작성합니다. 인라인 정의를 사용하여 데이터 흐름 만들기, 매시업 쿼리 수정, 연결 바인딩, 입력된 매개 변수 재정의를 사용하여 새로 고침 작업 실행 트리거, CI/CD용 정의 내보내기를 지원합니다. 사용자가 (1) 파워 쿼리 M 쿼리를 사용하여 새 Dataflow Gen2 만들기, (2) 데이터 흐름 매시업 정의 업데이트, (3) 데이터 흐름 새로 고침 작업 트리거, (4) 데이터 흐름 연결 바인딩 또는 관리, (5) 정의 내보내기 및 가져오기를 통해 CI/CD 설정, (6) 데이터 흐름 삭제, (7) 준비 대상 구성을 원할 때 사용합니다. 트리거: "데이터 흐름 만들기", "데이터 흐름 작성자", "파워 쿼리 M", "매시업 문서", "데이터 흐름 정의 업데이트", "데이터 흐름 새로 고침", "데이터 흐름 연결", "ETL 데이터 흐름", "데이터 흐름 CI/CD".
