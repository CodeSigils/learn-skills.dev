قم بتطوير سير عمل Microsoft Fabric Spark/هندسة البيانات واكتب التعليمات البرمجية في خلايا Fabric Notebook مع التوجيه الذكي إلى الموارد المتخصصة. يوفر إدارة مساحة العمل/البحيرة، وتأليف التعليمات البرمجية للكمبيوتر المحمول (PySpark، وScala، وSparkR، وSQL)، والطرق المؤدية إلى: أنماط هندسة البيانات، أو سير عمل التطوير، أو تنسيق البنية التحتية. يُستخدم عندما يريد المستخدم: (1) إدارة مساحات عمل وموارد Fabric، (2) كتابة التعليمات البرمجية أو تصحيح الأخطاء في خلايا دفتر الملاحظات، (3) استخدام دفاتر الملاحظات، (4) تطوير دفاتر الملاحظات وتطبيقات PySpark، (5) تصميم خطوط أنابيب البيانات، (6) توفير البنية التحتية كرمز. المشغلات: "تطوير دفتر الملاحظات"، "هندسة البيانات"، "إعداد مساحة العمل"، "تصميم خطوط الأنابيب"، "توفير البنية التحتية"، "أنماط Delta Lake"، "تطوير Spark"، "تكوين Lakehouse"، "كتابة رمز دفتر الملاحظات"، "notebookutils"، "خلية دفتر الملاحظات"، "دفتر PySpark"، "%%sql"، "%%configure"، "دفتر ملاحظات قماشي"، "تشغيل دفتر الملاحظات"، "نشر دفتر الملاحظات".
