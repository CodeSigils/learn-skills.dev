通过 Fabric Items REST API 创建、连接和发布 Microsoft Fabric Eventstream 实时事件流拓扑。使用 25 种源类型（事件中心、IoT 中心、CDC 连接器、Kafka、SampleData）、8 种转换运算符（Filter、Aggregate、GroupBy、Join、ManageFields、Union、Expand、SQL）、4 种目标类型（Lakehouse Delta、Eventhouse、Activator、自定义端点）和 DefaultStream/DerivedStream 路由构建基于图形的定义。当用户想要执行以下操作时使用：(1) 创作或发布 Eventstream 拓扑，(2) 通过基于 SQL 的 Debezium 负载扁平化添加 CDC 源，(3) 组装多表扇出路由，(4) 修改或删除 Eventstream 定义。触发器：“创建事件流”、“部署事件流”、“设计事件流拓扑”、“CDC 源”、“事件流运算符”、“实时摄取管道”、“事件流定义”、“更新事件流”。
