透過 Fabric Items REST API 建立、連接和發布 Microsoft Fabric Eventstream 即時事件流拓撲。使用 25 種來源類型（事件中心、IoT 中心、CDC 連接器、Kafka、SampleData）、8 種轉換運算子（Filter、Aggregate、GroupBy、Join、ManageFields、Union、Expand、SQL）、4 種目標類型（Lakehouse Delta、Eventhouse、Activds、StreamStream、Tippand、SQLault/Deriing）建置路由和驅動程式。當使用者想要執行以下操作時使用：(1) 創作或發布 Eventstream 拓撲，(2) 透過基於 SQL 的 Debezium 負載扁平化新增 CDC 來源，(3) 組裝多表扇出路由，(4) 修改或刪除 Eventstream 定義。觸發器：「建立事件流」、「部署事件流」、「設計事件流拓撲」、「CDC 來源」、「事件流運算子」、「即時攝取管道」、「事件流定義」、「更新事件流」。
