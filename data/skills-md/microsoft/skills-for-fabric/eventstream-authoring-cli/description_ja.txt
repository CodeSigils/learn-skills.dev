Fabric Items REST API を介して、Microsoft Fabric Eventstream リアルタイム イベント ストリーミング トポロジを作成、接続、公開します。 25 のソース タイプ (Event Hubs、IoT Hub、CDC コネクタ、Kafka、SampleData)、8 つの変換演算子 (Filter、Aggregate、GroupBy、Join、ManageFields、Union、Expand、SQL)、4 つの宛先タイプ (Lakehouse Delta、Eventhouse、Activator、Custom Endpoint)、DefaultStream/DerivedStream ルーティングを使用してグラフベースの定義を構築します。ユーザーが次のことを行う場合に使用します: (1) Eventstream トポロジの作成または公開、(2) SQL ベースの Debezium ペイロード平坦化による CDC ソースの追加、(3) マルチテーブル ファンアウト ルーティングのアセンブル、(4) Eventstream 定義の変更または削除。トリガー: 「eventstream の作成」、「eventstream のデプロイ」、「eventstream トポロジの設計」、「CDC ソース」、「eventstream オペレーター」、「リアルタイム取り込みパイプライン」、「eventstream 定義」、「eventstream の更新」。
