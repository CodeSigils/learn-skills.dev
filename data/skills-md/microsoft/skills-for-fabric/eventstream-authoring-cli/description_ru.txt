Создавайте, подключайте и публикуйте топологии потоковой передачи событий Microsoft Fabric Eventstream в реальном времени через API REST элементов Fabric. Создавайте определения на основе графов с 25 типами источников (Центры событий, Центр Интернета вещей, соединители CDC, Kafka, SampleData), 8 операторами преобразования (Filter, Aggregate, GroupBy, Join, ManageFields, Union, Expand, SQL), 4 типами назначения (Lakehouse Delta, Eventhouse, Activator, Custom Endpoint) и маршрутизацией DefaultStream/DerivedStream. Используйте, когда пользователь хочет: (1) создать или опубликовать топологию потока событий, (2) добавить источники CDC с выравниванием полезной нагрузки Debezium на основе SQL, (3) собрать многотабличную разветвленную маршрутизацию, (4) изменить или удалить определения потока событий. Триггеры: «создание потока событий», «развертывание потока событий», «разработка топологии потока событий», «источник CDC», «оператор потока событий», «конвейер приема в реальном времени», «определение потока событий», «обновление потока событий».
