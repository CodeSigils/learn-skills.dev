Fabric Items REST API를 통해 Microsoft Fabric Eventstream 실시간 이벤트 스트리밍 토폴로지를 생성, 연결 및 게시합니다. 25가지 소스 유형(Event Hubs, IoT Hub, CDC 커넥터, Kafka, SampleData), 8가지 변환 연산자(Filter, Aggregate, GroupBy, Join, ManageFields, Union, Expand, SQL), 4가지 대상 유형(Lakehouse Delta, Eventhouse, Activator, Custom Endpoint) 및 DefaultStream/DerivedStream 라우팅을 사용하여 그래프 기반 정의를 구축합니다. 사용자가 (1) Eventstream 토폴로지를 작성 또는 게시하고, (2) SQL 기반 Debezium 페이로드 평면화를 사용하여 CDC 소스를 추가하고, (3) 다중 테이블 팬아웃 라우팅을 어셈블하고, (4) Eventstream 정의를 수정 또는 삭제하려는 경우에 사용합니다. 트리거: "이벤트스트림 생성", "이벤트스트림 배포", "이벤트스트림 토폴로지 설계", "CDC 소스", "이벤트스트림 연산자", "실시간 수집 파이프라인", "이벤트스트림 정의", "이벤트스트림 업데이트".
