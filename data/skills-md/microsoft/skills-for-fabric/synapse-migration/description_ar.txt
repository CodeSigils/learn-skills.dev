دفاتر ملاحظات Port Azure Synapse Analytics وتجمعات SQL وخطوط الأنابيب إلى Microsoft Fabric. يترجم استدعاءات mssparkutils إلى أجهزة الكمبيوتر المحمولة (بما في ذلك تغيير مساحة الاسم env → وقت التشغيل)، ويستبدل الخدمات المرتبطة باتصالات بيانات النسيج واختصارات OneLake، ويعيد كتابة DDL المخصص لـ SQL Pool DDL عن طريق إزالة تلميحات DISTRIBUTION وCLUSTERED COLUMNSTORE، ويستبدل جداول PolyBase الخارجية بـ COPY INTO، ويعين أنشطة Synapse Pipeline لمكافئات Fabric Data Pipeline. يُستخدم عندما يريد المستخدم: (1) نقل دفاتر ملاحظات Synapse Spark إلى Fabric Lakehouse أو Spark Job Definitions، (2) استبدال mssparkutils أو الخدمات المرتبطة في كود Synapse، (3) إعادة كتابة SQL Pool T-SQL المخصص لـ Fabric Warehouse، (4) ترحيل خطوط أنابيب Synapse إلى خطوط أنابيب بيانات النسيج. المشغلات: "الترحيل من المشبك"، "المشبك إلى النسيج"، "mssparkutils إلى دفتر الملاحظات"، "استبدال الخدمة المرتبطة بالمشبك"، "تجمع SQL مخصص إلى المستودع"، "polybase للنسخ إلى"، "دفاتر ملاحظات المنفذ المشبك"، "ترحيل مساحة عمل المشبك".
