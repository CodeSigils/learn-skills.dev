Portez les notebooks, les pools SQL et les pipelines Azure Synapse Analytics vers Microsoft Fabric. Traduit les appels mssparkutils vers notebookutils (y compris le changement d'espace de noms env→runtime), remplace les services liés par des connexions de données Fabric et des raccourcis OneLake, réécrit le DDL du pool SQL dédié en supprimant les indications DISTRIBUTION et CLUSTERED COLUMNSTORE, remplace les tables externes PolyBase par COPY INTO et mappe les activités du pipeline Synapse aux équivalents du pipeline de données Fabric. À utiliser lorsque l'utilisateur souhaite : (1) porter les notebooks Synapse Spark vers Fabric Lakehouse ou Spark Job Definitions, (2) remplacer mssparkutils ou Linked Services dans le code Synapse, (3) réécrire le pool SQL dédié T-SQL pour Fabric Warehouse, (4) migrer les pipelines Synapse vers les pipelines de données Fabric.
