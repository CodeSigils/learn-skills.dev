Azure Synapse Analytics ノートブック、SQL プール、パイプラインを Microsoft Fabric にポートします。 mssparkutils 呼び出しを Notebookutils に変換し (env→ランタイム名前空間の変更を含む)、リンクされたサービスを Fabric Data Connections と OneLake Shortcuts に置き換え、DISTRIBUTION ヒントと CLUSTERED COLUMNSTORE ヒントを削除して専用 SQL プール DDL を書き換え、PolyBase 外部テーブルを COPY INTO に置き換え、Synapse Pipeline アクティビティを Fabric Data Pipeline の同等のアクティビティにマップします。ユーザーが次のことを行う場合に使用します: (1) Synapse Spark ノートブックを Fabric Lakehouse または Spark ジョブ定義に移植する、(2) Synapse コード内の mssparkutils またはリンク サービスを置き換える、(3) Fabric Warehouse 用に専用 SQL プール T-SQL を書き換える、(4) Synapse パイプラインを Fabric Data Pipelines に移行する。トリガー: 「シナプスからファブリックへの移行」、「シナプスからファブリックへの移行」、「mssparkutils から Notebookutils へ」、「シナプスのリンクされたサービスの置換」、「専用 SQL プールからウェアハウスへ」、「コピー先のポリベース」、「シナプス ノートブックのポート」、「シナプス ワークスペースの移行」。
