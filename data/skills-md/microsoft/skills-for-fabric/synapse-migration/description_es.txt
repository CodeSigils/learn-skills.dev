Porte los cuadernos, los grupos de SQL y las canalizaciones de Azure Synapse Analytics a Microsoft Fabric. Traduce las llamadas de mssparkutils a notebookutils (incluido el cambio de espacio de nombres env→runtime), reemplaza los servicios vinculados con conexiones de datos de Fabric y accesos directos de OneLake, reescribe el DDL del grupo de SQL dedicado eliminando las sugerencias de DISTRIBUCIÓN y CLUSTERED COLUMNSTORE, sustituye las tablas externas de PolyBase con COPY INTO y asigna las actividades de Synapse Pipeline a equivalentes de Fabric Data Pipeline. Úselo cuando el usuario desee: (1) migrar los cuadernos de Synapse Spark a Fabric Lakehouse o definiciones de trabajos de Spark, (2) reemplazar mssparkutils o servicios vinculados en el código de Synapse, (3) reescribir el grupo de SQL dedicado T-SQL para Fabric Warehouse, (4) migrar canalizaciones de Synapse a canalizaciones de datos de Fabric. Activadores: "migrar de Synapse", "synapse a fabric", "mssparkutils a notebookutils", "reemplazo de servicio vinculado a synapse", "grupo de SQL dedicado al almacén", "polybase para copiar", "portar cuadernos de synapse", "migración del espacio de trabajo de synapse".
