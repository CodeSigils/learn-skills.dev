Перенесите записные книжки Azure Synapse Analytics, пулы SQL и конвейеры в Microsoft Fabric. Преобразует вызовы mssparkutils в Notebookutils (включая изменение пространства имен env → runtime), заменяет связанные службы соединениями данных Fabric и ярлыками OneLake, перезаписывает DDL выделенного пула SQL, удаляя подсказки DISTRIBUTION и CLUSTERED COLUMNSTORE, заменяет внешние таблицы PolyBase на COPY INTO и сопоставляет действия Synapse Pipeline с эквивалентами Fabric Data Pipeline. Используйте, когда пользователь хочет: (1) перенести записные книжки Synapse Spark в Fabric Lakehouse или определения заданий Spark, (2) заменить mssparkutils или связанные службы в коде Synapse, (3) переписать выделенный пул SQL T-SQL для хранилища Fabric, (4) перенести конвейеры Synapse в конвейеры данных Fabric. Триггеры: «миграция из синапса», «синапс в фабрику», «mssparkutils в Notebookutils», «замена связанной службы Synapse», «выделенный пул SQL в хранилище», «polybase для копирования», «перенос записных книжек Synapse», «миграция рабочей области Synapse».
