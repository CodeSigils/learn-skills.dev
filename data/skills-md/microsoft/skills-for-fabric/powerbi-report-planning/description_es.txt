Cree un flujo de trabajo guiado desde los requisitos hasta la implementación para nuevos informes y paneles de Power BI a partir de modelos semánticos, conjuntos de datos o proyectos PBIP. Úselo cuando el usuario desee: (1) planificar y luego implementar un informe, (2) definir la audiencia, el alcance, el plan de páginas, la dirección del diseño, las dependencias y el objetivo de entrega, (3) crear una especificación de informe bloqueada con aprobación antes de la creación de PBIR. Para ediciones directas de archivos de informes existentes, utilice `powerbi-report-authoring`. Para críticas o rediseños solo de diseño, utilice `powerbi-report-design`. Desencadenadores: "construirme un panel", "crear un nuevo informe", "planificar y luego implementar", "definir y crear un informe de Power BI", "guiarme en la creación de un informe".
