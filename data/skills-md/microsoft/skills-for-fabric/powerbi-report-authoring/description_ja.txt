`powerbi-report-author` および `powerbi-desktop` CLI を使用して、Power BI レポート ファイルを PBIR/PBIP 形式で作成および変更します。ユーザーが次のことを行う場合に使用します: (1) 承認されたレポート仕様または設計概要を実装する、(2) ページ、ビジュアル、フィルター、スライサー、ブックマーク、テーマ、または書式設定を追加または編集する、(3) PBIR を検証し、Power BI Desktop でのレンダリングを検証する。自由なビジュアル デザインの場合は、最初に「powerbi-report-design」を使用します。エンドツーエンドの要件と承認ワークフローの場合は、最初に「powerbi-report-planning」を使用します。トリガー: 「PBIR の編集」、「Power BI レポート ページの作成」、「PBIP へのビジュアルの追加」、「レポート ビジュアルの書式設定」、「Power BI レポートの検証」、「デスクトップのスクリーンショットの再読み込み」、「承認された PBIP レポート仕様の実装」、「PBIR ページ/ビジュアルの編集」。
