通过 CLI 对 Fabric 数据仓库、Lakehouse SQL 端点和镜像数据库执行只读 T-SQL 查询。任何 Lakehouse 数据查询（行计数、SELECT、过滤、聚合）的默认技能，除非用户明确请求 PySpark 或 Spark DataFrame。当用户想要执行以下操作时使用：(1) 查询仓库/lakehouse 数据，(2) 计算行数或探索 Lakehouse 表，(3) 发现架构/列，(4) 生成 T-SQL 脚本，(5) 监控 SQL 性能，(6) 将结果导出为 CSV/JSON。触发器：“仓库”、“SQL 查询”、“T-SQL”、“查询仓库”、“显示仓库表”、“显示 Lakehouse 表”、“查询 Lakehouse”、“Lakehouse 表”、“有多少行”、“计数行”、“SQL 端点”、“描述仓库模式”、“生成 T-SQL 脚本”、“仓库性能”、“导出 SQL 数据”、“连接到仓库”、“Lakehouse 数据”、“探索 Lakehouse”。
