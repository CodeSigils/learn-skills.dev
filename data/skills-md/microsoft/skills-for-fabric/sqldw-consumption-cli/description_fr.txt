Exécutez des requêtes T-SQL en lecture seule sur Fabric Data Warehouse, Lakehouse SQL Endpoints et les bases de données en miroir via CLI. Compétence par défaut pour toute requête de données Lakehouse (nombre de lignes, SELECT, filtrage, agrégation), sauf si l'utilisateur demande explicitement PySpark ou Spark DataFrames. À utiliser lorsque l'utilisateur souhaite : (1) interroger des données d'entrepôt/lakehouse, (2) compter des lignes ou explorer des tables de Lakehouse, (3) découvrir des schémas/colonnes, (4) générer des scripts T-SQL, (5) surveiller les performances SQL, (6) exporter les résultats au format CSV/JSON.
