Выполняйте запросы T-SQL только для чтения к хранилищу данных Fabric, конечным точкам SQL Lakehouse и зеркальным базам данных через интерфейс командной строки. Навык по умолчанию для любого запроса данных Lakehouse (подсчет строк, SELECT, фильтрация, агрегирование), если только пользователь явно не запрашивает PySpark или Spark DataFrames. Используйте, когда пользователь хочет: (1) запросить данные хранилища или озера, (2) подсчитать строки или изучить таблицы озера, (3) обнаружить схемы/столбцы, (4) сгенерировать сценарии T-SQL, (5) отслеживать производительность SQL, (6) экспортировать результаты в CSV/JSON. Триггеры: «склад», «SQL-запрос», «T-SQL», «запрос к хранилищу», «показать таблицы хранилища», «показать таблицы Lakehouse», «запрос Lakehouse», «Таблица Lakehouse», «Сколько строк», «Подсчитать строки», «Конечная точка SQL», «Описать схему хранилища», «Создать сценарий T-SQL», «Производительность хранилища», «Экспорт данных SQL», «Подключиться к хранилищу», «Данные Lakehouse», «Изучить Lakehouse».
