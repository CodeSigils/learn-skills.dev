CLI を介して、ファブリック データ ウェアハウス、レイクハウス SQL エンドポイント、およびミラーリングされたデータベースに対して読み取り専用 T-SQL クエリを実行します。ユーザーが明示的に PySpark または Spark DataFrames を要求しない限り、レイクハウス データ クエリ (行数、SELECT、フィルタリング、集計) のデフォルト スキル。ユーザーが次のことを行う場合に使用します: (1) ウェアハウス/レイクハウス データのクエリ、(2) 行のカウントまたはレイクハウス テーブルの探索、(3) スキーマ/列の検出、(4) T-SQL スクリプトの生成、(5) SQL パフォーマンスの監視、(6) 結果の CSV/JSON へのエクスポート。トリガー: "ウェアハウス"、"SQL クエリ"、"T-SQL"、"ウェアハウスのクエリ"、"ウェアハウス テーブルの表示"、"レイクハウス テーブルの表示"、"レイクハウス テーブルのクエリ"、"レイクハウス テーブル"、"行数"、"行カウント"、"SQL エンドポイント"、"ウェアハウス スキーマの記述"、"T-SQL スクリプトの生成"、"ウェアハウス パフォーマンス"、"SQL データのエクスポート"、"ウェアハウスへの接続"、 「湖畔のデータ」、「湖畔の探索」。
