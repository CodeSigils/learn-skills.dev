Répondez aux questions commerciales en langage naturel sur les rapports et tableaux de bord Power BI existants via le point de terminaison FabricIQ MCP. Orchestre la découverte d’artefacts, l’inspection de schéma, la résolution d’entités, la génération DAX et l’exécution de requêtes pour renvoyer des réponses en langage clair. À utiliser lorsque l'utilisateur demande quoi, quoi, comparer, classer, expliquer ou résumer des questions sur le contenu du rapport ou du tableau de bord Power BI (et non du DAX brut). Pour l'exécution DAX brute (instructions EVALUATE) ou l'inspection des métadonnées du modèle (fonctions INFO), utilisez `semantic-model-consumption`. Pour télécharger/télécharger/publier/lister/supprimer des éléments de rapport ou des définitions PBIR, utilisez `powerbi-report-management`. Pour les modifications de fichiers/pages/visuels PBIR, utilisez `powerbi-report-authoring`. Déclencheurs : « poser une question à Power Bi », « question PBI », « découvrir mon rapport Power BI », « données du rapport », « données du tableau de bord », « quelles sont les principales données », « me montrer les données Power Bi », « quels produits vendus », « comparer les ventes dans le rapport », « quels clients ont produit », « demander le rapport Power BI ».
