**НАВЫКИ РАБОЧЕГО ПРОЦЕССА** — Маршрутизатор верхнего уровня для распределенных приложений Aspire 13.4. Обнаруживает AppHost, обеспечивает соблюдение мер безопасности и направляет к нужному субнавыку. ИСПОЛЬЗОВАНИЕ ДЛЯ: Aspire AppHost обнаружен, Aspire CLI, распределенное приложение, облачный .NET, Aspire Start, Aspire Stop, Aspire Resource, Aspire Deploy, Aspire уничтожить, Aspire опубликовать, Aspire init, Aspire new, Aspire add, Aspire list/search, Aspire wait, Aspire описать, Aspire PS, Aspire Dashboard Run, Aspire Doctor, Aspire update, журналы aspire, aspire otel, --include-hidden, aspireify, WithBrowserLogs, пользовательские команды панели управления/ресурсов, восстановление .aspire/modules, обнаружение URL-адресов Playwright. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: проектов .NET, отличных от Aspire (используйте dotnet напрямую), подготовки Azure без Aspire (используйте azure-prepare), репозиториев только для контейнеров без AppHost, обычных задач сборки и тестирования. ВЫЗЫВАЕТ: aspire-init, aspireify, aspire-orchestration, aspire-deployment, aspire-monitoring. ДЛЯ ОДИНОЧНЫХ ОПЕРАЦИЙ: Направляйтесь непосредственно к соответствующему субнавыку.
