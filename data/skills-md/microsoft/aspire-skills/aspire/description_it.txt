**CAPEVOLEZZA DEL FLUSSO DI LAVORO** - Router di livello superiore per app distribuite Aspire 13.4. Rileva l'AppHost, applica i guardrail di sicurezza e indirizza alla competenza secondaria corretta. UTILIZZARE PER: Aspire AppHost rilevato, aspire CLI, app distribuita, .NET cloud-native, aspire start, aspire stop, aspire risorsa, aspire deploy, aspire destroy, aspire pubblica, aspire init, aspire new, aspire add, aspire integrazione elenco/ricerca, aspire wait, aspire description, aspire ps, aspire dashboard run, aspire doctor, aspire update, aspire logs, aspire otel, --include-hidden, aspireify, WithBrowserLogs, comandi dashboard/risorse personalizzati, ripristino .aspire/moduli, rilevamento URL Playwright. NON UTILIZZARE PER: progetti .NET non Aspire (usare direttamente dotnet), provisioning di Azure senza Aspire (usare azure-prepare), repository solo contenitore senza AppHost, attività di compilazione/test ordinarie. INVOCA: aspire-init, aspireify, aspire-orchestration, aspire-deployment, aspire-monitoring. PER OPERAZIONI SINGOLE: Indirizza direttamente alla sottoabilità corrispondente.
