**COMPÉTENCE DE FLUX DE TRAVAIL** - Routeur de haut niveau pour les applications distribuées Aspire 13.4. Détecte l'AppHost, applique les garde-fous de sécurité et achemine vers la sous-compétence appropriée. UTILISER POUR : Aspire AppHost détecté, aspire CLI, application distribuée, .NET cloud natif, aspire start, aspire stop, aspire resource, aspire move, aspire destroy, aspire submit, aspire init, aspire new, aspire add, aspire Integration list/search, aspire wait, aspirescribe, aspire ps, aspire Dashboard Run, aspire doctor, aspire update, aspire logs, aspire otel, --include-hidden, aspireify, WithBrowserLogs, commandes de tableau de bord/ressource personnalisées, Récupération .aspire/modules, découverte d'URL Playwright. NE PAS UTILISER POUR : les projets .NET non-Aspire (utiliser dotnet directement), le provisionnement Azure sans Aspire (utiliser azure-prepare), les dépôts de conteneurs uniquement sans AppHost, les tâches de construction/test ordinaires. INVOKE : aspire-init, aspireify, aspire-orchestration, aspire-deployment, aspire-monitoring. POUR LES OPÉRATIONS SIMPLES : accédez directement à la sous-compétence correspondante.
