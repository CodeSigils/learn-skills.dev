**مهارة سير العمل** - جهاز توجيه عالي المستوى لتطبيقات Aspire 13.4 الموزعة. يكتشف AppHost، ويفرض حواجز السلامة، ويوجه إلى المهارة الفرعية الصحيحة. الاستخدام لـ: تم اكتشاف Aspire AppHost، aspire CLI، التطبيق الموزع، .NET الأصلي للسحابة، أسباير ستارت، أسباير ستوب، أسباير الموارد، أسباير نشر، أسباير تدمير، أسباير نشر، أسباير init، أسباير جديد، أسباير إضافة، أسباير قائمة التكامل / البحث، أسباير الانتظار، أسباير وصف، أسباير ps، أسباير لوحة القيادة تشغيل، أسباير طبيب، أسباير التحديث، أسباير سجلات، أسباير أوتيل، - تضمين مخفي، aspireify، WithBrowserLogs، أوامر لوحة المعلومات/الموارد المخصصة، استرداد .aspire/modules، اكتشاف عنوان URL للكاتب المسرحي. لا تستخدمه في: مشاريع غير Aspire .NET (استخدم dotnet مباشرةً)، وتوفير Azure بدون Aspire (استخدم azure-prepare)، ومستودعات الحاوية فقط بدون AppHost، ومهام البناء/الاختبار العادية. يستدعي: aspire-init، aspireify، aspire-orchestration، aspire-deployment، aspire-monitoring. للعمليات الفردية: قم بالتوجيه مباشرة إلى المهارة الفرعية المطابقة.
