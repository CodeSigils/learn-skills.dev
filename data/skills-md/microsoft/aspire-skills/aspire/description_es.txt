**HABILIDAD DE FLUJO DE TRABAJO** - Enrutador de nivel superior para aplicaciones distribuidas Aspire 13.4. Detecta AppHost, aplica barreras de seguridad y dirige la habilidad secundaria correcta. USO PARA: Aspire AppHost detectado, Aspire CLI, aplicación distribuida, .NET nativo de la nube, Aspire Start, Aspire Stop, Aspire Resource, Aspire Implement, Aspire Destruy, Aspire Publish, Aspire Init, Aspire New, Aspire Add, Aspire Integration List/Search, Aspire Wait, Aspire describe, Aspire PS, Aspire Dashboard Run, Aspire Doctor, Aspire Update, Aspire Logs, Aspire Otel, --incluye-oculto, aspireify, WithBrowserLogs, comandos de recursos/panel personalizados, recuperación de .aspire/módulos, descubrimiento de URL de Playwright. NO LO UTILICE PARA: proyectos .NET que no sean de Aspire (use dotnet directamente), aprovisionamiento de Azure sin Aspire (use azure-prepare), repositorios solo de contenedor sin AppHost, tareas ordinarias de compilación/prueba. INVOCACIONES: aspire-init, aspireify, aspire-orchestration, aspire-deployment, aspire-monitoring. PARA OPERACIONES ÚNICAS: Diríjase directamente a la subhabilidad correspondiente.
