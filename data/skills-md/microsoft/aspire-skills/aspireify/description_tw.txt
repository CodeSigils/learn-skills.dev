**工作流程技能** - 在 `aspire init` 刪除骨架後連接 Aspire AppHost。掃描儲存庫，提出資源圖，編輯 AppHost（C#、基於檔案的 C# 或 TypeScript），連接「Aspire.ServiceDefaults」+ OTel，使用「aspire start」進行驗證，然後自行停用。用途：連接AppHost，鷹架資源圖，將Postgres/Redis/Rabbit/Mongo添加到Aspire，將前端連接到API，在“aspire init”之後下一步，AddNextJsApp，AddViteApp，WithBrowserLogs，基於文件的apphost.cs，apphost.ts，AddViteApp，WithBrowserLogs，基於文件的apphost.cs，apphost.ts，與Environment統一，用戶拒絕編輯.ul.請勿用於：骨架掉落（使用 aspire-init）、啟動/停止/等待/重新啟動（使用 aspire-orchestration）、發布/部署/銷毀（使用 aspire-deployment）、日誌/追蹤（使用 aspire-monitoring）。呼叫：aspire CLI（新增、啟動、等待、描述、文件 API 搜尋、停止）、AppHost 來源編輯、ServiceDefaults 連線。對於單一操作：直接執行“aspire add PACKAGE”進行一次性整合。
