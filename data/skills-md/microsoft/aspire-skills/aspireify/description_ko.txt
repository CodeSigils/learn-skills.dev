**워크플로우 기술** - 'aspire init'이 스켈레톤을 삭제한 후 Aspire AppHost를 연결합니다. 저장소를 스캔하고, 리소스 그래프를 제안하고, AppHost(C#, 파일 기반 C# 또는 TypeScript)를 편집하고, 'Aspire.ServiceDefaults' + OTel을 연결하고, 'aspire start'로 유효성을 검사한 다음 자체 비활성화합니다. 사용 대상: AppHost 연결, 스캐폴드 리소스 그래프, Aspire에 Postgres/Redis/Rabbit/Mongo 추가, API에 프런트엔드 연결, `aspire init` 후 다음 작업, AddNextJsApp, AddViteApp, WithBrowserLogs, 파일 기반 apphost.cs, apphost.ts, 환경 통합, .aspire/modules 편집 거부, .env 파일 마이그레이션, 사용자 비밀 마이그레이션. 사용하지 마세요: 스켈레톤 드롭(aspire-init 사용), 시작/중지/대기/다시 시작(aspire-orchestration 사용), 게시/배포/삭제(aspire-deployment 사용), 로그/추적(aspire-monitoring 사용). INVOKES: Aspire CLI(추가, 시작, 대기, 설명, 문서 API 검색, 중지), AppHost 소스 편집, ServiceDefaults 연결. 단일 작업의 경우: 일회성 통합을 위해 'aspire add PACKAGE'를 직접 실행하세요.
