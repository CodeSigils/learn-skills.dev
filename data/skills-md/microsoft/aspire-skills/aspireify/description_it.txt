** COMPETENZA DEL FLUSSO DI LAVORO ** - Collega un Aspire AppHost dopo che "aspire init" rilascia uno scheletro. Esegue la scansione del repository, propone un grafico delle risorse, modifica AppHost (C#, C# basato su file o TypeScript), collega `Aspire.ServiceDefaults` + OTel, convalida con `aspire start`, quindi si disattiva automaticamente. UTILIZZARE PER: wire AppHost, grafico delle risorse dell'impalcatura, aggiungere Postgres/Redis/Rabbit/Mongo ad Aspire, connettere il frontend all'API, dopo "aspire init" cosa succederà dopo, AddNextJsApp, AddViteApp, WithBrowserLogs, apphost.cs basato su file, apphost.ts, unificato conEnvironment, rifiutare la modifica di .aspire/modules, migrare file .env, migrare segreti utente. NON UTILIZZARE PER: skeleton drop (usare aspire-init), start/stop/wait/restart (usare aspire-orchestration), pubblicare/deploy/distruggere (usare aspire-deployment), log/tracce (usare aspire-monitoring). INVOCA: aspire CLI (aggiungi, avvia, attendi, descrivi, ricerca API documenti, arresta), modifiche all'origine AppHost, cablaggio ServiceDefaults. PER OPERAZIONI SINGOLE: esegui direttamente `aspire add PACKAGE` per un'integrazione una tantum.
