**HABILIDAD DE FLUJO DE TRABAJO** - Conecte un AppHost de Aspire después de que `aspire init` suelte un esqueleto. Escanea el repositorio, propone un gráfico de recursos, edita AppHost (C#, C# basado en archivos o TypeScript), conecta `Aspire.ServiceDefaults` + OTel, valida con `aspire start` y luego se autodesactiva. UTILIZAR PARA: conectar AppHost, gráfico de recursos de andamio, agregar Postgres/Redis/Rabbit/Mongo a Aspire, conectar la interfaz a la API, después de `aspire init` qué sigue, AddNextJsApp, AddViteApp, WithBrowserLogs, apphost.cs basado en archivos, apphost.ts, unificado conEnvironment, rechazar la edición de .aspire/modules, migrar archivos .env, migrar secretos de usuario. NO UTILIZAR PARA: caída de esqueleto (use aspire-init), iniciar/detener/esperar/reiniciar (use aspire-orchestration), publicar/implementar/destruir (use aspire-deployment), registros/rastros (use aspire-monitoreo). INVOCA: CLI de Aspire (agregar, iniciar, esperar, describir, buscar en la API de documentos, detener), ediciones de código fuente de AppHost, cableado de ServiceDefaults. PARA OPERACIONES ÚNICAS: Ejecute `aspire add PACKAGE` directamente para una integración única.
