**工作流程技能** - 在 `aspire init` 删除骨架后连接 Aspire AppHost。扫描存储库，提出资源图，编辑 AppHost（C#、基于文件的 C# 或 TypeScript），连接“Aspire.ServiceDefaults”+ OTel，使用“aspire start”进行验证，然后自行停用。用途：连接AppHost，脚手架资源图，将Postgres/Redis/Rabbit/Mongo添加到Aspire，将前端连接到API，在“aspire init”之后下一步，AddNextJsApp，AddViteApp，WithBrowserLogs，基于文件的apphost.cs，apphost.ts，与Environment统一，拒绝.aspire/modules编辑，迁移.env文件，迁移用户机密。请勿用于：骨架掉落（使用 aspire-init）、启动/停止/等待/重新启动（使用 aspire-orchestration）、发布/部署/销毁（使用 aspire-deployment）、日志/跟踪（使用 aspire-monitoring）。调用：aspire CLI（添加、启动、等待、描述、文档 API 搜索、停止）、AppHost 源编辑、ServiceDefaults 连接。对于单一操作：直接运行“aspire add PACKAGE”进行一次性集成。
