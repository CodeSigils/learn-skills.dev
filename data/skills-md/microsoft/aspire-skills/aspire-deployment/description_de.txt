**WORKFLOW-FÄHIGKEIT** – Stellen Sie Aspire-Apps von AppHost-Modellen in Docker Compose, Kubernetes, Azure oder AWS bereit. WANN: „Aspire-App bereitstellen“, „Aspire-Artefakte veröffentlichen“, „in Azure Container Apps bereitstellen“, „Kubernetes-Artefakte generieren“, „Aspire-Bereitstellung abbrechen“. AUFRUFEN: Aspire-CLI, Aspire-Dokumente, Ziel-Cloud-/Container-CLIs. FÜR EINZELNE VORGÄNGE: Verwenden Sie generische Azure-, Kubernetes-, Docker- oder AWS-Tools nur, wenn kein Aspire AppHost vorhanden ist.
