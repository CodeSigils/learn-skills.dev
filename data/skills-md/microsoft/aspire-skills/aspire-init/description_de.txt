**WORKFLOW-FÄHIGKEIT** – Erstausführungsablauf zum Hinzufügen von Aspire zu einem Repo. Wählt „aspire new“ (Greenfield) oder „aspire init“ (vorhandenes Repo), löscht das AppHost-Skelett und übergibt dann an „aspireify“ für die Ressourcenverkabelung. VERWENDEN FÜR: aspire init, aspire new, aspire-starter, aspire-ts-starter, aspire-py-starter, Aspire zu vorhandenem Repo hinzufügen, Aspire-App gerüsten, Aspire booten, kein AppHost erkannt, aspireify installieren, .aspire/modules generieren. NICHT VERWENDEN FÜR: AppHost-Verkabelung auf einem vorhandenen AppHost (verwenden Sie aspireify), Starten/Stoppen/Warten (verwenden Sie aspire-orchestration), Bereitstellen/Veröffentlichen (verwenden Sie aspire-deployment), Protokolle/Traces (verwenden Sie aspire-monitoring), Repo, das bereits über einen AppHost verfügt. AUFRUFEN: aspire CLI (init, new, doctor), aspireify (Übergabe nach Skeleton-Drop). FÜR EINZELNE VORGÄNGE: Führen Sie „aspire init“ oder „aspire new TEMPLATE“ direkt aus.
