**CAPEVOLEZZA DEL FLUSSO DI LAVORO**: flusso di prima esecuzione per aggiungere Aspire a un repository. Scegli "aspire new" (greenfield) o "aspire init" (repo esistente), elimina lo scheletro di AppHost, quindi passa ad "aspireify" per il cablaggio delle risorse. UTILIZZARE PER: aspire init, aspire new, aspire-starter, aspire-ts-starter, aspire-py-starter, aggiungi Aspire al repository esistente, impalcatura dell'app Aspire, bootstrap Aspire, nessun AppHost rilevato, installa aspireify, file .aspire/moduli generati. NON UTILIZZARE PER: cablaggio AppHost su un AppHost esistente (usa aspireify), avvio/arresto/attesa (usa aspire-orchestration), distribuzione/pubblicazione (usa aspire-deployment), log/tracce (usa aspire-monitoring), repository che dispone già di un AppHost. INVOCA: aspire CLI (init, new, doctor), aspireify (handoff dopo skeleton drop). PER OPERAZIONI SINGOLE: eseguire direttamente `aspire init` o `aspire new TEMPLATE`.
