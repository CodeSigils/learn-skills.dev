**分析スキル** - Aspire アプリを観察します: ログ、トレース、メトリクス、リソース状態、テレメトリ エクスポート、ブラウザ テレメトリ、スタンドアロン ダッシュボード。ローカルの Aspire CLI、AKS ワークロード診断、デプロイされた Azure リソースの正常性の間のルーティング。用途: aspire ログ、aspire otel ログ、aspire otel トレース、aspire otel スパン、aspire description、aspire ps、aspire エクスポート、aspire ダッシュボード実行、--include-hidden、ダッシュボードのブラウザー ログ、WithBrowserLogs、App Insights クエリ、AKS ポッド ログ、コンテナー アプリ ログ。次の目的には使用しないでください: start/stop/wait (aspire-orchestration を使用)、deploy/publish/destroy (aspire-deployment を使用)、WithBrowserLogs() などの AppHost コード編集 (aspireify を使用)、Azure プロビジョニング (azure-prepare を使用)。呼び出し: aspire CLI、azure-diagnostics (デプロイされた Azure)、kubectl + Container Insights。単一操作の場合: aspire CLI コマンドを直接実行して、簡単なログまたは記述ルックアップを実行します。
