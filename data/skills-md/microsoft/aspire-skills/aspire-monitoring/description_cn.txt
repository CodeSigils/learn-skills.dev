**分析技能** - 观察 Aspire 应用程序：日志、跟踪、指标、资源状态、遥测导出、浏览器遥测和独立仪表板。本地 Aspire CLI、AKS 工作负载诊断和部署的 Azure 资源运行状况之间的路由。用于：aspire 日志、aspire otel 日志、aspire otel 跟踪、aspire otel 跨度、aspire 描述、aspire ps、aspire 导出、aspire 仪表板运行、--include-hidden、仪表板中的浏览器日志、WithBrowserLogs、App Insights 查询、AKS pod 日志、容器应用程序日志。请勿用于：启动/停止/等待（使用 aspire-orchestration）、部署/发布/销毁（使用 aspire-deployment）、AppHost 代码编辑，例如 WithBrowserLogs()（使用 aspireify）、Azure 配置（使用 azure-prepare）。调用：aspire CLI、azure-diagnostics（已部署 Azure）、kubectl + Container Insights。对于单一操作：直接运行 aspire CLI 命令进行快速日志或描述查找。
