**HABILIDAD DE ANÁLISIS**: observe las aplicaciones de Aspire: registros, seguimientos, métricas, estado de los recursos, exportación de telemetría, telemetría del navegador y el panel independiente. Rutas entre la CLI local de Aspire, los diagnósticos de cargas de trabajo de AKS y el estado de los recursos de Azure implementados. USO PARA: registros de Aspire, registros de Aspire Otel, Aspire Otel Traces, Aspire Otel Spans, Aspire describe, Aspire PS, Aspire Export, Aspire Dashboard Run, --include-hidden, registros del navegador en el panel, WithBrowserLogs, consulta de App Insights, registros de pod de AKS, registros de aplicaciones de contenedor. NO UTILIZAR PARA: iniciar/detener/esperar (use aspire-orchestration), implementar/publicar/destruir (use aspire-deployment), ediciones de código de AppHost como WithBrowserLogs() (use aspireify), aprovisionamiento de Azure (use azure-prepare). INVOCA: aspire CLI, azure-diagnostics (Azure implementado), kubectl + Container Insights. PARA OPERACIONES ÚNICAS: Ejecute el comando CLI de Aspire directamente para realizar búsquedas rápidas de registros o descripciones.
