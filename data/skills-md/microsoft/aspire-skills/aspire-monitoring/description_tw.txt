**分析技能** - 觀察 Aspire 應用程式：日誌、追蹤、指標、資源狀態、遙測導出、瀏覽器遙測和獨立儀表板。本地 Aspire CLI、AKS 工作負載診斷和部署的 Azure 資源運作狀況之間的路由。用於：aspire 日誌、aspire otel 日誌、aspire otel 追蹤、aspire otel 跨度、aspire 描述、aspire ps、aspire 匯出、aspire 儀表板運行、--include-hidden、儀表板中的瀏覽器日誌、WithBrowserLogs、App Insights 查詢、AKS pod 查詢、容器應用程式。請勿用於：啟動/停止/等待（使用 aspire-orchestration）、部署/發布/銷毀（使用 aspire-deployment）、AppHost 程式碼編輯，例如 WithBrowserLogs()（使用 aspireify）、Azure 設定（使用 azure-prepare）。呼叫：aspire CLI、azure-diagnostics（已部署 Azure）、kubectl + Container Insights。對於單一操作：直接執行 aspire CLI 指令進行快速日誌或描述查找。
