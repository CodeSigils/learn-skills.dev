**CAPE DI ANALISI** - Osserva le app Aspire: registri, tracce, metriche, stato delle risorse, esportazione di telemetria, telemetria del browser e dashboard autonomo. Instradamenti tra l'interfaccia della riga di comando di Aspire locale, la diagnostica del carico di lavoro AKS e l'integrità delle risorse di Azure distribuite. UTILIZZARE PER: aspire logs, aspire otel logs, aspire otel traces, aspire otel spans, aspire description, aspire ps, aspire export, aspire dashboard run, --include-hidden, log del browser nel dashboard, WithBrowserLogs, query App Insights, log pod AKS, log app contenitore. NON UTILIZZARE PER: avviare/arrestare/attendere (usare aspire-orchestration), distribuire/pubblicare/distruggere (usare aspire-deployment), modifiche al codice AppHost come WithBrowserLogs() (usare aspireify), provisioning di Azure (usare azure-prepare). RICHIAMA: aspire CLI, azure-diagnostics (distribuito Azure), kubectl + Container Insights. PER OPERAZIONI SINGOLE: eseguire direttamente il comando CLI di aspire per effettuare ricerche di registro o descrivere rapidamente.
