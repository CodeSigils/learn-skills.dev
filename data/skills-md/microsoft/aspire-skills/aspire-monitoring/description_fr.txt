**COMPÉTENCE D'ANALYSE** - Observez les applications Aspire : journaux, traces, métriques, état des ressources, exportation de télémétrie, télémétrie du navigateur et tableau de bord autonome. Routes entre l’Aspire CLI locale, les diagnostics de charge de travail AKS et l’état des ressources Azure déployées. UTILISER POUR : les journaux Aspire, les journaux Aspire Otel, les traces Aspire Otel, les étendues Aspire Otel, Aspire décrire, Aspire PS, Aspire Export, Aspire Dashboard Run, --include-hidden, journaux de navigateur dans le tableau de bord, WithBrowserLogs, requête App Insights, journaux de pod AKS, journaux d'applications de conteneur. NE PAS UTILISER POUR : démarrer/arrêter/attendre (utiliser aspire-orchestration), déployer/publier/détruire (utiliser aspire-deployment), les modifications de code AppHost comme WithBrowserLogs() (utiliser aspireify), le provisionnement Azure (utiliser azure-prepare). INVOKES : aspire CLI, azure-diagnostics (Azure déployé), kubectl + Container Insights. POUR DES OPÉRATIONS SIMPLES : exécutez directement la commande aspire CLI pour un journal rapide ou des recherches de description.
