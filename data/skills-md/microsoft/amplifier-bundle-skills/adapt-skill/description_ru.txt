Адаптируйте навык, написанный для другого помощника по кодированию ИИ (Claude Code, Cursor и т. д.), в правильно структурированный файл Amplifier SKILL.md. Считывает исходный навык, определяет соглашения, специфичные для платформы, при необходимости исследует исходную платформу и создает собственный навык Amplifier, соответствующий спецификации навыков агента, с расширениями Amplifier. Используйте, когда пользователь хочет адаптировать навык, портировать навык, преобразовать навык в усилитель, перевести навык или имеет SKILL.md с другой платформы, которую он хочет перенести в Amplifier.
