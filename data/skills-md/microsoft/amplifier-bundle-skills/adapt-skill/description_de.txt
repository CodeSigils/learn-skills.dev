Passen Sie einen für einen anderen KI-Codierungsassistenten (Claude Code, Cursor usw.) geschriebenen Skill in eine ordnungsgemäß strukturierte Amplifier SKILL.md-Datei an. Liest den Quell-Skill, identifiziert plattformspezifische Konventionen, recherchiert bei Bedarf die Quellplattform und erstellt einen Amplifier-nativen Skill, der der Agent Skills-Spezifikation mit Amplifier-Erweiterungen entspricht. Verwenden Sie diese Option, wenn der Benutzer eine Fertigkeit anpassen, eine Fertigkeit portieren, eine Fertigkeit in einen Verstärker umwandeln oder eine Fertigkeit übersetzen möchte oder über eine SKILL.md von einer anderen Plattform verfügt, die er in Amplifier integrieren möchte.
