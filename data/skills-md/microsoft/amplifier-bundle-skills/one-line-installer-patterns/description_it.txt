Da utilizzare quando si progetta uno script di installazione con pipe per un progetto che non può utilizzare uv tool install o npmpublish: stack multiservizio (Docker Compose), app TS/React non elaborate, strumenti che avviano le dipendenze di sistema o installazioni per un pubblico non tecnico. Documenta il compromesso di sicurezza, la convenzione della comunità utilizzata da ruggine, bun, deno, fly, ollama e supabase e i casi in cui questo modello rappresenta la risposta sbagliata.
