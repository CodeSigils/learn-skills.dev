Modelli duramente conquistati per il sondaggio, la creazione, la risoluzione dei problemi e l'iterazione sugli endpoint API di Microsoft Graph, in particolare da un browser SPA che utilizza l'autenticazione MSAL.js delegata che chiama Graph direttamente senza backend (le lezioni si generalizzano a qualsiasi integrazione di Graph). Copre la metodologia dei file di sonda usa e getta per ridurre i rischi prima della creazione, le peculiarità di OData/query, la sequenza di autorizzazioni e consenso dell'amministratore, i modelli di accesso a registrazioni/trascrizioni (SharePoint REST, non Graph), i requisiti CSP per una SPA puramente browser, modelli di tentativi/impaginazione/backoff e la saga di debug del ciclo di reindirizzamento di autenticazione MSAL/EasyAuth. Da utilizzare durante l'integrazione con Microsoft Graph, API Teams, MSAL.js o EasyAuth; quando si verifica un errore grafico imprevisto (400/403/429), un errore silenzioso dell'ambito mancante, un ciclo di reindirizzamento di autenticazione o una violazione CSP che appare solo in produzione; o quando si decide come convalidare una nuova funzionalità del grafico prima di impegnarla in una base di codice.
