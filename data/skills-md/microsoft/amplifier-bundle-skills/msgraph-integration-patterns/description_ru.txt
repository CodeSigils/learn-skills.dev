С трудом завоеванные шаблоны для проверки, построения, устранения неполадок и итераций на конечных точках API Microsoft Graph — особенно из SPA браузера с использованием делегированной проверки подлинности MSAL.js, вызывающей Graph напрямую без серверной части (уроки распространяются на любую интеграцию Graph). Охватывает методологию одноразового файла-зонда для снижения рисков перед сборкой, особенности OData/запросов, последовательность разрешений и согласия администратора, шаблоны доступа к записям/расшифровкам (SharePoint REST, а не Graph), требования CSP для однобраузерного SPA, шаблоны повтора/пагинации/отсрочки, а также сагу об отладке цикла аутентификации-перенаправления MSAL/EasyAuth. Используйте при интеграции с Microsoft Graph, API Teams, MSAL.js или EasyAuth; при возникновении неожиданной ошибки Graph (400/403/429), тихого сбоя отсутствия области, цикла перенаправления аутентификации или нарушения CSP, которое появляется только в рабочей среде; или при принятии решения о том, как проверить новую возможность Graph перед ее фиксацией в базе кода.
