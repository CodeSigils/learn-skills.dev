Modèles durement gagnés pour tester, créer, dépanner et itérer sur les points de terminaison de l'API Microsoft Graph - en particulier à partir d'un SPA de navigateur utilisant l'authentification MSAL.js déléguée appelant Graph directement sans backend (les leçons se généralisent à toute intégration Graph). Couvre la méthodologie des fichiers de sonde jetables pour réduire les risques avant la construction, les bizarreries OData/requête, le séquençage des autorisations et du consentement de l'administrateur, les modèles d'accès aux enregistrements/transcriptions (SharePoint REST, pas Graph), les exigences CSP pour un SPA de navigateur pur, les modèles de nouvelle tentative/pagination/interruption et la saga de débogage de boucle d'authentification MSAL/EasyAuth. À utiliser lors de l'intégration avec Microsoft Graph, les API Teams, MSAL.js ou EasyAuth ; en cas d'erreur graphique inattendue (400/403/429), d'un échec silencieux de portée manquante, d'une boucle de redirection d'authentification ou d'une violation CSP qui n'apparaît qu'en production ; ou lorsque vous décidez comment valider une nouvelle fonctionnalité Graph avant de la valider dans une base de code.
