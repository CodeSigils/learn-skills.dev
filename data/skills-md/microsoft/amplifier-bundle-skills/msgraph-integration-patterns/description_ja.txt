Microsoft Graph API エンドポイントに対するプローブ、構築、トラブルシューティング、および反復処理のための苦労して得たパターン。特に、バックエンドなしで Graph を直接呼び出す委任された MSAL.js 認証を使用するブラウザー SPA からのパターン (レッスンはあらゆる Graph 統合に一般化されます)。ビルド前のリスクを回避するための使い捨てプローブ ファイルの方法論、OData/クエリの癖、アクセス許可と管理者の同意のシーケンス、記録/トランスクリプトのアクセス パターン (Graph ではなく SharePoint REST)、純粋なブラウザー SPA の CSP 要件、再試行/ページネーション/バックオフ パターン、MSAL/EasyAuth の認証リダイレクト ループのデバッグ手順について説明します。 Microsoft Graph、Teams API、MSAL.js、または EasyAuth と統合する場合に使用します。予期しないグラフ エラー (400/403/429)、サイレントなスコープ欠落エラー、認証リダイレクト ループ、または運用環境でのみ発生する CSP 違反が発生したとき。または、コードベースにコミットする前に新しいグラフ機能を検証する方法を決定するとき。
