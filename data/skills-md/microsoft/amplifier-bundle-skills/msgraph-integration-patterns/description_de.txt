Hart erkämpfte Muster für die Prüfung, Erstellung, Fehlerbehebung und Iteration von Microsoft Graph-API-Endpunkten – insbesondere von einem Browser-SPA mit delegierter MSAL.js-Authentifizierung, der Graph direkt ohne Backend aufruft (die Lektionen lassen sich auf jede Graph-Integration verallgemeinern). Behandelt die Throwaway-Probe-File-Methodik zur Risikoreduzierung vor dem Erstellen, OData/Abfrage-Macken, Berechtigungs- und Administrator-Zustimmungssequenzierung, Aufzeichnungen/Transkripte-Zugriffsmuster (SharePoint REST, nicht Graph), CSP-Anforderungen für eine reine Browser-SPA, Wiederholungs-/Paginierungs-/Backoff-Muster und die MSAL/EasyAuth-Authentifizierungs-Umleitungsschleifen-Debugging-Saga. Verwendung bei der Integration mit Microsoft Graph, Teams-APIs, MSAL.js oder EasyAuth; wenn ein unerwarteter Graph-Fehler (400/403/429), ein stiller fehlender Bereichsfehler, eine Authentifizierungsumleitungsschleife oder ein CSP-Verstoß auftritt, der nur in der Produktion auftritt; oder wenn Sie entscheiden, wie eine neue Graph-Funktion validiert werden soll, bevor Sie sie in eine Codebasis übernehmen.
