Patrones logrados con esfuerzo para sondear, crear, solucionar problemas e iterar en puntos finales de la API de Microsoft Graph, especialmente desde un navegador SPA que utiliza autenticación delegada de MSAL.js llamando a Graph directamente sin backend (las lecciones se generalizan a cualquier integración de Graph). Cubre la metodología de archivo de sonda desechable para eliminar riesgos antes de la compilación, peculiaridades de OData/consultas, secuenciación de permisos y consentimiento del administrador, patrones de acceso a grabaciones/transcripciones (SharePoint REST, no Graph), requisitos de CSP para un SPA de navegador puro, patrones de reintento/paginación/retraso y la saga de depuración de bucle de redireccionamiento de autenticación de MSAL/EasyAuth. Úselo al integrar con Microsoft Graph, API de Teams, MSAL.js o EasyAuth; cuando se produce un error de gráfico inesperado (400/403/429), una falla silenciosa de alcance faltante, un bucle de redireccionamiento de autenticación o una infracción de CSP que solo aparece en producción; o al decidir cómo validar una nueva capacidad de Graph antes de enviarla a una base de código.
