Analysieren Sie Bilder mit LLM Vision APIs (Anthropic Claude, OpenAI GPT-4, Google Gemini, Azure OpenAI). Verwenden Sie es, wenn Aufgaben Folgendes erfordern: (1) Bildinhalte verstehen, (2) visuelle Elemente beschreiben, (3) Fragen zu Bildern beantworten, (4) Bilder vergleichen, (5) Text aus Bildern extrahieren (OCR). Bietet gebrauchsfertige Skripte – für einfache Fälle ist kein benutzerdefinierter Code erforderlich.
