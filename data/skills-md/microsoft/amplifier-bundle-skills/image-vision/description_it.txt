Analizza le immagini utilizzando le API di visione LLM (Anthropic Claude, OpenAI GPT-4, Google Gemini, Azure OpenAI). Da utilizzare quando le attività richiedono: (1) comprendere il contenuto dell'immagine, (2) descrivere elementi visivi, (3) rispondere a domande sulle immagini, (4) confrontare immagini, (5) estrarre testo dalle immagini (OCR). Fornisce script pronti all'uso: non è necessario alcun codice personalizzato per i casi semplici.
