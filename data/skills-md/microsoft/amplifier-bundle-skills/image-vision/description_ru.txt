Анализируйте изображения с помощью API-интерфейсов LLM Vision (Anthropic Claude, OpenAI GPT-4, Google Gemini, Azure OpenAI). Используйте, когда задачи требуют: (1) Понимания содержимого изображения, (2) Описания визуальных элементов, (3) Ответов на вопросы об изображениях, (4) Сравнения изображений, (5) Извлечения текста из изображений (OCR). Предоставляет готовые к использованию сценарии — для простых случаев не требуется специальный код.
