Analice imágenes utilizando las API de visión de LLM (Anthropic Claude, OpenAI GPT-4, Google Gemini, Azure OpenAI). Úselo cuando las tareas requieran: (1) Comprender el contenido de la imagen, (2) Describir elementos visuales, (3) Responder preguntas sobre imágenes, (4) Comparar imágenes, (5) Extraer texto de imágenes (OCR). Proporciona secuencias de comandos listas para usar; no se necesita código personalizado para casos simples.
