Analysez des images à l'aide des API de vision LLM (Anthropic Claude, OpenAI GPT-4, Google Gemini, Azure OpenAI). À utiliser lorsque les tâches nécessitent : (1) Comprendre le contenu de l'image, (2) Décrire des éléments visuels, (3) Répondre à des questions sur les images, (4) Comparer des images, (5) Extraire du texte à partir d'images (OCR). Fournit des scripts prêts à l'emploi : aucun code personnalisé n'est nécessaire pour les cas simples.
