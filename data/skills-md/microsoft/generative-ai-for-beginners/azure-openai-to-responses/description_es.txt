Migre aplicaciones de Python desde Finalizaciones de chat de Azure OpenAI a Responses API. Cubre la migración del cliente AzureOpenAI/AsyncAzureOpenAI al punto final v1, streaming, herramientas, salida estructurada, múltiples turnos, autenticación EntraID y comprobaciones de compatibilidad de modelos. Centrado en Python, específico de Azure OpenAI. USO PARA: migrar a la API de respuestas, cambiar de finalizaciones de chat, respuestas de openai, actualizar el SDK de openai, migración de API de respuestas, pasar de finalizaciones a respuestas, migración de gpt-5, migración de python de azure openai, finalización de chat a respuestas, cliente de AzureOpenAI a OpenAI, actualización de python azure openai. NO UTILIZAR PARA: crear nuevas aplicaciones desde cero (comience con las respuestas directamente), migraciones de Nodo/TypeScript/C#/Java/Go (esta habilidad es solo de Python), configuración de infraestructura de Azure (use azure-prepare), implementación de modelos (use microsoft-foundry).
