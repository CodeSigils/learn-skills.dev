Мигрировать Python‑приложения с Azure OpenAI Chat Completions на API Responses. Охватывает миграцию клиента AzureOpenAI/AsyncAzureOpenAI к endpoint v1, потоковую передачу, инструменты, структурированный вывод, многократные диалоги, аутентификацию EntraID и проверки совместимости моделей. Ориентировано на Python, специфично для Azure OpenAI. ИСПОЛЬЗОВАТЬ ДЛЯ: миграции на API Responses, перехода от чат‑завершений, openai responses, обновления SDK openai, миграции API responses, перехода от completions к responses, миграции gpt‑5, миграции Azure OpenAI Python, от чат‑завершений к responses, AzureOpenAI к клиенту OpenAI, обновления Python Azure OpenAI. НЕ ИСПОЛЬЗОВАТЬ ДЛЯ: создания новых приложений с нуля (начинайте сразу с responses), миграций Node/TypeScript/C#/Java/Go (это умение только для Python), настройки инфраструктуры Azure (используйте azure-prepare), развертывания моделей (используйте microsoft-foundry). Пожалуйста, всегда отвечайте на языке пользователя.
