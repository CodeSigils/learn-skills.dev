Перенесите приложения Python из Azure OpenAI Chat Completions в API ответов. Охватывает миграцию клиента AzureOpenAI/AsyncAzureOpenAI на конечную точку версии 1, потоковую передачу, инструменты, структурированный вывод, многоповоротную проверку подлинности EntraID и проверки совместимости моделей. Ориентирован на Python и ориентирован на Azure OpenAI. ИСПОЛЬЗОВАНИЕ ДЛЯ: перехода к API ответов, переключения с завершения чата, ответов Openai, обновления SDK openai, миграции API ответов, перехода от завершения к ответам, миграции gpt-5, миграции Azure Openai Python, завершения чата в ответы, AzureOpenAI на клиент OpenAI, обновления Python Azure OpenAI. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания новых приложений с нуля (начинайте непосредственно с ответов), миграции Node/TypeScript/C#/Java/Go (этот навык доступен только для Python), настройки инфраструктуры Azure (используйте azure-prepare), развертывания моделей (используйте microsoft-foundry).
