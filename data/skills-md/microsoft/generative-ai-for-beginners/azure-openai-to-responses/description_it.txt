Eseguire la migrazione delle app Python da Azure OpenAI Chat Completions all'API Responses. Copre la migrazione del client AzureOpenAI/AsyncAzureOpenAI all'endpoint v1, streaming, strumenti, output strutturato, multiturno, autenticazione EntraID e controlli di compatibilità dei modelli. Focalizzato su Python, specifico per Azure OpenAI. UTILIZZARE PER: migrazione all'API delle risposte, passaggio dai completamenti della chat, risposte openai, aggiornamento dell'SDK di openai, migrazione dell'API delle risposte, passaggio dai completamenti alle risposte, migrazione gpt-5, migrazione di Azure Openai Python, completamenti della chat alle risposte, AzureOpenAI al client OpenAI, aggiornamento Python Azure Openai. NON UTILIZZARE PER: creazione di nuove app da zero (iniziare direttamente con le risposte), migrazioni Node/TypeScript/C#/Java/Go (questa competenza è solo Python), configurazione dell'infrastruttura di Azure (usare azure-prepare), distribuzione di modelli (usare microsoft-foundry).
