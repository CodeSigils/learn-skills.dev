Da utilizzare quando jj log mostra voci divergent(), più commit condividono un change_id, vengono visualizzati gli avvisi "Aggiunto commit della copia di lavoro come ... (divergente)" o il repository ha accumulato modifiche divergenti. Utilizzare anche per qualsiasi domanda sul motivo per cui jj mostra commit duplicati, come gli ID di modifica si riferiscono agli ID di commit o pulizia sistematica della divergenza dai rebase remoti.
