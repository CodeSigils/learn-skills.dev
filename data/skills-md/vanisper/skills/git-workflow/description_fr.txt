Compétence de workflow Git réutilisable. Utilisé pour gérer des opérations telles que le statut git, la mise en scène, la validation, le push, la demande d'extraction, la fusion de branches, la restauration, le référentiel distant et les balises. L'en-tête de commit doit suivre le style de commit Conventional Commits et Vanisper : type anglais, portée anglaise facultative, sujet suivant les préférences linguistiques du projet, longueur d'en-tête ne dépassant pas 72 caractères, les emojis peuvent être placés avant le type ou au début du sujet.
