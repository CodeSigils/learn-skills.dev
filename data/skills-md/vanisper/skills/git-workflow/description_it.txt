Abilità del flusso di lavoro Git riutilizzabile. Utilizzato per gestire operazioni quali stato git, staging, commit, push, pull request, unione di rami, rollback, repository remoto e tag. L'intestazione del commit deve seguire lo stile commitlint convenzionale e Vanisper: tipo inglese, ambito inglese opzionale, oggetto che segue le preferenze della lingua del progetto, lunghezza dell'intestazione non superiore a 72 caratteri, gli emoji possono essere posizionati prima del tipo o all'inizio dell'oggetto.
