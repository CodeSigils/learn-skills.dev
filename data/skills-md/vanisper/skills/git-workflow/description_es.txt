Habilidad de flujo de trabajo Git reutilizable. Se utiliza para manejar operaciones como estado de git, preparación, confirmación, envío, solicitud de extracción, fusión de ramas, reversión, repositorio remoto y etiquetas. El encabezado de confirmación debe seguir el estilo de confirmación convencional y Vanisper: tipo inglés, alcance opcional en inglés, tema siguiendo las preferencias de idioma del proyecto, longitud del encabezado no mayor a 72 caracteres, los emojis se pueden colocar antes del tipo o al comienzo del asunto.
