Рендеринг видео, опрос статуса рендеринга и загрузка локальных исходных файлов через
API шотстека. Используйте при создании клипов, построении автоматизированных видеоконвейеров,
загрузка видеоматериалов/аудио/изображений для использования в монтаже или организация облачного видео
рендеринг из сценария, агента или рабочего процесса CI.
НЕ для: потоковой передачи в реальном времени или прямой трансляции.
