Создавайте и выполняйте команды для получения данных японского фондового рынка с помощью интерфейса командной строки J-Quants (jquants). Поддерживает получение цен на акции, OHLC, минутных баров, тиков, остатков маржи, коэффициентов коротких продаж, фьючерсов и опционов, финансовых отчетов и дивидендов, данных TOPIX и индексов. Также проверяет доступность API для каждого плана и доступные периоды данных (бесплатный/легкий/стандартный/премиум).
