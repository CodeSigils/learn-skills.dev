Создавайте и выполняйте команды для получения данных японского фондового рынка с помощью J-Quants CLI (jquants). Поддерживает получение цен на акции, OHLC, минутных баров, тиков, остатков маржи, коэффициентов коротких продаж, фьючерсов и опционов, финансовых отчетов и дивидендов, а также данных TOPIX/индексов. Также проверяет доступность API и доступные периоды передачи данных для каждого плана (бесплатный/легкий/стандартный/премиум).
