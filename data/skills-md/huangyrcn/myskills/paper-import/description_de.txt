Importieren Sie einen Artikel in die lokale Literaturbibliothek: Metadaten, PDF, LaTeX-Quelle, Markdown und Code-Repo. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Arbeit abrufen, herunterladen, abrufen, finden, importieren oder speichern möchte – auch wenn er nur den Titel, die arXiv-ID oder den DOI nennt. Verwenden Sie es auch, wenn der Benutzer den Code/die Implementierung für einen Artikel finden oder klonen möchte. Auslöser: „下载论文“, „获取论文“, „找这篇论文“, „下载这篇“, „导入论文“, „Papier importieren“, „Papier holen“, „Papier holen“, „Papier herunterladen“, „找代码“, „下载代码“, „den Code finden“, „die Implementierung abrufen“, „das Repo klonen“, „有没有开源代码“ oder jede Erwähnung des Erwerbs eines Artikels oder seines Codes. Kann von anderen Fähigkeiten (Lit-Review, Idea-Discovery) mit einer arXiv-ID oder einem DOI stillschweigend aufgerufen werden. Ausgabe: literatur/{identifier}/ mit metadata.yaml, paper/ und optional repo/.
