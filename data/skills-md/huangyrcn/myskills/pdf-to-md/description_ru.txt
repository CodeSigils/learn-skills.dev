Преобразуйте PDF-файл в высококачественный Markdown с помощью конвейера VLM MinerU API. Используйте этот навык всякий раз, когда пользователю требуется преобразование PDF в Markdown, извлечение в стиле OCR, извлечение бумажного текста или Markdown плюс извлеченные изображения из PDF-файла. Этот навык поддерживает только серверную часть API и всегда использует высококачественную конфигурацию модели VLM.
