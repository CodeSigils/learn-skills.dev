قم بتحويل ملف PDF إلى Markdown عالي الجودة من خلال خط أنابيب MinerU API VLM. استخدم هذه المهارة عندما يريد المستخدم تحويل PDF إلى Markdown، أو الاستخراج مثل OCR، أو استخراج النص الورقي، أو Markdown بالإضافة إلى الصور المستخرجة من ملف PDF. تدعم هذه المهارة الواجهة الخلفية لواجهة برمجة التطبيقات (API) فقط وتستخدم دائمًا تكوين نموذج VLM عالي الجودة.
