Convierta un PDF en Markdown de alta calidad a través del canal MinerU API VLM. Utilice esta habilidad siempre que el usuario desee una conversión de PDF a Markdown, una extracción tipo OCR, una extracción de texto en papel o Markdown más imágenes extraídas de un PDF. Esta habilidad solo admite el backend de API y siempre utiliza la configuración del modelo VLM de alta calidad.
