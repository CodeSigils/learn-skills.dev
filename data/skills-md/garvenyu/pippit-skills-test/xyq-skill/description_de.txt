Abgedeckte Szenarien:  
- Generierung: Text-zu-Bild, Text-zu-Video, Bild-zu-Video, Animation, „Zeichne ein …“, „Erstelle ein …“  
- Bearbeiten: Ersetzen … durch …, Entfernen …, Hinzufügen …, Ändern in …, Anpassen …, Teilbearbeitungen, Kameraoptimierungen  
- Stiltransfer: Stilmigration, Neugestaltung, Stiltausch  
- Videoverlängerung und -fortsetzung  
- Erstellung von Videos/TVCs/Promos  
- Erstellung von Kurzdramen/Comic-Videos  
- Musik-MV-Generation  
- Produktanzeigen/Showcase-Videos  
- Storyboard/Design  
- Produktion von Lehr-/Kurzvideos  

Wird ausgelöst, wenn Benutzer Xiaoyunque oder xyq erwähnen, Referenzbilder/-videos hochladen oder den Generierungsfortschritt überprüfen.  
Schlüsselregel: Jede Anfrage, die die Erstellung, Generierung, Bearbeitung oder Änderung von KI-Videos betrifft – unabhängig vom Wortlaut (z. B. „Zeichne eine Katze“, „Erstelle ein Poster“, „Bearbeite dieses Video“, „Erstelle diesen Clip neu“, „Erstelle ein MV mit diesem Lied“, „Generiere ein kurzes Drama aus einer Zeile“) – muss diese Fähigkeit aktivieren.
