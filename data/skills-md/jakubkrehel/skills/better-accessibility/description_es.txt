Ingeniería de accesibilidad para interfaces de productos, desde estados de enfoque y compatibilidad con teclado hasta ARIA, formularios y lectores de pantalla. Úselo al crear o revisar componentes de la interfaz de usuario, modales, menús, formularios, widgets personalizados o cuando el usuario diga "hacer esto accesible" o informe problemas con el teclado o el lector de pantalla. Activadores de accesibilidad, a11y, WCAG, aria, anillo de enfoque, enfoque visible, trampa de enfoque, navegación con teclado, orden de tabulación, índice de tabulación, lector de pantalla, solo sr, aria-live, texto alternativo, área de impacto, objetivo táctil, movimiento reducido preferido, reproducción automática, duración del brindis, omisión de enlace, HTML semántico, etiqueta de aria, errores de formulario, botones deshabilitados, "no se puede acceder al teclado".
