Rédige des chapitres de romans Web (3 000 à 5 000 mots) en utilisant l'architecture double agent v5.1. Context Agent rassemble le contexte, l'écrivain produit du texte pur (pas de balises XML), examine les agents signalent les problèmes, peaufine les problèmes, Data Agent extrait les entités avec l'IA.
