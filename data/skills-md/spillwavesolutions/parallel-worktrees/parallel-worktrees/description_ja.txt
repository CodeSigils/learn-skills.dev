Claude Code サブエージェントを使用した git worktree を使用した並列開発。分離されたワークツリー間で複数の非同期クロード エージェントを生成する場合、並列実装を実行する場合、マルチ エージェント ワークフローを調整する場合、複数のソリューションに対して LLM 非決定論を活用する場合、または完了を通知するバックグラウンド エージェントを実行する場合に使用します。 「並列エージェント」、「ワークツリー」、「サブエージェント」、「非同期クロード」、「スポーン エージェント」、「並列開発」、「マルチエージェント ワークフロー」、「バックグラウンド エージェント」、「エージェント調整」、「並列タスク」でトリガーされます。
