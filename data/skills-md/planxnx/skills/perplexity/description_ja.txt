Perplexity MCP 使用ガイド (perplexity_search、perplexity_ask、および禁止されている perplexity_research / perplexity_reason)。 mcp__perplexity__* ツールを実行する前に、必ずこのスキルを使用してください。また、組み込みの WebSearch や Tavily が提供するよりも優れた結果 (「検索」、「見つける」、「調べる」、「最新情報」) が Web クエリで必要な場合、引用や Web に基づいたフォローアップの質問を含む総合的な回答が必要な場合、または詳細な調査や段階的な推論を Perplexity に呼び出す前に使用します。ライブラリ/フレームワークのドキュメント (Context7 を使用) や、このワークスペースに関する質問 (コードを読む) は対象外です。
