Guide d'utilisation du MCP Perplexity (perplexity_search, perplexity_ask et les fonctions interdites perplexity_research / perplexity_reason). UTILISEZ TOUJOURS cette compétence avant d'exécuter tout outil mcp__perplexity__*. Utilisez‑la également lorsqu'une requête web nécessite de meilleurs résultats que le WebSearch intégré ou Tavily (« search », « find », « look up », « what's the latest »), lorsque vous avez besoin d'une réponse synthétisée avec des citations ou des questions de suivi basées sur le web, ou avant tout appel de recherche approfondie ou de raisonnement pas à pas vers Perplexity. PAS pour la documentation de bibliothèques/cadres (utilisez Context7) ou les questions concernant cet espace de travail (lisez le code).

Veuillez toujours répondre dans la langue de l'utilisateur.
