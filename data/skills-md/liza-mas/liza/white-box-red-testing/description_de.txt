Finden Sie Fehler, indem Sie Tests schreiben, die bestehen sollten, aber nicht bestehen. Manueller Aufruf im vom Benutzer gewählten Bereich (Commits, Dateien oder Abdeckungsschwellenwert). Gibt rote Tests mit strukturierter Begründung aus. Wird verwendet, wenn der Benutzer einen „Stresstest“, „Fehlersuche“, „Angriff“ oder „Brechen“ des Codes verlangt.
