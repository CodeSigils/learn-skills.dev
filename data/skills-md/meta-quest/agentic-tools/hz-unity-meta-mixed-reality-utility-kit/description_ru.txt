Meta XR Mixed Reality Utility Kit (MRUK) (com.meta.xr.mrutilitykit) для разработки Unity XR. Используйте при работе с данными API сцены (комнаты, стены, полы, мебель), создании префабов на привязках сцены, размещении виртуальных объектов в реальном мире, блокировке мира для предотвращения смещения привязки, рейкастинге по геометрии комнаты, создании NavMesh из данных сцены, raycasting глубины среды для мгновенного размещения без сканирования, сквозного доступа к камере (PCA), отслеживаемого обнаружения (клавиатуры, QR-коды), разрушаемых сеток сцены, космических карт, совместного использования комнаты для многопользовательской игры или любого MR функция распознавания сцены.
