Meta XR Mixed Reality Utility Kit (MRUK) (com.meta.xr.mrutilitykit) per lo sviluppo di Unity XR. Da utilizzare quando si lavora con dati API Scene (stanze, pareti, pavimenti, mobili), generazione di prefabbricati su ancoraggi di scena, posizionamento di oggetti virtuali nel mondo reale, blocco del mondo per impedire la deriva dell'ancora, raycasting contro la geometria della stanza, generazione di NavMesh dai dati di scena, raycasting di profondità dell'ambiente per il posizionamento istantaneo senza scansione, Passthrough Camera Access (PCA), rilevamento tracciabile (tastiere, codici QR), mesh di scene distruttibili, mappe spaziali, condivisione di stanze per multiplayer o qualsiasi funzionalità di riconoscimento della scena MR.
