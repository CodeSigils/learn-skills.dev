Unity XR 開発用の Meta XR Mixed Reality Utility Kit (MRUK) (com.meta.xr.mrutilitykit)。シーン API データ (部屋、壁、床、家具) の操作、シーン アンカー上でのプレハブの生成、現実世界への仮想オブジェクトの配置、アンカー ドリフトを防ぐためのワールド ロック、部屋のジオメトリに対するレイキャスト、シーン データからの NavMesh の生成、スキャンなしで即座に配置するための環境深度レイキャスト、パススルー カメラ アクセス (PCA)、追跡可能な検出 (キーボード、QR コード)、破壊可能なシーン メッシュ、スペース マップ、マルチプレイヤー用のルーム共有、またはMR シーン対応機能。
