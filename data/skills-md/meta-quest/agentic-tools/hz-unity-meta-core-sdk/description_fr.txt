SDK Meta XR Core (com.meta.xr.sdk.core) pour le développement d'Unity XR. À utiliser lors de la configuration de projets VR/MR, de la configuration d'OVRManager, de l'ajout d'OVRCameraRig, de l'activation du passthrough, du suivi manuel, des ancres spatiales, du mode sans limites, de l'entrée du contrôleur, de l'API de scène ou de toute fonctionnalité Meta Quest XR. Couvre OVRProjectSetup, la génération AndroidManifest et la configuration du projet pour les casques Meta Quest.
