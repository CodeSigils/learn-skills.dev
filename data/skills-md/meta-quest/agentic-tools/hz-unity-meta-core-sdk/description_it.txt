Meta XR Core SDK (com.meta.xr.sdk.core) per lo sviluppo di Unity XR. Da utilizzare durante l'impostazione di progetti VR/MR, la configurazione di OVRManager, l'aggiunta di OVRCameraRig, l'abilitazione di passthrough, tracciamento manuale, ancoraggi spaziali, modalità senza confini, input del controller, API Scene o qualsiasi funzionalità Meta Quest XR. Copre OVRProjectSetup, generazione di AndroidManifest e configurazione del progetto per visori Meta Quest.
