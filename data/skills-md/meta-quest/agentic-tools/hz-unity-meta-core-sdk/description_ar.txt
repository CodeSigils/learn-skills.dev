Meta XR Core SDK (com.meta.xr.sdk.core) لتطوير Unity XR. يُستخدم عند إعداد مشاريع VR/MR، أو تكوين OVRManager، أو إضافة OVRCameraRig، أو تمكين العبور، أو تتبع اليد، أو نقاط التثبيت المكانية، أو الوضع غير المحدود، أو إدخال وحدة التحكم، أو Scene API، أو أي ميزة Meta Quest XR. يغطي OVRProjectSetup، وإنشاء AndroidManifest، وتكوين المشروع لسماعات الرأس Meta Quest.
