Meta XR Core SDK (com.meta.xr.sdk.core) für die Unity XR-Entwicklung. Zum Einrichten von VR/MR-Projekten, zum Konfigurieren von OVRManager, zum Hinzufügen von OVRCameraRig, zum Aktivieren von Passthrough, Handverfolgung, räumlichen Ankern, grenzenlosem Modus, Controller-Eingabe, Szenen-API oder einer beliebigen Meta Quest XR-Funktion. Behandelt OVRProjectSetup, AndroidManifest-Generierung und Projektkonfiguration für Meta Quest-Headsets.
