Meta XR Core SDK (com.meta.xr.sdk.core) для разработки Unity XR. Используйте при настройке проектов VR/MR, настройке OVRManager, добавлении OVRCameraRig, включении сквозного режима, отслеживания рук, пространственных привязок, безграничного режима, ввода контроллера, API сцены или любой функции Meta Quest XR. Охватывает OVRProjectSetup, генерацию AndroidManifest и настройку проекта для гарнитур Meta Quest.
