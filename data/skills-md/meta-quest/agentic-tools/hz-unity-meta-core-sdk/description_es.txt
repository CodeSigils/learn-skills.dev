Meta XR Core SDK (com.meta.xr.sdk.core) para el desarrollo de Unity XR. Úselo al configurar proyectos de VR/MR, configurar OVRManager, agregar OVRCeraRig, habilitar paso a través, seguimiento manual, anclajes espaciales, modo sin límites, entrada de controlador, API de escena o cualquier función de Meta Quest XR. Cubre OVRProjectSetup, generación de AndroidManifest y configuración de proyectos para auriculares Meta Quest.
