Utilisez cette compétence chaque fois que l'utilisateur vous donne une URL de référentiel GitHub et vous demande de la consulter,
trouvez des bugs et des opportunités d'optimisation, et soumettez un PR en tant que contributeur. Déclenchez-le également
lorsque l'utilisateur dit des choses comme "contributeur 帮我混个", "对这个仓库来一遍", "examiner ce dépôt",
"trouver des bugs et les corriger", ou toute demande impliquant l'audit d'une base de code pour trouver et résoudre des problèmes
avec une pull request. L'utilisateur ne peut pas toujours dire explicitement « évaluation et relations publiques » - il se peut simplement
collez une URL GitHub et attendez le flux de travail complet.
