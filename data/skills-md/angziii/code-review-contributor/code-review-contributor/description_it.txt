Utilizza questa abilità ogni volta che l'utente ti fornisce l'URL di un repository GitHub e ti chiede di rivederlo,
trova bug e opportunità di ottimizzazione e invia un PR come collaboratore. Anche innescarlo
quando l'utente dice cose come "帮我混个 collaboratore", "对这个仓库来一遍", "rivedi questo repository",
"trova bug e risolvili" o qualsiasi richiesta che coinvolga il controllo di una codebase per trovare e risolvere problemi
con una richiesta pull. L'utente potrebbe non sempre dire esplicitamente "recensione e PR", potrebbe semplicemente
incolla un URL GitHub e attendi il flusso di lavoro completo.
