Construit les flux de travail d'autocorrélation spatiale I de Moran dans CARTO. Se déclenche lorsque l'utilisateur mentionne l'autocorrélation spatiale, l'I de Moran, la dépendance spatiale, la corrélation spatiale, les valeurs aberrantes spatiales, les quadrants HH HL LH LL, les clusters haut-haut, les clusters bas-bas, la matrice de pondération spatiale, "y a-t-il un clustering", "les valeurs sont-elles corrélées spatialement", les indicateurs locaux d'association spatiale, LISA, le test de caractère aléatoire spatial, ou souhaite déterminer si une variable présente un clustering spatial, une dispersion ou un caractère aléatoire sur un ensemble de données maillé. Également pertinent lorsque l'utilisateur a besoin de classer les emplacements en types de clusters (HH, HL, LH, LL) plutôt que de simplement identifier les points chauds et les points froids.
