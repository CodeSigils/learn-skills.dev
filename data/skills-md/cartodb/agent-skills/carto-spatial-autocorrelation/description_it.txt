Costruisce i flussi di lavoro di autocorrelazione spaziale I di Moran in CARTO. Si attiva quando l'utente menziona l'autocorrelazione spaziale, l'I di Moran, la dipendenza spaziale, la correlazione spaziale, gli outlier spaziali, i quadranti HH HL LH LL, i cluster alto-alto, i cluster basso-basso, la matrice del peso spaziale, "è presente un clustering", "sono valori spazialmente correlati", indicatori locali di associazione spaziale, LISA, test di casualità spaziale o desidera determinare se una variabile presenta clustering spaziale, dispersione o casualità in un set di dati su griglia. Rilevante anche quando l'utente deve classificare le posizioni in tipi di cluster (HH, HL, LH, LL) anziché semplicemente identificare hotspot e punti freddi.
