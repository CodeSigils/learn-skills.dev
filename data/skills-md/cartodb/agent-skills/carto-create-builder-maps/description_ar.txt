قم بتأليف خرائط CARTO Builder وتحريرها ونشرها والتحقق من صحتها عبر واجهة سطر الأوامر "carto Maps". يُستخدم عندما يريد المستخدم إنشاء خريطة من طلب لغة طبيعية، أو تحرير خريطة موجودة (مجموعات البيانات، أو الطبقات، أو التصميم، أو الخصوصية، أو النوافذ المنبثقة، أو عناصر واجهة المستخدم، أو معلمات SQL)، أو تكرار خريطة، أو تحميل أيقونات علامات مخصصة، أو توصيل وكيل AI على الخريطة. يغطي سطح الأوامر الفرعية الكامل لخرائط carto - `list` و`get` و`create` و`update` و`delete` و`publish` و`validate` و`schema` و`agents` و`markers` و`screenshot` و`تحديث مجموعات البيانات`.
