「carto マップ」 CLI を介して、CARTO Builder マップを作成、編集、公開、検証します。ユーザーが自然言語リクエストからマップを作成する場合、既存のマップ (データセット、レイヤー、スタイル、プライバシー、ポップアップ、ウィジェット、SQL パラメーター) を編集する場合、マップを複製する場合、カスタム マーカー アイコンをアップロードする場合、またはマップ上に AI エージェントを接続する場合に使用します。 「carto Maps」サブコマンドの全領域 (「list」、「get」、「create」、「update」、「delete」、「publish」、「validate」、「schema」、「agents」、「markers」、「screenshot」、「datasets update」) をカバーします。
