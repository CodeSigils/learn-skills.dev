Erstellen, bearbeiten, veröffentlichen und validieren Sie CARTO Builder-Karten über die „Carto Maps“-CLI. Verwenden Sie diese Option, wenn der Benutzer eine Karte aus einer Anfrage in natürlicher Sprache erstellen, eine vorhandene Karte bearbeiten (Datensätze, Ebenen, Stil, Datenschutz, Popups, Widgets, SQL-Parameter), eine Karte duplizieren, benutzerdefinierte Markierungssymbole hochladen oder einen KI-Agenten auf einer Karte vernetzen möchte. Deckt die gesamte Unterbefehlsoberfläche von „Carto Maps“ ab – „list“, „get“, „create“, „update“, „delete“, „publish“, „validate“, „schema“, „agents“, „markers“, „screenshot“, „datasets update“.
