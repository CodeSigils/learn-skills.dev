Rendern Sie eine interaktive Ad-hoc-Karte inline im Chat aus einer deklarativen Deck.gl-Spezifikation über das view_map-Tool des CARTO MCP-Servers. Verwenden Sie es immer dann, wenn der Benutzer die geografische Verteilung von Punkten, Polygonen, Sechsecken, Quadbins, Clustern, der Dichte (Heatmaps) oder einem Raster kartieren, visualisieren oder anzeigen möchte – und die Karte explorativ oder wegwerfbar ist und nicht dazu gedacht ist, als permanente CARTO Builder-Karte gespeichert zu werden. Löst aus bei „Zeige mir X auf einer Karte“, „visualisiere Y“, „erstelle eine Heatmap von Z“, „rendere die Punkte/Cluster/Raster von W“. Unterscheidet sich von carto-create-builder-maps (CLI-Erstellung permanenter Karten), carto-preview-builder-map (Laden einer vorhandenen gespeicherten Builder-Karte) und carto-develop-app (Schreiben einer völlig neuen deck.gl-App in TypeScript/JavaScript).
