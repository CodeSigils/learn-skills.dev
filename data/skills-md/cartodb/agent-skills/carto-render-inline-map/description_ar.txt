قم بعرض خريطة تفاعلية مخصصة مضمنة في الدردشة من المواصفات التعريفية Deck.gl عبر أداة view_map الخاصة بخادم CARTO MCP. يُستخدم عندما يطلب المستخدم رسم خريطة أو تصور أو عرض التوزيع الجغرافي للنقاط أو المضلعات أو الأشكال السداسية أو المربعات الرباعية أو المجموعات أو الكثافة (الخرائط الحرارية) أو البيانات النقطية - وتكون الخريطة استكشافية أو مجردة، وليس المقصود منها حفظها كخريطة CARTO Builder دائمة. المشغلات على "إظهار X على الخريطة"، و"تصور Y"، و"إنشاء خريطة حرارية لـ Z"، و"عرض النقاط/المجموعات/النقطية لـ W". يختلف عن carto-create-builder-maps (تأليف CLI للخرائط الدائمة)، وcarto-preview-builder-map (تحميل خريطة Builder المحفوظة الموجودة)، وcarto-develop-app (كتابة تطبيق Deck.gl من الصفر في TypeScript / JavaScript).
