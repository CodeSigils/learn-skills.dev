CARTO MCP サーバーの view_map ツールを介して、deck.gl 宣言仕様からチャット内でアドホック インタラクティブ マップをインラインでレンダリングします。ユーザーがポイント、ポリゴン、六角形、クワッドビン、クラスター、密度 (ヒートマップ)、またはラスターの地理的分布をマップ、視覚化、または表示するように要求する場合は常に使用します。マップは探索的または使い捨てであり、永続的な CARTO Builder マップとして保存することを目的としていません。 「マップ上に X を表示」、「Y を視覚化」、「Z のヒートマップを作成」、「W のポイント/クラスター/ラスターをレンダリング」をトリガーします。 carto-create-builder-maps (永続マップの CLI オーサリング)、carto-preview-builder-map (保存されている既存の Builder マップのロード)、carto-develop-app (TypeScript / JavaScript でスクラッチからデッキ.gl アプリを作成) とは異なります。
