ابدأ هنا لاستخدام CARTO لأول مرة — قم بتثبيت واجهة سطر الأوامر (CLI)، والمصادقة، وتبديل ملفات التعريف، وفهم مخرجات JSON وأنماط المهام غير المتزامنة. يوجه أيضًا مساري الوصول المتوازيين إلى منصة CARTO (CLI للتأليف/البرمجة النصية، وخادم MCP للتفاعلات المضمنة في مضيفي الدردشة) والمهارات التي تغطي كل منهما.
