Commencez ici pour la première utilisation de CARTO : installez la CLI, authentifiez-vous, changez de profil, comprenez la sortie JSON et les modèles de tâches asynchrones. Oriente également sur les deux chemins d'accès parallèles à la plate-forme CARTO (CLI pour la création/les scripts, le serveur MCP pour les interactions en ligne dans les hôtes de discussion) et sur les compétences couvertes par chacun.
