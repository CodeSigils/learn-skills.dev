Комплексный ArcGIS Portal / AGOL → миграция CARTO. Срабатывает, когда пользователь хочет перенести контент ArcGIS в CARTO, планирует миграцию, спрашивает «что у меня на портале», называет URL-адрес портала/AGOL или просит перенести наборы данных/веб-карты/простые приложения. Выполняется в три этапа — обнаружение (перечисление элементов + запись MIGRATION_MANIFEST.md), миграция данных (размещенные векторные слои/таблицы → таблицы CARTO), миграция карт (веб-карты + простые информационные панели/веб-интерфейсы/веб-картографические приложения → карты CARTO Builder). Режим по умолчанию — пакетный; перенесенные карты всегда имеют тег «Из ArcGIS» и создаются как частные.
