Portal ArcGIS de extremo a extremo / AGOL → Migración CARTO. Se activa cuando el usuario desea migrar contenido de ArcGIS a CARTO, planificar una migración, pregunta "qué hay en mi Portal", nombra una URL de Portal/AGOL o solicita migrar los conjuntos de datos/mapas web/aplicaciones simples. Ejecuta tres fases: descubrir (enumerar elementos + escribir MIGRATION_MANIFEST.md), migrar datos (capas de funciones alojadas/tablas → tablas CARTO), migrar mapas (mapas web + paneles simples/experiencias web/aplicaciones de mapas web → mapas CARTO Builder). El modo predeterminado es por lotes; Los mapas migrados siempre se etiquetan como "Desde ArcGIS" y se crean como privados.
