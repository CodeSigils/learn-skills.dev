End-to-End ArcGIS Portal / AGOL → CARTO-Migration. Wird ausgelöst, wenn der Benutzer ArcGIS-Inhalte nach CARTO migrieren möchte, eine Migration plant, fragt „Was ist in meinem Portal“, eine Portal-/AGOL-URL benennt oder die Datensätze/Webkarten/einfache Apps migrieren möchte. Führt drei Phasen aus: Entdecken (Elemente aufzählen + MIGRATION_MANIFEST.md schreiben), Daten migrieren (gehostete Feature-Layer/Tabellen → CARTO-Tabellen), Karten migrieren (Webkarten + einfache Dashboards/Web-Erlebnisse/Web-Mapping-Apps → CARTO Builder-Karten). Der Standardmodus ist Batch. Migrierte Karten werden immer mit „Von ArcGIS“ gekennzeichnet und als privat erstellt.
