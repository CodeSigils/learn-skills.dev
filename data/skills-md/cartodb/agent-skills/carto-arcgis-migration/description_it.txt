Portale ArcGIS end-to-end / AGOL → Migrazione CARTO. Si attiva quando l'utente desidera migrare il contenuto ArcGIS su CARTO, pianificare una migrazione, chiede "cosa c'è nel mio portale", nomina un URL portale/AGOL o chiede di migrare set di dati/mappe Web/app semplici. Esegue tre fasi: discover (enumerare gli elementi + scrivere MIGRATION_MANIFEST.md), migrate-data (Hosted Feature Layers/Tabelle → Tabelle CARTO), migrate-maps (Mappe Web + Dashboard semplici/Esperienze Web/App di mappatura Web → Mappe CARTO Builder). La modalità predefinita è batch; le mappe migrate vengono sempre contrassegnate con "Da ArcGIS" e create come private.
