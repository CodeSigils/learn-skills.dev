エンドツーエンドの ArcGIS Portal / AGOL → CARTO の移行。ユーザーが ArcGIS コンテンツを CARTO に移行する場合、移行を計画する場合、「ポータルに何があるか」を尋ねる場合、ポータル/AGOL URL に名前を付ける場合、またはデータセット/Web マップ/シンプル アプリの移行を要求する場合にトリガーされます。 3 つのフェーズを実行します - 検出 (アイテムの列挙 + MIGRATION_MANIFEST.md の書き込み)、データの移行 (ホスト フィーチャ レイヤー/テーブル → CARTO テーブル)、移行マップ (Web マップ + シンプルなダッシュボード / Web エクスペリエンス / Web マッピング アプリ → CARTO ビルダー マップ)。デフォルトのモードはバッチです。移行されたマップには常に「From ArcGIS」というタグが付けられ、プライベートとして作成されます。
