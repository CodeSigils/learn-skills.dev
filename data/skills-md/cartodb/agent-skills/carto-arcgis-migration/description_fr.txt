Migration Portail ArcGIS / AGOL → CARTO de bout en bout. Se déclenche lorsque l'utilisateur souhaite migrer le contenu ArcGIS vers CARTO, planifier une migration, demande « ce qu'il y a dans mon portail », nomme une URL de portail/AGOL ou demande de migrer les ensembles de données/cartes Web/applications simples. Exécute trois phases : découverte (énumération des éléments + écriture de MIGRATION_MANIFEST.md), migration des données (couches de fonctionnalités hébergées/tables → tables CARTO), migration des cartes (cartes Web + tableaux de bord simples/expériences Web/applications de cartographie Web → cartes CARTO Builder). Le mode par défaut est batch ; les cartes migrées sont toujours étiquetées « Depuis ArcGIS » et créées comme privées.
