يبني سير عمل تخطيط المناطق في CARTO ويجمع بين موازنة المناطق وتخصيص الموقع. يتم تشغيله عندما يذكر المستخدم موازنة المنطقة، أو تخطيط المنطقة، أو مناطق المبيعات، أو مناطق الخدمة، أو توزيع عبء العمل، أو المناطق المتوازنة، أو تخصيص الموقع، أو وضع المنشأة، أو المواقع المثالية، أو زيادة التغطية إلى الحد الأقصى، أو تقليل التكلفة، أو تقليل مسافة السفر، أو وضع المستودع، أو وضع المحور، أو تحديد موقع المستودع، أو تحسين وقت الاستجابة، أو تغطية الطلب، أو يريد تقسيم منطقة إلى مناطق متوازنة أو العثور على مواقع المرافق المثالية.
