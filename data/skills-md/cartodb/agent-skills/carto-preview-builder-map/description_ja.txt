CARTO MCP サーバーのload_builder_map ツールを使用して、チャット内で既存の保存済み CARTO Builder マップをインラインでプレビューします。ユーザーが保存された Builder マップを URL、ID、または名前 (最初に list_maps によって解決) で参照する場合は常に使用します。軽量の読み取り専用プレビュー (レイヤー、ベースマップ、ビューポート、ポップアップ、凡例) をレンダリングします。ウィジェット、SQL パラメーター、マップの説明、およびその他の Builder のみの機能は含まれていません。ユーザーは「ビルダーで開く」をクリックすると、完全なエクスペリエンスを得ることができます。 「X マップを表示」、「Y マップを開く」、「Z マップをプレビュー」、および新しく作成されたマップの CLI 作成後のインライン プレビューをトリガーします。 carto-create-builder-maps (CLI オーサリング)、carto-render-inline-map (アドホック Deck.gl 仕様)、carto-develop-app (開発者アプリ) とは異なります。
