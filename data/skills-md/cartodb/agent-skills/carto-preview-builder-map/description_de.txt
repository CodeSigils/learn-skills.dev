Vorschau einer vorhandenen gespeicherten CARTO Builder-Karte inline im Chat über das Tool „load_builder_map“ des CARTO MCP-Servers. Wird immer dann verwendet, wenn der Benutzer auf eine gespeicherte Builder-Karte verweist – nach URL, nach ID oder nach Namen (zuerst über list_maps aufgelöst). Rendert eine kompakte, schreibgeschützte Vorschau (Ebenen, Grundkarte, Ansichtsfenster, Popups, Legende). Widgets, SQL-Parameter, Kartenbeschreibung und andere Nur-Builder-Funktionen sind NICHT enthalten; Der Benutzer kann für das vollständige Erlebnis auf „In Builder öffnen“ klicken. Wird ausgelöst bei „Zeige mir die X-Karte“, „öffne die Y-Karte“, „Vorschau der Z-Karte“ und Inline-Vorschau nach der CLI-Erstellung einer frisch erstellten Karte. Unterscheidet sich von carto-create-builder-maps (CLI-Authoring), carto-render-inline-map (ad-hoc deck.gl-Spezifikation) und carto-develop-app (Entwickler-App).
