CARTO MCP 서버의 load_builder_map 도구를 통해 채팅에서 기존에 저장된 CARTO Builder 맵 인라인을 미리 봅니다. 사용자가 저장된 빌더 맵을 URL, ID 또는 이름(먼저 list_maps를 통해 확인됨)으로 참조할 때마다 사용합니다. 간단한 읽기 전용 미리보기(레이어, 베이스맵, 뷰포트, 팝업, 범례)를 렌더링합니다. 위젯, SQL 매개변수, 지도 설명 및 기타 빌더 전용 기능은 포함되지 않습니다. 사용자는 전체 경험을 위해 "빌더에서 열기"를 클릭할 수 있습니다. "X 맵 표시", "Y 맵 열기", "Z 맵 미리보기" 및 새로 생성된 맵의 CLI 생성 후 인라인 미리 보기를 트리거합니다. carto-create-builder-maps(CLI 작성), carto-render-inline-map(ad-hoc Deck.gl 사양) 및 carto-develop-app(개발자 앱)과 다릅니다.
