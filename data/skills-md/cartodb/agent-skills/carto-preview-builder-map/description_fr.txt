Prévisualisez une carte CARTO Builder enregistrée existante en ligne dans le chat via l'outil load_builder_map du serveur CARTO MCP. À utiliser chaque fois que l'utilisateur fait référence à une carte Builder enregistrée — par URL, par ID ou par nom (résolu d'abord via list_maps). Affiche un aperçu léger en lecture seule (couches, fond de carte, fenêtre, fenêtres contextuelles, légende). Les widgets, les paramètres SQL, la description de la carte et d'autres fonctionnalités réservées au générateur ne sont PAS inclus ; l'utilisateur peut cliquer sur "Ouvrir dans Builder" pour une expérience complète. Déclencheurs sur "montrez-moi la carte X", "ouvrez la carte Y", "prévisualisez la carte Z" et les aperçus en ligne post-création CLI d'une carte fraîchement créée. Distinct de carto-create-builder-maps (création CLI), carto-render-inline-map (spécification ad hoc deck.gl) et carto-develop-app (application de développement).
