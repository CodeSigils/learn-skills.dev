Предварительный просмотр существующей сохраненной карты CARTO Builder в чате с помощью инструмента load_builder_map сервера CARTO MCP. Используйте всякий раз, когда пользователь ссылается на сохраненную карту Builder — по URL-адресу, по идентификатору или по имени (сначала разрешается через list_maps). Отображает облегченный предварительный просмотр, доступный только для чтения (слои, базовая карта, область просмотра, всплывающие окна, легенда). Виджеты, параметры SQL, описание карты и другие функции, доступные только в Builder, НЕ включены; пользователь может нажать «Открыть в Builder», чтобы получить все возможности. Триггеры «покажи мне карту X», «открой карту Y», «предварительный просмотр карты Z» и встроенный предварительный просмотр только что созданной карты после создания CLI. В отличие от carto-create-builder-maps (разработка CLI), carto-render-inline-map (специальная спецификацияeck.gl) и carto-develop-app (приложение для разработчика).
