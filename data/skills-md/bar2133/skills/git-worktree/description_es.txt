Cree y administre árboles de trabajo de git para trabajos de corrección de errores o funciones aisladas. Maneja espacios de trabajo (planos) de repositorio único y múltiple con detección automática. Úselo cuando el usuario quiera comenzar a trabajar en una nueva característica o corregir un error en una rama aislada, configurar árboles de trabajo en múltiples repositorios o limpiar árboles de trabajo terminados.
