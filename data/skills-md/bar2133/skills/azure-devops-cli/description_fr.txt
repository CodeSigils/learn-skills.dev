Installez et configurez Azure CLI avec l'extension Azure DevOps sur macOS à l'aide de Homebrew. Gère la connexion, la configuration par défaut de l’organisation/du projet et les contrôles d’intégrité. À utiliser lorsque l’utilisateur souhaite configurer les outils Azure DevOps CLI, installer az cli, configurer les valeurs par défaut d’az devops ou dépanner sa configuration Azure DevOps CLI sur macOS.
