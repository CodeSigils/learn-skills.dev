Установите и настройте Azure CLI с расширением Azure DevOps в macOS с помощью Homebrew. Обрабатывает вход в систему, конфигурацию организации/проекта по умолчанию и проверки работоспособности. Используйте, когда пользователь хочет настроить инструменты Azure DevOps CLI, установить az cli, настроить параметры az devops по умолчанию или устранить неполадки при настройке Azure DevOps CLI в macOS.
