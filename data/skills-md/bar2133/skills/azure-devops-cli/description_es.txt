Instale y configure la CLI de Azure con la extensión Azure DevOps en macOS mediante Homebrew. Maneja el inicio de sesión, la configuración predeterminada de la organización/proyecto y las comprobaciones de estado. Úselo cuando el usuario desee configurar herramientas de la CLI de Azure DevOps, instalar az cli, configurar los valores predeterminados de az devops o solucionar problemas de la configuración de la CLI de Azure DevOps en macOS.
