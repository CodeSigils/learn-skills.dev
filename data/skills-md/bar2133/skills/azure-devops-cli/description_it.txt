Installa e configura l'interfaccia della riga di comando di Azure con l'estensione Azure DevOps in macOS usando Homebrew. Gestisce l'accesso, la configurazione predefinita dell'organizzazione/progetto e i controlli di integrità. Da usare quando l'utente vuole configurare gli strumenti dell'interfaccia della riga di comando di Azure DevOps, installare az cli, configurare le impostazioni predefinite di az devops o risolvere i problemi di configurazione dell'interfaccia della riga di comando di Azure DevOps in macOS.
