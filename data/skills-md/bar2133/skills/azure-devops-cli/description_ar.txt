قم بتثبيت Azure CLI وتكوينه باستخدام ملحق Azure DevOps على نظام التشغيل macOS باستخدام Homebrew. يتعامل مع تسجيل الدخول والتكوين الافتراضي للمؤسسة/المشروع وفحوصات السلامة. يُستخدم عندما يريد المستخدم إعداد أدوات Azure DevOps CLI، أو تثبيت az cli، أو تكوين الإعدادات الافتراضية لـ az devOps، أو استكشاف أخطاء إعداد Azure DevOps CLI وإصلاحها على نظام التشغيل macOS.
