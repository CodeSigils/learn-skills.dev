قم بتنفيذ منطق إعادة محاولة طلب HTTP باستخدام نظام البرنامج الوسيط للعميل الأصلي الخاص بـ aiohttp. يُستخدم عندما يريد المستخدم إضافة عمليات إعادة المحاولة لطلبات aiohttp، أو التعامل مع أخطاء HTTP العابرة (429، 5xx)، أو جعل مكالمات HTTP غير المتزامنة أكثر مرونة - بدون مكتبات إعادة المحاولة التابعة لجهات خارجية.
