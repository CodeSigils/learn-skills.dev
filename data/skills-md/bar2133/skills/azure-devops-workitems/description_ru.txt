Изучите рабочие элементы Azure DevOps и управляйте ими: эпики, функции, пользовательские истории и задачи. Предоставляет обзор проекта (дерево), получение эпической информации, получение функции, создание рабочего элемента и редактирование режимов рабочего элемента. Используйте, когда пользователь хочет составить список эпиков, просмотреть функции, просмотреть рабочие элементы, создать задачи, отредактировать пользовательские истории или изучить невыполненную работу в Azure DevOps.
