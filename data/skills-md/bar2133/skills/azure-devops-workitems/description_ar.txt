استكشف عناصر عمل Azure DevOps وإدارتها: الملاحم والميزات وقصص المستخدم والمهام. يوفر نظرة عامة على المشروع (شجرة)، والحصول على الملحمة، والحصول على الميزة، وإنشاء عنصر عمل، وتحرير أوضاع عنصر العمل. يُستخدم عندما يريد المستخدم سرد الملاحم أو عرض الميزات أو استعراض عناصر العمل أو إنشاء المهام أو تحرير قصص المستخدم أو استكشاف الأعمال المتراكمة في Azure DevOps.
