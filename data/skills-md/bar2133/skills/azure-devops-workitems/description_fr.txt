Explorez et gérez les éléments de travail Azure DevOps : Epics, fonctionnalités, témoignages utilisateur et tâches. Fournit une vue d'ensemble du projet (arborescence), obtient l'épopée, obtient une fonctionnalité, crée un élément de travail et modifie les modes d'élément de travail. À utiliser lorsque l'utilisateur souhaite répertorier les epics, afficher les fonctionnalités, parcourir les éléments de travail, créer des tâches, modifier les user stories ou explorer le backlog dans Azure DevOps.
