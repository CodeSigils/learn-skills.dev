Менеджер жизненного цикла конкретных задач для агентов кодирования ИИ. Опрашивает пользователя для устранения двусмысленностей, разлагает спецификации на атомарные задачи, управляет порядком выполнения с помощью графа зависимостей и завершает пакет с доказательствами. Используйте, когда пользователь хочет реализовать спецификацию, спланировать задачи, разложить функцию, существует файл *.tasks.json или пользователь говорит «продолжить с tp», чтобы возобновить работу после очистки контекста.
