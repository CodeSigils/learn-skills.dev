Gestionnaire de cycle de vie spécification-tâche pour les agents de codage IA. Interviewe l'utilisateur pour résoudre les ambiguïtés, décompose les spécifications en tâches atomiques, gère l'ordre d'exécution via un graphique de dépendances et clôture le lot avec des preuves. À utiliser lorsque l'utilisateur souhaite implémenter une spécification, planifier des tâches, décomposer une fonctionnalité, qu'un fichier *.tasks.json existe ou que l'utilisateur dit « continuer avec tp » pour reprendre le travail après un contexte clair.
