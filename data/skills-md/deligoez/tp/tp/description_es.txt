Administrador del ciclo de vida de especificaciones a tareas para agentes de codificación de IA. Entrevista al usuario para resolver ambigüedades, descompone las especificaciones en tareas atómicas, gestiona el orden de ejecución a través de un gráfico de dependencia y cierra lotes con evidencia. Úselo cuando el usuario quiera implementar una especificación, planificar tareas, descomponer una característica, exista un archivo *.tasks.json o el usuario diga "continuar con tp" para reanudar el trabajo después de borrar el contexto.
