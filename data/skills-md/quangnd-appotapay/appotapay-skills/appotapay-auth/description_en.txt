Build the AppotaPay authentication JWT (the X-APPOTAPAY-AUTH header) and sign request parameters. Use when integrating AppotaPay and you need to authenticate API calls, create/refresh the JWT token, understand the HS256 JWT claims (iss, jti, api_key, exp), or compute the HMAC-SHA256 request signature from PARTNER_CODE / API_KEY / SECRET_KEY. Required by every other AppotaPay API call.
