Cree el JWT de autenticación de AppotaPay (el encabezado X-APPOTAPAY-AUTH) y firme los parámetros de solicitud. Úselo cuando integre AppotaPay y necesite autenticar llamadas API, crear/actualizar el token JWT, comprender las reclamaciones HS256 JWT (iss, jti, api_key, exp) o calcular la firma de solicitud HMAC-SHA256 desde PARTNER_CODE / API_KEY / SECRET_KEY. Requerido por todas las demás llamadas a la API de AppotaPay.
