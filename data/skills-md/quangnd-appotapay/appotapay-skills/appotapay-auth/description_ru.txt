Создайте JWT аутентификации AppotaPay (заголовок X-APPOTAPAY-AUTH) и подпишите параметры запроса. Используйте при интеграции AppotaPay, когда вам необходимо аутентифицировать вызовы API, создать/обновить токен JWT, понять утверждения JWT HS256 (iss, jti, api_key, exp) или вычислить подпись запроса HMAC-SHA256 из PARTNER_CODE/API_KEY/SECRET_KEY. Требуется для каждого второго вызова API AppotaPay.
