Crea, estendi e risolvi i problemi degli agenti IA basati su eventi in Funzioni di Azure usando il pacchetto azure-functions-agents. Funziona sia per creare nuove app che per modificare quelle esistenti. Aiuta a creare file dell'agente (.agent.md), configurare trigger (timer, HTTP, coda, BLOB, hub eventi, bus di servizio, Cosmos DB, connettori e così via), configurare connettori (Office 365, Teams e così via), configurare sessioni dinamiche ACA per l'esecuzione del codice, aggiungere server MCP e strumenti personalizzati, eseguire localmente con azzurrite, distribuire in Azure con azd e diagnosticare problemi utilizzando App Insights e log. UTILIZZARE QUESTA COMPETENZA quando l'utente desidera: creare un agente basato su eventi, creare un agente pianificato/attivato, creare un agente in Funzioni di Azure, utilizzare agenti di funzioni di Azure, creare un agente timer/coda/blob, connettere un agente a Office 365 o Teams, distribuire un agente in Azure, configurare connettori per un agente, aggiungere l'esecuzione di codice a un agente, eseguire lo scaffold di una nuova app agente, correggere un agente danneggiato, eseguire il debug della distribuzione dell'agente o risolvere i problemi del connettore/sessione.
