azure-functions-agents 패키지를 사용하여 Azure Functions에서 이벤트 기반 AI 에이전트를 빌드, 확장 및 문제 해결합니다. 새로운 앱을 스캐폴딩하고 기존 앱을 수정하는 데 모두 작동합니다. 에이전트 파일(.agent.md) 생성, 트리거 구성(타이머, HTTP, 큐, Blob, Event Hub, Service Bus, Cosmos DB, 커넥터 등), 커넥터(Office 365, Teams 등) 설정, 코드 실행을 위한 ACA 동적 세션 구성, MCP 서버 및 사용자 지정 도구 추가, Azurite를 사용하여 로컬로 실행, azd를 사용하여 Azure에 배포, App Insights 및 로그를 사용하여 문제 진단을 돕습니다. 사용자가 원할 때 이 기술을 사용하십시오. 이벤트 기반 에이전트 구축, 예약/트리거된 에이전트 생성, Azure Functions에서 에이전트 구축, azure-functions-agents 사용, 타이머/큐/BLOB 에이전트 생성, 에이전트를 Office 365 또는 Teams에 연결, Azure에 에이전트 배포, 에이전트에 대한 커넥터 설정, 에이전트에 코드 실행 추가, 새 에이전트 앱 스캐폴드, 손상된 에이전트 수정, 에이전트 배포 디버그 또는 커넥터/세션 문제 해결 문제.
