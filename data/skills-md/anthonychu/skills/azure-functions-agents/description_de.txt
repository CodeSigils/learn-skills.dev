Erstellen, erweitern und beheben Sie ereignisgesteuerte KI-Agenten in Azure Functions mit dem Paket azure-functions-agents. Funktioniert sowohl für die Erstellung neuer Apps als auch für die Änderung vorhandener Apps. Hilft beim Erstellen von Agent-Dateien (.agent.md), beim Konfigurieren von Triggern (Timer, HTTP, Warteschlange, Blob, Event Hub, Service Bus, Cosmos DB, Konnektoren usw.), beim Einrichten von Konnektoren (Office 365, Teams usw.), beim Konfigurieren dynamischer ACA-Sitzungen für die Codeausführung, beim Hinzufügen von MCP-Servern und benutzerdefinierten Tools, beim lokalen Ausführen mit Azurite, beim Bereitstellen in Azure mit azd und beim Diagnostizieren von Problemen mithilfe von App Insights und Protokollen. NUTZEN SIE DIESE FÄHIGKEIT, wenn der Benutzer einen ereignisgesteuerten Agenten erstellen, einen geplanten/ausgelösten Agenten erstellen, einen Agenten auf Azure Functions erstellen, azure-functions-agents verwenden, einen Timer-/Warteschlangen-/Blob-Agenten erstellen, einen Agenten mit Office 365 oder Teams verbinden, einen Agenten in Azure bereitstellen, Connectors für einen Agenten einrichten, Codeausführung zu einem Agenten hinzufügen, ein Gerüst für eine neue Agenten-App erstellen, einen defekten Agenten reparieren, die Agentenbereitstellung debuggen oder Connectors/Sitzungen beheben möchte Probleme.
