Créez, étendez et dépannez des agents IA pilotés par événements sur Azure Functions à l’aide du package azure-functions-agents. Fonctionne à la fois pour créer de nouvelles applications et pour modifier celles existantes. Aide à créer des fichiers d'agent (.agent.md), à configurer des déclencheurs (minuterie, HTTP, file d'attente, blob, Event Hub, Service Bus, Cosmos DB, connecteurs, etc.), à configurer des connecteurs (Office 365, Teams, etc.), à configurer les sessions dynamiques ACA pour l'exécution de code, à ajouter des serveurs MCP et des outils personnalisés, à exécuter localement avec Azurite, à déployer sur Azure avec azd et à diagnostiquer les problèmes à l'aide d'App Insights et des journaux. UTILISEZ CETTE COMPÉTENCE lorsque l'utilisateur souhaite : créer un agent basé sur des événements, créer un agent planifié/déclenché, créer un agent sur Azure Functions, utiliser des agents Azure-Functions, créer un agent de minuterie/file d'attente/blob, connecter un agent à Office 365 ou Teams, déployer un agent sur Azure, configurer des connecteurs pour un agent, ajouter l'exécution de code à un agent, échafauder une nouvelle application d'agent, réparer un agent défectueux, déboguer le déploiement d'un agent ou dépanner un connecteur/une session. problèmes.
