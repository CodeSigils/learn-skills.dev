Cree, amplíe y solucione problemas de agentes de IA controlados por eventos en Azure Functions mediante el paquete azure-functions-agents. Funciona tanto para crear nuevas aplicaciones como para modificar las existentes. Ayuda a crear archivos de agente (.agent.md), configurar activadores (temporizador, HTTP, cola, blob, centro de eventos, Service Bus, Cosmos DB, conectores, etc.), configurar conectores (Office 365, Teams, etc.), configurar sesiones dinámicas de ACA para la ejecución de código, agregar servidores MCP y herramientas personalizadas, ejecutar localmente con Azurite, implementar en Azure con azd y diagnosticar problemas mediante App Insights y registros. USE ESTA HABILIDAD cuando el usuario desee: crear un agente controlado por eventos, crear un agente programado/activado, crear un agente en Azure Functions, usar agentes de funciones de Azure, crear un temporizador/cola/agente de blob, conectar un agente a Office 365 o Teams, implementar un agente en Azure, configurar conectores para un agente, agregar ejecución de código a un agente, desarrollar una nueva aplicación de agente, reparar un agente roto, depurar la implementación de un agente o solucionar problemas Problemas de conector/sesión.
