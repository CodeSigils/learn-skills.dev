Создавайте, расширяйте и устраняйте неполадки агентов искусственного интеллекта, управляемых событиями, в функциях Azure с помощью пакета azure-functions-agents. Работает как для создания новых приложений, так и для изменения существующих. Помогает создавать файлы агента (.agent.md), настраивать триггеры (таймер, HTTP, очередь, большие двоичные объекты, концентратор событий, служебную шину, Cosmos DB, соединители и т. д.), настраивать соединители (Office 365, Teams и т. д.), настраивать динамические сеансы ACA для выполнения кода, добавлять серверы MCP и специальные инструменты, запускать локально с помощью Azurite, развертывать в Azure с помощью azd и диагностировать проблемы с помощью App Insights и журналов. ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК, когда пользователь хочет: создать агент, управляемый событиями, создать запланированный/запускаемый агент, создать агент в функциях Azure, использовать azure-functions-agents, создать агент таймера/очереди/BLOB-объекта, подключить агент к Office 365 или Teams, развернуть агент в Azure, настроить соединители для агента, добавить выполнение кода в агент, подготовить новое приложение агента, исправить неисправный агент, отладить развертывание агента или устранить неполадки проблемы с разъемом/сессией.
