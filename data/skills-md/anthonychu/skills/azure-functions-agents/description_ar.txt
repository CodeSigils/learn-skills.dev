يمكنك إنشاء وكلاء الذكاء الاصطناعي المستندين إلى الأحداث وتوسيع نطاقهم واستكشاف أخطائهم وإصلاحها على وظائف Azure باستخدام حزمة azure-functions-agents. يعمل لكل من دعم التطبيقات الجديدة وتعديل التطبيقات الحالية. يساعد في إنشاء ملفات الوكيل (.agent.md)، وتكوين المشغلات (المؤقت، وHTTP، وقائمة الانتظار، وblob، وEvent Hub، وService Bus، وCosmos DB، والموصلات، وما إلى ذلك)، وإعداد الموصلات (Office 365، وTeams، وما إلى ذلك)، وتكوين جلسات ACA الديناميكية لتنفيذ التعليمات البرمجية، وإضافة خوادم MCP وأدوات مخصصة، والتشغيل محليًا باستخدام Azurite، والنشر إلى Azure باستخدام azd، وتشخيص المشكلات باستخدام App Insights والسجلات. استخدم هذه المهارة عندما يريد المستخدم: إنشاء وكيل يستند إلى حدث، أو إنشاء وكيل مجدول/مُشغل، أو إنشاء وكيل على وظائف Azure، أو استخدام وكلاء وظائف azure، أو إنشاء وكيل مؤقت/قائمة انتظار/وكيل ثنائي كبير الحجم، أو توصيل وكيل بـ Office 365 أو Teams، أو نشر وكيل إلى Azure، أو إعداد موصلات لوكيل، أو إضافة تنفيذ تعليمات برمجية إلى وكيل، أو دعم تطبيق وكيل جديد، أو إصلاح وكيل معطل، أو وكيل تصحيح الأخطاء النشر، أو استكشاف مشكلات الموصل/الجلسة وإصلاحها.
