A complete guide to developing WeChat Mini Programs using the VMS (Vue Mini SFC) tool. Covers core usage such as Vue 3 Composition API, TypeScript, event binding, v‑for, v‑show, reactive data, component communication, slots, as well as common issues and best practices. Use when developing WeChat Mini Program with VMS, writing Vue SFC with @unmagic/vue-mini, or debugging template compilation issues.
