BuilderBot 的專家助理 (v1.4.0) — 用於建立多平台聊天機器人（WhatsApp、Telegram、Instagram、電子郵件等）的 TypeScript/JavaScript 框架。在建立或編輯流程（addKeyword、addAnswer、addAction）、連接事件、管理每個使用者狀態或全域狀態、設定提供者（Baileys、Meta、Telegram、Evolution 等）或資料庫（Mongo、Postgres、MySQL、JSON）、實作 REST API端點（handleCtx、httpServer）、調試流控制（gotoFlow、endFlow、fallBack、idle、capture、flowDynamic）或處理黑名單邏輯時使用。架構：提供者+資料庫+流程。
