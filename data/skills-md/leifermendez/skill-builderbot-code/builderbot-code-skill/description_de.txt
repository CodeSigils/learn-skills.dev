Expertenassistent für BuilderBot (v1.4.0) – ein TypeScript/JavaScript-Framework zum Erstellen von Chatbots für mehrere Plattformen (WhatsApp, Telegram, Instagram, E-Mail usw.). Verwendung beim Erstellen oder Bearbeiten von Flows (addKeyword, addAnswer, addAction), beim Verknüpfen von EREIGNISSEN, beim Verwalten des Status pro Benutzer oder globalState, beim Konfigurieren von Anbietern (Baileys, Meta, Telegram, Evolution usw.) oder Datenbanken (Mongo, Postgres, MySQL, JSON), beim Implementieren von REST-API-Endpunkten (handleCtx, httpServer), beim Debuggen der Flusssteuerung (gotoFlow, endFlow, fallBack, empty, capture, flowDynamic) oder bei der Handhabung Blacklist-Logik. Architektur: Anbieter + Datenbank + Fluss.
