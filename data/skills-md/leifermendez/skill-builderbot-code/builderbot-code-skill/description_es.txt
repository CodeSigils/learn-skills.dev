Asistente experto para BuilderBot (v1.4.0): un marco TypeScript/JavaScript para crear chatbots multiplataforma (WhatsApp, Telegram, Instagram, correo electrónico, etc.). Úselo al crear o editar flujos (addKeyword, addAnswer, addAction), cablear EVENTOS, administrar el estado por usuario o globalState, configurar proveedores (Baileys, Meta, Telegram, Evolution, etc.) o bases de datos (Mongo, Postgres, MySQL, JSON), implementar puntos finales de API REST (handleCtx, httpServer), depurar el control de flujo (gotoFlow, endFlow, fallBack, idle, capture, flowDynamic), o manejar la lógica de la lista negra. Arquitectura: Proveedor + Base de Datos + Flujo.
