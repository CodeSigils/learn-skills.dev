BuilderBot용 전문 보조자(v1.4.0) — 다중 플랫폼 챗봇(WhatsApp, Telegram, Instagram, Email 등) 구축을 위한 TypeScript/JavaScript 프레임워크입니다. 흐름 생성 또는 편집(addKeyword, addAnswer, addAction), 이벤트 연결, 사용자별 상태 또는 globalState 관리, 공급자(Baileys, Meta, Telegram, Evolution 등) 또는 데이터베이스(Mongo, Postgres, MySQL, JSON) 구성, REST API 엔드포인트 구현(handleCtx, httpServer), 흐름 제어 디버깅(gotoFlow, endFlow, fallBack, 유휴, 캡처, flowDynamic) 또는 블랙리스트 처리 시 사용합니다. 논리. 아키텍처: 공급자 + 데이터베이스 + 흐름.
