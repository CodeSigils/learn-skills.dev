BuilderBot 的专家助手 (v1.4.0) — 用于构建多平台聊天机器人（WhatsApp、Telegram、Instagram、电子邮件等）的 TypeScript/JavaScript 框架。在创建或编辑流（addKeyword、addAnswer、addAction）、连接事件、管理每个用户状态或全局状态、配置提供程序（Baileys、Meta、Telegram、Evolution 等）或数据库（Mongo、Postgres、MySQL、JSON）、实现 REST API 端点（handleCtx、httpServer）、调试流控制（gotoFlow、endFlow、fallBack、idle、capture、flowDynamic）或处理黑名单逻辑时使用。架构：提供者+数据库+流程。
