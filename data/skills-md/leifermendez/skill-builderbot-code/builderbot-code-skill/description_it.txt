Assistente esperto per BuilderBot (v1.4.0): un framework TypeScript/JavaScript per la creazione di chatbot multipiattaforma (WhatsApp, Telegram, Instagram, e-mail, ecc.). Utilizzare durante la creazione o la modifica di flussi (addKeyword, addAnswer, addAction), il cablaggio di EVENTI, la gestione dello stato per utente o globalState, la configurazione di provider (Baileys, Meta, Telegram, Evolution, ecc.) o database (Mongo, Postgres, MySQL, JSON), l'implementazione di endpoint API REST (handleCtx, httpServer), il debug del controllo del flusso (gotoFlow, endFlow, fallBack, idle, capture, flowDynamic), o gestire la logica della lista nera. Architettura: provider + database + flusso.
