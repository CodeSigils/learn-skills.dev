Экспертный помощник для BuilderBot (v1.4.0) — фреймворк TypeScript/JavaScript для создания многоплатформенных чат-ботов (WhatsApp, Telegram, Instagram, электронная почта и т. д.). Используйте при создании или редактировании потоков (addKeyword, addAnswer, addAction), подключении EVENTS, управлении состоянием каждого пользователя или globalState, настройке поставщиков (Baileys, Meta, Telegram, Evolution и т. д.) или баз данных (Mongo, Postgres, MySQL, JSON), реализации конечных точек REST API (handleCtx, httpServer), отладке управления потоками (gotoFlow, endFlow, FallBack, IDLE, Capture, flowDynamic) или обработку логики черного списка. Архитектура: Поставщик + База данных + Поток.
