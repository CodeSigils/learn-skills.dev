BuilderBot (v1.4.0) のエキスパート アシスタント — マルチプラットフォーム チャットボット (WhatsApp、Telegram、Instagram、電子メールなど) を構築するための TypeScript/JavaScript フレームワーク。フロー (addKeyword、addAnswer、addAction) の作成または編集、イベントの接続、ユーザーごとの状態または globalState の管理、プロバイダー (Baileys、Meta、Telegram、Evolution など) またはデータベース (Mongo、Postgres、MySQL、JSON) の構成、REST API エンドポイント (handleCtx、httpServer) の実装、フロー制御 (gotoFlow、endFlow、fallBack、idle、キャプチャ、flowDynamic)、またはブラックリスト ロジックの処理。アーキテクチャ: プロバイダー + データベース + フロー。
