Assistant expert pour BuilderBot (v1.4.0) — un framework TypeScript/JavaScript pour créer des chatbots multiplateformes (WhatsApp, Telegram, Instagram, Email, etc.). À utiliser lors de la création ou de la modification de flux (addKeyword, addAnswer, addAction), du câblage d'ÉVÉNEMENTS, de la gestion de l'état par utilisateur ou de globalState, de la configuration de fournisseurs (Baileys, Meta, Telegram, Evolution, etc.) ou de bases de données (Mongo, Postgres, MySQL, JSON), de l'implémentation de points de terminaison d'API REST (handleCtx, httpServer), du débogage du contrôle de flux (gotoFlow, endFlow, fallBack, ralenti, capture, flowDynamic), ou gérer la logique de la liste noire. Architecture : Fournisseur + Base de données + Flux.
