مساعد خبير لـ BuilderBot (الإصدار 1.4.0) — إطار عمل TypeScript/JavaScript لإنشاء روبوتات دردشة متعددة المنصات (WhatsApp وTelegram وInstagram وEmail وما إلى ذلك). يُستخدم عند إنشاء التدفقات أو تحريرها (addKeyword، addAnswer، addAction)، أو توصيل الأحداث، أو إدارة حالة كل مستخدم أو globalState، أو تكوين مقدمي الخدمة (Baileys، Meta، Telegram، Evolution، إلخ) أو قواعد البيانات (Mongo، Postgres، MySQL، JSON)، تنفيذ نقاط نهاية REST API (handleCtx، httpServer)، تصحيح أخطاء التحكم في التدفق (gotoFlow، endFlow، FallBack، idle، الالتقاط أو التدفق الديناميكي) أو التعامل مع منطق القائمة السوداء. البنية: الموفر + قاعدة البيانات + التدفق.
