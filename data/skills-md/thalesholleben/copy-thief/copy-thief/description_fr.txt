Utilisez lorsque le processus consiste : écrire ou réviser une page de vente, une page de destination, une lettre de vente, une carte de vente, une copie de l'offre, un VSL, un publi-reportage, une pré-vente, un titre, un CTA ou "vendeur sans trafic froid". Le flux de travail est toujours diagnostique → structure approuvée par l'utilisateur → copie. Idioma de dit padrão: PT-BR (marché brésilien).
