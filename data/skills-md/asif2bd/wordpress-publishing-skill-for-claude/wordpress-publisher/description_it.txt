Pubblica contenuti direttamente sui siti WordPress tramite API REST con supporto completo del blocco Gutenberg. Crea e pubblica post/pagine, carica automaticamente e seleziona categorie dal sito Web, genera tag ottimizzati per SEO, visualizza in anteprima gli articoli prima della pubblicazione e genera blocchi Gutenberg per tabelle, immagini, elenchi e formattazione avanzata. Da utilizzare quando l'utente desidera pubblicare su WordPress, pubblicare su blog, creare articoli WordPress, aggiornare post WordPress o convertire markdown in blocchi Gutenberg.
