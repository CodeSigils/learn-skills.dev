Публикуйте контент непосредственно на сайтах WordPress через REST API с полной поддержкой блоков Gutenberg. Создавайте и публикуйте сообщения/страницы, автоматически загружайте и выбирайте категории на веб-сайте, создавайте оптимизированные для SEO теги, просматривайте статьи перед публикацией и генерируйте блоки Гутенберга для таблиц, изображений, списков и расширенного форматирования. Используйте, когда пользователь хочет опубликовать в WordPress, опубликовать в блоге, создать статью WordPress, обновить публикацию WordPress или преобразовать уценку в блоки Гутенберга.
