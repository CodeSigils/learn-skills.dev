انشر المحتوى مباشرةً على مواقع WordPress عبر REST API مع الدعم الكامل لكتلة Gutenberg. قم بإنشاء المنشورات/الصفحات ونشرها، والتحميل التلقائي للفئات وتحديدها من موقع الويب، وإنشاء علامات محسنة لتحسين محركات البحث، ومعاينة المقالات قبل النشر، وإنشاء كتل Gutenberg للجداول والصور والقوائم والتنسيق الغني. يُستخدم عندما يريد المستخدم النشر على WordPress، أو النشر على مدونة، أو إنشاء مقالة WordPress، أو تحديث منشور WordPress، أو تحويل تخفيض السعر إلى كتل Gutenberg.
