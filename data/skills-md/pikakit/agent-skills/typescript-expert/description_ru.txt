Программирование на уровне типов TypeScript, настройка производительности, управление монорепозиториями и инструменты. Используйте для комплексной гимнастики типов, повышения производительности сборки, миграции TypeScript или отладки TS. НЕ для шаблонов, специфичных для React (используйте response-pro) или архитектуры Node.js (используйте nodejs-pro).
