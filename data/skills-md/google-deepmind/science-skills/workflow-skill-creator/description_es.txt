Destila un flujo de trabajo o interacción de usuario completo en una habilidad de agente reutilizable. Úselo cuando el usuario solicite convertir su flujo de trabajo, interacción o proceso de varios pasos en una habilidad, o cuando diga "convierta esto en una habilidad", "cree una habilidad a partir de lo que acabamos de hacer", "empaquetar este flujo de trabajo" o similar. No lo use para crear habilidades desde cero sin un flujo de trabajo existente (use un creador de habilidades genérico para eso).
