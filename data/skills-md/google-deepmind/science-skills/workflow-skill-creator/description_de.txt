Destilliert einen abgeschlossenen Benutzerworkflow oder eine abgeschlossene Benutzerinteraktion in einen wiederverwendbaren Agentenskill. Verwenden Sie diese Option, wenn der Benutzer darum bittet, seinen Workflow, seine Interaktion oder seinen mehrstufigen Prozess in einen Skill umzuwandeln, oder wenn er sagt: „Machen Sie dies zu einem Skill“, „erstellen Sie einen Skill aus dem, was wir gerade getan haben“, „packen Sie diesen Workflow“ oder ähnliches. Nicht zum Erstellen von Fertigkeiten von Grund auf ohne vorhandenen Workflow verwenden (verwenden Sie dazu einen generischen Fertigkeitsersteller).
