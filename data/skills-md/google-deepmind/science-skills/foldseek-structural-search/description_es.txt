Realiza búsquedas estructurales 3D de proteínas en varias bases de datos (PDB, AlphaFold, CATH, MGnify, etc.) utilizando la API Foldseek. Úselo SÓLO cuando el usuario proporcione un archivo de coordenadas físicas 3D (.cif, .mmcif o .pdb) y desee encontrar proteínas estructuralmente similares. NO lo use si el usuario solo proporciona una secuencia de proteínas, un nombre de gen o una identificación de UniProt.
