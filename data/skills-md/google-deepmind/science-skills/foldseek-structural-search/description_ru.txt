Выполняет трехмерный структурный поиск белков в различных базах данных (PDB, AlphaFold, CATH, MGnify и т. д.) с использованием API Foldseek. Используйте ТОЛЬКО в том случае, если пользователь предоставляет физический файл трехмерных координат (.cif, .mmcif или .pdb) и хочет найти структурно схожие белки. НЕ используйте, если пользователь предоставляет только последовательность белка, имя гена или идентификатор UniProt.
