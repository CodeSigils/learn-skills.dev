Esegue ricerche strutturali 3D di proteine ​​su vari database (PDB, AlphaFold, CATH, MGnify, ecc.) utilizzando l'API Foldseek. Utilizzare SOLO quando l'utente fornisce un file di coordinate 3D fisiche (.cif, .mmcif o .pdb) e desidera trovare proteine ​​strutturalmente simili. NON utilizzare se l'utente fornisce solo una sequenza proteica, un nome di gene o un ID UniProt.
