Interrogez ClinicalTrials.gov via APIv2. À utiliser lorsque vous souhaitez rechercher des essais par condition, médicament, lieu, statut ou phase ; récupérer les détails de l'essai par ID NCT ; vérifier les critères d’éligibilité/d’inclusion ; compter les essais selon les conditions ou les périodes ; identifier le portefeuille d'essais d'un sponsor ; trouver des essais de recrutement pour l'appariement des patients.
