Consulte la API REST de QuickGO y Evidence & Conclusion Ontology (ECO). Utilícelo cuando necesite asignar genes a procesos biológicos, funciones moleculares o componentes celulares, encontrar genes asociados con una vía/término GO específico o explorar la jerarquía de ontología genética. No lo use para consultar objetivos de fármacos (use OpenTargets) o diagramas de vías de señalización mecanicistas (use KEGG).
