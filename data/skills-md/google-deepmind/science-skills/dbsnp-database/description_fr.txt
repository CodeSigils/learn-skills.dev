À utiliser lorsque vous souhaitez rechercher, cartographier et rechercher des variantes génétiques courtes (SNP, indels) dans la base de données dbSNP du NCBI. Résout entre les rsID, les coordonnées génomiques au format VCF et les chaînes HGVS. Pour un rsID, renvoie le type de variante, les associations de gènes, la signification clinique, les fréquences alléliques et les coordonnées génomiques (GRCh38).
