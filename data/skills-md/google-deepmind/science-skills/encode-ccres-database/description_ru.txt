Запросите реестр цис-регуляторных элементов ENCODE (cCRE) через API SCREEN GraphQL или сделайте собственные запросы к API REST портала ENCODE для получения экспериментов и файлов (пики ChIP-seq и т. д.). Используйте, если вы хотите запросить нормативные аннотации или необработанные экспериментальные данные по типам клеток человека.
