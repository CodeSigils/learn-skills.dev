استعلم عن سجل ENCODE للعناصر التنظيمية لرابطة الدول المستقلة (cCREs) عبر SCREEN GraphQL API، أو قم بإجراء استعلامات مخصصة إلى ENCODE Portal REST API للتجارب والملفات (قمم ChIP-seq، وما إلى ذلك). استخدمه عندما تريد الاستعلام عن التعليقات التوضيحية التنظيمية أو البيانات التجريبية الأولية عبر أنواع الخلايا البشرية.
