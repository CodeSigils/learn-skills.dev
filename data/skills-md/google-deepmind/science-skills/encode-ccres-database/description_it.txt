Interroga il registro ENCODE degli elementi cis-regolamentari (cCRE) tramite l'API SCREEN GraphQL o esegui query personalizzate sull'API REST del portale ENCODE per esperimenti e file (picchi ChIP-seq, ecc.). Da utilizzare quando si desidera eseguire query su annotazioni normative o dati sperimentali grezzi su tipi di cellule umane.
