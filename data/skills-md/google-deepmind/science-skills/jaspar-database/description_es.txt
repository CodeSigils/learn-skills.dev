Consulte la base de datos JASPAR para conocer los perfiles de enlace del factor de transcripción (TF). Úselo cuando recupere matrices de frecuencia de posición (PFM) o matrices de peso de posición (PWM) para TF específicos, resuelva símbolos genéticos en ID de matriz JASPAR u obtenga metadatos de TF. Admite múltiples formatos de salida (MEME, TRANSFAC, PFM, JASPAR, YAML).
