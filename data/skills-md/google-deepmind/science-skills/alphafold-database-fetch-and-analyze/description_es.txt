Recupere y analice las estructuras predichas por AlphaFold para una proteína. Utilícelo cuando el usuario proporciona un ID de acceso de UniProt específico y desea métricas de confianza estructural (pLDDT), análisis de límites de dominio o evaluación de trastornos. No lo use si el usuario solo tiene el nombre de una proteína, un nombre de gen o una secuencia de aminoácidos; primero solicite una identificación de UniProt.
