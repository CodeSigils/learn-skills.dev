Consulte la base de datos de Ensembl para resolver identificaciones de genes, transcripciones y proteínas, recuperar secuencias genómicas o de proteínas, recuperar estructuras genéticas (exones) y obtener predicciones de consecuencias y efectos (VEP) variantes. Utilice esta habilidad como traductor de identificación principal, base de datos de secuencias genómicas y herramienta de predicción de efectos variantes.
