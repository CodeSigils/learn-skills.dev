Interroga il database UniBind per i siti di legame del fattore di trascrizione (TF) validati sperimentalmente. Da utilizzare quando si recuperano set di dati di interazione diretta TF-DNA, si scaricano le coordinate del sito di legame (BED/FASTA) per l'analisi locale o si elencano set di dati disponibili per specie, linea cellulare o nome TF. Non utilizzare per interrogare intervalli, posizioni, geni, modelli di motivi o dati di espressione specifici.
