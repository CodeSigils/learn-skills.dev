Consulta la base de datos UniBind en busca de sitios de unión del factor de transcripción (TF) validados experimentalmente. Úselo al recuperar conjuntos de datos de interacción directa TF-ADN, descargar coordenadas del sitio de unión (BED/FASTA) para análisis local o enumerar conjuntos de datos disponibles por especie, línea celular o nombre de TF. No lo utilice para consultar intervalos, ubicaciones, genes, modelos de motivos o datos de expresión específicos.
