Запрашивайте, ищите и загружайте данные из API openFDA о лекарствах, устройствах, продуктах питания, табачных изделиях, косметике, продуктах животного и ветеринарного происхождения, веществах, а также данные о прозрачности. Используйте для выявления нежелательных явлений FDA, отзывов, маркировки, одобрений, нехватки, разрешений 510(k), поиска NDC и любых запросов FDA по безопасности или нормативным данным по всем 28 конечным точкам API.
