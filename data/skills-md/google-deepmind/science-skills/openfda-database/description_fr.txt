Interrogez, recherchez et téléchargez des données à partir de l'API openFDA pour les médicaments, les appareils, les aliments, le tabac, les cosmétiques, les produits animaux et vétérinaires, les substances et les données de transparence. À utiliser pour les événements indésirables de la FDA, les rappels, l'étiquetage, les approbations, les pénuries, les autorisations 510(k), les recherches NDC et toute requête de données de sécurité ou réglementaires de la FDA sur les 28 points finaux de l'API.
