Запросите базу данных STRING на предмет белок-белковых взаимодействий (PPI), функционального обогащения и гомологии. Используйте, когда пользователь спрашивает о взаимодействиях между конкретными белками, доказательствах взаимодействия, показателях достоверности, партнерах по взаимодействию белков или обогащении путей.
