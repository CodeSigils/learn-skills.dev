Skill ufficiale di Quark Drive, utilizzata per il caricamento/download di file (supporta la ripresa del punto di interruzione), condivisione e trasferimento di file, ricerca di file nell'archivio cloud, organizzazione di album, assistente AI (riepilogo dei file e domande e risposte sulla conoscenza, supporta decine di migliaia di file). Utilizzato quando l'utente deve utilizzare i file Quark Drive o eseguire l'autenticazione.
