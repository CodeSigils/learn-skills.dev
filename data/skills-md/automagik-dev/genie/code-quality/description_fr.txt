À utiliser lors de l'audit de la qualité du code dans n'importe quelle base de code : découvrez et exécutez les véritables portes du dépôt (vérification de type, charpie, code mort, complexité), jugez la discipline de type et la duplication. Évaluer par défaut, appliquer les modifications sur demande ; le compilateur est le premier réviseur.
