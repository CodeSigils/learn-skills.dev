À utiliser lors de l'audit de la qualité des tests dans n'importe quelle base de code : exécutez la suite réelle, cartographiez la topologie de couverture, classez les comportements non testés par risque. Évaluer par défaut, rédiger des tests sur demande ; les tests sont une spécification, et la question est de savoir quel changement aucun test ne détecterait.
