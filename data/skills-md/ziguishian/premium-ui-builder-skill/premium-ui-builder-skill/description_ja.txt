「ページが十分に洗練されていない、平凡すぎる、テンプレートのように見える、製品の雰囲気に欠けている」などの漠然とした美的要求を、実用的な UI デザイン システム、フロントエンド実装計画、AI コーディング プロンプトに変換します。これは 2 つのコア シナリオに適用されます。(1) 情報アーキテクチャ、ビジュアル システム、コンポーネント システム、モーション戦略、テクノロジ スタックの選択、および再現可能なスターター プロンプトをカバーする、新しいプロジェクトのページ プランニングをゼロから 1 まで行います。 (2) プレミアム感をアップグレードし、問題診断、モジュールレベルの再設計、コンポーネントの状態の完成、実装手順、および承認基準を含む既存のページを製品化します。これは、ユーザーが新しい公式 Web サイト、ランディング ページ、ダッシュボード、管理パネル、AI 製品ページ、個人サイト、ツール ページ、デスクトップ バージョン、モバイル バージョンをリクエストしたり、現在のページのテクスチャ、製品の感触、デザインの感性を改善するよう要求したときにトリガーされます。
