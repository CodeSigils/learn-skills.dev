قم بتحويل المتطلبات الجمالية الغامضة مثل "الصفحة ليست متطورة بدرجة كافية، أو عادية جدًا، أو تبدو كقالب، أو تفتقر إلى إحساس المنتج" إلى أنظمة تصميم واجهة مستخدم قابلة للتنفيذ، وخطط تنفيذ الواجهة الأمامية، ومطالبات ترميز الذكاء الاصطناعي. ينطبق هذا على سيناريوهين أساسيين: (1) تخطيط الصفحة لمشروع جديد تمامًا من 0 إلى 1، يغطي بنية المعلومات، والنظام المرئي، ونظام المكونات، واستراتيجية الحركة، واختيار مكدس التكنولوجيا، وموجه الإطلاق القابل للتكرار؛ (2) رفع مستوى تعقيد وإنتاج الصفحات الحالية، بما في ذلك تشخيص المشكلات، وإعادة التصميم على مستوى الوحدة، واستكمال حالات المكونات، وتوجيهات التنفيذ، ومعايير القبول. يتم تشغيله عندما يطلب المستخدم موقعًا رسميًا جديدًا، أو صفحة مقصودة، أو لوحة تحكم، أو لوحة إدارة، أو صفحة منتج AI، أو موقعًا شخصيًا، أو صفحة أداة، أو إصدار سطح مكتب، أو إصدارًا للجوال، أو يطلب تحسين نسيج الصفحة الحالية، أو مظهر المنتج، أو جمالية التصميم.
