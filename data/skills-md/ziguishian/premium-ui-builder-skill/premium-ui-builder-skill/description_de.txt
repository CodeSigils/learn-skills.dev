Verwandeln Sie vage ästhetische Anforderungen wie „Die Seite ist nicht anspruchsvoll genug, zu gewöhnlich, sieht aus wie eine Vorlage, es fehlt das Produktgefühl“ in umsetzbare UI-Designsysteme, Front-End-Implementierungspläne und KI-Codierungsaufforderungen. Es gilt für zwei Kernszenarien: (1) Seitenplanung für ein neues Projekt von Null auf Eins, die Informationsarchitektur, visuelles System, Komponentensystem, Bewegungsstrategie, Technologie-Stack-Auswahl und reproduzierbare Starter-Eingabeaufforderungen abdeckt; (2) Verbesserung des Premium-Feelings und Produktivierung bestehender Seiten, einschließlich Problemdiagnose, Neugestaltung auf Modulebene, Vervollständigung von Komponentenzuständen, Implementierungsanweisungen und Akzeptanzkriterien. Es wird ausgelöst, wenn ein Benutzer eine neue offizielle Website, Landingpage, ein Dashboard, ein Admin-Panel, eine KI-Produktseite, eine persönliche Website, eine Tool-Seite, eine Desktop-Version oder eine mobile Version anfordert oder darum bittet, die Textur, das Produktgefühl oder die Design-Sensibilität der aktuellen Seite zu verbessern.
