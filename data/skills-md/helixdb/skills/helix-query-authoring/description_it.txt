Scrivi e rivedi da zero le query memorizzate su HelixDB Rust DSL. Da utilizzare quando l'attività consiste nell'aggiungere, aggiornare o rivedere una query Helix creata con read_batch, write_batch, generatori traversali, proiezioni, indici, ricerca di testo BM25 o ricerca vettoriale. Ispeziona etichette locali, bordi, proprietà e modelli di query esistenti prima di inventare nuovo codice. Vedi REFERENCE.md per il catalogo completo del builder ed EXAMPLES.md per i modelli end-to-end.
