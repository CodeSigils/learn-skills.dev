Diseñe y opere un sistema avanzado de memoria de agentes de IA en HelixDB utilizando gráfico híbrido + vector + búsqueda BM25. Úselo al crear memoria a largo plazo, perfiles de usuario, RAG de documentos/fragmentos, funciones de recuperación/recordación, extracción de memoria, deduplicación, consolidación, control de versiones, actualización, olvido/eliminación, categorización o ingesta respaldada por conector. Cubre el modelado de datos Helix seguro para los inquilinos, las reglas de decisión de modalidad, el ciclo de vida completo de escritura/mantenimiento y las capas de producto que un agente debe implementar en torno a Helix. TypeScript-primero (@helix-db/helix-db); hay una variante de Rust DSL en EXAMPLES.rust.md.
