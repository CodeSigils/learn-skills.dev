Entwerfen und betreiben Sie ein fortschrittliches KI-Agentenspeichersystem auf HelixDB mit Hybrid-Graph + Vektor + BM25-Suche. Verwendung beim Aufbau von Langzeitspeicher, Benutzerprofilen, Dokument-/Chunk-RAG, Rückruf-/Erinnerungsfunktionen, Speicherextraktion, Deduplizierung, Konsolidierung, Versionierung, Aktualisierung, Vergessen/Löschen, Kategorisierung oder konnektorgestützte Aufnahme. Deckt die mandantensichere Helix-Datenmodellierung, Modalitätsentscheidungsregeln, den gesamten Schreib-/Wartungslebenszyklus und die Produktschichten ab, die ein Agent rund um Helix implementieren muss. TypeScript-first (@helix-db/helix-db); Eine Rust-DSL-Variante befindet sich in EXAMPLES.rust.md.
