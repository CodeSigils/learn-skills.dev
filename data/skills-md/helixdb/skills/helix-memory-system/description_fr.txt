Concevoir et exploiter un système avancé de mémoire d'agent IA sur HelixDB en utilisant la recherche hybride graphe + vecteur + BM25. À utiliser lors de la création de mémoire à long terme, de profils utilisateur, de RAG de documents/morceaux, de fonctionnalités de rappel/mémorisation, d'extraction de mémoire, de déduplication, de consolidation, de gestion de versions, de mise à jour, d'oubli/suppression, de catégorisation ou d'ingestion basée sur un connecteur. Couvre la modélisation des données Helix sécurisée pour les locataires, les règles de décision de modalité, le cycle de vie complet d'écriture/maintenance et les couches de produit qu'un agent doit implémenter autour d'Helix. TypeScript d'abord (@helix-db/helix-db); une variante Rust DSL se trouve dans EXAMPLES.rust.md.
