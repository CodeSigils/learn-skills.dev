Спроектируйте и эксплуатируйте усовершенствованную систему памяти агента искусственного интеллекта на базе HelixDB с использованием гибридного поиска по графу + вектору + BM25. Используйте при создании долговременной памяти, профилей пользователей, RAG документов/частей, функций отзыва/запоминания, извлечения памяти, дедупликации, консолидации, управления версиями, обновления, забывания/удаления, категоризации или приема с помощью соединителя. Охватывает безопасное для арендаторов моделирование данных Helix, правила принятия модальных решений, полный жизненный цикл записи/обслуживания, а также уровни продукта, которые агент должен реализовать вокруг Helix. TypeScript-first (@helix-db/helix-db); вариант Rust DSL находится в EXAMPLES.rust.md.
