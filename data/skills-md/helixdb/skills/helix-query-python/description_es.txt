Escriba y revise consultas de HelixDB con el SDK de Python (helix-db, importado como helixdb). Úselo al crear consultas Helix dinámicas en Python con read_batch, write_batch, g(), constructores transversales, proyecciones, parámetros, paquetes de consultas, búsqueda vectorial/BM25 y el Cliente sin dependencia. API Pythonic Snake_case; emite el mismo JSON AST dinámico POST /v1/query que los SDK de Rust, TypeScript y Go.
