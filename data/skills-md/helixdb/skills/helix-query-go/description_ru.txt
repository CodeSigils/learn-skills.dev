Пишите и редактируйте запросы HelixDB с помощью Go SDK. Используйте при построении динамических запросов Helix в Go с обычными функциями, возвращающими helix.Request, ReadQuery/WriteQuery, встроенные параметры, построители обхода, проекции, индексы, текстовый поиск BM25, векторный поиск и client.Exec. Динамический-первый; не используйте рабочие процессы хранимых запросов или пакетов для Go v1.
