Esamina e migliora le prestazioni delle query HelixDB rispetto al comportamento effettivo dell'interprete: push-down dell'indice, ambito dell'etichetta, ciclo di vita della distanza, pushdown limite/deup, ordinamento dell'indice di intervallo, costo di ripetizione/ramificazione e foot-guns del percorso di scrittura. Da utilizzare quando l'attività consiste nell'ottimizzare una query Helix lenta, decidere perché una query sta eseguendo una scansione completa, correggere un indice mancato, restringere l'ambito di ricerca BM25 o vettoriale o proiezioni ridotte. Vedere REFERENCE.md per il catalogo dei meccanismi con citazioni file:line ed EXAMPLES.md per modelli dinamici Rust DSL + JSON accoppiati.
