ترجمة استعلامات Cypher وNeo4j إلى استعلامات HelixDB Rust DSL. يُستخدم عندما يحتوي الإدخال على Cypher، أو Neo4j، أو MATCH، أو OPTIONAL MATCH، أو WHERE، أو RETURN، أو ORDER BY، أو LIMIT، أو DISTINCT، أو MERGE، أو CASE، أو UNWIND، أو FOREACH، أو DETACH DELETE، أو IS NULL، أو أنماط مسار متغيرة الطول والهدف هو إنتاج استعلام Helix Rust مكافئ.
