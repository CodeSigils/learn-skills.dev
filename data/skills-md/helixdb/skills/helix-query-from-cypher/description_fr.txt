Traduisez les requêtes de style Cypher et Neo4j en requêtes HelixDB Rust DSL. À utiliser lorsque l'entrée contient Cypher, Neo4j, MATCH, OPTIONAL MATCH, WHERE, RETURN, ORDER BY, LIMIT, DISTINCT, MERGE, CASE, UNWIND, FOREACH, DETACH DELETE, IS NULL ou des modèles de chemin de longueur variable et que l'objectif est de produire une requête Helix Rust équivalente.
