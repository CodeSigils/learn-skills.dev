Traduzca consultas de estilo Cypher y Neo4j en consultas HelixDB Rust DSL. Úselo cuando la entrada contenga Cypher, Neo4j, MATCH, OPTIONAL MATCH, WHERE, RETURN, ORDER BY, LIMIT, DISTINCT, MERGE, CASE, UNWIND, FOREACH, DETACH DELETE, IS NULL o patrones de ruta de longitud variable y el objetivo es producir una consulta Helix Rust equivalente.
