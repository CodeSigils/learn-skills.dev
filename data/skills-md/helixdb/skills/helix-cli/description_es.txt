Controle la CLI `helix` de HelixDB para ejecutar, consultar e implementar instancias de Helix. Úselo cuando la tarea sea desarrollar un proyecto (helix init / chef / add), administrar una instancia local de Docker/Podman (inicio de hélice, detener, reiniciar, estado, registros, podar), enviar una consulta dinámica a una instancia en ejecución (consulta de hélice con --file / --json / -e TypeScript DSL / --ts-file, contra POST /v1/query) u operar en Helix Cloud (autenticación de hélice, inserción, sincronización, espacio de trabajo, proyecto, clúster). Cubre helix.toml, el flujo de trabajo local versus nube y el modelo mental v3 (SIN compilación de hélice/verificación de hélice/archivos .hx). Para escribir los propios cuerpos de consulta, consulte las habilidades helix-query-*. Consulte REFERENCE.md para ver el catálogo de comandos completo y EXAMPLES.md para ver tutoriales de un extremo a otro.
