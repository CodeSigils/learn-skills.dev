HelixDB の「helix」 CLI を駆動して、Helix インスタンスを実行、クエリ、およびデプロイします。タスクが、プロジェクトのスキャフォールディング (helix init / Chef / add)、ローカル Docker/Podman インスタンスの管理 (helix start、stop、restart、status、logs、prune)、実行中のインスタンスへの動的クエリの送信 (POST /v1/query に対する --file / --json / -e TypeScript DSL / --ts-file を使用した Helix クエリ)、または Helix Cloud での操作 (helix auth、push、sync、workspace、project、クラスター）。 Helix.toml、ローカル対クラウドのワークフロー、および v3 メンタル モデルをカバーします (Helix コンパイル / Helix Check / .hx ファイルは含まれません)。クエリ本体自体を記述する場合は、helix-query-* スキルに従ってください。完全なコマンド カタログについては REFERENCE.md を、エンドツーエンドのウォークスルーについては EXAMPLES.md を参照してください。
