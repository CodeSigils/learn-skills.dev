Utilizza la CLI HelixDB "helix" per eseguire, eseguire query e distribuire istanze Helix. Da utilizzare quando l'attività consiste nell'impalcare un progetto (helix init/chef/add), gestire un'istanza Docker/Podman locale (avvio, arresto, riavvio dell'elica, stato, log, potatura), inviare una query dinamica a un'istanza in esecuzione (query dell'elica con --file / --json / -e TypeScript DSL / --ts-file, rispetto a POST /v1/query) o operare su Helix Cloud (autenticazione dell'elica, push, sincronizzazione, area di lavoro, progetto, cluster). Copre helix.toml, il flusso di lavoro locale/cloud e il modello mentale v3 (NO compilazione helix/controllo helix/file .hx). Per scrivere i corpi delle query stessi, fare riferimento alle competenze helix-query-*. Consulta REFERENCE.md per il catalogo completo dei comandi ed EXAMPLES.md per le procedure dettagliate end-to-end.
