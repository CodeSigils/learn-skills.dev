Pilotez la CLI HelixDB `helix` pour exécuter, interroger et déployer des instances Helix. À utiliser lorsque la tâche consiste à échafauder un projet (helix init / chef / add), à gérer une instance Docker/Podman locale (helix start, stop, restart, status, logs, prune), à ​​envoyer une requête dynamique à une instance en cours d'exécution (helix requête avec --file / --json / -e TypeScript DSL / --ts-file, contre POST /v1/query), ou à opérer sur Helix Cloud (helix auth, push, sync, workspace, project, cluster). Couvre helix.toml, le flux de travail local contre cloud et le modèle mental v3 (AUCUNE compilation d'hélice/vérification d'hélice/fichiers .hx). Pour écrire les corps de requête eux-mêmes, reportez-vous aux compétences helix-query-*. Voir REFERENCE.md pour le catalogue complet de commandes et EXAMPLES.md pour des procédures pas à pas de bout en bout.
