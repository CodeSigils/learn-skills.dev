قم بقيادة واجهة سطر الأوامر HelixDB `helix` لتشغيل مثيلات Helix والاستعلام عنها ونشرها. يُستخدم عندما تكون المهمة هي دعم مشروع (helix init / Chef / add)، أو إدارة مثيل Docker/Podman محلي (بدء حلزوني، إيقاف، إعادة تشغيل، حالة، سجلات، تقليم)، إرسال استعلام ديناميكي إلى مثيل قيد التشغيل (استعلام حلزوني باستخدام --file / --json / -e TypeScript DSL / --ts-file، مقابل POST /v1/query)، أو العمل على Helix Cloud (مصادقة الحلزون، الدفع، المزامنة، مساحة العمل، المشروع، الكتلة). يغطي ملف helix.toml، وسير العمل المحلي مقابل السحابي، والنموذج العقلي v3 (لا توجد ملفات تجميع حلزونية / فحص حلزوني / ملفات .hx). لكتابة أجسام الاستعلام نفسها، ارجع إلى مهارات helix-query-*. راجع REFERENCE.md للحصول على كتالوج الأوامر الكامل وEXAMPLES.md للحصول على إرشادات شاملة.
