Используйте CLI HelixDB «helix» для запуска, запроса и развертывания экземпляров Helix. Используйте, когда задача состоит в том, чтобы создать шаблон проекта (helix init/chef/add), управлять локальным экземпляром Docker/Podman (запуск, остановка, перезапуск Helix, состояние, журналы, обрезка), отправить динамический запрос к работающему экземпляру (запрос Helix с --file / --json / -e TypeScript DSL / --ts-file, против POST /v1/query) или работать в Helix Cloud (helix auth, push, sync, workspace, project, кластер). Охватывает helix.toml, рабочий процесс локального и облачного взаимодействия и ментальную модель v3 (БЕЗ компиляции Helix/проверки Helix/файлов .hx). Для написания самих тел запроса воспользуйтесь навыками helix-query-*. См. REFERENCE.md для полного каталога команд и EXAMPLES.md для сквозных пошаговых руководств.
