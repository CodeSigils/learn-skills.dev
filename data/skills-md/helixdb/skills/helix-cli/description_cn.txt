驱动 HelixDB `helix` CLI 来运行、查询和部署 Helix 实例。当任务是构建项目（helix init / Chef / add）、管理本地 Docker/Podman 实例（helix 启动、停止、重新启动、状态、日志、修剪）、向正在运行的实例发送动态查询（使用 --file / --json / -e TypeScript DSL / --ts-file，针对 POST /v1/query 的 Helix 查询）或在 Helix Cloud 上操作（helix auth、push、sync、workspace、project、cluster）时使用。涵盖 helix.toml、本地与云工作流程和 v3 心理模型（无螺旋编译/螺旋检查/.hx 文件）。对于编写查询体本身，请遵循 helix-query-* 技能。有关完整命令目录，请参阅 REFERENCE.md；有关端到端演练，请参阅 Examples.md。
