Crea e convalida richieste di query in linea dinamiche HelixDB per POST /v1/query. Da utilizzare quando l'attività prevede query dinamiche, query JSON in linea, AST in linea (passaggi, predicati, espressioni, proiezioni), parametri_tipo, coercizione DateTime, riscaldamento delle query o debug del corpo di una richiesta inviato direttamente al gateway Helix. Consulta REFERENCE.md per ogni variante AST ed EXAMPLES.md per i payload copiabili.
