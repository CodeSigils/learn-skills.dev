Scrivi e rivedi le query HelixDB con TypeScript DSL (@helix-db/helix-db). Da utilizzare quando l'attività consiste nell'aggiungere, aggiornare o rivedere una query Helix creata in TypeScript con readBatch, writeBatch, g(), builder traversali, proiezioni, indici, ricerca di testo BM25 o ricerca vettoriale, producendo richieste POST /v1/query dinamiche (toDynamicJson/toDynamicRequest) e, facoltativamente, un bundle di query (defineQueries/registerRead/registerWrite). Ispeziona etichette locali, bordi, proprietà e modelli di query esistenti prima di inventare nuovo codice. Vedi REFERENCE.md per il catalogo completo del builder ed EXAMPLES.md per i modelli end-to-end.
