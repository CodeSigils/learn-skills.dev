Пишите и редактируйте запросы HelixDB с помощью TypeScript DSL (@helix-db/helix-db). Используйте, когда задачей является добавление, обновление или проверка запроса Helix, встроенного в TypeScript, с помощью readBatch, writeBatch, g(), построителей обхода, проекций, индексов, текстового поиска BM25 или векторного поиска — создание динамических запросов POST /v1/query (toDynamicJson/toDynamicRequest) и, при необходимости, пакета запросов (defineQueries/registerRead/registerWrite). Прежде чем придумывать новый код, проверьте локальные метки, края, свойства и существующие шаблоны запросов. См. REFERENCE.md для полного каталога конструкторов и EXAMPLES.md для сквозных шаблонов.
