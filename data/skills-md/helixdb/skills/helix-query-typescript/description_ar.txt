قم بكتابة ومراجعة استعلامات HelixDB باستخدام TypeScript DSL (@helix-db/helix-db). يُستخدم عندما تكون المهمة هي إضافة استعلام Helix مضمن في TypeScript أو تحديثه أو مراجعته باستخدام readBatch أو writeBatch أو g() أو منشئي الاجتياز أو الإسقاطات أو الفهارس أو البحث النصي BM25 أو البحث المتجه - مما يؤدي إلى إنتاج طلبات POST /v1/query ديناميكية (toDynamicJson/toDynamicRequest)، واختياريًا، حزمة استعلام (defineQueries/registerRead/registerWrite). افحص التسميات والحواف والخصائص المحلية وأنماط الاستعلام الموجودة قبل اختراع تعليمات برمجية جديدة. راجع REFERENCE.md للحصول على كتالوج المنشئ الكامل وEXAMPLES.md للتعرف على الأنماط الشاملة.
