Escriba y revise consultas de HelixDB con TypeScript DSL (@helix-db/helix-db). Úselo cuando la tarea sea agregar, actualizar o revisar una consulta Helix integrada en TypeScript con readBatch, writeBatch, g(), generadores transversales, proyecciones, índices, búsqueda de texto BM25 o búsqueda vectorial, lo que produce solicitudes POST /v1/query dinámicas (toDynamicJson/toDynamicRequest) y, opcionalmente, un paquete de consultas (defineQueries/registerRead/registerWrite). Inspeccione las etiquetas locales, los bordes, las propiedades y los patrones de consulta existentes antes de inventar código nuevo. Consulte REFERENCE.md para ver el catálogo completo de constructores y EXAMPLES.md para ver patrones de un extremo a otro.
