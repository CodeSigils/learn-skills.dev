Traduci il legacy HelixDB HQL (.hx `QUERY ... => ... RETURN`) nel Rust DSL o TypeScript DSL. Da utilizzare quando l'input contiene la sintassi HQL: QUERY, N<T>/E<T>/V<T>, AddN/AddE/AddV, Out/In/OutE/InE, FromN/ToN, WHERE/EQ/GT/EXISTS, SearchV/SearchBM25, GROUP_BY/AGGREGATE_BY, ORDER<Desc>/RANGE, RETURN, UpsertN, RerankRRF, File ShortestPath, Embed o .hx e l'obiettivo è una query DSL Rust o TypeScript equivalente. Contrassegna le funzionalità HQL senza equivalenti DSL. Vedere REFERENCE.md per la tabella di mappatura completa ed EXAMPLES.md per le migrazioni HQL→Rust→TS eseguite.
