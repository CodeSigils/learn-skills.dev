Переведите устаревший HQL HelixDB (.hx `QUERY ... => ... RETURN`) в Rust DSL или TypeScript DSL. Используйте, когда входные данные содержат синтаксис HQL — QUERY, N<T>/E<T>/V<T>, AddN/AddE/AddV, Out/In/OutE/InE, FromN/ToN, WHERE/EQ/GT/EXISTS, SearchV/SearchBM25, GROUP_BY/AGGREGATE_BY, ORDER<Desc>/RANGE, RETURN, UpsertN, RerankRRF, Файлы ShortestPath, Embed или .hx — и целью является эквивалентный DSL-запрос Rust или TypeScript. Отмечает функции HQL, не имеющие эквивалента DSL. См. REFERENCE.md для полной таблицы сопоставлений и EXAMPLES.md для рабочих миграций HQL → Rust → TS.
