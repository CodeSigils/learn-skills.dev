将旧版 HelixDB HQL (.hx `QUERY ... => ... RETURN`) 转换为 Rust DSL 或 TypeScript DSL。当输入包含 HQL 语法时使用 - QUERY、N<T>/E<T>/V<T>、AddN/AddE/AddV、Out/In/OutE/InE、FromN/ToN、WHERE/EQ/GT/EXISTS、SearchV/SearchBM25、GROUP_BY/AGGREGATE_BY、ORDER<Desc>/RANGE、RETURN、UpsertN、RerankRRF、ShortestPath、嵌入或 .hx 文件 - 目标是等效的 Rust 或 TypeScript DSL 查询。标记没有 DSL 等效功能的 HQL 功能。请参阅 REFERENCE.md 了解完整的映射表，并参阅 Examples.md 了解已完成的 HQL→Rust→TS 迁移。
