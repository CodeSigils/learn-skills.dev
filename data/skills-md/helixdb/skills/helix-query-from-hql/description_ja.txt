従来の HelixDB HQL (.hx `QUERY ... => ... RETURN`) を Rust DSL または TypeScript DSL に変換します。入力に HQL 構文が含まれる場合に使用します — QUERY、N<T>/E<T>/V<T>、AddN/AddE/AddV、Out/In/OutE/InE、FromN/ToN、WHERE/EQ/GT/EXISTS、SearchV/SearchBM25、GROUP_BY/AGGREGATE_BY、ORDER<Desc>/RANGE、RETURN、UpsertN、RerankRRF、 ShortestPath、Embed、または .hx ファイル — そして目標は、同等の Rust または TypeScript DSL クエリです。 DSL に相当する機能がない HQL 機能にフラグを立てます。完全なマッピング テーブルについては REFERENCE.md を、実際の HQL→Rust→TS 移行については EXAMPLES.md を参照してください。
