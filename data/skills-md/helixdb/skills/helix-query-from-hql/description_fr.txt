Traduisez l'ancien HelixDB HQL (.hx `QUERY ... => ... RETURN`) en Rust DSL ou TypeScript DSL. À utiliser lorsque l'entrée contient une syntaxe HQL : QUERY, N<T>/E<T>/V<T>, AddN/AddE/AddV, Out/In/OutE/InE, FromN/ToN, WHERE/EQ/GT/EXISTS, SearchV/SearchBM25, GROUP_BY/AGGREGATE_BY, ORDER<Desc>/RANGE, RETURN, UpsertN, RerankRRF, ShortestPath, Embed, ou .hx - et l'objectif est une requête DSL Rust ou TypeScript équivalente. Signale les fonctionnalités HQL sans équivalent DSL. Voir REFERENCE.md pour le tableau de mappage complet et EXAMPLES.md pour les migrations HQL → Rust → TS travaillées.
