Traduzca HelixDB HQL heredado (.hx `QUERY... =>... RETURN`) a Rust DSL o TypeScript DSL. Úselo cuando la entrada contenga sintaxis HQL: QUERY, N<T>/E<T>/V<T>, AddN/AddE/AddV, Out/In/OutE/InE, FromN/ToN, WHERE/EQ/GT/EXISTS, SearchV/SearchBM25, GROUP_BY/AGGREGATE_BY, ORDER<Desc>/RANGE, RETURN, UpsertN, RerankRRF, Archivos ShortestPath, Embed o .hx, y el objetivo es una consulta DSL equivalente a Rust o TypeScript. Marca funciones HQL sin equivalente DSL. Consulte REFERENCE.md para ver la tabla de mapeo completa y EXAMPLES.md para migraciones trabajadas de HQL→Rust→TS.
