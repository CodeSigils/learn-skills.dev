레거시 HelixDB HQL(.hx `QUERY ... => ... RETURN`)을 Rust DSL 또는 TypeScript DSL로 변환합니다. 입력에 HQL 구문(QUERY, N<T>/E<T>/V<T>, AddN/AddE/AddV, Out/In/OutE/InE, FromN/ToN, WHERE/EQ/GT/EXISTS, SearchV/SearchBM25, GROUP_BY/AGGREGATE_BY, ORDER<Desc>/RANGE, RETURN, UpsertN, RerankRRF, ShortestPath,)이 포함된 경우 사용합니다. Embed 또는 .hx 파일 - 목표는 동등한 Rust 또는 TypeScript DSL 쿼리입니다. DSL과 동등한 기능이 없는 HQL 기능에 플래그를 지정합니다. 전체 매핑 테이블은 REFERENCE.md를, 작업된 HQL→Rust→TS 마이그레이션은 EXAMPLES.md를 참조하세요.
