قم بترجمة HelixDB HQL القديم (.hx `QUERY... => ... RETURN`) إلى Rust DSL أو TypeScript DSL. يُستخدم عندما يحتوي الإدخال على بناء جملة HQL - QUERY، N<T>/E<T>/V<T>، AddN/AddE/AddV، Out/In/OutE/InE، FromN/ToN، WHERE/EQ/GT/EXISTS، SearchV/SearchBM25، GROUP_BY/AGGREGATE_BY، ORDER<Desc>/RANGE، RETURN، UpsertN، RerankRRF أو ShortestPath أو Embed أو ملفات .hx - والهدف هو استعلام Rust أو TypeScript DSL مكافئ. تتميز Flags HQL بعدم وجود مكافئ لـ DSL. راجع REFERENCE.md للحصول على جدول التعيين الكامل وEXAMPLES.md لعمليات ترحيل HQL → Rust → TS.
