Active esta habilidad cuando el usuario desee una recopilación profunda de artículos académicos de varias rondas para una encuesta o revisión de literatura utilizando datos de AMiner y un controlador LLM estilo ReAct. Utilice esta habilidad para una exploración amplia de temas, construcción de bibliografía de encuestas, búsqueda automática de palabras clave, además de una bola de nieve con referencias hacia atrás y para recopilar cientos de artículos de candidatos con ID y títulos de AMiner. Esta habilidad llama a un modelo de chat compatible con OpenAI para decidir las llamadas a herramientas y utiliza la búsqueda de palabras clave AMiner más API de referencia en papel como herramientas. No está diseñado para búsquedas simples en un solo documento ni para recomendaciones ligeras; utilice papel académico sin aminer o papel diario aminer para esas tareas más sencillas.
