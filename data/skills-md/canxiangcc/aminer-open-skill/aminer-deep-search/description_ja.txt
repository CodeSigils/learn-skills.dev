ユーザーが AMiner データと ReAct スタイルの LLM コントローラーを使用して調査または文献レビューを行うために、複数ラウンドにわたる詳細な学術論文の収集を必要とする場合は、このスキルをアクティブにします。このスキルを使用して、広範なトピックの探索、文献目録の構築、自動キーワード検索と後方参照の雪だるま式検索、および AMiner ID とタイトルを持つ数百の候補論文の収集を行います。このスキルは、OpenAI 互換のチャット モデルを呼び出してツール呼び出しを決定し、AMiner キーワード検索と論文参照 API をツールとして使用します。これは、単純な単一論文の検索や軽量の推奨を目的としたものではありません。それらの単純なタスクには、アミンフリーアカデミックまたはアミンデイリーペーパーを使用してください。
