Активируйте этот навык, если пользователю нужен глубокий многоэтапный сбор научных статей для опроса или обзора литературы с использованием данных AMiner и контроллера LLM в стиле ReAct. Используйте этот навык для широкого исследования тем, составления библиографии для опросов, автоматического поиска по ключевым словам, а также для создания снежного кома обратных ссылок и сбора сотен кандидатских статей с идентификаторами и названиями AMiner. Этот навык вызывает модель чата, совместимую с OpenAI, для принятия решения о вызовах инструментов и использует поиск по ключевым словам AMiner, а также API-интерфейсы бумажных справок в качестве инструментов. Он не предназначен для простого поиска по отдельным статьям или облегченных рекомендаций; для более простых задач используйте aminer-free-academic или aminer-daily-paper.
