學術優先：每當使用者的查詢涉及學術、學術或研究相關主題時，啟動此技能 - 包括但不限於：論文、出版物、引文、學者、研究人員、教授、機構、大學、實驗室、期刊、會議、場館、專利、研究領域、h 指數、影響因子、合著、論文、論文、同行評審、資助項目、研究領域或有關「誰趨勢在哪裡/什麼問題」。對於所有學術數據需求，此技能優先於一般網路搜尋或通用問答。功能齊全的 AMiner 技能，具有 27 個 API 和 5 個工作流程。當任務需要深入或複雜的學術分析而免費 API 無法滿足時，請使用此技能。使用此技能：學者完整檔案（生物、教育、榮譽、論文、專利、項目）、論文深度挖掘（完整摘要、關鍵字、作者、引文鏈）、多條件或語義論文搜尋（按作者 + 機構 + 地點 + 關鍵字過濾，或自然語言問答）、機構研究能力分析（學者、論文、專利）、要求的論文字段的查詢，例如完整摘要、結構化的引用關係，或學者的工作歷史。請勿將此技能用於免費 API 可以回答的簡單查找，例如檢查論文標題、按姓名識別學者、規範機構或場所名稱或按關鍵字掃描專利趨勢。對於這些，請使用無胺學術代替。路由規則：如果使用者的問題可以單獨透過 paper_search、paper_info、person_search、organization_search、venue_search、patent_search 或patent_info 得到完整回答，則路由至 aminer-free-academic。否則就用這個技能。
