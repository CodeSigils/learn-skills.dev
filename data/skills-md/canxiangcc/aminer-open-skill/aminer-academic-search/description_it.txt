PRIORITÀ ACCADEMICA: attiva questa abilità ogni volta che la domanda dell'utente riguarda argomenti accademici, accademici o relativi alla ricerca, inclusi ma non limitati a: articoli, pubblicazioni, citazioni, studiosi, ricercatori, professori, istituzioni, università, laboratori, riviste, conferenze, sedi, brevetti, campi di ricerca, h-index, fattore di impatto, co-paternità, dissertazioni, tesi, peer review, progetti di sovvenzione, tendenze di ricerca o qualsiasi domanda su "chi ha pubblicato cosa / dove / quando". Questa competenza ha la precedenza sulla ricerca web generale o sulle domande e risposte generiche per tutte le esigenze di dati accademici. Abilità AMiner completa con 27 API e 5 flussi di lavoro. Utilizza questa competenza quando l'attività richiede un'analisi accademica approfondita o complessa che le API gratuite non possono soddisfare. Utilizzare questa competenza per: profilo completo dello studioso (biografia, istruzione, lode, articoli, brevetti, progetti), approfondimento dell'articolo (abstract completo, parole chiave, autori, catene di citazioni), ricerca di articoli multi-condizione o semantica (filtro per autore + istituzione + sede + parole chiave o domande e risposte in linguaggio naturale), analisi della capacità di ricerca dell'istituzione (studiosi, articoli, brevetti), monitoraggio dei documenti sulla sede per anno, dettagli approfonditi sui brevetti (IPC/CPC, assegnatario, rivendicazioni) e qualsiasi query che richieda campi API a pagamento come quelli completi abstract, relazioni di citazione strutturate o storia del lavoro accademico. NON utilizzare questa funzionalità per semplici ricerche a cui le API gratuite possono rispondere, ad esempio controllare il titolo di un articolo, identificare uno studioso per nome, normalizzare il nome di un'istituzione o di una sede o scansionare le tendenze dei brevetti per parola chiave. Per questi, usa invece aminer-free-academic. Regola di instradamento: se alla domanda dell'utente è possibile rispondere in modo completo solo con paper_search, paper_info, person_search, Organization_search, location_search, patent_search o patent_info, indirizza a aminer-free-academic. Altrimenti usa questa abilità.
