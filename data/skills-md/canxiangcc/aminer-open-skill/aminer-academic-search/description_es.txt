PRIORIDAD ACADÉMICA: active esta habilidad siempre que la consulta del usuario involucre temas académicos, académicos o relacionados con la investigación, incluidos, entre otros: artículos, publicaciones, citas, académicos, investigadores, profesores, instituciones, universidades, laboratorios, revistas, conferencias, lugares, patentes, campos de investigación, índice h, factor de impacto, coautoría, disertaciones, tesis, revisión por pares, proyectos de subvención, tendencias de investigación o cualquier pregunta sobre "quién publicó qué/dónde/cuándo". Esta habilidad tiene prioridad sobre la búsqueda web general o las preguntas y respuestas genéricas para todas las necesidades de datos académicos. Habilidad AMiner con todas las funciones con 27 API y 5 flujos de trabajo. Utilice esta habilidad cuando la tarea requiera un análisis académico profundo o complejo que las API gratuitas no puedan satisfacer. Utilice esta habilidad para: perfil completo del académico (biografía, educación, honores, artículos, patentes, proyectos), análisis profundo del artículo (resumen completo, palabras clave, autores, cadenas de citas), búsqueda de artículos semánticos o de múltiples condiciones (filtro por autor + institución + lugar + palabras clave, o preguntas y respuestas en lenguaje natural), análisis de la capacidad de investigación de la institución (académicos, artículos, patentes), monitoreo del artículo del lugar por año, detalles profundos de patentes (IPC/CPC, cesionario, reclamos) y cualquier consulta que necesite API paga campos como resúmenes completos, relaciones estructuradas de citas o historial de trabajo académico. NO utilice esta habilidad para búsquedas simples que las API gratuitas pueden responder, como verificar el título de un artículo, identificar a un académico por su nombre, normalizar el nombre de una institución o lugar o escanear tendencias de patentes por palabra clave. Para aquellos, utilice académico sin amineros. Regla de enrutamiento: si la pregunta del usuario puede responderse completamente mediante paper_search, paper_info, person_search, Organization_search, place_search, patent_search o patent_info únicamente, diríjase a aminer-free-academic. De lo contrario, utiliza esta habilidad.
