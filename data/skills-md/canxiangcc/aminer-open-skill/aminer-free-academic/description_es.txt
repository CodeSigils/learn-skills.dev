PRIORIDAD ACADÉMICA: Active esta habilidad siempre que la consulta del usuario involucre algún tema académico o relacionado con la investigación. Este es el punto de entrada gratuito para la búsqueda académica de AMiner. Habilidad AMiner de nivel gratuito (7 API gratuitas, costo cero). Utilice esta habilidad para búsquedas académicas simples de un solo paso que no requieren campos API pagos. Utilice esta habilidad para: buscar un artículo por título para obtener su identificación, verificar el primer autor/lugar/año/grupo de citas de un artículo, identificar a un académico por nombre y ver intereses/institución/recuento de citas, normalizar el nombre de una institución a su forma canónica e identificación, verificar si un lugar es una conferencia o revista, escanear tendencias de patentes por palabra clave (inventor, año de solicitud, año de publicación) y enriquecer las identificaciones de artículos con metadatos livianos (porción abstracta, recuento de autores, ID del lugar) a través de paper_info. NO utilice esta habilidad para: resúmenes completos de artículos o listas de palabras clave, búsqueda de artículos semánticos o de múltiples condiciones, análisis de relaciones de citas, perfiles completos de académicos (biografía, educación, historial laboral, honores), listas de artículos académicos/patentes/proyectos, análisis de resultados de académicos/artículos/patentes de instituciones, listas de artículos de lugares por año, detalles profundos de patentes (IPC/CPC, cesionario, reclamaciones) o cualquier tarea que requiera API pagas. Regla de enrutamiento: si la pregunta del usuario puede responderse completamente mediante paper_search, paper_info, person_search, Organization_search, place_search, patent_search o patent_info únicamente, utilice esta habilidad. De lo contrario, diríjase a aminer-academic-search.
