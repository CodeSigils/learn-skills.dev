學術優先：只要使用者的查詢涉及任何學術或研究相關主題，就啟動此技能。這是 AMiner 學術搜尋的免費入口點。僅免費層 AMiner 技能（7 個免費 API，零成本）。使用此技能進行簡單的單步驟學術查找，不需要付費 API 欄位。使用此技能可以：按標題搜尋論文以獲取其 ID，檢查論文的第一作者/地點/年份/引用桶，按姓名識別學者並查看興趣/機構/引用計數，將機構名稱標準化為其規範形式和 ID，檢查地點是否為會議或期刊，按關鍵字（發明人、申請年份、出版年份）掃描專利趨勢，以及通過 paper_info 使用輕量級資料 ID（摘要編號）。請勿將此技能用於：完整論文摘要或關鍵字列表、多條件或語義論文搜尋、引文關係分析、學者完整檔案（個人簡介、教育背景、工作經歷、榮譽）、學術論文/專利/項目列表、機構學者/論文/專利產出分析、按年份列出的地點論文列表、專利深度詳細信息（IPC/CPC、受讓人、權利要求）或任何需要 API 的任務。路由規則：如果使用者的問題可以單獨透過 paper_search、paper_info、person_search、organization_search、venue_search、patent_search 或patent_info 完全回答，則使用此技能。否則路由至 aminer-academic-search。
