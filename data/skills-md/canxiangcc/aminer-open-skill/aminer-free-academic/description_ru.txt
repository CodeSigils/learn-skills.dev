АКАДЕМИЧЕСКИЙ ПРИОРИТЕТ: активируйте этот навык всякий раз, когда запрос пользователя затрагивает какую-либо академическую или исследовательскую тему. Это бесплатная точка входа для академического поиска AMiner. Навык AMiner только на бесплатном уровне (7 бесплатных API, нулевая стоимость). Используйте этот навык для простых одноэтапных академических поисков, не требующих платных полей API. Используйте этот навык для: поиска статьи по названию, чтобы получить ее идентификатор, проверки первого автора/места/года/цитирования статьи, идентификации ученого по имени и просмотра интересов/учебного заведения/количества цитирований, нормализации названия учреждения до его канонической формы и идентификатора, проверки того, является ли местом проведения конференция или журнал, сканирования патентных тенденций по ключевым словам (изобретатель, год подачи заявки, год публикации) и обогащения идентификаторов статей облегченными метаданными (абстрактный фрагмент, количество авторов, идентификатор места проведения) через paper_info. НЕ используйте этот навык для: полных рефератов статей или списков ключевых слов, поиска статей по множеству условий или семантики, анализа взаимосвязей цитирования, полных профилей ученых (биография, образование, история работы, награды), списков научных статей / патентов / проектов, анализа результатов научных исследований / статей / патентов, списков документов по местам проведения по годам, детальной информации о патентах (IPC/CPC, правопреемник, претензии) или любых задач, требующих платных API. Правило маршрутизации: если на вопрос пользователя можно полностью ответить только с помощью paper_search, paper_info, person_search, Organization_search, места_поиска, патента_поиска или патента_информации, используйте этот навык. В противном случае перейдите к aminer-academic-search.
