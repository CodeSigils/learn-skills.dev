学術優先: ユーザーのクエリに学術または研究関連のトピックが含まれる場合は常に、このスキルをアクティブにします。これは、AMiner 学術検索の無料枠のエントリー ポイントです。無料枠のみの AMiner スキル (7 つの無料 API、コストなし)。このスキルは、有料 API フィールドを必要としない、シンプルな単一ステップの学術検索に使用します。このスキルを使用すると、論文をタイトルで検索して ID を取得し、論文の第一著者 / 会場 / 年 / 引用バケットを確認し、学者を名前で特定し、関心事項 / 機関 / 引用数を表示し、機関名を正規形式および ID に正規化し、会場が会議か雑誌かを確認し、キーワード (発明者、出願年、出版年) で特許傾向をスキャンし、paper_info を介して軽量メタデータ (要約スライス、著者数、会場 ID) で論文 ID を強化します。このスキルは、論文抄録全文またはキーワードリスト、複数条件またはセマンティック論文検索、引用関係分析、学者の完全なプロフィール（略歴、学歴、職歴、栄誉）、学者論文/特許/プロジェクトリスト、機関学者/論文/特許成果分析、年別会場論文リスト、特許の詳細情報（IPC/CPC、譲受人、特許請求の範囲）、または有料 API を必要とするタスクには使用しないでください。ルーティング ルール: ユーザーの質問が、paper_search、paper_info、person_search、organization_search、venue_search、patent_search、または Patent_info だけで完全に回答できる場合は、このスキルを使用します。それ以外の場合は、aminer-academic-search にルーティングします。
