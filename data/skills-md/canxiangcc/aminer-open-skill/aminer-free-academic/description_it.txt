PRIORITÀ ACCADEMICA: attiva questa abilità ogni volta che la domanda dell'utente riguarda argomenti accademici o relativi alla ricerca. Questo è il punto di ingresso a livello gratuito per la ricerca accademica AMiner. Abilità AMiner solo a livello gratuito (7 API gratuite, costo zero). Utilizza questa competenza per ricerche accademiche semplici, in un unico passaggio, che non richiedono campi API a pagamento. Utilizzare questa funzionalità per: cercare un articolo per titolo per ottenerne l'ID, controllare il primo autore/sede/anno/elenco di citazioni di un articolo, identificare uno studioso per nome e visualizzare interessi/istituzione/conteggio di citazioni, normalizzare il nome di un'istituzione nella sua forma e ID canonici, controllare se una sede è una conferenza o una rivista, scansionare le tendenze dei brevetti per parola chiave (inventore, anno della domanda, anno di pubblicazione) e arricchire gli ID del documento con metadati leggeri (sezione astratta, conteggio degli autori, ID della sede) tramite paper_info. NON utilizzare questa funzionalità per: abstract completi di documenti o elenchi di parole chiave, ricerca di documenti multi-condizione o semantica, analisi delle relazioni tra citazioni, profili completi degli studiosi (biografia, istruzione, storia lavorativa, lodi), elenchi di documenti/brevetti/progetti di studiosi, analisi dei risultati di studiosi/documenti/brevetti dell'istituzione, elenchi di documenti della sede per anno, dettagli approfonditi sui brevetti (IPC/CPC, assegnatario, rivendicazioni) o qualsiasi attività che richieda API a pagamento. Regola di instradamento: se alla domanda dell'utente è possibile rispondere in modo completo solo tramite paper_search, paper_info, person_search, Organization_search, location_search, patent_search o patent_info, utilizzare questa abilità. Altrimenti vai a aminer-academic-search.
