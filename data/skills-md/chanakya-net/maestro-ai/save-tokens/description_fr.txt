Mode de réponse ultra-compressé. Réduit l'utilisation des jetons en supprimant les articles, les remplissages, les plaisanteries et la couverture. Utilise des symboles pour les relations. Les termes techniques et les blocs de code restent exacts et non compressés. À utiliser lorsque l'utilisateur dit « enregistrer les jetons », « mode RTU » ou « mode de réponse compressé ».
