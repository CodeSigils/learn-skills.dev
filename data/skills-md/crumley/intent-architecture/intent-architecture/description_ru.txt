Создайте, загрузите или реорганизуйте любой репозиторий в четырехстороннюю структуру, управляемую намерениями — устойчивое дерево намерений (видение, принципы, глоссарий, концепции, контракты подсистем), которое управляет «проектированием» (как + хронологическая запись его создания — записи проекта и ADR), «src/» (код) и «тестирование» (тесты). Используйте его, когда вас попросят настроить этот макет, запустите с его помощью новый репозиторий (скаффолды из сопутствующего начального шаблона, включая закрепленный контрольный шлюз Markdown), перенесите в него существующий репозиторий, извлеките намерение (долговечное «что и почему») из существующих документов и кода или объясните правила, структуру каталогов/файлов, разделы файлов, AGENTS.md и README для каждого уровня, которые управляют им, включая дополнительные дисциплины записи сборки: жизненный цикл принятия решения по обратной связи по спецификации и форма доставки для записей, созданных агентом. Общего назначения: не содержит контента, специфичного для проекта.
