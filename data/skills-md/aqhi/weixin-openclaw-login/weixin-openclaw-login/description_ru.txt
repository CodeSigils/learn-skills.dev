Выполните официальный процесс входа в систему и устранение неполадок при интеграции личных учетных записей WeChat в OpenClaw. Используется для установки `@tencent-weixin/openclaw-weixin`, получения новых ссылок авторизации QR-кода, проверки статуса сканирования QR-кода, исправления зависания `openclaw-weixin` на `SETUP/no token` и организации документации для интеграции WeChat 8.0.70+ с OpenClaw.
