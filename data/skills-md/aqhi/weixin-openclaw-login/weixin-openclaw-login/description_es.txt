Maneje el proceso de inicio de sesión oficial y la resolución de problemas para integrar cuentas personales de WeChat en OpenClaw. Se utiliza para instalar `@tencent-weixin/openclaw-weixin`, obtener nuevos enlaces de autorización de códigos QR, verificar el estado del escaneo del código QR, arreglar `openclaw-weixin` atascado en `SETUP/no token` y organizar la documentación para integrar WeChat 8.0.70+ con OpenClaw.
