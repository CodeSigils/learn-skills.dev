قم بتشغيل لجنة تحكيم تصميم متعددة الوكلاء قبل التنفيذ. يُستخدم عندما يتعين على الوكيل المنفذ إجراء اختبار إجهاد لخطة أو اختيار بنية أو سلوك المنتج أو المقايضة عن طريق إرسال أسئلة الشبكة المركزة إلى Codex أو Claude Code أو Pi أو أدوات الوكيل التي تم تكوينها، ولا تسأل المستخدم إلا عندما لا تتمكن هيئة المحلفين من حل السؤال المركز.
