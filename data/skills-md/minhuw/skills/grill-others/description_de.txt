Führen Sie vor der Implementierung eine Multi-Agent-Design-Jury durch. Verwenden Sie diese Option, wenn der ausführende Agent einen Plan, eine Architekturauswahl, ein Produktverhalten oder einen Kompromiss einem Stresstest unterziehen soll, indem er gezielte Grillfragen an Codex, Claude Code, Pi oder konfigurierte Agentenbäume sendet und den Benutzer nur dann fragt, wenn die Jury die fokussierte Frage nicht lösen kann.
