تخطيط وتشغيل مسارات العمل الديناميكية لعامل الذكاء الاصطناعي للمهام المعقدة التي تستفيد من التنسيق الواضح ووضع الهدف والوكلاء الفرعيين أو حزم العمل المحاكية وبوابات الموافقة والتكامل والتحقق وعناصر سير العمل القابلة لإعادة الاستخدام. يتم استخدامها عندما يستدعي المستخدم هذه المهارة، أو يطلب سربًا، أو وكلاء فرعيين، أو وكلاء متوازيين، أو سير عمل ديناميكي، أو ترحيل أو تدقيق كبير، أو بحث متعدد المسارات بالإضافة إلى التنفيذ، أو تنسيق سير العمل بنمط Claude Code.
