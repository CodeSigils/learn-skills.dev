Создавайте API-интерфейсы Laravel REST промышленного уровня. Охватывает общие лучшие практики (качество кода, внедрение внедрения, события, аутентификация, исключения, тестирование, база данных) И конкретные шаблоны essa/api-tool-kit (ApiResponse, QueryFilters, DynamicPaginate, EnumHelpers). Используйте при создании или просмотре любого кода API Laravel в проекте, в котором установлен essa/api-tool-kit.
