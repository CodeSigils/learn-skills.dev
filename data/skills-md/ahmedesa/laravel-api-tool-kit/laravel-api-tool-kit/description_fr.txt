Créez des API REST Laravel de qualité production. Couvre les meilleures pratiques générales (qualité du code, DI, événements, authentification, exceptions, tests, base de données) ET les modèles spécifiques à essa/api-tool-kit (ApiResponse, QueryFilters, DynamicPaginate, EnumHelpers). À utiliser lors de la création ou de la révision de tout code API Laravel dans un projet sur lequel essa/api-tool-kit est installé.
