إنشاء واجهات برمجة تطبيقات Laravel REST على مستوى الإنتاج. يغطي أفضل الممارسات العامة (جودة التعليمات البرمجية، DI، والأحداث، والمصادقة، والاستثناءات، والاختبار، وقاعدة البيانات) والأنماط المحددة لمجموعة أدوات Essa/api (ApiResponse، وQueryFilters، وdynamicPaginate، وEnumHelpers). يُستخدم عند إنشاء أو مراجعة أي كود Laravel API في مشروع تم تثبيت essa/api-tool-kit عليه.
