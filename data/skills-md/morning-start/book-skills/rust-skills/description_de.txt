Vollständiges Kompetenzset für die Programmiersprache Rust unter Verwendung eines metakognitiven Frameworks, das die grundlegende Syntax, das Eigentumssystem, generische Merkmale, Parallelität und asynchrone Programmierung sowie die Verwaltung von Frachtpaketen abdeckt und ein dreischichtiges kognitives Modell der Schicht 1/2/3 unterstützt.
