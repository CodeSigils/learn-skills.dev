Examinez les modifications depuis un point fixe (validation, branche, balise ou base de fusion) selon deux dimensions : les normes (le code suit-il les normes de codage documentées du référentiel ?) et les spécifications (le code répond-il aux exigences du problème/spécification d'origine ?). Exécutez les deux révisions dans des sous-agents parallèles et affichez les résultats côte à côte. Utilisez cette fonctionnalité lorsqu'un utilisateur souhaite examiner une branche, une demande d'extraction, des modifications en cours ou demander un « examen des modifications depuis X ».
