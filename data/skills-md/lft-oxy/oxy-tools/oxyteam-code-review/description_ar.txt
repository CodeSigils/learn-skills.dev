قم بمراجعة التغييرات منذ نقطة ثابتة (الالتزام أو الفرع أو العلامة أو قاعدة الدمج) على طول بُعدين — المعايير (هل يتبع الكود معايير الترميز الموثقة للمستودع؟) والمواصفات (هل يفي الكود بمتطلبات الإصدار/المواصفات الأصلية؟). قم بتشغيل كلا المراجعتين في وكلاء فرعيين متوازيين واعرض النتائج جنبًا إلى جنب. استخدم هذه الميزة عندما يريد المستخدم مراجعة فرع أو طلب سحب أو تغييرات مستمرة أو طلب "مراجعة التغييرات منذ X".
