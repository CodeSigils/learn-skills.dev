Überprüfen Sie Änderungen seit einem festen Punkt (Commit-, Branch-, Tag- oder Merge-Basis) entlang zweier Dimensionen – Standards (entspricht der Code den dokumentierten Codierungsstandards des Repositorys?) und Spezifikationen (erfüllt der Code die ursprünglichen Problem-/Spezifikationsanforderungen?). Führen Sie beide Überprüfungen gleichzeitig in parallelen Subagenten durch und zeigen Sie die Ergebnisse nebeneinander an. Verwenden Sie diese Funktion, wenn ein Benutzer einen Zweig, eine Pull-Anfrage oder laufende Änderungen überprüfen oder eine „Änderungen seit X überprüfen“ anfordern möchte.
