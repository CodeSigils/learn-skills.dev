Revise los cambios desde un punto fijo (confirmación, bifurcación, etiqueta o base de fusión) a lo largo de dos dimensiones: estándares (¿el código sigue los estándares de codificación documentados del repositorio?) y especificaciones (¿el código cumple con los requisitos originales del problema/especificaciones?). Ejecute ambas revisiones en subagentes paralelos y muestre los resultados uno al lado del otro. Utilice esta función cuando un usuario desee revisar una rama, una solicitud de extracción, cambios en curso o solicitar una "revisión de cambios desdeX".
