قم بتكوين الرسوم المتحركة Angular باستخدام المشغلات والانتقالات والإطارات الرئيسية ووظائف الرسوم المتحركة القابلة لإعادة الاستخدام. يُستخدم عند العمل مع الرسوم المتحركة للدخول/الخروج Angular، أو انتقالات واجهة المستخدم، أو الرسوم المتحركة للمسار، أو التأثيرات المتداخلة، أو مشغلات الرسوم المتحركة، أو عندما يطلب المستخدم تحريك المكونات Angular.
