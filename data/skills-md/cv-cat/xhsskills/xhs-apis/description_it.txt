Utilizza questa capacità quando devi chiamare le API Xiaohongshu/XHS vendute da Spider_XHS per dati Web del PC o dati di pubblicazione della piattaforma del creatore. Questa competenza racchiude solo le API in xhs_pc_apis.py e xhs_creator_apis.py, incluse note, utente, ricerca, commento, argomento, posizione, caricamento di contenuti multimediali, pubblicazione di note e query di note pubblicate dal creatore.
