Utilisez cette compétence lorsque vous devez appeler les API Xiaohongshu/XHS fournies à partir de Spider_XHS pour les données Web PC ou les données de publication de la plateforme de création. Cette compétence encapsule uniquement les API dans xhs_pc_apis.py et xhs_creator_apis.py, y compris les requêtes de note, d'utilisateur, de recherche, de commentaire, de sujet, d'emplacement, de téléchargement de média, de publication de notes et de notes publiées par le créateur.
