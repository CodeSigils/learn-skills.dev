Utilice esta habilidad cuando necesite llamar a las API Xiaohongshu/XHS proporcionadas desde Spider_XHS para datos web de PC o datos de publicación de plataforma de creador. Esta habilidad solo incluye las API en xhs_pc_apis.py y xhs_creator_apis.py, incluidas notas, usuarios, búsquedas, comentarios, temas, ubicaciones, carga de medios, publicación de notas y consultas de notas publicadas por el creador.
