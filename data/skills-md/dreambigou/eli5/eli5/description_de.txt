Erklären Sie jedes Thema, jeden Code, jedes Konzept oder jeden Fehler, der auf das Verständnisniveau einer bestimmten Zielgruppe zugeschnitten ist. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer sagt: „Erklären Sie, wie ich bin“, „ELI5“, „Erklären Sie mir das“, „Brechen Sie das auf“, „verdummen Sie es“, „Vereinfachen Sie das für“ oder bittet Sie, einer bestimmten Person oder einem bestimmten Zielgruppentyp etwas zu erklären (z. B. „Erklären Sie das einem Manager“, „Wie würde ich das meiner Mutter erklären“, „Machen Sie das für einen Fünftklässler verständlich“). Wird auch ausgelöst, wenn der Benutzer angibt, dass er etwas auf einer bestimmten Ebene verstehen möchte, oder um eine Erklärung bittet, die sich an ein technisch nicht versiertes Publikum richtet. Selbst Teilübereinstimmungen wie „Erklär es meiner Frau“ oder „Sag es meinem Chef“ sollten diese Fähigkeit auslösen.
