Explica cualquier tema, código, concepto o error adaptado al nivel de comprensión de una audiencia específica. Usa esta habilidad siempre que el usuario diga "explícame como si fuera", "ELI5", "explícame esto a mi", "desglosa esto para", "simplifícalo", "simplifica esto para", o solicite explicar algo a una persona o tipo de audiencia concreto (por ejemplo, "explica esto a mi jefe", "¿cómo le explicaría esto a mi mamá?", "hazlo comprensible para un alumno de 5.º grado"). También actívalo cuando el usuario mencione que quiere entender algo a un nivel particular o pida una explicación para una audiencia no técnica. Incluso coincidencias parciales como "explícale a mi esposa" o "díselo a mi jefe" deben activar esta habilidad.

Responde siempre en el idioma del usuario.
