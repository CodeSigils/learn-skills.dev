قم بتشغيل سير عمل git القائم على التذاكر: اختر الفرع الأساسي، واربط العمل بتذكرة إدارة المشروع، وقم بتسمية الفروع والالتزامات، وافتح العلاقات العامة مقابل القاعدة الصحيحة، وتحقق قبل المراجعة، وانقل حالات التذكرة. يُستخدم عند بدء العمل من معرف تذكرة أو رقم مجرد، أو بدء ملف الخطة/المواصفات/PRD/المهام، أو السؤال عن الفرع المطلوب استخدامه، أو فتح العلاقات العامة، أو مزامنة حالة التعقب بعد عمل الفرع أو الدمج، أو إعداد/إعادة تكوين `.dev-flow/config.json` لإعدادات التعقب أو الفرع الأساسي أو العلاقات العامة أو الالتزام أو تتبع الوقت. لا تستخدم لمراجعة التعليمات البرمجية لعلاقات عامة موجودة، أو الالتزامات لمرة واحدة على فرع تم إنشاؤه بالفعل، أو تقسيم الخطة إلى العديد من المشكلات، أو كتابة PRDs، أو تكوين CI، أو ترويج فرع الإصدار/التكامل، أو أسئلة إرشادية عامة حول git.
