チケット駆動の Git ワークフローを実行します。ベース ブランチを選択し、作業をプロジェクト管理チケットに関連付け、ブランチとコミットに名前を付け、適切なベースに対して PR を開き、レビュー前に確認し、チケット ステータスを移動します。チケット ID またはベア番号から作業を開始する場合、プラン/スペック/PRD/todo ファイルを開始する場合、使用するブランチを尋ねる場合、PR を開く場合、ブランチまたはマージ作業後のトラッカー ステータスを同期する場合、またはトラッカー、ベース ブランチ、PR、コミット、または時間追跡設定の `.dev-flow/config.json` をセットアップ/再構成する場合に使用します。既存の PR のコード レビュー、すでに作成されたブランチでの 1 回限りのコミット、計画を多くの問題に分割する、PRD の作成、CI の構成、リリース/統合ブランチのプロモーション、または一般的な git ハウツーの質問には使用しないでください。
