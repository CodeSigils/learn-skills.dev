Générez un plan d'assurance qualité et de test manuel étape par étape pour une fonctionnalité qui vient d'être implémentée, fondé sur les modifications de code réelles, et enregistrez-le dans docs/qa pour qu'un humain puisse l'exécuter. À utiliser lorsqu'une session de codage se termine et que vous souhaitez tester manuellement le résultat, ou que l'utilisateur dit « écrire un plan d'assurance qualité », « créer un plan de test manuel », « comment tester cela », « générer un plan de test pour cette fonctionnalité » ou exécute /qakit.
