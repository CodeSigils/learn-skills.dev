Erstellen Sie einen schrittweisen manuellen Qualitätssicherungs- und Testplan für eine gerade implementierte Funktion, der auf den tatsächlichen Codeänderungen basiert, und speichern Sie ihn in docs/qa, damit ein Mensch ihn ausführen kann. Verwenden Sie diese Option, wenn eine Codierungssitzung endet und Sie das Ergebnis manuell testen möchten oder der Benutzer sagt „Schreiben Sie einen QA-Plan“, „Erstellen Sie einen manuellen Testplan“, „Wie teste ich das“, „Generieren Sie einen Testplan für diese Funktion“ oder führt /qakit aus.
