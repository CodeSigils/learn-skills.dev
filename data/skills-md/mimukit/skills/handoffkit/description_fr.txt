Compactez la conversation en cours dans un document de transfert qu'un autre agent ou une session peut récupérer à froid : objectif, état, étapes suivantes, artefacts clés par référence et contraintes. À utiliser lorsque l'utilisateur souhaite confier le travail, dit « écrire un transfert », « créer un document de transfert », « résumer ceci pour la prochaine session » ou « transmettre ceci à un autre agent ».
