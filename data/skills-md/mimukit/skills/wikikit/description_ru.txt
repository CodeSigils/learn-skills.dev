Создавайте и обслуживайте в репозитории документацию проекта, предназначенную для читателей — начало работы, практические руководства, обзор архитектуры, инструкции — с проверкой каждой команды по коду в четырех режимах: инициализация, обновление, аудит и публикация по согласию, которая отражает набор в вики GitHub. Используйте, когда пользователь говорит «написать документацию для этого проекта», «задокументировать этот репозиторий», «обновить документацию», «наши документы устарели», «написать модуль Runbook», «написать руководство по началу работы», «обзор архитектуры», «синхронизировать документы с вики GitHub» или «/wikikit». Не передача агента, не глоссарий или ADR.
