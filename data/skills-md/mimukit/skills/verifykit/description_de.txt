Beweisen Sie, dass eine Frontend-Funktion tatsächlich funktioniert, indem Sie sie in einem echten Browser ausführen und Screenshots sowie ein kurzes GIF als PR-bereiten Beweis aufnehmen und veröffentlichen, damit ein Pull-Request es inline einbetten kann. Verwenden Sie diese Option, wenn eine Frontend-Änderung erstellt wird und Sie einen visuellen Beweis dafür benötigen, dass sie funktioniert, bevor Sie den PR öffnen – „Diese Funktion überprüfen“, „Beweis, dass sie funktioniert“, „Funktionsfluss aufzeichnen“, „Änderung der Benutzeroberfläche beweisen“, „/verifykit“ oder wenn ein PR Proof-Artefakte zum Anhängen benötigt.
