Запустите подготовленную «готовую» задачу GitHub на протяжении всего периода сборки без присмотра — рабочее дерево, внедрение, фиксацию, проверку, исправление, план контроля качества и открытый PR — так, чтобы одна проблема достигла проверяемого PR без участия человека за клавиатурой. Используйте, когда пользователь говорит «afkkit», «запускать проблему #N без присмотра», «работать над готовыми проблемами, пока меня нет», «автопилотировать эту проблему», «перенести эту проблему на PR без меня» или хочет, чтобы середина рабочего процесса комплекта управлялась от начала до конца самостоятельно.
