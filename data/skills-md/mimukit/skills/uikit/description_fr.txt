Créez une interface utilisateur de production qui se lit comme un choix délibéré pour ce projet plutôt que comme une valeur par défaut de LLM, et auditez l'interface utilisateur livrée pour les indications qui la révèlent. À utiliser lorsque l'utilisateur dit « créer cette page », « faire en sorte que cette interface utilisateur n'ait pas l'air générée par l'IA », « cela ressemble à du slop », « concevoir cet écran », « auditer notre interface utilisateur », « donner une belle apparence à l'interface » ou « /uikit ». Lit le DESIGN.md d'un projet lorsqu'il en existe un ; ne l'écrit jamais.
