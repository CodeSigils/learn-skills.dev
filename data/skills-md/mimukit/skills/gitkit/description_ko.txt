다른 모든 기술은 공유 git 레이어를 차용합니다. 즉, 작업 트리가 있는 위치와 작업 트리의 이름, 작업 트리를 생성/채택/해체하는 방법, 기본 분기, 리베이스 또는 병합 여부 등을 차용합니다. 사용자가 "이 작업을 위해 작업 트리를 가동하세요", "작업 트리를 만들어 주세요", "#42에 대한 작업 트리는 어디에 있나요", "이 작업 트리를 해체하세요", "내 작업 트리를 정리하세요", "여기 기본 분기는 무엇인가요?", "리베이스하거나 병합해야 할까요?" 또는 "/gitkit"을 실행할 때 — 그리고 다른 스킬에 이러한 답변이 필요할 때마다 사용하세요.
