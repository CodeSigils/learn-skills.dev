Befragen Sie den Benutzer unermüdlich zu jeder Idee, jedem Plan oder jedem Design – eine Entscheidung nach der anderen, jede mit einer empfohlenen Antwort, bis Sie beide das gleiche Bild haben. Verwenden Sie diese Option, wenn der Benutzer eine Idee einem Stress- oder Drucktest unterziehen möchte, sagt „Mich auf die Probe stellen“, „Diesen Plan prüfen“, „Löcher darin stecken“, „Meinen Entwurf abfragen“ oder auf andere Weise darum bittet, ein Konzept zu befragen, bevor er sich darauf festlegt – eine grobe Idee, eine Plandatei, eine Architektur oder eine PR.
