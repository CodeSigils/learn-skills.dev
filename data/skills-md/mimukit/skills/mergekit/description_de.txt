Nehmen Sie eine offene GitHub-PR und bereiten Sie sie auf Ihrem Computer für die Zusammenführung vor – einen Git-Arbeitsbaum, eine Synchronisierung mit dem Basiszweig, das eingerichtete und ausgeführte Projekt und ein Review-Pack mit allem, was Sie zur Beurteilung benötigen – und führen Sie es dann mit einem Merge-Commit zusammen, sobald Sie es sagen. Verwenden Sie diese Option, wenn Sie sich hinsetzen, um die PRs zu überprüfen, die ein Agent über Nacht geöffnet hat. Sagen Sie: „Ziehen Sie PR Nr. 34 herunter, damit ich sie testen kann“, „Überprüfen Sie die fertigen PRs vor Ort“, „sehen Sie sich diese PR zur Qualitätssicherung an“, „machen Sie diese PR für die Zusammenführung bereit“, „führen Sie PR Nr. 34 zusammen“ oder führen Sie „/mergekit“ aus.
