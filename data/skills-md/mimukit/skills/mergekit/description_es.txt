Tome un GitHub PR abierto y prepárelo para fusionarse en su máquina (un árbol de trabajo de git, una sincronización con la rama base, el proyecto configurado y en ejecución y un paquete de revisión de todo lo que necesita para juzgarlo), luego combínelo con una confirmación de fusión una vez que lo diga. Úselo cuando se siente a revisar los PR que un agente abrió durante la noche, diga "baje el PR #34 para que pueda probarlo", "revise los PR listos localmente", "consulte este PR para control de calidad", "prepare este PR para fusionar", "fusione el PR #34" o ejecute "/mergekit".
