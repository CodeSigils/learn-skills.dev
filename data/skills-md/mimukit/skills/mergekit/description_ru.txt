Возьмите открытый PR GitHub и подготовьте его к слиянию на своем компьютере — рабочее дерево git, синхронизацию с базовой веткой, настройку и запуск проекта, а также пакет проверки всего, что вам нужно для его оценки — а затем объедините его с коммитом слияния, как только вы об этом скажете. Используйте, когда вы садитесь за просмотр PR, которые агент открыл ночью, скажите: «Потяните PR #34 вниз, чтобы я мог протестировать его», «Проверьте готовые PR на месте», «Проверьте этот PR для контроля качества», «Подготовьте этот PR к слиянию», «Объедините PR #34» или запустите «/mergekit».
