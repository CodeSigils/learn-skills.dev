Prenez un PR GitHub ouvert et préparez-le à la fusion sur votre machine - un arbre de travail git, une synchronisation avec la branche de base, le projet configuré et en cours d'exécution et un pack de révision de tout ce dont vous avez besoin pour le juger - puis fusionnez-le avec un commit de fusion une fois que vous le dites. À utiliser lorsque vous vous asseyez pour examiner les PR qu'un agent a ouverts pendant la nuit, dites « tirez le PR n° 34 vers le bas pour que je puisse le tester », « examinez les PR prêts localement », « consultez ce PR pour le contrôle qualité », « préparez ce PR pour la fusion », « fusionnez le PR n° 34 » ou exécutez « /mergekit ».
