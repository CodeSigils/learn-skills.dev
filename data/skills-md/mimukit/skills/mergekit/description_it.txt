Prendi un GitHub PR aperto e rendilo pronto per l'unione sul tuo computer: un albero di lavoro git, una sincronizzazione con il ramo base, il progetto configurato e in esecuzione e un pacchetto di revisione di tutto ciò di cui hai bisogno per giudicarlo, quindi uniscilo con un commit di unione una volta che lo dici. Da utilizzare quando ti siedi per rivedere i PR aperti da un agente durante la notte, dì "tira giù il PR n. 34 così posso testarlo", "rivedi i PR pronti localmente", "controlla questo PR per il QA", "prepara questo PR per l'unione", "unisci PR n. 34" o esegui "/mergekit".
