5가지 모드로 GitHub 이슈 라이프사이클을 소유하세요. plan-<slug>-YYYY-MM-DD.md 또는 설명(병렬 git-worktree 작업에 대해 독립적으로 유지되고 'blocked'라는 전제조건과 함께 유지됨)에서 이슈를 생성하고, 자체 작업 트리에서 '준비' 이슈를 시작하고, 해당 PR이 병합된 후 이슈를 종료하고(이슈 닫기, 종속 항목 차단 해제, 작업 트리 해체) 병합 후 PR←issue 링크를 동기화하고 추적기를 분류합니다. 사용자가 "이 계획에서 문제 만들기", "문제 제출", "문제 #42 시작", "작업 #42 시작", "#42 닫기", "#42 닫기", "PR 병합된 이제 #42 마무리", "내 문제 동기화", "이 PR에서 수정된 문제 닫기", "백로그 분류", "issuekit"이라고 말하거나 gh CLI를 통해 문제를 열거나 시작하거나 착륙하거나 조정하거나 검토하기를 원할 때 사용합니다.
