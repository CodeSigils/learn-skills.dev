Untersuchen Sie eine vorhandene Codebasis auf die strukturellen Änderungen, die vorgenommen werden sollten – flache Schnittstellen, Adapterwucherung, schlechte Lokalität, ungetestete Kopplung – ordnen Sie die Kandidaten ein, krönen Sie einen und verfassen Sie ihn als überprüfbaren Vorschlag. Wird verwendet, wenn der Benutzer sagt: „Wo soll ich umgestalten“, „Was stimmt mit der Struktur dieser Codebasis nicht“, „Finden Sie Möglichkeiten zur Umgestaltung“, „Dieser Code ist schwer zu ändern“, „Unsere Architektur verbessern“, „Überprüfen Sie die Modulgrenzen“ oder „/refactorkit“. It proposes and never edits code.
