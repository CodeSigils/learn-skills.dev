Redacte y abra una solicitud de extracción de GitHub desde su rama: título, resumen y plan de prueba escrito a partir de las confirmaciones y diferencias reales, luego creado con la CLI de gh, incorporando artefactos de prueba de verificarkit en línea cuando hay un paquete presente. Úselo cuando el usuario solicite abrir un PR, diga "crear una solicitud de extracción", "elevar un PR", "enviar esto para revisión" o "gh pr create", incluso si no detallan el título o el cuerpo.
