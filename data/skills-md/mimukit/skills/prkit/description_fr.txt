Rédigez et ouvrez une demande d'extraction GitHub à partir de votre branche : titre, résumé et plan de test écrits à partir des validations et des différences réelles, puis créés avec la CLI gh, intégrant les artefacts de preuve de verifykit en ligne lorsqu'un bundle est présent. À utiliser lorsque l'utilisateur demande à ouvrir un PR, dit "créer une pull request", "soumettre un PR", "soumettre ceci pour examen" ou "gh pr create" - même s'il n'épele pas le titre ou le corps.
