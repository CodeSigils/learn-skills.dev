Crea e apri una richiesta pull GitHub dal tuo ramo: titolo, riepilogo e piano di test scritti dai commit e dal diff effettivi, quindi creati con la CLI gh, incorporando artefatti di prova verifykit in linea quando è presente un bundle. Da utilizzare quando l'utente chiede di aprire una PR, dice "crea una richiesta pull", "solleva una PR", "invia questo per la revisione" o "gh pr create" - anche se non specifica il titolo o il corpo.
