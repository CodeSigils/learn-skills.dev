Leiten Sie das Designsystem eines Projekts von der bereits ausgelieferten Benutzeroberfläche ab und behalten Sie es bei, während sich der Code bewegt – eine spezifikationskonforme DESIGN.md im Repo-Stammverzeichnis, validiert durch den offiziellen Linter. Wird verwendet, wenn der Benutzer sagt: „schreibe eine DESIGN.md“, „dokumentiere unser Designsystem“, „extrahiere unsere Design-Tokens“, „unser Design-System ist veraltet“, „prüfe unsere Design-Tokens“, „Welche Farben werden in diesem Projekt tatsächlich verwendet“ oder „/designkit“. Kein UI-Generator, keine Palettenbibliothek.
