Derive el sistema de diseño de un proyecto a partir de la interfaz de usuario que ya incluye y manténgalo fiel a medida que se mueve el código: un DESIGN.md compatible con las especificaciones en la raíz del repositorio, validado por el linter oficial. Úselo cuando el usuario diga "escribir un DESIGN.md", "documentar nuestro sistema de diseño", "extraer nuestros tokens de diseño", "nuestro sistema de diseño está desactualizado", "auditar nuestros tokens de diseño", "qué colores usa realmente este proyecto" o "/designkit". No es un generador de UI, ni una biblioteca de paletas.
