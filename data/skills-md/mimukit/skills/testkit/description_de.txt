Rüsten Sie eine automatisierte Testsuite auf einer funktionierenden Codebasis nach, die keine hat: Ordnen Sie die ungetestete Oberfläche, krönen Sie einen Slice, stellen Sie einen Läufer auf und schreiben Sie Tests, bei denen jeder darauf achtete, dass sie scheiterten, bevor sie beibehalten wurden. Wird verwendet, wenn der Benutzer sagt: „Tests dafür schreiben“, „Dieses Projekt hat keine Tests“, „Testabdeckung hinzufügen“, „Tests auf diesem Repo nachrüsten“, „Tests hier einrichten“, „Was soll ich zuerst testen“, „Unsere Testabdeckung ist schrecklich“ oder „/testkit“. Es behebt niemals die gefundenen Fehler und strukturiert den Code niemals um, um ihn testbar zu machen.
