Modernisez une suite de tests automatisés sur une base de code fonctionnelle qui n'en a pas : classez la surface non testée, couronnez une tranche, mettez un coureur debout et écrivez des tests dont chacun a été observé comme échoué avant d'être conservé. À utiliser lorsque l'utilisateur dit « écrire des tests pour cela », « ce projet n'a pas de tests », « ajouter une couverture de test », « mettre à niveau les tests sur ce dépôt », « configurer les tests ici », « que dois-je tester en premier », « notre couverture de test est terrible » ou « /testkit ». Il ne corrige jamais les bogues détectés et ne restructure jamais le code pour le rendre testable.
