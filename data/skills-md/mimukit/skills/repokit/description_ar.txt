قم بإعداد البيانات التعريفية لـ GitHub repo من خلال gh CLI - وهو عبارة عن سطر واحد مستنتج حول الوصف + موضوعات من محتويات الريبو الخاصة، ودورة حياة مجموعة المشكلات وتسميات الأولوية. يُستخدم عندما يقول المستخدم "repokit"، أو "تعيين وصف الريبو"، أو "إضافة موضوعات/علامات"، أو "كتابة معلومات حول هذا الريبو"، أو "توفير تسميات سير العمل"، أو "إعداد تسميات الريبو"، أو "إضافة تسميات الأولوية"، أو "تكوين البيانات التعريفية لهذا الريبو" - أي شيء يتعلق بلوحة حول الريبو أو مفردات التسمية الخاصة به.
