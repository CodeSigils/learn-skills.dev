Configura i metadati di un repository GitHub tramite la CLI gh: una descrizione dell'informazione di una riga dedotta + argomenti dai contenuti del repository, il ciclo di vita del issuekit e le etichette di priorità. Da utilizzare quando l'utente dice "repokit", "imposta la descrizione del repository", "aggiungi argomenti/tag", "scrivi una descrizione delle informazioni per questo repository", "fornisci le etichette del flusso di lavoro", "imposta le etichette di questo repository", "aggiungi etichette di priorità" o "configura i metadati di questo repository" - qualsiasi cosa riguardante il pannello Informazioni di un repository o il suo vocabolario di etichette.
