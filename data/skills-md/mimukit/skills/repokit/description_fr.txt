Configurez les métadonnées d'un dépôt GitHub via la CLI gh - une description d'une ligne déduite + des sujets à partir du propre contenu du dépôt, ainsi que le cycle de vie et les étiquettes de priorité du issuekit. À utiliser lorsque l'utilisateur dit « repokit », « définir la description du dépôt », « ajouter des sujets/balises », « écrire un texte de présentation à propos de ce dépôt », « fournir les étiquettes de flux de travail », « configurer les étiquettes de ce dépôt », « ajouter des étiquettes de priorité » ou « configurer les métadonnées de ce dépôt » — tout ce qui concerne le panneau À propos d'un dépôt ou son vocabulaire d'étiquettes.
