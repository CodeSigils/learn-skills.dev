Mantenga el modelo de dominio de un proyecto como un subproducto consentido del trabajo de diseño: un glosario de CONTEXT.md del lenguaje omnipresente y registros docs/adr/decisiones. Úselo cuando es necesario precisar un término de dominio o se usa de manera inconsistente, cuando se resuelve una decisión de compensación difícil de revertir, cuando el usuario dice "registrar esta decisión", "escribir un ADR", "actualizar el glosario/lenguaje ubicuo", "agregar este término" o cuando otra habilidad necesita mantener actualizado el modelo de dominio: escribe el modelo, no lo interroga.
