Nommez un projet selon une convention de dénomination que vous utilisez déjà, puis prouvez que le nom est gratuit sur le domaine, npm et GitHub avant de vous y engager. À utiliser lorsque l'utilisateur dit « nommer ce projet », « comment dois-je appeler cela », « donnez-moi des idées de nom de projet », « trouvez un nom pour X », « est-ce que <nom> est pris », « vérifiez si ce nom est disponible » ou « /namekit ».
