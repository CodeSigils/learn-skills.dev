Benennen Sie ein Projekt nach einer Namenskonvention, die Sie bereits verwenden, und stellen Sie dann sicher, dass der Name in der Domäne, auf npm und auf GitHub frei ist, bevor Sie sich darauf festlegen. Wird verwendet, wenn der Benutzer sagt: „Nennen Sie dieses Projekt“, „Wie soll ich das nennen“, „Geben Sie mir Ideen für einen Projektnamen“, „Überlegen Sie sich einen Namen für X“, „ist <Name> vergeben“, „Überprüfen Sie, ob dieser Name verfügbar ist“ oder „/namekit“.
