Créez un code jetable qui répond à une question – un modèle d'état interactif que vous pouvez piloter, un script qui mesure une chose ou des simulations d'interface utilisateur concurrentes parmi lesquelles choisir – puis intégrez la réponse dans la décision et supprimez le code. À utiliser lorsque l'utilisateur dit « prototype ceci », « augmenter ceci », « explorer X jetable », « ce modèle d'état tient-il le coup », « cette conception survivra-t-elle <cas difficile> », « cette bibliothèque est-elle assez rapide », « ces deux-là sont-ils réellement interopérables », « montre-moi quelques options pour cet écran », « maquette de trois versions » ou « /prototypekit ». Pas un générateur de démo et jamais de code de production.
