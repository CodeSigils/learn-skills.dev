Implementar un plan, especificación o problema en el código de trabajo (sin compromiso, ese es el trabajo del kit de compromiso) seleccionando el modo directo versus el modo TDD por precedencia (mensaje → CLAUDE.md → hábito de repositorio → preguntar), luego ejecuta la prueba del repositorio + puerta de compilación/verificación de tipo antes de declarar terminado. Úselo cuando el usuario diga "implementar este plan", "compilar este problema", "escribir el código para el plan-<slug>-AAAA-MM-DD.md", "implementar #42", "hacer este TDD" o entregar una especificación reforzada para convertirla en código, incluso si no nombra un modo.
