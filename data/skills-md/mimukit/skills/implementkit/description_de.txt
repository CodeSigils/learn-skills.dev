Implementieren Sie einen Plan, eine Spezifikation oder ein Problem in Arbeitscode – kein Commit, das ist die Aufgabe von Commitkit. Wählen Sie den Straight-Through- oder TDD-Modus nach Priorität aus (Eingabeaufforderung → CLAUDE.md → Repo-Gewohnheit → Fragen) und führen Sie dann das Test- + Build-/Typecheck-Gate des Repos aus, bevor Sie es für erledigt erklären. Wird verwendet, wenn der Benutzer sagt „diesen Plan implementieren“, „dieses Problem erstellen“, „den Code für plan-<slug>-YYYY-MM-DD.md schreiben“, „#42 implementieren“, „dieses TDD ausführen“ oder eine gehärtete Spezifikation zur Umwandlung in Code übergibt – auch wenn er keinen Modus benennt.
