Implémentez un plan, une spécification ou un problème dans le code de travail - pas de validation, c'est le travail de commitkit - en choisissant le mode direct vs TDD par priorité (invite → CLAUDE.md → habitude de repo → demander), puis en exécutant le test du dépôt + la porte build/typecheck avant de déclarer terminé. À utiliser lorsque l'utilisateur dit "implémenter ce plan", "créer ce problème", "écrire le code pour plan-<slug>-YYYY-MM-DD.md", "implémenter #42", "faire ceci TDD", ou remettre une spécification renforcée à transformer en code - même s'il ne nomme pas de mode.
