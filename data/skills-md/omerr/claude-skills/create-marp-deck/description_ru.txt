Создает безупречные слайды Marp с помощью рабочего процесса, основанного на интервью. Используйте, когда пользователь хочет создать презентацию, слайды или презентацию. Сначала опрашивает пользователя (цель, аудитория, ключевые моменты, данные, ограничения), затем генерирует структурированную разметку Marp Markdown с градиентными разделителями разделов, навигационной цепочкой, согласованным форматированием и автоматическим экспортом HTML/PPTX.
