Produit une interface utilisateur distinctive de qualité production pour les pages, les composants, les interfaces visuelles, la typographie et la finition basée sur des captures d'écran. À utiliser lorsque les utilisateurs demandent dans n'importe quelle langue une interface utilisateur, une page, un composant, une interface, une typographie, une finition visuelle basée sur une capture d'écran ou des plaintes selon lesquelles un écran semble flou, laid, incohérent ou visuellement incorrect. Pas pour la logique backend ou les pipelines de données.
