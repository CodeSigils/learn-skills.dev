Extrayez le langage de conception complet de n’importe quelle URL de site Web. Produit 8 fichiers de sortie, dont un démarque optimisé pour l'IA, un aperçu HTML visuel, la configuration Tailwind, le thème React, le thème shadcn/ui, les variables Figma, les jetons de conception W3C et les variables CSS. Exécute également la notation d’accessibilité WCAG. À utiliser lorsque l'utilisateur dit « extraire le design », « obtenir le système de conception », « langage de conception », « jetons de conception », « quelles couleurs/polices ce site utilise-t-il » ou « /extract-design ».
