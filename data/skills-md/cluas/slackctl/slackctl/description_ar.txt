Slack Automation CLI لوكلاء الذكاء الاصطناعي. استخدم عندما:
- قراءة رسالة أو موضوع Slack (مع إعطاء عنوان URL أو قناة + ts)
- تصفح رسائل القناة الأخيرة / سجل القناة
- البحث في رسائل أو ملفات Slack
- إرسال رسالة أو تحريرها أو حذفها؛ إضافة/إزالة ردود الفعل
- قائمة القنوات / المحادثات. إنشاء القنوات ودعوة المستخدمين
- جلب قماش Slack كتخفيض
- البحث عن مستخدمي سلاك
- وضع علامة على القنوات/الرسائل المباشرة كمقروءة
- فتح قنوات DM أو جماعية
