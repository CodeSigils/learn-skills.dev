Générez une documentation détaillée du journal des modifications à partir de l'analyse des commits Git, sortie sous forme de deux fichiers markdown : changelog.md (indonésien) et changelog.en.md (anglais). Utilisez-le chaque fois que l'utilisateur demande à documenter un commit, à générer une entrée du journal des modifications, à résumer les modifications de Git ou à écrire des notes de version à partir d'un ID/diff de commit — même s'il ne dit pas explicitement « changelog » (par exemple « jelaskan commit ini », « buatin dokumentasi perubahan », « catat history commit abc123 »).
