Genere documentación detallada del registro de cambios a partir del análisis de confirmación de Git y genere dos archivos de rebajas: changelog.md (indonesio) y changelog.en.md (inglés). Utilice esto siempre que el usuario solicite documentar una confirmación, generar una entrada de registro de cambios, resumir los cambios de Git o escribir notas de la versión a partir de un ID/diff de confirmación, incluso si no dicen "registro de cambios" explícitamente (por ejemplo, "jelaskan commit ini", "buatin dokumentasi perubahan", "catat History commit abc123").
