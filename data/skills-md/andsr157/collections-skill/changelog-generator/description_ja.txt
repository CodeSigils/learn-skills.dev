Git コミット分析から詳細な変更ログ ドキュメントを生成し、2 つのマークダウン ファイル (changelog.md (インドネシア語) と changelog.en.md (英語)) として出力します。ユーザーがコミットの文書化、変更ログ エントリの生成、Git の変更の要約、またはコミット ID/diff からのリリース ノートの作成を要求するときは常にこれを使用します。たとえ「変更ログ」と明示的に言わなくても (例: 「jelaskan commit ini」、「buatin dokumentasi perubahan」、「catat History commit abc123」)。
