Genera documentazione dettagliata del log delle modifiche dall'analisi del commit Git, output come due file markdown: changelog.md (indonesiano) e changelog.en.md (inglese). Usalo ogni volta che l'utente chiede di documentare un commit, generare una voce nel log delle modifiche, riassumere le modifiche Git o scrivere note di rilascio da un ID/diff di commit — anche se non dice esplicitamente "changelog" (ad esempio "jelaskan commit ini", "buatin dokumentasi perubahan", "catat History commit abc123").
