git diff の分析、リスク領域のスコアリング、テストギャップの検出、所有権に関する質問の生成、ローカル所有権レポートの作成により、AI 支援によるソースコード変更に対する人間の所有権を検証します。ソース コードの変更、プル リクエスト、エージェントが生成したパッチ、セキュリティに配慮した差分、または開発者が Code Ready を呼び出す前に動作、爆発範囲、障害モード、テスト、ロールバックを理解していることを証明する必要があるワークフローを準備、レビュー、または完成させるときに使用します。ドキュメントやその他の非ソースのみの変更は、多肢選択式の質問やゲート アーティファクトのないレポートを受け取ります。
