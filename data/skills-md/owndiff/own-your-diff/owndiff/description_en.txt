Verify human ownership of AI-assisted source-code changes by analyzing git diffs, scoring risky areas, detecting test gaps, generating ownership questions, and producing local ownership reports. Use when preparing, reviewing, or finalizing source-code changes, pull requests, agent-generated patches, security-sensitive diffs, or any workflow where a developer should prove they understand behavior, blast radius, failure modes, tests, and rollback before calling code ready. Documentation and other non-source-only changes receive a report without multiple choice questions or gate artifacts.
