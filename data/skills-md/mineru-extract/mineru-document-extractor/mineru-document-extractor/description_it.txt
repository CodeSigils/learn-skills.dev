CLI di estrazione documenti MinerU che converte PDF, immagini e pagine Web in Markdown, HTML, LaTeX o DOCX tramite l'API MinerU. Supporta l'estrazione flash senza token per un avvio rapido, l'estrazione completa con riconoscimento di tabelle/formule, scansione web, elaborazione batch e flussi di lavoro convogliati.
