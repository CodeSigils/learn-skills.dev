Интерфейс командной строки для извлечения документов MinerU, который преобразует PDF-файлы, изображения и веб-страницы в Markdown, HTML, LaTeX или DOCX через API MinerU. Поддерживает флэш-извлечение без токенов для быстрого запуска, полное извлечение с распознаванием таблиц и формул, сканирование веб-страниц, пакетную обработку и конвейерные рабочие процессы.
