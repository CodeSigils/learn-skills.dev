CLI de extracción de documentos de MinerU que convierte archivos PDF, imágenes y páginas web a Markdown, HTML, LaTeX o DOCX a través de la API de MinerU. Admite extracción flash sin token para un inicio rápido, extracción completa con reconocimiento de tablas/fórmulas, rastreo web, procesamiento por lotes y flujos de trabajo canalizados.
