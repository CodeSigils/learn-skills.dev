Comment créer et publier des compétences d'agent pour l'écosystème skills.sh / `npx skills` — le format SKILL.md, pourquoi la description du frontmatter est le déclencheur, la disposition du dépôt multi-compétences, la CLI `skills` (init/ajouter/lister/trouver/mettre à jour/supprimer avec des indicateurs), la publication sur GitHub avec des métadonnées SEO et les dépôts publics ou privés (il clone git, donc privé fonctionne avec auth). À utiliser lorsqu'on vous demande de « créer/écrire/créer une compétence », « publier une compétence », « configurer un dépôt de compétences », « rendre une compétence installable/découverte », « utiliser des compétences npx » ou « puis-je utiliser un dépôt de compétences privé ».
