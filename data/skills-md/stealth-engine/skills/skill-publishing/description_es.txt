Cómo crear y publicar habilidades de agente para el ecosistema skills.sh / `npx skills`: el formato SKILL.md, por qué la descripción del frontmatter es el desencadenante, diseño de repositorio de habilidades múltiples, la CLI de `skills` (init/add/list/find/update/remove con banderas), publicación en GitHub con metadatos de SEO y repositorios públicos versus privados (se clona con git, por lo que el privado funciona con autenticación). Úselo cuando se le solicite "crear/escribir/crear una habilidad", "publicar una habilidad", "configurar un repositorio de habilidades", "hacer que una habilidad sea instalable/descubrible", "usar habilidades npx" o "puedo usar un repositorio de habilidades privado".
