Skills.sh / `npx skill` エコシステムのエージェント スキルを作成および公開する方法 — SKILL.md 形式、フロントマターの説明がトリガーとなる理由、マルチスキル リポジトリのレイアウト、`skills` CLI (フラグ付きの init/add/list/find/update/remove)、SEO メタデータを使用した GitHub への公開、パブリック リポジトリとプライベート リポジトリ (git-clone なので、プライベート リポジトリは認証で機能します)。 「スキルの作成/書き込み/作成」、「スキルの公開」、「スキル リポジトリの設定」、「スキルをインストール可能/検出可能にする」、「npx スキルを使用する」、または「プライベート スキル リポジトリを使用できますか」を求められた場合に使用します。
