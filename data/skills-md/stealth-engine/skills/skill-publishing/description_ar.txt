كيفية تأليف ونشر مهارات الوكيل للنظام البيئي Skills.sh / `npx Skills` - تنسيق SKILL.md، لماذا يكون وصف المادة الأمامية هو المشغل، وتخطيط الريبو متعدد المهارات، و`skills' CLI (init/add/list/find/update/remove with flags)، والنشر على GitHub باستخدام البيانات التعريفية لتحسين محركات البحث، والريبو العام مقابل الخاص (إنه git-clones، لذلك يعمل القطاع الخاص مع المصادقة). يُستخدم عندما يُطلب منك "إنشاء/كتابة/تأليف مهارة"، أو "نشر مهارة"، أو "إعداد مستودع مهارات"، أو "جعل مهارة قابلة للتثبيت/الاكتشاف"، أو "استخدام مهارات npx"، أو "هل يمكنني استخدام مستودع مهارات خاص".
