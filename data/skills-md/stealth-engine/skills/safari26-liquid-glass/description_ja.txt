iOS 26 / iPadOS 26 Safari の「液体ガラス」の半透明のステータス バーとアドレス バーが Web コンテンツ、その背後にあるビューポート/キーボードの事実とどのように相互作用するか、デザインがクリエイティブになるときに注意すべき点 (没入型/エッジツーエッジ レイアウト、カスタム ドロワー/モーダル、ジェスチャー パン、テーマに適した背景、キャンバス) について説明します。 iPhone/iPad の Web ページに黒/灰色のバー、バーの端でコンテンツが「切り取られた」、トリミングされた影、レイアウトを壊すドロワー/モーダル、スクロールしない内部スクロール、ソフト キーボードを閉じた後のページのジャンプ、または iOS でレンダリングされないキャンバスのぼかしが表示される場合、またはフルスクリーン/イマーシブ iOS Web UI を構築する前に使用します。
