Analyse une base de code MAF 1.3.0 à la recherche d'anti-modèles connus APRÈS la migration terminée. Préférez l'outil MCP MafScanAntiPatterns pour les scans ponctuels ; cette compétence permet de comprendre la taxonomie des règles ou de contribuer à de nouvelles règles anti-modèles. Détecte l'utilisation d'informations d'identification non sécurisées (DefaultAzureCredential, clés codées en dur), les valeurs par défaut non sécurisées (EnableSensitiveData = true en non-dev), l'état dangereux du thread dans AIContextProvider, l'observabilité manquante (UseOpenTelemetry non câblée) et l'identité manquante (ManagedIdentityCredential préféré à l'authentification basée sur le secret). Homologue des outils de migration : il s’agit d’un examen permanent des meilleures pratiques.
