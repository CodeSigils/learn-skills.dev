Сканирует кодовую базу MAF 1.3.0 на наличие известных антишаблонов ПОСЛЕ завершения миграции. Для однократного сканирования отдайте предпочтение инструменту MCP MafScanAntiPatterns; этот навык нужен для понимания таксономии правил или создания новых правил, не противоречащих шаблонам. Обнаруживает небезопасное использование учетных данных (DefaultAzureCredential, жестко запрограммированные ключи), небезопасные значения по умолчанию (EnableSensitiveData=true в версии, отличной от разработки), небезопасное для потоков состояние в AIContextProvider, отсутствие наблюдаемости (UseOpenTelemetry не подключено) и отсутствие удостоверения (ManagedIdentityCredential предпочтительнее проверки подлинности на основе секрета). Аналог инструментов миграции: это обзор лучших практик в устойчивом состоянии.
