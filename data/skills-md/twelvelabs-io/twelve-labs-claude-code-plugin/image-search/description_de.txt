Durchsuchen Sie Videos mithilfe eines Bildes in Kombination mit Text, um verfeinerte Ergebnisse zu erzielen. Verwenden Sie diese Option, wenn der Benutzer mit einem Referenzbild suchen möchte, sagt „Videos finden, die zu diesem Bild passen“, „Mit diesem Bild suchen“ oder visuelle Referenz mit Textbeschreibung kombinieren möchte.
