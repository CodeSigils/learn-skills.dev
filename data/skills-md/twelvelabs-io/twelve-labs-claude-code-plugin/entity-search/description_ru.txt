Настраивайте и ищите конкретных людей или объекты в видео, используя поиск по объектам. Используйте, когда пользователь хочет найти конкретного человека, отследить его по видео или настроить распознавание лиц/объектов. Запускается по таким фразам, как «найти этого человека», «настроить поиск по объекту», «отследить этого человека в моих видео», «кто в этом видео».
