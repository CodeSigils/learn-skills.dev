قم ببناء وتوسيع ومراجعة وتوثيق والتحقق من صحة وإصدار تطبيقات Ohtools والحزم والمكونات الإضافية والمحولات والمخططات والسقالات والأمثلة وخوادم MCP وأدوات MCP وأدوات CLI وأغلفة الأوامر وأغلفة الأدوات والأدوات التي تواجه الوكيل. استخدم هذه المهارة لمشاريع @bosun-sh/ohtools، وohtools إنشاء/بدء سير العمل، وخادم MCP العادي أو طلبات أداة MCP، وأداة CLI العادية أو طلبات غلاف الأوامر، وأنماط إطار عمل أداة الوكيل المحلي، والتعرض المشترك لـ CLI/MCP، وتصميم التسلسل الهرمي للأداة، وحدود مخطط JSON، وأوقات تشغيل التأثير، والمستندات التي تم إنشاؤها، واختبارات دخان الحزمة، وبوابات الإصدار.
