kachaka を ROS 2 から動かす (teleop, cmd_vel, goal_pose, rviz2) と、自前コンテナから 接続する際の実行方法。Utiliser lorsque l'utilisateur souhaite conduire un kachaka via Teleop, envoyez `/kachaka/manual_control/cmd_vel`, publiez sur `/kachaka/goal_pose` pour une navigation autonome, visualisez dans rviz2 ou séparez plusieurs kachakas via `ROS_DOMAIN_ID`. Exemples : teleop, cmd_vel, goal_pose, rviz2, ROS_LOCALHOST_ONLY, ROS_DOMAIN_ID, etc.
