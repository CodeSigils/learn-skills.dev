قم بتحليل التذاكر أو المشكلات المفتوحة للمستودع، والتبعيات، والتسميات، والوثائق، وحالة شجرة العمل، ثم قم بإرسال تذاكر التنفيذ غير المحظورة حاليًا فقط إلى الوكلاء الفرعيين. يُستخدم عندما يطلب المستخدم من Codex أو Claude Code فرز أعمال التذاكر الجاهزة لوكلاء AFK، أو توزيع مهام التنفيذ، أو إرسال وكلاء فرعيين، أو بدء فروع/أشجار عمل مستقلة للتذاكر، أو تشغيل الدفعة الآمنة التالية من أعمال التنفيذ من جهاز التعقب.
