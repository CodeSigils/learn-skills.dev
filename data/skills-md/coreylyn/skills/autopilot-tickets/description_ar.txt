استنزاف تذاكر التنفيذ الجاهزة للوكيل أو المشكلات باستمرار عن طريق إرسال دفعات آمنة بشكل متكرر إلى الوكلاء الفرعيين، وانتظار مسودة ممثلين رئيسيين أو ممثلين MR، والتحقق من بوابات الدمج، ودمج ممثلين رئيسيين أو ممثلين آمنين فقط أنشأهم الوكيل، وتحديث حالة التذكرة، والاستمرار حتى لا تبقى أي تذاكر جاهزة للوكيل. يُستخدم عندما يطلب المستخدم صراحةً من Codex أو Claude Code تشغيل حلقة معالجة التذاكر التلقائية، أو الدمج التلقائي للوكيل المكتمل PRs/MRs، أو الاستمرار في إرسال عمل التذاكر الجاهز حتى تصبح قائمة الانتظار فارغة.
