Abilità di script per riprese di brevi video di prodotti e-commerce della serie lyt. Viene utilizzato quando l'utente dispone già di un prodotto specifico, di immagini di prodotto, di un collegamento al prodotto, di informazioni sul prodotto, di punti vendita confermati o di una copia di prodotto esistente e desidera generare un breve script video, uno storyboard, uno script UGC, uno script dimostrativo/confronto/recensione/scena, uno script di materiale pubblicitario o uno script di esempio di influencer che può essere filmato direttamente per TikTok Shop o e-commerce transfrontaliero; può anche organizzare la copia del prodotto esistente in uno storyboard sparabile o generare la lingua del mercato di destinazione con una traduzione in cinese. Non è inteso per selezionare prodotti da zero, giudicare se un prodotto può essere realizzato, analizzare dati da video già pubblicati, generare/modificare direttamente video o gestire contenuti IP personali non relativi al prodotto.  
Comandi di attivazione: /lyt-product-video-script, /product‑video‑script, /shooting‑script, /product‑short‑video‑script, “Come girare questo prodotto”, “Scrivi uno script basato su questo prodotto”.
