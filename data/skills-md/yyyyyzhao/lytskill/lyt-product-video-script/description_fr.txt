La compétence de script de tournage de courtes vidéos de produits de commerce électronique de la série lyt. Il est utilisé lorsque l'utilisateur dispose déjà d'un produit spécifique, d'images de produit, d'un lien produit, d'informations sur le produit, d'arguments de vente confirmés ou d'une copie de produit existante, et souhaite générer un court script vidéo, un storyboard, un script UGC, un script de démonstration/comparaison/évaluation/scène, un script de matériel publicitaire ou un script d'échantillon d'influenceur qui peut être filmé directement pour TikTok Shop ou le commerce électronique transfrontalier ; il peut également organiser la copie d'un produit existant dans un storyboard exploitable, ou générer une langue de marché cible avec une rétro-traduction en chinois. Il n'est pas destiné à sélectionner des produits à partir de zéro, à juger si un produit peut être fabriqué, à analyser les données de vidéos déjà publiées, à générer/éditer directement des vidéos ou à gérer du contenu IP personnel non lié au produit.  
Commandes de déclenchement : /lyt-product-video-script, /product‑video-script, /shooting‑script, /product‑short‑video-script, « Comment filmer ce produit », « Écrire un script basé sur ce produit ».
