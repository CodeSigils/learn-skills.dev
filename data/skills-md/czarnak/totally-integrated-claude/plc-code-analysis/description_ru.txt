Автономный навык для многогранного анализа безопасности и качества кода ПЛК. Срабатывает по запросам: «review», «audit», «analyze», «security check», «vulnerability scan», «code review», «check this code», «is this safe», «find issues», когда они используются в сочетании с PLC, SCL, ST, LAD, FBD, Structured Text или контекстом блока. Также срабатывает, когда пользователь вставляет код ПЛК и просит обратную связь, либо загружает экспортированные файлы SimaticML XML. Этот навык независим от tia‑openness‑roadmap — он не выполняет инженерную автоматизацию. Он анализирует код, который уже экспортирован, вставлен или доступен через сервер MCP TIA Portal.

Пожалуйста, всегда отвечайте на языке пользователя.
