Compétence autonome pour l’analyse multi‑perspective de la sécurité et de la qualité du code PLC. Se déclenche sur : « review », « audit », « analyze », « security check », « vulnerability scan », « code review », « check this code », « is this safe », « find issues » lorsqu’ils sont combinés avec PLC, SCL, ST, LAD, FBD, Structured Text ou le contexte de bloc. Se déclenche également lorsque l’utilisateur colle du code PLC et demande un retour, ou téléverse des fichiers XML SimaticML exportés. Cette compétence est indépendante du plan tia‑openness‑roadmap — elle ne réalise pas d’automatisation d’ingénierie. Elle analyse le code déjà exporté, collé ou accessible via le serveur MCP du TIA Portal. Veuillez toujours répondre dans la langue de l’utilisateur.
