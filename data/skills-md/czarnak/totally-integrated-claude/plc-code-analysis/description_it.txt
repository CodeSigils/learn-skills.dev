Abilità autonoma per l'analisi della sicurezza e della qualità del codice PLC da più prospettive. Si attiva con: “review”, “audit”, “analyze”, “security check”, “vulnerability scan”, “code review”, “check this code”, “is this safe”, “find issues” quando è combinato con PLC, SCL, ST, LAD, FBD, Structured Text o contesto di blocco. Si attiva anche quando l'utente incolla codice PLC e chiede un feedback, o carica file XML SimaticML esportati. Questa abilità è indipendente dalla roadmap tia‑openness — non esegue automazione ingegneristica. Analizza il codice già esportato, incollato o accessibile tramite il server MCP del TIA Portal.

Rispondi sempre nella lingua dell'utente.
