PLCコードの多面的なセキュリティと品質分析のためのスタンドアロンスキル。  
「review」「audit」「analyze」「security check」「vulnerability scan」「code review」「check this code」「is this safe」「find issues」などのキーワードが、PLC、SCL、ST、LAD、FBD、Structured Text、またはブロックコンテキストと組み合わされたときにトリガーします。  
また、ユーザーがPLCコードを貼り付けてフィードバックを求めた場合や、エクスポートされたSimaticML XMLファイルをアップロードした場合にもトリガーします。  
このスキルはtia‑openness‑roadmapとは独立しており、エンジニアリング自動化は行いません。  
エクスポート済み、貼り付けられた、あるいはTIA Portal MCPサーバー経由でアクセス可能なコードを分析します。  
常にユーザーの言語で応答してください。
