مهارة مستقلة لتحليل أمان وجودة كود PLC من عدة منظور. يتم تفعيلها عند: "مراجعة"، "تدقيق"، "تحليل"، "فحص أمان"، "مسح ثغرات"، "مراجعة الكود"، "تحقق من هذا الكود"، "هل هذا آمن"، "اكتشاف المشكلات" عندما تكون مرتبطة بـ PLC، SCL، ST، LAD، FBD، النص المُنظم، أو سياق الكتلة. كما يتم تفعيلها عندما يلصق المستخدم كود PLC ويطلب ملاحظات، أو يحمّل ملفات SimaticML XML المُصدرة. هذه المهارة مستقلة عن خارطة طريق tia‑openness — فهي لا تقوم بأتمتة الهندسة. إنها تحلل الكود الذي تم تصديره مسبقًا، أو لصقه، أو المتاح عبر خادم MCP لمنصة TIA Portal.
