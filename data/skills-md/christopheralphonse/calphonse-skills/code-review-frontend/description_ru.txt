Мультиагентный оркестратор PR-обзоров. Сначала обнаруживает стандарты качества кодовой базы (lint, format, build,
CI), затем параллельно создает специализированные агенты для выявления реальных проблем в git diff.
Агенты сообщают только о результатах — никаких исправлений. Каждый вывод ПОДТВЕРЖДЕН или помечен как [Предположение].
Используйте, когда: «просмотрите этот PR», «проверка кода», «проверьте мои различия», «/review».
