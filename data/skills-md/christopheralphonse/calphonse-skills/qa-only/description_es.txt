Pruebas de control de calidad solo para informes. Prueba sistemáticamente una aplicación web y produce una
informe estructurado con puntuación de salud, capturas de pantalla y pasos de reproducción, pero nunca
arregla cualquier cosa. Úselo cuando se le solicite "solo informar errores", "solo informar de preguntas y respuestas" o
"probar pero no arreglar". Para el ciclo completo de prueba-reparación-verificación, utilice /qa en su lugar.
Sugiera de forma proactiva cuándo el usuario desea un informe de error sin ningún cambio en el código.
