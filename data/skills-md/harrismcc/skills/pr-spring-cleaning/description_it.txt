Triage PR aperti per un repository GitHub. Raccoglie tutte le PR aperte per un utente, riassume la suddivisione dello stato, crea un elenco di cose da fare, quindi esamina ciascuna PR una per una affinché l'utente possa decidere se mantenere la bozza, contrassegnare come pronto o chiudere. Utilizzare quando viene richiesto di ripulire i PR, triage PR o fare pulizie di primavera PR.
