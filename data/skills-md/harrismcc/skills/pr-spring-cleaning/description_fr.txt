Triez les PR ouverts pour un dépôt GitHub. Rassemble tous les PR ouverts pour un utilisateur, résume la répartition de l'état, crée une liste de tâches, puis parcourt chaque PR un par un pour que l'utilisateur décide de conserver le brouillon, de le marquer comme prêt ou de le fermer. À utiliser lorsqu'on vous demande de nettoyer les PR, de trier les PR ou de faire le ménage de printemps des PR.
