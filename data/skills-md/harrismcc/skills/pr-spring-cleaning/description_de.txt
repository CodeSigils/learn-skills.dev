Triagieren Sie offene PRs für ein GitHub-Repo. Sammelt alle offenen PRs für einen Benutzer, fasst die Statusaufschlüsselung zusammen, erstellt eine Aufgabenliste und geht dann jede PR einzeln durch, damit der Benutzer entscheiden kann, ob er den Entwurf behält, als bereit markiert oder schließt. Verwenden Sie es, wenn Sie gebeten werden, PRs zu bereinigen, PRs zu selektieren oder einen PR-Frühjahrsputz durchzuführen.
