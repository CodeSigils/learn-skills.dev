فرز العلاقات العامة المفتوحة لمستودع GitHub. يجمع كل العلاقات العامة المفتوحة للمستخدم، ويلخص تفاصيل الحالة، وينشئ قائمة المهام، ثم يستعرض كل العلاقات العامة واحدة تلو الأخرى ليقرر المستخدم الاحتفاظ بالمسودة، أو وضع علامة جاهزة، أو الإغلاق. استخدمه عندما يُطلب منك تنظيف العلاقات العامة، أو فرز العلاقات العامة، أو القيام بالتنظيف الربيعي للعلاقات العامة.
