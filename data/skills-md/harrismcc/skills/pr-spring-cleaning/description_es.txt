Clasificar relaciones públicas abiertas para un repositorio de GitHub. Reúne todos los PR abiertos para un usuario, resume el desglose del estado, crea una lista de tareas pendientes y luego recorre cada PR uno por uno para que el usuario decida mantener el borrador, marcarlo como listo o cerrar. Úselo cuando se le solicite limpiar RP, clasificar RP o realizar una limpieza de primavera de RP.
