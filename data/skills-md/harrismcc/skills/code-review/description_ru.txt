Используйте при просмотре изменений кода, PR или различий. Запускает специализированные средства проверки различий (качество кода, тесты, обработка ошибок, типы, комментарии, упрощение), которые отмечают проблемы только в измененных строках. Триггеры: «проверь мой код», «проверь код», «проверь этот PR», «проверь мои изменения».
