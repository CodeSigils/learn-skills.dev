Verwenden Sie diese Option, wenn Sie Codeänderungen, PRs oder Unterschiede überprüfen. Führt spezielle Prüfer mit Diff-Bereich aus (Codequalität, Tests, Fehlerbehandlung, Typen, Kommentare, Vereinfachung), die nur Probleme in geänderten Zeilen kennzeichnen. Löst auf „Meinen Code überprüfen“, „Codeüberprüfung“, „Diese PR überprüfen“ und „Meine Änderungen überprüfen“ aus.
