Méta‑Gateway de retour d’expérience. Collecte triple source (bilan de session / numérisation d'articles / saisie manuelle) → distillation et désensibilisation → cartographie de domaine → traitement à trois niveaux (publication / stockage local / suppression). Mots-clés déclencheurs : retour d'expérience, stockage d'expérience, soumission d'expérience, compte rendu d'expérience, consolidation des connaissances, leçons apprises.
