Realice análisis forenses de memoria utilizando Volatility3, el marco de Python para analizar volcados de RAM desde sistemas Windows, Linux y macOS. Úselo al investigar infecciones de malware, rootkits, robo de credenciales, código inyectado, artefactos de movimiento lateral o cualquier escenario que requiera análisis de procesos, redes, archivos o registros a partir de una imagen de memoria. Cubre la instalación, la adquisición de volcados de memoria, todos los complementos clave (pslist, pstree, netscan, malfind, hashdump, dumpfiles, cmdline), creación de tablas de símbolos, análisis de Linux, detección de rootkits y flujos de trabajo completos de análisis de malware.
