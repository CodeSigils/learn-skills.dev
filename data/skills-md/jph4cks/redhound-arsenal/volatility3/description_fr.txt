Effectuez des analyses de mémoire à l'aide de Volatility3, le framework Python pour analyser les vidages de RAM des systèmes Windows, Linux et macOS. À utiliser lors de l'investigation d'infections par des logiciels malveillants, de rootkits, de vols d'informations d'identification, de code injecté, d'artefacts de mouvement latéral ou de tout scénario nécessitant une analyse de processus, de réseau, de fichier ou de registre à partir d'une image mémoire. Couvre l'installation, l'acquisition de vidages de mémoire, tous les plugins clés (pslist, pstree, netscan, malfind, hashdump, dumpfiles, cmdline), la création de tables de symboles, l'analyse Linux, la détection de rootkits et les flux de travail complets d'analyse des logiciels malveillants.
