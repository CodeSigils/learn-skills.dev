Crear, configurar, documentar, auditar y verificar agentes en cualquier instancia de Tracker Hub o Banhaia Hub siguiendo las plantillas canónicas (doc madre + bootstrap 7-fases + driver Matrix + security defaults + verificación). Aplicalo también cuando te piden configurar un flujo de trabajo autónomo con LLM, conectar un bot externo (Slack/Telegram/Chatwoot/WhatsApp) a tracker-hub, diagnosticar por qué un agente sale con salida vacía o no llama tools, decidir entre langchain_ollama / cli / anthropic / openai, configurar un codificador con worktree aislado y require_approval, definir security_config / mcp_tools_allowlist / bloqueado_tools, o auditar el inventario de agentes existentes.
