Erstellen, Konfigurieren, Dokumentieren, Prüfen und Überprüfen von Agenten auf jeder Tracker Hub- oder Banhaia Hub-Instanz, die auf den kanadischen Anlagen basiert (Hauptdokument + 7-Phasen-Bootstrap + Treibermatrix + Sicherheitsstandards + Überprüfung). Verwenden Sie diesen Skill, um den Benutzer zu erstellen, zu ändern, zu prüfen oder einen Tracker-Hub-Agenten zu dokumentieren, ohne dabei „skill“, „plantilla“ oder „bootstrap“ zu erwähnen. Sie können dies auch tun, wenn Sie einen automatischen Workflow mit LLM konfigurieren, einen externen Bot (Slack/Telegram/Chatwoot/WhatsApp) mit einem Tracker-Hub verbinden, eine Diagnose durchführen, indem Sie einen Agenten mit Ausgabe ohne oder ohne Lama-Tools verwenden, sich für langchain_ollama / cli / anthropic / openai entscheiden und einen Coder mit Worktree konfigurieren „require_approval“, „security_config“ / „mcp_tools_allowlist“ / „blocked_tools“ definieren oder die Liste der vorhandenen Agenten überprüfen. Mehr als 7 Schritte – Erkennung, Arbeitsbereich, Betriebsdokumente, Hauptdokument, tracker_create_agent, Bindungen, Überprüfung.
