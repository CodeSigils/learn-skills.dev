Componer-Dashboards und Kioske und Tracker Hub verwenden agentengesteuerte Ansichten (Rutas /v/:slug con auth, /kiosk/:slug sin auth). Kombiniert native Blöcke (bevorstehend, Genehmigungen, Chat, Quick_Actions, KPI, App) in einem JSON-validierten Layout. Dies ist die Fähigkeit von SIEMPRE, mit der der Benutzer ein Dashboard, einen Kiosk, einen gemeinsamen Bildschirm (Raspberry Pi in der Küche/im Büro), eine öffentliche Seite mit Tracker-Hub-Daten, eine Ansicht für den Benutzer, eine Standardansicht pro Rolle oder eine aktuelle Blockzusammensetzung erstellen möchte, die nicht auf „Ansicht“ steht. Sie können auch verschiedene Abschnitte anzeigen (Kontaktdaten + Agenten-Chat + KPIs) oder einen automatisch aktualisierten Bildschirm anzeigen.
