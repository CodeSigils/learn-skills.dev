Панели мониторинга компонентов и киоски в Tracker Hub используются под управлением агента Vistas (руты /v/:slug с аутентификацией, /kiosk/:slug без аутентификации). Комбинируйте исходные блоки (предстоящие, утверждения, чат, быстрые действия, ключевые показатели эффективности, приложение) в валидированном макете JSON. Используйте этот навык, чтобы пользователь мог создать панель управления, киоск, панель управления (Raspberry Pi в офисе/офисине), общедоступную страницу с данными трекера-концентратора, вид для пользователя, представление по умолчанию для каждой роли или более сложную композицию блоков без цифрового «просмотра». Также приложение позволяет просматривать различные разделы (приблизительные адреса + чат с агентом + ключевые показатели эффективности), или отображать автообновляемую панель.
