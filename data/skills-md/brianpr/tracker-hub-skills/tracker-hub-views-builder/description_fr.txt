Les tableaux de bord et kiosques de composants dans Tracker Hub utilisent des vues pilotées par agent (routes /v/:slug avec auth, /kiosk/:slug sans auth). Combina bloque les éléments naturels (à venir, approbations, chat, quick_actions, kpi, application) dans une mise en page validée JSON. Utilisez cette compétence pour que l'utilisateur souhaite créer un tableau de bord, un kiosque, un écran partagé (Raspberry Pi dans la cuisine/bureau), une page publique avec les données du tracker-hub, une vue de l'utilisateur, une vue par défaut par rôle, ou toute composition de blocs même dans la "vue". Vous pourrez également l'utiliser si vous souhaitez afficher plusieurs sections (prochains événements + chat avec un agent + KPI), ou afficher un écran auto-réfractaire.
