لوحات معلومات المكونات والأكشاك في Tracker Hub تستخدم المشاهد التي يحركها الوكيل (rutas /v/:slug con auth، /kiosk/:slug sin auth). اجمع الكتل الأصلية (القادمة، الموافقات، الدردشة، الإجراءات السريعة، مؤشرات الأداء الرئيسية، التطبيق) في تخطيط JSON صالح. تُستخدم هذه المهارة دائمًا حيث يرغب المستخدم في إنشاء لوحة معلومات، أو كشك، أو شاشة مقسمة (Raspberry Pi في المطبخ/المكتب)، أو صفحة عامة تحتوي على مركز تعقب البيانات، أو مشهد للمستخدم، أو عرض افتراضي لكل دور، أو أي تكوين من الكتل بدون "عرض". يتم التطبيق أيضًا إذا كنت تستطيع عرض مجموعات مختلفة من الأقسام (المؤثرات التالية + الدردشة مع الوكلاء + مؤشرات الأداء الرئيسية)، أو عرض شاشة يتم تجديدها تلقائيًا.
