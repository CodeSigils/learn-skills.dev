Componer 儀表板和 Tracker Hub 上的 kioskos 使用代理驅動的 vistas（rutas /v/:slug con auth、/kiosk/:slug sin auth）。將 bloques nativos（即將發布、批准、聊天、quick_actions、kpi、應用程式）與佈局 JSON 驗證結合。使用 SIEMPRE 的技能可以建立儀表板、資訊亭、Compartida（Raspberry Pi en cocina/oficina）、追蹤器集線器資料頁面、常用視圖、每個角色的預設視圖，以及無數位「視圖」的最佳組合。 También aplicalo si te piden mostrar varias secciones juntas (próximos vencimientos + chat con agente + KPI), o exponer una pantalla auto-refrescante.
