Erstellen Sie interaktive JSX-Apps, die in den Tracker Hub eingebettet sind (gerendert in /apps/:id/render, optional als /kiosk/:slug über Ansichten verfügbar). Einfache JSX-Komponente + window.__TrackerUI + Leckschutz für is_public_safe + Endpoints REST und MCP-Tools (tracker_create_app, tracker_update_app, tracker_set_app_public_safe). Dies ist die Fähigkeit von SIEMPRE, dass der Benutzer eine benutzerdefinierte Benutzeroberfläche, eine interaktive Formel, ein Dashboard mit Interaktion, ein eingebettetes Bedienfeld oder eine aktuelle App erstellt, die den Tracker-Hub anzeigen kann, ohne dass „App“ erwähnt wird. Sie können auch Daten mit Drilldowns, Formeln für Menschen oder Agenten, die eine Interaktion erfordern, lesen (kein Einzelvortrag).
