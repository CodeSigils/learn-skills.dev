قم ببناء تطبيقات JSX التفاعلية التي يتم تضمينها في Tracker Hub (يتم عرضها على /apps/:id/render، ويتم عرضها اختياريًا مثل /kiosk/:slug عبر طرق العرض). المكونات المكعبة JSX الفريدة + window.__TrackerUI + أنظمة منع التسرب لـ is_public_safe + نقاط النهاية REST وأدوات MCP (tracker_create_app وtracker_update_app وtracker_set_app_public_safe). تُستخدم هذه المهارة دائمًا حيث يرغب المستخدم في إنشاء واجهة مستخدم مخصصة، أو صيغة تفاعلية، أو لوحة معلومات مع تفاعل، أو لوحة مدمجة، أو أي تطبيق يمكن أن يظهر في مركز التتبع بدون ذكر "التطبيق". يمكنك أيضًا التطبيق إذا كنت تريد عرض البيانات من خلال عمليات البحث، أو صيغ خاصة بالبشر، أو نتيجة الوكيل الذي يتطلب التفاعل (بدون محاضرة فردية).
