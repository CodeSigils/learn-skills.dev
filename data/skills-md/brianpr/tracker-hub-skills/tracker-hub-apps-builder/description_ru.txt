Создавайте интерактивные JSX-приложения, встраиваемые в Tracker Hub (рендеризация в /apps/:id/render, опционально выводится как /kiosk/:slug через представления). Кубический компонент JSX + window.__TrackerUI + защита от утечек для is_public_safe + конечные точки REST и инструменты MCP (tracker_create_app, tracker_update_app, tracker_set_app_public_safe). Используйте этот навык, чтобы пользователь мог создать собственный пользовательский интерфейс, интерактивную формулу, панель управления с взаимодействием, встроить панель или другое приложение, которое можно использовать в трекер-концентраторе, не упоминая «приложение». Также вы можете применить эти данные с подробной информацией, формулами для людей или советом агента, требующего взаимодействия (без индивидуальной лекции).
