Construire des applications JSX interactives intégrées dans Tracker Hub (rendues dans /apps/:id/render, éventuellement affichées comme /kiosk/:slug via des vues). Composant unique JSX + window.__TrackerUI + règle anti-fuite pour is_public_safe + points de terminaison REST et outils MCP (tracker_create_app, tracker_update_app, tracker_set_app_public_safe). Utilisez cette compétence si l'utilisateur souhaite créer une interface utilisateur personnalisée, un formulaire interactif, un tableau de bord avec interaction, un panneau intégré ou toute application qui peut être affichée dans le tracker-hub sans mentionner « app ». Également appliqué si vous avez déjà montré des données sur les analyses approfondies, les formulaires pour les humains ou la sortie d'agent qui nécessite une interaction (pas de lecture seule).
