Construir アプリ JSX インタラクティブは、Tracker Hub を組み込むことができます (/apps/:id/render でレンダリングし、ビュー経由で /kiosk/:slug を削除することもできます)。 Cubre コンポーネント JSX único + window.__TrackerUI + reglas anti-leak para is_public_safe + エンドポイント REST y MCP ツール (tracker_create_app、tracker_update_app、tracker_set_app_public_safe)。ユーザー エステ スキルは、UI カスタム、公式インタラクション、ダッシュボードの相互作用、パネルのエンベビド、または最も重要なトラッカー ハブの「アプリ」を参照していないアプリの詳細を確認します。多くのデータをドリルダウンし、人的資源を活用し、必要な対話を行うことができます (単独講義はありません)。
