كتابة الوثائق وإعادة هيكلتها وتصنيفها ومراجعتها باستخدام إطار عمل Diataxis. استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تحسين أو تدقيق أو إعادة تنظيم المستندات أو الوثائق أو قواعد المعرفة أو مراكز المساعدة أو أدلة الإعداد أو مستندات العمليات الداخلية أو الأدلة أو أدلة التشغيل أو مستندات المنتج أو مستندات واجهة برمجة التطبيقات/المطورين أو البرامج التعليمية أو الأدلة الإرشادية أو المراجع أو الشروحات. استخدمه أيضًا عندما يذكر المستخدم Diataxis، أو البرنامج التعليمي، أو الكيفية، أو المرجع، أو الشرح، أو تصنيف المستندات، أو بنية التوثيق، أو يسأل لماذا يبدو المستند مربكًا. لا تستخدمه للنسخ التسويقية، أو العقود القانونية، أو الخيال، أو عروض المبيعات، أو البيانات الصحفية، أو كتابة الإقناع أولاً ما لم يرغب المستخدم صراحةً في تحليل التوثيق بأسلوب Diataxis.
