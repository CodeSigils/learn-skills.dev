Напишите, реструктуризируйте, классифицируйте и просматривайте документацию с помощью платформы Diataxis. Используйте этот навык всякий раз, когда пользователь запрашивает создание, улучшение, аудит или реорганизацию документов, документации, баз знаний, справочных центров, руководств по адаптации, документации по внутренним процессам, руководств, модулей Runbook, документации по продукту, документации по API/разработчикам, учебных пособий, практических руководств, ссылок или объяснений. Также используйте его, когда пользователь упоминает Diataxis, руководство, инструкции, ссылки, объяснения, таксономию документации, архитектуру документации или спрашивает, почему документ кажется запутанным. Не используйте его для маркетинговых текстов, юридических контрактов, художественной литературы, коммерческих предложений, пресс-релизов или написания, ориентированного на убеждение, если только пользователь явно не хочет провести анализ документации в стиле Diataxis.
