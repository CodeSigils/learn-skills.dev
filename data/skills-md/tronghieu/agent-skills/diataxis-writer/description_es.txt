Redactar, reestructurar, clasificar y revisar documentación utilizando el marco Diataxis. Utilice esta habilidad siempre que el usuario solicite crear, mejorar, auditar o reorganizar documentos, bases de conocimientos, centros de ayuda, guías de incorporación, documentos de procesos internos, manuales, runbooks, documentos de productos, documentos de API/desarrolladores, tutoriales, guías prácticas, referencias o explicaciones. Úselo también cuando el usuario mencione Diataxis, tutorial, procedimientos, referencias, explicaciones, taxonomía de documentos, arquitectura de documentación o pregunte por qué un documento se siente confuso. No lo utilice para textos de marketing, contratos legales, ficción, propuestas de ventas, comunicados de prensa o escritos de persuasión a menos que el usuario desee explícitamente un análisis de documentación al estilo Diataxis.
