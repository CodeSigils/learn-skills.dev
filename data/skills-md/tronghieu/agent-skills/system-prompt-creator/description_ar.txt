قم بإنشاء مطالبات نظام عالية الجودة ومدروسة للنماذج لأي ماجستير في إدارة الأعمال (Claude، GPT، Gemini، open source، وما إلى ذلك). استخدم هذه المهارة عندما يريد المستخدم إنشاء أو كتابة أو إنشاء أو تصميم أو صياغة أو تحسين موجه النظام أو تعليمات النظام أو التعليمات المخصصة لأي نموذج من نماذج الذكاء الاصطناعي. يتم التشغيل أيضًا عندما يسأل المستخدم عن الهندسة السريعة، أو التصميم الفوري، أو التحسين السريع، أو يريد تحديد سلوك مساعد الذكاء الاصطناعي، أو chatbot، أو الوكيل، أو أي تطبيق مدعوم من LLM - حتى لو لم يذكر "موجه النظام" صراحةً. يغطي جميع حالات الاستخدام بما في ذلك برامج الدردشة الآلية، والأنظمة الوكيلة، وسير عمل استخدام الأدوات، وإنشاء المحتوى، واستخراج البيانات، ومساعدي التعليمات البرمجية، والمحادثات متعددة الأدوار.
