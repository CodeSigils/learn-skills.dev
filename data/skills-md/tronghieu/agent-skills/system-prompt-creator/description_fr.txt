Créez des invites système de haute qualité et sensibles aux modèles pour n'importe quel LLM (Claude, GPT, Gemini, open-source, etc.). Utilisez cette compétence chaque fois que l'utilisateur souhaite créer, écrire, construire, concevoir, rédiger ou améliorer une invite système, des instructions système ou des instructions personnalisées pour n'importe quel modèle d'IA. Déclenchez également lorsque l'utilisateur pose des questions sur l'ingénierie des invites, la conception des invites, l'optimisation des invites ou souhaite définir le comportement d'un assistant IA, d'un chatbot, d'un agent ou de toute application basée sur LLM, même s'il ne dit pas explicitement « invite système ». Couvre tous les cas d'utilisation, y compris les chatbots, les systèmes agents, les flux de travail d'utilisation d'outils, la génération de contenu, l'extraction de données, les assistants de code et les conversations à plusieurs tours.
