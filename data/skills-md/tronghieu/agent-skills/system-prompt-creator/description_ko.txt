모든 LLM(Claude, GPT, Gemini, 오픈 소스 등)에 대한 고품질 모델 인식 시스템 프롬프트를 생성합니다. 사용자가 AI 모델에 대한 시스템 프롬프트, 시스템 지침 또는 사용자 정의 지침을 생성, 작성, 구축, 디자인, 초안 또는 개선하려고 할 때마다 이 기술을 사용하십시오. 또한 사용자가 프롬프트 엔지니어링, 프롬프트 디자인, 프롬프트 최적화에 대해 질문하거나 AI 도우미, 챗봇, 에이전트 또는 LLM 기반 애플리케이션의 동작을 정의하려고 할 때에도 트리거됩니다. 이는 명시적으로 "시스템 프롬프트"라고 말하지 않더라도 마찬가지입니다. 챗봇, 에이전트 시스템, 도구 사용 워크플로, 콘텐츠 생성, 데이터 추출, 코드 도우미 및 다중 전환 대화를 포함한 모든 사용 사례를 다룹니다.
