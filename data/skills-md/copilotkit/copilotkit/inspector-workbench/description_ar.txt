يقوم بتشغيل Inspector UI في معمل حالة Threads المستقل حتى يتمكن الوكيل من رؤية التراكب. يُستخدم عندما يطلب أحد موظفي CopilotKit من أحد الوكلاء إصلاح أو تلميع أو إضافة أو تصحيح أخطاء واجهة مستخدم Inspector أو chrome أو الأجزاء أو إجراءات التراكب أو المشغّل أو الصفحة الرئيسية أو الخيوط أو ساحة اللعب أو الذاكرة أو أي سلوك مرئي في @copilotkit/web-inspector. لا تستخدمه لتحديثات وسائل الشرح الخاصة بالمستندات فقط (تحميل مستندات المفتش)، أو وقت التشغيل أو التغييرات الأساسية بدون واجهة مستخدم Inspector، أو عرض عمل الخلية، أو قراءة Inspector كمستهلك داخل التطبيق.
