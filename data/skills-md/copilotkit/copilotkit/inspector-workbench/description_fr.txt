Exécute le travail de l’interface utilisateur d’Inspector sur le laboratoire d’état Threads autonome afin que l’agent puisse voir la superposition. À utiliser lorsqu'un employé de CopilotKit demande à un agent de corriger, peaufiner, ajouter ou déboguer l'interface utilisateur de l'inspecteur, le chrome, les volets, les actions de superposition, le lanceur, l'accueil, les fils de discussion, l'aire de jeu, la mémoire ou tout comportement visuel dans @copilotkit/web-inspector. Ne pas utiliser pour les mises à jour de légende de documents uniquement (charger les documents de l'inspecteur), les modifications d'exécution ou de base sans interface utilisateur d'Inspector, la présentation du travail de cellule ou la lecture d'Inspector en tant que consommateur dans une application.
