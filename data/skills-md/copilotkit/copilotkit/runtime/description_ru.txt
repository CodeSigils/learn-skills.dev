@copilotkit/runtime — смонтируйте собственный CopilotRuntime на любом JS-сервере, подключите промежуточное программное обеспечение, выберите AgentRunner, создайте экземпляр встроенного агента (предпочтительным по умолчанию является заводской режим с TanStack AI) или подключите любую из 12 внешних платформ агентов (Mastra, LangGraph, CrewAI Crews/Flows, PydanticAI, ADK, LlamaIndex, Agno, AWS). Strands, MS Agent Framework, AG2, A2A), включите интеллектуальный режим для устойчивых потоков + веб-сокет, зарегистрируйте серверные инструменты с помощью defineTool и выполните транскрипцию голоса. Использует примитив createCopilotRuntimeHandler на основе выборки — адаптеры Express/Hono не рекомендуются. Загрузите ссылку в раздел references/, соответствующую вашей задаче.
