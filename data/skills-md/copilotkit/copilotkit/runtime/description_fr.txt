@copilotkit/runtime — montez un CopilotRuntime natif de récupération sur n'importe quel serveur JS, connectez un middleware, choisissez un AgentRunner, instanciez BuiltInAgent (le mode usine avec TanStack AI est la valeur par défaut préférée) ou branchez l'un des 12 frameworks d'agents externes (Mastra, LangGraph, CrewAI Crews/Flows, PydanticAI, ADK, LlamaIndex, Agno, AWS Strands, MS Agent Framework, AG2, A2A), activez le mode Intelligence pour les threads durables + websocket, enregistrez les outils côté serveur via DefinTool et effectuez la transcription vocale par fil. Utilise la primitive createCopilotRuntimeHandler basée sur la récupération — les adaptateurs Express/Hono sont déconseillés. Chargez la référence sous références/ qui correspond à votre tâche.
