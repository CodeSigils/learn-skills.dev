@copilotkit/runtime – mounten Sie eine fetch-native CopilotRuntime auf einem beliebigen JS-Server, verkabeln Sie Middleware, wählen Sie einen AgentRunner aus, instanziieren Sie BuiltInAgent (Factory-Modus mit TanStack AI ist die bevorzugte Standardeinstellung) oder schließen Sie eines von 12 externen Agent-Frameworks an (Mastra, LangGraph, CrewAI Crews/Flows, PydanticAI, ADK, LlamaIndex, Agno, AWS Strands, MS Agent Framework, AG2, A2A), aktivieren Sie den Intelligence-Modus für dauerhafte Threads + Websocket, registrieren Sie serverseitige Tools über defineTool und übertragen Sie die Sprachtranskription. Verwendet das abrufbasierte Grundelement „createCopilotRuntimeHandler“ – von den Express/Hono-Adaptern wird abgeraten. Laden Sie unter references/ die Referenz, die zu Ihrer Aufgabe passt.
