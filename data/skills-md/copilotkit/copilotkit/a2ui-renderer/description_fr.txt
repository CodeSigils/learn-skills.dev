Rendre A2UI (surfaces déclaratives agent-à-interface utilisateur) dans CopilotKit v2. Activez le runtime via CopilotRuntime({ a2ui: {...} }), puis activez le fournisseur via <CopilotKitProvider a2ui={{ theme }}>. S'active automatiquement via /info - ne transmettez PAS manuellement les renderActivityMessages. createA2UIMessageRenderer est livré à partir de @copilotkit/react-core/v2 ; les primitives de bas niveau (A2UIProvider, A2UIRenderer, createCatalog) sont expédiées depuis @copilotkit/a2ui-renderer. Couvre la personnalisation du thème, la déduplication de createSurface, l'essai/finalement du nettoyage d'action-bridge. Se charge lorsqu'un agent émet des opérations A2UI (createSurface / updateComponents / updateDataModel), lors du câblage d'a2ui sur CopilotRuntime ou lors du style des surfaces A2UI.
