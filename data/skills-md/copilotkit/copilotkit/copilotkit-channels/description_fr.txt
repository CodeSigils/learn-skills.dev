À utiliser pour la moitié CODE d'un Intelligence Channel géré avec Slack ou Microsoft Teams : personnalisation du canal qu'un projet échafaudé CLI est déjà livré ou, pour un projet que la CLI n'a pas généré, écriture de la déclaration du canal, de l'hôte de longue durée et de l'appel d'activation attendu. La configuration du fournisseur Teams entre dans le champ d’application, car l’assistant CLI ou le tableau de bord l’exécute. Créer une application Slack pour la première fois ne l'est pas : si aucune application Slack n'existe encore, utilisez setup-slack-channel pour la moitié du fournisseur et revenez ici pour le code.
