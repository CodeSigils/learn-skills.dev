Úselo para la mitad CÓDIGO de un canal de inteligencia administrado con Slack o Microsoft Teams: personalizar el canal que ya se envía un proyecto con estructura CLI o, para un proyecto que la CLI no generó, escribir la declaración del canal, el host de larga duración y la llamada de activación esperada. La configuración del proveedor de Teams está dentro del alcance porque la CLI o el asistente del panel la realiza. Crear una aplicación de Slack por primera vez no lo es: si aún no existe ninguna aplicación de Slack, use setup-slack-channel para la mitad del proveedor y regrese aquí para obtener el código.
