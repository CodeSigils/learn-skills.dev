@copilotkit/react-core - montez CopilotKitProvider dans une application Next.js App Router / React Router v7 / TanStack Start / SPA, déposez CopilotChat/CopilotPopup/CopilotSidebar (les composants de discussion v2 sont livrés à partir de réagir-core/v2 - PAS réagir-ui, qui est CSS uniquement dans la v2), accédez et abonnez-vous aux agents avec useAgent / useAgentContext / useCapabilities, basculez entre plusieurs agents, gérez des threads d'intelligence durables avec useThreads, enregistrez les outils côté navigateur via useFrontendTool, restituez les appels d'outils avec useRenderTool / useComponent / useDefaultRenderTool, exécutez la porte avec useHumanInTheLoop, câblez les pièces jointes avec useAttachments, configurez les pilules de suggestion et enregistrez les moteurs de rendu d'activité et de messages personnalisés. publicLicenseKey est canonique (publicApiKey est un alias obsolète). Chargez la référence sous références/ qui correspond à votre tâche.
