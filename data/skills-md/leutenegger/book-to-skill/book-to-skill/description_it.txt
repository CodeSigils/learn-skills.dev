Converte libri e documenti (PDF, EPUB, DOCX, HTML, Markdown, testo semplice, RTF, MOBI/AZW con Calibre) in competenze di agenti strutturati, estraendo strutture, modelli mentali, principi, tecniche e anti-pattern. Da utilizzare quando l'utente desidera studiare un documento tramite GitHub Copilot CLI, Amp o Claude Code, applicare i framework di un autore mentre lavora o creare una knowledge base riutilizzabile da un file.
