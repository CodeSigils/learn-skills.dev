استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تحسين أو تدقيق أو تقسيم المطالبات لمولدات فيديو الذكاء الاصطناعي (Seedance، وKling، وVeo، وRunway، وLuma، وPika، وSora، وأي نظام تحويل صورة إلى فيديو). تغطي المهارة أيضًا القصص المصورة، وقوائم اللقطات، ومعالجات المخرج، والمونتاج الديناميكي، وبنية القصة متعددة المقاطع، وتوجيه الكاميرا، والإضاءة، والحجب، والإيقاع، واستمرارية الشخصية، والحوار، وتصميم الصوت. يتم التشغيل حتى عندما يقول المستخدم أشياء مثل "ابتكر مشهدًا لمقطع فيديو"، أو "تقسيم إلى مقاطع"، أو "إنشاء لوحة عمل"، أو "تحسين المطالبة لـ Kling"، أو "ترجمة النص إلى مطالبات"، أو "كيفية تصوير X في فيديو بتقنية الذكاء الاصطناعي"، أو مشاركة مطالبة وطلب إصلاحها.

يرجى الرد دائمًا بلغة المستخدم.
