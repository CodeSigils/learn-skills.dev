Операции DeFi на Polygon с использованием интерфейса командной строки Polygon Agent. Охватывает обмен токенов в одной цепочке, межсетевое соединение и депозиты доходности в хранилищах Aave v3 и Morpho через обнаружение пула заработков Trails. По умолчанию все команды выполняются в пробном режиме — добавьте --broadcast для выполнения.
