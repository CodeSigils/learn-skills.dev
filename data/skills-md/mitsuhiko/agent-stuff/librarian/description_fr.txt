Mettez en cache et actualisez les référentiels git distants sous ~/.cache/checkouts/<host>/<org>/<repo> afin que les références futures puissent réutiliser une copie locale. Utilisez cette compétence lorsque l'utilisateur vous dirige vers un référentiel git distant comme référence ou que vous avez rencontré un dépôt git distant par d'autres moyens.
