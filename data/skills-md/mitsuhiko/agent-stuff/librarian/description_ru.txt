Кэшируйте и обновляйте удаленные репозитории git в ~/.cache/checkouts/<host>/<org>/<repo>, чтобы будущие ссылки могли повторно использовать локальную копию. Используйте этот навык, когда пользователь указывает вам на удаленный репозиторий git в качестве ссылки или вы столкнулись с удаленным репозиторием git другими способами.
