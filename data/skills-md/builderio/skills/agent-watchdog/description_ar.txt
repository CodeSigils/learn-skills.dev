استخدمه عندما يُطلب منك مشاهدة عمل وكيل آخر أو مجالسته أو تدقيقه أو مراجعته أو مقارنته أو إصلاحه من معرف جلسة Codex أو جلسة/نص Claude Code أو رابط الدردشة/السلسلة أو العلاقات العامة أو الفرع أو السجل أو ملخص التشغيل الملصق. راقب حتى ينتهي الوكيل الآخر أو يتم حظره، وأعد بناء ما طلبه المستخدم، وافحص ما قام الوكيل بتغييره بالفعل والتحقق منه، والإبلاغ عن الفجوات، وإجراء إصلاحات محددة بشكل اختياري عندما يسمح المستخدم بالإصلاح.
