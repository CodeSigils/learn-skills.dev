Verwenden Sie diese Funktion, wenn Sie aufgefordert werden, die Arbeit eines anderen Agenten aus einer Codex-Sitzungs-ID, einer Claude-Code-Sitzung/Transkription, einem Chat-/Thread-Link, einer PR, einer Verzweigung, einem Protokoll oder einer eingefügten Laufzusammenfassung zu beobachten, zu überwachen, zu prüfen, zu vergleichen oder zu korrigieren. Überwachen Sie, bis der andere Agent fertig oder blockiert ist, rekonstruieren Sie, was der Benutzer gefragt hat, überprüfen Sie, was der Agent tatsächlich geändert und überprüft hat, melden Sie Lücken und nehmen Sie optional bereichsbezogene Korrekturen vor, wenn der Benutzer die Reparatur autorisiert.
