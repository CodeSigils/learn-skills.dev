Décompressez ou extrayez un fichier zip dans le projet. À utiliser lorsque l'utilisateur dit « décompresser », « extraire le zip », « décompresser le fichier » ou demande d'extraire une archive .zip. Recherche le fichier .zip le plus récemment modifié dans la base de code et l'extrait à la racine du projet à l'aide de « npx extract-zip ».
