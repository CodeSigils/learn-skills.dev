Importiert einen Builder.io-Prototyp in das aktuelle Projekt, indem die Builder-Dev-Tools-CLI ausgeführt wird. Verwenden Sie diese Option, wenn der Benutzer das Importieren eines Prototyps, einer Builder.io-URL oder eines builder.io/app/projects-Links erwähnt oder Designs oder Komponenten aus einem Builder-Prototyp importieren möchte. Wird bei Phrasen wie „Prototyp importieren“, „diese Builder-URL verwenden“, „Von Builder importieren“ oder wenn eine builder.io/app/projects-URL geteilt wird, ausgelöst.
