Importe un prototype Builder.io dans le projet actuel en exécutant la CLI des outils de développement Builder. À utiliser lorsque l'utilisateur mentionne l'importation d'un prototype, d'une URL Builder.io, d'un lien builder.io/app/projects ou souhaite importer des conceptions ou des composants d'un prototype Builder. Se déclenche sur des expressions telles que « importer un prototype », « utiliser cette URL de générateur », « importer depuis le générateur » ou lorsqu'une URL builder.io/app/projects est partagée.
