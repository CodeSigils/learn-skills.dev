Importa un prototipo de Builder.io al proyecto actual ejecutando la CLI de herramientas de desarrollo de Builder. Úselo cuando el usuario mencione la importación de un prototipo, una URL de Builder.io, un enlace builder.io/app/projects o quiera incorporar diseños o componentes de un prototipo de Builder. Se activa con frases como "importar prototipo", "usar esta URL del constructor", "importar desde el constructor" o cuando se comparte una URL builder.io/app/projects.
