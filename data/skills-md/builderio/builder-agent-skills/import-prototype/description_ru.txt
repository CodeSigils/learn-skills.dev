Импортирует прототип Builder.io в текущий проект, запуская CLI инструментов Builder. Используйте, когда пользователь упоминает импорт прототипа, URL-адрес Builder.io, ссылку builder.io/app/projects или хочет импортировать проекты или компоненты из прототипа Builder. Запускается по таким фразам, как «импортировать прототип», «использовать этот URL-адрес компоновщика», «импортировать из компоновщика» или при совместном использовании URL-адреса builder.io/app/projects.
