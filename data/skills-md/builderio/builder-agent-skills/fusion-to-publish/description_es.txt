Registre los componentes de React creados en Builder.io Fusion para usarlos en el editor visual de Publish. Scaffolds rutas generales, registro de constructores, configuración de SDK y .builderrules. Asigna accesorios de TypeScript a tipos de entrada de Builder y genera llamadas a Builder.registerComponent(). Úselo cuando el usuario quiera registrar un componente para Publicar, configurar la integración de Publicar, hacer que los componentes estén disponibles en el editor visual, realizar una configuración Fusion-to-Publish o f2p, conectar la salida de Fusion al CMS sin cabeza, registrar componentes de forma masiva desde un directorio o hacer que los componentes se puedan arrastrar para los que no son desarrolladores, incluso si no mencionan "Publicar" por su nombre.
