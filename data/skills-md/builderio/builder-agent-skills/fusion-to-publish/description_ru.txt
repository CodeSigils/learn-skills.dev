Зарегистрируйте компоненты React, встроенные в Builder.io Fusion, для использования в визуальном редакторе Publish. Всеобъемлющие маршруты скаффолдов, реестр сборщиков, конфигурация SDK и .builderrules. Сопоставляет TypeScript с типами ввода Builder и генерирует вызовы Builder.registerComponent(). Используйте, когда пользователь хочет зарегистрировать компонент для публикации, настроить интеграцию публикации, сделать компоненты доступными в визуальном редакторе, выполнить настройку Fusion-to-Publish или f2p, подключить вывод Fusion к безголовой CMS, выполнить массовую регистрацию компонентов из каталога или сделать компоненты доступными для перетаскивания для не-разработчиков — даже если они не упоминают «Опубликовать» по имени.
