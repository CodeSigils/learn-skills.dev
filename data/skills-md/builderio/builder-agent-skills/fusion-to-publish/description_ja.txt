Publish のビジュアル エディターで使用するために、Builder.io Fusion に構築された React コンポーネントを登録します。スキャフォールドは、すべてのルート、ビルダー レジストリ、SDK 設定、および .builderrules をキャッチします。 TypeScript props を Builder 入力型にマップし、Builder.registerComponent() 呼び出しを生成します。ユーザーがコンポーネントをパブリッシュ用に登録する場合、パブリッシュ統合をセットアップする場合、コンポーネントをビジュアル エディターで使用できるようにする場合、Fusion-to-Publish または f2p セットアップを行う場合、Fusion 出力をヘッドレス CMS に接続する場合、ディレクトリからコンポーネントを一括登録する場合、開発者以外がコンポーネントをドラッグできるようにする場合に使用します (「パブリッシュ」という名前が記載されていない場合でも)。
