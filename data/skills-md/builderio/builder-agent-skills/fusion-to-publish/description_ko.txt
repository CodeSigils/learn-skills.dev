Publish의 비주얼 편집기에서 사용할 수 있도록 Builder.io Fusion에 내장된 React 구성 요소를 등록하세요. 스캐폴드는 포괄 경로, 빌더 레지스트리, SDK 구성 및 .builderrules를 제공합니다. TypeScript props를 Builder 입력 유형에 매핑하고 Builder.registerComponent() 호출을 생성합니다. 사용자가 게시를 위해 구성 요소를 등록하고, 게시 통합을 설정하고, 시각적 편집기에서 구성 요소를 사용할 수 있도록 만들고, Fusion-to-Publish 또는 f2p 설정을 수행하고, Fusion 출력을 헤드리스 CMS에 연결하고, 디렉토리에서 구성 요소를 대량 등록하거나, 개발자가 아닌 사람이 이름으로 "게시"를 언급하지 않더라도 구성 요소를 드래그할 수 있도록 만들려는 경우에 사용합니다.
