قم بتسجيل مكونات React المضمنة في Builder.io Fusion لاستخدامها في المحرر المرئي لـ Publish. مسارات التقاط الكل للسقالات، وسجل المنشئ، وتكوين SDK، وقواعد البناء. يقوم Map TypeScript بدعم أنواع مدخلات Builder ويقوم بإنشاء استدعاءات Builder.registerComponent(). يُستخدم عندما يريد المستخدم تسجيل مكون للنشر، أو إعداد تكامل النشر، أو إتاحة المكونات في المحرر المرئي، أو إجراء إعداد Fusion-to-Publish أو f2p، أو توصيل مخرجات Fusion بنظام إدارة المحتوى بدون رأس، أو تسجيل المكونات بشكل مجمّع من دليل، أو جعل المكونات قابلة للسحب لغير المطورين - حتى إذا لم يذكروا "النشر" بالاسم.
