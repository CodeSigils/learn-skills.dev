Registra i componenti React creati in Builder.io Fusion per l'utilizzo nell'editor visivo di Publish. Gli scaffold offrono percorsi omnicomprensivi, registro del builder, configurazione dell'SDK e .builderrules. Mappa le prop TypeScript sui tipi di input di Builder e genera chiamate Builder.registerComponent(). Da utilizzare quando l'utente desidera registrare un componente per la pubblicazione, impostare l'integrazione della pubblicazione, rendere i componenti disponibili nell'editor visivo, eseguire una configurazione Fusion-to-Publish o f2p, connettere l'output di Fusion al CMS headless, registrare in blocco i componenti da una directory o rendere i componenti trascinabili per i non sviluppatori, anche se non menzionano "Pubblica" per nome.
