Enregistrez les composants React créés dans Builder.io Fusion pour les utiliser dans l'éditeur visuel de Publish. Routes fourre-tout d'échafaudages, registre de constructeur, configuration du SDK et .builderrules. Mappe les accessoires TypeScript aux types d’entrée Builder et génère des appels Builder.registerComponent(). À utiliser lorsque l'utilisateur souhaite enregistrer un composant pour la publication, configurer l'intégration de la publication, rendre les composants disponibles dans l'éditeur visuel, effectuer une configuration Fusion-to-Publish ou f2p, connecter la sortie Fusion au CMS sans tête, enregistrer en masse des composants à partir d'un répertoire ou rendre les composants déplaçables pour les non-développeurs, même s'ils ne mentionnent pas « Publier » par leur nom.
