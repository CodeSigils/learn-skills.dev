Erstellen Sie neue Fertigkeiten, verbessern Sie vorhandene Fertigkeiten und verstehen Sie die Best Practices für Fertigkeiten für Builder.io Fusion. Verwenden Sie diese Option, wenn der Benutzer eine Fertigkeit erstellen, einen Schrägstrichbefehl erstellen, einen Arbeitsablauf automatisieren, benutzerdefinierte KI-Anweisungen hinzufügen, wiederverwendbares KI-Verhalten erstellen möchte oder fragt, wie er die Funktionen von Fusion in seinem Projekt erweitern kann. Verwenden Sie diese Funktion auch, wenn der Benutzer die Auslösung oder das Verhalten eines vorhandenen Skills verbessern, prüfen oder Fehler beheben möchte.
