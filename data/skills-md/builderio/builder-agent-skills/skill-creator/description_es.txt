Cree nuevas habilidades, mejore las existentes y comprenda las mejores prácticas de habilidades para Builder.io Fusion. Úselo cuando el usuario quiera crear una habilidad, crear un comando de barra diagonal, automatizar un flujo de trabajo, agregar instrucciones de IA personalizadas, crear comportamientos de IA reutilizables o pregunta cómo ampliar las capacidades de Fusion en su proyecto. Úselo también cuando el usuario quiera mejorar, auditar o solucionar problemas de activación o comportamiento de una habilidad existente.
