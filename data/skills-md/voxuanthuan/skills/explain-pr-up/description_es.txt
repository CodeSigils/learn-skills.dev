Cree un artefacto HTML independiente que presente una solicitud de extracción para su revisión. Muestra antes y después de los cambios de código, recorrido archivo por archivo con diferencias anotadas, mapa de riesgos, áreas de enfoque de revisión y un breve resumen. Úselo cuando el usuario solicite redactar un PR, resumir los cambios de código visualmente, crear un documento de revisión de PR, mostrar diferencias antes y después en HTML o preparar un tutorial de cambios para los revisores.
