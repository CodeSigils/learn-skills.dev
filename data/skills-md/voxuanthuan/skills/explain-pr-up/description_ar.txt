قم بإنشاء عنصر HTML مستقل يقدم طلب سحب للمراجعة. يُظهر قبل/بعد تغييرات التعليمات البرمجية، وجولة ملفًا تلو الآخر مع الاختلافات المشروحة، وخريطة المخاطر، ومراجعة مجالات التركيز، وملخصًا قصيرًا. يُستخدم عندما يطلب المستخدم كتابة تقرير علاقات عامة، أو تلخيص تغييرات التعليمات البرمجية بشكل مرئي، أو إنشاء مستند مراجعة علاقات عامة، أو إظهار الاختلافات قبل وبعد في HTML، أو إعداد دليل تفصيلي للتغيير للمراجعين.
