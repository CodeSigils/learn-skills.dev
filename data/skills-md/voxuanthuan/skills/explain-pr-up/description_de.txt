Erstellen Sie ein eigenständiges HTML-Artefakt, das eine Pull-Anfrage zur Überprüfung darstellt. Zeigt Codeänderungen vor/nachher, eine Datei-für-Datei-Tour mit kommentierten Unterschieden, eine Risikokarte, Überprüfungsschwerpunkte und eine kurze Zusammenfassung. Verwenden Sie diese Option, wenn der Benutzer eine PR verfassen, Codeänderungen visuell zusammenfassen, ein PR-Überprüfungsdokument erstellen, Vorher- und Nachher-Unterschiede in HTML anzeigen oder eine Änderungsanleitung für Prüfer vorbereiten möchte.
