Creare un artefatto HTML autonomo che presenti una richiesta pull per la revisione. Mostra prima/dopo le modifiche al codice, tour file per file con differenze annotate, mappa dei rischi, aree di interesse della revisione e un breve riepilogo. Da utilizzare quando l'utente chiede di scrivere un PR, riepilogare visivamente le modifiche al codice, creare un documento di revisione PR, mostrare le differenze prima e dopo in HTML o preparare una procedura dettagliata di modifica per i revisori.
