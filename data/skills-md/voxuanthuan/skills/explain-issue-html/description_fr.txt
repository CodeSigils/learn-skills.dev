Créez des artefacts d'explication HTML autonomes pour les bugs, les incidents, le comportement du code, les problèmes d'API/de cache/d'état ou les problèmes techniques que l'utilisateur ne comprend pas. À utiliser lorsque l'utilisateur demande d'expliquer un problème à partir de zéro, d'enseigner comme un débutant ou un lycéen, de créer un artefact HTML de documentation, d'utiliser des diagrammes ASCII, d'afficher des extraits avant/après, de pointer vers le champ/la ligne brisée ou d'expliquer pourquoi un correctif fonctionne.
