قم بإنشاء عناصر تفسير HTML مستقلة للأخطاء المربكة أو الحوادث أو سلوك التعليمات البرمجية أو مشكلات واجهة برمجة التطبيقات/ذاكرة التخزين المؤقت/الحالة أو المشكلات الفنية التي لا يفهمها المستخدم. يُستخدم عندما يطلب المستخدم شرح مشكلة من البداية، أو التدريس مثل طالب مبتدئ أو مدرسة ثانوية، أو إنشاء عنصر HTML للمستندات، أو استخدام مخططات ASCII، أو عرض المقتطفات قبل/بعدها، أو الإشارة إلى الحقل/السطر المقطوع، أو شرح سبب نجاح الإصلاح.
