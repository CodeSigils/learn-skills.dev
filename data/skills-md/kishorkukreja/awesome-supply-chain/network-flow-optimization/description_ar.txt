عندما يريد المستخدم تحسين تدفقات الشبكة، أو حل مشاكل تدفق التكلفة الدنيا، أو تصميم شبكات التدفق. استخدمه أيضًا عندما يذكر المستخدم "الحد الأدنى لتدفق التكلفة"، أو "التدفق الأقصى"، أو "مشكلة تدفق الشبكة"، أو "مشكلة النقل"، أو "مشكلة إعادة الشحن"، أو "تدفق السلع المتعددة"، أو "تحسين تدفق سلسلة التوريد"، أو "تخطيط سعة الشبكة". لمعرفة موقع المنشأة، راجع مشكلة موقع المنشأة. إذا كنت تريد شبكات التوزيع، انظر شبكة مركز التوزيع.
