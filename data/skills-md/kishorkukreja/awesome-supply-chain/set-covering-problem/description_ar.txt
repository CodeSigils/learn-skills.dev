عندما يريد المستخدم حل مشكلات تغطية المجموعة، أو تحديد الحد الأدنى من مجموعات التغطية، أو تحسين تغطية المنشأة. استخدمه أيضًا عندما يذكر المستخدم "مجموعة التغطية"، أو "الحد الأدنى لمجموعة التغطية"، أو "تحسين التغطية"، أو "مشكلة تغطية المنشأة"، أو "تغطية الخدمة"، أو "تغطية مجموعة الموقع"، أو "الحد الأقصى لمشكلة موقع التغطية"، أو "تصميم التغطية". للتعرف على الموقع العام للمنشأة، راجع مشكلة موقع المنشأة. بالنسبة لتطبيقات محددة، راجع تحسين موقع المستودع أو مشكلة موقع المحور.
