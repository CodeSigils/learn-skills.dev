عندما يريد المستخدم تحسين المخزون عبر مواقع شبكة متعددة، أو تنفيذ سياسات المخزون متعدد المستويات، أو تنسيق مستويات المخزون بين المستودعات ومراكز التوزيع. استخدمه أيضًا عندما يذكر المستخدم "تحسين مخزون الشبكة"، أو "المخزون متعدد المراحل"، أو "شبكة سلسلة التوريد"، أو "مخزون المستوى"، أو "مخزون التثبيت"، أو "سياسات المخزون الأساسي"، أو "نموذج الخدمة المضمونة"، أو "تخطيط متطلبات التوزيع (DRP)،" أو "هياكل الشبكة التسلسلية/المشجرة/العامة". بالنسبة لمخزون الموقع الواحد، راجع تحسين المخزون. للتوجيه مع المخزون، راجع مشكلة توجيه المخزون.
