عندما يريد المستخدم حل مشاكل الجدولة أو التخصيص أو التجميع المعقدة باستخدام برمجة القيد (CP). يُستخدم أيضًا عندما يذكر المستخدم "برمجة القيد"، أو "CP-SAT"، أو "رضا القيد"، أو "القيود المختلفة"، أو "القيود العالمية"، أو "الانتشار"، أو "استراتيجيات البحث"، أو عندما تكون المشكلة ذات قيود منطقية معقدة، أو جدولة باستخدام موارد منفصلة، ​​أو مشاكل في التخصيص. بالنسبة لـ MIP، راجع نمذجة التحسين. إذا كنت تريد علم الميتايورستك، انظر تحسين الميتايورستك.
