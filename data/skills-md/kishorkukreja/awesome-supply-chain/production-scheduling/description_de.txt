Wenn der Benutzer Produktionsabläufe planen, Fertigungspläne optimieren, Arbeitsbelastungen ausgleichen oder Aufträge sequenzieren möchte. Verwenden Sie diese Option auch, wenn der Benutzer „Job-Shop-Planung“, „Flow-Shop-Planung“, „Versandregeln“, „Sequenzoptimierung“, „Maschinenplanung“, „MRP“, „Finite-Kapazitätsplanung“, „Produktionsplanung“ oder „Werkstattplanung“ erwähnt. Informationen zur Kapazitätsplanung finden Sie unter Kapazitätsplanung. Informationen zur Masterplanung finden Sie unter Master-Production-Scheduling.
