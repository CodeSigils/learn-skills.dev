Cuando el usuario desea resolver el problema de rutas de vehículos (VRP), optimizar rutas para varios vehículos o planificar rutas de entrega de flotas. Utilícelo también cuando el usuario mencione "VRP", "enrutamiento de flotas", "enrutamiento para varios vehículos", "planificación de rutas de entrega", "despacho de vehículos", "optimización de flotas" o "asignación de rutas". Para un solo vehículo, consulte problema del viajante de comercio. Para ventanas de tiempo, consulte vrp-time-windows.
