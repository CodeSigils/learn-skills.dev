عندما يريد المستخدم تحسين العلاقات مع الموردين، أو تنفيذ برامج التعاون، أو تمكين مشاركة المعلومات مع الموردين. استخدمه أيضًا عندما يذكر المستخدم "شراكة الموردين"، أو "التخطيط التعاوني"، أو "VMI"، أو "CPFR"، أو "بوابة الموردين"، أو "مشاركة المعلومات"، أو "تطوير الموردين"، أو "الابتكار المشترك"، أو "الشراكات الإستراتيجية". لاختيار الموردين، راجع اختيار الموردين. بالنسبة لمخاطر الموردين، راجع إدارة مخاطر الموردين.
