عندما يريد المستخدم حل مشاكل موقع المنشأة، قم بتحسين وضع المنشأة، وتحديد المواقع المثالية للمستودعات أو المصانع. استخدمه أيضًا عندما يذكر المستخدم "FLP" أو "مشكلة الوسيط p" أو "موقع المنشأة غير المجهزة" أو "موقع المنشأة غير المجهزة" أو "UFLP" أو "CFLP" أو "وضع المستودع" أو "تحسين اختيار الموقع" أو "تحديد موقع المنشأة" أو "مشكلة تخصيص الموقع". بالنسبة للشبكات المحورية، راجع مشكلة موقع المحور. إذا كنت تريد مراكز التوزيع، انظر شبكة مركز التوزيع.
