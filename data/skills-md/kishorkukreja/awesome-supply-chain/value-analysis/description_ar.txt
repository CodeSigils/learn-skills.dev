عندما يريد المستخدم إجراء تحليل القيمة، أو تقييم المنتجات الطبية، أو إنشاء كتيبات الوصفات، أو تحسين اختيار المنتج للرعاية الصحية. استخدمه أيضًا عندما يذكر المستخدم "لجنة تحليل القيمة"، أو "تقييم المنتج"، أو "تحليل النتائج السريرية"، أو "التكلفة الإجمالية للملكية"، أو "التوحيد القياسي"، أو "إدارة الوصفات"، أو "المصادر القائمة على الأدلة"، أو "اختيار المنتج"، أو "عناصر تفضيلات الطبيب"، أو "تحسين جودة التكلفة". إذا كنت تريد عمليات سلسلة التوريد في المستشفيات، انظر لوجستيات المستشفيات. لتحليل التكاليف بشكل عام، راجع تحليل الإنفاق.
