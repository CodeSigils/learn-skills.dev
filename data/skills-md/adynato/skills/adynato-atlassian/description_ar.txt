اعمل مع روابط Jira وConfluence وAtlassian Cloud عبر Atlassian MCP بدلاً من أتمتة المتصفح. يغطي قراءة عناوين URL الخاصة بـ "atlassian.net"، وتفضيل MCP على Puppeteer للتذاكر والصفحات، وتلخيص حالة المشكلة والتعليقات، والرجوع فقط عند الحاجة إلى الفحص البصري بشكل صريح أو عندما يكون MCP غير متاح. يُستخدم عندما تتضمن المطالبة تذاكر Jira أو صفحات Confluence أو روابط Atlassian.
