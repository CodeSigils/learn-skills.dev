Recherchez, classez et supprimez en toute sécurité la complexité accidentelle de la base de code en prouvant les consommateurs réels, les points d'entrée dynamiques, les obligations de compatibilité, les représentations en double, les surfaces spéculatives et la propriété du cycle de vie. À utiliser lorsqu'on vous le demande pour simplifier ou nettoyer un référentiel, récupérer l'entropie du code, réduire la sur-ingénierie ou la redondance, rechercher des candidats à la suppression, réduire les états/API en double, supprimer le code mort ou ajouté puis abandonné au-delà de la sortie de l'outil statique, ou implémenter une passe de simplification fondée sur des preuves dans n'importe quel langage ou pile. Déclenche également pour 代码化简、熵回收、删代码、清理冗余、收敛抽象、去除过度设计. Ne pas utiliser comme audit de performance à moins que l’objectif déclaré soit la simplification.
