Encuentre, clasifique y elimine de forma segura la complejidad accidental de la base de código demostrando consumidores reales, puntos de entrada dinámicos, obligaciones de compatibilidad, representaciones duplicadas, superficies especulativas y propiedad del ciclo de vida. Úselo cuando se le solicite simplificar o limpiar un repositorio, recuperar la entropía del código, reducir el exceso de ingeniería o la redundancia, encontrar candidatos a eliminación, colapsar estados/API duplicados, eliminar código inactivo o agregado y luego abandonado más allá de la salida de la herramienta estática, o implementar un paso de simplificación respaldado por evidencia en cualquier lenguaje o pila. También activa para 代码化简、熵回收、删代码、清理冗余、收敛抽象、去除过度设计. No utilizar como auditoría de desempeño a menos que el objetivo declarado sea la simplificación.
