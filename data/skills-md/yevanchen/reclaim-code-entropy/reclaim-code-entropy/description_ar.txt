ابحث عن التعقيد العرضي لقاعدة التعليمات البرمجية ورتبه وقم بإزالته بأمان من خلال إثبات المستهلكين الحقيقيين ونقاط الدخول الديناميكية والتزامات التوافق والتمثيلات المكررة والأسطح التخمينية وملكية دورة الحياة. استخدمه عندما يُطلب منك تبسيط مستودع ما أو تنظيفه، أو استعادة إنتروبيا التعليمات البرمجية، أو تقليل الهندسة الزائدة أو التكرار، أو العثور على المرشحين للحذف، أو طي الحالة/واجهات برمجة التطبيقات المكررة، أو إزالة التعليمات البرمجية الميتة أو المضافة ثم المهجورة خارج نطاق مخرجات الأداة الثابتة، أو تنفيذ ممر تبسيط مدعوم بالأدلة بأي لغة أو حزمة. قم بتشغيل أيضًا لـ 代码化简، 熵回收، 删代码، 清理冗余، 收敛抽象، 去除过度设计. لا تستخدم كمراجعة للأداء ما لم يكن التبسيط هو الهدف المعلن.
