Utilice esta habilidad para convertir una solicitud de usuario sin formato en un resumen de tarea estructurado e independiente del modelo antes de ejecutarla. Invoque siempre que la solicitud sea compleja, de varios pasos, entre dominios, ambigua o se entregue a otro modelo o agente. También se activa cuando el usuario dice cosas como "ayúdame a descubrir lo que necesito", "No estoy seguro de cómo preguntar esto", "Quiero hacer X pero no sé por dónde empezar", "toma esto y déjalo más claro", o cuando la tarea combina múltiples objetivos o dominios. NO active solicitudes simples de una línea con una intención clara (por ejemplo, 'corregir el error tipográfico en la línea 42', 'cambiar el nombre de esta variable').
