Prüfen Sie Designdokumente auf fehlende Entscheidungen, Kompatibilitätsrisiken, Rollout-Lücken und Observability-Versäumnisse. Verwenden Sie diese Option immer dann, wenn der Benutzer ein Entwurfsdokument, einen Architekturvorschlag, einen umsetzungsbezogenen Entwurf, einen Plan oder eine an das Design angrenzende Markdown-Datei auf Vollständigkeit, Migrationsstrategie, Rollback, Datenverarbeitung oder vorgeschlagene Ergänzungen überprüfen möchte, ohne das Dokument direkt zu bearbeiten. Wird auch bei kurzen Anfragen wie „review <file>.md“ oder „audit <file>.md“ ausgelöst, wenn das Ziel wie ein Entwurf, ein Plan, eine Architektur, ein Vorschlag oder ein Entscheidungsdokument aussieht.
