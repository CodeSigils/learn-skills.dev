Refine un árbol de diseño existente hasta que las ramas clave estén listas para su implementación. Úselo cuando la estructura de alto nivel ya existe pero las ramas importantes siguen siendo vagas, superficiales o sin resolver. Se activa cuando el usuario necesita una descomposición más profunda, cobertura de casos extremos, aclaración de rutas de falla, detalles de interfaz o criterios de validación para un sistema parcialmente diseñado. No lo utilice para crear el esqueleto de diseño inicial desde cero ni para comparar opciones para un único nodo de decisión explícito.
