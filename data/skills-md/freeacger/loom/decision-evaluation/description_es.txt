Evalúe opciones para un nodo de decisión de diseño específico y recomiende uno con compensaciones explícitas. Utilícelo cuando el diseño ya expone una elección concreta, como estilo de arquitectura, enfoque de gestión de estado, modelo de autenticación, patrón de almacenamiento, estrategia de sincronización o modelo de coordinación de múltiples agentes. Se activa cuando el usuario necesita una comparación y recomendación estructuradas para una decisión de diseño acotada. No lo utilice para un descubrimiento amplio de diseños, una descomposición de todo el sistema o una revisión final de la preparación.
