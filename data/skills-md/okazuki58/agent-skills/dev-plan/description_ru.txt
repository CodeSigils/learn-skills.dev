Навык, который автоматически генерирует коллекции подсказок выполнения для параллельной разработки кода Claude (docs/prompts/xxx.md) из группы задач GitHub.
Запускается такими запросами, как «создать план разработки», «создать подсказки к выполнению», «составить план разработки», «создать коллекцию подсказок» или «настроить параллельный план разработки».
Принимает список номеров проблем, интерактивно определяет волновые структуры зависимостей и создает инструкции для каждой проблемы для всего конвейера: /gtr-workflow → реализация → /e2e-test → /pull-request.
