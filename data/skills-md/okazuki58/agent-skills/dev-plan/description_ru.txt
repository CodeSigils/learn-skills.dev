Навык автоматического создания коллекций запросов на выполнение для параллельной разработки с использованием кода Claude из групп задач GitHub (docs/prompts/xxx.md).  
Запускается такими запросами, как «создать план разработки», «создать подсказки к выполнению», «составить план разработки», «создать коллекцию подсказок» или «настроить параллельный план разработки».  
Принимает список номеров проблем, в интерактивном режиме определяет структуру зависимостей Wave и создает последовательность команд для каждой проблемы: /gtr-workflow → реализация → /e2e-test → /pull-request.
