Una habilidad que genera automáticamente colecciones de mensajes de ejecución para el desarrollo paralelo con Claude Code de los grupos de problemas de GitHub (docs/prompts/xxx.md).  
Activado por solicitudes como "crear un plan de desarrollo", "generar indicaciones de ejecución", "hacer un plan de desarrollo", "crear una colección de indicaciones" o "configurar un plan de desarrollo paralelo".  
Acepta una lista de números de problemas, determina interactivamente estructuras de oleadas de dependencia y produce instrucciones por problema para la secuencia /gtr-workflow → implementación → /e2e-test → /pull-request.
