GitHub Issue グループ (docs/prompts/xxx.md) の Claude Code を使用した並列開発用の実行プロンプト コレクションを自動的に生成するスキル。  
「開発計画の作成」、「実行プロンプトの生成」、「開発計画の作成」、「プロンプト コレクションの構築」、または「並行開発計画のセットアップ」などのリクエストによってトリガーされます。  
問題番号のリストを受け入れ、Wave の依存関係構造を対話的に決定し、問題ごとに一連のコマンド (/gtr-workflow →implementation → /e2e-test → /pull-request) を生成します。
