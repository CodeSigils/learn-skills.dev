Eine Fähigkeit, GitHub-Probleme aus groben Anforderungen oder Gedankenmemos zu generieren.
Ausgelöst durch Anfragen wie „Ein Problem erstellen“, „Ein Problem erstellen“, „Ein Problem einreichen“ oder „Dies in ein Problem umwandeln“.
Extrahiert Anforderungen aus Texteingaben oder angehängten Dateien und erstellt ein strukturiertes Problem.
Errät keine nicht spezifizierten Spezifikationen; fragt den Benutzer nach unklaren Punkten.
