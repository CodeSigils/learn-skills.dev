مهارة لتوليد مشكلات GitHub من المتطلبات التقريبية أو مذكرات التفكير.
يتم تشغيلها من خلال طلبات مثل "إنشاء مشكلة" أو "إنشاء مشكلة" أو "تقديم مشكلة" أو "تحويل هذا إلى مشكلة".
استخراج المتطلبات من إدخال النص أو الملفات المرفقة وإنشاء مشكلة منظمة.
لا يخمن المواصفات غير المحددة؛ يسأل المستخدم عن نقاط غير واضحة.
