Un'abilità per generare problemi GitHub da requisiti approssimativi o promemoria di pensiero.
Attivato da richieste come "Crea un problema", "Crea un problema", "Invia un problema" o "Trasforma questo in un problema".
Estrae i requisiti dall'input di testo o dai file allegati e crea un problema strutturato.
Non specula su requisiti non specificati; chiede chiarimenti all'utente quando necessario.
