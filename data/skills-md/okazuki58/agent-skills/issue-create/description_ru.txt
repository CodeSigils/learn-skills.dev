Навык генерировать проблемы GitHub на основе грубых требований или мысленных заметок.
Запускается такими запросами, как «Создать проблему», «Создать проблему», «Сообщить о проблеме» или «Превратить это в проблему».
Извлекает требования из текстового ввода или прикрепленных файлов и создает структурированную задачу.
Не угадывает неуказанные характеристики; спрашивает пользователя о неясных моментах.
