Умение генерировать проблемы GitHub на основе грубых требований или заметок.
Запускается такими запросами, как «Создать задачу», «Создать задачу», «Сообщить о проблеме» или «Превратить это в задачу».
Извлекает требования из текстового ввода или прикрепленных файлов и создает структурированную задачу.
Не угадывает неуказанные характеристики; спрашивает пользователя о неясных моментах.
