Una habilidad para generar problemas de GitHub a partir de requisitos aproximados o notas de pensamiento.
Activado por solicitudes como "Crear un problema", "Crear un problema", "Presentar un problema" o "Convertir esto en un problema".
Extrae requisitos de entradas de texto o archivos adjuntos y crea una edición estructurada.
No adivina especificaciones no especificadas; pregunta al usuario sobre puntos poco claros.
