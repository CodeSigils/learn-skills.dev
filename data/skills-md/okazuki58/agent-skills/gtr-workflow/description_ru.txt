Руководство по рабочему процессу Git Worktree Runner (gtr) для параллельной разработки с помощью Claude Code. Используйте, когда пользователь спрашивает о рабочих деревьях git, параллельной разработке ИИ, запуске нескольких сеансов Claude, управлении рабочими деревьями с помощью gtr или настройке изолированных сред разработки для работы с функциями.
