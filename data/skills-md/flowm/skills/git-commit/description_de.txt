Verwenden Sie diese Option für jede Anfrage zum Aufzeichnen von Arbeit als Git-Commit, egal wie beiläufig oder indirekt der Wortlaut ist – „commit“, „die Änderungen festschreiben“, „git commit“, „/commit“, „in Git speichern“, „alles bereitstellen und committen“ oder ein Commit, das durch eine größere Aufgabe impliziert wird („das abschließen und committen“). Leiten Sie Commits immer über diesen Skill weiter, anstatt „git commit“ direkt auszuführen, daher verwendet die Nachricht das konventionelle Commits-Format mit dem Assisted-by-Trailer.
