À utiliser pour toute demande d'enregistrement d'un travail en tant que commit git, aussi simple ou indirect soit-il - "commit", "valider les modifications", "git commit", "/commit", "enregistrer ceci dans git", "tout mettre en scène et valider", ou un commit impliqué par une tâche plus importante ("envelopper ceci et valider"). Acheminez toujours les commits via cette compétence plutôt que d'exécuter `git commit` directement, de sorte que le message utilise le format Conventional Commits avec la bande-annonce Assisted-by.
