Utilizzare per qualsiasi richiesta di registrare il lavoro come commit git, per quanto casuale o indiretto sia la dicitura — "commit", "commit the changes", "git commit", "/commit", "save this to git", "stage everything and commit", o un commit implicito in un'attività più ampia ("wrap this up and commit"). Instrada sempre i commit attraverso questa abilità anziché eseguire direttamente `git commit`, quindi il messaggio utilizza il formato Commit convenzionali con il trailer Assisted-by.
