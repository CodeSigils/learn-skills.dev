Struttura del progetto predefinita, strumenti e scelte di libreria per le app Web frontend (Vue 3 + Vite + TypeScript + Tailwind, distribuito su Cloudflare Workers). Utilizza questa competenza ogni volta che imposti un nuovo progetto frontend o SPA, aggiungi strumenti a uno (linting, formattazione, test, CI, PWA, distribuzione), ristruttura un repository frontend esistente o decidi quale libreria o modello utilizzare per stato, routing, grafici, stile o logica backend, anche se l'utente non richiede esplicitamente "la struttura predefinita".
