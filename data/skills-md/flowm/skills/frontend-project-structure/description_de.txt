Standardprojektstruktur, Tools und Bibliotheksoptionen für Frontend-Webanwendungen (Vue 3 + Vite + TypeScript + Tailwind, bereitgestellt für Cloudflare Workers). Verwenden Sie diese Fähigkeit immer dann, wenn Sie das Gerüst für ein neues Frontend-Projekt oder SPA erstellen, einem Tooling hinzufügen (Linting, Formatierung, Tests, CI, PWA, Bereitstellung), ein vorhandenes Frontend-Repo umstrukturieren oder entscheiden, welche Bibliothek oder welches Muster für Status, Routing, Diagramme, Stil oder Backend-Logik verwendet werden soll – auch wenn der Benutzer nicht explizit nach der „Standardstruktur“ fragt.
