Структура проекта по умолчанию, инструменты и выбор библиотек для веб-приложений внешнего интерфейса (Vue 3 + Vite + TypeScript + Tailwind, развернутые в Cloudflare Workers). Используйте этот навык при создании нового внешнего проекта или SPA, добавлении к нему инструментов (линтинг, форматирование, тестирование, CI, PWA, развертывание), реструктуризации существующего внешнего репозитория или принятии решения, какую библиотеку или шаблон использовать для состояния, маршрутизации, диаграмм, стилей или внутренней логики — даже если пользователь явно не запрашивает «структуру по умолчанию».
