خيارات بنية المشروع والأدوات والمكتبة الافتراضية لتطبيقات الويب الأمامية (Vue 3 + Vite + TypeScript + Tailwind، المنشورة على Cloudflare Workers). استخدم هذه المهارة عند دعم مشروع واجهة أمامية جديد أو SPA، أو إضافة أدوات إلى أحدهما (الفحص، أو التنسيق، أو الاختبار، أو CI، أو PWA، أو النشر)، أو إعادة هيكلة مستودع الواجهة الأمامية الحالي، أو تحديد المكتبة أو النمط الذي سيتم استخدامه للحالة أو التوجيه أو المخططات أو التصميم أو منطق الواجهة الخلفية - حتى إذا لم يطلب المستخدم صراحةً "البنية الافتراضية".
