Structure de projet par défaut, outils et choix de bibliothèques pour les applications Web frontales (Vue 3 + Vite + TypeScript + Tailwind, déployés sur Cloudflare Workers). Utilisez cette compétence chaque fois que vous élaborez un nouveau projet front-end ou SPA, que vous ajoutez des outils à un projet (peluchage, formatage, test, CI, PWA, déploiement), que vous restructurez un dépôt front-end existant ou que vous décidez quelle bibliothèque ou modèle utiliser pour l'état, le routage, les graphiques, le style ou la logique back-end - même si l'utilisateur ne demande pas explicitement « la structure par défaut ».
