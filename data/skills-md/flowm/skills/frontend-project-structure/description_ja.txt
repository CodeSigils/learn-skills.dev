フロントエンド Web アプリのデフォルトのプロジェクト構造、ツール、ライブラリの選択 (Vue 3 + Vite + TypeScript + Tailwind、Cloudflare Workers にデプロイ)。新しいフロントエンド プロジェクトまたは SPA をスキャフォールディングするとき、ツール (リンティング、フォーマット、テスト、CI、PWA、デプロイメント) を追加するとき、既存のフロントエンド リポジトリを再構築するとき、または状態、ルーティング、チャート、スタイル、またはバックエンド ロジックに使用するライブラリまたはパターンを決定するときは、ユーザーが明示的に「デフォルトの構造」を要求していない場合でも、このスキルを使用してください。
