Opciones predeterminadas de estructura de proyecto, herramientas y biblioteca para aplicaciones web frontend (Vue 3 + Vite + TypeScript + Tailwind, implementadas en Cloudflare Workers). Utilice esta habilidad siempre que cree un nuevo proyecto frontend o SPA, agregue herramientas a uno (linting, formateo, pruebas, CI, PWA, implementación), reestructure un repositorio frontend existente o decida qué biblioteca o patrón usar para el estado, el enrutamiento, los gráficos, el estilo o la lógica backend, incluso si el usuario no solicita explícitamente "la estructura predeterminada".
