Modelli di runtime del browser Tailwind CSS v4.2 per composizioni HyperFrames. Da utilizzare durante lo scaffolding o la modifica di progetti creati con `hyperframes init --tailwind`, la scrittura di classi di utilità Tailwind nella composizione HTML, l'aggiunta di token del tema Tailwind v4 CSS-first, il debug della sintassi v3 vs v4 o la decisione quando compilare Tailwind in CSS invece di utilizzare il runtime del browser.
