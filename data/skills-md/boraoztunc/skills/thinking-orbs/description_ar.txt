أضف تحميل AI متحركًا ومؤشرات حالة الوكيل التي يمكن الوصول إليها باستخدام مكتبة React Thinking-Orbs. يُستخدم عندما تحتاج واجهة الدردشة أو مساعد الطيار أو الصوت أو البحث أو الإنشاء أو تشغيل الأداة إلى حالة عمل دلالية أو بحث أو حل أو استماع أو تأليف أو تشكيل؛ عند استبدال الدوار العام بجرم نشاط الذكاء الاصطناعي؛ أو عند تنفيذ حجم المكتبة وموضوعها وسرعتها وإيقافها مؤقتًا وانخفاض الحركة وسلوك اللوحة القماشية.
