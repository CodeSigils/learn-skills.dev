Modèles d'adaptateur d'animation CSS pour HyperFrames. À utiliser lors de la création d'images clés CSS, de timing basé sur le délai d'animation, du mode de remplissage d'animation, de l'état de lecture d'animation ou de mouvements CSS uniquement que les HyperFrames doivent rechercher de manière déterministe lors de l'aperçu et du rendu.
