مبادئ هندسة التصميم لجعل الواجهات مصقولة. يُستخدم عند إنشاء مكونات واجهة المستخدم، أو مراجعة كود الواجهة الأمامية، أو تنفيذ الرسوم المتحركة، أو حالات التمرير، أو الظلال، أو الحدود، أو التفاعلات الدقيقة، أو الرسوم المتحركة للدخول/الخروج، أو اختيار الرموز أو مراجعتها، أو أي عمل تفصيلي مرئي. المشغلات في تلميع واجهة المستخدم، وتفاصيل التصميم، "تجعل الأمر يبدو أفضل"، "يشعر بالراحة"، الرسوم المتحركة المتدرجة، انتقالات تبديل السمة، نصف قطر الحدود، المحاذاة البصرية، مخططات الصورة، ظلال المربع، الرموز، وزن ضربة الأيقونات، حالات الأيقونات، تقييد الحركة.
