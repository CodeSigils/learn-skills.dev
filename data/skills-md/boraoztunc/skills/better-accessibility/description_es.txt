Ingeniería de accesibilidad para interfaces de productos, desde estados de enfoque y compatibilidad con teclado hasta ARIA, formularios y lectores de pantalla. Úselo al crear o revisar componentes de la interfaz de usuario, modales, menús, formularios, widgets personalizados o cuando el usuario diga "hacer esto accesible" o informe problemas con el teclado o el lector de pantalla.
