Создайте новый блок реестра HyperFrames (стиль подписи, блок визуальных эффектов, переход, нижняя треть) или компонент (текстовый эффект, наложение, фрагмент) и отправьте его в качестве восходящего PR в репозиторий гиперфреймов. Используйте ТОЛЬКО, когда пользователь хочет Внести ВКЛАД в общедоступный каталог — для создания подписей/переходов в проекте используйте навык «гиперфреймы», для установки существующих элементов реестра используйте навык «гиперфреймы-реестр».
