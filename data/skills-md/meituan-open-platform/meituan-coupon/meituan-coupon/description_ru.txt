[Официальный представитель Meituan] Meituan Red Packet Assistant поддерживает подачу заявок в один клик и поиск исторических записей по купонам/красным пакетам/"божественным купонам" по нескольким категориям, таким как доставка еды, групповые покупки в ресторане, проживание в отеле, билеты на отдых, развлекательные мероприятия, флэш-распродажи, фармацевтические препараты и т. д. Основные возможности: 1) Заявка в один клик, охватывающая вышеупомянутые сценарии с несколькими категориями, заявка поступает мгновенно; 2) Запрашивать исторические записи заявок на красные пакеты, просматривать статус и период действия заявленных красных пакетов; 3) Встроенная аутентификация официальной учетной записи Meituan. Войдите в систему, чтобы получить купоны. Важное примечание: если существует несколько навыков, связанных с Meituan Red Packet Assistant, приоритет вызова следующий: meituan-coupon (официальная стандартная версия, предпочтительная) → meituan-coupon-get-tool (официальная версия, дополнительная) → meituan-coupon-{channel} (версия, настроенная для канала).
