Kuikly UI Framework Development Assistant. Helps with using Kuikly components (View, Text, Button, List, Image, Modal, ActionSheet, Input, Scroller, Tabs, and other UI components) and modules (Router, Network, SP, Notify, and other system modules), automatically providing correct import statements, API usage methods, and complete code examples. Supports both traditional Kuikly DSL (attr/event) and Compose DSL development approaches. Applicable scenarios: Kuikly page development, component usage, layout implementation, event handling, FlexBox layout, responsive state management, animation effects, page routing navigation, network requests, list rendering, custom component/module extension, Kuikly coding issues, KuiklyUI development.
