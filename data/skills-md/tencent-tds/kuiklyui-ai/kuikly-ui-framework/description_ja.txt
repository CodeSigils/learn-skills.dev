Kuikly UI フレームワーク開発アシスタント。 Kuikly コンポーネント (View、Text、Button、List、Image、Modal、ActionSheet、Input、Scroller、Tabs、およびその他の UI コンポーネント) およびモジュール (Router、Network、SP、Notify、およびその他のシステム モジュール) の使用を支援し、正しいインポート ステートメント、API 使用方法、および完全なコード サンプルを自動的に提供します。従来の Kuikly DSL (attr/event) と Compose DSL 開発アプローチの両方をサポートします。該当するシナリオ: Kuikly ページ開発、コンポーネントの使用法、レイアウト実装、イベント処理、FlexBox レイアウト、応答状態管理、アニメーション効果、ページ ルーティング ナビゲーション、ネットワーク リクエスト、リスト レンダリング、カスタム コンポーネント/モジュール拡張機能、Kuikly コーディングの問題、KuiklyUI 開発。
