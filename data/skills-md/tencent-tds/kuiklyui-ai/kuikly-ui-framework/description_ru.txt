Kuikly UI Framework Помощник по разработке. Помогает использовать компоненты Kuikly (View, Text, Button, List, Image, Modal, ActionSheet, Input, Scroller, Tabs и другие компоненты пользовательского интерфейса) и модули (Router, Network, SP, Notify и другие системные модули), автоматически предоставляя правильные операторы импорта, методы использования API и полные примеры кода. Поддерживает как традиционные подходы разработки Kuikly DSL (attr/event), так и Compose DSL. Применимые сценарии: разработка страниц Kuikly, использование компонентов, реализация макета, обработка событий, макет FlexBox, адаптивное управление состоянием, эффекты анимации, навигация по маршрутизации страниц, сетевые запросы, рендеринг списков, расширение пользовательских компонентов/модулей, проблемы с кодированием Kuikly, разработка KuiklyUI.
