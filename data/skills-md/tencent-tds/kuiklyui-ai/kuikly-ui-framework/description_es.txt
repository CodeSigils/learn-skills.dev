Asistente de desarrollo del framework UI de Kuikly. Ayuda con el uso de componentes de Kuikly (Ver, Texto, Botón, Lista, Imagen, Modal, Hoja de acción, Entrada, Desplazador, Pestañas y otros componentes de la interfaz de usuario) y módulos (Enrutador, Red, SP, Notificación y otros módulos del sistema), proporcionando automáticamente declaraciones de importación correctas, métodos de uso de API y ejemplos de código completos. Admite los enfoques de desarrollo tradicionales Kuikly DSL (attr/event) y Compose DSL. Escenarios aplicables: desarrollo de páginas de Kuikly, uso de componentes, implementación de diseño, manejo de eventos, diseño de FlexBox, administración de estado reactivo, efectos de animación, enrutamiento y navegación de páginas, solicitudes de red, representación de listas, extensiones personalizadas de componentes/módulos, problemas de codificación de Kuikly, desarrollo de KuiklyUI.
