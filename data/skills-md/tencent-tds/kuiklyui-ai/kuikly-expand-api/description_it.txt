Assistente allo sviluppo di moduli personalizzati Kuikly. Ti guida attraverso la creazione di moduli personalizzati e l'estensione delle API native. Copre l'intero flusso di lavoro di sviluppo: definizione del modulo lato Kuikly, registrazione Pager/ComposeContainer, implementazioni native specifiche della piattaforma, registrazione del modulo e utilizzo. Usalo quando devi creare moduli personalizzati, estendere API native, abilitare la comunicazione bidirezionale tra Kuikly e Native o implementare la logica sul lato nativo per i moduli su ciascuna piattaforma.
