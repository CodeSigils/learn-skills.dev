Assistente allo sviluppo di moduli personalizzati Kuikly. Guide su come creare moduli personalizzati ed estendere le API native. Copre l'intero processo di sviluppo: definizione del modulo sul lato Kuikly, registrazione del pager/ComposeContainer, implementazione sul lato nativo per ciascuna piattaforma, registrazione del modulo e utilizzo. Utilizzalo quando devi personalizzare i moduli, estendere le API native, implementare la comunicazione bidirezionale tra Kuikly e Native o implementare la logica lato nativo per i moduli su ciascuna piattaforma.
