Kuikly-Assistent für die Entwicklung benutzerdefinierter Module. Führt Sie durch die Erstellung benutzerdefinierter Module und die Erweiterung nativer APIs. Deckt den gesamten Entwicklungsworkflow ab: Kuikly-seitige Moduldefinition, Pager/ComposeContainer-Registrierung, native Implementierungen auf jeder Plattform, Modulregistrierung und Nutzung. Verwenden Sie es immer dann, wenn Sie ein benutzerdefiniertes Modul erstellen, native APIs erweitern, eine bidirektionale Kommunikation zwischen Kuikly und Native ermöglichen oder die native Logik für Ihr Modul auf einer beliebigen Plattform implementieren müssen.
