Kuikly-Assistent für die Entwicklung benutzerdefinierter Module. Führt Sie durch die Erstellung benutzerdefinierter Module und die Erweiterung nativer APIs. Deckt den gesamten Entwicklungsworkflow ab: Kuikly-seitige Moduldefinition, Pager/ComposeContainer-Registrierung, plattformspezifische native Implementierungen, Modulregistrierung und Nutzung. Verwenden Sie es, wenn Sie benutzerdefinierte Module erstellen, native APIs erweitern, eine bidirektionale Kommunikation zwischen Kuikly und Native ermöglichen oder native Logik für Module auf jeder Plattform implementieren müssen.
