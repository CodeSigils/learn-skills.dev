Asistente de desarrollo de módulos personalizados de Kuikly. Le guía a través de la creación de módulos personalizados y la ampliación de las API nativas. Cubre el flujo de trabajo de desarrollo completo: definición de módulo del lado de Kuikly, registro de Pager/ComposeContainer, implementaciones nativas específicas de la plataforma, registro de módulo y uso. Úselo cuando necesite crear módulos personalizados, ampliar las API nativas, habilitar la comunicación bidireccional entre Kuikly y Native o implementar lógica del lado nativo para módulos en cada plataforma.
