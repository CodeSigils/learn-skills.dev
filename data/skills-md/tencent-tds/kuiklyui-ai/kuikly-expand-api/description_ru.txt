Kuikly Помощник по разработке пользовательских модулей. Поможет вам создать собственные модули и расширить собственные API. Охватывает полный рабочий процесс разработки: определение модуля на стороне Kuikly, регистрацию Pager/ComposeContainer, собственные реализации для конкретной платформы, регистрацию модуля и его использование. Используйте его, когда вам нужно создавать собственные модули, расширять собственные API, включать двустороннюю связь между Kuikly и Native или реализовывать собственную логику для модулей на каждой платформе.
