Assistant de développement de modules personnalisés Kuikly. Guide comment créer des modules personnalisés et étendre les API natives. Couvre le flux de travail de développement complet : définition du module côté Kuikly, enregistrement Pager/ComposeContainer, implémentation côté natif pour chaque plate-forme, enregistrement du module et utilisation. À utiliser lorsque les utilisateurs doivent personnaliser les modules, étendre les API natives, implémenter une communication bidirectionnelle entre Kuikly et Native ou implémenter une logique côté natif pour les modules sur diverses plates-formes.
