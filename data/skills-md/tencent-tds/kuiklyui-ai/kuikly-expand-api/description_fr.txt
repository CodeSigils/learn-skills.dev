Assistant de développement de modules personnalisés Kuikly. Vous guide dans la création de modules personnalisés et l’extension des API natives. Couvre le flux de travail de développement complet : définition du module côté Kuikly, enregistrement Pager/ComposeContainer, implémentations natives spécifiques à la plate-forme, enregistrement du module et utilisation. Utilisez-le lorsque vous avez besoin de créer des modules personnalisés, d'étendre les API natives, d'activer une communication bidirectionnelle entre Kuikly et Native ou d'implémenter une logique côté natif pour les modules sur chaque plate-forme.
