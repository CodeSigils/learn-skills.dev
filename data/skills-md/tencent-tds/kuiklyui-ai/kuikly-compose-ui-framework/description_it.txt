Kuikly Compose Assistente allo sviluppo del framework DSL. Aiuta nello sviluppo dell'interfaccia utente multipiattaforma utilizzando la sintassi Kuikly Compose DSL, fornendo metodi di utilizzo corretti ed esempi di codice completi per API come componenti Compose, modificatore, animazioni, gesti, gestione dello stato, navigazione, ViewModel e altro ancora. Scenari applicabili: sviluppo della pagina Kuikly Compose, utilizzo del componente Compose, implementazione del layout Compose, effetti di animazione Compose, gestione dello stato Compose, routing della navigazione Compose: utilizza questa competenza quando scrivi il codice Kuikly Compose. Se è necessario utilizzare il tradizionale Kuikly DSL (sintassi attr/event), utilizzare la competenza kuikly‑ui‑framework.
