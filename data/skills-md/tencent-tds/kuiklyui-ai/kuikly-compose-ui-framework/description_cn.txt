Kuikly Compose DSL 框架开发助手。它有助于使用 Kuikly Compose DSL 语法进行跨平台 UI 开发，为 Compose 组件、Modifier、动画、手势、状态管理、导航、ViewModel 等 API 提供正确的使用方法和完整的代码示例。适用场景：Kuikly Compose 页面开发、Compose 组件使用、Compose 布局实现、Compose 动画效果、Compose 状态管理、Compose 导航路由——在编写 Kuikly Compose 代码时使用此技能。如果您需要使用传统的 Kuikly DSL（attr/event 语法），请使用 kuikly-ui-framework 技能。
