Kuikly Compose — помощник по разработке инфраструктуры DSL. Он помогает при разработке кросс-платформенного пользовательского интерфейса с использованием синтаксиса Kuikly Compose DSL, предоставляя правильные методы использования и полные примеры кода для таких API, как компоненты Compose, модификатор, анимация, жесты, управление состоянием, навигация, ViewModel и многое другое. Применимые сценарии: разработка страницы Kuikly Compose, использование компонентов Compose, реализация макета Compose, эффекты анимации Compose, управление состоянием Compose, маршрутизация навигации Compose — используйте этот навык при написании кода Kuikly Compose. Если вам нужно использовать традиционный Kuikly DSL (синтаксис attr/event), используйте навык kuikly-ui-framework.
