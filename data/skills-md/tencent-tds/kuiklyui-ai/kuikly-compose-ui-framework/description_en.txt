Kuikly Compose DSL framework development assistant. It helps with cross‑platform UI development using the Kuikly Compose DSL syntax, providing correct usage methods and complete code examples for APIs such as Compose components, Modifier, animations, gestures, state management, navigation, ViewModel, and more. Applicable scenarios: Kuikly Compose page development, Compose component usage, Compose layout implementation, Compose animation effects, Compose state management, Compose navigation routing—use this skill when writing Kuikly Compose code. If you need to use the traditional Kuikly DSL (attr/event syntax), please use the kuikly‑ui‑framework skill.
