Assistant de développement du framework Kuikly Compose DSL. Il facilite le développement d'interface utilisateur multiplateforme à l'aide de la syntaxe Kuikly Compose DSL, en fournissant des méthodes d'utilisation correctes et des exemples de code complets pour les API telles que les composants Compose, le modificateur, les animations, les gestes, la gestion de l'état, la navigation, ViewModel, etc. Scénarios applicables : développement de pages Kuikly Compose, utilisation des composants Compose, implémentation de la mise en page Compose, effets d'animation Compose, gestion de l'état Compose, routage de navigation Compose : utilisez cette compétence lors de l'écriture du code Kuikly Compose. Si vous devez utiliser le Kuikly DSL traditionnel (syntaxe attr/event), veuillez utiliser la compétence kuikly‑ui‑framework.
