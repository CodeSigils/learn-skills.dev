Kuikly Compose DSL 框架開發助手。它有助於使用 Kuikly Compose DSL 語法進行跨平台 UI 開發，為 Compose 元件、Modifier、動畫、手勢、狀態管理、導航、ViewModel 等 API 提供正確的使用方法和完整的程式碼範例。適用情境：Kuikly Compose 頁面開發、Compose 元件使用、Compose 佈局實作、Compose 動畫效果、Compose 狀態管理、Compose 導航路由－在編寫 Kuikly Compose 程式碼時使用此技能。如果您需要使用傳統的 Kuikly DSL（attr/event 語法），請使用 kuikly-ui-framework 技能。
