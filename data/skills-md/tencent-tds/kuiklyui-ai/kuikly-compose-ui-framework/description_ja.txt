Kuikly Compose DSL フレームワーク開発アシスタント。 Kuikly Compose DSL 構文を使用したクロスプラットフォーム UI 開発を支援し、Compose コンポーネント、モディファイア、アニメーション、ジェスチャ、状態管理、ナビゲーション、ViewModel などの API の正しい使用方法と完全なコード サンプルを提供します。該当するシナリオ: Kuikly Compose ページの開発、Compose コンポーネントの使用、Compose レイアウトの実装、Compose アニメーション効果、Compose 状態管理、Compose ナビゲーション ルーティング - Kuikly Compose コードを作成するときにこのスキルを使用します。従来の Kuikly DSL (attr/event 構文) を使用する必要がある場合は、kuikly-ui-framework スキルを使用してください。
