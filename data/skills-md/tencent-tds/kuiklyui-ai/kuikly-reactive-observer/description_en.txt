Kuikly Responsive Update and Directive System Development Assistant (Kuikly DSL). Guides how to use observable, observableList, and observableSet to implement UI responsive updates, and the correct usage of directives such as vfor, vforIndex, vforLazy, vif, velseif, velse, and vbind. Use this when users need the following scenarios in Kuikly: (1) Declaring responsive fields and binding them to UI properties (2) List rendering (vfor/vforIndex/vforLazy) (3) Conditional rendering (vif/velseif/velse) (4) Value binding rendering (vbind) (5) Efficient list updates (diffUpdate) (6) Troubleshooting issues where responsive data doesn't take effect or UI doesn't update (7) Add, delete, and modify operations for observableList/observableSet (8) Responsive update strategies for complex objects
