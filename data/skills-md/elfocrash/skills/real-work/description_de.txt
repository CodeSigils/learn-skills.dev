Verwenden Sie diese Funktion, wenn Sie eine mehrstufige Aufgabe planen oder im Planmodus arbeiten und den Plan als dauerhaftes, wiederaufnehmbares Artefakt erfassen müssen – indem Sie die Arbeit in Phasen mit Kontrollkästchen pro Element, Abschlussverfolgung, autonomer Überprüfung und einer Übergabezusammenfassung aufteilen, damit ein zukünftiger Agent dort weitermachen kann, wo Sie aufgehört haben. Verwenden Sie diese Option, wenn der Benutzer einen Plan erstellen oder entwerfen möchte oder „echte Arbeit“ erwähnt.
