Eine auf yt-dlp und gallery-dl basierende Fähigkeit zum Herunterladen von Materialien, die Hunderte von Websites wie YouTube, Bilibili, Vimeo, ArtStation und mehr abdeckt. Wenn ein Benutzer einen Video- oder Bildlink bereitstellt und einen Download anfordert, muss dieser Skill verwendet werden – einschließlich, aber nicht beschränkt auf, Phrasen wie „Laden Sie dieses Video herunter“, „Laden Sie dies herunter“, „Helfen Sie mir, das herunterzuladen“, „Download-Link“, „Speichern Sie dieses Video“, „Laden Sie B-Site herunter“, „Laden Sie dieses YouTube herunter“, „ArtStation-Download“, „Laden Sie dieses Projekt herunter“, „Laden Sie ein Video herunter“, „Helfen Sie mir, etwas herunterzuladen“ usw. Der Skill übernimmt automatisch die Auswahl der Auflösung (fragt den Benutzer, ob über 1080p), Time-Point-Slicing lädt Downloads herunter und organisiert ArtStation-Projekte nach Benutzername/Projektname. gallery-dl wird speziell für Bildgalerie-Sites (ArtStation, Pixiv, DeviantArt usw.) verwendet. Immer wenn der Benutzer eine URL angibt, die einen Download beinhaltet, sollte dieser Fähigkeit Vorrang eingeräumt werden.
