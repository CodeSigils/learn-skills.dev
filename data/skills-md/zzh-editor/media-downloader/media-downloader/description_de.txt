Eine auf yt-dlp und gallery-dl basierende Fähigkeit zum Herunterladen von Medien, die Hunderte von Websites wie YouTube, Bilibili, Vimeo, ArtStation usw. abdeckt. Wenn ein Benutzer einen Video-/Bildlink bereitstellt und einen Download anfordert, muss diese Fähigkeit verwendet werden – einschließlich, aber nicht beschränkt auf Phrasen wie: „Laden Sie dieses Video herunter“, „Holen Sie sich das“, „Hilf mir, das herunterzuladen“, „Download-Link“, „Speichern Sie dieses Video“, „Laden Sie Bilibili herunter“, „Laden Sie dieses YouTube herunter“, „Laden Sie ArtStation herunter“, „Laden Sie dies herunter“. „Projekt“, „Laden Sie ein Video herunter“, „Hilf mir, etwas herunterzuladen“ usw. Der Skill übernimmt automatisch die Auswahl der Auflösung (fragt den Benutzer, ob mehr als 1080p), den Download in Zeitsegmente und organisiert ArtStation-Projekte nach Benutzername/Projektname. gallery-dl wird speziell zum Herunterladen von Bildgalerieseiten (ArtStation, Pixiv, DeviantArt usw.) verwendet. Immer wenn ein Benutzer eine URL angibt und die Aktion einen Download beinhaltet, sollte dieser Fähigkeit Vorrang eingeräumt werden.
