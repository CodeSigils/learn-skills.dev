Una habilidad de descarga de material basada en yt-dlp y gallery-dl que cubre cientos de sitios como YouTube, Bilibili, Vimeo, ArtStation y más. Cuando un usuario proporciona un enlace de video o imagen y solicita una descarga, se debe usar esta habilidad, que incluye, entre otras, frases como "descargar este video", "descargar esto", "ayúdame a descargar esto", "enlace de descarga", "guarda este video", "descarga el sitio B", "descarga este YouTube", "descarga de ArtStation", "descarga este proyecto", "descarga un video", "ayúdame a descargar algo", etc. La habilidad maneja automáticamente la selección de resolución (pregunta al usuario si es superior a 1080p). descargas de división de puntos de tiempo y organiza proyectos de ArtStation por nombre de usuario/nombre de proyecto. gallery-dl se utiliza específicamente para sitios de galerías de imágenes (ArtStation, Pixiv, DeviantArt, etc.). Siempre que el usuario proporcione una URL que implique una descarga, se debe dar prioridad a esta habilidad.
