Capacidad de descarga de material basada en yt-dlp y gallery-dl, que cubre cientos de sitios como YouTube, Bilibili, Vimeo, ArtStation, etc. Cuando un usuario proporciona un enlace de video/imagen y solicita una descarga, se debe usar esta capacidad, incluidas, entre otras, frases como: "descargar este video", "tomar esto", "ayúdame a descargar esto", "enlace de descarga", "guardar este video", "descargar Bilibili", "descargar este YouTube", "descargar ArtStation", "descargar esto". proyecto”, “descargar un video”, “ayúdame a descargar algo”, etc. La capacidad maneja automáticamente la selección de resolución (pregunta al usuario si es superior a 1080p), descargas de división de puntos de tiempo y organiza proyectos de ArtStation por nombre de usuario/nombre de proyecto. gallery-dl se dedica a descargar sitios de galerías de imágenes (ArtStation, Pixiv, DeviantArt, etc.). Siempre que un usuario proporciona una URL que implica una descarga, se debe dar prioridad a esta capacidad.
