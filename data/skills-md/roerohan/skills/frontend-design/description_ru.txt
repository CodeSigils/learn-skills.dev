React-ориентированные принципы UI/UX проектирования для фронтенд-разработки. Охватывает шаблоны React, архитектуру компонентов, хуки, макет, типографику, цвет, доступность и адаптивный дизайн. Используйте при создании пользовательского интерфейса React, просмотре кода внешнего интерфейса, проектировании компонентов или принятии решений по визуальному обеспечению/взаимодействию. Предполагается React с мета-фреймворком (TanStack Start, Next.js, Remix и т. д.).
