Principios de diseño UI/UX orientados a React para el desarrollo frontend. Cubre patrones de React, arquitectura de componentes, ganchos, diseño, tipografía, color, accesibilidad y diseño responsivo. Úselo al crear la interfaz de usuario de React, revisar el código de interfaz, diseñar componentes o tomar decisiones visuales/de interacción. Asume React con un metamarco (TanStack Start, Next.js, Remix, etc.).
