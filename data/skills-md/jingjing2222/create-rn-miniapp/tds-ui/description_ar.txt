مهارة اتخاذ القرار لاختيار مكونات TDS React Native وحدود واجهة المستخدم في شاشات MiniApp. يُستخدم عند ترجمة متطلبات المنتج إلى مكونات TDS، أو التوفيق بين المستندات العامة والصادرات الفعلية، أو تحديد أنماط الحالة الخاضعة للرقابة/غير الخاضعة للرقابة. لا تستخدم لتصميم المسار، أو البحث عن القدرات، أو عمل الموفر/وقت التشغيل، أو قرارات الوحدة الأصلية غير التابعة لـ TDS.
