Навыки принятия решений по выбору компонентов TDS React Native и границ пользовательского интерфейса на экранах MiniApp. Используйте при переводе требований к продукту в компоненты TDS, согласовании общедоступных документов с фактическим экспортом или определении шаблонов контролируемого/неконтролируемого состояния. Не используйте для проектирования маршрутов, поиска возможностей, работы поставщика/среды выполнения или решений, не относящихся к собственным модулям TDS.
