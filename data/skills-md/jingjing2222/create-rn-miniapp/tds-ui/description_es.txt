Habilidad de decisión para elegir componentes TDS React Native y límites de UI en pantallas de MiniApp. Úselo al traducir los requisitos del producto en componentes TDS, conciliar documentos públicos con exportaciones reales o decidir patrones estatales controlados/no controlados. No lo utilice para diseño de rutas, búsqueda de capacidades, trabajo de proveedor/tiempo de ejecución ni decisiones de módulos nativos que no sean TDS.
