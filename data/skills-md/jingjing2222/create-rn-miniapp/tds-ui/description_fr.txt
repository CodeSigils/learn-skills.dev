Compétence décisionnelle pour choisir les composants TDS React Native et les limites de l'interface utilisateur dans les écrans MiniApp. À utiliser pour traduire les exigences du produit en composants TDS, rapprocher les documents publics avec les exportations réelles ou décider des modèles d'état contrôlés/non contrôlés. Ne pas utiliser pour la conception d'itinéraires, la recherche de capacités, le travail de fournisseur/d'exécution ou les décisions de modules natifs non TDS.
