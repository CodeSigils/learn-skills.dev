CodeStable: структура для понимания эволюции программного обеспечения (видение/спецификация проекта/эпическая/проблема+CodeStable/институциональная память), которая действует в соответствии с текущим положением пользователя — обсуждение, быстрые изменения, управляемая реализация, исправление ошибок, организация видения/спецификации, понимание текущего состояния, закрытие/подведение итогов, проверка по требованию.  

Триггеры: cs, CodeStable, сначала обсуждение/уточнение, быстрое/быстрое изменение/начало немедленно, прокол, исправление ошибки/отладка, организация видения/спецификации, закрытие/подведение итогов, обзор, «как работает эта система», проект уже имеет CodeStable и обрабатывает закрытие реализации видения/спецификации.  

Вызов CS не означает запуск всего процесса: сначала оцените осанку, затем действуйте. Инициализируйте CodeStable только тогда, когда пользователь явно запрашивает это.
