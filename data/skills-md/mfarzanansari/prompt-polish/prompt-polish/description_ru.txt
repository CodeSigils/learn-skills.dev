Перепишите черновую подсказку в отточенную подсказку для конкретной модели, основанную на официальных руководствах по подсказкам Anthropic. Используйте, когда пользователь вызывает подсказку-полировку, вводит вызов типа «подсказка-полировка/FABLE 5/[подсказка]» или «подсказка-полировка/OPUS 4.8/[подсказка]» или просит отполировать, улучшить, переписать, оптимизировать или настроить подсказку для именованной модели («сделайте эту подсказку лучше для Fable 5», «настройте это для Opus»). Поддерживает Claude Fable 5 и Claude Opus 4.8 (Opus 4.7 направляет к руководству 4.8). Если проект подсказки не предоставлен, попросите его, а не придумывайте его.
