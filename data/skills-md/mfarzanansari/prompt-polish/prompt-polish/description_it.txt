Riscrivi un suggerimento approssimativo in un suggerimento raffinato, specifico per il modello, basato sulle guide ufficiali sui suggerimenti antropici. Da utilizzare quando l'utente richiama prompt-polish, digita un'invocazione come "prompt-polish/FABLE 5/[prompt]" o "prompt-polish/OPUS 4.8/[prompt]" o chiede di rifinire, migliorare, riscrivere, ottimizzare o mettere a punto un prompt per un modello denominato ("rendi migliore questo prompt per Fable 5", "ottimizza questo per Opus"). Supporta Claude Fable 5 e Claude Opus 4.8 (dall'Opus 4.7 alla guida 4.8). Se non viene fornita alcuna bozza di suggerimento, chiedila invece di inventarne una.
