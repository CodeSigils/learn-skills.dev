Conventions et rendu pour les diagrammes d'architecture/spécifications proofo. Utilisez cette compétence chaque fois que vous travaillez sous un répertoire `_spec/` ; création ou édition de diagrammes PlantUML (`.puml`), Mermaid (`.mmd`/`.mermaid`) ou Vega-Lite (`.vega.json`) ; ajouter ou maintenir les références sources `// SPEC:` / `# SPEC:` ; ou lorsque l'utilisateur pose des questions sur les conventions des diagrammes proofo, la palette/thème de couleurs de l'identité proofo, les stéréotypes de rôle, les flèches sémantiques ou comment valider et restituer les diagrammes. Couvre la livraison de thèmes hybrides (Inclure PlantUML à distance + thèmes Mermaid/Vega fournis dans `_spec/themes/`), le cycle de vie de référence SPEC et le rendu natif avec `plantuml`, `mmdc` et `vl2svg`.
