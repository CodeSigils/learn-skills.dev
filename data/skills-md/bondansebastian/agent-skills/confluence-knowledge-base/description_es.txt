Guía para crear y mantener una base de conocimientos de Confluence específica del producto donde todos los equipos comparten conocimientos sobre el producto, características, decisiones y conocimientos del cliente en un lenguaje sencillo. Utilice SIEMPRE esta habilidad cuando el usuario solicite CUALQUIER operación de Confluence: crear páginas, documentar funciones, configurar estructuras, administrar reglas comerciales o actualizar contenido. Úselo tanto para páginas individuales como para arquitectura de espacio completo. La base de conocimientos está centrada en el producto, puede contener reglas comerciales relacionadas con el producto y debe ser accesible para los equipos de diseño, ingeniería, ventas y soporte.
