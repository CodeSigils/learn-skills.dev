Assistant d'environnement de développement UiPath : authentification, gestion d'Orchestrator (dossiers, actifs, files d'attente, compartiments de stockage), cycle de vie de la solution (pack, publication, déploiement), service d'intégration, gestion des ressources, Test Manager, outils CLI et connaissances générales de la plate-forme UiPath. DÉCLENCHEMENT lorsque : l'utilisateur pose des questions sur les opérations de la plateforme UiPath (authentification, Orchestrator, dossiers, ressources, robots, files d'attente, packages, processus, compartiments de stockage) ; L'utilisateur pose des questions sur le cycle de vie de la solution (pack, publication, déploiement, activation) ; Références utilisateurs Integration Service (connecteurs, connexions, activités, ressources) ; L'utilisateur souhaite gérer les ressources (actifs, files d'attente, éléments de file d'attente, compartiments de stockage, fichiers de compartiment) ; L'utilisateur souhaite utiliser Test Manager (projets, ensembles de tests, cas de test, exécutions, résultats, rapports) ; L'utilisateur souhaite utiliser les commandes uip CLI ; L'utilisateur pose des questions sur la configuration de l'environnement, les informations d'identification ou la configuration du locataire ; L'utilisateur pose des questions générales sur la plateforme UiPath (dossiers, robots, files d'attente, déclencheurs, politiques machine). NE PAS DÉCLENCHER lorsque : L'utilisateur écrit ou modifie le code du flux de travail (utilisez plutôt uipath-coded-workflows ou uipath-rpa-workflows) ou demande comment automatiser une tâche spécifique dans un flux de travail.
