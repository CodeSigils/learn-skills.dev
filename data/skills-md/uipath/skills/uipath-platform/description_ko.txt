UiPath 개발 환경 도우미 - 인증, Orchestrator 관리(폴더, 자산, 대기열, 스토리지 버킷), 솔루션 라이프사이클(팩, 게시, 배포), 통합 서비스, 리소스 관리, 테스트 관리자, CLI 도구 및 일반 UiPath 플랫폼 지식. 트리거 시기: 사용자가 UiPath 플랫폼 작업(인증, Orchestrator, 폴더, 자산, 로봇, 대기열, 패키지, 프로세스, 스토리지 버킷)에 대해 질문합니다. 사용자가 솔루션 수명 주기(패킹, 게시, 배포, 활성화)에 대해 질문합니다. 사용자 참조 통합 서비스(커넥터, 연결, 활동, 리소스) 사용자는 리소스(자산, 큐, 큐 항목, 스토리지 버킷, 버킷 파일)를 관리하려고 합니다. 사용자는 Test Manager(프로젝트, 테스트 세트, 테스트 케이스, 실행, 결과, 보고서)를 사용하기를 원합니다. 사용자가 uip CLI 명령을 사용하려고 합니다. 사용자가 환경 설정, 자격 증명 또는 테넌트 구성에 대해 질문합니다. 사용자가 일반적인 UiPath 플랫폼 질문(폴더, 로봇, 대기열, 트리거, 시스템 정책)을 묻습니다. 다음의 경우에는 트리거하지 마십시오: 사용자가 워크플로 코드를 작성 또는 편집하거나(대신 uipath-coded-workflows 또는 uipath-rpa-workflows 사용) 워크플로 내에서 특정 작업을 자동화하는 방법을 묻는 경우.
