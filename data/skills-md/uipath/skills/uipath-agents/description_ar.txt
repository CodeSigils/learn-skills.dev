العمل الشامل مع وكلاء UiPath بجميع أنواعهم: الإنشاء والتكامل مع منتجات UiPath (على سبيل المثال، Orchestrator وFlow وMaestro)، والتصميم باستخدام أدوات UiPath (على سبيل المثال، Agent Builder/Studio Web)، والنشر والتكوين/التحقق من الصحة. يغطي الوكلاء المشفرين (على سبيل المثال، LangGraph وLlamaIndex وOpenAI Agents) والوكلاء ذوي التعليمات البرمجية المنخفضة (`agent.json` / Agent Builder). بالنسبة لوظائف Python المشفرة الحتمية (`وظائف uip`، خريطة وظائف `uipath.json`، لا يوجد وقت تشغيل وكيل/LLM) → وظائف uipath.
