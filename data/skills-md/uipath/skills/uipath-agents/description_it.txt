Lavora end-to-end con agenti UiPath di tutti i tipi: crea, integra con i prodotti UiPath (ad esempio Orchestrator, Flow, Maestro), progetta con gli strumenti UiPath (ad esempio Agent Builder/Studio Web), distribuisci e configura/convalida. Copre gli agenti codificati (ad esempio, LangGraph, LlamaIndex, agenti OpenAI) e gli agenti low-code (`agent.json` / Agent Builder). Per le funzioni deterministiche codificate Python ("funzioni uip", mappa delle funzioni "uipath.json", nessun runtime agente/LLM) → funzioni uipath.
