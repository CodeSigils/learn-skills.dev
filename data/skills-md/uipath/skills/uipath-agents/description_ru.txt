Комплексная работа с агентами UiPath всех типов: сборка, интеграция с продуктами UiPath (например, Orchestrator, Flow, Maestro), проектирование с помощью инструментов UiPath (например, Agent Builder/Studio Web), развертывание и настройка/проверка. Охватывает агенты с кодированным кодом (например, LangGraph, LlamaIndex, агенты OpenAI) и агенты с низким кодом («agent.json» / Agent Builder). Для детерминированных функций, закодированных на Python (функции uip, карта функций uipath.json, без среды выполнения агента/LLM) → uipath-functions.
