Enquête causale UiPath sur chaque produit, environnement d'exécution et package d'activités. À utiliser lorsque le résultat principal est une explication, un diagnostic ou la cause première d'un comportement existant indésirable : pannes, blocages, régressions, ralentissements, perte d'accès, changements d'état inattendus, résultats erronés ou vides, non-opérations silencieuses ou erreurs brutes. L'intention de diagnostic surpasse la propriété de surface pour le comportement d'exécution ; invoquez même lorsque l'invite nomme uniquement une tâche, un dossier, un élément de file d'attente, un connecteur, une connexion, une activité, une trace, un flux, un agent ou une autre ressource et qu'une autre compétence UiPath fournit des commandes d'inspection. Met en corrélation le temps d'exécution, la configuration, l'historique et les preuves sources pour trouver l'erreur d'origine et la corriger. Pour les ressources d'exploitation sans enquête causale → uipath-platform ; pour appliquer un correctif source connu → le propriétaire de l'artefact ; pour les erreurs de construction/CLI d'un artefact local (pack, build, validation, liaisons) → la compétence de l'artefact.
