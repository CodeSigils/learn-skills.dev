Boîte à outils de bout en bout pour les applications Web codées UiPath : authentifier, pousser/extraire le code source vers Studio Web, empaqueter dans .nupkg, publier sur Orchestrator et déployer. DÉCLENCHEMENT lorsque : L'utilisateur souhaite créer, créer, pousser, extraire, compresser, publier ou déployer une application Web codée UiPath ; L'utilisateur mentionne les applications codées, les applications Web codées, codedapp, l'application Web dans un contexte UiPath ; L'utilisateur pose des questions sur la transmission du code vers Studio Web, l'empaquetage d'une application Web, la publication d'un fichier .nupkg, le déploiement d'une application codée ; L'utilisateur pose des questions sur les commandes CLI uip codedapp, le répertoire .uipath, app.config.json ou le cycle de vie du projet d'application codée. NE PAS DÉCLENCHER lorsque : L'utilisateur travaille avec des agents codés (Python — utilisez plutôt des agents codés uipath) ; L'utilisateur travaille avec des flux de travail codés (fichiers .cs – utilisez plutôt les flux de travail codés uipath) ; L'utilisateur travaille avec des workflows XAML/RPA (utilisez plutôt uipath-rpa-workflows) ; L'utilisateur pose des questions sur la gestion d'Orchestrator sans contexte d'application codé (utilisez plutôt uipath-platform).
