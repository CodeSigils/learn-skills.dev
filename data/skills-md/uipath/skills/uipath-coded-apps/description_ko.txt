UiPath 코딩 웹 애플리케이션을 위한 엔드투엔드 툴킷: 인증, Studio 웹에 소스 코드 푸시/풀, .nupkg로 패키징, Orchestrator에 게시 및 배포. 트리거 시기: 사용자가 UiPath 코딩 웹 앱을 생성, 빌드, 푸시, 가져오기, 압축, 게시 또는 배포하려고 합니다. 사용자가 UiPath 컨텍스트에서 코딩된 앱, 코딩된 웹 앱, 코딩된 앱, 웹 애플리케이션을 언급합니다. 사용자가 Studio Web에 코드 푸시, 웹 앱 패키징, .nupkg 게시, 코딩된 앱 배포에 대해 질문합니다. 사용자가 uip codedapp CLI 명령, .uipath 디렉터리, app.config.json 또는 코딩된 앱 프로젝트 수명 주기에 대해 질문합니다. 다음과 같은 경우에는 트리거하지 마십시오. 사용자가 코딩된 에이전트로 작업 중입니다(Python — 대신 uipath-coded-agents 사용). 사용자가 코딩된 워크플로(.cs 파일 - 대신 uipath-coded-workflows 사용)로 작업 중입니다. 사용자가 XAML/RPA 워크플로로 작업 중입니다(대신 uipath-rpa-workflows 사용). 사용자가 코딩된 앱 컨텍스트 없이 Orchestrator 관리에 대해 질문합니다(대신 uipath-platform 사용).
