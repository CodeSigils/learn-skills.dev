TRIGGER, wenn: Der Benutzer möchte eine UiPath-codierte Web-App erstellen, erstellen, pushen, ziehen, packen, veröffentlichen oder bereitstellen; Der Benutzer erwähnt codierte Apps, codierte Web-Apps, codierte Apps und Webanwendungen in einem UiPath-Kontext. Der Benutzer fragt nach dem Übertragen von Code an Studio Web, dem Packen einer Web-App, dem Veröffentlichen einer .nupkg-Datei und dem Bereitstellen einer codierten App. Der Benutzer fragt nach uip-codierten App-CLI-Befehlen, dem .uipath-Verzeichnis, app.config.json oder dem Lebenszyklus eines codierten App-Projekts. NICHT AUSLÖSEN, wenn: Der Benutzer mit codierten Agenten arbeitet (Python – stattdessen uipath-coded-agents verwenden); Der Benutzer arbeitet mit codierten Workflows (.cs-Dateien – verwenden Sie stattdessen uipath-coded-workflows); Der Benutzer arbeitet mit XAML/RPA-Workflows (verwenden Sie stattdessen uipath-rpa-workflows); Der Benutzer fragt nach der Orchestrator-Verwaltung ohne codierten App-Kontext (verwenden Sie stattdessen uipath-platform).
