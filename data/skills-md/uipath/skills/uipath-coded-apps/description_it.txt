Toolkit end-to-end per applicazioni Web codificate UiPath: autenticazione, push/pull del codice sorgente in Studio Web, creazione di pacchetti in .nupkg, pubblicazione in Orchestrator e distribuzione. ATTIVA quando: l'utente desidera creare, costruire, inviare, estrarre, comprimere, pubblicare o distribuire un'app Web codificata UiPath; L'utente menziona app codificate, app Web codificate, codedapp, applicazione Web in un contesto UiPath; L'utente chiede informazioni sull'invio del codice a Studio Web, sul confezionamento di un'app Web, sulla pubblicazione di un file .nupkg, sulla distribuzione di un'app codificata; L'utente chiede informazioni sui comandi CLI di uip codedapp, sulla directory .uipath, su app.config.json o sul ciclo di vita del progetto dell'app codificata. NON ATTIVARE quando: l'utente sta lavorando con agenti codificati (Python: utilizzare invece uipath-coded-agents); L'utente sta lavorando con flussi di lavoro codificati (file .cs: utilizzare invece flussi di lavoro codificati uipath); L'utente sta lavorando con flussi di lavoro XAML/RPA (utilizza invece uipath-rpa-workflows); L'utente chiede informazioni sulla gestione dell'orchestrator senza contesto dell'app codificato (usa invece la piattaforma uipath).
