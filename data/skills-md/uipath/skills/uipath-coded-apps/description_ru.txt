Комплексный набор инструментов для веб-приложений с кодом UiPath: проверка подлинности, передача исходного кода в Studio Web, упаковка в .nupkg, публикация в Orchestrator и развертывание. ТРИГГЕР, когда: Пользователь хочет создать, собрать, отправить, получить, упаковать, опубликовать или развернуть веб-приложение с кодом UiPath; Пользователь упоминает закодированные приложения, закодированные веб-приложения, закодированные приложения, веб-приложения в контексте UiPath; Пользователь спрашивает об отправке кода в Studio Web, упаковке веб-приложения, публикации .nupkg, развертывании закодированного приложения; Пользователь спрашивает о командах CLI uip codedapp, каталоге .uipath, app.config.json или жизненном цикле проекта закодированного приложения. НЕ СРАБАТЫВАЙТЕ, когда: Пользователь работает с закодированными агентами (Python — вместо этого используйте uipath-coded-agents); Пользователь работает с закодированными рабочими процессами (файлы .cs — вместо этого используйте рабочие процессы с кодировкой uipath); Пользователь работает с рабочими процессами XAML/RPA (вместо этого используйте uipath-rpa-workflows); Пользователь спрашивает об управлении Orchestrator без закодированного контекста приложения (вместо этого используйте uipath-платформу).
