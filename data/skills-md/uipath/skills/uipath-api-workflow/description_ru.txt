Помощник по рабочим процессам UiPath API — создание, запуск, упаковка и публикация рабочих процессов JSON, выполняемых с помощью `uip api-workflow run`. Охватывает логическую/иерархическую структуру (Sequence, Assign, JavaScript, If with #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response — включая вложенные шаблоны) И действия соединителя HTTP/службы интеграции (Gmail, Outlook, GitHub, Slack и т. д.), созданные с помощью `uip api-workflow Registry Resolve` + `stub`. Запускается по запросам о рабочих процессах API UiPath, типе проекта «Api», файлах рабочих процессов JSON, содержащих `document.dsl`/`do[]`, любом из этих типов действий или получении данных из общедоступного API или API поставщика. Использует uip api-workflow run для локального выполнения и uip Solution Pack/publish для развертывания. Для .flow Maestro→uipath-maestro-flow. Для .xaml/coded RPA→uipath-rpa. Для закодированных агентов→uipath-агенты. Для закодированных приложений → приложения с кодировкой uipath.
