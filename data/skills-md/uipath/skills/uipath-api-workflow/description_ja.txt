UiPath API ワークフロー アシスタント — 「uip api-workflow run」によって実行される JSON ワークフローの作成、実行、パッケージ化、公開を行います。論理/階層構造 (Sequence、Assign、JavaScript、If with #Wrapper/#Then/#Else、ForEach、Dowhile、Break、TryCatch、Wait、Response — ネストされたパターンを含む) および「uip api-workflow registrysolve」 + `stub` によって作成された HTTP / Integration Service コネクタ アクティビティ (Gmail、Outlook、GitHub、Slack など) をカバーします。 UiPath API ワークフロー、プロジェクト タイプ「Api」、`document.dsl`/`do[]` を含む JSON ワークフロー ファイル、これらのアクティビティ タイプのいずれか、またはパブリック/ベンダー API からのデータ取得に関するプロンプトでトリガーされます。ローカル実行には「uip api-workflow run」を使用し、デプロイには「uip solution Pack」/「publish」を使用します。 .flow Maestro→uipath-maestro-flowの場合。 .xaml/コード化された RPA の場合→uipath-rpa。コード化されたエージェントの場合は、→「uipath-agents」。コード化されたアプリの場合→uipath-coded-apps。
