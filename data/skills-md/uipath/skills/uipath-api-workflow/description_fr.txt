Assistant UiPath API Workflow — créer, exécuter, empaqueter et publier des workflows JSON exécutés par « uip api-workflow run ». Couvre la structure logique/hiérarchique (Sequence, Assign, JavaScript, If with #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response — y compris les modèles imbriqués) ET les activités du connecteur HTTP/Integration Service (Gmail, Outlook, GitHub, Slack, etc.) créées via `uip api-workflow Registry solve` + `stub`. Se déclenche sur des invites concernant les workflows de l'API UiPath, le type de projet "Api", les fichiers de workflow JSON contenant `document.dsl`/`do[]`, l'un de ces types d'activité ou la récupération de données à partir d'une API publique/fournisseur. Utilise `uip api-workflow run` pour l'exécution locale et `uip solution pack`/`publish` pour le déploiement. Pour .flow Maestro → uipath-maestro-flow. Pour .xaml/coded RPA → uipath-rpa. Pour les agents codés → agents uipath. Pour les applications codées → applications codées uipath.
