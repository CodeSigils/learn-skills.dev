UiPath API 工作流程助手 — 创建、运行、打包、发布由“uip api-workflow run”执行的 JSON 工作流程。涵盖逻辑/分层结构（Sequence、Assign、JavaScript、If with #Wrapper/#Then/#Else、ForEach、DoWhile、Break、TryCatch、Wait、Response — 包括嵌套模式）以及通过“uip api-workflow 注册表解析”+“存根”编写的 HTTP/集成服务连接器活动（Gmail、Outlook、GitHub、Slack 等）。在有关 UiPath API 工作流程、项目类型“Api”、包含“document.dsl”/“do[]”的 JSON 工作流程文件、任何这些活动类型或从公共/供应商 API 获取数据的提示时触发。使用“uip api-workflow run”进行本地执行，使用“uip解决方案包”/“publish”进行部署。对于.flow Maestro→uipath-maestro-flow。对于.xaml/编码的RPA→uipath-rpa。对于编码代理→uipath-agents。对于编码应用程序→uipath-coded-apps。
