Asistente de flujo de trabajo API de UiPath: cree, ejecute, empaquete y publique flujos de trabajo JSON ejecutados por "uip api-workflow run". Cubre la estructura lógica/jerárquica (Secuencia, Asignación, JavaScript, If with #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response, incluidos patrones anidados) Y actividades del conector HTTP/Servicio de integración (Gmail, Outlook, GitHub, Slack, etc.) creadas a través de `uip api-workflow registro resolve` + `stub`. Se activa cuando se muestran mensajes sobre flujos de trabajo de la API de UiPath, tipo de proyecto "Api", archivos de flujo de trabajo JSON que contienen `document.dsl`/`do[]`, cualquiera de esos tipos de actividad o la obtención de datos de una API pública/proveedor. Utiliza `uip api-workflow run` para la ejecución local y `uip solution pack`/`publish` para la implementación. Para .flow Maestro → uipath-maestro-flow. Para .xaml/RPA codificada → uipath-rpa. Para agentes codificados → agentes uipath. Para aplicaciones codificadas → aplicaciones codificadas uipath.
