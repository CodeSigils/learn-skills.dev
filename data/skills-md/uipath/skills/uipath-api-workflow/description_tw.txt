UiPath API 工作流程助理 — 建立、執行、打包、發布由「uip api-workflow run」執行的 JSON 工作流程。涵蓋邏輯/分層結構（Sequence、Assign、JavaScript、If with #Wrapper/#Then/#Else、ForEach、DoWhile、Break、TryCatch、Wait、Response — 包括巢狀模式）以及透過「uip api-workflow 註冊表解析」+「存根」編寫的 HTTP/整合服務器。在有關 UiPath API 工作流程、專案類型「Api」、包含「document.dsl」/「do[]」的 JSON 工作流程檔案、任何這些活動類型或從公共/供應商 API 取得資料的提示時觸發。使用“uip api-workflow run”進行本地執行，使用“uip解決方案包”/“publish”進行部署。對於.flow Maestro→uipath-maestro-flow。對於.xaml/編碼的RPA→uipath-rpa。對於編碼代理→uipath-agents。對於編碼應用程式→uipath-coded-apps。
