Assistente flusso di lavoro API UiPath: crea, esegui, crea pacchetti e pubblica flussi di lavoro JSON eseguiti da "uip api-workflow run". Copre la struttura logica/gerarchica (Sequenza, Assegna, JavaScript, If con #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response, inclusi i modelli nidificati) E le attività del connettore HTTP/Integration Service (Gmail, Outlook, GitHub, Slack, ecc.) create tramite "uip api-workflow Registry Resolve" + "stub". Si attiva su prompt relativi a flussi di lavoro API UiPath, tipo di progetto "Api", file di flussi di lavoro JSON contenenti `document.dsl`/`do[]`, uno qualsiasi di questi tipi di attività o recupero di dati da un'API pubblica/fornitore. Utilizza `uip api-workflow run` per l'esecuzione locale e `uip solution pack`/`publish` per la distribuzione. Per .flow Maestro→uipath-maestro-flow. Per .xaml/coded RPA→uipath-rpa. Per agenti codificati→agenti uipath. Per le app codificate → app codificate uipath.
