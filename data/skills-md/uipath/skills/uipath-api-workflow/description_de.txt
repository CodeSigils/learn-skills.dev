UiPath API-Workflow-Assistent – ​​Erstellen, Ausführen, Packen und Veröffentlichen von JSON-Workflows, die von „uip api-workflow run“ ausgeführt werden. Deckt die logische/hierarchische Struktur (Sequenz, Zuweisen, JavaScript, If mit #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response – einschließlich verschachtelter Muster) UND HTTP-/Integrationsdienst-Connector-Aktivitäten (Gmail, Outlook, GitHub, Slack usw.) ab, die über „uip api-workflow Registry Resolution“ + „Stub“ erstellt wurden. Wird bei Eingabeaufforderungen zu UiPath-API-Workflows, zum Projekttyp „Api“, zu JSON-Workflowdateien mit „document.dsl“/„do[]“, zu einem dieser Aktivitätstypen oder zum Abrufen von Daten von einer öffentlichen/Anbieter-API ausgelöst. Verwendet „uip api-workflow run“ für die lokale Ausführung und „uip Solution Pack“/„publish“ für die Bereitstellung. Für .flow Maestro→uipath-maestro-flow. Für .xaml/codiertes RPA→uipath-rpa. Für codierte Agenten→uipath-agents. Für codierte Apps→uipath-coded-apps.
