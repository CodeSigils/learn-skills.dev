مساعد سير عمل UiPath API - المؤلف، والتشغيل، والحزم، ونشر سير عمل JSON الذي يتم تنفيذه بواسطة "uip api-workflow run". يغطي البنية المنطقية/الهرمية (Sequence، Assign، JavaScript، If with #Wrapper/#Then/#Else، ForEach، DoWhile، Break، TryCatch، Wait، Response - بما في ذلك الأنماط المتداخلة) وأنشطة موصل خدمة HTTP / التكامل (Gmail، Outlook، GitHub، Slack، وما إلى ذلك) التي تم تأليفها عبر `uip api-workflowregister` + `stub`. تشغيل المطالبات المتعلقة بسير عمل UiPath API، أو نوع المشروع "Api"، أو ملفات سير عمل JSON التي تحتوي على `document.dsl`/`do[]`، أو أي من أنواع الأنشطة تلك، أو جلب البيانات من واجهة برمجة التطبيقات العامة/الموردة. يستخدم "تشغيل سير عمل uip api" للتنفيذ المحلي و"حزمة حلول uip"/"النشر" للنشر. لـ .flow Maestro → uipath-maestro-flow. بالنسبة إلى .xaml/المشفر RPA → uipath-rpa. بالنسبة للوكلاء المشفرين → uipath-agents. للتطبيقات المشفرة → تطبيقات uipath-coded.
