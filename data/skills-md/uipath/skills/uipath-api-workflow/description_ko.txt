UiPath API 워크플로 도우미 — `uip api-workflow run`에 의해 실행되는 JSON 워크플로를 작성, 실행, 패키징, 게시합니다. 논리적/계층적 구조(시퀀스, 할당, JavaScript, If with #Wrapper/#Then/#Else, ForEach, DoWhile, Break, TryCatch, Wait, Response - 중첩 패턴 포함) 및 'uip api-workflow Registrysolve' + 'stub'을 통해 작성된 HTTP/Integration Service 커넥터 활동(Gmail, Outlook, GitHub, Slack 등)을 다룹니다. UiPath API 워크플로, 프로젝트 유형 "Api", `document.dsl`/`do[]`가 포함된 JSON 워크플로 파일, 이러한 활동 유형 또는 공개/공급업체 API에서 데이터 가져오기에 대한 프롬프트에서 트리거됩니다. 로컬 실행에는 `uip api-workflow run`을 사용하고 배포에는 `uip Solution Pack`/`publish`를 사용합니다. .flow Maestro→uipath-maestro-flow의 경우. .xaml/코딩된 RPA→uipath-rpa의 경우. 코딩된 에이전트의 경우→uipath-agents. 코딩된 앱의 경우→uipath-coded-apps.
