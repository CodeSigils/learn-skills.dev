Amministrazione UiPath tramite `uip admin`: server identità (utenti, gruppi, account robot, app OAuth2 esterne, segreti), autorizzazione (ruoli personalizzati, assegnazioni di ruoli, catalogo autorizzazioni, accesso effettivo tramite PDP di controllo accesso), OMS (lettura/aggiornamento organizzazione, ciclo di vita tenant, provisioning dei servizi, regioni, polling delle operazioni asincrone), restrizione IP (lista consentita, cambio di applicazione, regole di bypass, sicurezza di blocco), controllo (origini eventi, query impaginate, esportazioni giornaliere di cartelle JSON o singoli CSV (cronologia degli accessi, dump di conformità, chi ha fatto cosa, quando e dove su una risorsa). Risoluzione dei problemi: diagnosticare l'accesso negato, indagare sugli errori di accesso, sulla configurazione errata del ruolo, sul blocco IP, sui problemi di autenticazione PAT/app. Per ruoli/autorizzazioni/cartelle/processi specifici dell'orchestrator → piattaforma uipath. Per flussi di lavoro RPA→uipath-rpa.
