Администрирование UiPath через uip admin — сервер идентификации (пользователи, группы, учетные записи роботов, внешние приложения OAuth2, секреты), авторизация (настраиваемые роли, назначение ролей, каталог разрешений, эффективный доступ через PDP проверки доступа), OMS (чтение/обновление организации, жизненный цикл клиента, предоставление услуг, регионы, опрос асинхронных операций), ограничение IP-адресов (список разрешений, принудительное переключение, правила обхода, безопасность блокировки), аудит (источники событий, разбиение на страницы) запросы, экспорт по дням в формате JSON или одиночный CSV — история входов в систему, дампы соответствия, данные «кто, что, когда и где на ресурсе»). Устранение неполадок: диагностируйте отказ в доступе, исследуйте ошибки входа в систему, неправильную настройку ролей, блокировку IP-адреса, проблемы с аутентификацией PAT/приложения. Для ролей/разрешений/папок/заданий, специфичных для Оркестратора, → uipath-платформа. Для рабочих процессов RPA → uipath-rpa.
