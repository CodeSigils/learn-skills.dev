'uip admin'을 통한 UiPath 관리 — ID 서버(사용자, 그룹, 로봇 계정, 외부 OAuth2 앱, 비밀), 승인(사용자 정의 역할, 역할 할당, 권한 카탈로그, 액세스 확인 PDP를 통한 유효 액세스), OMS(조직 읽기/업데이트, 테넌트 수명 주기, 서비스 프로비저닝, 지역, 비동기 작업 폴링), IP 제한(허용 목록, 적용 스위치, 우회 규칙, 잠금 안전), 감사(이벤트 소스, 페이지가 매겨진 쿼리, day-wise-JSON-folder 또는 단일 CSV 내보내기 — 로그인 기록, 규정 준수 덤프, 누가 리소스에서 무엇을 했는지, 언제 어디서 했는지). 문제 해결: 액세스 거부 진단, 로그인 실패, 역할 구성 오류, IP 잠금, PAT/앱 인증 문제 조사. Orchestrator 관련 역할/권한/폴더/작업의 경우→uipath-platform. RPA 워크플로의 경우→uipath-rpa.
