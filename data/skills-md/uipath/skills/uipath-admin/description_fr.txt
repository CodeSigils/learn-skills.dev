Administrateur UiPath via « uip admin » — Serveur d'identité (utilisateurs, groupes, comptes robots, applications OAuth2 externes, secrets), autorisation (rôles personnalisés, attributions de rôles, catalogue d'autorisations, accès effectif via PDP de vérification d'accès), OMS (lecture/mise à jour de l'organisation, cycle de vie des locataires, fourniture de services, régions, interrogation des opérations asynchrones), restriction IP (liste verte, commutateur d'application, règles de contournement, sécurité de verrouillage), audit (sources d'événements, requêtes paginées, exportations de dossiers JSON journaliers ou CSV uniques : historique de connexion, vidages de conformité, qui a fait quoi, quand et où sur une ressource). Dépannage : diagnostiquer les accès refusés, enquêter sur les échecs de connexion, la mauvaise configuration des rôles, le verrouillage IP, les problèmes d'authentification PAT/application. Pour les rôles/autorisations/dossiers/travaux spécifiques à Orchestrator → uipath-platform. Pour les workflows RPA → uipath-rpa.
