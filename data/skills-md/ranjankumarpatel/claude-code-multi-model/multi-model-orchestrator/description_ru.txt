Руководство по оркестрации Opus для делегирования полномочий между Codex (Sonnet/Haiku), облаком Ollama, NVIDIA NIM, NVIDIA Security и Codex. Автозапускается при любой нетривиальной задаче — планировании, кодировании, рефакторинге, обзоре, исследовании, аудите, отладке, многофайловой работе. Гарантирует, что планы Opus + синтезируются и никогда не выполняются напрямую; разветвление к исполнителю с наименьшими возможностями, распараллеливание независимой работы, проверка Кодекса перед слиянием.
