دليل تشغيل تنسيق Opus للتفويض عبر Codex (Sonnet/Haiku)، وOllama cloud، وNVIDIA NIM، وNVIDIA Security، وCodex. يتم التشغيل تلقائيًا في أي مهمة غير تافهة - التخطيط، والترميز، وإعادة البناء، والمراجعة، والبحث، والتدقيق، وتصحيح الأخطاء، والعمل متعدد الملفات. يضمن تجميع خطط Opus وعدم تنفيذها بشكل مباشر أبدًا؛ التوزيع الشامل للمنفذ الأقل قدرة، وموازاة العمل المستقل، ومراجعة الدستور الغذائي قبل الدمج.
