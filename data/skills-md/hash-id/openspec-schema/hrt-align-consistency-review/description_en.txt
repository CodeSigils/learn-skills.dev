Cross-artifact consistency review for OpenSpec's hash schema — checks discovery.md, proposal.md, specs/**/*.md, design.md, and tasks.md are mutually consistent and faithful to the requirements, BEFORE any code is written. One cycle is an ALIGN pass (HIGH/MEDIUM/LOW severity, MECHANICAL/DECISION resolution tagging), a fresh-context VERIFY pass that re-checks ALIGN's own findings and fixes, then a human WALKTHROUGH — one generic question per round covering the full artifact list; any walkthrough feedback re-enters ALIGN. Uncapped — exits only on a clean walkthrough round or explicit user sign-off. Use during the hash schema's `align` phase.
