Проверка согласованности между артефактами для хеш-схемы OpenSpec — проверяет, что Discover.md, Offer.md, specs/**/*.md, design.md и Tasks.md взаимно согласованы и соответствуют требованиям ДО написания любого кода. Один цикл — это проход ALIGN (ВЫСОКАЯ/СРЕДНЯЯ/НИЗКАЯ серьезность, маркировка разрешения МЕХАНИЧЕСКИХ/РЕШЕНИЙ), проход VERIFY со свежим контекстом, который повторно проверяет собственные выводы и исправления ALIGN, затем ПРОХОЖДЕНИЕ человеком — один общий вопрос за раунд, охватывающий полный список артефактов; любая обратная связь по прохождению снова входит в ALIGN. Без ограничений — выход осуществляется только после полного прохождения или явного выхода пользователя из системы. Используйте на этапе выравнивания хэш-схемы.
