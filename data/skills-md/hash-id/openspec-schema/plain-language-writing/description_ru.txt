Два набора правил письма для читателей, которые не могут бегло читать по-английски: COMMS для живого текста, передаваемого агентом пользователю (вопросы для интервью, подтверждения, блокировщики), ARTIFACT для постоянной прозы артефактов (discovery.md, Offer.md, specs, design.md). Вызывающий абонент сообщает, какой набор применяется. Доказательства находятся в docs/research/2026-08-07-plain-language-non-native-readers.md.
