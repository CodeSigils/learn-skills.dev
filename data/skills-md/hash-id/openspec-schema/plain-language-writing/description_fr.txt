Deux ensembles de règles d'écriture pour les lecteurs qui ne lisent pas couramment l'anglais : COMMS pour le texte en direct entre l'agent et l'utilisateur (questions d'entretien, confirmations, bloqueurs), ARTIFACT pour la prose d'artefacts persistants (discovery.md, proposition.md, spécifications, design.md). Un appelant indique quel ensemble s'applique. Les preuves se trouvent dans docs/research/2026-08-07-plain-lingual-non-native-readers.md.
