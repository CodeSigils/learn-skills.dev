Paso de autoría con revisión adversarial para un solo artefacto OpenSpec: un subagente redacta el artefacto, dos subagentes adicionales lo revisan en contextos frescos y aislados sin visibilidad del razonamiento del autor (un Crítico Destructivo para contenido/lógica, un Auditor Estructural para formato/rastreabilidad); los hallazgos se resuelven antes de que el artefacto se finalice. Parametrizado según el tipo de artefacto que se está redactando (propuesta, especificaciones o diseño). Utilizar durante las fases `proposal`, `specs` y `design` del esquema tempa-spec.
