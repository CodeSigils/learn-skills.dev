Workflow complet pour la mise à niveau des projets Silverstripe CMS entre les versions majeures de la gamme SS4+ (par exemple SS4 → SS5, SS5 → SS6). Couvre l'évaluation, les mises à jour des dépendances, la migration de la configuration, les tâches de migration des données, les tests et le déploiement. Pour les mises à niveau SS3 → SS4 héritées, utilisez plutôt la compétence silverstripe-3-to-4-upgrade — cette migration est structurellement différente.
