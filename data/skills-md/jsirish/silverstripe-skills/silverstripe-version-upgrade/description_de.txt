Vollständiger Workflow für das Upgrade von Silverstripe CMS-Projekten zwischen Hauptversionen der SS4+-Reihe (z. B. SS4 → SS5, SS5 → SS6). Umfasst Bewertung, Abhängigkeitsaktualisierungen, Konfigurationsmigration, Datenmigrationsaufgaben, Tests und Bereitstellung. Verwenden Sie für ältere SS3 → SS4-Upgrades stattdessen den Silverstripe-3-to-4-Upgrade-Skill – diese Migration ist strukturell anders.
