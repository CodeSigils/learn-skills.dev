Полный рабочий процесс обновления проектов Silverstripe CMS между основными версиями линейки SS4+ (например, SS4 → SS5, SS5 → SS6). Охватывает оценку, обновление зависимостей, миграцию конфигурации, задачи миграции данных, тестирование и развертывание. Для устаревших обновлений SS3 → SS4 вместо этого используйте навык обновления silverstripe-3-to-4 — этот переход структурно отличается.
