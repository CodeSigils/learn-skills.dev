Überprüfen Sie die visuelle Parität zwischen zwei Webumgebungen (Produktion vs. aktualisiert/UAT), indem Sie ganzseitige Screenshots übereinstimmender URLs erfassen und einen Pixel-Diff-HTML-Bericht erstellen. VERWENDEN SIE DIESE FÄHIGKEIT, wann immer ein Agent antworten muss: „Sieht es gleich aus“, „Überprüfen Sie das Upgrade visuell“, „Vergleichen Sie Produkt und UAT“, „Hat sich das Layout geändert“, „Screenshot-Unterschied“, „visuelle Regression“ oder überprüfen Sie, ob ein CMS-Hauptversions-Upgrade (SilverStripe 4→5, Drupal 9→10, größere WordPress-Änderungen) das Front-End nicht beschädigt hat. Eigenständig – bündelt ein Playwright-Erfassungsskript, einen URL-Crawler und einen Pixel-Diff-Berichtsgenerator.
