一致する URL のフルページのスクリーンショットをキャプチャし、ピクセル差分の HTML レポートを作成することで、2 つの Web 環境 (運用環境とアップグレード/UAT) 間の視覚的な同等性を検証します。エージェントが「同じように見えますか」、「アップグレードを視覚的に確認」、「本番環境と UAT を比較」、「レイアウトは変更されましたか」、「スクリーンショットの差分」、「視覚的な回帰」に回答する必要がある場合、または CMS メジャー バージョン アップグレード (SilverStripe 4→5、Drupal 9→10、WordPress のメジャー バンプ) によってフロントエンドが壊れていないことを確認する必要がある場合には、必ずこのスキルを使用してください。自己完結型 — Playwright キャプチャ スクリプト、URL クローラー、ピクセル差分レポート ジェネレーターがバンドルされています。
