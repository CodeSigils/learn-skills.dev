GitBook ドキュメント サイト全体をエンドツーエンドで作成および維持します。ソース コンテンツからサイト構造を設計し、モノリポ レイアウトで Git リポジトリをスキャフォールディングし、GitHub/GitLab リモートをセットアップし、GitBook API を (REST API または MCP サーバー経由で) 操作してサイト/セクション/スペースを作成し、ブランドのカスタマイズを適用し、GitBook がプログラムで公開しない 1 つの UI ステップ (Git Sync ワイヤリング) について明確な指示をユーザーに渡します。ユーザーが新しい GitBook ドキュメント サイトを起動する場合、既存のドキュメント サイトを再構築または拡張する場合、同期のためにスペースを Git リポジトリにリンクする場合、サイトのブランディング (ロゴ、色、フォント、ヘッダー/フッター) を変更する場合、またはプログラムでスペース、セクション、またはサイト スペースを管理する場合は常に、このスキルをトリガーします。このスキルはオーケストレーション層です。個々のページのマークダウン コンテンツの作成については、付随する `write-docs` スキルに委ねられます。
