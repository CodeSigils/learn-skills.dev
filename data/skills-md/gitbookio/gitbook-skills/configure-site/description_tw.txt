端到端建立和維護整個 GitBook 文件網站 — 從來源內容設計網站結構，在 monorepo 佈局中建立 Git 儲存庫，設定 GitHub/GitLab 遠端，驅動 GitBook API（透過其 REST API 或 MCP 伺服器）建立網站/部分/空間，應用程式品牌客製化，並為使用者提供 GitBook 不會以程式設計方式公開的一個同步說明連接的一個清晰說明。每當使用者想要啟動新的 GitBook 文件網站、重組或擴展現有網站、將空間連結到 Git 儲存庫以進行同步、變更網站的品牌（標誌、色彩、字體、頁首/頁尾）或以程式設計方式管理空間、部分或網站空間時，即可觸發此技能。這個技能就是編排層；為了創作任何單一頁面的 Markdown 內容，它遵循配套的「write-docs」技能。
