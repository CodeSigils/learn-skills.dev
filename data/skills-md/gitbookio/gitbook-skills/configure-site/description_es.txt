Cree y mantenga sitios completos de documentación de GitBook de un extremo a otro: diseñe la estructura del sitio a partir del contenido fuente, cree un repositorio Git en diseño monorepo, configure el control remoto de GitHub/GitLab, controle la API de GitBook (a través de su API REST o servidor MCP) para crear el sitio/secciones/espacios, aplique personalización de marca y entregue al usuario instrucciones claras para un paso de la interfaz de usuario (cableado de Git Sync) que GitBook no expone mediante programación. Active esta habilidad cada vez que el usuario desee crear un nuevo sitio de documentos de GitBook, reestructurar o ampliar uno existente, vincular espacios a un repositorio de Git para sincronizarlos, cambiar la marca de un sitio (logotipo, colores, fuentes, encabezado/pie de página) o administrar espacios, secciones o espacios del sitio mediante programación. Esta habilidad es la capa de orquestación; para crear el contenido de rebajas de cualquier página individual, se remite a la habilidad complementaria "write-docs".
