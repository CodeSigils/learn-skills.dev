端到端创建和维护整个 GitBook 文档站点 — 从源内容设计站点结构，在 monorepo 布局中构建 Git 存储库，设置 GitHub/GitLab 远程，驱动 GitBook API（通过其 REST API 或 MCP 服务器）创建站点/部分/空间，应用品牌定制，并为用户提供 GitBook 不会以编程方式公开的一个 UI 步骤（Git 同步连接）的清晰说明。每当用户想要启动新的 GitBook 文档站点、重组或扩展现有站点、将空间链接到 Git 存储库以进行同步、更改站点的品牌（徽标、颜色、字体、页眉/页脚）或以编程方式管理空间、部分或站点空间时，即可触发此技能。这个技能就是编排层；为了创作任何单个页面的 Markdown 内容，它遵循配套的“write-docs”技能。
