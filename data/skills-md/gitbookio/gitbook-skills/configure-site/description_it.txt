Crea e mantieni interi siti di documentazione GitBook end-to-end: progetta la struttura del sito dal contenuto di origine, impalcatura di un repository Git in layout monorepo, configura il telecomando GitHub/GitLab, gestisci l'API GitBook (tramite la sua API REST o il server MCP) per creare il sito/sezioni/spazi, applica la personalizzazione con marchio e fornisci all'utente istruzioni pulite per l'unico passaggio dell'interfaccia utente (cablaggio Git Sync) che GitBook non espone a livello di codice. Attiva questa abilità ogni volta che l'utente desidera creare un nuovo sito di documenti GitBook, ristrutturarne o estenderne uno esistente, collegare spazi a un repository Git per la sincronizzazione, modificare il marchio di un sito (logo, colori, caratteri, intestazione/piè di pagina) o gestire a livello di codice spazi, sezioni o spazi del sito. Questa abilità è il livello di orchestrazione; per creare il contenuto di markdown di ogni singola pagina si rimanda all'abilità complementare "write-docs".
