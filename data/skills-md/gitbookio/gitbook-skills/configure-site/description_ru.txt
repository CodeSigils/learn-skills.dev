Создавайте и обслуживайте целые сайты документации GitBook — спроектируйте структуру сайта на основе исходного контента, создайте репозиторий Git в формате монорепозитория, настройте удаленный GitHub/GitLab, управляйте API GitBook (через его REST API или сервер MCP) для создания сайта/разделов/пространств, применяйте фирменную настройку и передайте пользователю чистые инструкции для одного шага пользовательского интерфейса (подключение Git Sync), которые GitBook не предоставляет программно. Активируйте этот навык всякий раз, когда пользователь хочет развернуть новый сайт документации GitBook, реструктурировать или расширить существующий, связать пространства с репозиторием Git для синхронизации, изменить фирменный стиль сайта (логотип, цвета, шрифты, верхний/нижний колонтитул) или программно управлять пространствами, разделами или пространствами сайта. Этот навык представляет собой уровень оркестровки; для создания уценочного содержимого любой отдельной страницы он поручает сопутствующему навыку `write-docs`.
