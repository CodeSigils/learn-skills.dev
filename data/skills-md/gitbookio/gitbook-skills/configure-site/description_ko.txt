전체 GitBook 문서 사이트를 엔드 투 엔드로 생성 및 유지 관리합니다. 소스 콘텐츠에서 사이트 구조를 설계하고, 모노레포 레이아웃으로 Git 저장소를 스캐폴드하고, GitHub/GitLab 원격을 설정하고, GitBook API를 구동하여(REST API 또는 MCP 서버를 통해) 사이트/섹션/공간을 생성하고, 브랜드 사용자 정의를 적용하고, GitBook이 프로그래밍 방식으로 노출하지 않는 단일 UI 단계(Git 동기화 연결)에 대한 깔끔한 지침을 사용자에게 전달합니다. 사용자가 새로운 GitBook 문서 사이트를 가동하고, 기존 사이트를 재구성 또는 확장하고, 동기화를 위해 공간을 Git 저장소에 연결하고, 사이트의 브랜딩(로고, 색상, 글꼴, 머리글/바닥글)을 변경하거나 프로그래밍 방식으로 공간, 섹션 또는 사이트 공간을 관리하려고 할 때마다 이 기술을 트리거합니다. 이 기술은 오케스트레이션 계층입니다. 개별 페이지의 마크다운 콘텐츠를 작성하려면 'write-docs' 기술이 필요합니다.
