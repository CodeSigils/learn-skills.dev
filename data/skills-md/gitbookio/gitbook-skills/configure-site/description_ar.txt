إنشاء وصيانة مواقع وثائق GitBook بالكامل من البداية إلى النهاية - تصميم بنية الموقع من محتوى المصدر، ودعم مستودع Git في تخطيط monorepo، وإعداد جهاز التحكم عن بعد لـ GitHub/GitLab، وتشغيل واجهة برمجة تطبيقات GitBook (عبر REST API أو خادم MCP) لإنشاء الموقع/الأقسام/المساحات، وتطبيق التخصيص ذي العلامة التجارية، وتسليم المستخدم تعليمات نظيفة لخطوة واجهة المستخدم الواحدة (أسلاك Git Sync) التي لا يكشفها GitBook برمجيًا. قم بتشغيل هذه المهارة عندما يريد المستخدم إنشاء موقع مستندات GitBook جديد، أو إعادة هيكلة موقع حالي أو توسيعه، أو ربط المساحات بمستودع Git للمزامنة، أو تغيير العلامة التجارية للموقع (الشعار، الألوان، الخطوط، الرأس/التذييل)، أو إدارة المسافات أو الأقسام أو مساحات الموقع برمجيًا. هذه المهارة هي طبقة التنسيق؛ لتأليف محتوى تخفيض السعر لأي صفحة فردية، فإنه يخضع لمهارة "كتابة المستندات" المصاحبة.
