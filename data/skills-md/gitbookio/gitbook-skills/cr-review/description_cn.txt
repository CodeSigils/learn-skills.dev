通过直接使用curl（无CLI）调用GitBook REST API来审查来自Claude Code的GitBook更改请求——cr-create的审阅者端伴侣（同一API的创作端）。发现需要审核的变更请求（按打开者、空间或整个组织进行过滤），获取 GitBook 应用程序链接来审核差异，总结 CR 中实际更改的内容，然后留下评论并可选择提交审核结论（批准/请求更改）。每当有人想要通过原始 API (curl/HTTP) 审查文档更改请求、询问“哪些 CR 已打开/等待我/由 <person> 打开”、“向我显示 <space>/<org> 中的更改请求”、“总结此 CR 中的更改内容”、“查看此更改请求”、“在 CR 上留下评论”或“在 CR 上批准/请求更改”时，请使用此选项。对于通过 API 进行创作的方面（创建 CR、推送内容、请求审阅者、修复评论），请改用 cr-create。
