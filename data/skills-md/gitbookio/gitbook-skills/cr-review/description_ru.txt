Просматривайте запросы на изменение GitBook из Claude Code, вызывая REST API GitBook напрямую с помощью Curl (без CLI) — помощника для cr-create на стороне рецензента (сторона автора через тот же API). Найдите запросы на изменения, которые требуют проверки (отфильтруйте по тому, кто их открыл, по пространству или по всей организации), получите ссылку на приложение GitBook, чтобы просмотреть различия, суммируйте, что на самом деле изменилось в запросе на изменение, затем оставьте комментарии и, при необходимости, отправьте вердикт проверки (одобрить/запросить изменения). Используйте это всякий раз, когда кто-то хочет просмотреть запросы на изменение документации через необработанный API (curl/HTTP), спрашивает «какие запросы на изменение открыты/ожидают меня/открыты <человеком>», «покажите мне запросы на изменения в <пространстве>/<org>», «подведите итоги того, что изменилось в этом запросе на изменение», «рассмотрите этот запрос на изменение», «оставьте комментарий к запросу на запрос» или «одобрите/запросите изменения в запросе на изменение». Для авторской стороны (создавайте CR, отправляйте контент, запрашивайте рецензентов, исправляйте комментарии) через API вместо этого используйте cr-create.
