Claude Code からの GitBook 変更リクエストを確認するには、curl (CLI なし) を使用して GitBook REST API を直接呼び出します。これは cr-create (同じ API 上のオーサリング側) に対するレビューア側のコンパニオンです。レビューが必要な変更リクエストを発見し(誰が開いたか、スペースごと、または組織全体でフィルタリング)、GitBookアプリのリンクを取得して差分をレビューし、CRで実際に変更された内容を要約し、コメントを残して、必要に応じてレビュー判定を送信します(変更の承認/リクエスト)。生の API (curl/HTTP) 経由でドキュメントの変更リクエストをレビューしたい場合、「どの CR が開いている / 待機中 / <人> によって開かれたか」、「<スペース>/<組織> の変更リクエストを表示」、「この CR の変更内容を要約」、「この変更リクエストを確認」、「CR にコメントを残す」、または「CR の変更を承認 / リクエスト」する場合に、これを使用します。 API を介したオーサリング側 (CR の作成、コンテンツのプッシュ、レビュー担当者のリクエスト、コメントの修正) の場合は、代わりに cr-create を使用してください。
