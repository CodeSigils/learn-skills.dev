Examinez les demandes de modification GitBook de Claude Code en appelant l'API REST GitBook directement avec curl (pas de CLI) - le compagnon côté réviseur de cr-create (le côté création sur la même API). Découvrez les demandes de modification qui nécessitent un examen (filtrez par qui les a ouvertes, par espace ou dans toute une organisation), obtenez le lien de l'application GitBook pour examiner la différence, résumez ce qui a réellement changé dans un CR, puis laissez des commentaires et éventuellement soumettez un verdict de révision (approuver/demander des modifications). Utilisez-le chaque fois que quelqu'un souhaite examiner les demandes de modification de documents via l'API brute (curl/HTTP), demande « quels CR sont ouverts / m'attendent / ouverts par <personne> », « montre-moi les demandes de modification dans <espace>/<org> », « résumez ce qui a changé dans cette CR », « examinez cette demande de modification », « laissez un commentaire sur une CR » ou « approuvez/demandez des modifications sur une CR ». Pour le côté création (créer un CR, diffuser du contenu, demander des réviseurs, corriger des commentaires) via l'API, utilisez plutôt cr-create.
