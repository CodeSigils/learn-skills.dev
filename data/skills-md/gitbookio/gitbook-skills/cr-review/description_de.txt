Überprüfen Sie GitBook-Änderungsanfragen von Claude Code, indem Sie die GitBook-REST-API direkt mit Curl (kein CLI) aufrufen – dem Begleiter auf der Prüferseite von cr-create (der Autorenseite über dieselbe API). Entdecken Sie die Änderungsanfragen, die überprüft werden müssen (filtern Sie nach demjenigen, der sie geöffnet hat, nach Bereich oder innerhalb einer gesamten Organisation), rufen Sie den GitBook-App-Link ab, um den Unterschied zu überprüfen, fassen Sie zusammen, was sich tatsächlich in einer CR geändert hat, hinterlassen Sie dann Kommentare und geben Sie optional ein Überprüfungsurteil ab (Änderungen genehmigen/anfordern). Verwenden Sie dies immer dann, wenn jemand Änderungsanfragen für Dokumente über die Roh-API (curl/HTTP) überprüfen möchte, fragt: „Welche CRs sind offen/warten auf mich/geöffnet von <Person>“, „Zeigen Sie mir die Änderungsanfragen in <Space>/<org>“, „Zusammenfassen Sie, was sich in dieser CR geändert hat“, „Überprüfen Sie diese Änderungsanfrage“, „Hinterlassen Sie einen Kommentar zu einer CR“ oder „Genehmigen/Anfordern von Änderungen an einer CR“. Verwenden Sie für die Autorenseite (CR erstellen, Inhalte übertragen, Prüfer anfordern, Kommentare korrigieren) über die API stattdessen cr-create.
