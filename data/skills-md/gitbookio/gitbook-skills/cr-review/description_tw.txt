透過直接使用curl（無CLI）呼叫GitBook REST API來審查來自Claude Code的GitBook變更請求－cr-create的審閱者端伴侶（相同API的創作端）。發現需要審核的變更請求（按開啟者、空間或整個組織進行過濾），取得 GitBook 應用程式連結來審核差異，總結 CR 中實際變更的內容，然後留下評論並可選擇提交審核結論（批准/請求變更）。每當有人想要透過原始 API (curl/HTTP) 審查文件變更要求、詢問「哪些 CR 已開啟/等待我/由 <person> 開啟」、「向我顯示 <space>/<org> 中的變更要求」、「總結此 CR 中的變更內容」、「查看此變更請求」、「在 CR 上留下註解」或「在 CR 上留下註解」或「要求對於透過 API 進行創作的方面（建立 CR、推播內容、請求審查者、修復評論），請改用 cr-create。
