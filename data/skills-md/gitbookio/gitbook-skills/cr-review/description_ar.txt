قم بمراجعة طلبات تغيير GitBook من Claude Code عن طريق استدعاء GitBook REST API مباشرةً باستخدام حليقة (بدون واجهة سطر الأوامر) - الرفيق من جانب المراجع لإنشاء cr (جانب التأليف عبر نفس واجهة برمجة التطبيقات). اكتشف طلبات التغيير التي تحتاج إلى مراجعة (قم بالتصفية حسب من فتحها، أو حسب المساحة، أو عبر مؤسسة بأكملها)، واحصل على رابط تطبيق GitBook لمراجعة الاختلافات، ولخص ما تم تغييره بالفعل في الرد الجاهز، ثم اترك التعليقات وأرسل حكم المراجعة بشكل اختياري (الموافقة / طلب التغييرات). استخدم هذا عندما يريد شخص ما مراجعة طلبات تغيير المستندات عبر واجهة برمجة التطبيقات الأولية (curl/HTTP)، ويسأل "ما هي السجلات الجاهزة المفتوحة/المنتظرة لي/المفتوحة بواسطة <person>"، أو "إظهار طلبات التغيير في <space>/<org>"، أو "تلخيص ما تم تغييره في هذا الرد الجاهز"، أو "مراجعة طلب التغيير هذا"، أو "اترك تعليقًا على سجل تجاري"، أو "الموافقة/طلب التغييرات على سجل تجاري". بالنسبة لجانب التأليف (إنشاء رد جاهز، دفع المحتوى، طلب المراجعين، إصلاح التعليقات) عبر واجهة برمجة التطبيقات، استخدم cr-create بدلاً من ذلك.
