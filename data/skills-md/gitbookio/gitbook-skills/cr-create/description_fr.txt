Pilotez un flux de révision de documents GitBook de bout en bout à partir de Claude Code en appelant l'API REST GitBook directement avec curl (pas de CLI) : créez une demande de modification, envoyez du contenu (mettez à jour une page existante ET créez une nouvelle page), demandez des réviseurs, informez Slack, puis récupérez les commentaires de révision, corrigez-les, repoussez et résolvez. Il s'agit du compagnon côté création de cr-review (le côté réviseur sur la même API). Utilisez-le chaque fois que quelqu'un souhaite exécuter une boucle de « révision de documents dans GitBook » à partir du terminal/agent sur l'API brute (curl/HTTP), mentionne la création d'une demande de modification via l'API, pousser le contenu dans un CR, « extraire les derniers commentaires et les corriger », demander une révision des documents ou montrer aux ingénieurs comment collaborer sur les documents GitBook à partir de Claude + Slack sans CLI.
