Управляйте сквозным потоком проверки документов GitBook из Claude Code, вызывая GitBook REST API напрямую с помощью Curl (без CLI) — создайте запрос на изменение, отправьте контент (обновите существующую страницу И создайте новую страницу), запросите рецензентов, уведомите Slack, затем извлеките комментарии рецензии обратно, исправьте их, повторно отправьте и разрешите. Это дополнение к cr-review на стороне автора (сторона рецензента через тот же API). Используйте это всякий раз, когда кто-то хочет запустить цикл «проверки документации в GitBook» из терминала/агента по необработанному API (curl/HTTP), упоминает о создании запроса на изменение через API, отправке контента в CR, «извлекает последние комментарии и исправляет их», запрашивает проверку документации или показывает инженерам, как совместно работать над документами GitBook из Claude + Slack без CLI.
