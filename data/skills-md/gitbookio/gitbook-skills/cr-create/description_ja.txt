Curde (CLI なし) で GitBook REST API を直接呼び出すことにより、Claude Code からエンドツーエンドの GitBook ドキュメント レビュー フローを推進します。変更リクエストの作成、コンテンツのプッシュ (既存のページを更新し、新しいページの作成)、レビュー担当者へのリクエスト、Slack への通知、レビュー コメントの取得、修正、再プッシュ、解決を行います。これは、cr-review のオーサリング側のコンパニオンです (同じ API 上のレビュー担当者側)。生の API (curl/HTTP) に対してターミナル/エージェントから「GitBook でのドキュメント レビュー」ループを実行したい場合、API 経由での変更リクエストの作成、CR へのコンテンツのプッシュ、「最新のコメントを取得して修正する」ことについて言及する場合、ドキュメントのレビューをリクエストする場合、または CLI を使用せずに Claude + Slack から GitBook ドキュメントで共同作業する方法をエンジニアに示す場合、これを使用します。
