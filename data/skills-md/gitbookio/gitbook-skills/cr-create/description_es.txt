Impulse un flujo de revisión de documentos de GitBook de extremo a extremo desde Claude Code llamando a la API REST de GitBook directamente con curl (sin CLI): cree una solicitud de cambio, envíe contenido (actualice una página existente Y cree una nueva página), solicite revisores, notifique a Slack, luego vuelva a incorporar los comentarios de revisión, corríjalos, vuelva a enviarlos y resuélvalos. Este es el complemento del lado de creación de cr-review (el lado del revisor sobre la misma API). Use esto siempre que alguien quiera ejecutar un bucle de "revisión de documentos en GitBook" desde la terminal/agente contra la API sin formato (curl/HTTP), mencione la creación de una solicitud de cambio a través de la API, inserte contenido en un CR, "extraiga los últimos comentarios y corríjalos", solicite una revisión de documentos o muestre a los ingenieros cómo colaborar en documentos de GitBook desde Claude + Slack sin una CLI.
