Fördern Sie einen End-to-End-Überprüfungsfluss für GitBook-Dokumente von Claude Code aus, indem Sie die GitBook-REST-API direkt mit Curl (kein CLI) aufrufen – erstellen Sie eine Änderungsanforderung, übertragen Sie Inhalte (aktualisieren Sie eine vorhandene Seite UND erstellen Sie eine neue Seite), fordern Sie Prüfer an, benachrichtigen Sie Slack, ziehen Sie dann Überprüfungskommentare zurück, korrigieren Sie sie, übertragen Sie sie erneut und lösen Sie sie auf. Dies ist der Begleiter auf der Autorenseite des CR-Reviews (die Reviewer-Seite über dieselbe API). Verwenden Sie dies immer dann, wenn jemand eine „Dokumentüberprüfung in GitBook“-Schleife vom Terminal/Agent gegen die Roh-API (curl/HTTP) ausführen möchte, erwähnt, eine Änderungsanforderung über die API zu erstellen, Inhalte in eine CR zu übertragen, „die neuesten Kommentare einzuholen und zu korrigieren“, eine Überprüfung von Dokumenten anzufordern oder Ingenieuren zu zeigen, wie sie von Claude + Slack aus ohne CLI an GitBook-Dokumenten zusammenarbeiten können.
