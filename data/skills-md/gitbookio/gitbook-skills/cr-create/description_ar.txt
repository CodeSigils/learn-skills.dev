قم بقيادة تدفق مراجعة مستندات GitBook من Claude Code من خلال استدعاء GitBook REST API مباشرةً باستخدام حليقة (بدون واجهة سطر الأوامر) - إنشاء طلب تغيير، ودفع المحتوى (تحديث صفحة موجودة وإنشاء صفحة جديدة)، وطلب المراجعين، وإخطار Slack، ثم سحب تعليقات المراجعة مرة أخرى، وإصلاحها، وإعادة إرسالها، وحلها. هذا هو الرفيق من جانب التأليف لمراجعة cr (جانب المراجع على نفس واجهة برمجة التطبيقات). استخدم هذا عندما يريد شخص ما تشغيل حلقة "مراجعة المستندات في GitBook" من الوحدة الطرفية/الوكيل مقابل واجهة برمجة التطبيقات الأولية (curl/HTTP)، أو يذكر إنشاء طلب تغيير عبر واجهة برمجة التطبيقات، أو دفع المحتوى إلى سجل تجاري، أو "سحب أحدث التعليقات وإصلاحها"، أو طلب المراجعة على المستندات، أو إظهار المهندسين كيفية التعاون في مستندات GitBook من Claude + Slack بدون واجهة سطر الأوامر.
