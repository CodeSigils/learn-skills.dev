قم بكتابة صفحات وثائق GitBook وتأليفها وتحريرها وتنسيقها في مستودعات Git المتزامنة أو IDEs أو أي محرر نصوص. يُستخدم عندما تتضمن مهمة إنشاء أو تحرير صفحة تخفيض GitBook، أو كتابة أو تحديث README.md أو SUMMARY.md، أو إدراج تلميح، أو علامة تبويب، أو أداة خطوة، أو بطاقة، أو كتلة GitBook أخرى، أو تكوين المادة الأمامية للصفحة أو خيارات التخطيط، أو إعداد المتغيرات أو التعبيرات، أو تنسيق المحتوى لـ GitBook خارج واجهة مستخدم GitBook.
