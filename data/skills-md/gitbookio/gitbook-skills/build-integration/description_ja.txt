GitBook 統合を構築、開発、公開します。これは、GitBook 内で実行され、カスタム ブロックの追加、イベントへの反応、OAuth 経由の外部サービスへの接続、エディターの拡張を行うアプリです。 GitBook 統合プラットフォームに関係するタスクの場合は必ずこのスキルを使用します。GitBook CLI との統合のスキャフォールディング (`gitbook new`)、統合のコードの作成または編集 (`createIntegration`、`createComponent`、ContentKit TSX)、`gitbook-manifest.yaml` の構成 (スコープ、ブロック、構成、シークレット)、カスタム エディター ブロックまたはリンク アンファーラーの構築、次のような GitBook イベントの処理です。 「space_content_updated」、統合の OAuth フローの設定、「gitbook dev」の実行、または統合の公開 (プライベート/非公開/パブリック、マーケットプレイスへの送信)。ユーザーが「統合」という言葉を言わずに「GitBook 用のアプリを構築する」、「カスタム ブロックを追加する」、または「<何らかのツール> を GitBook に接続する」とだけ言った場合でも、これをトリガーします。
