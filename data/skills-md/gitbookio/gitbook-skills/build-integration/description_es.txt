Cree, desarrolle y publique integraciones de GitBook: aplicaciones que se ejecutan dentro de GitBook para agregar bloques personalizados, reaccionar a eventos, conectar servicios externos a través de OAuth y ampliar el editor. Utilice esta habilidad siempre que una tarea involucre la plataforma de integraciones de GitBook: crear una integración con GitBook CLI (`gitbook new`), escribir o editar el código de una integración (`createIntegration`, `createComponent`, ContentKit TSX), configurar `gitbook-manifest.yaml` (ámbitos, bloques, configuraciones, secretos), crear bloques de editor personalizados o despliegues de enlaces, manejar eventos de GitBook como `space_content_updated`, configurar el flujo OAuth de una integración, ejecutar `gitbook dev` o publicar una integración (privada/no listada/pública, envío al mercado). Active esto incluso si el usuario simplemente dice que quiere "crear una aplicación para GitBook", "agregar un bloque personalizado" o "conectar <alguna herramienta> a GitBook" sin decir la palabra "integración".
