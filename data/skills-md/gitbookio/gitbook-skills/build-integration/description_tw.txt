建置、開發和發布 GitBook 整合 - 在 GitBook 內運行的應用程序，用於添加自訂區塊、對事件做出反應、透過 OAuth 連接外部服務以及擴展編輯器。每當任務涉及 GitBook 整合平台時，請使用此技能：建立與 GitBook CLI 的整合（`gitbook new`）、編寫或編輯整合的程式碼（`createIntegration`、`createComponent`、ContentKit TSX）、設定 `gitbook-manifest.yaml``s、sad、27_form(事件、設定整合的 OAuth 流程、執行`gitbook dev`，或發布整合（私有/不公開/公開、市場提交）。即使用戶只是說他們想要「為 GitBook 建立應用程式」、「新增自訂區塊」或「將 <某些工具> 連接到 GitBook」而不說「整合」一詞，也會觸發此操作。
