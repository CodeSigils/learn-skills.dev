Créez, développez et publiez des intégrations GitBook : des applications qui s'exécutent dans GitBook pour ajouter des blocs personnalisés, réagir aux événements, connecter des services externes via OAuth et étendre l'éditeur. Utilisez cette compétence chaque fois qu'une tâche implique la plate-forme d'intégrations GitBook : échafaudage d'une intégration avec la CLI GitBook (`gitbook new`), écriture ou modification du code d'une intégration (`createIntegration`, `createComponent`, ContentKit TSX), configuration de `gitbook-manifest.yaml` (portées, blocs, configurations, secrets), création de blocs d'éditeur personnalisés ou de déployeurs de liens, gestion d'événements GitBook comme `space_content_updated`, configurer le flux OAuth d'une intégration, exécuter « gitbook dev » ou publier une intégration (privée/non répertoriée/publique, soumission sur le marché). Déclenchez cela même si l'utilisateur dit simplement qu'il souhaite « créer une application pour GitBook », « ajouter un bloc personnalisé » ou « connecter <un outil> à ​​GitBook » sans prononcer le mot « intégration ».
