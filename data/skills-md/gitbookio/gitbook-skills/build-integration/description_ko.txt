GitBook 통합을 구축, 개발 및 게시합니다. GitBook 내부에서 실행되어 사용자 정의 블록을 추가하고, 이벤트에 반응하고, OAuth를 통해 외부 서비스를 연결하고, 편집기를 확장하는 앱입니다. 작업이 GitBook 통합 플랫폼과 관련될 때마다 이 기술을 사용하십시오: GitBook CLI와의 통합 스캐폴딩(`gitbook new`), 통합 코드 작성 또는 편집(`createIntegration`, `createComponent`, ContentKit TSX), `gitbook-manifest.yaml` 구성(범위, 블록, 구성, 비밀), 사용자 정의 편집기 블록 또는 링크 언펄러 구축, `space_content_updated`와 같은 GitBook 이벤트 처리, 통합 설정 OAuth 흐름, `gitbook dev` 실행 또는 통합 게시(비공개/미등록/공개, 마켓플레이스 제출). 사용자가 '통합'이라는 단어를 말하지 않고 단지 'GitBook용 앱 구축', '사용자 정의 블록 추가' 또는 '<일부 도구>를 GitBook에 연결'하고 싶다고 말하는 경우에도 이를 트리거합니다.
