إنشاء تكاملات GitBook وتطويرها ونشرها — وهي التطبيقات التي تعمل داخل GitBook لإضافة كتل مخصصة والتفاعل مع الأحداث وتوصيل الخدمات الخارجية عبر OAuth وتوسيع المحرر. استخدم هذه المهارة عندما تتضمن المهمة منصة تكامل GitBook: دعم التكامل مع GitBook CLI (`gitbook new`)، أو كتابة كود التكامل أو تحريره (`createIntegration`، أو `createComponent`، أو ContentKit TSX)، أو تكوين `gitbook-manifest.yaml` (النطاقات، أو الكتل، أو التكوينات، أو الأسرار)، أو إنشاء كتل محرر مخصصة أو أدوات نشر الروابط، أو التعامل مع أحداث GitBook مثل `space_content_updated`، أو إعداد تدفق OAuth للتكامل، أو تشغيل `gitbook dev`، أو نشر تكامل (خاص/غير مدرج/عام، تقديم في السوق). قم بتشغيل هذا حتى إذا قال المستخدم فقط أنه يريد "إنشاء تطبيق لـ GitBook"، أو "إضافة كتلة مخصصة"، أو "توصيل <بعض الأدوات> بـ GitBook" دون قول كلمة "تكامل".
