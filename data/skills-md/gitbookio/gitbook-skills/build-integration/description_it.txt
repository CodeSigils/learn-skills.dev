Crea, sviluppa e pubblica integrazioni GitBook: app eseguite all'interno di GitBook per aggiungere blocchi personalizzati, reagire agli eventi, connettere servizi esterni tramite OAuth ed estendere l'editor. Utilizza questa competenza ogni volta che un'attività coinvolge la piattaforma di integrazioni GitBook: impalcatura di un'integrazione con la CLI GitBook (`gitbook new`), scrittura o modifica del codice di un'integrazione (`createIntegration`, `createComponent`, ContentKit TSX), configurazione di `gitbook-manifest.yaml` (ambiti, blocchi, configurazioni, segreti), creazione di blocchi di editor personalizzati o unfurler di collegamenti, gestione di eventi GitBook come "space_content_updated", impostare il flusso OAuth di un'integrazione, eseguire "gitbook dev" o pubblicare un'integrazione (privata/non elencata/pubblica, invio al marketplace). Attivalo anche se l'utente dice semplicemente di voler "creare un'app per GitBook", "aggiungere un blocco personalizzato" o "connettere <qualche strumento> a GitBook" senza pronunciare la parola "integrazione".
