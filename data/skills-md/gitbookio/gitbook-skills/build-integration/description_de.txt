Erstellen, entwickeln und veröffentlichen Sie GitBook-Integrationen – Apps, die in GitBook ausgeführt werden, um benutzerdefinierte Blöcke hinzuzufügen, auf Ereignisse zu reagieren, externe Dienste über OAuth zu verbinden und den Editor zu erweitern. Verwenden Sie diese Fertigkeit immer dann, wenn eine Aufgabe die GitBook-Integrationsplattform betrifft: Aufbau einer Integration mit der GitBook-CLI („gitbook new“), Schreiben oder Bearbeiten des Codes einer Integration („createIntegration“, „createComponent“, ContentKit TSX), Konfigurieren von „gitbook-manifest.yaml“ (Bereiche, Blöcke, Konfigurationen, Geheimnisse), Erstellen benutzerdefinierter Editorblöcke oder Link-Entfalter, Behandeln von GitBook-Ereignissen wie „space_content_updated“, Einrichten des OAuth-Flows einer Integration, Ausführen von „gitbook dev“ oder Veröffentlichen einer Integration (privat/nicht gelistet/öffentlich, Marktplatzübermittlung). Lösen Sie dies aus, selbst wenn der Benutzer nur sagt, dass er „eine App für GitBook erstellen“, „einen benutzerdefinierten Block hinzufügen“ oder „<irgendein Tool> mit GitBook verbinden“ möchte, ohne das Wort „Integration“ zu sagen.
