قم بتأليف الوثائق المرجعية لـ OpenAPI/Swagger API وتكوينها وبنيتها واستكشاف الأخطاء وإصلاحها في GitBook. استخدم هذا عندما تتضمن مهمة كتلة GitBook OpenAPI أو كتلة `{% openapi %}`، أو إضافة أو تحديث مواصفات OpenAPI/Swagger في GitBook (عن طريق ملف أو عنوان URL، عبر واجهة برمجة التطبيقات، أو MCP، أو CLI، أو واجهة مستخدم التطبيق)، وإنشاء صفحات مرجعية لواجهة برمجة التطبيقات من إحدى المواصفات، وتكوين مشغل "اختباره" التفاعلي (المصادقة، والخوادم، وCORS، والوكيل)، وتخصيص الصفحات بامتدادات GitBook `x-*` (الأيقونات، العناوين، والتسلسل الهرمي للتنقل، ونماذج التعليمات البرمجية، وأوصاف التعداد)، ووضع علامات على العمليات التجريبية/المهملة/المخفية، أو أتمتة تحديثات المواصفات في CI/CD. يتم التشغيل حتى عندما يذكر المستخدم GitBook plus OpenAPI فقط، أو يضع امتداد `x-` على المواصفات المخصصة لـ GitBook، أو يسأل "لماذا لا يتم تحميل المواصفات الخاصة بي" أو "لماذا لا يعمل اختبارها"، دون تسمية هذه المهارة.
