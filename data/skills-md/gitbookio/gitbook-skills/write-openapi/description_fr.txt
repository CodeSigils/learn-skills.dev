Créez, configurez, structurez et dépannez la documentation de référence de l'API OpenAPI/Swagger dans GitBook. Utilisez-le chaque fois qu'une tâche implique un bloc GitBook OpenAPI ou `{% openapi %}`, l'ajout ou la mise à jour d'une spécification OpenAPI/Swagger dans GitBook (par fichier ou URL, via l'API, MCP, CLI ou l'interface utilisateur de l'application), la génération de pages de référence API à partir d'une spécification, la configuration du programme d'exécution interactif "Test it" (authentification, serveurs, CORS, proxy), la personnalisation des pages avec les extensions GitBook `x-*` (icônes, titres, hiérarchie de navigation, code échantillons, descriptions d'énumération), les opérations de marquage expérimentales/obsolètes/cachées ou l'automatisation des mises à jour des spécifications dans CI/CD. Se déclenche même lorsque l'utilisateur mentionne uniquement GitBook plus OpenAPI, met une extension `x-` sur une spécification destinée à GitBook, ou demande "pourquoi ma spécification ne se charge pas" ou "pourquoi la tester ne fonctionne-t-elle pas", sans nommer cette compétence.
