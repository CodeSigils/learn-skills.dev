GitBook에서 OpenAPI/Swagger API 참조 문서를 작성, 구성, 구성 및 문제 해결합니다. 작업에 GitBook OpenAPI 블록 또는 `{% openapi %}` 블록, GitBook에서 OpenAPI/Swagger 사양 추가 또는 업데이트(파일 또는 URL별, API, MCP, CLI 또는 앱 UI를 통해), 사양에서 API 참조 페이지 생성, 대화형 "Test it" 실행기(인증, 서버, CORS, 프록시) 구성, GitBook `x-*` 확장(아이콘, 제목, 탐색 계층 구조, 코드 샘플, 열거형 설명)으로 페이지 사용자 정의, 실험적/더 이상 사용되지 않음/숨겨진 작업을 표시하거나 CI/CD에서 사양 업데이트를 자동화합니다. 사용자가 GitBook과 OpenAPI만 언급하거나, GitBook용 사양에 `x-` 확장자를 추가하거나, 이 스킬의 이름을 지정하지 않고 "내 사양이 로드되지 않는 이유" 또는 "테스트가 작동하지 않는 이유"라고 묻는 경우에도 트리거됩니다.
