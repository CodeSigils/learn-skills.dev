Cree, configure, estructure y solucione problemas de documentación de referencia de OpenAPI/Swagger API en GitBook. Use esto siempre que una tarea involucre un bloque GitBook OpenAPI o `{% openapi %}`, agregar o actualizar una especificación OpenAPI/Swagger en GitBook (por archivo o URL, a través de API, MCP, CLI o interfaz de usuario de la aplicación), generar páginas de referencia API a partir de una especificación, configurar el corredor interactivo "Test it" (autenticación, servidores, CORS, proxy), personalizar páginas con extensiones GitBook `x-*` (iconos, títulos, navegación). jerarquía, ejemplos de código, descripciones de enumeración), marcar operaciones como experimentales/obsoletas/ocultas, o automatizar actualizaciones de especificaciones en CI/CD. Se activa incluso cuando el usuario solo menciona GitBook más OpenAPI, coloca una extensión `x-` en una especificación destinada a GitBook o pregunta "por qué no se carga mi especificación" o "por qué no funciona la prueba", sin nombrar esta habilidad.
