在 GitBook 中编写、配置、构建 OpenAPI/Swagger API 参考文档并对其进行故障排除。每当任务涉及 GitBook OpenAPI 块或 `{% openapi %}` 块、在 GitBook 中添加或更新 OpenAPI/Swagger 规范（通过文件或 URL、通过 API、MCP、CLI 或应用程序 UI）、从规范生成 API 参考页面、配置交互式“Test it”运行器（身份验证、服务器、CORS、代理）、使用 GitBook `x-*` 扩展自定义页面（图标、标题、导航层次结构、代码示例、枚举）时，请使用此选项描述），将操作标记为实验/弃用/隐藏，或在 CI/CD 中自动更新规范。即使用户只提到 GitBook 加上 OpenAPI，在指定给 GitBook 的规范上添加“x-”扩展，或者询问“为什么我的规范没有加载”或“为什么测试它不起作用”，而不命名此技能，也会触发该技能。
