Crea, configura, struttura e risolvi i problemi della documentazione di riferimento dell'API OpenAPI/Swagger in GitBook. Utilizzalo ogni volta che un'attività coinvolge un blocco GitBook OpenAPI o un blocco `{% openapi %}`, aggiungendo o aggiornando una specifica OpenAPI/Swagger in GitBook (tramite file o URL, tramite API, MCP, CLI o interfaccia utente dell'app), generando pagine di riferimento API da una specifica, configurando il runner interattivo "Test it" (autenticazione, server, CORS, proxy), personalizzando pagine con estensioni GitBook `x-*` (icone, titoli, gerarchia di navigazione, esempi di codice, descrizioni enum), contrassegnando le operazioni come sperimentali/deprecate/nascoste o automatizzando gli aggiornamenti delle specifiche in CI/CD. Si attiva anche quando l'utente menziona solo GitBook più OpenAPI, inserisce un'estensione "x-" su una specifica destinata a GitBook o chiede "perché la mia specifica non viene caricata" o "perché il test non funziona", senza nominare questa abilità.
