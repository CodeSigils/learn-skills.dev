在 GitBook 中編寫、配置、建立 OpenAPI/Swagger API 參考文件並對其進行故障排除。每當任務涉及 GitBook OpenAPI 區塊或 `{% openapi %}` 區塊、在 GitBook 中新增或更新 OpenAPI/Swagger 區塊或 `{% openapi %}` 區塊、在 GitBook 中新增或更新 OpenAPI/Swagger 規格（透過檔案或 URL、透過 API、MCP、CLI 或應用程式 UI）、從從規格產生 API 參考頁、設定互動式「Test it」執行器（「識別碼」執行器、使用識別碼、「數」執行器）、`x-RS設定擴充自訂頁面（圖示、標題、導覽層次結構、程式碼範例、枚舉）時，請使用此選項說明），將操作標記為實驗/棄用/隱藏，或在 CI/CD 中自動更新規格。即使用戶只提到 GitBook 加上 OpenAPI，在指定給 GitBook 的規範上添加“x-”擴展，或者詢問“為什麼我的規範沒有加載”或“為什麼測試它不起作用”，而不命名此技能，也會觸發該技能。
