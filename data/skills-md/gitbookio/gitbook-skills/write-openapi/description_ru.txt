Создавайте, настраивайте, структурируйте и устраняйте неполадки справочной документации по API OpenAPI/Swagger в GitBook. Используйте это всякий раз, когда задача включает в себя блок GitBook OpenAPI или блок `{% openapi %}`, добавление или обновление спецификации OpenAPI/Swagger в GitBook (по файлу или URL-адресу, через API, MCP, CLI или пользовательский интерфейс приложения), создание справочных страниц API из спецификации, настройку интерактивного средства запуска «Test it» (аутентификация, серверы, CORS, прокси), настройку страниц с расширениями GitBook `x-*` (значки, заголовки, навигация) иерархия, примеры кода, описания перечислений), пометка операций как экспериментальных/устаревших/скрытых или автоматизация обновлений спецификаций в CI/CD. Срабатывает, даже когда пользователь упоминает только GitBook плюс OpenAPI, добавляет расширение `x-` к спецификации, предназначенной для GitBook, или спрашивает «почему моя спецификация не загружается» или «почему не проверяется ее работа», не называя этот навык.
