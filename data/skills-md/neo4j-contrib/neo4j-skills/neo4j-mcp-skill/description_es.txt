Úselo al instalar, configurar o solucionar problemas del servidor MCP oficial Neo4j (neo4j/mcp): conectar Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Kiro u otros editores compatibles con MCP a una base de datos Neo4j a través de transporte stdio o HTTP. Cubre las cuatro herramientas MCP (get-schema, read-cypher, write-cypher, list-gds-procedures), el modo de solo lectura y la configuración de múltiples bases de datos. NO cubre la escritura de consultas Cypher a través de esas herramientas; use neo4j-cypher-skill. NO cubre la memoria del agente: use neo4j-agent-memory-skill. NO cubre el aprovisionamiento de instancias de Aura: utilice neo4j-aura-provisioning-skill.
