À utiliser lors de l'installation, de la configuration ou du dépannage du serveur officiel Neo4j MCP (neo4j/mcp) : connexion de Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Kiro ou d'autres éditeurs compatibles MCP à une base de données Neo4j via stdio ou transport HTTP. Couvre les quatre outils MCP (get-schema, read-cypher, write-cypher, list-gds-procedures), le mode lecture seule et la configuration multi-bases de données. Ne couvre PAS l'écriture de requêtes Cypher via ces outils - utilisez neo4j-cypher-skill. Ne couvre PAS la mémoire de l'agent - utilisez neo4j-agent-memory-skill. Ne couvre PAS le provisionnement de l’instance Aura – utilisez neo4j-aura-provisioning-skill.
