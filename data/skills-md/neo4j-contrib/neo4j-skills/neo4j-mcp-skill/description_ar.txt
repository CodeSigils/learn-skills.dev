يُستخدم عند تثبيت أو تكوين أو استكشاف أخطاء خادم Neo4j MCP الرسمي (neo4j/mcp): توصيل Claude Code أو Claude Desktop أو Cursor أو Windsurf أو VS Code أو Kiro أو برامج تحرير أخرى متوافقة مع MCP بقاعدة بيانات Neo4j عبر نقل stdio أو HTTP. يغطي أدوات MCP الأربعة (get-schema، read-cypher، write-cypher، list-gds-procedures)، وضع القراءة فقط، وتكوين قواعد البيانات المتعددة. لا يغطي كتابة استعلامات Cypher عبر تلك الأدوات — استخدم neo4j-cypher-skill. لا يغطي ذاكرة الوكيل — استخدم neo4j-agent-memory-skill. لا يغطي توفير مثيل Aura — استخدم مهارة توفير neo4j-aura.
