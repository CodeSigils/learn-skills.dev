Da utilizzare durante l'installazione, la configurazione o la risoluzione dei problemi del server MCP Neo4j ufficiale (neo4j/mcp): connessione di Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Kiro o altri editor compatibili con MCP a un database Neo4j tramite trasporto stdio o HTTP. Copre i quattro strumenti MCP (get-schema, read-cypher, write-cypher, list-gds-procedures), la modalità di sola lettura e la configurazione multi-database. NON copre la scrittura di query Cypher tramite questi strumenti: utilizzare neo4j-cypher-skill. NON copre la memoria dell'agente: utilizza neo4j-agent-memory-skill. NON copre il provisioning delle istanze Aura: utilizzare neo4j-aura-provisioning-skill.
