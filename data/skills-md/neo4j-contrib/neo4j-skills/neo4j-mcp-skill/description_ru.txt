Используйте при установке, настройке или устранении неполадок официального сервера Neo4j MCP (neo4j/mcp): подключение Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Kiro или других MCP-совместимых редакторов к базе данных Neo4j через stdio или HTTP-транспорт. Охватывает четыре инструмента MCP (get-schema, read-cypher, write-cypher, list-gds-procedures), режим только для чтения и настройку нескольких баз данных. НЕ охватывает написание запросов Cypher с помощью этих инструментов — используйте neo4j-cypher-skill. НЕ охватывает память агента — используйте neo4j-agent-memory-skill. НЕ охватывает подготовку экземпляра Aura — используйте neo4j-aura-provisioning-skill.
