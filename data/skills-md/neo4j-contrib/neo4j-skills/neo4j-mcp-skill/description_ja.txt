公式 Neo4j MCP サーバー (neo4j/mcp) をインストール、構成、またはトラブルシューティングするときに使用します。Claude Code、Claude Desktop、Cursor、Windsurf、VS Code、Kiro、またはその他の MCP 互換エディターを stdio または HTTP トランスポート経由で Neo4j データベースに接続します。 4 つの MCP ツール (get-schema、read-cypher、write-cypher、list-gds-procedures)、読み取り専用モード、およびマルチデータベース構成をカバーします。これらのツールを使用した Cypher クエリの作成はカバーされていません。neo4j-cypher-skill を使用してください。エージェントのメモリは対象外です。neo4j-agent-memory-skill を使用してください。 Aura インスタンスのプロビジョニングはカバーされていません。neo4j-aura-provisioning-skill を使用してください。
