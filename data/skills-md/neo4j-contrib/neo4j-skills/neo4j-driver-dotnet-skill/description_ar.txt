Neo4j .NET Driver v6 - دورة حياة IDriver، تسجيل DI (مفرد)، واجهة برمجة تطبيقات ExecutableQuery بطلاقة، المعاملات المُدارة ExecuteReadAsync/ExecuteWriteAsync، IResultCursor (FetchAsync/ ToListAsync)، الوصول إلى قيمة السجل (.Get<T>/As<T>)، الأمان الفارغ، تجميع UNWIND، الأنواع المؤقتة، انتظار الاستخدام، EagerResult، الكائن رسم الخرائط، CancellationToken، ومعالجة الأخطاء، والفخاخ الشائعة. يُستخدم عند كتابة كود C# أو .NET للاتصال بـ Neo4j. يتم تشغيله أيضًا على Neo4j.Driver أو IDriver أو ExecutableQuery أو ExecuteReadAsync أو ExecuteWriteAsync أو IResultCursor أو IAsyncSession أو أي عمل Bolt/Aura في .NET/C#. لا يتعامل مع تأليف Cypher — استخدم neo4j-cypher-skill. لا يشمل ترقيات إصدار برنامج التشغيل — استخدم neo4j-migration-skill.
