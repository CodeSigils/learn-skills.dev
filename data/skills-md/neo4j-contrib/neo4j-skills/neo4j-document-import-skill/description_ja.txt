非構造化ドキュメントおよび半構造化ドキュメントをナレッジ グラフとして Neo4j に取り込みます。 PDF、HTML、プレーンテキスト、またはマークダウンをチャンク化する場合に使用します。 LLM (SimpleKGPipeline、neo4j-graphrag) を使用してテキストからエンティティと関係を抽出します。 apoc.load.json 経由で JSON をロードします。ドキュメント→チャンク→エンティティのグラフ構造を構築します。または、LangChain/LlamaIndex ドキュメント ローダーを Neo4j に接続します。 neo4j-graphrag SimpleKGPipeline、LLM Graph Builder Web UI、エンティティ解決、チャンキング戦略、RAG パイプラインのグラフ スキーマ設計について説明します。構造化された CSV/リレーショナル インポートは処理しません。neo4j-import-skill を使用してください。取り込み後の GraphRAG 取得は処理しません。neo4j-graphrag-skill を使用します。ベクトルインデックスの作成は処理しません。neo4j-vector-search-skill を使用してください。
