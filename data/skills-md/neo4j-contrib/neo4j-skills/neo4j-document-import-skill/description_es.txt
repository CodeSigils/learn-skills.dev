Ingiere documentos no estructurados y semiestructurados en Neo4j como un gráfico de conocimiento. Úselo al fragmentar archivos PDF, HTML, texto sin formato o Markdown; extraer entidades y relaciones de texto con un LLM (SimpleKGPipeline, neo4j-graphrag); cargar JSON a través de apoc.load.json; construcción de estructuras de gráficos de documento → fragmento → entidad; o conectando cargadores de documentos LangChain/LlamaIndex a Neo4j. Cubre neo4j-graphrag SimpleKGPipeline, interfaz de usuario web de LLM Graph Builder, resolución de entidades, estrategias de fragmentación y diseño de esquemas de gráficos para canalizaciones RAG. NO maneja importación relacional/CSV estructurada: use neo4j-import-skill. NO maneja la recuperación de GraphRAG después de la ingestión; use neo4j-graphrag-skill. NO maneja la creación de índices vectoriales; use neo4j-vector-search-skill.
