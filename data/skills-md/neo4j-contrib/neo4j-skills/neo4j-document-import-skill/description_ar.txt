يستوعب المستندات غير المنظمة وشبه المنظمة في Neo4j كرسم بياني معرفي. يُستخدم عند تقسيم ملفات PDF أو HTML أو النص العادي أو Markdown؛ استخراج الكيانات والعلاقات من النص باستخدام LLM (SimpleKGPipeline، neo4j-graphrag)؛ تحميل JSON عبر apoc.load.json؛ مستند البناء → قطعة → هياكل الرسم البياني للكيان؛ أو توصيل أدوات تحميل المستندات LangChain/LlamaIndex بـ Neo4j. يغطي neo4j-graphrag SimpleKGPipeline، وواجهة مستخدم ويب LLM Graph Builder، ودقة الكيان، واستراتيجيات التقطيع، وتصميم مخطط الرسم البياني لخطوط أنابيب RAG. لا يتعامل مع ملف CSV/الاستيراد العلائقي المنظم — استخدم neo4j-import-skill. لا يتعامل مع استرجاع GraphRAG بعد الاستيعاب — استخدم neo4j-graphrag-skill. لا يتعامل مع إنشاء فهرس المتجهات — استخدم neo4j-vector-search-skill.
