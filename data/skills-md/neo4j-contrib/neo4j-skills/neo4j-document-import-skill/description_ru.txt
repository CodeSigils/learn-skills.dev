Принимает неструктурированные и полуструктурированные документы в Neo4j в виде графа знаний. Используйте при разбиении PDF-файлов, HTML, обычного текста или Markdown; извлечение сущностей и связей из текста с помощью LLM (SimpleKGPipeline, neo4j-graphrag); загрузка JSON через apoc.load.json; построение графовых структур Документ→Чанк→Entity; или подключение загрузчиков документов LangChain/LlamaIndex к Neo4j. Охватывает neo4j-graphrag SimpleKGPipeline, веб-интерфейс LLM Graph Builder, разрешение сущностей, стратегии фрагментирования и проектирование схемы графов для конвейеров RAG. НЕ обрабатывает структурированный CSV/реляционный импорт — используйте neo4j-import-skill. НЕ обрабатывает извлечение GraphRAG после приема — используйте neo4j-graphrag-skill. НЕ обрабатывает создание векторного индекса — используйте neo4j-vector-search-skill.
