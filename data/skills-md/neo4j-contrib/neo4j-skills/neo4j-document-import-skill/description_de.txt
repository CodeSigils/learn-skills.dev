Nimmt unstrukturierte und halbstrukturierte Dokumente als Wissensgraphen in Neo4j auf. Zum Aufteilen von PDFs, HTML, reinem Text oder Markdown verwenden; Extrahieren von Entitäten und Beziehungen aus Text mit einem LLM (SimpleKGPipeline, neo4j-graphrag); Laden von JSON über apoc.load.json; Erstellen von Document→Chunk→Entity-Graph-Strukturen; oder die Verbindung von LangChain/LlamaIndex-Dokumentladern mit Neo4j. Behandelt neo4j-graphrag SimpleKGPipeline, die Web-Benutzeroberfläche von LLM Graph Builder, Entitätsauflösung, Chunking-Strategien und Diagrammschemadesign für RAG-Pipelines. Verarbeitet NICHT den strukturierten CSV-/relationalen Import – verwenden Sie neo4j-import-skill. Verarbeitet NICHT den GraphRAG-Abruf nach der Aufnahme – verwenden Sie neo4j-graphrag-skill. Übernimmt NICHT die Erstellung von Vektorindizes – verwenden Sie neo4j-vector-search-skill.
