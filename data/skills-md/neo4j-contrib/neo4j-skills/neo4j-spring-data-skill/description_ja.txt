Spring Data Neo4j (SDN 7.x/8.x) を使用して Neo4j で Spring Boot アプリケーションを構築する場合に使用します — @Node エンティティ マッピング、@Relationship、@RelationshipProperties、Neo4jRepository、ReactiveNeo4jRepository、@Query アノテーション、application.yml 構成、プロジェクション、Neo4jClient、Neo4jTemplate、トランザクション、監査、または Spring AI Neo4jVectorStore ベクトル検索。 Spring なしでは生の Java ドライバー コードを処理しません。neo4j-driver-java-skill を使用します。 Cypher クエリの作成は処理しません。neo4j-cypher-skill を使用します。ドライバーのバージョンのアップグレードは処理しません。neo4j-migration-skill を使用してください。
