À utiliser lors de la création d'applications Spring Boot avec Neo4j à l'aide de Spring Data Neo4j (SDN 7.x/8.x) — Mappage d'entités @Node, @Relationship, @RelationshipProperties, Neo4jRepository, ReactiveNeo4jRepository, annotations @Query, configuration application.yml, projections, Neo4jClient, Neo4jTemplate, transactions, audit ou recherche vectorielle Spring AI Neo4jVectorStore. Ne gère PAS le code brut du pilote Java sans Spring – utilisez neo4j-driver-java-skill. Ne gère PAS la création de requêtes Cypher – utilisez neo4j-cypher-skill. Ne gère PAS les mises à niveau de version du pilote – utilisez neo4j-migration-skill.
