使用 Spring Data Neo4j (SDN 7.x/8.x) 透過 Neo4j 建立 Spring Boot 應用程式時使用 — @Node 實體映射、@Relationship、@RelationshipProperties、Neo4jRepository、ReactiveNeo4jRepository、@Query 註釋、application.y 交易、配置、Neo4jReposit、Neo4向量搜尋。如果沒有 Spring，則無法處理原始 Java 驅動程式程式碼 — 使用 neo4j-driver-java-skill。不處理 Cypher 查詢創作 - 使用 neo4j-cypher-skill。不處理驅動程式版本升級 - 使用 neo4j-migration-skill。
