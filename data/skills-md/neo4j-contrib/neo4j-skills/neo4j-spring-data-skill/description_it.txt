Da utilizzare durante la creazione di applicazioni Spring Boot con Neo4j utilizzando Spring Data Neo4j (SDN 7.x/8.x): mappatura entità @Node, @Relationship, @RelationshipProperties, Neo4jRepository, ReactiveNeo4jRepository, annotazioni @Query, configurazione application.yml, proiezioni, Neo4jClient, Neo4jTemplate, transazioni, controllo o ricerca vettoriale Spring AI Neo4jVectorStore. NON gestisce il codice del driver Java grezzo senza Spring: utilizza neo4j-driver-java-skill. NON gestisce la creazione di query Cypher: utilizza neo4j-cypher-skill. NON gestisce gli aggiornamenti della versione del driver: utilizza neo4j-migration-skill.
