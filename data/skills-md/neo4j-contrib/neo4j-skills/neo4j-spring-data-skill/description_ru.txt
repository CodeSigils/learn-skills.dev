Используйте при создании приложений Spring Boot с Neo4j с использованием Spring Data Neo4j (SDN 7.x/8.x) — сопоставление объектов @Node, @Relationship, @RelationshipProperties, Neo4jRepository, ReactiveNeo4jRepository, аннотации @Query, конфигурация application.yml, проекции, Neo4jClient, Neo4jTemplate, транзакции, аудит или векторный поиск Spring AI Neo4jVectorStore. НЕ обрабатывает необработанный код драйвера Java без Spring — используйте neo4j-driver-java-skill. НЕ обрабатывает создание запросов Cypher — используйте neo4j-cypher-skill. НЕ обрабатывает обновления версий драйверов — используйте neo4j-migration-skill.
