Orchestriert den gesamten Weg von Null bis zu einer laufenden Neo4j-Anwendung. Führt 8 benannte Phasen in der Reihenfolge aus: Voraussetzungen → Kontext → Bereitstellung → Modell → Laden → Erkunden → Abfrage → Erstellen. Jede Stufe verfügt über eine eigene Referenzdatei in references/, die der Agent liest und befolgt, wenn er diese Stufe betritt. Unterstützt sowohl HITL als auch den vollständig autonomen Betrieb. Zeitbudget: ≤15 Minuten nach Ausführung der DB (autonom), ≤90 Minuten insgesamt (HITL).
