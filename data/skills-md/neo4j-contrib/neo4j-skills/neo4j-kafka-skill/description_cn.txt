配置和操作 Neo4j Connector for Kafka（接收器 + 源）和本机 Neo4j CDC API。涵盖 Cypher/Pattern/CUD 接收器策略、基于 CDC 和基于查询的源、一次性语义、DLQ 错误处理、Confluence Cloud 托管连接器、模式注册表 (Avro/JSON) 和本机 db.cdc.query 游标循环模式 (Neo4j 5.13+ Enterprise/Aura BC/VDC)。当将 Kafka 事件流式传输到 Neo4j、将 Neo4j 更改流式传输到 Kafka 或在没有 Kafka 的情况下查询 Neo4j 更改事件时使用。不处理 Cypher 查询创作 - 使用 neo4j-cypher-skill。不处理批量 CSV/文件导入 — 使用 neo4j-import-skill。不处理 GDS 算法 — 使用 neo4j-gds-skill。
