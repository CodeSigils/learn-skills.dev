Konfigurieren und betreiben Sie den Neo4j Connector für Kafka (Sink + Source) und die native Neo4j CDC API. Behandelt Cypher-/Pattern-/CUD-Sink-Strategien, CDC-basierte und abfragebasierte Quellen, Exact-Once-Semantik, DLQ-Fehlerbehandlung, von Confluent Cloud verwalteter Connector, Schema-Registrierung (Avro/JSON) und native db.cdc.query-Cursor-Loop-Muster (Neo4j 5.13+ Enterprise/Aura BC/VDC). Wird verwendet, wenn Sie Kafka-Ereignisse in Neo4j streamen, Neo4j-Änderungen an Kafka streamen oder Neo4j-Änderungsereignisse ohne Kafka abfragen. Übernimmt NICHT die Erstellung von Cypher-Abfragen – verwenden Sie neo4j-cypher-skill. Verarbeitet KEINEN Massenimport von CSV-/Dateidateien – verwenden Sie neo4j-import-skill. Verarbeitet KEINE GDS-Algorithmen – verwenden Sie neo4j-gds-skill.
