Kafka 用の Neo4j コネクタ (シンク + ソース) とネイティブ Neo4j CDC API を構成して操作します。サイファー/パターン/CUD シンク戦略、CDC ベースおよびクエリベースのソース、1 回限りのセマンティクス、DLQ エラー処理、Confluent Cloud 管理対象コネクタ、スキーマ レジストリ (Avro/JSON)、およびネイティブ db.cdc.query カーソル ループ パターン (Neo4j 5.13+ Enterprise/Aura BC/VDC) をカバーします。 Kafka イベントを Neo4j にストリーミングする場合、Neo4j の変更を Kafka にストリーミングする場合、または Kafka を使用せずに Neo4j の変更イベントをクエリする場合に使用します。 Cypher クエリの作成は処理しません。neo4j-cypher-skill を使用します。 CSV/ファイルの一括インポートは処理しません。neo4j-import-skill を使用してください。 GDS アルゴリズムは処理しません。neo4j-gds-skill を使用します。
