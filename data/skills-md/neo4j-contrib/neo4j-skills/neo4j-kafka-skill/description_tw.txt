設定和操作 Neo4j Connector for Kafka（接收器 + 來源）和本機 Neo4j CDC API。涵蓋 Cypher/Pattern/CUD 接收器策略、基於 CDC 和基於查詢的來源、一次性語意、DLQ 錯誤處理、Confluence Cloud 託管連接器、模式註冊表 (Avro/JSON) 和本機 db.cdc.query 遊標循環模式 (Neo4j 5.13+ Enterprise/Aura BC/VDC)。當將 Kafka 事件串流傳輸到 Neo4j、將 Neo4j 變更串流傳輸到 Kafka 或在沒有 Kafka 的情況下查詢 Neo4j 變更事件時使用。不處理 Cypher 查詢創作 - 使用 neo4j-cypher-skill。不處理批次 CSV/檔案匯入 — 使用 neo4j-import-skill。不處理 GDS 演算法 — 使用 neo4j-gds-skill。
