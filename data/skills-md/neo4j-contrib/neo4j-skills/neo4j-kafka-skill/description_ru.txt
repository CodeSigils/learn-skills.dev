Настройте и используйте соединитель Neo4j для Kafka (приемник + источник) и собственный API Neo4j CDC. Охватывает стратегии приема Cypher/Pattern/CUD, источник на основе CDC и на основе запросов, однократную семантику, обработку ошибок DLQ, управляемый соединитель Confluent Cloud, реестр схем (Avro/JSON) и собственные шаблоны цикла курсора db.cdc.query (Neo4j 5.13+ Enterprise/Aura BC/VDC). Используйте при потоковой передаче событий Kafka в Neo4j, потоковой передаче изменений Neo4j в Kafka или запросе событий изменения Neo4j без Kafka. НЕ обрабатывает создание запросов Cypher — используйте neo4j-cypher-skill. НЕ обрабатывает массовый импорт CSV/файлов — используйте neo4j-import-skill. НЕ обрабатывает алгоритмы GDS — используйте neo4j-gds-skill.
