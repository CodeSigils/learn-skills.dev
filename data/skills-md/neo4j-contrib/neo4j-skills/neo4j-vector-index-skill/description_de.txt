Erstellen und verwalten Sie Neo4j-Vektorindizes, führen Sie eine Vektorähnlichkeitssuche (ANN/kNN) aus, speichern Sie Einbettungen auf Knoten oder Beziehungen, verwenden Sie die SEARCH-Klausel (Neo4j 2026.01+, bevorzugt) oder die Prozedur db.index.vector.queryNodes() (veraltet 2026.04, funktioniert immer noch auf 2025.x), konfigurieren Sie HNSW und Quantisierungsoptionen, wählen Sie Ähnlichkeitsfunktion und Einbettungsanbieterdimensionen aus und Batch-Update-Einbettungen. Wird verwendet, wenn Aufgaben CREATE VECTOR INDEX, vector.dimensions, die Kosinus-/Euklidische Suche, das Einbetten von Aufnahmepipelines oder die semantische Suche nach dem nächsten Nachbarn umfassen. Verarbeitet NICHT die GraphRAG retrieval_query-Graphdurchquerung – verwenden Sie neo4j-graphrag-skill. Verarbeitet KEINE Volltext-/Schlüsselwortindizes (FULLTEXT INDEX, db.index.fulltext) – verwenden Sie neo4j-cypher-skill. Verarbeitet KEINE GDS-Graph-Einbettungen (FastRP, Node2Vec) – verwenden Sie neo4j-gds-skill.
