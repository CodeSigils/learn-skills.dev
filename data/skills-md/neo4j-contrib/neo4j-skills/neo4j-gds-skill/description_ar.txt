البرنامج المساعد Neo4j Graph Data Science (GDS) - إسقاط الرسم البياني، وتنفيذ الخوارزمية، وأوضاع التنفيذ (الدفق/الإحصائيات/التحويل/الكتابة)، وتقدير الذاكرة، وعميل GDS Python (graphdatascience v1.21). يُستخدم عند تشغيل gds.pageRank، أو gds.louvain، أو gds.wcc، أو gds.fastRP، أو gds.knn، أو gds.betweenness، أو gds.nodeSimilarity، أو أي إجراء gds.*؛ عرض الرسوم البيانية المسماة في الذاكرة باستخدام gds.graph.project أو graph.project؛ خوارزميات التسلسل مع وضع التحور؛ تضمينات العقدة الحاسوبية لتعلم الآلة؛ بناء أنظمة التوصية باستخدام FastRP + KNN. يتم تشغيله أيضًا على GraphDataScience وGdsSessions وعمليات كتالوج الرسم البياني وخطوط أنابيب ML وتصنيف العقدة والتنبؤ بالارتباط. لا يغطي الجلسات التي لا تحتوي على خادم لـ Aura Graph Analytics — استخدم neo4j-aura-graph-analytics-skill. لا يتعامل مع تأليف Cypher — استخدم neo4j-cypher-skill. لا يغطي إعداد برنامج التشغيل - استخدم neo4j-driver-python-skill أو مهارات السائق الأخرى.
