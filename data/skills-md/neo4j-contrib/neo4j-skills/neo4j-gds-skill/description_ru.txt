Плагин Neo4j Graph Data Science (GDS) — проекция графа, выполнение алгоритма, режимы выполнения (поток/статистика/мутация/запись), оценка памяти и клиент GDS Python (graphdatascience v1.21). Используйте при запуске gds.pageRank, gds.louvain, gds.wcc, gds.fastRP, gds.knn, gds.betweenness, gds.nodeSimilarity или любой процедуры gds.*; проецирование именованных графов в памяти с помощью gds.graph.project илиgraph.project; алгоритмы объединения в режим изменения; встраивания вычислительных узлов для ML; построение рекомендательных систем с помощью FastRP + KNN. Также триггеры выполняются по GraphDataScience, GdsSessions, операциям с каталогом графов, конвейерам машинного обучения, классификации узлов, прогнозированию ссылок. НЕ распространяется на бессерверные сеансы Aura Graph Analytics — используйте neo4j-aura-graph-analytics-skill. НЕ поддерживает авторинг Cypher — используйте neo4j-cypher-skill. НЕ охватывает настройку драйвера — используйте neo4j-driver-python-skill или другой навык драйвера.
