使用 Neo4j GenAI 插件 ai.text.* 函数和过程进行 Cypher 内嵌入生成、文本完成、结构化输出、聊天、标记化和批量摄取。涵盖 ai.text.embed()、ai.text.embedBatch()、ai.text.completion()、ai.text.structuralCompletion()、ai.text.aggregateCompletion()、ai.text.chat()、ai.text.tokenCount()、ai.text.chunkByTokenLimit() 以及 OpenAI、Azure OpenAI、VertexAI 和 Amazon Bedrock 的提供程序配置。需要 CYPHER 25。替换已弃用的 genai.vector.encode()。在编写纯 Cypher GraphRAG、在图中嵌入节点、根据提示生成结构化映射或在 Cypher 查询中调用 LLM 时使用。不处理 neo4j-graphrag Python 库管道 - 使用 neo4j-graphrag-skill。不处理向量索引创建/搜索 - 使用 neo4j-vector-index-skill。
