Neo4j GenAI プラグイン ai.text.* 関数とプロシージャを、Cypher 内埋め込み生成、テキスト補完、構造化出力、チャット、トークン化、バッチ取り込みに使用します。 ai.text.embed()、ai.text.embedBatch()、ai.text.completion()、ai.text.structurdCompletion()、ai.text.aggregateCompletion()、ai.text.chat()、ai.text.tokenCount()、ai.text.chunkByTokenLimit()、および OpenAI、Azure OpenAI、VertexAI、Amazon のプロバイダー構成をカバーします。岩盤。 CYPHER 25 が必要です。非推奨の genai.vector.encode() を置き換えます。純粋な Cypher GraphRAG を作成する場合、グラフ内にノードを埋め込む場合、プロンプトから構造化マップを生成する場合、または Cypher クエリ内で LLM を呼び出す場合に使用します。 neo4j-graphrag Python ライブラリ パイプラインは処理しません。neo4j-graphrag-skill を使用します。ベクトルインデックスの作成/検索は処理しません。neo4j-vector-index-skill を使用してください。
