Используйте функции и процедуры плагина Neo4j GenAI ai.text.* для генерации встраивания в Cypher, завершения текста, структурированного вывода, чата, токенизации и пакетного приема. Охватывает ai.text.embed(), ai.text.embedBatch(), ai.text.completion(), ai.text.structuredCompletion(), ai.text.aggregateCompletion(), ai.text.chat(), ai.text.tokenCount(), ai.text.chunkByTokenLimit() и конфигурацию поставщика для OpenAI, Azure OpenAI, VertexAI и Amazon Bedrock. Требуется CYPHER 25. Заменяет устаревший genai.vector.encode(). Используйте при написании GraphRAG на чистом шифре, внедрении узлов в граф, создании структурированных карт из подсказок или вызове LLM внутри запросов Cypher. НЕ обрабатывает конвейеры библиотеки Python neo4j-graphrag — используйте neo4j-graphrag-skill. НЕ обрабатывает создание/поиск векторного индекса — используйте neo4j-vector-index-skill.
