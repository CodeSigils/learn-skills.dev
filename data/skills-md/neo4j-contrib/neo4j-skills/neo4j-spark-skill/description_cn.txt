在使用 Apache Spark 的 Neo4j 连接器 (org.neo4j:neo4j-connector-apache-spark) 通过 Apache Spark 或 Databricks 读取或写入 Neo4j 时使用。涵盖 SparkSession 设置、DataFrame 通过标签/Cypher/关系扫描读取、DataFrame 使用 SaveMode 写入、用于 MERGE 的 node.keys、关系写入映射、分区和批量调整、PySpark 和 Scala 示例、Databricks 集群配置、Databricks 凭证秘密、Delta Lake 到 Neo4j 管道。不处理 Cypher 创作 — 使用 neo4j-cypher-skill。不处理 Python 螺栓驱动程序 — 使用 neo4j-driver-python-skill。不处理 GDS 算法 — 使用 neo4j-gds-skill。
