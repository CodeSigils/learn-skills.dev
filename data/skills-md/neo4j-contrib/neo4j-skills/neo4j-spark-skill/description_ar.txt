استخدمه عند القراءة من Neo4j أو الكتابة إليه باستخدام Apache Spark أو Databricks باستخدام موصل Neo4j لـ Apache Spark (org.neo4j:neo4j-connector-apache-spark). يغطي إعداد SparkSession، ويقرأ DataFrame عبر التسميات/Cypher/فحص العلاقة، ويكتب DataFrame باستخدام SaveMode، وnode.keys لـ MERGE، ورسم خرائط كتابة العلاقة، وضبط التقسيم والدفعة، وأمثلة PySpark وScala، وتكوين مجموعة Databricks، وأسرار Databricks لبيانات الاعتماد، وخطوط أنابيب Delta Lake إلى Neo4j. لا يتعامل مع تأليف Cypher — استخدم neo4j-cypher-skill. لا يتعامل مع برنامج تشغيل Python - استخدم neo4j-driver-python-skill. لا يتعامل مع خوارزميات GDS — استخدم neo4j-gds-skill.
