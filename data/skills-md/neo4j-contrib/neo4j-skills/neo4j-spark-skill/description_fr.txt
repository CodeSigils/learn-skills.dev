À utiliser lors de la lecture ou de l'écriture sur Neo4j avec Apache Spark ou Databricks à l'aide du connecteur Neo4j pour Apache Spark (org.neo4j:neo4j-connector-apache-spark). Couvre la configuration de SparkSession, les lectures DataFrame via l'analyse des étiquettes/Cypher/relation, les écritures DataFrame avec SaveMode, node.keys pour MERGE, le mappage d'écriture des relations, le réglage des partitions et des lots, les exemples PySpark et Scala, la configuration du cluster Databricks, les secrets Databricks pour les informations d'identification, les pipelines Delta Lake vers Neo4j. Ne gère PAS la création de Cypher – utilisez neo4j-cypher-skill. Ne gère PAS le pilote de boulon Python – utilisez neo4j-driver-python-skill. Ne gère PAS les algorithmes GDS — utilisez neo4j-gds-skill.
