Используйте при чтении или записи в Neo4j с помощью Apache Spark или Databricks с использованием соединителя Neo4j для Apache Spark (org.neo4j:neo4j-connector-apache-spark). Охватывает настройку SparkSession, чтение DataFrame через метки/Cypher/сканирование отношений, запись DataFrame с использованием SaveMode, node.keys для MERGE, сопоставление записи отношений, настройку разделов и пакетов, примеры PySpark и Scala, конфигурацию кластера Databricks, секреты Databricks для учетных данных, конвейеры Delta Lake для Neo4j. НЕ поддерживает авторинг Cypher — используйте neo4j-cypher-skill. НЕ обрабатывает драйвер болта Python — используйте neo4j-driver-python-skill. НЕ обрабатывает алгоритмы GDS — используйте neo4j-gds-skill.
