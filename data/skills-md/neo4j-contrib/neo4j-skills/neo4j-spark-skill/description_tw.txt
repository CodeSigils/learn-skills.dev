使用 Apache Spark 的 Neo4j 連接器 (org.neo4j:neo4j-connector-apache-spark) 透過 Apache Spark 或 Databricks 讀取或寫入 Neo4j 時使用。涵蓋 SparkSession 設定、DataFrame 透過標籤/Cypher/關係掃描讀取、DataFrame 使用 SaveMode 寫入、用於 MERGE 的 node.keys、關係寫入映射、分區和批次調整、PySpark 和 Scala 範例、Databricks 叢集配置、Databricks 憑證秘密、Delta Lake 到 Neo4j 管道。不處理 Cypher 創作 — 使用 neo4j-cypher-skill。不處理 Python 螺栓驅動程式 — 使用 neo4j-driver-python-skill。不處理 GDS 演算法 — 使用 neo4j-gds-skill。
