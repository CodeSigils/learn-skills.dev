Neo4j Connector for Apache Spark (org.neo4j:neo4j-connector-apache-spark) を使用して、Apache Spark または Databricks で Neo4j との間で読み取りまたは書き込みを行うときに使用します。 SparkSession のセットアップ、ラベル/Cypher/リレーションシップ スキャンによる DataFrame の読み取り、SaveMode を使用した DataFrame の書き込み、MERGE 用の node.keys、リレーションシップの書き込みマッピング、パーティションとバッチのチューニング、PySpark と Scala の例、Databricks クラスターの構成、資格情報の Databricks シークレット、Delta Lake から Neo4j パイプラインまでをカバーします。 Cypher オーサリングは処理しません。neo4j-cypher-skill を使用します。 Python ボルト ドライバーは処理しません。neo4j-driver-python-skill を使用します。 GDS アルゴリズムは処理しません。neo4j-gds-skill を使用します。
