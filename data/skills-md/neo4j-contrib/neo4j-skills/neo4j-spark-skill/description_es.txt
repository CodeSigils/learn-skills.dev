Úselo al leer o escribir en Neo4j con Apache Spark o Databricks mediante el conector Neo4j para Apache Spark (org.neo4j:neo4j-connector-apache-spark). Cubre la configuración de SparkSession, lecturas de DataFrame a través de etiquetas/Cypher/escaneo de relaciones, escrituras de DataFrame con SaveMode, node.keys para MERGE, mapeo de escritura de relaciones, ajuste de particiones y lotes, ejemplos de PySpark y Scala, configuración de clúster de Databricks, secretos de Databricks para credenciales, canalizaciones de Delta Lake a Neo4j. NO maneja la creación de Cypher: use neo4j-cypher-skill. NO maneja el destornillador Python; use neo4j-driver-python-skill. NO maneja algoritmos GDS; use neo4j-gds-skill.
