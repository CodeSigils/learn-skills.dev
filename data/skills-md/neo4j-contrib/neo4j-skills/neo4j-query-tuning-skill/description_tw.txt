透過讀取執行計劃、識別不良運算子（AllNodesScan、CartesianProduct、Eager、NodeByLabelScan）以及規定修復（索引、提示、查詢重寫、執行時間選擇）來診斷和修復緩慢的 Neo4j Cypher 查詢。當查詢速度較慢時、當 EXPLAIN 或 PROFILE 輸出需要解釋時、當 dbHits 或 pageCacheHitRatio 很差時、當基數估計與實際值不同時，或在分槽/管道/並行運行時之間做出決定時使用。涵蓋 USING INDEX / USING SCAN / USING JOIN 提示、db.stats.retrieve、SHOW QUERIES、SHOW TRANSACTIONS、TERMINATE TRANSACTION。不從頭開始編寫新的 Cypher - 使用 neo4j-cypher-skill。不涵蓋 GDS 演算法調整 - 使用 neo4j-gds-skill。不涵蓋索引/約束創建語法細節 - 使用 neo4j-cypher-skillreferences/indexes.md。
