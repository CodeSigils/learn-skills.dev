Диагностирует и исправляет медленные запросы Neo4j Cypher, читая планы выполнения, выявляя плохие операторы (AllNodesScan, CartesianProduct, Eager, NodeByLabelScan) и предписывая исправления (индексы, подсказки, перезапись запросов, выбор времени выполнения). Используйте, когда запрос медленный, когда выходные данные EXPLAIN или PROFILE требуют интерпретации, когда dbHits или pageCacheHitRatio неудовлетворительны, когда оценка мощности отличается от фактической или при выборе между слотированной, конвейерной или параллельной средой выполнения. Охватывает подсказки USING INDEX / USING SCAN / USING JOIN, db.stats.retrieve, SHOW QERIES, SHOW TRANSACTIONS, TERMINATE TRANSACTION. НЕ пишет новый Cypher с нуля — используйте neo4j-cypher-skill. НЕ охватывает настройку алгоритма GDS — используйте neo4j-gds-skill. НЕ охватывает детали синтаксиса создания индексов/ограничений — используйте ссылки neo4j-cypher-skill/indexes.md.
