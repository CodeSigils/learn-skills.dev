실행 계획을 읽고 잘못된 연산자(AllNodesScan, CartesianProduct, Eager, NodeByLabelScan)를 식별하고 수정 사항(인덱스, 힌트, 쿼리 재작성, 런타임 선택)을 처방하여 느린 Neo4j Cypher 쿼리를 진단하고 수정합니다. 쿼리가 느릴 때, EXPLAIN 또는 PROFILE 출력에 해석이 필요할 때, dbHits 또는 pageCacheHitRatio가 좋지 않을 때, 카디널리티 추정이 실제와 다를 때 또는 슬롯/파이프라인/병렬 런타임 간에 결정할 때 사용합니다. USING INDEX / USING SCAN / USING JOIN 힌트, db.stats.retrieve, SHOW QUERIES, SHOW TRANSACTIONS, TERMINATE TRANSACTION을 다룹니다. 처음부터 새로운 Cypher를 작성하지 않습니다. neo4j-cypher-skill을 사용하십시오. GDS 알고리즘 튜닝은 다루지 않습니다. neo4j-gds-skill을 사용하십시오. 인덱스/제약 조건 생성 구문 세부 정보는 다루지 않습니다. neo4j-cypher-skill reference/indexes.md를 사용하세요.
