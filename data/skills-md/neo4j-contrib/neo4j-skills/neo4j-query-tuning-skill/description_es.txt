Diagnostica y corrige consultas lentas de Neo4j Cypher leyendo planes de ejecución, identificando operadores incorrectos (AllNodesScan, CartesianProduct, Eager, NodeByLabelScan) y prescribiendo correcciones (índices, sugerencias, reescrituras de consultas, selección de tiempo de ejecución). Úselo cuando una consulta es lenta, cuando la salida EXPLAIN o PROFILE necesita interpretación, cuando dbHits o pageCacheHitRatio son deficientes, cuando la estimación de cardinalidad difiere de los datos reales o cuando se decide entre tiempos de ejecución ranurados/canalizados/paralelos. Cubre USO DEL ÍNDICE / USO DEL ESCANEO / USO DE sugerencias PARA UNIRSE, db.stats.retrieve, MOSTRAR CONSULTAS, MOSTRAR TRANSACCIONES, TERMINAR TRANSACCIÓN. NO cubre los detalles de sintaxis de creación de índices/restricciones; utilice neo4j-cypher-skill references/indexes.md.
