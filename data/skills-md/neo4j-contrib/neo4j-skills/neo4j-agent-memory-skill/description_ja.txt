neo4j-agent-memory Python パッケージ (Neo4j 上に構築された AI エージェント用のグラフネイティブ メモリ システム) およびホストされたサービス (NAMS) に関する信頼できるリファレンス (memory.neo4jlabs.com)。ユーザーが neo4j-agent-memory、Neo4j によるエージェント メモリ、コンテキスト グラフ、POLE+O モデル、MemoryClient/MemorySettings、メモリ MCP サーバー、またはフレームワーク統合 (LangChain、PydanticAI、CrewAI、AWS Strands、Google ADK、Microsoft Agent Framework、OpenAI Agents、LlamaIndex) について言及するたびにこのスキルを使用します。ユーザーが、memory.neo4jlabs.com、NAMS、Neo4j Agent Memory Service、`nams_` API キー プレフィックス、またはホストされた MCP エンドポイントでホストされているサービスに言及する場合にも使用します。また、プロジェクトのドキュメント、ブログ投稿、チュートリアル、PRD、またはコード サンプルを作成するとき、エージェント メモリのアプローチを比較するとき、またはベクトルのみのアプローチに対してグラフ ネイティブ メモリを位置付けるときにも使用します (ユーザーが明示的にパッケージに名前を付けていない場合でも)。
