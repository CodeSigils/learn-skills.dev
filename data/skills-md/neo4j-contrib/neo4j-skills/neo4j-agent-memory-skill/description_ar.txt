مرجع موثوق لحزمة Python neo4j-agent-memory - نظام ذاكرة أصلي للرسم البياني لوكلاء الذكاء الاصطناعي المبني على Neo4j - وللخدمة المستضافة (NAMS) على Memory.neo4jlabs.com. استخدم هذه المهارة عندما يذكر المستخدم ذاكرة وكيل neo4j، أو ذاكرة الوكيل مع Neo4j، أو الرسوم البيانية السياقية، أو نموذج POLE+O، أو MemoryClient/MemorySettings، أو خادم الذاكرة MCP، أو أي من عمليات تكامل إطار العمل (LangChain، أو PydanticAI، أو CrewAI، أو AWS Strands، أو Google ADK، أو Microsoft Agent Framework، أو OpenAI Agents، أو LlamaIndex). استخدمه أيضًا عندما يذكر المستخدم الخدمة المستضافة على Memory.neo4jlabs.com، أو NAMS، أو Neo4j Agent Memory Service، أو بادئة مفتاح `nams_` API، أو نقطة نهاية MCP المستضافة. استخدمه أيضًا عند كتابة الوثائق، أو منشورات المدونة، أو البرامج التعليمية، أو PRDs، أو نماذج التعليمات البرمجية للمشروع، عند مقارنة أساليب ذاكرة الوكيل، أو عند وضع ذاكرة الرسم البياني الأصلية مقابل أساليب المتجهات فقط - حتى إذا لم يقم المستخدم بتسمية الحزمة بشكل صريح.
