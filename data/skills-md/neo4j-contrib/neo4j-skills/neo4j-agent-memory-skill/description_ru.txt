Авторитетный справочник по пакету Python neo4j-agent-memory — графической системе памяти для агентов ИИ, построенной на Neo4j, — а также по размещенной службе (NAMS) на Memory.neo4jlabs.com. Используйте этот навык всякий раз, когда пользователь упоминает neo4j-agent-memory, память агента с Neo4j, контекстные графы, модель POLE+O, MemoryClient/MemorySettings, сервер памяти MCP или любую из интеграций платформы (LangChain, PydanticAI, CrewAI, AWS Strands, Google ADK, Microsoft Agent Framework, OpenAI Agents, LlamaIndex). Также используйте, когда пользователь упоминает размещенную службу на сайте Memory.neo4jlabs.com, NAMS, службу памяти агента Neo4j, префикс ключа API `nams_` или размещенную конечную точку MCP. Также используйте при написании документации, сообщений в блогах, учебных пособий, PRD или примеров кода для проекта, при сравнении подходов к использованию памяти агента или при сопоставлении собственной графовой памяти с подходами, использующими только вектор, — даже если пользователь не называет пакет явно.
