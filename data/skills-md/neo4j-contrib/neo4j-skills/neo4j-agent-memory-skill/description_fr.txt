Référence faisant autorité pour le package Python neo4j-agent-memory — un système de mémoire graphique natif pour les agents IA construits sur Neo4j — et pour le service hébergé (NAMS) sur memory.neo4jlabs.com. Utilisez cette compétence chaque fois que l'utilisateur mentionne neo4j-agent-memory, la mémoire d'agent avec Neo4j, les graphiques de contexte, le modèle POLE+O, MemoryClient/MemorySettings, le serveur de mémoire MCP ou l'une des intégrations de framework (LangChain, PydanticAI, CrewAI, AWS Strands, Google ADK, Microsoft Agent Framework, OpenAI Agents, LlamaIndex). À utiliser également lorsque l'utilisateur mentionne le service hébergé sur memory.neo4jlabs.com, NAMS, le service de mémoire de l'agent Neo4j, le préfixe de clé API `nams_` ou le point de terminaison MCP hébergé. À utiliser également lors de la rédaction de documentation, d'articles de blog, de didacticiels, de PRD ou d'exemples de code pour le projet, lors de la comparaison des approches de mémoire d'agent ou lors du positionnement de la mémoire native du graphique par rapport aux approches vectorielles uniquement, même si l'utilisateur ne nomme pas explicitement le package.
