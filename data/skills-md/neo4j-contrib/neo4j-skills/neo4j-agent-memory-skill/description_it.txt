Riferimento autorevole per il pacchetto Python neo4j-agent-memory, un sistema di memoria nativo per grafici per agenti AI costruito su Neo4j, e per il servizio ospitato (NAMS) su memory.neo4jlabs.com. Utilizza questa competenza ogni volta che l'utente menziona neo4j-agent-memory, la memoria dell'agente con Neo4j, i grafici di contesto, il modello POLE+O, MemoryClient/MemorySettings, il server MCP di memoria o qualsiasi integrazione del framework (LangChain, PydanticAI, CrewAI, AWS Strands, Google ADK, Microsoft Agent Framework, OpenAI Agents, LlamaIndex). Da utilizzare anche quando l'utente menziona il servizio ospitato su memory.neo4jlabs.com, NAMS, il servizio di memoria dell'agente Neo4j, il prefisso della chiave API `nams_` o l'endpoint MCP ospitato. Da utilizzare anche quando si scrive documentazione, post di blog, esercitazioni, PRD o esempi di codice per il progetto, quando si confrontano gli approcci alla memoria dell'agente o quando si posiziona la memoria nativa del grafico rispetto ad approcci solo vettoriali, anche se l'utente non nomina esplicitamente il pacchetto.
