Referencia autorizada para el paquete Python neo4j-agent-memory, un sistema de memoria nativa de gráficos para agentes de IA creado en Neo4j, y para el servicio alojado (NAMS) en Memory.neo4jlabs.com. Utilice esta habilidad siempre que el usuario mencione neo4j-agent-memory, memoria de agente con Neo4j, gráficos de contexto, el modelo POLE+O, MemoryClient/MemorySettings, el servidor MCP de memoria o cualquiera de las integraciones del marco (LangChain, PydanticAI, CrewAI, AWS Strands, Google ADK, Microsoft Agent Framework, OpenAI Agents, LlamaIndex). Utilícelo también cuando el usuario mencione el servicio alojado en memoria.neo4jlabs.com, NAMS, el servicio de memoria del agente Neo4j, el prefijo de clave API `nams_` o el punto final MCP alojado. Úselo también al escribir documentación, publicaciones de blog, tutoriales, PRD o ejemplos de código para el proyecto, al comparar enfoques de memoria del agente o al posicionar la memoria nativa de gráficos frente a enfoques de solo vectores, incluso si el usuario no nombra explícitamente el paquete.
