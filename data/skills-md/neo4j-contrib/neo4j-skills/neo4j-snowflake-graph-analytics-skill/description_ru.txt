Запускайте алгоритмы графической аналитики Neo4j (PageRank, Louvain, WCC, Dijkstra, KNN, Node2Vec, FastRP, GraphSAGE) непосредственно внутри Snowflake без перемещения данных. Используйте при запуске графовых алгоритмов с таблицами Snowflake через приложение Neo4j Snowflake Native («GDS Snowflake», «графовые алгоритмы в Snowflake», «Neo4j Graph Analytics»). Охватывает установку, настройку привилегий, шаблон записи вычислений проекта и синтаксис SQL CALL. НЕ охватывает запросы к СУБД Cypher или Neo4j — используйте neo4j-cypher-skill. НЕ охватывает Aura Graph Analytics — используйте neo4j-aura-graph-analytics-skill. НЕ распространяется на самоуправляемую GDS — используйте neo4j-gds-skill.
