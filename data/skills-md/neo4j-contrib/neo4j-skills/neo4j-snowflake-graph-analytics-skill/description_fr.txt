Exécutez les algorithmes Neo4j Graph Analytics (PageRank, Louvain, WCC, Dijkstra, KNN, Node2Vec, FastRP, GraphSAGE) directement dans Snowflake sans déplacer de données. À utiliser lors de l'exécution d'algorithmes graphiques sur des tables Snowflake via l'application native Neo4j Snowflake ("GDS Snowflake", "algorithmes graphiques dans Snowflake", "Neo4j Graph Analytics"). Couvre l'installation, la configuration des privilèges, le modèle de calcul-écriture de projet et la syntaxe SQL CALL. Ne couvre PAS les requêtes SGBD Cypher ou Neo4j – utilisez neo4j-cypher-skill. Ne couvre PAS Aura Graph Analytics – utilisez neo4j-aura-graph-analytics-skill. Ne couvre PAS les GDS autogérés – utilisez neo4j-gds-skill.
