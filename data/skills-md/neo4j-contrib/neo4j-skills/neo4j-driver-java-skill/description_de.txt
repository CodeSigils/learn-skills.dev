Neo4j Java-Treiber v6 – Treiberlebenszyklus, Maven/Gradle-Setup, ausführbare Abfrage, verwaltete Transaktionen mit „executeRead/Write“, explizite Transaktionen, asynchrone/reaktive Muster, Fehlerbehandlung, Datentypzuordnung, Optimierung des Verbindungspools, kausale Konsistenz/Lesezeichen. Wird zum Schreiben von Java- oder Kotlin-Code verwendet, der über GraphDatabase.driver, executableQuery, SessionConfig,executeRead,executeWrite oder TransactionCallback eine Verbindung zu Neo4j herstellt. Übernimmt NICHT das Cypher-Authoring – verwenden Sie neo4j-cypher-skill. Deckt NICHT Treiberversions-Upgrades ab – verwenden Sie neo4j-migration-skill. Deckt Spring Data Neo4j (@Node, Neo4jRepository) NICHT ab – verwenden Sie neo4j-spring-data-skill.
