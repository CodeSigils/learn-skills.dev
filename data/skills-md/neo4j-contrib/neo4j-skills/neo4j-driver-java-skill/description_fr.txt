Neo4j Java Driver v6 — cycle de vie du pilote, configuration Maven/Gradle, requête exécutable, transactions gérées par exécution/écriture, transactions explicites, modèles asynchrones/réactifs, gestion des erreurs, mappage des types de données, réglage du pool de connexions, cohérence causale/signets. À utiliser lors de l'écriture de code Java ou Kotlin qui se connecte à Neo4j via GraphDatabase.driver, executableQuery, SessionConfig,executeRead,executeWrite ou TransactionCallback. Ne gère PAS la création de Cypher – utilisez neo4j-cypher-skill. Ne couvre PAS les mises à niveau de la version du pilote – utilisez neo4j-migration-skill. Ne couvre PAS Spring Data Neo4j (@Node, Neo4jRepository) — utilisez neo4j-spring-data-skill.
