Neo4j Java Driver v6 — жизненный цикл драйвера, настройка Maven/Gradle, исполняемый запрос, выполнение управляемых транзакций Read/Write, явные транзакции, асинхронные/реактивные шаблоны, обработка ошибок, сопоставление типов данных, настройка пула соединений, причинная согласованность/закладки. Используйте при написании кода Java или Kotlin, который подключается к Neo4j через GraphDatabase.driver, executableQuery, SessionConfig, ExecuteRead, ExecuteWrite или TransactionCallback. НЕ поддерживает авторинг Cypher — используйте neo4j-cypher-skill. НЕ распространяется на обновления версий драйверов — используйте neo4j-migration-skill. НЕ распространяется на Spring Data Neo4j (@Node, Neo4jRepository) — используйте neo4j-spring-data-skill.
