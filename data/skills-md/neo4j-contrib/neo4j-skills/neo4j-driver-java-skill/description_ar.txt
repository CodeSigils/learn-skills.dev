Neo4j Java Driver v6 - دورة حياة برنامج التشغيل، إعداد Maven/Gradle، الاستعلام القابل للتنفيذ، تنفيذ المعاملات المُدارة للقراءة/الكتابة، المعاملات الصريحة، الأنماط غير المتزامنة/التفاعلية، معالجة الأخطاء، تعيين نوع البيانات، ضبط تجمع الاتصال، الاتساق السببي/الإشارات المرجعية. يُستخدم عند كتابة كود Java أو Kotlin الذي يتصل بـ Neo4j عبر GraphDatabase.driver، أو executableQuery، أو SessionConfig، أو ExecuteRead، أو ExecuteWrite، أو TransactionCallback. لا يتعامل مع تأليف Cypher — استخدم neo4j-cypher-skill. لا يشمل ترقيات إصدار برنامج التشغيل — استخدم neo4j-migration-skill. لا يغطي Spring Data Neo4j (@Node, Neo4jRepository) - استخدم neo4j-spring-data-skill.
