Neo4j 可视化库 (NVL) — 与框架无关的浏览器图形渲染。涵盖 @neo4j-nvl/base（NVL 类、节点/关系、Canvas 与 WebGL 渲染器）、@neo4j-nvl/interaction-handlers（ZoomInteraction、PanInteraction、DragNodeInteraction、ClickInteraction、HoverInteraction、BoxSelectInteraction、LassoInteraction、KeyboardInteraction）和 @neo4j-nvl/react（InteractiveNvlWrapper、 BasicNvlWrapper、StaticPictureWrapper）。在浏览器中渲染 Neo4j 图形、通过 nvlResultTransformer 提供驱动程序结果、选择 Canvas 与 WebGL、连接节点/关系单击/悬停/拖动处理程序或在 React、Vite 或 vanilla JS 应用程序中嵌入 NVL 时使用。不处理 Cypher 查询创作 - 使用 neo4j-cypher-skill。不处理驱动程序生命周期、会话或executeQuery设置——使用neo4j-driver-javascript-skill。不处理 GraphVisualization/Needle 默认嵌入 - 使用 @neo4j-ndl/react。
