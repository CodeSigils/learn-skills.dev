Neo4j Python Driver v6: ciclo de vida del controlador, ejecución_query, transacciones administradas y explícitas, asíncrono (AsyncGraphDatabase), manejo de resultados, mapeo de tipos de datos, manejo de errores, procesamiento por lotes UNWIND, ajuste del grupo de conexiones y coherencia causal. Úselo al escribir código Python que se conecta a Neo4j a través de GraphDatabase.driver, ejecutar_query, ejecutar_lectura, ejecutar_escribir, AsyncGraphDatabase, neo4j.Result o RoutingControl. El nombre del paquete es `neo4j` (no neo4j-driver) desde v6. Se requiere Python >=3.10. NO maneja la creación de consultas Cypher; use neo4j-cypher-skill. NO cubre actualizaciones de controladores ni cambios importantes; utilice neo4j-migration-skill. NO cubre las canalizaciones GraphRAG (paquete neo4j-graphrag); use neo4j-graphrag-skill.
