Neo4j Python 드라이버 v6 — 드라이버 수명 주기, 실행 쿼리, 관리형 및 명시적 트랜잭션, 비동기(AsyncGraphDatabase), 결과 처리, 데이터 유형 매핑, 오류 처리, UNWIND 일괄 처리, 연결 풀 조정 및 인과적 일관성. GraphDatabase.driver,execute_query,execute_read,execute_write, AsyncGraphDatabase, neo4j.Result 또는 RoutingControl을 통해 Neo4j에 연결하는 Python 코드를 작성할 때 사용합니다. v6부터 패키지 이름은 `neo4j`(neo4j-driver가 아님)입니다. Python >=3.10이 필요합니다. Cypher 쿼리 작성을 처리하지 않습니다. neo4j-cypher-skill을 사용하세요. 드라이버 업그레이드 또는 주요 변경 사항은 다루지 않습니다. neo4j-migration-skill을 사용하십시오. GraphRAG 파이프라인(neo4j-graphrag 패키지)은 다루지 않습니다. neo4j-graphrag-skill을 사용하세요.
