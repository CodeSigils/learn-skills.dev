Neo4j Python 驱动程序 v6 — 驱动程序生命周期、execute_query、托管和显式事务、异步 (AsyncGraphDatabase)、结果处理、数据类型映射、错误处理、UNWIND 批处理、连接池调整和因果一致性。在编写通过 GraphDatabase.driver、execute_query、execute_read、execute_write、AsyncGraphDatabase、neo4j.Result 或 RoutingControl 连接到 Neo4j 的 Python 代码时使用。自 v6 起，软件包名称为“neo4j”（不是 neo4j-driver）。需要 Python >=3.10。不处理 Cypher 查询创作 - 使用 neo4j-cypher-skill。不涵盖驱动程序升级或重大更改 - 使用 neo4j-migration-skill。不涵盖 GraphRAG 管道（neo4j-graphrag 包）——使用 neo4j-graphrag-skill。
