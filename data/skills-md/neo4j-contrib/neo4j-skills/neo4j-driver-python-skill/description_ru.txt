Neo4j Python Driver v6 — жизненный цикл драйвера, выполнение_запроса, управляемые и явные транзакции, асинхронность (AsyncGraphDatabase), обработка результатов, сопоставление типов данных, обработка ошибок, пакетная обработка UNWIND, настройка пула соединений и причинно-следственная согласованность. Используйте при написании кода Python, который подключается к Neo4j через GraphDatabase.driver, Execute_query, Execute_read, Execute_write, AsyncGraphDatabase, neo4j.Result или RoutingControl. Имя пакета — neo4j (не neo4j-driver), начиная с v6. Требуется Python >= 3.10. НЕ обрабатывает создание запросов Cypher — используйте neo4j-cypher-skill. НЕ распространяется на обновления драйверов или критические изменения — используйте neo4j-migration-skill. НЕ распространяется на конвейеры GraphRAG (пакет neo4j-graphrag) — используйте neo4j-graphrag-skill.
