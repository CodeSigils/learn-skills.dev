Neo4j Python Driver v6 — cycle de vie du pilote, execute_query, transactions gérées et explicites, async (AsyncGraphDatabase), gestion des résultats, mappage des types de données, gestion des erreurs, traitement par lots UNWIND, réglage du pool de connexions et cohérence causale. À utiliser lors de l'écriture de code Python qui se connecte à Neo4j via GraphDatabase.driver,execute_query,execute_read,execute_write,AsyncGraphDatabase,neo4j.Result ou RoutingControl. Le nom du package est « neo4j » (pas neo4j-driver) depuis la v6. Python >=3.10 requis. Ne gère PAS la création de requêtes Cypher – utilisez neo4j-cypher-skill. Ne couvre PAS les mises à niveau des pilotes ou les modifications importantes – utilisez neo4j-migration-skill. Ne couvre PAS les pipelines GraphRAG (package neo4j-graphrag) — utilisez neo4j-graphrag-skill.
