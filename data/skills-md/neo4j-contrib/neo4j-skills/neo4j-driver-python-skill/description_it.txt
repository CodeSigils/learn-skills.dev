Neo4j Python Driver v6: ciclo di vita del driver, esecuzione_query, transazioni gestite ed esplicite, asincrono (AsyncGraphDatabase), gestione dei risultati, mappatura del tipo di dati, gestione degli errori, batch UNWIND, ottimizzazione del pool di connessioni e coerenza causale. Da utilizzare durante la scrittura di codice Python che si connette a Neo4j tramite GraphDatabase.driver,execute_query,execute_read,execute_write, AsyncGraphDatabase, neo4j.Result o RoutingControl. Il nome del pacchetto è "neo4j" (non neo4j-driver) dalla versione v6. Python >=3.10 richiesto. NON gestisce la creazione di query Cypher: utilizza neo4j-cypher-skill. NON copre gli aggiornamenti dei driver o le modifiche importanti: utilizza neo4j-migration-skill. NON copre le pipeline GraphRAG (pacchetto neo4j-graphrag): utilizzare neo4j-graphrag-skill.
