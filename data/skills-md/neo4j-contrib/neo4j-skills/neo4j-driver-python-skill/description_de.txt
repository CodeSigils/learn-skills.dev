Neo4j Python Driver v6 – Treiberlebenszyklus,execute_query, verwaltete und explizite Transaktionen, asynchron (AsyncGraphDatabase), Ergebnisverarbeitung, Datentypzuordnung, Fehlerbehandlung, UNWIND-Batching, Verbindungspooloptimierung und kausale Konsistenz. Wird beim Schreiben von Python-Code verwendet, der über GraphDatabase.driver,execute_query,execute_read,execute_write, AsyncGraphDatabase, neo4j.Result oder RoutingControl eine Verbindung zu Neo4j herstellt. Der Paketname lautet seit Version 6 „neo4j“ (nicht „neo4j-driver“). Python >=3.10 erforderlich. Übernimmt NICHT die Erstellung von Cypher-Abfragen – verwenden Sie neo4j-cypher-skill. Deckt NICHT Treiber-Upgrades oder Breaking Changes ab – verwenden Sie neo4j-migration-skill. Gilt NICHT für GraphRAG-Pipelines (neo4j-graphrag-Paket) – verwenden Sie neo4j-graphrag-skill.
