Neo4j Python Driver v6 — ドライバーのライフサイクル、execute_query、マネージドおよび明示的なトランザクション、非同期 (AsyncGraphDatabase)、結果処理、データ型マッピング、エラー処理、UNWIND バッチ処理、接続プール調整、および因果関係の一貫性。 GraphDatabase.driver、execute_query、execute_read、execute_write、AsyncGraphDatabase、neo4j.Result、または RoutingControl を介して Neo4j に接続する Python コードを作成するときに使用します。 v6 以降、パッケージ名は `neo4j` (neo4j-driver ではありません) です。 Python 3.10 以上が必要です。 Cypher クエリの作成は処理しません。neo4j-cypher-skill を使用します。ドライバーのアップグレードや重大な変更は対象外です。neo4j-migration-skill を使用してください。 GraphRAG パイプライン (neo4j-graphrag パッケージ) はカバーしていません。neo4j-graphrag-skill を使用してください。
