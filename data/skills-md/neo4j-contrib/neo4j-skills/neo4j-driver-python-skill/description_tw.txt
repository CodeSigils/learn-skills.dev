Neo4j Python 驅動程式 v6 — 驅動程式生命週期、execute_query、託管和明確交易、非同步 (AsyncGraphDatabase)、結果處理、資料類型對應、錯誤處理、UNWIND 批次、連線池調整和因果一致性。在編寫透過 GraphDatabase.driver、execute_query、execute_read、execute_write、AsyncGraphDatabase、neo4j.Result 或 RoutingControl 連接到 Neo4j 的 Python 程式碼時使用。自 v6 起，軟體包名稱為「neo4j」（不是 neo4j-driver）。需要 Python >=3.10。不處理 Cypher 查詢創作 - 使用 neo4j-cypher-skill。不涵蓋驅動程式升級或重大變更 - 使用 neo4j-migration-skill。不涵蓋 GraphRAG 管道（neo4j-graphrag 套件）——使用 neo4j-graphrag-skill。
