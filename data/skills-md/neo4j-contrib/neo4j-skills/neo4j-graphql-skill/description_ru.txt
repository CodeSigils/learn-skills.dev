Создайте и настройте API GraphQL на базе Neo4j, используя @neo4j/graphql v7 (текущий) или v5 (LTS). Охватывает конструктор Neo4jGraphQL, getSchema(), AssertIndexesAndConstraints(), определения типов с помощью @node, @relationship (IN/OUT/UNDIRECTED), @cypher для пользовательских преобразователей, @authorization/@authentication для безопасности JWT/JWKS, автоматически генерируемые запросы/мутации, программный доступ OGM, подписки через CDC и Apollo Federation. Используйте при написании typeDefs, защите полей или подключении Neo4j к серверу Apollo. НЕ обрабатывает необработанные внешние преобразователи Cypher — используйте neo4j-cypher-skill. НЕ охватывает сопоставление объектов Spring Data Neo4j — используйте neo4j-spring-data-skill.
