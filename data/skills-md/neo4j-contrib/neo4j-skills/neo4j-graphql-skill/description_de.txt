Erstellen und konfigurieren Sie eine von Neo4j unterstützte GraphQL-API mit @neo4j/graphql v7 (aktuell) oder v5 (LTS). Behandelt den Neo4jGraphQL-Konstruktor, getSchema(), AssertIndexesAndConstraints(), Typdefinitionen mit @node, @relationship (IN/OUT/UNDIRECTED), @cypher für benutzerdefinierte Resolver, @authorization/@authentication für JWT/JWKS-Sicherheit, automatisch generierte Abfragen/Mutationen, programmgesteuerten OGM-Zugriff, Abonnements über CDC und Apollo Federation. Zum Schreiben von TypeDefs, zum Sichern von Feldern oder zum Verbinden von Neo4j mit Apollo Server. Verarbeitet NICHT rohes Cypher außerhalb von Resolvern – verwenden Sie neo4j-cypher-skill. Deckt die Entitätszuordnung von Spring Data Neo4j NICHT ab – verwenden Sie neo4j-spring-data-skill.
