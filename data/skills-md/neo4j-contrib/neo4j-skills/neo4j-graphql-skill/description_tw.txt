使用 @neo4j/graphql v7（目前）或 v5（LTS）建置和配置由 Neo4j 支援的 GraphQL API。涵蓋 Neo4jGraphQL 構造函數、getSchema()、assertIndexesAndConstraints()、@node 的類型定義、@relationship (IN/OUT/UNDIRECTED)、用於自訂解析器的 @cypher、用於 JWTcation/JWKS 安全性的 @authorization/@authation 訂閱、透過程式化的查詢在編寫 typeDefs、保護欄位或將 Neo4j 連接到 Apollo Server 時使用。不處理解析器外部的原始 Cypher - 使用 neo4j-cypher-skill。不涵蓋 Spring Data Neo4j 實體映射 - 使用 neo4j-spring-data-skill。
