Cree y configure una API GraphQL respaldada por Neo4j usando @neo4j/graphql v7 (actual) o v5 (LTS). Cubre el constructor Neo4jGraphQL, getSchema(), afirmarIndexesAndConstraints(), definiciones de tipos con @node, @relationship (IN/OUT/UNDIRECTED), @cypher para solucionadores personalizados, @authorization/@authentication para seguridad JWT/JWKS, consultas/mutaciones generadas automáticamente, acceso programático OGM, suscripciones a través de CDC y Apollo Federation. Úselo al escribir typeDefs, proteger campos o conectar Neo4j al servidor Apollo. NO maneja resolutores externos de Cypher sin procesar; use neo4j-cypher-skill. NO cubre el mapeo de entidades Spring Data Neo4j; use neo4j-spring-data-skill.
