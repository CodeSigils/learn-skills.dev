@neo4j/graphql v7 (現在) または v5 (LTS) を使用して、Neo4j によってサポートされる GraphQL API を構築および構成します。 Neo4jGraphQL コンストラクター、getSchema()、assertIndexesAndConstraints()、@node による型定義、@relationship (IN/OUT/UNDIRECTED)、カスタム リゾルバーの @cypher、JWT/JWKS セキュリティの @authorization/@authentication、自動生成されたクエリ/ミューテーション、OGM プログラムによるアクセス、CDC 経由のサブスクリプション、および Apollo Federation をカバーします。 typeDef を記述するとき、フィールドを保護するとき、または Neo4j を Apollo Server に接続するときに使用します。リゾルバーの外部で生の Cypher を処理しません。neo4j-cypher-skill を使用します。 Spring Data Neo4j エンティティ マッピングはカバーしません。neo4j-spring-data-skill を使用してください。
