قم ببناء وتكوين واجهة برمجة تطبيقات GraphQL المدعومة من Neo4j باستخدام @neo4j/graphql v7 (الحالي) أو v5 (LTS). يغطي مُنشئ Neo4jGraphQL، وgetSchema()، وasserIndexesAndConstraints()، وتعريفات النوع باستخدام @node، و@relationship (IN/OUT/UNDIRECTED)، و@cypher للمحللات المخصصة، و@authorization/@authentication لأمان JWT/JWKS، والاستعلامات/الطفرات التي يتم إنشاؤها تلقائيًا، والوصول البرمجي لـ OGM، والاشتراكات عبر CDC، واتحاد Apollo. يُستخدم عند كتابة typeDefs أو تأمين الحقول أو توصيل Neo4j بخادم Apollo. لا يتعامل مع أدوات حل Cypher الخارجية — استخدم neo4j-cypher-skill. لا يغطي تعيين كيانات Spring Data Neo4j — استخدم neo4j-spring-data-skill.
