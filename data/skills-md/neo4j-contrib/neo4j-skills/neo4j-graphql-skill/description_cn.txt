使用 @neo4j/graphql v7（当前）或 v5（LTS）构建和配置由 Neo4j 支持的 GraphQL API。涵盖 Neo4jGraphQL 构造函数、getSchema()、assertIndexesAndConstraints()、@node 的类型定义、@relationship (IN/OUT/UNDIRECTED)、用于自定义解析器的 @cypher、用于 JWT/JWKS 安全性的 @authorization/@authentication、自动生成的查询/突变、OGM 编程访问、通过 CDC 订阅和 Apollo Federation。在编写 typeDefs、保护字段或将 Neo4j 连接到 Apollo Server 时使用。不处理解析器外部的原始 Cypher - 使用 neo4j-cypher-skill。不涵盖 Spring Data Neo4j 实体映射 - 使用 neo4j-spring-data-skill。
