Programmatische Sicherheitsverwaltung in Neo4j – RBAC/ABAC, Benutzerlebenszyklus (CREATE/ALTER/DROP USER), Rollenlebenszyklus (CREATE/GRANT ROLE/DROP ROLE), Gewährung und Verweigerung von Berechtigungen (GRANT/DENY/REVOKE für Diagramm, Datenbank, DBMS), Zugriffskontrolle auf Eigenschaftsebene, Zugriffskontrolle für untergeordnete Diagramme, SHOW PRIVILEGES-Inspektion und Konfigurationsreferenz des Authentifizierungsanbieters (LDAP, OIDC/SSO). Verwenden Sie diese Option, wenn ein Agent Benutzer, Rollen oder Berechtigungen programmgesteuert über Cypher in der Systemdatenbank verwalten muss. Verarbeitet NICHT das Schreiben von Cypher-Abfragen – verwenden Sie neo4j-cypher-skill. Verarbeitet KEINE Cluster-Operationen oder Backups – verwenden Sie neo4j-cli-tools-skill. Sicherheit auf Eigenschaftsebene und ABAC erfordern die Enterprise Edition.
