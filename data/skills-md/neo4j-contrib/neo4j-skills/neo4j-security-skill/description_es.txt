Gestión de seguridad programática en Neo4j: RBAC/ABAC, ciclo de vida del usuario (CREATE/ALTER/DROP USER), ciclo de vida del rol (CREATE/GRANT ROLE/DROP ROLE), concesión y denegación de privilegios (GRANT/DENY/REVOKE en gráfico, base de datos, DBMS), control de acceso a nivel de propiedad, control de acceso a subgráficos, inspección MOSTRAR PRIVILEGIOS y referencia de configuración del proveedor de autenticación (LDAP, OIDC/SSO). Úselo cuando un agente necesita administrar usuarios, roles o privilegios mediante programación a través de Cypher en la base de datos del sistema. NO maneja la escritura de consultas Cypher; use neo4j-cypher-skill. NO maneja operaciones de clúster ni copias de seguridad; use neo4j-cli-tools-skill. La seguridad a nivel de propiedad y ABAC requieren Enterprise Edition.
