使用 neo4j-graphrag Python 包（以前称为 neo4j-genai）在 Neo4j 上构建 GraphRAG 检索管道。涵盖检索器选择（VectorRetriever、HybridRetriever、VectorCypherRetriever、HybridCypherRetriever、Text2CypherRetriever）、retrieval_query Cypher 片段、query_params、管道接线（GraphRAG + LLM）、嵌入器设置、索引创建和 LangChain/LlamaIndex 集成。不处理文档中的 KG 构建 - 使用 neo4j-document-import-skill。不处理普通向量搜索 - 使用 neo4j-vector-index-skill。不处理 GDS 分析 — 使用 neo4j-gds-skill。不处理代理内存——使用 neo4j-agent-memory-skill。
