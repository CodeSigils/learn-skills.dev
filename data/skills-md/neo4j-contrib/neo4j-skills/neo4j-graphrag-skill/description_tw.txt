使用 neo4j-graphrag Python 套件（以前稱為 neo4j-genai）在 Neo4j 上建立 GraphRAG 檢索管道。涵蓋檢索器選擇（VectorRetriever、HybridRetriever、VectorCypherRetriever、HybridCypherRetriever、Text2CypherRetriever）、retrieval_query Cypher 片段、query_params、管道接線（GraphRAG + LLM）、嵌入器設定、索引建立和嵌入/Lparams。不處理文檔中的 KG 建置 - 使用 neo4j-document-import-skill。不處理普通向量搜尋 - 使用 neo4j-vector-index-skill。不處理 GDS 分析 — 使用 neo4j-gds-skill。不處理代理記憶體－使用 neo4j-agent-memory-skill。
