Cree canales de recuperación GraphRAG en Neo4j utilizando el paquete Python neo4j-graphrag (anteriormente neo4j-genai). Cubre la selección del recuperador (VectorRetriever, HybridRetriever, VectorCypherRetriever, HybridCypherRetriever, Text2CypherRetriever), fragmentos de recuperación_query Cypher, query_params, cableado de canalización (GraphRAG + LLM), configuración del incrustador, creación de índices e integración LangChain/LlamaIndex. NO maneja la construcción de KG a partir de documentos; use neo4j-document-import-skill. NO maneja búsqueda vectorial simple: use neo4j-vector-index-skill. NO maneja análisis GDS: use neo4j-gds-skill. NO maneja la memoria del agente: use neo4j-agent-memory-skill.
