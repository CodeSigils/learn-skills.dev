v2beta1 REST API를 통해 Neo4j Aura 에이전트를 관리합니다. AuraDB 인스턴스가 지원하는 Aura 에이전트를 생성, 나열, 가져오기, 업데이트, 삭제 및 호출합니다. Aura 에이전트 도구(CypherTemplate, 유사성 검색, Text2Cypher) 구성, 시스템 프롬프트 설정, REST 또는 MCP 엔드포인트에 에이전트 배포, 자연어 쿼리로 에이전트 호출 시 사용합니다. OAuth2 인증, 조직/프로젝트 범위 지정, 도구 매개변수 스키마 및 InvokeAgentResponse 형식을 다룹니다. AuraDB 인스턴스 프로비저닝은 다루지 않습니다. neo4j-aura-provisioning-skill을 사용하세요. 벡터 인덱스 생성은 다루지 않습니다. neo4j-Vector-index-skill을 사용하세요.
