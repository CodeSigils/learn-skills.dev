Verwaltet Neo4j Aura-Agenten über die v2beta1-REST-API – erstellen, auflisten, abrufen, aktualisieren, löschen und aufrufen von Aura-Agenten, die von einer AuraDB-Instanz unterstützt werden. Wird zum Konfigurieren von Aura-Agent-Tools (CypherTemplate, SimilaritySearch, Text2Cypher), zum Festlegen von Systemaufforderungen, zum Bereitstellen von Agenten auf REST- oder MCP-Endpunkten oder zum Aufrufen von Agenten mit Abfragen in natürlicher Sprache verwendet. Behandelt OAuth2-Authentifizierung, Organisations-/Projektbereich, Tool-Parameterschemata und InvokeAgentResponse-Format. Deckt NICHT die Bereitstellung von AuraDB-Instanzen ab – verwenden Sie neo4j-aura-provisioning-skill. Deckt NICHT die Erstellung von Vektorindizes ab – verwenden Sie neo4j-vector-index-skill.
