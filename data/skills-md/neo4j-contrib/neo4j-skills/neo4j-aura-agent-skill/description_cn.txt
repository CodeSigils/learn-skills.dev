通过 v2beta1 REST API 管理 Neo4j Aura 代理 — 创建、列出、获取、更新、删除和调用由 AuraDB 实例支持的 Aura 代理。在配置 Aura 代理工具（CypherTemplate、SimilaritySearch、Text2Cypher）、设置系统提示、将代理部署到 REST 或 MCP 端点或使用自然语言查询调用代理时使用。涵盖 OAuth2 身份验证、组织/项目范围、工具参数架构和 InvokeAgentResponse 格式。不涵盖 AuraDB 实例配置 — 使用 neo4j-aura-provisioning-skill。不包括矢量索引创建 - 使用 neo4j-vector-index-skill。
