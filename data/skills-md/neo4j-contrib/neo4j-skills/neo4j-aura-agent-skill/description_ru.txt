Управляет агентами Neo4j Aura через REST API v2beta1 — создает, составляет список, получает, обновляет, удаляет и вызывает агенты Aura, поддерживаемые экземпляром AuraDB. Используйте при настройке инструментов агента Aura (CypherTemplate, LikeitySearch, Text2Cypher), настройке системных подсказок, развертывании агентов на конечных точках REST или MCP или вызове агентов с запросами на естественном языке. Охватывает аутентификацию OAuth2, область действия организации/проекта, схемы параметров инструментов и формат InvokeAgentResponse. НЕ охватывает подготовку экземпляра AuraDB — используйте neo4j-aura-provisioning-skill. НЕ охватывает создание векторного индекса — используйте neo4j-vector-index-skill.
