يدير وكلاء Neo4j Aura عبر v2beta1 REST API - إنشاء وكلاء Aura وإدراجهم والحصول عليهم وتحديثهم وحذفهم واستدعائهم المدعومين بمثيل AuraDB. يُستخدم عند تكوين أدوات Aura Agent (CypherTemplate، أو SameitySearch، أو Text2Cypher)، أو إعداد مطالبات النظام، أو نشر الوكلاء إلى نقاط نهاية REST أو MCP، أو استدعاء الوكلاء باستخدام استعلامات اللغة الطبيعية. يغطي مصادقة OAuth2، ونطاق المؤسسة/المشروع، ومخططات معلمات الأداة، وتنسيق InvocAgentResponse. لا يغطي توفير مثيل AuraDB — استخدم مهارة توفير neo4j-aura. لا يشمل إنشاء فهرس المتجهات — استخدم neo4j-vector-index-skill.
