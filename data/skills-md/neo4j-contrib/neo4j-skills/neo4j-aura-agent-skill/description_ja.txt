v2beta1 REST API を介して Neo4j Aura エージェントを管理します。AuraDB インスタンスによってサポートされる Aura エージェントの作成、一覧表示、取得、更新、削除、呼び出しを行います。 Aura Agent ツール (CypherTemplate、SimilaritySearch、Text2Cypher) の設定、システムプロンプトの設定、REST または MCP エンドポイントへのエージェントのデプロイ、または自然言語クエリによるエージェントの呼び出しの場合に使用します。 OAuth2 認証、組織/プロジェクトのスコープ、ツール パラメーター スキーマ、および InvokeAgentResponse 形式について説明します。 AuraDB インスタンスのプロビジョニングはカバーされていません。neo4j-aura-provisioning-skill を使用してください。ベクトルインデックスの作成はカバーしません。neo4j-vector-index-skill を使用してください。
