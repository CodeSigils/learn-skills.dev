توفير وإدارة مثيلات Neo4j Aura عبر CLI (aura-cli v1.7+) أو REST API. يُستخدم عند إنشاء مثيلات AuraDB Free/Professional/Business Critical/VDC أو إيقافها مؤقتًا أو استئنافها أو تغيير حجمها أو حذفها؛ تنزيل بيانات الاعتماد؛ البرمجة النصية لخطوط أنابيب CI/CD؛ حالة تزامن الاقتراع؛ أو باستخدام موفر Terraform neo4j/neo4j-aura. يغطي إعداد المصادقة (بيانات اعتماد العميل OAuth2)، ودورة حياة بيانات الاعتماد (التنزيل مرة واحدة - لا يمكن استردادها أبدًا)، واختيار نوع المثيل، ورموز المنطقة، والبرامج النصية لتوفير Python. لا يتعامل مع استعلامات Cypher — استخدم neo4j-cypher-skill. لا يغطي خوارزميات علم بيانات الرسم البياني — استخدم neo4j-gds-skill أو neo4j-aura-graph-analytics-skill. لا يغطي neo4j-admin/cypher-Shell — استخدم neo4j-cli-tools-skill.
