Effettua il provisioning e gestisce le istanze Neo4j Aura tramite CLI (aura-cli v1.7+) o API REST. Da utilizzare durante la creazione, la pausa, la ripresa, il ridimensionamento o l'eliminazione di istanze AuraDB Free/Professional/Business Critical/VDC; download delle credenziali; scripting di pipeline CI/CD; polling dello stato asincrono; o utilizzando il provider Terraform neo4j/neo4j-aura. Copre la configurazione dell'autenticazione (credenziali del client OAuth2), il ciclo di vita delle credenziali (download una volta, mai recuperabile), la selezione del tipo di istanza, i codici regionali e gli script di provisioning Python. NON gestisce le query Cypher: utilizza neo4j-cypher-skill. NON copre gli algoritmi di Graph Data Science: utilizza neo4j-gds-skill o neo4j-aura-graph-analytics-skill. NON copre neo4j-admin/cypher-shell: utilizza neo4j-cli-tools-skill.
