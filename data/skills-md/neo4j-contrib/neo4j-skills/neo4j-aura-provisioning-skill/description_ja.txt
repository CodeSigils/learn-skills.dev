CLI (aura-cli v1.7+) または REST API を介して Neo4j Aura インスタンスをプロビジョニングおよび管理します。 AuraDB Free/Professional/Business Critical/VDC インスタンスを作成、一時停止、再開、サイズ変更、または削除するときに使用します。資格情報をダウンロードする。 CI/CD パイプラインのスクリプト作成。非同期ステータスのポーリング。または、Terraform neo4j/neo4j-aura プロバイダーを使用します。認証設定 (クライアント認証情報 OAuth2)、認証情報のライフサイクル (一度ダウンロードすると復元不可)、インスタンス タイプの選択、地域コード、Python プロビジョニング スクリプトについて説明します。 Cypher クエリは処理しません。neo4j-cypher-skill を使用します。グラフ データ サイエンス アルゴリズムはカバーされていません。neo4j-gds-skill または neo4j-aura-graph-analytics-skill を使用してください。 neo4j-admin/cypher-shell は対象外です。neo4j-cli-tools-skill を使用してください。
