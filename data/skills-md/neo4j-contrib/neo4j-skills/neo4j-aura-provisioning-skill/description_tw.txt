透過 CLI (aura-cli v1.7+) 或 REST API 設定和管理 Neo4j Aura 實例。在建立、暫停、恢復、調整大小或刪除 AuraDB 免費/專業/業務關鍵/VDC 實例時使用；下載憑證；編寫 CI/CD 管道腳本；輪詢非同步狀態；或使用 Terraform neo4j/neo4j-aura 提供者。涵蓋身份驗證設定（客戶端憑證 OAuth2）、憑證生命週期（下載一次 - 永遠無法恢復）、實例類型選擇、區域代碼和 Python 配置腳本。不處理 Cypher 查詢 - 使用 neo4j-cypher-skill。不涵蓋圖形資料科學演算法 - 使用 neo4j-gds-skill 或 neo4j-aura-graph-analytics-skill。不涵蓋 neo4j-admin/cypher-shell — 使用 neo4j-cli-tools-skill。
