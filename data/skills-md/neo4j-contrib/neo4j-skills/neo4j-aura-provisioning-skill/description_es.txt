Aprovisiona y administra instancias de Neo4j Aura a través de CLI (aura-cli v1.7+) o API REST. Úselo al crear, pausar, reanudar, cambiar el tamaño o eliminar instancias gratuitas/profesionales/críticas para el negocio/VDC de AuraDB; descargar credenciales; secuencias de comandos de canalizaciones de CI/CD; estado de sondeo asíncrono; o utilizando el proveedor Terraform neo4j/neo4j-aura. Cubre la configuración de autenticación (credenciales de cliente OAuth2), el ciclo de vida de las credenciales (descargar una vez, nunca recuperable), selección de tipo de instancia, códigos de región y scripts de aprovisionamiento de Python. NO maneja consultas Cypher; use neo4j-cypher-skill. NO cubre algoritmos de Graph Data Science: use neo4j-gds-skill o neo4j-aura-graph-analytics-skill. NO cubre neo4j-admin/cypher-shell; use neo4j-cli-tools-skill.
