通过 CLI (aura-cli v1.7+) 或 REST API 配置和管理 Neo4j Aura 实例。在创建、暂停、恢复、调整大小或删除 AuraDB 免费/专业/业务关键/VDC 实例时使用；下载凭证；编写 CI/CD 管道脚本；轮询异步状态；或使用 Terraform neo4j/neo4j-aura 提供程序。涵盖身份验证设置（客户端凭据 OAuth2）、凭据生命周期（下载一次 - 永远无法恢复）、实例类型选择、区域代码和 Python 配置脚本。不处理 Cypher 查询 - 使用 neo4j-cypher-skill。不涵盖图形数据科学算法 - 使用 neo4j-gds-skill 或 neo4j-aura-graph-analytics-skill。不涵盖 neo4j-admin/cypher-shell — 使用 neo4j-cli-tools-skill。
