تصميم ومراجعة وإعادة بناء نماذج بيانات الرسم البياني Neo4j. يُستخدم عند اختيار تسميات العقد مقابل أنواع العلاقات مقابل الخصائص، أو ترحيل المخططات العلائقية/المستندات إلى الرسم البياني، أو اكتشاف الأنماط المضادة (التسميات العامة، والعقد الفائقة، والقيود المفقودة)، أو تصميم العقد الوسيطة للعلاقات n-ary، أو فرض المخطط بالقيود والفهارس، أو تقييم نموذج موجود مقابل أفضل ممارسات نمذجة الرسم البياني. لا يتعامل مع تأليف استعلام Cypher — استخدم neo4j-cypher-skill. لا يتعامل مع تعيين كيانات Spring Data Neo4j - استخدم neo4j-spring-data-skill. لا يتعامل مع تعريفات نوع GraphQL — استخدم neo4j-graphql-skill. لا يتعامل مع استيراد البيانات — استخدم neo4j-import-skill.
