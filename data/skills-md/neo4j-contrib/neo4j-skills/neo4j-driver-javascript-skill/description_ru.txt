Драйвер Neo4j JavaScript/TypeScript v6 — жизненный цикл драйвера, выполнение запроса, управляемые транзакции (executeRead/executeWrite), session.run, обработка целых чисел, сериализация JSON, доступ к записи, шаблоны асинхронности/ожидания, типы TypeScript, обработка ошибок и настройка соединения для Node.js и браузера. Используйте при написании кода JS/TS, который подключается к Neo4j — neo4j.driver(),executeQuery,executRead,executeWrite, session.run, neo4j.int, Record.get, Integer, BookmarkManager,bolt://, neo4j+s://. НЕ обрабатывает создание запросов Cypher — используйте neo4j-cypher-skill. НЕ охватывает миграцию версий драйверов — используйте neo4j-migration-skill.
