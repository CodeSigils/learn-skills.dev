Импортируйте структурированные данные в Neo4j — ЗАГРУЗКА CSV, ВЫЗОВ ТРАНЗАКЦИЙ, полный импорт базы данных neo4j-admin (офлайн-массовый), apoc.load.csv/json, apoc. periodic.iterate, пакетная запись драйверов. Охватывает выбор метода, формат файла заголовка, приведение типов, обработку значений NULL, режимы ПРИ ОШИБКЕ, СОВРЕМЕННЫЕ ТРАНЗАКЦИИ, настройку ограничений перед импортом и проверку после импорта. Используйте при импорте файлов CSV/JSON/Parquet, переносе реляционных данных в график или массовой загрузке больших наборов данных. НЕ обрабатывает конвейеры фрагментации неструктурированных документов/PDF/векторов — используйте neo4j-document-import-skill. НЕ обрабатывает шаблоны записи живых приложений (MERGE/CREATE) — используйте neo4j-cypher-skill. НЕ обрабатывает резервное копирование/восстановление/конфигурацию neo4j-admin — используйте neo4j-cli-tools-skill.
