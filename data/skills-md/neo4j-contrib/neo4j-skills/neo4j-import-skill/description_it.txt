Importa dati strutturati in Neo4j: LOAD CSV, CALL IN TRANSACTIONS, importazione database neo4j-admin completa (bulk offline), apoc.load.csv/json, apoc.periodic.iterate, scritture batch driver. Riguarda la selezione del metodo, il formato del file di intestazione, la coercizione del tipo, la gestione dei valori nulli, le modalità ON ERROR, le TRANSAZIONI CONCORRENTI, l'impostazione dei vincoli pre-importazione e la convalida post-importazione. Da utilizzare durante l'importazione di file CSV/JSON/Parquet, la migrazione di dati relazionali in un grafico o il caricamento in blocco di set di dati di grandi dimensioni. NON gestisce pipeline di suddivisione in blocchi di documenti/PDF/vettori non strutturati: utilizzare neo4j-document-import-skill. NON gestisce modelli di scrittura di app live (MERGE/CREATE): utilizza neo4j-cypher-skill. NON gestisce il backup/ripristino/config di neo4j-admin: utilizza neo4j-cli-tools-skill.
