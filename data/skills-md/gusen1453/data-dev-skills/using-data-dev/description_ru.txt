Направляйте запросы на обработку данных финансовых исследований и управление соответствующим специалистом в зависимости от ответственности. Используйте это, когда пользователь упоминает «помогите мне создать таблицу / спроектировать структуру таблицы базы данных / написать DDL», «создать конвейер синхронизации данных / инкрементальное / обратное заполнение», «спроектировать интерфейс для запроса данных XX / инструмент MCP», «проверку качества / приемку / проверку пакета таблиц данных», «контракт данных / управление данными / соответствие / происхождение / маскирование» или не уверен, какой навык разработки данных использовать. Маршрутизация: Контракт данных/DDL → финансы-ddl-design; разработка пайплайна →finance-pipeline-dev; интерфейс запроса → контракт финансового запроса; приемка качества → контроль качества финансовых данных; управление данными/соблюдение требований → исполнитель еще не указан. Он занимается только маршрутизацией и определением ответственности, не подключается к источникам данных, не выполняет запросы и не создает бизнес-результаты. Когда основная ответственность ясна, переходите сразу к соответствующему навыку, не задерживаясь здесь. Если сначала необходим метод проектирования, вы можете использовать /data-grill для окончательной доработки требований и /data-solid для проверки структуры хранилища данных.
