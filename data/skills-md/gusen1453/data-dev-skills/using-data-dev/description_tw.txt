根據職責將金融研究和投資資料工程和治理請求轉交給適當的技能。當使用者提到「幫我建立表格/設計資料庫模式/編寫DDL」、「建立資料同步管道/增量/回填」、「設計一個查詢XX資料的介面/MCP工具」、「品質檢查/驗收/審查一批表」、「資料契約/資料治理/合規性/沿襲/屏蔽」時，或不確定使用哪種資料開發技能時，可以使用此選項。路由：資料契約/DDL→finance-ddl-design；管線開發 → 金融管道開發；查詢介面→財務查詢合約；品質驗收→財務-資料-QC；資料治理/合規性 → 尚未提供執行者。它只處理路由和責任確定；它不連接到資料來源、執行查詢或產生可交付成果。當主要職責明確後，直接進入對應的技能，不要在這裡徘徊。如果首先需要一種設計方法，您可以使用 /data-grill 來最終確定需求，使用 /data-solid 來檢查資料倉儲結構。
