Dirija las solicitudes de gobernanza e ingeniería de datos de investigación de inversiones financieras a la habilidad adecuada según la responsabilidad. Cuando un usuario menciona "ayúdame a crear una tabla/diseñar una estructura de tabla de base de datos/escribir DDL", "construir un canal de sincronización de datos/incremental/relleno", "diseñar una interfaz para consultar datos XX/herramienta MCP", "inspección de calidad/aceptación/revisar un lote de tablas de datos", "contrato de datos/gobierno de datos/cumplimiento/linaje/desensibilización", o no está seguro de qué habilidad de desarrollo de datos utilizar, esto se aplica. Enrutamiento: contrato de datos/DDL → finanzas-ddl-diseño, desarrollo de canalización → finanzas-canalización-dev, interfaz de consulta → contrato-de-consulta-financiera, aceptación de calidad → finanzas-datos-qc, gobernanza/cumplimiento de datos → ejecutor aún no proporcionado. Sólo maneja el enrutamiento y la determinación de responsabilidad; no se conecta a fuentes de datos, no ejecuta consultas ni genera resultados comerciales. Cuando la responsabilidad principal está clara, se debe ir directamente a la habilidad correspondiente sin detenerse aquí. Si primero se necesita un método de diseño, use /data-grill para finalizar los requisitos y /data-solid para revisar la estructura del almacén de datos.
