Dirija las solicitudes de ingeniería y gobernanza para datos de investigación de inversiones financieras a la habilidad correspondiente según la responsabilidad. Utilice esto cuando el usuario mencione "ayúdeme a crear una tabla/diseñar una estructura de tabla de base de datos/escribir DDL", "crear una canalización de sincronización de datos/incremental/relleno", "diseñar una interfaz para consultar datos XX/herramienta MCP", "inspección de calidad/aceptación/revisión de un lote de tablas de datos", "contrato de datos/gobierno de datos/cumplimiento/linaje/desidentificación", o no está seguro de qué habilidad de desarrollo de datos usar. Enrutamiento: contrato de datos/DDL → finanzas-ddl-diseño, desarrollo de canalización → finanzas-canalización-dev, interfaz de consulta → contrato-de-consulta-financiera, aceptación de calidad → finanzas-datos-qc, gobernanza/cumplimiento de datos → ejecutor aún no proporcionado. Solo maneja el enrutamiento y la determinación de responsabilidad, no se conecta a fuentes de datos, no ejecuta consultas y no genera entregables comerciales. Cuando la responsabilidad principal está clara, se debe ir directamente a la habilidad correspondiente sin quedarse aquí. Si primero se necesita un método de diseño, puede usar/data-grill para finalizar los requisitos, /data-solid para revisar la estructura del almacén de datos.
