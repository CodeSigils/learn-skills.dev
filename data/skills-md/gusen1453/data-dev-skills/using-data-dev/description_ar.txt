توجيه طلبات الهندسة والحوكمة لبيانات أبحاث الاستثمار المالي إلى المهارة المقابلة على أساس المسؤولية. عندما يذكر المستخدم "مساعدتي في إنشاء جدول / تصميم هيكل جدول قاعدة البيانات / كتابة DDL"، أو "إنشاء خط أنابيب لمزامنة البيانات / تزايدي / إعادة التعبئة"، أو "تصميم واجهة للاستعلام عن بيانات XX / أداة MCP"، أو "فحص الجودة / القبول / مراجعة مجموعة من جداول البيانات"، أو "عقد البيانات / إدارة البيانات / الامتثال / السلالة / الإخفاء، "أو غير متأكد من مهارة تطوير البيانات التي يجب استخدامها، ينطبق هذا التوجيه. التوجيه: عقد البيانات/DDL → تصميم-ddl المالية؛ تطوير خطوط الأنابيب → Finance-Pipeline-dev؛ واجهة الاستعلام → عقد الاستعلام المالي؛ قبول الجودة → مراقبة البيانات المالية؛ إدارة البيانات/الامتثال ← المنفذ لم يتم توفيره بعد. فهو يتعامل فقط مع التوجيه وتحديد المسؤولية، ولا يتصل بمصادر البيانات، أو ينفذ الاستعلامات، أو ينشئ مخرجات الأعمال. عندما تكون المسؤولية الأساسية واضحة، يجب أن تنتقل مباشرة إلى المهارة المقابلة دون البقاء هنا. إذا كانت هناك حاجة إلى طريقة تصميم أولاً، فيمكنك استخدام /data-grill لإنهاء المتطلبات و/data-solid لمراجعة بنية مستودع البيانات.
