Indirizza le richieste di ingegneria dei dati e di governance della ricerca sugli investimenti finanziari alle competenze appropriate in base alla responsabilità. Quando un utente menziona "aiutami a creare una tabella/progettare una struttura di tabelle di database/scrivere DDL", "costruire una pipeline di sincronizzazione dei dati/incrementale/riempimento", "progettare un'interfaccia per interrogare i dati XX/strumento MCP", "ispezione qualità/accettazione/revisione di un batch di tabelle di dati", "contratto dati/governance dei dati/conformità/lignaggio/desensibilizzazione" o non è sicuro di quale competenza di sviluppo dati utilizzare, si applica quanto segue. Instradamento: contratto dati/DDL → finanza-ddl-progettazione, sviluppo pipeline → finanza-pipeline-dev, interfaccia di query → contratto-query-finanza, accettazione qualità → finanza-dati-qc, governance/conformità dei dati → esecutore non ancora fornito. Gestisce solo il routing e la determinazione della responsabilità; non si connette a origini dati, non esegue query o genera risultati aziendali. Quando la responsabilità primaria è chiara, si dovrebbe passare direttamente alla competenza corrispondente senza soffermarsi qui. Se è necessario prima un metodo di progettazione, utilizzare /data-grill per finalizzare i requisiti e /data-solid per rivedere la struttura del data warehouse.
