Indirizzare le richieste di ingegneria dei dati e di governance della ricerca finanziaria alle competenze corrispondenti in base alla responsabilità. Utilizzare questa opzione quando un utente menziona "aiutami a creare una tabella/progettare una struttura di tabella di database/scrivere DDL", "costruire una pipeline di sincronizzazione dei dati/incrementale/riempimento", "progettare un'interfaccia per interrogare i dati XX/strumento MCP", "ispezione qualità/accettazione/revisione di un batch di tabelle di dati", "contratto dati/governance dei dati/conformità/derivazione/mascheramento" o non è sicuro di quale competenza di sviluppo dati utilizzare. Instradamento: contratto dati/DDL → finanza-ddl-progettazione, sviluppo pipeline → finanza-pipeline-sviluppo, interfaccia di query → contratto-query-finanza, accettazione della qualità → finanza-dati-qc, governance/conformità dei dati → esecutore non ancora fornito. Gestisce solo il routing e la determinazione delle responsabilità, non si connette alle origini dati, non esegue query e non genera risultati aziendali. Quando la responsabilità primaria è chiara è opportuno passare direttamente alla competenza corrispondente, senza soffermarsi qui. Se è necessario prima un metodo di progettazione, è possibile utilizzare /data‑grill per finalizzare i requisiti e /data‑solid per rivedere la struttura del magazzino.
