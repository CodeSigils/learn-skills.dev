Examiner la qualité des tableaux de données de recherche financière, produire des rapports d'inspection de qualité (PASS/BLOCK/WATCH) et des scripts de surveillance/SQL dont la réexécution peut être programmée. Utilisez-le lorsqu'un utilisateur demande : "Ces données sont-elles correctes ? / Aidez-moi à vérifier la qualité (accepter) la table XX / Générer un rapport sur la qualité des données / Pourquoi cette capitalisation boursière est-elle si absurde ? / Clé primaire dupliquée / Données manquantes un certain jour / Pourquoi le rapport financier n'a-t-il pas été mis à jour ? / Ne correspond-il pas à une autre base de données / Pourquoi avons-nous retiré un tas de tickets morts. " Examinez également les problèmes tels que les valeurs de capitalisation boursière absurdes, la duplication de clé primaire, les champs manquants, les ruptures dans les séries boursières/financières, les mises à jour tardives des rapports financiers, les fuseaux horaires incohérents dans la dénomination des unités du tableau croisé, les définitions d'annotations ambiguës, la contamination des balises sectorielles/thèmes, la troncature de l'interface de requête ou la récupération de cibles non valides. Couvre les données de marché, les données financières, les annonces, les données de base sur les titres, les fonds indiciels, la macro-industrie et d'autres bases de données de recherche. Exploration en lecture seule ; toutes les conclusions sont traçables et reproductibles. Non responsable de la création des tables (utilisez finance-ddl-design), non responsable des pipelines (utilisez finance-pipeline-dev), non responsable de la conception de l'interface de requête (utilisez finance-query-contract).
