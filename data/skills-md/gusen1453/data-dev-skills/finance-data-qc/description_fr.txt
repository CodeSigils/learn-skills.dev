Examiner la qualité des tableaux de données de recherche financière, produire des rapports d'inspection de qualité (PASS/BLOCK/WATCH) et des scripts de surveillance/SQL dont la réexécution peut être programmée. Utilisé lorsqu'un utilisateur demande : « Ces données sont-elles correctes ? / Aidez-moi à vérifier la qualité (accepter) la table XX / Générer un rapport sur la qualité des données / Pourquoi cette capitalisation boursière est-elle si mauvaise ? / Clé primaire dupliquée / Données manquantes un certain jour / Pourquoi le rapport financier n'a-t-il pas été mis à jour ? / Il ne correspond pas à une autre base de données / Pourquoi avons-nous extrait un tas de tickets morts ? » Examinez également les anomalies telles que les valeurs de marché hors plage, la duplication de clé primaire, les champs manquants, les lacunes dans les séries chronologiques de marché/financières, les mises à jour retardées des annonces et des rapports financiers, les fuseaux horaires incohérents dans la dénomination des unités dans les tables, les définitions d'annotations ambiguës, la contamination des balises de secteur/thème, la troncature de l'interface de requête ou la récupération de titres invalides. Le champ d'application couvre les données de marché, les données financières, les événements d'annonce, les données de base sur les titres, les fonds indiciels, la macro-industrie et d'autres bases de données de recherche. Il s'agit d'une exploration en lecture seule ; toutes les conclusions sont entièrement traçables et réexécutables. Ne gère pas la création de tables (utilisez finance-ddl-design), le développement de pipelines (utilisez finance-pipeline-dev) ou la conception d'interfaces de requête (utilisez finance-query-contract).
