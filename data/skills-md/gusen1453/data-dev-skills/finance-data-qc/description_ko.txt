금융 조사 데이터 테이블의 품질을 검토하고 품질 검사 보고서(PASS/BLOCK/WATCH)를 생성하며 재실행 예약이 가능한 스크립트/SQL 모니터링을 수행합니다. 사용자가 "이 데이터가 정확합니까? / XX 테이블의 품질 확인(수락)을 도와주세요 / 데이터 품질 보고서 생성 / 이 시가총액이 왜 그렇게 틀린가요? / 기본 키가 중복되었습니다. / 특정 날짜에 데이터가 누락되었습니다. / 왜 재무 보고서가 업데이트되지 않았나요? / 다른 데이터베이스와 일치하지 않습니다. / 왜 우리가 죽은 티켓을 많이 뽑았나요?"라고 말할 때 사용됩니다. 또한 범위를 벗어난 시장 가치 수치, 기본 키 중복, 누락된 필드, 시장/금융 시계열의 격차, 발표 및 재무 보고서의 업데이트 지연, 테이블 전체에 걸쳐 단위 이름 지정의 일관되지 않은 시간대, 모호한 주석 정의, 산업/테마 태그 오염, 쿼리 인터페이스 잘림 또는 유효하지 않은 증권 검색과 같은 이상 현상을 조사합니다. 범위에는 시장 데이터, 금융, 발표 이벤트, 증권 마스터 데이터, 인덱스 펀드, 거시 산업 및 기타 연구 데이터베이스가 포함됩니다. 읽기 전용 탐색입니다. 모든 결론은 완전히 추적 가능하고 재실행 가능합니다. 테이블 생성(finance‑ddl‑design 사용), 파이프라인 개발(finance‑pipeline‑dev 사용) 또는 쿼리 인터페이스 디자인(finance‑query‑contract 사용)을 처리하지 않습니다.
