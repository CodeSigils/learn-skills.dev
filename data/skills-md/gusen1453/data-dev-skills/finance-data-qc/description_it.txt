Esaminare la qualità delle tabelle dei dati di ricerca sugli investimenti finanziari, produrre report di controllo della qualità (PASS/BLOCK/WATCH) e monitorare script/SQL che possono essere pianificati per le repliche. Usatelo quando un utente dice "Questi dati sono corretti / Aiutami a controllare la qualità (accettare) la tabella XX / Genera un rapporto sulla qualità dei dati / Perché questa capitalizzazione di mercato è così assurda / Chiave primaria duplicata / Dati mancanti in un determinato giorno / Perché il rapporto finanziario non è stato aggiornato / Non corrisponde a un altro database / Perché abbiamo tirato fuori un mucchio di biglietti morti". Verificare inoltre la presenza di valori anomali quali anomalie della capitalizzazione di mercato, duplicazione della chiave primaria, campi mancanti, lacune nelle serie di mercato/finanziarie, aggiornamenti ritardati dei rapporti finanziari, fusi orari incoerenti nella denominazione delle unità nelle tabelle, definizioni di commenti ambigue, tag di settore/tema inquinati, troncamento dell'interfaccia di query o recupero di titoli non validi. Copre dati di mercato, dati finanziari, eventi di annunci, dati anagrafici di sicurezza, fondi indicizzati, macroindustria e altri database di ricerca sugli investimenti. Esplorazione di sola lettura; tutte le conclusioni sono completamente tracciabili e riproducibili. Non responsabile della creazione della tabella (utilizzare finance-ddl-design), non responsabile delle pipeline (utilizzare finance-pipeline-dev), non responsabile della progettazione dell'interfaccia di query (utilizzare finance-query-contract).
