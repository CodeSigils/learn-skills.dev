Esaminare la qualità delle tabelle dei dati di ricerca finanziaria, produrre report di ispezione della qualità (PASS/BLOCK/WATCH) e monitorare script/SQL che possono essere pianificati per la riesecuzione. Utilizzato quando un utente dice "Questi dati sono corretti? / Aiutami a controllare la qualità (accettare) la tabella XX / Genera un report sulla qualità dei dati / Perché questa capitalizzazione di mercato è così sbagliata? / Chiave primaria duplicata / Dati mancanti in un determinato giorno / Perché il rapporto finanziario non è stato aggiornato? / Non corrisponde a un altro database / Perché abbiamo estratto un mucchio di ticket morti?" Indagare inoltre su anomalie quali valori di mercato fuori range, duplicazione di chiavi primarie, campi mancanti, lacune nelle serie temporali di mercato/finanziarie, aggiornamenti ritardati di annunci e rapporti finanziari, fusi orari incoerenti nella denominazione delle unità nelle tabelle, definizioni di annotazioni ambigue, contaminazione di tag di settore/tema, troncamento dell'interfaccia di query o recupero di titoli non validi. L'ambito copre dati di mercato, dati finanziari, eventi di annuncio, dati anagrafici sui titoli, fondi indicizzati, macroindustria e altri database di ricerca. È un'esplorazione di sola lettura; tutte le conclusioni sono completamente tracciabili e riproducibili. Non gestisce la creazione di tabelle (utilizzare finanza-ddl-design), lo sviluppo della pipeline (utilizzare finanza-pipeline-dev) o la progettazione dell'interfaccia di query (utilizzare finanza-query-contratto).
