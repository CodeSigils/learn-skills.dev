Überprüfen Sie die Qualität von Finanzresearch-Datentabellen, erstellen Sie Qualitätsprüfberichte (PASS/BLOCK/WATCH) und überwachen Sie Skripte/SQL, deren erneute Ausführung geplant werden kann. Wird verwendet, wenn ein Benutzer sagt: „Sind diese Daten korrekt? / Helfen Sie mir, die XX-Tabelle auf Qualität zu prüfen (zu akzeptieren) / Erstellen Sie einen Datenqualitätsbericht / Warum ist diese Marktkapitalisierung so falsch? / Primärschlüssel dupliziert / Daten fehlen an einem bestimmten Tag / Warum wurde der Finanzbericht nicht aktualisiert? / Er stimmt nicht mit einer anderen Datenbank überein / Warum haben wir eine Menge ungültiger Tickets gezogen?“ Untersuchen Sie auch Anomalien wie außerhalb des Bereichs liegende Marktwertzahlen, Duplizierung von Primärschlüsseln, fehlende Felder, Lücken in Markt-/Finanzzeitreihen, verzögerte Aktualisierungen von Ankündigungen und Finanzberichten, inkonsistente Zeitzonen bei der Benennung von Einheiten in Tabellen, mehrdeutige Anmerkungsdefinitionen, Kontamination von Branchen-/Themen-Tags, Kürzungen der Abfrageschnittstelle oder das Abrufen ungültiger Wertpapiere. Der Umfang umfasst Marktdaten, Finanzdaten, Ankündigungsereignisse, Wertpapierstammdaten, Indexfonds, Makroindustrie und andere Forschungsdatenbanken. Es handelt sich um eine schreibgeschützte Erkundung; Alle Schlussfolgerungen sind vollständig nachvollziehbar und wiederholbar. Behandelt nicht die Tabellenerstellung (finance-ddl-design verwenden), die Pipeline-Entwicklung (finance-pipeline-dev verwenden) oder das Abfrageschnittstellendesign (finance-query-contract verwenden).
