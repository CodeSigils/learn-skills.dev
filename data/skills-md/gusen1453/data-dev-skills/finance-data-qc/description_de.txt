Überprüfen Sie die Qualität von Finanzresearch-Datentabellen, erstellen Sie Qualitätsinspektionsberichte (PASS/BLOCK/WATCH) und überwachen Sie Skripte/SQL, deren Wiederholung geplant werden kann. Verwenden Sie es, wenn der Benutzer sagt: „Sind diese Daten korrekt? / Helfen Sie mir, die XX-Tabelle auf Qualität zu überprüfen (zu akzeptieren) / Erstellen Sie einen Datenqualitätsbericht / Warum ist diese Marktkapitalisierung so absurd? / Duplikat des Primärschlüssels / Fehlende Daten an einem bestimmten Tag / Warum wurde der Finanzbericht nicht aktualisiert? / Stimmt nicht mit einer anderen Datenbank überein / Warum haben wir eine Menge toter Tickets gezogen?“ Untersuchen Sie auch Probleme wie ungewöhnliche numerische Werte (z. B. Marktkapitalisierung), doppelte Primärschlüssel, fehlende Felder, Lücken in Markt-/Finanzzeitreihen, verzögerte Aktualisierungen von Ankündigungen/Finanzberichten, inkonsistente Zeitzonen bei der Benennung von Einheiten in Tabellen, mehrdeutige Kommentardefinitionen, fehlerhafte Branchen-/Themen-Tags, Kürzungen der Abfrageschnittstelle oder das Abrufen ungültiger Wertpapiere. Deckt Marktdaten, Finanzdaten, Ankündigungsereignisse, Wertpapierstammdaten, Indexfonds, makroindustrielle Forschungsdatenbanken usw. ab.
