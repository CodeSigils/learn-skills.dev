قم بمراجعة جودة جداول بيانات الأبحاث المالية، وإنشاء تقارير فحص الجودة (PASS/BLOCK/WATCH) ومراقبة البرامج النصية/SQL التي يمكن جدولتها لإعادة التنفيذ. استخدمها عندما يقول المستخدم "هل هذه البيانات صحيحة؟ / ساعدني في مراقبة الجودة (قبول) الجدول XX / قم بإعداد تقرير جودة البيانات / لماذا تعتبر القيمة السوقية هذه سخيفة إلى هذا الحد؟ / تكرار المفتاح الأساسي / البيانات المفقودة في يوم معين / لماذا لم يتم تحديث التقرير المالي؟ / لا يتطابق مع قاعدة بيانات أخرى / لماذا قمت بسحب مجموعة من التذاكر الميتة؟" تحقق أيضًا من الحالات الشاذة مثل قيم القيمة السوقية غير المعقولة، أو المفاتيح الأساسية المكررة، أو الحقول المفقودة، أو الانقطاعات في سلاسل السوق/المالية، أو التحديثات المتأخرة للإعلانات أو التقارير المالية، أو المناطق الزمنية غير المتسقة في تسمية الوحدات عبر الجداول، أو تعريفات التعليقات الغامضة، أو علامات الصناعة/الموضوع الملوثة، أو اقتطاع واجهة الاستعلام أو استرجاع الأهداف غير الصالحة. يغطي بيانات السوق، والبيانات المالية، وأحداث الإعلانات، والبيانات الرئيسية الأمنية، وصناديق المؤشرات، وقواعد بيانات أبحاث الصناعة الكلية. استكشاف للقراءة فقط؛ الاستنتاجات يمكن تتبعها بالكامل وقابلة للتكرار. لست مسؤولاً عن إنشاء الجدول (استخدم تصميم Finance-ddl)، أو تطوير خطوط الأنابيب (استخدم Finance-Pipeline-dev)، أو تصميم واجهة الاستعلام (استخدم عقد استعلام التمويل).
