قم بمراجعة جودة جداول بيانات الأبحاث المالية، وإنتاج تقارير فحص الجودة (PASS/BLOCK/WATCH) ومراقبة البرامج النصية/SQL التي يمكن جدولتها لإعادة التنفيذ. تُستخدم عندما يقول المستخدم "هل هذه البيانات صحيحة؟ / ساعدني في التحقق من الجودة (قبول) الجدول XX / إنشاء تقرير جودة البيانات / لماذا هذه القيمة السوقية منخفضة جدًا؟ / المفتاح الأساسي مكرر / البيانات مفقودة في يوم معين / لماذا لم يتم تحديث التقرير المالي؟ / لا يتطابق مع قاعدة بيانات أخرى / لماذا قمنا بسحب مجموعة من التذاكر الميتة؟" تحقق أيضًا من الحالات الشاذة مثل أرقام القيمة السوقية خارج النطاق، وتكرار المفتاح الأساسي، والحقول المفقودة، والفجوات في السلاسل الزمنية للسوق/المالية، وتأخر تحديث الإعلانات والتقارير المالية، والمناطق الزمنية غير المتسقة في تسمية الوحدات عبر الجداول، وتعريفات التعليقات التوضيحية الغامضة، وتلوث علامات الصناعة/الموضوع، واقتطاع واجهة الاستعلام أو استرداد الأوراق المالية غير الصالحة. ويغطي النطاق بيانات السوق، والبيانات المالية، وأحداث الإعلانات، والبيانات الرئيسية للأوراق المالية، وصناديق المؤشرات، والصناعة الكلية وقواعد البيانات البحثية الأخرى. إنه استكشاف للقراءة فقط؛ جميع الاستنتاجات يمكن تتبعها بالكامل وإعادة تشغيلها. لا يتعامل مع إنشاء الجدول (استخدم تصميم Finance-ddl)، أو تطوير خط الأنابيب (استخدم Finance-Pipeline-dev)، أو تصميم واجهة الاستعلام (استخدم عقد استعلام التمويل).
