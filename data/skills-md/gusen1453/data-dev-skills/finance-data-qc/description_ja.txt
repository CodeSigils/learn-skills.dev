財務調査データ テーブルの品質をレビューし、品質検査レポート (PASS/BLOCK/WATCH) と再実行をスケジュールできる監視スクリプト/SQL を作成します。ユーザーが「これらのデータは正しいですか? / XX テーブルの品質チェック (受け入れ) を手伝ってください / データ品質レポートの生成 / この時価総額はなぜそれほど外れているのですか? / 主キーが重複しています / 特定の日にデータがありません / なぜ財務レポートが更新されていませんか? / 別のデータベースと一致しません / なぜ大量の無効チケットを取得したのですか?」と言うときに使用されます。また、範囲外の市場価値数値、主キーの重複、フィールドの欠落、市場/財務時系列のギャップ、発表と財務レポートの更新の遅延、テーブル間でのユニット名のタイムゾーンの不一致、あいまいな注釈定義、業界/テーマタグの汚染、クエリインターフェイスの切り捨てや無効な証券の取得などの異常も調査します。範囲は、市場データ、財務、発表イベント、証券マスターデータ、インデックスファンド、マクロ産業、その他の研究データベースをカバーします。これは読み取り専用の探索です。すべての結論は完全に追跡可能で、再実行可能です。テーブルの作成 (finance-ddl-design を使用)、パイプライン開発 (finance-pipeline-dev を使用)、またはクエリ インターフェイスの設計 (finance-query-contract を使用) は処理しません。
