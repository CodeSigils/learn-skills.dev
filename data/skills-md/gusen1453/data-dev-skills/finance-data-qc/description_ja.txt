財務調査データ テーブルの品質をレビューし、品質検査レポート (PASS/BLOCK/WATCH) と再実行をスケジュールできる監視スクリプト/SQL を作成します。これは、ユーザーが「これらのデータは正しいですか / テーブル XX の QA (承認) を手伝ってください / データ品質レポートを生成してください / なぜこの時価総額は非常に不合理なのでしょうか / 主キーが重複しています / 特定の日のデータが欠落しています / なぜ財務レポートが更新されないのですか / 別のデータベースと一致しません / なぜ大量の無効なチケットを取り出したのですか。」 という場合にこれを使用します。また、不合理な時価総額、主キーの重複、フィールドの欠落、市場/財務シリーズのギャップ、発表や財務レポートの更新の遅延、テーブル間でのユニット名のタイムゾーンの不一致、あいまいなコメント定義、汚染された業界/テーマタグ、クエリインターフェイスの切り捨て、無効な証券の取得などの問題も調査します。市場データ、財務、発表イベント、証券マスターデータ、インデックスファンド、マクロ産業、その他の研究データベースをカバーします。読み取り専用の探索。すべての結論は完全に追跡可能で再現可能です。テーブルの作成 (finance‑ddl‑design を使用)、パイプライン開発 (finance‑pipeline‑dev を使用)、またはクエリ インターフェイスの設計 (finance‑query‑contract を使用) は処理しません。
