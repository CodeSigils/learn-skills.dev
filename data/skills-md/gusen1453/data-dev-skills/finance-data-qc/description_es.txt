Revise la calidad de las tablas de datos de investigación financiera, produzca informes de inspección de calidad (PASS/BLOCK/WATCH) y scripts de monitoreo/SQL que se pueden programar para su reejecución. Se utiliza cuando un usuario dice "¿Son correctos estos datos? / Ayúdame a verificar la calidad (aceptar) la tabla XX / Generar un informe de calidad de los datos / ¿Por qué esta capitalización de mercado es tan baja? / Clave principal duplicada / Faltan datos en un día determinado / ¿Por qué no se ha actualizado el informe financiero? / No coincide con otra base de datos / ¿Por qué sacamos un montón de tickets inactivos?" También investigue anomalías como cifras de valor de mercado fuera de rango, duplicación de claves primarias, campos faltantes, brechas en las series temporales financieras/de mercado, actualizaciones retrasadas de anuncios e informes financieros, zonas horarias inconsistentes en la denominación de unidades en las tablas, definiciones de anotaciones ambiguas, contaminación de etiquetas de industria/tema, truncamiento de la interfaz de consulta o recuperación de valores no válidos. El alcance cubre datos de mercado, finanzas, eventos de anuncios, datos maestros de valores, fondos indexados, macroindustrias y otras bases de datos de investigación. Es una exploración de sólo lectura; Todas las conclusiones son totalmente rastreables y reejecutables. No maneja la creación de tablas (use Finance‑ddl‑design), el desarrollo de canalizaciones (use Finance‑pipeline‑dev) ni el diseño de interfaz de consulta (use Finance‑query‑contrat).
