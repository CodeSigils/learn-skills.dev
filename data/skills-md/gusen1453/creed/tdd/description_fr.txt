À utiliser lors de l'implémentation d'une fonctionnalité, d'une correction de bug, d'une refactorisation ou d'un changement de comportement, avant d'écrire du code de production. Applique le refactor rouge-vert (échec du test en premier, regardez-le échouer, code minimal, refactor). Complète la conception des tests (quoi affirmer) avec le rythme TDD (quand écrire du code).
