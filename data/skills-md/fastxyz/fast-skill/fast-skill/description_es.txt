Habilidad de enrutador para el ecosistema FAST. Úselo cuando el usuario pregunte sobre FAST, fastUSDC, AllSet, @fastxyz/sdk, @fastxyz/allset-sdk, @fastxyz/x402-client, @fastxyz/x402-server o @fastxyz/x402-facilitator; quiere saldos rápidos, transferencias rápidas, puente rápido a EVM o EVM a rápido, necesita recargar USDC del lado rápido a través del enlace de rampa alojado en `https://ramp.fast.xyz`, o quiere pagar o proteger una API con paquetes FAST x402. No lo utilice para billeteras EVM genéricas, puentes genéricos, preguntas HTTP 402 no relacionadas o pilas de pagos que no sean FAST.
