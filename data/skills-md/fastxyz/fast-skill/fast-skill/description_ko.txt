FAST 생태계를 위한 라우터 기술입니다. 사용자가 FAST, fastUSDC, AllSet, @fastxyz/sdk, @fastxyz/allset-sdk, @fastxyz/x402-client, @fastxyz/x402-server 또는 @fastxyz/x402-facilitator에 대해 질문할 때 사용합니다. 빠른 잔액, 빠른 전송, 빠른 EVM 또는 EVM에서 빠른 브리징을 원하는 경우 `https://ramp.fast.xyz`에 호스팅된 램프 링크를 통해 빠른 측 USDC를 충전해야 하거나 FAST x402 패키지로 API 비용을 지불하거나 보호하려는 경우. 일반 EVM 지갑, 일반 브리징, 관련 없는 HTTP 402 질문 또는 FAST가 아닌 결제 스택에는 사용하지 마세요.
