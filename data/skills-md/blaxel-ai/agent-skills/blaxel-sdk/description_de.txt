Verwenden Sie diese Option beim Erstellen von Cloud-Sandboxen (microVMs), um Code auszuführen, Entwicklungsserver zu starten und Live-Vorschau-URLs zu generieren. Behandelt auch die Bereitstellung von KI-Agenten, MCP-Servern, Batch-Jobs und Agent-Laufwerken (gemeinsam genutzten Dateisystemen) auf der serverlosen Infrastruktur von Blaxel. Greifen Sie zu dieser Fähigkeit, wenn Sie isolierte Rechenumgebungen, App-Vorschauen in Echtzeit, gemeinsam genutzten Dateispeicher über Sandboxes hinweg benötigen oder Agenten-Workloads bereitstellen möchten.
