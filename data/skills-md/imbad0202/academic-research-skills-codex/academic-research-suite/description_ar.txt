مجموعة مهارات البحث الأكاديمي الأصلية للبحث العميق، وكتابة الأوراق الأكاديمية، ومراجعة المخطوطات، وخطوط البحث الكاملة للورق، وتخطيط التجارب أو التحقق من صحتها. يُستخدم عندما يطلب المستخدم إجراء بحث عميق، أو مراجعة الأدبيات، أو المراجعة المنهجية، أو التحليل التلوي، أو تنقيح أسئلة البحث، أو صياغة الأوراق الأكاديمية، أو مراجعة الأوراق، أو التحقق من الاستشهاد أو النزاهة، أو محاكاة المراجع، أو مراجعة الأقران، أو رسائل القرار التحريري، أو سير عمل البحث إلى الورق، أو تخطيط تنفيذ التجربة، أو التفسير الإحصائي، أو دعم بروتوكول الدراسة البشرية. استخدم أيضًا الأسماء المستعارة لأوامر ARS بنمط كلود، مثل /ars-plan، وars-plan، و/ars-outline، و/ars-abstract، و/ars-lit-review، و/ars-citation-check، و/ars-disclosure، و/ars-format-convert، و/ars-revision-coach، و/ars-revision، و/ars-full. توفر هذه المهارة مطالبات دور ARS والمراجع والقوالب ومخططات التسليم المشتركة ضمن ars/.
