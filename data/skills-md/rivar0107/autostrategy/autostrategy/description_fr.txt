Outil de génération automatique de stratégies de trading quantitatives. Exigences de la stratégie de saisie (claires ou vagues) → analyse approfondie → générer un code de stratégie exécutable + vérification backtest → optimisation automatique.  
Innovation fondamentale : STRATEGY_DESIGN.md sert de « modèle de système », l'IA le traduisant strictement lors de la génération de code plutôt que d'improviser.  
Quatre points d'entrée : (1) exigences claires en matière de stratégie → analyse directe (2) exigences vagues → recommandation de diagnostic → réanalyse (3) stratégie existante → itération d'optimisation (4) big‑V/blogger → recherche Internet → stratégie d'extraction.  
Mots déclencheurs : « stratégie quantitative », « formuler une stratégie », « rédiger une stratégie », « backtest », « autostratégie », « génération de stratégie », « quantitativeXX », « stratégie d'investissement XX », « logique d'investissement de XX ».  
Déclencheurs du scénario : « Aidez-moi à concevoir une stratégie de croisement de moyennes mobiles », « Je souhaite créer une stratégie quantitative d'actions A », « Backtester cette stratégie », « Optimiser les résultats de backtest de cette stratégie ».  
Marchés applicables : actions A / actions de Hong Kong / actions américaines (les contrats à terme et les options ne sont pas encore pris en charge ; ils seront ajoutés dans les versions ultérieures).  
Les stratégies de style de personnalité déclenchent également : « Écrivez une stratégie d’investissement Buffett », « Quantifiez la logique d’investissement de DuanYongping », « Aidez-moi à utiliser la réflexivité de Soros pour élaborer une stratégie ».  
Déclencheurs de stratégie du blogueur : « Créer une stratégie basée sur les opinions d'investissement du blogueur XX », « Écrire une stratégie en suivant la réflexion de XX big V », « Aidez-moi à quantifier la méthode de sélection de titres de XX », « Transformer la logique d'investissement du blogueur XX en une stratégie. »
