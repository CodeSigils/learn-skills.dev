Quantitative trading strategy auto-generation tool. Input strategy requirements (clear or vague) → deep analysis → generate runnable strategy code + backtest verification → automatic optimization.  
Core innovation: STRATEGY_DESIGN.md serves as the “system blueprint,” with AI strictly translating it when generating code rather than improvising.  
Four entry points: (1) clear strategy requirements → direct analysis (2) vague requirements → diagnosis recommendation → re‑analysis (3) existing strategy → optimization iteration (4) big‑V/blogger → internet research → extract strategy.  
Trigger words: “quantitative strategy,” “formulate strategy,” “write a strategy,” “backtest,” “autostrategy,” “strategy generation,” “quantitative XX,” “XX investment strategy,” “XX’s investment logic.”  
Scenario triggers: “Help me design a moving‑average crossover strategy,” “I want to create an A‑share quantitative strategy,” “Backtest this strategy,” “Optimize the backtest results of this strategy.”  
Applicable markets: A‑shares / Hong Kong stocks / US stocks (futures and options are not supported yet; they will be added in later versions).  
Personality‑style strategies also trigger: “Write a Buffett investment strategy,” “Quantify Duan Yongping’s investment logic,” “Help me use Soros’s reflexivity to build a strategy.”  
Blogger‑strategy triggers: “Create a strategy based on XX blogger’s investment views,” “Write a strategy following XX big‑V’s thinking,” “Help me quantify XX’s stock‑picking method,” “Turn XX blogger’s investment logic into a strategy.”
