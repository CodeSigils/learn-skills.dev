Tool zur automatischen Generierung quantitativer Handelsstrategien. Eingabestrategieanforderungen (klar oder vage) → tiefgreifende Analyse → ausführbaren Strategiecode generieren + Backtest-Verifizierung → automatische Optimierung.  
Kerninnovation: STRATEGY_DESIGN.md dient als „Systemblaupause“, wobei die KI sie bei der Codegenerierung strikt übersetzt, anstatt zu improvisieren.  
Vier Einstiegspunkte: (1) klare Strategieanforderungen → direkte Analyse (2) vage Anforderungen → Diagnoseempfehlung → erneute Analyse (3) bestehende Strategie → Optimierungsiteration (4) Big-V/Blogger → Internetrecherche → Extraktionsstrategie.  
Auslöserwörter: „Quantitative Strategie“, „Strategie formulieren“, „Strategie schreiben“, „Backtest“, „Autostrategie“, „Strategiegenerierung“, „quantitativeXX“, „XX Anlagestrategie“, „XXs Anlagelogik“.  
Szenarioauslöser: „Helfen Sie mir, eine Crossover-Strategie mit gleitendem Durchschnitt zu entwerfen“, „Ich möchte eine quantitative A-Aktien-Strategie erstellen“, „Backtest dieser Strategie“, „Optimieren Sie die Backtest-Ergebnisse dieser Strategie.“  
Anwendbare Märkte: A-Aktien / Hongkong-Aktien / US-Aktien (Futures und Optionen werden noch nicht unterstützt; sie werden in späteren Versionen hinzugefügt).  
Strategien im Persönlichkeitsstil lösen auch Folgendes aus: „Schreiben Sie eine Anlagestrategie für Buffett“, „Quantifizieren Sie DuanYongpings Anlagelogik“, „Hilf mir, Soros‘ Reflexivität zu nutzen, um eine Strategie zu entwickeln.“  
Auslöser der Blogger-Strategie: „Erstellen Sie eine Strategie basierend auf den Anlageansichten von XX Blogger“, „Schreiben Sie eine Strategie, die den Überlegungen von XX Big-V folgt“, „Helfen Sie mir, die Aktienauswahlmethode von XX zu quantifizieren“, „Machen Sie die Anlagelogik von XX Blogger in eine Strategie aus.“
