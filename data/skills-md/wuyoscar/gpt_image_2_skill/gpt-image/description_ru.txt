Генерация изображений общего назначения и редактирование эталонных изображений с помощью OpenAI GPT Image 2 («gpt-image-2»). Обертывает две официальные конечные точки из кулинарной книги OpenAI — `/v1/images/generations` для преобразования текста в изображение и `/v1/images/edits` для редактирования эталонного изображения (включая маски альфа-канала). Используйте, когда агенту или пользователю необходимо (а) создать изображение из текстовой подсказки, (б) изменить стиль или преобразовать изображение с помощью эталонного изображения, (в) объединить несколько эталонных изображений, (г) закрасить область с помощью маски PNG или (д) отобразить плотную типографику/текст на китайском языке. Читает `OPENAI_API_KEY` из env; записывает PNG/JPEG/WebP на диск. Дополнительные ссылки на масштаб в разделе «references/» для полного атласа галереи подсказок, сквозных подсказок и официального руководства по параметрам OpenAI.
