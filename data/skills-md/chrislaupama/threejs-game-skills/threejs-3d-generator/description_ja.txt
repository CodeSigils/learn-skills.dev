Meshy API を使用して、Three.js ゲームの 3D アセットを生成、テクスチャ、リグ、アニメーション、再メッシュ、変換、ダウンロードします。テキストから 3D、画像から 3D、2D コンセプトから 3D への変換、ゲーム対応 GLB/FBX アセット、キャラクター、クリーチャー、建物、小道具、武器、地形ピース、人型自動リギング、アニメーション ライブラリ クリップ、モデル リテクスチャ、ローポリ/クアッド リメッシュ、ブラウザ アセット パイプラインに使用します。画像を 3D に生成する前に、コンセプト、テクスチャ参照、空/背景/地形テクスチャ、ロゴ、アイコン、および GUI アートを使用するために、threejs-image-generator と組み合わせます。
