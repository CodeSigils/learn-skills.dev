Основная точка входа для полного создания браузерной игры Three.js, премиум-итерации и автоматической оркестровки этапов. Используйте по умолчанию для запросов на создание игры, обновление, доработку, премиум-класс, AAA, высокое качество, с нуля, бесконечный раннер, аркаду, экшн, готовность к выпуску или демонстрацию. Для широкой работы сначала загрузите однотипные общедоступные файлы навыков для игровых систем, графики AAA, пользовательского интерфейса, отладки/профиля и контроля качества/выпуска. Для игр премиум-класса с персонажами, транспортными средствами, кораблями, оружием, зданиями, фирменным реквизитом, небом, текстурами, наклейками, логотипами, значками, графическим интерфейсом, аудио/SFX/голосовыми потребностями или менее простой графикой загрузите Threejs-3d-generator, Threejs-image-generator и/или Threejs-audio-generator, прежде чем решить, что сгенерированные ресурсы не нужны. Ведите журналы загрузки навыков, справок, поиска активов и поэтапного выполнения, чтобы пользователи не могли выбирать навыки вручную.
