Générez et modifiez des ressources d'image 2D pour les jeux Three.js à l'aide de l'API OpenAI Image. À utiliser pour les feuilles conceptuelles, les entrées d'image en 3D, les références de texture, les plaques de ciel/arrière-plan, les décalcomanies, les logos, les icônes, l'art de l'interface graphique, l'art du titre/menu, les vignettes, les images fixes marketing et les images source qui alimentent threejs-3d-generator. À utiliser également pour l'édition directe d'images lorsque l'utilisateur fournit un chemin d'image.
