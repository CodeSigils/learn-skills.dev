Создавайте и редактируйте ресурсы 2D-изображений для игр Three.js с помощью API изображений OpenAI. Используйте для концептуальных листов, входных изображений для преобразования изображений в 3D, ссылок на текстуры, пластин неба/фона, надписей, логотипов, значков, изображений графического интерфейса, изображений заголовков/меню, миниатюр, маркетинговых фотографий и исходных изображений, которые подаются в генератор Threejs-3d. Также используйте для прямого редактирования изображений, когда пользователь указывает путь к изображению.
