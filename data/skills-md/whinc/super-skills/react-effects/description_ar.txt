React useEffect دليل الكشف عن الأنماط وتصحيحها. استخدم هذه المهارة عند كتابة أو مراجعة أو تعديل أي مكون React يحتوي على useEffect، أو عندما تكون على وشك إضافة خطاف useEffect. يتم تشغيله أيضًا عندما ترى أنماطًا مثل "setState داخل useEffect"، أو "سلاسل التأثير"، أو "الحالة المشتقة سارية المفعول"، أو "إخطار الوالدين ساري المفعول". يغطي 12 سيناريو محددًا حيث تكون التأثيرات غير ضرورية أو يساء استخدامها، مع البدائل الصحيحة. حتى لو كان useEffect يبدو معقولًا للوهلة الأولى، استشر هذه المهارة للتحقق من الحاجة إليها حقًا.
