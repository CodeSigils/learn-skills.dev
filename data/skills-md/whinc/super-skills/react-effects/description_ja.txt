React useEffect アンチパターン検出および修正ガイド。 useEffect を含む React コンポーネントを作成、レビュー、変更するとき、または useEffect フックを追加しようとするときに、このスキルを使用します。また、「useEffect 内の setState」、「エフェクト チェーン」、「有効な派生状態」、「有効な親に通知」などのパターンが表示された場合にもトリガーされます。エフェクトが不必要または誤用される 12 の特定のシナリオを、正しい代替案とともにカバーします。 useEffect が一見合理的であるように見えても、このスキルを参照して、それが本当に必要であることを確認してください。
