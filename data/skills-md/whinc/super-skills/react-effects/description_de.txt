React useEffect Anti-Pattern-Erkennungs- und Korrekturanleitung. Verwenden Sie diese Fähigkeit, wenn Sie eine React-Komponente schreiben, überprüfen oder ändern, die useEffect enthält, oder wenn Sie einen useEffect-Hook hinzufügen möchten. Wird auch ausgelöst, wenn Muster wie „setState in useEffect“, „Effektketten“, „abgeleiteter Status in Kraft“ oder „übergeordnetes Element in Kraft benachrichtigen“ angezeigt werden. Deckt 12 spezifische Szenarien ab, in denen Effekte unnötig sind oder missbraucht werden, mit korrekten Alternativen. Auch wenn der useEffect auf den ersten Blick sinnvoll erscheint, konsultieren Sie diesen Skill, um zu überprüfen, ob er wirklich benötigt wird.
