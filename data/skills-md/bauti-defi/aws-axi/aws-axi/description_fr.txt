Exécutez les opérations AWS via la CLI AWS-axi — EC2, S3, IAM, Lambda, KMS, CloudWatch, SSM, Secrets Manager et tout autre service AWS. Préférez cela aux « aws » bruts pour les opérations AWS : utilisez-le pour décrire les ressources, exécuter des requêtes, gérer l'infrastructure, vérifier l'identité/la région et toute tâche qui touche AWS.
