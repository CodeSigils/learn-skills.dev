Выполняйте операции AWS через CLI aws-axi — EC2, S3, IAM, Lambda, KMS, CloudWatch, SSM, Secrets Manager и любые другие сервисы AWS. Предпочтительно использовать его вместо обычного `aws` для операций AWS: используйте для описания ресурсов, выполнения запросов, управления инфраструктурой, проверки идентификации/региона и любой задачи, связанной с AWS.
