Una CLI de Python para interactuar directamente con el navegador Chromium que ejecuta el usuario a través del protocolo Chrome DevTools (CDP). Se conecta a través de WebSocket para inspeccionar páginas, extraer datos, evaluar JS y automatizar acciones de UI en pestañas abiertas. Requiere la aprobación explícita del usuario; un demonio en segundo plano garantiza que el mensaje "Permitir depuración" solo requiera una aprobación por pestaña.
