Une CLI Python pour interagir directement avec le navigateur Chromium en cours d'exécution de l'utilisateur via le protocole Chrome DevTools (CDP). Se connecte via WebSocket pour inspecter les pages, extraire des données, évaluer JS et automatiser les actions de l'interface utilisateur dans les onglets ouverts. Nécessite l'approbation explicite de l'utilisateur ; un démon en arrière-plan garantit que l'invite « Autoriser le débogage » ne nécessite qu'une seule approbation par onglet.
