Una CLI Python per interagire direttamente con il browser Chromium in esecuzione dell'utente tramite Chrome DevTools Protocol (CDP). Si connette tramite WebSocket per ispezionare pagine, estrarre dati, valutare JS e automatizzare le azioni dell'interfaccia utente nelle schede aperte. Richiede l'approvazione esplicita dell'utente; un demone in background garantisce che la richiesta "Consenti debugging" richieda solo un'approvazione per scheda.
