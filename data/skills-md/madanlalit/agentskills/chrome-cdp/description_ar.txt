واجهة سطر أوامر Python للتفاعل مباشرة مع متصفح Chromium الذي يقوم المستخدم بتشغيله عبر بروتوكول Chrome DevTools (CDP). يتصل عبر WebSocket لفحص الصفحات واستخراج البيانات وتقييم JS وأتمتة إجراءات واجهة المستخدم في علامات التبويب المفتوحة. يتطلب موافقة صريحة من المستخدم؛ يضمن البرنامج الخفي للخلفية أن مطالبة "السماح بالتصحيح" تتطلب موافقة واحدة فقط لكل علامة تبويب.
