Интерфейс командной строки Python для прямого взаимодействия с запущенным пользователем браузером Chromium через протокол Chrome DevTools (CDP). Подключается через WebSocket для проверки страниц, извлечения данных, оценки JS и автоматизации действий пользовательского интерфейса на открытых вкладках. Требуется явное одобрение пользователя; фоновый демон гарантирует, что для запроса «Разрешить отладку» требуется только одно подтверждение для каждой вкладки.
