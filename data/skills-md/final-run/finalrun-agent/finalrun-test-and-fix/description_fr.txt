Orchestrez la boucle FinalRun complète : utilisez finalrun-generate-test pour explorer une fonctionnalité et créer des tests, exécutez-les via finalrun-use-cli, puis triez les échecs des artefacts CLI et corrigez le code ou les tests de l'application jusqu'à ce que l'exécution soit verte. Déclenchez des requêtes telles que « déboguer ce test FinalRun ayant échoué », « vérifier et corriger la fonctionnalité avec FinalRun » ou en tant que boucle Definition-of-Done après une modification de l'interface utilisateur.
