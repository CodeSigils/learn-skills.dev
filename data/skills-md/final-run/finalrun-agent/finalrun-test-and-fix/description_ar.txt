قم بتنظيم حلقة FinalRun الكاملة - استخدم اختبار Finalrun-generate لاستكشاف الميزات واختبارات المؤلف، وتشغيلها عبر Finalrun-use-cli، ثم فرز حالات الفشل من عناصر CLI وإصلاح كود التطبيق أو الاختبارات حتى يصبح التشغيل أخضر. تشغيل طلبات مثل "تصحيح أخطاء اختبار FinalRun الفاشل هذا" أو "التحقق من الميزة وإصلاحها باستخدام FinalRun" أو كحلقة تعريف تم تنفيذها بعد تغيير واجهة المستخدم.
