Создавайте спецификации тестов и пакетов в строгом формате FinalRun YAML. Управляет автоматическим планированием тестирования, группировкой папок по функциям, конфигурацией приложения репозитория, переопределениями для конкретной среды в .finalrun/env/*.yaml и проверкой с помощью проверки Finalrun.
