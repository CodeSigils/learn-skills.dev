Универсальный веб-поиск с использованием DuckDuckGo и поисковых систем, синтезированных с помощью искусственного интеллекта. Используйте этот навык для поиска в Интернете, получения текущей информации, проверки фактов, новостей и исследований по любой теме, где необходимы актуальные данные из Интернета. Поддерживает все языки. Три режима: быстрые результаты в Интернете, ответы, синтезированные с помощью ИИ (IAsk.ai, отлично подходит для глубоких вопросов и академических исследований) и синтез ИИ Моники. Запуск по: «поиск», «поиск», «найти информацию о», «что самое последнее», «поиск в Интернете», «узнать о», «что случилось с», «текущий статус», «последние новости», «правда ли X», «查一下», «搜索», «查资料», «上网查», «検索して», «調べて», любой вопрос, требующий веб-данных в реальном времени или после обучения. НЕ запускайте триггер для: исследования кода, анализа локальных файлов, внутренних вопросов по базе кода или общепризнанных фактов, полностью охватываемых учебными знаниями. Примечание. Если также доступен навык «агент-досягаемость», отдайте предпочтение «ddg-search» для задач чисто веб-поиска; отдайте предпочтение «агентскому охвату», когда задача включает в себя социальные платформы (Twitter, Reddit, YouTube, WeChat, Bilibili и т. д.) или API-интерфейсы для конкретной платформы.
