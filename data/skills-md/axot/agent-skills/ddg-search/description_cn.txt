使用 DuckDuckGo 和人工智能合成搜索引擎的通用网络搜索。使用此技能进行网络搜索、当前信息、事实核查、新闻以及需要实时互联网数据的任何主题的研究。支持所有语言。三种模式：快速网络结果、AI 合成答案（IAsk.ai，非常适合深度问题和学术研究）和 Monica AI 合成。触发：“搜索”、“查找”、“查找有关信息”、“最新消息”、“搜索网络”、“了解”、“发生了什么”、“现状”、“最近新闻”、“X还是真的吗”、“查一下”、“搜索”、“查资料”、“上网查”、“検索して”、“调べて”、任何需要实时或训练后网络数据。请勿触发：代码探索、本地文件分析、代码库内部问题或培训知识完全涵盖的既定事实。注意：如果“agent-reach”技能也可用，则优先选择“ddg-search”来执行纯网络搜索任务；当任务涉及社交平台（Twitter、Reddit、YouTube、微信、Bilibili 等）或特定于平台的 API 时，更喜欢使用“agent-reach”。
