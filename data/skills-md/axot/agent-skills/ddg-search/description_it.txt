Ricerca web generica utilizzando DuckDuckGo e motori di ricerca sintetizzati dall'intelligenza artificiale. Utilizza questa capacità per ricerche sul Web, informazioni attuali, verifica dei fatti, notizie e ricerche su qualsiasi argomento in cui siano necessari dati Internet in tempo reale. Supporta tutte le lingue. Tre modalità: risultati web veloci, risposte sintetizzate dall'intelligenza artificiale (IAsk.ai, ottimo per domande profonde e ricerche accademiche) e sintesi AI di Monica. Attivazione su: "cerca", "cerca", "trova informazioni su", "quali sono le ultime novità", "cerca nel Web", "scopri", "cosa è successo con", "stato attuale di", "notizie recenti", "X è ancora vero", "查一下", "搜索", "查资料", "上网查", "検索して", "調べて", qualsiasi domanda che richieda dati web in tempo reale o post-formazione. NON attivare per: esplorazione del codice, analisi di file locali, domande interne alla base di codice o fatti consolidati completamente coperti dalle conoscenze di formazione. Nota: se è disponibile anche la capacità "agent-reach", preferisci "ddg-search" per attività di ricerca web pura; preferisci la "portata dell'agente" quando l'attività coinvolge piattaforme social (Twitter, Reddit, YouTube, WeChat, Bilibili, ecc.) o API specifiche della piattaforma.
