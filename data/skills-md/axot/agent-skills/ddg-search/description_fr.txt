Recherche Web à usage général à l'aide de DuckDuckGo et des moteurs de recherche synthétisés par l'IA. Utilisez cette compétence pour les recherches sur le Web, les informations actuelles, la vérification des faits, les actualités et les recherches sur tout sujet nécessitant des données Internet en direct. Prend en charge toutes les langues. Trois modes : résultats Web rapides, réponses synthétisées par l'IA (IAsk.ai, idéal pour les questions approfondies et la recherche universitaire) et synthèse Monica AI. Déclencheur sur : "rechercher", "rechercher", "trouver des informations sur", "quelles sont les dernières", "rechercher sur le Web", "découvrir", "ce qui s'est passé avec", "état actuel de", "nouvelles récentes", "X est-il toujours vrai", "查一下", "搜索", "查资料", "上网查", "検索して", "調べて", toute question nécessitant des données Web en temps réel ou post-formation. Ne déclenchez PAS pour : l'exploration de code, l'analyse de fichiers locaux, les questions internes à la base de code ou les faits bien établis entièrement couverts par les connaissances de formation. Remarque : si la compétence « agent-reach » est également disponible, préférez « ddg-search » pour les tâches de recherche Web pure ; préférez « Agent-Reach » lorsque la tâche implique des plateformes sociales (Twitter, Reddit, YouTube, WeChat, Bilibili, etc.) ou des API spécifiques à la plateforme.
