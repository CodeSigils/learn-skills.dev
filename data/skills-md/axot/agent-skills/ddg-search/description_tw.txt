使用 DuckDuckGo 和人工智慧合成搜尋引擎的通用網路搜尋。使用此技能進行網路搜尋、當前資訊、事實查核、新聞以及需要即時網路資料的任何主題的研究。支援所有語言。三種模式：快速網路結果、AI 合成答案（IAsk.ai，非常適合深度問題和學術研究）和 Monica AI 合成。觸發：「搜尋」、「尋找」、「尋找資訊」、「最新消息」、「搜尋網路」、「查資料」、「上網查」、「X還是真的嗎」、「查一下」、「搜尋」、「查資料」、「上網查」、「検索して」、「調べててべぁぁぁ」、「調べてべてべぁぁ」、「調べてぁ」、「調べてぁ」、「調べて」、「調べてべぁぁ」、「調整」請勿觸發：程式碼探索、本地文件分析、程式碼庫內部問題或培訓知識完全涵蓋的既定事實。注意：如果「agent-reach」技能也可用，則優先選擇「ddg-search」來執行純網路搜尋任務；當任務涉及社交平台（Twitter、Reddit、YouTube、微信、Bilibili 等）或特定於平台的 API 時，更喜歡使用「agent-reach」。
