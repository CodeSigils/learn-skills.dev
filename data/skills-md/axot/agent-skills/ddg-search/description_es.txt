Búsqueda web de uso general utilizando DuckDuckGo y motores de búsqueda sintetizados por IA. Utilice esta habilidad para búsquedas web, información actual, verificación de hechos, noticias e investigaciones sobre cualquier tema donde se necesiten datos en vivo de Internet. Soporta todos los idiomas. Tres modos: resultados web rápidos, respuestas sintetizadas por IA (IAsk.ai, ideal para preguntas profundas e investigaciones académicas) y síntesis de Monica AI. Activar: "buscar", "buscar", "encontrar información sobre", "lo último", "buscar en la web", "averiguar", "qué pasó con", "estado actual de", "noticias recientes", "X sigue siendo cierto", "查一下", "搜索", "查资料", "上网查", "検索して", "調べて", cualquier pregunta que requiera datos web en tiempo real o posteriores al entrenamiento. NO active para: exploración de código, análisis de archivos locales, preguntas internas de la base de código o hechos bien establecidos cubiertos completamente por el conocimiento de la capacitación. Nota: si la habilidad "alcance del agente" también está disponible, prefiera "ddg-search" para tareas de búsqueda web pura; prefiera el "alcance del agente" cuando la tarea involucra plataformas sociales (Twitter, Reddit, YouTube, WeChat, Bilibili, etc.) o API específicas de la plataforma.
