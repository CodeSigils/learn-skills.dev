DuckDuckGo と AI 合成検索エンジンを使用した汎用 Web 検索。このスキルは、Web 検索、最新情報、事実確認、ニュース、およびライブ インターネット データが必要なあらゆるトピックの調査に使用できます。すべての言語をサポートします。 3 つのモード: 高速 Web 結果、AI 合成回答 (IAsk.ai、深い質問や学術研究に最適)、Monica AI 合成。トリガー: 「検索する」、「調べる」、「情報を見つける」、「最新情報」、「ウェブを検索する」、「について調べる」、「何が起こった」、「現在の状況」、「最近のニュース」、「X はまだ真実ですか」、「查一下」、「搜索」、「查资料」、「上网查」、「検索して」、「調べて」、リアルタイムまたはトレーニング後の Web データ。コード探索、ローカル ファイル分析、コードベース内部の質問、またはトレーニングの知識で完全にカバーされている十分に確立された事実をトリガーにしないでください。注: 「agent-reach」スキルも利用できる場合は、純粋な Web 検索タスクには「ddg-search」を優先してください。タスクにソーシャル プラットフォーム (Twitter、Reddit、YouTube、WeChat、Bilibili など) またはプラットフォーム固有の API が含まれる場合は、「エージェント リーチ」を優先します。
