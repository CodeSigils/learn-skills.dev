Delegue tareas a agentes de oh-my-openagent (bibliotecario, oracle, sísifo, prometheus, atlas, explore, metis, momus) a través de la CLI de oh-my-opencode. Utilice esta habilidad siempre que el usuario diga "usar bibliotecario para", "usar oráculo para", "dejar bibliotecario", "preguntar a oráculo", "@bibliotecario", "@oracle" o nombre cualquier agente de oh-my-openagent en el contexto de realizar una tarea. También se activan equivalentes chinos: '用 bibliotecario 做', '用 oracle 做', '让 bibliotecario 帮'. Desambiguación: NO active para Oracle Database, Oracle Cloud, MongoDB Atlas o verbos de exploración de propósito general no relacionados con oh-my-openagent.
