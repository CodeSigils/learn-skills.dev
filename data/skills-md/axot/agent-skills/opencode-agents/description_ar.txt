تفويض المهام إلى وكلاء oh-my-openagent (أمين المكتبة، Oracle، sisyphus، prometheus، atlas، explore، metis، momus) عبر واجهة سطر أوامر oh-my-opencode. استخدم هذه المهارة عندما يقول المستخدم "استخدم أمين المكتبة ل"، أو "استخدم أوراكل ل"، أو "اسمح لأمين المكتبة"، أو "اسأل أوراكل ل"، أو "@librarian"، أو "@Oracle"، أو يسمي أي وكيل oh-my-openagent في سياق القيام بمهمة. يتم تشغيله أيضًا على المرادفات الصينية: '用 أمين المكتبة 做'، '用 أوراكل 做'، '让 أمين المكتبة 帮'. توضيح: لا تقم بتشغيل Oracle Database، أو Oracle Cloud، أو MongoDB Atlas، أو أفعال الاستكشاف ذات الأغراض العامة التي لا علاقة لها بـ oh-my-openagent.
