Delega le attività agli agenti oh-my-openagent (bibliotecario, oracolo, sisifo, prometeo, atlante, esplora, metis, momus) tramite la CLI oh-my-opencode. Utilizza questa abilità ogni volta che l'utente dice "usa il bibliotecario per", "usa oracle per", "lascia che il bibliotecario", "chiedi a oracle per", "@librarian", "@oracle" o nomina qualsiasi agente oh-my-openagent nel contesto dell'esecuzione di un'attività. Si attiva anche sugli equivalenti cinesi: '用 bibliotecario 做', '用 oracolo 做', '让 bibliotecario 帮'. Disambiguazione: NON attivare per Oracle Database, Oracle Cloud, MongoDB Atlas o verbi di esplorazione generici non correlati a oh-my-openagent.
