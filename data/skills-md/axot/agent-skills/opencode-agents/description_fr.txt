Déléguez des tâches aux agents oh-my-openagent (bibliothécaire, oracle, sisyphe, prometheus, atlas, explore, metis, momus) via la CLI oh-my-opencode. Utilisez cette compétence chaque fois que l'utilisateur dit « utiliser le bibliothécaire pour », « utiliser Oracle pour », « laisser le bibliothécaire », « demander à Oracle de », « @bibliothécaire », « @oracle », ou nomme un agent oh-my-openagent dans le contexte de l'exécution d'une tâche. Se déclenche également sur les équivalents chinois : '用 bibliothécaire 做', '用 oracle 做', '让 bibliothécaire 帮'. Désambiguïsation : ne déclenchez PAS pour Oracle Database, Oracle Cloud, MongoDB Atlas ou les verbes d'exploration à usage général sans rapport avec oh-my-openagent.
