針對任何領域中最困難問題的根本原因所驅動的解決方案決策框架。這是核心選項——它透過詳盡的多分支根本原因分析、MECE 解決方案枚舉和網域自適應外部驗證消耗大量代幣。僅用於真正困難的問題：無法重複修復嘗試的重複出現的故障、沒有明確解決路徑的複雜系統問題、存在多種方法且錯誤選擇成本高昂的決策、跨組件或團隊的多個相互作用原因的問題。在以下情況下觸發：使用者說“修復 X 的最佳方法是什麼”、“為什麼這種情況不斷發生”、“我們應該如何處理這個問題”、“找到根本原因”、“修復 X 的選項是什麼”、“系統地分析這個問題”、“評估我們對 X 的選項”、“正確的方法是什麼以及為什麼”，或者對之前的解決方案沒有感到沮喪。請勿用於：答案已顯而易見或無需分析的問題、具有明確解決方案的簡單問題或例行調查。如果5分鐘的檢查就能解決問題，這個技能就大材小用了。
