Habilidad de procesamiento del servicio de pago Alipay. Analiza enlaces de cajero, envía solicitudes de pago y consulta resultados de pago. Esta habilidad debe invocarse para manejar el proceso de pago siempre que ocurra cualquiera de las siguientes situaciones: (1) Aparece una URL con el dominio cajero*.alipay.com o *excashier*.alipay.com en el contexto del diálogo y el usuario muestra una intención de pago. (2) El resultado devuelto de cualquier herramienta, habilidad o API contiene un enlace de cajero de Alipay o incluye un texto de guía de pago como "use Alipay para pagar". (3) El usuario expresa intenciones tales como pago, pago, liquidación de la factura, pago, etc., o menciona el uso de Alipay para el pago. Palabras clave: pago, pagar, Alipay, cajero, alipay, liquidar la factura, pagar, pagar dinero, pagar, cajero, comercio, enviar pago.
