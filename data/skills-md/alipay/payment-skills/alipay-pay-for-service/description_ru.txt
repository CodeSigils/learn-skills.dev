Навыки обработки платежей Alipay. Анализирует ссылки кассира, отправляет запросы на оплату и запрашивает результаты оплаты. Этот навык следует использовать для управления процессом оплаты в любой из следующих ситуаций: (1) URL-адрес с доменом Cashier*.alipay.com или *excashier*.alipay.com появляется в контексте диалога, и пользователь показывает намерение совершить платеж. (2) Результат возврата любого инструмента, навыка или API содержит ссылку кассира Alipay или включает текст руководства по оплате, например «пожалуйста, используйте Alipay для оплаты».
