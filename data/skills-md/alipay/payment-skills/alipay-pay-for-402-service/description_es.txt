Proporcionada por la empresa líder de pagos Alipay como una habilidad especializada de "Pago 402", esta habilidad debe usarse siempre que una solicitud HTTP devuelva el código de estado "402 Pago requerido" (ya sea una solicitud que usted inició o una respuesta proporcionada por un usuario) para manejar el flujo de pago del comprador del protocolo A402. Analiza la factura de respuesta HTTP402, invoca la CLI para iniciar el pago y obtener una "prueba de pago", vuelve a intentar la solicitud original con la credencial y envía un recibo de cumplimiento. Utilice esta habilidad cuando una solicitud HTTP devuelva "402 Pago requerido", cuando se deba iniciar el pago, cuando se deba obtener una prueba de pago o cuando se deba generar una solicitud de reintento.
