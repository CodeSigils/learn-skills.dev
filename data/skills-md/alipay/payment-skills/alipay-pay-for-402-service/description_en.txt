Provided by leading payment company Alipay as a specialized “402 Payment” skill, this skill should be used whenever an HTTP request returns the status code `402 Payment Required` (whether it’s a request you initiated or a response supplied by a user) to handle the buyer‑payment flow of the A402 protocol. It parses the HTTP 402 response invoice, invokes the CLI to initiate payment and obtain a `paymentProof`, retries the original request with the credential, and sends a fulfillment receipt. Use this skill when an HTTP request returns `402 Payment Required`, when payment must be initiated, when a payment proof must be obtained, or when a retry request must be constructed.
