يدير مكونات Starwind UI ومشاريع Astro - تهيئة واجهة المستخدم وإضافتها والبحث عنها وإصلاحها وتصحيح الأخطاء والتصميم والتخصيص وإنشاء واجهة المستخدم. يوفر سياق المشروع ومستندات المكونات وتوجيهات CLI وقواعد التكوين الخاصة بـ Starwind. ينطبق عند العمل مع Starwind UI، أو مكونات Starwind، أو Astro + Tailwind CSS v4 UI، أو starwind.config.json، أو الرموز المميزة للموضوع، أو الوضع المظلم، أو ترحيل السمات بنمط shadcn، أو طلبات المكونات مثل تعيين Combobox للتحديد.
