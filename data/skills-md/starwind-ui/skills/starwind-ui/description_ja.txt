Starwind UI コンポーネントと Astro プロジェクトを管理します (初期化、追加、検索、修正、デバッグ、スタイル設定、テーマ設定、UI の構成)。プロジェクトのコンテキスト、コンポーネント ドキュメント、CLI ガイダンス、Starwind 固有の構成ルールを提供します。 Starwind UI、Starwind コンポーネント、Astro + Tailwind CSS v4 UI、starwind.config.json、テーマ トークン、ダーク モード、shadcn スタイルのテーマ移行、または選択へのコンボボックス マッピングなどのコンポーネント リクエストを操作する場合に適用されます。
