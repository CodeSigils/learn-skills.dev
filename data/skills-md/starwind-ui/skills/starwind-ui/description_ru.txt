Управляет компонентами пользовательского интерфейса Starwind и проектами Astro — инициализация, добавление, поиск, исправление, отладка, стилизация, оформление тем и создание пользовательского интерфейса. Предоставляет контекст проекта, документацию по компонентам, руководство по интерфейсу командной строки и правила композиции, специфичные для Starwind. Применяется при работе с пользовательским интерфейсом Starwind, компонентами Starwind, пользовательским интерфейсом Astro + Tailwind CSS v4, starwind.config.json, токенами тем, темным режимом, миграцией тем в стиле shadcn или запросами компонентов, такими как сопоставление Combobox с Select.
