Gère les composants de l'interface utilisateur Starwind et les projets Astro : initialisation, ajout, recherche, correction, débogage, style, thème et composition de l'interface utilisateur. Fournit le contexte du projet, la documentation des composants, les conseils CLI et les règles de composition spécifiques à Starwind. S'applique lorsque vous travaillez avec l'interface utilisateur Starwind, les composants Starwind, l'interface utilisateur Astro + Tailwind CSS v4, starwind.config.json, les jetons de thème, le mode sombre, la migration de thème de style shadcn ou les demandes de composants telles que le mappage Combobox vers Select.
