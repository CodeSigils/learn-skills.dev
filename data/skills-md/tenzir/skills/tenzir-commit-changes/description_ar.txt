تنفيذ التغييرات باعتبارها لقطات نظيفة وقابلة للمراجعة. يُستخدم عند تنفيذ العمل أو تنظيمه أو تقسيمه إلى وحدات منطقية أو كتابة رسائل الالتزام أو إصلاحها أو إنشاء عمليات التثبيت أو تنظيف سجل الالتزام. استخدمه أيضًا عندما يقول المستخدم "ارتكب هذا"، أو "احفظ تغييراتي"، أو "قم بالالتزام"، أو "اكتب رسالة التزام أفضل".
