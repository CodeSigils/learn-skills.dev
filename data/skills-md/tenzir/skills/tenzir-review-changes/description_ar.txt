مراجعة ومعالجة تغييرات التعليمات البرمجية في مشاريع Tenzir. يُستخدم عند تدقيق الاختلافات أو سحب الطلبات بحثًا عن الأخطاء، أو مشكلات الأمان، أو الاختبارات المفقودة، أو انحراف الوثائق، أو مشكلات قابلية القراءة، أو تراجعات الأداء، أو مشكلات تجربة المستخدم، أو عند التعامل مع تعليقات مراجعة طلب السحب، وخاصة تنفيذ التغييرات المطلوبة، أو الرد على المراجعين، أو حل سلاسل مراجعة GitHub، أو التحقق من أن تعليقات المراجعة لها حالة نهائية. استخدم أيضًا هذه المهارة عندما يقول المستخدم "مراجعة"، أو "أنظر إلى هذه العلاقات العامة"، أو "تحقق من تغييراتي"، أو "تدقيق هذا الاختلاف"، أو "تناول نتائج المراجعة"، أو "حل تعليقات العلاقات العامة".
