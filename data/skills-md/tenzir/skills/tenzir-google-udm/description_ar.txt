أجب عن الأسئلة حول البنية الميدانية لـ Google SecOps / Chronicle UDM (نموذج البيانات الموحد)، وإرشادات التسوية، وتعيين السجلات لأحداث UDM أو كائنات الكيانات، وإنشاء حمولات استيعاب UDM API. يُستخدم عندما يسأل المستخدم عن حقول UDM، أو أنواع الأحداث، أو أنواع الكيانات، أو الحقول المطلوبة، أو تنسيقات الحقول، أو بادئات مسار الحقل لـ YARA-L، أو القواعد، أو Detect Engine، أو CBN، أو الرسائل، أو التعدادات، أو أسماء الكيانات، أو metadata.event_type / metadata.eventType، أو Security_result /securityResult، أو الشبكة، أو تسوية Chronicle، أو حمولات UDM API، أو نقاط نهاية استيعاب Google SecOps.
