Gérez les packages Tenzir tout au long du cycle de vie : ajoutez de nouveaux packages, inspectez les packages existants, mettez à jour les manifestes, étendez ou supprimez les fonctionnalités des packages, refactorisez les opérateurs définis par l'utilisateur, gérez les tests et les exemples, configurez les entrées et les contextes, expédiez les pipelines déployables, publiez les packages et retirez les surfaces de packages obsolètes. À utiliser lorsque l'utilisateur travaille dans le contexte d'un package Tenzir ou souhaite organiser des fonctionnalités réutilisables en tant que package.
