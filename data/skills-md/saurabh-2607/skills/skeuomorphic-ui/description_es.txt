Cree componentes de interfaz de usuario esqueuomórficos oscuros (perillas, controles deslizantes, controles insertados, carcasas elevadas) con iluminación superior, sombras en capas, profundidad táctil y patrones de interacción listos para animación. Active esta habilidad cuando el usuario solicite componentes esqueuomórficos, controles oscuros neumórficos, diales giratorios o una interfaz de usuario realista similar a un hardware.
