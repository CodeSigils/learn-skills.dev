Habilidad práctica de flujo de trabajo de descubrimiento de vulnerabilidades de SRC / crowdtesting / bug bounty. Incluye: una metodología de cinco etapas (ingesta → reconocimiento → enumeración → búsqueda → informe), 19 guías de tipo de ataque (SQLi, XSS, RCE, SSRF, IDOR, CSRF, Path Traversal, File Upload, SSTI, XXE, Race, HTTP Smuggling, OAuth, JWT, SAML, GraphQL, Mobile, LLM, DoS), 305 cargas útiles estructuradas, 263 bypass WAF/EDR variantes, 2.887 casos reales revelados de nivel alto/crítico de HackerOne, más de 77.000 estadísticas de casos de WooYun, una biblioteca de huellas dactilares de OA/middleware nacional y guías verticales para industrias bancarias y de telecomunicaciones. Se activa cuando el usuario menciona "excavación src / descubrimiento de vulnerabilidad src / recompensa por errores / crowdtesting / hackerone / recompensa por vulnerabilidad / SRC / cualquier vulnerabilidad X / prueba de penetración" o pregunta "cómo excavar un determinado objetivo/cómo probar una determinada API/cómo evitar WAF".
