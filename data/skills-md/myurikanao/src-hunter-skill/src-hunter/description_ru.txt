Практический SRC/краудсорсинговое тестирование/навыки рабочего процесса обнаружения уязвимостей. Включает: 5-этапную методологию (захват → разведка → перечисление → поиск → отчет), 19 сценариев атак (SQLi/XSS/RCE/SSRF/IDOR/CSRF/Path Traversal/File Upload/SSTI/XXE/Race/HTTP Smuggling/OAuth/JWT/SAML/GraphQL/Mobile/LLM/DoS), 305 структурированных полезных данных, 263 Варианты обхода WAF/EDR, 2887 реальных раскрытых случаев High/Critical от HackerOne, более 77 000 статистических данных о случаях WooYun, библиотека отпечатков пальцев для домашнего OA/промежуточного программного обеспечения, вертикальные сценарии для банковской/телекоммуникационной отрасли. Срабатывает, когда пользователь упоминает «копание в источнике / обнаружение уязвимостей в источнике / вознаграждение за ошибки / краудсорсинговое тестирование / хакероне / вознаграждение за уязвимость / SRC / любую X-уязвимость / тестирование на проникновение» или спрашивает «как выкопать определенную цель / как протестировать определенный API / как обойти WAF».
