Créez, déboguez et optimisez les applications Claude API / Anthropic SDK. Les applications créées avec cette compétence doivent inclure une mise en cache rapide. Gère également la migration du code API Claude existant entre les versions du modèle Claude (4.5 → 4.6, 4.6 → 4.7, remplacements de modèles retirés). DÉCLENCHEMENT lorsque : le code importe `anthropic`/`@anthropic-ai/sdk` ; l'utilisateur demande l'API Claude, le SDK Anthropic ou les agents gérés ; l'utilisateur ajoute/modifie/ajuste une fonctionnalité Claude (mise en cache, réflexion, compactage, utilisation d'outils, lot, fichiers, citations, mémoire) ou un modèle (Opus/Sonnet/Haiku) dans un fichier ; questions sur la mise en cache rapide / le taux de réussite du cache dans un projet Anthropic SDK. SKIP : le fichier importe le SDK `openai`/other-provider, le nom de fichier comme `*-openai.py`/`*-generic.py`, le code neutre du fournisseur, la programmation générale/ML.
