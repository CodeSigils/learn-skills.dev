Создавайте, отлаживайте и оптимизируйте приложения Claude API/Anthropic SDK. Приложения, созданные с использованием этого навыка, должны включать оперативное кэширование. Также обрабатывает миграцию существующего кода API Claude между версиями модели Claude (4.5 → 4.6, 4.6 → 4.7, замены устаревших моделей). TRIGGER когда: код импортирует `anthropic`/`@anthropic-ai/sdk`; пользователь запрашивает Claude API, Anthropic SDK или управляемые агенты; пользователь добавляет/изменяет/настраивает функцию Claude (кэширование, мышление, сжатие, использование инструментов, пакетная обработка, файлы, цитаты, память) или модель (Opus/Sonnet/Haiku) в файле; вопросы о быстром кэшировании/скорости попадания в кэш в проекте Anthropic SDK. ПРОПУСК: файл импортирует `openai`/other-provider SDK, имя файла типа `*-openai.py`/`*-generic.py`, независимый от поставщика код, общее программирование/ML.
