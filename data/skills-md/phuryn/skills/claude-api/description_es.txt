Cree, depure y optimice aplicaciones Claude API/Anthropic SDK. Las aplicaciones creadas con esta habilidad deben incluir almacenamiento en caché rápido. También maneja la migración del código API de Claude existente entre versiones del modelo Claude (4.5 → 4.6, 4.6 → 4.7, reemplazos de modelos retirados). DISPARAR cuando: el código importa `anthropic`/`@anthropic-ai/sdk`; el usuario solicita la API de Claude, el SDK de Anthropic o los agentes administrados; el usuario agrega/modifica/afina una característica de Claude (almacenamiento en caché, pensamiento, compactación, uso de herramientas, lotes, archivos, citas, memoria) o modelo (Opus/Sonnet/Haiku) en un archivo; preguntas sobre el almacenamiento en caché rápido/tasa de aciertos de caché en un proyecto de Anthropic SDK. SALTAR: el archivo importa `openai`/SDK de otro proveedor, nombre de archivo como `*-openai.py`/`*-generic.py`, código neutral del proveedor, programación general/ML.
