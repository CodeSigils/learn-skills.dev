Crée ou réconcilie un système de planification léger GitHub Projects V2 lié à un référentiel, à l'aide d'étiquettes de référentiel ainsi que de relations parent/sous-problème natives pour les conventions de phase, d'épopée, de spécification et de ticket d'implémentation. À utiliser lorsque l'utilisateur demande à installer, configurer, connecter ou standardiser un projet GitHub pour un référentiel ou un document de planification.
