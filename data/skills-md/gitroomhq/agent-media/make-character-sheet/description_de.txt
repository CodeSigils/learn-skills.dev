Erstellen Sie aus einem Porträt ein Charakterblatt im Magazinstil. Geben Sie ENTWEDER „portrait_url“ (muss von R2 gehostet werden) ODER „portrait_image_base64“ (PNG/JPEG, ≤ 10 MB; die API lädt es zuerst auf R2 hoch) an. Optionale Beschreibung mit ≤ 10 Wörtern für Hinweise zu Name, Alter und Stimmung.
