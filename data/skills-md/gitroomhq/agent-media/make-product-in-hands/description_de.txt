Erstellen Sie ein vertikales UGC-Video mit einer Länge von 5/10/15 Sekunden, in dem Ihr Charakter ein Produkt hält, trägt und zeigt. Geben Sie eine „character_sheet_url“ (von R2 gehostet) und das Produktbild an (product_image_url – eine beliebige https-URL – ODER „product_image_base64“; automatisch auf R2 gehostet). Zwei Modi: Skript für eine lippensynchrone Produktrezension mit sprechendem Kopf (2–4 Wörter/Sek.), ODER scene_action für eine stille Demo/B-Rolle. Legen Sie einen Betreff (z. B. „eine junge Frau“) fest, um das Geschlecht/Aussehen der Person zu sperren, damit ein geschlechtsspezifisches Produkt es nicht ändern kann. Rahmung: „close_up“ (Brust nach oben, Standard) oder „full_body“ (von Kopf bis Fuß, für Umdrehungen / Darstellung des gesamten Outfits). Sowohl die Person als auch das genaue Produkt sind aus den Referenzbildern ausgeschlossen.
