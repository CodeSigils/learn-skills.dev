À utiliser au début d'une session, après le compactage ou chaque fois que vous avez besoin de vous orienter vers une base de code inconnue ou obsolète. Charge le contexte des perles, approfondit la base de code et produit un résumé structuré de « l'état actuel ». Se déclenche sur des expressions telles que « rattrapez-moi », « où sommes-nous », « orientez-moi », « quel est l'état de ce projet », « mettez-moi au courant », « charger le contexte », « orientation de session ».
