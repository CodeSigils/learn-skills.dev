Costruisci suggerimenti di alta qualità attraverso un'intervista guidata. Da utilizzare quando l'utente esegue `/build-prompt`, chiede "aiutami a scrivere un prompt" o incolla un prompt approssimativo e desidera perfezionarlo. Rileva automaticamente se l'obiettivo è un prompt di sistema, una definizione di agente, un comando di barra o un prompt di attività one-shot e personalizza di conseguenza il modello di intervista e di intervista. L'output segue le ultime migliori pratiche di Anthropic per i modelli Opus/Sonnet/Haiku 4.x.
