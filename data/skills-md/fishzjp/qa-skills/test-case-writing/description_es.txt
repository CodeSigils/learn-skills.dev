Úselo al generar casos de prueba manuales ejecutables (mapa de marcas) a partir de documentos de requisitos, documentación de API, informes de errores o repositorios de código: código primero: solicite el repositorio, realice una revisión del código para encontrar errores potenciales antes de escribir casos de prueba y extraiga un esquema legible por máquina. No apto para: modelado de requisitos (análisis de requisitos), estrategia de prueba (estrategia de prueba), revisión independiente (revisión de caso de prueba), scripts automatizados (pruebas automáticas e2e/pruebas API).
