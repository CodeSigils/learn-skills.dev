Usato quando si generano casi di test manuali eseguibili (markmap) a partire da documenti dei requisiti, documentazione API, segnalazioni di bug o repository di codice — code‑first: recuperare il repository, eseguire una revisione del codice per trovare potenziali bug prima di scrivere i casi di test e estrarre uno schema leggibile dalla macchina. Non è per: modellazione dei requisiti (requirement-analysis), strategia di test (test-strategy), revisione indipendente (test-case-review), script automatizzati (automated‑e2e‑testing / api‑testing).
