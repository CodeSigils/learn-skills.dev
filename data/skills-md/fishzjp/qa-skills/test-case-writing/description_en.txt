Use when generating executable manual test cases (markmap) from requirement documents, API documentation, bug reports, or code repositories — code‑first: request the repository, conduct a code review to find potential bugs before writing test cases, and extract a machine‑readable schema. Not for: requirement modeling (requirement-analysis), test strategy (test-strategy), independent review (test-case-review), automated scripts (automated‑e2e‑testing / API testing).
