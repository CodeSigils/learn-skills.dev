Utilisez lors de la génération de cas de test manuels exécutables (markmap) à partir de documents d’exigences, de documentation d’API, de rapports de bugs ou de dépôts de code — code‑first : demandez le dépôt, effectuez une revue de code pour identifier les bugs potentiels avant d’écrire les cas de test, et extrayez un schéma lisible par machine. Pas pour : modélisation des exigences (requirement‑analysis), stratégie de test (test‑strategy), révision indépendante (test‑case‑review), scripts automatisés (automated‑e2e‑testing / test d’API).
