Verwendung beim Generieren ausführbarer manueller Testfälle (Markmap) aus Anforderungsdokumenten, API-Dokumentation, Fehlerberichten oder Code-Repositorys – Code zuerst: Fordern Sie das Repository an, führen Sie eine Codeüberprüfung durch, um potenzielle Fehler zu finden, bevor Sie Testfälle schreiben, und extrahieren Sie ein maschinenlesbares Schema. Nicht für: Anforderungsmodellierung (Anforderungsanalyse), Teststrategie (Teststrategie), unabhängige Überprüfung (Testfallüberprüfung), automatisierte Skripte (automatisierte E2E-Tests / API-Tests).
