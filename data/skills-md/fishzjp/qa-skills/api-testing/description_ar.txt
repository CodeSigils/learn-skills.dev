يُستخدم لاختبار مستوى الـ API — بدءًا من حالات اختبار الـ API القابلة للتشغيل الآلي المستخرجة من وثائق OpenAPI/Swagger أو مخططات حالات الاختبار، يغطي المعلمات، الحدود، المصادقة، عدم التكرار، التزامن، استجابات الأخطاء، واتساق البيانات، وينتج سكريبتات اختبار API قابلة للتنفيذ ونتائج التنفيذ؛ يشمل تكامل اختبار أداء API (k6، طبقة تنفيذ المحور 1 من type‑matrix). ليس للاستخدام في: تدفقات واجهة المستخدم الويب (اختبار end‑to‑end آلي)، كتابة حالات الاختبار يدوياً (كتابة حالات الاختبار). يرجى دائمًا الرد بلغة المستخدم.
