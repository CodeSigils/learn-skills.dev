Utilisé lors des tests au niveau de l'API : à partir de cas de test d'interface automatisables dérivés de la documentation OpenAPI/Swagger ou de schémas de cas, couvrant les paramètres, les limites, l'authentification, l'idempotence, la concurrence, les réponses aux erreurs et la cohérence des données, produisant des scripts de test d'API exécutables et des résultats d'exécution ; inclut l’intégration des tests de charge API (k6, couche d’exécution de l’axe 1 de la matrice de type). Non utilisé pour : les flux d'interface utilisateur Web (tests e2e automatisés), l'écriture manuelle de cas de test (écriture de cas de test).
