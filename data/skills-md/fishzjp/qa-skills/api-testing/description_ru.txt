Используется во время тестирования на уровне API — начиная с автоматизированных тестовых примеров интерфейса, полученных из документации OpenAPI/Swagger или схем случаев, охватывающих параметры, границы, аутентификацию, идемпотентность, параллелизм, ответы на ошибки и согласованность данных, создание исполняемых тестовых сценариев API и результатов выполнения; включает интеграцию API-интерфейса нагрузочного тестирования (k6, уровень выполнения матрицы типов по оси 1). Не используется для: потоков веб-интерфейса (автоматическое e2e-тестирование), написания тестовых сценариев вручную (написание тестовых сценариев).
