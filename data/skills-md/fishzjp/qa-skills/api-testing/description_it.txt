Used for interface-level testing—starting from automatable interface cases in OpenAPI/Swagger documentation or case schemas, covering parameters, boundaries, authentication, idempotency, concurrency, error responses, and data consistency, producing executable API test scripts and run results; include l'integrazione del test di carico dell'interfaccia (k6, livello di esecuzione dell'asse 1 della matrice di tipo). Non utilizzato per: flussi dell'interfaccia utente Web (e2e‑testing automatizzato), scrittura manuale dei test case (scrittura dei test case).
