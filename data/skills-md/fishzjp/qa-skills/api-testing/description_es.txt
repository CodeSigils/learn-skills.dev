Se utiliza durante las pruebas a nivel de API, a partir de casos de prueba de interfaz automatizables derivados de la documentación o esquemas de casos de OpenAPI/Swagger, que cubren parámetros, límites, autenticación, idempotencia, concurrencia, respuestas de error y coherencia de datos, produciendo scripts de prueba de API ejecutables y resultados de ejecución; Incluye integración de pruebas de carga API (k6, capa de ejecución type-matrix axis1). No se utiliza para: flujos de interfaz de usuario web (pruebas e2e automatizadas), escritura manual de casos de prueba (escritura de casos de prueba).
