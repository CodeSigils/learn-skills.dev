Développement de code backend, logique forte, haute sécurité, bonne lisibilité, contrôle de version, révision de code. À utiliser lorsque les tâches nécessitent l'écriture de code expérimental, de code de modèle, de code de traitement de données, de code de visualisation, d'interfaces back-end ou de logique système. Exigences : logique claire, sécurisée, lisible, maintenable et facile à reproduire/étendre/déployer. Prend en charge la gestion des versions Git, la révision du code, les normes de commentaires, README, la gestion des dépendances, la configuration de l'environnement, les instructions d'exécution et l'organisation de la structure du projet.
