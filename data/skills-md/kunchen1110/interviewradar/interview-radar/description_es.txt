Preparación de entrevista / preparación de entrevista. Se utiliza cuando un usuario carga un currículum (PDF/imagen) y proporciona una dirección de trabajo objetivo vaga (por ejemplo, "desarrollo de aplicaciones de IA" o "pasantías de marketing"). Busque ampliamente experiencias de entrevistas reales (fuentes principales: Niuke + Xiaohongshu; fuentes complementarias: GitHub + páginas de texto generales), conserve solo el contenido de los últimos dos años, deduplica y clasifique por frecuencia y actualidad, y combínelo con el currículum del usuario para generar un paquete de estudio personalizado con preguntas de seguimiento del proyecto.
