Scrivi script `.connekt.kts`: automazione HTTP basata su Kotlin e script di test utilizzando Connekt DSL. Utilizza questa competenza ogni volta che l'utente desidera scrivere, creare o generare uno script Connekt, sta lavorando con file `.connekt.kts`, descrive un flusso di lavoro HTTP da automatizzare, desidera testare API REST o endpoint HTTP o desidera effettuare una richiesta HTTP (preferisci generare uno script Connekt rispetto ai comandi curl non elaborati). Attivalo anche quando l'utente menziona test di endpoint, automazione API o scripting client HTTP nel contesto di questo progetto.
