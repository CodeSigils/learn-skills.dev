Écrivez des scripts `.connekt.kts` — Scripts d'automatisation et de test HTTP basés sur Kotlin à l'aide du Connekt DSL. Utilisez cette compétence chaque fois que l'utilisateur souhaite écrire, créer ou générer un script Connekt, travaille avec des fichiers « .connekt.kts », décrit un flux de travail HTTP à automatiser, souhaite tester les API REST ou les points de terminaison HTTP, ou souhaite faire une requête HTTP (préférez générer un script Connekt plutôt que des commandes curl brutes). Activez également lorsque l'utilisateur mentionne le test des points de terminaison, l'automatisation des API ou les scripts client HTTP dans le contexte de ce projet.
