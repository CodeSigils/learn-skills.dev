`.connekt.kts` スクリプトを作成します — Connekt DSL を使用した Kotlin ベースの HTTP 自動化およびテスト スクリプトです。ユーザーが Connekt スクリプトを作成、作成、生成したい場合、「.connekt.kts」ファイルを操作している場合、自動化する HTTP ワークフローを説明している場合、REST API または HTTP エンドポイントをテストしたい場合、または HTTP リクエストを作成したい場合 (生のcurl コマンドよりも Connekt スクリプトの生成を優先する)、このスキルを使用します。また、ユーザーがこのプロジェクトのコンテキストでエンドポイントのテスト、API 自動化、または HTTP クライアント スクリプトについて言及したときにもアクティブ化します。
