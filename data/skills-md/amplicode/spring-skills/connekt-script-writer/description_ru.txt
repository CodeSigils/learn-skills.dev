Напишите сценарии `.connekt.kts` — сценарии автоматизации и тестирования HTTP на основе Kotlin с использованием Connekt DSL. Используйте этот навык всякий раз, когда пользователь хочет написать, создать или сгенерировать сценарий Connekt, работает с файлами .connekt.kts, описывает рабочий процесс HTTP для автоматизации, хочет протестировать REST API или конечные точки HTTP или хочет сделать HTTP-запрос (предпочитает генерировать сценарий Connekt, а не необработанные команды Curl). Также активируйте, когда пользователь упоминает конечные точки тестирования, автоматизацию API или сценарии HTTP-клиента в контексте этого проекта.
