Escriba scripts `.connekt.kts`: scripts de prueba y automatización HTTP basados ​​en Kotlin utilizando Connekt DSL. Utilice esta habilidad siempre que el usuario quiera escribir, crear o generar un script de Connekt, esté trabajando con archivos `.connekt.kts`, describa un flujo de trabajo HTTP para automatizar, quiera probar API REST o puntos finales HTTP, o quiera realizar una solicitud HTTP (prefiera generar un script de Connekt en lugar de comandos curl sin formato). Actívelo también cuando el usuario mencione puntos finales de prueba, automatización de API o secuencias de comandos de cliente HTTP en el contexto de este proyecto.
