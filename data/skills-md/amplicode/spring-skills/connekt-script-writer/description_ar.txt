كتابة البرامج النصية `.connekt.kts` - أتمتة HTTP المستندة إلى Kotlin واختبار البرامج النصية باستخدام Connekt DSL. استخدم هذه المهارة عندما يريد المستخدم كتابة برنامج نصي Connekt أو إنشائه أو إنشاؤه، أو العمل مع ملفات `.connekt.kts`، أو وصف سير عمل HTTP للتشغيل التلقائي، أو يريد اختبار واجهات برمجة تطبيقات REST أو نقاط نهاية HTTP، أو يريد تقديم طلب HTTP (يفضل إنشاء برنامج نصي Connekt على أوامر الضفيرة الأولية). يتم التنشيط أيضًا عندما يذكر المستخدم اختبار نقاط النهاية أو أتمتة واجهة برمجة التطبيقات (API) أو البرمجة النصية لعميل HTTP في سياق هذا المشروع.
