Reglas de seguridad, flujos de trabajo y referencia de herramientas para depurar aplicaciones mediante el depurador IntelliJ: puntos de interrupción, sesiones de depuración, pasos, evaluación de expresiones, inspección del estado del tiempo de ejecución. DISPARAR cuando: el usuario quiere depurar, investigar un error, establecer puntos de interrupción, inspeccionar el comportamiento en tiempo de ejecución, recorrer el código o comprender por qué el código se comporta inesperadamente en tiempo de ejecución. Frases de activación (ES): "depurar", "punto de interrupción", "pasar a través", "pasar a", "pasar por encima", "por qué falla esto", "por qué es nulo", "iniciar en modo de depuración", "rastrear ejecución", "ejecutar con depurador", "evaluar expresión". Frases de activación (RU): "отладить", "дебаг", "брейкпоинт", "почему падает", "пошагово пройти", "зайти в метод", "посмотреть значеменной", "запустить в режиме отладки", "почему null", "стектрейс". También se activa cuando el usuario quiere comprender el comportamiento del tiempo de ejecución o investigar un comportamiento incorrecto.
