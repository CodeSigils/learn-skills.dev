Reformater le code source de ce projet en utilisant ses propres paramètres de style de code — via l’IDE IntelliJ lorsqu’il est en cours d’exécution, sinon via le formateur propre au projet (Spotless / google‑java‑format / palantir‑java‑format) en secours. Utilisez ceci chaque fois que l’utilisateur demande de formater, reformater, nettoyer, « embellir », corriger l’indentation ou optimiser les imports sur des fichiers Java/Kotlin/XML/etc. — que ce soit un seul fichier nommé, un bloc ou une plage de lignes sélectionnée, un groupe de fichiers nommés, ou tous les fichiers non validés (modifiés par git). Cette compétence est également généralement invoquée après toute modification de fichiers — appliquez‑la aux fichiers que vous venez de créer ou de modifier une fois les éditions terminées, afin que le résultat reste cohérent avec le style de code du projet.
