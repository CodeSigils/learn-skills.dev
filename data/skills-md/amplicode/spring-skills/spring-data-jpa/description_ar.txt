القواعد والمبادئ التوجيهية للعمل مع Spring Data JPA في المشروع. استخدم هذه المهارة دائمًا عند إضافة أو إزالة أو تعديل كيانات JPA أو المستودعات أو الإسقاطات. تشغيل أي طلب يتضمن تغيير بنية الكيان، أو إضافة كيانات جديدة، أو تعديل التعليقات التوضيحية للحقل، أو تحديث تعيينات قاعدة البيانات، أو إنشاء أو تعديل مستودعات Spring Data، أو تحديد توقعات الاستعلام (الواجهات، DTOs).
