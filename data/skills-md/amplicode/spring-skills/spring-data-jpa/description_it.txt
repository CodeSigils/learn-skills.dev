Regole e linee guida per lavorare con Spring Data JPA nel progetto. Utilizza SEMPRE questa abilità quando aggiungi, rimuovi o modifichi entità, repository o proiezioni JPA. Attivazione su qualsiasi richiesta che comporti la modifica della struttura delle entità, l'aggiunta di nuove entità, la modifica delle annotazioni dei campi, l'aggiornamento delle mappature dei database, la creazione o la modifica dei repository Spring Data o la definizione delle proiezioni delle query (interfacce, DTO).
