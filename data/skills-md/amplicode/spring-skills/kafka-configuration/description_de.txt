Konfiguriert den Kafka-Starter von Spring Boot über „application.properties“ / „application.yml“. Verwenden Sie diese Fähigkeit, wenn eine Kafka-Konfiguration erstellt werden muss, entweder eigenständig oder als Teil einer größeren Aufgabe (z. B. vor dem Hinzufügen eines „KafkaTemplate“-Produzenten oder eines „@KafkaListener“-Konsumenten).
