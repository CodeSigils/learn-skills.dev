Reglas y pautas para trabajar con Spring Data JDBC en el proyecto. SIEMPRE utilice esta habilidad al agregar, eliminar o modificar entidades Spring Data JDBC (@Table de org.springframework.data.relational.core.mapping), agregados, enlaces AggregateReference, objetos incrustados, asociaciones @MappedCollection o repositorios Spring Data JDBC (CrudRepository/ListCrudRepository). Se activa en cualquier solicitud que toque anotaciones @Table, @Column, @MappedCollection, @Embedded de spring-data-relational, campos AggregateReference, constructores @PersistenceCreator o métodos @Query en repositorios JDBC. NO lo use para entidades JPA (jakarta.persistence); en su lugar, use la habilidad spring-data-jpa.
