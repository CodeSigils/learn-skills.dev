Règles et directives pour travailler avec Spring Data JDBC dans le projet. Utilisez TOUJOURS cette compétence lors de l'ajout, de la suppression ou de la modification d'entités Spring Data JDBC (@Table de org.springframework.data.relational.core.mapping), d'agrégats, de liens AggregateReference, d'objets incorporés, d'associations @MappedCollection ou de référentiels Spring Data JDBC (CrudRepository / ListCrudRepository). Déclenchez toute requête qui touche les annotations @Table, @Column, @MappedCollection, @Embedded de spring-data-relational, les champs AggregateReference, les constructeurs @PersistenceCreator ou les méthodes @Query sur les référentiels JDBC. Ne PAS utiliser pour les entités JPA (jakarta.persistence) – utilisez plutôt la compétence spring-data-jpa.
