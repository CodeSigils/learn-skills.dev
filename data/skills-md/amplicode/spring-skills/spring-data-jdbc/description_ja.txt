プロジェクト内で Spring Data JDBC を使用するためのルールとガイドライン。 Spring Data JDBC エンティティ (org.springframework.data.relational.core.mapping の @Table)、集約、AggregateReference リンク、埋め込みオブジェクト、@MappedCollection 関連付け、または Spring Data JDBC リポジトリ (CrudRepository / ListCrudRepository) を追加、削除、または変更する場合は、常にこのスキルを使用してください。 Spring-data-relational からの @Table、@Column、@MappedCollection、@Embedded アノテーション、AggregateReference フィールド、@PersistenceCreator コンストラクター、または JDBC リポジトリの @Query メソッドに触れるリクエストをトリガーします。 JPA (jakarta.persistence) エンティティには使用しないでください。代わりに spring-data-jpa スキルを使用してください。
