Правила и рекомендации по работе со Spring Data JDBC в проекте. ВСЕГДА используйте этот навык при добавлении, удалении или изменении сущностей Spring Data JDBC (@Table из org.springframework.data.relational.core.mapping), агрегатов, ссылок AggregateReference, внедренных объектов, ассоциаций @MappedCollection или репозиториев Spring Data JDBC (CrudRepository/ListCrudRepository). Запускайте любой запрос, который касается аннотаций @Table, @Column, @MappedCollection, @Embedded из полей Spring-Data-Relational, AggregateReference, конструкторов @PersistenceCreator или методов @Query в репозиториях JDBC. НЕ используйте для объектов JPA (jakarta.persistence) — вместо этого используйте навык Spring-data-jpa.
