القواعد والإرشادات للعمل مع Spring Data JDBC في المشروع. استخدم دائمًا هذه المهارة عند إضافة أو إزالة أو تعديل كيانات Spring Data JDBC (@Table from org.springframework.data.relational.core.mapping)، أو التجميعات، أو روابط AggregateReference، أو الكائنات المضمنة، أو اقترانات @MappedCollection، أو مستودعات Spring Data JDBC (CrudRepository / ListCrudRepository). قم بتشغيل أي طلب يمس @Table أو @Column أو @MappedCollection أو @Embedded التعليقات التوضيحية من حقول Spring-data-relational أو AggregateReference أو مُنشئات @PersistenceCreator أو أساليب @Query في مستودعات JDBC. لا تستخدم مع كيانات JPA (jakarta.persistence) — استخدم مهارة Spring-data-jpa بدلاً من ذلك.
