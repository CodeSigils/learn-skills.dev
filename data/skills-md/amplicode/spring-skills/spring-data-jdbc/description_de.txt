Regeln und Richtlinien für die Arbeit mit Spring Data JDBC im Projekt. Verwenden Sie diese Fähigkeit IMMER, wenn Sie Spring Data JDBC-Entitäten (@Table aus org.springframework.data.relational.core.mapping), Aggregate, AggregateReference-Links, eingebettete Objekte, @MappedCollection-Zuordnungen oder Spring Data JDBC-Repositorys (CrudRepository/ListCrudRepository) hinzufügen, entfernen oder ändern. Wird bei jeder Anfrage ausgelöst, die @Table-, @Column-, @MappedCollection-, @Embedded-Annotationen aus Spring-Data-Relational-, AggregateReference-Feldern, @PersistenceCreator-Konstruktoren oder @Query-Methoden in JDBC-Repositorys berührt. NICHT für JPA-Entitäten (jakarta.persistence) verwenden – verwenden Sie stattdessen den Skill spring-data-jpa.
