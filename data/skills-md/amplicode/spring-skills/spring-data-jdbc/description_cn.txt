在项目中使用 Spring Data JDBC 的规则和指南。在添加、删除或修改 Spring Data JDBC 实体（org.springframework.data.relational.core.mapping 中的 @Table）、聚合、AggregateReference 链接、嵌入对象、@MappedCollection 关联或 Spring Data JDBC 存储库（CrudRepository / ListCrudRepository）时，始终使用此技能。触发任何涉及来自 spring-data-relational 的 @Table、@Column、@MappedCollection、@Embedded 注释、AggregateReference 字段、@PersistenceCreator 构造函数或 JDBC 存储库上的 @Query 方法的请求。不要用于 JPA (jakarta.persistence) 实体 - 请改用 spring-data-jpa 技能。
