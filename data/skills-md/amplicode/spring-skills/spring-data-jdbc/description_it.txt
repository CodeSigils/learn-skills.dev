Regole e linee guida per lavorare con Spring Data JDBC nel progetto. Utilizzare SEMPRE questa competenza quando si aggiungono, rimuovono o modificano entità JDBC Spring Data (@Table da org.springframework.data.relational.core.mapping), aggregati, collegamenti AggregateReference, oggetti incorporati, associazioni @MappedCollection o repository JDBC Spring Data (CrudRepository/ListCrudRepository). Attivazione su qualsiasi richiesta che tocca le annotazioni @Table, @Column, @MappedCollection, @Embedded da spring-data-relational, campi AggregateReference, costruttori @PersistenceCreator o metodi @Query su repository JDBC. NON utilizzare per entità JPA (jakarta.persistence): utilizzare invece la competenza spring-data-jpa.
