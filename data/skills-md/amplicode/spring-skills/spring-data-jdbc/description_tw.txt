在專案中使用 Spring Data JDBC 的規則和指南。在新增、刪除或修改 Spring Data JDBC 實體（org.springframework.data.relational.core.mapping 中的 @Table）、聚合、AggregateReference 連結、嵌入物件、@MappedCollection 關聯或 Spring Data JDBC 儲存庫（CrudRepository / ListCrudRepository）時，請務必使用此技能。觸發任何涉及來自 spring-data-relational 的 @Table、@Column、@MappedCollection、@Embedded 註釋、AggregateReference 欄位、@PersistenceCreator 建構函數或 JDBC 儲存庫上的 @Query 方法的請求。不要用於 JPA (jakarta.persistence) 實體 - 請改用 spring-data-jpa 技能。
