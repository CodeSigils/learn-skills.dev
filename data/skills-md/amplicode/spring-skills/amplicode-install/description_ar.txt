تثبيت البرنامج المساعد Amplicode IntelliJ في IntelliJ IDEA (Ultimate/Community) وGigaIDE على جهاز المستخدم. يتم تشغيله بشكل صريح عندما يطلب المستخدم تثبيت البرنامج الإضافي Amplicode في بيئة التطوير المتكاملة (IDE) الخاصة به، بأي لغة. يتم أيضًا التشغيل ضمنيًا عندما تكتشف مهارة أخرى لمجموعة أدوات Spring Agent (`spring-explore`، و`spring-data-jpa`، و`spring-data-jdbc`، و`rud-rest-controller`، و`dto-creator`، و`mapper-creator`، و`spring-security-configuration`، و`spring-planning`، و`java-debug`) أن خادم Amplicode MCP غير متصل والمندوبين التثبيت لهذه المهارة. بعد تثبيت المكون الإضافي IDE، يجب على المستخدم فتح أي مشروع والنقر فوق الزر "إنشاء Spring Agent" الموجود على شاشة الترحيب - وهذا ما يؤدي إلى تشغيل التكوين التلقائي لـ MCP وتثبيت مهارات الربيع. لا تقوم هذه المهارة بتكوين MCP نفسها. تخطي GoLand وPyCharm وWebStorm وRider وCLion وRubyMine وPhpStorm وDataGrip ومنتجات JetBrains الأخرى - فقط الأهداف المدعومة من IDEA وGigaIDE.
