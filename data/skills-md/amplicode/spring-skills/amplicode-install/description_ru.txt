Устанавливает плагин Amplicode IntelliJ в IntelliJ IDEA (Ultimate/Community) и GigaIDE на компьютере пользователя. Запускается явно, когда пользователь просит установить плагин Amplicode в свою IDE на любом языке. Также срабатывает неявно, когда другой навык Spring Agent Toolkit (spring-explore, Spring-data-jpa, Spring-data-jdbc, Crud-rest-Controller, dto-creator, Mapper-Creator, Spring-Security-Configuration, Spring-Planning, Java-Debug) обнаруживает, что сервер Amplicode MCP не подключен, и делегирует установку этот навык. После установки IDE-плагина пользователь должен открыть любой проект и нажать кнопку «Настроить Spring Agent» на экране приветствия — именно это запускает автоконфигурацию MCP и установку Spring-skills. Этот навык НЕ настраивает сам MCP. Пропустите GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip и другие продукты JetBrains — поддерживаются только IDEA и GigaIDE.
