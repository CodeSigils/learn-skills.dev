Amplicode IntelliJ 플러그인을 사용자 컴퓨터의 IntelliJ IDEA(Ultimate/Community) 및 GigaIDE에 설치합니다. 사용자가 어떤 언어로든 IDE에 Amplicode 플러그인을 설치하도록 요청하면 명시적으로 트리거됩니다. 또한 다른 Spring Agent Toolkit 기술(`spring-explore`, `spring-data-jpa`, `spring-data-jdbc`, `crud-rest-controller`, `dto-creator`, `mapper-creator`, `spring-security-configuration`, `spring-planning`, `java-debug`)이 Amplicode MCP 서버가 연결되지 않았음을 감지하고 설치를 이 기술에 위임하는 경우에도 암시적으로 트리거됩니다. IDE 플러그인이 설치된 후 사용자는 프로젝트를 열고 시작 화면에서 "Настроить Spring Agent" 버튼을 클릭해야 합니다. 이것이 MCP 자동 구성 및 spring-skill 설치를 트리거하는 것입니다. 이 기술은 MCP 자체를 구성하지 않습니다. GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip 및 기타 JetBrains 제품은 건너뛰십시오. IDEA 및 GigaIDE만 지원되는 대상입니다.
