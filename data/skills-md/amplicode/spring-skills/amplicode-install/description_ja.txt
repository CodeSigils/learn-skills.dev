Amplicode IntelliJ プラグインをユーザーのマシン上の IntelliJ IDEA (Ultimate/Community) および GigaIDE にインストールします。ユーザーが Amplicode プラグインを IDE にインストールするよう要求したときに、任意の言語で明示的にトリガーします。また、別の Spring Agent Toolkit スキル (`spring-explore`、`spring-data-jpa`、`spring-data-jdbc`、`crud-rest-controller`、`dto-creator`、`mapper-creator`、`spring-security-configuration`、`spring-planning`、`java-debug`) が Amplicode MCP サーバーが接続されていないことを検出し、委任したときに暗黙的にトリガーされます。このスキルにインストールします。 IDE プラグインのインストール後、ユーザーは任意のプロジェクトを開いて、ようこそ画面の「Spring Agent」ボタンをクリックする必要があります。これにより、MCP 自動構成と Spring スキルのインストールがトリガーされます。このスキルは MCP 自体を構成しません。 GoLand、PyCharm、WebStorm、Rider、CLion、RubyMine、PhpStorm、DataGrip、その他の JetBrains 製品はスキップしてください。IDEA と GigaIDE のみがサポートされています。
