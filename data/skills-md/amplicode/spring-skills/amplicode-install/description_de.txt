Installiert das Amplicode IntelliJ-Plugin in IntelliJ IDEA (Ultimate/Community) und GigaIDE auf dem Computer des Benutzers. Wird explizit ausgelöst, wenn der Benutzer in einer beliebigen Sprache darum bittet, das Amplicode-Plugin in seiner IDE zu installieren. Wird auch implizit ausgelöst, wenn ein anderer Spring Agent Toolkit-Skill („spring-explore“, „spring-data-jpa“, „spring-data-jdbc“, „crud-rest-controller“, „dto-creator“, „mapper-creator“, „spring-security-configuration“, „spring-planning“, „java-debug“) erkennt, dass der Amplicode MCP-Server nicht verbunden ist, und die Installation delegiert zu dieser Fähigkeit. Nachdem das IDE-Plugin installiert ist, muss der Benutzer ein beliebiges Projekt öffnen und auf dem Begrüßungsbildschirm auf die Schaltfläche „Spring Agent installieren“ klicken – das löst die automatische MCP-Konfiguration und die Spring-Skills-Installation aus. Dieser Skill konfiguriert MCP NICHT selbst. Überspringen Sie GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip und andere JetBrains-Produkte – nur IDEA und GigaIDE sind unterstützte Ziele.
