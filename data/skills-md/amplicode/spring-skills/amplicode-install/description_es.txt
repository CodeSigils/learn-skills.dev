Instala el complemento Amplicode IntelliJ en IntelliJ IDEA (Ultimate/Community) y GigaIDE en la máquina del usuario. Se activa explícitamente cuando el usuario solicita instalar el complemento Amplicode en su IDE, en cualquier idioma. También se activa implícitamente cuando otra habilidad de Spring Agent Toolkit (`spring-explore`, `spring-data-jpa`, `spring-data-jdbc`, `crud-rest-controller`, `dto-creator`, `mapper-creator`, `spring-security-configuration`, `spring-planning`, `java-debug`) detecta que el servidor Amplicode MCP no está conectado y delega la instalación a esta habilidad. Después de instalar el complemento IDE, el usuario debe abrir cualquier proyecto y hacer clic en el botón "Instalar Spring Agent" en la pantalla de bienvenida; eso es lo que activa la configuración automática de MCP y la instalación de Spring-Skills. Esta habilidad NO configura MCP en sí. Omita GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip y otros productos JetBrains; solo IDEA y GigaIDE son objetivos compatibles.
