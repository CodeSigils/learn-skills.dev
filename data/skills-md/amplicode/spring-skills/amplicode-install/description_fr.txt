Installe le plugin Amplicode IntelliJ dans IntelliJ IDEA (Ultimate/Community) et GigaIDE sur la machine de l'utilisateur. Déclenchez explicitement lorsque l'utilisateur demande d'installer le plugin Amplicode dans son IDE, dans n'importe quelle langue. Se déclenche également implicitement lorsqu'une autre compétence Spring Agent Toolkit (`spring-explore`, `spring-data-jpa`, `spring-data-jdbc`, `crud-rest-controller`, `dto-creator`, `mapper-creator`, `spring-security-configuration`, `spring-planning`, `java-debug`) détecte que le serveur Amplicode MCP n'est pas connecté et lui délègue l'installation. compétence. Une fois le plugin IDE installé, l'utilisateur doit ouvrir n'importe quel projet et cliquer sur le bouton "Ouvrir Spring Agent" sur l'écran d'accueil - c'est ce qui déclenche la configuration automatique de MCP et l'installation de Spring-Skills. Cette compétence ne configure PAS MCP lui-même. Ignorez GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip et d'autres produits JetBrains : seuls IDEA et GigaIDE sont des cibles prises en charge.
