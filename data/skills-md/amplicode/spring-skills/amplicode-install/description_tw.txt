將 Amplicode IntelliJ 外掛程式安裝到使用者電腦上的 IntelliJ IDEA（Ultimate/Community）和 GigaIDE 中。當使用者要求以任何語言將 Amplicode 插件安裝到其 IDE 中時明確觸發。當另一個 Spring Agent Toolkit 技能（「spring-explore」、「spring-data-jpa」、「spring-data-jdbc」、「crud-rest-controller」、「dto-creator」、「mapper-creator」、「spring-security-configuration」、「spring-plan」、「java-dem伺服器未連接並將安裝委託給此技能時，也會隱式觸發。安裝 IDE 外掛程式後，使用者必須開啟任何項目並點擊歡迎畫面上的「Настроить Spring Agent」按鈕 - 這將觸發 MCP 自動配置和 spring-skills 安裝。此技能不會配置 MCP 本身。跳過 GoLand、PyCharm、WebStorm、Rider、CLion、RubyMine、PhpStorm、DataGrip 和其他 JetBrains 產品 — 僅 IDEA 和 GigaIDE 是支援的目標。
