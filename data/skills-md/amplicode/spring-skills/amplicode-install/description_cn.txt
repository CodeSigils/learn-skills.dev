将 Amplicode IntelliJ 插件安装到用户计算机上的 IntelliJ IDEA（Ultimate/Community）和 GigaIDE 中。当用户要求以任何语言将 Amplicode 插件安装到其 IDE 中时显式触发。当另一个 Spring Agent Toolkit 技能（“spring-explore”、“spring-data-jpa”、“spring-data-jdbc”、“crud-rest-controller”、“dto-creator”、“mapper-creator”、“spring-security-configuration”、“spring-planning”、“java-debug”）检测到 Amplicode MCP 服务器未连接并将安装委托给此技能时，也会隐式触发。安装 IDE 插件后，用户必须打开任何项目并单击欢迎屏幕上的“Настроить Spring Agent”按钮 - 这将触发 MCP 自动配置和 spring-skills 安装。此技能不会配置 MCP 本身。跳过 GoLand、PyCharm、WebStorm、Rider、CLion、RubyMine、PhpStorm、DataGrip 和其他 JetBrains 产品 — 仅 IDEA 和 GigaIDE 是受支持的目标。
