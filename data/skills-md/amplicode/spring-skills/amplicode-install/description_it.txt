Installa il plug-in Amplicode IntelliJ in IntelliJ IDEA (Ultimate/Community) e GigaIDE sul computer dell'utente. Si attiva esplicitamente quando l'utente richiede di installare il plugin Amplicode nel proprio IDE, in qualsiasi lingua. Si attiva implicitamente anche quando un'altra competenza di Spring Agent Toolkit (`spring-explore`, `spring-data-jpa`, `spring-data-jdbc`, `crud-rest-controller`, `dto-creator`, `mapper-creator`, `spring-security-configuration`, `spring-planning`, `java-debug`) rileva che il server Amplicode MCP non è connesso e delega l'installazione a questa competenza. Dopo aver installato il plug-in IDE, l'utente deve aprire qualsiasi progetto e fare clic sul pulsante "Installa Spring Agent" nella schermata di benvenuto: questo è ciò che attiva la configurazione automatica di MCP e l'installazione delle competenze primaverili. Questa abilità NON configura MCP stesso. Salta GoLand, PyCharm, WebStorm, Rider, CLion, RubyMine, PhpStorm, DataGrip e altri prodotti JetBrains: solo IDEA e GigaIDE sono target supportati.
