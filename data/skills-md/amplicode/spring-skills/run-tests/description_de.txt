Führen Sie die Tests eines Gradle-Projekts nach Testtyp oder Modul aus – Einheit, Integration oder alle. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer die Tests des Projekts ausführen, erneut ausführen oder überprüfen möchte (z. B. „Komponententests ausführen“, „Alle Tests ausführen“, „Integrationstests für das Veterinärmodul ausführen“, „Wurden die Tests bestanden?“).
