Запускайте тесты проекта Gradle по типу теста или модулю — модульному, интеграционному или всем. Используйте этот навык всякий раз, когда пользователь хочет запустить, перезапустить или проверить тесты проекта (например, «запустить модульные тесты», «запустить все тесты», «запустить интеграционные тесты для модуля ветеринара», «прошли ли тесты?»).
