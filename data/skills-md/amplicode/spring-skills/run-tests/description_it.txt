Esegui i test di un progetto Gradle per tipo di test o modulo: unità, integrazione o tutti. Utilizza questa abilità ogni volta che l'utente desidera eseguire, rieseguire o verificare i test del progetto (ad esempio "esegui i test unitari", "esegui tutti i test", "esegui i test di integrazione per il modulo veterinario", "i test sono passati?").
