Exécutez les tests d'un projet Gradle par type de test ou module : unité, intégration ou tout. Utilisez cette compétence chaque fois que l'utilisateur souhaite exécuter, réexécuter ou vérifier les tests du projet (par exemple « exécuter les tests unitaires », « exécuter tous les tests », « exécuter les tests d'intégration pour le module vétérinaire », « les tests ont-ils réussi ? »).
