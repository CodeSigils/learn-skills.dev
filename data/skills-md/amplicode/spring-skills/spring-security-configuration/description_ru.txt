Создает класс конфигурации Spring Security с настройкой аутентификации, авторизации и защиты HTTP. Используйте этот навык, когда необходимо создать конфигурацию безопасности, как отдельную, так и как часть более крупной задачи (например, добавление аутентификации в REST API, настройка входа в систему OAuth2/OIDC, настройка сервера ресурсов JWT).
