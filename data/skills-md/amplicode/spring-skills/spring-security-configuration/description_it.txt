Crea una classe di configurazione Spring Security con configurazione di autenticazione, autorizzazione e protezione HTTP. Utilizza questa competenza quando è necessario creare una configurazione di sicurezza, autonoma o come parte di un'attività più ampia (ad esempio, aggiunta dell'autenticazione a un'API REST, configurazione dell'accesso OAuth2/OIDC, configurazione del server di risorse JWT).
