Erstellt eine Spring Security-Konfigurationsklasse mit Authentifizierung, Autorisierung und HTTP-Schutzeinrichtung. Verwenden Sie diese Fähigkeit, wenn eine Sicherheitskonfiguration erstellt werden muss, entweder eigenständig oder als Teil einer größeren Aufgabe (z. B. Hinzufügen einer Authentifizierung zu einer REST-API, Konfigurieren der OAuth2/OIDC-Anmeldung, Einrichten eines JWT-Ressourcenservers).
