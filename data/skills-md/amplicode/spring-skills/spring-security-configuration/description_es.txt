Crea una clase de configuración de Spring Security con configuración de autenticación, autorización y protección HTTP. Utilice esta habilidad cuando sea necesario crear una configuración de seguridad, ya sea de forma independiente o como parte de una tarea más grande (por ejemplo, agregar autenticación a una API REST, configurar el inicio de sesión OAuth2/OIDC, configurar el servidor de recursos JWT).
