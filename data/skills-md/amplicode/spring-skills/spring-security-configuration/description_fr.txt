Crée une classe de configuration Spring Security avec configuration de l'authentification, de l'autorisation et de la protection HTTP. Utilisez cette compétence lorsqu'une configuration de sécurité doit être créée, soit de manière autonome, soit dans le cadre d'une tâche plus vaste (par exemple, ajout d'une authentification à une API REST, configuration de la connexion OAuth2/OIDC, configuration du serveur de ressources JWT).
