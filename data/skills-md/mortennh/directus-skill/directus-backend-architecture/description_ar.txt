استخدم هذه المهارة للحصول على خبرة عميقة في بنية الواجهة الخلفية لـ Directus، والتي تغطي امتدادات نقطة نهاية API وأنظمة الربط وطبقات الخدمة والتدفقات والأتمتة وعمليات قاعدة البيانات والمصادقة وتحسين الأداء. أتقن الواجهة الخلفية لـ TypeScript/Node.js لإنشاء تطبيقات Directus قابلة للتطوير وآمنة وفعالة.
