Guida gli utenti passo dopo passo attraverso le interviste per chiarire le loro esigenze e infine fornire un pacchetto di competenze completo (incluso SKILL.md, documenti di riferimento, file di esempio, ecc.), pronto per l'uso come archivio compresso.
Si attiva quando l'utente dice “Voglio creare una Skill tramite un colloquio”, “crea una Skill tramite colloquio”, “colloquio per costruire una Skill”, “aiutami a generare una Skill tramite un colloquio”, “creazione di Skill in stile colloquio”, “Voglio un colloquio per costruire una Skill per XX”.
La parola chiave trigger deve contenere la parola “intervista”; Le richieste di creazione di competenze senza "colloquio" non vengono gestite da questa competenza.
Non nei casi in cui esiste già un SKILL.md completo e sono necessarie solo modifiche minori, né per richieste di prompt one-shot.
