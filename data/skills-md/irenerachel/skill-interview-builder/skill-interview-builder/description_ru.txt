Используйте пошаговые интервью, чтобы помочь пользователям уточнить их потребности и в конечном итоге создать полный пакет файлов Skill (включая SKILL.md, справочные документы, файлы примеров и т. д.) и упаковать его в готовый к использованию сжатый архив.
Запускается, когда пользователь говорит: «Я хочу создать навык посредством собеседования», «создать навык посредством собеседования», «интервью для развития навыка», «помогите мне создать навык посредством собеседования», «создание навыка в стиле интервью» или «Я хочу пройти собеседование, чтобы развить навык для XX».
Ключевое слово-триггер должно содержать слово «интервью»; Запросы на создание навыков без «интервью» не обрабатываются этим навыком.
Не предназначено для случаев, когда полный SKILL.md уже существует и требуются лишь незначительные изменения, а также для однократных запросов на подсказку.
