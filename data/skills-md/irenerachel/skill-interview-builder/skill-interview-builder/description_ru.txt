Направляйте пользователей шаг за шагом через собеседования, чтобы уточнить их потребности и в конечном итоге предоставить полный пакет Skill (включая SKILL.md, справочную документацию, файлы примеров и т. д.), сжатый и готовый к использованию.  
Запускается, когда пользователь говорит: «Я хочу создать Навык посредством собеседования», «Создать Навык посредством собеседования», «Интервью для формирования Навыка», «Помогите мне создать Навык посредством собеседования», «Создание Навыка в стиле собеседования» или «Я хочу пройти собеседование, чтобы развить Навык для XX».  
Ключевое слово триггера должно содержать «интервью»; Запросы на создание навыков без «интервью» не обрабатываются этим навыком.  
Не для случаев, когда уже есть полный файл SKILL.md, требующий лишь незначительных изменений, и не для однократных запросов на подсказку.
