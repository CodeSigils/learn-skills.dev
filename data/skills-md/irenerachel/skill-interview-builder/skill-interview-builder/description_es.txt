Guíe a los usuarios paso a paso a través de una entrevista para aclarar los requisitos y, en última instancia, entregar un paquete de habilidades completo (que incluye SKILL.md, documentos de referencia, archivos de ejemplo, etc.), comprimido y listo para usar.
Se activa cuando el usuario dice "Quiero crear una habilidad a través de una entrevista", "crear una habilidad a través de una entrevista", "crear una habilidad mediante entrevista", "ayúdame a generar una habilidad a través de una entrevista", "creación de habilidades estilo entrevista" o "Quiero realizar una entrevista para desarrollar una habilidad XX".
La palabra clave desencadenante debe contener "entrevista"; Las solicitudes de creación de habilidades sin "entrevista" no son manejadas por esta habilidad.
No para casos que ya tienen un SKILL.md completo que necesita solo ediciones menores, ni para solicitudes puntuales.
