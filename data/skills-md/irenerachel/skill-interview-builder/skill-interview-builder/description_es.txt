Utilice entrevistas paso a paso para guiar a los usuarios a aclarar sus necesidades y, en última instancia, producir un paquete de archivos Skill completo (incluido SKILL.md, documentos de referencia, archivos de ejemplo, etc.) y empaquetarlo en un archivo comprimido listo para usar.
Se activa cuando el usuario dice "Quiero crear una habilidad a través de una entrevista", "crear una habilidad a través de una entrevista", "entrevista para desarrollar una habilidad", "ayúdame a generar una habilidad a través de una entrevista", "creación de habilidades estilo entrevista" o "Quiero una entrevista para desarrollar una habilidad para XX".
La palabra clave desencadenante debe contener la palabra "entrevista"; Las solicitudes de creación de habilidades sin "entrevista" no son manejadas por esta habilidad.
No está destinado a casos en los que ya existe un SKILL.md completo y solo se necesitan cambios menores, ni para solicitudes puntuales.
