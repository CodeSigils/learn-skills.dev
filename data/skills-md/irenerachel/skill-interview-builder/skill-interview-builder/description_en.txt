Use step-by-step interviews to guide users in clarifying their requirements, ultimately producing a complete Skill file package (including SKILL.md, reference documents, example files, etc.) and packaging it into a ready-to-use compressed archive.
Triggered when the user says “I want to create a Skill through an interview,” “make a Skill via interview,” “interview to build Skill,” “help me generate a Skill through an interview,” “interview-style Skill creation,” or “I want to interview to build a Skill for XX.”
The trigger keywords must include the word “interview”; Skill creation requests without “interview” are not handled by this Skill.
Not intended for cases where a complete SKILL.md already exists and only minor changes are needed, nor for one-shot prompt requests.
