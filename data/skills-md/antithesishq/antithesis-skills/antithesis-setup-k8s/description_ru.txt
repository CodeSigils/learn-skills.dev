Создайте возможности Antithesis для клиентов, использующих Kubernetes: преобразуйте управляющие диаграммы, настраиваемые шаблоны или необработанные манифесты Kubernetes в минимизированный набор манифестов для Antithesis. Убедитесь, что манифесты Kubernetes находятся в правильной форме с помощью snouty validate и развертывания локального кластера. Передает его на запуск антитезиса, если пользователь хочет отправить запуск. В конце концов, пользователь готов запустить антитезисную рабочую нагрузку для построения тестов. Если желаемой настройкой является создание докеров, отложите навык настройки антитезиса.
