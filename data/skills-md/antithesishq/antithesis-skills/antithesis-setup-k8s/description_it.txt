Impalcatura del cablaggio di Antithesis per i clienti che utilizzano Kubernetes: converti grafici helm, modelli kustomize o manifest Kubernetes grezzi in un set ridotto di manifest per Antithesis. Verifica che i manifest Kubernetes abbiano la forma corretta con la convalida snouty e la distribuzione del cluster locale. Passa a antithesis-launch se l'utente desidera inviare un'esecuzione. Alla fine, l'utente è pronto per eseguire antithesis-workload per creare test. Se la configurazione desiderata è docker-compose, rimandare alla competenza di configurazione dell'antitesi.
