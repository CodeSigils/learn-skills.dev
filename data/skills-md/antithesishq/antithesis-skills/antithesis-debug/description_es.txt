Utilice esta habilidad para depurar interactivamente ejecuciones de pruebas de Antithesis utilizando el depurador multiverso. Abra una URL de sesión de depuración, inspeccione los sistemas de archivos del contenedor y el estado del tiempo de ejecución, ejecute comandos de shell y extraiga evidencia desde el interior del entorno Antithesis. Admite tanto el depurador simplificado (predeterminado) como el modo portátil avanzado.
