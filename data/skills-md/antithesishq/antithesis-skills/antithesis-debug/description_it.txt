Utilizza questa competenza per eseguire il debug interattivo delle esecuzioni di test di Antithesis utilizzando il debugger multiverse. Apri un URL della sessione di debug, ispeziona i file system del contenitore e lo stato di runtime, esegui comandi shell ed estrai prove dall'interno dell'ambiente Antithesis. Supporta sia il debugger semplificato (predefinito) che la modalità notebook avanzata.
