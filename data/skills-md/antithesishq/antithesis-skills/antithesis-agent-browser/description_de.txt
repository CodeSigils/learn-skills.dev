Authentifizieren Sie den „Agent-Browser“ gegenüber einem Antithesis-Mandanten und lesen Sie Daten von Antithesis-Webseiten (Triage-Berichte, Ausführungsseite, Protokollanzeige, Kausalitätsberichte). Rufen Sie diesen Skill nur auf, wenn dies ausdrücklich von einem anderen Skill oder dem Benutzer angefordert wird. Erfordert eine interaktive Browserauthentifizierung und ist für vollständig Headless-Workflows ungeeignet.
