مهارات أتمتة FreeCAD CAD، مما يؤدي إلى قيادة FreeCAD مباشرة عبر نصوص Python للنمذجة البارامترية.  
يغطي سير العمل الهندسي بالكامل: نمذجة الأجزاء (Part Design + Sketcher)، والتجميعات، والرسومات (TechDraw)، وتصدير الملفات.  
يعمل عبر الأنظمة الأساسية (Windows / macOS / Linux) دفعة واحدة بدون واجهة المستخدم الرسومية.  
متوافق مع FreeCAD 0.21 و1.0+.
