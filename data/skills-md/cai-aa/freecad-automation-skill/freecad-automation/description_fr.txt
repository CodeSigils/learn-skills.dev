Compétences en automatisation CAO FreeCAD, pilotant FreeCAD directement via des scripts Python pour la modélisation paramétrique.  
Couvre l'ensemble du flux de travail d'ingénierie : modélisation de pièces (Part Design + Sketcher), assemblages, dessins (TechDraw), exportation de fichiers.  
Multiplateforme (Windows / macOS / Linux), s'exécute par lots sans interface graphique.  
Compatible avec FreeCAD 0.21 et 1.0+.
