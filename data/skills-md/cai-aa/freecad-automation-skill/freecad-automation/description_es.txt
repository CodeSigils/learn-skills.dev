Habilidades de automatización CAD de FreeCAD, manejando FreeCAD directamente a través de scripts de Python para modelado paramétrico.  
Cubre todo el flujo de trabajo de ingeniería: modelado de piezas (Part Design + Sketcher), ensamblajes, dibujos (TechDraw), exportación de archivos.  
Multiplataforma (Windows / macOS / Linux), se ejecuta por lotes sin GUI.  
Compatible con FreeCAD 0.21 y 1.0+.
