FreeCAD Навыки автоматизации САПР, управление FreeCAD напрямую с помощью скриптов Python для параметрического моделирования.  
Охватывает полный рабочий процесс проектирования: моделирование деталей (Part Design + Sketcher), сборки, чертежи (TechDraw), экспорт файлов.  
Кроссплатформенность (Windows/macOS/Linux), работает в пакетном режиме без графического интерфейса.  
Совместим с FreeCAD 0.21 и 1.0+.
