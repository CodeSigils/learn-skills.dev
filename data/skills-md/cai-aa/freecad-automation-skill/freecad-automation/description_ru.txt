FreeCAD Навыки автоматизации САПР, управление FreeCAD напрямую с помощью скриптов Python для параметрического моделирования.  
Охватывает полный рабочий процесс проектирования: моделирование деталей (Part Design + Sketcher), сборки, чертежи (TechDraw), экспорт файлов.  
Кроссплатформенность (Windows/macOS/Linux), работает в пакетном режиме без графического интерфейса.  
Совместим с FreeCAD 0.21 и 1.0+.  
Сценарии срабатывания: когда пользователи упоминают FreeCAD, САПР с открытым исходным кодом, параметрическое моделирование, проектирование деталей, эскизы, сценарии 3D-моделирования, экспорт STEP/STL/IGES, макросы FreeCAD, моделирование FEM, листовой металл, чертежи или связанные с ними потребности.  
Ключевые слова-триггеры: FreeCAD, САПР с открытым исходным кодом, Part Design, Sketcher, TechDraw, FCStd, макрос FreeCAD, FreeCAD Python, сценарий FreeCAD, экспорт STEP, экспорт STL, бесплатный CAD.
