Web を検索し、ローカル ツール スタックを使用してページをスクレイピングします: SearXNG (メタ検索)、Lightpanda (高速ヘッドレス フェッチ)、Agent-Browser (完全なブラウザ自動化)。これはデフォルトの Web スキルです。何かを調べたり、トピックを調査したり、Web ページを取得したり、URL からコンテンツを抽出したり、現在の情報を確認したり、ドキュメントを検索したり、競合調査を行ったり、ライブ Web データから恩恵を受ける質問に答えたりする必要があるときはいつでも、このスキルを使用してください。あらゆる形式でトリガーされます: 検索、ルックアップ、Google、調べる、調査、最新情報、このページを取得する、このサイトをスクレイピングする、この URL を確認する、情報を取得する、Web 検索、または現在の Web 情報が答えを改善するタスクです。ユーザーが検索を明示的に求めていなくても、適切に答えるために自分が持っていない最新の情報が必要な場合は、このスキルを使用してください。フォームへの入力やクリックなどの対話型ブラウザ自動化には使用できません ([[agent-browser]] または [[browser-use]] を使用します)。
