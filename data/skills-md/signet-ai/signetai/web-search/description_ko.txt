로컬 도구 스택인 SearXNG(메타 검색), Lightpanda(빠른 헤드리스 가져오기) 및 Agent-Browser(전체 브라우저 자동화)를 사용하여 웹을 검색하고 페이지를 스크랩합니다. 이것은 기본 웹 기술입니다. 무언가를 찾고, 주제를 조사하고, 웹페이지를 가져오고, URL에서 콘텐츠를 추출하고, 현재 정보를 확인하고, 문서를 찾고, 경쟁 조사를 수행하거나, 라이브 웹 데이터의 이점을 활용하는 질문에 답해야 할 때마다 이 기술을 사용하세요. 모든 형태의 트리거: 검색, 조회, Google, 알아보기, 연구, 최신 정보, 이 페이지 가져오기, 이 사이트 스크랩, 이 URL 확인, 정보 가져오기, 웹 검색 또는 현재 웹 정보가 답변을 향상시킬 수 있는 모든 작업. 사용자가 검색을 명시적으로 요청하지 않더라도 — 답변을 잘하기 위해 현재 가지고 있지 않은 정보가 필요한 경우 이 기술을 사용하세요. 양식 채우기 또는 클릭과 같은 대화형 브라우저 자동화에는 적합하지 않습니다([[agent-browser]] 또는 [[browser-use]] 사용).
