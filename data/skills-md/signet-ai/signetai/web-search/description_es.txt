Busque en la web y extraiga páginas utilizando la pila de herramientas local: SearXNG (metabúsqueda), Lightpanda (búsqueda rápida sin cabeza) y Agent-Browser (automatización completa del navegador). Esta es su habilidad web PREDETERMINADA: úsela siempre que necesite buscar algo, investigar un tema, buscar una página web, extraer contenido de una URL, verificar información actual, buscar documentación, realizar una investigación competitiva o responder cualquier pregunta que se beneficie de los datos web en vivo. Activa cualquier forma de: buscar, buscar en Google, averiguar, investigar, qué hay de nuevo, buscar esta página, extraer este sitio, verificar esta URL, extraer información, búsqueda web o cualquier tarea en la que la información web actual mejoraría su respuesta. Incluso si el usuario no te pide explícitamente que busques, si responder bien requiere información actual que no tienes, utiliza esta habilidad. NO para la automatización interactiva del navegador, como completar formularios o hacer clic (use [[agent-browser]] o [[browser-use]]).
