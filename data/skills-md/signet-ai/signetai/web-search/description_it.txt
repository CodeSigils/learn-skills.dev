Cerca sul Web e acquisisci pagine utilizzando lo stack di strumenti locali: SearXNG (meta-ricerca), Lightpanda (recupero veloce senza testa) e Agent-Browser (automazione completa del browser). Questa è la tua competenza web PREDEFINITA: usala ogni volta che hai bisogno di cercare qualcosa, ricercare un argomento, recuperare una pagina web, estrarre contenuto da un URL, controllare informazioni correnti, trovare documentazione, fare ricerche competitive o rispondere a qualsiasi domanda che trae vantaggio dai dati web in tempo reale. Si attiva in qualsiasi forma di: ricerca, ricerca, google, scopri, ricerca, quali sono le ultime novità, recupera questa pagina, analizza questo sito, controlla questo URL, estrai informazioni da, ricerca sul Web o qualsiasi attività in cui le informazioni Web correnti potrebbero migliorare la tua risposta. Anche se l'utente non ti chiede esplicitamente di effettuare una ricerca, se per rispondere correttamente sono necessarie informazioni attuali che non disponi, utilizza questa abilità. NON per l'automazione interattiva del browser come la compilazione di moduli o il clic (usa [[agent-browser]] o [[browser-use]]).
