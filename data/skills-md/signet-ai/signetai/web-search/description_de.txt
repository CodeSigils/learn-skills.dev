Durchsuchen Sie das Web und scrapen Sie Seiten mit dem lokalen Tool-Stack: SearXNG (Meta-Suche), Lightpanda (schneller Headless-Abruf) und Agent-Browser (vollständige Browser-Automatisierung). Dies ist Ihre STANDARD-Webkompetenz – verwenden Sie sie immer dann, wenn Sie etwas nachschlagen, ein Thema recherchieren, eine Webseite abrufen, Inhalte aus einer URL extrahieren, aktuelle Informationen überprüfen, Dokumentation finden, Wettbewerbsrecherchen durchführen oder Fragen beantworten müssen, die von Live-Webdaten profitieren. Wird bei jeder Form von Folgendem ausgelöst: Suchen, Nachschlagen, Googlen, Herausfinden, Recherchieren, Was ist das Neueste, Abrufen dieser Seite, Scrapen dieser Website, Überprüfen dieser URL, Abrufen von Informationen, Websuche oder jede andere Aufgabe, bei der aktuelle Webinformationen Ihre Antwort verbessern würden. Auch wenn der Benutzer Sie nicht ausdrücklich zur Suche auffordert – wenn für eine gute Antwort aktuelle Informationen erforderlich sind, die Sie nicht haben, nutzen Sie diese Fähigkeit. NICHT für interaktive Browser-Automatisierung wie das Ausfüllen oder Klicken von Formularen (verwenden Sie [[agent-browser]] oder [[browser-use]]).
