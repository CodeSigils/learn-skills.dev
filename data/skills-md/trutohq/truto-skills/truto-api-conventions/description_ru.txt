Соглашения Truto API — базовый URL-адрес (https://api.truto.one), аутентификация носителя, шаблоны унифицированных/прокси-адресов/пользовательских URL-адресов, нумерация страниц курсора, идемпотентность, синтаксис фильтра администратора и маршрутизация навыков между `truto` (код приложения) и `truto-cli` (терминал). Загружается при каждом вызове, настройке или обсуждении любой конечной точки api.truto.one.
