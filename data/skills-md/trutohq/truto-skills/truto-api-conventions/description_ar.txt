اصطلاحات واجهة برمجة التطبيقات Truto - عنوان URL الأساسي (https://api.truto.one)، ومصادقة الحامل، وأنماط عنوان URL الموحدة/الوكيل/المخصص، وترقيم الصفحات للمؤشر، والفاعلية، وبناء جملة مرشح المسؤول، وتوجيه المهارات بين `truto` (رمز التطبيق) و`truto-cli` (المحطة الطرفية). قم بالتحميل عند الاتصال بأي نقطة نهاية api.truto.one أو تكوينها أو التفكير فيها.
