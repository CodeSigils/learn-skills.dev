Analysez toute une application Web en cours d'exécution pour rechercher ce qui est défectueux, sans écrire de script ni connaître la base de code. Clique sur tous les contrôles accessibles et signale les boutons morts, les erreurs de console, les requêtes ayant échoué et les endroits où l'API et l'écran ne sont pas d'accord. À utiliser sur une base de code inconnue, avant une version, après une grosse fusion ou une dépendance, lorsque l'utilisateur demande un test de fumée ou un bilan de santé, ou lorsque quelqu'un dit "vérifiez simplement que tout fonctionne toujours".
