Busque en toda una aplicación web en ejecución lo que está roto, sin escribir un script ni conocer el código base. Hace clic en todos los controles accesibles e informa sobre botones inactivos, errores de consola, solicitudes fallidas y lugares donde la API y la pantalla no están de acuerdo. Úselo en una base de código desconocida, antes de un lanzamiento, después de una gran fusión o aumento de dependencia, cuando el usuario solicita una prueba de humo o una verificación de estado, o cuando alguien dice "simplemente verifique que todo siga funcionando".
