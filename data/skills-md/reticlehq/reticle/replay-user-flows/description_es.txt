Convierta el recorrido de un usuario en el que acaba de hacer clic en una verificación de regresión guardada que se vuelve a ejecutar de manera determinista, sin ningún modelo en el bucle y sin código de prueba que escribir. Úselo cuando haya impulsado el mismo flujo dos veces, cuando el usuario desee una cobertura de regresión sin una suite Playwright, cuando sea necesario probar una refactorización con cada recorrido existente o cuando volver a verificar manualmente cueste un viaje completo cada vez.
