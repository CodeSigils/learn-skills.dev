اكتشف سبب عدم عمل شيء ما في تطبيق ويب قيد التشغيل، عندما تكون وحدة التحكم فارغة ويبدو الرمز صحيحًا. يقرأ النقرة والطلب والمتجر ووحدة التحكم معًا ويعيد الملف: السطر لفتحه. يُستخدم عندما لا يفعل الزر شيئًا، أو لن يتم إرسال النموذج، أو لن يتم تحميل البيانات، أو تصبح الصفحة فارغة أو قديمة، أو لن يتم إغلاق المشروط، أو يقول المستخدم "إنها معطلة" وتشير مراجعة الكود إلى أنها جيدة.
