Découvrez pourquoi quelque chose dans une application Web en cours d'exécution ne fonctionne pas lorsque la console est vide et que le code semble correct. Lit le clic, la requête, le magasin et la console ensemble et renvoie le fichier : ligne à ouvrir. À utiliser lorsqu'un bouton ne fait rien, qu'un formulaire ne sera pas soumis, que les données ne se chargeront pas, qu'une page deviendra vierge ou obsolète, qu'un modal ne se fermera pas ou que l'utilisateur dit "c'est cassé" et que la révision du code indique que tout va bien.
