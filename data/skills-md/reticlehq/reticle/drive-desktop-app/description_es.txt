Conduzca y verifique una aplicación de escritorio Electron o Tauri desde adentro, incluido el proceso principal y las llamadas de Rust IPC que una herramienta de navegador no puede ver. Úselo cuando sea necesario probar una aplicación de escritorio, cuando una función funcione en el navegador pero no en la aplicación empaquetada, cuando sea necesario probar un IPC o una llamada de invocación, cuando se desee una captura de pantalla del escritorio o una diferenciación visual, o cuando necesite una ejecución sin cabeza de una interfaz de usuario de escritorio en CI.
