Pilotez et vérifiez une application de bureau Electron ou Tauri de l'intérieur, y compris le processus principal et les appels Rust IPC qu'un outil de navigateur ne peut pas voir. À utiliser lorsqu'une application de bureau doit être testée, lorsqu'une fonctionnalité fonctionne dans le navigateur mais pas dans l'application packagée, lorsqu'un appel IPC ou d'appel doit être prouvé, lorsqu'une capture d'écran du bureau ou une différence visuelle est souhaitée, ou lorsque vous avez besoin d'une exécution sans tête d'une interface utilisateur de bureau dans CI.
