Interaktive Sitzung zur Erstellung einer Systemaufforderung für einen KI-Agenten, der vom Sanity Context MCP-Server unterstützt wird. Verwenden Sie diese Fähigkeit, wenn Benutzer die Persönlichkeit des Agenten definieren, Ton/Stimme festlegen, Grenzen und Leitplanken festlegen, Ablehnungsverhalten konfigurieren oder steuern möchten, wie ihr Agent kommuniziert. Wird ausgelöst, wenn Benutzer erwähnen, dass ihr Agent falsch klingt, bestimmte Anfragen ablehnen muss, den falschen Ton hat oder Kommunikationsregeln und -richtlinien festlegen möchte.
