Создавайте агенты ИИ со структурированным доступом к контенту Sanity через Sanity Context. Используйте при настройке чат-бота на базе Sanity, подключении ИИ-помощника к контенту Sanity или добавлении клиентских инструментов к агенту. Охватывает настройку Studio, реализацию агента и расширенные шаблоны. Всегда используйте этот навык, когда пользователи упоминают о создании чат-бота с помощью Sanity, создании ИИ-помощника для своего контента, настройке сервера Sanity Context MCP, интеграции Sanity с Claude/GPT/любым LLM, обеспечении возможности поиска контента с помощью ИИ, реализации семантического поиска по данным Sanity или подключении своей CMS к агенту ИИ.
