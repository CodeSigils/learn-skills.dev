قم ببناء وكلاء الذكاء الاصطناعي مع وصول منظم إلى محتوى Sanity عبر Sanity context. يُستخدم عند إعداد chatbot مدعوم من Sanity، أو توصيل مساعد الذكاء الاصطناعي بمحتوى Sanity، أو إضافة أدوات من جانب العميل إلى الوكيل. يغطي إعداد الاستوديو وتنفيذ الوكيل والأنماط المتقدمة. استخدم هذه المهارة دائمًا عندما يذكر المستخدمون إنشاء روبوت دردشة باستخدام Sanity، أو إنشاء مساعد ذكاء اصطناعي للمحتوى الخاص بهم، أو إعداد خادم Sanity context MCP، أو دمج Sanity مع Claude/GPT/أي LLM، أو جعل المحتوى قابلاً للبحث بواسطة الذكاء الاصطناعي، أو تنفيذ البحث الدلالي عبر بيانات Sanity، أو ربط نظام إدارة المحتوى (CMS) الخاص بهم بوكيل الذكاء الاصطناعي.
