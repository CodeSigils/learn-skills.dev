Sanity Context 経由で Sanity コンテンツに構造的にアクセスできる AI エージェントを構築します。 Sanity を利用したチャットボットをセットアップする場合、AI アシスタントを Sanity コンテンツに接続する場合、またはクライアント側ツールをエージェントに追加する場合に使用します。 Studio のセットアップ、エージェントの実装、高度なパターンについて説明します。ユーザーが Sanity を使用したチャットボットの構築、コンテンツ用の AI アシスタントの作成、Sanity Context MCP サーバーのセットアップ、Sanity と Claude/GPT/任意の LLM の統合、AI によるコンテンツの検索可能化、Sanity データに対するセマンティック検索の実装、または CMS の AI エージェントへの接続について言及する場合は、必ずこのスキルを使用してください。
