Interaktive Sitzung zum Erstellen von Feldinhalten für Anweisungen für den Sanity Context MCP-Server. Verwenden Sie diese Fähigkeit immer dann, wenn Benutzer die Optimierung des Agentenkontexts, die Verbesserung der Agentenantworten auf Sanity-Daten, die Konfiguration von MCP-Anweisungen oder die Einrichtung von Inhaltsfiltern erwähnen oder wenn ihr Agent bei Sanity-Abfragen falsche Ergebnisse liefert. Wird auch ausgelöst, wenn Benutzer sagen, dass ihr Agent über Schemabeziehungen verwirrt ist, datenspezifische Anleitung benötigt oder optimieren möchte, auf welche Inhalte der Agent zugreifen kann.
