Session interactive pour créer le contenu du champ Instructions pour le serveur Sanity Context MCP. Utilisez cette compétence chaque fois que les utilisateurs mentionnent le réglage du contexte de l'agent, l'amélioration des réponses de l'agent aux données Sanity, la configuration des instructions MCP, la configuration des filtres de contenu ou lorsque leur agent donne des résultats erronés à partir des requêtes Sanity. Déclenchez également lorsque les utilisateurs disent que leur agent ne comprend pas les relations entre les schémas, a besoin de conseils spécifiques aux données ou souhaite optimiser le contenu auquel l'agent peut accéder.
