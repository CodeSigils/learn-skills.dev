Рендеринг и сериализация переносимого текста для React, Svelte, Vue, Astro, HTML, Markdown и обычного текста. Используйте при реализации рендеринга переносимого текста в любой внешней среде, создании пользовательских сериализаторов для нестандартных типов блоков, преобразовании переносимого текста в строки HTML на стороне сервера, преобразовании переносимого текста в Markdown, извлечении обычного текста из переносимого текста или устранении неполадок отрисовки с метками, блоками, списками или пользовательскими типами.
