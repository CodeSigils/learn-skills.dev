Convierta contenido HTML y Markdown en bloques de texto portátiles para Sanity. Úselo al migrar contenido de CMS heredados, importar HTML o Markdown a Sanity, crear canalizaciones de contenido que ingieran contenido externo, convertir texto enriquecido entre formatos o crear mediante programación documentos de texto portátiles. Cubre @portabletext/markdown (markdownToPortableText), @portabletext/block-tools (htmlToBlocks), deserializadores personalizados y la especificación Portable Text para la construcción manual de bloques.
