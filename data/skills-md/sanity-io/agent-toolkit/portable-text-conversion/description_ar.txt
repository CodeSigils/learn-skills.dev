قم بتحويل محتوى HTML وMarkdown إلى كتل نصية محمولة من أجل Sanity. يُستخدم عند ترحيل المحتوى من أنظمة إدارة المحتوى القديمة، أو استيراد HTML أو Markdown إلى Sanity، أو إنشاء مسارات محتوى تستوعب محتوى خارجي، أو تحويل نص منسق بين التنسيقات، أو إنشاء مستندات نصية محمولة برمجيًا. يغطي @portabletext/markdown (markdownToPortableText)، @portabletext/block-tools (htmlToBlocks)، وأدوات إلغاء التسلسل المخصصة، ومواصفات النص المحمول لإنشاء الكتل يدويًا.
