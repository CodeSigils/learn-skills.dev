HTML および Markdown コンテンツを Sanity 用のポータブル テキスト ブロックに変換します。従来の CMS からコンテンツを移行する場合、HTML または Markdown を Sanity にインポートする場合、外部コンテンツを取り込むコンテンツ パイプラインを構築する場合、形式間でリッチ テキストを変換する場合、またはプログラムでポータブル テキスト ドキュメントを作成する場合に使用します。 @portabletext/markdown (markdownToPortableText)、@portabletext/block-tools (htmlToBlocks)、カスタム デシリアライザー、および手動ブロック構築のための Portable Text 仕様について説明します。
