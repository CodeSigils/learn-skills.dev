Konvertieren Sie HTML- und Markdown-Inhalte in tragbare Textblöcke für Sanity. Verwenden Sie es, wenn Sie Inhalte aus älteren CMS migrieren, HTML oder Markdown in Sanity importieren, Content-Pipelines erstellen, die externe Inhalte aufnehmen, Rich Text zwischen Formaten konvertieren oder programmgesteuert tragbare Textdokumente erstellen. Behandelt @portabletext/markdown (markdownToPortableText), @portabletext/block-tools (htmlToBlocks), benutzerdefinierte Deserialisierer und die Portable Text-Spezifikation für die manuelle Blockkonstruktion.
