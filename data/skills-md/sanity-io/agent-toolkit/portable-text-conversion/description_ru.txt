Преобразуйте содержимое HTML и Markdown в блоки переносимого текста для Sanity. Используйте при переносе контента из устаревших CMS, импорте HTML или Markdown в Sanity, создании конвейеров контента, которые принимают внешний контент, преобразовании форматированного текста между форматами или программном создании переносимых текстовых документов. Охватывает @portabletext/markdown (markdownToPortableText), @portabletext/block-tools (htmlToBlocks), пользовательские десериализаторы и спецификацию Portable Text для создания блоков вручную.
