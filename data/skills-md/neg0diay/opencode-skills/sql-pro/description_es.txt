Optimiza consultas SQL, diseña esquemas de bases de datos y soluciona problemas de rendimiento. Úselo cuando un usuario pregunta por qué su consulta es lenta, necesita ayuda para escribir uniones o agregaciones complejas, menciona problemas de rendimiento de la base de datos o desea diseñar o migrar un esquema. Invocar para consultas complejas, funciones de ventana, CTE, estrategias de indexación, análisis de planes de consultas, creación de índices, consultas recursivas, interpretación de EXPLICAR/ANAlizar, evaluación comparativa de consultas antes/después o migración de consultas entre dialectos de bases de datos (PostgreSQL, MySQL, SQL Server, Oracle).
