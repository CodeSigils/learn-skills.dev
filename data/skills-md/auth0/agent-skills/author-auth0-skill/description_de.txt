Verwenden Sie diese beim Hinzufügen oder Bearbeiten der Auth0-Anleitung im einzelnen Auth0-Skill dieses Repos – einem neuen Framework, einer neuen Funktion, einem neuen Tool oder einer Musterreferenz –, um die Dateistruktur, die Router-Verkabelung und die Validierung gleich beim ersten Mal richtig hinzubekommen. Verwenden Sie dies auch dann, wenn die Anfrage nur „Referenz hinzufügen“ oder „Dokument X im Skill“ lautet, ohne den Router zu nennen.
