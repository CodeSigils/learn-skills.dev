Da utilizzare quando si aggiungono o si modificano le indicazioni Auth0 nella singola abilità auth0 di questo repository (un nuovo framework, funzionalità, strumento o riferimento a un modello) per ottenere la struttura del file, il cablaggio del router e la convalida correttamente la prima volta. Utilizzare anche se la richiesta dice semplicemente "aggiungi un riferimento" o "documento X nella competenza" senza nominare il router.
