Используйте при добавлении аутентификации Auth0 в мобильное приложение Flutter (iOS/Android) — интегрирует SDK auth0_flutter (собственная платформа) для входа/выхода из веб-аутентификации через системный браузер с безопасным хранением учетных данных и биометрической защитой через CredentialsManager.
