Verwenden Sie diese Option, wenn Sie (1) das universelle Login eines Auth0-Mandanten mit einem Branding versehen möchten, damit es mit einer Website oder Markenwerten (Farben, Logo, Schriftarten, Seitenlayout, Text) übereinstimmt; (2) einen oder mehrere Branding-Werte (Logos, Farben, Schriftarten, Rahmen, Hintergründe, Textzeichenfolgen oder die Seitenvorlage) ohne Extraktion manuell aktualisieren; (3) Anmeldetext so umschreiben, dass er zu Stimme und Ton passt; (4) Branding auf Auth0-Standardwerte zurücksetzen; oder (5) prüfen, ob ein Mandant so eingerichtet ist, dass das Branding durchgängig wirksam wird. Deckt nicht die erweiterten Anpassungen für Universal Login (ACUL) ab; Verwenden Sie dazu den Skill „Acul-Screen-Generator“.
