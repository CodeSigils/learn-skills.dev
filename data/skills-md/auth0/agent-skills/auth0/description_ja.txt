アプリによるユーザーの認証方法や API の保護方法を追加、修正、改善する場合、または Auth0 機能 (ユーザーのサインインとサインアウト、セッションとトークン、ルートとエンドポイントの保護、MFA、SSO、組織、RBAC、カスタム ドメイン、ホストされたアカウントと組織のセルフサービス用のユニバーサル ポータル、ユニバーサル ログインのブランディング) を使用または構成する場合に使用します。また、テナントの健全性、セキュリティ、プラン適合性の監査 (CheckMate)、認証フローが失敗する理由のデバッグ、別の認証プロバイダーからの移行、または Vercel ネイティブ統合のセットアップにも使用します。あらゆる Web、モバイル、バックエンド フレームワークと、あらゆる Auth0 SDK、ツール、API をカバーします。ユーザーが Auth0 について言及しない場合でも使用します。
