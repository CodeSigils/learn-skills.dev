يُستخدم عند إضافة أو إصلاح أو تحسين كيفية مصادقة التطبيق للمستخدمين أو حماية واجهة برمجة التطبيقات، أو عند استخدام أو تكوين أي ميزة Auth0 - تسجيل دخول المستخدمين وخروجهم، والجلسات والرموز المميزة، ومسارات الحماية ونقاط النهاية، وMFA، وSSO، والمؤسسات، وRBAC، والمجالات المخصصة، والبوابات العالمية للحساب المستضاف والخدمة الذاتية للمؤسسة، أو العلامة التجارية لتسجيل الدخول الشامل. استخدمه أيضًا لتدقيق صحة المستأجر وأمانه وملاءمة الخطة (CheckMate)، أو لتصحيح سبب فشل تدفق المصادقة، أو الترحيل من موفر مصادقة آخر، أو لإعداد تكامل Vercel الأصلي. يغطي أي إطار ويب أو جوال أو إطار عمل للواجهة الخلفية وكل Auth0 SDK والأداة وواجهة برمجة التطبيقات. استخدم حتى إذا لم يذكر المستخدم مطلقًا Auth0.
