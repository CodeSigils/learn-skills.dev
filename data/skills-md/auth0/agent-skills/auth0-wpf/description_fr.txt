À utiliser lors de l'ajout de l'authentification Auth0 aux applications de bureau WPF (Windows Présentation Foundation) : intègre le package Auth0.OidcClient.WPF NuGet pour la connexion native, la déconnexion, l'actualisation des jetons et le profil utilisateur.
