À utiliser lors de l'ajout de l'authentification Auth0 aux applications de bureau Windows Forms (WinForms) : intègre le package NuGet Auth0.OidcClient.WinForms pour la connexion native, la déconnexion, l'actualisation du jeton et le profil utilisateur. Déclenchez l'authentification WinForms, ajoutez une connexion à WinForms, Auth0 WinForms, authentification .NET Windows Forms, authentification du bureau Windows
