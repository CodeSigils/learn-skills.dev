À utiliser lors de l'ajout d'une authentification aux applications mobiles Expo (React Native) : connexion, déconnexion, sessions utilisateur, itinéraires protégés, biométrie ou gestion des jetons. Intègre le SDK React-native-auth0 avec le plug-in Expo Config pour les versions natives iOS/Android. Déclencheur pour tout projet Expo nécessitant Auth0, y compris la configuration du plugin app.json, la configuration d'un schéma personnalisé ou la gestion des informations d'identification. Ne pas utiliser pour les projets React Native CLI nus (utilisez auth0-react-native), les applications Web React (utilisez auth0-react), Next.js (utilisez auth0-nextjs) ou les API backend.
