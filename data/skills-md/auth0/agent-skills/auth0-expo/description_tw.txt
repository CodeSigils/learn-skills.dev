在 Expo (React Native) 行動應用程式中新增身分驗證時使用 - 登入、登出、使用者工作階段、受保護的路由、生物辨識或令牌管理。將react-native-auth0 SDK 與Expo Config Plugin 集成，用於本機iOS/Android 建置。觸發任何需要 Auth0 的 Expo 項目，包括 app.json 外掛程式配置、自訂方案設定或憑證管理。請勿用於裸 React Native CLI 專案（使用 auth0-react-native）、React Web 應用程式（使用 auth0-react）、Next.js（使用 auth0-nextjs）或後端 API。
