在向 Expo (React Native) 移动应用程序添加身份验证时使用 - 登录、注销、用户会话、受保护的路由、生物识别或令牌管理。将react-native-auth0 SDK 与Expo Config Plugin 集成，用于本机iOS/Android 构建。触发任何需要 Auth0 的 Expo 项目，包括 app.json 插件配置、自定义方案设置或凭证管理。请勿用于裸 React Native CLI 项目（使用 auth0-react-native）、React Web 应用程序（使用 auth0-react）、Next.js（使用 auth0-nextjs）或后端 API。
