يُستخدم عند إضافة المصادقة إلى تطبيقات الهاتف المحمول Expo (React Native) - تسجيل الدخول أو تسجيل الخروج أو جلسات المستخدم أو المسارات المحمية أو القياسات الحيوية أو إدارة الرمز المميز. يدمج حزمة SDK الخاصة بـ React-Native-auth0 مع البرنامج الإضافي Expo Config لإصدارات iOS/Android الأصلية. قم بتشغيل أي مشروع Expo يحتاج إلى Auth0، بما في ذلك تكوين المكون الإضافي app.json أو إعداد المخطط المخصص أو إدارة بيانات الاعتماد. لا تستخدم مشاريع React Native CLI العارية (استخدم auth0-react-native)، أو تطبيقات الويب React (استخدم auth0-react)، أو Next.js (استخدم auth0-nextjs)، أو واجهات برمجة التطبيقات الخلفية.
