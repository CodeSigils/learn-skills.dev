Wird beim Hinzufügen der Authentifizierung zu mobilen Expo-Apps (React Native) verwendet – Anmeldung, Abmeldung, Benutzersitzungen, geschützte Routen, Biometrie oder Token-Verwaltung. Integriert das React-Native-Auth0 SDK mit dem Expo Config Plugin für native iOS/Android-Builds. Auslöser für jedes Expo-Projekt, das Auth0 benötigt, einschließlich der app.json-Plugin-Konfiguration, der Einrichtung eines benutzerdefinierten Schemas oder der Verwaltung von Anmeldeinformationen. NICHT für reine React Native CLI-Projekte (verwenden Sie auth0-react-native), React-Webanwendungen (verwenden Sie auth0-react), Next.js (verwenden Sie auth0-nextjs) oder Backend-APIs verwenden.
