Da utilizzare quando si aggiunge l'autenticazione alle app mobili Expo (React Native): accesso, disconnessione, sessioni utente, percorsi protetti, dati biometrici o gestione dei token. Integra l'SDK react-native-auth0 con il plug-in Expo Config per build iOS/Android native. Attiva qualsiasi progetto Expo che richiede Auth0, inclusa la configurazione del plug-in app.json, l'impostazione di schemi personalizzati o la gestione delle credenziali. NON utilizzare per progetti CLI React Native semplici (utilizzare auth0-react-native), app Web React (utilizzare auth0-react), Next.js (utilizzare auth0-nextjs) o API backend.
