Expo (React Native) モバイル アプリに認証 (ログイン、ログアウト、ユーザー セッション、保護されたルート、生体認証、トークン管理) を追加するときに使用します。ネイティブ iOS/Android ビルド用に、react-native-auth0 SDK を Expo Config プラグインと統合します。 app.json プラグイン構成、カスタム スキームのセットアップ、資格情報の管理など、Auth0 を必要とする Expo プロジェクトのトリガー。ベア React Native CLI プロジェクト (auth0-react-native を使用)、React Web アプリ (auth0-react を使用)、Next.js (auth0-nextjs を使用)、またはバックエンド API には使用しないでください。
