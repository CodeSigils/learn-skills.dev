Используйте при добавлении аутентификации в мобильные приложения Expo (React Native) — вход в систему, выход из системы, пользовательские сеансы, защищенные маршруты, биометрия или управление токенами. Интегрирует SDK реакции-native-auth0 с плагином Expo Config для собственных сборок iOS/Android. Триггер для любого проекта Expo, требующего Auth0, включая конфигурацию плагина app.json, настройку пользовательской схемы или управление учетными данными. НЕ используйте для голых проектов React Native CLI (используйте auth0-react-native), веб-приложений React (используйте auth0-react), Next.js (используйте auth0-nextjs) или серверных API.
