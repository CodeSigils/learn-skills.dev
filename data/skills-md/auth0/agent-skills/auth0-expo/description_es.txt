Úselo al agregar autenticación a las aplicaciones móviles Expo (React Native): inicio de sesión, cierre de sesión, sesiones de usuario, rutas protegidas, datos biométricos o administración de tokens. Integra el SDK react-native-auth0 con el complemento Expo Config para compilaciones nativas de iOS/Android. Activador para cualquier proyecto de Expo que necesite Auth0, incluida la configuración del complemento app.json, la configuración de esquema personalizado o la administración de credenciales. NO lo use para proyectos CLI nativos de React (use auth0-react-native), aplicaciones web de React (use auth0-react), Next.js (use auth0-nextjs) o API de backend.
