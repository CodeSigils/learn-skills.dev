À utiliser lors de la sécurisation des points de terminaison de l'API Web ASP.NET Core avec la validation du jeton JWT Bearer, les contrôles de portée/autorisation ou l'authentification sans état - intègre Auth0.AspNetCore.Authentication.Api pour les API REST recevant des jetons d'accès à partir d'interfaces ou d'applications mobiles. Gère également la liaison du jeton de preuve de possession DPoP. Déclencheurs sur : AddAuth0ApiAuthentication, authentification de l'API Web .NET, validation JWT, UseAuthentication, UseAuthorization.
