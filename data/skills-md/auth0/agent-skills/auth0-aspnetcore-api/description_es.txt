Úselo al proteger los puntos finales de ASP.NET Core Web API con validación de token de portador JWT, comprobaciones de alcance/permisos o autenticación sin estado: integra Auth0.AspNetCore.Authentication.Api para API REST que reciben tokens de acceso desde interfaces o aplicaciones móviles. También maneja la vinculación de tokens de prueba de posesión DPoP. Activadores de: AddAuth0ApiAuthentication, autenticación de API web .NET, validación JWT, UseAuthentication, UseAuthorization.
