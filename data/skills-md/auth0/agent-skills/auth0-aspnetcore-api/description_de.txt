Wird zum Sichern von ASP.NET Core-Web-API-Endpunkten mit JWT-Bearer-Token-Validierung, Bereichs-/Berechtigungsprüfungen oder zustandsloser Authentifizierung verwendet – integriert Auth0.AspNetCore.Authentication.Api für REST-APIs, die Zugriffstoken von Frontends oder mobilen Apps empfangen. Verarbeitet außerdem die DPoP-Besitznachweis-Tokenbindung. Auslöser bei: AddAuth0ApiAuthentication, .NET Web API-Authentifizierung, JWT-Validierung, UseAuthentication, UseAuthorization.
