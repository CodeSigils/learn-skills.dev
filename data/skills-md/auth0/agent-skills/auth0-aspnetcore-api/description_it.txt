Da usare per proteggere gli endpoint API Web ASP.NET Core con la convalida del token Bearer JWT, i controlli di ambito/autorizzazione o l'autenticazione senza stato: integra Auth0.AspNetCore.Authentication.Api per le API REST che ricevono token di accesso da frontend o app per dispositivi mobili. Gestisce anche l'associazione dei token di prova di possesso DPoP. Si attiva su: AddAuth0ApiAuthentication, autenticazione API Web .NET, convalida JWT, UseAuthentication, UseAuthorization.
