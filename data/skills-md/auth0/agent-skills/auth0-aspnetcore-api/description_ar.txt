يُستخدم عند تأمين نقاط نهاية ASP.NET Core Web API من خلال التحقق من صحة الرمز المميز لـ JWT Bearer، أو فحوصات النطاق/الإذن، أو المصادقة عديمة الحالة - يدمج Auth0.AspNetCore.Authentication.Api لواجهات REST API التي تتلقى رموز الوصول من الواجهات الأمامية أو تطبيقات الهاتف المحمول. يتعامل أيضًا مع ربط الرمز المميز لإثبات الحيازة DPoP. المشغلات على: AddAuth0ApiAuthentication، ومصادقة .NET Web API، والتحقق من صحة JWT، وUseAuthentication، وUseAuthorization.
