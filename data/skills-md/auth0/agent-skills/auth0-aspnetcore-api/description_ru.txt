Используйте при защите конечных точек веб-API ASP.NET Core с помощью проверки токена носителя JWT, проверки области/разрешений или проверки подлинности без отслеживания состояния — интегрирует Auth0.AspNetCore.Authentication.Api для REST API, получающих токены доступа от интерфейсов или мобильных приложений. Также обрабатывает привязку токена подтверждения владения DPoP. Срабатывает при: AddAuth0ApiAuthentication, аутентификации веб-API .NET, проверке JWT, UseAuthentication, UseAuthorization.
