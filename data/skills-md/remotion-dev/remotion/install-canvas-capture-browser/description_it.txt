Installa e verifica la build Chrome for Testing bloccata utilizzata dall'estensione privata Remotion Canvas Capture su Apple Silicon macOS. Da utilizzare durante la configurazione di Canvas Capture, quando Recorder Chrome è mancante o ha la versione sbagliata oppure quando il programma di installazione dell'estensione canvas-capture segnala che Chrome for Testing 150.0.7842.0 (r1631007) non è disponibile.
