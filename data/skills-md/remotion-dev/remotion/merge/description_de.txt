Warten Sie, bis eine Remotion-Pull-Anfrage zusammenführbar ist, behandeln Sie Zusammenführungskonflikte, unterscheiden Sie echte CI-Fehler von Flakes, führen Sie Flaky-Prüfungen durch den Flake-Skill erneut durch und führen Sie die PR zusammen. Verwenden Sie diese Option, wenn Sie aufgefordert werden, /merge auszuführen, einen aktuellen PR zusammenzuführen, nachdem die Prüfungen bestanden wurden, oder einen Remotion-PR zur Zusammenführung über CI zu leiten.
