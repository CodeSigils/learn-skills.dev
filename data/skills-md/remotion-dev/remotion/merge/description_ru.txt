Подождите, пока запрос на включение Remotion станет доступным для слияния, обработайте конфликты слияния, отличите подлинные сбои CI от нештатных, повторно запустите ненадежные проверки с помощью навыка ненадежных и объедините PR. Используйте, когда вас попросят запустить команду /merge, объединить текущий PR после прохождения проверок или передать запрос Remotion PR через CI для слияния.
