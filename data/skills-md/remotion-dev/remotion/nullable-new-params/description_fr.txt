Corrigez les paramètres facultatifs nouvellement ajoutés, les accessoires React facultatifs et les membres de type/interface facultatifs dans les différences monorepo Remotion en convertissant les API internes en valeurs nullables requises et en mettant à jour les sites d'appel. À utiliser lorsqu'un PR, une révision ou un utilisateur demande d'interdire les nouveaux ajouts `foo?: T` / `param?: T`, sauf pour les API publiques exportées ou documentées où exiger la valeur serait une rupture.
