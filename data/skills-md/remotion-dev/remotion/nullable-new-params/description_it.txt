Correggi i parametri facoltativi appena aggiunti, le proprietà React facoltative e i membri di tipo/interfaccia facoltativi nelle differenze monorepo di Remotion convertendo le API interne in valori nullable richiesti e aggiornando i siti di chiamata. Da utilizzare quando un PR, una recensione o un utente chiede di vietare nuove aggiunte di `foo?: T` / `param?: T` ad eccezione delle API pubbliche esportate o documentate in cui richiedere il valore sarebbe dannoso.
