Classificare e collegare le opzioni di configurazione di Remotion Studio come fisse all'avvio o ricaricabili, prevenendo al contempo comportamenti misti del ciclo di vita tra i consumatori. Da utilizzare quando si aggiunge, si modifica o si rivede un setter di configurazione o un'opzione CLI utilizzata da Studio, dal server di anteprima, dal compilatore, dal bootstrap HTML, dal watcher delle cartelle pubbliche o dalla coda di rendering.
