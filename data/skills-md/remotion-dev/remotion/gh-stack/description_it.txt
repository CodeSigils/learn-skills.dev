Gestisci rami in pila e richieste pull con l'estensione CLI GitHub gh-stack. Da utilizzare quando l'utente desidera creare, inviare, rebase, sincronizzare, navigare o visualizzare stack di PR dipendenti. Trigger su attività che coinvolgono differenze in pila, richieste pull dipendenti, catene di filiali o flussi di lavoro di revisione del codice incrementale.
