Linee guida per le modifiche dell'interfaccia utente di Remotion Studio in cui il ripristino CSS globale influisce sugli elementi nidificati. Da utilizzare durante la modifica di pacchetti/interfaccia utente di Studio, in particolare quando si aggiungono estensioni di wrapper, icone in linea, etichette, pulsanti, righe compatte o qualsiasi testo nidificato la cui tipografia, colore, ridimensionamento o troncamento deve rimanere stabile.
