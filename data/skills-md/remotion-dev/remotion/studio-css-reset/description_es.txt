Guía para cambios en la interfaz de usuario de Remotion Studio donde el restablecimiento global de CSS afecta a los elementos anidados. Úselo al editar paquetes/IU de estudio, especialmente al agregar espacios contenedores, íconos en línea, etiquetas, botones, filas compactas o cualquier texto anidado cuya tipografía, color, tamaño o truncamiento deban permanecer estables.
