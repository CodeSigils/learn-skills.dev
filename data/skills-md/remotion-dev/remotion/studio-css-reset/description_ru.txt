Руководство по изменениям пользовательского интерфейса Remotion Studio, когда глобальный сброс CSS влияет на вложенные элементы. Используйте при редактировании пользовательского интерфейса пакетов/студии, особенно при добавлении интервалов-оболочек, встроенных значков, меток, кнопок, компактных строк или любого вложенного текста, типографика, цвет, размер или усечение которого должны оставаться стабильными.
