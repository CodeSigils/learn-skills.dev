Anleitung für Änderungen an der Remotion Studio-Benutzeroberfläche, bei denen sich das globale CSS-Reset auf verschachtelte Elemente auswirkt. Verwenden Sie diese Option beim Bearbeiten von Paketen/Studio-Benutzeroberflächen, insbesondere beim Hinzufügen von Wrapper-Bereichen, Inline-Symbolen, Beschriftungen, Schaltflächen, kompakten Zeilen oder verschachteltem Text, dessen Typografie, Farbe, Größe oder Kürzung stabil bleiben müssen.
