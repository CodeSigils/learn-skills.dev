Téléchargez de grandes ressources du référentiel Remotion dans le compartiment Cloudflare R2 derrière remotion.media et remplacez les ressources publiques/locales par des URL hébergées. À utiliser lorsqu'un fichier est trop volumineux pour Git ou lorsqu'un PR doit éviter de valider des binaires multimédias en les hébergeant sur remotion.media.
