Laden Sie große Remotion-Repository-Assets in den Cloudflare R2-Bucket hinter remotion.media hoch und ersetzen Sie lokale öffentliche/Assets durch gehostete URLs. Verwenden Sie diese Option, wenn eine Datei zu groß für Git ist oder wenn ein PR das Festschreiben von Medienbinärdateien vermeiden sollte, indem er diese auf remotion.media hostet.
