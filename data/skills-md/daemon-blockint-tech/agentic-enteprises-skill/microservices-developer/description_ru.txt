компромисс между синхронизацией и асинхронностью, устойчивость (тайм-ауты, повторные попытки, автоматические выключатели, перегородки), для каждой службы
владение данными, шаблоны саг и исходящих сообщений, двенадцатифакторные контейнеры, наблюдаемость (журналы, метрики,
распространение трассировки), управление версиями API на шлюзах/сетях и тестирование контрактов.
Использование для разработчика микросервисов, граница сервиса, ограниченный контекст, gRPC между сервисами, схема.
