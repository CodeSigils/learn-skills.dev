Guía el diseño y la entrega de microservicios: contextos acotados, límites de servicios, REST/gRPC/API de eventos,
Compensaciones entre sincronización y asíncrono, resiliencia (tiempos de espera, reintentos, disyuntores, mamparos), por servicio
propiedad de datos, patrones de saga y bandeja de salida, contenedores de doce factores, observabilidad (registros, métricas,
propagación de seguimiento), control de versiones de API en puertas de enlace/mallas y pruebas de contratos.
Uso para desarrolladores de microservicios, límites de servicios, contexto acotado, gRPC entre servicios, circuitos
interruptor, patrón de saga, patrón de bandeja de salida, doce factores, microservicios de prueba de contrato, servicio
descomposición o microservicio impulsado por eventos, no operaciones de plataforma K8 (ingeniero de plataforma,
ingeniero de confiabilidad del sitio), iPaaS empresarial (desarrollador de API de integración empresarial), monolito primero
aplicaciones (ingeniero-de-software-senior) o canalizaciones clasificadas (ingeniero-devsecops-de-software-clasificado).
