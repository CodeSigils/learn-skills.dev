يرشد تحليل عقارات الخدمات الصغيرة الموجودة - مخزون الخدمة وواجهة برمجة التطبيقات (API)، والتبعية و
خرائط الاقتران (سلاسل المزامنة، وروائح قاعدة البيانات المشتركة)، وإمكانية الملاحظة وفجوات تغطية SLO،
انحراف النشر والإصدار، وانجراف عقد API وكسر المستهلكين، والكدح التشغيلي
المؤشرات، ونصف قطر الانفجار الأمني، وتوصيات الدمج أو التحلل
الأدلة. يُنتج ملخصات تنفيذية لجماهير المنصات وSRE والمهندسين المعماريين. استخدم متى
يقول المستخدم محلل الخدمات الصغيرة، ويحلل الخدمات الصغيرة، وخريطة تبعية الخدمة، والاقتران
التحليل، صحة الخدمات الصغيرة، انجراف واجهة برمجة التطبيقات (API)، مخزون الخدمة، نصف قطر الانفجار، التحليل التشغيلي،
تغطية SLO، والخدمات الفنية الدقيقة للديون، والتقييم الخانق - وليس أبحاث الحدود الجديدة
فقط (باحث خدمات صغيرة)، كتابة خدمات جديدة (مهندس برمجيات أول)، Kubernetes فقط
الضبط (مهندس السحابة)، أو اختبار الحمل النقي (مهندس الأداء).
