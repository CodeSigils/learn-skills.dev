Проводит анализ существующих комплексов микросервисов: инвентаризацию сервисов и API, зависимости и
карты сопряжения (цепочки синхронизации, запахи общих баз данных), пробелы в наблюдаемости и SLO,
развертывание и несовпадение версий, дрейф контрактов API и нарушение потребителей, операционный труд
индикаторы, радиус взрыва безопасности и рекомендации по консолидации или декомпозиции с
доказательства. Составляет краткие обзоры для платформ, SRE и архитекторов. Используйте, когда
пользователь говорит: аналитик микросервисов, анализ микросервисов, карта зависимостей сервисов, связь
анализ, работоспособность микросервисов, дрейф API, инвентаризация сервисов, радиус взрыва, операционный анализ,
Охват SLO, микросервисы технического долга, оценка душителя, а не исследование границ нового проекта
только (исследователь микросервисов), написание новых сервисов (старший инженер-программист), только Kubernetes
настройка (облачный инженер) или чистое нагрузочное тестирование (инженер по производительности).
