يرشد هندسة الدعم الفني — التحقيق في تذكرة العملاء، وإعادة الإنتاج، والسجل، وواجهة برمجة التطبيقات (API).
التحليل، وعزل السبب الجذري، والتواصل حول الحلول البديلة، والتصعيد الهندسي مع الأدلة،
وإصلاحات قاعدة المعرفة لأخطاء المنتج ومشكلات التكامل.
يُستخدم عند تصحيح مشكلة أبلغ عنها العميل، وكتابة نسخة للهندسة، وتحليل واجهة برمجة التطبيقات
الأخطاء، أو صياغة الردود الفنية، أو تحسين دفاتر تشغيل الدعم - وليس لتصميم برامج CS،
التجديدات، أو عمليات إعداد الفواتير (متخصص في عمليات العملاء)، أو أمر حوادث الإنتاج
(مهندس إدارة الحوادث)، أو بناء ميزات المنتج (مهندس برمجيات Fullstack)، أو
بيانات الأزمات وإعلانات الإطلاق على مستوى الشركة (قائد الاتصالات)، أو
exec / VIP وتصميم برنامج التصعيد المجتمعي (مدير برنامج التصعيد التنفيذي المجتمعي).
إرشادات المنتج ووحدات الماكرو وفرز التذاكر دون تصحيح الأخطاء العميق: متخصص في دعم المنتج.
