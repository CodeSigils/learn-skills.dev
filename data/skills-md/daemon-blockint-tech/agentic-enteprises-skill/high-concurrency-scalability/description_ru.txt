Проектируйте и оптимизируйте системы для обеспечения высокого уровня параллелизма, пропускной способности, масштабируемости и эластичного масштабирования: модели параллелизма (потоки, асинхронность/ожидание, актеры), шаблоны без блокировок, пулы соединений, устранение проблем с кэшированием, горизонтальное масштабирование, балансировка нагрузки, противодавление, организация очередей, ограничение скорости, перегородки, реплики чтения, сегментирование, настройка пула, профилирование, планирование мощности, автоматическое масштабирование на основе SLO, многорегиональное и Граничная архитектура CDN. Используйте, когда пользователь спрашивает о высоком уровне параллелизма, масштабируемости, пропускной способности, горизонтальном масштабировании, пуле соединений, противодавлении, ограничении скорости, спаде кэширования, реплике чтения, сегментировании, автомасштабировании, планировании мощности, конкуренции блокировок, асинхронной масштабируемости или балансировке нагрузки — не декомпозиция службы (разработчик микросервисов), только шины событий (архитектура, управляемая событиями), общий CRUD (старший инженер программного обеспечения), только SRE по вызову (инженер по надежности объекта), нагрузочные тесты без архитектуры (инженер по производительности) или FinOps с оплатой только затрат (экономист по облачным технологиям).
