تصميم وتحسين الأنظمة للتزامن العالي، والإنتاجية، وقابلية التوسع، والمقياس المرن - نماذج التزامن (السلاسل، غير المتزامن/الانتظار، الممثلين)، الأنماط الخالية من القفل، تجميع الاتصال، تخفيف التدافع في التخزين المؤقت، القياس الأفقي، موازنة التحميل، الضغط الخلفي، قائمة الانتظار، تحديد المعدل، الحواجز، قراءة النسخ المتماثلة، المشاركة، ضبط التجمع، التنميط، تخطيط السعة، القياس التلقائي القائم على SLO، بنية متعددة المناطق و CDN edge. يُستخدم عندما يسأل المستخدم عن التزامن العالي، أو قابلية التوسع، أو الإنتاجية، أو القياس الأفقي، أو تجميع الاتصال، أو الضغط الخلفي، أو تحديد المعدل، أو التخزين المؤقت للتدافع، أو قراءة النسخة المتماثلة، أو التقسيم، أو القياس التلقائي، أو تخطيط السعة، أو تنافس القفل، أو قابلية التوسع غير المتزامنة، أو موازنة التحميل - وليس تحليل الخدمة (مطور الخدمات الصغيرة)، أو ناقلات الأحداث فقط (الهندسة المستندة إلى الحدث)، أو CRUD العام (مهندس برمجيات أول)، أو SRE عند الطلب فقط (مهندس موثوقية الموقع)، أو اختبارات التحميل بدون بنية (مهندس أداء)، أو FinOps بالتكلفة فقط (خبير اقتصادي في السحابة).
