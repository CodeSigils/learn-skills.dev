Guida lo sviluppo di applicazioni Web: prodotti basati su browser che comprendono interfaccia utente, API HTTP, sessioni e
cookie, routing (SPA e SSR), moduli, caricamento di file e sicurezza specifica del Web (CSRF, CORS, CSP,
Prevenzione XSS) su stack come React/Next.js, Vue o simili con backend Node/Python/Ruby.
Da utilizzare durante la creazione o la manutenzione di un'app Web, l'implementazione di flussi di accesso, rendering su server o ibridi
pagine, consumo REST/GraphQL o debug di problemi browser-server, non per app native per dispositivi mobili,
Strumenti CLI o pipeline di dati. Per la distribuzione di funzionalità full-stack generiche utilizzare fullstack-software-engineer;
per il lavoro solo front-end utilizzare senior-frontend-software-engineer; per la distribuzione/CI utilizzare devops.
Per l'implementazione dell'interfaccia utente dalla progettazione al codice (token, stati, Storybook) senza focus autenticazione/CORS, utilizzare
ui-software-ingegnere.
