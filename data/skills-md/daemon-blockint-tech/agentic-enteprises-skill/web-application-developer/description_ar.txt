يرشد تطوير تطبيقات الويب — المنتجات المستندة إلى المستعرض والتي تشمل واجهة المستخدم وواجهات برمجة تطبيقات HTTP والجلسات و
ملفات تعريف الارتباط، والتوجيه (SPA وSSR)، والنماذج، وتحميل الملفات، والأمان الخاص بالويب (CSRF، CORS، CSP،
منع XSS) على مكدسات مثل React/Next.js أو Vue أو ما شابه ذلك مع الواجهات الخلفية لـ Node/Python/Ruby.
يُستخدم عند إنشاء تطبيق ويب أو صيانته، أو تنفيذ تدفقات تسجيل الدخول، أو المقدمة من الخادم أو المختلطة
الصفحات، أو استهلاك REST/GraphQL، أو تصحيح مشكلات المتصفح والخادم - وليس لتطبيقات الأجهزة المحمولة الأصلية،
أدوات CLI، أو خطوط أنابيب البيانات. للحصول على ميزة عامة متكاملة، استخدم fullstack-software-engineer؛
بالنسبة لعمل الواجهة الأمامية فقط، استخدم مهندس برمجيات الواجهة الأمامية؛ للنشر/استخدام CI devops.
لتنفيذ واجهة المستخدم من التصميم إلى التعليمات البرمجية (الرموز المميزة والحالات والقصص المصورة) دون التركيز على المصادقة/CORS، استخدم
مهندس واجهة المستخدم.
