Руководит разработкой веб-приложений — продуктов на основе браузера, включающих пользовательский интерфейс, HTTP API, сеансы и
файлы cookie, маршрутизация (SPA и SSR), формы, загрузка файлов и веб-безопасность (CSRF, CORS, CSP,
предотвращение XSS) в таких стеках, как React/Next.js, Vue или аналогичных с бэкэндами Node/Python/Ruby.
Используйте при создании или обслуживании веб-приложения, реализации потоков входа в систему, серверной визуализации или гибридной версии.
страниц, использование REST/GraphQL или отладка проблем браузера и сервера — не для мобильных приложений,
Инструменты CLI или конвейеры данных. Для реализации универсального полного стека функций используйте fullstack-software-engineer;
для работы только с интерфейсом используйте старшего инженера-разработчика программного обеспечения; для развертывания/CI используйте Devops.
Для реализации пользовательского интерфейса от дизайна к коду (токены, состояния, Storybook) без фокуса аутентификации/CORS используйте
ui-инженер-программист.
