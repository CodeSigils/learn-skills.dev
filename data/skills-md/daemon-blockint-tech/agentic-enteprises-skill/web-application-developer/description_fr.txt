Guide le développement d'applications Web : produits basés sur un navigateur couvrant l'interface utilisateur, les API HTTP, les sessions et
cookies, routage (SPA et SSR), formulaires, téléchargements de fichiers et sécurité spécifique au Web (CSRF, CORS, CSP,
Prévention XSS) sur des piles telles que React/Next.js, Vue ou similaire avec les backends Node/Python/Ruby.
À utiliser lors de la création ou de la maintenance d'une application Web, de la mise en œuvre de flux de connexion, rendus par le serveur ou hybrides
pages, consommation REST/GraphQL ou problèmes de débogage navigateur-serveur – pas pour les applications mobiles natives,
Outils CLI ou pipelines de données. Pour la fourniture de fonctionnalités génériques full-stack, utilisez fullstack-software-engineer ;
pour le travail front-end uniquement, utilisez senior-frontend-software-engineer ; pour le déploiement/CI, utilisez devops.
Pour l’implémentation de l’interface utilisateur de conception à code (jetons, états, Storybook) sans focus auth/CORS, utilisez
ingénieur logiciel ui.
