Guía el desarrollo de aplicaciones web: productos basados en navegador que abarcan UI, API HTTP, sesiones y
cookies, enrutamiento (SPA y SSR), formularios, carga de archivos y seguridad específica de la web (CSRF, CORS, CSP,
Prevención XSS) en pilas como React/Next.js, Vue o similares con backends Node/Python/Ruby.
Úselo al crear o mantener una aplicación web, implementar flujos de inicio de sesión, renderizados por servidor o híbridos.
páginas, consumo de REST/GraphQL o depuración de problemas entre el navegador y el servidor, no para aplicaciones nativas móviles,
Herramientas CLI o canalizaciones de datos. Para la entrega genérica de funciones de pila completa, utilice fullstack-software-engineer;
para trabajos de front-end únicamente, utilice senior-frontend-software-engineer; para implementación/uso de CI devops.
Para la implementación de la interfaz de usuario de diseño a código (tokens, estados, Storybook) sin enfoque de autenticación/CORS, utilice
ingeniero de software de interfaz de usuario.
