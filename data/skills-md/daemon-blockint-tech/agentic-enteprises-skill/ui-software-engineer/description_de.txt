Leitet das UI-Software-Engineering an – Implementierung von Bildschirmen und Komponenten aus Design-Spezifikationen, Design-Tokens,
Responsives Layout, Interaktionszustände, Formulare und API-Grenzen-Lade-/Fehler-Benutzeroberfläche in React/Next.js oder
ähnliche Stapel. Behandelt die Nutzung der Komponentenbibliothek, die grundlegende WCAG-Implementierung und die visuelle Qualitätssicherung – nicht für
Senior-Frontend-Architektur oder Core Web Vitals-Programme (Senior-Frontend-Software-Ingenieur),
Web-Authentifizierung/CORS/Sitzungssicherheit (Web-Anwendungsentwickler), UX-Erkennung ohne Code
(Produktdesigner), Interaktionsspezifikationen und codierte Prototypen (UX-Software-Ingenieur) oder Backend
APIs und Schemata (Fullstack-Software-Ingenieur).
