Руководства по разработке программного обеспечения пользовательского интерфейса — реализация экранов и компонентов из спецификаций дизайна, токенов дизайна,
адаптивный макет, состояния взаимодействия, формы и пользовательский интерфейс загрузки/ошибок API в React/Next.js или
подобные стопки. Охватывает использование библиотеки компонентов, базовую реализацию WCAG и визуальный контроль качества — не для
старший интерфейсный разработчик архитектуры или программы Core Web Vitals (старший интерфейсный инженер-программист),
веб-аутентификация/CORS/сеансовая безопасность (разработчик веб-приложений), обнаружение UX без кода
(дизайнер продукта), спецификации взаимодействия и закодированные прототипы (инженер программного обеспечения) или бэкэнд
API и схемы (инженер-программист полного стека).
