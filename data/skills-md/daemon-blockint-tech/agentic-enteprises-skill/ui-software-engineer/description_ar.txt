يرشد هندسة برمجيات واجهة المستخدم - تنفيذ الشاشات والمكونات من مواصفات التصميم، ورموز التصميم،
التخطيط المستجيب وحالات التفاعل والنماذج وواجهة مستخدم التحميل/الخطأ لحدود واجهة برمجة التطبيقات في React/Next.js أو
أكوام مماثلة. يغطي استخدام مكتبة المكونات، وتنفيذ WCAG الأساسي، وضمان الجودة المرئي - وليس لـ
كبير مهندسي الواجهة الأمامية أو برامج Core Web Vitals (مهندس برمجيات الواجهة الأمامية الأول)،
مصادقة الويب/CORS/أمان الجلسة (مطور تطبيقات الويب)، اكتشاف تجربة المستخدم بدون تعليمات برمجية
(مصمم المنتج)، ومواصفات التفاعل والنماذج الأولية المشفرة (مهندس برمجيات ux)، أو الواجهة الخلفية
واجهات برمجة التطبيقات والمخططات (مهندس برمجيات Fullstack).
