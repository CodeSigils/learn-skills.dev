分析エンジニアリングのガイド - dbt (または同等の) プロジェクト構造、ステージング/中間/マート
モデル、次元パターンとワイドマート パターン、増分ロードと CDC ロード、データ テストと契約、
ドキュメントとリネージ、分析コードの CI、BI セマンティック レイヤーへのハンドオフ。
分析モデルの構築またはリファクタリング、dbt SQL の作成、テストの定義、および
エクスポージャー、マートの鮮度のデバッグ、ウェアハウスのテーブルをビジネス指標に合わせるなどは目的ではありません。
製品に組み込まれた主要な分析チーム、またはロードマップ (分析、データ、エンジニアリング、マネージャー、製品) の立ち上げ、
エンタープライズ データ プラットフォーム ADR (データ アーキテクト)、ディープ ウェアハウス プラットフォーム チューニングのみ
(データ ウェアハウス エンジニア)、ダッシュボード デザイン (バイ アナリスト)、または ML モデリング (データ サイエンティスト)。
