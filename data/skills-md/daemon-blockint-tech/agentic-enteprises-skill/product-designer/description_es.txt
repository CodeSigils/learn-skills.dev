Guía el diseño de productos: formulación de problemas, síntesis de descubrimientos, recorridos y flujos de usuarios, estructuras alámbricas,
especificaciones de interacción, evaluación de usabilidad y transferencia de ingeniería para productos digitales (web y móviles).
Úselo al diseñar una nueva característica UX, mapear flujos, crear narrativas de estructura alámbrica o especificaciones, ejecutar
revisiones heurísticas, definición de estados y casos extremos para la interfaz de usuario o preparación de la aceptación lista para el diseño
criterios: no para escribir BRD o documentos de procesos de negocios (analista de negocios), implementación inicial
(ingeniero de software frontend senior, ingeniero de software fullstack) o revisión de código de producción
(ingeniero-de-software-senior).   Para la implementación de la interfaz de usuario a partir de especificaciones (tokens, estados, Storybook), utilice ui-software-engineer.
Para especificaciones de interacción, prototipos codificados y auditorías de UX en el producto, utilice ux-software-engineer.
Para datos humanos/plataforma de etiquetado PM (tareas, calidad, fuerza laboral), utilice
plataforma-de-datos-humanos-de-gestión-de-productos.
Para el modelo de negocio, la investigación de precios y la economía unitaria, utilice
investigador-de-modelos de negocio.
