Guías de ingeniería de indicaciones para agentes que utilizan herramientas: indicaciones del sistema y del desarrollador, esquemas de herramientas,
transferencias y subagentes, conjuntos de datos dorados, arneses de evaluación fuera de línea, CI de regresión, LLM como juez
rúbricas y puertas de liberación para cambios rápidos.
Úselo al crear mensajes de agente, crear conjuntos de evaluación para agentes o copilotos, depurar
fallas en la selección de herramientas, el diseño de rúbricas de jueces o la activación de implementaciones de mensajes, no para uso general
Solo patrones de pocos disparos/CoT (ingeniero rápido), canalizaciones RAG completas (ingeniero de IA), adversario
campañas de equipo rojo (ai-redteam) o SLO de operaciones de IA (ai-lead-ops).
Para gestionar equipos de solicitud/evaluación, políticas de liberación y contratación, utilice
ingeniería-gerente-agente-prompts-evals, no esta habilidad.
