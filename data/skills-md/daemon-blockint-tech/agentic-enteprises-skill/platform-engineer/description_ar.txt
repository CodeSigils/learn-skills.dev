توجيه هندسة الأنظمة الأساسية — منصات المطورين الداخلية (IDP)، والمسارات الذهبية، والخدمة الذاتية
التجريدات، وبوابات المطورين، وقوالب الطرق المعبدة، ومنصات Kubernetes متعددة المستأجرين، و
ممارسات النظام الأساسي كمنتج (خريطة الطريق، والاعتماد، وSLOs للنظام الأساسي).
يُستخدم عند تصميم أو تشغيل منصة للفرق الهندسية، وبناء سقالات الخدمة،
توحيد أنماط النشر/وقت التشغيل، ودمج Backstage أو البوابات المماثلة، وتحديد
واجهات برمجة تطبيقات النظام الأساسي والعقود، أو قياس تجربة المطورين - وليس لشبكة VPC أو الشبكة لمرة واحدة
التصميم (مهندس البنية التحتية)، CI YAML لكل تطبيق فقط (المطورون)، التخطيط الشامل للإصدار
(خبير استراتيجي للنشر)، أو تنفيذ التحكم الأمني (مهندس أمن المعلومات)، أو
تكامل النظام على مستوى المؤسسة ADRs (بنية النظام العليا). للتدريب العملي على الكتلة
الوظائف الإضافية، وتخطيط Helm، ومساحة الاسم على المجموعات المشتركة، استخدم Cluster-Deployment-engineer.
