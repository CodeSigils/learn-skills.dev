Progetta, crea e gestisce SDK client per API HTTP/REST, GraphQL, gRPC e stile RPC:
Allineamento del contratto OpenAPI-first, modellazione delle risorse, autenticazione (chiavi API, OAuth, firma),
tentativi/timeout/idempotenza, impaginazione e streaming, tassonomia degli errori, controllo delle versioni e deprecazione,
creazione di pacchetti e nomi multilingue, esperienza degli sviluppatori (avvio rapido, esempi) e test dell'SDK
(contratto e integrazione) con documentazione allineata al riferimento API.
Da utilizzare quando l'utente dice SDK engineer, client SDK, crea un SDK, libreria client API, OpenAPI SDK,
Progettazione dell'SDK, controllo delle versioni dell'SDK, SDK dei criteri di ripetizione, client di impaginazione, autenticazione dell'SDK o sviluppatore
SDK: non solo progettazione API backend (sviluppo API), interfaccia utente dell'app per l'utente finale (ingegnere software frontend senior),
modelli di piattaforma di integrazione generici (platform-engineer), scrittura tecnica senza implementazione dell'SDK
(scrittore-ricercatore tecnologico) o architettura pre-flight go/no-go senza il lavoro dell'SDK (build-validator).
