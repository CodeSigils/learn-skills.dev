Guía la evaluación de seguridad de sistemas integrados y ciberfísicos en hardware-in-the-loop
(HIL) bancos de pruebas: configuración del banco, objetivos ECU/ECM o PLC, interfaces de bus (CAN/CAN-FD, LIN,
Ethernet automotriz, Modbus de alto nivel), inyección de fallas y diseño de estímulos, simulado
integración planta/entorno, monitoreo de superficie de ataque en hardware real, prueba reproducible
casos, interbloqueos de seguridad de laboratorio y captura de evidencia para equipos de seguridad de vehículos y firmware.
Uso para pruebas de seguridad HIL, evaluación de seguridad de ECU, seguridad de bus CAN, prueba PLC HIL, falla
laboratorio de inyección, seguridad de hardware integrada, no pentest web/API (web-pentester), solo de red
pentest (pentester de red), malware/RE binario únicamente (ingeniería inversa), operaciones SOC
(soc-analyst), equipo rojo de AI (ai-redteam), trámites clasificados ISSO
(oficial-clasificado-de-seguridad-de-sistemas-de-información-especialista), o CI de software puro sin
hardware (validador de compilación).
