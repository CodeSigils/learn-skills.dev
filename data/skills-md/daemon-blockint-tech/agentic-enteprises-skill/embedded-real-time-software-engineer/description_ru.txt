Руководства по встроенной прошивке реального времени: компромиссы между MCU, «голое железо» и RTOS (шаблоны FreeRTOS/Zephyr),
приоритеты задач/сроки/дрожание, отложенная работа ISR, политика стека/кучи, WCET/анализ времени,
параллелизм и инверсия приоритетов, драйверы/HAL, JTAG/SWD/trace, режимы питания, поддержка MISRA C,
безопасные автомобильные/медицинские/промышленные модели без претензий на сертификацию.
Используется для встроенного встроенного ПО, планирования RTOS, драйверов/HAL, проектирования IRQ, политики памяти, WCET, запуска,
малое энергопотребление — не безопасность HIL (аппаратный контроль безопасности), серверные приложения
(старший инженер-программист), SCADA/OT (специалист по scada-ics-кибербезопасности), производительность сервера
(инженер производительности), только RTL без прошивки, шлюзы CI (сборка-валидатор), только многоуровневое распределение
(критически важный).
