Управляет проектированием производительности — профилирование (ЦП, память, ввод-вывод), распределенная трассировка, задержка и
анализ пропускной способности, нагрузочное/выдерживаемое/стресс-тестирование, модели мощности, бюджеты производительности, база данных
настройка запросов и обнаружение регрессии в CI.
Используйте при исследовании медленных конечных точек, регрессии p99, утечек памяти, насыщения, тестов нестабильной нагрузки,
определение SLO для задержки или создание отчетов по оптимизации с доказательствами — не для построения конвейера CI/CD
(devops), стратегия перехода на развертывание (специалист по развертыванию), размерное моделирование склада
(инженер хранилища данных), реализация React/UI (старший интерфейсный инженер-программист), объект
использование вычислительных ресурсов (эффективность поставок вычислительных ресурсов центра обработки данных) или исследование токенов LLM/стоимости
(жетоны инженера-исследователя-ученого).
