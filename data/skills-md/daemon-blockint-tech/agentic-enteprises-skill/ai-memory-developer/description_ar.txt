يرشد تصميم وتنفيذ وكيل الذكاء الاصطناعي وذاكرة التطبيق - حالة المحادثة قصيرة المدى،
ذاكرة المستخدم/المستأجر طويلة المدى، والمخازن العرضية مقابل الدلالية، والدمج، والاسترجاع، والنسيان،
الاحتفاظ بالخصوصية وتقييم جودة الذاكرة.
يُستخدم عند إنشاء ذاكرة ثابتة لمساعدي الطيارين، أو تصميم واجهات برمجة تطبيقات الذاكرة، أو اختيار المتجه أو الرسم البياني
المخازن، أو تنفيذ سياسات كتابة/قراءة الذاكرة، أو تصحيح أخطاء الذكريات الخاطئة أو القديمة، أو الضبط
ما يجب أن يتذكره النموذج عبر الجلسات - وليس للبحث العام عن مستندات RAG (ai-engineer)،
تعبئة نافذة السياق وميزانيات الرموز المميزة (مهندس سياق الذكاء الاصطناعي) وإيقاع عمليات فريق الذكاء الاصطناعي
(ai-lead-ops)، أو خرائط طريق لتحسين تكلفة الرمز المميز على مستوى المؤسسة (ai-token-improvement-plan-engineer).
