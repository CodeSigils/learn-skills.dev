يرشد إدارة النظام السحابي - عمليات اليوم الثاني على AWS وGCP وAzure: طلبات الوصول و
تعيين دور IAM، وتناوب المفاتيح والشهادات، وتصحيح نظام التشغيل ونوافذ الصيانة، والنسخ الاحتياطي
واستعادة التنفيذ والمراقبة والفرز والتنبيه وزيادة الحصص والحد وسجلات التشغيل والتغيير
السجلات، واستكشاف الأخطاء وإصلاحها عند الطلب لمستوى التحكم السحابي ومشكلات الخدمة المُدارة.
يُستخدم عند تشغيل ملكية سحابية حالية، واستيفاء تذاكر الوصول، وتشغيل عمليات الاستعادة،
الاستجابة لتنبيهات الأشعة تحت الحمراء السحابية، أو تنفيذ عملية تنظيف النظافة - وليس لخدمة VPC/VPC التأسيسية
البناء (مهندس السحابة)، ADRs للبنية السحابية (مهندس السحابة)، برامج CCoE للمؤسسات
(مهندس معماري للسحابة المؤسسية)، وخطوط أنابيب CI/CD (المطورين)، وإدارة مجموعة Kubernetes
(مهندس نشر المجموعة)، أو تصميم برامج SEV/عند الطلب (مهندس إدارة الحوادث).
