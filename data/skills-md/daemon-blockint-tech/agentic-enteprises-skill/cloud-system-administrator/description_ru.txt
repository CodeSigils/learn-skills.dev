Руководства по администрированию облачной системы — операции второго дня на AWS, GCP и Azure: запросы на доступ и
Назначение ролей IAM, ротация ключей и сертификатов, периоды обновления и обслуживания ОС, резервное копирование
восстановление выполнения, мониторинг и сортировка оповещений, увеличение квот и лимитов, модули Runbook, изменение
записи и устранение неполадок в облачной плоскости управления и управляемых услугах по вызову.
Используйте при работе с существующим облачным хранилищем, выполнении заявок на доступ, выполнении восстановления,
реагирование на оповещения об облачной инфраструктуре или выполнение гигиенической очистки — не для новых VPC/услуг
сборка (облачный инженер), ADR облачной архитектуры (облачный архитектор), корпоративные программы CCoE
(корпоративный облачный архитектор), конвейеры CI/CD (devops), администратор кластера Kubernetes
(инженер по развертыванию кластеров) или разработку программ SEV/дежурства по вызову (инженер по управлению инцидентами).
