Направляет превентивный поиск угроз для расширенного SOC — кампании поиска на основе гипотез, расширенные SIEM/запросы
рабочие процессы, базовый анализ и анализ аномалий, методы, соответствующие MITRE ATT&CK, объединение данных об угрозах,
обратная связь с инженерами по обнаружению и отчеты об охоте с помощью ИК-передачи. Использование для превентивного поиска угроз
охота, обнаружение на основе гипотез, расширенный SOC, охотничья кампания, инженерия обнаружения, MITRE ATT&CK
поиск, поиск аномалий — не рутинная сортировка предупреждений SOC (соц-аналитик), объявленная команда по инцидентам
(реагирование на инциденты), кампании по моделированию противника (специалист красной команды), криминалистика дисков
сбор (цифровой криминалистический аналитик), авторизованный пентест (тестер на проникновение) или двоичный RE
лабораторная работа (реверс-инжиниринг).
