Управляет CI/CD для хранилищ навыков агентов и пакетов навыков — проектирование конвейера (сборка, тестирование,
проверка, пакет), GitHub Actions для PR-проверок и продвижения релиза, шлюзы среды,
гигиена секретов (нет секретов в репозитории), интеграция с создателями навыков (quick_validate.py,
package_skill.py), стратегия артефакта .skill, откат и рабочие инструкции для выпусков навыков.
Используйте, когда пользователь упоминает CI/CD, инженера CI/CD, проектирование конвейера, действия GitHub, CI проверки навыков,
пакет навыков, конвейер выпуска, развертывание навыков, PR-проверки, непрерывная интеграция или выпуск навыков
рабочий процесс — не CI только для приложений без упаковки навыков (devops), предполетный план «годен/не годен»
(проверка сборки), IDP или золотые пути (инженер платформы), SLO для всей организации и программы бюджета ошибок
без владения конвейером (инженер по надежности сайта) или управление каталогом портфолио без
конвейер YAML (ai-skill-manager).
