يرشد CI/CD لمستودعات مهارات الوكيل وحزم المهارات - تصميم خطوط الأنابيب (البناء، الاختبار،
التحقق من الصحة، الحزمة)، إجراءات GitHub لفحوصات العلاقات العامة وترويج الإصدار، بوابات البيئة،
أسرار النظافة (لا توجد أسرار في الريبو)، تكامل منشئ المهارات (quick_validate.py،
package_skill.py)، واستراتيجية .skill artifact، والتراجع، وسجلات التشغيل التشغيلية لإصدارات المهارات.
يُستخدم عندما يذكر المستخدم CI/CD، ومهندس CI/CD، وتصميم خطوط الأنابيب، وإجراءات GitHub، والتحقق من صحة المهارات CI،
مهارات الحزمة، أو خط الأنابيب، أو نشر المهارات، أو فحوصات العلاقات العامة، أو التكامل المستمر، أو إطلاق المهارات
سير العمل - وليس CI للتطبيق فقط بدون تعبئة المهارات (devops)، خطة ما قبل الرحلة go/no-go
(أداة التحقق من البناء)، أو IDP أو المسارات الذهبية (مهندس النظام الأساسي)، وبرامج SLO على مستوى المؤسسة، وبرامج ميزانية الأخطاء
بدون ملكية خطوط الأنابيب (مهندس موثوقية الموقع)، أو إدارة كتالوج المحفظة بدون
خط أنابيب YAML (مدير الذكاء الاصطناعي).
