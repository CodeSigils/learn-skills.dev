(React/Next.js o simili), API backend (Node/TypeScript o Python), database, autenticazione, test,
e debugging della produzione per codice applicativo gestibile.

implementare moduli e percorsi API, scrivere migrazioni, aggiungere test o rivedere l'applicazione
PR: non per piattaforme CI/CD (devops), VPC/IaC cloud (ingegnere dell'infrastruttura), data warehouse
modellazione (data-warehouse-engineer), funzionalità LLM/RAG (ai-engineer) o sicurezza/conformità dell'organizzazione
programmi (cybersecurity, compliance-engineer). Per i modelli di app Web del browser (sessioni, CSRF, CORS,
CSP, routing SSR/SPA), utilizzare lo sviluppatore di applicazioni web. Per la progettazione di sistemi di livello senior e
revisione in stile tutoraggio, utilizza anche senior-fullstack-developer. Solo interfaccia utente dal design: ui-software-engineer.
