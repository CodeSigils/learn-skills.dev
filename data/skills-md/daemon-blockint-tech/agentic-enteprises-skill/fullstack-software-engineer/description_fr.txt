Guide l’ingénierie logicielle complète : fonctionnalités de produit de bout en bout sur les interfaces Web
(React/Next.js ou similaire), API backend (Node/TypeScript ou Python), bases de données, authentification, tests,
et débogage de production pour un code d'application maintenable.
À utiliser lors de la création ou de la correction de fonctionnalités destinées aux utilisateurs, de la conception de contrats REST/GraphQL/tRPC,
implémenter des formulaires et des routes API, rédiger des migrations, ajouter des tests ou réviser une application
PR : pas pour les plateformes CI/CD (devops), cloud VPC/IaC (ingénieur d'infrastructure), entrepôt de données
modélisation (ingénieur d'entrepôt de données), fonctionnalités LLM/RAG (ingénieur IA) ou sécurité/conformité de l'organisation
programmes (cybersécurité, ingénieur conformité). Pour les modèles d'application Web de navigateur (sessions, CSRF, CORS,
CSP, routage SSR/SPA), utilisez un développeur d'applications Web. Pour la conception de systèmes de niveau supérieur et
examen de type mentorat, utilisez également un développeur senior fullstack. Interface utilisateur uniquement à partir de la conception : ui-software-engineer.
Reproduction du ticket sans code : support-ingénieur.
