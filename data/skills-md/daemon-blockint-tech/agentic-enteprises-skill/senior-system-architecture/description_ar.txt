يوجه بنية النظام والحلول العليا - حدود الخدمة المشتركة، وأنماط التكامل،
المتطلبات غير الوظيفية (الحجم، الموثوقية، الأمان، التكلفة)، التفاعلات التفاعلية، النمذجة على طراز C4،
مراجعة البنية، والبناء مقابل الشراء، والترحيل المرحلي (الخانق، والكتابة المزدوجة).
يُستخدم عند تصميم أنظمة متعددة الخدمات، أو تقييم النظام الأساسي أو اختيارات البائعين، أو الكتابة أو
مراجعة سجلات قرارات الهندسة المعمارية، وتحديد المعايير والمبادئ، أو التقييم
المخاطر الفنية عبر المجالات - وليس لطلبات RFC ذات الخدمة الواحدة وتصميم الوحدة النمطية
(مهندس برمجيات أول)، منصة البيانات أو قرارات الشبكة (مهندس البيانات)، منطقة الهبوط السحابية،
بنية جيدة التصميم والهجرة (مهندس سحابي) وتنفيذ السحابة/IaC
(مهندس البنية التحتية، مهندس السحابة)، منتج النظام الأساسي للمطور الداخلي (مهندس النظام الأساسي)،
أو تتبع البرنامج (مدير البرنامج الفني). لاستراتيجية العمل والحالات، استخدم
مستشار الأعمال؛ بالنسبة للذكاء الاصطناعي التطبيقي (RAG، الوكلاء، مساعدي الطيارين)، استخدم المؤسسة التجارية التطبيقية.
