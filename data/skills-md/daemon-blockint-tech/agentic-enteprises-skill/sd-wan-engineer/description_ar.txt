تصميم ونشر وتشغيل شبكة SD-WAN — تراكب WAN (شبكة WAN (محورية، شبكة، محاور إقليمية)، تراكب التراكب (MPLS، النطاق العريض، LTE/5G)، اختيار المسار، التوجيه المدرك للتطبيق، SASE، شبكة WAN ذات الثقة المعدومة، اتصال الفروع، قوالب التنسيق، إدراج NGFW/SWG/ZTNA، HA، وترحيل SD-WAN للحقل البني؛ البائع الملحد (Viptela، VeloCloud، Prisma SD-WAN). يجب استخدام هذه المهارة عندما يسأل المستخدم عن SD-WAN، أو شبكة WAN المعرفة بالبرمجيات، أو مهندس SDWAN، أو شبكة WAN المتراكبة، أو تحديد المسار، أو التوجيه المدرك للتطبيق، أو SD-WAN، أو SASE، أو شبكة WAN ذات الثقة المعدومة، أو اتصال الفروع، أو التراكب الأساسي، أو VeloCloud، أو Viptela، أو Prisma SD-WAN، أو تحسين WAN، أو ترحيل SD-WAN للحقل البني - وليس العمود الفقري BGP/MPLS للناقل فقط (مهندس العمود الفقري للشبكة)، أو تصميم VPC السحابي (مهندس السحابة، أو مهندس السحابة)، أو واجهات برمجة تطبيقات المؤسسة (مطور واجهة برمجة التطبيقات للتكامل المؤسسي)، أو برنامج أمان نقطة النهاية فقط (مهندس أمن المعلومات)، أو كابلات التيار المباشر الفعلية (مهندس البنية التحتية).
