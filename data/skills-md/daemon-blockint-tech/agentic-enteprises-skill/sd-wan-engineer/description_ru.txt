Проектирование, развертывание и эксплуатация SD-WAN — наложение WAN (концентратор, ячеистая сеть, региональные концентраторы), наложение нижнего уровня (MPLS, широкополосная связь, LTE/5G), выбор пути, маршрутизация с учетом приложений, SASE, WAN с нулевым доверием, подключение филиалов, шаблоны оркестрации, вставка NGFW/SWG/ZTNA, HA и миграция существующих SD-WAN; независимо от поставщика (Viptela, VeloCloud, Prisma SD-WAN). Этот навык следует использовать, когда пользователь задает вопросы о SD-WAN, программно-определяемой глобальной сети, инженере SDWAN, оверлейной глобальной сети, выборе пути, маршрутизации с учетом приложений, концентраторной сети SD-WAN, SASE, глобальной сети с нулевым доверием, подключении филиалов, подложном оверлее, VeloCloud, Viptela, Prisma SD-WAN, оптимизации глобальной сети или миграции существующих SD-WAN — а не только опорная сеть оператора связи BGP/MPLS (сетевой магистральный архитектор), проектирование облачного VPC (облачный архитектор, облачный инженер), корпоративные API (разработчик корпоративной интеграции API), только программа безопасности конечных точек (инженер по информационной безопасности) или физическая кабельная система постоянного тока (инженер по инфраструктуре).
