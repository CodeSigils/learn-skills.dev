上級フロントエンド ソフトウェア エンジニアリングをガイドします。TypeScript/React/Next.js アーキテクチャ、コンポーネント設計、
クライアントとサーバーのレンダリング、状態とデータの取得、スタイルとデザイン システム、アクセシビリティ (WCAG)、
パフォーマンス (Core Web Vitals)、テスト、および上級レベルの UI コード レビュー。
複雑な UI の構築またはリファクタリング、コンポーネント API の設計、LCP/INP/CLS の最適化、
アクセシブルなインタラクションの実装、デザイン トークンの統合、フロントエンド PR のレビューなどは目的ではありません。
バックエンド API またはデータベース (フルスタック ソフトウェア エンジニア、シニア フルスタック開発者)、設計のみ
実装、CI/CD (devops)、またはクロスサービス システム RFC (上級ソフトウェア エンジニア) を伴わない批評。
設計仕様、コンポーネントの状態、ビジュアル QA から画面を実装するには、ui-software-engineer を使用します。
パフォーマンスの詳細な調査と負荷/RUM 分析: パフォーマンス エンジニア。
