Guida l'ingegneria software front-end senior: architettura TypeScript/React/Next.js, progettazione dei componenti,
rendering client e server, recupero di stati e dati, sistemi di stile e progettazione, accessibilità (WCAG),
prestazioni (Core Web Vitals), test e revisione del codice dell'interfaccia utente di livello senior.
Da utilizzare durante la creazione o il refactoring di interfacce utente complesse, la progettazione di API di componenti, l'ottimizzazione di LCP/INP/CLS,
implementare interazioni accessibili, integrare token di progettazione o rivedere PR front-end, non per
API o database backend (ingegnere software fullstack, sviluppatore fullstack senior), solo progettazione
critiche senza implementazione, CI/CD (devops) o RFC di sistemi cross-service (senior-software-engineer).
Per implementare le schermate dalle specifiche di progettazione, dagli stati dei componenti e dal QA visivo, utilizzare ui-software-engineer.
