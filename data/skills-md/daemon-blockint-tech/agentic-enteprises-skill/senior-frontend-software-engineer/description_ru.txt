Руководит старшими специалистами по разработке программного обеспечения: архитектура TypeScript/React/Next.js, проектирование компонентов,
клиентский и серверный рендеринг, получение состояния и данных, системы стилизации и дизайна, доступность (WCAG),
производительность (Core Web Vitals), тестирование и проверка кода пользовательского интерфейса высшего уровня.
Используйте при создании или рефакторинге сложных пользовательских интерфейсов, разработке API компонентов, оптимизации LCP/INP/CLS,
внедрение доступных взаимодействий, интеграция токенов дизайна или проверка внешних PR — не для
серверные API или базы данных (инженер полного стека программного обеспечения, старший разработчик полного стека), только для проектирования
критика без реализации, CI/CD (devops) или RFC кросс-сервисной системы (старший инженер-программист).
Для реализации экранов из спецификаций дизайна, состояний компонентов и визуального контроля качества используйте ui-software-engineer.
Глубокие исследования производительности и анализ нагрузки/RUM: Performance-engineer.
