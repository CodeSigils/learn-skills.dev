يرشد الترميز الآمن ومراجعة التعليمات البرمجية التي تركز على الأمان عبر اللغات والبنية التحتية - موجه نحو OWASP
أنماط الثغرات الأمنية (الحقن، XSS، المصادقة، التشفير، إلغاء التسلسل، SSRF، XXE)، التعامل مع الأسرار،
وأمن IaC (Terraform وKubernetes وDocker وGitHub Actions).
يُستخدم عند كتابة أو مراجعة التعليمات البرمجية التي تتعامل مع إدخال المستخدم والمصادقة والملفات وقواعد البيانات،
طلبات الشبكة، أو التشفير، أو تكوين البنية التحتية - أو عندما يطلب المستخدم التحقق من وجود SQL
الحقن، أو XSS، أو SSRF، أو الأسرار المشفرة، أو مشكلات OWASP، أو أمان Terraform، أو أمان إجراءات GitHub.
ليس من أجل ارتباطات اختبار الاختراق المصرح بها (ai-redteam، والأمن السيبراني)، وبرنامج الامتثال
رسم الخرائط (مهندس الامتثال)، أو قواعد YARA/البرامج الضارة (تأليف قاعدة yara)، أو إعداد خط أنابيب CI فقط
(ديفسيكوبس).
