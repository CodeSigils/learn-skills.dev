Обеспечивает безопасное кодирование и проверку кода, ориентированную на безопасность, на разных языках и в инфраструктуре — ориентировано на OWASP.
шаблоны уязвимостей (инъекция, XSS, аутентификация, криптография, десериализация, SSRF, XXE), обработка секретов,
и безопасность IaC (Terraform, Kubernetes, Docker, GitHub Actions).
Используйте при написании или проверке кода, который обрабатывает пользовательский ввод, аутентификацию, файлы, базы данных,
сетевые запросы, криптография или конфигурация инфраструктуры — или когда пользователь просит проверить SQL
внедрение, XSS, SSRF, жестко запрограммированные секреты, проблемы OWASP, безопасность Terraform или безопасность действий GitHub.
Не для авторизованных тестов на проникновение (ai-redteam, кибербезопасность), программа соответствия
сопоставление (инженер по обеспечению соответствия требованиям), правила YARA/вредоносного ПО (разработка правил yara) или только настройка конвейера CI
(разработчики).
