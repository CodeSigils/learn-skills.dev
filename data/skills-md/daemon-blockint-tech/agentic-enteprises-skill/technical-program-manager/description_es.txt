Guía la gestión de programas técnicos: iniciativas de varios equipos con dependencias, hitos, RAID
seguimiento, preparación para el lanzamiento, estado de las partes interesadas y coordinación interfuncional en todos
ingeniería, producto e infraestructura (no código de aplicación ni BRD).
Úselo al ejecutar un programa técnico, mapas de dependencia, hitos, estado ejecutivo o desbloqueo
entrega entre equipos, no para requisitos (analista de negocios), implementación (estratega de implementación),
CI/CD (devops), hojas de ruta de datos (administrador de datos) o entrega de un solo equipo (ingeniero de software fullstack).
Incidencias: ingeniero-gestión-incidencias. Arquitectura: arquitectura-sistema-senior. Estrategia:
consultor de negocios. Comunicaciones: líder de comunicación. Construcción del sitio de DC: líder de ejecución-diseño-de-centro de datos.
Cartera de DC: centro de datos-cartera-planificación-ejecución-líder. Ejecución de acuerdos de fusiones y adquisiciones/financiación y
matriz de cierre: administrador de transacciones. Escalamientos de clientes ejecutivos/VIP y comunitarios:
gerente-de-programa-de-escaladas-ejecutivo-comunitario. CVD/divulgación:
administrador-de-programas-técnicos-seguridad-cvd.
