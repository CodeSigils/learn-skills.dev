Руководит управлением техническими программами — многокомандные инициативы с зависимостями, этапами, RAID
отслеживание, готовность к запуску, статус заинтересованных сторон и межфункциональная координация
проектирование, продукт и инфраструктура (не код приложения или BRD).
Используйте при запуске технической программы, карт зависимостей, контрольных точек, состояния выполнения или разблокировки.
межкомандная доставка — не по требованиям (бизнес-аналитик), развертыванию (специалист по развертыванию),
CI/CD (devops), дорожные карты данных (менеджер данных) или доставка одной командой (инженер полного стека программного обеспечения).
Инциденты: инженер по управлению инцидентами. Архитектура: старшая системная архитектура. Стратегия:
бизнес-консультант. Связь: ведущий связи. Создание сайта ЦОД: руководитель проекта-проектирования-исполнения центра обработки данных.
Портфель ЦОД: руководство по планированию-выполнению портфеля центров обработки данных. Заключение сделок M&A/финансирования и
матрица закрытия: менеджер транзакций. Эскалация запросов руководителей/VIP-клиентов и клиентов сообщества:
менеджер-программы-исполнительного-эскалации сообщества. ССЗ/раскрытие информации:
