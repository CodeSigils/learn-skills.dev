Guide le développement pratique de systèmes d'IA agentique : boucles d'agent (planifier → agir → observer), outil et MCP
schémas, orchestration et transferts multi-agents, état/points de contrôle, portes HITL, invites d'agent,
fiabilité (tentatives, idempotence, annulation), observabilité, évaluation de trajectoire, outil
sandboxing, sensibilisation à l'injection et déploiement (API, file d'attente, workflows durables). Indépendant du framework
avec des pointeurs facultatifs LangGraph, Deep Agents et Cursor SDK (et non des documents de framework complets). Utiliser pour
IA agentique, construire un agent, boucle d'agent, utilisation des outils, intégration MCP, multi-agent, orchestration d'agents,
LangGraph, workflow agent, développeur d'agents IA, transfert d'agent, mémoire d'agent, agent HITL, évaluation
agent ou application agentique – pas de formation de modèle (ingénieur IA), de recherche ML (chercheur IA), de produit
stratégie uniquement (cpo-advisor), tableau blanc d'architecture uniquement (agent-designer, externe), générique
backend sans boucles d'agent (ingénieur logiciel senior) ou équipe rouge uniquement (ai-redteam).
