セキュリティ調整型脆弱性開示 (CVD) のための技術プログラム管理をガイドします—
開示ポリシー、SLAの取り込みとトリアージ、研究者の調整、修正/修復の追跡、
禁輸措置と公開のタイムライン、CVE/アドバイザリーの調整、バグ報奨金プログラムの運営、
および機能横断的なゲート (セキュリティ エンジニアリング、法務、通信、製品)。
CVD または責任ある開示プログラム、開示カレンダー、報奨金作戦、
または、報告された脆弱性に対するマルチチーム修復のブロックを解除します（実践的な侵入テストではありません）。
(攻撃側セキュリティ アナリスト)、SOC トリアージ (防御側セキュリティ アナリスト)、CI での脆弱性スキャン
(devsecops)、企業セキュリティ戦略 (サイバーセキュリティ)、一般的な非セキュリティ プログラム
(技術プログラムマネージャー)、または契約のレッドライン (商業顧問)。
