توجيه إدارة البرامج الفنية للكشف عن الثغرات الأمنية المنسقة (CVD) —
سياسة الإفصاح، واتفاقيات مستوى الخدمة (SLA) الخاصة بالقبول والفرز، وتنسيق الباحثين، وتتبع الإصلاح/المعالجة،
الجداول الزمنية للحظر والنشر، ومكافحة التطرف العنيف/التنسيق الاستشاري، وعمليات برنامج مكافأة الأخطاء،
وبوابات متعددة الوظائف (هندسة أمنية، قانونية، اتصالات، منتج).
يُستخدم عند تشغيل برنامج CVD أو برنامج الكشف المسؤول، أو تقويم الكشف، أو عمليات المكافآت،
أو إلغاء حظر العلاج متعدد الفرق لنقاط الضعف المبلغ عنها - وليس للاختبار العملي
(محلل الأمن الهجومي)، فرز SOC (محلل الأمن الدفاعي)، مسح الثغرات الأمنية في CI
(devsecops)، استراتيجية أمن المؤسسات (الأمن السيبراني)، البرامج العامة غير الأمنية
(مدير البرنامج الفني)، أو الخطوط الحمراء للعقود (المستشار التجاري).
