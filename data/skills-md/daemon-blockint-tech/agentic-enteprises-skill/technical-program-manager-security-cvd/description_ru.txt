Руководит техническим управлением программами для скоординированного раскрытия уязвимостей (CVD) —
политика раскрытия информации, соглашения об уровне обслуживания по приему и сортировке, координация исследований, отслеживание исправлений/восстановлений,
сроки эмбарго и публикации, координация CVE/консультаций, операции по программе вознаграждения за обнаружение ошибок,
и межфункциональные шлюзы (инженерия безопасности, юриспруденция, связь, продукция).
Используйте при запуске программы CVD или ответственного раскрытия информации, календаря раскрытия информации, операций по вознаграждению,
или разблокирование многокомандного исправления обнаруженных уязвимостей, а не для практического пентеста.
(аналитик наступательной безопасности), сортировка SOC (аналитик защитной безопасности), сканирование уязвимостей в CI
(devsecops), стратегия безопасности предприятия (кибербезопасность), общие программы, не связанные с безопасностью
(технический менеджер программ) или красные линии контракта (коммерческий консультант).
