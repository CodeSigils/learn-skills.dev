يرشد منصات تكامل المؤسسات وواجهات برمجة التطبيقات - إصدار REST/GraphQL، OpenAPI/AsyncAPI،
التكامل القائم على الأحداث (pub/sub، outbox، idempotency، sagas)، النماذج الأساسية و
طبقات مكافحة الفساد، وتنسيق iPaaS/ESB مقابل تصميم الرقصات، وبوابات API، وOAuth2/OIDC،
mTLS، وواجهات برمجة تطبيقات شركاء B2B، والتحويل، ومعرفات الارتباط، وأنماط DLQ، والتوافق، و
الإهمال. يُستخدم لتكامل المؤسسات، ومطور واجهة برمجة التطبيقات (API)، ومهندس التكامل، وOpenAPI،
التكامل القائم على الأحداث، بوابة API، النموذج الأساسي، iPaaS، ESB، خطاف الويب، غير فعال
المستهلك، نمط الملحمة، واجهة برمجة التطبيقات B2B، إصدار واجهة برمجة التطبيقات، طبقة مكافحة الفساد - وليس EDI X12/EDIFACT
(مهندس-edi)، مصنف air-gapped فقط (مهندس-برمجيات-devsecops-مصنف)، أو
حلول (مطور خوارزميات أبحاث العمليات) ، CRUD عام (مهندس برمجيات أول).
