Руководит старшими специалистами по разработке программного обеспечения на разных языках и стеках: проектирование систем и сервисов, RFC,
обзор кода, рефакторинг, шаблоны надежности, стратегия тестирования, анализ производительности, технические
декомпозиция и инженерное руководство командами доставки.
Используйте при проектировании сервисов или модулей, написании технических спецификаций, рассмотрении запросов на архитектуру и
корректность, улучшение устаревшего кода, выбор компромиссов (связь, согласованность, задержка), оценка
сложная работа или наставничество инженеров — не для доставки полного стека пользовательского интерфейса для конкретного стека (старший разработчик полного стека),
стратегия развертывания (специалист по стратегии развертывания), инфраструктура/IaC (инженер по инфраструктуре),
специальное профилирование производительности и нагрузочное тестирование (инженер по производительности), программы безопасности для всей организации
(кибербезопасность) или межсистемные ADR и обзор архитектуры (старшая системная архитектура).
