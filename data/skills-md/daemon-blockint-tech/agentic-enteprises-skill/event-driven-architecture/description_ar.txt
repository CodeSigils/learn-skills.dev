المقايضات، وصندوق الصادر/صندوق الوارد للمعاملات، وتصميم الرقصات مقابل التنسيق، والملاحم، وقوائم انتظار الرسائل الميتة،
إعادة التشغيل، البث مقابل الأحداث المنفصلة، حدود الخدمات الصغيرة. استخدم عندما يطلب المستخدم ذلك
الهندسة المعمارية المستندة إلى الأحداث، ومصادر الأحداث، وCQRS، والحانة/الفرعية، وأحداث كافكا، ونمط البريد الصادر،
المستهلك العاجز، أو تصميم رقصات الأحداث، أو تنسيق الملحمة، أو قائمة انتظار الحروف الميتة، أو مخطط الحدث

(مطور واجهة برمجة التطبيقات للتكامل المؤسسي)، EDI (مهندس EDI)، الترويج المبوب
