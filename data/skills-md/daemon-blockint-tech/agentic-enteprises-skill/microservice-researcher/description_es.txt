Guía la investigación y el análisis para decisiones de arquitectura de microservicios: descomposición de dominios,
contextos acotados, opciones y compensaciones de límites de servicios, patrones de integración sincronizados frente a asincrónicos,
propiedad y coherencia de los datos (consistencia eventual, sagas a nivel de investigación), API y contrato
evolución, alineación de topologías de equipo, construcción versus compra versus servicios administrados, estrangulador de monolitos
migración, impacto NFR (latencia, confiabilidad, operatividad) y registros de decisiones con opciones y
recomendaciones. Uso para investigación de microservicios, límites de servicios, contexto acotado, estrangulador
higo, monolito a microservicios, saga vs compromiso de dos fases, descomposición de dominio, microservicios
compensación, topologías de equipo, investigación de consistencia eventual, estrategia de control de versiones de API, sin evaluar
un patrimonio existente (analista de microservicios), código de servicio de producción (ingeniero de software senior,
ingeniero de plataforma), solo operaciones de clúster de Kubernetes (ingeniero de nube), diseño de red puro
(red-backbone-arquitecto), o implementación de EDA cuando se construye, no se investiga
