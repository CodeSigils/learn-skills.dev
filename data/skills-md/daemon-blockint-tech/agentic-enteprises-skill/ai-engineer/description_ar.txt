توجيه هندسة الذكاء الاصطناعي للإنتاج - تطبيقات LLM، RAG، الوكلاء، أدوات التقييم، إمكانية الملاحظة، التكلفة/زمن الوصول،
والنشر الآمن. يُستخدم عند إنشاء روبوتات الدردشة، ومساعدي الطيارين، والاسترجاع، وسير عمل الوكيل، وتوجيه النموذج،
أو تكامل LLM API - وليس توليف الأبحاث (الباحث بالذكاء الاصطناعي)، وسياسة الذكاء الاصطناعي (الذكاء الاصطناعي-حوكمة المخاطر)،
الفريق الأحمر (ai-redteam)، العمل الفوري فقط (مهندس سريع)، ADRs غير الذكاء الاصطناعي (كبار مهندسي النظام)،
برامج الرموز المميزة (ai-token-improvement-plan-engineer) وهندسة الحلول
(التطبيقية-الهندسة المعمارية-المؤسسات التجارية)، محفظة المهارات (الذكاء الاصطناعي-مدير المهارات)، أو الذكاء الاصطناعي العمودي
الإدارة الهندسية (المدير الهندسي-العمودي-المنتجات).
التأليف الفوري للوكيل وتصميم تسخير التقييم: تقييم المهندس الفوري للوكيل.
بوابات الاستدلال الوقائية والاعتدال بالأشعة تحت الحمراء: إجراءات الحماية لمهندس البنية التحتية.
أبحاث مصنفات الحماية: ضمانات مهندس أبحاث ml.
