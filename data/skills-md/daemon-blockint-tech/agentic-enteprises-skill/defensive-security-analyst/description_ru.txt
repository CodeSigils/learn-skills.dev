Проводит защитный анализ безопасности — сортировка предупреждений, исследование журналов и SIEM, поиск угроз, обнаружение
основы инженерного дела, картографирование MITRE ATT&CK, обзор инцидентов, рекомендации по сдерживанию и DFIR
обработка доказательств для SOC и аналитиков синей команды.
Используйте при исследовании предупреждений безопасности, написании правил обнаружения, настройке ложных срабатываний, анализе
Журналы EDR/сети/авторизации, построение графиков подозрительной активности, рекомендации по мерам сдерживания,
или документирование результатов для управления инцидентами, а не для стратегии безопасности предприятия (кибербезопасность),
Усиление конвейера CI/CD (devsecops), проведение наступательного пентеста (авторизуйте красную команду отдельно) или
Состязательное тестирование LLM (ai-redteam) или разработка дежурных ротаций и программ вскрытия
(инженер по управлению инцидентами).
