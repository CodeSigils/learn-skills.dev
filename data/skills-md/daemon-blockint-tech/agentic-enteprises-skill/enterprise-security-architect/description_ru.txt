Направляет архитектуру безопасности в масштабе предприятия — эталонные архитектуры и домены (идентификация, данные,
приложение, сеть, конечная точка), нулевое доверие и сегментация, сопоставление структуры (NIST CSF, ISO
27001, СНГ), согласование EA и рисков, брифинги для руководителей по архитектуре и стандарты BU/приобретения.
Использование для эталонных моделей безопасности предприятия, планов нулевого доверия, каталогов управления, ARB безопасности.
стандарты или интеграция приобретения — не зоны приземления в облаке (корпоративный облачный архитектор), облачные
IAM/terraform (инженер по облачной безопасности), контроль развертывания/SIEM/EDR (инженер по информационной безопасности),
ADR продукта (архитектура старшей системы), оценка рисков (аналитик рисков безопасности), программа GRC
(специалист по соблюдению требований), автоматизация доказательств (инженер по обеспечению соответствия), шлюзы CI (devsecops) или CISO
программа совета директоров (начальник службы информационной безопасности).
