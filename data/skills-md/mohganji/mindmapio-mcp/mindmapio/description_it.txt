Guida le mappe di Mindmap.io direttamente sulla sua API del nodo HTTP: elenca e leggi le mappe, crea sottoalberi di nodi con ID coniati dal client ed esegui le operazioni del nodo generativo (invia, espansione automatica, riprova, interrompi). Da utilizzare quando l'utente desidera creare o espandere una mappa mindmap.io, eseguire prompt sui nodi, suddividere un nodo in follow-up o leggere una mappa/ramo a livello di codice senza il server MCP.
