Esplorazione guidata e interattiva di dati statistici tramite fornitori SDMX (Eurostat, OCSE, BCE, Banca Mondiale, ISTAT e altri) utilizzando la CLI opensdmx. Utilizza questa abilità ogni volta che l'utente pone una domanda sulle statistiche a cui è possibile rispondere con i dati SDMX: dati demografici, economia, occupazione, nascite, morti, popolazione, prezzi, commercio, salute, agricoltura o qualsiasi altro argomento. Utilizzalo anche quando l'utente menziona un ID flusso di dati specifico che desidera esplorare. La competenza guida l'utente passo dopo passo: scopre i set di dati rilevanti, propone i candidati più significativi, esplora lo schema utilizzando vincoli reali (non elenchi di codici), spiega la struttura del set di dati e invita l'utente a fare scelte informate sui filtri prima di recuperare qualsiasi dato.
