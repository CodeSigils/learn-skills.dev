Управляемое интерактивное исследование статистических данных через поставщиков SDMX (Евростат, ОЭСР, ЕЦБ, Всемирный банк, ISTAT и другие) с использованием интерфейса командной строки opensdmx. Используйте этот навык всякий раз, когда пользователь задает вопрос о статистике, на который можно ответить с помощью данных SDMX: демография, экономика, занятость, рождаемость, смертность, население, цены, торговля, здравоохранение, сельское хозяйство или любая другая тема. Также используйте его, когда пользователь упоминает конкретный идентификатор потока данных, который он хочет изучить. Этот навык направляет пользователя шаг за шагом: обнаруживает соответствующие наборы данных, предлагает наиболее значимых кандидатов, исследует схему с использованием реальных ограничений (а не списков кодов), объясняет структуру набора данных и предлагает пользователю сделать осознанный выбор фильтра перед получением каких-либо данных.
