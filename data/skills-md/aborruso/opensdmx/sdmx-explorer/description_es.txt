Exploración guiada e interactiva de datos estadísticos a través de proveedores SDMX (Eurostat, OCDE, BCE, Banco Mundial, ISTAT y otros) utilizando la CLI de opensdmx. Utilice esta habilidad siempre que el usuario haga una pregunta sobre estadísticas que podrían responderse con datos SDMX: demografía, economía, empleo, nacimientos, muertes, población, precios, comercio, salud, agricultura o cualquier otro tema. Úselo también cuando el usuario mencione un ID de flujo de datos específico que desee explorar. La habilidad guía al usuario paso a paso: descubre conjuntos de datos relevantes, propone los candidatos más significativos, explora el esquema utilizando restricciones reales (no listas de códigos), explica la estructura del conjunto de datos e invita al usuario a tomar decisiones de filtrado informadas antes de recuperar cualquier dato.
