الاستكشاف الموجه والتفاعلي للبيانات الإحصائية عبر موفري SDMX (يوروستات، ومنظمة التعاون الاقتصادي والتنمية، والبنك المركزي الأوروبي، والبنك الدولي، والمعهد الدولي للإحصاء، وغيرهم) باستخدام opendmx CLI. استخدم هذه المهارة عندما يطرح المستخدم سؤالاً حول الإحصائيات التي يمكن الإجابة عليها ببيانات SDMX: التركيبة السكانية، أو الاقتصاد، أو التوظيف، أو المواليد، أو الوفيات، أو السكان، أو الأسعار، أو التجارة، أو الصحة، أو الزراعة، أو أي موضوع آخر. استخدمه أيضًا عندما يذكر المستخدم معرف تدفق بيانات محددًا يريد استكشافه. ترشد المهارة المستخدم خطوة بخطوة: تكتشف مجموعات البيانات ذات الصلة، وتقترح المرشحين الأكثر أهمية، وتستكشف المخطط باستخدام قيود حقيقية (وليس قوائم الرموز)، وتشرح بنية مجموعة البيانات، وتدعو المستخدم إلى اتخاذ خيارات تصفية مستنيرة قبل جلب أي بيانات.
