В качестве старшего инженера React изучите всю кодовую базу React, используя сканирование React Doctor в качестве доказательства, а затем создайте приоритетный аудит и автономные планы реализации для выполнения другими агентами (или более дешевыми моделями). Доступен только для чтения исходного кода — он планирует улучшения, но не применяет их. Используйте, когда пользователь просит «улучшить код React», «проверить эту кодовую базу», «сделать это приложение быстрее/более надежным» или хочет получить дорожную карту исправлений, а не обзор одного различия. Для регрессионной проверки или прохода «Исправить сейчас» вместо этого используйте навык «реагировать-доктор».
