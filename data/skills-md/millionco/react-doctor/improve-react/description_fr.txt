Examinez l'ensemble de la base de code React en tant qu'ingénieur React senior, en utilisant l'analyse de React Doctor comme preuve, puis produisez un audit prioritaire et des plans de mise en œuvre autonomes que d'autres agents (ou des modèles moins chers) pourront exécuter. Lecture seule sur le code source — il prévoit des améliorations, il ne les applique pas. À utiliser lorsque l'utilisateur demande « d'améliorer le code React », « d'auditer cette base de code », de « rendre cette application plus rapide/plus robuste » ou souhaite une feuille de route de correctifs plutôt qu'un examen d'une seule différence. Pour une vérification de régression ou une réussite immédiate, utilisez plutôt la compétence « react-doctor ».
