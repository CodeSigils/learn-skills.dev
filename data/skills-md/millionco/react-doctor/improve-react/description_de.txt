Untersuchen Sie als leitender React-Ingenieur eine gesamte React-Codebasis, indem Sie den Scan von React Doctor als Beweis verwenden, und erstellen Sie dann eine priorisierte Prüfung und eigenständige Implementierungspläne für die Ausführung durch andere Agenten (oder günstigere Modelle). Schreibgeschützt für den Quellcode – Verbesserungen werden geplant, aber nicht umgesetzt. Verwenden Sie diese Option, wenn der Benutzer „den React-Code verbessern“, „diese Codebasis prüfen“ oder „diese App schneller/robuster machen“ möchte oder eine Roadmap mit Korrekturen anstelle einer Überprüfung eines einzelnen Unterschiedes wünscht. Für eine Regressionsprüfung oder einen „Fix-it-Now“-Durchgang verwenden Sie stattdessen die Fertigkeit „react-doctor“.
