Esamina un'intera base di codice React come ingegnere React senior, utilizzando la scansione di React Doctor come prova, quindi produci un audit con priorità e piani di implementazione autonomi per altri agenti (o modelli più economici) da eseguire. Di sola lettura sul codice sorgente: pianifica i miglioramenti, non li applica. Da utilizzare quando l'utente chiede di "migliorare il codice React", "controllare questa base di codice", "rendere questa app più veloce/più robusta" o desidera una tabella di marcia delle correzioni anziché una revisione di una singola differenza. Per un controllo di regressione o un passaggio "risolvilo subito", utilizza invece l'abilità "react-doctor".
