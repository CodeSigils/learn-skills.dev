Utilice truffler para encontrar símbolos JavaScript/TypeScript similares o preexistentes antes de implementar código nuevo, especialmente ayudantes, utilidades, analizadores, formateadores, escáneres, comparadores difusos y otras funciones reutilizables. Los agentes deben usar esta habilidad siempre que estén a punto de agregar o refactorizar funcionalidad en un repositorio JS/TS y deben evitar duplicar el código existente, incluso si el usuario no menciona explícitamente la deduplicación.
