Прежде чем менять общедоступную поверхность React Doctor, подумайте как менеджер по продукту — команды/флаги CLI, оценка 0–100, конфигурация (doctor.config.*), схема отчета JSON, API-интерфейсы пакета (inspect()/diagnose()), действие GitHub, веб-сайт и канонические подсказки. Пошаговое руководство для внесения изменений, ориентированных на пользователя: найдите поверхность, найдите кандидата на повторное использование, подключите одну метрику телеметрии, добавьте артефакты совместимости (набор изменений/схемаверсия/тег действия), обновите документы и запишите метрику уничтожения. Не для правил lint, у которых есть собственный конвейер. Также запускается, когда пользователь вводит `/product-thinking`.
