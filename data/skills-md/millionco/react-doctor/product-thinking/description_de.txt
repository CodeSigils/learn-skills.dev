Denken Sie wie ein Produktmanager, bevor Sie die öffentliche Oberfläche von React Doctor ändern – CLI-Befehle/Flags, den 0–100-Score, die Konfiguration (doctor.config.*), das JSON-Berichtsschema, Paket-APIs (inspect()/diagnose()), die GitHub-Aktion, die Website und die kanonischen Eingabeaufforderungen. Ein Schritt-für-Schritt-Runbook für eine benutzerseitige Änderung – suchen Sie die Oberfläche, suchen Sie nach einem Wiederverwendungskandidaten, verbinden Sie eine Telemetriemetrik, fügen Sie die Kompatibilitätsartefakte (Changeset/SchemaVersion/Aktionstag) hinzu, aktualisieren Sie Dokumente und zeichnen Sie eine Kill-Metrik auf. Nicht für Lint-Regeln, die über eine eigene Pipeline verfügen. Wird auch ausgeführt, wenn der Benutzer „/product-thinking“ eingibt.
