قم بمراجعة React Doctor مقابل ReactBench أو مجموعة معايير تشخيصية مماثلة بحثًا عن الإيجابيات الكاذبة المؤكدة والسلبيات الكاذبة وثغرات التصنيف وعناصر التحقق. يُستخدم عند تحليل rd.log، أو rd-before.json، أو rd-after.json، أو model.patch، أو result.json، أو سجلات المكافآت/الاختبار، أو توزيعات القواعد، أو عندما يُطلب منك إجراء تمريرة عدائية ثانية عبر نتائج اختبار React Doctor.
