قم بمراجعة وإصلاح تطبيقات Three.js وReact Three Fiber لأداء حلقة الإطار، وتسربات ذاكرة وحدة معالجة الرسومات، وتصحيح الرسم البياني للمشهد، والعيوب البصرية مثل z-fighting، وحب الشباب في الظل، ومساحة الألوان الخاطئة، ومعالجة تغيير الحجم المعطلة. يستخدم React Doctor كمحرك المسح بالإضافة إلى نموذج تقييم مرئي يتم فحصه مقابل المخرجات المقدمة. يُستخدم عندما يطلب المستخدم تحسين تطبيق Three.js أو R3F أو React-three-fiber أو drei أو WebGL أو تدقيقه أو فحصه أو تنظيفه، أو الأنواع `/improve-threejs`.
