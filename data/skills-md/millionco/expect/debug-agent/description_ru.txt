Систематическая отладка на основе фактических данных с использованием журналов времени выполнения. Генерирует гипотезы, обрабатывает код с помощью журналов NDJSON, направляет воспроизведение, анализирует данные журналов и выполняет итерации до тех пор, пока основная причина не будет доказана с помощью цитируемых строк журнала. Используйте, когда пользователь сообщает об ошибке, неожиданном поведении или просит отладить проблему.
