Systematisches evidenzbasiertes Debugging mithilfe von Laufzeitprotokollen. Erstellt Hypothesen, instrumentiert Code mit NDJSON-Protokollen, steuert die Reproduktion, analysiert Protokollbeweise und iteriert, bis die Grundursache anhand zitierter Protokollzeilen nachgewiesen ist. Verwenden Sie diese Option, wenn der Benutzer einen Fehler oder unerwartetes Verhalten meldet oder um die Behebung eines Problems bittet.
