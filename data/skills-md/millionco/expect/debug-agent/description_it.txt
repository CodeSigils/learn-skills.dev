Debug sistematico basato sull'evidenza utilizzando i log di runtime. Genera ipotesi, codifica gli strumenti con i log NDJSON, guida la riproduzione, analizza le prove dei log ed esegue l'iterazione finché la causa principale non viene dimostrata con le righe di log citate. Da utilizzare quando l'utente segnala un bug, un comportamento imprevisto o chiede di eseguire il debug di un problema.
