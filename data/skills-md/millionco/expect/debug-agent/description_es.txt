Depuración sistemática basada en evidencia utilizando registros de tiempo de ejecución. Genera hipótesis, instrumenta código con registros NDJSON, guía la reproducción, analiza la evidencia de registros e itera hasta que se prueba la causa raíz con las líneas de registro citadas. Úselo cuando el usuario informa un error, un comportamiento inesperado o solicita depurar un problema.
