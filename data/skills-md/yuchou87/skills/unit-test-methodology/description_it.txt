Genera sistematicamente test unitari applicando la metodologia di test per una copertura completa. Si attiva quando l'utente dice: "scrivi test unitari", "aggiungi test", "genera casi di test", "copertura del test", "come posso testarlo", "scrivi test per", "补充测试", "帮我写单元测试", "生成测试用例", "这个函数怎么测", "测试覆盖率不够", "写 test", "给这个方法加测试", "单测". A differenza della generazione di test ad hoc, questa abilità applica l'analisi-quindi-deriva: partiziona sistematicamente le classi di equivalenza per parametro, applica valori limite per input con intervallo, utilizza Pairwise per comprimere combinazioni per 4+ parametri e utilizza tabelle decisionali per rami multi-condizione. Ogni caso di test deve essere annotato con la sua tecnica di origine per garantire una copertura sistematica senza perdere scenari critici al contorno. Supporta Go/Python/Java/TypeScript/Rust. Si attiva anche quando l'utente dice semplicemente "scrivi un test".
