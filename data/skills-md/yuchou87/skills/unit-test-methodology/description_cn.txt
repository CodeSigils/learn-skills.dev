通过强制执行完整覆盖的测试方法来系统地生成单元测试。当用户说：“编写单元测试”、“添加测试”、“生成测试用例”、“测试覆盖率”、“我如何测试这个”、“编写测试”、“补充测试”、“帮我写单元测试”、“生成测试用例”、“这个函数怎么测”、“测试覆盖率不够”、“写测试”、“给这个方法加测试”、“单测”时触发。与临时测试生成不同，此技能强制分析然后推导：系统地划分每个参数的等价类，对范围输入应用边界值，使用 Pairwise 压缩 4 个以上参数的组合，并使用决策表进行多条件分支。每个测试用例都必须用其源技术进行注释，以保证系统覆盖而不会遗漏关键边界场景。支持 Go / Python / Java / TypeScript / Rust。即使用户只是说“编写测试”也会触发。
