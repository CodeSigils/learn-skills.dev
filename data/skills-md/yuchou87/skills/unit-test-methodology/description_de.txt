Generieren Sie systematisch Unit-Tests, indem Sie die Testmethodik für eine vollständige Abdeckung durchsetzen. Wird ausgelöst, wenn der Benutzer sagt: „Komponententests schreiben“, „Tests hinzufügen“, „Testfälle generieren“, „Testabdeckung“, „Wie teste ich das“, „Tests schreiben für“, „补充测试“, „帮我写单元测试“, „生成测试用例“, „这个函数怎么测“, „测试覆盖率不够“, „写 test“, „给这个方法加测试“, „单测“. Im Gegensatz zur Ad-hoc-Testgenerierung erzwingt dieser Skill das Analysieren und dann das Ableiten: Äquivalenzklassen systematisch nach Parametern aufteilen, Grenzwerte für Bereichseingaben anwenden, Paarweise verwenden, um Kombinationen für mehr als 4 Parameter zu komprimieren, und Entscheidungstabellen für Verzweigungen mit mehreren Bedingungen verwenden. Jeder Testfall muss mit seiner Quelltechnik annotiert werden, um eine systematische Abdeckung zu gewährleisten, ohne dass kritische Grenzszenarien übersehen werden. Unterstützt Go / Python / Java / TypeScript / Rust. Wird auch dann ausgelöst, wenn der Benutzer nur „Test schreiben“ sagt.
