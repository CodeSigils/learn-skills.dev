Систематически создавайте модульные тесты, применяя методологию тестирования для полного покрытия. Срабатывает, когда пользователь говорит: «написать модульные тесты», «добавить тесты», «создать тестовые примеры», «покрытие тестами», «как это протестировать», «написать тесты для», «补充测试», «帮我写单元测试», «生成测试用例», «这个函数怎么测», «测试覆盖率不够», «写 test», «给这个方法加测试», «单测». В отличие от специальной генерации тестов, этот Навык обеспечивает анализ, а затем вывод: систематическое разбиение классов эквивалентности на каждый параметр, применение граничных значений для ранжированных входных данных, использование парного сжатия комбинаций для более чем 4 параметров и использование таблиц решений для ветвей с несколькими условиями. Каждый тестовый пример должен быть аннотирован с указанием исходного метода, чтобы гарантировать систематическое покрытие без пропуска критических граничных сценариев. Поддерживает Go/Python/Java/TypeScript/Rust. Триггер, даже когда пользователь просто говорит «написать тест».
