Используйте этот навык всякий раз, когда пользователь просит разделить проверенный PRD на выполняемые задачи. Запуск по «фрагменту PRD», «разбивке PRD», «Созданию задач» и т. д. Создавайте небольшие вертикальные срезы с учетом зависимостей. Классифицируйте задачи на AFK (автономные) или HITL (требует участия человека). Предоставьте предложенную разбивку пользователю для обратной связи перед написанием задач. Запишите каждую задачу в отдельный файл Task-###.md в папке .lcs/work-items/<timestamp>-<slug-work-item>/task/.
