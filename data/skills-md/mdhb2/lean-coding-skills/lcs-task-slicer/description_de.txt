Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine überprüfte PRD in ausführbare Aufgaben aufteilen möchte. Auslösen bei „prd aufschneiden“, „prd aufschlüsseln“, „Aufgaben erstellen“ oder ähnliches. Erzeugen Sie kleine, abhängigkeitsbewusste vertikale Schnitte mit Leuchtspurgeschossen. Klassifizieren Sie Aufgaben in AFK (autonom) oder HITL (erfordert menschliche Eingabe). Präsentieren Sie dem Benutzer die vorgeschlagene Aufschlüsselung zur Rückmeldung, bevor Sie Aufgaben schreiben. Schreiben Sie jede Aufgabe in eine eigene Datei task-###.md unter .lcs/work-items/<timestamp>-<slug-work-item>/task/.
