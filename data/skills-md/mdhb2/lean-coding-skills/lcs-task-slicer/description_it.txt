Utilizza questa capacità ogni volta che l'utente chiede di suddividere un PRD revisionato in attività eseguibili. Attivazione su "slice prd", "break down prd", "crea attività" o simili. Produci sezioni verticali di proiettili traccianti piccoli e sensibili alle dipendenze. Classificare le attività in AFK (autonomo) o HITL (richiede input umano). Presentare la suddivisione proposta all'utente per ottenere feedback prima di scrivere le attività. Scrivi ogni attività nel proprio file task-###.md in .lcs/work-items/<timestamp>-<slug-work-item>/task/.
