Genere documentación de incorporación fácil de usar para desarrolladores para un proyecto en ejecución existente. Ejecútelo cuando el usuario solicite incorporar un proyecto, generar documentos iniciales del proyecto o resumir el código base para nuevos ingenieros. Escanea el repositorio, extrae arquitectura, puntos de entrada, instrucciones de configuración/ejecución/prueba y escribe informes de rebajas lean en .lcs/work-items/onboarding.md y .lcs/work-items/onboarding-map.md.
