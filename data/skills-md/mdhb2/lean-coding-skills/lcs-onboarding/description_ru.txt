Создайте удобную для разработчиков документацию по адаптации для существующего работающего проекта. Запускается, когда пользователь просит внедрить проект, создать раннюю документацию проекта или обобщить кодовую базу для новых инженеров. Сканирует репозиторий, извлекает архитектуру, точки входа, инструкции по настройке/запуску/тестированию и записывает отчеты с уменьшенной уценкой в ​​.lcs/work-items/onboarding.md и .lcs/work-items/onboarding-map.md.
