مرجع TanStack Query v5 (React Query) لجلب البيانات والتخزين المؤقت،
وإدارة حالة الخادم في React. يُستخدم عندما: (1) كتابة useQuery،
useMutation، أو خطافات useInfiniteQuery، (2) إعداد QueryClient
وqueryOptions، (3) تنفيذ التحديثات المتفائلة أو ذاكرة التخزين المؤقت
الإبطال، (4) تكوين SSR/الترطيب باستخدام جهاز توجيه تطبيق Next.js
أو جهاز توجيه الصفحات، (5) اختبار خطافات React Query، (6) العمل معها
أنواع TypeScript أو Suspense أو الأنماط المتقدمة مثل التابعة
الاستعلامات والتمرير اللانهائي.
