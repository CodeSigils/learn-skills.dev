Ejecuta una tarea, ya sea desde un archivo TASK_N.md o una descripción de formato libre. Úselo cuando: (1) implemente una tarea desde un archivo TASK_N.md, (2) el usuario proporcione una ruta de archivo de tarea o diga "ejecutar esta tarea", "implementar TASK_02" o "ejecutar esta tarea", (3) el usuario describe una tarea directamente sin un documento. Acepta una ruta de archivo o una descripción de formato libre: si al documento de la tarea le faltan las secciones requeridas (alcance, criterios de éxito, plan de verificación), llama automáticamente a /generate-tasks para generarlo antes de ejecutarlo.
