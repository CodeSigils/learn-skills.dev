Выполняет задачу либо из файла TASK_N.md, либо из описания в свободной форме. Используйте, когда: (1) реализует задачу из файла TASK_N.md, (2) пользователь указывает путь к файлу задачи или говорит «выполнить эту задачу», «реализовать TASK_02» или «запустить эту задачу», (3) пользователь описывает задачу напрямую, без документа. Принимает путь к файлу или описание в свободной форме — если в документе задачи отсутствуют необходимые разделы (объем, критерии успеха, план проверки), автоматически вызывает /generate-tasks для его создания перед выполнением.
