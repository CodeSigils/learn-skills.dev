Esegue un'attività, da un file TASK_N.md o da una descrizione in formato libero. Da utilizzare quando: (1) si implementa un'attività da un file TASK_N.md, (2) l'utente fornisce un percorso del file dell'attività o dice "esegui questa attività", "implementa TASK_02" o "esegui questa attività", (3) l'utente descrive un'attività direttamente senza un documento. Accetta un percorso file o una descrizione in formato libero: se nel documento dell'attività mancano le sezioni richieste (ambito, criteri di successo, piano di verifica), chiama automaticamente /generate-tasks per produrlo prima dell'esecuzione.
