Exécute une tâche, soit à partir d'un fichier TASK_N.md, soit d'une description de forme libre. À utiliser lorsque : (1) implémentez une tâche à partir d'un fichier TASK_N.md, (2) l'utilisateur fournit un chemin de fichier de tâche ou dit "exécuter cette tâche", "implémenter TASK_02" ou "exécuter cette tâche", (3) l'utilisateur décrit une tâche directement sans document. Accepte un chemin de fichier ou une description de forme libre — s'il manque des sections requises dans le document de tâche (portée, critères de réussite, plan de vérification), appelle automatiquement /generate-tasks pour le produire avant de l'exécuter.
