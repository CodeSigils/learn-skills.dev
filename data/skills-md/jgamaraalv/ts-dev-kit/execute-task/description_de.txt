Führt eine Aufgabe aus, entweder aus einer TASK_N.md-Datei oder einer Freiformbeschreibung. Verwenden Sie diese Option, wenn: (1) eine Aufgabe aus einer TASK_N.md-Datei implementiert wird, (2) der Benutzer einen Aufgabendateipfad angibt oder „diese Aufgabe ausführen“, „TASK_02 implementieren“ oder „diese Aufgabe ausführen“ sagt, (3) der Benutzer eine Aufgabe direkt ohne Dokument beschreibt. Akzeptiert einen Dateipfad oder eine Beschreibung in freier Form – wenn im Aufgabendokument erforderliche Abschnitte fehlen (Umfang, Erfolgskriterien, Überprüfungsplan), ruft es automatisch /generate-tasks auf, um es vor der Ausführung zu erstellen.
