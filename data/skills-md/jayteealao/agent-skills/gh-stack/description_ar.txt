قم بإدارة الفروع المكدسة وسحب الطلبات باستخدام ملحق gh-stack GitHub CLI. يُستخدم عندما يريد المستخدم إنشاء مجموعات من العلاقات العامة التابعة أو دفعها أو إعادة تأسيسها أو مزامنتها أو التنقل فيها أو عرضها. يتم تشغيل المهام التي تتضمن فروقًا مكدسة أو طلبات سحب تابعة أو سلاسل فرعية أو سير عمل مراجعة التعليمات البرمجية المتزايدة.
