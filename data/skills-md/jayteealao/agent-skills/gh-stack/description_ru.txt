Управляйте составными ветвями и запросами на включение с помощью расширения CLI GitHub gh-stack. Используйте, когда пользователь хочет создавать, отправлять, перебазировать, синхронизировать, перемещаться или просматривать стеки зависимых PR. Triggers on tasks involving stacked diffs, dependent pull requests, branch chains, or incremental code review workflows.
