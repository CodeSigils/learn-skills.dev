Machen Sie ein Repository Superset-bereit – erstellen Sie .superset/config.json mit Setup-/Teardown-/Run-Skripten, damit jeder neue Arbeitsbereich konfiguriert startet, und überprüfen Sie es dann mit einem echten Arbeitsbereich. Verwenden Sie diese Option, wenn der Benutzer ein Projekt oder Repo für Superset einrichten, Arbeitsbereich-Setup-Skripts konfigurieren oder ein fehlerhaftes Arbeitsbereich-Setup reparieren möchte.
