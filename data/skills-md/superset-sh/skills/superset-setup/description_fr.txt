Créez un référentiel prêt pour Superset : créez .superset/config.json avec des scripts de configuration/démontage/exécution pour que chaque nouvel espace de travail démarre configuré, puis vérifiez avec un espace de travail réel. À utiliser lorsque l'utilisateur souhaite configurer un projet ou un dépôt pour Superset, configurer des scripts de configuration d'espace de travail ou corriger une configuration d'espace de travail défaillante.
