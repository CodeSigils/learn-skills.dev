Crea un repository pronto per Superset: crea .superset/config.json con script di installazione/smontaggio/esecuzione in modo che ogni nuova area di lavoro venga avviata configurata, quindi verifica con un'area di lavoro reale. Da utilizzare quando l'utente desidera impostare un progetto o un repository per Superset, configurare gli script di impostazione dell'area di lavoro o correggere una configurazione dell'area di lavoro non riuscita.
