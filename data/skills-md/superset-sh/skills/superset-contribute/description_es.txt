Configure una contribución de código abierto de Superset: bifurque y clone superset-sh/superset, ejecute la configuración de desarrollo local y siga las reglas de contribución del repositorio hasta obtener un PR listo para fusionar. Úselo cuando el usuario quiera contribuir a Superset, corregir un error de Superset por sí mismo o preparar un PR contra superset-sh/superset.
