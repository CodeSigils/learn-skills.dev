Assistant SQL multi-bases de données — requête MySQL, PostgreSQL, SQLite et MariaDB
dans les environnements dev/test/prod avec une seule commande.
La sécurité d'abord : lecture seule par défaut, contrôle DML/DDL, analyse EXPLAIN.
Il s'agit d'une application MySQL/PostgreSQL/SQLite/MariaDB basée sur MySQL/PostgreSQL/SQLite/MariaDB.
