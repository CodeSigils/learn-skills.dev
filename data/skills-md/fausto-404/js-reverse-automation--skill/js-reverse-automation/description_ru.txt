Подключитесь к реальному браузеру через chrome-devtools-mcp, проследите цепочку генерации знака/enc/токена, определите функции и зависимости входа во время выполнения, затем сгенерируйте код внедрения JSRPC, код прокси-сервера Flask и документацию по интеграции автодекодера Burp с выводом проверки — этот навык создает только соответствующий код и не будет проверять неавторизованные цели.
