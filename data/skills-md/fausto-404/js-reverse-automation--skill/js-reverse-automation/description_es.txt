Utilice chrome-devtools-mcp para conectarse a un navegador real, rastrear la cadena de generación de sign/enc/token, identificar la función de entrada en tiempo de ejecución y sus dependencias, luego generar código de inyección JSRPC, código proxy Flask y un documento de integración Burp autoDecoder con salida de verificación; esta habilidad solo produce el código correspondiente y no probará objetivos no autorizados.
