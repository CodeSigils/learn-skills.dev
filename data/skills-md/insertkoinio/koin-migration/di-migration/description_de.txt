Automatisieren Sie die Migration zwischen Kotlin/Android-Dependency-Injection-Frameworks. Behandelt Griff → Koin, Dolch → Koin, Zahnstocher → Koin, Kodein → Koin, Koin 3.x → Koin 4.x-Upgrades, Koin DSL → Koin 4.x Safe DSL mit Compiler-Plugin und Koin KSP-Anmerkungen → Koin Compiler-Plugin. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer die Migration, Konvertierung oder den Wechsel von DI-Frameworks, die Umgestaltung von Hilt/Dagger/Toothpick/Kodein zu Koin, das Entfernen von Hilt/Dagger/Toothpick/Kodein, die Aktualisierung von Koin-Versionen, die Migration von klassischem Koin DSL zu Koin Safe DSL oder Annotationen mit dem Compiler Plugin oder den Wechsel von KSP-basierten Annotationen zum Koin Compiler Plugin erwähnt. Wird auch ausgelöst, wenn der Benutzer Hilt/Dagger/Toothpick/Kodein-Modulcode einfügt und um Konvertierung bittet, wenn er eine Kompilierzeitüberprüfung für Koin-Module wünscht oder wenn er „Abhängigkeitsinjektionsmigration“, „Hilt durch Koin ersetzen“, „von Dagger entfernen“, „von Toothpick migrieren“, „von Kodein migrieren“, „Kodein zu Koin“, „DSL in Annotationen konvertieren“, „Koin-Compiler hinzufügen“, „Koin KSP“ erwähnt. „Koin-Compiler-Plugin“, „KSP entfernen“, „Zum Koin-Compiler verschieben“ oder jede Variation, die DI-Framework-Änderungen in Kotlin-/Android-/KMP-Projekten beinhaltet. Für Greenfield-Projekte oder manuellen DI-Code ist diese Fähigkeit nicht erforderlich – verweisen Sie den Benutzer auf die offiziellen Koin-Dokumente unter https://insert-koin.io und wenden Sie dieselben Safe DSL + Compiler Plugin-Regeln direkt an.
