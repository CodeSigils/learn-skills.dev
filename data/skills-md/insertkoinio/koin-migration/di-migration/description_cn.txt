在 Kotlin/Android 依赖注入框架之间自动迁移。涵盖 Hilt → Koin、Dagger → Koin、Toothpick → Koin、Kodein → Koin、Koin 3.x → Koin 4.x 升级、Koin DSL → Koin 4.x 带编译器插件的安全 DSL，以及 Koin KSP Annotations → Koin 编译器插件。每当用户提到迁移、转换或切换 DI 框架、从 Hilt/Dagger/Toothpick/Kodein 重构到 Koin、删除 Hilt/Dagger/Toothpick/Kodein、升级 Koin 版本、从经典 Koin DSL 迁移到 Koin Safe DSL 或使用编译器插件的注释，或者从基于 KSP 的注释迁移到 Koin 编译器插件时，请使用此技能。当用户粘贴 Hilt/Dagger/Toothpick/Kodein 模块代码并要求转换它时，当他们想要对 Koin 模块进行编译时验证时，或者当他们提到“依赖注入迁移”、“用 Koin 替换 Hilt”、“远离 Dagger”、“从 Toothpick 迁移”、“从 Kodein 迁移”、“Kodein 到 Koin”、“将 DSL 转换为注释”、“添加 Koin 编译器”时，也会触发“Koin KSP”、“Koin 编译器插件”、“删除 KSP”、“移至 Koin 编译器”或涉及 Kotlin/Android/KMP 项目中 DI 框架更改的任何变体。对于新建项目或手动 DI 代码，不需要此技能 - 将用户指向 https://insert-koin.io 的官方 Koin 文档，并直接应用相同的 Safe DSL + 编译器插件规则。
