在 Kotlin/Android 依賴注入框架之間自動遷移。涵蓋 Hilt → Koin、Dagger → Koin、Toothpick → Koin、Kodein → Koin、Koin 3.x → Koin 4.x 升級、Koin DSL → Koin 4.x 帶編譯器插件的安全 DSL，以及 Koin KSP Annotations → Koin 編譯器插件。每當使用者提到遷移、轉換或切換 DI 框架、從 Hilt/Dagger/Toothpick/Kodein 重構到 Koin、刪除 Hilt/Dagger/Toothpick/Kodein、升級 Koin 版本、從經典 Koin DSL 遷移到 Koin Safe DSL 或使用此技能插件的註釋，或從基於 KSP 的註釋器遷移到 Koin.當使用者貼上 Hilt/Dagger/Toothpick/Kodein 模組程式碼並要求轉換它時，當他們想要對 Koin 模組進行編譯時驗證時，或者當他們提到“依賴注入遷移”、“用 Koin 替換 Hilt”、“遠離 Dagger”、“從 Toothpick 遷移”、“從 Kodein 遷移”、“遠離 Dagger”、“從 Toothpick 遷移”、“從 Kodein 遷移”、“Kinodein”編譯器」時，也會觸發「Koin KSP」、「Koin 編譯器插件」、「刪除 KSP」、「移至 Koin 編譯器」或涉及 Kotlin/Android/KMP 專案中 DI 框架變更的任何變體。對於新建專案或手動 DI 程式碼，不需要此技能 - 將使用者指向 https://insert-koin.io 的官方 Koin 文檔，並直接套用相同的 Safe DSL + 編譯器插件規則。
