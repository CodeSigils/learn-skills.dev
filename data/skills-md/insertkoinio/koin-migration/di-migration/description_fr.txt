Automatisez la migration entre les frameworks d'injection de dépendances Kotlin/Android. Couvre Hilt → Koin, Dagger → Koin, Toothpick → Koin, Kodein → Koin, Koin 3.x → Koin 4.x mises à niveau, Koin DSL → Koin 4.x Safe DSL avec plugin de compilateur et Koin KSP Annotations → Koin Compiler Plugin. Utilisez cette compétence chaque fois que l'utilisateur mentionne la migration, la conversion ou le changement de framework DI, la refactorisation de Hilt/Dagger/Toothpick/Kodein vers Koin, la suppression de Hilt/Dagger/Toothpick/Kodein, la mise à niveau des versions de Koin, la migration du Koin DSL classique vers Koin Safe DSL ou des annotations avec le plug-in du compilateur, ou le passage des annotations basées sur KSP au plug-in du compilateur Koin. Se déclenche également lorsque l'utilisateur colle le code du module Hilt/Dagger/Toothpick/Kodein et demande de le convertir, lorsqu'il souhaite une vérification à la compilation pour les modules Koin, ou lorsqu'il mentionne "migration par injection de dépendances", "remplacer Hilt par Koin", "s'éloigner de Dagger", "migrer depuis Toothpick", "migrer de Kodein", "Kodein vers Koin", "convertir DSL en annotations", "ajouter un compilateur Koin", "Koin KSP", "Plugin du compilateur Koin", "supprimer KSP", "passer au compilateur Koin" ou toute variante impliquant des modifications du framework DI dans les projets Kotlin/Android/KMP. Pour les nouveaux projets ou le code DI manuel, cette compétence n'est pas nécessaire - dirigez l'utilisateur vers la documentation officielle de Koin sur https://insert-koin.io et appliquez directement les mêmes règles du plug-in Safe DSL + Compiler.
