أتمتة الترحيل بين أطر حقن التبعية Kotlin/Android. يغطي Hilt → Koin، Dagger → Koin، Toothpick → Koin، Kodein → Koin، Koin 3.x → Koin 4.x ترقيات، Koin DSL → Koin 4.x Safe DSL مع البرنامج المساعد للمترجم، وتعليقات Koin KSP → Koin Compiler Plugin. استخدم هذه المهارة عندما يذكر المستخدم ترحيل أطر عمل DI أو تحويلها أو تبديلها، أو إعادة البناء من Hilt/Dagger/Toothpick/Kodein إلى Koin، أو إزالة Hilt/Dagger/Toothpick/Kodein، أو ترقية إصدارات Koin، أو الانتقال من Koin DSL الكلاسيكي إلى Koin Safe DSL أو التعليقات التوضيحية باستخدام Compiler Plugin، أو الانتقال من التعليقات التوضيحية المستندة إلى KSP إلى Koin Compiler Plugin. يتم تشغيله أيضًا عندما يقوم المستخدم بلصق رمز وحدة Hilt/Dagger/Toothpick/Kodein ويطلب تحويله، عندما يريد التحقق من وقت الترجمة لوحدات Koin، أو عندما يذكر "ترحيل حقن التبعية"، "استبدال Hilt بـ Koin"، "الابتعاد عن Dagger"، "الترحيل من Toothpick"، "الترحيل من Kodein"، "Kodein إلى Koin"، "تحويل DSL إلى تعليقات توضيحية"، "إضافة مترجم Koin"، "Koin KSP"، أو "المكون الإضافي لمترجم Koin"، أو "إزالة KSP"، أو "الانتقال إلى مترجم Koin"، أو أي اختلاف يتضمن تغييرات إطار عمل DI في مشاريع Kotlin/Android/KMP. بالنسبة للمشاريع الجديدة أو كود DI اليدوي، ليست هناك حاجة لهذه المهارة - قم بتوجيه المستخدم إلى مستندات Koin الرسمية على https://insert-koin.io وقم بتطبيق نفس قواعد Safe DSL + Compiler Plugin مباشرة.
