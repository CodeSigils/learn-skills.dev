Der KI-Bildbearbeitungs-Router – Inpainting/Objektentfernung, Hintergrundentfernung, Hochskalierung, Outpainting, Wiederherstellung alter Fotos und Retusche – leitet die Aufgabe zuerst an die richtige Engine weiter. Verwenden Sie diese Funktion, wenn jemand ein Objekt/eine Person aus einem Foto entfernen, Hintergründe ausschneiden, ein Bild hochskalieren, ein Bild auf neue Seitenverhältnisse erweitern, ein altes Foto wiederherstellen, ein generiertes Bild reparieren möchte oder fragt, welches Bearbeitungswerkzeug verwendet werden soll. Verwendet das TOUCH-Framework. Liest zuerst das Markenprofil + Design und Vorlagen. Der Agent benennt die Aufgabe, leitet sie an die richtige Engine weiter, schreibt die Spezifikation und kann APIs aufrufen, sofern eine Verbindung besteht. der MENSCH beurteilt jedes Ergebnis zu 100 %; WoopSocial veröffentlicht. Ehrlichkeit: Ein bearbeitetes echtes Foto ist eine bearbeitete Behauptung – kreative Upscaler halluzinieren Details (niemals auf Produkten/Dokumenten), keine Verschleierung von Mängeln, Offenlegung von Körperretuschen wird akzeptiert, kein Entfernen von Wasserzeichen/Herkunft. Unterscheidet sich von image-prompt/flux/nano-banana (Generierung), Canva (dem Design-Workflow) und Vorher-Nachher-und-Transformation (den Anspruchsregeln).
