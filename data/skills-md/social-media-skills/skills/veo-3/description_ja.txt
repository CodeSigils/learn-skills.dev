Google Veo (Veo 3.1) でソーシャル メディア用のビデオを生成またはアニメーション化するための優れたプロンプトを作成するために使用します。ビデオ プロンプト クラフト ミニスキルは、ビデオのナノバナナに相当します。ユーザーが Veo / AI ビデオ プロンプト、投稿用の短いビデオ クリップ (B ロール、モーション製品、フック ビジュアル、広報担当者/UGC クリップ、広告)、静止画をビデオにアニメーション化する場合、または垂直のリール/TikTok/ショート クリップを必要とする場合に実行します。ブランド スタイルについてはブランド プロフィールを読み取ります。 Veo の優れている点は、ワン パスでのネイティブ同期オーディオに加え、画像からビデオへの変換とネイティブ 9:16 垂直変換です。プロンプトの構造、音声プロンプト、画像からビデオへのパイプライン、および 8 秒の制約 + 拡張/スティッチングについて説明します。正直: 安価に繰り返してからファイナライズし、AI ビデオ (SynthID ウォーターマーク) を公開し、実際の個人を特定できる人物や著作権で保護された IP を生成することはありません。これはプロンプト クラフト レイヤーです。API/接続と生成 -> WoopSocial Media へのアップロード -> フローを tools/integrations/veo.md にライブで添付します。使用するパックは、reels-script の veo-prompt-pack です。
