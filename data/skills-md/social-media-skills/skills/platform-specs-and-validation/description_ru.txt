Спецификации платформы и проверка публикации — требования для каждой платформы и этап проверки перед публикацией для развертывания на нескольких платформах. Используйте при распределении публикации на несколько платформ, когда публикация отклоняется, при сопоставлении полей postType/обязательных полей для каждой платформы или для запуска шага проверки перед публикацией. Кодирует перечисления postType для каждой платформы, матрицы обязательных полей и правила мультимедиа из спецификации OpenAPI и запускает POST /posts/validate, чтобы сообщение правильно попадало в каждую цель. Использует структуру CHECK. Краеугольный камень, на который указывают навыки работы с форматами для каждой платформы. WoopSocial проверяет + публикует атомарно и не имеет конечной точки обновления; агент отображает поля и исправляет нарушения спецификаций, но требования человеческого суждения (правдивость раскрытия информации, намерение конфиденциальности) остаются за человеком; метрики никогда не выдумывались. В отличие от навыков формата для каждой платформы (контент одной платформы) и планирования и очереди (времени).
