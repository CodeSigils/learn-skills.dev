Runway السريع والمباشر (Gen-4.5, Aleph) - أداة الفيديو التوليدية بدرجة التحكم لتحركات الكاميرا، وتناسق الشخصية، ولقطات درجة التحرير. يُستخدم عندما يريد شخص ما "حركة كاميرا محددة"، أو "نفس الشخصية عبر لقطات متعددة"، أو "لتحرير/إعادة تصميم اللقطات الموجودة"، أو "لقطة إعلانية/منتج يحمل علامة تجارية"، أو "معاينة بنمط فيلم"، أو "صورة إلى فيديو باستخدام Runway" (تحريك صورة ثابتة)، أو أسماء Runway / Gen-4 / Gen-4.5 / Aleph / Act-Two / Motion Brush / References. المدرج يولد مقاطع. إنسان يجمع/يحرر؛ الصوت يأتي من التعليق الصوتي بالذكاء الاصطناعي؛ جداول / منشورات WoopSocial. أسفل جهاز توجيه الفيديو المدعم بالذكاء الاصطناعي، وهو شقيق veo-3 (صوت شامل + أصلي)، وkling (دقة 4K أصلية/لقطة متعددة/حركة)، وluma (تقنية HDR/الحالة المزاجية السينمائية). العروض المتفق عليها فقط (الفصل الثاني)؛ الكشف عن الذكاء الاصطناعي إلزامي.
