Используйте, чтобы написать зацепку — начало, которое привлекает внимание — для любого социального контента: первая строка подписи, первые три секунды видео, титульный слайд карусели, начало темы, заголовок YouTube или тема электронного письма. Запускайте, когда пользователь говорит «напишите привязку», «прицепите для этого», «первую строку», «первые три секунды», «защитный слайд», «сделайте эту остановку прокрутки» или когда хороший контент продолжает игнорироваться. Сначала читает профиль и голос бренда, поэтому хуки звучат как бренд, а не шаблоны вирусной приманки. Хуки должны быть ВЕРНЫМИ для последующего контента — этот навык извлекает крючок из самого сильного элемента сообщения и никогда не дает завышенных обещаний. Для полных подписей используйте caption-writer; для полных видеосценариев используйте навыки работы с видео. Об этом пишет само открытие.
