Úselo para escribir el gancho (la apertura que llama la atención) para cualquier contenido social: la primera línea de un título, los primeros tres segundos de un video, una diapositiva de portada de carrusel, una apertura de hilo, un título de YouTube o el asunto de un correo electrónico. Ejecútalo cuando el usuario diga "escribe un gancho", "gancho para esto", "línea de apertura", "primeros tres segundos", "portada", "haz que esto se detenga" o cuando se siga ignorando el buen contenido. Lee primero el perfil de la marca y la voz para que los ganchos suenen como la marca, no como plantillas de cebo viral. Los ganchos deben ser VERDADEROS con respecto al contenido que sigue: esta habilidad extrae el gancho del elemento más fuerte de la publicación y nunca hace promesas excesivas. Para subtítulos completos utilice caption-writer; para guiones de vídeo completos utilice las habilidades de vídeo. Esto escribe la apertura misma.
