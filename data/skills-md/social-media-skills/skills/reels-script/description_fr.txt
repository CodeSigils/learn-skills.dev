Utilisez-le pour écrire un script Instagram Reels : un script vidéo court natif, sans son en premier, optimisé pour le moteur de découverte d'Instagram, construit autour d'un hook, d'une visualisation et d'un envoi de 3 secondes (partages DM). Exécuté lorsque l'utilisateur dit « script Reels », « Instagram Reel », « créer une bobine », « Reel hook », « bobine d'essai » ou souhaite une vidéo courte pour Instagram spécifiquement. Lit le profil de la marque et la voix en premier ; écrit d'abord la version muette ; structures de surveillance + envois ; place des mots-clés de recherche IG ; sélectionne l'audio original par rapport aux tendances (l'audio tendance est ajouté nativement dans l'application - pas via WoopSocial) ; informe le cadre de couverture ; génère un document de production (prise de vue - texte à l'écran - parole - audio - timing) ainsi qu'un pack d'invites Veo pour les prises de vue sans visage/b-roll. Le métier de scripteur générique réside dans le script vidéo court ; pour TikTok, utilisez tiktok-script ; pour les courts métrages, utilisez des shorts youtube ; remet la légende à l'auteur de la légende, publie la publication sur les bobines instagram et la planification à la planification et à la file d'attente.
