Используйте для написания сценария Instagram Reels — собственного сценария короткого видео без звука, оптимизированного для механизма обнаружения Instagram, построенного на основе 3-секундного перехвата, просмотра и отправки (поделиться в DM). Запускается, когда пользователь говорит «Сценарий Reels», «Рост Instagram», «Создать ролик», «Привязка к ролику», «Пробный ролик» или хочет короткое видео специально для Instagram. Сначала читает профиль бренда и его голос; сначала записывает приглушенную версию; структуры для сквозного просмотра + отправки; размещает ключевые слова IG-поиска; выбирает оригинальный и популярный звук (трендовый звук добавляется в приложение, а не через WoopSocial); закрывает рамку чехла; выводит производственный документ (кадр — текст на экране — речь — аудио — синхронизация), а также пакет подсказок Veo для безликих кадров или кадров в ролике. Общее мастерство написания сценариев живет в коротких видеосценариях; для ТикТока используйте тикток-скрипт; для коротких видео используйте YouTube-короткие видео; передает подпись автору подписей, публикацию — публикации роликов в Instagram, а планирование — планированию и очереди.
