La compétence de publication de métadonnées YouTube. À utiliser lorsque quelqu'un souhaite « écrire un titre/description YouTube », « définir des balises/catégories/confidentialité », « optimiser le référencement/métadonnées YouTube », définir des paramètres conçus pour les enfants ou publier une vidéo YouTube via WoopSocial. Écrit les métadonnées (titre, description + chapitres, balises) et définit la catégorie/confidentialité/madeForKids — YouTube est un moteur de recherche, donc les métadonnées sont la rampe de lancement, et madeForKids est un indicateur légal COPPA/FTC défini de manière véridique. Utilise le framework INDEX. Lit d'abord le profil de la marque + les objectifs et les KPI + le script/la vidéo. Le fichier vidéo + le script sont des entrées (pas WoopSocial) ; les tests de vignettes et de titres A/B sont natifs de YouTube Studio ; WoopSocial publie via les champs YouTube ; des mesures jamais fabriquées. Distinct de youtube-long-form/youtube-shorts (le script) et de miniature-design (la vignette).
