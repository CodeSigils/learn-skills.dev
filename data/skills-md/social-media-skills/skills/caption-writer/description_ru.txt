Используйте для написания подписей в социальных сетях (копий постов), адаптированных для платформы, голосом бренда — слов, которые сопровождают посты в Instagram, LinkedIn, TikTok, Facebook, X/Twitter, Threads, Pinterest, YouTube или Bluesky. Запускается, когда пользователь говорит: «Напишите подпись», «Подпишите это», «Опубликовать копию», «Напишите копию для этой фотографии/видео/ролика», «Подпись в IG», «Что мне написать для этого поста» или ему нужно, чтобы слова сочетались с визуальным эффектом. Сначала считывает профиль бренда и голос, поэтому подписи звучат как бренд, а не как обычный искусственный интеллект. Для длинных постов LinkedIn, посвященных лидерству идей, используйте linkedin-post-writer; для многопостовых потоков X/Threads используйте thread-writer; для видеоскриптов используйте навыки работы с видео. Этот навык пишет сам заголовок.
