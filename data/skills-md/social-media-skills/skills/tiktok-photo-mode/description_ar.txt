مهارة تنفيذ تنسيق TikTok Photo Mode. يُستخدم عندما يريد شخص ما "دوامة صور TikTok"، أو "وضع الصورة"، أو "عرض شرائح TikTok"، أو "منشور TikTok قابل للتمرير"، أو لنشر منشور TikTok متعدد الصور عبر WoopSocial (postType PHOTO). ينشئ عرضًا دائريًا أصليًا لـ TikTok يفوز بمعدل الاكتمال - شريحة الخطاف 1، والكشف التدريجي مع cliffhangers، والمكافأة + CTA واحدة - ويحدد التكوين الدقيق لنشر WoopSocial PHOTO (الخصوصية، والتعليقات، والموسيقى، وإشارات الكشف الصادقة). يستخدم إطار SWIPE. يقرأ ملف تعريف العلامة التجارية + الأهداف ومؤشرات الأداء الرئيسية أولاً. يقوم الوكيل بكتابة خطة الشريحة + نسخة التراكب + التسمية التوضيحية + التكوين؛ يتم إنشاء الصور بواسطة مهارة بشرية/صورة، وليس بواسطة WoopSocial؛ تنشر WoopSocial منشور الصور الأصلي؛ لم يتم تصنيع المقاييس مطلقًا ولم يتم الوعد أبدًا بوضع الصورة باعتباره اختراقًا للوصول. يختلف عن نص tiktok (الفيديو) والكاتب الدائري (النسخ عبر الأنظمة الأساسية).
