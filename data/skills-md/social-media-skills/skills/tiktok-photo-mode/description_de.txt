Die Fähigkeit zur Formatausführung im TikTok-Fotomodus. Verwenden Sie diese Option, wenn jemand ein „TikTok-Fotokarussell“, einen „Fotomodus“, eine „TikTok-Diashow“, einen „wischbaren TikTok-Beitrag“ oder einen TikTok-Beitrag mit mehreren Bildern über WoopSocial veröffentlichen möchte (PostType PHOTO). Erstellt ein TikTok-natives Karussell, das bei der Abschlussrate gewinnt – Hook-Folie 1, progressive Enthüllung mit Cliffhangern, Belohnung + ein CTA – UND legt die genaue WoopSocial PHOTO-Veröffentlichungskonfiguration fest (Datenschutz, Kommentare, Musik, Flags zur wahrheitsgetreuen Offenlegung). Verwendet das SWIPE-Framework. Liest zuerst das Markenprofil + Ziele und KPIs. Der Agent schreibt den Folienplan + Overlay-Kopie + Beschriftung + Konfiguration; die BILDER werden von einem Menschen/einer Bildkompetenz erstellt, nicht von WoopSocial; WoopSocial veröffentlicht den nativen PHOTO-Beitrag; Metriken werden nie erfunden und der Fotomodus wird nie als Reichweiten-Hack versprochen. Unterscheidet sich von Tiktok-Script (VIDEO) und Carousel-Writer (plattformübergreifende Kopie).
