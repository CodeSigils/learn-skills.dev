Le manuel de croissance X/Twitter pour 2026. À utiliser lorsque quelqu'un souhaite « grandir sur X/Twitter », « obtenir plus de portée/abonnés/impressions sur X », « une stratégie de contenu/publication X », « devrais-je obtenir X Premium », « comment fonctionne l'algorithme X » ou comment utiliser les réponses/citations/publications/versions longues/vidéo pour se développer. La conversation est le moteur (réponses et vitesse de la première heure), Premium est en fait une référence et les liens sont placés dans la première réponse. Utilise le framework SPARK. Lit d'abord le profil de marque et le générateur de voix. L'agent rédige les messages + copie de réponse ; un humain répond en direct, cite les messages et s'engage auprès de la communauté ; WoopSocial planifie les publications ; les métriques proviennent d’analyses X natives ; rien n'est fabriqué. Complète le thread-writer (artisanat au format fil).
