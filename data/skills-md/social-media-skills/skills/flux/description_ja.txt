FLUX クラフト スキル (Black Forest Labs) — 適切なバリアントとライセンスを使用してブランド画像を生成および編集します。 FLUX/FLUX.2/Kontext を使用して画像を生成する場合、生成された画像を編集する場合、キャンペーン全体でキャラクターや製品の一貫性を維持する場合、画像内の読みやすいテキストをレンダリングする場合、ブランドに忠実な色を取得する場合、FLUX のバリエーションを選択する場合、または FLUX の使用が商用ライセンスされているかどうかを尋ねる場合に使用します。 PIXELフレームワークを使用します。最初に画像プロンプト + ブランド プロフィール + デザインとテンプレートを読み取ります。エージェントはプロンプト/編集指示を作成し、接続されている場所で API を呼び出すことができます。人間はあらゆるイメージを判断します。 WoopSocialが公開しています。ライセンススパイン: [dev] 出力は商用OKですが、商用サービスのセルフホスティングには有料の BFL 層が必要です。 Apache-2.0 のパスは [schnell]/[klein] 4B です。許可されていない肖像を使用したり、トレードドレスを複製したり、出自を剥奪したり、統計をでっち上げたりしないでください。 image-prompt、ideogram/nano-banana/Midjourney (兄弟ツール)、ai-image-editing (これがフィードする編集ルーター)、canva とは異なります。
