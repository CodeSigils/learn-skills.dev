Das Meisterhandwerk des eigenständigen Textbeitrags/Microblogs (LinkedIn, X/Twitter, Threads, Bluesky, Facebook-Textbeiträge). Verwenden Sie diese Option, wenn jemand einen Textbeitrag, einen LinkedIn-Beitrag, ein kurzes schriftliches Update oder einen Mikroblog schreiben oder einen Beitrag reparieren möchte, der gefloppt ist / sich wie eine Textwand liest / eine schwache Eröffnungszeile hat. Ein Textbeitrag hat nichts zu verbergen – die Wörter sind alles und die ersten ca. 140–210 Zeichen (die „Mehr anzeigen“-Falte) machen den größten Teil der Arbeit aus. Verwendet das LINES-Framework. Liest zuerst Markenprofil + Voice-Builder + Hook-Autor; zieht das „Was“ aus den Fähigkeiten im Hinblick auf den Inhalt. Der Agent schreibt den Beitrag; der Mensch stimmt zu; WoopSocial veröffentlicht auf unterstützten Plattformen und leitet Einzelheiten an LinkedIn-Post-Writer / Threads-Post / Thread-Writer weiter. NIEMALS Statistiken/Geschichten/Metriken erfinden oder Engagement-Köder verwenden; vermeidet AI-Slop-Überformatierung. Keine nativen Multi-Post-Threads; Reddit/Mastodon dienen nur der Beratung. Unterscheiden Sie sich von den Fähigkeiten zum Verfassen von Untertiteln, Threads und den Inhaltsaspekten (WAS vs. dieses WIE).
