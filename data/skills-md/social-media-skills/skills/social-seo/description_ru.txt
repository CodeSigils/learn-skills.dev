Используйте, чтобы сделать социальный контент доступным для поиска через ПОИСК на социальных платформах — навык социального SEO / обнаружения ключевых слов. Запускайте, когда пользователь говорит «социальное SEO», «находятся в поиске», «SEO для TikTok», «SEO для YouTube», «ключевые слова для социальных сетей», «подписи с возможностью поиска» или хочет выполнять поиск на разных платформах, а не только в ленте. Для глубины единой платформы направьте «Instagram SEO» на instagram-seo, и Pinterest запросит pinterest-seo; этот навык владеет кросс-платформенной структурой. В первую очередь читает профиль бренда и аудиторию. Все платформы являются поисковыми системами; ключевые слова, а не хэштеги, являются рычагом. Охватывает проиндексированные поверхности для каждой платформы, исследование ключевых слов с помощью автозаполнения + встроенная аналитика (никогда не создает объемы), технику тройного упоминания, тематические кластеры и профиль как поисковый ресурс. Направляет хэштеги в стратегию хэштегов; передает уровень AI-поиска/LLM-цитирования (GEO) ИИ-поисковой оптимизации. Измеряется с помощью встроенной поисковой аналитики, а не аналитики WoopSocial.
