Das Handwerk, ein einzelnes Zitat, eine Zeile oder eine Statistik in eine gestaltete typografische Grafik umzuwandeln – Zitatkarten, Pull-Quotes, Text-auf-Bild, Statistikkarten, Typografiebeiträge. Verwenden Sie es, wenn jemand eine Zitatkarte, eine Textgrafik, ein Zitat oder eine Statistikkarte möchte oder eine starke Linie in ein gemeinsam nutzbares Bild umwandeln möchte. Das Design verstärkt eine starke Linie; es kann keinen erstellen. Verwendet das QUOTE-Framework. Liest zuerst Markenprofil + Design-und-Vorlagen + Voice-Builder und zieht die Grenze zwischen Hook-Writer, Storytelling oder Daten-und-Original-Recherche (eine Statistik). Der Agent wählt die Zeile aus und gibt die Karte an; ein Design-Tool rendert; der Mensch stimmt zu; WoopSocial veröffentlicht das Bild (es generiert keine Medien).
