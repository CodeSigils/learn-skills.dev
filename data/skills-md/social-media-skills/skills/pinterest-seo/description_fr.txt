La compétence Pinterest SEO / search-ranking - la couche de mots clés qui s'associe au visuel de pinterest-pin-design. À utiliser lorsque quelqu'un souhaite que les épingles soient classées dans la recherche Pinterest, a besoin d'une recherche de mots clés ou souhaite des titres/descriptions/tableaux d'épingles optimisés pour les mots clés. Pinterest est un moteur de recherche visuel où les mots-clés et la pertinence vous classent, et non vos abonnés. Utilise le framework FOUND. Lit d'abord le profil de la marque + la destination de l'épingle. L'agent recherche des requêtes réelles (complétion automatique + recherche guidée + tendances ; ne fabrique jamais de volume), écrit le titre par mot-clé + une description naturelle (pas de bourrage), spécifie le mot-clé de superposition sur l'épingle et conseille les tableaux + lien. WoopSocial publie le titre de l'épingle + la description + le tableau + le lien ; le profil/bio, la configuration du tableau, le texte alternatif, les épingles enrichies et les tendances/analyses restent natifs/humains. Pas de farce ; Épingle->Tableau->La page doit correspondre ; des épingles fraîches, pas des dupes. Distinct de Pinterest-pin-design (le visuel), Pinterest-growth (la stratégie) et social-seo (recherche transversale).
