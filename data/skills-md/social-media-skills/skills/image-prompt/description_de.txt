Verwenden Sie es als Grundlage und Router für jedes Bild, das ein Beitrag benötigt – verwandeln Sie ein soziales Bedürfnis in ein klares Bild-Briefing, beschreiben Sie es mit modellunabhängigem Prompt Craft und leiten Sie es zum richtigen Tool weiter. Wird ausgeführt, wenn der Benutzer sagt: „Ich benötige ein Bild/Bild für diesen Beitrag“, „Welches Bild soll ich verwenden“, „Erstelle eine Grafik“, „Hilf mir, ein Bild anzufordern“ oder nicht sicher ist, welches Bildwerkzeug/-modell er verwenden soll. Liest das Markenprofil für die visuelle Marke. Vermittelt die Bildbeschreibung, die universelle Anatomie einer starken Eingabeaufforderung in natürlicher Sprache und einen Werkzeugrouter (typografisch -> Ideogramm/Nano-Banane; Fotoreal -> Nano-Banane/Flussmittel; surreal -> Midjourney; Bearbeitung -> Nano-Banane/Flussmittel; Vektor -> Recraft; Video -> Veo-3). Enthält ein „Sollte dies überhaupt KI-generiert sein?“ Gate (ein echtes Foto, ein echter Screenshot oder ein Diagramm ist oft besser als generische KI), Zugänglichkeit und ehrlicher Umfang (KI offenlegen, niemals echte identifizierbare Personen oder urheberrechtlich geschütztes geistiges Eigentum, Text/Daten überprüfen). Hände weg von den werkzeugspezifischen Mini-Fähigkeiten; WoopSocial veröffentlicht über Medien und generiert keine Bilder.
