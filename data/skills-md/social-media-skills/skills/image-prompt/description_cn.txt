用作帖子所需的任何图像的基础和路由器 - 将社交需求转化为清晰的图像简介，使用与模型无关的提示技巧对其进行描述，并路由到正确的工具。当用户说“我需要为这篇文章提供视觉效果/图像”、“我应该使用什么图像”、“制作图形”、“帮助我提示图像”或不确定要使用哪个图像工具/模型时运行。读取视觉品牌的品牌简介。教授图像简介、自然语言强烈提示的通用解剖学和工具路由器（印刷 -> 表意文字/nano-banana；照片真实 -> nano-banana/flux；超现实 -> Midjourney；编辑 -> nano-banana/flux；矢量 -> Recraft；视频 -> veo-3）。包括“这是否应该由人工智能生成？”门（真实的照片、屏幕截图或图表通常胜过通用人工智能）、可访问性和诚实范围（披露人工智能，从不真实可识别的人或受版权保护的知识产权，验证文本/数据）。交给特定于工具的小技能； WoopSocial 通过媒体发布，不生成图像。
