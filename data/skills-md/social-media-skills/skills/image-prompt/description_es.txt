Úselo como base y enrutador para cualquier imagen que necesite una publicación: convierta una necesidad social en un resumen de imagen claro, descríbala con sugerencias independientes del modelo y diríjase a la herramienta adecuada. Se ejecuta cuando el usuario dice "Necesito una imagen/visual para esta publicación", "qué imagen debo usar", "hacer un gráfico", "ayúdame a generar una imagen" o no está seguro de qué herramienta/modelo de imagen usar. Lee el perfil de marca de la marca visual. Enseña la imagen breve, la anatomía universal de un fuerte mensaje en lenguaje natural y un enrutador de herramientas (tipográfico -> ideograma/nano-banana; fotoreal -> nano-banana/flux; surrealista -> Midjourney; edición -> nano-banana/flux; vector -> Recraft; video -> veo-3). Incluye un "¿debería esto siquiera generarse mediante IA?" puerta (una foto real, una captura de pantalla o un gráfico a menudo supera a la IA genérica), accesibilidad y alcance honesto (divulgar IA, nunca personas reales identificables o IP con derechos de autor, verificar texto/datos). Deja de lado las minihabilidades específicas de la herramienta; WoopSocial publica a través de medios y no genera imágenes.
