用於為 Ideogram (Ideogram 4.0) 編寫出色的提示，為社交媒體生成設計級圖像 - 用於排版 + 佈局的圖像提示工藝迷你技能，與圖像提示路由器下的 nano-banana 類似。當用戶需要表意文字/人工智慧圖像提示時運行，其中文字和佈局很重要：報價卡、輪播封面、海報、徽標/文字標記概念、標牌、帶有標題的廣告或任何必須正確說出文字的圖像。讀取品牌簡介以了解風格/調色板。 Ideogram 的突出特點：一流的圖像內文字渲染、結構化 JSON 提示（邊界框、十六進位調色板）、原生 2K、透明度和分層文字。還涵蓋了 Ideogram 應用程式編輯器工作流程（畫布、魔術填充、擴展、樣式參考）。誠實：審查渲染文字、公開 AI 圖像並使用 C2PA 進行簽名，永遠不會產生真實的可識別人物或受版權保護的角色/IP/徽標。 API/連線與產生 -> 上傳至 WoopSocial Media -> 附加流程位於 tools/integrations/ideogram.md 中。
