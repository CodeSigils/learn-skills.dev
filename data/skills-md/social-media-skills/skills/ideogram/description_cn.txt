用于为 Ideogram (Ideogram 4.0) 编写出色的提示，为社交媒体生成设计级图像 - 用于排版 + 布局的图像提示工艺迷你技能，与图像提示路由器下的 nano-banana 类似。当用户需要表意文字/人工智能图像提示时运行，其中文本和布局很重要：报价卡、轮播封面、海报、徽标/文字标记概念、标牌、带有标题的广告或任何必须正确说出文字的图像。读取品牌简介以了解风格/调色板。 Ideogram 的突出特点：一流的图像内文本渲染、结构化 JSON 提示（边界框、十六进制调色板）、原生 2K、透明度和分层文本。还涵盖了 Ideogram 应用程序编辑器工作流程（画布、魔术填充、扩展、样式参考）。诚实：审查渲染文本、公开 AI 图像并使用 C2PA 进行签名，永远不会生成真实的可识别人物或受版权保护的角色/IP/徽标。 API/连接和生成 -> 上传到 WoopSocial Media -> 附加流程位于 tools/integrations/ideogram.md 中。
