استخدم لكتابة مطالبات رائعة لـ Ideogram (Ideogram 4.0) لإنشاء صور على مستوى التصميم لوسائل التواصل الاجتماعي - المهارة الصغيرة في صياغة الصور السريعة للطباعة + التخطيط، وهي شقيقة لـ nano-banana تحت جهاز توجيه الصور السريعة. يتم تشغيله عندما يريد المستخدم مطالبة صورة Ideogram / AI حيث يكون النص والتخطيط مهمًا: بطاقات الاقتباس، أو أغلفة الرف الدائري، أو الملصقات، أو مفاهيم الشعارات/العلامات النصية، أو اللافتات، أو الإعلانات ذات العناوين الرئيسية، أو أي صورة يجب أن تقول الكلمات بشكل صحيح. يقرأ الملف التعريفي للعلامة التجارية للأسلوب/لوحة الألوان. مميزات Ideogram: عرض النص في الصورة الأفضل في فئته، ومطالبة JSON المنظمة (المربعات المحيطة، واللوحات السداسية)، ودقة 2K الأصلية، والشفافية، وطبقة النص. يغطي أيضًا سير عمل محرر تطبيق Ideogram (اللوحة القماشية، والتعبئة السحرية، والتوسيع، ومراجع النمط). صادق: قم بمراجعة النص المقدم، والكشف عن صور الذكاء الاصطناعي والتوقيع باستخدام C2PA، ولا تقم أبدًا بإنشاء أشخاص حقيقيين يمكن التعرف عليهم أو أحرف / IP / شعارات محمية بحقوق الطبع والنشر. واجهة برمجة التطبيقات/الاتصال والتوليد -> التحميل إلى WoopSocial Media -> إرفاق التدفق المباشر في الأدوات/التكامل/ideogram.md.
