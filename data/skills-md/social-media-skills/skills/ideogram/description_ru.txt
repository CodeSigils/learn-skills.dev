Используйте для написания отличных подсказок для идеограммы (идеограмма 4.0) для создания изображений дизайнерского уровня для социальных сетей — мини-навык создания подсказок изображения для типографики + макета, аналог нано-банана под маршрутизатором подсказок изображений. Запускайте, когда пользователю нужна подсказка с изображением идеограммы или искусственного интеллекта, где ТЕКСТ и МАКЕТ имеют значение: карточки с цитатами, обложки каруселей, плакаты, концепции логотипов/словесных знаков, вывески, рекламные объявления с заголовками или любое изображение, которое должно правильно произносить слова. Читает профиль бренда по стилю/палитре. Отличительные черты Ideogram: лучший в своем классе рендеринг текста в изображении, структурированные подсказки JSON (ограничивающие рамки, шестнадцатеричные палитры), собственное разрешение 2K, прозрачность и многослойность текста. Также рассматривается рабочий процесс редактора приложения Ideogram (холст, магическая заливка, расширение, ссылки на стили). Честно: просматривайте визуализированный текст, раскрывайте изображения AI и подписывайтесь с помощью C2PA, никогда не создавайте реальных идентифицируемых людей или персонажей/IP/логотипы, защищенных авторским правом. API/соединение и поток генерации -> загрузки в WoopSocial Media -> прикрепления находятся в файле Tools/integrations/ideogram.md.
