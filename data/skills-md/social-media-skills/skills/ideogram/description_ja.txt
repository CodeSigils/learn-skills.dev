Ideogram (Ideogram 4.0) の優れたプロンプトを作成して、ソーシャル メディア用のデザイン グレードの画像を生成するために使用します。これは、タイポグラフィーとレイアウトのための画像プロンプト クラフト ミニスキルで、画像プロンプト ルーターのナノバナナに相当します。ユーザーがテキストとレイアウトが重要な表意文字/AI 画像プロンプトを必要とする場合に実行します。引用カード、カルーセル カバー、ポスター、ロゴ/ワードマークのコンセプト、看板、見出し付きの広告、または単語を正確に言う必要がある画像などです。スタイル/パレットのブランドプロフィールを読み取ります。 Ideogram の優れた点: クラス最高の画像内テキスト レンダリング、構造化 JSON プロンプト (バウンディング ボックス、16 進パレット)、ネイティブ 2K、透明度、およびテキストのレイヤー化。 Ideogram アプリエディターのワークフロー (キャンバス、マジック フィル、拡張、スタイル参照) についても説明します。正直: レンダリングされたテキストをレビューし、AI 画像を開示し、C2PA と署名します。実際の識別可能な人物や著作権で保護されたキャラクター、IP、ロゴは決して生成しません。 API/接続と生成 -> WoopSocial Media へのアップロード -> 添付フローは tools/integrations/ideogram.md にあります。
