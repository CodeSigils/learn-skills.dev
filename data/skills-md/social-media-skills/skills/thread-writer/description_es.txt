Úselo para escribir un hilo: una secuencia conectada de publicaciones en X/Twitter o Hilos que cuenta una historia o presenta un argumento en varias publicaciones. Ejecutar cuando el usuario dice "escribir un hilo", "convertir esto en un hilo", "hilo X", "hilo de Twitter", "hilo sobre X" o tiene una idea de varios ritmos que no se ajusta a una publicación. Lee primero el perfil de la marca y la voz, utiliza un escritor gancho para la publicación inicial (que debe enganchar Y prometer la recompensa), construye una idea cohesiva en la que cada publicación gana la siguiente y cierra con una llamada a la acción. Sabe cuándo una sola publicación supera a un hilo. Trampa de nombres: "escribir un hilo" significa esta cadena de publicaciones múltiples; "publicar en/en Threads" significa una única publicación en la aplicación Threads de Meta; use threads-post para eso. Para un solo título, utilice caption-writer; solo para el gancho de apertura use gancho-escritor.
