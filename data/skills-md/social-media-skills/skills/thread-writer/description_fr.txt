Utilisez pour écrire un fil de discussion : une séquence connectée de publications sur X/Twitter ou Threads qui raconte une histoire ou présente un argument dans plusieurs publications. Exécuté lorsque l'utilisateur dit « écrire un fil de discussion », « transformer ceci en fil de discussion », « fil de discussion X », « fil de discussion Twitter », « fil de discussion sur X » ou a une idée à plusieurs battements qui ne rentre pas dans un seul message. Lit d'abord le profil de la marque et la voix, utilise un rédacteur pour le message d'ouverture (qui doit accrocher ET promettre le gain), construit une idée cohérente où chaque message rapporte le suivant et se termine avec un CTA. Sait quand un seul message bat un fil de discussion. Piège de dénomination : « écrire un fil de discussion » désigne cette chaîne multi-posts ; « publier sur/vers Threads » signifie une seule publication sur l'application Threads de Meta — utilisez threads-post pour cela. Pour une seule légende, utilisez caption-writer ; pour uniquement le crochet d'ouverture, utilisez hook-writer.
