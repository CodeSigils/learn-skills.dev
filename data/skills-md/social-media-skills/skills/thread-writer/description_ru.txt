Используйте для создания темы — связанной последовательности сообщений в X/Twitter или Threads, которая рассказывает одну историю или приводит один аргумент в нескольких сообщениях. Запускайте, когда пользователь говорит «написать ветку», «превратить это в ветку», «тема X», «тема в Твиттере», «обсудить тему X» или у него есть многозадачная идея, которая не умещается в одном сообщении. Сначала читает профиль бренда и его голос, использует крючок для вступительного поста (который должен зацепить И обещать отдачу), выстраивает одну связную идею, при которой каждый пост приносит пользу следующему, и приводит к завершению с помощью одного призыва к действию. Знает, когда один пост превосходит ветку. Ловушка именования: «написать ветку» означает эту цепочку из нескольких сообщений; «Публикация в Threads» означает одну публикацию в приложении Meta’s Threads — для этого используйте threads-post. Для одиночной подписи используйте caption-writer; только для открывающего крючка используйте крючок-писатель.
