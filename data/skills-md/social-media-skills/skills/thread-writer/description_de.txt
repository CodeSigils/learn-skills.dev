Zum Schreiben eines Threads verwenden – einer zusammenhängenden Folge von Posts auf X/Twitter oder Threads, die eine Geschichte erzählt oder ein Argument über mehrere Posts hinweg vorbringt. Wird ausgeführt, wenn der Benutzer „einen Thread schreiben“, „daraus einen Thread machen“, „X-Thread“, „Twitter-Thread“, „Thread über X“ sagt oder eine Multi-Beat-Idee hat, die nicht in einen Beitrag passt. Liest zuerst das Markenprofil und die Stimme, verwendet den Hook-Writer für den Eröffnungsbeitrag (der fesseln UND den Erfolg versprechen muss), baut eine zusammenhängende Idee auf, bei der jeder Beitrag den nächsten verdient, und schließt mit einem CTA ab. Erkennt, wann ein einzelner Beitrag einen Thread übertrifft. Namensfalle: „Einen Thread schreiben“ bedeutet diese Multi-Post-Kette; „Auf/in Threads posten“ bedeutet einen einzelnen Beitrag in der Threads-App von Meta – verwenden Sie dafür threads-post. Für eine einzelne Bildunterschrift verwenden Sie caption-writer; Verwenden Sie nur für den Eröffnungs-Hook den Hook-Writer.
