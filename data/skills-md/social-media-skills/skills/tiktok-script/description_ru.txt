Используйте для написания сценария TikTok — встроенного сценария короткого видео с поддержкой звука, оптимизированного для механизма обнаружения TikTok (FYP), построенного на жестком 1-секундном захвате, времени просмотра и повторных просмотрах. Запускается, когда пользователь говорит «Сценарий TikTok», «Видео TikTok», «Сценарий для TikTok», «Сделай TikTok», «Время истории», «Припев TikTok» или хочет короткое видео специально для TikTok. Сначала читает профиль бренда и его голос; использует трендовый звук/формат там, где он действительно подходит (живое исследование тенденций приводит к перехвату трендов); структуры для завершения+пересмотра; оптимизируется для поиска TikTok; выводит производственный документ (кадр — текст на экране — речь — звук — синхронизация), а также пакет подсказок Veo для безликих кадров или видеороликов (нативная съемка часто превосходит искусственный интеллект в TikTok). Для Instagram Reels используйте reels-script; для YouTube Shorts используйте youtube-shorts; для создания сценариев, не зависящих от платформы, используйте короткий видеоскрипт; передает подпись автору подписей, а планирование — планировщику и очереди.
