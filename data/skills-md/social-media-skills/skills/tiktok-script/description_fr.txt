Utilisez-le pour écrire un script TikTok : un script vidéo court natif et sensible au son, optimisé pour le moteur de découverte de TikTok (le FYP), construit autour d'un crochet brutal d'une seconde, d'une durée de visionnage et de revisions. Exécuté lorsque l'utilisateur dit « script TikTok », « vidéo TikTok », « script pour TikTok », « créer un TikTok », « heure du conte », « crochet TikTok » ou souhaite une vidéo courte pour TikTok spécifiquement. Lit le profil de la marque et la voix en premier ; utilise un son/un format tendance là où il s'adapte réellement (la recherche de tendances en direct sert au détournement de tendance) ; structures à terminer + rewatch ; optimise pour la recherche TikTok ; produit un document de production (prise de vue - texte à l'écran - parole - son - timing) ainsi qu'un pack d'invites Veo pour les prises de vue sans visage/b-roll (le tournage natif bat souvent l'IA sur TikTok). Pour Instagram Reels, utilisez reels-script ; pour YouTube Shorts, utilisez youtube-shorts ; pour les scripts indépendants de la plate-forme, utilisez un script vidéo court ; remet la légende au rédacteur de sous-titres et la planification à la planification et à la file d'attente.
