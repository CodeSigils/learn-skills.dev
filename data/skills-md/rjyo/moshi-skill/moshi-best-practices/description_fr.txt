À utiliser lors de la préparation ou de la vérification d'un hôte pour le codage à distance Moshi. Déclenchez ceci pour la préparation SSH ou de préférence Mosh, les problèmes de PATH du shell non interactif, les valeurs par défaut de tmux, la création d'une session de projet tmux enracinée dans un répertoire choisi, l'installation de hooks d'agent Moshi pour Claude Code ou Codex CLI, ou l'offre de l'assistant shell `moshi DIR` en option.
