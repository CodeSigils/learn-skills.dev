Da utilizzare durante la preparazione o la verifica di un host per la codifica remota Moshi. Attivalo per la disponibilità SSH o preferibilmente Mosh, problemi di PATH della shell non interattiva, impostazioni predefinite di tmux, creazione di una sessione di progetto tmux radicata in una directory scelta, installazione di hook dell'agente Moshi per Claude Code o Codex CLI o offerta dell'helper shell opzionale `moshi DIR`.
