قم بإعداد أو ترحيل مسار إصدار GitHub الذي يستخدم Release Please لـ PRs للإصدار الآلي، وتعيين الإصدارات، والعلامات، وإصدارات GitHub، بالإضافة إلى نشر عناصر GoReleaser الاختيارية. استخدم عندما يُطلب منك أتمتة الإصدارات عند الدمج، أو استبدال الإصدارات اليدوية المستندة إلى العلامات، أو إصلاح فشل إذن الإصدار، أو إصلاح أصول الإصدار المفقودة، أو التحقق من صحة سلوك الإصدار الشامل في GitHub، أو إعداد CI باستخدام golangci-lint، أو gitleaks، أو govulncheck، أو yamllint.
