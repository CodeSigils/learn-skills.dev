Configura o esegui la migrazione di una pipeline di rilascio GitHub che utilizza Release Please per PR di rilascio automatizzati, controllo delle versioni, tag e versioni GitHub, oltre alla pubblicazione facoltativa di artefatti GoReleaser. Da utilizzare quando viene richiesto di automatizzare i rilasci durante l'unione, sostituire i rilasci manuali basati su tag, correggere gli errori di autorizzazione di Release Please, correggere le risorse di rilascio mancanti, convalidare il comportamento dei rilasci end-to-end in GitHub o impostare CI con golangci-lint, gitleaks, govulncheck o yamllint.
