Настройте или перенесите конвейер выпуска GitHub, который использует Release Please для автоматического создания PR-запросов на выпуск, управления версиями, тегов и выпусков GitHub, а также дополнительной публикации артефактов GoReleaser. Используйте при запросе для автоматизации выпусков при слиянии, замены выпусков на основе тегов вручную, исправления ошибок разрешения Release Please, исправления отсутствующих ресурсов выпуска, проверки сквозного поведения выпуска в GitHub или настройки CI с помощью golangci-lint, gitleaks, govulncheck или yamllint.
