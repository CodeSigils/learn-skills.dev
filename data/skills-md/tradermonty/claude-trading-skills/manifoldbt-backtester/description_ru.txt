Запускает спецификацию декларативной стратегии для столбцов OHLCV с помощью механизма коллектора Rust, связывает журнал заполнения с циклическими обходами и отправляет восемь входных данных для оценки навыков эксперта по бэктестированию. Используйте, когда пользователь хочет выполнить бэктест, измерить описанное им правило, получить процент выигрышей/средний выигрыш/средний убыток/максимальную просадку на реальных барах или предоставить эксперту по бэктесту измеренные цифры вместо оценок.
