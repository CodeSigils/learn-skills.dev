Порекомендуйте правильный торговый процесс, набор навыков, профиль API и путь настройки, исходя из цели естественного языка. Используйте это как отправную точку, когда пользователь выражает торговую или инвестиционную цель и ему нужно знать, какой навык/рабочий процесс использовать, с чего начать или работает ли что-то без платных ключей API — например, «с чего начать», «какой навык мне следует использовать», «я хочу торговать только тогда, когда рынок благоприятный», «что работает без ключей API», «どれを使えばいい», «API キー無しで 使えるものは». Только маршруты и объяснения; он никогда не выполняет сделки и не запускает автоматически другие навыки, и он честен, когда рабочий процесс еще не реализован.
