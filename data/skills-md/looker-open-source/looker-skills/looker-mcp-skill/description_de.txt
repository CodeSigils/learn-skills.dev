Anleitung zum Herstellen einer Verbindung zum Looker MCP-Server und zur Verwendung. Erklärt, wie Sie auf den Looker-MCP-Server zugreifen, eine von Looker verwaltete oder lokale/eigenständige Bereitstellung einrichten, die OAuth-Authentifizierung konfigurieren und verfügbare MCP-Tools katalogisieren.
