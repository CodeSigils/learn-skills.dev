PDFMathTranslate-next (pdf2zh) を使用して英語の PDF 文書 (特に学術論文) を中国語に翻訳し、数式、図、レイアウトを保持した単言語中国語 PDF と二言語並列 PDF を生成します。 uv 経由で pdf2zh_next 環境を自動的にインストールし、ユーザーが Codex または Claude Code (任意の OpenAI 互換ゲートウェイ) で設定済みのモデル/API を再利用し、キーが存在しない場合は無料の SiliconFlow サービスにフォールバックします。ユーザーが PDF を中国語 (または別の言語) に翻訳したい場合、論文や论文を翻訳したい場合、バイリンガル PDF を作成したい場合、または pdf2zh / PDFMathTranslate について言及したい場合は、ツールの名前を明示的に指定していない場合でも、このスキルを使用してください。 PDF 翻訳タスクが表示されるたびに、このスキルを積極的に呼び出します (手動で翻訳しないでください)。
