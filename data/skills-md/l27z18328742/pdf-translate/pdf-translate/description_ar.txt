ترجمة مستندات PDF الإنجليزية (خاصة الأوراق الأكاديمية) إلى الصينية باستخدام PDFMathTranslate-next (pdf2zh)، مما يؤدي إلى إنتاج ملف PDF صيني أحادي اللغة وملف PDF ثنائي اللغة جنبًا إلى جنب مع الحفاظ على الصيغ والأشكال والتخطيط. يقوم تلقائيًا بتثبيت بيئة pdf2zh_next عبر الأشعة فوق البنفسجية وإعادة استخدام النموذج/واجهة برمجة التطبيقات التي قام المستخدم بتكوينها بالفعل في Codex أو Claude Code (أي بوابة متوافقة مع OpenAI)، والعودة إلى خدمة SiliconFlow المجانية في حالة عدم وجود مفتاح. استخدم هذه المهارة عندما يريد المستخدم ترجمة ملف PDF إلى اللغة الصينية (أو لغة أخرى)، أو ترجمة ورقة/论文، أو إنتاج ملف PDF ثنائي اللغة، أو ذكر pdf2zh / PDFMathTranslate - حتى لو لم يذكر اسم الأداة بشكل صريح. قم باستدعاء هذه المهارة بشكل استباقي (لا تترجم يدويًا) كلما ظهرت مهمة ترجمة PDF.
