Übersetzen Sie englische PDF-Dokumente (insbesondere wissenschaftliche Arbeiten) mit PDFMathTranslate-next (pdf2zh) ins Chinesische und erstellen Sie ein einsprachiges chinesisches PDF und ein zweisprachiges Side-by-Side-PDF mit erhaltenen Formeln, Abbildungen und Layout. Installiert automatisch die pdf2zh_next-Umgebung über UV und verwendet das Modell/die API wieder, die der Benutzer bereits in Codex oder Claude Code (jedem OpenAI-kompatiblen Gateway) konfiguriert hat, und greift auf den kostenlosen SiliconFlow-Dienst zurück, wenn kein Schlüssel vorhanden ist. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine PDF-Datei ins Chinesische (oder eine andere Sprache) übersetzen, eine Arbeit/ein Dokument übersetzen, eine zweisprachige PDF-Datei erstellen möchte oder pdf2zh/PDFMathTranslate erwähnt – auch wenn er das Tool nicht explizit nennt. Rufen Sie diese Fähigkeit proaktiv auf (nicht manuell übersetzen), wenn eine PDF-Übersetzungsaufgabe angezeigt wird.
