Переведите PDF-документы с английского языка (особенно академические статьи) на китайский с помощью PDFMathTranslate-next (pdf2zh), создав одноязычный китайский PDF-файл и двуязычный параллельный PDF-файл с сохраненными формулами, рисунками и макетом. Автоматически устанавливает среду pdf2zh_next через uv и повторно использует модель/API, уже настроенные пользователем в Codex или Claude Code (любом шлюзе, совместимом с OpenAI), возвращаясь к бесплатному сервису SiliconFlow, когда ключ отсутствует. Используйте этот навык всякий раз, когда пользователь хочет перевести PDF-файл на китайский (или другой язык), перевести статью/китайский язык, создать двуязычный PDF-файл или упомянуть pdf2zh/PDFMathTranslate — даже если он не называет инструмент явно. Активно активируйте этот навык (не переводите вручную) всякий раз, когда появляется задача перевода PDF.
