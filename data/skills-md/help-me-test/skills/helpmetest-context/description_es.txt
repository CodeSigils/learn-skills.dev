Utilice esta habilidad para acceder o actualizar la memoria del proyecto de prueba. Invoquelo cuando el usuario pregunte sobre trabajos anteriores: qué pruebas existen, qué errores se encontraron, qué características se cubrieron o qué sucedió en una sesión anterior. También invoquelo cuando el usuario necesite registrar un nuevo trabajo en el proyecto: vincular una prueba recién escrita a una función, agregar un error descubierto, actualizar la cobertura o el estado de la función. Esta habilidad responde "¿qué sabemos?" y realiza "por favor recuerda esto". Dos trabajos: leer el registro de prueba (ponerme al día, reanudar el trabajo, mostrar cobertura) y escribirlo (vincular esta prueba, registrar este error, actualizar este artefacto). Omítalo para: ejecutar pruebas, depurar fallas de pruebas, explorar las características de un nuevo sitio o escribir código de prueba.
