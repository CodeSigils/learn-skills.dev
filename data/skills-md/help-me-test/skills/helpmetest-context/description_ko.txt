이 기술을 사용하여 테스트 프로젝트의 메모리에 액세스하거나 업데이트합니다. 사용자가 이전 작업(어떤 테스트가 있는지, 어떤 버그가 발견되었는지, 어떤 기능이 다루어졌는지 또는 이전 세션에서 발생한 일)에 대해 물을 때 이를 호출합니다. 또한 사용자가 프로젝트에 새 작업을 기록해야 할 때 이를 호출합니다. 새로 작성된 테스트를 기능에 연결하고, 발견된 버그를 추가하고, 적용 범위 또는 기능 상태를 업데이트합니다. 이 스킬은 "우리가 무엇을 알고 있나요?"에 답합니다. '이것을 기억해주세요' 공연을 펼친다. 두 가지 작업: 테스트 기록 읽기(확인, 작업 재개, 적용 범위 표시) 및 쓰기(이 테스트 연결, 이 버그 기록, 이 아티팩트 업데이트). 테스트 실행, 테스트 실패 디버깅, 새 사이트 기능 탐색, 테스트 코드 작성 등의 작업은 건너뛰세요.
