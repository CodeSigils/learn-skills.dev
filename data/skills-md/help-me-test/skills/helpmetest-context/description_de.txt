Verwenden Sie diese Fähigkeit, um auf den Speicher des Testprojekts zuzugreifen oder ihn zu aktualisieren. Rufen Sie es auf, wenn der Benutzer nach früheren Arbeiten fragt – welche Tests existieren, welche Fehler gefunden wurden, welche Funktionen abgedeckt wurden oder was in einer früheren Sitzung passiert ist. Rufen Sie es auch auf, wenn der Benutzer neue Arbeiten im Projekt aufzeichnen muss – einen neu geschriebenen Test mit einer Funktion verknüpfen, einen entdeckten Fehler hinzufügen, die Abdeckung oder den Funktionsstatus aktualisieren muss. Diese Fähigkeit antwortet: „Was wissen wir?“ und spielt „Bitte denken Sie daran.“ Zwei Aufgaben: Lesen des Testprotokolls (Nachholen, Arbeit fortsetzen, Abdeckung anzeigen) und Schreiben darin (Diesen Test verknüpfen, diesen Fehler aufzeichnen, dieses Artefakt aktualisieren). Überspringen Sie es für Folgendes: Tests ausführen, Testfehler beheben, die Funktionen einer neuen Site erkunden oder Testcode schreiben.
