Azure DevOps 자동화 기술을 완성하세요. 사용자 의도에 따라 올바른 기능으로 라우팅합니다. 기능: (1) 백로그 생성기 — 모든 문서(PRD, 사양, 회의록)를 읽고 상위-하위 링크, 승인 기준, 스토리 포인트 및 태그를 사용하여 에픽, 기능, 사용자 스토리, 작업 및 버그의 전체 계층 구조를 생성합니다. (2) 백로그 상태 감사 — 기존 백로그를 스캔하고 누락된 승인 기준, 고아 작업, 오래된 항목, 중복 및 8개 이상의 문제 유형을 식별하는 0-100의 상태 점수를 생성합니다. (3) 스프린트 플래너 — 백로그를 읽고 팀 속도, 우선순위 및 종속성을 기반으로 최적의 스프린트 할당을 제안합니다. (4) 작업 항목 템플릿 — 공통 패턴(API 엔드포인트, CRUD 기능, 인증 흐름, 데이터베이스 마이그레이션, CI/CD 파이프라인, 대시보드)을 위해 사전 구축된 템플릿 18개. (5) Azure DevOps CLI 참조 — 예제, 패턴 및 모범 사례가 포함된 az Board, az repos, az Pipelines 명령에 대한 전체 가이드입니다. 사용 시기: 백로그 만들기, 보드 채우기, 문서를 작업 항목으로 변환, 백로그 상태 감사, 스프린트 계획, 작업 항목 템플릿 생성, az Boards CLI 사용, WIQL을 사용하여 작업 항목 쿼리, 영역 및 반복 관리, 부모-자식 계층 구조 만들기, Azure DevOps, Azure Boards 또는 ADO 작업.
