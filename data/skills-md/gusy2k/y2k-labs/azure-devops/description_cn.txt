完成 Azure DevOps 自动化技能。根据用户意图路由到正确的功能。功能： (1) Backlog Creator — 读取任何文档（PRD、规范、会议记录），并使用父子链接、验收标准、故事点和标签创建史诗、功能、用户故事、任务和 Bug 的完整层次结构。 (2) 待办事项健康审核 — 扫描现有待办事项并生成 0-100 的健康评分，识别缺失的验收标准、孤立的任务、过时的项目、重复项和另外 8 种问题类型。 (3) Sprint Planner — 读取积压工作并根据团队速度、优先级和依赖性建议最佳的冲刺分配。 (4) 工作项模板 — 18 个针对常见模式的预构建模板（API 端点、CRUD 功能、身份验证流程、数据库迁移、CI/CD 管道、仪表板）。 (5) Azure DevOps CLI 参考 — az board、az repos、az pipelines 命令的完整指南，包含示例、模式和最佳实践。使用场合：创建待办事项、填充看板、将文档转换为工作项、审核待办事项运行状况、规划冲刺、生成工作项模板、使用 azboard CLI、使用 WIQL 查询工作项、管理区域和迭代、创建父子层次结构或任何 Azure DevOps、Azure Boards 或 ADO 任务。
