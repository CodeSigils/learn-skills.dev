完成 Azure DevOps 自動化技能。根據用戶意圖路由到正確的功能。功能： (1) Backlog Creator — 讀取任何文件（PRD、規格、會議記錄），並使用父子連結、驗收標準、故事點和標籤建立史詩、功能、使用者故事、任務和 Bug 的完整層次結構。 (2) 待辦事項健康審核 — 掃描現有待辦事項並產生 0-100 的健康評分，識別缺少的驗收標準、孤立的任務、過時的項目、重複項和另外 8 種問題類型。 (3) Sprint Planner — 讀取積壓工作並根據團隊速度、優先順序和依賴性建議最佳的衝刺分配。 (4) 工作項目範本 — 18 個針對常見模式的預先建置範本（API 端點、CRUD 功能、驗證流程、資料庫遷移、CI/CD 管道、儀表板）。 (5) Azure DevOps CLI 參考 — 有關 az board、az repos、az pipelines 指令的完整指南，包含範例、模式和最佳實務。使用場合：建立待辦事項、填入看板、將文件轉換為工作項目、審核待辦事項運作狀況、規劃衝刺、產生工作項目範本、使用 azboard CLI、使用 WIQL 查詢工作項目、管理區域和迭代、建立父子層次結構或任何 Azure DevOps、Azure Boards 或 ADO 任務。
