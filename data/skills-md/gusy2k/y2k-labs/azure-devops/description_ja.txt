Azure DevOps 自動化スキルを完了します。ユーザーの意図に基づいて適切な機能にルーティングします。機能: (1) Backlog Creator — あらゆるドキュメント (PRD、仕様、会議メモ) を読み取り、親子リンク、承認基準、ストーリー ポイント、タグを含むエピック、機能、ユーザー ストーリー、タスク、バグの完全な階層を作成します。 (2) バックログ健全性監査 — 既存のバックログをスキャンし、欠落している受け入れ基準、孤立したタスク、古い項目、重複、およびその他 8 つの問題タイプを識別する 0 ～ 100 の健全性スコアを生成します。 (3) スプリント プランナー — バックログを読み取り、チームの速度、優先順位、依存関係に基づいて最適なスプリント割り当てを提案します。 (4) 作業項目テンプレート — 一般的なパターン (API エンドポイント、CRUD 機能、認証フロー、データベース移行、CI/CD パイプライン、ダッシュボード) 用の 18 個の事前構築済みテンプレート。 (5) Azure DevOps CLI リファレンス — 例、パターン、ベスト プラクティスを含む、azboards、az repos、az Pipelines コマンドの完全なガイド。以下の場合に使用します: バックログの作成、ボードへの入力、ドキュメントから作業項目への変換、バックログの健全性の監査、スプリントの計画、作業項目テンプレートの生成、azboards CLI の使用、WIQL による作業項目のクエリ、エリアとイテレーションの管理、親子階層の作成、または Azure DevOps、Azure Boards、または ADO タスク。
