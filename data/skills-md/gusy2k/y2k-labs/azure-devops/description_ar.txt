أكمل مهارة أتمتة Azure DevOps. يوجه إلى القدرة الصحيحة بناءً على نية المستخدم. القدرات: (1) Backlog Creator - يقرأ أي مستند (PRD، والمواصفات، وملاحظات الاجتماع) وينشئ تسلسلًا هرميًا كاملاً للملاحم والميزات وقصص المستخدم والمهام والأخطاء مع روابط بين الوالدين والطفل ومعايير القبول ونقاط القصة والعلامات. (2) تدقيق صحة الأعمال المتراكمة - يقوم بفحص الأعمال المتراكمة الموجودة وينشئ درجة صحة من 0 إلى 100 تحدد معايير القبول المفقودة والمهام المعزولة والعناصر التي لا معنى لها والنسخ المكررة و8 أنواع أخرى من المشكلات. (3) مخطط Sprint - يقرأ الأعمال المتراكمة ويقترح تعيينات العدو الأمثل بناءً على سرعة الفريق والأولوية والتبعيات. (4) قوالب عناصر العمل - 18 قالبًا تم إعداده مسبقًا للأنماط الشائعة (نقطة نهاية واجهة برمجة التطبيقات، وميزة CRUD، وتدفق المصادقة، وترحيل قاعدة البيانات، وخط أنابيب CI/CD، ولوحة المعلومات). (5) مرجع Azure DevOps CLI - دليل كامل للوحات AZ، ومستودعات AZ، وأوامر خطوط أنابيب AZ مع الأمثلة والأنماط وأفضل الممارسات. يُستخدم عندما: إنشاء تراكم، أو ملء لوحة، أو تحويل المستندات إلى عناصر عمل، أو تدقيق صحة الأعمال المتراكمة، أو التخطيط للسباقات السريعة، أو إنشاء قوالب عناصر العمل، أو استخدام لوحات AZ CLI، أو الاستعلام عن عناصر العمل باستخدام WIQL، أو إدارة المناطق والتكرارات، أو إنشاء تسلسلات هرمية بين الوالدين والطفل، أو أي مهمة Azure DevOps أو Azure Boards أو ADO.
