دليل لدمج واستخدام حزمة npm المنشورة `@minswap/sdk` في مشاريع TypeScript. يُستخدم عندما يحتاج المستخدمون إلى مساعدة في تثبيت الحزمة، أو إصلاح إعداد ESM/وقت التشغيل، أو الاختيار بين محولات Blockfrost وMaestro، أو الاستعلام عن المجمعات أو الأسعار، أو استخدام مساعدي الحساب، أو إنشاء معاملات Minswap باستخدام Lucid. ركز بشكل أساسي على سير عمل المستهلك "Dex" و"DexV2" و"Stableswap". تعامل مع `LbeV2` و`Dao` و`ExpiredOrderMonitor` كصادرات ثانوية يتم تغطيتها فقط عندما يطلب المستخدم ذلك صراحةً. تجاهل البنية الأساسية لإعادة الشراء فقط مثل المفهرس/المزامن، وPrisma/Postgres، وDocker، والأدوات الداخلية الأخرى ما لم يطلب المستخدم صراحةً تفاصيل المزامن المستضاف ذاتيًا.
