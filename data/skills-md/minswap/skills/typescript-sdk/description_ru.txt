Руководство по интеграции и использованию опубликованного пакета npm `@minswap/sdk` в проектах TypeScript. Используйте, когда пользователям нужна помощь в установке пакета, исправлении настройки ESM/среды выполнения, выборе между адаптерами Blockfrost и Maestro, запросе пулов или цен, использовании помощников по расчетам или создании транзакций Minswap с помощью Lucid. Сосредоточьтесь в первую очередь на потребительских рабочих процессах «Dex», «DexV2» и «Stableswap». Рассматривайте `LbeV2`, `Dao` и `ExpiredOrderMonitor` как вторичный экспорт, который можно будет использовать только по явному запросу пользователя. Игнорируйте инфраструктуру, предназначенную только для репозитория, такую ​​как индексатор/синхронизатор, Prisma/Postgres, Docker и другие внутренние инструменты, если только пользователь явно не запрашивает сведения о локальном синхронизаторе.
