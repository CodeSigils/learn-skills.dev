Guía para integrar y utilizar el paquete npm `@minswap/sdk` publicado en proyectos TypeScript. Úselo cuando los usuarios necesiten ayuda para instalar el paquete, arreglar la configuración de ESM/tiempo de ejecución, elegir entre adaptadores Blockfrost y Maestro, consultar grupos o precios, usar ayudas de cálculo o crear transacciones Minswap con Lucid. Céntrese principalmente en los flujos de trabajo de los consumidores "Dex", "DexV2" y "Stableswap". Trate `LbeV2`, `Dao` y `ExpiredOrderMonitor` como exportaciones secundarias para cubrir solo cuando el usuario lo solicite explícitamente. Ignore la infraestructura de solo repositorio, como indexador/sincronizador, Prisma/Postgres, Docker y otras herramientas internas, a menos que el usuario solicite explícitamente detalles del sincronizador autohospedado.
