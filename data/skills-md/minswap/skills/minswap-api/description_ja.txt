「https://docs.minswap.org/developer/aggregator-api」および「https://docs.minswap.org/developer/minswap-apis」に記載されている Minswap がホストするパブリック API を操作します。 Codex がエンドポイントの選択、リクエストまたはレスポンスの形状の説明、Minswap API ルートに対する統合の構築、ウォレットまたはトークン データの取得、スワップの推定、アグリゲーター トランザクションの構築または送信、保留中の注文の検査、または Minswap 資産およびプールの市場データ エンドポイントのクエリを行う必要がある場合に使用します。
