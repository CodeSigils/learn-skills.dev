Lavora con le API pubbliche ospitate da Minswap documentate su "https://docs.minswap.org/developer/aggregator-api" e "https://docs.minswap.org/developer/minswap-apis". Utilizzare quando Codex deve scegliere endpoint, spiegare forme di richiesta o risposta, creare integrazioni con percorsi API Minswap, recuperare dati di portafoglio o token, stimare scambi, creare o inviare transazioni di aggregatori, ispezionare ordini in sospeso o eseguire query su asset Minswap e raggruppare endpoint di dati di mercato.
