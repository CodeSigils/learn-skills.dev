قم بدمج وتكوين الحزمة `@minswap/aggregator-widget` في تطبيقات React أو صفحات HTML العادية. استخدمه عند الحاجة إلى إضافة عنصر واجهة المستخدم Minswap، أو شرح أو اختيار دعائم عنصر واجهة المستخدم، أو توصيل كائن متوافق مع محفظة CIP-30، أو تحديد الأصول أو البروتوكولات القابلة للتحديد، أو تخصيص الزر أو وضع العرض الكامل، أو تطبيق السمات على عنصر واجهة المستخدم المجمع.
