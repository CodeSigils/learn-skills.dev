Intégrez et configurez le package `@minswap/aggregator-widget` dans les applications React ou les pages HTML simples. À utiliser lorsque vous avez besoin d'ajouter le widget d'échange Minswap, d'expliquer ou de choisir les accessoires du widget, de connecter un objet compatible avec le portefeuille CIP-30, de limiter les actifs ou les protocoles sélectionnables, de personnaliser le bouton ou le mode d'affichage complet, ou d'appliquer un thème pour le widget agrégateur.
