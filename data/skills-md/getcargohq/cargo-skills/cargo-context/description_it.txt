Ispeziona e modifica il repository di contesto supportato da git dell'area di lavoro (la knowledge base GTM dei file markdown/MDX) e il suo sandbox di runtime utilizzando la CLI Cargo. Da utilizzare quando l'utente desidera sfogliare/leggere/scrivere/modificare file di contesto, eseguire un comando nella sandbox o ispezionare il grafico della conoscenza del contesto.
