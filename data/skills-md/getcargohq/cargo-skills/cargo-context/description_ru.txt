Проверьте и отредактируйте репозиторий контекста рабочей области, поддерживаемый git (база знаний GTM файлов уценки/MDX), и ее изолированную среду выполнения с помощью интерфейса командной строки Cargo. Используйте, когда пользователь хочет просмотреть/прочитать/записать/редактировать файлы контекста, запустить команду в песочнице или проверить граф знаний контекста.
