從 Cargo 擁有的收件匣發送郵件 — 在發送域上配置信箱，執行供應商暖機以及 5→40/日 的發送坡度，使用 `sendEmail` 動作發送，並讀取回覆的線索、回覆、投遞事件以及工作區的抑制清單。觸發詞：「設置發送信箱」「為對外配置收件匣」「暖機此信箱」「我今天還剩多少次發送」「從 Cargo 發送此郵件」「他們有回覆嗎」「誰取消訂閱了」「抑制此收件者」「把我從你的清單中移除」「永遠不要再寄信給他們」「信箱費用多少」「我的信箱卡在待處理」。信箱是每月重複的信用額度收費，且每次發送皆受到基礎、抑制與相關性的限制。跳過時機：編寫文案或建立受眾 — 使用 cargo-gtm；信箱屬於 git 管理 — 使用 cargo-cdk。
