从 Cargo 拥有的收件箱发送邮件——在发送域上配置邮箱，进行提供商预热以及 5→40/日 的发送坡度，使用 `sendEmail` 操作进行投递，并读取线程、回复、投递事件以及工作区的抑制列表。触发词：“设置发送邮箱”，“为外发配置收件箱”，“预热此邮箱”，“我今天还能发送多少封”，“从 Cargo 发送此邮件”，“他们有回复吗”，“谁取消订阅了”，“抑制此收件人”，“把我从你的列表中移除”，“永不再给他们发邮件”，“邮箱费用是多少”，“我的邮箱卡在待处理”。邮箱是按月循环计费的信用费用，且每次发送都受基础、抑制和相关性的限制。跳过的情形：编写文案或构建受众——使用 cargo-gtm；邮箱应放在 git 中——使用 cargo-cdk。
