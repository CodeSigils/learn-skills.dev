Définissez un espace de travail Cargo entier dans le code — connecteurs, modèles, jeux, outils, agents, serveurs MCP, contexte, capacités, territoires, segments, dossiers, fichiers, travailleurs, applications — et déployez-le de manière déclarative avec `cargo-ai cdk` (init → types → plan → déployer), de la même manière que vous géreriez l'infra cloud avec Pulumi ou AWS CDK. À utiliser lorsque l'utilisateur souhaite gérer les ressources Cargo sous forme de code : de manière reproductible, avec contrôle de version, dans git, à partir d'un modèle ou dans plusieurs environnements. Itinéraires vers les guides de création/déploiement/saisie (niveau 2), les recettes (niveau 2.5) et les références. Pour les opérations impératives ponctuelles (créer un connecteur, lire un modèle, exécuter un workflow), utilisez plutôt la compétence de capacité de correspondance.
