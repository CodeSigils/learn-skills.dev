Определите в коде все рабочее пространство Cargo — соединители, модели, игровые элементы, инструменты, агенты, серверы MCP, контекст, мощности, территории, сегменты, папки, файлы, рабочие процессы, приложения — и разверните его декларативно с помощью «cargo-ai cdk» (init → типы → план → развертывание), так же, как вы управляете облачной инфраструктурой с помощью Pulumi или AWS CDK. Используйте, когда пользователь хочет управлять ресурсами Cargo как кодом: воспроизводимо, с контролем версий, в git, из шаблона или в разных средах. Пути создания/развертывания/набора руководств (уровень 2), рецептов (уровень 2.5) и ссылок. Для одноразовых обязательных операций (создание одного соединителя, чтение модели, запуск рабочего процесса) вместо этого используйте навык сопоставления.
