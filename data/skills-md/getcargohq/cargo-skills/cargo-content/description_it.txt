Gestisci i file e le librerie della conoscenza dell'area di lavoro nel dominio dei contenuti Cargo: carica, elenca, rinomina, sposta e rimuovi file (PDF, CSV, testo) e crea o sincronizza librerie native e supportate da connettori per la generazione aumentata di recupero (RAG). Da utilizzare quando l'utente desidera caricare o organizzare file di conoscenza, creare una libreria di conoscenza o sincronizzare una fonte di conoscenza esterna. Per collegarli a un agente, usa l'abilità cargo-ai.
