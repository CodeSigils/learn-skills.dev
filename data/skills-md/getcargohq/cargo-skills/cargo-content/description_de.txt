Verwalten Sie Arbeitsbereich-Wissensdateien und -Bibliotheken in der Cargo-Inhaltsdomäne – laden Sie Dateien (PDFs, CSVs, Text) hoch, listen Sie sie auf, benennen Sie sie um, verschieben und entfernen Sie sie. Erstellen oder synchronisieren Sie native und Connector-gestützte Bibliotheken für die Retrieval-Augmented Generation (RAG). Verwenden Sie diese Option, wenn der Benutzer Wissensdateien hochladen oder organisieren, eine Wissensbibliothek erstellen oder eine externe Wissensquelle synchronisieren möchte. Um diese an einen Agenten anzuhängen, verwenden Sie die Fracht-KI-Fähigkeit.
