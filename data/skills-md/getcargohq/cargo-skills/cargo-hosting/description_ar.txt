يمكنك إنشاء تطبيقات وعاملي Cargo Hosting ونشرها وإدارتها باستخدام Cargo CLI — Vite SPA التي يتم تقديمها على *.cargo.app ومعالجات HTTP الطرفية بدون خادم، بالإضافة إلى عمليات النشر التي يتم شحنها والترويج لها. يُستخدم عندما يريد المستخدم دعم تطبيق أو عامل مستضاف أو نشره أو الترويج له أو إدارته على Cargo.
