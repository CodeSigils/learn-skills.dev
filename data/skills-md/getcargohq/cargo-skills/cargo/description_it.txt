Router e panoramica per le competenze dell'agente Cargo CLI. Spiega le nove competenze (una competenza di risultato cargo-gtm + otto competenze di capacità), il flusso UUID tra di loro, polling asincrono, casi d'uso end-to-end (arricchimento di un record, arricchimento e sincronizzazione con CRM, punteggio lead AI, flusso di lavoro personalizzato, monitoraggio degli errori, bootstrap di nuovo spazio di lavoro, esportazione di segmenti, creazione di contesto GTM) e trucchi comuni (ortografia di "congiunzione", esecuzione vs batch, modello-uuid vs segmento-uuid). Carica per primo ogni volta che si lavora con la CLI di Cargo, quando non si è sicuri di quale competenza secondaria applicare, quando si uniscono più competenze secondarie, quando si avvia uno spazio di lavoro o quando l'utente chiede informazioni sulle competenze di Cargo in generale.
