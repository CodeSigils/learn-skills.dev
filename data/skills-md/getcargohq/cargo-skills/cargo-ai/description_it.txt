Crea e configura agenti AI, carica file per RAG, gestisci server MCP e gestisci le memorie degli agenti utilizzando la CLI Cargo. Utilizzare quando l'utente desidera creare o aggiornare agenti, caricare file della knowledge base, connettere i server degli strumenti MCP o gestire le memorie degli agenti. Per inviare messaggi agli agenti, utilizza invece l'abilità di orchestrazione del carico.
