Cree y configure agentes de IA, cargue archivos para RAG, administre servidores MCP y maneje memorias de agentes mediante Cargo CLI. Úselo cuando el usuario desee crear o actualizar agentes, cargar archivos de base de conocimientos, conectar servidores de herramientas MCP o administrar memorias de agentes. Para enviar mensajes a agentes, utilice la habilidad de orquestación de carga.
