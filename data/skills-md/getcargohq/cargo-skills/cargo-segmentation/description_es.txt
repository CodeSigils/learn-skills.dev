Defina y utilice segmentos: filtros guardados y con nombre en un modelo de carga que se convierten en la audiencia para una ejecución por lotes, un activador de reproducción o una exportación. Activadores: "crear un segmento de", "filtrar mis contactos dónde", "quién coincide con este criterio", "guardar esto como una lista", "cuántas empresas coinciden", "el segmento cerrado-ganado", "todos los que no han recibido correos electrónicos", "apuntar solo a cuentas que", "qué hay en este segmento", "reducir esto a". El filtro JSON usa "conjunción" (no "conjunción"); el error ortográfico falla silenciosamente. Omita cuando: ejecute algo sobre el segmento: use orquestación de carga; exportar sus filas: utilice análisis de carga; SQL ad-hoc sobre el modelo: use almacenamiento de carga.
