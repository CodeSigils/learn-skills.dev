セグメントを定義して使用します。バッチ実行、再生トリガー、またはエクスポートの対象となる Cargo モデルに対して名前を付けて保存したフィルターです。トリガー: 「セグメントを作成する」、「どこで連絡先をフィルターする」、「この基準に一致する人」、「これをリストとして保存する」、「一致する企業の数」、「成約済みセグメント」、「電子メールを受信して​​いない全員」、「該当するアカウントのみをターゲットにする」、「このセグメントに含まれる内容」、「絞り込む」。フィルター JSON は (「conjunction」ではなく)「conjonction」を使用します。スペルを間違えると通知なく失敗します。次の場合はスキップします: セグメント上で何かを実行する場合 - カーゴ オーケストレーションを使用します。行をエクスポートする — カーゴ分析を使用します。モデルに対するアドホック SQL — カーゴストレージを使用します。
