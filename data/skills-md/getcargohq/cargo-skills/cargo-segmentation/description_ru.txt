Определите и используйте сегменты — именованные сохраненные фильтры для модели Cargo, которые станут аудиторией для пакетного запуска, триггера воспроизведения или экспорта. Триггеры: «создать сегмент», «отфильтровать мои контакты, где», «кто соответствует этому критерию», «сохранить это как список», «сколько компаний соответствует», «сегмент «Закрытый выигранный», «все, кому не отправили электронное письмо», «таргетинг только на учетные записи, которые», «что находится в этом сегменте», «ограничить это до». В фильтре JSON используется `conjunction` (а не `conjunction`) — ошибка в написании не сработает автоматически. Пропустить, когда: выполняется что-то по сегменту — используйте грузовую оркестровку; экспортируя свои строки — используйте грузоаналитику; специальный SQL для модели — используйте хранилище грузов.
