Определите и используйте сегменты — именованные сохраненные фильтры для модели Cargo, которые станут аудиторией для пакетного запуска, триггера воспроизведения или экспорта. Триггеры: «создать сегмент», «отфильтровать мои контакты, где», «кто соответствует этому критерию», «сохранить это как список», «сколько компаний соответствует», «сегмент «Закрытый выигранный», «все, кому не было отправлено электронное письмо», «таргетинг только на те учетные записи», «что находится в этом сегменте», «сузить это до». В фильтре JSON используется `conjunction` (а не `conjunction`) — ошибка в написании не сработает автоматически. Пропустить, когда: выполняется что-то по сегменту — используйте грузовую оркестровку; экспортируя свои строки — используйте грузоаналитику; специальный SQL для модели — используйте хранилище грузов.
