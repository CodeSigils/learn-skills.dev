Definieren und verwenden Sie Segmente – benannte, gespeicherte Filter über einem Cargo-Modell, die zur Zielgruppe für einen Stapellauf, einen Wiedergabeauslöser oder einen Export werden. Auslöser: „Erstellen Sie ein Segment von“, „Filtern Sie meine Kontakte wo“, „Wer erfüllt dieses Kriterium“, „Speichern Sie dies als Liste“, „Wie viele Unternehmen passen“, „das Geschlossen-Won-Segment“, „jeder, der keine E-Mail erhalten hat“, „Nur auf Konten abzielen“, „Was ist in diesem Segment“, „Einschränken auf“. Filter JSON verwendet „Konjunktion“ (nicht „Konjunktion“) – eine falsche Schreibweise schlägt stillschweigend fehl. Überspringen, wenn: etwas über das Segment läuft – Ladungsorchestrierung verwenden; seine Zeilen exportieren – Frachtanalysen verwenden; Ad-hoc-SQL über das Modell – verwenden Sie Cargo-Storage.
