Gestisci gli utenti dell'area di lavoro, i token API, le cartelle, i ruoli e invia report alla gestione dell'area di lavoro utilizzando la CLI Cargo. Da utilizzare quando l'utente desidera invitare o gestire i membri dell'area di lavoro, creare o ruotare token API, organizzare le risorse in cartelle, controllare i ruoli e le autorizzazioni dell'area di lavoro o inviare un report alla gestione dell'area di lavoro quando la CLI non funziona o viene utilizzata in modo improprio.
