إنشاء تنبيهات Cargo وإدارتها - عمليات فحص الحدود المجدولة التي تراقب القياس عن بعد لسير العمل (الامتدادات، والتشغيل، والسجلات)، وصحة نموذج التخزين، أو استعلام SQL عشوائي، وإطلاق الإجراءات (موصل أو أداة أو تشغيل وكيل) عندما ينتهك أحد القياسات. يُستخدم عندما يريد المستخدم أن يتم إعلامه بشأن ارتفاع معدل الخطأ، أو انفجار التكلفة، أو العقد البطيئة، أو المزامنة المتوقفة، أو النماذج القديمة أو الفارغة، أو سير العمل الذي توقف عن التشغيل (مفتاح الرجل الميت)، أو أي مراقبة "لتنبيهي عندما يتجاوز <metric> <القيمة>"؛ ولإدراج سجل إطلاق تلك التنبيهات أو معاينته أو تحديثه أو فحصه.
