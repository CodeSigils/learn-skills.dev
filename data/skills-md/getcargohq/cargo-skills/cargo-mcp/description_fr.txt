Utilisez Cargo depuis son serveur MCP hébergé à https://mcp.getcargo.io/mcp — connectez un client, découvrez et tarifez une action, exécutez‑la sur un enregistrement ou un lot, interrogez‑la, et lisez les modèles d’espace de travail, le tout sans installer de CLI. Indiquez également quand appeler un outil MCP plutôt que de lancer `cargo-ai`. Déclencheurs : « connect Cargo to Claude Desktop », « add Cargo to ChatGPT », « Cargo MCP server », « mcp.getcargo.io », « use Cargo without installing anything », « which Cargo tool do I call », « search_actions », « execute_action_batch », « MCP server is showing the wrong workspace ». Outils : whoami, search_actions, get_action_schema, execute_action, execute_action_batch, get_run, query_models. À ignorer lorsqu’un shell est disponible et que la tâche est un flux de travail, un déploiement CDK, du SQL d’entrepôt ou une boîte aux lettres — utilisez les compétences CLI ; lors de la publication d’un serveur MCP depuis votre propre espace de travail ou de son rattachement à un agent Cargo — utilisez cargo-ai. Veuillez toujours répondre dans la langue de l'utilisateur.
