Steuere Cargo über seinen gehosteten MCP‑Server unter https://mcp.getcargo.io/mcp — verbinde einen Client, entdecke und bewerte eine Aktion, führe sie für einen Datensatz oder einen Batch aus, poll sie und lese Workspace‑Modelle, ohne dass eine CLI‑Installation nötig ist. Außerdem, wann ein MCP‑Tool aufgerufen werden sollte, anstatt `cargo-ai` über die Shell zu starten. Auslöser: „connect Cargo to Claude Desktop“, „add Cargo to ChatGPT“, „Cargo MCP server“, „mcp.getcargo.io“, „use Cargo without installing anything“, „which Cargo tool do I call“, „search_actions“, „execute_action_batch“, „MCP server is showing the wrong workspace“. Werkzeuge: whoami, search_actions, get_action_schema, execute_action, execute_action_batch, get_run, query_models. Überspringen, wenn du eine Shell hast und die Aufgabe ein Workflow, ein CDK‑Deploy, Warehouse‑SQL oder ein Postfach ist — nutze die CLI‑Fähigkeiten; wenn du einen MCP‑Server aus deinem eigenen Workspace veröffentlichst oder einen an einen Cargo‑Agent anschließt — nutze cargo‑ai.  

Bitte antworte immer in der Sprache des Benutzers.
