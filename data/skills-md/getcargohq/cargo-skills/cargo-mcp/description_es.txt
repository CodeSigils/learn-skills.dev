Conduce Cargo desde su servidor MCP alojado en https://mcp.getcargo.io/mcp — conecta un cliente, descubre y cotiza una acción, ejecútala sobre un registro o un lote, hazle polling y lee los modelos del espacio de trabajo, sin instalar la CLI. También cuándo llamar a una herramienta MCP en lugar de lanzar `cargo-ai`. Disparadores: "conectar Cargo a Claude Desktop", "añadir Cargo a ChatGPT", "servidor MCP de Cargo", "mcp.getcargo.io", "usar Cargo sin instalar nada", "qué herramienta de Cargo llamo", "search_actions", "execute_action_batch", "el servidor MCP muestra el espacio de trabajo incorrecto". Herramientas: whoami, search_actions, get_action_schema, execute_action, execute_action_batch, get_run, query_models. Omitir cuando: tienes una shell y el trabajo es un flujo de trabajo, un despliegue CDK, SQL de almacén o un buzón — usa las habilidades de la CLI; al publicar un servidor MCP fuera de tu propio espacio de trabajo o al adjuntar uno a un agente Cargo — usa cargo‑ai.
