通过其托管的 MCP 服务器 https://mcp.getcargo.io/mcp 来驱动 Cargo —— 连接客户端、发现并定价操作、对单条记录或批量执行、轮询以及读取工作区模型，无需安装 CLI。还要说明何时调用 MCP 工具而不是通过 `cargo-ai` 进行 shell 调用。触发词：“connect Cargo to Claude Desktop”、 “add Cargo to ChatGPT”、 “Cargo MCP server”、 “mcp.getcargo.io”、 “use Cargo without installing anything”、 “which Cargo tool do I call”、 “search_actions”、 “execute_action_batch”、 “MCP server is showing the wrong workspace”。工具：whoami、search_actions、get_action_schema、execute_action、execute_action_batch、get_run、query_models。跳过条件：如果有 shell 且任务是工作流、CDK 部署、仓库 SQL 或邮箱——使用 CLI 技能；在从自己的工作区发布 MCP 服务器或将其附加到 Cargo 代理时——使用 cargo‑ai。请始终使用用户的语言回复。
