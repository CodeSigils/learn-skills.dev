Управляйте Cargo с его размещённого MCP‑сервера по адресу https://mcp.getcargo.io/mcp — подключайте клиент, ищите и оценивайте действие, выполняйте его для одной записи или партии, опрашивайте статус и читайте модели рабочей области без установки CLI. Также указывайте, когда следует вызывать MCP‑инструмент вместо запуска `cargo-ai`. Триггеры: «подключить Cargo к Claude Desktop», «добавить Cargo в ChatGPT», «Cargo MCP сервер», «mcp.getcargo.io», «использовать Cargo без установки», «какой инструмент Cargo вызвать», «search_actions», «execute_action_batch», «MCP сервер показывает неправильную рабочую область». Инструменты: whoami, search_actions, get_action_schema, execute_action, execute_action_batch, get_run, query_models. Пропускайте, если у вас есть оболочка и задача является workflow, CDK‑деплоем, warehouse SQL или почтовым ящиком — используйте возможности CLI; при публикации MCP‑сервера из собственной рабочей области или присоединении его к агенту Cargo — используйте cargo-ai.
