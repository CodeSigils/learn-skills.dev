Descargue resultados de ejecución del flujo de trabajo, exporte datos de segmentos y supervise las métricas de ejecución mediante Cargo CLI. Úselo cuando el usuario desee ejecutar métricas, tasas de error, exportar datos o descargar resultados para su espacio de trabajo de Cargo. Para facturación y uso de crédito, utilice la habilidad de facturación de carga.
