Загрузите результаты выполнения рабочего процесса, экспортируйте данные сегментов и отслеживайте показатели выполнения с помощью интерфейса командной строки Cargo. Используйте, когда пользователь хочет просмотреть метрики, частоту ошибок, экспортировать данные или загрузить результаты для своей рабочей области Cargo. Для выставления счетов и использования кредитов вместо этого используйте навык выставления счетов за груз.
