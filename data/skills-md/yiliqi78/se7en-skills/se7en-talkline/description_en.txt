Speech Script Generator — Turn your core message into a dramatic narrative structure.  
From “What do I want to make clear?” to an executable, scene-by-scene script.  

**Trigger moments**: writing a speech script, pre-planning a slide deck, unpacking speech logic, scripting a PPT, designing talk structure, explaining something, preparing a share, helping me sort out the thread of a speech.  
Use this skill whenever the user is preparing a talk/share/training and is still at the “figuring out what to say” stage.  
Even if the user only says “I want to talk about X,” it should trigger—this is the pivotal point from idea to structure.  
Output: a Markdown script + slide-manifest.yaml ready for any PPT builder.
