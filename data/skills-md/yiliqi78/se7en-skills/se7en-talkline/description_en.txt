Speech Script Generator – turns your core message into a dramatic narrative structure, transforming “What do I want to say?” into an actionable, scene-by-scene script.  
**Trigger moments**: writing a speech script, pre-planning a presentation, breaking down speech logic, scripting a PPT, designing talk structure, explaining something, preparing a share, helping me outline the thread.  
Use this skill whenever the user is preparing a speech/share/workshop and is still at the “figuring out what to say” stage.  
Even if the user only says “I want to talk about X,” trigger it—this is the critical pivot from idea to structure.  
The output is a Markdown script + slide-manifest.yaml, ready to plug into any PPT builder.
