Speech Script Generator – turns your core message into a dramatic narrative structure, transforming “What do I want to say?” en un guión procesable, escena por escena.  
**Momentos desencadenantes**: escribir el guión de un discurso, planificar previamente una presentación, desglosar la lógica del discurso, crear un guión de PPT, diseñar la estructura del discurso, explicar algo, preparar un contenido compartido, ayudarme a delinear el hilo.  
Use this skill whenever the user is preparing a speech/share/workshop and is still at the “figuring out what to say” stage.  
Even if the user only says “I want to talk about X,” trigger it—this is the critical pivot from idea to structure.  
The output is a Markdown script + slide-manifest.yaml, ready to plug into any PPT builder.
