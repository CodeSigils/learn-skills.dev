Automatically summarize video content and extract spoken-word transcripts via the BibiGPT API.
Use this skill when a user sends a video link (YouTube, Bilibili, Douyin, Xiaohongshu, podcasts, etc.) and requests a summary, transcript extraction, or subtitles.
Trigger keywords: summarize video, transcript, extract subtitles, video summary, summarize video, transcript.
It also applies when the user only sends a video link without any explicit instructions—by default, perform summary + transcript extraction.
Supports all platforms supported by BibiGPT.
