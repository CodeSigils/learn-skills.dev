Universal Style Writing – ein umfassendes Tool zur Stilextraktion und -übertragung  
**Trigger-Szenarien**:  
- Schreiben im Stil eines bestimmten Autors: „Schreiben Sie im Stil von Lu Xun“, „Schreiben Sie einen Aufsatz im Stil von Wang Zengqi“, „Schreiben Sie im Stil von Shi Tiesheng.“  
- Stilbezogene Operationen: „Universeller Stil“, „Stilimitation“, „Stilmaster“, „Stilschreiben“, „Stilextraktion“, „Stil extrahieren“, „Stilübertragung“, „Universeller Stilschreiben“.  
- Vorgänge in der Stilbibliothek: „Stilbibliothek anzeigen“, „Stil empfehlen“, „Stil erkunden“, „Meine Stilbibliothek“.  
- Textstil wiedergeben: „Schreiben Sie im Stil dieses Artikels“, „Imitieren Sie den Stil dieser Passage.“  
Diese Fähigkeit kümmert sich um die Extraktion und Übertragung von Stilen Dritter.
