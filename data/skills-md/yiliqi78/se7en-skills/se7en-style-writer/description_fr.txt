Universal Style Writing – Un outil complet pour l’extraction et la migration de styles.
**Scénarios de déclenchement** :
- Écrire dans le style d'un auteur spécifié : "Écrivez dans le style de Lu Xun", "Écrivez un essai dans le style de Wang Zengqi", "Écrivez avec la voix de Shi Tiesheng".
- Opérations liées au style : « Style universel », « Imitation de style », « Style master », « Écriture de style », « Extraction de style », « Extraire le style », « Transfert de style », « Écriture de style universelle ».
- Opérations sur la bibliothèque de styles : "Vérifier la bibliothèque de styles", "Recommander un style", "Exploration de styles", "Ma bibliothèque de styles".
- Reproduction du style du texte : « Écrivez dans le style de cet article », « Imitez le style de ce passage ».
Cette compétence gère l'extraction et la migration des styles d'auteurs tiers.
