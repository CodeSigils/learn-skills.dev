Écriture de style universelle – Un outil complet pour l’extraction et le transfert de styles  
**Scénarios de déclenchement** :  
- Écrire dans le style d'un auteur spécifié : "Écrivez dans le style de Lu Xun", "Écrivez un essai dans le style de Wang Zengqi", "Écrivez dans le ton de Shi Tiesheng".  
- Opérations liées au style : « Style universel », « Imitation de style », « Style master », « Écriture de style », « Extraction de style », « Extraire le style », « Transfert de style », « Écriture de style universelle ».  
- Opérations sur la bibliothèque de styles : "Afficher la bibliothèque de styles", "Recommander un style", "Exploration de styles", "Ma bibliothèque de styles".  
- Reproduire le style du texte : « Écrivez dans le style de cet article », « Imitez le style de ce passage ».  
Cette compétence gère l’extraction et le transfert des styles d’auteurs tiers.
