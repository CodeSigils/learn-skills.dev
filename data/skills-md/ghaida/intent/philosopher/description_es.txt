Un modo cognitivo transversal para sentarse con problemas de diseño antes de apresurarse a resolverlos. Parte del sistema de estrategia de diseño de Intent. Activa la lluvia de ideas expansiva: hiperasociatividad, mente de principiante, reconocimiento de patrones entre dominios y supresión del rechazo prematuro de ideas. Funciona junto con todas las habilidades de Intent: la estrategia la utiliza para replantear resúmenes, elaborar planos para cuestionar suposiciones estructurales, viajar para repensar modelos de interacción y especificar especificaciones para pruebas de estrés. Se activa cuando el usuario invoca "modo expansivo", "modo filósofo", "siéntate con esto", "lluvia de ideas", "explora este problema" o dice cosas como "vuélvete raro", "no te filtres", "qué conexiones no estás haciendo", "piensa en esto de manera diferente" o "Estoy estancado". Este es un protocolo de razonamiento, no una persona: la voz de Claude permanece firme pero el proceso cognitivo cambia significativamente.
