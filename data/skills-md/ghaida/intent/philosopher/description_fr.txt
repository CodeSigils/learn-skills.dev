Un mode cognitif transversal pour s’asseoir sur des problèmes de conception avant de se précipiter pour les résoudre. Fait partie du système de stratégie de conception d'intention. Active un brainstorming étendu : hyperassociativité, esprit de débutant, reconnaissance de formes inter-domaines et suppression du rejet prématuré des idées. Fonctionne avec toutes les compétences d'intention : la stratégie l'utilise pour recadrer les briefs, les plans pour remettre en question les hypothèses structurelles, le parcours pour repenser les modèles d'interaction et les spécifications pour tester les spécifications. Se déclenche lorsque l'utilisateur invoque le « mode expansif », le « mode philosophe », « s'asseoir avec ça », « réfléchir », « explorer ce problème » ou dit des choses comme « allez bizarrement avec ça », « ne vous filtrez pas », « quelles connexions n'établissez-vous pas », « pensez à cela différemment » ou « je suis coincé ». Il s'agit d'un protocole de raisonnement, pas d'un personnage : la voix de Claude reste posée mais le processus cognitif change de manière significative.
