يشخص سبب ضعف أداء الحملات أو رحلات إدارة علاقات العملاء أو خطط الوسائط أو مسارات التحويل أو الصفحات المقصودة أو التطبيقات أو مؤشرات الأداء الرئيسية للأعمال. يُستخدم عندما يكون الأداء أقل من الهدف، أو ترتفع التكاليف، أو ينخفض ​​التحويل، أو يكون التسليم ضعيفًا، أو تنخفض استجابة إدارة علاقات العملاء، أو التعب الإبداعي، أو تحتاج القيادة إلى تحليل السبب الجذري. يتم تشغيله أيضًا عندما يقول أحد الأشخاص "لماذا انخفض الأداء؟"، أو "تكلفة الاكتساب آخذة في الارتفاع"، أو "انخفاض عائد النفقات الإعلانية"، أو "العملاء المحتملون سيئون"، أو "ماذا حدث؟"، أو "تشخيص الحملة"، أو "خطة استعادة الأداء". حتى العبارات غير الرسمية مثل "هناك شيء ما مكسور" أو "الأرقام متوقفة" أو "توقفت عن العمل" أو "لماذا لا نحقق الهدف؟" يجب تفعيل هذه المهارة.
