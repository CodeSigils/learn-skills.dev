Комплексная настройка lint и управление ошибками для многоязычных проектов. Автоматически определяет языки программирования, генерирует соответствующие конфигурации lint (ESLint, Ruff, SwiftLint, golangci-lint), устанавливает необходимые инструменты, запускает проверки lint и автоматически исправляет ошибки с помощью ИИ. Используйте для настройки lint для нового проекта, настройки перехватчиков перед фиксацией, запуска lint для промежуточных или определенных файлов, автоматического исправления ошибок lint, определения языков программирования проекта и создания файлов конфигурации lint. Поддерживает JavaScript/TypeScript, Python, Swift и Go.
