Extraiga el sistema de diseño completo del sitio de referencia, genere tokens de diseño, una paleta de colores, documentación del sistema de diseño y un área de juegos HTML interactiva, luego guarde todo como archivos reutilizables para el desarrollo posterior de la página. Se activa cuando los usuarios desean replicar, hacer referencia o extraer el estilo de diseño, combinación de colores, movimiento, tipografía o estructura de componentes de un sitio. También se aplica a escenarios como "Quiero hacer referencia al estilo del sitio X para mi sitio", "Ayúdame a extraer las especificaciones de diseño de este sitio" o "Recrear la navegación, las tarjetas y los componentes de este sitio".
