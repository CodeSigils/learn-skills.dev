Запрашивайте записи экрана пользователя, аудио, элементы пользовательского интерфейса и аналитику использования через локальный REST API Screenpipe по адресу localhost:3030. Используйте, когда пользователь спрашивает об активности экрана, встречах, приложениях, производительности, экспорте мультимедиа, перетранскрипции или подключенных услугах.
