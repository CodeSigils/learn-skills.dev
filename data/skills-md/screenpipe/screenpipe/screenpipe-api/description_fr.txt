Interrogez les enregistrements d'écran, l'audio, les éléments d'interface utilisateur et les analyses d'utilisation de l'utilisateur via l'API REST Screenpipe locale sur localhost:3030. À utiliser lorsque l'utilisateur pose des questions sur son activité à l'écran, ses réunions, ses applications, sa productivité, l'exportation de médias, la retranscription ou les services connectés.
