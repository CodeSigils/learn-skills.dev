Настройте проект смарт-контракта Sui Move с помощью OpenZeppelin Contracts для Sui. Используйте, когда пользователям необходимо: (1) установить Sui CLI и набор инструментов Move, (2) создать новый пакет Sui Move, (3) обнаружить и добавить зависимости OpenZeppelin Sui в Move.toml через реестр Move (MVR), (4) изучить шаблон интеграции из примеров библиотеки и документации API перед реализацией или (5) понять соглашения об импорте Sui Move и команды сборки/тестирования для OpenZeppelin.
