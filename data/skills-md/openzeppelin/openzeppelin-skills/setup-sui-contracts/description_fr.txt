Mettez en place un projet de contrat intelligent Sui Move avec OpenZeppelin Contracts for Sui. À utiliser lorsque les utilisateurs doivent : (1) installer la chaîne d'outils Sui CLI et Move, (2) créer un nouveau package Sui Move, (3) découvrir et ajouter des dépendances OpenZeppelin Sui à Move.toml via le Move Registry (MVR), (4) apprendre le modèle d'intégration à partir des exemples de la bibliothèque et de la documentation API avant l'implémentation, ou (5) comprendre les conventions d'importation Sui Move et créer/tester les commandes pour OpenZeppelin.
