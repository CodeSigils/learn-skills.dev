Configure un proyecto de contrato inteligente Sui Move con OpenZeppelin Contracts para Sui. Úselo cuando los usuarios necesiten: (1) instalar Sui CLI y la cadena de herramientas Move, (2) crear un nuevo paquete Sui Move, (3) descubrir y agregar dependencias de OpenZeppelin Sui a Move.toml a través del Registro Move (MVR), (4) aprender el patrón de integración de los ejemplos de la biblioteca y los documentos API antes de implementar, o (5) comprender las convenciones de importación de Sui Move y compilar/probar comandos para OpenZeppelin.
