قم بإعداد مشروع العقد الذكي Sui Move مع OpenZeppelin Contracts for Sui. يُستخدم عندما يحتاج المستخدمون إلى: (1) تثبيت Sui CLI وسلسلة أدوات Move، (2) إنشاء حزمة Sui Move جديدة، (3) اكتشاف وإضافة تبعيات OpenZeppelin Sui إلى Move.toml عبر سجل النقل (MVR)، (4) التعرف على نمط التكامل من أمثلة المكتبة ومستندات API قبل التنفيذ، أو (5) فهم اتفاقيات استيراد Sui Move وأوامر البناء/الاختبار لـ OpenZeppelin.
