Используйте, когда пользователь спрашивает о синтаксисе T-SQL, администрировании SQL Server, производительности запросов, хранимых процедурах, индексах, блокировке, транзакциях, резервном копировании/восстановлении, высокой доступности, безопасности или любой теме, связанной с MSSQL, даже не говоря явно «SQL Server». Также запускайте запуск по таким терминам, как SSMS, tempdb, bcp, sqlcmd, MSSQL, sp_executesql, NOLOCK, columnsstore, Hekaton, RCSI, анализ параметров или план выполнения.
