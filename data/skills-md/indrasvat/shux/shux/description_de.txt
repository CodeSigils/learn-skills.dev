Steuern Sie Terminalsitzungen, Bereiche und TUIs von einem Agent aus – erzeugen Sie Shells, senden Sie Tastenanschläge, erstellen Sie pixelgenaue Snapshots von PNGs aller Bereiche und erweitern Sie Shux selbst mit zeilengetrennten JSON-RPC-Plugins in jeder Sprache. Verwenden Sie diese Option, wenn Sie Terminalarbeit multiplexen, eine TUI steuern müssen, die Sie sonst mit tmux / screen / iTerm2 / Expect / pexpect / asciinema / vhs / termshot steuern würden, skriptbasierte CLI/REPL-Interaktionen ausführen, Headless Visual Regression auf einer Terminal-Benutzeroberfläche durchführen oder ein Prozess-Plugin schreiben müssen, das den Shux-Ereignisbus abonniert und über „window.rename“, „pane.send_keys“ zurückruft. „state.apply“ usw.
