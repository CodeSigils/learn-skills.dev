قم بتنفيذ العلاقات العامة ودفعها وفتحها باستخدام وصف قابل للتكيف وأول قيمة. يُستخدم عندما يقول المستخدم "الالتزام والعلاقات العامة"، أو "ادفع وافتح العلاقات العامة"، أو "اشحن هذا"، أو "أنشئ علاقات عامة"، أو "افتح طلب سحب"، أو "التزم بالدفع العلاقات العامة"، أو عندما يريد الانتقال من تغييرات العمل إلى طلب سحب مفتوح في خطوة واحدة. يُستخدم أيضًا عندما يقول المستخدم "تحديث وصف العلاقات العامة"، أو "تحديث وصف العلاقات العامة"، أو "تحديث العلاقات العامة"، أو يريد إعادة كتابة وصف علاقات عامة موجود. يُنتج أوصاف العلاقات العامة التي تتوسع في العمق مع تعقيد التغيير، مع تجنب قوالب قطع ملفات تعريف الارتباط.
