적응형 가치 우선 설명을 사용하여 PR을 커밋하고 푸시하고 엽니다. 사용자가 "커밋 및 PR", "PR 푸시 및 열기", "이것을 배송", "PR 만들기", "풀 요청 열기", "푸시 PR 커밋"이라고 말하거나 한 단계로 작업 변경 사항에서 공개 풀 요청으로 이동하려고 할 때 사용합니다. 또한 사용자가 "PR 설명 업데이트", "PR 설명 새로 고침", "PR 새로 고침"이라고 말하거나 기존 PR 설명을 다시 작성하려는 경우에도 사용합니다. 진부한 템플릿을 사용하지 않고 변경의 복잡성에 따라 심도 있게 확장되는 PR 설명을 생성합니다.
