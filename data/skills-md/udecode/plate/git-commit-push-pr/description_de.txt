Begehen, pushen und eröffnen Sie eine PR mit einer adaptiven, wertorientierten Beschreibung. Wird verwendet, wenn der Benutzer „Commit and PR“, „Push and Open a PR“, „Shift this“, „Create a PR“, „Open a Pull Request“, „Commit Push PR“ sagt oder in einem Schritt von funktionierenden Änderungen zu einem offenen Pull Request übergehen möchte. Wird auch verwendet, wenn der Benutzer „PR-Beschreibung aktualisieren“, „PR-Beschreibung aktualisieren“, „PR aktualisieren“ sagt oder eine vorhandene PR-Beschreibung neu schreiben möchte. Erstellt PR-Beschreibungen, deren Tiefe sich an die Komplexität der Änderung anpasst, und vermeidet dabei vorgefertigte Vorlagen.
