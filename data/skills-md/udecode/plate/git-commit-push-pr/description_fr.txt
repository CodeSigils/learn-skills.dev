Validez, poussez et ouvrez un PR avec une description adaptative axée sur la valeur. À utiliser lorsque l'utilisateur dit « valider et PR », « pousser et ouvrir un PR », « expédier ceci », « créer un PR », « ouvrir une demande d'extraction », « valider un PR push » ou souhaite passer des modifications en cours à une demande d'extraction ouverte en une seule étape. À utiliser également lorsque l'utilisateur dit « mettre à jour la description du PR », « actualiser la description du PR », « actualiser le PR » ou souhaite réécrire une description du PR existante. Produit des descriptions de relations publiques qui évoluent en profondeur avec la complexité du changement, en évitant les modèles à l'emporte-pièce.
