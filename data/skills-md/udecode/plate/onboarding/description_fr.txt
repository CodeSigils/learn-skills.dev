Générez ou régénérez ONBOARDING.md pour aider les nouveaux contributeurs à comprendre une base de code. À utiliser lorsque l'utilisateur demande de « créer des documents d'intégration », « générer ONBOARDING.md », « documenter ce projet pour les nouveaux développeurs », « rédiger la documentation d'intégration », « vonboard », « vonboarding », « préparer ce dépôt pour un nouveau contributeur », « actualiser le document d'intégration » ou « mettre à jour ONBOARDING.md ». À utiliser également lorsque quelqu'un a besoin d'intégrer un nouveau membre de l'équipe et souhaite un artefact écrit, ou lorsqu'une base de code manque de documentation d'intégration et que l'utilisateur souhaite en générer une.
