افتح متابعة GitHub موجزة للتعرف على قيود متصفح التطوير أو متصفح الوكيل القابلة لإعادة الاستخدام. يُستخدم عندما يتم حظر أتمتة المتصفح بسبب مشكلة محتملة في جانب الأداة تستحق الإصلاح بشكل منفصل، خاصة بالنسبة للنقرات أو القوائم المنسدلة أو مدخلات الملفات أو مصائد التركيز أو غيرها من حالات فشل الوكيل/المتصفح القابلة للتكرار.
