Apri un follow-up conciso su GitHub per le limitazioni riutilizzabili del browser di sviluppo o del browser dell'agente. Da utilizzare quando l'automazione del browser è bloccata da un probabile problema lato strumento che vale la pena risolvere separatamente, in particolare per clic, menu a discesa, input di file, trappole di messa a fuoco o altri errori ripetibili dell'agente/browser.
