Abra un seguimiento conciso de GitHub para conocer las limitaciones reutilizables del navegador de desarrollo o del navegador de agentes. Úselo cuando la automatización del navegador esté bloqueada por un posible problema relacionado con la herramienta que vale la pena solucionar por separado, especialmente para clics, menús desplegables, entradas de archivos, trampas de enfoque u otras fallas repetibles del agente/navegador.
