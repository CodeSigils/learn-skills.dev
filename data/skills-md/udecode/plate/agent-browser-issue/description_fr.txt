Ouvrez un suivi GitHub concis pour les limitations réutilisables du navigateur de développement ou du navigateur d'agent. À utiliser lorsque l'automatisation du navigateur est bloquée par un problème probable côté outil qui mérite d'être résolu séparément, en particulier pour les clics, les listes déroulantes, les entrées de fichiers, les pièges de focus ou d'autres pannes répétables d'agent/navigateur.
