Genere transcripciones de video estructuradas a partir de archivos locales o URL de video usando la API de Gemini Files. Úselo cuando un elemento, comentario o archivo adjunto del rastreador de GitHub o Linear incluya una grabación de pantalla, .mov, .mp4 o un video alojado en el rastreador y necesite un bloque <video-transcripts> en lugar de notas escritas a mano.
