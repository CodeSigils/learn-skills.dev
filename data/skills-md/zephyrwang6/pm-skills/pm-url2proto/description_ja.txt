ライブ Web ページのクローンをローカルの Next.js + Tailwind CSS プロジェクトに作成して、ラピッド プロトタイピングを実現します。ユーザーが URL またはスクリーンショットを共有し、そのページをローカルで複製、再設計、または反復処理したい場合は常に、このスキルを使用します。「このサイトのクローンを作成する」、「このページに基づいてプロトタイプを作成する」、「この UI を再作成する」、「次のようなものを構築する」などと言われる場合でも、単にリンクを貼り付けてコードに変換するように要求される場合でも、このスキルを使用します。また、ユーザーが新しいページを追加したり、既存のページを変更したり、このスキルによって以前に作成されたプロトタイプ プロジェクトを拡張したりするときにもトリガーされます。ユーザーが参照リンクや画像を使って「X のようなページを構築したい」と言うだけの場合でも、このスキルは適用されます。
