Klonen Sie Live-Webseiten in ein lokales Next.js + Tailwind-CSS-Projekt für schnelles Prototyping. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer eine URL oder einen Screenshot teilt und diese Seite lokal replizieren, neu gestalten oder iterieren möchte – egal, ob er sagt „diese Website klonen“, „einen Prototyp auf Basis dieser Seite erstellen“, „diese Benutzeroberfläche neu erstellen“, „etwas erstellen, das so aussieht“ oder einfach einen Link einfügt und Sie bittet, ihn in Code umzuwandeln. Wird auch ausgelöst, wenn der Benutzer neue Seiten hinzufügen, vorhandene Seiten ändern oder ein Prototypprojekt erweitern möchte, das zuvor mit diesem Skill erstellt wurde. Selbst wenn der Benutzer nur mit einem Referenzlink oder Bild sagt: „Ich möchte eine Seite wie X erstellen“, gilt diese Fähigkeit.
