Lösungsgenerator für Tracking und metrisches Design. Ausgehend von den Produktanforderungen/dem Kernfluss wird ein vollständiges Tracking-Lösungsdokument erstellt (Ereignisse, Felder, Trigger-Timing, Definitionserklärungen, Checkliste zur Qualitätssicherung).

Auslösebedingung: Der Benutzer erwähnt Schlüsselwörter wie „埋点“, „Tracking“, „Ereignisdesign“, „Datenerfassung“, „Berichtsschema“, „Tracking-Schema“, „Ereignisspezifikation“, „Felddesign“, „Metrikdefinition“, „Datenakzeptanz“, „QA-Überprüfung“ usw.

Also applicable: the user provides a product PRD/requirements document and requests a tracking scheme; the user provides a core user flow and asks to break down events; the user requests standardized event naming or field definitions; Der Benutzer fordert einen Datenabnahmeplan an.

Typical input: event naming conventions + field dictionary + core flow description/flowchart.

Not applicable: pure data analysis (use pm-analytics), pure BI dashboard building, pure SQL query writing.
