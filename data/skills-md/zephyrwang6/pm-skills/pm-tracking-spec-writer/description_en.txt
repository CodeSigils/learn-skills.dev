Tracking and Metric Design Solution Generator. Starting from product requirements/core flow, it produces a complete tracking solution document (events, fields, trigger timing, definition explanations, QA verification checklist).

Trigger condition: the user mentions keywords such as “埋点”, “tracking”, “event design”, “data collection”, “reporting scheme”, “tracking scheme”, “event specification”, “field design”, “metric definition”, “data acceptance”, “QA verification”, etc.

Also applicable: the user provides a product PRD/requirements document and requests a tracking scheme; the user provides a core user flow and asks to break down events; the user requests standardized event naming or field definitions; the user requests a data acceptance plan.

Typical input: event naming conventions + field dictionary + core flow description/flowchart.

Not applicable: pure data analysis (use pm-analytics), pure BI dashboard building, pure SQL query writing.
