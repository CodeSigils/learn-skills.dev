Trigger conditions: user mentions keywords such as “A/B test”, “AB experiment”, “experiment design”, “control experiment”, “traffic‑splitting experiment”, “gray rollout plan”, “experiment plan”, “sample size calculation”, “significance test”, “experiment evaluation”, “p‑value”, “confidence interval”, “MDE”, “statistical power”, “experiment duration”, “stop‑loss rule”, etc.

Also applicable when: the user provides experiment objectives / modifiable points / data scale / time‑frame constraints and requests an experiment plan; the user asks to evaluate whether an existing experiment design is reasonable; the user asks to formulate experiment decision criteria and decision rules.

Typical input: experiment objective + modifiable points + current data scale + acceptable experiment duration.

Not applicable: pure data analysis (use pm‑analytics), pure instrumentation design (use tracking‑spec‑writer), pure PRD writing (use pm‑prd‑writer).
