Partendo dai fenomeni dei dati, genera consigli attuabili sulle decisioni sui prodotti e generali come report visivi HTML. Si attiva quando l'utente dice "Analizza questo set di dati", "Perché questa metrica è diminuita", "Aiutami a fare un'analisi di fidelizzazione", "Quali sono i motivi dell'abbandono dell'utente", "Vedi quale passaggio della canalizzazione è caduto" o "Dammi un rapporto di analisi dei dati".

Applicabile anche: gli utenti caricano file di dati CSV/Excel e richiedono approfondimenti analitici; gli utenti forniscono i risultati delle query SQL e chiedono l'interpretazione; gli utenti richiedono suddivisioni metriche, analisi di attribuzione, confronti di coorte, analisi di esperimenti A/B; gli utenti menzionano parole chiave per l'analisi dei dati come "albero metrico", "imbuto", "fidelizzazione", "tasso di conversione", "rifiuto DAU", "coorte", "attribuzione", ecc.

Non applicabile: pura creazione di dashboard BI (utilizzando xlsx), pura scrittura SQL (scrittura diretta), pura pulizia dei dati (scrittura diretta di script).
