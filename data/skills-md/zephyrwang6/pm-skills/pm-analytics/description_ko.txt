데이터 현상에서 시작하여 실행 가능한 제품 결정 권장 사항을 생성하고 이를 시각적 HTML 보고서로 출력합니다. 사용자가 "이 데이터 세트를 분석하세요", "이 측정항목이 하락한 이유", "유지율 분석을 도와주세요", "사용자 이탈 이유는 무엇입니까", "퍼널의 어느 단계에서 하락했는지 확인하세요" 또는 "데이터 분석 보고서를 주세요"라고 말할 때 트리거됩니다.

또한 적용 가능: 사용자가 CSV/Excel 데이터 파일을 업로드하고 분석 통찰력을 요청합니다. 사용자는 SQL 쿼리 결과를 제공하고 해석을 요청합니다. 사용자는 지표 분석, 기여도 분석, 집단 비교, A/B 실험 분석을 요청합니다. 사용자는 '메트릭 트리', '퍼널', '유지', '전환율', 'DAU 감소', '코호트', '속성' 등과 같은 데이터 분석 키워드를 언급합니다.

해당 없음: 순수 BI 대시보드 구축(xlsx 사용), 순수 SQL 작성(직접 작성), 순수 데이터 정리(스크립트 직접 작성).
