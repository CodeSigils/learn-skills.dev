A partir de fenómenos de datos, genere recomendaciones de decisiones de productos procesables y envíelas como informes HTML visuales. Se activa cuando el usuario dice "Analice este conjunto de datos", "¿Por qué cayó esta métrica?", "Ayúdeme a hacer un análisis de retención", "Cuáles son los motivos de la pérdida de usuarios", "Ver qué paso del embudo cayó" o "Dame un informe de análisis de datos".

También aplicable: los usuarios cargan archivos de datos CSV/Excel y solicitan información analítica; los usuarios proporcionan resultados de consultas SQL y solicitan interpretación; los usuarios solicitan desgloses de métricas, análisis de atribución, comparaciones de cohortes, análisis de experimentos A/B; los usuarios mencionan palabras clave de análisis de datos como "árbol de métricas", "embudo", "retención", "tasa de conversión", "disminución de DAU", "cohorte", "atribución", etc.

No aplicable: creación pura de paneles de BI (usando xlsx), escritura SQL pura (escritura directa), limpieza de datos pura (escritura directa de scripts).
