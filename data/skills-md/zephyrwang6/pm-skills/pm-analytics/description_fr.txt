À partir des phénomènes de données, générez des recommandations de décision de produit exploitables et générez-les sous forme de rapports HTML visuels. Déclenché lorsque l'utilisateur dit « Analyser cet ensemble de données », « Pourquoi cette métrique a-t-il chuté », « Aidez-moi à faire une analyse de rétention », « Quelles sont les raisons de l'attrition des utilisateurs », « Voir quelle étape de l'entonnoir a été abandonnée » ou « Donnez-moi un rapport d'analyse des données ».

Également applicable : les utilisateurs téléchargent des fichiers de données CSV/Excel et demandent des informations analytiques ; les utilisateurs fournissent des résultats de requête SQL et demandent une interprétation ; les utilisateurs demandent des ventilations de métriques, des analyses d'attribution, des comparaisons de cohortes, des analyses d'expériences A/B ; les utilisateurs mentionnent des mots-clés d'analyse de données tels que « arbre métrique », « entonnoir », « rétention », « taux de conversion », « déclin des DAU », « cohorte », « attribution », etc.

Non applicable : création pure de tableaux de bord BI (à l'aide de xlsx), écriture pure SQL (écriture directe), nettoyage pur des données (écriture directe de scripts).
