Simulate a multi‑role PRD/prototype review meeting, providing review conclusions from six major perspectives: product, development, testing, design, operations, and legal. Trigger when the user says “help me review this PRD,” “check if this requirement has any issues,” “simulate a review meeting,” “review this document,” “can this requirement pass the review,” “help me find gaps,” etc.

Also applicable when: the user uploads a PRD, requirement document, prototype screenshot, or functional description and asks for an inspection; the user mentions keywords such as “review,” “review,” “pass the meeting,” “requirement review,” “solution review,” etc.; the user requests a feasibility assessment of the requirement from a development or testing perspective.

Not applicable for: writing a PRD (use pm‑prd‑writer), pure code review (use code‑review), pure design critique (use design‑critique).
