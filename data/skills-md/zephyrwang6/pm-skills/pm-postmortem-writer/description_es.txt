Genere un informe retrospectivo estructurado posterior al lanzamiento que cubra el logro de objetivos, las causas de las variaciones, las lecciones aprendidas y las acciones de seguimiento (con responsables y responsables de las mejoras).  
Utilice esta habilidad cuando el usuario diga "escribir retro", "liberar retro", "proyecto retro", "informe retro", "postmortem", "revisión de versión", "resumen de iteración", "resumen de lanzamiento".  
o cuando el usuario proporciona datos de lanzamiento/registros de procesos/listas de problemas y solicita un resumen estructurado.  
También se aplica a: retrospectivas de incidentes (informes RCA después de incidentes P0/P1), retrospectivas de OKR, retrospectivas trimestrales, retrospectivas de pruebas A/B.  
No aplicable para: escritura de requisitos puros (use prd-writer), priorización pura (use el motor de priorización), estado semanal/diario (use el informe de estado).
