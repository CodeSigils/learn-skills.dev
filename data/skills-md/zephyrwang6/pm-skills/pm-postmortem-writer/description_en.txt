Generate a structured postmortem report covering goal achievement, variance reasons, lessons learned, and follow-up actions (with responsibility assignment and improvement owner). Use this Skill when the user says "write postmortem," "launch postmortem," "project postmortem," "postmortem report," "postmortem," "release review," "iteration summary," or "launch summary," or when the user provides launch data / process logs / issue lists and requests a structured summary. Also applies to: incident postmortem (RCA report after P0/P1 incidents), OKR review, quarterly review, A/B test postmortem. Not applicable for: pure requirement writing (use prd-writer), pure prioritization (use prioritization-engine), weekly/daily status (use status-report).
