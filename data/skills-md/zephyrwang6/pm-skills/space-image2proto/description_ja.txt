反復改良と学習メモリを備えたスクリーンショットから HTML へのプロトタイプ ジェネレーター。このスキルは、ユーザーが UI のスクリーンショット、モックアップ、ワイヤーフレーム、または画像を提供し、それを動作する HTML プロトタイプとして再現したい場合、または以前に生成した既存のプロトタイプを変更したい場合に使用します。また、「照这个做原型」、「参考这个图」、「握るこれ页面画出来」、「この UI はプロトタイプを作成する必要があります」、「このデザインを複製する」、「このモックアップを HTML に変換する」、「帮我出力原型」、「根据截图出力 HTML」、または次のようなリクエストと組み合わせた画像添付ファイルでもトリガーされます。 「输出HTML」、「做成页面」、「帮我实现」。ユーザーが「加一字段」や「这个也一样」などの短い指示を含むスクリーンショットを送信しただけの場合でも、このスキルは適用されます。つまり、表示されている UI を変更または複製することをユーザーが求めていることを意味します。疑わしい場合、会話に UI スクリーンショットがある場合は、このスキルを使用してください。
