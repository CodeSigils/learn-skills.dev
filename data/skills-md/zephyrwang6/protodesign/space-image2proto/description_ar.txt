منشئ نموذج أولي للقطة شاشة إلى HTML مع تحسين تكراري وذاكرة تعليمية. استخدم هذه المهارة عندما يقدم المستخدم لقطة شاشة، أو نموذج بالحجم الطبيعي، أو إطار سلكي، أو صورة لأي واجهة مستخدم ويريد إعادة إنتاجها كنموذج أولي HTML عامل - أو عندما يريد تعديل نموذج أولي موجود قام بإنشائه مسبقًا. يتم تشغيله أيضًا على: "照这个做原型"، "参考这个图"، "把这个页面画出来"، "تحتاج واجهة المستخدم هذه إلى إنشاء نموذج أولي"، "تكرار هذا التصميم"، "تحويل هذا النموذج بالحجم الطبيعي إلى HTML"، "帮我出个原型"، "根据截图输出 HTML"، أو أي مرفق صورة مدمج مع طلبات مثل "输出 HTML"، أو "做成页面"، أو "帮我实现". حتى إذا أرسل المستخدم لقطة شاشة تحتوي على تعليمات موجزة مثل "加一个字段" أو "这个也一样"، تنطبق هذه المهارة - فهذا يعني أنه يريد منك تعديل واجهة المستخدم المعروضة أو تكرارها. عندما تكون في شك، إذا كانت هناك لقطة شاشة لواجهة المستخدم في المحادثة، فاستخدم هذه المهارة.
