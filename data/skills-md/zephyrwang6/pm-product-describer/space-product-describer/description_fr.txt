Aidez les utilisateurs à générer une description complète du produit à partir de six dimensions, permettant à l’IA de produire des prototypes ou du code de haute qualité en un seul passage. Utilisez cette compétence lorsque l'utilisateur dit « Je veux créer un produit », « Aidez-moi à décrire ce produit », « Je veux créer un outil XX », « Décrire un produit à partir de zéro », « Comment décomposer un produit », « Aidez-moi à analyser un produit à l'aide de la méthode à six dimensions » ou « Je veux développer une application XX ».

Applicable également : l’utilisateur a une vague idée de produit mais ne sait pas comment la décrire systématiquement ; l'utilisateur doit donner des instructions à un agent pour créer un produit/prototype mais la description est trop générique ; l'utilisateur souhaite pratiquer une pensée structurée ; l'utilisateur doit rédiger la description préliminaire d'un plan de produit ou d'une solution technique.

Non applicable : le projet est déjà au stade PRD (utiliser pm‑prd‑writer) ; le prototype doit être dessiné (utilisez pm‑image2proto).
