Help users generate a complete product description from six dimensions, enabling AI to output high‑quality prototypes or code in a single pass. Use this skill when the user says “I want to create a product,” “Help me describe this product,” “I want to build an XX tool,” “Describe a product from scratch,” “How to decompose a product,” “Help me analyze a product using the six‑dimensional method,” or “I want to develop an XX application.”

Also applicable: the user has a vague product idea but doesn’t know how to describe it systematically; the user needs to give an agent instructions to create a product/prototype but the description is too generic; the user wants to practice structured thinking; the user needs to write the preliminary description for a product plan or technical solution.

Not applicable: the project is already at the PRD stage (use pm‑prd‑writer); the prototype needs to be drawn (use pm‑image2proto).
