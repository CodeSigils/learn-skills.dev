Compétences complètes en analyse de données, prenant en charge le traitement des données tabulaires (CSV/Excel), de documents (PDF/DOCX/MD) et d'images. Le flux de travail principal suit strictement : 1. Exploration sécurisée : lisez uniquement les métadonnées et un petit échantillon, ne chargez jamais de données complètes pour éviter un débordement de jeton ; 2. Contrôle qualité : détection automatique des valeurs manquantes, dupliquées et incohérentes ; 3. Exécution de code : nettoyer, analyser et visualiser via Python (Pandas/Matplotlib) ; 4. Validation des résultats et génération de rapports. Scénarios applicables : analyse exploratoire des données (EDA), extraction de données multimodales, création de graphiques et génération de rapports d'analyse des données.
