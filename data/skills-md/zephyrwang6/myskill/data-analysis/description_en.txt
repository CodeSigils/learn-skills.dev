End-to-end data analysis skills supporting tabular (CSV/Excel), document (PDF/DOCX/MD), and image data processing. Core workflow strictly follows: 1. Safe exploration: read only metadata and a small sample, never full load to avoid token overflow; 2. Quality check: automatically detect missing values, duplicates, and consistency; 3. Code execution: clean, analyze, and visualize with Python (Pandas/Matplotlib); 4. Result validation and report generation. Use cases: exploratory data analysis (EDA), multimodal data extraction, charting, and insight report generation.
