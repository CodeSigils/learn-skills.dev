Habilidades de análisis de datos de un extremo a otro que admiten tablas (CSV/Excel), documentos (PDF/DOCX/MD) y procesamiento de imágenes. El flujo de trabajo principal sigue estrictamente lo siguiente: 1. Exploración segura: lee solo metadatos y una pequeña muestra, nunca datos completos para evitar el desbordamiento de tokens; 2. Control de calidad: detecta automáticamente problemas faltantes, duplicados y de coherencia; 3. Ejecución de código: limpia, analiza y visualiza mediante Python (Pandas/Matplotlib); 4. Validación de resultados y generación de informes. Casos de uso: análisis exploratorio (EDA), extracción de datos multimodal, gráficos y generación de informes de conocimientos.
