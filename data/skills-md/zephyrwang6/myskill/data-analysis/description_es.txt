Habilidades de análisis de datos de un extremo a otro que admiten tablas (CSV/Excel), documentos (PDF/DOCX/MD) y procesamiento de imágenes. El flujo de trabajo principal sigue estrictamente lo siguiente: 1. Exploración segura: solo lectura de metadatos y una pequeña muestra, nunca carga completa para evitar el desbordamiento del token; 2. Control de calidad: detección automática de problemas faltantes, duplicados y de coherencia; 3. Ejecución de código: limpiar, analizar y visualizar con Python (Pandas/Matplotlib); 4. Validación de resultados y generación de informes. Casos de uso: análisis exploratorio (EDA), extracción de datos multimodal, gráficos y generación de informes de conocimientos.
