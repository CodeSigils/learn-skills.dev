Helfen Sie Benutzern, durch eine interaktive Frage-und-Antwort-Runde einen benutzerdefinierten Skill zur Batch-Bildgenerierung zu erstellen. Es ist keine Codierung erforderlich – beantworten Sie einfach die Fragen, um einen vollständig nutzbaren Skill zur Bildgenerierung zu erstellen. Wird ausgelöst, wenn der Benutzer sagt: „Helfen Sie mir, einen Bild-Skill zu erstellen“, „Ich möchte einen Illustrations-Skill erstellen“, „Erstellen Sie einen Stapelbild-Skill“, „Wie erstelle ich einen Skill zur Bildgenerierung“ oder „Erstellen Sie mir einen KI-Zeichen-Skill.“ Unterstützt Artikelillustrationen, Logo-Design, Storyboard-Panels, Social-Media-Bilder, Poster und jedes andere Bildszenario.
