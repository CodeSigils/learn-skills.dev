Анализируйте структуру статьи и создавайте пакетные иллюстрации с помощью искусственного интеллекта, вызывая API Gemini для создания профессиональных логических диаграмм/концептуальных карт для каждого абзаца. Срабатывает, когда пользователь говорит «пакетные иллюстрации», «проиллюстрировать статью», «создать иллюстрации для статьи» или «добавить иллюстрации к этой статье». Поддерживает два стиля: минималистичный рисованный стиль и стиль архитектурного чертежа. Автоматически сохраняет в каталог изображений Obsidian и вставляет в документ.
