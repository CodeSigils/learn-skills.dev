Vérifiez et améliorez la qualité du code ABAP en utilisant les principes abaplint et Clean ABAP. Utilisez cette compétence lorsque les utilisateurs demandent à vérifier, lint, valider, réviser ou analyser le code ABAP pour détecter les erreurs de syntaxe, la conformité du code propre, la qualité du code, les meilleures pratiques ou le respect des directives Clean ABAP. À utiliser également lorsque les utilisateurs demandent à configurer abaplint, à configurer abaplint.json ou à exécuter abaplint sur leur projet ABAP. Les déclencheurs incluent des requêtes telles que « vérifier ce code ABAP », « lint mon ABAP », « exécuter abaplint », « configurer abaplint », « est-ce un ABAP propre », « réviser mon ABAP » ou « analyser la qualité du code ABAP ».
