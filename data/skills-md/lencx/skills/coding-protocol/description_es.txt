Protocolo de ejecución escalado de riesgo para una codificación confiable. Evita suposiciones silenciosas, ingeniería excesiva, ediciones colaterales, afirmaciones no verificadas y comprobaciones fallidas silenciadas. Aplicar de forma predeterminada a cada tarea de codificación: cambios de código, corrección de errores, refactorizaciones, revisiones, depuración y planes de implementación; mantenga ligeras las ediciones triviales y las tareas de solo lectura.
