Протокол выполнения с масштабированием риска для надежного кодирования. Предотвращает молчаливые предположения, чрезмерное проектирование, сопутствующие правки, непроверенные утверждения и замалчивание неудачных проверок. Применяется по умолчанию к каждой задаче кодирования — изменения кода, исправления ошибок, рефакторинг, проверки, отладка и планы реализации; делайте тривиальные изменения и задачи только для чтения легкими.
