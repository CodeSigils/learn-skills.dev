Используйте, когда пользователь запрашивает схему архитектуры Azure — виртуальную сеть/сеть, службу приложений, AKS, целевую зону, несколько регионов или любую диаграмму, созданную с помощью значков служб Azure. Выполняет сборку с помощью механизма декларативного макета с использованием достоверных трафаретов Azure, проверяет (трафареты/цвета/вложение/геометрию), запускает самопроверку изображения на основе рендеринга. Вывод по умолчанию — .drawio; PNG/SVG только по запросу.
