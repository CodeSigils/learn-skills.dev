Используйте, когда пользователь запрашивает диаграмму архитектуры AWS — VPC/сеть, управляемая событиями, целевая зона, несколько зон доступности, бессерверный конвейер или любая диаграмма, построенная с помощью значков сервисов AWS. Создается с помощью декларативного механизма компоновки с использованием трафаретов mxgraph.aws4, проверяющих (трафареты/цвета/вложение/геометрию), запускает самопроверку визуального представления на основе рендеринга. Вывод по умолчанию — .drawio; PNG/SVG только по запросу.
