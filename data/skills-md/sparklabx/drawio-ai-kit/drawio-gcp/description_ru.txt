Используйте, когда пользователь запрашивает диаграмму архитектуры GCP или Google Cloud — VPC/сеть, GKE, Cloud Run, зона приземления, несколько регионов или любую диаграмму, созданную с помощью значков служб GCP. Создает с помощью декларативного механизма компоновки с использованием достоверных трафаретов GCP, проверяет (трафареты/цвета/вложение/геометрию), запускает самопроверку изображения на основе рендеринга. Вывод по умолчанию — .drawio; PNG/SVG только по запросу.
