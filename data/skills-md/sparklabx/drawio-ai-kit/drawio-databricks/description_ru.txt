Используйте, когда пользователь запрашивает схему архитектуры Databricks Lakehouse — архитектуру медальона (бронза/серебро/золото), Delta Lake, каталог Unity, развертывание рабочей области, плоскость данных/плоскость управления или любую диаграмму, созданную с помощью значков Databricks. Создает с помощью декларативного механизма компоновки с использованием трафаретов на основе достоверности, проверяет (трафареты/цвета/вложение/геометрию), запускает самопроверку изображения на основе рендеринга. Вывод по умолчанию — .drawio; PNG/SVG только по запросу.
