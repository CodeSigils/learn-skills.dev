Motore canonico del ciclo di vita dei ticket per l'orchestrazione multi-agente. Due backend: (1) bundle YAML di file system per la gestione del lavoro a livello di progetto (roadmap → bundle → ticket → revisione), (2) ticket durevoli supportati da DB per ciclo di vita di richiesta/blocco/chiusura a livello di sessione. Questa abilità è l'unica fonte di verità per tutte le operazioni di ticket.
