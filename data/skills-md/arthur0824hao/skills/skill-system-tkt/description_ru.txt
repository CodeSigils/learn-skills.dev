Механизм жизненного цикла билетов Canonical для многоагентной оркестрации. Два бэкэнда: (1) пакеты YAML файловой системы для управления работой на уровне проекта (дорожная карта → пакет → билеты → проверка), (2) устойчивые билеты на базе БД для жизненного цикла заявок/блокировок/закрытий на уровне сеанса. Этот навык является единственным источником достоверной информации для всех операций с билетами.
