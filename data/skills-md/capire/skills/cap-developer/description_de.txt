Fachkundige Anleitung zum Erstellen und Erweitern von CAP-Anwendungen (Cloud Application Programming Model) in Node.js oder Java. Behandelt Projektinitialisierung, CDS-Modellierung, deklarative Anmerkungen und Best Practices für benutzerdefinierte Handler für beide Laufzeiten. Verwenden Sie es, wenn Sie eine neue CAP-App erstellen, eine bestehende erweitern oder CAP-Code auf Richtigkeit und Redewendungen überprüfen – unabhängig davon, ob der Stack Node.js oder Java ist.
