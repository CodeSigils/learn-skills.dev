Добавьте интеграцию удаленного сервиса в существующее приложение CAP Node.js, используя шаблон Calesi. Импортирует внешние API (из других приложений CAP или источников OData/S4), создает представления потребления, подключает обработчики делегирования и объединения данных и проверяет результат с помощью cds watch. Используйте, когда разработчик хочет использовать внешнюю службу в своем приложении CAP.
