Agregue una integración de servicio remoto a una aplicación CAP Node.js existente utilizando el patrón Calesi. Importa API externas (de otras aplicaciones CAP u fuentes OData/S4), crea vistas de consumo, conecta controladores de delegación y federación de datos y valida el resultado con cds watch. Úselo cuando un desarrollador quiera consumir un servicio externo en su aplicación CAP.
