Ajoutez une intégration de services à distance à une application CAP Node.js existante à l'aide du modèle Calesi. Importe des API externes (à partir d'autres applications CAP ou de sources OData/S4), crée des vues de consommation, connecte les gestionnaires de délégation et de fédération de données et valide le résultat avec cds watch. À utiliser lorsqu'un développeur souhaite utiliser un service externe dans son application CAP.
