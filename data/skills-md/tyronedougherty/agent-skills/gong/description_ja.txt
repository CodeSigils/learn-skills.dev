Gong のパブリック REST API を介して Gong の通話記録を検索し、取得します。ユーザーが通話のコンテキストを検索したり、顧客との会話から引用を取得したり、アカウントに関する最近の通話を要約したり、機能/トピック/競合他社についての言及のトランスクリプトを検索したり、通話全体でのセマンティック/自然言語検索をしたり、特定の参加者と話し合った内容を解決したり、通話録音をダウンロードしたりする場合に使用します。製品のユースケース (機能のリクエスト、問題点、機能領域に関する顧客のフィードバック、PRD/ロードマップへの入力)、販売/CS のユースケース (アカウントの準備、更新の状況、取引レビュー、競合上の異議申し立て、発見メモ)、および GTM/マーケティングのユースケース (顧客の声の見積もり、メッセージング調査、ケーススタディの調達、競合他社に対するポジショニング、カテゴリ言語) をカバーします。トリガーには、「... での通話の検索」、「[顧客] の発言...」、「... との先週の通話の要約」、「... について Gong トランスクリプトを取得」、「... について Gong を検索」、「顧客が発言した通話...」、「... のビデオをダウンロード」、「[機能] について顧客が何と言っているか...」、「... に関する顧客のフィードバックを取得」、「... に関する問題点を見つける」、「... に関する機能リクエスト」、「... についての調査」が含まれます。 「... に関する PRD」、「... に関する顧客の声の引用」、「... に関する顧客の言葉」、「私たちが聞いている反対意見...」、「見込み客は [競合他社] についてどのように話しているのか...」、「... の更新の背景」、「[アカウント] の電話に備えてください...」。
