Ищите и получайте расшифровки вызовов Gong через общедоступный REST API Gong. Используйте, когда пользователь хочет найти контекст звонка, извлечь цитаты из разговоров с клиентами, суммировать недавние звонки для учетной записи, выполнить поиск в стенограммах упоминаний функции/темы/конкурента, выполнить семантический поиск/поиск на естественном языке между звонками, решить, что обсуждалось с конкретными участниками, или загрузить запись разговора. Охватывает варианты использования продукта (запросы функций, болевые точки, отзывы клиентов о функциональной области, входные данные для PRD/дорожной карты), варианты использования продаж/CS (подготовка аккаунта, контекст продления, обзоры сделок, возражения конкурентов, заметки об открытии) и варианты использования GTM/маркетинга (цитаты клиентов, исследования сообщений, поиск тематических исследований, позиционирование по сравнению с конкурентами, язык категорий). Триггеры включают в себя «найти звонки, где...», «что [клиент] сказал о...», «подвести итоги звонков на прошлой неделе с...», «получить стенограммы Gong для...», «поиск Gong для...», «звонки, в которых клиенты выразили...», «загрузить видео о...», «что клиенты говорят о [функции]...», «получить отзывы клиентов о...», «найти болевые точки вокруг...», «запросы функций для...», «исследование PRD на...», «цитаты из уст клиентов о...», «язык клиентов вокруг...», «возражения, о которых мы слышим...», «как потенциальные клиенты говорят о [конкуренте]...», «контекст обновления для...», «подготовьте меня к звонку в [аккаунт]...».
