Crea un dashboard HTML statico portatile dalle esportazioni CSV o XLSX di e-commerce transfrontaliero ispezionando e normalizzando i dati di prodotto, calcolando metriche trasparenti e indicatori di opportunità, aggiungendo informazioni sugli agenti basate su prove ed eseguendo il rendering del modello offline in bundle. Da utilizzare quando un agente deve creare o aggiornare una dashboard di TikTok Shop, FastMoss, Amazon, Shopee o un prodotto simile; adattare le colonne di esportazione modificate; diagnosticare una tabella illeggibile; confrontare le prestazioni dei prodotti disponibili; oppure sostituisci una dashboard Streamlit con file web direttamente condivisibili.
