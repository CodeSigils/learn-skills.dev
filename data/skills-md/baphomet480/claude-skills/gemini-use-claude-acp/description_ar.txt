تفويض مهمة فرعية إلى Claude Code عبر بروتوكول عميل الوكيل (ACP). استخدم هذه المهارة عندما تريد تسليم العمل إلى Claude - الترميز الوكيل المعقد مع الوصول إلى أداة MCP، أو عمليات إعادة البناء التفصيلية متعددة الملفات، أو المهام التي تتطلب أسلوب Claude الاستدلالي، أو أي شيء حيث تعطي نقاط قوة Claude ميزة. استدعي أيضًا عندما يطلب منك المستخدم "اسأل Claude"، أو "استخدام Claude لهذا الغرض"، أو "تشغيل هذا من خلال Claude". يتعامل البرنامج النصي مع دورة حياة العملية الفرعية وإعداد جلسة ACP؛ ما عليك سوى تقديم المطالبة وقراءة stdout.
