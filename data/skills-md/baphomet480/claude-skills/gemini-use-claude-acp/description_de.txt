Delegieren Sie eine Unteraufgabe über das Agent Client Protocol (ACP) an Claude Code. Nutzen Sie diese Fähigkeit immer dann, wenn Sie Arbeit an Claude übergeben möchten – komplexe Agentencodierung mit MCP-Tool-Zugriff, detaillierte Multi-File-Refactors, Aufgaben, die Claudes Argumentationsstil erfordern, oder alles, wo Claudes Stärken einen Vorteil verschaffen. Rufen Sie es auch auf, wenn der Benutzer Sie auffordert, „Claude zu fragen“, „Claude dafür zu verwenden“ oder „dies über Claude laufen zu lassen“. Das Skript verwaltet den Lebenszyklus des Unterprozesses und die Einrichtung der ACP-Sitzung. Sie geben einfach die Eingabeaufforderung ein und lesen stdout.
