Delegue una subtarea a Claude Code a través del Protocolo de cliente agente (ACP). Utilice esta habilidad siempre que desee entregarle el trabajo a Claude: codificación agente compleja con acceso a herramientas MCP, refactorizaciones detalladas de múltiples archivos, tareas que requieran el estilo de razonamiento de Claude o cualquier cosa en la que las fortalezas de Claude brinden una ventaja. También invoca cuando el usuario te pide "preguntarle a Claude", "usar a Claude para esto" o "ejecutar esto a través de Claude". El script maneja el ciclo de vida del subproceso y la configuración de la sesión ACP; simplemente proporcione el mensaje y lea la salida estándar.
