Agent Client Protocol (ACP) を介してサブタスクを Claude Code に委任します。 MCP ツールにアクセスできる複雑なエージェント コーディング、詳細な複数ファイルのリファクタリング、クロードの推論スタイルを必要とするタスク、またはクロードの強みが有利になるあらゆる作業をクロードに引き継ぎたい場合は、このスキルをいつでも使用してください。また、ユーザーが「クロードに質問する」、「これにはクロードを使用する」、または「これをクロードを通じて実行する」ように要求したときにも呼び出します。このスクリプトは、サブプロセスのライフサイクルと ACP セッションのセットアップを処理します。プロンプトを提供して標準出力を読み取るだけです。
