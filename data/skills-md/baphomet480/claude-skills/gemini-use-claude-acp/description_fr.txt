Déléguez une sous-tâche à Claude Code via le Agent Client Protocol (ACP). Utilisez cette compétence chaque fois que vous souhaitez confier du travail à Claude : codage agent complexe avec accès à l'outil MCP, refactoriseurs multi-fichiers détaillés, tâches nécessitant le style de raisonnement de Claude ou tout ce qui donne un avantage aux points forts de Claude. Invoquez également lorsque l'utilisateur vous demande de "demander à Claude", "d'utiliser Claude pour cela" ou de "exécuter ceci via Claude". Le script gère le cycle de vie des sous-processus et la configuration de la session ACP ; vous fournissez simplement l'invite et lisez la sortie standard.
