مزامنة تغييرات مخطط TinaCMS عن طريق إعادة إنشاء القطع الأثرية المحلية وارتكابها. يُستخدم عندما يتم تعديل مخطط Tina (tina/config.ts)، أو عند إضافة أنواع كتل جديدة أو حقول تجميع، أو عندما يفشل إنشاء tinacms مع وجود أخطاء "غير قادر على البذور". يتم تشغيلها عند "مزامنة tina"، أو "إعادة بناء tina"، أو "تغيير مخطط tina"، أو "تجديد عناصر tina"، أو "ملف قفل tina"، أو بعد أي تعديل على tina/config.ts.
