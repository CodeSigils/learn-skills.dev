Применяет брендинг Generic Service (GS) к документам Markdown и создает фирменные PDF-файлы. Это ОСНОВНОЙ навык для создания PDF-файлов из Markdown, создания предложений или применения шаблонов для конкретного проекта. Не используйте общий навык «pdf» для создания документов из шаблонов Markdown или React.
