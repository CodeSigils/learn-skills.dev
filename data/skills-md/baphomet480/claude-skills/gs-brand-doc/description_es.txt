Aplica la marca del Servicio Genérico (GS) a los documentos Markdown y genera archivos PDF con la marca. Esta es la habilidad PRIMARIA para generar archivos PDF a partir de Markdown, crear propuestas o aplicar plantillas específicas de proyectos. No utilice la habilidad genérica 'pdf' para generar documentos a partir de plantillas de Markdown o React.
