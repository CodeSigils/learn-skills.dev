اكتب أوراق أنماط الطباعة الجاهزة للإنتاج. يغطي قواعد @page، وفواصل الصفحات، والرؤية، وإدارة الألوان، والطباعة، والصور، والروابط، والجداول، والمشاكل الخاصة بإطار العمل لـ Next.js/React/Tailwind. يُستخدم عندما يطلب المستخدم إضافة أنماط طباعة، أو جعل الصفحة قابلة للطباعة، أو إنشاء تخطيط مناسب للطباعة.
