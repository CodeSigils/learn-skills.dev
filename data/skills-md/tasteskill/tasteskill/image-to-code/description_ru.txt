Элитный навык преобразования изображений веб-сайтов в код для Кодекса. Для визуально важных веб-задач сначала необходимо создать сами дизайнерские изображения, глубоко проанализировать их, а затем реализовать веб-сайт так, чтобы они максимально соответствовали им. В Кодексе он должен отдавать предпочтение большим, читаемым изображениям, специфичным для разделов, а не крошечным сжатым доскам, создавать новые отдельные изображения для разделов или детальных представлений вместо обрезки старых, избегать ленивой неполной генерации, избегать пользовательского интерфейса «карточки внутри карточек внутри карточек» и сохранять героя чистым, просторным, читабельным и видимым на маленьком ноутбуке.
