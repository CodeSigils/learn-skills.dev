Concevez, améliorez ou révisez de manière proactive les outils Dear ImGui de haute qualité, les panneaux d'édition C++, les interfaces de développement de jeux, les tableaux de bord de débogage, les écrans de visualisation et les flux de travail de bureau. À utiliser lorsque Dear ImGui est nommé ou que le code fourni contient des preuves directes telles que `ImGui::`, `imgui.h`, `ImGuiContext` ou des symboles backend ImGui. Pour une demande d'éditeur/d'outils C++ non étiquetée, à utiliser uniquement lorsque l'utilisateur demande explicitement si Dear ImGui convient ; sinon, gardez le choix du cadre ouvert. Ne déclenchez pas une tâche qui nomme explicitement un autre framework d'interface utilisateur tel que Qt, GTK, WPF, wxWidgets, JUCE ou Slate. Couvrez l'architecture de l'interface utilisateur, la hiérarchie des informations, la disposition des espaces de quai, les systèmes de conception, les composants personnalisés, les états UX, l'interaction clavier/manette de jeu, le DPI/polices, les performances et la qualité du code.
