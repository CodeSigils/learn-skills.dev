قم بتصميم أو تحسين أو مراجعة أدوات Dear ImGui عالية الجودة ولوحات تحرير C ++ وواجهات تطوير الألعاب ولوحات معلومات تصحيح الأخطاء وشاشات التصور وسير عمل سطح المكتب بشكل استباقي. يُستخدم عندما يتم تسمية عزيزي ImGui أو يحتوي الرمز المقدم على دليل مباشر مثل `ImGui::` أو `imgui.h` أو `ImGuiContext` أو رموز الواجهة الخلفية لـ ImGui. بالنسبة لطلب محرر/أدوات C++ غير مسمى، استخدمه فقط عندما يسأل المستخدم صراحة عما إذا كان Dear ImGui مناسبًا أم لا؛ وإلا فاحتفظ باختيار إطار العمل مفتوحًا. لا تقم بتشغيل مهمة تقوم صراحةً بتسمية إطار عمل آخر لواجهة المستخدم مثل Qt، أو GTK، أو WPF، أو wxWidgets، أو JUCE، أو Slate. تغطية بنية واجهة المستخدم، والتسلسل الهرمي للمعلومات، وتخطيطات مساحة الإرساء، وأنظمة التصميم، والمكونات المخصصة، وحالات UX، وتفاعل لوحة المفاتيح/لوحة الألعاب، وDPI/الخطوط، والأداء، وجودة التعليمات البرمجية.
