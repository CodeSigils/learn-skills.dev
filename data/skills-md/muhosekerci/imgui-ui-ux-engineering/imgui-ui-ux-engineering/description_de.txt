Entwerfen, verbessern oder überprüfen Sie proaktiv hochwertige Dear ImGui-Tools, C++-Editor-Panels, Spieleentwicklungsschnittstellen, Debugging-Dashboards, Visualisierungsbildschirme und Desktop-Workflows. Wird verwendet, wenn Dear ImGui benannt ist oder der bereitgestellte Code direkte Hinweise wie „ImGui::“, „imgui.h“, „ImGuiContext“ oder ImGui-Backend-Symbole enthält. Für eine unbeschriftete C++-Editor-/Tooling-Anfrage nur verwenden, wenn der Benutzer explizit fragt, ob Dear ImGui geeignet ist; Andernfalls lassen Sie die Rahmenauswahl offen. Nicht für eine Aufgabe auslösen, die explizit ein anderes UI-Framework wie Qt, GTK, WPF, wxWidgets, JUCE oder Slate benennt. Behandeln Sie UI-Architektur, Informationshierarchie, Dockspace-Layouts, Designsysteme, benutzerdefinierte Komponenten, UX-Status, Tastatur-/Gamepad-Interaktion, DPI/Schriftarten, Leistung und Codequalität.
