Внедряйте работоспособность активной системы в контекст агента при открытии сеанса. Cron-скрипт проверяет интеграции, диск, статус шлюза, активные сессии — записывает компактный JSON. Агент читает его, прежде чем ответить на любой вопрос о статусе. Устраняет сбои устаревшего отзыва, когда агенты отвечают по памяти, а не по живому состоянию. Используйте при настройке постоянно актуальной информации о системе для автономного агента.
