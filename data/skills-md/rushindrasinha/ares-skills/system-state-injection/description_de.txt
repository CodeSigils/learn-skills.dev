Integrieren Sie bei geöffneter Sitzung den Live-Systemzustand in den Agentenkontext. Cron-Skript prüft Integrationen, Festplatte, Gateway-Status, aktive Sitzungen – schreibt kompaktes JSON. Der Agent liest es, bevor er eine Statusfrage beantwortet. Beseitigt veraltete Rückruffehler, bei denen Agenten aus dem Speicher statt aus dem Live-Status antworten. Verwenden Sie diese Option, wenn Sie eine stets aktuelle Systemerkennung für einen autonomen Agenten einrichten.
