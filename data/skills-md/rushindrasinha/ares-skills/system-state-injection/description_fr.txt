Injectez l’état du système en direct dans le contexte de l’agent à l’ouverture de la session. Le script Cron vérifie les intégrations, le disque, l'état de la passerelle, les sessions actives — écrit du JSON compact. L'agent le lit avant de répondre à toute question de statut. Élimine les échecs de rappel obsolètes où les agents répondent à partir de la mémoire au lieu de leur état actif. À utiliser lors de la configuration d’une connaissance du système toujours à jour pour un agent autonome.
