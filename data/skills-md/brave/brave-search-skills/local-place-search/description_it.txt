UTILIZZARE PER trovare luoghi nel mondo fisico: aziende, PDI, indirizzi stradali, città e strade. I risultati riportano indirizzo, coordinate, valutazione, orari di apertura e telefono, quindi i dettagli di base non richiedono una chiamata di follow-up. Autonomo: non sono richiesti ID POI o ricerche web precedenti; gli ID restituiti funzionano con local-pois e local-descriptions. Individua tramite coordinate o una stringa di posizione oppure ometti entrambi per eseguire la ricerca a livello globale. Omettere la query per esplorare un'area. Massimo 100 risultati.
