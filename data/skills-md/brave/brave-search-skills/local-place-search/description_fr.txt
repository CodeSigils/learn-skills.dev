UTILISER POUR trouver des lieux dans le monde physique : entreprises, POI, adresses postales, villes et rues. Les résultats contiennent l'adresse, les coordonnées, la note, les heures d'ouverture et le téléphone, les détails de base ne nécessitent donc aucun appel de suivi. Autonome : aucun identifiant de POI ni recherche préalable sur le Web n'est requis ; les identifiants qu'il renvoie fonctionnent avec les pois locaux et les descriptions locales. Recherchez par coordonnées ou une chaîne de localisation, ou omettez les deux pour effectuer une recherche globale. Omettez la requête pour parcourir une zone. Max 100 résultats.
