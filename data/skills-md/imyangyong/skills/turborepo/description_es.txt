Guía del sistema de compilación monorepo de Turborepo. Se activa con: turbo.json, canalizaciones de tareas, dependsOn, caché, caché remoto, el CLI “turbo”, --filter, --affected, optimización de CI, variables de entorno, paquetes internos, estructura/buenas prácticas del monorepo y límites.

Usar cuando el usuario: configura tareas/flujos de trabajo/canales, crea paquetes, configura el monorepo, comparte código entre aplicaciones, ejecuta paquetes modificados/afectados, depura la caché, o tiene directorios de apps/paquetes.
