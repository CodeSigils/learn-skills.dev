Guide du système de build monorepo Turborepo. Se déclenche sur : turbo.json, pipelines de tâches, dependsOn, mise en cache, cache distant, l’interface en ligne de commande « turbo », --filter, --affected, optimisation CI, variables d’environnement, paquets internes, structure monorepo / bonnes pratiques et limites.

À utiliser lorsque l’utilisateur : configure des tâches/flux de travail/pipelines, crée des paquets, met en place le monorepo, partage du code entre applications, exécute les paquets modifiés/affectés, débogue le cache ou possède des répertoires apps/paquets.

Veuillez toujours répondre dans la langue de l’utilisateur.
