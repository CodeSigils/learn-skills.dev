Навыки сокращения токенов для агентов кодирования. Сжимает выходные данные инструмента JSON, журналы сборки, результаты поиска grep/ripgrep, исходный код и историю разговоров так же, как это делает прокси-сервер Headroom, — но в контексте, без двоичной установки. Используйте этот навык всякий раз, когда агент собирается вставить большой результат инструмента (массив JSON из 1000 строк, журнал pytest из 5000 строк, grep из 200 результатов, исходный файл из 1000 строк) в свое следующее сообщение, или когда разговор агента приближается к пределу контекста, или когда пользователь жалуется на стоимость токена или задержку. Также используйте его для формирования собственных результатов работы агента: пропустите церемонию, не повторяйте код, уже отображенный на экране, отбросьте рассуждения о рутинных действиях. Триггеры: «сжать этот вывод», «это слишком долго», «обрезать», «суммировать журнал», «сократить токены», «контекст заполнен», «контекст заканчивается», «слишком много токенов», «сделать его короче», «быть кратким».
