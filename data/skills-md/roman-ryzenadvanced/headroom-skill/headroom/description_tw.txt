編碼代理的令牌減少技能。以與 Headroom 代理程式相同的方式壓縮 JSON 工具輸出、建置日誌、grep/ripgrep 搜尋結果、原始程式碼和對話歷史記錄 - 但在上下文中，無需二進位安裝。每當代理程式即將將大型工具結果（1000 行 JSON 數組、5000 行 pytest 日誌、200 個結果 grep、1000 行原始檔）貼上到其下一則訊息時，或者當代理程式的對話接近上下文限制時，或當使用者抱怨令牌成本或延遲時，請抱怨使用此技能。也可以用它來塑造代理自己的輸出：跳過儀式，不要重述螢幕上已有的程式碼，在例行程序中放棄推理。觸發器：「壓縮此輸出」、「這太長」、「修剪」、「總結日誌」、「減少標記」、「上下文已滿」、「脫離上下文」、「標記太多」、「使其更短」、「簡潔」。
