코딩 에이전트를 위한 토큰 감소 기술. Headroom 프록시와 동일한 방식으로 JSON 도구 출력, 빌드 로그, grep/ripgrep 검색 결과, 소스 코드 및 대화 기록을 압축하지만 바이너리 설치 없이 컨텍스트 내에서 압축합니다. 에이전트가 대규모 도구 결과(1000행 JSON 배열, 5000행 pytest 로그, 200행 grep, 1000행 소스 파일)를 다음 메시지에 붙여넣으려고 할 때마다, 또는 에이전트의 대화가 컨텍스트 제한에 접근하고 있거나 사용자가 토큰 비용이나 대기 시간에 대해 불평할 때 이 기술을 사용하세요. 또한 이를 사용하여 에이전트 자체 출력을 형성합니다. 예식을 건너뛰고, 화면에 이미 표시된 코드를 다시 언급하지 말고, 루틴 차례에 추론을 삭제합니다. 트리거: "이 출력을 압축합니다", "너무 깁니다", "자르기", "로그 요약", "토큰 줄이기", "컨텍스트가 가득 찼습니다", "컨텍스트 부족", "토큰이 너무 많습니다", "더 짧게 만듭니다", "간결하게 만듭니다".
