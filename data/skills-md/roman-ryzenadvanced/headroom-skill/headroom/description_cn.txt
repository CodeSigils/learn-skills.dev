编码代理的令牌减少技能。以与 Headroom 代理相同的方式压缩 JSON 工具输出、构建日志、grep/ripgrep 搜索结果、源代码和对话历史记录 - 但在上下文中，无需二进制安装。每当代理即将将大型工具结果（1000 行 JSON 数组、5000 行 pytest 日志、200 个结果 grep、1000 行源文件）粘贴到其下一条消息中时，或者当代理的对话接近上下文限制时，或者当用户抱怨令牌成本或延迟时，请使用此技能。还可以用它来塑造代理自己的输出：跳过仪式，不要重述屏幕上已有的代码，在例行程序中放弃推理。触发器：“压缩此输出”、“这太长”、“修剪”、“总结日志”、“减少标记”、“上下文已满”、“脱离上下文”、“标记太多”、“使其更短”、“简洁”。
