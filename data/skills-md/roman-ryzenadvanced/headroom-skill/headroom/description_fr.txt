Compétence de réduction de jetons pour les agents de codage. Compresse la sortie de l'outil JSON, les journaux de construction, les résultats de recherche grep/ripgrep, le code source et l'historique des conversations de la même manière que le proxy Headroom, mais en contexte, sans installation binaire. Utilisez cette compétence chaque fois qu'un agent est sur le point de coller un résultat d'outil volumineux (un tableau JSON de 1 000 lignes, un journal pytest de 5 000 lignes, un grep de 200 résultats, un fichier source de 1 000 lignes) dans son prochain message, ou lorsque la conversation de l'agent approche de la limite de contexte, ou lorsque l'utilisateur se plaint du coût ou de la latence du jeton. Utilisez-le également pour façonner le propre résultat de l'agent : ignorez la cérémonie, ne reformulez pas le code déjà à l'écran, abandonnez le raisonnement lors des tours de routine. Déclencheurs : « compresser cette sortie », « c'est trop long », « couper », « résumer le journal », « réduire les jetons », « le contexte est plein », « manquer de contexte », « trop de jetons », « le rendre plus court », « être concis ».
