مساعد العملية الكاملة العنبر لمحاكاة الديناميكيات الجزيئية. يقوم كلود مباشرة ببناء النظام (antechamber/parmchk2/tleap) وتحليل المسار (cpptraj + Python التخطيط)، بينما يقوم المستخدم بتشغيل خطوات المحاكاة المكثفة حسابيًا (pmemd.cuda/pmemd.MPI/sander) بنفسه. يدعم الأنظمة المعقدة للبروتين والبروتين والبروتين النقي. يقوم تلقائيًا بإنشاء ملفات إدخال Amber (min.in / Heat.in / Density.in / Product.in) والبرامج النصية للتنفيذ (bash / Slurm / PBS). تشمل قدرات التحليل RMSD، وRMSF، ونصف قطر الدوران، وSASA، والبنية الثانوية DSSP، وتحليل روابط الهيدروجين، ومصفوفة المسافة، وتحليل المجموعات، وتحليل المكونات الرئيسية (PCA)، ومخططات المناظر الطبيعية للطاقة الحرة، وحسابات الطاقة الحرة الملزمة MM-PBSA/GBSA. يتم تشغيله عندما يذكر المستخدم Amber، ومحاكاة MD، والديناميكيات الجزيئية، ومحاكاة البروتين، وربط الروابط، وغرفة الانتظار، وtleap/LEaP، وpmemd، وsander، وcpptraj، وMMMPBSA، وتحليل RMSD، وتحليل المسار.
