Amber 분자 역학 시뮬레이션 전체 프로세스 보조자. Claude는 시스템 구성(antechamber/parmchk2/tleap)과 궤적 분석(cpptraj + Python 플로팅)을 직접 수행하는 반면, 사용자는 계산 집약적인 시뮬레이션 단계(pmemd.cuda/pmemd.MPI/sander)를 직접 실행합니다. 단백질-리간드, 순수 단백질, 단백질-단백질 복합체 시스템을 지원합니다. Amber 입력 파일(min.in/heat.in/density.in/product.in)과 실행 스크립트(bash/Slurm/PBS)를 자동으로 생성합니다. 분석 기능에는 RMSD, RMSF, 회전 반경, SASA, DSSP 2차 구조, 수소 결합 분석, 거리 매트릭스, 클러스터링 분석, 주성분 분석(PCA), 자유 에너지 지형 플롯, MM-PBSA/GBSA 결합 자유 에너지 계산이 포함됩니다. 사용자는 Amber, MD 시뮬레이션, 분자 역학, 단백질 시뮬레이션, 리간드 결합, antechamber, tleap/LEaP, pmemd, sander, cpptraj, MMPBSA, RMSD 분석, 궤적 분석을 언급할 때 이를 트리거합니다.
