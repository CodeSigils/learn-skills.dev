Amber full-process assistant for molecular dynamics simulations. Claude directly performs system building (antechamber/parmchk2/tleap) and trajectory analysis (cpptraj + Python plotting), while the user runs the computationally intensive simulation steps (pmemd.cuda/pmemd.MPI/sander) themselves. Supports protein‑ligand, pure protein, and protein‑protein complex systems. Automatically generates Amber input files (min.in / heat.in / density.in / product.in) and execution scripts (bash / Slurm / PBS). Analysis capabilities include RMSD, RMSF, radius of gyration, SASA, DSSP secondary structure, hydrogen‑bond analysis, distance matrix, clustering analysis, principal component analysis (PCA), free‑energy landscape plots, MM‑PBSA/GBSA binding free‑energy calculations. Triggered when the user mentions Amber, MD simulation, molecular dynamics, protein simulation, ligand binding, antechamber, tleap/LEaP, pmemd, sander, cpptraj, MMPBSA, RMSD analysis, trajectory analysis.
