Automated molecular docking workflow with AutoDock Vina. Use when users want to dock ligands to protein receptors, run virtual screening, prepare PDB files for docking, extract residues, or perform structure-based drug design. Supports multiple ligand formats (SMILES, SDF, MOL2, PDB, CDX), automatic receptor preparation, parallel docking execution, and result visualization. Trigger for any docking-related task, PDB file preparation, or when working with protein-ligand complexes.
