Générez une feuille de triche HTML personnelle Claude Code à partir de votre liste de compétences en direct, de la configuration CLAUDE.md et des propres modèles de comportement de Claude. Produit un fichier HTML autonome à thème sombre avec 8 onglets : raccourcis, compétences (sous-catégorisées), modèles d'invite, précision, jetons, routage de modèle, catalogue complet et fonctionnement de Claude (méta-informations + suggestions). Open-source – fonctionne pour tout utilisateur de Claude Code.
