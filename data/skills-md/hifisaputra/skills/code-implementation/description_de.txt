Implementiert eine Codeaufgabe mithilfe eines strukturierten Plan-First-Ansatzes mit TDD, wenn Tests vorhanden sind, oder direkter Implementierung für Dokument-/Konfigurationsänderungen. Wird verwendet, wenn der Benutzer „dies implementieren“, „diese Funktion erstellen“, „diesen Fehler beheben“ oder eine Anfrage zum Schreiben von Code für eine genau definierte Aufgabe sagt.
