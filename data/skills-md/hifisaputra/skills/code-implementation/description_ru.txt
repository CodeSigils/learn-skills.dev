Реализует задачу кода, используя структурированный подход «сначала план» с TDD, если существуют тесты, или прямую реализацию для изменений документации и конфигурации. Используйте, когда пользователь говорит «реализовать это», «создать эту функцию», «исправить эту ошибку» или при любом запросе на написание кода для четко определенной задачи.
