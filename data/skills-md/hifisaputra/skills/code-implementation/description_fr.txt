Implémente une tâche de code en utilisant une approche structurée axée sur le plan avec TDD lorsque des tests existent, ou une implémentation directe pour les modifications de documentation/configuration. À utiliser lorsque l'utilisateur dit « implémenter ceci », « créer cette fonctionnalité », « corriger ce bug » ou toute demande d'écriture de code pour une tâche bien définie.
