Examen approfondi du code d'un PR : vérifie l'exactitude, la sécurité, les performances, la cohérence du style, la couverture des tests et vérifie que le PR résout son problème associé. À utiliser lorsque l'utilisateur dit « examiner ce PR », « vérifier ce PR », « regarder cette différence » ou toute demande de révision des modifications de code.
