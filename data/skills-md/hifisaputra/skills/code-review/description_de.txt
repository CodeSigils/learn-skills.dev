Gründliche Codeüberprüfung einer PR – prüft Korrektheit, Sicherheit, Leistung, Stilkonsistenz, Testabdeckung und verifiziert, dass die PR das damit verbundene Problem behebt. Wird verwendet, wenn der Benutzer sagt: „Überprüfen Sie diese PR“, „Überprüfen Sie diese PR“, „Sehen Sie sich diesen Unterschied an“ oder wenn er eine Anfrage zur Überprüfung von Codeänderungen stellt.
