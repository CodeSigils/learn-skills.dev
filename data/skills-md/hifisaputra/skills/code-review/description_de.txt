Gründliche Codeüberprüfung eines PR – prüft Korrektheit, Sicherheit, Leistung, Stilkonsistenz, Testabdeckung und überprüft, ob der PR das damit verbundene Problem behebt. Wird verwendet, wenn der Benutzer sagt: „Überprüfen Sie diese PR“, „Überprüfen Sie diese PR“, „Sehen Sie sich diesen Unterschied an“ oder eine Anfrage zur Überprüfung von Codeänderungen.
