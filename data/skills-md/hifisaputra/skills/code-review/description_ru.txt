Тщательная проверка кода PR — проверяет правильность, безопасность, производительность, согласованность стиля, тестовое покрытие и проверяет, решает ли PR связанную с ним проблему. Используйте, когда пользователь говорит «просмотрите этот PR», «проверьте этот PR», «посмотрите на эту разницу» или при любом запросе на просмотр изменений кода.
