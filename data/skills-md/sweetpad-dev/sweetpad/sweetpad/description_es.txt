Compila, ejecuta y prueba aplicaciones de Xcode y Swift Package desde la terminal con la CLI sweetpad ("xcodebuild para humanos"). Úsala cuando el usuario quiera compilar una aplicación iOS/macOS/Swift, ejecutarla en un simulador o dispositivo, leer errores de compilación, ejecutar pruebas o inspeccionar la configuración de compilación resuelta desde la línea de comandos, con invocaciones en modo JSON, seguras para agentes y no bloqueantes, en lugar de usar xcodebuild sin procesar.
