Compilez, exécutez et testez les applications Xcode et Swift Package depuis le terminal avec le CLI sweetpad (« xcodebuild pour les humains »). Utilisez‑le lorsque l’utilisateur veut compiler une application iOS/macOS/Swift, l’exécuter sur un simulateur ou un appareil, lire les erreurs de compilation, lancer des tests ou inspecter les paramètres de construction résolus depuis la ligne de commande — avec des appels en mode JSON, sûrs pour les agents et non bloquants, au lieu de xcodebuild brut.
