Собирайте, запускайте и тестируйте приложения Xcode и Swift Package из терминала с помощью CLI sweetpad («xcodebuild для людей»). Используйте, когда пользователь хочет скомпилировать iOS/macOS/Swift‑приложение, запустить его в симуляторе или на устройстве, прочитать ошибки сборки, запустить тесты или изучить разрешённые настройки сборки из командной строки — с безопасными для агентов, неблокирующими вызовами в JSON‑режиме вместо прямых вызовов xcodebuild.
