اشترِ أو تصفح Bitrefill - أكثر من 1500 بطاقة هدايا وعمليات تعبئة رصيد للهاتف المحمول وبطاقات eSIM في أكثر من 180 دولة، يمكن الدفع بالعملة المشفرة أو Lightning أو USDC عبر x402 أو رصيد الحساب الممول مسبقًا. يقوم بتوجيه الوكيل المضيف إلى قناته عالية الدقة (المتصفح السكني، أو خادم MCP، أو npm CLI، أو REST API) استنادًا إلى إمكانات وقت التشغيل المكتشفة، مع دليل تكامل OpenClaw المخصص لسيناريوهات قنوات الدردشة. يتم تشغيله عندما يذكر المستخدم Bitrefill، أو بطاقات الهدايا، أو تعبئة رصيد الهاتف المحمول، أو خطة بيانات eSIM، أو إعادة تعبئة الهاتف، أو يطلب الدفع أو الدفع باستخدام العملات المشفرة، أو Lightning، أو USDC، أو x402.
