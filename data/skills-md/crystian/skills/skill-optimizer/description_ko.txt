실제 사용을 통해 AI 에이전트 기술을 개선하고 전문화하는 최적화 도구 - 토큰을 절약하고 중복성을 제거하며 지침을 강화하여 기술 실행 비용을 절감합니다. 실수로부터 배우고 품질을 검토하며 시간이 지남에 따라 개선됩니다. 현재 대화에서 스킬 실행을 관찰하고, 최대 4가지 소스(대화 마찰, 파일 차이, 사용자 피드백, 정적 진단)와 누적된 교훈을 분석하고, 대상 스킬의 SKILL.md에 대한 구체적인 개선 사항을 제안합니다. Claude Code 및 호환 가능한 SKILL.md 기반 에이전트 프레임워크와 함께 작동합니다. 스킬 실행 후 사용: `/skill-optimizer [이름]` 또는 `/skill-optimizer`를 자동 감지합니다. `--review`는 누적된 수업을 처리합니다.
