Correggi i difetti nel repository SDK di Composio con riproduzione mirata, analisi delle cause principali, test di regressione e verifica ristretta. Da utilizzare quando l'utente segnala un bug, un test non riuscito, una regressione dell'elemento della configurazione, un difetto di runtime o un comportamento errato dell'SDK. Non utilizzare per la progettazione di nuove funzionalità o per refactoring ampi.
