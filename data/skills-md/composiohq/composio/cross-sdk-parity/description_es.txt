Mantenga alineados el comportamiento del SDK de TypeScript y Python, el uso del cliente generado, los nombres de API públicas y los ejemplos de documentos. Úselo cuando un cambio afecte a ambos SDK, cuando se muevan los pines de cliente generados, al comparar el comportamiento de TS/Python o cuando cambie un contrato de API de backend. No lo utilice para cambios internos en un solo idioma.
