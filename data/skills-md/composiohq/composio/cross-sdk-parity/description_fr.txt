Gardez le comportement du SDK TypeScript et Python, l'utilisation du client généré, la dénomination de l'API publique et les exemples de documentation alignés. À utiliser lorsqu'une modification affecte les deux SDK, lorsque les broches client générées bougent, lors de la comparaison du comportement TS/Python ou lorsqu'un contrat d'API backend est modifié. Ne pas utiliser pour des modifications internes uniquement dans une seule langue.
