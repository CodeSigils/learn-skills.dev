قم بتنفيذ أو تعديل سلوك TypeScript SDK في @composio/core أو حزم TypeScript المشتركة، بما في ذلك الأدوات ومجموعات الأدوات والجلسات وتكوينات المصادقة والحسابات المتصلة والمعدلات وأسطح SDK التي تم إنشاؤها. يستخدم لوقت تشغيل TS/عمل واجهة برمجة التطبيقات؛ قم بالاقتران مع اختبار الكتابة على الآلة الكاتبة للتحقق والتكافؤ عبر sdk عندما يجب أن تتطابق Python.
