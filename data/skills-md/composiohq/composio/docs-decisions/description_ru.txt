Работайте над содержимым документации Composio, конфигурацией Fumadocs, журналами изменений, подсказками по автоматизации документации, решениями по документации, записями в стиле ADR и рекомендациями по проверке документации. Используйте для файлов в папке docs/, рабочих процессов документации или запросов на запись или обновление решения по документации. Не используйте для изменений во время выполнения SDK, если документация не является основным результатом.
