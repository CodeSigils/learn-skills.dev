Diseñe, implemente o revise los comandos de Composio CLI en ts/packages/cli usando Effect, @effect/cli, servicios, convenciones de salida, variables de configuración y entorno, y referencias de proveedores locales. Úselo para UX de comandos CLI, cableado de comandos, cambios de servicio o ediciones de fuentes CLI. No lo utilice para trabajos CLI E2E únicamente; use cli-e2e allí.
