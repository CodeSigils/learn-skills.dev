Создавайте, внедряйте или проверяйте команды Composio CLI в ts/packages/cli, используя Effect, @effect/cli, сервисы, соглашения вывода, переменные конфигурации и среды, а также ссылки местных поставщиков. Используйте для пользовательского интерфейса команд CLI, подключения команд, изменений служб или редактирования исходного кода CLI. Не используйте для работы CLI только с E2E; используйте там cli-e2e.
