Sélectionnez et exécutez la vérification du SDK Python avec nox, les cibles Makefile, Ruff, mypy, les marqueurs pytest, les tests d'intégrité, les vérifications d'inférence de type et les vérifications de build. À utiliser lors de l'ajout de tests Python, du diagnostic de Python CI ou de la validation des modifications apportées au SDK/fournisseur Python. Ne pas utiliser pour les vérifications TypeScript uniquement.
