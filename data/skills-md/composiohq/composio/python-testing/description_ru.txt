Выберите и запустите проверку Python SDK с помощью nox, целевых объектов Makefile, Ruff, mypy, маркеров pytest, тестов работоспособности, проверок вывода типов и проверок сборки. Используйте при добавлении тестов Python, диагностике Python CI или проверке изменений Python SDK/поставщика. Не используйте для проверок только TypeScript.
