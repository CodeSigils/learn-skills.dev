Libérez et récupérez les binaires Composio CLI propriétaires via Build CLI Binaries, y compris les versions bêta automatiques, les distributions stables, la sélection de balises bêta, la vérification des actifs et de l'installation et la récupération des versions ayant échoué. À utiliser lorsqu'un contributeur demande de créer une version bêta de CLI, de publier ou de promouvoir une version stable de CLI, de choisir une version candidate, de surveiller une version de CLI ou de diagnostiquer une version de CLI ayant échoué. Ne pas utiliser pour les versions des ensembles de modifications du SDK TypeScript ou l'implémentation de la source CLI.
