Geben Sie Composio-CLI-Binärdateien von Erstanbietern über Build CLI Binaries frei und stellen Sie sie wieder her, einschließlich automatischer Beta-Builds, Heraufstufung von Stable-Dispatches, Beta-Tag-Auswahl, Asset- und Installationsüberprüfung sowie Wiederherstellung fehlgeschlagener Versionen. Verwenden Sie diese Option, wenn ein Mitwirkender darum bittet, eine CLI-Beta zu erstellen, eine stabile CLI-Version zu veröffentlichen oder zu bewerben, einen Release-Kandidaten auszuwählen, eine CLI-Version zu überwachen oder eine fehlgeschlagene CLI-Version zu diagnostizieren. Nicht für TypeScript SDK Changesets-Releases oder CLI-Quellimplementierung verwenden.
