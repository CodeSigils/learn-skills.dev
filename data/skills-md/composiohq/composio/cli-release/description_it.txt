Rilascia e ripristina i file binari Composio CLI di prima parte tramite Build CLI Binaries, incluse build beta automatiche, invii di promozione stabile, selezione di tag beta, verifica di asset e installazione e ripristino di versioni non riuscite. Da utilizzare quando un collaboratore chiede di creare una versione beta della CLI, pubblicare o promuovere una versione stabile della CLI, scegliere un candidato al rilascio, monitorare una versione della CLI o diagnosticare una versione della CLI non riuscita. Non utilizzare per le versioni di TypeScript SDK Changesets o l'implementazione dell'origine CLI.
