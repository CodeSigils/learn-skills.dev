Libere y recupere archivos binarios de Composio CLI propios a través de Build CLI Binaries, incluidas compilaciones beta automáticas, envíos de promoción estable, selección de etiquetas beta, verificación de activos e instalaciones y recuperación de versiones fallidas. Úselo cuando un colaborador solicita crear una versión CLI beta, publicar o promocionar una versión CLI estable, elegir una versión candidata, monitorear una versión CLI o diagnosticar una versión CLI fallida. No lo utilice para versiones de conjuntos de cambios del SDK de TypeScript ni para la implementación de fuentes CLI.
