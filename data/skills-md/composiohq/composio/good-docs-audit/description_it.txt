Controlla un documento, una guida, un file README o un blocco di prosa rispetto alla guida di stile per la buona scrittura di documenti e segnala le violazioni. Da utilizzare quando l'utente chiede di rivedere, criticare, sottolineare o controllare la voce e il tono della documentazione o del testo. Produce un rapporto strutturato sui risultati (file:riga, regola violata, testo offensivo, riscrittura suggerita) e NON modifica i file a meno che non venga esplicitamente richiesto.
