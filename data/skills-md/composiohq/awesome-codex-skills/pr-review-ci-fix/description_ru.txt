Автоматизированная проверка связей с общественностью и автоматическое исправление CI для GitHub и GitLab с использованием интерфейса командной строки Composio. Извлекает различия, извлекает журналы неудачных заданий, публикует комментарии к проверке и циклически выполняет фиксации коммитов до тех пор, пока проверки не станут зелеными.
