Genere un archivo de rebajas completo del sistema de diseño de diapositivas HTML a partir de una URL de referencia. Estudia la paleta de colores, la tipografía, el logotipo y el estado de ánimo estético de la página, luego escribe un sistema de diseño que se basa en reglas de ingeniería comprobadas (contrato de ajuste de 1280 × 720, red de seguridad de desbordamiento de tres capas, regla de absorción única, trampa móvil flexible en línea para todo, solución móvil de tarjeta invertida, logotipo como símbolo SVG con patrón de color actual, piso de legibilidad de 12 píxeles) mientras deja que la identidad de la marca impulse las imágenes. Utilícelo siempre que el usuario le proporcione una URL y le solicite "crear un sistema de diseño a partir de este sitio", "extraer un sistema de diseño de", "crear diapositivas como esta marca", "diapositivas de diseño que coincidan con el lenguaje visual de este sitio" o quiera crear diapositivas HTML en el lenguaje visual de cualquier sitio web específico. Úselo también cuando el usuario nombra un sitio de marca como referencia de diapositivas, incluso si no dice "sistema de diseño" explícitamente.
