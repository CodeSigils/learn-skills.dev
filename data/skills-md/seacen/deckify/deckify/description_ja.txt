参照 URL から完全な HTML スライド Design System マークダウン ファイルを生成します。ページのカラー パレット、タイポグラフィ、ロゴ、美的雰囲気を研究し、実証済みのエンジニアリング ルール (1280×720 フィット コントラクト、3 層オーバーフロー セーフティ ネット、シングル アブソーバー ルール、モバイル インライン フレックス トラップ キャッチオール、フリップ カード モバイル フィックス、現在のカラー パターンでの SVG シンボルとしてのロゴ、12 ピクセルの可読性フロア) を組み込むデザイン システムを作成し、同時にブランド アイデンティティをビジュアルに反映させます。ユーザーが URL を提供し、「このサイトからデザイン システムを構築する」、「からデザイン システムを抽出する」、「このブランドのようなスライドを作成する」、「このサイトのビジュアル言語に合わせてスライドを作成する」、または特定の Web サイトのビジュアル言語で HTML スライドを作成することを要求する場合は、常にこれを使用します。また、ユーザーが「デザイン システム」と明示的に言わなくても、スライドデッキの参照としてブランド サイトの名前を付ける場合にも使用します。
