Generieren Sie eine vollständige HTML-Slide Design System-Markdown-Datei aus einer Referenz-URL. Studiert die Farbpalette, die Typografie, das Logo und die ästhetische Stimmung der Seite und schreibt dann ein Designsystem, das auf bewährten technischen Regeln basiert (1280×720-Anpassungsvertrag, dreischichtiges Überlaufsicherheitsnetz, Einzelabsorberregel, mobiler Inline-Flex-Trap-Catch-All, Flip-Card-Mobile-Fix, Logo-als-SVG-Symbol-mit-aktuellemFarbmuster, 12-Pixel-Lesbarkeitsboden), während die Markenidentität die visuelle Darstellung bestimmen lässt. Verwenden Sie dies immer dann, wenn der Benutzer Ihnen eine URL angibt und Sie auffordert, „ein Designsystem aus dieser Website zu erstellen“, „ein Designsystem aus dieser Website zu extrahieren“, „Folien wie diese Marke zu erstellen“, „Folien so zu gestalten, dass sie zur visuellen Sprache dieser Website passen“ oder HTML-Folien in der visuellen Sprache einer bestimmten Website erstellen möchte. Verwenden Sie es auch, wenn der Benutzer eine Markenseite als Referenz auf dem Foliendeck benennt, auch wenn er nicht ausdrücklich „Designsystem“ sagt.
