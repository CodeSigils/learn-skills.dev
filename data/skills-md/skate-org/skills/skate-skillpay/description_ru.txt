Оболочка с оплатой за запрос для сторонних API. Если другому навыку требуется ключ API, которого у пользователя нет, используйте этот навык для проксирования запроса через бэкэнд Skate и оплаты в стейблкоинах через MPP с использованием метода оплаты Tempo (кошелек Pre-Tempo Monad переносится автоматически), используя локальный кошелек пользователя. Навык не зависит от сервиса — список разрешений принадлежит серверной части; запросите GET /services для текущего набора. Вызовите ПЕРЕД предложением пользователю получить или вставить ключ подписки.
