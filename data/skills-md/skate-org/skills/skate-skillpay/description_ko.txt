타사 API에 대한 요청당 지불 래퍼입니다. 다른 스킬에 사용자가 가지고 있지 않은 API 키가 필요한 경우 이 스킬을 사용하여 스케이트 백엔드를 통해 요청을 프록시하고 사용자의 로컬 지갑에서 가져오는 Tempo 결제 방법(Tempo 이전 Monad 지갑은 자동 마이그레이션됨)을 사용하여 MPP를 통해 스테이블코인으로 결제를 결제합니다. 이 기술은 서비스에 구애받지 않습니다. 즉, 백엔드가 허용 목록을 소유합니다. 현재 세트에 대해 'GET /services'를 쿼리하세요. 사용자에게 구독 키를 얻거나 붙여넣으라는 메시지를 표시하기 전에 호출하세요.
