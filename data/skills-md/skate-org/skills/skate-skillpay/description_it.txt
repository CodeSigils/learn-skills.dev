Wrapper pay-per-request per API di terze parti. Quando un'altra competenza necessita di una chiave API che l'utente non possiede, utilizza questa competenza per inoltrare la richiesta attraverso il backend Skate e regolare il pagamento in stablecoin su MPP utilizzando il metodo di pagamento Tempo (un portafoglio Monad pre-Tempo viene migrato automaticamente), attingendo al portafoglio locale dell'utente. La competenza è indipendente dal servizio: il backend possiede la lista consentita; interroga "GET /services" per il set corrente. Richiamare PRIMA di chiedere all'utente di ottenere o incollare una chiave di abbonamento.
