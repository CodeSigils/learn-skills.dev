Envoltorio de pago por solicitud para API de terceros. Cuando otra habilidad necesita una clave API que el usuario no tiene, use esta habilidad para enviar la solicitud a través del backend de Skate y liquidar el pago en monedas estables a través de MPP usando el método de pago Tempo (una billetera Monad anterior a Tempo se migra automáticamente), extrayendo de la billetera local del usuario. La habilidad es independiente del servicio: el backend posee la lista de permitidos; consultar `GET /services` para el conjunto actual. Invocar ANTES de solicitar al usuario que obtenga o pegue una clave de suscripción.
