サードパーティ API の Pay-per-Request ラッパー。ユーザーが持っていない API キーが別のスキルで必要な場合、このスキルを使用して Skate バックエンド経由でリクエストをプロキシし、Tempo 支払い方法 (Tempo 以前のモナド ウォレットは自動移行されます) を使用して MPP 経由でステーブルコインで支払いを決済し、ユーザーのローカル ウォレットから引き出します。このスキルはサービスに依存せず、バックエンドが許可リストを所有します。現在のセットに対して `GET /services` をクエリします。ユーザーにサブスクリプション キーの取得または貼り付けを求めるプロンプトを表示する前に呼び出します。
