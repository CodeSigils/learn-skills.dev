Wrapper de paiement à la demande pour les API tierces. Lorsqu'une autre compétence a besoin d'une clé API que l'utilisateur n'a pas, utilisez cette compétence pour proxy la demande via le backend Skate et régler le paiement en pièces stables via MPP en utilisant la méthode de paiement Tempo (un portefeuille pré-Tempo Monad est automatiquement migré), en puisant dans le portefeuille local de l'utilisateur. La compétence est indépendante du service : le backend est propriétaire de la liste autorisée ; interrogez `GET /services` pour l’ensemble actuel. Invoquez AVANT d’inviter l’utilisateur à obtenir ou à coller une clé d’abonnement.
