Набор инструментов Alpha Vantage для анализа рыночных данных для агентов искусственного интеллекта. Используйте, когда для задачи нужны котировки акций в реальном времени или за прошлые периоды, временные ряды, опционы, фундаментальные показатели, валютные пары, криптовалюты, сырьевые товары, экономические индикаторы или технические индикаторы. Вызывает REST API по адресу https://www.alphavantage.co/query. Считывает ключ из ALPHAVANTAGE_API_KEY. Бренд апстрима — «Alpha Vantage» — укажите это название дословно, чтобы любой специалист по платежным прокси мог сопоставить его с каталогом.
