GitHub-Open-Source-Projekt-Deep-Research-Tool. Suchen und analysieren Sie Open-Source-Projekte in bestimmten Bereichen auf GitHub und erstellen Sie dann strukturierte Forschungsberichte. Auslöseszenario: Verwenden Sie diesen Skill, wenn der Benutzer „XXX-Tools auf GitHub recherchieren“, „nach XXX Open-Source-Projekten suchen“, „GitHub-Repositories zusammenfassen“, „Open-Source-Alternativen zu XXX finden“, „XXX-Projekte auf GitHub vergleichen“ anfordert oder eine Stapelanalyse von Open-Source-Projekten mit Berichtsausgabe benötigt.
