Strumento di ricerca approfondita sui progetti open source GitHub. Cerca e analizza progetti open source in domini specifici su GitHub, quindi compila rapporti di ricerca strutturati. Scenario di attivazione: utilizza questa abilità quando l'utente richiede "cerca strumenti XXX su GitHub", "cerca progetti open source XXX", "riepiloga repository GitHub", "trova alternative open source a XXX", "confronta progetti XXX su GitHub" o necessita di analisi batch di progetti open source con output di report.
