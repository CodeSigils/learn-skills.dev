Инструмент глубокого исследования проектов с открытым исходным кодом GitHub. Ищите и анализируйте проекты с открытым исходным кодом в конкретных областях на GitHub, а затем составляйте структурированные отчеты об исследованиях. Сценарий триггера: используйте этот навык, когда пользователь запрашивает «исследование XXX инструментов на GitHub», «поиск XXX проектов с открытым исходным кодом», «обобщение репозиториев GitHub», «найти альтернативы XXX с открытым исходным кодом», «сравнить XXX проектов на GitHub» или ему требуется пакетный анализ проектов с открытым исходным кодом с выводом отчета.
