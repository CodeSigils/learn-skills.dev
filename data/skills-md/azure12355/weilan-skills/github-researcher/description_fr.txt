Outil de recherche approfondie de projet open source GitHub. Recherchez et analysez des projets open source dans des domaines spécifiques sur GitHub, puis compilez des rapports de recherche structurés. Scénarios de déclenchement : utilisez cette compétence lorsqu'un utilisateur demande de « rechercher des outils XXX sur GitHub », « rechercher des projets open source XXX », « résumer les référentiels GitHub », « trouver des alternatives open source à XXX », « comparer des projets XXX sur GitHub » ou lorsqu'une analyse par lots de projets open source et la production de rapports sont nécessaires.
