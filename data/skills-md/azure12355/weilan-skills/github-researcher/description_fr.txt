Outil de recherche approfondie de projet open source GitHub. Recherchez et analysez des projets open source dans des domaines spécifiques sur GitHub, puis compilez des rapports de recherche structurés. Scénario de déclenchement : utilisez cette compétence lorsque l'utilisateur demande « rechercher des outils XXX sur GitHub », « rechercher des projets open source XXX », « résumer les référentiels GitHub », « trouver des alternatives open source à XXX », « comparer des projets XXX sur GitHub » ou a besoin d'une analyse par lots de projets open source avec sortie de rapport.
