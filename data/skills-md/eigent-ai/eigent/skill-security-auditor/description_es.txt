Auditoría de seguridad para código, configuraciones e infraestructura. Úselo cuando el usuario quiera auditar o mejorar la seguridad: buscar vulnerabilidades (inyección SQL, XSS, inyección de comandos, recorrido de ruta), detectar secretos y credenciales codificados, revisar la autenticación y autorización, verificar dependencias para CVE conocidos, auditar archivos de configuración para valores predeterminados inseguros o generar informes de seguridad.
