Audit de sécurité pour le code, les configurations et l'infrastructure. À utiliser lorsque l'utilisateur souhaite auditer ou améliorer la sécurité : rechercher des vulnérabilités (injection SQL, XSS, injection de commandes, traversée de chemin), détecter les secrets et les informations d'identification codés en dur, examiner l'authentification et l'autorisation, vérifier les dépendances pour les CVE connus, auditer les fichiers de configuration pour les valeurs par défaut non sécurisées ou générer des rapports de sécurité. Déclenchez "audit de sécurité", "analyse de vulnérabilité", "révision du code pour la sécurité", "trouver des secrets", "vérifier les vulnérabilités", "OWASP", "CVE" ou des questions sur la sécurité du code.
