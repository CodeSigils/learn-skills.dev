Controllo della sicurezza per codice, configurazioni e infrastruttura. Da utilizzare quando l'utente desidera controllare o migliorare la sicurezza: eseguire la scansione delle vulnerabilità (SQL injection, XSS, command injection, path traversal), rilevare segreti e credenziali codificati, rivedere l'autenticazione e l'autorizzazione, controllare le dipendenze per CVE noti, controllare i file di configurazione per impostazioni predefinite non sicure o generare report sulla sicurezza. Attiva "controllo di sicurezza", "scansione delle vulnerabilità", "revisione del codice per la sicurezza", "trova segreti", "verifica vulnerabilità", "OWASP", "CVE" o domande sulla sicurezza del codice.
