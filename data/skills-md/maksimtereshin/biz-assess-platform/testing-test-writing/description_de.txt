Schreiben Sie minimale, fokussierte Tests nach den KISS- und YAGNI-Prinzipien – testen Sie während der Entwicklung nur Kernbenutzerabläufe, verschieben Sie Randfalltests, testen Sie das Verhalten, nicht die Implementierung, verwenden Sie klare Testnamen, simulieren Sie externe Abhängigkeiten und stellen Sie eine schnelle Testausführung sicher. Verwenden Sie diese Fähigkeit beim Erstellen von Testdateien, beim Schreiben von Komponententests, Integrationstests oder Komponententests. Verwenden Sie es, wenn Sie mit Test-Frameworks (Jest, Vitest, pytest, RSpec, JUnit, Mocha) arbeiten, wenn Sie entscheiden, was wann getestet werden soll, wenn Sie Testfälle für kritische Pfade und primäre Arbeitsabläufe schreiben, wenn Sie externe Dienste oder Datenbanken verspotten oder wenn Sie sicherstellen möchten, dass Tests schnell ausgeführt werden, um die Produktivität der Entwickler zu steigern. Anwenden beim Erstellen von Testdateien (.test.ts, .spec.ts, test_*.py, *_test.go) oder beim Implementieren verhaltensgesteuerter Testfälle.
