Scrivi test minimi e mirati seguendo i principi KISS e YAGNI: testa solo i flussi utente principali durante lo sviluppo, rinvia i test dei casi limite, verifica il comportamento e non l'implementazione, utilizza nomi di test chiari, simula le dipendenze esterne e garantisce una rapida esecuzione dei test. Utilizzare questa competenza durante la creazione di file di test, la scrittura di unit test, test di integrazione o test dei componenti. Da utilizzare quando si lavora con framework di test (Jest, Vitest, pytest, RSpec, JUnit, Mocha), quando si decide cosa testare e quando, quando si scrivono casi di test per percorsi critici e flussi di lavoro primari, quando si deridono servizi o database esterni o quando si garantisce che i test vengano eseguiti rapidamente per la produttività degli sviluppatori. Applicare durante la creazione di file di test (.test.ts, .spec.ts, test_*.py, *_test.go) o durante l'implementazione di casi di test basati sul comportamento.
