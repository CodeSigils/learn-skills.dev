Definire e strutturare modelli ed entità di database con convenzioni di denominazione, timestamp, vincoli di integrità dei dati, relazioni e livelli di convalida adeguati. Utilizzare questa competenza durante la creazione o la modifica di definizioni di modelli ORM, classi di entità di database, definizioni di schema o oggetti del livello di accesso ai dati. Da utilizzare quando si lavora con entità TypeORM, modelli Sequelize, modelli SQLAlchemy, schemi Mongoose, modelli Django, file di schema Prisma o qualsiasi file di modello specifico del framework (models.ts, entità.py, schema.prisma, models.py). Da utilizzare quando si definiscono strutture di tabelle, relazioni di chiave esterna, vincoli di database (NON NULL, UNIQUE), indici o regole di convalida multilivello. Da utilizzare durante l'implementazione di modelli di repository o la progettazione di modelli di dati che bilanciano la normalizzazione con le prestazioni delle query.
