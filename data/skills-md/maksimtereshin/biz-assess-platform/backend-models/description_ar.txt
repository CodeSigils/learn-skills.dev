قم بتحديد وبناء نماذج وكيانات قاعدة البيانات باستخدام اصطلاحات التسمية المناسبة والطوابع الزمنية وقيود تكامل البيانات والعلاقات وطبقات التحقق من الصحة. استخدم هذه المهارة عند إنشاء أو تعديل تعريفات نموذج ORM أو فئات كيان قاعدة البيانات أو تعريفات المخطط أو كائنات طبقة الوصول إلى البيانات. يُستخدم عند العمل مع كيانات TypeORM، أو نماذج Sequelize، أو نماذج SQLAlchemy، أو مخططات Mongoose، أو نماذج Django، أو ملفات مخطط Prisma، أو أي ملفات نماذج خاصة بإطار العمل (models.ts، أو الكيانات.py، أو schema.prisma، أوmodels.py). يُستخدم عند تعريف بنيات الجدول، أو علاقات المفاتيح الخارجية، أو قيود قاعدة البيانات (ليست فارغة، أو فريدة)، أو الفهارس، أو قواعد التحقق من الصحة متعددة الطبقات. يُستخدم عند تنفيذ أنماط المستودع أو تصميم نماذج البيانات التي توازن التسوية مع أداء الاستعلام.
