Implementa layout reattivi mobile-first utilizzando contenitori fluidi, query multimediali, punti di interruzione standard, unità relative (rem/em) e modelli di progettazione touch-friendly. Utilizza questa competenza quando crei layout che si adattano agli schermi di dispositivi mobili, tablet e desktop. Da utilizzare quando si scrivono query multimediali o stili specifici per punti di interruzione, si implementano sistemi a griglia fluida, si progettano target touch per dispositivi mobili o si ottimizzano immagini e risorse per schermi di diverse dimensioni. Da utilizzare quando si lavora con framework CSS reattivi (utilità reattive Tailwind, griglia Bootstrap, griglia CSS, Flexbox), quando si testano layout su più finestre o quando si garantisce la tipografia leggibile e la priorità dei contenuti su schermi più piccoli. Da utilizzare quando si implementano modelli di navigazione mobile o componenti dell'interfaccia utente adattivi.
