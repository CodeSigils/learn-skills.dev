流体コンテナ、メディア クエリ、標準ブレークポイント、相対単位 (rem/em)、タッチ フレンドリーなデザイン パターンを使用して、モバイル ファーストのレスポンシブ レイアウトを実装します。モバイル、タブレット、デスクトップの画面に適応するレイアウトを作成する場合は、このスキルを使用します。メディア クエリやブレークポイント固有のスタイルを作成する場合、流体グリッド システムを実装する場合、モバイル デバイス用のタッチ ターゲットを設計する場合、またはさまざまな画面サイズに合わせて画像やアセットを最適化する場合に使用します。レスポンシブ CSS フレームワーク (Tailwind レスポンシブ ユーティリティ、ブートストラップ グリッド、CSS グリッド、フレックスボックス) を操作する場合、複数のビューポートにわたるレイアウトをテストする場合、または小さな画面で読みやすいタイポグラフィとコンテンツの優先順位を確保する場合に使用します。モバイル ナビゲーション パターンまたはアダプティブ UI コンポーネントを実装するときに使用します。
