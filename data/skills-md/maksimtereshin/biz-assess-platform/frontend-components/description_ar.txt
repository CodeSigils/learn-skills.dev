قم بتصميم وبناء مكونات واجهة مستخدم قابلة لإعادة الاستخدام وقابلة للتركيب وفقًا لمبدأ المسؤولية الفردية مع واجهات دعم واضحة وحالة بسيطة وتغليف مناسب. استخدم هذه المهارة عند إنشاء أو تعديل مكونات React، أو مكونات Vue، أو مكونات Angular، أو مكونات Svelte، أو مكونات الويب. يُستخدم عند العمل مع ملفات المكونات (.tsx، .jsx، .vue، .svelte، .component.ts) في أدلة المكونات. يُستخدم عند تصميم واجهات برمجة تطبيقات المكونات مع الدعائم وأنواعها، أو تنفيذ أنماط تكوين المكونات، أو إدارة حالة المكونات المحلية، أو إنشاء مكونات نظام تصميم قابلة لإعادة الاستخدام. يُستخدم عند إعادة هيكلة المكونات الكبيرة إلى مكونات أصغر مركزة، أو تحديد وثائق المكونات وأمثلة الاستخدام، أو إنشاء مكتبات المكونات.
