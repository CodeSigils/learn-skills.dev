Diseñe y cree componentes de interfaz de usuario reutilizables y componibles siguiendo el principio de responsabilidad única con interfaces de accesorios claras, estado mínimo y encapsulación adecuada. Utilice esta habilidad al crear o modificar componentes React, componentes Vue, componentes Angular, componentes Svelte o componentes web. Úselo cuando trabaje con archivos de componentes (.tsx, .jsx, .vue, .svelte, .component.ts) en directorios de componentes. Úselo al diseñar API de componentes con accesorios y tipos de accesorios, implementar patrones de composición de componentes, administrar el estado de los componentes locales o crear componentes de sistemas de diseño reutilizables. Úselo al refactorizar componentes grandes en componentes más pequeños, definir documentación de componentes y ejemplos de uso, o crear bibliotecas de componentes.
