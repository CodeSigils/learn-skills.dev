明確な prop インターフェイス、最小限の状態、適切なカプセル化を備えた単一責任原則に従って、再利用可能で構成可能な UI コンポーネントを設計および構築します。このスキルは、React コンポーネント、Vue コンポーネント、Angular コンポーネント、Svelte コンポーネント、または Web コンポーネントを作成または変更するときに使用します。コンポーネント ディレクトリ内のコンポーネント ファイル (.tsx、.jsx、.vue、.svelte、.component.ts) を操作する場合に使用します。プロップおよびプロップ タイプを使用してコンポーネント API を設計する場合、コンポーネント構成パターンを実装する場合、ローカル コンポーネントの状態を管理する場合、または再利用可能なデザイン システム コンポーネントを作成する場合に使用します。大きなコンポーネントを焦点を絞った小さなコンポーネントにリファクタリングする場合、コンポーネントのドキュメントと使用例を定義する場合、またはコンポーネント ライブラリを構築する場合に使用します。
