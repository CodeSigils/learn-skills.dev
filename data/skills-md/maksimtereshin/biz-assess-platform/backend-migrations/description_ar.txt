قم بإنشاء وإدارة عمليات ترحيل قاعدة البيانات باستخدام أساليب قابلة للعكس لأعلى/لأسفل، واستراتيجيات النشر بدون توقف، وإصدار المخطط المناسب. استخدم هذه المهارة عند إنشاء ملفات ترحيل قاعدة البيانات، أو تغيير مخططات الجدول، أو إضافة أو تعديل فهارس قاعدة البيانات، أو تنفيذ عمليات ترحيل البيانات. يُستخدم عند العمل باستخدام أدوات الترحيل مثل عمليات ترحيل TypeORM، أو عمليات ترحيل Sequelize، أو Alembic (Python)، أو عمليات ترحيل Rails، أو Flyway، أو Liquibase. يُستخدم عند كتابة ملفات الترحيل (على سبيل المثال، YYYYMMDDHHMMSS_migration_name.ts، 001_create_table.sql، الإصدارات/*.py) أو عند تعديل مخطط قاعدة البيانات بطريقة يتم التحكم فيها بالإصدار. يُستخدم عند التعامل مع التوافق مع الإصدارات السابقة لعمليات النشر ذات التوفر العالي أو عند فصل تغييرات المخطط عن عمليات ترحيل البيانات.
