Escriba y estructure CSS utilizando una metodología coherente (Tailwind, BEM, módulos CSS, componentes con estilo), mantenga tokens del sistema de diseño, minimice el CSS personalizado y optimice el rendimiento. Utilice esta habilidad al escribir o modificar hojas de estilo, archivos CSS o componentes con estilo. Úselo cuando trabaje con archivos .css, .scss, .sass, .module.css, clases de utilidad Tailwind, bibliotecas CSS-in-JS (componentes con estilo, emoción, JSS) o estilo de componentes. Úselo al establecer tokens de diseño para colores, espaciado y tipografía, al evitar anulaciones de estilo del marco, al implementar la purga de CSS o la agitación de árboles para la producción, o al mantener una metodología de estilo consistente en todo el proyecto. Utilícelo cuando trabaje con estilos globales, estilos con ámbito de componente o sistemas de clases de servicios públicos.
