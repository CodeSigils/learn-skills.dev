一貫した方法論 (Tailwind、BEM、CSS モジュール、スタイル付きコンポーネント) を使用して CSS を作成および構造化し、デザイン システム トークンを維持し、カスタム CSS を最小限に抑え、パフォーマンスを最適化します。このスキルは、スタイルシート、CSS ファイル、またはスタイル付きコンポーネントを作成または変更するときに使用します。 .css、.scss、.sass、.module.css ファイル、Tailwind ユーティリティ クラス、CSS-in-JS ライブラリ (styled-components、emotion、JSS)、またはコンポーネント スタイルを操作する場合に使用します。色、間隔、タイポグラフィのデザイン トークンを確立する場合、フレームワーク スタイルのオーバーライドを回避する場合、制作用に CSS パージやツリーシェイキングを実装する場合、またはプロジェクト全体で一貫したスタイル方法論を維持する場合に使用します。グローバル スタイル、コンポーネント スコープのスタイル、またはユーティリティ クラス システムを操作する場合に使用します。
