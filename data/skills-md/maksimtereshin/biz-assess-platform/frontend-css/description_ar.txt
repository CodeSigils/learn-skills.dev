قم بكتابة CSS وتنظيمه باستخدام منهجية متسقة (Tailwind، وBEM، ووحدات CSS، والمكونات المصممة)، والحفاظ على الرموز المميزة لنظام التصميم، وتقليل CSS المخصص، وتحسين الأداء. استخدم هذه المهارة عند كتابة أو تعديل أوراق الأنماط أو ملفات CSS أو المكونات المصممة. يُستخدم عند العمل مع ملفات .css، أو .scss، أو .sass، أو .module.css، أو فئات الأداة المساعدة Tailwind، أو مكتبات CSS-in-JS (المكونات المصممة، أو العاطفة، أو JSS)، أو تصميم المكونات. يُستخدم عند إنشاء رموز تصميم مميزة للألوان والتباعد والطباعة، أو عند تجنب تجاوزات نمط إطار العمل، أو عند تنفيذ عملية تطهير CSS أو اهتزاز الشجرة للإنتاج، أو عند الحفاظ على منهجية تصميم متسقة عبر المشروع. يُستخدم عند العمل مع الأنماط العامة، أو الأنماط ذات نطاق المكونات، أو أنظمة فئة المرافق.
