Scrivi e struttura CSS utilizzando una metodologia coerente (Tailwind, BEM, moduli CSS, componenti con stile), mantieni i token del sistema di progettazione, riduci al minimo i CSS personalizzati e ottimizza le prestazioni. Utilizza questa competenza quando scrivi o modifichi fogli di stile, file CSS o componenti con stili. Da utilizzare quando si lavora con file .css, .scss, .sass, .module.css, classi di utilità Tailwind, librerie CSS-in-JS (componenti con stile, emotion, JSS) o stili di componenti. Da utilizzare quando si stabiliscono token di progettazione per colori, spaziatura e tipografia, quando si evitano le sostituzioni dello stile del framework, quando si implementa l'eliminazione dei CSS o lo scuotimento degli alberi per la produzione o quando si mantiene una metodologia di stile coerente in tutto il progetto. Da utilizzare quando si lavora con stili globali, stili con ambito componente o sistemi di classi di utilità.
