Cree interfaces de usuario accesibles utilizando HTML semántico, atributos ARIA adecuados, soporte de navegación con teclado, suficiente contraste de color y compatibilidad con lectores de pantalla. Utilice esta habilidad al crear o modificar componentes de la interfaz de usuario, formularios, elementos de navegación, modales o cualquier elemento de interfaz interactivo. Úselo cuando trabaje con componentes React, componentes Vue, plantillas Angular o archivos HTML/JSX básicos (.tsx, .jsx, .vue, .html). Úselo al implementar navegación por teclado, administración de enfoque, etiquetas y entradas de formularios, texto alternativo de imágenes, jerarquías de encabezados o roles y propiedades de ARIA. Úselo para garantizar el cumplimiento de las WCAG, realizar pruebas con lectores de pantalla o crear contenido dinámico accesible y aplicaciones de una sola página. Úselo al agregar requisitos de contraste de color o indicadores de enfoque visibles a elementos interactivos.
