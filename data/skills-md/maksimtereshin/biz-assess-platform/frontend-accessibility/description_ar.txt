أنشئ واجهات مستخدم يمكن الوصول إليها باستخدام لغة HTML الدلالية وسمات ARIA المناسبة ودعم التنقل عبر لوحة المفاتيح وتباين الألوان الكافي وتوافق قارئ الشاشة. استخدم هذه المهارة عند إنشاء أو تعديل مكونات واجهة المستخدم أو النماذج أو عناصر التنقل أو الوسائط أو أي عناصر واجهة أمامية تفاعلية. يُستخدم عند العمل مع مكونات React، أو مكونات Vue، أو قوالب Angular، أو ملفات HTML/JSX الفانيليا (.tsx، .jsx، .vue، .html). يُستخدم عند تنفيذ التنقل عبر لوحة المفاتيح، أو إدارة التركيز، أو تسميات النماذج والمدخلات، أو النص البديل للصور، أو التسلسلات الهرمية للعناوين، أو أدوار وخصائص ARIA. يُستخدم عند التأكد من توافق WCAG، أو الاختبار باستخدام قارئات الشاشة، أو إنشاء محتوى ديناميكي يمكن الوصول إليه وتطبيقات من صفحة واحدة. يُستخدم عند إضافة متطلبات تباين الألوان أو مؤشرات التركيز المرئية إلى العناصر التفاعلية.
