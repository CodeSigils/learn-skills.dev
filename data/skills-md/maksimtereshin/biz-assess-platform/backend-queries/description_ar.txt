اكتب استعلامات قاعدة بيانات محسنة وآمنة باستخدام الاستعلامات ذات المعلمات، والتحميل السريع، والفهرسة الإستراتيجية، وإدارة المعاملات المناسبة. استخدم هذه المهارة عند كتابة استعلامات قاعدة البيانات أو أساليب المستودع أو منطق جلب البيانات الذي يتفاعل مع قواعد بيانات SQL أو NoSQL. يُستخدم عند تنفيذ منشئي الاستعلامات، أو أساليب استعلام ORM، أو استعلامات SQL الأولية، أو وظائف خدمة قاعدة البيانات. يُستخدم عند العمل مع الملفات التي تحتوي على رمز الوصول إلى قاعدة البيانات (repositories.ts،services.ts، query.py، dao.java)، عند تحسين مشكلات استعلام N+1، أو تنفيذ إستراتيجيات التخزين المؤقت للاستعلام، أو كتابة الاستعلامات باستخدام عبارات JOINs وWHERE. يُستخدم عند منع ثغرات حقن SQL، أو إعداد مهلات الاستعلام، أو تغليف العمليات ذات الصلة في معاملات قاعدة البيانات.
