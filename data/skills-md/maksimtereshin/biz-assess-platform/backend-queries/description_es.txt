Escriba consultas de bases de datos optimizadas y seguras utilizando consultas parametrizadas, carga inmediata, indexación estratégica y gestión adecuada de transacciones. Utilice esta habilidad al escribir consultas de bases de datos, métodos de repositorio o lógica de recuperación de datos que interactúe con bases de datos SQL o NoSQL. Úselo al implementar creadores de consultas, métodos de consulta ORM, consultas SQL sin formato o funciones de servicio de base de datos. Úselo cuando trabaje con archivos que contienen código de acceso a bases de datos (repositories.ts, servicios.ts, queries.py, dao.java), cuando optimice problemas de consultas N+1, implemente estrategias de almacenamiento en caché de consultas o escriba consultas con cláusulas JOIN y WHERE. Úselo para prevenir vulnerabilidades de inyección SQL, configurar tiempos de espera de consultas o empaquetar operaciones relacionadas en transacciones de bases de datos.
