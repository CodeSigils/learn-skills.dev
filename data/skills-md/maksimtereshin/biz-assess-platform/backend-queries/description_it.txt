Scrivi query di database ottimizzate e sicure utilizzando query parametrizzate, caricamento rapido, indicizzazione strategica e corretta gestione delle transazioni. Utilizzare questa competenza durante la scrittura di query di database, metodi di repository o logica di recupero dei dati che interagisce con database SQL o NoSQL. Da utilizzare durante l'implementazione di generatori di query, metodi di query ORM, query SQL non elaborate o funzioni di servizio di database. Da utilizzare quando si lavora con file contenenti codice di accesso al database (repositories.ts, services.ts, query.py, dao.java), quando si ottimizzano problemi di query N+1, si implementano strategie di memorizzazione nella cache delle query o si scrivono query con clausole JOIN e WHERE. Da utilizzare per prevenire le vulnerabilità SQL injection, impostare i timeout delle query o eseguire il wrapper di operazioni correlate nelle transazioni del database.
