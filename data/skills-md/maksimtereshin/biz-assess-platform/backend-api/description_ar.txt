قم بتصميم وتنفيذ نقاط نهاية RESTful API باتباع مبادئ REST باستخدام أساليب HTTP المناسبة ورموز الحالة وأنماط URL المستندة إلى الموارد. استخدم هذه المهارة عند إنشاء أو تعديل معالجات مسار API أو وحدات التحكم أو تعريفات نقطة النهاية في أطر عمل الواجهة الخلفية (Express، وNestJS، وFastAPI، وDjango REST Framework، وما إلى ذلك). يُستخدم عند العمل مع إستراتيجيات إصدار واجهة برمجة التطبيقات (API)، أو تنفيذ تحديد المعدل، أو تصميم نقاط نهاية الموارد المتداخلة، أو تحديد تصفية معلمات الاستعلام وترقيم الصفحات. يُستخدم عند كتابة ملفات مثل Routes.ts، أو Controllers.ts، أو api.py، أو views.py، أو أي ملفات خلفية تحدد نقاط نهاية HTTP وتتعامل مع طلبات/استجابات واجهة برمجة التطبيقات.
