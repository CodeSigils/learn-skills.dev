Спроектируйте и внедрите конечные точки API RESTful в соответствии с принципами REST с использованием правильных методов HTTP, кодов состояния и шаблонов URL-адресов на основе ресурсов. Используйте этот навык при создании или изменении обработчиков маршрутов API, контроллеров или определений конечных точек в серверных платформах (Express, NestJS, FastAPI, Django REST Framework и т. д.). Используйте при работе со стратегиями управления версиями API, реализации ограничения скорости, разработке конечных точек вложенных ресурсов или определении фильтрации и разбиения на страницы параметров запроса. Используйте при написании таких файлов, как Routes.ts, Controllers.ts, api.py,views.py или любых внутренних файлов, которые определяют конечные точки HTTP и обрабатывают запросы/ответы API.
