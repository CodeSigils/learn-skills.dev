Progetta e implementa endpoint API RESTful seguendo i principi REST con metodi HTTP, codici di stato e modelli URL basati su risorse adeguati. Utilizza questa competenza durante la creazione o la modifica di gestori di route API, controller o definizioni di endpoint nei framework backend (Express, NestJS, FastAPI, Django REST Framework, ecc.). Da utilizzare quando si lavora con strategie di controllo delle versioni API, si implementa la limitazione della velocità, si progettano endpoint di risorse nidificate o si definiscono il filtraggio e l'impaginazione dei parametri di query. Da utilizzare durante la scrittura di file come Routes.ts, Controllers.ts, api.py, Views.py o qualsiasi file di backend che definisce endpoint HTTP e gestisce richieste/risposte API.
