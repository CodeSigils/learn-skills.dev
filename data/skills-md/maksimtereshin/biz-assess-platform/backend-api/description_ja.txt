適切な HTTP メソッド、ステータス コード、リソースベースの URL パターンを使用して、REST 原則に従って RESTful API エンドポイントを設計および実装します。このスキルは、バックエンド フレームワーク (Express、NestJS、FastAPI、Django REST Framework など) で API ルート ハンドラー、コントローラー、またはエンドポイント定義を作成または変更するときに使用します。 API バージョン管理戦略の使用、レート制限の実装、ネストされたリソース エンドポイントの設計、またはクエリ パラメーターのフィルタリングとページネーションの定義を行う場合に使用します。 Routes.ts、controllers.ts、api.py、views.py などのファイル、または HTTP エンドポイントを定義して API リクエスト/レスポンスを処理するバックエンド ファイルを作成するときに使用します。
