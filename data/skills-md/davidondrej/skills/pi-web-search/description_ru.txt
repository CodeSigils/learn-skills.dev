ТОЛЬКО для агентов Pi — у всех остальных агентов есть свои веб-инструменты. Как Pi получает доступ к Интернету через пакет pi-web-access — поиск, получение URL-адресов/PDF-файлов/YouTube/GitHub. Используйте всякий раз, когда задаче Pi требуется текущая информация, документы, новости, цены или контент с определенного URL-адреса.
