NUR für Pi-Agenten – alle anderen Agenten verfügen über ihre eigenen Web-Tools. Wie Pi über das pi-web-access-Paket auf das Web zugreift – suchen, URLs/PDFs/YouTube/GitHub abrufen. Verwenden Sie es immer dann, wenn eine Pi-Aufgabe aktuelle Informationen, Dokumente, Neuigkeiten, Preise oder Inhalte von einer bestimmten URL benötigt.
