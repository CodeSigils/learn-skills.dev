Lassen Sie einen KI-Agenten nach einem Zeitplan, einer Schleife oder einem Intervall laufen – Cron, Heartbeats, wiederkehrende autonome Prüfungen. Verwenden Sie diese Option für „Alle N Minuten ausführen“, „Eine Aufgabe planen“, „In einer Schleife ausführen“ und „Heartbeat“. Deckt externe Uhren (Claude Code, Codex, Pi) im Vergleich zum integrierten Scheduler von Hermes ab.
