Создайте специализированный файл CLAUDE.md (+ символическую ссылку AGENTS.md) внутри определенной папки, чтобы предоставить будущим агентам контекст на уровне папки. Используйте, когда пользователь просит создать CLAUDE.md для папки, записать инструкции для папки или добавить контекст агента в каталог.
