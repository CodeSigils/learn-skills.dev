Esegui i comandi Git e GitHub CLI attraverso il contesto host quando il sandboxing blocca l'autenticazione del portachiavi, l'accesso alla rete o le scritture .git. Utilizzare per operazioni gh auth, repository o PR e git index.lock o errori di autorizzazione. Gestisce solo il contesto di esecuzione, non la progettazione del flusso di lavoro GitHub.
