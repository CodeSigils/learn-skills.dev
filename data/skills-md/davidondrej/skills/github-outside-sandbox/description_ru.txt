Запускайте команды Git и GitHub CLI через контекст хоста, когда песочница блокирует аутентификацию связки ключей, доступ к сети или запись .git. Используйте для операций аутентификации gh, репозитория или PR, а также для ошибок git index.lock или разрешений. Обрабатывает только контекст выполнения, а не дизайн рабочего процесса GitHub.
