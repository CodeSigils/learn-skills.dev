Ejecute comandos CLI de Git y GitHub a través del contexto del host cuando el sandboxing bloquee la autenticación de llavero, el acceso a la red o las escrituras .git. Úselo para operaciones de autenticación de gh, repositorio o relaciones públicas, y fallas de permisos o git index.lock. Maneja únicamente el contexto de ejecución, no el diseño del flujo de trabajo de GitHub.
