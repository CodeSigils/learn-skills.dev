Fournissez un rôle Postgres renforcé SELECT uniquement afin que les agents IA puissent lire en toute sécurité une base de données de production. Fonctionne sur Supabase et n'importe quel Postgres. À utiliser lorsque l'utilisateur souhaite que les agents interrogent les données de production, déclare « rôle en lecture seule », « accès sécurisé à la base de données de production pour les agents » ou est fatigué d'exécuter SQL manuellement pour les agents. Différenciateur : cette compétence CRÉE le rôle et le câblage ; les requêtes quotidiennes appartiennent à une compétence locale du projet.
