Stellen Sie eine gehärtete Nur-SELECT-Postgres-Rolle bereit, damit KI-Agenten eine Produktionsdatenbank sicher lesen können. Funktioniert auf Supabase und allen Postgres. Verwenden Sie diese Option, wenn der Benutzer möchte, dass Agenten Produktdaten abfragen, sagt „schreibgeschützte Rolle“, „sicherer Produkt-DB-Zugriff für Agenten“ oder es leid ist, SQL für Agenten manuell auszuführen. Unterscheidungsmerkmal: Diese Fähigkeit ERSTELLT die Rolle und die Verkabelung; Das tägliche Abfragen gehört zu einer projektlokalen Fähigkeit.
