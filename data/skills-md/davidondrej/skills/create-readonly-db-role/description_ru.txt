Предоставьте усиленную роль Postgres, поддерживающую только SELECT, чтобы агенты ИИ могли безопасно читать рабочую базу данных. Работает на Supabase и любом Postgres. Используйте, когда пользователь хочет, чтобы агенты запрашивали данные продукта, говорит «роль только для чтения», «безопасный доступ к базе данных продукта для агентов» или устал запускать SQL вручную для агентов. Дифференциатор: этот навык СОЗДАЕТ роль и структуру; ежедневные запросы относятся к локальному навыку проекта.
