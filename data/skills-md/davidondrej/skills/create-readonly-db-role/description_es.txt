Proporcione una función de Postgres reforzada solo SELECT para que los agentes de IA puedan leer de forma segura una base de datos de producción. Funciona en Supabase y cualquier Postgres. Úselo cuando el usuario quiera que los agentes consulten datos de producción, diga "función de solo lectura", "acceso seguro a la base de datos de producción para los agentes" o esté cansado de ejecutar SQL manualmente para los agentes. Diferenciador: esta habilidad CREA el rol y el cableado; Las consultas diarias pertenecen a una habilidad local del proyecto.
