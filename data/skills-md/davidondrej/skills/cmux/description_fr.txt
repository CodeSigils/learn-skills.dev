Contrôlez l'application de terminal cmux macOS (CLI + API socket) : espaces de travail cmux, volets, surfaces, automatisation du navigateur, notifications, paramètres, hooks. DOIT être lu avant d'exécuter une commande `cmux`. Déclenchez UNIQUEMENT lorsque l'utilisateur dit explicitement « cmux » — un volet cmux, un espace de travail cmux, une surface cmux ou un agent s'exécutant dans cmux. Ne déclenchez PAS sur des mentions génériques de « espace de travail », « volet », « l'autre agent » ou « délégué » lorsque cmux n'est pas nommé — les espaces de travail dans tmux, Ghostty, herdr, VS Code, etc. ne sont PAS cmux. macOS uniquement (14.0+).
