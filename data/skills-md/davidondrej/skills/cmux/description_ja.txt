cmux macOS ターミナル アプリ (CLI + ソケット API) — cmux ワークスペース、ペイン、サーフェス、ブラウザ自動化、通知、設定、フックを制御します。 「cmux」コマンドを実行する前に必ず読む必要があります。ユーザーが明示的に「cmux」(cmux ペイン、cmux ワークスペース、cmux surface、または cmux で実行されているエージェント) と発言した場合にのみトリガーされます。 cmux の名前が指定されていない場合は、「ワークスペース」、「ペイン」、「他のエージェント」、または「デリゲート」という一般的な言及でトリガーしないでください。tmux、Ghostty、herdr、VS Code などのワークスペースは cmux ではありません。 macOS のみ (14.0 以降)。
