Управляйте приложением терминала cmux macOS (CLI + API сокетов) — рабочие области cmux, панели, поверхности, автоматизация браузера, уведомления, настройки, перехватчики. ДОЛЖЕН быть прочитан перед запуском любой команды cmux. Запускается ТОЛЬКО тогда, когда пользователь явно говорит «cmux» — панель cmux, рабочее пространство cmux, поверхность cmux или агент, работающий в cmux. НЕ срабатывает при общих упоминаниях «рабочей области», «панели», «другого агента» или «делегата», если cmux не назван — рабочие области в tmux, Ghostty, herdr, VS Code и т. д. НЕ являются cmux. Только для macOS (14.0+).
