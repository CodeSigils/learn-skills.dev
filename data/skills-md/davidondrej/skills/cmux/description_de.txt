MUSS gelesen werden, bevor ein „cmux“-Befehl ausgeführt wird. Wird NUR ausgelöst, wenn der Benutzer explizit „cmux“ sagt – ein Cmux-Bereich, ein Cmux-Arbeitsbereich, eine Cmux-Oberfläche oder ein Agent, der in Cmux ausgeführt wird. Lösen Sie NICHT bei generischen Erwähnungen von „Arbeitsbereich“, „Bereich“, „der andere Agent“ oder „Delegierter“ aus, wenn cmux nicht genannt wird – Arbeitsbereiche in tmux, Ghostty, herdr, VS Code usw. sind KEINE cmux.
