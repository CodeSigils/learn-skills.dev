cmux macOS 터미널 앱(CLI + 소켓 API) — cmux 작업 공간, 창, 표면, 브라우저 자동화, 알림, 설정, 후크를 제어합니다. `cmux` 명령을 실행하기 전에 반드시 읽어야 합니다. 사용자가 cmux 창, cmux 작업 공간, cmux 표면 또는 cmux에서 실행 중인 에이전트와 같이 "cmux"라고 명시적으로 말한 경우에만 트리거됩니다. cmux의 이름이 지정되지 않은 경우 "작업 공간", "창", "다른 에이전트" 또는 "대리자"에 대한 일반적인 언급에 대해 트리거하지 마십시오. tmux, Ghostty, herdr, VS Code 등의 작업 공간은 cmux가 아닙니다. macOS 전용(14.0+).
