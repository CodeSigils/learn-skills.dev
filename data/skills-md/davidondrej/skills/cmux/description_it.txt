Controlla l'app terminale cmux macOS (CLI + API socket): aree di lavoro, riquadri, superfici cmux, automazione del browser, notifiche, impostazioni, hook. DEVE essere letto prima di eseguire qualsiasi comando `cmux`. Si attiva SOLO quando l'utente dice esplicitamente "cmux": un riquadro cmux, un'area di lavoro cmux, una superficie cmux o un agente in esecuzione in cmux. NON attivarsi in caso di menzioni generiche di "area di lavoro", "riquadro", "l'altro agente" o "delegato" quando cmux non è nominato: le aree di lavoro in tmux, Ghostty, herdr, VS Code, ecc. NON sono cmux. Solo macOS (14.0+).
