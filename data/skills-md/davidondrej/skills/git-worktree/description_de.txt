Verwenden Sie Git Worktrees, um mehrere Codierungsagenten parallel auf einem Repo ohne Kollisionen auszuführen. Verwenden Sie diese Option, wenn Sie eine Aufgabe in einem freigegebenen Repo starten, wenn der Benutzer „Arbeitsbaum“, „parallele Agenten“, „ein Arbeitsbaum pro Aufgabe“ sagt oder wenn Agenten ständig die Änderungen der anderen überschreiben. Behandelt das Erstellen von Arbeitsbäumen, um sie so vollständig wie den Hauptcheckout zu machen (.env-Dateien, Abhängigkeiten, Datenbanken, Ports), das Zurückführen und die Bereinigung.
