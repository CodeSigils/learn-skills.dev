Используйте рабочие деревья git для параллельного запуска нескольких агентов кодирования в одном репозитории без конфликтов. Используйте при запуске задачи в общем репозитории, когда пользователь говорит «рабочее дерево», «параллельные агенты», «одно рабочее дерево на задачу» или когда агенты продолжают перезаписывать изменения друг друга. Охватывает создание рабочих деревьев, делает их такими же полными, как и основная проверка (файлы .env, зависимости, базы данных, порты), обратное слияние и очистку.
