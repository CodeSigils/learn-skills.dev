Utilisez git worktrees pour exécuter plusieurs agents de codage en parallèle sur un seul dépôt sans collisions. À utiliser lors du démarrage d'une tâche dans un dépôt partagé, lorsque l'utilisateur dit « arbre de travail », « agents parallèles », « un arbre de travail par tâche » ou lorsque les agents continuent d'écraser les modifications des autres. Couvre la création d'arbres de travail, les rendant aussi complets que l'extraction principale (fichiers .env, dépendances, bases de données, ports), la fusion et le nettoyage.
