Utilice árboles de trabajo de git para ejecutar varios agentes de codificación en paralelo en un repositorio sin colisiones. Úselo al iniciar una tarea en un repositorio compartido, cuando el usuario dice "árbol de trabajo", "agentes paralelos", "un árbol de trabajo por tarea" o cuando los agentes siguen sobrescribiendo los cambios de los demás. Cubre la creación de árboles de trabajo, haciéndolos tan completos como el proceso de pago principal (archivos .env, dependencias, bases de datos, puertos), fusionándolos y limpiando.
