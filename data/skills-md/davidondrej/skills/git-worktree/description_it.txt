Utilizza git worktrees per eseguire più agenti di codifica in parallelo su un repository senza collisioni. Da utilizzare quando si avvia un'attività in un repository condiviso, quando l'utente dice "albero di lavoro", "agenti paralleli", "un albero di lavoro per attività" o quando gli agenti continuano a sovrascrivere le modifiche degli altri. Copre la creazione di alberi di lavoro, rendendoli completi quanto il checkout principale (file .env, dipendenze, database, porte), la fusione e la pulizia.
