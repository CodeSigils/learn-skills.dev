استخدم أشجار عمل git لتشغيل العديد من عوامل الترميز بالتوازي في ريبو واحد دون حدوث تصادمات. يُستخدم عند بدء مهمة في مستودع مشترك، أو عندما يقول المستخدم "شجرة العمل"، أو "الوكلاء المتوازيون"، أو "شجرة عمل واحدة لكل مهمة"، أو عندما يستمر الوكلاء في الكتابة فوق تغييرات بعضهم البعض. يغطي إنشاء أشجار العمل، مما يجعلها كاملة مثل عملية الدفع الرئيسية (ملفات .env، والتبعيات، وقواعد البيانات، والمنافذ)، والدمج مرة أخرى، والتنظيف.
