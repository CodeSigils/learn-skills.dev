Répartissez une compétence dans les 4 dossiers de compétences des agents (Codex, Claude Code, Pi, Hermes) afin que tous les agents la voient. À utiliser lorsque l'utilisateur dit « distribuer cette compétence », « synchroniser les compétences entre les agents » ou après avoir créé/mis à jour une compétence qui doit être globale. Couvre la disposition du lien symbolique et le piège ~/.pi/agent/skills.
