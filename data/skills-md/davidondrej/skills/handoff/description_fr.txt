Compactez la conversation en cours en un seul message de transfert détaillé (tout ce qui s'est passé, pourquoi cela s'est produit et ce qui reste) affiché dans un bloc de code afin qu'il puisse être copié-collé dans une nouvelle session d'agent. À utiliser lorsque vous dépassez les limites du contexte, changez de focus, terminez une session de travail ou partitionnez une tâche dans de nouveaux contextes.
