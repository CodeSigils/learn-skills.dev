Utilizzare quando l'utente desidera costruire un documento strategico strutturato rispondendo a domande (priorità di vita, documenti sugli obiettivi, file quadro, classifiche, principi, revisioni). Intervista una domanda alla volta, correggi il file dopo ogni risposta, quindi chiedi nuovamente. Non per la pianificazione giornaliera (utilizzare il piano giornaliero).
