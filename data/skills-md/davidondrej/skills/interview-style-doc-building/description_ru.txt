Используйте, когда пользователь хочет создать структурированный стратегический документ, отвечая на вопросы (жизненные приоритеты, документы о целях, файлы рамок, ранжированные списки, принципы, обзоры). Задавайте вопросы по одному, исправляйте файл после каждого ответа, а затем переспрашивайте. Не для планирования дня (используйте план дня).
