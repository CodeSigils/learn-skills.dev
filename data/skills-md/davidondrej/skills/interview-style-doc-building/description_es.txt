Úselo cuando el usuario desee crear un documento estratégico estructurado respondiendo preguntas (prioridades de vida, documentos de objetivos, archivos marco, listas clasificadas, principios, revisiones). Entreviste una pregunta a la vez, parchee el archivo después de cada respuesta y luego vuelva a preguntar. No apto para planificación diaria (use plan diario).
