Eine gemeinsame Sperrliste katastrophaler Shell-Befehle (rm -rf on / or ~, dd/mkfs, sudo rm, fork bombs, curl|sh, git push --force, gh repo delete), die als PreToolUse/pre-exec-Schutz für jeden KI-Codierungsagenten auf der Maschine durchgesetzt wird – Cursor, Claude Code, Codex, OpenCode, Pi, Hermes, Grok, Droid, Devin. Verwenden Sie diese Option, wenn Sie Muster für blockierte Befehle hinzufügen oder optimieren, den Schutz mit einem neuen Agenten oder einer neuen Maschine verbinden, debuggen, warum ein Befehl blockiert wurde (oder nicht), oder wenn der Benutzer Befehlsschutz, Leitplanken, gefährliche Befehls-Hooks oder PreToolUse-Sicherheit erwähnt.
