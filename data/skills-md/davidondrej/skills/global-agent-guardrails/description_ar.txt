قائمة رفض واحدة مشتركة لأوامر Shell الكارثية (rm -rf on / or ~، dd/mkfs، sudo rm، fork Bombs، curl|sh، git Push --force، gh repodelete) التي يتم فرضها كحارس PreToolUse/pre-exec عبر كل وكيل ترميز AI على الجهاز - Cursor، Claude Code، Codex، OpenCode، Pi، Hermes، Grok، Droid، Devin. يُستخدم عند إضافة أو ضبط أنماط الأوامر المحظورة، أو توصيل الحماية إلى وكيل جديد أو جهاز جديد، أو تصحيح سبب حظر (أو عدم حظر) الأمر، أو عندما يذكر المستخدم حارس الأوامر، أو حواجز الحماية، أو خطاف الأوامر الخطير، أو سلامة PreToolUse.
