Una lista de denegación compartida de comandos de shell catastróficos (rm -rf on / or ~, dd/mkfs, sudo rm, fork bombs, curl|sh, git push --force, gh repo delete) aplicada como protección PreToolUse/pre-exec en todos los agentes de codificación de IA en la máquina: Cursor, Claude Code, Codex, OpenCode, Pi, Hermes, Grok, Droid, Devin. Úselo al agregar o ajustar patrones de comando bloqueado, conectar la protección a un nuevo agente o una nueva máquina, depurar por qué un comando fue (o no) bloqueado, o cuando el usuario menciona la protección de comando, barandillas, gancho de comando peligroso o seguridad PreToolUse.
