Una lista negata condivisa di comandi shell catastrofici (rm -rf on / o ~, dd/mkfs, sudo rm, fork bombs, curl|sh, git push --force, gh repo delete) applicata come guardia PreToolUse/pre-exec su ogni agente di codifica AI sulla macchina: Cursor, Claude Code, Codex, OpenCode, Pi, Hermes, Grok, Droid, Devin. Da utilizzare quando si aggiungono o si regolano modelli di comandi bloccati, si collega la protezione a un nuovo agente o a una nuova macchina, si esegue il debug del motivo per cui un comando è stato (o non è stato) bloccato o quando l'utente menziona la protezione dei comandi, i guardrail, il gancio di comando pericoloso o la sicurezza PreToolUse.
