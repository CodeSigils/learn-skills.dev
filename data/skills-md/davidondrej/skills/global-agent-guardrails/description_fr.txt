Une liste de refus partagée de commandes shell catastrophiques (rm -rf on / or ~, dd/mkfs, sudo rm, fork bombs, curl|sh, git push --force, gh repo delete) appliquée en tant que garde PreToolUse/pre-exec sur chaque agent de codage IA sur la machine – Cursor, Claude Code, Codex, OpenCode, Pi, Hermes, Grok, Droid, Devin. À utiliser lors de l'ajout ou du réglage de modèles de commandes bloquées, du câblage de la protection dans un nouvel agent ou une nouvelle machine, du débogage de la raison pour laquelle une commande a été (ou n'a pas été) bloquée, ou lorsque l'utilisateur mentionne une protection de commande, des garde-corps, un crochet de commande dangereux ou la sécurité PreToolUse.
