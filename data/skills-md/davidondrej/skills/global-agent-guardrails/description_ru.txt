Один общий список запретов для катастрофических команд оболочки (rm -rf on / или ~, dd/mkfs, sudo rm, fork Bombs, Curl|sh, git push --force, gh repo delete), используемый в качестве защиты PreToolUse/pre-exec для каждого агента кодирования AI на машине — Cursor, Claude Code, Codex, OpenCode, Pi, Hermes, Grok, Droid, Devin. Используйте при добавлении или настройке шаблонов заблокированных команд, подключении защиты к новому агенту или новому компьютеру, отладке того, почему команда была (или не была) заблокирована, или когда пользователь упоминает защиту команды, ограждения, опасную командную перехватку или безопасность PreToolUse.
