Cómo escribir habilidades efectivas para los agentes: qué hacer, qué no hacer, anatomía, divulgación progresiva, patrones de diseño, antipatrones, pruebas, seguridad. Lea esto cada vez que se cree, edite, revise o depure una habilidad (Claude Skill, Agent Skill, SKILL.md). Úselo cuando el usuario diga "crear una habilidad", "nueva habilidad", "actualizar esta habilidad", "mejorar una habilidad", "por qué no se activa mi habilidad" o cualquier otra cosa que implique la creación o edición de archivos SKILL.md.
