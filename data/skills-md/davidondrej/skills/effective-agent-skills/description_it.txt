Come scrivere competenze efficaci dell'agente: cosa fare, cosa non fare, anatomia, divulgazione progressiva, modelli di progettazione, anti-modelli, test, sicurezza. Leggilo ogni volta che una competenza (Claude Skill, Agent Skill, SKILL.md) viene creata, modificata, rivista o sottoposta a debug. Da utilizzare quando l'utente dice "crea una competenza", "nuova competenza", "aggiorna questa competenza", "migliora una competenza", "perché la mia competenza non si attiva" o qualsiasi altra cosa che implichi la creazione o la modifica di file SKILL.md.
