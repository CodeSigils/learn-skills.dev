Wie man effektive Agentenfähigkeiten schreibt – was zu tun ist, was nicht, Anatomie, progressive Offenlegung, Entwurfsmuster, Anti-Muster, Tests, Sicherheit. Lesen Sie dies immer dann, wenn ein Skill (Claude Skill, Agent Skill, SKILL.md) erstellt, bearbeitet, überprüft oder debuggt wird. Wird verwendet, wenn der Benutzer sagt: „Eine Fertigkeit erstellen“, „Neue Fertigkeit“, „Diese Fertigkeit aktualisieren“, „Eine Fertigkeit verbessern“, „Warum wird meine Fertigkeit nicht ausgelöst“ oder alles andere, was das Erstellen oder Bearbeiten von SKILL.md-Dateien betrifft.
