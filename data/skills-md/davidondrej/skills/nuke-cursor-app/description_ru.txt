Комплексный перезапуск Cursor IDE на MacBook пользователя: метрики снимков, завершение ВСЕХ процессов Cursor, перезапуск Cursor, отчет до/после памяти. Восстанавливается известная утечка памяти средства рендеринга, из-за которой курсор зависает. Только вручную — запускается ТОЛЬКО тогда, когда пользователь явно вызывает его (/nuke-cursor-app, «nuke курсор»). Дифференциатор: убивает настольное приложение Cursor; Сеансы курсора-cli не связаны между собой.
