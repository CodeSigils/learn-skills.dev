OpenRouter API を介して、DeepSWE コーディング エージェント ベンチマークで AI モデルをスコアリングします。ユーザーが独立した再現可能なコーディング エージェントの評価を必要とする場合、つまり「DeepSWE を実行する」、「DeepSWE でこのモデルをベンチマークする」、「コーディング ベンチマークでモデル X をスコアリングする」、「DeepSWE で OpenRouter 経由でモデルをテストする」、またはベンダーが報告したコーディング スコアを検証する場合に使用します。セットアップ、ミニ SWE エージェント用の OpenRouter 配線、単一タスク / サブセット / 113 タスク全体の実行、およびリーダーボードの提出について説明します。
