Оцените любую модель искусственного интеллекта в тесте агента кодирования DeepSWE через API OpenRouter. Используйте, когда пользователь хочет провести независимую, воспроизводимую оценку агента кодирования — «запустить DeepSWE», «провести тестирование этой модели на DeepSWE», «оценить модель X в тесте кодирования», «протестировать модель через OpenRouter на DeepSWE» или для проверки оценок кодирования, сообщаемых поставщиком. Охватывает настройку, подключение OpenRouter для мини-агента, выполнение одной задачи / подмножества / полных 113 задач и отправку в таблицу лидеров.
