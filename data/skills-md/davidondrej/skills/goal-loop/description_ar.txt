اشرح واكتب تعليمات فعالة لميزة `/goal` - حلقة وكيل الفحص الذاتي المستمر (التخطيط → الفعل → الاختبار → المراجعة → التكرار)، المتوفرة في وكلاء مثل Codex وClaude Code وHermes Agent. يُستخدم عندما يذكر المستخدم `/goal`، أو "حلقة الهدف"، أو "حلقة رالف"، أو يريد بدء تشغيل وكيل مستقل طويل الأمد، أو يسأل عن كيفية كتابة موجه هدف، أو يريد صياغة تعليمات هدف من فقرة واحدة.
