macbook メトリクスのセットアップを任意の Mac にレプリケートします。ローカルの常時オンのシステム メトリクス コレクター (CPU、GPU、RAM、ディスク、ネットワーク、バッテリー、サーマル) は Swift CLI として構築され、60 秒ごとに launchd によって実行され、SQLite に保存され、プライベート GitHub リポジトリにバックアップされます。長期的な Mac パフォーマンス追跡が必要な場合、Macbook メトリクスがどのように機能するかを尋ねる場合、または新しいマシンで同じ監視を設定したい場合に使用します。差別化要因: 既存のインストールに対する日常的なクエリではなく、アーキテクチャとセットアップのイデオロギー全体をカバーします。
