Répliquez la configuration des métriques du MacBook sur n'importe quel Mac : un collecteur de métriques système local et toujours actif (CPU, GPU, RAM, disque, réseau, batterie, thermiques) construit comme Swift CLI, exécuté par launchd toutes les 60 s, stocké dans SQLite et sauvegardé dans un dépôt GitHub privé. À utiliser lorsque quelqu'un souhaite suivre les performances Mac à long terme, demande comment fonctionnent les métriques MacBook ou souhaite configurer la même surveillance sur une nouvelle machine. Différenciateur : couvre l'architecture complète et l'idéologie de configuration, et non l'interrogation quotidienne d'une installation existante.
