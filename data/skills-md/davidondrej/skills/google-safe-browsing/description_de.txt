Verhindern und beheben Sie Google Safe Browsing-Flaggen „Gefährliche Websites“. Verwenden Sie diese Option, wenn Sie eine öffentliche Web-App starten, eine Domain kaufen/auswählen, eine Anmelde- oder Registrierungsseite erstellen oder wenn auf einer Website in Chrome, Brave, Safari, Firefox oder Edge eine rote Warnung „Gefährliche Website“/„Trügerische Website“ angezeigt wird. Löst auf „gefährliche Website“, „trügerische Website“, „Website blockiert“, „sicheres Surfen“, „Phishing-Flagge“ und „roter Warnbildschirm“ aus.
