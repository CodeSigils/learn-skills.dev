À utiliser lorsque l'utilisateur souhaite concevoir, repenser, façonner, critiquer, auditer, polir, clarifier, distiller, durcir, optimiser, adapter, animer, coloriser, extraire ou améliorer de toute autre manière une interface frontale. Couvre les sites Web, les pages de destination, les tableaux de bord, l'interface utilisateur du produit, les shells d'applications, les composants, les formulaires, les paramètres, l'intégration et les états vides. Gère l'examen UX, la hiérarchie visuelle, l'architecture de l'information, la charge cognitive, l'accessibilité, les performances, le comportement réactif, les thèmes, les anti-motifs, la typographie, les polices, l'espacement, la mise en page, l'alignement, la couleur, le mouvement, les micro-interactions, la copie UX, les états d'erreur, les cas extrêmes, i18n et les systèmes ou jetons de conception réutilisables. Utilisez également pour les conceptions fades qui doivent devenir plus audacieuses ou plus attrayantes, les conceptions bruyantes qui doivent devenir plus silencieuses, les itérations en direct du navigateur sur les éléments de l'interface utilisateur ou les effets visuels ambitieux qui devraient sembler techniquement extraordinaires. Pas pour les tâches backend uniquement ou sans interface utilisateur.
