Utilizzato quando l'utente richiede esplicitamente di gestire il repository locale corrente tramite la collaborazione Web ChatGPT Pro o deve avviare, continuare, attendere, archiviare o chiudere più attività di collaborazione Pro Web reciprocamente isolate.
