Utilisé lorsque l'utilisateur demande explicitement de gérer le référentiel local actuel via la collaboration Web ChatGPT Pro, ou doit démarrer, continuer, attendre, archiver ou fermer plusieurs tâches de collaboration Web Pro mutuellement isolées. L'agent hôte sélectionne explicitement l'invite et les pièces jointes ; cette compétence gère uniquement les sessions de navigateur, les réponses originales et les enregistrements d'audit tour par tour, ne comprend pas le référentiel, n'applique pas les réponses et ne valide pas de code.
