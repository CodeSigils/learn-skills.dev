저장소 컨텍스트를 읽고 다단계 엔지니어링 작업을 완료해야 하는 개발 협업 프로세스의 경우: 코드 수정, 버그 디버깅, 여러 모듈, 상태 흐름, 외부 계약, 부작용, 권한/데이터 흐름 또는 사용자가 볼 수 있는 동작 리팩토링, 코드 검토, TDD/테스트 우선, 전달 확인 및 기술 문서 업데이트가 포함됩니다. 저위험 로컬 구현은 경량 경로를 따르는 반면, 고위험 작업은 고급 위험 게이트를 통과합니다. 사용자가 구현, 수정, 검토, 리팩토링, 문제 해결, 확인, 문서 변경을 언급하거나 기존 코드에서 솔루션을 결정해야 할 때 사용해야 합니다. 단일 명령, 순수 개념 설명 또는 저장소 컨텍스트가 필요하지 않은 1단계 Q&A를 사용할 필요가 없습니다.
