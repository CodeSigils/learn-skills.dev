Gérez de manière déclarative les métadonnées de l'expérience Roblox (paramètres de l'univers, passes de jeu, produits de développement, badges, lieux) à partir d'un fichier YAML via l'action rblxsync CLI / GitHub. À utiliser lors de la configuration de rblxsync dans un projet Roblox, de l'écriture ou de la modification de rblxsync.yml, de la synchronisation/publication de passes de jeu, de produits de développement, de badges, de lieux ou de paramètres d'univers, du câblage du Config.luau généré dans le code du jeu Luau, du débogage des erreurs ROBLOX_API_KEY / ROBLOX_COOKIE ou de l'ajout de rblxsync à CI. Déclencheurs sur "rblxsync", "rblxsync.yml", "sync game passes", "Open Cloud metadata", "publish place", "Config.luau", "rblxsync-lock.yml".
