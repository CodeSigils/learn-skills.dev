通过 rblxsync CLI / GitHub Action 从 YAML 文件以声明方式管理 Roblox 体验元数据（Universe 设置、游戏通行证、开发者产品、徽章、地点）。在 Roblox 项目中设置 rblxsync、编写或编辑 rblxsync.yml、同步/发布游戏通行证、开发人员产品、徽章、地点或宇宙设置、将生成的 Config.luau 连接到 Luau 游戏代码、调试 ROBLOX_API_KEY / ROBLOX_COOKIE 错误或将 rblxsync 添加到 CI 时使用。在“rblxsync”、“rblxsync.yml”、“同步游戏通行证”、“开放云元数据”、“发布位置”、“Config.luau”、“rblxsync-lock.yml”上触发。
