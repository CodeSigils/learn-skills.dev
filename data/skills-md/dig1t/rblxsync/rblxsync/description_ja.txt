rblxsync CLI / GitHub アクションを介して、YAML ファイルから Roblox エクスペリエンス メタデータ (ユニバース設定、ゲーム パス、開発者製品、バッジ、プレイス) を宣言的に管理します。 Roblox プロジェクトで rblxsync を設定する場合、rblxsync.yml を作成または編集する場合、ゲーム パス、開発者製品、バッジ、場所またはユニバース設定を同期/公開する場合、生成された Config.luau を Luau ゲーム コードに接続する場合、ROBLOX_API_KEY / ROBLOX_COOKIE エラーをデバッグする場合、または rblxsync を CI に追加する場合に使用します。 「rblxsync」、「rblxsync.yml」、「同期ゲームパス」、「オープンクラウドメタデータ」、「公開場所」、「Config.luau」、「rblxsync-lock.yml」でトリガーされます。
