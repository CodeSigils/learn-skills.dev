Declaratively manage Roblox experience metadata (Universe settings, Game Passes, Developer Products, Badges, Places) from a YAML file via the rblxsync CLI / GitHub Action. Use when setting up rblxsync in a Roblox project, writing or editing rblxsync.yml, syncing/publishing game passes, developer products, badges, places or universe settings, wiring the generated Config.luau into Luau game code, debugging ROBLOX_API_KEY / ROBLOX_COOKIE errors, or adding rblxsync to CI. Triggers on "rblxsync", "rblxsync.yml", "sync game passes", "Open Cloud metadata", "publish place", "Config.luau", "rblxsync-lock.yml".
