透過 rblxsync CLI / GitHub Action 從 YAML 檔案以聲明方式管理 Roblox 體驗元資料（Universe 設定、遊戲通行證、開發者產品、徽章、地點）。在 Roblox 專案中設定 rblxsync、編寫或編輯 rblxsync.yml、同步/發布遊戲通行證、開發人員產品、徽章、地點或宇宙設定、將產生的 Config.luau 連接到 Luau 遊戲程式碼、偵錯 ROBLOX_API_KEY / ROBLOX_COOKIE 錯誤或將 rblx 新增時使用。在「rblxsync」、「rblxsync.yml」、「同步遊戲通行證」、「開放雲元資料」、「發布位置」、「Config.luau」、「rblxsync-lock.yml」上觸發。
