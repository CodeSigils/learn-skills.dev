قم بتحرير الصور بدقة - القص، وتغيير الحجم، والعكس، والتدوير، والقص، وإعادة الإطار. استخدم هذه المهارة عندما يطلب المستخدم قص الصورة أو تغيير حجمها أو قصها أو عكسها أو قلبها أو تدويرها أو إعادة تأطيرها أو معالجتها بأي طريقة أخرى. استخدمه أيضًا لإنشاء اقتصاصات مربعة، أو صور شخصية/لقطات للرأس من صور الجسم بالكامل، أو أحجام الأيقونات، أو أي تحويل للصور. حتى لو بدا الطلب بسيطًا، فإن هذه المهارة تمنع الأخطاء الشائعة وتضمن الحصول على نتائج صحيحة من المحاولة الأولى.
