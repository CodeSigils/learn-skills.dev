Holen Sie sich eine zweite Meinung von Googles Gemini Pro über die lokal installierte Gemini-CLI ein (standardmäßig gemini-3.1-pro-preview; Überschreibung mit der Umgebungsvariable CLAUDE_SECOND_OPINION_MODEL). Nutzen Sie diese Fähigkeit im Planungsmodus für große oder kritische Aufgaben, wenn Sie beim Debuggen in einer Sackgasse stecken, wenn Sie Kompromisse bei der Architektur eingehen müssen, für subtile Randfälle bei der Codeüberprüfung oder in jeder Situation, in der eine unabhängige Perspektive einen Mehrwert bieten würde. Verwenden Sie es auch, wenn der Benutzer ausdrücklich nach einer „zweiten Meinung“, „Fragen Sie Gemini“, „einer anderen Perspektive“ oder „Gegenprobe“ fragt. Meldet Nichtverfügbarkeit, anstatt auf ein schwächeres Modell zurückzugreifen.
