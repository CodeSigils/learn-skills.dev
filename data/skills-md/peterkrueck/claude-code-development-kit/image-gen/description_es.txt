Genere arte de personajes y variaciones de imágenes utilizando la generación de imágenes de IA (Google Gemini) con imágenes de referencia para lograr estilo y coherencia de personajes. Utilice esta habilidad cuando el usuario solicite generar nuevas poses de personajes, variaciones de mascotas, recursos artísticos, ilustraciones o cualquier imagen generada por IA, especialmente cuando mantenga la coherencia con un personaje o estilo existente.
