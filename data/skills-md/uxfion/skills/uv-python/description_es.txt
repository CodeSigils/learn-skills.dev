Utilice uv exclusivamente para toda la gestión de paquetes y ejecución de scripts de Python. Se activa cada vez que el usuario instala/elimina paquetes de Python, ejecuta scripts de Python, administra dependencias, crea proyectos de Python o menciona pip/poetry/conda/pip-tools. Si los paquetes, entornos o ejecución de scripts de Python están involucrados de alguna manera, utilice esta habilidad.
