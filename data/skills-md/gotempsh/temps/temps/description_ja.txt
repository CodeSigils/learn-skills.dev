Temps を使用してアプリケーションを管理、展開、操作、計測します。ユーザーが Temps、`@temps-sdk/cli@0.1.34`、Temps へのアプリのデプロイまたは移行、プロジェクト、環境、サービス、ドメイン、バックアップ、ログ、モニタリング、分析、ブラウザー Performance Insights/Core Web Vitals、可観測性、エラー追跡、OpenTelemetry、トレース、セッション リプレイ、または Temps Cloud について言及する場合は常に、このスキルを使用します。また、ユーザーが明示的に CLI を要求しない場合でも、Temps 上で実稼働用にアプリケーションを準備するときにも使用します。焦点を絞った参照にルーティングし、作成/リンク/デプロイの過程で欠落しているオブザーバビリティを積極的に検出し、明示的なターゲット コンテキストで固定された「bunx」または「npx」の CLI 呼び出しを使用します。
