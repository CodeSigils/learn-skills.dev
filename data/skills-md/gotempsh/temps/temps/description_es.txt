Administre, implemente, opere e instrumente aplicaciones con Temps. Utilice esta habilidad siempre que el usuario mencione Temps, `@temps-sdk/cli@0.1.34`, implemente o migre una aplicación a Temps, proyectos, entornos, servicios, dominios, copias de seguridad, registros, monitoreo, análisis, Performance Insights/Core Web Vitals del navegador, observabilidad, seguimiento de errores, OpenTelemetry, seguimiento, reproducción de sesiones o Temps Cloud. Úselo también cuando prepare una aplicación para producción en Temps, incluso si el usuario no solicita explícitamente la CLI. Dirija a referencias enfocadas, detecte proactivamente la observabilidad faltante durante los procesos de creación/vinculación/implementación y utilice invocaciones CLI ancladas `bunx` o `npx` con contextos de destino explícitos.
