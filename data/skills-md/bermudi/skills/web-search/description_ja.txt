mcporter 経由で Tavily を使用して、Web を検索し、ページ コンテンツを抽出し、Web サイトをクロールし、サイト構造をマップし、マルチソースの詳細な調査を実行します。 Web 検索、URL からのコンテンツのスクレイピング/抽出、サイトのクロール、サイトの構造の理解、トピックに関する包括的な調査など、インターネットから最新の情報が必要なときは常にこのスキルを使用してください。トリガー: 「Web を検索する」、「これを調べる」、「最新情報」、「このページをスクレイピングする」、「コンテンツを抽出する」、「このサイトをクロールする」、「この Web サイトをマップする」、「このトピックを調査する」、「情報を見つける」、「Web で何について述べているか」。 tavily_skill 経由でライブラリ ドキュメントが必要な場合にも使用します (ライブラリ/API/ツールのドキュメントを検索)。
