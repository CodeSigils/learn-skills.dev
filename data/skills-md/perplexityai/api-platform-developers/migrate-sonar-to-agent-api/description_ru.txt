Перенесите код из Sonar API Perplexity (завершения чата) в API агента (/v1/agent, responses.create). Сопоставляет конечные точки, параметры запросов, фрагменты моделей (сонар, сонар-про, сонар-рассуждение, сонар-глубокое исследование), анализ ответов, потоковую передачу и цитаты. Используйте при переходе с Sonar, переносе завершений чата в API агента, замене устаревших моделей sonar-pro или sonar-reasoning, а также исправлении 400 ошибок неизвестного поля и отсутствующих цитат после попытки миграции.
