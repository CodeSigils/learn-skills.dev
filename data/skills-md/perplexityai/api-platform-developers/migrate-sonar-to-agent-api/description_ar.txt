قم بترحيل التعليمات البرمجية من Sonar API الخاص بـ Perplexity (إكمال الدردشة) إلى Agent API (/v1/agent, Responses.create). نقاط النهاية للخرائط، ومعلمات الطلب، والارتزاقات النموذجية (السونار، والسونار الاحترافي، واستدلال السونار، والبحث العميق للسونار)، وتحليل الاستجابة، والتدفق، والاستشهادات. يُستخدم عند الترحيل من Sonar، أو نقل عمليات إكمال الدردشة إلى Agent API، أو استبدال نماذج sonar-pro أو نماذج Sonar-reasoning المهملة، أو إصلاح 400 خطأ في الحقول غير المعروفة والاستشهادات المفقودة بعد محاولة الترحيل.
