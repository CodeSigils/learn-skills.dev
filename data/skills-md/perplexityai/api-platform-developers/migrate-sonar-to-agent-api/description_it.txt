Migra il codice dall'API Sonar di Perplexity (completamenti chat) all'API Agent (/v1/agent, risposte.create). Mappa endpoint, parametri di richiesta, slug del modello (sonar, sonar-pro, sonar-reasoning, sonar-deep-research), analisi delle risposte, streaming e citazioni. Da utilizzare durante la migrazione da Sonar, lo spostamento dei completamenti della chat nell'API dell'agente, la sostituzione di modelli sonar-pro o sonar-reasoning obsoleti o la correzione di 400 errori di campi sconosciuti e citazioni mancanti dopo un tentativo di migrazione.
