コードを Perplexity の Sonar API (チャット完了) からエージェント API (/v1/agent、response.create) に移行します。エンドポイント、リクエストパラメータ、モデルスラッグ（ソナー、ソナープロ、ソナー推論、ソナーディープリサーチ）、応答解析、ストリーミング、および引用をマップします。 Sonar から移行する場合、チャット完了をエージェント API に移動する場合、非推奨の sonar-pro または sonar-reasoning モデルを置き換える場合、または移行試行後に 400 件の不明なフィールド エラーや引用の欠落を修正する場合に使用します。
