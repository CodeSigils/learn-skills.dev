Une compétence permettant d'examiner une différence spécifique et d'afficher les résultats sous forme de commentaires dans difit (le visualiseur de différences). Utilisez-le pour examiner les différences de branche, les différences de validation ou les PR GitHub, puis préchargez les résultats ou les explications de code dans difit avec « --comment » avant de le lancer pour l'utilisateur.
