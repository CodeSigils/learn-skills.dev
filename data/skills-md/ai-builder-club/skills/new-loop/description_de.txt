Erstellen Sie eine neue Schleife (Domäne) in einer dateibasierten Wissensdatenbank – laden Sie das Substrat hoch, wenn es fehlt, stellen Sie die Charta der Schleife zusammen, erstellen Sie ein Gerüst für domains/<loop>/README.md, führen Sie dann EINEN echten Testlauf durch und zeichnen Sie ihn in der Timeline und LOG.md der Schleife auf. Wird verwendet, wenn der Benutzer „Neue Schleife einrichten“, „Domäne erstellen“, „Neuen Beat/Workstream starten“ sagt oder einen wiederkehrenden Job benennt, den der Agent besitzen soll.
