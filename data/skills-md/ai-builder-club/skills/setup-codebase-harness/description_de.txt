Meisterfähigkeit – Richten Sie den vollständigen Agenten-Harness für jedes Repo ein, damit ein Agent zuverlässig damit arbeiten kann: lesbar (Karten-nicht-manuelle Dokumente + benutzerdefinierte Lints), ausführbar (Ein-Befehl-Entwicklungsstack), überprüfbar (E2E-Gate + eine Schleife zur Überprüfung vor dem Versand) sowie Commit-Hygiene und Entropiekontrolle. Verwenden Sie diese Option, wenn Sie eine neue/unbekannte Codebasis in die agentengesteuerte Entwicklung integrieren – „Geschirr einrichten“, „Dieses Repo für den Agenten vorbereiten“, „Diese Codebasis nutzen“.
