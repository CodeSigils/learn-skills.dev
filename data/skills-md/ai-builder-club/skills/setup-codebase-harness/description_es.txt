Habilidad maestra: configure el arnés completo del agente para cualquier repositorio para que un agente pueda trabajarlo de manera confiable: legible (documentos de mapa no manuales + pelusas personalizadas), ejecutable (pila de desarrollo de un solo comando), verificable (puerta e2e + un bucle de verificación antes de enviar), además de compromiso de higiene y control de entropía. Úselo al incorporar una base de código nueva o desconocida al desarrollo impulsado por agentes: "configurar el aprovechamiento", "preparar este repositorio para el agente", "aprovechar esta base de código".
