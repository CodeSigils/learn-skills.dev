Abilità principale: configura il cablaggio completo dell'agente per qualsiasi repository in modo che un agente possa utilizzarlo in modo affidabile: leggibile (documenti mappa-non-manuale + lint personalizzati), eseguibile (stack di sviluppo a un comando), verificabile (gate e2e + un ciclo di verifica prima della spedizione), oltre all'igiene del commit e al controllo dell'entropia. Da utilizzare durante l'onboarding di una base di codice nuova/sconosciuta per lo sviluppo basato su agenti: "imposta il cablaggio", "rendi questo repository pronto per l'agente", "sfrutta questa base di codice".
