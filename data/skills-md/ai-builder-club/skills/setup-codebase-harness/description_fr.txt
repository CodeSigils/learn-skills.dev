Compétence de maîtrise : configurez le harnais complet de l'agent pour n'importe quel dépôt afin qu'un agent puisse le travailler de manière fiable : lisible (documents de carte non manuels + lints personnalisés), exécutable (pile de développement à une commande), vérifiable (porte e2e + une boucle de vérification avant expédition), ainsi que l'hygiène de validation et le contrôle de l'entropie. À utiliser lors de l'intégration d'une base de code nouvelle/inconnue dans un développement piloté par agent : "configurer le harnais", "préparer ce référentiel pour l'agent", "exploiter cette base de code".
