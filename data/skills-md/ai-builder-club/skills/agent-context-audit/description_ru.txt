Проведите аудит контекста агента репозитория — файлов CLAUDE.md, документации кодовой базы, навыков и проектов инструментов/MCP — на соответствие руководству Anthropic по контекстной инженерии Claude 5 («освобождение»: Anthropic сократил ~80% системных запросов Claude Code без потери оценки). Находит чрезмерные ограничения, противоречивые инструкции, избыточность, устаревшие факты и недостающие «неизвестные известные»; составляет отчет о результатах оценки с конкретными изменениями, а затем применяет утвержденные исправления. Используйте, когда кто-то говорит «проверить мой CLAUDE.md», «контекстный аудит», «освободить этот репозиторий», «просмотреть документацию/навыки/инструменты нашего агента» или после обновления до моделей Claude 5-го поколения.
