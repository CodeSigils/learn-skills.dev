Auditez le contexte de l'agent d'un dépôt (fichiers CLAUDE.md, documents de base de code, compétences et conceptions d'outils/MCP) par rapport aux conseils d'ingénierie contextuelle Claude 5 d'Anthropic (« débobinage » : Anthropic a coupé environ 80 % de l'invite système de Claude Code sans perte d'évaluation). Détecte la surcontrainte, les instructions contradictoires, la redondance, les faits obsolètes et les « inconnus connus » manquants ; produit un rapport de résultats noté avec des réécritures concrètes, puis applique les correctifs approuvés. À utiliser lorsque quelqu'un dit « auditer mon CLAUDE.md », « audit de contexte », « débloquer ce dépôt », « examiner nos documents/compétences/outils d'agent » ou après la mise à niveau vers les modèles Claude 5 génération.
