Enregistrez les flux de travail du navigateur et générez des compétences autonomes à partir de ceux-ci. À utiliser lorsque l'utilisateur souhaite automatiser une tâche Web répétitive : soumission de formulaires, navigation sur des portails, dépôt de rapports, etc. Déclencheurs : « flux d'enregistrement », « automatisation du site Web », « création d'une compétence de navigateur ».
