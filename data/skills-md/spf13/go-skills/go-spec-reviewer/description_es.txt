Revise los documentos de especificaciones de diseño para los programas Go antes de que comience la implementación. Utilice esta habilidad cuando un usuario tenga una especificación de Go, un documento de diseño, un RFC o un PRD para revisar, quiera comentarios sobre una función planificada en una base de código de Go, esté a punto de comenzar a implementar una especificación o pregunte "¿está lista esta especificación?". o "revisa esto antes de construirlo". Aplica la filosofía Go (simplicidad, composición, errores explícitos, propagación de contexto) además de las convenciones CLI de Cobra/Viper cuando corresponda.
