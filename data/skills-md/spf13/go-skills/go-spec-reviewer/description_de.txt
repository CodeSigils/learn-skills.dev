Überprüfen Sie die Designspezifikationsdokumente für Go-Programme, bevor Sie mit der Implementierung beginnen. Verwenden Sie diese Fähigkeit, wenn ein Benutzer eine Go-Spezifikation, ein Designdokument, einen RFC oder ein PRD überprüfen muss, Feedback zu einer geplanten Funktion in einer Go-Codebasis möchte, mit der Implementierung einer Spezifikation beginnen möchte oder fragt: „Ist diese Spezifikation fertig?“ oder „Überprüfen Sie dies, bevor ich es baue“. Wendet die Go-Philosophie an – Einfachheit, Komposition, explizite Fehler, Kontextweitergabe – sowie ggf. Cobra/Viper-CLI-Konventionen.
