Examinez les documents de spécifications de conception pour les programmes Go avant le début de la mise en œuvre. Utilisez cette compétence lorsqu'un utilisateur a une spécification Go, un document de conception, une RFC ou un PRD à réviser, souhaite obtenir des commentaires sur une fonctionnalité prévue dans une base de code Go, est sur le point de commencer l'implémentation à partir d'une spécification ou demande « cette spécification est-elle prête ? ou "examinez ceci avant de le construire". Applique la philosophie Go — simplicité, composition, erreurs explicites, propagation du contexte — ainsi que les conventions CLI Cobra/Viper, le cas échéant.
