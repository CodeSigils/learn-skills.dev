Cobra および Viper を使用して CLI アプリケーションを構築する専門スキル。両方のライブラリのオリジナル作成者である spf13 によって作成されました。コマンドファーストのアーキテクチャ、分離されたビジネス ロジック、構成管理、環境変数バインディング、コンテキスト認識コマンド、およびメモリ内 CLI テストをカバーします。 Go CLI またはコマンドライン ツールが構築、レビュー、またはリファクタリングされている場合は常に、Cobra または Viper の名前がまだ付けられていない場合でも、コマンド、サブコマンド、フラグ、または CLI 設定についての言及があれば必ず使用してください (推奨)。
