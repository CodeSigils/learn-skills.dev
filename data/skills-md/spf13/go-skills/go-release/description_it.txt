Competenze esperte nel rilascio di moduli e applicazioni Go: controllo delle versioni semantico, compatibilità API, rilevamento di modifiche importanti, deprecazione, igiene go.mod, tagging e distribuzione binaria con GoReleaser. Da utilizzare ogni volta che una versione di Go viene tagliata, pianificata o rivista: qualsiasi menzione di tag di versione, semver, modifiche sostanziali, moduli v2, deprecazione di un'API, modifica di go.mod per la versione, log delle modifiche o file binari di spedizione. Da utilizzare anche durante la revisione di una PR o di una specifica che modifica qualsiasi identificatore esportato in una libreria Go pubblicata.
