مهارة الخبراء في إطلاق وحدات وتطبيقات Go: الإصدار الدلالي، وتوافق واجهة برمجة التطبيقات (API)، واكتشاف التغيير الجذري، والإهمال، ونظافة go.mod، ووضع العلامات، والتوزيع الثنائي باستخدام GoReleaser. يُستخدم عندما يتم قطع إصدار Go أو التخطيط له أو مراجعته - أي ذكر لعلامات الإصدار أو semver أو التغييرات المعطلة أو وحدات v2 أو إهمال واجهة برمجة التطبيقات (API) أو تحرير go.mod للإصدار أو سجلات التغيير أو شحن الثنائيات. استخدمه أيضًا عند مراجعة العلاقات العامة أو المواصفات التي تغير أي معرف تم تصديره في مكتبة Go المنشورة.
