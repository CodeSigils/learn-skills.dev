Compétence d'expert pour la publication de modules et d'applications Go : gestion des versions sémantiques, compatibilité API, détection des modifications avec rupture, dépréciation, hygiène go.mod, balisage et distribution binaire avec GoReleaser. À utiliser chaque fois qu'une version Go est coupée, planifiée ou révisée : toute mention de balises de version, de semver, de modifications importantes, de modules v2, de dépréciation d'une API, de modification de go.mod pour la version, de journaux de modifications ou d'envoi de fichiers binaires. À utiliser également lors de l'examen d'un PR ou d'une spécification qui modifie tout identifiant exporté dans une bibliothèque Go publiée.
