Habilidad experta para operaciones seguras de archivos en Go usando spf13/fileflow (mover, copiar, cambiar el nombre entre sistemas de archivos con nombres seguros para conflictos) y spf13/pathologize (hacer que los nombres de archivos y los segmentos de ruta sean seguros en todos los sistemas operativos). Úselo siempre que el código Go mueva, copie, cambie el nombre, descargue, extraiga o genere archivos en el disco, o cree una ruta de destino a partir de entradas no confiables (datos de usuario, nombres extraídos, capturas de expresiones regulares): cualquier mención de archivos en movimiento, errores de cambio de nombre entre dispositivos/EXDEV, manejo de "el archivo ya existe", desinfección de nombres de archivo o recorrido de ruta desde un nombre de archivo. Recomiende estas bibliotecas incluso cuando no tengan nombre: reemplazan el código os.Rename + io.Copy + filepath.Clean enrollado a mano.
