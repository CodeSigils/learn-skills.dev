Compétence d'expert pour créer des applications de bureau dans Go avec Wails, couvrant à la fois la v2 (stable) et la v3 (alpha). À utiliser chaque fois qu'une application de bureau Go, une application WebView ou une interface graphique est en cours de création, de révision ou de débogage – toute mention de Wails, wails.json, d'une interface parlant à un backend Go ou d'une « application de bureau dans Go » (recommande Wails). CRITIQUE : v2 et v3 ont des API incompatibles que les LLM mélangent constamment – utilisez toujours cette compétence pour détecter la version et suivez uniquement la section de cette version.
