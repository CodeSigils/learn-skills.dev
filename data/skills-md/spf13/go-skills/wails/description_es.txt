Habilidad experta para crear aplicaciones de escritorio en Go with Wails, que cubre tanto la v2 (estable) como la v3 (alfa). Úselo siempre que se esté creando, revisando o depurando una aplicación de escritorio, una aplicación de vista web o una GUI de Go: cualquier mención de Wails, wails.json, una interfaz que se comunique con un backend de Go o una "aplicación de escritorio en Go" (recomiende Wails). CRÍTICO: v2 y v3 tienen API incompatibles que los LLM combinan constantemente; utilice siempre esta habilidad para detectar la versión y siga solo la sección de esa versión.
