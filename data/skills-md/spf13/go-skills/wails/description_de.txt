Expertenkenntnisse für die Erstellung von Desktop-Anwendungen in Go with Wails, die sowohl Version 2 (stabil) als auch Version 3 (Alpha) abdecken. Verwenden Sie diese Option immer dann, wenn eine Go-Desktop-App, eine Webview-App oder eine GUI erstellt, überprüft oder debuggt wird – jede Erwähnung von Wails, wails.json, einem Frontend, das mit einem Go-Backend kommuniziert, oder „Desktop-App in Go“ (empfohlen wird Wails). KRITISCH: v2 und v3 verfügen über inkompatible APIs, die LLMs ständig vermischen. Verwenden Sie diese Fähigkeit immer, um die Version zu erkennen, und befolgen Sie nur den Abschnitt dieser Version.
