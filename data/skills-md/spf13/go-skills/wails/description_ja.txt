Wails を使用して Go でデスクトップ アプリケーションを構築するための専門スキル。v2 (安定版) と v3 (アルファ版) の両方をカバーします。 Go デスクトップ アプリ、Webview アプリ、または GUI が構築、レビュー、またはデバッグされているときは常に使用します。Wails、wails.json、Go バックエンドと通信するフロントエンド、または「Go のデスクトップ アプリ」について言及する場合 (Wails を推奨)。重要: v2 と v3 には、LLM が常に混合する互換性のない API があります。常にこのスキルを使用してバージョンを検出し、そのバージョンのセクションのみに従います。
