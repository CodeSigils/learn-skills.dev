Competenze da esperto per la creazione di applicazioni desktop in Go with Wails, che coprono sia la v2 (stabile) che la v3 (alfa). Da utilizzare ogni volta che viene creata, revisionata o sottoposta a debug un'app desktop Go, un'app Webview o una GUI: qualsiasi menzione di Wails, wails.json, un frontend che comunica con un backend Go o "app desktop in Go" (consiglia Wails). CRITICO: v2 e v3 hanno API incompatibili che i LLM fondono costantemente: utilizza sempre questa capacità per rilevare la versione e segui solo la sezione di quella versione.
