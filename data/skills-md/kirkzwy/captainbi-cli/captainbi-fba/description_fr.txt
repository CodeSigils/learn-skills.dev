Inventaire FBA, frais, expéditions et commandes de surveillance pour CaptainBI CLI. QUAND utiliser pour : l'inventaire Expédié par Amazon, les listes d'expédition, les frais de stockage, les frais de distribution anormale et la surveillance des ASIN Expédié par Amazon. QUAND PAS : ne pas utiliser pour les commandes des clients, les avis sur les produits, les mesures publicitaires ou les rapports financiers, sauf si le contexte de l'inventaire est nécessaire.
