Configure confirmaciones convencionales con liberación semántica para control de versiones semánticas automatizadas. Utilice esta habilidad siempre que el usuario mencione confirmaciones convencionales, control de versiones semánticas, semver, automatización de lanzamientos, eliminación automática de versiones, generación de registros de cambios, estándares de mensajes de confirmación, lanzamientos semánticos o desee configurar lanzamientos automatizados. También se activa cuando el usuario pregunta sobre formatos de mensajes de confirmación como "feat:", "fix:" o "BREAKING CHANGE", o desea reemplazar un sistema de control de versiones existente (versión estándar, conjuntos de cambios, lerna, lanzamiento por favor) con lanzamiento semántico. Incluso si el usuario simplemente dice "configurar versiones" o "agregar automatización de lanzamiento", esta habilidad se aplica.
