Configurez des validations conventionnelles avec la version sémantique pour une gestion des versions sémantique automatisée. Utilisez cette compétence chaque fois que l'utilisateur mentionne des validations conventionnelles, la gestion des versions sémantiques, le semver, l'automatisation des versions, le remplacement automatique des versions, la génération du journal des modifications, les normes de message de validation, la publication sémantique ou souhaite configurer des versions automatisées. Se déclenche également lorsque l'utilisateur pose des questions sur les formats de message de validation tels que "feat:", "fix:" ou "BREAKING CHANGE", ou souhaite remplacer un système de gestion de versions existant (version standard, changesets, lerna, release-please) par une version sémantique. Même si l'utilisateur dit simplement « configurer la gestion des versions » ou « ajouter l'automatisation des versions », cette compétence s'applique.
