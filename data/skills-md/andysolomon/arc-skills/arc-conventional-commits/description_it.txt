Configura commit convenzionali con rilascio semantico per il controllo delle versioni semantico automatizzato. Utilizza questa abilità ogni volta che l'utente menziona commit convenzionali, controllo delle versioni semantico, semver, automazione del rilascio, bumping automatico della versione, generazione del log delle modifiche, standard dei messaggi di commit, rilascio semantico o desidera configurare rilasci automatizzati. Si attiva anche quando l'utente chiede informazioni sui formati dei messaggi di commit come "feat:", "fix:" o "BREAKING CHANGE" o desidera sostituire un sistema di versione esistente (versione standard, changeset, lerna, release-please) con rilascio semantico. Anche se l'utente dice semplicemente "imposta il controllo delle versioni" o "aggiungi l'automazione del rilascio", questa abilità si applica.
