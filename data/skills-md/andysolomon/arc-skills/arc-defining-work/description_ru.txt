Маршрутизатор назначения для создания новых рабочих элементов в GitHub Issues, Linear или Agile Accelerator. Используйте, когда вас просят создать истории, создать невыполненную работу, определить работу на основе анализа кодовой базы или преобразовать требования в отслеживаемые рабочие элементы, если трекер назначения еще не исправлен. Не использовать для планирования выполнения уже существующих работ.
