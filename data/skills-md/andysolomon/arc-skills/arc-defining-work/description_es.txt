Enrutador de destino para la creación de nuevos elementos de trabajo en GitHub Issues, Linear o Agile Accelerator. Úselo cuando se le solicite crear historias, crear un trabajo pendiente, definir el trabajo a partir del análisis de la base de código o convertir requisitos en elementos de trabajo rastreados y el rastreador de destino aún no está solucionado. No lo utilice para la planificación de implementación de trabajos existentes.
