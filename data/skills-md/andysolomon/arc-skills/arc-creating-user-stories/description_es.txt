Creación de trabajos pendientes de historias de usuario para problemas de GitHub utilizando historias de trabajo con criterios de aceptación de lista de verificación verificables. Úselo cuando se le solicite crear historias de desarrollo, escribir problemas de GitHub a partir de un plan, crear un trabajo pendiente de funciones o convertir ideas de funciones en historias de usuarios con seguimiento. No lo utilice para la planificación de la implementación después de que ya existan problemas.
