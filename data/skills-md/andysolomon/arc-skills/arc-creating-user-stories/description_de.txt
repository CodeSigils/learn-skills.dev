Erstellung eines User-Story-Backlogs für GitHub-Probleme mithilfe von Job-Storys mit überprüfbaren Checklisten-Akzeptanzkriterien. Verwenden Sie es, wenn Sie aufgefordert werden, Entwicklungsgeschichten zu erstellen, GitHub-Probleme aus einem Plan zu schreiben, ein Feature-Backlog aufzubauen oder Feature-Ideen in verfolgte User Stories umzuwandeln. Nicht für die Implementierungsplanung verwenden, nachdem bereits Probleme vorhanden sind.
