إنشاء سجل متراكم لقصة المستخدم لمشكلات GitHub باستخدام قصص الوظائف مع معايير قبول قائمة التحقق التي يمكن التحقق منها. استخدمها عندما يُطلب منك إنشاء قصص تطوير، أو كتابة مشكلات GitHub من خطة، أو إنشاء قائمة ميزات متراكمة، أو تحويل أفكار الميزات إلى قصص مستخدمين متتبعة. لا تستخدم لتخطيط التنفيذ بعد وجود مشكلات بالفعل.
