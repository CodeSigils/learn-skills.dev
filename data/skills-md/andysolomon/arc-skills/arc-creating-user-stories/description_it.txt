Creazione di backlog di storie utente per problemi GitHub utilizzando storie di lavoro con criteri di accettazione della lista di controllo verificabili. Da utilizzare quando richiesto per creare storie di sviluppo, scrivere problemi di GitHub da un piano, creare un backlog di funzionalità o trasformare idee di funzionalità in storie utente monitorate. Non utilizzare per la pianificazione dell'implementazione dopo che esistono già problemi.
