Создание журнала пользовательских историй для задач GitHub с использованием историй заданий с проверяемыми критериями приемки контрольного списка. Используйте, когда вас просят создавать истории разработки, записывать проблемы GitHub на основе плана, создавать невыполненные функции или превращать идеи функций в отслеживаемые пользовательские истории. Не используйте для планирования внедрения, если проблемы уже существуют.
