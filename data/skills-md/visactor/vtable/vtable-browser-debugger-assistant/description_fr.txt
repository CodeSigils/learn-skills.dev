Cette compétence doit être utilisée lors du débogage des problèmes de rendu/d'interaction de VTable (table basée sur toile) dans le navigateur via Chrome DevTools en inspectant le VRender Scenegraph (Scenegraph.tableGroup). Utilisez-le pour les canevas vierges/blancs, les cellules manquantes/mal alignées, les problèmes d'en-tête/corps gelés, les problèmes de survol/de zone de sélection, les problèmes de superposition DOM (attribut de réaction) et les différences React18/React19 dans la mise en page personnalisée/réconciliateur de réaction (par exemple, contamination par fibre, double React, erreurs d'éléments React plus anciens).
