Этот навык следует использовать при отладке проблем рендеринга/взаимодействия VTable (таблицы на основе холста) в браузере с помощью Chrome DevTools путем проверки VRender Scenegraph (Scenegraph.tableGroup). Используйте его для устранения пустого/белого холста, отсутствующих/невыровненных ячеек, проблем с замороженным заголовком/телом, проблем с наведением курсора/полем выбора, проблем с наложением DOM (атрибут реакции), а также различий React18/React19 в пользовательском макете/реакционном согласовании (например, загрязнение волокна, двойное реагирование, ошибки старых элементов React).
