Nutzen Sie diese Fähigkeit für jede PostgreSQL-Datenbankarbeit – Tabellendesign, Indizierung, Datentypen, Einschränkungen, Erweiterungen (pgvector, PostGIS, TimescaleDB), Suche und Migrationen.

**Auslösen, wenn der Benutzer dazu auffordert:**
- Entwerfen oder ändern Sie PostgreSQL-Tabellen, Schemata oder Datenmodelle
- Wählen Sie Datentypen, Einschränkungen, Indizes oder Partitionierungsstrategien
- Arbeiten Sie mit pgvector-Einbettungen, semantischer Suche oder RAG
- Richten Sie eine Volltextsuche, eine Hybridsuche oder ein BM25-Ranking ein
- Verwenden Sie PostGIS für räumliche/geografische Daten
- Richten Sie TimescaleDB-Hypertabellen für Zeitreihendaten ein
- Migrieren Sie Tabellen zu Hypertabellen oder bewerten Sie Migrationskandidaten
