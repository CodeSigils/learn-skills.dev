استخدم هذه المهارة لأي عمل في قاعدة بيانات PostgreSQL - تصميم الجدول، والفهرسة، وأنواع البيانات، والقيود، والامتدادات (pgvector، وPostGIS، وTimescaleDB)، والبحث، والترحيلات.

** يتم التشغيل عندما يطلب المستخدم:**
- تصميم أو تعديل جداول أو مخططات أو نماذج بيانات PostgreSQL
- اختر أنواع البيانات أو القيود أو الفهارس أو استراتيجيات التقسيم
- العمل مع تضمينات pgvector أو البحث الدلالي أو RAG
- قم بإعداد البحث عن النص الكامل، أو البحث المختلط، أو تصنيف BM25
- استخدم PostGIS للبيانات المكانية/الجغرافية
- إعداد الجداول الفائقة TimescaleDB لبيانات السلاسل الزمنية
- ترحيل الجداول إلى الجداول الفائقة أو تقييم مرشحي الترحيل

** الكلمات الرئيسية: ** PostgreSQL، Postgres، SQL، المخطط، تصميم الجدول، الفهارس، القيود، pgvector، PostGIS، TimescaleDB، جدول مفرط، البحث الدلالي، البحث المختلط، BM25، السلاسل الزمنية
