Utilisez cette compétence pour tout travail de base de données PostgreSQL : conception de tables, indexation, types de données, contraintes, extensions (pgvector, PostGIS, TimescaleDB), recherche et migrations.

** Déclenché lorsque l'utilisateur demande : **
- Concevoir ou modifier des tables, des schémas ou des modèles de données PostgreSQL
- Choisissez des types de données, des contraintes, des index ou des stratégies de partitionnement
- Travaillez avec les intégrations pgvector, la recherche sémantique ou RAG
- Configurer la recherche en texte intégral, la recherche hybride ou le classement BM25
- Utiliser PostGIS pour les données spatiales/géographiques
- Configurer les hypertables TimescaleDB pour les données de séries chronologiques
- Migrer des tables vers des hypertables ou évaluer les candidats à la migration

**Mots clés :** PostgreSQL, Postgres, SQL, schéma, conception de tables, index, contraintes, pgvector, PostGIS, TimescaleDB, hypertable, recherche sémantique, recherche hybride, BM25, séries chronologiques
