Utilice esta habilidad para cualquier trabajo de base de datos PostgreSQL: diseño de tablas, indexación, tipos de datos, restricciones, extensiones (pgvector, PostGIS, TimescaleDB), búsqueda y migraciones.

**Se activa cuando el usuario solicita:**
- Diseñar o modificar tablas, esquemas o modelos de datos de PostgreSQL.
- Elija tipos de datos, restricciones, índices o estrategias de partición
- Trabajar con incrustaciones de pgvector, búsqueda semántica o RAG
- Configurar búsqueda de texto completo, búsqueda híbrida o clasificación BM25
- Utilice PostGIS para datos espaciales/geográficos
- Configurar hipertablas TimescaleDB para datos de series temporales
- Migrar tablas a hipertablas o evaluar candidatos a migración

**Palabras clave:** PostgreSQL, Postgres, SQL, esquema, diseño de tablas, índices, restricciones, pgvector, PostGIS, TimescaleDB, hipertabla, búsqueda semántica, búsqueda híbrida, BM25, series de tiempo
