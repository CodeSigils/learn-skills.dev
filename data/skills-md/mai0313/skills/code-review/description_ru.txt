Проверка кода локальной проверки с учетом дефектов: незафиксированные изменения, разница между базовыми ветвями, одиночная фиксация или пользовательские инструкции по проверке. Возвращает приоритетные выводы P0-P3, привязанные к файлу:строка, а также общий вердикт о правильности. Только чтение, отчеты только в чат.
