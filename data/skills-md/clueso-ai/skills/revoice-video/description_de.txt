Geben Sie einem bestehenden Video eine erzählerische Überarbeitung – schreiben Sie das Drehbuch in einem neuen Ton um (enger, wärmer, formeller, energischer), wählen Sie eine passende Stimme, regenerieren Sie den Voiceover und richten Sie die visuellen Elemente an das neue Timing aus. Verwenden Sie diese Option, wenn der Benutzer sagt: „Machen Sie die Erzählung weniger roboterhaft“, „schreiben Sie den Voiceover so um, dass er freundlicher klingt“, „Dieses Video klingt zu steif, stimmen Sie es neu“, „Ändern Sie den Ton dieses Videos“ oder „Wiederholen Sie die Erzählung in einem anderen Stil“.
