Reduce una demostración completa de varias personas a solo las pantallas relevantes para un comprador específico en un acuerdo (consola de administración, experiencia del usuario final, análisis e informes, lo que corresponda) transcribiendo la estructura de la demostración, confirmando con el usuario exactamente qué secciones le interesan a esta persona, duplicando el proyecto para mantener intacta la demostración completa, luego eliminando las secciones irrelevantes en límites limpios y verificando que las transiciones aún se lean de forma natural. Esto es sustracción, no reencuadre: no se escribe ninguna narración nueva más allá de recortar una costura. Úselo cuando el usuario diga "reduzca esta demostración solo a las pantallas de administración", "recorte esto solo para lo que le interesa a este comprador", "elimine las partes de esta demostración que no sean relevantes para esta persona" o "haga una versión más corta de esta demostración para este comprador que se salte una sección".
