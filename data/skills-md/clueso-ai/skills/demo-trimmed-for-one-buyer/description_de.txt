Reduziert eine vollständige Multi-Persona-Demo auf nur die Bildschirme, die für einen bestimmten Käufer in einem Geschäft relevant sind (Administratorkonsole, Endbenutzererfahrung, Analyse und Berichterstellung, was auch immer zutrifft), indem die Struktur der Demo transkribiert wird, mit dem Benutzer genau bestätigt wird, welche Abschnitte diese Persona interessiert, das Projekt dupliziert wird, um die vollständige Demo intakt zu halten, dann die irrelevanten Abschnitte an sauberen Grenzen entfernt und überprüft wird, ob Übergänge immer noch natürlich lesbar sind. Dies ist eine Subtraktion, keine Umformulierung: Es wird keine neue Erzählung geschrieben, außer dass eine Naht zugeschnitten wird. Verwenden Sie diese Option, wenn der Benutzer sagt: „Reduzieren Sie diese Demo auf nur die Admin-Bildschirme“, „kürzen Sie sie nur auf das, was diesen Käufer interessiert“, „entfernen Sie die Teile dieser Demo, die für diese Persona nicht relevant sind“ oder „erstellen Sie eine kürzere Version dieser Demo für diesen Käufer, die einen Abschnitt überspringt“.
