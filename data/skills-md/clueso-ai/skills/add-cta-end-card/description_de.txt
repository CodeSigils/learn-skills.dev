Hängen Sie eine gebrandete Endkarte an ein vorhandenes Video an, mit einer einzigen klaren nächsten Aktion – einem Link, einer Testversion, einer Dokumentationsseite oder einem Kontakt – und einem sauberen Abschluss. Verwenden Sie es, wenn der Benutzer sagt: „Fügen Sie am Ende einen CTA hinzu“, „fügen Sie eine Endkarte hinzu“, „schließen Sie das Video mit einem Call-to-Action“, „fügen Sie ein Outro mit unserem Link hinzu“ oder „beenden Sie dies mit ‚Testversion starten‘“.
