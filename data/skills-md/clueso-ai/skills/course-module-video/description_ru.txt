Превратите план урока или заметки для SME в готовое для LMS видео модуля курса с указанием целей обучения, демонстрацией глав, однозначно сопоставленной с этими целями, мини-резюме и итоговым резюме с подсказкой для проверки знаний. Используйте, когда пользователь говорит «создать модуль курса», «превратить этот план урока в видео», «видео LMS по этой теме», «видео урока академии» или «видео модуля обучения для наших клиентов».
