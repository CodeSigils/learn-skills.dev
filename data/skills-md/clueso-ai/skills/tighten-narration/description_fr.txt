Réduisez le script d'une vidéo à l'essentiel pour qu'il atteigne une longueur cible : supprimez les redondances, conservez chaque étape, régénérez la narration et réalignez les visuels. À utiliser lorsque l'utilisateur dit « resserrer la narration », « la voix off est trop verbeuse », « réduire ce script à 60 secondes », « rendre la narration plus percutante » ou donne une vidéo plus une longueur cible que le script actuel dépasse.
