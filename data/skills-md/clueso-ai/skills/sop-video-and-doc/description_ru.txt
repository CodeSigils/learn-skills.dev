Создайте два артефакта из одной процедуры за один проход: видео с описанием СОП и пошаговую письменную СОП с аннотированным снимком экрана для каждого шага с одинаковой нумерацией шагов для обоих. Используйте, когда пользователь говорит: «Создайте видео и документ СОП», «Мне нужна эта процедура в виде видео и документа», «создайте СОП для этого процесса», «стандартная рабочая процедура со скриншотами» или «задокументируйте этот рабочий процесс для развертывания».
