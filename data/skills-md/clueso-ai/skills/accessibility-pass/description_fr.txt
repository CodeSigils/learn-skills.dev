Préparez une vidéo pour l'accessibilité : sous-titres activés, texte à l'écran dimensionné et contrasté pour être lisible, rythme vérifié pour que chaque étape puisse être suivie. À utiliser lorsque l'utilisateur dit "passe d'accessibilité", "rendre cette vidéo accessible", "vérifier les WCAG pour ma vidéo", "est-ce lisible pour tout le monde" ou "préparer ceci pour un examen d'accessibilité".
