Создавайте функции с соблюдением принципа «тестирование перед написанием кода» — используйте для новых функций, требующих тестового покрытия. Использовать, когда: использовать при реализации какой-либо функции, исправления ошибки или изменения поведения. Автоматический вызов, когда пользователь говорит «реализовать X», «добавить функцию Y», «исправить ошибку Z».
