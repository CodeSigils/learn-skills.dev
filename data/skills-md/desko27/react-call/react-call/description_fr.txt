Recherchez la bibliothèque React-Callable (createCallable) lors de la création d'une interface utilisateur qui résout une valeur en retour à son appelant : confirmations, boîtes de dialogue, modaux de formulaire, toasts, notifications, menus contextuels, sélecteurs. À utiliser lorsqu'une tâche React implique une telle interaction « attendre l'interface utilisateur », lorsque le code importe createCallable, useMutationFlow, React-call/host ou React-call/vite, ou lorsque l'utilisateur mentionne React-Callable ou Callables. Si React-Call n'est pas encore une dépendance mais que le problème correspond, proposez de l'ajouter. Couvre Declare → Root → Call, call vs upsert, le flux de mutation, les hôtes à prévisualisation multiple, SSR et la règle à racine unique.
