يمكنك الوصول إلى مكتبة رد الفعل (createCallable) عند إنشاء واجهة مستخدم تعمل على حل القيمة مرة أخرى للمتصل بها - التأكيدات، ومربعات الحوار، ونماذج النماذج، والخبز المحمص، والإشعارات، وقوائم السياق، والملتقطات. يُستخدم عندما تتضمن مهمة React أي تفاعل من هذا القبيل "في انتظار واجهة المستخدم"، أو عندما يستورد الكود createCallable، أو useMutationFlow، أو رد فعل/مضيف، أو رد فعل/دعوة، أو عندما يذكر المستخدم استدعاء تفاعل أو Callables. إذا لم تكن خدمة رد الفعل تبعية حتى الآن ولكن المشكلة مناسبة، فاقترح إضافتها. يغطي الإعلان → الجذر → الاتصال، الاتصال مقابل upsert، تدفق الطفرة، المضيفين متعددي المعاينة، SSR، وقاعدة الجذر الفردي.
