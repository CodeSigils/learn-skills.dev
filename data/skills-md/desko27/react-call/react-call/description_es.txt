Utilice la biblioteca de llamada de reacción (createCallable) cuando cree una interfaz de usuario que resuelva un valor en su interlocutor: confirmaciones, diálogos, modales de formulario, brindis, notificaciones, menús contextuales, selectores. Úselo cuando una tarea de React implique una interacción de "esperar la interfaz de usuario", cuando el código importe createCallable, useMutationFlow, reaccionar-call/host o reaccionar-call/vite, o cuando el usuario mencione reaccionar-call o Callables. Si reaccionar-call aún no es una dependencia pero el problema encaja, propón agregarlo. Cubre Declarar → Raíz → Llamar, llamar vs insertar, flujo de mutación, hosts de vista previa múltiple, SSR y la regla de raíz única.
