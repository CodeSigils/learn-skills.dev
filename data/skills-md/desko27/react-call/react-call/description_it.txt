Raggiungi la libreria react-call (createCallable) quando crei un'interfaccia utente che risolve un valore al chiamante: conferme, finestre di dialogo, moduli modali, avvisi, menu contestuali, selettori. Da utilizzare quando un'attività React prevede un'interazione di tipo "attendi l'interfaccia utente", quando il codice importa createCallable, useMutationFlow, react-call/host o react-call/vite o quando l'utente menziona react-call o Callables. Se react-call non è ancora una dipendenza ma il problema si adatta, proponi di aggiungerlo. Copre Declare→Root→Call, call vs upsert, flusso di mutazione, host con anteprima multipla, SSR e la regola della radice singola.
