Révisez, convertissez et améliorez le code de l'interface utilisateur à l'aide de Chakra UI v3. Utilisez cette compétence chaque fois qu'un utilisateur souhaite examiner le code de l'interface utilisateur de Chakra pour détecter des problèmes, convertir du HTML/CSS simple, Tailwind, des modules CSS ou des composants stylisés en interface utilisateur Chakra, nettoyer des composants Chakra désordonnés, corriger la structure de mise en page ou l'utilisation des jetons, ou demande quelque chose comme "est-ce correct", "qu'est-ce qui ne va pas avec ceci", "réviser mon composant", "refactoriser ceci", "nettoyer", "convertir" ou "chakra-ifier ceci" - même sans les mots "réviser" ou "refactoriser". Déclenchez toute demande de vérification, d'amélioration ou de conversion du code de l'interface utilisateur Chakra, même si elle est formulée avec désinvolture.
