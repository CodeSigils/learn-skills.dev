Просматривайте, конвертируйте и улучшайте код пользовательского интерфейса с помощью Chakra UI v3. Используйте этот навык всякий раз, когда пользователь хочет проверить код пользовательского интерфейса Chakra на наличие проблем, преобразовать простые HTML/CSS, Tailwind, CSS-модули или стилизованные компоненты в пользовательский интерфейс Chakra, очистить беспорядочные компоненты Chakra, исправить структуру макета или использование токенов или спросить что-то вроде «это правильно», «что в этом не так», «проверить мой компонент», «рефакторить это», «очистить», «конвертировать» или «откорректировать чакрой это» — даже без слов «проверить» или «рефакторинг». Запускайте любой запрос на проверку, улучшение или преобразование кода пользовательского интерфейса Chakra, даже если он сформулирован небрежно.
