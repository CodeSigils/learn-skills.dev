قم بمراجعة وتحويل وتحسين كود واجهة المستخدم باستخدام Chakra UI v3. استخدم هذه المهارة عندما يريد المستخدم مراجعة كود Chakra UI لحل المشكلات، أو تحويل HTML/CSS عادي، أو Tailwind، أو وحدات CSS، أو المكونات المصممة إلى Chakra UI، أو تنظيف مكونات Chakra الفوضوية، أو إصلاح بنية التخطيط أو استخدام الرمز المميز، أو طرح أي شيء مثل "هل هذا صحيح"، أو "ما الخطأ في هذا"، أو "مراجعة المكون الخاص بي"، أو "إعادة بناء هذا"، أو "تنظيف"، أو "تحويل"، أو "chakra-ify this" - حتى بدون الكلمات "مراجعة" أو "إعادة البناء". قم بتشغيل أي طلب للتحقق من كود Chakra UI أو تحسينه أو تحويله، مهما كانت صياغته بشكل عرضي.
