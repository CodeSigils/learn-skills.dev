Migrieren Sie Chakra-UI-Projekte von Version 2 auf Version 3 und umfassen Sie Paketänderungen, Codemods, Anbietereinrichtung, Farbmodus, Umbenennung von Requisiten, zusammengesetzte Komponenten, Themen, Rezepte und Next.js-Updates. Verwenden Sie diesen Skill immer dann, wenn ein Benutzer Chakra-UI-Versionen aktualisiert, nach einem Upgrade auf wichtige Änderungen stößt, alte v2-Muster (ColorModeScript, useColorModeValue, styleConfig, extensionTheme, isDisabled, colorScheme, @chakra-ui/icons, Framer-Motion-Abhängigkeit) konvertiert, zusammengesetzte Komponentenmuster repariert oder nach Unterschieden zwischen Chakra UI v2 und v3 fragt – auch wenn nicht explizit „Migrieren“ oder „Upgrade“ gesagt wird.
