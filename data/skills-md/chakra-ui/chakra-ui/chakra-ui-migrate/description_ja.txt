Chakra UI プロジェクトを v2 から v3 に移行します。これには、パッケージの変更、codemod、プロバイダーのセットアップ、カラー モード、プロップの名前変更、複合コンポーネント、テーマ、レシピ、Next.js の更新が含まれます。ユーザーが Chakra UI のバージョンをアップグレードするとき、アップグレード後に重大な変更が発生するとき、古い v2 パターン (ColorModeScript、useColorModeValue、styleConfig、extendTheme、isDisabled、colorScheme、@chakra-ui/icons、framer-motion 依存関係) を変換するとき、複合コンポーネント パターンを修正するとき、または Chakra UI v2 と v3 の違いについて尋ねるときは必ず、「移行」または「アップグレード」と言っていなくても、このスキルを使用してください。明示的に。
