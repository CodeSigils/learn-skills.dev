Migra i progetti dell'interfaccia utente Chakra dalla v2 alla v3, coprendo modifiche ai pacchetti, codemod, configurazione del provider, modalità colore, ridenominazione delle prop, componenti composti, temi, ricette e aggiornamenti Next.js. Utilizza questa abilità ogni volta che un utente aggiorna le versioni dell'interfaccia utente di Chakra, riscontra modifiche sostanziali dopo un aggiornamento, converte vecchi modelli v2 (ColorModeScript, useColorModeValue, styleConfig, extendTheme, isDisabled, colorScheme, @chakra-ui/icons, framer-motion dependency), corregge i modelli di componenti composti o chiede informazioni sulle differenze tra Chakra UI v2 e v3, anche se non dicono esplicitamente "migra" o "aggiorna".
