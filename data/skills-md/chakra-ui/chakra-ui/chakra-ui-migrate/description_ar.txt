قم بترحيل مشاريع Chakra UI من الإصدار 2 إلى الإصدار 3، مع تغطية تغييرات الحزمة، وتعديلات التعليمات البرمجية، وإعداد الموفر، ووضع الألوان، وإعادة تسمية العناصر، والمكونات المركبة، والسمات، والوصفات، وتحديثات Next.js. استخدم هذه المهارة عندما يقوم المستخدم بترقية إصدارات Chakra UI، أو يواجه تغييرات معطلة بعد الترقية، أو تحويل أنماط الإصدار 2 القديمة (ColorModeScript، أو useColorModeValue، أو styleConfig، أو ExtendTheme، أو isDisabled، أو colorScheme، أو @chakra-ui/icons، أو تبعية Framer-motion)، أو إصلاح أنماط المكونات المركبة، أو السؤال عن الاختلافات بين Chakra UI v2 وv3 - حتى لو لم يقولوا "ترحيل" أو "ترقية" صراحة.
