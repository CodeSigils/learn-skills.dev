Migrez les projets d'interface utilisateur Chakra de la v2 vers la v3, couvrant les modifications de package, les codemods, la configuration du fournisseur, le mode couleur, le renommage des accessoires, les composants composés, les thèmes, les recettes et les mises à jour Next.js. Utilisez cette compétence chaque fois qu'un utilisateur met à niveau les versions de Chakra UI, rencontre des changements importants après une mise à niveau, convertit d'anciens modèles v2 (ColorModeScript, useColorModeValue, styleConfig, extendTheme, isDisabled, colorScheme, @chakra-ui/icons, framer-motion dependency), corrige les modèles de composants composés ou pose des questions sur les différences entre Chakra UI v2 et v3 - même s'ils ne disent pas explicitement "migrer" ou "mettre à niveau".
