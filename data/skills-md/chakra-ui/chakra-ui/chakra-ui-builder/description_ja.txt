Chakra UI v3 を使用して応答性が高くアクセスしやすい UI コンポーネントとレイアウトを構築し、新規および既存のプロジェクトに Chakra UI をインストールまたは構成し、トークン、セマンティック トークン、レシピ、スロット レシピを使用してスケーラブルなテーマを設計します。ユーザーが Chakra UI を使用して UI コンポーネント、ページ、フォーム、ダッシュボード、ナビゲーションバー、カード、ランディング セクション、価格表、またはレイアウトを構築、作成、または生成するように要求するときは常に、このスキルを使用します。 Chakra UI をプロジェクトに追加する、ChakraProvider をセットアップする、CLI スニペットを実行する、カラー モードを構成する、またはプロバイダーのラッピングを修正したい。または、テーマについて尋ねます。ブランドカラー、デザイントークン、セマンティックトークン、ダークモード値、コンポーネントレシピ、スロットレシピ、typegen の定義、またはデフォルトテーマの削除などです。 「ブランドカラーを追加する」、「再利用可能なカードスタイルを作成する」、「棒グラフを作成する」、「折れ線グラフを表示する」、「ログインフォームを作成する」、「サイドバーを作成する」、「アプリにChakraを追加する」など、Chakra UIの構築、セットアップ、またはテーマまたはチャートのリクエストが、たとえカジュアルな表現であってもトリガーされます。
