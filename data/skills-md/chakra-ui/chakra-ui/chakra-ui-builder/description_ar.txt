قم ببناء مكونات وتخطيطات واجهة مستخدم سريعة الاستجابة ويمكن الوصول إليها باستخدام Chakra UI v3، وقم بتثبيت أو تكوين Chakra UI في المشاريع الجديدة والحالية، وتصميم سمات قابلة للتطوير باستخدام الرموز المميزة والرموز الدلالية والوصفات ووصفات الفتحات. استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو إنشاء أو إنشاء أي مكون لواجهة المستخدم أو صفحة أو نموذج أو لوحة معلومات أو شريط تنقل أو بطاقة أو قسم مقصود أو جدول تسعير أو تخطيط باستخدام Chakra UI؛ يريد إضافة Chakra UI إلى مشروع، أو إعداد ChakraProvider، أو تشغيل مقتطفات CLI، أو تكوين وضع الألوان، أو إصلاح التفاف الموفر؛ أو يسأل عن السمات - تحديد ألوان العلامة التجارية، أو رموز التصميم، أو الرموز الدلالية، أو قيم الوضع المظلم، أو وصفات المكونات، أو وصفات الفتحات، أو الكتابة، أو إخراج السمة الافتراضية. قم بتشغيل أي طلب بناء أو إعداد أو سمات أو مخططات لواجهة مستخدم Chakra، مهما كانت صياغتها بشكل عرضي - "أضف ألوان علامتي التجارية"، "إنشاء نمط بطاقة قابل لإعادة الاستخدام"، "إنشاء مخطط شريطي"، "إظهار مخطط خطي"، "إنشاء نموذج تسجيل دخول"، "إنشاء شريط جانبي"، "إضافة شقرا إلى تطبيقي".
