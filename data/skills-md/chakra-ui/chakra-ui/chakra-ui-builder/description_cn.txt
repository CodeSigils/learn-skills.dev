使用 Chakra UI v3 构建响应式、可访问的 UI 组件和布局，在新项目和现有项目中安装或配置 Chakra UI，并使用令牌、语义令牌、配方和槽配方设计可扩展主题。每当用户要求使用 Chakra UI 构建、创建或生成任何 UI 组件、页面、表单、仪表板、导航栏、卡片、登陆部分、定价表或布局时，请使用此技能；想要将 Chakra UI 添加到项目、设置 ChakraProvider、运行 CLI 片段、配置颜色模式或修复提供程序包装；或询问主题 - 定义品牌颜色、设计标记、语义标记、暗模式值、组件配方、插槽配方、类型生成或弹出默认主题。触发任何 Chakra UI 构建、设置或主题或图表请求，无论措辞如何随意 —“添加我的品牌颜色”、“制作可重复使用的卡片样式”、“构建条形图”、“向我显示折线图”、“为我制作一个登录表单”、“构建侧边栏”、“将 Chakra 添加到我的应用程序”。
