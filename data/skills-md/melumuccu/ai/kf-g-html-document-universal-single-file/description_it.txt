Utilizza questa competenza durante la creazione o la revisione di documenti HTML interattivi a file singolo senza build, ad esempio HTML di PR o di revisione dei problemi, guide con annotazioni, procedure dettagliate o pagine esplicative statiche condivisibili. Applicalo ogni volta che l'utente desidera una documentazione interattiva di una pagina o una spiegazione HTML condivisibile, anche se non dice "HTML a file singolo".
