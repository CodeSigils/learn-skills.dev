Nutzen Sie diese Fertigkeit beim Erstellen oder Überarbeiten von Build-freien, interaktiven HTML-Dokumenten aus einer einzigen Datei – zum Beispiel PR- oder Issue-Review-HTML, kommentierte Leitfäden, exemplarische Vorgehensweisen oder gemeinsam nutzbare statische Erklärungsseiten. Wenden Sie es immer dann an, wenn der Benutzer eine einseitige interaktive Dokumentation oder eine gemeinsam nutzbare HTML-Erklärung wünscht, auch wenn er nicht „Einzeldatei-HTML“ sagt.
