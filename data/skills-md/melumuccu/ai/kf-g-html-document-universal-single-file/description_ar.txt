استخدم هذه المهارة عند إنشاء أو مراجعة مستندات HTML تفاعلية خالية من البناء وملف واحد - على سبيل المثال العلاقات العامة أو HTML لمراجعة المشكلات، أو الأدلة المشروحة، أو الإرشادات الإرشادية، أو صفحات الشرح الثابتة القابلة للمشاركة. قم بتطبيقه عندما يريد المستخدم وثائق تفاعلية من صفحة واحدة أو شرح HTML قابل للمشاركة، حتى لو لم يذكر "HTML ملف واحد".
