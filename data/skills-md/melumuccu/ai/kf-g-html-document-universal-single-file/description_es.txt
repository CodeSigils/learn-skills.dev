Utilice esta habilidad al crear o revisar documentos HTML interactivos de un solo archivo y sin compilación, por ejemplo HTML de relaciones públicas o revisión de problemas, guías comentadas, tutoriales o páginas explicativas estáticas que se pueden compartir. Aplíquelo siempre que el usuario desee documentación interactiva de una página o una explicación HTML que se pueda compartir, incluso si no dice "HTML de un solo archivo".
