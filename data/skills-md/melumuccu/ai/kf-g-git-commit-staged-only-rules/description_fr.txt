Appliquez un comportement par étapes uniquement pour les commits git. Utilisez toujours cette compétence chaque fois que l'utilisateur demande une validation, souhaite qu'une validation soit créée, demande d'exécuter git commit, souhaite un message de validation basé sur les modifications du dépôt ou utilise des invites courtes telles que "commit", "commit plz" ; combinez-le avec kf-g-git-commit-japanese-commit-message lors de la création du message.
