Applica il comportamento di sola messa in scena per i commit git. Usa sempre questa abilità ogni volta che l'utente chiede di impegnarsi, desidera creare un commit, chiede di eseguire git commit, desidera un messaggio di commit basato sulle modifiche del repository o utilizza brevi istruzioni come "commit", "commit per favore"; combinalo con kf-g-git-commit-japanese-commit-message durante la creazione del messaggio.
