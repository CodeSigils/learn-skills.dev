Erzwingen Sie nur gestaffeltes Verhalten für Git-Commits. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach einem Commit fragt, einen Commit erstellen möchte, die Ausführung von git commit wünscht, eine Commit-Nachricht basierend auf Repo-Änderungen wünscht oder kurze Eingabeaufforderungen wie „commit“, „commit plz“ verwendet; Kombinieren Sie es mit kf-g-git-commit-japanese-commit-message, wenn Sie die Nachricht erstellen.
