فرض السلوك المرحلي فقط لالتزامات git. استخدم هذه المهارة دائمًا عندما يطلب المستخدم الالتزام، أو يريد إنشاء التزام، أو يطلب تشغيل git Commit، أو يريد رسالة التزام بناءً على تغييرات الريبو، أو يستخدم مطالبات قصيرة مثل "commit"، "commit plz"؛ قم بدمجها مع رسالة kf-g-git-commit-japanese-commit-message عند إنشاء الرسالة.
