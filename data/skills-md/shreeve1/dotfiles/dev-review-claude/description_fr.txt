Révision de code indépendante en utilisant une nouvelle session interactive Claude Code en tant que réviseur. À UTILISER QUAND l'utilisateur dit "dev-review-claude", "/skill:dev-review-claude", "independent Claude review", ou souhaite une deuxième évaluation par Claude d'un plan, d'une construction (diff non validée), d'un chemin de fichier/répertoire ou d'une proposition. Accepte les indicateurs de modèle facultatifs `--claude` / `--opus` / `--sonnet` et un argument cible (`plan`, `build`, `proposal` ou un chemin).
