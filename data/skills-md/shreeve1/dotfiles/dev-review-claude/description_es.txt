Revisión de código independiente utilizando una nueva sesión interactiva de Claude Code como revisor. UTILIZAR CUANDO el usuario dice "dev-review-claude", "/skill:dev-review-claude", "revisión independiente de Claude", o quiere una revisión de segunda opinión impulsada por Claude de un plan, compilación (diferencia no confirmada), ruta de archivo/directorio o propuesta. Acepta indicadores de modelo opcionales `--claude` / `--opus` / `--sonnet` y un argumento de destino (`plan`, `build`, `propuesta` o una ruta).
