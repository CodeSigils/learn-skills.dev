تفاعل مع YouThumb.ai API لإنشاء صور مصغرة على YouTube مدعومة بالذكاء الاصطناعي. تحميل الأصول، وإنشاء الأشخاص، وإنشاء المشاريع، وإطلاق التوليد، واسترداد النتائج. يُستخدم عندما يقول المستخدم "YouThumb API"، أو "إنشاء صورة مصغرة عبر واجهة برمجة التطبيقات"، أو "تحميل الأصل إلى YouThumb"، أو "إنشاء مشروع YouThumb"، أو "إنشاء صورة مصغرة"، أو "شخص YouThumb"، أو عند أتمتة إنشاء الصورة المصغرة على YouTube برمجيًا.
