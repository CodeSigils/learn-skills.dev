Interagissez avec l'API YouThumb.ai pour générer des miniatures YouTube basées sur l'IA. Téléchargez des actifs, créez des personnes, créez des projets, lancez la génération et récupérez les résultats. À utiliser lorsque l'utilisateur dit « API YouThumb », « générer une miniature via l'API », « télécharger une ressource sur YouThumb », « créer un projet YouThumb », « générer une miniature », « personne YouThumb » ou lors de l'automatisation de la création de miniatures YouTube par programme.
