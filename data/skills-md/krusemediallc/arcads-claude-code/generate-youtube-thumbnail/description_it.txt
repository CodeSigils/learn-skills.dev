Genera miniature YouTube con CTR elevato utilizzando Nano Banana 2 tramite l'API esterna Arcads. Gestisce il caricamento delle immagini di riferimento, l'allineamento della somiglianza dei caratteri, le formule di prompt comprovate testate dal CTR e la generazione batch parallela. Da utilizzare quando l'utente chiede di creare una miniatura di YouTube, una miniatura di video, varianti di miniature di test A/B o fa riferimento al design della miniatura con il proprio volto, risorse del brand o foto di prodotti.
