قم بإنشاء صور مصغرة على YouTube ذات نسبة نقر إلى ظهور عالية باستخدام Nano Banana 2 عبر واجهة برمجة تطبيقات Arcads الخارجية. يتعامل مع تحميل الصور المرجعية، ومحاذاة تشابه الأحرف، والصيغ السريعة التي تم اختبارها بواسطة نسبة النقر إلى الظهور (CTR)، وإنشاء الدفعات المتوازية. يُستخدم عندما يطلب المستخدم إنشاء صورة مصغرة على YouTube، أو صورة مصغرة للفيديو، أو أشكال مختلفة من الصور المصغرة لاختبار A/B، أو يشير إلى تصميم الصورة المصغرة بوجهه، أو أصول العلامة التجارية، أو صور المنتج.
