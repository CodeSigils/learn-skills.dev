Arcads 外部 API を介して Nano Banana 2 / Nano Banana Pro (Gemini Flash Image ファミリー) を介して 1 つ以上のスタンドアロン メタ イメージ広告クリエイティブを生成します。モデル ファミリをロックし、プラットフォームのクロムを自動削除し、エッジセーフ レイアウトを強制します。ユーザーが「Nano Banana 広告」、「Gemini イメージ広告」、「nano-banana-2 広告クリエイティブ」、「Gemini で静的イメージ広告を作成」を要求する場合、またはフォトリアル / ライフスタイル / マルチリファレンス / 手持ちオブジェクト / 粘土テクスチャの広告クリエイティブ (付箋紙のフラットレイ、保持されたホワイトボードの看板、ライフスタイルのポートレート、食材のコラージュ、OOH 写真) のニーズをアンカーする場合に使用します。 ChatGPT 画像キューではトリガーされません。それらには chatgpt-image-ad を使用します。
