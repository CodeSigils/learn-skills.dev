Создайте один или несколько автономных мета-изображений с помощью Nano Banana 2/Nano Banana Pro (семейство Gemini Flash Image) через внешний API Arcads. Блокирует семейство моделей, автоматически удаляет хромированную платформу, обеспечивает безопасную компоновку. Используйте, когда пользователь запрашивает «рекламу нано-банан», «рекламу с изображением Близнецов», «объявление нано-банан-2», «создать статическую графическую рекламу с Близнецами» или указывает на потребность в фотореалистичных рекламных объявлениях, образах жизни, мультиреференциях, портативных объектах, глиняных текстурах (плоские стикеры, таблички на досках, портреты образа жизни, коллажи из ингредиентов, наружная фотография). НЕ срабатывает по подсказкам изображений ChatGPT — для них используйте chatgpt-image-ad.
