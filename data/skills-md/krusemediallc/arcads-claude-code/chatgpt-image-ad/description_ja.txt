Arcads 外部 API を介して ChatGPT 画像 2 (gpt-image-2) を介して 1 つ以上のスタンドアロン メタ イメージ広告クリエイティブを生成します。モデルをロックし、プラットフォームのクロムを自動的に削除し、エッジセーフ レイアウトと本文テキスト内のグリフ セーフを強制します。ユーザーが「gpt-image-2 広告」、「ChatGPT イメージ広告」、「イメージ 2 広告クリエイティブ」、「GPT で静的イメージ広告を作成する」、またはタイポグラフィーを多用した/密なテキスト/UI を模倣した広告クリエイティブ (チャット スレッド、比較表、偽の検索結果、iOS ダイアログ、Slack スナップショット、ChatGPT 会話広告、Apple Notes リスト) の必要性をアンカーする場合に使用します。 Nano Banana キューではトリガーされません。それらには nano-banana-image-ad を使用してください。
