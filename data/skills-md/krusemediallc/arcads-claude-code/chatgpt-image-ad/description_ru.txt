Создайте одно или несколько отдельных мета-изображений с помощью изображения ChatGPT 2 (gpt-image-2) через внешний API Arcads. Блокирует модель, автоматически удаляет хром платформы, обеспечивает безопасный макет и безопасность глифов внутри основного текста. Используйте, когда пользователь запрашивает «объявление gpt-image-2», «изображение ChatGPT», «объявление изображения 2», «создать статическое графическое объявление с GPT» или указывает на потребность в рекламных объявлениях с большим количеством типографики, плотным текстом или имитацией пользовательского интерфейса (темы чата, сравнительные таблицы, поддельные результаты поиска, диалоговые окна iOS, снимки Slack, рекламные объявления ChatGPT, списки Apple Notes). НЕ срабатывает по сигналам Nano Banana — для них используйте nano-banana-image-ad.
