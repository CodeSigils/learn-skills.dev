يُستخدم عندما يريد المستخدم إجراء هندسة عكسية لإعلان مصور حالي وتحويله إلى نموذج مطالبة قابل لإعادة الاستخدام. يتم التحقق من الصحة عبر Arcads — يختار gpt-image-2 أو Nano Banana في المرحلة الأولى. يتم تشغيله عند "استنساخ هذا الإعلان كقالب"، و"الهندسة العكسية لهذا الإعلان"، و"تحويل هذا الإعلان إلى مطالبة"، و"استخراج نموذج"، و"جعل هذا الإعلان قابلاً لإعادة الاستخدام"، و"إضافة إلى مكتبتي السريعة"، و"دراسة هذا الإعلان وإنشاء نموذج". الإدخال عبارة عن صورة إعلانية موجودة؛ لا يتم تشغيله للجيل الجديد (استخدم chatgpt-image-ad أو nano-banana-image-ad).
