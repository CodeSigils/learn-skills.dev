Создает и извлекает AI-видео и ресурсы, связанные с изображениями, через внешний API Arcads (Seedance 2.0, Sora 2, Veo 3.1, Kling, Grok Video, Nano Banana, b-roll, сцены, сценарии/потоки актеров). Загружает подсказки из встроенного руководства по подсказкам и библиотеки моделей, соблюдает базовую аутентификацию HTTP из ARCADS_API_KEY и опрашивает ресурсы/видео до тех пор, пока они не будут готовы. Используйте, когда пользователь упоминает Arcads, external-api.arcads.ai, Seedance, Sora2, Veo, Kling, Nano Banana, b-roll, сценарии пользовательского контента или создание маркетингового креатива с помощью Arcads.
