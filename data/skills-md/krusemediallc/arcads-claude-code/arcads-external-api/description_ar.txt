إنشاء واسترداد مقاطع الفيديو والأصول المتعلقة بالصور بالذكاء الاصطناعي عبر واجهة برمجة تطبيقات Arcads الخارجية (Seedance 2.0، Sora 2، Veo 3.1، Kling، Grok Video، Nano Banana، b-roll، المشهد، تدفقات البرنامج النصي/الممثل). يقوم بتحميل المطالبات من دليل المطالبة المضمن ومكتبة النماذج، ويحترم مصادقة HTTP الأساسية من ARCADS_API_KEY، ويستقصي الأصول/مقاطع الفيديو حتى يصبح جاهزًا. يُستخدم عندما يذكر المستخدم Arcads، أو External-api.arcads.ai، أو Seedance، أو Sora2، أو Veo، أو Kling، أو Nano Banana، أو b-roll، أو البرامج النصية التي ينشئها المستخدمون، أو إنشاء تصميم إبداعي للتسويق من خلال Arcads.
