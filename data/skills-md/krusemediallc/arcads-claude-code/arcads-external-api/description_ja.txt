Arcads 外部 API (Seedance 2.0、Sora 2、Veo 3.1、Kling、Grok Video、Nano Banana、B ロール、シーン、スクリプト/アクター フロー) を介して AI ビデオおよび画像関連アセットを作成および取得します。バンドルされたプロンプト ガイドとモデル ライブラリからプロンプトをロードし、ARCADS_API_KEY からの HTTP 基本認証を尊重し、準備ができるまでアセット/ビデオをポーリングします。ユーザーが Arcads、external-api.arcads.ai、Seedance、Sora2、Veo、Kling、Nano Banana、b-roll、UGC スクリプト、または Arcads を介したマーケティング クリエイティブの生成について言及する場合に使用します。
