Stock Smart 3D Scoring Analysis Skill (v2.0). Input a stock code (A‑shares/Hong Kong stocks/US stocks) and it automatically:
1. Retrieves real‑time quotes + historical K‑line data + fundamental indicators
2. Calculates technical indicators (MA / MACD / RSI / volume / price deviation)
3. Generates a three‑dimensional score: technical 50 + fundamental 30 + news 20 = 100 points
4. Performs a WebSearch to pull news → Claude evaluates the news‑sentiment score
5. Outputs a 3D decision dashboard (including the 3‑D breakdown + buy/sell signals + price targets)

Trigger scenarios: the user provides a stock code and requests an analysis, asks how a particular stock is performing, requests a market view, etc.
Example inputs: “Analyze TSLA PLTR”, “How about 600519”, “Help me look at HK00700”.
