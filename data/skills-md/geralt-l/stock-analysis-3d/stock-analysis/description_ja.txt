株式スマート 3D スコア分析スキル (v2.0)。銘柄コード (A 株/香港株/米国株) を入力すると、次のように自動的に行われます。
1. リアルタイム相場 + 過去の K-line データ + ファンダメンタルズ指標を取得します
2.テクニカル指標（MA / MACD / RSI / 出来高 / 価格偏差）を計算します
3. 三次元スコアを生成します: 技術 50 + 基礎 30 + ニュース 20 = 100 ポイント
4. Web 検索を実行してニュースを取得 → クロードがニュース感情スコアを評価します
5. 3D 意思決定ダッシュボードを出力します (3D 内訳 + 売買シグナル + 価格目標を含む)

トリガーシナリオ: ユーザーは銘柄コードを入力して分析をリクエストし、特定の銘柄のパフォーマンスを尋ね、市場の見方をリクエストします。
入力例: 「TSLA PLTR を分析する」、「600519 はどうですか」、「HK00700 を調べるのを手伝ってください」。
