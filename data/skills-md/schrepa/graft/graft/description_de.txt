Wird zum Erstellen, Umgestalten oder Dokumentieren von Graft-Apps und -Proxys verwendet, einschließlich der Aufforderung, einen Tool-Server, API-Server, Dual-Protokoll-Server oder eine MCP-HTTP-Brücke zu erstellen. Die Kernthese von Graft: Definieren Sie Tools einmal und stellen Sie sie sowohl als HTTP-REST-Endpunkte als auch als MCP-Tools vom selben Server bereit, wobei Erkennung, Dokumentation und OpenAPI automatisch generiert werden. Behandelt konkrete Aktionen wie das Definieren von Tools und Handlern, das Konfigurieren von Authentifizierungs-Middleware, das Einrichten von HTTP- und Standardtransporten, das Generieren von OpenAPI-Dokumentation, das Umschließen vorhandener APIs über den Proxy-Modus und das Verkabeln des gesamten CLI-Workflows.
