يُستخدم عند إنشاء تطبيقات Graft والوكلاء أو إعادة هيكلتها أو توثيقها، بما في ذلك عندما يُطلب منك إنشاء خادم أدوات، أو خادم API، أو خادم بروتوكول مزدوج، أو جسر MCP-HTTP. الأطروحة الأساسية لـ Graft: تحديد الأدوات مرة واحدة وتقديمها كنقاط نهاية HTTP REST وأدوات MCP من نفس الخادم، مع إنشاء الاكتشاف والمستندات وOpenAPI تلقائيًا. يغطي إجراءات ملموسة مثل تعريف الأدوات والمعالجات، وتكوين البرامج الوسيطة للمصادقة، وإعداد عمليات النقل HTTP وstdio، وإنشاء وثائق OpenAPI، وتغليف واجهات برمجة التطبيقات الموجودة عبر وضع الوكيل، وتوصيل سير عمل CLI الكامل.
