Da utilizzare durante la creazione, il refactoring o la documentazione di app e proxy Graft, anche quando viene richiesto di creare un server di strumenti, un server API, un server a doppio protocollo o un bridge MCP-HTTP. La tesi principale di Graft: definire gli strumenti una volta e servirli sia come endpoint REST HTTP che come strumenti MCP dallo stesso server, con rilevamento, documenti e OpenAPI generati automaticamente. Copre azioni concrete come la definizione di strumenti e gestori, la configurazione del middleware di autenticazione, l'impostazione dei trasporti HTTP e stdio, la generazione di documentazione OpenAPI, il confezionamento delle API esistenti tramite modalità proxy e il cablaggio dell'intero flusso di lavoro CLI.
