Graft アプリとプロキシを構築、リファクタリング、または文書化するときに使用します。これには、ツール サーバー、API サーバー、デュアル プロトコル サーバー、または MCP-HTTP ブリッジの作成を求められた場合も含まれます。 Graft の核となるテーマは、ツールを一度定義すると、同じサーバーから HTTP REST エンドポイントと MCP ツールの両方として機能し、ディスカバリ、ドキュメント、OpenAPI が自動的に生成されるというものです。ツールとハンドラーの定義、認証ミドルウェアの構成、HTTP および stdio トランスポートのセットアップ、OpenAPI ドキュメントの生成、プロキシ モードを介した既存の API のラップ、完全な CLI ワークフローの接続などの具体的なアクションについて説明します。
