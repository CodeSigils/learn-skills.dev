Úselo al crear, refactorizar o documentar aplicaciones y servidores proxy de Graft, incluso cuando se le solicite crear un servidor de herramientas, un servidor API, un servidor de protocolo dual o un puente MCP-HTTP. La tesis central de Graft: definir herramientas una vez y servirlas como puntos finales HTTP REST y herramientas MCP desde el mismo servidor, con descubrimiento, documentos y OpenAPI generados automáticamente. Cubre acciones concretas como definir herramientas y controladores, configurar middleware de autenticación, configurar transportes HTTP y stdio, generar documentación OpenAPI, empaquetar API existentes a través del modo proxy y conectar el flujo de trabajo CLI completo.
