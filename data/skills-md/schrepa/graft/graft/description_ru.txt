Используйте при создании, рефакторинге или документировании приложений и прокси-серверов Graft, в том числе при запросе на создание сервера инструментов, сервера API, сервера с двумя протоколами или моста MCP-HTTP. Основной тезис Graft: определить инструменты один раз и использовать их как конечные точки HTTP REST и инструменты MCP с одного и того же сервера, с автоматическим созданием обнаружения, документации и OpenAPI. Охватывает конкретные действия, такие как определение инструментов и обработчиков, настройка промежуточного программного обеспечения для аутентификации, настройка транспорта HTTP и stdio, создание документации OpenAPI, перенос существующих API через режим прокси и подключение полного рабочего процесса CLI.
