قم بإنشاء أفكار الشركات الناشئة وتحسينها والبحث عنها والتحقق من صحتها من خلال آلة أفكار تفاعلية خاصة بالمؤسس. استخدمه عندما يحتاج Codex إلى طرح بعض الأسئلة المركزة، أو البحث في إشارات الويب العامة الحالية، أو تبادل الأفكار سريعًا لبدء التشغيل أو أفكار SaaS، أو التعلم من الحب/ربما/عدم التفاعلات، أو إنتاج جولات أفكار إضافية، أو مقارنة المتأهلين للتصفيات النهائية، أو التحقيق في المنافسين والحلول الحالية، أو تحديد فرصة واعدة، أو إنشاء تقرير Markdown مرتبط بالأدلة حول فكرة بدء التشغيل.
