Analizza una base di codice software per la complessità algoritmica e i punti caldi delle prestazioni, quindi proponi o implementa ottimizzazioni sicure senza interrompere il comportamento. Da utilizzare quando al Codex viene richiesto di scansionare molti file, trovare loop inefficienti, iterazioni nidificate, scansioni ripetute, rendering/ricalcoli costosi, query N+1, operazioni O(n^2) o O(n) evitabili o ridurre la complessità come da O(n^2) a O(n log n) / O(n), preservando test, API, output e manutenibilità.
