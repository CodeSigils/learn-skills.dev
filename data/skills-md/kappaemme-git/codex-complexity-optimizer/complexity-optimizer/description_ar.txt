قم بتحليل قاعدة تعليمات برمجية للبرامج لمعرفة التعقيد الخوارزمي ونقاط الأداء الفعالة، ثم اقترح أو قم بتنفيذ تحسينات آمنة دون انتهاك السلوك. يُستخدم عندما يُطلب من Codex فحص العديد من الملفات، أو العثور على حلقات غير فعالة، أو تكرار متداخل، أو عمليات فحص متكررة، أو عرض/إعادة حساب مكلفة، أو استعلامات N+1، أو عمليات O(n^2) أو O(n) التي يمكن تجنبها، أو تقليل التعقيد مثل O(n^2) إلى O(n log n) / O(n)، مع الحفاظ على الاختبارات وواجهات برمجة التطبيقات والمخرجات وقابلية الصيانة.
