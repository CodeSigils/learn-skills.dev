Laden Sie Bilder als Figurenbett in ein beliebiges GitHub-Repo hoch und erhalten Sie CDN/Markdown-Links (jsdelivr/jsdmirror/raw). Das einmalige setup.sh leitet die GH-Anmeldung, erkennt den Besitzer automatisch, erstellt das Standard-Repo (img.shenzjd.com), falls es fehlt, und synchronisiert die Konfiguration mit der img.shenzjd.com-Web-App über die .imgx-config/config.json des Repos – Hochladen ohne manuelle Konfiguration. Zum Hochladen von Bildern auf GitHub, zum Generieren von CDN-Links, zum Löschen/Auflisten gehosteter Bilder oder zum Einrichten eines Figurenbetts. Schlüsselwörter: Github Figure Bed, Image Host, CDN-Link, jsdelivr, jsdmirror, Bild auf GitHub hochladen, 图床, 上传图片, CDN 链接, 初始化图床.
