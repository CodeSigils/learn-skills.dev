Téléchargez des images sur n'importe quel dépôt GitHub en tant que lit de figures et obtenez des liens CDN/markdown (jsdelivr/jsdmirror/raw). setup.sh unique guide la connexion gh, détecte automatiquement le propriétaire, crée le dépôt par défaut (img.shenzjd.com) s'il est manquant et synchronise la configuration avec l'application Web img.shenzjd.com via le dépôt .imgx-config/config.json - téléchargement sans configuration manuelle. À utiliser pour télécharger des images sur GitHub, générer des liens CDN, supprimer/répertorier des images hébergées ou configurer un lit de figures. Mots-clés : lit de figures github, hôte d'image, lien CDN, jsdelivr, jsdmirror, télécharger une image sur GitHub, 图床, 上传图片, CDN 链接, 初始化图床.
