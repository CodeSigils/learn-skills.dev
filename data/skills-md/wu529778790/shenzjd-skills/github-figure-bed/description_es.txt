Cargue imágenes en cualquier repositorio de GitHub como base de figuras y obtenga enlaces CDN/markdown (jsdelivr/jsdmirror/raw). Un setup.sh único guía el inicio de sesión de gh, detecta automáticamente al propietario, crea el repositorio predeterminado (img.shenzjd.com) si falta y sincroniza la configuración con la aplicación web img.shenzjd.com a través del .imgx-config/config.json del repositorio: carga sin configuración manual. Úselo para cargar imágenes en GitHub, generar enlaces CDN, eliminar/enumerar imágenes alojadas o configurar una base de figuras. Palabras clave: base de figuras de github, host de imágenes, enlace CDN, jsdelivr, jsdmirror, cargar imagen en GitHub, 图床, 上传图片, CDN 链接, 初始化图床.
