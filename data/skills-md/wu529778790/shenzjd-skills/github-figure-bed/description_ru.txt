Загрузите изображения в любой репозиторий GitHub в качестве шаблона и получите ссылки CDN/уценки (jsdelivr/jsdmirror/raw). Одноразовый файл setup.sh направляет вход в систему, автоматически определяет владельца, создает репозиторий по умолчанию (img.shenzjd.com), если он отсутствует, и синхронизирует конфигурацию с веб-приложением img.shenzjd.com через .imgx-config/config.json репозитория — загрузка без ручной настройки. Используйте для загрузки изображений на GitHub, создания ссылок CDN, удаления/перечисления размещенных изображений или настройки фигурной кровати. Ключевые слова: фигурная кровать github, хост изображений, ссылка CDN, jsdelivr, jsdmirror, загрузка изображения на GitHub, 图床, 上传图片, CDN 链接, 初始化图床.
