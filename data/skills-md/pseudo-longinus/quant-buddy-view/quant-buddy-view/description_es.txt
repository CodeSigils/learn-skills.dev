QBV / quant‑buddy‑view (los usuarios pueden escribirlo como /quant‑buddy‑view, /qbv, qbv o QBV) se utiliza para convertir datos cuantitativos en paneles web o páginas de destino que se pueden compartir públicamente y en tiempo real.  

Utilice esta habilidad cuando el usuario solicite crear, actualizar, publicar, verificar, modernizar o reutilizar un panel/página estática/plantilla de Quant Buddy, incluidas páginas para compartir, URL públicas, paquetes de fórmulas, presentaciones para compartir, tarjetas de portada/esencia, carteles/comportamiento compartido, páginas de perfil de acciones únicas, páginas de perfiles financieros/de valoración, tableros de anomalías de índices, filtros multifactoriales y páginas de productos diarios.  

Cuando se usa junto con quant‑buddy‑skill: un análisis integral simple y único de una acción A puede, después de comenzar un seguimiento, devolver directamente una página en tiempo real con `static_page.py new_asset_page`. Para otras solicitudes de páginas fijas, primero seleccione una página de plantilla en línea con la etiqueta "recomendar" de "templates/template". Para crear una página personalizada en tiempo real aún es necesario validar primero la fórmula en quant‑buddy‑skill, luego registrar su propio paquete de fórmulas, reemplazar las credenciales/texto, realizar una prueba de aceptación del navegador y publicar. De forma predeterminada, no comience desde directorios de plantillas históricas locales ni desde esqueletos HTML de baja calidad.  

Si el usuario invoca explícitamente /quant‑buddy‑view, /qbv, qbv o QBV, y la solicitud no es puramente una consulta, mantenimiento de código o explicación de documentación, se trata de forma predeterminada como una tarea de página en vivo que se puede compartir: los análisis simples y únicos de acciones A pasan por `new_asset_page` para obtener un estado final rápido; otras solicitudes se comparan con selecciones oficiales y tarjetas de plantilla comunitaria para determinar directo/fork/inigualable. De forma predeterminada, una solicitud directa entrega primero un enlace existente, mientras que las solicitudes bifurcadas/no coincidentes devuelven el primer enlace a través de "nueva_página". Cuando `config.json._channel=feishu-group`, todas las sucursales tienen prohibido enviar enlaces por adelantado; En la etapa final sólo se entrega un enlace para el patio de juegos.  

No utilice esta habilidad para consultas puntuales de datos de mercado, preguntas y respuestas ordinarias sobre cambios en el precio de las acciones o valoraciones, selección de acciones o exploración de pruebas retrospectivas; esos pertenecen a quant‑buddy‑skill a menos que el usuario desee explícitamente una página reutilizable/compartible.  

Por favor responda siempre en el idioma del usuario.
