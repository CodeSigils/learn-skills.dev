QBV / quant-buddy-view (los usuarios pueden escribirlo como /quant-buddy-view, /qbv, qbv o QBV) se utiliza para convertir datos cuantitativos en páginas web de datos en tiempo real o páginas de inicio de panel que se pueden compartir públicamente.  

Utilice esta habilidad cuando el usuario solicite crear, actualizar, publicar, verificar, modernizar o reutilizar un panel/página estática/plantilla de Quant Buddy, incluidas páginas para compartir, URL públicas, paquetes de fórmulas, carcasas para compartir, tarjetas de portada/esencia, carteles/comportamiento compartido, páginas de perfil de acciones únicas, páginas de perfiles financieros/de valoración, tableros de anomalías de índices, filtros multifactoriales y páginas diarias de productos básicos.  

Para usar junto con quant-buddy-skill: un análisis integral simple de acciones A de una sola acción puede, después de "comenzar el seguimiento", usar directamente "static_page.py new_asset_page" para devolver una página en tiempo real; otras solicitudes de páginas fijas deben seleccionar primero una página de plantilla en línea con una etiqueta "recomendar" de "templates/template". Las páginas autoconstruidas en tiempo real aún deben validar primero las fórmulas en quant-buddy-skill, luego registrar un paquete de fórmulas personalizado, reemplazar las credenciales/texto, realizar pruebas de aceptación del navegador y publicar. De forma predeterminada, no comience desde directorios de plantillas históricas locales ni desde esqueletos HTML de baja calidad.  

Cuando el usuario invoca explícitamente /quant-buddy-view, /qbv, qbv o QBV, y la solicitud no es puramente una consulta/mantenimiento de código/explicación de documentación, se trata de forma predeterminada como una tarea de página en vivo que se puede compartir: el análisis simple de acción A de acción única continúa con `new_asset_page` para un estado final rápido; Para otras solicitudes, consulte las tarjetas de plantilla oficiales curadas y comunitarias para determinar "directo"/"fork"/"incomparable". De forma predeterminada, `direct` entrega primero un enlace listo para usar, mientras que `fork`/`unmatched` usa `new_page` para devolver el enlace inicial; cuando `config.json._channel=feishu-group`, todas las ramas tienen prohibido enviar enlaces por adelantado y solo se entrega un enlace de patio de juegos en el estado final.  

No utilice esta habilidad para consultas puntuales de mercado, preguntas y respuestas ordinarias sobre movimientos de precios de acciones/valoración, selección de acciones/exploración de pruebas retrospectivas; esos pertenecen a quant-buddy-skill a menos que el usuario desee explícitamente una página reutilizable/compartible.  

Por favor responda siempre en el idioma del usuario.
