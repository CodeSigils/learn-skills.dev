QBV / quant‑buddy‑view（使用者可以將其寫入 /quant‑buddy‑view、/qbv、qbv 或 QBV）用於將定量資料轉換為可公開共享的即時 Web 儀表板/登陸頁面。  

當使用者要求建立、更新、發布、驗證、改造或重複使用 Quant Buddy 儀表板/靜態頁面/範本（包括可共享頁面、公共 URL、公式包、共享外殼、封面/精華卡、海報/共享行為、個股概況頁面、估值/財務概況頁面、指數異常板、多因素篩選器和商品每日頁面）時，請使用此技能。  

與 Quant‑buddy‑skill 搭配使用：簡單的單一 A 股綜合分析，在追蹤開始後，可以直接回到一個即時頁面，即 `static_page.py new_asset_page`。对于其他固定页面请求，首先从“templates/template”中选择带有“recommend”标签的在线模板页面。建立自訂即時頁面仍然需要先驗證 quant‑buddy‑skill 中的公式，然後註冊您自己的公式包、替換憑證/文字、執行瀏覽器驗收測試並發布。默认情况下，不要从本地历史模板目录或低质量的 HTML 框架开始。  

如果使用者明確呼叫 /quant‑buddy‑view、/qbv、qbv 或 QBV，且要求不純粹是諮詢、程式碼維護或文件解釋，則預設將其視為可共享的即時頁面任務：簡單的單一 A 股分析透過「new_asset_page」快速取得最終狀態；其他要求將根據官方選擇和社群範本卡進行檢查，以確定直接/分叉/不匹配。默认情况下，直接请求首先传递现有链接，而分叉/不匹配的请求则通过“new_page”返回第一个链接。当`config.json._channel=feishu-group`时，禁止所有分支提前发送链接；最后阶段仅提供游乐场链接。  

請勿將此技能用於一次性市場數據查詢、普通股價變動或估值問答、選股或回測探索；除非用戶明確想要可重複使用/可分享的頁面，否則這些屬於定量好友技能。  

請始終使用使用者的語言進行回覆。
