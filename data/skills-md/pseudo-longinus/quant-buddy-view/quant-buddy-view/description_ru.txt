QBV / quant-buddy-view (пользователи могут писать как /quant-buddy-view, /qbv, qbv или QBV) используется для превращения количественных данных в общедоступную веб-панель/целевую страницу для получения данных в режиме реального времени.  

Используйте этот навык, когда пользователь запрашивает создание, обновление, публикацию, проверку, модификацию или повторное использование информационной панели/статической страницы/шаблона Quant Buddy, включая общедоступные страницы, общедоступные URL-адреса, пакеты формул, оболочку общего доступа, обложки/карточки с сутью, плакат/поведение, страницы профилей отдельных акций, страницы оценочных/финансовых профилей, доски индексных аномалий, многофакторные скрининговые программы и ежедневные страницы товаров.  

Используйте вместе с quant-buddy-skill: простой одиночный комплексный анализ A-share может, после начала трассировки, напрямую использовать static_page.py new_asset_page для возврата страницы в реальном времени; другие запросы с фиксированной страницей должны сначала выбрать страницу онлайн-шаблона с тегом «рекомендовать» из файла «templates/template». Для самостоятельно созданной страницы в реальном времени вам все равно необходимо сначала проверить формулу в quant-buddy-skill, затем зарегистрировать собственный пакет формул, заменить учетные данные/текст, выполнить приемочное тестирование браузера и опубликовать. По умолчанию не начинайте с локальных каталогов исторических шаблонов или низкокачественных HTML-скелетонов.  

Когда пользователь явно вызывает /quant-buddy-view, /qbv, qbv или QBV, и запрос не является чистой консультацией/обслуживанием кода/объяснением документа, он по умолчанию рассматривается как задача совместной работы с живой страницей: простой одиночный анализ A-share проходит через `new_asset_page` для быстрого окончательного состояния; другие запросы проверяют официальные 精选+社区范式卡, чтобы определить `direct`/`fork`/`unmatched`. По умолчанию `direct` сначала доставляет существующую ссылку, а `fork`/`unmatched` использует `new_page` для возврата основной ссылки; когда `config.json._channel=feishu-group`, всем веткам заранее запрещено отправлять ссылки, и в конечном состоянии доставляется только ссылка на игровую площадку.  

Не используйте этот навык для одноразовых запросов рыночных данных, обычного роста/падения акций или вопросов и ответов по оценке, выбора акций/исследований на исторических данных; они относятся к quant-buddy-skill, если только пользователь явно не хочет иметь страницу, которую можно использовать повторно или совместно использовать.  

Пожалуйста, всегда отвечайте на языке пользователя.
