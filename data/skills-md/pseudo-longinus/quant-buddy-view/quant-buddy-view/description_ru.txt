QBV / quant-buddy-view (пользователи могут записать его как /quant-buddy-view, /qbv, qbv или QBV) используется для превращения количественных данных в общедоступные веб-панели/целевые страницы в режиме реального времени.  

Используйте этот навык, когда пользователь запрашивает создание, обновление, публикацию, проверку, модификацию или повторное использование информационной панели/статической страницы/шаблона Quant Buddy, включая общедоступные страницы, общедоступные URL-адреса, пакеты формул, оболочки для обмена, обложки/карточки с сутью, плакаты/поведение, страницы профилей отдельных акций, страницы оценочных/финансовых профилей, доски индексных аномалий, средства многофакторного скрининга и ежедневные страницы по товарам.  

При использовании вместе с quant‑buddy‑skill: простой комплексный анализ с одной долей A может после начала трассировки напрямую возвращать страницу в реальном времени с `static_page.py new_asset_page`. Для других запросов с фиксированной страницей сначала выберите страницу онлайн-шаблона с тегом «рекомендовать» из файла «templates/template». Для создания пользовательской страницы в реальном времени по-прежнему требуется сначала проверить формулу в Quant-Buddy-Skill, затем зарегистрировать собственный пакет формул, заменить учетные данные/текст, выполнить приемочное тестирование браузера и опубликовать. По умолчанию не начинайте с локальных каталогов исторических шаблонов или низкокачественных HTML-скелетонов.  

Если пользователь явно вызывает /quant‑buddy‑view, /qbv, qbv или QBV, и запрос не является просто консультацией, обслуживанием кода или пояснением документации, он по умолчанию рассматривается как общая задача интерактивной страницы: простой, одиночный анализ A-share проходит через `new_asset_page` для быстрого окончательного состояния; другие запросы проверяются на соответствие официальным выборам и карточкам шаблонов сообщества для определения прямых/разветвленных/несовпадающих. По умолчанию прямой запрос сначала доставляет существующую ссылку, а запросы fork/unmatched возвращают первую ссылку через `new_page`. При `config.json._channel=feishu-group` всем веткам заранее запрещается отправлять ссылки; На заключительном этапе доставляется только ссылка на игровую площадку.  

Не используйте этот навык для одноразовых запросов рыночных данных, обычных вопросов и ответов об изменении цен на акции или их оценке, выборе акций или исследовании исторических данных; они относятся к Quant-Buddy-Skill, если только пользователь явно не хочет иметь страницу, которую можно использовать повторно или совместно использовать.  

Пожалуйста, всегда отвечайте на языке пользователя.
