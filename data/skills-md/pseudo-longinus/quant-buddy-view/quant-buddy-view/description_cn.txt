QBV / quant-buddy-view（用户可以将其写为 /quant-buddy-view、/qbv、qbv 或 QBV）用于将定量数据转换为可公开共享、实时数据可检索的 Web 仪表板/登陆页面。  
当用户要求创建、更新、发布、验证、改造或重用 Quant Buddy 仪表板/静态页面/模板（包括可共享页面、公共 URL、公式包、共享外壳、封面/精华卡、海报/共享行为、个股概况页面、估值/财务概况页面、指数异常板、多因素筛选器和商品每日页面）时，请使用此技能。  
与quant-buddy-skill配合使用：简单的单A股综合分析，在trace开始后，可以直接使用static_page.py new_asset_page返回实时页面；其他对固定页面的请求应首先从 templates/template 中选择带有“推荐”标签的在线模板页面。对于自建的实时页面，您仍然需要先验证 quant-buddy-skill 中的公式，然后注册自己的公式包，替换凭据/文本，进行浏览器验收测试并发布。默认情况下，不要从本地历史示例目录或低质量的 HTML 框架开始。  
当用户显式调用 /quant-buddy-view、/qbv、qbv 或 QBV，并且请求不是纯粹的咨询/代码维护/文档解释时，默认情况下将其视为可共享的实时页面任务：简单的单个 A 股分析会通过 new_asset_page 快速获得最终状态；其他请求请查阅官方精选+社区模板卡以确定直接/分叉/不匹配。默认情况下，direct 首先传递现有链接，而 fork/unmatched 通过 new_page 返回第一个链接；当config.json._channel=feishu-group时，禁止所有分支提前发送链接，最后阶段只发送playground链接。  
请勿将此技能用于一次性行情数据查询、普通股价变动/估值问答、选股/回测探索等；除非用户明确想要可重用/可共享的页面，否则这些属于 quant-buddy-skill。  
请始终使用用户的语言进行回复。
