QBV / quant‑buddy‑view（用户可以将其写为 /quant‑buddy‑view、/qbv、qbv 或 QBV）用于将定量数据转换为可公开共享的实时 Web 仪表板/登陆页面。  

当用户要求创建、更新、发布、验证、改造或重用 Quant Buddy 仪表板/静态页面/模板（包括可共享页面、公共 URL、公式包、共享外壳、封面/精华卡、海报/共享行为、个股概况页面、估值/财务概况页面、指数异常板、多因素筛选器和商品每日页面）时，请使用此技能。  

与 Quant‑buddy‑skill 配合使用：简单的单一 A 股综合分析，在追踪开始后，可以直接返回一个实时页面，即 `static_page.py new_asset_page`。对于其他固定页面请求，首先从“templates/template”中选择带有“recommend”标签的在线模板页面。构建自定义实时页面仍然需要首先验证 quant‑buddy‑skill 中的公式，然后注册您自己的公式包、替换凭据/文本、执行浏览器验收测试并发布。默认情况下，不要从本地历史模板目录或低质量的 HTML 框架开始。  

如果用户明确调用 /quant‑buddy‑view、/qbv、qbv 或 QBV，并且请求不纯粹是咨询、代码维护或文档解释，则默认情况下将其视为可共享的实时页面任务：简单的单个 A 股分析通过“new_asset_page”快速获得最终状态；其他请求将根据官方选择和社区模板卡进行检查，以确定直接/分叉/不匹配。默认情况下，直接请求首先传递现有链接，而分叉/不匹配的请求则通过“new_page”返回第一个链接。当`config.json._channel=feishu-group`时，禁止所有分支提前发送链接；最后阶段仅提供游乐场链接。  

请勿将此技能用于一次性市场数据查询、普通股价变动或估值问答、选股或回测探索；除非用户明确想要可重用/可共享的页面，否则这些属于定量好友技能。  

请始终使用用户的语言进行回复。
