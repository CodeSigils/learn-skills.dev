QBV / 퀀트버디뷰(사용자는 /퀀트버디뷰, /qbv, qbv 또는 QBV로 작성할 수 있음)는 정량적 데이터를 공개적으로 공유할 수 있는 실시간 웹 대시보드/랜딩 페이지로 전환하는 데 사용됩니다.  

사용자가 공유 가능한 페이지, 공개 URL, 포뮬러 패키지, 공유 쉘, 커버/에센스 카드, 포스터/공유 동작, 단일 주식 프로필 페이지, 평가/재무 프로필 페이지, 지수 변칙 보드, 다단계 스크리너 및 상품 일일 페이지를 포함하여 Quant Buddy 대시보드/정적 페이지/템플릿을 생성, 업데이트, 게시, 확인, 개조 또는 재사용하도록 요청할 때 이 기술을 사용합니다.  

퀀트 버디 스킬과 함께 사용하면 간단한 단일 A 공유 종합 분석으로 추적이 시작된 후 `static_page.py new_asset_page`를 사용하여 실시간 페이지를 직접 반환할 수 있습니다. 다른 고정 페이지 요청의 경우 먼저 `templates/template`에서 `recommend` 태그가 있는 온라인 템플릿 페이지를 선택하세요. 사용자 정의 실시간 페이지를 구축하려면 먼저 퀀트 버디 스킬에서 공식을 검증한 다음 자체 공식 패키지를 등록하고, 자격 증명/텍스트를 교체하고, 브라우저 승인 테스트를 수행하고 게시해야 합니다. 기본적으로 로컬 기록 템플릿 디렉터리나 품질이 낮은 HTML 뼈대에서 시작하지 마세요.  

사용자가 명시적으로 /Quant‑buddy‑view, /qbv, qbv 또는 QBV를 호출하고 요청이 순전히 상담, 코드 유지 관리 또는 문서 설명이 아닌 경우 이는 기본적으로 공유 가능한 라이브 페이지 작업으로 처리됩니다. 간단한 단일 A 공유 분석은 빠른 최종 상태를 위해 `new_asset_page`를 거칩니다. 다른 요청은 공식 선택 및 커뮤니티 템플릿 카드와 비교하여 직접/포크/불일치 여부를 결정합니다. 기본적으로 직접 요청은 기존 링크를 먼저 전달하는 반면, 포크/일치하지 않는 요청은 `new_page`를 통해 첫 번째 링크를 반환합니다. `config.json._channel=feishu-group`인 경우 모든 지점에서 사전에 링크를 보낼 수 없습니다. 마지막 단계에서는 플레이그라운드 링크만 전달됩니다.  

일회성 시장 데이터 쿼리, 일반적인 주가 변동 또는 평가 Q&A, 주식 선정 또는 백테스트 탐색에는 이 기술을 사용하지 마십시오. 사용자가 재사용/공유 가능한 페이지를 명시적으로 원하지 않는 한 이는 퀀트 버디 스킬에 속합니다.  

항상 사용자의 언어로 응답하시기 바랍니다.
