QBV / quant‑buddy‑view (users may write it as /quant‑buddy‑view, /qbv, qbv, or QBV) is used to turn quantitative data into publicly shareable, real‑time web dashboards/landing pages.  

Use this skill when the user asks to create, update, publish, verify, retrofit, or reuse a Quant Buddy dashboard/static page/template, including shareable pages, public URLs, formula packages, share shells, cover/essence cards, poster/share behavior, single‑stock profile pages, valuation/financial profile pages, index‑anomaly boards, multi‑factor screeners, and commodity‑daily pages.  

When used together with quant‑buddy‑skill: a simple, single A‑share comprehensive analysis can, after a trace begin, directly return a real‑time page with `static_page.py new_asset_page`. For other fixed‑page requests, first select an online template page with the `recommend` tag from `templates/template`. Building a custom real‑time page still requires first validating the formula in quant‑buddy‑skill, then registering your own formula package, replacing credentials/text, performing a browser acceptance test, and publishing. By default, do not start from local historical template directories or low‑quality HTML skeletons.  

If the user explicitly invokes /quant‑buddy‑view, /qbv, qbv, or QBV, and the request is not purely a consultation, code maintenance, or documentation explanation, it is by default treated as a shareable live‑page task: simple, single A‑share analyses go through `new_asset_page` for a quick final state; other requests are checked against official selections and community template cards to determine direct/fork/unmatched. By default, a direct request delivers an existing link first, while fork/unmatched requests return the first link via `new_page`. When `config.json._channel=feishu-group`, all branches are prohibited from sending links in advance; only a playground link is delivered at the final stage.  

Do not use this skill for one‑off market data queries, ordinary stock price‑change or valuation Q&A, stock‑picking or back‑testing exploration; those belong to quant‑buddy‑skill unless the user explicitly wants a reusable/shareable page.  

Please always respond in the user's language.
