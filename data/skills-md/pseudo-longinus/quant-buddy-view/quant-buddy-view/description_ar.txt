يتم استخدام QBV / quant-buddy-view (يمكن للمستخدمين كتابته كـ /quant-buddy-view أو /qbv أو qbv أو QBV) لتحويل البيانات الكمية إلى لوحات تحكم ويب/صفحات مقصودة قابلة للمشاركة بشكل عام وفي الوقت الفعلي.  

استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تحديث أو نشر أو التحقق من أو تعديل أو إعادة استخدام لوحة معلومات/صفحة ثابتة/قالب Quant Buddy، بما في ذلك الصفحات القابلة للمشاركة، وعناوين URL العامة، وحزم الصيغة، وأغلفة المشاركة، وبطاقات الغلاف/الجوهر، وسلوك الملصق/المشاركة، وصفحات الملف الشخصي للأسهم الفردية، وصفحات التقييم/الملف الشخصي المالي، ولوحات شذوذ الفهرس، وأجهزة الغربلة متعددة العوامل، وصفحات السلع اليومية.  

عند استخدامه مع المهارة الكمية: يمكن للتحليل الشامل البسيط لمشاركة A، بعد بدء التتبع، إرجاع صفحة في الوقت الفعلي مباشرة باستخدام `static_page.py new_asset_page`. بالنسبة لطلبات الصفحات الثابتة الأخرى، حدد أولاً صفحة قالب عبر الإنترنت تحمل علامة "recommend" من "templates/template". لا يزال إنشاء صفحة مخصصة في الوقت الفعلي يتطلب أولاً التحقق من صحة الصيغة في المهارة الكمية، ثم تسجيل حزمة الصيغة الخاصة بك، واستبدال بيانات الاعتماد/النص، وإجراء اختبار قبول المتصفح، والنشر. افتراضيًا، لا تبدأ من أدلة القوالب التاريخية المحلية أو هياكل HTML منخفضة الجودة.  

إذا قام المستخدم باستدعاء عرض /quant‑buddy‑view، أو /qbv، أو qbv، أو QBV بشكل صريح، ولم يكن الطلب مجرد استشارة أو صيانة تعليمات برمجية أو شرح توثيق، فسيتم التعامل معه افتراضيًا على أنه مهمة صفحة مباشرة قابلة للمشاركة: تمر تحليلات A-share البسيطة والمفردة عبر "new_asset_page" للحصول على حالة نهائية سريعة؛ ويتم فحص الطلبات الأخرى مقابل الاختيارات الرسمية وبطاقات قوالب المجتمع لتحديد المباشر/المفترق/غير المطابق. افتراضيًا، يقوم الطلب المباشر بتسليم رابط موجود أولاً، بينما تقوم الطلبات المتفرعة/غير المتطابقة بإرجاع الرابط الأول عبر `new_page`. عندما يكون `config.json._channel=feishu-group`، يُمنع على جميع الفروع إرسال الروابط مسبقًا؛ يتم تسليم رابط الملعب فقط في المرحلة النهائية.  

لا تستخدم هذه المهارة للاستعلامات الخاصة ببيانات السوق لمرة واحدة، أو تغير أسعار الأسهم العادية أو أسئلة وأجوبة التقييم، أو انتقاء الأسهم أو استكشاف الاختبار العكسي؛ تنتمي هذه إلى المهارات الكمية ما لم يرغب المستخدم صراحةً في الحصول على صفحة قابلة لإعادة الاستخدام/المشاركة.  

يرجى الرد دائمًا بلغة المستخدم.
