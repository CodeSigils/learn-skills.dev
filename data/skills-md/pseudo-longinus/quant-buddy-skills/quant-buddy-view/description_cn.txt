QBV / quant-buddy-view（用户可以将其写为 /quant-buddy-view、/qbv、qbv 或 QBV）用于将定量数据转换为公共、可共享、实时的网络仪表板/登陆页面。

当用户要求创建、更新、发布、验证、改造或重用 Quant Buddy 仪表板/静态页面/模板（包括可共享页面、公共 URL、公式包、共享外壳、封面/精华卡、海报/共享行为、个股概况页面、估值/财务概况页面、指数异常板、多因素筛选器和商品每日页面）时，请使用此技能。

与 quant-buddy-skill 配合使用：简单的单个 A 股综合分析，在 `trace begin` 之后，直接使用 `static_page.py new_asset_page` 返回实时页面；如果用户提供现有的 QuantBuddy 实时页面 URL 并要求解释，则直接使用 static_page.py Interpret 读取页面的实时数据，无需下载 HTML、暴露签名或进入模板或页面创建工作流程；其他固定页面请求应首先通过“templates/template”选择带有“推荐”标签的在线模板页面。构建自定义实时页面，首先根据数据性质选择渠道：普通市场数据、估值、财务数据默认为Data Grant，而自定义计算必须经过验证并注册为公式包；可以在同一页面上混合两种类型的凭据，然后替换凭据/文本、执行浏览器验收测试并发布。默认情况下，不要从本地历史示例目录或低质量的 HTML 框架开始。

当用户显式调用 /quant-buddy-view、/qbv、qbv 或 QBV，并且请求不纯粹是咨询/代码维护/文档说明时，默认情况下将其视为可共享的实时页面任务：通过“new_asset_page”进行简单的单个 A 股分析，以快速获得最终状态；其他请求将根据官方选择和社区模板卡进行检查，以确定“直接”/“分叉”/“不匹配”。默认情况下，“direct”首先传递现有链接，而“fork”/“unmatched”使用“new_page”返回第一个链接；当`config.json._channel=feishu-group`时，所有分支禁止提前发送链接，仅在最后阶段发送playground链接。

请勿将此技能用于一次性行情查询、普通股价变动/估值问答、选股/回测探索等；除非用户明确想要可重用/可共享的页面，否则这些属于 quant-buddy-skill。
