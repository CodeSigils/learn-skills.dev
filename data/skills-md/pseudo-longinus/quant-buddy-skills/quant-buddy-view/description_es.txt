QBV / quant-buddy-view (los usuarios pueden escribirlo como /quant-buddy-view, /qbv, qbv o QBV) se utiliza para convertir datos cuantitativos en una página de inicio/panel de control web “que se puede compartir públicamente y recuperar datos en tiempo real”.  

Utilice esta habilidad siempre que el usuario solicite crear, actualizar, publicar, verificar, modernizar o reutilizar un panel/página estática/plantilla de Quant Buddy, incluidas páginas para compartir, URL públicas, paquetes de fórmulas, presentaciones para compartir, tarjetas de portada/esencia, carteles/comportamiento compartido, páginas de perfil de acciones únicas, páginas de perfiles financieros/de valoración, tableros de anomalías de índices, filtros multifactoriales y páginas diarias de productos básicos.  

Cuando se trabaja en conjunto con quant‑buddy‑skill: un análisis integral simple de una sola acción A puede, después de `trace start`, devolverse como una página en tiempo real directamente con `static_page.py new_asset_page`; si el usuario proporciona una URL de página en vivo de QuantBuddy existente y solicita interpretación, use `static_page.py interpret` para leer los datos en tiempo real de la página sin descargar HTML, exponer firmas o ingresar al flujo de trabajo de creación de plantillas o páginas; otras solicitudes de páginas fijas deben seleccionar primero una página de plantilla en línea marcada con la etiqueta "recomendar" a través de "templates/template". Para las páginas en tiempo real creadas por usted mismo, primero elija el canal según el tipo de datos: los datos ordinarios del mercado, la valoración y los datos financieros dan prioridad a una concesión de datos; Los cálculos personalizados deben validarse y registrarse como un paquete de fórmulas. Ambos tipos de credenciales se pueden combinar en la misma página, después de lo cual se reemplazan las credenciales/texto, se realizan pruebas de aceptación del navegador y se publica. De forma predeterminada, no comience desde directorios de muestras históricos locales ni desde esqueletos HTML de baja calidad.  

Si el usuario invoca explícitamente /quant‑buddy‑view, /qbv, qbv o QBV y la solicitud no es pura consulta/mantenimiento de código/explicación de documentación, trátela como una tarea de página en vivo que se puede compartir de forma predeterminada: un análisis simple de acciones A de una sola acción continúa con `new_asset_page` para obtener un resultado final rápido; otras solicitudes se comparan con tarjetas de plantilla comunitaria y seleccionadas oficiales para determinar "directo"/"fork"/"incomparable". De forma predeterminada, `direct` entrega primero un enlace existente, mientras que `fork`/`unmatched` devuelve el primer enlace a través de `new_page`. Cuando `config.json._channel=feishu-group`, todas las ramas tienen prohibido enviar enlaces prematuramente; Los enlaces se entregan sólo en la etapa final como un enlace de patio de recreo.  

No utilice esta habilidad para consultas de mercado únicas, preguntas y respuestas ordinarias sobre cambios de precios/valoraciones de acciones, selección de acciones/exploración de pruebas retrospectivas; esos pertenecen a quant‑buddy‑skill a menos que el usuario desee explícitamente una página reutilizable/compartible.
