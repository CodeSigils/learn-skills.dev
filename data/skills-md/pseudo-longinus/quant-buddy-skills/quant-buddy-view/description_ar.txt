يتم استخدام QBV / quant-buddy-view (يمكن للمستخدمين كتابته كـ /quant-buddy-view أو /qbv أو qbv أو QBV) لتحويل البيانات الكمية إلى لوحة تحكم / صفحة مقصودة على الويب "قابلة للمشاركة بشكل عام وفي الوقت الفعلي".  

استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تحديث أو نشر أو التحقق من أو تعديل أو إعادة استخدام لوحة معلومات/صفحة ثابتة/قالب Quant Buddy، بما في ذلك الصفحات القابلة للمشاركة، وعناوين URL العامة، وحزم الصيغة، وأغلفة المشاركة، وبطاقات الغلاف/الجوهر، وسلوك الملصق/المشاركة، وصفحات الملف الشخصي للأسهم الفردية، وصفحات التقييم/الملف الشخصي المالي، ولوحات شذوذ الفهرس، وأجهزة الغربلة متعددة العوامل، وصفحات السلع اليومية.  

عند العمل جنبًا إلى جنب مع المهارة الكمية: يمكن إرجاع التحليل الشامل البسيط لسهم A، بعد "بدء التتبع"، كصفحة في الوقت الفعلي مباشرةً باستخدام "static_page.py new_asset_page"؛ إذا قام المستخدم بتوفير عنوان URL موجود للصفحة المباشرة لـ QuantBuddy وطلب تفسيرًا، فاستخدم "static_page.py Interpret" لقراءة بيانات الصفحة في الوقت الفعلي دون تنزيل HTML أو الكشف عن التوقيعات أو الدخول في سير عمل القوالب أو بناء الصفحة؛ يجب أن تحدد طلبات الصفحة الثابتة الأخرى أولاً صفحة قالب عبر الإنترنت تحمل علامة "التوصية" عبر "القوالب/القالب". بالنسبة لصفحات الوقت الفعلي المنشأة ذاتيًا، اختر أولاً القناة وفقًا لنوع البيانات: تعطي بيانات السوق العادية والتقييم والبيانات المالية الأولوية لمنحة البيانات؛ يجب التحقق من صحة الحسابات المخصصة وتسجيلها كحزمة صيغة. يمكن خلط كلا النوعين من بيانات الاعتماد في نفس الصفحة، وبعد ذلك يمكنك استبدال بيانات الاعتماد/النص وإجراء اختبار قبول المتصفح والنشر. افتراضيًا، لا تبدأ من نماذج الدلائل التاريخية المحلية أو هياكل HTML منخفضة الجودة.  

إذا قام المستخدم باستدعاء عرض /quant‑buddy‑view أو /qbv أو qbv أو QBV بشكل صريح ولم يكن الطلب عبارة عن استشارة خالصة/صيانة التعليمات البرمجية/شرح التوثيق، فتعامل معه كمهمة صفحة مباشرة قابلة للمشاركة افتراضيًا: يستمر تحليل سهم A بسيط ومخزون واحد مع "new_asset_page" للحصول على نتيجة نهائية سريعة؛ ويتم فحص الطلبات الأخرى مقابل بطاقات قوالب المجتمع الرسمية المنسقة لتحديد "مباشر"/"مفترق"/"غير مطابق". افتراضيًا، يعرض `direct` الرابط الموجود أولاً، بينما يعرض `fork`/`unmatched` الرابط الأول عبر `new_page`. عندما يكون `config.json._channel=feishu-group`، يُمنع على جميع الفروع إرسال الروابط قبل الأوان؛ يتم تسليم الروابط فقط في المرحلة النهائية كرابط للملعب.  

لا تستخدم هذه المهارة لاستفسارات السوق لمرة واحدة، والأسئلة والأجوبة المتعلقة بتغير/تقييم أسعار الأسهم العادية، واختيار الأسهم/استكشاف الاختبار العكسي؛ تنتمي هذه إلى المهارات الكمية ما لم يرغب المستخدم صراحةً في الحصول على صفحة قابلة لإعادة الاستخدام/المشاركة.
