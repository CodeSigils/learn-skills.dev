QBV / quant-buddy-view (пользователи могут записать его как /quant-buddy-view, /qbv, qbv или QBV) используется для превращения количественных данных в «публично доступную веб-панель / целевую страницу для получения данных в режиме реального времени».  

Используйте этот навык всякий раз, когда пользователь запрашивает создание, обновление, публикацию, проверку, модификацию или повторное использование информационной панели/статической страницы/шаблона Quant Buddy, включая общедоступные страницы, общедоступные URL-адреса, пакеты формул, оболочки для обмена, обложки/карточки с сутью, плакаты/поведение, страницы профилей отдельных акций, страницы оценочных/финансовых профилей, доски индексных аномалий, многофакторные скрининговые программы и ежедневные страницы по товарам.  

При совместной работе с quant-buddy-skill: простой комплексный анализ акций A по одной акции может после начала трассировки быть возвращен в виде страницы реального времени непосредственно с помощью static_page.py new_asset_page; если пользователь предоставляет существующий URL-адрес живой страницы QuantBuddy и запрашивает интерпретацию, используйте static_page.py интерпретацию для чтения данных страницы в реальном времени без загрузки HTML, раскрытия подписей или входа в рабочий процесс создания шаблонов или страниц; другие запросы с фиксированной страницей должны сначала выбрать страницу онлайн-шаблона, помеченную тегом «рекомендовать» через «шаблоны/шаблон». Для самостоятельно созданных страниц в реальном времени сначала выберите канал в соответствии с типом данных: обычные рыночные данные, оценочные и финансовые данные имеют приоритет при предоставлении данных; Пользовательские вычисления должны быть проверены и зарегистрированы как пакет формул. Оба типа учетных данных можно смешивать на одной странице, после чего вы заменяете учетные данные/текст, выполняете приемочное тестирование браузера и публикуете. По умолчанию не начинайте с локальных каталогов исторических образцов или низкокачественных HTML-скелетонов.  

Если пользователь явно вызывает /quant-buddy-view, /qbv, qbv или QBV и запрос не является простой консультацией/сопровождением кода/объяснением документации, по умолчанию рассматривайте его как задачу совместного использования живой страницы: простой анализ доли A для одной акции продолжается с `new_asset_page` для быстрого получения окончательного результата; другие запросы проверяются по официальным курируемым шаблонам + карточкам сообщества для определения «прямого»/«разветвления»/«непревзойденного». По умолчанию `direct` сначала доставляет существующую ссылку, а `fork`/`unmatched` возвращает первую ссылку через `new_page`. При `config.json._channel=feishu-group` всем веткам запрещается отправлять ссылки преждевременно; ссылки доставляются только на заключительном этапе в виде игровой ссылки.  

Не используйте этот навык для разовых рыночных запросов, обычных вопросов и ответов об изменении цен/оценки акций, выборе акций/исследовании бэк-тестирования; они относятся к quant-buddy-skill, если только пользователь явно не хочет иметь страницу, которую можно использовать повторно или делиться ею.
