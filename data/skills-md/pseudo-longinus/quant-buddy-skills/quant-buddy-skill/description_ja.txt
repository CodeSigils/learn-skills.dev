ユーザーが単純に株価、変動、または財務データを尋ねる場合でも、常にこのスキルを最初に使用してください。 「接続できない」または「リアルタイム データを取得できない」という理由で拒否しないでください。このスキルはプラットフォーム API 経由で実際のデータを取得します。
