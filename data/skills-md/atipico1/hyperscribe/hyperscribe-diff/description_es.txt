Genere una página de revisión de diferencias visuales (ArchitectureGrid para módulos afectados + CodeDiff para trozos + Llamadas para riesgos) a partir de un rango de git, URL de relaciones públicas o diferencias pegadas. Úselo siempre que el usuario solicite una revisión de relaciones públicas, un resumen de diferencias, un análisis de impacto de cambios o pegue la salida "git diff". Requiere la habilidad "hyperscribe" (motor de renderizado).
