قم بإنشاء صفحة مراجعة الفرق المرئية (ArchitectureGrid للوحدات المتأثرة + CodeDiff للكتل + وسائل شرح للمخاطر) من نطاق git، أو عنوان URL للعلاقات العامة، أو الفرق الملصق. يُستخدم عندما يطلب المستخدم مراجعة العلاقات العامة، أو ملخص الفرق، أو تحليل تأثير التغيير، أو لصق مخرجات git diff. يتطلب مهارة "الكتابة المفرطة" (محرك العارض).
