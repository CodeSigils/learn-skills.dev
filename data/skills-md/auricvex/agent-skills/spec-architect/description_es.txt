Le brinda competencia de nivel maestro para obtener requisitos de un usuario y redactar un documento de especificación riguroso, inequívoco y listo para implementar. Utilice esta habilidad siempre que un usuario le solicite "diseñar", "especificar", "especificar", "documentar los requisitos" o "escribir una especificación para" cualquier sistema, protocolo, característica o proceso, incluso si no dice explícitamente "especificación". El resultado es un documento estructurado del que dos agentes diferentes deben producir de forma independiente versiones materialmente equivalentes. NO utilice esta habilidad para la generación, implementación o refactorización de código, solo para el documento de especificación en sí.
