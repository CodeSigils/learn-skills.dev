Vous donne une compétence de niveau master pour obtenir les exigences d'un utilisateur et rédiger un document de spécification rigoureux, sans ambiguïté et prêt à être mis en œuvre. Utilisez cette compétence chaque fois qu'un utilisateur vous demande de "concevoir", "spécifier", "spécifier", "documenter les exigences" ou "écrire une spécification pour" un système, un protocole, une fonctionnalité ou un processus, même s'il ne dit pas explicitement "spécification". Le résultat est un document structuré dont deux agents différents doivent produire indépendamment des versions matériellement équivalentes. N'utilisez PAS cette compétence pour la génération, l'implémentation ou la refactorisation de code – uniquement pour le document de spécification lui-même.
