Создавайте изображения с помощью API Pollinations.ai. Поддерживает такие модели, как Flux, Zimage, Imagen-4, Klein, Klein-Large, gptimage (бесплатно) и Seedream, kontext, nanobanana, gptimage-large (платно). Используйте, когда пользователь просит сгенерировать, создать или нарисовать изображения из текстовых подсказок.
