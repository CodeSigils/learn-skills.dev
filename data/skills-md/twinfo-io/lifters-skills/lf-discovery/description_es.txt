Descubrimiento interactivo de funciones para equipos de desarrollo de productos. Lleva a cabo una entrevista estructurada de 7 fases: recopila documentos de referencia (URL o contenido pegado), extrae el contexto de las entradas, determina áreas nuevas y antiguas, ejecuta preguntas específicas sobre brechas, investiga puntos de referencia del mercado a través de búsquedas web y genera un artefacto discover.md. Úselo al iniciar una nueva función, planificar una iniciativa de producto o cuando el usuario ejecuta /lf-discovery.
