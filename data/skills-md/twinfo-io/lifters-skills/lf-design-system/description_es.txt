Se conecta a Figma a través del servidor MCP, extrae tipografía, colores, espaciado, radio de borde, sombras y todas las definiciones de tokens de diseño, y genera specs/design-system.md, la fuente oficial del sistema de diseño para el proyecto. Solicita el nombre del sistema de diseño y la URL de Figma si no se proporcionan como argumentos. Úselo cuando el usuario ejecuta /lf-design-system o desea crear o actualizar el sistema de diseño del proyecto desde Figma.
