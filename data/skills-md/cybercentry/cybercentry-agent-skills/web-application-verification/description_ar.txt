استخدم هذه المهارة عندما تحتاج إلى فحص أمني لمواقع الويب أو التطبيقات اللامركزية. حالات المستخدم: العثور على ثغرات XSS، أو تحديد واجهات برمجة التطبيقات غير الآمنة، أو تقييم أمان الواجهة الأمامية، أو تقييم ثغرات تطبيقات الويب، أو تأمين واجهات dApp الأمامية، أو إجراء فحوصات امتثال OWASP على واجهات الويب.
