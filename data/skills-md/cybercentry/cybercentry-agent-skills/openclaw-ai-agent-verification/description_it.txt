Utilizza questa competenza quando devi controllare le configurazioni dell'agente OpenClaw AI per individuare eventuali rischi per la sicurezza. Casi utente: convalida dell'accesso allo strumento dell'agente, controllo delle autorizzazioni dell'agente, valutazione della sicurezza dei messaggi dell'agente, revisione delle competenze dell'agente, controllo del gate degli agenti prima della distribuzione, rilevamento delle vulnerabilità del prompt injection o valutazione della sicurezza dell'orchestrazione dell'agente.
