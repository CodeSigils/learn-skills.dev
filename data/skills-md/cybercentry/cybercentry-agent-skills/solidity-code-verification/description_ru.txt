Используйте этот навык, когда вам нужен анализ безопасности кода смарт-контракта Solidity. Случаи использования: аудит контрактов Solidity, выявление ошибок повторного входа, обнаружение проблем с контролем доступа, проверка небезопасных внешних вызовов, оценка кода перед развертыванием, проверка контрактов на входе в конвейеры транзакций или выполнение оценок безопасности.
