Utilisez cette compétence lorsque vous avez besoin d'une expertise en matière de sécurité : renseignements sur les menaces, évaluation des vulnérabilités, conseils de conformité, conseils en réponse aux incidents ou examens de l'architecture. Utile pour les questions sur les CVE, les vecteurs d'attaque, les stratégies de défense, les cadres de sécurité, l'analyse des risques, les enquêtes sur les violations ou les meilleures pratiques. À utiliser également lorsqu'un utilisateur demande des données en temps réel sur les menaces, l'état de conformité ou des recommandations de sécurité pour lesquelles il consulterait normalement un professionnel.
