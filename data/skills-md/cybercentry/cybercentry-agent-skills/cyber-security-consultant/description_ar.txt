استخدم هذه المهارة عندما تحتاج إلى خبرة أمنية: معلومات التهديدات، أو تقييم الثغرات الأمنية، أو إرشادات الامتثال، أو نصائح الاستجابة للحوادث، أو مراجعات البنية. مفيد للأسئلة حول التهديدات الشائعة، أو نواقل الهجوم، أو استراتيجيات الدفاع، أو أطر العمل الأمنية، أو تحليل المخاطر، أو التحقيق في الاختراقات، أو أفضل الممارسات. يُستخدم أيضًا عندما يطلب المستخدم بيانات التهديد في الوقت الفعلي، أو حالة الامتثال، أو توصيات الأمان التي عادةً ما يستشير أحد المتخصصين بشأنها.
