افتح أو قم بإرجاع صفحات مشروع Logfire والعروض المباشرة وروابط التتبع واستكشاف الصفحات في متصفح Codex دون الاستعلام عن القياس عن بعد أولاً. استخدم هذه المهارة عندما يطلب المستخدم "الفتح في Logfire"، أو "العرض في العرض المباشر"، أو "فتح الاستكشاف"، أو "فتح واجهة المستخدم"، أو "العرض في Codex"، أو "استخدام المتصفح"، أو "إعطائي رابطًا"، أو يطلب عرضًا تقديميًا لواجهة المستخدم الرسومية/المتصفح/العرض المباشر لـ Logfire لمشروع أو نطاق زمني أو خدمة أو نطاق أو تتبع أو سجل أو عامل تصفية. إذا كانت صياغة "إظهار" أو "عرض" غامضة، فاسأل عما إذا كان المستخدم يريد عرض واجهة المستخدم أو تحليل الاستعلام.
