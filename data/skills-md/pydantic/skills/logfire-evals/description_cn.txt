使用 pydantic_evals 根据测试用例数据集评估 Python AI/代理代码，并在 Logfire 的数据集和实验 UI 中查看结果。还包括将现有 Braintrust Eval() 套件重定向到 Logfire，无需更改代码。每当用户要求“设置评估”、“添加评估”、“根据案例测试我的代理”、“编写测试用例数据集”、“对我的 LLM 输出进行评分”、“添加 LLM 法官”、“检查工具调用正确性”、“将 Braintrust 评估发送到 Logfire”、“从 Braintrust 迁移”，或提及 pydantic_evals、Braintrust、数据集和实验，或根据已知的 AI/代理行为评估时，请使用此技能输入。 `pydantic_evals` 工作流程仅适用于 Python； Braintrust 重定向还支持 TypeScript 套件、仅 env-vars。两者都是为了离线对定义的测试用例进行评分，而不是用于检测实时生产流量（使用“logfire-instrumentation”），也不用于基础设施监控（使用“logfire-infrastruction”）。
