pydantic_evals を使用してテスト ケースのデータセットに対して Python AI/エージェント コードを評価し、Logfire のデータセットと実験 UI で結果を確認します。また、コードを変更せずに既存の Braintrust Eval() スイートを Logfire にリダイレクトする方法についても説明します。ユーザーが「評価を設定する」、「評価を追加する」、「エージェントをケースに対してテストする」、「テスト ケースのデータセットを作成する」、「LLM 出力をスコアリングする」、「LLM ジャッジを追加する」、「ツール呼び出しの正確性をチェックする」、「Braintrust の評価を Logfire に送信する」、「Braintrust から移行する」を要求するとき、または pydantic_evals、Braintrust、データセットと実験、または評価に言及するときは必ずこのスキルを使用します。既知の入力に対する AI/エージェントの動作。 「pydantic_evals」ワークフローは Python のみです。 Braintrust リダイレクトは、TypeScript スイート (env-vars のみ) もサポートします。どちらも定義済みのテスト ケースをオフラインでスコアリングするためのものであり、ライブ運用トラフィックの計測 (その場合は「logfire-instrumentation」を使用) やインフラストラクチャの監視 (「logfire-infrastruction」を使用) ではありません。
