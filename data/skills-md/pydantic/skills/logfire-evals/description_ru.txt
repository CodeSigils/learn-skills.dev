Оцените код ИИ/агента Python на основе набора данных тестовых случаев с помощью pydantic_evals и просмотрите результаты в пользовательском интерфейсе наборов данных и экспериментов Logfire. Также рассматривается перенаправление существующего пакета Braintrust Eval() на Logfire без изменения кода. Используйте этот навык всякий раз, когда пользователь просит «настроить оценки», «добавить оценку», «проверить моего агента на соответствие случаям», «написать набор данных тестовых случаев», «оценить мои результаты LLM», «добавить судью LLM», «проверить правильность вызова инструмента», «отправить оценки Braintrust в Logfire», «мигрировать из Braintrust» или упоминает pydantic_evals, Braintrust, Datasets & Experiments или оценивает поведение ИИ/агента на основе известных входных данных. Рабочий процесс `pydantic_evals` предназначен только для Python; перенаправление Braintrust также поддерживает наборы TypeScript, только env-vars. Оба предназначены для оценки ОПРЕДЕЛЕННЫХ тестовых случаев в автономном режиме, а не для инструментирования реального производственного трафика (используйте для этого logfire-instrumentation) и не для мониторинга инфраструктуры (используйте logfire-infrastructure).
