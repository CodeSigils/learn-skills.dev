Точка входа для Pydantic Logfire — платформы наблюдения, мониторинга и оценки. Используйте этот навык, когда пользователь просит «настроить Logfire», «добавить Logfire в мой проект», «настроить правильно с помощью Logfire», «отправить столько данных, сколько будет полезно», упоминает Logfire без конкретной области или его запрос охватывает более одного: инструментирование кода приложения/мониторинг инфраструктуры/оценка поведения ИИ. Если запрос явно ограничен одним из них, извлеките этот конкретный навык напрямую вместо этого — этот навык существует для маршрутизации, а не для дублирования их содержимого.
