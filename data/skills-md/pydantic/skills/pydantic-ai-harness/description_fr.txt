Étendez les agents Pydantic AI avec les capacités incluses dans les batteries de pydantic-ai-harness – actuellement le mode Code, qui regroupe de nombreux appels d'outils en une seule exécution Python en bac à sable. À utiliser lorsque l'utilisateur mentionne pydantic-ai-harness, CodeMode, Monty, le mode code ou le sandboxing d'outils, lorsqu'il souhaite qu'un agent exécute Python écrit par un agent, ou lorsqu'un agent Pydantic AI bénéficierait de l'orchestration de plusieurs appels d'outils dans un seul script en bac à sable.
