قم بتنسيق أعمال الترميز من خلال تفويض مهام التنفيذ المحددة جيدًا إلى Grok Build CLI (grok) الخاص بـ xAI الذي يعمل بدون رأس، بينما يقوم مساعد الترميز بالتخطيط وكتابة مواصفات المهمة ومراجعة كل اختلافات وامتلاك النتيجة. يُستخدم عندما يقول المستخدم: "استخدام grok"، و"إنشاء grok"، و"تفويض إلى grok"، و"تنفيذ grok"، و"تنفيذ grok"، و"have بناء grok"، و"إرسال إلى grok"، و"تنفيذ هذه الخطة باستخدام grok". ينفذ خطة تنفيذ Markdown مهمة بمهمة، أو مهام مخصصة بمواصفات مضمنة.
