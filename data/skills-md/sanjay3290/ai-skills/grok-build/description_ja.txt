明確に指定された実装タスクをヘッドレスで実行される xAI の Grok Build CLI (grok) に委任することでコーディング作業を調整します。一方、コーディング アシスタントは計画を立て、タスク仕様を作成し、すべての差分をレビューし、結果を所有します。ユーザーが「grok を使用する」、「grok ビルドを行う」、「grok に委任する」、「grok を実装させる」、「grok を実行させる」、「grok をビルドさせる」、「grok に送信する」、「このプランを grok で実行する」と言う場合に使用します。 Markdown 実装計画をタスクごとに実行するか、インライン仕様を使用してアドホック タスクを実行します。
