Отправляйте и получайте сообщения WhatsApp через неофициальный клиент связанного устройства pywhats (pip install pywhats) — сопряжение с QR, отправку текста/изображений, групповой чат, уведомления о прочтении, присутствие/ввод текста и длительный поток событий JSON. Используйте, когда пользователь хочет создать сценарий WhatsApp в качестве связанного сопутствующего устройства (например, WhatsApp Web), выполнить сопряжение устройства, отправить WhatsApp из Python или прослушать входящие сообщения. Триггеры: «whatsapp», «отправить WhatsApp», «сопряжение WhatsApp», «pywhats», «связанное устройство», «веб-клиент WhatsApp». НЕ официальный API WhatsApp Business/Cloud.
