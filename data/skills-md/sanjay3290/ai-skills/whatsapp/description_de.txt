Senden und empfangen Sie WhatsApp-Nachrichten über den inoffiziellen Link-Device-Client pywhats (pip install pywhats) – koppeln Sie ihn mit QR, senden Sie Text/Bilder, Gruppenchat, Lesebestätigungen, Anwesenheit/Eingabe und einen lang laufenden JSON-Ereignisstream. Verwenden Sie diese Option, wenn der Benutzer WhatsApp als verknüpftes Begleitgerät (wie WhatsApp Web) skripten, ein Gerät koppeln, eine WhatsApp von Python aus senden oder auf eingehende Nachrichten warten möchte. Auslöser: „WhatsApp“, „WhatsApp senden“, „WhatsApp koppeln“, „Pywhats“, „Verknüpftes Gerät“, „WhatsApp-Webclient“. NICHT die offizielle WhatsApp Business/Cloud API.
