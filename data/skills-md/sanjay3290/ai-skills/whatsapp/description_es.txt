Envíe y reciba mensajes de WhatsApp a través del cliente no oficial de dispositivo vinculado pywhats (pip install pywhats): emparéjelo con QR, envíe texto/imágenes, chat grupal, lea recibos, presencia/escritura y un flujo de eventos JSON de larga duración. Úselo cuando el usuario quiera programar WhatsApp como un dispositivo complementario vinculado (como WhatsApp Web), emparejar un dispositivo, enviar un WhatsApp desde Python o escuchar mensajes entrantes. Activadores: 'whatsapp', 'enviar whatsapp', 'emparejar whatsapp', 'pywhats', 'dispositivo vinculado', 'cliente web de whatsapp'. NO es la API oficial de WhatsApp Business/Cloud.
