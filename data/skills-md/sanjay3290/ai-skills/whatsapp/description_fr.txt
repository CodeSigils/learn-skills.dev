Envoyez et recevez des messages WhatsApp via le client non officiel d'appareil lié pywhats (pip install pywhats) - associez-le à QR, envoyez du texte/des images, une discussion de groupe, des accusés de lecture, une présence/saisie et un flux d'événements JSON de longue durée. À utiliser lorsque l'utilisateur souhaite créer un script WhatsApp en tant qu'appareil compagnon lié (comme WhatsApp Web), associer un appareil, envoyer un WhatsApp depuis Python ou écouter les messages entrants. Déclencheurs : « WhatsApp », « envoyer WhatsApp », « coupler WhatsApp », « pywhats », « appareil lié », « client Web WhatsApp ». PAS l'API officielle WhatsApp Business/Cloud.
