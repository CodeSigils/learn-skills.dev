Invia e ricevi messaggi WhatsApp tramite il client non ufficiale per dispositivi collegati pywhats (pip install pywhats): abbinalo a QR, invia testo/immagini, chat di gruppo, conferme di lettura, presenza/digitazione e un flusso di eventi JSON di lunga durata. Da utilizzare quando l'utente desidera creare script per WhatsApp come dispositivo associato collegato (come WhatsApp Web), associare un dispositivo, inviare un WhatsApp da Python o ascoltare i messaggi in entrata. Trigger: "whatsapp", "invia whatsapp", "accoppia whatsapp", "pywhats", "dispositivo collegato", "client web whatsapp". NON l'API ufficiale di WhatsApp Business/Cloud.
