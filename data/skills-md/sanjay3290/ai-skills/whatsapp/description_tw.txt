透過非官方連結裝置用戶端 pywhats (pip install pywhats) 發送和接收 WhatsApp 訊息 — 與 QR 配對、發送文字/圖像、群組聊天、已讀回執、線上狀態/打字以及長期運行的 JSON 事件流。當使用者想要將 WhatsApp 編寫為連結的配套裝置（如 WhatsApp Web）、配對裝置、從 Python 發送 WhatsApp 或偵聽入站訊息時使用。觸發器：「whatsapp」、「傳送 Whatsapp」、「配對 Whatsapp」、「pywhats」、「連結裝置」、「Whatsapp Web 用戶端」。不是官方 WhatsApp Business/Cloud API。
