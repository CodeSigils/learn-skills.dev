通过非官方链接设备客户端 pywhats (pip install pywhats) 发送和接收 WhatsApp 消息 — 与 QR 配对、发送文本/图像、群聊、已读回执、在线状态/打字以及长期运行的 JSON 事件流。当用户想要将 WhatsApp 编写为链接的配套设备（如 WhatsApp Web）、配对设备、从 Python 发送 WhatsApp 或侦听入站消息时使用。触发器：“whatsapp”、“发送 Whatsapp”、“配对 Whatsapp”、“pywhats”、“链接设备”、“Whatsapp Web 客户端”。不是官方 WhatsApp Business/Cloud API。
