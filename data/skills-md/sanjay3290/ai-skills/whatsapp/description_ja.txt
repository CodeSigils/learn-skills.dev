非公式のリンクされたデバイス クライアント pywhats (pip install pywhats) を介して WhatsApp メッセージを送受信します。QR とペアリングし、テキスト/画像を送信し、グループ チャット、開封確認、プレゼンス/入力、および長時間実行される JSON イベント ストリームを送信します。ユーザーがリンクされたコンパニオン デバイス (WhatsApp Web など) として WhatsApp をスクリプト化する場合、デバイスをペアリングする場合、Python から WhatsApp を送信する場合、または受信メッセージをリッスンする場合に使用します。トリガー: 'whatsapp'、'whatsapp の送信'、'whatsapp のペアリング'、'pywhats'、'リンクされたデバイス'、'whatsapp Web クライアント'。公式の WhatsApp Business/Cloud API ではありません。
