Guide l'échafaudage et le codage quotidien d'un monolithe modulaire Java Spring Boot : Maven BOM, démarreurs de framework, shell de serveur, modules api/biz, trois canaux API, superposition contrôleur/service/mapper, code d'erreur spécifique par panne, journalisation et gouvernance de la configuration. À utiliser lors de la création d'un nouveau backend, de l'ajout d'un module ou d'une API, de la révision de l'architecture, de la copie de conventions dans un autre projet ou lorsque l'utilisateur mentionne 单体架构、模块化单体、搭建框架、工程规范、代码规范.
