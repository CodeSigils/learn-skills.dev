Запустите локальный сервер разработки, подключенный к локальной сети (LAN WiFi) для доступа к настольному компьютеру и мобильному телефону. Используйте, когда пользователь хочет протестировать на мобильном устройстве, запустить приложение на локальном Wi-Fi, получить доступ к серверу разработки с телефона или совместно использовать локальный сервер между устройствами.
