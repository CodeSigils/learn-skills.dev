Führen Sie den lokalen Entwicklungsserver aus, der dem lokalen Netzwerk (LAN-WLAN) zugänglich ist, um Desktop- und Mobiltelefonzugriff zu ermöglichen. Verwenden Sie diese Option, wenn der Benutzer auf Mobilgeräten testen, die App im lokalen WLAN ausführen, vom Telefon aus auf den Entwicklungsserver zugreifen oder den lokalen Server geräteübergreifend freigeben möchte.
