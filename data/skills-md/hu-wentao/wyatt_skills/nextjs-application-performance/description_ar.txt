تصميم أداء تطبيق Next.js وقياسه وتنفيذه ومراجعته وترحيله عبر مسارات بيانات App Router وواجهة المستخدم المقدمة ومساحات عمل pnpm والرسوم البيانية للمترجم والمخرجات المستقلة وإجراءات الأعمال التي يدركها المستخدم وحاويات الإنتاج. يُستخدم لصفحات RSC، ومعالجات التوجيه، وإجراءات الخادم، واستعلام/جدول TanStack، والمجموعات المتزايدة، وترقيم الصفحات، والتخزين المؤقت، واستعلامات N+1، وحجم الحمولة، وحدود العرض، والرؤوس اللاصقة، وحاويات التمرير المتداخلة، وقص التراكب، ومراقبة المستخدم الحقيقي (RUM)، وتحليلات إعادة تشغيل الجلسة، وإخفاء Microsoft Clarity، ووقت استجابة النقر للاستعداد أو إجراء العمل، ووقت استجابة التنقل في الصفحة، وعناصر حيوية الويب، وTTFB، والبناء OOM أو RSS، أو serverExternalPackages، أو إضفاء الطابع الخارجي على حزمة الويب، أو روابط pnpm، أو حدود حزمة الخادم/العميل، أو إغلاق التبعية المستقلة، أو Dockerfiles، أو نشر Docker Compose لـ Next.js.
