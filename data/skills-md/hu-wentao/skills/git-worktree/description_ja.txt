スクリプト Git ワークツリーの作成、オーナー タスクの完了、一時配信、ローカル ブランチのメンテナンス、レスキュー、マージ、クリーンアップを、Exact-HEAD およびダーティ ワーク セーフガードで実行します。 Codex がワークツリーを作成または入力するときに使用します。非メインタスクブランチに計画または仕様を実装します。検証されたコミットを渡す必要があります。ローカルのブランチとワークツリーをリスト、マージ、保持、削除、レスキュー、またはクリーンアップします。またはローカルの開発状態を監査します。確定的な Git 遷移を自動化しながら、検証とセマンティックな値の判断を明示的に保ちます。リモート参照のプッシュ、削除、リベース、スカッシュ、スタッシュ、強制削除、または通常のタグの変更は決して行わないでください。
