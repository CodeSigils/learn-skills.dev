Объединить указанную ветку с текущей веткой с помощью фиксации слияния. Используйте это, когда пользователь хочет объединить одну ветку с текущей веткой или когда Кодекс должен автоматически обнаружить исходную ветку, в которой есть коммиты после текущей ветки. Навык проверяет, есть ли в исходной и целевой ветках незафиксированные работы в любом активном рабочем дереве git, и по умолчанию разрешает конфликты слияния автономно.
