Fusionnez une branche spécifiée dans la branche actuelle avec une validation de fusion. Utilisez-le lorsque l'utilisateur souhaite fusionner une branche dans la branche actuelle, ou lorsque le Codex doit détecter automatiquement la branche source qui a des validations après la branche actuelle. La compétence vérifie si la branche source et la branche cible ont du travail non validé dans un arbre de travail git actif et résout les conflits de fusion de manière autonome par défaut.
