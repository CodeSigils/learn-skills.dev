الاستعلام عن البنية التحتية المشتركة للمضيف والتحكم فيها عبر المشاريع، بما في ذلك المخزون الآمن لنشر الخدمة، والتمهيد الأولي لخادم Linux المحمي، وتثبيت Docker، وتنظيف ذاكرة التخزين المؤقت لـ Docker/BuildKit، وإنتاج الوظائف التشغيلية القابلة لإعادة الاستخدام، ومشغلات GitHub Actions ذاتية الاستضافة، وتثبيت Jenkins، والترقيات، وتكوين وحدة التحكم والوكيل، وبيانات الاعتماد، والمكونات الإضافية، والوظائف، والتغليف Android/iOS؛ مقياس الذيل. العلبة؛ PostgreSQL; نفق Cloudflare، وDNS، وAccess، وWAF/Rulesets، وتشخيص Cloudflare HTTP 403 الانتقائي. يُستخدم عندما يحتاج الوكيل إلى مخزون مضيف موثوق، أو إعداد خادم، أو تثبيت وقت تشغيل الحاوية، أو أتمتة الاحتفاظ بذاكرة التخزين المؤقت لـ Docker، أو تكوين مشغل CI، أو الخدمة المنشورة وملاحظات الموارد، أو حدث أمان Cloudflare أو تشخيص WAF، أو الفحص، أو التخطيط، أو الكتابة، أو التحقق، أو التراجع، أو طلب إجراء مضيف مثل تثبيت برنامج معين كوظيفة إدارة مضيف قابلة لإعادة الاستخدام.
