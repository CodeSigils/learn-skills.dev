Utilizza correttamente le API FlowR Flutter nei progetti che utilizzano il pacchetto flowr. Da utilizzare durante la scrittura o la revisione di widget FrViewModel/FrBlocViewModel, configurazione di FrProvider, stato di FrUnion, utilizzo di FrView/FrListener/FrConsumer, autoDisposeNotifier e altri modelli di proprietà specifici di Flutter o estensioni di pacchetto come fr_mvvm_theme/locale/env/user, anche quando il progetto ha un proprio layout di file.
