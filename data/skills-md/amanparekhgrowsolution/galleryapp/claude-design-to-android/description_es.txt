Convierta paquetes de transferencia de Claude Code Design (archivos zip que contienen prototipos JSX/HTML/CSS) en código Android Kotlin + Jetpack Compose con precisión de píxeles. Utilice esta habilidad siempre que el usuario cargue un archivo zip de Claude Design (claude.ai/design), un "paquete de transferencia" o cualquier prototipo de diseño exportado desde la herramienta de diseño de Claude que desee implementar como una aplicación de Android. También se activa cuando el usuario dice "convertir este diseño a Android", "implementar este diseño en Kotlin", "crear esta aplicación a partir del diseño", "convertir esto en una aplicación Compose", "convertir esta maqueta en código de Android" o hace referencia a un archivo zip de diseño y desea salida Kotlin/Android. Esta habilidad maneja todo el proceso: descomprimir, descubrir tokens de diseño y jerarquías de componentes de CUALQUIER estructura de origen JSX/HTML/CSS, asignarlos a equivalentes de Compose y generar una estructura de proyecto de Android completa con pantallas, navegación, temas y componentes reutilizables, que coincidan con el diseño original tan fielmente como lo permita Compose. Funciona con cualquier exportación de Claude Design independientemente del nombre del archivo, la estructura de la carpeta o el formato del token.
