Claude Code Design ハンドオフ バンドル (JSX/HTML/CSS プロトタイプを含む zip ファイル) をピクセル精度の Android Kotlin + Jetpack Compose コードに変換します。このスキルは、ユーザーが Claude Design (claude.ai/design) から zip ファイル、「ハンドオフ バンドル」、または Android アプリとして実装したい Claude の設計ツールからエクスポートされた任意の設計プロトタイプをアップロードするときに必ず使用します。また、ユーザーが「このデザインを Android に変換する」、「このデザインを Kotlin で実装する」、「デザインからこのアプリを構築する」、「これを Compose アプリに作成する」、「このモックアップを Android コードに変換する」、またはデザイン zip を参照して Kotlin/Android 出力を要求した場合にもトリガーされます。このスキルは、パイプライン全体を処理します。解凍して、任意の JSX/HTML/CSS ソース構造からデザイン トークンとコンポーネント階層を検出し、それらを Compose の同等のものにマッピングし、画面、ナビゲーション、テーマ、再利用可能なコンポーネントを含む完全な Android プロジェクト構造を生成します。これは、Compose が許す限り元のデザインと一致します。ファイル名、フォルダー構造、トークン形式に関係なく、あらゆる Claude Design エクスポートで動作します。
