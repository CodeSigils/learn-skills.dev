將 Claude Code Design 交付套件（包含 JSX/HTML/CSS 原型的 zip 檔案）轉換為像素精確的 Android Kotlin + Jetpack Compose 程式碼。每當使用者上傳 Claude Design (claude.ai/design) 的 zip 檔案、「交接包」或從 Claude 的設計工具匯出並希望作為 Android 應用程式實現的任何設計原型時，請使用此技能。當用戶說「將此設計轉換為 Android」、「在 Kotlin 中實現此設計」、「從設計構建此應用程式」、「將其製作為 Compose 應用程式」、「將此模型轉換為 Android 程式碼」或引用設計 zip 並想要 Kotlin/Android 輸出時也會觸發。此技能處理完整的管道：從任何 JSX/HTML/CSS 來源結構中解壓縮、發現設計標記和元件層次結構，將它們對應到 Compose 等效項，並產生包含螢幕、導航、主題和可重複使用元件的完整 Android 專案結構 - 在 Compose 允許的範圍內盡可能匹配原始設計。適用於任何 Claude Design 匯出，無論檔案命名、資料夾結構或令牌格式如何。
