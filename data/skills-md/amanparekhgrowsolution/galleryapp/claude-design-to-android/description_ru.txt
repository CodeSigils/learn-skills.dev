Преобразуйте пакеты передачи Claude Code Design (zip-файлы, содержащие прототипы JSX/HTML/CSS) в код Android Kotlin + Jetpack Compose с точностью до пикселя. Используйте этот навык всякий раз, когда пользователь загружает zip-файл из Claude Design (claude.ai/design), «пакет передачи» или любой прототип дизайна, экспортированный из инструмента дизайна Claude, который он хочет реализовать в виде приложения для Android. Также срабатывает, когда пользователь говорит «преобразовать этот дизайн в Android», «реализовать этот дизайн в Kotlin», «создать это приложение на основе дизайна», «превратить это в приложение Compose», «превратить этот макет в код Android» или ссылается на zip-архив дизайна и хочет получить выходные данные Kotlin/Android. Этот навык управляет полным конвейером: распаковка, обнаружение токенов дизайна и иерархий компонентов из ЛЮБОЙ исходной структуры JSX/HTML/CSS, сопоставление их с эквивалентами Compose и создание полной структуры проекта Android с экранами, навигацией, темами и компонентами многократного использования, максимально близкими к исходному дизайну, насколько это позволяет Compose. Работает с любым экспортом Claude Design независимо от имени файла, структуры папок или формата токена.
