Verwandeln Sie jede öffentliche URL mithilfe der integrierten Tools des Agenten – WebFetch, Browser/Screenshot und Dateischreibvorgänge – in eine 9-teilige design.md-Spezifikation in Produktionsqualität (Farben, Typografie, Komponenten, Layout, Tiefe, Bewegung, Reaktionsfähigkeit, Eingabeaufforderungsanleitung). Wird verwendet, wenn der Benutzer „ein Designsystem aus einer URL generieren“, „Markentokens extrahieren“, „eine design.md schreiben“, den Stil einer Website klonen oder ein Designsystem aus einer Live-Seite zurückentwickeln möchte. Wird bei Phrasen wie „Designspezifikation“, „Styleguide von URL“, „Markentokens“ oder jeder Anfrage ausgelöst, die eine URL einfügt und nach einem Designdokument fragt.
