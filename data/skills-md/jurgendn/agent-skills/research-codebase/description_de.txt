Strukturieren und pflegen Sie eine Forschungscodebasis für schnelle Hypothesentests in einem einzigen Dokument. Optimiert für lokale Ausführungen, jeweils ein Experiment. Verwenden Sie es, wenn Sie ein neues Projekt starten, Experimente organisieren oder eine Codebasis bereinigen, in der sich die Navigation schwierig gestaltet. Lösen Sie aus auf „Wie soll ich meinen Code strukturieren“, „Mein Projekt einrichten“, „Meine Experimente organisieren“, „Eine neue Arbeit beginnen“, „Mein Code wird chaotisch“, „Vereinfachen“, „Zu viele Abstraktionen“, „Ich habe ihn überentwickelt“ oder „Ich habe diese Codebasis geerbt“. Verhindert beide Richtungen des Scheiterns: (1) das Hinzufügen von Struktur, bevor es Schmerzen gibt, die es rechtfertigen, und (2) das Löschen von Abstraktionen, die tatsächlich tragend sind.
