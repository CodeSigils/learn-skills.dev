研究リポジトリの README.md を作成または監査します。ユーザーが研究用コードベースの README を作成、改善、修正、またはレビューしたい場合は常にこのスキルを使用します。これには、「私の README を書いてください」、「私の README は何を言うべきですか」、「私の README は適切ですか」、「私のリポジトリの文書化を手伝ってください」、「私の README は単なる使用例です」、または「このリポジトリを共有する必要があります」などの表現が含まれます。また、ユーザーがリサーチ コードベースを設定したばかりで (リサーチ コードベース スキルの使用後など)、まだ README を書いていないときにもトリガーされます。最も一般的な 2 つの失敗モードを防ぎます。(1) 完全に見えても実際には論文結果を再現できない 1 つの例の README、(2) 研究内容は説明するがコードは説明しない動機優先の README。
