Écrivez ou auditez un README.md pour un référentiel de recherche. Utilisez cette compétence chaque fois que l'utilisateur souhaite écrire, améliorer, corriger ou réviser un README pour une base de code de recherche - y compris des expressions telles que « écrire mon README », « que doit dire mon README », « est-ce que mon README est bon », « aidez-moi à documenter mon dépôt », « mon README n'est qu'un exemple d'utilisation » ou « Je dois partager ce dépôt ». Déclenchez également lorsque l'utilisateur vient de configurer une base de code de recherche (par exemple après avoir utilisé la compétence de base de code de recherche) et n'a pas encore écrit de README. Empêche les deux modes de défaillance les plus courants : (1) le README à un exemple qui semble complet mais ne peut réellement reproduire aucun résultat papier, et (2) le README axé sur la motivation qui explique la recherche mais pas le code.
