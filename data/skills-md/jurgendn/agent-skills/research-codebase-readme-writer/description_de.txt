Schreiben oder prüfen Sie eine README.md für ein Forschungsrepository. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine README-Datei für eine Forschungscodebasis schreiben, verbessern, korrigieren oder überprüfen möchte – einschließlich Formulierungen wie „Schreibe meine README-Datei“, „Was soll meine README-Datei sagen“, „Ist meine README-Datei gut“, „Helfen Sie mir, mein Repo zu dokumentieren“, „Meine README-Datei ist nur ein Anwendungsbeispiel“ oder „Ich muss dieses Repo teilen“. Wird auch ausgelöst, wenn der Benutzer gerade eine Forschungscodebasis eingerichtet hat (z. B. nachdem er die Fähigkeit zur Forschungscodebasis verwendet hat) und noch keine README-Datei geschrieben hat. Verhindert die beiden häufigsten Fehlermodi: (1) die Ein-Beispiel-README-Datei, die vollständig aussieht, aber kein tatsächliches Papierergebnis reproduzieren kann, und (2) die Motivation-erste README-Datei, die die Recherche, aber nicht den Code erklärt.
