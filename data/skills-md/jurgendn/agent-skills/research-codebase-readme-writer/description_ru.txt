Напишите или проверьте файл README.md для исследовательского репозитория. Используйте этот навык всякий раз, когда пользователь хочет написать, улучшить, исправить или просмотреть README для исследовательской кодовой базы, включая такие фразы, как «напишите мой README», «что должен сказать мой README», «хорош ли мой README», «помогите мне документировать мой репозиторий», «мой README — это просто пример использования» или «Мне нужно поделиться этим репозиторием». Также срабатывает, когда пользователь только что настроил базу кода для исследования (например, после использования навыка работы с базой кода для исследования) и еще не написал README. Предотвращает два наиболее распространенных режима сбоя: (1) README с одним примером, который выглядит законченным, но на самом деле не может воспроизвести какой-либо бумажный результат, и (2) README, ориентированный на мотивацию, который объясняет исследование, но не код.
