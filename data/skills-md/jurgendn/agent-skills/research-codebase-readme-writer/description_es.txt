Escriba o audite un archivo README.md para un repositorio de investigación. Utilice esta habilidad siempre que el usuario quiera escribir, mejorar, corregir o revisar un archivo README para una base de código de investigación, incluidas frases como "escriba mi archivo README", "qué debería decir mi archivo README", "es bueno mi archivo README", "ayúdeme a documentar mi repositorio", "mi archivo README es solo un ejemplo de uso" o "Necesito compartir este repositorio". También se activa cuando el usuario acaba de configurar una base de código de investigación (por ejemplo, después de usar la habilidad de base de código de investigación) y aún no ha escrito un archivo README. Previene los dos modos de falla más comunes: (1) el README de un ejemplo que parece completo pero en realidad no puede reproducir ningún resultado en papel, y (2) el README de motivación que explica la investigación pero no el código.
