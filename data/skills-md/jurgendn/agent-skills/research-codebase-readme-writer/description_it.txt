Scrivi o controlla un README.md per un repository di ricerca. Utilizza questa abilità ogni volta che l'utente desidera scrivere, migliorare, correggere o rivedere un README per una base di codici di ricerca, comprese frasi come "scrivi il mio README", "cosa dovrebbe dire il mio README", "il mio README è buono", "aiutami a documentare il mio repository", "il mio README è solo un esempio di utilizzo" o "devo condividere questo repository". Si attiva anche quando l'utente ha appena impostato una base di codice di ricerca (ad esempio dopo aver utilizzato l'abilità base di ricerca-codice) e non ha ancora scritto un file README. Previene le due modalità di errore più comuni: (1) il README con un esempio che sembra completo ma in realtà non è in grado di riprodurre alcun risultato cartaceo e (2) il README motivazionale che spiega la ricerca ma non il codice.
