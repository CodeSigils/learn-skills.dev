Cree una base agente de entrega de proyectos para un repositorio nuevo o poco documentado. Úselo cuando Codex necesite generar ideas sobre la dirección del proyecto, investigar la base de código existente o el contexto competitivo, estructurar documentos de planificación, definir hitos y notas de protocolo, crear ADR y generar archivos AGENTS.md y CLAUDE.md alineados que apliquen un flujo de trabajo en el que los documentos primero y las pruebas primero.
