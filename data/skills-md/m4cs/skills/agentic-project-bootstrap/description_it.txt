Crea una base di consegna di progetti tramite agenti per un repository nuovo o scarsamente documentato. Utilizzalo quando Codex ha bisogno di fare brainstorming sulla direzione del progetto, ricercare la base di codice esistente o il contesto competitivo, creare documenti di pianificazione dell'impalcatura, definire tappe fondamentali e note di protocollo, creare ADR e generare file AGENTS.md e CLAUDE.md allineati che impongono un flusso di lavoro incentrato sui documenti e sui test.
