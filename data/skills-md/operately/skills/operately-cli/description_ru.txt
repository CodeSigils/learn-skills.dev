Используйте при работе с Operately CLI для управления проектами, целями, задачами, пространствами и центрами ресурсов. Охватывает аутентификацию, операции CRUD для всех бизнес-объектов, совместную работу в команде, регистрацию, контрольные точки и организационные рабочие процессы. Триггеры «оперативно», «CLI», «управление проектами», «отслеживание целей», «OKR», «задача», «этап», «регистрация», «пространство», «концентратор ресурсов».
