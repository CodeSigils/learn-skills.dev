Маршрутизатор, используемый для интеграции нескольких специализированных результатов при проектировании, реализации и проверке среднего и крупного масштаба, для сквозной проверки воспроизводимости требований или для тестов воспроизведения при нескольких запусках. Он не используется для отдельных результатов или небольших механических изменений, которые не связаны с государственными контрактами или значением данных.
