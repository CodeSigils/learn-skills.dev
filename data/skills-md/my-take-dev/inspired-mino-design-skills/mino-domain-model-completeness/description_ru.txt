Используется при проверке отсутствия или неправильного размещения бизнес-терминов, контекстов, концепций, ограничений значений, состояний, переходов, поведения, сбоев и средств записи/считывания, необходимых для целевого варианта использования. Он предназначен только для моделирования всей реальности, только для диаграмм и не используется в общих объяснениях DDD.
