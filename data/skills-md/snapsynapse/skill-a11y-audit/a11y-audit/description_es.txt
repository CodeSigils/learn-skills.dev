Ejecute auditorías de accesibilidad en proyectos web combinando escaneo automatizado (axe-core, Lighthouse) con mapeo de cumplimiento WCAG 2.1 AA, guía de verificación manual e informes estructurados. La salida es configurable: solo informe de rebajas, rebajas más JSON legible por máquina, o rebajas más integración de seguimiento de problemas. Utilice esta habilidad siempre que el usuario mencione "auditoría de accesibilidad", "auditoría a11y", "auditoría WCAG", "verificación de accesibilidad", "escaneo de cumplimiento" o solicite verificar un proyecto web para detectar problemas de accesibilidad. También se activa cuando el usuario desea verificar la conformidad con las WCAG o asignar los hallazgos a un estándar específico (CAN-ASC-6.2, EN 301 549, ADA/AODA).
