Führen Sie Barrierefreiheitsprüfungen für Webprojekte durch, indem Sie automatisiertes Scannen (Axe-Core, Lighthouse) mit WCAG 2.1 AA-Compliance-Mapping, manueller Prüfanleitung und strukturiertem Reporting kombinieren. Die Ausgabe ist konfigurierbar: nur Markdown-Bericht, Markdown plus maschinenlesbares JSON oder Markdown plus Issue-Tracker-Integration. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „Barrierefreiheitsprüfung“, „a11y-Audit“, „WCAG-Audit“, „Barrierefreiheitsprüfung“, „Compliance-Scan“ erwähnt oder darum bittet, ein Webprojekt auf Barrierefreiheitsprobleme zu überprüfen. Wird auch ausgelöst, wenn der Benutzer die WCAG-Konformität überprüfen oder Ergebnisse einem bestimmten Standard zuordnen möchte (CAN-ASC-6.2, EN 301 549, ADA/AODA).
