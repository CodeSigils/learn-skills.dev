DEBE usarse cuando una solicitud combina la intención de salida HTML con un archivo similar a un plan existente. Activador para “HTML 文件”, “HTML 预览页”, “配套 HTML”, “用 HTML 展示”, “展示成 HTML”, “render as HTML”, “不要改计划内容”, además de archivos como plan.md, implementación-plan.md, lanzamiento-plan.md, planes roadmap.yaml, task.json o .txt. Los archivos de hoja de ruta y tareas cuentan como plan 文件 incluso si el usuario no dice plan. No lo utilice simplemente para redactar un plan sin un archivo de plan ni salida HTML. 这个 habilidad 不负责制定计划本身，不预设 secciones；HTML 必须基于输入 plan 文件的实际内容和顺序生成。
