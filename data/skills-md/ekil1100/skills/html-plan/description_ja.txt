リクエストが HTML 出力インテントと既存のプランのようなファイルを組み合わせる場合に使用する必要があります。 「HTML 文件」、「HTML 预览页」、「配套 HTML」、「用 HTML 展示」、「展示成 HTML」、「HTML としてレンダリング」、「不要改计划内容」、および plan.md、implementation-plan.md、release-plan.md、roadmap.yaml、tasks.json、または .txt プランなどのファイルのトリガー。ロードマップ ファイルとタスク ファイルは、ユーザーが計画を言わなくても計画文書としてカウントされます。計画ファイルや HTML 出力を行わずに、単に計画を作成する目的で使用しないでください。 このスキルは、計画そのものを策定するものではなく、セクションを構成するものではありません。HTML は、計画ファイルの入力の実際の内容とシーケンスの生成に基づいている必要があります。
