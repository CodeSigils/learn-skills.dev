ДОЛЖЕН использоваться, когда запрос объединяет намерение вывода HTML с существующим файлом, подобным плану. Триггер для «HTML 文件», «HTML 预览页», «配套 HTML», «用 HTML 展示», «展示成 HTML», «рендеринга как HTML», «不要改计划内容», а также таких файлов, как plan.md,implementation-plan.md, Release-plan.md, планы roadmap.yaml, Tasks.json или .txt. Файлы дорожной карты и задач считаются планом, даже если пользователь не говорит «план». Не используйте для простого составления плана без файла плана и вывода в формате HTML. 这个 навык 不负责制定计划本身，不预设 разделы；HTML 必须基于输入 план 文件的实际内容和顺序生成。
