DEVE essere utilizzato quando una richiesta combina l'intento di output HTML con un file simile a un piano esistente. Trigger per “HTML 文件”, “HTML 预览页”, “配套 HTML”, “用 HTML 展示”, “展示成 HTML”, “render as HTML”, “不要改计划内容”, oltre a file come plan.md, implement-plan.md, release-plan.md, piani roadmap.yaml, task.json o .txt. I file della roadmap e delle attività contano come piano 文件 anche se l'utente non dice piano. Non utilizzare semplicemente per la stesura di un piano senza file di piano e senza output HTML. 这个 abilità 不负责制定计划本身, sezioni 不预设；HTML 必须基于输入 piano 文件的实际内容和顺序生成.
