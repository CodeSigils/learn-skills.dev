DOIT être utilisé lorsqu'une requête combine l'intention de sortie HTML avec un fichier de type plan existant. Déclencheur pour « HTML 文件 », « HTML 预览页 », « 配套 HTML », « 用 HTML 展示 », « 展示成 HTML », « render as HTML », « 不要改计划内容 », ainsi que des fichiers comme plan.md, Implementation-plan.md, release-plan.md, plans roadmap.yaml, Tasks.json ou .txt. Les fichiers de feuille de route et de tâches comptent comme un plan même si l'utilisateur ne dit pas de plan. Ne pas utiliser pour simplement rédiger un plan sans fichier de plan ni sortie HTML. 这个 compétence 不负责制定计划本身，不预设 sections；HTML 必须基于输入 plan 文件的实际内容和顺序生成。
