Diseño de novela web china "dedo dorado" (trucos/sistema). Se utiliza cuando un usuario quiere crear conceptos básicos como flujo del sistema, flujo de inicio de sesión, flujo espacial, simulador, profeta reencarnado, hacerse el tonto para burlar a un depredador, etc., o para darle al protagonista un mecanismo de encendido. Genera una solución de dedo de oro con umbrales de entrada, una curva de crecimiento, un costo y vínculos con la trama principal.
