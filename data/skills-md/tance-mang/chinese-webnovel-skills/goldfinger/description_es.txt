Diseño de novela web china dedo dorado (truco/hack/sistema). Se utiliza cuando un usuario desea diseñar configuraciones básicas como el flujo del sistema, el flujo de inicio de sesión, el flujo espacial, el simulador, el profeta renacido, hacerse el tonto pero ser astuto, etc., o para darle al protagonista un mecanismo de encendido. El resultado es un plan de dedo de oro que tiene umbrales, una curva de crecimiento, costos y está vinculado a la historia principal.
