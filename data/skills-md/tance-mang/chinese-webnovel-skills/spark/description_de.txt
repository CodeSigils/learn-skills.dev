Aufzeichnung der Inspiration für chinesische Web-Romane und Erstellung von Manuskripten mit einem Klick. Es wird verwendet, wenn ein Benutzer eine Inspiration oder Idee hat, die er schnell aufschreiben möchte, eine bestimmte Idee aus seinem Inspirationsnotizbuch in eine Gliederung oder einen Entwurf umwandeln möchte oder sagt: „Nur diese eine Idee – helfen Sie mir, sie aufzuschreiben.“ Es unterstützt das schnelle Notieren von Inspirationen, einen vollständigen Arbeitsablauf von der Idee → Gliederung → Entwurf und ermöglicht die Festlegung einer Gesamtwortzahl oder einer Wortzahl pro Kapitel mit automatischer Kapitelunterteilung.
