Sistema de memoria y archivo de creación de novelas web chinas. Se utiliza cuando el usuario desea registrar/guardar la configuración de los caracteres del esquema, continuar escribiendo un libro anterior en varias sesiones, preguntar "¿Dónde lo dejé?/¿Se ha resuelto este presagio?", crear instantáneas de la versión de un libro (como git) o ​​gestionar el progreso creativo de varios libros. Mantiene archivos persistentes en la carpeta del libro, y todas las capacidades de escritura comparten acceso de lectura/escritura.
