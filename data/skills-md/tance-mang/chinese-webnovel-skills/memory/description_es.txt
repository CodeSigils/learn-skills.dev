Sistema de memoria y archivo de escritura creativa para novelas web chinas. Se utiliza cuando los usuarios necesitan grabar/guardar la configuración de los caracteres del esquema, continuar escribiendo un libro anterior en varias sesiones y preguntar "¿Dónde me detuve?" o "¿Se ha resuelto este presagio?", cree instantáneas de la versión de un libro (como git) o ​​administre el progreso de escritura de varios libros. Mantiene archivos persistentes en la carpeta de cada libro, y todas las habilidades de escritura comparten acceso de lectura/escritura.
