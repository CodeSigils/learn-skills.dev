Schreiben Sie Drehbücher (vertikale Kurzdramen/Filme/Hörspiele) in einem Standard-Drehbuchformat. Verwenden Sie dies, wenn der Benutzer ein Drehbuch, ein Kurzdrama oder ein Episodenskript schreiben, einen Roman in ein Drehbuch umwandeln, ein Dialogskript schreiben möchte oder fragt, wie man ein Drehbuch schreibt/formatiert. Verwenden Sie standardmäßig den vertikalen Kurzdrama-Stil, beziehen Sie nur das ein, was die Kamera einfangen kann (Aktionen/Dialoge/Soundeffekte), lassen Sie innere Gedanken weg und sorgen Sie für starke Beats in jeder Episode.
