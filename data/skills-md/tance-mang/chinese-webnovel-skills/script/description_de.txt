Schreiben Sie ein Drehbuch (vertikales Kurzdrama/Film/Hörspiel) im Standard-Drehbuchformat. Verwenden Sie dies, wenn der Benutzer ein Drehbuch, ein Kurzdrama oder ein Episodenskript schreiben, einen Roman in ein Drehbuch umwandeln, ein Dialogskript schreiben möchte oder fragt, wie man ein Drehbuch schreibt bzw. formatiert. Verwenden Sie standardmäßig einen vertikalen Kurzdrama-Stil, der nur beschreibt, was die Kamera einfangen kann (Aktionen, Dialoge, Soundeffekte), innere Gedanken weglässt und sicherstellt, dass jede Episode starke Schlagpunkte hat.
