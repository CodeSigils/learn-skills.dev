Busque en la web utilizando los más de 100 motores de búsqueda de SerpApi. Utilice esta habilidad siempre que el usuario necesite información actual o de origen web: investigar un tema, consultar noticias recientes, comparar productos o precios, encontrar empresas locales, buscar imágenes o videos, o buscar artículos académicos, vuelos, hoteles o acciones, incluso si no solicitan explícitamente "buscar en la web". El valor predeterminado es google_light para mayor velocidad. Admite Google, Bing, DuckDuckGo, YouTube, Amazon, Maps, Scholar y más.
