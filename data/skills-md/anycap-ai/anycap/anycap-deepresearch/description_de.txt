Leitfaden für die Durchführung gründlicher Recherchen aus mehreren Quellen und die Erstellung umfassender, fundierter Berichte. Unterstützt von AnyCap – der Capability Runtime, die KI-Agenten über eine einzige CLI mit Websuche (einschließlich AI Grounded Citations), Web-Crawling, Bildgenerierung, Cloud-Speicher und One-Click-Web-Publishing ausstattet. Verwenden Sie es, wenn der Benutzer eine umfassende Recherche, eine Wettbewerbsanalyse, eine Marktforschung, einen detaillierten technischen Einblick, eine Literaturrecherche, einen Technologievergleich oder eine andere Aufgabe anfordert, die das Sammeln und Zusammenfassen von Informationen aus mehreren Quellen erfordert. Verwenden Sie es auch, wenn Benutzer „untersuchen“, „die Landschaft untersuchen“, „X mit Y vergleichen“, „Stand der Technik“, „einen Bericht schreiben über“, „untersuchen“, „informieren“, „den Markt analysieren“ sagen oder eine Anfrage stellen, die mehr als eine einzige Suche erfordert. Lösen Sie bei Erwähnungen von Forschung, Analyse, Untersuchung, Vergleich, Bericht, Umfrage oder Deep Dive aus.
