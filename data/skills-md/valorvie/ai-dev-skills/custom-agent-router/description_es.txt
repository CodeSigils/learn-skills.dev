Seleccione modo de interacción, nivel de capacidad, riesgo, forma de despacho, revisión y respaldo limitado para tareas de Agente no triviales cuyas objetivos, alcance y autoridad están claramente definidos. Esto se aplica a tareas que requieren una elección entre manejo directo por el Agente principal, un proxy de tarea único o paralelismo limitado, o donde el nivel de capacidad y la intensidad de revisión deben determinarse según la complejidad y el riesgo; cuando un proyecto Codex carece de una configuración de Agente verificada, esta habilidad también guía al usuario a crear, previsualizar o omitir. No lo use para preguntas y respuestas simples, confirmaciones solo de lectura o ediciones menores que pueden verificarse directamente.

Por favor, responda siempre en el idioma del usuario.
