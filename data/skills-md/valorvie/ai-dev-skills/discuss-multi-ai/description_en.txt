Multi‑AI cross‑review workflow. Performs cross‑review of code changes among different AI tools (e.g., Claude, Codex, Gemini, etc.).  
When to use: when a user invokes /discuss-multi-ai, mentions wanting another AI to review the changes, or pastes a review request that includes a commit hash.  
Even if the user simply says “Generate review text for another AI” or “Pass this change to another AI for review,” this capability should be triggered.
