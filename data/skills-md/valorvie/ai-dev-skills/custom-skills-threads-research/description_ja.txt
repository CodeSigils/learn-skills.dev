Playwright MCP + Context Mode MCP を使用して、公開されている Threads (threads.net) の投稿を検索・分析します。Google 検索は JavaScript のレンダリングが必要なため、検索は Playwright が担当し、Context Mode がインデックス作成、圧縮、クエリ処理を行い、コンテキストウィンドウの消費を最小限に抑えます。Google（site:threads.net）によるキーワード検索、ユーザープロフィールの直接閲覧、複数キーワードをまとめたバッチ調査、構造化要約をサポートします。以下の場合に積極的に使用してください：ユーザーが Threads に言及した、Threads の投稿を探したい、threads.net のディスカッションについて質問した、Threads のソーシャルメディア調査を求めた、Threads からの口碑/評價/推薦 を求めた、あるいは Threads コミュニティの意見が価値あると考えられるトピックに言及した場合。トリガーフレーズは「搜尋 Threads」「Threads 上有人說」「threads 口碑」「threads 評價」「threads 討論」「threads 推薦」「找 threads 貼文」「site:threads.net」などです。

常にユーザーの言語で回答してください。
