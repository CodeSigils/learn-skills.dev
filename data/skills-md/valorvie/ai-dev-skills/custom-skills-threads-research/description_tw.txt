使用 Playwright MCP + Context Mode MCP 搜尋並分析公開的 Threads（threads.net）貼文。Google 搜尋需要 JS 渲染，因此由 Playwright 負責搜尋；Context Mode 負責索引、壓縮與查詢，以降低上下文窗口的消耗。支援透過 Google（site:threads.net）進行關鍵字搜尋、直接瀏覽使用者個人檔案、批次多關鍵字研究，以及結構化摘要。當以下情況出現時請主動使用：使用者提及 Threads、想找 Threads 貼文、詢問 threads.net 討論、需要 Threads 社群媒體研究、要求來自 Threads 的口碑/評價/推薦，或提到任何 Threads 社群意見可能有價值的主題。觸發關鍵字亦包括：「搜尋 Threads」、「Threads 上有人說」、「threads 口碑」、「threads 評價」、「threads 討論」、「threads 推薦」、「找 threads 貼文」、「site:threads.net」。請始終以使用者的語言回覆。
