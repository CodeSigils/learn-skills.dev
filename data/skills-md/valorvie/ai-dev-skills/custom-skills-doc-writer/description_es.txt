Con base en las tareas de los lectores y las líneas principales verificables, redacta, refactoriza y organiza documentos técnicos, manejando tipos de documento, rutas, nombres de archivo, frontmatter, índices y ciclos de vida según las convenciones del proyecto. Los documentos técnicos también protegen hechos, comandos, rutas e identificadores dentro de contenido mixto chino‑inglés; el texto explicativo en inglés sigue el principio ASD‑STE100. Cuando el usuario proporciona un PDF estándar legítimo junto con un validador local, se dispone de asistencia automática para la verificación. Esta habilidad debe usarse siempre que se añadan o reescriban sustancialmente planes, investigaciones, análisis, estudios, informes de progreso, guías, manuales de operación, tutoriales, materiales de referencia, explicaciones de principios, decisiones, eventos, reuniones, registros de cambios o especificaciones; también se aplica al organizar el directorio docs y el índice de temas. No lo utilice para traducción pura, pulido menor de texto, cambios solo de código o verificación de un único hecho.

Por favor, responda siempre en el idioma del usuario.
