Assunzione di progettazione per l'architettura delle miniapp. Si attiva quando si crea una nuova miniapp, si progetta l'infrastruttura o quando l'utente digita "progetta miniapp" o "crea miniapp". Raccoglie i requisiti dell'architettura tramite elenco di controllo, genera un documento di progettazione Markdown e file diagramma come codice.
