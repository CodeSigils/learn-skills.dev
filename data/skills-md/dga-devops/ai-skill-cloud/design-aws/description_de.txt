Designaufnahme für die AWS-Architektur. Wird beim Erstellen einer neuen Anwendung, beim Entwerfen einer Infrastruktur oder wenn der Benutzer „design aws“ oder „design Architecture“ eingibt, ausgelöst. Unterstützt mehrere Architekturmuster über die Musterregistrierung. Erfasst Anforderungen über strukturierte Schritte, überprüft Ressourcen, generiert ein Markdown-Designdokument und eine Diagramm-als-Code-Datei.
