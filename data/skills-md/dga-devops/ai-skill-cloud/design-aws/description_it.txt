Assunzione di progettazione per l'architettura AWS. Si attiva quando si crea una nuova applicazione, si progetta l'infrastruttura o quando l'utente digita "design aws" o "design architecture". Supporta più modelli di architettura tramite il registro dei modelli. Raccoglie i requisiti tramite passaggi strutturati, verifica le risorse, genera un documento di progettazione Markdown e un file diagramma come codice.
