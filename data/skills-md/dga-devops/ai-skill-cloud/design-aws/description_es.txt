Admisión de diseño para la arquitectura de AWS. Se activa al crear una nueva aplicación, diseñar una infraestructura o cuando el usuario escribe "design aws" o "design Architecture". Admite múltiples patrones de arquitectura a través del registro de patrones. Recopila requisitos a través de pasos estructurados, verifica recursos, genera un documento de diseño Markdown y un archivo de diagrama como código.
