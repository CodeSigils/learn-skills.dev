Aplique la guía prescriptiva de AWS para el desarrollo de CDK de TypeScript. Activadores al crear, modificar o revisar pilas de AWS CDK, construcciones L2, configuraciones multientorno, escaneo de seguridad cdk-nag, pruebas unitarias o administración de versiones de dependencia. Úselo para cualquier tarea que involucre código CDK en bin/, lib/, config/ o test/.
