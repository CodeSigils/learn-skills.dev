Applica le linee guida prescrittive di AWS per lo sviluppo di CDK TypeScript. Trigger durante la creazione, la modifica o la revisione di stack AWS CDK, costrutti L2, configurazioni multiambiente, scansione di sicurezza cdk-nag, test di unità o gestione delle versioni delle dipendenze. Utilizzare per qualsiasi attività che coinvolga il codice CDK in bin/, lib/, config/ o test/.
