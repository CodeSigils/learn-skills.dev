Wenden Sie die AWS Prescriptive Guidance für die TypeScript CDK-Entwicklung an. Wird beim Erstellen, Ändern oder Überprüfen von AWS CDK-Stacks, L2-Konstrukten, Multi-Umgebungs-Konfigurationen, CDK-Nag-Sicherheitsscans, Unit-Tests oder Abhängigkeitsversionsmanagement ausgelöst. Für jede Aufgabe verwenden, die CDK-Code in bin/, lib/, config/ oder test/ beinhaltet.
