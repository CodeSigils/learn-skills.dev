Interpreta i profili di runtime delle query Apache Doris, in particolare la valutazione dei colli di bottiglia dei profili, i contatori di attesa fuorvianti, la priorità della metrica per operatore, la scansione, l'analisi dell'ordine di join/filtro di runtime e le spiegazioni delle prestazioni limitate dall'evidenza. Da utilizzare quando viene fornito un profilo Doris, un ID query, un URL/testo del profilo o una richiesta per spiegare le prestazioni della query Doris.
