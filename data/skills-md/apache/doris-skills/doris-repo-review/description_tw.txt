給定一個PR URL（`/doris-repo-review https://github.com/apache/doris/pull/66807`），首先檢查當前目錄的分支和提交是否與該PR匹配，如果不匹配，則將當前目錄與PR頭對齊，而不干擾本地工作（當跟踪文件被修改時拒絕切換，並將其還拒絕切換主代理風險掃描，1-3 個全面審查子代理加上以風險為中心的子代理，共享賬本收斂（最多 3 輪），以及寫入 review-docs/ 的一份英文加一份中文審查文檔。本機運行沒有 GitHub 內聯註釋，因此每個發現都必須帶有路徑：行錨點和逐字片段，並由腳本驗證。當審核通過（沒有 Blocker 且沒有 Major）時，它還會從本地 gh 帳戶對 PR 發布一條強格式的、機器可讀的 PASS 評論 - 審核日期、審核的提交 sha、狀態、模型和維護人員註釋 - 在向用戶顯示確切的正文以供確認之後。當使用者說“/doris-repo-review <PR URL>”、“查看此 PR”、“以 CI 管道的方式查看它”或“像 CI 一樣在本地查看此 PR”時使用。對原始程式碼唯讀 - 無需建置、無需測試、無需更改儲存庫檔案； PASS 評論是唯一的 GitHub 評論，而 REQUEST_CHANGES 評論根本沒有發布任何內容。
