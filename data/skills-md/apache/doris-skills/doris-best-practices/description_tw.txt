Apache Doris 表格設計和叢集大小調整最佳實務。在編寫、審查或最佳化 Doris CREATE TABLE 語句、分區/儲存桶策略、資料模型或叢集配置時必須使用。每當 doris-architecture-advisor 技能產生 DDL 時也必須使用 — 在輸出之前將飛行前檢查表應用於每個 CREATE TABLE。還可以觸發涉及以下的任何工作負載設計：物聯網、分析、儀表板、CDC、時間序列、日誌分析、即時倉庫、點查詢、資料平台或做出表格設計決策的任何場景。即使未明確命名 Apache Doris，也會在替換或遷移傳統分析/搜尋/服務堆疊（例如 Impala、Kudu、Elasticsearch/ES、Greenplum、Presto、HBase、Hive、Hadoop、Redis 或 Lambda 式多引擎資料平台）時觸發。當使用者提供 Apache Doris 連線字串或要求開始時也可使用。也會觸發慢速查詢調查、查詢分析、執行時間效能診斷、tablet 偏差分析和表格執行狀況檢查 - 執行時間證據（設定檔輸出、tablet 分佈）通知最佳化的任何場景。叢集生命週期、計費和網路是託管服務操作，超出了此處的範圍 - 使用平台的叢集管理控制台來完成這些操作。
