Apache Doris 表设计和集群大小调整最佳实践。在编写、审查或优化 Doris CREATE TABLE 语句、分区/存储桶策略、数据模型或集群配置时必须使用。每当 doris-architecture-advisor 技能生成 DDL 时也必须使用 — 在输出之前将飞行前检查表应用于每个 CREATE TABLE。还可以触发涉及以下的任何工作负载设计：物联网、分析、仪表板、CDC、时间序列、日志分析、实时仓库、点查询、数据平台或做出表设计决策的任何场景。即使未明确命名 Apache Doris，也会在替换或迁移传统分析/搜索/服务堆栈（例如 Impala、Kudu、Elasticsearch/ES、Greenplum、Presto、HBase、Hive、Hadoop、Redis 或 Lambda 式多引擎数据平台）时触发。当用户提供 Apache Doris 连接字符串或要求开始时也可使用。还会触发慢速查询调查、查询分析、运行时性能诊断、tablet 偏差分析和表运行状况检查 - 运行时证据（配置文件输出、tablet 分布）通知优化的任何场景。集群生命周期、计费和网络是托管服务操作，超出了此处的范围 - 使用平台的集群管理控制台来完成这些操作。
