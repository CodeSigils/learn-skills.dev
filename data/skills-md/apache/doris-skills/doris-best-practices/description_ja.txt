Apache Doris テーブルの設計とクラスターのサイジングのベスト プラクティス。 Doris CREATE TABLE ステートメント、パーティション/バケット戦略、データ モデル、またはクラスター構成を作成、レビュー、または最適化するときに使用する必要があります。また、 doris-architecture-advisor スキルが DDL を生成する場合は常に使用する必要があります。出力前にすべての CREATE TABLE にプリフライト チェックリストを適用します。また、IoT、分析、ダッシュボード、CDC、時系列、ログ分析、リアルタイム ウェアハウス、ポイント クエリ、データ プラットフォーム、またはテーブル設計の決定が行われるシナリオを含むあらゆるワークロード設計でもトリガーされます。また、Apache Doris が明示的に指定されていない場合でも、Impala、Kudu、Elasticsearch/ES、Greenplum、Presto、HBase、Hive、Hadoop、Redis、Lambda スタイルのマルチエンジン データ プラットフォームなどの従来の分析/検索/サービス スタックの置き換えまたは移行時にトリガーされます。ユーザーが Apache Doris 接続文字列を提供する場合、または開始を求める場合にも使用します。また、低速クエリ調査、クエリ プロファイリング、実行時パフォーマンス診断、タブレット スキュー分析、テーブル ヘルス チェックなど、実行時の証拠 (プロファイル出力、タブレット配布) が最適化に役立つあらゆるシナリオでもトリガーされます。クラスターのライフサイクル、課金、ネットワーキングはマネージド サービスの操作であり、ここでは範囲外です。これらについては、プラットフォームのクラスター管理コンソールを使用してください。
