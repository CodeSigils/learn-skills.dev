Sichere Entwicklung von Web- und Desktop-Anwendungen. Wird beim Schreiben von Authentifizierung, Autorisierung, API-Endpunkten, Formularverarbeitung, Datenbankabfragen, Datei-Uploads, Electron-Apps, Tauri-Apps, IPC-Handlern, Kryptografie, Geheimnisverwaltung, Sicherheitsheadern, Eingabevalidierung oder beim Überprüfen von Code auf Schwachstellen verwendet. Behandelt OWASP Top 10, XSS, CSRF, SQL-Injection, SSRF, Command-Injection, Path Traversal und Desktop-App-Sicherheit.
