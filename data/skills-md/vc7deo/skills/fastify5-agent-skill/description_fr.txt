Modèles de production Fastify 5 (TypeScript) : validation de schéma, plugins, routes typées, gestion des erreurs, renforcement de la sécurité, journalisation, tests avec injection et arrêt progressif. Utilisez cette compétence chaque fois que l'utilisateur crée une API Node.js/TypeScript avec Fastify, configure la validation d'itinéraire avec Zod ou TypeBox, crée des plugins Fastify, ajoute un middleware de sécurité (Helmet, CORS, limitation de débit), écrit des tests à l'aide de la méthode d'injection de Fastify ou configure un arrêt progressif. Déclenchez également lorsque l'utilisateur pose des questions sur les fournisseurs de type Fastify vs Express, Zod vs TypeBox ou toute question sur l'architecture du plugin Fastify.
