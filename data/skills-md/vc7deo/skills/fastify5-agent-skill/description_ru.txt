Шаблоны производственного Fastify 5 (TypeScript): проверка схемы, плагины, типизированные маршруты, обработка ошибок, усиление безопасности, ведение журналов, тестирование с помощью внедрения и корректное завершение работы. Используйте этот навык всякий раз, когда пользователь создает API Node.js/TypeScript с помощью Fastify, настраивает проверку маршрутов с помощью Zod или TypeBox, создает плагины Fastify, добавляет промежуточное программное обеспечение безопасности (Helmet, CORS, ограничение скорости), пишет тесты с использованием метода инъекции Fastify или настраивает корректное завершение работы. Также срабатывает, когда пользователь спрашивает о поставщиках типов Fastify и Express, Zod и TypeBox или любой вопрос об архитектуре плагина Fastify.
