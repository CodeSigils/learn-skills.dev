Patrones de Production Fastify 5 (TypeScript): validación de esquemas, complementos, rutas escritas, manejo de errores, refuerzo de seguridad, registro, pruebas con inyección y cierre ordenado. Utilice esta habilidad siempre que el usuario esté creando una API de Node.js/TypeScript con Fastify, configurando la validación de rutas con Zod o TypeBox, creando complementos de Fastify, agregando middleware de seguridad (Helmet, CORS, limitación de velocidad), escribiendo pruebas usando el método de inyección de Fastify o configurando un apagado elegante. También se activa cuando el usuario pregunta sobre los proveedores de tipo Fastify vs Express, Zod vs TypeBox o cualquier pregunta sobre la arquitectura del complemento Fastify.
