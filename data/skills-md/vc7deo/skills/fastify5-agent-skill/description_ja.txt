Production Fastify 5 (TypeScript) パターン: スキーマ検証、プラグイン、型付きルート、エラー処理、セキュリティ強化、ロギング、注入によるテスト、および正常なシャットダウン。ユーザーが Fastify を使用して Node.js/TypeScript API を構築する場合、Zod または TypeBox を使用してルート検証を設定する場合、Fastify プラグインを作成する場合、セキュリティ ミドルウェア (ヘルメット、CORS、レート制限) を追加する場合、Fastify の挿入メソッドを使用してテストを作成する場合、または正常なシャットダウンを構成する場合は常に、このスキルを使用します。また、ユーザーが Fastify と Express、Zod と TypeBox タイプ プロバイダー、または Fastify プラグイン アーキテクチャに関する質問をしたときにもトリガーされます。
