PHP/Laravel Lumen API エンドポイントを landau-api-main から aspire-fastify の Fastify 5 (TypeScript) に移行します。ユーザーが API コントローラー、ルート ファイル、またはエンドポイント グループをレガシー PHP バックエンドから移行したい場合は常に、このスキルを使用します。 「category.php を移行する」、「教室コントローラーを変換する」、「認証ルートを Fastify に移植する」、または「X のどのエンドポイントがフロントエンドで使用されており、移行が必要であるか」。また、ユーザーが landau-api-main 内のコントローラーまたはルート ファイルを参照し、それを aspire-fastify に取り込みたい場合にもトリガーされます。ユーザーが Fastify について言及せずに「移行 [コントローラー名]」とだけ言った場合でもトリガーされます。
