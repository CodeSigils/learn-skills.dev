Migra los puntos finales de PHP/Laravel Lumen API de landau-api-main a Fastify 5 (TypeScript) en aspire-fastify. Utilice esta habilidad siempre que el usuario desee migrar un controlador API, un archivo de ruta o un grupo de puntos finales desde el backend PHP heredado, por ejemplo. "migrar categoría.php", "convertir el controlador de las aulas", "portar las rutas de autenticación a Fastify" o "qué puntos finales de X se utilizan en la interfaz y necesitan migrarse". También se activa cuando el usuario hace referencia a cualquier controlador o archivo de ruta en landau-api-main y desea incorporarlo a aspire-fastify. Se activa incluso si el usuario simplemente dice "migrar [nombre del controlador]" sin mencionar Fastify.
