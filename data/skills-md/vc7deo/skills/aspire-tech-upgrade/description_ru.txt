Мигрирует конечные точки PHP/Laravel Lumen API из Landau-api-main в Fastify 5 (TypeScript) в aspire-fastify. Используйте этот навык всякий раз, когда пользователь хочет перенести контроллер API, файл маршрута или группу конечных точек из устаревшего бэкэнда PHP — например. «перенести категорию.php», «преобразовать контроллер классов», «перенести маршруты аутентификации в Fastify» или «какие конечные точки из X используются во внешнем интерфейсе и требуют миграции». Также срабатывает, когда пользователь ссылается на какой-либо контроллер или файл маршрута вlandau-api-main и хочет перенести его в aspire-fastify. Срабатывает, даже если пользователь просто говорит «перенести [имя контроллера]», не упоминая Fastify.
