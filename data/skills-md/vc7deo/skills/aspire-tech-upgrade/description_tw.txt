將 PHP/Laravel Lumen API 端點從 landau-api-main 遷移到 aspire-fastify 中的 Fastify 5 (TypeScript)。每當使用者想要從舊 PHP 後端遷移 API 控制器、路由檔案或端點群組時，請使用此技能 - 例如「遷移category.php」、「轉換教室控制器」、「將驗證路由移植到Fastify」或「X 中的哪些端點用於前端並需要遷移」。當使用者引用 landau-api-main 中的任何控制器或路由檔案並希望將其引入 aspire-fastify 時也會觸發。即使使用者只是說「遷移[控制器名稱]」而不提及 Fastify，也會觸發。
