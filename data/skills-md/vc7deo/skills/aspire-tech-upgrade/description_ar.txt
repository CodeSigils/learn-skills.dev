يقوم بترحيل نقاط نهاية PHP/Laravel Lumen API من Landau-api-main إلى Fastify 5 (TypeScript) في aspire-fastify. استخدم هذه المهارة عندما يريد المستخدم ترحيل وحدة تحكم API أو ملف التوجيه أو مجموعة نقاط النهاية من الواجهة الخلفية القديمة لـ PHP - على سبيل المثال. "ترحيل الفئة.php"، أو "تحويل وحدة التحكم في الفصول الدراسية"، أو "نقل مسارات المصادقة إلى Fastify"، أو "أي نقاط النهاية من X يتم استخدامها في الواجهة الأمامية وتحتاج إلى الترحيل". يتم تشغيله أيضًا عندما يشير المستخدم إلى أي وحدة تحكم أو ملف توجيه في Landau-api-main ويريد إحضاره إلى aspire-fastify. يتم تشغيله حتى إذا قال المستخدم فقط "ترحيل [اسم وحدة التحكم]" دون ذكر Fastify.
