Migra gli endpoint API PHP/Laravel Lumen da landau-api-main a Fastify 5 (TypeScript) in aspire-fastify. Utilizza questa competenza ogni volta che l'utente desidera migrare un controller API, un file di instradamento o un gruppo di endpoint dal backend PHP legacy, ad es. "migrate Category.php", "converti il ​​controller delle classi", "porta i percorsi di autenticazione su Fastify" o "quali endpoint da X vengono utilizzati nel frontend e necessitano di migrazione". Si attiva anche quando l'utente fa riferimento a qualsiasi controller o file di instradamento in landau-api-main e desidera portarlo in aspire-fastify. Si attiva anche se l'utente dice semplicemente "migra [nome controller]" senza menzionare Fastify.
