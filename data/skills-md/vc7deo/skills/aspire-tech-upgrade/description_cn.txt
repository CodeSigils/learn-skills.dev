将 PHP/Laravel Lumen API 端点从 landau-api-main 迁移到 aspire-fastify 中的 Fastify 5 (TypeScript)。每当用户想要从旧 PHP 后端迁移 API 控制器、路由文件或端点组时，请使用此技能 - 例如“迁移category.php”、“转换教室控制器”、“将身份验证路由移植到Fastify”或“X 中的哪些端点用于前端并需要迁移”。当用户引用 landau-api-main 中的任何控制器或路由文件并希望将其引入 aspire-fastify 时也会触发。即使用户只是说“迁移[控制器名称]”而不提及 Fastify，也会触发。
