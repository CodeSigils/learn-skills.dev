Migriert PHP/Laravel Lumen API-Endpunkte von landau-api-main nach Fastify 5 (TypeScript) in aspire-fastify. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen API-Controller, eine Routendatei oder eine Endpunktgruppe vom alten PHP-Backend migrieren möchte – z. B. „Kategorie.php migrieren“, „Klassenzimmer-Controller konvertieren“, „Authentifizierungsrouten auf Fastify portieren“ oder „Welche Endpunkte von X werden im Frontend verwendet und müssen migriert werden“. Wird auch ausgelöst, wenn der Benutzer auf einen Controller oder eine Routendatei in landau-api-main verweist und diese in aspire-fastify übernehmen möchte. Wird auch dann ausgelöst, wenn der Benutzer nur „[Controller-Name] migrieren“ sagt, ohne Fastify zu erwähnen.
