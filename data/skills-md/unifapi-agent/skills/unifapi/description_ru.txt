Используйте при работе с API общедоступных данных UnifAPI или сервером UnifAPI MCP: подключение клиентов OAuth MCP, обнаружение операций, вызов API социальных сетей/поиска/очистки/новостей, устранение неполадок аутентификации UnifAPI или выбор между MCP OAuth и резервным ключом API.
