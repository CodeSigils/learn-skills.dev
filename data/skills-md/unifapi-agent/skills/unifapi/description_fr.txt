À utiliser lorsque vous travaillez avec les API de données publiques UnifAPI ou le serveur UnifAPI MCP : connexion de clients OAuth MCP, découverte d'opérations, appel d'API sociales/recherche/scrape/news, dépannage de l'authentification UnifAPI ou choix entre MCP OAuth et le repli de clé API. Utilisez-le toujours avant de demander des informations d'identification UnifAPI ou d'appeler les outils UnifAPI.
