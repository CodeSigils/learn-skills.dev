Da utilizzare quando si lavora con le API di dati pubblici UnifAPI o il server MCP UnifAPI: connessione di client MCP OAuth, rilevamento di operazioni, chiamata di API social/ricerca/scrape/news, risoluzione dei problemi di autenticazione UnifAPI o decisione tra OAuth MCP e fallback della chiave API. Utilizzare sempre prima di richiedere le credenziali UnifAPI o chiamare gli strumenti UnifAPI.
