Richiamando Alibaba Cloud Yaoci Data Agent for Analytics tramite la riga di comando, gli utenti possono eseguire analisi dei dati basate sul linguaggio naturale sui database aziendali.  
Data Agent for Analytics è un agente di analisi dei dati intelligente lanciato dal team di database di Alibaba Cloud Yaoci per utenti aziendali, in grado di completare automaticamente l'analisi dei requisiti, la comprensione dei dati, gli approfondimenti analitici e la generazione di report basati su descrizioni in linguaggio naturale.  
Questo strumento supporta: la scoperta di risorse dati (istanze/database/tabelle) già ospitate in DMS, l'avvio di sessioni di query o analisi approfondite, il monitoraggio in tempo reale dell'avanzamento dell'esecuzione e l'ottenimento di conclusioni analitiche e file di report generati.
