Richiama Alibaba Cloud Yaochi Data Agent for Analytics tramite riga di comando per aiutare gli utenti a eseguire analisi dei dati basate sul linguaggio naturale sui database aziendali.
Data Agent for Analytics è un agente di analisi dei dati intelligente lanciato dal team del database Alibaba Cloud Yaochi per utenti aziendali; può completare automaticamente l'analisi dei requisiti, la comprensione dei dati, gli approfondimenti analitici e la generazione di report basati su descrizioni in linguaggio naturale.
Questo strumento supporta: la scoperta di risorse dati (istanze/database/tabelle) già ospitate in DMS, l'avvio di sessioni di query o analisi approfondite, il monitoraggio dell'avanzamento dell'esecuzione in tempo reale e l'ottenimento di conclusioni di analisi e file di report generati.
