قم باستدعاء Alibaba Cloud Yaochi Data Agent for Analytics عبر سطر الأوامر لمساعدة المستخدمين على إجراء تحليل البيانات المستند إلى اللغة الطبيعية في قواعد بيانات المؤسسة.
وكيل البيانات للتحليلات هو وكيل تحليل بيانات ذكي أطلقه فريق قاعدة بيانات Alibaba Cloud Yaochi لمستخدمي المؤسسات؛ يمكنه إكمال تحليل المتطلبات وفهم البيانات والرؤى التحليلية تلقائيًا وإنشاء التقارير بناءً على أوصاف اللغة الطبيعية.
تدعم هذه الأداة: اكتشاف موارد البيانات (المثيلات/قواعد البيانات/الجداول) المستضافة بالفعل في DMS، وبدء جلسات الاستعلام أو التحليل العميق، وتتبع تقدم التنفيذ في الوقت الفعلي، والحصول على استنتاجات التحليل وملفات التقارير التي تم إنشاؤها.
