من خلال استدعاء Alibaba Cloud Yaoci Data Agent for Analytics عبر سطر الأوامر، يمكن للمستخدمين إجراء تحليل البيانات المستندة إلى اللغة الطبيعية في قواعد بيانات المؤسسة.  
وكيل البيانات للتحليلات هو وكيل تحليل بيانات ذكي أطلقه فريق قاعدة بيانات Alibaba Cloud Yaoci لمستخدمي المؤسسات، وهو قادر على إكمال تحليل المتطلبات وفهم البيانات والرؤى التحليلية تلقائيًا وإنشاء التقارير بناءً على أوصاف اللغة الطبيعية.  
تدعم هذه الأداة: اكتشاف موارد البيانات (المثيلات/قاعدة البيانات/الجداول) المستضافة بالفعل في DMS، وبدء جلسات الاستعلام أو التحليل العميق، والتتبع الفوري لتقدم التنفيذ، والحصول على استنتاجات تحليلية وملفات التقارير التي تم إنشاؤها.
