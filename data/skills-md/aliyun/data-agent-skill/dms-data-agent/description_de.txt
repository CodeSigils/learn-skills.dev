Rufen Sie Alibaba Cloud Yaochi Data Agent for Analytics über die Befehlszeile auf, um Benutzern bei der Durchführung natürlichsprachlicher Datenanalysen in Unternehmensdatenbanken zu helfen.
Data Agent for Analytics ist ein intelligenter Datenanalyse-Agent, der vom Alibaba Cloud Yaochi-Datenbankteam für Unternehmensbenutzer eingeführt wurde. Es kann die Anforderungsanalyse, das Datenverständnis, analytische Erkenntnisse und die Berichterstellung automatisch auf der Grundlage von Beschreibungen in natürlicher Sprache durchführen.
Dieses Tool unterstützt: das Erkennen von Datenressourcen (Instanzen/Datenbanken/Tabellen), die bereits im DMS gehostet sind, das Initiieren von Abfrage- oder Tiefenanalysesitzungen, das Verfolgen des Ausführungsfortschritts in Echtzeit sowie das Erhalten von Analyseschlussfolgerungen und generierten Berichtsdateien.
