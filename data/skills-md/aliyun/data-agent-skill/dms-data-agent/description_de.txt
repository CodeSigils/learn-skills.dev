Durch Aufrufen des Alibaba Cloud Yaoci Data Agent for Analytics über die Befehlszeile können Benutzer eine natürlichsprachliche Datenanalyse für Unternehmensdatenbanken durchführen.  
Data Agent for Analytics ist ein intelligenter Datenanalyse-Agent, der vom Datenbankteam von Alibaba Cloud Yaoci für Unternehmensbenutzer eingeführt wurde und in der Lage ist, automatisch Anforderungsanalysen, Datenverständnis, analytische Erkenntnisse und Berichterstellung auf der Grundlage natürlichsprachlicher Beschreibungen durchzuführen.  
Dieses Tool unterstützt: das Erkennen von Datenressourcen (Instanzen/Datenbanken/Tabellen), die bereits im DMS gehostet sind, das Initiieren von Abfrage- oder Tiefenanalysesitzungen, die Verfolgung des Ausführungsfortschritts in Echtzeit sowie das Erhalten analytischer Schlussfolgerungen und generierter Berichtsdateien.
