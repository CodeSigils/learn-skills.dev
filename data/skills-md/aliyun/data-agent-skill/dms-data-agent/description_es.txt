Al invocar Alibaba Cloud Yaoci Data Agent for Analytics a través de la línea de comando, los usuarios pueden realizar análisis de datos basados ​​en lenguaje natural en bases de datos empresariales.  
Data Agent for Analytics es un agente de análisis de datos inteligente lanzado por el equipo de base de datos de Alibaba Cloud Yaoci para usuarios empresariales, capaz de completar automáticamente análisis de requisitos, comprensión de datos, conocimientos analíticos y generación de informes basados ​​en descripciones en lenguaje natural.  
Esta herramienta admite: descubrir recursos de datos (instancias/base de datos/tablas) ya alojados en DMS, iniciar consultas o sesiones de análisis profundo, realizar un seguimiento en tiempo real del progreso de la ejecución y obtener conclusiones analíticas y archivos de informes generados.
