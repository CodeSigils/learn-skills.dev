コマンドライン経由で Alibaba Cloud Yaoci Data Agent for Analytics を呼び出すことにより、ユーザーはエンタープライズ データベース上で自然言語主導のデータ分析を実行できます。  
Data Agent for Analytics は、Alibaba Cloud Yaoci のデータベース チームがエンタープライズ ユーザー向けに発表したインテリジェントなデータ分析エージェントで、要件分析、データ理解、分析洞察、自然言語記述に基づくレポート生成を自動的に完了できます。  
このツールは、DMS ですでにホストされているデータ リソース (インスタンス/データベース/テーブル) の検出、クエリまたは詳細分析セッションの開始、実行進行状況のリアルタイム追跡、分析結果と生成されたレポート ファイルの取得をサポートします。
