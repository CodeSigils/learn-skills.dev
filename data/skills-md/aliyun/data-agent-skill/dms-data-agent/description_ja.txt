コマンドライン経由で Alibaba Cloud Yaochi Data Agent for Analytics を呼び出し、ユーザーがエンタープライズ データベース上で自然言語主導のデータ分析を実行できるようにします。
Data Agent for Analytics は、Alibaba Cloud Yaochi データベース チームが企業ユーザー向けに開始したインテリジェントなデータ分析エージェントです。自然言語の記述に基づいて、要件分析、データ理解、分析洞察、レポート生成を自動的に完了できます。
このツールは、DMS ですでにホストされているデータ リソース (インスタンス/データベース/テーブル) の検出、クエリまたは詳細分析セッションの開始、実行の進行状況のリアルタイム追跡、分析結果と生成されたレポート ファイルの取得をサポートします。
