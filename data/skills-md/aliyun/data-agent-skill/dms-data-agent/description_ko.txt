명령줄을 통해 Analytics용 Alibaba Cloud Yaochi 데이터 에이전트를 호출하면 사용자가 엔터프라이즈 데이터베이스에서 자연어 기반 데이터 분석을 수행할 수 있습니다.
Data Agent for Analytics는 Alibaba Cloud Yaochi 데이터베이스 팀이 기업 사용자를 위해 출시한 지능형 데이터 분석 에이전트입니다. 자연어 설명을 기반으로 요구 사항 분석, 데이터 이해, 분석 통찰력 및 보고서 생성을 자동으로 완료할 수 있습니다.
이 도구는 DMS에 이미 호스팅된 데이터 리소스(인스턴스/데이터베이스/테이블) 검색, 쿼리 또는 심층 분석 세션 시작, 실행 진행 상황 실시간 추적, 분석 결론 및 생성된 보고서 파일 획득을 지원합니다.
