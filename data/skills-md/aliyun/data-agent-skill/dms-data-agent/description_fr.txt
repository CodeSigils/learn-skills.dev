Invoquez Alibaba Cloud Yaochi Data Agent for Analytics via la ligne de commande pour aider les utilisateurs à effectuer une analyse de données en langage naturel sur les bases de données d'entreprise.
Data Agent for Analytics est un agent d'analyse de données intelligent lancé par l'équipe de base de données Alibaba Cloud Yaochi pour les utilisateurs d'entreprise ; il peut effectuer automatiquement l'analyse des exigences, la compréhension des données, les informations analytiques et la génération de rapports basés sur des descriptions en langage naturel.
Cet outil prend en charge : la découverte de ressources de données (instances/bases de données/tables) déjà hébergées dans DMS, le lancement de sessions de requêtes ou d'analyse approfondie, le suivi de la progression de l'exécution en temps réel et l'obtention de conclusions d'analyse et de fichiers de rapport générés.
