En appelant Alibaba Cloud Yaoci Data Agent for Analytics via la ligne de commande, les utilisateurs peuvent effectuer une analyse de données basée sur le langage naturel sur les bases de données d'entreprise.  
Data Agent for Analytics est un agent d'analyse de données intelligent lancé par l'équipe de base de données d'Alibaba Cloud Yaoci pour les utilisateurs d'entreprise, capable de réaliser automatiquement l'analyse des exigences, la compréhension des données, les informations analytiques et la génération de rapports basés sur des descriptions en langage naturel.  
Cet outil prend en charge : la découverte de ressources de données (instances/base de données/tables) déjà hébergées dans DMS, le lancement de sessions de requêtes ou d'analyse approfondie, le suivi en temps réel de la progression de l'exécution et l'obtention de conclusions analytiques et de fichiers de rapport générés.
