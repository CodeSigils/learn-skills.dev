By invoking Alibaba Cloud Yaoci Data Agent for Analytics via the command line, users can perform natural language‑driven data analysis on enterprise databases.  
Data Agent for Analytics is an intelligent data analysis agent launched by Alibaba Cloud Yaoci’s database team for enterprise users, capable of automatically completing requirement analysis, data understanding, analytical insights, and report generation based on natural language descriptions.  
This tool supports: discovering data resources (instances/database/tables) already hosted in DMS, initiating query or deep‑analysis sessions, real‑time tracking of execution progress, and obtaining analytical conclusions and generated report files.
