Invoke Alibaba Cloud Yaochi Data Agent for Analytics via command line to help users perform natural-language-driven data analysis on enterprise databases.
Data Agent for Analytics is an intelligent data-analysis agent launched by the Alibaba Cloud Yaochi database team for enterprise users; it can automatically complete requirement analysis, data understanding, analytic insights, and report generation based on natural-language descriptions.
This tool supports: discovering data resources (instances/databases/tables) already hosted in DMS, initiating query or deep-analysis sessions, tracking execution progress in real time, and obtaining analysis conclusions and generated report files.
