Вызывая агент данных Alibaba Cloud Yaoci для аналитики через командную строку, пользователи могут выполнять анализ данных на естественном языке в корпоративных базах данных.  
Агент данных для аналитики — это интеллектуальный агент анализа данных, запущенный командой баз данных Alibaba Cloud Yaoci для корпоративных пользователей, способный автоматически выполнять анализ требований, понимание данных, аналитическую информацию и создание отчетов на основе описаний на естественном языке.  
Этот инструмент поддерживает: обнаружение ресурсов данных (экземпляров/баз данных/таблиц), уже размещенных в DMS, инициирование сеансов запросов или глубокого анализа, отслеживание хода выполнения в реальном времени, а также получение аналитических заключений и созданных файлов отчетов.
