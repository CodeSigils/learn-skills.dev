Вызовите агент данных Alibaba Cloud Yaoshi для аналитики через командную строку, чтобы помочь пользователям выполнять анализ данных на естественном языке в корпоративных базах данных.
Агент данных для аналитики — это аналитический агент для корпоративных пользователей, запущенный командой базы данных Alibaba Cloud Yaoshi; он может автоматически выполнять анализ требований, понимание данных, аналитическую информацию и создание отчетов на основе описаний на естественном языке.
Этот инструмент поддерживает: обнаружение ресурсов данных (экземпляров/баз данных/таблиц), уже управляемых в DMS, инициирование сеансов запросов или глубокого анализа, отслеживание хода выполнения в режиме реального времени, а также получение аналитических заключений и сгенерированных файлов отчетов.
