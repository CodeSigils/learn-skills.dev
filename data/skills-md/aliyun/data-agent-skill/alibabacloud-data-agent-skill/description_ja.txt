コマンドライン経由で Alibaba Cloud Yaochi Data Agent for Analytics を呼び出し、ユーザーが企業データベース上で自然言語駆動のデータ分析を実行できるようにします。
Data Agent for Analytics は、Alibaba Cloud Yaochi データベース チームが企業ユーザー向けに開始したインテリジェントなデータ分析エージェントです。自然言語の記述に基づいて、要件分析、データ理解、分析洞察、レポート生成を自動的に完了します。
このツールは、DMS ですでにホストされているデータ リソース (インスタンス/データベース/テーブル) の検出、Q&A または詳細分析セッションの開始、実行の進行状況のリアルタイム追跡、生成されたレポート ファイルとともに分析の結論の取得をサポートします。
このスキルは、ユーザーがデータベースのクエリ、データ傾向の分析、データ レポートの生成、自然言語での質問、または「データ エージェント」、「データ分析」、「データベース クエリ」、「SQL 分析」、または「データ インサイト」について言及する必要がある場合に使用します。
