コマンドライン経由で Alibaba Cloud Yaoci Data Agent for Analytics を呼び出し、ユーザーが企業データベース上で自然言語駆動のデータ分析を実行できるようにします。

Data Agent for Analytics は、Alibaba Cloud Yaoci のデータベース チームがエンタープライズ ユーザー向けに発表したインテリジェントなデータ分析エージェントで、要件分析、データ理解、分析洞察、自然言語記述に基づくレポート生成を自動的に完了できます。

このツールは、DMS ですでにホストされているデータ リソース (インスタンス/データベース/テーブル) の検出、クエリまたは詳細分析セッションの開始、実行進行状況のリアルタイム追跡、分析結果の取得、レポート ファイルの生成をサポートします。

このスキルは、ユーザーがデータベースのクエリ、データ傾向の分析、データ レポートの生成、自然言語での質問、または「データ エージェント」、「データ分析」、「データベース クエリ」、「SQL 分析」、または「データ インサイト」について言及する必要がある場合に使用します。
