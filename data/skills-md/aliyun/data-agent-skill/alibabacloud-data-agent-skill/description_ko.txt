명령줄을 통해 Alibaba Cloud Yaoshi Data Agent for Analytics를 호출하면 사용자가 기업 데이터베이스에서 자연어 기반 데이터 분석을 수행할 수 있습니다.
Data Agent for Analytics는 Alibaba Cloud의 Yaoshi 데이터베이스 팀이 기업 사용자를 위해 출시한 지능형 데이터 분석 에이전트입니다. 자연어 설명을 기반으로 요구 사항 분석, 데이터 이해, 분석 통찰력 및 보고서 생성을 자동으로 완료합니다.

사용자가 데이터베이스 쿼리, 데이터 추세 분석, 데이터 보고서 생성, 자연어로 질문 또는 "데이터 에이전트", "데이터 분석", "데이터베이스 쿼리", "SQL 분석" 또는 "데이터 통찰력"을 언급해야 할 때 이 기술을 사용하세요.
