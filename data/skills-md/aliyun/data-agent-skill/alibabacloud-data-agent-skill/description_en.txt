Invoke Alibaba Cloud Yaoci Data Agent for Analytics via the command line to help users perform natural-language-driven data analysis on enterprise databases.

Data Agent for Analytics is an intelligent data analysis agent launched by Alibaba Cloud Yaoci’s database team for enterprise users, capable of automatically completing requirement analysis, data understanding, analytical insights, and report generation based on natural language descriptions.

This tool supports: discovering data resources (instances/databases/tables) already hosted in DMS, initiating query or deep‑analysis sessions, real‑time tracking of execution progress, retrieving analytical conclusions, and generating report files.

Use this skill when users need to query a database, analyze data trends, generate data reports, ask questions in natural language, or mention “Data Agent,” “data analysis,” “database query,” “SQL analysis,” or “data insight.”
