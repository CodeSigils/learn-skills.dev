Invoke Alibaba Cloud Yaochi Data Agent for Analytics via the command line to help users perform natural-language-driven data analysis on enterprise databases.
Data Agent for Analytics is an intelligent data-analysis agent launched by the Alibaba Cloud Yaochi database team for enterprise users; it automatically completes requirements analysis, data understanding, analytical insights, and report generation based on natural-language descriptions.
This tool supports: discovering data resources (instances/databases/tables) already hosted in DMS, initiating Q&A or deep-analysis sessions, tracking execution progress in real time, and obtaining analysis conclusions along with generated report files.
Use this Skill when the user needs to query databases, analyze data trends, generate data reports, ask questions in natural language, or mentions “Data Agent,” “data analysis,” “database query,” “SQL analysis,” or “data insight.”
