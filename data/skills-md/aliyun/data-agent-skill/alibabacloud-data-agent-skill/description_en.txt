Invoke Alibaba Cloud Yaoshi Data Agent for Analytics via the command line to help users perform natural-language-driven data analysis on enterprise databases.
Data Agent for Analytics is an intelligent data-analysis agent launched by Alibaba Cloud's Yaoshi database team for enterprise users; it automatically completes requirement analysis, data comprehension, analytical insights, and report generation based on natural language descriptions.
This tool supports: discovering data resources (instances/databases/tables) already managed in DMS, initiating Q&A or deep-analysis sessions, tracking execution progress in real time, and obtaining analytical conclusions and generated report files.
Use this Skill when users need to query databases, analyze data trends, generate data reports, ask questions in natural language, or mention "Data Agent", "data analysis", "database query", "SQL analysis", or "data insights".
