قم باستدعاء Alibaba Cloud Yaoshi Data Agent for Analytics عبر سطر الأوامر لمساعدة المستخدمين على إجراء تحليل البيانات المستند إلى اللغة الطبيعية في قواعد بيانات المؤسسة.
وكيل البيانات للتحليلات هو وكيل تحليل بيانات ذكي أطلقه فريق قاعدة بيانات Yaoshi التابع لشركة Alibaba Cloud لمستخدمي المؤسسات؛ يقوم تلقائيًا بإكمال تحليل المتطلبات وفهم البيانات والرؤى التحليلية وإنشاء التقارير بناءً على أوصاف اللغة الطبيعية.
تدعم هذه الأداة: اكتشاف موارد البيانات (المثيلات/قواعد البيانات/الجداول) المُدارة بالفعل في DMS، وبدء جلسات الأسئلة والأجوبة أو التحليل العميق، وتتبع تقدم التنفيذ في الوقت الفعلي، والحصول على استنتاجات تحليلية وملفات التقارير التي تم إنشاؤها.
استخدم هذه المهارة عندما يحتاج المستخدمون إلى الاستعلام عن قواعد البيانات، أو تحليل اتجاهات البيانات، أو إنشاء تقارير البيانات، أو طرح الأسئلة باللغة الطبيعية، أو ذكر "وكيل البيانات"، أو "تحليل البيانات"، أو "الاستعلام عن قاعدة البيانات"، أو "تحليل SQL"، أو "رؤى البيانات".
