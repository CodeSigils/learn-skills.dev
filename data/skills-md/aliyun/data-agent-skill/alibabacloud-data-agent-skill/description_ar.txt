قم باستدعاء Alibaba Cloud Yaoshi Data Agent for Analytics عبر سطر الأوامر لمساعدة المستخدمين على إجراء تحليل البيانات المستند إلى اللغة الطبيعية في قواعد بيانات المؤسسة.  
وكيل البيانات للتحليلات هو وكيل تحليل بيانات ذكي أطلقه فريق قاعدة بيانات Alibaba Cloud Yaoshi لمستخدمي المؤسسات؛ يمكنه إكمال تحليل المتطلبات وفهم البيانات والرؤى التحليلية تلقائيًا وإنشاء التقارير من أوصاف اللغة الطبيعية.  
تدعم هذه الأداة: اكتشاف موارد البيانات (المثيلات/قواعد البيانات/الجداول) المستضافة بالفعل في DMS، وبدء جلسات الأسئلة والأجوبة أو التحليل العميق، وتتبع تقدم التنفيذ في الوقت الفعلي، والحصول على استنتاجات تحليلية وملفات التقارير التي تم إنشاؤها.  
استخدم هذه المهارة عندما يحتاج المستخدم إلى الاستعلام عن قاعدة بيانات، أو تحليل اتجاهات البيانات، أو إنشاء تقارير بيانات، أو طرح أسئلة باللغة الطبيعية، أو عندما يذكر "وكيل البيانات"، أو "تحليل البيانات"، أو "استعلام قاعدة البيانات"، أو "تحليل SQL"، أو "رؤى البيانات".
