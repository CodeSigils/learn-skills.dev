قم باستدعاء Alibaba Cloud Yaoci Data Agent for Analytics عبر سطر الأوامر لمساعدة المستخدمين على إجراء تحليل البيانات المستند إلى اللغة الطبيعية في قواعد بيانات المؤسسة.

وكيل البيانات للتحليلات هو وكيل تحليل بيانات ذكي أطلقه فريق قاعدة بيانات Alibaba Cloud Yaoci لمستخدمي المؤسسات، وهو قادر على إكمال تحليل المتطلبات وفهم البيانات والرؤى التحليلية تلقائيًا وإنشاء التقارير بناءً على أوصاف اللغة الطبيعية.

تدعم هذه الأداة: اكتشاف موارد البيانات (المثيلات/قواعد البيانات/الجداول) المستضافة بالفعل في DMS، وبدء جلسات الاستعلام أو التحليل العميق، والتتبع الفوري لتقدم التنفيذ، واسترداد الاستنتاجات التحليلية، وإنشاء ملفات التقارير.

استخدم هذه المهارة عندما يحتاج المستخدمون إلى الاستعلام عن قاعدة بيانات، أو تحليل اتجاهات البيانات، أو إنشاء تقارير البيانات، أو طرح الأسئلة باللغة الطبيعية، أو ذكر "وكيل البيانات"، أو "تحليل البيانات"، أو "الاستعلام عن قاعدة البيانات"، أو "تحليل SQL"، أو "رؤية البيانات".
