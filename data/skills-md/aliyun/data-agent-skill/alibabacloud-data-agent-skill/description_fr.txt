Appelez Alibaba Cloud Yaoshi Data Agent for Analytics via la ligne de commande pour aider les utilisateurs à effectuer une analyse de données en langage naturel sur les bases de données d'entreprise.
Data Agent for Analytics est un agent d'analyse de données intelligent lancé par l'équipe de base de données Yaoshi d'Alibaba Cloud pour les utilisateurs d'entreprise ; il effectue automatiquement l'analyse des exigences, la compréhension des données, les informations analytiques et la génération de rapports basés sur des descriptions en langage naturel.
Cet outil prend en charge : la découverte de ressources de données (instances/bases de données/tables) déjà gérées dans DMS, le lancement de sessions de questions-réponses ou d'analyse approfondie, le suivi de la progression de l'exécution en temps réel et l'obtention de conclusions analytiques et de fichiers de rapport générés.
Utilisez cette compétence lorsque les utilisateurs ont besoin d'interroger des bases de données, d'analyser les tendances des données, de générer des rapports de données, de poser des questions en langage naturel ou de mentionner « Agent de données », « analyse de données », « requête de base de données », « analyse SQL » ou « informations sur les données ».
