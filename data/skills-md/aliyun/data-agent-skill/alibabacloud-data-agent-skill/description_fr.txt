Appelez Alibaba Cloud Yaoci Data Agent for Analytics via la ligne de commande pour aider les utilisateurs à effectuer une analyse de données en langage naturel sur les bases de données d'entreprise.

Data Agent for Analytics est un agent d'analyse de données intelligent lancé par l'équipe de base de données d'Alibaba Cloud Yaoci pour les utilisateurs d'entreprise, capable de réaliser automatiquement l'analyse des exigences, la compréhension des données, les informations analytiques et la génération de rapports basés sur des descriptions en langage naturel.

Cet outil prend en charge : la découverte de ressources de données (instances/bases de données/tables) déjà hébergées dans DMS, le lancement de sessions de requêtes ou d'analyse approfondie, le suivi en temps réel de la progression de l'exécution, la récupération de conclusions analytiques et la génération de fichiers de rapport.

Utilisez cette compétence lorsque les utilisateurs ont besoin d'interroger une base de données, d'analyser les tendances des données, de générer des rapports de données, de poser des questions en langage naturel ou de mentionner « Agent de données », « analyse de données », « requête de base de données », « analyse SQL » ou « aperçu des données ».
