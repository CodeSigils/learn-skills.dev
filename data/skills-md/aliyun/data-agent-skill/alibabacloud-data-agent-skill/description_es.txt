Invoque Alibaba Cloud Yaoci Data Agent for Analytics a través de la línea de comando para ayudar a los usuarios a realizar análisis de datos basados ​​en lenguaje natural en bases de datos empresariales.

Data Agent for Analytics es un agente de análisis de datos inteligente lanzado por el equipo de base de datos de Alibaba Cloud Yaoci para usuarios empresariales, capaz de completar automáticamente análisis de requisitos, comprensión de datos, conocimientos analíticos y generación de informes basados ​​en descripciones en lenguaje natural.

Esta herramienta admite: descubrir recursos de datos (instancias/bases de datos/tablas) ya alojados en DMS, iniciar consultas o sesiones de análisis profundo, realizar un seguimiento en tiempo real del progreso de la ejecución, recuperar conclusiones analíticas y generar archivos de informes.

Utilice esta habilidad cuando los usuarios necesiten consultar una base de datos, analizar tendencias de datos, generar informes de datos, hacer preguntas en lenguaje natural o mencionar "Agente de datos", "análisis de datos", "consulta de base de datos", "análisis SQL" o "conocimiento de datos".
