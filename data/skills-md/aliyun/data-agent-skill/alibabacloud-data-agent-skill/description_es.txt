Invoque Alibaba Cloud Yaochi Data Agent for Analytics a través de la línea de comando para ayudar a los usuarios a realizar análisis de datos basados ​​en lenguaje natural en bases de datos empresariales.
Data Agent for Analytics es un agente de análisis de datos inteligente lanzado por el equipo de base de datos de Alibaba Cloud Yaochi para usuarios empresariales; completa automáticamente el análisis de requisitos, la comprensión de datos, la información analítica y la generación de informes basados ​​en descripciones en lenguaje natural.
Esta herramienta admite: descubrir recursos de datos (instancias/bases de datos/tablas) ya alojados en DMS, iniciar sesiones de preguntas y respuestas o análisis profundo, rastrear el progreso de la ejecución en tiempo real y obtener conclusiones de análisis junto con archivos de informes generados.
Utilice esta habilidad cuando el usuario necesite consultar bases de datos, analizar tendencias de datos, generar informes de datos, hacer preguntas en lenguaje natural o mencione "Agente de datos", "análisis de datos", "consulta de base de datos", "análisis SQL" o "conocimiento de datos".
