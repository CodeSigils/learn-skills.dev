Вызовите агент данных Alibaba Cloud Yaotai для аналитики через командную строку, чтобы помочь пользователям выполнять анализ данных на естественном языке в корпоративных базах данных.
Агент данных для аналитики — это интеллектуальный агент анализа данных, запущенный командой базы данных Alibaba Cloud Yaotai для корпоративных пользователей; он автоматически выполняет анализ требований, понимание данных, аналитическую информацию и создание отчетов на основе описаний на естественном языке.
Этот инструмент поддерживает: обнаружение ресурсов данных (экземпляров/баз данных/таблиц), уже размещенных в DMS, инициирование сеансов вопросов и ответов или глубокого анализа, отслеживание хода выполнения в режиме реального времени и получение аналитических заключений вместе с созданными файлами отчетов.
Используйте этот навык, когда пользователям необходимо запрашивать базы данных, анализировать тенденции данных, создавать отчеты о данных, задавать вопросы на естественном языке или упоминать «агент данных», «анализ данных», «запрос к базе данных», «анализ SQL» или «аналитику данных».
