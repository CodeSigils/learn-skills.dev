Вызовите агент данных Alibaba Cloud Yaoci для аналитики через командную строку, чтобы помочь пользователям выполнять анализ данных на естественном языке в корпоративных базах данных.

Агент данных для аналитики — это интеллектуальный агент анализа данных, запущенный командой баз данных Alibaba Cloud Yaoci для корпоративных пользователей, способный автоматически выполнять анализ требований, понимание данных, аналитическую информацию и создание отчетов на основе описаний на естественном языке.

Этот инструмент поддерживает: обнаружение ресурсов данных (экземпляров/баз данных/таблиц), уже размещенных в DMS, инициирование сеансов запросов или глубокого анализа, отслеживание хода выполнения в реальном времени, получение аналитических заключений и создание файлов отчетов.

Используйте этот навык, когда пользователям нужно запросить базу данных, проанализировать тенденции данных, создать отчеты о данных, задать вопросы на естественном языке или упомянуть «агент данных», «анализ данных», «запрос к базе данных», «анализ SQL» или «анализ данных».
