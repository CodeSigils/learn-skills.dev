Rufen Sie Alibaba Cloud Yaoshi Data Agent for Analytics über die Befehlszeile auf, um Benutzern bei der Durchführung natürlichsprachlicher Datenanalysen für Unternehmensdatenbanken zu helfen.
Data Agent for Analytics ist ein intelligenter Datenanalyse-Agent, der vom Yaoshi-Datenbankteam von Alibaba Cloud für Unternehmensbenutzer entwickelt wurde. Es führt automatisch die Anforderungsanalyse, das Datenverständnis, analytische Erkenntnisse und die Berichterstellung auf der Grundlage natürlichsprachlicher Beschreibungen durch.
Dieses Tool unterstützt: das Erkennen von Datenressourcen (Instanzen/Datenbanken/Tabellen), die bereits im DMS verwaltet werden, das Initiieren von Frage-und-Antwort-Sitzungen oder eingehenden Analysesitzungen, das Verfolgen des Ausführungsfortschritts in Echtzeit sowie das Erhalten analytischer Schlussfolgerungen und generierter Berichtsdateien.
Verwenden Sie diesen Skill, wenn Benutzer Datenbanken abfragen, Datentrends analysieren, Datenberichte erstellen, Fragen in natürlicher Sprache stellen oder „Datenagent“, „Datenanalyse“, „Datenbankabfrage“, „SQL-Analyse“ oder „Dateneinblicke“ erwähnen müssen.
