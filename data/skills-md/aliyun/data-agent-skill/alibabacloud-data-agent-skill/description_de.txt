Rufen Sie Alibaba Cloud Yaoci Data Agent for Analytics über die Befehlszeile auf, um Benutzern bei der Durchführung natürlichsprachlicher Datenanalysen für Unternehmensdatenbanken zu helfen.

Data Agent for Analytics ist ein intelligenter Datenanalyse-Agent, der vom Datenbankteam von Alibaba Cloud Yaoci für Unternehmensbenutzer eingeführt wurde und in der Lage ist, automatisch Anforderungsanalysen, Datenverständnis, analytische Erkenntnisse und Berichterstellung auf der Grundlage natürlichsprachlicher Beschreibungen durchzuführen.

Dieses Tool unterstützt: das Erkennen von Datenressourcen (Instanzen/Datenbanken/Tabellen), die bereits im DMS gehostet sind, das Initiieren von Abfrage- oder Tiefenanalysesitzungen, das Verfolgen des Ausführungsfortschritts in Echtzeit, das Abrufen von analytischen Schlussfolgerungen und das Erstellen von Berichtsdateien.

Verwenden Sie diese Fähigkeit, wenn Benutzer eine Datenbank abfragen, Datentrends analysieren, Datenberichte erstellen, Fragen in natürlicher Sprache stellen oder „Datenagent“, „Datenanalyse“, „Datenbankabfrage“, „SQL-Analyse“ oder „Dateneinblick“ erwähnen müssen.
