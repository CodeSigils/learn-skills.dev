Rufen Sie Alibaba Cloud Yaochi Data Agent for Analytics über die Befehlszeile auf, um Benutzern bei der Durchführung natürlichsprachlicher Datenanalysen für Unternehmensdatenbanken zu helfen.
Data Agent for Analytics ist ein intelligenter Datenanalyse-Agent, der vom Alibaba Cloud Yaochi-Datenbankteam für Unternehmensbenutzer eingeführt wurde. Es vervollständigt automatisch die Anforderungsanalyse, das Datenverständnis, analytische Erkenntnisse und die Berichterstellung auf der Grundlage von Beschreibungen in natürlicher Sprache.
Dieses Tool unterstützt: das Erkennen von Datenressourcen (Instanzen/Datenbanken/Tabellen), die bereits im DMS gehostet sind, das Initiieren von Frage-und-Antwort- oder Tiefenanalysesitzungen, das Verfolgen des Ausführungsfortschritts in Echtzeit und das Erhalten von Analyseschlussfolgerungen zusammen mit generierten Berichtsdateien.
Verwenden Sie diese Fähigkeit, wenn der Benutzer Datenbanken abfragen, Datentrends analysieren, Datenberichte erstellen, Fragen in natürlicher Sprache stellen muss oder „Datenagent“, „Datenanalyse“, „Datenbankabfrage“, „SQL-Analyse“ oder „Dateneinblick“ erwähnt.
