Déployez, démarrez et mettez à jour le serveur MCP Alibaba Cloud Observability (阿里云可观测 MCP Server). Utilisez cette compétence chaque fois que l'utilisateur mentionne le déploiement, l'installation, le démarrage, la mise à jour ou la configuration du serveur d'observabilité MCP, des outils Alibaba Cloud SLS/CMS MCP, ou souhaite connecter la surveillance Alibaba Cloud à son agent de codage IA. Se déclenche également lorsque l'utilisateur dit des choses telles que « configurer le serveur MCP », « installer les outils d'observabilité », « déployer aliyun MCP », « configurer SLS MCP » ou « mettre à jour les outils du serveur MCP ».
