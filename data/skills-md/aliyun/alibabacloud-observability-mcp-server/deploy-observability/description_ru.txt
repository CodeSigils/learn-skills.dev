Разверните, запустите и обновите сервер MCP Alibaba Cloud Observability (阿里云可观测 MCP Server). Используйте этот навык всякий раз, когда пользователь упоминает о развертывании, установке, запуске, обновлении или настройке сервера наблюдаемости MCP, инструментов Alibaba Cloud SLS/CMS MCP или хочет подключить мониторинг Alibaba Cloud к своему агенту кодирования AI. Также срабатывает, когда пользователь говорит такие вещи, как «настроить сервер MCP», «установить инструменты наблюдения», «развернуть aliyun MCP», «настроить SLS MCP» или «обновить инструменты сервера MCP».
