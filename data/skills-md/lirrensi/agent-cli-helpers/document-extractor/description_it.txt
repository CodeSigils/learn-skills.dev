Converti file difficili da leggere in Markdown trasparente con MarkItDown. Utilizzare per input PDF, Word, PowerPoint, Excel, immagini, audio, HTML, CSV, JSON, XML, ZIP, EPUB, Outlook e YouTube. Controlla se `markitdown` è installato prima, preferisci `uv tool install`, torna a `pipx` e usa i documenti upstream quando necessario.
