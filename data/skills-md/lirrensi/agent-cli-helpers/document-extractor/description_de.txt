Konvertieren Sie schwer lesbare Dateien mit MarkItDown in klares Markdown. Zur Verwendung für PDF-, Word-, PowerPoint-, Excel-, Bilder-, Audio-, HTML-, CSV-, JSON-, XML-, ZIP-, EPUB-, Outlook- und YouTube-Eingaben. Überprüfen Sie, ob „markitdown“ zuerst installiert ist, bevorzugen Sie „uv tool install“, greifen Sie auf „pipx“ zurück und verwenden Sie bei Bedarf die Upstream-Dokumente.
