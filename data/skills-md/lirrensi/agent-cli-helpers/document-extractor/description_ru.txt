Преобразуйте трудночитаемые файлы в чистый Markdown с помощью MarkItDown. Используйте для ввода PDF, Word, PowerPoint, Excel, изображений, аудио, HTML, CSV, JSON, XML, ZIP, EPUB, Outlook и YouTube. Проверьте, установлен ли сначала markitdown, отдайте предпочтение uvtool install, вернитесь к pipx и при необходимости используйте исходную документацию.
