Convertissez les fichiers difficiles à lire en Markdown clair avec MarkItDown. À utiliser pour les entrées PDF, Word, PowerPoint, Excel, images, audio, HTML, CSV, JSON, XML, ZIP, EPUB, Outlook et YouTube. Vérifiez si « markitdown » est installé en premier, préférez « uv tool install », revenez à « pipx » et utilisez la documentation en amont si nécessaire.
