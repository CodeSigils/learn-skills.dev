Eine Metakompetenz für die Recherche aktueller Best Practices und das Treffen von Technologieentscheidungen. Verwenden Sie diese Option, wenn der Benutzer nach Best Practices, Codierungsstandards oder Mustern fragt oder zwischen Technologien für JEDEN Stack wählen muss. Triggern Sie auf „Best Practices“, „Branchenstandard“, „empfohlene Vorgehensweise“, „Wie machen die Leute normalerweise X“, „Ist das die richtige Vorgehensweise“, „Sollte ich X oder Y verwenden“ oder „Überprüfe meinen Code anhand von Best Practices“. Wird auch ausgelöst, wenn der Benutzer Code einfügt und fragt, ob dieser korrekt oder gut strukturiert ist. Es sind keine Fertigkeiten pro Technologie erforderlich – diese Fertigkeit ist für alle Stapel eigenständig.
