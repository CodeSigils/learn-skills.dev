مهارة وصفية للبحث عن أفضل الممارسات الحالية واتخاذ القرارات التكنولوجية. يُستخدم عندما يسأل المستخدم عن أفضل الممارسات أو معايير الترميز أو الأنماط أو يحتاج إلى الاختيار بين التقنيات لأي مكدس. قم بتشغيل "أفضل الممارسات"، أو "معيار الصناعة"، أو "الطريقة الموصى بها"، أو "كيف يفعل الأشخاص عادةً X"، أو "هل هذه هي الطريقة الصحيحة"، أو "هل يجب أن أستخدم X أو Y"، أو "مراجعة الكود الخاص بي وفقًا لأفضل الممارسات". يتم تشغيله أيضًا عندما يلصق المستخدم التعليمات البرمجية ويسأل عما إذا كانت صحيحة أو جيدة التنظيم. ليست هناك حاجة إلى مهارات خاصة بالتكنولوجيا — فهذه المهارة قائمة بذاتها لجميع الأكوام.
