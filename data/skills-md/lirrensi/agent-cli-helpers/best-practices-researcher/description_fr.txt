Une méta-compétence pour rechercher les meilleures pratiques actuelles et prendre des décisions technologiques. À utiliser lorsque l'utilisateur pose des questions sur les meilleures pratiques, les normes de codage, les modèles ou doit choisir entre des technologies pour TOUTE pile. Déclenchez sur les « meilleures pratiques », les « normes de l'industrie », la « méthode recommandée », « comment les gens font habituellement X », « est-ce la bonne façon », « dois-je utiliser X ou Y » ou « réviser mon code par rapport aux meilleures pratiques ». Se déclenche également lorsque l'utilisateur colle du code et demande s'il est correct ou bien structuré. Aucune compétence technologique n'est requise : cette compétence est autonome pour toutes les piles.
