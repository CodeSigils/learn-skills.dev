Una metahabilidad para investigar las mejores prácticas actuales y tomar decisiones tecnológicas. Úselo cuando el usuario pregunte sobre las mejores prácticas, estándares de codificación, patrones o necesite elegir entre tecnologías para CUALQUIER pila. Active "mejores prácticas", "estándar de la industria", "forma recomendada", "cómo suele hacer la gente X", "es esta la forma correcta", "debería usar X o Y" o "revisar mi código según las mejores prácticas". También se activa cuando el usuario pega código y pregunta si es correcto o está bien estructurado. No se necesitan habilidades por tecnología: esta habilidad es independiente para todas las pilas.
