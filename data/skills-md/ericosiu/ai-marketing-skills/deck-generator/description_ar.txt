قم بإنشاء عروض تقديمية احترافية باستخدام الصور التي تم إنشاؤها بواسطة الذكاء الاصطناعي. استخدمه عندما يُطلب منك إنشاء عرض تقديمي أو عرض تقديمي أو عرض تقديمي عرضي أو شرائح. يدعم الإعدادات المسبقة للأسلوب (السبورة، والشركات، والحد الأدنى، وما إلى ذلك). يستخدم Imagen 4.0 API لإنشاء الصور وGoogle Slides API للتجميع. يُنتج مجموعات كاملة من مواصفات محتوى تخفيض السعر في دقائق.
