Используйте этот навык, когда пользователь хочет прочитать или выполнить поиск своих заметок Monologue через REST API Monologue Notes. Он охватывает аутентификацию с помощью переменной среды MONOLOGUE_API_KEY, безопасную обработку токенов, листинг заметок, выборку одной заметки, нумерацию страниц, фильтры и обработку ошибок. API доступен только для чтения, и к нему следует обращаться с помощью прямых HTTP-запросов, таких как Curl или любой эквивалентный клиент REST.
