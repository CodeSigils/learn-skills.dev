Utilice esta habilidad cuando el usuario quiera leer o buscar sus notas de Monologue a través de la API REST de Monologue Notes. Cubre la autenticación con la variable de entorno MONOLOGUE_API_KEY, el manejo seguro de tokens, el listado de notas, la recuperación de una sola nota, la paginación, los filtros y el manejo de errores. La API es de solo lectura y se debe acceder a ella con solicitudes HTTP directas, como curl o cualquier cliente REST equivalente.
