Utilizza questa abilità quando l'utente desidera leggere o cercare le note di Monologue tramite l'API REST di Monologue Notes. Copre l'autenticazione con la variabile di ambiente MONOLOGUE_API_KEY, la gestione sicura dei token, l'elenco delle note, il recupero di una singola nota, l'impaginazione, i filtri e la gestione degli errori. L'API è di sola lettura ed è possibile accedervi con richieste HTTP dirette come curl o qualsiasi client REST equivalente.
