Verwenden Sie diese Fähigkeit, wenn der Benutzer seine Monologue-Notizen über die Monologue Notes-REST-API lesen oder durchsuchen möchte. Es umfasst die Authentifizierung mit der Umgebungsvariablen MONOLOGUE_API_KEY, die sichere Token-Verarbeitung, das Auflisten von Notizen, das Abrufen einer einzelnen Notiz, Paginierung, Filter und Fehlerbehandlung. Die API ist schreibgeschützt und sollte mit direkten HTTP-Anfragen wie Curl oder einem gleichwertigen REST-Client aufgerufen werden.
