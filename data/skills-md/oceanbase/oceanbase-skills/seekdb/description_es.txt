Resumen de la habilidad para OceanBase SeekDB. Enrutamientos a sub‑habilidades especializadas que cubren todo el ciclo de vida de SeekDB: instalación/despliegue en una máquina objetivo, compilación desde el código fuente, búsqueda de documentación, uso del seekdb‑cli para operaciones SQL/esquema/vector, importación de datos CSV/Excel y consultas/exportación de resultados. Úselo como punto de partida cuando el usuario mencione seekdb, pyseekdb, "install seekdb", "build seekdb", "seekdb docs", "seekdb-cli", "import to seekdb", "query seekdb", o desee una base de datos ligera independiente compatible con OceanBase. Para despliegues de seekdb gestionados por obd y HA primaria‑secundaria, consulte la habilidad separada oceanbase-deploy/seekdb.
