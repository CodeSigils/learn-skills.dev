Обзор навыков для OceanBase SeekDB. Маршруты к специализированным поднавыкам, охватывающим полный жизненный цикл SeekDB — установка/развертывание на целевой машине, сборка из исходного кода, поиск документации, использование searchdb-cli для операций SQL/схемы/векторов, импорт данных CSV/Excel и запрос/экспорт результатов. Используйте в качестве отправной точки, когда пользователь упоминает seekdb, pyseekdb, «установить searchdb», «создать SeekDB», «seekdb docs», «seekdb-cli», «импортировать в SeekDB», «запросить SeekDB» или хочет получить облегченную автономную базу данных, совместимую с OceanBase. Для развертываний seekdb, управляемых obd, и первичной резервной доступности см. отдельный навык Oceanbase-deploy/seekdb.
