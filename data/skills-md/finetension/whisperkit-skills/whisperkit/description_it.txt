It normalizes audio/video files on Apple Silicon into WhisperKit‑compatible audio, then performs speech‑to‑text conversion and speaker separation. It is used when a user wants to transcribe media, create a transcript or subtitles, distinguish speakers, needs a transcript before summarizing a meeting recording, or places a media file in the inbox. It is triggered by requests such as “transcribe for me,” “extract audio from this video,” “convert to text,” “separate speakers,” “I put a file in the inbox.” Il riepilogo del contenuto, delle decisioni e delle azioni della riunione è delegato alla capacità di riepilogo della riunione.
