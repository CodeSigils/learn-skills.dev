Supprime les restrictions de démonstration hébergées par Open Harness d’un fork. À utiliser lorsqu'un responsable souhaite supprimer les plafonds d'essai des modèles gérés, le contrôle du déploiement hébergé ou les limites de « déployer vos propres ». Déclencheurs sur "supprimer les limites de démonstration", "supprimer les limites d'essai", "supprimer les restrictions hébergées", "ouvrir ceci pour mon fork", "supprimer les restrictions de modèles gérés".
