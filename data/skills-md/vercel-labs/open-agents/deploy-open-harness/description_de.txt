Führt einen Benutzer durch das Sammeln der Anmeldeinformationen, die für die Bereitstellung seiner eigenen Kopie von Open Harness erforderlich sind, die Bereitstellung dieses Repos auf Vercel und den Abschluss der Ersteinrichtung. Verwenden Sie diese Option für Anfragen zur Bereitstellung, zum Selbsthosting, zum Konfigurieren von Anmeldeinformationen oder zum Einstieg in einen Fork dieser App.
