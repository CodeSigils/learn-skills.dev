Chat SDK (`chat` npm パッケージ) を使用してマルチプラットフォームのチャット ボットを構築します。開発者が次のことを行う場合に使用します。(1) Slack、Teams、Google Chat、Discord、Telegram、GitHub、Linear、または WhatsApp ボットを構築する、(2) Chat SDK を使用してメンション、ダイレクト メッセージ、購読スレッド、リアクション、スラッシュ コマンド、カード、モーダル、ファイル、または AI ストリーミングを処理する、(3) Webhook ルートまたはマルチアダプター ボットを設定する、(4) リッチ カードまたはストリーミング AI 応答をチャット プラットフォームに送信する、 (5) カスタム アダプターまたは状態アダプターを構築または保守します。 「チャット SDK」、「チャット ボット」、「Slack ボット」、「チーム ボット」、「Google チャット ボット」、「Discord ボット」、「テレグラム ボット」、「whatsapp ボット」、「@chat-adapter」、「@chat-adapter/state-」、「カスタム アダプター」、「状態アダプター」、「ビルド アダプター」、および複数のチャットで機能するボットの構築でトリガープラットフォーム。
