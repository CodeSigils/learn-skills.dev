Erstellen Sie plattformübergreifende Chat-Bots mit dem Chat SDK (npm-Paket „chat“). Verwenden Sie diese Option, wenn Entwickler (1) einen Slack-, Teams-, Google Chat-, Discord-, Telegram-, GitHub-, Linear- oder WhatsApp-Bot erstellen möchten, (2) das Chat SDK verwenden möchten, um Erwähnungen, Direktnachrichten, abonnierte Threads, Reaktionen, Slash-Befehle, Karten, Modalitäten, Dateien oder KI-Streaming zu verarbeiten, (3) Webhook-Routen oder Multi-Adapter-Bots einrichten, (4) Rich Cards oder gestreamte KI-Antworten an Chat-Plattformen senden, (5) einen benutzerdefinierten Adapter oder Status erstellen oder verwalten möchten Adapter. Löst auf „Chat SDK“, „Chat Bot“, „Slack Bot“, „Teams Bot“, „Google Chat Bot“, „Discord Bot“, „Telegram Bot“, „WhatsApp Bot“, „@chat-adapter“, „@chat-adapter/state-“, „Custom Adapter“, „State Adapter“, „Build Adapter“ und beim Erstellen von Bots aus, die auf mehreren Chat-Plattformen funktionieren.
