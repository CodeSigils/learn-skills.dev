أنشئ روبوتات دردشة متعددة المنصات باستخدام Chat SDK (حزمة `chat` npm). يُستخدم عندما يريد المطورون (1) إنشاء روبوت Slack أو Teams أو Google Chat أو Discord أو Telegram أو GitHub أو Linear أو WhatsApp، (2) استخدام Chat SDK للتعامل مع الإشارات أو الرسائل المباشرة أو سلاسل الرسائل المشتركة أو التفاعلات أو أوامر الشرطة المائلة أو البطاقات أو الوسائط أو الملفات أو تدفق الذكاء الاصطناعي، (3) إعداد مسارات خطاف الويب أو الروبوتات متعددة المحولات، (4) إرسال بطاقات غنية أو استجابات الذكاء الاصطناعي المتدفقة إلى منصات الدردشة، (5) البناء أو الحفاظ على محول مخصص أو محول الحالة. مشغلات على "chat sdk"، و"chat bot"، و"slack bot"، و"teams bot"، و"google chat bot"، و"discord bot"، و"telegram bot"، و"whatsapp bot"، و"chat-adapter"، و"@chat-adapter/state-"، و"custom converter"، و"state converter"، و"build converter"، وبناء الروبوتات التي تعمل عبر منصات دردشة متعددة.
