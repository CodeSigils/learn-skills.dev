Compétence de découverte pour le SDK natif, la boîte à outils complète pour créer des applications de bureau natives - les vues sont un balisage natif déclaratif (.native), la logique est simple Zig et le propre moteur de la boîte à outils restitue chaque pixel, avec les surfaces WebView comme chemin de contenu Web facultatif. À utiliser lorsque l'utilisateur demande ce qu'est le SDK natif, comment créer une application SDK natif, créer une interface utilisateur native, échafauder une application, configurer app.zon, ajouter des commandes de pont, intégrer du contenu Web, empaqueter une application, tester une application en cours d'exécution ou automatiser une application SDK natif.
