ネイティブ SDK の検出スキル。ネイティブ デスクトップ アプリケーションを構築するための完全なツールキットです。ビューは宣言型ネイティブ マークアップ (.native)、ロジックはプレーン Zig、ツールキット独自のエンジンは、オプションの Web コンテンツ パスとして WebView サーフェスを使用してすべてのピクセルをレンダリングします。ユーザーが、ネイティブ SDK とは何か、ネイティブ SDK アプリの構築方法、ネイティブ UI の作成方法、アプリのスキャフォールディング方法、app.zon の構成方法、ブリッジ コマンドの追加方法、Web コンテンツの埋め込み方法、アプリのパッケージ化方法、実行中のアプリのテスト方法、またはネイティブ SDK アプリの自動化方法を尋ねた場合に使用します。
