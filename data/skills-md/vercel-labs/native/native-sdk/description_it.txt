Capacità di individuazione per Native SDK, il toolkit completo per la creazione di applicazioni desktop native: le visualizzazioni sono dichiarative Markup nativo (.native), la logica è semplice Zig e il motore del toolkit esegue il rendering di ogni pixel, con le superfici WebView come percorso del contenuto Web opzionale. Da utilizzare quando l'utente chiede cos'è l'SDK nativo, come creare un'app Native SDK, creare un'interfaccia utente nativa, strutturare un'app, configurare app.zon, aggiungere comandi bridge, incorporare contenuto Web, creare un pacchetto di un'app, testare un'app in esecuzione o automatizzare un'app Native SDK.
