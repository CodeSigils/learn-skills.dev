Навыки открытия для нулевой нативности, оболочки настольного приложения Zig для создания нативных приложений с веб-интерфейсами. Используйте, когда пользователь спрашивает, что такое нулевое нативное приложение, как создать нулевое нативное приложение, создать каркас внешнего приложения, настроить app.zon, выбрать механизм WebView, добавить команды моста, упаковать приложение, протестировать работающее приложение или автоматизировать нуль нативную оболочку WebView.
