Compétence de découverte pour Zero-Native, un shell d'application de bureau Zig permettant de créer des applications natives avec des interfaces utilisateur Web. À utiliser lorsque l'utilisateur demande ce qu'est le zéro natif, comment créer une application zéro natif, échafauder une application frontale, configurer app.zon, choisir un moteur WebView, ajouter des commandes de pont, empaqueter une application, tester une application en cours d'exécution ou automatiser un shell WebView zéro natif.
