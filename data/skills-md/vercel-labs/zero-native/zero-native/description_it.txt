Competenza di individuazione per zero-native, una shell per app desktop Zig per la creazione di app native con interfacce utente Web. Da utilizzare quando l'utente chiede cos'è zero-native, come creare un'app zero-native, strutturare un'app frontend, configurare app.zon, scegliere un motore WebView, aggiungere comandi bridge, creare un pacchetto di un'app, testare un'app in esecuzione o automatizzare una shell WebView zero-native.
