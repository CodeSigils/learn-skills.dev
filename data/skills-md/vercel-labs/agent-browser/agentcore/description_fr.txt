Exécutez agent-browser sur les navigateurs cloud AWS Bedrock AgentCore. À utiliser lorsque l'utilisateur souhaite utiliser AgentCore, exécuter l'automatisation du navigateur sur AWS, utiliser un navigateur cloud avec des informations d'identification AWS ou a besoin d'une session de navigateur gérée soutenue par l'infrastructure AWS. Les déclencheurs incluent « utiliser agentcore », « exécuter sur AWS », « navigateur cloud avec AWS », « navigateur bedrock », « session agentcore » ou toute tâche nécessitant l'automatisation du navigateur hébergé par AWS.
