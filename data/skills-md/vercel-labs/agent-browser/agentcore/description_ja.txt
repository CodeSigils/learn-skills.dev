AWS Bedrock AgentCore クラウド ブラウザ上でエージェント ブラウザを実行します。ユーザーが AgentCore を使用する場合、AWS でブラウザ自動化を実行する場合、AWS 認証情報を使用してクラウド ブラウザを使用する場合、または AWS インフラストラクチャによってサポートされるマネージド ブラウザ セッションが必要な場合に使用します。トリガーには、「agentcore の使用」、「AWS で実行」、「AWS を使用したクラウドブラウザ」、「bedrock ブラウザ」、「agentcore セッション」、または AWS でホストされるブラウザの自動化を必要とするタスクが含まれます。
