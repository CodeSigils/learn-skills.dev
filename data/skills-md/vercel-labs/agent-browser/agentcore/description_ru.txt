Запустите агент-браузер в облачных браузерах AWS Bedrock AgentCore. Используйте, когда пользователь хочет использовать AgentCore, запустить автоматизацию браузера на AWS, использовать облачный браузер с учетными данными AWS или ему нужен управляемый сеанс браузера, поддерживаемый инфраструктурой AWS. Триггеры включают «использование агентного ядра», «запуск на AWS», «облачный браузер с AWS», «основанный браузер», «сеанс агентного ядра» или любую задачу, требующую автоматизации браузера, размещенного на AWS.
