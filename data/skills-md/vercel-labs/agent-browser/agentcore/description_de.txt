Führen Sie agent-browser auf AWS Bedrock AgentCore-Cloud-Browsern aus. Verwenden Sie diese Option, wenn der Benutzer AgentCore verwenden, die Browserautomatisierung auf AWS ausführen, einen Cloud-Browser mit AWS-Anmeldeinformationen verwenden möchte oder eine verwaltete Browsersitzung benötigt, die von der AWS-Infrastruktur unterstützt wird. Zu den Auslösern gehören „Agentcore verwenden“, „Auf AWS ausführen“, „Cloud-Browser mit AWS“, „Basisbrowser“, „Agentcore-Sitzung“ oder jede Aufgabe, die eine von AWS gehostete Browserautomatisierung erfordert.
