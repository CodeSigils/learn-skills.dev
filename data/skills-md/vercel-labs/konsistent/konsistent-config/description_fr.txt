Créez ou modifiez un fichier de configuration konsistent.json qui applique les conventions structurelles dans une base de code TypeScript. À utiliser lorsque l'utilisateur souhaite appliquer une structure de code cohérente, valider les exportations/importations entre les fichiers, garantir que les répertoires contiennent les fichiers requis, appliquer des modèles de dénomination, ajouter/supprimer/mettre à jour des règles de convention, configurer des remplacements de carte de cas pour les acronymes ou la casse spéciale (kebabToPascalMap, kebabToCamelMap) ou déterminer pourquoi konsistent signale des violations.
