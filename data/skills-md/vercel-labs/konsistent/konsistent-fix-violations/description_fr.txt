Exécutez la CLI cohérente, examinez toutes les violations signalées et corrigez-les dans la base de code. À utiliser lorsque l'utilisateur souhaite « corriger les violations cohérentes », « résoudre les erreurs cohérentes », « nettoyer les diagnostics cohérents », « effectuer une réussite cohérente », « traiter les violations des conventions structurelles » ou demande d'exécuter cohérent et d'agir en fonction des résultats. La compétence est interactive : elle nécessite des décisions explicites de l'utilisateur lorsque de nombreuses violations proviennent de la même règle (question règle ou code), une confirmation explicite de l'utilisateur avant de modifier un code et une étape de tri pour les violations non triviales. Pour éditer « konsistent.json », cette compétence s'en remet à la compétence « konsistent-config ».
