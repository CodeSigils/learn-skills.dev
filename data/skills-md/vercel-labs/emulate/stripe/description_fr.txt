API Stripe émulée pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit traiter des paiements localement, tester les flux de paiement, créer des clients, gérer les produits et les prix, gérer les intentions de paiement, travailler avec des webhooks ou utiliser le SDK Stripe sans accéder à de vrais serveurs Stripe. Les déclencheurs incluent « API Stripe », « émuler Stripe », « tester les paiements localement », « flux de paiement », « intention de paiement », « webhook Stripe », « SDK Stripe », « STRIPE_API_KEY » ou toute tâche nécessitant une API Stripe locale.
