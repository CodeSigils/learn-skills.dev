Эмулируемый Stripe API для локальной разработки и тестирования. Используйте, когда пользователю необходимо обрабатывать платежи локально, тестировать потоки оформления заказов, создавать клиентов, управлять продуктами и ценами, обрабатывать платежные намерения, работать с веб-перехватчиками или использовать Stripe SDK, не затрагивая реальные серверы Stripe. Триггеры включают в себя «Stripe API», «эмуляцию Stripe», «локальное тестирование платежей», «поток оформления заказа», «намерение платежа», «Stripe webhook», «Stripe SDK», «STRIPE_API_KEY» или любую задачу, требующую локального Stripe API.
