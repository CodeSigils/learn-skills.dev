ローカル開発およびテスト用にエミュレートされた Stripe API。ユーザーがローカルでの支払いの処理、チェックアウト フローのテスト、顧客の作成、製品と価格の管理、支払いインテントの処理、Webhook の操作、または実際の Stripe サーバーにアクセスせずに Stripe SDK を使用する必要がある場合に使用します。トリガーには、「Stripe API」、「Stripe のエミュレート」、「ローカルでの支払いのテスト」、「チェックアウト フロー」、「支払いインテント」、「Stripe Webhook」、「Stripe SDK」、「STRIPE_API_KEY」、またはローカルの Stripe API を必要とするタスクが含まれます。
