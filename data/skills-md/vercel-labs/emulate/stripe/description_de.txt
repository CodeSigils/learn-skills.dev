Emulierte Stripe-API für lokale Entwicklung und Tests. Verwenden Sie es, wenn der Benutzer Zahlungen lokal verarbeiten, Checkout-Abläufe testen, Kunden erstellen, Produkte und Preise verwalten, Zahlungsabsichten verwalten, mit Webhooks arbeiten oder das Stripe SDK verwenden muss, ohne echte Stripe-Server zu erreichen. Zu den Auslösern gehören „Stripe API“, „Stripe emulieren“, „Zahlungen lokal testen“, „Checkout-Ablauf“, „Zahlungsabsicht“, „Stripe Webhook“, „Stripe SDK“, „STRIPE_API_KEY“ oder jede Aufgabe, die eine lokale Stripe API erfordert.
