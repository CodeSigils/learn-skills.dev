Lokaler Drop-in-API-Emulator für Vercel, GitHub und Google. Verwenden Sie diese Option, wenn der Benutzer emulierte Dienste starten, Seed-Daten konfigurieren, Tests für lokale APIs schreiben, CI ohne Netzwerkzugriff einrichten oder mit der emulierten CLI oder programmgesteuerten API arbeiten muss. Zu den Auslösern gehören „Emulator starten“, „Dienste emulieren“, „API lokal simulieren“, „Emulatorkonfiguration erstellen“, „gegen lokale API testen“, „npx-Emulation“ oder jede Aufgabe, die eine lokale Dienstemulation erfordert.
