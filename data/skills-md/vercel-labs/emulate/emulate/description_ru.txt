Локальный эмулятор API для Vercel, GitHub и Google. Используйте, когда пользователю необходимо запустить эмулируемые службы, настроить исходные данные, написать тесты для локальных API, настроить CI без доступа к сети или работать с эмулируемым CLI или программным API. Триггеры включают «запуск эмулятора», «эмуляцию служб», «локальную имитацию API», «создание конфигурации эмулятора», «тестирование локального API», «эмуляцию npx» или любую задачу, требующую эмуляции локальной службы.
