Vercel、GitHub、Google 用のローカル ドロップイン API エミュレーター。ユーザーがエミュレートされたサービスの開始、シード データの構成、ローカル API に対するテストの作成、ネットワーク アクセスなしで CI のセットアップ、またはエミュレート CLI またはプログラム API の操作を行う必要がある場合に使用します。トリガーには、「エミュレーターの開始」、「サービスのエミュレート」、「API をローカルでモック」、「エミュレーター構成の作成」、「ローカル API に対するテスト」、「npx エミュレート」、またはローカル サービス エミュレーションを必要とするタスクが含まれます。
