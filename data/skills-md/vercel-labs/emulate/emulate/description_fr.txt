Émulateur d'API local pour Vercel, GitHub et Google. À utiliser lorsque l'utilisateur doit démarrer des services émulés, configurer des données de départ, écrire des tests sur des API locales, configurer CI sans accès au réseau ou travailler avec l'interface CLI d'émulation ou l'API programmatique. Les déclencheurs incluent "démarrer l'émulateur", "émuler les services", "simuler une API localement", "créer une configuration d'émulateur", "tester par rapport à l'API locale", "émuler npx" ou toute tâche nécessitant une émulation de service local.
