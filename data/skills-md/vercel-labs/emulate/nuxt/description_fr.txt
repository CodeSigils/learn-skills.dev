Adaptateur Nuxt pour intégrer des émulateurs directement dans une application Nuxt via @emulators/adapter-nuxt. À utiliser lorsque l'utilisateur doit intégrer des émulateurs dans Nuxt, configurer OAuth de même origine pour les déploiements en version préliminaire, créer une route de serveur fourre-tout d'émulation, configurer la persistance pour les émulateurs Nuxt intégrés ou encapsuler nuxt.config avec withEmulate. Les déclencheurs incluent « émulateur Nuxt », « adaptateur-nuxt », « émulateur intégré », « OAuth de même origine », « createEmulateHandler », « withEmulate » ou toute tâche nécessitant des émulateurs dans une application Nuxt.
