Adaptador Nuxt para integrar emuladores directamente en una aplicación Nuxt a través de @emulators/adapter-nuxt. Úselo cuando el usuario necesite incrustar emuladores en Nuxt, configurar OAuth del mismo origen para implementaciones de vista previa, crear una ruta de emulación de servidor general, configurar la persistencia para emuladores de Nuxt integrados o empaquetar nuxt.config con withEmulate. Los activadores incluyen "emulador de Nuxt", "adapter-nuxt", "emulador integrado", "OAuth del mismo origen", "createEmulateHandler", "withEmulate" o cualquier tarea que requiera emuladores dentro de una aplicación Nuxt.
