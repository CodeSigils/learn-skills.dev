Эмулированные API REST Twilio для локальной разработки и тестирования. Используйте, когда пользователю необходимо протестировать Twilio Messaging, Verify, Voice, телефонные номера, веб-перехватчики, обратные вызовы состояния, симуляцию входящих SMS или интеграцию Twilio SDK, не затрагивая реальную службу Twilio.
