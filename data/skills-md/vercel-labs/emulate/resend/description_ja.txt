ローカル開発およびテスト用にエミュレートされた電子メール再送信 API。ユーザーがローカルで電子メールを送信する必要がある場合、トランザクション電子メール フローをテストする必要がある場合、マジック リンクまたは検証コード認証を実装する必要がある場合、送信された電子メールを検査する必要がある場合、ドメイン/連絡先/API キーを管理する必要がある場合、または実際の電子メールを送信せずに再送信 API を操作する必要がある場合に使用します。トリガーには、「API 再送信」、「再送信のエミュレート」、「電子メールをローカルに送信」、「電子メールのテスト」、「マジック リンク」、「確認電子メール」、「電子メールの受信箱」、「RESEND_BASE_URL」、またはローカル電子メール API を必要とするタスクが含まれます。
