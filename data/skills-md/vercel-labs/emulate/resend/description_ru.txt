Эмулированный API повторной отправки электронной почты для локальной разработки и тестирования. Используйте, когда пользователю необходимо отправлять электронную почту локально, тестировать потоки транзакционной электронной почты, реализовать аутентификацию по магической ссылке или коду подтверждения, проверять отправленные электронные письма, управлять доменами/контактами/ключами API или работать с API повторной отправки без отправки реальных электронных писем. Триггеры включают «API повторной отправки», «эмулировать повторную отправку», «отправить электронную почту локально», «тестовое электронное письмо», «магическую ссылку», «электронное письмо с подтверждением», «входящие сообщения электронной почты», «RESEND_BASE_URL» или любую задачу, требующую локального API электронной почты.
