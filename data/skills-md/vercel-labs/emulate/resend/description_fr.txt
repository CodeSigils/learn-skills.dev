API de renvoi de courrier électronique émulée pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit envoyer des e-mails localement, tester des flux de courrier électronique transactionnels, mettre en œuvre un lien magique ou un code de vérification d'authentification, inspecter les e-mails envoyés, gérer les domaines/contacts/clés API ou travailler avec l'API Resend sans envoyer de vrais e-mails. Les déclencheurs incluent « Renvoyer l'API », « émuler Renvoyer », « envoyer un e-mail localement », « tester l'e-mail », « lien magique », « e-mail de vérification », « boîte de réception e-mail », « RESEND_BASE_URL » ou toute tâche nécessitant une API de messagerie locale.
