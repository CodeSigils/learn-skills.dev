محاكاة إعادة إرسال واجهة برمجة تطبيقات البريد الإلكتروني للتطوير والاختبار المحلي. يُستخدم عندما يحتاج المستخدم إلى إرسال رسائل البريد الإلكتروني محليًا، أو اختبار تدفقات البريد الإلكتروني للمعاملات، أو تنفيذ الرابط السحري أو مصادقة رمز التحقق، أو فحص رسائل البريد الإلكتروني المرسلة، أو إدارة المجالات/جهات الاتصال/مفاتيح واجهة برمجة التطبيقات، أو العمل مع Resend API دون إرسال رسائل بريد إلكتروني حقيقية. تتضمن المشغلات "إعادة إرسال API"، أو "محاكاة إعادة الإرسال"، أو "إرسال البريد الإلكتروني محليًا"، أو "اختبار البريد الإلكتروني"، أو "الرابط السحري"، أو "البريد الإلكتروني للتحقق"، أو "صندوق البريد الإلكتروني"، أو "RESEND_BASE_URL"، أو أي مهمة تتطلب واجهة برمجة تطبيقات بريد إلكتروني محلية.
