Эмулированные облачные сервисы AWS (S3, SQS, IAM, STS) для локальной разработки и тестирования. Используйте, когда пользователю необходимо локально взаимодействовать с конечными точками API AWS, тестировать операции с сегментом S3 и объектами, эмулировать очереди и сообщения SQS, управлять пользователями/ролями/ключами доступа IAM, тестировать роль STS или работать без использования реальных API AWS. Триггеры включают «эмулятор AWS», «эмуляцию AWS», «макет S3», «локальный SQS», «тест IAM», «эмуляцию S3», «локальный AWS», «STS принимает на себя роль» или любую задачу, требующую эмуляции локального сервиса AWS.
