خدمات AWS السحابية التي تمت محاكاتها (S3 وSQS وIAM وSTS) للتطوير والاختبار المحلي. يُستخدم عندما يحتاج المستخدم إلى التفاعل مع نقاط نهاية AWS API محليًا، واختبار عمليات حاوية S3 والكائنات، ومحاكاة قوائم انتظار ورسائل SQS، وإدارة مستخدمي/أدوار/مفاتيح الوصول IAM، واختبار STS لتولي الدور، أو العمل دون الوصول إلى واجهات برمجة تطبيقات AWS الحقيقية. تتضمن المشغلات "AWS emulator"، أو "emulate AWS"، أو "mock S3"، أو "local SQS"، أو "test IAM"، أو "emulate S3"، أو "AWS locally"، أو "STS take role"، أو أي مهمة تتطلب محاكاة خدمة AWS المحلية.
