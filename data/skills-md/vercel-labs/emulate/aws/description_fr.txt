Services cloud AWS émulés (S3, SQS, IAM, STS) pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit interagir localement avec les points de terminaison de l'API AWS, tester les opérations du compartiment et des objets S3, émuler les files d'attente et les messages SQS, gérer les utilisateurs/rôles/clés d'accès IAM, tester le rôle de STS ou travailler sans utiliser les véritables API AWS. Les déclencheurs incluent « émulateur AWS », « émuler AWS », « simuler S3 », « SQS local », « tester IAM », « émuler S3 », « AWS localement », « STS ​​assumer un rôle » ou toute tâche nécessitant une émulation de service AWS local.
