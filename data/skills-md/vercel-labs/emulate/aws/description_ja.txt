ローカル開発およびテスト用にエミュレートされた AWS クラウド サービス (S3、SQS、IAM、STS)。ユーザーがローカルで AWS API エンドポイントと対話したり、S3 バケットとオブジェクトの操作をテストしたり、SQS キューとメッセージをエミュレートしたり、IAM ユーザー/ロール/アクセス キーを管理したり、ロールを引き受ける STS をテストしたり、実際の AWS API にアクセスせずに作業したりする必要がある場合に使用します。トリガーには、「AWS エミュレータ」、「AWS のエミュレート」、「S3 モック」、「ローカル SQS」、「IAM のテスト」、「S3 のエミュレート」、「AWS ローカル」、「STS の役割の引き受け」、またはローカル AWS サービス エミュレーションを必要とするタスクが含まれます。
