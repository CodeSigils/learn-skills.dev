Servizi cloud AWS emulati (S3, SQS, IAM, STS) per sviluppo e test locali. Da utilizzare quando l'utente deve interagire con gli endpoint API AWS localmente, testare operazioni su bucket e oggetti S3, emulare code e messaggi SQS, gestire utenti/ruoli/chiavi di accesso IAM, testare l'assunzione del ruolo di STS o lavorare senza utilizzare le API AWS reali. I trigger includono "emulatore AWS", "emulazione AWS", "mock S3", "SQS locale", "test IAM", "emulazione S3", "AWS localmente", "STS assume ruolo" o qualsiasi attività che richieda l'emulazione del servizio AWS locale.
