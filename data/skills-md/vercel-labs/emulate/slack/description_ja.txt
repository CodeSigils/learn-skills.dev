ローカル開発とテスト用にエミュレートされた Slack API。ユーザーがローカルで Slack API エンドポイントと対話したり、Slack 統合をテストしたり、チャネル/メッセージ/ユーザーをエミュレートしたり、Slack OAuth フローを設定したり、受信 Webhook をテストしたり、実際の Slack API にアクセスせずに Slack Web API を操作したりする必要がある場合に使用します。トリガーには、「Slack API」、「Slack のエミュレート」、「Slack のモック」、「Slack OAuth のテスト」、「Slack ボット」、「受信 Webhook」、「ローカル Slack」、またはローカル Slack API を必要とするタスクが含まれます。
