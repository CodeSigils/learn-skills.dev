Эмулируемый Slack API для локальной разработки и тестирования. Используйте, когда пользователю необходимо локально взаимодействовать с конечными точками Slack API, тестировать интеграцию Slack, эмулировать каналы/сообщения/пользователей, настраивать потоки Slack OAuth, тестировать входящие веб-перехватчики или работать с Slack Web API, не затрагивая реальный Slack API. Триггеры включают «Slack API», «эмуляцию Slack», «имитацию Slack», «тест Slack OAuth», «бот Slack», «входящий веб-перехватчик», «локальный Slack» или любую задачу, требующую локального API Slack.
