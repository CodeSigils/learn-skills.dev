Microsoft Entra ID emulato (Azure AD) OAuth 2.0/OpenID Connect per sviluppo e test locali. Da utilizzare quando l'utente deve testare l'accesso Microsoft in locale, emulare l'individuazione OIDC Entra ID, gestire lo scambio di token Microsoft, configurare i client OAuth di Azure AD, lavorare con Microsoft Graph /me o testare i flussi di credenziali PKCE/client senza utilizzare le API Microsoft reali. I trigger includono "Microsoft OAuth", "Entra ID", "Azure AD", "emulazione di Microsoft", "accesso fittizio a Microsoft", "test dell'accesso a Microsoft", "Microsoft OIDC", "autenticazione Microsoft locale" o qualsiasi attività che richiede un provider Microsoft OAuth/OIDC locale.
