Émulation de Microsoft Entra ID (Azure AD) OAuth 2.0 / OpenID Connect pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit tester la connexion Microsoft localement, émuler la découverte Entra ID OIDC, gérer l'échange de jetons Microsoft, configurer les clients Azure AD OAuth, travailler avec Microsoft Graph /me ou tester les flux d'informations d'identification PKCE/client sans accéder aux véritables API Microsoft. Les déclencheurs incluent « Microsoft OAuth », « Entra ID », « Azure AD », « émuler Microsoft », « simuler la connexion Microsoft », « tester la connexion Microsoft », « Microsoft OIDC », « l'authentification Microsoft locale » ou toute tâche nécessitant un fournisseur Microsoft OAuth/OIDC local.
