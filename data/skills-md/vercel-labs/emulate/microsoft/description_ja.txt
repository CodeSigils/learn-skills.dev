ローカル開発およびテスト用にエミュレートされた Microsoft Entra ID (Azure AD) OAuth 2.0 / OpenID Connect。ユーザーがローカルでの Microsoft サインインのテスト、Entra ID OIDC 検出のエミュレート、Microsoft トークン交換の処理、Azure AD OAuth クライアントの構成、Microsoft Graph /me の操作、または実際の Microsoft API にアクセスせずに PKCE/クライアント資格情報フローのテストを行う必要がある場合に使用します。トリガーには、「Microsoft OAuth」、「Entra ID」、「Azure AD」、「Microsoft のエミュレート」、「Microsoft ログインのモック」、「Microsoft サインインのテスト」、「Microsoft OIDC」、「ローカル Microsoft 認証」、またはローカル Microsoft OAuth/OIDC プロバイダーを必要とするタスクが含まれます。
