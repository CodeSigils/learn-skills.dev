Эмулируемый Microsoft Entra ID (Azure AD) OAuth 2.0 / OpenID Connect для локальной разработки и тестирования. Используйте, когда пользователю необходимо протестировать вход в Microsoft локально, эмулировать обнаружение Entra ID OIDC, обработать обмен токенами Microsoft, настроить клиенты Azure AD OAuth, работать с Microsoft Graph /me или протестировать потоки учетных данных PKCE/клиента, не задействуя реальные API Microsoft. Триггеры включают «Microsoft OAuth», «Entra ID», «Azure AD», «эмуляцию Microsoft», «имитацию входа в систему Microsoft», «проверку входа в систему Microsoft», «Microsoft OIDC», «локальную проверку подлинности Microsoft» или любую задачу, требующую локального поставщика Microsoft OAuth/OIDC.
