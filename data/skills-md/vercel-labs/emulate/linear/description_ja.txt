ローカル開発およびテスト用にエミュレートされた Linear GraphQL API。ユーザーがローカルで Linear 統合をテストする必要がある場合、Linear の問題、コメント、チーム、ワークフロー状態、OAuth アプリ、Webhook、エージェント セッションをエミュレートする必要がある場合、または実際の Linear サービスにアクセスせずに Linear API を操作する必要がある場合に使用します。トリガーには、「リニア API」、「リニアのエミュレート」、「リニアのモック」、「リニア OAuth のテスト」、「リニア Webhook」、「リニア エージェント」、「ローカル リニア」、またはローカル リニア API を必要とするタスクが含まれます。
