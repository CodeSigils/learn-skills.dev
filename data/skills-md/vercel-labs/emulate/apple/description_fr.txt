Émulé Connectez-vous avec Apple / Apple OIDC pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit tester la connexion Apple localement, émuler la découverte Apple OIDC, gérer l'échange de jetons Apple, configurer les clients Apple OAuth ou travailler avec les informations utilisateur Apple sans accéder aux véritables API Apple. Les déclencheurs incluent « Apple OAuth », « émuler Apple », « simulation de connexion Apple », « tester la connexion Apple », « Se connecter avec Apple », « Apple OIDC », « Apple authentification locale » ou toute tâche nécessitant un fournisseur Apple OAuth/OIDC local.
