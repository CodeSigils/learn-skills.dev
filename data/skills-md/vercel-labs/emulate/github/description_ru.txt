Эмулированный REST API GitHub для локальной разработки и тестирования. Используйте, когда пользователю необходимо локально взаимодействовать с конечными точками API GitHub, тестировать интеграцию GitHub, эмулировать репозитории/проблемы/PR, настраивать потоки GitHub OAuth, настраивать приложения GitHub или тестировать веб-перехватчики, не затрагивая реальный API GitHub. Триггеры включают «GitHub API», «эмуляцию GitHub», «имитацию GitHub», «проверку GitHub OAuth», «JWT приложения GitHub», «локальный GitHub» или любую задачу, требующую локального API GitHub.
