API REST GitHub emulata per sviluppo e test locali. Da utilizzare quando l'utente deve interagire localmente con gli endpoint API GitHub, testare le integrazioni GitHub, emulare repository/problemi/PR, impostare flussi OAuth GitHub, configurare app GitHub o testare webhook senza utilizzare la vera API GitHub. I trigger includono "GitHub API", "emulate GitHub", "mock GitHub", "test GitHub OAuth", "GitHub App JWT", "local GitHub" o qualsiasi attività che richiede un'API GitHub locale.
