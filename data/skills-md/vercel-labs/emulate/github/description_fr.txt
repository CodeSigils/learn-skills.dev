API GitHub REST émulée pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit interagir localement avec les points de terminaison de l'API GitHub, tester les intégrations GitHub, émuler des dépôts/problèmes/PR, configurer des flux GitHub OAuth, configurer des applications GitHub ou tester des webhooks sans accéder à la véritable API GitHub. Les déclencheurs incluent « API GitHub », « émuler GitHub », « mock GitHub », « tester GitHub OAuth », « GitHub App JWT », « local GitHub » ou toute tâche nécessitant une API GitHub locale.
