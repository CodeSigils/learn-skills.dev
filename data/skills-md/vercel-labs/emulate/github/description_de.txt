Emulierte GitHub-REST-API für lokale Entwicklung und Tests. Verwenden Sie diese Option, wenn der Benutzer lokal mit GitHub-API-Endpunkten interagieren, GitHub-Integrationen testen, Repos/Issues/PRs emulieren, GitHub-OAuth-Flows einrichten, GitHub-Apps konfigurieren oder Webhooks testen muss, ohne auf die echte GitHub-API zuzugreifen. Zu den Auslösern gehören „GitHub API“, „GitHub emulieren“, „Mock GitHub“, „GitHub OAuth testen“, „GitHub App JWT“, „local GitHub“ oder jede Aufgabe, die eine lokale GitHub API erfordert.
