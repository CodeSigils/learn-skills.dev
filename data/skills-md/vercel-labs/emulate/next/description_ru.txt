Адаптер Next.js для встроенных эмуляторов, встроенное проксирование во время выполнения через @emulators/adapter-next и каркас предварительного просмотра функции Vercel Go. Используйте, когда пользователю необходимо внедрить эмуляторы в Next.js, проксировать собственную среду выполнения через всеобъемлющий маршрут Next.js, настроить OAuth того же источника для предварительных развертываний Vercel, настроить Auth.js/NextAuth с маршрутами эмулятора, добавить постоянство во встроенные эмуляторы, создать каркас npx, эмулировать vercel init или обернуть next.config с помощью withEmulate. Триггеры включают «эмулятор Next.js», «adapter-next», «встроенный эмулятор», «собственный прокси-сервер времени выполнения», «OAuth того же происхождения», «предварительный просмотр Vercel», «функция Vercel Go», «npx emulate vercel init», «createEmulateHandler», «createEmulateProxy», «withEmulate» или любую задачу, требующую эмуляторов внутри приложения Next.js.
