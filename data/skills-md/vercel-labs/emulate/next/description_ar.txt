محول Next.js للمحاكيات المضمنة، ووكلاء وقت التشغيل الأصلي عبر @emulators/adapter-next، وسقالات معاينة Vercel Go Function. يُستخدم عندما يحتاج المستخدم إلى تضمين المحاكيات في Next.js، أو وكيل وقت تشغيل أصلي من خلال مسار التقاط الكل Next.js، أو إعداد OAuth من نفس المصدر لعمليات نشر معاينة Vercel، أو تكوين Auth.js/NextAuth باستخدام مسارات المحاكي، أو إضافة الثبات إلى المحاكيات المضمنة، أو محاكاة npx لـ vercel init، أو لف next.config باستخدام withEmulate. تتضمن المشغلات "Next.js emulator"، و"adapter-next"، و"embedded emulator"، و"native runtime proxy"، و"same-origin OAuth"، و"Vercel Preview"، و"Vercel Go Function"، و"npx emulate vercel init"، و"createEmulateHandler"، و"createEmulateProxy"، و"withEmulate"، أو أي مهمة تتطلب محاكاة داخل تطبيق Next.js.
