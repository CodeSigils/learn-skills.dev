Adaptateur Next.js pour les émulateurs intégrés, proxy d'exécution natif via @emulators/adapter-next et échafaudage de prévisualisation Vercel Go Function. À utiliser lorsque l'utilisateur doit intégrer des émulateurs dans Next.js, proxy un environnement d'exécution natif via une route fourre-tout Next.js, configurer OAuth de même origine pour les déploiements préliminaires de Vercel, configurer Auth.js/NextAuth avec des routes d'émulateur, ajouter de la persistance aux émulateurs intégrés, échafauder npx émuler vercel init ou envelopper next.config avec withEmulate. Les déclencheurs incluent « émulateur Next.js », « adapter-next », « émulateur intégré », « proxy d'exécution natif », « OAuth de même origine », « aperçu Vercel », « fonction Vercel Go », « npx émuler vercel init », « createEmulateHandler », « createEmulateProxy », « withEmulate » ou toute tâche nécessitant des émulateurs dans une application Next.js.
