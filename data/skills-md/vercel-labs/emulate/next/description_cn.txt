用于嵌入式模拟器的 Next.js 适配器、通过 @emulators/adapter-next 的本机运行时代理以及 Vercel Go Function 预览脚手架。当用户需要在 Next.js 中嵌入模拟器、通过 Next.js catch-all 路由代理本机运行时、为 Vercel 预览部署设置同源 OAuth、使用模拟器路由配置 Auth.js/NextAuth、向嵌入式模拟器添加持久性、脚手架 npx 模拟 vercel init 或使用 withEmulate 包装 next.config 时使用。触发器包括“Next.js 模拟器”、“adapter-next”、“嵌入式模拟器”、“本机运行时代理”、“同源 OAuth”、“Vercel 预览”、“Vercel Go Function”、“npx emulate vercel init”、“createEmulateHandler”、“createEmulateProxy”、“withEmulate”或任何需要 Next.js 应用程序内的模拟器的任务。
