ローカル開発およびテスト用にエミュレートされた Vercel REST API。ユーザーがローカルで Vercel API エンドポイントと対話したり、Vercel 統合をテストしたり、プロジェクト/デプロイメント/ドメインをエミュレートしたり、Vercel OAuth フローを設定したり、環境変数を管理したり、実際の Vercel API を使用せずにテストしたりする必要がある場合に使用します。トリガーには、「Vercel API」、「Vercel エミュレート」、「Vercel モック」、「Vercel OAuth テスト」、「Vercel 統合」、「ローカル Vercel」、またはローカル Vercel API を必要とするタスクが含まれます。
