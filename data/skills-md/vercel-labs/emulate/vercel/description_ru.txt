Эмулированный API-интерфейс Vercel REST для локальной разработки и тестирования. Используйте, когда пользователю необходимо локально взаимодействовать с конечными точками API Vercel, тестировать интеграцию Vercel, эмулировать проекты/развертывания/домены, настраивать потоки Vercel OAuth, управлять переменными среды или тестировать, не затрагивая реальный API Vercel. Триггеры включают «Vercel API», «эмуляцию Vercel», «имитацию Vercel», «тестирование Vercel OAuth», «интеграцию Vercel», «локальный Vercel» или любую задачу, требующую локального API Vercel.
