API REST Vercel émulée pour le développement et les tests locaux. À utiliser lorsque l'utilisateur doit interagir localement avec les points de terminaison de l'API Vercel, tester les intégrations Vercel, émuler des projets/déploiements/domaines, configurer des flux Vercel OAuth, gérer des variables d'environnement ou tester sans accéder à la véritable API Vercel. Les déclencheurs incluent « API Vercel », « émuler Vercel », « simuler Vercel », « tester Vercel OAuth », « intégration Vercel », « Vercel local » ou toute tâche nécessitant une API Vercel locale.
