Impulsa una ruta Next.js hacia la navegación instantánea configurando un bucle agente, en Componentes de caché/PPR, en la carga inicial (navegación dura) y en la navegación del lado del cliente (navegación suave). Codifique el objetivo como un @next/playwright instant() e2e fallido y póngalo en verde, una ruta verificada a la vez; la prueba enviada protege entonces contra la regresión. Úselo cuando se le solicite hacer que la navegación de una ruta sea instantánea (su shell estático se confirma inmediatamente), arreglar una ruta cuyo shell estático no está prerenderizado/servido/precargado, hacer crecer el shell estático de una ruta o arreglar su primera pintura lenta, diagnosticar qué límite de suspenso mantiene una ruta fuera de su shell estático, o escribir el protector instantáneo() e2e para uno. Requiere Next.js 16.3+ con componentes de caché; dirige una actualización si es anterior.
