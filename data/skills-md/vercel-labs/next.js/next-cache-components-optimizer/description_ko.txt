초기 로드(하드 탐색) 및 클라이언트 측 탐색(소프트 탐색) 시 캐시 구성 요소/PPR 아래에 에이전트 루프를 설정하여 Next.js 경로를 즉시 탐색하도록 유도합니다. 목표를 실패한 @next/playwright instant() e2e로 인코딩하고 한 번에 하나의 확인된 경로씩 녹색으로 작업합니다. 그런 다음 제공된 테스트는 회귀를 방지합니다. 경로의 탐색을 즉시 수행하도록 요청받을 때(정적 쉘은 즉시 커밋됨), 정적 쉘이 사전 렌더링/제공/프리페치되지 않은 경로를 수정하고, 경로의 정적 쉘을 늘리거나 느린 첫 번째 페인트를 수정하고, 어떤 Suspense 경계가 경로를 정적 쉘에서 유지하는지 진단하거나, instant() e2e 가드를 작성하라는 요청을 받을 때 사용합니다. 캐시 구성 요소가 포함된 Next.js 16.3 이상이 필요합니다. 오래된 경우 업그레이드를 지시합니다.
