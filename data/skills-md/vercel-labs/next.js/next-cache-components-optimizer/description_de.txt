Fahren Sie eine Next.js-Route zur sofortigen Navigation, indem Sie unter Cache-Komponenten/PPR eine Agentenschleife beim ersten Laden (harte Navigation) und bei der clientseitigen Navigation (weiche Navigation) einrichten. Kodieren Sie das Ziel als fehlgeschlagenes @next/playwright instant() e2e und arbeiten Sie es auf grün, eine verifizierte Route nach der anderen; the shipped test then guards against regression. Verwenden Sie diese Option, wenn Sie dazu aufgefordert werden, die Navigation einer Route sofort zu machen (ihre statische Shell wird sofort festgeschrieben), eine Route zu reparieren, deren statische Shell nicht vorgerendert/bereitgestellt/vorabgerufen wird, die statische Shell einer Route zu vergrößern oder ihren langsamen ersten Paint zu reparieren, zu diagnostizieren, welche Suspense-Grenze eine Route von ihrer statischen Shell fernhält, oder den Instant()-E2E-Guard für eine Route zu schreiben. Requires Next.js 16.3+ with cacheComponents; directs an upgrade if older.
