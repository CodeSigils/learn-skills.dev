Activez les composants de cache dans une application Next.js et résolvez les routes bloquantes qu'elles font apparaître. À utiliser lorsque l'utilisateur souhaite activer, adopter ou migrer vers les composants de cache, inverser l'indicateur « cacheComponents », gérer un flot d'erreurs de blocage-pré-rendu/validation instantanée, exécuter le codemod « cache-components-instant-false », ou décider entre désactiver les routes avec « export const instant = false » et les corriger en place.
