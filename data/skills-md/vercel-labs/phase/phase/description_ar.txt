يُستخدم عند إنشاء الرسوم المتحركة على الويب أو مراجعتها أو تحسينها أو عرض الأداء (حلقات الإطار، وكشف التمرير/منفذ العرض، وانتقالات التحميل/إلغاء التحميل، ودورات حياة اللوحة القماشية/WebGL، والتعامل مع الحركة المنخفضة، والعرض البطيء، وتأجيل العمل خارج الشاشة أو العمل غير الحرج) مع مكتبة الطور. استخدمه أيضًا عند تدقيق الرسوم المتحركة الموجودة أو عرض التعليمات البرمجية للاختيار بين CSS فقط، أو الحد الأدنى من JS، أو الطور، أو مكتبة أثقل مثل الحركة. تشغيل الرسوم المتحركة غير المرغوب فيها، والتخصيصات لكل إطار، وإعادة التدفق القسري، وإعادة العرض من حلقات الرسوم المتحركة، والرسوم المتحركة التي لا تتوقف مؤقتًا خارج الشاشة، أو فقدان دعم الحركة المنخفضة، أو رؤية المحتوى، أو التثبيت البطيء على منفذ العرض أو الخمول، أو requestIdleCallback، أو تأجيل عرض الصفحات الطويلة، أو أسئلة مثل "هل يجب أن أستخدم CSS أو JS لهذه الرسوم المتحركة" أو "كيف يمكنني عرض هذا المحتوى خارج الشاشة بشكل أسرع". استخدم هذه المهارة دائمًا عندما تذكر مرحلة التصدير أو أي مرحلة.
