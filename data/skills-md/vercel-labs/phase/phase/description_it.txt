Da utilizzare durante la creazione, la revisione o l'ottimizzazione delle animazioni Web O delle prestazioni di rendering (loop di fotogrammi, rivelazioni di scorrimento/visualizzazione, transizioni di montaggio/smontaggio, cicli di vita Canvas/WebGL, gestione del movimento ridotto, rendering lento, differimento di lavoro fuori schermo o non critico) con la libreria di fase. Utilizzalo anche quando controlli l'animazione esistente o il codice di rendering per decidere tra solo CSS, JS minimo, fase o una libreria più pesante come motion. Attivazione su animazioni stravaganti, allocazioni per fotogramma, ridisposizioni forzate, nuovi rendering da loop di animazione, animazioni che non si fermano fuori dallo schermo, supporto per movimenti ridotti mancante, visibilità dei contenuti, montaggio lento su viewport o inattivo, requestIdleCallback, differimento del rendering di pagine lunghe o domande come "devo utilizzare CSS o JS per questa animazione" o "come posso eseguire il rendering di questo contenuto fuori schermo più velocemente". Usa sempre questa abilità quando menzioni la fase o qualsiasi esportazione di fase.
