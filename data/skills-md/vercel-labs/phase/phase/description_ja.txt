Web アニメーションを構築、レビュー、最適化する場合、またはフェーズ ライブラリを使用してレンダリング パフォーマンス (フレーム ループ、スクロール/ビューポートの表示、マウント/アンマウントの遷移、キャンバス/WebGL ライフサイクル、モーションの削減の処理、遅延レンダリング、オフスクリーンまたは重要ではない作業の延期) を行う場合に使用します。また、既存のアニメーションまたはレンダリング コードを監査して、CSS のみ、最小限の JS、フェーズ、またはモーションなどのより重いライブラリのいずれかを決定するときにも使用します。ぎくしゃくしたアニメーション、フレームごとの割り当て、強制リフロー、アニメーション ループからの再レンダリング、オフスクリーンで一時停止しないアニメーション、モーション削減サポートの欠如、コンテンツの可視性、ビューポートまたはアイドル状態での遅延マウント、requestIdleCallback、長いページのレンダリングの遅延、または「このアニメーションには CSS または JS を使用するべきか」や「このオフスクリーン コンテンツをより速くレンダリングするにはどうすればよいか」などの質問がトリガーされます。フェーズまたはフェーズのエクスポートについて言及するときは、常にこのスキルを使用してください。
