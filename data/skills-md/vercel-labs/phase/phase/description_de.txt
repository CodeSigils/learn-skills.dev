Verwenden Sie die Phasenbibliothek beim Erstellen, Überprüfen oder Optimieren von Webanimationen ODER beim Rendern der Leistung (Bildschleifen, Bildlauf-/Ansichtsfenster-Enthüllungen, Ein-/Aushängen von Übergängen, Canvas-/WebGL-Lebenszyklen, reduzierte Bewegungsverarbeitung, verzögertes Rendern, Verschieben außerhalb des Bildschirms oder unkritischer Arbeiten). Verwenden Sie es auch bei der Prüfung vorhandener Animationen oder beim Rendern von Code, um zwischen reinem CSS, minimalem JS, Phase oder einer schwereren Bibliothek wie Bewegung zu entscheiden. Auslöser für ruckartige Animationen, Zuweisungen pro Frame, erzwungene Reflows, erneutes Rendern aus Animationsschleifen, Animationen, die nicht außerhalb des Bildschirms anhalten, fehlende Unterstützung für reduzierte Bewegungen, Sichtbarkeit von Inhalten, verzögerte Montage im Ansichtsfenster oder im Leerlauf, requestIdleCallback, verzögertes Rendern langer Seiten oder Fragen wie „Soll ich CSS oder JS für diese Animation verwenden“ oder „Wie rendere ich diesen Off-Screen-Inhalt schneller?“. Verwenden Sie diese Fähigkeit immer, wenn Sie eine Phase oder einen Phasenexport erwähnen.
