توجيهات خبراء shadcn/ui - واجهة سطر الأوامر (CLI)، وتثبيت المكونات، وأنماط التركيب، والسجلات المخصصة، والسمات، وتكامل Tailwind CSS، وتصميم الواجهة عالي الجودة. يُستخدم عند تهيئة shadcn، أو إضافة مكونات، أو إنشاء واجهة مستخدم للمنتج، أو إنشاء سجلات مخصصة، أو تكوين السمات، أو استكشاف مشكلات المكونات وإصلاحها.
