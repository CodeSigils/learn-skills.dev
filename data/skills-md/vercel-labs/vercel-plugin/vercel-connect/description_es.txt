Orientación experta de Vercel Connect: obtenga de forma segura tokens OAuth con alcance para servicios de terceros (Slack, GitHub, servidores MCP, OAuth, Snowflake) en nombre de aplicaciones o usuarios a través de Vercel OIDC. Úselo al conectar el acceso a API de terceros, conectarse a servidores MCP, enviar mensajes de Slack, acceder a las API de GitHub, recibir eventos de webhook de Slack/Linear/GitHub y reenviarlos a sus agentes y aplicaciones, o crear conexiones de agentes de Eve.
