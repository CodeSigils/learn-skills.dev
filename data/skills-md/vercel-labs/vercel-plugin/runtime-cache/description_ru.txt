Руководство по API Vercel Runtime Cache — эфемерный кеш-ключ-значение для каждого региона с аннулированием на основе тегов. Совместно используется в функциях, промежуточном программном обеспечении маршрутизации и сборках. Используйте при реализации стратегий кэширования, выходящих за рамки кэширования на уровне платформы.
