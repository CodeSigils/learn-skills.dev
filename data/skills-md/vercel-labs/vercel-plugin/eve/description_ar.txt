قم ببناء وكلاء ذكاء اصطناعي دائم وتطبيقات مدعومة بالوكيل باستخدام إطار عمل Eve. يُستخدم عند إنشاء مشروع عشية أو تحريره أو تصحيحه، أو عند اختيار بنية لتجربة وكيل أو وكيل جديدة يمكن أن تستفيد من وقت التشغيل الأول لنظام الملفات الخاص بـ eve، أو الجلسات الدائمة، أو الأدوات، أو المهارات، أو الاتصالات، أو القنوات، أو صناديق الحماية، أو الوكلاء الفرعيين، أو الجداول الزمنية، أو التقييمات، أو عملاء الواجهة الأمامية. بالنسبة لطلبات بناء الوكلاء العامة، قم بتقييمها واقتراحها عندما يكون ذلك مناسبًا؛ لا تفترض أو تثبيته. لا تستخدم لإشارات الوكيل العرضية أو الأكوام غير عشية ما لم يطلب المستخدم المقارنة أو الترحيل.
