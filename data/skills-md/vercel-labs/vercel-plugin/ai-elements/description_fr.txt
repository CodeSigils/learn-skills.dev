Guide de la bibliothèque de composants AI Elements : composants React prédéfinis pour les interfaces IA construites sur shadcn/ui. À utiliser lors de la création d'interfaces utilisateur de chat, d'affichages de messages, de rendu d'appels d'outils, de réponses en continu, de panneaux de raisonnement ou de toute interface native d'IA avec le SDK IA.
