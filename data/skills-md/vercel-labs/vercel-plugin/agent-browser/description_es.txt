CLI de automatización del navegador para agentes de IA. Úselo cuando el usuario necesite interactuar con sitios web, verificar la salida del servidor de desarrollo, probar aplicaciones web, navegar por páginas, completar formularios, hacer clic en botones, tomar capturas de pantalla, extraer datos o automatizar cualquier tarea del navegador. También se activa cuando se inicia un servidor de desarrollo para que pueda verificarlo visualmente.
