Browser-Automatisierungs-CLI für KI-Agenten. Verwenden Sie es, wenn der Benutzer mit Websites interagieren, die Ausgabe des Entwicklungsservers überprüfen, Web-Apps testen, durch Seiten navigieren, Formulare ausfüllen, auf Schaltflächen klicken, Screenshots erstellen, Daten extrahieren oder eine beliebige Browseraufgabe automatisieren muss. Wird auch ausgelöst, wenn ein Entwicklungsserver gestartet wird, damit Sie ihn visuell überprüfen können.
