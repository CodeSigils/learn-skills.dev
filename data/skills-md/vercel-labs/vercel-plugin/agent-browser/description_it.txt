CLI di automazione del browser per agenti AI. Da utilizzare quando l'utente deve interagire con siti Web, verificare l'output del server di sviluppo, testare app Web, navigare tra le pagine, compilare moduli, fare clic su pulsanti, acquisire screenshot, estrarre dati o automatizzare qualsiasi attività del browser. Si attiva anche all'avvio di un server di sviluppo in modo da poterlo verificare visivamente.
