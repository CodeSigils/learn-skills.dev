CLI d’automatisation du navigateur pour les agents IA. À utiliser lorsque l'utilisateur doit interagir avec des sites Web, vérifier les sorties du serveur de développement, tester des applications Web, parcourir des pages, remplir des formulaires, cliquer sur des boutons, prendre des captures d'écran, extraire des données ou automatiser n'importe quelle tâche du navigateur. Se déclenche également au démarrage d'un serveur de développement afin que vous puissiez le vérifier visuellement.
