يُستخدم لتحسين تكلفة Vercel والأداء في المشروعات المنشورة، وخاصة Next.js وSvelteKit وNuxt وتطبيقات Astro المحدودة. اجمع مقاييس Vercel والاستخدام وتكوين المشروع ونتائج فحص التعليمات البرمجية أولاً؛ التحقيق فقط في المرشحين المدعومين بالقياس؛ إنتاج توصيات مرتبة ترتكز على ملفات تم التحقق منها ومستندات Vercel/framework المدركة للإصدار. تفعيل تخفيض فاتورة Vercel، أو المسارات البطيئة أو المكلفة، أو فرص التخزين المؤقت، أو استدعاءات الوظائف، أو دقائق البناء، أو النقل السريع للبيانات، أو مؤشرات الويب الأساسية، أو إدارة الروبوتات، أو حوسبة السوائل، أو طلبات توزيع التكاليف.
