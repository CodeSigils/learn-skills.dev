À utiliser pour l'optimisation des coûts et des performances de Vercel sur les projets déployés, en particulier Next.js, SvelteKit, Nuxt et les applications Astro limitées. Collectez d'abord les métriques Vercel, l'utilisation, la configuration du projet et les résultats de l'analyse du code ; enquêter uniquement sur les candidats basés sur des métriques ; produire des recommandations classées fondées sur des fichiers vérifiés et des documents Vercel/framework tenant compte des versions. Déclencheur pour la réduction de la facture Vercel, les itinéraires lents ou coûteux, les opportunités de mise en cache, les appels de fonctions, les minutes de construction, le transfert de données rapide, les éléments essentiels du Web, la gestion des robots, le calcul fluide ou les demandes de répartition des coûts.
