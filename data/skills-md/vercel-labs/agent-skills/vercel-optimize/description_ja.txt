デプロイされたプロジェクト、特に Next.js、SvelteKit、Nuxt、および限定された Astro アプリでの Vercel のコストとパフォーマンスの最適化に使用します。まず Vercel メトリクス、使用状況、プロジェクト構成、およびコード スキャン結果を収集します。指標に裏付けられた候補のみを調査します。検証済みのファイルとバージョンを認識した Vercel/フレームワーク ドキュメントに基づいて、ランク付けされた推奨事項を生成します。 Vercel の請求額削減、遅いまたは高価なルート、キャッシュの機会、関数の呼び出し、ビルド時間、高速データ転送、コア Web バイタル、ボット管理、流動的なコンピューティング、またはコストの内訳リクエストのトリガー。
