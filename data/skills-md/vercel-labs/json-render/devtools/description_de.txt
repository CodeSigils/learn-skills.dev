Drop-in-Inspektorfeld für jede JSON-Render-App. Verwenden Sie diese Option, wenn der Benutzer eine generative Benutzeroberfläche debuggen, den Spezifikationsbaum untersuchen, den Status zur Laufzeit bearbeiten, gesendete Aktionen anzeigen, Stream-Patches live verfolgen, einen Katalog durchsuchen oder DOM-Elemente auswählen möchte, um ihre Spezifikationsschlüssel zu finden. Zu den Auslösern gehören „Devtools hinzufügen“, „JSON-Render debuggen“, „Spezifikation überprüfen“, „Warum wird dieses Element nicht gerendert“, „Status zur Laufzeit anzeigen“ oder Anforderungen zum Anzapfen von Streams/Erfassen von Aktionsprotokollen für „@json-render/devtools“.
