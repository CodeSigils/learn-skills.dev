Вставная панель инспектора для любого приложения json-рендеринга. Используйте, когда пользователь хочет отладить генеративный пользовательский интерфейс, проверить дерево спецификаций, отредактировать состояние во время выполнения, просмотреть отправленные действия, следить за исправлениями потока в реальном времени, просмотреть каталог или выбрать элементы DOM, чтобы найти их ключи спецификации. Триггеры включают в себя «добавить инструменты разработчика», «отладку json-render», «проверить спецификацию», «почему этот элемент не отображается», «просмотреть состояние во время выполнения» или запросы на переключение потоков/захват журналов действий для `@json-render/devtools`.
