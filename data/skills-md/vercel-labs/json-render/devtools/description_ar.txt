لوحة مفتش منسدلة لأي تطبيق json-render. يُستخدم عندما يريد المستخدم تصحيح أخطاء واجهة مستخدم مولدة، أو فحص شجرة المواصفات، أو تحرير الحالة في وقت التشغيل، أو الاطلاع على الإجراءات المرسلة، أو متابعة تصحيحات البث مباشرة، أو تصفح الكتالوج، أو اختيار عناصر DOM للعثور على مفاتيح المواصفات الخاصة بها. تتضمن المشغلات "إضافة أدوات تطوير"، أو "تصحيح أخطاء json-render"، أو "فحص المواصفات"، أو "لماذا لا يتم عرض هذا العنصر"، أو "رؤية الحالة في وقت التشغيل"، أو طلبات النقر على التدفقات/التقاط سجلات الإجراءات لـ `@json-render/devtools`.
