Pannello di ispezione drop-in per qualsiasi app di rendering json. Da utilizzare quando l'utente desidera eseguire il debug di un'interfaccia utente generativa, ispezionare l'albero delle specifiche, modificare lo stato in fase di esecuzione, visualizzare le azioni inviate, seguire le patch del flusso in tempo reale, sfogliare un catalogo o selezionare elementi DOM per trovare le chiavi delle specifiche. I trigger includono "aggiungi devtools", "debug di json-render", "ispeziona le specifiche", "perché questo elemento non viene visualizzato", "visualizza lo stato in fase di esecuzione" o richieste di toccare flussi/acquisire registri di azioni per `@json-render/devtools`.
