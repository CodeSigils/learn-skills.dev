Panel de inspección desplegable para cualquier aplicación de renderizado json. Úselo cuando el usuario desee depurar una interfaz de usuario generativa, inspeccionar el árbol de especificaciones, editar el estado en tiempo de ejecución, ver las acciones enviadas, seguir los parches de transmisión en vivo, explorar un catálogo o seleccionar elementos DOM para encontrar sus claves de especificaciones. Los activadores incluyen "agregar devtools", "depurar json-render", "inspeccionar la especificación", "por qué este elemento no se procesa", "ver el estado en tiempo de ejecución" o solicitudes para aprovechar transmisiones/capturar registros de acciones para `@json-render/devtools`.
