Средство рендеринга Next.js для json-рендеринга, которое превращает спецификации JSON в полноценные приложения Next.js с маршрутами, макетами, SSR и метаданными. Используйте при работе с @json-render/next, создании приложений Next.js на основе спецификаций JSON или создании многостраничных приложений, созданных искусственным интеллектом.
