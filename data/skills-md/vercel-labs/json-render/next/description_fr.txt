Moteur de rendu Next.js pour json-render qui transforme les spécifications JSON en applications Next.js complètes avec des itinéraires, des mises en page, SSR et des métadonnées. À utiliser lorsque vous travaillez avec @json-render/next, créez des applications Next.js à partir des spécifications JSON ou créez des applications multipages générées par l'IA.
