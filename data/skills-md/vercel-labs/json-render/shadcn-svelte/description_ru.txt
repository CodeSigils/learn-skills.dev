Предварительно созданные компоненты shadcn-svelte для приложений Svelte с json-рендерингом. Используйте при работе с @json-render/shadcn-svelte, добавлении стандартных компонентов пользовательского интерфейса в каталог Svelte или создании веб-интерфейсов Svelte с помощью компонентов shadcn-svelte + Tailwind CSS.
