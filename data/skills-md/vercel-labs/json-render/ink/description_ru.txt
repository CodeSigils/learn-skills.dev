Средство визуализации терминала Ink для json-рендеринга, которое превращает спецификации JSON в интерактивные пользовательские интерфейсы терминала. Используйте при работе с @json-render/ink, создании пользовательского интерфейса терминала из JSON, создании каталогов компонентов терминала или рендеринге спецификаций, созданных искусственным интеллектом, в терминале.
