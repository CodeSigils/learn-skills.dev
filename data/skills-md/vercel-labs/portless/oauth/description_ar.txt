قم بتكوين موفري OAuth (Google وApple وMicrosoft وFacebook وGitHub وما إلى ذلك) للعمل مع عناوين URL المحلية للتطوير بدون منفذ. يُستخدم عند إعداد عناوين URI لإعادة توجيه OAuth، أو إصلاح أخطاء "redirect_uri_mismatch" أو "إعادة التوجيه غير الصالحة"، أو تكوين موفري تسجيل الدخول للتطوير المحلي، أو عندما يرفض الموفر نطاقات .localhost الفرعية. تتضمن المشغلات "OAuth لا يعمل مع بدون منفذ"، أو "عدم تطابق URI لإعادة التوجيه"، أو "فشل تسجيل الدخول إلى Google/Apple/Microsoft محليًا"، أو "تكوين OAuth للمطور المحلي"، أو أي مهمة تتضمن عناوين URL لرد اتصال OAuth مع نطاقات بدون منفذ.
