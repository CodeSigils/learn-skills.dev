Настройте поставщиков OAuth (Google, Apple, Microsoft, Facebook, GitHub и т. д.) для работы с URL-адресами локальных разработчиков без портов. Используйте при настройке URI перенаправления OAuth, исправлении ошибок «redirect_uri_mismatch» или «недопустимое перенаправление», настройке поставщиков входа в систему для локальной разработки или когда поставщик отклоняет поддомены .localhost. Триггеры включают в себя «OAuth не работает с портами без портов», «несоответствие URI перенаправления», «Ошибка входа в систему Google/Apple/Microsoft локально», «Настройка OAuth для локальной разработки» или любая задача, включающая URL-адреса обратного вызова OAuth с доменами без портов.
