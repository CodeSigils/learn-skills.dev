Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Caching in einem Next.js 16+ App Router-Projekt entwerfen oder implementieren möchte – Einrichten der Anweisung „Cache verwenden“, Erstellen einer Cache-Tag-Registrierung, Verknüpfen von Mutationen mit Ungültigkeitsdienstprogrammen, Strukturieren von Suspense-Grenzen für teilweises Vorrendern, Behandeln personalisierter Inhalte in der Nähe von Cache-Grenzen, Auswählen von CacheLife-Profilen, korrektes Aufrufen von CacheTag/UpdateTag/RevalidateTag, Migrieren von unstable_cache oder Debuggen veralteter oder falsch aktueller Daten. Wird auch dann ausgelöst, wenn der Benutzer nur seine Domain beschreibt (z. B. „Ich habe eine Beitragstabelle“) und fragt, wie er sie richtig zwischenspeichern soll.
