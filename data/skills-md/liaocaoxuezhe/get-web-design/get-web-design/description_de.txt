Diese Fähigkeit sollte verwendet werden, wenn der Benutzer einen vollständigen DESIGN.md-Styleguide (Frontmatter + Design Thinking + AI-Stilanalyse + komprimierte CSS-Beweise + negative Einschränkungen) aus einer beliebigen Live-Website-URL extrahieren möchte. Es erfasst 3 Ansichtsfenster-Screenshots, probiert DOM und berechnetes CSS über chrome-devtools MCP aus, fordert ein vom Benutzer konfiguriertes multimodales LLM auf, den visuellen Stil von Screenshots + DOM zu analysieren, und führt dann alles in einer einzigen DESIGN.md-Datei zusammen. Zu den Triggerphrasen gehören „Design aus einer URL extrahieren“, „生成 DESIGN.md“, „分析这个网站的设计风格“ und „Webdesign abrufen“.
