Этот навык следует использовать, когда пользователь хочет извлечь полное руководство по стилю DESIGN.md (внешняя сторона + дизайн-мышление + анализ стиля AI + сжатые доказательства CSS + негативные ограничения) из любого действующего URL-адреса веб-сайта. Он захватывает 3 скриншота области просмотра, сэмплирует DOM и вычисляет CSS с помощью chrome-devtools MCP, запрашивает настроенный пользователем мультимодальный LLM для анализа визуального стиля из снимков экрана + DOM, а затем объединяет все в один файл DESIGN.md. Триггерные фразы включают «извлечь дизайн из URL-адреса», «生成 DESIGN.md», «分析这个网站的设计风格», «получить веб-дизайн».
