Questa competenza dovrebbe essere utilizzata quando l'utente desidera estrarre una guida di stile DESIGN.md completa (frontmatter + design thinking + analisi di stile AI + prove CSS compresse + vincoli negativi) da qualsiasi URL di sito Web live. Cattura 3 screenshot del viewport, campiona DOM e CSS calcolato tramite MCP di chrome-devtools, chiede a un LLM multimodale configurato dall'utente di analizzare lo stile visivo da screenshot+DOM, quindi unisce tutto in un unico file DESIGN.md. Le frasi trigger includono "estrai design da un URL", "生成 DESIGN.md", "分析这个网站的设计风格", "ottieni web design".
