Cette compétence doit être utilisée lorsque l'utilisateur souhaite extraire un guide de style DESIGN.md complet (frontmatter + design thinking + analyse de style IA + preuves CSS compressées + contraintes négatives) à partir de n'importe quelle URL de site Web en direct. Il capture 3 captures d'écran de fenêtre, des échantillons de DOM et du CSS calculé via Chrome-devtools MCP, demande à un LLM multimodal configuré par l'utilisateur d'analyser le style visuel à partir des captures d'écran + DOM, puis fusionne le tout dans un seul fichier DESIGN.md. Les expressions de déclenchement incluent « extraire la conception d'une URL », « 生成 DESIGN.md », « 分析这个网站的设计风格 », « obtenir une conception Web ».
