Esta habilidad debe usarse cuando el usuario desea extraer una guía de estilo DESIGN.md completa (frontmatter + pensamiento de diseño + análisis de estilo de IA + evidencia CSS comprimida + restricciones negativas) de cualquier URL de un sitio web activo. Captura 3 capturas de pantalla de la ventana gráfica, muestra DOM y CSS calculado a través de Chrome-devtools MCP, solicita a un LLM multimodal configurado por el usuario que analice el estilo visual de las capturas de pantalla + DOM y luego fusiona todo en un solo archivo DESIGN.md. Las frases desencadenantes incluyen "extraer diseño de una URL", "生成 DESIGN.md", "分析这个网站的设计风格", "obtener diseño web".
