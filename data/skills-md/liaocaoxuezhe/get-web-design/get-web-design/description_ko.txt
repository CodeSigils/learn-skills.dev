이 기술은 사용자가 라이브 웹사이트 URL에서 완전한 DESIGN.md 스타일 가이드(머리말 + 디자인 사고 + AI 스타일 분석 + 압축된 CSS 증거 + 부정적인 제약 조건)를 추출하려고 할 때 사용해야 합니다. 3개의 뷰포트 스크린샷을 캡처하고 chrome-devtools MCP를 통해 DOM 및 계산된 CSS를 샘플링하고 사용자가 구성한 다중 모달 LLM에 스크린샷+DOM의 시각적 스타일을 분석하도록 요청한 다음 모든 것을 단일 DESIGN.md 파일로 병합합니다. 트리거 문구에는 "url에서 디자인 추출", "生成 DESIGN.md", "分析这个网站的设计风格", "웹 디자인 가져오기"가 포함됩니다.
