このスキルは、ユーザーがライブ Web サイトの URL から完全な DESIGN.md スタイル ガイド (フロントマター + デザイン思考 + AI スタイル分析 + 圧縮 CSS 証拠 + ネガティブ制約) を抽出したい場合に使用する必要があります。 chrome-devtools MCP を介して 3 つのビューポート スクリーンショット、サンプル DOM、計算された CSS をキャプチャし、ユーザー設定のマルチモーダル LLM にスクリーンショット + DOM からのビジュアル スタイルを分析するよう依頼し、すべてを 1 つの DESIGN.md ファイルにマージします。トリガー フレーズには、「URL からデザインを抽出」、「DESIGN の生成.md」、「分析这个网站的设计风格」、「Web デザインの取得」などがあります。
