مستوى البكسل 750 بكسل من الصورة إلى الكود وسير عمل التقطيع. يُستخدم عندما يحتاج Codex إلى تحويل صورة واجهة المستخدم المحددة حاليًا، أو لقطة الشاشة، أو نموذج تصميم التطبيق/الويب، أو تصدير Figma، أو تصميم صورة طويلة إلى كود وإخراج أصول شريحة PNG شفافة مستقلة. مناسب للمهام التي تتطلب استعادة نسبية صارمة بنسبة 1:1، وعرض لوحة فنية يبلغ 750 بكسل بالضبط، وتعطيل تحسين التخطيط التلقائي، ونص قابل للتحرير، ورسومات بسيطة كمتجهات/رموز أصلية، واستخراج PNG الشفاف المستقل للأيقونات والصور النقطية، والتحقق المستقل من ثلاثة أنواع من الوحدات: الطبقات المتجهة، وطبقات النص، وشرائح الصور النقطية/الأيقونات.
