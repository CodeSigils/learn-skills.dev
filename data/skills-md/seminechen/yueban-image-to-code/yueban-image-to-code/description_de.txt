750-Pixel-Bild-zu-Code- und Slicing-Workflow auf Pixelebene. Wird verwendet, wenn Codex das aktuell ausgewählte UI-Bild, den Screenshot, das App-/Webdesign-Mockup, den Figma-Export oder das Design-Langbild in Code konvertieren und unabhängige transparente PNG-Slice-Assets ausgeben muss. Geeignet für Aufgaben, die eine strikte 1:1-Proportionalwiederherstellung, eine Zeichenflächenbreite von genau 750 Pixel, Deaktivierung der automatischen Layoutoptimierung, bearbeitbaren Text, einfache Grafiken als native Vektoren/Code, unabhängige transparente PNG-Extraktion von Symbolen und Bitmaps und unabhängige Validierung von drei Modultypen erfordern: Vektorebenen, Textebenen und Bitmap-/Symbol-Slices.
