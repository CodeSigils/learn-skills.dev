750-Pixel-Bild-zu-Code- und Slicing-Workflow auf Pixelebene. Verwenden Sie dies, wenn Codex das aktuell ausgewählte UI-Bild, den Screenshot, das App-/Webdesign-Mockup, den Figma-Export oder das Design-Langbild in Code konvertieren und unabhängige transparente PNG-Slice-Assets ausgeben muss. Es eignet sich für eine strikte 1:1-Proportionalwiedergabe, eine Zeichenflächenbreite, die genau auf 750 Pixel eingestellt ist, die Deaktivierung der automatischen Layoutoptimierung, bearbeitbaren Text, native Vektoren/Codes für einfache Grafiken, unabhängige transparente PNG-Extraktion von Symbolen und Bitmaps und die separate Annahme von Aufgaben über drei Modultypen hinweg: Vektorebenen, Textebenen und Bitmap-/Symbol-Slices.
