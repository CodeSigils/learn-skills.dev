Flujo de trabajo de corte y conversión de imagen a código de 750 píxeles con perfección de píxeles. Se utiliza cuando Codex necesita convertir la imagen de la interfaz de usuario, la captura de pantalla, la maqueta de aplicación/diseño web, la exportación de Figma o la imagen de diseño larga actualmente seleccionada en código y generar recursos de corte PNG transparentes independientes. Adecuado para tareas que requieren una estricta restauración proporcional 1:1, un ancho de lienzo de exactamente 750 px, sin optimización automática del diseño, texto editable, vector/código nativo para gráficos simples, extracción PNG transparente independiente de iconos y mapas de bits, y validación separada de módulos por capas vectoriales, capas de texto y sectores de mapas de bits/iconos.
