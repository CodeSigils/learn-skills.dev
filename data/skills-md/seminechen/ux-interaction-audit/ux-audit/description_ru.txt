Аудит взаимодействия UX: китайский структурированный помощник по оценке UX и локальный пользовательский интерфейс браузера для снимков экрана интерфейса, макетов дизайна продукта, снимков экрана веб-страниц/страниц приложений и описаний страниц. Используйте, когда пользователь просит оценить UX, дизайн взаимодействия, удобство использования, ясность страницы, поток конверсий, формы, доступность, риск доверия, улучшение дизайна или открыть/использовать интерфейс аудита UX в браузере. Создает отчеты по аудиту UX на китайском языке по 9 уровням UX, оценивает разумность взаимодействия, а при предоставлении изображений по умолчанию использует аннотации проблем и рекомендации по сравнению версий, если пользователь не откажется от этого.
