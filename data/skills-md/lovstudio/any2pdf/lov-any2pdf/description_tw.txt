使用 reportlab 將 Markdown 文件轉換為專業排版的 PDF 檔案。處理 CJK/Latin 混合文字、圍欄程式碼區塊、表格、區塊引用、黑曜石標註、內聯圖像、表情符號回退、LaTeX 樣式公式、封面、可點擊目錄、PDF 書籤、水印和頁碼。支援多種顏色主題（可配置學術、Nord、GitHub Light、Solarized 等），並針對中文技術報告進行了實戰檢驗。每當使用者想要將 .md 檔案轉換為樣式 PDF、從 Markdown 產生報告 PDF 或從 Markdown 內容建立可列印文件時，請使用此技能 - 特別是在涉及 CJK 字元、程式碼區塊或表格時。當使用者提到“markdown to PDF”、“md2pdf”、“any2pdf”、“md轉pdf”、“報告產生”，或要求來自 markdown 來源的“排版”或“專業格式”PDF 時也會觸發。
