قم بتحويل مستندات Markdown إلى ملفات PDF منسقة بشكل احترافي باستخدام Reportlab. يتعامل مع النص المختلط CJK/Latin، وكتل التعليمات البرمجية المسيجة، والجداول، وعلامات الاقتباس، ووسائل شرح Obsidian، والصور المضمنة، والرموز التعبيرية الاحتياطية، وصيغ نمط LaTeX، وصفحات الغلاف، وجدول المحتويات القابل للنقر، وإشارات PDF، والعلامات المائية، وأرقام الصفحات. يدعم سمات الألوان المتعددة (Configurable Academic، Nord، GitHub Light، Solarized، وما إلى ذلك) وتم اختباره في المعركة للتقارير الفنية الصينية. استخدم هذه المهارة عندما يريد المستخدم تحويل ملف .md إلى ملف PDF ذو نمط، أو إنشاء تقرير PDF من تخفيض السعر، أو إنشاء مستند جاهز للطباعة من محتوى تخفيض السعر - خاصة إذا كانت أحرف CJK، أو كتل التعليمات البرمجية، أو الجداول متضمنة. يتم تشغيله أيضًا عندما يذكر المستخدم "markdown to PDF"، أو "md2pdf"، أو "any2pdf"، أو "md转pdf"، أو "报告生成"، أو يطلب ملف PDF "مجموعة منضدية" أو "منسق بشكل احترافي" من مصدر تخفيض السعر.
