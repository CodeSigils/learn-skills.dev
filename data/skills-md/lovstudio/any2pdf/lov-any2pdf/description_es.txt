Convierta documentos Markdown en archivos PDF tipográficos profesionalmente con reportlab. Maneja texto mixto CJK/latín, bloques de código delimitados, tablas, citas en bloque, leyendas de obsidiana, imágenes en línea, respaldo de emoji, fórmulas de estilo LaTeX, portadas, índice de contenido en el que se puede hacer clic, marcadores de PDF, marcas de agua y números de página. Admite múltiples temas de color (Configurable Academic, Nord, GitHub Light, Solarized, etc.) y está probado en batalla para informes técnicos chinos. Utilice esta habilidad siempre que el usuario quiera convertir un archivo .md en un PDF con estilo, generar un informe PDF a partir de rebajas o crear un documento listo para imprimir a partir de contenido de rebajas, especialmente si se trata de caracteres CJK, bloques de código o tablas. También se activa cuando el usuario menciona "markdown to PDF", "md2pdf", "any2pdf", "md转pdf", "报告生成", o solicita un PDF "compuesto" o "formateado profesionalmente" de la fuente de Markdown.
