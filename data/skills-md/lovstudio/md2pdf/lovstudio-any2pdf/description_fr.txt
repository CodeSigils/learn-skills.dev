Convertissez des documents Markdown en fichiers PDF rédigés de manière professionnelle avec reportlab. Gère le texte mixte CJK/latin, les blocs de code clôturés, les tableaux, les citations, les légendes d'obsidienne, les images en ligne, les emoji de secours, les formules de style LaTeX, les pages de garde, la table des matières cliquable, les signets PDF, les filigranes et les numéros de page. Prend en charge plusieurs thèmes de couleurs (Warm Academic, Nord, GitHub Light, Solarized, etc.) et est testé au combat pour les rapports techniques chinois. Utilisez cette compétence chaque fois que l'utilisateur souhaite transformer un fichier .md en un PDF stylisé, générer un rapport PDF à partir de markdown ou créer un document prêt à imprimer à partir de contenu markdown, en particulier si des caractères CJK, des blocs de code ou des tableaux sont impliqués.
