Стандартизируйте сообщения коммитов Git. Прочитайте разницу git, чтобы понять цель изменений кода, сгенерируйте сообщение фиксации, соответствующее спецификации обычных коммитов (английский тип + описание на китайском языке), отобразите его пользователю для подтверждения, а затем выполните git commit. Используйте это, когда пользователь хочет зафиксировать код, сгенерировать сообщение о фиксации или стандартизировать сообщение о фиксации. Китайские триггерные слова: отправить, отправить код, зафиксировать, сообщение о фиксации, git commit, сгенерировать фиксацию.
