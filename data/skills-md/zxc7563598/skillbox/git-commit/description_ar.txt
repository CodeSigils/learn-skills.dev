توحيد رسائل الالتزام Git. اقرأ فرق git لفهم الغرض من تغييرات التعليمات البرمجية، وقم بإنشاء رسالة التزام تتوافق مع مواصفات الالتزامات التقليدية (النوع الإنجليزي + الوصف الصيني)، وعرضها للمستخدم للتأكيد، ثم قم بتنفيذ التزام git. استخدم هذا عندما يريد المستخدم تنفيذ تعليمات برمجية، أو إنشاء رسالة التزام، أو توحيد رسالة التزام. كلمات التشغيل الصينية: إرسال، إرسال التعليمات البرمجية، الالتزام، رسالة الالتزام، git الالتزام، إنشاء الالتزام.
