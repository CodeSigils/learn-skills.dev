Standardisez les messages de validation Git. Lisez le git diff pour comprendre l'intention des modifications de code, générez un message de validation conforme à la spécification Conventional Commits (type anglais + description chinoise), affichez-le à l'utilisateur pour confirmation, puis exécutez git commit. Utilisez-le lorsque l'utilisateur souhaite valider du code, générer un message de validation ou standardiser un message de validation. Mots déclencheurs chinois : soumettre, soumettre du code, valider, message de validation, git commit, générer un commit.
