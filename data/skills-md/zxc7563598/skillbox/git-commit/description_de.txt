Git-Commit-Nachrichten standardisieren. Lesen Sie den Git-Diff, um die Absicht der Codeänderungen zu verstehen, generieren Sie eine Commit-Nachricht, die der Spezifikation für konventionelle Commits entspricht (englischer Typ + chinesische Beschreibung), zeigen Sie sie dem Benutzer zur Bestätigung an und führen Sie dann Git Commit aus. Verwenden Sie dies, wenn der Benutzer Code festschreiben, eine Festschreibungsnachricht generieren oder eine Festschreibungsnachricht standardisieren möchte. Chinesische Auslösewörter: Senden, Code senden, Festschreiben, Nachricht festschreiben, Git-Festschreiben, Festschreiben generieren.
