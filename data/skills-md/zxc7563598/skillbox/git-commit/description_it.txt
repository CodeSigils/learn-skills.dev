Standardizza i messaggi di commit Git. Leggi il diff git per comprendere lo scopo delle modifiche al codice, genera un messaggio di commit conforme alla specifica Conventional Commits (tipo inglese + descrizione cinese), mostralo all'utente per conferma, quindi esegui git commit. Utilizzalo quando l'utente desidera eseguire il commit del codice, generare un messaggio di commit o standardizzare un messaggio di commit. Parole trigger cinesi: invia, invia codice, commit, messaggio di commit, git commit, genera commit.
