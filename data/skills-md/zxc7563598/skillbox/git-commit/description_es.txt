Estandarice los mensajes de confirmación de Git. Lea el git diff para comprender la intención de los cambios de código, genere un mensaje de confirmación que se ajuste a la especificación de confirmaciones convencionales (tipo en inglés + descripción en chino), muéstrelo al usuario para su confirmación y luego ejecute git commit. Úselo cuando el usuario quiera confirmar código, generar un mensaje de confirmación o estandarizar un mensaje de confirmación. Palabras desencadenantes chinas: enviar, enviar código, confirmar, enviar mensaje, git confirmar, generar confirmación.
