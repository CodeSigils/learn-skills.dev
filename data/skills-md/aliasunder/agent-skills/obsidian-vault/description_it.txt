Crea, modifica e controlla le note in un caveau di Obsidian. Gestisce proprietà del frontmatter, wikilink, incorporamenti, callout, attività, riferimenti a blocchi, tag e diagrammi a sirena. Compatibile con i plug-in: query Dataview e campi in linea, sintassi emoji di Tasks, schede Kanban, campi Meta Bind, modelli Templater, schemi Bases e Canvas JSON. SEMPRE ATTIVO: se la directory di lavoro si trova all'interno di un vault Obsidian (una directory .obsidian/ in qualsiasi antenato o un CLAUDE.md che identifica il progetto come incorporato nel vault), utilizza questa abilità per TUTTE le operazioni sui file .md, inclusi CLAUDE.md, TASKS.md e i registri di sessione, anche quando Obsidian non è menzionato. Trigger: "crea/modifica una nota", "aggiorna frontmatter", "aggiungi tag", "correggi i collegamenti", "scrivi una query Dataview", "correggi questo callout", "aggiungi un'attività", "modifica la mia bacheca Kanban", "crea un modello" o qualsiasi attività di modifica delle note in un vault. NON per: file .md esterni a un vault (README di repository di codice, problemi di GitHub, contenuto di siti statici), linting di markdown generico o sviluppo di plug-in Obsidian.
