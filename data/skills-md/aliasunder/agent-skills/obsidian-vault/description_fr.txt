Créez, modifiez et auditez des notes dans un coffre-fort Obsidian. Gère les propriétés de premier plan, les liens wiki, les intégrations, les légendes, les tâches, les références de bloc, les balises et les diagrammes Mermaid. Compatible avec les plugins : requêtes Dataview et champs en ligne, syntaxe emoji des tâches, tableaux Kanban, champs Meta Bind, modèles Templater, schémas de base et Canvas JSON. TOUJOURS activé : si le répertoire de travail se trouve dans un coffre-fort Obsidian (un répertoire .obsidian/ dans n'importe quel ancêtre ou un CLAUDE.md identifiant le projet comme étant intégré au coffre-fort), utilisez cette compétence pour TOUTES les opérations sur les fichiers .md - y compris CLAUDE.md, TASKS.md et les journaux de session - même lorsque Obsidian n'est pas mentionné. Déclencheurs : "créer/modifier une note", "mettre à jour le frontmatter", "ajouter des balises", "corriger les liens", "écrire une requête Dataview", "corriger cette légende", "ajouter une tâche", "modifier mon tableau Kanban", "créer un modèle" ou toute tâche d'édition de notes dans un coffre-fort. PAS pour : les fichiers .md en dehors d'un coffre-fort (README de dépôt de code, problèmes GitHub, contenu de site statique), le peluchage générique ou le développement de plugins Obsidian.
