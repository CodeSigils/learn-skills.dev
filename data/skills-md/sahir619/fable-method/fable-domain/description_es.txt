Discuta un dominio con el usuario, investíguelo a partir de fuentes reales y luego genere un paquete de habilidades confiable para él: un flujo de trabajo paso a paso con un diagrama de flujo, un adaptador de dominio, un dispositivo de trampa y una evaluación de humo. Úselo cuando el usuario diga "/fable-domain <sector>", "crear una habilidad para <dominio>", "agregar un dominio al método fable" o "dar un modelo menor del flujo de trabajo de Fable para <dominio>". El paquete es el entregable; un flujo de trabajo sin su diagrama de flujo, fuentes y capturas no se realiza.
