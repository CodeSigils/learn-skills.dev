Обсудите домен с пользователем, изучите его из реальных источников, а затем создайте для него надежный набор навыков — пошаговый рабочий процесс с блок-схемой, адаптером домена, приспособлением для ловушек и оценкой дыма. Используйте, когда пользователь говорит «/fable-domain <сектор>», «создать навык для <домен>», «добавить домен в метод fable» или «задать рабочий процесс Fable меньшей модели для <домен>». Пакет — это результат; рабочий процесс без его блок-схемы, источников и ловушек невозможен.
