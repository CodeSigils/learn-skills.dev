Сквозной организованный рабочий процесс, который выполняет задачу так же, как сеансы Fable — параллельные субагенты доказательств, один фиксированный план, хирургическое выполнение с воротами намерения, агенты состязательной проверки, честный отчет, ориентированный на результат. Используйте для нетривиальных многошаговых задач, когда пользователь говорит «/fable-loop», «запустите цикл Fable» или «сделайте это так, как это сделал бы Fable». Только для правил без оркестровки используйте метод fable; для больших многоэтапных проектов отдайте предпочтение рабочему процессу GSD и используйте его внутри этапов.
