Desafíe las pruebas unitarias generadas por IA (o cualquier otra) para encontrar falsos positivos, pruebas que pasan contra comportamientos incorrectos. Utilice esta habilidad siempre que el usuario solicite revisar, auditar, validar o cuestionar la calidad de las pruebas, especialmente las pruebas generadas por IA para aumentar la cobertura del código. Activadores de frases como "revisar estas pruebas", "¿son realmente correctas estas pruebas?", "desafiar mis pruebas", "auditoría de calidad de las pruebas", "pruebas falsas positivas", "estas pruebas se generaron automáticamente", "la IA escribió estas pruebas", "la cobertura aumentó pero no confío en ellas", "¿estas pruebas prueban lo correcto?", "validar la corrección de la prueba", o cualquier situación en la que las pruebas existen junto con el código fuente y alguien quiere saber si las pruebas son genuinas. verificar el comportamiento correcto versus simplemente reflejar errores de implementación. También se activa cuando el usuario menciona una mayor cobertura de código con IA, pruebas generadas por copiloto o herramientas de generación de pruebas: estos son contextos de alto riesgo para pruebas falsas positivas.
