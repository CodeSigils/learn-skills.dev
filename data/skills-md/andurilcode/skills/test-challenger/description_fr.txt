Défiez les tests unitaires générés par l’IA (ou tout autre) pour trouver des faux positifs – des tests qui réussissent contre un mauvais comportement. Utilisez cette compétence chaque fois que l'utilisateur demande à examiner, auditer, valider ou contester la qualité des tests, en particulier les tests générés par l'IA pour augmenter la couverture du code. Déclencheurs sur des expressions telles que « examiner ces tests », « ces tests sont-ils réellement corrects ? », « contester mes tests », « audit de qualité des tests », « tests faussement positifs », « ces tests ont été générés automatiquement », « l'IA a écrit ces tests », « la couverture a augmenté mais je n'y fais pas confiance », « ces tests testent-ils la bonne chose ? », « valider l'exactitude des tests », ou toute situation où des tests existent à côté du code source et que quelqu'un veut pour savoir si les tests vérifient véritablement un comportement correct ou s'ils reflètent simplement des bogues d'implémentation. Déclenchez également lorsque l'utilisateur mentionne une couverture croissante du code avec l'IA, des tests générés par le copilote ou des outils de génération de tests : il s'agit de contextes à haut risque pour les tests faussement positifs.
