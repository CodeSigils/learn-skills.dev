ユーザーがコード、PR、差分、またはマージ リクエストのレビューを要求するとき、またはコードを貼り付けてフィードバックを求めるときは常に、このスキルを適用します。また、誰かが「レビューを準備する」、「この PR をチェックする」、「変更をレビューする」、「このコードについてどう思いますか」、「この PR はマージする準備ができていますか」、「レビューを手伝ってください」、またはコードの品質評価が関係する状況を求めたときにもトリガーされます。このスキルは人間のレビュー担当者の代わりをするものではありません。コンテキストを組み立て、表面の問題を事前にスキャンし、設計の一貫性に関する質問を生成し、知識伝達の機会をルーティングすることにより、人間のレビュー担当者を強化します。小さなスニペットにもこのスキルを使用してください。7 次元のフレームワークは適切にスケールダウンされます。ユーザーが何らかの形式で「コードレビュー」と言ったら、このスキルをトリガーします。
