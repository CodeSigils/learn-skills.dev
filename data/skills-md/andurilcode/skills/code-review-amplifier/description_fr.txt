Appliquez cette compétence chaque fois que l'utilisateur demande à réviser le code, un PR, une différence ou une demande de fusion - ou lorsqu'il colle du code et demande des commentaires à ce sujet. Se déclenche également lorsque quelqu'un demande de « préparer une révision », « vérifier ce PR », « réviser mes modifications », « que pensez-vous de ce code », « ce PR est-il prêt à fusionner », « aidez-moi à réviser », ou toute situation où l'évaluation de la qualité du code est impliquée. Cette compétence n’essaie PAS de remplacer le réviseur humain. Il amplifie les évaluateurs humains en rassemblant le contexte, en analysant préalablement les problèmes de surface, en générant des questions de cohérence de conception et en acheminant les opportunités de transfert de connaissances. Utilisez cette compétence même pour de petits extraits : le cadre à 7 dimensions se réduit gracieusement. Si l'utilisateur dit « révision du code » sous quelque forme que ce soit, déclenchez cette compétence.
