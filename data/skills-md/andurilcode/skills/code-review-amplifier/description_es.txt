Aplique esta habilidad siempre que el usuario solicite revisar el código, un PR, una diferenciación o una solicitud de fusión, o cuando pegue el código y solicite comentarios al respecto. También se activa cuando alguien pide "preparar una revisión", "verificar este PR", "revisar mis cambios", "qué piensas de este código", "este PR está listo para fusionarse", "ayúdame a revisar" o cualquier situación en la que esté involucrada la evaluación de la calidad del código. Esta habilidad NO intenta reemplazar al revisor humano. Amplifica a los revisores humanos al reunir el contexto, escanear previamente los problemas superficiales, generar preguntas sobre la coherencia del diseño y enrutar oportunidades de transferencia de conocimientos. Utilice esta habilidad incluso para fragmentos pequeños: el marco de 7 dimensiones se reduce con elegancia. Si el usuario dice "revisión de código" de cualquier forma, active esta habilidad.
