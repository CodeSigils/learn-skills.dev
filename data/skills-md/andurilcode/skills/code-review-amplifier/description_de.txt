Wenden Sie diese Fähigkeit immer dann an, wenn der Benutzer um die Überprüfung von Code, eine PR, einen Diff oder eine Zusammenführungsanfrage bittet – oder wenn er Code einfügt und um Feedback dazu bittet. Wird auch ausgelöst, wenn jemand darum bittet, „eine Überprüfung vorzubereiten“, „diese PR zu überprüfen“, „meine Änderungen zu überprüfen“, „Was halten Sie von diesem Code“, „Ist diese PR zum Zusammenführen bereit“, „hilft mir bei der Überprüfung“ oder in jeder Situation, in der es um die Bewertung der Codequalität geht. Diese Fähigkeit versucht NICHT, den menschlichen Prüfer zu ersetzen. Es stärkt menschliche Prüfer, indem es Kontexte zusammenstellt, Oberflächenprobleme vorab scannt, Fragen zur Designkohärenz generiert und Möglichkeiten zum Wissenstransfer weiterleitet. Nutzen Sie diese Fähigkeit auch für kleine Ausschnitte – das 7-dimensionale Framework lässt sich elegant verkleinern. Wenn der Benutzer in irgendeiner Form „Codeüberprüfung“ sagt, lösen Sie diesen Skill aus.
