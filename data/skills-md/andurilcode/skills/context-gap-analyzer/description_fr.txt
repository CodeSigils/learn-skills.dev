Identifiez le contexte implicite manquant dans une base de code qui améliorerait le plus les performances de l'agent : la connaissance que le code ne peut pas indiquer explicitement. Utilisez cette compétence chaque fois que quelqu'un demande à auditer, évaluer ou améliorer le contexte d'une base de code ; veut trouver ce qui n'est pas documenté mais qui est essentiel pour les agents ; demande « quel contexte ma base de code manque-t-elle ? », « pourquoi les agents continuent-ils à faire des erreurs ici ? », « comment puis-je améliorer les performances de l'agent sur mon dépôt ? », « que dois-je mettre dans mes fichiers AGENTS.md / CLAUDE.md / .context ? Se déclenche également lorsqu'un utilisateur configure l'infrastructure de contexte d'agent pour la première fois ou lorsque le code généré par l'agent continue de violer les conventions implicites. Il s'agit du principal outil de diagnostic de l'ingénieur contextuel.
