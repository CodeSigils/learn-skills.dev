Identifique el contexto implícito que falta en una base de código que mejoraría más el rendimiento del agente: el conocimiento que el código no puede indicar explícitamente. Utilice esta habilidad siempre que alguien solicite auditar, evaluar o mejorar el contexto de una base de código; quiere encontrar lo que está indocumentado pero es crítico para los agentes; pregunta "¿qué contexto le falta a mi base de código?", "¿por qué los agentes siguen cometiendo errores aquí?", "¿cómo mejoro el rendimiento del agente en mi repositorio?", "¿qué debo poner en mis archivos AGENTS.md / CLAUDE.md / .context?", "audita el contexto de mi base de código", "cobertura de contexto", "brechas de contexto", "¿qué necesita saber un agente sobre esta base de código?", o cualquier variación. También se activa cuando un usuario está configurando la infraestructura de contexto del agente por primera vez o cuando el código generado por el agente sigue violando convenciones implícitas. Esta es la principal herramienta de diagnóstico del ingeniero de contexto.
