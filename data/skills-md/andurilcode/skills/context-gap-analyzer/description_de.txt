Identifizieren Sie den in einer Codebasis fehlenden impliziten Kontext, der die Agentenleistung am meisten verbessern würde – das Wissen, das der Code nicht explizit erkennen kann. Verwenden Sie diese Fähigkeit immer dann, wenn jemand darum bittet, den Kontext einer Codebasis zu prüfen, zu bewerten oder zu verbessern. möchte herausfinden, was nicht dokumentiert, aber für Agenten von entscheidender Bedeutung ist; fragt: „Welcher Kontext fehlt in meiner Codebasis?“, „Warum machen Agenten hier immer wieder Fehler?“, „Wie verbessere ich die Agentenleistung in meinem Repo?“, „Was soll ich in meine AGENTS.md-/CLAUDE.md-/.context-Dateien einfügen?“, „Meinen Codebasiskontext prüfen“, „Kontextabdeckung“, „Kontextlücken“, „Was muss ein Agent über diese Codebasis wissen?“ oder eine beliebige Variation. Wird auch ausgelöst, wenn ein Benutzer zum ersten Mal die Agentenkontextinfrastruktur einrichtet oder wenn vom Agenten generierter Code weiterhin implizite Konventionen verletzt. Dies ist das primäre Diagnosetool des Kontextingenieurs.
