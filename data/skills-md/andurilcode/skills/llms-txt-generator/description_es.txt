Utilice esta habilidad siempre que alguien solicite generar un llms.txt, crear documentación compatible con LLM, producir un documento de contexto para una biblioteca o código base, crear una referencia lista para RAG, hacer que los documentos sean "legibles para el agente", crear una referencia rápida para desarrolladores o decir algo como "generar contexto para X", "crear un llms.txt para este repositorio", "crear un documento de referencia para NotebookLM", "convertir estos documentos en algo único". LLM puede usar', 'documento de contexto', 'hoja de referencia para desarrolladores de documentos'. También se activa cuando alguien proporciona una URL de repositorio de GitHub y solicita una síntesis de la documentación, o cuando trabaja dentro de una base de código y le pide que produzca una referencia independiente de cómo funciona. Esta es la herramienta de generación de documentos del ingeniero de contexto: convierte una documentación extensa en un contexto preciso, estructurado y eficiente en términos de tokens.
