Создавайте контекстные документы в стиле llms.txt — с бюджетом на токены и уценкой по разделам для каждой концепции, оптимизированной для использования LLM и RAG. Используйте этот навык всякий раз, когда кто-то просит сгенерировать llms.txt, создать документацию, удобную для LLM, создать контекстный документ для библиотеки или базы кода, создать ссылку для RAG, сделать документы «читаемыми для агента», создать краткий справочник для разработчика или сказать что-то вроде «создать контекст для X», «создать llms.txt для этого репозитория», «создать справочный документ для NotebookLM», «превратить эти документы во что-то, что может LLM». использовать», «контекстный документ», «шпаргалка разработчика из документации». Также срабатывает, когда кто-то предоставляет URL-адрес репозитория GitHub и запрашивает синтез документации или когда работает внутри базы кода и просит предоставить автономную ссылку о том, как это работает. Это инструмент для создания документации контекстного инженера — он превращает обширную документацию в точный, структурированный контекст с эффективным использованием токенов.
