Générez des documents contextuels de style llms.txt — Markdown budgétisé par jeton, section par concept, optimisé pour la consommation LLM et RAG. Utilisez cette compétence chaque fois que quelqu'un demande de générer un llms.txt, de créer une documentation adaptée au LLM, de produire un document contextuel pour une bibliothèque ou une base de code, de créer une référence prête pour RAG, de rendre les documents « lisibles par l'agent », de créer une référence rapide pour les développeurs, ou dit quelque chose comme « générer un contexte pour X », « créer un llms.txt pour ce dépôt », « créer un document de référence pour NotebookLM », « transformer ces documents en quelque chose qu'un LLM peut use', 'document contextuel', 'aide-mémoire du développeur à partir de la documentation'. Se déclenche également lorsque quelqu'un fournit une URL de dépôt GitHub et demande une synthèse de la documentation, ou lorsqu'il travaille dans une base de code et est invité à produire une référence autonome sur son fonctionnement. Il s'agit de l'outil de génération de documents de l'ingénieur de contexte : il transforme une documentation tentaculaire en un contexte précis, structuré et efficace en termes de jetons.
