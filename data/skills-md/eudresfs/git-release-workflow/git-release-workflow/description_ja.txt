Node.js/TypeScript リポジトリの自動化された Git バージョン管理とリリース ワークフロー。ユーザーが自動リリースの設定、セマンティック リリースの構成、従来のコミットの作成、変更ログの管理、または GitHub 上で CI/CD リリース パイプラインの確立を行う場合には、このスキルを使用します。また、ユーザーが「リリース」または「CI/CD」について明示的に言及していない場合でも、あらゆるプロジェクト コンテキストにおける commitlint、Husky、セマンティック バージョニング、またはコミット メッセージの書式設定に関する質問もトリガーされます。このスキルは、完全なワークフローとして連携して動作する、すぐに使用できる 2 つのクロード コード スラッシュ コマンドを提供します。
