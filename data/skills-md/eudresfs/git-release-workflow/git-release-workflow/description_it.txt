Controllo delle versioni git automatizzato e flusso di lavoro di rilascio per i repository Node.js/TypeScript. Utilizza questa competenza ogni volta che l'utente desidera impostare rilasci automatizzati, configurare il rilascio semantico, creare commit convenzionali, gestire i log delle modifiche o stabilire una pipeline di rilascio CI/CD su GitHub. Attiva anche domande su commitlint, Husky, controllo delle versioni semantico o formattazione dei messaggi di commit in qualsiasi contesto di progetto, anche se l'utente non menziona esplicitamente "release" o "CI/CD". Questa competenza fornisce due comandi barra di Claude Code pronti all'uso che funzionano insieme come un flusso di lavoro completo.
