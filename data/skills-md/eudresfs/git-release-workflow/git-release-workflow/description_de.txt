Automatisierter Git-Versionierungs- und Release-Workflow für Node.js/TypeScript-Repositorys. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer automatisierte Releases einrichten, semantische Releases konfigurieren, konventionelle Commits erstellen, Änderungsprotokolle verwalten oder eine CI/CD-Release-Pipeline auf GitHub einrichten möchte. Löst außerdem Fragen zu Commitlint, Husky, semantischer Versionierung oder Commit-Nachrichtenformatierung in jedem Projektkontext aus – auch wenn der Benutzer „Release“ oder „CI/CD“ nicht explizit erwähnt. Dieser Skill stellt zwei gebrauchsfertige Claude Code-Slash-Befehle bereit, die als vollständiger Workflow zusammenarbeiten.
