Flux de travail automatisé de gestion des versions et de publication de Git pour les référentiels Node.js/TypeScript. Utilisez cette compétence chaque fois que l'utilisateur souhaite configurer des versions automatisées, configurer la version sémantique, créer des validations conventionnelles, gérer les journaux de modifications ou établir un pipeline de versions CI/CD sur GitHub. Déclenche également des questions sur commitlint, Husky, la gestion des versions sémantiques ou le formatage des messages de validation dans n'importe quel contexte de projet, même si l'utilisateur ne mentionne pas explicitement « release » ou « CI/CD ». Cette compétence fournit deux commandes slash Claude Code prêtes à l'emploi qui fonctionnent ensemble comme un flux de travail complet.
