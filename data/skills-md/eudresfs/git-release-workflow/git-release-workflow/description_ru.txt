Автоматизированное управление версиями git и рабочий процесс выпуска для репозиториев Node.js/TypeScript. Используйте этот навык всякий раз, когда пользователь хочет настроить автоматические выпуски, настроить семантический выпуск, создать обычные фиксации, управлять журналами изменений или установить конвейер выпусков CI/CD на GitHub. Также вызывает вопросы о коммитлинте, хаски, семантическом управлении версиями или форматировании сообщений о фиксации в любом контексте проекта — даже если пользователь не упоминает явно «релиз» или «CI/CD». Этот навык предоставляет две готовые к использованию слэш-команды Claude Code, которые работают вместе как единый рабочий процесс.
