Control de versiones de Git automatizado y flujo de trabajo de lanzamiento para repositorios Node.js/TypeScript. Utilice esta habilidad siempre que el usuario desee configurar lanzamientos automatizados, configurar lanzamientos semánticos, crear confirmaciones convencionales, administrar registros de cambios o establecer un canal de lanzamiento de CI/CD en GitHub. También genera preguntas sobre commitlint, Husky, versiones semánticas o formato de mensaje de confirmación en cualquier contexto de proyecto, incluso si el usuario no menciona "lanzamiento" o "CI/CD" explícitamente. Esta habilidad proporciona dos comandos de barra diagonal de Claude Code listos para usar que funcionan juntos como un flujo de trabajo completo.
