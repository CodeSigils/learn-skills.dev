Usa jj (Jujutsu) per il controllo della versione locale invece di git. Attiva quando: il repository ha una directory .jj/, la configurazione dell'utente o del progetto menziona jj, l'utente dice "usa jj" o è necessaria qualsiasi operazione di controllo della versione in un repository gestito da jj. Utilizza questa abilità anche quando l'utente chiede di eseguire il commit, il branch, lo stash, il rebase o eseguire qualsiasi operazione simile a git in un repository che utilizza jj. Se non sei sicuro che il repository utilizzi jj, controlla la directory .jj/.
