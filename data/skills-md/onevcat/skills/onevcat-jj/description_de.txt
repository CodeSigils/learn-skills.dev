Verwenden Sie jj (Jujutsu) für die lokale Versionskontrolle anstelle von Git. Aktivieren Sie diese Option, wenn: das Repo über ein .jj/-Verzeichnis verfügt, die Benutzer- oder Projektkonfiguration jj erwähnt, der Benutzer „jj verwenden“ sagt oder eine Versionskontrolloperation in einem von jj verwalteten Repo erforderlich ist. Verwenden Sie diese Fähigkeit auch, wenn der Benutzer in einem Repo, das jj verwendet, Commit, Branch, Stash, Rebase oder die Ausführung einer Git-ähnlichen Operation auffordert. Wenn Sie nicht sicher sind, ob das Repo jj verwendet, suchen Sie nach einem .jj/-Verzeichnis.
