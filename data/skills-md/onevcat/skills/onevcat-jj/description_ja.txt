ローカルのバージョン管理には git の代わりに jj (ジュジュツ) を使用します。次の場合にアクティブ化します: リポジトリに .jj/ ディレクトリがある場合、ユーザーまたはプロジェクト構成で jj が言及されている場合、ユーザーが「jj を使用する」と言っている場合、または jj 管理のリポジトリでバージョン管理操作が必要な場合。また、ユーザーが jj を使用するリポジトリでコミット、ブランチ、スタッシュ、リベース、または git のような操作を実行するように要求した場合にも、このスキルを使用します。リポジトリが jj を使用しているかどうか不明な場合は、.jj/ ディレクトリを確認してください。
