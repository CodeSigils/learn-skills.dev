Utilisez jj (Jujutsu) pour le contrôle de version local au lieu de git. Activez lorsque : le dépôt a un répertoire .jj/, la configuration de l'utilisateur ou du projet mentionne jj, l'utilisateur dit "utiliser jj", ou toute opération de contrôle de version est nécessaire dans un dépôt géré par jj. Utilisez également cette compétence lorsque l'utilisateur demande de valider, de créer une branche, de cacher, de rebaser ou d'effectuer toute opération de type git dans un dépôt qui utilise jj. Si vous ne savez pas si le dépôt utilise jj, recherchez un répertoire .jj/.
