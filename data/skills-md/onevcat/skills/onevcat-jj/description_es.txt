Utilice jj (Jujutsu) para el control de versiones local en lugar de git. Activar cuando: el repositorio tiene un directorio .jj/, la configuración del usuario o del proyecto menciona jj, el usuario dice "usar jj" o se necesita cualquier operación de control de versiones en un repositorio administrado por jj. Utilice también esta habilidad cuando el usuario solicite confirmar, bifurcar, guardar, rebase o realizar cualquier operación similar a git en un repositorio que use jj. Si no está seguro de si el repositorio usa jj, busque un directorio .jj/.
