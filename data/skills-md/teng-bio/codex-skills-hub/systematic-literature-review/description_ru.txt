Используйте это, когда пользователь явно запрашивает «систематический обзор/обзор литературы/соответствующую работу/исследование литературы». ИИ автономно генерирует поисковые запросы, выполняет поиск из нескольких источников → дедупликацию → читает каждую статью и присваивает балл (1–10 для семантической релевантности и группировки подтем) → выбирает статьи пропорционально высоким баллам → автоматически создает бюджет на количество слов для рецензии → старшие эксперты в предметной области пишут свободно (фиксированная аннотация, введение, подтемы, обсуждение, прогноз, заключение), обеспечивают жесткие проверки длины основного текста и количества ссылок, а также принудительно экспортируют PDF-файлы и файлы Word. Поддерживает многоязычный перевод и интеллектуальную компиляцию (en/zh/ja/de/fr/es). Китайские триггерные слова: 系统综述、文献综述、родственный работа, работа, работа, работа. Дополнительные китайские триггерные слова:寻找参考文献、搜索文献、参考文献整理、系统找文献、批量筛选文献、根据文献写综述、文献评分、родственное работа.
