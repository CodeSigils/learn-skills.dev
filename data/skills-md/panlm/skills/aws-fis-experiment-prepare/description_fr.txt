À utiliser lorsque l'utilisateur souhaite préparer, créer ou générer une configuration d'expérience AWS FIS (Fault Injection Service). Déclencheurs sur « préparer l'expérience FIS », « créer une expérience FIS pour [scénario] », « générer une configuration d'expérience de chaos », « 准备 FIS 实验 », « 生成 [scenario] 混沌实验配置 », « créer un modèle d'expérience pour une interruption de courant AZ », « configurer un test d'injection de pannes ». Prend en charge les scénarios prédéfinis de la bibliothèque de scénarios FIS (interruption de courant AZ, ralentissement des applications AZ, etc.) et les actions FIS uniques personnalisées (aws:rds:failover-db-cluster, aws:ec2:stop-instances, etc.). Génère tous les fichiers nécessaires à l'exécution de l'expérience : modèle JSON, stratégie IAM, modèle CloudFormation, alarmes CloudWatch, tableau de bord et documentation sur le comportement attendu. Après avoir généré les fichiers, déploie automatiquement le modèle CFN avec itération d'auto-réparation : si le déploiement échoue, analyse l'erreur, corrige le modèle, supprime la pile défaillante et réessaye jusqu'à ce que le déploiement réussisse (jusqu'à 5 tentatives).
