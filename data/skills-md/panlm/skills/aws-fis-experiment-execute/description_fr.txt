À utiliser lorsque l'utilisateur souhaite déployer et exécuter une expérience AWS FIS préparée. Déclencheurs sur « exécuter l'expérience FIS », « exécuter l'expérience FIS », « démarrer l'expérience chaos », « déployer le modèle FIS », « 启动 FIS 实验 », « 运行混沌实验 », « 执行故障注入实验 », « déployer et exécuter l'expérience dans [répertoire] ». Attend un répertoire d'expérience préparé (à partir de aws-fis-experiment-prepare ou créé manuellement) contenant experience-template.json, iam-policy.json, cfn-template.yaml et les configurations d'alarme. Déploie des ressources via CLI ou CloudFormation, démarre l'expérience avec une confirmation stricte de l'utilisateur, surveille les progrès et génère un rapport sur les résultats.
