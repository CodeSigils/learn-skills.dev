Da utilizzare quando l'utente desidera distribuire ed eseguire un esperimento AWS FIS preparato. Trigger su "esegui esperimento FIS", "esegui esperimento FIS", "avvia esperimento caos", "distribuisci modello FIS", "启动 FIS 实验", "运行混沌实验", "执行故障注入实验", "distribuisci ed esegui l'esperimento in [directory]". Si prevede una directory dell'esperimento preparata (da aws-fis-experiment-prepare o creata manualmente) contenente sperimentale-template.json, iam-policy.json, cfn-template.yaml e configurazioni di allarme. Distribuisce le risorse tramite CLI o CloudFormation, avvia l'esperimento con una rigorosa conferma da parte dell'utente, monitora i progressi e genera un report sui risultati.
