Ripristina l'elenco delle sessioni e le attività pianificate (routine) dell'app desktop Claude Code dopo aver cambiato account Claude. Utilizzalo quando un utente segnala che dopo aver cambiato account le sessioni mancano, l'elenco delle conversazioni è vuoto, le sessioni storiche sono scomparse, le routine sono scomparse o le attività pianificate non sono più in esecuzione.
