Shopee (XiaPi) Store-Gutscheine (gleiche Serie wie linkfox-shopee-store-auth) werden über /shopee/developerProxy an alle sechs Shopee Open API Voucher-Modulschnittstellen weitergeleitet: add_voucher, get_voucher_list, get_voucher, update_voucher, end_voucher und delete_voucher. Wenn ein Benutzer Shopee-Gutscheine, Voucher, Store-Gutscheine, add_voucher, Voucher_id, Rabattgutscheine oder Rabattcodes erwähnt, wird dies ausgelöst. Auch wenn „Gutschein“ nicht ausdrücklich erwähnt wird, sollte auch jede Beteiligung an der Verwaltung von Gutscheinaktivitäten für einen autorisierten Shopee-Shop ausgelöst werden.
