Bon de coupons de magasin Shopee (XiaPi) (de la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy aux six interfaces du module Shopee Open API Voucher : add_voucher, get_voucher_list, get_voucher, update_voucher, end_voucher, delete_voucher. Déclenchez lorsqu'un utilisateur mentionne des coupons Shopee, un bon, des coupons de magasin, add_voucher, voucher_id, un coupon de réduction complet ou un code de réduction. Même si « coupon » n'est pas explicitement mentionné, toute référence à la gestion des activités de bons d'achat pour un magasin Shopee agréé devrait également déclencher.
