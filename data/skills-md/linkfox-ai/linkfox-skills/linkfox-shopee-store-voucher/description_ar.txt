قسيمة كوبونات متجر Shopee (XiaPi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، يتم إعادة توجيهها عبر /shopee/developerProxy إلى الواجهات الست لوحدة Shopee Open API Voucher: add_voucher، get_voucher_list، get_voucher، update_voucher، end_voucher،delete_voucher. يتم تشغيله عندما يذكر المستخدم كوبونات Shopee، أو القسيمة، أو كوبونات المتجر، أو add_voucher، أو voucher_id، أو قسيمة التخفيض الكامل، أو رمز الخصم. حتى إذا لم يتم ذكر "القسيمة" صراحةً، فإن أي إشارة إلى إدارة أنشطة القسيمة لمتجر Shopee معتمد يجب أن تؤدي أيضًا إلى تفعيلها.
