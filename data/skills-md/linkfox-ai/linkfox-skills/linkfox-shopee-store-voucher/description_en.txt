Shopee (XiaPi) store coupons Voucher (in the same series as linkfox-shopee-store-auth) are forwarded via /shopee/developerProxy to the Shopee Open API Voucher module’s six interfaces: add_voucher, get_voucher_list, get_voucher, update_voucher, end_voucher, delete_voucher. It is triggered when a user mentions Shopee coupons, Voucher, store coupons, add_voucher, voucher_id, discount coupons, or discount codes. Even if “coupon” is not explicitly mentioned, any reference to the management of Voucher activities for an authorized Shopee store should also trigger.
