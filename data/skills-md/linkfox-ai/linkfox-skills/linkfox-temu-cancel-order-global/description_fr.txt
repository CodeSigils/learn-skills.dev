API d'annulation de commande du site Temu Global (hors États-Unis/UE) (acheteur+vendeur combiné), transmise via la passerelle LinkFox à six interfaces : annulation après-vente de l'acheteur (bg.aftersales.cancel.*), appel du vendeur/annulation de rupture de stock (temu.order.cancel.*), etc., avec par défaut site=global et tokenPurpose=order‑shipping. Il est déclenché lorsque l'utilisateur mentionne l'annulation d'une commande Temu Global, l'annulation d'un acheteur sur un site mondial, une annulation de rupture de stock du vendeur, afterSalesStatusGroup ou applySn. Utilisez linkfox-temu-cancel-order-us pour le site américain, linkfox-temu-cancel-order-eu pour le site européen et linkfox-temu-order-global pour les commandes.
