API отмены заказа на сайте Temu Global (за пределами США/ЕС) (комбинированный покупатель+продавец), пересылаемый через шлюз LinkFox на шесть интерфейсов: отмена послепродажного обслуживания покупателя (bg.aftersales.cancel.*), апелляция продавца/отмена отсутствия на складе (temu.order.cancel.*) и т. д., со значением по умолчанию site=global и tokenPurpose=order‑shipping. Он срабатывает, когда пользователь упоминает отмену заказа Temu Global, отмену покупателя на глобальном сайте, отмену отсутствия у продавца на складе, afterSalesStatusGroup или applySn. Используйте linkfox-temu-cancel-order-us для сайта в США, linkfox-temu-cancel-order-eu для сайта ЕС и linkfox-temu-order-global для заказов.
