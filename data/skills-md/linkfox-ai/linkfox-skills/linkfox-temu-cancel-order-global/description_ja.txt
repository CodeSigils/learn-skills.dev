Temu グローバル サイト (米国/EU 以外) の注文キャンセル API (購入者と販売者の組み合わせ)。LinkFox ゲートウェイを介して 6 つのインターフェイスに転送されます: 購入者の販売後のキャンセル (bg.aftersales.cancel.*)、販売者のアピール/在庫切れキャンセル (temu.order.cancel.*) など。デフォルトの site=global および tokenPurpose=order-shipping です。これは、ユーザーが Temu Global 注文キャンセル、グローバルサイト購入者のキャンセル、販売者の在庫切れキャンセル、afterSalesStatusGroup、または applySn に言及したときにトリガーされます。米国サイトには linkfox-temu-cancel-order-us、EU サイトには linkfox-temu-cancel-order-eu、注文には linkfox-temu-order-global を使用します。
