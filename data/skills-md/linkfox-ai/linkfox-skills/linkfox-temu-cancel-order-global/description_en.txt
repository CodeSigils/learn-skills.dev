Temu Global site (non‑US/EU) order cancellation API (combined buyer + seller), forwarded through the LinkFox gateway to six interfaces: buyer after‑sales cancellation (bg.aftersales.cancel.*), seller appeal/out‑of‑stock cancellation (temu.order.cancel.*), etc., with default site=global and tokenPurpose=order‑shipping. It is triggered when the user mentions Temu Global order cancellation, global‑site buyer cancellation, seller out‑of‑stock cancellation, afterSalesStatusGroup, or applySn. Use linkfox-temu-cancel-order-us for the US site, linkfox-temu-cancel-order-eu for the EU site, and linkfox-temu-order-global for orders.
