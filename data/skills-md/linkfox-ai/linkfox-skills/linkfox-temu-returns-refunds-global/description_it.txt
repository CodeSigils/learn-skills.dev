API globale per resi e rimborsi e-commerce Temu, inoltrata tramite il gateway LinkFox alle interfacce bg/temu relative a Resi e rimborsi globali del Partner/resi e rimborsi post-vendita (richiesta di reso, rimborso, query ed elaborazione degli ordini post-vendita, ecc.; le interfacce saranno integrate una per una in base alla documentazione del Partner). Si attiva quando un utente menziona resi, rimborsi, resi post-vendita, reso, rimborso, reso post-vendita Temu Global, parentAfterSalesSn, ordine di reso, ordine di rimborso, post-vendita con spedizione dell'ordine. Le cancellazioni degli ordini dell'acquirente/venditore utilizzano linkfox-temu-cancel-order-global / linkfox-temu-cancel-order-global; gli ordini utilizzano linkfox-temu-order-global.
