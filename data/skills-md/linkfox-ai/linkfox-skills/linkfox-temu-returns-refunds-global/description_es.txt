API de devoluciones y reembolsos de comercio electrónico global de Temu, reenviada a través de la puerta de enlace de LinkFox a las interfaces bg/temu relacionadas con devoluciones y reembolsos globales del socio/devoluciones posventa y reembolsos (solicitud de devolución, reembolso, consulta y procesamiento de pedidos posventa, etc.; las interfaces se integrarán una por una de acuerdo con la documentación del socio). Se activa cuando un usuario menciona devoluciones, reembolsos, devoluciones posventa, devolución, reembolso, devolución posventa, parentAfterSalesSn, pedido de devolución, pedido de reembolso, envío de pedido posventa de Temu Global. Las cancelaciones de pedidos de compradores/vendedores utilizan linkfox-temu-cancel-order-global / linkfox-temu-cancel-order-global; los pedidos utilizan linkfox-temu-order-global.
