API globale de retours et de remboursements du commerce électronique Temu, transmise via la passerelle LinkFox vers les interfaces partenaires bg/temu liées aux retours et remboursements globaux / après-vente (demande de retour, remboursement, requête et traitement des commandes après-vente, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsqu'un utilisateur mentionne les retours, remboursements, retours après-vente de Temu Global, le retour, le remboursement, le retour après-vente, parentAfterSalesSn, la commande de retour, la commande de remboursement, l'expédition de la commande après-vente. Les annulations de commande acheteur/vendeur utilisent linkfox-temu-cancel-order-global / linkfox-temu-cancel-order-global ; les commandes utilisent linkfox-temu-order-global.
