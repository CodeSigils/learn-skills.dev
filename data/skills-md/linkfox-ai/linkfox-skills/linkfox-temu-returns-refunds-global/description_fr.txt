API de retours et de remboursements du site mondial de commerce électronique Temu, transmis via la passerelle LinkFox, les interfaces bg/temu liées aux retours et remboursements globaux des partenaires après-vente et aux remboursements (demande de retour, remboursement, requête et traitement des commandes après-vente, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsqu'un utilisateur mentionne Temu Global retour, remboursement, retour après-vente, retour, remboursement, retour après-vente, parentAfterSalesSn, commande de retour, commande de remboursement, expédition de commande après-vente. Les acheteurs/vendeurs annulent les commandes en utilisant linkfox‑temu‑cancel‑order‑global / linkfox‑temu‑cancel‑order‑global ; les commandes utilisent linkfox‑temu‑order‑global.
