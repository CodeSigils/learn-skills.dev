La gestion des produits du magasin Shopee (虾皮) (dans la même série que linkfox-shopee-store-auth), transmise via /shopee/developerProxy, gère les 57 points de terminaison du module produit Shopee Open API : get_category, get_item_list, add_item, update_item, update_price, update_stock, boost_item, search_item, etc. Lorsqu'un utilisateur mentionne les produits Shopee, Shopee annonces, inscription, radiation, SKU, inventaire, prix, catégorie, attributs, get_item_list, add_item, avis sur les produits, boost épinglage, cela se déclenche. Même si « produit » n'est pas explicitement mentionné, toute requête, création ou mise à jour de produits dans une boutique Shopee agréée devrait se déclencher.
