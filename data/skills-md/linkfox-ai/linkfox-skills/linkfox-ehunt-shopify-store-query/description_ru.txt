С помощью запроса магазина EHunt Shopify (маршрут шлюза `ehunt/shopify/storeQuery`) можно фильтровать независимые магазины Shopify по нескольким параметрам (название магазина/домен, страна, годы с момента создания, количество продуктов, количество рекламы, ежемесячные посещения, ежемесячные заказы, подписчики в социальных сетях и т. д.). Срабатывает, когда пользователь упоминает магазин EHunt Shopify, анализ магазина Shopify, независимый магазин, продавец Shopify, независимый магазин-конкурент, ежемесячные посещения Shopify, независимую библиотеку объявлений, магазины Shopify, запрос магазина Shopify. Даже если пользователь не пишет EHunt, пока он ищет магазины на независимых сайтах Shopify, фильтрует данные магазинов или анализирует эффективность магазинов, этот навык должен срабатывать.
