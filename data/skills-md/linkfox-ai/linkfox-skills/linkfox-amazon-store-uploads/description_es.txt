La carga de archivos de la tienda de Amazon (equivalente a la serie linkfox-amazon-store-auth) se realiza invocando createUploadDestinationForResource de la API de cargas v2020-11-01 a través de /spApi/developerProxy, luego cargando el archivo en la URL devuelta para que lo utilicen API como A+ Content y Messaging. Se activa cuando el usuario menciona la carga de archivos, createUploadDestinationForResource, destino de carga, contentMD5, carga prefirmada, carga de SP-API, carga de imagen A+ o carga de archivos adjuntos de mensajería.
