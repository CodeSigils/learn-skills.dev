Il caricamento del file del negozio Amazon (equivalente alla serie linkfox-amazon-store-auth) viene eseguito richiamando createUploadDestinationForResource dell'API Uploads v2020-11-01 tramite /spApi/developerProxy, quindi caricando il file nell'URL restituito per l'utilizzo da parte di API come A+ Content e Messaging. Viene attivato quando l'utente menziona il caricamento di file, createUploadDestinationForResource, destinazione del caricamento, contentMD5, caricamento pre‑firmato, caricamento SP‑API, caricamento di immagini A+ o caricamento di allegati di messaggistica.
