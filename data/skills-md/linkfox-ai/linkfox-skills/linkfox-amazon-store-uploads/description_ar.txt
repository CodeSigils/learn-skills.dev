يتم إجراء تحميل ملف متجر أمازون (أي ما يعادل سلسلة linkfox-amazon-store-auth) عن طريق استدعاء Uploads API v2020-11-01's createUploadDestinationForResource عبر /spApi/developerProxy، ثم تحميل الملف إلى عنوان URL الذي تم إرجاعه للاستخدام بواسطة واجهات برمجة التطبيقات مثل محتوى A+ والمراسلة. يتم تشغيله عندما يذكر المستخدم تحميل الملفات، أو createUploadDestinationForResource، أو وجهة التحميل، أو contentMD5، أو التحميل الموقع مسبقًا، أو تحميل SP‑API، أو تحميل صورة A+، أو تحميل مرفقات الرسائل.
