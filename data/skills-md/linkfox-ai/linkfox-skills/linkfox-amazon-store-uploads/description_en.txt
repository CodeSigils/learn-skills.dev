Amazon store file upload (equivalent to the linkfox-amazon-store-auth series) is performed by invoking the Uploads API v2020-11-01’s createUploadDestinationForResource via /spApi/developerProxy, then uploading the file to the returned URL for use by APIs such as A+ Content and Messaging. It is triggered when the user mentions uploading files, createUploadDestinationForResource, upload destination, contentMD5, pre‑signed upload, SP‑API upload, A+ image upload, or Messaging attachment upload.
