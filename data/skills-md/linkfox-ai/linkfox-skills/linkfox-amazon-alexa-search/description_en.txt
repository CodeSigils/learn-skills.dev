Initiate natural language Q&A through Amazon’s frontend Alexa Shopping Assistant to obtain buying guide answers, recommended product groupings, ASIN lists, and follow‑up questions related to the query. Each call supports only one prompt; if a follow‑up is needed, the agent must summarize the context and concatenate the new question to make a new request. URL can be used to supplement Amazon page context. This skill is triggered when the user mentions scenarios such as Amazon Alexa, Alexa Shopping Assistant, Amazon Smart Assistant, AI buying guide, conversational product selection, natural language shopping, Amazon chat Q&A, product recommendation dialogue, contextual follow‑up, etc. Even if the user does not explicitly mention “Alexa,” as long as the need is “to ask for product recommendations on Amazon’s frontend using natural language,” this skill should be activated.
