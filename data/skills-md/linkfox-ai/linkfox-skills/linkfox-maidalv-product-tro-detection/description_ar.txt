باستخدام خدمة "Sell DaLü" لاكتشاف ما إذا كان المنتج يحتوي على TRO (أمر تقييدي مؤقت) ومخاطر انتهاك الملكية الفكرية (العلامات التجارية/براءات الاختراع/حقوق الطبع والنشر)، يمكنك إدخال الصورة الرئيسية للمنتج (عناوين URL للصور الداعمة أو عناوين URL لبيانات Base64) وإضافة صور مرجعية ونص مرجعي وكلمات IP الرئيسية بشكل اختياري. يُرجع النظام تصنيفًا إجماليًا للمخاطر، وقائمة بعناصر الانتهاك عالية الخطورة وعناصر الملكية الفكرية منخفضة المخاطر (بما في ذلك مدعي TRO، وتاريخ التقديم، ورقم قضية المحكمة، وعدد القضايا)، ودرجة مخاطر رقمية من 0 إلى 10، وتقرير تقييم قانوني تم إنشاؤه بواسطة الذكاء الاصطناعي.

يتم تشغيل هذه الإمكانية عندما يذكر المستخدم اكتشاف TRO، أو خطر TRO، أو انتهاك TRO، أو اكتشاف انتهاك الملكية الفكرية، أو انتهاك العلامة التجارية، أو انتهاك براءات الاختراع، أو انتهاك حقوق الطبع والنشر، أو اكتشاف مخاطر IP، أو اكتشاف امتثال المنتج، أو "Sell DaLü"، أو اكتشاف TRO للمنتج، أو خطر انتهاك IP، أو التحقق من انتهاك العلامات التجارية/براءات الاختراع/حقوق النشر. حتى إذا لم يذكر المستخدم صراحةً "Sell DaLü" أو "TRO"، فلا يزال يتعين تنشيط المهارة عندما يقدم المستخدم صورة منتج ويريد تقييم مخاطر الانتهاك فيما يتعلق بالعلامات التجارية أو براءات الاختراع أو حقوق الطبع والنشر أو TROs.
