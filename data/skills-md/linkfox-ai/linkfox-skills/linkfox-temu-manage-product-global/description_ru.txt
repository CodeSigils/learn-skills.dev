API «Управление продуктом» глобального сайта Temu (за пределами США/ЕС) перенаправляется через шлюз LinkFox на 24 конечные точки bg.local/temu.local, при этом сайт по умолчанию установлен на глобальный. Он срабатывает, когда пользователь упоминает продукт Temu Global Manage, продукты глобального сайта, сайт=глобальный список/исключение продуктов, изменения запасов или bg.local.goods. Используйте linkfox-temu-manage-product-us для сайта в США, linkfox-temu-manage-product-eu для европейского сайта, а для других доменов, таких как публикация продуктов, ценообразование, рекламные акции, реклама, заказы и т. д., используйте соответствующий навык при настройке site=global.
