The Temu global site (non‑US/EU) product management “Manage Product” API is forwarded via the LinkFox gateway to 24 bg.local/temu.local endpoints, with the default site set to global. It is triggered when a user mentions Temu Global Manage Product, global‑site products, site=global product listing/delisting, inventory changes, or bg.local.goods. Use linkfox‑temu‑manage‑product‑us for the US site, linkfox‑temu‑manage‑product‑eu for the European site, and for other domains such as product publishing, pricing, promotions, advertising, orders, etc., use the corresponding skill while setting site=global.
