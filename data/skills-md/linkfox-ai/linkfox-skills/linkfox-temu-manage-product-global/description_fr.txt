L'API « Gérer le produit » de gestion de produits du site mondial Temu (hors États-Unis/UE) est transmise via la passerelle LinkFox à 24 interfaces bg.local/temu.local, le site par défaut étant défini sur global. Il est déclenché lorsqu'un utilisateur mentionne Temu Global Manage Product, les produits du site global, la liste ou la suppression de produits site=global, les modifications d'inventaire ou bg.local.goods. Le site américain utilise linkfox‑temu‑manage‑product‑us ; le site de l'UE utilise linkfox‑temu‑manage‑product‑eu ; d'autres domaines tels que la publication de produits, les prix, les promotions, la publicité, les commandes, etc., utilisent la compétence correspondante avec site=global.
