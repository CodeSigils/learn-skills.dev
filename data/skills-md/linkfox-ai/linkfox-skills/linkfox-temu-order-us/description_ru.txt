API управления заказами на сайте Temu в США, пересылаемый через шлюз LinkFox в интерфейс заказов партнера в США: список заказов, сведения о заказе, адрес доставки, сумма, комбинированная доставка, настройка, загрузка проверки серийного номера (bg.order.*, temu.local.order.verification.upload), доставка, логистика и т. д. Запускается, когда пользователь упоминает заказы Temu в США, загрузку SN, IMEI, вторичную проверку, загрузку проверки, индивидуальные продукты, комбинированную доставку, сумму заказа, parentOrderSn, или доставка заказа. Управление продуктами использует linkfox-temu-manage-product-us; публикация продукта использует linkfox-temu-add-product-us; ценообразование использует linkfox-temu-price-us.
