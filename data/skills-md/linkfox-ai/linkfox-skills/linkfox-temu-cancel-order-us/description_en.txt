Temu US site order cancellation API (buyer and seller combined), forwarded by the LinkFox gateway to Partner US: buyer after‑sales cancellation list/consent (bg.aftersales.cancel.*), seller appeals/out‑of‑stock cancellations (temu.order.cancel.appeal/outofstock.*), etc. Triggered when the user mentions Temu US order cancellation, buyer cancellation, seller cancellation, out‑of‑stock cancellation, afterSalesStatusGroup, applySn, order‑shipping. Use linkfox‑temu‑order‑us for orders; linkfox‑temu‑cancel‑order‑eu for the European site; linkfox‑temu‑cancel‑order‑global for the global site.
