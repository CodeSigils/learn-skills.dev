API отмены заказа на сайте Temu в США (покупатель и продавец вместе), пересылаемый шлюзом LinkFox партнеру в США: список/согласие покупателя на отмену послепродажного обслуживания (bg.aftersales.cancel.*), апелляции продавца/отмены отсутствия на складе (temu.order.cancel.appeal/outofstock.*) и т. д. Запускается, когда пользователь упоминает отмену заказа Temu US, отмену покупателя, отмену продавца, отмену отсутствия на складе, afterSalesStatusGroup, applySn, доставка заказа. Для заказов используйте linkfox‑temu‑order‑us; linkfox‑temu‑cancel‑order‑eu для европейского сайта; linkfox‑temu‑cancel‑order‑global для глобального сайта.
