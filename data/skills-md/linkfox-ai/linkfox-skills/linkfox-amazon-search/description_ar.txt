محاكاة مستخدم حقيقي يقوم بإجراء بحث على الواجهة الأمامية لأمازون، والحصول على تصنيفات الكلمات الرئيسية في الوقت الفعلي وبيانات صفحة نتائج البحث. يتم تشغيل هذه المهارة عندما يذكر المستخدم البحث عن منتجات أمازون، أو استخلاص نتائج البحث، أو ترتيب الكلمات الرئيسية في صفحة البحث، أو البحث عن موضع تصنيف ASIN، أو اكتشاف المنافسين، أو مقارنة الأسعار على صفحة البحث، أو تحليل المنتجات المدعومة، أو مراقبة المنتجات الجديدة، أو محاكاة البحث الأمامي، أو بحث أمازون، أو تصنيف الكلمات الرئيسية، أو نتائج البحث، أو موضع تصنيف ASIN، أو اكتشاف المنافسين، أو مقارنة الأسعار، أو تحليل المنتجات المدعومة، أو البحث في الوقت الفعلي، أو مراقبة المنتجات الجديدة. حتى لو لم يذكر المستخدم صراحةً "محاكاة البحث"، طالما أن الطلب يتضمن نتائج بحث أمازون في الوقت الفعلي، أو بيانات تصنيف المنتج، أو تحليل SERP الأمامي، فيجب تفعيل هذه المهارة.

يرجى الرد دائمًا بلغة المستخدم.
