Habilidad de administración y autorización de tiendas de Amazon, que proporciona un proceso de autorización completo, actualización de tokens, consulta de tiendas autorizadas y capacidades de adquisición de tokens de acceso. Al obtener el enlace de autorización, se requiere el nombre de las tiendas sellerName para diferenciar las tiendas autorizadas. Esta habilidad se activa cuando el usuario menciona la autorización de la tienda de Amazon, vincular una tienda de Amazon, actualizar un token, consultar tokens de tienda, administrar tiendas autorizadas, autorización de vendedor de Amazon, vincular una cuenta de vendedor de Amazon, actualizar el token de acceso, consultar tokens de tienda o administrar tiendas autorizadas. Siempre que la solicitud involucre autorización de cuenta de vendedor de Amazon, administración de tokens de acceso o consultas de listas de tiendas, esta habilidad también debe activarse.
