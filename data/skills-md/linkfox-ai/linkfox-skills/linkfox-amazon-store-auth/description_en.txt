Amazon store authorization and management skill, providing a complete authorization process, token refresh, authorized store query, and access token retrieval capabilities. When obtaining the authorization link, the store name sellerName is required to distinguish authorized stores. This skill is triggered when the user mentions Amazon store authorization, binding an Amazon store, refreshing tokens, querying store tokens, managing authorized stores, Amazon seller authorization, bind Amazon seller account, refresh access token, query store tokens, or manage authorized stores. As long as the request involves Amazon seller account authorization, access token management, or store list query, this skill should also be triggered.
