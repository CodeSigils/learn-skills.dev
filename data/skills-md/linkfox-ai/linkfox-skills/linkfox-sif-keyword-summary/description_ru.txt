Разложите источники трафика всех ASIN конкурентов по заданному ключевому слову — обычный поиск, рекламу SP, рекламу бренда SB, видеорекламу SBV, рекомендации SP, AC/ER/TR и другие слоты рекомендаций — с поддержкой фильтров по ASIN, заданным диапазонам дат и новым терминам трафика. Эта возможность срабатывает, когда пользователь упоминает источники трафика по ключевым словам, которые конкуренты захватывают трафик по ключевому слову, долю органического трафика по сравнению с платным, показы рекламы SP, долю рекламы бренда, места для рекомендаций SP, разбивку рекламных мест рекомендаций по сравнению с нерекламой, анализ результатов поиска, выбор Amazon или редакционные рекомендации, конкурентную среду ключевых слов, состав трафика ASIN, трафик ключевых слов, анализ структуры трафика, долю поиска, долю рекламы, распределение источников трафика, SIF, анализ трафика, рекомендацию SP, разбивку по рекомендациям. Даже если пользователь явно не упоминает «SIF», этот навык должен активироваться всякий раз, когда запрос включает анализ распределения источников трафика ASIN конкурентов по определенному ключевому слову.
