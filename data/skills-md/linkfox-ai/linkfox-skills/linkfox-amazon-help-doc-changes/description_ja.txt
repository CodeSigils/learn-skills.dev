Amazon 販売者ヘルプ ドキュメント (ヘルプ センター) コンテンツへの変更を監視し、AI でフィルタリングして販売者にとって価値のある変更を返します。変更時間範囲とタイトル キーワードによるページ分割検索をサポートし、AI 変更概要、特定の変更ポイント、および変更レコード ID による完全な最新ドキュメントを取得します。このスキルは、ユーザーが Amazon ヘルプドキュメントの変更、ヘルプセンターの更新、ルール変更の監視、ポリシー/料金ドキュメントの調整、コンプライアンスアラート、ドキュメントの変更内容、完全な最新ドキュメント、または Amazon ヘルプドキュメントの変更、セラーセントラルヘルプセンターの更新、ポリシー/料金ドキュメントの変更、コンプライアンスアラートに言及したときにトリガーされます。ユーザーが「ヘルプドキュメントの変更」と明示的に言及していない場合でも、リクエストに Amazon ヘルプセンタードキュメントの更新と変更の詳細の監視が含まれている限り、このスキルはトリガーされる必要があります。
