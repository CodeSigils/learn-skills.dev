Shopee (XiaPi) First-Mile-Logistik FirstMile (gleiche Serie wie linkfox-shopee-store-auth), weitergeleitet über /shopee/developerProxy an den vollständigen Satz von 16 Schnittstellen des Shopee Open API FirstMile-Moduls: get_unbind_order_list, generic_first_mile_tracking_number, bind_first_mile_tracking_number, get_waybill, get_channel_list usw. Wann Ein Benutzer erwähnt Shopee First‑Mile, FirstMile, First‑Mile Waybill, Binding First‑Mile, First Mile Tracking, Transit Warehouse, get_unbind_order_list, es wird ausgelöst. Auch wenn „erste Meile“ nicht ausdrücklich erwähnt wird, sollte jeder Verweis auf das Binden oder Beschriften eines Frachtbriefs für die erste Meile für einen autorisierten Shopee-Shop ebenfalls ausgelöst werden.
