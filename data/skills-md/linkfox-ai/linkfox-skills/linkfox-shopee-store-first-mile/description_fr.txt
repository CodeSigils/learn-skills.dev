Shopee (Shopee) logistique du premier kilomètre FirstMile (dans la même série que linkfox‑shopee‑store‑auth) transmet les 16 interfaces du module Shopee Open API FirstMile, telles que get_unbind_order_list, generate_first_mile_tracking_number, bind_first_mile_tracking_number, get_waybill, get_channel_list, etc., via /shopee/developerProxy. Lorsqu'un utilisateur mentionne Shopee first-mile, FirstMile, first-mile waybill, contraignant first-mile, first-mile tracking, transit Warehouse, get_unbind_order_list, cela doit être déclenché. Même si le « premier kilomètre » n'est pas explicitement mentionné, toute discussion sur la liaison ou l'étiquetage d'une lettre de transport du premier kilomètre pour un magasin Shopee agréé devrait également déclencher.
