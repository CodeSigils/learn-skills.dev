Shopee (XiaPi) logistique du premier kilomètre FirstMile (de la même série que linkfox‑shopee‑store‑auth), transmis via/shopee/developerProxy, comprend les 16 interfaces du module Shopee Open API FirstMile : get_unbind_order_list, generate_first_mile_tracking_number, bind_first_mile_tracking_number, get_waybill, get_channel_list, etc. Il est déclenché lorsque les utilisateurs mentionnent Shopee premier kilomètre, FirstMile, lettre de transport du premier kilomètre, premier kilomètre de liaison, suivi du premier kilomètre, entrepôt de transit, get_unbind_order_list, etc. Même si le « premier kilomètre » n’est pas explicitement indiqué, toute implication dans la liaison ou les lettres de voiture du premier kilomètre d’un magasin Shopee agréé devrait également le déclencher.
