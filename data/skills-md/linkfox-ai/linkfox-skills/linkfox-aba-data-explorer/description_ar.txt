استعلام وتحليل بيانات مصطلح البحث Amazon ABA (تحليل العلامة التجارية)، والذي يغطي البيانات الأسبوعية من 15 موقعًا على مدار السنوات الثلاث الماضية تقريبًا. يتم تشغيل هذه المهارة عندما يذكر المستخدمون بيانات ABA، أو تحليل مصطلح بحث Amazon، أو استخراج الكلمات الرئيسية، أو اتجاهات ترتيب البحث، أو تحليل فرص السوق، أو الكلمات الرئيسية الموسمية، أو تحليل التحويل المنخفض للنقرات العالية، أو اكتشاف الكلمات الرئيسية للمحيط الأزرق، أو تحليل الكلمات الرئيسية المنافسة، أو بيانات ABA، أو تقرير مصطلحات البحث، أو استخراج الكلمات الرئيسية، أو اتجاهات ترتيب البحث، أو الكلمات الرئيسية للمحيط الأزرق، أو مشاركة النقرات، أو نسبة التحويل، أو الكلمات الرئيسية الموسمية، أو تحليل فرص السوق، أو الكلمات الرئيسية المنافسة. حتى لو لم يذكر المستخدم صراحةً "ABA"، طالما أن الطلب يتضمن بيانات مصطلح بحث Amazon وتحليل التصنيف، فيجب تفعيل هذه المهارة.
