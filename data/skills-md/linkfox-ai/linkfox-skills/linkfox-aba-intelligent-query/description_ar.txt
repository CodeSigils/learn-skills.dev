استعلام وتحليل بيانات مصطلح البحث Amazon ABA (تحليل العلامة التجارية)، والذي يغطي البيانات الأسبوعية لما يقرب من ثلاث سنوات عبر 15 موقعًا. يتم تشغيل هذه المهارة عندما يذكر المستخدمون بيانات ABA، وتحليل مصطلح بحث Amazon، واستخراج الكلمات الرئيسية، واتجاهات ترتيب البحث، وتحليل فرص السوق، والكلمات الرئيسية الموسمية، وتحليل التحويل المنخفض للنقرات العالية، واكتشاف الكلمات الرئيسية للمحيط الأزرق، وتحليل الكلمات الرئيسية المنافسة، وبيانات ABA، وتقرير مصطلحات البحث، واستخراج الكلمات الرئيسية، واتجاهات ترتيب البحث، والكلمات الرئيسية للمحيط الأزرق، ونسبة النقر، وحصة التحويل، والكلمات الرئيسية الموسمية، وتحليل فرص السوق، والكلمات الرئيسية المنافسة. حتى إذا لم يذكر المستخدم صراحةً "ABA"، طالما أن الطلب يتضمن بيانات مصطلح بحث Amazon وتحليل التصنيف، فيجب تفعيل هذه المهارة.
