Habilidad de cumplimiento saliente de Amazon Multi-Channel Fulfilment (MCF), invocada a través de LinkFox/spApi/developerProxy para llamar a la API de cumplimiento saliente v2026‑07‑04 y proporcionar Facturas v2026‑06‑25getInvoiceHeaders asociados con la lista de funciones del documento; admite cotizaciones y vistas previas de tarifas de envío, creación/consulta/enumeración/actualización/cancelación de pedidos de cumplimiento, actualizaciones dinámicas de estado de pedidos/paquetes en la zona de pruebas y consultas paginadas de encabezados de facturas. El usuario menciona Logística saliente, MCF, envío multicanal, getOffers, getOrderPreview, createOrder, getInvoiceHeaders, envío de inventario de Amazon a clientes externos, paquetes y seguimiento de pedidos, comprobante de recibo o fotografías de entrega, recibido por, casillero/ubicación de entrega, números de serie de productos/identificadores de unidades, activados en v2026‑07‑04. Esto difiere del cumplimiento externo, la API de pedidos normal y la versión anterior v2020‑07‑01.
