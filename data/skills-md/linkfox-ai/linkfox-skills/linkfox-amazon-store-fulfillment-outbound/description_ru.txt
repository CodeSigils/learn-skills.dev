Навык выполнения исходящих заказов Amazon Multi-Channel Fulfillment (MCF), вызываемый через LinkFox/spApi/developerProxy для вызова API Fulfillment Outbound API v2026-07-04 и предоставляющий Invoices v2026-06-25 getInvoiceHeaders, связанный со списком ролей документа; он поддерживает расценки на доставку и предварительный просмотр, создание/запрос/список/обновление/отмену заказов на выполнение, динамические обновления статуса заказов/пакетов в изолированной среде и запросы заголовков счетов с разбивкой на страницы. Пользователи упоминают Fulfillment Outbound, MCF, многоканальную доставку, getOffers, getOrderPreview, createOrder, getInvoiceHeaders, доставку запасов Amazon клиентам за пределами офиса, пакеты заказов и отслеживание, подтверждение получения или фотографии доставки, получения, место хранения/выдачи, серийные номера продуктов/идентификаторы единиц, активированные в v2026-07-04. Он отличается от внешнего выполнения, стандартного API заказов и более старой версии 2020-07-01.
