مهارة التنفيذ الصادر لـ Amazon Multi-Channel Fulfillment (MCF)، التي يتم استدعاؤها عبر LinkFox/spApi/developerProxy لاستدعاء Fulfillment Outbound API v2026‑07‑04، وتوفير الفواتير v2026‑06‑25getInvoiceHeaders المرتبطة بقائمة أدوار المستند؛ وهو يدعم عروض أسعار ومعاينات أسعار الشحن، وإنشاء/استعلام/إدراج/تحديث/إلغاء أوامر التنفيذ، وتحديثات حالة الطلب/الحزمة الديناميكية، واستعلامات رأس الفاتورة المرقّمة. يذكر المستخدم Fulfillment Outbound، وMCF، والشحن متعدد القنوات، وgetOffers، وgetOrderPreview، وcreateOrder، وgetInvoiceHeaders، وشحن مخزون Amazon إلى العملاء خارج الموقع، وحزم الطلبات وتتبعها، وإثبات الاستلام أو صور التسليم، المستلمة بواسطة، موقع الخزانة/التسليم، الأرقام التسلسلية للمنتج/معرفات الوحدة، التي يتم تشغيلها في v2026‑07‑04. وهذا يختلف عن التنفيذ الخارجي وواجهة برمجة التطبيقات للطلبات العادية والإصدار v2020‑07‑01 الأقدم.
