Through the Google Patents public patent database, retrieve worldwide patents, supporting multidimensional filtering such as keywords, inventors, assignees, country, date, patent status, etc., and return core bibliographic data including patent publication number, title, inventors, filing/publication/grant date, assignee, CPC classification, PDF link, and other essential information. This skill is triggered when the user mentions Google Patents, patent search, patent retrieval, patent checking, patent infringement prevention, FTO clearance, prior art search, patent infringement investigation, etc. Even if the user does not explicitly mention “Google Patents,” as long as the user wants to search patent literature using keywords or bibliographic criteria, this skill should be activated.
