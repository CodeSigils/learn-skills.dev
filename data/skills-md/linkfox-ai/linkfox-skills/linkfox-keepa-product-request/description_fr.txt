Obtenez les détails des produits Amazon via ASIN, notamment le prix, le titre, l'image principale, la date de lancement, le matériau, le poids, les ventes mensuelles des variantes et les données de ventes mensuelles des 12 derniers mois. Cette compétence est déclenchée lorsque l'utilisateur interroge les détails du produit Amazon, la recherche d'ASIN, le prix du produit, l'historique du classement des ventes, les tendances des ventes mensuelles, les dimensions du produit, les frais Expédié par Amazon, les spécifications du produit, la recherche d'ASIN par lots, les détails du produit Keepa, la recherche de détails d'ASIN, les données de ventes mensuelles, les informations sur les prix, les spécifications du produit, les frais Expédié par Amazon ou la requête ASIN par lot. Même si l'utilisateur ne mentionne pas explicitement « Keepa », tant que la demande implique l'obtention de données produit structurées pour un ou plusieurs ASIN Amazon, cette compétence doit être activée.
