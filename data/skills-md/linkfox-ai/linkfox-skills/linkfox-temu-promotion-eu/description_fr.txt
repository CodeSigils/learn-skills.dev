API de promotion du commerce électronique du site Temu Europe, transmise via la passerelle LinkFox en tant que partenaire EU Promotion / interfaces bg/temu liées à l'activité de promotion (création d'activité, inscription, requête, coupons/ventes flash, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenchement lorsque l'utilisateur mentionne une promotion Temu EU, une activité promotionnelle, un coupon, une vente flash, un enregistrement d'activité, une campagne de promotion, une promotion d'inventaire de produits. Utilisez linkfox-temu-manage-product-eu pour la gestion des produits ; linkfox-temu-price-eu pour les prix ; linkfox-temu-order-eu pour les commandes.
