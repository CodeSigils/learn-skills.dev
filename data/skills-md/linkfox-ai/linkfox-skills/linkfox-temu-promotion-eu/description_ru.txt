API продвижения электронной коммерции на сайте Temu Europe, пересылаемый через шлюз LinkFox в качестве партнеров по продвижению в ЕС / интерфейсам bg/temu, связанным с рекламной деятельностью (создание активности, регистрация, запрос, купоны/мгновенные продажи и т. д.; интерфейсы будут интегрированы один за другим в соответствии с документацией партнера). Срабатывает, когда пользователь упоминает акцию Temu EU, рекламную деятельность, купон, флэш-распродажу, регистрацию активности, рекламную кампанию, продвижение ассортимента продукции. Используйте linkfox-temu-manage-product-eu для управления продуктами; linkfox-temu-price-eu для ценообразования; ссылкаfox-temu-order-eu для заказов.
