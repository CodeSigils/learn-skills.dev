استنادًا إلى اكتشاف RuiGuan لانتهاك براءات الاختراع للتصميم، دعم عمليات البحث عن براءات الاختراع للصور في أكثر من 25 دولة/منطقة. يتم تشغيل هذه المهارة عندما يذكر المستخدم اكتشاف براءات الاختراع، أو التحقق من انتهاك براءات الاختراع، أو تحليل مخاطر براءات الاختراع، أو استعلامات حالة TRO، أو البحث عن براءات التصميم، أو تشابه براءات الاختراع، أو فحص براءات الاختراع للمنتج، أو اكتشاف براءات الاختراع، أو انتهاك براءات الاختراع، أو براءات الاختراع التصميمية، أو حالات TRO، أو مخاطر براءات الاختراع، أو البحث عن براءات الاختراع، أو Ruiguan. حتى إذا لم يذكر المستخدم صراحةً "براءة تصميم"، طالما أن الطلب يتضمن التحقق مما إذا كانت صورة المنتج قد تنتهك براءة تصميم حالية، أو يذكر كلمات رئيسية مثل الانتهاك، أو براءة الاختراع، أو TRO، أو براءة اختراع التصميم، فيجب أيضًا تفعيل هذه المهارة.
