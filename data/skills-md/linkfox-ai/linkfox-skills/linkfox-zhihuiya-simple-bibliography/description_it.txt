Richiedi brevi dati bibliografici sui brevetti (bibliografici) dal database dei brevetti WisdomBud. Quando un utente menziona query di informazioni bibliografiche sui brevetti, recupero di informazioni di base sui brevetti, dati bibliografici di brevetti, dettagli di pubblicazione di brevetti, ricerca dell'inventore per numero di brevetto, informazioni sul richiedente di brevetto, recupero di abstract di brevetto, numero di classificazione di brevetto (IPC/CPC), query di citazione di brevetto o qualsiasi richiesta di recuperare metadati strutturati tramite ID di brevetto o numero di pubblicazione (bibliografia breve di brevetti, informazioni di base di brevetto, ricerca di numero di brevetto, abstract di brevetto, PatSnap, metadati di brevetto), attiva questa funzionalità. Anche se l’utente non menziona esplicitamente “WisdomBud” o “informazioni bibliografiche”, purché la richiesta implichi l’interrogazione dei campi bibliografici principali di un brevetto specifico, questa funzionalità dovrebbe essere attivata.
