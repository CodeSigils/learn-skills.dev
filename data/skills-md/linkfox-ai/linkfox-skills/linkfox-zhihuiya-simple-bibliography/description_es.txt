Consulte breves datos bibliográficos de patentes de la base de datos de patentes WiseSeed. Esta habilidad se activa cuando el usuario menciona consultas de información bibliográfica de patentes, recuperación de información básica de patentes, datos bibliográficos de patentes, detalles de publicación de patentes, búsqueda de inventor por número de patente, información del solicitante, recuperación de resúmenes de patentes, códigos de clasificación de patentes (IPC/CPC), consultas de citas de patentes o cualquier solicitud para recuperar metadatos estructurados mediante ID de patente o número de publicación, así como términos como bibliografía breve de patentes, información básica de patentes, búsqueda de número de patente, resumen de patente, PatSnap o metadatos de patente. Incluso si el usuario no menciona explícitamente "WiseSeed" o "información bibliográfica", la habilidad debe activarse siempre que la solicitud implique consultar campos bibliográficos principales de una patente específica.
