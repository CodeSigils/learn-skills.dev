Shopee (虾皮) in‑store advertising Ads (in the same series as linkfox‑shopee‑store‑auth) is forwarded via /shopee/developerProxy to the Shopee Open API Ads module, covering 23 interfaces such as get_total_balance, create_manual_product_ads, get_product_campaign_daily_performance, GMS ads, etc. When a user mentions Shopee advertising, Ads, ad balance, CPC, product promotion, manual ads, campaign, ad performance, ROI, or get_total_balance, it should be triggered. Even if “advertising” is not explicitly mentioned, as long as the query involves the ad account, promotion, or performance of an authorized Shopee store, it should also be triggered.
