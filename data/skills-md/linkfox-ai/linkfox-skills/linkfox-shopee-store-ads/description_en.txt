Shopee (虾皮) shop internal ads (Ads, same series as linkfox-shopee-store-auth) are forwarded via /shopee/developerProxy to the Shopee Open API Ads module’s 23 interfaces: get_total_balance, create_manual_product_ads, get_product_campaign_daily_performance, GMS ads, etc. When a user mentions Shopee ads, Ads, ad balance, CPC, product promotion, manual ads, campaign, ad performance, ROI, or get_total_balance, it should be triggered. Even if "ads" is not explicitly mentioned, any reference to the ad account, promotion, or performance query of an authorized Shopee shop should also trigger it.
