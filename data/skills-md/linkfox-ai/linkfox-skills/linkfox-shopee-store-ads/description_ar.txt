تقوم Shopee (XiaPei) بتخزين الإعلانات الإعلانية الداخلية (نفس السلسلة مثل linkfox-shopee-store-auth)، والتي يتم توجيهها عبر /shopee/developerProxy إلى الواجهات الـ 23 لوحدة Shopee Open API Ads: get_total_balance، create_manual_product_ads، get_product_campaign_daily_performance، إعلانات GMS، وما إلى ذلك. عندما يذكر المستخدم إعلانات Shopee، والإعلانات، وتوازن الإعلانات، تكلفة النقرة، أو ترويج المنتج، أو الإعلانات اليدوية، أو الحملة، أو أداء الإعلان، أو عائد الاستثمار، أو get_total_balance، فيجب تشغيلها. حتى لو لم يتم ذكر "الإعلان" صراحةً، طالما أنه يتضمن حسابًا إعلانيًا أو عرضًا ترويجيًا أو استعلامًا عن الأداء لمتجر Shopee معتمد، فيجب أن يتم تشغيله أيضًا.
