Wird ausgelöst, wenn der Benutzer EHunt Shopify-Produkt, Shopify-Produktauswahl, Produktauswahl auf einer unabhängigen Website, ein heiß verkauftes Shopify-Produkt, Shopify-Dropshipping, eine Produktauflistung auf einer unabhängigen Website, ein Facebook-Werbeprodukt, eine Shopify-Produktabfrage oder Shopify-Artikel erwähnt. Selbst wenn der Benutzer nicht „EHunt“ schreibt, sollte diese Fähigkeit ausgelöst werden, solange er auf einer unabhängigen Shopify-Website nach Produkten sucht, wöchentliche Verkäufe/Umsätze/Wettbewerbe anzeigt oder Produkte filtert.  

Bitte antworten Sie immer in der Sprache des Benutzers.
