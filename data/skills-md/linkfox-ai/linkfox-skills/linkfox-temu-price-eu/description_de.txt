API zur Produktpreisverwaltung auf der Website von Temu Europe, weitergeleitet über das LinkFox-Gateway an die Preisschnittstelle von Partner EU: Preisbestelllistenabfrage (bg.local.goods.priceorder.query), Batch-Änderung des SKU-Grundpreises (bg.local.goods.priceorder.change.sku.price), empfohlener Angebotspreis/Grundpreisschätzung usw. Wird ausgelöst, wenn Benutzer den Temu-EU-Preis, die Preisbestellung auf der Website von Temu Europe, eine Preisbestellabfrage, priceAuditList, Angebotsänderung erwähnen Preis, Chargenpreisänderung, Site=eu-Preisänderung, empfohlene Preisabfrage oder Basispreisempfehlung. Das Produktmanagement verwendet linkfox-temu-manage-product-eu; Bestellungen, Sendungen und andere Domains können den US-Skill mit site=eu nutzen.
