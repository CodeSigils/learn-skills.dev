API управления заказами на сайте Temu Europe, пересылаемый шлюзом LinkFox в интерфейс заказов партнеров в ЕС: список заказов/детали/адрес доставки/сумма/комбинированная доставка/индивидуализация/загрузка аутентификации по серийному номеру (bg.order.*, tem u.local.order.verification.upload) и т. д. Он срабатывает, когда пользователи упоминают заказ Temu EU, заказ на сайте Temu Europe, загрузку серийного номера, IMEI, загрузку проверки, индивидуальный продукт, комбинированную доставку, родительский заказ, site=eu заказ-доставка. Управление продуктами использует linkfox-temu-manage-product-eu; ценообразование использует linkfox-temu-price-eu; при выполнении/доставке используется linkfox-temu-fulfillment-eu; возврат/возврат использует ссылкуfox-temu-returns-refunds-eu; для отмены используется linkfox-temu-cancel-order-eu.
