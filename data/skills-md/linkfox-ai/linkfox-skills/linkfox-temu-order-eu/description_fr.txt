API de gestion des commandes du site Temu Europe, transmise par la passerelle LinkFox à l'interface de commande du partenaire UE : liste de commande/détail/adresse de livraison/montant/expédition combinée/personnalisation/téléchargement d'authentification SN (bg.order.*, tem u.local.order.verification.upload), etc. Elle est déclenchée lorsque les utilisateurs mentionnent la commande Temu EU, la commande du site Temu Europe, le téléchargement SN, IMEI, le téléchargement de vérification, le produit personnalisé, l'expédition combinée, parentOrderSn, site=eu expédition de la commande. La gestion des produits utilise linkfox-temu-manage-product-eu ; la tarification utilise linkfox-temu-price-eu ; l'exécution/l'expédition utilise linkfox-temu-fulfillment-eu ; les retours/remboursements utilisent linkfox-temu-returns-refunds-eu ; l'annulation utilise linkfox-temu-cancel-order-eu.
