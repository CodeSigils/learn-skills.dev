API de gestion des commandes du site Temu Europe, transmise via la passerelle LinkFox à l'interface de commande du partenaire UE : liste de commande/détail/adresse de livraison/montant/expédition combinée/personnalisation/téléchargement de vérification SN (bg.order.*, temu.local.order.verification.upload), etc. Elle est déclenchée lorsque l'utilisateur mentionne la commande Temu EU, la commande du site Temu Europe, le téléchargement SN, IMEI, le téléchargement de vérification, le produit personnalisé, l'expédition combinée, parentOrderSn, site=eu expédition de la commande. Pour la gestion des produits, utilisez linkfox‑temu‑manage‑product‑eu ; pour les prix, utilisez linkfox‑temu‑price‑eu ; pour l'exécution/l'expédition, utilisez linkfox‑temu‑fulfillment‑eu ; pour les retours/remboursements, utilisez linkfox‑temu‑returns‑refunds‑eu ; pour l'annulation, utilisez linkfox‑temu‑cancel‑order‑eu.
