API de retours et de remboursements du site de commerce électronique Temu US, transmis via la passerelle LinkFox, les interfaces bg/temu liées aux retours et remboursements américains / retours après-vente et remboursements partenaires (demandes de retour, remboursements, requête et traitement des commandes après-vente, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsque les utilisateurs mentionnent les retours Temu US, les remboursements, les retours après-vente, le retour, le remboursement, le retour après-vente, parentAfterSalesSn, la commande de retour, la commande de remboursement, l'expédition de la commande après-vente. Les acheteurs/vendeurs annulent les commandes en utilisant linkfox-temu-cancel-order-us / linkfox-temu-cancel-order-us ; les commandes utilisent linkfox-temu-order-us.
