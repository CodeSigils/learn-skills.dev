الاستعلام عن المعلومات الببليوغرافية (السجلية) لبراءات الاختراع في قاعدة بيانات براءات الاختراع PatSnap باستخدام معرف براءة الاختراع أو رقم النشر. يتم تشغيل هذه المهارة عندما يذكر المستخدم الاستعلام عن المعلومات الببليوغرافية لبراءات الاختراع، أو البيانات الببليوغرافية لبراءات الاختراع، أو البحث عن مقدم طلب براءة الاختراع، أو البحث عن مخترع براءة الاختراع، أو رقم تصنيف براءة الاختراع، أو استرجاع ملخص براءة الاختراع، أو تحليل الاستشهاد ببراءة الاختراع، أو المطالبة بأولوية براءة الاختراع، أو الاستشهاد بطلب براءة الاختراع، أو معلومات فاحص براءة الاختراع، أو البيانات الببليوغرافية لبراءة الاختراع، أو البحث عن المخترع، أو البحث عن مقدم الطلب، أو تصنيف براءة الاختراع، أو البيانات الوصفية لبراءة الاختراع، أو PatSnap، أو استشهادات براءات الاختراع. وحتى لو لم يذكر المستخدم صراحةً "المعلومات الببليوغرافية"، فطالما أن الطلب يتضمن استرجاع البيانات الوصفية التفصيلية لبراءة اختراع معينة عبر معرفها أو رقم نشرها، فيجب تفعيل هذه المهارة.
