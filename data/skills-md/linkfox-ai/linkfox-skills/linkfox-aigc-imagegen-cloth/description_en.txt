Clothing picture generation (model/clothing type). Supports single images or image sets: white‑background image (invisible model), model image, “grass‑planting” image, selling‑point image, A+ image, size chart. A single image of a single type is output directly; multiple images of multiple types are automatically arranged and planned. When the user uploads a model photo or clothing picture (top/bottom/dress/jacket/shoes & hats, etc.) and says “make set images”, “make model image”, “make grass‑planting image”, “make selling‑point image”, “make A+ image”, “make size chart”, “make clothing white‑background image”, the process is triggered. Pure image‑editing operations go through linkfox‑aigc‑imagegen.
