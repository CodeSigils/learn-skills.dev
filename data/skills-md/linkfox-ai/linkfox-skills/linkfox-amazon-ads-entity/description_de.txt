Grundlegende Fähigkeit zur Entitätsabfrage von Amazon Ads, die sechs Listen für Sponsored Products (SP) abdeckt: Kampagnen, Anzeigengruppen, Schlüsselwörter, negative Keywords, Produktanzeigen und Ziele sowie drei Listen für Sponsored Brands (SB v4): Kampagnen, Anzeigengruppen und Anzeigen; Es verarbeitet automatisch Paginierung, Token und inkonsistente Filterbedingungsformate über Entitäten hinweg in der nativen API von Amazon. Es wird ausgelöst, wenn der Benutzer die Abfrage von Amazon-Werbekampagnen, das Anzeigen von Anzeigengruppen, das Auflisten von Schlüsselwörtern, Anzeigenplatzierungen entsprechend ASINs, das Überprüfen von Zielen, das Auflisten von SP-Kampagnen/Anzeigengruppen/Schlüsselwörtern/Produktanzeigen/Zielen oder SB-Kampagnen/Anzeigengruppen/Anzeigen erwähnt. Dieser Skill hängt von der Linkfox-Amazon-Ads-Auth-Authentisierung ab. Sponsored Display (SD) / Sponsored Television (ST) / Amazon DSP werden noch nicht abgedeckt.
