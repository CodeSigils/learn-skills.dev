Amazon 広告の基本的なエンティティ クエリ スキル。スポンサー プロダクト (SP) の 6 つのリスト (キャンペーン、広告グループ、キーワード、除外キーワード、商品広告、ターゲット) と、スポンサー ブランド (SB v4) の 3 つのリスト (キャンペーン、広告グループ、広告) をカバーします。 Amazon のネイティブ API のエンティティ間でページネーション、トークン、一貫性のないフィルター条件形式を自動的に処理します。これは、Amazon 広告キャンペーンのクエリ、広告グループの表示、キーワードのリスト、ASIN に対応する広告プレースメントのリスト、ターゲットの確認、SP キャンペーン/広告グループ/キーワード/productAds/ターゲット、または SB キャンペーン/広告グループ/広告のリストをユーザーが言及したときにトリガーされます。このスキルは linkfox‑amazon‑ads‑auth に依存します。スポンサーディスプレイ (SD) / スポンサーテレビ (ST) / Amazon DSP はまだカバーされていません。
