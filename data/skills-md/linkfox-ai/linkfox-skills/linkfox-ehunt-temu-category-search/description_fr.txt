Grâce à la recherche de catégorie EHunt Temu (route de passerelle `ehunt/temu/temuCategorySearch`), recherchez par mot-clé le nom chinois, le nom anglais et l'ID de catégorie dans les données de catégorie EHunt Temu qui ont été synchronisées avec la base de données locale, pour obtenir les ID de catégorie utilisés dans le filtrage des produits/magasins. Ceci est déclenché lorsque l'utilisateur mentionne la catégorie EHunt Temu, l'ID de catégorie Temu, l'arborescence de catégories Temu, la catégorie backend Temu, la catégorie Temu, syncTemuCategory (synchronisation de catégorie Temu) suivi d'une recherche de catégorie ou d'une recherche de catégorie Temu. Même si l'utilisateur n'écrit pas « EHunt », tant qu'un identifiant de catégorie est recherché par mot-clé dans la base de données de catégories Temu synchronisée localement, cette compétence doit être déclenchée.
