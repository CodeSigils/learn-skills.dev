Attraverso la ricerca per categoria di EHunt Temu (percorso gateway `ehunt/temu/temuCategorySearch`), ricerca per parola chiave il nome cinese, il nome inglese e l'ID della categoria all'interno dei dati della categoria EHunt Temu che sono stati sincronizzati con il database locale, per ottenere gli ID di categoria utilizzati nel filtraggio del prodotto/negozio. Questo viene attivato quando l'utente menziona la categoria EHunt Temu, l'ID categoria Temu, l'albero delle categorie Temu, la categoria backend Temu, la categoria Temu, syncTemuCategory (sincronizzazione della categoria Temu) seguita da una ricerca di categoria o una ricerca di categoria Temu. Anche se l'utente non scrive "EHunt", purché un ID di categoria venga cercato per parola chiave nel database delle categorie Temu sincronizzato localmente, questa abilità dovrebbe essere attivata.
