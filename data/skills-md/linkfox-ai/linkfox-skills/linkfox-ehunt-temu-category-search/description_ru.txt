С помощью поиска по категориям EHunt Temu (маршрут шлюза `ehunt/temu/temuCategorySearch`) выполните поиск по ключевым словам по китайскому названию категории, английскому названию и идентификатору категории в данных категории EHunt Temu, которые были синхронизированы с локальной базой данных, для получения идентификаторов категорий, используемых при фильтрации товаров/магазинов. Это срабатывает, когда пользователь упоминает категорию EHunt Temu, идентификатор категории Temu, дерево категорий Temu, внутреннюю категорию Temu, категорию Temu, syncTemuCategory (синхронизация категорий Temu), а затем выполняет поиск по категории или поиск по категории Temu. Даже если пользователь не пишет «EHunt», пока идентификатор категории ищется по ключевому слову в локально синхронизированной базе данных категорий Temu, этот навык должен сработать.
