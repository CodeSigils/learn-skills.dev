A través de la búsqueda de categorías de EHunt Temu (ruta de entrada `ehunt/temu/temuCategorySearch`), busque con palabras clave el nombre chino de la categoría, el nombre en inglés y el ID de categoría dentro de los datos de categoría de EHunt Temu que se han sincronizado con la base de datos local, para obtener los ID de categoría utilizados en el filtrado de productos/tiendas. Esto se activa cuando el usuario menciona la categoría EHunt Temu, el ID de la categoría Temu, el árbol de categorías de Temu, la categoría de backend de Temu, la categoría de Temu, syncTemuCategory (sincronización de categorías de Temu) seguido de una búsqueda de categorías o una búsqueda de categorías de Temu. Incluso si el usuario no escribe "EHunt", siempre que se busque un ID de categoría por palabra clave en la base de datos de categorías de Temu sincronizada localmente, esta habilidad debería activarse.
