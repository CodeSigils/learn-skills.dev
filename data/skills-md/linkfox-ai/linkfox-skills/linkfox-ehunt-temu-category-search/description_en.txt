Through the EHunt Temu category search (gateway route `ehunt/temu/temuCategorySearch`), keyword-search the category’s Chinese name, English name, and category ID within the EHunt Temu category data that has been synchronized to the local database, for obtaining category IDs used in product/store filtering. This is triggered when the user mentions EHunt Temu category, Temu category ID, Temu category tree, Temu backend category, Temu category, syncTemuCategory (Temu category synchronization) followed by a category lookup, or Temu category search. Even if the user does not write “EHunt,” as long as a category ID is searched by keyword in the locally synchronized Temu category database, this skill should be triggered.
