باستخدام بيانات تصنيف منتجات EchoTik الجديدة، اكتشف العناصر الجديدة الشائعة عبر 16 سوقًا إقليميًا لمتجر TikTok. يتم تشغيل هذه المهارة عندما يذكر المستخدم تصنيفات منتجات TikTok الجديدة، أو منتجات TikTok الأكثر مبيعًا، أو عناصر TikTok Shop الساخنة، أو اختيار منتجات التجارة الإلكترونية للفيديو القصير، أو اكتشاف منتج TikTok الجديد، أو اختيار منتج TikTok عبر الحدود، أو تصنيفات منتجات TikTok الجديدة، أو أكثر منتجات TikTok مبيعًا، أو اختيار منتجات الفيديو القصيرة، أو منتجات TikTok واسعة الانتشار، أو تصنيف المنتجات الجديدة، أو اتجاهات منتجات TikTok. حتى لو لم يذكر المستخدم صراحةً "EchoTik" أو "تصنيف المنتج الجديد"، طالما أن طلبه يتضمن العثور على منتجات جديدة رائجة أو اتجاهات المنتجات الناشئة على متجر TikTok، فيجب تفعيل هذه المهارة.  

يرجى الرد دائمًا بلغة المستخدم.
