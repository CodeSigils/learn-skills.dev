API de retours et de remboursements du site de commerce électronique de Temu Europe, transmise via la passerelle LinkFox pour les interfaces bg/temu liées aux retours et remboursements des partenaires EU / retours après-vente et remboursements (demande de retour, remboursement, requête et traitement des commandes après-vente, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsque l'utilisateur mentionne le retour Temu EU, le remboursement, le retour après-vente, le retour, le remboursement, le retour après-vente, parentAfterSalesSn, la commande de retour, la commande de remboursement, l'expédition de la commande après-vente. Annuler les commandes, utilisez linkfox‑temu‑cancel‑order‑eu ; les commandes utilisent linkfox‑temu‑order‑eu.
