API für E-Commerce-Rückgaben und Rückerstattungen auf der Website von Temu Europe, weitergeleitet über das LinkFox-Gateway für EU-Rückgaben und Rückerstattungen von Partnern/After-Sales-Retouren und Rückerstattungen im Zusammenhang mit bg/temu-Schnittstellen (Rückgabeanfrage, Rückerstattung, Abfrage und Bearbeitung von After-Sales-Bestellungen usw.; die Schnittstellen werden gemäß der Partnerdokumentation einzeln integriert). Wird ausgelöst, wenn der Benutzer Temu EU-Rückgabe, Rückerstattung, After-Sales-Retoure, Rückgabe, Rückerstattung, After-Sales-Retoure, parentAfterSalesSn, Retourenauftrag, Rückerstattungsauftrag, Auftragsversand After-Sales erwähnt. Zum Stornieren von Bestellungen verwenden Sie linkfox‑temu‑cancel‑order‑eu; Für Bestellungen verwenden Sie linkfox‑temu‑order‑eu.
