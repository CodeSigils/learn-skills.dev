API per resi e rimborsi e-commerce del sito Temu Europe, inoltrata tramite il gateway LinkFox per le interfacce bg/temu relative a resi e rimborsi/resi post-vendita dei partner UE (richiesta di reso, rimborso, query ed elaborazione degli ordini post-vendita, ecc.; le interfacce verranno integrate una per una in base alla documentazione del partner). Si attiva quando l'utente menziona reso, rimborso, reso post-vendita di Temu EU, reso, rimborso, reso post-vendita, parentAfterSalesSn, ordine di reso, ordine di rimborso, post-vendita con spedizione dell'ordine. Per annullare gli ordini utilizzare linkfox‑temu‑cancel‑order‑eu; gli ordini utilizzano linkfox‑temu‑order‑eu.
