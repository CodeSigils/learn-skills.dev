Règlement des paiements de la boutique Shopee (de la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy aux 18 interfaces du module de paiement Shopee Open API : get_escrow_detail, get_escrow_list, get_payout_detail, get_wallet_transaction_list, get_ Income_overview, generate_ Income_report, etc. Il est déclenché lorsqu'un utilisateur mentionne le paiement Shopee, règlement, séquestre, paiement, transactions de portefeuille, rapports de revenus, paiement échelonné, get_escrow_detail, etc. Même si le « paiement » n'est pas explicitement mentionné, toute requête concernant le règlement/paiement/revenu pour une boutique Shopee autorisée devrait également le déclencher.
