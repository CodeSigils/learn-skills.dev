Le règlement des paiements du magasin Shopee (Shopee) (même série que linkfox-shopee-store-auth) est transmis par /shopee/developerProxy aux 18 interfaces du module de paiement Shopee Open API : get_escrow_detail, get_escrow_list, get_payout_detail, get_wallet_transaction_list, get_ Income_overview, generate_ Income_report, etc. Il est déclenché lorsque l'utilisateur mentionne Shopee paiement, règlement, séquestre, paiement, transactions de portefeuille, rapports de revenus, paiements échelonnés, get_escrow_detail. Même si le « paiement » n'est pas explicitement mentionné, tant qu'il implique des requêtes de règlement/paiement/revenu pour une boutique Shopee autorisée, il doit être déclenché.
