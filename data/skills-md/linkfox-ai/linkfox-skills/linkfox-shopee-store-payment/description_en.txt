Shopee (Shopee) store payment settlement (same series as linkfox-shopee-store-auth) is forwarded by /shopee/developerProxy to all 18 Shopee Open API Payment module interfaces: get_escrow_detail, get_escrow_list, get_payout_detail, get_wallet_transaction_list, get_income_overview, generate_income_report, etc. It is triggered when the user mentions Shopee payment, settlement, escrow, payout, wallet transactions, income reports, installment payments, get_escrow_detail. Even if "payment" is not explicitly mentioned, as long as it involves settlement/payout/income queries for an authorized Shopee store, it should be triggered.
