Shopee store payment settlement (in the same series as linkfox-shopee-store-auth) forwards all 18 Shopee Open API Payment module interfaces through /shopee/developerProxy: get_escrow_detail, get_escrow_list, get_payout_detail, get_wallet_transaction_list, get_income_overview, generate_income_report, etc. When a user mentions Shopee payment, settlement, escrow, payout, wallet transactions, income reports, installment payments, or get_escrow_detail, it should be triggered. Even if "payment" is not explicitly mentioned, any query related to settlement/payout/income for an authorized Shopee store should also trigger.
