تسوية دفع متجر Shopee (في نفس السلسلة مثل linkfox-shopee-store-auth)، يتم إعادة توجيهها من خلال /shopee/developerProxy إلى جميع واجهات وحدة الدفع لـ Shopee Open API الـ 18: get_escrow_detail، get_escrow_list، get_payout_detail، get_wallet_transaction_list، get_interview_overview، generator_venue_report، وما إلى ذلك. يتم تشغيلها عندما يذكر المستخدم دفع Shopee أو التسوية أو الضمان أو الدفع أو معاملة المحفظة أو تقرير الدخل أو الدفع بالتقسيط أو get_escrow_detail. حتى لو لم يتم ذكر "الدفع" صراحةً، طالما أنه يتضمن استعلامات التسوية/الدفع/الدخل لمتجر Shopee معتمد، فيجب تشغيله.
