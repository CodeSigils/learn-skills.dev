Utilice la capacidad de búsqueda inversa de palabras clave de tráfico de SellerSprite para consultar fuentes de tráfico de palabras clave, tipos de participación de tráfico, tipos de conversión, posiciones orgánicas y publicitarias, y otras métricas por ASIN, lo que admite meses históricos y clasificación multidimensional. Cuando el usuario menciona palabras clave de tráfico de búsqueda inversa de ASIN, listas de palabras clave de tráfico, estructura de tráfico de palabras clave, análisis de palabras clave orgánicas/publicitarias, tipos de conversión de palabras clave, palabras clave de tráfico de SellerSprite, palabras clave de tráfico de Amazon o palabras clave de ASIN inversas, se activa esta habilidad. Incluso si el usuario no menciona explícitamente "SellerSprite", siempre que la solicitud sea para ver las fuentes de tráfico de palabras clave y la lista de palabras clave de un ASIN, esta habilidad debe activarse.
