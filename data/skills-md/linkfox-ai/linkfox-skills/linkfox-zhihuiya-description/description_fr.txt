Obtenez des données de spécification (description) de brevet à partir de la base de données de brevets PatSnap à l'aide d'un identifiant de brevet ou d'un numéro de publication. Cette compétence est déclenchée lorsque l'utilisateur mentionne la description du brevet, le texte intégral du brevet, la description technique du brevet, les détails des modes de réalisation du brevet, les données de la spécification PatSnap, la description du brevet, le texte intégral du brevet, la description technique, les détails du mode de réalisation, PatSnap ou la description détaillée du brevet. Même si l'utilisateur ne dit pas explicitement « PatSnap », tant qu'il a besoin de visualiser la spécification/description complète d'un ou plusieurs brevets, cette compétence doit être déclenchée.
