API Temu US e-commerce Ads, transmise via la passerelle LinkFox aux interfaces bg/temu liées aux annonces/diffusion publicitaire du partenaire US (campagnes publicitaires, groupes d'annonces, créations, rapports, enchères budgétaires, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenchez lorsque l'utilisateur mentionne les annonces Temu US, les annonces, la diffusion publicitaire, la campagne publicitaire, le groupe d'annonces, la création, les enchères, le budget, le rapport publicitaire, la campagne publicitaire ou la publicité d'inventaire de produits. Utilisez linkfox-temu-manage-product-us pour la gestion des produits ; linkfox-temu-promotion-us pour les promotions ; et linkfox-temu-order-us pour les commandes.
