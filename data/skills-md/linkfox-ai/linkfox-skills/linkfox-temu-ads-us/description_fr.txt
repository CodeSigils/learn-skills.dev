API Temu US e-commerce Advertising Ads, transmise via la passerelle LinkFox aux interfaces bg/temu liées au déploiement publicitaire du partenaire US Ads (campagne publicitaire, groupe d'annonces, création, rapports, budget et enchères, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsque les utilisateurs mentionnent les annonces Temu US, les annonces, le déploiement publicitaire, la campagne publicitaire, le groupe d'annonces, la création, les enchères, le budget, les rapports publicitaires, la campagne publicitaire, la publicité sur l'inventaire de produits. Utilisez linkfox‑temu‑manage‑product‑us pour la gestion des produits ; linkfox‑temu‑promotion‑us pour les promotions ; et linkfox‑temu‑order‑us pour les commandes.
