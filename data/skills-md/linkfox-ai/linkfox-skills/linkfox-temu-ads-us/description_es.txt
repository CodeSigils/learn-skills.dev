API de anuncios de comercio electrónico de Temu EE. UU., reenviada a través de la puerta de enlace LinkFox a las interfaces bg/temu relacionadas con anuncios/entrega de publicidad del socio EE. UU. (campañas publicitarias, grupos de anuncios, creatividades, informes, ofertas de presupuesto, etc.; las interfaces se integrarán una por una de acuerdo con la documentación del socio). Se activa cuando el usuario menciona anuncios de Temu US, anuncios, entrega de publicidad, campaña publicitaria, grupo de anuncios, creatividad, ofertas, presupuesto, informe publicitario, campaña publicitaria o publicidad de inventario de productos. Utilice linkfox-temu-manage-product-us para la gestión de productos; linkfox-temu-promotion-us para promociones; y linkfox-temu-order-us para pedidos.
