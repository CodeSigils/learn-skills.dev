صفقة الوظيفة الإضافية لـ Shopee (Xia Pi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، التي تمت إعادة توجيهها عبر/shopee/developerProxy، وتتضمن جميع واجهات وحدة صفقة الوظيفة الإضافية لـ Shopee Open API الـ 14: add_add_on_deal، get_add_on_deal_list، add_add_on_deal_main_item، add_add_on_deal_sub_item، update_add_on_deal، وend_add_on_deal، وما إلى ذلك. يتم تشغيلها عندما يذكر المستخدم صفقة Shopee Add-On Deal، أو Add-On Deal، أو الوظيفة الإضافية للمنتج الرئيسي، أو add_add_on_deal، أو add_on_deal_id، أو الوظيفة الإضافية كاملة المبلغ. حتى إذا لم يتم ذكر "الوظيفة الإضافية" صراحةً، فإن أي إشارة إلى إدارة أنشطة الصفقة الإضافية لمتجر Shopee معتمد يجب أن تؤدي أيضًا إلى تشغيلها.
