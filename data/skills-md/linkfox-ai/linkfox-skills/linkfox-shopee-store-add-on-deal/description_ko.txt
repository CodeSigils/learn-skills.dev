/shopee/developerProxy를 통해 전달되는 Shopee(Shopee) 추가 거래(linkfox-shopee-store-auth와 동일한 시리즈)에는 14개의 Shopee Open API 추가 거래 모듈 인터페이스가 모두 포함됩니다: add_add_on_deal, get_add_on_deal_list, add_add_on_deal_main_item, add_add_on_deal_sub_item, update_add_on_deal, end_add_on_deal 등. 사용자가 Shopee 추가 거래, 추가 거래, 주요 제품 추가 기능, add_add_on_deal, add_on_deal_id, 전체 금액 추가 기능 등을 언급할 때 트리거됩니다. "추가 기능"이 명시적으로 언급되지 않은 경우에도 승인된 Shopee 매장에 대한 추가 기능 거래 활동 관리와 관련된 경우 해당 기능도 실행되어야 합니다.
