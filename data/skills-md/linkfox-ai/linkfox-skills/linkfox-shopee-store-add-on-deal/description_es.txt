Shopee (Xia Pi) Add-On Deal (en la misma serie que linkfox-shopee-store-auth), reenviado a través de /shopee/developerProxy, incluye las 14 interfaces del módulo Shopee Open API Add-On Deal: add_add_on_deal, get_add_on_deal_list, add_add_on_deal_main_item, add_add_on_deal_sub_item, update_add_on_deal, end_add_on_deal, etc. Cuando un usuario menciona Shopee Add-On Deal, Add-On Deal, complemento de producto principal, add_add_on_deal, add_on_deal_id, complemento de monto total, se activa. Incluso si el "complemento" no se menciona explícitamente, también debería activarse cualquier participación en la gestión de las actividades de la oferta de complementos para una tienda Shopee autorizada.
