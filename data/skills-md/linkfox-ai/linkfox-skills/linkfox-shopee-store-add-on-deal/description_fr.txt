Shopee (Xia‑Pi) Add‑On Deal (dans la même série que linkfox‑shopee‑store‑auth), transmis via /shopee/developerProxy, comprend les 14 interfaces du module Shopee Open API Add‑On Deal : add_add_on_deal, get_add_on_deal_list, add_add_on_deal_main_item, add_add_on_deal_sub_item, update_add_on_deal, end_add_on_deal, etc. Il est déclenché lorsque les utilisateurs mentionnent Shopee Add‑On Deal, Add‑On Deal, le module complémentaire du produit principal, add_add_on_deal, add_on_deal_id, le module complémentaire à montant total, etc. Même si le « module complémentaire » n’est pas explicitement mentionné, tant qu’il implique la gestion des activités Add-On Deal pour une boutique Shopee agréée, il doit également être déclenché.
