Shopee (Xia Pi) Add-On Deal (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy au module Shopee Open API Add-On Deal, englobant les 14 interfaces : add_add_on_deal, get_add_on_deal_list, add_add_on_deal_main_item, add_add_on_deal_sub_item, update_add_on_deal, end_add_on_deal, etc. Il est déclenché lorsqu'un utilisateur mentionne Shopee Add-On Deal, Add-On Deal, le module complémentaire du produit principal, add_add_on_deal, add_on_deal_id ou le module complémentaire à montant total. Même si le « module complémentaire » n'est pas explicitement référencé, toute implication dans la gestion des activités de module complémentaire pour une boutique Shopee autorisée devrait également se déclencher.
