Shopee (Xia Pi) Add-On Deal (in the same series as linkfox-shopee-store-auth) is forwarded via /shopee/developerProxy to the Shopee Open API Add-On Deal module, which includes all 14 interfaces: add_add_on_deal, get_add_on_deal_list, add_add_on_deal_main_item, add_add_on_deal_sub_item, update_add_on_deal, end_add_on_deal, etc. It is triggered when a user mentions Shopee Add-On Deal, Add-On Deal, main product add-on, add_add_on_deal, add_on_deal_id, or full‑amount add-on. Even if "add‑on" is not explicitly mentioned, as long as it involves the management of Add-On Deal activities for an authorized Shopee store, it should be triggered.
