Woshifu (Walmart WMTwin) herramienta automatizada de inicio de sesión y búsqueda de competidores. Esta habilidad se activa cuando el usuario menciona Woshifu, wmtwin, www.wmtwin.com, herramientas de Walmart, búsqueda de competidores o necesita acceder a las funciones del sitio web de Woshifu. Proporciona inicio de sesión automático, llamadas API y funciones de búsqueda de competidores (que admiten búsqueda de palabras clave, filtrado WFS y filtrado de rango de ventas), con todos los datos decodificados automáticamente.
