Rechercher des informations bibliographiques sur les brevets (Bibliographie) dans la base de données des brevets Eureka, y compris le titre, le résumé, le demandeur, l'inventeur, le numéro de classification, la priorité, les références citées, etc. Cette compétence est déclenchée lorsque l'utilisateur mentionne des éléments de bibliographie de brevet, des informations de base sur le brevet, le titre et le résumé du brevet, le demandeur/inventeur du brevet, le numéro de classification du brevet, la classification IPC, la classification CPC, l'agent de brevets, l'examinateur, la priorité, les références citées, les documents connexes, la date d'expiration estimée, la bibliographie du brevet, les informations de base du brevet, le brevet. titre et résumé, demandeur de brevet/inventeur, classification du brevet, CIB/CPC, agent de brevets, examinateur de brevets, revendications de priorité, références citées, documents connexes, expiration estimée, données de brevet Eureka. Même si l'utilisateur ne mentionne pas explicitement « Eureka » ou « éléments bibliographiques », tant que la demande implique une requête d'informations bibliographiques de base sur le brevet (titre, résumé, déposant, numéro de classification, etc.), cette compétence doit être déclenchée.
