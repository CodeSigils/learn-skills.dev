Habilidad de recuperación de informes integral de Amazon Ads, que cubre todos los tipos de informes para productos patrocinados (SP)/marcas patrocinadas (SB). El script maneja automáticamente la creación, espera, descarga y extracción de informes, y devuelve directamente datos estructurados legibles. Los tipos de informes reales utilizables y la lista de columnas/groupBy/filtros de cada tipo se mantienen como una única fuente de verdad en `references/report-types/<adProduct-dir>/<reportTypeId>.md`. Se activa cuando el usuario menciona obtener informes de Amazon Ads, descargar informes de Amazon Ads, recuperar cualquier informe como campañas SP/SB/palabras clave/términos de búsqueda/productos específicos/productos comprados/grupos de anuncios/anomalías de tráfico/extensiones de aviso, etc. Esta habilidad depende de linkfox-amazon-ads-auth. Patrocinado Display (SD) / Patrocinado Televisión (ST) / Amazon DSP aún no están cubiertos.
