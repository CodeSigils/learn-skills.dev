Etsy category data. Allows retrieval of category names, IDs, and parent IDs, used for product/store filter category IDs. This skill is triggered when the user mentions Etsy category, Etsy category ID, Etsy category tree, Etsy product query, syncEtsyCategory, or category lookup. Even if the user doesn't mention the tool name, it should still be triggered when they search for a category ID by keyword in the locally synced Etsy category database.
