Etsy category data. Allows retrieval of category names, IDs, and parent IDs, used for product/store filtering category IDs. Trigger when the user mentions Etsy category, Etsy category ID, Etsy category tree, Etsy category query, syncEtsyCategory, or category lookup. Even if the user does not mention the tool name, as long as a category ID is searched by keyword in the locally synchronized Etsy category database, this skill should be triggered.
