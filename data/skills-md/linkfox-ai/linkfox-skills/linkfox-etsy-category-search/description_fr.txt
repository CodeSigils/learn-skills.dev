Données de catégorie Etsy. Les noms de catégorie, les identifiants et les identifiants parents peuvent être récupérés et sont utilisés pour les identifiants de catégorie de filtrage de produits/magasins. Cette compétence est déclenchée lorsque l'utilisateur mentionne la catégorie Etsy, l'ID de catégorie Etsy, l'arborescence des catégories Etsy, la requête de catégorie de produits Etsy, syncEtsyCategory ou la requête de catégorie. Même si l'utilisateur ne mentionne pas le nom de l'outil, tant qu'il recherche un identifiant de catégorie par mot-clé dans la base de données de catégories Etsy synchronisée localement, cette compétence doit être déclenchée.
