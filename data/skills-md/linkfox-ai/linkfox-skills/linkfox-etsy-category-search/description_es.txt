Datos de categorías de Etsy. Le permite recuperar nombres de categorías, ID e ID principales, que se utilizan como ID de categoría para el filtrado de productos/tiendas. Esta habilidad se activa cuando el usuario menciona la categoría de Etsy, el ID de categoría de Etsy, el árbol de categorías de Etsy, la consulta de productos de Etsy, syncEtsyCategory o la búsqueda de categorías. Incluso si el usuario no menciona el nombre de la herramienta, siempre que busque un ID de categoría por palabra clave en la base de datos de categorías de Etsy sincronizada localmente, esta habilidad debe activarse.
