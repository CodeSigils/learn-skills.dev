API di gestione dei prezzi dei prodotti del sito Temu US, inoltrata tramite il gateway LinkFox all'interfaccia dei prezzi del Partner US: query del listino prezzi (bg.local.goods.priceorder.query), modifica batch del prezzo base SKU (bg.local.goods.priceorder.change.sku.price), prezzo di fornitura consigliato/stima del prezzo base, ecc. Quando gli utenti menzionano il prezzo Temu US, ordine prezzo, query ordine prezzo, priceAuditList, modifica prezzo di fornitura, modifica prezzo batch, modifica sku ordine prezzo prezzo, query prezzo consigliato, prezzo base consigliato, viene attivato. Utilizzare linkfox-temu-manage-product-us per la gestione del prodotto; linkfox-temu-order-us per gli ordini; linkfox-temu-add-product-us per la pubblicazione del prodotto.
