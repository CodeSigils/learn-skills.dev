API de gestión de precios de productos del sitio de Temu EE. UU., reenviada a través de la puerta de enlace LinkFox a la interfaz de precios del socio EE. UU.: consulta de lista de pedidos de precios (bg.local.goods.priceorder.query), precio base de SKU de modificación por lotes (bg.local.goods.priceorder.change.sku.price), precio de suministro recomendado/estimación de precio base, etc. precio, consulta de precio recomendado, recomendación de precio base, se activa. Utilice linkfox-temu-manage-product-us para la gestión de productos; linkfox-temu-order-us para pedidos; linkfox-temu-add-product-us para la publicación de productos.
