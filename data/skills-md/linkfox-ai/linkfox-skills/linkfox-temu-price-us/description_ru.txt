API управления ценами на продукты на сайте Temu в США, пересылаемый через шлюз LinkFox в интерфейс цен партнеров в США: запрос списка заказа цен (bg.local.goods.priceorder.query), пакетное изменение базовой цены SKU (bg.local.goods.priceorder.change.sku.price), рекомендуемая цена поставки/оценка базовой цены и т. д. Когда пользователи упоминают цену Temu в США, порядок цен, запрос заказа цены, PriceAuditList, изменение цены поставки, изменение цены партии, изменение заказа цены цена товара, запрос рекомендованной цены, рекомендация базовой цены, он срабатывает. Используйте linkfox-temu-manage-product-us для управления продуктами; ссылкаfox-temu-order-us для заказов; linkfox-temu-add-product-us для публикации продукта.
