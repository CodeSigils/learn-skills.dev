Image recognition and analysis based on multimodal AI. This skill is triggered when the user wants to analyze, describe, or extract information from an image URL, image recognition, image analysis, image description, image content understanding, OCR text recognition, or visual Q&A. It is also triggered when the user mentions image recognition, image analysis, image description, recognizing image content, analyzing product images, reading text from images, describing images, extracting visual content, or understanding photo content. When the user provides an image URL and asks about its visual content, the skill should be triggered even if they do not explicitly say “image recognition.”
