Basado en IA multimodal para reconocimiento y análisis de imágenes. Esta capacidad se activa cuando un usuario desea analizar, describir o extraer información de la URL de una imagen, así como cuando menciona el reconocimiento de imágenes, el análisis de imágenes, la descripción de imágenes, la comprensión del contenido de las imágenes, el reconocimiento de texto OCR o las preguntas y respuestas visuales. También se activa cuando el usuario hace referencia al reconocimiento de imágenes, análisis de imágenes, descripción de imágenes, reconocimiento de contenido de imágenes, análisis de imágenes de productos, lectura de texto de imágenes, descripción de imágenes, extracción de contenido visual o comprensión del contenido fotográfico. Cuando un usuario proporciona la URL de una imagen y pregunta sobre su contenido visual, la capacidad debe activarse incluso si no dice explícitamente "reconocimiento de imagen".
