أداة لإنشاء الصور وتحريرها تعتمد على الذكاء الاصطناعي لإنشاء صور منتج عالية الجودة. يتم تشغيل هذه المهارة عندما يطلب المستخدم إنشاء صور، أو إنشاء صور، أو تحرير الصور، أو تحويل النص إلى صورة، أو صورة إلى صورة، أو استبدال الخلفيات، أو تغيير الأنماط، أو استبدال الكائنات في صورة، أو تركيب المنتجات في مشاهد، أو تبديل النماذج، أو إنتاج أي نوع من المحتوى المرئي الذي تم إنشاؤه بواسطة الذكاء الاصطناعي، أو رسم الذكاء الاصطناعي، أو إنشاء الصور، أو تحويل النص إلى صورة، أو صورة إلى صورة، أو استبدال الخلفية، أو نقل النمط، أو إنشاء صورة المنتج، أو تحرير صور الذكاء الاصطناعي. حتى لو لم يذكر المستخدم صراحةً "صورة الذكاء الاصطناعي"، طالما أن الطلب يتضمن إنشاء صورة أو تعديلها أو تحويلها، فيجب تفعيل هذه المهارة.
