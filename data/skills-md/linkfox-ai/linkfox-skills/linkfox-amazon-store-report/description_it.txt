Capacità di automazione dei report del negozio Amazon, che supporta il recupero automatico dell'intero processo di oltre 95 tipi di report come report sull'inventario, report sugli ordini, report sul traffico delle vendite, report FBA, report sui regolamenti finanziari, ecc. (richiesta → polling → download → decomprimi); al termine, avvia automaticamente un servizio HTTP locale di breve durata, generando un extractFileHttpUrl affinché i browser possano scaricare i file estratti. Questa competenza dipende da linkfox‑amazon‑store‑auth (autorizzazione e gestione dei token). Quando l'utente menziona l'estrazione di report Amazon, il download di report Amazon, il recupero di report sull'inventario, il recupero di report sugli ordini, report di Logistica di Amazon, report sul traffico di vendita, report di liquidazione, report di Brand Analytics, report su parole chiave ABA, pull report di Amazon, download di report Amazon, recupero di report di inventario, recupero di report sugli ordini, report di FBA, report sulle vendite e sul traffico, report di liquidazione, report del negozio Amazon, l'abilità viene attivata. Anche qualsiasi richiesta che implichi l'estrazione di qualsiasi forma di dati strutturati dal backend del venditore Amazon (inventario, ordini, vendite, finanza, resi, ecc.) dovrebbe attivare questa abilità.
