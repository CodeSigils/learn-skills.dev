Amazon store report automation retrieval skill, supporting full‑process automatic acquisition of over 95 report types—including inventory reports, order reports, sales traffic reports, FBA reports, and financial settlement reports (request → poll → download → unzip); upon completion it automatically starts a short‑lived local HTTP service, generating an extractedFileHttpUrl for the browser to download the unzipped files. This skill depends on linkfox-amazon-store-auth (authorization and token management). When a user mentions pulling Amazon reports, downloading Amazon reports, fetching inventory reports, fetching order reports, FBA reports, sales traffic reports, financial settlement reports, Brand Analytics reports, ABA search term reports, pull Amazon report, download Amazon report, fetch inventory report, fetch orders report, FBA report, sales and traffic report, settlement report, Amazon store report, this skill is triggered. Any request that involves pulling any form of structured data (inventory, orders, sales, financial, returns, etc.) from the Amazon seller backend should also trigger this skill.
