Fähigkeit zum automatisierten Abrufen von Amazon-Store-Berichten, die die automatische Erfassung von über 95 Berichtstypen im gesamten Prozess unterstützt – einschließlich Bestandsberichten, Bestellberichten, Verkaufsverkehrsberichten, FBA-Berichten und Finanzabrechnungsberichten (Anfrage→Umfrage→Download→Entpacken); Nach Abschluss wird automatisch ein kurzlebiger lokaler HTTP-Dienst gestartet, der eine extrahierteFileHttpUrl für den Browser generiert, um die entpackten Dateien herunterzuladen. Dieser Skill ist abhängig von linkfox-amazon-store-auth (Autorisierung und Token-Verwaltung). Wenn ein Benutzer das Abrufen von Amazon-Berichten, das Herunterladen von Amazon-Berichten, das Abrufen von Bestandsberichten, das Abrufen von Bestellberichten, FBA-Berichte, Verkaufsverkehrsberichte, Finanzabrechnungsberichte, Brand Analytics-Berichte, ABA-Suchbegriffsberichte, das Abrufen von Amazon-Berichten, das Herunterladen von Amazon-Berichten, das Abrufen von Lagerbestandsberichten, das Abrufen von Bestellungen, den Versand durch Amazon-Bericht, Verkaufs- und Verkehrsberichte, Abrechnungsberichte und Amazon-Shop-Berichte erwähnt, wird dieser Skill ausgelöst. Jede Anfrage, bei der strukturierte Daten jeglicher Art (Bestand, Bestellungen, Verkäufe, Finanzen, Retouren usw.) aus dem Amazon-Verkäufer-Backend abgerufen werden, sollte diese Fähigkeit ebenfalls auslösen.
