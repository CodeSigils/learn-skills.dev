API продвижения электронной коммерции Temu в США, пересылаемый через шлюз LinkFox партнеру по продвижению в США / интерфейсам bg/temu, связанным с продвижением (создание активности, регистрация, запрос, купоны/мгновенные продажи и т. д.; интерфейсы будут интегрированы один за другим в соответствии с документацией партнера). Активируется, когда пользователь упоминает рекламную акцию Temu в США, рекламную деятельность, купон, флэш-распродажу, регистрацию активности, рекламную кампанию, продвижение ассортимента продукции и т. д. Используйте linkfox-temu-manage-product-us для управления продуктами; linkfox‑temu‑price‑us для определения цен; и linkfox‑temu‑order‑us для заказов.
