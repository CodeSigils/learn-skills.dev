API de promotion e-commerce Temu US, transmise via la passerelle LinkFox vers les interfaces bg/temu liées à la promotion US du partenaire (création d'activité, inscription, requête, coupons/ventes flash, etc. ; les interfaces seront intégrées une à une selon la documentation du partenaire). Déclenchez lorsque l'utilisateur mentionne la promotion Temu US, l'activité promotionnelle, le coupon, la vente flash, l'enregistrement d'une activité, la campagne promotionnelle, la promotion de l'inventaire de produits, etc. Utilisez linkfox‑temu‑manage‑product‑us pour la gestion des produits ; linkfox‑temu‑price‑us pour les tarifs ; et linkfox‑temu‑order‑us pour les commandes.
