API de promoción de comercio electrónico de Temu EE. UU., reenviada a través de la puerta de enlace de LinkFox a las interfaces bg/temu relacionadas con la promoción del socio EE. UU. (creación de actividades, registro, consulta, cupones/ventas flash, etc.; las interfaces se integrarán una por una de acuerdo con la documentación del socio). Se activa cuando el usuario menciona la promoción de Temu EE. UU., actividad de promoción, cupón, venta flash, registro de actividad, campaña de promoción, promoción de inventario de productos, etc. Utilice linkfox-temu-manage-product-us para la gestión de productos; linkfox-temu-price-us para conocer los precios; y linkfox‑temu‑order‑us para pedidos.
