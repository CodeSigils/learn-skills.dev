Получите данные о спецификации (описании) патента через платформу патентных данных Eureka. Этот навык активируется, когда пользователь упоминает описание патента, полный текст патента, техническое описание патента, подробности вариантов осуществления патента, данные спецификации Eureka, спецификацию патента, полный текст патента, техническое описание, детали варианта реализации, Eureka, подробное описание патента или данные описания патента. Даже если пользователь не говорит явно «Эврика», пока ему необходимо просмотреть полную спецификацию/описание одного или нескольких патентов, этот навык должен быть активирован.
