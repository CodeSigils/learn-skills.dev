Obtenez des données de spécification (description) de brevet via la plateforme de données de brevet Eureka. Cette compétence est déclenchée lorsque l'utilisateur mentionne la description du brevet, le texte intégral du brevet, la description technique du brevet, les détails des modes de réalisation du brevet, les données de la spécification Eureka, la description du brevet, le texte intégral du brevet, la description technique, les détails du mode de réalisation, Eureka, la description détaillée du brevet ou les données de description du brevet. Même si l'utilisateur ne dit pas explicitement « Eureka », tant qu'il a besoin de visualiser le contenu complet de la spécification/description d'un ou plusieurs brevets, cette compétence doit être déclenchée.
