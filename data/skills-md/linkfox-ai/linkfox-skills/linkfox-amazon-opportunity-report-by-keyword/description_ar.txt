ابحث في تقارير رؤى أعمال أمازون حسب الكلمة الرئيسية، والتي تغطي التحليل الشامل للذكاء الاصطناعي عبر ستة أبعاد: إمكانات السوق، وميزات المنتج، ومراجعات المستخدمين، وملفات تعريف العملاء، واتجاهات البحث، وتحليل الأسعار. يتم تشغيل هذه المهارة عندما يذكر المستخدم رؤية أعمال أمازون، أو تقرير رؤية السوق، أو تقرير اختيار المنتج، أو تحليل فرص السوق، أو المشهد التنافسي، أو ملف تعريف المستهلك، أو تحليل الأسعار، أو أبحاث السوق المتخصصة، أو تقرير فرصة أمازون، أو رؤية السوق، أو رؤية الأعمال، أو إمكانات السوق، أو المشهد التنافسي، أو سلوك المستهلك، أو تحليل الأسعار، أو تقرير اختيار المنتج، أو التحليل المتخصص. حتى لو لم يذكر المستخدم صراحةً "رؤية الأعمال"، طالما أن الطلب يتضمن تقييمًا شاملاً لفرص السوق أو إنشاء تقرير شامل لكلمة رئيسية محددة على موقع أمازون، فيجب تفعيل هذه المهارة.
