احصل على بيانات (وصف) مواصفات براءة الاختراع من قاعدة بيانات براءات الاختراع PatSnap (智慧芽) باستخدام معرف براءة الاختراع أو رقم النشر. يتم تشغيل هذه المهارة عندما يذكر المستخدم مواصفات براءة الاختراع، أو النص الكامل لبراءة الاختراع، أو الوصف الفني لبراءة الاختراع، أو تفاصيل تجسيدات براءات الاختراع، أو بيانات مواصفات PatSnap، أو مواصفات براءة الاختراع، أو النص الكامل لبراءة الاختراع، أو الوصف الفني، أو تفاصيل التجسيد، أو PatSnap، أو الوصف التفصيلي لبراءة الاختراع. حتى لو لم يذكر المستخدم "PatSnap" صراحةً، طالما أنه يحتاج إلى عرض المواصفات/الوصف الكامل لواحدة أو أكثر من براءات الاختراع، فيجب تفعيل هذه المهارة.
