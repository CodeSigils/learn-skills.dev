Orientación sobre la cuenta y el entorno de LinkFox. Dos puntos de entrada: (1) Cuando LINKFOX_AGENT_API_KEY/LINKFOXAGENT_API_KEY no están configurados, o cualquier habilidad linkfox-* devuelve errcode=401/error autorizado, guía al usuario para configurar la clave: admite el registro con script (número de teléfono → código de verificación → obtener clave automáticamente); (2) Cuando cualquier habilidad de linkfox-* devuelve un error de facturación insuficiente (código de error = 402 o el mensaje contiene "saldo de puntos insuficiente/facturación insuficiente/saldo insuficiente/cuota excedida/saldo insuficiente/paquete caducado/necesidad de recargar/recargue"), active el proceso de recarga: enumere los paquetes → el usuario selecciona un paquete (validación) → elija el método de pago (WeChat/Alipay, validación) → llame a la API de creación de pedidos para generar un código QR de pago → visualización de tres vías (PNG/link/ASCII) → consulta opcional del estado del pedido. Se activa cuando el usuario dice "no hay clave configurada", "falló la autenticación", "puntos insuficientes", "saldo insuficiente", "recarga", "recarga", "paquete de actualización", "registro" o "registro de teléfono".
