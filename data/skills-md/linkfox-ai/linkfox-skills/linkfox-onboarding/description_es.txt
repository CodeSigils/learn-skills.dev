Orientación sobre la cuenta y el entorno de LinkFox. Dos puntos de entrada: (1) Cuando LINKFOX_AGENT_API_KEY y LINKFOXAGENT_API_KEY no están configurados, o cualquier habilidad de linkfox‑* devuelve errcode=401 o un error de autorización, guía al usuario para configurar la clave, lo que admite el registro mediante script (número de teléfono → código de verificación → obtener clave automáticamente); (2) Cuando cualquier habilidad de linkfox‑* devuelve un error de facturación insuficiente (código de error=402 o el mensaje contiene “saldo de puntos insuficiente”, “facturación insuficiente”, “saldo insuficiente”, “cuota excedida”, “saldo insuficiente”, “paquete vencido”, “necesita recarga”, “recargue”), active un proceso de recarga: enumere los paquetes → el usuario selecciona un paquete (validación) → elija el método de pago (WeChat/Alipay, validación) → llamar a la API de creación de pedidos para generar un código QR de pago → mostrar en tres formas (PNG, enlace, ASCII) → consulta opcional del estado del pedido. El flujo se activa cuando el usuario dice "no hay clave configurada", "falló la autenticación", "puntos insuficientes", "saldo insuficiente", "recarga", "paquete de actualización", "registro" o "registro telefónico".
