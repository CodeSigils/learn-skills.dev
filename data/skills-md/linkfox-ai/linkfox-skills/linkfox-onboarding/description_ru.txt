Руководство по учетной записи LinkFox и среде. Две точки входа: (1) Когда оба LINKFOX_AGENT_API_KEY и LINKFOXAGENT_API_KEY не настроены или какой-либо навык linkfox‑* возвращает код ошибки = 401 или возникает ошибка авторизации, предложите пользователю настроить ключ — поддержка регистрации по сценарию (номер телефона → код проверки → автоматическое получение ключа); (2) Когда какой-либо навык linkfox‑* возвращает ошибку недостаточности выставления счета (код ошибки = 402 или сообщение содержит «недостаточный баланс баллов», «недостаточный баланс», «недостаточный баланс», «превышена квота», «недостаточный баланс», «истёк срок действия пакета», «необходимо пополнить счет», «пожалуйста, пополните баланс»), инициируйте процесс пополнения: список пакетов → пользователь выбирает пакет (проверка) → выберите способ оплаты (WeChat/Alipay, проверка) → вызов API создания заказа для генерации платежного QR-кода → отображение в трех формах (PNG, ссылка, ASCII) → дополнительный запрос статуса заказа. Поток запускается, когда пользователь говорит: «ключ не настроен», «не удалось выполнить аутентификацию», «недостаточно баллов», «недостаточный баланс», «пополнение счета», «пакет обновления», «регистрация» или «регистрация телефона».
