Compte LinkFox et conseils en matière d'environnement. Deux points d'entrée : (1) Lorsque LINKFOX_AGENT_API_KEY et LINKFOXAGENT_API_KEY ne sont pas définis, ou qu'une compétence linkfox‑* renvoie errcode=401 ou une erreur d'autorisation, guidez l'utilisateur pour configurer la clé, prenant en charge l'enregistrement par script (numéro de téléphone → code de vérification → obtention automatique de la clé) ; (2) Lorsqu'une compétence Linkfox‑* renvoie une erreur de facturation insuffisante (errcode = 402 ou que le message contient « solde de points insuffisant », « facturation insuffisante », « solde insuffisant », « quota dépassé », « solde insuffisant », « colis expiré », « doit être rechargé », « veuillez recharger »), déclenchez un processus de recharge : liste des forfaits → l'utilisateur sélectionne un forfait (validation) → choisit le mode de paiement (WeChat/Alipay, validation) → appelle l'API de création de commande pour générer un QR code de paiement → affichage sous trois formes (PNG, lien, ASCII) → requête optionnelle sur l'état de la commande. Le flux est déclenché lorsque l'utilisateur dit « aucune clé configurée », « échec de l'authentification », « points insuffisants », « solde insuffisant », « recharge », « package de mise à niveau », « s'inscrire » ou « enregistrement du téléphone ».
