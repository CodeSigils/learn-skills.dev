Compte LinkFox et guide de l'environnement. Il existe deux points d'entrée : (1) Si LINKFOX_AGENT_API_KEY et LINKFOXAGENT_API_KEY ne sont pas définis, ou si une compétence linkfox-* renvoie errcode=401/authorization error, guidez l'utilisateur pour configurer la clé – prise en charge de l'enregistrement par script (numéro de téléphone → code de vérification → obtention automatique de la clé) ; (2) Si une compétence linkfox-* renvoie une erreur de facturation insuffisante (errcode=402 ou le message contient « solde de points insuffisant/facturation insuffisante/solde insuffisant/quota dépassé/solde insuffisant/paquet expiré/besoin de recharger/veuillez recharger »), déclenchez un processus de recharge : lister les forfaits → l'utilisateur sélectionne un forfait (validation) → choisir le mode de paiement (WeChat/Alipay, validation) → appeler l'API de création de commande pour générer un code QR de paiement → afficher via trois canaux (PNG/lien/ASCII) → requête facultative sur l'état de la commande. Ce flux est activé lorsque l'utilisateur dit « aucune clé configurée », « échec de l'authentification », « points insuffisants », « solde insuffisant », « recharge », « package de mise à niveau », « s'inscrire » ou « enregistrement du téléphone ».
