LinkFox アカウントと環境ガイド。 2 つのエントリ ポイント: (1) LINKFOX_AGENT_API_KEY/LINKFOXAGENT_API_KEY の両方が未設定として検出された場合、またはいずれかの linkfox‑* スキルが errcode=401/authorized エラーを返した場合、ユーザーにキーを設定するようガイドします。スクリプトによる登録をサポートします (電話番号 → 確認コード → キーの自動取得)。 (2) linkfox‑* スキルが残高不足エラー (errcode=402、またはメッセージに「ポイント残高不足 / 請求不足 / 残高不足 / 割り当て超過 / 残高不足 / パッケージの期限切れ / 再チャージが必要 / 再チャージしてください」) を返した場合、再チャージプロセスをトリガーします: パッケージの一覧表示 → ユーザーがパッケージを選択 (検証) → 支払い方法 (WeChat/Alipay、検証) を選択 → 電話支払い QR コードを生成する注文作成 API → 3 方向表示 (PNG/リンク/ASCII) → 注文ステータスのオプションのクエリ。ユーザーが「キーが設定されていません」、「認証に失敗しました」、「ポイントが不足しています」、「残高が不足しています」、「リチャージ」、「リチャージ」、「アップグレードパッケージ」、「登録」、「電話登録」と言ったときにトリガーされます。
