LinkFox account and environment guidance. Two entry points: (1) When both LINKFOX_AGENT_API_KEY and LINKFOXAGENT_API_KEY are unset, or any linkfox‑* skill returns errcode = 401 or an authorization error, guide the user to configure the key—supporting scripted registration (phone number → verification code → automatically obtain key); (2) When any linkfox‑* skill returns a billing‑insufficient error (errcode = 402 or the message contains “insufficient points balance,” “billing insufficient,” “insufficient balance,” “quota exceeded,” “insufficient balance,” “package expired,” “needs recharge,” “please recharge”), trigger a recharge process: list packages → user selects a package (validation) → choose payment method (WeChat/Alipay, validation) → call order‑creation API to generate a payment QR code → display in three forms (PNG, link, ASCII) → optional query of order status. The flow is triggered when the user says “no key configured,” “authentication failed,” “insufficient points,” “insufficient balance,” “recharge,” “upgrade package,” “register,” or “phone registration.”
