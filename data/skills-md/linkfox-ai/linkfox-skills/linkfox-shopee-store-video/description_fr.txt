Shopee (虾皮) stocke la vidéo (Vidéo, même série que linkfox-shopee-store-auth), transmise via /shopee/developerProxy au module Shopee Open API Video couvrant les 15 interfaces : get_cover_list, post_video, get_video_list, get_video_detail, edit_video_info, get_overview_performance, get_video_detail_performance, etc. Il est déclenché lorsque l'utilisateur mentionne Shopee vidéo, stocker la vidéo, télécharger la vidéo, post_video, couverture vidéo, effet vidéo, performance vidéo, get_video_list. Même si « vidéo » n'est pas explicitement mentionnée, tant qu'elle implique une publication vidéo ou une analyse des performances d'une boutique Shopee autorisée, elle doit également être déclenchée.
