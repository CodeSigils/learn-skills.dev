Grâce à `_ehunt_etsyCategorySearch` (nom d'affichage MCP « Etsy Category Search »), récupérez les noms de catégorie, les identifiants et les identifiants parents à partir des données de catégorie EHunt Etsy qui ont été synchronisées avec la bibliothèque MCP, pour les identifiants de catégorie utilisés dans le filtrage des produits/magasins. Ceci est déclenché lorsque l'utilisateur mentionne la catégorie EHunt Etsy, l'ID de catégorie Etsy, l'arborescence des catégories Etsy, `_ehunt_etsyCategorySearch`, la recherche de catégorie Etsy, syncEtsyCategory / `_ehunt_syncEtsyCategory` (synchronisation de catégorie Etsy), puis recherche les catégories. Même si l'utilisateur n'écrit pas « EHunt », tant qu'il recherche un identifiant de catégorie par mot-clé dans la bibliothèque de catégories Etsy synchronisée localement, cette compétence doit également être déclenchée.
