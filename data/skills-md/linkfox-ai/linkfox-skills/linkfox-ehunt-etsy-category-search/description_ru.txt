Через `_ehunt_etsyCategorySearch` (отображаемое имя MCP «Поиск категорий Etsy») извлекайте имена категорий, идентификаторы и родительские идентификаторы из данных категорий EHunt Etsy, которые были синхронизированы с библиотекой MCP, для идентификаторов категорий, используемых при фильтрации продуктов/магазинов. Это срабатывает, когда пользователь упоминает категорию EHunt Etsy, идентификатор категории Etsy, дерево категорий Etsy, `_ehunt_etsyCategorySearch`, поиск категорий Etsy, syncEtsyCategory / `_ehunt_syncEtsyCategory` (синхронизация категорий Etsy), а затем ищет категории. Даже если пользователь не пишет «EHunt», пока он ищет идентификатор категории по ключевому слову в локально синхронизированной библиотеке категорий Etsy, этот навык также должен быть активирован.
