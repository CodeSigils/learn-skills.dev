Through `_ehunt_etsyCategorySearch` (MCP display name “Etsy Category Search”) retrieve category names, IDs, and parent IDs from the EHunt Etsy category data that has been synced to the MCP library, for category IDs used in product/store filtering. This is triggered when the user mentions EHunt Etsy category, Etsy category ID, Etsy category tree, `_ehunt_etsyCategorySearch`, Etsy Category Search, syncEtsyCategory / `_ehunt_syncEtsyCategory` (Etsy category sync) and then looks up categories. Even if the user does not write “EHunt”, as long as they search for a category ID by keyword in the locally synced Etsy category library, this skill should also be triggered.
