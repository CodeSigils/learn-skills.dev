Les produits sélectionnés par Shopee (Xiapi) Top Picks (même série que linkfox‑shopee‑store‑auth) sont transmis via /shopee/developerProxy au module Shopee Open API Top Picks, qui comprend les quatre interfaces : get_top_picks_list, add_top_picks, update_top_picks et delete_top_picks. Il est déclenché lorsque l'utilisateur mentionne les produits sélectionnés par Shopee, les meilleurs choix, les sélections de magasins, add_top_picks, top_picks_id ou les recommandations populaires. Même si « sélectionné » n’est pas explicitement mentionné, toute référence à la gestion de la collection Top Picks d’un magasin Shopee agréé devrait également le déclencher.
