PatSnap(智慧芽) 특허 데이터베이스에서 특허 제목과 초록의 번역된 버전을 얻으세요. 이 기능은 사용자가 특허 초록 번역, 특허 제목 번역, 번역된 특허 초록, 다른 언어로 된 특허 콘텐츠, 중국어, 영어 또는 일본어로 된 특허 초록을 요청하거나 특허 ID 또는 출판 번호로 특정 특허의 초록이나 제목을 쿼리해야 하는 경우(예: 특허 초록 번역, 특허 제목 번역, PatSnap, 특허 번역, 초록 조회) 트리거됩니다. "번역"이라는 단어가 명시적으로 사용되지 않은 경우에도 사용자가 PatSnap, 智慧芽 또는 특허 요약 조회를 언급할 때마다 해당 기술이 활성화되어야 합니다.
