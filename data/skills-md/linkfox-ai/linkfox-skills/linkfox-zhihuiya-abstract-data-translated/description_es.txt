Recupere versiones traducidas de títulos de patentes y resúmenes de la base de datos de patentes PatSnap (智慧芽). Esta habilidad se activa cuando un usuario solicita traducción de resúmenes de patentes, traducción de títulos de patentes, un resumen de patentes traducido, contenido de patentes en otros idiomas, resúmenes de patentes en chino/inglés/japonés, o necesita buscar un resumen o título de una patente específica utilizando un ID de patente o número de publicación, así como para consultas que involucran traducción de resúmenes de patentes, traducción de títulos de patentes, PatSnap, traducción de patentes o búsqueda de resúmenes. La habilidad también debe activarse cada vez que el usuario mencione PatSnap, 智慧芽 o la búsqueda de resúmenes de patentes, incluso si "traducción" no se indica explícitamente.
