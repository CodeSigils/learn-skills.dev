استرجع النسخ المترجمة لعناوين وملخصات براءات الاختراع من قاعدة بيانات براءات الاختراع PatSnap (智慧芽). يتم تشغيل هذه الإمكانية عندما يطلب المستخدم ترجمة ملخص براءة اختراع، أو ترجمة عنوان براءة اختراع، أو ملخص براءة اختراع مترجم، أو محتوى براءة اختراع بلغات أخرى، أو ملخصات براءات الاختراع الصينية/الإنجليزية/اليابانية، أو يحتاج إلى البحث عن ملخص أو عنوان براءة اختراع معينة بواسطة معرف براءة الاختراع أو رقم النشر - أي ترجمة ملخص براءة الاختراع، أو ترجمة عنوان براءة الاختراع، أو PatSnap، أو ترجمة براءة الاختراع، أو البحث الملخص. يجب أيضًا تفعيل المهارة عندما يذكر المستخدم PatSnap أو 智慧芽 أو البحث الملخص عن براءات الاختراع، حتى لو لم يذكر "ترجمة" صراحةً.
