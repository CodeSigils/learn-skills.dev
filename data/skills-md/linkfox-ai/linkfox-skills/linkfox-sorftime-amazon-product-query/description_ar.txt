البحث والتصفية متعدد الأبعاد عن منتجات أمازون استنادًا إلى بيانات Sorftime، والتي تغطي 14 موقعًا وتدعم مراجعة اللقطات الشهرية التاريخية. يتم تشغيل هذه المهارة عندما يذكر المستخدم البحث عن منتج Sorftime، أو تصفية منتجات أمازون، أو بحث المنافسين، أو تحليل الفئات، أو العلامات التجارية الأكثر مبيعًا، أو تحليل البائع، أو المنتجات الموسمية، أو مراجعة اللقطات التاريخية، أو البحث عن المنتج، أو المبيعات والإيرادات الشهرية، أو البحث عن منتج الكلمات الرئيسية ABA، أو تصفية النطاق السعري، أو اكتشاف منتج جديد، أو تصفية مجمعة متعددة المعايير، أو البحث عن المنتج، أو بحث المنافسين، أو تحليل الفئة، أو أكثر العلامات التجارية مبيعًا، أو تحليل البائع، أو المنتجات الموسمية، أو لقطة تاريخية. حتى إذا لم يذكر المستخدم "Sorftime" صراحةً، طالما أن طلبه يتضمن البحث عن منتجات أمازون، أو تصفيتها، أو مقارنتها، أو استكشاف المنتج عبر أبعاد الفئة/العلامة التجارية/البائع، فيجب تفعيل هذه المهارة.
