Многомерный поиск и фильтрация продуктов Amazon на основе данных Sorftime, охватывающих 14 сайтов, с поддержкой ежемесячного просмотра исторических снимков. Этот навык срабатывает, когда пользователь упоминает поиск продуктов Sorftime, фильтрацию продуктов Amazon, исследование конкурентов, анализ категорий, бестселлеры брендов, анализ продавцов, сезонные продукты, исторический обзор снимков, поиск продуктов, ежемесячный объем продаж и доход, поиск продуктов по ключевым словам ABA, фильтрацию ценового диапазона, открытие новых продуктов, многокритериальную комбинированную фильтрацию, поиск продуктов, исследование конкурентов, анализ категорий, бестселлеры брендов, анализ продавцов, сезонные продукты, исторический снимок. Даже если пользователь явно не упоминает «Sorftime», если его запрос включает поиск продуктов Amazon, фильтрацию, сравнение или исследование продуктов по категориям/бренду/продавцу, этот навык должен быть активирован.
