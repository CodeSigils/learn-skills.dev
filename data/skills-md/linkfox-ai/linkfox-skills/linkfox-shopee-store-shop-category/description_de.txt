Shopee (Xiaopi) Store-Kategorie Shop-Kategorie (in der gleichen Serie wie linkfox-shopee-store-auth), weitergeleitet über /shopee/developerProxy an das Shopee Open API Shop Category-Modul, das alle sieben Schnittstellen umfasst: add_shop_category, get_shop_category_list, update_shop_category, add_item_list, get_item_list, delete_item_list usw. Wenn ein Benutzer erwähnt Shopee-Store-Kategorie, Shop-Kategorie, benutzerdefinierte Kategorie, add_shop_category, shop_category_id oder Kategorieprodukte, es sollte ausgelöst werden. Auch wenn „Kategorie“ nicht explizit erwähnt wird, sollte dies ebenfalls ausgelöst werden, sofern es sich um die Verwaltung der Shop-Kategorie für einen autorisierten Shopee-Shop handelt.
