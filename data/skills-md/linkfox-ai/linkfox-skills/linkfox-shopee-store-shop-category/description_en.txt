Shopee (Xiaopi) store category Shop Category (in the same series as linkfox-shopee-store-auth), forwarded via /shopee/developerProxy to the Shopee Open API Shop Category module, encompassing all seven interfaces: add_shop_category, get_shop_category_list, update_shop_category, add_item_list, get_item_list, delete_item_list, etc. When a user mentions Shopee store category, Shop Category, custom category, add_shop_category, shop_category_id, or category products, it should be triggered. Even if "category" is not explicitly mentioned, as long as it involves management of Shop Category for an authorized Shopee store, it should also be triggered.
