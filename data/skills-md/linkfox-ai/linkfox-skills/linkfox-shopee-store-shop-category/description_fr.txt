Catégories de magasin Shopee (XiaPi) Catégorie de magasin (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy au module Shopee Open API Shop Category, englobant les sept interfaces : add_shop_category, get_shop_category_list, update_shop_category, add_item_list, get_item_list, delete_item_list, etc. Lorsqu'un utilisateur mentionne les catégories de magasin Shopee, Shop Catégorie, catégories personnalisées, add_shop_category, shop_category_id ou catégorie de produits, cela doit être déclenché. Même si la « catégorie » n'est pas explicitement mentionnée, toute implication dans la gestion de la catégorie de boutique pour un magasin Shopee agréé devrait également se déclencher.
