Catégorie de magasin Shopee (Xiaopi) Catégorie de magasin (dans la même série que linkfox-shopee-store-auth), transmise via /shopee/developerProxy au module Shopee Open API Shop Category, englobant les sept interfaces : add_shop_category, get_shop_category_list, update_shop_category, add_item_list, get_item_list, delete_item_list, etc. Lorsqu'un utilisateur mentionne la catégorie de magasin Shopee, Shop Catégorie, catégorie personnalisée, add_shop_category, shop_category_id ou catégorie produits, cela doit être déclenché. Même si « catégorie » n'est pas explicitement mentionnée, tant qu'elle implique la gestion de la catégorie de boutique pour une boutique Shopee autorisée, elle doit également être déclenchée.
