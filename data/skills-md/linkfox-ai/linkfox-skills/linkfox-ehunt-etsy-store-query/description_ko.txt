EHunt MCP 도구 `_ehunt_storeQuery`(표시 이름 "Etsy Store Query")를 사용하여 Etsy 매장을 다양한 차원(판매량, 즐겨찾기, 리뷰, 매장 개장 날짜, 국가, 주요 카테고리, 호평/별표 표시 등)에 걸쳐 필터링합니다. 사용자가 EHunt Etsy 매장, Etsy 매장 검색, Etsy 판매자, Etsy 매장 순위, Etsy 주간 판매 매장, ehunt 매장, Etsy 매장 쿼리 또는 `_ehunt_storeQuery`를 언급하면 ​​스킬이 트리거됩니다. 사용자가 "EHunt"를 쓰지 않더라도 Etsy에서 매장을 찾거나 매장 데이터를 필터링하거나 매장 성과를 분석하는 한 이 스킬은 트리거되어야 합니다.
