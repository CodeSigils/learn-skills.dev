EHunt MCP 도구 `_ehunt_storeQuery`(표시 이름 "Etsy Store Query")를 사용하여 Etsy 매장을 다양한 차원(판매, 즐겨찾기, 리뷰, 매장 개점 날짜, 국가, 주요 카테고리, 평점/별표 평점 등)에 걸쳐 필터링합니다. 사용자가 Etsy 상점, Etsy 상점 검색, Etsy 판매자, Etsy 상점 순위, Etsy 주간 판매 상점, ehunt 상점, Etsy 상점 쿼리 또는 '_ehunt_storeQuery'를 언급할 때 트리거됩니다. 사용자가 EHunt를 언급하지 않더라도 Etsy에서 상점을 찾고, 상점 데이터를 필터링하거나 상점 성과를 분석하는 한 이 스킬은 트리거되어야 합니다.
