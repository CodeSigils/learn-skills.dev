من خلال أداة EHunt MCP `_ehunt_storeQuery` (اسم العرض "Etsy Store Query")، قم بتصفية متاجر Etsy عبر أبعاد متعددة (المبيعات، المفضلة، المراجعات، تاريخ افتتاح المتجر، البلد، الفئة الرئيسية، تصنيف Raving/النجوم، وما إلى ذلك). يتم تشغيله عندما يذكر المستخدم متجر EHunt Etsy، أو بحث متجر Etsy، أو بائع Etsy، أو تصنيف متجر Etsy، أو متجر مبيعات Etsy الأسبوعي، أو متاجر ehunt، أو استعلام متجر Etsy، أو `_ehunt_storeQuery`. حتى لو لم يكتب المستخدم "EHunt"، طالما أنه يبحث عن متاجر على Etsy، أو يقوم بتصفية بيانات المتجر، أو تحليل أداء المتجر، فيجب تفعيل هذه المهارة.
