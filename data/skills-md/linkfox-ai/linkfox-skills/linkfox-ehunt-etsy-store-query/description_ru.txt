С помощью инструмента EHunt MCP `_ehunt_storeQuery` (отображаемое имя «Запрос магазина Etsy») фильтруйте магазины Etsy по нескольким параметрам (продажи, избранное, обзоры, дата открытия магазина, страна, основная категория, рейтинг / рейтинг звезд и т. д.). Запускается, когда пользователь упоминает магазин EHunt Etsy, поиск магазина Etsy, продавца Etsy, рейтинг магазина Etsy, магазин еженедельных продаж Etsy, магазины ehunt, запрос магазина Etsy или _ehunt_storeQuery. Даже если пользователь не пишет EHunt, пока он ищет магазины на Etsy, фильтрует данные магазинов или анализирует эффективность магазинов, этот навык должен сработать.
