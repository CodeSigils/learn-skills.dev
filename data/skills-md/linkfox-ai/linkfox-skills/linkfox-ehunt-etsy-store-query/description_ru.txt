Используйте инструмент EHunt MCP `_ehunt_storeQuery` (отображаемое имя «Запрос магазина Etsy») для фильтрации магазинов Etsy по нескольким параметрам (продажи, избранное, обзоры, дата открытия магазина, страна, основная категория, рейтинг / рейтинг звезд и т. д.). Срабатывает, когда пользователь упоминает магазин EHunt Etsy, поиск магазинов Etsy, продавца Etsy, рейтинг магазинов Etsy, магазин еженедельных продаж Etsy, магазины охоты, запрос магазина Etsy или `_ehunt_storeQuery`. Даже если пользователь не упоминает EHunt, пока он ищет магазины на Etsy, фильтрует данные о магазинах или анализирует эффективность магазинов, этот навык должен быть активирован.
