Shopee store orders (in the same series as linkfox‑shopee‑store‑auth), forwarded through /shopee/developerProxy, include all 22 interfaces of the Shopee Open API Order module: get_order_list, get_order_detail, get_shipment_list, search_package_list, cancel_order, ship, and related booking/invoice/FBS functions. Trigger when the user mentions Shopee orders, Shopee order list, order details, packages, split orders, order cancellation, buyer cancellation, order remarks, booking, FBS invoices, order_sn, READY_TO_SHIP, or Shopee order processing. Even if “order” is not explicitly mentioned, any query or processing of orders from an authorized Shopee store should also trigger.
