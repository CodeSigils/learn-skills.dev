Shopee (虾皮) store orders (in the same series as linkfox-shopee-store-auth) are forwarded through /shopee/developerProxy to all 22 Shopee Open API Order module interfaces: get_order_list, get_order_detail, get_shipment_list, search_package_list, cancel_order, ship, and related booking/invoice/FBS functions. When a user mentions Shopee orders, Shopee order lists, order details, packages, split orders, order cancellations, buyer cancellations, order notes, booking, FBS invoices, order_sn, READY_TO_SHIP, or Shopee order processing, it should be triggered. Even if "order" is not explicitly referenced, any query or handling of orders from an authorized Shopee store should also trigger.
