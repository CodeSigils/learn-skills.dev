تتضمن طلبات متجر Shopee (في نفس السلسلة مثل linkfox‑shopee‑store‑auth)، التي يتم توجيهها من خلال /shopee/developerProxy، جميع الواجهات الـ 22 لوحدة طلب Shopee Open API: get_order_list، get_order_detail، get_shipment_list، search_package_list، Cancel_order، ship، ووظائف الحجز/الفاتورة/FBS ذات الصلة. يتم تشغيله عندما يذكر المستخدم طلبات Shopee، أو قائمة طلبات Shopee، أو تفاصيل الطلب، أو الحزم، أو الطلبات المقسمة، أو إلغاء الطلب، أو إلغاء المشتري، أو ملاحظات الطلب، أو الحجز، أو فواتير FBS، أو order_sn، أو READY_TO_SHIP، أو معالجة طلب Shopee. حتى لو لم يتم ذكر "الطلب" صراحة، فإن أي استفسار أو معالجة للطلبات من متجر Shopee معتمد يجب أن يتم تشغيله أيضًا.
