طلبات متجر Shopee (虾皮) (في نفس السلسلة مثل linkfox-shopee-store-auth)، يتم توجيهها عبر /shopee/developerProxy إلى جميع واجهات وحدة طلب Shopee Open API البالغ عددها 22: get_order_list، get_order_detail، get_shipment_list، search_package_list، Cancel_order، ship، ووظائف الحجز/الفاتورة/FBS ذات الصلة. عندما يذكر المستخدم طلبات Shopee، أو قائمة طلبات Shopee، أو تفاصيل الطلب، أو الحزم، أو الطلبات المقسمة، أو إلغاء الطلب، أو إلغاء المشتري، أو ملاحظات الطلب، أو الحجز، أو فواتير FBS، أو order_sn، أو READY_TO_SHIP، أو معالجة طلب Shopee، فيجب تشغيله. حتى لو لم يتم ذكر "الطلب" بشكل صريح، فإن أي استفسار أو معالجة طلبات لمتجر Shopee معتمد يجب أن يؤدي أيضًا إلى تشغيله.
