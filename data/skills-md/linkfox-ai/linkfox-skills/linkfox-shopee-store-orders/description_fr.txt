Les commandes des magasins Shopee (de la même série que linkfox‑shopee‑store‑auth), transmises via /shopee/developerProxy, incluent les 22 interfaces du module de commande Shopee Open API : get_order_list, get_order_detail, get_shipment_list, search_package_list, Cancel_order, Ship et les fonctions de réservation/facture/FBS associées. Déclenchez lorsque l'utilisateur mentionne les commandes Shopee, la liste des commandes Shopee, les détails de la commande, les forfaits, les commandes fractionnées, l'annulation de la commande, l'annulation de l'acheteur, les remarques sur la commande, la réservation, les factures FBS, order_sn, READY_TO_SHIP ou le traitement des commandes Shopee. Même si « commande » n'est pas explicitement mentionnée, toute requête ou traitement de commandes provenant d'un magasin Shopee agréé devrait également se déclencher.
