احصل على نص مترجم لمواصفات (وصف) براءة الاختراع من خلال منصة بيانات براءات الاختراع Eureka. يتم تشغيل هذه الإمكانية عندما يطلب المستخدم ترجمة مواصفات براءة اختراع، أو نص براءة اختراع كامل بلغة أخرى، أو نص براءة اختراع كامل مترجم، أو يريد عرض مواصفات براءة الاختراع باللغة الصينية أو الإنجليزية أو اليابانية، بالإضافة إلى مواصفات براءة اختراع Eureka، أو ترجمة مواصفات براءة الاختراع، أو ترجمة وصف براءة الاختراع، أو براءة اختراع Eureka، أو ترجمة براءات الاختراع. ويجب أن يتم تشغيله أيضًا عندما يقدم المستخدم معرف براءة اختراع أو رقم منشور ويطلب محتوى المواصفات/الوصف بلغة أخرى، أو يذكر نوايا مثل "ترجمة مواصفات براءة الاختراع" أو "ترجمة الوصف" أو "ترجمة النص الكامل" أو ما شابه ذلك.
