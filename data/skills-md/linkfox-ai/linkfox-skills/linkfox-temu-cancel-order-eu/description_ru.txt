API отмены заказа на сайте Temu Europe (комбинированный покупатель+продавец), пересылаемый через шлюз LinkFox партнеру из ЕС: отмена послепродажного обслуживания покупателя (bg.aftersales.cancel.*), апелляция продавца/отмена отсутствия на складе (temu.order.cancel.*) и т. д. Активируется, когда пользователь упоминает отмену заказа Temu EU, отмену покупателя европейского сайта, отмену отсутствия у продавца, afterSalesStatusGroup, applySn, site=eu заказ-доставка. Для заказов используйте ссылкуfox-temu-order-eu; используйте linkfox-temu-cancel-order-us для сайта в США; используйте linkfox-temu-cancel-order-global для глобального сайта.
