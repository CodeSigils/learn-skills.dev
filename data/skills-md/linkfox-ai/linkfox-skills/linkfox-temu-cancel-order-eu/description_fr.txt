API d'annulation de commande du site Temu Europe (acheteur + vendeur combinés), transmise via la passerelle LinkFox au partenaire EU : annulation après-vente de l'acheteur (bg.aftersales.cancel.*), appel du vendeur/annulation de rupture de stock (temu.order.cancel.*), etc. Déclenchée lorsque l'utilisateur mentionne l'annulation de commande Temu EU, l'annulation de l'acheteur du site Europe, l'annulation de rupture de stock du vendeur, afterSalesStatusGroup, applySn, site=eu order‑shipping. Utilisez linkfox‑temu‑order‑eu pour les commandes ; linkfox‑temu‑cancel‑order‑us pour le site américain ; linkfox‑temu‑cancel‑order‑global pour le site mondial.
