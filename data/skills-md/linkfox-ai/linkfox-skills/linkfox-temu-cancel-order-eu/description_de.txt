API für die Auftragsstornierung auf der Website von Temu Europe (Käufer + Verkäufer kombiniert), weitergeleitet über das LinkFox-Gateway an Partner EU: After-Sales-Stornierung des Käufers (bg.aftersales.cancel.*), Beschwerde des Verkäufers/Stornierung von nicht vorrätigen Bestellungen (temu.order.cancel.*) usw. Wird ausgelöst, wenn der Benutzer die Stornierung einer Bestellung von Temu EU, die Stornierung von Käufern auf der Website von Europa, die Stornierung von nicht vorrätigen Verkäufern, afterSalesStatusGroup, applySn, site=eu order-shipping erwähnt. Benutzen Sie für Bestellungen linkfox-temu-order-eu; Verwenden Sie linkfox-temu-cancel-order-us für die US-Site; Verwenden Sie linkfox-temu-cancel-order-global für die globale Site.
