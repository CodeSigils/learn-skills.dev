API für die Auftragsstornierung auf der Website von Temu Europe (Käufer + Verkäufer zusammen), weitergeleitet über das LinkFox-Gateway an den Partner EU: umfasst die Stornierung des Käufers nach dem Verkauf (bg.aftersales.cancel.*), Einspruch des Verkäufers/Stornierung von Nichtvorräten (temu.order.cancel.*) usw. Sie wird ausgelöst, wenn der Benutzer die Stornierung einer Bestellung von Temu EU, die Stornierung von Käufern auf der Website von Europa, die Stornierung von Nichtvorräten des Verkäufers, afterSalesStatusGroup, applySn, site=eu order‑shipping erwähnt. Benutzen Sie für Bestellungen linkfox-temu-order-eu; Verwenden Sie linkfox-temu-cancel-order-us für die US-Site; Verwenden Sie linkfox-temu-cancel-order-global für die globale Site.
