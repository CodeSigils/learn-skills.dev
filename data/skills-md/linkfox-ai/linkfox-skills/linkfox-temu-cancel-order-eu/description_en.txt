Temu Europe site order cancellation API (buyer + seller combined), forwarded through the LinkFox gateway to Partner EU: buyer after‑sales cancellation (bg.aftersales.cancel.*), seller appeal/out‑of‑stock cancellation (temu.order.cancel.*), etc. Triggered when the user mentions Temu EU order cancellation, Europe site buyer cancellation, seller out‑of‑stock cancellation, afterSalesStatusGroup, applySn, site=eu order‑shipping. Use linkfox-temu-order-eu for orders; use linkfox-temu-cancel-order-us for the US site; use linkfox-temu-cancel-order-global for the global site.
