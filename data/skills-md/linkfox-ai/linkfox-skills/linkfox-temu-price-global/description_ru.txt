API цены/цены поставки глобального сайта Temu (за пределами США/ЕС), пересылаемый через шлюз LinkFox с пятью конечными точками (прайс-лист, рекомендуемая цена, прайс-лист поставки SKU, пакетные обновления цен и т. д.), по умолчанию используется site=global. Он срабатывает, когда пользователи обращаются к глобальной цене Temu, прайс-листу глобального сайта, запросу заказа цены, прейскурантной цене SKU, проверке цены поставки SKU, изменению цены поставки, рекомендуемой цене или рекомендуемой базовой цене. Используйте linkfox-temu-price-us для сайта в США, linkfox-temu-price-eu для европейского сайта и linkfox-temu-manage-product-global для управления продуктами.
