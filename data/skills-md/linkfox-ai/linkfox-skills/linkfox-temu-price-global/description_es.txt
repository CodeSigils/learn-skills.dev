API de precio/precio de suministro del sitio Temu Global (fuera de EE. UU./UE), reenviada a través de la puerta de enlace LinkFox con cinco puntos finales (lista de precios, precio recomendado, lista de precios de suministro de SKU, actualizaciones de precios por lotes, etc.), de forma predeterminada sitio = global. Se activa cuando los usuarios consultan el precio global de Temu, la lista de precios del sitio global, la consulta de orden de precio, el precio de lista de SKU, la verificación del precio de suministro de SKU, el cambio del precio de suministro, el precio recomendado o el precio base recomendado. Utilice linkfox‑temu‑price‑us para el sitio de EE. UU., linkfox‑temu‑price‑eu para el sitio europeo y linkfox‑temu‑manage‑product‑global para la gestión de productos.
