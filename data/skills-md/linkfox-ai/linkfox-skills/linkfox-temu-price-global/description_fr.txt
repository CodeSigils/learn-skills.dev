API de prix/prix de fourniture du site Temu Global (hors États-Unis/UE), transmise via la passerelle LinkFox avec cinq points de terminaison (liste de prix, prix recommandé, liste de prix de fourniture SKU, mises à jour de prix par lots, etc.), par défaut sur site=global. Il est déclenché lorsque l'utilisateur mentionne le prix Temu Global, la liste de prix du site mondial, la requête de commande de prix, le prix catalogue SKU, la vérification du prix d'approvisionnement SKU, la modification du prix d'approvisionnement, le prix recommandé ou la recommandation de prix de base. Utilisez linkfox-temu-price-us pour le site américain, linkfox-temu-price-eu pour le site européen et linkfox-temu-manage-product-global pour la gestion des produits.
