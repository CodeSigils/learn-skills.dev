PatSnap에서 번역된 특허 사양(설명) 텍스트를 받으세요. 이 기능은 사용자가 특허 사양 번역, 다른 언어로 된 전체 특허 텍스트, 번역된 전체 특허 텍스트를 요청하거나 특허 사양 번역, 특허 설명 번역, PatSnap 또는 특허 번역뿐만 아니라 중국어, 영어 또는 일본어 버전으로 특허 사양을 보기를 원할 때 트리거됩니다. 또한 사용자가 특허 ID 또는 출판 번호를 제공하고 사양/설명 콘텐츠를 다른 언어로 요청하거나 '특허 사양 번역', '설명 번역', '전체 텍스트 번역' 또는 유사한 의도와 같은 문구를 언급하는 경우에도 트리거되어야 합니다.
