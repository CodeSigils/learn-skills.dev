Erhalten Sie den übersetzten Text der Patentspezifikation (Beschreibung) von PatSnap. Diese Funktion wird ausgelöst, wenn ein Benutzer eine Patentspezifikationsübersetzung, einen vollständigen Patenttext in einer anderen Sprache oder einen übersetzten vollständigen Patenttext anfordert oder die Patentspezifikation in chinesischen, englischen oder japanischen Versionen sowie eine Patentspezifikationsübersetzung, eine Patentbeschreibungsübersetzung, PatSnap oder eine Patentübersetzung anzeigen möchte. Es sollte auch ausgelöst werden, wenn ein Benutzer eine Patent-ID oder Veröffentlichungsnummer angibt und nach dem Spezifikations-/Beschreibungsinhalt in einer anderen Sprache fragt oder Ausdrücke wie „Übersetzung der Patentspezifikation“, „Übersetzung der Beschreibung“, „Volltextübersetzung“ oder ähnliche Absichten erwähnt.
