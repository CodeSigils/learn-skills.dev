Shopee (Xia Pi) stocke les retours et les remboursements (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy l'ensemble des 15 interfaces du module Shopee Open API Returns : get_return_list, get_return_detail, confirm, contest, offer, accept_offer, upload_proof, get_reverse_tracking_info, etc. Lorsqu'un utilisateur mentionne le retour, le remboursement de Shopee, return_sn, liste de retour, confirmation de retour, litige de retour, litige ou logistique inverse, cela se déclenche. Même si « retour » n'est pas explicitement mentionné, toute requête ou traitement lié aux retours/remboursements pour une boutique Shopee agréée devrait également se déclencher.
