Retours et remboursements de la boutique Shopee (de la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy, couvrant les 15 interfaces du module de retours Shopee Open API : get_return_list, get_return_detail, confirm, contest, offer, accept_offer, upload_proof, get_reverse_tracking_info, etc. Liste de retour, confirmation du retour, litige de retour, litige ou logistique inversée. Même si le « retour » n'est pas explicitement mentionné, tant qu'il implique des requêtes ou un traitement de retours/remboursements pour une boutique Shopee agréée, il doit également être déclenché.
