Devoluciones y reembolsos de la tienda Shopee (Xia Pi) (en la misma serie que linkfox-shopee-store-auth), reenviados a través de /shopee/developerProxy el conjunto completo de 15 interfaces del módulo Shopee Open API Returns: get_return_list, get_return_detail, confirm, disputa, oferta, aceptar_oferta, upload_proof, get_reverse_tracking_info, etc. Cuando un usuario menciona Shopee return, refund, return_sn, return Lista, confirmación de devolución, disputa de devolución, disputa o logística inversa, se activa. Incluso si no se menciona explícitamente "devolución", también debería activarse cualquier consulta o procesamiento relacionado con devoluciones/reembolsos para una tienda Shopee autorizada.
