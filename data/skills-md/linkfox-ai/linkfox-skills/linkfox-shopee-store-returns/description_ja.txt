Shopee (虾皮) ストアの返品と返金 (linkfox-shopee-store-auth と同じシリーズ) は、/shopee/developerProxy 経由で転送され、15 の Shopee Open API Returns モジュールのエンドポイントすべてを網羅します: get_return_list、get_return_detail、confirm、dispute、offer、accept_offer、upload_proof、get_reverse_tracking_info など。これは、ユーザーが Shopee の返品について言及するとトリガーされます。返金、return_sn、返品リスト、返品の確認、返品に関する紛争、紛争、またはリバース ロジスティクス。 「返品」が明示的に言及されていない場合でも、正規の Shopee ストアに対する返品/返金のクエリまたは処理によってもそれがトリガーされるはずです。
