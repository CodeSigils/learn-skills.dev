Shopee (Xia Pi) memorizza resi e rimborsi (nella stessa serie di linkfox-shopee-store-auth), inoltrati tramite /shopee/developerProxy l'intero set di 15 interfacce del modulo Shopee Open API Returns: get_return_list, get_return_detail, confirm, dispute, offer, Accept_offer, upload_proof, get_reverse_tracking_info, ecc. Quando un utente menziona Shopee return, rimborso, return_sn, elenco resi, conferma reso, contestazione reso, contestazione o logistica inversa, si attiva. Anche se il "reso" non è menzionato esplicitamente, dovrebbero attivarsi anche qualsiasi richiesta o elaborazione relativa a resi/rimborsi per un negozio Shopee autorizzato.
