Shopee (Xia Pi) store returns and refunds (in the same series as linkfox-shopee-store-auth), forwarded via /shopee/developerProxy to all 15 Shopee Open API Returns module endpoints: get_return_list, get_return_detail, confirm, dispute, offer, accept_offer, upload_proof, get_reverse_tracking_info, etc. It is triggered when the user mentions Shopee returns, refunds, return_sn, return list, confirm return, return dispute, dispute, or reverse logistics. Even if “return” is not explicitly mentioned, as long as it involves a return/refund query or processing for an authorized Shopee store, it should be triggered.
