Consulta los detalles de las citas directas de una patente en la base de datos de patentes de WisdomSeed. Esta habilidad se activa cuando el usuario pregunta sobre citas de patentes, patentes citadas, literatura citada, referencias de patentes, citas posteriores, citas de la técnica anterior, o quiere ver qué patentes, literatura no relacionada con patentes se citaron durante el proceso de solicitud de una patente específica: referencias citadas de patentes, citas posteriores, referencias de patentes, análisis de citas, PatSnap. Cuando el usuario proporciona una identificación de patente o un número de publicación y necesita información de cita, incluso si no dice explícitamente "cita directa", se aplica cualquier solicitud sobre qué referencias cita la patente.
