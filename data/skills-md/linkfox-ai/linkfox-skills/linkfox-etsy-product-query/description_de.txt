Filtern Sie Etsy-Produkte über mehrere Dimensionen hinweg (Schlüsselwörter/URL, Preis, Verkaufsvolumen, Favoriten, Bewertungen, Angebotsdatum, Kategorie, Typ wie handgefertigt/vintage, Tags wie Pick/Bestsell/Raving). Wird ausgelöst, wenn der Benutzer ein Etsy-Produkt, einen Etsy-Eintrag, eine Etsy-Auswahl, einen Etsy-Bestseller, Etsy-Handarbeit, Etsy-Vintage, Etsy-Artikel oder eine Etsy-Produktanfrage erwähnt. Selbst wenn der Benutzer den Namen des Tools nicht erwähnt, sollte dieser Skill ausgelöst werden, solange er auf Etsy nach Produkten sucht, Verkäufe/Preise/Tags anzeigt oder Artikel filtert.
