Shopee 미디어 업로드 MediaSpace(linkfox-shopee-store-auth와 동일한 시리즈)는 /shopee/developerProxy를 통해 Shopee Open API MediaSpace 모듈의 6개 인터페이스(init_video_upload, upload_video_part, Complete_video_upload, get_video_upload_result, cancel_video_upload, upload_image)로 전달됩니다. 사용자가 Shopee 이미지 업로드, 비디오 업로드, media_space, init_video_upload, upload_image, 비디오 청크 업로드 또는 Shopee 이미지 URL 얻기를 언급하면 ​​트리거됩니다. "미디어"가 명시적으로 언급되지 않더라도 승인된 Shopee 스토어에 대한 이미지/동영상 파일 업로드와 관련된 경우에도 트리거되어야 합니다.
