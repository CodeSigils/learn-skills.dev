Shopee media upload MediaSpace (in the same series as linkfox-shopee-store-auth), forwarded through /shopee/developerProxy to the Shopee Open API MediaSpace module's six interfaces: init_video_upload, upload_video_part, complete_video_upload, get_video_upload_result, cancel_video_upload, upload_image. It is triggered when the user mentions Shopee image upload, video upload, media_space, init_video_upload, upload_image, video chunk upload, or obtaining Shopee image URL. Even if "media" is not explicitly mentioned, as long as it involves uploading image/video files for an authorized Shopee store, it should also be triggered.
