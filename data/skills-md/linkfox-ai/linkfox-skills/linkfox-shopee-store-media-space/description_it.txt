Caricamento multimediale di Shopee MediaSpace (della stessa serie di linkfox-shopee-store-auth), inoltrato tramite /shopee/developerProxy alle sei interfacce del modulo Shopee Open API MediaSpace: init_video_upload, upload_video_part, complete_video_upload, get_video_upload_result, cancel_video_upload, upload_image. Viene attivato quando l'utente menziona il caricamento di immagini Shopee, il caricamento di video, media_space, init_video_upload, upload_image, caricamento di blocchi video o ottenendo l'URL dell'immagine Shopee. Anche se "media" non è menzionato esplicitamente, purché implichi il caricamento di file immagine/video per un negozio Shopee autorizzato, dovrebbe essere attivato.
