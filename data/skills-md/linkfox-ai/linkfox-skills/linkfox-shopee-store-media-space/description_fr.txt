Téléchargement de médias Shopee MediaSpace (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy aux six interfaces du module Shopee Open API MediaSpace : init_video_upload, upload_video_part, complete_video_upload, get_video_upload_result, Cancel_video_upload, upload_image. Il est déclenché lorsque l'utilisateur mentionne le téléchargement d'images Shopee, le téléchargement de vidéos, media_space, init_video_upload, upload_image, le téléchargement de morceaux de vidéo ou l'obtention de l'URL de l'image Shopee. Même si le « média » n'est pas explicitement mentionné, tant qu'il s'agit de télécharger des fichiers image/vidéo pour une boutique Shopee agréée, il doit également être déclenché.
