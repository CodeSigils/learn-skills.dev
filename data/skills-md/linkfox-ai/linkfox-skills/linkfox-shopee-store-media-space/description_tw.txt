Shopee媒體上傳MediaSpace（與linkfox-shopee-store-auth同系列），透過/shopee/developerProxy轉送至Shopee Open API MediaSpace模組的六個介面：init_video_upload、upload_video_part、complete_video_upload、get_video_upload_result、cancel_part、complete_video_upload、get_video_upload_result、cancel_part_result、canceldeo_upage。當使用者提到Shopee圖片上傳、影片上傳、media_space、init_video_upload、upload_image、影片區塊上傳或取得Shopee圖片URL時觸發。即使沒有明確提及“媒體”，只要涉及為 Shopee 授權商店上傳圖片/視訊文件，也應該被觸發。
