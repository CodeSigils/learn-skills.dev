Shopee (Xia Pi) SBS warehousing service (in the same series as linkfox-shopee-store-auth), forwarded through /shopee/developerProxy, includes all five interfaces of the Shopee Open API SBS module: get_bound_whs_info, get_current_inventory, get_expiry_report, get_stock_aging, and get_stock_movement. It is triggered when a user mentions Shopee SBS, warehousing inventory, bound warehouse, get_bound_whs_info, stock aging report, expiry report, or inventory movement. Even if "SBS" is not explicitly mentioned, any query involving authorized Shopee store SBS warehousing and inventory data should also trigger it.
