Shopee (XiaPi) SBS warehousing service (in the same series as linkfox-shopee-store-auth) forwards all five Shopee Open API SBS module interfaces through /shopee/developerProxy: get_bound_whs_info, get_current_inventory, get_expiry_report, get_stock_aging, get_stock_movement. It is triggered when the user mentions Shopee SBS, warehousing inventory, bound warehouse, get_bound_whs_info, stock aging report, expiry report, or inventory movement. Even if "SBS" is not explicitly mentioned, any query involving authorized Shopee store SBS warehousing and inventory data should also trigger.
