El servicio de almacenamiento SBS de Shopee (Xia Pi) (en la misma serie que linkfox-shopee-store-auth), reenviado a través de /shopee/developerProxy, abarca los cinco puntos finales del módulo Shopee Open API SBS: get_bound_whs_info, get_current_inventory, get_expiry_report, get_stock_aging y get_stock_movement. Se activa cuando un usuario menciona Shopee SBS, inventario de almacenamiento, almacén vinculado, get_bound_whs_info, informe de antigüedad de existencias, informe de vencimiento o movimiento de inventario. Incluso si no se hace referencia explícita a "SBS", cualquier consulta que involucre datos de inventario o almacenamiento de SBS para una tienda Shopee autorizada debería activarla.
