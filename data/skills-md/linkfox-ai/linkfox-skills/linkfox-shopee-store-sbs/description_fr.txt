Le service d'entreposage SBS Shopee (XiaPi) (de la même série que linkfox-shopee-store-auth) transmet les cinq interfaces du module Shopee Open API SBS : get_bound_whs_info, get_current_inventory, get_expiry_report, get_stock_aging, get_stock_movement — via /shopee/developerProxy. Il est déclenché lorsque l'utilisateur mentionne Shopee SBS, l'inventaire de l'entrepôt, l'entrepôt lié, get_bound_whs_info, le rapport de vieillissement des stocks, le rapport d'expiration ou le mouvement des stocks. Même si « SBS » n'est pas explicitement mentionné, toute requête impliquant les données d'entreposage et d'inventaire SBS du magasin Shopee autorisé devrait également la déclencher.
