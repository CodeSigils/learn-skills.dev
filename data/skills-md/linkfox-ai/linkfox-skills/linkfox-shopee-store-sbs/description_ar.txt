تقوم خدمة تخزين Shopee (XiaPi) SBS (في نفس السلسلة مثل linkfox-shopee-store-auth) بإعادة توجيه جميع واجهات وحدة Shopee Open API SBS الخمس من خلال /shopee/developerProxy: get_bound_whs_info، get_current_inventory، get_expiry_report، get_stock_aging، get_stock_movement. يتم تشغيله عندما يذكر المستخدم Shopee SBS، أو مخزون المستودعات، أو المستودع المرتبط، أو get_bound_whs_info، أو تقرير تقادم المخزون، أو تقرير انتهاء الصلاحية، أو حركة المخزون. حتى لو لم يتم ذكر "SBS" بشكل صريح، يجب أيضًا تشغيل أي استعلام يتضمن بيانات تخزين وجرد SBS لمتجر Shopee المعتمد.
