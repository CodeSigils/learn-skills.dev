تقوم خدمة تخزين Shopee (المعروفة أيضًا باسم Xiaapi) SBS (في نفس السلسلة مثل linkfox-shopee-store-auth) بإعادة توجيه جميع واجهات وحدة Shopee Open API SBS الخمس — get_bound_whs_info، وget_current_inventory، وget_expiry_report، وget_stock_aging، وget_stock_movement — من خلال/shopee/developerProxy. يتم تشغيله عندما يذكر المستخدم Shopee SBS، أو مخزون المستودعات، أو المستودعات المقيدة، أو get_bound_whs_info، أو تقرير تقادم المخزون، أو تقرير انتهاء الصلاحية، أو حركة المخزون. حتى لو لم يتم ذكر "SBS" بشكل صريح، فإن أي استعلام يتضمن بيانات تخزين وجرد SBS الخاصة بمتجر Shopee المعتمد يجب أن يؤدي أيضًا إلى تشغيله.
