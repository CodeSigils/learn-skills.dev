تصفية متاجر Shopify المستقلة حسب أبعاد متعددة (اسم المتجر/المجال، البلد، سنوات الإنشاء، عدد المنتجات، عدد الإعلانات، الزيارات الشهرية، الطلبات الشهرية، متابعي وسائل التواصل الاجتماعي، وما إلى ذلك). يتم تشغيله عندما يذكر المستخدم متجر Shopify، أو تحليل متجر Shopify، أو متجر مستقل، أو بائع Shopify، أو متجر مستقل منافس، أو زيارات Shopify الشهرية، أو مكتبة إعلانات المتجر المستقلة، أو متاجر Shopify، أو استعلام متجر Shopify. حتى لو لم يذكر المستخدم اسم الأداة، طالما أنه يبحث عن متاجر على موقع Shopify المستقل، أو يقوم بتصفية بيانات المتجر، أو تحليل أداء المتجر، فيجب تشغيل هذه الإمكانية.
