تصفية متاجر Shopify المستقلة عبر أبعاد متعددة (اسم المتجر/المجال، البلد، العمر، عدد المنتجات، عدد الإعلانات، الزيارات الشهرية، الطلبات الشهرية، متابعي وسائل التواصل الاجتماعي، وما إلى ذلك). يتم تشغيله عندما يذكر المستخدم متجر Shopify، أو تحليل متجر Shopify، أو متجر مستقل، أو بائع Shopify، أو متجر مستقل منافس، أو زيارات Shopify الشهرية، أو مكتبة إعلانات المتجر المستقلة، أو متاجر Shopify، أو استعلام متجر Shopify. وحتى لو لم يذكر المستخدم اسم الأداة، فطالما أنه يبحث عن متاجر على موقع Shopify المستقل، أو يقوم بتصفية بيانات المتجر، أو تحليل أداء المتجر، فيجب تفعيل هذه الإمكانية.
