Shopee (Shopee) Livestream (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy, inclut les 25 points de terminaison du module Shopee Open API Livestream : create_session, start_session, add_item_list, get_session_detail, get_session_metric, post_comment, upload_image, etc. Il est déclenché lorsqu'un utilisateur mentionne Shopee Livestream, Livestream, créant un livestream session, produit livestream, commentaire livestream, session_id, upload_image. Même si « livestream » n'est pas explicitement mentionné, toute référence à la gestion de session/produit/interaction Livestream d'une boutique Shopee agréée devrait également le déclencher.
