Shopee (Xia Pi) Livestream (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy, englobe les 25 points de terminaison du module Shopee Open API Livestream : create_session, start_session, add_item_list, get_session_detail, get_session_metric, post_comment, upload_image, etc. Lorsqu'un utilisateur mentionne Shopee livestream, Livestream, créant une session de livestream, produits livestream, commentaires livestream, session_id, upload_image, cela se déclenche. Même si le « livestream » n'est pas explicitement mentionné, tant qu'il implique des sessions Livestream, des produits ou la gestion des interactions d'une boutique Shopee autorisée, il devrait également se déclencher.
