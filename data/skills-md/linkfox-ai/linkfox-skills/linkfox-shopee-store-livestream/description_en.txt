Shopee (also known as Xiapi) livestream (Livestream, part of the same series as linkfox-shopee-store-auth), forwarded through /shopee/developerProxy, supports all 25 interfaces of the Shopee Open API Livestream module: create_session, start_session, add_item_list, get_session_detail, get_session_metric, post_comment, upload_image, etc. It is triggered when the user mentions Shopee livestream, Livestream, creating a livestream session, livestream products, livestream comments, session_id, or upload_image. Even if “livestream” is not explicitly mentioned, as long as it involves Livestream sessions/products/interaction management of an authorized Shopee store, it should also be triggered.
