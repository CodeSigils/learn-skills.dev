Shopee (Shopee) Livestream (in the same series as linkfox-shopee-store-auth), forwarded via /shopee/developerProxy, includes all 25 Shopee Open API Livestream module endpoints: create_session, start_session, add_item_list, get_session_detail, get_session_metric, post_comment, upload_image, etc. It is triggered when a user mentions Shopee Livestream, Livestream, creating a livestream session, livestream product, livestream comment, session_id, upload_image. Even if "livestream" is not explicitly mentioned, any reference to the Livestream session/product/interaction management of an authorized Shopee store should also trigger it.
