Der Livestream von Shopee (auch bekannt als „Xiapi“) (Livestream, Teil derselben Serie wie linkfox-shopee-store-auth) wird über /shopee/developerProxy an das Shopee Open API Livestream-Modul weitergeleitet und deckt alle 25 Schnittstellen ab: create_session, start_session, add_item_list, get_session_detail, get_session_metric, post_comment, upload_image usw. Es wird ausgelöst, wenn ein Benutzer erwähnt Shopee-Livestream, Livestream, das Erstellen einer Livestream-Sitzung, ein Livestream-Produkt, einen Livestream-Kommentar, eine Sitzungs-ID oder ein Upload-Bild. Auch wenn „Livestream“ nicht explizit erwähnt wird, sollte jeder Verweis auf Livestream-Sitzungen, Produkte oder Interaktionsmanagement für einen autorisierten Shopee-Shop dies ebenfalls auslösen.
