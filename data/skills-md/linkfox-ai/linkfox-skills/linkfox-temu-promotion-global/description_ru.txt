API продвижения электронной коммерции Temu Global Site, пересылаемый через шлюз LinkFox для интерфейсов bg/temu, связанных с глобальным продвижением партнеров/деятельностью по продвижению (создание действий, регистрация, запрос, купоны/мгновенные продажи и т. д.; интерфейсы будут интегрированы поэлементно в соответствии с документацией партнера). Срабатывает, когда пользователь упоминает акцию Temu Global, рекламные акции, купоны, флэш-распродажи, регистрацию активности, рекламную кампанию, продвижение ассортимента продукции. Используйте linkfox-temu-manage-product-global для управления продуктами; linkfox-temu-price-global для ценообразования; linkfox-temu-order-global для заказов.
