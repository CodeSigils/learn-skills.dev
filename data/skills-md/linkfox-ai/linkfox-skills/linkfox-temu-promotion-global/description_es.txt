API de promoción de comercio electrónico del sitio global de Temu, reenviada a través de la puerta de enlace de LinkFox para la promoción global del socio/interfaces bg/temu relacionadas con la actividad de promoción (creación de actividad, registro, consulta, cupones/ventas flash, etc.; las interfaces se integrarán artículo por artículo de acuerdo con la documentación del socio). Se activa cuando el usuario menciona la promoción de Temu Global, actividades de promoción, cupones, ventas flash, registro de actividades, campaña de promoción, promoción de inventario de productos. Utilice linkfox-temu-manage-product-global para la gestión de productos; linkfox-temu-price-global para conocer los precios; linkfox-temu-order-global para pedidos.
