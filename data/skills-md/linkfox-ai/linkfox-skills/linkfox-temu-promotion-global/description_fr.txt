API de promotion du commerce électronique du site mondial Temu, transmise via la passerelle LinkFox pour les interfaces bg/temu liées aux activités de promotion globale des partenaires (création d'activités, inscription, requête, coupons/ventes flash, etc. ; les interfaces seront intégrées article par article selon la documentation du partenaire). Déclenchez lorsque l'utilisateur mentionne la promotion Temu Global, les activités promotionnelles, les coupons, les ventes flash, l'enregistrement des activités, la campagne promotionnelle, la promotion de l'inventaire de produits. Utilisez linkfox-temu-manage-product-global pour la gestion des produits ; linkfox-temu-price-global pour les prix ; linkfox-temu-order-global pour les commandes.
