API di promozione e-commerce del sito globale Temu, inoltrata tramite il gateway LinkFox per le interfacce bg/temu relative alla promozione globale del partner/attività di promozione (creazione di attività, registrazione, query, coupon/vendite flash, ecc.; le interfacce saranno integrate articolo per articolo in base alla documentazione del partner). Si attiva quando l'utente menziona la promozione globale di Temu, le attività promozionali, i coupon, le vendite flash, la registrazione delle attività, la campagna promozionale, la promozione dell'inventario dei prodotti. Utilizzare linkfox-temu-manage-product-global per la gestione del prodotto; linkfox-temu-price-global per i prezzi; linkfox-temu-order-global per gli ordini.
