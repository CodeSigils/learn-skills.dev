La herramienta de expansión de palabras clave Jungle Scout genera una lista de palabras clave relacionadas basadas en una palabra clave inicial, que incluye datos como volumen de búsqueda, tendencias, ofertas de PPC y dificultad de clasificación, y cubre diez sitios de Amazon, incluidos Estados Unidos, Reino Unido, Alemania, Japón y otros. Esta habilidad se activa cuando el usuario menciona expansión de palabras clave, minería de palabras clave, minería de palabras clave de cola larga, palabras clave relacionadas, sugerencias de palabras clave, expansión de palabras clave, investigación de ofertas de PPC, competencia de palabras clave, descubrimiento de palabras clave, palabras clave de Jungle Scout, expansión de palabras clave, descubrimiento de palabras clave, exploración de palabras clave, palabras clave relacionadas, palabras clave de cola larga, sugerencias de palabras clave, investigación de ofertas de PPC, competencia de palabras clave, expansión de palabras clave iniciales o minería de palabras clave. Incluso si el usuario no menciona explícitamente "Jungle Scout", siempre que su solicitud implique encontrar más palabras clave y métricas relacionadas, como el volumen de búsqueda y la competencia, a partir de una palabra clave inicial, esta habilidad debe activarse.
