Les informations et paramètres de la boutique Shopee (de la même série que linkfox‑shopee‑store‑auth), transmis via/shopee/developerProxy, couvrent les neuf points de terminaison du module Shopee Open API Shop : get_shop_info, get_profile, update_profile, get_warehouse_detail, get_shop_notification, get_authorised_reseller_brand, get_br_shop_onboarding_info, get_shop_holiday_mode, set_shop_holiday_mode. Déclenchez lorsque l'utilisateur mentionne les informations du magasin Shopee, les détails du magasin, le nom du magasin, l'adresse de l'entrepôt, les notifications du vendeur, les marques autorisées, le KYC du Brésil, le mode vacances (假期模式), le mode vacances ou get_shop_info. Même si les « informations du magasin » ne sont pas explicitement citées, toute requête ou configuration concernant les données d’un magasin Shopee autorisé devrait également se déclencher.
