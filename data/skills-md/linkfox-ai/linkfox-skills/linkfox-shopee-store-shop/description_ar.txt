معلومات وإعدادات متجر Shopee (في نفس السلسلة مثل linkfox‑shopee‑store‑auth)، التي يتم إعادة توجيهها عبر/shopee/developerProxy، وتغطي جميع نقاط نهاية وحدة Shopee Open API Shop التسعة: get_shop_info، get_profile، update_profile، get_warehouse_detail، get_shop_notification، get_authorised_reseller_brand، get_br_shop_onboarding_info، get_shop_holiday_mode، set_shop_holiday_mode. يتم تشغيله عندما يذكر المستخدم معلومات متجر Shopee، أو تفاصيل المتجر، أو اسم المتجر، أو عنوان المستودع، أو إشعارات البائع، أو العلامات التجارية المعتمدة، أو KYC في البرازيل، أو وضع العطلة (假期模式)، أو وضع العطلة، أو get_shop_info. حتى إذا لم يتم الاستشهاد بـ "معلومات المتجر" بشكل صريح، فيجب أيضًا تشغيل أي استعلام أو تكوين يتعلق ببيانات متجر Shopee معتمد.
