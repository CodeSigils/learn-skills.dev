Shopee store information and settings (in the same series as linkfox‑shopee‑store‑auth), forwarded via /shopee/developerProxy, cover all nine Shopee Open API Shop module endpoints: get_shop_info, get_profile, update_profile, get_warehouse_detail, get_shop_notification, get_authorised_reseller_brand, get_br_shop_onboarding_info, get_shop_holiday_mode, set_shop_holiday_mode. Trigger when the user mentions Shopee store information, store details, store name, warehouse address, seller notifications, authorized brands, Brazil KYC, holiday mode (假期模式), holiday mode, or get_shop_info. Even if “store information” is not explicitly cited, any query or configuration concerning an authorized Shopee store’s data should also trigger.
