API de traitement/expédition du commerce électronique du site Temu Global (hors États-Unis/UE) (unifiée) : étiquette d'achat Achat-Shipping, traitement en entrepôt coopératif, auto-expédition du vendeur, suivi logistique et 23 autres interfaces (à l'exclusion du formulaire de numérisation). Déclenché lorsque l'utilisateur mentionne l'expédition Temu Global, l'étiquette d'achat, Buy‑Shipping, l'entrepôt coopératif, l'auto-expédition, le suivi, l'expédition.create, le site=global order‑shipping. Utilisez linkfox‑temu‑order‑global pour les commandes. Pour le formulaire de numérisation, veuillez utiliser linkfox‑temu‑fulfillment‑us.
