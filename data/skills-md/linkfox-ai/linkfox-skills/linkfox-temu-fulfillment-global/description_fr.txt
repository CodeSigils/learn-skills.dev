API de traitement/expédition du site Temu Global (hors États-Unis/UE) (combinée) : achat d'étiquettes d'achat-expédition, traitement en entrepôt coopératif, expédition automatique par le vendeur, suivi logistique et 23 autres interfaces (à l'exclusion du formulaire de numérisation). Déclenché lorsque l'utilisateur mentionne l'expédition Temu Global, l'achat d'étiquettes, l'achat‑expédition, l'entrepôt coopératif, l'auto-expédition, le suivi, l'expédition.create, le site=global order‑shipping. Utilisezlinkfox‑temu‑order‑global pour les commandes. Pour le formulaire de numérisation, veuillez utiliserlinkfox‑temu‑fulfillment‑us.
