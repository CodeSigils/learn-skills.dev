API выполнения/доставки электронной коммерции на сайте Temu Global (за пределами США/ЕС) (комбинированный): покупка с этикеткой для доставки, выполнение на совместном складе, самостоятельная доставка продавцом, отслеживание логистики и другие 23 интерфейса (исключая форму сканирования). Срабатывает, когда пользователь упоминает глобальную доставку Temu, покупку этикетки, покупку-доставку, совместный склад, самостоятельную доставку, отслеживание, отгрузку.создать, site=глобальную доставку заказа. Используйте ссылкуfox‑temu‑order‑global для заказов. Для формы сканирования используйте ссылкуfox‑temu‑fulfillment‑us.
