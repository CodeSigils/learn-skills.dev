Shopee (虾皮) Mécanisme Push (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy, inclut les quatre interfaces du module Shopee Open API Push : set_app_push_config, get_app_push_config, get_lost_push_message, confirm_consumed_lost_push_message. Déclenchez lorsque l'utilisateur mentionne Shopee Push, les rappels push, le mécanisme push, set_app_push_config, le renvoi push perdu ou la configuration du webhook. Même si « Push » n'est pas explicitement mentionné, toute référence à la configuration Push de Shopee Open Platform ou à la gestion des messages de renvoi devrait également se déclencher.
