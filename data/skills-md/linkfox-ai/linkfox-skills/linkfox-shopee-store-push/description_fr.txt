Le mécanisme Push de Shopee (XiaPi) (de la même série que linkfox‑shopee‑store‑auth), transmet les quatre interfaces du module Shopee Open API Push — set_app_push_config, get_app_push_config, get_lost_push_message, confirm_consumed_lost_push_message — via /shopee/developerProxy. Il est déclenché lorsqu'un utilisateur mentionne Shopee Push, les rappels push, le mécanisme Push, set_app_push_config, les tentatives de push perdues ou la configuration du webhook. Même si « Push » n'est pas explicitement mentionné, tant qu'il s'agit d'une configuration Push de Shopee Open Platform ou d'une nouvelle tentative de gestion des messages, il doit être déclenché.
