Shopee (XiaPi) Push mechanism (in the same series as linkfox-shopee-store-auth), forwarded through /shopee/developerProxy, includes all four interfaces of the Shopee Open API Push module: set_app_push_config, get_app_push_config, get_lost_push_message, confirm_consumed_lost_push_message. Trigger when the user mentions Shopee Push, push callback, Push Mechanism, set_app_push_config, lost push retransmission, or webhook configuration. Even if "Push" is not explicitly mentioned, as long as it involves Shopee Open Platform Push configuration or retransmission message management, it should also be triggered.
