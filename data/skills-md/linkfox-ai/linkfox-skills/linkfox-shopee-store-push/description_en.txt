Shopee (XiaPi) Push mechanism (in the same series as linkfox‑shopee‑store‑auth), forwards all four Shopee Open API Push module interfaces—set_app_push_config, get_app_push_config, get_lost_push_message, confirm_consumed_lost_push_message—through /shopee/developerProxy. It is triggered when a user mentions Shopee Push, push callbacks, Push Mechanism, set_app_push_config, lost‑push retries, or webhook configuration. Even if “Push” is not explicitly mentioned, as long as it involves Shopee Open Platform Push configuration or retry message management, it should be triggered.
