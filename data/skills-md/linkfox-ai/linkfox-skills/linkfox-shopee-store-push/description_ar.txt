تقوم آلية دفع Shopee (XiaPi) (في نفس السلسلة مثل linkfox‑shopee‑store‑auth)، بإعادة توجيه جميع واجهات وحدة Shopee Open API Push الأربعة - set_app_push_config، وget_app_push_config، وget_lost_push_message، وconfirm_consumed_lost_push_message - من خلال /shopee/developerProxy. يتم تشغيله عندما يذكر المستخدم Shopee Push، أو عمليات رد الاتصال بالدفع، أو آلية الدفع، أو set_app_push_config، أو عمليات إعادة محاولة الدفع المفقودة، أو تكوين خطاف الويب. حتى لو لم يتم ذكر "الدفع" بشكل صريح، طالما أنه يتضمن تكوين Shopee Open Platform Push أو إعادة محاولة إدارة الرسائل، فيجب تشغيله.
