تقوم آلية دفع Shopee (XiaPi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، بإعادة توجيه جميع الواجهات الأربع لوحدة Shopee Open API Push عبر /shopee/developerProxy: set_app_push_config، get_app_push_config، get_lost_push_message، Confirm_consumed_lost_push_message. يتم تشغيله عندما يذكر المستخدم Shopee Push، أو عمليات رد الاتصال بالدفع، أو آلية الدفع، أو set_app_push_config، أو إعادة إرسال الدفع المفقود، أو تكوين خطاف الويب. حتى لو لم يتم ذكر "الدفع" بشكل صريح، طالما أنه يتضمن تكوين Shopee Open Platform Push أو إدارة رسائل إعادة الإرسال، فيجب أيضًا تشغيله.
