Mecanismo Push de Shopee (XiaPi) (en la misma serie que linkfox‑shopee‑store‑auth), reenviado a través de /shopee/developerProxy, que cubre las cuatro interfaces del módulo Shopee Open API Push: set_app_push_config, get_app_push_config, get_lost_push_message y confirm_consumed_lost_push_message. Se activa cuando un usuario menciona Shopee Push, enviar devoluciones de llamada, mecanismo de inserción, set_app_push_config, retransmisión de inserción perdida o configuración de webhook. Incluso si "Push" no se menciona explícitamente, cualquier referencia a la configuración Push de Shopee Open Platform o a la gestión de mensajes de retransmisión también debería activarlo.
