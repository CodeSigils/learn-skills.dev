El mecanismo Push de Shopee (XiaPi) (en la misma serie que linkfox‑shopee‑store‑auth), reenvía las cuatro interfaces del módulo Shopee Open API Push—set_app_push_config, get_app_push_config, get_lost_push_message, confirm_consumed_lost_push_message—a través de /shopee/developerProxy. Se activa cuando un usuario menciona Shopee Push, enviar devoluciones de llamada, mecanismo de envío, set_app_push_config, reintentos de envío perdidos o configuración de webhook. Incluso si "Push" no se menciona explícitamente, siempre que implique la configuración Push de Shopee Open Platform o la gestión de mensajes de reintento, debe activarse.
