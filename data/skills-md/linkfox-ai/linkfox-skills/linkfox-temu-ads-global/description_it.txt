API per gli annunci di e-commerce del sito globale Temu, inoltrata tramite il gateway LinkFox alle interfacce bg/temu relative ad annunci globali dei partner/posizionamento pubblicitario (campagne pubblicitarie, gruppi di annunci, creatività, report, offerte di budget, ecc.; le interfacce verranno integrate una per una in base alla documentazione del partner). Si attiva quando un utente menziona Temu Annunci globali, Annunci, posizionamento pubblicitario, campagna pubblicitaria, gruppo di annunci, creatività, offerte, budget, rapporto sugli annunci, campagna pubblicitaria, annunci di inventario dei prodotti. Utilizzarelinkfox‑temu‑manage‑product‑global per la gestione del prodotto; utilizzarelinkfox‑temu‑promotion‑global per le promozioni; e utilizzarelinkfox‑temu‑order‑global per gli ordini.
