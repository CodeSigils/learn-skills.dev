API рекламы электронной коммерции Temu Global Site, пересылаемый через шлюз LinkFox в партнерские глобальные рекламные интерфейсы / интерфейсы bg/temu, связанные с размещением рекламы (рекламные кампании, группы объявлений, креативы, отчеты, бюджетные ставки и т. д.; интерфейсы будут интегрированы один за другим в соответствии с документацией партнера). Срабатывает, когда пользователь упоминает объявления Temu Global, рекламу, размещение рекламы, рекламную кампанию, группу объявлений, креатив, ставки, бюджет, отчет о рекламе, рекламную кампанию, рекламу ассортимента товаров. Используйтеlinkfox‑temu‑manage‑product‑global для управления продуктами; используйтеlinkfox‑temu‑promotion‑global для рекламных акций; и используйте linkfox‑temu‑order‑global для заказов.
