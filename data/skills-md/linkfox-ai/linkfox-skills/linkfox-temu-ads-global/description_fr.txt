API Temu Global e-commerce Ads, transmise via la passerelle LinkFox aux interfaces bg/temu liées au déploiement de Global Ads/publicité du partenaire (campagnes publicitaires, groupes d'annonces, créations, rapports, enchères budgétaires, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenchez lorsque l'utilisateur mentionne les publicités Temu Global, les publicités, le déploiement publicitaire, la campagne publicitaire, le groupe de publicités, la création, les enchères, le budget, le rapport publicitaire, la campagne publicitaire, la publicité sur l'inventaire de produits. Utilisez linkfox-temu-manage-product-global pour la gestion des produits ; linkfox-temu-promotion-global pour les promotions ; linkfox-temu-order-global pour les commandes.
