API Temu Global Site e-commerce Ads, transmise via la passerelle LinkFox aux interfaces bg/temu liées au placement publicitaire / aux annonces globales des partenaires (campagnes publicitaires, groupes d'annonces, créations, rapports, enchères budgétaires, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenchez lorsqu'un utilisateur mentionne les annonces Temu Global, les annonces, l'emplacement publicitaire, la campagne publicitaire, le groupe d'annonces, la création, les enchères, le budget, le rapport publicitaire, la campagne publicitaire, les annonces d'inventaire de produits. Utilisezlinkfox‑temu‑manage‑product‑global pour la gestion des produits ; utilisezlinkfox‑temu‑promotion‑global pour les promotions ; et utilisezlinkfox‑temu‑order‑global pour les commandes.
