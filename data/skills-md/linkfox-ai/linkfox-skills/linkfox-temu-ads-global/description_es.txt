API de anuncios de comercio electrónico del sitio global de Temu, reenviada a través de la puerta de enlace de LinkFox a las interfaces bg/temu relacionadas con anuncios globales de socios/ubicación de publicidad (campañas publicitarias, grupos de anuncios, creatividades, informes, ofertas de presupuesto, etc.; las interfaces se integrarán una por una de acuerdo con la documentación del socio). Se activa cuando un usuario menciona anuncios de Temu Global, anuncios, ubicación publicitaria, campaña publicitaria, grupo de anuncios, creatividad, ofertas, presupuesto, informe publicitario, campaña publicitaria o anuncios de inventario de productos. Utilicelinkfox‑temu‑manage‑product‑global para la gestión de productos; uselinkfox‑temu‑promotion‑global para promociones; y uselinkfox‑temu‑order‑global para pedidos.
