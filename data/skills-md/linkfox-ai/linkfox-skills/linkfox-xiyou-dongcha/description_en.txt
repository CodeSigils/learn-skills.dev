Xiyou Keyword Finder (Xiyou Insight) provides Amazon ASIN and keyword analysis via the LinkFox gateway forwarding to the Xiyou OpenAPI. It covers 17 endpoints, including ASIN traffic score, reverse keyword lookup, keyword ranking/traffic trends, BSR, weekly ABA trends, keyword competitiveness, and suggested bidding, supporting 13 sites such as US, UK, and DE. It is triggered when users mention Xiyou Keyword Finder, Xiyou Insight, Xiyou, ASIN reverse keyword lookup, keyword analysis, weekly ABA search volume, traffic score, ranking trend, xiyou keyword research, ASIN traffic score, reverse ASIN lookup, or search term analysis. Even if the user does not write “Xiyou,” as long as the request is to query Amazon ASIN/keyword traffic and ranking data through Xiyou Keyword Finder, it should be triggered. Before use, configure LINKFOXAGENT_API_KEY and the environment variables XIYOU_CLIENT_ID and XIYOU_CLIENT_SECRET.
