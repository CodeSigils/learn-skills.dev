Shopee (Xia Pi) Store Logistics-Versand (in der gleichen Reihe wie linkfox-shopee-store-auth) wird über/shopee/developerProxy an alle 46 Schnittstellen des Shopee Open API Logistics-Moduls weitergeleitet: get_shipping_parameter, Ship_order, get_tracking_number, create_shipping_document, download_shipping_document, get_channel_list usw. Es wird ausgelöst, wenn der Benutzer Shopee erwähnt Logistik, Versand, Versandauftrag, Frachtbriefnummer, Versandetikett, Sendungsverfolgung, Abholadresse, Logistikkanal oder READY_TO_SHIP-Versand. Auch wenn „Logistik“ nicht explizit erwähnt wird, sollte jeder Verweis auf Versand, Versandetiketten oder logistische Rückverfolgungsabfragen für einen autorisierten Shopee-Shop dies ebenfalls auslösen.
