Expédition logistique du magasin Shopee (de la même série que linkfox-shopee-store-auth), transmise via /shopee/developerProxy vers les 46 interfaces du module Shopee Open API Logistics : get_shipping_parameter, ship_order, get_tracking_number, create_shipping_document, download_shipping_document, get_channel_list, etc. Il est déclenché lorsque l'utilisateur mentionne Shopee logistique, expédition, ship_order, numéro de lettre de transport, expédition étiquette, suivi, adresse de retrait, canal logistique ou expédition READY_TO_SHIP. Même si la « logistique » n'est pas explicitement mentionnée, tant qu'elle implique des requêtes d'expédition, d'étiquette d'expédition ou de suivi logistique pour un magasin Shopee agréé, elle doit être déclenchée.
