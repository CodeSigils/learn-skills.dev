La logística y el envío de la tienda Shopee (Shopee) (en la misma serie que linkfox-shopee-store-auth) se reenvían a través de /shopee/developerProxy a las 46 interfaces del módulo Shopee Open API Logistics: get_shipping_parameter, ship_order, get_tracking_number, create_shipping_document, download_shipping_document, get_channel_list, etc. Cuando un usuario menciona Shopee logística, envío, ship_order, waybill número, etiqueta de envío, seguimiento, dirección de recogida, canal logístico o envío READY_TO_SHIP, se activa el activador. Incluso si no se menciona explícitamente la "logística", también debería activarse cualquier discusión relacionada con el envío, las etiquetas de envío o las consultas de seguimiento de logística para una tienda Shopee autorizada.
