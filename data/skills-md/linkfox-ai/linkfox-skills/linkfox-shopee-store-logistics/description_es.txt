El envío logístico de la tienda Shopee (Xia Pi) (en la misma serie que linkfox-shopee-store-auth) se reenvía a través de/shopee/developerProxy a las 46 interfaces del módulo Shopee Open API Logistics: get_shipping_parameter, ship_order, get_tracking_number, create_shipping_document, download_shipping_document, get_channel_list, etc. Se activa cuando el usuario menciona Shopee logística, envío, ship_order, número de guía de embarque, etiqueta de envío, seguimiento, dirección de recogida, canal logístico o envío READY_TO_SHIP. Incluso si la “logística” no se menciona explícitamente, cualquier referencia al envío, etiquetas de envío o consultas de seguimiento de logística para una tienda Shopee autorizada también debería activarla.
