Shopee (Xia Pi) store logistics shipping (in the same series as linkfox-shopee-store-auth) is forwarded through /shopee/developerProxy to all 46 interfaces of the Shopee Open API Logistics module: get_shipping_parameter, ship_order, get_tracking_number, create_shipping_document, download_shipping_document, get_channel_list, etc. It is triggered when the user mentions Shopee logistics, shipping, ship_order, waybill number, shipping label, tracking, collection address, logistics channel, or READY_TO_SHIP shipping. Even if “logistics” is not explicitly mentioned, any reference to shipping, shipping labels, or logistics trace queries for an authorized Shopee store should also trigger it.
