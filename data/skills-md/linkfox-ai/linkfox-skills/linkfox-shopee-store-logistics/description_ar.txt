تتم إعادة توجيه الشحن اللوجستي لمتجر Shopee (Xia Pi) (في نفس السلسلة مثل linkfox-shopee-store-auth) من خلال /shopee/developerProxy إلى جميع الواجهات الـ 46 لوحدة Shopee Open API Logistics: get_shipping_parameter، ship_order، get_tracking_number، create_shipping_document، download_shipping_document، get_channel_list، وما إلى ذلك. يتم تشغيله عندما يذكر المستخدم لوجستيات Shopee، أو الشحن، أو ship_order، أو رقم بوليصة الشحن، أو ملصق الشحن، أو التتبع، أو عنوان التجميع، أو قناة الخدمات اللوجستية، أو READY_TO_SHIP Shipping. حتى لو لم يتم ذكر "اللوجستيات" بشكل صريح، فإن أي إشارة إلى الشحن أو ملصقات الشحن أو استعلامات التتبع اللوجستي لمتجر Shopee معتمد يجب أن تؤدي أيضًا إلى ظهورها.
