تتم إعادة توجيه الشحن اللوجستي لمتجر Shopee (في نفس السلسلة مثل linkfox-shopee-store-auth) عبر /shopee/developerProxy إلى جميع الواجهات الـ 46 لوحدة Shopee Open API Logistics: get_shipping_parameter، ship_order، get_tracking_number، create_shipping_document، download_shipping_document، get_channel_list، وما إلى ذلك. يتم تشغيله عندما يذكر المستخدم الخدمات اللوجستية لـ Shopee، والشحن، ship_order، أو رقم التتبع، أو ملصق الشحن، أو التتبع، أو عنوان الالتقاط، أو قناة الخدمات اللوجستية، أو الشحن READY_TO_SHIP. حتى لو لم يتم ذكر كلمة "اللوجستيات" بشكل صريح، طالما أنها تتضمن الشحن أو ملصق الشحن أو استعلام تتبع لوجستي لمتجر Shopee معتمد، فيجب أيضًا تشغيلها.
