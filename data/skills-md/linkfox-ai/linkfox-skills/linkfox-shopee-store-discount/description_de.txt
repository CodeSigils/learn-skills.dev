Shopee (Xiaopi) Store-Rabattaktion „Discount“ (in der gleichen Serie wie linkfox-shopee-store-auth), weitergeleitet über/shopee/developerProxy an das Shopee Open API Discount-Modul, das alle 12 Schnittstellen abdeckt: add_discount, get_discount_list, update_discount, add_discount_item, end_discount, SIP-Rabatt usw. Sie wird ausgelöst, wenn ein Benutzer Shopee-Rabatt, Rabatt, Werbeaktion erwähnt Aktivität, zeitlich begrenzter Rabatt, add_discount, discount_id, Rabattereignis usw. Auch wenn „Rabatt“ nicht explizit erwähnt wird, sollte dieser ausgelöst werden, sofern es sich um die Erstellung oder Verwaltung von Rabattaktivitäten für einen autorisierten Shopee-Shop handelt.
