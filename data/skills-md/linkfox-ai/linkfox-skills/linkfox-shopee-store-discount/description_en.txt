Shopee (Xiaopi) store discount promotion “Discount” (in the same series as linkfox-shopee-store-auth), forwarded through /shopee/developerProxy to the Shopee Open API Discount module covering all 12 interfaces: add_discount, get_discount_list, update_discount, add_discount_item, end_discount, SIP discount, etc. It is triggered when a user mentions Shopee discount, Discount, promotional activity, limited‑time discount, add_discount, discount_id, discount event, and so on. Even if “discount” is not explicitly mentioned, as long as it involves creating or managing discount activities for an authorized Shopee store, it should be triggered.
