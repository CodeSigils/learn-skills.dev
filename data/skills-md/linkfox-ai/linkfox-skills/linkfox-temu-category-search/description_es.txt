Busque nombres de categorías en chino, nombres en inglés e ID de categorías por palabra clave dentro de los datos de categorías de Temu sincronizados con la base de datos local, para usar en el filtrado de productos/tiendas. Esto se activa cuando el usuario menciona la categoría de Temu, el ID de la categoría de Temu, el árbol de categorías de Temu, la categoría de backend de Temu, el tipo de producto de Temu, syncTemuCategory (sincronización de categorías de Temu) después de consultar las categorías o la búsqueda de categorías de Temu. Incluso si el usuario no menciona el nombre de la herramienta, siempre que busque un ID de categoría por palabra clave en la base de datos de categorías de Temu sincronizada localmente, esta habilidad debería activarse.
