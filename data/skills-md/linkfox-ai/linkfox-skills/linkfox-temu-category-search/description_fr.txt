Recherchez dans la base de données locale synchronisée des catégories Temu le nom chinois de la catégorie, le nom anglais et l'ID de catégorie à l'aide de mots-clés, dans le but de filtrer les produits/boutiques par ID de catégorie. Ceci est déclenché lorsque l'utilisateur mentionne la catégorie Temu, l'ID de catégorie Temu, l'arborescence de catégories Temu, la catégorie backend Temu, la catégorie Temu, la catégorie de requête syncTemuCategory (synchronisation de catégorie Temu) ou la recherche de catégorie Temu. Même si l'utilisateur ne mentionne pas le nom de l'outil, cette compétence doit être déclenchée tant qu'un identifiant de catégorie est trouvé dans la base de données de catégories Temu synchronisée localement par mot-clé.
