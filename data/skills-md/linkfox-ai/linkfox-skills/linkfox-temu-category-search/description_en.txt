Search the synchronized local Temu category database for category Chinese name, English name, and category ID using keywords, for the purpose of filtering products/shops by category ID. This is triggered when the user mentions Temu category, Temu category ID, Temu category tree, Temu backend category, Temu category, syncTemuCategory (Temu category sync) query category, or Temu category search. Even if the user does not mention the tool name, this skill should be triggered as long as a category ID is found in the locally synchronized Temu category database by keyword.
