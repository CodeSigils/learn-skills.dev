Erhalten Sie den übersetzten Text der Patentspezifikation (Beschreibung) von PatSnap. Diese Funktion wird ausgelöst, wenn ein Benutzer eine Patentspezifikationsübersetzung, den vollständigen Patenttext in einer anderen Sprache oder den übersetzten vollständigen Patenttext anfordert oder die Patentspezifikation auf Chinesisch, Englisch oder Japanisch anzeigen möchte, sowie wenn er eine Patentspezifikationsübersetzung, eine Patentbeschreibungsübersetzung, PatSnap oder eine Patentübersetzung erwähnt. Es sollte auch aktiviert werden, wenn ein Benutzer eine Patent-ID oder Veröffentlichungsnummer angibt und nach dem Spezifikations-/Beschreibungsinhalt in einer anderen Sprache fragt oder Ausdrücke wie „Übersetzung der Patentspezifikation“, „Übersetzung der Beschreibung“, „Übersetzung des Volltexts“ oder ähnliche Absichten verwendet.
