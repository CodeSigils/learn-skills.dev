Obtain the translated patent specification (description) text from PatSnap. This capability is triggered when a user requests a patent specification translation, the full patent text in another language, the translated full patent text, or wants to view the patent specification in Chinese, English, or Japanese, as well as when they mention patent specification translation, patent description translation, PatSnap, or patent translation. It should also be activated when a user provides a patent ID or publication number and asks for the specification/description content in another language, or uses phrases like “patent specification translation,” “description translation,” “full text translation,” or similar intents.
