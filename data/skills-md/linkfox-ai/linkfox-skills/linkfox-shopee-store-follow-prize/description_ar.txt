جائزة متابعة Shopee (XiaPi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، التي يتم إعادة توجيهها عبر /shopee/developerProxy، تتضمن جميع واجهات وحدة جائزة متابعة Shopee Open API الست: add_follow_prize وget_follow_prize_list وget_follow_prize_detail وupdate_follow_prize وend_follow_prize وdelete_follow_prize. يتم تشغيلها عندما يذكر المستخدم جائزة Shopee Follow، أو جائزة المتابعة، أو قسائم المتابعة لتلقيها، أو add_follow_prize، أو Campaign_id، أو مزايا المعجبين. حتى إذا لم يتم ذكر "جائزة المتابعة" صراحةً، فإن أي مشاركة في إدارة أنشطة جائزة المتابعة لمتجر Shopee معتمد يجب أن تؤدي إلى تفعيلها.
