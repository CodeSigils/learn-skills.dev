Shopee (XiaPi) Follow Prize (in the same series as linkfox-shopee-store-auth), forwarded via /shopee/developerProxy, includes all six Shopee Open API Follow Prize module interfaces: add_follow_prize, get_follow_prize_list, get_follow_prize_detail, update_follow_prize, end_follow_prize, delete_follow_prize. It is triggered when the user mentions Shopee Follow Prize, Follow Prize, follow-to-receive coupons, add_follow_prize, campaign_id, or fan benefits. Even if "Follow Prize" is not explicitly mentioned, any involvement with the management of Follow Prize activities for an authorized Shopee store should trigger it.
