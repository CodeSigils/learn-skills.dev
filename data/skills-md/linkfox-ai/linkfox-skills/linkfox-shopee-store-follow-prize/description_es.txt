Shopee (XiaPi) Follow Prize (en la misma serie que linkfox-shopee-store-auth), reenviado a través de /shopee/developerProxy, incluye las seis interfaces del módulo Shopee Open API Follow Prize: add_follow_prize, get_follow_prize_list, get_follow_prize_detail, update_follow_prize, end_follow_prize, delete_follow_prize. Se activa cuando el usuario menciona Shopee Follow Prize, Follow Prize, cupones de seguimiento para recibir, add_follow_prize, Campaign_id o beneficios para fanáticos. Incluso si el "Premio Seguir" no se menciona explícitamente, cualquier participación en la gestión de las actividades del Premio Seguir para una tienda Shopee autorizada debería activarlo.
