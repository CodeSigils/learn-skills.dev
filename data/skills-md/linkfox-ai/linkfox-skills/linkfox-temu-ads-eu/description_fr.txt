API d'annonces de commerce électronique du site Temu Europe, transmise via la passerelle LinkFox aux interfaces bg/temu liées aux annonces partenaires EU Ads/à la diffusion publicitaire (campagnes publicitaires, groupes d'annonces, créations, rapports, enchères budgétaires, etc. ; les interfaces seront intégrées une par une selon la documentation du partenaire). Déclenché lorsque les utilisateurs mentionnent les annonces Temu EU, les annonces, la diffusion publicitaire, la campagne publicitaire, le groupe d'annonces, la création, les enchères, le budget, le rapport publicitaire, la campagne publicitaire, les annonces d'inventaire de produits. Utilisez linkfox-temu-manage-product-eu pour la gestion des produits ; linkfox-temu-promotion-eu pour les promotions ; linkfox-temu-order-eu pour les commandes.
