API d'annonces de commerce électronique du site Temu Europe, transmise via la passerelle LinkFox aux interfaces bg/temu liées aux annonces/placements publicitaires du partenaire EU (campagnes publicitaires, groupes d'annonces, créations, rapports, enchères budgétaires, etc. ; les interfaces seront intégrées étape par étape selon la documentation du partenaire). Déclenchez-vous lorsqu'un utilisateur mentionne les annonces Temu EU, les annonces, l'emplacement publicitaire, la campagne publicitaire, le groupe d'annonces, la création, les enchères, le budget, le rapport publicitaire, la campagne publicitaire, les annonces d'inventaire de produits. Utilisez linkfox-temu-manage-product-eu pour la gestion des produits ; linkfox-temu-promotion-eu pour les promotions ; linkfox-temu-order-eu pour les commandes.
