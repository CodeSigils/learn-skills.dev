API рекламы электронной коммерции на сайте Temu Europe, пересылаемый через шлюз LinkFox партнерским интерфейсам bg/temu, связанным с рекламой/размещением рекламы в ЕС (рекламные кампании, группы объявлений, креативы, отчеты, бюджетные ставки и т. д.; интерфейсы будут интегрироваться шаг за шагом в соответствии с документацией партнера). Срабатывает, когда пользователь упоминает объявления Temu EU, рекламу, размещение рекламы, рекламную кампанию, группу объявлений, креатив, ставки, бюджет, отчет о рекламе, рекламную кампанию, рекламу ассортимента товаров. Используйте linkfox-temu-manage-product-eu для управления продуктами; linkfox-temu-promotion-eu для рекламных акций; ссылкаfox-temu-order-eu для заказов.
