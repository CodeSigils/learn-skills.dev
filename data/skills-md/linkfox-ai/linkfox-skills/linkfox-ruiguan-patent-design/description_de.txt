Basierend auf der Erkennung von Design- und Patentverletzungen von Ruiguan unterstützt es Bildpatentrecherchen in über 25 Ländern/Regionen. This capability is triggered when a user mentions design‑patent detection, patent‑infringement checking, patent‑risk analysis, TRO case queries, design‑patent searching, design‑patent similarity, product‑patent screening, design‑patent detection, patent infringement, design patent, TRO cases, patent risk, patent search, or Ruiguan. Even if the user does not explicitly refer to “design patents,” as long as the request involves checking whether a product image might infringe an existing design patent, or mentions keywords such as infringement, patent, TRO, design patent, etc., this capability should be activated.
