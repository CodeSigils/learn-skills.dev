Shopee (XiaPi) FBS Brazil warehousing (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy aux quatre interfaces du module Shopee Open API FBS : query_br_shop_enrollment_status, query_br_shop_invoice_error, query_br_shop_block_status, query_br_sku_block_status. Il est déclenché lorsqu'un utilisateur mentionne Shopee FBS, Brazil FBS, le statut d'inscription de la boutique, une erreur de facture, le statut de blocage ou query_br_shop_enrollment_status. Même si « FBS » n'est pas explicitement mentionné, tant que la requête concerne le statut d'inscription/blocage/facture du FBS d'une boutique Shopee Brésil autorisée, elle doit également être déclenchée.
