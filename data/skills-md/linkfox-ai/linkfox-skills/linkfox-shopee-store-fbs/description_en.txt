Shopee (XiaPi) FBS Brazil warehousing (in the same series as linkfox-shopee-store-auth), forwarded via /shopee/developerProxy to the Shopee Open API FBS module's four interfaces: query_br_shop_enrollment_status, query_br_shop_invoice_error, query_br_shop_block_status, query_br_sku_block_status. It is triggered when a user mentions Shopee FBS, Brazil FBS, shop enrollment status, invoice error, block status, or query_br_shop_enrollment_status. Even if "FBS" is not explicitly mentioned, as long as the query concerns the enrollment/block/invoice status of an authorized Shopee Brazil shop's FBS, it should also be triggered.
