قم بتحليل أسواق أمازون الفرعية بعمق حسب رقم ASIN للمنتج، مع تغطية مستوى الاحتكار وتركيز العلامة التجارية ومعدل نجاح المنتج الجديد ونقاط الفرص في السوق. يتم تشغيل هذه المهارة عندما يذكر المستخدم تحليل السوق الفرعية المستند إلى ASIN، أو أبحاث السوق الخاصة بـ ASIN، أو الاستعلام عن ASIN المتخصصة، أو تقييم الاحتكارات، أو تحليل تركيز العلامة التجارية، أو معدل نجاح المنتج الجديد، أو تسجيل الطلب في السوق، أو المشهد التنافسي، أو استكشاف سوق Amazon الفرعية، أو تحليل ASIN المتخصصة، أو المتخصصة حسب ASIN، أو مستوى الاحتكار، أو تركيز العلامة التجارية، أو معدل نجاح المنتج الجديد، أو نقاط الفرص في السوق، أو المشهد التنافسي، أو بيانات Jiimore. حتى إذا لم يذكر المستخدم صراحةً "السوق الفرعية" أو "رقم ASIN"، طالما أن الطلب يتضمن تقييم المشهد التنافسي أو كثافة العلامة التجارية أو الفرص المحتملة لسوق فرعية استنادًا إلى رقم ASIN للمنتج، فيجب تفعيل هذه المهارة.
