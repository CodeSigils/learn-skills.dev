TikTok Shopの公開製品の詳細をクエリします。完全な製品 URL または 19 桁の製品 ID を入力すると、米国、英国、東南アジア、およびヨーロッパの主要なサイトを指定できます。製品タイトル、カテゴリ、価格、販売量、SKU 在庫、画像、店舗、レビュー概要、物流、プロモーションなどのグループ化されたデータを返します。このスキルは、ユーザーが TikTok ショップの製品の詳細、TikTok 製品リンクの解析、製品 ID の検索、価格と在庫の確認、SKU のバリエーション、競合他社のページの内訳、TikTok 製品の詳細、または TikTok ショップのリストの検索に言及したときにトリガーされます。ユーザーが「製品の詳細」と明示的に言わなくても、TikTok Shop の製品 URL または 19 桁の製品 ID に基づいて現在の公開製品ページ データを取得したい限り、このスキルを有効にする必要があります。
