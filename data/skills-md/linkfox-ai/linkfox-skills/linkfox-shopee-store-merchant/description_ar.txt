معلومات التاجر عبر الحدود الخاصة بـ Shopee (Xia Pi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، يتم إعادة توجيهها من خلال/shopee/developerProxy إلى جميع نقاط نهاية وحدة Shopee Open API Merchant الست: get_merchant_info، get_shop_list_by_merchant، get_merchant_warehouse_list، get_merchant_warehouse_location_list، get_warehouse_eligible_shop_list، get_merchant_prepay_account_list. يتم تشغيله عندما يذكر المستخدم تاجر Shopee، أو معرف التاجر، أو البائع عبر الحدود، أو CNSC، أو قائمة متاجر التاجر، أو get_merchant_info، أو مستودع التاجر، أو حساب الدفع المسبق. حتى إذا لم يتم ذكر "التاجر" صراحةً، طالما أن الاستعلام يتضمن معلومات عن تاجر معتمد عبر الحدود من Shopee أو قائمة المتاجر التابعة له، فيجب تشغيله.
