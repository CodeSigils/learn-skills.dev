تتضمن معلومات التاجر عبر الحدود الخاصة بـ Shopee (Xia Pi) (في نفس السلسلة مثل linkfox‑shopee‑store‑auth)، التي تتم إعادة توجيهها من خلال /shopee/developerProxy، جميع الواجهات الستة لوحدة Shopee Open API Merchant: get_merchant_info، وget_shop_list_by_merchant، وget_merchant_warehouse_list، وget_merchant_warehouse_location_list، و get_warehouse_eligible_shop_list وget_merchant_prepay_account_list. يتم تشغيله عندما يذكر المستخدم تاجر Shopee، أو معرف التاجر، أو البائع عبر الحدود، أو CNSC، أو قائمة متاجر التاجر، أو get_merchant_info، أو مستودع التاجر، أو حساب الدفع المسبق. حتى إذا لم يتم ذكر "التاجر" صراحةً، فإن أي استفسار حول معلومات التاجر المعتمد عبر الحدود في Shopee أو قائمة المتاجر التابعة له يجب أن يتم تشغيله أيضًا.
