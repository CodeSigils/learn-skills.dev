Les informations sur les marchands transfrontaliers Shopee (XiaPi) (même série que linkfox‑shopee‑store‑auth), transmises via /shopee/developerProxy, incluent les six interfaces du module Shopee Open API Merchant : get_merchant_info, get_shop_list_by_merchant, get_merchant_warehouse_list, get_merchant_warehouse_location_list, get_warehouse_eligible_shop_list et get_merchant_prepaid_account_list. Déclenchez lorsque l'utilisateur mentionne le commerçant Shopee, le MerchantId, le vendeur transfrontalier, la CCSN, la liste des boutiques du commerçant, get_merchant_info, l'entrepôt du commerçant ou le compte prépayé. Même si « marchand » n'est pas explicitement mentionné, toute requête concernant les informations sur les commerçants transfrontaliers Shopee autorisés ou la liste de leurs magasins subordonnés devrait également être déclenchée.
