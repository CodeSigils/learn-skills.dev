استخدم أداة EHunt MCP `_ehunt_productQuery` (اسم العرض "استعلام منتج Etsy") لتصفية عناصر Etsy عبر أبعاد متعددة (الكلمة الرئيسية/عنوان URL، السعر، حجم المبيعات، المفضلة، المراجعات، تاريخ الإدراج، الفئة، النوع مثل صناعة يدوية/عتيقة، اختيار/الأفضل مبيعًا/Raving، وما إلى ذلك). يتم تشغيله عندما يذكر المستخدم منتج EHunt Etsy، أو قائمة Etsy، أو تحديد Etsy، أو عنصر Etsy الساخن، أو Etsy handmade، أو Etsy Vintage، أو عناصر ehunt، أو الاستعلام عن منتج Etsy، أو `_ehunt_productQuery`. حتى لو لم يكتب المستخدم "EHunt"، طالما أنه يبحث عن المنتجات على Etsy، أو يعرض المبيعات/السعر/العلامات، أو يقوم بتصفية العناصر، فيجب تفعيل هذه المهارة.
