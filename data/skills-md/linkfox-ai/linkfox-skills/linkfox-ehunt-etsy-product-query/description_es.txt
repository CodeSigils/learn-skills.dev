Utilice la herramienta EHunt MCP `_ehunt_productQuery` (nombre para mostrar “Consulta de producto de Etsy”) para filtrar artículos de Etsy en múltiples dimensiones (palabra clave/URL, precio, volumen de ventas, favoritos, reseñas, fecha de publicación, categoría, tipo como hecho a mano/vintage, Pick/Bestsell/Raving, etc.). Se activa cuando el usuario menciona el producto EHunt Etsy, el listado de Etsy, la selección de Etsy, el artículo popular de Etsy, el hecho a mano de Etsy, el vintage de Etsy, los artículos de ehunt, la consulta de productos de Etsy o "_ehunt_productQuery". Incluso si el usuario no escribe "EHunt", siempre que busque productos en Etsy, vea ventas/precios/etiquetas o filtre artículos, esta habilidad debe activarse.
