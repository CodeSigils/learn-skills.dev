Shopee (Shopee) bundle discount Bundle Deal (dans la même série que linkfox-shopee-store-auth), transmis via /shopee/developerProxy, comprend les 10 interfaces du module Shopee Open API Bundle Deal : add_bundle_deal, get_bundle_deal_list, add_bundle_deal_item, update_bundle_deal, end_bundle_deal, etc. Il est déclenché lorsqu'un utilisateur mentionne Remise groupée Shopee, offre groupée, promotion combinée, add_bundle_deal, bundle_deal_id ou remise sur l'article complet. Même si « bundle » n'est pas explicitement mentionné, tant qu'il implique la gestion des activités Bundle Deal pour une boutique Shopee agréée, il doit être déclenché.
