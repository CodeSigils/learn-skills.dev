صفقة حزمة Shopee (XiaPi) (في نفس السلسلة مثل linkfox-shopee-store-auth)، تم إعادة توجيهها عبر /shopee/developerProxy إلى وحدة صفقة حزمة Shopee Open API التي تغطي جميع الواجهات العشر: add_bundle_deal، get_bundle_deal_list، add_bundle_deal_item، update_bundle_deal، end_bundle_deal، وما إلى ذلك. يذكر Shopee Bundle Deal، أو Bundle Deal، أو الترويج المجمع، أو add_bundle_deal، أو Bundle_deal_id، أو خصم العنصر الكامل، فإنه يتم تشغيله. حتى لو لم يتم ذكر "الحزمة" صراحةً، طالما أنها تتضمن إدارة أنشطة Bundle Deal لمتجر Shopee معتمد، فيجب تفعيلها أيضًا.
