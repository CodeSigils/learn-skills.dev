API di conformità (conformità) e-commerce del sito globale Temu, inoltrata tramite il gateway LinkFox all'OpenAPI relativa alla conformità di Partner Global (bg.compliance.*, bg.arbok.open.*, bg.flash.open.*, ecc., per un totale di nove endpoint). Viene attivato quando un utente menziona la conformità globale di Temu, le qualifiche del prodotto, il GPSR, gli attributi di governance, le immagini reali, i caricamenti delle qualifiche, bg.compliance.edit, arbok cert o site=conformità globale.
