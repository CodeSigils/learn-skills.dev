API управления продуктами на сайте Temu в США (управление продуктом), пересылаемый через шлюз LinkFox на 24 интерфейса bg.local/temu.local партнера в США: список продуктов/детали/запрос SKU, частичное/полное редактирование, удаление, инвентаризация, листинг/исключение из списка, предварительная продажа, предварительная проверка категории, шаблоны атрибутов, соответствие требованиям, внешние коды, видеообложки и т. д. Когда пользователи упоминают Temu US Manage Product, bg.local.goods, product внесение в список/исключение из списка, изменение запасов, удаление продукта, редактирование соответствия требованиям или документация по управлению продуктами партнера в США, он срабатывает. Используйте linkfox-temu-add-product-us для публикации продуктов; **цена/цена предложения** использует **linkfox-temu-price-us**; **рекламная/маркетинговая деятельность** использует **linkfox-temu-promotion-us**; **рекламные объявления** используют **linkfox-temu-ads-us**; **заказы** используйте **linkfox-temu-order-us**; Для **самостоятельных поставок** используйте **linkfox-temu-fulfillment-us**; **отмена покупателя** использует **linkfox-temu-cancel-order-us**; **отмена продавца** использует **linkfox-temu-cancel-order-us**.
