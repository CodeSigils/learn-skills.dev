API de gestion des produits du site Temu US (Gérer le produit), transmise via la passerelle LinkFox aux 24 interfaces bg.local/temu.local du partenaire américain : liste de produits/détails/requête SKU, modification partielle/complète, suppression, inventaire, mise en vente/délistation, prévente, pré-vérification de catégorie, modèles d'attributs, conformité, codes externes, couvertures vidéo, etc. Lorsque les utilisateurs mentionnent Temu US Manage Product, bg.local.goods, liste/délistation de produits, inventaire modifications, suppression de produit, modification de conformité ou documentation de gestion de produit Partner US, il se déclenche. Utilisez linkfox-temu-add-product-us pour publier des produits ; **prix/prix de l'offre** utilise **linkfox-temu-price-us** ; **activités de promotion/marketing** utilise **linkfox-temu-promotion-us** ; **Annonces publicitaires** utilise **linkfox-temu-ads-us** ; **commandes** utilisez **linkfox-temu-order-us** ; **Envois auto-expédiés** utilisez **linkfox-temu-fulfillment-us** ; **l'annulation de l'acheteur** utilise **linkfox-temu-cancel-order-us** ; **l'annulation du vendeur** utilise **linkfox-temu-cancel-order-us**.

Veuillez toujours répondre dans la langue de l'utilisateur.
