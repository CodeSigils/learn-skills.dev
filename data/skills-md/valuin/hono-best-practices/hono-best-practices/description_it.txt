Modelli di produzione per i backend Hono v4+ con Bun, Drizzle ORM, Better Auth, Stoker, hono-openapi + Zod + Scalar e TDD con il test runner Bun. Da utilizzare durante la creazione di funzionalità, la scrittura di test, la revisione del codice o l'impostazione di autenticazione/RBAC in progetti Hono monolitici modulari. Applica ogni volta che vedi definizioni di route Hono, createRouter(), descriptionRoute(), Better Auth config, importazioni di Stoker o file di test Bun in questo stack. Da utilizzare anche quando si aggiungono nuovi moduli, si scrivono specifiche OpenAPI o si esegue il debug di problemi del middleware di autenticazione.
