Laden Sie diesen Skill, bevor Sie einen Fix für eine Barriere implementieren, die ihren Ursprung in einer gemeinsam genutzten Komponente, einem Designsystem, einem Renderer oder einer externen Abhängigkeit und nicht im eigenen Code dieses Projekts haben kann. Entscheiden Sie, ob der verantwortliche Fix lokal, eine bereits installierte Funktion oder ein Upstream-Beitrag ist, bevor Sie eine Problemumgehung schreiben. Notieren Sie unbedingt immer alle vorübergehenden lokalen Abweichungen von Eigentümer und Entfernungsbedingung. Öffnen, kommentieren oder übermitteln Sie unter keinen Umständen etwas in einem externen Projekt ohne ausdrückliche menschliche Genehmigung.
