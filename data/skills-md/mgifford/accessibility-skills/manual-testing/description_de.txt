Laden Sie diesen Skill immer dann, wenn Sie manuelle Barrierefreiheitstests planen, ausführen oder überprüfen. Manuelle Tests mit echten Hilfstechnologien sind unerlässlich – automatisierte Tools erkennen nur etwa 30–40 % der WCAG-Probleme. Führen Sie unbedingt immer nur einen Tastaturtest und mindestens einen Screenreader-Test durch, bevor Sie eine Funktion als barrierefrei markieren. Überspringen Sie unter keinen Umständen das Testen des erzwungenen Farbmodus für UI-Komponenten.
