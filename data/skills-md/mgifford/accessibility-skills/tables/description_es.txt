Cargue esta habilidad siempre que el proyecto contenga tablas de datos HTML (elementos <table>). Bajo ninguna circunstancia utilice tablas para fines de diseño. Absolutamente siempre incluya elementos <th> con atributos de alcance apropiados, un <caption> o aria-labelledby, y asegúrese de que las tablas complejas tengan encabezados asociados con celdas de datos. Aplique estas reglas a todas las tablas de datos sin excepción.
