Carica questa competenza durante la creazione di funzionalità Web, la revisione delle decisioni sull'architettura o la valutazione delle dipendenze JavaScript. In nessun caso creare funzionalità che si interrompono completamente quando JavaScript non è disponibile o fallisce. Inizia assolutamente sempre con HTML semantico, miglioramenti CSS a livello e aggiungi JavaScript come livello finale facoltativo. Dai priorità alla resilienza e all'accesso universale rispetto alle funzionalità all'avanguardia.
