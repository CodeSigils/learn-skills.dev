Используйте этот навык при создании любой веб-функции, проверке архитектурных решений или оценке зависимостей JavaScript. Ни при каких обстоятельствах не создавайте функции, которые полностью ломаются, когда JavaScript недоступен или дает сбой. Абсолютно всегда начинайте с семантического HTML, улучшений CSS слоев и добавляйте JavaScript в качестве последнего, необязательного слоя. Отдавайте предпочтение устойчивости и универсальному доступу перед передовыми функциями.
