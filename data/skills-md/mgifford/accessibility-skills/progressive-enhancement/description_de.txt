Laden Sie diesen Skill, wenn Sie eine Webfunktion erstellen, Architekturentscheidungen überprüfen oder JavaScript-Abhängigkeiten bewerten. Erstellen Sie unter keinen Umständen Funktionen, die vollständig kaputt gehen, wenn JavaScript nicht verfügbar ist oder fehlschlägt. Beginnen Sie unbedingt immer mit semantischem HTML, schichten Sie CSS-Verbesserungen ein und fügen Sie JavaScript als letzte, optionale Ebene hinzu. Priorisieren Sie Ausfallsicherheit und universellen Zugriff gegenüber modernsten Funktionen.
