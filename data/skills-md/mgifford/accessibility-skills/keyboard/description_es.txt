Cargue esta habilidad para cada proyecto que contenga elementos interactivos de la interfaz de usuario: botones, enlaces, modales, menús desplegables, controles deslizantes, pestañas, carruseles o cualquier widget personalizado. Bajo ninguna circunstancia cree un componente interactivo que no pueda operarse completamente solo con el teclado. Asegúrese siempre de tener indicadores de enfoque visibles, orden de tabulación lógico y ausencia de trampas de teclado. Aplique estas reglas a todos los elementos interactivos sin excepción.
