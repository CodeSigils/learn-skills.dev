Laden Sie diesen Skill für jedes Projekt, das interaktive UI-Elemente enthält – Schaltflächen, Links, Modalitäten, Dropdowns, Schieberegler, Registerkarten, Karussells oder jedes benutzerdefinierte Widget. Erstellen Sie unter keinen Umständen eine interaktive Komponente, die nicht vollständig über die Tastatur allein bedient werden kann. Achten Sie unbedingt immer auf sichtbare Fokusanzeigen, eine logische Tab-Reihenfolge und keine Tastaturfallen. Wenden Sie diese Regeln ausnahmslos auf jedes interaktive Element an.
