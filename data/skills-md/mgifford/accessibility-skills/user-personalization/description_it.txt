Carica questa competenza ogni volta che il progetto dispone di funzionalità di personalizzazione, controlli delle preferenze dell'utente, selettori di temi, regolatori della dimensione del carattere, attivatori/disattivatori di movimento, impostazioni di contrasto o qualsiasi sistemazione di accessibilità configurabile dall'utente. In nessun caso sovrascrivere o ignorare le preferenze di accessibilità a livello di sistema operativo dell'utente senza il consenso esplicito dell'utente. Perseverare assolutamente sempre le preferenze dell'utente, applicarle immediatamente e rispettare le preferenze di movimento ridotto, di contrasto e simili query multimediali.
