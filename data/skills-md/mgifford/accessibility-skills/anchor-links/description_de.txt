Laden Sie diesen Skill immer dann, wenn das Projekt In-Page-Anker-Links, Skip-Links, Fragment-IDs oder Überschriften-Links enthält. Lassen Sie unter keinen Umständen die Anforderungen an barrierefreie Ankerlinks außer Acht, wenn solche Links vorhanden sind. Stellen Sie sicher, dass jeder Ankerlink einen aussagekräftigen Text, ein erreichbares Ziel und einen sichtbaren Fokusindikator enthält. Wenden Sie diese Regeln an, wenn Sie eine In-Page-Navigation erstellen oder überprüfen.
