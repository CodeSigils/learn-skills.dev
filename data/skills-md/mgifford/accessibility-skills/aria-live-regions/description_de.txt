Laden Sie diesen Skill immer dann, wenn das Projekt dynamische Inhaltsaktualisierungen, Statusmeldungen, Warnungen, Benachrichtigungen, Ladeindikatoren oder eine Verwendung von aria-live, Role="status", Role="alert" oder Role="log" enthält. Fügen Sie unter keinen Umständen Live-Region-Markup hinzu oder ändern Sie es, ohne diese Regeln anzuwenden. Priorisieren Sie die richtige Höflichkeit und vermeiden Sie überflüssige Ansagen. Verwenden Sie niemals eine Problemumgehung mit fester Verzögerung zum Löschen und erneuten Einfügen – es gibt keine Standardgarantie dafür, dass es funktioniert.
