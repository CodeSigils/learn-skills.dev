Загружайте этот навык всякий раз, когда проект содержит компоненты всплывающей подсказки, всплывающие информационные окна, запускаемые при наведении курсора, всплывающие подсказки атрибутов заголовка или любой контент, отображаемый при наведении курсора или фокусе. Ни при каких обстоятельствах не создавайте всплывающие подсказки, которые активируются только при наведении курсора без доступа, эквивалентного клавиатуре. Всегда следите за тем, чтобы всплывающие подсказки были понятными, достаточно постоянными для чтения и не являлись единственным источником важной информации.
