Руководство по разработке приложений для iOS, охватывающее UIKit, SnapKit и SwiftUI. Включает сенсорные объекты, безопасные области, шаблоны навигации, динамический тип, темный режим, специальные возможности, представления коллекций, общие компоненты пользовательского интерфейса и рекомендации по дизайну SwiftUI. Подробные ссылки по конкретным темам см. в справочных файлах.
Используйте при разработке приложений для iOS, реализации пользовательского интерфейса, проверке кода iOS, работе с макетами UIKit/SnapKit/SwiftUI, создании интерфейсов iPhone, разработке мобильных устройств на Swift, соблюдении требований Apple HIG, реализации специальных возможностей iOS.
