Guide de développement d'applications iOS couvrant UIKit, SnapKit et SwiftUI. Comprend les cibles tactiles, les zones de sécurité, les modèles de navigation, le type dynamique, le mode sombre, l'accessibilité, les vues de collection, les composants d'interface utilisateur courants et les directives de conception SwiftUI. Pour des références détaillées sur des sujets spécifiques, consultez les fichiers de référence.
À utiliser pour : le développement d'applications iOS, la mise en œuvre de l'interface utilisateur, la révision du code iOS, l'utilisation des mises en page UIKit/SnapKit/SwiftUI, la création d'interfaces iPhone, le développement mobile Swift, la conformité Apple HIG, la mise en œuvre de l'accessibilité iOS.
