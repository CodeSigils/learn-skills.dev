Creación, edición y formateo profesional de documentos DOCX utilizando OpenXML SDK (.NET). Tres procesos: (A) crear nuevos documentos desde cero, (B) completar/editar contenido en documentos existentes, (C) aplicar formato de plantilla con verificación de validación XSD. DEBE usar esta habilidad siempre que el usuario desee producir, modificar o formatear un documento de Word, incluso cuando diga "escribir un informe", "redactar una propuesta", "hacer un contrato", "rellenar este formulario", "formatear para que coincida con esta plantilla" o cualquier tarea cuyo resultado final sea un archivo .docx. Incluso si el usuario no menciona "docx" explícitamente, si la tarea implica un documento imprimible/formal, utilice esta habilidad.
