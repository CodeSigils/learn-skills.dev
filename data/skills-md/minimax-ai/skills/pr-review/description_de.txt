Überprüfen Sie Pull-Anfragen für das MiniMax Skills-Repository. Verwenden Sie diese Option, wenn Sie PRs überprüfen, neue Skill-Einreichungen validieren oder bestehende Skills auf Konformität überprüfen. Führen Sie zunächst das Validierungsskript für harte Prüfungen aus und wenden Sie dann Qualitätsrichtlinien für die Inhaltsüberprüfung an. Auslöser: PR-Review, Pull-Request, Skill validieren, Skill prüfen.
