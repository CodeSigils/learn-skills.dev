Guía de desarrollo de React Native y Expo que cubre componentes, estilo, animaciones, navegación,
gestión de estado, formularios, redes, optimización del rendimiento, pruebas, capacidades nativas,
e ingeniería (estructura del proyecto, implementación, actualizaciones de SDK, CI/CD).
Úselo cuando: cree aplicaciones React Native o Expo, implemente animaciones o UI nativa, administre
estado, obtención de datos, redacción de pruebas, optimización del rendimiento, implementación en App Store/Play Store,
configurar CI/CD, actualizar Expo SDK o configurar Tailwind/NativeWind.
