Guida allo sviluppo di React Native ed Expo che copre componenti, stile, animazioni, navigazione,
gestione dello stato, moduli, networking, ottimizzazione delle prestazioni, test, funzionalità native,
e ingegneria (struttura del progetto, distribuzione, aggiornamenti SDK, CI/CD).
Utilizzare quando: creazione di app React Native o Expo, implementazione di animazioni o interfaccia utente nativa, gestione
stato, recupero dati, scrittura di test, ottimizzazione delle prestazioni, distribuzione su App Store/Play Store,
impostare CI/CD, aggiornare Expo SDK o configurare Tailwind/NativeWind.
