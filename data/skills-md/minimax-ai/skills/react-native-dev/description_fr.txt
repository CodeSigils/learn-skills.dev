Guide de développement React Native et Expo couvrant les composants, le style, les animations, la navigation,
gestion de l'état, formulaires, mise en réseau, optimisation des performances, tests, capacités natives,
et ingénierie (structure du projet, déploiement, mises à niveau du SDK, CI/CD).
À utiliser lorsque : créer des applications React Native ou Expo, implémenter des animations ou une interface utilisateur native, gérer
état, récupération de données, rédaction de tests, optimisation des performances, déploiement sur App Store/Play Store,
configuration de CI/CD, mise à niveau du SDK Expo ou configuration de Tailwind/NativeWind.
