Analice, describa y extraiga información de imágenes utilizando la herramienta MCP de visión MiniMax. Úselo cuando: el usuario comparte una ruta de archivo de imagen o URL (cualquier mensaje que contenga una extensión de archivo .jpg, .jpeg, .png, .gif, .webp, .bmp o .svg) o usa cualquiera de estas palabras/frases cerca de una imagen: "analizar", "analizar", "describir", "explicar", "comprender", "mirar", "revisar", "extraer texto", "OCR", "qué hay en", "qué hay en", "leer esta imagen", "ver esta imagen", "cuéntame sobre", "explica esto", "interpreta esto", en conexión con una imagen, captura de pantalla, diagrama, gráfico, maqueta, estructura alámbrica o fotografía. También desencadenantes para: revisión de maquetas de UI, análisis de estructura alámbrica, crítica de diseño, extracción de datos de gráficos, detección de objetos, identificación de persona/animal/actividad. Activadores: cualquier mensaje con una extensión de archivo de imagen (jpg, jpeg, png, gif, webp, bmp, svg), o cualquier solicitud para analizar/describir/comprender/revisar/extraer texto de una imagen, captura de pantalla, diagrama, gráfico, foto, maqueta o estructura alámbrica.
