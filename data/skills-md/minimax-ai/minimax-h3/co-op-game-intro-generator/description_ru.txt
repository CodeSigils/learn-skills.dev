Для пользователей, создающих меню совместной игры для двух игроков или открывающую анимацию. Пользователи предоставляют два имени игрока, название игры, целевой визуальный стиль и дополнительные эталонные изображения персонажей. Навык блокирует идентификационные сигналы, генерирует изображение одобрения из фиксированной структуры меню с согласованным цветом, кнопками, значками и типографикой, а затем использует утвержденный результат для перестройки персонажа, копии пользовательского интерфейса и инструкций по времени событий для окончательного видео. Он выводит вступительную часть совместной игры с двумя персонажами, карточками игроков и движением взаимодействия с меню. Лучше всего подходит для игровых концепций, меню с участием персонажей и социального контента; не для разработки игровых игр, сложного многостраничного пользовательского интерфейса, точного повторения логотипа бренда или общих последовательностей заголовков без символов.
