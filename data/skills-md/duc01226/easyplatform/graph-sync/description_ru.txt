[Интеллект кода] Синхронизируйте график знаний проверки кода с текущим состоянием git. Обнаруживает файлы, измененные с момента последней синхронизации с помощью git diff, и повторно анализирует их. Запускается автоматически при запуске сеанса; используйте вручную после извлечения кода или переключения ветвей.
