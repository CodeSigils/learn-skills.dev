macOS 上で UTM 仮想マシン アプリを操作します。VM の一覧表示、作成、開始、停止、一時停止、クローン作成、削除、インポートおよびエクスポートを行います。ゲスト内でコマンドを実行し、ファイルを転送し、ゲスト IP をクエリし、キーボードまたはマウス入力を送信し、USB デバイスを転送し、VM 構成を検査または更新します。ユーザーが UTM、utmctl、.utm バンドル、「UTM アプリ」、Mac 上の QEMU、または UTM 経由の Apple Virtualization.framework について言及する場合、またはシェルまたは AppleScript から macOS でホストされる VM を自動化したい場合に使用します。 QEMU バックエンド (クロスアーキテクチャ エミュレーション) と Apple Virtualization バックエンド (Apple Silicon 上のネイティブ macOS/Linux) の両方をカバーします。
