Opera la aplicación de máquina virtual UTM en macOS: enumera, crea, inicia, detiene, suspende, clona, ​​elimina, importa y exporta máquinas virtuales; ejecuta comandos dentro de un invitado, transfiere archivos, consulta direcciones IP de invitados, envía entradas de teclado o mouse, reenvía dispositivos USB e inspecciona o actualiza la configuración de VM. Úselo cuando el usuario mencione paquetes UTM, utmctl, .utm, "la aplicación UTM", QEMU en una Mac o Apple Virtualization.framework a través de UTM, o quiera automatizar máquinas virtuales alojadas en macOS desde el shell o AppleScript. Cubre tanto el backend de QEMU (emulación entre arquitecturas) como el backend de virtualización de Apple (macOS/Linux nativo en Apple Silicon).
