在 macOS 上操作 UTM 虛擬機器應用程式 — 列出、建立、啟動、停止、掛起、複製、刪除、匯入和匯出 VM；在來賓內部執行命令、傳輸檔案、查詢來賓 IP、傳送鍵盤或滑鼠輸入、轉發 USB 裝置以及檢查或更新 VM 配置。當使用者提及 UTM、utmctl、.utm 捆綁包、「UTM 應用程式」、Mac 上的 QEMU 或透過 UTM 的 Apple Virtualization.framework，或想要從 shell 或 AppleScript 自動化 macOS 託管的 VM 時使用。涵蓋 QEMU 後端（跨架構模擬）和 Apple 虛擬化後端（Apple Silicon 上的本機 macOS/Linux）。
