Operates the UTM virtual machine app on macOS — lists, creates, starts, stops, suspends, clones, deletes, imports and exports VMs;在來賓內部運行命令、傳輸文件、查詢來賓 IP、發送鍵盤或滑鼠、轉發、轉發、配置以及輸入或 VM 設備以及設定。當使用者提及 UTM、utmctl、.utm 捆綁包、「UTM 應用程式」、Mac 上的 QEMU 或透過 UTM 的 Apple Virtualization.framework，或想要從 shell 或 AppleScript 自動化 macOS 託管的 VM 時使用。 Covers both the QEMU backend (cross-architecture emulation) and the Apple Virtualization backend (native macOS/Linux on Apple Silicon).
