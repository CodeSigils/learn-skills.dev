在 macOS 上操作 UTM 虚拟机应用程序 — 列出、创建、启动、停止、挂起、克隆、删除、导入和导出 VM；在来宾内部运行命令、传输文件、查询来宾 IP、发送键盘或鼠标输入、转发 USB 设备以及检查或更新 VM 配置。当用户提及 UTM、utmctl、.utm 捆绑包、“UTM 应用程序”、Mac 上的 QEMU 或通过 UTM 的 Apple Virtualization.framework，或者想要从 shell 或 AppleScript 自动化 macOS 托管的 VM 时使用。涵盖 QEMU 后端（跨架构仿真）和 Apple 虚拟化后端（Apple Silicon 上的本机 macOS/Linux）。
