Einheitliche Anwendungssicherheitsfähigkeit für Coding Agent-Systeme wie OpenCode. Wird zum Überprüfen oder Schreiben von Code verwendet, der Authentifizierung, Autorisierung, Benutzereingaben, Zahlungen, Datenbankzugriff, Geheimnisse, Bereitstellung, Abhängigkeiten oder KI-/Agent-Workflows berührt. Beinhaltet OWASP Top 10 (2025), ASVS 5.0-Highlights, Agenten-KI-Sicherheit, Vibe-codierte Fallstricke, unsichere Standarderkennung, Lieferketten-Risikosignale und CI/CD-Agenten-Aktionshärtung.
