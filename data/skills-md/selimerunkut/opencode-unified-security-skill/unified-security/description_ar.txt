مهارة أمان التطبيق الموحدة لأنظمة وكيل الترميز مثل OpenCode. يُستخدم عند مراجعة أو كتابة تعليمات برمجية تتعلق بالمصادقة أو الترخيص أو إدخال المستخدم أو المدفوعات أو الوصول إلى قاعدة البيانات أو الأسرار أو النشر أو التبعيات أو سير عمل الذكاء الاصطناعي/الوكيل. يتضمن أفضل 10 OWASP (2025)، وميزات ASVS 5.0، وأمن الذكاء الاصطناعي الوكيل، والمزالق المرمزة، والكشف عن الإعدادات الافتراضية غير الآمنة، وإشارات مخاطر سلسلة التوريد، وتقوية إجراءات وكيل CI/CD.
