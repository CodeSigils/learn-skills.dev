Compétence en matière de sécurité des applications unifiées pour les systèmes Coding Agent comme OpenCode. À utiliser lors de la révision ou de l'écriture de code touchant l'authentification, l'autorisation, la saisie utilisateur, les paiements, l'accès à la base de données, les secrets, le déploiement, les dépendances ou les flux de travail IA/agent. Comprend le Top 10 OWASP (2025), les points forts d'ASVS 5.0, la sécurité de l'IA agentique, les pièges codés par ambiance, la détection des défauts non sécurisés, les signaux de risque de la chaîne d'approvisionnement et le renforcement des actions des agents CI/CD.
