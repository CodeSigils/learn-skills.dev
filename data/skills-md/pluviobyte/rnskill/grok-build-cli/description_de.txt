Rufen Sie die lokal installierte Grok Build-CLI von Codex auf und geben Sie die Antwort von Grok zurück. Wird immer dann verwendet, wenn der Benutzer Codex auffordert, eine Eingabeaufforderung an Grok oder Grok Build aufzurufen, zu konsultieren, auszuführen oder an Grok Build zu delegieren, einschließlich Grok-Web/X-Suchen und Agenten-Grok-Aufgaben. Dieser Skill deckt nur den Aufrufmechanismus, die Prozessüberwachung und die Antworterfassung ab; es schreibt nicht die Aufgabe selbst vor.
