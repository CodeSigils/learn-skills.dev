المهارة: تدقيق مهارات وكيل الذكاء الاصطناعي المثبتة عبر Codex وClaude Code وCursor ومجلدات المهارات المحلية للمشروع الاختيارية. يُستخدم عندما يسأل المستخدم عن المهارات التي تم تثبيتها، وعدد مرات استخدام Claude Code/Codex/Cursor للمهارات، وما إذا كانت المهارة قد تم استخدامها مؤخرًا، أو ما هي المهارات القديمة أو غير المستخدمة، أو يريد توصيات التنظيف/الإزالة/التعطيل للمهارات.
