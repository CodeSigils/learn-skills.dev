Используйте при написании или просмотре JavaScript/TypeScript в этом репозитории, который вызывает API Deepgram Management для проектов, ключи API, участников, приглашения, запросы, использование, выставление счетов, модели и обнаружение моделей мышления агента. Охватывает `client.manage.v1.*` плюс `client.agent.v1.settings.think.models.list()`. Используйте deepgram-js-voice-agent, если вы хотите запустить агент в реальном времени, а не администрировать проекты или проверять модели. Триггеры включают «API управления», «список проектов», «ключи API», «участники», «приглашения», «статистика использования», «выставление счетов», «список моделей» и «manage.v1».
