À utiliser lors de l'écriture ou de la révision de JavaScript/TypeScript dans ce référentiel qui appelle les API Deepgram Management pour les projets, les clés API, les membres, les invitations, les demandes, l'utilisation, la facturation, les modèles et la découverte de modèles de réflexion d'agent. Couvre `client.manage.v1.*` plus `client.agent.v1.settings.think.models.list()`. Utilisez `deepgram-js-voice-agent` lorsque vous souhaitez exécuter un agent en direct plutôt que d'administrer des projets ou d'inspecter des modèles. Les déclencheurs incluent « API de gestion », « liste de projets », « clés API », « membres », « invitations », « statistiques d'utilisation », « facturation », « modèles de liste » et « gérer.v1 ».
