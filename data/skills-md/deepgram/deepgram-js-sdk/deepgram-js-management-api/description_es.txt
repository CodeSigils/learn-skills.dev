Úselo al escribir o revisar JavaScript/TypeScript en este repositorio que llama a las API de Deepgram Management para proyectos, claves de API, miembros, invitaciones, solicitudes, uso, facturación, modelos y descubrimiento de modelos de pensamiento de agentes. Cubre `client.manage.v1.*` más `client.agent.v1.settings.think.models.list()`. Utilice `deepgram-js-voice-agent` cuando desee ejecutar un agente en vivo en lugar de administrar proyectos o inspeccionar modelos. Los activadores incluyen "API de administración", "lista de proyectos", "claves de API", "miembros", "invitaciones", "estadísticas de uso", "facturación", "lista de modelos" y "manage.v1".
