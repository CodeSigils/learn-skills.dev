プロジェクト、API キー、メンバー、招待、リクエスト、使用状況、請求、モデル、エージェントの思考モデル検出のための Deepgram Management API を呼び出すこのリポジトリで JavaScript/TypeScript を作成またはレビューするときに使用します。 「client.manage.v1.*」と「client.agent.v1.settings.think.models.list()」をカバーします。プロジェクトを管理したりモデルを検査したりするのではなく、エージェントをライブで実行したい場合は、「deepgram-js-voice-agent」を使用します。トリガーには、「管理 API」、「プロジェクトのリスト」、「API キー」、「メンバー」、「招待」、「使用状況統計」、「請求」、「モデルのリスト」、および「manage.v1」が含まれます。
