Verwenden Sie es beim Schreiben oder Überprüfen von JavaScript/TypeScript in diesem Repo, das Deepgram-Management-APIs für Projekte, API-Schlüssel, Mitglieder, Einladungen, Anfragen, Nutzung, Abrechnung, Modelle und Agent-Think-Model-Erkennung aufruft. Deckt „client.manage.v1.*“ plus „client.agent.v1.settings.think.models.list()“ ab. Verwenden Sie „deepgram-js-voice-agent“, wenn Sie einen Agenten live ausführen möchten, anstatt Projekte zu verwalten oder Modelle zu prüfen. Zu den Auslösern gehören „Verwaltungs-API“, „Projekte auflisten“, „API-Schlüssel“, „Mitglieder“, „Einladungen“, „Nutzungsstatistiken“, „Abrechnung“, „Modelle auflisten“ und „manage.v1“.
