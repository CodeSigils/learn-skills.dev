Wird beim Schreiben oder Überprüfen von JavaScript/TypeScript in diesem Repo verwendet, das Deepgram Text-to-Speech v1 („/v1/speak“) für die Audiosynthese aufruft. Deckt One-Shot-REST über „client.speak.v1.audio.generate“ und Streaming von WebSocket über „client.speak.v1.createConnection()“ / „connect()“ ab. Verwenden Sie „deepgram-js-voice-agent“, wenn Sie Vollduplex-STT + LLM + TTS anstelle einer Einwegsynthese benötigen. Zu den Auslösern gehören „TTS“, „Text to Speech“, „Speak“, „Aura“, „Streaming TTS“ und „speak.v1“.
