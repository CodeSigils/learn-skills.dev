Используйте при написании или просмотре JavaScript/TypeScript в этом репозитории, который вызывает Deepgram Text-to-Speech v1 (`/v1/speak`) для синтеза звука. Охватывает одноразовый REST через client.speak.v1.audio.generate и потоковую передачу WebSocket через client.speak.v1.createConnection()/connect(). Используйте deepgram-js-voice-agent, когда вам нужен полнодуплексный STT + LLM + TTS вместо одностороннего синтеза. Триггеры включают «TTS», «преобразование текста в речь», «говорение», «ауру», «потоковое TTS» и «speak.v1».
