Используйте при написании или просмотре JavaScript/TypeScript в этом репозитории, который создает интерактивный голосовой агент через `agent.deepgram.com/v1/agent/converse`. Охватывает `client.agent.v1.createConnection()` / `connect()`, `sendSettings`, `sendMedia`, обновления во время выполнения, обработку событий и ответы на вызовы функций. Используйте deepgram-js-text-to-speech для одностороннего синтеза, deepgram-js-speech-to-text или deepgram-js-conversational-stt только для транскрипции и deepgram-js-management-api для администрирования проекта/модели, а не для среды выполнения живого агента. Триггеры включают «голосовой агент», «разговор агента», «полный дуплекс», «вмешательство», «вызов функции» и «agent.v1».
