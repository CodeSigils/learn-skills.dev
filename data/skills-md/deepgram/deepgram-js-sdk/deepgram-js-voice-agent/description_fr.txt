À utiliser lors de l'écriture ou de la révision de JavaScript/TypeScript dans ce référentiel qui crée un agent vocal interactif via `agent.deepgram.com/v1/agent/converse`. Couvre `client.agent.v1.createConnection()` / `connect()`, `sendSettings`, `sendMedia`, les mises à jour d'exécution, la gestion des événements et les réponses aux appels de fonction. Utilisez `deepgram-js-text-to-speech` pour la synthèse unidirectionnelle, `deepgram-js-speech-to-text` ou `deepgram-js-conversational-stt` pour la transcription uniquement, et `deepgram-js-management-api` pour l'administrateur de projet/modèle plutôt que pour l'exécution de l'agent en direct. Les déclencheurs incluent « agent vocal », « agent converse », « full duplex », « intervention », « appel de fonction » et « agent.v1 ».
