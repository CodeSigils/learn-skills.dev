Verwenden Sie es beim Schreiben oder Überprüfen von JavaScript/TypeScript in diesem Repo, das über „agent.deepgram.com/v1/agent/converse“ einen interaktiven Sprachagenten erstellt. Behandelt „client.agent.v1.createConnection()“ / „connect()“, „sendSettings“, „sendMedia“, Laufzeitaktualisierungen, Ereignisbehandlung und Antworten auf Funktionsaufrufe. Verwenden Sie „deepgram-js-text-to-speech“ für die unidirektionale Synthese, „deepgram-js-speech-to-text“ oder „deepgram-js-conversational-stt“ nur für die Transkription und „deepgram-js-management-api“ für die Projekt-/Modellverwaltung anstelle der Live-Agent-Laufzeit. Zu den Auslösern gehören „Voice Agent“, „Agent Converse“, „Full Duplex“, „Barge-In“, „Function Calling“ und „Agent.v1“.
