このリポジトリで、ターンアウェア ストリーミング文字起こしのために Deepgram Conversational STT v2 / Flux (`/v2/listen`) を呼び出す JavaScript/TypeScript を作成またはレビューするときに使用します。 `client.listen.v2.createConnection()` / `connect()`、Flux モデル、および `TurnInfo` などのターン イベントをカバーします。標準 v1 ASR には「deepgram-js-speech-to-text」を使用し、全二重アシスタントには「deepgram-js-voice-agent」を使用します。トリガーには、「フラックス」、「v2 listen」、「会話型 STT」、「ターン検出」、「ターン終了」、「EOT」、および「listen.v2」が含まれます。
