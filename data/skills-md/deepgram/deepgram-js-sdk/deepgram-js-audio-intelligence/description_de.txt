Wird beim Schreiben oder Überprüfen von JavaScript/TypeScript in diesem Repo verwendet, das Deepgram-Audioanalyse-Overlays auf „/v1/listen“ aufruft – Zusammenfassung, Themen, Absichten, Stimmung, Diarize, Schwärzung, Erkennung_Sprache und Entitätserkennung. Gleicher Endpunkt wie einfaches STT, andere Parameter. Deckt REST über „client.listen.v1.media.transcribeUrl“ / „transcribeFile“ und die von WebSocket unterstützte Teilmenge auf „client.listen.v1.createConnection()“ / „connect()“ ab. Verwenden Sie „deepgram-js-speech-to-text“ für die einfache Transkription und „deepgram-js-text-intelligence“ für die Analyse von bereits transkribiertem Text. Zu den Auslösern gehören „Audio-Intelligenz“, „Audio zusammenfassen“, „Diarisieren“, „Stimmung aus Audio“, „PII schwärzen“ und „Sprach-Audio erkennen“.
