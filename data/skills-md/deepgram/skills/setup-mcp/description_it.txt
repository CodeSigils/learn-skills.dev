Configura il server MCP di Deepgram per il tuo strumento di codifica AI. Controlla se la CLI di Deepgram (dg/deepctl) è installata: in tal caso, utilizza il server MCP CLI locale (dg mcp) per l'accesso completo allo strumento; in caso contrario offre la documentazione ospitata MCP o suggerisce l'installazione della CLI. Da utilizzare ogni volta che qualcuno desidera installare gli strumenti agenti di Deepgram, configurare il server MCP o connettere il proprio editor a Deepgram.
