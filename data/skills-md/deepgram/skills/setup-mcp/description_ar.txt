قم بإعداد خادم Deepgram MCP لأداة ترميز الذكاء الاصطناعي الخاصة بك. التحقق من تثبيت Deepgram CLI (dg/deepctl): إذا كان الأمر كذلك، يستخدم خادم CLI MCP المحلي (dg mcp) للوصول الكامل إلى الأداة؛ وإلا يعرض الوثائق المستضافة MCP أو يقترح تثبيت CLI. استخدمه عندما يريد شخص ما تثبيت أدوات وكيل Deepgram، أو إعداد خادم MCP، أو توصيل المحرر الخاص به بـ Deepgram.
