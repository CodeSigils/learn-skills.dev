Richten Sie den Deepgram MCP-Server für Ihr KI-Codierungstool ein. Überprüft, ob die Deepgram-CLI (dg/deepctl) installiert ist: Wenn ja, wird der lokale CLI-MCP-Server (dg mcp) für den vollständigen Toolzugriff verwendet; Andernfalls bietet er die gehostete Dokumentation MCP an oder schlägt die Installation der CLI vor. Verwenden Sie es immer dann, wenn jemand die Agenten-Tools von Deepgram installieren, den MCP-Server einrichten oder seinen Editor mit Deepgram verbinden möchte.
