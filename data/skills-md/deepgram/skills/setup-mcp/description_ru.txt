Настройте сервер Deepgram MCP для вашего инструмента кодирования AI. Проверяет, установлен ли Deepgram CLI (dg/deepctl): если да, то использует локальный сервер CLI MCP (dg mcp) для полного доступа к инструменту; в противном случае предлагает размещенную документацию MCP или предлагает установить CLI. Используйте, когда кто-то хочет установить агентские инструменты Deepgram, настроить сервер MCP или подключить свой редактор к Deepgram.
