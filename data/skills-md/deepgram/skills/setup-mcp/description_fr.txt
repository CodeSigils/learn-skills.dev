Configurez le serveur Deepgram MCP pour votre outil de codage d'IA. Vérifie si la CLI Deepgram (dg/deepctl) est installée : si c'est le cas, utilise le serveur CLI MCP local (dg mcp) pour un accès complet à l'outil ; sinon, propose la documentation hébergée MCP ou suggère d'installer la CLI. À utiliser chaque fois que quelqu'un souhaite installer les outils agents de Deepgram, configurer le serveur MCP ou connecter son éditeur à Deepgram.
