Configure el servidor Deepgram MCP para su herramienta de codificación de IA. Comprueba si la CLI de Deepgram (dg/deepctl) está instalada: si es así, utiliza el servidor CLI MCP local (dg mcp) para obtener acceso completo a la herramienta; de lo contrario, ofrece la documentación alojada MCP o sugiere instalar la CLI. Úselo siempre que alguien quiera instalar las herramientas agentes de Deepgram, configurar el servidor MCP o conectar su editor a Deepgram.
