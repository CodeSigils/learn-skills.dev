Référence de l'API Deepgram pour la synthèse vocale, la synthèse vocale, les agents vocaux, l'intelligence audio et la gestion des comptes. À utiliser lors de la création avec les API Deepgram – REST ou WebSocket. Couvre l'authentification, tous les points de terminaison, les paramètres de requête, les schémas de demande/réponse et les formats de message WebSocket. Les fichiers de référence sont organisés par domaine : écouter (STT), parler (TTS), agent (agents vocaux), lecture (intelligence texte/audio), modèles, projets, authentification et auto-hébergé.
