Справочник по API Deepgram для преобразования речи в текст, преобразования текста в речь, голосовых агентов, аудиоаналитики и управления учетными записями. Используйте при сборке с использованием API Deepgram — REST или WebSocket. Охватывает аутентификацию, все конечные точки, параметры запроса, схемы запросов/ответов и форматы сообщений WebSocket. Справочные файлы организованы по доменам: прослушивание (STT), разговор (TTS), агент (голосовые агенты), чтение (текст/аудиоразведка), модели, проекты, аутентификация и самостоятельное размещение.
