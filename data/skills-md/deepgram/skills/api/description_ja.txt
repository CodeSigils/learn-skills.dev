音声合成、テキスト読み上げ、音声エージェント、オーディオ インテリジェンス、アカウント管理のための Deepgram API リファレンス。 Deepgram API (REST または WebSocket) を使用して構築する場合は常に使用します。認証、すべてのエンドポイント、クエリ パラメータ、リクエスト/レスポンス スキーマ、および WebSocket メッセージ形式をカバーします。参照ファイルは、リッスン (STT)、スピーキング (TTS)、エージェント (音声エージェント)、読み取り (テキスト/オーディオ インテリジェンス)、モデル、プロジェクト、認証、およびセルフホストのドメインごとに編成されています。
