Referencia de la API de Deepgram para conversión de voz a texto, texto a voz, agentes de voz, inteligencia de audio y gestión de cuentas. Úselo siempre que construya con API de Deepgram: REST o WebSocket. Cubre la autenticación, todos los puntos finales, parámetros de consulta, esquemas de solicitud/respuesta y formatos de mensajes WebSocket. Los archivos de referencia están organizados por dominio: escuchar (STT), hablar (TTS), agente (agentes de voz), leer (inteligencia de texto/audio), modelos, proyectos, autenticación y autohospedado.
