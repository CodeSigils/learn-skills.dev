مرجع Deepgram API لتحويل الكلام إلى نص، وتحويل النص إلى كلام، ووكلاء الصوت، والذكاء الصوتي، وإدارة الحساب. استخدمه عند البناء باستخدام واجهات برمجة التطبيقات Deepgram — REST أو WebSocket. يغطي المصادقة وجميع نقاط النهاية ومعلمات الاستعلام ومخططات الطلب/الاستجابة وتنسيقات رسائل WebSocket. يتم تنظيم الملفات المرجعية حسب المجال: الاستماع (STT)، التحدث (TTS)، الوكيل (وكلاء الصوت)، القراءة (ذكاء النص/الصوت)، النماذج، المشاريع، المصادقة، والاستضافة الذاتية.
