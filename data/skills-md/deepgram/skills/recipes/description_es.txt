Encuentre recetas de Deepgram enfocadas y ejecutables para una característica × idioma específico. Úselo siempre que alguien quiera un fragmento de código mínimo que funcione para UNA función (transcribir URL, diario, formato inteligente, conexión de agente de voz, etc.) en lugar de una aplicación de inicio completa. Las recetas tienen menos de 50 líneas, leen DEEPGRAM_API_KEY de env y se envían con un example_test ejecutable. Cubre Python, JavaScript, Go, .NET, Java, Rust y Deepgram CLI.
