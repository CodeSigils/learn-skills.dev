Steuern Sie eine Chrome-Browsersitzung über die chrome-devtools-axi-CLI – navigieren Sie, machen Sie Snapshots, klicken Sie, füllen Sie Formulare aus, führen Sie JavaScript aus, überprüfen Sie Konsole und Netzwerk, machen Sie Screenshots und prüfen Sie die Leistung. Verwenden Sie es immer dann, wenn eine Aufgabe einen echten Browser erfordert: Öffnen oder Testen einer Webseite, Klicken durch einen Flow, Extrahieren von Seiteninhalten oder Debuggen einer Website.
