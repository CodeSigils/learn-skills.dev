Controlla una sessione del browser Chrome tramite la CLI chrome-devtools-axi: naviga, esegui istantanee, fai clic, compila moduli, esegui JavaScript, ispeziona la console e la rete, acquisisci screenshot, controlla le prestazioni. Da utilizzare ogni volta che un'attività richiede un browser reale: aprire o testare una pagina Web, fare clic su un flusso, estrarre il contenuto della pagina o eseguire il debug di un sito Web.
