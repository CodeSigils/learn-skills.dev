يمكنك التحكم في جلسة متصفح Chrome من خلال واجهة سطر الأوامر chrome-devtools-axi - التنقل والتقاط الصور والنقر وملء النماذج وتشغيل JavaScript وفحص وحدة التحكم والشبكة والتقاط لقطات الشاشة وتدقيق الأداء. يُستخدم عندما تحتاج المهمة إلى متصفح حقيقي: فتح صفحة ويب أو اختبارها، أو النقر خلال التدفق، أو استخراج محتوى الصفحة، أو تصحيح أخطاء موقع ويب.
