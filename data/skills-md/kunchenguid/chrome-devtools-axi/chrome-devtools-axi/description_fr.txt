Contrôlez une session du navigateur Chrome via la CLI chrome-devtools-axi : naviguez, capturez un instantané, cliquez, remplissez des formulaires, exécutez JavaScript, inspectez la console et le réseau, prenez des captures d'écran, auditez les performances. À utiliser chaque fois qu'une tâche nécessite un véritable navigateur : ouvrir ou tester une page Web, cliquer sur un flux, extraire le contenu d'une page ou déboguer un site Web.
