Entrez dans la supervision en mode absence lorsque le capitaine invoque /afk, dit qu'il va en mode absence, que `state/.afk` existe, qu'un message entrant commence par `FM_INJECT_MARK`, ou que tout marqueur `state/.subsuper-*` est impliqué. Il définit un indicateur de mode absence durable afin que le démon sous-superviseur puisse gérer lui-même les réveils de routine et faire remonter les événements pertinents pour le capitaine, ainsi que les revérifications d'attente externe déclarées limitées sous forme de résumés par lots pendant les périodes de sortie, puis se ferme automatiquement lorsqu'un message réel non marqué renvoie le premier compagnon à une réactivité complète par réveil.
