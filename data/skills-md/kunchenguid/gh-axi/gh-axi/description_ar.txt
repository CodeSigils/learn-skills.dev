قم بتشغيل GitHub من خلال gh-axi CLI - المشكلات، وطلبات السحب، وعمليات سير العمل، وسير العمل، والإصدارات، والمستودعات، والتسميات، والبحث، والوصول إلى واجهة برمجة التطبيقات الأولية. استخدمه عندما تلامس مهمة GitHub: إدراج المشكلات أو حفظها، أو مراجعة أو دمج العلاقات العامة، أو التحقق من تشغيل CI، أو قطع الإصدارات، أو الاستعلام عن واجهة برمجة تطبيقات GitHub.
