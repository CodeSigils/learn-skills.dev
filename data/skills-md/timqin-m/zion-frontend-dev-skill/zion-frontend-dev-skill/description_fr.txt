Guide d'intégration complet pour créer des applications frontend personnalisées avec le backend-as-a-service de Zion.app. À utiliser lorsque : (1) Création d'applications Web React/TypeScript avec le backend Zion, (2) Développement de mini-programmes WeChat avec le backend Zion, (3) Configuration de clients GraphQL (Apollo Client), (4) Utilisation des opérations de base de données, des flux d'action, des agents IA, des paiements, des téléchargements de fichiers, (5) Respect des règles de conception d'interface utilisateur (style organique/naturel), (6) Déploiement sur la plateforme Zeabur.
