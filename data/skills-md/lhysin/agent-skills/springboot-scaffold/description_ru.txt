Создайте и проверьте каркас проекта Spring Boot. Используйте этот навык, когда пользователь запрашивает создание проекта Spring Boot, создание шаблонов Spring Boot, «스프링부트 프로젝트 생성», «스프링부트 스캐폴딩», «새 스프링부트 앱». 만들기", или вызывает /springboot-scaffold.
Скаффолд создается механически с помощью скриптов/scaffold.py, а затем проверяется с помощью детерминированных правил макета пакета, зависимостей Gradle, профилей, поведения .gitkeep и дополнительного примера кода домена.

Использование:
  /springboot-scaffold --root GROUP_ID --appname APP_NAME [-java-version 25] [--skeleton on|off] [--target PATH] [--help]
