قم بإنشاء صفحات Confluence وتحديثها ونسخها احتياطيًا ونقلها والتحقق منها من أصول Markdown وMermaid المحلية باستخدام Confluence CLI وPandoc وMermaid CLI. استخدم هذه المهارة عندما يقوم المستخدم بعمل نشر Confluence متعدد الخطوات مثل تحديثات الصفحة من الملفات المحلية، أو تغييرات شجرة الصفحة، أو معالجة المرفقات، أو تحويل Markdown-to-Confluence، أو نشر Mermaid، أو سير عمل CLI الصريح "التقاء".
