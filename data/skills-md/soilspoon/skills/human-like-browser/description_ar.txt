أتمتة المتصفح الشبيهة بالإنسان والتي تتجاوز اكتشاف الروبوتات. يلتف أدوات Playwright MCP لمحاكاة السلوك البشري الواقعي: حركات الماوس Bezier-curve مع اهتزاز صغير، وتأخير الكتابة العادي مع توقيت digraph والأخطاء المطبعية (~ 600 حرف/دقيقة)، والتمرير السلس بالقصور الذاتي، وتنظيف قطعة أثرية CDP، وتسلل شامل لمكافحة بصمات الأصابع (الأجهزة، WebGL، المكونات الإضافية، الاتصال). يمر FCaptcha القياسات الحيوية ضغطة المفتاح. استخدم هذه المهارة عندما يذكر المستخدم اكتشاف الروبوتات، أو تجاوز مكافحة الاستخلاص، أو التصفح الشبيه بالبشر، أو التشغيل الآلي الخفي، أو تجاوز Cloudflare، أو DataDome، أو PerimeterX، أو Akamai، أو استخلاص المواقع المحمية، أو يحتاج إلى التفاعل مع مواقع الويب التي تكتشف الروبوتات وتحظرها. يتم تشغيله أيضًا عندما يقول المستخدم "تصرف كإنسان"، أو "التصفح الطبيعي"، أو "تجنب الاكتشاف"، أو "اكشط دون أن يتم حظرك"، أو "املأ النموذج كشخص"، أو أي مهمة للكاتب المسرحي/المتصفح حيث يكون التهرب من الاكتشاف مهمًا. دعم تخطيط QWERTY الكوري (لا توجد محاكاة IME).
