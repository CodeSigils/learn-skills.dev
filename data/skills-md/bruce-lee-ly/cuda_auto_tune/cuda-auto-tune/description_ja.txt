CUDA/CUTLASS/Triton/CuTe DSL カーネル向けの NCU 主導の反復最適化ワークフロー。必須: すべての最適化は、NCU プロファイリングから開始し、次に多次元分析、次にターゲットを絞ったコード変更、次に検証のための再プロファイリングを行う必要があります。ルーフライン、メモリ階層、ワープ ストール、命令ミックス、占有、発散分析をサポートします。実装固有のコード変更を提供します: ネイティブ CUDA (起動設定、メモリ パターン、非同期コピー、Tensor コア)、CUTLASS (ThreadblockShape、ステージ、エピローグ、スケジュール ポリシー、アライメント)、Triton (自動調整パラメータ、コンパイラ ヒント、tl.* API パターン)、CuTe DSL (threads_per_cta、elems_per_thread、tiled_copy、コピー アトム、共有メモリ、ワープ/CTA削減）。 CUDA カーネルのパフォーマンスを最適化する場合に使用します。
