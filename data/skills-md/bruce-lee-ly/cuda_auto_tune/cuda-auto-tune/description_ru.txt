Рабочий процесс итеративной оптимизации на основе NCU для ядер CUDA/CUTLASS/Triton/CuTe DSL. ОБЯЗАТЕЛЬНО: каждая оптимизация ДОЛЖНА начинаться с профилирования NCU, за которым следует многомерный анализ, затем целевая модификация кода, а затем повторное профилирование для проверки. Поддерживает линию крыши, иерархию памяти, варп-стойки, сочетание команд, занятость, анализ расхождений. Обеспечивает изменения кода, зависящие от реализации: Native CUDA (конфигурация запуска, шаблоны памяти, асинхронное копирование, Tensor Core), CUTLASS (ThreadblockShape, этапы, эпилог, политика расписания, выравнивание), Triton (параметры автонастройки, подсказки компилятора, шаблоны API tl.*), CuTe DSL (threads_per_cta, elems_per_thread, tiled_copy, copyatom, общая память, warp/cta сокращение). Используйте при оптимизации производительности любого ядра CUDA.
