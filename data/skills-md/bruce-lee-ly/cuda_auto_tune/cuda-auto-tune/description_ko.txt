CUDA/CUTLASS/Triton/CuTe DSL 커널을 위한 NCU 기반 반복 최적화 워크플로우입니다. 필수: 모든 최적화는 NCU 프로파일링으로 시작해야 하며, 다차원 분석, 대상 코드 수정, 다시 프로파일링을 통해 검증해야 합니다. 루프라인, 메모리 계층, 워프 스톨, 명령 혼합, 점유, 발산 분석을 지원합니다. 구현별 코드 수정 사항 제공: 네이티브 CUDA(실행 구성, 메모리 패턴, 비동기 복사, Tensor Core), CUTLASS(ThreadblockShape, 단계, 에필로그, 일정 정책, 정렬), Triton(자동 조정 매개변수, 컴파일러 힌트, tl.* API 패턴), CuTe DSL(threads_per_cta, elems_per_thread, Tiled_copy, 복사 원자, 공유 메모리, warp/cta 감소). CUDA 커널 성능을 최적화할 때 사용합니다.
