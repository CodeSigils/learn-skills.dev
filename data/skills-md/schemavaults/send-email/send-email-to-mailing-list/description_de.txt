Senden Sie eine E-Mail über die Route „/api/send“ des SchemaVaults-Mailservers an eine Mailingliste, indem Sie entweder den Helfer „sendEmailToMailingList()“ oder die CLI „schemavaults-send-email send-to-mailing-list“ von „@schemavaults/send-email“ verwenden. Wird verwendet, wenn ein serverseitiger TypeScript-/JavaScript-Code eine Benachrichtigung an eine Mailinglisten-Zielgruppe senden muss – **oder wenn Claude Code selbst am Ende einer Aufgabe eine einmalige Benachrichtigung senden möchte** (bevorzugt – rufen Sie die CLI über „bunx schemavaults-send-email send-to-mailing-list …“ auf; Fallback – schreiben Sie ein kurzes Skript in „/tmp/“ und führen Sie es mit „bun“ aus).
