Envoyez un e-mail à une liste de diffusion via la route du serveur de messagerie SchemaVaults `/api/send`, en utilisant soit l'assistant `sendEmailToMailingList()` ou la CLI `schemavaults-send-email send-to-mailing-list` de `@schemavaults/send-email`. À utiliser lorsqu'un code TypeScript/JavaScript côté serveur doit envoyer une notification à une liste de diffusion — **ou lorsque Claude Code lui-même souhaite envoyer une notification unique à la fin d'une tâche** (de préférence — invoquez la CLI via `bunx schemavaults-send-email send-to-mailing-list…` ; solution de secours — écrivez un court script dans `/tmp/` et exécutez-le avec `bun`).
