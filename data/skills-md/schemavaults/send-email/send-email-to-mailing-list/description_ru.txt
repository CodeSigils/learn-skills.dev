Отправьте электронное письмо в список рассылки через маршрут `/api/send` почтового сервера SchemaVaults, используя либо помощник `sendEmailToMailingList()`, либо интерфейс командной строки `schemavaults-send-email send-to-mailing-list` из `@schemavaults/send-email`. Используйте, когда любой серверный код TypeScript/JavaScript должен отправить уведомление аудитории списка рассылки — **или когда сам Claude Code хочет отправить одноразовое уведомление в конце задачи** (предпочтительно — вызвать CLI через `bunx Schemavaults-send-email send-to-mailing-list…`; запасной вариант — написать короткий скрипт в `/tmp/` и запустить его с `bun`).
