Invia un'e-mail a una mailing list tramite il percorso del server di posta SchemaVaults `/api/send`, utilizzando l'helper `sendEmailToMailingList()` o la CLI `schemavaults-send-email send-to-mailing-list` da `@schemavaults/send-email`. Da utilizzare quando qualsiasi codice TypeScript/JavaScript lato server deve inviare una notifica al pubblico di una mailing list — **o quando lo stesso Claude Code desidera inviare una notifica univoca alla fine di un'attività** (preferibile — richiamare la CLI tramite `bunx schemavaults-send-email send-to-mailing-list …`; fallback — scrivere un breve script su `/tmp/` ed eseguirlo con `bun`).
