قم بتحسين الزاوية والبنية والأدلة وملاءمة القالب وصوت المبدع وآثار كتابة الذكاء الاصطناعي للكتابة الموجهة للجمهور. يُستخدم مباشرة عندما يقوم المستخدم بتسمية Amy Writing Angle أو يطلب تحليل زاوية الكتابة أو الخطاف أو القالب أو تحليل مكافحة الذكاء الاصطناعي. إذا طلب المستخدم فقط تحسين أو صقل أو إعادة كتابة أو تقوية أو تحسين مقال أو نشر أو نسخ أو أسلوب كتابة دون تسمية هذه المهارة، فاسأل عما إذا كان يريد تعديلًا مباشرًا خفيفًا أو سير عمل Amy Writing Angle الكامل قبل تطبيقه. لا تستدعيها أو تقترحها للبحث أو التلخيص أو الترجمة أو الاستخراج أو تنظيم LLM المحلي أو تصميم قاعدة المعرفة أو التوثيق الفني أو غيرها من المهام التي لا يكون فيها تغيير الكتابة هو الهدف المعلن.
