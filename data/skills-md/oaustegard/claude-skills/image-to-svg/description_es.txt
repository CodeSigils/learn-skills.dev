Convierta imágenes rasterizadas (fotos, pinturas, ilustraciones, arte lineal) en reproducciones vectoriales SVG. Se utiliza cuando el usuario sube una imagen y solicita reproducirla, vectorizarla, trazarla o convertirla a SVG. Úselo también cuando se le solicite descomponer una imagen en formas, crear una versión SVG de una imagen o reproducir fielmente obras de arte como gráficos vectoriales. Maneja entradas de gráficos/arte lineal (Kandinsky, dibujos arquitectónicos, trabajos en tinta) a través de un proceso de composición que extrae líneas como trazos SVG. NO lo use para crear ilustraciones SVG originales a partir de descripciones de texto; solo para convertir imágenes rasterizadas existentes.
