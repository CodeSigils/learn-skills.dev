قم بتحويل الصور النقطية (الصور واللوحات والرسوم التوضيحية والفن الخطي) إلى نسخ متجهة بصيغة SVG. يُستخدم عندما يقوم المستخدم بتحميل صورة ويطلب إعادة إنتاجها أو توجيهها أو تتبعها أو تحويلها إلى SVG. استخدمه أيضًا عندما يُطلب منك تحليل صورة إلى أشكال، أو إنشاء إصدار SVG من الصورة، أو إعادة إنتاج العمل الفني بدقة كرسومات متجهة. يتعامل مع المدخلات الرسومية/فن الخط (كاندينسكي، الرسومات المعمارية، أعمال الحبر) عبر خط أنابيب تركيبي يستخرج الخطوط كحدود SVG. لا تستخدم لإنشاء رسوم توضيحية SVG أصلية من أوصاف النص - فقط لتحويل الصور النقطية الموجودة.
