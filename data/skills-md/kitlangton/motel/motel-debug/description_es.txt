Depure aplicaciones con motel, un servidor local de consultas e ingesta de OpenTelemetry. Úselo cuando el usuario desee una depuración de evidencia en tiempo de ejecución con seguimientos o registros, desee instrumentación de depuración temporal que pueda eliminarse más adelante o necesite un repositorio conectado para enviar telemetría OTLP/HTTP a un servidor de motel local. Si el repositorio de destino usa Effect o @effect/*, lea también references/effect.md.
