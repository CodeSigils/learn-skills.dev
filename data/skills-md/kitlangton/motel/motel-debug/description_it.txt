Eseguire il debug delle applicazioni con Motel, un server di immissione e query OpenTelemetry locale. Da utilizzare quando l'utente vuole eseguire il debug delle prove di runtime con tracce o log, vuole una strumentazione di debug temporanea che possa essere rimossa in seguito o ha bisogno di un repository cablato per inviare la telemetria OTLP/HTTP a un server motel locale. Se il repository di destinazione utilizza Effect o @effect/*, leggi anche references/effect.md.
