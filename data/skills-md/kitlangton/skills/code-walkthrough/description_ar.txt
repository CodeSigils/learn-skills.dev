قم بتوجيه التعليمات البرمجية المرئية والمتحقق منها في Neovim باستخدام Terminal Control وNavi، أو تسجيل العرض التقديمي اختياريًا باستخدام OBS أو الاحتفاظ بالأدلة الطرفية. يُستخدم عندما يريد المستخدم جولة التعليمات البرمجية التي يقودها الوكيل، أو التعليمات البرمجية المصاحبة، أو شرح المصدر المباشر، أو الإرشادات التفصيلية للمحطة الطرفية المسجلة.
