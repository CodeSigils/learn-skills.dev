Проведите наглядное и проверенное выполнение кода в Neovim с помощью Terminal Control и Navi, при необходимости записывая презентацию с помощью OBS или сохраняя доказательства терминала. Используйте, когда пользователю требуется экскурсия по коду под руководством агента, описание кода, объяснение исходного кода в реальном времени или записанное пошаговое руководство по терминалу.
