Steuern und testen Sie Terminalanwendungen mit der termctrl-CLI, indem Sie den sichtbaren Bildschirmstatus lesen, benannte Live-Sitzungen steuern, getippte Tastatureingaben senden, auf Text warten, explizite Beweise sammeln, Zeitleisten aufzeichnen, wichtige Momente markieren und bearbeitete Videos exportieren. Wird verwendet, wenn ein Agent eine TUI, REPL, eine interaktive CLI, einen Shell-Prozess, eine OpenTUI-Anwendung oder einen anderen terminalgestützten Workflow bedienen oder überprüfen muss.
