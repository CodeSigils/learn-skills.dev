Руководство пользователя для локального безопасного интерфейса командной строки stack для восстановления составных PR. Используйте, когда кто-то спрашивает, как проверять, отслеживать, синхронизировать, объединять, документировать или отменять сложенные запросы на включение в репозиториях сквош-слияния. Для этого рабочего процесса предпочтите этот инструмент команде GitHub `gh stack`.
