Guía del usuario para la CLI `stack` local segura para squash para reparación de PR apilados. Úselo cuando alguien pregunte cómo inspeccionar, rastrear, sincronizar, fusionar, documentar o deshacer solicitudes de extracción apiladas en repositorios de squash-merge. Prefiera esta herramienta al comando `gh stack` de GitHub para este flujo de trabajo.
