Guida per l'utente per la CLI `stack` locale sicura per lo squash per la riparazione di PR in pila. Da utilizzare quando qualcuno chiede come ispezionare, tenere traccia, sincronizzare, unire, documentare o annullare le richieste pull in pila nei repository squash-merge. Preferisci questo strumento al comando "gh stack" di GitHub per questo flusso di lavoro.
