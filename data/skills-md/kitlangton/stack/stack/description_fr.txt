Guide de l'utilisateur pour la CLI `stack` locale sécurisée pour la réparation des PR empilés. À utiliser lorsque quelqu'un demande comment inspecter, suivre, synchroniser, fusionner, documenter ou annuler les demandes d'extraction empilées dans les référentiels de fusion par squash. Préférez cet outil à la commande « gh stack » de GitHub pour ce workflow.
