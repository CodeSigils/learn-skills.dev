Capturez des fichiers, des pages Web et des documents en ligne, des référentiels et bases de code Git, des notes, des réunions, des messages, des e-mails, des tickets, des médias, des feuilles de calcul, des requêtes de base de données, des résultats d'API, des tableaux de bord ou des conversations dans un wiki Markdown local géré avec des preuves immuables, des citations au niveau des revendications, des conflits, des liens et des événements d'audit. À utiliser lorsque l'utilisateur demande à capturer, ingérer, importer, enregistrer, synchroniser ou mémoriser une source ; ingérer une URL de référentiel ou un répertoire de référentiel local ; importer une base de code GitHub ou GitLab ; construire un wiki de projet à partir du code ; créer un wiki de référentiel complet ; documenter une base de code entière afin que les lecteurs puissent la comprendre sans ouvrir le code ; préserver une conversation; ou enregistrez des données ou des instantanés de métriques. Les déclencheurs chinois incluent记住、保存、收录、导入、同步、归档、收录网页、录入仓库、录入会议记录、保存业务数据、把代码库收录进Wiki、从代码生成项目 Wiki、生成完整项目 Wiki、为代码仓库创建全量 Wiki、无需看代码了解整个仓库. Ne pas utiliser pour l'examen des sources en lecture seule, l'analyse du code en lecture seule, l'analyse des données sans capture persistante, les questions et réponses, le travail lint uniquement ou la configuration de l'espace de travail.
