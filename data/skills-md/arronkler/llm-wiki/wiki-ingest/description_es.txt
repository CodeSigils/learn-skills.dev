Capture archivos, páginas web y documentos en línea, repositorios y bases de código de Git, notas, reuniones, mensajes, correos electrónicos, tickets, medios, hojas de cálculo, consultas de bases de datos, resultados de API, paneles o conversaciones en un wiki de Markdown local administrado con evidencia inmutable, citas a nivel de reclamo, conflictos, enlaces y eventos de auditoría. Úselo cuando el usuario solicite capturar, ingerir, importar, guardar, sincronizar o recordar una fuente; ingerir una URL de repositorio o un directorio de repositorio local; importar un código base de GitHub o GitLab; construir un proyecto wiki a partir del código; crear un repositorio wiki completo; documentar una base de código completa para que los lectores puedan entenderla sin abrir el código; preservar una conversación; o guardar datos o instantáneas de métricas. Los desencadenantes chinos incluyen记住、保存、收录、导入、同步、归档、收录网页、录入仓库、录入会议记录、保存业务数据、把代码库收录进Wiki、从代码生成项目 Wiki、生成完整项目 Wiki、为代码仓库创建全量 Wiki、无需看代码了解整个仓库. No lo utilice para revisión de fuentes de solo lectura, análisis de código de solo lectura, análisis de datos sin captura persistente, preguntas y respuestas, trabajo de solo pelusa o configuración del espacio de trabajo.
