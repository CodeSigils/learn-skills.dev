Интегрируйте проекты AWS Lambda с Watchy — фиксируйте ошибки с указанием их критичности и бизнес-контекста, а затем запрашивайте их через MCP для отладки с учетом производственной среды. Используйте, когда пользователь хочет: отслеживать ошибки Lambda, настроить отчеты об ошибках для бессерверных приложений, подключить свой проект к Watchy, включить кодирование с учетом производственной среды с помощью агентов искусственного интеллекта или инструментировать обработчики Lambda. Триггеры включают в себя: «настроить наблюдение», «фиксировать ошибки Lambda», «отслеживать ошибки для Lambda», «инструментировать мои обработчики», «подключиться к отслеживанию», «отладку с учетом производства».
