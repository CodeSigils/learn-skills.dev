Комплексно создавайте, изменяйте, отлаживайте, тестируйте и развертывайте статические приложения Railcode. Используйте при создании приложения Railcode на основе идеи, создании каркаса с помощью интерфейса командной строки Railcode, подключении глобальных переменных SDK с нулевой конфигурацией, объяснении «магии» аутентификации/данных Railcode, тестировании с помощью разработки Railcode, объявлении полномочий приложения, понимании доступа к приложению или развертывании приложения. Не используйте для разработки управляемых агентов или общего администрирования организации.
