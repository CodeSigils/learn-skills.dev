Cree, modifique, depure, pruebe e implemente aplicaciones estáticas Railcode de un extremo a otro. Úselo al crear una aplicación Railcode a partir de una idea, realizar andamiaje con la CLI de Railcode, conectar los globales del SDK de configuración cero, explicar la "magia" de datos/autenticación de Railcode, realizar pruebas con el desarrollador de Railcode, declarar la autoridad de la aplicación, comprender el acceso a la aplicación o implementar una aplicación. No lo utilice para la creación de agentes administrados ni para la administración general de la organización.
