Cree, pruebe, publique, invoque, programe y actualice agentes administrados por Railcode con Railcode CLI. Úselo al crear un agente administrado con ámbito de organización, editar el manifiesto JSON de un agente, ejecutar un agente borrador o guardado, investigar la ejecución de un agente o administrar su programación cron, o cuando el agente debe poseer conectores personales (Gmail, Slack,...) en nombre de un único propietario. No lo use para aplicaciones estáticas de Railcode o administración general de organizaciones.
