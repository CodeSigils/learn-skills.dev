Crea, testa, pubblica, richiama, pianifica e aggiorna gli agenti gestiti Railcode con la CLI Railcode. Da utilizzare durante la creazione di un agente gestito con ambito organizzazione, la modifica del manifest JSON di un agente, l'esecuzione di una bozza o un agente salvato, l'analisi dell'esecuzione di un agente o la gestione della pianificazione cron o quando l'agente deve possedere connettori personali (Gmail, Slack, ...) per conto di un singolo proprietario. Non utilizzare per app Railcode statiche o per l'amministrazione generale dell'organizzazione.
