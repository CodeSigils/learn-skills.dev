Erstellen, testen, veröffentlichen, aufrufen, planen und aktualisieren Sie von Railcode verwaltete Agenten mit der Railcode-CLI. Verwenden Sie diese Option, wenn Sie einen verwalteten Agenten auf Organisationsebene erstellen, ein JSON-Manifest eines Agenten bearbeiten, einen Entwurf oder einen gespeicherten Agenten ausführen, die Ausführung eines Agenten untersuchen oder seinen Cron-Zeitplan verwalten oder wenn der Agent persönliche Konnektoren (Gmail, Slack usw.) im Namen eines einzelnen Eigentümers besitzen soll. Nicht für statische Railcode-Apps oder allgemeine Organisationsverwaltung verwenden.
