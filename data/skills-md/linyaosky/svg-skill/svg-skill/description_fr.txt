Compétence d'agent pour écrire du balisage SVG prêt pour la production : icônes, logos, favicons, illustrations, organigrammes, diagrammes, anneaux de progression, sprites, masques CSS et graphiques animés de l'interface utilisateur. À utiliser lorsque l'utilisateur demande du SVG, des graphiques vectoriels, des graphiques en ligne, des jeux d'icônes, une visualisation de données ou des ressources Web évolutives, ou mentionne cette compétence. Préférez la génération d’images lorsque la mise à l’échelle, la thématique, le contrôle CSS ou l’intégration de code sont importants.
