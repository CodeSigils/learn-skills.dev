Навыки агента для написания готовой к использованию разметки SVG — значков, логотипов, значков, иллюстраций, блок-схем, диаграмм, колец выполнения, спрайтов, масок CSS и анимированной графики пользовательского интерфейса. Используйте, когда пользователь запрашивает SVG, векторную графику, встроенную графику, наборы значков, визуализацию данных или масштабируемые веб-ресурсы или упоминает этот навык. Отдавайте предпочтение генерации изображений, когда важны масштабирование, тематика, управление CSS или интеграция кода.
