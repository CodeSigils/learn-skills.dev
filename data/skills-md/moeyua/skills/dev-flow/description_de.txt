Vollständiger Entwicklungsworkflow für die KI-Agent-gesteuerte Funktionsentwicklung. Bewältigt den gesamten Lebenszyklus: Spezifikation lesen → Zweig/Arbeitsbaum erstellen → Feature-Entwicklung → Lint/Test → Festschreiben → Push → PR erstellen. Verwenden Sie diese Fähigkeit, wenn der Benutzer mit der End-to-End-Entwicklung einer Funktion beginnen möchte, Dinge sagt wie „Diese Funktion implementieren“, „mit der Arbeit an [Funktion] beginnen“, „[Spezifikation] entwickeln“, auf eine Spezifikationsdatei verweist oder den Beginn einer Entwicklungsaufgabe fordert. Dies umschließt feature-dev:feature-dev und fügt die Einrichtung vor der Entwicklung und die Finalisierung nach der Entwicklung hinzu. Verwenden Sie dies anstelle von „feature-dev“, wenn Sie den gesamten Lebenszyklus einschließlich Git-Workflow wünschen.
