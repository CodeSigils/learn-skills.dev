AI 에이전트 기반 기능 개발을 위한 전체 개발 워크플로입니다. 전체 수명 주기를 처리합니다. 사양 읽기 → 분기/작업 트리 생성 → 기능 개발 → 린트/테스트 → 커밋 → 푸시 → PR 생성. 사용자가 기능 개발을 처음부터 끝까지 시작하려고 할 때, '이 기능 구현', '[기능] 작업 시작', '[사양] 개발'과 같은 말을 하거나, 사양 파일을 참조하거나, 개발 작업 시작을 요청할 때 이 기술을 사용하세요. 이는 feature-dev:feature-dev를 둘러싸며 개발 전 설정과 개발 후 마무리를 추가합니다. Git 워크플로를 포함한 전체 수명 주기를 원할 경우 feature-dev 대신 이를 사용하세요.
