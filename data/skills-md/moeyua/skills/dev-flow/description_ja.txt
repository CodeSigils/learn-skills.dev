AI エージェント主導の機能開発のための完全な開発ワークフロー。完全なライフサイクルを処理します: 仕様の読み取り → ブランチ/ワークツリーの作成 → 機能開発 → lint/テスト → コミット → プッシュ → PR の作成。このスキルは、ユーザーが機能の開発をエンドツーエンドで開始したい場合、「この機能を実装する」、「[機能] の作業を開始する」、「[仕様] を開発する」などの指示をする場合、仕様ファイルを参照する場合、または開発タスクの開始を求める場合に使用します。これは、feature-dev:feature-dev をラップし、開発前のセットアップと開発後のファイナライズを追加します。 git ワークフローを含むライフサイクル全体が必要な場合は、feature-dev の代わりにこれを使用します。
