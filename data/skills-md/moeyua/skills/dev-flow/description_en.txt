Full development workflow for AI Agent-driven feature development. Handles the complete lifecycle: read spec → create branch/worktree → feature-dev → lint/test → commit → push → create PR. Use this skill when the user wants to start developing a feature end-to-end, says things like 'implement this feature', 'start working on [feature]', 'develop [spec]', references a spec file, or asks to begin a development task. This wraps around feature-dev:feature-dev and adds pre-development setup and post-development finalization. Use this instead of feature-dev when you want the full lifecycle including git workflow.
