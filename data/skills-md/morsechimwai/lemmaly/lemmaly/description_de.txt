Verwenden Sie es immer dann, wenn Sie Code schreiben, bearbeiten oder überprüfen, der Schleifen, Sammlungen, Suchvorgänge, Suchen, Verknüpfungen, Rekursionen, Diagramme, Abfragen oder Berechnungen über mehr als eine Handvoll Elemente umfasst. Erzwingt algorithmisches Denken VOR dem Schreiben von Code – benennt die zeitliche/räumliche Komplexität, die Datenstruktur, die Algorithmenfamilie und die dominante Eingabedimension. Fängt O(n^2)-Schleifen, N+1-Abfragen, wiederholte Arbeiten, falsche Datenstrukturen und träge Brute-Force-Lösungen ab, die KI-Assistenten standardmäßig ausliefern. Kombiniert mit Mathguard (erweiterte mathematische Optimierung), Invariant-Guard (Korrektheit) und Complexity-Cuts (korrigierende Big-O-Korrekturen).
