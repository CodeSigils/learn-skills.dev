Use whenever writing, editing, or reviewing code that involves loops, collections, lookups, searches, joins, recursion, graphs, queries, or any computation over more than a handful of items. Forces algorithmic thinking BEFORE writing code — names the time/space complexity, the data structure, the algorithm family, and the dominant input dimension. Улавливает циклы O(n^2), запросы N+1, повторяющуюся работу, неправильные структуры данных и ленивые решения методом перебора, которые ИИ-помощники предоставляют по умолчанию. Сочетается с mathguard (расширенная математическая оптимизация), invariant-guard (правильность) и сокращением сложности (корректирующие исправления Big-O).
