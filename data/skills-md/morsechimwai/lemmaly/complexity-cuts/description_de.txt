Verwenden Sie diese Option, wenn Sie vorhandenen Code umgestalten, der schlechte Big-O-verschachtelte Schleifen, O(n^2)+-Scans, wiederholte Arbeit, redundante Zuordnungen, überlasteten Speicher oder angegebene Symptome wie „Das ist bei großen Eingaben langsam“, „Zeitüberschreitung“, „OOM“, „Zu viel Speicher“, „Komplexität reduzieren“, „Diesen Algorithmus optimieren“ aufweist. Zielt auf die zeitliche und räumliche Komplexität von bereits vorhandenem Code ab. Um eine schlechte Komplexität zu verhindern, bevor Code geschrieben wird, verwenden Sie Lemmaly. Für Optimierungen auf mathematischer Ebene (Bloom, HLL, FFT, JL-Projektion) eskalieren Sie es an mathguard.
