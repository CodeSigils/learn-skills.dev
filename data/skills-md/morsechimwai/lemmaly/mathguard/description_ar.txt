يُستخدم عند العمل مع بيانات واسعة النطاق، أو البحث عن التشابه، أو إلغاء البيانات المكررة، أو أعلى K / الضاربون الثقيلون، أو تحليلات التدفق، أو تقدير العناصر الأساسية، أو التضمينات، أو أنظمة التوصية، أو معالجة الإشارات/الصور، أو حساب متعدد الحدود أو الأعداد الصحيحة الكبيرة، أو الالتفاف، أو مسافة الرسم البياني، أو الهندسة الحسابية، أو الخوارزميات العشوائية، أو أي مشكلة مع n >= 10^6 حيث يكون الحساب الدقيق مهدرًا. يتعرف على الوقت الذي تصل فيه الخوارزميات الكلاسيكية إلى الحد الأدنى وتقنية تقريبية أو ثقيلة في الرياضيات (مرشح Bloom، HyperLogLog، Count-Min Sketch، MinHash/LSH، FFT/NTT، إسقاط Johnson-Lindenstrauss، خط الاجتياح، kd-tree/BVH، الأسي السريع، التخفيض المتوازي الأحادي، طريقة الجهد المطفأ) يعطي فوزًا مقاربًا. قم بالتحميل بعد lemmaly عندما تكون O(n log n) الكلاسيكية هي الأرضية ولكن الرياضيات الأكثر ذكاءً هي التي تفوز.
