Élabore une suite complète de tests Playwright E2E à partir de zéro. Crée le répertoire e2e/ avec les fichiers de configuration, la structure des dossiers, la classe de page de base, les appareils personnalisés, la configuration d'authentification et la configuration de l'environnement. À utiliser lorsque : la configuration de tests E2E pour un nouveau projet, l'initialisation d'une suite de tests Playwright ou le démarrage du répertoire e2e.
