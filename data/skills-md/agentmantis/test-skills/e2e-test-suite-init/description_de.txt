Stellt eine komplette Playwright E2E-Testsuite von Grund auf bereit. Erstellt das e2e/-Verzeichnis mit Konfigurationsdateien, Ordnerstruktur, Basisseitenklasse, benutzerdefinierten Vorrichtungen, Authentifizierungseinrichtung und Umgebungskonfiguration. Wird verwendet, wenn: E2E-Tests für ein neues Projekt eingerichtet, eine Playwright-Testsuite initialisiert oder das E2e-Verzeichnis gebootet werden.
