Supporta da zero una suite di test E2E completa per Playwright. Crea la directory e2e/ con file di configurazione, struttura di cartelle, classe di pagina base, dispositivi personalizzati, configurazione di autenticazione e configurazione dell'ambiente. Da utilizzare quando: si impostano test E2E per un nuovo progetto, si inizializza una suite di test di Playwright o si avvia la directory e2e.
