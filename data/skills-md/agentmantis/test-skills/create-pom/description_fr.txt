Crée une classe POM (Page Object Model) pour une page spécifiée dans une suite de tests Playwright E2E. Génère le fichier POM avec une structure appropriée, des bannières de commentaires, JSDoc, des méthodes de cycle de vie setUp/tearDown et des localisateurs. À utiliser lorsqu'on vous demande de créer un POM, un objet de page ou un modèle de page.
