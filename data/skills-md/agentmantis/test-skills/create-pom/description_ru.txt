Создает класс объектной модели страницы (POM) для указанной страницы в наборе тестов Playwright E2E. Создает POM-файл с правильной структурой, баннерами комментариев, JSDoc, методами жизненного цикла setUp/tearDown и локаторами. Используйте, когда вас попросят создать POM, объект страницы или модель страницы.
