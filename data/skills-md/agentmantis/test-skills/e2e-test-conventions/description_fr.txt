Conventions et règles de base pour les tests Playwright E2E avec TypeScript. Couvre la structure du projet, les conventions de dénomination, la stratégie de sélection, l'authentification, la navigation, la configuration de l'environnement, l'indépendance des tests et le parallélisme. Chargé automatiquement lors de l'écriture ou de la modification de tests E2E.

À utiliser lorsque : générer des tests E2E, créer des POM, réviser le code de test ou configurer une suite de tests Playwright.
