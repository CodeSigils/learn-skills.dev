Создает тест передачи на основе билетов для набора тестов Playwright E2E. Называет тест префиксом билета, помещает его в каталог тестов передачи обслуживания и следует жизненному циклу продвижения. Используйте, когда вас просят написать тест передачи, тест билета, функциональный тест или тест для определенного номера билета.
