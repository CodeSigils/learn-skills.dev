Crea un test di passaggio basato su ticket per una suite di test Playwright E2E. Assegna un nome al test con il prefisso del ticket, lo inserisce nella directory del test di consegna e segue il ciclo di vita della promozione. Da utilizzare quando viene richiesto di scrivere un test di consegna, un test ticket, un test funzionale o un test per un numero di ticket specifico.
