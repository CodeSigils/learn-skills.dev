يقوم بإنشاء ملف مواصفات اختبار الانحدار أو الدخان لمجموعة اختبار Playwright E2E. يُنشئ ملف المواصفات وبيانات الاختبار JSON وتحديثات التركيبات. يتعامل مع سقالات الاختبار الكاملة بما في ذلك التنظيف قبل الكل واستخدام POM والبيانات الآمنة المتوازية. يُستخدم عندما يُطلب منك كتابة اختبار الانحدار، أو اختبار الدخان، أو اختبار E2E لميزة ما.
