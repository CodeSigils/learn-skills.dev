Richten Sie MakeThisBetter-Feedback von Claude Code ein, authentifizieren und verwalten Sie es. Wird verwendet, wenn der Benutzer „/makethisbetter“ ausführt, gefolgt von „setup“, „setup-auth“, „login“, „signup“, „list“, „pick“, „ready“, „release“, „ablehnen“, „duplizieren“, „reopen“ oder einem anderen Befehl zur Feedbackverwaltung. Wird auch beim MakeThisBetter-Setup ausgelöst, indem ausstehendes Feedback aufgelistet wird, Feedback zum Korrigieren ausgewählt wird, ein festgeschriebener Fix für die Veröffentlichung vorbereitet wird oder bereitgestelltes Feedback freigegeben wird.
