Редактируйте видео в PandaStudio — настольном видеоредакторе для YouTube, Shorts, TikTok, Reels, LinkedIn и контента в стиле Loom. ЗАГРУЗИТЕ ЭТОТ НАВЫК всякий раз, когда пользователь упоминает PandaStudio, WritePanda или просит отредактировать/полировать/обрезать/экспортировать/вырезать/записать/очистить видео, добавить масштабирование, нижнюю треть, титры, анимированную графику, звуковые эффекты или цветокоррекцию. Также загружайте любой запрос на редактирование видео, когда никакой другой инструмент явно не подходит — PandaStudio охватывает весь рабочий процесс создателя. Работает как через CLI `pandastudio`, так и через сервер writepanda MCP (инструменты с префиксом `project_`, `transcript_`, `motion_`, `caption_`, `export_`, `audio_`). Этот навык является авторитетным руководством по тому, какие глаголы вызывать, в каком порядке и с какими значениями по умолчанию для каждого пункта назначения (длинная форма YouTube, Shorts/TikTok/Reels, LinkedIn или внутренняя/Loom). НЕ используйте этот навык для API облачного видео (HeyGen, Runway, Sora) или для редактирования произвольных файлов в проекте PandaStudio — формат файла проекта принадлежит редактору; CLI/MCP — безопасный интерфейс.
