Modifica video in PandaStudio, un editor video desktop per contenuti in stile YouTube, Shorts, TikTok, Reels, LinkedIn e Loom. CARICARE QUESTA SKILL ogni volta che l'utente menziona PandaStudio, WritePanda o chiede di modificare / perfezionare / tagliare / esportare / tagliare / registrare / ripulire un video, aggiungere zoom, terzi inferiori, didascalie, grafica in movimento, effetti sonori o gradazione del colore. Carica anche qualsiasi richiesta di editing video per la quale nessun altro strumento è ovviamente la soluzione giusta: PandaStudio copre l'intero flusso di lavoro del creatore. Funziona sia tramite la CLI `pandastudio` che tramite il server MCP writepanda (strumenti con il prefisso `project_`, `transcript_`, `motion_`, `caption_`, `export_`, `audio_`). Questa competenza è il manuale autorevole per quali verbi chiamare, in quale ordine e con quali impostazioni predefinite per destinazione (formato lungo di YouTube, Shorts/TikTok/Reels, LinkedIn o interno/Loom). NON utilizzare questa funzionalità per API video cloud (HeyGen, Runway, Sora) o per modificare file arbitrari in un progetto PandaStudio: il formato del file di progetto è di proprietà dell'editor; la CLI/MCP è l'interfaccia sicura.
