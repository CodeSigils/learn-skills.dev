PandaStudio でビデオを編集します。PandaStudio は、YouTube、ショート、TikTok、リール、LinkedIn、および Loom スタイルのコンテンツ用のデスクトップ ビデオ エディタです。ユーザーが PandaStudio、WritePanda について言及したとき、またはビデオの編集 / 磨き上げ / トリム / エクスポート / カット / 録画 / クリーンアップ、ズーム、ローワー サード、キャプション、モーション グラフィックス、サウンド エフェクト、またはカラー グレーディングの追加を要求するたびに、このスキルをロードしてください。また、他のツールが明らかに適切ではないビデオ編集リクエストにもロードします。PandaStudio はクリエイターのワークフロー全体をカバーします。 `pandastudio` CLI 経由と writepanda MCP サーバー経由の両方で動作します (ツールの接頭辞は `project_`、`transcript_`、`motion_`、`caption_`、`export_`、`audio_` です)。このスキルは、どの動詞をどの順序で呼び出すか、そして宛先 (YouTube 長編、ショート/TikTok/リール、LinkedIn、社内/Loom) ごとのデフォルト設定を指定するための信頼できるプレイブックです。このスキルは、クラウド ビデオ API (HeyGen、Runway、Sora) や PandaStudio プロジェクト内の任意のファイルの編集には使用しないでください。プロジェクト ファイル形式はエディターが所有します。 CLI/MCP は安全なインターフェイスです。
