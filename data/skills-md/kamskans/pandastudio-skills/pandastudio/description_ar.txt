تحرير مقاطع الفيديو في PandaStudio - محرر فيديو سطح المكتب لمحتوى YouTube وShorts وTikTok وReels وLinkedIn وLoom. قم بتحميل هذه المهارة عندما يذكر المستخدم PandaStudio أو WritePanda أو يطلب تحرير / تلميع / تقليم / تصدير / قص / تسجيل / تنظيف مقطع فيديو، أو إضافة تكبير/تصغير، أو الثلث السفلي، أو التسميات التوضيحية، أو الرسومات المتحركة، أو المؤثرات الصوتية، أو تدرج الألوان. قم أيضًا بالتحميل لأي طلب لتحرير الفيديو حيث لا توجد أداة أخرى مناسبة بشكل واضح - يغطي PandaStudio سير عمل المنشئ الكامل. يعمل عبر واجهة سطر الأوامر "pandastudio" وعبر خادم writepanda MCP (الأدوات مسبوقة بـ "project_"، و"transcript_"، و"motion_"، و"caption_"، و"export_"، و"audio_`). هذه المهارة هي دليل اللعب الرسمي الذي يتم من خلاله استدعاء الأفعال، وبأي ترتيب، وبأي إعدادات افتراضية لكل وجهة (نموذج طويل على YouTube، أو Shorts/TikTok/Reels، أو LinkedIn، أو داخلي/Loom). لا تستخدم هذه المهارة لواجهات برمجة تطبيقات الفيديو السحابية (HeyGen، Runway، Sora) أو لتحرير الملفات العشوائية في مشروع PandaStudio - تنسيق ملف المشروع مملوك للمحرر؛ CLI/MCP هي الواجهة الآمنة.
