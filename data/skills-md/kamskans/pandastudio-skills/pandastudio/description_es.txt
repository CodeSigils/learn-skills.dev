Edite videos en PandaStudio, un editor de videos de escritorio para YouTube, Shorts, TikTok, Reels, LinkedIn y contenido estilo Loom. CARGUE ESTA HABILIDAD cada vez que el usuario mencione PandaStudio, WritePanda o solicite editar / pulir / recortar / exportar / cortar / grabar / limpiar un video, agregar zooms, tercios inferiores, subtítulos, gráficos en movimiento, efectos de sonido o gradación de color. También cargue para cualquier solicitud de edición de video donde ninguna otra herramienta sea obviamente la adecuada: PandaStudio cubre todo el flujo de trabajo del creador. Funciona tanto a través de la CLI `pandastudio` como a través del servidor writepanda MCP (herramientas con el prefijo `project_`, `transcript_`, `motion_`, `caption_`, `export_`, `audio_`). Esta habilidad es el manual autorizado para saber qué verbos llamar, en qué orden y con qué valores predeterminados por destino (formato largo de YouTube, Shorts/TikTok/Reels, LinkedIn o interno/Loom). NO utilice esta habilidad para API de video en la nube (HeyGen, Runway, Sora) o para editar archivos arbitrarios en un proyecto PandaStudio: el formato del archivo del proyecto es propiedad del editor; CLI/MCP es la interfaz segura.
