Analizza un ambiente Materialise tramite l'endpoint MCP Developer e/o configura un client MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) per connettersi al server materialize-developer. Per l'analisi: verifica l'integrità dell'ambiente, esamina le prestazioni, risolvi i problemi relativi alle visualizzazioni materializzate obsolete, diagnostica l'utilizzo della memoria, controlla l'utilizzo delle risorse, ottieni consigli sull'ottimizzazione. Per la connessione client: configurare/connettere/impostare un client MCP per materializzare lo sviluppatore (emulatore, cloud o autogestito), controllare quale utente/ruolo viene utilizzato, passare da un'identità all'altra. Si attiva anche se l'utente dice semplicemente "controlla il mio ambiente", "perché il mio MV è stantio", "perché il mio cluster è lento", "cosa posso ottimizzare", "come collego Claude Code a materialize-developer" o "configura il cursore per Materialise MCP".
