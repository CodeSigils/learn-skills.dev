Analysieren Sie eine Materialise-Umgebung über den MCP Developer-Endpunkt und/oder konfigurieren Sie einen MCP-Client (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop), um eine Verbindung zum Materialise-Developer-Server herzustellen. Zur Analyse: Überprüfen Sie den Zustand der Umgebung, untersuchen Sie die Leistung, beheben Sie veraltete materialisierte Ansichten, diagnostizieren Sie den Speicherdruck, prüfen Sie die Ressourcennutzung und erhalten Sie Optimierungsempfehlungen. Für Client-Verbindung: Konfigurieren/verbinden/einrichten eines MCP-Clients für Materialise-Developer (Emulator, Cloud oder selbstverwaltet), steuern, welcher Benutzer/welche Rolle verwendet wird, zwischen Identitäten wechseln. Wird auch dann ausgelöst, wenn der Benutzer nur sagt: „Überprüfe meine Umgebung“, „Warum ist mein MV veraltet“, „Warum ist mein Cluster langsam“, „Was kann ich optimieren“, „Wie verbinde ich Claude Code mit Materialise-Developer“ oder „Konfiguriere den Cursor für den Materialise MCP“.
