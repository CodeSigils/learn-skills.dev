通过 MCP Developer 端点分析 Materialise 环境，和/或配置 MCP 客户端（Claude Code、Cursor、VS Code、Zed、Continue、Windsurf、Claude Desktop）以连接到 Materialise-Developer 服务器。用于分析：检查环境健康状况、调查性能、对过时的物化视图进行故障排除、诊断内存压力、审核资源利用率、获取优化建议。对于客户端连接：配置/连接/设置 MCP 客户端以实现开发人员（模拟器、云或自我管理）、控制使用哪个用户/角色、在身份之间切换。即使用户只是说“检查我的环境”、“为什么我的 MV 陈旧”、“为什么我的集群很慢”、“我可以优化什么”、“如何将 Claude Code 连接到 Materialise-developer”或“为 Materialise MCP 配置游标”，也会触发。
