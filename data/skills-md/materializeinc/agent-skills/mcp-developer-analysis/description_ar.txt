قم بتحليل بيئة التجسيد عبر نقطة نهاية MCP Developer، و/أو قم بتكوين عميل MCP (Claude Code، Cursor، VS Code، Zed، continue، Windsurf، Claude Desktop) للاتصال بخادم تجسيد المطور. للتحليل: التحقق من صحة البيئة، والتحقق من الأداء، واستكشاف أخطاء طرق العرض المتحققة التي لا معنى لها وإصلاحها، وتشخيص ضغط الذاكرة، ومراجعة استخدام الموارد، والحصول على توصيات التحسين. للاتصال بالعميل: قم بتكوين/الاتصال/إعداد عميل MCP لتجسيد المطور (المحاكي أو السحابة أو الإدارة الذاتية)، والتحكم في المستخدم/الدور المستخدم، والتبديل بين الهويات. قم بالتشغيل حتى إذا قال المستخدم فقط "التحقق من بيئتي"، أو "لماذا أصبحت MV قديمة"، أو "لماذا تكون مجموعتي بطيئة"، أو "ما الذي يمكنني تحسينه"، أو "كيف يمكنني توصيل Claude Code بمطور التجسيد"، أو "تكوين المؤشر لـ Materialize MCP".
