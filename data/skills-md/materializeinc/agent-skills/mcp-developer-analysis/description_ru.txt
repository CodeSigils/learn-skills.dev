Проанализируйте среду Materialize через конечную точку MCP Developer и/или настройте клиент MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) для подключения к серверу Materialize-developer. Для анализа: проверьте работоспособность среды, исследуйте производительность, устраните неполадки с устаревшими материализованными представлениями, диагностируйте нехватку памяти, проверьте использование ресурсов, получите рекомендации по оптимизации. Для подключения клиента: настройте/подключите/настройте клиент MCP для материализации-разработчика (эмулятор, облако или самостоятельное управление), укажите, какой пользователь/роль используется, переключитесь между удостоверениями. Срабатывает, даже если пользователь просто говорит: «проверьте мою среду», «почему мой MV устарел», «почему мой кластер медленный», «что я могу оптимизировать», «как мне подключить Claude Code к Materialize-Developer» или «настроить курсор для Materialize MCP».
