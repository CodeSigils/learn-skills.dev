Analice un entorno de Materialise a través del punto final de MCP Developer y/o configure un cliente MCP (Claude Code, Cursor, VS Code, Zed, Continuar, Windsurf, Claude Desktop) para conectarse al servidor de materialize-developer. Para análisis: verifique el estado del entorno, investigue el rendimiento, solucione problemas de vistas materializadas obsoletas, diagnostique la presión de la memoria, audite la utilización de recursos y obtenga recomendaciones de optimización. Para conexión de cliente: configurar/conectar/configurar un cliente MCP para materializar-desarrollador (emulador, nube o autoadministrado), controlar qué usuario/rol se utiliza, cambiar entre identidades. Se activa incluso si el usuario simplemente dice "verificar mi entorno", "por qué mi MV está obsoleto", "por qué mi clúster es lento", "qué puedo optimizar", "cómo conecto Claude Code a materialize-developer" o "configurar el cursor para Materialise MCP".
