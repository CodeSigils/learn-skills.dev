MCP Developer エンドポイント経由でマテリアライズ環境を分析したり、MCP クライアント (Claude Code、Cursor、VS Code、Zed、Continue、Windsurf、Claude Desktop) を構成してマテリアライズ開発者サーバーに接続したりできます。分析の場合: 環境の健全性のチェック、パフォーマンスの調査、古くなったマテリアライズド ビューのトラブルシューティング、メモリ不足の診断、リソース使用率の監査、最適化の推奨事項の取得。クライアント接続の場合: 開発者 (エミュレーター、クラウド、または自己管理) を実現するための MCP クライアントの構成/接続/セットアップ、使用するユーザー/ロールの制御、アイデンティティ間の切り替え。ユーザーが「環境を確認してください」、「MV が古いのはなぜですか」、「クラスターが遅いのはなぜですか」、「何を最適化できますか」、「クロード コードをマテリアライズ開発者に接続するにはどうすればよいですか」、または「マテリアライズ MCP のカーソルを設定してください」と言った場合でもトリガーされます。
