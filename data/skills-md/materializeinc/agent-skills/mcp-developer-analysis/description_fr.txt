Analysez un environnement Materialise via le point de terminaison MCP Developer et/ou configurez un client MCP (Claude Code, Cursor, VS Code, Zed, Continue, Windsurf, Claude Desktop) pour vous connecter au serveur Materialise-Developer. Pour l'analyse : vérifiez l'état de l'environnement, étudiez les performances, dépannez les vues matérialisées obsolètes, diagnostiquez la pression de la mémoire, auditez l'utilisation des ressources, obtenez des recommandations d'optimisation. Pour la connexion client : configurer/connecter/installer un client MCP pour matérialiser le développeur (émulateur, cloud ou autogéré), contrôler quel utilisateur/rôle est utilisé, basculer entre les identités. Déclenchez même si l'utilisateur dit simplement « vérifier mon environnement », « pourquoi mon MV est-il obsolète », « pourquoi mon cluster est-il lent », « que puis-je optimiser », « comment connecter Claude Code au développeur Materialise » ou « configurer le curseur pour le MCP Materialise ».
