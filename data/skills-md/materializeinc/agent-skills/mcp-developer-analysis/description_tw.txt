透過 MCP Developer 端點分析 Materialise 環境，和/或設定 MCP 用戶端（Claude Code、Cursor、VS Code、Zed、Continue、Windsurf、Claude Desktop）以連接到 Materialise-Developer 伺服器。用於分析：檢查環境健康狀況、調查效能、對過時的物化視圖進行故障排除、診斷記憶體壓力、審核資源利用率、取得最佳化建議。對於客戶端連線：設定/連線/設定 MCP 用戶端以實現開發人員（模擬器、雲端或自我管理）、控制使用哪個使用者/角色、在身分之間切換。即使用戶只是說“檢查我的環境”、“為什麼我的 MV 陳舊”、“為什麼我的叢集很慢”、“我可以優化什麼”、“如何將 Claude Code 連接到 Materialise-developer”或“為 Materialise MCP 配置遊標”，也會觸發。
