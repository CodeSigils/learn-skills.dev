Moduli Terraform per la distribuzione di Materialise autogestita su AWS (EKS), Azure (AKS) e GCP (GKE). Copre il networking, i cluster Kubernetes, PostgreSQL gestito, l'archiviazione di oggetti, l'operatore Materialise e la configurazione dell'istanza Materialise. Utilizza questa competenza ogni volta che l'utente chiede informazioni sulla distribuzione di Materialise autogestita con Terraform, sulla configurazione dell'infrastruttura Materialise su qualsiasi cloud, sulla configurazione di EKS/AKS/GKE per Materialise, sulla risoluzione dei problemi di una distribuzione autogestita, sull'aggiornamento delle istanze di Materialise, sulla personalizzazione delle variabili Terraform per Materialise o sull'utilizzo del repository autogestito materialise-terraform. Si attiva anche quando l'utente menziona i pool di nodi Karpenter per gli URL di materialise, persist o backend dei metadati, il grafico Helm dell'operatore Materialise, le versioni CRD (v1alpha1 vs v1), le strategie di implementazione o la configurazione di scambio NVMe per i nodi Materialise.
