AWS (EKS)、Azure (AKS)、および GCP (GKE) にセルフマネージドの Materialize をデプロイするための Terraform モジュール。ネットワーキング、Kubernetes クラスター、マネージド PostgreSQL、オブジェクト ストレージ、Materialize オペレーター、および Materialsize インスタンス構成について説明します。 Terraform を使用したセルフマネージドの Materialize のデプロイ、任意のクラウド上での Materialize インフラストラクチャのセットアップ、Materialize 用の EKS/AKS/GKE の構成、セルフマネージドのデプロイメントのトラブルシューティング、Materialize インスタンスのアップグレード、Materialize の Terraform 変数のカスタマイズ、またはmaterialize-terraform-self-managed リポジトリの操作についてユーザーから質問されたときは、このスキルを使用してください。また、ユーザーがマテリアライズの Karpenter ノード プール、永続またはメタデータ バックエンド URL、マテリアライズ オペレーター ヘルム チャート、CRD バージョン (v1alpha1 と v1)、ロールアウト戦略、またはマテリアライズ ノードの NVMe スワップ構成に言及したときにもトリガーされます。
