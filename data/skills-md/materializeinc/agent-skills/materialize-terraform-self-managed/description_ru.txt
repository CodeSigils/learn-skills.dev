Модули Terraform для самостоятельного развертывания Materialize на AWS (EKS), Azure (AKS) и GCP (GKE). Охватывает сеть, кластеры Kubernetes, управляемый PostgreSQL, объектное хранилище, оператор Materialize и конфигурацию экземпляра Materialize. Используйте этот навык всякий раз, когда пользователь спрашивает о развертывании Самоуправляемого Materialize с помощью Terraform, настройке инфраструктуры Materialize в любом облаке, настройке EKS/AKS/GKE для Materialize, устранении неполадок при самостоятельном развертывании, обновлении экземпляров Materialize, настройке переменных Terraform для Materialize или работе с самоуправляемым репозиторием Materialize-terraform-self-managed. Также срабатывает, когда пользователь упоминает пулы узлов Karpenter для Materialize, постоянные URL-адреса или внутренние URL-адреса метаданных, диаграмму Helm оператора Materialize, версии CRD (v1alpha1 против v1), стратегии развертывания или конфигурацию подкачки NVMe для узлов Materialize.
