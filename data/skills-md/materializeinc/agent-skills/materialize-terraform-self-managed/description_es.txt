Módulos Terraform para implementar Materialize autoadministrado en AWS (EKS), Azure (AKS) y GCP (GKE). Cubre redes, clústeres de Kubernetes, PostgreSQL administrado, almacenamiento de objetos, el operador Materialise y la configuración de instancias de Materialize. Utilice esta habilidad siempre que el usuario pregunte sobre la implementación de Materialize autoadministrado con Terraform, la configuración de la infraestructura de Materialise en cualquier nube, la configuración de EKS/AKS/GKE para Materialise, la solución de problemas de una implementación autoadministrada, la actualización de instancias de Materialize, la personalización de variables de Terraform para Materialise o el trabajo con el repositorio autoadministrado materialize-terraform. También se activa cuando el usuario menciona grupos de nodos de Karpenter para Materialise, URL de backend persistentes o de metadatos, el gráfico Helm del operador de Materialize, versiones CRD (v1alpha1 vs v1), estrategias de implementación o configuración de intercambio NVMe para nodos Materialize.
