وحدات Terraform لنشر Materialize المُدارة ذاتيًا على AWS (EKS)، وAzure (AKS)، وGCP (GKE). يغطي الشبكات ومجموعات Kubernetes وPostgreSQL المُدارة وتخزين الكائنات ومشغل Materialize وتكوين مثيل Materialize. استخدم هذه المهارة عندما يسأل المستخدم عن نشر Materialize المُدار ذاتيًا باستخدام Terraform، أو إعداد البنية الأساسية لـ Materialize على أي سحابة، أو تكوين EKS/AKS/GKE لـ Materialize، أو استكشاف أخطاء النشر المُدار ذاتيًا وإصلاحها، أو ترقية مثيلات Materialize، أو تخصيص متغيرات Terraform لـ Materialize، أو العمل مع مستودع Materialize-terraform المُدار ذاتيًا. يتم التشغيل أيضًا عندما يذكر المستخدم مجموعات عقدة Karpenter لعناوين URL الخلفية لـ Materialize أو الاستمرار أو بيانات التعريف، أو مخطط Helm لمشغل Materialize، أو إصدارات CRD (v1alpha1 vs v1)، أو استراتيجيات الطرح، أو تكوين مبادلة NVMe لعقد Materialize.
