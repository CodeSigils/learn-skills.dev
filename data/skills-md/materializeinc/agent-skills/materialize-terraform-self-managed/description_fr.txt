Modules Terraform pour le déploiement de Materialise autogéré sur AWS (EKS), Azure (AKS) et GCP (GKE). Couvre la mise en réseau, les clusters Kubernetes, PostgreSQL géré, le stockage d'objets, l'opérateur Materialise et la configuration de l'instance Materialise. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur le déploiement de Materialise autogéré avec Terraform, la configuration de l'infrastructure Materialise sur n'importe quel cloud, la configuration d'EKS/AKS/GKE pour Materialise, le dépannage d'un déploiement autogéré, la mise à niveau des instances Materialise, la personnalisation des variables Terraform pour Materialise ou l'utilisation du référentiel Materialise-terraform-self-managed. Se déclenche également lorsque l'utilisateur mentionne les pools de nœuds Karpenter pour les URL backend Materialise, persistantes ou de métadonnées, le graphique Helm de l'opérateur Materialise, les versions CRD (v1alpha1 vs v1), les stratégies de déploiement ou la configuration d'échange NVMe pour les nœuds Materialise.
