Terraform-Module für die Bereitstellung von selbstverwaltetem Materialise auf AWS (EKS), Azure (AKS) und GCP (GKE). Behandelt Netzwerke, Kubernetes-Cluster, verwaltetes PostgreSQL, Objektspeicher, den Materialise-Operator und die Materialise-Instanzkonfiguration. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach der Bereitstellung von selbstverwaltetem Materialise mit Terraform, dem Einrichten der Materialise-Infrastruktur in einer beliebigen Cloud, der Konfiguration von EKS/AKS/GKE für Materialise, der Fehlerbehebung bei einer selbstverwalteten Bereitstellung, der Aktualisierung von Materialise-Instanzen, der Anpassung von Terraform-Variablen für Materialise oder der Arbeit mit dem selbstverwalteten Materialise-Terraform-Repository fragt. Wird auch ausgelöst, wenn der Benutzer Karpenter-Knotenpools für Materialise-, Persistenz- oder Metadaten-Backend-URLs, das Materialise-Operator-Helmdiagramm, CRD-Versionen (v1alpha1 vs. v1), Rollout-Strategien oder NVMe-Swap-Konfiguration für Materialise-Knoten erwähnt.
