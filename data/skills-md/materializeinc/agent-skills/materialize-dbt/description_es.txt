Uso del adaptador dbt-materialize para administrar canalizaciones de transmisión de Materialize con dbt. Cubre materializaciones (fuente, tabla_fuente, vista, vista_materializada, receptor, tabla, semilla), configuración de perfil, creación de índice, implementaciones azul/verde (deploy_init, implementar_promote, implementar_cleanup), administración de clústeres, modo estricto y pruebas. Utilice esta habilidad siempre que el usuario pregunte sobre cómo escribir modelos dbt para Materialise, configurar perfiles dbt para Materialize, ejecutar dbt contra Materialize, implementaciones azul/verde o sin tiempo de inactividad con dbt, crear fuentes o sumideros en dbt, solucionar problemas de dbt-materialize o migrar proyectos dbt existentes a Materialize. También se activa cuando el usuario menciona dbt-materialize, materialized_view materialization, implementar_init, implementar_promote, implementar_await, estricto_modo, actualizar_interval, retener_historia o partición_por en un contexto dbt.
