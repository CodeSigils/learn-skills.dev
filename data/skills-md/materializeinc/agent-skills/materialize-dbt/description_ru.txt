Использование адаптера dbt-materialize для управления потоковыми конвейерами Materialize с помощью dbt. Охватывает материализацию (source, source_table, view, Materialized_view, приёмник, таблица, начальное число), конфигурацию профиля, создание индекса, синее/зелёное развертывание (deploy_init, Deploy_promote, Deploy_cleanup), управление кластером, строгий режим и тестирование. Используйте этот навык всякий раз, когда пользователь спрашивает о написании моделей dbt для Materialize, настройке профилей dbt для Materialize, запуске dbt для Materialize, синем/зеленом развертывании или развертывании с нулевым временем простоя с помощью dbt, создании источников или приемников в dbt, устранении проблем с dbt-materialize или переносе существующих проектов dbt в Materialize. Также срабатывает, когда пользователь упоминает dbt-materialize, Materialized_View Materialization, Deploy_init, Deploy_promote, Deploy_await, strict_mode, Refresh_interval, сохраняйте_историю или Partition_by в контексте dbt.
