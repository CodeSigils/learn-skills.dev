Utilisation de l'adaptateur dbt-materialize pour gérer les pipelines de streaming Materialise avec dbt. Couvre les matérialisations (source, source_table, vue, matérialisée_vue, récepteur, table, graine), la configuration du profil, la création d'index, les déploiements bleu/vert (deploy_init, déployer_promote, déployer_cleanup), la gestion des clusters, le mode strict et les tests. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur l'écriture de modèles dbt pour Materialise, la configuration de profils dbt pour Materialise, l'exécution de dbt sur Materialise, les déploiements bleu/vert ou sans temps d'arrêt avec dbt, la création de sources ou de récepteurs dans dbt, le dépannage de problèmes de dbt-materialize ou la migration de projets dbt existants vers Materialise. Déclenchez également lorsque l'utilisateur mentionne dbt-materialize,materialized_view matérialisation, déployer_init, déployer_promote, déployer_await, strict_mode,fresh_interval, retention_history ou partition_by dans un contexte dbt.
