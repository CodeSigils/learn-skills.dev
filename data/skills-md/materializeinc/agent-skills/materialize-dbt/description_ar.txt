استخدام محول dbt-materialize لإدارة خطوط أنابيب البث المادي باستخدام dbt. يغطي التجسيدات (المصدر، source_table، العرض، Materialized_view، الحوض، الجدول، البذور)، تكوين ملف التعريف، إنشاء الفهرس، عمليات النشر الأزرق/الأخضر (deploy_init، Publish_promote، Publish_cleanup)، وإدارة المجموعة، والوضع الصارم، والاختبار. استخدم هذه المهارة عندما يسأل المستخدم عن كتابة نماذج dbt لـ Materialize، أو تكوين ملفات تعريف dbt لـ Materialize، أو تشغيل dbt مقابل Materialize، أو عمليات النشر باللون الأزرق/الأخضر أو ​​عمليات النشر بدون توقف باستخدام dbt، أو إنشاء مصادر أو مصارف في dbt، أو استكشاف مشكلات تجسيد dbt وإصلاحها، أو ترحيل مشاريع dbt الحالية إلى Materialize. يتم التشغيل أيضًا عندما يذكر المستخدم dbt-materialize، أو المادي_عرض، أو Publish_init، أو Publish_promote، أو Publish_await، أو الصارم_mode، أو Refresh_interval، أو Retain_history، أو Partition_by في سياق dbt.
