قم بتحويل أي نص أو صفحة ويب أو عنوان URL إلى بطاقة معلومات HTML جاهزة للنشر.
مثالية لتحويل المقالات أو المواضيع أو الأوراق أو وجهات النظر أو ملخصات البيانات إلى بطاقات صور مناسبة لـ WeChat أو Xiaohongshu أو X.
استخدم هذه المهارة أولاً عندما يذكر المستخدم "بطاقة المعلومات، ملخص البطاقة، صورة المقالة، استخراج المحتوى، صورة المشاركة الاجتماعية، تحويل الرابط إلى بطاقة، إنشاء ملخص على شكل ملصق".
