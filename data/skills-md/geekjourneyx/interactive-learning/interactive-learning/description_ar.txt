اقبل أي نص أو رابط أو مستند أو سؤال، وقم بترقية "شرح هذا" إلى حلقة تعلم حقيقية: حدد أولاً ما إذا كان الأمر يستحق التعلم ومدى التعمق فيه، ثم استخدم الحد الأدنى من التحقق لفرض فهم حقيقي، وقم بإنشاء HTML لنقطة التفتيش ديناميكيًا عند الضرورة. استخدم هذه المهارة بشكل استباقي عندما يريد المستخدم بوضوح "الفهم الحقيقي" أو "إتقانه جيدًا" أو "مساعدتي في التحقق مما إذا كنت أفهمه بالفعل" - بدلاً من مجرد الرغبة في ملخص أو إعادة كتابة أو شرح عادي. ينطبق أيضًا عندما يريد المستخدم تصدير البطاقات التعليمية أو صفحات نقاط التفتيش أو صفحات المراجعة أو صفحات حالة التعلم.
