Siempre que el usuario claramente quiera “dominar”, “obtener”, “guiarme” o “verificar que realmente lo entiendo” (en lugar de simplemente un resumen, una reescritura o una explicación ordinaria), active esta habilidad de manera proactiva. Úselo también cuando el usuario desee exportar tarjetas de estudio, páginas de puntos de control, páginas de revisión o páginas de estado de aprendizaje.
