تطبيق مبادئ ديزني الـ 12 كتصميم عملي وقواعد هندسية للرسوم المتحركة الإجرائية. يُستخدم عند إنشاء حركة تعتمد على التعليمات البرمجية أو تحسينها أو مراجعتها أو تصحيح أخطاءها في الويب أو SVG أو اللوحة القماشية أو React أو Remotion أو اللعبة أو واجهة المستخدم أو الشخصية أو الكاميرا أو المشاهد ثلاثية الأبعاد؛ خاصة عندما تبدو الحركة قاسية، أو انعدام الوزن، أو ميكانيكية، أو غير واضحة، أو صحيحة جسديًا ولكنها ضعيفة بصريًا.
