À utiliser lorsque l'utilisateur dit « convertir ce code HTML en briques » ou « coller du code HTML dans des briques », ou qu'il dispose d'un Webflow, Framer, CodePen ou d'une ancienne exportation statique à importer dans un site Bricks. Convertit le HTML et le CSS bruts en éléments Bricks natifs, en mappant les couleurs, le type et l'espacement pour concevoir des jetons, ainsi que des classes ACSS une fois installées.
