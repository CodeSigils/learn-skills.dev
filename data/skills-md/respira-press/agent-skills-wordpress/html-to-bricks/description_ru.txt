Используйте, когда пользователь говорит «конвертировать этот HTML в блоки» или «вставить HTML в блоки» или у него есть Webflow, Framer, CodePen или старый статический экспорт для переноса на сайт Bricks. Преобразует необработанный HTML и CSS в собственные элементы Bricks, сопоставляя цвета, тип и интервалы с маркерами дизайна, а также классы ACSS при установке.
