Úselo cuando el usuario solicite crear un tipo de publicación personalizada, crear un portafolio, configurar estudios de casos, agregar miembros del equipo, eventos o episodios de podcasts, o diga "desarrollar un CPT". Crea el tipo de publicación más taxonomías de soporte, un grupo de campos ACF, entradas de muestra y una sugerencia de plantilla única específica del creador.
