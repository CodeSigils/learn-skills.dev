Используйте, когда пользователь просит создать собственный тип публикации, создать портфолио, настроить тематические исследования, добавить членов команды, события или эпизоды подкаста или говорит «подготовьте CPT». Создает тип публикации, а также вспомогательные таксономии, группу полей ACF, образцы записей и предложение единого шаблона для конкретного компоновщика.
