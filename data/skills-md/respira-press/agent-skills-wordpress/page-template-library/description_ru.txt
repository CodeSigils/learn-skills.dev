Используйте, когда пользователь говорит «сохраните это как шаблон», «создайте сборник сценариев из этой страницы», «запишите этот макет» или трижды вручную создал один и тот же тип страницы. Захватывает канонические шаблоны страниц в виде повторно используемых плейбуков, из которых последующая генерация страниц может создаваться за секунды.
