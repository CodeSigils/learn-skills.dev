Úselo cuando el usuario diga "crear un sistema de diseño para mi sitio", "extraer tokens de diseño", "capturar mi marca" o "crear mi guía de estilo", o después de un cambio de marca. Lee páginas representativas, archivos de temas y medios para extraer logotipos, colores, tipografía, espaciado y componentes, luego escribe una página de guía de estilo visible.
