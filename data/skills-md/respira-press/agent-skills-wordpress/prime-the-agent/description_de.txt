Verwenden Sie diese Option, wenn Sie eine Sitzung auf einer vorhandenen WordPress-Site starten oder wenn der Benutzer sagt: „Machen Sie sich bereit“, „Welchen Builder verwendet diese Site“ oder „Geben Sie mir eine Einweisung in die Site“. Lädt die aktive Site, erkennt den Builder, lädt Inline-Schemas, liest die gespeicherten Informationen pro Site und legt die Do-not-write-raw-HTML-Regel fest.
