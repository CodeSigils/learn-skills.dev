À utiliser lors du démarrage d'une session sur un site WordPress existant, ou lorsque l'utilisateur dit « préparez-vous », « quel constructeur ce site utilise-t-il » ou « donnez-moi un briefing sur le site ». Charge le site actif, détecte le générateur, charge les schémas en ligne, lit le résumé stocké par site et définit la règle ne pas écrire-raw-HTML.
