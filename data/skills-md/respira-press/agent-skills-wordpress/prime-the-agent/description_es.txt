Úselo al iniciar una sesión en un sitio de WordPress existente, o cuando el usuario diga "prepárate", "qué creador utiliza este sitio" o "dame una sesión informativa sobre el sitio". Carga el sitio activo, detecta el constructor, carga esquemas en línea, lee el resumen almacenado por sitio y establece la regla de no escribir HTML sin formato.
