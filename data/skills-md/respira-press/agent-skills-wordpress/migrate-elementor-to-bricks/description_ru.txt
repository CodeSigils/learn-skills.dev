Используйте, когда пользователь говорит «перенести элементор в блоки», «конвертировать элементор в блоки» или «переместить мой сайт из элементара в кирпичи». Считывает данные виджета Elementor JSON, сопоставляет каждый виджет с его эквивалентом Bricks и создает черновые дубликаты с чистым JSON Bricks.
