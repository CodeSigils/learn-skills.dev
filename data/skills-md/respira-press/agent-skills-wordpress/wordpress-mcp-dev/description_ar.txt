قم ببناء وصيانة ملحقات WordPress الحديثة وخوادم MCP، بما في ذلك منتجات WordPress+MCP المختلطة. يُستخدم عند تنفيذ بنية المكونات الإضافية (PHP، وREST API، وتكاملات Gutenberg/admin/page-builder)، وأدوات MCP (TypeScript/Python، ونقل stdio/HTTP)، وتعزيز الأمان، والترخيص/التحديثات، وسير عمل التسليم من السقالة إلى التوزيع.
