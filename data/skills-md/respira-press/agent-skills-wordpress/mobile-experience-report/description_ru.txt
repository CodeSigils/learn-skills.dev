Используйте, когда пользователь говорит: «Мой сайт плохо выглядит на мобильных устройствах», «проверьте макет для мобильных устройств», «проверка адаптивности» или «сайт не работает на телефонах». Диагностирует проблемы с точками останова, размером текста, сбоями расположения столбцов, скрытыми элементами и поведением меню навигации для каждого устройства.
