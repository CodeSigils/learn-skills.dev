À utiliser lorsque l'utilisateur dit « mon site semble mauvais sur mobile », « vérifier la mise en page mobile », « audit réactif » ou « site en panne sur les téléphones ». Diagnostique les problèmes de points d'arrêt, le dimensionnement du texte, les échecs d'empilement de colonnes, les éléments masqués et le comportement du menu de navigation, appareil par appareil.
