Verwenden Sie es für die Bearbeitung von In-Page-Inhalten auf einer WordPress-Site mit einem Seitenersteller. Behandelt das Finden von Elementen, das Anwenden chirurgischer Bearbeitungen, das Duplizieren vor großen Änderungen und das Überprüfen des Ergebnisses. Funktioniert mit Elementor 3 + 4, Divi 4 + 5, Beaver Builder, Bricks, Oxygen Classic, Oxygen 6, Breakdance, WPBakery, Uncode und Gutenberg.
