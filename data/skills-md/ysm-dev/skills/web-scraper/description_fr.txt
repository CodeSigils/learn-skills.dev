À utiliser lorsque l'utilisateur souhaite récupérer, explorer ou extraire des données d'un site Web ou d'une URL. Déclencheurs sur : "gratter ce site", "obtenir des données de cette URL", "explorer cette page", "extraire des données du Web", "extraire des données de ce lien", "télécharger des données de ce site Web", "J'ai besoin de données de [URL]", ou toute demande impliquant la collecte de données structurées à partir d'une page Web. Se déclenche également lorsque l'utilisateur fournit une URL et demande ses données au format CSV, JSON ou d'autres formats tabulaires. Chargez toujours la compétence Agent-Navigateur à côté de celle-ci.
