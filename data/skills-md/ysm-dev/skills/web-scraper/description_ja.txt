ユーザーが Web サイトまたは URL からデータをスクレイピング、クロール、または抽出する場合に使用します。トリガー: 「このサイトをスクレイピング」、「この URL からデータを取得」、「このページをクロール」、「Web からデータを抽出」、「このリンクからデータを取得」、「この Web サイトからデータをダウンロード」、「[URL] からデータが必要」、または Web ページからの構造化データの収集を含むリクエスト。また、ユーザーが URL を指定し、そのデータを CSV、JSON、またはその他の表形式で要求したときにもトリガーされます。常に、このスキルと一緒にエージェント ブラウザ スキルをロードします。
