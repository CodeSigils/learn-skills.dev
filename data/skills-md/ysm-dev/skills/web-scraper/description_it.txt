Utilizzare quando l'utente desidera eseguire lo scraping, la scansione o l'estrazione di dati da un sito Web o da un URL. Si attiva su: "raschia questo sito", "ottieni dati da questo URL", "scansiona questa pagina", "estrai dati dal Web", "estrai dati da questo collegamento", "scarica dati da questo sito Web", "Ho bisogno di dati da [URL]" o qualsiasi richiesta che comporti la raccolta di dati strutturati da una pagina Web. Si attiva anche quando l'utente fornisce un URL e richiede i relativi dati in CSV, JSON o altri formati tabulari. Carica sempre la capacità del browser dell'agente insieme a questa.
