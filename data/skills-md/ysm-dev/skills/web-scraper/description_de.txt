Verwenden Sie diese Option, wenn der Benutzer Daten von einer Website oder URL scrapen, crawlen oder extrahieren möchte. Wird ausgelöst bei: „Diese Website scrapen“, „Daten von dieser URL abrufen“, „Diese Seite crawlen“, „Daten aus dem Web extrahieren“, „Daten von diesem Link abrufen“, „Daten von dieser Website herunterladen“, „Ich benötige Daten von [URL]“ oder jede Anfrage, die das Sammeln strukturierter Daten von einer Webseite beinhaltet. Wird auch ausgelöst, wenn der Benutzer eine URL angibt und nach deren Daten in CSV, JSON oder anderen Tabellenformaten fragt. Laden Sie immer den Agent-Browser-Skill neben diesem.
