Используйте, когда пользователь хочет очистить, просканировать или извлечь данные с веб-сайта или URL-адреса. Срабатывает при: «очистить этот сайт», «получить данные с этого URL-адреса», «сканировать эту страницу», «извлечь данные из Интернета», «извлечь данные из этой ссылки», «загрузить данные с этого веб-сайта», «Мне нужны данные из [URL]» или любого запроса, включающего сбор структурированных данных с веб-страницы. Также срабатывает, когда пользователь предоставляет URL-адрес и запрашивает его данные в CSV, JSON или других табличных форматах. Всегда загружайте навык агента-браузера рядом с этим.
