Úselo cuando el usuario quiera raspar, rastrear o extraer datos de un sitio web o URL. Activadores en: 'extraer este sitio', 'obtener datos de esta URL', 'rastrear esta página', 'extraer datos de la web', 'extraer datos de este enlace', 'descargar datos de este sitio web', 'Necesito datos de [URL]' o cualquier solicitud que implique la recopilación de datos estructurados de una página web. También se activa cuando el usuario proporciona una URL y solicita sus datos en CSV, JSON u otros formatos tabulares. Cargue siempre la habilidad agente-navegador junto con ésta.
