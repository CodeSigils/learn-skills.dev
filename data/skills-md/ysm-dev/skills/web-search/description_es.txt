Busque en la web desde la línea de comando usando duckduckgo-cli. Utilice esta habilidad siempre que necesite información actual, últimas noticias, eventos recientes, verificación de hechos, investigaciones, búsquedas de documentación o cualquier respuesta que pueda haber cambiado desde la capacitación. Active esto incluso cuando el usuario no diga "buscar": frases como "qué es lo último...", "descubra...", "busque...", "¿X sigue siendo cierto?", "quién es el actual...", "comparar precios/opciones", o cualquier pregunta sobre cosas recientes debería activarlo.
