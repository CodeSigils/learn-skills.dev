Durchsuchen Sie das Web über die Befehlszeile mit duckduckgo-cli. Nutzen Sie diese Fähigkeit immer dann, wenn Sie aktuelle Informationen, aktuelle Nachrichten, aktuelle Ereignisse, Faktenprüfung, Recherche, Dokumentationssuche oder eine Antwort benötigen, die sich seit der Schulung geändert hat. Lösen Sie dies auch dann aus, wenn der Benutzer nicht „Suchen“ sagt – Sätze wie „Was ist das Neueste …“, „Finde es heraus …“, „Schau nach …“, „Ist X immer noch wahr?“, „Wer ist das Aktuelle ...“, „Preise/Optionen vergleichen“ oder jede Frage zu aktuellen Dingen sollte es aktivieren.
