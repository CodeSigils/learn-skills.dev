Выполните поиск в Интернете из командной строки с помощью Duckduckgo-cli. Используйте этот навык всякий раз, когда вам нужна актуальная информация, последние новости, недавние события, проверка фактов, исследования, поиск документации или любой ответ, который мог измениться со времени обучения. Активируйте это, даже если пользователь не говорит «поиск» — такие фразы, как «что нового...», «узнать...», «поищите...», «X все еще верно?», «кто сейчас...», «сравнить цены/варианты» или любой вопрос о недавних событиях должны активировать его.
