À utiliser lorsque l'utilisateur pose des questions sur le contenu de sa base de connaissances OpenKB
— sujets de recherche, concepts compilés à partir de leurs documents,
synthèse inter-documents - ou mentionne `openkb`, un `.openkb/`
répertoire, ou une arborescence `wiki/` générée par openkb. L'utilisateur peut
vous invoquer depuis n'importe quel répertoire de travail ; la base de connaissances active est résolue via
`statut openkb`. Ne PAS utiliser pour des répertoires Markdown arbitraires,
Coffres-forts en obsidienne ou sites de documentation non construits par openkb.
