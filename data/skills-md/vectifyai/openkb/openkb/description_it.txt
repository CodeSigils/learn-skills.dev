Da utilizzare quando l'utente chiede informazioni sul contenuto nella propria knowledge base OpenKB
— argomenti di ricerca, concetti ricavati dai loro documenti,
sintesi tra documenti - o menziona `openkb`, un `.openkb/`
directory o un albero `wiki/` generato da openkb. L'utente può
invocarti da qualsiasi directory di lavoro; il KB attivo si risolve tramite
"stato openkb". NON utilizzare per directory Markdown arbitrarie,
Depositi di ossidiana o siti di documentazione non creati da openkb.
