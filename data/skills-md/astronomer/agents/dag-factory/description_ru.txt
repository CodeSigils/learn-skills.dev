Создавайте DAG Apache Airflow декларативно с помощью конфигураций YAML dag-factory. Используйте при создании шаблонов DAG-Factory, составлении DAG-файлов из YAML для DAG-Factory, настройке значений по умолчанию/динамических задач/наборов данных/обратных вызовов для DAG-Factory или проверке конфигураций DAG-Factory.
