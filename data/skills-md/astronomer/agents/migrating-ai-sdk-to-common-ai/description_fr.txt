Migre les projets Airflow d'airflow-ai-sdk vers apache-airflow-providers-common-ai 0.1.0+. Utilisez cette compétence lorsque l'utilisateur souhaite remplacer airflow-ai-sdk par le fournisseur officiel Airflow AI, migrer les décorateurs LLM (@task.llm, @task.agent, @task.llm_branch, @task.embed), passer des chaînes/objets de modèle à la configuration LLM basée sur la connexion ou mettre à jour les importations d'airflow_ai_sdk vers le nouveau fournisseur. Déclenchez également lorsque l'utilisateur mentionne le fournisseur common-ai, AIP-99, la connexion pydanticai ou la migration loin d'airflow-ai-sdk.
