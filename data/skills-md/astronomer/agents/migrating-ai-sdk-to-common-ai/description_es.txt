Migra proyectos de Airflow de airflow-ai-sdk a apache-airflow-providers-common-ai 0.1.0+. Utilice esta habilidad cuando el usuario desee reemplazar airflow-ai-sdk con el proveedor oficial de Airflow AI, migrar decoradores de LLM (@task.llm, @task.agent, @task.llm_branch, @task.embed), cambiar de cadenas/objetos de modelo a una configuración de LLM basada en conexión o actualizar las importaciones de airflow_ai_sdk al nuevo proveedor. También se activa cuando el usuario menciona el proveedor common-ai, AIP-99, la conexión pydanticai o la migración fuera de airflow-ai-sdk.
