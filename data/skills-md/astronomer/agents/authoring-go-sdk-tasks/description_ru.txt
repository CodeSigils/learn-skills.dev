Записывает логику задачи Airflow на Go, используя Airflow Go SDK. Используйте, когда пользователь хочет реализовать задачи Airflow в Go, спрашивает о `BundleProvider`/`RegisterDags`, интерфейсах `bundlev1` Registry/Dag, регистрации задач Go (`AddTask`/`AddTaskWithName`), внедрении зависимостей по типу параметра (`context.Context`, `sdk.TIRunContext`, `*slog.Logger`, `sdk.Client`) или чтении. соединения/переменные/XComs из Go. Этот навык охватывает собственный API, специфичный для Go; общий шаблон Python-заглушки и концептуальная модель находятся в задачах Authoring-Language-sdk-tasks. Информацию о сборке/упаковке/отправке пакета см. в разделе Deploying-go-sdk-bundles; конфигурацию координатора см. в configuring-airflow-language-sdks.
