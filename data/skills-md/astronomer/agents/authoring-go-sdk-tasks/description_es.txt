Escribe la lógica de tareas de Airflow en Go usando el SDK de Airflow Go. Úselo cuando el usuario desea implementar tareas de Airflow en Go, pregunta sobre `BundleProvider`/`RegisterDags`, las interfaces `bundlev1` Registry/Dag, el registro de tareas de Go (`AddTask`/`AddTaskWithName`), la inyección de dependencia por tipo de parámetro (`context.Context`, `sdk.TIRunContext`, `*slog.Logger`, `sdk.Client`), o lectura conexiones/variables/XComs de Go. Esta habilidad cubre la API nativa específica de Go; El patrón Python-stub y el modelo conceptual compartidos se encuentran en Authoring-language-sdk-tasks. Para crear/embalar/enviar el paquete, consulte implementar-go-sdk-bundles; para la configuración del coordinador, consulte configuración-airflow-language-sdks.
