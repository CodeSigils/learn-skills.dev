Airflow Go SDK を使用して、Airflow タスク ロジックを Go で作成します。ユーザーが Go で Airflow タスクを実装したい場合、`BundleProvider`/`RegisterDags`、`bundlev1` レジストリ/Dag インターフェイス、Go タスクの登録 (`AddTask`/`AddTaskWithName`)、パラメーター タイプによる依存関係注入 (`context.Context`、`sdk.TIRunContext`、`*slog.Logger`、 `sdk.Client`)、または Go から接続/変数/XCom を読み取ります。このスキルは Go 固有のネイティブ API をカバーします。共有された Python スタブ パターンと概念モデルは、authoring-lang-sdk-tasks 内に存在します。バンドルの構築/梱包/発送については、deploying-go-sdk-bundles を参照してください。コーディネーターの設定については、configuring-airflow- language-sdks を参照してください。
