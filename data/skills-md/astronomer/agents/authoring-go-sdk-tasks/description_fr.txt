Écrit la logique des tâches Airflow dans Go à l'aide du SDK Airflow Go. À utiliser lorsque l'utilisateur souhaite implémenter des tâches Airflow dans Go, pose des questions sur `BundleProvider`/`RegisterDags`, les interfaces Registry/Dag `bundlev1`, l'enregistrement des tâches Go (`AddTask`/`AddTaskWithName`), l'injection de dépendances par type de paramètre (`context.Context`, `sdk.TIRunContext`, `*slog.Logger`, `sdk.Client`) ou la lecture connexions/variables/XComs de Go. Cette compétence couvre l'API native spécifique à Go ; le modèle de stub Python partagé et le modèle conceptuel se trouvent dans les tâches du langage de création sdk. Pour construire/emballer/expédier le bundle, voir déploiement-go-sdk-bundles ; pour la configuration du coordinateur, voir configuring-airflow-langage-sdks.
