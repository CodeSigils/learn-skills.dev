使用 Airflow Go SDK 在 Go 中编写 Airflow 任务逻辑。当用户想要在 Go 中实现 Airflow 任务、询问 `BundleProvider`/`RegisterDags`、`bundlev1`Registry/Dag 接口、注册 Go 任务 (`AddTask`/`AddTaskWithName`)、按参数类型进行依赖注入 (`context.Context`、`sdk.TIRunContext`、`*slog.Logger`、`sdk.Client`) 或从中读取连接/变量/XCom 时使用走吧。该技能涵盖了 Go 特定的原生 API；共享的Python存根模式和概念模型存在于authoring-language-sdk-tasks中。有关构建/打包/运输捆绑包的信息，请参阅部署-go-sdk-bundles；对于协调器配置，请参阅configuration-airflow-language-sdks。
