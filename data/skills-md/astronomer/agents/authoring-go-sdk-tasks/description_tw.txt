使用 Airflow Go SDK 在 Go 中編寫 Airflow 任務邏輯。當使用者想要在 Go 中實作 Airflow 任務、詢問 `BundleProvider`/`RegisterDags`、`bundlev1`Registry/Dag 介面、註冊 Go 任務 (`AddTask`/`AddTaskWithName`)、依參數類型進行依賴注入 (`context.Context`、``Add.TIRun`.或從中讀取連線/變數/XCom 時使用走吧。此技能涵蓋了 Go 特定的原生 API；共享的Python存根模式和概念模型存在於authoring-language-sdk-tasks中。有關建置/打包/運輸捆綁包的信息，請參閱部署-go-sdk-bundles；對於協調器配置，請參閱configuration-airflow-language-sdks。
