Airflow Go SDK를 사용하여 Go에서 Airflow 작업 로직을 작성합니다. 사용자가 Go에서 Airflow 작업을 구현하려고 할 때, `BundleProvider`/`RegisterDags`, `bundlev1` 레지스트리/Dag 인터페이스, Go 작업 등록(`AddTask`/`AddTaskWithName`), 매개변수 유형별 종속 항목 삽입(`context.Context`, `sdk.TIRunContext`, `*slog.Logger`, `sdk.Client`)에 대해 질문하거나 다음에서 연결/변수/XCom을 읽을 때 사용합니다. 가세요. 이 기술은 Go 관련 기본 API를 다룹니다. 공유 Python-stub 패턴과 개념 모델은 저작 언어 SDK 작업에 있습니다. 번들을 빌드/포장/배송하려면 배포-go-sdk-bundles를 참조하세요. 코디네이터 구성은 구성-airflow-언어-sdks를 참조하세요.
