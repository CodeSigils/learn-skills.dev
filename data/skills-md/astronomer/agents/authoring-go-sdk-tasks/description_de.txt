Schreibt Airflow-Aufgabenlogik in Go mithilfe des Airflow Go SDK. Wird verwendet, wenn der Benutzer Airflow-Aufgaben in Go implementieren möchte, nach „BundleProvider“/„RegisterDags“, den Registry/Dag-Schnittstellen „bundlev1“, der Registrierung von Go-Aufgaben („AddTask“/„AddTaskWithName“), der Abhängigkeitsinjektion nach Parametertyp („context.Context“, „sdk.TIRunContext“, „*slog.Logger“, „sdk.Client“) oder zum Lesen fragt Verbindungen/Variablen/XComs von Go. Dieser Skill deckt die Go-spezifische native API ab; Das gemeinsame Python-Stub-Muster und das konzeptionelle Modell leben in Authoring-Language-SDK-Tasks. Informationen zum Erstellen/Verpacken/Versenden des Bundles finden Sie unter „deploying-go-sdk-bundles“; Informationen zur Koordinatorkonfiguration finden Sie unter configure-airflow-lingual-sdks.
