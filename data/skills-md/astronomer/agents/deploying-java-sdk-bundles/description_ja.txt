コンパイルされた Airflow Java SDK バンドルを構築してデプロイし、ワーカーが実行できるようにします。ユーザーが JVM タスク バンドルを JAR にパッケージ化したい場合、「org.apache.airflow.sdk」 Gradle プラグイン、「./gradlew バンドル」、Maven シェード/BOM セットアップ、ファット JAR とシン JAR のログ記録統合アーティファクト (JPL、SLF4J、Log4j 2、JUL)、プレビュー/スナップショット ビルド、または JAR を Airflow ワーカー (Docker、 Kubernetes、または Astro)。タスク コードについては、authoring-java-sdk-tasks を参照してください。 Airflow コーディネーターの設定については、configuring-airflow- language-sdks を参照してください。
