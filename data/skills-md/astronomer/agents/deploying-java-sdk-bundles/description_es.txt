Crea e implementa paquetes compilados de Airflow Java SDK para que los trabajadores puedan ejecutarlos. Úselo cuando el usuario desea empaquetar un paquete de tareas JVM en un JAR, pregunta sobre el complemento Gradle `org.apache.airflow.sdk`, `./gradlew bundle`, la configuración de sombra/BOM de Maven, JAR gruesos vs delgados, los artefactos de integración de registro (JPL, SLF4J, Log4j 2, JUL), compilaciones de vista previa/instantáneas o cómo obtener el JAR en un trabajador de Airflow (Docker, Kubernetes o Astro). Para ver el código de la tarea, consulte Authoring-java-sdk-tasks; para conocer la configuración del coordinador de Airflow, consulte configuración-airflow-language-sdks.
