Создает и развертывает скомпилированные пакеты Airflow Java SDK, чтобы сотрудники могли их запускать. Используйте, когда пользователь хочет упаковать пакет задач JVM в JAR, спрашивает о плагине `org.apache.airflow.sdk` Gradle, `./gradlew Bundle`, настройке Maven Shade/BOM, толстых и тонких JAR-файлах, артефактах интеграции журналирования (JPL, SLF4J, Log4j 2, JUL), сборках предварительного просмотра/снимков или передаче JAR на рабочий поток Airflow (Docker, Kubernetes или Астро). Код задачи см. в разделеauthoring-java-sdk-tasks; настройки координатора Airflow см. в разделе configuring-airflow-language-sdks.
