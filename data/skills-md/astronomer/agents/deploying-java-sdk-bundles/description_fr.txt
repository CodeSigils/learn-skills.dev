Crée et déploie des ensembles de SDK Airflow Java compilés afin que les utilisateurs puissent les exécuter. À utiliser lorsque l'utilisateur souhaite regrouper un ensemble de tâches JVM dans un JAR, pose des questions sur le plugin Gradle `org.apache.airflow.sdk`, `./gradlew bundle`, la configuration Maven shade/BOM, les JAR gras ou fins, les artefacts d'intégration de journalisation (JPL, SLF4J, Log4j 2, JUL), les versions d'aperçu/instantané ou l'obtention du JAR sur un travailleur Airflow (Docker, Kubernetes ou Astro). Pour le code de la tâche, voir authoring-java-sdk-tasks ; pour les paramètres du coordinateur Airflow, voir configuring-airflow- Language-sdks.
