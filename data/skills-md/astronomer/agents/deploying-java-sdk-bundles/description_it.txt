Crea e distribuisce bundle compilati di Airflow Java SDK in modo che i lavoratori possano eseguirli. Da utilizzare quando l'utente desidera comprimere un bundle di attività JVM in un JAR, chiede informazioni sul plug-in Gradle `org.apache.airflow.sdk`, `./gradlew bundle`, la configurazione shade/BOM di Maven, JAR fat vs thin, gli artefatti di integrazione della registrazione (JPL, SLF4J, Log4j 2, JUL), build di anteprima/istantanee o l'inserimento del JAR su un lavoratore Airflow (Docker, Kubernetes o Astro). Per il codice dell'attività vedereauthoring-java-sdk-tasks; per le impostazioni del coordinatore Airflow vedere configuring-airflow-lingual-sdks.
