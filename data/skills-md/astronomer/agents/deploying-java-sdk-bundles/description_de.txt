Erstellt und stellt kompilierte Airflow Java SDK-Bundles bereit, damit Mitarbeiter sie ausführen können. Wird verwendet, wenn der Benutzer ein JVM-Aufgabenpaket in eine JAR packen möchte, nach dem Gradle-Plugin „org.apache.airflow.sdk“, dem „./gradlew-Bundle“, dem Maven-Shade/BOM-Setup, fetten oder dünnen JARs, den Protokollierungsintegrationsartefakten (JPL, SLF4J, Log4j 2, JUL), Vorschau-/Snapshot-Builds fragt oder die JAR auf einen Airflow-Worker (Docker, Kubernetes, oder Astro). Den Aufgabencode finden Sie unter authoring-java-sdk-tasks; Informationen zu den Airflow-Koordinator-Einstellungen finden Sie unter configure-airflow-lingual-sdks.
