يبني وينشر حزم Airflow Java SDK المجمعة حتى يتمكن العمال من تشغيلها. يُستخدم عندما يريد المستخدم حزم حزمة مهام JVM في JAR، أو يسأل عن `org.apache.airflow.sdk` Gradle plugin، `./gradlew Bundle`، أو إعداد Maven Shade/BOM، أو ملفات JAR الدهنية مقابل الرقيقة، أو عناصر تكامل التسجيل (JPL، SLF4J، Log4j 2، JUL)، إنشاءات المعاينة/اللقطة، أو الحصول على JAR على عامل Airflow (Docker، كوبيرنيتيس، أو أسترو). للحصول على رمز المهمة، راجع Authoring-Java-sdk-tasks؛ للتعرف على إعدادات منسق Airflow، راجع configuring-airflow-language-sdks.
