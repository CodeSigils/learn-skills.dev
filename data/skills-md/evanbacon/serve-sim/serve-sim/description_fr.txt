Contrôle un iOS, un iPad ou un Apple Watch Simulator en cours d'exécution via la CLI serve-sim (npx serve-sim) et le diffuse dans le volet de prévisualisation de l'agent hôte. À utiliser chaque fois que l'utilisateur souhaite qu'un agent IA visualise ou pilote un Apple Simulator : streaming pour prévisualiser, tapotements sur des coordonnées normalisées, gestes multi-touch, boutons matériels, rotation, avertissements de mémoire, débogage CoreAnimation, injection de caméra synthétique, glisser-déposer multimédia ou gestion des autorisations de confidentialité des applications. Les déclencheurs incluent « serve-sim », « simulateur iOS », « simulateur Apple », « simulateur iPad », « simulateur Apple Watch », « diffuser le simulateur », « afficher le simulateur en aperçu », « afficher le simulateur ici », « ouvrir le simulateur en aperçu », « gestes du simulateur », « appuyer sur le simulateur », « faire pivoter le simulateur », « injecter le flux de la caméra », « accorder des autorisations au simulateur », « autoriser les notifications push dans le simulateur » ou toute demande de piloter ou d'afficher visuellement un simulateur Apple. Ne pas utiliser pour les émulateurs Android, la création/l'installation d'une application iOS (utilisez xcodebuild), le démarrage d'un simulateur à partir de zéro (utilisez xcrun simctl boot), le débogage du runtime React Native dans l'application (utilisez rn-debugger) ou le vrai matériel iOS.
