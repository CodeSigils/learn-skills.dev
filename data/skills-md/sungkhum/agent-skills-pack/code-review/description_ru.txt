Состязательная проверка кода, которая проверяет реализованную работу на соответствие истории/спецификации, критериям приемки и фактическим изменениям git. Используйте, когда пользователь просит провести проверку кода, просмотреть различия или PR, проверить выполнение задач или критериев приемки или проверить утверждения истории по сравнению с кодом.
