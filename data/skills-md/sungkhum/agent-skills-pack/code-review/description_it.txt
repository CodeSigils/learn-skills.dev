Revisione contraddittoria del codice che convalida il lavoro implementato rispetto a una storia/specifiche, criteri di accettazione e modifiche git effettive. Da utilizzare quando l'utente chiede di eseguire una revisione del codice, rivedere una differenza/PR, verificare che le attività o i criteri di accettazione siano stati eseguiti o convalidare le affermazioni della storia rispetto al codice.
