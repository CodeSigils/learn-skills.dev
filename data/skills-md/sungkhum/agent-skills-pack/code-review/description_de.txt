Kontroverse Codeüberprüfung, die implementierte Arbeit anhand einer Story/Spezifikation, Akzeptanzkriterien und tatsächlichen Git-Änderungen validiert. Verwenden Sie diese Option, wenn der Benutzer eine Codeüberprüfung durchführen, einen Diff/PR überprüfen, überprüfen möchte, ob Aufgaben oder Akzeptanzkriterien erfüllt sind, oder Story-Ansprüche im Vergleich zum Code validieren möchte.
