مراجعة التعليمات البرمجية التنافسية التي تتحقق من صحة العمل المنفَّذ مقابل القصة/المواصفات، ومعايير القبول، والتغييرات الفعلية في البوابة. يُستخدم عندما يطلب المستخدم إجراء مراجعة للتعليمات البرمجية، أو مراجعة الفرق/العلاقات العامة، أو التحقق من إتمام المهام أو معايير القبول، أو التحقق من صحة مطالبات القصة مقابل التعليمات البرمجية.
