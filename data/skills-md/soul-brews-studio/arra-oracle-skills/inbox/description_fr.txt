Lisez et écrivez dans la boîte de réception Oracle : notes, tâches, messages, transferts. À utiliser lorsque l'utilisateur dit « boîte de réception », « laisser une note », « écrire dans la boîte de réception », « vérifier la boîte de réception », « ce qui est en attente » ou souhaite lire/écrire des messages pour lui-même ou pour d'autres agents. Ne déclenchez PAS les transferts de session (utilisez /forward), la planification (utilisez /schedule) ou la messagerie d'agent (utilisez /talk-to).
