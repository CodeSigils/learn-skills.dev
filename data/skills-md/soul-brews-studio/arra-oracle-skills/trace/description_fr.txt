v3.3.1 G-SKLL | Recherchez des projets, du code et des connaissances dans l'historique Git, les dépôts, les documents et Oracle. À utiliser lorsque l'utilisateur demande "tracer", "trouver un projet", "où se trouve [projet]", "historique de recherche" ou a besoin de localiser quelque chose dans la base de code. Prend en charge --oracle (rapide), --smart (par défaut), --deep (exécution wave). Ne déclenchez PAS l'exploration de session ou les "sessions passées" (utilisez /dig), ou l'exploration de la base de code "apprendre le dépôt" (utilisez /learn).
