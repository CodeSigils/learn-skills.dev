توجيه الجلسة والوعي بها - الملخصات القديمة، وعمليات التسليم، وحالة git، والتركيز. يُستخدم عند بدء جلسة، أو بعد /jump، أو فقدان مكانك، أو تبديل السياق، أو عندما يسأل المستخدم "الآن"، "أين نحن"، "ماذا نفعل"، "الحالة"، "ملخص". لا تقم بتشغيل "الوقوف" أو "الفحص الصباحي" (استخدم /standup)، أو "حفر" الجلسة، أو "الجلسات الماضية" (استخدم /dig).
