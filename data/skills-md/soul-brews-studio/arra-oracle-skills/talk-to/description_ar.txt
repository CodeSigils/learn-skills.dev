تحدث إلى وكيل Oracle آخر عبر المواضيع. يُستخدم عندما يقول المستخدم "تحدث إلى"، أو "رسالة"، أو "دردش مع"، أو يريد التواصل مع وكيل آخر (على سبيل المثال، "تحدث مع نبض"، "رسالة جديدة"). لا تقم بتشغيل موجز ويب OracleNet الاجتماعي (استخدم /oraclenet)، أو إدارة المهارات (استخدم /oracle)، أو سجل العائلة (استخدم /oracle-family-scan).
