Sprechen Sie über Threads mit einem anderen Oracle-Agenten. Verwenden Sie diese Option, wenn der Benutzer „Sprechen mit“, „Nachricht senden“, „Chatten mit“ sagt oder mit einem anderen Agenten kommunizieren möchte (z. B. „Mit Puls sprechen“, „Nachricht an Neo“). NICHT für den OracleNet-Social-Feed (verwenden Sie /oraclenet), das Skill-Management (verwenden Sie /oracle) oder das Familienregister (verwenden Sie /oracle-family-scan) auslösen.
