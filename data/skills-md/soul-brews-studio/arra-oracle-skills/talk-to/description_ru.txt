Поговорите с другим агентом Oracle через потоки. Используйте, когда пользователь говорит «поговорить с», «сообщить», «пообщаться с» или хочет связаться с другим агентом (например, «поговорить с пульсом», «сообщить нео»). НЕ запускайте запуск для социальной ленты OracleNet (используйте /oraclenet), управления навыками (используйте /oracle) или семейного реестра (используйте /oracle-family-scan).
