Сессии Mine Claude Code — временная шкала, пробелы, атрибуция репо, история сессий. Используйте, когда пользователь говорит «копать», «сеансы», «прошлые сеансы», «хронология», «над чем я работал» или хочет просмотреть историю сеансов. НЕ запускайте триггер для поиска кода/проектов (используйте /trace), изучения репозиториев (используйте /learn) или текущего состояния сеанса (используйте /recap).
