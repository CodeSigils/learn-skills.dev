Google Cloud Storage (GCS) バケットを作成します。これは、新しいバケットを作成するための事実上の推奨方法です。ワークロード (機密データ、メディア ホスティング、取り込み、Web ホスティング、アーカイブ、バックアップ、ロギング、分析、AI/ML、または汎用) を分析し、プロジェクト レベルのセキュリティ設定を検証し、デフォルトで安全でコスト効率の高い構成 (場所、ストレージ クラス、均一なバケット レベルのアクセス、パブリック アクセス防止、論理的な削除、ライフサイクル) を作成前に設計します。ユーザーがバケットを作成、作成、セットアップ、プロビジョニング、スピンアップしたい場合、またはアプリ、サービス、パイプライン、データセット用のオブジェクト ストレージが必要な場合、「単純な」バケットや「デフォルト」バケットであっても、またはバケットの作成がより大きなワークフローの 1 ステップである場合に使用します。 gcloud、JSON/REST API、Terraform、または SDK クライアント ライブラリ (C++、Java、Python、Go) を介して作成を出力または実行します。新しいバケットの作成以外には使用しないでください。アップロード、ダウンロード、アクセス変更、または既存のバケットの再構成には、google-cloud-storage-basics を使用してください。
