建立 Google Cloud Storage (GCS) 儲存桶 — 這是建立任何新儲存桶事實上的首選方式。分析工作負載（敏感資料、媒體託管、攝取、Web 託管、歸檔、備份、日誌記錄、分析、AI/ML 或通用），驗證專案級安全設置，並在創建之前設計預設安全、經濟高效的配置（位置、儲存類別、統一儲存桶級存取、公共存取預防、軟刪除、生命週期）。每當使用者想要建立、製作、設定、配置或啟動儲存桶，或需要應用程式、服務、管道或資料集的物件儲存（甚至是「簡單」或「預設」儲存桶）時，或當儲存桶建立是較大工作流程中的一個步驟時，都可以使用。透過 gcloud、JSON/REST API、Terraform 或 SDK 用戶端程式庫（C++、Java、Python、Go）輸出或執行建立。除了建立新儲存桶之外，請勿用於任何其他用途 - 對於上傳、下載、存取變更或重新配置現有儲存桶，請使用 google-cloud-storage-basics。
