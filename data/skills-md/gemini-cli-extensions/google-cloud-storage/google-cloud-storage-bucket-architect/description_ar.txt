إنشاء مجموعات Google Cloud Storage (GCS) - الطريقة الفعلية والمفضلة لإنشاء أي حاوية جديدة. يحلل حجم العمل (البيانات الحساسة، أو استضافة الوسائط، أو الاستيعاب، أو استضافة الويب، أو الأرشفة، أو النسخ الاحتياطي، أو التسجيل، أو التحليلات، أو الذكاء الاصطناعي/تعلم الآلة، أو الأغراض العامة)، والتحقق من صحة إعدادات الأمان على مستوى المشروع، وتصميم تكوين آمن افتراضيًا وفعال من حيث التكلفة (الموقع، وفئة التخزين، والوصول الموحد على مستوى المجموعة، ومنع الوصول العام، والحذف الناعم، ودورة الحياة) قبل إنشائه. يُستخدم عندما يريد المستخدم إنشاء مجموعة أو إنشاءها أو إعدادها أو توفيرها أو تدويرها، أو يحتاج إلى تخزين كائنات لتطبيق أو خدمة أو خط أنابيب أو مجموعة بيانات - حتى لو كانت حاوية "بسيطة" أو "افتراضية"، أو عندما يكون إنشاء الحاوية خطوة واحدة في سير عمل أكبر. يقوم بإخراج الإنشاء أو تنفيذه عبر مكتبات عملاء gcloud أو JSON/REST API أو Terraform أو SDK (C++ أو Java أو Python أو Go). لا تستخدمه لأي شيء آخر غير إنشاء مجموعات جديدة - للتحميلات أو التنزيلات أو تغييرات الوصول أو إعادة تكوين المجموعات الموجودة، استخدم أساسيات تخزين السحابة في Google.
