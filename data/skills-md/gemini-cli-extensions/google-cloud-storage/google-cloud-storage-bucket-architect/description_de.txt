Erstellt Google Cloud Storage (GCS)-Buckets – die de facto bevorzugte Methode zum Erstellen neuer Buckets. Analysiert die Arbeitslast (sensible Daten, Medienhosting, Aufnahme, Webhosting, Archivierung, Sicherung, Protokollierung, Analyse, KI/ML oder allgemeine Zwecke), validiert Sicherheitseinstellungen auf Projektebene und entwirft vor der Erstellung eine standardmäßig sichere, kostengünstige Konfiguration (Standort, Speicherklasse, einheitlicher Zugriff auf Bucket-Ebene, öffentliche Zugriffsverhinderung, vorläufiges Löschen, Lebenszyklus). Verwenden Sie es immer dann, wenn ein Benutzer einen Bucket erstellen, erstellen, einrichten, bereitstellen oder hochfahren möchte oder Objektspeicher für eine App, einen Dienst, eine Pipeline oder einen Datensatz benötigt – sogar für einen „einfachen“ oder „Standard“-Bucket, oder wenn die Bucket-Erstellung ein Schritt in einem größeren Workflow ist. Gibt die Erstellung über gcloud, die JSON/REST API, Terraform oder SDK-Clientbibliotheken (C++, Java, Python, Go) aus oder führt sie aus. Verwenden Sie es nur zum Erstellen neuer Buckets. Für Uploads, Downloads, Zugriffsänderungen oder die Neukonfiguration bestehender Buckets verwenden Sie google-cloud-storage-basics.
