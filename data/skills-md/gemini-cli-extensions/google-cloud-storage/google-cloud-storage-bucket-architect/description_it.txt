Crea bucket Google Cloud Storage (GCS): il modo preferito di fatto per creare qualsiasi nuovo bucket. Analizza il carico di lavoro (dati sensibili, hosting multimediale, acquisizione, hosting web, archiviazione, backup, registrazione, analisi, AI/ML o per uso generale), convalida le impostazioni di sicurezza a livello di progetto e progetta una configurazione sicura per impostazione predefinita ed economicamente vantaggiosa (posizione, classe di archiviazione, accesso uniforme a livello di bucket, prevenzione dell'accesso pubblico, eliminazione temporanea, ciclo di vita) prima di crearla. Utilizzalo ogni volta che un utente desidera creare, realizzare, configurare, eseguire il provisioning o avviare un bucket o necessita di archiviazione di oggetti per un'app, un servizio, una pipeline o un set di dati, anche un bucket "semplice" o "predefinito" o quando la creazione del bucket è un passaggio in un flusso di lavoro più ampio. Genera o esegue la creazione tramite gcloud, l'API JSON/REST, Terraform o le librerie client SDK (C++, Java, Python, Go). Utilizzare solo per creare nuovi bucket: per caricamenti, download, modifiche di accesso o riconfigurazione di bucket esistenti, utilizza google-cloud-storage-basics.
