Crea depósitos de Google Cloud Storage (GCS): la forma preferida de facto de crear cualquier depósito nuevo. Analiza la carga de trabajo (datos confidenciales, alojamiento de medios, ingesta, alojamiento web, archivado, copia de seguridad, registro, análisis, IA/ML o de propósito general), valida la configuración de seguridad a nivel de proyecto y diseña una configuración segura por defecto y rentable (ubicación, clase de almacenamiento, acceso uniforme a nivel de depósito, prevención de acceso público, eliminación temporal, ciclo de vida) antes de crearla. Úselo siempre que un usuario quiera crear, crear, configurar, aprovisionar o poner en marcha un depósito, o necesite almacenamiento de objetos para una aplicación, servicio, canalización o conjunto de datos, incluso un depósito "simple" o "predeterminado", o cuando la creación del depósito es un paso en un flujo de trabajo más amplio. Genera o ejecuta la creación a través de gcloud, la API JSON/REST, Terraform o las bibliotecas cliente SDK (C++, Java, Python, Go). No lo use para nada más que crear nuevos depósitos: para cargas, descargas, cambios de acceso o reconfiguración de depósitos existentes, use google-cloud-storage-basics.
