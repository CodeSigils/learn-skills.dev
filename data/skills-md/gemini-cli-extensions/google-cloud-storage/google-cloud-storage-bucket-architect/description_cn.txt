创建 Google Cloud Storage (GCS) 存储桶 — 这是创建任何新存储桶事实上的首选方式。分析工作负载（敏感数据、媒体托管、摄取、Web 托管、归档、备份、日志记录、分析、AI/ML 或通用），验证项目级安全设置，并在创建之前设计默认安全、经济高效的配置（位置、存储类、统一存储桶级访问、公共访问预防、软删除、生命周期）。每当用户想要创建、制作、设置、配置或启动存储桶，或者需要应用程序、服务、管道或数据集的对象存储（甚至是“简单”或“默认”存储桶）时，或者当存储桶创建是较大工作流程中的一个步骤时，都可以使用。通过 gcloud、JSON/REST API、Terraform 或 SDK 客户端库（C++、Java、Python、Go）输出或执行创建。除了创建新存储桶之外，请勿用于任何其他用途 - 对于上传、下载、访问更改或重新配置现有存储桶，请使用 google-cloud-storage-basics。
