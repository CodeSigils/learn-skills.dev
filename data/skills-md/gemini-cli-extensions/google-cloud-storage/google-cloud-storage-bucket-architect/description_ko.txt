Google Cloud Storage(GCS) 버킷을 생성합니다. 이는 사실상 새 버킷을 생성하는 데 선호되는 방법입니다. 워크로드(민감한 데이터, 미디어 호스팅, 수집, 웹 호스팅, 보관, 백업, 로깅, 분석, AI/ML 또는 범용)를 분석하고, 프로젝트 수준 보안 설정을 검증하고, 생성하기 전에 기본적으로 안전하고 비용 효율적인 구성(위치, 스토리지 클래스, 균일한 버킷 수준 액세스, 공개 액세스 방지, 일시 삭제, 수명 주기)을 설계합니다. 사용자가 버킷을 생성, 생성, 설정, 프로비저닝 또는 스핀업하려고 하거나 앱, 서비스, 파이프라인 또는 데이터세트에 대한 객체 스토리지가 필요할 때마다("단순" 또는 "기본" 버킷 포함) 버킷 생성이 더 큰 워크플로의 한 단계인 경우에 사용하세요. gcloud, JSON/REST API, Terraform 또는 SDK 클라이언트 라이브러리(C++, Java, Python, Go)를 통해 생성을 출력하거나 실행합니다. 새 버킷을 만드는 것 외에는 사용하지 마세요. 업로드, 다운로드, 액세스 변경 또는 기존 버킷 재구성의 경우 google-cloud-storage-basics를 사용하세요.
