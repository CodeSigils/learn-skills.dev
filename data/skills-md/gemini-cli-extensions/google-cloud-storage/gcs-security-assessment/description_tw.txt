評估 Google Cloud Storage (GCS) 儲存桶和專案的安全狀況。基於收集到的遙測資料中的每項發現，根據 Google 安全最佳實踐（公共存取、IAM 過度授予、CMEK、VPC 服務控制、審核日誌記錄）評估儲存桶，並將訊號關聯起來以標記各個低風險設定的有毒組合，並進行可行的補救措施。每當用戶要求進行安全掃描、審計、審查、漏洞檢查或合規性評估（包括 SAIF）時使用，或者只是詢問他們的存儲桶、項目或數據是否安全、暴露、公開或配置錯誤，誰可以訪問他們的數據，或者希望存儲強化或鎖定，例如在發射之前。請勿用於診斷特定存取故障或 403、管理或配置儲存、調查即時中斷或非 GCS 資源（計算引擎、GKE 等）。
