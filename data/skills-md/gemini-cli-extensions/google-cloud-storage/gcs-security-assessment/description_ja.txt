Google Cloud Storage (GCS) バケットとプロジェクトのセキュリティ体制を評価します。収集されたテレメトリーのすべての結果を根拠にし、Google セキュリティのベスト プラクティス (パブリック アクセス、IAM の過剰付与、CMEK、VPC サービス コントロール、監査ログ) に照らしてバケットを評価し、信号を関連付けて、個別にリスクの低い設定の有害な組み合わせにフラグを立て、実用的な修復を行います。ユーザーがセキュリティ スキャン、監査、レビュー、脆弱性チェック、またはコンプライアンス評価 (SAIF を含む) を要求するときは常に使用します。または、単にバケット、プロジェクト、データが安全か、公開されているか、公開されているか、設定が間違っているか、誰がデータにアクセスできるか、またはストレージの強化またはロックダウンを望んでいるかを単純に尋ねる場合に使用します。打ち上げの前に。特定のアクセス障害や 403 の診断、ストレージの管理または構成、ライブ停止の調査、または GCS 以外のリソース（Compute Engine、GKE など）には使用しないでください。
