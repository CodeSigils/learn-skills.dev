تقييم الوضع الأمني ​​لحاويات ومشاريع Google Cloud Storage (GCS). يرتكز كل اكتشاف في القياس عن بعد المجمع، ويقيم المجموعات مقابل أفضل ممارسات أمان Google (الوصول العام، والمنح المفرط لـ IAM، وCMEK، وضوابط خدمة VPC، وتسجيل التدقيق)، ويربط الإشارات لوضع علامة على المجموعات السامة من الإعدادات الفردية منخفضة المخاطر، مع المعالجة القابلة للتنفيذ. يُستخدم عندما يطلب المستخدم إجراء فحص أمني، أو تدقيق، أو مراجعة، أو فحص الثغرات الأمنية، أو تقييم الامتثال (بما في ذلك SAIF) - أو يسأل ببساطة عما إذا كانت مجموعاته أو مشروعه أو بياناته آمنة أو مكشوفة أو عامة أو تم تكوينها بشكل خاطئ، ومن يمكنه الوصول إلى بياناته، أو يريد تخزينًا معززًا أو مقفلاً، على سبيل المثال. قبل الإطلاق. لا تستخدم لتشخيص فشل وصول محدد أو 403، أو إدارة التخزين أو تكوينه، أو التحقيق في انقطاع مباشر، أو موارد غير تابعة لـ GCS (Compute Engine، GKE، وما إلى ذلك).
