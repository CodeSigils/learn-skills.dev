يقوم بتخزين البيانات واستردادها وإدارتها ككائنات في مجموعات التخزين السحابي (Google Cloud Storage، أو GCS). استخدمه عندما تحتاج إلى التفاعل مع Cloud Storage - إنشاء مجموعات أو تكوينها، وتحميل، وتنزيل، ودفق، أو نقل البيانات، وتنظيم الكائنات مع المجلدات، وإنشاء عناوين URL موقعة، والتحكم في الوصول (IAM، وقوائم ACL، ومنع الوصول العام)، وتعيين فئات التخزين والطبقات (قياسي، وNearline، وColdline، والأرشيف)، وإدارة التكلفة ودورة الحياة، وحماية البيانات (إصدار الإصدارات، والتشفير/CMEK، والاحتفاظ وقفل الجرافة، واحتجاز الكائنات، والحذف الناعم)، واستضافة مواقع الويب الثابتة، وتشغيل إشعارات Pub/Sub بشأن تغييرات الكائنات، قم بتحميل الدلاء كنظام ملفات (gcsfuse)، أو قم بتحسين أداء التخزين على أي نطاق. يغطي تخزين gcloud / واجهات برمجة التطبيقات gsutil CLI وJSON وXML ومكتبات العملاء وخوادم Terraform وCloud Storage MCP. لا تستخدمه لتخزين الكتل (القرص الثابت)، أو تخزين/تحليلات البيانات (BigQuery)، أو قواعد البيانات (Cloud SQL، أو Spanner، أو Bigtable، أو Firestore).
