Almacena, recupera y administra datos como objetos en depósitos de Cloud Storage (Google Cloud Storage o GCS). Úselo cuando necesite interactuar con Cloud Storage: cree o configure depósitos, cargue, descargue, transmita o transfiera datos, organice objetos con carpetas, genere URL firmadas, controle el acceso (IAM, ACL, prevención de acceso público), establezca clases y niveles de almacenamiento (Standard, Nearline, Coldline, Archive), administre el costo y el ciclo de vida, proteja los datos (versiones, cifrado/CMEK, retención y bloqueo de depósitos, retención de objetos, eliminación temporal), aloje sitios web estáticos, active notificaciones de Pub/Sub sobre cambios de objetos, monte depósitos como un sistema de archivos (gcsfuse) u optimizar el rendimiento del almacenamiento a cualquier escala. Cubre las API de gcloud Storage/gsutil CLI, JSON y XML, bibliotecas cliente, Terraform y servidores MCP de Cloud Storage. No lo use para almacenamiento en bloque (Disco persistente), almacenamiento/análisis de datos (BigQuery) o bases de datos (Cloud SQL, Spanner, Bigtable, Firestore).
