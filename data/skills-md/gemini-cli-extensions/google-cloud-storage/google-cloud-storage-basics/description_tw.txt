将数据作为 Cloud Storage（Google Cloud Storage 或 GCS）存储桶中的对象进行存储、检索和管理。當您需要與 Cloud Storage 互動時使用 - 建立或配置儲存桶、上傳、下載、串流或傳輸資料、使用資料夾組織物件、產生簽章 URL、控制存取（IAM、ACL、公共存取預防）、設定儲存類別和分層（標準、近線、冷線、EKsex）、管理成本和生命週期、保護資料（1/CM 保留版本、「儲存空間」、「實體」 通知、装载存储桶作为文件系统 (gcsfuse)，或优化任何规模的存储性能。涵盖 gcloud storage / gsutil CLI、JSON 和 XML API、客户端库、Terraform 和 Cloud Storage MCP 服务器。请勿用于块存储（持久磁盘）、数据仓库/分析 (BigQuery) 或数据库（Cloud SQL、Spanner、Bigtable、Firestore）。
