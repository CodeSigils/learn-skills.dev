將資料作為 Cloud Storage（Google Cloud Storage 或 GCS）儲存桶中的物件進行儲存、擷取和管理。当您需要与 Cloud Storage 交互时使用 - 创建或配置存储桶、上传、下载、流式传输或传输数据、使用文件夹组织对象、生成签名 URL、控制访问（IAM、ACL、公共访问预防）、设置存储类别和分层（标准、近线、冷线、存档）、管理成本和生命周期、保护数据（版本控制、加密/CMEK、保留和存储桶锁定、对象保留、软删除）、托管静态网站、触发有关对象更改的 Pub/Sub通知、裝載儲存桶作為檔案系統 (gcsfuse)，或最佳化任何規模的儲存效能。涵蓋 gcloud storage / gsutil CLI、JSON 和 XML API、客戶端程式庫、Terraform 和 Cloud Storage MCP 伺服器。請勿用於區塊儲存（持久性磁碟）、資料倉儲/分析 (BigQuery) 或資料庫（Cloud SQL、Spanner、Bigtable、Firestore）。
