Archivia, recupera e gestisce i dati come oggetti nei bucket Cloud Storage (Google Cloud Storage o GCS). Da utilizzare quando è necessario interagire con Cloud Storage: creare o configurare bucket, caricare, scaricare, eseguire lo streaming o trasferire dati, organizzare oggetti con cartelle, generare URL firmati, controllare l'accesso (IAM, ACL, prevenzione dell'accesso pubblico), impostare classi di archiviazione e tiering (Standard, Nearline, Coldline, Archivio), gestire costi e ciclo di vita, proteggere i dati (controllo delle versioni, crittografia/CMEK, conservazione e blocco bucket, blocchi di oggetti, eliminazione temporanea), ospitare siti Web statici, attivare notifiche Pub/Sub sulle modifiche degli oggetti, montare bucket come file system (gcsfuse) o ottimizzare le prestazioni di archiviazione su qualsiasi scala. Copre la CLI gcloud storage/gsutil, le API JSON e XML, le librerie client, Terraform e i server MCP Cloud Storage. Non utilizzare per l'archiviazione a blocchi (disco permanente), data warehousing/analisi (BigQuery) o database (Cloud SQL, Spanner, Bigtable, Firestore).
