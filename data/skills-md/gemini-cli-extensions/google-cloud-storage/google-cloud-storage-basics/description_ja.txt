データを Cloud Storage (Google Cloud Storage または GCS) バケット内のオブジェクトとして保存、取得、管理します。 Cloud Storage を操作する必要がある場合に使用します。バケットの作成または構成、データのアップロード、ダウンロード、ストリームまたは転送、フォルダーによるオブジェクトの整理、署名付き URL の生成、アクセスの制御 (IAM、ACL、パブリック アクセス防止)、ストレージ クラスと階層化 (標準、ニアライン、コールドライン、アーカイブ) の設定、コストとライフサイクルの管理、データの保護 (バージョン管理、暗号化/CMEK、保持とバケット ロック、オブジェクトの保持、論理的な削除)、静的ウェブサイトのホスト、オブジェクト変更時の Pub/Sub 通知のトリガー、マウントバケットをファイル システム (gcsfuse) として使用したり、あらゆる規模でストレージ パフォーマンスを最適化したりできます。 gcloud storage / gsutil CLI、JSON および XML API、クライアント ライブラリ、Terraform、Cloud Storage MCP サーバーについて説明します。ブロック ストレージ (Persistent Disk)、データ ウェアハウジング/分析 (BigQuery)、データベース (Cloud SQL、Spanner、Bigtable、Firestore) には使用しないでください。
