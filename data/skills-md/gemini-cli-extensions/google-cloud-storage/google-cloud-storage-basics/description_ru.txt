Хранит, извлекает и управляет данными как объектами в сегментах облачного хранилища (Google Cloud Storage или GCS). Используйте, когда вам нужно взаимодействовать с облачным хранилищем — создавать или настраивать корзины, загружать, скачивать, передавать в потоковом режиме или передавать данные, организовывать объекты с помощью папок, генерировать подписанные URL-адреса, контролировать доступ (IAM, ACL, предотвращение публичного доступа), устанавливать классы хранилища и уровни (стандартное, Nearline, Coldline, Archive), управлять стоимостью и жизненным циклом, защищать данные (версии, шифрование/CMEK, хранение и блокировка сегмента, удержание объектов, обратимое удаление), размещать статические веб-сайты, запускать уведомления Pub/Sub об изменениях объекта, монтировать сегменты в качестве файловой системы (gcsfuse) или оптимизировать производительность хранилища в любом масштабе. Охватывает интерфейс командной строки gcloud Storage/gsutil, API JSON и XML, клиентские библиотеки, серверы Terraform и Cloud Storage MCP. Не используйте для блочного хранилища (постоянный диск), хранилища данных/аналитики (BigQuery) или баз данных (Cloud SQL, Spanner, Bigtable, Firestore).
