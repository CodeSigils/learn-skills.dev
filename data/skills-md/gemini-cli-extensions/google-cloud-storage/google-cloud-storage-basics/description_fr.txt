Stocke, récupère et gère les données en tant qu'objets dans des compartiments Cloud Storage (Google Cloud Storage ou GCS). À utiliser lorsque vous devez interagir avec Cloud Storage : créer ou configurer des compartiments, charger, télécharger, diffuser ou transférer des données, organiser des objets avec des dossiers, générer des URL signées, contrôler l'accès (IAM, ACL, prévention de l'accès public), définir des classes de stockage et une hiérarchisation (Standard, Nearline, Coldline, Archive), gérer les coûts et le cycle de vie, protéger les données (version, chiffrement/CMEK, rétention et verrouillage du compartiment, conservation des objets, suppression logicielle), héberger des sites Web statiques, déclencher des notifications Pub/Sub sur les modifications d'objets, monter des compartiments en tant que un système de fichiers (gcsfuse) ou optimiser les performances de stockage à n'importe quelle échelle. Couvre la CLI gcloud storage/gsutil, les API JSON et XML, les bibliothèques clientes, les serveurs Terraform et Cloud Storage MCP. Ne pas utiliser pour le stockage par blocs (disque persistant), l'entreposage/l'analyse de données (BigQuery) ou les bases de données (Cloud SQL, Spanner, Bigtable, Firestore).
