将数据作为 Cloud Storage（Google Cloud Storage 或 GCS）存储桶中的对象进行存储、检索和管理。当您需要与 Cloud Storage 交互时使用 - 创建或配置存储桶、上传、下载、流式传输或传输数据、使用文件夹组织对象、生成签名 URL、控制访问（IAM、ACL、公共访问预防）、设置存储类别和分层（标准、近线、冷线、存档）、管理成本和生命周期、保护数据（版本控制、加密/CMEK、保留和存储桶锁定、对象保留、软删除）、托管静态网站、触发有关对象更改的 Pub/Sub 通知、装载存储桶作为文件系统 (gcsfuse)，或优化任何规模的存储性能。涵盖 gcloud storage / gsutil CLI、JSON 和 XML API、客户端库、Terraform 和 Cloud Storage MCP 服务器。请勿用于块存储（持久磁盘）、数据仓库/分析 (BigQuery) 或数据库（Cloud SQL、Spanner、Bigtable、Firestore）。
