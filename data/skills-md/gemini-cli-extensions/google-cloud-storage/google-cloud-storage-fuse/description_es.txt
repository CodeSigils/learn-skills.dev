Monta depósitos de Cloud Storage como un sistema de archivos POSIX con Cloud Storage FUSE (gcsfuse). Úselo cuando necesite interactuar con gcsfuse: decida si FUSE, lecturas gs:// nativas o Filestore/Managed Lustre se adaptan a una carga de trabajo, implemente montajes optimizados en GKE, Compute Engine o Cloud Run, habilite y dimensione los cachés de archivos, estadísticas y listas, ajuste los indicadores de montaje o la configuración del archivo de configuración, aplique perfiles de carga de trabajo, mantenga seguros los puntos de control de ML (cambie el nombre de la atomicidad, el espacio de nombres jerárquico, la finalización en tiempo de cierre, los escritores concurrentes) o diagnostique entrenamiento lento, bajo rendimiento o picos de facturas de GCS en montajes existentes con métricas de gcsfuse. Cubre la semántica de montaje, la CLI de gcsfuse y el archivo de configuración, el controlador CSI gcsfuse de GKE (enlaces principal:// de identidad de carga de trabajo, clases de almacenamiento de perfil, dimensionamiento de sidecar) y montajes de volumen de Cloud Run. No lo use para la administración de depósitos o la gestión de datos sin un montaje (google-cloud-storage-basics) ni para sistemas de archivos compartidos totalmente compatibles con POSIX (Filestore, Managed Lustre).
