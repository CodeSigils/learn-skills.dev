Monta i bucket Cloud Storage come file system POSIX con Cloud Storage FUSE (gcsfuse). Da utilizzare quando è necessario interagire con gcsfuse: decidere se FUSE, letture gs:// native o Filestore/Managed Lustre si adattano a un carico di lavoro, distribuire montaggi ottimizzati su GKE, Compute Engine o Cloud Run, abilitare e dimensionare file, statistiche ed elenchi di cache, ottimizzare i flag di montaggio o le impostazioni del file di configurazione, applicare profili di carico di lavoro, mantenere sicuro il checkpoint ML (rinominare atomicità, spazio dei nomi gerarchico, finalizzazione in fase di chiusura, writer simultanei), oppure diagnosticare l'addestramento lento, il throughput basso o i picchi di fatturazione GCS sui montaggi esistenti con le metriche gcsfuse. Copre la semantica di montaggio, la CLI gcsfuse e il file di configurazione, il driver CSI gcsfuse GKE (binding Principal:// di Workload Identity, StorageClasses del profilo, dimensionamento sidecar) e i montaggi di volumi Cloud Run. Non utilizzare per l'amministrazione del bucket o la gestione dei dati senza un montaggio (google-cloud-storage-basics) o per file system condivisi completamente conformi a POSIX (Filestore, Managed Lustre).
