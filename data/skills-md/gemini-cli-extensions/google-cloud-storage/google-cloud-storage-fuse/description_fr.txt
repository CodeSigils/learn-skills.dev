Monte les buckets Cloud Storage en tant que système de fichiers POSIX avec Cloud Storage FUSE (gcsfuse). À utiliser lorsque vous devez interagir avec gcsfuse : décidez si FUSE, les lectures natives gs:// ou Filestore/Managed Lustre conviennent à une charge de travail, déployez des montages optimisés sur GKE, Compute Engine ou Cloud Run, activez et dimensionnez les caches de fichiers, de statistiques et de liste, ajustez les indicateurs de montage ou les paramètres du fichier de configuration, appliquez des profils de charge de travail, protégez les points de contrôle ML (renommer l'atomicité, l'espace de noms hiérarchique, la finalisation en temps de fermeture, les écrivains simultanés) ou diagnostiquer la lenteur. formation, faible débit ou pics de facture GCS sur les montages existants avec les métriques gcsfuse. Couvre la sémantique de montage, la CLI gcsfuse et le fichier de configuration, le pilote GKE gcsfuse CSI (liaisons Workload Identity principal://, profils StorageClasses, dimensionnement side-car) et les montages de volumes Cloud Run. Ne pas utiliser pour l'administration de compartiments ou la gestion de données sans montage (google-cloud-storage-basics) ou pour des systèmes de fichiers partagés entièrement conformes à POSIX (Filestore, Managed Lustre).
