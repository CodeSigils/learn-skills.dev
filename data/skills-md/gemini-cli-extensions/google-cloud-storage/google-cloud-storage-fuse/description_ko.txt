Cloud Storage FUSE(gcsfuse)를 사용하여 Cloud Storage 버킷을 POSIX 파일 시스템으로 마운트합니다. gcsfuse와 상호작용해야 할 때 사용합니다. FUSE, 기본 gs:// 읽기 또는 Filestore/Managed Lustre가 워크로드에 적합한지 결정하고, GKE, Compute Engine 또는 Cloud Run에 조정된 마운트를 배포하고, 파일, 통계 및 목록 캐시를 사용 설정 및 크기 조정하고, 마운트 플래그 또는 파일 설정을 조정하고, 워크로드 프로필을 적용하고, ML 체크포인트를 안전하게 유지(원자성, 계층적 네임스페이스, 마감 시간 최종화, 동시 작성자 이름 바꾸기), 느린 학습 진단, 낮음 처리량 또는 gcsfuse 측정항목을 사용하는 기존 마운트의 GCS 청구 급증. 마운트 의미 체계, gcsfuse CLI 및 구성 파일, GKE gcsfuse CSI 드라이버(워크로드 아이덴티티 주체:// 바인딩, 프로필 StorageClasses, 사이드카 크기 조정), Cloud Run 볼륨 마운트를 다룹니다. 마운트가 없는 버킷 관리 또는 데이터 관리(google-cloud-storage-basics) 또는 POSIX와 완전히 호환되는 공유 파일 시스템(Filestore, Managed Lustre)에는 사용하지 마세요.
