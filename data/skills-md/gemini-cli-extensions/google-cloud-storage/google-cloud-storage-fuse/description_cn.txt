使用 Cloud Storage FUSE (gcsfuse) 将 Cloud Storage 存储桶装载为 POSIX 文件系统。当您需要与 gcsfuse 交互时使用 - 决定 FUSE、原生 gs:// 读取或 Filestore/Managed Lustre 是否适合工作负载，在 GKE、Compute Engine 或 Cloud Run 上部署调整后的挂载，启用文件、统计数据和列出缓存并调整其大小，调整挂载标志或配置文件设置，应用工作负载配置文件，保持 ML 检查点安全（重命名原子性、分层命名空间、关闭时间终结、并发编写器），或者诊断训练速度慢、吞吐量低或根据 gcsfuse 指标，GCS 费用在现有安装上激增。涵盖挂载语义、gcsfuse CLI 和配置文件、GKE gcsfuse CSI 驱动程序（工作负载身份主体://绑定、配置文件 StorageClasses、sidecar 大小调整）以及 Cloud Run 卷挂载。请勿在没有挂载的情况下用于存储桶管理或数据管理 (google-cloud-storage-basics) 或用于完全符合 POSIX 的共享文件系统（Filestore、托管 Lustre）。
