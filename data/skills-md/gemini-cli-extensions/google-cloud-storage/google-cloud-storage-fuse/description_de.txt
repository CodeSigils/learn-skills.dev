Stellt Cloud Storage-Buckets als POSIX-Dateisystem mit Cloud Storage FUSE (gcsfuse) bereit. Verwenden Sie diese Option, wenn Sie mit gcsfuse interagieren müssen – entscheiden Sie, ob FUSE, native gs://-Lesevorgänge oder Filestore/Managed Lustre zu einer Arbeitslast passen, stellen Sie abgestimmte Mounts auf GKE, Compute Engine oder Cloud Run bereit, aktivieren und dimensionieren Sie die Datei-, Statistik- und Listencaches, optimieren Sie Mount-Flags oder Konfigurationsdateieinstellungen, wenden Sie Arbeitslastprofile an, sorgen Sie für die Sicherheit von ML-Prüfpunkten (Umbenennen von Atomizität, hierarchischer Namespace, Close-Time-Finalisierung, gleichzeitige Autoren) oder Diagnostizieren Sie langsames Training, geringen Durchsatz oder GCS-Rechnungsspitzen auf vorhandenen Mounts mit gcsfuse-Metriken. Behandelt die Mount-Semantik, die gcsfuse-CLI und die Konfigurationsdatei, den GKE-gcsfuse-CSI-Treiber (Workload Identity-Principal://-Bindungen, Profil-StorageClasses, Sidecar-Größe) und Cloud Run-Volume-Mounts. Nicht für die Bucket-Verwaltung oder Datenverwaltung ohne Bereitstellung (google-cloud-storage-basics) oder für vollständig POSIX-kompatible freigegebene Dateisysteme (Filestore, Managed Lustre) verwenden.
