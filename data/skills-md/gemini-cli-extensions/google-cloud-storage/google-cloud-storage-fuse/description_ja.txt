Cloud Storage FUSE (gcsfuse) を使用して Cloud Storage バケットを POSIX ファイル システムとしてマウントします。 gcsfuse を操作する必要がある場合に使用します。FUSE、ネイティブ gs:// 読み取り、または Filestore/Managed Lustre がワークロードに適合するかどうかを決定し、GKE、Compute Engine、または Cloud Run に調整されたマウントをデプロイし、ファイル、統計、リスト キャッシュの有効化とサイズ設定、マウント フラグまたは構成ファイル設定の調整、ワークロード プロファイルの適用、ML チェックポイントの安全性の確保 (アトミック性、階層型名前空間、クローズタイム ファイナライズ、同時ライターの名前変更)、または、gcsfuse メトリクスを使用して、既存のマウントでのトレーニングの遅さ、スループットの低さ、または GCS 請求の急増を診断します。マウント セマンティクス、gcsfuse CLI と構成ファイル、GKE gcsfuse CSI ドライバー (Workload Identity のプリンシパル:// バインディング、プロファイル StorageClasses、サイドカー サイズ設定)、Cloud Run ボリューム マウントについて説明します。マウントを使用しないバケット管理やデータ管理 (google-cloud-storage-basics)、または完全に POSIX 準拠の共有ファイル システム (Filestore、マネージド Lustre) には使用しないでください。
