يتم تركيب مجموعات التخزين السحابي كنظام ملفات POSIX مع Cloud Storage FUSE (gcsfuse). استخدمه عندما تحتاج إلى التفاعل مع gcsfuse - حدد ما إذا كان FUSE أو gs:// الأصلي للقراءة أو Filestore/Managed Luster يناسب عبء العمل، أو نشر عمليات التثبيت المضبوطة على GKE، أو Compute Engine، أو Cloud Run، وتمكين وحجم الملفات والإحصائيات وذاكرة التخزين المؤقت للقائمة، وضبط علامات التثبيت أو إعدادات ملف التكوين، وتطبيق ملفات تعريف عبء العمل، والحفاظ على أمان فحص ML (إعادة تسمية الذرية، ومساحة الاسم الهرمية، والإنهاء في وقت قريب، والتزامن الكتاب)، أو تشخيص التدريب البطيء، أو الإنتاجية المنخفضة، أو ارتفاع فاتورة GCS على الحوامل الموجودة باستخدام مقاييس gcsfuse. يغطي دلالات التحميل، وgcsfuse CLI وملف التكوين، وبرنامج تشغيل GKE gcsfuse CSI (معرف عبء العمل الرئيسي: // الارتباطات، وفئات تخزين الملف الشخصي، وتغيير حجم السيارة الجانبية)، ووحدات تخزين Cloud Run. لا تستخدم لإدارة المجموعة أو إدارة البيانات بدون تثبيت (google-cloud-storage-basics) أو لأنظمة الملفات المشتركة المتوافقة تمامًا مع POSIX (Filestore، Managed Lustre).
