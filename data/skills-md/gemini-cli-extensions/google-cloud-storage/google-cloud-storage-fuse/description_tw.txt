使用 Cloud Storage FUSE (gcsfuse) 将 Cloud Storage 存储桶装载为 POSIX 文件系统。當您需要與 gcsfuse 互動時使用 - 決定 FUSE、原生 gs:// 讀取或 Filestore/Managed Lustre 是否適合工作負載，在 GKE、Compute Engine 或 Cloud Run 上部署調整後的掛載，啟用檔案、統計資料和列出快取並調整其大小，調整掛載標誌或設定檔設定，應用工作負載配置檔案，保持 ML檢查點安全性（重命名原子性、分層命名空間、關閉時間終結、並發編寫器），或診斷訓練速度慢、吞吐量低或根據 gcsfuse 指標，GCS 費用在現有安裝上激增。涵蓋掛載語意、gcsfuse CLI 和設定檔、GKE gcsfuse CSI 驅動程式（工作負載身分主體://綁定、設定檔 StorageClasses、sidecar 大小調整）以及 Cloud Run 磁碟區掛載。請勿在沒有掛載的情況下用於儲存桶管理或資料管理 (google-cloud-storage-basics) 或用於完全符合 POSIX 的共用檔案系統（Filestore、託管 Lustre）。
