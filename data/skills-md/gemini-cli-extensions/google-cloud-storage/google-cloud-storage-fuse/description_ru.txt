Подключает сегменты Cloud Storage как файловую систему POSIX с помощью Cloud Storage FUSE (gcsfuse). Используйте, когда вам нужно взаимодействовать с gcsfuse — решите, подходит ли FUSE, встроенный gs:// или Filestore/Managed Lustre для рабочей нагрузки, разверните настроенные монтирования в GKE, Compute Engine или Cloud Run, включите и измените размер кешей файлов, статистики и списков, настройте флаги монтирования или настройки файла конфигурации, примените профили рабочей нагрузки, обеспечьте безопасность контрольных точек ML (переименуйте атомарность, иерархическое пространство имен, финализацию по времени закрытия, параллельную писатели) или диагностировать медленное обучение, низкую пропускную способность или скачки счетов за GCS на существующих подключениях с помощью показателей gcsfuse. Охватывает семантику монтирования, интерфейс командной строки и файл конфигурации gcsfuse, драйвер GKE gcsfuse CSI (привязки Workload Identity Principal://, профиль StorageClasses, размер дополнительного модуля) и монтирование томов Cloud Run. Не используйте для администрирования корзины или управления данными без монтирования (google-cloud-storage-basics) или для полностью совместимых с POSIX общих файловых систем (Filestore, Managed Lustre).
