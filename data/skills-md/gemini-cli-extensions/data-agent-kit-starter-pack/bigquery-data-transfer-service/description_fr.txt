Détecte et inspecte les configurations du service de transfert de données BigQuery (DTS). Utilisez-le pour identifier les pipelines d'ingestion existants et extraire la source de données ou transférer les métadonnées de configuration pour les pipelines de données. À utiliser lorsqu'un utilisateur demande des scénarios d'ingestion lors de la création ou de la gestion de pipelines de données ou lorsqu'un utilisateur demande « d'ingérer » ou d'« ajouter » des données qui peuvent déjà être gérées par un transfert DTS.
