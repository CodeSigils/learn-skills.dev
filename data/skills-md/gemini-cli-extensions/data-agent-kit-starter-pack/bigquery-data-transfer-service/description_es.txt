Descubre e inspecciona las configuraciones del Servicio de transferencia de datos (DTS) de BigQuery. Úselo para identificar canalizaciones de ingesta existentes y extraer fuentes de datos o transferir metadatos de configuración para canalizaciones de datos. Úselo cuando un usuario solicita escenarios de ingesta mientras crea o administra canalizaciones de datos o cuando un usuario solicita "ingerir" o "agregar" datos que pueden ya estar administrados mediante una transferencia DTS.
