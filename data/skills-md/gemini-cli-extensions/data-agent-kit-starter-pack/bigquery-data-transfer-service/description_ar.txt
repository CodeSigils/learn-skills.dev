يكتشف ويفحص تكوينات خدمة نقل البيانات BigQuery (DTS). استخدم هذا لتحديد مسارات الاستيعاب الحالية واستخراج مصدر البيانات أو نقل بيانات تعريف التكوين لخطوط تدفق البيانات. يُستخدم عندما يطلب المستخدم سيناريوهات الاستيعاب أثناء إنشاء مسارات البيانات أو إدارتها أو عندما يطلب المستخدم "استيعاب" أو "إضافة" البيانات التي قد تتم إدارتها بالفعل عن طريق نقل DTS.
