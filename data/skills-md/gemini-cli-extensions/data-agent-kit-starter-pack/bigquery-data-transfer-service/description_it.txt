Rileva e controlla le configurazioni di BigQuery Data Transfer Service (DTS). Utilizzalo per identificare le pipeline di acquisizione esistenti ed estrarre l'origine dati o trasferire i metadati di configurazione per le pipeline di dati. Da utilizzare quando un utente richiede scenari di inserimento durante la creazione o la gestione di pipeline di dati o quando un utente chiede di "inserire" o "aggiungere" dati che potrebbero già essere gestiti da un trasferimento DTS.
