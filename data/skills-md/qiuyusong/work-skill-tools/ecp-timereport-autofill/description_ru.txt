Автоматически создавайте и отправляйте журналы времени ECP из коммитов Git того же дня в ветку выпуска. Используется для таких сценариев, как «время автоматического заполнения ежедневно», «время обратного заполнения на основе сообщений о фиксации» и «периодическая автоматическая запись журналов времени ECP».
