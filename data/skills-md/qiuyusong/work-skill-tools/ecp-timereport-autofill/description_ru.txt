Автоматически генерирует журналы времени ECP на основе текущих коммитов Git в ветке выпуска и разрешает отправку. Используется для таких сценариев, как «автозаполнение журналов времени ежедневно», «заполнение журналов времени на основе сообщений о фиксации» и «периодическая автоматическая запись журналов времени ECP».
