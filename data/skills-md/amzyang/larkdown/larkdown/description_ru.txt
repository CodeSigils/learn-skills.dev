Документ Feishu и инструмент двунаправленного преобразования Markdown (интерфейс командной строки Larkdown). Этот навык следует использовать в следующих сценариях:
1. Пользователь предоставляет ссылку на документ/вики/папку с сайта feishu.cn или <поддомен>.feishu.cn (docx, wiki, папка).
2. Пользователь упоминает «Фейшу» вместе со словами «загрузить», «экспортировать», «конвертировать в Markdown», «загрузить», «синхронизировать» или «обновить».
3. Пользователю необходимо загрузить локальный файл Markdown в Feishu Wiki.
4. Пользователь спрашивает об использовании, установке или настройке команды Larkdown.
Даже если пользователь просто вставляет ссылку на Фейшу, не говоря явно «загрузить», этот навык все равно следует применить.
