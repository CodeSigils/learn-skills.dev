Bidirektionales Konvertierungstool für Feishu-Dokumente und Markdown (Larkdown-CLI). Diese Fähigkeit sollte in den folgenden Szenarien verwendet werden:
1. Der Benutzer stellt einen Dokument-/Wiki-/Ordner-Link von feishu.cn oder <subdomain>.feishu.cn (docx, wiki, Ordner) bereit.
2. Der Benutzer erwähnt „Feishu“ zusammen mit „herunterladen“, „exportieren“, „in Markdown konvertieren“, „hochladen“, „synchronisieren“ oder „aktualisieren“.
3. Der Benutzer muss eine lokale Markdown-Datei in ein Feishu-Wiki hochladen.
4. Der Benutzer fragt nach der Verwendung, Installation oder Konfiguration des Larkdown-Befehls.
Auch wenn der Benutzer nur einen Feishu-Link einfügt, ohne explizit „Herunterladen“ zu sagen, sollte diese Fähigkeit dennoch angewendet werden.
