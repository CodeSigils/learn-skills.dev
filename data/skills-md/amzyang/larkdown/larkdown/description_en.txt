Feishu document and Markdown bidirectional conversion tool (larkdown CLI). This skill should be used in the following scenarios:
1. The user provides a document/Wiki/folder link from feishu.cn or <subdomain>.feishu.cn (docx, wiki, folder).
2. The user mentions "Feishu" together with "download", "export", "convert to Markdown", "upload", "sync", or "update".
3. The user needs to upload a local Markdown file to a Feishu Wiki.
4. The user asks about larkdown command usage, installation, or configuration.
Even if the user only pastes a Feishu link without explicitly saying "download", this skill should still be applied.
