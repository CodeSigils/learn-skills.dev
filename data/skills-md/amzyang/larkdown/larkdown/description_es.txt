Documento Feishu y herramienta de conversión bidireccional Markdown (CLI Larkdown). Esta habilidad debe usarse en los siguientes escenarios:
1. El usuario proporciona un enlace a un documento/Wiki/carpeta desde feishu.cn o <subdominio>.feishu.cn (docx, wiki, carpeta).
2. El usuario menciona "Feishu" junto con "descargar", "exportar", "convertir a Markdown", "cargar", "sincronizar" o "actualizar".
3. El usuario debe cargar un archivo Markdown local en un Feishu Wiki.
4. El usuario pregunta sobre el uso, la instalación o la configuración del comando larkdown.
Incluso si el usuario solo pega un enlace de Feishu sin decir explícitamente "descargar", esta habilidad aún debe aplicarse.
