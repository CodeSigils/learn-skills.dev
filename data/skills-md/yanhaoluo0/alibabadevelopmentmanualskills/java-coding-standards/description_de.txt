Programmierkonventionen des Alibaba Java Development Manual, einschließlich Namenskonventionen, Konstantendefinitionen, Codeformat, OOP-Konventionen, Datums- und Uhrzeitbehandlung, Sammlungsverarbeitung, Parallelitätsbehandlung, Steueranweisungen, Kommentarkonventionen usw. Wird beim Schreiben von Java-Code, beim Überprüfen von Code oder beim Befolgen der Java-Codierungsstandards von Alibaba verwendet.
