Полный охват акций А + акции Гонконга + акции США + индексы + финансовые показатели + макроэкономические данные. Бесплатно, ключ API не требуется, собственный Python. Поддерживает котировки в реальном времени, исторические свечи, отраслевой анализ, потоки капитала, три финансовых отчета, исследования акционеров, списки ведущих трейдеров, увеличение/ограничение лимитов, маржинальную торговлю, макроданные и т. д. Автоматически вызывается при упоминании акций A, котировок Гонконга, финансовых отчетов, отчетов о прибылях, макропоказателей, ВВП, CPI, PMI, секторов, потоков капитала, списка лучших трейдеров, лимитных движений, маржинальной торговли, IPO, истечения срока блокировки, исследовательских отчетов.
