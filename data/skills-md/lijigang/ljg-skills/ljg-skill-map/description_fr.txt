Visionneuse de cartes de compétences. Analyse toutes les compétences installées et affiche un aperçu visuel : nom, version, description, catégorie en un coup d'œil. À utiliser lorsque l'utilisateur dit « compétences », « 技能 », « 技能地图 », « carte des compétences », « 我有哪些技能 », « 看看技能 », « 列出技能 », « liste de compétences ». Déclenchez également lorsque l'utilisateur demande quelles compétences sont disponibles ou installées.
