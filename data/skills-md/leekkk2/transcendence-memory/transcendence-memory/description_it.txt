Da utilizzare durante la connessione a un backend di memoria self-hosted, la ricerca, l'archiviazione o la gestione delle memorie, l'importazione di token di connessione o la risoluzione dei problemi di recupero. Utilizza questa abilità ogni volta che l'utente menziona ricerca di memoria, recupero RAG, incorporamento, archiviazione di memoria, caricamento di documenti multimodali, query di conoscenza o desidera connettersi a un servizio di memoria, anche se non dice esplicitamente "memoria di trascendenza".
