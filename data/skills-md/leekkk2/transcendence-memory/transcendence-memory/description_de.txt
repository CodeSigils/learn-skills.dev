Verwenden Sie diese Option, wenn Sie eine Verbindung zu einem selbstgehosteten Speicher-Backend herstellen, Speicher suchen, speichern oder verwalten, Verbindungstokens importieren oder Probleme beim Abrufen beheben. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Speichersuche, RAG-Abruf, Einbettung, Speicherspeicherung, multimodales Hochladen von Dokumenten oder Wissensabfragen erwähnt oder eine Verbindung zu einem Speicherdienst herstellen möchte, auch wenn er nicht ausdrücklich „Transzendenz-Speicher“ sagt.
