يُستخدم عند الاتصال بواجهة خلفية للذاكرة مستضافة ذاتيًا، أو البحث عن الذكريات أو تخزينها أو إدارتها، أو استيراد الرموز المميزة للاتصال، أو استكشاف مشكلات الاسترجاع وإصلاحها. استخدم هذه المهارة عندما يذكر المستخدم البحث عن الذاكرة، أو استرجاع RAG، أو التضمين، أو تخزين الذاكرة، أو تحميل المستندات متعددة الوسائط، أو استعلامات المعرفة، أو يريد الاتصال بخدمة ذاكرة، حتى لو لم يذكر "ذاكرة التفوق" صراحةً.
