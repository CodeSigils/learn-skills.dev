يُستخدم عند تدقيق استخدام المهارات، أو تحديد المهارات غير النشطة، أو إدارة أرشيفات المهارات، أو التحقق من حالة الإدارة. استخدم هذه المهارة عندما يذكر المستخدم استخدام المهارات، أو تحليلات المهارات، أو تنظيف المهارات، أو المهارات الباردة، أو مهارات الأرشيف، أو الإدارة - حتى لو لم يذكر "الحاكم" صراحةً.
