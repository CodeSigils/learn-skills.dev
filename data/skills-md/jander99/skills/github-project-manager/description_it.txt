Gestisci, configura, genera, convalida e imposta progetti GitHub (v2) con la creazione di problemi, il rilevamento di progetti, l'aggiunta di elementi ai progetti e l'aggiornamento dello stato dei problemi nelle schede di progetto. Le funzionalità includono la creazione di problemi con metadati (etichette, assegnatari, traguardi), l'elenco di progetti per utenti/organizzazioni, l'aggiunta di problemi/PR ai progetti, l'aggiornamento dei campi degli elementi del progetto (stato, priorità) e la gestione dei flussi di lavoro del progetto (Backlog, Pronto, In corso, Fatto). Utilizza il fallback GraphQL, gli ID nodo, gli strumenti server MCP e le operazioni batch per l'automazione degli elementi del progetto. Da utilizzare durante la creazione di problemi GitHub, la gestione di schede di progetto, lo spostamento di problemi tra colonne di progetto, l'organizzazione di elementi di lavoro del repository, il monitoraggio dell'avanzamento del progetto, l'automazione dei flussi di lavoro di progetto GitHub o l'integrazione di schede di progetto con pipeline CI/CD.
