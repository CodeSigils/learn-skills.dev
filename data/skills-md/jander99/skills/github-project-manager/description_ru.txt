Управляйте, настраивайте, генерируйте, проверяйте и настраивайте проекты GitHub (v2) с созданием задач, обнаружением проектов, добавлением элементов в проекты и обновлением статуса задач на досках проектов. Возможности включают создание задач с метаданными (метками, правопреемниками, контрольными точками), составление списка проектов для пользователей/организаций, добавление задач/запросов в проекты, обновление полей элементов проекта (статус, приоритет) и управление рабочими процессами проекта (Невыполненные работы, Готово, В процессе, Готово). Используйте резервный вариант GraphQL, идентификаторы узлов, серверные инструменты MCP и пакетные операции для автоматизации элементов проекта. Используйте при создании задач GitHub, управлении досками проектов, перемещении задач между столбцами проекта, организации рабочих элементов репозитория, отслеживании хода проекта, автоматизации рабочих процессов проекта GitHub или интеграции досок проектов с конвейерами CI/CD.
