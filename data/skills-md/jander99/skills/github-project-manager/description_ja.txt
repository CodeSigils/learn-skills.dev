GitHub プロジェクト (v2) を管理、構成、生成、検証、セットアップし、問題の作成、プロジェクトの検出、プロジェクトへの項目の追加、プロジェクト ボード全体での問題のステータスの更新を行います。機能には、メタデータ (ラベル、担当者、マイルストーン) を使用した課題の作成、ユーザー/組織のプロジェクトのリスト、プロジェクトへの課題/PR の追加、プロジェクト項目フィールド (ステータス、優先度) の更新、プロジェクト ワークフローの管理 (バックログ、準備完了、進行中、完了) が含まれます。プロジェクト項目の自動化には、GraphQL フォールバック、ノード ID、MCP サーバー ツール、およびバッチ操作を使用します。 GitHub 課題の作成、プロジェクト ボードの管理、プロジェクト列間での課題の移動、リポジトリ作業項目の整理、プロジェクトの進行状況の追跡、GitHub プロジェクト ワークフローの自動化、またはプロジェクト ボードと CI/CD パイプラインの統合を行う場合に使用します。
