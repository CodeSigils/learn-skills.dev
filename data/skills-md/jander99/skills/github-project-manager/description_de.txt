Verwalten, konfigurieren, generieren, validieren und richten Sie GitHub-Projekte (v2) mit Problemerstellung, Projekterkennung, Hinzufügen von Elementen zu Projekten und Aktualisieren des Problemstatus in allen Projektboards ein. Zu den Funktionen gehören das Erstellen von Problemen mit Metadaten (Bezeichnungen, Beauftragte, Meilensteine), das Auflisten von Projekten für Benutzer/Organisationen, das Hinzufügen von Problemen/PRs zu Projekten, das Aktualisieren von Projektelementfeldern (Status, Priorität) und das Verwalten von Projektworkflows (Rückstand, Bereit, In Bearbeitung, Fertig). Verwenden Sie GraphQL-Fallback, Knoten-IDs, MCP-Server-Tools und Batch-Operationen für die Automatisierung von Projektelementen. Zum Erstellen von GitHub-Vorgängen, zum Verwalten von Projektboards, zum Verschieben von Problemen zwischen Projektspalten, zum Organisieren von Repository-Arbeitselementen, zum Verfolgen des Projektfortschritts, zum Automatisieren von GitHub-Projektworkflows oder zum Integrieren von Projektboards in CI/CD-Pipelines.
