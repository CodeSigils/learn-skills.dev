إدارة وتكوين وإنشاء والتحقق من صحة وإعداد مشاريع GitHub (الإصدار 2) مع إنشاء المشكلات واكتشاف المشروع وإضافة عناصر إلى المشاريع وتحديث حالة المشكلة عبر لوحات المشروع. تتضمن القدرات إنشاء مشكلات باستخدام البيانات الوصفية (التسميات، والمُعيَّنين، والمعالم الرئيسية)، وسرد المشاريع للمستخدمين/المؤسسات، وإضافة المشكلات/العلاقات العامة إلى المشاريع، وتحديث حقول عناصر المشروع (الحالة، والأولوية)، وإدارة سير عمل المشروع (Backlog، Ready، قيد التقدم، Done). استخدم احتياطي GraphQL ومعرفات العقدة وأدوات خادم MCP والعمليات المجمعة لأتمتة عناصر المشروع. يُستخدم عند إنشاء مشكلات GitHub، أو إدارة لوحات المشروع، أو نقل المشكلات بين أعمدة المشروع، أو تنظيم عناصر عمل المستودع، أو تتبع تقدم المشروع، أو أتمتة سير عمل مشروع GitHub، أو دمج لوحات المشروع مع خطوط أنابيب CI/CD.
