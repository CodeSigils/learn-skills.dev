Crea, scrivi, genera, modifica, aggiorna e formatta la documentazione di markdown (README, CHANGELOG, note di ricerca, piani, guide, tutorial). Gestisce i metadati del frontmatter, l'organizzazione delle directory e la denominazione dei file. Da utilizzare quando si scrivono file .md, si documenta codice, si creano documenti di progetto, si salvano risultati di ricerca, si creano file README, si gestiscono elenchi di cose da fare o si genera qualsiasi contenuto di markdown.
