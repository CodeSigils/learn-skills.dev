إنشاء وكتابة وبناء وتصحيح الأخطاء واختبار وإعادة بناء وتحسين تطبيقات Python 3.10+ في جميع المجالات (علم البيانات وواجهات برمجة التطبيقات الخلفية والبرمجة النصية والأتمتة). إدارة التبعيات باستخدام الأشعة فوق البنفسجية (المفضلة) أو الشعر أو النقطة. تنفيذ تلميحات الكتابة (وحدة الكتابة، والأدوية العامة، والبروتوكولات)، وكتابة الاختبارات باستخدام pytest (التركيبات، والمعلمات، والسخرية)، والعمل مع pandas DataFrames (الإنشاء، والاختيار، والتجميع، والدمج)، واستخدام فئات البيانات والديكورات، والتعامل مع الأخطاء من خلال تكامل التسجيل، واتباع سير عمل TDD (الأحمر-الأخضر-Refactor). قم بتكوين البيئات الافتراضية وpyproject.toml وأدوات التحليل الثابتة (mypy وpyright). يُستخدم عند تنفيذ ميزات Python، أو إصلاح الأخطاء، أو كتابة الاختبارات، أو إدارة الحزم، أو تحليل البيانات، أو إنشاء مشاريع Python.
