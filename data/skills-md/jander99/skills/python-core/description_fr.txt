Créer, écrire, construire, déboguer, tester, refactoriser et optimiser des applications Python 3.10+ dans tous les domaines (science des données, API backend, scripts, automatisation). Gérez les dépendances avec uv (de préférence), poésie ou pip. Implémentez des astuces de type (module de saisie, génériques, protocoles), écrivez des tests avec pytest (fixtures, paramétrage, moquerie), travaillez avec des DataFrames pandas (création, sélection, groupby, fusion), utilisez des classes de données et des décorateurs, gérez les erreurs avec l'intégration de la journalisation et suivez les workflows TDD (Red-Green-Refactor). Configurez les environnements virtuels, pyproject.toml et les outils d'analyse statique (mypy, pyright). À utiliser lors de l'implémentation de fonctionnalités Python, de la correction de bogues, de l'écriture de tests, de la gestion de packages, de l'analyse de données ou de la création de projets Python.
