استكمال وكيل OpenClaw وإدارة التكوين. يُستخدم عندما يريد المستخدم إنشاء وكلاء جدد، أو تكوين روبوتات Telegram، أو إعداد توجيه الرسائل باستخدام الارتباطات، أو إدارة تكوينات الوكلاء المتعددين، أو سرد الإعداد الحالي، أو استكشاف مشكلات التوجيه وإصلاحها. يتعامل مع إنشاء الوكيل وإدارة الارتباط والتكوين بناءً على وثائق OpenClaw الرسمية.
