Pubblica e condividi le competenze OpenClaw nei repository GitHub. Da utilizzare quando l'utente desidera condividere competenze, creare un repository di raccolta di competenze, aggiungere competenze a un repository esistente o gestire flussi di lavoro di condivisione delle competenze. Automatizza la creazione di repository, l'aggiunta di competenze, gli aggiornamenti README e le operazioni git.
