Публикуйте и делитесь навыками OpenClaw в репозиториях GitHub. Используйте, когда пользователь хочет поделиться навыками, создать хранилище коллекции навыков, добавить навыки в существующий репозиторий или управлять рабочими процессами обмена навыками. Автоматизирует создание репозитория, добавление навыков, обновления README и операции git.
