Publique y comparta habilidades de OpenClaw en repositorios de GitHub. Úselo cuando el usuario desee compartir habilidades, crear un repositorio de recopilación de habilidades, agregar habilidades a un repositorio existente o administrar flujos de trabajo para compartir habilidades. Automatiza la creación de repositorios, la incorporación de habilidades, las actualizaciones de README y las operaciones de git.
