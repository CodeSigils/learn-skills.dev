Betreiben Sie einen Pool wiederverwendbarer Git-Worktrees über die Treehouse-CLI: Leasen Sie einen isolierten Worktree nicht interaktiv, lesen Sie den Poolstatus, geben Sie eine Lease zurück und fordern Sie Slots mit Prune oder Destroy zurück. Verwenden Sie es immer dann, wenn für die Arbeit ein isoliertes Auschecken erforderlich ist, ein Pool voll ist, ein Steckplatz verschmutzt oder vermietet ist oder ein Worktree-Pfad unter einem .treehouse/-Verzeichnis erklärt werden muss.
