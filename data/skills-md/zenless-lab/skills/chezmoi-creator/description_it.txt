Crea, migra, rivedi ed esegui il debug degli stati di origine, dei modelli, degli script e dei file di configurazione di Chezmoi. Utilizza questa competenza quando gestisci dotfile con chezmoi, mappi i file di destinazione sui nomi dello stato di origine, scrivi script run_once/run_onchange, gestisci file speciali come .chezmoiignore o .chezmoiexternal o crei configurazioni di directory home multipiattaforma per Linux, macOS, Windows e Codespaces.
