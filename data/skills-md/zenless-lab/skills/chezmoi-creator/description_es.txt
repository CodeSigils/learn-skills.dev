Cree, migre, revise y depure estados fuente, plantillas, scripts y archivos de configuración de chezmoi. Utilice esta habilidad cuando administre archivos de puntos con chezmoi, asigne archivos de destino a nombres de estado de origen, escriba scripts run_once/run_onchange, maneje archivos especiales como .chezmoiignore o .chezmoiexternal, o cree configuraciones de directorios de inicio multiplataforma para Linux, macOS, Windows y Codespaces.
