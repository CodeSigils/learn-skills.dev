Руководство по реализации Lism CSS: см. при редактировании HTML, CSS и SCSS, а также при реализации или редактировании компонентов в JSX, React или Astro. Предоставляет служебные классы, токены дизайна, модули макета, соглашения об именах, правила слоев CSS, адаптивную поддержку, базовые правила оформления и архитектуру CSS.
