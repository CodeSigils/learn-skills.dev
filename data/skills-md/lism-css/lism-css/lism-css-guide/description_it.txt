Guida all'implementazione di Lism CSS: fare riferimento quando si modifica HTML, CSS e SCSS e quando si implementano o si modificano componenti in JSX, React o Astro. Fornisce classi di utilità, token di progettazione, moduli di layout, convenzioni di denominazione, regole dei livelli CSS, supporto reattivo, regole di stile di base e architettura CSS.
