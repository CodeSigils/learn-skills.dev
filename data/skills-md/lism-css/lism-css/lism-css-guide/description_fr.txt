Guide d'implémentation Lism CSS : à consulter lors de l'édition de HTML, CSS et SCSS, et lors de l'implémentation ou de l'édition de composants dans JSX, React ou Astro. Fournit des classes utilitaires, des jetons de conception, des modules de mise en page, des conventions de dénomination, des règles de couche CSS, une prise en charge réactive, des règles de style de base et une architecture CSS.
