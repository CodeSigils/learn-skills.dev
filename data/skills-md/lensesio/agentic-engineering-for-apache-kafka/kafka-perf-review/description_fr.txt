Examinez les configurations de performances du producteur et du consommateur Kafka dans le cluster actif (via Lenses MCP) et dans la base de code. Signale les défauts non réglés, les anti-modèles et les meilleures pratiques manquantes. À utiliser lorsque l'utilisateur dit « examiner les performances de Kafka », « vérifier les configurations du producteur », « régler les paramètres de Kafka » ou pose des questions sur le débit, le traitement par lots ou la compression. Ne PAS utiliser pour le dimensionnement du cluster ou la planification de la capacité.
