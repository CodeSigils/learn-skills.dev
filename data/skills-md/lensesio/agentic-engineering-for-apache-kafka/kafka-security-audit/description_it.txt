Controlla la configurazione di sicurezza di Kafka nella codebase e nel cluster live utilizzando il server MCP Lenses. Controlla l'autenticazione (SASL), la crittografia (SSL/TLS), l'autorizzazione (ACL), la gestione dei segreti e le discrepanze tra i livelli di ambiente. Da utilizzare quando l'utente dice "controlla la sicurezza Kafka", "controlla la configurazione della sicurezza", "il mio cluster è sicuro" o chiede informazioni su autenticazione, crittografia o credenziali. NON utilizzare per configurare certificati, creare utenti SASL o impostare ACL.
