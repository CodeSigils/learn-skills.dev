Auditez la configuration de la sécurité de Kafka sur la base de code et le cluster en direct à l'aide du serveur Lenses MCP. Vérifie l'authentification (SASL), le cryptage (SSL/TLS), l'autorisation (ACL), la gestion des secrets et les incompatibilités de niveau d'environnement. À utiliser lorsque l'utilisateur dit « auditer la sécurité Kafka », « vérifier la configuration de sécurité », « mon cluster est-il sécurisé » ou pose des questions sur l'authentification, le cryptage ou les informations d'identification. Ne PAS utiliser pour configurer des certificats, créer des utilisateurs SASL ou configurer des ACL.
