Audite la configuración de seguridad de Kafka en todo el código base y el clúster en vivo utilizando el servidor MCP de Lenses. Comprueba la autenticación (SASL), el cifrado (SSL/TLS), la autorización (ACL), la gestión de secretos y las discrepancias en los niveles de entorno. Úselo cuando el usuario diga "auditar la seguridad de Kafka", "verificar la configuración de seguridad", "mi clúster es seguro" o pregunta sobre autenticación, cifrado o credenciales. NO lo utilice para configurar certificados, crear usuarios SASL o configurar ACL.
