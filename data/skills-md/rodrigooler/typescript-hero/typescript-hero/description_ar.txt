دقة Elite TypeScript في كتابة أو مراجعة أو إعادة البناء أو ترحيل أي كود .ts/.tsx/.mts/.cts. يفرض سياسة ZERO-`any`، وtsconfig الصارم إلى أقصى حد، ومصطلحات TS 5.x الحديثة (``satisfies`` و`const` type params و`NoInfer` و`using` و`isolatedDeclarations`)، وأنماط درجة الإنتاج (الأنواع ذات العلامات التجارية، لا يتم التحقق من صحة التحليل باستخدام Zod/Valibot/ArkType، `النتيجة<T,E>`، شاملة `أبدًا`، أجهزة الحالة على مستوى النوع). استخدمه عندما يتعلق الأمر برمز TypeScript أو يذكر المستخدم الأنواع أو tsconfig أو الأدوية العامة أو أمان النوع أو "خطأ TS" أو Zod أو Valibot أو tRPC أو Effect أو ترحيل JS → TS.
