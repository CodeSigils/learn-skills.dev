Rigueur Elite TypeScript pour l'écriture, la révision, la refactorisation ou la migration de tout code .ts/.tsx/.mts/.cts. Applique une politique ZÉRO-`any`, un tsconfig strict au maximum, des idiomes TS 5.x modernes (`satisfies`, paramètres de type `const`, `NoInfer`, `using`, `isolatedDeclarations`) et des modèles de qualité production (types de marque, analyse sans validation avec Zod/Valibot/ArkType, `Result<T,E>`, exhaustif « jamais », machines à états au niveau du type). À utiliser chaque fois que du code TypeScript est impliqué ou que l'utilisateur mentionne des types, tsconfig, génériques, type-safety, "TS error", Zod, Valibot, tRPC, Effect ou migration de JS → TS.
