Rigor Elite TypeScript para escribir, revisar, refactorizar o migrar cualquier código .ts/.tsx/.mts/.cts. Aplica una política CERO-`cualquier`, tsconfig máximamente estricto, modismos modernos de TS 5.x (`satisfies`, `const` type params, `NoInfer`, `using`, `isolatedDeclarations`) y patrones de grado de producción (tipos de marca, analizar-no-validar con Zod/Valibot/ArkType, `Result<T,E>`, exhaustivo `never`, estado de nivel de tipo máquinas). Úselo siempre que esté involucrado código TypeScript o el usuario mencione tipos, tsconfig, genéricos, seguridad de tipos, "error TS", Zod, Valibot, tRPC, Effect o migración de JS→TS.
