Analysez les données structurées d'un site Web et générez un balisage de schéma JSON-LD prêt à l'emploi pour améliorer la découvrabilité de l'IA. À utiliser lorsque l'utilisateur demande de corriger le schéma, d'ajouter des données structurées, de générer du JSON-LD, d'ajouter un balisage de schéma ou d'améliorer le balisage schema.org pour les moteurs d'IA.
