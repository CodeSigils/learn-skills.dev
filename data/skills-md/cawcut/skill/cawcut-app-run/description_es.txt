Todo lo relacionado con CawCut-App a través de la CLI local `cawcut`:
ejecutar aplicaciones publicadas y solicitudes abiertas como "¿qué puede hacer <aplicación>?",
"qué genera <aplicación>", "qué aplicaciones hay", "lista de aplicaciones oficiales",
explorar/enumerar las aplicaciones disponibles o comprobar las entradas/salidas de una aplicación.
Usar cuando: "/cawcut-app-run", "ejecutar mi aplicación CawCut", "invocar aplicación publicada",
"lista de aplicaciones CawCut disponibles", "qué aplicaciones están disponibles" o el usuario
describe una solicitud creativa de estilo de plantilla/flujo de trabajo (anuncios, campañas,
plantillas de varios pasos) que pueden coincidir con una aplicación publicada. busca la vida
Catálogo de aplicaciones y puntuación de intención antes del enrutamiento; manos libres simple en un solo paso
Generación de texto a imagen/vídeo o imagen a imagen/vídeo sin coincidencia de aplicación
a cawcut-generate, que devolverá aquí si más tarde encuentra un
Aplicación coincidente.
Requiere `cawcut` instalado y autenticado. NO para: consentimiento de OAuth
solo o aplicaciones a las que el usuario no puede acceder. Cuando no esté seguro de si una solicitud
necesita una aplicación o generación sin procesar, comience aquí: esta habilidad decide y
delegados.
