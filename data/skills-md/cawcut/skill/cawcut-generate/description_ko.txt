다음을 사용하여 CawCut 공식 노드 기능을 통해 이미지 또는 비디오를 생성합니다.
로컬 `cawcut` CLI. 기본값: 이미지/편집용 gpt-image-2; 시드스 2.0
실시간 검색이 불가능한 경우 비디오.
사용 시기: "이미지 생성", "비디오 만들기", "텍스트를 이미지로",
"텍스트를 이미지로", "텍스트를 비디오로", "텍스트를 비디오로", "이미지를 이미지로",
"이미지를 이미지로", "이 이미지를 편집/스타일화/리믹스", "이미지를 비디오로",
"이미지를 비디오로", "이 사진에 애니메이션 적용", "옴니-비디오", "옴니를 비디오로",
"/cawcut-generate" 또는 자유 형식의 콘텐츠 설명(예: "귀여운
작은 고슴도치"). 텍스트를 이미지로, 텍스트를 비디오로, 이미지를 이미지로,
이미지-비디오, 옴니-비디오. 먼저 앱 카탈로그를 확인합니다. 손
유사한 앱 일치에서 cawcut-app-run으로 이동합니다.
'cawcut'이 설치되어 있고 'cawcut auth login'이 완료되어야 합니다.
해당되지 않음: 이미 선택한 앱 실행(cawcut-app-run 사용), 앱
검색/탐색("어떤 앱이 있는지", "앱이 생성할 수 있는 것"),
OAuth 설정만 사용하거나 CLI 없이 웹 UI 전용 흐름을 사용합니다.
