使用 CawCut 官方節點功能產生圖像或視頻
本地“cawcut”CLI。預設值：gpt-image-2 用於映像/編輯；Seedance 2.0 為
即時發現不可用時的影片。
使用場合：「生成圖像」、「製作影片」、「文字轉圖像」、
「文字轉影像」、「文字轉影片」、「文字轉影片」、「影像轉影像」、
「圖像到圖像」、「編輯/風格化/重新混合該圖像」、「圖像到影片」、
「圖像到影片」、「為這張照片添加動畫」、「全向影片」、「全向影片」、
“/cawcut-generate”，或自由格式的內容描述（例如“一個可愛的
小刺蝟”）。支援文字轉圖像、文字轉影片、圖像轉圖像、
圖像到視訊和全方位到視訊。首先查看App目錄；手
在類似的應用程式匹配上轉到 cawcut-app-run。
需要安裝“cawcut”並完成“cawcut auth login”。
不適用於：運行已選擇的應用程式（使用 cawcut-app-run）、應用程式
發現/瀏覽（“有哪些應用程式”，“應用程式可以產生什麼”），
僅 OAuth 設置，或僅 Web UI 流程，無需 CLI。
