CawCut 公式ノード機能を使用して画像またはビデオを生成します。
ローカルの「cawcut」CLI。デフォルト: 画像/編集の場合は gpt-image-2。シーダンス 2.0 用
ライブディスカバリーが利用できない場合のビデオ。
「画像を生成する」、「ビデオを作成する」、「テキストを画像に変換する」、
「テキストから画像」、「テキストからビデオ」、「テキストからビデオ」、「画像から画像」、
「画像から画像へ」、「この画像を編集/スタイル化/リミックス」、「画像からビデオへ」、
「画像からビデオへ」、「この写真をアニメーション化」、「オムニからビデオへ」、「オムニからビデオへ」、
「/cawcut-generate」、または自由形式のコンテンツの説明 (例: 「かわいい
小さなハリネズミ」）。テキストから画像へ、テキストからビデオへ、画像から画像へ、
画像からビデオへ、そしてオムニからビデオへ。最初にアプリカタログを確認します。手
同様のアプリの一致で cawcut-app-run に移行します。
「cawcut」がインストールされ、「cawcut auth login」が完了している必要があります。
対象外: すでに選択されているアプリの実行 (cawcut-app-run を使用)、アプリ
発見/閲覧 (「どのようなアプリがあるか」、「アプリが何を生成できるか」)、
OAuth セットアップのみ、または CLI を使用しない Web UI のみのフロー。
