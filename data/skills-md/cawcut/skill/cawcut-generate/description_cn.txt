使用 CawCut 官方节点功能生成图像或视频
本地“cawcut”CLI。默认值：gpt-image-2 用于图像/编辑； Seedance 2.0 为
实时发现不可用时的视频。
使用场合：“生成图像”、“制作视频”、“文本转图像”、
“文本转图像”、“文本转视频”、“文本转视频”、“图像转图像”、
“图像到图像”、“编辑/风格化/重新混合该图像”、“图像到视频”、
“图像到视频”、“为这张照片添加动画”、“全向视频”、“全向视频”、
“/cawcut-generate”，或自由格式的内容描述（例如“一个可爱的
小刺猬”）。支持文本转图像、文本转视频、图像转图像、
图像到视频和全方位到视频。首先查看App目录；手
在类似的应用程序匹配上转到 cawcut-app-run。
需要安装“cawcut”并完成“cawcut auth login”。
不适用于：运行已选择的应用程序（使用 cawcut-app-run）、应用程序
发现/浏览（“有哪些应用程序”，“应用程序可以生成什么”），
仅 OAuth 设置，或仅 Web UI 流程，无需 CLI。
