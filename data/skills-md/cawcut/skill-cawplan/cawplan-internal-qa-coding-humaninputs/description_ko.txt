단일 텍스트(AI 코딩 인간 입력, 선택적으로 쌍으로 된 보조 응답 및 이전 보조 꼬리 포함)를 현재 v2 인간 입력 카테고리 + 주제 분류로 분류하여 기본 카테고리, 전체 우선 순위가 지정된 범주 배열, 하나의 주제, topic_reason 및 topic_confidence를 반환합니다. uid.core-product의 분류 규칙에 대한 순수한 추론 검사이며 CawPlan 데이터 또는 API 호출은 포함되지 않습니다.
사용 시기: 현재 카테고리 및 주제 규칙에 대해 특정 문장이나 사람의 입력을 분류/분류하도록 요청하는 경우 — 예: "이것은 어떤 카테고리/주제입니까: ...", "이 보조 응답으로 분류" 또는 cawplan-internal-qa-coding-humaninputs-test에서 사용되는 행별 분류 단계로 사용됩니다.
해당되지 않음: 이미 업로드된 많은 인간 입력에 대한 대량/배치 정확도 테스트 또는 CawPlan에서 데이터 가져오기(cawplan-internal-qa-coding-humaninputs-test 사용), 보고서 제출 또는 티켓 생성.
