単一のテキスト (AI コーディングによる人間の入力、オプションでそのペアのアシスタント応答と前のアシスタントの尾) を現在の v2 人間入力カテゴリ + トピック分類法に分類し、プライマリ カテゴリ、完全な優先順位付きカテゴリ配列、1 つのトピック、topic_reason、および topic_confidence を返します。これは、uid.core-product の分類ルールに対する純粋な推論チェックであり、CawPlan データや API 呼び出しは含まれません。
いつ使用するか: 特定の文または人間の入力を現在のカテゴリおよびトピックのルールに基づいて分類/分類するよう求められる場合 — 例: 「これはどのカテゴリ/トピックですか: ...」、「このアシスタント応答でこれを分類」 — または、cawplan-internal-qa-coding-humaninputs-test で使用される行ごとの分類ステップとして。
対象外: すでにアップロードされている多数の人的入力に対する一括/バッチ精度テスト、または CawPlan からのデータの取得 (そのためには cawplan-internal-qa-coding-humaninputs-test を使用)、レポートの送信、またはチケットの作成。
