새로운 AI 코딩 세션 요약 기능에 대한 내부 QA 검사: cawplan CLI를 통해 한 세션의 전체 대화를 가져오고 uid.core-product의 세션 통찰력 프롬프트가 사용하는 것과 동일한 규칙을 사용하여 직접 설명 요약을 생성하므로 클라우드 강화 파이프라인을 실행하기 전/없이 요약 품질을 확인할 수 있습니다. 표시 전용이며 클라우드 값과 비교되지 않습니다(필드가 새 필드이므로 아직 백필되지 않았을 수 있음).
사용 시기: 세션 요약 프롬프트를 테스트/확인/시도하도록 요청하는 경우 — 예: "오늘 yupeng의 세션에 대한 요약을 테스트합니다.", "<id> 항목에 대한 요약이 어떻게 보이는지 확인합니다.", "임의의 최근 세션에서 세션 요약을 시도합니다."
해당되지 않음: 사람이 입력한 범주 분류(cawplan-internal-qa-coding-humaninputs[-test] 사용), 대량 정확도 테스트, 보고서 제출 또는 일반 세션 비용/사용 통찰력.
