Внутренняя проверка качества для новой функции сводки сеанса AI-кодирования: извлекает полный диалог одного сеанса через интерфейс командной строки cawplan и самостоятельно генерирует описательную сводку, используя те же правила, которые использует подсказка session-insights uid.core-product, поэтому вы можете оценить качество сводки до запуска облачного конвейера обогащения или без него. Только отображение, без сравнения с каким-либо облачным значением (поле новое и еще не может быть заполнено).
Используйте, когда: вас просят протестировать/проверить/опробовать подсказку сводки сеанса — например. «проверьте сводку сегодняшнего сеанса Юпэна», «посмотрите, как будет выглядеть сводка для записи <id>», «попробуйте сводку сеанса на случайном недавнем сеансе».
НЕ для: классификации категорий ввода данных человеком (используйте cawplan-internal-qa-coding-humaninputs[-test]), массового тестирования точности, отправки отчетов или общей информации о стоимости/использовании сеанса.
