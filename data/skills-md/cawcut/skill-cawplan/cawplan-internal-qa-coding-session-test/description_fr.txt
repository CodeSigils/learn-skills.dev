Contrôle qualité interne pour la nouvelle fonctionnalité de résumé de session de codage AI : récupère la conversation complète d'une session via la CLI cawplan et génère vous-même un résumé narratif en utilisant les mêmes règles que celles utilisées par l'invite d'informations de session de uid.core-product, afin que vous puissiez surveiller la qualité du résumé avant/sans avoir besoin de l'exécution du pipeline d'enrichissement du cloud. Affichage uniquement, aucune comparaison avec une valeur cloud (le champ est nouveau et ne peut pas encore être rempli).
À utiliser lorsque : il est demandé de tester/vérifier/essayer l'invite de résumé de session - par ex. "testez le résumé de la session de yupeng aujourd'hui", "voyez à quoi ressemblerait le résumé pour l'entrée <id>", "essayez le résumé de la session sur une session récente aléatoire".
PAS pour : la classification des catégories d'entrée humaine (utilisez cawplan-internal-qa-coding-humaninputs[-test]), les tests de précision en masse, la soumission de rapports ou les informations générales sur le coût/l'utilisation de la session.
