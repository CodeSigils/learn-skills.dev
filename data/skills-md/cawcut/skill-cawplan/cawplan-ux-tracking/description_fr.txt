Trouvez les tickets CawPlan qui nécessitent une attention UX : UX en attente pour une version, tickets hautement prioritaires manquant de conception UX ou toute la file d'attente UX en attente d'une équipe.
À utiliser lorsque : l'utilisateur demande quels tickets nécessitent un suivi/révision/spécification UX pour une version, quels tickets hautement prioritaires ont besoin d'UX mais n'ont pas encore de design, ou quelle équipe n'a pas reçu d'UX pour ses tickets.
PAS pour : la création ou la mise à jour de tickets, la définition du statut UX d'un ticket, la recherche générale de tickets ou le suivi des versions (utilisez « cawplan-plan-track » pour l'état des versions).
