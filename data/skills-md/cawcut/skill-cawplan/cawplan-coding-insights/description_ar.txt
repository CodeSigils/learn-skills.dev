اعرض رؤى استخدام ترميز الذكاء الاصطناعي: التكلفة، والرموز المميزة، ونشاط الجلسة، والتفاصيل حسب العضو، أو النموذج، أو الوكيل، أو المشروع، أو المنتج، أو الجودة السريعة.
يُستخدم عندما: يسأل المستخدم عن تكاليف البرمجة، أو إحصائيات استخدام الذكاء الاصطناعي، أو نشاط جلسة الفريق، أو إنفاق النموذج، أو استخدام الوكيل، أو الجودة الفورية، أو مقاييس الإنتاجية.
ليس من أجل: إرسال التقارير، أو إنشاء التذاكر، أو مقاييس صحة المنتج، أو تتبع الإصدار.
