SQA 요구 사항 입력을 5개의 구조화된 필드와 디스플레이 요약으로 분석하고 요구 사항을 CawPlan QA Insights에 보관합니다.
사용 시기: 사용자가 요구 사항 분석 의도와 함께 티켓 링크 또는 ID를 제공하는 경우(예: "需求分析", "이 티켓 분석", 스크린샷 + 티켓)를 포함하여 요구 사항 분석, 요구 사항 필드 구조, 표시 요약 및 공개 질문 목록이 포함된 5개 필드 초안 생성, QA 모듈 트리 노드 추천, 요구 사항 보관 또는 QA Insights의 기존 요구 사항 업데이트를 명시적으로 요청합니다.
메시지가 요구사항 분석 문구가 없는 순수 CawPlan 문제 URL인 경우 자동 선택하지 마십시오. 코딩 세션 티켓 로딩에는 `cawplan-ticket-context`를 선호합니다.
해당되지 않음: 코딩 세션에만 티켓 로드, 코드 작성 또는 편집, AI 일일 보고서 업로드, 티켓 생성 또는 테스트 포인트 생성.
