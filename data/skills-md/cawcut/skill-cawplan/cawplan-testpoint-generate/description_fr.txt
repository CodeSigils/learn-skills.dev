Générez des contours de couverture de points de test à partir d'une exigence CawPlan archivée (cinq champs), avec une liste de questions ouvertes et des points de test archivés par lots après confirmation SQA.
À utiliser lorsque : une exigence archivée nécessite des points de test ou un aperçu de la couverture ; transfert à froid (lien ou identifiant du portail d'exigence) ; transfert à chaud après l'archive A1 (« générer des points de test pour cette exigence » ); des points de test incrémentiels complètent une exigence existante.
PAS pour : la structuration ou l'archivage des exigences (utilisez `cawplan-requirement-analyze`) ; étendre les points de test dans des cas étape par étape ou dans Excel (A3) ; visualiser ou modifier des points de test archivés ou réviser dans des suites de tests (utiliser l'interface utilisateur Web) ; uniquement les brouillons à cinq champs non archivés (archiver via A1 d'abord).
