보관된 CawPlan 요구 사항(5개 필드)에서 공개 질문 목록과 SQA 확인 후 일괄 보관 테스트 포인트를 사용하여 테스트 포인트 적용 범위 개요를 생성합니다.
다음 경우에 사용하십시오: 보관된 요구 사항에 테스트 포인트 또는 적용 범위 개요가 필요합니다. 콜드 핸드오프(요구 사항 포털 링크 또는 ID) A1 아카이브 이후 핫 핸드오프("이 요구 사항에 대한 테스트 포인트 생성") 기존 요구사항에 대한 증분 테스트 포인트 보완입니다.
해당되지 않음: 요구 사항 구조화 또는 보관(`cawplan-requirement-analyze` 사용) 테스트 포인트를 단계별 사례 또는 Excel(A3)로 확장합니다. 보관된 테스트 포인트 보기 또는 편집 또는 테스트 스위트에서 검토(웹 UI 사용) 보관되지 않은 5개 필드 초안만 해당(먼저 A1을 통해 보관).
