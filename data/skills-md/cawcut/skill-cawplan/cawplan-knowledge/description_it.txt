Sfoglia ed esegui ricerche nella knowledge base di CawPlan: elenca/crea set di dati, elenca/carica documenti in a
set di dati e cercare informazioni in uno o tutti i set di dati.
Utilizzare quando: l'utente vuole sapere quali set di dati/documenti di conoscenza esistono, sfogliarne uno specifico
contenuto del set di dati, trovare/cercare informazioni archiviate nella knowledge base, creare un nuovo set di dati,
o caricare file/testo in uno.
NON per: sincronizzazione di origini dati (Notion/sito Web/Confluence), ricerche di ticket o dati di prodotto (utilizzare
`/cawplan-product-insights` o `/cawplan-ticket-context`).
