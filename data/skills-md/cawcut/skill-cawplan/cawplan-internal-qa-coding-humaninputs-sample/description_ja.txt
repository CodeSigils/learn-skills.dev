人間が入力したログを CawPlan から取得し (製品、ユーザー/メンバー、日付範囲、カウント、またはセッションごと)、本番分類などの prev/アシスタント コンテキストを前処理し、ローカル Web エディタを開いて、プロンプト評価フィクスチャの予期されるカテゴリ/トピック ラベルに注釈を付けます。
次の場合に使用します: 分類プロンプト テスト用のラベル付き人間入力サンプル JSON を構築または拡張する — 例: 「先週の SPX の Slack セッションから 20 ターンを取り出してラベルを付ける」、「コア製品のために人による入力をサンプリングする」。
対象外: クラウド ラベルに対する分類精度の実行 (cawplan-internal-qa-coding-humaninputs-test を使用)、単一の文の分類 (cawplan-internal-qa-coding-humaninputs を使用)、またはコーディング レポートの送信。
