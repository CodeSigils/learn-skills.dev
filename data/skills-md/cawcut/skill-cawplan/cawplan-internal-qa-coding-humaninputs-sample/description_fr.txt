Extrayez les journaux de saisie humaine de CawPlan (par produit, utilisateur/membre, plage de dates, nombre ou session), prétraitez le contexte précédent/assistant comme la classification de production et ouvrez un éditeur Web local pour annoter les étiquettes de catégorie/sujet attendues pour une évaluation rapide.
À utiliser lorsque : la création ou l'extension d'un exemple JSON étiqueté à entrée humaine pour classifier les tests d'invite - par ex. "tirez 20 tours de la session Slack de spx la semaine dernière et étiquetez-les", "échantillonnez les entrées humaines pour le produit principal".
PAS pour : exécuter une classification de précision par rapport aux étiquettes cloud (utilisez cawplan-internal-qa-coding-humaninputs-test), classer une seule phrase (utiliser cawplan-internal-qa-coding-humaninputs) ou soumettre des rapports de codage.
