미리보기 우선 워크플로를 사용하여 CawPlan(요구 사항/TestPoint 또는 INLINE 세션 사례)에서 TestRail로 QA 테스트 사례를 가져옵니다.

NOT: 테스트 포인트 생성(`cawplan-testpoint-generate` 사용) 보관 요구 사항(`cawplan-requirement-analyze` 사용) 테스트 계획/실행 생성(A2, 미래) 고장-결함(A4); 방출 위험(A5).
