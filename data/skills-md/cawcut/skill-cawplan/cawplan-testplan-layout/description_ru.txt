Организуйте планы тестирования CawPlan QA Insights TestRail из импортированных случаев на основе версий/заявок с помощью рабочего процесса с предварительным просмотром.
Используйте при: создании или выполнении планов/запусков TestRail A2 для версии CawPlan или одного или нескольких билетов CawPlan после импорта обращений.
НЕ для: импорта тестовых случаев (используйте `cawplan-testcase-import`); создание тестовых точек; сводки исполнения; регистрация дефектов; освободить риск.
НЕ используйте `cawplan api GET /api/v1/public/openapi/product/{product_id}` для разрешения имени продукта — такого маршрута не существует.
