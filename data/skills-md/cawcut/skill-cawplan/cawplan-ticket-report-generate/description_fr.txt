Générez et insérez un rapport d'assurance qualité à l'échelle du ticket (PROGRÈS ou COMPLÉTION) pour tout ticket CawPlan (ancre) + version : collectez les données de sous-arbre/relation/exécution relatives à l'ancre, appliquez les règles de résultat, restituez le modèle ticket-qa-report.1 et conservez via le portail qa_report POST/PUT existant.
À utiliser lorsque : SQA demande un rapport d'assurance qualité sur la progression ou l'achèvement du test pour un ticket et une version (histoire, sous-ticket d'exigence ou CORRECTIF DE BUGFIX) ; republier/mettre à jour un rapport lié existant ; inclure les tickets associés/bloquants dans la portée du rapport.
PAS pour : le rapport de qualité de version ou le cumul d'automatisation AQA ; évaluation des risques de libération (utiliser A5 séparément) ; importation de cas (A1), plan de mise en page (A2) ou classement de défauts (A4).
V1 zéro-BE : upsert côté agent ; couverture approximative ; profondeur de sous-arbre relative à l'ancre ≤ 3.
