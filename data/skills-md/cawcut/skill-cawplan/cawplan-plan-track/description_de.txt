Verfolgen Sie den CawPlan-Veröffentlichungsfortschritt für eine Version: Ticketabschluss, Risikostufe, offene Punkte und geplante Veröffentlichungstermine.
Verwenden Sie diese Option, wenn: Der Benutzer möchte eine Veröffentlichung verfolgen, den Veröffentlichungsfortschritt überprüfen, sehen, was eine Version blockiert, oder offene Tickets für eine Version überprüfen.
NICHT für: das Erstellen von Versionen oder Tickets, Produktmetrik-Dashboards, Zusammenfassungen der Benutzeraktivitäten oder die Suche nach kritischen Problemen.
