Développez les points de test archivés en cas de test exécutables : démarquez d'abord l'aperçu du titre et de l'état, développez les étapes à la demande, exportez le CSV de l'équipe lorsque SQA le demande activement après examen (lecture seule – n'écrit pas dans CawPlan).
À utiliser lorsque : la génération de scénarios de test (aperçu en premier), le développement d'étapes exécutables dans l'aperçu Markdown, l'exportation d'un fichier CSV lorsque SQA demande l'exportation ou un transfert à chaud après A2 ("按上面的生成用例", "générer des scénarios de test par le haut", ou similaire) ; transfert à froid via le lien du portail Requirement ou require_id.
PAS pour : les contours de la couverture des points de test (utilisez `cawplan-testpoint-generate`) ; analyse ou archivage des exigences (utilisez « cawplan-requirement-analyze » ); afficher ou modifier les points de test archivés dans les suites de tests (interface utilisateur Web) ; uniquement les brouillons à cinq champs non archivés (archiver via A1 d'abord).
