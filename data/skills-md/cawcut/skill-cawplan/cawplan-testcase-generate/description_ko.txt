보관된 테스트 포인트를 실행 가능한 테스트 사례로 확장: 먼저 마크다운 제목 상태 미리보기, 요청 시 단계 확장, 검토 후 SQA가 적극적으로 요청할 때 팀 CSV 내보내기(읽기 전용 - CawPlan에 쓰지 않음).
사용 시기: 테스트 사례 생성(미리보기 먼저), Markdown 미리보기에서 실행 가능한 단계 확장, SQA에서 내보내기를 요청할 때 CSV 내보내기 또는 A2 이후 핫 핸드오프("按上面的生成用例", "위에서 테스트 사례 생성" 등) 요구 사항 포털 링크 또는 요구 사항_id를 통한 콜드 핸드오프.
해당되지 않음: 테스트 포인트 적용 범위 개요(`cawplan-testpoint-generate` 사용) 요구 사항 분석 또는 보관(`cawplan-requirement-analyze` 사용) 테스트 스위트(웹 UI)에서 보관된 테스트 포인트 보기 또는 편집 보관되지 않은 5개 필드 초안만 해당(먼저 A1을 통해 보관).
