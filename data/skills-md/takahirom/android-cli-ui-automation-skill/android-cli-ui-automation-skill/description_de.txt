Automatisieren Sie die Benutzeroberfläche auf einem verbundenen Android-Gerät oder Emulator über die Android-CLI. Verwenden Sie diese Funktion, wenn Sie aufgefordert werden, eine App zu starten, auf eine Schaltfläche zu tippen, Text einzugeben, durch eine URL zu navigieren oder einen Fluss auf dem Bildschirm zu einem Ziel zu führen.
