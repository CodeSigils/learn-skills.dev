أداة إدارة مدونة Hexo بنقرة واحدة، يوجد ملف التكوين في ~/.config/hexo/config.yaml.

الميزات الأساسية:
1. إنشاء مدونة بنقرة واحدة: إنشاء الغلاف تلقائيًا ← التحميل إلى OSS ← إنشاء تخفيض السعر ← إرسال إلى GitHub
2. إنشاء غلاف بتقنية الذكاء الاصطناعي: اتصل بواجهة برمجة التطبيقات المخصصة (defaultgpt‑image‑2)، ويدعم أغلفة 16:9
3. استضافة الصور: التحميل إلى مستودع GitHub_Oss، وإنشاء رابط jsDelivr CDN
4. المصادقة المزدوجة: تدعم gh CLI (افتراضي) أو GitHub Personal Access Token
5. إدارة التكوين: الإدارة الموحدة لمفتاح API ورمز GitHub ومسار المستودع وما إلى ذلك.

وصف البرنامج النصي:
- hexo_config.py: تكوين القراءة/الكتابة (init/show/check/set‑api‑key/set‑github‑token)
- generator_cover.py: إنشاء الغلاف (--title/--style/--model)
- upload_prep.py: إعداد تحميل OSS (تشفير Base64)
- create_post.py: إنشاء مدونة بنقرة واحدة (يدمج جميع الخطوات المذكورة أعلاه)

سيناريو التشغيل: يستخدم عندما يذكر المستخدم إنشاء مدونة، أو نشر مقال، أو إنشاء غلاف، أو تحميل الصور، أو تكوين Hexo، أو إدارة المدونة، أو استضافة الصور، أو مصادقة GitHub.

يرجى الرد دائمًا بلغة المستخدم.
