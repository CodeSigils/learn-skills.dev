Hexo blog one-click management tool, configuration file located at ~/.config/hexo/config.yaml.

Core features:
1. One-click blog creation: automatically generate cover → upload to OSS → create Markdown → submit to GitHub
2. AI cover generation: calls custom API (default gpt-image-2), supports 16:9 covers
3. Image hosting: upload to GitHub_Oss repository, generate jsDelivr CDN link
4. Dual authentication: supports gh CLI (default) or GitHub Personal Access Token
5. Configuration management: unified management of API Key, GitHub Token, repository path, etc.

Script descriptions:
- hexo_config.py: configuration read/write (init/show/check/set-api-key/set-github-token)
- generate_cover.py: cover generation (--title/--style/--model)
- upload_prep.py: OSS upload preparation (Base64 encoding)
- create_post.py: one-click blog creation (integrates all the above steps)

Trigger scenarios: used when the user mentions creating a blog, publishing an article, generating a cover, uploading images, Hexo configuration, blog management, image hosting, GitHub authentication.
