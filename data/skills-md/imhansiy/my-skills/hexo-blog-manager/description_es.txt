Herramienta de administración con un solo clic del blog Hexo, archivo de configuración ubicado en ~/.config/hexo/config.yaml.

Características principales:
1. Creación de blog con un clic: generar portada automáticamente → subir a OSS → crear Markdown → enviar a GitHub
2. Generación de portadas de IA: llama a API personalizada (gpt-image-2 predeterminada), admite portadas 16:9
3. Alojamiento de imágenes: cárguelo en el repositorio GitHub_Oss, genere el enlace CDN jsDelivr
4. Autenticación dual: admite gh CLI (predeterminado) o GitHub Personal Access Token
5. Gestión de configuración: gestión unificada de clave API, token de GitHub, ruta del repositorio, etc.

Descripciones de guiones:
- hexo_config.py: configuración de lectura/escritura (init/show/check/set-api-key/set-github-token)
- generate_cover.py: generación de portada (--título/--estilo/--modelo)
- upload_prep.py: preparación de carga OSS (codificación Base64)
- create_post.py: creación de blog con un solo clic (integra todos los pasos anteriores)

Escenarios de activación: se utilizan cuando el usuario menciona crear un blog, publicar un artículo, generar una portada, cargar imágenes, configuración de Hexo, gestión de blog, alojamiento de imágenes, autenticación de GitHub.
