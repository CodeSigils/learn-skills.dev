Инструмент управления блогом Hexo одним щелчком мыши, файл конфигурации расположен по адресу ~/.config/hexo/config.yaml.

Основные функции:
1. Создание блога в один клик: автоматическое создание обложки → загрузка в OSS → создание Markdown → отправка на GitHub.
2. Генерация обложки AI: вызов пользовательского API (defaultgpt-image-2), поддержка обложки 16:9.
3. Хостинг изображений: загрузите в репозиторий GitHub_Oss, сгенерируйте ссылку jsDelivr CDN.
4. Двойная аутентификация: поддерживает gh CLI (по умолчанию) или токен личного доступа GitHub.
5. Управление конфигурацией: унифицированное управление ключом API, токеном GitHub, путем к хранилищу и т. д.

Описание скрипта:
- hexo_config.py: чтение/запись конфигурации (init/show/check/set‑api‑key/set‑github‑token)
-gener_cover.py: создание обложки (--title/--style/--model)
- upload_prep.py: подготовка загрузки OSS (кодировка Base64)
- create_post.py: создание блога в один клик (объединяет все вышеперечисленные шаги)

Сценарии триггера: используются, когда пользователь упоминает создание блога, публикацию статьи, создание обложки, загрузку изображений, настройку Hexo, управление блогом, хостинг изображений, аутентификацию GitHub.
