Le schede organizzano i contenuti correlati in un contesto condiviso: cambiando scheda si cambia la visualizzazione senza uscire dalla pagina. Da utilizzare quando una schermata presenta più aree di contenuto distinte che condividono un'intestazione o un set di azioni comune e quando l'utente deve passare frequentemente dall'una all'altra. Da utilizzare durante la progettazione di layout a schede, pannelli di contenuto, pagine di impostazioni, visualizzazioni di dettagli o dashboard con più visualizzazioni di dati.
