HTML5 الدلالي، وأساسيات تحسين محركات البحث (SEO)، والنصوص البديلة، والتحسين التدريجي، واعتبارات SPA، واكتشاف قدرة الجهاز، والوعي بسياق المستخدم. HTML الجيد هو أساس إمكانية الوصول وتحسين محركات البحث وواجهة المستخدم المرنة. يُستخدم عند إنشاء أي واجهة مستخدم ويب، أو مراجعة جودة الترميز، أو تحسين البحث وإمكانية الوصول.
