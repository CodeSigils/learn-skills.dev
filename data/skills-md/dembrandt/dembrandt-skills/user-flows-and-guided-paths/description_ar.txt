يجب تصميم الميزات والمهام ذات الصلة - مثل تدفقات الشراء أو الإعداد أو التكوين متعدد الخطوات - كمسارات طبيعية وموجهة تبدو متماسكة وتناسب التسلسل الهرمي للمنتج. استخدم المعالجات للمهام المتسلسلة المعقدة. يُستخدم عند تصميم التدفقات، أو الإعداد، أو الخروج، أو تسلسلات الإعداد، أو أي رحلة مستخدم متعددة الخطوات.
