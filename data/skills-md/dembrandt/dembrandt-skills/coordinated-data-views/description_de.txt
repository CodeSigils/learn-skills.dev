Wenn Daten sowohl eine Tabellen-/Listendarstellung als auch eine visuelle Darstellung haben, zeigen Sie beide gleichzeitig an und halten Sie sie synchron. Durch Klicken auf eine Zeile wird das entsprechende Element in der visuellen Ansicht hervorgehoben und umgekehrt. Gilt für Karten, Diagramme, Zeitleisten und Diagramme, die einer Datentabelle beiliegen. Verwenden Sie diese Option beim Entwerfen einer Benutzeroberfläche, bei der Daten gleichzeitig in zwei verschiedenen Darstellungen angezeigt werden.
