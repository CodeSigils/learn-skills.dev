Dans les applications volumineuses, l'architecture de l'information détermine si les utilisateurs peuvent trouver, comprendre et agir sur les données. Le nom est important. L'interface utilisateur doit refléter le modèle de données et indiquer comment les données peuvent être transformées. Les modifications dangereuses ou irréversibles nécessitent toujours une boîte de dialogue de confirmation. À utiliser lors de la conception de la navigation, de la dénomination d'entités, de la structuration de grands ensembles de fonctionnalités ou de la modélisation d'une interface utilisateur basée sur les données.
