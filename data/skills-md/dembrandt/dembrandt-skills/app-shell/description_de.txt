Die dauerhafte Hülle um eine Anwendung – die obere Leiste, der App-Launcher, der Mandanten- und Umgebungshinweis und bei umfangreichen Tools eine Statusleiste. In einem Bestand aus mehreren Anwendungen gehört die Shell zum Bestand und nicht zu einer einzelnen App, und sie ist es, die einen Benutzer zwischen den Tools transportiert. Verwenden Sie diese Option beim Entwerfen einer oberen Leiste, eines App-Umschalters, einer Mandantenauswahl, eines Umgebungshinweises, einer Statusleiste oder der Navigation zwischen separaten Tools hinter einer Anmeldung. Informationen zu den Gebietsschema-, Währungs- und Einheitensteuerelementen, die die Shell enthält, finden Sie unter global-toolbar-controls.
