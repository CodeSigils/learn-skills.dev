Elija deliberadamente el modo de color claro, oscuro o combinado según el tono de la marca y el contexto del usuario. Ofrezca un selector de temas solo cuando el control del usuario realmente importe: herramientas empresariales, interfaces de usuario con gran cantidad de datos o aplicaciones de uso extendido. Úselo al definir la paleta de colores base, diseñar un sistema de diseño o decidir si desea crear soporte para el modo oscuro.
