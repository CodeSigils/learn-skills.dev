Оркестратор для полного UX-конвейера dembrandt. Маршрутизирует задачу UI/UX через шесть упорядоченных этапов — основа бренда → токены дизайна → макет → компоненты → полировка UX → ворота доступности — загружая правильный поднавык на каждом этапе. Используйте, когда задача охватывает несколько задач проектирования: «обзор дизайна», «создание пользовательского интерфейса», «аудит интерфейса», «от бренда к пользовательскому интерфейсу». Для задач, связанных с одной задачей (например, «проверить мою цветовую палитру»), вместо этого перейдите непосредственно к соответствующему поднавыку.
