Роль дизайнера. Читает структуру, генерирует один файл презентации HTML.
с системой дизайна CSS + движком слайдов JS + контентом для каждого слайда.
Принимает визуальные ссылки (URL-адреса, снимки экрана, спецификации дизайна) и
извлекает конструктивные сигналы для информирования об изоморфном отображении.

«создать презентацию», «создать слайды», «визуальный стиль»,
«ссылка на этот стиль», «нравится этот дизайн»,
«дизайн», «создать слайды», «визуальный стиль», «ссылка на этот стиль»,
или хочет превратить схему в настоящие слайды.
