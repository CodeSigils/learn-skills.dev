Intégrez un vendeur x402 sur Solana via pr402 (ipay.sh) : portes HTTP 402, intégration de SplitVault, vérification/règlement de PAIEMENT-SIGNATURE et inscription à la découverte. À utiliser chaque fois que l'utilisateur monétise une API, ajoute le paiement par appel, implémente HTTP 402, mentionne le vendeur x402, le vendeur pr402, X402SellerSDK, le portefeuille marchand, SplitVault, x402-resources.json, x402-seller-starter, x402-subscription-starter, l'abonnement, l'abonnement JWT mensuel quotidien ou exact-rail UniversalSettle. Si le vendeur et l'acheteur ne sont pas clairs, chargez d'abord **pr402**.
