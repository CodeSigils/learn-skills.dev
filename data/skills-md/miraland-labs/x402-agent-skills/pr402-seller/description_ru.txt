Интегрируйте продавца x402 в Solana через pr402 (ipay.sh): шлюзы HTTP 402, подключение SplitVault, проверка/сопоставление PAYMENT-SIGNATURE и регистрация обнаружения. Используйте каждый раз, когда пользователь монетизирует API, добавляет оплату за вызов, реализует HTTP 402, упоминает продавца x402, продавца pr402, X402SellerSDK, кошелек продавца, SplitVault, x402-resources.json, x402-seller-starter, x402-subscription-starter, подписку, почасовую ежедневную ежемесячную подписку JWT или точные рельсы UniversalSettle. Если неясно, продавец или покупатель, сначала загрузите **pr402**.
