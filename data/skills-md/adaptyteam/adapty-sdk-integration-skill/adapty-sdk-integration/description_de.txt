Verwenden Sie diese Option, wenn ein Benutzer das Adapty SDK in eine mobile App integrieren, In-App-Käufe mit Adapty einrichten oder seiner App eine Paywall hinzufügen möchte. Wird ausgelöst bei „Adapty integrieren“, „Adapty zu meiner App hinzufügen“, „Abonnements einrichten“, „Paywall hinzufügen“ oder ähnliches.
