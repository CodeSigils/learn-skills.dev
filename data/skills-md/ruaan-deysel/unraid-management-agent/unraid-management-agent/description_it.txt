Monitora e controlla un server Unraid tramite il server MCP di Unraid Management Agent (125 strumenti, 5 risorse, 6 prompt diagnostici) e l'API REST. Utilizzare quando: si connette un client AI (Claude, ChatGPT, Cursor, Copilot, Gemini CLI) a Unraid; controllare lo stato di sistema, array, disco, Docker, VM, GPU, UPS, ZFS o rete; avvio/arresto di contenitori, macchine virtuali, array o controlli di parità; diagnosticare l'integrità del disco, le prestazioni o lo stato dell'array; gestire avvisi, controlli di integrità, ventola/CPU/ottimizzazione o aggiornamenti; oppure scegliendo tra MCP, REST e WebSocket. Correzioni: inventare nomi di strumenti Unraid o percorsi REST; eseguire azioni distruttive (arrestare array, riavviare, eliminare snapshot) senza confirm=true; interrogare REST in un ciclo invece di utilizzare WebSocket/MCP; dumping di elenchi completi invece di strumenti search_/get_; e presupponendo che l'autenticazione manchi all'agente per impostazione predefinita.
