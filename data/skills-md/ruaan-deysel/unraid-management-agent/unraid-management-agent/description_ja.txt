Unraid Management Agent の MCP サーバー (125 のツール、5 つのリソース、6 つの診断プロンプト) および REST API を介して Unraid サーバーを監視および制御します。 AI クライアント (Claude、ChatGPT、Cursor、Copilot、Gemini CLI) を Unraid に接続する場合に使用します。システム、アレイ、ディスク、Docker、VM、GPU、UPS、ZFS、またはネットワークのステータスをチェックします。コンテナ、VM、アレイ、またはパリティ チェックの開始/停止。ディスクの健全性、パフォーマンス、またはアレイの状態を診断します。アラート、ヘルスチェック、ファン/CPU/チューニング、またはアップデートの管理。または、MCP、REST、WebSocket のいずれかを選択します。修正: Unraid ツール名または REST パスの考案。 verify=true を指定せずに破壊的なアクション (アレイの停止、再起動、スナップショットの削除) を実行しています。 WebSocket/MCP を使用する代わりにループ内で REST をポーリングします。 search_/get_ ツールの代わりに完全なリストをダンプします。そして、エージェントにはデフォルトで認証がないと仮定します。
