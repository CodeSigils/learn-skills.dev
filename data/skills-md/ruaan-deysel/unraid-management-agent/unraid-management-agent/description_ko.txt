Unraid Management Agent의 MCP 서버(도구 125개, 리소스 5개, 진단 프롬프트 6개) 및 REST API를 통해 Unraid 서버를 모니터링하고 제어합니다. 사용 시기: AI 클라이언트(Claude, ChatGPT, Cursor, Copilot, Gemini CLI)를 Unraid에 연결합니다. 시스템, 어레이, 디스크, Docker, VM, GPU, UPS, ZFS 또는 네트워크 상태 확인 컨테이너, VM, 어레이 또는 패리티 검사 시작/중지 디스크 상태, 성능 또는 어레이 상태 진단 경고, 상태 확인, 팬/CPU/튜닝 또는 업데이트 관리 또는 MCP, REST 및 WebSocket 중에서 선택합니다. 수정 사항: Unraid 도구 이름 또는 REST 경로를 고안합니다. 확인=true 없이 파괴적인 작업(스토리지 중지, 재부팅, 스냅샷 삭제)을 실행합니다. WebSocket/MCP를 사용하는 대신 루프에서 REST를 폴링합니다. search_/get_ 도구 대신 전체 목록을 덤프합니다. 인증이 기본적으로 에이전트에 부족하다고 가정합니다.
