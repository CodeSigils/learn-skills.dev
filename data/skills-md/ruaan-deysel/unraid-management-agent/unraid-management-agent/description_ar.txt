مراقبة خادم Unraid والتحكم فيه عبر خادم MCP الخاص بـ Unraid Management Agent (125 أداة و5 موارد و6 مطالبات تشخيصية) وREST API. يُستخدم عندما: توصيل عميل AI (Claude، ChatGPT، Cursor، Copilot، Gemini CLI) بـ Unraid؛ التحقق من النظام أو المصفوفة أو القرص أو Docker أو VM أو GPU أو UPS أو ZFS أو حالة الشبكة؛ بدء/إيقاف الحاويات أو الأجهزة الافتراضية أو المصفوفة أو عمليات التحقق من التكافؤ؛ تشخيص صحة القرص أو الأداء أو حالة الصفيف؛ إدارة التنبيهات أو فحوصات السلامة أو المروحة/وحدة المعالجة المركزية/الضبط أو التحديثات؛ أو الاختيار بين MCP وREST وWebSocket. التصحيحات: اختراع أسماء أدوات Unraid أو مسارات REST؛ تنفيذ إجراءات مدمرة (إيقاف المصفوفة، إعادة التشغيل، حذف اللقطة) بدون تأكيد = صحيح؛ استقصاء REST في حلقة بدلاً من استخدام WebSocket/MCP؛ تفريغ القوائم الكاملة بدلاً من أدوات البحث_/get_؛ وبافتراض المصادقة التي يفتقر إليها الوكيل افتراضيًا.
