Riferimento ai principi e alle pratiche del Clean Code basati sul lavoro di Robert Martin. Utilizza questa competenza durante la revisione della qualità del codice, le convenzioni di denominazione, il refactoring o l'applicazione dei principi SOLID. Si attiva automaticamente per il rilevamento dell'odore del codice, i miglioramenti dello stile e i problemi di manutenibilità.
