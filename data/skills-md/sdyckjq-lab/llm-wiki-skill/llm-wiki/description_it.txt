Sistema di costruzione della base di conoscenza personale (basato sulla metodologia llm-wiki di Karpathy). Lascia che l'intelligenza artificiale crei e mantenga continuamente la tua base di conoscenza, supportando più fonti di contenuto (pagine web, Twitter, articoli WeChat, Xiaohongshu, Zhihu, YouTube, PDF, file locali), organizzandoli automaticamente in un wiki strutturato.
Condizione di attivazione: l'utente menziona esplicitamente "knowledge base", "wiki" o "llm-wiki" o richiede digestione, query, controlli di integrità o operazioni simili su una knowledge base già inizializzata. Non attivarsi quando l'utente chiede semplicemente di "riassumere questo articolo": l'intento deve essere chiaramente correlato alla knowledge base.
