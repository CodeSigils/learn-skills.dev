Habilidad de operación de base de datos MySQL, compatible con operaciones INSERTAR, ACTUALIZAR, SELECCIONAR y cambiar entre múltiples instancias de MySQL. Nota: Esta habilidad solo permite operaciones INSERTAR, ACTUALIZAR, SELECCIONAR, y prohíbe estrictamente operaciones peligrosas como ELIMINAR, SOLTAR, TRUNCAR, ALTERAR, CREAR.
