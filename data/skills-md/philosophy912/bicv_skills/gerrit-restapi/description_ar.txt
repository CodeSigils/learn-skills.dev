مهارة REST API لنظام مراجعة كود Gerrit. يستخدم لتنفيذ نقاط نهاية Gerrit REST API المطبقة داخل المستودع الحالي ويدعم التمديد عند الطلب لنقاط النهاية الجديدة. استخدم هذه المهارة عندما تحتاج إلى الاستعلام عن التغييرات أو مراجعة التعليمات البرمجية أو تنفيذ العمليات المتعلقة بإدارة المشروع. عندما تكون الأوامر الفرعية موجودة بالفعل، قم بإعطاء الأولوية للتنفيذ عبر scripts/gerrit_api.py؛ إذا لم يتم تنفيذ الواجهة، فيمكنك كتابة رمز الطلب بنفسك.
