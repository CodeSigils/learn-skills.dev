Habilidad API REST para el sistema de revisión de código Gerrit. Se utiliza para ejecutar puntos finales de Gerrit REST API implementados dentro del repositorio actual y admite la extensión bajo demanda de nuevos puntos finales. Utilice esta habilidad cuando necesite consultar cambios, revisar código o realizar operaciones relacionadas con la gestión de proyectos. Cuando ya existan subcomandos, priorice la ejecución mediante scripts/gerrit_api.py; Si no se implementa una interfaz, usted mismo puede escribir el código de solicitud.
