Competenza API REST per il sistema di revisione del codice Gerrit. Utilizzato per eseguire gli endpoint API Gerrit REST implementati all'interno del repository corrente e supporta l'estensione su richiesta di nuovi endpoint. Utilizza questa competenza quando è necessario eseguire query su modifiche, rivedere il codice o eseguire operazioni relative alla gestione del progetto. Quando i sottocomandi esistono già, dai la priorità all'esecuzione tramite scripts/gerrit_api.py; se un'interfaccia non è implementata, puoi scrivere tu stesso il codice di richiesta.
