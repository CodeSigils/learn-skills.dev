REST-API-Kenntnisse für das Gerrit-Codeüberprüfungssystem. Wird zur Ausführung implementierter Gerrit REST API-Endpunkte im aktuellen Repository verwendet und unterstützt die bedarfsgesteuerte Erweiterung neuer Endpunkte. Nutzen Sie diese Fähigkeit, wenn Sie Änderungen abfragen, Code überprüfen oder projektmanagementbezogene Vorgänge durchführen müssen. Wenn Unterbefehle bereits vorhanden sind, priorisieren Sie die Ausführung über scripts/gerrit_api.py; Wenn eine Schnittstelle nicht implementiert ist, können Sie selbst Anforderungscode schreiben.
