Compétence API REST pour le système de révision de code Gerrit. Utilisé pour exécuter les points de terminaison de l'API Gerrit REST implémentés dans le référentiel actuel et prend en charge l'extension à la demande de nouveaux points de terminaison. Utilisez cette compétence lorsque vous devez interroger des modifications, réviser du code ou effectuer des opérations liées à la gestion de projet. Lorsque des sous-commandes existent déjà, priorisez l'exécution via scripts/gerrit_api.py ; si une interface n'est pas implémentée, vous pouvez écrire le code de requête vous-même.
