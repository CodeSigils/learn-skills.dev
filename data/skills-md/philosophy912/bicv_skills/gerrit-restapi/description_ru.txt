Навыки REST API для системы проверки кода Gerrit. Используется для выполнения реализованных конечных точек Gerrit REST API в текущем репозитории и поддерживает расширение новых конечных точек по требованию. Используйте этот навык, когда вам нужно запросить изменения, просмотреть код или выполнить операции, связанные с управлением проектом. Если подкоманды уже существуют, установите приоритет выполнения через scripts/gerrit_api.py; если интерфейс не реализован, вы можете написать код запроса самостоятельно.
