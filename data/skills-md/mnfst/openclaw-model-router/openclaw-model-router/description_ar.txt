قم بتثبيت وتكوين البرنامج المساعد لجهاز التوجيه Manifest LLM لـ OpenClaw. يُستخدم عندما يقول المستخدم "/install-manifest"، أو "تثبيت البيان"، أو "إضافة مكون إضافي للبيان"، أو "جهاز توجيه طراز الإعداد"، أو "تقليل تكاليف LLM"، أو يريد تثبيت المكون الإضافي Manifest لتوجيه الطلبات، وخفض التكاليف، وإضافة احتياطيات، وتعيين حدود الإنفاق. يقبل الوضع الاختياري (المحلي أو السحابي) ومفتاح API.
