API NOAA Weather.gov обеспечивает доступ к прогнозам, оповещениям, наблюдениям, радиолокационным данным Национальной метеорологической службы и многому другому для США. Используйте этот навык для получения прогнозов погоды, активных оповещений, наблюдений станций и данных зон. Никакого ключа API не требуется — только заголовок User-Agent.
