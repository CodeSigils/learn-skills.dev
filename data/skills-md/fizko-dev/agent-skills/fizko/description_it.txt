Utilizza questa skill ogni volta che l'utente richiede dati contabili, movimenti bancari, riconciliazione, IVA, F29, obligaciones, asientos contables o qualsiasi dato finanziario/contabile per la propria attività cilena. Utilizzalo anche quando l'utente chiede di classificare un movimento bancario, riconciliare un movimento con un documento, creare una registrazione prima nota o eseguire qualsiasi azione contabile. Questa competenza controlla la CLI `fizko` (pacchetto npm) per eseguire query e agire sui dati dell'API Fizko. Usala anche se l'utente non menziona esplicitamente "fizko": se chiede i dati finanziari della propria azienda o vuole fare qualcosa con un movimento o un obbligo bancario, questa abilità si applica.
