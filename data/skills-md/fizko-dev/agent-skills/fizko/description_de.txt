Verwenden Sie diesen Skill immer dann, wenn der Benutzer nach Buchhaltungsdaten, Bankbewegungen, Abstimmung, IVA, F29, Obligaciones, Asientos Contables oder anderen Finanz-/Buchhaltungsdaten für sein chilenisches Unternehmen fragt. Verwenden Sie es auch, wenn der Benutzer eine Bankbewegung klassifizieren, eine Bewegung mit einem Dokument abgleichen, einen Journaleintrag erstellen oder eine Buchhaltungsaktion durchführen möchte. Dieser Skill steuert die „fizko“-CLI (npm-Paket), um Daten von der Fizko-API abzufragen und darauf zu reagieren. Verwenden Sie es auch dann, wenn der Benutzer „fizko“ nicht explizit erwähnt – wenn er nach den Finanzdaten seines Unternehmens fragt oder etwas mit einer Bankbewegung oder -verpflichtung tun möchte, ist diese Fähigkeit anwendbar.
