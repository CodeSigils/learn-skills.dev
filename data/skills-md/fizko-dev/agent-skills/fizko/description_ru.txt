Используйте этот навык всякий раз, когда пользователь спрашивает о данных бухгалтерского учета, банковских движениях, выверке, IVA, F29, obligaciones, asientos contables или любых финансовых/бухгалтерских данных для его чилийского бизнеса. Также используйте его, когда пользователь просит классифицировать банковское движение, согласовать движение с документом, создать проводку в журнале или выполнить какое-либо учетное действие. Этот навык управляет интерфейсом командной строки fizko (пакет npm) для запроса и обработки данных из API Fizko. Используйте его, даже если пользователь не упоминает «физко» явно — если он спрашивает о финансовых данных своей компании или хочет что-то сделать с банковским движением или обязательством, этот навык применим.
