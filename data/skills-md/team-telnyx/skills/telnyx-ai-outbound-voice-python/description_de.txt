End-to-End-Setup, um einen Telnyx-KI-Assistenten dazu zu bringen, eine Telefonnummer anzurufen. Behandelt die Bereitstellung einer Telefonnummer, das Erstellen einer TeXML-Anwendung, das Zuweisen der Nummer, das Konfigurieren von Telefonieeinstellungen, das Aufnehmen von Zielländern auf die Whitelist und das Auslösen ausgehender Anrufe über geplante Ereignisse. Verwenden Sie diese Fähigkeit (nicht telnyx-ai-assistants-python), wenn die Aufgabe darin besteht, dass ein KI-Assistent einen ausgehenden Anruf an einen Benutzer tätigt, tätigt oder auslöst.
