Создавайте кроссплатформенные приложения для VoIP-вызовов с помощью React Native, используя Telnyx Voice SDK. Высокоуровневый реактивный API с автоматическим управлением жизненным циклом, интеграцией CallKit/ConnectionService и push-уведомлениями. Используйте для мобильных приложений VoIP с минимальной настройкой.
