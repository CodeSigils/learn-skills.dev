Turso Cloud: piattaforma database compatibile con SQLite completamente gestita, accessibile tramite la rete. Da utilizzare quando si connette un'applicazione a un database Turso Cloud, si creano o si definiscono token di autenticazione (JWT, autorizzazioni granulari, JWKS/provider di autenticazione esterni) o si effettua il provisioning e la gestione di database cloud. Copre SDK per lingua (JavaScript/TypeScript, Python, Go, Rust), autenticazione e autorizzazione e integrazioni del marketplace (Vercel).
