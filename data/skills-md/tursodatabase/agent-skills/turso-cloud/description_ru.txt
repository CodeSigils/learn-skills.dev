Turso Cloud — полностью управляемая платформа баз данных, совместимая с SQLite, доступ к которой осуществляется по сети. Используйте при подключении приложения к базе данных Turso Cloud, создании или определении токенов аутентификации (JWT, детальные разрешения, JWKS/внешние поставщики аутентификации) или при подготовке облачных баз данных и управлении ими. Охватывает пакеты SDK для каждого языка (JavaScript/TypeScript, Python, Go, Rust), аутентификацию и авторизацию, а также интеграцию с торговой площадкой (Vercel).
