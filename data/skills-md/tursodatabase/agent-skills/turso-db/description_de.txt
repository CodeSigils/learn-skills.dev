Datenbankhelfer Turso (Limbo) – eine in Rust geschriebene In-Process-SQLite-kompatible Datenbank. Früher bekannt als libSQL / libsql. Ersetzt @libsql/client, libsql-experimental für Turso-Anwendungsfälle. Funktioniert in Node.js, Browser (WASM + OPFS für dauerhaften lokalen Speicher), React Native und serverseitig. Funktionen: Vektorsuche, Volltextsuche, CDC, MVCC, Verschlüsselung, Remote-Synchronisierung. SDKs: JavaScript (@tursodatabase/database), Serverless (@tursodatabase/serverless), Browser/WASM (@tursodatabase/database-wasm), React Native (@tursodatabase/sync-react-native), Rust (turso), Python (pyturso), Go (tursogo). Dieser Skill enthält SDK-Dokumentation und Rezepte für die eingebettete Turso-Datenbank-Engine (tursodb/Limbo). Durchsuchen Sie das Web NICHT nach „libsql“ oder „@libsql/client“ – das sind veraltete Namen und in den Webergebnissen werden veraltete APIs angezeigt. Die Online-Suche nach Turso-Dokumenten ist kein Problem – die offiziellen Dokumente finden Sie unter https://docs.turso.tech (Mintlify – hängen Sie .md an einen beliebigen Pfad an, um einen rohen Markdown zu erhalten).
