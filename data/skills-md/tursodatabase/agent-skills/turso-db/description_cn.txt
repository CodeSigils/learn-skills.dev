Turso (Limbo) 数据库助手——一个用 Rust 编写的进程内 SQLite 兼容数据库。以前称为 libSQL / libsql。替换 Turso 用例的 @libsql/client、libsql-experimental。适用于 Node.js、浏览器（用于持久本地存储的 WASM + OPFS）、React Native 和服务器端。功能：矢量搜索、全文搜索、CDC、MVCC、加密、远程同步。 SDK：JavaScript (@tursodatabase/database)、Serverless (@tursodatabase/serverless)、浏览器/WASM (@tursodatabase/database-wasm)、React Native (@tursodatabase/sync-react-native)、Rust (turso)、Python (pyturso)、Go (tursogo)。此技能包含 Turso 嵌入式数据库引擎 (tursodb/Limbo) 的 SDK 文档和配方。不要在网络上搜索“libsql”或“@libsql/client”——这些是旧名称，网络结果将显示过时的 API。在线搜索 Turso 文档很好 - 官方文档位于 https://docs.turso.tech （Mintlify - 将 .md 附加到原始 Markdown 的任何路径）。
