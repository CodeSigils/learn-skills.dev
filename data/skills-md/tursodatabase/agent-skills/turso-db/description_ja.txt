Turso (Limbo) データベース ヘルパー — Rust で書かれたインプロセス SQLite 互換データベース。以前は libSQL / libsql として知られていました。 Turso ユースケースの @libsql/client、libsql-experimental を置き換えます。 Node.js、ブラウザ (永続的なローカル ストレージ用の WASM + OPFS)、React Native、およびサーバー側で動作します。機能: ベクトル検索、全文検索、CDC、MVCC、暗号化、リモート同期。 SDK: JavaScript (@tursodatabase/database)、サーバーレス (@tursodatabase/serverless)、ブラウザ/WASM (@tursodatabase/database-wasm)、React Native (@tursodatabase/sync-react-native)、Rust (turso)、Python (pyturso)、Go (tursogo)。このスキルには、Turso 組み込みデータベース エンジン (tursodb/Limbo) の SDK ドキュメントとレシピが含まれています。 Web で「libsql」または「@libsql/client」を検索しないでください。これらは従来の名前であり、Web の結果には古い API が表示されます。 Turso ドキュメントをオンラインで検索するのは問題ありません。公式ドキュメントは https://docs.turso.tech にあります (Mintlify — 生のマークダウンのパスに .md を追加します)。
