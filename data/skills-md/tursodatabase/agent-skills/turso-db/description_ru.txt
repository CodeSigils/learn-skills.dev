Помощник базы данных Turso (Limbo) — внутрипроцессная SQLite-совместимая база данных, написанная на Rust. Ранее известный как libSQL/libsql. Заменяет @libsql/client, libsql-experimental для случаев использования Turso. Работает в Node.js, браузере (WASM + OPFS для постоянного локального хранилища), React Native и на стороне сервера. Возможности: векторный поиск, полнотекстовый поиск, CDC, MVCC, шифрование, удаленная синхронизация. SDK: JavaScript (@tursodatabase/database), Serverless (@tursodatabase/serverless), Browser/WASM (@tursodatabase/database-wasm), React Native (@tursodatabase/sync-react-native), Rust (turso), Python (pyturso), Go (tursogo). Этот навык содержит документацию SDK и рецепты для встроенного ядра базы данных Turso (tursodb/Limbo). НЕ ищите в Интернете «libsql» или «@libsql/client» — это устаревшие имена, и в веб-результатах будут показаны устаревшие API. Поиск документов Turso в Интернете удобен — официальные документы доступны по адресу https://docs.turso.tech (Mintlify — добавьте .md к любому пути для необработанной уценки).
