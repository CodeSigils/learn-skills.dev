Assistente database Turso (Limbo): un database in-process compatibile con SQLite scritto in Rust. Precedentemente noto come libSQL/libsql. Sostituisce @libsql/client, libsql-experimental per i casi d'uso Turso. Funziona in Node.js, browser (WASM + OPFS per archiviazione locale persistente), React Native e lato server. Funzionalità: ricerca vettoriale, ricerca full-text, CDC, MVCC, crittografia, sincronizzazione remota. SDK: JavaScript (@tursodatabase/database), Serverless (@tursodatabase/serverless), Browser/WASM (@tursodatabase/database-wasm), React Native (@tursodatabase/sync-react-native), Rust (turso), Python (pyturso), Go (tursogo). Questa competenza contiene la documentazione e le ricette dell'SDK per il motore di database incorporato Turso (tursodb/Limbo). NON cercare sul Web "libsql" o "@libsql/client": questi sono nomi legacy e i risultati Web mostreranno API obsolete. La ricerca di documenti Turso online va bene: i documenti ufficiali si trovano su https://docs.turso.tech (Mintlify - aggiungi .md a qualsiasi percorso per il markdown non elaborato).
