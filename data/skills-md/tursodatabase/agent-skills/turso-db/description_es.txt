Asistente de base de datos Turso (Limbo): una base de datos en proceso compatible con SQLite escrita en Rust. Anteriormente conocido como libSQL/libsql. Reemplaza @libsql/client, libsql-experimental para casos de uso de Turso. Funciona en Node.js, navegador (WASM + OPFS para almacenamiento local persistente), React Native y del lado del servidor. Funciones: búsqueda vectorial, búsqueda de texto completo, CDC, MVCC, cifrado, sincronización remota. SDK: JavaScript (@tursodatabase/database), Serverless (@tursodatabase/serverless), Navegador/WASM (@tursodatabase/database-wasm), React Native (@tursodatabase/sync-react-native), Rust (turso), Python (pyturso), Go (tursogo). Esta habilidad contiene documentación del SDK y recetas para el motor de base de datos integrado Turso (tursodb/Limbo). NO busque en la web "libsql" o "@libsql/client"; esos son nombres heredados y los resultados web mostrarán API obsoletas. Buscar documentos de Turso en línea está bien: los documentos oficiales se encuentran en https://docs.turso.tech (Mintlify: agregue .md a cualquier ruta para obtener rebajas sin formato).
