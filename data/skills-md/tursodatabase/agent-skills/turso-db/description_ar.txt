مساعد قاعدة بيانات Turso (Limbo) - قاعدة بيانات متوافقة مع SQLite قيد التشغيل ومكتوبة بلغة Rust. المعروف سابقًا باسم libSQL / libsql. يستبدل @libsql/client وlibsql-experimental لحالات استخدام Turso. يعمل في Node.js، والمتصفح (WASM + OPFS للتخزين المحلي المستمر)، وReact Native، ومن جانب الخادم. الميزات: البحث المتجه، البحث عن النص الكامل، CDC، MVCC، التشفير، المزامنة عن بعد. مجموعات SDK: JavaScript (@tursodatabase/database)، بدون خادم (@tursodatabase/serverless)، Browser/WASM (@tursodatabase/database-wasm)، React Native (@tursodatabase/sync-react-native)، Rust (turso)، Python (pyturso)، Go (tursogo). تحتوي هذه المهارة على وثائق SDK ووصفات لمحرك قاعدة البيانات المضمن Turso (tursodb/Limbo). لا تبحث في الويب عن "libsql" أو "@libsql/client" - فهي أسماء قديمة وستعرض نتائج الويب واجهات برمجة التطبيقات القديمة. يعد البحث عن مستندات Turso عبر الإنترنت أمرًا جيدًا - المستندات الرسمية موجودة على https://docs.turso.tech (Mintlify - قم بإلحاق .md بأي مسار لتخفيض السعر الخام).
