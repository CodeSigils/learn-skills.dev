Turso (Limbo) 資料庫助理－一個用 Rust 寫的行程內 SQLite 相容資料庫。以前稱為 libSQL / libsql。取代 Turso 用例的 @libsql/client、libsql-experimental。適用於 Node.js、瀏覽器（用於持久性本地儲存的 WASM + OPFS）、React Native 和伺服器端。功能：向量搜尋、全文搜尋、CDC、MVCC、加密、遠端同步。 SDK：JavaScript (@tursodatabase/database)、Serverless (@tursodatabase/serverless)、瀏覽器/WASM (@tursodatabase/database-wasm)、React Native (@tursodatabase/sync-react-native)、Rust (turso)、Python (pytursodatabase/sync-react-native)、Rust (turso)、Python (pyturturgo)、Gotursogo)。此技能包含 Turso 嵌入式資料庫引擎 (tursodb/Limbo) 的 SDK 文件和配方。不要在網路上搜尋「libsql」或「@libsql/client」——這些是舊名稱，網路結果將顯示過時的 API。在線搜索 Turso 文件很好 - 官方文檔位於 https://docs.turso.tech （Mintlify - 將 .md 附加到原始 Markdown 的任何路徑）。
