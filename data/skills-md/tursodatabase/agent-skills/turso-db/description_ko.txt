Turso(Limbo) 데이터베이스 도우미 — Rust로 작성된 처리 중인 SQLite 호환 데이터베이스입니다. 이전에는 libSQL/libsql로 알려졌습니다. Turso 사용 사례에 대해 @libsql/client, libsql-experimental을 대체합니다. Node.js, 브라우저(영구 로컬 저장소용 WASM + OPFS), React Native 및 서버 측에서 작동합니다. 기능: 벡터 검색, 전체 텍스트 검색, CDC, MVCC, 암호화, 원격 동기화. SDK: JavaScript(@tursodatabase/database), 서버리스(@tursodatabase/serverless), 브라우저/WASM(@tursodatabase/database-wasm), React Native(@tursodatabase/sync-react-native), Rust(turso), Python(pyturso), Go(tursogo). 이 스킬에는 Turso 내장 데이터베이스 엔진(tursodb/Limbo)에 대한 SDK 문서 및 레시피가 포함되어 있습니다. 웹에서 "libsql" 또는 "@libsql/client"를 검색하지 마십시오. 이는 레거시 이름이며 웹 결과에는 오래된 API가 표시됩니다. Turso 문서를 온라인으로 검색하는 것은 괜찮습니다. 공식 문서는 https://docs.turso.tech에 있습니다(Mintlify - 원시 마크다운을 위해 경로에 .md를 추가합니다).
