Assistant de base de données Turso (Limbo) – une base de données en cours compatible SQLite écrite en Rust. Anciennement connu sous le nom de libSQL/libsql. Remplace @libsql/client, libsql-experimental pour les cas d'utilisation de Turso. Fonctionne dans Node.js, navigateur (WASM + OPFS pour le stockage local persistant), React Native et côté serveur. Fonctionnalités : recherche vectorielle, recherche en texte intégral, CDC, MVCC, cryptage, synchronisation à distance. SDK : JavaScript (@tursodatabase/database), Serverless (@tursodatabase/serverless), Navigateur/WASM (@tursodatabase/database-wasm), React Native (@tursodatabase/sync-react-native), Rust (turso), Python (pyturso), Go (tursogo). Cette compétence contient de la documentation et des recettes SDK pour le moteur de base de données intégré Turso (tursodb/Limbo). Ne recherchez PAS sur le Web « libsql » ou « @libsql/client » : ce sont des noms hérités et les résultats Web afficheront des API obsolètes. La recherche de documents Turso en ligne est très bien – les documents officiels sont disponibles sur https://docs.turso.tech (Mintlify – ajoutez .md à n'importe quel chemin pour la démarque brute).
