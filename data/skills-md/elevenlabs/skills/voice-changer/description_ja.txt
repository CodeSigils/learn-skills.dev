Celebrities Voice Changer (音声合成) API を使用して、感情、タイミング、配信を維持しながら、オーディオ録音内の音声を別のターゲット音声に変換します。ある音声を別の音声に変換する場合、既存の録音のスピーカー/ナレーターを変更する場合、別の音声でナレーションをダビングする場合、スクラッチ パフォーマンスからキャラクター ボイスを作成する場合、スピーカーを匿名化する場合、または「音声変換 / 音声転送 / 音声合成」タスクを行う場合に使用します。ユーザーが音声変更、音声変換、音声合成、オーディオ内の音声の交換、クリップの再音声化、または既存の録音への別の音声の適用について言及するときは、たとえ「音声チェンジャー」と明示的に言わなくても、必ずこのスキルを使用してください。
