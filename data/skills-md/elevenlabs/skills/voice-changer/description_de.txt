Wandeln Sie die Stimme in einer Audioaufnahme mit der ElevenLabs Voice Changer-API (Speech-to-Speech) in eine andere Zielstimme um und bewahren Sie dabei Emotionen, Timing und Übermittlung. Verwenden Sie diese Funktion, wenn Sie eine Stimme in eine andere umwandeln, den Sprecher/Erzähler einer vorhandenen Aufnahme ändern, einen Voice-Over mit einer anderen Stimme synchronisieren, Charakterstimmen von Grund auf neu erstellen, einen Sprecher anonymisieren oder jede andere „Stimmenkonvertierung/Sprachübertragung/Sprache-zu-Sprache“-Aufgabe durchführen möchten. Stellen Sie sicher, dass Sie diese Fähigkeit immer dann verwenden, wenn der Benutzer von Stimmveränderung, Stimmumwandlung, Sprache-zu-Sprache, Austausch einer Stimme im Audio, Neuvertonung eines Clips oder dem Anwenden einer anderen Stimme auf eine vorhandene Aufnahme spricht – auch wenn er nicht ausdrücklich „Stimmenverwechsler“ sagt.
