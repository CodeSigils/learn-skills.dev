Перейдите на следующую основную версию @elevenlabs/client, @elevenlabs/react и @elevenlabs/react-native. Используйте при обновлении кода, который использует Conversation, Input, Output, useConversation, ElevenLabsProvider, ConversationProvider или связанные API из этих пакетов. Также срабатывает, когда пользователи упоминают об обновлении пакетов ElevenLabs, исправлении критических изменений после обновления npm, переходе на последнюю версию ElevenLabs SDK или обнаружении ошибок типа или ошибок времени выполнения после обновления зависимостей @elevenlabs/*.
