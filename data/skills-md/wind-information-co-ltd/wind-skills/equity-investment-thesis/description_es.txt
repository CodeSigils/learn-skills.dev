Se utiliza para una investigación en profundidad de la lógica de inversión central para acciones individuales, centrándose en la investigación de acciones, el análisis fundamental y la investigación institucional. Esta habilidad sirve principalmente para responder preguntas de los usuarios, redactar informes y redactar artículos financieros. El resultado del informe contiene una gran cantidad de contenido y no es adecuado para escenarios de diálogo simples. Se puede obtener diversa información y datos utilizando la herramienta wind.financial.data con palabras clave apropiadas o combinaciones de palabras clave. Después de que el usuario ingresa el nombre de una acción, desea obtener rápidamente un análisis de acciones de alta calidad que se asemeje mucho al estilo de un analista de corretaje.
