قم بتحويل التغييرات الفوضوية التي تم إنشاؤها بواسطة الذكاء الاصطناعي إلى سجل Git نظيف وآمن من خلال الالتزامات الذكية والفروع والفحوصات وعمليات السحب والدفع الآمنة والعلاقات العامة في GitHub وإنشاء مشكلات GitHub أو إصلاحاتها. يُستخدم عندما يطلب المستخدم gitx، أو التزام، أو فرع، أو عمليات فحص، أو سحب، أو دفع، أو طلب سحب أو علاقات عامة، أو مشكلة GitHub، أو لإنشاء مشكلة، أو لإصلاح مشكلة، أو تعارض دمج، أو حالة Git، أو خطة التزام.
