フル機能の SEO、GEO、および AEO Web サイト監査ツール。検索エンジン最適化 (SEO)、生成エンジン最適化 (GEO - Perplexity、ChatGPT 検索、Gemini などの AI 搭載検索エンジン用)、アンサー エンジン最適化 (AEO - 注目のスニペットや音声検索用) のために URL または Web サイトを分析します。ユーザーが URL、ドメイン、または Web サイトを提供し、検索パフォーマンス、SEO の問題、ランキング、AI 検索の準備状況、アンサー エンジンの可視性、メタ タグ、スキーマ マークアップ、コンテンツの品質、または検索での可視性について質問するときは常に、このスキルを使用します。また、ユーザーが「サイトを監査する」、「SEO をチェックする」、「なぜ私のサイトがランキングされないのか」、「AI 検索用に最適化する」、または Web プロパティと検索パフォーマンスに関連する同様のリクエストを要求したときにもトリガーされます。
