أداة تدقيق مواقع الويب SEO وGEO وAEO كاملة المواصفات. يحلل أي عنوان URL أو موقع ويب لتحسين محرك البحث (SEO)، وتحسين المحرك التوليدي (GEO - لمحركات البحث التي تعمل بالذكاء الاصطناعي مثل Perplexity، وChatGPT Search، وGemini)، وتحسين محرك الإجابة (AEO - للمقتطفات المميزة والبحث الصوتي). استخدم هذه المهارة عندما يقدم المستخدم عنوان URL أو مجالًا أو موقع ويب ويسأل عن أداء البحث، أو مشكلات تحسين محركات البحث، أو التصنيفات، أو جاهزية بحث الذكاء الاصطناعي، أو رؤية محرك الإجابات، أو العلامات الوصفية، أو ترميز المخطط، أو جودة المحتوى، أو الرؤية في البحث. يتم تشغيله أيضًا عندما يطلب المستخدم "تدقيق موقعي"، أو "التحقق من تحسين محركات البحث"، أو "لماذا لا يتم تصنيف موقعي"، أو "تحسين بحث الذكاء الاصطناعي"، أو أي طلب مماثل يتضمن موقع ويب وأداء البحث.
