Herramienta de auditoría de sitios web SEO, GEO y AEO con todas las funciones. Analiza cualquier URL o sitio web para optimización de motores de búsqueda (SEO), optimización de motores generativos (GEO, para motores de búsqueda con tecnología de inteligencia artificial como Perplexity, ChatGPT Search y Gemini) y optimización de motores de respuesta (AEO, para fragmentos destacados y búsqueda por voz). Utilice esta habilidad siempre que un usuario proporcione una URL, un dominio o un sitio web y pregunte sobre el rendimiento de la búsqueda, problemas de SEO, clasificaciones, preparación para la búsqueda de IA, visibilidad del motor de respuestas, metaetiquetas, marcado de esquema, calidad del contenido o visibilidad en la búsqueda. También se activa cuando el usuario solicita "auditar mi sitio", "verificar mi SEO", "por qué no está clasificado mi sitio", "optimizar para la búsqueda de IA" o cualquier solicitud similar que involucre una propiedad web y el rendimiento de la búsqueda.
