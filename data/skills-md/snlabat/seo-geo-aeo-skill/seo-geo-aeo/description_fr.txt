Outil d'audit de sites Web SEO, GEO et AEO complet. Analyse n'importe quelle URL ou site Web pour l'optimisation des moteurs de recherche (SEO), l'optimisation des moteurs génératifs (GEO — pour les moteurs de recherche basés sur l'IA comme Perplexity, ChatGPT Search et Gemini) et l'optimisation des moteurs de réponse (AEO — pour les extraits de code et la recherche vocale). Utilisez cette compétence chaque fois qu'un utilisateur fournit une URL, un domaine ou un site Web et pose des questions sur les performances de recherche, les problèmes de référencement, les classements, la préparation à la recherche par l'IA, la visibilité du moteur de réponse, les balises méta, le balisage de schéma, la qualité du contenu ou la visibilité dans la recherche. Se déclenche également lorsque l'utilisateur demande « auditer mon site », « vérifier mon référencement », « pourquoi mon site n'est-il pas classé », « optimiser pour la recherche IA » ou toute demande similaire impliquant une propriété Web et des performances de recherche.
