قم بتنفيذ نقطة تفتيش git بعد جولة التكرار، مع رسالة التزام مفيدة ذات جودة تدقيق تلخص ما تغير. رفيق اختياري لحلقة التكرار. يُستخدم عندما يقول المستخدم "ارتكب هذا التكرار"، أو "احفظ نقطة تفتيش"، أو "التزم git"، أو بعد حد تكرار ذي معنى (تجاوزت درجة التقييم الحد الأدنى، أو إغلاق الفجوة، أو إجراء تغيير هيكلي). تخطي إذا لم تتم تهيئة git في هذا المشروع.
