Validez un point de contrôle git après un cycle d'itération, avec un message de validation utile de qualité piste d'audit qui résume ce qui a changé. Compagnon facultatif de la boucle d’itération. À utiliser chaque fois que l'utilisateur dit « valider cette itération », « enregistrer un point de contrôle », « git commit » ou après une limite d'itération significative (le score de la rubrique a franchi un seuil, un écart comblé, un changement structurel effectué). Ignorer si git n'est pas initialisé sur ce projet.
