Effettua il commit di un checkpoint git dopo un ciclo di iterazione, con un utile messaggio di commit di qualità audit trail che riepiloga ciò che è cambiato. Compagno facoltativo al ciclo di iterazione. Da utilizzare ogni volta che l'utente dice "esegui il commit di questa iterazione", "salva un checkpoint", "git commit" o dopo un limite di iterazione significativo (il punteggio della rubrica ha superato una soglia, il gap è stato chiuso, è stata apportata una modifica strutturale). Salta se git non è inizializzato su questo progetto.
