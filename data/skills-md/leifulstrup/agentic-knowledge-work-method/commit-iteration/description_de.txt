Übertragen Sie nach einer Iterationsrunde einen Git-Checkpoint mit einer nützlichen Commit-Nachricht in Audit-Trail-Qualität, die zusammenfasst, was sich geändert hat. Optionaler Begleiter zur Iterationsschleife. Wird immer dann verwendet, wenn der Benutzer sagt: „Diese Iteration festschreiben“, „Prüfpunkt speichern“, „Git-Commit“ oder nachdem eine sinnvolle Iterationsgrenze erreicht wurde (Rubrikbewertung hat einen Schwellenwert überschritten, Lücke geschlossen, strukturelle Änderung vorgenommen). Überspringen, wenn Git in diesem Projekt nicht initialisiert ist.
