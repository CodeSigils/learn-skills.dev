Reduzieren Sie die RAM-Nutzung von Windows im Leerlauf, indem Sie Startprogramme und unnötige Hintergrunddienste prüfen und bereinigen. Verwenden Sie diese Option, wenn der Benutzer eine hohe Speicherauslastung hat, nichts geöffnet ist, die Leistung aufgrund von RAM-Auslastung langsam ist oder er wissen möchte, was seinen RAM verbraucht. Auslöser für: „Zu viel RAM verwendet“, „15 GB im Leerlauf verwendet“, „RAM immer voll“, „Was belegt meinen Speicher“, „Hintergrundprozesse reduzieren“, „Es werden zu viele Dinge ausgeführt“.
