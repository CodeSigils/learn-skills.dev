Überprüfen und bereinigen Sie Windows-Startprogramme, um die Startzeit zu verkürzen und den ungenutzten Arbeitsspeicher zu reduzieren. Verwenden Sie diese Option, wenn der Benutzer einen schnelleren Start wünscht, weniger Dinge beim Start geladen werden oder wissen möchte, was automatisch ausgeführt wird. Auslöser für: „Zu viele Startprogramme“, „langsamer Start“, „Zu viele Dinge werden beim Start geöffnet“, „Start-Apps deaktivieren“, „Was wird beim Start ausgeführt“, „Der Start meines PCs dauert ewig“.
