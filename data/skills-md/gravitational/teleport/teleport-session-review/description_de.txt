Überprüfen und untersuchen Sie Teleport-Sitzungsaufzeichnungen. Verwenden Sie diese Option, wenn der Benutzer aufgezeichnete Sitzungen überprüfen oder prüfen möchte, herausfinden möchte, was in einer Sitzung passiert ist, oder Sitzungen danach suchen möchte, was in ihnen passiert ist (z. B. „Sitzungen, die Produktionsdatenbanken berührt haben“, „Wer hat Sudo auf Produkt ausgeführt“). Deckt gängige Sicherheitsworkflows wie SOC-Risikotriage der riskantesten Sitzungen, regelmäßige Compliance-Überprüfungen des Produktionszugriffs, Bedrohungssuche nach Techniken (Berechtigungsausweitung, Persistenz, Datenexfiltration, SSH-Konfigurationsmanipulation, Offenlegung von Geheimnissen) und Vorfall-Reaktions-Pivots („Was hat dieser Benutzer auf diesem Host getan“) ab. Listet außerdem aktuelle SSH-/DB-/Kubernetes-/Desktop-Aufzeichnungen auf, fasst eine Sitzung zusammen und lädt sie herunter oder spielt sie ab. Lösen Sie auf Phrasen wie „Sitzungsaufzeichnungen überprüfen“, „Sitzungsaufzeichnungen durchsuchen“, „Was ist in Sitzung <ID> passiert“, „Risikositzungen finden“ oder jede Erwähnung von Teleport-Sitzungsaufzeichnungen oder Sitzungszusammenfassungen aus. Wird auch ausgelöst, wenn eine Sitzung von einem vorherigen Befehl aus fortgesetzt wird.
