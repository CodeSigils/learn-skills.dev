À utiliser pour le travail de liste d'accès Teleport avec tctl ; répertorier les ressources disponibles (serveurs, bases de données, applications, etc.) avant de choisir une cible d'octroi d'accès, de créer de nouvelles listes d'accès, de mettre à jour les listes existantes ou de supprimer/retirer des listes. Déclencheur de requêtes telles que « donner l'accès à Alice », « créer une liste d'accès », « accès permanent », « demande d'accès », « liste d'accès personnalisée », « afficher/lister les applications », « afficher les ensembles d'autorisations AWS IC », « ajouter AWS IC à cette liste », « modifier les propriétaires/membres/accès », « supprimer l'accès », « supprimer/retirer/démanteler une liste d'accès ». Gère les listes de types d'accès dans lesquelles Teleport crée des rôles de support, ainsi que les listes personnalisées qui accordent des rôles/traits existants.
