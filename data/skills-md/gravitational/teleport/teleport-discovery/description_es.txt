Configure y solucione problemas de detección automática de Teleport para instancias AWS EC2, clústeres de AWS EKS y máquinas virtuales de Azure a través del módulo Terraform de detección de Teleport. Úselo para configurar o ampliar el descubrimiento automático, agregar una región, etiqueta o suscripción, aplicar el descubrimiento Terraform, verificar el estado de inscripción o diagnosticar por qué los recursos de la nube no se están inscribiendo. No para GCP, AWS RDS o descubrimiento de bases de datos, inscripción estática o manual de tokens de unión ni configuración de Teleport no relacionada con el descubrimiento.
