Teleport discovery Terraform 모듈을 통해 AWS EC2 인스턴스, AWS EKS 클러스터 및 Azure VM에 대한 Teleport 자동 검색을 구성하고 문제를 해결합니다. 자동 검색을 설정 또는 확장하고, 지역, 태그 또는 구독을 추가하고, 검색 Terraform을 적용하고, 등록 상태를 확인하거나, 클라우드 리소스가 등록되지 않는 이유를 진단하는 데 사용합니다. GCP, AWS RDS 또는 데이터베이스 검색, 정적 또는 수동 조인 토큰 등록, 검색과 관련 없는 Teleport 구성에는 해당되지 않습니다.
