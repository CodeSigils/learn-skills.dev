قم بتكوين اكتشاف Teleport التلقائي واستكشاف الأخطاء فيه وإصلاحه لمثيلات AWS EC2 ومجموعات AWS EKS وAzure VMs عبر وحدة Terraform لاكتشاف Teleport. يُستخدم لإعداد الاكتشاف التلقائي أو توسيعه، أو إضافة منطقة أو علامة أو اشتراك، أو تطبيق Terraform الاكتشاف، أو التحقق من حالة التسجيل، أو تشخيص سبب عدم تسجيل الموارد السحابية. ليس مخصصًا لـ GCP أو AWS RDS أو اكتشاف قاعدة البيانات، أو تسجيل رمز الانضمام الثابت أو اليدوي، أو تكوين النقل الفوري غير المرتبط بالاكتشاف.
