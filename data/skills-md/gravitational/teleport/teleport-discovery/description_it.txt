Configura e risolvi i problemi di rilevamento automatico di Teleport per istanze AWS EC2, cluster AWS EKS e VM di Azure tramite il modulo Terraform di rilevamento Teleport. Da utilizzare per configurare o estendere il rilevamento automatico, aggiungere una regione, un tag o un abbonamento, applicare Terraform di rilevamento, controllare lo stato della registrazione o diagnosticare il motivo per cui le risorse cloud non vengono registrate. Non per GCP, AWS RDS o rilevamento di database, registrazione di token di join statici o manuali o configurazione di teletrasporto non correlata al rilevamento.
