Configurez et dépannez la découverte automatique Teleport pour les instances AWS EC2, les clusters AWS EKS et les machines virtuelles Azure via le module Terraform de découverte Teleport. Utilisez-le pour configurer ou étendre la découverte automatique, ajouter une région, une balise ou un abonnement, appliquer le Terraform de découverte, vérifier l'état d'inscription ou diagnostiquer pourquoi les ressources cloud ne s'inscrivent pas. Pas pour GCP, AWS RDS ou la découverte de bases de données, l'inscription statique ou manuelle de jetons de jointure, ou la configuration Teleport sans rapport avec la découverte.
