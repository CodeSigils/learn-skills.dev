Agentic MCP – Dreischichtige progressive Offenlegung für MCP-Server mit Socket-Daemon. Verwenden Sie diese Option, wenn der Benutzer mit MCP-Servern interagieren, verfügbare Tools abfragen, MCP-Tools aufrufen oder den MCP-Daemon-Prozess verwalten muss. Bietet Socket-basierte Kommunikation für eine effiziente Serverinteraktion mit der dreischichtigen Progressive Disclosure API.
