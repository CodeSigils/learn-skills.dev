Agentic MCP - Divulgation progressive à trois couches pour les serveurs MCP avec démon Socket. À utiliser lorsque l'utilisateur doit interagir avec les serveurs MCP, interroger les outils disponibles, appeler les outils MCP ou gérer le processus démon MCP. Fournit une communication basée sur socket pour une interaction efficace avec le serveur avec une API de divulgation progressive à trois couches.
