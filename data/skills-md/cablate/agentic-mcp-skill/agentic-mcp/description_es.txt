Agentic MCP: divulgación progresiva de tres capas para servidores MCP con demonio Socket. Úselo cuando el usuario necesite interactuar con servidores MCP, consultar herramientas disponibles, llamar a herramientas MCP o administrar el proceso del demonio MCP. Proporciona comunicación basada en sockets para una interacción eficiente con el servidor con una API de divulgación progresiva de tres capas.
