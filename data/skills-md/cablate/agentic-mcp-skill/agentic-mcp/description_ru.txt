Agentic MCP — трехуровневое прогрессивное раскрытие для серверов MCP с демоном Socket. Используйте, когда пользователю необходимо взаимодействовать с серверами MCP, запрашивать доступные инструменты, вызывать инструменты MCP или управлять процессом демона MCP. Обеспечивает связь на основе сокетов для эффективного взаимодействия с сервером с помощью трехуровневого API постепенного раскрытия.
