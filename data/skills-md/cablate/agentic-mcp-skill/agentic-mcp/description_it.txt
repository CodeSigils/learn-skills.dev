Agentic MCP: divulgazione progressiva a tre livelli per server MCP con demone Socket. Da utilizzare quando l'utente deve interagire con i server MCP, interrogare gli strumenti disponibili, chiamare gli strumenti MCP o gestire il processo del daemon MCP. Fornisce comunicazioni basate su socket per un'interazione efficiente del server con API di divulgazione progressiva a tre livelli.
