Agentic MCP - كشف تقدمي ثلاثي الطبقات لخوادم MCP المزودة ببرنامج المقبس الخفي. يُستخدم عندما يحتاج المستخدم إلى التفاعل مع خوادم MCP، أو الاستعلام عن الأدوات المتاحة، أو الاتصال بأدوات MCP، أو إدارة عملية البرنامج الخفي لـ MCP. يوفر اتصالاً قائمًا على مأخذ التوصيل للتفاعل الفعال مع الخادم مع واجهة برمجة تطبيقات الكشف التدريجي ثلاثية الطبقات.
