إمكانات الاستعلام الجغرافي المكاني - الترميز الجغرافي والبحث القريب والتوجيه وتفاصيل المكان والارتفاع. يتم تشغيله عندما يذكر المستخدم المواقع، أو العناوين، أو الإحداثيات، أو التنقل، أو "الأماكن القريبة"، أو "كيفية الوصول إلى هناك"، أو المسافة/المدة، أو أي سؤال يتضمن معلومات جغرافية بطبيعتها - حتى لو لم يذكر "خريطة" صراحةً. قم بالتحديث عند إضافة أدوات جديدة أو تغيير معلمات الأداة.
