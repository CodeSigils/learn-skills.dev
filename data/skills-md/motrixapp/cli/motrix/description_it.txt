Da utilizzare quando è necessario gestire un gestore di download Motrix dalla riga di comando: elenca/esamina i download, aggiungi download (URL, magnet o torrent), sospendi/riprendi/rimuovi attività, guarda i progressi in tempo reale o leggi statistiche aggregate. Funziona con un Motrix desktop locale (rilevamento automatico) o un server remoto/headless (tramite `--endpoint` + un token accoppiato).
