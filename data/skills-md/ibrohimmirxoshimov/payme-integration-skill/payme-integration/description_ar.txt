تكامل بوابة الدفع Payme Business لأوزبكستان. استخدم هذه المهارة عندما يذكر المستخدم Payme، أو Paycom، أو paycom.uz، أو تكامل الدفع لأوزبكستان، أو مدفوعات بطاقة Uzcard/HUMO، أو واجهة Merchant API، أو واجهة برمجة التطبيقات الخاصة بالاشتراك، أو Payme checkout، أو الإيصالات.إنشاء، أو Cards.create، أو CheckPerformTransaction، أو CreateTransaction، أو PerformanceTransaction، أو CancelTransaction، أو أي معالجة دفع للسوق الأوزبكية. يتم تشغيله أيضًا عندما يسأل المستخدم عن دمج مدفوعات البطاقة في أوزبكستان، أو إنشاء نماذج الدفع، أو التعامل مع المعاملات باستخدام JSON-RPC 2.0 للمدفوعات، أو تنفيذ خادم الفوترة لـ Payme. يغطي كلاً من Merchant API (من خادم إلى خادم، يرسل Payme الطلبات إلى التاجر) وSubscribe API (يرسل التاجر الطلبات إلى Payme، وترميز البطاقة، والمدفوعات بنقرة واحدة، والفواتير). يتضمن تهيئة الدفع (نماذج الخروج)، واختبار وضع الحماية، والتمويل المالي، وتعليق الدفعات، وتكامل SDK للأجهزة المحمولة، ومعالجة الأخطاء.
