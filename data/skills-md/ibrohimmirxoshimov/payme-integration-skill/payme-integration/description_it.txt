Integrazione del gateway di pagamento Payme Business per l'Uzbekistan. Utilizza questa abilità ogni volta che l'utente menziona Payme, Paycom, paycom.uz, integrazione dei pagamenti per l'Uzbekistan, pagamenti con carta Uzcard/HUMO, API commerciante, API di sottoscrizione, checkout Payme, ricevute.create, carte.create, CheckPerformTransaction, CreateTransaction, PerformTransaction, CancelTransaction o qualsiasi elaborazione di pagamento per il mercato uzbeko. Si attiva anche quando l'utente chiede informazioni sull'integrazione dei pagamenti con carta in Uzbekistan, sulla creazione di moduli di pagamento, sulla gestione delle transazioni con JSON-RPC 2.0 per i pagamenti o sull'implementazione di un server di fatturazione per Payme. Copre sia l'API del commerciante (server-server, Payme invia richieste al commerciante) sia l'API di iscrizione (il commerciante invia richieste a Payme, tokenizzazione della carta, pagamenti con un clic, fatture). Include l'inizializzazione dei pagamenti (moduli di pagamento), test sandbox, fiscalizzazione, sospensione dei pagamenti, integrazione dell'SDK mobile e gestione degli errori.
