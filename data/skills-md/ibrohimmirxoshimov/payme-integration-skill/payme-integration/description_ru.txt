Интеграция платежного шлюза Payme Business для Узбекистана. Используйте этот навык всякий раз, когда пользователь упоминает Payme, Paycom, paycom.uz, интеграцию платежей для Узбекистана, платежи по картам Uzcard/HUMO, Merchant API, Subscribe API, проверку Payme, квитанции.create, card.create, CheckPerformTransaction, CreateTransaction, PerformTransaction, CancelTransaction или любую обработку платежей для рынка Узбекистана. Также срабатывает, когда пользователь спрашивает об интеграции карточных платежей в Узбекистане, создании платежных форм, обработке транзакций с помощью JSON-RPC 2.0 для платежей или внедрении биллингового сервера для Payme. Охватывает как Merchant API (между серверами, Payme отправляет запросы продавцу), так и Subscribe API (продавец отправляет запросы в Payme, токенизацию карт, платежи в один клик, счета). Включает инициализацию платежей (формы оформления заказа), тестирование в песочнице, фискализацию, удержание платежей, интеграцию мобильного SDK и обработку ошибок.
