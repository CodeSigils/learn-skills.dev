Integración de la pasarela de pagos Payme Business para Uzbekistán. Utilice esta habilidad siempre que el usuario mencione Payme, Paycom, paycom.uz, integración de pagos para Uzbekistán, pagos con tarjeta Uzcard/HUMO, API de comerciante, API de suscripción, pago de Payme, recibos.create, cards.create, CheckPerformTransaction, CreateTransaction, PerformTransaction, CancelTransaction o cualquier procesamiento de pagos para el mercado uzbeko. También se activa cuando el usuario pregunta sobre la integración de pagos con tarjeta en Uzbekistán, la creación de formularios de pago, el manejo de transacciones con JSON-RPC 2.0 para pagos o la implementación de un servidor de facturación para Payme. Cubre tanto la API de comerciante (servidor a servidor, Payme envía solicitudes al comerciante) como la API de suscripción (el comerciante envía solicitudes a Payme, tokenización de tarjetas, pagos con un solo clic, facturas). Incluye inicialización de pagos (formularios de pago), pruebas de espacio aislado, fiscalización, retención de pagos, integración de SDK móvil y manejo de errores.
