ウズベキスタン向けの Payme Business 支払いゲートウェイの統合。ユーザーが Payme、Paycom、paycom.uz、ウズベキスタンの支払い統合、Uzcard/HUMO カード支払い、Merchant API、Subscribe API、Payme checkout、receiptes.create、cards.create、CheckPerformTransaction、CreateTransaction、PerformTransaction、CancelTransaction、またはウズベキスタン市場の支払い処理に言及するたびにこのスキルを使用します。また、ウズベキスタンでのカード支払いの統合、支払いフォームの構築、支払いのための JSON-RPC 2.0 によるトランザクションの処理、または Payme の請求サーバーの実装についてユーザーが尋ねたときにもトリガーされます。 Merchant API (サーバー間、Payme が販売者にリクエストを送信) と Subscribe API (販売者が Payme にリクエストを送信、カードトークン化、ワンクリック支払い、請求書) の両方をカバーします。支払いの初期化 (チェックアウト フォーム)、サンドボックス テスト、会計処理、支払いの保留、モバイル SDK の統合、エラー処理が含まれます。
