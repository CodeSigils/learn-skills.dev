Интерактивная викторина на уровне урока по учебникам Claude Code. Проверяет понимание конкретного урока (01–10) с помощью 8–10 вопросов, сочетающих концептуальные и практические знания. Используйте перед уроком для предварительного тестирования, во время урока для проверки прогресса или после урока для проверки мастерства. Используйте, когда вас просят «проверить меня на крючках», «проверить мои знания по уроку 3», «викторину по уроку», «попрактиковаться в викторине для MCP» или «понимаю ли я навыки».
