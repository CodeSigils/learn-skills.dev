Prueba interactiva a nivel de lección para los tutoriales de Claude Code. Evalúa la comprensión de una lección específica (01-10) con 8-10 preguntas que combinan conocimientos conceptuales y prácticos. Úselo antes de una lección para realizar una prueba previa, durante para verificar el progreso o después para verificar el dominio. Úselo cuando se le solicite "preguntarme sobre los ganchos", "probar mis conocimientos de la lección 3", "examen de lección", "examen de práctica para MCP" o "entiendo las habilidades".
