قم بتنظيف قاعدة التعليمات البرمجية عن طريق إزالة انحدار الذكاء الاصطناعي، والتعليمات البرمجية الميتة، والأنواع الضعيفة، والازدواجية، والهندسة الدفاعية الزائدة، والمهارة القديمة باستخدام 8 وكلاء فرعيين متخصصين متوازيين عبر موجتي تنظيف. لا تستخدم لإضافة ميزات جديدة، أو ضبط الأداء، أو عمليات التدقيق للأمان فقط.
