Pulisci una base di codice rimuovendo problemi di intelligenza artificiale, codice morto, tipi deboli, duplicazione, ingegneria eccessiva difensiva e errori legacy utilizzando 8 agenti secondari specializzati paralleli in due ondate di pulizia. Non utilizzare per l'aggiunta di nuove funzionalità, l'ottimizzazione delle prestazioni o controlli esclusivamente di sicurezza.
