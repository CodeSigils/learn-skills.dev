AI-Agent-Commit-Protokoll, das eine Shadscan-Basislinie erstellt und die Prüfung unmittelbar vor jedem vom Agenten erstellten Commit erneut ausführt, ohne Abhängigkeiten zu installieren oder Git zu konfigurieren. Wird verwendet, wenn ein Agent aufgefordert wird, Arbeit in einem React-Shadcn-Projekt festzuschreiben, UI-Regressionen während einer Agentenaufgabe zu verhindern oder Shadscan vor Festschreibungen auszuführen.
