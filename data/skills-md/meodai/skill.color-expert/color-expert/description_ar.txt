يُستخدم عند العمل باستخدام تسمية الألوان، أو نظرية الألوان، أو مساحات الألوان، أو تعريفات الألوان، أو أي مهمة تتضمن معرفة الألوان - اللوحات، أو المنحدرات، أو التدرجات، أو التحويلات، أو إمكانية الوصول، أو المطابقة الإدراكية، أو خلط الأصباغ، أو ألوان الطباعة مقابل الشاشة، أو تركيب ألوان CSS، أو مصطلحات الألوان التاريخية. استخدم هذه المهارة عندما يقوم المستخدم باختيار الألوان أو مقارنتها أو توليدها أو تسميتها أو تحويلها أو شرحها، حتى لو لم يطلب صراحةً "نظرية الألوان".
