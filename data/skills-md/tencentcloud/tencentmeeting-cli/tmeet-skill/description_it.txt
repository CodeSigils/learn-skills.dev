Tencent Meeting CLI (tmeet): query di accesso/disconnessione/stato OAuth, gestione delle riunioni (crea/aggiorna/annulla/query/invitati), gestione delle registrazioni (elenco/URL di download/riepilogo intelligente/trascrizione), report delle riunioni (partecipanti/sala d'attesa). Utilizza questa abilità quando gli utenti devono utilizzare Tencent Meeting tramite la riga di comando.
