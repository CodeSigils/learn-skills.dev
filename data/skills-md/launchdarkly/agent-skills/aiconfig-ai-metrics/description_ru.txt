Инструментируйте существующую кодовую базу с помощью отслеживания LaunchDarkly AI Config. Проходит четырехуровневую лестницу (управляемый бегун → пакет поставщика → пользовательский экстрактор + trackMetricsOf → необработанное руководство) и выбирает вариант с самой низкой церемонией, который по-прежнему фиксирует продолжительность, токены и успех/ошибку.
