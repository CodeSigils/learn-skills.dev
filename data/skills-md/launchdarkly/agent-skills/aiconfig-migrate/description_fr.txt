Migrez une application avec des invites LLM codées en dur vers une implémentation complète de LaunchDarkly AI Configs en cinq étapes : auditer le code, envelopper l'appel, déplacer les outils, ajouter un suivi, attacher des évaluateurs. À utiliser lorsque l'utilisateur souhaite externaliser la configuration du modèle/de l'invite, passer des appels directs du fournisseur (OpenAI, Anthropic, Bedrock, Gemini, Strands) à une configuration AI gérée, ou organiser une migration complète codée en dur vers LaunchDarkly.
