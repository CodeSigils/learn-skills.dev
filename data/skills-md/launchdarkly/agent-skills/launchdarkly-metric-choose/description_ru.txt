Выберите правильные метрики для эксперимента LaunchDarkly, защищенного развертывания или политики выпуска. Используйте, когда пользователь хочет знать, какие метрики использовать, какая метрика является основной для эксперимента, какие ограничения добавить или какие события отслеживать при развертывании. Определяет, что будет автоматически присоединено из существующих политик выпуска, прежде чем давать дополнительные рекомендации.
