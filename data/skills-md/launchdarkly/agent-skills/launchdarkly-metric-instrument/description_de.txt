Instrumentieren Sie ein LaunchDarkly-Metrikereignis in einer Codebasis, indem Sie einen track()-Aufruf hinzufügen. Verwenden Sie diese Option, wenn der Benutzer ein Ereignis verknüpfen, eine Aktion für eine Metrik instrumentieren, Tracking zu einer Funktion hinzufügen oder bestätigen möchte, dass ein Ereignis an LaunchDarkly übermittelt wird.
