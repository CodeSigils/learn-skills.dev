Erstellen Sie eine LaunchDarkly-Metrik, die misst, was für ein Experiment oder eine Einführung wichtig ist. Verwenden Sie diese Option, wenn der Benutzer eine Metrik erstellen, ein Ereignis verfolgen, Seitenaufrufe, Schaltflächenklicks, Konvertierung, Latenz, Fehlerrate oder ein beliebiges benutzerdefiniertes numerisches oder binäres Ergebnis messen möchte. Instrumentiert das Ereignis zunächst bei Bedarf (einschließlich SDK-Setup und .env) und erstellt und überprüft dann die Metrik.
