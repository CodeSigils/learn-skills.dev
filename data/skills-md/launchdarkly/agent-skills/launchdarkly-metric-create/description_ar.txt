قم بإنشاء مقياس LaunchDarkly الذي يقيس ما يهم بالنسبة للتجربة أو الطرح. يُستخدم عندما يريد المستخدم إنشاء مقياس، أو تتبع حدث، أو قياس مشاهدات الصفحة، أو نقرات الأزرار، أو التحويل، أو زمن الاستجابة، أو معدل الخطأ، أو أي نتيجة رقمية أو ثنائية مخصصة. قياس الحدث أولاً عند الحاجة (بما في ذلك إعداد SDK و.env)، ثم إنشاء المقياس والتحقق منه.
