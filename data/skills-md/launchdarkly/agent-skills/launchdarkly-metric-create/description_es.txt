Cree una métrica de LaunchDarkly que mida lo que importa para un experimento o implementación. Úselo cuando el usuario desee crear una métrica, realizar un seguimiento de un evento, medir las visitas a la página, los clics en los botones, la conversión, la latencia, la tasa de error o cualquier resultado numérico o binario personalizado. Instrumenta el evento primero cuando es necesario (incluida la configuración del SDK y .env), luego crea y verifica la métrica.
