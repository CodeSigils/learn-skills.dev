Créez une métrique LaunchDarkly qui mesure ce qui compte pour une expérience ou un déploiement. À utiliser lorsque l'utilisateur souhaite créer une métrique, suivre un événement, mesurer les pages vues, les clics sur les boutons, la conversion, la latence, le taux d'erreur ou tout résultat numérique ou binaire personnalisé. Instrumente d'abord l'événement lorsque cela est nécessaire (y compris la configuration du SDK et .env), puis crée et vérifie la métrique.
