Wird beim Schreiben von Antworten auf Koreanisch verwendet. Entwurf → Kritik → abschließender 2-Durchgang zur Eliminierung von Translationese (wörtliche englische Übersetzung, abstrakte Substantivsubjekte, Passiv im englischen Stil, 1:1-Wortzuordnung). Rufen Sie immer auf, wenn der Benutzer eine Frage auf Koreanisch stellt oder ausdrücklich eine koreanische Antwort anfordert.
