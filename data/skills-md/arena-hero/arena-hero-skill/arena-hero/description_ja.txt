Arena Hero の Python 戦術を作成、テスト、実行したり、API を通じて直接プレイしたり、そのルール、プロトコル、状態、コマンド、イベント、エラー、Python SDK について説明したりできます。エージェントがアリーナ ヒーロー戦術の構築または改善、ユニットまたはコアの制御、ライブ ゲームへの接続、クライアントまたはフロントエンドの構築、ライブ ターンの検査、計画の提出、公式 SDK の使用、またはプレーヤーがエージェントのプレイを観察するのを支援するように求められた場合に使用します。完全なバンドルされたゲームプレイ、HTTP、WebSocket、OpenAPI、AsyncAPI、Python SDK ドキュメントが含まれています。
