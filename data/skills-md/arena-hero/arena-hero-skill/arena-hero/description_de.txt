Erstellen, testen und führen Sie Python-Taktiken für Arena Hero aus, spielen Sie direkt über die API oder erklären Sie die Regeln, das Protokoll, den Status, die Befehle, Ereignisse, Fehler und das Python SDK. Wird verwendet, wenn ein Agent gebeten wird, eine Arena-Heldentaktik zu entwickeln oder zu verbessern, Einheiten oder einen Kern zu steuern, eine Verbindung zum Live-Spiel herzustellen, einen Client oder ein Frontend zu erstellen, Live-Runden zu inspizieren, Pläne einzureichen, das offizielle SDK zu verwenden oder einem Spieler dabei zu helfen, dem Agenten beim Spielen zuzusehen. Enthält das komplette gebündelte Gameplay, HTTP, WebSocket, OpenAPI, AsyncAPI und Python SDK-Dokumentation.
