Обработка запросов на изменение черновиков электронных писем InboxMate. Считывает черновики с ожидающими запросами на изменения из API службы уведомлений, применяет запрошенные изменения к HTML-коду электронной почты и обновляет черновики. Запускаться после добавления запросов на изменения через пользовательский интерфейс администратора.
