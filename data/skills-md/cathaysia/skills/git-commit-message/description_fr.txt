Rédigez ou créez des messages de commit git à l'aide de commits conventionnels dans un style compatible avec les commitizens. À utiliser lorsque l'utilisateur demande un message de validation, souhaite obtenir de l'aide pour choisir un type ou une portée de validation, ou souhaite que le codex valide les modifications avec une formulation en minuscules et des pieds de page BREAKING CHANGES au lieu d'un raccourci.
