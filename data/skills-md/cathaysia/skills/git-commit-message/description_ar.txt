قم بصياغة أو إنشاء رسائل التزام git باستخدام الالتزامات التقليدية بأسلوب متوافق مع الالتزام. يتم استخدامه عندما يطلب المستخدم رسالة التزام، أو يريد مساعدة في اختيار نوع الالتزام أو النطاق، أو يريد أن ينفذ المخطوطة تغييرات باستخدام صياغة بالأحرف الصغيرة أولاً وتذييلات "تغيير التغييرات" بدلاً من الاختصار المفاجئ.
