Entwerfen oder erstellen Sie Git-Commit-Nachrichten mit herkömmlichen Commits in einem Commitizen-kompatiblen Stil. Verwenden Sie diese Option, wenn der Benutzer nach einer Commit-Nachricht fragt, Hilfe bei der Auswahl eines Commit-Typs oder -Bereichs benötigt oder möchte, dass der Codex Änderungen mit Kleinbuchstaben zuerst und BREAKING CHANGES-Fußzeilen anstelle von Knallkürzeln festschreibt.
