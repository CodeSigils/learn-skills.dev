Ayude al usuario a pasar de cero a un prototipo de evaluación de MLflow enviado comprendiendo su aplicación, generalizando un pequeño conjunto de criterios de calidad atómica e implementando cada criterio con el evaluador confiable más barato. Úselo cuando el usuario necesite ayuda para elegir, crear o iterar jueces/puntuadores de MLflow para un agente, una aplicación RAG, una aplicación LLM o un flujo de trabajo GenAI.
