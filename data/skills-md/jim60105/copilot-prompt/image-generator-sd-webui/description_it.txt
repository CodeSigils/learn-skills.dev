Genera immagini tramite Stable Diffusion WebUI/Forge HTTP API (`/sdapi/v1/*` compatibile con AUTOMATIC1111). Da utilizzare quando l'utente desidera (1) scoprire o scegliere un modello/modulo extra (TE/VAE)/campionatore/schedulatore/preimpostazione di stile da un server sd-webui in esecuzione, (2) generare un'immagine con un determinato prompt (txt2img), (3) controllare l'avanzamento della generazione, (4) annullare/interrompere una generazione in corso, (5) ispezionare o modificare un'opzione sd-webui globale (ad esempio checkpoint attivo) o (6) testare la connettività. Questa abilità comunica con un server *generico* compatibile con sd-webui (AUTOMATIC1111, Forge, reForge, sd-webui-forge-classic). NON eseguire l'attivazione per richieste che stanno semplicemente scrivendo il prompt stesso.
