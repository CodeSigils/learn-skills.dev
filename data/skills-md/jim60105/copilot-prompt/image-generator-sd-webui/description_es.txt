Genere imágenes a través de Stable Diffusion WebUI / Forge HTTP API (compatible con AUTOMATIC1111 `/sdapi/v1/*`). Úselo cuando el usuario desee (1) descubrir o elegir un modelo/módulo adicional (TE/VAE)/muestra/programador/estilo preestablecido de un servidor sd-webui en ejecución, (2) generar una imagen con un mensaje determinado (txt2img), (3) verificar el progreso de la generación, (4) cancelar/interrumpir una generación en vuelo, (5) inspeccionar o cambiar una opción global de sd-webui (por ejemplo, punto de control activo) o (6) probar la conectividad. Esta habilidad se comunica con un servidor *genérico* compatible con sd-webui (AUTOMATIC1111, Forge, reForge, sd-webui-forge-classic). NO active solicitudes que simplemente escriban el mensaje en sí.
