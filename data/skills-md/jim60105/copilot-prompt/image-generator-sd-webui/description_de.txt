Generieren Sie Bilder über die Stable Diffusion WebUI/Forge HTTP API (AUTOMATIC1111-kompatibel „/sdapi/v1/*“). Verwenden Sie diese Option, wenn der Benutzer (1) ein Modell/Extramodul (TE/VAE)/Sampler/Scheduler/Stilvoreinstellung von einem laufenden SD-Webui-Server entdecken oder auswählen möchte, (2) ein Bild mit einer bestimmten Eingabeaufforderung (txt2img) generieren, (3) den Generierungsfortschritt überprüfen, (4) eine Generierung während des Flugs abbrechen/unterbrechen, (5) eine globale SD-Webui-Option (z. B. einen aktiven Prüfpunkt) überprüfen oder ändern möchte oder (6) die Konnektivität testen möchte. Dieser Skill kommuniziert mit einem *generischen* sd-webui-kompatiblen Server (AUTOMATIC1111, Forge, reForge, sd-webui-forge-classic). Lösen Sie NICHT für Anfragen aus, bei denen es sich lediglich um das Schreiben der Eingabeaufforderung selbst handelt.
