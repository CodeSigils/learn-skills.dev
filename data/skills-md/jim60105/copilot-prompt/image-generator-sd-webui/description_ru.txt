Создавайте изображения с помощью Stable Diffusion WebUI/Forge HTTP API (AUTOMATIC1111-совместимый `/sdapi/v1/*`). Используйте, когда пользователь хочет (1) обнаружить или выбрать модель/дополнительный модуль (TE/VAE)/сэмплер/планировщик/предустановку стиля с работающего сервера sd-webui, (2) сгенерировать изображение с заданным приглашением (txt2img), (3) проверить ход генерации, (4) отменить/прервать генерацию в реальном времени, (5) проверить или изменить глобальную опцию sd-webui (например, активную контрольную точку) или (6) проверить подключение. Этот навык взаимодействует с *универсальным* сервером, совместимым с sd-webui (AUTOMATIC1111, Forge, reForge, sd-webui-forge-classic). НЕ запускайте запросы, которые просто пишут само приглашение.
