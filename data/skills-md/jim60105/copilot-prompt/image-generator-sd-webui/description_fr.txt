Générez des images via l'API HTTP Stable Diffusion WebUI / Forge (compatible AUTOMATIC1111 `/sdapi/v1/*`). À utiliser lorsque l'utilisateur souhaite (1) découvrir ou choisir un modèle / module supplémentaire (TE/VAE) / échantillonneur / planificateur / style prédéfini à partir d'un serveur sd-webui en cours d'exécution, (2) générer une image avec une invite donnée (txt2img), (3) vérifier la progression de la génération, (4) annuler/interrompre une génération en vol, (5) inspecter ou modifier une option globale sd-webui (par exemple, point de contrôle actif) ou (6) tester la connectivité. Cette compétence communique avec un serveur *générique* compatible sd-webui (AUTOMATIC1111, Forge, reForge, sd-webui-forge-classic). Ne déclenchez PAS les requêtes qui écrivent uniquement l'invite elle-même.
