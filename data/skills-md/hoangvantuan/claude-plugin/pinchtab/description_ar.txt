أتمتة المتصفح لوكلاء الذكاء الاصطناعي عبر PinchTab HTTP API وCLI. استخدمه عندما يريد المستخدم التحكم في المتصفح، أو التنقل في مواقع الويب، أو استخراج محتوى الصفحة، أو ملء النماذج، أو النقر فوق العناصر، أو استخراج البيانات، أو أتمتة سير عمل الويب، أو التقاط لقطات الشاشة، أو تصدير ملفات PDF، أو تشغيل JavaScript على الصفحات، أو إدارة ملفات تعريف الارتباط، أو القيام بأي شيء يتضمن تصفح الويب. يتم تشغيله أيضًا عندما يذكر المستخدم "pinchtab"، أو "أتمتة المتصفح"، أو "فتح موقع الويب"، أو "مسح الصفحة"، أو "ملء النموذج"، أو "زر النقر"، أو "الحصول على نص الصفحة"، أو "أتمتة الويب"، أو "متصفح بدون رأس"، أو "تجريد الويب"، أو "لقطة شاشة للصفحة"، أو "تنزيل ملف من الويب"، أو أي مهمة تتطلب التفاعل مع صفحات الويب.
