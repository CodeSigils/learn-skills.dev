Автоматизация браузера для агентов искусственного интеллекта через HTTP API и CLI PinchTab. Используйте всякий раз, когда пользователь хочет управлять браузером, перемещаться по веб-сайтам, извлекать содержимое страниц, заполнять формы, щелкать элементы, очищать данные, автоматизировать рабочие процессы в Интернете, делать снимки экрана, экспортировать PDF-файлы, запускать JavaScript на страницах, управлять файлами cookie или делать что-либо, связанное с просмотром веб-страниц. Также срабатывает, когда пользователь упоминает «pinchtab», «автоматизацию браузера», «открыть веб-сайт», «очистить страницу», «заполнить форму», «нажать кнопку», «получить текст страницы», «веб-автоматизацию», «безголовый браузер», «очистку веб-страниц», «скриншот страницы», «загрузить файл из Интернета» или любую задачу, требующую взаимодействия с веб-страницами.
