PinchTab HTTP API および CLI を介した AI エージェントのブラウザ自動化。ユーザーがブラウザの制御、Web サイトの移動、ページ コンテンツの抽出、フォームへの入力、要素のクリック、データの収集、Web ワークフローの自動化、スクリーンショットの取得、PDF のエクスポート、ページでの JavaScript の実行、Cookie の管理、または Web ブラウジングに関連するあらゆる操作を行う場合に使用します。また、ユーザーが「ピンチタブ」、「ブラウザ オートメーション」、「Web サイトを開く」、「ページをスクレイピング」、「フォームに入力」、「ボタンをクリック」、「ページ テキストの取得」、「Web オートメーション」、「ヘッドレス ブラウザ」、「Web スクレイピング」、「ページのスクリーンショット」、「Web からファイルをダウンロード」、または Web ページとの対話を必要とするタスクに言及したときにもトリガーされます。
