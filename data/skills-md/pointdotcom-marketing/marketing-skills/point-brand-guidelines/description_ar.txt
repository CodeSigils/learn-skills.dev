قم بتطبيق ومراجعة نظام العلامة التجارية المرئية الرسمي لشركة Point فيما يتعلق بالشعارات والطباعة والألوان والأعمال الفنية والتصوير الفوتوغرافي وتخطيطات المقارنة. يُستخدم عند إنشاء أو تحرير أو تدقيق صفحات الويب أو الإعلانات أو المجموعات أو المستندات أو الأصول الاجتماعية أو الرسوم التوضيحية أو توجيه الصور أو أنظمة التصميم أو CSS أو مكونات واجهة المستخدم التي تحمل علامة Point التجارية حيث يكون الامتثال للعلامة التجارية المرئية مهمًا.
