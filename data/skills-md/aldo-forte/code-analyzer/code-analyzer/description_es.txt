Analiza en profundidad cualquier archivo fuente o fragmento de código. Utilice esta habilidad cuando el usuario quiera comprender qué hace un fragmento de código, quiera una explicación de funciones/clases, quiera saber qué bibliotecas se utilizan y qué hacen, o quiera verificar la corrección del código mediante una búsqueda en línea. También se activa cuando el usuario dice "explica este código", "analiza este archivo", "qué hace esta función", "qué bibliotecas utiliza", "es correcto este código".
