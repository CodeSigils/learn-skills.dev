Глубоко анализирует любой исходный файл или фрагмент кода. Используйте этот навык, когда пользователь хочет понять, что делает фрагмент кода, хочет получить объяснение функций/классов, хочет знать, какие библиотеки используются и что они делают, или хочет проверить правильность кода с помощью поиска в Интернете. Также активируйте, когда пользователь говорит «объясните этот код», «проанализируйте этот файл», «что делает эта функция», «какие библиотеки она использует», «правильный ли этот код».
