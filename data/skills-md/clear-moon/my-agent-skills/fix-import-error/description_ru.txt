Решите проблемы с импортом модуля корневого каталога проекта Python. Активируйте этот навык, когда пользователи сталкиваются с ModuleNotFoundError, им необходимо настроить редактируемый режим установки или вы хотите настроить pip install -e .

Триггерные сценарии:
- Пользователь сообщает ModuleNotFoundError или ImportError.
- Пользователь спрашивает: «Как сделать импортируемым корневой каталог проекта».
- Пользователь хочет настроить pip install -e . (редактируемый режим установки)
- Пользователь спрашивает: «Как настроить пакеты в pyproject.toml».

Примечание. Этот навык фокусируется на проблемах импорта, вызванных структурой проекта, а также на отсутствии сторонних пакетов.
