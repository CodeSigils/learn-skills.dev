Lösen Sie Probleme beim Importieren von Python-Projektstammverzeichnismodulen. Lösen Sie diesen Skill aus, wenn Benutzer auf ModuleNotFoundError stoßen, den bearbeitbaren Installationsmodus konfigurieren müssen oder pip install -e einrichten möchten.

Auslöseszenarien:
– Der Benutzer meldet ModuleNotFoundError oder ImportError
- Benutzer fragt: „Wie mache ich das Stammverzeichnis des Projekts importierbar?“
– Der Benutzer möchte pip install -e konfigurieren. (bearbeitbarer Installationsmodus)
– Benutzer fragt „wie man Pakete in pyproject.toml konfiguriert“

Hinweis: Dieser Skill konzentriert sich auf Importprobleme, die durch die Projektstruktur verursacht werden, und nicht auf fehlende Pakete von Drittanbietern.
