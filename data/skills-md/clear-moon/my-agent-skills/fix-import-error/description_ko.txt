Python 프로젝트 루트 디렉터리 모듈 가져오기 문제를 해결합니다. 사용자가 ModuleNotFoundError를 경험하거나 편집 가능한 설치 모드를 구성해야 하거나 pip install -e를 설정하려는 경우 이 기술을 트리거합니다.

트리거 시나리오:
- 사용자가 ModuleNotFoundError 또는 ImportError를 보고합니다.
- 사용자가 "프로젝트 루트 디렉터리를 가져올 수 있게 만드는 방법"을 묻습니다.
- 사용자가 pip install -e 를 구성하려고 합니다. (편집 가능한 설치 모드)
- 사용자가 "pyproject.toml에서 패키지를 구성하는 방법"을 묻습니다.

참고: 이 기술은 타사 패키지가 누락되지 않고 프로젝트 구조로 인해 발생하는 가져오기 문제에 중점을 둡니다.
