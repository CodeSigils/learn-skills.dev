حل مشكلات استيراد وحدة الدليل الجذر لمشروع Python. قم بتشغيل هذه المهارة عندما يواجه المستخدمون ModuleNotFoundError، أو يحتاجون إلى تكوين وضع التثبيت القابل للتحرير، أو يريدون إعداد pip install -e .

سيناريوهات الزناد:
- تقارير المستخدم ModuleNotFoundError أو ImportError
- يسأل المستخدم "كيفية جعل الدليل الجذر للمشروع قابلاً للاستيراد"
- يريد المستخدم تكوين pip install -e . (وضع التثبيت القابل للتحرير)
- يسأل المستخدم "كيفية تكوين الحزم في pyproject.toml"

ملحوظة: تركز هذه المهارة على مشكلات الاستيراد الناتجة عن بنية المشروع، وليس فقدان حزم الطرف الثالث.
