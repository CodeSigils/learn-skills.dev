Interacción precisa con el escritorio para Windows con automatización de la interfaz de usuario, captura de pantalla, coincidencia de imágenes, control, verificación y recuperación del teclado y el mouse. Úselo cuando Codex u OpenClaw necesiten operar aplicaciones de escritorio como un humano, lo que incluye iniciar aplicaciones, enfocar ventanas, hacer clic en controles, escribir en campos, validar resultados, inspeccionar el árbol de la interfaz de usuario o recuperarse de estados visuales ambiguos. Prefiera esta habilidad cuando las coordenadas sin procesar por sí solas serían frágiles y utilice su respaldo de análisis de imágenes de Clawbot cuando la interfaz de usuario sea visualmente compleja o esté poco expuesta a las API de accesibilidad.
