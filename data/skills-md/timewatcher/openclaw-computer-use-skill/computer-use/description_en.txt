Accurate desktop interaction for Windows with UI Automation, screen capture, image matching, keyboard and mouse control, verification, and recovery. Use when Codex or OpenClaw needs to operate desktop applications like a human, including launching apps, focusing windows, clicking controls, typing into fields, validating results, inspecting the UI tree, or recovering from ambiguous visual states. Prefer this skill when raw coordinates alone would be fragile, and use its Clawbot image-analysis fallback when the UI is visually complex or poorly exposed to accessibility APIs.
