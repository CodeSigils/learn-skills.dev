Interazione desktop accurata per Windows con automazione dell'interfaccia utente, acquisizione dello schermo, corrispondenza delle immagini, controllo di tastiera e mouse, verifica e ripristino. Da utilizzare quando Codex o OpenClaw devono gestire applicazioni desktop come un essere umano, ad esempio avviare app, mettere a fuoco finestre, fare clic su controlli, digitare nei campi, convalidare risultati, ispezionare la struttura dell'interfaccia utente o ripristinare stati visivi ambigui. Preferisci questa abilità quando le sole coordinate grezze sarebbero fragili e usa il fallback di analisi delle immagini di Clawbot quando l'interfaccia utente è visivamente complessa o scarsamente esposta alle API di accessibilità.
