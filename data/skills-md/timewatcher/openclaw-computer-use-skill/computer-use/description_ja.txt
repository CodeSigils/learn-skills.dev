UI オートメーション、画面キャプチャ、画像マッチング、キーボードとマウスの制御、検証、回復を備えた Windows の正確なデスクトップ インタラクション。 Codex または OpenClaw が、アプリの起動、ウィンドウのフォーカス、コントロールのクリック、フィールドへの入力、結果の検証、UI ツリーの検査、またはあいまいな表示状態からの回復など、デスクトップ アプリケーションを人間のように操作する必要がある場合に使用します。生の座標だけでは脆弱な場合はこのスキルを優先し、UI が視覚的に複雑であるか、アクセシビリティ API への公開が不十分な場合は Clawbot 画像分析フォールバックを使用します。
