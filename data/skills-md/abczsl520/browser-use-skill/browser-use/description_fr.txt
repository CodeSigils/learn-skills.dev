Utilisez l'utilisation du navigateur pour une automatisation Web complexe (connexion en plusieurs étapes, remplissage de formulaires, publication, récupération de données). Lorsque l'outil de navigateur intégré (instantané → acte) ne peut pas le gérer, utilisez-le : il s'agit d'un agent d'IA de navigateur dédié qui termine de manière autonome l'ensemble du flux de travail lorsque vous lui confiez une tâche. Mots déclencheurs : utilisation du navigateur, automatisation du Web, connexion automatique, remplissage automatique des formulaires, publication automatique, manipulation du Web, opérations Web complexes.
