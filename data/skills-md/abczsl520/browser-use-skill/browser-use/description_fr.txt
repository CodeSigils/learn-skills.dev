Utilisez l'utilisation du navigateur pour une automatisation Web complexe (connexion en plusieurs étapes, remplissage de formulaires, publication, récupération de données). Utilisez-le lorsque l'outil de navigateur intégré (instantané → acte) ne peut pas gérer le travail : il s'agit d'un agent d'IA de navigateur dédié qui exécute de manière autonome l'ensemble du flux de travail à partir d'une seule tâche. Mots déclencheurs : utilisation du navigateur, automatisation du navigateur, connexion automatique, remplissage automatique de formulaires, publication automatique, contrôle Web, opérations Web complexes.
