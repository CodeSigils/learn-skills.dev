Utilice el uso del navegador para la automatización web compleja (inicio de sesión de varios pasos, llenado de formularios, publicación, extracción de datos). Cuando la herramienta integrada del navegador (instantánea→actuar) no pueda manejarla, úsela: es un agente de IA del navegador dedicado que completa de forma autónoma todo el flujo de trabajo cuando le asigna una tarea. Palabras desencadenantes: uso del navegador, automatización web, inicio de sesión automático, llenado automático de formularios, publicación automática, manipulación web, operaciones web complejas.
