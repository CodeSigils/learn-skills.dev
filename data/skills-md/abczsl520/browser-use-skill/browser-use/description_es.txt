Utilice el uso del navegador para la automatización web compleja (inicio de sesión de varios pasos, llenado de formularios, publicación, extracción de datos). Úselo cuando la herramienta de navegador incorporada (instantánea → actuar) no pueda realizar el trabajo: es un agente de inteligencia artificial del navegador dedicado que completa de forma autónoma todo el flujo de trabajo desde una sola tarea. Palabras desencadenantes: uso del navegador, automatización del navegador, inicio de sesión automático, llenado automático de formularios, publicación automática, control web, operaciones web complejas.
