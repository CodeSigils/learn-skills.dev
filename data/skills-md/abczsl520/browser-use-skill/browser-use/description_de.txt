Verwenden Sie Browser-Use für komplexe Web-Automatisierung (mehrstufige Anmeldung, Ausfüllen von Formularen, Posten, Daten-Scraping). Verwenden Sie es, wenn das integrierte Browser-Tool (Snapshot→Act) die Aufgabe nicht bewältigen kann – es handelt sich um einen dedizierten Browser-KI-Agenten, der den gesamten Workflow autonom mit einer einzigen Aufgabe abschließt. Auslöserwörter: Browsernutzung, Browserautomatisierung, automatische Anmeldung, automatisches Ausfüllen von Formularen, automatische Veröffentlichung, Websteuerung, komplexe Webvorgänge.
