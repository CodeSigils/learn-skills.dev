Utilizza l'utilizzo del browser per l'automazione web complessa (accesso in più passaggi, compilazione di moduli, pubblicazione, scraping di dati). Quando lo strumento browser integrato (istantanea→azione) non è in grado di gestirlo, usa questo: è un agente AI del browser dedicato che completa autonomamente l'intero flusso di lavoro quando gli assegni un'attività. Parole chiave: uso del browser, automazione web, accesso automatico, compilazione automatica di moduli, pubblicazione automatica, manipolazione web, operazioni web complesse.
