Utilizza l'utilizzo del browser per l'automazione web complessa (accesso in più passaggi, compilazione di moduli, pubblicazione, scraping di dati). Usalo quando lo strumento browser integrato (istantanea→azione) non è in grado di gestire il lavoro: è un agente AI del browser dedicato che completa autonomamente l'intero flusso di lavoro da una singola attività. Parole chiave: utilizzo del browser, automazione del browser, accesso automatico, compilazione automatica dei moduli, pubblicazione automatica, controllo web, operazioni web complesse.
