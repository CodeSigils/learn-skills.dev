フルスタックの Frappe Framework アプリケーションをエンドツーエンドで構築します。 DocType の作成または変更、コントローラーまたはライフサイクル フックの作成、ホワイトリストに登録された API の追加、新しい Frappe アプリまたはベンチ サイトのセットアップ、デスク フォームまたはリスト ビューの構築、ポータル ページの作成、バックグラウンド ジョブまたはスケジュールされたタスクの作成、アクセス許可またはロールの管理、Frappe テストの作成、または frappe.db / frappe.qb の操作についてユーザーが言及するときはいつでも、このスキルを使用してください。また、ユーザーが「保存にフックする方法」、「DocType にフィールドを追加する」、「Frappe で REST エンドポイントを作成する」、「ベンチ移行を実行する」、または「サイトにアプリをインストールする」などのことを言った場合にも適用されます。これは、ユーザーが明示的に「Frappe」と言わなくてもです。
