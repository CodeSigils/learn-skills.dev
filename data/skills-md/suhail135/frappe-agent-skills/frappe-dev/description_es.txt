Crea aplicaciones Frappe Framework de pila completa de un extremo a otro. Utilice esta habilidad cada vez que el usuario mencione: crear o modificar un DocType, escribir un controlador o un enlace de ciclo de vida, agregar una API incluida en la lista blanca, configurar una nueva aplicación Frappe o un sitio de banco, crear un formulario de escritorio o una vista de lista, crear páginas de portal, escribir trabajos en segundo plano o tareas programadas, administrar permisos o roles, escribir pruebas de Frappe o trabajar con frappe.db/frappe.qb. También se aplica cuando el usuario dice cosas como "cómo puedo conectarme para guardar", "agregar un campo a un DocType", "crear un punto final REST en Frappe", "ejecutar migración de banco" o "instalar una aplicación en un sitio", incluso si no dicen explícitamente "Frappe".
