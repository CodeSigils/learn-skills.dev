One-on-one interactive learning system based on Benjamin Bloom’s 2 Sigma problem theory. Adaptive teaching—determine mastery level from the student’s answers, automatically advance or supplement, never skipping material that hasn’t been mastered. Supports student profiles, post‑lesson discussions, and course‑completion assessment.

Trigger phrases: “Open interactive learning system”, “Open interactive learning”, “Interactive learning”, “I want to learn X”, “Continue learning X”, “Continue learning”, “Finished learning X”.
Do not undertrigger—if the user says they want to learn something, continue the class, or open the learning system, this skill must be invoked.
When the user says “continue” but the context is unclear, first check whether a `.learning-config.json` file exists in the current working directory; if it does, trigger this skill.
