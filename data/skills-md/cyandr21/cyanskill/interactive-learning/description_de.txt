Interaktives Eins-zu-eins-Lernsystem basierend auf der 2-Sigma-Problemtheorie von Benjamin Bloom. Adaptives Unterrichten – Bestimmen Sie das Lernniveau anhand der Antworten des Schülers, führen Sie automatisch Fortschritte oder Ergänzungen durch und überspringen Sie niemals Material, das Sie nicht beherrschen. Supports student profiles, post‑lesson discussions, and course‑completion assessment.

Auslösersätze: „Interaktives Lernsystem öffnen“, „Interaktives Lernen öffnen“, „Interaktives Lernen“, „Ich möchte X lernen“, „Lernen Sie weiter X“, „Lernen Sie weiter“, „Lernen X abgeschlossen“.
Nicht untertriggern – wenn der Benutzer sagt, dass er etwas lernen, den Kurs fortsetzen oder das Lernsystem öffnen möchte, muss diese Fähigkeit aufgerufen werden.
Wenn der Benutzer „Weiter“ sagt, der Kontext jedoch unklar ist, prüfen Sie zunächst, ob im aktuellen Arbeitsverzeichnis eine Datei „.learning-config.json“ vorhanden ist. Wenn dies der Fall ist, lösen Sie diese Fertigkeit aus.
