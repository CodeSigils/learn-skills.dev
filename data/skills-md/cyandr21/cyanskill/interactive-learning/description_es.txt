Sistema de aprendizaje interactivo uno a uno basado en la teoría de problemas 2 Sigma de Benjamin Bloom. Enseñanza adaptativa: determine el nivel de dominio a partir de las respuestas del estudiante, avance o complemente automáticamente, sin omitir nunca material que no se haya dominado. Admite perfiles de estudiantes, debates posteriores a las lecciones y evaluación de finalización de cursos.

Frases desencadenantes: “Sistema de aprendizaje interactivo abierto”, “Aprendizaje interactivo abierto”, “Aprendizaje interactivo”, “Quiero aprender X”, “Continuar aprendiendo X”, “Continuar aprendiendo”, “Terminado de aprender X”.
No lo subestimes: si el usuario dice que quiere aprender algo, continuar la clase o abrir el sistema de aprendizaje, se debe invocar esta habilidad.
Cuando el usuario dice "continuar" pero el contexto no está claro, primero verifique si existe un archivo `.learning-config.json` en el directorio de trabajo actual; si es así, activa esta habilidad.
