Un sistema de aprendizaje interactivo uno a uno basado en la teoría del problema 2 Sigma de Benjamin Bloom. Enseñanza adaptativa: evaluar el nivel de dominio a partir de las respuestas de los estudiantes, avanzar o complementar automáticamente, sin omitir nunca material que no se haya dominado. Admite perfiles de estudiantes, debates posteriores a las lecciones y evaluación de finalización de cursos.

Frases desencadenantes: "Sistema de aprendizaje interactivo abierto", "Aprendizaje interactivo abierto", "Aprendizaje interactivo", "Quiero aprender X", "Continuar aprendiendo X", "Continuar aprendiendo", "Terminé de aprender X". No subestimules: cuando el usuario dice que quiere aprender algo, continuar una clase o abrir el sistema de aprendizaje, se debe invocar esta habilidad. Cuando el usuario dice "continuar" pero el contexto no está claro, primero verifique si el directorio de trabajo actual contiene `.learning-config.json`; si existe, activa esta habilidad.
