التعامل مع الملفات والبيانات الثنائية في n8n بشكل صحيح. يُستخدم عند العمل مع الملفات أو الصور أو ملفات PDF أو المرفقات أو التحميلات أو التنزيلات أو base64 أو الرؤية/الإدخال متعدد الوسائط، أو عندما يحتاج وكيل الذكاء الاصطناعي إلى ملف كأداة إدخال أو إخراج - وعندما يذكر المستخدم $binary، أو BinaryPropertyName، أو "قراءة ملف PDF"، أو "إرفاق الملف"، أو "إرسال الصورة"، أو دمج الملفات الثنائية المفقودة، أو CDN لصور الدردشة. يغطي تقسيم $binary مقابل $json، وقراءة/كتابة الملف الثنائي، والحفاظ على الثنائي حيًا عبر التحويلات باستخدام Merge، والحدود الثنائية لأداة الوكيل، ومتطلبات CDN/URL لأسطح الدردشة.
