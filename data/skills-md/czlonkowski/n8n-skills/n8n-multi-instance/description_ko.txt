n8n-mcp 계정이 두 개 이상의 n8n 인스턴스를 대상으로 하는 경우에 사용합니다. 즉, `n8n_instances` 도구를 사용할 수 있고, 사용자가 여러 n8n 인스턴스 또는 환경(프로덕션 대 스테이징, 여러 팀 또는 클라이언트)을 언급하거나, 워크플로/데이터 테이블/자격 증명/실행 호출이 예기치 않은 NOT_FOUND를 반환하거나 인식할 수 없는 데이터를 읽거나, 자격 증명 생성/업데이트/삭제가 거부되는 경우에 사용합니다. 'INSTANCE_AMBIGUOUS' 오류입니다. 이 MCP 세션의 대상 인스턴스 선택 및 전환, 높은 위험 작업(무엇보다 자격 증명 쓰기) 전에 대상 확인, 잘못된 경로 및 모호한 쓰기 페일클로즈 복구 등을 다룹니다. 특정 인스턴스에서 작업하기 전, 다중 인스턴스 계정에서 자격 증명 생성/업데이트/삭제 전, 호출에서 잘못된/빈 데이터 또는 'INSTANCE_AMBIGUOUS' 오류가 발생하는 경우 항상 이 기술을 참조하세요.
