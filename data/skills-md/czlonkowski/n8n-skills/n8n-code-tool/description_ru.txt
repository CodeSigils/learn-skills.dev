Напишите JavaScript или Python для инструмента пользовательского кода n8n (@n8n/n8n-nodes-langchain.toolCode) — инструмента, вызываемого AI-агентом, а НЕ узла кода рабочего процесса. Используйте при создании инструмента кода, подключенного к агенту AI, написании кода, который будет вызывать LLM, анализе входных данных запроса, возврате строкового результата, определении входной схемы для структурированных аргументов (specifyInputSchema, jsonSchemaExample, DynamicStructuredTool) или устранении ошибок, таких как «возвращен неправильный тип вывода», «нет доступных данных выполнения», «свойство ответа должно быть строкой, но это объект», «невозможно назначить свойство только для чтения». «имя»» или агент ИИ, который отказывается вызывать инструмент. Охватывает критические различия между узлом кода и инструментом кода: формат возвращаемого значения (строка и `[{json:{...}}]`), недоступность `$fromAI`/`$input`/`$helpers` в песочнице инструмента кода, правила именования для вызова AI и когда вместо этого использовать `toolWorkflow`/HTTP Request Tool.
