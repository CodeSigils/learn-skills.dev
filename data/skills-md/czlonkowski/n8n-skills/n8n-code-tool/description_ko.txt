n8n 사용자 정의 코드 도구(@n8n/n8n-nodes-langchain.toolCode)용 JavaScript 또는 Python을 작성합니다. 워크플로 코드 노드가 아닌 AI 에이전트 호출 가능 도구입니다. AI 에이전트에 연결된 코드 도구를 빌드할 때, LLM이 호출할 코드 작성, `query` 입력 구문 분석, 문자열 결과 반환, 구조화된 인수에 대한 입력 스키마 정의(specifyInputSchema, jsonSchemaExample, DynamicStructuredTool) 또는 "잘못된 출력 유형이 반환됨", "사용 가능한 실행 데이터 없음", "응답 속성은 문자열이어야 하지만 객체입니다.", "읽기 전용 속성에 할당할 수 없습니다"와 같은 오류 문제 해결 시 사용합니다. '이름'' 또는 도구 호출을 거부하는 AI 에이전트. 코드 노드와 코드 도구 간의 중요한 차이점을 다룹니다. 반환 형식(문자열 대 `[{json:{...}}]`), 코드 도구 샌드박스에서 `$fromAI`/`$input`/`$helpers`를 사용할 수 없음, AI 호출에 대한 명명 규칙, 대신 `toolWorkflow`/HTTP 요청 도구를 사용하는 경우.
