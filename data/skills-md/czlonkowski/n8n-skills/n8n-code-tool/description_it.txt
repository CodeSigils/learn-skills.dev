Scrivi JavaScript o Python per lo strumento di codice personalizzato n8n (@n8n/n8n-nodes-langchain.toolCode) — lo strumento richiamabile dall'agente AI, NON il nodo Codice del flusso di lavoro. Da utilizzare durante la creazione di uno strumento di codice collegato a un agente AI, la scrittura del codice che verrà richiamato da un LLM, l'analisi dell'input "query", la restituzione di un risultato di stringa, la definizione di uno schema di input per argomenti strutturati (specifyInputSchema, jsonSchemaExample, DynamicStructuredTool) o la risoluzione di errori come "Tipo di output restituito errato", "Nessun dato di esecuzione disponibile", "La proprietà della risposta deve essere una stringa, ma è un oggetto", "Impossibile assegnare la proprietà di sola lettura" 'nome'", o un agente AI che rifiuta di chiamare lo strumento. Copre le differenze critiche tra il nodo Codice e lo strumento Codice: formato restituito (stringa anziché `[{json:{...}}]`), indisponibilità di `$fromAI`/`$input`/`$helpers` nella sandbox dello strumento codice, regole di denominazione per l'invocazione dell'intelligenza artificiale e quando utilizzare invece `toolWorkflow`/strumento di richiesta HTTP.
