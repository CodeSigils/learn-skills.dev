Schreiben Sie JavaScript oder Python für das n8n Custom Code Tool (@n8n/n8n-nodes-langchain.toolCode) – das vom KI-Agent aufrufbare Tool, NICHT den Workflow-Code-Knoten. Wird verwendet, wenn Sie ein an einen KI-Agenten angehängtes Code-Tool erstellen, Code schreiben, den ein LLM aufruft, die „Abfrage“-Eingabe analysieren, ein Zeichenfolgenergebnis zurückgeben, ein Eingabeschema für strukturierte Argumente definieren (specifyInputSchema, jsonSchemaExample, DynamicStructuredTool) oder Fehler beheben wie „Falscher Ausgabetyp zurückgegeben“, „Keine Ausführungsdaten verfügbar“, „Die Antworteigenschaft sollte eine Zeichenfolge sein, ist aber ein Objekt“, „Zuweisung zur schreibgeschützten Eigenschaft nicht möglich“. „Name“ oder ein KI-Agent, der sich weigert, das Tool aufzurufen. Behandelt die entscheidenden Unterschiede zwischen Code-Knoten und Code-Tool: Rückgabeformat (Zeichenfolge vs. „[{json:{...}}]“, Nichtverfügbarkeit von „$fromAI“/„$input“/„$helpers“ in der Code-Tool-Sandbox, Benennungsregeln für den AI-Aufruf und wann stattdessen „toolWorkflow“/HTTP-Request-Tool verwendet werden sollte.
