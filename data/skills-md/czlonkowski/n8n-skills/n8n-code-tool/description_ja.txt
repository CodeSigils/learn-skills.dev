n8n カスタム コード ツール (@n8n/n8n-nodes-langchain.toolCode) 用の JavaScript または Python を作成します。これは、ワークフロー コード ノードではなく、AI エージェントから呼び出し可能なツールです。 AI エージェントにアタッチされたコード ツールを構築する場合、LLM が呼び出すコードを作成する場合、「クエリ」入力を解析する場合、文字列結果を返す場合、構造化引数 (specifyInputSchema、jsonSchemaExample、DynamicStructuredTool) の入力スキーマを定義する場合、または「間違った出力タイプが返されました」、「利用可能な実行データがありません」、「応答プロパティは文字列である必要がありますが、オブジェクトです」などのエラーのトラブルシューティングを行う場合に使用します。 「読み取り専用プロパティ 'name' に割り当てることはできません」、または AI エージェントがツールの呼び出しを拒否する。コード ノードとコード ツールの重要な違いについて説明します。戻り形式 (文字列と `[{json:{...}}]`)、コード ツール サンドボックスでの `$fromAI`/`$input`/`$helpers` の利用不可、AI 呼び出しの命名規則、代わりに `toolWorkflow`/HTTP リクエスト ツールを使用する場合について説明します。
