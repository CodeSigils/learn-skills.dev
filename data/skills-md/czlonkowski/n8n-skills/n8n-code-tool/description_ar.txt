اكتب JavaScript أو Python لأداة n8n Custom Code Tool (@n8n/n8n-nodes-langchain.toolCode) - أداة قابلة للاستدعاء لوكيل الذكاء الاصطناعي، وليست عقدة التعليمات البرمجية لسير العمل. تُستخدم عند إنشاء أداة تعليمات برمجية مرفقة بعامل الذكاء الاصطناعي، أو كتابة التعليمات البرمجية التي ستستدعيها LLM، أو تحليل إدخال "الاستعلام"، أو إرجاع نتيجة سلسلة، أو تحديد مخطط إدخال للوسيطات المنظمة (specifyInputSchema، أو jsonSchemaExample، أو DynamicStructuredTool)، أو استكشاف الأخطاء وإصلاحها مثل "تم إرجاع نوع إخراج خاطئ"، "لا تتوفر بيانات تنفيذ"، "يجب أن تكون خاصية الاستجابة عبارة عن سلسلة، ولكنها كائن"، "لا يمكن التعيين إلى" قراءة الخاصية "اسم" فقط"، أو وكيل الذكاء الاصطناعي الذي يرفض استدعاء الأداة. يغطي الاختلافات الهامة بين عقدة Code وأداة Code: تنسيق الإرجاع (سلسلة مقابل `[{json:{...}}]`)، وعدم توفر `$fromAI`/`$input`/`$helpers` في صندوق حماية أداة Code، وقواعد التسمية لاستدعاء AI، ومتى يتم استخدام `toolWorkflow`/HTTP Request Tool بدلاً من ذلك.
