Комплексное развертывание производственного автономного сервера n8n на новой виртуальной машине Linux через SSH с помощью Docker Compose за обратным прокси-сервером Caddy с автоматическим HTTPS. Используйте всякий раз, когда пользователь хочет самостоятельно разместить, установить, настроить, предоставить или развернуть n8n на своем собственном сервере/VPS/коробке (Hetzner, DigitalOcean, AWS EC2, «голое железо» и т. д.) — в одиночном/обычном режиме или режиме очереди с рабочими — или для обновления, резервного копирования, восстановления или усиления защиты такого экземпляра. Это для САМОХОСТИНГА n8n (Docker), а не для n8n Cloud и не для создания рабочих процессов. Этот навык заставляет агента сначала запрашивать одиночную очередь, собирать входные данные о домене/SSH/часовом поясе, генерировать новые секреты в ящике и собирать стек с помощью TLS. Триггер по «развертыванию n8n», «самостоятельному хостингу n8n», «установке n8n на моем сервере», «созданию докера n8n», «режиму очереди n8n/работникам/масштабированию», «обратному прокси-серверу n8n/SSL» или «резервному копированию/обновлению моего n8n».
