Implemente un n8n autohospedado de producción de extremo a extremo en una máquina virtual Linux nueva a través de SSH, utilizando Docker Compose detrás de un proxy inverso Caddy con HTTPS automático. Úselo siempre que el usuario desee autohospedar, instalar, configurar, aprovisionar o implementar n8n en su propio servidor/VPS/box (Hetzner, DigitalOcean, AWS EC2, bare metal, etc.), ya sea en modo único/regular o en modo de cola con trabajadores, o para actualizar, realizar copias de seguridad, restaurar o reforzar dicha instancia. Esto es para n8n AUTOHOSTED (Docker), no para n8n Cloud y no para crear flujos de trabajo. La habilidad hace que el agente pregunte primero en cola única versus cola, recopile las entradas de dominio/SSH/zona horaria, genere nuevos secretos en la caja y actualice la pila con TLS.
