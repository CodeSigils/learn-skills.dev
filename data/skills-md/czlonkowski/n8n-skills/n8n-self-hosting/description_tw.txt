使用帶有自動 HTTPS 的 Caddy 反向代理後面的 Docker Compose，透過 SSH 將生產自託管 n8n 端到端部署到新的 Linux VM。每當使用者想要在自己的伺服器/VPS/盒子（Hetzner、DigitalOcean、AWS EC2、裸機等）上自行託管、安裝、設定、設定或部署 n8n 時使用 - 無論是在單一/常規模式或與工作執行緒的佇列模式下 - 或更新、備份、還原或強化此類執行個體。這是針對自架的 n8n (Docker)，而不是 n8n 雲，也不是建置工作流程。此技能使代理人首先詢問 single-vs-queue，收集域/SSH/時區輸入，在盒子上產生新的機密，並使用 TLS 啟動堆疊。觸發「部署 n8n」、「自架 n8n」、「在我的伺服器上安裝 n8n」、「n8n docker compose」、「n8n 佇列模式/workers/縮放」、「n8n 反向代理/SSL」或「備份/更新我的 n8n」。
