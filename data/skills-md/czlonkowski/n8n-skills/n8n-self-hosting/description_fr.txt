À utiliser chaque fois que l'utilisateur souhaite auto-héberger, installer, configurer, provisionner ou déployer n8n sur son propre serveur/VPS/box (Hetzner, DigitalOcean, AWS EC2, bare metal, etc.) — en mode simple/régulier ou en mode file d'attente avec des travailleurs — ou pour mettre à jour, sauvegarder, restaurer ou renforcer une telle instance. Ceci est pour n8n AUTO-HÉBERGÉ (Docker), pas n8n Cloud et ne crée pas de flux de travail. La compétence permet à l'agent de demander d'abord une file d'attente unique, de collecter les entrées de domaine/SSH/fuseau horaire, de générer de nouveaux secrets sur la boîte et d'amener la pile avec TLS.
