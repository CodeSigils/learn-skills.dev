Stellen Sie ein selbstgehostetes n8n in der Produktion End-to-End auf einer neuen Linux-VM über SSH bereit, indem Sie Docker Compose hinter einem Caddy-Reverse-Proxy mit automatischem HTTPS verwenden. Verwenden Sie es immer dann, wenn der Benutzer n8n auf seinem eigenen Server/VPS/Box (Hetzner, DigitalOcean, AWS EC2, Bare Metal usw.) selbst hosten, installieren, einrichten, bereitstellen oder bereitstellen möchte – entweder im Einzel-/regulären Modus oder im Warteschlangenmodus mit Workern – oder um eine solche Instanz zu aktualisieren, zu sichern, wiederherzustellen oder zu härten. Dies gilt für SELF-HOSTED n8n (Docker), nicht für n8n Cloud und nicht für die Erstellung von Workflows. Der Skill sorgt dafür, dass der Agent zuerst Single vs. Queue fragt, die Domänen-/SSH-/Zeitzonen-Eingaben sammelt, neue Geheimnisse auf der Box generiert und den Stapel mit TLS hochlädt. Auslösen bei „n8n bereitstellen“, „n8n selbst hosten“, „n8n auf meinem Server installieren“, „n8n Docker Compose“, „n8n Warteschlangenmodus / Worker / Skalierung“, „n8n Reverse Proxy / SSL“ oder „mein n8n sichern / aktualisieren“.
