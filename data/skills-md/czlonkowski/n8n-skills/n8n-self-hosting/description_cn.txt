使用带有自动 HTTPS 的 Caddy 反向代理后面的 Docker Compose，通过 SSH 将生产自托管 n8n 端到端部署到新的 Linux VM。每当用户想要在自己的服务器/VPS/盒子（Hetzner、DigitalOcean、AWS EC2、裸机等）上自行托管、安装、设置、配置或部署 n8n 时使用 - 无论是在单一/常规模式还是与工作线程的队列模式下 - 或者更新、备份、恢复或强化此类实例。这是针对自托管的 n8n (Docker)，而不是 n8n 云，也不是构建工作流程。该技能使代理首先询问 single-vs-queue，收集域/SSH/时区输入，在盒子上生成新的机密，并使用 TLS 启动堆栈。触发“部署 n8n”、“自托管 n8n”、“在我的服务器上安装 n8n”、“n8n docker compose”、“n8n 队列模式/workers/缩放”、“n8n 反向代理/SSL”或“备份/更新我的 n8n”。
