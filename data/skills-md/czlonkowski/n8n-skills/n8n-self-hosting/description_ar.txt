انشر n8n الإنتاجي المستضاف ذاتيًا من طرف إلى طرف إلى جهاز Linux VM جديد عبر SSH، باستخدام Docker Compose خلف وكيل Caddy العكسي مع HTTPS التلقائي. يُستخدم عندما يريد المستخدم استضافة n8n أو تثبيته أو إعداده أو توفيره أو نشره على الخادم/VPS/box الخاص به (Hetzner، وDigitalOcean، وAWS EC2، والأنظمة المعدنية، وما إلى ذلك) - إما في الوضع الفردي/العادي أو في وضع قائمة الانتظار مع العمال - أو لتحديث مثل هذا المثيل أو نسخه احتياطيًا أو استعادته أو تقويته. هذا مخصص لـ n8n (Docker) المُستضاف ذاتيًا، وليس n8n Cloud وليس بناء سير العمل. تجعل المهارة الوكيل يسأل قائمة الانتظار الفردية أولاً، ويجمع مدخلات المجال/SSH/المنطقة الزمنية، ويولد أسرارًا جديدة على الصندوق، ويجمع المكدس باستخدام TLS. قم بتشغيل "نشر n8n" أو "المضيف الذاتي n8n" أو "تثبيت n8n على الخادم الخاص بي" أو "إنشاء عامل الإرساء n8n" أو "وضع قائمة الانتظار n8n / العمال / القياس" أو "الوكيل العكسي n8n / SSL" أو "النسخ الاحتياطي / تحديث n8n الخاص بي".
