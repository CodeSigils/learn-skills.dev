自動 HTTPS を備えた Caddy リバース プロキシの背後で Docker Compose を使用して、本番環境のセルフホスト型 n8n を SSH 経由で新しい Linux VM にエンドツーエンドでデプロイします。ユーザーが独自のサーバー/VPS/ボックス (Hetzner、DigitalOcean、AWS EC2、ベアメタルなど) 上で n8n をセルフホスト、インストール、セットアップ、プロビジョニング、またはデプロイする場合 (シングル/通常モードまたはワーカーによるキュー モード)、またはそのようなインスタンスを更新、バックアップ、復元、または強化する場合に使用します。これはセルフホスト型の n8n (Docker) 用であり、n8n クラウドやワークフローの構築ではありません。このスキルにより、エージェントは最初に単一対キューを要求し、ドメイン/SSH/タイムゾーン入力を収集し、ボックス上で新しいシークレットを生成し、TLS でスタックを構築します。 「n8n のデプロイ」、「セルフホスト n8n」、「サーバーに n8n をインストール」、「n8n docker compose」、「n8n キュー モード / ワーカー / スケーリング」、「n8n リバース プロキシ / SSL」、または「n8n のバックアップ / 更新」でトリガーします。
