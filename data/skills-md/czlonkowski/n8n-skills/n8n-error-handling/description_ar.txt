معالجة أخطاء Wire n8n بحيث تكون حالات الفشل عالية ومنظمّة وقابلة للاسترداد. يُستخدم عند إنشاء أي خطاف ويب/سير عمل API، أو سير عمل مجدول أو غير مراقب، أو أي مسار يؤدي فيه الفشل الصامت إلى إسقاط العمل المرئي للمستخدم - وعندما يذكر المستخدم معالجة الأخطاء، أو onError، أو continueErrorOutput، أو فروع/مخرجات الخطأ، أو إعادة المحاولة، أو retryOnFail، أو الاستجابة لرموز حالة Webhook، أو 4xx/5xx، أو Error Trigger، أو "يفشل سير العمل بصمت". يغطي مخرجات الأخطاء والأسلاك لكل عقدة، وإعادة المحاولة/الإصلاح الذاتي، وسير عمل تشغيل الأخطاء، وأشكال الاستجابة 4xx/5xx.
