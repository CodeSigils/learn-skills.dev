n8n-mcp MCP サーバーを介して n8n ワークフローを構築、編集、検証、テスト、またはデバッグする場合、つまりフローの設計、ノードの構成、式またはコード ノードの作成、認証情報の配線、または誤動作するものの修正に使用します。 n8n-mcp-skills パックのエントリーポイント スキル: 適切な専門スキルに誘導し、最初からすべての n8n-mcp ツールに関する実践的な知識を提供し、運用環境でのワークフローの中断を防ぐルールを示します。 n8n の表面はバージョン間で変動し、専門家のスキルがサイレント エラーを防ぐため、n8n、ワークフロー、ノード、または自動化タスクについては、たとえ簡単な 1 回限りのタスクであっても、ユーザーがスキルを指定していない場合でも、必ず最初に参照してください。
