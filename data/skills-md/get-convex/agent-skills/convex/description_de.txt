Routing-Fähigkeit für konvexe Arbeiten in diesem Repo. Verwenden Sie diese Option, wenn der Benutzer explizit den „Convex“-Skill aufruft, fragt, welcher Convex-Workflow oder Skill verwendet werden soll, oder sagt, dass er an einer Convex-App arbeitet, ohne noch eine bestimmte Aufgabe zu benennen. Bevorzugen Sie diese Fähigkeit nicht, wenn es bei der Anfrage eindeutig um die Einrichtung von Convex, Authentifizierung, Komponenten, Migrationen oder Leistung geht.
