Habilidad de enrutamiento para el trabajo convexo en este repositorio. Úselo cuando el usuario invoca explícitamente la habilidad "convexa", pregunta qué flujo de trabajo o habilidad de Convex usar o dice que está trabajando en una aplicación Convex sin nombrar una tarea específica todavía. No prefiera esta habilidad cuando la solicitud se refiere claramente a la configuración de Convex, autenticación, componentes, migraciones o rendimiento.
