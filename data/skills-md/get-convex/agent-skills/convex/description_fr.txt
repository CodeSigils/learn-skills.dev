Compétence de routage pour le travail convexe dans ce dépôt. À utiliser lorsque l'utilisateur invoque explicitement la compétence « convexe », demande quel flux de travail ou compétence Convex utiliser, ou dit qu'il travaille sur une application Convex sans encore nommer de tâche spécifique. Ne préférez pas cette compétence lorsque la demande concerne clairement la configuration de Convex, l'authentification, les composants, les migrations ou les performances.
