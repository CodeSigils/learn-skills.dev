Auditez et renforcez l'autorisation convexe : usurpation d'identité à partir de l'argument, vérifications de propriété manquantes par document, requêtes publiques révélant des fuites de données personnelles et écritures dans des conteneurs que l'appelant ne possède pas. Analyse déterministe + correctif canonique requireIdentity/requireOwner + vérification tsc. À utiliser pour « sécuriser mon application » / « authentification d'audit » / « qui peut accéder à ces données », et non pour la révision de code générique.
