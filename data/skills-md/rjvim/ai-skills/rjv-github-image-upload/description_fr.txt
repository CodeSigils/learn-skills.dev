Téléchargez des images locales sur GitHub et intégrez-les dans un PR/issue/commentaire en tant qu'URL canoniques github.com/user-attachments (les dépôts privés restent privés), via la CLI gh-image. Déclencheurs : « joindre une capture d'écran au PR », « ajouter une image au PR/problème », « afficher les résultats des tests dans le PR », « intégrer des captures d'écran avant/après ».
