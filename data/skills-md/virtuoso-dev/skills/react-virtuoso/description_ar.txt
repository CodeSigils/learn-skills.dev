أنشئ قوائم وشبكات وجداول افتراضية باستخدام مبدعي التفاعل. استخدم هذه المهارة عند (1) عرض قوائم كبيرة أو لا نهائية، (2) إنشاء قوائم مجمعة ذات رؤوس ثابتة، (3) إضفاء الطابع الافتراضي على جداول HTML، (4) تخطيط العناصر ذات الحجم نفسه في شبكة سريعة الاستجابة، (5) إنشاء خلاصات أو سجلات تتبع العناصر الجديدة في الأسفل، (6) تشخيص أعراض المحاكاة الافتراضية مثل التمرير السريع، أو القائمة التي لا يتم التمرير إلى الأسفل، أو العناصر المتداخلة، أو العناصر الفارغة، أو أخطاء "العنصر بحجم صفر"، أو (7) أي مهمة تتضمن Virtuoso أو GroupedVirtuoso أو VirtuosoGrid أو TableVirtuoso أو VirtuosoHandle أو itemContent أو FollowOutput أو firstItemIndex.
