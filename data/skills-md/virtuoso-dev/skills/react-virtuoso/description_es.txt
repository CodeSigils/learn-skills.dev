Cree listas, cuadrículas y tablas virtualizadas con reaccionar-virtuoso. Utilice esta habilidad cuando (1) renderice listas grandes o infinitas, (2) cree listas agrupadas con encabezados fijos, (3) virtualice tablas HTML, (4) diseñe elementos del mismo tamaño en una cuadrícula responsiva, (5) cree feeds o registros que siguen a nuevos elementos en la parte inferior, (6) diagnostique síntomas de virtualización como desplazamiento brusco, una lista que no se desplaza hacia abajo, elementos superpuestos, elementos en blanco o errores de "elementos de tamaño cero", o (7) cualquier tarea que involucre Virtuoso, GroupedVirtuoso, VirtuosoGrid, TableVirtuoso, VirtuosoHandle, itemContent, followOutput o firstItemIndex.
