通过 VoiceStudio MCP 服务器（开源 ElevenLabs 替代方案；没有任何东西离开机器，在 MPS/CUDA/CPU 上运行）进行本地 TTS、语音克隆、语音设计和视频配音。在以下情况下使用：(1) 从 646 种语言中任意一种的文本生成语音，(2) 从 3 秒参考剪辑克隆语音，(3) 按性别/年龄/口音/音调/风格设计语音，(4) 将视频配音为另一种语言，(5) 列出语音配置文件或个性预设，(6) 在隐私、成本或缺少 API 密钥很重要的情况下生成旁白，(7) Edge TTS/kokoro 不足的非英语旁白， (8) 博客文章或内容管道的批量音频。触发器：“全语音”、“语音克隆”、“克隆此语音”、“tts”、“叙述”、“生成语音”、“语音合成”、“配音视频”、“语音设计”、“本地 tts”、“多语言语音”、“叙述这篇文章”、“elevenlabs 替代方案”。
