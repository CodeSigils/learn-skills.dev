VoiceStudio MCP サーバーを介したローカル TTS、音声クローン、音声デザイン、およびビデオ ダビング (オープンソース イレブンラボの代替品。マシンから何も出ず、MPS/CUDA/CPU で実行されます)。次の場合に使用します: (1) 646 言語のいずれかのテキストから音声を生成する、(2) 3 秒のリファレンス クリップから音声をクローン作成する、(3) 性別/年齢/アクセント/ピッチ/スタイルごとに音声をデザインする、(4) ビデオを別の言語に吹き替える、(5) 音声プロファイルまたはパーソナリティ プリセットをリストする、(6) プライバシー、コスト、または API キーの欠落が重要な場合にナレーションを作成する、(7) Edge TTS/kokoro が該当する場合に英語以外のナレーションを作成する簡単に説明すると、(8) ブログ投稿またはコンテンツ パイプラインのバッチ オーディオ。トリガー: 「オムニボイス」、「音声クローン」、「この音声のクローン」、「tts」、「ナレーション」、「音声の生成」、「音声合成」、「吹き替えビデオ」、「音声デザイン」、「ローカル tts」、「多言語音声」、「この投稿のナレーション」、「elevenlabs 代替」。
