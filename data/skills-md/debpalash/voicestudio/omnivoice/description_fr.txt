TTS local, clonage vocal, conception vocale et doublage vidéo via le serveur VoiceStudio MCP (alternative open source à ElevenLabs ; rien ne quitte la machine, fonctionne sur MPS/CUDA/CPU). À utiliser lorsque : (1) générer de la parole à partir d'un texte dans l'une des 646 langues, (2) cloner une voix à partir d'un clip de référence de 3 secondes, (3) concevoir une voix par sexe/âge/accent/hauteur/style, (4) doubler une vidéo dans une autre langue, (5) répertorier les profils vocaux ou les préréglages de personnalité, (6) produire une narration là où la confidentialité, le coût ou l'absence de clés API comptent, (7) une narration non anglaise là où Edge TTS/kokoro est en deçà, (8) un lot audio pour les articles de blog ou les pipelines de contenu. Déclencheurs : « omnivoice », « clone de voix », « cloner cette voix », « tts », « raconter », « générer de la parole », « synthèse vocale », « dub vidéo », « conception vocale », « tts local », « voix multilingue », « raconter ce message », « alternative à onzelabs ».
