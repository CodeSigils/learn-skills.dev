من خلال تحليل المتطلبات، حوّل المشكلات المتكررة إلى مهارة واحدة قابلة للتثبيت ومُتحقّق منها على مستويات متعددة. تُستخدم عندما يطلب المستخدم إنشاء مهارة، أو تجميع مشكلة كمهارة، أو فحص أو اختبار مهارة مرشحة؛ فقط عندما يطلب المستخدم صراحةً المشاركة أو النشر نقوم بإنشاء مستودع GitHub والتحقق من `npx skills add`.

يرجى دائمًا الرد بلغة المستخدم.
