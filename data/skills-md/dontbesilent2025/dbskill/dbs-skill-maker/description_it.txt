Attraverso l'analisi dei requisiti, i problemi ricorrenti vengono trasformati in una singola Skill installabile e convalidata a più livelli. Viene utilizzata quando un utente richiede di creare una Skill, di distillare un problema in una Skill o di verificare o testare una Skill candidata; solo quando l'utente chiede esplicitamente di condividere o pubblicare viene preparato un repository GitHub e viene verificato `npx skills add`.
