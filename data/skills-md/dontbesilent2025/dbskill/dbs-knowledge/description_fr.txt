Transformez le dossier local existant de l'utilisateur en une base de connaissances que l'agent peut rechercher, ingérer et gérer de manière fiable ; lorsque l'utilisateur ne dispose pas de données, créer une base de connaissances minimale, et lorsque les données sont disponibles, générer une navigation dans la base de connaissances. La prise en charge ultérieure comprend l'ajout de nouvelles données, la recherche de réponses, la reconnaissance de la version actuelle, la vérification de la base de connaissances, la mise à jour précise de la navigation, ainsi que l'allègement et la gouvernance en couches d'une navigation surchargée dans la base de connaissances. Lorsque l'utilisateur mentionne « créer une base de connaissances », « mon dossier est la base de connaissances », « laisser l'IA lire ces fichiers », « mettre des données dans la base de connaissances », « trouver quelque chose dans la base de connaissances », « mettre à jour la base de connaissances », « mettre à jour la navigation dans la base de connaissances », « optimiser SOT », « SOT est trop volumineux », « source de vérité mince », « navigation dans la base de connaissances trop longue », « insérer les détails dans README », « ajouter le fichier précédent à la base de connaissances », « ce chemin est erroné », « définir ce comme la dernière version », « quel fichier est la dernière version », « les données sont en désordre » ou « établir la source de la vérité », il doit être utilisé. L'utilisateur n'a pas besoin de comprendre la configuration de Source of Truth, RAG ou Agent.

Base de connaissances basée sur des dossiers pour les agents IA. À utiliser chaque fois que l'utilisateur souhaite créer, remplir, interroger, organiser, auditer, affiner ou connecter un dossier local en tant que base de connaissances, y compris la navigation vers la source de vérité, l'indexation en couches et la résolution de version.
