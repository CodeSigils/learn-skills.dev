Transformez le dossier local existant de l'utilisateur en une base de connaissances que l'agent peut rechercher, ingérer et gérer de manière fiable ; lorsque l'utilisateur ne dispose pas de matériel, créer une base de connaissances minimale, et lorsque du matériel est présent, générer une navigation dans la base de connaissances. L'assistance ultérieure comprend l'ajout de nouveaux éléments, la recherche de réponses, la reconnaissance de la version actuelle, la vérification de la base de connaissances, la mise à jour précise de la navigation, ainsi que l'allègement et la gestion hiérarchique d'une navigation volumineuse dans la base de connaissances. Lorsque l'utilisateur mentionne « créer une base de connaissances », « mon dossier est une base de connaissances », « laisser l'IA comprendre ces fichiers », « mettre du matériel dans la base de connaissances », « rechercher des éléments dans la base de connaissances », « mettre à jour la base de connaissances », « mettre à jour la navigation dans la base de connaissances », « optimiser SOT », « SOT est trop volumineux », « affiner la source de vérité », « la navigation dans la base de connaissances est trop longue », « insérer les détails dans README », « ajouter le fichier précédent à la base de connaissances », « ce chemin est erroné », « définir ceci comme la dernière version », « quel fichier est la dernière version », « le matériel est désordonné », « établir la source de la vérité », le système doit être utilisé. L'utilisateur n'a pas besoin de comprendre la configuration de Source of Truth, RAG ou Agent.
