Nettoyeur de compétences local. Analyse Claude Code, Codex, Grok, les agents génériques et les compétences dans des répertoires spécifiés, identifiant les redirections publicitaires, les intentions commerciales secrètes, le détournement de tâches, les appels externes suspects, les lectures de données sensibles et tout autre contenu qui viole l'autorisation de l'utilisateur ; par défaut, génère uniquement un rapport et, après confirmation de l'utilisateur, isole la compétence problématique.
