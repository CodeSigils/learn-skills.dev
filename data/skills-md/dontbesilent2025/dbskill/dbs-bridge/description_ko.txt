에이전트 基建: 把任의 스킬 或 스킬 集合目录桥接到 클로드 코드(~/.claude/skills) 및 코덱스(~/.codex/skills) 。支持 dbskill 仓库内 스킬, 也支持외부 스킬绝对路径。通过软链连接源目录，改源目录后两端同步。支持按 Skill name称, 相对路径, 绝对路径, Skills目录批桥接，也支持拆桥와查看桥接状态。
触发方式：/dbs-bridge、/bridge、 「桥接这个 스킬」 「桥接整个 스킬 目录」 「把这个 스킬 接到 Claude Code 와 Codex」 「让 Claude 와 Codex 都能调用这个스킬」 「取消桥接」 「查看桥接状态」
심볼릭 링크를 사용하여 기술 폴더 또는 기술 폴더 디렉터리를 Claude Code 및 Codex에 연결합니다. dbskill 기술 및 외부 기술 디렉터리를 지원합니다. 사용자가 두 상담원 모두에서 호출할 수 있는 하나 이상의 기술을 원하거나 브리지 상태를 연결 해제/확인하려는 경우에 사용합니다.
