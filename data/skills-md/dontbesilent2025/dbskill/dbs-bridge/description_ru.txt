Агент 基建：把任意 навык 或 навык 集合目录桥接到 Клод Код（~/.claude/skills）和 Кодекс（~/.codex/skills）。支持 dbskill 仓库内навык, 也支持外部 навык 绝对路径。通过软链连接源目录,改源目录后两端同步。支持按 навык名称、相对路径、绝对路径、навыки 目录批量桥接，也支持拆桥和查看桥接状态。
触发方式:/dbs-bridge、/bridge、「桥接这个 навык」「桥接整个 навыки 目录」「把这个 навык 接到 Claude Code 和 Codex」「让 Claude和 Кодекс 都能调用这个 навык」「取消桥接」「查看桥接状态」
Соедините любую папку навыков или каталог папок навыков с Claude Code и Кодексом с помощью символических ссылок. Поддерживает навыки dbskill и внешние каталоги навыков. Используйте, когда пользователь хочет, чтобы один или несколько навыков можно было вызвать от обоих агентов, или хочет отключить/проверить статус моста.
Триггер: /dbs-bridge, /bridge, «соединить этот навык», «соединить этот каталог навыков», «сделать этот навык доступным для Клода Кода и Кодекса», «отключить этот навык», «проверить статус моста»
