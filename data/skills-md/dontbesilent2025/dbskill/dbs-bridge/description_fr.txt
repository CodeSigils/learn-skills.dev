Agent 基建：把任意 skills et skills 集合目录桥接到 Claude Code（~/.claude/skills） et Codex（~/.codex/skills）。支持 dbskill 仓库内compétence，也支持外部 compétence 绝对路径。通过软链连接源目录，改源目录后两端同步。支持按 compétence也支持拆桥和查看桥接状态。
触发方式：/dbs-bridge、/bridge、「桥接这个 skills」「桥接整个 skills 目录」「把这个 skills 接到 Claude Code et Codex」「让 Claude et Codex Compétence 都能调用这个」「取消桥接」「查看桥接状态」
Reliez n'importe quel dossier de compétences ou répertoire de dossiers de compétences à Claude Code et Codex à l'aide de liens symboliques. Prend en charge les compétences dbskill et les répertoires de compétences externes. À utiliser lorsque l'utilisateur souhaite qu'une ou plusieurs compétences puissent être appelées à partir des deux agents, ou souhaite dissocier/vérifier l'état du pont.
Déclencheur : /dbs-bridge, /bridge, "relier cette compétence", "relier ce répertoire de compétences", "rendre cette compétence disponible pour Claude Code et Codex", "dissocier cette compétence", "vérifier l'état du pont"
