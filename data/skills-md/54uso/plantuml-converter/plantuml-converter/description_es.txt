Convierta archivos PlantUML (.puml) a imágenes (PNG/SVG/PDF). Admite rutas configurables de PlantUML jar y Java a través de un archivo de configuración (plantuml-config.json en el directorio de habilidades) o variables de entorno (PLANTUML_LIB). No hay dependencias externas más allá de Java y PlantUML.jar. Activador: convertir puml, renderizar PlantUML, puml a png, exportar diagrama.
