Конвертируйте файлы PlantUML (.puml) в изображения (PNG/SVG/PDF). Поддерживает настраиваемые пути jar и Java PlantUML через файл конфигурации (plantuml-config.json в каталоге навыков) или переменные среды (PLANTUML_LIB). Никаких внешних зависимостей, кроме Java и PlantUML.jar. Триггер: конвертировать puml, визуализировать PlantUML, puml в PNG, экспортировать диаграмму.
