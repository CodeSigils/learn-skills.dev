Convertissez les fichiers PlantUML (.puml) en images (PNG/SVG/PDF). Prend en charge les chemins jar et Java configurables via le fichier de configuration (plantuml-config.json dans le répertoire de compétences) ou des variables d'environnement (PLANTUML_LIB). Aucune dépendance externe au-delà de Java et PlantUML.jar. Déclencheur : convertir puml, rendre PlantUML, puml en png, exporter un diagramme.
