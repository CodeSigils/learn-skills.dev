Inserisci una nuova fonte (URL, file locale o una risposta sintetizzata da una parte precedente della conversazione) nel wiki/vault dell'utente: salva una copia non elaborata, quindi sintetizzala in una pagina Concetto, Entità o Origine. Si attiva quando l'utente incolla un URL senza altro contesto, fornisce un percorso di file locale, dice "importa questo", "aggiungi questo al wiki", "elabora questa fonte" o chiede di salvare/resistere una risposta prodotta dalla query kyn-wiki: questa abilità prende sempre di mira il wiki/vault dell'utente, indipendentemente dalla directory di lavoro corrente.
