Guide l’architecture d’isolation des locataires dans Qdrant pour les applications multi-locataires ou multi-utilisateurs. À utiliser lorsque quelqu'un demande « comment isoler les données client », « comment créer une recherche/RAG multi-tenant », « combien de collections dois-je créer », « comment partitionner les locataires par charge utile », « les données d'un client doivent légalement rester dans un certain pays ou une certaine région ». À utiliser également lorsqu'ils décrivent un symptôme : les données d'un client sont bien plus volumineuses que les autres et ralentissent tout le monde, ou un locataire monopolise les ressources.
