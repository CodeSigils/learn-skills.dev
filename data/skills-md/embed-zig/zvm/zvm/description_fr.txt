Zig Version Manager (zvm) : installez ou mettez à jour zvm, installez les chaînes d'outils Zig, changez de version active de Zig, résolvez les modèles SemVer tels que 0.15/0.15.2-esp et résolvez les problèmes de PATH où zig ne pointe pas vers ~/.zvm/bin/zig. À utiliser lorsque l'utilisateur mentionne zvm, la gestion des versions de Zig, les builds ESP Zig, zvm install/use/current/doctor, ou demande pourquoi la version de zig ne correspond pas à zvm current.
