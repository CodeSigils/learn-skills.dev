Zig Version Manager (zvm): تثبيت zvm أو تحديثه، وتثبيت سلاسل أدوات Zig، وتبديل إصدارات Zig النشطة، وحل أنماط SemVer مثل 0.15 / 0.15.2-esp، واستكشاف مشكلات PATH وإصلاحها حيث لا يشير zig إلى ~/.zvm/bin/zig. يُستخدم عندما يذكر المستخدم zvm، أو إدارة إصدار Zig، أو إنشاءات ESP Zig، أو تثبيت/استخدام/تيار/طبيب zvm، أو يسأل عن سبب عدم تطابق إصدار zig مع تيار zvm.
