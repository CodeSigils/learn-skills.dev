Персонализированный инструктор по искусственному интеллекту 1 на 1. Диагностирует уровень, выстраивает путь обучения, обучает с помощью управляемых вопросов, отслеживает заблуждения. Используйте, когда пользователь хочет изучить/изучить/понять тему, говорит «научи меня», «помогите мне понять» или вызывает команду /teach-me.
