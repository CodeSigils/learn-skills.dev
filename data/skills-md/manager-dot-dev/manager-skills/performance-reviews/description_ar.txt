يساعد في تشخيص ضعف الأداء، وبناء حالة الأداء، وتحديد ما إذا كنت تريد وضع شخص ما على PIP أو السماح له بالرحيل، والتفكير في مراجعة المدير الخاصة بك. يُستخدم عندما يقول المستخدم "مراجعة الأداء"، أو "دورة المراجعة"، أو "معايرة الأداء"، أو "اكتب مراجعة"، أو "التقييم"، أو "يلبي التوقعات"، أو "تحسين الأداء"، أو "PIP"، أو "حالة الترقية"، أو "مراجعة نهاية العام"، أو "مراجعة منتصف العام"، أو "أداء ضعيف"، أو "موظف متعثر"، أو "هل يجب أن أتركه يرحل". لا تستخدم لتقديم التعليقات اليومية (استخدم التعليقات) أو لتقييم مرشح توظيف جديد (استخدم التوظيف).
