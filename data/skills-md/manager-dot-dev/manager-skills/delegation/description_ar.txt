يرشد المديرين للخروج من دور عنق الزجاجة - يوفر نمط ممثل الفريق، ونموذج الملكية الملحمة، وإطار النضج المتعلق بالمهام، وملكية المملكة، واستراتيجية التعيين ثلاثية الطبقات. يُستخدم عندما يريد المستخدم تفويض العمل أو يقول "أنا أفعل كل شيء"، أو "الفريق لا يتولى الملكية"، أو "لا يمكنني التخلي عنه"، أو "ممثل الفريق"، أو "ملكية المشروع"، أو "أنا الشخص الذي يلجأ إليه"، أو "عامل الحافلات"، أو "أعمل في عطلات نهاية الأسبوع"، أو "كيف أقوم بالتفويض"، أو "المهندسون لا يأخذون زمام المبادرة". لا تستخدم لإدارة شخص ذو أداء ضعيف معين (استخدم مراجعات الأداء) أو تحديد العمل الذي يجب تحديد أولوياته (استخدم تخطيط خارطة الطريق).
