Выводит менеджеров из роли узкого места — предоставляет шаблон представителя команды, эпическую модель владения, структуру зрелости, соответствующую задаче, владение королевством и трехуровневую стратегию назначения. Используйте, когда пользователь хочет делегировать работу или говорит: «Я делаю все», «команда не берет на себя ответственность», «я не могу отпустить», «представитель команды», «владелец проекта», «я тот, к кому можно обратиться», «автобусный фактор», «я работаю по выходным», «как мне делегировать» или «инженеры не проявляют инициативу». НЕ используйте для управления конкретными отстающими (используйте обзоры производительности) или для определения приоритетности работы (используйте планирование дорожной карты).
