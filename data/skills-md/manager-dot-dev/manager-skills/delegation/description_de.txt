Führt Manager aus der Engpassrolle heraus – bietet das Team-Repräsentanten-Muster, das Epic-Ownership-Modell, das Framework für aufgabenrelevante Reife, Kingdom-Ownership und eine dreistufige Zuweisungsstrategie. Verwenden Sie diese Option, wenn der Benutzer Arbeit delegieren möchte oder sagt: „Ich mache alles“, „Team übernimmt keine Verantwortung“, „Ich kann nicht loslassen“, „Teamvertreter“, „Projekteigentümerschaft“, „Ich bin der Ansprechpartner“, „Busfaktor“, „Ich arbeite am Wochenende“, „Wie delegiere ich“ oder „Ingenieure ergreifen keine Initiative“. Verwenden Sie es NICHT, um einen bestimmten Underperformer zu verwalten (Leistungsbeurteilungen zu verwenden) oder zu entscheiden, welche Arbeit priorisiert werden soll (Roadmap-Planung verwenden).
