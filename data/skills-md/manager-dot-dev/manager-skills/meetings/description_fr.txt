Couvre le cycle de vie complet des réunions pour les responsables de l'ingénierie : produit des conseils sur l'opportunité de planifier une réunion, comment bien la gérer, comment protéger le temps de concentration de l'équipe, comment éliminer le gaspillage récurrent et comment évaluer une réunion passée à partir d'une transcription ou d'une description. À utiliser lorsque l'utilisateur dit « trop de réunions », « les réunions sont une perte de temps », « comment organiser cette réunion », « ordre du jour de la réunion », « culture de la réunion », « personne ne vient préparé », « les réunions ne mènent nulle part », « comment refuser des réunions », « distractions », « temps de concentration », « les ingénieurs ne peuvent pas se concentrer », « changement de contexte », « protéger le temps d'ingénierie », « réviser cette réunion » ou « transcription ».
