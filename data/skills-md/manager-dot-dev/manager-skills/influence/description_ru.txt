Предоставляет инженерным менеджерам методы убеждения и стратегии позиционирования для выполнения задач без прямых полномочий — разрабатывает тактические методы (нэмаваши, ложное ценообразование, обратная психология, LMDTFY, инженерная прозорливость), методы разговора для обезоружения сопротивления (маркируйте озабоченность, доберитесь до «это правильно»), структуру аргументации численности персонала и трехуровневую модель видимости/доверия. Используйте, когда пользователь говорит «как мне убедить», «убедить», «заручиться поддержкой», «управление заинтересованными сторонами», «влияние без полномочий», «получить одобрение», «калибровка», «никто не воспринимает меня всерьез», «как мне узнать численность персонала» или «политика организации». НЕ используйте, если проблема заключается в отношениях пользователя с его собственным менеджером (используйте управление).
