يساعد مديري الهندسة على تحديد وقياس وتقليل استنزاف القدرات المخفية التي تجعل الفرق تفوت الالتزامات حتى عندما يكون الجميع مشغولين. استخدم هذه المهارة عندما يذكر المستخدم العمل غير المرئي، أو العمل الذي لم يتم تعقبه، أو طلبات الدعم التي تستهلك الفريق، أو العمل الملتصق، أو تراكم الظل، أو الانتشار السريع، أو خطأ تخطيط السعة، أو التقليل من تقدير الفرق دائمًا، أو إرهاق كبار المهندسين، أو "نحن مشغولون ولكن لا شيء يشحن". ينتج خطة تشخيصية وأدلة وتدخلات ملموسة.
