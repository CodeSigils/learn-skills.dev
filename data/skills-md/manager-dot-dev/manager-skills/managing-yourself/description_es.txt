Úselo cuando el usuario diga "Me siento estancado", "estoy haciendo esto bien", "desarrollo personal", "efectividad de EM", "puntos ciegos", "días malos", "verificación de cordura de mi comportamiento", "el mismo problema sigue reapareciendo", "cometí un error con alguien" o "mi equipo no está motivado". NO lo use cuando el problema sea sobre la relación del usuario con su propio gerente (use administración) o sobre dar comentarios específicos a alguien (use comentarios).
