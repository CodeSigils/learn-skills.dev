Помогает инженерным менеджерам ориентироваться в смене ролей — создает структуру четырех типов для первых управленческих ролей (ученик, преемник, пионер, новый босс), модель интеграции приобретения, руководство для инженеров-консультантов на пути управления, метод синей ленты для новых ролей, процесс изменения сломанной команды и структуру дофаминового сдвига для новых менеджеров. Используйте, когда пользователь говорит «новый менеджер», «первая управленческая роль», «взял на себя управление командой», «управление бывшими коллегами», «новая команда», «только что стал менеджером», «унаследовал команду», «начал с нуля в качестве менеджера», «второй раз в качестве менеджера», «интеграция приобретений» или «должен ли мой инженер стать менеджером».
