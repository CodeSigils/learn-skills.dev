Aide les responsables de l'ingénierie à naviguer dans les transitions de rôle - produit un cadre de quatre types pour les premiers rôles de direction (apprenti, successeur, pionnier, nouveau patron), un modèle d'intégration des acquisitions, des conseils pour conseiller les ingénieurs sur la voie de la gestion, une méthode Blue Tape List pour les nouveaux rôles, un processus de redressement d'équipe brisé et le cadrage Dopamine Shift pour les nouveaux managers. À utiliser lorsque l'utilisateur dit « nouveau manager », « premier rôle de direction », « a repris une équipe », « gérer d'anciens pairs », « nouvelle équipe », « vient de devenir manager », « a hérité d'une équipe », « repartir à neuf en tant que manager », « une deuxième fois en tant que manager », « intégration d'acquisition » ou « mon ingénieur devrait-il devenir manager ».
