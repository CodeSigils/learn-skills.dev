Hilft technischen Managern bei der Bewältigung von Rollenübergängen – erstellt ein Vier-Typen-Framework für erste Führungsrollen (Lehrling, Nachfolger, Pionier, neuer Chef), ein Akquisitionsintegrationsmodell, Anleitungen für die Beratung von Ingenieuren auf dem Managementweg, eine Blue-Tape-List-Methode für neue Rollen, einen Prozess zur Umstrukturierung unterbrochener Teams und den Dopamin-Shift-Rahmen für neue Manager. Wird verwendet, wenn der Benutzer „neuer Manager“, „erste Managementrolle“, „übernahm ein Team“, „Verwaltung ehemaliger Kollegen“, „neues Team“, „sind gerade Manager geworden“, „hat ein Team geerbt“, „Neustart als Manager“, „zweites Mal als Manager“, „Akquisitionsintegration“ oder „Sollte mein Ingenieur Manager werden“ sagt.
