يشرح المصطلحات والأطر المالية للأعمال لمديري الهندسة - وينتج تعريفات المصطلحات (ARR، COGS، CAC، LTV، هامش الربح الإجمالي، معدل الحرق، EBITDA، AARRR)، وصيغ الترجمة لجعل العمل الهندسي مرئيًا بلغة الأعمال، وإطارًا ثلاثي الطبقات لبناء مصداقية الأعمال. يُستخدم عندما يقول المستخدم "مصطلحات الأعمال"، أو "EBITDA"، أو "معدل الحرق"، أو "CAC"، أو "LTV"، أو "الهامش الإجمالي"، أو "ARR"، أو "كيف أتحدث إلى رجال الأعمال"، أو "لا أفهم التمويل"، أو "دعم العمل الهندسي"، أو "ربط الهندسة بنتائج الأعمال"، أو "التحدث إلى مالك الأرباح والخسائر"، أو "تأثير الأعمال". لا تستخدمه عندما يريد المستخدم ربط المقاييس الهندسية (DORA، السرعة) بمقاييس الأعمال - استخدم إنتاجية المطور بدلاً من ذلك.
