يقوم بإعداد جداول الأعمال، وتشخيص العلاقات المتعثرة 1:1، ويوفر أطرًا لإدارة اجتماعات فعالة 1:1 مع التقارير المباشرة. يُستخدم عندما يريد المستخدم الاستعداد لـ 1:1 أو تشغيله أو تحسينه أو متابعته، أو يقول "جدول أعمال 1:1" أو "التحضير لملاحظات 1:1" أو "ملاحظات 1:1" أو "ما الذي يجب أن أتحدث عنه" أو "تقريري المباشر" أو "التحقق من تقريري" أو "تحسين بيانات 1:1" أو "قالب 1:1" أو "تبدو بيانات 1:1 وكأنها تحديثات حالة". لا تستخدم عندما يحتاج المستخدم إلى تقديم تعليقات محددة (استخدم التعليقات) أو مناقشة مراجعات الأداء (استخدم مراجعات الأداء).
