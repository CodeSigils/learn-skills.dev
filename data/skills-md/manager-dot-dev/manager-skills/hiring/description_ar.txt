يساعد في تنظيم عملية المقابلة، ومعايرة شريط التوظيف، ومكافحة التحيز في المقابلة، والاختيار بين الترويج داخليًا مقابل التوظيف خارجيًا. يغطي أيضًا تقييم ملاءمة الموظف الجديد خلال أول 90 يومًا. يُستخدم عندما يقول المستخدم "مقابلة"، أو "تعيين"، أو "وصف الوظيفة"، أو "JD"، أو "حلقة المقابلة"، أو "استخلاص المعلومات"، أو "شريط التوظيف"، أو "عرض"، أو "رفض"، أو "مصادر"، أو "مسؤول التوظيف"، أو "عدد الموظفين"، أو "هل يجب أن أقوم بتوظيف مبتدئ"، أو "الترقية من الداخل"، أو "الموظف الجديد لا يعمل". لا تستخدم لإدارة الأداء المستمر لأحد أعضاء الفريق (استخدم مراجعات الأداء).
