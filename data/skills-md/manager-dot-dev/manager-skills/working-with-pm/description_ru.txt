Помогает инженерным менеджерам построить функциональное партнерство PM-EM и стать более ориентированным на продукт — создает динамическую модель PM-EM с тремя шаблонами (PM-Led / Engineering-Led / Fake Balanced), истинное определение партнерства, карточку «Это важно для меня» для разрешения разногласий, советы по сближению инженеров с клиентами и данные об использовании (запуск против запуска, записи сеансов, разговоры с клиентами), а также четкое описание обязанностей. Используйте, когда пользователь говорит: «Отношения с менеджером по продукту», «Менеджер по продукту сводит меня с ума», «Менеджер по продукту», «Разногласия по плану», «Продакт-менеджер важнее меня», «Партнерство между менеджером по управлению проектом», «Я хочу быть более ориентированным на продукт» или «Как мне приблизить инженеров к клиентам». НЕ используйте для общей расстановки приоритетов дорожной карты (используйте «планирование дорожной карты») или когда проектный менеджер определяет срочность (используйте «управление срочностью»).
