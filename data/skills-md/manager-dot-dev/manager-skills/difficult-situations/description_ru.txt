Предоставляет ситуационные руководства для крайних случаев с высокими ставками, которые не соответствуют стандартному набору инструментов управления — дает пошаговые инструкции по ненадлежащему поведению команды, ругательству инженера о вашем менеджере, отпусканию кого-то в тяжелых обстоятельствах, отказу менеджера от чувства вины и управлению увольнениями (как для тех, кто уходит, так и для тех, кто остается). Используйте, когда пользователь говорит: «не знаю, как с этим справиться», «кто-то сказал что-то неуместное», «инженер сказал что-то оскорбительное», «разработчик плохо отзывается о моем менеджере», «отпустить кого-то, когда у него тяжелая ситуация», «Я чувствую себя виноватым из-за того, что ухожу с работы» или «справляюсь с увольнением». НЕ используйте для стандартного управления недостаточной производительностью (используйте обзоры производительности) или для предоставления прямой обратной связи (используйте обратную связь).
