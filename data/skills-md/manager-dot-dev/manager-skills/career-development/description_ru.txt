Помогает инженерным менеджерам поддерживать рост прямых подчиненных — создает поэтапную модель инженерного воздействия (Круги влияния), основу для нелинейного планирования карьеры (Метод Тарзана), диагностические сигналы для остановки роста, сценарии разговоров для переговоров о карьере, а также готовность к продвижению по службе и различие во времени. Используйте, когда пользователь говорит «карьерный рост», «продвижение по службе», «карьерный путь», «этот человек хочет расти», «карьерный разговор», «что будет дальше с этим человеком», «карьерная лестница», «IC против менеджера», «как мне помочь продвинуться в моем отчете», «помочь кому-то расти» или «инженер хочет повышения». НЕ используйте для формальных письменных обзоров производительности или неэффективности — вместо этого используйте обзоры производительности.
