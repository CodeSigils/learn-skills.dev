Aide les responsables de l'ingénierie à rédiger des messages, des annonces et des mises à jour pour les parties prenantes qui fonctionnent bien - produit un cadre d'écriture en 3 étapes (préparer/écrire simplement/exécuter un garbage collector), le piège de réexplication asynchrone (appelant les messages manqués) et le modèle de compression/décompression pour diagnostiquer pourquoi les messages sont mal compris. À utiliser lorsque l'utilisateur dit « rédiger un message », « rédiger une annonce », « communiquer ce changement », « comment formuler ceci », « message pour mon équipe », « rédiger une mise à jour » ou « comment puis-je communiquer X ». Ne PAS utiliser pour des commentaires verbaux ou des conversations difficiles (utilisez « feedback » ou « situations difficiles »).
