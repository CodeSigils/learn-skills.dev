يساعد المديرين الهندسيين على كتابة الرسائل والإعلانات وتحديثات أصحاب المصلحة التي تصل بشكل جيد - وينتج إطار عمل للكتابة من ثلاث خطوات (الإعداد / الكتابة ببساطة / تشغيل أداة تجميع البيانات المهملة)، ومصيدة إعادة الشرح غير المتزامن (استدعاء الرسائل الفائتة)، ونموذج الضغط/إلغاء الضغط لتشخيص سبب سوء فهم الرسائل. يُستخدم عندما يقول المستخدم "مسودة رسالة"، أو "اكتب إعلانًا"، أو "أبلغ بهذا التغيير"، أو "كيف يمكنني صياغة هذا"، أو "رسالة لفريقي"، أو "اكتب تحديثًا"، أو "كيف يمكنني توصيل X." لا تستخدم للتعليقات اللفظية أو المحادثات الصعبة (استخدم "التعليقات" أو "المواقف الصعبة").
