Ayuda a los gerentes de ingeniería a escribir mensajes, anuncios y actualizaciones de las partes interesadas que lleguen bien: produce un marco de escritura de 3 pasos (preparar/escribir de manera simple/ejecutar un recolector de basura), la trampa de reexplicación asíncrona (indicando mensajes perdidos) y el modelo de compresión/descompresión para diagnosticar por qué se malinterpretan los mensajes. Úselo cuando el usuario diga "redactar un mensaje", "escribir un anuncio", "comunicar este cambio", "cómo escribo esto", "mensaje para mi equipo", "escribir una actualización" o "cómo comunico X". NO lo use para comentarios verbales o conversaciones difíciles (use "retroalimentación" o "situaciones difíciles").
