エンジニアリング マネージャーが効果的なメッセージ、お知らせ、関係者向けの最新情報を作成できるようにします。3 ステップの作成フレームワーク (準備 / 簡単に書く / ガベージ コレクターの実行)、非同期再説明トラップ (見逃したメッセージの呼び出し)、およびメッセージが誤解される理由を診断するための圧縮/解凍モデルを生成します。ユーザーが「メッセージを下書きする」、「お知らせを書く」、「この変更を伝える」、「これをどう表現するか」、「チームへのメッセージ」、「更新情報を書く」、または「X をどのように伝えるか」というときに使用します。口頭でのフィードバックや難しい会話には使用しないでください (「フィードバック」または「困難な状況」を使用します)。
