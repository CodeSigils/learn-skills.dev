Проверка и ранжирование акций США с использованием данных SEC EDGAR. Используйте, когда вас попросят: найти акции по секторам или темам; ранжировать акции по показателям оценки, роста или качества; поверхностные инвестиционные идеи; поиск акций, соответствующих определенным критериям; найдите акции с лучшим ростом/ценностью/качеством в группе. Триггеры: «лучшие акции ИИ», «дешевые акции здравоохранения», «самые быстрорастущие акции полупроводников», «найдите для меня ценные акции», «проверить быстрорастущие технологии», «ранжировать эти акции по качеству», «какая из них является лучшей растущей акцией». Примечание. Для параллельного сравнительного анализа со статистическим анализом используйте вместо этого конкурентный анализ.
