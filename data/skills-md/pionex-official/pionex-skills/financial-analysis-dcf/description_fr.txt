Valorisation DCF (Discounted Cash Flow) des actions américaines à l'aide des données financières SEC EDGAR. À utiliser lorsqu'on vous le demande pour : estimer la valeur intrinsèque ou la juste valeur d'une action américaine ; déterminer si une action est surévaluée ou sous-évaluée ; effectuer une analyse des flux de trésorerie actualisés ; calculer la hausse/la baisse à partir du prix actuel. Déclencheurs : "que vaut AAPL", "DCF MSFT", "NVDA est-il surévalué", "valeur intrinsèque de GOOGL", "juste valeur Tesla".
