DCF-Bewertung (Discounted Cash Flow) für US-Aktien mithilfe von SEC EDGAR-Finanzdaten. Verwenden Sie es, wenn Sie aufgefordert werden: den inneren Wert oder den beizulegenden Zeitwert einer US-Aktie zu schätzen; feststellen, ob eine Aktie über- oder unterbewertet ist; Führen Sie eine Discounted-Cashflow-Analyse durch; Berechnen Sie das Auf-/Abwärtspotenzial anhand des aktuellen Preises. Auslöser: „Was ist AAPL wert“, „DCF MSFT“, „Ist NVDA überbewertet“, „Intrinsischer Wert von GOOGL“, „Fair Value Tesla“.
