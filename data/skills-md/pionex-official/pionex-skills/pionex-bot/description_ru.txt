Используйте, когда пользователь просит создать, запросить, скорректировать, уменьшить или отменить ордера Pionex Futures Grid Bot. Требуются учетные данные API и разрешения бота. НЕ используйте только для рыночных данных (pionex-market), только для баланса (pionex-portfolio) или размещения/отмены спот-ордеров (pionex-trade).
