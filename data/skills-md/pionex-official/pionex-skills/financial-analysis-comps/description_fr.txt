Analyse d’entreprises comparables à l’aide des données financières SEC EDGAR. À utiliser lorsqu'on vous demande de : comparer plusieurs actions ; analyser les multiples de valorisation d'un groupe de référence ; référencer les marges, la croissance ou la valorisation des entreprises ; trouver le titre le moins cher ou le plus cher d'un groupe ; voyez comment une entreprise se compare à ses pairs. Déclencheurs : "comparez AAPL, MSFT et GOOGL", "compositions du secteur technologique", "quelle méga-capitalisation a les meilleures marges", "analyse d'évaluation par les pairs", "comparez ces actions", "comment NVDA se compare-t-il à AMD". Remarque : Pour découvrir/sélectionner des actions par thème ou par critère, utilisez plutôt la sélection des actions.
