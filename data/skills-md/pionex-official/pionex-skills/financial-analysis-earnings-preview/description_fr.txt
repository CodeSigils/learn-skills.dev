Workflow de prévisualisation des bénéfices pour les actions américaines. À utiliser lorsque vous y êtes invité pour : prévisualiser les revenus à venir ; définir les attentes pour le prochain trimestre ; élaborer des scénarios haussier/base/baissier avant les bénéfices ; préparer la publication des résultats ; comprendre ce que Wall Street attend. Déclencheurs : "Aperçu des bénéfices AAPL", "À quoi s'attendre de NVDA pour le prochain trimestre", "Aperçu des bénéfices MSFT", "Construire des scénarios pour les bénéfices GOOGL", "Préparer la publication des résultats de Tesla". Remarque : Pour l'analyse des revenus POST (une fois les résultats publiés), utilisez plutôt la compétence d'analyse des revenus.
