當使用者想要與 LinkedIn 或 X (Twitter) 互動時使用：
外展、發布、受眾洞察、訊息分類、帳號研究、
評論/回應、公司、公司頁面管理、職位、書籤、
連接帳戶管理、計費審核、錯誤報告和功能請求。觸發器包括“搜尋
LinkedIn", "在 LinkedIn 上尋找 <name>", "尋找此推文", "我的 X 書籤",
“顯示我的主頁時間軸”、“檢查我的消息”、“來自：<用戶名>”、“報告
bug」、「請求功能」、「傳送回饋」、「讓我們開始社交」、
「設定我」、「讓我登入」、「連結我的 LinkedIn/X」以及明確的「/social」。
操作 `social` CLI (npm `@usesocial/cli`)；切勿致電 LinkedIn 或 X
直接使用 HTTP API。
