Verwenden Sie es beim Planen, Schreiben, Bearbeiten oder Überprüfen von Code in jeder Sprache oder jedem Framework – bei jeder Entwicklungsaufgabe, einschließlich Fehlerbehebungen, Refaktorierungen und neuen Funktionen. Enthält die Codequalitätsregeln, Workflow-Disziplinen und eine selbstprüfende Definition-of-Done-Tabelle, anhand derer die Ausgabe des Agenten ausgewertet wird. Jeder Verstoß ist ein Fehler und der Agent darf keinen Code ausgeben, der gegen diese verstößt. Es ist obligatorisch, nicht optional, es zu lesen, bevor Sie mit der Aufgabe, der Planung oder sogar der Recherche/Erkundung fortfahren – es enthält die Disziplin, der die Planung selbst folgen muss. Gehen Sie nicht davon aus, dass Sie den Inhalt bereits kennen.
