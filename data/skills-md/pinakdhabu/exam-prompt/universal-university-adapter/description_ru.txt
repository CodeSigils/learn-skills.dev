Универсальная точка входа для ЛЮБОГО университета по всему миру. Определяет университет пользователя по каталогу PDF-файлов, загруженных файлов, словесных описаний, URL-адресов или неявного контекста. Определяет образец экзамена (индийский, американский, британский, европейский, австралийский, азиатский или общий) и направляет к правильному универсальному навыку. Работает для ВСЕХ отделов инженерии/науки/искусства/коммерции в каждой стране.
