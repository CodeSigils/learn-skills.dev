Ejecute esta habilidad cada vez que un usuario le solicite "asignar este repositorio a Notion", "diseñar un espacio de trabajo de Notion para este proyecto", "configurar Notion para este código base" o "averiguar qué debe incluir Notion frente al repositorio". También se activa cuando el usuario dice "Quiero usar Notion para realizar un seguimiento de este proyecto" y estás dentro de un repositorio local. NO active preguntas genéricas de Notion que no estén relacionadas con una base de código local. Esta habilidad produce un diseño estructurado del espacio de trabajo de Notion basado en una topología de repositorio descubierta por shell, heurísticas de clasificación explícitas y una matriz de decisión de fuente canónica, nunca un espejo de carpeta ingenuo.
