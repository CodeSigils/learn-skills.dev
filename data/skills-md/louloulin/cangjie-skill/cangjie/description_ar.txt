إنشاء الأكواد والتصميم الهندسي وإصلاح الأخطاء ومهارات تحليل المستودعات الكبيرة للغة برمجة Cangjie / Cangjie. عندما يذكر المستخدم "Cangjie / Cangjie / .cj / cjpm / cjc / cjfmt / cjdb / LSP"، أو يريد إنشاء/إصلاح وظائف Cangjie، وأنواعها، ووحداتها، ومساحات العمل، وتصميمات الحزم متعددة الوحدات، والتزامن، والشبكات، ووحدات الماكرو، وأمثلة FFI، أو تحليل التسلسل الهرمي للوحدة، و`package.package-configuration`، و`workspace`، والتنظيم الأسماء، واختلافات الإصدار في مستودع Cangjie الحقيقي، يجب استخدام هذه المهارة بشكل استباقي. حتى لو لم يقل المستخدم صراحةً "استخدام المهارة"، طالما أن المهمة الأساسية هي كتابة أو إصلاح أو تحليل كود Cangjie وهياكل المشروع، فيجب استخدام هذه المهارة.
