إنشاء الأكواد والتصميم الهندسي وإصلاح الأخطاء ومهارات تحليل الريبو الكبير للغة البرمجة Cangjie / Cangjie. عندما يذكر المستخدم "Cangjie / Cangjie / .cj / cjpm / cjc / cjfmt / cjdb / LSP"، أو يريد إنشاء/إصلاح وظائف Cangjie، وأنواعها، ووحداتها، ومساحات العمل، وتصميمات الحزم متعددة الوحدات، والتزامن، والشبكات، ووحدات الماكرو، وأمثلة FFI، أو تحليل التسلسلات الهرمية للوحدة، و"package.package-configuration"، و"workspace"، وأسماء المؤسسات والاختلافات في الإصدار في مستودعات Cangjie الحقيقية، يجب استخدام هذه المهارة بشكل نشط. حتى لو لم يقل المستخدم صراحةً "استخدام المهارة"، طالما أن المهمة الأساسية هي كتابة أو إصلاح أو تحليل كود Cangjie وهيكل المشروع، فيجب استخدام هذه المهارة.
