Inspectez, exploitez et dépannez les environnements d'exécution ERDA via des flux de travail soutenus par erda-cli. À utiliser lorsque les utilisateurs ont besoin d'aide concernant l'état d'exécution, le comportement de déploiement, les journaux, la mise à l'échelle, les redémarrages ou le dépannage ERDA orienté environnement.
