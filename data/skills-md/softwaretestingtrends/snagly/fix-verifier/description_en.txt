Re-verify previously-found defects against the current build using a real browser — take one or more defect IDs (or "all open defects"), locate each one's recorded minimal repro, re-run it faithfully at the original rigor, and deliver a per-defect verdict of FIXED, STILL BROKEN, REGRESSED, or BLOCKED, updating the bug bundle and defect ledger in place. Use whenever the user wants to know if a fix landed, whether known bugs are still present on the latest build, or to refresh the defect ledger after a deploy — trigger on phrases like "is D4 fixed," "re-check the open bugs," "did the fix for the invite bug land," "verify the fixes," or "re-run the defect checks on the new build," even without the word Playwright. Distinct from bug-triage, which investigates something newly suspected broken and produces the repro this skill consumes — if a defect has no recorded minimal repro yet, triage comes first.
