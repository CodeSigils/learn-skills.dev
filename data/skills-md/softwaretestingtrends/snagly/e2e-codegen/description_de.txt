Konvertieren Sie ein Szenario, das bereits von Flow-Runner (oder Network-Assertion/Cross-Browser-Matrix für ihre Szenariotypen) verifiziert wurde, in eine permanente, ausführbare @playwright/test-Spezifikationsdatei – mit rollenbasierten Locators, echten Assertionen pro Schritt, ohne Wartezeiten mit fester Zeit, dynamischen Testdaten und gemeinsamen Authentifizierungsvorkehrungen. Führt den generierten Test sofort aus, um zu bestätigen, dass er tatsächlich bestanden wurde, bevor er übergeben wird. Verwenden Sie es immer dann, wenn der Benutzer einen getesteten Ablauf in einen automatisierten Test umwandeln, Playwright-Testcode generieren, „dies zu einem echten Test machen“ oder etwas zu einer CI-Testsuite hinzufügen möchte. Verwenden Sie dies nicht, um Code aus einer nicht verifizierten Szenario-Mapper-Zeile zu generieren – überprüfen Sie ihn zuerst über Flow Runner, da beim Generieren von Code aus einem Szenario, das noch nie tatsächlich ausgeführt wurde, ungetestete Annahmen in etwas umgewandelt werden, das maßgeblicher aussieht, als es ist.
