Convierta un escenario que ya haya sido verificado por flow-runner (o network-assertion/cross-browser-matrix para sus tipos de escenario) en un archivo @playwright/test spec permanente y ejecutable, con localizadores basados ​​en roles, afirmaciones reales por paso, sin esperas de tiempo fijo, datos de prueba dinámicos y elementos de autenticación compartidos. Ejecuta la prueba generada inmediatamente para confirmar que realmente pasa antes de entregarla. Úselo siempre que el usuario quiera convertir un flujo probado en una prueba automatizada, generar código de prueba de Playwright, "hacer de esto una prueba real" o agregar algo a un conjunto de pruebas de CI. No use esto para generar código a partir de una fila del mapeador de escenarios no verificado; verifíquelo primero mediante flow-runner, ya que generar código a partir de un escenario que nunca se ha ejecutado convierte suposiciones no probadas en algo que parece más autorizado de lo que es.
