Genere una guía práctica orientada al usuario final para una característica del sitio recorriendo un flujo verificado con un navegador real, capturando una captura de pantalla con el elemento relevante resaltado visualmente en cada paso y escribiendo una instrucción en lenguaje sencillo usando las etiquetas de botón/campo de la propia interfaz. Úselo siempre que el usuario desee una guía de usuario, un documento de ayuda, un artículo instructivo o un tutorial paso a paso para usuarios finales; active frases como "escribir una guía de usuario para pagar", "crear un documento instructivo para registrarse" o "documentar cómo usar esta función". Solo documenta los flujos ya verificados por flow-runner (o un documento de escritor de casos de prueba marcado como Verificado); nunca escribe instrucciones para el usuario para un flujo que nadie ha confirmado que realmente funciona. Escrito para usuarios finales, no para control de calidad: sin jerga de pruebas, sin afirmaciones ni prioridades.
