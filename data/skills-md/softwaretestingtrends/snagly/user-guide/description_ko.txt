실제 브라우저를 사용하여 검증된 흐름을 살펴보고, 각 단계에서 관련 요소가 시각적으로 강조 표시된 스크린샷을 캡처하고, 인터페이스의 자체 버튼/필드 레이블을 사용하여 일반 언어 지침을 작성하여 사이트 기능에 대한 최종 사용자용 방법 가이드를 생성합니다. 사용자가 최종 사용자를 위한 사용자 가이드, 도움말 문서, 방법 문서 또는 단계별 안내를 원할 때마다 사용합니다. "결제를 위한 사용자 가이드 작성", "가입을 위한 방법 문서 만들기" 또는 "이 기능 사용 방법 문서화"와 같은 문구를 트리거합니다. flow-runner(또는 Verified로 표시된 테스트 사례 작성기 문서)에 의해 이미 검증된 문서 흐름만 — 누구도 확인하지 않은 흐름에 대해 실제로 작동하는 사용자 대상 지침을 작성하지 않습니다. QA가 아닌 최종 사용자를 위해 작성되었습니다. 테스트 전문 용어, 주장, 우선순위가 없습니다.
