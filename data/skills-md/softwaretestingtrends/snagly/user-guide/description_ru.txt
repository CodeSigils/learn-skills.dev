Используйте всякий раз, когда пользователю нужно руководство пользователя, справочный документ, статья с инструкциями или пошаговое руководство для конечных пользователей — активируйте такие фразы, как «написать руководство пользователя для оформления заказа», «создать документ с инструкциями по регистрации» или «задокументировать, как использовать эту функцию». Только потоки документов, уже проверенные потоковым исполнителем (или документом составителя тестовых сценариев с пометкой «Проверено») — никогда не пишут пользовательские инструкции для потока, который никто не подтвердил, на самом деле работает. Написано для конечных пользователей, а не для контроля качества — без жаргона тестирования, без утверждений и приоритетов.
