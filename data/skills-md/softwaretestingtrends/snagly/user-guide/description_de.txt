Erstellen Sie eine Endbenutzer-Anleitung für eine Website-Funktion, indem Sie einen verifizierten Ablauf mit einem echten Browser durchlaufen, einen Screenshot mit dem relevanten Element bei jedem Schritt visuell hervorgehoben machen und eine verständliche Anleitung unter Verwendung der eigenen Schaltflächen-/Feldbeschriftungen der Benutzeroberfläche schreiben. Verwenden Sie es immer dann, wenn der Benutzer ein Benutzerhandbuch, ein Hilfedokument, einen Anleitungsartikel oder eine Schritt-für-Schritt-Anleitung für Endbenutzer benötigt – lösen Sie dies bei Formulierungen wie „Schreiben Sie ein Benutzerhandbuch zum Auschecken“, „Erstellen Sie ein Anleitungsdokument für die Anmeldung“ oder „Dokumentieren Sie die Verwendung dieser Funktion“ aus. Dokumentiert nur Flows, die bereits vom Flow-Runner verifiziert wurden (oder ein als „Verifiziert“ gekennzeichnetes Dokument des Testfallschreibers) – schreibt niemals benutzerbezogene Anweisungen für einen Flow, von dem niemand bestätigt hat, dass er tatsächlich funktioniert. Für Endbenutzer geschrieben, nicht für die Qualitätssicherung – kein Testjargon, keine Behauptungen, keine Prioritäten.
