Verwenden Sie diese Option, wenn der Benutzer einen Fehlerbericht, einen Stack-Trace, einen fehlgeschlagenen Test oder ein Jira-Problem teilt und die wahrscheinlichen Grundursachen und zugehörigen Code identifizieren möchte – gibt geordnete, evidenzbasierte Hypothesen zurück (die Datei:Zeile, das Commit, das Protokoll), keine Urteile. Ruft den Fehler von Jira ab und kann die Analyse über den Jira-Connector zurücksenden (Trockenlauf). z.B. „analyze PROJ-123“, „Warum passiert dieser Stack-Trace?“, „Ursache für diesen fehlgeschlagenen Test“.
