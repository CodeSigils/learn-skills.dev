Escriba un documento de incorporación para un nuevo compañero de control de calidad que se una a la práctica de pruebas de este equipo: el panorama de pruebas del sitio (alcance, áreas P0, cadencia, convenciones de datos de prueba/entorno, extraídos del plan de pruebas), un recorrido seleccionado sobre qué habilidad de este kit de herramientas debe alcanzar y cuándo, puntos problemáticos conocidos extraídos de resultados recientes de clasificación de errores/generador de informes, y una ruta sugerida para la primera semana. Úselo siempre que el usuario desee incorporar a un nuevo empleado de control de calidad, escribir un documento de "introducción" para la práctica de prueba o presentarle a alguien cómo este equipo prueba este sitio. A diferencia de la guía del usuario, que documenta el producto para los usuarios finales en un lenguaje sencillo: documenta la práctica de prueba para un compañero de equipo técnico y utiliza el vocabulario de prueba de este equipo libremente en lugar de evitarlo. No maneja un navegador: esta es una habilidad de síntesis, del mismo carácter que el plan de prueba y el generador de informes.
