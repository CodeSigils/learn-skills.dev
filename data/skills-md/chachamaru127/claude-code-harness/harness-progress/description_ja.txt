エンジニア以外のバイブコーダー向けに、セッションの進行状況 (cc:WIP / cc:TODO / cc:完了数、パーセンテージ、経過時間/推定分数、これまでのコスト/推定値、ドリフト アラート) を一目で確認できるように、Progress Tracker HTML を生成します。 Plans.md を信頼できる情報源として使用し、自動再生成サポートを備えた単一ファイルの HTML をレンダリングします。ユーザーが進捗状況の概要、セッション ステータスのスナップショット、ダッシュボードを要求する場合、または次のように言う場合に使用します: 進捗トラッカー、進捗確認、進捗ボード、ダッシュボード。実際の実装、コードレビュー、リリース作業のためにロードしないでください。
