Genera un HTML demo di accettazione per vibecoder non tecnici subito prima della decisione di spedizione/attesa/rifiuto. Rilegge i criteri di accettazione che sono stati archiviati come personal-preference.v1 da Harness-Plan-brief (unito da user_request_hash), quindi esegue il rendering di un file HTML a file singolo che mostra ciascun criterio come verificato o non verificato insieme a una raccomandazione di spedizione/attesa/rifiuto. Da utilizzare quando l'utente richiede una revisione dell'accettazione, vuole decidere se spedire un'attività consegnata o dice: demo di accettazione, accetta demo, 受け入れ判断, 受入レビュー, spedisci/attendi/rifiuta 判定, 検収レビュー. NON caricare per: implementazione, revisione del codice, lavoro di rilascio.
