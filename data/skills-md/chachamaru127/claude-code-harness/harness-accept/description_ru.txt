Создайте HTML-код приемочной демонстрации для вибекодедов, не являющихся инженерами, непосредственно перед принятием решения об отправке/ожидании/отклонении. Считывает Accept_criteria, которые были сохранены как Personal-preference.v1 с помощью Harper-Plan-Brief (присоединены к user_request_hash), затем визуализирует однофайловый HTML-код, показывающий каждый критерий как проверенный или непроверенный, а также рекомендации по отправке/ожиданию/отклонению. Используйте, когда пользователь запрашивает приемочную проверку, хочет решить, отправлять ли поставленную задачу или говорит: принять демо, принять демо, 受け入れ判断, 受入レビュー, отправить/подождать/отклонить 判定, 検収レビュー. НЕ загружайте для: реализации, проверки кода, работы над выпуском.
