Создайте автоматизированный навык для создания собственных корпоративных приложений Feishu. Используйте этот навык, когда пользователь запрашивает создание приложения Feishu или корпоративного приложения, разработанного самостоятельно. Он охватывает весь процесс создания приложения, добавления возможностей бота, выпуска версий, настройки разрешений и получения учетных данных.
