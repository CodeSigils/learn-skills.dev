استخدم هذه المهارة عند تقييم أو تنفيذ تحديد مصادر الأحداث في تطبيق PHP. إطلاق أسئلة حول مخازن الأحداث، أو التجميعات، أو الإسقاطات، أو اللقطات، أو إعادة تشغيل الحدث، أو الاستعلامات المؤقتة، أو CQRS مع مصادر الأحداث، أو مكتبات مصادر الأحداث PHP (Ecotone، Prooph، EventSauce، Patchlevel). يميز مصادر الأحداث عن أحداث المجال والأدلة عندما يكون النمط مناسبًا مقابل المبالغة.
