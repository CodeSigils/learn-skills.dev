Используйте этот навык при применении чистой архитектуры, DDD или шестиугольных шаблонов внутри конкретной среды PHP. Предоставляет сопоставление портов для конкретной платформы, шаблоны адаптеров и ошибки, которых следует избегать для Laravel, Symfony, Slim, CakePHP, CodeIgniter, Yii, Laminas, Mezzio, Zend Framework и устаревших платформ/платформ с режимом обслуживания. Срабатывает, когда инфраструктура получает имя или когда принципы чистой архитектуры требуют руководства по подключению для конкретной платформы.
