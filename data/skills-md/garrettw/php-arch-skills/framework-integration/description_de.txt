Verwenden Sie diese Fähigkeit, wenn Sie Clean-Architecture-, DDD- oder hexagonale Muster in einem bestimmten PHP-Framework anwenden. Bietet Framework-spezifische Portzuordnung, Adaptermuster und zu vermeidende Fallstricke für Laravel, Symfony, Slim, CakePHP, CodeIgniter, Yii, Laminas, Mezzio, Zend Framework und Legacy-/Wartungsmodus-Frameworks. Wird ausgelöst, wenn ein Framework benannt wird oder wenn Clean-Architecture-Prinzipien eine Framework-spezifische Verkabelungsanleitung erfordern.
