استخدم هذه المهارة عند تطبيق أنماط بنية نظيفة أو DDD أو سداسية داخل إطار PHP محدد. يوفر تعيين منافذ خاصة بإطار العمل، وأنماط المحولات، والمزالق التي يجب تجنبها بالنسبة إلى Laravel، وSymfony، وSlim، وCakePHP، وCodeIgniter، وYii، وLaminas، وMezzio، وZend Framework، والأطر القديمة/وضع الصيانة. يتم تشغيله عند تسمية إطار عمل أو عندما تحتاج مبادئ البنية النظيفة إلى توجيهات الأسلاك الخاصة بإطار العمل.
