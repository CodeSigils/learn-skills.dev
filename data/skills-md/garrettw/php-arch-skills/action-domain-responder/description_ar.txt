استخدم هذه المهارة عند إنشاء معالجة لطلبات الويب/HTTP أو وحدات التحكم أو طرق العرض أو القوالب من جانب الخادم في أطر عمل PHP، أو عندما تسبب مصطلحات "MVC" الخاصة بإطار العمل ارتباكًا حول المكان الذي ينتمي إليه المنطق. يثير أسئلة حول وحدات التحكم، أو نمط Web MVC، أو Action-Domain-Responder، أو فصل العرض/القالب، أو إبقاء مخاوف HTTP وإطار العمل خارج المجال.
