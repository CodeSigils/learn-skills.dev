Utilizza questa competenza quando si progettano interfacce o API remote, si decide quanto dovrebbe essere granulare un endpoint o un'operazione o si modellano i dati che attraversano un processo o un confine di rete. Copre la facciata remota e il DTO (oggetto di trasferimento dati). Attiva domande sulla progettazione di endpoint REST/GraphQL/gRPC, esponendo casi d'uso in remoto, evitando API chiacchierone, impedendo alle entità ORM di fuoriuscire attraverso l'API o trasportando dati in modo sicuro attraverso contesti o livelli delimitati.
