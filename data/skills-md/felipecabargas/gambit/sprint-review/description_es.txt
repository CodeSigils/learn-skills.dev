Genere un informe de revisión de sprint profesional para las partes interesadas: PM, liderazgo y equipos multifuncionales. Utilice esta habilidad siempre que un usuario quiera redactar un sprint, resumir lo que envió el equipo, producir un documento retrospectivo del sprint, resumir lo que se completó en una iteración o crear un resumen del sprint para el liderazgo. Los desencadenantes incluyen: "escribir mi revisión de sprint", "generar un resumen de sprint", "crear un informe de sprint", "resumir lo que enviamos este sprint", "ayúdame a escribir nuestro sprint para las partes interesadas" o cualquier mención de resultados de sprint, informes de velocidad o resúmenes de iteraciones, incluso si no usan la palabra "habilidad" o "informe". También se activa cuando un usuario pega una lista de tickets/tareas y solicita un artículo o un resumen.
