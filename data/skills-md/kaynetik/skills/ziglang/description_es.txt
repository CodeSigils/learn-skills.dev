Las guías corrigen la programación de Zig 0.15.x, la configuración del sistema de compilación y el uso de la biblioteca estándar. Cubre cambios importantes de API de versiones anteriores (ArrayList, reescritura de E/S, build.zig, Ed25519, JSON, cliente HTTP, carcasa de enumeración @typeInfo, eliminación de espacio de nombres). Úselo al escribir código Zig, depurar errores del compilador Zig, configurar build.zig o cuando el usuario mencione Zig, zig build, zig test o biblioteca estándar Zig.
