Руководства корректируют программирование Zig 0.15.x, конфигурацию системы сборки и использование стандартной библиотеки. Охватывает критические изменения API по сравнению с предыдущими версиями (ArrayList, перезапись ввода-вывода, build.zig, Ed25519, JSON, HTTP-клиент, регистр перечислений @typeInfo, использование удаления пространства имен). Используйте при написании кода Zig, отладке ошибок компилятора Zig, настройке build.zig или когда пользователь упоминает Zig, сборку zig, тест zig или стандартную библиотеку Zig.
