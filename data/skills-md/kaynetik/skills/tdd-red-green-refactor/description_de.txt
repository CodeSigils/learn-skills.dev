Testgetriebene Entwicklung mit Red-Green-Refactor für Fehlerbehebungen, neue Funktionen und Regressionsverhinderung. Schreibt zunächst einen fehlgeschlagenen Test, um einen Fehler zu beweisen oder das Verhalten zu definieren, implementiert dann den minimal zu bestehenden Code und führt dann eine Umgestaltung durch. Verwenden Sie diese Option, wenn Sie Fehler beheben, fehlerhaftes Verhalten feststellen, neue Funktionen hinzufügen, Tests schreiben oder wenn der Benutzer TDD, Rot-Grün-Refaktor, Regressionstest, fehlgeschlagener Test, Test zuerst oder testgetrieben erwähnt.
