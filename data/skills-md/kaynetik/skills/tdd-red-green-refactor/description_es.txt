Desarrollo basado en pruebas utilizando Red-Green-Refactor para corrección de errores, nuevas funciones y prevención de regresión. Primero escribe una prueba fallida para demostrar un defecto o definir el comportamiento, luego implementa un código mínimo para aprobar y luego refactoriza. Úselo cuando corrija errores, encuentre comportamientos fallidos, agregue nuevas funciones, escriba pruebas o cuando el usuario mencione TDD, refactor rojo-verde, prueba de regresión, prueba fallida, prueba primero o basada en pruebas.
