Standard e pratiche per la documentazione di Markdown e GitHub Flavored Markdown (GFM). Copre la gerarchia delle intestazioni, lo stile di prosa, gli avvisi GFM, gli elenchi di attività, le sezioni comprimibili, i diagrammi delle sirene, le tabelle, i badge e gli anti-modelli. Applica regole anti-intelligenza artificiale: nessun artefatto Unicode, nessun emoji, nessun linguaggio di riempimento, nessuna interruzione di linea dura in prosa. Da utilizzare durante la scrittura di README, pagine di documenti, log delle modifiche, documenti API, guide di contributo o qualsiasi file Markdown.
