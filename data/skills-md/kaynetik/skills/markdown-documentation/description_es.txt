Estándares y prácticas para la documentación de Markdown y GitHub Flavored Markdown (GFM). Cubre la jerarquía de encabezados, el estilo de prosa, las alertas de GFM, las listas de tareas, las secciones plegables, los diagramas de sirena, las tablas, las insignias y los antipatrones. Aplica reglas sin desvíos de IA: sin artefactos Unicode, sin emojis, sin lenguaje de relleno, sin saltos de línea estrictos en prosa. Úselo al escribir archivos README, páginas de documentos, registros de cambios, documentos API, guías de contribución o cualquier archivo Markdown.
