Стандарты и практики для документации Markdown и GitHub Flavored Markdown (GFM). Охватывает иерархию заголовков, стиль прозы, оповещения GFM, списки задач, свертываемые разделы, диаграммы «Русалка», таблицы, значки и антишаблоны. Соблюдает правила отсутствия искусственного интеллекта: никаких артефактов Юникода, никаких смайлов, никаких языков-заполнителей, никаких жестких разрывов строк в прозе. Используйте при написании файлов README, страниц документации, журналов изменений, документации API, руководств по участию или любого файла Markdown.
