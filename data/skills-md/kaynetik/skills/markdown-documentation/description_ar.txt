المعايير والممارسات الخاصة بتوثيق Markdown وGitHub Flavoured Markdown (GFM). يغطي التسلسل الهرمي للعناوين، وأسلوب النثر، وتنبيهات GFM، وقوائم المهام، والأقسام القابلة للطي، ومخططات حورية البحر، والجداول، والشارات، والأنماط المضادة. يفرض قواعد عدم الانحدار في الذكاء الاصطناعي: لا توجد عناصر Unicode، ولا رموز تعبيرية، ولا لغة حشو، ولا فواصل متشددة في النثر. يُستخدم عند كتابة ملفات README، أو صفحات المستندات، أو سجلات التغيير، أو مستندات API، أو الأدلة المساهمة، أو أي ملف Markdown.
