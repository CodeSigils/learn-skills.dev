Normes et pratiques pour la documentation Markdown et GitHub Flavored Markdown (GFM). Couvre la hiérarchie des titres, le style de prose, les alertes GFM, les listes de tâches, les sections pliables, les diagrammes Mermaid, les tableaux, les badges et les anti-modèles. Applique des règles sans IA : pas d'artefacts Unicode, pas d'émojis, pas de langage de remplissage, pas de sauts de ligne durs dans la prose. À utiliser lors de l'écriture de README, de pages de documentation, de journaux de modifications, de documents API, de guides de contribution ou de tout fichier Markdown.
