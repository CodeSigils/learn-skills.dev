Standards und Praktiken für Markdown- und GitHub Flavored Markdown (GFM)-Dokumentation. Behandelt Überschriftenhierarchie, Prosastil, GFM-Benachrichtigungen, Aufgabenlisten, zusammenklappbare Abschnitte, Meerjungfrau-Diagramme, Tabellen, Abzeichen und Anti-Muster. Erzwingt No-AI-Slop-Regeln: keine Unicode-Artefakte, keine Emojis, keine Füllsprache, keine harten Zeilenumbrüche in der Prosa. Zum Schreiben von READMEs, Dokumentationsseiten, Änderungsprotokollen, API-Dokumenten, beitragenden Leitfäden oder Markdown-Dateien verwenden.
