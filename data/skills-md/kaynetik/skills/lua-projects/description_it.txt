Guida la programmazione idiomatica di Lua 5.4, la progettazione dei moduli e la manutenzione dei progetti per gli ecosistemi plugin/config Neovim (LazyVim, lazy.nvim) e gli strumenti della barra macOS (SketchyBar/SbarLua). Copre stile, strumenti (StyLua, Selene, LuaLS), modelli di moduli e test. Da utilizzare quando si scrive codice Lua, si configurano plugin Neovim, si lavora con le configurazioni SketchyBar Lua, si esegue il debug di errori di modulo/richiesta Lua o quando l'utente menziona Lua, file .lua, LazyVim, lazy.nvim, SbarLua, SketchyBar, luarocks, LuaLS, StyLua o Selene.
