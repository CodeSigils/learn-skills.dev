إرشادات هندسية لقواعد البيانات تغطي تصميم المخطط والفهرسة وتحسين الاستعلام والنسخ المتماثل وعمليات الإنتاج عبر المخازن العلائقية والمستندات والعمودية. التركيز الأساسي هو PostgreSQL؛ يغطي MySQL وMongoDB وClickHouse وRedis وSQLite وDuckDB. يُستخدم عند تصميم المخططات، أو تحسين الاستعلامات البطيئة، أو اختيار أنواع الفهرس، أو مراجعة عمليات الترحيل، أو إعداد النسخ المتماثل، أو نمذجة المستندات، أو التعامل مع VACUUM/MVCC، أو عندما يذكر المستخدم SQL، أو NoSQL، أو OLAP، أو EXPLAIN، أو تضخم الفهرس، أو التجزئة، أو التقسيم، أو أي نظام قاعدة بيانات مسمى.
