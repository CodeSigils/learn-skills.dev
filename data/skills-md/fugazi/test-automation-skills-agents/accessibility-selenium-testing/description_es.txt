Kit de herramientas de prueba de accesibilidad que utiliza Selenium WebDriver 4+ con Java 21+ y motor axe-core. Úselo cuando se le solicite validar el cumplimiento de WCAG 2.2 AA, escanear páginas o componentes en busca de infracciones totales, probar la navegación con el teclado, auditar el contraste de color, verificar la semántica de ARIA, generar informes de accesibilidad, filtrar reglas de hacha, depurar problemas con el lector de pantalla o implementar principios POUR (perceptibles, operables, comprensibles y sólidos).
