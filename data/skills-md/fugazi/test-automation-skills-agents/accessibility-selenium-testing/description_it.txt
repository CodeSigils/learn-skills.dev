Toolkit per test di accessibilità che utilizza Selenium WebDriver 4+ con Java 21+ e motore axe-core. Utilizzare quando richiesto per convalidare la conformità WCAG 2.2 AA, scansionare pagine o componenti per eventuali violazioni, testare la navigazione da tastiera, verificare il contrasto dei colori, controllare la semantica ARIA, generare report di accessibilità, filtrare regole ax, eseguire il debug di problemi di screen reader o implementare i principi POUR (percepibile, operabile, comprensibile, robusto).
