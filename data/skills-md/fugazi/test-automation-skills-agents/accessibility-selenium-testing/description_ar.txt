مجموعة أدوات اختبار إمكانية الوصول باستخدام Selenium WebDriver 4+ مع Java 21+ ومحرك ax-core. استخدمه عندما يُطلب منك التحقق من صحة امتثال WCAG 2.2 AA، أو مسح الصفحات أو المكونات بحثًا عن انتهاكات a11y، أو اختبار التنقل في لوحة المفاتيح، أو تدقيق تباين الألوان، أو التحقق من دلالات ARIA، أو إنشاء تقارير إمكانية الوصول، أو تصفية قواعد الفأس، أو تصحيح مشكلات قارئ الشاشة، أو تنفيذ مبادئ POUR (يمكن إدراكها، وقابلية تشغيلها، وفهمها، وقوية).
