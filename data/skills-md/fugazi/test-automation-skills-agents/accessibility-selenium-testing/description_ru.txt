Набор инструментов для тестирования доступности с использованием Selenium WebDriver 4+ с Java 21+ и движком Axe-Core. Используйте, когда вас просят проверить соответствие WCAG 2.2 AA, сканировать страницы или компоненты на предмет нарушений, проверить навигацию с помощью клавиатуры, проверить цветовой контраст, проверить семантику ARIA, создать отчеты о доступности, отфильтровать правила ax, отладить проблемы чтения с экрана или реализовать принципы POUR (ощутимые, работоспособные, понятные, надежные).
