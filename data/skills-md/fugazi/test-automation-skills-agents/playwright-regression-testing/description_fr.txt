Stratégie de tests de régression automatisés et meilleures pratiques utilisant Playwright avec TypeScript. À utiliser lorsqu'on vous demande de planifier, d'organiser, de sélectionner, d'exécuter ou d'optimiser des suites de tests de régression pour les applications Web. Couvre la sélection de tests basée sur les changements et les risques, le marquage et la priorisation des tests, l'exécution parallèle, le partitionnement, l'intégration du pipeline CI/CD avec GitHub Actions, la gestion des tests irréguliers, la surveillance de l'état de la suite et les types de régression (corrective, progressive, sélective, complète). Mots clés : tests de régression, sélection de tests, tests de fumée, optimisation de la suite de tests, pipeline CI, tests irréguliers, fragmentation de tests, analyse d'impact, git diff.
