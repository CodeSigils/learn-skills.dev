Strategia di test di regressione automatizzata e best practice utilizzando Playwright con TypeScript. Da utilizzare quando richiesto per pianificare, organizzare, selezionare, eseguire o ottimizzare suite di test di regressione per applicazioni web. Copre la selezione dei test in base alle modifiche e al rischio, l'assegnazione di tag e priorità ai test, l'esecuzione parallela, lo sharding, l'integrazione della pipeline CI/CD con GitHub Actions, la gestione instabile dei test, il monitoraggio dello stato della suite e i tipi di regressione (correttiva, progressiva, selettiva, completa). Parole chiave: test di regressione, selezione dei test, test del fumo, ottimizzazione della suite di test, pipeline CI, test instabili, test sharding, analisi dell'impatto, git diff.
