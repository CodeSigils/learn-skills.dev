Estrategia de prueba de regresión automatizada y mejores prácticas utilizando Playwright con TypeScript. Úselo cuando se le solicite planificar, organizar, seleccionar, ejecutar u optimizar conjuntos de pruebas de regresión para aplicaciones web. Cubre la selección de pruebas basadas en cambios y riesgos, etiquetado y priorización de pruebas, ejecución paralela, fragmentación, integración de canalización de CI/CD con GitHub Actions, gestión de pruebas inestables, monitoreo del estado de la suite y tipos de regresión (correctiva, progresiva, selectiva, completa). Palabras clave: pruebas de regresión, selección de pruebas, pruebas de humo, optimización del conjunto de pruebas, canalización de CI, pruebas inestables, fragmentación de pruebas, análisis de impacto, git diff.
