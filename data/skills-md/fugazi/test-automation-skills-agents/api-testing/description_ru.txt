Протестируйте контракты конечных точек REST и GraphQL, используя приспособление запроса Playwright (TypeScript) или REST Assured (Java). Используйте для автономных тестов API, охватывающих схемы, аутентификацию, обработку статуса/ошибок, разбиение на страницы, идемпотентность, ограничения скорости или проверки контракта; не для спецификаций браузера E2E. Ключевые слова: REST, GraphQL, контракт API, проверка схемы, REST Assured.
