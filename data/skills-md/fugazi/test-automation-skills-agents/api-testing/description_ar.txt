اختبر عقود نقاط النهاية REST وGraphQL باستخدام أداة تثبيت طلب Playwright (TypeScript) أو REST Assured (Java). الاستخدام لاختبارات واجهة برمجة التطبيقات (API) المستقلة التي تغطي المخططات، أو المصادقة، أو معالجة الحالة/الأخطاء، أو ترقيم الصفحات، أو العجز، أو حدود الأسعار، أو عمليات التحقق من العقد؛ ليس لمواصفات المتصفح E2E. الكلمات الرئيسية: REST، GraphQL، عقد API، التحقق من صحة المخطط، REST Assured.
