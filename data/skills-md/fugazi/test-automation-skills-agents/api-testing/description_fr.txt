Testez les contrats de point de terminaison REST et GraphQL à l'aide du dispositif de requête Playwright (TypeScript) ou REST Assured (Java). Utilisation pour les tests d'API autonomes couvrant les schémas, l'authentification, la gestion des statuts/erreurs, la pagination, l'idempotence, les limites de débit ou les vérifications de contrat ; pas pour les spécifications du navigateur E2E. Mots clés : REST, GraphQL, contrat API, validation de schéma, REST Assured.
