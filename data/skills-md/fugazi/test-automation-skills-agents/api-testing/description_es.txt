Pruebe los contratos de puntos finales REST y GraphQL utilizando el dispositivo de solicitud Playwright (TypeScript) o REST Assured (Java). Úselo para pruebas de API independientes que cubran esquemas, autenticación, manejo de estado/error, paginación, idempotencia, límites de velocidad o verificaciones de contratos; no para especificaciones de navegador E2E. Palabras clave: REST, GraphQL, contrato API, validación de esquema, REST Assured.
