Testa i contratti endpoint REST e GraphQL utilizzando il dispositivo di richiesta Playwright (TypeScript) o REST Assuring (Java). Utilizzare per test API autonomi che coprono schemi, autenticazione, gestione di stati/errori, impaginazione, idempotenza, limiti di velocità o controlli dei contratti; non per le specifiche E2E del browser. Parole chiave: REST, GraphQL, contratto API, convalida dello schema, REST Assured.
