Testen Sie REST- und GraphQL-Endpunktverträge mit Playwright Request Fixture (TypeScript) oder REST Assured (Java). Verwendung für eigenständige API-Tests, die Schemata, Authentifizierung, Status-/Fehlerbehandlung, Paginierung, Idempotenz, Ratenlimits oder Vertragsprüfungen abdecken; Nicht für Browser-E2E-Spezifikationen. Schlüsselwörter: REST, GraphQL, API-Vertrag, Schemavalidierung, REST Assured.
