Instala y valida automáticamente el paquete de habilidades Civitai Videoflow desde el repositorio civitai-agent-skills. Admite git clone o carga zip manual, ejecuta npx skills add en orden seguro para las dependencias y guía las comprobaciones de requisitos previos del entorno y de las herramientas para CIVITAI_RECORDS_DATABASE_URL, DUOMI_API_TOKEN, IMAGEKIT_PRIVATE_KEY y CIVITAI_ACCOUNT. Úselo cuando: el usuario necesita configurar videoflow, instalar habilidades de canalización de Civitai, configurar el flujo de trabajo de imagen a video, habilitar la canalización de publicación de Civitai o cuando se mencionan civitai-videoflow y habilidades de trabajadores relacionadas pero no están disponibles. Activadores: instalar habilidades de videoflow, configurar el paquete de habilidades de civitai, configurar habilidades de agente de civitai, habilitar comandos de videoflow, instalar habilidades de canalización de duomi/civitai.
