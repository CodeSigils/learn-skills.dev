Civitai-agent-skills リポジトリから Civitai Videoflow スキル バンドルを自動的にインストールして検証します。 git clone または手動 zip アップロードをサポートし、npx スキル add を依存関係に安全な順序で実行し、CIVITAI_RECORDS_DATABASE_URL、DUOMI_API_TOKEN、IMAGEKIT_PRIVATE_KEY、および CIVITAI_ACCOUNT の環境とツールの前提条件チェックをガイドします。次の場合に使用します: ユーザーがビデオフローのセットアップを必要とする場合、Civtai パイプライン スキルのインストール、画像からビデオへのワークフローの構成、Civitai パブリッシュ パイプラインの有効化、または civitai-videoflow および関連するワーカー スキルが言及されているが利用できない場合。トリガー: videoflow スキルのインストール、civitai スキル バンドルのセットアップ、civitai-agent-skills の構成、videoflow コマンドの有効化、duomi/civitai パイプライン スキルのインストール。
