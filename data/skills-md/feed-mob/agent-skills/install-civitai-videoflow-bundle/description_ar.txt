يقوم تلقائيًا بتثبيت حزمة مهارات Civitai Videoflow والتحقق من صحتها من مستودع مهارات civitai-agent. يدعم استنساخ git أو تحميل zip يدويًا، وتشغيل إضافة مهارات npx بترتيب آمن للتبعية، وتوجيه البيئة والتحقق من المتطلبات الأساسية للأداة لـ CIVITAI_RECORDS_DATABASE_URL وDUOMI_API_TOKEN وIMAGEKIT_PRIVATE_KEY وCIVITAI_ACCOUNT. يُستخدم عندما: يحتاج المستخدم إلى إعداد تدفق الفيديو، أو تثبيت مهارات خطوط أنابيب Civitai، أو تكوين سير عمل تحويل الصورة إلى فيديو، أو تمكين خط أنابيب نشر Civitai، أو عندما يتم ذكر تدفق فيديو Civitai ومهارات العمال ذات الصلة ولكنها غير متوفرة. المحفزات: تثبيت مهارات تدفق الفيديو، وإعداد حزمة مهارات civitai، وتكوين مهارات وكيل civitai، وتمكين أوامر تدفق الفيديو، وتثبيت مهارات خط أنابيب duomi/civitai.
