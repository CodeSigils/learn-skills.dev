Installiert und validiert automatisch das Civitai Videoflow-Skill-Paket aus dem civitai-agent-skills-Repository. Unterstützt das Klonen von Git oder den manuellen Zip-Upload, führt das Hinzufügen von Npx-Skills in abhängigkeitssicherer Reihenfolge aus und leitet Umgebungs- und Toolvoraussetzungsprüfungen für CIVITAI_RECORDS_DATABASE_URL, DUOMI_API_TOKEN, IMAGEKIT_PRIVATE_KEY und CIVITAI_ACCOUNT. Verwenden Sie diese Option, wenn: Der Benutzer muss Videoflow einrichten, Civitai-Pipeline-Kenntnisse installieren, den Bild-zu-Video-Workflow konfigurieren, die Civitai-Veröffentlichungspipeline aktivieren oder wenn Civitai-Videoflow und zugehörige Arbeitsfähigkeiten erwähnt, aber nicht verfügbar sind. Auslöser: Videoflow-Skills installieren, Civitai-Skills-Bundle einrichten, Civitai-Agent-Skills konfigurieren, Videoflow-Befehle aktivieren, Duomi/Civitai-Pipeline-Skills installieren.
