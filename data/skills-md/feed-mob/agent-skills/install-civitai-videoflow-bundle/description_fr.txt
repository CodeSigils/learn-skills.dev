Installe et valide automatiquement l'ensemble de compétences Civitai Videoflow à partir du référentiel civitai-agent-skills. Prend en charge le clone git ou le téléchargement zip manuel, exécute l'ajout de compétences npx dans un ordre sécurisé en matière de dépendance et guide les vérifications des prérequis de l'environnement et des outils pour CIVITAI_RECORDS_DATABASE_URL, DUOMI_API_TOKEN, IMAGEKIT_PRIVATE_KEY et CIVITAI_ACCOUNT. À utiliser lorsque : l'utilisateur a besoin de configurer Videoflow, d'installer les compétences de pipeline Civitai, de configurer le flux de travail image vers vidéo, d'activer le pipeline de publication Civitai ou lorsque civitai-videoflow et les compétences des travailleurs associées sont mentionnées mais indisponibles. Déclencheurs : installez les compétences videoflow, configurez l'ensemble de compétences civitai, configurez les compétences d'agent civitai, activez les commandes videoflow, installez les compétences de pipeline duomi/civitai.
