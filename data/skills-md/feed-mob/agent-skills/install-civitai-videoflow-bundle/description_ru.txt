Автоматически устанавливает и проверяет пакет навыков Civitai Videoflow из репозитория civitai-agent-skills. Поддерживает клонирование git или загрузку zip-файлов вручную, запускает добавление навыков npx в порядке, безопасном для зависимостей, а также направляет проверки предварительных условий среды и инструментов для CIVITAI_RECORDS_DATABASE_URL, DUOMI_API_TOKEN, IMAGEKIT_PRIVATE_KEY и CIVITAI_ACCOUNT. Используйте, когда: пользователю нужна настройка видеопотока, установка навыков конвейера Civitai, настройка рабочего процесса преобразования изображения в видео, включение конвейера публикации Civitai или когда civitai-videoflow и связанные с ним навыки работников упомянуты, но недоступны. Триггеры: установка навыков видеопотока, настройка пакета навыков civitai, настройка civitai-agent-skills, включение команд видеопотока, установка навыков конвейера duomi/civitai.
