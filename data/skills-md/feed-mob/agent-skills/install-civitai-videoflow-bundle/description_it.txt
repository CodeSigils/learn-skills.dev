Installa e convalida automaticamente il pacchetto di competenze Civitai Videoflow dal repository civitai-agent-skills. Supporta git clone o caricamento manuale tramite zip, esegue l'aggiunta delle competenze npx in ordine protetto dalle dipendenze e guida i controlli dei prerequisiti dell'ambiente e dello strumento per CIVITAI_RECORDS_DATABASE_URL, DUOMI_API_TOKEN, IMAGEKIT_PRIVATE_KEY e CIVITAI_ACCOUNT. Da utilizzare quando: l'utente necessita della configurazione di videoflow, installa le competenze della pipeline Civitai, configura il flusso di lavoro da immagine a video, abilita la pipeline di pubblicazione Civitai o quando civitai-videoflow e le competenze del lavoratore correlate sono menzionate ma non disponibili. Trigger: installa le competenze di videoflow, configura il pacchetto di competenze di Civitai, configura le competenze di Civitai-Agent, abilita i comandi di Videoflow, installa le competenze di pipeline Duomi/Civitai.
