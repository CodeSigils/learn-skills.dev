Blockscout PRO API (100 以上の EVM チェーンにまたがる単一の HTTP API) を介して、ブロックチェーン データを必要とする Web3 アプリケーション、スクリプト、CLI、ボット、モバイル アプリ、デスクトップ アプリを構築します。ユーザーが HTTP 経由でブロックチェーン データ (トランザクション、ブロック、アドレス、トークン、NFT、ログ、コントラクト コンテキスト、内部 TX、アカウント抽象化など) を読み取りたい場合、および API を直接呼び出すソフトウェアを構築している場合は常に、このスキルを呼び出します。 「Blockscout PRO API」、「pro-api」、「proapi_」、「Blockscout API」、「block Explorer API」、「api.blockscout.com」、または「Web3 アプリの構築」、「オンチェーン データのインデックス/クエリ」、「ウォレット履歴」、「NFT インベントリ」、「チェーン間のトランザクション ログ」などのより広範な表現でトリガーされます。 「Blockscout API の費用はいくらですか」、「Blockscout でサポートされているチェーン ID」。このスキルは HTTP を直接統合するために使用します。兄弟の「blockscout-analysis」スキルは、Blockscout MCP サーバーをカバーします。
