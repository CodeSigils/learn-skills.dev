Cree aplicaciones web3, scripts, CLI, bots, aplicaciones móviles y aplicaciones de escritorio que necesiten datos de blockchain a través de la API Blockscout PRO, una única API HTTP que abarca más de 100 cadenas EVM. Invoque esta habilidad siempre que el usuario quiera leer datos de blockchain a través de HTTP (transacciones, bloques, direcciones, tokens, NFT, registros, contexto de contrato, txs internos, abstracción de cuentas, etc.) y esté creando software que llame a una API directamente. Se activa con menciones directas de `Blockscout PRO API`, `pro-api`, `proapi_`, `Blockscout API`, `block explorer API`, `api.blockscout.com`, o en frases más amplias como "crear una aplicación web3", "indexar/consultar datos en cadena", "historial de billetera", "inventario NFT", "registros de transacciones entre cadenas", "cuánto cuesta la API de Blockscout", "cadena ID compatibles con Blockscout". Utilice esta habilidad para integraciones HTTP directas; la habilidad hermana `blockscout-analysis` cubre el servidor Blockscout MCP.
