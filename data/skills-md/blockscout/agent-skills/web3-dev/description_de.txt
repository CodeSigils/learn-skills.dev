Erstellen Sie Web3-Anwendungen, Skripte, CLIs, Bots, mobile Apps und Desktop-Apps, die Blockchain-Daten benötigen, über die Blockscout PRO API – eine einzige HTTP-API, die über 100 EVM-Ketten umfasst. Rufen Sie diese Fähigkeit immer dann auf, wenn der Benutzer Blockchain-Daten über HTTP lesen möchte (Transaktionen, Blöcke, Adressen, Token, NFTs, Protokolle, Vertragskontext, interne Übertragungen, Kontoabstraktion usw.) und Software erstellt, die eine API direkt aufruft. Auslösen bei direkter Erwähnung von „Blockscout PRO API“, „pro-api“, „proapi_“, „Blockscout API“, „Block Explorer API“, „api.blockscout.com“ oder bei breiteren Formulierungen wie „eine Web3-App erstellen“, „On-Chain-Daten indizieren/abfragen“, „Wallet-Verlauf“, „NFT-Inventar“, „Transaktionsprotokolle über Ketten hinweg“, „Wie viel kostet die Blockscout API“, „Kette Von Blockscout unterstützte IDs". Nutzen Sie diesen Skill für direkte HTTP-Integrationen; Der Geschwister-Skill „Blockscout-Analyse“ deckt den Blockscout MCP-Server ab.
