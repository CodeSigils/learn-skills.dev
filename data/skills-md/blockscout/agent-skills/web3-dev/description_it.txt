Crea applicazioni web3, script, CLI, bot, app mobili e app desktop che necessitano di dati blockchain tramite l'API Blockscout PRO: una singola API HTTP che abbraccia oltre 100 catene EVM. Richiama questa abilità ogni volta che l'utente desidera leggere i dati blockchain su HTTP (transazioni, blocchi, indirizzi, token, NFT, registri, contesto contrattuale, tx interni, astrazione dell'account, ecc.) e sta creando un software che chiama direttamente un'API. Attivazione su menzioni dirette di `Blockscout PRO API`, `pro-api`, `proapi_`, `Blockscout API`, `block explorer API`, `api.blockscout.com` o frasi più ampie come "crea un'app web3", "indicizza/interroga dati sulla catena", "cronologia del portafoglio", "inventario NFT", "registri delle transazioni tra catene", "quanto costa l'API Blockscout", "catena ID supportati da Blockscout". Utilizza questa competenza per integrazioni HTTP dirette; la competenza gemella "blockscout-analysis" copre il server MCP Blockscout.
