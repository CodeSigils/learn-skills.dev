أنشئ تطبيقات web3، والبرامج النصية، وواجهات سطر الأوامر، والروبوتات، وتطبيقات الأجهزة المحمولة، وتطبيقات سطح المكتب التي تحتاج إلى بيانات blockchain عبر Blockscout PRO API - واجهة برمجة تطبيقات HTTP واحدة تمتد لأكثر من 100 سلسلة EVM. قم باستدعاء هذه المهارة عندما يريد المستخدم قراءة بيانات blockchain عبر HTTP (المعاملات، والكتل، والعناوين، والرموز، وNFTs، والسجلات، وسياق العقد، وtxs الداخلي، وتجريد الحساب، وما إلى ذلك) ويقوم ببناء برنامج يستدعي واجهة برمجة التطبيقات (API) مباشرة. تفعيل الإشارات المباشرة إلى `Blockscout PRO API`، أو `pro-api`، أو `proapi_`، أو `Blockscout API`، أو `block explorer API`، أو `api.blockscout.com`، أو على عبارات أوسع مثل "إنشاء تطبيق web3"، و"بيانات الفهرس/الاستعلام على السلسلة"، و"سجل المحفظة"، و"مخزون NFT"، و"سجلات المعاملات عبر السلاسل"، و"كم عدد تكلفة Blockscout API"، "معرفات السلسلة المدعومة بواسطة Blockscout". استخدم هذه المهارة لعمليات تكامل HTTP المباشرة؛ تغطي مهارة "تحليل Blockscout" للأخوة خادم Blockscout MCP.
