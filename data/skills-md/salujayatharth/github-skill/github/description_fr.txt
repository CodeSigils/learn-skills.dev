Intégration complète de GitHub pour les référentiels, les problèmes, les PR, les flux de travail et la sécurité. À utiliser lorsque vous travaillez avec GitHub : (1) Opérations de référentiel - obtenir/créer des fichiers, des branches, rechercher du code, (2) Gestion des problèmes - lister, créer, mettre à jour, commenter les problèmes, (3) Demandes d'extraction - créer, examiner, fusionner des PR, vérifier l'état des CI, (4) Actions GitHub - répertorier les flux de travail, afficher les exécutions, télécharger les journaux, déclencher des flux de travail, (5) Sécurité du code - Alertes Dependabot, analyse de code, analyse secrète. Nécessite la variable d'environnement GITHUB_TOKEN avec les étendues appropriées.
