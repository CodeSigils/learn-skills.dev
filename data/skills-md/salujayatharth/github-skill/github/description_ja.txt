リポジトリ、問題、PR、ワークフロー、セキュリティのための完全な GitHub 統合。 GitHub を使用する場合に使用します: (1) リポジトリ操作 - ファイル、ブランチ、コードの取得/作成、(2) 問題管理 - 問題のリスト、作成、更新、コメント、(3) プル リクエスト - PR の作成、レビュー、マージ、CI ステータスの確認、(4) GitHub アクション - ワークフローのリスト、実行の表示、ログのダウンロード、ワークフローのトリガー、(5) コード セキュリティ - dependabot アラート、コード スキャン、シークレット スキャン。適切なスコープを持つ GITHUB_TOKEN 環境変数が必要です。
