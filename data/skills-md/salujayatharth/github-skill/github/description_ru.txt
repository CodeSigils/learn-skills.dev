Полная интеграция с GitHub для репозиториев, задач, PR, рабочих процессов и безопасности. Используйте при работе с GitHub: (1) Операции с репозиторием — получение/создание файлов, веток, код поиска, (2) Управление проблемами — список, создание, обновление, комментирование проблем, (3) Запросы на включение — создание, просмотр, объединение PR, проверка статуса CI, (4) Действия GitHub — список рабочих процессов, просмотр запусков, загрузка журналов, запуск рабочих процессов, (5) Безопасность кода — оповещения Dependabot, сканирование кода, секретное сканирование. Требуется переменная среды GITHUB_TOKEN с соответствующими областями действия.
