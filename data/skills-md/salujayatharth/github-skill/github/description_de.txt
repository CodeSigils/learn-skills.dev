Vollständige GitHub-Integration für Repositories, Issues, PRs, Workflows und Sicherheit. Verwendung bei der Arbeit mit GitHub: (1) Repository-Vorgänge – Dateien, Zweige abrufen/erstellen, Code suchen, (2) Problemverwaltung – Probleme auflisten, erstellen, aktualisieren, kommentieren, (3) Pull-Requests – PRs erstellen, überprüfen, zusammenführen, CI-Status prüfen, (4) GitHub-Aktionen – Arbeitsabläufe auflisten, Ausführungen anzeigen, Protokolle herunterladen, Arbeitsabläufe auslösen, (5) Codesicherheit – Dependabot-Warnungen, Code-Scannen, geheimes Scannen. Erfordert die Umgebungsvariable GITHUB_TOKEN mit entsprechenden Bereichen.
