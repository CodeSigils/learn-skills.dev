تكامل GitHub الكامل للمستودعات والمشكلات والعلاقات العامة وسير العمل والأمان. يُستخدم عند العمل مع GitHub: (1) عمليات المستودع - الحصول على/إنشاء الملفات والفروع ورمز البحث، (2) إدارة المشكلات - قائمة المشكلات وإنشاءها وتحديثها والتعليق عليها، (3) طلبات السحب - إنشاء ومراجعة ودمج العلاقات العامة والتحقق من حالة CI، (4) إجراءات GitHub - قائمة سير العمل، وعمليات العرض، وتنزيل السجلات، وتشغيل سير العمل، (5) أمان الكود - تنبيهات Dependabot، ومسح الكود، والمسح السري. يتطلب متغير البيئة GITHUB_TOKEN مع النطاقات المناسبة.
