리포지토리, 이슈, PR, 워크플로 및 보안을 위한 완전한 GitHub 통합입니다. GitHub 작업 시 사용: (1) 리포지토리 작업 - 파일 가져오기/생성, 분기, 코드 검색, (2) 문제 관리 - 목록 작성, 생성, 업데이트, 문제에 대한 설명, (3) 끌어오기 요청 - PR 생성, 검토, 병합, CI 상태 확인, (4) GitHub Actions - 워크플로 나열, 실행 보기, 로그 다운로드, 워크플로 트리거, (5) 코드 보안 - 종속봇 경고, 코드 검색, 비밀 검색. 적절한 범위의 GITHUB_TOKEN 환경 변수가 필요합니다.
