Integración completa de GitHub para repositorios, incidencias, relaciones públicas, flujos de trabajo y seguridad. Úselo cuando trabaje con GitHub: (1) Operaciones de repositorio: obtener/crear archivos, ramas, código de búsqueda, (2) Gestión de problemas: enumerar, crear, actualizar, comentar problemas, (3) Solicitudes de extracción: crear, revisar, fusionar relaciones públicas, verificar el estado de CI, (4) Acciones de GitHub: enumerar flujos de trabajo, ver ejecuciones, descargar registros, activar flujos de trabajo, (5) Seguridad de código: alertas de Dependabot, escaneo de código, escaneo secreto. Requiere la variable de entorno GITHUB_TOKEN con alcances adecuados.
