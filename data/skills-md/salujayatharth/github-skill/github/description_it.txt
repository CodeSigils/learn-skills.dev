Integrazione completa di GitHub per repository, problemi, PR, flussi di lavoro e sicurezza. Da utilizzare quando si lavora con GitHub: (1) Operazioni repository: ottieni/crea file, rami, codice di ricerca, (2) Gestione problemi: elenca, crea, aggiorna, commenta i problemi, (3) Richieste pull: crea, rivedi, unisci PR, controlla lo stato CI, (4) Azioni GitHub: elenca flussi di lavoro, visualizza esecuzioni, scarica registri, attiva flussi di lavoro, (5) Sicurezza del codice: avvisi Dependabot, scansione del codice, scansione segreta. Richiede la variabile di ambiente GITHUB_TOKEN con ambiti appropriati.
