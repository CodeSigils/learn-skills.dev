Rendern Sie eine PR-Diff-Überprüfung als Cursor-Leinwand, die Änderungen nach Wichtigkeit des Prüfers gruppiert, Boilerplate von der Kernlogik trennt und kniffligen oder unerwarteten Code hervorhebt. Verwenden Sie diese Option, wenn Sie eine Pull-Anfrage überprüfen, ein Diff zur Überprüfung zusammenfassen oder wenn der Benutzer nach einem PR-Review-Canvas, einer Diff-Komplettlösung oder einer Änderungssatzübersicht fragt.
