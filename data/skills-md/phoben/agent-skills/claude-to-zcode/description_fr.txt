Lorsque vous devez migrer les configurations d'ingénierie de « .claude », d'un « .zcode » existant ou de « .claude-plugin/.codex-plugin/.zcode-plugin » vers des ressources d'espace de travail ou des packages de plugins conformes à la spécification ZCode, utilisez cette compétence. Il convient pour inventorier automatiquement les sources, comparer les différences dans les « .zcode » existants, migrer les compétences/commandes/hooks/mcp/agents/templates/scripts et gérer les problèmes de compatibilité tels que les manifestes du plugin ZCode, les protocoles hook JSON, les remplacements de commandes et les schémas MCP.
