`.claude`, 기존 `.zcode` 또는 `.claude-plugin/.codex-plugin/.zcode-plugin`의 엔지니어링 구성을 ZCode 사양을 준수하는 작업공간 리소스 또는 플러그인 패키지로 마이그레이션해야 하는 경우 이 기술을 사용하세요. 자동으로 소스 인벤토리를 작성하고, 기존 `.zcode`의 차이점을 비교하고, 기술/명령/후크/mcp/에이전트/템플릿/스크립트를 마이그레이션하고, ZCode 플러그인 매니페스트, 후크 JSON 프로토콜, 명령 재정의 및 MCP 스키마와 같은 호환성 문제를 처리하는 데 적합합니다.
