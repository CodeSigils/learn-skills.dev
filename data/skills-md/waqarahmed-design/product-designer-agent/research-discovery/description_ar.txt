مهارة البحث والاكتشاف في تجربة المستخدم التي تغطي أساليب بحث المستخدم وتوليف البحث. يُستخدم عند التخطيط أو إجراء بحث المستخدم، أو اختبار قابلية الاستخدام، أو اختبار A/B، أو تصميم الاستطلاع، أو تطوير الشخصية، أو رسم خرائط الرحلة، أو رسم خرائط التعاطف، أو التحليل التنافسي، أو البحث الإثنوغرافي، أو تفسير التحليلات. استخدمه أيضًا عند تجميع نتائج البحث من خلال رسم خرائط التقارب، أو توليد الرؤى، أو مقابلات أصحاب المصلحة، أو إطار المهام التي سيتم إنجازها، أو التقييم الإرشادي. محفزات على: بحث المستخدم، اختبار قابلية الاستخدام، دليل المقابلة، خطة البحث، الشخصية، خريطة الرحلة، خريطة التعاطف، التحليل التنافسي، اختبار أ/ب، المسح، التحليلات، خريطة التقارب، توليف الرؤية، التقييم الإرشادي، JTBD.
