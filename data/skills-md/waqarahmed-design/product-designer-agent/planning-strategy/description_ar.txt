تخطيط تصميم المنتج ومهارة الإستراتيجية التي تغطي إستراتيجية المنتج وهندسة المعلومات وتخطيط المشروع. يُستخدم عند تحديد المشكلات، أو تقييم الفرص، أو تحديد أولويات الميزات، أو تخطيط خرائط الطريق، أو تحديد مقاييس النجاح، أو تصميم عروض القيمة، أو هيكلة المحتوى أو التنقل، أو تصميم أنظمة البحث أو التصنيف، أو تحديد نطاق أعمال التصميم، أو تسهيل دورات التصميم السريعة أو ورش العمل، أو تقييم مخاطر التصميم. المشغلات على: تعريف المشكلة، تقييم الفرص، تحديد أولويات الميزات، RICE، MoSCoW، Kano، خريطة الطريق، مؤشرات الأداء الرئيسية، مقاييس النجاح، عرض القيمة، هندسة المعلومات، خريطة الموقع، استراتيجية المحتوى، التصنيف، تصميم التنقل، تصميم البحث، النموذج العقلي، تحديد نطاق التصميم، سباق التصميم، تيسير ورشة العمل، تقييم المخاطر، تخطيط الموارد.
