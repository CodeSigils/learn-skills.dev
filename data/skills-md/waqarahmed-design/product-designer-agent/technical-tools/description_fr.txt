Compétences techniques et outils pour les concepteurs de produits couvrant les outils de conception, les connaissances frontales, la collaboration conception-développement et les technologies émergentes. À utiliser lorsque vous travaillez avec Figma, Sketch, Adobe XD, Framer, ProtoPie ou After Effects. Également pour les sujets front-end (HTML/CSS, flexbox, grille, animations CSS, JavaScript, React/Vue/Angular, transfert de conception vers code, DevTools), la collaboration conception-développement (Git, API Figma, jetons de conception, Storybook, bibliothèques de composants, assurance qualité de conception) ou les technologies émergentes (AR/VR, interfaces vocales, fonctionnalités AI/ML, contrôle gestuel). Déclencheurs sur : Figma, Sketch, Adobe XD, Framer, ProtoPie, After Effects, outil de conception, HTML, CSS, flexbox, grille, réactif, animation CSS, JavaScript, React, Vue, Angular, transfert de conception, DevTools, Git, API Figma, Storybook, bibliothèque de composants, assurance qualité de la conception, conception AR, conception VR, interface vocale, conception de fonctionnalités IA, contrôle gestuel.
