يغطي تصميم تجربة المستخدم التصميم التفاعلي والإطار السلكي والنماذج الأولية وسهولة الاستخدام وإمكانية الوصول والتصميم سريع الاستجابة. يُستخدم عند تصميم تدفقات المستخدم، أو تدفقات المهام، أو تصميم الحالة، أو حالات الحافة، أو الكشف التدريجي، أو الإمكانيات، أو التعليقات، أو النسخة المصغرة. أيضًا للإطارات السلكية، أو النماذج الأولية التفاعلية، أو امتثال WCAG، أو التنقل عبر لوحة المفاتيح، أو قارئات الشاشة، أو تباين الألوان، أو إدارة التركيز، أو الحمل المعرفي، أو منع الأخطاء، أو التصميم سريع الاستجابة والتكيف (الجوال أولاً، نقاط التوقف، أهداف اللمس، أنماط النظام الأساسي). المشغلات على: تدفق المستخدم، تدفق المهام، تصميم الحالة، الحالة الفارغة، حالة الحافة، الكشف التدريجي، القدرة على تحمل التكاليف، التعليقات، النسخ المصغر، الإطار السلكي، النموذج الأولي، WCAG، إمكانية الوصول، التنقل عبر لوحة المفاتيح، قارئ الشاشة، تباين الألوان، التركيز، التصميم الشامل، الحمل المعرفي، معالجة الأخطاء، الهاتف المحمول أولاً، نقاط التوقف، هدف اللمس، التخطيط سريع الاستجابة، iOS، Android، عبر الأجهزة.
