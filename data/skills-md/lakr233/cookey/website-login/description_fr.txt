À utiliser chaque fois que l'utilisateur a besoin de se connecter à un site Web sur son téléphone et de réutiliser cette session authentifiée localement, en particulier pour Playwright storageState JSON, les cookies/localStorage capture, MFA, les codes SMS, les clés d'accès ou les flux de connexion mobiles d'abord qui sont gênants dans l'automatisation sans tête. Vous exécutez Cookey CLI dans votre environnement actuel ; l'utilisateur se connecte sur son iPhone dans l'application Cookey ; le relais transporte uniquement des blobs chiffrés. Se déclenche même si l'utilisateur demande plus librement de l'aide pour se connecter, réutiliser un état de navigateur authentifié, exporter des cookies ou obtenir une session d'automatisation locale à partir d'une connexion téléphonique.
