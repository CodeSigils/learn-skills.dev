從任何即時 URL（包括受 CSP 保護的生產和暫存網站）捕獲 UI 錯誤，並將其直接注入到 Claude Code 上下文中，並且零手動步驟。當使用者說出類似以下內容時觸發：“讓我向您展示錯誤”、“我想指出問題”、“捕獲暫存時出現的問題”、“向您展示 UI 問題”、“對生產中的問題進行屏幕截圖”、“拖動並選擇問題”、“對該頁面進行錯誤截圖”，或者想要在正在運行的站點上直觀地顯示 UI 問題的任何變體。透過 Playwright 打開一個真實可見的 Chrome 窗口，用戶拖曳以選擇損壞的區域，對其進行描述，點擊發送 - 螢幕截圖和結構化報告立即到達 Claude Code。沒有書籤，沒有擴展，沒有複製貼上。適用於每個 URL，包括具有嚴格內容安全策略的網站。
