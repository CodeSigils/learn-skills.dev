从任何实时 URL（包括受 CSP 保护的生产和暂存站点）捕获 UI 错误，并将其直接注入到 Claude Code 上下文中，并且零手动步骤。当用户说出类似以下内容时触发：“让我向您展示错误”、“我想指出问题”、“捕获暂存时出现的问题”、“向您展示 UI 问题”、“对生产中的问题进行屏幕截图”、“拖动并选择问题”、“对该页面进行错误截图”，或者想要在正在运行的站点上直观地显示 UI 问题的任何变体。通过 Playwright 打开一个真实可见的 Chrome 窗口，用户拖动以选择损坏的区域，对其进行描述，点击发送 - 屏幕截图和结构化报告立即到达 Claude Code。没有书签，没有扩展，没有复制粘贴。适用于每个 URL，包括具有严格内容安全策略的网站。
