CSP로 보호되는 프로덕션 및 스테이징 사이트를 포함한 모든 라이브 URL에서 UI 버그를 캡처하고 수동 단계 없이 Claude Code 컨텍스트에 직접 삽입합니다. 사용자가 "버그를 보여드리겠습니다", "문제를 지적하고 싶습니다", "스테이징에서 손상된 부분 캡처", "UI 문제 표시", "프로덕션 문제 스크린샷", "문제를 드래그하여 선택", "이 페이지 버그샷" 또는 실행 중인 사이트에서 UI 문제를 시각적으로 표시하려는 변형과 같은 말을 하면 트리거됩니다. Playwright를 통해 실제로 보이는 Chrome 창을 열고, 사용자가 드래그하여 깨진 영역을 선택하고, 설명하고, 보내기를 누르십시오. 스크린샷과 구조화된 보고서가 Claude Code에 즉시 도착합니다. 북마크릿도 없고, 확장자도 없고, 복사하여 붙여넣을 수도 없습니다. 엄격한 콘텐츠 보안 정책이 적용되는 사이트를 포함한 모든 URL에서 작동합니다.
