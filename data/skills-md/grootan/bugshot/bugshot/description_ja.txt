CSP で保護された運用サイトやステージング サイトを含む、あらゆるライブ URL から UI バグをキャプチャし、手動ステップなしでクロード コード コンテキストに直接挿入します。ユーザーが「バグを見せてください」、「問題を指摘したい」、「ステージングで何が壊れているのかをキャプチャしてください」、「UI の問題を見せてください」、「本番環境で問題をスクリーンショットしてください」、「問題をドラッグして選択してください」、「このページのバグショットを撮ってください」、または実行中のサイトで UI の問題を視覚的に示したいというバリエーションをユーザーが言ったときにトリガーされます。 Playwright 経由で実際に表示される Chrome ウィンドウを開き、ユーザーがドラッグして壊れた領域を選択し、説明し、[送信] をクリックします。スクリーンショットと構造化されたレポートが即座に Claude Code に届きます。ブックマークレット、拡張子、コピー＆ペーストは不要です。厳格なコンテンツ セキュリティ ポリシーを持つサイトを含むすべての URL で動作します。
