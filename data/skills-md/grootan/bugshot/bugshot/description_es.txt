Capture un error de interfaz de usuario desde cualquier URL activa, incluidos los sitios de producción y ensayo protegidos por CSP, e inyéctelo directamente en el contexto de Claude Code sin pasos manuales. Se activa cuando el usuario dice algo como: "déjame mostrarte el error", "Quiero señalar el problema", "capturar lo que está roto en la preparación", "mostrar el problema de la interfaz de usuario", "captura de pantalla del problema en producción", "arrastrar y seleccionar el problema", "capturar el error de esta página" o cualquier variación de querer mostrar visualmente un problema de la interfaz de usuario en un sitio en ejecución. Abre una ventana de Chrome realmente visible a través de Playwright, el usuario arrastra para seleccionar el área rota, la describe, presiona Enviar: la captura de pantalla y el informe estructurado llegan a Claude Code al instante. Sin bookmarklet, sin extensión, sin copiar y pegar. Funciona en todas las URL, incluidos los sitios con una estricta política de seguridad de contenido.
