Erfassen Sie einen UI-Fehler von jeder Live-URL – einschließlich CSP-geschützter Produktions- und Staging-Sites – und fügen Sie ihn ohne manuelle Schritte direkt in den Claude Code-Kontext ein. Wird ausgelöst, wenn der Benutzer etwas sagt wie: „Lassen Sie mich Ihnen den Fehler zeigen“, „Ich möchte auf das Problem hinweisen“, „Erfassen Sie, was beim Staging kaputt ist“, „Zeigen Sie Ihnen das UI-Problem“, „Screenshot des Problems in der Produktion“, „Ziehen Sie das Problem und wählen Sie es aus“, „Fehler auf dieser Seite erstellen“ oder eine beliebige Variante des Wunsches, ein UI-Problem auf einer laufenden Site visuell anzuzeigen. Öffnet über Playwright ein echtes sichtbares Chrome-Fenster, der Benutzer zieht, um den defekten Bereich auszuwählen, beschreibt ihn, klickt auf Senden – Screenshot und strukturierter Bericht kommen sofort in Claude Code an. Kein Bookmarklet, keine Erweiterung, kein Kopieren und Einfügen. Funktioniert auf jeder URL, einschließlich Websites mit strengen Inhaltssicherheitsrichtlinien.
