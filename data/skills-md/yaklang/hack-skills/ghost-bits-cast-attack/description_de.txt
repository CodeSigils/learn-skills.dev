Java „Ghost Bits“ / Cast Attack-Playbook (Black Hat Asia 2026). Wird beim Angriff auf Java-Dienste verwendet, bei denen 16-Bit-Zeichen stillschweigend auf 8-Bit-Byte beschränkt werden, um WAF/IDS für SQL-Injection, Deserialisierungs-RCE, Datei-Upload (Webshell), Pfaddurchquerung, CRLF-Injection, Anforderungsschmuggel und SMTP-Injection zu umgehen. Betrifft Tomcat, Spring, Jetty, Undertow, Vert.x, Jackson, Fastjson, Apache Commons BCEL, Apache HttpClient, Angus Mail, JDK HttpServer, Lettuce, Jodd, XMLWriter und aktiviert viele „gepatchte“ CVEs durch WAF-Umgehung wieder.
