Пособие по Java «Ghost Bits» / Cast Attack (Black Hat Asia, 2026). Используйте при атаке на службы Java, где 16-битный символ незаметно сужается до 8-битного байта для обхода WAF/IDS для внедрения SQL, десериализации RCE, загрузки файлов (веб-оболочка), обхода пути, внедрения CRLF, контрабанды запросов и внедрения SMTP. Влияет на Tomcat, Spring, Jetty, Undertow, Vert.x, Jackson, Fastjson, Apache Commons BCEL, Apache HttpClient, Angus Mail, JDK HttpServer, Lettuce, Jodd, XMLWriter и повторно включает многие «исправленные» CVE через обход WAF.
