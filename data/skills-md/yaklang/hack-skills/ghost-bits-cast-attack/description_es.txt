Libro de jugadas de Java "Ghost Bits" / Cast Attack (Black Hat Asia 2026). Úselo al atacar servicios Java donde el carácter de 16 bits se reduce silenciosamente a bytes de 8 bits para omitir WAF/IDS para inyección SQL, deserialización RCE, carga de archivos (Webshell), recorrido de ruta, inyección CRLF, contrabando de solicitudes e inyección SMTP. Afecta a Tomcat, Spring, Jetty, Undertow, Vert.x, Jackson, Fastjson, Apache Commons BCEL, Apache HttpClient, Angus Mail, JDK HttpServer, Lettuce, Jodd, XMLWriter y vuelve a habilitar muchos CVE "parcheados" a través de la omisión de WAF.
