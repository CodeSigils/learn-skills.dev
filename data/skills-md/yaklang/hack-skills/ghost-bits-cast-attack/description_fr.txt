Livre de jeu Java "Ghost Bits" / Cast Attack (Black Hat Asia 2026). À utiliser lors de l'attaque de services Java où les caractères 16 bits sont réduits silencieusement à 8 bits pour contourner WAF/IDS pour l'injection SQL, la désérialisation RCE, le téléchargement de fichiers (Webshell), la traversée de chemin, l'injection CRLF, la contrebande de requêtes et l'injection SMTP. Affecte Tomcat, Spring, Jetty, Undertow, Vert.x, Jackson, Fastjson, Apache Commons BCEL, Apache HttpClient, Angus Mail, JDK HttpServer, Lettuce, Jodd, XMLWriter et réactive de nombreux CVE « corrigés » via le contournement WAF.
