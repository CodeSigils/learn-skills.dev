Playbook Java "Ghost Bits" / Cast Attack (Black Hat Asia 2026). Da utilizzare quando si attaccano servizi Java in cui il carattere a 16 bit viene ridotto silenziosamente a byte a 8 bit per bypassare WAF/IDS per SQL injection, deserializzazione RCE, caricamento di file (Webshell), path traversal, CRLF injection, request smuggling e SMTP injection. Interessa Tomcat, Spring, Jetty, Undertow, Vert.x, Jackson, Fastjson, Apache Commons BCEL, Apache HttpClient, Angus Mail, JDK HttpServer, Lettuce, Jodd, XMLWriter e riattiva molti CVE "patchati" tramite il bypass WAF.
