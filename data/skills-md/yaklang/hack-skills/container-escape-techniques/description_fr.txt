Livre de jeu d'évasion de conteneur. À utiliser lorsque vous travaillez à l'intérieur d'un conteneur Docker, d'un pod LXC ou Kubernetes et que vous devez vous échapper vers l'hôte via le mode privilégié, les fonctionnalités, le socket Docker, l'abus de groupe de contrôle, les astuces d'espace de noms ou les vulnérabilités d'exécution.
