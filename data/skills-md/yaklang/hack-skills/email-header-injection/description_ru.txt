Руководство по внедрению заголовков электронной почты и подмене. Используйте при тестировании контактных форм, API электронной почты, потоков сброса пароля или любой функции, которая создает сообщения SMTP с полями, управляемыми пользователем. Охватывает внедрение CRLF в заголовки, обход SPF/DKIM/DMARC и усиление фишинга.
