Руководство по внедрению заголовка HTTP-хоста и злоупотреблениям маршрутизацией. Используйте, когда приложение доверяет заголовку Host для создания URL-адресов, запросов маршрутизации или контроля доступа — включение отравления при сбросе пароля, отравления веб-кэша, SSRF через маршрутизацию и обхода виртуального хоста.
