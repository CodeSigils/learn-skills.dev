Manual de estrategias de abuso de enrutamiento y inyección de encabezados de host HTTP. Úselo cuando la aplicación confía en el encabezado del Host para generar URL, solicitudes de enrutamiento o control de acceso, lo que permite el envenenamiento por restablecimiento de contraseña, envenenamiento de caché web, SSRF mediante enrutamiento y omisión de host virtual.
