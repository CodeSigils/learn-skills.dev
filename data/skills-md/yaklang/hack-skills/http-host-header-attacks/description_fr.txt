Manuel d'injection d'en-tête d'hôte HTTP et d'abus de routage. À utiliser lorsque l'application fait confiance à l'en-tête Host pour générer des URL, des demandes de routage ou un contrôle d'accès, ce qui permet l'empoisonnement de la réinitialisation du mot de passe, l'empoisonnement du cache Web, SSRF via le routage et le contournement de l'hôte virtuel.
