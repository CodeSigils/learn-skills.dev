Écriture arbitraire dans le playbook RCE. À utiliser lorsque vous disposez d'une primitive d'écriture arbitraire (issue de l'exploitation du tas, d'une chaîne de format ou d'une écriture OOB) et que vous devez la convertir en exécution de code en ciblant GOT, les hooks, la table virtuelle _IO_FILE, exit_funcs, TLS_dtor_list, modprobe_path, .fini_array ou les tables virtuelles C++.
