Руководство по атаке с перепривязкой DNS. Используйте при тестировании приложений, которые доверяют разрешению DNS для проверки происхождения, взаимодействуют с внутренними службами из контекста браузера или когда SSRF невозможен на стороне сервера, но цель имеет выборку на стороне клиента/XHR для доменов, контролируемых злоумышленником.
