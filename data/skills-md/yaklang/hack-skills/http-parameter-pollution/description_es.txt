Contaminación de parámetros HTTP (HPP): claves de cuerpo/consulta duplicadas analizadas de manera diferente por servidores, proxies, WAF y marcos de aplicaciones. Úselo cuando los filtros y las capas de aplicación no estén de acuerdo sobre qué valor gana, lo que permite omitir, segunda URL SSRF, abuso de lógica o confusión de token CSRF.
