Playbook d'injection de balisage en suspens. À utiliser lorsque l'injection HTML est possible mais que l'exécution de JavaScript est bloquée (CSP, gestionnaires d'événements de suppression de désinfectant, WAF bloque les balises de script) : exfiltrez les jetons CSRF, les données de session et le contenu de la page en injectant des balises HTML non fermées qui capturent le contenu de la page suivante.
