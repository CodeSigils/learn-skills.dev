Manual de estrategias de inyección de marcado colgante. Úselo cuando sea posible la inyección de HTML pero la ejecución de JavaScript esté bloqueada (CSP, controladores de eventos de tiras desinfectantes, WAF bloquea etiquetas de script): extraiga tokens CSRF, datos de sesión y contenido de la página inyectando etiquetas HTML abiertas que capturan el contenido de la página posterior.
