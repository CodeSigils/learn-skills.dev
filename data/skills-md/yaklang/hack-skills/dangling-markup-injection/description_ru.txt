Пособие по внедрению висячей разметки. Используйте, когда внедрение HTML возможно, но выполнение JavaScript заблокировано (CSP, обработчики событий дезинфицирующих полос, WAF блокирует теги сценариев) — извлекайте токены CSRF, данные сеанса и содержимое страницы, внедряя незакрытые теги HTML, которые фиксируют последующее содержимое страницы.
