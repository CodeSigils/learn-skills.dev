Yakit の右クリック プラグイン (コーデック プラグイン) の使用法とプログラミングのヒント。コーデック プラグインには単一のハンドル (入力) 関数のみが必要であると説明されています。プラグインのタイプコードと「パケット右クリック用」スイッチ (タグ:allow-custom-context-menu-execute) を組み合わせると、HTTP エディターの右クリック メニューに表示されます。また、フロー ID と等しい履歴の右クリック (単一または複数選択) の特別な契約もカバーしています (ayakit.SetProgress プログレス バーと DBYieldchannel を使用して、ID によるパケットの逆引きを可能にし、ホストの完全なパス/パラメータ名を抽出できます)。コーデック プラグインは CLI パラメータとスタックして、ドロップダウン選択 (パス/パラメータ名/Cookie の抽出) を提供できます。Web Fuzzer の選択では「奇妙な変換」を実行でき、heak codec-plugin コマンドで検証する方法が示されています。ユーザーが「右クリック プラグインの書き方 / コーデック プラグインの使い方 / 履歴右クリックでデータを抽出する方法 / Web Fuzzer 右クリックで変換する方法 / パラメータ付きコーデック」を質問する場合に使用します。右クリックのプラグインは、小さなツールを開発するための最も速い方法です。
