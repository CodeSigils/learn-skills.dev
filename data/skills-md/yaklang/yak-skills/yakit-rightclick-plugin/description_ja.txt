Yakit の右クリック プラグイン (コーデック プラグイン) の使用法とプログラミングのヒント。コーデック プラグインには「handle(input)」関数のみが必要であると説明されています。プラグイン タイプ「コーデック」と「パケット右クリック」スイッチ (tag:allow‑custom‑context‑menu‑execute) を組み合わせると、HTTP エディタの右クリック メニューに表示されます。また、履歴の右クリック (単一選択または複数選択) の特別な契約についても説明します。ここでは、「input = flow id」です。この ID を使用して、パケットを検索し、ホスト、すべてのパス、パラメータ名を抽出することができます。これには、「yakit.SetProgress」プログレス バーと DB イールド チャネルが含まれます。コーデック プラグインは、ドロップダウン選択 (パス/パラメーター名/Cookie の抽出) の CLI パラメーターをオーバーレイでき、Web Fuzzer の選択は「奇数の変換」を実行でき、「yak codec-plugin」 コマンドで検証する方法を示しています。これは、ユーザーが「右クリック プラグインの書き方 / コーデック プラグインの使用方法 / 履歴の右クリック データ抽出 / Web Fuzzer の右クリック変換 / パラメータ付きコーデック」を尋ねたときに使用します。右クリックのプラグインは、小さなツールを作成する最も速い方法です。
