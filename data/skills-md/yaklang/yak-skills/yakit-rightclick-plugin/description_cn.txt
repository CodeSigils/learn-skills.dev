Yakit右键插件（编解码器插件）使用和编程技巧。它解释了编解码器插件只需要一个单句柄（输入）函数；与插件 typecodec 和“数据包右键单击”开关（标签：allow-custom-context-menu-execute）相结合，它将出现在任何 HTTP 编辑器的右键单击菜单中。它还涵盖历史右键单击（单选或多选）的特殊约定，其中输入等于流 ID（允许通过 ID 反向查找数据包以提取主机的完整路径/参数名称，使用 ayakit.SetProgress 进度条和 DBYield 通道）。编解码器插件可以与 CLI 参数堆叠以提供下拉选择（提取路径/参数名称/Cookie），Web Fuzzer 选择可以执行“奇怪的转换”，并且它展示了如何使用 yak 编解码器插件命令进行验证。当用户询问“如何编写右键单击插件/如何使用编解码器插件/如何通过历史右键单击提取数据/如何使用 Web Fuzzer 右键单击​​/带参数的编解码器进行转换”时，请使用此选项。右键单击插件是开发小型工具的最快方法。
