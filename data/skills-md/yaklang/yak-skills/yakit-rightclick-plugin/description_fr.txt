Conseils d'utilisation et de programmation des plugins clic droit Yakit (plugins codecs). Il explique qu'un plugin de codec n'a besoin que d'une seule fonction `handle(input)` ; avec le type de plugin **codec** et le commutateur « Utilisé pour le clic droit sur les paquets » (balise : `allow-custom-context-menu-execute`), il apparaîtra dans le menu contextuel de n'importe quel éditeur HTTP. Il décrit également le contrat spécial pour le clic droit sur l'historique (sélection simple ou multiple) où « input = flow id » (l'ID peut être utilisé pour effectuer une recherche inversée du paquet et extraire les noms complets de chemin/paramètre de l'hôte, avec une barre de progression « yakit.SetProgress » et un canal DB Yield). Le plugin codec peut superposer les paramètres CLI pour fournir une sélection déroulante (extraire le chemin/noms des paramètres/Cookie), la sélection Web Fuzzer peut effectuer des « transformations étranges » et montre comment vérifier avec la commande « yak codec-plugin ». Utilisez-le lorsque les utilisateurs demandent « Comment écrire un plugin de clic droit / Comment utiliser un plugin de codec / Comment extraire des données de l'historique, clic droit / Comment transformer avec Web Fuzzer, clic droit / Codec avec paramètres ». Les plugins par clic droit sont le moyen le plus rapide de créer de petits outils.
