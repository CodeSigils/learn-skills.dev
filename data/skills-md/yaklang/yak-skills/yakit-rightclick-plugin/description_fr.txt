Conseils d'utilisation et de programmation des plugins Yakit par clic droit (plugins de codec). Il explique qu'un plugin de codec n'a besoin que d'une fonction singlehandle(input) ; combiné avec le type de plugin codec et le commutateur « pour le clic droit du paquet » (tag:allow-custom-context-menu-execute), il apparaîtra dans le menu contextuel de n'importe quel éditeur HTTP. Il couvre également le contrat spécial pour le clic droit sur l'historique (sélection simple ou multiple) dans lequel pute est égal à l'ID de flux (permettant une recherche inversée du paquet par ID pour extraire les noms complets de chemin/paramètre de l'hôte, avec la barre de progression ayakit.SetProgress et un DBYieldchannel). Le plugin de codec peut être empilé avec des paramètres CLI pour fournir une sélection déroulante (chemin d'extraction/nom du paramètre/cookie), la sélection Web Fuzzer peut effectuer des « transformations étranges » et montre comment vérifier avec la commande du plugin de codec. Utilisez-le lorsque les utilisateurs demandent « comment écrire un plugin de clic droit / comment utiliser un plugin de codec / comment extraire des données avec un clic droit sur l'historique / comment transformer avec un clic droit de Web Fuzzer / un codec avec des paramètres ». Les plugins clic droit sont le moyen le plus rapide de développer de petits outils.
