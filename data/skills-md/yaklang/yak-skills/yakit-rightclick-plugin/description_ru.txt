Советы по использованию и программированию плагинов Yakit, вызываемых правой кнопкой мыши (плагины кодеков). В нем объясняется, что плагину кодека нужна только функция одиночного дескриптора (входа); в сочетании с плагином typecodec и переключателем «для пакета правой кнопкой мыши» (tag:allow-custom-context-menu-execute) он появится в контекстном меню любого HTTP-редактора. Он также охватывает специальный контракт для щелчка правой кнопкой мыши по истории (одиночный или множественный выбор), в котором put соответствует идентификатору потока (позволяет обратный поиск пакета по идентификатору для извлечения полного пути/имена параметров хоста с помощью панели ayakit.SetProgressprogress и канала DBYieldchannel). Плагин кодека можно объединить с параметрами CLI, чтобы обеспечить выбор в раскрывающемся списке (извлечь путь/имя параметра/Cookie), выбор Web Fuzzer может выполнять «странные преобразования», и он показывает, как проверить с помощью команды Theyak codec‑plugin. Используйте это, когда пользователи спрашивают: «Как написать плагин для щелчка правой кнопкой мыши / как использовать плагин для кодека / как извлечь данные с помощью щелчка правой кнопкой мыши по истории / как преобразовать с помощью щелчка правой кнопкой мыши с помощью Web Fuzzer / кодек с параметрами». Плагины, вызываемые правой кнопкой мыши, — это самый быстрый способ разработки небольших инструментов.
