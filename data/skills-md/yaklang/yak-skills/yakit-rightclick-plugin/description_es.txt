Consejos de programación y uso de complementos de clic derecho de Yakit (complementos de códec). Explica que un complemento de códec solo necesita una función de control único (entrada); combinado con el código de tipo del complemento y el interruptor “para hacer clic derecho en el paquete” (etiqueta: permitir-ejecutar-menú-contextual-personalizado), aparecerá en el menú contextual de cualquier editor HTTP. También cubre el contrato especial para el clic derecho en Historial (selección única o múltiple) en el que la computadora es igual al ID del flujo (lo que permite la búsqueda inversa del paquete por ID para extraer los nombres completos de la ruta/parámetro del host, con la barra de progreso ayakit.SetProgress y un canal DBYield). El complemento de códec se puede apilar con parámetros CLI para proporcionar una selección desplegable (ruta de extracción/nombre de parámetro/cookie), la selección de Web Fuzzer puede realizar "transformaciones extrañas" y muestra cómo verificar con el comando de complemento de códec. Utilícelo cuando los usuarios pregunten "cómo escribir un complemento de clic derecho / cómo usar un complemento de códec / cómo extraer datos con el clic derecho de Historial / cómo transformar con el clic derecho de Web Fuzzer / códec con parámetros". Los complementos de clic derecho son la forma más rápida de desarrollar pequeñas herramientas.
