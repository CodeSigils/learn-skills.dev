Consejos de uso y programación para complementos de clic derecho de Yakit (complementos de códec). Explica que un complemento de códec solo necesita una única función `handle(input)`; combinado con el tipo de complemento "códec" y el interruptor "Habilitar para clic derecho en paquetes" (etiqueta: "permitir-menú-contextual-personalizado-ejecutar"), aparecerá en el menú contextual de cualquier editor HTTP. También cubre el contrato especial para el clic derecho en Historial (selección única o múltiple) donde `entrada = id de flujo`; el ID se puede usar para buscar el paquete y extraer el host, todas las rutas y los nombres de los parámetros, con una barra de progreso `yakit.SetProgress` y un canal de rendimiento de la base de datos. El complemento de códec puede superponer los parámetros de CLI para proporcionar una selección desplegable (ruta de extracción/nombre de parámetro/cookie), la selección de Web Fuzzer puede realizar "transformaciones extrañas" y cómo verificar con el comando `yak codec-plugin`. Utilícelo cuando los usuarios pregunten "cómo escribir un complemento de clic derecho/cómo usar un complemento de códec/cómo extraer datos del Historial de clic derecho/cómo transformar con Web Fuzzer clic derecho/códec con parámetros". Los complementos de clic derecho son la forma más rápida de desarrollar pequeñas herramientas.
