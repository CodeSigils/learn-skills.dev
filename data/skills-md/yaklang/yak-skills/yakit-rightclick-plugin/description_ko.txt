Yakit 마우스 오른쪽 버튼 클릭 플러그인(코덱 플러그인) 사용법 및 프로그래밍 팁. 코덱 플러그인에는 `handle(input)` 기능만 필요하다고 설명합니다. 플러그인 유형 "코덱" 및 "패킷 오른쪽 클릭의 경우" 스위치(태그: `allow-custom-context-menu-execute`)와 결합하면 모든 HTTP 편집기의 오른쪽 클릭 메뉴에 나타납니다. 또한 '입력 = 흐름 ID'('yakit.SetProgress' 진행률 표시줄 및 DB Yield 채널을 사용하여 패킷을 조회하고 호스트, 모든 경로 및 매개변수 이름을 추출하는 데 ID를 사용할 수 있음), 드롭다운 선택(경로/매개변수 이름/쿠키 추출)을 생성하기 위해 CLI 매개변수를 스택하는 코덱 플러그인, "이상한 변환"을 수행하기 위한 Web Fuzzer 선택 및 `yak codec-plugin` 명령을 사용하여 확인하는 방법. 사용자가 “마우스 오른쪽 클릭 플러그인 작성 방법 / 코덱 플러그인 사용 방법 / 내역 마우스 오른쪽 클릭 데이터 추출 / 웹 퍼저 마우스 오른쪽 클릭 변환 / 매개변수가 포함된 코덱”을 질문할 때 사용됩니다. 마우스 오른쪽 버튼 클릭 플러그인은 작은 도구를 작성하는 가장 빠른 방법입니다.
