Yakit 마우스 오른쪽 버튼 클릭 플러그인(코덱 플러그인) 사용법 및 프로그래밍 팁. 코덱 플러그인에는 단일 핸들(입력) 기능만 필요하다고 설명합니다. 플러그인 유형 코드와 "패킷 오른쪽 클릭용" 스위치(태그:allow-custom-context-menu-execute)를 결합하면 모든 HTTP 편집기의 오른쪽 클릭 메뉴에 나타납니다. 또한 Put이 흐름 ID와 일치하는 기록 마우스 오른쪽 버튼 클릭(단일 또는 다중 선택)에 대한 특별 계약도 다룹니다(ayakit.SetProgressprogress 막대 및 DBYieldchannel을 사용하여 호스트의 전체 경로/매개변수 이름을 추출하기 위해 ID로 패킷을 역방향 조회할 수 있음). 코덱 플러그인은 CLI 매개변수와 함께 스택되어 드롭다운 선택(경로/매개변수 이름/쿠키 추출)을 제공할 수 있으며, Web Fuzzer 선택은 "이상한 변환"을 수행할 수 있으며, theyak codec-plugin 명령으로 확인하는 방법을 보여줍니다. 사용자가 "마우스 오른쪽 버튼 클릭 플러그인 작성 방법 / 코덱 플러그인 사용 방법 / 히스토리 마우스 오른쪽 버튼 클릭으로 데이터 추출 방법 / Web Fuzzer 마우스 오른쪽 버튼 클릭으로 변환하는 방법 / 매개변수가 있는 코덱"을 질문할 때 사용하세요. 마우스 오른쪽 버튼 클릭 플러그인은 작은 도구를 개발하는 가장 빠른 방법입니다.
