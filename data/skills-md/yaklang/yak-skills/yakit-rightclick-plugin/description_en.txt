Yakit right‑click plugins (codec plugins) usage and programming tips. It explains that a codec plugin only needs a single handle(input) function; combined with the plugin type codec and the switch “for packet right‑click” (tag: allow-custom-context-menu-execute), it will appear in the right‑click menu of any HTTP editor. It also covers the special contract for History right‑click (single or multiple selection) where input equals the flow ID (allowing reverse lookup of the packet by ID to extract the host’s full path/parameter names, with a yakit.SetProgress progress bar and a DB Yield channel). The codec plugin can be stacked with CLI parameters to provide a dropdown selection (extract Path/parameter name/Cookie), the Web Fuzzer selection can perform “strange transformations”, and it shows how to verify with the yak codec‑plugin command. Use this when users ask “how to write a right‑click plugin / how to use a codec plugin / how to extract data with History right‑click / how to transform with Web Fuzzer right‑click / codec with parameters”. Right‑click plugins are the fastest way to develop small tools.
