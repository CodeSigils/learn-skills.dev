Yakit右鍵外掛（編解碼器外掛程式）使用和程式設計技巧。它解釋了編解碼器外掛程式只需要一個單句柄（輸入）函數；與外掛程式 typecodec 和「封包右鍵單擊」開關（標籤：allow-custom-context-menu-execute）相結合，它將出現在任何 HTTP 編輯器的右鍵選單中。它還涵蓋歷史右鍵單擊（單選或多選）的特殊約定，其中輸入等於流 ID（允許透過 ID 反向查找資料包以提取主機的完整路徑/參數名稱，使用 ayakit.SetProgress 進度條和 DBYield 通道）。編解碼器插件可以與 CLI 參數堆疊以提供下拉選擇（提取路徑/參數名稱/Cookie），Web Fuzzer 選擇可以執行“奇怪的轉換”，並且它展示瞭如何使用 yak 編解碼器插件命令進行驗證。當使用者詢問「如何編寫右鍵單擊插件/如何使用編解碼器插件/如何透過歷史右鍵單擊提取資料/如何使用 Web Fuzzer 右鍵單擊/帶參數的編解碼器進行轉換」時，請使用此選項。右鍵單擊外掛程式是開發小型工具最快的方法。
