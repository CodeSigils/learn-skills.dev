Yakit 右鍵外掛（編解碼器外掛程式）的使用和程式設計技巧。它解釋了編解碼器外掛程式只需要一個「handle(input)」函數；與外掛程式類型「codec」和「用於封包右鍵」開關（標籤：「allow-custom-context-menu-execute」）結合，它將出現在任何 HTTP 編輯器的右鍵選單中。它還描述了右鍵單擊歷史記錄（單選或多選）的特殊約定，其中“input = flow id”（可以反向查找 id 以提取資料包的主機、所有路徑和參數名稱，並帶有“yakit.SetProgress”進度條和 DB 收益通道）。編解碼器插件可以與 CLI 參數堆疊以提供下拉選擇（提取路徑/參數名稱/Cookie），Web Fuzzer 選擇區域可以執行“奇怪的轉換”，並且它展示瞭如何使用“yak codec-plugin”命令進行驗證。當使用者詢問「如何編寫右鍵插件/如何使用編解碼器插件/歷史右鍵單擊資料提取/Web Fuzzer右鍵單擊轉換/帶參數的編解碼器」時，會使用此功能。右鍵單擊插件是編寫小工具的最快方法。
