Yakit ネイティブ プラグイン (yak / mitm タイプ) と CLI パラメータ システム。ネイティブ プラグインとホットロード プラグインの違い、cli.* がどのように Yakit の実行ページ (String/Int/Bool/Urls/Ports/StringSlice ドロップダウン/ファイルなど + setRequired / setDefault / setVerboseName / setCliGroup) のパラメータ フォームになるか、および 3 つの優れた例を説明します。CLI を使用してユーザー入力を収集する yak ネイティブ プラグイン。複雑なコンテンツを受動的にスキャンしてリスクを生成する mitm ネイティブ プラグイン。外部パラメータ (キーワード辞書/スコープ) をロードしてスキャンを実行する mitm + CLI インタラクティブ プラグイン。これは、ユーザーが「パラメーター フォームを使用した yak/mitm プラグインの作成方法、CLI の使用方法、mitm プラグインにパッシブ スキャンを実行させる方法」を尋ねたときに使用します。
