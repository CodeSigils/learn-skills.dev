Yakit ネイティブ プラグイン (yak/mitm タイプ) と CLI パラメータ システム。ネイティブ プラグインとホット ロードの違い、cli.* がどのようにして Yakit 実行ページ パラメータ フォーム (String/Int/Bool/Urls/Ports/StringSlice ドロップダウン/ファイルなど + setRequired / setDefault / setVerboseName / setCliGroup) になるかを明確にし、3 つの例を示します。CLI を使用してユーザー入力を収集する yak ネイティブ プラグイン。 mitm ネイティブ プラグインは複雑なコンテンツのパッシブ スキャンを実行し、リスクを生成します。 mitm+CLI 対話型プラグインは外部パラメータ (キーワード辞書/スコープ) をロードしてスキャンを実行します。これは、ユーザーが「パラメーター フォームを使用した yak/mitm プラグインの作成方法、CLI の使用方法、mitm プラグインでパッシブ スキャンを実行する方法」を尋ねたときに使用します。
