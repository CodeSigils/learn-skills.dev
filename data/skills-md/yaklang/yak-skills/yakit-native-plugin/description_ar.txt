مكونات Yakit الأصلية (نوع yak/mitm) ونظام معلمات CLI. توضيح الفرق بين المكونات الإضافية الأصلية والتحميل السريع، وكيف يصبح cli.* نماذج معلمات صفحة تنفيذ Yakit (String/Int/Bool/Urls/Ports/StringSlice المنسدلة/الملف، وما إلى ذلك + setRequired / setDefault / setVerboseName / setCliGroup)، وتقديم ثلاث حالات نموذجية: مكون إضافي أصلي لـ yak يستخدم CLI لجمع مدخلات المستخدم؛ مكون إضافي أصلي لـ mitm يقوم بإجراء فحص سلبي للمحتوى المعقد ويولد المخاطر؛ ويقوم البرنامج الإضافي التفاعلي mitm+CLI بتحميل المعلمات الخارجية (قاموس/نطاق الكلمات الرئيسية) لدفع المسح. استخدم هذا عندما يسأل المستخدم "كيفية كتابة مكونات yak/mitm الإضافية باستخدام نماذج المعلمات، وكيفية استخدام CLI، وكيفية إجراء المسح السلبي باستخدام مكون mitm الإضافي."
