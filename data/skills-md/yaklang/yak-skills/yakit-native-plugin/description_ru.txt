Собственные плагины Yakit (типа yak/mitm) и система параметров CLI. Уточните разницу между собственными плагинами и горячей загрузкой, как cli.* становится формами параметров страницы выполнения Yakit (String/Int/Bool/Urls/Ports/StringSlice раскрывающийся список/File и т. д. + setRequired / setDefault / setVerboseName / setCliGroup), и представьте три примерных случая: собственный плагин yak, использующий CLI для сбора пользовательского ввода; собственный плагин mitm, выполняющий пассивное сканирование сложного контента и генерирующий риски; и интерактивный плагин mitm+CLI, загружающий внешние параметры (словарь/область ключевых слов) для управления сканированием. Используйте это, когда пользователь спрашивает: «Как писать плагины yak/mitm с формами параметров, как использовать CLI, как выполнять пассивное сканирование с помощью плагина mitm».
