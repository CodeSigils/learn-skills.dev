Native Yakit-Plugins (Yak/Mitm-Typ) und das CLI-Parametersystem. Erklären Sie den Unterschied zwischen nativen Plugins und Hot Loading, wie „cli.*“ zur Ausführungsseitenparameterform von Yakit wird (String/Int/Bool/Urls/Ports/StringSlice-Dropdown/Datei usw. plus „setRequired“, „setDefault“, „setVerboseName“, „setCliGroup“) und stellen Sie drei beispielhafte Fälle vor: ein natives Yak-Plugin, das CLI verwendet, um Benutzereingaben zu sammeln; ein natives Mitm-Plugin, das passives Scannen komplexer Inhalte durchführt und Risiken generiert; und ein interaktives Mitm+CLI-Plugin, das externe Parameter (Schlüsselwortwörterbücher/Bereiche) lädt, um das Scannen voranzutreiben. Verwenden Sie dies, wenn ein Benutzer fragt: „Wie schreibt man ein Yak/Mitm-Plugin mit einer Parameterform, wie verwendet man CLI, wie implementiert man passives Scannen in einem Mitm-Plugin?“
