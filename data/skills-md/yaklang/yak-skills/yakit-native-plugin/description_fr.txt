Plugins natifs Yakit (types yak/mitm) et système de paramètres CLI. Clarifiez la différence entre les plugins natifs et le chargement à chaud, comment cli.* devient un formulaire de paramètre sur la page d'exécution de Yakit (String, Int, Bool, Urls, Ports, liste déroulante StringSlice, File, etc., avec setRequired, setDefault, setVerboseName, setCliGroup), et présentez trois excellents exemples : un plugin natif yak utilisant cli pour collecter les entrées de l'utilisateur ; un plugin natif mitm qui analyse passivement le contenu complexe et génère des risques ; et un plugin interactif mitm+cli qui charge des paramètres externes (dictionnaire de mots clés/portée) pour piloter l'analyse. Utilisez-le lorsqu'un utilisateur demande « comment écrire des plugins yak/mitm avec des formulaires de paramètres, comment utiliser cli, comment effectuer une analyse passive avec un plugin mitm ».
