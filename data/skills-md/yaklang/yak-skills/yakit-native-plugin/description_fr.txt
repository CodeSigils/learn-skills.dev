Plugins natifs Yakit (type yak/mitm) et système de paramètres CLI. Clarifiez la différence entre les plugins natifs et le chargement à chaud, comment cli.* devient les formulaires de paramètres de page d'exécution Yakit (String/Int/Bool/Urls/Ports/StringSlice dropdown/File, etc. + setRequired / setDefault / setVerboseName / setCliGroup), et présentez trois cas exemplaires : un plugin natif yak utilisant CLI pour collecter les entrées de l'utilisateur ; un plugin natif mitm effectuant une analyse passive de contenus complexes et générant des risques ; et un plugin interactif mitm+CLI chargeant des paramètres externes (dictionnaire de mots clés/portée) pour piloter l'analyse. Utilisez-le lorsqu'un utilisateur demande « comment écrire des plugins yak/mitm avec des formulaires de paramètres, comment utiliser CLI, comment effectuer une analyse passive avec un plugin mitm ».
