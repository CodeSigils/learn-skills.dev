Complementos nativos de Yakit (tipo yak/mitm) y el sistema de parámetros CLI. Aclare la diferencia entre complementos nativos y complementos cargados en caliente, cómo cli.* se convierte en formularios de parámetros de página de ejecución de Yakit (String/Int/Bool/Urls/Ports/StringSlice dropdown/File, etc.+setRequired / setDefault / setVerboseName / setCliGroup), y tres casos excelentes: un complemento nativo de yak que usa CLI para recopilar información del usuario, un complemento nativo de mitm que escanea pasivamente contenido complejo y genera riesgo, y un complemento interactivo mitm+CLI que carga parámetros externos (diccionario/alcance de palabras clave) para impulsar el escaneo. Utilice esto cuando un usuario pregunte "cómo escribir un complemento yak/mitm con un formulario de parámetro, cómo usar CLI, cómo implementar el escaneo pasivo en un complemento mitm".
