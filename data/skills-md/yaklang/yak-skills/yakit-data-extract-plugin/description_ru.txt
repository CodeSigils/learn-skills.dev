Решите общую практическую проблему: после накопления большого объема трафика для определенного сайта в истории Yakit, как мгновенно получить все уникальные пути по имени домена, получить файл cookie для входа и превратить эти пути в многоразовый словарь полезной нагрузки, а затем использовать сеанс входа в систему для отправки запросов путь за путем для сканирования/фаззинга. В нем рассматривается использование db.QueryHTTPFlowsByKeyword для получения истории, дедупликации URI, извлечения файлов cookie, управления словарем с помощью db.SavePayload/YieldPayload и отправки запросов с состоянием входа через poc.HTTP. Это используется, когда пользователь хочет «извлечь данные из исторического трафика для последующего сканирования».
