Solve a common practical pain point: after accumulating a large amount of traffic for a specific site in Yakit History, how to instantly retrieve all unique paths by domain name, obtain the login cookie, and turn those paths into a reusable payload dictionary, then use the logged‑in session to send requests path by path for scanning/fuzzing. It covers using `db.QueryHTTPFlowsByKeyword` to fetch history, deduplicating URIs, extracting cookies, managing the dictionary with `db.SavePayload`/`YieldPayload`, and sending requests with login state via `poc.HTTP`. This is used when a user wants to “extract data from historical traffic to drive subsequent scans.”
