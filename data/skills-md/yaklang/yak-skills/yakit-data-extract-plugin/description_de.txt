Beheben Sie ein häufiges praktisches Problem: Nachdem sich eine große Menge an Datenverkehr für eine bestimmte Site im Yakit-Verlauf angesammelt hat, wie können Sie alle eindeutigen Pfade nach Domäne mit einem einzigen Klick abrufen, die Anmeldecookies abrufen, diese Pfade in ein wiederverwendbares Nutzlastwörterbuch umwandeln und dann Paketscans/-fuzzing pro Pfad durchführen und dabei die Anmeldesitzung beibehalten? Es umfasst die Verwendung von db.QueryHTTPFlowsByKeyword zum Abrufen des Verlaufs, das Deduplizieren von URIs, das Extrahieren von Cookies, das Verwalten von Nutzlastwörterbüchern über db.SavePayload/YieldPayload und das Senden von Paketen mit Anmeldestatus mithilfe von poc.HTTP. Es wird verwendet, wenn der Benutzer „Daten aus dem historischen Datenverkehr extrahieren möchte, um nachfolgende Scans durchzuführen“.
