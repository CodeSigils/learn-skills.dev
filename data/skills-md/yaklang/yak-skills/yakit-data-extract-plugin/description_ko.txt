일반적인 실제 문제 해결: Yakit History에서 특정 사이트에 대해 대량의 트래픽을 축적한 후, 도메인 이름별로 모든 고유 경로를 즉시 검색하고, 로그인 쿠키를 얻고, 해당 경로를 재사용 가능한 페이로드 사전으로 전환한 다음, 로그인된 세션을 사용하여 검색/퍼징을 위해 경로별로 요청을 보내는 방법. `db.QueryHTTPFlowsByKeyword`를 사용하여 기록 가져오기, URI 중복 제거, 쿠키 추출, `db.SavePayload`/`YieldPayload`를 사용하여 사전 관리, `poc.HTTP`를 통해 로그인 상태와 함께 요청 보내기 등을 다룹니다. 이는 사용자가 "이후 검색을 수행하기 위해 기록 트래픽에서 데이터를 추출"하려는 경우에 사용됩니다.
