일반적인 실제 문제점을 해결합니다. Yakit History에서 특정 사이트에 대해 많은 양의 트래픽을 축적한 후, 한 번의 클릭으로 도메인별로 모든 고유 경로를 검색하고, 로그인 쿠키를 얻고, 이러한 경로를 재사용 가능한 페이로드 사전으로 추출한 다음, 로그인 세션을 유지하면서 각 경로를 스캔/퍼징하는 방법을 해결합니다. 여기에는 db.QueryHTTPFlowsByKeyword를 사용하여 기록 가져오기, URI 중복 제거, 쿠키 추출, db.SavePayload/YieldPayload를 사용한 사전 관리, poc.HTTP를 통해 로그인 상태와 함께 요청 보내기 등이 포함됩니다. 사용자가 "이후 검색을 수행하기 위해 기록 트래픽에서 데이터를 추출"하려는 경우에 사용됩니다.
