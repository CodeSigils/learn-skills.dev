Resuelva un problema práctico común: después de acumular una gran cantidad de tráfico para un sitio en particular en Yakit History, cómo, con un solo clic, recuperar todas las rutas únicas por dominio, obtener la cookie de inicio de sesión y consolidar estas rutas en un diccionario de carga útil reutilizable, luego usar el estado de inicio de sesión para enviar escaneos de paquetes/fuzzing para cada ruta. Esto cubre el uso de db.QueryHTTPFlowsByKeyword para recuperar el historial, deduplicar URI, extraer cookies, administrar el diccionario con db.SavePayload/YieldPayload y enviar paquetes de estado de inicio de sesión a través de poc.HTTP. Se utiliza cuando un usuario desea "extraer datos del tráfico histórico para impulsar el escaneo posterior".
