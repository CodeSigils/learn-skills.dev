Resuelva un problema práctico común: después de acumular una gran cantidad de tráfico para un sitio específico en Yakit History, cómo recuperar instantáneamente todas las rutas únicas por nombre de dominio, obtener la cookie de inicio de sesión y convertir esas rutas en un diccionario de carga útil reutilizable, luego usar la sesión iniciada para enviar solicitudes ruta por ruta para escanear/difuminar. Cubre el uso de `db.QueryHTTPFlowsByKeyword` para obtener el historial, la deduplicación de URI, la extracción de cookies, la administración del diccionario con `db.SavePayload`/`YieldPayload` y el envío de solicitudes con estado de inicio de sesión a través de `poc.HTTP`. Esto se utiliza cuando un usuario desea "extraer datos del tráfico histórico para impulsar análisis posteriores".
