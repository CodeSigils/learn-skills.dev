Yakit Web Fuzzer 핫 리로드(핫 패치) 주제입니다. 이는 사용자가 코드를 사용하여 요청 및 응답을 자동으로 암호화/해독하고, 서명을 삽입하고, 지능형 재시도를 수행하고, 사용자 정의 비즈니스 실패 검사를 정의하고, fuzztag를 사용하여 동적으로 페이로드를 생성하거나, 단일 Web Fuzzer 탭에서 패킷을 보내는 동안 상관 테스트를 위해 응답에서 매개변수를 추출해야 하는 경우에 사용됩니다. beforeRequest/afterRequest/retryHandler/customFailureChecker/mirrorHTTPFlow/mockHTTPRequest 및 {{yak(...)} } fuzztag를 다룹니다.
