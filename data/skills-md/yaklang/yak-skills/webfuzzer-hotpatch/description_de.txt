Thema „Hot-Reload“ (Hot-Patch) von Yakit Web Fuzzer. Es wird verwendet, wenn ein Benutzer Anforderungen und Antworten automatisch mit Code verschlüsseln/entschlüsseln, Signaturen einfügen, intelligente Wiederholungsversuche durchführen, benutzerdefinierte Geschäftsfehlerprüfungen definieren, Nutzlasten mithilfe von Fuzztag dynamisch generieren oder Parameter aus Antworten für Korrelationstests extrahieren muss, während er Pakete in einer einzigen Web-Fuzzer-Registerkarte sendet. Es umfasst beforeRequest/afterRequest/retryHandler/customFailureChecker/mirrorHTTPFlow/mockHTTPRequest und den Fuzztag {{yak(...)} }.
