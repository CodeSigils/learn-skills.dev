Anleitung zum Hot-Reload (Hot Patch) von Yakit Web Fuzzer. Verwenden Sie es, wenn Sie Anfragen und Antworten automatisch mit Code verschlüsseln/entschlüsseln, Signaturen einfügen, intelligente Wiederholungsversuche durchführen, benutzerdefinierte Geschäftsfehlerprüfungen definieren, Nutzlasten mit Fuzztag dynamisch generieren oder Parameter aus Antworten für Korrelationstests extrahieren müssen, während Sie Pakete in einer einzigen Web-Fuzzer-Registerkarte senden. Es umfasst beforeRequest, afterRequest, retryHandler, customFailureChecker, MirrorHTTPFlow, MockHTTPRequest und den Fuzztag {{yak(...)}}.
