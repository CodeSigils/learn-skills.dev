Tema de recarga en caliente (Hot Patch) de Yakit Web Fuzzer. Se utiliza cuando los usuarios necesitan cifrar/descifrar automáticamente datos de solicitud/respuesta con código, inyectar firmas, realizar reintentos inteligentes, definir comprobaciones de fallas comerciales personalizadas, generar cargas útiles dinámicamente usando fuzztag o extraer parámetros de las respuestas para pruebas de correlación mientras envían paquetes en una única pestaña Web Fuzzer. Cubre beforeRequest, afterRequest, retryHandler, customFailureChecker, mirrorHTTPFlow, mockHTTPRequest y {{yak(...)} } fuzztag.
