Tema de recarga en caliente (Hot Patch) de Yakit Web Fuzzer. Se utiliza cuando un usuario necesita cifrar/descifrar automáticamente solicitudes y respuestas con código, inyectar firmas, realizar reintentos inteligentes, definir comprobaciones de fallas comerciales personalizadas, generar cargas útiles dinámicamente usando fuzztag o extraer parámetros de las respuestas para pruebas de correlación mientras envía paquetes en una única pestaña Web Fuzzer. Cubre beforeRequest/afterRequest/retryHandler/customFailureChecker/mirrorHTTPFlow/mockHTTPRequest y el fuzztag {{yak(...)} }.
