Тема «горячей перезагрузки» (Hot Patch) Yakit Web Fuzzer. Он используется, когда пользователю необходимо автоматически шифровать/расшифровывать запросы и ответы с помощью кода, внедрять подписи, выполнять интеллектуальные повторные попытки, определять пользовательские проверки бизнес-сбоев, динамически генерировать полезные данные с помощью fuzztag или извлекать параметры из ответов для корреляционного тестирования при отправке пакетов на одной вкладке Web Fuzzer. Он охватывает beforeRequest/afterRequest/retryHandler/customFailureChecker/mirrorHTTPFlow/mockHTTPRequest и fuzztag {{yak(...)} }.
