Punto de entrada principal y ruta de habilidades de yak. Cuando un usuario quiere realizar programación de Yaklang, carga en caliente de Yak (MITM/Web Fuzzer/global), desarrollo secundario de Yakit o pruebas de MCP, primero determina aquí qué tema de habilidad específico ingresar. Esta página aclara el sistema de carga en caliente de tres capas, las convenciones de depuración YAK_MAIN, el método de prueba go run y enruta las solicitudes a mitm‑hotpatch / webfuzzer‑hotpatch / global‑hotpatch / yaklang‑syntax / yaklang‑database / yakit‑rightclick‑plugin / yaklang‑toolchain / yakit‑data‑extract‑plugin.
