مهارات الياك نقطة الدخول الرئيسية والتوجيه. عندما يريد المستخدم القيام ببرمجة Yaklang، أو تحميل Yak الساخن (MITM / Web Fuzzer / global)، أو تطوير Yakit الثانوي، أو اختبار MCP، فإنه يحدد هنا أولاً موضوع المهارة المحدد الذي سيتم إدخاله. توضح هذه الصفحة نظام التحميل السريع ثلاثي الطبقات، واصطلاحات تصحيح الأخطاء YAK_MAIN، وطريقة اختبار التشغيل، وتوجيه الطلبات إلى mitm‑hotpatch / webfuzzer‑hotpatch / global‑hotpatch / yaklang‑syntax / yaklang‑database / yakit‑rightclick‑plugin / yaklang‑toolchain / yakit-data-extract-plugin.
