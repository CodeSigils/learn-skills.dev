Yaklang ツールチェーンとプラグインの検証ガイド。 Yaklang ソース エンジン (go run common/yak/cmd/yak.go) と 4 つのホットパッチ/コーデック検証コマンド (yak hotpatch-mitm / hotpatch-global / hotpatch-webfuzzer / codec-plugin) を使用してスクリプトを実行する方法が明確に説明されています。実際の gRPC 互換の実行パスを使用して、MITM、グローバル、および Web Fuzzer のホットパッチを検証し、作成したコーデック プラグインを右クリックする方法を示します。また、Yaklang リポジトリのソース コードを活用して MITM の問題を特定してデバッグする方法についても説明します。これは、ユーザーが「プラグインを確認するにはどうすればよいですか? 間違った MITM 動作のトラブルシューティングを行うにはどうすればよいですか?」と尋ねたときに使用します。
