Guía de verificación de complementos y cadenas de herramientas de Yaklang. Explica claramente cómo ejecutar scripts usando el motor fuente de Yaklang (go run common/yak/cmd/yak.go), así como también cómo usar los cuatro comandos de verificación de códec/carga en caliente (yak hotpatch-mitm, hotpatch-global, hotpatch-webfuzzer, codec-plugin) para validar sus cargas en caliente MITM, globales o Web Fuzzer y el complemento de códec de clic derecho a través de una ruta de ejecución real equivalente a gRPC. También cubre cómo aprovechar el código fuente del repositorio de Yaklang para localizar y depurar problemas de MITM. Utilice esto cuando un usuario pregunte: "¿Cómo verifico mi complemento?" o "Mi comportamiento MITM es incorrecto. ¿Cómo soluciono el problema?"
