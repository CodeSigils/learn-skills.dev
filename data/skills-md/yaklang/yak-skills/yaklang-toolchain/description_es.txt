Guía de verificación de complementos y cadena de herramientas de Yaklang. Explica claramente cómo ejecutar scripts usando el motor fuente de Yaklang (go run common/yak/cmd/yak.go), así como los cuatro comandos de verificación de hot-patch/códec (yak hotpatch-mitm / hotpatch-global / hotpatch-webfuzzer / codec-plugin) y cómo usar la ruta de ejecución real de gRPC para verificar los hot-patches MITM / global / Web Fuzzer y los complementos de códec de clic derecho que escribió; también describe cómo aprovechar el código fuente del repositorio de Yaklang para localizar y depurar problemas de MITM. Utilice esto cuando un usuario pregunte "¿Cómo verifico mi complemento/qué debo hacer si el comportamiento de MITM es incorrecto?"
