Guide de vérification de la chaîne d'outils et des plugins Yaklang. Il explique clairement comment exécuter des scripts à l'aide du moteur source Yaklang (allez exécuter common/yak/cmd/yak.go), ainsi que comment utiliser les quatre commandes de vérification de chargement à chaud/codec (yak hotpatch-mitm, hotpatch-global, hotpatch-webfuzzer, codec-plugin) pour valider vos chargements chauds MITM, global ou Web Fuzzer et le plugin de codec par clic droit via un véritable chemin d'exécution équivalent à gRPC. Il explique également comment exploiter le code source du référentiel Yaklang pour localiser et déboguer les problèmes MITM. Utilisez-le lorsqu'un utilisateur demande : « Comment puis-je vérifier mon plugin ? ou "Mon comportement MITM est incorrect : comment puis-je résoudre le problème ?"
