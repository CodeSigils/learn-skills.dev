Guide de vérification de la chaîne d'outils et des plugins Yaklang. Il explique comment exécuter des scripts à l'aide du moteur source Yaklang (allez exécuter common/yak/cmd/yak.go), ainsi que comment utiliser les quatre commandes de vérification de correctifs chauds/codecs (yak hotpatch-mitm / hotpatch-global / hotpatch-webfuzzer / codec-plugin) pour valider vos correctifs chauds MITM, globaux et Web Fuzzer et vos plugins de codecs clic droit avec un véritable chemin d'exécution gRPC ; il explique également comment localiser et déboguer les problèmes MITM en exploitant le code source du référentiel Yaklang. Utilisez-le lorsqu'un utilisateur demande « Comment puis-je vérifier mon plugin ? » ou "Mon comportement MITM est incorrect, comment puis-je résoudre le problème ?"
