Yaklang 工具鍊和插件驗證指南。它解釋瞭如何使用 Yaklang 來源引擎（go run common/yak/cmd/yak.go）運行腳本，以及四個熱補丁/編解碼器驗證命令（yak hotpatch-mitm / hotpatch-global / hotpatch-webfuzzer / codec-plugin）。它顯示如何使用真正的 gRPC 等效執行路徑來驗證您編寫的 MITM / 全域 / Web Fuzzer 熱補丁和右鍵編解碼器外掛程式；也介紹如何利用 Yaklang 儲存庫原始程式碼來定位和偵錯 MITM 問題。當用戶詢問「如何驗證我的插件/如果 MITM 行為不正確該怎麼辦？」時，請使用此選項。
