موضوع عمليات قاعدة بيانات Yaklang (مكتبة db). يتم استخدامه عندما يحتاج المستخدمون إلى الاستمرار أو الاستعلام عن البيانات في البرامج النصية/المكونات الإضافية: إنشاء جدول SQLite مؤقت وعمليات CRUD (db.OpenTempSqliteDatabase / db.ScanResult / Exec)، وتخزين قيمة مفتاح التكوين المشترك للبرامج النصية (db.SetKey / GetKey / DelKey / SetKeyWithTTL)، والإدارة الموحدة لقواميس القوة الغاشمة (db.SavePayload / YieldPayload)، والتكوين على مستوى المشروع (db.SetProjectKey / GetProjectKey).
