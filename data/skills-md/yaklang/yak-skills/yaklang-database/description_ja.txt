Yaklang データベース操作 (db ライブラリ) のトピック。これは、ユーザーがスクリプト/プラグインでデータを永続化またはクエリする必要がある場合に使用されます: 一時的な SQLite テーブルの作成と CRUD 操作 (db.OpenTempSqliteDatabase / db.ScanResult / Exec)、クロススクリプト共有構成キー値ストレージ (db.SetKey / GetKey / DelKey / SetKeyWithTTL)、ブルートフォース ディクショナリの統合管理 (db.SavePayload / YieldPayload)、プロジェクトレベルの設定 (db.SetProjectKey / GetProjectKey)。
