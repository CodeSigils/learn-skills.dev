Sujet spécial sur les opérations de base de données Yaklang (bibliothèque db). Lorsque les utilisateurs ont besoin de conserver ou d'interroger des données dans des scripts/plugins : création de tables SQLite temporaires et CRUD (db.OpenTempSqliteDatabase / db.ScanResult / Exec), stockage de valeurs-clés pour la configuration partagée entre scripts (db.SetKey/GetKey/DelKey/SetKeyWithTTL), gestion unifiée des dictionnaires de force brute (db.SavePayload/YieldPayload) et configuration au niveau du projet (db.SetProjectKey/GetProjectKey).
