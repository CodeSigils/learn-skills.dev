Sujet sur les opérations de base de données Yaklang (bibliothèque de base de données). Il est utilisé lorsque les utilisateurs ont besoin de conserver ou d'interroger des données dans des scripts/plugins : création de tables SQLite temporaires et opérations CRUD (db.OpenTempSqliteDatabase / db.ScanResult / Exec), stockage clé-valeur de configuration partagée par script croisé (db.SetKey / GetKey / DelKey / SetKeyWithTTL), gestion unifiée des dictionnaires de force brute (db.SavePayload / YieldPayload) et configuration au niveau du projet (db.SetProjectKey / GetProjectKey).
