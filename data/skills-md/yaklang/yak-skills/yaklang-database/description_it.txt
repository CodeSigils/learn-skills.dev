Argomento sulle operazioni del database Yaklang (libreria db). Viene utilizzato quando gli utenti devono persistere o eseguire query sui dati in script/plugin: creazione di tabelle SQLite temporanee e operazioni CRUD (db.OpenTempSqliteDatabase / db.ScanResult / Exec), archiviazione di valori-chiave di configurazione condivisa tra script (db.SetKey / GetKey / DelKey / SetKeyWithTTL), gestione unificata di dizionari di forza bruta (db.SavePayload / YieldPayload) e configurazione a livello di progetto (db.SetProjectKey/GetProjectKey).
