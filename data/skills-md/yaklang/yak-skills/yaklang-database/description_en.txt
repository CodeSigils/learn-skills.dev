Yaklang database operations (db library) topic. It is used when users need to persist or query data in scripts/plugins: temporary SQLite table creation and CRUD operations (db.OpenTempSqliteDatabase / db.ScanResult / Exec), cross‑script shared configuration key‑value storage (db.SetKey / GetKey / DelKey / SetKeyWithTTL), unified management of brute‑force dictionaries (db.SavePayload / YieldPayload), and project‑level configuration (db.SetProjectKey / GetProjectKey).
