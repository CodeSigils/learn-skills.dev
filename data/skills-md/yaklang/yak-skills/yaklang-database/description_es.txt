Tema de operaciones de base de datos de Yaklang (biblioteca db). Se utiliza cuando los usuarios necesitan conservar o consultar datos dentro de scripts/complementos: creación de tablas SQLite temporales y operaciones CRUD (db.OpenTempSqliteDatabase / db.ScanResult / Exec), almacenamiento de valores clave para configuración compartida entre scripts (db.SetKey / GetKey / DelKey / SetKeyWithTTL), gestión unificada de diccionarios de fuerza bruta (db.SavePayload / YieldPayload) y configuración a nivel de proyecto (db.SetProjectKey / Obtener clave de proyecto).
