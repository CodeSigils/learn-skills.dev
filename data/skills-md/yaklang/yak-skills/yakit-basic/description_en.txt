Yakit Basic Usage Guide. Used when users need to understand what Yakit is, how to install it, the purpose of each UI functional area, the relationship between the engine and the frontend, and how to get started with Yakit from scratch. Covers an overview of the architecture (engine + Electron frontend + gRPC channel), three interface modes (Classic / Security Expert / Scan), a routing table of core functional areas (MITM / Web Fuzzer / Codec / Port Scan / Plugins / Database, etc.), engine connection and project switching, and an entry point for the most common beginner questions. It is accessed when users ask “How to use Yakit / Where is a certain feature / Engine cannot connect”.
