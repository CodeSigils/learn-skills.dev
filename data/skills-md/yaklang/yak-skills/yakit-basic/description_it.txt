Guida all'utilizzo di base di Yakit. Utilizzato quando gli utenti hanno bisogno di capire cos'è Yakit, come installarlo, lo scopo di ciascuna area funzionale dell'interfaccia utente, la relazione tra il motore e il frontend e come iniziare con Yakit da zero. Copre una panoramica dell'architettura (motore + frontend Electron + canale gRPC), tre modalità di interfaccia (Classica / Esperto di sicurezza / Scansione), una tabella di routing delle aree funzionali principali (MITM / Web Fuzzer / Codec / Scansione porta / Plugin / Database, ecc.), connessione al motore e cambio di progetto e un punto di ingresso per le domande più comuni dei principianti. È possibile accedervi quando gli utenti chiedono "Come utilizzare Yakit / Dov'è una determinata funzionalità / Il motore non può connettersi".
