Yakitの基本的な使い方ガイド。ユーザーが、Yakit とは何か、そのインストール方法、各 UI 機能領域の目的、エンジンとフロントエンドの関係、および Yakit を最初から始める方法を理解する必要がある場合に使用されます。アーキテクチャの概要 (エンジン + Electron フロントエンド + gRPC チャネル)、3 つのインターフェイス モード (クラシック / セキュリティ エキスパート / スキャン)、コア機能領域のルーティング テーブル (MITM / Web ファザー / コーデック / ポート スキャン / プラグイン / データベースなど)、エンジン接続とプロジェクトの切り替え、および最も一般的な初心者の質問へのエントリ ポイントをカバーします。ユーザーが「Yakitの使い方 / 特定の機能はどこにある / エンジンが接続できない」と尋ねたときにアクセスされます。
