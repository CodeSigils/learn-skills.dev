Guía de uso básico de Yakit. Se utiliza cuando los usuarios necesitan comprender qué es Yakit, cómo instalarlo, el propósito de cada área funcional de la interfaz de usuario, la relación entre el motor y la interfaz y cómo comenzar con Yakit desde cero. Cubre una descripción general de la arquitectura (motor + interfaz Electron + canal gRPC), tres modos de interfaz (Clásico / Experto en seguridad / Escaneo), una tabla de enrutamiento de áreas funcionales principales (MITM / Web Fuzzer / Codec / Escaneo de puertos / Complementos / Base de datos, etc.), conexión del motor y cambio de proyectos, y un punto de entrada para las preguntas más comunes para principiantes. Se accede a él cuando los usuarios preguntan "Cómo usar Yakit/Dónde hay una determinada característica/El motor no se puede conectar".
