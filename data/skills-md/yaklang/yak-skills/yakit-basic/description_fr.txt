Guide d'utilisation de base de Yakit. Utilisé lorsque les utilisateurs ont besoin de comprendre ce qu'est Yakit, comment l'installer, le but de chaque domaine fonctionnel de l'interface utilisateur, la relation entre le moteur et le frontend et comment démarrer avec Yakit à partir de zéro. Couvre un aperçu de l'architecture (moteur + interface Electron + canal gRPC), trois modes d'interface (Classique / Expert en sécurité / Scan), une table de routage des domaines fonctionnels de base (MITM / Web Fuzzer / Codec / Port Scan / Plugins / Base de données, etc.), la connexion du moteur et le changement de projet, et un point d'entrée pour les questions les plus courantes des débutants. On y accède lorsque les utilisateurs demandent « Comment utiliser Yakit / Où se trouve une certaine fonctionnalité / Le moteur ne peut pas se connecter ».
