Grundlegende Gebrauchsanweisung für Yakit. Wird verwendet, wenn Benutzer verstehen müssen, was Yakit ist, wie es installiert wird, welchen Zweck die einzelnen UI-Funktionsbereiche haben, welche Beziehung zwischen der Engine und dem Frontend besteht und wie sie Yakit von Grund auf nutzen können. Enthält einen Überblick über die Architektur (Engine + Electron-Frontend + gRPC-Kanal), drei Schnittstellenmodi (Classic / Security Expert / Scan), eine Routing-Tabelle der Kernfunktionsbereiche (MITM / Web Fuzzer / Codec / Port Scan / Plugins / Datenbank usw.), Engine-Verbindung und Projektwechsel sowie einen Einstiegspunkt für die häufigsten Anfängerfragen. Der Zugriff erfolgt, wenn Benutzer fragen: „Wie verwende ich Yakit / Wo ist eine bestimmte Funktion / Engine kann keine Verbindung herstellen“.
