Руководство по базовому использованию Yakit. Используется, когда пользователям необходимо понять, что такое Yakit, как его установить, назначение каждой функциональной области пользовательского интерфейса, взаимосвязь между движком и интерфейсом, а также как начать работу с Yakit с нуля. Охватывает обзор архитектуры (движок + интерфейс Electron + канал gRPC), три режима интерфейса (Классический / Эксперт по безопасности / Сканирование), таблицу маршрутизации основных функциональных областей (MITM / Web Fuzzer / Кодек / Сканирование портов / Плагины / База данных и т. д.), подключение движка и переключение проектов, а также точку входа для наиболее распространенных вопросов новичков. Доступ к нему осуществляется, когда пользователи спрашивают: «Как использовать Yakit / Где находится определенная функция / Engine не может подключиться».
