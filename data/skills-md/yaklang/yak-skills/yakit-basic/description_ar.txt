ياكيت دليل الاستخدام الأساسي. يُستخدم عندما يحتاج المستخدمون إلى فهم ماهية Yakit، وكيفية تثبيته، والغرض من كل منطقة وظيفية لواجهة المستخدم، والعلاقة بين المحرك والواجهة الأمامية، وكيفية البدء مع Yakit من الصفر. يغطي نظرة عامة على البنية (المحرك + الواجهة الأمامية الإلكترونية + قناة gRPC)، وثلاثة أوضاع للواجهة (كلاسيكي / خبير أمان / مسح)، وجدول توجيه للمجالات الوظيفية الأساسية (MITM / Web Fuzzer / Codec / Port Scan / Plugins / Database، وما إلى ذلك)، واتصال المحرك وتبديل المشروع، ونقطة دخول لأسئلة المبتدئين الأكثر شيوعًا. يتم الوصول إليه عندما يسأل المستخدمون "كيفية استخدام ياكيت / أين توجد ميزة معينة / لا يمكن للمحرك الاتصال".
