Ejemplos de sintaxis de Yaklang DSL. Se utiliza cuando los usuarios necesitan escribir o comprender código Yaklang (.yak): variables y tipos, sectores/mapas, flujo de control, funciones (función/flecha/cierre/parámetros variables/múltiples valores de retorno), plantillas de cadena f y manejo de errores de tres frentes (tilde ~ / if err / aplazar recuperación). Incluye tutoriales de sintaxis ejecutables directamente y ejemplos de manejo de errores.
