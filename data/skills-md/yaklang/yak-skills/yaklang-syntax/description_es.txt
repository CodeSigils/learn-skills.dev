Ejemplos de sintaxis de Yaklang DSL. Úselo cuando un usuario necesite escribir o comprender código Yaklang (.yak): variables y tipos, sectores/mapas, flujo de control, funciones (func/flecha/cierres/parámetros variables/múltiples valores de retorno), cadenas f de plantilla de cadena y las tres técnicas esenciales de manejo de errores (~ tilde / if err / aplazar recuperación). Incluye tutoriales de sintaxis ejecutables directamente y ejemplos de manejo de errores.
