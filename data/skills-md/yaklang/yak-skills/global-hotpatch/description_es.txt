Función Yakit Global Hot Reload (Global Hot Patch). Utilícelo cuando un usuario necesite una configuración única que permita a MITM compartir el mismo conjunto de enlaces en todas las pestañas de Web Fuzzer: cifrado/descifrado transparente en todo el sitio, inyección de firma/autenticación unificada, respuesta dinámica a desafíos, enmascaramiento de datos basado en colores en todo el sitio, salvaguardias para operaciones peligrosas. El enlace global se ejecuta antes que los enlaces de módulo y solo se puede habilitar uno a la vez. Reutiliza beforeRequest/afterRequest/hijackHTTPRequest/hijackSaveHTTPFlow/mockHTTPRequest.
