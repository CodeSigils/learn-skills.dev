Yakit Global Hot Reload (Global Hot Patch) Thema. Verwenden Sie dies, wenn der Benutzer eine einzige Konfiguration benötigt, die es MITM und allen Web Fuzzer-Registerkarten ermöglicht, denselben Satz von Hooks zu teilen: Site-weite transparente Verschlüsselung/Entschlüsselung, einheitliche Signatur-/Authentifizierungsinjektion, dynamische Challenge-Response, Site-weite Farbgebung/Desensibilisierung und Schutzmaßnahmen für gefährliche Vorgänge. Globale Hooks werden vor Modul-Hooks ausgeführt und es kann jeweils nur einer aktiviert sein. Wiederverwendung von beforeRequest/afterRequest/hijackHTTPRequest/hijackSaveHTTPFlow/mockHTTPRequest.
