Yakit Global Hot Reload (Global Hot Patch) Thema. Wenn ein Benutzer eine Konfiguration benötigt, die es MITM ermöglicht, den gleichen Satz von Hooks mit allen Web Fuzzer-Registerkarten zu teilen: Site-weite transparente Verschlüsselung/Entschlüsselung, einheitliche Signatur-/Authentifizierungsinjektion, dynamische Challenge-Response, Site-weite Farbgebung/Desensibilisierung und Schutzmaßnahmen für gefährliche Vorgänge. Globale Hooks werden vor Modul-Hooks ausgeführt und es kann jeweils nur einer aktiviert sein. Wiederverwendung beforeRequest / afterRequest / hijackHTTPRequest / hijackSaveHTTPFlow / mockHTTPRequest.
