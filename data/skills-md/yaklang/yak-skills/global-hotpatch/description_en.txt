Yakit Global Hot Reload (Global Hot Patch) topic. Use this when the user needs a single configuration that allows MITM and all Web Fuzzer tabs to share the same set of hooks: site‑wide transparent encryption/decryption, unified signature/authentication injection, dynamic challenge response, site‑wide coloring/desensitization, and safeguards for dangerous operations. Global hooks run before module hooks, and only one can be enabled at a time. Reuses beforeRequest / afterRequest / hijackHTTPRequest / hijackSaveHTTPFlow / mockHTTPRequest.
