关于 yak 脚本和 Yakit UI 之间的交互机制的主题。它清楚地解释了 yakit.* 库函数如何通过 gRPC ExecResult 流驱动 UI 渲染：yakit.Info/Warn/Error/Success 日志输出、yakit.SetProgress 进度条、yakit.NewTable/EnableTable/TableData 表（静态与动态）、yakit.NewLineGraph/NewBarGraph/NewPieGraph/NewWordCloud 图表、yakit.StatusCard 状态卡、yakit.EnableWebsiteTrees 网站树，yakit.EnableText/TextTabData 文本选项卡，yakit.Output 统一输出通道，以及从前端的 useHoldGRPCStream 消耗 ExecResult 到渲染 UI 的完整链。当用户询问“脚本如何让 Yakit 显示表格/图表/进度条/卡片？”时使用此选项。或“yakit.Info 输出去哪里？”
