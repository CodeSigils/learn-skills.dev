yak スクリプトと Yakit UI の間の対話メカニズムに関するトピック。 yakit.* ライブラリ関数が gRPC ExecResult ストリームを介して UI レンダリングをどのように駆動するかについて明確に説明しています: yakit.Info/Warn/Error/Success ログ出力、yakit.SetProgress プログレス バー、yakit.NewTable/EnableTable/TableData テーブル (静的対動的)、yakit.NewLineGraph/NewBarGraph/NewPieGraph/NewWordCloud チャート、yakit.StatusCard ステータス カード、 yakit.EnableWebsiteTrees Web サイト ツリー、yakit.EnableText/TextTabData テキスト タブ、yakit.Output 統合出力チャネル、および ExecResult を消費するフロントエンドの useHoldGRPCStream から UI のレンダリングまでの完全なチェーン。ユーザーが「スクリプトでどのようにして Yakit に表、グラフ、進行状況バー、カードを表示させることができますか?」と尋ねたときにこれを使用します。または「yakit.Info の出力はどこに行きますか?」
