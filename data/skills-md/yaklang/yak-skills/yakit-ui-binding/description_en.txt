Topic on the interaction mechanism between yak scripts and the Yakit UI. It explains clearly how the yakit.* library functions drive UI rendering through the gRPC ExecResult stream: yakit.Info/Warn/Error/Success log output, yakit.SetProgress progress bar, yakit.NewTable/EnableTable/TableData tables (static vs. dynamic), yakit.NewLineGraph/NewBarGraph/NewPieGraph/NewWordCloud charts, yakit.StatusCard status cards, yakit.EnableWebsiteTrees website trees, yakit.EnableText/TextTabData text tabs, yakit.Output unified output channel, and the complete chain from the frontend's useHoldGRPCStream consuming ExecResult to rendering the UI. Use this when a user asks “How can a script make Yakit display tables/charts/progress bars/cards?” or “Where does yakit.Info output go?”
