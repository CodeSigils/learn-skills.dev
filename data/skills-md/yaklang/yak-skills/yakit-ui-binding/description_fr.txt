Sujet sur le mécanisme d'interaction entre les scripts yak et l'interface utilisateur Yakit. Il explique clairement comment les fonctions de la bibliothèque yakit.* pilotent le rendu de l'interface utilisateur via le flux gRPC ExecResult : sortie du journal yakit.Info/Warn/Error/Success, barre de progression yakit.SetProgress, tables yakit.NewTable/EnableTable/TableData (statiques ou dynamiques), graphiques yakit.NewLineGraph/NewBarGraph/NewPieGraph/NewWordCloud, cartes d'état yakit.StatusCard, site Web yakit.EnableWebsiteTrees les arbres, les onglets de texte yakit.EnableText/TextTabData, le canal de sortie unifié yakit.Output et la chaîne complète depuis le useHoldGRPCStream du frontend consommant ExecResult jusqu'au rendu de l'interface utilisateur. Utilisez-le lorsqu'un utilisateur demande « Comment un script peut-il permettre à Yakit d'afficher des tableaux/graphiques/barres de progression/cartes ?" ou "Où va la sortie yakit.Info?"
