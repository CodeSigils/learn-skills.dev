Argomento sul meccanismo di interazione tra script Yak e UI Yakit. Spiega come le funzioni della libreria yakit.* guidano il rendering dell'interfaccia tramite lo stream gRPC ExecResult: output di log yakit.Info/Warn/Error/Success, barra di avanzamento yakit.SetProgress, tabelle yakit.NewTable/EnableTable/TableData (statiche vs. dinamiche), grafici yakit.NewLineGraph/NewBarGraph/NewPieGraph/NewWordCloud, schede di stato yakit.StatusCard, alberi di siti web yakit.EnableWebsiteTrees, schede di testo yakit.EnableText/TextTabData, canale di output unificato yakit.Output e l'intera pipeline dal consumo di ExecResult da parte di useHoldGRPCStream nel front‑end al rendering della UI. Usa questo quando un utente chiede “Come può uno script far visualizzare a Yakit una tabella/grafico/barra di avanzamento/carta?” o “Dove vanno gli output di yakit.Info?”.
