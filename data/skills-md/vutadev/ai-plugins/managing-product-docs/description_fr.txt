À utiliser lorsque l'utilisateur demande à créer, extraire, mettre à jour, affiner ou auditer la documentation du produit (PRD, pile technologique, architecture, SRS, user stories avec critères d'acceptation INVEST + Gherkin, plan du site, système de conception, feuille de route, cas d'utilisation, flux d'utilisateurs, règles métier, conception de base de données, référence d'API, cas de test, documents externes) pour un projet logiciel - couvre l'initialisation inédite à partir d'un bref, l'extraction de friches industrielles à partir du code existant, les mises à jour incrémentielles après des modifications de portée/fonctionnalité/technologie/architecture/conception et les audits d'écarts pour détecter la dérive entre les documents et le code.
