Audit des performances de la base de données : détecte les requêtes N+1, les index manquants, les jointures
opportunités, requêtes lentes, analyse EXPLAIN et nombre d’appels à la base de données par point de terminaison.
À utiliser lorsqu'on lui demande « d'optimiser la base de données », « rechercher des requêtes lentes », « vérifier N+1 »,
"analyser les performances des requêtes" ou "auditer les appels de base de données".
