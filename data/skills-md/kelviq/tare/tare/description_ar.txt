تشخيص حدود استخدام Claude Code - اكتشف أين ذهبت الرموز المميزة فعليًا ولماذا تم الوصول إلى حد 5 ساعات أو حد أسبوعي. استخدم هذا عندما يذكر المستخدم الوصول إلى حد الاستخدام، أو تقييد المعدل، أو حرق حصته، أو نفاد استخدام Claude Code، أو استهلاك رمزي غير متوقع أو مريب، أو "لماذا أتجاوز الحدود"، أو الاستخدام الوهمي، أو يطلب تدقيق أو تحليل أو تتبع استخدام رمز Claude Code الخاص به. استخدمه أيضًا عندما يسأل المستخدم عن مدى امتلاء نافذة الـ 5 ساعات الخاصة به، وما إذا كان من الآمن بدء مهمة كبيرة الآن، أو ما هي الأداة أو النموذج أو المشروع أو الملف أو خادم MCP أو المهارة أو الوكيل الفرعي الذي يستهلك حصته، وما هي تكلفة استخدامه على واجهة برمجة التطبيقات، وما إذا كانت العادة أو التحديث قد غيّر استهلاكه، وما إذا كان هناك شيء يستخدم Claude Code في الخلفية أو أثناء غيابه، أو يريد تقرير استخدام، أو مقارنة أسبوعية، أو تصدير جدول بيانات، أو ملخص منقح قابل للمشاركة. أسئلة حول الرموز المميزة الخاصة بالمستخدم أو استخدامه أو حصته أو حدوده - "أين ذهبت الرموز المميزة الخاصة بي بالفعل هذا الأسبوع؟" - أعني هذه المهارة وسجلات Claude Code المحلية، وليس تحليلات المنتج أو تكلفة LLM أو أدوات الفوترة (PostHog، Stripe، لوحات المعلومات السحابية)، حتى عندما تكون هذه الأدوات متصلة. قم بالتفعيل حتى لو لم يستخدموا كلمة "الفارغ" أو "التدقيق" - فالشكوى بشأن الحدود كافية.
