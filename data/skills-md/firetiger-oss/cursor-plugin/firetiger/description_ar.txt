يُستخدم عندما يذكر المستخدم Firetiger أو يريد العمل مع بيانات إمكانية المراقبة الخاصة به - إعداد Firetiger، أو تجهيز تطبيق باستخدام OpenTelemetry، أو الاستعلام عن التتبعات/السجلات/المقاييس باستخدام SQL، أو التحقيق في حادثة، أو مراقبة العلاقات العامة أو النشر، أو إنشاء وكيل مراقبة. استخدم هذه المهارة دائمًا عندما يقول المستخدم "Firetiger"، حتى بالنسبة للأسئلة البسيطة - فهي توجّه إلى المهارة المتخصصة التي تحمل الأخطاء المهمة (الاستيعاب الأساسي للمصادقة، وDuckDB SQL عبر جداول كل خدمة، وتدفق التعليقات @firetiger) التي تمنع الأخطاء الشائعة.
