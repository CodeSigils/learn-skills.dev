À utiliser lorsque l'utilisateur mentionne Firetiger ou souhaite travailler avec ses données d'observabilité : configuration de Firetiger, instrumentation d'une application avec OpenTelemetry, interrogation de traces/journaux/métriques avec SQL, enquête sur un incident, surveillance d'un PR ou d'un déploiement, ou création d'un agent de surveillance. Utilisez toujours cette compétence lorsque l'utilisateur dit "Firetiger", même pour des demandes simples - elle est acheminée vers la compétence spécialisée qui comporte les pièges critiques (ingestion d'authentification de base, DuckDB SQL sur les tables par service, le flux de commentaires @firetiger) qui évitent les erreurs courantes.
