Используйте, когда пользователь упоминает Firetiger или хочет поработать со своими данными наблюдения — настройка Firetiger, оснащение приложения OpenTelemetry, запрос трассировок/журналов/метрик с помощью SQL, расследование инцидента, мониторинг PR или развертывания или создание агента мониторинга. Всегда используйте этот навык, когда пользователь говорит «Firetiger», даже для простых вопросов — он перенаправляет к специализированному навыку, который содержит важные ошибки (загрузка базовой аутентификации, DuckDB SQL над таблицами для каждого сервиса, поток комментариев @firetiger), которые предотвращают распространенные ошибки.
