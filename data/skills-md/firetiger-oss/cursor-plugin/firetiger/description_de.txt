Verwenden Sie es, wenn der Benutzer Firetiger erwähnt oder mit seinen Observability-Daten arbeiten möchte – Firetiger einrichten, eine App mit OpenTelemetry instrumentieren, Traces/Protokolle/Metriken mit SQL abfragen, einen Vorfall untersuchen, eine PR oder Bereitstellung überwachen oder einen Überwachungsagenten erstellen. Verwenden Sie diesen Skill immer, wenn der Benutzer „Firetiger“ sagt, auch für einfache Fragen – er leitet an den speziellen Skill weiter, der die kritischen Fallstricke enthält (Basic-Auth-Ingest, DuckDB SQL über dienstbezogene Tabellen, den @firetiger-Kommentarablauf), die häufige Fehler verhindern.
