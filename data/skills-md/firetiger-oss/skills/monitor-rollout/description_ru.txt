Запускает план мониторинга изменений на переднем плане текущего сеанса агента кодирования: опрашивает систему развертывания каждой среды на предмет развертывания, запускает каждую контрольную точку по индикаторам с группировкой по средам, применяет дисциплину доказательств (базовый показатель ≥24 часов + предшествующее время того же дня + аналитическая причина + тест на отклонения) и выдает встроенные отчеты о ходе выполнения для каждой среды. Спит между контрольными точками через фоновый сон bash + уведомление. При первой проблеме, обнаруженной в любой среде, переходите в режим планирования, чтобы тот же сеанс перешел к ее исправлению (режим последовательной одной проблемы). Используйте, когда развертывание было запущено, пользователь объединил PR и хочет наблюдать за производством, выполнять проверку после развертывания, наблюдать за канарейкой или присматривать за развертыванием в нескольких средах - даже если он не говорит «выполнить план». Считывает план, созданный plan-rollout.
