Contrôle des modifications de niveau SRE pour les modifications de code sur le point d'être expédiées en production. Itinéraires vers la bonne sous-compétence : déploiement de plan pour créer un plan de surveillance avant la fusion, déploiement de surveillance pour exécuter ce plan après le déploiement. Prend en charge les déploiements multi-environnements (staging + prod, multi-région, fan-out). À utiliser lorsque l'utilisateur prépare un changement de code pour la production, planifie une version, demande comment surveiller un déploiement, effectue une validation post-déploiement, surveille un canari, surveille un déploiement ou réfléchit au rayon d'explosion/SLI/budget d'erreur pour un changement à venir - même s'il ne dit pas « contrôle des changements » ou « surveillance du déploiement ». Ancré dans le vocabulaire du livre Google SRE (signaux d'or, SLI, budget d'erreur, rayon de souffle, canari, MTTR, validation post-déploiement).
