Управление изменениями уровня SRE для изменений кода, готовящихся к отправке в производство. Маршруты к нужному субнавыку: план-развертывание для разработки плана мониторинга перед слиянием, мониторинг-развертывание для запуска этого плана после развертывания. Поддерживает развертывание в нескольких средах (промежуточный + производственный, в нескольких регионах, разветвленный). Используйте, когда пользователь готовит изменение кода для производства, планирует выпуск, спрашивает, как контролировать развертывание, выполняет проверку после развертывания, наблюдает за канарейкой, присматривает за развертыванием или думает о радиусе взрыва / SLI / бюджете ошибок для предстоящего изменения - даже если он не говорит «контроль изменений» или «мониторинг развертывания». Закреплено на словаре книги Google SRE (золотые сигналы, SLI, бюджет ошибок, радиус взрыва, канарейка, MTTR, проверка после развертывания).
