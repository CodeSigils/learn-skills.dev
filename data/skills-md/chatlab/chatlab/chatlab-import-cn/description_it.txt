Visualizza l'anteprima in tutta sicurezza tramite la CLI di chatlab e importa i file di esportazione della chat locale in ChatLab. Utilizzato quando un utente richiede a un agente esterno di eseguire un'importazione iniziale, una reimportazione o un aggiornamento incrementale da QQ locale, WeChat, Telegram, WhatsApp, LINE, Discord, Instagram, Google Chat, ChatLab JSON/JSONL o altri file di esportazione chat supportati.
