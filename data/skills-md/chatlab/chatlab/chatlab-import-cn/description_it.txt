Visualizza in anteprima e importa in modo sicuro i file di esportazione della chat locale in ChatLab utilizzando la CLI di chatlab. Utilizzato quando l'utente richiede a un agente esterno di eseguire un'importazione iniziale, una reimportazione o un aggiornamento incrementale da QQ locale, WeChat, Telegram, WhatsApp, LINE, Discord, Instagram, Google Chat, ChatLab JSON/JSONL o altri file di esportazione chat supportati.
