Obtenga una vista previa e importe de forma segura archivos de exportación de chat local a ChatLab utilizando la CLI de chatlab. Se utiliza cuando un usuario solicita a un agente externo que realice una importación inicial, una reimportación o una actualización incremental desde QQ local, WeChat, Telegram, WhatsApp, LINE, Discord, Instagram, Google Chat, ChatLab JSON/JSONL u otros archivos de exportación de chat compatibles.
