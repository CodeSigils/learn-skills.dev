Convierta las exportaciones de chat local que ChatLab aún no admite en ChatLab JSONL o JSON validado: analice la estructura del archivo fuente, escriba y ejecute un script de conversión local de Node.js o Python y verifique el recuento de registros antes de importar. Utilícelo cuando ChatLab no pueda reconocer exportaciones de chat como CSV, HTML, TXT, XML, SQLite/base de datos, JSON/JSONL personalizado específico del proveedor, paquetes comprimidos, etc., o cuando un usuario solicite al Agente que se adapte a un formato de chat desconocido.
