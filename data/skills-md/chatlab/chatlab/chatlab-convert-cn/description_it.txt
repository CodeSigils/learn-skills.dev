Converti le esportazioni di chat locali non attualmente supportate da ChatLab in ChatLab JSONL o JSON verificati: analizza la struttura del file di origine, scrivi ed esegui uno script di conversione Node.js o Python locale e verifica il conteggio dei record prima dell'importazione. Utilizzalo quando ChatLab non è in grado di riconoscere esportazioni di chat come CSV, HTML, TXT, XML, SQLite/database, JSON/JSONL specifici del fornitore, archivi, ecc. o quando un utente richiede all'agente di adattare un formato di chat sconosciuto.
