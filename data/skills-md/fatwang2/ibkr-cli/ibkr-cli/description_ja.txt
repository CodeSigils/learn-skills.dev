IB ゲートウェイ/TWS および ibkr-cli 自体のインストールから、株の取引、口座の監視、市場データの取得、金融ニュースの閲覧、オプション チェーンの探索、マーケット スキャナーによる銘柄のスクリーニング、企業ファンダメンタルズの照会まで、Interactive Brokers CLI 操作を通じてユーザーをガイドします。ユーザーがインタラクティブ ブローカー、IBKR、TWS、IB ゲートウェイ、CLI を介した株式取引、ポートフォリオやポジションの確認、相場の取得、注文、株式ニュースの閲覧、オプション チェーン、ギリシャ株、株式スクリーナー、マーケット スキャナー、トップゲイン、最もアクティブな企業のファンダメンタルズ、財務諸表、貸借対照表、損益計算書、キャッシュ フロー、所有権、機関投資家、または端末を介した証券口座管理に関連するものについて言及するたびに、このスキルを使用します。ユーザーが明示的に「ibkr」と言わなくても、コマンドラインから株を売買したいとき、証券口座を確認したいとき、株に関するニュースを読みたいとき、オプションデータを調べたいとき、株を選別したいとき、会社の財務状況をチェックしたいとき、ブローカーへの API 接続を設定したいときにトリガーします。
