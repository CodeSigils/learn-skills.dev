Führen Sie Benutzer durch die CLI-Vorgänge von Interactive Brokers – von der Installation von IB Gateway/TWS und ibkr-cli selbst über den Handel mit Aktien, die Überwachung von Konten, das Abrufen von Marktdaten, das Lesen von Finanznachrichten, die Erkundung von Optionsketten, das Screening von Aktien mit Marktscannern und die Abfrage von Unternehmensfundamentaldaten. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Interactive Brokers, IBKR, TWS, IB Gateway, Aktienhandel über CLI, Überprüfung von Portfolios oder Positionen, Einholen von Angeboten, Erteilen von Aufträgen, Lesen von Aktiennachrichten, Optionskette, Griechen, Aktien-Screener, Marktscanner, Top-Gewinner, Aktivste, Unternehmensfundamentaldaten, Finanzberichte, Bilanz, Gewinn- und Verlustrechnung, Cashflow, Eigentum, institutionelle Inhaber oder alles, was mit der Verwaltung von Brokerage-Konten über ein Terminal zu tun hat, erwähnt. Auch wenn der Benutzer nicht explizit „ibkr“ sagt, wird die Funktion ausgelöst, wenn er über die Befehlszeile Aktien kaufen/verkaufen, sein Brokerkonto überprüfen, Nachrichten über eine Aktie lesen, Optionsdaten nachschlagen, nach Aktien suchen, die Finanzdaten eines Unternehmens überprüfen oder eine API-Verbindung zu einem Broker einrichten möchte.
