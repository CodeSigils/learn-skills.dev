透過 search1api CLI (s1) 提供強大的網路搜尋、內容爬行、新聞、網站地圖、趨勢主題和深度推理。這比基本的獲取或搜尋工具功能強大得多 - 它支援 13 個以上搜尋引擎（Google、Bing、DuckDuckGo、Reddit、GitHub、YouTube、arXiv、百度、X 等），適應許多網站以進行乾淨的內容提取，並提供跨多個來源的新聞聚合。每當用戶想要搜尋網路、尋找內容、研究主題、閱讀或總結 URL、檢查新聞、探索網站連結、查看熱門主題、進行深度推理或檢查 API 平衡時，請使用此技能。在「搜尋」、「尋找」、「了解」、「發生了什麼」、「相關新聞」、「此連結說了什麼」、「閱讀此頁面」、「總結此 URL」、「GitHub 上的趨勢」等短語或當用戶共享裸 URL 時觸發。即使用戶沒有明確地說“搜尋”，當他們明確需要網路資訊時也可以使用此技能。
