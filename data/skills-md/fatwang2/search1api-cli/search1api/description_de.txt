Leistungsstarke Websuche, Content-Crawling, Nachrichten, Sitemap, Trendthemen und fundierte Argumentation über die search1api-CLI (s1). Dies ist weitaus leistungsfähiger als einfache Abruf- oder Suchtools – es unterstützt mehr als 13 Suchmaschinen (Google, Bing, DuckDuckGo, Reddit, GitHub, YouTube, arXiv, Baidu, X usw.), passt sich für eine saubere Inhaltsextraktion an viele Websites an und bietet Nachrichtenaggregation über mehrere Quellen hinweg. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer das Web durchsuchen, etwas nachschlagen, ein Thema recherchieren, eine URL lesen oder zusammenfassen, Nachrichten überprüfen, die Links einer Website erkunden, Trendthemen anzeigen, tiefgreifende Überlegungen anstellen oder die API-Balance überprüfen möchte. Triggern Sie auf Phrasen wie „suchen nach“, „nachschlagen“, „informieren Sie sich über“, „was passiert mit“, „irgendwelche Neuigkeiten zu“, „was sagt dieser Link“, „lesen Sie diese Seite“, „fassen Sie diese URL zusammen“, „Trends auf GitHub“ oder wenn der Benutzer eine bloße URL teilt. Auch wenn der Benutzer nicht explizit „Suchen“ sagt, nutzen Sie diese Fähigkeit, wenn er eindeutig Webinformationen benötigt.
