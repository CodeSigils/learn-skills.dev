Recherche Web puissante, exploration de contenu, actualités, plan du site, sujets d'actualité et raisonnement approfondi via la CLI search1api (s1). C'est bien plus performant que les outils de récupération ou de recherche de base : il prend en charge plus de 13 moteurs de recherche (Google, Bing, DuckDuckGo, Reddit, GitHub, YouTube, arXiv, Baidu, X, etc.), s'adapte à de nombreux sites Web pour une extraction propre du contenu et fournit une agrégation d'actualités sur plusieurs sources. Utilisez cette compétence chaque fois que l'utilisateur souhaite effectuer une recherche sur le Web, rechercher quelque chose, rechercher un sujet, lire ou résumer une URL, consulter des actualités, explorer les liens d'un site, voir des sujets d'actualité, effectuer un raisonnement approfondi ou vérifier l'équilibre de l'API. Déclenchez des expressions telles que « rechercher », « rechercher », « découvrir », « que se passe-t-il », « des nouvelles sur », « que dit ce lien », « lire cette page », « résumer cette URL », « tendances sur GitHub » ou lorsque l'utilisateur partage une URL nue. Même si l'utilisateur ne dit pas explicitement « rechercher », utilisez cette compétence lorsqu'il a clairement besoin d'informations sur le Web.
