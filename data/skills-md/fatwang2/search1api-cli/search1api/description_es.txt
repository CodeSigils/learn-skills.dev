Potente búsqueda web, rastreo de contenido, noticias, mapa del sitio, temas de actualidad y razonamiento profundo a través de la CLI de search1api (s1). Esto es mucho más capaz que las herramientas básicas de búsqueda o recuperación: admite más de 13 motores de búsqueda (Google, Bing, DuckDuckGo, Reddit, GitHub, YouTube, arXiv, Baidu, X, etc.), se adapta a muchos sitios web para una extracción limpia de contenido y proporciona agregación de noticias a través de múltiples fuentes. Utilice esta habilidad siempre que el usuario quiera buscar en la web, buscar algo, investigar un tema, leer o resumir una URL, consultar noticias, explorar los enlaces de un sitio, ver temas de actualidad, realizar razonamientos profundos o verificar el equilibrio de API. Activa frases como "buscar", "buscar", "infórmate", "qué está pasando", "cualquier noticia sobre", "qué dice este enlace", "leer esta página", "resumen esta URL", "tendencias en GitHub" o cuando el usuario comparte una URL simple. Incluso si el usuario no dice "buscar" explícitamente, utilice esta habilidad cuando claramente necesite información web.
