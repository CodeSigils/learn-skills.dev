search1api CLI (s1) を介した強力な Web 検索、コンテンツ クローリング、ニュース、サイトマップ、トレンド トピック、および深い推論。これは、基本的なフェッチ ツールや検索ツールよりもはるかに機能が高く、13 を超える検索エンジン (Google、Bing、DuckDuckGo、Reddit、GitHub、YouTube、arXiv、Baidu、X など) をサポートし、多くの Web サイトに適応してクリーンなコンテンツを抽出し、複数のソースにわたるニュースの集約を提供します。ユーザーが Web を検索したり、何かを調べたり、トピックを調査したり、URL を読んだり要約したり、ニュースをチェックしたり、サイトのリンクを探索したり、トレンドのトピックを確認したり、深い推論を行ったり、API バランスをチェックしたりする場合には、このスキルを使用します。 「検索する」、「調べる」、「調べる」、「何が起こっている」、「何かニュース」、「このリンクには何と書いてある」、「このページを読む」、「この URL を要約する」、「GitHub でのトレンド」などのフレーズ、またはユーザーが裸の URL を共有したときにトリガーされます。ユーザーが明示的に「検索」と言わなくても、明らかに Web 情報が必要な場合にこのスキルを使用します。
