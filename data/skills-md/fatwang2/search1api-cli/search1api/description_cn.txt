通过 search1api CLI (s1) 提供强大的网络搜索、内容爬行、新闻、站点地图、趋势主题和深度推理。这比基本的获取或搜索工具功能强大得多 - 它支持 13 个以上搜索引擎（Google、Bing、DuckDuckGo、Reddit、GitHub、YouTube、arXiv、百度、X 等），适应许多网站以进行干净的内容提取，并提供跨多个来源的新闻聚合。每当用户想要搜索网络、查找内容、研究主题、阅读或总结 URL、检查新闻、探索网站链接、查看热门主题、进行深度推理或检查 API 平衡时，请使用此技能。在“搜索”、“查找”、“了解”、“发生了什么”、“有关新闻”、“此链接说了什么”、“阅读此页面”、“总结此 URL”、“GitHub 上的趋势”等短语或当用户共享裸 URL 时触发。即使用户没有明确地说“搜索”，当他们明确需要网络信息时也可以使用此技能。
