Используйте REST API Vika.cn через Curl для управления данными онлайн-таблиц. ВСЕГДА используйте этот навык, когда пользователи упоминают Vika, vika.cn, 维格表, 维格云 или любой из этих шаблонов:
- Идентификаторы, начинающиеся с "dst" (таблица данных/数据表), "spc" (пробел/空间站), "fld" (поле/字段), "rec" (запись/记录), "viw" (просмотр/视图)
- Совместные онлайн-таблицы/таблицы с операциями API.
- Пакетный импорт/экспорт данных в онлайн-таблицы.
- Чтение/создание/обновление/удаление записей через API
- Загрузка вложений в таблицы данных.
- Поиск в таблицах данных или пространствах, список рабочих пространств.
- Поля участников, управление командой в онлайн-таблицах
