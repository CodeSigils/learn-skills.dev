استخدم Vika.cn REST API عبر حليقة لإدارة بيانات جدول البيانات عبر الإنترنت. استخدم دائمًا هذه المهارة عندما يذكر المستخدمون Vika أو vika.cn أو 维格表 أو 维格云 أو أي من هذه الأنماط:
- المعرفات التي تبدأ بـ "dst" (ورقة البيانات/数据表)، "spc" (مسافة/空间站)، "fld" (حقل/字段)، "rec" (سجل/记录)، "عرض" (عرض/视图)
- جداول/جداول بيانات تعاونية عبر الإنترنت مع عمليات واجهة برمجة التطبيقات (API).
- بيانات الاستيراد/التصدير المجمعة إلى الجداول عبر الإنترنت
- قراءة/إنشاء/تحديث/حذف السجلات عبر API
- تحميل المرفقات إلى أوراق البيانات
- البحث في أوراق البيانات أو المساحات، وقائمة مساحات العمل
- حقول الأعضاء وإدارة الفريق في الجداول عبر الإنترنت
