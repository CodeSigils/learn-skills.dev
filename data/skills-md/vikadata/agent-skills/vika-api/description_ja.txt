オンライン スプレッドシート データを管理するには、curl 経由で Vika.cn REST API を使用します。ユーザーが Vika、vika.cn、维格表、维格云、またはこれらのパターンのいずれかについて言及する場合は、常にこのスキルを使用してください。
- "dst" (データシート/データテーブル)、"spc" (スペース/空间站)、"fld" (フィールド/字段)、"rec" (レコード/记录)、"viw" (ビュー/映像図) で始まる ID
- API 操作を使用したオンラインの共同テーブル/スプレッドシート
- オンラインテーブルへのデータの一括インポート/エクスポート
- API経由でレコードの読み取り/作成/更新/削除
- 添付ファイルをデータシートにアップロードする
- データシートまたはスペースを検索し、ワークスペースをリストします。
- メンバーフィールド、オンラインテーブルでのチーム管理
