Utilizza l'API REST Vika.cn tramite curl per gestire i dati del foglio di calcolo online. Usa SEMPRE questa abilità quando gli utenti menzionano Vika, vika.cn, 维格表, 维格云 o uno qualsiasi di questi modelli:
- ID che iniziano con "dst" (datasheet/数据表), "spc" (space/空间站), "fld" (field/字段), "rec" (record/记录), "viw" (view/视图)
- Tabelle/fogli di calcolo collaborativi online con operazioni API
- Importazione/esportazione batch di dati in tabelle online
- Leggi/crea/aggiorna/elimina record tramite API
- Carica gli allegati alle schede tecniche
- Cerca schede tecniche o spazi, elenca gli spazi di lavoro
- Campi dei membri, gestione del team nelle tabelle online
