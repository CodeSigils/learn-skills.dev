Utilice la API REST de Vika.cn a través de curl para administrar datos de hojas de cálculo en línea. SIEMPRE utilice esta habilidad cuando los usuarios mencionen Vika, vika.cn, 维格表, 维格云 o cualquiera de estos patrones:
- ID que comienzan con "dst" (datasheet/数据表), "spc" (space/空间站), "fld" (field/字段), "rec" (record/记录), "viw" (view/视图)
- Tablas/hojas de cálculo colaborativas en línea con operaciones API
- Importación/exportación de datos por lotes a tablas en línea
- Leer/crear/actualizar/eliminar registros a través de API
- Cargar archivos adjuntos a hojas de datos
- Buscar hojas de datos o espacios, enumerar espacios de trabajo
- Campos de miembros, gestión de equipos en mesas en línea.
