Utilisez l'API REST Vika.cn via curl pour gérer les données des feuilles de calcul en ligne. Utilisez TOUJOURS cette compétence lorsque les utilisateurs mentionnent Vika, vika.cn, 维格表, 维格云 ou l'un de ces modèles :
- ID commençant par "dst" (datasheet/数据表), "spc" (espace/空间站), "fld" (field/字段), "rec" (record/记录), "viw" (view/视图)
- Tableaux/feuilles de calcul collaboratifs en ligne avec opérations API
- Importer/exporter des données par lots vers des tables en ligne
- Lire/créer/mettre à jour/supprimer des enregistrements via API
- Télécharger des pièces jointes aux fiches techniques
- Rechercher des fiches techniques ou des espaces, répertorier les espaces de travail
- Champs membres, gestion d'équipe dans les tableaux en ligne
