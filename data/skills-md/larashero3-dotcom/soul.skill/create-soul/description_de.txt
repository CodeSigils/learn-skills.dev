Erstelle einen KI-Charakter von Grund auf. Interaktive Anleitung: Charakternamen eingeben → Quellmaterial bereitstellen (URL/Datei/Text einfügen) → automatische Destillation → ein gebrauchsfertiges Skill-Verzeichnis ausgeben. Aktivieren, wenn: Der Benutzer sagt /create-soul, „Charakter erstellen“, „[jemanden] destillieren“, „eine Persona für [Name] erstellen“.
