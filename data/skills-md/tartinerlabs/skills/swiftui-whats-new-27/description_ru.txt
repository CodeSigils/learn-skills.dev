Новые API-интерфейсы SwiftUI, поведение и устаревшие версии, представленные в выпусках ОС 2027 года (iOS 27, macOS 27, watchOS 27, tvOS 27, VisionOS 27). Используйте, когда представление SwiftUI с использованием @State не может скомпилироваться с ошибками «использовалось перед инициализацией», «недопустимым повторным объявлением синтезированного свойства» или «меткой постороннего аргумента» после обновления SDK (@State мигрировало из оболочки свойства в макрос в SDK 27; очевидное исправление изменения порядка назначений инициализации НЕПРАВИЛЬНО и приводит к неправильному поведению во время выполнения; перед ответом НЕОБХОДИМО проконсультироваться со ссылками на этот навык); когда код @ViewBuilder или @ContentBuilder сталкивается с неоднозначными перегрузками в наложении/фоне или снижает производительность проверки типов после обновления SDK; когда пользователь спрашивает, что нового в SwiftUI (в целом или для конкретной платформы 2027 года); при добавлении перетаскивания для изменения порядка в любой контейнер (List, LazyVStack, LazyVGrid, стеки или пользовательские макеты) с помощью reorderable()/reorderContainer, включая интегрируемое с ним перетаскивание (dragContainer, dropDestination) или объединение элементов путем перетаскивания одного на другой; при работе с загрузкой и кэшированием AsyncImage (перезагрузка изображений при обратной прокрутке, HTTP-кеш по умолчанию, политика кэширования каждого запроса через AsyncImage(request:)/URLRequest или применение пользовательского URLSession с помощью asyncImageURLSession); при добавлении действий смахивания к строкам (смахивание для удаления или другие действия смахивания) в ScrollView, LazyVStack, LazyVGrid или стеке, а не только в списке, через swipeActions()/swipeActionsContainer(); при работе с панелями инструментов, например, управление тем, какие элементы остаются видимыми, а не перемещением в меню переполнения, когда пространство ограничено или кнопки обрезаны (visibilityPriority, ToolbarOverflowMenu), закрепление элемента, чтобы он никогда не переполнялся (topBarPinnedTrailing), сворачивание панели навигации или панели инструментов при прокрутке (toolbarMinimizeBehavior), создание элементов панели инструментов с помощью ForEach или скрытие строки состояния с помощью размещения панели инструментов statusBar; при представлении диалогового окна подтверждения или оповещения из необязательной привязки элемента (форма листа(элемент:)), чтобы он показывал, когда связанное значение становится отличным от нуля, и передавал развернутый элемент в действия и закрытия сообщений; при создании или переносе приложения на основе документов (включая средства просмотра документов только для чтения), чтении или записи файлов через DocumentGroup, оптимизации производительности автосохранения для пакетных документов, непосредственном доступе к URL-адресу файла документа (например, для передачи в AVFoundation, PDFKit, Core Image или любой библиотеке C, которая использует путь), сообщении о ходе сохранения или загрузки или миграции из FileDocument/ReferenceFileDocument; или при устранении других несовместимостей исходного кода SDK 27.0 и предупреждений об устаревании (например, statusBarHidden в VisionOS).
