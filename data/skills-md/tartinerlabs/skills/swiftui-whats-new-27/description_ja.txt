2027 OS リリース (iOS 27、macOS 27、watchOS 27、tvOS 27、visionOS 27) で導入された新しい SwiftUI API、動作、および非推奨。 @State を使用する SwiftUI ビューが SDK 更新後に「初期化前に使用されました」、「合成されたプロパティの無効な再宣言」、または「無関係な引数ラベル」エラーでコンパイルに失敗した場合に使用します (@State は SDK 27 でプロパティ ラッパーからマクロに移行されました。init 割り当ての並べ替えの明らかな修正が間違っており、誤った実行時の動作が生成されます。回答する前にこのスキルのリファレンスを参照する必要があります)。 @ViewBuilder または @ContentBuilder コードが、SDK の更新後にオーバーレイ/バックグラウンドまたはタイプチェックのパフォーマンス低下であいまいなオーバーロードに遭遇した場合。ユーザーが SwiftUI の新機能 (一般的に、または特定の 2027 プラットフォームについて) を尋ねたとき。 reorderable()/reorderContainer を介して任意のコンテナ (List、LazyVStack、LazyVGrid、スタック、またはカスタム レイアウト) にドラッグツーリオーダーを追加するとき (それに統合されるドラッグ アンド ドロップ (dragContainer、dropDestination) を含む)、または項目を別の項目にドロップして結合するとき。 AsyncImage の読み込みとキャッシュを使用する場合 (スクロールバック時の画像の再読み込み、デフォルトの HTTP キャッシュ、AsyncImage(request:)/URLRequest によるリクエストごとのキャッシュ ポリシー、または asyncImageURLSession によるカスタム URLSession の適用)。 swipeActions()/swipeActionsContainer() を介して、List だけでなく、ScrollView、LazyVStack、LazyVGrid、またはスタックの行にスワイプ アクション (スワイプして削除またはその他のスワイプ アクション) を追加する場合。ツールバーを使用する場合、スペースが制限されている場合やボタンが切り取られている場合にどの項目を表示し続けるかオーバーフロー メニューに移動するかを制御する (visibilityPriority、ToolbarOverflowMenu)、アイテムがオーバーフローしないように固定する (topBarPinnedTrailing)、スクロール時のナビゲーション バーまたはツールバーを最小化する (toolbarMinimizeBehavior)、ForEach を使用してツールバー項目を生成する、または statusBar ツールバーの配置を介してステータス バーを非表示にするなど。オプションの項目バインディング (sheet(item:) シェイプ) からの確認ダイアログまたはアラートを表示するときに、バインドされた値が非 nil になり、ラップされていない項目がアクションとメッセージ クロージャーに渡されるタイミングを示します。ドキュメント ベースのアプリ (読み取り専用ドキュメント ビューアーを含む) の構築または移行、DocumentGroup を介したファイルの読み取りまたは書き込み、パッケージ ドキュメントの自動保存パフォーマンスの最適化、ドキュメントのファイル URL への直接アクセス (たとえば、AVFoundation、PDFKit、Core Image、またはパスを取る C ライブラリに渡すため)、保存または読み込みの進行状況のレポート、または FileDocument / ReferenceFileDocument からの移行。または、他の SDK 27.0 ソースの非互換性や非推奨の警告 (visionOS の statusBarHidden など) を解決するとき。
