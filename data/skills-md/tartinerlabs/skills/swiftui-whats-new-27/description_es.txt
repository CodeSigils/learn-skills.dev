Nuevas API, comportamientos y obsolescencias de SwiftUI introducidas en las versiones del sistema operativo 2027 (iOS 27, macOS 27, watchOS 27, tvOS 27, visionOS 27). Úselo cuando una vista SwiftUI que usa @State no se compila con errores "usado antes de ser inicializado", "redeclaración no válida de propiedad sintetizada" o "etiqueta de argumento extraño" después de una actualización del SDK (@State migró de un contenedor de propiedades a una macro en el SDK 27; la solución obvia de reordenar las asignaciones de inicio es INCORRECTA y produce un comportamiento de tiempo de ejecución incorrecto; DEBE consultar las referencias de esta habilidad antes de responder); cuando el código @ViewBuilder o @ContentBuilder sufre sobrecargas ambiguas en superposición/fondo o regresiones de rendimiento de verificación de tipo después de una actualización del SDK; cuando el usuario pregunta qué hay de nuevo en SwiftUI (en general o para una plataforma 2027 específica); al agregar arrastrar para reordenar a cualquier contenedor (List, LazyVStack, LazyVGrid, pilas o diseños personalizados) mediante reorderable()/reorderContainer, incluido el arrastrar y soltar que se integra con él (dragContainer, dropDestination), o combinar elementos soltando uno sobre otro; cuando se trabaja con la carga y el almacenamiento en caché de AsyncImage (recarga de imágenes al retroceder, el caché HTTP predeterminado, una política de caché por solicitud a través de AsyncImage(request:)/URLRequest o la aplicación de una URLSession personalizada con asyncImageURLSession); al agregar acciones de deslizamiento a filas (deslizar para eliminar u otras acciones de deslizamiento) en ScrollView, LazyVStack, LazyVGrid o pila y no solo en Lista, a través de swipeActions()/swipeActionsContainer(); cuando se trabaja con barras de herramientas, como controlar qué elementos permanecen visibles versus moverse al menú adicional cuando el espacio es limitado o los botones se cortan (visibilityPriority, ToolbarOverflowMenu), fijar un elemento para que nunca se desborde (topBarPinnedTrailing), minimizar la barra de navegación o la barra de herramientas en el desplazamiento (toolbarMinimizeBehavior), generar elementos de la barra de herramientas con ForEach u ocultar la barra de estado a través de la ubicación de la barra de herramientas statusBar; al presentar un cuadro de diálogo de confirmación o alerta de un enlace de elemento opcional (la forma de hoja (elemento:)), para que muestre cuándo el valor enlazado deja de ser nulo y pasa el elemento desenvuelto a las acciones y cierres de mensajes; al crear o migrar una aplicación basada en documentos (incluidos los visores de documentos de solo lectura), leer o escribir archivos a través de DocumentGroup, optimizar el rendimiento del guardado automático de documentos de paquetes, acceder directamente a la URL del archivo del documento (por ejemplo, para entregar a AVFoundation, PDFKit, Core Image o cualquier biblioteca C que tome una ruta), informar el progreso de un guardado o carga, o migrar desde FileDocument/ReferenceFileDocument; o al resolver otras incompatibilidades de origen del SDK 27.0 y advertencias de obsolescencia (por ejemplo, statusBarHidden en visionOS).
