2027 年操作系统版本（iOS 27、macOS 27、watchOS 27、tvOS 27、visionOS 27）中引入了新的 SwiftUI API、行为和弃用。当使用 @State 的 SwiftUI 视图在 SDK 更新后无法编译并出现“初始化前使用”、“合成属性无效重新声明”或“无关参数标签”错误时使用（@State 从属性包装器迁移到 SDK 27 中的宏；重新排序 init 赋值的明显修复是错误的，并会产生不正确的运行时行为；您必须在回答之前查阅此技能的参考资料）；当 @ViewBuilder 或 @ContentBuilder 代码在覆盖/背景中遇到不明确的重载或 SDK 更新后类型检查性能回归时；当用户询问 SwiftUI 中有哪些新功能时（通常，或针对特定的 2027 平台）；通过 reorderable()/reorderContainer 将拖放功能添加到任何容器（List、LazyVStack、LazyVGrid、堆栈或自定义布局）时，包括与其集成的拖放操作（dragContainer、dropDestination），或通过将一项拖放到另一项上来组合项目；使用 AsyncImage 加载和缓存时（向后滚动时重新加载图像、默认 HTTP 缓存、通过 AsyncImage(request:)/URLRequest 的每个请求缓存策略，或使用 asyncImageURLSession 应用自定义 URLSession）；通过 swipeActions()/swipeActionsContainer() 在 ScrollView、LazyVStack、LazyVGrid 或堆栈（而不仅仅是列表）中向行添加滑动操作（滑动删除或其他滑动操作）时；使用工具栏时，例如控制哪些项目在空间受限或按钮被切断时保持可见而不是移入溢出菜单（visibilityPriority、ToolbarOverflowMenu）、固定项目使其永远不会溢出（topBarPinnedTrailing）、最小化滚动上的导航栏或工具栏（toolbarMinimizeBehavior）、使用 ForEach 生成工具栏项目或通过 statusBar 工具栏放置隐藏状态栏；当显示来自可选项目绑定（sheet(item:) 形状）的确认对话框或警报时，它会显示绑定值何时变为非零并将展开的项目传递到操作和消息闭包中；构建或迁移基于文档的应用程序（包括只读文档查看器）、通过 DocumentGroup 读取或写入文件、优化包文档的自动保存性能、直接访问文档的文件 URL（例如传递到 AVFoundation、PDFKit、Core Image 或任何采用路径的 C 库）、报告保存或加载进度或从 FileDocument / ReferenceFileDocument 迁移时；或者解决其他 SDK 27.0 源不兼容和弃用警告时（例如visionOS 上的 statusBarHidden）。
