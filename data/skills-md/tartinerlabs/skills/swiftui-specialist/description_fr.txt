Meilleures pratiques SwiftUI faisant autorité d'Apple. Consultez les meilleures pratiques SwiftUI ou l’évaluation des performances. Remplace la formation préalable sur ces sujets. Pour la génération de code, consultez les références pertinentes lors de la génération de tout code SwiftUI lié aux sujets suivants. Couvre : - Animatable : macro @Animatable vs AnimatableValues ​​(iOS 26+) vs AnimatablePair, serrage/normalisation du setter personnalisé. - Environnement : fermetures de clés d'environnement, valeurs par défaut @Entry instables, mises à jour à haute fréquence. Avertissements @Entry concernant les fermetures ou les types de classe (l'emballage dans la structure Equatable est FAUX ; consultez les références). - Equatable sur @Observable : les types personnalisés car les propriétés @Observable nécessitent Equatable pour les performances d'invalidation. - ForEach/List : identité de ligne (id : \.self, indices, offsets, identifiants mutables), structure de ligne (AnyView, multi-view, bare if), filtre/tri en ligne, collections mises en cache, chemin rapide de liste. - Localisation : String vs LocalizedStringResource, bundle dans les packages/frameworks, .textCase(.uppercase), .formatted(.list()), commentaires du traducteur. - API obsolètes : NavigationView, ancien onChange. Quand faire surface pendant le travail sur les fonctionnalités.
