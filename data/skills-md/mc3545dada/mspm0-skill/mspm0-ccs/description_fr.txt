Règles d'agent CLI indépendantes des outils pour le développement TI MSPM0 avec Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig et DriverLib. À utiliser lorsqu'un agent doit inspecter ou modifier des projets MSPM0, modifier la configuration .syscfg, éviter les fichiers SysConfig/build générés, utiliser les API DriverLib, valider la sortie SysConfig, empaqueter des exemples MSPM0 réutilisables ou travailler sur un micrologiciel intégré MSPM0 de style NUEDC.
