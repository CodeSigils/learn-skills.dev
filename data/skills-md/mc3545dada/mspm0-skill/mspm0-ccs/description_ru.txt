Независимые от инструментов правила агента CLI для разработки TI MSPM0 с помощью Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig и DriverLib. Используйте, когда агенту необходимо проверить или изменить проекты MSPM0, отредактировать конфигурацию .syscfg, избежать создания файлов SysConfig/сборки, использовать API-интерфейсы DriverLib, проверить выходные данные SysConfig, упаковать повторно используемые примеры MSPM0 или работать со встроенной прошивкой MSPM0 в стиле NUEDC.
