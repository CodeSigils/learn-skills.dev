Toolneutrale CLI-Agent-Regeln für die TI MSPM0-Entwicklung mit Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig und DriverLib. Wird verwendet, wenn ein Agent MSPM0-Projekte überprüfen oder ändern, die .syscfg-Konfiguration bearbeiten, generierte SysConfig-/Build-Dateien vermeiden, DriverLib-APIs verwenden, SysConfig-Ausgaben validieren, wiederverwendbare MSPM0-Beispiele verpacken oder an eingebetteter MSPM0-Firmware im NUEDC-Stil arbeiten muss.
