Regole dell'agente CLI indipendenti dallo strumento per lo sviluppo di TI MSPM0 con Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig e DriverLib. Da utilizzare quando un agente deve controllare o modificare progetti MSPM0, modificare la configurazione .syscfg, evitare file SysConfig/build generati, utilizzare API DriverLib, convalidare l'output SysConfig, creare pacchetti di esempi MSPM0 riutilizzabili o lavorare su firmware incorporato MSPM0 in stile NUEDC.
