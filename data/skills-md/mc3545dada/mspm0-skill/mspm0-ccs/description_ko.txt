Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig 및 DriverLib를 사용한 TI MSPM0 개발을 위한 도구 중립적인 CLI 에이전트 규칙입니다. 에이전트가 MSPM0 프로젝트를 검사 또는 수정하고, .syscfg 구성을 편집하고, 생성된 SysConfig/빌드 파일을 방지하고, DriverLib API를 사용하고, SysConfig 출력을 검증하고, 재사용 가능한 MSPM0 예제를 패키지하거나 NUEDC 스타일 MSPM0 내장 펌웨어에서 작업해야 하는 경우에 사용합니다.
