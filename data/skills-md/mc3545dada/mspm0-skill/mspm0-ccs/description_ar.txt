قواعد وكيل CLI المحايدة للأدوات لتطوير TI MSPM0 باستخدام Code Composer Studio وKeil/uVision وCMake/GCC/OpenOCD وSysConfig وDriverLib. يُستخدم عندما يحتاج الوكيل إلى فحص مشاريع MSPM0 أو تعديلها، أو تحرير تكوين .syscfg، أو تجنب ملفات SysConfig/build التي تم إنشاؤها، أو استخدام DriverLib APIs، أو التحقق من صحة مخرجات SysConfig، أو حزمة أمثلة MSPM0 القابلة لإعادة الاستخدام، أو العمل على البرامج الثابتة المضمنة بنمط MSPM0 على نمط NUEDC.
