Code Composer Studio、Keil/uVision、CMake/GCC/OpenOCD、SysConfig、および DriverLib を使用した TI MSPM0 開発用のツール中立的な CLI エージェント ルール。エージェントが MSPM0 プロジェクトの検査または変更、.syscfg 構成の編集、生成された SysConfig/ビルド ファイルの回避、DriverLib API の使用、SysConfig 出力の検証、再利用可能な MSPM0 サンプルのパッケージ化、または NUEDC スタイルの MSPM0 組み込みファームウェアでの作業を行う必要がある場合に使用します。
