Reglas de agente CLI independientes de herramientas para el desarrollo de TI MSPM0 con Code Composer Studio, Keil/uVision, CMake/GCC/OpenOCD, SysConfig y DriverLib. Úselo cuando un agente necesita inspeccionar o modificar proyectos MSPM0, editar la configuración .syscfg, evitar archivos SysConfig/compilación generados, usar las API DriverLib, validar la salida de SysConfig, empaquetar ejemplos MSPM0 reutilizables o trabajar en firmware integrado MSPM0 estilo NUEDC.
