Ищите в Semantic Scholar научные статьи по всем дисциплинам с помощью анализа графа цитирования. Используйте, когда: (1) поиск статей по различным дисциплинам, (2) обход графика цитирования/ссылки, (3) поиск авторов, (4) рекомендации статей, (5) крупномасштабный библиометрический анализ. НЕ для: доступа к конкретной базе данных (используйте pubmed для биомедицины, arxiv для препринтов).
