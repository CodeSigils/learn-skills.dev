Recherchez dans Semantic Scholar des articles universitaires dans toutes les disciplines avec une analyse des graphiques de citations. À utiliser lorsque : (1) recherche d'articles dans plusieurs disciplines, (2) parcours de graphiques de citations/références, (3) recherche d'auteurs, (4) recommandations d'articles, (5) analyse bibliométrique à grande échelle. PAS pour : un accès spécifique à une base de données (utilisez pubmed pour le biomédical, arxiv pour les prépublications).
