Найдите в arXiv препринты по физике, математике, информатике, количественной биологии, количественным финансам, статистике, электротехнике, экономике. Используйте, когда: (1) поиск препринтов по теме, (2) поиск по автору, (3) просмотр категорий arXiv, (4) получение метаданных/резюме статьи. НЕ для: опубликованных журнальных статей (используйте поиск по перекрестным ссылкам), биомедицинских статей (используйте поиск по публикациям).
