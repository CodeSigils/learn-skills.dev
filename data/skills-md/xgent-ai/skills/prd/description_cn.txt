从高级产品经理的角度来看，将想法或请求转变为可以通过 SPMS 生命周期进行管理的需求——项目级“概述/目标/非目标”加上逐项 FR/NFR（包括可断言的验收标准和种子测试用例），生成 PRD 文档并将其写入 SPMS 作为开发计划的先决输入。每当用户要求“编写 PRD / 编写需求文档 / 整理需求 / 分解需求 / 提交需求 / 进行需求审查 / 将这个想法转化为需求 / 记录需求”，或者提供业务需求并希望首先澄清“要做什么、为什么以及如何知道它已经完成”时，请务必使用此技能 - 即使用户没有明确地说“PRD”。当用户希望在实施任何实施计划之前在 SPMS (FR/NFR) 中编写、澄清、分解或记录需求时，请使用它。
