以资深产品经理视角把一个想法/诉求梳理成可被 SPMS 生命周期管理的需求——项目级「概述/目标/非目标」+ 逐条 FR/NFR（含可断言的验收标准与测试用例种子），产出 PRD 文档并写入 SPMS，作为 dev-plan 的前置输入。凡用户要求「写 PRD / 写需求文档 / 梳理需求 / 拆需求 / 提需求 / 需求评审 / 把这个想法变成需求 / 录入需求」，或给出一段业务诉求并期望先把「做什么、为什么、怎样算做完」定清楚时，务必使用本 skill——即使用户没说「PRD」三个字。Use whenever the user wants requirements written, clarified, decomposed, or filed into SPMS (FR/NFR) before any implementation planning happens.
