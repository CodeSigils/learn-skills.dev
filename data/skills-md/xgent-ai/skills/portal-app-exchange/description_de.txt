Verkabelung und Fehlerbehebung bei anwendungsübergreifenden Aufrufen (OAuth Token Exchange). Immer wenn es bei einer Aufgabe darum geht, dass AppA Daten von AppB liest (z. B. bei der Testpapiererstellung, die eine Fragendatenbank liest, bei der Dateiverwaltung, die eine multimodale Analyse aufruft, beim Taskcenter, bei dem das LMS gelesen wird), bei der Deklaration von ExchangeTargets/Whitelists für Austausch/Zustimmungsmitteilung oder bei Auftreten von Symptomen wie EXCHANGE_NOT_ALLOWED, EXCHANGE_CONSENT_REQUIRED, CONSENT_REQUIRED, SECRET_INVALID, GRANT_NOT_ALLOWED oder die anwendungsübergreifende Dropdown-Liste aus unerklärlichen Gründen leer ist, stellen Sie sicher, dass Sie diesen Skill zuerst verwenden, bevor Sie Code ändern. Verwendung zum Verknüpfen oder Debuggen des App-übergreifenden Tokenaustauschs: Gewährungen, Whitelists, gemeinsame Zustimmungsgewährung, Bereichsüberschneidung und die klassischen Fehlermodi (geheime Abweichung, fehlende Benutzereinwilligungszeilen, Einschränkung der Zustimmung).
