Integre “aplicaciones de servicios de imágenes entregadas externamente”: código del lado del servidor que no está en este repositorio, entregado como imágenes de Docker (por ejemplo, base de conocimientos, análisis multimodal, puerta de enlace de tareas asincrónicas, etc.). Para cualquier tarea que implique redactar contratos de integración para un servicio externo o app.manifest.json, registrar la aplicación/aprovisionar el cableado de registro, enrutamiento /svc y verificaciones de estado, las cuentas y alcances del servicio externo, la depuración local de un solo cuadro o la revisión de los entregables de un equipo externo, asegúrese de usar esta habilidad primero, incluso si el usuario solo dice "traiga el servicio XX". Úselo al integrar una aplicación de servicio entregada por Docker construida externamente en el portal: manifiesto, registro de aplicación, aprovisionamiento, cableado /svc, depuración de una sola caja o revisión de la entrega de un equipo externo.
