Integrate “externally hosted image service applications” — server‑side code that is not in this repository, delivered as a Docker image (e.g., knowledge base, multimodal parsing, asynchronous task gateway, etc.). For any task that involves writing integration contracts or app.manifest.json for an external service, register‑app/provisioning wiring, /svc routing and health checks, service accounts and scopes of the external service, one‑box local debugging, or reviewing an external team’s deliverables, be sure to use this skill first — even if the user only says “bring the XX service in”. Use when integrating an externally‑built docker‑delivered service app into the portal: manifest, register‑app, provisioning, /svc wiring, one‑box debugging, or reviewing an external team’s delivery.
