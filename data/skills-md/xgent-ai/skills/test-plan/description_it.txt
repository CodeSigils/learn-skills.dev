Sulla base dei requisiti (testo PRD + criteri di accettazione), produci un set completo di casi di test preliminari e scrivili in SPMS (TC‑N, collegati ai requisiti), coprendo quattro categorie: percorso normale, limite, permessi e concorrenza. Per ogni criterio di accettazione, fornisci una mappatura “criterio → caso di test” e controlla la presenza di duplicati prima di scrivere. Ogni volta che un utente richiede “aggiungere casi di test / scrivere casi di test / creare un piano di test / come testare questo requisito / coprire i criteri di accettazione / i casi di test sono sufficienti”, assicurati di utilizzare questa abilità — anche se l'utente non menziona la parola “caso di test”. Usala ogni volta che l'utente vuole casi di test scritti, una copertura di test ampliata o un piano di test derivato dai requisiti SPMS e archiviato come TC‑N tramite gli strumenti PMS MCP.
