На основе требований (текст PRD + критерии приемки) создайте полный набор черновых тестовых примеров и запишите их в SPMS (TC-N, связанный с требованиями), охватывая четыре категории: нормальный путь, граница, разрешение и параллелизм. Для каждого критерия приемлемости предоставьте сопоставление «критерий → тестовый пример» и проверьте наличие дубликатов перед написанием. Всякий раз, когда пользователь запрашивает «добавить тестовые примеры / написать тестовые примеры / создать план тестирования / как проверить это требование / охватить критерии приемки / достаточны ли тестовые примеры», обязательно используйте этот навык — даже если пользователь не упоминает слово «тестовый пример». Используйте его всякий раз, когда пользователь хочет, чтобы были написаны тестовые примеры, расширено тестовое покрытие или составлен план тестирования на основе требований SPMS и сохранен в виде TC-N с помощью инструментов PMS MCP.
