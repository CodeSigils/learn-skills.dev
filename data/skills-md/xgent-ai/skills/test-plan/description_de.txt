Erstellen Sie basierend auf den Anforderungen (PRD-Text + Akzeptanzkriterien) einen vollständigen Satz von Testfallentwürfen und schreiben Sie diese in SPMS (TC-N, verknüpft mit den Anforderungen), wobei vier Kategorien abgedeckt werden: normaler Pfad, Grenze, Berechtigung und Parallelität. Stellen Sie für jedes Akzeptanzkriterium eine „Kriterium→Testfall“-Zuordnung bereit und prüfen Sie vor dem Schreiben auf Duplikate. Wenn ein Benutzer fragt: „Testfälle hinzufügen / Testfälle schreiben / einen Testplan erstellen / wie diese Anforderung getestet wird / die Akzeptanzkriterien abdecken / sind die Testfälle ausreichend“, verwenden Sie diese Fähigkeit unbedingt – auch wenn der Benutzer das Wort „Testfall“ nicht erwähnt. Verwenden Sie es immer dann, wenn der Benutzer Testfälle schreiben, die Testabdeckung erweitern oder einen Testplan aus SPMS-Anforderungen ableiten und über die PMS-MCP-Tools als TC-N ablegen möchte.
