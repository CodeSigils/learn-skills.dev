요구 사항(PRD 텍스트 + 승인 기준)을 기반으로 전체 테스트 사례 초안 세트를 생성하고 일반 경로, 경계, 권한 및 동시성이라는 네 가지 범주를 다루는 SPMS(TC‑N, 요구 사항에 연결됨)에 기록합니다. 각 합격 기준에 대해 '기준→테스트 케이스' 매핑을 제공하고, 작성 전 중복 여부를 확인합니다. 사용자가 "테스트 케이스 추가 / 테스트 케이스 작성 / 테스트 계획 생성 / 이 요구 사항을 테스트하는 방법 / 수용 기준 충족 / ​​테스트 케이스가 충분합니까"라고 요청할 때마다 사용자가 "테스트 케이스"라는 단어를 언급하지 않더라도 이 스킬을 사용하십시오. 사용자가 테스트 사례 작성, 테스트 범위 확장 또는 SPMS 요구 사항에서 파생되어 PMS MCP 도구를 통해 TC‑N으로 제출된 테스트 계획을 원할 때마다 사용하세요.
