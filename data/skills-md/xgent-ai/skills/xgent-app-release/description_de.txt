Veröffentlichen Sie eine neue Version einer Anwendung im XGENT.ai‑Portal – aus dem eigenen Repository der App, verwenden Sie das xrel_‑Release‑Token in einem einzigen Befehl, um das „Frontend‑Artefakt dist / Versions‑Bump / Image‑Swap / vollständige app.manifest‑Manifest“ einzureichen und einen Release‑Vorschlag zu erstellen: Governance‑Änderungen greifen automatisch ohne weitere Änderungen, während berechtigungsbezogene Änderungen den „Release‑Review“‑Genehmigungen der Plattform unterzogen werden; ein Login in die Portal‑Konsole oder die Einbindung von Portal‑Operations für die Übertragung ist nicht nötig. Für jede Aufgabe, die das Veröffentlichen/Release einer Front‑ oder Backend‑Image, das Hochladen von Artefakten, das Einreichen oder Ändern von app.manifest.json, das erstmalige Integrieren einer App in das Portal, die Nutzung von release‑cli/xrel_‑Token, POST /api/market/release/, die Konfiguration von Vite‑Base, das Schreiben von Release‑Schritten in CI oder das Auftreten von Symptomen wie „publish 401/404“, „publish 200 but ok:false“, „PROPOSAL_PENDING / ständig ausstehend, wartet auf Review“, „/apps/<key>/ leerer Bildschirm oder Ressource 404“, „hochgeladen aber keine Änderung online / Container nicht aktualisiert“ beinhaltet, stellen Sie sicher, dass Sie diese Fähigkeit zuerst verwenden, bevor Sie fortfahren – selbst wenn der Benutzer nur „eine Version veröffentlichen“ sagt.
