客観的要因テーブルに従って要件/チケットのストーリー ポイント (フィボナッチ スケール) を推定し、SPMS MCP インターフェイスを介して「現在の状態の読み取り → 決定 → 計画ポイントの書き戻し → スプリント キャパシティのレビュー」の閉ループを完了します。ユーザーが「ポイントの見積もり / ストーリー ポイントの見積もり / この要件へのスコアの割り当て / スプリント計画項目のポイントの見積もり / 事前スケジュール見積もりラウンドの実行 / 反復キャパシティーのレビュー」を要求するとき、または要件を提供し、再現可能で決定可能なポイント値を期待するときは常に、たとえユーザーが「ストーリー ポイント」という言葉を言わなくても、このスキルを使用する必要があります。ユーザーが SPMS 要件/問題のストーリー ポイントの見積もり、スプリント キャパシティのレビュー、または PMS MCP ツールを介して計画されたポイントを書き戻す必要があるときはいつでも使用します。
