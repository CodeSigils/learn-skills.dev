객관적인 요소 테이블에 따라 요구 사항/티켓에 대한 스토리 포인트(피보나치 척도)를 추정하고 SPMS MCP 인터페이스를 통해 "현재 상태 읽기 → 결정 → 계획된 포인트 다시 쓰기 → 스프린트 용량 검토"의 폐쇄 루프를 완료합니다. 사용자가 "포인트 추정 / 스토리 포인트 추정 / 이 요구 사항 평가 / 스프린트 계획 항목에 대한 포인트 추정 / 예약 전 빠른 추정 수행 / 반복 용량 검토"를 요청하거나 요구 사항을 제공하고 재현 가능하고 정당한 포인트 값을 기대할 때마다 사용자가 "스토리 포인트"라는 용어를 언급하지 않더라도 이 기술을 사용해야 합니다. 사용자가 SPMS 요구 사항/문제에 대한 스토리 포인트 추정, 스프린트 용량 검토 또는 PMS MCP 도구를 통해 계획된 포인트 다시 작성을 원할 때마다 사용합니다.
