Оцените баллы истории (используя уровни Фибоначчи) для требований/заявок в соответствии с таблицей объективных факторов и завершите замкнутый цикл «прочитать текущее состояние → определить → записать обратно запланированные баллы → просмотреть возможности спринта» через интерфейс MCP SPMS. Всякий раз, когда пользователь запрашивает «оценить баллы/оценить баллы истории/оценить это требование/оценить баллы для элемента планирования спринта/выполнить предварительную оценку перед планированием/пересмотреть возможности итерации» или предоставляет требование и ожидает воспроизводимого, основанного на критериях значения балла, этот навык должен использоваться — даже если пользователь явно не упоминает термин «баллы истории». Используйте всякий раз, когда пользователю требуется оценка сюжетных точек для требований/проблем SPMS, проверка производительности спринта или запись запланированных точек обратно с помощью инструментов PMS MCP.
