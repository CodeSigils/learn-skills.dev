Оцените баллы истории (шкала Фибоначчи) для требований/заявок в соответствии с таблицей объективных факторов и завершите замкнутый цикл «прочитать текущий статус → определить → записать обратно запланированные баллы → просмотреть возможности спринта» через интерфейс SPMS MCP. Всякий раз, когда пользователь запрашивает «оценку баллов / оценку сюжетных баллов / оцените это требование / оцените баллы для элементов планирования спринта / сделайте быструю оценку перед планированием / просмотрите возможности итерации» или предоставляет требование и ожидает воспроизводимое, обоснованное значение балла, этот навык должен использоваться — даже если пользователь не упоминает термин «баллы истории». Используйте всякий раз, когда пользователю требуется оценка сюжетных точек для требований/проблем SPMS, проверка производительности спринта или запись запланированных точек обратно с помощью инструментов PMS MCP.
