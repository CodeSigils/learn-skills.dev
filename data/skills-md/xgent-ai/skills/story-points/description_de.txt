Schätzen Sie Story Points (Fibonacci-Skala) für Anforderungen/Tickets gemäß der Zielfaktortabelle und schließen Sie die geschlossene Schleife „aktuellen Status lesen → ermitteln → geplante Punkte zurückschreiben → Sprintkapazität überprüfen“ über die SPMS MCP-Schnittstelle ab. Immer wenn ein Benutzer „Punktschätzung / Story-Point-Schätzung / Diese Anforderung bewerten / Punkte für Sprint-Planungselemente schätzen / vor der Planung eine schnelle Schätzung durchführen / Iterationskapazität überprüfen“ anfordert oder eine Anforderung angibt und einen reproduzierbaren, gerechtfertigten Punktwert erwartet, muss diese Fähigkeit verwendet werden – auch wenn der Benutzer den Begriff „Story Points“ nicht erwähnt. Verwenden Sie es immer dann, wenn der Benutzer eine Story-Point-Schätzung für SPMS-Anforderungen/-Probleme, eine Sprint-Kapazitätsüberprüfung oder das Zurückschreiben geplanter Punkte über die PMS-MCP-Tools wünscht.
