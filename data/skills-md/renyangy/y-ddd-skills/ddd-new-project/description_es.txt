Guía de proceso completo para desarrollar un nuevo proyecto DDD. Escenarios aplicables: establecer un proyecto DDD desde cero, incluidos talleres de tormenta de eventos, definición de contexto acotado, generación del esqueleto del proyecto y aplicación de convenciones de nomenclatura. Úselo cuando el usuario se refiere a crear un nuevo proyecto DDD, construir DDD desde cero o comenzar el diseño del proyecto con una tormenta de eventos.
