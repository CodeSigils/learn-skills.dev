Полное руководство по разработке нового проекта DDD. Применимые сценарии: создание проекта DDD с нуля, включая семинары по шторму событий, определение ограниченного контекста, создание скелета проекта и применение соглашения об именовании. Используйте, когда пользователь имеет в виду создание нового проекта DDD, создание DDD с нуля или начало разработки проекта с помощью шторма событий.
