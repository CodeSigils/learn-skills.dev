مفاهيم DDD الأساسية للتصميم القائم على المجال والنمذجة الاستراتيجية. السيناريوهات القابلة للتطبيق: فهم المبادئ الأساسية، وتصميم السياقات المحدودة، وإنشاء لغة واسعة الانتشار، ورسم خرائط السياق قبل إنشاء نموذج المجال. استخدم هذا عندما يذكر المستخدمون تصميم DDD، أو نمذجة المجال، أو السياقات المحدودة، أو اللغة واسعة الانتشار، أو التصميم الاستراتيجي.
