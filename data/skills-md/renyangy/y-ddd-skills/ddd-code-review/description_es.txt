Lista de verificación de revisión de código DDD y diagnóstico antipatrón. Escenarios aplicables: revisar el código DDD, identificar antipatrones comunes, verificar el cumplimiento de las especificaciones de capas y verificar la calidad de la implementación del diseño táctico. Utilícelo cuando el usuario mencione revisión de código, revisión de relaciones públicas, verificación de especificaciones DDD o identificación antipatrón.
