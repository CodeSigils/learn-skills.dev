Leiten Sie jede Frage, Idee oder Entscheidung durch einen Rat von 5 KI-Beratern, die sie unabhängig analysieren, sich gegenseitig anonym begutachten und ein endgültiges Urteil fällen. Basierend auf der LLM Council-Methodik von Karpathy. OBLIGATORISCHE AUSLÖSER: „Rat dies“, „Leitung des Rates“, „Kriegsraum dies“, „Drucktest dies“, „Stresstest dies“, „Debatte darüber“. STARKE AUSLÖSER (in Kombination mit einer echten Entscheidung oder einem Kompromiss verwenden): „Sollte ich X oder Y“, „Welche Option“, „Was würden Sie tun“, „Ist das der richtige Schritt“, „Bestätigen Sie dies“, „Mehrere Perspektiven erhalten“, „Ich kann mich nicht entscheiden“, „Ich bin hin- und hergerissen“. Lösen Sie NICHT auf einfache Ja/Nein-Fragen, sachliche Nachschlagewerke oder beiläufige „Sollte ich“ ohne einen sinnvollen Kompromiss aus (z. B. „Sollte ich Markdown verwenden“ ist keine Ratsfrage). Lösen Sie es aus, wenn der Benutzer eine echte Entscheidung mit Risiken, mehreren Optionen und einem Kontext vorlegt, die darauf hindeuten, dass er sie aus mehreren Blickwinkeln auf den Prüfstand stellen möchte.
