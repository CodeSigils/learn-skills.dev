Мета-навык для фигур, готовых к публикации. Используйте при создании рисунков для отправки в журнал, требующих многопанельных макетов, значимых аннотаций, полос ошибок, палитр, безопасных для дальтоников, и специального форматирования журнала (Природа, Наука, Ячейка). Управляет matplotlib/seaborn/plotly стилями публикации. Для быстрого исследования используйте Seaborn или Plotly напрямую.
