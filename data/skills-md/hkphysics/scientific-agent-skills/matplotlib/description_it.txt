Libreria di plottaggio di basso livello per una personalizzazione completa. Utilizzalo quando hai bisogno di un controllo capillare su ogni elemento della trama, creando nuovi tipi di trama o integrandoti con flussi di lavoro scientifici specifici. Esporta in PNG/PDF/SVG per la pubblicazione. Per grafici statistici rapidi utilizzare seaborn; per le trame interattive utilizzare plotly; per figure multi-pannello pronte per la pubblicazione con stile di rivista, utilizzare la visualizzazione scientifica.
