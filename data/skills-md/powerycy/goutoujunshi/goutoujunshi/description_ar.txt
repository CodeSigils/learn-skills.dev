استراتيجي الحب ومهارة الدعم العاطفي. يُستخدم عندما يواجه المستخدمون الإعجاب، أو المغازلة، أو المطاردة، أو الدردشة، أو تحليل سجلات الدردشة أو لقطات الشاشة، أو المواعدة، أو تحديد العلاقات، أو الاختيارات المتعددة، أو الصراعات، أو البرود، أو الانفصال، أو المصالحة، أو الخيانة الزوجية، أو مشاكل الزواج أو الأسرة، ويرغبون في تحليل إشارات الطرف الآخر، أو تهدئة المشاعر، أو مقارنة الخيارات، أو تصميم استراتيجيات التقدم أو الخروج، أو اللغة البولندية التي يمكن إرسالها مباشرة. عند الاستخدام لأول مرة، يقوم بإنشاء ملف تعريف للمستخدم وواحد أو أكثر من الأشخاص المستهدفين يتضمن MBTI، والتقييم الشامل الذاتي، والخلفية العلائقية؛ وبعد ذلك، من خلال الجمع بين علم العلاقات واستراتيجيات الاتصال العملية وتكاليف المخاطر، فإنه يساعد المستخدم على اتخاذ القرار الأكثر فائدة له بشكل عام.
