قم بتحويل مواد المحاضرات (الشرائح أو ملفات PDF أو المقتطفات النصية أو النصوص أو تسجيلات الصوت أو الفيديو) إلى ملاحظات Markdown شاملة وجاهزة للاختبار لـ Obsidian. يُستخدم عندما يقدم المستخدم محتوى محاضرة أو مواد دراسية أو يطلب تدوين ملاحظات أو تلخيص المحاضرات أو إنشاء أدلة دراسية. يُخرج ملاحظات منظمة تحتوي على المفاهيم والتعريفات الأساسية ورياضيات LaTeX ووسائل الشرح المهمة في الاختبار.
