Interrogez la base de données Postgres de production en lecture seule. À utiliser pour enquêter sur une incohérence des données de production, vérifier le contenu réel des lignes d'un espace de travail (par rapport à ce que montre l'API/l'interface utilisateur), confirmer le nombre de lignes après un remplissage, diagnostiquer les retards dans la boîte d'envoi/la file d'attente ou toute autre analyse médico-légale en lecture seule dans la base de données de production. Deux chemins d'accès : psql avec $POSTGRESQL_PROD_READ_ONLY_CONN_STRING depuis un terminal, ou HTTPS via le service apps/db-read-proxy lors d'une exécution dans une session web Claude Code. Pas pour les écritures : chaque couche est en lecture seule.
