Запросить производственную базу данных Postgres только для чтения. Используйте при исследовании несогласованности производственных данных, проверке того, что на самом деле находится в строках рабочей области (по сравнению с тем, что показывает API/пользовательский интерфейс), подтверждении количества строк после обратного заполнения, диагностике невыполненной работы в ящике/очереди или любой другой криминалистической экспертизе базы данных продукта, доступной только для чтения. Два пути доступа: psql с $POSTGRESQL_PROD_READ_ONLY_CONN_STRING из терминала или HTTPS через службу apps/db-read-proxy при запуске в веб-сеансе Claude Code. Не для записи — каждый слой доступен только для чтения.
