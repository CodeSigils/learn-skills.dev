Consulta la base de datos de producción de Postgres de solo lectura. Úselo al investigar una inconsistencia de datos de producción, verificar lo que hay realmente en las filas de un espacio de trabajo (frente a lo que muestra la API/UI), confirmar el recuento de filas después de un reabastecimiento, diagnosticar los retrasos en la bandeja de salida/cola o cualquier otra investigación forense de solo lectura en la base de datos de producción. Dos rutas de acceso: psql con $POSTGRESQL_PROD_READ_ONLY_CONN_STRING desde una terminal, o HTTPS a través del servicio apps/db-read-proxy cuando se ejecuta en una sesión web de Claude Code.
