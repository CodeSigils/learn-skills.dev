Cette compétence doit être utilisée lorsque l'utilisateur demande une révision contradictoire du code, un audit de sécurité, un tri des bogues, une révision de l'architecture ou toute analyse approfondie bénéficiant de plusieurs perspectives se défiant mutuellement. Les phrases de déclenchement incluent : « trier ceci », « rechercher des bogues », « audit de sécurité », « examiner ce code », « examen contradictoire », « rechercher des vulnérabilités », « auditer ceci », « examiner ce PR pour en vérifier l'exactitude ». Utilise trois rôles contradictoires (le pousseur trouve, les questions du challenger, l'arbitre décide) avec des préréglages de style (mesuré, entonnoir large, paranoïaque, ligne de base, tension maximale).
