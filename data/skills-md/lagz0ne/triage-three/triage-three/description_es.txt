Esta habilidad debe usarse cuando el usuario solicita una revisión de código contradictorio, una auditoría de seguridad, una clasificación de errores, una revisión de la arquitectura o cualquier análisis profundo que se beneficie de múltiples perspectivas que se desafíen entre sí. Las frases desencadenantes incluyen: 'clasificar esto', 'encontrar errores', 'auditoría de seguridad', 'revisar este código', 'revisión adversaria', 'encontrar vulnerabilidades', 'auditar esto para', 'revisar este PR para verificar que sea correcto'. Utiliza tres roles de adversario (el empujador encuentra, el retador pregunta, el árbitro decide) con ajustes preestablecidos de estilo (medido, de embudo ancho, paranoico, de línea de base, de tensión máxima).
