طبقة الإدراك المعززة التي تجعل المستخدمين أكثر ذكاءً من خلال ربط المحادثات بشجرة المعرفة المستمرة الخاصة بهم. استخدم بشكل استباقي عند ظهور موضوعات قد تكون لها معرفة مسبقة، وعندما يطلب المستخدمون التذكر أو الاستدعاء أو البحث أو التنظيم. تثير المناقشات الفنية، أو اتخاذ القرار، أو عمل المشروع، أو "تذكر هذا"، أو "أتذكر"، أو "ماذا أعرف عنه"، أو أي طلب للمعرفة.
