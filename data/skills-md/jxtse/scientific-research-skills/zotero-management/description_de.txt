Verwaltet eine akademische Zotero-Referenzbibliothek sowohl über die lokale API (localhost:23119, schreibgeschützt) als auch die Web-API (api.zotero.org, Lese-/Schreibzugriff) unter Verwendung einer strukturierten Sammlungshierarchie (Posteingang / Aktive Projekte / Hintergrund / Lesewarteschlange / Archiv / Meta) plus Projekt-, Status-, Prioritäts- und Typ-Tags. Behandelt das Hinzufügen von Artikeln mit vollständigen Metadaten, die Deduplizierung, das Anhängen von Herkunftshinweisen, das Verschieben von Elementen zwischen Sammlungen, das Aktualisieren von Tags nach dem Lesen, das Auflisten der priorisierten Lesewarteschlange und das Einrichten des Literaturgerüsts für ein neues Projekt. Verwenden Sie diese Option, wenn der Benutzer einen Aufsatz in Zotero hinzufügen/speichern/ablegen/organisieren, die Lesewarteschlange überprüfen/auflisten/bereinigen, Aufsätze zwischen Sammlungen verschieben, Aufsätze für ein Projekt markieren, seine Bibliothek abfragen möchte („Was habe ich auf X?“) oder Zotero für ein neues Forschungsprojekt einrichten möchte.
