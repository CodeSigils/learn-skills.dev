Zotero 学術リファレンス ライブラリを、ローカル API (localhost:23119、読み取り専用) と Web API (api.zotero.org、読み取り/書き込み) の両方を通じて管理します。構造化されたコレクション階層 (受信箱 / アクティブ プロジェクト / バックグラウンド / 読み取りキュー / アーカイブ / メタ) とプロジェクト、ステータス、優先順位、タイプ タグを使用します。完全なメタデータを含む論文の追加、重複排除、来歴メモの添付、コレクション間でのアイテムの移動、読み取り後のタグの更新、優先順位付きの読み取りキューのリスト化、および新しいプロジェクトの文献足場の設定を処理します。ユーザーが Zotero での論文の追加/保存/ファイル/整理、閲覧キューのチェック/リスト/クリーンアップ、コレクション間での論文の移動、プロジェクトの論文のタグ付け、ライブラリのクエリ (「X には何があるか?」)、または新しい研究プロジェクト用に Zotero をセットアップするように要求する場合に使用します。
