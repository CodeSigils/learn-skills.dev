Управляет академической справочной библиотекой Zotero через локальный API (localhost:23119, только для чтения) и веб-API (api.zotero.org, чтение и запись), используя структурированную иерархию коллекций (Входящие / Активные проекты / Фон / Очередь чтения / Архив / Мета) плюс теги проекта, статуса, приоритета и типа. Управляет добавлением статей с полными метаданными, дедупликацией, прикреплением заметок о происхождении, перемещением элементов между коллекциями, обновлением тегов после прочтения, составлением списка приоритетной очереди чтения и настройкой базы литературы для нового проекта. Используйте, когда пользователь просит добавить/сохранить/поместить в файл/упорядочить статью в Zotero, проверить/составить список/очистить очередь чтения, переместить статьи между коллекциями, пометить статьи для проекта, запросить их библиотеку («что у меня есть на X?») или настроить Zotero для нового исследовательского проекта.
