Administra una biblioteca de referencia académica de Zotero a través de la API local (localhost:23119, solo lectura) y la API web (api.zotero.org, lectura-escritura), utilizando una jerarquía de colección estructurada (Bandeja de entrada/Proyectos activos/Fondo/Cola de lectura/Archivo/Meta) además de etiquetas de proyecto, estado, prioridad y tipo. Se encarga de agregar artículos con metadatos completos, deduplicación, adjuntar notas de procedencia, mover elementos entre colecciones, actualizar etiquetas después de la lectura, enumerar la cola de lectura priorizada y configurar la estructura de literatura para un nuevo proyecto. Úselo cuando el usuario solicita agregar/guardar/archivar/organizar un artículo en Zotero, verificar/enumerar/limpiar la cola de lectura, mover artículos entre colecciones, etiquetar artículos para un proyecto, consultar su biblioteca ("¿qué tengo en X?"), o configurar Zotero para un nuevo proyecto de investigación.
