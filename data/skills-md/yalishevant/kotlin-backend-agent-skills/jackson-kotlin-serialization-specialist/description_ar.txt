تشخيص وتصميم تسلسل JSON وسلوك إلغاء التسلسل لتطبيقات Kotlin plus Jackson في Spring. يُستخدم عندما تفشل DTOs في إلغاء التسلسل، أو تتصرف المعلمات الافتراضية أو القابلية للإلغاء بشكل غير متوقع، أو تنحرف تنسيقات التاريخ والوقت أو التعداد، أو تتضمن حمولات متعددة الأشكال، أو يجب أن تميز دلالات PATCH بين القيمة الفارغة والغائبة، أو تخاطر تغييرات ObjectMapper بكسر واجهة برمجة التطبيقات الحالية أو عقود الرسائل.
