Диагностика и разработка поведения сериализации и десериализации JSON для приложений Kotlin Plus Jackson в Spring. Используйте, когда DTO не удается десериализовать, параметры по умолчанию или возможность обнуления ведут себя неожиданно, форматы даты и времени или перечисления смещаются, задействованы полиморфные полезные данные, семантика PATCH должна отличать значение null от отсутствия или изменения ObjectMapper рискуют нарушить существующие контракты API или сообщений.
