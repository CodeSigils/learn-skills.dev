Diagnosticar y diseñar el comportamiento de serialización y deserialización JSON para aplicaciones Kotlin plus Jackson en Spring. Úselo cuando los DTO no pueden deserializarse, los parámetros predeterminados o la capacidad de nulidad se comportan inesperadamente, los formatos de fecha, hora o enumeración cambian, hay cargas útiles polimórficas involucradas, la semántica PATCH debe distinguir nulo de ausente o los cambios de ObjectMapper corren el riesgo de romper los contratos de mensajes o API existentes.
