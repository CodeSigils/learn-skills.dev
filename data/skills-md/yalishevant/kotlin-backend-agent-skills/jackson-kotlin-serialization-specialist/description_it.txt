Diagnosticare e progettare il comportamento di serializzazione e deserializzazione JSON per le applicazioni Kotlin e Jackson in Spring. Da utilizzare quando i DTO non riescono a deserializzare, i parametri predefiniti o l'annullamento dei valori si comportano in modo imprevisto, i formati data-ora o enum si discostano, sono coinvolti payload polimorfici, la semantica PATCH deve distinguere null da assente o le modifiche di ObjectMapper rischiano di interrompere l'API esistente o i contratti di messaggio.
