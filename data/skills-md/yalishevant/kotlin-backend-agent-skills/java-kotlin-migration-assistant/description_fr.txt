Migrez le code Java vers Kotlin dans les bases de code Spring sans modifier le comportement, les contrats publics, la compatibilité du framework ou les hypothèses binaires, sauf intention explicite. À utiliser lors de la conversion incrémentielle de classes, du remplacement de modèles Lombok, de la gestion des types de plate-forme et de la nullité, de la préservation du comportement JPA et proxy ou de la planification de l'ordre de migration sécurisé d'une base de code mixte Java et Kotlin.
