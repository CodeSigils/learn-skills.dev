قم بترحيل كود Java إلى Kotlin في قواعد التعليمات البرمجية المستندة إلى Spring دون تغيير السلوك أو العقود العامة أو توافق إطار العمل أو الافتراضات الثنائية ما لم يكن ذلك مقصودًا بشكل صريح. يُستخدم عند تحويل الفئات بشكل متزايد، أو استبدال أنماط Lombok، أو إدارة أنواع الأنظمة الأساسية وقابلية البطلان، أو الحفاظ على سلوك JPA والوكيل، أو التخطيط لترتيب الترحيل الآمن لقاعدة تعليمات Java وKotlin المختلطة.
