Migrieren Sie Java-Code zu Kotlin in Spring-basierten Codebasen, ohne Verhalten, öffentliche Verträge, Framework-Kompatibilität oder binäre Annahmen zu ändern, sofern nicht ausdrücklich beabsichtigt. Verwenden Sie es, wenn Sie Klassen inkrementell konvertieren, Lombok-Muster ersetzen, Plattformtypen und Nullfähigkeit verwalten, JPA- und Proxy-Verhalten beibehalten oder die sichere Migrationsreihenfolge einer gemischten Java- und Kotlin-Codebasis planen.
