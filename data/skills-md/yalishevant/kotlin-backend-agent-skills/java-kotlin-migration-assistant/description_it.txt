Migra il codice Java su Kotlin nelle basi di codice basate su Spring senza modificare il comportamento, i contratti pubblici, la compatibilità del framework o i presupposti binari se non esplicitamente previsto. Da utilizzare quando si convertono classi in modo incrementale, si sostituiscono modelli Lombok, si gestiscono tipi di piattaforma e nullability, si preserva il comportamento JPA e proxy o si pianifica l'ordine di migrazione sicuro di una codebase mista Java e Kotlin.
