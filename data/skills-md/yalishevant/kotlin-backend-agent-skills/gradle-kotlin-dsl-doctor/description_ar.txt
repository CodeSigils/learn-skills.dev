قم بإنشاء وتصحيح وإصلاح إصدارات Kotlin + Spring Gradle مع الحد الأدنى من التغييرات المتوافقة. يُستخدم عند فشل `build.gradle.kts` أو `settings.gradle.kts`، أو عدم توافق المكونات الإضافية أو سلاسل الأدوات، أو انجراف إدارة التبعية من Spring Boot BOM، أو تعطل مسارات فئات الاختبار أو وقت التشغيل، أو يجب أن يكون تصحيح Kotlin DSL آمنًا ومتزايدًا.
