Рефакторинг кода Kotlin в сторону более четкого и идиоматического дизайна без нарушения поведения Spring, сериализации, персистентности или публичных контрактов. Используйте его, когда Kotlin со вкусом Java нуждается в очистке, моделирование предметной области должно стать более выразительным или сократить шаблонный код, но рефакторинг должен оставаться безопасным для прокси, Джексона, JPA, привязки конфигурации и существующих тестов.
