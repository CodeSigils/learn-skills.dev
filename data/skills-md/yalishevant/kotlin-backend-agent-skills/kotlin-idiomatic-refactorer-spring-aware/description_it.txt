Rifattorizza il codice Kotlin verso un design più chiaro e idiomatico senza interrompere il comportamento di Spring, la serializzazione, la persistenza o i contratti pubblici. Da utilizzare quando Kotlin con funzionalità Java necessita di pulizia, la modellazione del dominio deve diventare più espressiva o il boilerplate deve essere ridotto, ma il refactoring deve rimanere sicuro per proxy, Jackson, JPA, associazione di configurazione e test esistenti.
