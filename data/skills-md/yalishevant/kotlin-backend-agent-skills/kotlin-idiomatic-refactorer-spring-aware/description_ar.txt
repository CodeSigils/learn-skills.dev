قم بإعادة صياغة كود Kotlin نحو تصميم أكثر وضوحًا واصطلاحية دون كسر سلوك Spring أو التسلسل أو الاستمرارية أو العقود العامة. يُستخدم عندما يحتاج Kotlin ذو نكهة Java إلى التنظيف، ويجب أن تصبح نمذجة النطاق أكثر تعبيرًا، أو يجب تقليل النموذج المعياري، ولكن يجب أن تظل إعادة البناء آمنة للوكلاء، وJackson، وJPA، وربط التكوين، والاختبارات الحالية.
