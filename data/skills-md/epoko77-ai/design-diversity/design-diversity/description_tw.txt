一個用於創建「設計包目錄」的編排器，解決了 Claude 產生的單調、重複的 PPT 和網站設計的問題。它收集和提煉公開可用的設計系統和視覺風格，並創建一個設計包（prompt.md+tokens.json+preview.png+meta.yaml），在粘貼到 Claude Code 時重現該風格；在根據基線驗證多樣性後，它將包發佈到公共 GitHub 存儲庫和目錄網站。它協調一個七人代理商團隊（採購、架構、PPT 創作、網頁創作、渲染、多樣性 QA、發布）作為管道。觸發器——「設計多樣性」、「設計套件」、「設計套件目錄」、「設計系統目錄」、「PPT設計多樣化」、「網頁設計套件」、「基於提示的設計系統」、「克勞德設計單調」、「製作設計套件」。後續任務 - 「新增套件」、「更多 PPT 套件」、「新增 Web 套件」、「重新建立特定套件」、「重新驗證多樣性」、「重新創作套件」、「變更架構」、「重新部署目錄網站」、「更新儲存庫」、「重新運行」皆由此技能處理。使用韓國高級甲板簡單創建單一 PPT，使用前端設計創建一個簡單的網站。
