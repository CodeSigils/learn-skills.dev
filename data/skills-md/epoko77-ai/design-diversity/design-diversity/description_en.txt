An orchestrator for creating a “design pack catalog” that solves the problem of monotonous, repetitive PPT and website designs generated by Claude. It collects and distills publicly available design systems and visual styles, and creates a design pack (prompt.md + tokens.json + preview.png + meta.yaml) that reproduces that style when pasted into Claude Code; after verifying diversity against a baseline, it publishes the pack to a public GitHub repository and a catalog website. It coordinates a seven‑person agent team (sourcing, schema, PPT authoring, web authoring, rendering, diversity QA, publishing) as a pipeline. Triggers — “design diversity,” “design pack,” “design pack catalog,” “design system catalog,” “PPT design diversification,” “web design pack,” “prompt‑based design system,” “Claude design monotony,” “make a design pack.” Follow‑up tasks — “add pack,” “more PPT packs,” “add web pack,” “recreate specific pack,” “re‑verify diversity,” “re‑author pack,” “change schema,” “re‑deploy catalog site,” “update repo,” “re‑run” are all handled by this skill. Simple creation of a single PPT uses korean‑premium‑deck, and a single simple website uses frontend‑design.
