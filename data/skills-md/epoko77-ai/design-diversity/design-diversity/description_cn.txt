一个用于创建“设计包目录”的编排器，解决了 Claude 生成的单调、重复的 PPT 和网站设计的问题。它收集和提炼公开可用的设计系统和视觉风格，并创建一个设计包（prompt.md+tokens.json+preview.png+meta.yaml），在粘贴到 Claude Code 时重现该风格；在根据基线验证多样性后，它将包发布到公共 GitHub 存储库和目录网站。它协调一个七人代理团队（采购、架构、PPT 创作、网页创作、渲染、多样性 QA、发布）作为管道。触发器——“设计多样性”、“设计包”、“设计包目录”、“设计系统目录”、“PPT设计多样化”、“网页设计包”、“基于提示的设计系统”、“克劳德设计单调”、“制作设计包”。后续任务 - “添加包”、“更多 PPT 包”、“添加 Web 包”、“重新创建特定包”、“重新验证多样性”、“重新创作包”、“更改架构”、“重新部署目录站点”、“更新存储库”、“重新运行”均由此技能处理。使用韩国高级甲板简单创建单个 PPT，使用前端设计创建一个简单的网站。
