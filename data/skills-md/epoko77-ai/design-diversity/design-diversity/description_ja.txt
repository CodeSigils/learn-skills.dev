Claude によって生成された単調で繰り返しの PPT および Web サイトのデザインの問題を解決する「デザイン パック カタログ」を作成するためのオーケストレーター。公開されているデザイン システムとビジュアル スタイルを収集して抽出し、クロード コードに貼り付けたときにそのスタイルを再現するデザイン パック (prompt.md+tokens.json+preview.png+meta.yaml) を作成します。ベースラインと比較して多様性を検証した後、パックをパブリック GitHub リポジトリとカタログ Web サイトに公開します。 7 人のエージェント チーム (ソーシング、スキーマ、PPT オーサリング、Web オーサリング、レンダリング、多様性 QA、パブリッシング) をパイプラインとして調整します。トリガー — 「デザインの多様性」、「デザイン パック」、「デザイン パック カタログ」、「デザイン システム カタログ」、「PPT デザインの多様化」、「Web デザイン パック」、「プロンプトベースのデザイン システム」、「クロード デザインの単調さ」、「デザイン パックの作成」。フォローアップ タスク - 「パックの追加」、「PPT パックの追加」、「Web パックの追加」、「特定のパックの再作成」、「多様性の再検証」、「パックの再作成」、「スキーマの変更」、「カタログ サイトの再展開」、「リポジトリの更新」、「再実行」はすべて、このスキルによって処理されます。単一の PPT の簡単な作成には韓国のプレミアムデッキが使用され、単一の単純な Web サイトにはフロントエンドデザインが使用されます。
