Ein Orchestrator zum Erstellen eines „Design-Pack-Katalogs“, der das Problem der von Claude generierten monotonen, sich wiederholenden PPT- und Website-Designs löst. Es sammelt und destilliert öffentlich verfügbare Designsysteme und visuelle Stile und erstellt ein Designpaket (prompt.md+tokens.json+preview.png+meta.yaml), das diesen Stil reproduziert, wenn es in Claude Code eingefügt wird; Nachdem die Diversität anhand einer Baseline überprüft wurde, wird das Paket in einem öffentlichen GitHub-Repository und einer Katalog-Website veröffentlicht. Es koordiniert ein siebenköpfiges Agententeam (Sourcing, Schema, PPT-Authoring, Web-Authoring, Rendering, Diversity-QA, Veröffentlichung) als Pipeline. Auslöser – „Design-Vielfalt“, „Design-Paket“, „Design-Paket-Katalog“, „Design-System-Katalog“, „PPT-Design-Diversifizierung“, „Web-Design-Paket“, „Prompt-basiertes Design-System“, „Claude-Design-Monotonie“, „Design-Paket erstellen“. Folgeaufgaben – „Paket hinzufügen“, „mehr PPT-Pakete“, „Web-Paket hinzufügen“, „spezifisches Paket neu erstellen“, „Diversität erneut überprüfen“, „Paket erneut erstellen“, „Schema ändern“, „Katalog-Site erneut bereitstellen“, „Repository aktualisieren“, „erneut ausführen“ werden alle von dieser Fertigkeit erledigt. Für die einfache Erstellung einer einzelnen PPT wird koreanisches Premium-Deck verwendet, und für eine einzelne einfache Website wird Frontend-Design verwendet.
