Оркестратор для создания «каталога пакетов дизайна», который решает проблему монотонных, повторяющихся PPT и дизайнов веб-сайтов, созданных Клодом. Он собирает и анализирует общедоступные системы дизайна и визуальные стили и создает пакет дизайна (prompt.md+tokens.json+preview.png+meta.yaml), который воспроизводит этот стиль при вставке в Claude Code; после проверки разнообразия на соответствие базовому уровню он публикует пакет в общедоступном репозитории GitHub и на веб-сайте-каталоге. Он координирует команду агентов из семи человек (поиск ресурсов, схема, разработка PPT, веб-разработка, рендеринг, контроль разнообразия, публикация) в качестве конвейера. Триггеры — «разнообразие дизайна», «пакет дизайна», «каталог пакета дизайна», «каталог системы дизайна», «диверсификация дизайна PPT», «пакет веб-дизайна», «система дизайна на основе подсказок», «однообразие дизайна Клода», «сделать пакет дизайна». Последующие задачи — «добавление пакета», «больше пакетов PPT», «добавление веб-пакета», «воссоздание определенного пакета», «повторная проверка разнообразия», «переписывание пакета», «изменение схемы», «повторное развертывание сайта-каталога», «обновление репозитория», «повторный запуск» — все эти задачи выполняются с помощью этого навыка. Для простого создания одного PPT используется корейский премиум-дек, а для одного простого веб-сайта используется дизайн внешнего интерфейса.
