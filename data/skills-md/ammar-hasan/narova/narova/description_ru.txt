Используйте narova для видео с повествованием: пояснения с комментарием или субтитрами, диалоги с несколькими хостами (от 0 до N рассказчиков), подсказки/сценарии/README для видео, видеоролики, полученные с любого URL-адреса (сайт продукта, статья, документ, документация, репозиторий или общая страница), субтитры в караоке с синхронизацией по словам, голосовые показы, фоновые кровати и звуковые эффекты, экспорт для каждой платформы (TikTok/Reels/Shorts/LinkedIn/X), субтитры SRT/VTT, варианты перехвата A/B или локальные нейронные TTS без ключей API. Он превращает приглашение или сценарий сцены в формат MP4 с локальной озвучкой piper/xtts/qwen/chatterbox, подписями на уровне слов и визуальными эффектами, синхронизированными с речью, визуализируемыми через HyperFrames. Полный инструмент поставляется внутри навыка. Также используйте всякий раз, когда пользователь называет имя narova или файл reel.config. Для бесшумной графики без повествования используйте вместо этого простые HyperFrames.
