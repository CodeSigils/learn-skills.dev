استخدم narova لفيديو السرد الأول: الشرح المروي أو الموضح، حوار متعدد المضيفين (من 0 إلى N رواة)، موجه/نص/اقرأ إلى فيديو، مقاطع فيديو مصدرها أي عنوان URL (موقع منتج، مقالة، ورق، مستندات، مستودع، أو صفحة عامة)، تسميات توضيحية كاريوكي متزامنة مع الكلمات، عروض يتم تشغيلها بالصوت، أسرة خلفية ومؤثرات صوتية، عمليات تصدير لكل منصة (TikTok/Reels/Shorts/LinkedIn/X)، أو التسميات التوضيحية الجانبية SRT/VTT، أو متغيرات الخطاف A/B، أو TTS العصبية المحلية بدون مفاتيح API. يقوم بتحويل نص موجه أو مشهد إلى ملف MP4 مع تعليق صوتي محلي، وتسميات توضيحية على مستوى الكلمة، ومرئيات بتوقيت الكلام يتم تقديمها من خلال HyperFrames. يتم شحن الأداة الكاملة داخل المهارة. استخدمه أيضًا عندما يقوم المستخدم بتسمية narova أو ملف reel.config. بالنسبة للرسومات المتحركة الصامتة بدون السرد، استخدم إطارات HyperFrames العادية بدلاً من ذلك.
