ナレーションファーストビデオには narova を使用します: ナレーション付きまたはキャプション付きの説明者、マルチホストダイアログ (0 ～ N 人のナレーター)、プロンプト/スクリプト/README からビデオへの変換、任意の URL (製品サイト、記事、論文、ドキュメント、リポジトリ、または一般ページ) からソースされたビデオ、単語同期カラオケキャプション、音声トリガーによる公開、背景ベッドとサウンドエフェクト、プラットフォームごとのエクスポート(TikTok/Reels/Shorts/LinkedIn/X)、SRT/VTT サイドカー キャプション、フック A/B バリアント、または API キーのないローカル ニューラル TTS。プロンプトまたはシーン スクリプトを、ローカルのpiper/xtts/qwen/chatterbox ナレーション、単語レベルのキャプション、および HyperFrame を介してレンダリングされる音声タイミングのビジュアルを含む MP4 に変換します。完全なツールはスキル内に同梱されています。また、ユーザーが narova またはリール.config ファイルに名前を付ける場合にも使用します。ナレーションのないサイレント モーション グラフィックスの場合は、代わりにプレーンな HyperFrames を使用してください。
