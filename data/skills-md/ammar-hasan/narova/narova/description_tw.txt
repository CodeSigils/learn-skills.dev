使用 narova 進行旁白優先的影片：旁白或帶字幕的解釋器、多主持人對話（0 到 N 個旁白）、提示/腳本/自述文件到影片、來自任何 URL（產品網站、文章、論文、文件、儲存庫或一般頁面）的影片、文字同步卡拉 OK 字幕、語音觸發的顯示、背景床和音效、每個字幕平台的匯出 (Tikk/Real A/B 變體或沒有 API 金鑰的本機神經 TTS。它將提示或場景腳本轉換為 MP4，並帶有本地 Piper/xtts/qwen/chatterbox 畫外音、單字級字幕以及透過 HyperFrame 渲染的語音定時視覺效果。完整的工具包含在技能中。每當使用者命名 narova 或 reel.config 檔案時也可使用。對於沒有旁白的無聲動態圖形，請使用普通的超幀。
