Utilizza questo compagno Narova opzionale quando l'utente richiede esplicitamente la sintesi vocale OpenAI, una voce OpenAI come marin o cedar, un ID vocale OpenAI personalizzato, gpt-4o-mini-tts o una narrazione cloud orientabile tramite l'API OpenAI.
