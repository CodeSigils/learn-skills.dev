Verwenden Sie diesen optionalen Narova-Begleiter für umfassendes, kreatives Internet-Sourcing, wenn die integrierten Standardadapter kein geeignetes Foto, Video, Audiodatei, Schriftart, 2D-Asset, 3D-Asset, Textur, HDRI, Karte, wissenschaftliches Bildmaterial oder kulturelles Objekt erzeugen. Verwenden Sie es, wenn der Benutzer eine umfassende Anbietererkundung, browserbasierte Medien oder eine LLM-gesteuerte Suche auf wechselnden Websites anfordert. Arbeiten Sie mit der verfügbaren Websuche, HTTP oder interaktiven Browserfunktionen. benötigen keinen Browser. Halten Sie die Erkennung flexibel, überprüfen Sie das ausgewählte Element und die Rechte und geben Sie heruntergeladene Bytes über den zentralen Asset-Lebenszyklus von Narova zurück.
