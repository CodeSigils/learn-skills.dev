Solicite una revisión del código del Codex independiente y no interactiva, verifique sus hallazgos y, opcionalmente, repita la revisión después de las correcciones. Úselo cuando un usuario solicite ejecutar o llamar a Codex para su revisión, obtener una segunda opinión de Codex, auditar una implementación con respecto a una declaración de problema o una lista de verificación de aceptación, revisar cambios no confirmados o una rama/compromiso, o usar Codex como puerta de implementación final.
