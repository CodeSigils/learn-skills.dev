Verwenden Sie diese Fähigkeit, wenn der Benutzer eine PR, einen Zweigunterschied, aktuelle Änderungen, die Zusammenführungsbereitschaft, Coderisiken oder Kommentare überprüfen möchte. Erzeugt nach Schweregrad geordnete Ergebnisse, Auswirkungen auf die Architektur und eine Entscheidung zu APPROVE/COMMENT/REQUEST_CHANGES. Wenn der Benutzer auch darum bittet, Probleme zu beheben, führen Sie dies zuerst aus und übergeben Sie die Ergebnisse dann an „iterative-self-review“.
