سير عمل عرض Vulkan متعدد النواة مع المزامنة والإطارات أثناء الطيران ومجموعات الأوامر لكل مؤشر ترابط. يُستخدم عند تنفيذ حلقة العرض، أو إدارة مزامنة Vulkan، أو التعامل مع الإطارات أثناء الطيران، أو إعداد مجموعات أوامر لسلاسل العمليات المتعددة، أو عندما يسأل المستخدم عن الأسوار أو الإشارات أو الحواجز أو مزامنة سلسلة المبادلة أو تنسيق GPU/CPU.
