Meilleures pratiques OpenTelemetry pour l’instrumentation manuelle. À utiliser lors de l’ajout, de la modification ou de la révision de l’instrumentation OpenTelemetry dans le code. Conseils pour choisir les limites d'exécution, choisir les signaux, appliquer les conventions sémantiques, gérer la propagation, contrôler la cardinalité et vérifier le résultat.
