Best Practices von OpenTelemetry für die manuelle Instrumentierung. Wird zum Hinzufügen, Ändern oder Überprüfen der OpenTelemetry-Instrumentierung im Code verwendet. Anleitung zur Auswahl von Laufzeitgrenzen, zur Auswahl von Signalen, zur Anwendung semantischer Konventionen, zur Handhabung der Ausbreitung, zur Kontrolle der Kardinalität und zur Überprüfung des Ergebnisses.
