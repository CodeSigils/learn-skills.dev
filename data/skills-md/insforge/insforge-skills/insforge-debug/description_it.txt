Utilizza questa competenza quando riscontri errori, bug, problemi di prestazioni o comportamenti imprevisti in un progetto InsForge, dagli errori dell'SDK frontend ai problemi dell'infrastruttura backend. Attivazione su: SDK che restituisce oggetti di errore, risposte HTTP 4xx/5xx, errori o timeout delle funzioni edge, query di database lente, errori di autenticazione/autorizzazione, problemi del canale in tempo reale, degrado delle prestazioni del backend (CPU/memoria elevata/risposte lente), errori di distribuzione della funzione edge o errori di distribuzione Vercel frontend. Questa abilità guida l'esecuzione dei comandi diagnostici per individuare i problemi. Gli scenari manuali mostrano solo log/stati; il percorso assistito dall'intelligenza artificiale ("diagnose --ai") restituisce inoltre le cause e le soluzioni suggerite.
