Используйте этот навык при обнаружении ошибок, ошибок, проблем с производительностью или неожиданного поведения в проекте InsForge — от ошибок внешнего интерфейса SDK до проблем внутренней инфраструктуры. Запуск по: SDK, возвращающему объекты ошибок, ответы HTTP 4xx/5xx, сбои или тайм-ауты пограничных функций, медленные запросы к базе данных, сбои аутентификации/авторизации, проблемы с каналом реального времени, снижение производительности серверной части (высокий уровень загрузки ЦП/памяти/медленные ответы), сбои развертывания пограничных функций или сбои развертывания Vercel на внешнем интерфейсе. Этот навык управляет выполнением диагностических команд для обнаружения проблем. В ручных сценариях отображаются только журналы/статус; путь с помощью ИИ («diagnose --ai») дополнительно возвращает предлагаемые причины и решения.
