Utilisez cette compétence lors de l'intégration d'un fournisseur d'authentification tiers (Clerk, Auth0, WorkOS, Kinde, Stytch) avec InsForge pour l'authentification et RLS. Couvre la configuration JWT, la configuration du client, les politiques RLS de base de données et les pièges spécifiques au fournisseur pour chaque intégration prise en charge.
