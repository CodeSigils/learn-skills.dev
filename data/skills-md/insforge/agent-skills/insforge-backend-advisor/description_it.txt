Utilizza questa competenza per controlli proattivi sull'integrità del backend in un progetto InsForge: errori di configurazione della sicurezza, regressioni delle prestazioni e problemi di integrità del sistema emersi da "diagnose advisor", oltre agli approfondimenti sul lato backend associati a ciascun problema dell'advisor. Utilizzare questa capacità anche quando un utente segnala un degrado delle prestazioni a livello di backend (CPU/memoria elevata, tutte le risposte lente, esaurimento del pool di connessioni, conflitto di blocchi) senza una singola richiesta non riuscita. Attiva richieste come "controllo dello stato", "controlla il mio backend", "esamina la sicurezza", "controlla i criteri RLS", "trova query lente", "revisione delle prestazioni del backend", "CPU/memoria elevata", "tutto è lento", "integrità EC2/database/sistema" o controlli di preparazione pre-lancio. Per gli errori di runtime reattivi con una singola richiesta concreta non riuscita (oggetti errore SDK, HTTP 4xx/5xx, errori di funzione, errori di distribuzione), utilizza invece `insforge-debug`.
