Используйте этот навык для превентивного аудита работоспособности серверной части проекта InsForge — неправильных конфигураций безопасности, снижения производительности и проблем со здоровьем системы, выявленных с помощью «диагностического советника», а также глубокого изучения серверной части, связанного с каждой проблемой советника. Также используйте этот навык, когда пользователь сообщает о снижении производительности всей серверной части (высокая загрузка ЦП/памяти, медленные все ответы, исчерпание пула соединений, конфликты блокировок) без единого неудачного запроса. Запуск по таким запросам, как «проверка работоспособности», «проверка моего бэкэнда», «проверка безопасности», «проверка политик RLS», «найти медленные запросы», «проверка производительности бэкенда», «высокий уровень загрузки ЦП/памяти», «все медленно», «исправность EC2/базы данных/системы» или аудит готовности к запуску. Для реактивных ошибок времени выполнения с одним конкретным неудачным запросом (объекты ошибок SDK, HTTP 4xx/5xx, сбои функций, сбои развертывания) вместо этого используйте `insforge-debug`.
