Utilice esta habilidad para realizar auditorías proactivas del estado del backend en un proyecto de InsForge: configuraciones erróneas de seguridad, regresiones de rendimiento y problemas de salud del sistema detectados por el "asesor de diagnóstico", además de las inmersiones profundas del backend que se combinan con cada problema del asesor. Utilice también esta habilidad cuando un usuario informe una degradación del rendimiento en todo el backend (alta CPU/memoria, todas las respuestas lentas, agotamiento del grupo de conexiones, contención de bloqueo) sin una sola solicitud fallida. Activar solicitudes como "verificación de estado", "auditar mi backend", "revisar seguridad", "verificar políticas RLS", "buscar consultas lentas", "revisión de rendimiento de backend", "alta CPU/memoria", "todo es lento", "EC2/base de datos/estado del sistema" o auditorías de preparación previas al lanzamiento. Para errores de tiempo de ejecución reactivos con una única solicitud fallida concreta (objetos de error de SDK, HTTP 4xx/5xx, fallas de funciones, fallas de implementación), use `insforge-debug` en su lugar.
