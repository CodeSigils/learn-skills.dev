フロントエンド SDK エラーからバックエンド インフラストラクチャの問題まで、InsForge プロジェクトでエラー、バグ、パフォーマンスの問題、または予期しない動作が発生した場合は、このスキルを使用します。トリガー条件: SDK がエラー オブジェクトを返す、HTTP 4xx/5xx 応答、エッジ関数の失敗またはタイムアウト、遅いデータベース クエリ、認証/承認の失敗、リアルタイム チャネルの問題、バックエンドのパフォーマンスの低下 (CPU/メモリの使用量が多い/応答が遅い)、エッジ関数のデプロイの失敗、またはフロントエンドの Vercel デプロイの失敗。このスキルは、問題を特定するための診断コマンドの実行をガイドします。修正の提案は提供されません。
