Utilice esta habilidad cuando encuentre errores, problemas de rendimiento o comportamientos inesperados en un proyecto de InsForge, desde errores del SDK de frontend hasta problemas de infraestructura de backend. Activación: SDK que devuelve objetos de error, respuestas HTTP 4xx/5xx, fallas o tiempos de espera de la función perimetral, consultas lentas a la base de datos, fallas de autenticación/autorización, problemas del canal en tiempo real, degradación del rendimiento del backend (alta CPU/memoria/respuestas lentas), fallas de implementación de la función perimetral o fallas de implementación frontend de Vercel. Esta habilidad guía la ejecución de comandos de diagnóstico para localizar problemas; no proporciona sugerencias de solución.
