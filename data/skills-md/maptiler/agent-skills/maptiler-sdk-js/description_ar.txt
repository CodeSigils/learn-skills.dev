مهارة ترميز احترافية لبناء خرائط ويب تفاعلية باستخدام MapTiler SDK JS (المبني على MapLibre GL JS). يُستخدم عندما يريد المستخدم إضافة خريطة إلى تطبيق ويب، أو عرض المواقع على الخريطة، أو عرض البيانات الجغرافية، أو إنشاء محدد موقع متجر، أو إنشاء تصورات للبيانات على الخرائط، أو إضافة ترميز جغرافي أو بحث عن العناوين، أو إظهار المسارات أو مسارات نظام تحديد المواقع العالمي (GPS)، أو عرض التضاريس ثلاثية الأبعاد أو عرض الكرة الأرضية، أو استخدام صور القمر الصناعي، أو إضافة علامات أو نوافذ منبثقة، أو إنشاء خرائط حرارية أو مجموعات، أو تضمين صور خريطة ثابتة، أو الحصول على بيانات الارتفاع، أو تحديد الموقع الجغرافي لـ IP. استخدم أيضًا عندما يذكر المستخدم MapLibre GL JS - يقوم MapTiler SDK بتوسيع MapLibre مع الخدمات السحابية المضمنة والمساعدين وفواتير الجلسة. يغطي React وVue وSvelte وAngular وNext.js وvanilla JS. يتضمن واجهات برمجة التطبيقات MapTiler Cloud REST ومساعدي طبقة المتجهات وتصور الطقس والأنماط الخاصة بإطار العمل.
