使用 MapTiler SDK JS（基於 MapLibre GL JS 建置）建立互動式 Web 地圖的專家編碼技能。當使用者想要將地圖新增至 Web 應用程式、在地圖上顯示位置、顯示地理資料、建立商店定位器、在地圖上建立資料視覺化、新增地理編碼或位址搜尋、顯示路線或 GPS 軌跡、顯示 3D 地形或全球視圖、使用衛星影像、新增標記或彈出視窗、建立熱圖或聚類、嵌入靜態影像、擷取海拔資料或進行靜態影像也可以在使用者提及 MapLibre GL JS 時使用 - MapTiler SDK 透過內建雲端服務、幫助程式和會話計費來擴展 MapLibre。涵蓋 React、Vue、Svelte、Angular、Next.js 和 vanilla JS。包括 MapTiler Cloud REST API、向量圖層幫助器、天氣視覺化和特定於框架的模式。
