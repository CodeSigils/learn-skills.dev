Compétence experte en codage pour créer des cartes Web interactives avec MapTiler SDK JS (construit sur MapLibre GL JS). À UTILISER LORSQUE l'utilisateur souhaite ajouter une carte à une application Web, afficher des emplacements sur une carte, afficher des données géographiques, créer un localisateur de magasin, créer des visualisations de données sur des cartes, ajouter un géocodage ou une recherche d'adresse, afficher des itinéraires ou des traces GPS, afficher un terrain 3D ou une vue du globe, utiliser des images satellite, ajouter des marqueurs ou des fenêtres contextuelles, créer des cartes thermiques ou des clusters, intégrer des images cartographiques statiques, obtenir des données d'élévation ou effectuer une géolocalisation IP. À utiliser également lorsque l'utilisateur mentionne MapLibre GL JS — MapTiler SDK étend MapLibre avec des services cloud intégrés, des aides et une facturation de session. Couvre React, Vue, Svelte, Angular, Next.js et Vanilla JS. Inclut les API REST MapTiler Cloud, les assistants de couche vectorielle, la visualisation météo et les modèles spécifiques au framework.
