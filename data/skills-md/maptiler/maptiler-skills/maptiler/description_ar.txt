مهارة ترميز احترافية لمنصة MapTiler الكاملة - واجهات Cloud REST APIs وMapTiler SDK JS (المبنية على MapLibre GL JS) ومجموعات SDK الأصلية للأجهزة المحمولة والبنية التحتية المحلية ومخططات تجانب المتجهات. يُستخدم عندما يريد المستخدم إضافة خريطة إلى تطبيق ويب أو هاتف محمول، أو عرض المواقع أو المسارات، أو عرض البيانات الجغرافية، أو إنشاء محدد موقع المتجر، أو إنشاء تصورات للبيانات على الخرائط، أو إضافة ترميز جغرافي أو بحث عن العناوين، أو القيام بالترميز الجغرافي العكسي، أو البحث عن الارتفاع، أو تحديد الموقع الجغرافي لـ IP، أو جلب بيانات الطقس، أو تحويل الإحداثيات بين CRS/EPSG، أو تضمين صور الخرائط الثابتة، أو العمل مع مجموعات تجانب المتجهات (Planet v4، المباني، خطوط الكنتور، في الهواء الطلق، المحيط، Landcover، Cadastre)، كتابة تعبيرات نمط MapLibre أو التصميم المستند إلى البيانات، أو عرض التضاريس ثلاثية الأبعاد، أو عرض الكرة الأرضية، أو بثق المباني ثلاثية الأبعاد، أو استخدام صور الأقمار الصناعية، أو إضافة علامات، أو نوافذ منبثقة، أو خرائط حرارية، أو مجموعات، أو دمج الخرائط في React، أو Vue، أو Svelte، أو Angular، أو Next.js، أو Leaflet، أو OpenLayers، أو Cesium، أو Deck.gl، وإنشاء خرائط أصلية على iOS (Swift)، أو Android (Kotlin)، Flutter، أو React Native، يمكنك الاستضافة الذاتية باستخدام MapTiler Server أو إنشاء مربعات باستخدام MapTiler Engine CLI، أو تحميل/إدارة مجموعات البلاط عبر Admin API. استخدم أيضًا عندما يذكر المستخدم MapLibre GL JS - يقوم SDK بتوسيع MapLibre مع الخدمات السحابية المضمنة والمساعدين وفواتير الجلسة.
