Competenze di codifica esperte per l'intera piattaforma MapTiler: API REST cloud, MapTiler SDK JS (basato su MapLibre GL JS), SDK mobili nativi, infrastruttura locale e schemi di riquadri vettoriali. UTILIZZARE QUANDO l'utente desidera aggiungere una mappa a un'app Web o mobile, mostrare posizioni o percorsi, visualizzare dati geografici, creare un localizzatore di negozi, creare visualizzazioni di dati su mappe, aggiungere geocodifica o ricerca di indirizzi, eseguire geocodifica inversa, cercare elevazione, eseguire geolocalizzazione IP, recuperare dati meteorologici, trasformare le coordinate tra CRS/EPSG, incorporare immagini di mappe statiche, lavorare con set di riquadri vettoriali (Pianeta v4, Edifici, Contorni, Esterno, Oceano, Copertura del terreno, Catasto), scrivere Espressioni di stile MapLibre o stili basati sui dati, rendering di terreni 3D, visualizzazione globo o estrusione di edifici 3D, utilizzo di immagini satellitari, aggiunta di marcatori, popup, mappe di calore o clustering, integrazione di mappe in React, Vue, Svelte, Angular, Next.js, Leaflet, OpenLayers, Cesium o deck.gl, creazione di mappe native su iOS (Swift), Android (Kotlin), Flutter o React Native, hosting autonomo con MapTiler Server o genera riquadri con la CLI di MapTiler Engine oppure carica/gestisci set di riquadri tramite l'API di amministrazione. UTILIZZARE ANCHE QUANDO l'utente menziona MapLibre GL JS: l'SDK estende MapLibre con servizi cloud integrati, assistenti e fatturazione delle sessioni.
