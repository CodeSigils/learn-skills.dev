Compétence d'expert en codage pour la plate-forme MapTiler complète : API Cloud REST, MapTiler SDK JS (construit sur MapLibre GL JS), SDK mobiles natifs, infrastructure sur site et schémas de tuiles vectorielles. À UTILISER LORSQUE l'utilisateur souhaite ajouter une carte à une application Web ou mobile, afficher des emplacements ou des itinéraires, afficher des données géographiques, créer un localisateur de magasin, créer des visualisations de données sur des cartes, ajouter un géocodage ou une recherche d'adresse, effectuer un géocodage inversé, rechercher une élévation, effectuer une géolocalisation IP, récupérer des données météorologiques, transformer des coordonnées entre CRS/EPSG, intégrer des images de cartes statiques, travailler avec des jeux de tuiles vectorielles (Planète v4, Bâtiments, Contours, Extérieur, Océan, Couverture terrestre, Cadastre), écrire Expressions de style MapLibre ou style basé sur les données, rendu du terrain 3D, de la vue du globe ou de l'extrusion de bâtiments 3D, utilisation d'images satellite, ajout de marqueurs, de popups, de cartes thermiques ou de clustering, intégration de cartes dans React, Vue, Svelte, Angular, Next.js, Leaflet, OpenLayers, Cesium ou deck.gl, création de cartes natives sur iOS (Swift), Android (Kotlin), Flutter ou React Native, auto-hébergement avec MapTiler Server ou générez des tuiles avec MapTiler Engine CLI, ou téléchargez/gérez des jeux de tuiles via l'API Admin. À utiliser également lorsque l'utilisateur mentionne MapLibre GL JS : le SDK étend MapLibre avec des services cloud intégrés, des aides et une facturation de session.
