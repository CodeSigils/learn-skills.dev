Экспертные навыки программирования для всей платформы MapTiler — API Cloud REST, MapTiler SDK JS (построенный на MapLibre GL JS), собственные мобильные SDK, локальная инфраструктура и схемы векторных листов. ИСПОЛЬЗУЙТЕ, КОГДА пользователь хочет добавить карту в веб-приложение или мобильное приложение, показать местоположения или маршруты, отобразить географические данные, создать местоположение магазина, создать визуализацию данных на картах, добавить геокодирование или поиск адреса, выполнить обратное геокодирование, посмотреть высоту, выполнить геолокацию по IP, получить данные о погоде, преобразовать координаты между CRS/EPSG, встроить статические изображения карты, работать с векторными наборами плиток (Planet v4, Buildings, Contours, Outdoor, Ocean, Landcover, Cadastre), писать выражения стиля MapLibre или стили на основе данных, визуализировать 3D-рельеф, вид глобуса или вытягивание 3D-зданий, использовать спутниковые изображения, добавлять маркеры, всплывающие окна, тепловые карты или кластеризацию, интегрировать карты в React, Vue, Svelte, Angular, Next.js, Leaflet, OpenLayers, Cesium или Deck.gl, создавать собственные карты для iOS (Swift), Android (Kotlin), Flutter или React Native размещаются самостоятельно с помощью MapTiler Server, генерируют плитки с помощью интерфейса командной строки MapTiler Engine или загружают наборы плиток и управляют ими через API администратора. Также ИСПОЛЬЗУЙТЕ, КОГДА пользователь упоминает MapLibre GL JS — SDK расширяет MapLibre встроенными облачными сервисами, помощниками и оплатой сеансов.
