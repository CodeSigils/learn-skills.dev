完全な MapTiler プラットフォーム — クラウド REST API、MapTiler SDK JS (MapLibre GL JS 上に構築)、ネイティブ モバイル SDK、オンプレミス インフラストラクチャ、およびベクター タイル スキーマの専門的なコーディング スキル。ユーザーが Web またはモバイル アプリに地図を追加する、場所やルートを表示する、地理データを表示する、店舗ロケーターを構築する、地図上でデータ ビジュアライゼーションを作成する、ジオコーディングまたは住所検索を追加する、リバース ジオコーディングを行う、標高を調べる、IP 地理位置情報を行う、気象データを取得する、CRS/EPSG 間の座標を変換する、静的地図画像を埋め込む、ベクター タイルセットを操作する (Planet v4、建物、等高線、屋外、海洋、土地被覆、 Cadastre)、MapLibre スタイル式またはデータ駆動型スタイルの作成、3D 地形、グローブ ビュー、または 3D 建物の押し出しのレンダリング、衛星画像の使用、マーカー、ポップアップ、ヒートマップ、またはクラスタリングの追加、React、Vue、Svelte、Angular、Next.js、Leaflet、OpenLayers、Cesium、または Deck.gl でのマップの統合、iOS (Swift)、Android でのネイティブ マップの構築(Kotlin)、Flutter、または React Native、MapTiler Server でセルフホストするか、MapTiler Engine CLI でタイルを生成するか、Admin API 経由でタイルセットをアップロード/管理します。ユーザーが MapLibre GL JS について言及する場合にも使用してください。SDK は、組み込みのクラウド サービス、ヘルパー、およびセッション課金で MapLibre を拡張します。
