Erfahrene Programmierkenntnisse für die gesamte MapTiler-Plattform – Cloud-REST-APIs, MapTiler SDK JS (basierend auf MapLibre GL JS), native mobile SDKs, lokale Infrastruktur und Vektorkachelschemata. VERWENDEN, WENN der Benutzer eine Karte zu einer Web- oder mobilen App hinzufügen, Standorte oder Routen anzeigen, geografische Daten anzeigen, einen Filialfinder erstellen, Datenvisualisierungen auf Karten erstellen, Geokodierung oder Adresssuche hinzufügen, eine umgekehrte Geokodierung durchführen, die Höhe nachschlagen, eine IP-Geolokalisierung durchführen, Wetterdaten abrufen, Koordinaten zwischen CRS/EPSG umwandeln, statische Kartenbilder einbetten, mit Vektorkacheln (Planet v4, Gebäude, Konturen, Outdoor, Ozean, Landbedeckung, Kataster) arbeiten und schreiben möchte Ausdrücke im MapLibre-Stil oder datengesteuertes Styling, Rendern von 3D-Gelände, Globusansicht oder 3D-Gebäudeextrusion, Verwenden von Satellitenbildern, Hinzufügen von Markierungen, Popups, Heatmaps oder Clustering, Integrieren von Karten in React, Vue, Svelte, Angular, Next.js, Leaflet, OpenLayers, Cäsium oder deck.gl, Erstellen nativer Karten auf iOS (Swift), Android (Kotlin), Flutter oder React Native, Selbsthosting mit MapTiler Servern oder generieren Sie Kacheln mit der MapTiler Engine-CLI oder laden Sie Kachelsätze über die Admin-API hoch/verwalten Sie sie. Auch VERWENDEN, WENN der Benutzer MapLibre GL JS erwähnt – das SDK erweitert MapLibre um integrierte Cloud-Dienste, Hilfsprogramme und Sitzungsabrechnung.
