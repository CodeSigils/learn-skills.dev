قم بتثبيت TurboDocx SDK وقم بإنشاء رمز التكامل لـ TurboSign (التوقيعات الرقمية)، و/أو التسليم (إنشاء المستندات المستندة إلى القالب)، وTurboPartner (إدارة الشركاء)، و/أو TurboWebhooks (اشتراكات حدث التوقيع)، و/أو TurboQuote (عروض أسعار المبيعات والمقترحات). يُستخدم عندما يريد المستخدم إضافة التوقيعات الإلكترونية، أو توقيع المستندات، أو إنشاء مستندات من القوالب ذات الاستبدال المتغير، أو إدارة المؤسسة الشريكة، أو خطافات التوقيع على الويب، أو إنشاء عروض الأسعار/المقترحات/CPQ مع المنتجات وكتب الأسعار، أو أي وظيفة TurboDocx/TurboSign/TurboPartner/Deliverable/TurboWebhooks/TurboQuote لمشروعهم. يدعم JavaScript وTypeScript وPython وGo وPHP وJava وRuby.
