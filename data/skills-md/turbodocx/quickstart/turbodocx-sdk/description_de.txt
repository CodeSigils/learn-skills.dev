Installieren Sie das TurboDocx SDK und generieren Sie Integrationscode für TurboSign (digitale Signaturen), Deliverable (vorlagenbasierte Dokumentgenerierung), TurboPartner (Partnerverwaltung), TurboWebhooks (Signature-Event-Abonnements) und/oder TurboQuote (Verkaufsangebote und Angebote). Verwenden Sie diese Option, wenn der Benutzer seinem Projekt elektronische Signaturen, das Signieren von Dokumenten, das Generieren von Dokumenten aus Vorlagen mit Variablenersetzung, die Verwaltung von Partnerorganisationen, Signatur-Webhooks, die Erstellung von Angeboten/Vorschlägen/CPQ mit Produkten und Preisbüchern oder eine beliebige TurboDocx/TurboSign/TurboPartner/Deliverable/TurboWebhooks/TurboQuote-Funktionalität hinzufügen möchte. Unterstützt JavaScript, TypeScript, Python, Go, PHP, Java und Ruby.
