Установите TurboDocx SDK и сгенерируйте код интеграции для TurboSign (цифровые подписи), Deliverable (создание документов на основе шаблонов), TurboPartner (управление партнерами), TurboWebhooks (подписка на события подписи) и/или TurboQuote (коммерческие предложения и предложения). Используйте, когда пользователь хочет добавить электронные подписи, подпись документов, генерировать документы из шаблонов с подстановкой переменных, управление партнерскими организациями, веб-перехватчики для подписей, создавать котировки/предложения/CPQ с продуктами и прайс-листами или любую функциональность TurboDocx/TurboSign/TurboPartner/Deliverable/TurboWebhooks/TurboQuote в свой проект. Поддерживает JavaScript, TypeScript, Python, Go, PHP, Java и Ruby.
