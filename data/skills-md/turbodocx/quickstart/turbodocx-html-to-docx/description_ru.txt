Настройте @turbodocx/html-to-docx для преобразования HTML в документы Microsoft Word (.docx) в проекте Node.js. Используйте этот навык, когда пользователь хочет сгенерировать файлы DOCX из HTML, добавить генерацию документов в свое приложение, преобразовать шаблоны HTML в документы Word или интегрировать TurboDocx html-to-docx в свой проект. Также триггер для упоминаний о преобразовании HTML в Word, HTML в DOCX, создании документов, создании отчетов из HTML или любом запросе, включающем пакет @turbodocx/html-to-docx.
