Configurez @turbodocx/html-to-docx pour convertir du HTML en documents Microsoft Word (.docx) dans un projet Node.js. Utilisez cette compétence lorsque l'utilisateur souhaite générer des fichiers DOCX à partir de HTML, ajouter la génération de documents à son application, convertir des modèles HTML en documents Word ou intégrer TurboDocx html-to-docx dans son projet. Déclenchez également les mentions de HTML vers Word, HTML vers DOCX, de génération de documents, de génération de rapports à partir de HTML ou de toute demande impliquant le package @turbodocx/html-to-docx.
