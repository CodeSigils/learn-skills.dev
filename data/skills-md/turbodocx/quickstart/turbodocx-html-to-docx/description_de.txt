Richten Sie @turbodocx/html-to-docx ein, um HTML in Microsoft Word-Dokumente (.docx) in einem Node.js-Projekt zu konvertieren. Nutzen Sie diese Fähigkeit, wenn der Benutzer DOCX-Dateien aus HTML generieren, Dokumentgenerierung zu seiner App hinzufügen, HTML-Vorlagen in Word-Dokumente konvertieren oder TurboDocx HTML-to-Docx in sein Projekt integrieren möchte. Wird auch für Erwähnungen von HTML-zu-Word, HTML-zu-DOCX, Dokumentgenerierung, Berichtsgenerierung aus HTML oder allen Anfragen ausgelöst, die das @turbodocx/html-to-docx-Paket betreffen.
