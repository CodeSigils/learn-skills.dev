ドキュメント ページまたはガイドを読んで、実際の製品で Chrome DevTools MCP を使用して説明されている手順を実行し、それをより明確で使いやすくする方法について、優先順位が付けられた具体的な専門家のフィードバックを返すことで、ユーザー エクスペリエンスの品質を確認します。ユーザーがドキュメントのレビュー、ガイドの UX レビュー、「このドキュメントは役に立ちますか/どう改善すればよいか」の確認、ドキュメントが実際の UI から逸脱した箇所を見つけたい場合、またはドキュメントを最高のテクニカル ライティングおよびドキュメント UX 専門家の標準に準拠させたい場合に使用します。ユーザーがこのスキルに名前を付けずに、「このドキュメントを確認してください」、「このガイドを批判してください」、「このハウツーは意味がありますか」、「ドキュメントを監査してください」、または「ドキュメントに不快感を感じます」とだけ言った場合でもトリガーされます。
