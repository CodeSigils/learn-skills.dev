Überprüfen Sie eine Dokumentationsseite oder einen Leitfaden auf die Qualität der Benutzererfahrung, indem Sie sie lesen, den darin beschriebenen Weg im Live-Produkt mit Chrome DevTools MCP beschreiten und priorisiertes, spezifisches Experten-Feedback dazu geben, wie Sie es klarer und benutzerfreundlicher machen können. Verwenden Sie es immer dann, wenn der Benutzer eine Dokumentationsüberprüfung, eine UX-Überprüfung eines Leitfadens, eine Überprüfung „Ist dieses Dokument gut/wie kann ich es verbessern“ wünscht, herausfinden möchte, wo Dokumente von der eigentlichen Benutzeroberfläche abweichen, oder möchte, dass seine Dokumentation dem Standard der besten Experten für technisches Schreiben und Dokumentations-UX entspricht. Wird auch dann ausgelöst, wenn der Benutzer nur „Dieses Dokument überprüfen“, „Diese Anleitung kritisieren“, „Macht diese Anleitung Sinn“, „Unsere Dokumente prüfen“ oder „Die Dokumente fühlen sich schlecht“ sagt, ohne diese Fähigkeit zu benennen.
