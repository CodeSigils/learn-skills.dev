Revise una página de documentación o una guía para determinar la calidad de la experiencia del usuario leyéndola, siguiendo el camino que describe en el producto en vivo con Chrome DevTools MCP y brindando comentarios priorizados, específicos y de expertos sobre cómo hacerlo más claro y más utilizable. Úselo siempre que el usuario quiera una revisión de documentos, una revisión de UX de una guía, una verificación de "¿es bueno este documento? ¿Cómo puedo mejorarlo?", quiere encontrar dónde se desviaron los documentos de la interfaz de usuario real o quiere que su documentación se mantenga según el estándar de los mejores expertos en redacción técnica y documentos-UX. Se activa incluso cuando el usuario simplemente dice "revisar este documento", "criticar esta guía", "tiene sentido este procedimiento", "auditar nuestros documentos" o "los médicos se sienten mal" sin nombrar esta habilidad.
