يستخدم عندما يريد المستخدم إنشاء أو صياغة أو دعم أو تحرير أو إعادة ترتيب أو إضافة أو مراجعة مجموعة شرائح أو عرض تقديمي لـ OpenPress؛ تأليف أو مراجعة تخطيطات الشرائح وبدائل واجهة المستخدم؛ تحويل تخطيطات دعامة البيانات إلى إطار فتحة JSX؛ أو قم بالإشارة إلى شريحة أو قالب أو افتتاحية أو صفحة عمود معينة. تمتلك هذه المهارة إنشاء ضغط الشرائح، وتحرير الشرائح، وتأليف التخطيط والقالب، وبنية مصدر DeckSlide/التخطيط/واجهة المستخدم، وقرارات حدود الفتحة، وموضوع شريحة التمرير الأول، وسرد المجموعة، وكثافة الشريحة، والأصول، وانضباط الحركة، والتحقق.
