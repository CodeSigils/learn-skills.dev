Решите, какой работник CLI (Claude, OpenCode или Gemini) должен реализовать данную задачу. Маршруты по типу задачи — большой контекст для Gemini, механический для OpenCode, суждение для Claude. Возвращает выбранного работника и краткое обоснование; вызывающая сторона вызывает работника через узкую точку вызова-worker.sh оркестратора.
