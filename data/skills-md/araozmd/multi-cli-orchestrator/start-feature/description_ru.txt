Точка входа для рабочего процесса оркестровки с несколькими CLI. Используйте, когда пользователь хочет создать новую функцию, исправить ошибку или внести нетривиальные изменения. Проводит мозговой штурм спецификации, генерирует план тестирования, открывает запрос на запрос, передает его специалисту по маршрутизации и запускает цикл проверки запроса на запрос.
