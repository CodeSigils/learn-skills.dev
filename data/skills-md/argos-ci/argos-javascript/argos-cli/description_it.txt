Gestisci la piattaforma di regressione visiva Argos dal terminale: recupera metadati di build, esamina le differenze tra istantanee, carica screenshot e gestisci build CI tramite la CLI "argos". Da utilizzare quando l'utente desidera eseguire comandi Argos nella shell, negli script o nelle pipeline CI/CD oppure durante la revisione delle build di regressione visiva. Carica sempre questa skill prima di eseguire i comandi "argos": contiene il contratto del flag e le forme di output che impediscono errori silenziosi.
