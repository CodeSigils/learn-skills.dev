Utilisez la plate-forme de régression visuelle Argos à partir du terminal : récupérez les métadonnées de build, examinez les différences d'instantanés, téléchargez des captures d'écran et gérez les builds CI via la CLI « argos ». À utiliser lorsque l'utilisateur souhaite exécuter des commandes Argos dans le shell, les scripts ou les pipelines CI/CD, ou lors de l'examen des versions de régression visuelle. Chargez toujours cette compétence avant d'exécuter les commandes « argos » — elle contient le contrat d'indicateur et les formes de sortie qui empêchent les pannes silencieuses.
