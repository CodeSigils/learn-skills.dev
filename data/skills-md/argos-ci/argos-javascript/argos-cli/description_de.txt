Bedienen Sie die visuelle Regressionsplattform von Argos vom Terminal aus – rufen Sie Build-Metadaten ab, überprüfen Sie Snapshot-Unterschiede, laden Sie Screenshots hoch und verwalten Sie CI-Builds über die „Argos“-CLI. Verwenden Sie diese Option, wenn der Benutzer Argos-Befehle in der Shell, in Skripts oder in CI/CD-Pipelines ausführen möchte oder wenn er visuelle Regressionsbuilds überprüft. Laden Sie diesen Skill immer, bevor Sie „argos“-Befehle ausführen – er enthält den Flag-Vertrag und Ausgabeformen, die stille Fehler verhindern.
