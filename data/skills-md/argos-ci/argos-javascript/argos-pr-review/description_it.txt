Utilizza le build di regressione visiva di Argos come input per una revisione completa della richiesta pull. Utilizza questa competenza quando un PR include un URL di build Argos, un controllo dello stato di Argos o un commento di bot che si collega a una build Argos e devi determinare se le differenze visive corrispondono al probabile intento dello sviluppatore in base al contesto PR, alle modifiche del codice e agli screenshot prima di approvare il PR.
