Utilice las compilaciones de regresión visual de Argos como entrada para una revisión completa de la solicitud de extracción. Utilice esta habilidad cuando un PR incluya una URL de compilación de Argos, una verificación de estado de Argos o un comentario de bot que enlace a una compilación de Argos, y necesite determinar si las diferencias visuales coinciden con la posible intención del desarrollador según el contexto del PR, los cambios de código y las capturas de pantalla antes de aprobar el PR.
