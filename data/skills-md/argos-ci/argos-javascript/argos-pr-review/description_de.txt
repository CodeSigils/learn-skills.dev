Verwenden Sie die visuellen Regressions-Builds von Argos als eine Eingabe für eine vollständige Pull-Request-Überprüfung. Verwenden Sie diese Fähigkeit, wenn eine PR eine Argos-Build-URL, eine Argos-Statusprüfung oder einen Bot-Kommentar enthält, der auf einen Argos-Build verweist, und Sie anhand des PR-Kontexts, Codeänderungen und Screenshots feststellen müssen, ob die visuellen Unterschiede mit der wahrscheinlichen Absicht des Entwicklers übereinstimmen, bevor Sie die PR genehmigen.
