Создайте или обновите элемент проекта GitHub типа «документы» в качестве живого справочного списка определения готовности (DoR) команды. Этот элемент проекта определяет минимальные критерии, которым должна соответствовать пользовательская история перед входом в спринт, и к нему обращается /refine-story во время проверки соответствия DoR в конце каждого сеанса уточнения. Запускается, когда пользователь говорит «/definition-of-ready», «создать определение готовности», «настроить DoR», «обновить наше определение готовности», «каков наш DoR» или любой вариант управления контрольным списком определения готовности команды.
