PRD から抽出されたユーザー ストーリーごとに GitHub プロジェクト アイテムを作成し、GitHub プロジェクトで正しいアイテム タイプとプロジェクト フィールド (タイプ、サイズ、リスク、推定) を設定します。本文リンクを介して参照される子ユーザー ストーリーを持つ、大きなストーリーの親として Epic アイテムを作成します。ユーザーが PRD からユーザー ストーリーを作成する場合、仕様からディスカバリー ボード アイテムを生成する場合、製品ドキュメントをプロジェクト アイテムに分割する場合、製品バックログにデータを入力する場合、または GitHub プロジェクトでユーザー ストーリー アイテムを作成する場合には、このスキルを使用します。 「ユーザー ストーリーの作成」、「PRD からのユーザー ストーリー」、「ユーザー ストーリー」、「バックログ項目の生成」、「ディスカバリー ボードへの入力」、「PRD からの問題の作成」、または製品要件文書を構造化されたユーザー ストーリー プロジェクト項目に変換するバリエーションをトリガーします。
