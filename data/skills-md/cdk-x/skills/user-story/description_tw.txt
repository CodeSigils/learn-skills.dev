為從 PRD 中提取的每個使用者故事建立 GitHub 專案項目，在 GitHub 專案上設定正確的專案類型和專案欄位（類型、大小、風險、估計）。建立 Epic 專案作為大型故事的父級，並透過正文連結引用子使用者故事。每當使用者想要從 PRD 建立使用者故事、從規範產生 Discovery Board 專案、將產品文件分解為專案專案、填入產品待辦事項清單或在 GitHub 專案上建立使用者故事專案時，請使用此技能。觸發「建立使用者故事」、「來自 PRD 的使用者故事」、「使用者故事」、「產生待辦事項清單項目」、「填充發現板」、「從 PRD 建立問題」或將產品需求文件轉換為結構化使用者故事項目項目的任何變體。
