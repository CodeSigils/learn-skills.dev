Создайте элементы проекта GitHub для каждой пользовательской истории, извлеченной из PRD, задав правильный тип элемента и поля проекта (Тип, Размер, Риск, Оценка) в проекте GitHub. Создает элементы Epic в качестве родительских для больших историй, при этом дочерние пользовательские истории ссылаются на них через ссылки в теле. Используйте этот навык всякий раз, когда пользователь хочет создавать пользовательские истории на основе PRD, генерировать элементы Discovery Board на основе спецификации, разбивать документ продукта на элементы проекта, заполнять невыполненную работу по продукту или создавать элементы пользовательских историй в проекте GitHub. Запускайте «создание пользовательских историй», «пользовательские истории из PRD», «пользовательскую историю», «создание элементов невыполненной работы», «заполнение доски объявлений», «создание проблем из PRD» или любой вариант превращения документа с требованиями к продукту в структурированные элементы проекта пользовательской истории.
