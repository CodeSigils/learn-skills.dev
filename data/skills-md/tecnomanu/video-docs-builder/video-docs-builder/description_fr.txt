Enregistre et assemble des vidéos de documentation pour les applications Web à l'aide de l'automatisation du navigateur Playwright, de la narration TTS et de FFmpeg. Génère un site de documentation React avec des vidéos intégrées. À utiliser lorsqu'on vous demande de documenter une application, d'enregistrer des flux d'utilisateurs, de créer des didacticiels vidéo, des procédures pas à pas, des vidéos d'intégration, des guides étape par étape, des vidéos explicatives, « créer des documents », « documenter mon application », « montrer comment l'utiliser » ou « créer un guide vidéo ».
