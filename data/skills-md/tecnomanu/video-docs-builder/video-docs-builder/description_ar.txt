يقوم بتسجيل وتجميع مقاطع الفيديو التوثيقية لتطبيقات الويب باستخدام أتمتة متصفح Playwright وسرد TTS وFFmpeg. يُنشئ موقع مستندات React مع مقاطع فيديو مضمنة. استخدمه عندما يُطلب منك توثيق تطبيق ما، أو تسجيل تدفقات المستخدم، أو إنشاء مقاطع فيديو تعليمية، أو إرشادات تفصيلية، أو مقاطع فيديو إعدادية، أو أدلة خطوة بخطوة، أو مقاطع فيديو إرشادية، أو "إنشاء مستندات"، أو "توثيق تطبيقي"، أو "إظهار كيفية الاستخدام"، أو "إنشاء دليل فيديو".
