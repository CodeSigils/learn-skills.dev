Une boucle de développement visuelle basée sur des tests pour les applications Compose utilisant Compose HotSwan pour les tests d'appareils Android. Navigue dans l'application en direct, modifie le code, recharge à chaud et produit un rapport de démarque qui intègre les captures d'écran avant/après afin que la modification soit affichée, pas seulement revendiquée.
