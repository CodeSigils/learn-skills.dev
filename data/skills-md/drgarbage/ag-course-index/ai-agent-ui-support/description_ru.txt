Руководство по проектированию и интеграции для добавления многократно используемого интерфейса чата AI Agent в существующее веб-приложение. Используйте при добавлении встроенного ИИ-помощника, представления чата, мультимодального ввода, преобразования речи в текст, истории сеансов, пользовательского интерфейса длительного выполнения задач, состояний активности агента, настроек поставщика/модели или поддержки вызова инструментов/функций. Агент — это вспомогательный интерфейс для существующего приложения, а не основной пользовательский интерфейс приложения.
