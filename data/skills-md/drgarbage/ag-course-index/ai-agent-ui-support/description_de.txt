Design- und Integrationsanleitung zum Hinzufügen einer wiederverwendbaren AI Agent-Chat-Schnittstelle zu einer vorhandenen Webanwendung. Verwenden Sie diese Option, wenn Sie einen eingebetteten KI-Assistenten, eine Chat-Ansicht, eine multimodale Eingabe, Sprache-zu-Text, einen Sitzungsverlauf, eine Benutzeroberfläche für die Ausführung langer Aufgaben, Agentenaktivitätsstatus, Anbieter-/Modelleinstellungen oder Unterstützung für Tool-/Funktionsaufrufe hinzufügen. Der Agent ist eine unterstützende Schnittstelle für die vorhandene Anwendung und nicht die primäre Benutzeroberfläche der Anwendung.
