Conseils de conception et d'intégration pour l'ajout d'une interface de discussion AI Agent réutilisable à une application Web existante. À utiliser lors de l'ajout d'un assistant IA intégré, d'une vue de discussion, d'une entrée multimodale, d'une synthèse vocale, d'un historique de session, d'une interface utilisateur d'exécution de tâches longues, d'états d'activité de l'agent, de paramètres de fournisseur/modèle ou de la prise en charge des appels d'outils/fonctions. L'agent est une interface de prise en charge pour l'application existante plutôt que l'interface utilisateur principale de l'application.
