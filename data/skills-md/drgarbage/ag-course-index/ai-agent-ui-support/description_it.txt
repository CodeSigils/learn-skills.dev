Linee guida per la progettazione e l'integrazione per l'aggiunta di un'interfaccia di chat riutilizzabile dell'agente AI a un'applicazione Web esistente. Da utilizzare quando si aggiunge un assistente AI incorporato, visualizzazione chat, input multimodale, sintesi vocale, cronologia sessioni, interfaccia utente di esecuzione di attività lunghe, stati di attività dell'agente, impostazioni del provider/modello o supporto per chiamate a strumenti/funzioni. L'agente è un'interfaccia di supporto per l'applicazione esistente anziché l'interfaccia utente principale dell'applicazione.
