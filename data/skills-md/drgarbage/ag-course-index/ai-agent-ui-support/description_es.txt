Guía de diseño e integración para agregar una interfaz de chat reutilizable de AI Agent a una aplicación web existente. Úselo al agregar un asistente de IA integrado, vista de chat, entrada multimodal, voz a texto, historial de sesiones, interfaz de usuario de ejecución de tareas largas, estados de actividad del agente, configuración de proveedor/modelo o soporte de llamadas de herramientas/funciones. El Agente es una interfaz de soporte para la aplicación existente en lugar de la interfaz de usuario principal de la aplicación.
