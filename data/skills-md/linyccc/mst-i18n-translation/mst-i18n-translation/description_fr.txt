Détectez les changements de clé i18n (t(), <Trans i18nKey>) et les chaînes potentielles non traduites dans le diff de branche git actuel pour les projets React-i18next. Génère un JSON structuré avec des clés ajoutées (avec des valeurs traduites par l'IA pour chaque paramètre régional) et des clés supprimées. À utiliser lorsque l'utilisateur demande de collecter les traductions i18n, d'exécuter un diff de traduction, de vérifier les clés i18n manquantes ou de mentionner « mst-i18n-translation ».
