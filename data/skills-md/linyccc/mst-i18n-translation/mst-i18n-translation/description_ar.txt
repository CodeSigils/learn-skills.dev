اكتشاف تغييرات مفتاح i18n (t()، <Trans i18nKey>) والسلاسل المحتملة غير المترجمة في فرع git الحالي لمشاريع رد الفعل i18next. يقوم بإخراج JSON منظم مع مفاتيح مضافة (مع قيم مترجمة بواسطة الذكاء الاصطناعي لكل لغة) ومفاتيح تمت إزالتها. يُستخدم عندما يطلب المستخدم جمع ترجمات i18n، أو تشغيل فرق الترجمة، أو التحقق من مفاتيح i18n المفقودة، أو يذكر "mst-i18n-translation".
