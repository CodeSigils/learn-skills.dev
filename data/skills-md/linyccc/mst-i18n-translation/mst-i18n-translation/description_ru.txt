Обнаружение изменений ключа i18n (t(), <Trans i18nKey>) и потенциальных непереведенных строк в текущей разнице ветки git для проектов реакции-i18next. Выводит структурированный JSON с добавленными ключами (со значениями, переведенными AI для каждого языкового стандарта) и удаленными ключами. Используйте, когда пользователь просит собрать переводы i18n, запустить diff перевода, проверить отсутствие ключей i18n или упоминает «mst-i18n-translation».
