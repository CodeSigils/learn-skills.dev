Nebius Token Factory で専用の推論エンドポイントを作成および管理します。ユーザーがモデルを専用 GPU インスタンスにデプロイする場合、自動スケーリングを構成する場合、プライベート エンドポイントに対して推論を実行する場合、エンドポイント設定を更新する場合、またはデプロイメントを破棄する場合は、このスキルを常に使用します。 「専用エンドポイントを作成する」、「専用 GPU にモデルをデプロイする」、「Nebius エンドポイントの自動スケーリングを設定する」、「専用モデルで推論を実行する」、「エンドポイントをスケーリングする」などのフレーズ、または Token Factory での分離/プライベート推論デプロイメントに関する質問をトリガーします。
