Créez et gérez des points de terminaison d'inférence dédiés sur Nebius Token Factory. Utilisez cette compétence chaque fois que l'utilisateur souhaite déployer un modèle sur une instance GPU dédiée, configurer la mise à l'échelle automatique, exécuter une inférence sur un point de terminaison privé, mettre à jour les paramètres du point de terminaison ou supprimer un déploiement. Déclenchez des expressions telles que « créer un point de terminaison dédié », « déployer un modèle sur un GPU dédié », « configurer la mise à l'échelle automatique pour mon point de terminaison Nebius », « exécuter l'inférence sur mon modèle dédié », « mettre à l'échelle mon point de terminaison » ou toute question sur les déploiements d'inférence isolés/privés sur Token Factory.
