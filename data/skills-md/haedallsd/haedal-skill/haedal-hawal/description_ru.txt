Используйте, когда пользователь упоминает о размещении WAL, выводе Hawal, получении вознаграждений или использовании haWAL по протоколу Haedal (протокол DeFi/LST на SUI).
Триггерные фразы: «ставка хавал», «ставка хавал», «снять хавал», «снять вал», «мгновенный вывод хавал», «мгновенный вывод вал», «требовать вознаграждение хавал», «требовать вознаграждение вал».
Этот навык вызывает https://skillsapi.haedal.xyz/api/v1/hawal/* через Curl POST. По HTTP 200 возвращает txBytes (base64); если не 200, возвращается сообщение.
