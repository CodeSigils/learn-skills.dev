Используйте, когда пользователь упоминает ставку SUI, вывод средств, получение вознаграждений или работу haSUI по протоколу Haedal (протокол DeFi/LST на SUI).
Триггерные фразы: «haedal», «ставка sui», «ставка хасуи», «снять хасуи», «снять суй», «мгновенный вывод хасуи», «мгновенный вывод суй», «получить вознаграждение хасуи», «получить вознаграждение суи».
Этот навык вызывает https://skillsapi.haedal.xyz/api/v1/hasui/* через Curl POST. По HTTP 200 возвращает txBytes (base64); если не 200, возвращается сообщение.
