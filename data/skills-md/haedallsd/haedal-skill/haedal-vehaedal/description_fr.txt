À utiliser lorsque l'utilisateur mentionne le jalonnement de HAEDAL, le verrouillage, l'extension du verrouillage, la réclamation de récompenses, la désintégration ou l'exploitation de VeHaedal sur le protocole Haedal (un écosystème DeFi sur SUI).
Phrases de déclenchement : « miser sur haedal », « verrouiller haedal », « prolonger le verrouillage », « réclamer des récompenses auprès de haedal », « débloquer/échanger haedal », « ajouter à la mise », « démarrer le déclin », « arrêter le déclin », « vehaedal ».
Cette compétence appelle https://skillsapi.haedal.xyz/api/v1/vehaedal/* via curl POST. add_stake et Claim_rewards* n'ont besoin que de signerAddress (+ montant/périodes) ; add_to_existing_stake, extend_existing_lock, start_decay, stop_decay, unstake_and_claim require vehaedalObj — récupérer via get_vehaedal_list(address), présenter la liste avec current_amount/locked_amount/is_decaying/lock_end_time à l'utilisateur, puis utiliser l'ID d'objet choisi. Tous les montants sont lisibles par l'homme. Sur HTTP, 200 renvoie txBytes (base64) ; sur les non‑200 renvoie msg.
