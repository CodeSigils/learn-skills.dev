Используйте, когда пользователь упоминает ставку HAEDAL, блокировку, продление блокировки, получение вознаграждений, распад или работу VeHaedal по протоколу Haedal (экосистема DeFi на SUI).
Триггерные фразы: «ставка на хедал», «заблокировать хедал», «продлить блокировку», «получить вознаграждение от хедала», «разблокировать/выкупить хедал», «добавить в ставку», «начать распад», «остановить распад», «вехаедаль».
Этот навык вызывает https://skillsapi.haedal.xyz/api/v1/vehaedal/* через Curl POST. add_stake иclaim_rewards* нужен только SignerAddress (+сумма/периоды); add_to_existing_stake, Extend_existing_lock, start_decay, stop_decay, unstake_and_claim требуют vehaedalObj — получение через get_vehaedal_list(address), представление списка с current_amount/locked_amount/is_decaying/lock_end_time пользователю, затем использование выбранного им objectId. Все суммы читабельны для человека. По HTTP 200 возвращает txBytes (base64); если не 200, возвращается сообщение.
