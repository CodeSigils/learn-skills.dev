À utiliser lors du test des serveurs MCP : tests e2e avec l'inspecteur Sunpeak, tests de régression visuelle, tests en direct par rapport à ChatGPT réel, évaluations multimodèles, configuration Playwright ou infrastructure de test d'échafaudage avec "sunpeak test init". Fonctionne avec n'importe quel serveur MCP (Python, Go, TypeScript, etc.), pas seulement avec les projets Sunpeak.
