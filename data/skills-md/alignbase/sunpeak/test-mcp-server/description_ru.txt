Используйте при тестировании серверов MCP — тесты e2e с инспектором Sunpeak, визуальное регрессионное тестирование, живое тестирование с реальным ChatGPT, многомодельные оценки, конфигурацию Playwright или инфраструктуру тестирования строительных лесов с помощью «sunpeak test init». Работает с любым сервером MCP (Python, Go, TypeScript и т. д.), а не только с проектами Sunpeak.
