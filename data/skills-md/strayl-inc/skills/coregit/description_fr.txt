Backend Git sans serveur pour les produits natifs d’IA. Utilisez cette compétence lorsque l'utilisateur souhaite créer des dépôts git, valider du code, lire des fichiers, des branches de comparaison, rechercher du code (recherche sémantique en texte intégral ou AI), configurer le contrôle de version via l'API ou créer des bases de connaissances LLM Wiki - sans la CLI git. Gère l’intégration des utilisateurs (inscription, vérification des e-mails, clé API) entièrement depuis le terminal.
