Serverloses Git-Backend für KI-native Produkte. Verwenden Sie diese Fähigkeit, wenn der Benutzer Git-Repos erstellen, Code festschreiben, Dateien lesen, Diff-Zweige lesen, Code durchsuchen (Volltext oder semantische KI-Suche), eine Versionskontrolle über die API einrichten oder LLM-Wiki-Wissensdatenbanken erstellen möchte – ohne die Git-CLI. Verwaltet das Benutzer-Onboarding (Anmeldung, E-Mail-Verifizierung, API-Schlüssel) vollständig über das Terminal.
