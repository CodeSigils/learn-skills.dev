Backend Git serverless per prodotti nativi AI. Utilizza questa competenza quando l'utente desidera creare repository git, eseguire il commit di codice, leggere file, rami diff, cercare codice (ricerca semantica full-text o AI), impostare il controllo della versione tramite API o creare basi di conoscenza LLM Wiki, senza la CLI git. Gestisce l'onboarding dell'utente (registrazione, verifica e-mail, chiave API) interamente dal terminale.
