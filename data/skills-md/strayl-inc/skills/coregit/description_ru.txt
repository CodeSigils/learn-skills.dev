Бессерверный бэкэнд Git для продуктов с искусственным интеллектом. Используйте этот навык, когда пользователь хочет создавать репозитории git, фиксировать код, читать файлы, различать ветки, искать код (полнотекстовый поиск или семантический поиск AI), настраивать контроль версий через API или создавать базы знаний LLM Wiki — без git CLI. Осуществляет регистрацию пользователей (регистрация, проверка электронной почты, ключ API) полностью с терминала.
