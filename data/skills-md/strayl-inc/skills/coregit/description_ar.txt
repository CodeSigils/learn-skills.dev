واجهة Git بدون خادم لمنتجات الذكاء الاصطناعي الأصلية. استخدم هذه المهارة عندما يريد المستخدم إنشاء مستودعات git، أو تنفيذ التعليمات البرمجية، أو قراءة الملفات، أو فروع الفروق، أو كود البحث (النص الكامل أو البحث الدلالي باستخدام الذكاء الاصطناعي)، أو إعداد التحكم في الإصدار عبر واجهة برمجة التطبيقات، أو إنشاء قواعد معرفة LLM Wiki - بدون git CLI. يتعامل مع إعداد المستخدم (الاشتراك، التحقق من البريد الإلكتروني، مفتاح واجهة برمجة التطبيقات) بالكامل من الجهاز.
