Backend Git sin servidor para productos nativos de IA. Utilice esta habilidad cuando el usuario desee crear repositorios de git, confirmar código, leer archivos, realizar diferencias, buscar código (búsqueda semántica de texto completo o IA), configurar el control de versiones a través de API o crear bases de conocimiento LLM Wiki, sin la CLI de git. Maneja la incorporación de usuarios (registro, verificación de correo electrónico, clave API) completamente desde la terminal.
