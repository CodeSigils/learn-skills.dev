Criterios de juicio para localizar el límite correcto de un cambio solicitado: permanecer inerte fuera de él mientras se completa cada sitio requerido dentro de él. Úselo cuando el alcance sea ambiguo, una diferencia afecte superficies vecinas, las ediciones dependientes requeridas no estén claras, o una capa de compatibilidad, migración, alternativa, bandera, abstracción o implementación paralela propuesta pueda exceder la solicitud.
