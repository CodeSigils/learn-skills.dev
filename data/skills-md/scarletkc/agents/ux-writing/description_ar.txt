قواعد الحكم للنصوص والوثائق الموجهة للمستخدم: مخرجات سطر الأوامر وتشخيص الأخطاء، نصوص الأخطاء والمساعدة، ملف README وبنية الوثائق، تعليقات الشيفرة، العناوين، والتقارير المُولَّدة والعروض أو الصادرات. استخدمها عند كتابة أو تعديل أي سلسلة ظاهرة للمستخدم، عند إضافة أو إعادة هيكلة الوثائق أو تحديد أي صفحة تمتلك معلومة، عندما تكون صفحة على وشك تسجيل نسخة، حالة نشر، أو قيمة يملكها الكود بالفعل، عندما يمكن لتعليق أو عنوان أو قطعة فنية أن تحمل السبب أو خيارًا مهجورًا خلف التغيير، عندما يتطلب تغيير سلوك مسح مواقع النسخ الخاصة به، أو عند مراجعة اختلاف يؤثر على النص أو الوثائق.
