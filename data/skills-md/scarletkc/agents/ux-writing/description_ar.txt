قواعد الحكم للنصوص والوثائق الموجهة للمستخدم: مخرجات سطر الأوامر والتشخيص، رسائل الخطأ والنصوص المساعدة، ملف README وبنية الوثائق، تعليقات الشيفرة، العناوين، والتقارير المُولَّدة، العروض أو الصادرات. استخدمها عند كتابة أو تعديل أي سلسلة تظهر للمستخدم، عند إضافة أو إعادة هيكلة الوثائق أو تحديد أي صفحة تمتلك حقيقةً معينة، عندما تكون صفحة على وشك تسجيل نسخة أو حالة نشر أو قيمة يملكها الكود بالفعل، عندما يمكن لتعليق أو عنوان أو قطعة أثرية أن يحمل السبب أو خيارًا تم التخلي عنه خلف التغيير، عندما يتطلب تغيير سلوك مسح مواقع النسخ الخاصة به، أو عند مراجعة اختلاف يلمس النص أو الوثائق.
