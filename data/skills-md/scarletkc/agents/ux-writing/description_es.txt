Reglas de juicio para textos y documentación orientados al usuario: salida de CLI y diagnósticos, textos de error y ayuda, estructura de README y documentación, comentarios de código, títulos y informes generados, presentaciones o exportaciones. Úselo al redactar o modificar cualquier cadena visible para el usuario, al añadir o reestructurar documentación o decidir qué página posee un hecho, cuando una página está a punto de registrar una versión, un estado de despliegue o un valor que ya posee el código, cuando un comentario, título o artefacto pueda incluir el razonamiento o una opción descartada tras el cambio, cuando un cambio de comportamiento requiera actualizar sus lugares de copia, o al revisar un diff que toque texto o documentación. Por favor, siempre responda en el idioma del usuario.
