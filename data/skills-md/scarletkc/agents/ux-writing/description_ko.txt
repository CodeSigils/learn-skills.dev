사용자 대상 텍스트 및 문서에 대한 판단 규칙: CLI 및 진단 출력, 오류 및 도움말 텍스트, README 및 문서 구조, 코드 주석, 제목, 그리고 생성된 보고서, 프레젠테이션 자료 또는 내보내기. 다음과 같은 경우에 사용하십시오: 사용자에게 보이는 문자열을 작성하거나 변경할 때, 문서를 추가하거나 재구성하거나 어떤 페이지가 사실을 소유할지 결정할 때, 페이지가 버전, 배포 상태 또는 코드가 이미 소유하고 있는 값을 기록하려 할 때, 주석, 제목, 혹은 아티팩트에 변경 배경이나 포기된 옵션을 담을 수 있을 때, 동작 변경으로 인해 복사 위치를 전체적으로 정리해야 할 때, 혹은 복사본이나 문서에 영향을 주는 차이를 검토할 때.
