Diseñe sitios web y aplicaciones que los agentes de IA puedan consumir, navegar e interactuar. Úselo al crear cualquier sitio, aplicación o producto que los agentes utilizarán como usuario final, no solo para rastrear o indexar. Cubre la estructura semántica, la accesibilidad como interfaz de agente, los datos legibles por máquina, los patrones de API primero y los protocolos emergentes (llms.txt, MCP, NLWeb, A2UI) que preparan los sitios para agentes.
