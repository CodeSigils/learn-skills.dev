Создавайте веб-сайты и приложения, которые агенты ИИ смогут использовать, перемещаться и взаимодействовать с ними. Используйте при создании любого сайта, приложения или продукта, который агенты будут использовать в качестве конечного пользователя, а не только при сканировании или индексировании. Охватывает семантическую структуру, доступность как интерфейс агента, машиночитаемые данные, шаблоны, ориентированные на API, и новые протоколы (llms.txt, MCP, NLWeb, A2UI), которые делают сайты готовыми к работе с агентами. Запускается по следующим причинам: удобный для агентов, читаемый для агентов, доступный для агентов, AX, взаимодействие с агентами, агентная сеть, двойной интерфейс, машиночитаемый, llms.txt, интеграция MCP, NLWeb, дерево доступности, ARIA для агентов, структурированные данные, JSON-LD, Schema.org, проектирование с упором на API, сборка для агентов, готовность к работе с агентами.
