Concevez des sites Web et des applications que les agents d’IA peuvent utiliser, naviguer et interagir avec. À utiliser lors de la création d'un site, d'une application ou d'un produit que les agents utiliseront en tant qu'utilisateur final, et pas seulement lors de l'exploration ou de l'indexation. Couvre la structure sémantique, l'accessibilité en tant qu'interface d'agent, les données lisibles par machine, les modèles API-first et les protocoles émergents (llms.txt, MCP, NLWeb, A2UI) qui rendent les sites prêts pour les agents. Déclencheurs sur : convivial pour les agents, lisible par l'agent, accessible par l'agent, AX, expérience d'agent, Web agent, double interface, lisible par machine, llms.txt, intégration MCP, NLWeb, arborescence d'accessibilité, ARIA pour les agents, données structurées, JSON-LD, Schema.org, conception API-first, build pour les agents, prêt pour l'agent.
