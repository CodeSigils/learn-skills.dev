Manage a project's Claude Code context layer (CLAUDE.md, .claude/rules/, .claude/skills/) using the directive model. Three commands: handle-one-directive (add, update, or evaluate a single knowledge point — "I want Claude to know X", "add a rule", "这个要加进去", "帮 Claude 记住"), rebuild (reprocess all existing context from scratch — "rebuild", "重建", "start fresh"), audit (score the health of the current context layer — "audit", "health check", "评分", "what's wrong with my CLAUDE.md"). Also proactively suggest audit when noticing bloat or wrong-layer content — never modify files without explicit user confirmation.
