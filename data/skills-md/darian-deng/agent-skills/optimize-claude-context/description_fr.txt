Gérer la couche contextuelle Claude Code d'un projet (CLAUDE.md, .claude/rules/, .claude/skills/) à l'aide du modèle de directive. Trois commandes : handle-one-directive (ajouter, mettre à jour ou évaluer un seul point de connaissance — "Je veux que Claude connaisse X", "ajouter une règle", "这个要加进去", "帮 Claude 记住"), reconstruire (retraiter tout le contexte existant à partir de zéro - "reconstruire", "重建", "recommencer à zéro"), audit (évaluer l'état de santé de la couche de contexte actuelle - "audit", "health check", "评分", "qu'est-ce qui ne va pas avec mon CLAUDE.md"). Suggérez également un audit de manière proactive lorsque vous remarquez une surcharge ou un contenu de mauvaise couche : ne modifiez jamais les fichiers sans confirmation explicite de l'utilisateur.
