Управляйте контекстным слоем кода Claude проекта (CLAUDE.md, .claude/rules/, .claude/skills/) с помощью модели директив. Три команды: handle-one-directive (добавление, обновление или оценка одной точки знаний — «Я хочу, чтобы Клод знал X», «добавить правило», «这个要加进去», «帮 Claude 记住»), rebuild (переобработка всего существующего контекста с нуля — «перестроить», «重建», «начать заново»), аудит (оценить работоспособность текущего контекстного слоя — «аудит», «проверка здоровья», «评分», «что не так с моим CLAUDE.md»). Также заранее предложите провести аудит при обнаружении раздутого содержимого или содержимого неправильных слоев — никогда не изменяйте файлы без явного подтверждения пользователя.
