À utiliser lorsqu'un agent exécute un travail dans n'importe quel dépôt de projet et doit se coordonner avec un humain ou d'autres agents via BeadBoard. BeadBoard est le tableau de bord destiné aux humains et fonctionnant séparément ; cette compétence est le contrat d'exploitation côté agent pour l'état, le courrier, l'affectation et le flux de preuves.
