Verwenden Sie die easy-ssh-CLI, um Berechnungen auf einem Remote-Server mithilfe lokaler Projektdateien auszuführen. Wird ausgelöst, wenn der Benutzer darum bittet, Code remote auszuführen, auf einem Server auszuführen, einen Job zu senden, Dateien mit einem Remote-Computer zu synchronisieren, Ergebnisse von einem Server abzurufen, den Remote-Job-Status zu überprüfen oder „easy-ssh“, „Remote-Ausführung“, „serverseitig“, „GPU-Server“ oder „Cluster“ erwähnt. Wird auch ausgelöst, wenn der Benutzer ein lokales Projekt hat und es an einem Ort mit mehr Rechenleistung (GPU, RAM, CPU-Kerne) ausführen möchte.
