Utilizza la CLI easy-ssh per eseguire calcoli su un server remoto utilizzando file di progetto locali. Si attiva quando l'utente chiede di eseguire codice in remoto, eseguire su un server, inviare un lavoro, sincronizzare file su un computer remoto, estrarre risultati da un server, controllare lo stato del lavoro remoto o menziona "easy-ssh", "esecuzione remota", "lato server", "server GPU" o "cluster". Si attiva anche quando l'utente ha un progetto locale e desidera eseguirlo da qualche parte con più risorse di calcolo (GPU, RAM, core della CPU).
