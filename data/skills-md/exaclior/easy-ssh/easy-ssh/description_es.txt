Utilice la CLI easy-ssh para ejecutar cálculos en un servidor remoto utilizando archivos de proyecto locales. Se activa cuando el usuario solicita ejecutar código de forma remota, ejecutar en un servidor, enviar un trabajo, sincronizar archivos con una máquina remota, extraer resultados de un servidor, verificar el estado del trabajo remoto o menciona "easy-ssh", "ejecución remota", "lado del servidor", "servidor GPU" o "clúster". También se activa cuando el usuario tiene un proyecto local y quiere ejecutarlo en algún lugar con más computación (GPU, RAM, núcleos de CPU).
