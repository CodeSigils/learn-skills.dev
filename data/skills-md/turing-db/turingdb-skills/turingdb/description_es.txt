Inicie, consulte, escriba y administre bases de datos de gráficos de columnas de TuringDB utilizando el SDK de Python y el dialecto Cypher. DISPARAR cuando: el código importa `turingdb` o `TuringDB`; el usuario menciona TuringDB, turing db o base de datos de turing; el usuario pregunta sobre consultas de TuringDB Cypher, control de versiones de gráficos con cambios/confirmaciones, búsqueda de vectores en TuringDB o la CLI `turingdb`; Los archivos contienen cadenas de conexión de TuringDB (localhost:6666) o llamadas al SDK de TuringDB (`client.query`, `client.new_change`, `client.load_graph`). SALTAR: preguntas genéricas sobre gráficos/Neo4j/Cypher sin mención de TuringDB; Trabajo general de base de datos no relacionado con TuringDB.
