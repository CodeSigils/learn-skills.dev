Démarrez, interrogez, écrivez et gérez des bases de données de graphiques en colonnes TuringDB à l'aide du SDK Python et du dialecte Cypher. DÉCLENCHEMENT lorsque : le code importe `turingdb` ou `TuringDB` ; l'utilisateur mentionne TuringDB, turing db ou turing database ; l'utilisateur pose des questions sur les requêtes TuringDB Cypher, la gestion des versions de graphiques avec modifications/validations, la recherche de vecteurs dans TuringDB ou la CLI `turingdb` ; les fichiers contiennent des chaînes de connexion TuringDB (localhost:6666) ou des appels du SDK TuringDB (`client.query`, `client.new_change`, `client.load_graph`). SKIP : questions génériques sur les graphiques/Neo4j/Cypher sans mention de TuringDB ; travail général sur la base de données sans rapport avec TuringDB.
