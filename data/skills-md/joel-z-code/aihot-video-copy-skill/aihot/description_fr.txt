AI HOT (aihot.virxact.com) Compétence de requête d'informations sur l'IA chinoise. Lorsqu'un utilisateur souhaite savoir « ce qui se passe dans le cercle de l'IA aujourd'hui », « rapport quotidien sur l'IA », « AI HOT », « actualités sur l'IA », « points chauds de l'IA », « IA récentes », « ce qu'OpenAI/Anthropic/Google ont récemment publié », « l'actualité de l'IA aujourd'hui », « l'actualité de l'IA aujourd'hui », « jeter un œil à la dynamique de l'industrie de l'IA », « quelles sont les versions de grands modèles aujourd'hui », « le cercle de l'IA hier », « voir les éléments sélectionnés », « la sélection AI HOT », « les articles sur l'IA de la semaine dernière », « les versions de modèles d'IA », « Sorties de produits IA », « Tendances de l'industrie de l'IA », « Conseils et points de vue sur l'IA » ou toute autre requête d'informations sur l'IA chinoise, cette compétence doit être utilisée. Même si l’utilisateur dit seulement « cercle IA », « actualités IA », « rapport quotidien IA » ou demande simplement « ce qui s’est passé aujourd’hui » alors que le contexte est IA / grands modèles / LLM / entrepreneuriat, la compétence doit être déclenchée. La compétence bouclera directement une API REST publique pour récupérer les données et les formater dans un briefing de démarque chinoise, ne nécessitant aucune clé API ou configuration de serveur MCP de la part de l'utilisateur. **Ne sous-déclenchez pas** : si l'utilisateur demande des actualités sur l'IA et que vous n'invoquez pas cette compétence, vous vous fierez à des données d'entraînement obsolètes comme actualités d'aujourd'hui, ce qui sera préjudiciable à l'utilisateur. 

Veuillez toujours répondre dans la langue de l'utilisateur.
