AI HOT (aihot.virxact.com) Навык информационного запроса китайского ИИ. Когда пользователь хочет знать, «что происходит сегодня в сфере ИИ», «Ежедневный отчет ИИ», «AI HOT», «Новости ИИ», «Горячие точки ИИ», «недавний ИИ», «что недавно выпустили OpenAI/Anthropic/Google», «горячий ИИ сегодня», «новости ИИ сегодня», «взгляните на тенденции отрасли ИИ», «какие крупные модели были выпущены сегодня», «Круг ИИ вчера», «проверьте выбранные элементы», «Выбор AI HOT», «Документы по ИИ за прошедшую неделю», «Выпуски моделей ИИ», «Выпуски продуктов ИИ», «Обновления отрасли ИИ», «Советы и мнения по ИИ» или любой другой информационный запрос по ИИ в Китае — следует использовать этот навык. Даже если пользователь говорит только «Круг ИИ», «Новости ИИ», «Ежедневный отчет ИИ» или просто спрашивает «что произошло сегодня», в то время как контекст — ИИ / крупные модели / LLM / предпринимательство, этот навык должен быть активирован. Skill будет напрямую использовать общедоступный REST API для получения данных и компиляции их в брифинг по уценке на китайском языке, не требуя от пользователя настройки какого-либо ключа API или сервера MCP. **Не использовать недостаточный триггер** — если пользователь запрашивает новости ИИ, а вы не активируете этот навык, вы будете использовать устаревшие данные обучения в качестве сегодняшних новостей, что нанесет вред пользователю. 

Пожалуйста, всегда отвечайте на языке пользователя.
