AI HOT (aihot.virxact.com) 中国の AI 情報クエリ スキル。ユーザーが「今日 AI サークルで何が起こっているか」、「AI 日報」、「AI HOT」、「AI ニュース」、「AI ホットスポット」、「最近の AI」、「OpenAI/Anthropic/Google が最近リリースしたもの」、「今日の AI ホット」、「今日の AI ニュース」、「AI 業界のダイナミクスを見てみる」、「今日の大型モデルのリリース」、「昨日の AI サークル」、「選択したアイテムを表示」、「AI HOT」を知りたい場合「選択」、「過去 1 週間の AI 論文」、「AI モデルのリリース」、「AI 製品のリリース」、「AI 業界のトレンド」、「AI のヒントと視点」、またはその他の中国の AI 情報のクエリには、このスキルを使用する必要があります。ユーザーが「AI サークル」、「AI ニュース」、「AI 日報」とだけ言った場合でも、コンテキストが AI / 大型モデル / LLM / 起業家精神であるときに単に「今日何が起こった」と尋ねた場合でも、スキルはトリガーされる必要があります。このスキルは、パブリック REST API を直接カールしてデータを取得し、それを中国語のマークダウン ブリーフィングにフォーマットします。ユーザーによる API キーや MCP サーバーの設定は必要ありません。 **アンダートリガーしないでください** - ユーザーが AI ニュースを要求したときにこのスキルを呼び出さない場合、今日のニュースとして古いトレーニング データに依存することになり、ユーザーにとって有害で​​す。
