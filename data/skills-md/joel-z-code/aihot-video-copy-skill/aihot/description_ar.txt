AI HOT (aihot.virxact.com) مهارة الاستعلام عن معلومات الذكاء الاصطناعي الصينية. يجب استخدامه عندما يريد المستخدم معرفة أي استفسارات معلوماتية عن الذكاء الاصطناعي الصيني مثل "ما يحدث في دائرة الذكاء الاصطناعي اليوم"، "التقرير اليومي للذكاء الاصطناعي"، "أخبار الذكاء الاصطناعي"، "نقاط الذكاء الاصطناعي الساخنة"، "الذكاء الاصطناعي الحديث"، "ما الذي أصدرته OpenAI/Anthropic/Google مؤخرًا"، "الذكاء الاصطناعي الساخن اليوم"، "أخبار الذكاء الاصطناعي اليوم"، "ألقِ نظرة على اتجاهات صناعة الذكاء الاصطناعي"، "ما هي النماذج الكبيرة التي تم إصدارها اليوم"، "دائرة الذكاء الاصطناعي بالأمس"، "التحقق من العناصر المحددة"، "اختيارات الذكاء الاصطناعي الساخنة"، "أوراق الذكاء الاصطناعي". من الأسبوع الماضي،" "إصدارات نماذج الذكاء الاصطناعي"، "إصدارات منتجات الذكاء الاصطناعي"، "اتجاهات صناعة الذكاء الاصطناعي"، "نصائح ووجهات نظر حول الذكاء الاصطناعي"، وما إلى ذلك. حتى إذا قال المستخدم فقط "دائرة الذكاء الاصطناعي"، أو "أخبار الذكاء الاصطناعي"، أو "التقرير اليومي للذكاء الاصطناعي"، أو ببساطة سأل "ماذا حدث اليوم" وكان السياق هو الذكاء الاصطناعي / النماذج الكبيرة / ماجستير إدارة الأعمال / ريادة الأعمال، فيجب تفعيل هذه المهارة. ستقوم المهارة مباشرة بتجعيد واجهة REST API العامة لجلب البيانات وتنظيمها في ملخص تخفيض السعر الصيني، دون مطالبة المستخدم بتكوين أي مفتاح API أو خادم MCP. **لا تقم بالتحفيز**—إذا طلب المستخدم معلومات الذكاء الاصطناعي ولم تقم باستدعاء هذه المهارة، فسوف تستخدم بيانات تدريب قديمة كأخبار اليوم، وهو ما يضر المستخدم.
