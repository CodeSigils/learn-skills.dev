Методология разработки Coding Agent Harness. Для команд, использующих агенты кодирования (такие как Codex, Claude Code, Gemini CLI и т. д.) для разработки долгосрочных проектов, на основе проекта пользователя создается полная система разработки жгутов. Включает: диагностику проекта, создание входных файлов AGENTS.md + CLAUDE.md, создание каталога coding-agent-harness/, цикл планирования, управление SSoT, операционную модель доставки, управление репозиторием, CI/CD, протокол долгосрочных задач, отчет о состязательной проверке, маршрутизацию проверки, параллельную разработку с рабочими деревьями, регрессию SSoT и многоуровневую регрессию Evidence-Depth, обход/закрытие Закрытие индекса, Cadence Ledger, локальные варианты уроков по задачам и подробная документация продвигаемых уроков, а также глобальный контекстный реестр обратной записи Harness Ledger. Когда пользователь запрашивает настройку процесса разработки агента кодирования, создание системы регрессионного тестирования, разработку AGENTS.md / CLAUDE.md, планирование структуры выполнения для долгосрочных задач агента, циклов проверки субагента, отчетов о состязательной проверке, создание системы или упоминает разработку системы, используйте эту возможность. Это также применимо к таким сценариям, как «помогите мне создать спецификацию разработки агента», «как не дать ИИ отвлекаться на длительные задачи», «как провести регрессионное тестирование агента», «помогите мне инициализировать систему проекта» и тому подобные запросы.
