Méthodologie d’ingénierie du harnais d’agent de codage. Pour les équipes utilisant des agents de codage (tels que Codex, Claude Code, Gemini CLI, etc.) pour développer des projets à long terme, il construit un système d'ingénierie de harnais complet sur le projet de l'utilisateur. Comprend : diagnostic de projet, génération des fichiers d'entrée AGENTS.md + CLAUDE.md, création du répertoire coding‑agent‑harness/, Planning Loop, gouvernance SSoT, Delivery Operating Model, Repository Governance, CI/CD, Long‑Running Task Protocol, Adversarial Review Report, Review Routing, développement parallèle avec worktrees, Regression SSoT et Evidence‑Depth tiered regression, Walkthrough/Closeout Index close, Cadence Ledger, tâche locale les candidats aux cours et la documentation détaillée des cours promus, ainsi que le grand livre de réécriture contextuelle global Harness Ledger. Lorsque l'utilisateur demande à mettre en place un processus de développement d'agent de codage, à établir un système de tests de régression, à concevoir AGENTS.md / CLAUDE.md, à planifier le cadre d'exécution pour les tâches d'agent à long terme, les boucles d'examen de sous-agents, les rapports d'examen contradictoires, à créer un harnais ou à mentionner l'ingénierie de harnais, utilisez cette fonctionnalité. Cela s'applique également à des scénarios tels que « aidez-moi à créer une spécification de développement d'agent », « comment empêcher l'IA de dériver sur de longues tâches », « comment effectuer des tests de régression d'agent », « aidez-moi à initialiser le harnais du projet » et des demandes similaires.
