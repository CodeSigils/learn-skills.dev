منهجية هندسة تسخير وكيل الترميز. بالنسبة للفرق التي تستخدم وكلاء الترميز (مثل Codex، وClaude Code، وGemini CLI، وما إلى ذلك) لتطوير مشاريع طويلة الأجل، فإنها تبني نظامًا هندسيًا متكاملاً في مشروع المستخدم. يتضمن: تشخيص المشروع، وإنشاء ملفات الإدخال AGENTS.md + CLAUDE.md، وإنشاء دليل coding-agent-harness/، وحلقة التخطيط، وحوكمة SSoT، ونموذج تشغيل التسليم، وإدارة المستودع، وCI/CD، وبروتوكول المهام طويل الأمد، وتقرير مراجعة الخصومة، وتوجيه المراجعة، والتطوير المتوازي مع أشجار العمل، والانحدار SSoT، والانحدار المتدرج لعمق الأدلة، إغلاق فهرس الإرشادات التفصيلية/الإغلاق، وCadence Ledger، ومرشحي دروس المهام المحلية والوثائق التفصيلية للدرس المعزز، ودفتر أستاذ الكتابة الخلفي للسياق العالمي Harness Ledger. عندما يطلب المستخدم إعداد عملية تطوير وكيل الترميز، أو إنشاء نظام اختبار الانحدار، أو تصميم AGENTS.md / CLAUDE.md، أو تخطيط إطار التنفيذ لمهام الوكيل طويلة الأجل، أو حلقات مراجعة الوكيل الفرعي، أو تقارير المراجعة التنافسية، أو بناء أداة تسخير، أو ذكر هندسة تسخير، استخدم هذه الإمكانية. وينطبق أيضًا على سيناريوهات مثل "ساعدني في إنشاء مواصفات تطوير الوكيل"، و"كيفية منع الذكاء الاصطناعي من الانجراف في المهام الطويلة"، و"كيفية إجراء اختبار انحدار الوكيل"، و"ساعدني في تهيئة أدوات المشروع"، والطلبات المشابهة.
