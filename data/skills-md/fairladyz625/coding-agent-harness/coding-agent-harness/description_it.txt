Metodologia di ingegneria del cablaggio dell'agente di codifica. Per i team che utilizzano agenti di codifica (come Codex, Claude Code, Gemini CLI, ecc.) per sviluppare progetti a lungo termine, crea un sistema di ingegneria di cablaggio completo per i progetti degli utenti. Include: diagnosi del progetto, generazione di file di ingresso AGENTS.md + CLAUDE.md, impostazione della directory coding‑agent‑harness/, Planning Loop, SSoT governance, Delivery Operating Model, Repository Governance, CI/CD, Long‑Running Task Protocol, Adversarial Review Report, Review Routing, sviluppo parallelo con alberi di lavoro, Regression SSoT con regressione della profondità delle prove graduate, Finalizzazione dell'indice Walkthrough/Closeout, Cadence Ledger, candidati e promossi alle lezioni locali documentazione dettagliata della lezione e Harness Ledger per il registro di write-back del contesto globale.

Quando gli utenti richiedono di impostare un flusso di lavoro di sviluppo dell'agente di codifica, stabilire un sistema di test di regressione, progettare AGENTS.md / CLAUDE.md, pianificare il quadro di esecuzione per attività dell'agente a lungo termine, creare cicli di revisione di sub-agente, produrre rapporti di revisione contraddittoria, costruire un cablaggio o menzionare l'ingegneria del cablaggio, utilizzare questa competenza. Si applica anche a scenari come "aiutami a impostare una specifica di sviluppo dell'agente", "come evitare che l'intelligenza artificiale vada alla deriva su compiti lunghi", "come eseguire test di regressione per gli agenti", "aiutami a inizializzare il cablaggio del progetto", ecc.
