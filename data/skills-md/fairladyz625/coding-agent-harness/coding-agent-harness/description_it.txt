Metodologia di ingegneria del cablaggio dell'agente di codifica. Per i team che utilizzano agenti di codifica (come Codex, Claude Code, Gemini CLI, ecc.) per sviluppare progetti a lungo termine, crea un sistema di ingegneria di cablaggio completo sul progetto dell'utente. Include: diagnosi del progetto, generazione di file di ingresso AGENTS.md + CLAUDE.md, creazione della directory coding‑agent‑harness/, Planning Loop, governance SSoT, modello operativo di consegna, governance del repository, CI/CD, protocollo di attività di lunga durata, rapporto di revisione contraddittoria, routing delle revisioni, sviluppo parallelo con alberi di lavoro, regressione SSoT e regressione a livelli Evidence‑Depth, chiusura dell'indice di walkthrough/closeout, registro di cadenza, candidati alla lezione di attività locale, documentazione dettagliata della lezione promossa e registro di riscrittura del contesto globale Harness Ledger. Quando l'utente richiede di impostare un processo di sviluppo dell'agente di codifica, stabilire un sistema di test di regressione, progettare AGENTS.md / CLAUDE.md, pianificare la struttura di esecuzione per attività dell'agente a lungo termine, cicli di revisione di sub-agente, rapporti di revisione contraddittoria, creare un cablaggio o menzionare l'ingegneria del cablaggio, utilizzare questa funzionalità. Si applica anche a scenari come "aiutami a creare una specifica di sviluppo dell'agente", "come evitare che l'intelligenza artificiale vada alla deriva su attività lunghe", "come eseguire test di regressione dell'agente", "aiutami a inizializzare il cablaggio del progetto" e richieste simili.
