Metodología de ingeniería de Coding Agent Harness. Para los equipos que utilizan agentes de codificación (como Codex, Claude Code, Gemini CLI, etc.) para desarrollar proyectos a largo plazo, crea un sistema de ingeniería de arnés completo en el proyecto del usuario. Incluye: diagnóstico de proyecto, generación de archivos de entrada AGENTS.md + CLAUDE.md, creación del directorio/agente de codificación, bucle de planificación, gobernanza SSoT, modelo operativo de entrega, gobernanza del repositorio, CI/CD, protocolo de tareas de larga duración, informe de revisión adversarial, enrutamiento de revisión, desarrollo paralelo con árboles de trabajo, regresión SSoT y regresión por niveles de profundidad de evidencia, cierre de índice de recorrido/cierre, libro mayor de cadencia, local candidatos a lecciones de tareas y documentación detallada de lecciones promocionadas, y libro de contabilidad de reescritura de contexto global de Harness Ledger. Cuando el usuario solicita configurar un proceso de desarrollo de agente de codificación, establecer un sistema de prueba de regresión, diseñar AGENTS.md / CLAUDE.md, planificar el marco de ejecución para tareas de agente a largo plazo, ciclos de revisión de subagente, informes de revisión adversarios, crear un arnés o mencionar la ingeniería de arnés, utilice esta capacidad. También se aplica a escenarios como "ayúdame a crear una especificación de desarrollo de agente", "cómo evitar que la IA se desvíe en tareas largas", "cómo hacer pruebas de regresión del agente", "ayúdame a inicializar el arnés del proyecto" y solicitudes similares.
