UTILISER QUAND : contrôle de qualité Markdown, validation, formatage ou génération d'un index à partir du frontmatter YAML sous forme de CSV, de table Markdown ou de liste Markdown. Analyse du schéma de front YAML (clé, valeur, type, liste, imbrication), hiérarchie des titres (nombre H1, niveau séquentiel), vérification des fragments de liens/références via rumdl, syntaxe de format via rumdl fmt. EXCLU : compilation de génération/modèle de texte sans validation de cible.
