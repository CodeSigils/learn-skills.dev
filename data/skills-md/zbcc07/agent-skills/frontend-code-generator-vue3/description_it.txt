Abilità di refactoring della pagina: genera codice di pagina conforme a Vue3 altamente fedele da bozze di progettazione (file Figma o screenshot di pagina). Inserisci una bozza di progettazione o uno screenshot, genera file di pagina completi che separano dati/DOM, segui le convenzioni di directory e supporta l'adattamento reattivo. Si attiva quando l'utente fornisce una bozza/uno screenshot del progetto e richiede lo sviluppo della pagina front-end.
