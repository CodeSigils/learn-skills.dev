Навыки рефакторинга страниц: генерирует высокоточный код страницы, совместимый с Vue3, из черновиков дизайна (файлов Figma или снимков экрана страниц). Введите черновой вариант дизайна или снимок экрана, выведите полные файлы страниц, которые разделяют данные/DOM, соответствуют соглашениям о каталогах и поддерживают адаптивную адаптацию. Срабатывает, когда пользователь предоставляет черновик дизайна/скриншот и запрашивает разработку интерфейсной страницы.
