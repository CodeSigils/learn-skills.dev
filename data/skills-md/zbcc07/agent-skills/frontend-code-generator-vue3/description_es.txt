Ingrese un borrador de diseño o una captura de pantalla, genere archivos de página completos que separen datos/DOM, siga las convenciones de directorio y admita la adaptación receptiva. Se activa cuando el usuario proporciona un borrador de diseño o una captura de pantalla y solicita el desarrollo de la página de inicio.
