Geben Sie einen Designentwurf oder Screenshot ein, geben Sie vollständige Seitendateien aus, die Daten/DOM trennen, befolgen Sie Verzeichniskonventionen und unterstützen Sie reaktionsfähige Anpassungen. Wird ausgelöst, wenn der Benutzer einen Designentwurf/Screenshot bereitstellt und die Entwicklung einer Front-End-Seite anfordert.
