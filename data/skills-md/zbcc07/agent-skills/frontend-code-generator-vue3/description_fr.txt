Compétence de refactorisation de page : génère un code de page très fidèle, conforme à Vue3, à partir de brouillons de conception (fichiers Figma ou captures d'écran de page). Saisissez un brouillon de conception ou une capture d'écran, produisez des fichiers de page complets qui séparent les données/DOM, suivez les conventions de répertoire et prenez en charge l'adaptation réactive. Déclenché lorsque l'utilisateur fournit un brouillon de conception/une capture d'écran et demande le développement d'une page frontale.
