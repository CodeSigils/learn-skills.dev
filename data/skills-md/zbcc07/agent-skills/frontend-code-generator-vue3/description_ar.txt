مهارة إعادة هيكلة الصفحة: إنشاء رمز صفحة متوافق للغاية مع Vue3 من مسودات التصميم (ملفات Figma أو لقطات شاشة الصفحة). أدخل مسودة تصميم أو لقطة شاشة، وأخرج ملفات صفحة كاملة تفصل بين البيانات/DOM، واتبع اصطلاحات الدليل، ودعم التكيف سريع الاستجابة. يتم تشغيله عندما يقدم المستخدم مسودة تصميم/لقطة شاشة ويطلب تطوير الصفحة الأمامية.
