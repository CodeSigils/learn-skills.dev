Wird verwendet, um GitCode-PRs zu überprüfen und detaillierte Überprüfungsschlussfolgerungen zu generieren oder zeilenweise Kommentare zu veröffentlichen, indem PR-Metadaten, Unterschiede und der gesamte Repository-Kontext kombiniert werden. Wird verwendet, wenn Benutzer eine GitCode-PR überprüfen, einen GitCode-PR-Link überprüfen, Änderungsrisiken analysieren oder Bewertungskommentare zur GitCode-PR veröffentlichen möchten. Typische Auslöser sind „diese PR überprüfen“, „diese PR überprüfen“, „PR prüfen“ oder die direkte Bereitstellung eines GitCode-PR-Links, z. B. https://gitcode.com/owner/repo/pull/123.
