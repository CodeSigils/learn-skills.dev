GitCode PR을 검토하고 심층적인 검토 결론을 생성하거나 PR 메타데이터, 차이점 및 전체 저장소 컨텍스트를 결합하여 한 줄씩 설명을 게시하는 데 사용됩니다. 사용자가 GitCode PR을 검토하고, GitCode PR 링크를 확인하고, 변경 위험을 분석하거나, GitCode PR에 검토 의견을 게시하려는 경우에 사용됩니다. 일반적인 트리거에는 "이 PR 검토", "이 PR 검토", "PR 확인" 또는 GitCode PR 링크 직접 제공(예: https://gitcode.com/owner/repo/pull/123)이 포함됩니다.
