يُستخدم لمراجعة GitCode PRs، والجمع بين البيانات التعريفية للعلاقات العامة، والاختلافات، وسياق الريبو بأكمله لإنشاء استنتاجات مراجعة متعمقة أو نشر تعليقات سطرًا بسطر. يُستخدم عندما يريد المستخدم مراجعة GitCode PR، أو التحقق من رابط GitCode PR، أو تحليل مخاطر التغيير، أو نشر تعليقات المراجعة على GitCode PR. تتضمن المشغلات النموذجية "مراجعة هذه العلاقات العامة" أو "مراجعة هذه العلاقات العامة" أو "التحقق من العلاقات العامة" أو توفير رابط GitCode PR مباشرةً، على سبيل المثال، https://gitcode.com/owner/repo/pull/123.
