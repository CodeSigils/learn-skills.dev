Utilisé pour examiner les PR GitCode et générer des conclusions d'examen approfondies ou publier des commentaires ligne par ligne en combinant les métadonnées PR, les différences et l'ensemble du contexte du référentiel. Utilisé lorsque les utilisateurs souhaitent réviser un PR GitCode, vérifier un lien GitCode PR, analyser les risques de changement ou publier des commentaires de révision sur le PR GitCode. Les déclencheurs typiques incluent « examiner ce PR », « examiner ce PR », « vérifier le PR » ou fournir directement un lien PR GitCode, par exemple https://gitcode.com/owner/repo/pull/123.
