Utilisé pour examiner les PR GitCode et générer des conclusions d'examen approfondies ou des commentaires par ligne en combinant les métadonnées PR, les différences et l'ensemble du contexte du référentiel. À utiliser lorsque l'utilisateur souhaite réviser un PR GitCode, vérifier un lien GitCode PR, analyser le risque de changement ou publier des commentaires de révision sur le PR GitCode. Les déclencheurs typiques incluent « examiner ce PR », « inspecter ce PR », « vérifier le PR » ou fournir directement un lien GitCode PR tel que https://gitcode.com/owner/repo/pull/123.
