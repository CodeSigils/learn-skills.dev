Используется для проверки запросов GitCode и формирования выводов углубленного обзора или публикации построчных комментариев путем объединения метаданных PR, различий и всего контекста репозитория. Используется, когда пользователи хотят просмотреть PR GitCode, проверить ссылку на PR GitCode, проанализировать риски изменений или опубликовать комментарии к PR GitCode. Типичные триггеры включают «просмотреть этот PR», «просмотреть этот PR», «проверить PR» или прямое предоставление ссылки на PR GitCode, например, https://gitcode.com/owner/repo/pull/123.
