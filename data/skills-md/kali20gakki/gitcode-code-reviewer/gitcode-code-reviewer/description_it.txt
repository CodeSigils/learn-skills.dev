Utilizzato per rivedere i PR GitCode, combinando metadati PR, differenze e l'intero contesto della base di codice per generare conclusioni di revisione approfondite o pubblicare commenti riga per riga. Da utilizzare quando l'utente desidera rivedere un GitCode PR, controllare un collegamento GitCode PR, analizzare i rischi di modifica o pubblicare commenti di revisione su GitCode PR. I trigger tipici includono "rivedi questo PR", "rivedi questo PR", "controlla il PR" o fornire direttamente un collegamento PR GitCode, ad esempio https://gitcode.com/owner/repo/pull/123.
