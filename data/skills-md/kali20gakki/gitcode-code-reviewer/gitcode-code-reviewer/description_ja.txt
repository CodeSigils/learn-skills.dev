GitCode PR をレビューし、PR メタデータ、差分、リポジトリ コンテキスト全体を組み合わせて、詳細なレビューの結論を生成したり、行ごとのコメントを投稿したりするために使用されます。ユーザーが GitCode PR をレビューする場合、GitCode PR リンクを確認する場合、変更リスクを分析する場合、または GitCode PR にレビュー コメントを投稿する場合に使用されます。一般的なトリガーには、「この PR をレビューする」、「この PR をレビューする」、「PR を確認する」、または GitCode PR リンク (例: https://gitcode.com/owner/repo/pull/123) を直接提供するなどが含まれます。
