GitCode PR をレビューし、PR メタデータ、差分、リポジトリ コンテキスト全体を組み合わせて、詳細なレビューの結論を生成したり、行ごとのコメントを投稿したりするために使用されます。ユーザーが GitCode PR をレビューする場合、GitCode PR リンクを確認する場合、変更リスクを分析する場合、またはレビュー コメントを GitCode PR に公開する場合に使用します。一般的なトリガーには、「この PR をレビューする」、「この PR をレビューする」、「PR を確認する」、または https://gitcode.com/owner/repo/pull/123 などの GitCode PR リンクを直接提供するなどが含まれます。
