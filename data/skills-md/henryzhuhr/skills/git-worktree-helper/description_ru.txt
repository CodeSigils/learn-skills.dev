Проверяйте, создавайте и управляйте рабочими деревьями Git для разработки параллельных ветвей. Идеально подходит для пакетного создания рабочих деревьев по шаблону локальных ветвей, размещения рабочих деревьев рядом с корнем репозитория, предотвращения дублирования рабочих деревьев для ветвей, уже извлеченных в другом месте, проверки сопоставления путей между ветвями и рабочими деревьями или подготовки изолированных рабочих пространств перед внесением изменений в несколько ветвей.
