Проверяйте, создавайте и управляйте рабочими деревьями Git для разработки параллельных ветвей. Подходит для сценариев, требующих пакетного создания рабочих деревьев по шаблону локальных ветвей, размещения рабочих деревьев в каталоге, примыкающем к репозиторию, предотвращения дублирования рабочих деревьев для ветвей, уже извлеченных в другом месте, проверки сопоставления путей между ветвями и рабочими деревьями или подготовки изолированных рабочих пространств перед внесением изменений в несколько ветвей.
