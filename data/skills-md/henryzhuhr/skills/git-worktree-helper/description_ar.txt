فحص وإنشاء وإدارة أشجار عمل Git لتطوير الفروع الموازية. مناسب للسيناريوهات التي تتطلب إنشاء دفعات من أشجار العمل باتباع نمط الفرع المحلي، أو وضع أشجار العمل في دليل مجاور للمستودع، أو تجنب أشجار العمل المكررة للفروع التي تم سحبها بالفعل في مكان آخر، أو التحقق من تعيينات مسار الفرع إلى شجرة العمل، أو إعداد مساحات عمل معزولة قبل إجراء تغييرات عبر فروع متعددة.
