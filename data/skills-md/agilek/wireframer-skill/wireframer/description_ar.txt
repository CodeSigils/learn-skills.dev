استخدم هذه المهارة لإنشاء إطار سلكي أو نموذج بالحجم الطبيعي أو نموذج أولي منخفض الدقة قابل للنقر لأي واجهة مستخدم ويب. قم بالاستدعاء عندما يذكر المستخدم الإطارات الشبكية أو المحاكاة أو النماذج الأولية أو رسم تخطيطي لواجهة المستخدم - بما في ذلك عبارات مثل "نموذج lo-fi الأولي" أو "التخطيط التقريبي" أو "نمط Balsamiq" أو "واجهة المستخدم المرسومة يدويًا" أو "النموذج الأولي القابل للنقر" أو "رسم الشاشات" أو "تصور التدفق" أو "إظهار الشكل الذي سيبدو عليه التطبيق". يُستخدم أيضًا عندما يريد المستخدم التفكير قبل كتابة كود الإنتاج، أو إعداد مفهوم لأصحاب المصلحة، أو تشغيل سباق التصميم، أو السؤال عن أيقونات رسومات الشعار المبتكرة التفاعلية. يُنتج منتجعًا صحيًا قائمًا بذاته مع جماليات مرسومة يدويًا: مكونات تفاعلية ذات عناصر سلكية، وخلفية ورق بياني، وأيقونات رسومات الشعار المبتكرة.
