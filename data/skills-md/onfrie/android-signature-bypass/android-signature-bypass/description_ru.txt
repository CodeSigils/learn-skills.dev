Обход проверки подписи платформы Android SharedUserId БЕЗ ключа платформы. Используйте, когда пользователь сообщает INSTALL_FAILED_SHARED_USER_INCOMPATIBLE, ему необходимо установить APK с android:sharedUserId="android.uid.system" на корневом эмуляторе/устройстве userdebug или ему необходимо вызвать системные API (android.car.jar и т. д.) на эмуляторе Android Automotive, где ключ платформы недоступен. Охватывает небольшое исправление Services.jar, регенерацию OAT через dex2oat, привязку монтирования с исправлением контекста SELinux и постоянную настройку системы с возможностью записи с помощью Disable-Verity. Только для сборок userdebug/eng.
