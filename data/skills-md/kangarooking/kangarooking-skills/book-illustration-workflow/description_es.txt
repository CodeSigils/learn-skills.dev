Un flujo de trabajo para manejar capturas de pantalla e ilustraciones de capítulos durante el proceso de escritura del libro. Aplicable para: organizar qué capturas de pantalla se necesitan para un capítulo, proporcionar indicaciones de operación de Claude Code paso a paso, especificar el nombre del archivo de la captura de pantalla para representar asignaciones de números, rellenar las posiciones de las imágenes en Markdown local, limpiar las notas del autor en texto listo para leer y sincronizar capítulos e imágenes con documentos Feishu en las posiciones correctas. Esta habilidad debe activarse cuando el usuario menciona "capturas de pantalla de libros", "ilustraciones de capítulos", "asignación de números de figuras", "insertar en el texto original", "cargar en un documento Feishu" o "seguir el mismo flujo de trabajo".
