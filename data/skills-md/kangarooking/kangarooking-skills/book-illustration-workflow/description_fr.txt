Un flux de travail pour gérer les captures d’écran et les illustrations des chapitres pendant le processus d’écriture du livre. Applicable pour : organiser les captures d'écran nécessaires pour un chapitre, fournir des invites d'utilisation étape par étape de Claude Code, spécifier le nom de fichier de capture d'écran avec les mappages de numéros de figure, remplir les positions des images dans Markdown local, nettoyer les notes de l'auteur dans un texte prêt pour le lecteur et synchroniser les chapitres et les images avec les documents Feishu dans les positions correctes. Cette compétence doit être déclenchée lorsque l'utilisateur mentionne « captures d'écran de livre », « illustrations de chapitre », « mappage de numéros de figures », « insérer dans le texte original », « télécharger vers un document Feishu » ou « suivre le même flux de travail ».
