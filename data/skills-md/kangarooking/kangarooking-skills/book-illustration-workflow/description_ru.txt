Рабочий процесс обработки снимков экрана и иллюстраций глав в процессе написания книги. Применимо для: организации снимков экрана, необходимых для главы, предоставления пошаговых подсказок по работе с кодом Claude, указания имени файла снимка экрана для определения сопоставления номеров, заполнения позиций изображений в локальном Markdown, очистки примечаний автора в текст, готовый для чтения, а также синхронизации глав и изображений с документами Feishu в правильных позициях. Этот навык должен срабатывать, когда пользователь упоминает «скриншоты книги», «иллюстрации глав», «сопоставление номеров цифр», «вставить в исходный текст», «загрузить в документ Feishu» или «следовать тому же рабочему процессу».
