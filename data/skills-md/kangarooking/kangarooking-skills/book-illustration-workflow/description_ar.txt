سير عمل للتعامل مع لقطات شاشة الفصل والرسوم التوضيحية أثناء عملية كتابة الكتاب. ينطبق على: تنظيم لقطات الشاشة المطلوبة للفصل، وتوفير مطالبات تشغيل Claude Code خطوة بخطوة، وتحديد اسم ملف لقطة الشاشة لتحديد تعيينات الأرقام، وإعادة ملء مواضع الصور في Markdown المحلي، وتنظيف ملاحظات المؤلف في نص جاهز للقارئ، ومزامنة الفصول والصور مع مستندات Feishu في المواضع الصحيحة. يجب تفعيل هذه المهارة عندما يذكر المستخدم "لقطات شاشة الكتاب"، أو "الرسوم التوضيحية للفصول"، أو "تعيين أرقام الأشكال"، أو "إدراج في النص الأصلي"، أو "تحميل إلى مستند Feishu"، أو "اتباع نفس سير العمل".
