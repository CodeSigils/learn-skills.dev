Divida los requisitos en una lista de tareas estructurada y genere un sistema de gestión de tareas del Agente de larga duración (basado en la metodología Anthropic Effective Harnesses). Actívelo automáticamente cuando el usuario necesite administrar tareas de desarrollo de múltiples sesiones, realizar un seguimiento del progreso de finalización de funciones o solicitar "descomposición de tareas", "administración de tareas" o "planificación de proyectos".
