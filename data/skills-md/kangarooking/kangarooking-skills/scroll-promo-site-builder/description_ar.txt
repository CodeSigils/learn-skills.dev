قم بإنشاء موقع ويب لمنتج سينمائي يتم التحكم فيه بالتمرير باستخدام حركة غنية (动效网站) من مواد المنتج والصفحات المرجعية أو مقاطع الفيديو وأصول العلامة التجارية. يُستخدم للطلبات التي تتضمن 网站动效، والصفحات المقصودة الغامرة للمنتج حيث يؤدي التمرير إلى تحريك مقطع فيديو مستمر للأمام والخلف، أو رواية القصص المرئية متعددة المشاهد، أو إنشاء image2.0 المباشر وSeedance 2.0، أو مراجعة استمرارية المشهد، أو تعبئة المعاينة المحلية. لا تستخدمه لمواقع الشركات العادية أو لوحات المعلومات أو التجارة الإلكترونية أو المدونات أو مقاطع الفيديو الترويجية المستقلة بدون موقع ويب.
