Rufen Sie aktuelle Beiträge von einem oder mehreren X/Twitter-Konten über twitterapi.io ab, geben Sie strukturierte JSON/CSV-Datensätze aus, synchronisieren Sie Datensätze optional mit Feishu/Lark Bitable über feishu-cli und steuern Sie optional die wiederkehrende Ausführung über OpenClaw, Codex-Automatisierungen, cron oder launchd. Verwenden Sie diese Option, wenn der Benutzer X-Blogger überwachen, aktuelle Tweets sammeln, Tweet-Metriken exportieren, Tweets an Feishu Bitable anhängen oder einen geplanten Twitter/X-Kontoverfolgungsworkflow einrichten möchte.
