Se activa cuando los usuarios necesitan comprender "por qué las personas hacen lo que hacen" (especialmente comportamientos aparentemente irracionales), diseñar sistemas de gestión o mecanismos de incentivos, evaluar la credibilidad de las recomendaciones de asesores profesionales o intentar persuadir a otros para que cambien su comportamiento. Señales de activación típicas: el usuario está desconcertado por "por qué el comportamiento no cambió a pesar de los cambios en el sistema"; las recomendaciones de los asesores/subordinados/partes del usuario resultan especialmente beneficiosas para ellos; El usuario necesita diseñar un sistema para hacer que otros se comporten como se espera. No se aplica al diseño de soluciones puramente técnicas o a escenarios que no requieren considerar el comportamiento humano.
