Activate when users need to understand extreme events (bubbles, crashes, mass manias, cults, mob behavior), diagnose organizational systemic failures, or assess risks where multiple psychological/market/institutional forces stack in one direction. Typical trigger signals: user describes phenomena "far beyond what any single factor could explain"; user attempts to explain extreme outcomes with a single cause; user worries about "multiple adverse factors erupting simultaneously." Not applicable for routine single-factor decision analysis or assessment of mild incremental changes.
