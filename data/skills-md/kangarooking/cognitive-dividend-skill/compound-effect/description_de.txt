Entwerfen Sie ein Wachstumsmodell mit Zinseszinseffekten. Verwenden Sie es, wenn Sie lange an etwas gearbeitet haben, nur langsam Fortschritte machen und das Gefühl haben, es aufzugeben, oder wenn Sie möchten, dass Ihre Bemühungen eine „Je mehr Sie tun, desto schneller wird es“-Dynamik erzeugen. Kernschritte: Finden Sie den Hebelpunkt (Validierung von Ursache und Wirkung) → Entwerfen Sie eine Verstärkungsschleife (A stärkt B, B stärkt wiederum A) → Beharren Sie bis zu einem Meilenstein. Nicht geeignet für einmalige Aufgaben, kurzfristige Projekte oder Ereignisse mit unklarer Kausalität. Wichtige Auslösesignale: „Warum hat es nach all der Zeit nicht geklappt?“ „Soll ich weitermachen?“ „Wie kann ich das Wachstum beschleunigen?“
