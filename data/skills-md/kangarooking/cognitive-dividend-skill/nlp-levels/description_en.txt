A framework for analyzing and solving problems using the NLP Neurological Levels model. Use when you're stuck in a dilemma with no way out, going in circles at the same level, or facing major life decisions. Six levels from low to high: Environment → Behavior → Capability → BVR (Beliefs/Values/Rules) → Identity → Spirit/Purpose. Core method: Design life from the top down, solve problems by ascending to dimensions where lower-level problems cannot be solved. Not applicable to daily operational issues (e.g., how to write an email). Key trigger signals: "What should I do," "Why do I always encounter the same problems," "Don't know how to choose," "Confused about life direction."
