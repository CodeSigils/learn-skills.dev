Use the "Dialysis Triangular Prism" framework to penetrate the surface of a problem and uncover its underlying cause. Solve recurring stubborn issues in three steps: calibrate target B, reconstruct method A, and eliminate variable C. This applies to scenarios where the same problem repeatedly surfaces despite trying various solutions, as well as analytical situations that require precisely defining the problem before addressing it. Use this skill when patch‑style fixes prove ineffective. It is not suitable for entirely new fields lacking historical methods to reference, nor for purely uncertain events (those belong to the probability/risk domain and should use the mirror‑world approach). Key trigger signals: “Why is this problem happening again?”, “Why can’t it ever be solved?”, “I’ve tried many methods and none work”, “What is the root cause of the problem?”.
