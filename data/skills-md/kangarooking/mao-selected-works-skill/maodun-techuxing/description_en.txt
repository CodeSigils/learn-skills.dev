When a user is about to apply a successful methodology (someone else’s or their own past one) to a new scenario, this skill is activated. Typical trigger signals: “A certain company succeeded with method X, we should try it too,” “I did this before and it worked, keep doing it,” “The industry’s best practice is Y.”  
Non‑invocation scenario: the user is facing repeated occurrences of the same type of problem and needs execution rather than methodology selection.  
Difference from the “Contradiction Analysis Method”: this skill emphasizes “each problem has a different nature and requires a different method,” whereas the latter emphasizes “finding the most important problem.”
