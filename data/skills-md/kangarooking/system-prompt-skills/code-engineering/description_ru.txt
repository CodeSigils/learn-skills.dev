Вызывайте, когда системное приглашение нацелено на сценарий агента кодирования. Подходит для системных подсказок, связанных с созданием редакторов кода, файловыми операциями, рабочими процессами Git и автоматизированными помощниками по программированию. Неприменимо к сценариям интерпретации кода или обучения (без изменений файлов), неприменимо к конфигурации инфраструктуры DevOps (некодовый уровень) и неприменимо к чисто диалоговым вопросам и ответам по коду (без вызова инструментов).
