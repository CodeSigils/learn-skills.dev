Invocar cuando el indicador del sistema esté orientado a un escenario de agente de codificación. Es adecuado para indicaciones del sistema que crean edición de código, operaciones de archivos, flujos de trabajo de Git y asistentes de programación automatizados. No es adecuado para explicación de código o escenarios de enseñanza (sin modificaciones de archivos), no es adecuado para la configuración de infraestructura DevOps (capa sin código) y no es adecuado para preguntas y respuestas sobre código conversacional puro (sin invocación de herramientas).
