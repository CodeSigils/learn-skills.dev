Richiamare quando il prompt del sistema è rivolto a uno scenario di agente di codifica. Adatto per prompt di sistema che creano modifiche del codice, operazioni sui file, flussi di lavoro Git e assistenti di programmazione automatizzati. Non adatto per la spiegazione del codice o scenari didattici (senza modifica dei file), non adatto per la configurazione dell'infrastruttura DevOps (livello non codice) e non adatto per domande e risposte sul codice puramente conversazionale (senza invocazione dello strumento).
