يتم الاستدعاء عندما يكون موجه النظام مخصصًا لسيناريو وكيل الترميز. مناسب لمطالبات النظام التي تنشئ تحرير التعليمات البرمجية وعمليات الملفات وسير عمل Git ومساعدي البرمجة الآليين. غير مناسب لشرح التعليمات البرمجية أو سيناريوهات التدريس (لا توجد تعديلات على الملفات)، وغير مناسب لتكوين البنية التحتية لـ DevOps (طبقة غير التعليمات البرمجية)، وغير مناسب للأسئلة والأجوبة الخاصة بكود المحادثة الخالص (لا يوجد استدعاء للأداة).
