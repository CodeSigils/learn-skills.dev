When system prompts need to define when the AI model searches, how it searches, which data sources to search, and how to handle search results, use this skill. It applies to all AI product designs involving real-time knowledge retrieval—chatbots, research assistants, enterprise knowledge base Q&A, etc. It does not apply to: purely offline scenarios (environments without search capability), fully internalized knowledge Q&A (e.g., mathematical derivations), creative generation tasks. When the requirement only involves "reading content from local files" rather than "retrieving external information online," this is not the optimal skill.
