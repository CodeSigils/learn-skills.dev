Cuando el indicador del sistema requiera diseñar una asignación de presupuesto de tokens, estrategias de compresión de contexto, mecanismos de carga diferida o soluciones de persistencia de memoria, utilice esta habilidad. Es adecuado para escenarios que necesitan una gestión detallada de la ventana contextual, como asistentes de IA de largas conversaciones, integraciones de editores de código, agentes de investigación, sistemas multisesión y casos de uso similares. No es apropiado para sistemas de interacción de un solo turno (sin necesidad de administración de contexto), API puramente sin estado (sin historial de conversaciones) o diseño simple de plantilla de solicitud. Cuando el requisito se centra en "cómo buscar información externa" en lugar de "cómo gestionar la información existente", debe utilizar la integración de búsqueda en lugar de esta habilidad.
