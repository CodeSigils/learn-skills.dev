When the system prompt requires designing token budget allocation, context compression strategies, lazy‑loading mechanisms, and memory persistence solutions, invoke this skill. It is suitable for scenarios that need fine‑grained management of the context window, such as long‑conversation AI assistants, code‑editor integrations, research agents, multi‑session systems, etc. It is not suitable for single‑turn interaction systems (no context‑management needs), purely stateless APIs (no conversation history), or simple prompt‑template designs. When the requirement focuses on “how to search external information” rather than “how to manage existing information,” you should use search‑integration instead of this skill.
