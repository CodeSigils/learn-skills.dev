When the system prompt needs to define how the AI categorizes user intents, routes to different processing flows, decides clarification strategies, and autonomy levels, this skill should be invoked. It is suitable for scenarios requiring structured dialogue management such as multi‑task AI assistants, customer‑service bots, programming tools, research assistants, and the like. It is not suitable for pure Q&A systems (no task execution), single‑turn interactions (no dialogue state), or simple prompt templates (no routing logic). When the requirement only involves “what format to output” rather than “how to decide what to output,” you should use output‑formatting instead of this skill.
