Когда возникает необходимость разработать механизмы хранения, извлечения, применения и обновления памяти для ИИ, используйте этот навык. Типичные сценарии включают в себя: проектирование архитектуры постоянной памяти (предпочтения пользователя, исторический контекст, знания проекта), определение жизненного цикла создания/чтения/обновления/удаления воспоминаний, реализацию тихого использования памяти (не раскрывая содержимое памяти в ответах) и управление границами конфиденциальных воспоминаний.  

Неприменимо для: определения интерфейсов инструментов (спецификация инструмента), определения правил безопасности (защитные ограждения), определения стилей личности (система личности).  

Ключевые триггерные сигналы: ИИ должен запоминать пользовательскую информацию между сеансами, содержимое памяти может быть конфиденциальным, память должна применяться неявно в ответах, а не явно, пользователь просит «запомнить это».
