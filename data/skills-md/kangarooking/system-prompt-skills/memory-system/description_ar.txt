استخدم هذه المهارة عندما تحتاج إلى تصميم آليات تخزين الذاكرة واسترجاعها وتطبيقها وتحديثها للذكاء الاصطناعي. تتضمن السيناريوهات النموذجية: تصميم بنية الذاكرة المستمرة (تفضيلات المستخدم، والسياق التاريخي، ومعرفة المشروع)، وتحديد دورة حياة إنشاء/قراءة/تحديث/حذف الذكريات، وتنفيذ استخدام الذاكرة الصامت (عدم الكشف عن محتوى الذاكرة في الردود)، وإدارة حدود الذكريات الحساسة.  
لا ينطبق على: تحديد واجهات الأداة (مواصفات الأداة)، وتحديد قواعد السلامة (حواجز السلامة)، وتحديد نمط الشخصية (نظام الشخصية).  
إشارات التشغيل الرئيسية: يحتاج الذكاء الاصطناعي إلى تذكر معلومات المستخدم عبر الجلسات، وقد يكون محتوى الذاكرة حساسًا، ويجب تطبيق الذاكرة ضمنيًا في الردود بدلاً من الإشارة إليها بشكل صريح، ويطلب المستخدم "تذكر هذا".
