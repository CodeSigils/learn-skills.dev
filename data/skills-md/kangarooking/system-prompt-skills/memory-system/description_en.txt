When you need to design memory storage, retrieval, application, and update mechanisms for AI, invoke this skill. Typical scenarios include: designing persistent memory architectures (user preferences, historical context, project knowledge), defining the create/read/update/delete lifecycle of memories, implementing silent memory usage (not revealing memory content in replies), and managing the boundaries of sensitive memories.  

Not applicable to: defining tool interfaces (tool‑specification), defining safety rules (safety‑guardrails), defining personality styles (personality‑system).  

Key trigger signals: AI needs to remember user information across sessions, memory content may be sensitive, memory needs to be applied implicitly in replies rather than explicitly referenced, user requests “remember this.”
