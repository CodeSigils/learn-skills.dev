When the system prompt needs to define output format specifications, length constraints, style guidelines, or anti-"AI flavor" strategies for the AI, use this skill. It applies to scenarios requiring adaptive output such as chatbots, CLI tools, mobile assistants, design generators, etc. It does not apply to: pure content generation (no format requirements), internal reasoning chain design, security policy formulation. When the requirement only involves "which format to return data in" rather than "how to control the output's style and density," this is not the optimal skill.
