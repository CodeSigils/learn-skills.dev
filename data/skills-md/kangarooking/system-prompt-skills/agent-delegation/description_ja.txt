システム プロンプトで、マルチエージェントの協調アーキテクチャ、サブエージェント間の専門分業、エージェント間のコンテキストの分離と送信メカニズム、およびタスクのライフサイクル管理の設計が必要な場合は、このスキルを呼び出します。これは、AI エージェント プラットフォーム、マルチツール オーケストレーション システム、コード レビュー パイプライン、アプリケーション間コラボレーション シナリオなどに適用されます。単一エージェント システム (委任の必要がない)、単純なツール呼び出し (サブエージェント概念なし)、または純粋な API オーケストレーション (AI 意思決定なし) には適用されません。要件が「複数のエージェント間のタスク割り当て」ではなく「単一エージェント内の対話ルーティング」に焦点を当てている場合、このスキルの代わりに会話フローを使用する必要があります。
