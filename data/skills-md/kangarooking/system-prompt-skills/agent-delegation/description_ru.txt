Используйте этот навык, когда системное приглашение требует разработки многоагентной совместной архитектуры, специализированного разделения труда между субагентами, механизмов изоляции и передачи контекста между агентами, а также управления жизненным циклом задач. Он подходит для платформ агентов ИИ, систем оркестрации с несколькими инструментами, конвейеров проверки кода, сценариев совместной работы между приложениями и т. д. Он не подходит для: систем с одним агентом (без необходимости делегирования), простых вызовов инструментов (без концепции субагента), чистой оркестрации API (без принятия решений ИИ). Когда требование фокусируется на «маршрутизации диалога внутри одного агента», а не на «распределении задач между несколькими агентами», вместо этого навыка следует использовать поток разговора.
