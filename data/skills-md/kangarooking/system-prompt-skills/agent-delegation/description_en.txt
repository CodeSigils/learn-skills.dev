When the system prompt requires designing a multi-agent collaborative architecture, specialized division of labor among sub-agents, context isolation and transmission mechanisms between agents, and task lifecycle management, invoke this skill. It applies to AI agent platforms, multi-tool orchestration systems, code review pipelines, cross-application collaboration scenarios, etc. It does not apply to single-agent systems (no delegation needs), simple tool calls (no sub-agent concept), or pure API orchestration (no AI decision-making). When the requirement focuses on "dialogue routing within a single agent" rather than "task allocation between multiple agents," conversation-flow should be used instead of this skill.
