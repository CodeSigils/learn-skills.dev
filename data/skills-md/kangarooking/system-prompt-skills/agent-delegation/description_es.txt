Cuando el indicador del sistema requiera diseñar una arquitectura de colaboración de múltiples agentes, especialización de subagente, aislamiento de contexto y mecanismos de transmisión entre agentes y gestión del ciclo de vida de las tareas, invoque esta habilidad. Se aplica a plataformas de agentes de IA, sistemas de orquestación de múltiples herramientas, canalizaciones de revisión de código, escenarios de colaboración entre aplicaciones, etc. No es aplicable a: sistemas de agente único (sin necesidad de delegación), llamadas de herramientas simples (sin concepto de subagente), orquestación de API pura (sin decisión de IA). Cuando el requisito se centra en "enrutamiento del diálogo dentro de un solo agente" en lugar de "asignación de tareas entre múltiples agentes", debe utilizar el flujo de conversación en lugar de esta habilidad.
