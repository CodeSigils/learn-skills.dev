Invoke this skill when you need to define the core identity, role statements, and capability boundaries for an AI product. Typical scenarios include: designing the opening paragraph of the system prompt for a new AI product, creating differentiated roles for different contexts (e.g., teaching assistant vs. programming agent), and redefining the framework of the AI‑user relationship. Not applicable to: pure personality style tuning (use personality-system), safety rule formulation (use safety-guardrails), tool integration (use tool-specification). Key trigger signals: the product requires the AI to have clear self‑awareness, multiple roles share underlying capabilities but have different identities, the AI needs to be restricted to operate in specific domains, and users ask “Who are you?”.
