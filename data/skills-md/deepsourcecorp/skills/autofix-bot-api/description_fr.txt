Analysez le code pour détecter les vulnérabilités de sécurité, les secrets divulgués et les problèmes de dépendance à l'aide de l'API Autofix Bot (api.autofix.bot) et corrigez automatiquement les problèmes détectés. Utilisez cette compétence lorsqu'on vous demande de : (1) analyser ou analyser un référentiel ou un code à la recherche de problèmes de sécurité, de secrets ou de vulnérabilités à l'aide d'Autofix Bot, (2) télécharger/synchroniser un référentiel git local sur Autofix Bot pour analyse, (3) exécuter Autofix Bot sur les modifications de code, les demandes d'extraction ou les correctifs, (4) appliquer les correctifs automatiques à partir des résultats de l'analyse d'Autofix Bot. Nécessite une clé API Autofix Bot (variable d'environnement AUTOFIX_BOT_API_KEY).
