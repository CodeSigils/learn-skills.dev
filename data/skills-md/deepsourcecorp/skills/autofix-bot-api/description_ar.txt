قم بمسح الكود بحثًا عن الثغرات الأمنية والأسرار المسربة ومشكلات التبعية باستخدام Autofix Bot API (api.autofix.bot)، والإصلاح التلقائي للمشكلات المكتشفة. استخدم هذه المهارة عندما يُطلب منك: (1) فحص أو تحليل مستودع أو رمز بحثًا عن مشكلات الأمان أو الأسرار أو نقاط الضعف باستخدام Autofix Bot، (2) تحميل/مزامنة مستودع git محلي إلى Autofix Bot للتحليل، (3) تشغيل Autofix Bot عند تغييرات التعليمات البرمجية أو طلبات السحب أو التصحيحات، (4) تطبيق الإصلاحات التلقائية من نتائج تحليل Autofix Bot. يتطلب مفتاح Autofix Bot API (متغير البيئة AUTOFIX_BOT_API_KEY).
