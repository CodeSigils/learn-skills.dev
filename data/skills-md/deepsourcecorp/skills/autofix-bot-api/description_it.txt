Esegui la scansione del codice per individuare vulnerabilità della sicurezza, segreti trapelati e problemi di dipendenza utilizzando l'API Bot di correzione automatica (api.autofix.bot) e risolvendo automaticamente i problemi rilevati. Utilizzare questa competenza quando viene richiesto di: (1) scansionare o analizzare un repository o un codice per problemi di sicurezza, segreti o vulnerabilità utilizzando Autofix Bot, (2) caricare/sincronizzare un repository git locale su Autofix Bot per l'analisi, (3) eseguire Autofix Bot su modifiche al codice, richieste pull o patch, (4) applicare correzioni automatiche dai risultati dell'analisi di Autofix Bot. Richiede una chiave API Autofix Bot (variabile di ambiente AUTOFIX_BOT_API_KEY).
