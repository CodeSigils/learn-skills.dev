Сканируйте код на наличие уязвимостей безопасности, утечки секретов и проблем с зависимостями с помощью API Autofix Bot (api.autofix.bot), а также автоматически исправляйте обнаруженные проблемы. Используйте этот навык, когда вас просят: (1) сканировать или анализировать репозиторий или код на предмет проблем безопасности, секретов или уязвимостей с помощью Autofix Bot, (2) загружать/синхронизировать локальный репозиторий git с Autofix Bot для анализа, (3) запускать Autofix Bot при изменениях кода, запросах на включение или исправлениях, (4) применять автоматические исправления на основе результатов анализа Autofix Bot. Требуется ключ API Autofix Bot (переменная среды AUTOFIX_BOT_API_KEY).
