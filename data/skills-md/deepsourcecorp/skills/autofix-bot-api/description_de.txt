Scannen Sie Code mit der Autofix Bot API (api.autofix.bot) auf Sicherheitslücken, durchgesickerte Geheimnisse und Abhängigkeitsprobleme und beheben Sie erkannte Probleme automatisch. Verwenden Sie diese Fähigkeit, wenn Sie aufgefordert werden: (1) ein Repository oder einen Code mit Autofix Bot auf Sicherheitsprobleme, Geheimnisse oder Schwachstellen zu scannen oder zu analysieren, (2) ein lokales Git-Repository zur Analyse in Autofix Bot hochzuladen/synchronisieren, (3) Autofix Bot bei Codeänderungen, Pull Requests oder Patches auszuführen, (4) automatische Korrekturen aus den Ergebnissen der Autofix Bot-Analyse anzuwenden. Erfordert einen Autofix Bot API-Schlüssel (Umgebungsvariable AUTOFIX_BOT_API_KEY).
