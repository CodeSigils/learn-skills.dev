Escanee el código en busca de vulnerabilidades de seguridad, secretos filtrados y problemas de dependencia utilizando la API de Autofix Bot (api.autofix.bot) y solucione automáticamente los problemas detectados. Utilice esta habilidad cuando se le solicite: (1) Escanear o analizar un repositorio o código en busca de problemas de seguridad, secretos o vulnerabilidades usando Autofix Bot, (2) Cargar/sincronizar un repositorio git local con Autofix Bot para su análisis, (3) Ejecutar Autofix Bot en cambios de código, solicitudes de extracción o parches, (4) Aplicar correcciones automáticas a partir de los resultados del análisis de Autofix Bot. Requiere una clave API de Autofix Bot (variable de entorno AUTOFIX_BOT_API_KEY).
