Autofix Bot API (api.autofix.bot) を使用してコードをスキャンし、セキュリティの脆弱性、漏洩したシークレット、依存関係の問題を調べ、検出された問題を自動修正します。このスキルは、(1) Autofix Bot を使用してセキュリティ問題、シークレット、または脆弱性についてリポジトリまたはコードをスキャンまたは分析する、(2) 分析のためにローカル git リポジトリを Autofix Bot にアップロード/同期する、(3) コードの変更、プル リクエスト、またはパッチに対して Autofix Bot を実行する、(4) Autofix Bot の分析結果から自動修正を適用する、といった場合にこのスキルを使用します。 Autofix Bot API キー (環境変数 AUTOFIX_BOT_API_KEY) が必要です。
