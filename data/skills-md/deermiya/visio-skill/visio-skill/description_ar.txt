قم بإنشاء أو تعديل الرسوم التخطيطية لـ Microsoft Visio .vsdx باستخدام أتمتة Visio COM المحلية. يُستخدم عندما يطلب المستخدم من Codex إنشاء ملفات Visio، أو رسم مخططات انسيابية، أو مخططات معمارية، أو مخططات تسلسلية، أو تخطيطات بنمط الحارة، أو مخططات هيكلية الشبكة، أو خرائط العمليات، أو لأتمتة الأشكال/الموصلات/النص في Microsoft Visio على نظام التشغيل Windows.
