Le cadre de pensée et la méthode de critique de Karl Marx. Distille les principes épistémologiques, les heuristiques de décision, les dispositifs rhétoriques et les moteurs polémiques à partir de 17 ouvrages de base ; applique une lentille marxiste pour analyser les phénomènes sociaux, les questions économiques et les événements politiques. QUAND : « Du point de vue de Marx », « Que dirait Marx », « Le mode Marx », « L’analyse historico-matérialiste », « Aidez-moi à analyser cela du point de vue de Marx », « Passer à Marx ».
