قم بإنشاء قوالب بريد إلكتروني احترافية ومتوافقة مع Outlook (EML + HTML) من خلال المحادثة الطبيعية. ينشئ تخطيطات مثالية للرسائل الإخبارية ورسائل البريد الإلكتروني الإعلانية والتقارير الأسبوعية ودعوات الأحداث وأي بريد إلكتروني منسق يحتاج إلى العرض بشكل صحيح في Outlook. يجب استخدام هذه المهارة عندما يريد المستخدم: إنشاء قالب بريد إلكتروني أو تصميمه، أو إنشاء ملف EML، أو إنشاء رسالة إخبارية، أو تنسيق بريد إلكتروني لبرنامج Outlook، أو تصميم بريد إلكتروني، أو تنفيذ بريد إلكتروني أو إنشاء بريد إلكتروني بتنسيق HTML متوافق مع Outlook، أو إنشاء بريد إلكتروني ذو مظهر احترافي لإرساله عبر Outlook، أو إنتاج أي نوع من مخرجات البريد الإلكتروني المنسقة/المصممة. يتم تشغيله أيضًا عندما يذكر المستخدم: البريد الإلكتروني للتقرير الأسبوعي (周报邮件)، أو البريد الإلكتروني لتحديث المنتج، أو البريد الإلكتروني لدعوة الحدث (活动邀请邮件)، أو البريد الإلكتروني للإعلان (公告邮件)، أو النشرة الإخبارية للشركة، أو يريد جعل البريد الإلكتروني "يبدو احترافيًا/جميلًا" للإرسال. تتعامل هذه المهارة مع التصميم المرئي وإنشاء EML - وليس إرسال البريد الإلكتروني أو إعداد SMTP أو تحليل البريد الإلكتروني. بدون هذه المهارة، ستكون رسائل البريد الإلكتروني في Outlook ذات تخطيطات معطلة لأن Outlook يستخدم محرك عرض Word الذي يتجاهل CSS الحديث.
