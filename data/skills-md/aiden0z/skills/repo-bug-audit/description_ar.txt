يُستخدم عندما يحتاج الوكيل إلى عمليات تدقيق الأخطاء على مستوى المستودع، أو اكتشاف الأخطاء بالتحليل الثابت، أو مراجعة مخاطر البنية/الأمان/الموثوقية، أو تعيين علاقات الريبو المتبادل، أو الفرز الإيجابي الخاطئ، أو إلغاء البيانات المكررة، أو عمليات التدقيق التزايدية/الاستئنافية، أو سجلات الأخطاء المدعومة بالأدلة، أو معرفة الريبو القابلة لإعادة الاستخدام، أو مخرجات تدقيق الأخطاء الجاهزة للإصلاح.
