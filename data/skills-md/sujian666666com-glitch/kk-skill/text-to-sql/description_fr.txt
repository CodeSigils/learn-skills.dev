À utiliser lorsque (1) l'utilisateur décrit les données qu'il souhaite en anglais simple et demande la requête SQL correspondante.  (2) l'utilisateur dit "écrire du SQL pour cela", "convertir en requête", "comment sélectionner" ou "donnez-moi le SQL".  (3) l'utilisateur fournit un schéma de base de données ou des descriptions de table et pose une question à laquelle SQL répond.
