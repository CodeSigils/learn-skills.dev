Da utilizzare quando (1) l'utente descrive quali dati desidera in un inglese semplice e richiede la query SQL corrispondente.  (2) l'utente dice "scrivi SQL per questo", "converti in query", "come faccio a selezionare" o "dammi l'SQL".  (3) l'utente fornisce uno schema di database o descrizioni di tabelle e pone una domanda a cui è possibile rispondere tramite SQL.
