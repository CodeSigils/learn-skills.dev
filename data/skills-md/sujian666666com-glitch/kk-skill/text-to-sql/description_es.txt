Úselo cuando (1) el usuario describe qué datos desea en inglés sencillo y solicita la consulta SQL correspondiente.  (2) el usuario dice "escribir SQL para esto", "convertir a consulta", "cómo selecciono" o "dame el SQL".  (3) el usuario proporciona un esquema de base de datos o descripciones de tablas y hace una pregunta que puede responder mediante SQL.
