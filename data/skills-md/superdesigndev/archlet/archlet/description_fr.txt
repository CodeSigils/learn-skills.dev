Cartes d'architecture interactives basées sur la provenance dans .archlet/. Deux modes : MAP – analyser l'intégralité de la base de code dans .archlet/data.js et créer une superposition de démarrage à partir d'une modification récente ; DIFF - étant donné les modifications d'un PR, d'un commit, d'une plage, d'une branche ou d'un arbre de travail, superposez ce qu'ils touchent. À utiliser lorsque l'utilisateur demande de cartographier/diagramme/visualiser l'architecture d'une base de code, d'actualiser la carte ou de montrer ce qu'un PR/commit/modification touche.
