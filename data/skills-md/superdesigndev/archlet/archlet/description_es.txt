Mapas de arquitectura interactivos respaldados por procedencia en .archlet/. Dos modos: MAP: analiza todo el código base en .archlet/data.js y genera una superposición inicial a partir de un cambio reciente; DIFF: dado un PR, compromiso, rango, rama o cambios en el árbol de trabajo, superponga lo que tocan. Úselo cuando el usuario solicite mapear/diagramar/visualizar la arquitectura de una base de código, actualizar el mapa o mostrar lo que toca un PR/compromiso/cambio.
