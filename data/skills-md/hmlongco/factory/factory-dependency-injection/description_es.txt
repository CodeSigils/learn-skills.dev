Guía profunda de Factory, un sistema de inyección de dependencias basado en contenedores para Swift y SwiftUI. Utiliza esta habilidad cada vez que el usuario esté escribiendo, leyendo, refactorizando, depurando o probando código Swift que use Factory, FactoryKit o FactoryTesting — incluyendo registros en Container, los property wrappers `@Injected`/`@LazyInjected`/`@WeakLazyInjected`/`@DynamicInjected`/`@InjectedObject`/`@InjectedObservable`/`@InjectedContainer`/`@InjectedType`, `Factory<T>` y `ParameterFactory<P, T>`, alcances (`.unique`, `.cached`, `.shared`, `.singleton`, `.graph`), modificadores de contexto (`.onTest`, `.onPreview`, `.onDebug`, `.onArg`, `.onSimulator`, `.onDevice`), las funciones globales `dependency(\.path)`, `AutoRegistering`, contenedores personalizados, el rasgo `.container` de Swift Testing y el cableado entre módulos con `promised()`. Activa cuando veas `Factory<`, `Container.shared`, `extension Container`, `@Injected(\.`, `import FactoryKit`, o cuando el usuario mencione “Factory DI”, “FactoryKit” o compare con Resolver, Swinject o Needle.
