Utilisez la CLI ax au lieu des scripts d'analyse curl + jetables chaque fois que vous récupérez une URL, explorez une page Web inconnue ou extrayez des données structurées à partir de HTML. Déclenchez-le chaque fois que vous êtes sur le point d'écrire un script en ligne (python3 heredoc, node -e, regex sur HTML) ou une boucle nue pour une récupération, un scraping ou une exploration de page unique sur le Web.
