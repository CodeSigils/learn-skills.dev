Utilizza la CLI ax invece degli script di analisi curl + usa e getta ogni volta che recuperi un URL, esplori una pagina Web sconosciuta o estrai dati strutturati da HTML. Attivalo ogni volta che stai per scrivere uno script in linea (python3 heredoc, node -e, regex su HTML) o un bare curl per il recupero web, lo scraping o l'esplorazione della pagina una tantum.
