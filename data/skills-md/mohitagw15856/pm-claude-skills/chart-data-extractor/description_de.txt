Extrahieren Sie Daten auf Pixelebene aus einem Bild eines Diagramms oder einer Grafik und erstellen Sie eine strukturierte Datentabelle. Verwenden Sie diese Option, wenn Sie aufgefordert werden, Daten aus einem Diagrammbild zu extrahieren, Zahlen aus einem Diagramm zu transkribieren, ein Diagramm zu digitalisieren oder einen Screenshot von Daten in eine Tabelle umzuwandeln. Erstellt eine strukturierte Tabelle mit extrahierten Werten, Konfidenzniveaus und einer rekonstruierten Diagrammquelle. Am besten mit Claude Opus 4.7 oder neuer für eine zuverlässige Extraktion von Diagrammdaten verwenden.
