Extraiga datos a nivel de píxel de una imagen de un cuadro o gráfico y produzca una tabla de datos estructurados. Úselo cuando se le solicite extraer datos de la imagen de un gráfico, transcribir números de un gráfico, digitalizar un gráfico o convertir una captura de pantalla de datos en una tabla. Produce una tabla estructurada con valores extraídos, niveles de confianza y una fuente de gráfico reconstruida. Se utiliza mejor con Claude Opus 4.7 o posterior para una extracción confiable de datos de gráficos.
