اكتب وثائق واجهة برمجة التطبيقات (API) الواضحة والموجهة للمطورين. استخدمه عندما يُطلب منك توثيق نقطة نهاية واجهة برمجة التطبيقات، أو كتابة مستندات مرجعية لواجهة برمجة التطبيقات، أو إنشاء دليل مطور، أو تحويل المواصفات الأولية/مجموعة Postman إلى وثائق. يُنتج وثائق نقطة النهاية مع الأوصاف والمعلمات وأمثلة الطلب/الاستجابة ورموز الخطأ.
