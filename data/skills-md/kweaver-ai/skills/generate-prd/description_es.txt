Genere documentos completos del PRD chino a partir de solicitudes de productos preliminares. Úselo cuando el usuario solicite crear, perfeccionar o estandarizar un PRD, convertir requisitos ambiguos en un documento de requisitos de producto compatible con Agile o completar una plantilla de PRD haciendo primero preguntas aclaratorias específicas y luego guardando el archivo de rebajas final.
