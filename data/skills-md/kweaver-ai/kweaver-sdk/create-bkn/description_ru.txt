Руководства по созданию файлов определений BKN (Сеть бизнес-знаний) в соответствии со спецификацией версии 2.0.0. Охватывает сеть, тип_объекта, тип_отношения, тип_действия, концептуальную_группу. Используйте при создании сетей знаний, файлов BKN, типов объектов, типов отношений, типов действий, групп понятий или когда пользователь просит смоделировать бизнес-знания в формате BKN. Если также загружен kweaver-core, используйте его для запуска CLI kweaver (auth, bkn push) после существования файлов.
