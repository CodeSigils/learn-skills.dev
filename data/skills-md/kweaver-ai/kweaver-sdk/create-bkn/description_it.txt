Guida la creazione dei file di definizione BKN (Business Knowledge Network) secondo le specifiche v2.0.0. Copre rete, tipo_oggetto, tipo_relazione, tipo_azione, gruppo_concetto. Da utilizzare durante la creazione di reti di conoscenza, file BKN, tipi di oggetto, tipi di relazione, tipi di azioni, gruppi di concetti o quando l'utente richiede di modellare la conoscenza aziendale in formato BKN. Quando viene caricato anche kweaver-core, utilizzarlo per eseguire la CLI di kweaver (auth, bkn push) dopo che i file esistono.
