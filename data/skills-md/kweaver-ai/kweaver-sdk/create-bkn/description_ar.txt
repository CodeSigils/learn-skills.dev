يرشد إلى إنشاء ملفات تعريف BKN (شبكة المعرفة التجارية) التي تتبع مواصفات الإصدار 2.0.0. يغطي الشبكة، ونوع_الكائن، ونوع_العلاقة، ونوع_الإجراء، ومجموعة_المفاهيم. يُستخدم عند إنشاء شبكات المعرفة، أو ملفات BKN، أو أنواع الكائنات، أو أنواع العلاقات، أو أنواع الإجراءات، أو مجموعات المفاهيم، أو عندما يطلب المستخدم تصميم نموذج للمعرفة التجارية بتنسيق BKN. عندما يتم تحميل kweaver-core أيضًا، استخدمه لتشغيل kweaver CLI (auth، bkn Push) بعد وجود الملفات.
