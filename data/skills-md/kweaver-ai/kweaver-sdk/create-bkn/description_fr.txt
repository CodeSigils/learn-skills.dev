Guide la création de fichiers de définition BKN (Business Knowledge Network) conformément à la spécification v2.0.0. Couvre le réseau, object_type, relation_type, action_type, concept_group. À utiliser lors de la création de réseaux de connaissances, de fichiers BKN, de types d'objets, de types de relations, de types d'actions, de groupes de concepts ou lorsque l'utilisateur demande de modéliser les connaissances métier au format BKN. Lorsque kweaver-core est également chargé, utilisez-le pour exécuter kweaver CLI (auth, bkn push) une fois les fichiers existants.
