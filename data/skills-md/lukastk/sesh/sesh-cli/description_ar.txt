استخدم `sesh` CLI/TUI لسرد جلسات وكيل الترميز أو البحث عنها أو إدخالها أو استئنافها أو إنشائها أو وضع علامة عليها أو أرشفتها أو إعادة تسميتها أو حذفها أو إرسالها إلى أو فحصها عبر الأجهزة. يُستخدم عندما يسأل المستخدم عن استخدام أمر sesh، أو TUI للجلسة، أو الدخول/استئناف sesh، أو حالة جلسة العمل عبر الأجهزة، أو البرنامج الخفي sesh، أو الأقران.
