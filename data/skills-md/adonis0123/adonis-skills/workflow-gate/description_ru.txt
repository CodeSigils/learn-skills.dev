Используйте ПЕРЕД загрузкой навыков более тяжелого рабочего процесса (мозговой штурм, обсуждение перед планированием, написание планов, разработка подагентом, передача агентской проверки, выполнение планов, завершение ветки разработки), когда маршрут еще не очевиден. 60-90-секундный консультативный классификатор, который предотвращает чрезмерную или недостаточную эскалацию. Выводит один маршрут, один навык выполнения с одним жетоном для загрузки следующего, один дополнительный резервный псевдоним для совместимости с Клодом/Кодексом и один путь выполнения. Творческая работа (новая функция/реплицирование пользовательского интерфейса/редизайн/намеренное изменение поведения) без ссылки на проектный документ или спецификацию ДОЛЖНА направляться в Brainstorm, даже когда пользователь называет планы написания или спрашивает, какой рабочий процесс использовать. Пропускайте шлюз ТОЛЬКО для однострочного поиска только для чтения, редактирования чистого форматирования без изменения поведения или явно названного нижестоящего навыка, который уже безопасен и неразрушителен.
