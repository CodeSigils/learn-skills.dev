Initialisieren oder migrieren Sie Agent-Skill-Symlinks in einem beliebigen Repository. Verwenden Sie diese Option, wenn für ein Projekt eine Verknüpfung von „.claude/skills“ mit „.agents/skills“, eine Verknüpfung von „AGENTS.md“ mit „CLAUDE.md“, eine Migration weg von „.ruler“-basierten KI-Regeln oder die Entfernung älterer „sync-llm-skills“-Kopier-/Synchronisierungseinstellungen erforderlich ist. Wird bei Anfragen zu Claude/Codex-Skill-Symlinks, AGENTS/CLAUDE-Symlinks, der Einrichtung von „.claude/skills“, dem Ersetzen kopierter Skill-Ordner durch Symlinks oder dem Bereinigen alter Lineal-/Synchronisierungsautomatisierungen ausgelöst.
