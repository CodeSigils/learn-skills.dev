Coware Living Specs — общая синхронизация спецификаций API для групп мультиагентного кодирования. ТРИГГЕР, когда: в проекте есть каталог .coware/, пользователь упоминает общие спецификации, согласование API, конфликты слияния, синхронизацию интерфейса, координацию команды, совместную работу над кодированием Vibe или рабочий процесс кодирования AI с участием нескольких разработчиков. НЕ ЗАПУСКАТЬ, когда: проект с одним разработчиком без каталога .coware/ и пользователь не упомянул о совместной работе в команде.
