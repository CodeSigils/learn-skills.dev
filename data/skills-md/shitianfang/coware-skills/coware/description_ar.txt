Coware Living Specs - مزامنة مواصفات API المشتركة لفرق الترميز متعددة الوكلاء. يتم تشغيله عندما: يحتوي المشروع على دليل .coware/، أو يذكر المستخدم المواصفات المشتركة، أو محاذاة واجهة برمجة التطبيقات (API)، أو تعارضات الدمج، أو مزامنة الواجهة، أو تنسيق الفريق، أو تعاون الترميز الحيوي، أو سير عمل ترميز الذكاء الاصطناعي متعدد التطوير. لا يتم تشغيله عندما: مشروع مطور فردي بدون دليل .coware/ ولم يذكر المستخدم تعاون الفريق.
