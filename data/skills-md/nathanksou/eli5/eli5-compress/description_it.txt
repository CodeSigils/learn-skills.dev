Comprimi i file di memoria in linguaggio naturale (CLAUDE.md, todos, preferences) in un linguaggio semplice e chiaro per risparmiare token di input. Semplifica i testi ricchi di gergo mantenendo tutta la sostanza tecnica, il codice, gli URL e la struttura. La versione compressa sovrascrive il file originale. Un backup leggibile dall’uomo viene salvato come FILE.original.md. Attivatore: /eli5-compress <filepath> o "compress memory file".
