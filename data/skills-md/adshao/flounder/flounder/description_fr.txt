Exploite Flounder, un auditeur de sécurité autonome au chapeau blanc. À utiliser lorsqu'un utilisateur demande un audit de sécurité, un examen de prime aux bogues, une enquête de vulnérabilité ou une preuve d'exploitation pour un référentiel autorisé, une arborescence source, un package, un contrat intelligent, un projet Solidity/EVM, un code ZK ou un système de preuve, une adresse déployée, une transaction, un lien de projet ou une exécution antérieure de Flounder ; pour exécuter Flounder, préparer, cartographier, creuser, auditer, vérifier, confirmer ou signaler les flux de travail ; pour configurer le serveur Flounder, le démon, les profils de fournisseur, l'authentification du modèle, l'exécution en bac à sable, les chemins de corpus, les chemins sources, les racines de construction, la couverture ou les budgets ; pour surveiller l'activité d'audit en direct, poursuivre les étendues en attente, vérifier les vulnérabilités suspectées, reproduire les résultats ou collecter des rapports de bogues basés sur l'exécution.
