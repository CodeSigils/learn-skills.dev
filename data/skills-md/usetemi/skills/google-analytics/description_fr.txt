Interrogez les rapports GA4 (utilisateurs, sessions, conversions, entonnoirs, temps réel), gérez les propriétés/flux de données/événements clés/dimensions personnalisées/audiences/liaisons d'accès et envoyez les événements du protocole de mesure via la CLI « ga4 ». Utilisez cette compétence chaque fois que l'utilisateur mentionne GA4, Google Analytics, les ID de propriété commençant par « propriétés/ », les événements de suivi, les mesures d'engagement ou de trafic, l'attribution, les conversions, les événements clés, les audiences, les liens BigQuery, les rôles d'accès ou les utilisateurs en temps réel, même s'ils ne disent pas explicitement « GA4 ». Ne pas utiliser pour Google Search Console (voir la compétence google-search-console) ou pour l'analyse Web générique dont la source n'est pas GA4 (demandez d'abord).
