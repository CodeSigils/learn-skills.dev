Consulte informes GA4 (usuarios, sesiones, conversiones, embudos, tiempo real), administre propiedades/flujos de datos/eventos clave/dimensiones personalizadas/audiencias/vinculaciones de acceso y envíe eventos del Protocolo de medición a través de la CLI `ga4`. Utilice esta habilidad siempre que el usuario mencione GA4, Google Analytics, ID de propiedad que comiencen con "properties/", eventos de seguimiento, métricas de interacción o tráfico, atribución, conversiones, eventos clave, audiencias, enlaces de BigQuery, roles de acceso o usuarios en tiempo real, incluso si no dicen explícitamente "GA4". No lo utilice para Google Search Console (consulte la habilidad google-search-console) ni para análisis web genéricos donde la fuente no sea GA4 (pregunte primero).
