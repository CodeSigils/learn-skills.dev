الاستعلام عن تقارير GA4 (المستخدمون، والجلسات، والتحويلات، ومسارات التحويل، والوقت الفعلي)، وإدارة الخصائص / مصادر البيانات / الأحداث الرئيسية / الأبعاد المخصصة / الجماهير / روابط الوصول، وإرسال أحداث Measurement Protocol عبر واجهة سطر الأوامر `ga4`. استخدم هذه المهارة عندما يذكر المستخدم "إحصاءات Google"‏ 4، أو "إحصاءات Google"، أو معرّفات المواقع التي تبدأ بـ "الخصائص/"، أو أحداث التتبع، أو مقاييس التفاعل أو عدد الزيارات، أو الإحالة، أو التحويلات، أو الأحداث الرئيسية، أو الجماهير، أو روابط BigQuery، أو أدوار الوصول، أو المستخدمين في الوقت الفعلي - حتى إذا لم يذكروا "GA4" صراحةً. لا تستخدم مع Google Search Console (راجع مهارات google-search-console) أو تحليلات الويب العامة حيث لا يكون المصدر GA4 (اسأل أولاً).
