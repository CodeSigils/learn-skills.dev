[Hyper] Crea, inserisci, elenca, rimuovi, pulisci o ripara alberi di lavoro Git per rami isolati e sessioni di agenti paralleli, inclusa la creazione diretta di `git-worktree <ARGUMENT>` senza domande di follow-up. Da utilizzare quando l'utente richiede l'impostazione/rimozione di git worktree, flussi di lavoro ramo per cartella, spazi di lavoro paralleli Codex/Claude/Cursor o la convenzione `.hypercore/git-worktree/<nome_cartella>` locale del repository; durante la creazione e nessun argomento/attività è chiaro, chiedi quale lavoro verrà svolto lì nella lingua dell'utente, ricava il nome della cartella, quindi sposta il lavoro successivo nel nuovo albero di lavoro.
