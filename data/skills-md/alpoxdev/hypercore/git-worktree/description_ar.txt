[Hyper] إنشاء أشجار عمل Git أو إدخالها أو إدراجها أو إزالتها أو تنظيفها أو إصلاحها للفروع المعزولة وجلسات الوكيل المتوازية، بما في ذلك الإنشاء المباشر لـ git-worktree <ARGUMENT>` بدون أسئلة متابعة. يُستخدم عندما يطلب المستخدم إعداد/إزالة شجرة عمل git، أو سير عمل فرع لكل مجلد، أو مساحات عمل Codex/Claude/Cursor المتوازية، أو اتفاقية المستودع المحلي `.hypercore/git-worktree/<folder_name>`؛ عند الإنشاء ولا توجد وسيطة/مهمة واضحة، اسأل عن العمل الذي سيحدث هناك بلغة المستخدم، واشتق اسم المجلد، ثم انقل العمل اللاحق إلى شجرة العمل الجديدة.
