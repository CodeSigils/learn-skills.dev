[Hyper] Cree, ingrese, enumere, elimine, limpie o repare árboles de trabajo de Git para ramas aisladas y sesiones de agentes paralelas, incluida la creación directa de `git-worktree <ARGUMENT>` sin preguntas de seguimiento. Úselo cuando el usuario solicite configuración/eliminación de git worktree, flujos de trabajo de rama por carpeta, espacios de trabajo paralelos de Codex/Claude/Cursor o la convención local del repositorio `.hypercore/git-worktree/<folder_name>`; al crear y no hay ningún argumento/tarea claro, pregunte qué trabajo se realizará allí en el idioma del usuario, obtenga el nombre de la carpeta y luego mueva el trabajo posterior al nuevo árbol de trabajo.
