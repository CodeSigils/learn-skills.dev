[Гипер] Создание, ввод, перечисление, удаление, очистка или восстановление рабочих деревьев Git для изолированных ветвей и параллельных сеансов агента, включая прямое создание `git-worktree <ARGUMENT>` без дополнительных вопросов. Используйте, когда пользователь запрашивает установку/удаление рабочего дерева git, рабочие процессы для каждой папки, параллельные рабочие пространства Codex/Claude/Cursor или локальное соглашение `.hypercore/git-worktree/<folder_name>`; когда при создании нет ясного аргумента/задачи, спросите, какая работа будет выполняться на языке пользователя, получите имя папки, а затем переместите последующую работу в новое рабочее дерево.
