[ハイパー] 分離されたブランチおよび並列エージェント セッションの Git ワークツリーを作成、入力、リスト、削除、クリーンアップ、または修復します。これには、フォローアップの質問なしで直接「git-worktree <ARGUMENT>」を作成することも含まれます。ユーザーが git worktree のセットアップ/削除、フォルダーごとのブランチ ワークフロー、並列 Codex/Claude/Cursor ワークスペース、またはリポジトリ ローカルの `.hypercore/git-worktree/<folder_name>` 規則を要求する場合に使用します。作成時に引数やタスクが明確でない場合は、ユーザーの言語でそこでどのような作業が行われるかを尋ね、フォルダー名を導き出し、その後の作業を新しいワークツリーに移動します。
