[Hyper] 후속 질문 없이 직접 `git-worktree <ARGUMENT>` 생성을 포함하여 격리된 분기 및 병렬 에이전트 세션에 대한 Git 작업 트리를 생성, 입력, 나열, 제거, 정리 또는 복구합니다. 사용자가 git 작업 트리 설정/제거, 폴더별 분기 워크플로, 병렬 Codex/Claude/Cursor 작업 영역 또는 저장소 로컬 `.hypercore/git-worktree/<folder_name>` 규칙을 요청할 때 사용합니다. 생성 시 인수/작업이 명확하지 않은 경우 사용자의 언어로 어떤 작업이 발생할지 물어보고 폴더 이름을 파생한 다음 후속 작업을 새 작업 트리로 옮깁니다.
