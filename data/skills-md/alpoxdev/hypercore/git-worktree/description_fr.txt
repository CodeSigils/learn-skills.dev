[Hyper] Créez, saisissez, répertoriez, supprimez, nettoyez ou réparez les arbres de travail Git pour les branches isolées et les sessions d'agent parallèles, y compris la création directe de `git-worktree <ARGUMENT>` sans questions de suivi. À utiliser lorsque l'utilisateur demande la configuration/suppression de git worktree, des workflows de branche par dossier, des espaces de travail parallèles Codex/Claude/Curseur ou la convention `.hypercore/git-worktree/<folder_name>` du référentiel local ; lors de la création et qu'aucun argument/tâche n'est clair, demandez quel travail s'y déroulera dans la langue de l'utilisateur, dérivez le nom du dossier, puis déplacez le travail ultérieur dans le nouvel arbre de travail.
