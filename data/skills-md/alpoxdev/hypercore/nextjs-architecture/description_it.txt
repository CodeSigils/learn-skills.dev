Da utilizzare quando si lavora su progetti Next.js o si introduce App Router in una codebase. Applica le regole ufficiali dell'architettura Next.js per la struttura dell'app, i limiti dei componenti server e client, il recupero dei dati innanzitutto dal server e un ordine decisionale predefinito dei componenti server per le letture, le azioni server per le scritture interne, i gestori di route per gli endpoint nativi HTTP e il proxy solo come ultima risorsa.
