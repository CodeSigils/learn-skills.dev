À utiliser lorsque vous travaillez sur des projets Next.js ou lorsque vous introduisez App Router dans une base de code. Applique les règles officielles de l'architecture Next.js pour la structure de l'application, les limites des composants serveur et client, la récupération des données en premier sur le serveur et un ordre de décision par défaut des composants serveur pour les lectures, les actions serveur pour les écritures internes, les gestionnaires de routes pour les points de terminaison HTTP natifs et le proxy uniquement en dernier recours.
