Úselo cuando trabaje en proyectos de Next.js o introduzca App Router en una base de código. Aplica reglas de arquitectura oficiales de Next.js para la estructura de la aplicación, los límites de los componentes del servidor y del cliente, la obtención de datos primero del servidor y un orden de decisión predeterminado de los componentes del servidor para lecturas, acciones del servidor para escrituras internas, controladores de ruta para puntos finales nativos HTTP y proxy solo como último recurso.
