Используйте при работе над проектами Next.js или при добавлении App Router в базу кода. Применяет официальные правила архитектуры Next.js для структуры приложения, границ серверных и клиентских компонентов, выборки данных с сервера и порядка принятия решений по умолчанию для серверных компонентов для чтения, действий сервера для внутренней записи, обработчиков маршрутов для собственных конечных точек HTTP и прокси-сервера только в крайнем случае.
