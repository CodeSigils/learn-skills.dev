Используйте, когда пользователю явно нужен CLI Anthropic Claude Code («claude») для изолированного сеанса, неинтерактивного запуска или возобновления сеанса. Триггерные фразы: «использовать код Клода», «спросить Клода», «запустить Клода», «продолжить последний сеанс Клода» или «использовать CLI Anthropic для проверки или исправления этого репозитория».
