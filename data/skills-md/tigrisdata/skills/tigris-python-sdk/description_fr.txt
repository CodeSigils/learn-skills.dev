À utiliser lorsque vous travaillez avec Tigris à partir de Python : configuration de boto3, téléchargements de Django via des stockages Django, instantanés, fork de compartiment, changement de nom d'objet sur place, écritures conditionnelles (IfMatch/IfNoneMatch) et l'API Bundle pour les récupérations de données ML par lots. Couvre la bibliothèque d'extensions tigris-boto3-ext (gestionnaires de contexte, décorateurs, assistants) ainsi que l'intégration du framework.
