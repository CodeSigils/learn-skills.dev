استخدمه عند العمل مع Tigris من Python - إعداد boto3، وتحميلات Django عبر مخازن Django، واللقطات، وتقسيم الجرافة، وإعادة تسمية الكائن في المكان، والكتابة المشروطة (IfMatch/IfNoneMatch)، وBundle API لجلب بيانات ML المجمعة. يغطي مكتبة الملحقات tigris-boto3-ext (مديري السياق، ومصممي الديكور، والمساعدين) بالإضافة إلى تكامل الإطار.
