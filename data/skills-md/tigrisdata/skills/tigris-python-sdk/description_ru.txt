Используйте при работе с Tigris из Python — настройка boto3, загрузка Django через хранилища django, снимки, разветвление корзины, переименование объектов на месте, условные записи (IfMatch/IfNoneMatch) и Bundle API для пакетной выборки данных ML. Охватывает библиотеку расширений tigris-boto3-ext (контекстные менеджеры, декораторы, помощники), а также интеграцию с фреймворком.
