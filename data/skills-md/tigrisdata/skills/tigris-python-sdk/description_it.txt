Da utilizzare quando si lavora con Tigris da Python: configurazione di boto3, caricamenti di Django tramite archivi django, snapshot, fork del bucket, ridenominazione di oggetti sul posto, scritture condizionali (IfMatch/IfNoneMatch) e API bundle per recuperi di dati ML batch. Copre la libreria di estensioni tigris-boto3-ext (gestori di contesto, decoratori, aiutanti) più l'integrazione del framework.
