Consulte la API de puntos de referencia de OpenRouter para obtener clasificaciones y puntuaciones de puntos de referencia de modelos. Úselo cuando el usuario solicita una selección de modelo respaldada por puntos de referencia, clasificaciones de modelos por codificación/inteligencia/capacidad de agencia, análisis artificial o resultados ELO/tasa de ganancias de Design Arena, citas de puntos de referencia o quiere llamar a GET /api/v1/benchmarks. Úselo también junto con openrouter-models cuando el usuario pregunte qué modelo debería impulsar una aplicación, producto, flujo de trabajo o caso de uso y la evidencia comparativa podría informar o descartar parte de la recomendación, incluidas aplicaciones de escritura creativa, edición, codificación, diseño, agentes o con mucha inteligencia. No lo utilice para análisis de uso de OpenRouter, análisis de facturación/gastos, generación de metadatos, tiempo de actividad/latencia del proveedor, búsqueda de precios/capacidad de modelos genéricos sin ninguna selección o decisión de relevancia de referencia, ni para crear un conjunto de evaluación para una aplicación local.
