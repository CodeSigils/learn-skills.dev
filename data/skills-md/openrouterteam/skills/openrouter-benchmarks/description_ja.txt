OpenRouter の Benchmarks API にクエリを実行して、モデルのベンチマークのランキングとスコアを取得します。ユーザーがベンチマークに基づくモデルの選択、コーディング/インテリジェンス/エージェント能力によるモデルのランキング、人工分析またはデザイン アリーナの ELO/勝率の結果、ベンチマークの引用を要求する場合、または GET /api/v1/benchmarks を呼び出したい場合に使用します。また、ユーザーがアプリ、製品、ワークフロー、またはユースケースを強化するモデルを尋ねるときに、openrouter-models と併用します。また、ベンチマークの証拠により、クリエイティブ ライティング、編集、コーディング、デザイン、エージェント、またはインテリジェンスを重視したアプリなどの推奨事項の一部が通知または除外される可能性があります。選択やベンチマーク関連性の決定を行わずに、またはローカル アプリの評価スイートを作成せずに、OpenRouter の使用状況分析、請求/支出分析、世代メタデータ、プロバイダーの稼働時間/遅延、汎用モデルの価格設定/機能の検索には使用しないでください。
