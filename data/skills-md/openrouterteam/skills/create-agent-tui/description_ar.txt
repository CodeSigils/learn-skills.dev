يدعم وكيل TUI كاملاً في TypeScript باستخدام @openrouter/agent - مثل تطبيق create-react-app لوكلاء المحطة الطرفية. ينشئ واجهة طرفية قابلة للتخصيص بثلاثة أنماط إدخال وأربعة أوضاع لعرض الأدوات ولافتات ASCII وإخراج البث واستمرارية الجلسة وأدوات قابلة للتكوين. يُستخدم عند إنشاء وكيل، أو إنشاء TUI، أو دعم مشروع وكيل، أو إنشاء مساعد ترميز.
