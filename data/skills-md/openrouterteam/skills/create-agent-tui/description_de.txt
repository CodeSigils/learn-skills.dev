Baut mithilfe von @openrouter/agent eine vollständige Agenten-TUI in TypeScript auf – wie eine Create-React-App für Terminalagenten. Erzeugt eine anpassbare Terminalschnittstelle mit drei Eingabestilen, vier Tool-Anzeigemodi, ASCII-Bannern, Streaming-Ausgabe, Sitzungspersistenz und konfigurierbaren Tools. Wird zum Erstellen eines Agenten, zum Erstellen einer TUI, zum Gerüstbau eines Agentenprojekts oder zum Erstellen eines Codierungsassistenten verwendet.
