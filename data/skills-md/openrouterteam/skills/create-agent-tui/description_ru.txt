Формирует полный TUI агента в TypeScript с использованием @openrouter/agent — например, create-react-app для терминальных агентов. Создает настраиваемый интерфейс терминала с тремя стилями ввода, четырьмя режимами отображения инструментов, баннерами ASCII, потоковым выводом, сохранением сеанса и настраиваемыми инструментами. Используйте при создании агента, TUI, создании проекта агента или создании помощника по программированию.
