Cette compétence doit être utilisée lors de la mise en œuvre, de l'utilisation ou du débogage d'une API compatible Open Responses, la norme ouverte pour l'interopérabilité LLM multi-fournisseurs. Couvre le protocole, les éléments, les machines à états, les événements de streaming, les outils, le modèle de boucle agent et les extensions. Déclencheurs sur : les réponses ouvertes, les réponses ouvertes, le point de terminaison /v1/responses, l'API LLM multifournisseur, la conformité des réponses ouvertes.
