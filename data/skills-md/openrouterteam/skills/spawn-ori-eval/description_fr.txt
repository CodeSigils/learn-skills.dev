Générez Ori en tant que sous-processus pour exécuter une évaluation de modèle jetable sur un faisceau et un modèle épinglés, puis relayez les résultats. À utiliser lorsque l'utilisateur demande quel modèle il doit utiliser, souhaite comparer des modèles, souhaite mesurer si son agent ou son invite fait la bonne chose, souhaite détecter les régressions dans le comportement de l'agent ou demande quelle est la qualité de son modèle actuel. S'applique à n'importe quelle base de code dans n'importe quelle langue. Ne pas utiliser pour des tests unitaires simples qui n'impliquent aucun modèle, et ne pas utiliser pour réexécuter une évaluation qui existe déjà (exécuter directement `ori eval <file>`).
