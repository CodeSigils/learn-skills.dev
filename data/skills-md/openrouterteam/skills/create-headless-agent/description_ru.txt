Формирует автономный агент в TypeScript с использованием @openrouter/agent и Bun — для инструментов CLI, серверов API, обработчиков очередей и конвейеров. Нет пользовательского интерфейса терминала. Используйте при создании автономного агента, программного агента, инструмента CLI, использующего искусственный интеллект, пакетного агента, агента конвейера, агента API, агента без пользовательского интерфейса или службы агента.
