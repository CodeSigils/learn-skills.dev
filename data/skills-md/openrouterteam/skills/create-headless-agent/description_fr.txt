Élabore un agent sans tête dans TypeScript à l'aide de @openrouter/agent et Bun — pour les outils CLI, les serveurs API, les gestionnaires de file d'attente et les pipelines. Aucune interface utilisateur de terminal. À utiliser lors de la création d'un agent sans tête, d'un agent de programmation, d'un outil CLI qui utilise l'IA, d'un agent par lots, d'un agent de pipeline, d'un agent API, d'un agent sans interface utilisateur ou d'un service d'agent.
