يدعم وكيل بدون رأس في TypeScript باستخدام @openrouter/agent وBun - لأدوات CLI وخوادم API وعمال قائمة الانتظار وخطوط الأنابيب. لا توجد واجهة مستخدم طرفية. يُستخدم عند إنشاء وكيل بدون رأس، أو وكيل برمجي، أو أداة CLI تستخدم الذكاء الاصطناعي، أو وكيل الدفعة، أو وكيل خط الأنابيب، أو وكيل واجهة برمجة التطبيقات، أو الوكيل بدون واجهة مستخدم، أو خدمة الوكيل.
