Supporta un agente headless in TypeScript utilizzando @openrouter/agent e Bun: per strumenti CLI, server API, operatori in coda e pipeline. Nessuna interfaccia utente del terminale. Da utilizzare durante la creazione di un agente headless, un agente programmatico, uno strumento CLI che utilizza l'intelligenza artificiale, un agente batch, un agente pipeline, un agente API, un agente senza interfaccia utente o un servizio agente.
