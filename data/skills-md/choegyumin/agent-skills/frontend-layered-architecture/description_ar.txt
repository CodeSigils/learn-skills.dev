يُستخدم عندما يتطلب عمل الواجهة الأمامية تحديد ملكية التعليمات البرمجية، أو وضع الملف، أو اتجاه الاستيراد، أو حدود الطبقة، خاصة بالنسبة لبنية الدليل، أو استخراج واجهة المستخدم/المكونات، أو المجلدات المشتركة/المستندة إلى النوع، أو عقود واجهة برمجة التطبيقات (API)، أو جلب الاستعلام/البيانات، أو حالة عنوان URL، أو مخططات الخرائط، أو الخطافات، أو المتاجر، أو DTOs، أو تغييرات واجهة المستخدم الصغيرة التي قد تخلط بين سياسة المنتج أو قواعد العمل أو البيانات الخارجية في أدوار منخفضة المستوى.
