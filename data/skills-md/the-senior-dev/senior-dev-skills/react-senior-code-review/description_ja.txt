SeniorDev による React 機能の上級レベルのレビュー — 構造と境界、状態とデータ フロー、パフォーマンスとレンダリング、タイプ/フォーム/テスト容易性/a11y、スタイリング アーキテクチャとモーション。当てはまるデザインパターンを名前で推奨します。 file:line、理由、および具体的な修正を使用して優先順位付けされた検出結果 (Critical → Nit) を生成し、検出結果ごとに適用するかどうかを尋ねます。 「この React 機能のレビュー」、「監査機能のアーキテクチャ」、「上級レビュー」、「上級開発レビュー」、または `/react-senior-code-review <path>` 経由で依頼された場合に使用します。
