مهارة الرسم الديناميكي لـ Enterprise AutoCAD لـ Claude Code - صياغة خطوة بخطوة تعتمد على COM مع تأخير قابل للتكوين، ونسخ احتياطي تلقائي، وإدارة الطبقات، والتسجيل. يُستخدم عندما يذكر المستخدم "AutoCAD 动态绘制"، أو "逐步画图"، أو "演示画图过程"، أو "AutoCAD 中一笔一笔画"، أو صياغة/رسم CAD. يدعم التصور في الوقت الفعلي لكل كيان رسم لمراجعة التصميم والعروض التوضيحية للتدريب وتوثيق العملية.
