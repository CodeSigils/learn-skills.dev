ZEGO ドキュメントで特定の API 情報、エラー コード、エラー メッセージ、パラメーターを検索します。ユーザーがエラー コード/エラー メッセージの意味、API パラメーター、または機能のサポートについて質問する場合に使用します。 ZEGO SDK の問題のトラブルシューティングやプラットフォームの互換性を確認するときに使用します。ユーザーが错误コード、このパラメータの意思決定、API の使用、ZEGO サポートの有無、または RTC/ZIM/Express SDK の問題のデバッグについて言及する場合に使用します。ユーザーが ZEGO 製品/機能を統合または実装したい場合は、このスキルを使用しないでください。代わりに、integrate-zego-product を使用してください。
