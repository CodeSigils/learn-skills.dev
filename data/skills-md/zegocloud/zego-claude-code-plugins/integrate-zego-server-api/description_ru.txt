Реализует интеграцию API сервера ZEGO с аутентификацией по подписи. Используйте, когда пользователь запрашивает вызов API-интерфейсов сервера ZEGO, создание подписей API или интеграцию внутренних функций. Используйте при реализации управления комнатами, микшировании потоков, удалении пользователей или обмене сообщениями между серверами. Используйте, когда пользователь упоминает 服务端API, 签名, 后端调用, подпись API сервера или интеграцию серверной части с агентом RTC/ZIM/AI.
