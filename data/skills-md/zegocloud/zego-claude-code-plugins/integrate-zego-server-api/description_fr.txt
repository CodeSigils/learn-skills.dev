Implémente l'intégration de l'API du serveur ZEGO avec l'authentification par signature. À utiliser lorsque l'utilisateur demande à appeler les API du serveur ZEGO, à générer des signatures API ou à intégrer des fonctionnalités backend. À utiliser lors de la mise en œuvre de la gestion de salle, du mixage de flux, de l'envoi d'utilisateurs ou de la messagerie de serveur à serveur. À utiliser lorsque l'utilisateur mentionne 服务端API, 签名, 后端调用, la signature API du serveur ou l'intégration backend avec l'agent RTC/ZIM/AI.
