Strumento di revisione e ottimizzazione del registro di rilascio di ZEGO. Utilizzato per rivedere e ottimizzare le note di rilascio nei documenti ZEGO, tra cui: controllo della completezza dei campi richiesti (numero di versione, data di rilascio, contenuto di modifica), verifica della coerenza del formato (tabella/pannello comprimibile/modulo elenco) e valutazione della qualità dell'espressione (uso di titoli onorifici, collegamenti a termini tecnici, espressione eufemistica delle soluzioni dei problemi). Utilizza questa capacità quando l'utente richiede di rivedere, controllare o ottimizzare i registri di rilascio o quando il file release-notes.mdx viene aperto e dice direttamente ottimizza.
