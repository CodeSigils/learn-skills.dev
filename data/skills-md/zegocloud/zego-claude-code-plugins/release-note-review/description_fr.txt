Outil d'examen et d'optimisation du journal de version ZEGO. Utilisé pour examiner et optimiser les notes de version dans les documents ZEGO, notamment : vérifier l'exhaustivité des champs obligatoires (numéro de version, date de publication, contenu modifié), vérifier la cohérence du format (tableau/panneau pliable/formulaire de liste) et évaluer la qualité de l'expression (utilisation de titres honorifiques, liens de termes techniques, expression euphémique des correctifs de problèmes). Utilisez cette compétence lorsque l'utilisateur demande à examiner, vérifier ou optimiser les journaux de version ou lorsque le fichier release-notes.mdx est ouvert et dit directement optimiser.
