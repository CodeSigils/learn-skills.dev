ZEGO-Release-Log-Überprüfungs- und Optimierungstool. Wird zur Überprüfung und Optimierung von Versionshinweisen in ZEGO-Dokumenten verwendet, einschließlich: Überprüfung der Vollständigkeit erforderlicher Felder (Versionsnummer, Veröffentlichungsdatum, Änderungsinhalt), Überprüfung der Formatkonsistenz (Tabelle/zusammenklappbares Panel/Listenformular) und Bewertung der Ausdrucksqualität (Verwendung von Ehrentiteln, Links zu technischen Begriffen, euphemistische Ausdrücke von Problembehebungen). Verwenden Sie diese Fähigkeit, wenn der Benutzer die Überprüfung, Prüfung oder Optimierung von Versionsprotokollen anfordert oder wenn die Datei „release-notes.mdx“ geöffnet wird und direkt „Optimieren“ sagt.
