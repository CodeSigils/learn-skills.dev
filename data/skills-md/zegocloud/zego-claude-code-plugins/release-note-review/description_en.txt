ZEGO Release Log Review and Optimization Tool. Used to review and optimize release notes in ZEGO documents, including: checking the completeness of required fields (version number, release date, change content), verifying format consistency (table/collapsible panel/list form), and evaluating expression quality (use of honorifics, technical term links, euphemistic expression of problem fixes). Use this skill when the user requests to review, check, or optimize release logs or when the release-notes.mdx file is opened and directly says optimize.
