أداة مراجعة سجل إصدار ZEGO وتحسينها. يُستخدم لمراجعة ملاحظات الإصدار وتحسينها في مستندات ZEGO، بما في ذلك: التحقق من اكتمال الحقول المطلوبة (رقم الإصدار، تاريخ الإصدار، تغيير المحتوى)، والتحقق من اتساق التنسيق (جدول/لوحة قابلة للطي/نموذج قائمة)، وتقييم جودة التعبير (استخدام التكريم، وروابط المصطلحات الفنية، والتعبير الملطف لإصلاحات المشكلات). استخدم هذه المهارة عندما يطلب المستخدم مراجعة سجلات الإصدار أو فحصها أو تحسينها أو عندما يتم فتح ملف Release-notes.mdx ويشير مباشرة إلى التحسين.
