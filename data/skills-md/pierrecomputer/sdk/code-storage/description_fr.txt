Compétence d'agent pour interagir avec code.storage, une couche d'infrastructure Git gérée. Fournit la création de référentiels, le branchement, les validations, l'accès aux fichiers, les différences, la recherche, les notes, la synchronisation GitHub, les branches éphémères et le forking via une API HTTP RESTful authentifiée avec des JWT signés par le client. Chaque opération de mise en pension est limitée à JWT.
