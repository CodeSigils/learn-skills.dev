مهارة الوكيل للتفاعل مع code.storage، وهي طبقة بنية تحتية مُدارة لـ Git. يوفر إنشاء المستودع، والتفريع، والالتزامات، والوصول إلى الملفات، والاختلافات، والبحث، والملاحظات، ومزامنة GitHub، والفروع المؤقتة، والتفرع من خلال RESTful HTTP API المصادق عليها باستخدام JWTs الموقعة من قبل العميل. يتم تحديد نطاق كل عملية ريبو لكل JWT.
