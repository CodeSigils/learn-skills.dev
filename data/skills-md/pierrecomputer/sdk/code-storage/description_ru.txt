Навыки агента по взаимодействию с code.storage — управляемым уровнем инфраструктуры Git. Обеспечивает создание репозитория, ветвление, фиксацию, доступ к файлам, различия, поиск, заметки, синхронизацию GitHub, временные ветки и разветвление через RESTful HTTP API, аутентифицированный с помощью JWT, подписанных клиентом. Каждая операция репо распространяется на JWT.
