Agentenfähigkeit für die Interaktion mit code.storage, einer verwalteten Git-Infrastrukturebene. Bietet Repository-Erstellung, Verzweigung, Commits, Dateizugriff, Diffs, Suche, Notizen, GitHub-Synchronisierung, kurzlebige Verzweigungen und Fork über eine RESTful-HTTP-API, die mit vom Kunden signierten JWTs authentifiziert ist. Jeder Repo-Vorgang gilt pro JWT.
