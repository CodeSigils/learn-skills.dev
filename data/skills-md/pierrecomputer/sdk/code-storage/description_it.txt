Abilità dell'agente per interagire con code.storage, un livello di infrastruttura Git gestito. Fornisce creazione di repository, ramificazione, commit, accesso ai file, differenze, ricerca, note, sincronizzazione GitHub, rami temporanei e fork tramite un'API HTTP RESTful autenticata con JWT firmati dal cliente. Ogni operazione di repository ha ambito per JWT.
