Habilidad del agente para interactuar con code.storage, una capa de infraestructura administrada de Git. Proporciona creación de repositorios, bifurcaciones, confirmaciones, acceso a archivos, diferencias, búsqueda, notas, sincronización de GitHub, bifurcaciones efímeras y bifurcaciones a través de una API HTTP RESTful autenticada con JWT firmados por el cliente. Cada operación de repositorio tiene un alcance según JWT.
