Установите и настройте сервер DefiLlama MCP для аналитики DeFi. Предоставляет 23 инструмента для TVL, цен токенов, доходности, показателей протокола, стейблкоинов, мостов, ETF, хаков, повышений и многого другого. Поддерживает вход по OAuth с вашей учетной записью DefiLlama. Используйте, когда пользователь хочет настроить DefiLlama MCP, подключиться к данным DeFi или установить инструменты аналитики DeFi.
