Guide pour interroger les données et les événements de flux DeFi à l'aide des outils DefiLlama MCP. Couvre les flux de transition, les entrées/sorties d'ETF, l'approvisionnement en pièces stables, les avoirs institutionnels/DAT avec ratios mNAV, les hacks et les exploits, les levées de fonds, les volumes CEX, les intérêts ouverts et les trésoreries de protocole. À utiliser lorsque les utilisateurs posent des questions sur le volume du pont, les flux d'ETF, l'approvisionnement en pièces stables, les avoirs MicroStrategy, les hacks DeFi, les cycles de financement, le volume d'échange ou les données de trésorerie.
