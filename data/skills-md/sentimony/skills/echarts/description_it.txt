Da utilizzare durante la creazione, il controllo, lo styling, il debug o l'ottimizzazione delle visualizzazioni Apache ECharts in applicazioni JavaScript, React o Vue Vanilla: configurazione di grafici, gestione del ciclo di vita, ridimensionamento reattivo, temi, set di dati di grandi dimensioni, aggiornamenti in streaming, rendering lato server (SVG in Node) e sintomi come un grafico vuoto o vuoto, un grafico che non si ridimensiona o non si aggiorna, serie obsolete dopo aver cambiato tipo di grafico o errori "componente non esistente". Non per la scelta dei tipi di grafici o del design visivo e non per altre librerie di grafici (D3, Chart.js, Highcharts).
