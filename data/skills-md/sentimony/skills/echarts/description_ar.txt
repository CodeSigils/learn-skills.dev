يُستخدم عند إنشاء تصورات Apache ECharts أو تدقيقها أو تصميمها أو تصحيحها أو تحسينها في تطبيقات JavaScript أو React أو Vue - إعداد المخطط، وإدارة دورة الحياة، وتغيير الحجم المستجيب، والسمات، ومجموعات البيانات الكبيرة، وتحديثات التدفق، والعرض من جانب الخادم (SVG في Node)، والأعراض مثل مخطط فارغ أو فارغ، أو مخطط لا يتم تغيير حجمه أو تحديثه، أو سلسلة قديمة بعد تبديل أنواع المخططات، أو أخطاء "المكونات غير موجودة". ليس لاختيار أنواع المخططات أو التصميم المرئي، وليس لمكتبات الرسوم البيانية الأخرى (D3، Chart.js، Highcharts).
