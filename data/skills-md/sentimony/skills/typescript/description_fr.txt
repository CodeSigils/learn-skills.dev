À utiliser lors de la configuration de tsconfig, de la résolution des erreurs du compilateur TypeScript, du débogage d'une vérification de type ou de builds lentes, de la résolution de modules et des problèmes ESM/CJS, de l'audit ou du renforcement de la rigueur du type dans une base de code existante, de la migration de JavaScript vers TypeScript, de la migration des versions majeures du compilateur telles que TypeScript 7 ou de la configuration de la vérification de type dans monorepos. Pas pour le travail de fonctionnalités générales qui se produit simplement dans une base de code TypeScript.
