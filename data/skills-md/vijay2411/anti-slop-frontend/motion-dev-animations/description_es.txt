Úselo para TODOS los trabajos de animación de React/JSX: transiciones de página, revelaciones activadas por desplazamiento, animaciones de diseño, manejo de gestos, microinteracciones de desplazamiento/toque, fondos animados, secuencias escalonadas y cualquier movimiento que históricamente se haya realizado con framer-motion. motion.dev (anteriormente Framer Motion) es el reemplazo moderno: motor híbrido más pequeño (respaldo CSS + JS acelerado por hardware), API React directa. Prefiera siempre los fotogramas clave CSS para cualquier cosa que no sea trivial, prefiera siempre los fotogramas clave GSAP para proyectos React.
