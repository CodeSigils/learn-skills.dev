Utilizzare per TUTTI i lavori di animazione React/JSX: transizioni di pagina, rivelazioni attivate dallo scorrimento, animazioni di layout, gestione dei gesti, microinterazioni al passaggio del mouse/tocco, sfondi animati, sequenze sfalsate e qualsiasi movimento storicamente eseguito con framer-motion. motion.dev (precedentemente Framer Motion) è il sostituto moderno: motore ibrido più piccolo (CSS con accelerazione hardware + fallback JS), API React drop-in. Preferisci sempre ai fotogrammi chiave CSS per qualsiasi cosa non banale, preferisci sempre a GSAP per i progetti React.
