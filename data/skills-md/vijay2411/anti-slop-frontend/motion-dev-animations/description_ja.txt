すべての React/JSX アニメーション作業 - ページ遷移、スクロール トリガーによる表示、レイアウト アニメーション、ジェスチャー処理、ホバー/タップ マイクロ インタラクション、アニメーション化された背景、スタガー シーケンス、およびこれまでフレーマー モーションで行われていたあらゆるモーションに使用します。 motion.dev (旧称 Framer Motion) は、最新の置き換えとなる、小型のハイブリッド エンジン (ハードウェア アクセラレーションによる CSS + JS フォールバック)、ドロップイン React API です。重要でないものについては常に CSS キーフレームよりも優先され、React プロジェクトについては常に GSAP よりも優先されます。
