Use for ALL React/JSX animation work - page transitions, scroll-triggered reveals, layout animations, gesture handling, hover/tap micro-interactions, animated backgrounds, stagger sequences, and any motion that was historically done with framer-motion. motion.dev (formerly Framer Motion) is the modern replacement - smaller, hybrid engine (hardware-accelerated CSS + JS fallback), drop-in React API. Always prefer over CSS keyframes for anything non-trivial, always prefer over GSAP for React projects.
