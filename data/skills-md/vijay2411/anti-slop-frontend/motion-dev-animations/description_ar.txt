يُستخدم لجميع أعمال الرسوم المتحركة React/JSX - انتقالات الصفحة، والكشف عن التمرير، ورسوم التخطيط المتحركة، والتعامل مع الإيماءات، والتفاعلات الدقيقة بالتمرير/النقر، والخلفيات المتحركة، والتسلسلات المتدرجة، وأي حركة تم إجراؤها تاريخيًا باستخدام حركة الإطار. يعدmotion.dev (المعروف سابقًا باسم Framer Motion) هو البديل الحديث - محرك هجين أصغر حجمًا (احتياطي CSS + JS لتسريع الأجهزة)، وواجهة برمجة تطبيقات React. تفضل دائمًا إطارات CSS الرئيسية لأي شيء غير تافه، وتفضل دائمًا GSAP لمشاريع React.
