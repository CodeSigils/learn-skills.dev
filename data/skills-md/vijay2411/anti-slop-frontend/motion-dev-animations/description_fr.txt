À utiliser pour TOUS les travaux d'animation React/JSX : transitions de page, révélations déclenchées par défilement, animations de mise en page, gestion des gestes, micro-interactions de survol/appui, arrière-plans animés, séquences décalées et tout mouvement historiquement effectué avec framer-motion. motion.dev (anciennement Framer Motion) est le remplacement moderne - un moteur hybride plus petit (succès CSS + JS accéléré par le matériel), une API React intégrée. Préférez toujours les images clés CSS pour tout ce qui n'est pas trivial, préférez toujours le GSAP pour les projets React.
