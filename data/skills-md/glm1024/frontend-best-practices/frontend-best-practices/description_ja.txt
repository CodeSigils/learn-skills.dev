Web、ミニプログラム、アプリのサーフェス全体でユーザー向け UI を構築およびレビューするためのフロントエンド開発のベスト プラクティス。再作業ループを減らします。フロントエンド インターフェイス、特に非同期ボタン、フォーム、モーダル、ドロワー、テーブル、フィルター、アップロード、ダッシュボード、管理ツール、レスポンシブ レイアウト、読み込み/エラー/空/成功状態、アクセシビリティ、UX コピー、視覚的な磨き上げ、プラットフォーム固有のインタラクション、または検証の決定を作成、変更、研磨、またはレビューするときに使用します。ユーザーがフロントエンドのベスト プラクティス、繰り返しの手戻り、重複クリック、防重复提交、不好看、返工、状態态不完整、小程序、アプリ終了について言及する場合、またはハンドオフ前に UI 品質のチェックを希望する場合にも使用します。
