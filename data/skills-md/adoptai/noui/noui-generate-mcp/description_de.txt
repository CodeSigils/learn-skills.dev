Verwenden Sie diesen Skill, wenn der Benutzer generierte NoUI MCP-Server starten, stoppen, überprüfen oder auflisten oder einen Server mit Claude Code verbinden möchte. Auslöser bei „Starten Sie den MCP-Server“, „Run noui mcp“, „connect to Claude Code“, „add to mcpServers“, „Noui mcp start“, „Noui mcp list“, „Noui mcp status“, „wie verwende ich den generierten Server“ oder „Ich möchte dieses Tool von Claude aus aufrufen“.
