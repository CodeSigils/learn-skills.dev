ユーザーがブラウザーのワークフローを記録し、それを FastMCP サーバー、クロード コード スキル、またはその両方としてエクスポートする場合は、このスキルを使用します。 「ワークフローの記録」、「MCP としてエクスポート」、「スキルとしてエクスポート」、「FastMCP サーバーの生成」、「クロード コード スキルの生成」、「noui ワークフロー レコード」、「ワークフロー エクスポート」、「ワークフローのキャプチャ」、「ワークフローをツールに変換」、「Web サイトから MCP サーバーを作成」、または「このワークフローを自動化したい」でトリガーされます。認証済み (Tabby 経由のセッション Cookie)、静的 API キー、および認証されていないサブパスをカバーします。両方の出力形式をカバーします。
