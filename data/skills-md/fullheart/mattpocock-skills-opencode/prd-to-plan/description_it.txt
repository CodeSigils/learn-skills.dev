Trasforma un PRD in un piano di implementazione a più fasi utilizzando slice verticali tracer‑bullet, salvato come file Markdown locale in ./plans/. Usalo quando l'utente vuole suddividere un PRD, creare un piano di implementazione, pianificare le fasi da un PRD o menziona “tracer bullets”.

Per favore rispondi sempre nella lingua dell'utente.
