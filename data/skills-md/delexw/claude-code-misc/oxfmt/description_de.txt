Führen Sie oxfmt aus und konfigurieren Sie es – den leistungsstarken JavaScript/TypeScript-Formatierer, der auf dem Oxc-Compiler-Stack basiert und etwa 30-mal schneller als Prettier ist. Verwenden Sie diese Fertigkeit immer dann, wenn Sie an einem Projekt arbeiten, in dem oxfmt installiert ist (überprüfen Sie, ob „oxfmt“ in package.json devDependencies oder einer „.oxfmtrc.json“ / „.oxfmtrc.jsonc“-Konfigurationsdatei vorhanden ist). Dazu gehört, wenn Sie Code formatieren müssen, nachdem Sie Änderungen vorgenommen haben, oxfmt in einem neuen Projekt einrichten, von Prettier migrieren, Formatierungsregeln konfigurieren, Editor-Integration einrichten (VS Code, Neovim, Zed, JetBrains) oder Formatierungsprüfungen zu CI/CD-Pipelines hinzufügen müssen. Auch verwenden, wenn der Benutzer „oxfmt“, „oxc formatter“, „format with oxc“ erwähnt oder nach hübscheren Alternativen mit besserer Leistung fragt.
