Exécutez et configurez oxlint — le linter JavaScript/TypeScript hautes performances construit sur la pile du compilateur Oxc. Utilisez cette compétence chaque fois que vous travaillez dans un projet sur lequel oxlint est installé (vérifiez `oxlint` dans package.json devDependencies ou un fichier de configuration `.oxlintrc.json` / `oxlint.config.ts`). Cela inclut le cas où vous devez linter le code après avoir apporté des modifications, corriger les erreurs de linting, configurer les règles/plugins oxlint, configurer ou modifier « .oxlintrc.json » ou migrer depuis ESLint.
