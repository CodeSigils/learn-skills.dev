Ejecute y configure oxlint: el linter JavaScript/TypeScript de alto rendimiento creado en la pila del compilador Oxc. Utilice esta habilidad siempre que trabaje en un proyecto que tenga oxlint instalado (busque `oxlint` en package.json devDependencies o un archivo de configuración `.oxlintrc.json`/`oxlint.config.ts`). Esto incluye cuando necesita modificar el código después de realizar cambios, corregir errores de linting, configurar reglas/complementos de oxlint, configurar o modificar `.oxlintrc.json` o migrar desde ESLint.
