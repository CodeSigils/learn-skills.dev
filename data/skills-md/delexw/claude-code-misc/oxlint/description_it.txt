Esegui e configura oxlint: il linter JavaScript/TypeScript ad alte prestazioni costruito sullo stack del compilatore Oxc. Usa questa abilità ogni volta che lavori in un progetto su cui è installato oxlint (controlla "oxlint" in package.json devDependencies o un file di configurazione ".oxlintrc.json" / "oxlint.config.ts"). Ciò include quando è necessario eseguire l'linting del codice dopo aver apportato modifiche, correggere errori di lint, configurare regole/plug-in oxlint, impostare o modificare `.oxlintrc.json` o migrare da ESLint.
