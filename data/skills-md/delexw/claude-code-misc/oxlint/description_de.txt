Führen Sie Oxlint aus und konfigurieren Sie es – den leistungsstarken JavaScript/TypeScript-Linter, der auf dem Oxc-Compiler-Stack basiert. Verwenden Sie diese Fähigkeit immer dann, wenn Sie an einem Projekt arbeiten, in dem Oxlint installiert ist (überprüfen Sie, ob „oxlint“ in package.json devDependencies oder einer „.oxlintrc.json“ / „oxlint.config.ts“-Konfigurationsdatei vorhanden ist). Dazu gehört, wenn Sie Code linten müssen, nachdem Sie Änderungen vorgenommen haben, Linting-Fehler beheben, Oxlint-Regeln/Plugins konfigurieren, „.oxlintrc.json“ einrichten oder ändern oder von ESLint migrieren müssen.
