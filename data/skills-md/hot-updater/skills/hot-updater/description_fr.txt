Exploitez et diagnostiquez les projets qui utilisent une CLI Hot Updater installée localement. À utiliser pour la configuration, le déploiement, la politique de livraison, la restauration, la promotion, l'inspection des bundles ou des versions, les correctifs, le nettoyage du stockage, les canaux, les clés de signature, les opérations de base de données ou de catalogue, les versions d'applications, les empreintes digitales et la réparation par un médecin. Découvrez les commandes et les options de l'aide CLI en direct du projet sélectionné ; n'utilisez pas cette compétence pour développer Hot Updater lui-même.
