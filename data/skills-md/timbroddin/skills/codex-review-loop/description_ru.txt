Запросите проверку Codex для текущего PR, дождитесь её, автоматически исправьте найденные замечания и повторяйте процесс, пока проверка не станет чистой. Используется, когда пользователь хочет «запустить цикл проверки codex», «получить codex для проверки и исправления», «@codex review и исправить замечания», автоматически итеративно обрабатывать обратную связь по проверке PR от Codex/OpenAI или выполнить команду /codex-review-loop. Управляет ботом GitHub Codex (комментарий PR `@codex review`) раунд за раундом, пока не останется активных замечаний или не будет достигнут максимальный предел итераций.
