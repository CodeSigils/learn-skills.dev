Elija un problema que esté listo para un agente y trabaje en él de principio a fin. Lee el rastreador de problemas del proyecto para detectar problemas que lleven la etiqueta de clasificación AFK-ready (predeterminado "listo para el agente"), elige uno, verifica que esté realmente listo, luego lo implementa a través de /tdd o /diagnose y abre un PR. Úselo cuando el usuario quiera capturar un problema, trabajar en el siguiente ticket listo para el agente, iniciar el trabajo AFK o ejecutar /recoger. Este es el punto de entrada de "Trabajo" para el canal to-prd → to-issues → triage → pickup; se combina con mattpocock/skills.
