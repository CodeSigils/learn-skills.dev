Выберите задачу, готовую для агента, и проработайте ее от начала до конца. Считывает систему отслеживания проблем проекта на наличие проблем с меткой сортировки AFK-ready (по умолчанию «готов для агента»), выбирает одну, проверяет, действительно ли она готова, затем реализует ее через /tdd или /diagnose и открывает PR. Используйте, когда пользователь хочет получить информацию о проблеме, обработать следующую заявку, готовую для агента, начать работу AFK или запустить команду /pickup. Это точка входа «Работа» для конвейера to-prd → to-issues → сортировка → пикап; он сочетается с mattpocock/skills.
