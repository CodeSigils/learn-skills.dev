Проверяйте Localizable.xcstrings (и AppShortcuts.xcstrings) проекта Swift/SwiftUI на предмет отсутствующих переводов, вычисляйте охват каждого языка, находите необработанные литералы исходного языка, все еще жестко закодированные в коде пользовательского интерфейса, и массово переводите пробелы. Исходный язык читается из каталога — работает для любого исходного языка (en, nl, de, …).
