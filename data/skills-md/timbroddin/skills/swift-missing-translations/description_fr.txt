Auditez les fichiers Localizing.xcstrings (et AppShortcuts.xcstrings) d'un projet Swift/SwiftUI pour détecter les traductions manquantes, calculez la couverture par langue, recherchez les littéraux bruts de la langue source encore codés en dur dans le code de l'interface utilisateur et traduisez en masse les lacunes. La langue source est lue à partir du catalogue — fonctionne pour n'importe quelle langue source (en, nl, de, …).
