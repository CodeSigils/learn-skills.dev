Prenez une application Expo + Cloudflare Worker qui s'exécute sur la machine de l'utilisateur et mettez-la en production sur Cloudflare - provisionnement de D1, R2, KV, e-mail, paiements, secrets, domaines personnalisés ; déploiement une fois ; prouver le site en direct. À utiliser lorsque l'utilisateur souhaite déployer, expédier, publier, lancer ou mettre en ligne une application ; quand ils ont fini de construire et demandent comment le mettre en ligne ; ou lorsqu'une application déjà déployée a besoin d'une base de données, d'un domaine personnalisé, d'un domaine de messagerie ou d'une intégration correctement connectée. Couvre le contrôle en amont et la détection de la pile, l'approvisionnement de D1 et R2, les clés de production et les webhooks de Wiring Clerk, le service de messagerie Cloudflare et ses enregistrements DNS, les déclencheurs cron et les files d'attente, les webhooks et les clés Stripe, les domaines personnalisés et DNS, les secrets via Wrangler et une passe de clôture qui vérifie le site déployé plutôt que de croire le déploiement sur parole.
