Ejecute un proceso de identidad de marca estructurado y basado en críticas desde cualquier punto de partida (un sitio web de la empresa, un resumen escrito, una lista de productos o simplemente un nombre y concepto) hasta un kit de marca completo y un sistema de diseño: marca de logotipo, marca denominativa delineada, bloqueos, íconos redondos de seguridad, favicon con tema propio, rásteres PNG, una página de pautas generada, un archivo README y maquetas de productos de IA opcionales (camisas, gorras, tarjetas de presentación). Utilice esto siempre que el usuario desee un logotipo, una marca, una identidad visual, un cambio de marca, un logotipo, activos de marca, un favicon/conjunto de íconos, o diga cosas como "diseñar un logotipo para mi empresa", "necesitamos una marca", "haganos un kit de marca" o comparta el sitio de una empresa solicitando un trabajo de identidad. Incluso si solo te piden "un logotipo", utiliza esta habilidad: un logotipo que se envía sin sus variantes, pruebas de tamaño pequeño y pautas no se realiza.
