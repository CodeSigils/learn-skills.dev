يولد كود Angular ويوفر التوجيه المعماري. يتم التشغيل عند إنشاء مشاريع أو مكونات أو خدمات، أو للحصول على أفضل الممارسات المتعلقة بالتفاعل (الإشارات أو LinkedSignal أو الموارد) أو النماذج أو حقن التبعية أو التوجيه أو SSR أو إمكانية الوصول (ARIA) أو الرسوم المتحركة أو التصميم (أنماط المكونات أو Tailwind CSS) أو الاختبار أو أدوات واجهة سطر الأوامر (CLI).
