جمع البيانات المهملة لتكوين Claude Code الخاص بك. يقوم بشكل دوري بفحص ~/.claude (المهارات، والذاكرة، والخطافات، والأذونات، وخوادم MCP، وذاكرات التخزين المؤقت) بحثًا عن العناصر المتكررة أو التي لا معنى لها أو المعزولة أو ذات القيمة المنخفضة، ثم يرشد المستخدم خلال عملية تنظيف تأكيد كل عملية حذف. يُستخدم عندما يقول المستخدم "تنظيف التكوين الخاص بي"، أو "config GC"، أو "مهارات كثيرة جدًا"، أو "تدقيق الإعداد الخاص بي"، أو ".claude الخاص بي منتفخ"، أو يطلب مراجعة تكوين دورية.
