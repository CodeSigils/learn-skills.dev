tinystruct Java 프레임워크를 사용한 개발에 대한 전문가 지침입니다. 애플리케이션 클래스 생성, @Action 매핑 경로, 단위 테스트, ActionRegistry, HTTP/CLI 이중 모드 처리, 내장 HTTP 서버, 이벤트 시스템, 빌더/빌더가 있는 JSON, AbstractData를 사용한 데이터베이스 지속성, POJO 생성, SSE(서버 전송 이벤트), 파일 업로드 및 아웃바운드 HTTP 네트워킹을 포함하여tinystruct 코드베이스 또는tinystruct를 기반으로 구축된 모든 프로젝트에서 작업할 때 사용합니다.
