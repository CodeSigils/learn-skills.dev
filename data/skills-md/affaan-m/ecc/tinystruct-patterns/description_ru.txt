Экспертное руководство по разработке с использованием платформы Tinystruct Java. Используйте при работе с кодовой базой tinystruct или любым проектом, построенным на tinystruct, включая создание классов приложений, маршрутов, отображаемых @Action, модульных тестов, ActionRegistry, двухрежимную обработку HTTP/CLI, встроенный HTTP-сервер, систему событий, JSON с Builder/Builders, сохранение базы данных с помощью AbstractData, генерацию POJO, события, отправленные сервером (SSE), загрузку файлов и исходящую сеть HTTP.
