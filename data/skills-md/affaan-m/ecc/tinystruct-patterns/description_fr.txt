Conseils d'experts pour le développement avec le framework Java tinystruct. À utiliser lorsque vous travaillez sur la base de code tinystruct ou sur tout projet construit sur tinystruct — y compris la création de classes d'application, les routes mappées @Action, les tests unitaires, ActionRegistry, la gestion bimode HTTP/CLI, le serveur HTTP intégré, le système d'événements, JSON avec Builder/Builders, la persistance de la base de données avec AbstractData, la génération POJO, les événements envoyés par le serveur (SSE), les téléchargements de fichiers et la mise en réseau HTTP sortante.
