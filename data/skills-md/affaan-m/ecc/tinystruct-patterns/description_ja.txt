tinystruct Java フレームワークを使用した開発に関する専門家によるガイダンス。 tinystruct コードベース、または tinystruct 上に構築されたプロジェクトで作業する場合に使用します。これには、アプリケーション クラス、@Action マップされたルート、単体テスト、ActionRegistry、HTTP/CLI デュアルモード処理、組み込み HTTP サーバー、イベント システム、ビルダー/ビルダーによる JSON、AbstractData によるデータベース永続化、POJO 生成、サーバー送信イベント (SSE)、ファイル アップロード、およびアウトバウンド HTTP ネットワーキングの作成が含まれます。
