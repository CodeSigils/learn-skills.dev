Genera icone di app iOS come set di immagini PNG per cataloghi di risorse Xcode da SF Symbols (oltre 5000 nativi Apple) o API Iconify (oltre 275.000 icone open source da oltre 200 raccolte). Da utilizzare durante la generazione di icone, la creazione di risorse di icone, l'aggiunta di icone al catalogo delle risorse o la ricerca di icone per progetti iOS.
