Modelli di ottimizzazione delle prestazioni React e Next.js adattati dalle best practice React di Vercel Engineering (https://github.com/vercel-labs/agent-skills). Organizza oltre 70 regole in 8 categorie di priorità: cascate, dimensione del bundle, lato server, recupero del client, re-rendering, rendering, JS micro-perf, avanzato. Da utilizzare durante la scrittura, la revisione o il refactoring del codice React/Next.js per migliorare le prestazioni.
