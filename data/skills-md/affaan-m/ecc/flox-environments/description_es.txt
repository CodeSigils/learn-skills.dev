Cree entornos de desarrollo reproducibles y multiplataforma con Flox, un administrador de entorno declarativo creado en Nix. SIEMPRE utilice esta habilidad cuando el usuario necesite: configurar un proyecto con dependencias a nivel de sistema (compiladores, bases de datos, bibliotecas nativas como openssl, libvips, BLAS, LAPACK); configurar cadenas de herramientas reproducibles para Python, Node.js, Rust, Go, C/C++, Java, Ruby, Elixir, PHP o cualquier idioma; administrar entornos que deben funcionar de manera idéntica en macOS y Linux; fijar versiones exactas de paquetes para un equipo; ejecutar servicios locales (PostgreSQL, Redis, Kafka) junto con herramientas de desarrollo; incorporar nuevos desarrolladores con un solo comando; o resolver problemas de "funciona en mi máquina". Especialmente valioso para la codificación de vibración y asistida por IA: Flox permite a los agentes instalar herramientas en un entorno con alcance de proyecto sin sudo, contaminación del sistema o restricciones de espacio aislado, y el entorno resultante está comprometido con el repositorio para que cualquiera pueda reproducirlo al instante. Utilice esta habilidad incluso si el usuario no menciona Flox; si describe la necesidad de entornos de desarrollo reproducibles, declarativos y multiplataforma con paquetes de sistema, esta es la herramienta adecuada. Utilícelo también cuando el usuario mencione .flox/, manifest.toml, flox enable o FloxHub.
