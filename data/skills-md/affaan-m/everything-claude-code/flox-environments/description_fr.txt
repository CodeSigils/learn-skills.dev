Créez des environnements de développement reproductibles et multiplateformes avec Flox, un gestionnaire d'environnement déclaratif basé sur Nix. Utilisez TOUJOURS cette compétence lorsque l'utilisateur a besoin de : mettre en place un projet avec des dépendances au niveau du système (compilateurs, bases de données, bibliothèques natives comme openssl, libvips, BLAS, LAPACK) ; configurer des chaînes d'outils reproductibles pour Python, Node.js, Rust, Go, C/C++, Java, Ruby, Elixir, PHP ou tout autre langage ; gérer les environnements qui doivent fonctionner de manière identique sur macOS et Linux ; épingler les versions exactes des packages pour une équipe ; exécuter des services locaux (PostgreSQL, Redis, Kafka) parallèlement aux outils de développement ; embarquez de nouveaux développeurs avec une seule commande ; ou résoudre les problèmes « fonctionne sur ma machine ». Particulièrement utile pour le codage assisté par IA et par ambiance - Flox permet aux agents d'installer des outils dans un environnement limité à un projet sans sudo, pollution du système ou restrictions de bac à sable, et l'environnement résultant est engagé dans le dépôt afin que tout le monde puisse le reproduire instantanément. Utilisez cette compétence même si l'utilisateur ne mentionne pas Flox - s'il décrit avoir besoin d'environnements de développement reproductibles, déclaratifs et multiplateformes avec des packages système, c'est le bon outil. À utiliser également lorsque l'utilisateur mentionne .flox/, manifest.toml, flox activate ou FloxHub.
