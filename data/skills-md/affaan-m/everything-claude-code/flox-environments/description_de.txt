Erstellen Sie reproduzierbare, plattformübergreifende Entwicklungsumgebungen mit Flox – einem deklarativen Umgebungsmanager, der auf Nix basiert. Verwenden Sie diese Fähigkeit IMMER, wenn der Benutzer: ein Projekt mit Abhängigkeiten auf Systemebene einrichten muss (Compiler, Datenbanken, native Bibliotheken wie OpenSSL, Libvips, BLAS, LAPACK); Konfigurieren Sie reproduzierbare Toolchains für Python, Node.js, Rust, Go, C/C++, Java, Ruby, Elixir, PHP oder jede andere Sprache; Verwalten Sie Umgebungen, die unter macOS und Linux identisch funktionieren müssen. genaue Paketversionen für ein Team anheften; Führen Sie neben Entwicklungstools auch lokale Dienste (PostgreSQL, Redis, Kafka) aus. Integrieren Sie neue Entwickler mit einem einzigen Befehl. oder „Funktioniert auf meinem Computer“-Probleme lösen. Besonders wertvoll für KI-gestütztes und Vibe-Coding – Flox ermöglicht es Agenten, Tools in einer projektbezogenen Umgebung ohne Sudo, Systemverschmutzung oder Sandbox-Einschränkungen zu installieren, und die resultierende Umgebung wird dem Repo übergeben, sodass jeder sie sofort reproduzieren kann. Nutzen Sie diese Fähigkeit auch dann, wenn der Benutzer Flox nicht erwähnt – wenn er beschreibt, dass er reproduzierbare, deklarative, plattformübergreifende Entwicklungsumgebungen mit Systempaketen benötigt, ist dies das richtige Tool. Auch verwenden, wenn der Benutzer .flox/, manifest.toml, flox activate oder FloxHub erwähnt.
