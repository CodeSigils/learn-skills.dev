React- und Next.js-Leistungsoptimierungsmuster, angepasst an die React Best Practices von Vercel Engineering (https://github.com/vercel-labs/agent-skills). Organisiert über 70 Regeln in 8 Prioritätskategorien – Wasserfälle, Bundle-Größe, serverseitig, Client-Abruf, erneutes Rendern, Rendering, JS-Mikroperfektion, erweitert. Wird zum Schreiben, Überprüfen oder Refactoring von React/Next.js-Code für die Leistung verwendet.
