Modèles d'optimisation des performances React et Next.js adaptés des meilleures pratiques React de Vercel Engineering (https://github.com/vercel-labs/agent-skills). Organise plus de 70 règles dans 8 catégories prioritaires : cascades, taille du bundle, côté serveur, récupération client, re-rendu, rendu, micro-perf JS, avancé. À utiliser lors de l'écriture, de la révision ou de la refactorisation du code React/Next.js pour améliorer les performances.
