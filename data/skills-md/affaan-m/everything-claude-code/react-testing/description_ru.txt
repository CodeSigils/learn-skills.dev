Тестирование компонентов React с помощью библиотеки тестирования React, Vitest/Jest, MSW для макетирования сети, утверждений доступности с помощью Axe и границы принятия решений между тестами компонентов и сквозными прогонами Playwright/Cypress. Используйте при написании или исправлении тестов для компонентов, перехватчиков или страниц React.
