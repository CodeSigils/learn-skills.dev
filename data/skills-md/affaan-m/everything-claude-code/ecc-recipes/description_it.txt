Mappare un flusso di lavoro descritto al GRUPPO di comandi ECC corretto con ordine di esecuzione e condizione di arresto ed esplorare tutte le famiglie di ricette del gruppo di comandi. Aggiunge un livello di raggruppamento di famiglie + ordine di esecuzione + quando arrestare sopra il catalogo dei comandi flat. Solo consultivo. SI ATTIVA quando l'utente dice quali comandi per X, quale gruppo di comandi esegue X, mostra ricette ECC, elenca pipeline ECC o come posso eseguire un flusso di lavoro con ECC. NON SI ATTIVA quando l'utente desidera che l'attività venga eseguita direttamente, desidera un documento approfondito a comando singolo (utilizza ecc-guide) o desidera che una bozza di prompt venga riscritta (utilizza prompt-optimizer).
