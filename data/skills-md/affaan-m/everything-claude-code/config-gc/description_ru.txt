Сбор мусора для вашей конфигурации Claude Code. Периодически сканирует ~/.claude (навыки, память, перехватчики, разрешения, серверы MCP, кеши) на наличие избыточных, устаревших, потерянных или малоценных элементов, а затем проводит пользователя через очистку при подтверждении каждого удаления. Используйте, когда пользователь говорит «очистить мою конфигурацию», «конфигурировать GC», «слишком много навыков», «проверить мою настройку», «мой .claude раздут» или просит периодически проверять конфигурацию.
