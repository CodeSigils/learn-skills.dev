Garbage Collection per la configurazione del tuo codice Claude. Esegue periodicamente la scansione di ~/.claude (competenze, memoria, hook, permessi, server MCP, cache) per elementi ridondanti, obsoleti, orfani o di basso valore, quindi guida l'utente attraverso una pulizia di conferma di ogni eliminazione. Da utilizzare quando l'utente dice "ripulisci la mia configurazione", "config GC", "troppe competenze", "controlla la mia configurazione", "il mio file .claude è gonfio" o richiede una revisione periodica della configurazione.
