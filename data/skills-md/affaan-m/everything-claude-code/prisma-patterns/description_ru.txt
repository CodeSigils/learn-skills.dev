Шаблоны Prisma ORM для бэкэндов TypeScript — проектирование схемы, оптимизация запросов, транзакции, разбивка на страницы и критические ловушки, такие как updateMany, возвращающее количество не записей, тайм-ауты $transaction, миграция dev, сброс БД, @updatedAt, пропущенный при массовой записи, и исчерпание бессерверных соединений.
