Créez une solution complète d'âme de homard pour l'agent OpenClaw AI. Basé sur les préférences de l'utilisateur ou le gacha aléatoire, le positionnement de l'identité de sortie, la description de l'âme (SOUL.md), les règles de base personnifiées, le nom et l'invite de génération d'avatar. Si l'environnement actuel fournit une compétence de génération d'images approuvée, il peut créer automatiquement une image d'avatar de style unifié. À utiliser lorsque les utilisateurs doivent créer, concevoir ou personnaliser une âme de homard OpenClaw. Ne convient pas pour : affiner un SOUL.md existant, la conception de personnages pour les plates-formes non OpenClaw ou les agents purement basés sur des outils sans personnalité.
