Forgez un plan complet d'âme de homard pour l'agent OpenClaw AI. Selon les préférences de l'utilisateur ou les tirages aléatoires de gacha, le positionnement de l'identité de sortie, la description de l'âme (SOUL.md), les règles de base des personnages, le nom et les mots d'invite de l'avatar. Si l’environnement actuel fournit une compétence d’image brute approuvée, une image d’avatar de style unifié peut être automatiquement générée. À utiliser lorsque l'utilisateur a besoin de créer, concevoir ou personnaliser une âme de homard OpenClaw. Ne s'applique pas à : la mise au point de SOUL.md existant, la conception de personnages pour les plates-formes non OpenClaw, les agents purement de type outil sans personnalité.
