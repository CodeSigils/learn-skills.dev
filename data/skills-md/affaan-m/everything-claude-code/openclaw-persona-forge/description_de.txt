Schmieden Sie eine komplette Lobster Soul-Lösung für den OpenClaw AI Agent. Basierend auf Benutzerpräferenzen oder zufälligem Gacha werden Identitätspositionierung, Seelenbeschreibung (SOUL.md), personifizierte Grundregeln, Name und Aufforderung zur Avatar-Generierung ausgegeben. Wenn die aktuelle Umgebung über eine zugelassene Fähigkeit zur Bildgenerierung verfügt, kann automatisch ein Avatarbild im einheitlichen Stil erstellt werden. Verwenden Sie es, wenn Benutzer eine OpenClaw-Hummerseele erstellen, entwerfen oder anpassen müssen. Nicht geeignet für: Feinabstimmung eines vorhandenen SOUL.md, Charakterdesign für Nicht-OpenClaw-Plattformen oder rein werkzeugbasierte Agenten ohne Persönlichkeit. Auslösewörter: 龙虾灵魂, 虾魂, OpenClaw 灵魂, 养虾灵魂, 龙虾角色, 龙虾定位, 龙虾剧本杀角色,龙虾游戏角色, 龙虾 NPC, 龙虾性格, 龙虾背景故事, Hummerseele, Hummercharakter, 抽卡, 随机龙虾, 龙虾 SOUL, Gacha.
