Операции, автоматизация и управление репозиторием GitHub. Сортировка проблем, управление связями с общественностью, операции CI/CD, управление выпусками и мониторинг безопасности с помощью gh CLI. Используйте, когда пользователь хочет управлять проблемами GitHub, PR, статусом CI, выпусками, участниками, устаревшими элементами или любой операционной задачей GitHub, помимо простых команд git.
