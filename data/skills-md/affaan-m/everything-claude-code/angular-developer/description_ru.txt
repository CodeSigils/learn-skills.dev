Генерирует код Angular и предоставляет рекомендации по архитектуре. Запускайте при создании проектов, компонентов или сервисов, а также для получения рекомендаций по реагированию (сигналы, linkedSignal, ресурс), формам, внедрению зависимостей, маршрутизации, SSR, доступности (ARIA), анимации, стилизации (стили компонентов, Tailwind CSS), тестированию или инструментам CLI.
