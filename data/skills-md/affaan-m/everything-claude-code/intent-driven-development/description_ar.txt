قم بتحويل تغييرات المنتج والهندسة الغامضة أو عالية التأثير إلى معايير قبول محددة النطاق وقابلة للتحقق قبل التنفيذ أو بجانبه. يُستخدم عندما يطلب المستخدم توضيح ميزة ما، أو تحديد معايير القبول، أو إزالة المخاطر المتعلقة بتغيير الأمان/البيانات/الترحيل/التكامل، أو إعداد متطلبات التنفيذ لوكيل آخر، أو تقديم طلب معقد قابل للاختبار. لا تقم بإجراء تعديلات تافهة، أو إصلاحات مباشرة، أو تصحيح أخطاء نشط، أو مراجعة التعليمات البرمجية، أو طلبات التنفيذ التي تكون شروط قبولها واضحة بالفعل ما لم يستدعي المستخدم هذه المهارة صراحةً.
