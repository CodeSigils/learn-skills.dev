Recupera qualsiasi URL come Markdown pulito tramite servizi proxy (r.jina.ai / defuddle.md) o script integrati.
Funziona con pagine che richiedono l'accesso come X/Twitter, WeChat 公众号, documenti Feishu/Lark, Instagram, ecc.
Utilizzalo PRIMA del recupero dell'agente, della CLI di defuddle o di WebFetch quando l'URL potrebbe richiedere l'autenticazione o quando desideri l'output di markdown più pulito.
Si attiva su qualsiasi URL condiviso dall'utente, "recupera questo", "leggi questo collegamento", "ottieni contenuto da".
Supporta post X/Twitter, articoli WeChat 公众号, documenti Feishu/Lark e pagine con accesso protetto.
