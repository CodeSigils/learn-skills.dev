Rufen Sie jede URL als sauberen Markdown über Proxy-Dienste (r.jina.ai / defuddle.md) oder integrierte Skripte ab.
Funktioniert mit Seiten, für die eine Anmeldung erforderlich ist, wie X/Twitter, WeChat 公众号, Feishu/Lark-Dokumente, Instagram usw.
Verwenden Sie dies VOR dem Agentenabruf, der Defuddle-CLI oder WebFetch, wenn die URL möglicherweise eine Authentifizierung erfordert oder wenn Sie die sauberste Markdown-Ausgabe wünschen.
Löst auf jeder URL aus, die der Benutzer teilt: „dieses abrufen“, „diesen Link lesen“, „Inhalt abrufen von“.
Unterstützt X/Twitter-Beiträge, WeChat 公众号-Artikel, Feishu/Lark-Dokumente und Login-Walled-Seiten.
