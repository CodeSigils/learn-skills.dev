Obtenga cualquier URL como Markdown limpio a través de servicios proxy (r.jina.ai / defuddle.md) o scripts integrados.
Funciona con páginas que requieren inicio de sesión como X/Twitter, WeChat 公众号, Feishu/Lark docs, Instagram, etc.
Utilice esto ANTES de buscar el agente, desactivar la CLI o WebFetch cuando la URL pueda necesitar autenticación o cuando desee obtener el resultado de rebajas más limpio.
Se activa en cualquier URL que el usuario comparta, "buscar esto", "leer este enlace", "obtener contenido".
Admite publicaciones de X/Twitter, artículos de WeChat 公众号, documentos de Feishu/Lark y páginas de inicio de sesión.
