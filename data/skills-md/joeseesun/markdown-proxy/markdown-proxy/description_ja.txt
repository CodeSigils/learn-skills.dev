プロキシ サービス (r.jina.ai / defuddle.md) または組み込みスクリプトを介して、任意の URL をクリーンなマークダウンとして取得します。
X/Twitter、WeChat 公众号、Feishu/Lark ドキュメント、Instagram などのログインが必要なページで動作します。
URL に認証が必要な場合、または最もクリーンなマークダウン出力が必要な場合は、エージェントフェッチ、デファドル CLI、または WebFetch の前にこれを使用します。
ユーザーが共有する任意の URL でトリガーされ、「これを取得」、「このリンクを読む」、「コンテンツを取得」します。
X/Twitter の投稿、WeChat 公众号の記事、Feishu/Lark ドキュメント、およびログイン ウォール ページをサポートします。
