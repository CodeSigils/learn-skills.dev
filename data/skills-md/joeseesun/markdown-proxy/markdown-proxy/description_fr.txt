Récupérez n'importe quelle URL sous forme de Markdown propre via des services proxy (r.jina.ai / defuddle.md) ou des scripts intégrés.
Fonctionne avec les pages nécessitant une connexion comme X/Twitter, WeChat 公众号, Feishu/Lark docs, Instagram, etc.
Utilisez ceci AVANT la récupération d'agent, la CLI defuddle ou WebFetch lorsque l'URL peut nécessiter une authentification ou lorsque vous souhaitez la sortie de démarque la plus propre.
Se déclenche sur n'importe quelle URL partagée par l'utilisateur, "récupérer ceci", "lire ce lien", "obtenir du contenu à partir de".
Prend en charge les publications X/Twitter, les articles WeChat 公众号, les documents Feishu/Lark et les pages protégées par un mur de connexion.
