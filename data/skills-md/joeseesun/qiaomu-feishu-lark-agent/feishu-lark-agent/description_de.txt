Feishu/Lark All-Purpose Operation Agent (Nachrichten/Dokumente/mehrdimensionale Tabellen/Kalender/Aufgaben/Benutzer).

⚠️ Regeln für die Fähigkeitsauswahl:
- Senden Sie eine Nur-Text-Nachricht → diesen Skill (Nachricht senden)
- Senden Sie Rich Text/Karte → Feishu-Post / Feishu-Karte
- Anwesenheit überprüfen → Feishu-Anwesenheit
- Alle anderen Feishu-Operationen → diese Fertigkeit

Auslösewörter (jede Übereinstimmung wird aufgerufen):
Feishu senden, Nachricht senden an, Gruppennachrichten überprüfen, Feishu antworten, Feishu-Nachrichten durchsuchen, Gruppenchats auflisten,
Feishu-Dokument erstellen, Feishu-Dokument lesen, mehrdimensionale Tabelle prüfen, bitbaren Datensatz hinzufügen, Tabelle aktualisieren,
Feishu-Kalender, Zeitplan prüfen, Zeitplan hinzufügen, Feishu-Aufgabe, Aufgabe erstellen, Aufgabe abschließen,
Überprüfen Sie den Feishu-Benutzer, finden Sie den Kontakt und erhalten Sie open_id

Bitte antworten Sie immer in der Sprache des Benutzers.
