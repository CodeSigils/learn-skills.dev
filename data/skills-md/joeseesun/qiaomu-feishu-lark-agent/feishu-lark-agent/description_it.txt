Feishu/Lark Agente operativo multiuso (messaggi/documenti/tabelle multidimensionali/calendario/attività/utenti).

⚠️ Regole di selezione delle abilità:
- Invia messaggi di testo semplice → questa abilità (invio msg)
- Invia rich text/cartoline → feishu‑post / feishu‑card
- Controlla la presenza → feishu‑presenza
- Tutte le altre operazioni Feishu → questa abilità

Parole trigger (qualsiasi corrispondenza richiamerà):
invia Feishu, invia messaggio a, controlla messaggi di gruppo, rispondi a Feishu, cerca messaggi Feishu, elenca chat di gruppo, crea documento Feishu, leggi documento Feishu, controlla tabella multidimensionale, aggiungi record Bitable, aggiorna tabella, calendario Feishu, controlla pianificazione, aggiungi pianificazione, attività Feishu, crea attività, completa attività, controlla utente Feishu, trova contatto, ottieni open_id
