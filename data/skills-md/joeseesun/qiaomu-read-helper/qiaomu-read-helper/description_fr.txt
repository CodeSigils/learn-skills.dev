Assistant de co-lecture Qiaomu : organise les livres électroniques locaux ou les livres téléchargés par chapitre dans les documents Feishu, aide les utilisateurs à mettre en gras, souligner et commenter après la lecture, puis lit les commentaires Feishu et les marques surlignées pour fournir de courtes réponses de révision, et rédige une note de lecture de style Qiaomu basée sur les notes de l'utilisateur. Les phrases déclencheurs incluent : « lire un livre avec moi », « colire », « assistant de lecture », « envoyer ce chapitre à Feishu », « lire mes annotations », « répondre aux commentaires de Feishu », « écrire une note de lecture basée sur les caractères gras et les commentaires », « chapitre suivant ».
