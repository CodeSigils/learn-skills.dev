Utilisation pour le référencement technique, l'exploration, le rendu et l'indexation, le référencement JavaScript, les robots.txt, les plans de site, les canoniques, les redirections, les codes d'état, les métadonnées, les liens internes, les données structurées, les Core Web Vitals, la recherche de mots clés et d'intentions, la qualité ou l'élagage du contenu, la conception d'expériences de référencement, les baisses de trafic, les migrations, le référencement international et le hreflang, le référencement de commerce électronique et de produits, la recherche d'images ou de vidéos, le référencement de grands sites et programmatiques, IndexNow, l'analyse de la console de recherche ou des outils pour les webmasters et les aperçus de l'IA, Mode IA, recherche ChatGPT, visibilité Copilot ou Perplexité. À utiliser avec les URL, le code de site Web, les pages rendues, les journaux du serveur, les fichiers d'analyse, les exportations propriétaires et les ensembles de données de mots clés.
