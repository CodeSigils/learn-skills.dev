Используйте при создании нового адаптера OpenCLI с нуля, добавлении поддержки нового веб-сайта или платформы, изучении конечных точек API сайта с помощью DevTools браузера или когда пользователь запрашивает автоматическое создание CLI для веб-сайта (например, «帮我生成 xxx.com 的 cli»). Охватывает автоматическое создание, рабочий процесс обнаружения API, выбор стратегии аутентификации, написание адаптера TS и тестирование.
