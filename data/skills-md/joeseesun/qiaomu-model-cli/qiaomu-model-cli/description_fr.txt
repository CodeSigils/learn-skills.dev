Appelez Grok CLI local, Kimi Code CLI et Claude Code CLI avec le plus puissant
modèles par défaut actuels et outils natifs. Utilisez ce flux de travail de compétences Qiaomu lorsque
l'utilisateur veut exécuter Grok
4.5 pour la recherche X/Web, la génération d'images/vidéos, la recherche ou l'agent multi-outils
travail; exécutez Kimi K3 (1M) pour le travail frontend UI/CSS/React/Vue ; lancez Claude Fable 5,
Opus 4.8, ou Sonnet 5 pour le codage/révision/refactorisation ; exécuter un multimodèle indépendant
comparaisons simultanément avec la progression du flux natif, la vérification des artefacts,
journaux privés, annulation et nouvelle tentative de travail ayant échoué ; choisir entre les trois
CLI ; ou encapsuler les invocations CLI non interactives. Déclencheur sur des phrases
comme "用 grok cli", "用 kimi cli", "grok 搜 X", "kimi 写前端",
"qiaomu-model-cli", "调用 grok4.5", "调用 k3 1m", "用 claude code",
"用 fable 5", "opus 4.8 改代码", "分别调用三个模型", "多模型横评".

gestion du registre (utilisez qiaomu-llm) ou adaptateurs de site OpenCLI.
