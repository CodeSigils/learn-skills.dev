Chiama Grok CLI locale, Kimi Code CLI e Claude Code CLI con il più potente
attuali modelli predefiniti e strumenti nativi. Utilizza questo flusso di lavoro delle competenze qiaomu quando
l'utente vuole eseguire Grok
4.5 per ricerca X/web, generazione di immagini/video, ricerca o agente multi-strumento
lavoro; eseguire Kimi K3 (1M) per il lavoro frontend UI/CSS/React/Vue; esegui Claude Fable 5,
Opus 4.8, o Sonetto 5 per codifica/revisione/refactoring; eseguire multi-modello indipendente
confronti simultanei con l'avanzamento del flusso nativo, verifica degli artefatti,
registri privati, annullamento e nuovi tentativi di lavoro non riuscito; scegli tra i tre
CLI; o eseguire il wrap delle chiamate CLI non interattive. Trigger sulle frasi
come "用 grok cli", "用 kimi cli", "grok 搜 X", "kimi 写前端",
"qiaomu-model-cli", "调用 grok4.5", "调用 k3 1m", "用 claude code",
"用 fable 5", "opus 4.8 改代码", "分别调用三个模型", "多模型横评".
Non per API cloud generiche
gestione del registro (utilizzare qiaomu-llm) o adattatori del sito OpenCLI.
