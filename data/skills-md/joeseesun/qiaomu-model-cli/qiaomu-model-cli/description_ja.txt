ローカルの Grok CLI、Kimi Code CLI、および Claude Code CLI を最も強力な方法で呼び出します。
現在のデフォルト モデルとネイティブ ツール。この qiaomu スキル ワークフローは次の場合に使用します。
ユーザーは Grok を実行したいと考えています
X/Web 検索、画像/ビデオ生成、リサーチ、またはマルチツール エージェントの場合は 4.5
仕事。フロントエンド UI/CSS/React/Vue の作業には Kim K3 (1M) を実行します。クロード・フェイブル5を実行し、
コーディング/レビュー/リファクタリングには Opus 4.8、または Sonnet 5。独立したマルチモデルを実行する
ネイティブ ストリームの進行状況との比較、アーティファクトの検証、
プライベート ログ、キャンセル、失敗したジョブの再試行。 3 つの中から選択します
CLI。または、非対話型 CLI 呼び出しをラップします。フレーズでトリガー
例: "用 grok cli"、"用 kimi cli"、"grok 搜 X"、"kimi 写前端"、
"qiaomu-model-cli"、"调用 grok4.5"、"调用 k3 1m"、"クロード コード"、
「用寓話5」、「作品4.8改版」、「分别调用三个模型」、「多模型横评」。
汎用クラウド API には対応していません
レジストリ管理 (qiaomu-llm を使用) または OpenCLI サイト アダプター。
