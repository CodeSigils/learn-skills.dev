Вызовите локальный CLI Grok, Kimi Code CLI и Claude Code CLI с самым сильным
текущие модели по умолчанию и собственные инструменты. Используйте этот рабочий процесс с навыками qiaomu, когда
пользователь хочет запустить Grok
4.5 для X/веб-поиска, создания изображений/видео, исследований или многофункционального агента
работа; запустите Kimi K3 (1M) для работы с интерфейсом UI/CSS/React/Vue; запустить Клод Фабл 5,
Opus 4.8 или Sonnet 5 для кодирования/ревью/рефакторинга; запустить независимую мультимодель
сравнение одновременно с прогрессом собственного потока, проверка артефактов,
частные журналы, отмена и повтор неудачного задания; выбирать между тремя
интерфейсы командной строки; или оберните неинтерактивные вызовы CLI. Триггер по фразам
например «用 grok cli», «用 kimi cli», «grok 搜 X», «kimi 写前端»,
"qiaomu-model-cli", "调用 grok4.5", "调用 k3 1m", "用 код Клода",
«用 басня 5», «опус 4.8 改代码», «分别调用三个模型», «多模型横评».
Не для общего облачного API.
управление реестром (используйте qiaomu-llm) или адаптеры сайта OpenCLI.
