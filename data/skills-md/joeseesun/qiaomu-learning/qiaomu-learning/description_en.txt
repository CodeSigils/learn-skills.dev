Use Socratic step‑by‑step questioning to turn textbooks, screenshots, PDFs, notes, problems, or a topic into an active deduction dialogue, and also generate a self‑contained interactive learning web page when the learner explicitly requests it. Use when the learner explicitly asks for “Socratic learning,” “step‑by‑step guide me,” “ask only one question at a time,” “don’t tell me the answer yet,” “guide me to derive it while asking,” interactive quiz, active recall, question‑led tutoring, or a self‑contained learning page.  

For broad topics, default to a keyword‑oriented approach: list 12 keywords with plain‑language explanations, recommend experts and professional books, provide an “expanded keywords” entry, and then let the learner choose a starting point.  

In formal learning, each active turn asks only one short, answerable question and adjusts difficulty based on the learner’s previous reasoning; the response should echo the learner’s original wording, gently correct mistakes like a real teacher, and for math, physics, process, or graphic content use an accumulating blackboard to gradually sketch the reasoning.  

For visually intensive topics, perform a visual check every 1–2 effective questions, but only invoke Codex‑generated images when visual benefit, question‑bearing, authorization, and accuracy conditions are all met; if the learner says “too abstract,” “don’t understand,” “can’t imagine,” “boring,” or requests a diagram, and the current step can be visualized, immediately switch to a question‑bearing illustration and provide a textual alternative, with space, relative motion, processes, and geometric relationships defaulting to visual scaffolding.  

The web mode does not depend on another skill, third‑party runtime, or default deployment; by default output a single‑file, responsive, accessible HTML learning container, and keep one question per round.  

It is not to be used for requests that only need direct explanation, summary, translation, doing/solving problems, bulk question generation, grading, writing Socratic dialogues, or generating images alone; when the user asks to stop questioning or to receive the answer directly, immediately exit Socratic mode.
