Utilice preguntas socráticas paso a paso para convertir libros de texto, capturas de pantalla, archivos PDF, notas, problemas o un tema en un diálogo de deducción activo, y también genere una página web de aprendizaje interactiva e independiente cuando el alumno lo solicite explícitamente. Úselo cuando el alumno solicite explícitamente "aprendizaje socrático", "guíeme paso a paso", "haga solo una pregunta a la vez", "no me diga la respuesta todavía", "guíeme para deducirla mientras pregunta", cuestionario interactivo, recuerdo activo, tutoría basada en preguntas o una página de aprendizaje independiente.  

Para temas amplios, utilice de forma predeterminada un enfoque orientado a palabras clave: enumere 12 palabras clave con explicaciones en lenguaje sencillo, recomiende libros de expertos y profesionales, proporcione una entrada de "palabras clave ampliadas" y luego deje que el alumno elija un punto de partida.  

En el aprendizaje formal, cada turno activo plantea solo una pregunta breve que se puede responder y ajusta la dificultad en función del razonamiento previo del alumno; la respuesta debe hacer eco de la redacción original del alumno, corregir suavemente los errores como un verdadero maestro y, para matemáticas, física, procesos o contenido gráfico, utilizar una pizarra de acumulación para esbozar gradualmente el razonamiento.  

Para temas visualmente intensivos, realizar una verificación visual cada 1 o 2 preguntas efectivas, pero solo invocar imágenes generadas por el Codex cuando se cumplan todas las condiciones de beneficio visual, formulación de preguntas, autorización y precisión; Si el alumno dice “demasiado abstracto”, “no entiendo”, “no puedo imaginar”, “aburrido” o solicita un diagrama y el paso actual puede visualizarse, cambie inmediatamente a una ilustración que contenga preguntas y proporcione una alternativa textual, con el espacio, el movimiento relativo, los procesos y las relaciones geométricas por defecto en el andamiaje visual.  

El modo web no depende de otra habilidad, tiempo de ejecución de terceros o implementación predeterminada; de forma predeterminada, genera un contenedor de aprendizaje HTML accesible, responsivo y de un solo archivo, y guarda una pregunta por ronda.  

No debe usarse para solicitudes que solo necesitan una explicación directa, un resumen, una traducción, hacer/resolver problemas, generar preguntas en masa, calificar, escribir diálogos socráticos o generar imágenes solas; cuando el usuario solicite dejar de hacer preguntas o recibir la respuesta directamente, salga inmediatamente del modo socrático.
