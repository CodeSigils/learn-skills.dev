Utilice el aprendizaje socrático mediante preguntas paso a paso para convertir libros de texto, capturas de pantalla, archivos PDF, notas, problemas o un tema en un diálogo deductivo activo y también generar una página web de aprendizaje interactiva independiente cuando el alumno lo solicite explícitamente. Úselo cuando el alumno solicite explícitamente "aprendizaje socrático", "enseñeme paso a paso", "haga solo una pregunta a la vez", "no me diga la respuesta todavía", "guíeme para deducirla mientras hace preguntas", cuestionario interactivo, recuerdo activo, tutoría basada en preguntas o una página de aprendizaje independiente. Para temas amplios, utilice de forma predeterminada la orientación de palabras clave: enumere 12 palabras clave con explicaciones en lenguaje sencillo, recomiende libros de expertos y profesionales, proporcione una entrada de "palabras clave ampliadas" y luego deje que el alumno elija un punto de partida. En el aprendizaje formal, cada ronda activa plantea solo una pregunta breve que se puede responder y ajusta la dificultad en función del razonamiento previo del alumno; las respuestas deben hacer eco de las palabras del alumno, corregirlas suavemente como un verdadero maestro y, para el contenido matemático, físico, de procedimiento o gráfico, utilizar una pizarra acumulativa para dibujar gradualmente el razonamiento. Para temas visualmente intensivos, realice una verificación visual cada 1 o 2 preguntas efectivas, pero solo invoque imágenes generadas por el Codex cuando se cumplan todas las condiciones de beneficio visual, carga de preguntas, autorización y precisión; Si el alumno dice "demasiado abstracto", "no entiendo", "no puedo imaginar", "aburrido" o solicita un diagrama, y ​​el paso actual puede visualizarse, cambie inmediatamente a una ilustración basada en preguntas y proporcione alternativas textuales, con relaciones espaciales, de movimiento relativo, de proceso y geométricas de forma predeterminada en un andamiaje visual. El modo web no depende de otra habilidad, tiempo de ejecución de terceros o implementación predeterminada; de forma predeterminada, genera un contenedor de aprendizaje HTML accesible, responsivo y de un solo archivo y mantiene una pregunta por ronda. No se utiliza para solicitudes que solo necesitan explicación directa, resumen, traducción, resolución/resolución de problemas, generación de preguntas en masa, calificación, escritura de diálogos socráticos o generación de imágenes solas; cuando el usuario solicite dejar de hacer preguntas o recibir la respuesta directamente, salga inmediatamente del modo socrático.
