с окончательным выводом отчета Markdown + HTML + PDF. Используйте для сложных вопросов, технических решений,
социальные темы, архитектурный выбор, тщательный анализ или любой вопрос, над которым стоит подумать.
Триггеры включают 深度分析, 多角度推理, 验证答案, тяжелый навык, думать усерднее, 让我们深入思考,
推敲一下, 讨论一下, 分析利弊. Не используйте для простого поиска фактов или рутинных задач.
