Utilizza la competenza qiaomu-bento-ppt autonoma per creare o modificare presentazioni bento in stile qiaomu come file .bento.html autonomi da brief, note, report, URL, dati o mazzi bento esistenti. Utilizza questa abilità quando l'utente richiede esplicitamente bento/slides, una presentazione .bento.html, una presentazione HTML a file singolo modificabile offline o invoca qiaomu-bento-ppt. Applica un flusso di lavoro di presentazione della proposta, invia una shell bento ufficiale bloccata e riferimenti di creazione all'interno della competenza, costruisce attraverso il contratto #bento-doc in testo normale senza richiedere il repository bento originale e convalida la struttura, l'identità, l'integrità della shell, l'euristica visiva e i limiti di rollback. Non utilizzare per la distribuzione convenzionale di file .pptx, per lo sviluppo di sorgenti bento generici o per il lavoro con bento/spaces e bento/dash.
