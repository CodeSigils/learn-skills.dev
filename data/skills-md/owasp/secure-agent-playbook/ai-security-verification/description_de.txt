Umfassende KI-Sicherheitsüberprüfung mithilfe des OWASP AI Security Verification Standard (AISVS)-Frameworks. Bietet eine strukturierte Checkliste zur Überprüfung von Sicherheits- und ethischen Überlegungen in 13 Kategorien von KI-gesteuerten Anwendungen, von der Schulungsdatenverwaltung bis zur menschlichen Aufsicht.
