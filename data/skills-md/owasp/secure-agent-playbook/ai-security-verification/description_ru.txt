Комплексная проверка безопасности ИИ с использованием платформы OWASP AI Security Verification Standard (AISVS). Предоставляет структурированный контрольный список для проверки безопасности и этических соображений в 13 категориях приложений на базе ИИ, от управления обучающими данными до человеческого контроля.
