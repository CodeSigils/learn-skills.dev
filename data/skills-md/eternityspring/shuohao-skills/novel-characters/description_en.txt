Extract a character list, character portraits, visual prompt terms, and voice timbre prompt terms from a novel or short story, and generate a character design illustration for each character (left half‑body portrait + right full‑body three‑view + detail bar), outputting JSON + Markdown + an interactive report.html. The report language can be specified (--lang), default is Chinese, and any language is supported; the illustration style can be specified (--style), default is semi‑realistic, with a Studio Ghibli animation style also available. Zero dependencies, zero API key, using the current session quota; image generation uses the built‑in $imagegen in codex (optional). Use when asked to extract novel characters, analyze characters, generate character cards, character sheets from a novel.
