Извлеките список персонажей, портреты персонажей, термины визуальных подсказок и термины подсказок тембра голоса из романа или рассказа и создайте иллюстрацию дизайна персонажа для каждого персонажа (левый портрет половины тела + правый полный вид в полный рост + панель подробностей), выводя JSON+Markdown+интерактивный отчет.html. Можно указать язык отчета (--lang), по умолчанию — китайский, поддерживается любой язык; можно указать стиль иллюстрации (--style), по умолчанию — полуреалистичный, также доступен стиль анимации Studio Ghibli. Нулевые зависимости, нулевой ключ API, использование текущей квоты сеанса; для генерации изображений используется встроенный $imagegen в кодексе (необязательно). Используйте, когда вас просят извлечь персонажей романа, проанализировать персонажей, создать карточки персонажей, листы персонажей из романа.
