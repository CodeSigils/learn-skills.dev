Extraiga una lista de personajes, retratos de personajes, términos de indicaciones visuales y términos de indicaciones de timbre de voz de una novela o cuento, y genere una ilustración de diseño de personaje para cada personaje (retrato de medio cuerpo izquierdo + vista triple de cuerpo completo derecho + barra de detalles), generando JSON+Markdown+un informe interactivo.html. Se puede especificar el idioma del informe (--lang), el idioma predeterminado es el chino y se admite cualquier idioma; se puede especificar el estilo de ilustración (--style), el valor predeterminado es semirealista y también está disponible un estilo de animación de Studio Ghibli. Cero dependencias, cero clave API, utilizando la cuota de sesión actual; La generación de imágenes utiliza el $imagegen integrado en el códice (opcional). Úselo cuando se le solicite extraer personajes novedosos, analizar personajes, generar tarjetas de personajes, hojas de personajes de una novela.
