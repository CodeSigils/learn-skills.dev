Создавайте раскадровки для коротких драм с искусственным интеллектом: трехуровневая структура — Сегмент (генерация одного видео, ≤15 секунд) → Кадр (2–5-секундный фрагмент внутри сегмента, требующий такта сценария) → Кадровое изображение (один ключевой кадр на кадр: точка основной раскадровки с интервалом 0,00 секунды, метки подкадровой раскадровки в соответствующих точках обрезки).

Каждый сегмент включает в себя собственную видеоподсказку MiniMax H3 (официально по умолчанию используется английский язык, разрывы строк для каждого кадра; PromptLang можно переключить на китайский): команды выравнивания и временные метки обрезки [Shotk] извлекаются из структуры раскадровки и проверяются слово за словом; диалог вставляется слово за словом в блоки <d> (соглашения о написании встроены в references/h3-prompt.md и не зависят от внешних навыков).

Выходные данные: Storyboard.json+Markdown+ одностраничный отчет о проверке (дорожка ритма раскадровки/таблица раскадровки эпизодов/список пакетов генерации/лист выравнивания закадрового голоса, включая экспортированный JSON). Кадровые изображения могут быть созданы с использованием изображений дизайна сцен и персонажей в качестве ссылки с помощью codex$imagegen (необязательно).

Все 16 элементов качества детерминированно проверяются сценарием; «Экспорт» обеспечивает экспорт производственного пакета H3 одним щелчком мыши (подсказка каждого сегмента + список снятых изображений, упорядоченных по изображению). Нулевые зависимости, нулевой ключ API, использование текущей квоты сеанса.
