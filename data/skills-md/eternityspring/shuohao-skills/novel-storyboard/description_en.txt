Create storyboards for AI short dramas: a three-tier structure — Segment (a single video generation, ≤15 seconds) → Shot (a 2–5 second cut within the segment, claiming the script beat) → Shot image (one key frame per cut: main storyboard pin at 0.00 seconds, sub‑storyboard pins at their respective cut points).

Each segment includes its own MiniMax H3 video prompt (officially defaulting to English, line breaks per shot; promptLang can be switched to Chinese): alignment commands and the [Shot k] cut timestamps are derived from the storyboard structure and verified word by word; dialogue is inserted word by word into <d> blocks (the writing conventions are internalized in references/h3-prompt.md and do not rely on external skills).

Outputs: storyboard.json + Markdown + a single-page review report (storyboard rhythm track / episode storyboard table / generation batch list / voice‑over alignment sheet, including exported JSON). Shot images can be generated using scene and character design images as reference via codex $imagegen (optional).

All 16 quality gates are deterministically checked by the script; “export” provides one‑click export of the H3 production package (each segment’s prompt + a list of shot images ordered by Picture). Zero dependencies, zero API key, using the current session quota.
