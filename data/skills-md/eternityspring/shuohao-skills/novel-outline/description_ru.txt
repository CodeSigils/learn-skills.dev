Адаптируйте роман в комплект из пяти частей короткой драмы: примечания к адаптации, список персонажей, список очков волнения, краткое изложение эпизодов, инвентаризация активов; вывод Outline.json + Markdown + отчет об обзоре на одну страницу (диапазон ключевых показателей эффективности, ключевые решения, временная шкала точек волнения, матрица планирования, обзор сцены, контрольные показатели качества). Все 13 показателей качества полностью определяются проверкой сценария (ограничение уровня персонажа, динамическое ограничение основной сцены с учетом количества эпизодов, интервал точки возбуждения≤3 эпизодов, обязательная интрига для каждого эпизода и т. д.), не полагаясь на самосознание модели; поддерживает режим проверки работоспособности: вставьте существующую схему, запустите контроль качества только для диагностики. Нулевые зависимости, нулевой ключ API, использование текущей квоты сеанса. Используйте, когда вас просят указать план адаптации, краткий план драмы, разбивку наброска, драму от романа к короткометражке, план адаптации.
