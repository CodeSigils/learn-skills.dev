Adapter un roman en un court kit dramatique de cinq pièces : description de l'adaptation, liste des personnages, liste des points forts, synopsis de l'épisode, inventaire des atouts ; produire outline.json + Markdown + un rapport d'examen d'une seule page (bande de KPI, décisions clés, chronologie des faits saillants, matrice de planification, aperçu de la scène, portes de qualité). Les 13 portes de qualité sont vérifiées de manière déterministe par des scripts (limites de niveau de personnage, limites de scène principale ajustées dynamiquement en fonction du nombre d'épisodes, intervalles de surbrillance ≤ 3 épisodes, chaque épisode doit inclure un suspense, etc.), sans s'appuyer sur la conscience de soi du modèle ; prend en charge le mode de contrôle de santé : collez un plan existant, exécutez uniquement les portes de qualité pour le diagnostic. Zéro dépendance, zéro clé API, en utilisant le quota de session actuel. À utiliser lorsqu'on lui demande d'adapter le plan, le plan d'un court drame, le plan de décomposition, le roman vers le court drame, le plan d'adaptation.
