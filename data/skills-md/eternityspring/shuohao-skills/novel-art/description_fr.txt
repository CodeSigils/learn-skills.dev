Créer un package de conception artistique (scènes + accessoires narratifs) pour un court drame d'IA : l'intention de conception de la scène, les ancres de cohérence, les variantes de temps d'éclairage, les mots-clés d'invite de scène vide ; la fonction dramatique des accessoires, les variantes d’état, les références à l’échelle, les mots-clés d’invite sans main sur fond blanc. Sortie art.json + Markdown + un rapport de révision d'une seule page (y compris le JSON exporté). Conçu pour le contenu généré par l'IA, et non pour le tournage en direct : l'environnement et les accessoires sont tous des actifs générés, et le livrable est un système de cohérence qui les fait apparaître uniformément dans les collections. Les onze portes de qualité sont vérifiées de manière déterministe par script (ancres 3 à 5, aucune personne/aucune main, découpe sur fond blanc, phrases d'échelle, invites en anglais, etc.). Si le fichier outline.json d'un roman est présent, utilisez sa graine pour pré-remplir la liste des scènes et l'ensemble d'apparences ; la génération d’images s’effectue via le $imagegen intégré dans le Codex (facultatif). Zéro dépendance, zéro clé API, en utilisant le quota de session actuel. À utiliser lorsqu'on vous le demande pour le décor de scène, la génération de scène, la collection de décors d'environnement, la cohérence de scène ou les bibles de scène pour un court drame d'IA.
