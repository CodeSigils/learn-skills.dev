Создайте набор художественного дизайна (сцены + повествовательный реквизит) для короткометражной драмы с использованием ИИ: замысел дизайна сцены, привязки последовательности, варианты периода освещения, подсказки для пустой сцены; драматическая функция реквизита, варианты состояния, ссылки на масштаб, термины-подсказки на белом фоне, не требующие рук. Вывод art.json + Markdown + одностраничный отчет о проверке (включая экспортированный JSON). Разработано для создания искусственного интеллекта, а не для реальной фотографии: окружающая среда и реквизит являются сгенерированными активами, обеспечивая схему согласованности, благодаря которой они выглядят одинаково в разных наборах; все 11 ворот качества детерминированно проверяются скриптами (якоря 3–5, нет человека/нет руки, белый фон убирается, масштабные фразы, подсказки на английском языке и т. д.). Если присутствует файл Outline Outline.json, используйте его начальное значение для предварительного заполнения списка сцен и набора внешнего вида; для генерации изображений используется встроенный $imagegen Кодекса (необязательно). Нулевые зависимости, нулевой ключ API, использование текущей квоты сеанса. Используйте при запросе настроек сцены, создания сцен, наборов настроек среды, согласованности сцен, библий сцен для короткометражных драм с искусственным интеллектом.
