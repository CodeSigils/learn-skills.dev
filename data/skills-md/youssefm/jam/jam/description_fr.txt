Discutez avec l'utilisateur dans une fenêtre de navigateur où vos réponses s'affichent sous forme de code HTML riche et magnifiquement composé au lieu d'une démarque de terminal. À utiliser lorsqu'une réponse nécessite réellement une présentation visuelle que le terminal ne peut pas transporter (diagrammes, graphiques ou comparaisons côte à côte denses) ou lorsque l'utilisateur demande à déplacer la conversation dans un navigateur (« jammons », « discutons dans le navigateur »), pas pour les réponses qui se lisent bien comme une démarque de terminal.
