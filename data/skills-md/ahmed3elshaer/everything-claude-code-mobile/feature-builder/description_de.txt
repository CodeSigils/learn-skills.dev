End-to-End-Builder für mobile Funktionen. Führt eine Funktion von der Beschreibung zum vollständig ausgeführten Code mit E2E-Tests durch sechs Phasen – Planung, Architekturüberprüfung, Implementierung, Tests, Build-Fix, Qualitätsgate und Verifizierung. Unterstützt Android, iOS und KMP mit automatischer Plattformerkennung.
