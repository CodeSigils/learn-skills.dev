À utiliser lorsqu'un projet est connecté à Chai Studio MCP pour le travail du système de conception sensible aux applications, les refontes régies par Chai, la sélection de préréglages/ensembles de règles, les audits de l'interface utilisateur, les téléchargements d'audit et le suivi des violations. Se déclenche lorsque l'utilisateur mentionne Chai Studio, chai-studio.yaml, design-studio.yaml, Chai MCP, les préréglages de conception, les ensembles de règles d'audit, le flux de travail de refonte, le téléchargement des résultats d'audit de l'interface utilisateur ou la synchronisation des conseils de conception de projet avec MCP.
