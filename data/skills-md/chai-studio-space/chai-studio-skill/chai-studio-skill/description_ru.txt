Используйте, когда проект подключен к Chai Studio MCP для работы системы проектирования с учетом приложений, редизайна под управлением Chai, выбора предустановок/наборов правил, аудита пользовательского интерфейса, загрузки аудита и отслеживания нарушений. Срабатывает, когда пользователь упоминает Chai Studio, chai-studio.yaml, design-studio.yaml, Chai MCP, настройки дизайна, наборы правил аудита, рабочий процесс редизайна, загрузку результатов аудита пользовательского интерфейса или синхронизацию руководства по проектированию проекта с MCP.
