Wird verwendet, wenn ein Projekt mit Chai Studio MCP für anwendungsorientierte Designsystemarbeit, Chai-gesteuerte Neudesigns, Voreinstellungs-/Regelsatzauswahl, UI-Audits, Audit-Uploads und Nachverfolgung von Verstößen verbunden ist. Wird ausgelöst, wenn der Benutzer Chai Studio, chai-studio.yaml, design-studio.yaml, Chai MCP, Designvoreinstellungen, Audit-Regelsätze, Redesign-Workflow, das Hochladen von UI-Audit-Ergebnissen oder die Synchronisierung von Projektdesign-Anleitungen mit MCP erwähnt.
