Compétence de contrôle principal de détection de défauts multi-agents distribués. Basé sur la randomisation des entrées, l'examen parallèle basé sur les rôles, le regroupement sémantique, le consensus pondéré et l'examen d'arbitrage, il génère un rapport d'examen du code signal/bruit élevé. Utilisé pour les PR à grande échelle, les changements logiques complexes, les modifications sensibles à la sécurité ou les scénarios dans lesquels le rappel de révision par un seul agent est insuffisant.
