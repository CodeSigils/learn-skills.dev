Одностраничный SEO-аудит: глубокая оценка качества контента с использованием системы Google E-E-A-T, рекомендации по полезному контенту, факторы SEO на странице, согласование целей поиска, технические сигналы и анализ читабельности. Получает данные о производительности GSC для этой конкретной страницы, сканирует живой HTML, оценивает метаданные, разметку схемы, внутренние ссылки, глубину контента и создает оценочный отчет с практическими исправлениями. Используйте этот навык всякий раз, когда пользователь хочет проанализировать конкретную страницу или URL-адрес, а не весь сайт. Запуск по: «проанализировать эту страницу», «проверить этот URL», «как дела на этой странице», «оценить мое сообщение в блоге», «проверить эту целевую страницу», «SEO страницы», «проверка качества контента», «достаточно ли хороша эта страница», «проверить SEO этой страницы», «что не так с этой страницей», «как я могу улучшить эту страницу», «анализ страницы», «аудит одной страницы», «аудит контента для [URL]» или любой запрос, в котором указан конкретный URL/страница для оценки SEO. Если пользователь предоставляет конкретный URL-адрес (а не только домен), это, вероятно, правильный навык — вместо этого используйте /seo-analysis для полного аудита сайта.
