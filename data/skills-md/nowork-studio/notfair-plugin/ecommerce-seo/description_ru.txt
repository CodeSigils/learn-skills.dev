SEO-аудит электронной коммерции для интернет-магазинов (WooCommerce, Shopify, Magento, на заказ). Охватывает структурные проблемы, уникальные для коммерческих сайтов: страницы категорий/списков продуктов (PLP), страницы сведений о продуктах (PDP), фасетная навигация и ловушки обходного бюджета/дубликата контента, которые она создает, нумерация страниц, каноническая обработка вариантов и фильтров, обработка товаров, которых нет в наличии/снят с производства, внутренние ссылки и хлебные крошки, а также структурированные данные Product/Offer/Review/AggregateRating/BreadcrumbList для получения расширенных результатов. Используйте этот навык всякий раз, когда пользователь запускает интернет-магазин и спрашивает о SEO электронной коммерции, SEO страницы продукта, SEO страницы категории, фасетной навигации, индексируемых URL-адресов фильтра, схеме продукта / расширенных результатах, SEO отсутствия на складе или тонких / дублирующих страницах продуктов. Триггер: «SEO для электронной коммерции», «SEO для электронной коммерции», «SEO для страницы продукта», «SEO для страницы категории», «SEO для WooCommerce», «SEO для Shopify», «фасетная навигация», «фильтровать URL-адреса в Google», «схема продукта», «расширенные фрагменты для продуктов», «SEO, нет в наличии», «дубликаты страниц продукта». Для одного URL-адреса используйте /seo-page; для полноценного использования сайта/seo-анализа.
