XML サイトマップ監査 - クロール予算を静かに浪費し、インデックス作成を遅らせるサイトマップの問題を見つけて修正します。サイトマップ (robots.txt、/sitemap.xml、サイトマップ インデックス) を検出し、構造とサイズの制限を検証し、サイトマップにリストされている URL を実際と照合します。サイトマップ内にあるべきではない 200 以外の URL、リダイレクトされた URL、インデックスなし、正規化されたアウェイ URL、およびサイトマップに欠落しているインデックス可能なページ。 lastmod の精度、サイトマップ インデックスの構成、robots.txt リファレンスをレビューします。ユーザーがサイトマップ、Search Console でのサイトマップ エラー、「サイトマップを取得できなかった / エラーがある」、クロール予算、ページがインデックスに登録されていない、またはサイトマップがクリーンかどうかについて尋ねたときに、このスキルを使用します。トリガー: 「サイトマップ」、「sitemap.xml」、「XML サイトマップ」、「サイトマップ エラー」、「サイトマップ監査」、「サイトマップを取得できませんでした」、「クロール バジェット」、「サイトマップのインデックスが作成されていないページ」、「サイトマップ インデックス」、「lastmod」、「robots.txt サイトマップ」、またはサイトマップ/クロール カバレッジの質問。フルサイト SEO 監査の場合は、/seo-analysis を使用します。リンク切れの場合は /broken-link-checker を使用してください。
