تدقيق خريطة موقع XML - يمكنك العثور على مشكلات خريطة الموقع وإصلاحها التي تهدر ميزانية الزحف والفهرسة البطيئة بهدوء. يكتشف خريطة الموقع (robots.txt، /sitemap.xml، فهرس خريطة الموقع)، ويتحقق من صحة حدود البنية والحجم، ويقارن عناوين URL التي يدرجها مع الواقع: عناوين URL غير 200 / المعاد توجيهها / noindex / المتعارف عليها والتي لا ينبغي أن تكون في خريطة الموقع، بالإضافة إلى الصفحات القابلة للفهرسة المفقودة منه. يراجع دقة lastmod وتنظيم فهرس خريطة الموقع ومرجع ملف robots.txt. استخدم هذه المهارة عندما يسأل المستخدم عن ملفات Sitemap، أو أخطاء خريطة الموقع في Search Console، أو "تعذر على ملف Sitemap جلب / يحتوي على أخطاء"، أو ميزانية الزحف، أو عدم فهرسة الصفحات، أو ما إذا كان ملف Sitemap نظيفًا. قم بتشغيل: "خريطة الموقع"، أو "خريطة الموقع.xml"، أو "خريطة موقع XML"، أو "أخطاء خريطة الموقع"، أو "تدقيق خريطة الموقع"، أو "تعذر جلب خريطة الموقع"، أو "ميزانية الزحف"، أو "خريطة الموقع غير المفهرسة"، أو "فهرس خريطة الموقع"، أو "lastmod"، أو "ملف ملف robots.txt"، أو أي سؤال حول خريطة الموقع/تغطية الزحف. لإجراء تدقيق SEO كامل للموقع، استخدم /تحليل seo؛ بالنسبة للروابط المعطلة، استخدم /broken-link-checker.
