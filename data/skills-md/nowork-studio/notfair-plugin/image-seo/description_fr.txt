Audit SEO d'images : rendez les images d'un site visibles dans Google Images et empêchez-les de faire glisser Core Web Vitals. Audite la qualité et la couverture du texte alternatif, les noms de fichiers descriptifs, les formats modernes (WebP/AVIF), les dimensions et la compression, le srcset réactif, le chargement différé, la largeur/hauteur explicite (CLS), les plans de site d'images et les données structurées ImageObject. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur le référencement des images, le texte alternatif, le classement Google Images, l'optimisation des images pour la recherche, la taille du fichier image nuisant à la vitesse de la page, WebP/AVIF ou les données structurées de l'image. Déclenchez sur : "SEO d'image", "texte alternatif", "classement dans Google Images", "optimiser mes images pour la recherche", "balises alt d'image", "WebP", "SEO de compression d'image", "plan de site d'image", "schéma ImageObject", ou toute question de découverte d'image/performance d'image. Pour la vitesse globale de la page, utilisez /seo-analysis ; pour générer de nouvelles images, utilisez les compétences en image de marque.
