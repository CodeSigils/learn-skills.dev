Durchsucht eine Website nach defekten Links (404s, 500s). Crawlt interne Seiten, identifiziert fehlerhafte ausgehende Links und meldet Quellseiten zur einfachen Behebung. Verwenden Sie dies, wenn der Benutzer fragt: „Auf defekte Links prüfen“, „404-Fehler finden“, „Meine Links prüfen“ oder „Ist meine Website fehlerfrei“.
