Aggiorna il plugin NotFair alla versione più recente. Aggiorna il repository del marketplace, installa la nuova versione nella cache dei plug-in e aggiorna installato_plugins.json. Utilizzare quando viene richiesto di "aggiornare notfair", "aggiornare notfair" o "ottenere l'ultima versione". Gestisce anche le richieste di aggiornamento in linea quando una competenza rileva UPGRADE_AVAILABLE all'avvio.
