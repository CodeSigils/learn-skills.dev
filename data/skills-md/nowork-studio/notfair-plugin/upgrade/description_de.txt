Aktualisieren Sie das NotFair-Plugin auf die neueste Version. Aktualisiert das Marktplatz-Repository, installiert die neue Version im Plugin-Cache und aktualisiert die Datei „installed_plugins.json“. Wird verwendet, wenn Sie nach „Notfair aktualisieren“, „Notfair aktualisieren“ oder „Neueste Version abrufen“ gefragt werden. Verarbeitet auch Inline-Upgrade-Eingabeaufforderungen, wenn ein Skill beim Start UPGRADE_AVAILABLE erkennt.
