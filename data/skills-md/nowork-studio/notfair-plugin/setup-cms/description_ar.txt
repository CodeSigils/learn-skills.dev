قم بتوصيل نظام إدارة المحتوى (CMS) بأدوات تحسين محركات البحث غير العادلة (SEO). يرشد المستخدمين من خلال تكوين WordPress، أو Strapi، أو Contentful، أو Ghost - ويختبر الاتصال، ويكتب بيانات الاعتماد إلى .env.local. بمجرد الإعداد، يقوم تحليل تحسين محركات البحث (SEO) تلقائيًا بمراجعة محتوى نظام إدارة المحتوى (CMS) مقابل بيانات Google Search Console. يُستخدم عندما يقول المستخدم "توصيل نظام إدارة المحتوى الخاص بي" أو "إعداد WordPress" أو "تكوين Strapi" أو "إضافة محتوى" أو "توصيل Ghost" أو "إعداد CMS". يتم التشغيل أيضًا إذا سأل المستخدم عن سبب عدم ظهور بيانات نظام إدارة المحتوى (CMS) في تقرير تحليل تحسين محركات البحث.
