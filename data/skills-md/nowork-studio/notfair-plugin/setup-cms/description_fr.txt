Connectez un CMS aux outils de référencement notfair. Guide les utilisateurs dans la configuration de WordPress, Strapi, Contentful ou Ghost – teste la connexion et écrit les informations d'identification dans .env.local. Une fois configurée, seo-analysis croise automatiquement le contenu du CMS avec les données de Google Search Console. À utiliser chaque fois que l'utilisateur dit « connecter mon CMS », « configurer WordPress », « configurer Strapi », « ajouter Contentful », « connecter Ghost » ou « configurer le CMS ». Déclenchez également si l'utilisateur demande pourquoi aucune donnée CMS n'apparaît dans un rapport d'analyse SEO.
