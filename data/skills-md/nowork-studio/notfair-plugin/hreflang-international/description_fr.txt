Audit SEO international/multilingue axé sur l’exactitude du hreflang. Détecte et diagnostique les erreurs hreflang les plus courantes (et préjudiciables au classement) : balises de retour manquantes ou cassées, codes de langue/région erronés, défaut x manquant, erreurs d'auto-référencement, conflits entre hreflang et canonique et signaux incohérents dans l'en-tête HTML/les en-têtes HTTP/le plan du site XML. Examine également la configuration internationale plus large : structure d'URL (ccTLD vs sous-répertoire vs sous-domaine), ciblage linguistique et signaux géographiques. Utilisez cette compétence chaque fois que l'utilisateur gère un site multilingue ou multirégional et pose des questions sur le hreflang, le référencement international, le référencement multilingue, la page dans une mauvaise langue affichée dans la recherche, la duplication de contenu dans les versions nationales ou le « classement de la page th/en dans le mauvais pays ». Déclenchez sur : "hreflang", "SEO international", "SEO multilingue", "multi-région", "mauvaise langue dans Google", "x-default", "ccTLD vs sous-répertoire", "ciblage géographique", "ciblage linguistique", "ma page en anglais s'affiche pour les utilisateurs thaïlandais", ou toute question de classement multilingue/international. Pour les audits complets du site, utilisez /seo-analysis ; pour une seule URL, utilisez /seo-page.
