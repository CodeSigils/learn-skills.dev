hreflang の正確さに重点を置いた国際/多言語 SEO 監査。最も一般的な (そしてランキングに悪影響を与える) hreflang の間違いを検出および診断します。たとえば、リターン タグの欠落または破損、間違った言語/地域コード、x デフォルトの欠落、自己参照エラー、hreflang と正規間の競合、HTML ヘッド / HTTP ヘッダー / XML サイトマップ間の一貫性のないシグナルなどです。また、URL 構造 (ccTLD、サブディレクトリ、サブドメイン)、言語ターゲティング、地域信号など、より広範な国際的な設定についても確認します。ユーザーが多言語または複数地域のサイトを運営しており、hreflang、国際 SEO、多言語 SEO、検索で表示される間違った言語のページ、各国バージョン間での重複コンテンツ、または「間違った国でのそのページのランキング」について質問するときは、必ずこのスキルを使用してください。トリガー: 「hreflang」、「国際 SEO」、「多言語 SEO」、「マルチリージョン」、「Google の間違った言語」、「x-default」、「ccTLD とサブディレクトリ」、「地域ターゲティング」、「言語ターゲティング」、「私の英語ページはタイのユーザー向けに表示される」、または言語間/国を越えたランキングの質問。フルサイト監査の場合は、/seo-analysis を使用します。単一の URL の場合は /seo-page を使用します。
