ركز تدقيق تحسين محركات البحث (SEO) الدولي / متعدد اللغات على صحة hreflang. يكتشف ويشخص أخطاء hreflang الأكثر شيوعًا (والمدمرة للترتيب): علامات الإرجاع المفقودة أو المعطلة، ورموز اللغة/المنطقة الخاطئة، وخطأ x الافتراضي، وأخطاء المرجع الذاتي، والتعارضات بين hreflang وcanonical، والإشارات غير المتناسقة عبر رأس HTML / رؤوس HTTP / خريطة موقع XML. يراجع أيضًا الإعداد الدولي الأوسع - بنية عنوان URL (ccTLD مقابل الدليل الفرعي مقابل النطاق الفرعي)، واستهداف اللغة، والإشارات الجغرافية. استخدم هذه المهارة عندما يقوم المستخدم بتشغيل موقع متعدد اللغات أو المناطق ويسأل عن hreflang، أو تحسين محركات البحث الدولية، أو تحسين محركات البحث متعدد اللغات، أو ظهور صفحة باللغة الخاطئة في البحث، أو محتوى مكرر عبر إصدارات البلدان، أو "تصنيف الصفحة/ar في البلد الخطأ". قم بتشغيل: "hreflang"، أو "SEO الدولي"، أو "SEO متعدد اللغات"، أو "متعدد المناطق"، أو "لغة خاطئة في Google"، أو "x-default"، أو "ccTLD مقابل الدليل الفرعي"، أو "الاستهداف الجغرافي"، أو "استهداف اللغة"، أو "تظهر صفحتي باللغة الإنجليزية للمستخدمين التايلانديين"، أو أي سؤال حول التصنيف عبر اللغات/البلدان. لإجراء عمليات تدقيق كاملة للموقع، استخدم تحليل /seo؛ لعنوان URL واحد، استخدم /seo-page.
