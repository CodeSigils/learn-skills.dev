مراقبة انحراف تحسين محركات البحث (SEO) - التقط صورة لحالة تحسين محركات البحث (SEO) للموقع واكتشف التراجعات بمرور الوقت. يلتقط خطًا أساسيًا (التصنيفات/المواضع، وعدد الصفحات المفهرسة، والعناوين والأوصاف التعريفية، والتوجيهات الأساسية/الروبوتات، ووجود المخطط، والعناصر الرئيسية على الصفحة) ويتم تشغيله لاحقًا ويختلف معه لإظهار ما تغير: انخفاض التصنيف، والصفحات التي سقطت من الفهرس، والعناوين/التعريفات التي تم الكتابة فوقها عن طريق الخطأ (نظام إدارة المحتوى/إعادة النشر الكلاسيكي)، أو انقلبت المعايير أو noindex، أو المخطط الذي اختفى. استخدم هذه المهارة عندما يريد المستخدم مراقبة تحسين محركات البحث بمرور الوقت، أو اكتشاف الانحدارات بعد تغيير الموقع / ترحيله / إعادة نشره، أو تعيين خط أساس، أو الاختلاف مقابل حالة سابقة، أو يسأل "ما الذي تغير في تحسين محركات البحث لموقعي" أو "هل أدت إعادة تصميمي إلى كسر تحسين محركات البحث". تشغيل: "انجراف تحسين محركات البحث"، "مراقبة تحسين محركات البحث"، "تتبع تحسين محركات البحث بمرور الوقت"، "هل تغير موقعي إلى تحسين محركات البحث"، "بعد ترحيل تحسين محركات البحث"، "تراجع تحسين محركات البحث"، "خط الأساس لتحسين محركات البحث"، "مقارنة تحسين محركات البحث بالشهر الماضي"، "تغيرت عناويني"، "سقطت الصفحات من الفهرس". لاستخدام التدقيق الكامل/تحليل تحسين محركات البحث (SEO) لمرة واحدة.
