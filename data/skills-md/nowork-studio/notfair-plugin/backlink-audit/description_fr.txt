Audit backlink / SEO off-page. Fonctionne SANS outil payant par défaut : il utilise le rapport sur les liens de la console de recherche de Google (vos principaux sites de liens, pages les plus liées et texte d'ancrage) ainsi que toute exportation de backlink fournie par l'utilisateur (Ahrefs / Semrush / Majestic / DataForSEO CSV). Analyse le profil du domaine référent, la distribution du texte d'ancrage (modèles sur-optimisés/spam), les pages les plus liées par rapport aux pages d'argent (opportunité de liens internes), les signaux de liens toxiques/spam et les priorités de création de liens. Utilisez cette compétence lorsque l'utilisateur pose des questions sur les backlinks, la création de liens, le référencement hors page, les domaines référents, le texte d'ancrage, les liens toxiques/spam, le désaveu ou leur profil de lien. Déclenchez sur : "backlinks", "audit de backlink", "link building", "off-page SEO", "domaines référents", "ancre texte", "liens toxiques", "liens spam", "fichier de désaveu", "qui crée un lien vers moi", "profil de lien", "autorité de domaine". REMARQUE : les métriques tierces riches (DR/DA, index de liens complets) nécessitent une source de données payante ; cette compétence est explicite sur ce qu'elle peut et ne peut pas voir sans elle.
