Обратная ссылка/внестраничный SEO-аудит. По умолчанию работает БЕЗ платного инструмента — он использует отчет «Ссылки» Google Search Console (ваши сайты с наибольшим количеством ссылок, страницы с наибольшим количеством ссылок и текст привязки), а также любой экспорт обратных ссылок, предоставляемый пользователем (Ahrefs / Semrush / Majestic / DataForSEO CSV). Анализирует профиль ссылающегося домена, распределение якорного текста (шаблоны чрезмерной оптимизации/спама), страницы с наибольшим количеством ссылок по сравнению с денежными страницами (возможность внутренних ссылок), сигналы токсичных/спамовых ссылок и приоритеты построения ссылок. Используйте этот навык, когда пользователь спрашивает об обратных ссылках, построении ссылок, внестраничном SEO, ссылающихся доменах, якорном тексте, токсичных/спам-ссылках, отклонении или профиле ссылок. Триггер: «обратные ссылки», «аудит обратных ссылок», «построение ссылок», «внестраничное SEO», «ссылающиеся домены», «анкорный текст», «токсичные ссылки», «спам-ссылки», «отклонить файл», «кто ссылается на меня», «профиль ссылки», «авторитет домена». ПРИМЕЧАНИЕ. Для расширенных сторонних показателей (DR/DA, полный индекс ссылок) требуется платный источник данных; этот навык ясно показывает, что он может и чего не может видеть без него.
