Чтение файлов хирургическим путем — сначала grep, чтение только соответствующих разделов. Предотвращает загрузку целых больших файлов, когда требуется всего несколько строк. Активируется автоматически при включении режима умного чтения. Экономия входных токенов: 40–90 % в зависимости от размера файла и объема задачи.
