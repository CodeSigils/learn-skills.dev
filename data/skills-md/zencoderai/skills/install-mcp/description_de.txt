Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „einen MCP-Server installieren“, „diesen MCP-Server hinzufügen“, „MCP einrichten“, „dieses MCP-Tool konfigurieren“, „dies zu meiner MCP-Konfiguration hinzufügen“ auffordert oder die Installation, Einrichtung oder Konfiguration eines beliebigen MCP-Servers (Model Context Protocol) von einer externen Quelle erwähnt. Der externe MCP-Server von Gates wird mit einer Sicherheitsbewertung installiert und über alle unterstützten CLIs hinweg konfiguriert.
