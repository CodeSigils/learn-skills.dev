Этот навык следует использовать, когда пользователь просит «установить сервер MCP», «добавить этот сервер MCP», «настроить MCP», «настроить этот инструмент MCP», «добавить это в мою конфигурацию MCP» или упоминает установку, настройку или настройку любого сервера MCP (протокола контекста модели) из внешнего источника. Внешний сервер MCP Gates устанавливается с оценкой безопасности и настраивается для всех поддерживаемых интерфейсов командной строки.
