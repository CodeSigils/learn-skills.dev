Questa abilità dovrebbe essere utilizzata quando l'utente chiede di "installare un server MCP", "aggiungere questo server MCP", "impostare MCP", "configurare questo strumento MCP", "aggiungere questo alla mia configurazione MCP" o menziona l'installazione, l'impostazione o la configurazione di qualsiasi server MCP (Model Context Protocol) da una fonte esterna. Il server MCP esterno di Gates si installa con una valutazione della sicurezza e si configura su tutte le CLI supportate.
