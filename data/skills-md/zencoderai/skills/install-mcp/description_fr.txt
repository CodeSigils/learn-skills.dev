Cette compétence doit être utilisée lorsque l'utilisateur demande « installer un serveur MCP », « ajouter ce serveur MCP », « configurer MCP », « configurer cet outil MCP », « l'ajouter à ma configuration MCP » ou mentionne l'installation, l'installation ou la configuration d'un serveur MCP (Model Context Protocol) à partir d'une source externe. Le serveur MCP externe Gates s'installe avec une évaluation de sécurité et se configure sur toutes les CLI prises en charge.
