Diseñe interfaces frontales distintivas y de nivel de producción: maquetas como páginas HTML o páginas de aplicaciones de trabajo. Úselo cuando el usuario solicite diseñar una página web, una página de destino, una maqueta de interfaz de usuario, un panel de control, una página de aplicación o cualquier interfaz HTML visual. Admite diseños únicos, generación de múltiples variantes e integración con marcos de proyectos existentes.
