Навык инженерного менеджера для инженерных менеджеров. Используйте этот навык, когда пользователь говорит: «инженерная информационная панель», «инженерные лидеры», «покажи мне информационную панель», «показатели DORA», «состояние PR», «пульс спринта», «частота развертывания», «время выполнения», «частота неудачных изменений», «MTTR», «скорость спринта», «распределение инвестиций», «инженерный отчет», «отчет технического менеджера» или «ежедневное техническое задание». Собирает реальные данные из GitHub (через gh CLI), Linear (с помощью zen-linear), Jira (с помощью zen-jira) и Sentry (с помощью zen-sentry). Отображает живую панель управления HTML во встроенном браузере Zenflow. Также выполняет автоматизированные действия: многомодельный PR-анализ, аудит зависимостей и сортировку ошибок.
