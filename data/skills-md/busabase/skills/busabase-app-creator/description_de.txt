Erstellen Sie eine vollständig isolierte Busabase-Arbeitsbereichs-App, erstellen Sie eine installierbare Busabase-Vorlage oder entwickeln Sie eine bestehende AirApp kontinuierlich weiter – alles über einen einzigen Review-First-Workflow. Beginnen Sie entweder mit der Erstellung eines Live-Space und exportieren Sie das Ergebnis als Vorlage oder schreiben Sie das Vorlagenpaket auf die Festplatte und installieren Sie es zur Überprüfung. Verwendung für neue Cloud-/Desktop-Workspace-Apps, zum Verfassen oder Beitragen einer Busabase-Vorlage oder eines Vorlagen-Skills sowie zum Prüfen, Aktualisieren, Erweitern oder Migrieren einer identifizierten AirApp, einschließlich genehmigter Änderungen an der Benutzeroberfläche, Dateien, Ordnern, Basen, Ansichten, Daten und zugehörigen nativen Ressourcen, wobei alles außerhalb des angeforderten Bereichs erhalten bleibt.
