دليل الهندسة المعمارية لمشاريع Kotlin + Spring Boot التي تستخدم بنية سداسية (المنافذ والمحولات) مع بنية متراصة معيارية. استخدم هذه المهارة عند إنشاء ميزات جديدة أو وحدات نمطية أو حالات استخدام أو كيانات المجال أو وحدات التحكم أو المستودعات أو أي تعليمات برمجية تحتاج إلى اتباع بنية طبقات المشروع. يُستخدم أيضًا عندما يسأل المستخدم عن بنية المشروع، أو مكان وضع التعليمات البرمجية الجديدة، أو كيفية ربط التبعيات بين الطبقات، أو كيفية تنفيذ أنماط نمط CQRS. تشغيل الإشارات إلى "الميزة الجديدة"، أو "حالة الاستخدام الجديدة"، أو "الكيان الجديد"، أو "نقطة النهاية الجديدة"، أو "إضافة واجهة برمجة التطبيقات"، أو "وحدة نمطية جديدة"، أو "الهندسة المعمارية"، أو "السداسية"، أو "المنافذ والمحولات"، أو أي طلب لدعم أو إنشاء تعليمات برمجية تتبع اصطلاحات المشروع.
