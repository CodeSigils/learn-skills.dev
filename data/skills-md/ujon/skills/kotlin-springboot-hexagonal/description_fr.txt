Guide d'architecture pour les projets Kotlin + Spring Boot utilisant une architecture hexagonale (ports et adaptateurs) avec une structure monolithique modulaire. Utilisez cette compétence chaque fois que vous créez de nouvelles fonctionnalités, modules, cas d'utilisation, entités de domaine, contrôleurs, référentiels ou tout code devant suivre l'architecture en couches du projet. À utiliser également lorsque l'utilisateur pose des questions sur la structure du projet, où placer le nouveau code, comment câbler les dépendances entre les couches ou comment implémenter des modèles de style CQRS. Déclenchez les mentions de « nouvelle fonctionnalité », « nouveau cas d'utilisation », « nouvelle entité », « nouveau point de terminaison », « ajouter une API », « nouveau module », « architecture », « hexagonal », « ports et adaptateurs » ou toute demande d'échafaudage ou de génération de code suivant les conventions du projet.
