Guía de arquitectura para proyectos Kotlin + Spring Boot que utilizan arquitectura hexagonal (puertos y adaptadores) con una estructura monolítica modular. Utilice esta habilidad siempre que cree nuevas funciones, módulos, casos de uso, entidades de dominio, controladores, repositorios o cualquier código que deba seguir la arquitectura en capas del proyecto. Úselo también cuando el usuario pregunte sobre la estructura del proyecto, dónde colocar el código nuevo, cómo conectar las dependencias entre capas o cómo implementar patrones de estilo CQRS. Se activa ante menciones de "nueva característica", "nuevo caso de uso", "nueva entidad", "nuevo punto final", "agregar API", "nuevo módulo", "arquitectura", "hexagonal", "puertos y adaptadores" o cualquier solicitud para realizar scaffolding o generar código siguiendo las convenciones del proyecto.
