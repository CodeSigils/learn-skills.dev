Architekturleitfaden für Kotlin + Spring Boot-Projekte mit hexagonaler (Ports und Adapter) Architektur mit einer modularen Monolithstruktur. Nutzen Sie diese Fähigkeit immer dann, wenn Sie neue Funktionen, Module, Anwendungsfälle, Domänenentitäten, Controller, Repositorys oder Code erstellen, der der mehrschichtigen Architektur des Projekts folgen muss. Verwenden Sie es auch, wenn der Benutzer nach der Projektstruktur fragt, wo neuer Code platziert werden soll, wie Abhängigkeiten zwischen Ebenen verknüpft werden oder wie Muster im CQRS-Stil implementiert werden. Auslösen bei Erwähnungen von „neuem Feature“, „neuem Anwendungsfall“, „neuer Entität“, „neuem Endpunkt“, „API hinzufügen“, „neuem Modul“, „Architektur“, „hexagonal“, „Ports und Adapter“ oder bei jeder Anforderung zum Gerüstbau oder zur Generierung von Code gemäß Projektkonventionen.
