パレット、タイポグラフィ スケール、間隔、半径、明るい/暗いテーマ、コンポーネントごとの CSS、および (デフォルトでは) HTML プレビュー ページなど、Web プロジェクトの CSS デザイン トークン スタイルガイドを生成します。 7 つのデザイン システムをすぐにコピーできる CSS ブロックとしてリファレンスとして出荷します (Minimal、マテリアル デザイン 3、Uber Base、IBM Carbon、Shopify Polaris、Radix Themes、Maximal)。 **ファイルを書き込む前に、クロードはまず 7 つのシステムのどれを使用するかをユーザーに尋ね、その答えを待つ必要があります**。唯一の例外は、ユーザーがトリガー メッセージで既にシステムの名前を指定している場合です。サイレントデフォルトはありません。システムが選択されると、Claude はファイルを直接アセンブルします (ビルド スクリプトは使用しません)。このスキルは、ユーザーが CSS デザイン トークン、テーマの CSS 変数、スタイルガイド、タイポグラフィ スケール、カラー パレット、間隔/半径トークン、名前付きデザイン システムの外観のプレビュー、コンポーネント CSS (`.btn`、`.input`、`.card` など) を要求する場合、または Minimal / Maximal / Materials / Uber / Carbon / Polaris / Radix / Fluent などを適用/比較したい場合に使用します。 「CSS トークンを更新する」、「theme.css を再構築する」、「CSS 変数を設定する」、「1 ページにすべてのサイズ/色を表示する」場合に使用します。たとえ「styleguide」が指定されていない場合でも。プロジェクトに依存しない。 React、Vue、Svelte、Angular、またはプレーン HTML/CSS で動作します。
