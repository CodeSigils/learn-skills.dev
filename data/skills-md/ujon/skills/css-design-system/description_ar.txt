قم بإنشاء دليل نمط رمز تصميم CSS لأي مشروع ويب - لوحة الألوان، ومقياس الطباعة، والتباعد، ونصف القطر، والموضوع الفاتح/الداكن، وCSS لكل مكون، و(افتراضيًا) صفحة معاينة HTML. يتم شحن سبعة أنظمة تصميم ككتل CSS جاهزة للنسخ في المراجع (Minimal، Material Design 3، Uber Base، IBM Carbon، Shopify Polaris، Radix Themes، Maximal). **قبل كتابة أي ملف، يجب على كلود أولاً أن يسأل المستخدم عن أي من الأنظمة السبعة يجب استخدامه وانتظار الإجابة** — الاستثناء الوحيد هو عندما يقوم المستخدم بالفعل بتسمية نظام في رسالة التشغيل. لا توجد افتراضيات صامتة. بمجرد اختيار النظام، يقوم كلود بتجميع الملفات مباشرة (لا يوجد برنامج نصي للإنشاء). استخدم هذه المهارة عندما يطلب المستخدم رموز تصميم CSS، أو متغيرات CSS لموضوع، أو دليل نمط، أو مقياس طباعة، أو لوحة ألوان، أو رموز تباعد/نصف قطر، أو معاينة لكيفية ظهور نظام تصميم مسمى، أو مكون CSS (`.btn`، `.input`، `.card`، وما إلى ذلك)، أو يريد تطبيق / مقارنة الحد الأدنى / الحد الأقصى / المادة / Uber / Carbon / Polaris / Radix / Fluent / إلخ. استخدم أيضًا بالنسبة إلى "تحديث رموز CSS"، و"إعادة بناء theme.css"، و"إعداد متغيرات CSS"، و"إظهار جميع الأحجام/الألوان في صفحة واحدة" - حتى لو لم يتم ذكر "دليل النمط" مطلقًا. حياد المشروع. يعمل مع React أو Vue أو Svelte أو Angular أو HTML/CSS العادي.
