Générez un guide de style de jeton de conception CSS pour n'importe quel projet Web : palette, échelle de typographie, espacement, rayon, thème clair/sombre, CSS par composant et (par défaut) une page d'aperçu HTML. Fournit sept systèmes de conception sous forme de blocs CSS prêts à copier dans des références (Minimal, Material Design 3, Uber Base, IBM Carbon, Shopify Polaris, Radix Themes, Maximal). **Avant d'écrire un fichier, Claude doit d'abord demander à l'utilisateur lequel des sept systèmes utiliser et attendre la réponse** — la seule exception est lorsque l'utilisateur a déjà nommé un système dans le message déclencheur. Aucun défaut silencieux. Une fois le système choisi, Claude assemble directement les fichiers (pas de script de build). Utilisez cette compétence chaque fois que l'utilisateur demande des jetons de conception CSS, des variables CSS pour un thème, un guide de style, une échelle typographique, une palette de couleurs, des jetons d'espacement/rayon, un aperçu de l'apparence d'un système de conception nommé, un composant CSS (`.btn`, `.input`, `.card`, etc.), ou souhaite appliquer/comparer Minimal / Maximal / Material / Uber / Carbon / Polaris / Radix / Fluent / etc. Utilisez également pour "actualiser les jetons CSS", "reconstruire theme.css", "configurer les variables CSS", "afficher toutes les tailles/couleurs sur une seule page" - même si "styleguide" n'est jamais dit. Indépendant du projet ; fonctionne pour React, Vue, Svelte, Angular ou HTML/CSS simple.
