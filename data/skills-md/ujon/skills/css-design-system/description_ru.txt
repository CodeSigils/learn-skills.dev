Создайте руководство по стилю токена дизайна CSS для любого веб-проекта — палитру, типографский масштаб, интервал, радиус, светлую/темную тему, CSS для каждого компонента и (по умолчанию) страницу предварительного просмотра HTML. Поставляет семь систем дизайна в виде готовых к копированию блоков CSS в ссылках (Minimal, Material Design 3, Uber Base, IBM Carbon, Shopify Polaris, Radix Themes, Maximal). **Перед записью любого файла Клод должен сначала спросить пользователя, какую из семи систем использовать, и дождаться ответа** — единственное исключение — когда пользователь уже назвал систему в триггерном сообщении. Никаких молчаливых настроек по умолчанию. После выбора системы Клод собирает файлы напрямую (без сценария сборки). Используйте этот навык всякий раз, когда пользователь запрашивает токены дизайна CSS, переменные CSS для темы, руководство по стилю, типографскую шкалу, цветовую палитру, токены интервалов/радиусов, предварительный просмотр того, как выглядит именованная система дизайна, компонент CSS (`.btn`, `.input`, `.card` и т. д.) или хочет применить / сравнить Minimal / Maximal / Material / Uber / Carbon / Polaris / Radix / Fluent / и т. д. Также используйте для «обновить CSS» tokens», «перестроить theme.css», «настроить переменные CSS», «показать все размеры/цвета на одной странице» — даже если «руководство по стилю» никогда не упоминается. Независимость от проекта; работает для React, Vue, Svelte, Angular или простого HTML/CSS.
