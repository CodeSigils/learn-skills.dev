Generieren Sie einen CSS-Design-Token-Styleguide für jedes Webprojekt – Palette, Typografieskalierung, Abstand, Radius, Hell-/Dunkel-Thema, CSS pro Komponente und (standardmäßig) eine HTML-Vorschauseite. Liefert sieben Designsysteme als kopierfertige CSS-Blöcke in Referenzen (Minimal, Material Design 3, Uber Base, IBM Carbon, Shopify Polaris, Radix Themes, Maximal). **Vor dem Schreiben einer Datei muss Claude den Benutzer zunächst fragen, welches der sieben Systeme verwendet werden soll, und auf die Antwort warten** – die einzige Ausnahme besteht, wenn der Benutzer in der auslösenden Nachricht bereits ein System benannt hat. Keine stillen Standardeinstellungen. Sobald das System ausgewählt ist, stellt Claude die Dateien direkt zusammen (kein Build-Skript). Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach CSS-Design-Tokens, CSS-Variablen für ein Thema, einem Styleguide, einer Typografieskala, einer Farbpalette, Abstands-/Radius-Tokens, einer Vorschau auf das Aussehen eines benannten Designsystems, Komponenten-CSS („.btn“, „.input“, „.card“ usw.) fragt oder Minimal/Maximal/Material/Uber/Carbon/Polaris/Radix/Fluent/usw. anwenden/vergleichen möchte. Verwenden Sie ihn auch für „CSS-Token aktualisieren“. „theme.css neu erstellen“, „CSS-Variablen einrichten“, „alle Größen/Farben auf einer Seite anzeigen“ – auch wenn „styleguide“ nie erwähnt wird. Projektunabhängig; Funktioniert für React, Vue, Svelte, Angular oder einfaches HTML/CSS.
