Genere una guía de estilo de token de diseño CSS para cualquier proyecto web: paleta, escala de tipografía, espaciado, radio, tema claro/oscuro, CSS por componente y (de forma predeterminada) una página de vista previa HTML. Incluye siete sistemas de diseño como bloques CSS listos para copiar en referencias (Minimal, Material Design 3, Uber Base, IBM Carbon, Shopify Polaris, Radix Themes, Maximal). **Antes de escribir cualquier archivo, Claude primero debe preguntarle al usuario cuál de los siete sistemas usar y esperar la respuesta**; la única excepción es cuando el usuario ya ha nombrado un sistema en el mensaje desencadenante. Sin valores predeterminados silenciosos. Una vez elegido el sistema, Claude ensambla los archivos directamente (sin script de compilación). Utilice esta habilidad siempre que el usuario solicite tokens de diseño CSS, variables CSS para un tema, una guía de estilo, una escala de tipografía, una paleta de colores, tokens de espaciado/radio, una vista previa de cómo se ve un sistema de diseño con nombre, componente CSS (`.btn`, `.input`, `.card`, etc.), o quiera aplicar/comparar Mínimo/Máximo/Material/Uber/Carbon/Polaris/Radix/Fluent/etc. También utilícelo para "actualizar los tokens CSS". "reconstruir theme.css", "configurar variables CSS", "mostrar todos los tamaños/colores en una página", incluso si nunca se dice "guía de estilo". Independiente del proyecto; funciona para React, Vue, Svelte, Angular o HTML/CSS simple.
