Genera una guida di stile del token di progettazione CSS per qualsiasi progetto web: tavolozza, scala tipografica, spaziatura, raggio, tema chiaro/scuro, CSS per componente e (per impostazione predefinita) una pagina di anteprima HTML. Fornisce sette sistemi di progettazione come blocchi CSS pronti per la copia nei riferimenti (Minimal, Material Design 3, Uber Base, IBM Carbon, Shopify Polaris, Radix Themes, Maximal). **Prima di scrivere qualsiasi file, Claude deve chiedere all'utente quale dei sette sistemi utilizzare e attendere la risposta** — l'unica eccezione è quando l'utente ha già nominato un sistema nel messaggio di attivazione. Nessuna impostazione predefinita silenziosa. Una volta scelto il sistema, Claude assembla direttamente i file (senza script di compilazione). Usa questa abilità ogni volta che l'utente richiede token di progettazione CSS, variabili CSS per un tema, una guida di stile, una scala tipografica, una tavolozza di colori, token di spaziatura/raggio, un'anteprima di come appare un sistema di progettazione con nome, un componente CSS (`.btn`, `.input`, `.card`, ecc.), o desidera applicare/confrontare Minimal/Maximal/Material/Uber/Carbon/Polaris/Radix/Fluent/etc. Utilizzare anche per "aggiornare il Token CSS", "ricostruisci theme.css", "imposta variabili CSS", "mostra tutte le dimensioni/colori su una pagina" - anche se "guida di stile" non viene mai detto. Indipendente dal progetto; funziona con React, Vue, Svelte, Angular o semplice HTML/CSS.
