قم بإنشاء رسائل التزام جيدة التنظيم من خلال تحليل حالة git الحالية - الاختلافات المرحلية، والالتزامات الأخيرة، وسياق الفرع. يقوم أيضًا بإنشاء مطالبات رسائل الالتزام الخاصة بـ IDE (IntelliJ، وVS Code، وXcode، وما إلى ذلك) باستخدام متغيرات القالب الأصلية الخاصة بها. استخدم هذه المهارة عندما يطلب المستخدم كتابة رسالة التزام، أو يقول "/commit-message"، أو يريد مساعدة في رسائل التزام git، أو يطلب قالب رسالة التزام IDE أو مطالبة، أو يذكر اصطلاحات الالتزام. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "اكتب رسالة التزام"، أو "إنشاء رسالة التزام"، أو "إنشاء قالب التزام لـ IntelliJ/VSCode"، أو "إعداد رسالة التزام موجهة لـ IDE الخاص بي".
