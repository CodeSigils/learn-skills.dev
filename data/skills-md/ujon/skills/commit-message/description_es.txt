Genere mensajes de confirmación bien estructurados analizando el estado actual de git: diferencias en escena, confirmaciones recientes y contexto de rama. También genera mensajes de confirmación específicos de IDE (IntelliJ, VS Code, Xcode, etc.) con sus variables de plantilla nativas. Utilice esta habilidad cuando el usuario solicite escribir un mensaje de confirmación, diga "/mensaje de confirmación", quiera ayuda con los mensajes de confirmación de git, solicite una plantilla o mensaje de confirmación de IDE o mencione convenciones de confirmación. También se activa cuando el usuario dice cosas como "escribir un mensaje de confirmación", "generar un mensaje de confirmación", "crear una plantilla de confirmación para IntelliJ/VSCode" o "configurar un mensaje de confirmación para mi IDE".
