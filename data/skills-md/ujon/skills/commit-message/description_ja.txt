現在の git 状態 (ステージングされた差分、最近のコミット、ブランチ コンテキスト) を分析することで、適切に構造化されたコミット メッセージを生成します。また、ネイティブ テンプレート変数を使用して、IDE 固有のコミット メッセージ プロンプト (IntelliJ、VS Code、Xcode など) を生成します。このスキルは、ユーザーがコミット メッセージの作成を要求する場合、「/commit-message」と言う場合、git コミット メッセージに関するヘルプが必要な場合、IDE コミット メッセージ テンプレートまたはプロンプトを要求する場合、またはコミット規則について言及する場合に使用します。また、ユーザーが「コミット メッセージを書く」、「コミット メッセージを生成する」、「IntelliJ/VSCode 用のコミット テンプレートを作成する」、または「IDE 用のコミット メッセージ プロンプトを設定する」などの発言をしたときにもトリガーされます。
