Générez des messages de validation bien structurés en analysant l'état actuel de Git : différences par étapes, validations récentes et contexte de branche. Génère également des invites de message de validation spécifiques à l'IDE (IntelliJ, VS Code, Xcode, etc.) avec leurs variables de modèle natives. Utilisez cette compétence lorsque l'utilisateur demande à écrire un message de validation, dit "/commit-message", souhaite de l'aide avec les messages de validation git, demande un modèle ou une invite de message de validation IDE, ou mentionne des conventions de validation. Déclenchez également lorsque l'utilisateur dit des choses comme « écrire un msg de validation », « générer un message de validation », « créer un modèle de validation pour IntelliJ/VSCode » ou « configurer une invite de message de validation pour mon IDE ».
