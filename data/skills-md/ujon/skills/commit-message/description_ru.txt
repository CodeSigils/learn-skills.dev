Создавайте хорошо структурированные сообщения о коммитах, анализируя текущее состояние git — промежуточные различия, недавние коммиты и контекст ветки. Также генерирует запросы сообщений о фиксации, специфичные для IDE (IntelliJ, VS Code, Xcode и т. д.) с их собственными переменными шаблона. Используйте этот навык, когда пользователь просит написать сообщение о фиксации, говорит «/commit-message», хочет получить помощь с сообщениями о фиксации git, запрашивает шаблон или приглашение сообщения о фиксации IDE или упоминает соглашения о фиксации. Также срабатывает, когда пользователь говорит такие вещи, как «написать сообщение о фиксации», «сгенерировать сообщение о фиксации», «создать шаблон фиксации для IntelliJ/VSCode» или «настроить приглашение к сообщению о фиксации для моей IDE».
