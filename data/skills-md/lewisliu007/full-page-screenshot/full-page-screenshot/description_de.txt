Erstellen Sie im Browser einen Screenshot einer Webseite in voller Länge (ganzseitiger Screenshot) und erstellen Sie so ein einzelnes PNG-Bild, das den gesamten Inhalt der Seite enthält.
Auslöseszenarien: Der Benutzer fordert einen langen Screenshot, einen ganzseitigen Screenshot, einen vollständigen Screenshot, einen „langen Screenshot“, eine „ganzseitige Aufnahme“ oder bittet darum, eine Webseite/einen Artikel/einen Bericht als ein vollständiges Bild aufzunehmen. Unterstützt den aktuell geöffneten Tab oder eine angegebene URL.
Behandelt automatisch interne Bildlaufcontainer in SPAs, verzögert geladene Bilder und das Zusammenfügen sehr langer Seiten.
Keine externen Abhängigkeiten; stellt eine direkte Verbindung zum Chrome DevTools-Protokoll her, um alle Vorgänge auszuführen.
