التقط لقطة شاشة كاملة لصفحة ويب في المتصفح (لقطة شاشة لصفحة كاملة)، وقم بإنشاء صورة PNG واحدة تحتوي على محتوى الصفحة بالكامل.
سيناريوهات التشغيل: يطلب المستخدم لقطة شاشة طويلة، أو لقطة شاشة لصفحة كاملة، أو لقطة شاشة كاملة، أو "لقطة شاشة طويلة"، أو "التقاط صفحة كاملة"، أو يطلب التقاط صفحة ويب/مقالة/تقرير كصورة واحدة كاملة. يدعم علامة التبويب المفتوحة حاليًا أو عنوان URL المحدد.
يتعامل تلقائيًا مع حاويات التمرير الداخلية في المنتجعات الصحية (SPA)، والصور المحملة ببطء، ودمج الصفحات الطويلة جدًا معًا.
لا تبعيات خارجية. يتصل مباشرة ببروتوكول Chrome DevTools لتنفيذ جميع العمليات.
