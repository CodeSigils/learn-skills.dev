Prenez une capture d'écran complète d'une page Web dans le navigateur (capture d'écran pleine page), générant une seule image PNG contenant tout le contenu de la page.
Scénarios de déclenchement : l'utilisateur demande une longue capture d'écran, une capture d'écran pleine page, une capture d'écran complète, une "longue capture d'écran", une "capture pleine page" ou demande de capturer une page Web/un article/un rapport sous la forme d'une image complète. Prend en charge l'onglet actuellement ouvert ou une URL spécifiée.
Gère automatiquement les conteneurs de défilement internes dans les SPA, les images chargées paresseusement et l'assemblage de très longues pages.
Aucune dépendance externe ; se connecte directement au protocole Chrome DevTools pour effectuer toutes les opérations.
