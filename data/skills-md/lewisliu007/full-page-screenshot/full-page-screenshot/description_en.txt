Take a full-length screenshot of a webpage in the browser (full-page screenshot), generating a single PNG image that contains all the page’s content.
Trigger scenarios: the user requests a long screenshot, full-page screenshot, complete screenshot, “long screenshot”, “full page capture”, or asks to capture a webpage/article/report as one complete image. Supports the currently opened tab or a specified URL.
Automatically handles internal scrolling containers in SPAs, lazy-loaded images, and stitching together very long pages.
No external dependencies; connects directly to the Chrome DevTools protocol to perform all operations.
