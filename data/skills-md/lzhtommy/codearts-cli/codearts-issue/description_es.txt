Gestión de elementos de trabajo de CodeArts (ProjectMan IPD): consultar la lista de elementos de trabajo, ver detalles, crear elementos de trabajo, actualizar por lotes, consultar relaciones de elementos de trabajo, consultar miembros del proyecto, consultar el estado de los elementos de trabajo y consultar/publicar comentarios. Se utiliza cuando los usuarios necesitan administrar elementos de trabajo como errores, tareas, historias de usuarios, epopeyas, ver miembros del proyecto, consultar definiciones de estado para un tipo de elemento de trabajo específico o ver y publicar comentarios/registros de operaciones.
