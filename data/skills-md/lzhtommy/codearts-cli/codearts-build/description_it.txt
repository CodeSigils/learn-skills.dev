CodeArts Compile Build (CodeCI): interroga l'elenco dei lavori di build (ListProjectJobs), esegue la build (ExecuteJob), arresta la build (StopTheJob), interroga lo stato del lavoro di build (ShowJobStepStatus). Utilizzalo quando l'utente deve visualizzare i processi di compilazione, attivare una compilazione, interrompere una compilazione in esecuzione o interrogare lo stato della compilazione.
