Hosting del codice CodeArts: elenco di repository di query (ListRepositories), creazione di richieste di unione (CreateMergeRequest), creazione di commenti di revisione MR (CreateMergeRequestDiscussion), membri di repository di query (ListMembers). Da utilizzare quando un utente deve visualizzare i repository, creare una MR, inviare commenti sulla revisione del codice o interrogare i membri del repository.
