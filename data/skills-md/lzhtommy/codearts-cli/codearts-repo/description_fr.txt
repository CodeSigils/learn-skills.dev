Hébergement de code CodeArts : interroger la liste des référentiels (ListRepositories), créer une demande de fusion (CreateMergeRequest), créer un commentaire de révision MR (CreateMergeRequestDiscussion), interroger les membres du référentiel (ListMembers). À utiliser lorsqu'un utilisateur a besoin d'afficher des référentiels, de créer des MR, de publier des commentaires de révision de code ou d'interroger les membres du référentiel.
