Úselo cuando Codex necesite trabajar con Canvas LMS/Instructure a través de la API de Canvas: enumerar cursos, buscar ID de cursos, leer programas de estudios, tareas, módulos, páginas, archivos, envíos, calificaciones, rúbricas, fechas de entrega o calcular las calificaciones actuales/finales/máximas del curso. Utilícelo también cuando un usuario solicite enviar tareas de Canvas o descargar materiales del curso de Canvas, manteniendo los tokens de Canvas en el llavero de macOS o en las variables de entorno.
