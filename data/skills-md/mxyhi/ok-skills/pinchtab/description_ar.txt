استخدم هذه المهارة عندما تحتاج مهمة إلى أتمتة المتصفح من خلال PinchTab: افتح موقع ويب، أو افحص العناصر التفاعلية، أو انقر فوق التدفقات، أو املأ النماذج، أو استخرج نص الصفحة، أو قم بتسجيل الدخول إلى المواقع ذات ملف تعريف ثابت، أو قم بتصدير لقطات الشاشة أو ملفات PDF، أو قم بإدارة مثيلات المتصفح المتعددة، أو ارجع إلى HTTP API عندما لا تكون واجهة سطر الأوامر (CLI) متاحة. قم بتفضيل هذه المهارة لعمل المتصفح ذو الرمز المميز والمدفوع بمراجع إمكانية الوصول الثابتة مثل `e5` و`e12`.
