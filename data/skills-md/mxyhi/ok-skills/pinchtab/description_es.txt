Utilice esta habilidad cuando una tarea necesite automatización del navegador a través de PinchTab: abra un sitio web, inspeccione elementos interactivos, haga clic en flujos, complete formularios, extraiga texto de la página, inicie sesión en sitios con un perfil persistente, exporte capturas de pantalla o archivos PDF, administre múltiples instancias del navegador o recurra a la API HTTP cuando la CLI no esté disponible. Prefiera esta habilidad para un trabajo de navegador con token eficiente impulsado por referencias de accesibilidad estables como "e5" y "e12".
