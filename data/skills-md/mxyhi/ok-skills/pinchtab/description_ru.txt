Используйте этот навык, когда задача требует автоматизации браузера с помощью PinchTab: откройте веб-сайт, проверьте интерактивные элементы, пройдите по потокам, заполните формы, очистите текст страницы, войдите на сайты с постоянным профилем, экспортируйте снимки экрана или PDF-файлы, управляйте несколькими экземплярами браузера или вернитесь к HTTP API, когда CLI недоступен. Предпочитайте этот навык для эффективной работы браузера с использованием токенов, основанной на стабильных ссылках на доступность, таких как «e5» и «e12».
