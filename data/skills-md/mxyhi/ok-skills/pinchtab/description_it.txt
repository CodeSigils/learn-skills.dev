Utilizza questa competenza quando un'attività richiede l'automazione del browser tramite PinchTab: apri un sito Web, ispeziona elementi interattivi, fai clic sui flussi, compila moduli, raschia il testo della pagina, accedi a siti con un profilo persistente, esporta schermate o PDF, gestisci più istanze del browser o ricorri all'API HTTP quando la CLI non è disponibile. Preferisci questa competenza per un lavoro del browser efficiente in termini di token guidato da riferimenti di accessibilità stabili come "e5" ed "e12".
