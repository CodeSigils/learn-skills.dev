Verwenden Sie diese Fähigkeit, wenn eine Aufgabe eine Browserautomatisierung über PinchTab erfordert: Öffnen Sie eine Website, überprüfen Sie interaktive Elemente, klicken Sie durch Abläufe, füllen Sie Formulare aus, scrapen Sie Seitentext, melden Sie sich bei Websites mit einem dauerhaften Profil an, exportieren Sie Screenshots oder PDFs, verwalten Sie mehrere Browserinstanzen oder greifen Sie auf die HTTP-API zurück, wenn die CLI nicht verfügbar ist. Bevorzugen Sie diese Fähigkeit für tokeneffiziente Browserarbeit, die durch stabile Barrierefreiheitsreferenzen wie „e5“ und „e12“ unterstützt wird.
