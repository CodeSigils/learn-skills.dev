Creazione, modifica e formattazione di documenti DOCX professionali utilizzando OpenXML SDK (.NET). Tre pipeline: (A) creare nuovi documenti da zero, (B) compilare/modificare il contenuto nei documenti esistenti, (C) applicare la formattazione del modello con il controllo del gate di convalida XSD. DEVE utilizzare questa capacità ogni volta che l'utente desidera produrre, modificare o formattare un documento Word, incluso quando dice "scrivi un rapporto", "redige una proposta", "stipula un contratto", "compila questo modulo", "riformatta per adattarlo a questo modello" o qualsiasi attività il cui output finale sia un file .docx. Anche se l'utente non menziona esplicitamente "docx", se l'attività implica un documento stampabile/formale, utilizza questa abilità.
