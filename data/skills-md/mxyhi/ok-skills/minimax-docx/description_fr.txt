Création, édition et formatage professionnels de documents DOCX à l'aide du SDK OpenXML (.NET). Trois pipelines : (A) créer de nouveaux documents à partir de zéro, (B) remplir/modifier le contenu des documents existants, (C) appliquer le formatage du modèle avec contrôle de validation XSD. DOIT utiliser cette compétence chaque fois que l'utilisateur souhaite produire, modifier ou formater un document Word, y compris lorsqu'il dit « rédiger un rapport », « rédiger une proposition », « conclure un contrat », « remplir ce formulaire », « reformater pour correspondre à ce modèle » ou toute tâche dont le résultat final est un fichier .docx. Même si l'utilisateur ne mentionne pas explicitement « docx », si la tâche implique un document imprimable/formel, utilisez cette compétence.
