Kimi WebBridge permet à l'IA de contrôler le véritable navigateur de l'utilisateur : naviguer, cliquer, saisir, lire, capturer et interagir avec n'importe quel site Web en utilisant les sessions de connexion réelles de l'utilisateur. Utilisez cette compétence chaque fois que l'utilisateur souhaite interagir avec des sites Web, automatiser les tâches du navigateur, récupérer du contenu Web ou effectuer toute action nécessitant un vrai navigateur. À utiliser également lorsque l'utilisateur mentionne « navigateur », « page Web », « URL ouverte », « capture d'écran » ou demande à lire/interagir avec un site Web. À utiliser même pour les requêtes de navigateur apparemment simples : le démon gère toute la complexité.
