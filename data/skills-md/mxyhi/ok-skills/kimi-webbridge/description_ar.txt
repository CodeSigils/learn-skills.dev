يتيح Kimi WebBridge للذكاء الاصطناعي التحكم في المتصفح الحقيقي للمستخدم — التنقل والنقر والكتابة والقراءة والتقاط لقطة الشاشة والتفاعل مع أي موقع ويب باستخدام جلسات تسجيل الدخول الفعلية للمستخدم. استخدم هذه المهارة عندما يريد المستخدم التفاعل مع مواقع الويب، أو أتمتة مهام المتصفح، أو استخراج محتوى الويب، أو تنفيذ أي إجراء يتطلب متصفحًا حقيقيًا. يُستخدم أيضًا عندما يذكر المستخدم "المتصفح"، أو "صفحة الويب"، أو "عنوان URL مفتوح"، أو "لقطة الشاشة"، أو يطلب القراءة/التفاعل مع أي موقع ويب. استخدمه حتى مع طلبات المتصفح البسيطة — حيث يتعامل البرنامج الخفي مع كل التعقيدات.
