Kimi WebBridge permite que la IA controle el navegador real del usuario: navegar, hacer clic, escribir, leer, realizar capturas de pantalla e interactuar con cualquier sitio web utilizando las sesiones de inicio de sesión reales del usuario. Utilice esta habilidad siempre que el usuario quiera interactuar con sitios web, automatizar tareas del navegador, extraer contenido web o realizar cualquier acción que requiera un navegador real. Utilícelo también cuando el usuario mencione "navegador", "página web", "abrir URL", "captura de pantalla" o solicite leer/interactuar con cualquier sitio web. Úselo incluso para solicitudes de navegador que parezcan simples: el demonio maneja toda la complejidad.
