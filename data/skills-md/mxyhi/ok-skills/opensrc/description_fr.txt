Récupérez le code source des dépendances pour donner aux agents IA un contexte de mise en œuvre plus approfondi. À utiliser lorsque l'agent a besoin de comprendre le fonctionnement d'une bibliothèque en interne, de lire le code source d'un package, de récupérer les détails d'implémentation d'une dépendance ou d'explorer comment un package npm/PyPI/crates.io est construit. Les déclencheurs incluent "récupérer la source de", "lire la source de", "comment X fonctionne en interne", "obtenir l'implémentation de", "chemin opensrc" ou toute tâche nécessitant un accès au code source des dépendances au-delà des types et des documents.
