Obtenga el código fuente de dependencia para brindar a los agentes de IA un contexto de implementación más profundo. Úselo cuando el agente necesite comprender cómo funciona internamente una biblioteca, leer el código fuente de un paquete, obtener detalles de implementación de una dependencia o explorar cómo se construye un paquete npm/PyPI/crates.io. Los desencadenantes incluyen "obtener la fuente de", "leer la fuente de", "cómo funciona X internamente", "obtener la implementación de", "ruta de opensrc" o cualquier tarea que requiera acceso al código fuente de dependencia más allá de tipos y documentos.
