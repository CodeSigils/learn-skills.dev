Rufen Sie den Abhängigkeitsquellcode ab, um KI-Agenten einen tieferen Implementierungskontext zu geben. Verwenden Sie diese Option, wenn der Agent verstehen muss, wie eine Bibliothek intern funktioniert, Quellcode für ein Paket lesen, Implementierungsdetails für eine Abhängigkeit abrufen oder untersuchen muss, wie ein npm/PyPI/crates.io-Paket erstellt wird. Zu den Auslösern gehören „Quelle abrufen für“, „Quelle lesen von“, „Wie funktioniert X intern“, „Implementierung abrufen von“, „opensrc-Pfad“ oder jede Aufgabe, die Zugriff auf Abhängigkeitsquellcode über Typen und Dokumente hinaus erfordert.
