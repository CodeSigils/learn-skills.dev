Uncle Hua Design: uso de HTML para crear prototipos, diapositivas, animaciones, visualizaciones y reseñas de expertos de alta fidelidad. Para cualquier diseño nuevo, 100% primero produce tres borradores de direcciones para que el usuario elija (incluso cuando se especifica un estilo o marca específica); Sólo después de la selección se ejecuta el trabajo. Palabras desencadenantes: crear prototipo, PPT, diapositiva, animación, estilo de diseño, revisar, crear una página HTML, maqueta de interfaz de usuario, exportar MP4/GIF, hacer algo atractivo. Las aplicaciones web o sistemas de producción que requieren un backend no son aplicables.
