Uncle Hua Design : utilise HTML pour créer des prototypes, des diapositives, des animations, des visualisations et des évaluations d'experts haute fidélité. Pour tout nouveau design, 100 % produit d'abord trois projets d'instructions parmi lesquels l'utilisateur peut choisir (même lorsqu'un style ou une marque spécifique est spécifié) ; ce n'est qu'après la sélection que le travail est exécuté. Mots déclencheurs : créer un prototype, un PPT, une diapositive, une animation, un style de conception, une révision, créer une page HTML, une maquette d'interface utilisateur, exporter un MP4/GIF, créer quelque chose d'attrayant. Les applications Web de niveau production ou les systèmes nécessitant un backend ne sont pas applicables.
