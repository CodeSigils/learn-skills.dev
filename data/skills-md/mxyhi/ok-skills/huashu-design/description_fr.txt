Flower Uncle Design : utilisation de HTML pour créer des prototypes, des diapositives, des animations, des visualisations et des avis d'experts haute fidélité. Pour tout nouveau design, nous produisons toujours d'abord trois ébauches directionnelles parmi lesquelles l'utilisateur peut choisir (même lorsqu'un style ou une marque spécifique est spécifié) ; ce n’est qu’après qu’une sélection est faite que nous procédons. Mots déclencheurs : créer un prototype, un PPT, une diapositive, une animation, un style de conception, une révision, créer une page HTML, une maquette d'interface utilisateur, exporter un MP4/GIF, créer quelque chose de beau. Les applications Web de niveau production ou les systèmes nécessitant un backend ne sont pas applicables.
