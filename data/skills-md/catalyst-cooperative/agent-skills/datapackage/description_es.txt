Explore y consulte cualquier conjunto de datos anotado con un descriptor de paquete de datos Frictionless (datapackage.json). Utilice esta habilidad siempre que un usuario quiera descubrir qué tablas o recursos contiene un conjunto de datos, buscar nombres y descripciones de columnas, mostrar advertencias de uso integradas en metadatos o comprender cómo cargar datos desde archivos Parquet, bases de datos DuckDB o SQLite, o archivos CSV descritos por un datapackage.json. Úselo también cuando el usuario tenga un datapackage.json y quiera saber qué contiene, cómo consultarlo de manera eficiente o cómo conectar sus metadatos a archivos de datos reales. Combina bien con habilidades específicas de conjuntos de datos (como `pudl`) que superponen el conocimiento del dominio.
