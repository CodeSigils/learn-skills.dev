Esplora ed esegui query su qualsiasi set di dati annotato con un descrittore del pacchetto dati Frictionless (datapackage.json). Utilizza questa competenza ogni volta che un utente desidera scoprire quali tabelle o risorse contiene un set di dati, cercare nomi e descrizioni di colonne, avvisi sull'utilizzo della superficie incorporati nei metadati o capire come caricare dati da file Parquet, database DuckDB o SQLite o file CSV descritti da un datapackage.json. Da utilizzare anche quando l'utente dispone di un datapackage.json e desidera sapere cosa contiene, come eseguirne una query in modo efficiente o come connettere i relativi metadati ai file di dati effettivi. Si abbina bene con competenze specifiche del set di dati (come "pudl") che sovrappongono la conoscenza del dominio.
