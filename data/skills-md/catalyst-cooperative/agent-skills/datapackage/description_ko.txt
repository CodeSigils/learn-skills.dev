무마찰 데이터 패키지 설명자(datapackage.json)로 주석이 달린 데이터 세트를 탐색하고 쿼리합니다. 사용자가 데이터세트에 포함된 테이블이나 리소스를 검색하고, 열 이름과 설명을 조회하고, 메타데이터에 포함된 표면 사용 경고를 검색하거나, Parquet 파일, DuckDB 또는 SQLite 데이터베이스 또는 datapackage.json에서 설명하는 CSV 파일에서 데이터를 로드하는 방법을 이해하려고 할 때마다 이 기술을 사용하세요. 또한 사용자가 datapackage.json을 가지고 있고 그 안에 무엇이 있는지, 효율적으로 쿼리하는 방법 또는 해당 메타데이터를 실제 데이터 파일에 연결하는 방법을 알고 싶을 때 사용합니다. 도메인 지식을 위에 얹은 데이터세트 관련 기술(예: 'pudl')과 잘 어울립니다.
