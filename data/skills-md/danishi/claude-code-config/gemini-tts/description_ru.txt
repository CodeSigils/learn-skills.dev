Создавайте аудио для чтения вслух (преобразование текста в речь) с помощью Google Gemini TTS (gemini-3.1-flash-tts-preview). Автоматически определяет режим на входе: повествование с одним динамиком для обычного текста и диалог с несколькими динамиками, когда на входе есть две метки динамика «Имя:». Поддерживает 30 встроенных голосов, управление в стиле естественного языка и аудиотеги, ввод текста или файлов и вывод WAV. Работает как с API Gemini Developer, так и с Vertex AI.
