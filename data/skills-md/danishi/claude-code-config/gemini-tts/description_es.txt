Genere audio de lectura en voz alta (texto a voz) utilizando Google Gemini TTS (gemini-3.1-flash-tts-preview). Detecta automáticamente el modo de la entrada: narración de un solo hablante para texto sin formato y diálogo de varios hablantes cuando la entrada tiene dos etiquetas de altavoz "Nombre:". Admite 30 voces prediseñadas, control de estilo de lenguaje natural y etiquetas de audio, entrada de texto o archivos y salida WAV. Funciona tanto con Gemini Developer API como con Vertex AI.
