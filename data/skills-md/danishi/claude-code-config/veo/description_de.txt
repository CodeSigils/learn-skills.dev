Erstellen Sie Videos mit Google Gemini Veo 3.1. Standardmäßig das kostengünstige Veo 3.1 Lite-Modell; Die Premium- (Veo 3.1) und Fast-Modelle werden nur verwendet, wenn dies explizit über --pro / --fast angefordert wird. Unterstützt Text-zu-Video und Bild-zu-Video (erstes Bild + optional letztes Bild), 16:9 / 9:16, 720p / 1080p (4k auf Pro), 4-8s-Clips und 1-4 Videos pro Anfrage. Funktioniert sowohl mit der Gemini Developer API als auch mit Vertex AI.
