Создавайте видео с помощью Google Gemini Veo 3.1. По умолчанию используется экономичная модель Veo 3.1 Lite; модели премиум-класса (Veo 3.1) и Fast используются только по явному запросу через --pro/--fast. Поддерживает преобразование текста в видео и изображения в видео (первый кадр + опционально последний кадр), 16:9/9:16, 720p/1080p (4k в версии Pro), клипы продолжительностью 4–8 секунд и 1–4 видео на запрос. Работает как с API Gemini Developer, так и с Vertex AI.
