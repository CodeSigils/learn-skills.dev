Создавайте музыкальные файлы с помощью Google Gemini Lyria 3. Автоматически выбирает лучшую модель в зависимости от запроса/цели: Lyria 3 Pro для полноформатных, структурированных песен с лирикой и Lyria 3 Clip для 30-секундных клипов, петель, джинглов и быстрого предварительного просмотра. Поддерживает подсказки жанра/настроения/инструмента, теги структуры песни, пользовательские тексты, вывод в формате MP3/WAV и работает как с Gemini Developer API, так и с Vertex AI.
