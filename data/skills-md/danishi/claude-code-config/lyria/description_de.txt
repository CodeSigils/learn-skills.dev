Generieren Sie Musikdateien mit Google Gemini Lyria 3. Wählt je nach Anforderung/Zweck automatisch das beste Modell aus: Lyria 3 Pro für vollständige, strukturierte, lyrische Songs und Lyria 3 Clip für 30-Sekunden-Clips, Loops, Jingles und schnelle Vorschauen. Unterstützt Genre-/Stimmungs-/Instrumenten-Eingabeaufforderungen, Songstruktur-Tags, benutzerdefinierte Liedtexte, MP3-/WAV-Ausgabe und funktioniert sowohl mit der Gemini Developer API als auch mit Vertex AI.
