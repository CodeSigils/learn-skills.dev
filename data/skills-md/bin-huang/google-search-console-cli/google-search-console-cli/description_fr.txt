Analyse des données de Google Search Console et gestion du site via google-search-console-cli. À utiliser lorsque l'utilisateur souhaite vérifier les performances de recherche, analyser les requêtes, inspecter l'état de l'index d'URL, gérer les plans de site ou afficher les propriétés du site. Déclencheurs : "Search Console", "performances de recherche", "requêtes de recherche", "GSC", "état de l'index", "inspection d'URL", "plan du site", "analyses de recherche", "impressions", "CTR", "apparence de recherche".
