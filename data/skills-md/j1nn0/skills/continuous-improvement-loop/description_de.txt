Führt autonome Software-Engineering-Verbesserungen in wiederholten, überprüfbaren Runden durch, bis das Repository konvergiert: In jeder Runde wird der aktuelle Status neu bewertet, eine lohnenswerte Verbesserung ausgewählt, die Agenten-Orchestrierung zur Untersuchung und Implementierung verwendet, das Ergebnis überprüft und festgeschrieben und dann anhand des neuen Repository-Status entschieden, ob eine weitere Runde gerechtfertigt ist. Verwenden Sie diese Option, wenn der Benutzer möchte, dass sich eine Codebasis selbstständig weiter verbessert, anstatt eine feste Aufgabenliste abzuarbeiten. Erfordert die Fähigkeit zur Agenten-Orchestrierung, wenn eine Runde die unten definierten Delegationskriterien erfüllt.
