Runs autonomous software-engineering improvement as repeated, reviewable rounds until the repository converges: each round reassesses the current state, selects one worthwhile improvement, uses agent-orchestration for investigation and implementation, verifies and commits the result, then decides from the new repository state whether another round is justified. Use when the user wants a codebase to keep improving autonomously rather than complete a fixed task list. Requires the agent-orchestration skill when a round meets the delegation criteria defined below.
