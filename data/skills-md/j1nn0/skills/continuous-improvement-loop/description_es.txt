Ejecuta mejoras autónomas de ingeniería de software en rondas repetidas y revisables hasta que el repositorio converge: cada ronda reevalúa el estado actual, selecciona una mejora que vale la pena, utiliza la orquestación de agentes para la investigación y la implementación, verifica y confirma el resultado, luego decide a partir del nuevo estado del repositorio si se justifica otra ronda. Úselo cuando el usuario quiera que una base de código siga mejorando de forma autónoma en lugar de completar una lista de tareas fija. Requiere la habilidad de orquestación de agente cuando una ronda cumple con los criterios de delegación definidos a continuación.
