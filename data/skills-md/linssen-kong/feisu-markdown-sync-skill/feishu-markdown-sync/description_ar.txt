قم بتصدير محتوى صفحة Feishu wiki وdoc وSheet إلى ملفات Markdown وCSV والمصنفات والمعاينة وتنسيق ملفات اللقطات الملائمة لـ Git؛ فحص مساحات عمل المزامنة المدعومة بالبيان وسحبها وتخطيطها ودفعها بشكل محمي؛ إدارة ملفات Markdown الأصلية في Drive بشكل منفصل؛ كتابة بيانات مجموعة CSV أو JSON 2D مرة أخرى في نطاقات ورقة Feishu الصريحة مع التحقق من إعادة القراءة؛ صور المستندات المضمنة؛ وتوسيع الأوراق المضمنة إلى معاينات CSV بالإضافة إلى Markdown؛ تحويل ألواح المعلومات الخام إلى معاينات حورية البحر قابلة للقراءة بالإضافة إلى ملفات تدقيق JSON الأولية؛ سهولة قراءة التدقيق والإخلاص ذهابًا وإيابًا؛ وأعد استيراد Markdown مرة أخرى إلى مستندات Feishu مع صورة الموضع الأصلي واستعادة الملف عبر إدراج الوسائط الموضوعة في lark-cli. يُستخدم عندما يطلب المستخدم مزامنة محتوى Feishu wiki أو docx أو Sheet أو محتوى Markdown الأصلي أو تصديره أو أرشفته أو تدقيقه أو إعادة استيراده بطريقة متوافقة مع Git.
