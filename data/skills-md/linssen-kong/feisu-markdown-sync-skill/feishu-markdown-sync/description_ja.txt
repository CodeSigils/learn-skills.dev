Feishu wiki、ドキュメント、シート ページのコンテンツを Git 対応のマークダウン、CSV、ワークブック、プレビュー、およびフォーマット スナップショット ファイルにエクスポートします。マニフェストに基づく同期ワークスペースの検査、プル、計画、およびガードプッシュ。ドライブネイティブの Markdown ファイルを個別に管理します。リードバック検証を使用して、CSV または JSON 2D 配列データを明示的な Feishu Sheet 範囲に書き込みます。インラインドキュメント画像。埋め込みシートを CSV と Markdown プレビューに展開します。生のホワイトボードを読み取り可能な Mermaid プレビューと生の JSON 監査ファイルに変換します。監査の可読性とラウンドトリップ忠実度。そして、lark-cli で配置されたメディア挿入を介して、元の位置のイメージとファイルの復元を使用して、Markdown を Feishu ドキュメントに再インポートします。ユーザーが Git に適した方法で Feishu wiki、docx、Sheet、または Drive-native Markdown コンテンツを同期、エクスポート、アーカイブ、監査、または再インポートするように要求する場合に使用します。
