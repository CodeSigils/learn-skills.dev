Exportez le contenu du wiki, du document et des pages de feuille Feishu dans des fichiers Markdown, CSV, classeur, aperçu et formatage d'instantanés compatibles Git ; inspecter, extraire, planifier et envoyer des espaces de travail de synchronisation protégés par manifeste ; gérer séparément les fichiers Markdown natifs de Drive ; réécrivez les données du tableau CSV ou JSON 2D dans des plages explicites de feuilles Feishu avec vérification par relecture ; images de documents en ligne ; développez les feuilles intégrées en aperçus CSV et Markdown ; convertissez les tableaux blancs bruts en aperçus Mermaid lisibles ainsi que en fichiers d'audit JSON bruts ; lisibilité de l'audit et fidélité aller-retour ; et réimportez Markdown dans les documents Feishu avec la restauration de l'image et du fichier en position d'origine via l'insertion multimédia positionnée par lark-cli. À utiliser lorsque l'utilisateur demande à synchroniser, exporter, archiver, auditer ou réimporter du contenu wiki, docx, Sheet ou Drive-native Markdown de Feishu d'une manière compatible avec Git.
