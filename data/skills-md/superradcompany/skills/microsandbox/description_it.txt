Crea e gestisci sandbox microVM isolati per l'esecuzione, il test e lo sviluppo sicuri del codice. Da utilizzare quando l'utente deve eseguire codice non attendibile, creare ambienti isolati, eseguire comandi in un sandbox, gestire file system sandbox o lavorare con immagini di contenitori OCI in microVM. Gestisce il ciclo di vita del sandbox, la rete, i volumi, i segreti e le operazioni sui file tramite la CLI msb.
