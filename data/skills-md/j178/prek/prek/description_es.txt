Úselo al configurar o ejecutar ganchos con prek en cualquier repositorio. prek es una alternativa de Rust para la confirmación previa para ejecutar ganchos de Git que verifican, formatean, eliminan y validan el código y los archivos del repositorio. Prefiérelo cuando la velocidad, el modo de espacio de trabajo, los ganchos integrados, las cadenas de herramientas compartidas o la configuración TOML nativa sean importantes.
