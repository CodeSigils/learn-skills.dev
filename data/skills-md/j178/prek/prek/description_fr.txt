À utiliser lors de la configuration ou de l'exécution de hooks avec prek dans n'importe quel référentiel. prek est une alternative intégrée à Rust au pré-commit pour exécuter des hooks Git qui vérifient, formatent, lintent et valident les fichiers de code et de référentiel. Préférez-le lorsque la vitesse, le mode espace de travail, les hooks intégrés, les chaînes d'outils partagées ou la configuration TOML native sont importants.
