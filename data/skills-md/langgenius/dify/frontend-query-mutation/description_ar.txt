دليل لتنفيذ استعلام الواجهة الأمامية Dify وأنماط الطفرات باستخدام TanStack Query وoRPC. يتم التشغيل عند إنشاء أو تحديث العقود في الويب/العقد، أو تكوين جهاز توجيه الأسلاك، أو استهلاك وحدة التحكم أو استعلام السوق في المكونات أو الخدمات، أو تحديد ما إذا كان سيتم استدعاء queryOptions() مباشرة أو استخراج مساعد أو ربط استخدام-*، أو التعامل مع الاستعلامات المشروطة، أو إبطال ذاكرة التخزين المؤقت، أو معالجة أخطاء الطفرة، أو ترحيل مكالمات الخدمة القديمة إلى استعلام العقد الأول ومساعدي الطفرة.
