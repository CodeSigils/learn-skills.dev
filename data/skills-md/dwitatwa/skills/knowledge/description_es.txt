Utilice esta habilidad cuando el usuario necesite crear, reparar, consultar, actualizar o estandarizar una carpeta `.knowledge` local de repositorio como un espacio de trabajo personal de segundo cerebro. Admite el arranque de un sistema de conocimiento de tres capas a partir de documentos de diseño, notas de investigación o memoria de proyecto, con capas de "fuentes", "conocimiento" y "reglas", además de plantillas estilo Zettelkasten para literatura, permanente, estructura, preguntas abiertas y notas fuente. Úselo cuando el usuario solicite un segundo cerebro, una bóveda de conocimientos, un sistema de notas, una memoria de proyecto duradera en archivos, quiera encontrar lo que el repositorio ya sabe sobre un tema a partir de ".knowledge" o quiera mantener un registro de los cambios de conocimiento después de las actualizaciones o fusiones del repositorio. No lo utilice para sitios de documentación genéricos, contenido wiki o funciones de aplicaciones no relacionadas con un espacio de trabajo `.knowledge`.
