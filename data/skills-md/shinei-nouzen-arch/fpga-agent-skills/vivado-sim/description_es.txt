Utilice esta habilidad cuando el usuario necesite ayuda con la estrategia de simulación, la selección de flujo y la depuración de Vivado. Esto incluye simulación de comportamiento (verificación funcional RTL), simulación posterior a la síntesis (verificación funcional de netlist), simulación de tiempo posterior a la implementación (anotación posterior SDF, verificación de tiempo), uso de Vivado Simulator xsim (flujo de tres pasos xvlog/xvhdl/xelab/xsim, modo de proyecto launch_simulation), integración de simuladores de terceros (Questa/ModelSim/VCS/Xcelium/Riviera/ActiveHDL, compile_simlib, export_simulation), simulación de potencia SAIF/VCD (open_saif/log_saif, open_vcd/log_vcd, read_saif + report_power), generación de lista de red de simulación (write_verilog -mode funcsim/timesim, write_sdf), comandos de depuración xsim (add_force, add_wave, log_wave, add_bp, step, run, restart, get_objects, get_value), propiedades de simulación y configuraciones, uso de glbl.v o cualquier pregunta sobre cómo elegir el enfoque de simulación correcto para la verificación o el análisis de potencia.
