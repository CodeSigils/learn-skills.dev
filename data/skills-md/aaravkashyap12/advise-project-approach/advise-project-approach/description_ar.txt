البحث وتقديم المشورة بشأن أفضل طريقة للتعامل مع مشروع برمجي، بما في ذلك الهندسة المعمارية، والمكدس التكنولوجي، واستراتيجية التنفيذ، ومقايضات التسعير/تكلفة التشغيل، والبحث المعياري، والمقارنات مع مشاريع العالم الحقيقي المماثلة. يُستخدم قبل البناء، أو في منتصفه، أو بعد الانتهاء عندما يسأل المستخدم عن استراتيجية المشروع، أو النهج الأمثل، أو مقارنات البحث، أو المشاريع المماثلة، أو اختيار المكدس، أو اختيار البائع/الخدمة، أو تحليل الريبو، أو نقد البنية، أو تعليقات التنفيذ، أو خطة تحسين ذات أولوية. تجنب تصحيح الأخطاء المفردة الضيقة أو عمليات تحرير الملفات المعزولة ما لم يطلب المستخدم توجيهًا أوسع للمشروع.
