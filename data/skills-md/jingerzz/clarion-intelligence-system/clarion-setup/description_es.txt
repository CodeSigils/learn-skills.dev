Inicia el sistema de inteligencia Clarion en Zo Computer. Ejecute esto una vez después de instalar la habilidad: clona el repositorio fuente, instala la biblioteca Python ai_buffett_zo, crea el espacio de trabajo ~/clarion/, escribe la configuración predeterminada y registra el servicio en segundo plano sec-indexer. Idempotente (es seguro volver a ejecutarlo). Úselo cuando el usuario solicite "configurar Clarion", "instalar Clarion" o después de instalar cualquier otra habilidad clarion-* antes de que se haya iniciado.
