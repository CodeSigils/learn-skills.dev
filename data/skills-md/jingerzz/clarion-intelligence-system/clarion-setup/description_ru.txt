Запускает интеллектуальную систему Clarion на компьютере Zo. Запустите это один раз после установки навыка — клонирует репозиторий исходного кода, устанавливает библиотеку Python ai_buffett_zo, создает рабочую область ~/clarion/, записывает конфигурацию по умолчанию и регистрирует фоновую службу sec-indexer. Идемпотент (безопасен для повторного запуска). Используйте, когда пользователь просит «настроить Clarion», «установить Clarion» или после установки любого другого навыка Clarion-* до его начальной загрузки.
