Создайте новый тезисный документ для тикера в каноническом формате тезисов Clarion. Предварительно заполняет блок метаданных YAML, открывает историю с ОТКРЫТОЙ записью и (когда документы проиндексированы) заполняет раздел доказательств «Почему я этому верю» черновиками цитат из поиска с помощью линзы Баффета. Пользователь заполняет фактическую прозу. Выводит файл уценки по адресу ~/clarion/theses/{TICKER}.md. Используйте, когда пользователь говорит «написать тезис по <TICKER>», «подготовить тезис для <TICKER>», «составить проект тезиса по <TICKER>» или после того, как Clarion-single-stock-eval возвращает вердикт «Добавить», и пользователь хочет формализовать позицию. Для запуска требуется установка Clarion.
