Erstellen Sie ein neues Abschlussdokument für einen Ticker im kanonischen Clarion-Abschlussformat. Füllt den YAML-Metadatenblock vorab aus, öffnet den Verlauf mit einem GEÖFFNETEN Eintrag und füllt (wenn Einreichungen indiziert werden) den Beweisabschnitt „Warum ich daran glaube“ mit Zitatentwürfen aus der Buffett-Linsen-Suche. Der Benutzer trägt die eigentliche Prosa ein. Gibt eine Markdown-Datei unter ~/clarion/theses/{TICKER}.md aus. Verwenden Sie diese Option, wenn der Benutzer sagt: „Schreiben Sie eine Abschlussarbeit über <TICKER>“, „Gerüst für eine Abschlussarbeit für <TICKER>“, „Entwerfen Sie eine Abschlussarbeit für <TICKER>“ oder nachdem clarion-single-stock-eval ein Add-Urteil zurückgibt und der Benutzer die Position formalisieren möchte. Erfordert die Ausführung von clarion-setup.
