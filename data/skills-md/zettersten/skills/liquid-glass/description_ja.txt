CSS および SVG ディスプレイスメント フィルターを使用して、Apple の液体ガラス UI エフェクト (iOS 26 / macOS 26) を実装します。液体ガラス エフェクト、すりガラス コンポーネント、iOS 26 ガラス UI、屈折を伴うガラスモーフィズム、ガラス ボタン/カード/ナビゲーションバー、feDisplacementMap 屈折効果、または背景コンテンツの現実的なガラスのような歪みを必要とする UI を作成するように求められた場合は、このスキルを使用します。物理学 (スネルの法則、SDF) からすぐに使える HTML/React/CSS テンプレートまで、完全なテクニックを教えます。
