Go Unit Test (UT) scrive la specifica e l'elenco di controllo dell'implementazione (per impostazione predefinita è filtrabile con `-run=TestUnit`), fornendo sei modelli di test pronti all'uso: test di base, test guidati da tabelle, test con metodo struct, test simultanei, test di benchmark e test di gestione degli errori. Utilizza gomonkey/gomock/testify per derisioni e asserzioni, supportando test guidati da tabelle, test benchmark, test simultanei e altri scenari.
