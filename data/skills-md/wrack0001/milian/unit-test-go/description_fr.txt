Go guide de rédaction de tests unitaires (UT) et liste de contrôle de déploiement (par défaut peut être filtré avec `-run=Test`), fournissant des modèles prêts à copier pour 6 domaines : de base, basés sur des tables, méthodes de structure, simultanées, de référence et gestion des erreurs. Utilisez gomonkey/gomovk/testify pour les moqueries et les assertions, couvrant les tests basés sur des tables, les tests de référence, les tests simultanés, etc.
