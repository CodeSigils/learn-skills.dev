Diese Fähigkeit sollte beim Suchen, Verfolgen oder Verstehen von Code in einem Repository verwendet werden
mit SymDex verfügbar. Lösen Sie es für Anfragen aus wie „Wo ist das definiert?“, „Wer
ruft das auf?“, „Welche Route verarbeitet diesen Pfad?“, „Zeige mir die Dateigliederung“, „Suche
„diese Codebasis absichtlich“ oder jede Aufgabe, die andernfalls auf breites Lesen/Grep/Glob angewiesen wäre
Erkundung.
