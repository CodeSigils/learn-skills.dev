Cette compétence doit être utilisée lors de la recherche, du traçage ou de la compréhension du code dans un référentiel
avec SymDex disponible. Déclenchez-le pour des requêtes telles que « où est-ce défini ? », « qui
appelle ça ?", "quelle route gère ce chemin ?", "montre-moi le plan du fichier", "recherche
cette base de code intentionnellement", ou toute tâche qui autrement reposerait sur une large lecture/Grep/Glob
exploration.
