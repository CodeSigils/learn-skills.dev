Анализ журналов JSONL сеанса OpenClaw и загрузка структурированной телеметрии в Langfuse
через API телеметрии кошелька Cobo Agentic. Ноль внешних зависимостей — только
требуется Python 3 и действительная установка CAW (ключ API определяется автоматически).
Используйте, когда: пользователь хочет проанализировать сеанс OpenClaw, загрузить телеметрию сеанса,
просматривать трассировки сеансов в Langfuse или отлаживать поведение агента OpenClaw.
