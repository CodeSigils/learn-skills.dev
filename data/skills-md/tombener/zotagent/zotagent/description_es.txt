Search, retrieve, inspect, add, or edit Zotero literature via the `zotagent` CLI. Cargue esta habilidad siempre que el usuario quiera consultar su biblioteca de Zotero (palabra clave/semántica/metadatos), extraer citas o contexto de artículos indexados, agregar elementos por DOI, URL de página web, identificador ISBN/PMID/arXiv, paperId de Semantic Scholar, JSON o metadatos manuales, cambiar elementos existentes (corregir un campo, agregar o eliminar etiquetas, archivar en una colección, adjuntar una nota, eliminar un elemento), inspeccionar elementos recientes de Zotero o diagnosticar archivos adjuntos indexados. Use it even on indirect requests — any mention of references, citations, bibliography checks, PDF passages, or literature discovery. Do not guess at zotagent's flags — consult this reference first.
