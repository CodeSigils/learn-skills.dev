Suchen, abrufen, prüfen, hinzufügen oder bearbeiten Sie Zotero-Literatur über die „zotagent“-CLI. Laden Sie diesen Skill immer dann, wenn der Benutzer seine Zotero-Bibliothek abfragen möchte (Stichwort/Semantik/Metadaten), Zitate oder Kontext aus indizierten Artikeln abrufen, Elemente nach DOI, Webseiten-URL, ISBN/PMID/arXiv-Kennung, Semantic Scholar paperId, JSON oder manuellen Metadaten hinzufügen, vorhandene Elemente ändern (ein Feld reparieren, Tags hinzufügen oder entfernen, in einer Sammlung ablegen, eine Notiz anhängen, ein Element in den Papierkorb verschieben), aktuelle Zotero-Elemente überprüfen oder indizierte Anhänge diagnostizieren möchte. Verwenden Sie es auch bei indirekten Anfragen – jeder Erwähnung von Referenzen, Zitaten, Bibliographieprüfungen, PDF-Passagen oder Literaturentdeckungen. Raten Sie nicht über die Flags von Zotagent – ​​konsultieren Sie zuerst diese Referenz.
