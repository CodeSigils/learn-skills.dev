ユーザーが GPU プールまたは GPU クラスターの容量を分析したり、トラフィック、QPS、または推論負荷の増大におけるボトルネックを予測したり、スケーリング、スロットル、ルーティング変更のいずれかを選択することを要求した場合に使用します。 GPU 池/収集群容量、流量上涨、QPS 增长、滞在负下增长、哪个 GPU 池先成為瓶颈、否扩容/限界流/改路由に関する中国語のリクエストにも使用します。プロンプトの例には、「如果今晚流量上涨 30%，哪个 GPU 池会先成的瓶颈?」、「建议扩容、制限流还是改路由?」、「どの GPU プールが最初にボトルネックになるか」、「トラフィックが X% 増加したらどうなるか」などがあります。
