قم ببناء مكونات وشاشات واجهة المستخدم التي تظل قيد المراجعة - التخطيط، والتباعد، ومقياس الكتابة، واللون والتباين، وتشريح المكونات، وتغطية الحالة الكاملة، وإمكانيات إمكانية الوصول. يُستخدم عند كتابة أو إعادة تصميم أي كود واجهة (React، Vue، Svelte، HTML/CSS، SwiftUI، أصلي)، أو بناء مكون أو شاشة، أو إعداد نظام تصميم أو رموز مميزة، أو عندما يتم إنشاء واجهة مستخدم وتبدو عامة أو ضيقة أو غير مكتملة. استخدمه أيضًا عندما يُطلب منك جعل شيء ما "يبدو أفضل" أو يطابق التصميم.
