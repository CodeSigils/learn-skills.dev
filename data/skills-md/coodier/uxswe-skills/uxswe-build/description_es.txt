Cree componentes de interfaz de usuario y pantallas que resistan la revisión: diseño, espaciado, escala de texto, color y contraste, anatomía de los componentes, cobertura estatal completa y posibilidades de accesibilidad. Úselo al escribir o cambiar el estilo de cualquier código de interfaz (React, Vue, Svelte, HTML/CSS, SwiftUI, nativo), crear un componente o pantalla, configurar un sistema de diseño o tokens, o cuando se creó una interfaz de usuario y parece genérica, estrecha o sin terminar. Úselo también cuando se le solicite hacer que algo "se vea mejor" o combine con un diseño.
