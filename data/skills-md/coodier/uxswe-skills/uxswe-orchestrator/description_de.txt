Leiten Sie die UI-Arbeit zwischen Erstellung und Überprüfung weiter und führen Sie die Build-Evaluate-Repair-Schleife aus, bis die Schnittstelle funktioniert. Verwenden Sie diese Option, wenn eine UI-Aufgabe sowohl erstellt als auch überprüft werden muss („Erstellen Sie dies und stellen Sie sicher, dass es gut ist“, „Versandbereit“, „Produktionsqualität“), wenn der richtige nächste Schritt unklar ist oder wenn eine Schnittstelle anhand von Überprüfungsergebnissen repariert wird. Für einen reinen Build verwenden Sie uxswe-build direkt; Für eine reine Überprüfung verwenden Sie direkt uxswe-evaluate.
