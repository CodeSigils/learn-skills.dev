استخدم هذه المهارة عندما يريد المستخدم التفاعل مع Jira أو Confluence. يتضمن ذلك إنشاء أو قراءة أو تحديث أو حذف مشكلات Jira أو المشاريع أو الدورات السريعة أو اللوحات أو المكونات أو الإصدارات أو المرفقات أو التعليقات أو سجلات العمل أو المستخدمين أو المجموعات أو الأذونات. استخدمه أيضًا لأي عملية Confluence: الصفحات، أو المسافات، أو التسميات، أو المرفقات، أو القوالب، أو لوحات المعلومات، أو التعليقات، أو البحث (CQL)، أو أذونات المساحة. قم بتشغيل عبارات مثل "إنشاء مشكلة Jira"، أو "تحديث صفحة التقاء"، أو "البحث عن مشكلات في JQL"، أو "إضافة تعليق إلى التذكرة"، أو "الحصول على معلومات العدو السريع"، أو "قائمة مساحات التقاء"، أو "تصدير الصفحة بتنسيق PDF"، أو أي طلب يتضمن أدوات Atlassian. قم دائمًا باستدعاء هذه المهارة قبل الإجابة على أسئلة Jira أو Confluence، حتى لو لم يقل المستخدم صراحةً "استخدم المهارة".
