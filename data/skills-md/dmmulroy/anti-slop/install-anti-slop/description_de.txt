Installieren und konfigurieren Sie das Anti-Slop-Oxlint-Plugin in einem lokalen TypeScript- oder JavaScript-Repository. Verwenden Sie es immer dann, wenn ein Benutzer Anti-Slop-Lint-Regeln hinzufügen, das Anti-Slop-Plugin kopieren, eigene Oxlint-Regeln konfigurieren oder ein vorhandenes lokales Anti-Slop-Setup migrieren möchte.
