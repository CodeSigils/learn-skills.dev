Преобразует проекты Figma в готовый к использованию код приложения с визуальной точностью 1:1. Используйте при реализации кода пользовательского интерфейса из файлов Figma, когда пользователь упоминает «проектирование реализации», «создание кода», «компонент реализации», «код из Figma» или просит создать код приложения, соответствующий спецификациям Figma. НЕ для просмотра/анализа проектов (вместо этого используйте Design-Review). Для записи холста Figma через use_figma используйте figcraft-use.
