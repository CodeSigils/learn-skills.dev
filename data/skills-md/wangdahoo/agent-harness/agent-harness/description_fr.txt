Framework pour les agents d'IA de longue durée qui fonctionnent sur plusieurs fenêtres contextuelles. À utiliser lorsque Claude doit exécuter des projets complexes multi-sessions qui nécessitent : (1) Décomposer les exigences importantes en fonctionnalités gérables, (2) Suivre les progrès sur plusieurs sessions, (3) Maintenir le contexte entre les réinitialisations de la fenêtre contextuelle, (4) Coordonner les agents de sprint (planification) et de codage (implémentation), (5) Gérer les dépendances et la priorisation des fonctionnalités, (6) Assurer la qualité du code et l'état de fonctionnement à chaque fin de session. Basé sur les recherches d'Anthropic sur les harnais efficaces pour les agents à long terme.
