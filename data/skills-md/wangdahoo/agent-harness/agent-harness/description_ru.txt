Платформа для долговременных агентов ИИ, работающих в нескольких контекстных окнах. Используйте, когда Клоду необходимо выполнить сложные, многосессионные проекты, требующие: (1) разбивки больших требований на управляемые функции, (2) отслеживания прогресса в нескольких сеансах, (3) поддержания контекста между сбросами контекстных окон, (4) координации агентов спринта (планирование) и кодирования (реализация), (5) управления зависимостями функций и определения приоритетов, (6) обеспечения качества кода и рабочего состояния в конце каждого сеанса. На основе исследований Anthropic по эффективным ремням безопасности для долгоживущих агентов.
