Шаблоны API EVE Online ESI и интеграция с zkillboard. Охватывает конечные точки ESI, аутентификацию, модели данных, прослушиватель zkillboard RedisQ, стратегии кэширования и идентификаторы, специфичные для EVE (персонажи, корпорации, альянсы, корабли, системы, регионы). Используйте при работе с данными killmail, получении информации о вселенной EVE или реализации вызовов ESI.
