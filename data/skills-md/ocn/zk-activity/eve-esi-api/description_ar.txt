أنماط EVE Online ESI API وتكامل zkillboard. يغطي نقاط نهاية ESI والمصادقة ونماذج البيانات ومستمع zkillboard RedisQ واستراتيجيات التخزين المؤقت والمعرفات الخاصة بـ EVE (الشخصيات والشركات والتحالفات والسفن والأنظمة والمناطق). يُستخدم عند العمل مع بيانات Killmail، أو جلب معلومات EVE Universe، أو تنفيذ مكالمات ESI.
