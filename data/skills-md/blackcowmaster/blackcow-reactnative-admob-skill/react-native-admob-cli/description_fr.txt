Adaptateur AdMob Bare React Native CLI pour les annonces React-Native-Google-Mobile. À utiliser uniquement lorsque le projet est React Native CLI ou une application native RN nue avec ios/ et android/, et que l'utilisateur demande à intégrer, configurer, déboguer ou auditer le code Google Mobile Ads/AdMob, le consentement, l'ATT, les identifiants de test, la bannière, l'interstitiel, la récompense, l'emplacement ouvert de l'application ou la préparation à la publication. Ne pas utiliser pour les applications gérées par Expo, les applications Flutter, l'automatisation générique de la console AdMob ou le déploiement en magasin, sauf pour acheminer vers la compétence appropriée.
