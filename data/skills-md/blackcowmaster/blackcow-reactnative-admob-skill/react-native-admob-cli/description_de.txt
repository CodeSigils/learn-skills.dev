Bare React Native CLI AdMob-Adapter für React-Native-Google-Mobile-Ads. Nur verwenden, wenn es sich bei dem Projekt um eine reine React Native-CLI oder eine reine native RN-App mit ios/ und android/ handelt und der Benutzer die Integration, Konfiguration, Fehlerbehebung oder Prüfung von Google Mobile Ads/AdMob-Code, Einwilligung, ATT, Test-IDs, Banner, Interstitial, Belohnung, App-Open-Placement oder Veröffentlichungsbereitschaft anfordert. Nicht für von Expo verwaltete Apps, Flutter-Apps, generische AdMob-Konsolenautomatisierung oder Store-Bereitstellung verwenden, außer zur Weiterleitung an den entsprechenden Skill.
