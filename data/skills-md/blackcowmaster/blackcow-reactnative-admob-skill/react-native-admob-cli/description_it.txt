Adattatore AdMob CLI Bare React Native per annunci react-native-google-mobile. Utilizzare solo quando il progetto è una CLI React Native semplice o un'app nativa RN semplice con ios/ e android/ e l'utente chiede di integrare, configurare, eseguire il debug o controllare il codice Google Mobile Ads/AdMob, il consenso, l'ATT, gli ID test, i banner, gli interstitial, i premi, il posizionamento all'apertura dell'app o la disponibilità del rilascio. Non utilizzare per app gestite da Expo, app Flutter, automazione generica della console AdMob o distribuzione in negozio se non per instradare alla competenza appropriata.
