Bare React Native CLI AdMob adapter for react-native-google-mobile-ads. Use only when the project is bare React Native CLI or a bare RN native app with ios/ and android/, and the user asks to integrate, configure, debug, or audit Google Mobile Ads/AdMob code, consent, ATT, test IDs, banner, interstitial, rewarded, app-open placement, or release readiness. Do not use for Expo-managed apps, Flutter apps, generic AdMob console automation, or store deployment except to route to the appropriate skill.
