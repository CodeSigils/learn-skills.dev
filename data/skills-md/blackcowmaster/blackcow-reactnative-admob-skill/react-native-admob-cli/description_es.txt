Adaptador de AdMob CLI nativo de React para reaccionar-nativo-google-mobile-ads. Úselo solo cuando el proyecto sea React Native CLI simple o una aplicación nativa RN simple con ios/ y android/, y el usuario solicite integrar, configurar, depurar o auditar el código de Google Mobile Ads/AdMob, consentimiento, ATT, ID de prueba, banner, intersticial, recompensa, ubicación de apertura de aplicación o preparación para el lanzamiento. No lo use para aplicaciones administradas por Expo, aplicaciones Flutter, automatización genérica de la consola de AdMob o implementación de tiendas, excepto para dirigirlo a la habilidad adecuada.
