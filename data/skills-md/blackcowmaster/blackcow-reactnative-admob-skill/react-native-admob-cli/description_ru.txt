Адаптер Bare React Native CLI AdMob для React-native-google-mobile-ads. Используйте только в том случае, если проект представляет собой простой интерфейс командной строки React Native или чистое собственное приложение RN с ios/ и android/, и пользователь запрашивает интеграцию, настройку, отладку или аудит кода Google Mobile Ads/AdMob, согласие, ATT, тестовые идентификаторы, баннер, межстраничное объявление, вознаграждение, размещение с открытым приложением или готовность к выпуску. Не используйте для приложений, управляемых Expo, приложений Flutter, общей автоматизации консоли AdMob или развертывания в магазине, за исключением перенаправления к соответствующему навыку.
