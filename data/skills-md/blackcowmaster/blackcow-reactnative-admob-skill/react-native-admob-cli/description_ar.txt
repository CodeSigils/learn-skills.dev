محول Bare React Native CLI AdMob لإعلانات الهاتف المحمول التفاعلية الأصلية. يُستخدم فقط عندما يكون المشروع مجردًا من React Native CLI أو تطبيق RN أصلي مع ios/ وandroid/، ويطلب المستخدم دمج أو تكوين أو تصحيح الأخطاء أو تدقيق كود Google Mobile Ads/AdMob، أو الموافقة، أو ATT، أو معرفات الاختبار، أو الشعار، أو الإعلان البيني، أو المكافأة، أو الموضع المفتوح للتطبيق، أو الاستعداد للإصدار. لا تستخدم للتطبيقات التي يديرها Expo، أو تطبيقات Flutter، أو أتمتة وحدة تحكم AdMob العامة، أو نشر المتجر إلا للتوجيه إلى المهارة المناسبة.
