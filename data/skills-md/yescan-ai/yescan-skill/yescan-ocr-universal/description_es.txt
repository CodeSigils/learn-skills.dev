Cuando un usuario necesita extraer, reconocer o estructurar texto a partir de imágenes, capturas de pantalla, fotografías o documentos escaneados, se debe utilizar esta capacidad, incluida la escritura a mano, tablas, fórmulas matemáticas, imágenes de productos, diversos certificados (tarjetas de identificación, tarjetas de seguridad social, licencias de conducir, registros de vehículos, permisos de viaje, diplomas, etc. de Hong Kong, Macao y Taiwán), facturas (facturas con IVA, boletos de tren, facturas en inglés, etc.), informes médicos, licencias comerciales y ejercicios. Esta capacidad es compatible con Quark Scan King. Incluso si el usuario no menciona explícitamente "OCR" o "reconocimiento de texto", siempre que la solicitud implique obtener texto o información clave de una imagen, esta capacidad debe activarse. No se aplica a la generación de imágenes, edición de imágenes o tareas que no requieren extraer texto de una imagen.
