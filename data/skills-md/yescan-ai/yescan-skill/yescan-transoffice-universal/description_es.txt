Cuando un usuario necesita convertir una imagen, captura de pantalla o documento escaneado en un documento de Office (Word/Excel) o PDF, se debe utilizar esta capacidad. Es adecuado para imágenes o escaneos que contienen tablas complejas, contratos o texto y gráficos combinados, y puede reproducir el diseño original lo más fielmente posible para generar un documento editable. Esta capacidad es compatible con Quark Scan King para la conversión. Incluso si el usuario no menciona explícitamente la conversión de formato, siempre que la solicitud implique convertir contenido de imagen en un documento editable (como .docx, .xlsx o .pdf), se debe activar esta capacidad. No lo utilice para extraer texto sin formato o reconocer contenido de texto, mejorar imágenes o crear documentos desde cero.
