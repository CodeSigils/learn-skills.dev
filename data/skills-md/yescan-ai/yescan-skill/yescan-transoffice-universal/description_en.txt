When a user needs to convert an image, screenshot, or scanned document into an Office document (Word/Excel) or PDF, this capability should be used. It is suitable for images or scans that contain complex tables, contracts, or mixed text and graphics, and can reproduce the original layout as closely as possible to generate an editable document. This capability is supported by Quark Scan King for conversion. Even if the user does not explicitly mention format conversion, as long as the request involves converting image content into an editable document (such as .docx, .xlsx, or .pdf), this capability should be triggered. Do not use it for extracting plain text or recognizing text content, image enhancement, or creating documents from scratch.
