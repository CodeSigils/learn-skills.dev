Lorsque vous souhaitez créer, adapter ou mettre à jour une compétence Claude Code dans l'un de vos dépôts frères (répertoriez vos propres dépôts dans ~/.config/makerskills/skillify/repos.yaml ; par défaut, makerskills). Itinéraires vers le bon mode automatiquement. Modes — CREATE (à partir d'un chat / à partir d'une vidéo / à partir d'un dump / à partir de zéro) transforme un flux de travail, un brief, un enregistrement ou une nouvelle idée en une nouvelle compétence. ADAPT transfère une compétence externe (URL GitHub, agentskills.io, disque local) dans votre espace de noms avec une classification à trois compartiments (conserver/adapter/ajouter) + vérification de licence + attribution. UPDATE améliore les compétences existantes issues des apprentissages grâce à la propagation des compétences croisées, au tri mémoire par rapport aux compétences et à la discipline semver. S'en remet aux conseils d'Anthropic (ingénierie composée : créer-agent-compétence, ingénierie composée : créateur de compétences, ingénierie composée : guérir-compétence) pour le schéma et la profondeur des meilleures pratiques. Déclencheurs sur « /skillify », « créer une compétence », « en faire une compétence », « compétence de ce chat », « extraire une compétence de ce que nous avons fait », « adapter cette compétence », « porter cette compétence », « fork cette compétence », « emprunter cette compétence », « mettre à jour la compétence X », « appliquer ceci aux compétences pertinentes », « propager cet apprentissage », « améliorer [compétence] », « réparer [compétence] », "itérer sur [compétence]." Une partie du trio -ify (skillify / toolify / loopify) pour étendre Claude Code.
