Если вы хотите создать, адаптировать или обновить навык Claude Code в одном из ваших родственных репозиториев (укажите свои собственные репозитории в ~/.config/makerskills/skillify/repos.yaml; по умолчанию —makerskills). Автоматически переключается в нужный режим. Режимы — СОЗДАНИЕ (из чата / из видео / из дампа / с нуля) превращает рабочий процесс, бриф, запись или свежую идею в новый навык. ADAPT переносит внешний навык (URL-адрес GitHub, Agentskills.io, локальный диск) в ваше пространство имен с классификацией по трем сегментам (сохранить/адаптировать/добавить) + проверка лицензии + атрибуция. UPDATE улучшает существующие навыки в результате обучения за счет распространения перекрестных навыков, сортировки памяти по навыкам и семверной дисциплины. Полагается на руководство Anthropic (составное проектирование: создание-навык-агента, сложное проектирование: создатель навыка, сложное проектирование: исцеление-навык) для схемы и глубины передового опыта. Триггеры: «/skillify», «создать навык», «сделать это навыком», «навык из этого чата», «извлечь навык из того, что мы делали», «адаптировать этот навык», «портировать этот навык», «разветвить этот навык», «заимствовать этот навык», «обновить X навык», «применить это к соответствующим навыкам», «распространить это обучение», «улучшить [навык]», «исправить [навык]». «повторить [навык]». Часть -ify trifecta (skillify/toolify/loopify) для расширения кода Claude.
