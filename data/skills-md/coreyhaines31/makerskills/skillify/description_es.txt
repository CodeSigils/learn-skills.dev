Cuando desee crear, adaptar o actualizar una habilidad de Claude Code en uno de sus repositorios hermanos (enumere sus propios repositorios en ~/.config/makerskills/skillify/repos.yaml; el valor predeterminado es makerskills). Rutas al modo correcto automáticamente. Modos: CREAR (desde el chat/desde el video/desde el volcado/desde cero) convierte un flujo de trabajo, un resumen, una grabación o una nueva idea en una nueva habilidad. ADAPT transfiere una habilidad externa (URL de GitHub, agenteskills.io, disco local) a su espacio de nombres con clasificación de tres depósitos (mantener/adaptar/agregar) + verificación de licencia + atribución. UPDATE mejora las habilidades existentes a partir del aprendizaje con propagación entre habilidades, clasificación de memoria versus habilidades y disciplina semver. Se remite a la guía de Anthropic (ingeniería compuesta: crear habilidad de agente, ingeniería compuesta: creador de habilidades, ingeniería compuesta: habilidad de curación) para conocer el esquema y las mejores prácticas en profundidad. Activadores en "/skillify", "crear una habilidad", "hacer de esto una habilidad", "habilidad de este chat", "extraer una habilidad de lo que hemos estado haciendo", "adaptar esta habilidad", "portar esta habilidad", "bifurcar esta habilidad", "tomar prestada esta habilidad", "actualizar X habilidad", "aplicar esto a las habilidades relevantes", "propagar este aprendizaje", "mejorar [habilidad]", "arreglar [habilidad]". "iterar sobre [habilidad]". Parte de la trifecta -ify (skillify / toolify / loopify) para extender Claude Code.
