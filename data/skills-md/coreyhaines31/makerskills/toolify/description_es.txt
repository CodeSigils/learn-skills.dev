Cuando desee integrar una herramienta externa, API, servidor MCP o servicio en un proyecto, el asistente lo guiará a través de la autenticación, la configuración, las variables de entorno, el código contenedor del cliente, el uso de ejemplo y (opcionalmente) una prueba de humo. Ambito a los proyectos Next.js y Rails (las dos pilas principales). Patrón interactivo de preguntas y respuestas: comienza con el nombre de la herramienta, formula preguntas estructuradas hasta que la integración está completamente especificada y luego organiza los archivos. Ejemplos de herramientas para crear herramientas: Stripe, Kit, Sanity, Notion, Neon, Supabase, Fathom, Rewardful, SavvyCal, Riverside, ScrapeCreators, Anthropic, OpenAI, Gemini, Twilio, Resend, Postmark, Vercel Blob, API internas personalizadas. Específicamente para servidores MCP, también maneja el cableado .mcp.json. Activadores en "/toolify", "integrar X", "agregar X a este proyecto", "conectar X", "configurar la integración de X", "conectar X", "conectar X", "agregar MCP para X". Parte de la trifecta -ify (skillify / toolify / loopify) para extender Claude Code. NO para agregar nuevos archivos SKILL.md, eso es Skillify. NO para bucles cron/agent, eso es loopify.
