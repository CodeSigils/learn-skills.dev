Quando desideri integrare uno strumento esterno, un'API, un server MCP o un servizio in un progetto, la procedura guidata ti guida attraverso l'autenticazione, la configurazione, le variabili di ambiente, il codice wrapper del client, l'utilizzo di esempio e (facoltativo) un test del fumo. Con ambito sui progetti Next.js e Rails (i due stack principali). Modello di domande e risposte interattive: inizia con il nome dello strumento, pone domande strutturate fino a quando l'integrazione non viene completamente specificata, quindi crea i file con impalcature. Esempi di strumenti da utilizzare: Stripe, Kit, Sanity, Notion, Neon, Supabase, Fathom, Rewardful, SavvyCal, Riverside, ScrapeCreators, Anthropic, OpenAI, Gemini, Twilio, Resend, Postmark, Vercel Blob, API interne personalizzate. In particolare per i server MCP, gestisce anche il cablaggio .mcp.json. Si attiva su "/toolify", "integra X", "aggiungi X a questo progetto", "collega X", "imposta l'integrazione X", "collega X", "connetti X", "aggiungi MCP per X". Parte di -ify trifecta (skillify / toolify / loopify) per estendere il codice Claude. NON per aggiungere nuovi file SKILL.md: questo è skillify. NON per i loop cron/agent: questo è loopify.
