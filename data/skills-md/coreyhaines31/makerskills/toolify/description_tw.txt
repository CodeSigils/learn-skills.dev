當您想要將外部工具、API、MCP 伺服器或服務整合到專案中時，精靈將引導您完成身份驗證、設定、環境變數、用戶端包裝程式碼、範例用法和（可選）冒煙測試。範圍為 Next.js 和 Rails 專案（兩個主要堆疊）。互動式問答模式－從工具名稱開始，提出結構化問題，直到完全指定集成，然後建立文件。工具化工具範例 — Stripe、Kit、Sanity、Notion、Neon、Supabase、Fathom、Rewardful、SavvyCal、Riverside、ScrapeCreators、Anthropic、OpenAI、Gemini、Twilio、Resend、Postmark、Vercel Blob、自訂內部 API。特別是對於 MCP 伺服器，也處理 .mcp.json 接線。在「/toolify」、「整合 X」、「將 X 新增至此專案」、「連接 X」、「設定 X 整合」、「連接 X」、「連接 X」、「為 X 新增 MCP」上觸發。用於擴展 Claude 程式碼的 -ify 三連勝（skillify / toolify / Loopify）的一部分。不是為了添加新的 SKILL.md 檔案——那是 Skillify。不適用於 cron/agent 循環——那是 Loopify。
