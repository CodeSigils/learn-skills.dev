Если вы хотите интегрировать внешний инструмент, API, сервер MCP или службу в проект, мастер проведет вас через аутентификацию, конфигурацию, переменные среды, код оболочки клиента, пример использования и (необязательно) дымовое тестирование. Ограничено проектами Next.js и Rails (два основных стека). Шаблон интерактивных вопросов и ответов — начинается с названия инструмента, задает структурированные вопросы до тех пор, пока интеграция не будет полностью определена, а затем формирует файлы. Примеры инструментов для инструментов — Stripe, Kit, Sanity, Notion, Neon, Supabase, Fathom, Rewardful, SavvyCal, Riverside, ScrapeCreators, Anthropic, OpenAI, Gemini, Twilio, Resend, Postmark, Vercel Blob, пользовательские внутренние API. В частности, для серверов MCP также обрабатывается подключение .mcp.json. Триггеры по «/toolify», «интегрировать X», «добавить X в этот проект», «подключить X», «настроить интеграцию X», «подключить X», «подключить X», «добавить MCP для X». Часть -ify trifecta (skillify/toolify/loopify) для расширения кода Claude. НЕ для добавления новых файлов SKILL.md — это Skillify. НЕ для циклов cron/agent — это Loopify.
