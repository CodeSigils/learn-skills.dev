Lorsque vous souhaitez intégrer un outil externe, une API, un serveur MCP ou un service dans un projet, l'assistant vous guide à travers l'authentification, la configuration, les variables d'environnement, le code du wrapper client, un exemple d'utilisation et (éventuellement) un test de fumée. Porté sur les projets Next.js et Rails (les deux piles principales). Modèle de questions-réponses interactif : commence par le nom de l'outil, pose des questions structurées jusqu'à ce que l'intégration soit entièrement spécifiée, puis échafaude les fichiers. Exemples d'outils à utiliser : Stripe, Kit, Sanity, Notion, Neon, Supabase, Fathom, Rewardful, SavvyCal, Riverside, ScrapeCreators, Anthropic, OpenAI, Gemini, Twilio, Resend, Postmark, Vercel Blob, API internes personnalisées. Pour les serveurs MCP en particulier, gère également le câblage .mcp.json. Déclencheurs sur "/toolify", "intégrer X", "ajouter X à ce projet", "câbler X", "configurer l'intégration X", "brancher X", "connecter X", "ajouter MCP pour X". Une partie du trio -ify (skillify / toolify / loopify) pour étendre Claude Code. PAS pour ajouter de nouveaux fichiers SKILL.md - c'est Skillify. PAS pour les boucles cron/agent - c'est loopify.
