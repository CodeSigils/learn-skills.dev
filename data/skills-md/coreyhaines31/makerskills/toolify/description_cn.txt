当您想要将外部工具、API、MCP 服务器或服务集成到项目中时，向导将引导您完成身份验证、配置、环境变量、客户端包装器代码、示例用法和（可选）冒烟测试。范围为 Next.js 和 Rails 项目（两个主要堆栈）。交互式问答模式——从工具名称开始，提出结构化问题，直到完全指定集成，然后构建文件。工具化工具示例 — Stripe、Kit、Sanity、Notion、Neon、Supabase、Fathom、Rewardful、SavvyCal、Riverside、ScrapeCreators、Anthropic、OpenAI、Gemini、Twilio、Resend、Postmark、Vercel Blob、自定义内部 API。特别是对于 MCP 服务器，还处理 .mcp.json 接线。在“/toolify”、“集成 X”、“将 X 添加到此项目”、“连接 X”、“设置 X 集成”、“连接 X”、“连接 X”、“为 X 添加 MCP”上触发。用于扩展 Claude 代码的 -ify 三连胜（skillify / toolify / Loopify）的一部分。不是为了添加新的 SKILL.md 文件——那是 Skillify。不适用于 cron/agent 循环——那是 Loopify。
