외부 도구, API, MCP 서버 또는 서비스를 프로젝트에 통합하려는 경우 마법사는 인증, 구성, 환경 변수, 클라이언트 래퍼 코드, 사용법 예시 및 (선택적으로) 연기 테스트를 안내합니다. Next.js 및 Rails 프로젝트(두 개의 기본 스택)로 범위가 지정됩니다. 대화형 Q&A 패턴 — 도구 이름으로 시작하여 통합이 완전히 지정될 때까지 구조화된 질문을 한 다음 파일을 스캐폴드합니다. 도구화할 도구의 예 — Stripe, Kit, Sanity, Notion, Neon, Supabase, Fathom, Rewardful, SavvyCal, Riverside, ScrapeCreators, Anthropic, OpenAI, Gemini, Twilio, Resend, Postmark, Vercel Blob, 맞춤형 내부 API. 특히 MCP 서버의 경우 .mcp.json 연결도 처리합니다. "/toolify", "X 통합", "이 프로젝트에 X 추가", "X 연결", "X 통합 설정", "X 연결", "X 연결", "X용 MCP 추가"에 대해 트리거됩니다. Claude Code 확장을 위한 -ify trifecta(skillify / toolify / loopify)의 일부입니다. 새로운 SKILL.md 파일을 추가하는 것이 아닙니다. 그것은 Skillify입니다. cron/agent 루프가 아닙니다. 이는 loopify입니다.
