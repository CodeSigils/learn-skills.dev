Если вы хотите провести мозговой штурм и проверить доступные домены .com для нового проекта — название бренда, цены на вторичном рынке (HugeDomains / Afternic / Sedo / Dan), проверку товарных знаков USPTO и доступность социальных сетей. Создано на основе методологии Лауры Рёдер «работайте в обратном направлении от доступности, а не от имени, в которое вы влюбились». Использует Vercel CLI + whois + Domainr API + Namecheap API + агент-браузер для частей, которые действительно надежно поддерживает каждый инструмент (ансамбля из нескольких инструментов, поскольку ни один инструмент не охватывает все четко). 11-этапный рабочий процесс: бюджет → мозговой штурм → первичная проверка доступности → перекрестная проверка Whois → агрегация доменов → дешевая цена имени → анализ послепродажного обслуживания → сегмент → переговоры → исследование НАЗВАНИЯ (торговая марка + социальные сети) → покупка. Триггеры по «/domain», «найти домен», «проверить доступность домена», «мозговой штурм домена», «какой домен .com доступен для X», «поиск домена», «назовите мой проект», «доступен ли X.com», «цена послепродажного обслуживания на X.com», «проверка товарного знака для X».
