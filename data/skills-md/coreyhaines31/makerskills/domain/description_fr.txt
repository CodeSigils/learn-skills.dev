Lorsque vous souhaitez réfléchir et vérifier les domaines .com disponibles pour un nouveau projet : dénomination de la marque, prix du marché secondaire (HugeDomains / Afternic / Sedo / Dan), sélection des marques USPTO et disponibilité des identifiants sociaux. Construit sur la méthodologie de Laura Roeder « travaillez à rebours de la disponibilité, pas à partir d'un nom dont vous êtes tombé amoureux ». Utilise Vercel CLI + whois + API Domainr + API Namecheap + navigateur d'agent pour les éléments que chaque outil prend réellement en charge de manière fiable (ensemble multi-outils car aucun outil unique ne couvre tout proprement). Flux de travail en 11 étapes : budget → brainstorming → vérification de la disponibilité principale → vérification croisée whois → agrégation de domaines → prix Namecheap → balayage du marché secondaire → seau → négocier → recherche de NOM (marque + réseaux sociaux) → acheter. Déclencheurs sur « /domain », « trouver un domaine », « vérifier la disponibilité du domaine », « réfléchir à un domaine », « quel .com est disponible pour X », « recherche de domaine », « nommer mon projet », « X.com est-il disponible », « prix de rechange sur X.com », « vérification de marque pour X ».
