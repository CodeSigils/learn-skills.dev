Cuando desee realizar una lluvia de ideas y verificar los dominios .com disponibles para un nuevo proyecto: nombre de marca, precios de posventa (HugeDomains / Afternic / Sedo / Dan), selección de marcas comerciales de la USPTO y disponibilidad de identificadores sociales. Basado en la metodología de Laura Roeder de "trabajar al revés desde la disponibilidad, no desde un nombre del que te enamoraste". Utiliza Vercel CLI + whois + Domainr API + Namecheap API + agente-navegador para las piezas que cada herramienta realmente admite de manera confiable (conjunto de múltiples herramientas porque ninguna herramienta cubre todo de manera limpia). Flujo de trabajo de 11 pasos: presupuesto → lluvia de ideas → verificación de disponibilidad primaria → verificación cruzada de whois → agregación de dominios → precio barato de nombre → barrido de posventa → depósito → negociar → investigación de NOMBRE (marca comercial + redes sociales) → comprar. Activadores en "/dominio", "buscar un dominio", "verificar la disponibilidad del dominio", "hacer una lluvia de ideas sobre un dominio", "qué .com está disponible para X", "búsqueda de dominio", "nombrar mi proyecto", "está disponible X.com", "precio de posventa en X.com", "comprobación de marca registrada para X".
