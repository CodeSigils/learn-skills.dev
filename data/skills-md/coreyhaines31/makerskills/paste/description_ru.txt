Если вы хотите очистить и переформатировать контент (обычно с вашего терминала) для вставки в Slack, Notion, Twitter/X, LinkedIn, электронную почту, GitHub или обычный текст. Удаляет коды ANSI, символы рисования прямоугольников, артефакты подсказок терминала и применяет форматирование, зависящее от места назначения. По умолчанию используется буфер обмена (читается через `pbpaste`); выводом по умолчанию является как буфер обмена (`pbcopy`), так и предварительный просмотр чата. Триггеры по "/paste", "/paste [destination]", "очистить это для X", "форматировать для slack/notion/twitter/linkedin/email/github", "рендеринг как уценку", "готовность к вставке", "очистить форматирование", "сделать это доступным для копирования". Пункт назначения по умолчанию простой. Также сканирует секреты (ключи API, токены, значения .env) и предупреждает перед копированием чего-либо конфиденциального.
