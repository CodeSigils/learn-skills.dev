Cuando desee limpiar y reformatear contenido (normalmente desde su terminal) para pegarlo en Slack, Notion, Twitter/X, LinkedIn, correo electrónico, GitHub o texto sin formato. Elimina códigos ANSI, caracteres de dibujo de cuadros, artefactos de mensajes de terminal y aplica formato específico de destino. La entrada predeterminada es el portapapeles (leído mediante `pbpaste`); La salida predeterminada es tanto el portapapeles (`pbcopy`) como una vista previa del chat. Activadores en "/pegar", "/pegar [destino]", "limpiar esto para X", "formatear para slack/notion/twitter/linkedin/email/github", "presentar como descuento", "listo para pegar", "formatear tiras", "hacer que esto se pueda copiar y pegar". El destino predeterminado es sencillo. También busca secretos (claves API, tokens, valores .env) y advierte antes de copiar cualquier cosa confidencial.
