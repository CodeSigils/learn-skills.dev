Lorsque vous ou une autre compétence devez récupérer le contenu d'une publication sur les réseaux sociaux par URL : tweet, fil X, publication LinkedIn, publication Instagram, vidéo TikTok, publication Bluesky, fil Reddit, statut Mastodon, publication Threads, fil Hacker News. Renvoie des données structurées normalisées (auteur, posts_at, texte, nombre d'engagements, URL des médias, réponses si demandées), quelle que soit la plate-forme. Essaie les stratégies dans l'ordre : API directe (Bluesky, Mastodon, HN, Reddit), agent-navigateur avec licenciement modal (LinkedIn, aperçu X), Wayback Machine (articles plus anciens), API payantes (ScrapeCreators / Apify — uniquement si les clés d'environnement sont présentes). Déclencheurs sur « /social-fetch <url> », « récupérer ce tweet », « récupérer ce message », « que dit ce LinkedIn », « lire ce fil de discussion », « retirer ce message ». Utilisé par la recherche approfondie (citant des articles spécifiques), le jab-hook (analyse de compte d'inspiration), le brainstorming commercial (commentaire d'un concurrent/opérateur).
