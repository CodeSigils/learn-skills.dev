Когда вам или другому навыку необходимо получить содержимое публикации в социальной сети по URL-адресу — твит, ветка X, публикация в LinkedIn, публикация в Instagram, видео в TikTok, публикация Bluesky, ветка Reddit, статус Mastodon, публикация в Threads, ветка Hacker News. Возвращает нормализованные структурированные данные (автор, Posted_at, текст, количество вовлечений, URL-адреса мультимедиа, ответы по запросу) независимо от платформы. Пробует стратегии по порядку: прямой API (Bluesky, Mastodon, HN, Reddit), агент-браузер с модальным отключением (LinkedIn, X превью), Wayback Machine (старые посты), платные API (ScrapeCreators/Apify — только при наличии ключей env). Триггеры: «/social-fetch <url>», «получить этот твит», «получить эту публикацию», «что говорит этот LinkedIn», «прочитать эту тему», «извлечь эту публикацию». Используется при глубоких исследованиях (цитирование конкретных постов), джеб-хуке (анализ вдохновения аккаунта), бизнес-мозговом штурме (комментарий конкурентов/оператора).
