Wenn Sie oder eine andere Fähigkeit den Inhalt eines Social-Media-Beitrags per URL abrufen müssen – Tweet, X-Thread, LinkedIn-Beitrag, Instagram-Beitrag, TikTok-Video, Bluesky-Beitrag, Reddit-Thread, Mastodon-Status, Threads-Beitrag, Hacker-News-Thread. Gibt unabhängig von der Plattform normalisierte strukturierte Daten zurück (Autor, gepostetes_at, Text, Anzahl der Interaktionen, Medien-URLs, Antworten, falls angefordert). Versucht Strategien in der Reihenfolge: direkte API (Bluesky, Mastodon, HN, Reddit), Agent-Browser mit modaler Entlassung (LinkedIn, X-Vorschau), Wayback Machine (ältere Beiträge), kostenpflichtige APIs (ScrapeCreators / Apify – nur wenn Env-Schlüssel vorhanden). Wird ausgelöst bei „/social-fetch <url>“, „Diesen Tweet abrufen“, „Diesen Beitrag abrufen“, „Was sagt dieses LinkedIn“, „Diesen Thread lesen“, „Diesen Beitrag abrufen“. Wird für Deep Research (Zitieren bestimmter Beiträge), Jab-Hook (Analyse von Inspirationskonten) und Business-Brainstorming (Kommentar von Wettbewerbern/Betreibern) verwendet.
