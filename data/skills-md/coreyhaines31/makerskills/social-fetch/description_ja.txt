自分または別のスキルが URL によってソーシャル メディア投稿のコンテンツを取得する必要がある場合 — ツイート、X スレッド、LinkedIn 投稿、Instagram 投稿、TikTok ビデオ、Bluesky 投稿、Reddit スレッド、Mastodon ステータス、スレッド投稿、ハッカー ニュース スレッド。プラットフォームに関係なく、正規化された構造化データ (作成者、posted_at、テキスト、エンゲージメント数、メディア URL、要求された場合の返信) を返します。戦略を順番に試行します: 直接 API (Bluesky、Mastodon、HN、Reddit)、モーダル解除付きエージェント ブラウザー (LinkedIn、X プレビュー)、ウェイバック マシン (古い投稿)、有料 API (ScrapeCreators / Apify — env キーが存在する場合のみ)。 「/social-fetch <url>」、「このツイートを取得」、「この投稿を取得」、「この LinkedIn の内容」、「このスレッドを読む」、「この投稿をプル」でトリガーします。ディープリサーチ（特定の投稿の引用）、ジャブフック（インスピレーションアカウント分析）、ビジネスブレインストーミング（競合他社/事業者のコメント）によって使用されます。
