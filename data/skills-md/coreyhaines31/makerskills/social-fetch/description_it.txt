Quando tu o un'altra persona avete bisogno di recuperare il contenuto di un post sui social media tramite URL: tweet, thread X, post di LinkedIn, post di Instagram, video di TikTok, post di Bluesky, thread di Reddit, stato di Mastodon, post di thread, thread di Hacker News. Restituisce dati strutturati normalizzati (autore, posted_at, testo, conteggi di coinvolgimento, URL dei media, risposte se richieste) indipendentemente dalla piattaforma. Prova le strategie in ordine: API diretta (Bluesky, Mastodon, HN, Reddit), browser agente con licenziamento modale (LinkedIn, anteprima X), Wayback Machine (post più vecchi), API a pagamento (ScrapeCreators / Apify — solo se sono presenti le chiavi env). Si attiva su "/social-fetch <url>", "recupera questo tweet", "recupera questo post", "cosa dice questo LinkedIn", "leggi questo thread", "estrai questo post". Utilizzato da ricerche approfondite (citando post specifici), jab-hook (analisi dell'account di ispirazione), business-brainstorming (commenti di concorrenti/operatori).
