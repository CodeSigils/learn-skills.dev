Cuando desee configurar un bucle de agente, una tarea programada cron o un flujo de trabajo recurrente que se ejecute de forma autónoma en Claude Code. Capa de juicio encima de ScheduleWakeup, CronCreate y la habilidad /loop: decide si se utiliza ritmo dinámico (despertadores autoprogramados), programación cron (intervalos fijos) o un bucle de una sola vez; las melodías se retrasan para evitar el abismo de pérdida de caché de 5 minutos; diseña cuerpos de bucle idempotentes; establece condiciones de rescate para que los ciclos no duren para siempre. Ejemplos de bucles para loopificar: pulso de revisión semanal, generación de resúmenes diarios, monitoreo cada hora de una métrica, compilación periódica de la bóveda, verificación ascendente de una habilidad adaptada, actualización del canal de patrocinio, descarga por lotes de transcripciones de YouTube, rutina de inicio matutino. Activadores en "/loopify", "configurar un bucle", "programar esta tarea", "ejecutar esto diariamente", "ejecutar esto semanalmente", "cronizar esto", "hacer esto recurrente", "automatizar esto según un cronograma", "mantener esto ejecutándose hasta X". Parte de la trifecta -ify (skillify / toolify / loopify) para extender Claude Code. NO para crear una nueva habilidad, eso es Skillify. NO para agregar una herramienta/integración, eso es toolify.
