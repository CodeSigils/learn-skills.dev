當您想要設定在 Claude Code 中自主執行的代理程式循環、cron 排程任務或重複工作流程。 ScheduleWakeup、CronCreate 和 /loop 技能之上的判斷層 — 決定是否使用動態節奏（自我調度喚醒）、cron 調度（固定間隔）或一次性循環；調整延遲以避免 5 分鐘緩存未命中懸崖；設計冪等循環體；設置紓困條件，以便循環不會永遠運行。 Loopify 的循環範例 — 每週回顧脈衝、每日簡報產生、每小時監控指標、定期庫編譯、上游檢查適應技能、贊助管道刷新、YouTube 成績單批量下載、早上啟動例程。在「/loopify」、「設定循環」、「排程此任務」、「每天執行此任務」、「每週執行此任務」、「cron 此任務」、「使其重複執行」、「按計畫自動執行此任務」、「保持此任務運行直到 X」上觸發。用於擴展 Claude 程式碼的 -ify 三連勝（skillify / toolify / Loopify）的一部分。不是為了創造新技能——那是技能化。不是為了添加工具/整合——那是工具化。
