Wenn Sie eine Agentenschleife, eine Cron-geplante Aufgabe oder einen wiederkehrenden Workflow einrichten möchten, der autonom in Claude Code ausgeführt wird. Beurteilungsebene über ScheduleWakeup, CronCreate und dem /loop-Skill – entscheidet, ob dynamisches Pacing (selbstplanende Weckvorgänge), Cron-Scheduling (feste Intervalle) oder eine One-Shot-Schleife verwendet werden soll; optimiert die Verzögerung, um die 5-Minuten-Cache-Miss-Klippe zu vermeiden; entwirft idempotente Schleifenkörper; legt Bail-out-Bedingungen fest, damit Schleifen nicht ewig laufen. Beispiele für zu wiederholende Schleifen – wöchentlicher Überprüfungsimpuls, tägliche Briefgenerierung, stündliche Überwachung einer Metrik, regelmäßige Vault-Kompilierung, Upstream-Prüfung für eine angepasste Fähigkeit, Sponsoring-Pipeline-Aktualisierung, YouTube-Transkript-Batch-Download, morgendliche Startup-Routine. Löst aus bei „/loopify“, „eine Schleife einrichten“, „diese Aufgabe planen“, „diese Aufgabe täglich ausführen“, „diese wöchentlich ausführen“, „dieses cronieren“, „dieses wiederkehrend machen“, „dieses nach einem Zeitplan automatisieren“, „dieses bis X laufen lassen“. Teil des -ify-Trifecta (Skillify / Toolify / Loopify) zur Erweiterung von Claude Code. NICHT zum Erstellen eines neuen Skills – das ist Skillify. NICHT zum Hinzufügen eines Tools/einer Integration – das ist Toolify.
