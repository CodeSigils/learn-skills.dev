Cuando desee leer y extraer notas estructuradas de un libro: PDF, EPUB, MOBI, rebajas, .txt, texto pegado o URL de una obra de dominio público. Lee en fragmentos (por capítulo cuando existe un TOC, en bloques de 50 páginas en caso contrario), extrae TL por capítulo; DR + conceptos clave + citas + elementos de acción + marcos, y ofrece capturarlo en el segundo cerebro sin procesar/como un archivo destacado. Cuatro modos: notas (predeterminado, capítulo por capítulo), resumen (libro completo TL; DR + 3 a 5 conclusiones), citas (solo citas destacadas), estudio (notas + preparación de preguntas y respuestas espaciadas). Activadores en "/leer-libro", "leer este libro", "extraer notas de este PDF", "qué hay en este libro", "resumir este libro electrónico", "extraer citas de este". Hermano para ver vídeo (mismo patrón de consumo de contenidos, diferente medio).
