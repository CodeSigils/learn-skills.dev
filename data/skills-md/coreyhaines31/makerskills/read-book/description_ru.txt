Если вы хотите прочитать и извлечь структурированные заметки из книги — PDF, EPUB, MOBI, уценки, .txt, вставленный текст или URL-адрес общедоступного произведения. Читает по частям (по главам, если существует оглавление, по 50-страничным блокам в противном случае), извлекает для каждой главы TL;DR + ключевые понятия + цитаты + элементы действий + рамки и предлагает записать во второй мозг необработанные данные/в виде файла основных моментов. Четыре режима — заметки (по умолчанию, по главам), резюме (TL;DR + 3–5 выводов), цитаты (только выделенные цитаты), исследование (заметки + подготовка к вопросам и ответам). Триггеры «/read-book», «прочитать эту книгу», «извлечь заметки из этого PDF-файла», «что в этой книге», «подвести итог этой электронной книги», «извлечь цитаты из этой». Брат и сестра для просмотра видео (та же модель потребления контента, другой носитель).
