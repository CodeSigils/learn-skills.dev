Pixelgenauer Figma-Design-Workflow zur Webcode-Wiederherstellung. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Benutzeroberfläche aus einem Figma-Design implementieren, ein Design reproduzieren, die Benutzeroberfläche wiederherstellen (UI还原), eine Seite mit einem Figma-Modell vergleichen oder visuelle Unterschiede zwischen Implementierung und Design beheben möchte. Wird auch ausgelöst, wenn der Benutzer eine Figma-URL angibt und auffordert, diese zu erstellen, oder wenn er „Designspezifikation“, „Pixel-perfekt“, „passt zum Design“ oder ähnliche Ausdrücke erwähnt. Diese Fähigkeit orchestriert Playwright MCP, Figma MCP und Chrome DevTools MCP für systematischen Vergleich und Iteration.
