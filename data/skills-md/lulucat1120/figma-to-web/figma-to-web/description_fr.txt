Conception Figma au pixel près pour le flux de travail de restauration de code Web. Utilisez cette compétence chaque fois que l'utilisateur demande d'implémenter une interface utilisateur à partir d'une conception Figma, de reproduire une conception, d'effectuer une restauration d'interface utilisateur (UI还原), de comparer une page avec une maquette Figma ou de corriger les différences visuelles entre l'implémentation et la conception. Déclenchez également lorsque l'utilisateur fournit une URL Figma et demande de la créer, ou lorsqu'il mentionne « spécifications de conception », « pixel parfait », « correspondre au design » ou des expressions similaires. Cette compétence orchestre Playwright MCP, Figma MCP et Chrome DevTools MCP pour une comparaison et une itération systématiques.
