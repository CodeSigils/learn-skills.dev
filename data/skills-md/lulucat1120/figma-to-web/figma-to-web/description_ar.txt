تصميم Figma مثالي للبكسل لسير عمل استعادة كود الويب. استخدم هذه المهارة عندما يطلب المستخدم تنفيذ واجهة مستخدم من تصميم Figma، أو إعادة إنتاج تصميم، أو القيام باستعادة واجهة المستخدم (UI还原)، أو مقارنة صفحة بنموذج Figma بالحجم الطبيعي، أو إصلاح الاختلافات المرئية بين التنفيذ والتصميم. يتم تشغيله أيضًا عندما يقدم المستخدم عنوان URL لـ Figma ويطلب إنشائه، أو عندما يذكر "مواصفات التصميم" أو "البكسل المثالي" أو "مطابقة التصميم" أو عبارات مماثلة. تعمل هذه المهارة على تنسيق Playwright MCP وFigma MCP وChrome DevTools MCP لإجراء مقارنة وتكرار منهجي.
