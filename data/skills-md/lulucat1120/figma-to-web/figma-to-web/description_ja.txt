ピクセルパーフェクトな Figma デザインから Web コード復元ワークフロー。ユーザーが Figma デザインから UI を実装する、デザインを再現する、UI 復元 (UI还原) を行う、ページと Figma モックアップを比較する、実装とデザインの視覚的な違いを修正するなどの要求を行う場合には、このスキルを使用してください。また、ユーザーが Figma URL を提供してその構築を依頼したとき、またはユーザーが「デザイン仕様」、「ピクセルパーフェクト」、「デザインに一致」、または同様のフレーズに言及したときにもトリガーされます。このスキルは、体系的な比較と反復のために Playwright MCP、Figma MCP、Chrome DevTools MCP を調整します。
