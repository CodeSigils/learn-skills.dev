Diseño Figma perfecto en píxeles para el flujo de trabajo de restauración de código web. Utilice esta habilidad siempre que el usuario solicite implementar una interfaz de usuario a partir de un diseño de Figma, reproducir un diseño, realizar una restauración de la interfaz de usuario (UI还原), comparar una página con una maqueta de Figma o corregir diferencias visuales entre la implementación y el diseño. También se activa cuando el usuario proporciona una URL de Figma y solicita crearla, o cuando menciona "especificaciones de diseño", "píxeles perfectos", "coincide con el diseño" o frases similares. Esta habilidad organiza Playwright MCP, Figma MCP y Chrome DevTools MCP para realizar comparaciones e iteraciones sistemáticas.
