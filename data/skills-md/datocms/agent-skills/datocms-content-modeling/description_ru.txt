Структуры принятия решений для моделирования контента DatoCMS — форма схемы, выбор полей, повторное использование контента, таксономии, контент и представление, организация пользовательского интерфейса администратора. Используйте для моделирования *решений*, а не реализации: модель против блока; single_block против модульного контента против структурированного текста; ссылки против встроенных блоков; форма таксономии (плоская/дерево/граненая); рефакторинг схем в форме страниц для повторного использования контента; установка лимита записи 300 КБ/500 блоков/5 уровней; поведение модели (singleton, черновой режим, all_locales_required, sortable/tree/ordering_field,presentation_title_field, Collection_appearance, inverse_relationships_enabled); конфигурация поля (валидатор + внешний вид — enum + string_select, автозаполнение фрагмента, требуемый_alt_title, списки разрешенных структурированных_текстов, одиночный_блок с рамкой и без рамки). Также обзор схемы (повторное использование, эргономика редактора, омниканальность). *Создание* схемы → `datocms-cli` или `datocms-cma`. Запрос/рендеринг → `datocms-cda` + `datocms-frontend-integrations`. Валидаторы + каскад: `datocms-cma/references/schema.md`.
