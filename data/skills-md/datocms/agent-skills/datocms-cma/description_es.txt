Secuencias de comandos Node.js/TypeScript que impulsan la API de administración de contenido de DatoCMS a través de @datocms/cma-client (-node/-browser). Compañero de código primero para contenido + trabajo de automatización. Úselo para grabar/cargar código de automatización de proyectos: preguntas breves ("publicarlas", "arreglar esos errores", "eliminar todos los borradores", "importar masivamente este CSV") y scripts registrados. Cubre: (1) operaciones de contenido: CRUD + registros de publicación, importación/exportación masiva, canalizaciones CSV, paginación, carga de activos (URL/archivo) con metadatos, texto estructurado + ediciones de carga útil en bloque; (2) env + gobernanza: bifurcar/promocionar envs, webhooks, activadores de compilación, configuración del proyecto, modo de mantenimiento, publicación/despublicación programada, registros de auditoría, análisis de uso, límites de suscripción; (3) acceso + flujos escritos: roles, tokens API, pistas/etiquetas de carga, tipos de CMA generados; (4) mutación de esquema/UI solo cuando el usuario opta por no participar en las migraciones o las integra en la automatización. Cambios de esquema ordinarios → migraciones `datocms-cli`. Se ejecuta a través de scripts `cma:call`/`cma:script` o `buildClient()` registrados.
