@datocms/cma-client (-node/-browser) 経由で DatoCMS コンテンツ管理 API を駆動する Node.js/TypeScript スクリプト。コンテンツ + 自動化作業のためのコードファーストのコンパニオン。コードの記録/アップロード/プロジェクト自動化に使用します。短い質問 (「公開する」、「スラッグを修正する」、「すべての下書きを削除する」、「この CSV を一括インポートする」) およびチェックインされたスクリプト。対象範囲: (1) コンテンツ操作 — CRUD + レコードの公開、一括インポート/エクスポート、CSV パイプライン、ページネーション、メタデータを含むアセットのアップロード (URL/ファイル)、構造化テキスト + ペイロード編集のブロック。 (2) 環境 + ガバナンス — フォーク/プロモート環境、Webhook、ビルド トリガー、プロジェクト設定、メンテナンス モード、スケジュールされた公開/非公開、監査ログ、使用状況分析、サブスクリプション制限。 (3) アクセス + 型付きフロー — ロール、API トークン、アップロード トラック/タグ、生成された CMA タイプ。 (4) ユーザーが移行をオプトアウトするか自動化に組み込む場合にのみ、スキーマ/UI が変更されます。通常のスキーマ変更 → `datocms-cli` 移行。 `cma:call`/`cma:script` またはチェックインされた `buildClient()` スクリプト経由で実行されます。
