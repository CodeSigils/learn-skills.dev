Node.js/TypeScript-Skripte, die die DatoCMS Content Management API über @datocms/cma-client (-node/-browser) steuern. Code-First-Begleiter für Content- und Automatisierungsarbeiten. Verwendung für Code zum Aufzeichnen/Hochladen/Projektautomatisieren – kurze Aufforderungen („Veröffentlichen“, „Fehler beheben“, „Alle Entwürfe löschen“, „Massenimport dieser CSV“) und eingecheckte Skripte. Deckt ab: (1) Inhaltsoperationen – CRUD + Veröffentlichungsdatensätze, Massenimport/-export, CSV-Pipelines, Paginierung, Asset-Uploads (URL/Datei) mit Metadaten, strukturierter Text + Block-Payload-Änderungen; (2) Env + Governance – Envs forken/fördern, Webhooks, Build-Trigger, Projekteinstellungen, Wartungsmodus, geplante Veröffentlichung/Aufhebung der Veröffentlichung, Audit-Protokolle, Nutzungsanalysen, Abonnementlimits; (3) Zugriff + typisierte Abläufe – Rollen, API-Tokens, Upload-Tracks/Tags, generierte CMA-Typen; (4) Schema-/UI-Mutation nur, wenn der Benutzer Migrationen ablehnt oder sie in die Automatisierung einbettet. Gewöhnliche Schemaänderungen → „datocms-cli“-Migrationen. Wird über „cma:call“/„cma:script“ oder eingecheckte „buildClient()“-Skripte ausgeführt.
