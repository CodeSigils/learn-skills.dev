Скрипты Node.js/TypeScript, управляющие API управления контентом DatoCMS через @datocms/cma-client (-node/-browser). Код-первый компаньон для работы с контентом и автоматизацией. Используйте для записи/загрузки/автоматизации проекта — короткие запросы («опубликовать их», «исправить эти фрагменты», «удалить все черновики», «массовый импорт этого CSV») и проверенные сценарии. Охватывает: (1) операции с контентом — CRUD + публикации записей, массовый импорт/экспорт, конвейеры CSV, разбиение на страницы, загрузку ресурсов (URL/файл) с метаданными, структурированный текст + редактирование полезной нагрузки блока; (2) env + управление — разветвление/продвижение env, веб-перехватчики, триггеры сборки, настройки проекта, режим обслуживания, запланированная публикация/отмена публикации, журналы аудита, аналитика использования, ограничения подписки; (3) доступ + типизированные потоки — роли, токены API, треки/теги загрузки, сгенерированные типы CMA; (4) мутация схемы/UI только тогда, когда пользователь отказывается от миграции или встраивает ее в автоматизацию. Обычные изменения схемы → миграция `datocms-cli`. Запускается через `cma:call`/`cma:script` или проверенные скрипты `buildClient()`.
