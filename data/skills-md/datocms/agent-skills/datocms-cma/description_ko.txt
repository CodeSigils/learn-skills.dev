@datocms/cma-client(-node/-browser)를 통해 DatoCMS 콘텐츠 관리 API를 구동하는 Node.js/TypeScript 스크립트. 콘텐츠 + 자동화 작업을 위한 코드 우선 동반자. 기록/업로드/프로젝트 자동화 코드에 사용 — 짧은 요청("게시", "슬러그 수정", "모든 초안 삭제", "이 CSV 대량 가져오기") 및 체크인 스크립트. 포함: (1) 콘텐츠 작업 — CRUD + 게시 레코드, 대량 가져오기/내보내기, CSV 파이프라인, 페이지 매김, 메타데이터가 포함된 자산 업로드(URL/파일), 구조화된 텍스트 + 블록 페이로드 편집; (2) 환경 + 거버넌스 — 환경 포크/승격, 웹후크, 빌드 트리거, 프로젝트 설정, 유지 관리 모드, 예약된 게시/게시 취소, 감사 로그, 사용량 분석, 구독 제한 (3) 액세스 + 유형화된 흐름 - 역할, API 토큰, 업로드 트랙/태그, 생성된 CMA 유형 (4) 사용자가 마이그레이션을 선택 해제하거나 자동화에 포함하는 경우에만 스키마/UI 변형. 일반 스키마 변경 → `datocms-cli` 마이그레이션. `cma:call`/`cma:script` 또는 체크인된 `buildClient()` 스크립트를 통해 실행됩니다.
