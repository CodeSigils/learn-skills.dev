Scripts Node.js/TypeScript pilotant l'API de gestion de contenu DatoCMS via @datocms/cma-client (-node/-browser). Compagnon code-first pour le travail de contenu et d'automatisation. À utiliser pour l'enregistrement/le téléchargement/le code d'automatisation du projet : demandes courtes ("publiez-les", "corrigez ces slugs", "supprimez tous les brouillons", "importez en masse ce CSV") et les scripts archivés. Couvre : (1) opérations de contenu – CRUD + publication d'enregistrements, importation/exportation en masse, pipelines CSV, pagination, téléchargements d'actifs (URL/fichier) avec métadonnées, texte structuré + modifications de charge utile de bloc ; (2) env + gouvernance — environnements fork/promote, webhooks, déclencheurs de build, paramètres du projet, mode de maintenance, publication/dépublication planifiée, journaux d'audit, analyses d'utilisation, limites d'abonnement ; (3) accès + flux typés — rôles, jetons API, pistes/tags de téléchargement, types CMA générés ; (4) mutation de schéma/interface utilisateur uniquement lorsque l'utilisateur se désengage des migrations ou l'intègre dans l'automatisation. Modifications de schéma ordinaires → migrations `datocms-cli`. S'exécute via des scripts `cma:call`/`cma:script` ou `buildClient()` archivés.
