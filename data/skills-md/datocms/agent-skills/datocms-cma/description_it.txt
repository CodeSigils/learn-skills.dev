Script Node.js/TypeScript che guidano l'API di gestione dei contenuti DatoCMS tramite @datocms/cma-client (-node/-browser). Compagno code-first per contenuti e lavoro di automazione. Utilizzare per registrare/caricare/codice di automazione del progetto: domande brevi ("pubblicali", "correggi quegli slug", "elimina tutte le bozze", "importa in blocco questo CSV") e script archiviati. Copre: (1) operazioni sui contenuti: CRUD + pubblicazione di record, importazione/esportazione in blocco, pipeline CSV, impaginazione, caricamenti di risorse (URL/file) con metadati, testo strutturato + blocco delle modifiche al payload; (2) env + governance: fork/promozione di env, webhook, trigger di build, impostazioni di progetto, modalità di manutenzione, pubblicazione/annulla pubblicazione pianificata, registri di controllo, analisi di utilizzo, limiti di abbonamento; (3) accesso + flussi digitati: ruoli, token API, tracce/tag di caricamento, tipi CMA generati; (4) mutazione dello schema/interfaccia utente solo quando l'utente disattiva le migrazioni o le incorpora nell'automazione. Modifiche ordinarie dello schema → migrazioni `datocms-cli`. Funziona tramite `cma:call`/`cma:script` o script `buildClient()` archiviati.
