DatoCMS CLI (datocms): migraciones de línea de comandos, generación de código de esquema, inspección de esquema, llamadas CMA únicas, scripts CMA TypeScript escritos, operaciones env, flujos de trabajo de implementación, sincronización de perfiles de múltiples proyectos. Úselo para comandos/scripts CLI de datocms: migraciones:nuevas, migraciones:ejecutar; esquema:generar; esquema: inspeccionar (modelos de volcado, bloques, campos, validadores, apariencia, conjuntos de campos, bloques anidados, modelos referenciados/incrustados); cma:call, cma:docs, cma:script (TS escrito ad hoc con cliente ambiental/esquema global); andamiaje de migración para modelos/campos/bloques; Configuración de CLI a través de perfiles datocms.config.json +; OAuth (iniciar sesión/cerrar sesión/whoami); proyectos: lista; vincular/desvincular el proyecto; lista de entornos/fork/promocionar/renombrar/destruir; alternancia del modo de mantenimiento; Canales de migración de CI/CD; sincronización de planos/proyectos del cliente; importaciones desde WordPress o Contentful (activos + contenido); Gestión de complementos CLI (complementos: instalar/añadir/disponible/enlace/eliminar/actualizar/reset/inspect).
