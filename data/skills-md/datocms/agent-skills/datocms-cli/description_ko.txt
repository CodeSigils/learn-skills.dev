DatoCMS CLI(datocms) — 명령줄 마이그레이션, 스키마 코드 생성, 스키마 검사, 일회성 CMA 호출, 입력된 TypeScript CMA 스크립트, 환경 작업, 배포 워크플로, 다중 프로젝트 프로필 동기화. datocms CLI 명령/스크립트에 사용: migrations:new, migrations:run; 스키마:생성; 스키마:검사(덤프 모델, 블록, 필드, 유효성 검사기, 모양, 필드 세트, 중첩 블록, 참조/임베딩 모델); cma:call, cma:docs, cma:script(주변 클라이언트/스키마 전역이 포함된 임시 유형의 TS); 모델/필드/블록을 위한 마이그레이션 스캐폴딩; datocms.config.json + 프로필을 통한 CLI 설정 OAuth(로그인/로그아웃/whoami); 프로젝트:목록; 프로젝트 링크/링크 해제; 환경 목록/포크/승격/이름 바꾸기/파괴; 유지 관리 모드 토글; CI/CD 마이그레이션 파이프라인 청사진/클라이언트 프로젝트 동기화; WordPress 또는 Contentful(자산 + 콘텐츠)에서 가져오기 CLI 플러그인 관리(플러그인:설치/추가/사용 가능/링크/제거/업데이트/재설정/검사).
