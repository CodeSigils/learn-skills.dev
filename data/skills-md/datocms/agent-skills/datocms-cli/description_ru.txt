DatoCMS CLI (datocms) — миграция из командной строки, создание кода схемы, проверка схемы, разовые вызовы CMA, типизированные сценарии CMA TypeScript, операции env, рабочие процессы развертывания, синхронизация профилей нескольких проектов. Используйте для команд/скриптов CLI datocms: миграции:новая, миграции:запустить; схема: сгенерировать; схема:инспектировать (дамп моделей, блоков, полей, валидаторов, внешнего вида, наборов полей, вложенных блоков, моделей, на которые ссылаются/встраивают); cma:call, cma:docs, cma:script (специально типизированный TS с внешними глобальными объектами клиента/схемы); каркас миграции для моделей/полей/блоков; Настройка CLI через datocms.config.json + профили; OAuth (вход/выход/whoami); проекты: список; привязать/отсоединить проект; список окружения/форк/продвижение/переименование/уничтожение; переключатель режима обслуживания; конвейеры миграции CI/CD; синхронизация проекта/клиента; импорт из WordPress или Contentful (активы + контент); Управление плагинами CLI (плагины: установить/добавить/доступно/связать/удалить/обновить/сбросить/проверить).
