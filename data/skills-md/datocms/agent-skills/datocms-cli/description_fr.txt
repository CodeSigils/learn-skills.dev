DatoCMS CLI (datocms) — migrations de ligne de commande, génération de schémas, inspection de schéma, appels CMA ponctuels, scripts CMA TypeScript tapés, opérations d'environnement, workflows de déploiement, synchronisation de profils multi-projets. À utiliser pour les commandes/scripts CLI datocms : migrations : new, migrations : run ; schéma:générer; schéma : inspecter (vider les modèles, les blocs, les champs, les validateurs, l'apparence, les jeux de champs, les blocs imbriqués, les modèles référencés/incorporés) ; cma:call, cma:docs, cma:script (TS typé ad hoc avec client ambiant/globaux de schéma) ; échafaudage de migration pour les modèles/champs/blocs ; Configuration CLI via datocms.config.json + profils ; OAuth (connexion/déconnexion/whoami) ; projets:liste; lien/dissociation du projet ; env list/fork/promote/rename/destroy ; basculement du mode maintenance ; Pipelines de migration CI/CD ; synchronisation du plan/projet client ; importations depuis WordPress ou Contentful (actifs + contenu) ; Gestion des plugins CLI (plugins : install/add/available/link/remove/update/reset/inspect).
