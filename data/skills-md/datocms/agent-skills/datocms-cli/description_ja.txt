DatoCMS CLI (datocms) — コマンドライン移行、スキーマ codegen、スキーマ検査、1 回限りの CMA 呼び出し、型指定された TypeScript CMA スクリプト、env 操作、展開ワークフロー、マルチプロジェクト プロファイル同期。 datocms CLI コマンド/スクリプトに使用します: migrations:new、migrations:run;スキーマ:生成;スキーマ:検査 (モデル、ブロック、フィールド、バリデーター、外観、フィールドセット、ネストされたブロック、参照/埋め込みモデルをダンプ); cma:call、cma:docs、cma:script (アンビエント クライアント/スキーマ グローバルを備えたアドホック型の TS);モデル/フィールド/ブロックの移行足場。 datocms.config.json + プロファイルによる CLI セットアップ。 OAuth (ログイン/ログアウト/whoami);プロジェクト:リスト;プロジェクトのリンク/リンク解除。環境リスト/フォーク/プロモート/名前変更/破壊;メンテナンスモードの切り替え。 CI/CD 移行パイプライン。ブループリント/クライアント プロジェクトの同期。 WordPress または Contentful (アセット + コンテンツ) からインポートします。 CLI プラグイン管理 (プラグイン:インストール/追加/利用可能/リンク/削除/更新/リセット/検査)。
