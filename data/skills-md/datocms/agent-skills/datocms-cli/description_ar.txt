DatoCMS CLI (datocms) - عمليات ترحيل سطر الأوامر، ورمز المخطط، وفحص المخطط، واستدعاءات CMA لمرة واحدة، ونصوص TypeScript CMA المكتوبة، وعمليات البيئة، وسير عمل النشر، ومزامنة ملفات تعريف المشاريع المتعددة. استخدم لأوامر/برامجيات datacms CLI: عمليات الترحيل: جديدة، عمليات الترحيل: تشغيل؛ المخطط: إنشاء؛ المخطط: فحص (نماذج التفريغ، الكتل، الحقول، أدوات التحقق من الصحة، المظهر، مجموعات الحقول، الكتل المتداخلة، النماذج المشار إليها/التضمين)؛ cma:call، cma:docs، cma:script (TS مكتوب بشكل خاص مع العميل المحيط/Schema globals)؛ سقالات الترحيل للنماذج/الحقول/الكتل؛ إعداد CLI عبر ملفات تعريف datocms.config.json +؛ OAuth (تسجيل الدخول/تسجيل الخروج/whoami)؛ المشاريع:قائمة؛ رابط المشروع/إلغاء الارتباط؛ env list/fork/promote/rename/destroy; تبديل وضع الصيانة؛ خطوط أنابيب ترحيل CI/CD؛ مزامنة مشروع المخطط/العميل؛ الواردات من WordPress أو Contentful (الأصول + المحتوى)؛ إدارة المكونات الإضافية لـ CLI (المكونات الإضافية: تثبيت/إضافة/متوفر/رابط/إزالة/تحديث/إعادة تعيين/فحص).
