DatoCMS CLI (datocms) — 命令行迁移、模式代码生成、模式检查、一次性 CMA 调用、类型化 TypeScript CMA 脚本、环境操作、部署工作流程、多项目配置文件同步。用于 datocms CLI 命令/脚本：migrations:new、migrations:run；架构：生成；模式：检查（转储模型、块、字段、验证器、外观、字段集、嵌套块、引用/嵌入模型）； cma:call、cma:docs、cma:script（具有环境客户端/架构全局变量的临时类型 TS）；模型/字段/块的迁移脚手架；通过 datocms.config.json + 配置文件进行 CLI 设置； OAuth（登录/注销/whoami）；项目：列表；项目链接/取消链接； env list/fork/promote/rename/destroy;维护模式切换； CI/CD 迁移管道；蓝图/客户项目同步；从 WordPress 或 Contentful 导入（资产 + 内容）； CLI插件管理（插件：安装/添加/可用/链接/删除/更新/重置/检查）。
