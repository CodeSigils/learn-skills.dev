DatoCMS CLI (datocms): migrazioni della riga di comando, codegen dello schema, ispezione dello schema, chiamate CMA una tantum, script CMA TypeScript digitati, operazioni env, flussi di lavoro di distribuzione, sincronizzazione di profili multiprogetto. Utilizzare per comandi/script CLI datocms: migrazioni:nuovo, migrazioni:run; schema:generare; schema:inspect (modelli di dump, blocchi, campi, validatori, aspetto, set di campi, blocchi nidificati, modelli di riferimento/incorporamento); cma:call, cma:docs, cma:script (TS tipizzati ad hoc con client di ambiente/globali di schema); ponteggi di migrazione per modelli/campi/blocchi; Configurazione CLI tramite datocms.config.json + profili; OAuth (accesso/disconnessione/whoami); progetti:elenco; collegamento/scollegamento del progetto; env list/fork/promuovi/rinomina/distruggi; attivazione/disattivazione della modalità di manutenzione; pipeline di migrazione CI/CD; sincronizzazione del progetto blueprint/cliente; importazioni da WordPress o Contentful (risorse + contenuti); Gestione dei plugin CLI (plugin: installa/aggiungi/disponibile/collega/rimuovi/aggiorna/reimposta/ispeziona).
