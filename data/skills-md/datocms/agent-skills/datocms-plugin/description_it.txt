Costruisci, supporta, mantieni o rinnova lo stile dei plugin DatoCMS creati con datocms-plugin-sdk e datocms-react-ui. Da utilizzare quando gli utenti chiedono di creare un nuovo progetto di plugin DatoCMS, applicare patch a un plugin esistente, aggiungere o modificare hook di plugin, estensioni di campo, schermate di configurazione, barre laterali, pagine, modali, origini risorse, azioni a discesa, hook del ciclo di vita, flussi CMA del browser, autorizzazioni di plugin, metadati dei pacchetti, aggiornamenti della modalità oscura o modifiche dell'interfaccia utente che dovrebbero corrispondere al dashboard di DatoCMS. Instrada gli script CMA autonomi a datocms-cma e le integrazioni del sito Web frontend alle integrazioni datocms-frontend.
