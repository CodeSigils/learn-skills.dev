datocms-plugin-sdk および datocms-react-ui で構築された DatoCMS プラグインを構築、足場、保守、または再スタイルします。新しい DatoCMS プラグイン プロジェクトの作成、既存のプラグインへのパッチ適用、プラグイン フック、フィールド拡張機能、設定画面、サイドバー、ページ、モーダル、アセット ソース、ドロップダウン アクション、ライフサイクル フック、ブラウザ CMA フロー、プラグイン アクセス許可、パッケージ メタデータ、ダーク モードのアップグレード、または DatoCMS ダッシュボードと一致する UI の変更の追加または調整をユーザーが要求する場合に使用します。スタンドアロン CMA スクリプトを datocms-cma にルーティングし、フロントエンド Web サイト統合を datocms-frontend-integrations にルーティングします。
