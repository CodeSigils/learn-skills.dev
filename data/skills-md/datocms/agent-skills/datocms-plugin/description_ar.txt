قم ببناء مكونات DatoCMS الإضافية أو دعمها أو صيانتها أو إعادة تصميمها والتي تم إنشاؤها باستخدام datocms-plugin-sdk وdatocms-react-ui. يُستخدم عندما يطلب المستخدمون إنشاء مشروع مكون إضافي جديد لـ DatoCMS، أو تصحيح مكون إضافي موجود، أو إضافة أو ضبط روابط المكونات الإضافية، أو امتدادات الحقول، أو شاشات التكوين، أو الأشرطة الجانبية، أو الصفحات، أو الوسائط، أو مصادر الأصول، أو إجراءات القائمة المنسدلة، أو روابط دورة الحياة، أو تدفقات CMA للمتصفح، أو أذونات المكونات الإضافية، أو بيانات تعريف الحزمة، أو ترقيات الوضع المظلم، أو تغييرات واجهة المستخدم التي يجب أن تتطابق مع لوحة معلومات DatoCMS. قم بتوجيه البرامج النصية المستقلة لـ CMA إلى تكاملات موقع الويب datocms-cma والواجهة الأمامية مع تكاملات datocms-frontend-integrations.
