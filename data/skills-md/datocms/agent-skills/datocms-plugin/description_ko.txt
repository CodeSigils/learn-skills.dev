datocms-plugin-sdk 및 datocms-react-ui로 구축된 DatoCMS 플러그인을 구축, 스캐폴드, 유지 관리 또는 스타일 변경합니다. 사용자가 새로운 DatoCMS 플러그인 프로젝트 생성, 기존 플러그인 패치, 플러그인 후크, 필드 확장, 구성 화면, 사이드바, 페이지, 모달, 자산 소스, 드롭다운 작업, 수명 주기 후크, 브라우저 CMA 흐름, 플러그인 권한, 패키지 메타데이터, 다크 모드 업그레이드 또는 DatoCMS 대시보드와 일치해야 하는 UI 변경 추가 또는 조정을 요청할 때 사용합니다. 독립형 CMA 스크립트를 datocms-cma로 라우팅하고 프런트엔드 웹 사이트 통합을 datocms-frontend-integrations로 라우팅합니다.
