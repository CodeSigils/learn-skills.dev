À utiliser uniquement lorsque les utilisateurs demandent explicitement de rapporter, d'envoyer par courrier électronique ou de résumer les commentaires sur les compétences/MCP DatoCMS, ou lorsque le flux de travail des compétences/MCP est clairement dans une impasse après des boucles répétées, un mauvais routage, des malentendus non résolus ou l'absence d'étape suivante crédible. Ne pas utiliser pour les premiers échecs ordinaires, les erreurs MCP/commande/API réessayables, les retours de validation, les échecs de découverte de schéma, les valeurs d'environnement manquantes, les bogues de projet/plug-in ou les problèmes de configuration où une autre compétence DatoCMS peut encore continuer.
