دليل لتكوين الأسرار الديناميكية غير المالية - بيانات اعتماد قصيرة الأجل عند الطلب لقواعد البيانات وIAM السحابية وSSH وKubernetes. يغطي 27 مزودًا بما في ذلك PostgreSQL وMySQL وRedis وMongoDB وAWS IAM وGCP IAM وشهادات SSH وحسابات خدمة Kubernetes والمزيد. استخدم هذه المهارة عندما يسأل شخص ما عن: الأسرار الديناميكية، أو بيانات اعتماد قاعدة البيانات المؤقتة، أو الرموز المميزة قصيرة العمر، أو مستخدمي قاعدة البيانات المتناوبة، أو بيانات اعتماد PostgreSQL/MySQL/Redis الديناميكية، أو شهادات SSH، أو مستخدمي AWS IAM المؤقتين، أو "كيف يمكنني إنشاء بيانات اعتماد مؤقتة باستخدام Infisical".
