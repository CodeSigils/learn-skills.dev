Руководство по настройке Infisical Dynamic Secrets — кратковременные учетные данные по требованию для баз данных, облачного IAM, SSH и Kubernetes. Охватывает 27 поставщиков, включая PostgreSQL, MySQL, Redis, MongoDB, AWS IAM, GCP IAM, сертификаты SSH, сервисные учетные записи Kubernetes и многое другое. Используйте этот навык, когда кто-то спрашивает о: динамических секретах, эфемерных учетных данных базы данных, кратковременных токенах, меняющихся пользователях базы данных, динамических учетных данных PostgreSQL/MySQL/Redis, сертификатах SSH, временных пользователях AWS IAM или «как мне создать временные учетные данные с помощью Infisical».
