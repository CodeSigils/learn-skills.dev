Экспертное руководство для поставщика Infisical Terraform. Охватывает конфигурацию ресурсов HCL, управление эфемерными секретами, шаблоны источников данных, разрешения ролей проекта и аутентификацию OIDC для Terraform Cloud. Используйте для внедрения секретов через IaC, настройку Machine Identity, политики утверждения доступа и собственные облачные шаблоны интеграции.
