Infisical Agent の構成ガイド。アプリケーション コードを変更せずに、トークンのライフサイクルを管理し、Go テンプレートを介してシークレットをレンダリングするクライアント デーモンです。完全な YAML 構成形式、6 つの認証方法すべて (ユニバーサル認証、Kubernetes、AWS IAM、Azure、GCP ID トークン、GCP IAM)、シンク、テンプレート関数 (listSecrets、listSecretsByProjectSlug、getSecretByName、dynamicSecret)、ポーリング、変更時コマンド、およびキャッシュをカバーします。このスキルは、Infisical Agent、エージェント構成ファイル、エージェント テンプレート、ファイルへのシークレットのレンダリング、サイドカー シークレットの挿入、トークンの更新、Infisical Agent コマンド、または「Infisical Agent を使用してシークレットを挿入する方法」について質問されたときに使用します。
