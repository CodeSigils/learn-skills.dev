Руководство по настройке Infisical Agent — клиентского демона, который управляет жизненным циклом токена и отображает секреты через шаблоны Go без изменения кода приложения. Охватывает полный формат конфигурации YAML, все 6 методов аутентификации (Universal Auth, Kubernetes, AWS IAM, Azure, GCP ID Token, GCP IAM), приемники, функции шаблона (listSecrets, listSecretsByProjectSlug, getSecretByName, DynamicSecret), опрос, команды при изменении и кеширование. Используйте этот навык, когда кто-то спрашивает о: Infisical Agent, файле конфигурации агента, шаблонах агентов, рендеринге секретов в файлы, дополнительном внедрении секретов, обновлении токена, команде infisical агента или «как мне использовать Infisical Agent для внедрения секретов».
