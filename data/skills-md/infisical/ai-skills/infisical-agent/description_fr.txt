Guide de configuration d'Infisical Agent — un démon client qui gère le cycle de vie des jetons et restitue les secrets via des modèles Go sans modifier le code de l'application. Couvre le format de configuration YAML complet, les 6 méthodes d'authentification (Universal Auth, Kubernetes, AWS IAM, Azure, GCP ID Token, GCP IAM), les récepteurs, les fonctions de modèle (listSecrets, listSecretsByProjectSlug, getSecretByName, DynamicSecret), l'interrogation, les commandes de modification et la mise en cache. Utilisez cette compétence lorsque quelqu'un pose des questions sur : l'agent Infisical, le fichier de configuration de l'agent, les modèles d'agent, le rendu des secrets dans les fichiers, l'injection de secrets side-car, le renouvellement du jeton, la commande de l'agent Infisical ou "comment utiliser l'agent Infisical pour injecter des secrets".
