Guía para configurar Infisical Agent: un demonio de cliente que administra el ciclo de vida del token y genera secretos a través de plantillas Go sin modificar el código de la aplicación. Cubre el formato de configuración YAML completo, los 6 métodos de autenticación (Universal Auth, Kubernetes, AWS IAM, Azure, GCP ID Token, GCP IAM), receptores, funciones de plantilla (listSecrets, listSecretsByProjectSlug, getSecretByName,dynamicSecret), sondeo, comandos de cambio y almacenamiento en caché. Utilice esta habilidad cuando alguien pregunte sobre: ​​Infisical Agent, archivo de configuración del agente, plantillas de agente, representación de secretos en archivos, inyección de secretos secundarios, renovación de tokens, comando del agente infisical o "cómo uso Infisical Agent para inyectar secretos".
