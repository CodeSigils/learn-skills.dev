دليل لتكوين Infisical Agent - برنامج عميل يدير دورة حياة الرمز المميز ويعرض الأسرار عبر قوالب Go دون تعديل رمز التطبيق. يغطي تنسيق تكوين YAML الكامل، وجميع أساليب المصادقة الستة (Universal Auth، وKubernetes، وAWS IAM، وAzure، وGCP ID Token، وGCP IAM)، والمصارف، ووظائف القالب (listSecrets، وlistSecretsByProjectSlug، وgetSecretByName، وdynamicSecret)، والاستقصاء، وأوامر التغيير، والتخزين المؤقت. استخدم هذه المهارة عندما يسأل شخص ما عن: الوكيل المالي، أو ملف تكوين الوكيل، أو قوالب الوكيل، أو تقديم الأسرار إلى الملفات، أو الحقن السري الجانبي، أو تجديد الرمز المميز، أو أمر الوكيل المالي، أو "كيف يمكنني استخدام الوكيل المالي لإدخال الأسرار".
