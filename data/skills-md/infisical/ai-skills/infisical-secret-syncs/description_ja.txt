Infisical Secret Sync を設定して Infisical からサードパーティ サービスにシークレットをプッシュするためのガイド。 AWS Secrets Manager、GCP Secret Manager、Azure Key Vault、GitHub、Vercel、HashiCorp Vault、Cloudflare などを含む 38 以上の同期先をカバーします。このスキルは、シークレットの AWS/GCP/Azure への同期、シークレットの GitHub Actions へのプッシュ、Vercel 環境変数、シークレット同期セットアップ、アプリ接続、マッピング動作、キー スキーマ、または「Infisical シークレットを [サービス] に取得するにはどうすればよいか」について質問されたときに使用します。
