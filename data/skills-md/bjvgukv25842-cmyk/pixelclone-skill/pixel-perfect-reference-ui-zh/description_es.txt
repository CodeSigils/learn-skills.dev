Cuando Codex necesita realizar una replicación perfecta en píxeles o una reconstrucción visual de la interfaz de un sitio web existente basándose en un diseño de página web maestra, una imagen generada por image2, capturas de pantalla, maquetas, exportación de Figma o un conjunto de imágenes de referencia local, se utiliza esta habilidad. La habilidad exige que: el diseño maestro sea la única fuente visual; los materiales se cortan únicamente de las imágenes de referencia; no se crean elementos de diseño originales; no se utilizan activos externos; la funcionalidad empresarial se preserva estrictamente; y mediante capturas de pantalla, bordes de activos, oclusiones, capacidad de respuesta, índice z y comprobaciones de regresión, se garantiza que la página se replicará lo más cerca posible de uno a uno.
