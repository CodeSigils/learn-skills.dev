Cuando Codex necesita realizar una replicación perfecta en píxeles o una reconstrucción visual de la interfaz de un sitio web existente basándose en un diseño de página web maestra, una imagen generada por image2, capturas de pantalla, maquetas, imágenes exportadas de Figma o una colección de imágenes de referencia local, se utiliza esta habilidad. La habilidad se aplica: el diseño maestro es la única fuente visual, los materiales se cortan solo de las imágenes de referencia, no se crean elementos de diseño originales, no se utilizan activos externos, la funcionalidad comercial se conserva estrictamente y, a través de capturas de pantalla, bordes de materiales, oclusión, capacidad de respuesta, índice z y comprobaciones de regresión, se garantiza que la página se replicará lo más cerca posible uno a uno.
