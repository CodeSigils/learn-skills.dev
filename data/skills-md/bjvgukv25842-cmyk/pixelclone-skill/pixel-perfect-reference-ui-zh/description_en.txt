When Codex needs to perform pixel‑perfect replication or visual reconstruction of an existing website front‑end based on a master webpage design, an image2‑generated image, screenshots, mockup, Figma export, or a local reference image set, this skill is used. The skill enforces that: the master design is the sole visual source; materials are cut only from the reference images; no original design elements are created; no external assets are used; business functionality is strictly preserved; and through screenshots, asset edges, occlusions, responsiveness, z‑index, and regression checks, the page is ensured to be replicated as close to one‑to‑one as possible.
