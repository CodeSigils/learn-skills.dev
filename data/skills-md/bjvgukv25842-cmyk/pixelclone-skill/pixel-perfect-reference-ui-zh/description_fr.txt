Utilisez cette compétence lorsque Codex doit effectuer une réplication parfaite au pixel près ou une reconstruction visuelle du front-end d'un site Web existant sur la base d'une conception de page Web principale, d'une génération d'image2, de captures d'écran, de maquettes, d'images d'exportation Figma ou de collections d'images de référence locales. Cette compétence impose que la conception principale soit la seule source visuelle, que les matériaux soient découpés uniquement à partir des images de référence, qu'aucun élément de conception original ne soit créé, qu'aucun actif externe ne soit utilisé, que les fonctionnalités commerciales soient strictement préservées et que les captures d'écran, les bords des matériaux, les occlusions, la réactivité, l'index z et les contrôles de régression soient utilisés pour garantir que la page est reproduite aussi fidèlement que possible.
