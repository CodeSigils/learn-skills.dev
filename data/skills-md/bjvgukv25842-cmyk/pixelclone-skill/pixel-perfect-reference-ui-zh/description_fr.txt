Lorsque Codex doit effectuer une réplication au pixel près ou une reconstruction visuelle d'un front-end de site Web existant sur la base d'une conception de page Web principale, d'une image générée par image2, de captures d'écran, d'une maquette, d'une exportation Figma ou d'un ensemble d'images de référence locale, cette compétence est utilisée. La compétence impose que : le projet principal est la seule source visuelle ; les matériaux sont découpés uniquement à partir des images de référence ; aucun élément de conception original n'est créé ; aucun actif externe n’est utilisé ; la fonctionnalité métier est strictement préservée ; et grâce aux captures d'écran, aux bords des actifs, aux occlusions, à la réactivité, au z-index et aux contrôles de régression, la page est assurée d'être répliquée aussi près que possible.
