Quando Codex deve eseguire una replica pixel-perfect o una ricostruzione visiva del front-end di un sito Web esistente sulla base di un mockup di web design principale, un'immagine generata da image2, screenshot, un mockup, un'esportazione Figma o una raccolta di immagini di riferimento locale, viene utilizzata questa abilità. Questa competenza viene applicata rigorosamente: il design principale è l'unica fonte visiva, i materiali vengono ritagliati solo da immagini di riferimento, non vengono creati elementi di design originali, non vengono utilizzate risorse esterne, la funzionalità aziendale è rigorosamente preservata e, attraverso screenshot, bordi delle risorse, occlusione, reattività, z-index e controlli di regressione, viene garantita la replica della pagina il più vicino possibile a uno a uno.
