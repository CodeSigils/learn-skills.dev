Quando Codex deve eseguire una replica pixel-perfect o una ricostruzione visiva del front-end di un sito Web esistente basato sul design di una pagina Web principale, un'immagine generata da Image2, screenshot, mockup, esportazione Figma o un set di immagini di riferimento locale, viene utilizzata questa competenza. L'abilità impone che: il progetto principale sia l'unica fonte visiva; i materiali vengono tagliati solo dalle immagini di riferimento; non vengono creati elementi di design originali; non vengono utilizzate risorse esterne; la funzionalità aziendale è rigorosamente preservata; e attraverso screenshot, bordi delle risorse, occlusioni, reattività, z-index e controlli di regressione, viene garantita la replica della pagina il più vicino possibile a uno a uno.
