Verwenden Sie dies, wenn Codex eine pixelgenaue Replikation oder visuelle Rekonstruktion eines vorhandenen Website-Frontends auf der Grundlage eines Master-Webseitendesigns, eines mit Image2 generierten Bildes, Screenshots, Modellen, Figma-Exports oder einer lokalen Referenzbildsammlung durchführen muss. Diese Fähigkeit erzwingt die folgenden Regeln: Das Master-Design ist die einzige visuelle Quelle, Materialien werden nur aus den Referenzbildern ausgeschnitten, es werden keine Original-Designelemente erstellt, es werden keine externen Assets verwendet, die Geschäftsfunktionalität bleibt strikt erhalten und durch Screenshots, Asset-Kanten, Verdeckungen, Reaktionsfähigkeit, Z-Index und Regressionstests wird sichergestellt, dass die Seite so eins-zu-eins wie möglich reproduziert wird.
