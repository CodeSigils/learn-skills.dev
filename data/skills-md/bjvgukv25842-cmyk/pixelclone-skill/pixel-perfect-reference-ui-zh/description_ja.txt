Codex が、単一の Web ページ全体のデザイン、image2 で生成された画像、スクリーンショット、モックアップ、Figma エクスポート、またはローカル参照画像コレクションに基づいて、既存の Web サイトのフロントエンドのピクセル完璧なコピーまたは視覚的な再構築を実行する必要がある場合にこれを使用します。このスキルでは、デザイン全体が唯一のビジュアル ソースであり、アセットは参照画像からのみ切り取られ、オリジナルのデザイン要素は作成されず、外部アセットは使用されず、ビジネス機能は厳密に保持され、スクリーンショット、アセット エッジ、オクルージョン、応答性、Z インデックス、回帰チェックを通じて、ページが可能な限り 1 対 1 のレプリカに近い状態で再現されます。
