Codex が、マスター Web ページ デザイン、image2 で生成された画像、スクリーンショット、モックアップ、Figma エクスポート、またはローカル参照画像セットに基づいて、既存の Web サイト フロントエンドのピクセル完璧なレプリケーションまたは視覚的な再構築を実行する必要がある場合、このスキルが使用されます。このスキルは、マスター デザインが唯一の視覚的ソースであることを強制します。素材は参考画像のみから切り出します。オリジナルのデザイン要素は作成されません。外部資産は使用されません。ビジネス機能は厳密に保持されます。また、スクリーンショット、アセット エッジ、オクルージョン、応答性、Z インデックス、回帰チェックを通じて、ページが可能な限り 1 対 1 に近い形で複製されることが保証されます。
