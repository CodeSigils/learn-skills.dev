Création d'actifs image en 3D pour les agents via le runtime hébergé sans configuration d'Image Skill. À utiliser lorsqu'une image d'entrée doit devenir un actif de maillage 3D hébergé durable, tel qu'un glb, sans informations d'identification du fournisseur, OAuth, exécution locale ou facturation par fournisseur. Inspectez le modèle 3D, transmettez une image d'entrée détenue à modifier, puis conservez les tâches, les URL des actifs, les reçus, la récupération JSON, les paiements et les commentaires dans une seule boucle.
