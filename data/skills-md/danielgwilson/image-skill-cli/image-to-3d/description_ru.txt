Создание активов из изображения в 3D для агентов с помощью размещенной среды выполнения Image Skill, не требующей установки. Используйте, когда входное изображение должно стать надежным размещенным ресурсом 3D-сетки, например glb, без учетных данных поставщика, OAuth, локальной среды выполнения или выставления счетов для каждого поставщика. Проверьте 3D-модель, передайте для редактирования одно принадлежащее вам входное изображение, а затем сохраняйте задания, URL-адреса активов, квитанции, восстановление JSON, платежи и отзывы в одном цикле.
