Creazione di risorse da immagine a 3D per gli agenti tramite il runtime ospitato senza configurazione di Image Skill. Da utilizzare quando un'immagine di input deve diventare una risorsa mesh 3D ospitata durevole, ad esempio un glb, senza credenziali del fornitore, OAuth, runtime locale o fatturazione per fornitore. Ispeziona il modello 3D, passa un'immagine di input di proprietà da modificare, quindi mantieni lavori, URL di risorse, ricevute, ripristino JSON, pagamenti e feedback in un unico ciclo.
