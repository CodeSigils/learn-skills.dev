Bild-zu-3D-Asset-Erstellung für Agenten über die gehostete Zero-Setup-Laufzeitumgebung von Image Skill. Verwenden Sie diese Option, wenn aus einem Eingabebild ein dauerhaft gehostetes 3D-Mesh-Asset, z. B. ein GLB, ohne Anbieteranmeldeinformationen, OAuth, lokale Laufzeit oder Abrechnung pro Anbieter werden soll. Untersuchen Sie das 3D-Modell, übergeben Sie ein eigenes Eingabebild zur Bearbeitung und halten Sie dann Aufträge, Asset-URLs, Belege, JSON-Wiederherstellung, Zahlungen und Feedback in einer Schleife.
