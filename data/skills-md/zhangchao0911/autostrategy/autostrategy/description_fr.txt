Outil de génération automatique de stratégies de trading quantitatives. Exigences de la stratégie de saisie (claires ou vagues) → analyse approfondie → générer un code de stratégie exécutable + validation du backtest → optimisation automatique.  
Innovation de base : STRATEGY_DESIGN.md fait office de « modèle de système » ; L'IA génère du code par traduction stricte et non par improvisation libre.  
Quatre points d'entrée : (1) exigence claire → analyse directe ; (2) exigence vague → diagnostic et recommandation → analyse ; (3) stratégie existante → optimiser et itérer ; (4) influenceur/blogueur → recherche sur le Web → stratégie de distillation.  
Phrases déclencheurs : « stratégie quantitative », « concevoir une stratégie », « rédiger une stratégie », « backtest », « autostratégie », « génération de stratégie », « quant XX », « stratégie d'investissement XX », « logique d'investissement XX ».  
Déclencheurs de scénario : « Aidez-moi à concevoir une stratégie de croisement de moyenne mobile », « Je veux une stratégie quantitative d'actions A », « Backtestez cette stratégie », « Optimisez ces résultats de backtest ».  
Marchés couverts : actions A / actions de Hong Kong / actions américaines (futures et options non encore prises en charge, à venir plus tard).  
Les stratégies de style célébrité déclenchent également : « Écrire une stratégie d’investissement Buffett », « Quantifier la logique de Duan Yongping », « Construire une stratégie de réflexivité Soros ».  
Déclencheur des stratégies de blogueur : « Élaborer une stratégie du point de vue du blogueur XX », « Coder une stratégie selon l'idée du big-V XX », « Quantifier la méthode de sélection de titres de XX », « Transformer la logique du blogueur XX en stratégie ».
