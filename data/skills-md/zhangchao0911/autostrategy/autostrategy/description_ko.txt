정량적 거래 전략 자동 생성 도구. 입력 전략 요구사항(명확하거나 모호함) → 심층 분석 → 실행 가능한 전략 코드 생성 + 백테스트 검증 → 자동 최적화.  
핵심 혁신: STRATEGY_DESIGN.md는 "시스템 청사진" 역할을 합니다. AI는 자유로운 즉흥 연주가 아닌 엄격한 번역을 통해 코드를 생성합니다.  
4가지 진입점: (1) 명확한 요구사항 → 직접 분석; (2) 모호한 요구사항 → 진단 및 추천 → 분석; (3) 기존 전략 → 최적화 및 반복; (4) 인플루언서/블로거 → 웹 조사 → 증류 전략.  
트리거 문구: "정량적 전략", "전략 설계", "전략 작성", "백테스트", "자동 전략", "전략 생성", "퀀트 XX", "XX 투자 전략", "XX 투자 로직".
