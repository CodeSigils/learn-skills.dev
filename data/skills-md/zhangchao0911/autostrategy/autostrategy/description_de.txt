Tool zur automatischen Generierung quantitativer Handelsstrategien. Eingabestrategieanforderungen (klar oder vage) → eingehende Analyse → ausführbaren Strategiecode generieren + Backtest-Verifizierung → automatische Optimierung.  
Kerninnovation: STRATEGY_DESIGN.md fungiert als „Systemblaupause“; Wenn KI Code generiert, wird dieser strikt übersetzt, anstatt zu improvisieren.  
Vier Einstiegspunkte: (1) klare Strategieanforderung → direkte Analyse (2) vage Anforderung → Diagnose & Empfehlung → erneute Analyse (3) bestehende Strategie → Optimierung & Iteration (4) Influencer/Blogger → Internetrecherche → Strategieextraktion.  
Auslöserphrasen: „Quant-Strategie“, „Design-Strategie“, „Strategie schreiben“, „Backtest“, „Autostrategie“, „Strategiegenerierung“, „Quant XX“, „XX-Investmentstrategie“, „XX-Investmentlogik“.  
Szenarioauslöser: „Helfen Sie mir, eine Crossover-Strategie mit gleitendem Durchschnitt zu entwerfen“, „Ich möchte eine quantitative A-Aktien-Strategie entwickeln“, „Backtest dieser Strategie“, „Optimieren Sie die Backtest-Ergebnisse dieser Strategie“.  
Anwendbare Märkte: A-Aktien / HK-Aktien / US-Aktien (Futures und Optionen werden noch nicht unterstützt, werden in späteren Versionen hinzugefügt).  
Strategien im Promi-Stil lösen auch Folgendes aus: „Schreiben Sie eine Anlagestrategie für Warren Buffett“, „quantifizieren Sie Duan Yongpings Anlagelogik“, „Helfen Sie mir, eine Soros-Reflexivitätsstrategie zu entwickeln“.  
Auslöser der Blogger-Strategie: „Entwickeln Sie eine Strategie basierend auf der Investitionsansicht von Blogger XX“, „Schreiben Sie eine Strategie, die der Idee von Big-V XX folgt“, „Helfen Sie mir, die Aktienauswahlmethode von XX zu quantifizieren“, „wandeln Sie die Investitionslogik von Blogger XX in eine Strategie um“.
