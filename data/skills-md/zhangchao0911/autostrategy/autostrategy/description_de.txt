Tool zur automatischen Generierung quantitativer Handelsstrategien. Anforderungen an die Eingabestrategie (klar oder vage) → eingehende Analyse → ausführbaren Strategiecode generieren + Backtest-Validierung → automatische Optimierung.  
Kerninnovation: STRATEGY_DESIGN.md fungiert als „Systemblaupause“; KI generiert Code durch strikte Übersetzung, nicht durch freie Improvisation.  
Vier Einstiegspunkte: (1) klare Anforderung → direkte Analyse; (2) vage Anforderung → Diagnose und Empfehlung → Analyse; (3) bestehende Strategie → optimieren & iterieren; (4) Influencer/Blogger → Webrecherche → Strategie destillieren.  
Auslöserphrasen: „Quantitative Strategie“, „Strategie entwerfen“, „Strategie schreiben“, „Backtest“, „Autostrategie“, „Strategiegenerierung“, „Quant XX“, „XX Anlagestrategie“, „XX Anlagelogik“.  
Szenarioauslöser: „Helfen Sie mir, eine Crossover-Strategie mit gleitendem Durchschnitt zu entwerfen“, „Ich möchte eine quantitative A-Aktien-Strategie“, „Backtest dieser Strategie“, „Optimieren Sie diese Backtest-Ergebnisse“.  
Abgedeckte Märkte: A-Aktien / HK-Aktien / US-Aktien (Futures und Optionen werden noch nicht unterstützt, folgen später).  
Strategien im Promi-Stil lösen auch Folgendes aus: „Schreiben Sie eine Buffett-Investitionsstrategie“, „Quantifizieren Sie Duan Yongpings Logik“, „Entwickeln Sie eine Soros-Reflexivitätsstrategie“.  
Blogger-Strategien lösen Folgendes aus: „Erstellen Sie eine Strategie aus der Sicht von Blogger XX“, „Kodieren Sie eine Strategie gemäß der Idee von Big-V XX“, „Quantifizieren Sie die Aktienauswahlmethode von XX“, „Verwandeln Sie die Logik von Blogger XX in eine Strategie“.
