Strumento di generazione automatica della strategia di trading quantitativo. Inserisci una richiesta di strategia (chiara o fuzzy) → analisi approfondita → fornisci codice eseguibile + convalida del backtest → ottimizzazione automatica.  
Innovazione fondamentale: STRATEGY_DESIGN.md funge da “progetto di sistema”; quando l’intelligenza artificiale scrive il codice, lo traduce rigorosamente invece di improvvisare.  
Quattro punti di ingresso:  
1) Richiesta chiara → analisi diretta  
2) Richiesta fuzzy → diagnostica e consiglia → quindi analizza  
3) Strategia esistente → ottimizzare e iterare  
4) Influencer/blogger → ricerca web → strategia distillata  

Frasi trigger: “strategia quantitativa”, “progettare una strategia”, “scrivere una strategia”, “test retrospettivo”, “autostrategia”, “generazione di strategie”, “quant XX”, “strategia di investimento XX”, “logica di investimento XX”.  
Trigger dello scenario: “Aiutami a progettare una strategia crossover a media mobile”, “Voglio una strategia quantitativa per le azioni A”, “Effettuare il test retrospettivo di questa strategia”, “Migliorare i risultati del test retrospettivo di questa strategia”.  
Mercati coperti: azioni A/azioni HK/azioni USA (future e opzioni verranno fornite più avanti).  
Scattano anche richieste in stile celebrità: “Codificare una strategia Buffett”, “Quantificare la logica di Duan Yongping”, “Costruire una strategia di riflessività Soros”.  
Le richieste dei blogger si attivano: "Trasforma la visione di blogger XX in una strategia", "Codifica una strategia in base all'idea di big-V XX", "Quantifica il metodo di selezione titoli di XX", "Crea una strategia dalla logica di blogger XX".
