Strumento di generazione automatica della strategia di trading quantitativo. Requisiti della strategia di input (chiari o vaghi) → analisi approfondita → generazione di codice di strategia eseguibile + convalida del backtest → ottimizzazione automatica.  
Innovazione fondamentale: STRATEGY_DESIGN.md funge da "progetto di sistema"; L’intelligenza artificiale genera codice mediante una traduzione rigorosa, non mediante una libera improvvisazione.  
Quattro punti di ingresso: (1) requisito chiaro → analisi diretta; (2) requisito vago → diagnosi e raccomandazione → analisi; (3) strategia esistente → ottimizzare e iterare; (4) influencer/blogger → ricerca web → strategia distillata.  
Frasi trigger: “strategia quantitativa”, “progettare una strategia”, “scrivere una strategia”, “backtest”, “autostrategia”, “generazione di strategie”, “quant XX”, “strategia di investimento XX”, “logica di investimento XX”.  
Trigger dello scenario: “Aiutami a progettare una strategia crossover a media mobile”, “Voglio una strategia quantitativa per azioni A”, “Backtest di questa strategia”, “Ottimizza questi risultati del backtest”.  
Mercati coperti: azioni A/azioni HK/azioni USA (future e opzioni non ancora supportati, disponibili in seguito).  
Si innescano anche strategie in stile celebrità: “Scrivere una strategia di investimento di Buffett”, “Quantificare la logica di Duan Yongping”, “Costruire una strategia di riflessività di Soros”.  
Le strategie dei blogger si attivano: "Crea una strategia dal punto di vista di blogger XX", "Codifica una strategia in base all'idea di big-V XX", "Quantifica il metodo di selezione titoli di XX", "Trasforma la logica di blogger XX in una strategia".
