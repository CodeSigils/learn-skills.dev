À utiliser lors de l'analyse d'un référentiel de code local et de la production de diagrammes d'architecture, d'organigrammes logiques de code, de graphiques d'appel de code et d'exemples de données fictives étape par étape. Déclenchez lorsque l'utilisateur souhaite comprendre un projet inconnu, documenter la structure du système, expliquer le flux d'exécution ou générer des documents markdown dans le répertoire de documents du projet cible.
