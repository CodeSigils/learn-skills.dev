Da utilizzare durante l'analisi di un repository di codice locale e la produzione di diagrammi di architettura, diagrammi di flusso logico del codice, grafici di chiamate di codice ed esempi di dati simulati fase per fase. Si attiva quando l'utente desidera comprendere un progetto non familiare, documentare la struttura del sistema, spiegare il flusso di esecuzione o generare documenti di markdown nella directory dei documenti del progetto di destinazione.
