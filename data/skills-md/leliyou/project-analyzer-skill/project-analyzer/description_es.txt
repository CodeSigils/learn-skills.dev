Úselo al analizar un repositorio de código local y producir diagramas de arquitectura, diagramas de flujo de lógica de código, gráficos de llamadas de código y ejemplos de datos simulados etapa por etapa. Se activa cuando el usuario desea comprender un proyecto desconocido, documentar la estructura del sistema, explicar el flujo de ejecución o generar documentos de rebajas en el directorio de documentos del proyecto de destino.
