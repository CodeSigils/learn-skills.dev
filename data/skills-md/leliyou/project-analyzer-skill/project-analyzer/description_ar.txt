يُستخدم عند تحليل مستودع تعليمات برمجية محلي وإنتاج مخططات معمارية ومخططات تدفق منطقية للتعليمات البرمجية ورسوم بيانية لاستدعاء التعليمات البرمجية وأمثلة بيانات وهمية خطوة بخطوة. يتم تشغيله عندما يريد المستخدم فهم مشروع غير مألوف، أو توثيق بنية النظام، أو شرح تدفق التنفيذ، أو إنشاء مستندات تخفيض السعر ضمن دليل مستندات المشروع المستهدف.
