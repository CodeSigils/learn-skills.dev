Управляйте автоматически возобновляемыми подписками с помощью инструмента командной строки asc.
Используйте этот навык, когда:
(1) Группы подписки: «по возрастанию списка групп подписки|создать|обновить|удалить»
(2) Локализации группы подписки (настраиваемое имя приложения для каждой локали): «asc список локализаций группы подписки|создать|обновить|удалить»
(3) Подписки: «список подписок по возрастанию|создать|обновить|удалить|отправить|отменить отправку»
(4) Цены на подписку: «список цен на подписки по возрастанию», «набор цен на подписки по возрастанию» (для каждой территории, с учетом доходов за второй год).
(5) Локализации по подписке: «по возрастанию списка локализаций по подписке|создать|обновить|удалить»
(6) Вступительные предложения: «список предложений по подписке|создать|удалить» (FREE_TRIAL, PAY_AS_YOU_GO, PAY_UP_FRONT)
(7) Рекламные предложения (в приложении, с ценами для каждой территории): «список рекламных предложений по подписке по возрастанию | создать | удалить», «список цен на рекламные предложения по подписке по возрастанию»
(8) Предложения возврата (истекшие подписчики): «список предложений возврата по возрастанию|создать|обновить|удалить», «список цен на предложения возврата по возрастанию»
(9) Коды предложений (3 уровня): «список кодов предложений подписки по возрастанию/создание/обновление», «список цен на коды предложений подписки по возрастанию», пользовательские коды, одноразовые коды (включая `значения` для погашения CSV)
(10) Скриншот обзора подписки: «asc подписка-обзор-скриншот get|upload|delete»
(11) Пользователь говорит «группа подписки», «уровень подписки», «рекламное предложение», «предложение возврата», «прекращенный подписчик», «код предложения подписки», «пользовательский код», «одноразовые коды», «бесплатная пробная версия», «промокод», «скриншот обзора», «Пользовательское имя приложения».
