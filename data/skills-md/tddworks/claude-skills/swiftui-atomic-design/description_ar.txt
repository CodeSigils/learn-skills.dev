دليل لبناء مكونات SwiftUI باستخدام منهجية التصميم الذري الخاصة ببراد فروست - تنظيم طرق العرض في الذرات والجزيئات والكائنات الحية والقوالب والصفحات باستخدام رموز التصميم الخاصة بها. استخدم هذه المهارة عند إنشاء مكونات SwiftUI UI جديدة، أو إعادة هيكلة طرق العرض الحالية إلى أجزاء قابلة لإعادة الاستخدام، أو إنشاء نظام تصميم، أو تنظيم مكتبة مكونات. يتم تشغيله أيضًا عندما يذكر المستخدم "التصميم الذري"، أو "نظام التصميم"، أو "التسلسل الهرمي للمكونات"، أو "المكونات القابلة لإعادة الاستخدام"، أو "الذرات والجزيئات"، أو "الرموز المميزة للتصميم"، أو يريد تحليل عرض SwiftUI المعقد إلى أجزاء أصغر قابلة للتركيب، أو يحتاج إلى تنفيذ السمات/التخصيص عبر تطبيق SwiftUI.
