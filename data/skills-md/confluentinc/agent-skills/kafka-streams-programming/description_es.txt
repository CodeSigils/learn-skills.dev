Diseñe, cree y depure aplicaciones Kafka Streams (procesamiento de secuencias integrado en JVM). Úselo cuando el usuario mencione KStream, KTable, topología, TopologyTestDriver, StreamsBuilder, consultas interactivas, GlobalKTable, uniones/ventanas/agregaciones o problemas de depuración (reequilibrio, almacenes de estado, retrasos, errores de deserialización). NO active para Flink, conectores, CDC o simple productor/consumidor.
