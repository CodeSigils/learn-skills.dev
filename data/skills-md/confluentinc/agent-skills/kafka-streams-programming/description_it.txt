Architetta, crea ed esegui il debug delle app Kafka Streams (elaborazione del flusso incorporata in JVM). Da utilizzare quando l'utente menziona KStream, KTable, topologia, TopologyTestDriver, StreamsBuilder, query interattive, GlobalKTable, join/finestre/aggregazioni o problemi di debug (ribilanciamento, archivi di stati, ritardo, errori di deserializzazione). NON attivare per Flink, connettori, CDC o semplice produttore/consumatore.
