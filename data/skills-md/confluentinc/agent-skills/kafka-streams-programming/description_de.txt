Entwerfen, erstellen und debuggen Sie Kafka Streams-Apps (in JVM eingebettete Stream-Verarbeitung). Wird verwendet, wenn der Benutzer KStream, KTable, Topologie, TopologyTestDriver, StreamsBuilder, interaktive Abfragen, GlobalKTable, Joins/Windows/Aggregationen oder Debugging-Probleme (Neuverteilung, Statusspeicher, Verzögerung, Deserialisierungsfehler) erwähnt. NICHT für Flink, Anschlüsse, CDC oder einfachen Producer/Consumer auslösen.
