Utilice esta habilidad cuando el usuario le pida al agente que abra, explore, inspeccione, extraiga contenido, haga clic, complete formularios, haga capturas de pantalla o verifique una página web con un navegador. Úselo también para escenarios de MoviePilot que necesitan interacción con el navegador, como verificar la página de un sitio, confirmar un resultado generado por JavaScript, probar el estado de inicio de sesión, capturar errores visibles o actualizar y validar las cookies del sitio de seguimiento.
