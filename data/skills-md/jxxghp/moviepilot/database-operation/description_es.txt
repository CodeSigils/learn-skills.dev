Utilice esta habilidad cuando necesite ejecutar SQL en la base de datos MoviePilot. Esta habilidad lo guía a través de la conexión a la base de datos y la ejecución de declaraciones SQL. El tipo de base de datos (SQLite o PostgreSQL) y los detalles de la conexión se proporcionan en el indicador del sistema <system_info>. Los escenarios aplicables incluyen: 1) El usuario pregunta sobre estadísticas, recuentos o agregaciones de datos que las herramientas existentes no cubren; 2) El usuario desea inspeccionar, modificar o corregir registros de bases de datos sin procesar; 3) El usuario solicita limpiar datos, actualizar registros o realizar mantenimiento de base de datos; 4) El usuario hace preguntas como "cuántas descargas", "muéstrame las estadísticas del sitio", "eliminar registros antiguos", etc.
