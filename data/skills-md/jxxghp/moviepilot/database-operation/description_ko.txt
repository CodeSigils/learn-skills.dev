MoviePilot 데이터베이스에 대해 SQL을 실행해야 할 때 이 기술을 사용하십시오. 이 기술은 데이터베이스에 연결하고 SQL 문을 실행하는 과정을 안내합니다. 데이터베이스 유형(SQLite 또는 PostgreSQL) 및 연결 세부 정보는 시스템 프롬프트 <system_info>에 제공됩니다. 적용 가능한 시나리오는 다음과 같습니다. 1) 사용자가 기존 도구에서 다루지 않는 데이터 통계, 개수 또는 집계에 대해 질문합니다. 2) 사용자가 원시 데이터베이스 기록을 검사, 수정 또는 수정하기를 원합니다. 3) 사용자가 데이터 정리, 기록 업데이트, 데이터베이스 유지 관리 수행을 요청하는 경우 4) 사용자는 "다운로드 횟수", "사이트 통계 보여줘", "오래된 기록 삭제" 등과 같은 질문을 합니다.
