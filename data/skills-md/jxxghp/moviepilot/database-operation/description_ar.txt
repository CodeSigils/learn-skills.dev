استخدم هذه المهارة عندما تحتاج إلى تنفيذ SQL مقابل قاعدة بيانات MoviePilot. ترشدك هذه المهارة خلال الاتصال بقاعدة البيانات وتنفيذ عبارات SQL. يتم توفير نوع قاعدة البيانات (SQLite أو PostgreSQL) وتفاصيل الاتصال في موجه النظام <system_info>. تتضمن السيناريوهات القابلة للتطبيق ما يلي: 1) يسأل المستخدم عن إحصائيات البيانات أو الأعداد أو التجميعات التي لا تغطيها الأدوات الموجودة؛ 2) يريد المستخدم فحص سجلات قاعدة البيانات الأولية أو تعديلها أو إصلاحها؛ 3) يطلب المستخدم تنظيف البيانات أو تحديث السجلات أو إجراء صيانة قاعدة البيانات؛ 4) يطرح المستخدم أسئلة مثل "كم عدد التنزيلات"، "إظهار إحصائيات الموقع"، "حذف السجلات القديمة"، وما إلى ذلك.
