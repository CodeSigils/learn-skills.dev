Utilisez cette compétence lorsque vous devez exécuter SQL sur la base de données MoviePilot. Cette compétence vous guide tout au long de la connexion à la base de données et de l'exécution des instructions SQL. Le type de base de données (SQLite ou PostgreSQL) et les détails de connexion sont fournis dans l'invite système <system_info>. Les scénarios applicables incluent : 1) L'utilisateur pose des questions sur les statistiques, les décomptes ou les agrégations de données que les outils existants ne couvrent pas ; 2) L'utilisateur souhaite inspecter, modifier ou corriger les enregistrements bruts de la base de données ; 3) L'utilisateur demande de nettoyer les données, de mettre à jour les enregistrements ou d'effectuer la maintenance de la base de données ; 4) L'utilisateur pose des questions telles que « combien de téléchargements », « me montrer les statistiques du site », « supprimer les anciens enregistrements », etc.
