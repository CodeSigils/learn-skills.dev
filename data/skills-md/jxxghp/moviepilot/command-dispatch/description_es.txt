Utilice esta habilidad cuando la intención del usuario sea ejecutar una función del sistema o complemento. Los escenarios aplicables incluyen: 1) El usuario envía un comando de barra diagonal que comienza con / (por ejemplo, /cookiecloud, /sites, /subscribes, etc.); 2) El usuario describe una acción en lenguaje natural que puede realizarse mediante un comando del sistema o de un complemento (por ejemplo, "sincronizar sitios", "mostrar suscripciones", "actualizar suscripciones", "verificar descargas", etc.). Esta habilidad le ayuda a identificar la intención del usuario, encontrar el comando correspondiente, extraer los parámetros necesarios y ejecutar el comando correspondiente.
