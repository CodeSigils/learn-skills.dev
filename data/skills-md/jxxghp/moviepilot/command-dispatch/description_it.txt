Utilizza questa abilità quando l'intento dell'utente è eseguire una funzione di sistema o plug-in. Gli scenari applicabili includono: 1) L'utente invia un comando slash che inizia con / (ad esempio /cookiecloud, /sites, /subscribes, ecc.); 2) L'utente descrive un'azione in linguaggio naturale che può essere compiuta da un comando di sistema o plugin (es. "sincronizza siti", "mostra abbonamenti", "aggiorna abbonamenti", "controlla download", ecc.). Questa abilità ti aiuta a identificare l'intento dell'utente, trovare il comando corrispondente, estrarre i parametri necessari ed eseguire il comando corrispondente.
