Utilisez cette compétence lorsque l'intention de l'utilisateur est d'exécuter une fonction du système ou du plugin. Les scénarios applicables incluent : 1) L'utilisateur envoie une commande slash commençant par / (par exemple /cookiecloud, /sites, /subscribes, etc.) ; 2) L'utilisateur décrit une action en langage naturel qui peut être exécutée par une commande système ou plugin (par exemple « synchroniser les sites », « afficher les abonnements », « actualiser les abonnements », « vérifier les téléchargements », etc.). Cette compétence vous aide à identifier l'intention de l'utilisateur, à trouver la commande correspondante, à extraire les paramètres nécessaires et à exécuter la commande correspondante.
