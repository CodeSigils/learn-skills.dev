Utilice esta habilidad cuando un usuario proporciona un nombre de torrent o de archivo y desea solucionar problemas de reconocimiento, o solicita agregar/administrar identificadores personalizados (自定义识别词). Esta habilidad genera reglas de identificación basadas en la lógica de preprocesamiento de WordsMatcher, busca duplicados con respecto a las reglas existentes y las guarda mediante herramientas MCP. Los escenarios aplicables incluyen: 1) Un torrent o nombre de archivo se reconoce incorrectamente (título, temporada, episodio, etc. incorrectos); 2) El usuario desea bloquear palabras clave no deseadas de los nombres de torrents; 3) El usuario necesita reglas de compensación de episodios para series con numeración no estándar; 4) El usuario desea forzar el reconocimiento de un medio específico mediante TMDB/Douban ID.
