Utilizza questa abilità quando un utente fornisce un nome torrent o un nome file e desidera risolvere problemi di riconoscimento o chiede di aggiungere/gestire identificatori personalizzati (自定义识别词). Questa abilità genera regole di identificazione basate sulla logica di preelaborazione di WordsMatcher, controlla i duplicati rispetto alle regole esistenti e li salva tramite gli strumenti MCP. Gli scenari applicabili includono: 1) Un torrent o un nome di file viene riconosciuto in modo errato (titolo, stagione, episodio errato, ecc.); 2) L'utente desidera bloccare le parole chiave indesiderate dai nomi torrent; 3) L'utente necessita di regole di offset degli episodi per le serie con numerazione non standard; 4) L'utente desidera forzare il riconoscimento di un supporto specifico tramite TMDB/Douban ID.
