사용자가 토렌트 이름이나 파일 이름을 제공하고 인식 문제를 해결하고 싶거나 사용자 정의 식별자 추가/관리(自定义识别词)를 요청하는 경우 이 기술을 사용하세요. 이 기술은 WordsMatcher 전처리 논리를 기반으로 식별자 규칙을 생성하고 기존 규칙과 중복되는지 확인하며 MCP 도구를 통해 저장합니다. 적용 가능한 시나리오는 다음과 같습니다: 1) 토렌트 또는 파일 이름이 잘못 인식됩니다(잘못된 제목, 시즌, 에피소드 등). 2) 사용자가 토렌트 이름에서 원치 않는 키워드를 차단하려고 합니다. 3) 사용자는 비표준 번호 매기기를 사용하는 시리즈에 대한 에피소드 오프셋 규칙이 필요합니다. 4) 사용자가 TMDB/Douban ID로 특정 미디어를 강제로 인식하려고 합니다.
