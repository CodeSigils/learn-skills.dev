استخدم هذه المهارة عندما تحتاج إلى الاتصال بنقاط نهاية MoviePilot REST API مباشرةً. يغطي جميع نقاط نهاية واجهة برمجة التطبيقات البالغ عددها 237 نقطة عبر 27 فئة بما في ذلك البحث عن الوسائط والتنزيلات والاشتراكات وإدارة المكتبات وإدارة الموقع وإدارة النظام والمكونات الإضافية وسير العمل والمزيد. استخدم هذه المهارة عندما يطلب المستخدم التفاعل مع MoviePilot عبر HTTP API الخاص به، أو عندما لا تتمكن مهارة moviepilot-cli من تغطية عملية معينة.
