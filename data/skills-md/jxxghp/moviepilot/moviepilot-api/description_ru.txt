Используйте этот навык, когда вам нужно напрямую вызвать конечные точки REST API MoviePilot. Охватывает все 237 конечных точек API в 27 категориях, включая поиск мультимедиа, загрузки, подписки, управление библиотеками, управление сайтами, системное администрирование, плагины, рабочие процессы и многое другое. Используйте этот навык всякий раз, когда пользователь запрашивает взаимодействие с MoviePilot через его HTTP API или когда навык Moviepilot-cli не может охватить конкретную операцию.
