Verwenden Sie diesen Skill, wenn der Benutzer einen MoviePilot-Agenten-Skill erstellen, aufbauen, aktualisieren oder überprüfen möchte. Dazu gehört das Hinzufügen eines neuen integrierten Skills im Repository-Verzeichnis „skills/“, das Bearbeiten eines vorhandenen integrierten Skills, das Schreiben von „SKILL.md“-Frontmatter- und Workflow-Anweisungen, die Auswahl von „allowed-tools“, das Hinzufügen von Hilfsskripten bei Bedarf und das Erhöhen der „Version“ des integrierten Skills, damit Änderungen in „config/agent/skills“ synchronisiert werden können.
