Utilizzare questa competenza SOLO quando l'utente richiede ESPLICITAMENTE di segnalare un problema upstream per il core MoviePilot, il frontend o un plug-in installato, ad esempio "反馈 issue", "提 issue", "报 bug", "给 MP 提 issue", "让上游修一下", "提交错误报告", "提问题", "提需求", "功能请求", o inglese "presenta un problema/segnala un bug/apri un problema upstream/richiesta di funzionalità". Una semplice segnalazione del problema non è sufficiente: diagnosticare prima localmente. Questa abilità utilizza i propri script in "script/"; non aggiunge né chiama strumenti Agent dedicati per raccogliere/preparare/inviare.
