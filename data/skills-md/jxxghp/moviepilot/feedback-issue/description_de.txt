Verwenden Sie diesen Skill NUR, wenn der Benutzer AUSDRÜCKLICH die Einreichung eines Upstream-Problems für den MoviePilot-Kern, das Frontend oder ein installiertes Plugin anfordert, zum Beispiel „反馈 issue“, „提 issue“, „报 bug“, „给 MP 提 issue“, „让上游修一下“, „提交错误报告“, „提问题“, „提需求“, „功能请求“ oder Englisch „ein Problem einreichen / einen Fehler melden / ein Upstream-Problem / eine Funktionsanfrage öffnen“. Eine bloße Problemmeldung reicht nicht aus: Führen Sie zunächst eine lokale Diagnose durch. Dieser Skill verwendet seine eigenen Skripte unter „scripts/“; Es werden keine dedizierten Agent-Tools zum Sammeln/Vorbereiten/Senden hinzugefügt oder aufgerufen.
