استخدم هذه المهارة عندما يطلب المستخدم نشر مكون إضافي محلي لـ MoviePilot أو تحميله أو مزامنته أو سحبه أو دفعه أو فرقه أو الاحتفاظ به في مستودع GitHub. يغطي استخدام رمز MoviePilot GitHub الذي تم تكوينه، ومستودعات المكونات الإضافية المحلية PLUGIN_LOCAL_REPO_PATHS، والبيانات التعريفية package.json/package.v2.json، وتخطيطات المكونات الإضافية/plugins.v2، واستبعاد الملفات الآمنة، ومعاينة الفرق قبل النشر، وتحديثات GitHub Contents API المتزايدة، ومزامنة تغييرات المكونات الإضافية المحلية مرة أخرى من GitHub. يتضمن السؤال عما إذا كان سيتم استخدام مستودع موجود أو إنشاء مستودع عام جديد في حالة عدم توفر مستودع مستهدف. استخدم أيضًا للطلبات الصينية التي تذكر 插件发布، 插件维护، 推送插件到 GitHub، 从 GitHub 拉取插件، 同步本地插件仓库، أفضل ما في الأمر هو أن هناك الكثير من الأشياء.
