Verwenden Sie diese Fähigkeit, wenn der Benutzer ein lokales MoviePilot-Plugin in einem GitHub-Repository veröffentlichen, hochladen, synchronisieren, ziehen, pushen, vergleichen oder verwalten möchte. Behandelt die Verwendung des konfigurierten MoviePilot GitHub-Tokens, PLUGIN_LOCAL_REPO_PATHS lokale Plugin-Repositorys, package.json/package.v2.json-Metadaten, Plugins/plugins.v2-Layouts, sicheren Dateiausschluss, Diff-Vorschau vor der Veröffentlichung, inkrementelle GitHub Contents API-Updates und die Synchronisierung lokaler Plugin-Änderungen zurück von GitHub. Beinhaltet die Frage, ob ein vorhandenes Repository verwendet oder ein neues öffentliches Repository erstellt werden soll, wenn kein Ziel-Repository verfügbar ist. Auch für chinesische Anfragen verwenden, die 插件发布, 插件维护, 推送插件到 GitHub, 从 GitHub 拉取插件, 同步本地插件仓库,增量发布插件, 插件仓库维护.
