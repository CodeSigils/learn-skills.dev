Utilice esta habilidad cuando el usuario solicite publicar, cargar, sincronizar, extraer, insertar, diferenciar o mantener un complemento local de MoviePilot en un repositorio de GitHub. Cubre el uso del token MoviePilot GitHub configurado, repositorios de complementos locales PLUGIN_LOCAL_REPO_PATHS, metadatos de package.json/package.v2.json, diseños de complementos/plugins.v2, exclusión segura de archivos, vista previa de diferencias antes de publicar, actualizaciones incrementales de la API de contenido de GitHub y sincronización de cambios de complementos locales desde GitHub. Incluye preguntar si se debe utilizar un repositorio existente o crear un nuevo repositorio público cuando no haya ningún repositorio de destino disponible. Úselo también para solicitudes en chino que mencionen 插件发布, 插件维护, 推送插件到 GitHub, 从 GitHub 拉取插件, 同步本地插件仓库,增量发布插件, 插件仓库维护.
