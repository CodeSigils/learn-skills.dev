Utilizza questa abilità quando l'utente chiede di pubblicare, caricare, sincronizzare, estrarre, inviare, fare diff o mantenere un plug-in locale MoviePilot in un repository GitHub. Riguarda l'utilizzo del token GitHub MoviePilot configurato, i repository di plug-in locali PLUGIN_LOCAL_REPO_PATHS, i metadati package.json/package.v2.json, i layout plugins/plugins.v2, l'esclusione sicura dei file, l'anteprima diff prima della pubblicazione, gli aggiornamenti incrementali dell'API dei contenuti GitHub e la sincronizzazione delle modifiche dei plug-in locali da GitHub. Include la richiesta se utilizzare un repository esistente o creare un nuovo repository pubblico quando non è disponibile alcun repository di destinazione. Utilizzare anche per le richieste cinesi che menzionano 插件发布, 插件维护, 推送插件到 GitHub, 从 GitHub 拉取插件, 同步本地插件仓库,增量发布插件, 插件仓库维护.
