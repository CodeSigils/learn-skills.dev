Utilisez cette compétence lorsque l'utilisateur demande à publier, télécharger, synchroniser, extraire, pousser, comparer ou maintenir un plugin local MoviePilot dans un référentiel GitHub. Couvre l'utilisation du jeton MoviePilot GitHub configuré, les référentiels de plugins locaux PLUGIN_LOCAL_REPO_PATHS, les métadonnées package.json/package.v2.json, les mises en page plugins/plugins.v2, l'exclusion de fichiers sécurisée, l'aperçu des différences avant la publication, les mises à jour incrémentielles de l'API de contenu GitHub et la synchronisation des modifications du plugin local depuis GitHub. Inclut de demander s'il faut utiliser un référentiel existant ou créer un nouveau référentiel public lorsqu'aucun référentiel cible n'est disponible. À utiliser également pour les requêtes chinoises mentionnant 插件发布, 插件维护, 推送插件到 GitHub, 从 GitHub 拉取插件, 同步本地插件仓库,增量发布插件, 插件仓库维护.
