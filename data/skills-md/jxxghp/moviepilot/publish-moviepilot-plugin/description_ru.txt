Используйте этот навык, когда пользователь запрашивает публикацию, загрузку, синхронизацию, извлечение, отправку, сравнение или поддержку локального плагина MoviePilot в репозитории GitHub. Охватывает использование настроенного токена MoviePilot GitHub, локальных репозиториев плагинов PLUGIN_LOCAL_REPO_PATHS, метаданных package.json/package.v2.json, макетов плагинов/plugins.v2, безопасного исключения файлов, предварительного просмотра различий перед публикацией, дополнительных обновлений API содержимого GitHub и синхронизации локальных изменений плагинов с GitHub. Включает вопрос, использовать ли существующий репозиторий или создать новый общедоступный репозиторий, если целевой репозиторий недоступен. Также используйте для китайских запросов с упоминанием 插件发布, 插件维护, 推送插件到 GitHub, 从 GitHub 拉取插件, 同步本地插件仓库,增量发布插件, 插件仓库维护.
