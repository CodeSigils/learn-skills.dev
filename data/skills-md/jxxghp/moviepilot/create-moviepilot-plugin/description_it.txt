Utilizza questa capacità quando l'utente chiede di creare, modificare, eseguire il debug, convalidare o eseguire lo scaffold di un plug-in locale MoviePilot. Copre lo sviluppo di plugin MoviePilot V2, implementazioni _PluginBase, metadati di mercato package.v2.json/package.json, layout sorgente plugins.v2/plugins, sorgenti plugin locali PLUGIN_LOCAL_REPO_PATHS, API plugin, moduli/pagine/dashboard JSON Vuetify, componenti remoti della federazione dei moduli Vue, get_render_mode, get_sidebar_nav, pagine della barra laterale plugin, comandi, servizi, flusso di lavoro azioni, strumenti dell'agente e flussi di installazione/ricaricamento locale. Utilizzare anche per le richieste cinesi che menzionano 编写插件、本地插件源, 插件开发, V2插件, 插件市场, 本地安装插件, 插件热加载,前端联邦, 侧栏入口, Vue插件页面.
