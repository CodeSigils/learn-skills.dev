Используйте этот навык, когда пользователь просит создать, изменить, отладить, проверить или создать шаблон локального плагина MoviePilot. Охватывает разработку плагинов MoviePilot V2, реализации _PluginBase, рыночные метаданные package.v2.json/package.json, макет исходного кода плагинов.v2/plugins, локальные источники плагинов PLUGIN_LOCAL_REPO_PATHS, API-интерфейсы плагинов, формы/страницы/панели Vuetify JSON, удаленные компоненты федерации модулей Vue, get_render_mode, get_sidebar_nav, страницы боковой панели плагина, команды, службы, действия рабочего процесса, инструменты агента и локальные потоки установки/перезагрузки. Также используйте для китайских запросов с упоминанием 编写插件、本地插件源, 插件开发, V2插件, 插件市场, 本地安装插件, 插件热加载,前端联邦, 侧栏入口, Vue插件页面.
