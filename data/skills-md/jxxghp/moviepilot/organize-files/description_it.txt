Utilizza questa capacità quando l'utente chiede all'agente MoviePilot di identificare e organizzare file multimediali locali/scaricati che il trasferimento automatico non è in grado di gestire. I trigger tipici includono: organizzare manualmente un file o una cartella, organizzare download non riconosciuti, correggere file bloccati in una directory di download, identificare un pacchetto di episodi disordinato, spostare/copiare/collegare file nella libreria o organizzare file tramite ID TMDB/Douban esplicito. Se l'utente fornisce ID della cronologia dei trasferimenti non riusciti, preferisci invece trasferimento non riuscito-riprova.
