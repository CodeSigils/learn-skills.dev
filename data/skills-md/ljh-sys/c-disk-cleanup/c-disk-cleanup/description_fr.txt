Scénario d'utilisation : l'utilisateur demande d'analyser l'espace du lecteur C, de nettoyer le lecteur C, de générer un rapport de nettoyage du lecteur C et d'afficher l'utilisation du disque. Les phrases de déclenchement incluent « analyser le lecteur C », « nettoyer le lecteur C », « nettoyer le lecteur C », « espace disque C », « nettoyage de disque », « résumer une recommandation d’analyse de nettoyage du lecteur C », « donnez-moi un rapport de nettoyage du lecteur C », etc.
