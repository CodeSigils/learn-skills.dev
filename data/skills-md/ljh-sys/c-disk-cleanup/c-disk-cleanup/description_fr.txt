Cas d'utilisation : les utilisateurs demandent à analyser l'espace du lecteur C, à nettoyer le lecteur C, à générer un rapport de nettoyage du lecteur C et à afficher l'utilisation du disque. Les phrases de déclenchement incluent « analyser le lecteur C », « nettoyer le lecteur C », « nettoyer le lecteur C », « espace sur le lecteur C », « nettoyer le disque », « résumer une suggestion d'analyse de nettoyage du lecteur C », « donner-moi un rapport de nettoyage du lecteur C », etc.
