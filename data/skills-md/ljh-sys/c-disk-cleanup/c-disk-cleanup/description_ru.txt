Сценарий использования: пользователь запрашивает анализ места на диске C, очистку диска C, создание отчета об очистке диска C и просмотр использования диска. Триггерные фразы включают в себя «проанализировать диск C», «очистить диск C», «очистить диск C», «пространство на диске C», «очистка диска», «подвести итоги по рекомендациям по анализу очистки диска C», «дать мне отчет об очистке диска C» и т. д.
