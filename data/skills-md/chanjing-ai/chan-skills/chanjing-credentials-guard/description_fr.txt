Exécutez cette compétence avant toute action liée au chanjing. Lorsque l'utilisateur demande à générer ou à configurer des informations d'identification/clés de chanjing (AK/SK), exécutez cette compétence pour le guider : vérifiez si elle est déjà configurée ; si oui, demandez si vous devez présenter une nouvelle demande ; puis ouvrez la page de connexion et affichez les commandes de configuration. TOUJOURS s'exécuter lorsque l'utilisateur demande des informations d'identification/clés de chanjing ou avant toute API de chanjing (liste vocale, TTS, avatar, clone vocal).
