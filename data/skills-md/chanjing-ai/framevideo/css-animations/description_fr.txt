Modèles d'adaptateur d'animation CSS pour FrameVideo. À utiliser lors de la création d'images clés CSS, de synchronisation basée sur le délai d'animation, du mode de remplissage d'animation, de l'état de lecture d'animation ou d'un mouvement CSS uniquement que FrameVideo doit rechercher de manière déterministe lors de l'aperçu et du rendu.
