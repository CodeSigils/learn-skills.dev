Cree un nuevo bloque de registro de FrameVideo (estilo de título, bloque VFX, transición, tercio inferior) o componente (efecto de texto, superposición, fragmento) y envíelo como un PR ascendente al repositorio de framevideo. Úselo SÓLO cuando el usuario quiera CONTRIBUIR al catálogo público: para la creación de subtítulos/transiciones en el proyecto, use la habilidad "framevideo", para instalar elementos de registro existentes, use la habilidad "framevideo-registry".
