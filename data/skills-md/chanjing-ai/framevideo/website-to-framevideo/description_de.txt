Erfassen Sie eine Website und erstellen Sie daraus ein FrameVideo-Video. Verwenden Sie dies, wenn: (1) ein Benutzer eine URL angibt und ein Video möchte, (2) jemand sagt: „Nehmen Sie diese Website auf“, „verwandeln Sie dies in ein Video“, „machen Sie eine Werbung von meiner Website“, (3) der Benutzer möchte eine soziale Anzeige, eine Produkttour oder ein beliebiges Video, das auf einer vorhandenen Website basiert, (4) der Benutzer teilt einen Link und fragt nach Videoinhalten jeglicher Art. Selbst wenn der Benutzer nur eine URL einfügt, ist dies die Fähigkeit, die er nutzen muss.
