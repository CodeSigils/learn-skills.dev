Цикл разработки FrameVideo CLI — `npxframevideo` для создания шаблонов (инициализация), проверки (проверка, проверка), предварительного просмотра, рендеринга и устранения неполадок среды (доктор, браузер, информация, обновление). Используйте при запуске любой из этих команд или устранении неполадок в среде сборки/рендеринга FrameVideo. Для команд предварительной обработки ресурсов («tts», «transcribe», «remove-background») вместо этого вызывайте навык «framevideo-media».
