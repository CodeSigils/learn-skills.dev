Modelli di runtime del browser Tailwind CSS v4.2 per composizioni FrameVideo. Da utilizzare durante lo scaffolding o la modifica di progetti creati con `framevideo init --tailwind`, scrivendo classi di utilità Tailwind in HTML di composizione, aggiungendo token del tema Tailwind v4 CSS-first, eseguire il debug della sintassi v3 vs v4 o decidere quando compilare Tailwind in CSS invece di utilizzare il runtime del browser.
