Translate an existing Remotion (React-based) video composition into a FrameVideo HTML composition. Use ONLY when the user explicitly asks to port, convert, migrate, translate, or rewrite a Remotion composition as FrameVideo (e.g. "port my Remotion project to FrameVideo"). Do NOT use when (a) authoring a NEW FrameVideo composition (even if A/B-testing a Remotion video); (b) Remotion is mentioned in passing; (c) Remotion code is shared as reference, not for translation; (d) the user wants "the same video as my Remotion one" without explicitly asking to migrate the source — treat as a fresh FrameVideo build. When in doubt, default to the `framevideo` skill. Detects unsupported patterns (useState, useEffect side effects, async calculateMetadata, third-party React component libraries, `@remotion/lambda`) and recommends the runtime interop escape hatch instead of a lossy translation.
