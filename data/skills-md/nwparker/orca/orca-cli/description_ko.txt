`orca` CLI를 사용하여 실행 중인 Orca 편집기를 구동하고 Orca 작업 트리를 관리합니다. Orca 관리 터미널에서 셸 명령을 생성하고 읽고 실행합니다. Orca의 내장 브라우저(스냅샷/클릭/채우기/스크린샷/탭)를 자동화합니다. 작업이 Orca 상태에 닿을 때마다 원시 `git worktree`, 임시 쉘 PTY 또는 Playwright 대신 이것을 사용하십시오. Orca 작업 트리 내부의 코딩 에이전트는 이를 사용하여 의미 있는 체크포인트에서 작업 트리 주석을 최신 상태로 유지해야 합니다. '오케스트레이션'의 경계: 터미널 쓰기 수신자가 다른 AI 에이전트(Claude Code, Gemini, Codex, 작업자)인 경우 '오케스트레이션'을 사용하십시오. 에이전트에게 메시지, 넛지, 응답 또는 작업 전달을 보내는 유일한 올바른 방법입니다. orca-cli 쓰기는 에이전트가 아닌 터미널(셸, 빌드/테스트 명령)용입니다. 에이전트 터미널을 포함한 모든 터미널에서 읽기 또는 `대기`는 orca-cli에 유지됩니다.
