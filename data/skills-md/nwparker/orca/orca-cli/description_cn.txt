使用“orca” CLI 驱动正在运行的 Orca 编辑器 — 管理 Orca 工作树；在 Orca 管理的终端中创建、读取和运行 shell 命令；并自动化 Orca 的内置浏览器（快照/单击/填充/屏幕截图/选项卡）。每当任务触及 Orca 状态时，请使用它来代替原始的 `git worktree`、ad hoc shell PTY 或 Playwright。 Orca 工作树内的编码代理也应该使用它来使工作树注释在有意义的检查点保持新鲜。与“编排”的边界：如果终端写入的接收者是另一个人工智能代理（Claude Code、Gemini、Codex、工人），请使用“编排”——这是向代理发送消息、推动、回复或任务移交的唯一正确方法。 orca-cli 写入适用于非代理终端（shell、构建/测试命令）；在任何终端（包括代理终端）上读取或“等待”都会保留在 orca-cli 中。
