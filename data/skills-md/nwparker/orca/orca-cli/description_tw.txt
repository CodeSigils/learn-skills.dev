使用「orca」 CLI 驅動正在執行的 Orca 編輯器 — 管理 Orca 工作樹；在 Orca 管理的終端機中建立、讀取和執行 shell 命令；並自動化 Orca 的內建瀏覽器（快照/點擊/填充/螢幕截圖/標籤）。每當任務觸及 Orca 狀態時，請使用它來取代原始的 `git worktree`、ad hoc shell PTY 或 Playwright。 Orca 工作樹內的編碼代理也應該使用它來使工作樹註釋在有意義的檢查點保持新鮮。與「編排」的邊界：如果終端寫入的接收者是另一個人工智慧代理（Claude Code、Gemini、Codex、工人），請使用「編排」－這是向代理程式發送訊息、推動、回覆或任務移交的唯一正確方法。 orca-cli 寫入適用於非代理終端（shell、建置/測試命令）；在任何終端（包括代理終端）上讀取或「等待」都會保留在 orca-cli 中。
