Herramienta de operación del Proyecto Feishu (Meego/Meegle). Admite consultas y gestión de elementos de trabajo, transiciones de nodos, consultas de visualización, tareas pendientes personales, estadísticas de programación y otras funciones. Úselo cuando el usuario necesite trabajar con la gestión de proyectos de Feishu/Lark Meego, incluida la consulta de elementos de trabajo, la creación/actualización de elementos de trabajo, la finalización de nodos de flujo de trabajo, la verificación de vistas, la lista de tareas pendientes, el análisis de cronogramas/cargas de trabajo o la búsqueda con MQL. Palabras clave: proyecto Feishu, Meego, Meegle, elemento de trabajo, requisito, tarea, defecto, cronograma, vista, tarea pendiente, nodo.
