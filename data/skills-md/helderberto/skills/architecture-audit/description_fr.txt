Explorez une base de code pour faire ressortir les frictions architecturales et proposer des refactorisations de modules approfondis lorsque GitHub publie des RFC. À utiliser lorsque l'utilisateur souhaite améliorer l'architecture, trouver des opportunités de refactorisation, consolider des modules étroitement couplés ou rendre une base de code plus testable et navigable par l'IA. Ne pas utiliser pour de petits refactors ponctuels ou des nettoyages de fichiers uniques.
