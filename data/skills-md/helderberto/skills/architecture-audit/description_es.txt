Explore una base de código para sacar a la luz la fricción arquitectónica y proponer refactores de módulo profundo a medida que GitHub emite RFC. Úselo cuando el usuario desee mejorar la arquitectura, encontrar oportunidades de refactorización, consolidar módulos estrechamente acoplados o hacer que una base de código sea más comprobable y navegable por IA. No lo use para refactorizaciones pequeñas y únicas o limpiezas de un solo archivo.
