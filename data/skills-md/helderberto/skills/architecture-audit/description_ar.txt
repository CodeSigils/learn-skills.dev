استكشف قاعدة التعليمات البرمجية لتوضيح الاحتكاك المعماري واقتراح عمليات إعادة بناء الوحدة العميقة مثل إصدار GitHub لطلبات RFC. يُستخدم عندما يريد المستخدم تحسين البنية، أو العثور على فرص إعادة البناء، أو دمج الوحدات النمطية المقترنة بإحكام، أو جعل قاعدة التعليمات البرمجية أكثر قابلية للاختبار والتنقل عبر الذكاء الاصطناعي. لا تستخدمه مع عمليات إعادة البناء الصغيرة لمرة واحدة أو عمليات تنظيف الملف الفردي.
