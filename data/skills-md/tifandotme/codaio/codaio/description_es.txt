Interactúe con documentos, tablas, filas, páginas y fórmulas de Coda utilizando la CLI de codaio. Utilice esta habilidad siempre que el usuario mencione Coda, coda.io, un documento de Coda, una tabla de Coda o quiera leer/escribir/exportar datos de Coda, incluso si no dice explícitamente "codaio". No llame a la API REST de Coda directamente con curl o fetch; codaio maneja automáticamente la autenticación, paginación, limitación de velocidad y formato de error. Utilice esta habilidad para: leer filas de una tabla Coda, escribir o insertar datos, exportar páginas a Markdown, enumerar documentos, descubrir esquemas de tablas y cualquier otra tarea de datos relacionada con Coda.
