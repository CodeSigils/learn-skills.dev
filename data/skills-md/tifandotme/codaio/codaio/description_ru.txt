Взаимодействуйте с документами, таблицами, строками, страницами и формулами Coda с помощью интерфейса командной строки codaio. Используйте этот навык всякий раз, когда пользователь упоминает Coda, coda.io, документ Coda, таблицу Coda или хочет прочитать/записать/экспортировать данные из Coda — даже если он явно не говорит «codaio». Не вызывайте Coda REST API напрямую с помощью Curl или Fetch; codaio автоматически обрабатывает аутентификацию, нумерацию страниц, ограничение скорости и форматирование ошибок. Используйте этот навык для чтения строк из таблицы Coda, записи или добавления данных, экспорта страниц в уценку, составления списков документов, обнаружения схем таблиц и любых других задач, связанных с данными Coda.
