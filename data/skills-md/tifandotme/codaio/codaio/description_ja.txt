codaio CLI を使用して、Coda ドキュメント、テーブル、行、ページ、および数式を操作します。ユーザーが Coda、coda.io、Coda ドキュメント、Coda テーブルに言及した場合、または Coda からデータの読み取り/書き込み/エクスポートを行う場合は、明示的に「codaio」と言わなくても、このスキルを使用します。 Coda REST API をcurl または fetch で直接呼び出さないでください。 codaio は、認証、ページネーション、レート制限、エラーのフォーマットを自動的に処理します。このスキルは、Coda テーブルからの行の読み取り、データの書き込みまたは更新挿入、マークダウンへのページのエクスポート、ドキュメントの一覧表示、テーブル スキーマの検出、およびその他の Coda 関連のデータ タスクに使用します。
