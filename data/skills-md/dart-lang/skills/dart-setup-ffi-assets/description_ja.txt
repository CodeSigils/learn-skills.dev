Dart の Native Assets フック システム (package:hooks および package:native_toolchain_c を利用する hook/build.dart および hook/link.dart 経由) を使用して、エージェントが C/C++ ソース コードをコンパイルして動的ライブラリまたは静的ライブラリ (コード アセット) にパッケージ化する方法をガイドします。ユーザーが「ネイティブ アセットのセットアップ」、「C/C++ ソース コードのコンパイル」、「ダイナミック ライブラリのバンドル」、「ネイティブ C コードのビルド」、「ネイティブ アセットのリンク」、「build.dart または link.dart フックの実装」、または「Dart/Flutter への C/C++ 相互運用の統合」を要求する場合に使用します。エージェントが手動のツールチェーン オーケストレーションを回避し、安全なハッシュ検証済みバイナリ ダウンロードまたは package:record_use マッピングを使用した高度なリンカー ツリー シェーキングを構成できるようにします。
