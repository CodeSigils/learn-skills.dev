Правила и рекомендации по форматированию для написания документации по API Dart /// и комментариев к документам. Используйте при документировании кода Dart, написании комментариев к документации для любого объявления Dart (библиотеки, классы, методы, переменные и т. д.) или при указании следовать рекомендациям по эффективной документации Dart.
