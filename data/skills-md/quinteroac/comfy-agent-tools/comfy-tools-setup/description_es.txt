Arranque y valide las CLI de Python de las herramientas de agente cómodas para el uso del agente. Úselo cuando el usuario solicite configurar, instalar, actualizar o diagnosticar herramientas de agente cómodo; cuando falta una CLI requerida, como por ejemplo, cómoda-imagegen, cómoda-videogen, cómoda-musicgen o cómodas-modelos; o antes de que otra habilidad cómoda ejecute una CLI en una máquina nueva.
