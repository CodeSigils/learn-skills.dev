قم بتشغيل Bootstrap والتحقق من صحة أدوات Python CLIs المريحة لاستخدام الوكيل. يُستخدم عندما يطلب المستخدم إعداد أدوات comfy-agent-tools أو تثبيتها أو تحديثها أو تشخيصها؛ عندما يكون سطر الأوامر المطلوب مثل comfy-imagegen، أو comfy-videogen، أو comfy-musicgen، أو comfy-models مفقودًا؛ أو قبل أن تقوم مهارة مريحة أخرى بتشغيل CLI على جهاز جديد.
