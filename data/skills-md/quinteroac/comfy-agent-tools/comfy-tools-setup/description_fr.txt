Démarrez et validez les CLI Python confortables-agent-tools pour l’utilisation des agents. À utiliser lorsque l'utilisateur demande à configurer, installer, mettre à jour ou diagnostiquer les outils d'agent confortables ; lorsqu'une CLI requise telle que confortable-imagegen, confortable-videogen, confortable-musicgen ou confortable-modèles est manquante ; ou avant qu'une autre compétence confortable n'exécute une CLI sur une nouvelle machine.
