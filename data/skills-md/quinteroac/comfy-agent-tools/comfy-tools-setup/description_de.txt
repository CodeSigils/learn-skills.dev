Bootstrapping und Validierung der Python-CLIs von „comfort-agent-tools“ für die Verwendung durch Agenten. Wird verwendet, wenn der Benutzer Comfy-Agent-Tools einrichten, installieren, aktualisieren oder diagnostizieren möchte. wenn eine erforderliche CLI wie „comforty-imagegen“, „comforty-videogen“, „comforty-musicgen“ oder „comfortable-models“ fehlt; oder bevor ein anderer komfortabler Skill eine CLI auf einem neuen Computer ausführt.
