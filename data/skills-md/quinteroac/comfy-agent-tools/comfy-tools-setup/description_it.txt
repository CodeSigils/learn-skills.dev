Avvia e convalida le CLI Python di Comodi-Agent-Tools per l'utilizzo da parte dell'agente. Da utilizzare quando l'utente richiede di configurare, installare, aggiornare o diagnosticare gli strumenti comodi-agent; quando manca una CLI richiesta come Comod-imagegen, Comodo-videogen, Comodo-musicgen o Comodo-modelli; o prima che un'altra comoda abilità esegua una CLI su una nuova macchina.
