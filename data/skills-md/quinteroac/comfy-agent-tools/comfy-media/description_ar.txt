قم بمراجعة وسائط أدوات الوكيل المريحة التي تم إنشاؤها، وإنشاء فهارس محلية، وخدمة المعرض، وتصدير العناصر المحددة إلى مشروع بكرة مراجعة HyperFrames. يتم استخدامه بعد إنشاء مخرجات comfy-imagegen أو comfy-videogen أو comfy-musicgen، أو عندما يريد المستخدم تصفح الوسائط التي تم إنشاؤها أو مقارنتها أو تحديدها أو إنشائها.
