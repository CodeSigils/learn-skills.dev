Genera video MP4 con comoda diffusione utilizzando LTX 2.3 10Eros locale o nodi API ByteDance Seedance 2.0 remoti. Da utilizzare quando l'utente desidera che l'utente desideri la generazione di video da testo a video, da immagine a video, da immagine a video, da immagine+audio a video, primo/ultimo fotogramma, il controllo IC-LoRA con traccia di movimento LTX o il video testo/riferimento/primo-ultimo fotogramma API Seedance 2.0 salvato nell'area di lavoro. Non utilizzare per la generazione di sole immagini, la generazione di sola musica, la generazione di voce, download di modelli, flussi di lavoro del server ComfyUI, lavoro dell'interfaccia utente, installazione di nodi personalizzati o API video ospitate non da Seedance.
