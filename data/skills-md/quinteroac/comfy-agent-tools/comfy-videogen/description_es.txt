Genere videos MP4 con difusión cómoda utilizando nodos API LTX 2.3 10Eros locales o ByteDance Seedance 2.0 remotos. Úselo cuando el usuario desee generar texto a video, imagen a video, imagen+audio a video respaldado por GPU local, generación de video de primer/último fotograma, control IC-LoRA de seguimiento de movimiento LTX o video/referencia/primer-último fotograma de API Seedance 2.0 guardado en el espacio de trabajo. No lo utilice para generación de solo imágenes, generación de solo música, generación de voz, descargas de modelos, flujos de trabajo del servidor ComfyUI, trabajo de interfaz de usuario, instalación de nodos personalizados o API de video no alojadas en Seedance.
