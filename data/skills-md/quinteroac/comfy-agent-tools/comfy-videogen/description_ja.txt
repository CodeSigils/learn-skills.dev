ローカル LTX 2.3 10Eros またはリモート ByteDance Seedance 2.0 API ノードを使用して、快適な拡散を備えた MP4 ビデオを生成します。ユーザーがローカル GPU によるテキストからビデオへの変換、画像からビデオへの変換、画像 + 音声からビデオへの変換、最初/最後のフレームのビデオ生成、LTX モーション トラック IC-LoRA コントロール、または Seedance 2.0 API のテキスト/リファレンス/最初から最後のフレームのビデオをワークスペースに保存する場合に使用します。画像のみの生成、音楽のみの生成、音声生成、モデルのダウンロード、ComfyUI サーバー ワークフロー、UI 作業、カスタム ノードのインストール、または Seedance 以外でホストされるビデオ API には使用しないでください。
