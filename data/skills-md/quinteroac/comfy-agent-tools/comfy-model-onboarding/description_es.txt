Configure los perfiles y valores predeterminados del modelo de herramientas de agente cómodo locales. Úselo cuando el usuario no tiene una configuración .comfy-agent-tools.json, desea configurar models_dir, cambiar un perfil de capacidad predeterminado, agregar un nuevo punto de control o ajustar una arquitectura compatible, o diagnosticar errores de perfil/configuración como perfil_desconocido, capacidad_no compatible, falta de coincidencia de arquitectura, error de configuración, archivo_modelo_faltante o arquitectura_no compatible.
