Загрузите недостающие встроенные файлы моделей comfy-agent-tools по требованию в зависимости от возможностей. Используйте, когда для запроса генерации/редактирования/увеличения масштаба/музыки/видео требуются отсутствующие локальные модели, когда comfy-models сообщает о недостающем_файле_модели или когда пользователь просит загрузить поддерживаемые базовые модели. Не используйте для загрузки всех моделей, если это явно не требуется.
