Descargue los archivos de modelo de herramientas de agente cómodas integradas que faltan según demanda según la capacidad. Úselo cuando una solicitud de generación/edición/mejora/música/vídeo necesita modelos locales que faltan, cuando Comfort-models informa que falta_model_file o cuando el usuario solicita descargar modelos base compatibles. No lo utilice para descargar todos los modelos a menos que se solicite explícitamente.
