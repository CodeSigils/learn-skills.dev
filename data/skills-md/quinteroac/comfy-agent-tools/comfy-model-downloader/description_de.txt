Laden Sie fehlende integrierte Comfy-Agent-Tools-Modelldateien bei Bedarf nach Funktion herunter. Wird verwendet, wenn eine Generierungs-/Bearbeitungs-/Hochskalierungs-/Musik-/Videoanforderung lokale Modelle benötigt, die fehlen, wenn „comforty-models“ eine fehlende_Modelldatei meldet oder wenn der Benutzer darum bittet, unterstützte Basismodelle herunterzuladen. Verwenden Sie diese Option nicht zum Herunterladen aller Modelle, es sei denn, Sie werden ausdrücklich dazu aufgefordert.
