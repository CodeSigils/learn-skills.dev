Genere videos LTX 2.3 locales guiados por el HDR IC-LoRA configurado a través del flujo de trabajo de control de pista de movimiento. Úselo cuando el usuario desee una imagen animada a lo largo de trayectorias de movimiento dispersas dibujadas, superposiciones de splines, seguimientos de puntos o un video de referencia de control de movimiento preparado. No lo use para LoRA de solo estilo, video API de Seedance, generación de solo imágenes, generación de solo música, seguimiento automático de puntos a partir de video real o flujos de trabajo de solo servidor ComfyUI.
