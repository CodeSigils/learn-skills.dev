Genera video LTX 2.3 locali guidati dall'HDR IC-LoRA configurato attraverso il flusso di lavoro di controllo del movimento. Utilizzare quando l'utente desidera un'immagine animata lungo traiettorie di movimento sparse disegnate, sovrapposizioni di spline, tracce di punti o un video di riferimento per il controllo del movimento preparato. Non utilizzare per LoRA di solo stile, video API Seedance, generazione di sole immagini, generazione di sola musica, tracciamento automatico dei punti da video reale o flussi di lavoro solo server ComfyUI.
