Générez des vidéos LTX 2.3 locales guidées par le HDR IC-LoRA configuré via le flux de travail de contrôle de suivi de mouvement. À utiliser lorsque l'utilisateur souhaite une image animée le long de trajectoires de mouvement clairsemées, de superpositions de splines, de pistes de points ou d'une vidéo de référence de contrôle de mouvement préparée. Ne pas utiliser pour les LoRA de style uniquement, la vidéo de l'API Seedance, la génération d'images uniquement, la génération de musique uniquement, le suivi automatique des points à partir d'une vidéo réelle ou les flux de travail du serveur ComfyUI uniquement.
