Создавайте локальные видеоролики LTX 2.3, руководствуясь настроенным HDR IC-LoRA, посредством рабочего процесса управления отслеживанием движения. Используйте, когда пользователь хочет, чтобы изображение было анимировано по нарисованным редким траекториям движения, наложениям сплайнов, трекам точек или подготовленному эталонному видео с управлением движением. Не используйте только для стилей LoRA, видео Seedance API, создания только изображений, создания только музыки, автоматического отслеживания точек на основе реального видео или рабочих процессов ComfyUI только для сервера.
