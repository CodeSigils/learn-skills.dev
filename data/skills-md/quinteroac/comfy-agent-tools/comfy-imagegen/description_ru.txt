Создавайте, редактируйте или повышайте масштаб растровых изображений с помощью удобного распространения, включая локальную Anima Base v1.0 с турбо-LoRA, Qwen Image Edit 2511, FLUX.2 Klein 9B SNOFS, ClearReality и удаленные узлы API Grok Imagine. Используйте, когда пользователь хочет создать или отредактировать изображение на текущем компьютере с сохранением результатов в рабочей области. Не используйте для создания размещенных изображений OpenAI, работы с векторами/SVG, видео, музыки, голоса, загрузки моделей, установки пользовательских узлов или рабочих процессов сервера ComfyUI.
