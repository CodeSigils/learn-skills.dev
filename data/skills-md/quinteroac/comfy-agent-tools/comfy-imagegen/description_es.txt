Genere, edite o mejore imágenes rasterizadas con una cómoda difusión, incluida Anima Base v1.0 local con turbo LoRA, Qwen Image Edit 2511, FLUX.2 Klein 9B SNOFS, ClearReality y nodos remotos de Grok Imagine API. Úselo cuando el usuario desee generar o editar imágenes desde la máquina actual con resultados guardados en el espacio de trabajo. No lo utilice para generación de imágenes OpenAI alojadas, trabajos vectoriales/SVG, videos, música, voz, descargas de modelos, instalación de nodos personalizados o flujos de trabajo del servidor ComfyUI.
