Genera, modifica o esegui l'upscaling di immagini raster con comoda diffusione, incluso Anima Base v1.0 locale con turbo LoRA, Qwen Image Edit 2511, FLUX.2 Klein 9B SNOFS, ClearReality e nodi API Grok Imagine remoti. Da utilizzare quando l'utente desidera generare o modificare immagini dal computer corrente con gli output salvati nell'area di lavoro. Non utilizzare per la generazione di immagini OpenAI ospitate, lavori vettoriali/SVG, video, musica, voce, download di modelli, installazione di nodi personalizzati o flussi di lavoro del server ComfyUI.
