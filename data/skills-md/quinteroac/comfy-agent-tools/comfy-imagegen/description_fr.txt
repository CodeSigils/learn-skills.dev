Générez, modifiez ou mettez à niveau des images raster avec une diffusion confortable, y compris Anima Base v1.0 locale avec turbo LoRA, Qwen Image Edit 2511, FLUX.2 Klein 9B SNOFS, ClearReality et les nœuds API Grok Imagine distants. À utiliser lorsque l'utilisateur souhaite générer ou éditer des images à partir de la machine actuelle avec des sorties enregistrées dans l'espace de travail. Ne pas utiliser pour la génération d'images OpenAI hébergées, le travail vectoriel/SVG, la vidéo, la musique, la voix, les téléchargements de modèles, l'installation de nœuds personnalisés ou les flux de travail du serveur ComfyUI.
