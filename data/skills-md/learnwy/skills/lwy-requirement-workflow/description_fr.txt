À utiliser lorsque l'utilisateur souhaite créer, implémenter ou développer une fonctionnalité. Orchestre le développement axé sur les spécifications et fondé sur des preuves. Le cycle de vie par défaut est « lite » (INIT → IMPLEMENTING → TESTING → DONE) ; promotion automatique vers « standard » ou « complet » lorsque la portée, le risque ou la traçabilité AC l'exigent. Déclencheurs : « développer une fonctionnalité », « implémenter ceci », « créer une fonctionnalité », « ajouter un module », « corriger un bug », « 开发功能 », « 实现这个 ».
