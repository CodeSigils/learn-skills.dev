Installez et configurez la configuration copilot-devcontainer dans un projet cible. À utiliser lorsqu'on vous le demande : configurer un devcontainer, configurer GitHub Copilot CLI, démarrer un environnement de développement assisté par l'IA, installer des plugins Copilot CLI ou ajouter des fichiers devcontainer à un dépôt existant. Mots-clés : configuration de devcontainer, installation CLI copilot, configuration de GitHub Copilot, environnement de développement AI, serveurs MCP.
