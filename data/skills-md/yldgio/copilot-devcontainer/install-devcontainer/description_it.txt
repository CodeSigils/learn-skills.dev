Installa e configura la configurazione del copilot-devcontainer in un progetto di destinazione. Utilizzare quando richiesto per: impostare un devcontainer, configurare GitHub Copilot CLI, avviare un ambiente di sviluppo assistito dall'intelligenza artificiale, installare plug-in Copilot CLI o aggiungere file devcontainer a un repository esistente. Parole chiave: configurazione devcontainer, installazione CLI di copilot, configurazione di GitHub Copilot, ambiente di sviluppo AI, server MCP.
