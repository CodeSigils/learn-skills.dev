Testgetriebene Entwicklung mit Rot-Grün-Refaktor-Schleife. Wird verwendet, wenn der Benutzer mithilfe von TDD Funktionen erstellen oder Fehler beheben, Tests für vorhandenen Code schreiben, Tests zu einem Modul hinzufügen, Code testbarer machen möchte, sagt: „Tests dafür schreiben“, „Hilf mir, dies zu testen“, „Wie teste ich das“, „Meine Tests brechen immer wieder ab, wenn ich umgestalte“, „Ich weiß nicht, was ich testen soll“, „Soll ich zuerst den Test schreiben“, „Machen Sie dies testbar“, „Wie schreibe ich gute Tests“, erwähnt „Rot-Grün-Refaktor“, möchte Integrationstests oder fragt danach Test-First-Entwicklung.
