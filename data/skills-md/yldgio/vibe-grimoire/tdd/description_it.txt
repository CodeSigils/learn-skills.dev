Da utilizzare quando l'utente desidera creare funzionalità o correggere bug utilizzando TDD, scrivere test per codice esistente, aggiungere test a un modulo, rendere il codice più testabile, dice "scrivi test per questo", "aiutami a testarlo", "come posso testarlo", "i miei test continuano a interrompersi quando eseguo il refactoring", "Non so cosa testare", "devo scrivere prima il test", "rendilo testabile", "come faccio a scrivere buoni test", menziona "red-green-refactor", vuole test di integrazione o chiede sviluppo di prova.
