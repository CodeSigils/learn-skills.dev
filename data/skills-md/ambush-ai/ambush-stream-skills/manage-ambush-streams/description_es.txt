Administre las transmisiones de noticias de Ambush de un usuario a través del servidor MCP de Ambush Streams. Úselo cuando el usuario desee crear, enumerar, inspeccionar, cambiar el nombre, cambiar, pausar, reanudar o eliminar una transmisión de Ambush, o revisar las noticias emitidas y la configuración de entrega de una transmisión.
