Verwandeln Sie jeden Markdown über md.page in eine gemeinsam nutzbare Webseite. Verwenden Sie diese Option, wenn der Benutzer „dieses teilen“, „diesen Markdown veröffentlichen“, „einen gemeinsam nutzbaren Link erstellen“, „dieses zu einer Webseite machen“, „dieses als Link senden“, „dieses hosten“ möchte oder Markdown-Inhalte in eine URL umwandeln möchte. Wird auch bei „Bericht veröffentlichen“, „Meine Notizen teilen“, „Seite erstellen“ oder jeder Anfrage, Inhalte über einen Link zugänglich zu machen, ausgelöst.
