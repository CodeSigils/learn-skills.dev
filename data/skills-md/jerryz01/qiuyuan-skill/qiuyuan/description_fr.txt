qiuyuan-skill : entrez le nom du joueur, recherche approfondie automatique → extraction du cadre tactique → générer une compétence de joueur exécutable.
Deux points d'entrée : (1) Nom spécifique du joueur → distillation directe (2) Exigence vague → recommandation diagnostique → puis distillation.
Phrases de déclenchement : "Analyser le joueur XX", "Distiller XX", "Comment XX jouerait", "Du point de vue de XX", "Créer une perspective tactique de XX", "Créer une perspective de joueur de XX".
Des exigences vagues déclenchent : « Comment ce poste doit-il être joué », « Comment évaluer ce joueur », « De quel type d'attaquant ai-je besoin ».
