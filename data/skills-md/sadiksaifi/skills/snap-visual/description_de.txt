Erstellen Sie ein einseitiges visuelles HTML-Briefing, um ein Konzept, einen Plan, eine Architektur, einen Vergleich oder einen Vorschlag zu erläutern – und öffnen Sie es dann im Browser. Verwenden Sie es immer dann, wenn der Benutzer „dies visuell erklären“, „mir eine HTML-Seite zeigen“, „visuell erstellen“, „dies grafisch darstellen“ oder „X visualisieren“ möchte oder möchte, dass etwas als Seite statt als Prosa gerendert wird. Versuchen Sie dies auch proaktiv, wenn eine ausführliche Erklärung (eine Architektur, ein Migrationsplan, eine Reihe von Kompromissen, ein Designvorschlag) als visuelles Dokument eindeutig besser ankommen würde als eine Textwand.
