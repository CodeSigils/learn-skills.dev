Cree un resumen visual HTML de una sola página para explicar un concepto, plan, arquitectura, comparación o propuesta y luego ábralo en el navegador. Úselo siempre que el usuario solicite "explicar esto visualmente", "muéstrame una página HTML", "hacer un visual", "diagramar esto", "visualizar X" o quiere que algo se represente como una página en lugar de prosa. También busque esto de manera proactiva cuando una explicación densa (una arquitectura, un plan de migración, un conjunto de compensaciones, una propuesta de diseño) sería claramente mejor como un documento visual que un muro de texto.
