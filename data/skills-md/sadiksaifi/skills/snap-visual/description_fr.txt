Créez un brief visuel HTML d'une seule page pour expliquer un concept, un plan, une architecture, une comparaison ou une proposition, puis ouvrez-le dans le navigateur. À utiliser chaque fois que l'utilisateur demande « d'expliquer cela visuellement », « me montrer une page HTML », « créer un visuel », « schématiser ceci », « visualiser X » ou souhaite que quelque chose soit rendu sous forme de page au lieu de prose. Essayez-le également de manière proactive lorsqu'une explication dense (une architecture, un plan de migration, un ensemble de compromis, une proposition de conception) conviendrait clairement mieux à un document visuel qu'à un mur de texte.
