Connectez-vous à votre Oura Ring et consultez les données de santé. À utiliser lorsque l'utilisateur mentionne Oura, le score de sommeil, le score de préparation, le score d'activité, le nombre de pas, les pas, la fréquence cardiaque, le VRC, la SpO2, l'oxygène dans le sang, les données de stress, le suivi de l'entraînement, le coût de récupération, la récupération de l'entraînement ou pose des questions sur ses mesures de santé, la qualité du sommeil, la récupération ou les données de sonnerie. Déclenchez également des expressions telles que « comment ai-je dormi », « afficher mes données de santé », « vérifier ma bague », « quel est mon état de préparation », « combien de pas », « comment le pickleball affecte-t-il ma récupération », « dois-je m'entraîner aujourd'hui », « si je joue demain », « temps de récupération » ou toute question sur les données biométriques, de bien-être ou de bague portable.
