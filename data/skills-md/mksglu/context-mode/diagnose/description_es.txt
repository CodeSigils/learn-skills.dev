Bucle de diagnóstico disciplinado para errores difíciles y regresiones de rendimiento. Reproducir → minimizar → formular hipótesis → instrumento → corregir → prueba de regresión. Úselo cuando el usuario diga "diagnosticar esto"/"depurar esto", informe un error, diga que algo está roto/arrojando/fallando o describe una regresión de rendimiento.
