Genere imágenes infográficas a partir de descripciones de usuarios utilizando Gemini API (Nano Banana Pro). Convierte descripciones en lenguaje natural en indicaciones infográficas estructuradas y luego llama a la generación de imágenes Gemini para producir imágenes PNG. Admite 11 estilos visuales (sketchnote, kawaii, profesional, científico, anime, plastilina, editorial, guión gráfico, cuadrícula bento, ladrillos), 3 orientaciones (paisaje/retrato/cuadrado), 3 niveles de detalle (breve/estándar/detallado) y múltiples idiomas. Úselo cuando el usuario solicite crear infografías, generar resúmenes visuales, realizar visualizaciones de datos o producir explicaciones ilustradas. Las palabras desencadenantes incluyen 信息图, infografía, 生成图, 可视化, resumen visual y visualización de datos.
