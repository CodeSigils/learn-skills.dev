قم بإنشاء صور رسومية من أوصاف المستخدم باستخدام Gemini API (Nano Banana Pro). يحول أوصاف اللغة الطبيعية إلى مطالبات رسومية منظمة، ثم يستدعي إنشاء صور Gemini لإنتاج صور PNG. يدعم 11 نمطًا مرئيًا (رسم تخطيطي، كاواي، احترافي، علمي، أنمي، طين، تحريري، لوحة القصة، شبكة بينتو، طوب)، 3 اتجاهات (أفقي/صورةي/مربع)، 3 مستويات تفصيلية (موجز/قياسي/مفصل)، ولغات متعددة. يُستخدم عندما يطلب المستخدم إنشاء رسوم بيانية، أو إنشاء ملخصات مرئية، أو إنشاء تصورات للبيانات، أو تقديم تفسيرات موضحة. تتضمن الكلمات المحفزة: 信息图، مخطط معلوماتي، 生成图، 可视化، ملخص مرئي، تصور البيانات.
