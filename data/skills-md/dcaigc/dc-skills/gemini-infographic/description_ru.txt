Создавайте инфографические изображения на основе описаний пользователей с помощью Gemini API (Nano Banana Pro). Преобразует описания на естественном языке в структурированные инфографические подсказки, а затем вызывает генерацию изображений Gemini для создания изображений PNG. Поддерживает 11 визуальных стилей (эскиз, каваи, профессиональный, научный, аниме, пластилин, редакционная работа, раскадровка, сетка бенто, кубики), 3 ориентации (пейзаж/портрет/квадрат), 3 уровня детализации (краткий/стандартный/подробный) и несколько языков. Используйте, когда пользователь просит создать инфографику, создать визуальные сводки, визуализировать данные или предоставить иллюстрированные пояснения. Триггерные слова включают 信息图, инфографику, 生成图, 可视化, визуальное резюме, визуализацию данных.
