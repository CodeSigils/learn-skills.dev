Leitplanken für das Core-Vite-2-Frontend-Repository. Verwenden Sie diese Option, wenn Sie eine atomare Benutzeroberfläche erstellen, neue Komponenten erstellen, Headless-Komponenten erstellen, die Synchronisierung von Komponentenkommentaren erzwingen, lange Tailwind-Klassennamenszeichenfolgen organisieren, JSX-Strukturkommentare erzwingen, BoxLayout-Wrapper erzwingen, Inhaltssichtbarkeit für lange Listen mit beliebigen Tailwind-Eigenschaften anwenden, die Benutzeroberfläche anhand von Webinterface-Richtlinien überprüfen oder die erforderliche Linting-Schleife vor der Freigabe von Updates anwenden.
