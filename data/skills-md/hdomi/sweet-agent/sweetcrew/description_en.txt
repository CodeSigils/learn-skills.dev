Guide for deciding whether to delegate to a Sweet‑style sub‑agent. It tells you when the main thread should launch `sweetcrew‑investigator` (finding code locations), `sweetcrew‑builder` (modifying 1–2 files), and `sweetcrew‑reviewer` (diff review). It compares doing it yourself or using the default `Explore`. Because the sub‑agent output is compressed, the tool‑result that returns to the main context is small — the context lasts longer in long sessions. Triggers: “hand over to sub‑agent,” “use sweetcrew,” “launch investigator/builder/reviewer,” “save context,” “compressed agent output.”
