Commentaires sur la révision du code coréen. Supprimez tout excès et ne conservez que les signaux exploitables. Chaque commentaire est une seule ligne : emplacement, problème, correctif. Il s'active lorsque l'utilisateur dit « 리뷰해줘 », « 코드 리뷰 », « PR 리뷰 », « diff 봐줘 », « /review » ou appelle /sweet-review. Il s'allume également automatiquement lors de l'examen d'un PR.
