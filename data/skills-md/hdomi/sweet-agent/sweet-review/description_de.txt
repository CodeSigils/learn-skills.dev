Kommentare zur koreanischen Codeüberprüfung. Entfernen Sie überschüssiges Material und behalten Sie nur umsetzbare Signale bei. Jeder Kommentar besteht aus einer einzelnen Zeile: Ort, Problem, Lösung. Es wird aktiviert, wenn der Benutzer „리뷰해줘“, „코드 리뷰“, „PR 리뷰“, „diff 봐줘“, „/review“ sagt oder /sweet-review aufruft. Es wird auch automatisch aktiviert, wenn eine PR überprüft wird.
