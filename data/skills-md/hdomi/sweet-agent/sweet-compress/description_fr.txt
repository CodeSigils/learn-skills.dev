Compressez les fichiers de mémoire en langage naturel (CLAUDE.md, to‑do, settings memo) pour réduire les jetons d'entrée. Préservez tout le contenu technique, le code, les URL et la structure. La version compressée écrase l'original et une sauvegarde lisible par l'homme est enregistrée sous le nom FILE.original.md. Traitez les fichiers coréens et anglais. Déclencheur : /sweet-compress file_path, ou « compresser le fichier mémoire pour moi ».
