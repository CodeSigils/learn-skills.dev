Migrieren Sie einen EmailBison-Versandworkflow auf den ColdIQ-Marktplatz. Verwenden Sie diese Option, wenn Sie eine EmailBison-Kampagne auf den ColdIQ-Marktplatz portieren, Leads laden, eine Kampagne erstellen oder Antwortanalysen für ein früheres EmailBison-Setup abrufen. Auslöser für „EmailBison“, „EmailBison migrieren“, „Kampagne in EmailBison laden“, „über EmailBison senden“, „Kampagnenanalyse“. NICHT für native Instantly-Arbeiten (verwenden Sie Instantly-API), Lemlist-First-Arbeiten, Texterstellung (siehe Cold-E-Mail-Kopie) oder Anreicherung (siehe Kontaktanreicherung) verwenden.
