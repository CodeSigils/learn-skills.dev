أنشئ حسابات مستهدفة وقوائم جهات اتصال باستخدام قاعدة بيانات Apollo من خلال سوق ColdIQ. يُستخدم عند البحث عن الشركات أو الأشخاص باستخدام دلالات مرشح Apollo (العناوين، والأقدمية، ونطاقات الموظفين، والصناعات، والتقنيات، والنوايا)، أو إثراء الأشخاص أو المؤسسات، أو إنشاء TAM من Apollo. مشغلات في "بحث Apollo"، و"مرشحات Apollo"، و"إنشاء TAM"، و"البحث عن الشركات"، و"البحث عن الأشخاص"، و"إثراء المؤسسة"، و"إثراء الأشخاص"، و"العثور على الشركات حسب التكنولوجيا"، و"نطاق عدد الموظفين"، و"الموضوعات المقصودة". لا تستخدمه مع Lima Data أو بحث AI-ark واسع النطاق (انظر إثراء البحث Coldiq)، أو شلالات البحث عن البريد الإلكتروني (انظر إثراء جهات الاتصال)، أو إرسال الحملات (راجع API الفورية).
