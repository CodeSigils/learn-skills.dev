Создавайте подходящие рекламные аудитории (LinkedIn/Meta/Google) и целевые списки ABM на основе данных о ваших потенциальных клиентах и ​​используйте взаимодействие с рекламой в качестве исходящих триггеров — через торговую площадку ColdIQ. Используйте при преобразовании целевого списка в аудиторию, соответствующую хешированной электронной почте, для рекламы, создании списков компаний/контактов ABM, настройке исключений, координации рекламы с исходящей рекламой (вовлечение рекламы → триггер продаж) или определении личности для таргетинга рекламы. Триггеры по «рекламной аудитории», «соответствующей аудитории», «хешированной электронной почте», «аудитории LinkedIn», «списку ABM», «ретаргетингу», «списку исключений», «рекламе + исходящей», «триггеру взаимодействия с рекламой», «многоканальному ABM», «списку компаний для рекламы». НЕ используйте для создания рекламных объявлений, назначения ставок или настройки менеджера кампаний (зависит от платформы, без конечной точки ColdIQ) или для кампаний по рассылке электронной почты (см. Instant-API).
