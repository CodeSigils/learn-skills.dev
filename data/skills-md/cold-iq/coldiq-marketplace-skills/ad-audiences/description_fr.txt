Créez des audiences publicitaires correspondantes (LinkedIn/Meta/Google) et des listes de cibles ABM à partir de vos données de prospects, et utilisez l'engagement publicitaire comme déclencheurs sortants – via le marché ColdIQ. À utiliser pour transformer une liste cible en une audience correspondant à des e-mails hachés pour les publicités, créer des listes d'entreprises/de contacts ABM, configurer des exclusions, coordonner les publicités avec les publicités sortantes (engagement publicitaire → déclencheur de ventes) ou résoudre les identités pour le ciblage publicitaire. Déclencheurs sur « audience publicitaire », « audience correspondante », « e-mail haché », « audience LinkedIn », « liste ABM », « reciblage », « liste d'exclusion », « annonces + sortantes », « déclencheur d'engagement publicitaire », « ABM multicanal », « liste d'entreprises pour les annonces ». Ne PAS utiliser pour la configuration de la création publicitaire, des enchères ou du gestionnaire de campagne (spécifique à la plate-forme, sans point de terminaison ColdIQ), ni pour les campagnes d'envoi d'e-mails (voir API instantanée).
