قم ببناء وتشغيل نماذج التسجيل التي تصنف قوائم الشركات الأولية إلى شرائح جاهزة للحملة، وقم بتوجيه كل نقطة بيانات مسجلة إلى نقطة نهاية ColdIQ التي مصدرها. يُستخدم عند إنشاء نموذج تسجيل النقاط، أو تصنيف TAM، أو تحديد مجموعات الإشارة وتخصيصات النقاط، أو تعيين حدود الطبقة، أو تنظيف القائمة قبل التسجيل، أو تشغيل مسجل Python عند التصدير. المشغلات على "شركات النتائج"، "تصنيف القائمة"، "نموذج التسجيل"، "تسجيل TAM"، "درجة ملاءمة برنامج المقارنات الدولية"، "عتبات المستوى"، "نموذج 100 نقطة"، "الحسابات المؤهلة". لا تستخدم للإثراء/البحث لبناء القائمة (انظر بحث apollo / إثراء البحث Coldiq)، أو تحديد مصادر الإشارة (انظر اكتشاف الإشارة)، أو حذف القائمة (انظر حذف القائمة).
