匿名化を解除された Web サイト訪問者を、充実したアウトリーチの準備ができた潜在顧客に変えます。訪問者の識別自体は、外部ピクセル/IP ツール (RB2B、Warmly、Koala、Leadfeeder) で実行されます。このスキルは、ColdIQ マーケットプレイス テールをカバーし、特定された訪問者を強化して解決し、アウトリーチのタイミングを計ります。 Web サイト訪問者の追跡を設定する場合、識別された訪問者の情報を充実させる場合、価格設定/デモページの訪問をスコアリングする場合、または訪問者シグナルをシーケンスにルーティングする場合に使用します。 「Web サイト訪問者」、「訪問者追跡」、「RB2B」、「匿名化解除」、「ピクセル識別」、「会社への IP」、「Warmly」、「Leadfeeder」、「Koala」、「訪問者アラート」、「私のサイトを訪問した人」をトリガーします。ソーシャル投稿エンゲージメント (シグナル検出を参照) またはサードパーティのインテント データ (シグナル検出を参照) には使用しないでください。
