Превратите деанонимных посетителей веб-сайта в потенциальных клиентов, готовых к общению. Сама идентификация посетителей выполняется во внешнем инструменте пикселей/IP (RB2B, Warmly, Koala, Leadfeeder); этот навык охватывает хвостовую часть рынка ColdIQ — обогащение и определение идентифицированных посетителей и определение времени охвата. Используйте при настройке отслеживания посетителей веб-сайта, расширении идентифицированных посетителей, оценке цен/посещений демонстрационных страниц или маршрутизации сигналов посетителей по последовательностям. Триггеры по «посетители сайта», «отслеживание посетителей», «RB2B», «деанонимизация», «идентификация пикселей», «IP для компании», «Тепло», «Leadfeeder», «Коала», «оповещения посетителей», «посетившие мой сайт». НЕ используйте для взаимодействия с публикациями в социальных сетях (см. «Обнаружение сигналов») или сторонние данные о намерениях (см. «Обнаружение сигналов»).
