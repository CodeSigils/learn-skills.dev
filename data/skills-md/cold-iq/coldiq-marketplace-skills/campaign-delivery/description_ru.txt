Создайте комплексную исходящую кампанию с помощью проверенной 9-этапной системы, координируя другие навыки и их конечные точки ColdIQ на каждом этапе. Используйте при запуске полной кампании с нуля, планировании порядка сборки, зная, что предшествует чему (копировать перед списком), или координируя TAM → подсчет → обогащение → копирование → загрузка. Триггеры «создать кампанию», «кампания с нуля», «полный исходящий конвейер», «9 этапов», «контрольный список кампании», «какой порядок», «начать кампанию». НЕ используйте для одного подэтапа изолированно (используйте конкретные навыки: поиск по Аполлону, оценка там, обогащение контактов, холодное копирование по электронной почте, мгновенное API) или структуры чистого копирования (см. метод Кроуфорда/холодное копирование по электронной почте).
