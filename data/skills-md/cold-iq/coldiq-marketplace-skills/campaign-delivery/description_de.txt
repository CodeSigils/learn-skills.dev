Erstellen Sie eine End-to-End-Outbound-Kampagne mit einem bewährten 9-Phasen-System und orchestrieren Sie die anderen Fähigkeiten und ihre ColdIQ-Endpunkte in jeder Phase. Verwenden Sie diese Option, wenn Sie eine vollständige Kampagne von Grund auf durchführen, die Erstellungsreihenfolge planen, wissen, was vor was kommt (Kopieren vor was) oder TAM → Bewertung → Anreicherung → Kopieren → Laden koordinieren. Auslöser für „Kampagne erstellen“, „Kampagne von Grund auf“, „vollständige Outbound-Pipeline“, „9-Phasen“, „Kampagnen-Checkliste“, „Welche Reihenfolge“, „Kampagne starten“. NICHT für einen einzelnen Unterschritt isoliert (verwenden Sie die spezifische Fähigkeit: Apollo-Suche, Tam-Scoring, Kontaktanreicherung, Kalt-E-Mail-Kopie, Sofort-API) oder reine Kopier-Frameworks (siehe Crawford-Methode / Kalt-E-Mail-Kopie) verwenden.
