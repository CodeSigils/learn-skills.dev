Обнаруживайте и расставляйте приоритеты сигналов о покупательских намерениях (финансирование, найм, технические изменения, изменения в работе, новости) и сопоставляйте каждый из них с конкретной конечной точкой рынка ColdIQ. Используйте при принятии решения о том, какие сигналы о намерениях отслеживать для клиента, поиске сигналов финансирования/найма/привлечения/смены работы, оценке счетов по силе сигнала, определении времени охвата на основе свежести сигнала или суммировании сигналов. Срабатывает по «сигналам намерения», «сигналам покупки», «триггерным событиям», «сигналу финансирования», «сигналу найма», «смене работы», «изменению стека технологий», «обнаружению сигналов», «когда обращаться», «наложению сигналов». НЕ используйте для написания копии, которая ссылается на сигнал (см. метод Crawford/cold-email-copy), математические вычисления по списку (см. tam-scoring) или общий поиск (см. coldiq-search-enrich).
