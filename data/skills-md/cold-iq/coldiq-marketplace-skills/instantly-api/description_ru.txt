Создавайте и запускайте кампании по холодной электронной почте в Instantly через торговую площадку ColdIQ — кампании, лиды, последовательности, аналитику и учетные записи. Используйте при создании кампании, загрузке/добавлении потенциальных клиентов, установке настроек кампании ColdIQ по умолчанию, получении аналитики ответов/открытий/отказов, активации или приостановке кампании или форматировании HTML-кода электронной почты для Instantly. Триггеры: «Мгновенная кампания», «Загрузка потенциальных клиентов», «Создать кампанию», «Аналитика кампании», «Активировать кампанию», «Добавить потенциальных клиентов в Мгновенно», «Частота ответов», «Настройки кампании». НЕ используйте для написания самой копии (см. метод холодного копирования по электронной почте / метод Кроуфорда), поиска/обогащения электронной почты (см. обогащение контактов), отправки Lemlist или EmailBison (см. эти навыки).
