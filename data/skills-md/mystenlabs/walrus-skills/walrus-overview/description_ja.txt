Walrus の概要: Walrus とは何か、どのように機能するか、どのツールを使用するか。ユーザーが Walrus を初めて使用する場合、「Walrus とは何ですか」、「Walrus はどのように機能するか」、「BLOB とは何ですか」を尋ねる場合、または CLI、HTTP API、TypeScript SDK、および Move 統合のいずれかを選択する必要がある場合に使用します。 Walrus アーキテクチャを説明する場合、Walrus と AWS S3 または IPFS を比較する場合、パブリッシャー/アグリゲーター/アップロード リレーの区別を説明する場合、または BLOB ID と Suui オブジェクト ID を明確にする場合にも使用します。これは、セイウチの初心者にとってのエントリーポイントのスキルです。
