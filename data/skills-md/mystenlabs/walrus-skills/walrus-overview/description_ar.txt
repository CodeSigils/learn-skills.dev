نظرة عامة رفيعة المستوى على Walrus: ما هو وكيف يعمل والأداة التي يجب استخدامها. يُستخدم عندما يكون المستخدم جديدًا على Walrus، أو يسأل "ما هو Walrus"، أو "كيف يعمل Walrus"، أو "ما هو blob"، أو يحتاج إلى الاختيار بين CLI وHTTP API وTypeScript SDK وتكامل النقل. استخدمه أيضًا عند شرح بنية Walrus، أو مقارنة Walrus بـ AWS S3 أو IPFS، أو شرح التمييز بين الناشر/المجمع/ترحيل التحميل، أو توضيح معرف blob مقابل معرف كائن Sui. هذه هي مهارة نقطة الدخول للوافدين الجدد من حيوان الفظ.
