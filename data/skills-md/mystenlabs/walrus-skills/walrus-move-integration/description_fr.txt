Référencement et emballage des blobs Walrus dans les contrats intelligents Sui Move. À utiliser lorsque l'utilisateur doit envelopper un objet Walrus Blob dans une structure Move personnalisée, ajouter Walrus en tant que dépendance Move, créer un contrat qui dépend du package Walrus ou intégrer une logique en chaîne avec le stockage blob Walrus. À utiliser également lorsque l'utilisateur pose des questions sur enveloppé_blob.move, sur le package Walrus Move ou sur la façon de référencer des blobs à partir du code Move.
