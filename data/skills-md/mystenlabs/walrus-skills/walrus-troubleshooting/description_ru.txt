Распространенные сообщения об ошибках Walrus, их причины и исправления. Используйте, когда пользователь сталкивается с ошибкой при использовании Walrus CLI, TypeScript SDK, HTTP API или интеграции Move. Охватывает VMVerificationOrDeserializationError, ChainNotSupportedError, превышение чаевых, RetryableWalrusClientError, file.bytes не является функцией, 413 Payload Too Large, BlobNotCertifiedError, spawn walrus ENOENT, Cannot find gas coin, EWrongVersion и другие повторяющиеся ошибки из потоков поддержки.
