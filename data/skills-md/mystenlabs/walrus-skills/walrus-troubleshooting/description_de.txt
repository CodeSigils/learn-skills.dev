Häufige Walross-Fehlermeldungen, ihre Ursachen und Lösungen. Wird verwendet, wenn der Benutzer bei der Verwendung von Walrus CLI, TypeScript SDK, HTTP API oder Move-Integration auf einen Fehler stößt. Deckt VMVerificationOrDeserializationError, ChainNotSupportedError, Trinkgeld überschritten, RetryableWalrusClientError, file.bytes ist keine Funktion, 413 Payload Too Large, BlobNotCertifiedError, spawn walrus ENOENT, Gasmünze kann nicht gefunden werden, EWrongVersion und andere wiederkehrende Fehler aus Support-Threads ab.
