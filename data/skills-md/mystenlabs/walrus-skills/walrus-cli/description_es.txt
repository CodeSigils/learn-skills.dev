Cliente Walrus CLI para almacenar, leer y administrar blobs desde la línea de comandos. Úselo cuando el usuario necesite ejecutar walrus store, walrus read, walrus blob-status, walrus extend, walrus delete, walrus share o cualquier otro comando CLI de walrus. Úselo también para instalación CLI, configuración (client_config.yaml), modo JSON para secuencias de comandos, presupuestos de gas, configuración de billetera y registro. Para obtener detalles sobre la administración del ciclo de vida de los blobs, consulte "walrus-blob-lifecycle". Para edredones, consulte "edredones de morsa".
