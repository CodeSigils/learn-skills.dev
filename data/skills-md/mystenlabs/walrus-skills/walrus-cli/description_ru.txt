Клиент Walrus CLI для хранения, чтения и управления большими двоичными объектами из командной строки. Используйте, когда пользователю необходимо запустить walrus store, walrus read, walrus blob-status, walrus Extend, walrus delete, walrus Share или любую другую команду walrus CLI. Также используйте для установки CLI, настройки (client_config.yaml), режим JSON для сценариев, бюджетов газа, настройки кошелька и ведения журналов. Подробности управления жизненным циклом больших двоичных объектов см. в разделе «walrus-blob-lifecycle». Чтобы узнать о одеялах, см. «Одеяла из моржа».
