عميل Walrus CLI لتخزين وقراءة وإدارة النقط من سطر الأوامر. يُستخدم عندما يحتاج المستخدم إلى تشغيل Walrus Store أو قراءة Walrus أو حالة Walrus blob أو توسيع Walrus أو حذف Walrus أو مشاركة Walrus أو أي أمر Walrus CLI آخر. استخدمه أيضًا لتثبيت واجهة سطر الأوامر (CLI)، والتكوين (client_config.yaml)، ووضع JSON للبرمجة النصية، وميزانيات الغاز، وتكوين المحفظة، والتسجيل. للحصول على تفاصيل إدارة دورة حياة blob، راجع "دورة حياة walrus-blob". بالنسبة للألحف، راجع "لحاف الفظ".
