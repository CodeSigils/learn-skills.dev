Walrus CLI-Client zum Speichern, Lesen und Verwalten von Blobs über die Befehlszeile. Verwenden Sie diese Option, wenn der Benutzer „Walrus Store“, „Walrus Read“, „Walrus Blob-Status“, „Walrus Extend“, „Walrus Delete“, „Walrus Share“ oder einen anderen Walrus-CLI-Befehl ausführen muss. Auch für CLI-Installation, Konfiguration (client_config.yaml), JSON-Modus für Skripterstellung, Gasbudgets, Wallet-Konfiguration und Protokollierung verwenden. Einzelheiten zur Blob-Lebenszyklusverwaltung finden Sie unter „walrus-blob-lifecycle“. Quilts finden Sie unter „Walross-Quilts“.
