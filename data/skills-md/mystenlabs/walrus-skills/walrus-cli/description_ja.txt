コマンド ラインから BLOB を保存、読み取り、管理するための Walrus CLI クライアント。ユーザーが walrus Store、walrus read、walrus blob-status、walrus extend、walrus delete、walrus share、またはその他の walrus CLI コマンドを実行する必要がある場合に使用します。 CLI のインストール、構成 (client_config.yaml)、スクリプト作成用の JSON モード、ガス予算、ウォレット構成、ロギングにも使用します。 BLOB ライフサイクル管理の詳細については、「walrus-blob-lifecycle」を参照してください。キルトについては、「walrus-quilts」を参照してください。
