Client CLI Walrus pour stocker, lire et gérer les blobs à partir de la ligne de commande. À utiliser lorsque l'utilisateur doit exécuter walrus store, walrus read, walrus blob-status, walrus extend, walrus delete, walrus share ou toute autre commande CLI walrus. Utilisez également pour l'installation CLI, la configuration (client_config.yaml), le mode JSON pour les scripts, les budgets de gaz, la configuration du portefeuille et la journalisation. Pour plus de détails sur la gestion du cycle de vie des objets blob, consultez « walrus-blob-lifecycle ». Pour les courtepointes, voir `morse-quilts`.
