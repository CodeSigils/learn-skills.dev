نشر وتحديث وخدمة المواقع الثابتة اللامركزية على مواقع Walrus. يُستخدم عندما يحتاج المستخدم إلى نشر واجهة أمامية لمواقع Walrus، أو تشغيل بوابة محلية لشبكة الاختبار أو الشبكة الرئيسية، أو استخدام واجهة سطر الأوامر الخاصة بمنشئ الموقع، أو تكوين ws-resources.json (التوجيه، والرؤوس، وبيانات التعريف)، أو إعداد المجالات المخصصة (SuiNS، DNS)، أو أتمتة عمليات النشر باستخدام GitHub Actions CI/CD، أو تصحيح أخطاء منشئ الموقع، أو إدارة دورة حياة كائن الموقع (التحديث، أو التدمير، أو توسيع النقاط الكبيرة). يُستخدم أيضًا عندما يسأل المستخدم عن أداة إنشاء المواقع، أو مواقع الفظ، أو إعداد البوابة، أو استضافة dApp على Walrus. بالنسبة لتخزين الكائنات كبيرة الحجم بدون إطار عمل المواقع (تحميل/تنزيل أولي)، راجع `walrus-cli` أو `walrus-http-api`.
