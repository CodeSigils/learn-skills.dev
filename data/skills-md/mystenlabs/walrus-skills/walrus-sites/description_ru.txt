Развертывание, обновление и обслуживание децентрализованных статических веб-сайтов на сайтах Walrus. Используйте, когда пользователю необходимо развернуть внешний интерфейс на Walrus Sites, запустить локальный портал для тестовой или основной сети, использовать CLI конструктора сайтов, настроить ws-resources.json (маршрутизация, заголовки, метаданные), настроить пользовательские домены (SuiNS, DNS), автоматизировать развертывание с помощью GitHub Actions CI/CD, отладить ошибки конструктора сайтов или управлять жизненным циклом объектов сайта (обновление, уничтожение, расширение больших двоичных объектов). Также используйте, когда пользователь спрашивает о конструкторе сайтов, сайтах Walrus, настройке портала или размещении децентрализованного приложения на Walrus. Информацию о хранилище BLOB-объектов без платформы Sites (необработанная загрузка/скачивание) см. в разделе «walrus-cli» или «walrus-http-api».
