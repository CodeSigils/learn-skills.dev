Implementar, actualizar y ofrecer sitios web estáticos descentralizados en Walrus Sites. Úselo cuando el usuario necesite implementar una interfaz en Walrus Sites, ejecutar un portal local para testnet o mainnet, usar la CLI del creador de sitios, configurar ws-resources.json (enrutamiento, encabezados, metadatos), configurar dominios personalizados (SuiNS, DNS), automatizar implementaciones con GitHub Actions CI/CD, depurar errores del creador de sitios o administrar el ciclo de vida de los objetos del sitio (actualizar, destruir, extender blobs). Utilícelo también cuando el usuario pregunte sobre el creador de sitios, los sitios de morsa, la configuración del portal o el alojamiento de una dApp en Walrus. Para el almacenamiento de blobs sin el marco de Sites (carga/descarga sin formato), consulte `walrus-cli` o `walrus-http-api`.
