Bereitstellung, Aktualisierung und Bereitstellung dezentraler statischer Websites auf Walrus Sites. Verwenden Sie diese Option, wenn der Benutzer ein Frontend für Walrus Sites bereitstellen, ein lokales Portal für Testnet oder Mainnet ausführen, die Site-Builder-CLI verwenden, ws-resources.json (Routing, Header, Metadaten) konfigurieren, benutzerdefinierte Domänen (SuiNS, DNS) einrichten, Bereitstellungen mit GitHub Actions CI/CD automatisieren, Site-Builder-Fehler debuggen oder den Lebenszyklus von Site-Objekten verwalten muss (Aktualisieren, Zerstören, Erweitern von Blobs). Verwenden Sie es auch, wenn der Benutzer nach Site-Builder, Walrus-Sites, Portal-Einrichtung oder dem Hosten einer dApp auf Walrus fragt. Informationen zur Blob-Speicherung ohne das Sites-Framework (Roh-Upload/Download) finden Sie unter „walrus-cli“ oder „walrus-http-api“.
