Walrus는 많은 작은 덩어리를 단일 저장 장치로 일괄 처리하기 위해 퀼트합니다. 사용자가 여러 파일을 퀼트로 저장하거나, QuiltPatchId 또는 식별자로 개별 Blob을 검색하거나, 퀼트에 패치를 나열하거나, 퀼트 HTTP 엔드포인트를 사용해야 하는 경우에 사용합니다. 또한 많은 작은 Blob에 대한 스토리지 비용을 최적화할 때도 사용합니다. CLI(store-quilt, read-quilt, list-patches-in-quilt) 및 HTTP API 퀼트 작업을 모두 다룹니다. 일반 단일 Blob 스토리지의 경우 'walrus-cli' 또는 'walrus-http-api'를 참조하세요.
