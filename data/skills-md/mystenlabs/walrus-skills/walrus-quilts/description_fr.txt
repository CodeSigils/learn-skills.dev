Quilts de morse pour regrouper de nombreux petits blobs dans une seule unité de stockage. À utiliser lorsque l'utilisateur a besoin de stocker plusieurs fichiers sous forme de courtepointe, de récupérer des blobs individuels par QuiltPatchId ou un identifiant, de répertorier les correctifs dans une courtepointe ou d'utiliser des points de terminaison HTTP de courtepointe. À utiliser également pour optimiser les coûts de stockage de nombreux petits blobs. Couvre à la fois les opérations CLI (store-quilt, read-quilt, list-patches-in-quilt) et HTTP API quilt. Pour le stockage régulier d'un seul blob, voir `walrus-cli` ou `walrus-http-api`.
