多数の小さなブロブを 1 つのストレージ ユニットにまとめるためのセイウチ キルト。ユーザーが複数のファイルをキルトとして保存する必要がある場合、QuiltPatchId または識別子によって個々の BLOB を取得する必要がある場合、キルト内のパッチを一覧表示する場合、またはキルト HTTP エンドポイントを使用する必要がある場合に使用します。多数の小さな BLOB のストレージ コストを最適化する場合にも使用します。 CLI (store-quilt、read-quilt、list-patches-in-quilt) と HTTP API の Quilt 操作の両方をカバーします。通常の単一 BLOB ストレージについては、「walrus-cli」または「walrus-http-api」を参照してください。
