Trapunte Walrus per raggruppare molti piccoli blob in un'unica unità di stoccaggio. Da utilizzare quando l'utente deve archiviare più file come quilt, recuperare singoli BLOB in base a QuiltPatchId o identificatore, elencare le patch in un quilt o utilizzare endpoint HTTP quilt. Da utilizzare anche per ottimizzare i costi di archiviazione per molti BLOB di piccole dimensioni. Copre sia le operazioni CLI (store-quilt, read-quilt, list-patches-in-quilt) che le operazioni quilt dell'API HTTP. Per l'archiviazione regolare di un singolo BLOB, vedere `walrus-cli` o `walrus-http-api`.
