Edredones de morsa para agrupar muchas gotas pequeñas en una sola unidad de almacenamiento. Úselo cuando el usuario necesite almacenar varios archivos como una colcha, recuperar blobs individuales por QuiltPatchId o identificador, enumerar parches en una colcha o usar puntos finales HTTP de colcha. Úselo también para optimizar los costos de almacenamiento de muchos blobs pequeños. Cubre las operaciones CLI (store-quilt, read-quilt, list-patches-in-quilt) y HTTP API quilt. Para el almacenamiento normal de un solo blob, consulte `walrus-cli` o `walrus-http-api`.
