Одеяла «Морж» позволяют складывать множество маленьких кусочков в одну единицу хранения. Используйте, когда пользователю необходимо сохранить несколько файлов в виде составного листа, получить отдельные BLOB-объекты по QuiltPatchId или идентификатору, составить список исправлений в составном образе или использовать конечные точки HTTP составного листа. Также используйте при оптимизации затрат на хранение множества небольших больших двоичных объектов. Охватывает как CLI (store-quilt, read-quilt, list-patches-in-quilt), так и операции HTTP API quilt. Информацию о обычном хранилище с одним BLOB-объектом см. в разделе «walrus-cli» или «walrus-http-api».
