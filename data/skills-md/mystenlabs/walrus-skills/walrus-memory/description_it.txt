Walrus Memory (MemWal): memoria persistente, portatile e crittografata per agenti IA. Da utilizzare quando l'utente deve fornire a un agente AI memoria persistente tra sessioni e app, integrare @mysten-incubation/memwal TypeScript SDK o Python memwal SDK, configurare il server Walrus Memory MCP per Cursor/Claude/Codex, configurare operazioni di memorizzazione/richiamo/analisi/ripristino, gestire spazi di memoria e spazi dei nomi, impostare chiavi e account delegati, ospitare autonomamente il relè o utilizzare con il middleware MemWal AI (Vercel AI SDK, LangChain, OpenAI SDK). Da utilizzare anche quando l'utente chiede informazioni su MemWal, Walrus Memory, memoria dell'agente, spazi di memoria o il pacchetto memwal-mcp.
