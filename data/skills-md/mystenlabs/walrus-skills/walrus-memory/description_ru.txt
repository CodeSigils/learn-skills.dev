Walrus Memory (MemWal) — постоянная, портативная, зашифрованная память для агентов ИИ. Используйте, когда пользователю необходимо предоставить постоянную память агенту ИИ между сеансами и приложениями, интегрировать @mysten-incubation/memwal TypeScript SDK или Python memwal SDK, настроить сервер Walrus Memory MCP для Cursor/Claude/Codex, настроить операции запоминания/вызова/анализа/восстановления, управлять пространствами памяти и пространствами имен, настраивать делегированные ключи и учетные записи, самостоятельно размещать ретранслятор или использовать с промежуточным программным обеспечением MemWal AI (Vercel). AI SDK, LangChain, OpenAI SDK). Также используйте, когда пользователь спрашивает о MemWal, Walrus Memory, памяти агента, пространствах памяти или пакете memwal-mcp.
