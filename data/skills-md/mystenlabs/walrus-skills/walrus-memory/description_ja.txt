Walrus Memory (MemWal) — AI エージェント用の永続的でポータブルな暗号化されたメモリ。ユーザーがセッションやアプリ全体で AI エージェントに永続メモリを提供する必要がある場合、@mysten-incubation/memwal TypeScript SDK または Python memwal SDK を統合する、カーソル/クロード/コーデックス用の Walrus Memory MCP サーバーを設定する、記憶/呼び出し/分析/復元操作の構成、メモリ空間と名前空間の管理、デリゲート キーとアカウントの設定、リレーラーの自己ホスト、または MemWal AI ミドルウェアの使用が必要な場合に使用します。 (Vercel AI SDK、LangChain、OpenAI SDK)。ユーザーが MemWal、Walrus Memory、エージェント メモリ、メモリ スペース、または memwal-mcp パッケージについて質問する場合にも使用します。
