Walrus Memory(MemWal) — AI 에이전트를 위한 영구적이고 휴대 가능한 암호화된 메모리입니다. 사용자가 세션과 앱 전체에서 AI 에이전트에 영구 메모리를 제공해야 할 때 사용하고, @mysten-incubation/memwal TypeScript SDK 또는 Python memwal SDK를 통합하고, Cursor/Claude/Codex용 Walrus Memory MCP 서버를 설정하고, 기억/호출/분석/복원 작업을 구성하고, 메모리 공간 및 네임스페이스를 관리하고, 위임 키 및 계정을 설정하고, 중계기를 자체 호스팅하거나 MemWal AI 미들웨어(Vercel AI SDK, LangChain, OpenAI SDK). 또한 사용자가 MemWal, Walrus Memory, 에이전트 메모리, 메모리 공간 또는 memwal-mcp 패키지에 대해 문의할 때 사용합니다.
