Walrus Memory (MemWal) — 用于 AI 代理的持久、便携式、加密内存。当用户需要为 AI 代理提供跨会话和应用程序的持久内存、集成 @mysten-incubation/memwal TypeScript SDK 或 Python memwal SDK、为 Cursor/Claude/Codex 设置 Walrus Memory MCP 服务器、配置记住/调用/分析/恢复操作、管理内存空间和命名空间、设置委托密钥和帐户、自托管中继器或与 MemWal AI 中间件（Vercel AI SDK、LangChain、 OpenAI SDK）。当用户询问 MemWal、Walrus Memory、代理内存、内存空间或 memwal-mcp 包时也可使用。
