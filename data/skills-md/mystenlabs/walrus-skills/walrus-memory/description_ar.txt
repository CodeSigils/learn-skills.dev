ذاكرة Walrus (MemWal) - ذاكرة ثابتة ومحمولة ومشفرة لعملاء الذكاء الاصطناعي. يُستخدم عندما يحتاج المستخدم إلى منح وكيل الذكاء الاصطناعي ذاكرة ثابتة عبر الجلسات والتطبيقات، أو دمج @mysten-incubation/memwal TypeScript SDK أو Python memwal SDK، أو إعداد خادم Walrus Memory MCP لـ Cursor/Claude/Codex، أو تكوين عمليات التذكر/الاستدعاء/التحليل/الاستعادة، أو إدارة مساحات الذاكرة ومساحات الأسماء، أو إعداد مفاتيح وحسابات المفوض، أو الاستضافة الذاتية للمرحل، أو الاستخدام مع البرامج الوسيطة MemWal AI (Vercel AI SDK، LangChain، OpenAI SDK). استخدمه أيضًا عندما يسأل المستخدم عن MemWal، أو Walrus Memory، أو ذاكرة الوكيل، أو مساحات الذاكرة، أو حزمة memwal-mcp.
