Walrus Memory (MemWal) – mémoire persistante, portable et cryptée pour les agents IA. À utiliser lorsque l'utilisateur a besoin de donner à un agent IA une mémoire persistante entre les sessions et les applications, d'intégrer le SDK TypeScript @mysten-incubation/memwal ou le SDK Python memwal, de configurer le serveur Walrus Memory MCP pour Cursor/Claude/Codex, de configurer les opérations de mémorisation/rappel/analyse/restauration, de gérer les espaces mémoire et les espaces de noms, de configurer les clés et les comptes de délégué, d'auto-héberger le relais ou d'utiliser le middleware MemWal AI (Vercel AI SDK, LangChain, SDK OpenAI). À utiliser également lorsque l'utilisateur pose des questions sur MemWal, Walrus Memory, la mémoire de l'agent, les espaces mémoire ou le package memwal-mcp.
