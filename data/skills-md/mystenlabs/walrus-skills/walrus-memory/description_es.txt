Walrus Memory (MemWal): memoria cifrada, portátil y persistente para agentes de IA. Úselo cuando el usuario necesite brindarle a un agente de IA memoria persistente entre sesiones y aplicaciones, integrar el SDK de TypeScript @mysten-incubation/memwal o el SDK de memwal de Python, configurar el servidor MCP de memoria Walrus para Cursor/Claude/Codex, configurar operaciones de recordar/recordar/analizar/restaurar, administrar espacios de memoria y espacios de nombres, configurar cuentas y claves delegadas, autohospedar el repetidor o usar con middleware de IA de MemWal (Vercel AI SDK, LangChain, SDK de OpenAI). Úselo también cuando el usuario pregunte sobre MemWal, Walrus Memory, memoria del agente, espacios de memoria o el paquete memwal-mcp.
