Verschlüsseln von Daten vor dem Speichern auf Walrus mit Seal (Schwellenverschlüsselung mit On-Chain-Zugriffskontrolle). Verwenden Sie diese Option, wenn der Benutzer private oder vertrauliche Daten auf Walrus speichern, eine Zugriffskontrolle für Blob-Inhalte implementieren, Blobs vor dem Hochladen verschlüsseln, @mysten/seal für die Schwellenwertverschlüsselung verwenden oder die Datensicherheitsgarantien von Walrus (Verfügbarkeit, Integrität, Vertraulichkeit) verstehen muss. Wird auch verwendet, wenn der Benutzer im Zusammenhang mit Walrus-Daten nach Nautilus (TEE-basierte Off-Chain-Berechnung) fragt. Alle Blobs auf Walrus sind standardmäßig öffentlich.
