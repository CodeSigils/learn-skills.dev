Seal을 사용하여 Walrus에 저장하기 전에 데이터를 암호화합니다(온체인 액세스 제어를 통한 임계값 암호화). 사용자가 Walrus에 개인 데이터 또는 민감한 데이터를 저장해야 하거나, Blob 콘텐츠에 대한 액세스 제어를 구현하거나, 업로드하기 전에 Blob을 암호화하거나, 임계값 암호화를 위해 @mysten/seal을 사용하거나, Walrus 데이터 보안 보장(가용성, 무결성, 기밀성)을 이해해야 하는 경우에 사용합니다. 또한 사용자가 Walrus 데이터의 맥락에서 Nautilus(TEE 기반 오프체인 계산)에 대해 문의할 때 사용합니다. Walrus의 모든 Blob은 기본적으로 공개됩니다.
