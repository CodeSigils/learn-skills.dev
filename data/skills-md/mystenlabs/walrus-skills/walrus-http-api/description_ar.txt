ناشر ومجمع Walrus REST API لتخزين وقراءة النقط عبر HTTP. يُستخدم عندما يحتاج المستخدم إلى تخزين أو قراءة نقاط Walrus باستخدام طلبات HTTP PUT/GET، أو دمج Walrus من أي لغة برمجة، أو تكوين خيارات التخزين (العصور، أو الحذف، أو الدائم، أو send_object_to)، أو تحليل استجابات تخزين/قراءة واجهة برمجة التطبيقات. استخدمه أيضًا عند استكشاف أخطاء HTTP API وإصلاحها أو مشكلات التخزين المؤقت لـ CDN بعد التحميل. بالنسبة لنقاط نهاية HTTP الخاصة باللحاف، راجع مهارة "لحاف الفظ". لاستخدام CLI، راجع "walrus-cli".
