API REST editore e aggregatore Walrus per l'archiviazione e la lettura di BLOB su HTTP. Da utilizzare quando l'utente deve archiviare o leggere i BLOB Walrus utilizzando richieste HTTP PUT/GET, integrare Walrus da qualsiasi linguaggio di programmazione, configurare le opzioni di archiviazione (epoca, cancellabile, permanente, send_object_to) o analizzare le risposte API di archiviazione/lettura. Da utilizzare anche per la risoluzione degli errori dell'API HTTP o dei problemi di memorizzazione nella cache della CDN dopo il caricamento. Per gli endpoint HTTP quilt, consulta la competenza "walrus-quilts". Per l'utilizzo della CLI, vedere "walrus-cli".
