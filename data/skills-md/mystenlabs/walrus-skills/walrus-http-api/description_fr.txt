API REST de l'éditeur et agrégateur Walrus pour le stockage et la lecture des blobs via HTTP. À utiliser lorsque l'utilisateur a besoin de stocker ou de lire des blobs Walrus à l'aide de requêtes HTTP PUT/GET, d'intégrer Walrus à partir de n'importe quel langage de programmation, de configurer les options de stockage (époques, supprimables, permanents, send_object_to) ou d'analyser les réponses API de stockage/lecture. À utiliser également pour résoudre les erreurs de l'API HTTP ou les problèmes de mise en cache CDN après le téléchargement. Pour les points de terminaison HTTP quilt, consultez la compétence « walrus-quilts ». Pour l'utilisation de la CLI, voir `walrus-cli`.
