API REST del editor y agregador de Walrus para almacenar y leer blobs a través de HTTP. Úselo cuando el usuario necesite almacenar o leer blobs de Walrus mediante solicitudes HTTP PUT/GET, integrar Walrus desde cualquier lenguaje de programación, configurar opciones de almacenamiento (épocas, eliminables, permanentes, send_object_to) o analizar respuestas de API de almacenamiento/lectura. Úselo también para solucionar errores de API HTTP o problemas de almacenamiento en caché de CDN después de la carga. Para los puntos finales HTTP de quilt, consulte la habilidad `walrus-quilts`. Para el uso de CLI, consulte `walrus-cli`.
