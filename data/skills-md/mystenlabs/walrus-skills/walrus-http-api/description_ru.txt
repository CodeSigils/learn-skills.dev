Издатель и агрегатор Walrus REST API для хранения и чтения больших двоичных объектов через HTTP. Используйте, когда пользователю необходимо хранить или читать BLOB-объекты Walrus с помощью HTTP-запросов PUT/GET, интегрировать Walrus из любого языка программирования, настраивать параметры хранения (эпохи, удаляемые, постоянные, send_object_to) или анализировать ответы API на сохранение/чтение. Также используйте при устранении ошибок HTTP API или проблем с кэшированием CDN после загрузки. Конечные точки HTTP quilt см. в разделе «Walrus-quilts». Информацию об использовании CLI см. в разделе «walrus-cli».
