Walrus パブリッシャーおよびアグリゲーター REST API は、HTTP 経由で BLOB を保存および読み取ります。ユーザーが HTTP PUT/GET リクエストを使用して Walrus BLOB を保存または読み取る必要がある場合、任意のプログラミング言語から Walrus を統合する場合、ストレージ オプション (エポック、削除可能、永続、send_object_to) を構成する場合、またはストア/読み取り API 応答を解析する必要がある場合に使用します。アップロード後の HTTP API エラーや CDN キャッシュの問題のトラブルシューティングにも使用します。キルト HTTP エンドポイントについては、「walrus-quilts」スキルを参照してください。 CLI の使用法については、「walrus-cli」を参照してください。
