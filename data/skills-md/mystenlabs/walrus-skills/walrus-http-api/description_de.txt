Walrus-Publisher- und Aggregator-REST-API zum Speichern und Lesen von Blobs über HTTP. Verwenden Sie diese Option, wenn der Benutzer Walrus-Blobs mithilfe von HTTP-PUT/GET-Anforderungen speichern oder lesen, Walrus aus einer beliebigen Programmiersprache integrieren, Speicheroptionen (Epochen, löschbar, permanent, send_object_to) konfigurieren oder Speicher-/Lese-API-Antworten analysieren muss. Verwenden Sie es auch zur Fehlerbehebung bei HTTP-API-Fehlern oder CDN-Caching-Problemen nach dem Hochladen. Informationen zu Quilt-HTTP-Endpunkten finden Sie im Skill „walrus-quilts“. Informationen zur CLI-Nutzung finden Sie unter „walrus-cli“.
