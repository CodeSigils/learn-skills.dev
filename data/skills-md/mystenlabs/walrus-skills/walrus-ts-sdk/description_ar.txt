Walrus TypeScript SDK (@mysten/walrus) لتخزين البيانات النقطية وقراءتها برمجيًا. يُستخدم عند كتابة كود TypeScript/JavaScript الذي يتفاعل مع Walrus لتخزين البيانات الثنائية الكبيرة أو القراءة أو إدارة دورة الحياة. استخدمه أيضًا عند تكوين إعدادات الشبكة (حزمة Testnet/Mainnet ومعرفات الكائنات)، أو توصيل Walrus بمحفظة Sui، أو دمج Walrus في تطبيق ويب. لمعرفة استخدام واجهة سطر الأوامر (CLI)، راجع مهارة "الفظ-cli". بالنسبة لـ HTTP API، راجع مهارة `walrus-http-api`.
