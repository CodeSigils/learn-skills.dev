Walrus TypeScript SDK (@mysten/walrus) para almacenar y leer blobs mediante programación. Úselo al escribir código TypeScript/JavaScript que interactúe con Walrus para el almacenamiento, la lectura o la administración del ciclo de vida de blobs. Úselo también al configurar los ajustes de red (paquete Testnet/Mainnet e ID de objetos), conectar Walrus a una billetera Sui o integrar Walrus en una aplicación web. Para el uso de CLI, consulte la habilidad `walrus-cli`. Para la API HTTP, consulte la habilidad `walrus-http-api`.
