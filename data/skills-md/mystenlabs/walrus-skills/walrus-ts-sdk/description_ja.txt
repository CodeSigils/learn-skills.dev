プログラムで BLOB を保存および読み取りするための Walrus TypeScript SDK (@mysten/walrus)。 BLOB ストレージ、読み取り、ライフサイクル管理のために Walrus と対話する TypeScript/JavaScript コードを作成するときに使用します。ネットワーク設定 (テストネット/メインネット パッケージおよびオブジェクト ID) を構成する場合、Walrus を Sui ウォレットに接続する場合、または Walrus を Web アプリに統合する場合にも使用します。 CLI の使用法については、「walrus-cli」スキルを参照してください。 HTTP API については、「walrus-http-api」スキルを参照してください。
