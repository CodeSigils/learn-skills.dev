Walrus TypeScript SDK (@mysten/walrus) zum programmgesteuerten Speichern und Lesen von Blobs. Wird zum Schreiben von TypeScript-/JavaScript-Code verwendet, der mit Walrus für die Blob-Speicherung, das Lesen oder die Lebenszyklusverwaltung interagiert. Wird auch verwendet, wenn Sie Netzwerkeinstellungen (Testnet/Mainnet-Paket und Objekt-IDs) konfigurieren, Walrus mit einem Sui-Wallet verbinden oder Walrus in eine Web-App integrieren. Informationen zur CLI-Nutzung finden Sie im Skill „walrus-cli“. Informationen zur HTTP-API finden Sie im Skill „walrus-http-api“.
