Walrus TypeScript SDK (@mysten/walrus) для программного хранения и чтения больших двоичных объектов. Используйте при написании кода TypeScript/JavaScript, который взаимодействует с Walrus для хранения, чтения или управления жизненным циклом BLOB-объектов. Также используйте при настройке сетевых параметров (пакет Testnet/Mainnet и идентификаторы объектов), подключении Walrus к кошельку Sui или интеграции Walrus в веб-приложение. Подробнее об использовании CLI см. в описании навыка «walrus-cli». Для HTTP API см. навык «walrus-http-api».
