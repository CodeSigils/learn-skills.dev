suiup を使用した、Sui CLI バージョンのインストール、更新、管理。ユーザーが、Sui のインストール、新しいバージョンへの更新、ネットワーク固有のバージョン間の切り替え、「コマンドが見つかりません」またはバージョンの不一致エラーの解決、追加のツールチェーン コンポーネント (Walrus、MVR、Move Analyzer) のインストール、または suiup コマンドのトラブルシューティングを行う必要がある場合に、このスキルを使用します。また、ユーザーに「クライアント/サーバー API バージョンの不一致」警告が表示された場合、または suiup のインストール、更新、切り替え、または表示について質問された場合にも使用します。
