Installazione, aggiornamento e gestione delle versioni della CLI di Sui con suiup. Utilizza questa competenza quando l'utente deve installare Sui, aggiornare a una versione più recente, passare da una versione specifica della rete all'altra, risolvere errori di "comando non trovato" o mancata corrispondenza della versione, installare componenti aggiuntivi della toolchain (Walrus, MVR, Move Analyser) o risolvere i problemi relativi ai comandi suiup. Da utilizzare anche quando l'utente vede avvisi di "mancata corrispondenza della versione API client/server" o chiede informazioni sull'installazione, l'aggiornamento, il cambio o la visualizzazione di suiup.
