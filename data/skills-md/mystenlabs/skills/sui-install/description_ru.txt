Установка, обновление и управление версиями Sui CLI с помощью suiup. Используйте этот навык, когда пользователю необходимо установить Sui, обновиться до более новой версии, переключиться между версиями для конкретной сети, устранить ошибки «команда не найдена» или ошибки несоответствия версий, установить дополнительные компоненты набора инструментов (Walrus, MVR, Move Analyzer) или устранить неполадки команд suiup. Также используйте, когда пользователь видит предупреждения о несоответствии версий клиентского и серверного API или спрашивает об установке, обновлении, переключении или показе suiup.
