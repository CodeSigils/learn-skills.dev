Instalación, actualización y administración de versiones de Sui CLI con suiup. Utilice esta habilidad cuando el usuario necesite instalar Sui, actualizar a una versión más reciente, cambiar entre versiones específicas de la red, resolver errores de "comando no encontrado" o de discrepancia de versión, instalar componentes adicionales de la cadena de herramientas (Walrus, MVR, Move Analyzer) o solucionar problemas de comandos de suiup. Úselo también cuando el usuario vea advertencias de "la versión de la API del cliente/servidor no coincide" o pregunte sobre la instalación, actualización, cambio o presentación de Suiup.
