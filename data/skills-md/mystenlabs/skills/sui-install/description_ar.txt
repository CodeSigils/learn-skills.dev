تثبيت وتحديث وإدارة إصدارات Sui CLI باستخدام suiup. استخدم هذه المهارة عندما يحتاج المستخدم إلى تثبيت Sui، أو التحديث إلى إصدار أحدث، أو التبديل بين الإصدارات الخاصة بالشبكة، أو حل أخطاء "لم يتم العثور على الأمر" أو عدم تطابق الإصدار، أو تثبيت مكونات إضافية لسلسلة الأدوات (Walrus، أو MVR، أو Move Analyzer)، أو استكشاف أخطاء أوامر suiup وإصلاحها. يُستخدم أيضًا عندما يرى المستخدم تحذيرات "عدم تطابق إصدار واجهة برمجة تطبيقات العميل/الخادم" أو يسأل عن تثبيت suiup أو تحديثه أو تبديله أو عرضه.
