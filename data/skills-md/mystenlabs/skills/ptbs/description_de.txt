Sui Programmable Transaction Blocks (PTBs). Wird zum Schreiben, Überprüfen oder Debuggen von Code verwendet, der mehrere Sui-Transaktionsbefehle zu einer einzigen atomaren Transaktion zusammenfasst – einschließlich der Verwendung von „Transaktionen“ des TypeScript SDK, der CLI-PTB-Konstruktion, der Handhabung von Gasmünzen, gesponserten Transaktionen, Eingaben gemeinsam genutzter Objekte, der Verkettung von Befehlsergebnissen oder der Fehlerbehebung bei PTB-Ausführungsfehlern.
