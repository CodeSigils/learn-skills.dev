Desarrollo de contratos inteligentes Sui Move. Úselo al escribir, revisar o depurar código Move en Sui. Cubre capacidades de movimiento (clave, almacenamiento, copia, colocación), TxContext, funciones de inicio, testigo único, publicación y actualizaciones de paquetes, seguridad de recursos, eventos y monedas. Úselo también cuando el usuario pregunte sobre habilidades de estructura, UID, cómo destruir objetos o cómo crear un token fungible.
Para conocer el modelo de objeto y la propiedad, consulte la habilidad "modelo de objeto". Para bloques de transacciones programables, consulte la habilidad "ptbs". Para el desarrollo de dApps frontend, consulte la habilidad "aplicaciones frontend". Para la configuración del proyecto y Move.toml, consulte la habilidad `sui-move-project`.
