Intelligente Vertragsentwicklung von Sui Move. Wird zum Schreiben, Überprüfen oder Debuggen von Move-Code auf Sui verwendet. Deckt Move-Fähigkeiten (Schlüssel, Speichern, Kopieren, Ablegen), TxContext, Init-Funktionen, One-Time Witness, Paketveröffentlichung und Upgrades, Ressourcensicherheit, Ereignisse und Münzen ab. Verwenden Sie es auch, wenn der Benutzer nach Strukturfähigkeiten, UID, der Zerstörung von Objekten oder der Erstellung eines fungiblen Tokens fragt.
Informationen zum Objektmodell und zum Besitz finden Sie im Skill „Objektmodell“. Informationen zu programmierbaren Transaktionsblöcken finden Sie im Skill „ptbs“. Informationen zur Frontend-dApp-Entwicklung finden Sie im Skill „Frontend-Apps“. Informationen zur Projekteinrichtung und Move.toml finden Sie im Skill „sui-move-project“.
