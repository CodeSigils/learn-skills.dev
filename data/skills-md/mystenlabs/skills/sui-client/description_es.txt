Configuración del cliente Sui CLI, gestión de direcciones y adquisición de tokens. Utilice esta habilidad cuando el usuario necesite configurar el cliente Sui por primera vez, administrar entornos o direcciones, cambiar de red, obtener tokens de faucet, verificar saldos, recuperar claves de una frase de recuperación, fusionar objetos de monedas o buscar transacciones en exploradores. Úselo también cuando el usuario vea errores "No se puede encontrar la moneda de gas para la dirección del firmante" o pregunte sobre los comandos del cliente sui, client.yaml, sui.keystore, SuiVision o Suiscan.
