Come leggere i dati dalla rete Sui. Da utilizzare quando si sceglie o si implementa una strategia di accesso ai dati: query per stato sulla catena, pipeline di indicizzazione, ricerche cronologiche, sottoscrizioni di eventi, letture multicatena o archiviazione BLOB fuori catena. Copre le tre API Sui live (gRPC, GraphQL RPC, JSON-RPC deprecato), l'Archival Store, l'indicizzatore per uso generale, il framework di indicizzazione personalizzato `sui-indexer-alt` e Walrus per i BLOB fuori catena.
