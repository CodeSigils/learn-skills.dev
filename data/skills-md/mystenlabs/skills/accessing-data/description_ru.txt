Как читать данные из сети Sui. Используйте при выборе или реализации стратегии доступа к данным — запросы на состояние в цепочке, конвейеры индексации, исторические поиски, подписки на события, чтение между цепочками или хранилище BLOB-объектов вне цепочки. Охватывает три действующих API Sui (gRPC, GraphQL RPC, устаревший JSON-RPC), архивное хранилище, индексатор общего назначения, инфраструктуру пользовательского индексирования sui-indexer-alt и Walrus для BLOB-объектов вне цепочки.
