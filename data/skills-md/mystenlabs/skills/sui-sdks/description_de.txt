Sui SDK-Landschaft – welches SDK ausgewählt werden soll (TypeScript, Rust oder von der Community gepflegtes Python/Go/Dart/Kotlin/Swift), wie sie einander zugeordnet werden und wie jedes einzelne installiert und verkabelt wird. Verwenden Sie diese Option, wenn ein Benutzer ein neues Sui-Projekt in einer beliebigen Sprache startet, zwischen Sprachen migriert, APIs verschiedener SDKs vergleicht oder fragt: „Welches SDK soll ich für X verwenden?“. Für tiefe Muster innerhalb eines einzelnen SDKs leiten Sie zur Referenzdatei dieses SDKs weiter.
