Panorama de Sui SDK: qué SDK elegir (TypeScript, Rust o Python/Go/Dart/Kotlin/Swift mantenido por la comunidad), cómo se asignan entre sí y cómo instalar y conectar cada uno de ellos. Úselo cuando un usuario inicia un nuevo proyecto Sui en cualquier idioma, migra entre idiomas, compara API entre SDK o pregunta "¿qué SDK debo usar para X?". Para patrones profundos dentro de un único SDK, diríjase al archivo de referencia de ese SDK.
