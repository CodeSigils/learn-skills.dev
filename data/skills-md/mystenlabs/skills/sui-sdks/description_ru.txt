Ландшафт Sui SDK — какой SDK выбрать (TypeScript, Rust или поддерживаемый сообществом Python/Go/Dart/Kotlin/Swift), как они сопоставляются друг с другом, а также как установить и подключить каждый из них. Используйте, когда пользователь запускает новый проект Sui на любом языке, мигрирует между языками, сравнивает API разных SDK или спрашивает: «Какой SDK мне следует использовать для X?». Для глубоких шаблонов внутри одного SDK перейдите к справочному файлу этого SDK.
