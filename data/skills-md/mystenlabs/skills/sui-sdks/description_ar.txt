مشهد Sui SDK - أي SDK يجب اختياره (TypeScript أو Rust أو Python/Go/Dart/Kotlin/Swift التي يديرها المجتمع)، وكيفية ربطها ببعضها البعض، وكيفية تثبيت كل منها وتوصيلها. يتم استخدامه عندما يبدأ المستخدم مشروع Sui جديد بأي لغة، أو يتنقل بين اللغات، أو يقارن واجهات برمجة التطبيقات عبر مجموعات SDK، أو يسأل "ما هو SDK الذي يجب أن أستخدمه لـ X؟". بالنسبة للأنماط العميقة داخل حزمة SDK واحدة، قم بالتوجيه إلى الملف المرجعي الخاص بـ SDK هذا.
