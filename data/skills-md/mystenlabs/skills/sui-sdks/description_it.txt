Panorama dell'SDK Sui: quale SDK scegliere (TypeScript, Rust o Python/Go/Dart/Kotlin/Swift gestito dalla community), come si associano tra loro e come installarli e collegarli. Da utilizzare quando un utente sta avviando un nuovo progetto Sui in qualsiasi lingua, effettuando la migrazione da una lingua all'altra, confrontando le API tra gli SDK o chiedendo "quale SDK dovrei utilizzare per X?". Per i pattern profondi all'interno di un singolo SDK, instrada al file di riferimento di quell'SDK.
