Paysage du SDK Sui - quel SDK choisir (TypeScript, Rust ou Python/Go/Dart/Kotlin/Swift géré par la communauté), comment ils se mappent les uns aux autres et comment les installer et les connecter chacun. À utiliser lorsqu'un utilisateur démarre un nouveau projet Sui dans n'importe quelle langue, migre entre les langues, compare les API entre les SDK ou demande « quel SDK dois-je utiliser pour X ? Pour les modèles profonds au sein d’un seul SDK, accédez au fichier de référence de ce SDK.
