Разработка внешнего интерфейса / dApp с помощью @mysten/dapp-kit-react (React) и @mysten/dapp-kit-core (Vue, vanilla JS, Svelte, веб-компоненты, другие фреймворки). Используйте при создании браузерных приложений, которые подключают кошельки Sui, запрашивают состояние цепочки или отправляют транзакции. Охватывает подключение кошелька, переключение сети, выполнение транзакций, шаблоны запросов с помощью TanStack React Query и конкретные подводные камни сред браузер + кошелек + асинхронный индексатор. Используйте навык sui-sdks для шаблонов построения транзакций @mysten/sui и навык ptbs для семантики PTB.
