Veröffentlichung, Aktualisierung und Bereitstellung dezentraler Websites auf Walrus Sites. Verwenden Sie diese Option, wenn der Benutzer ein Frontend für Walrus Sites bereitstellen, ein lokales Portal für Testnet ausführen, Site-Builder-Fehler debuggen, ws-resources.json konfigurieren oder den Lebenszyklus von Site-Objekten verwalten muss (Blobs aktualisieren, zerstören, erweitern). Verwenden Sie es auch, wenn der Benutzer nach Site-Builder, Walrus-Sites, Portal-Einrichtung oder dem Hosten einer dApp auf Walrus fragt. Informationen zur Blob-Speicherung ohne das Sites-Framework (Roh-Upload/Download) finden Sie in walrus.md des Skills „accessing-data“.
