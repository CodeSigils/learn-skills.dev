Publication, mise à jour et service de sites Web décentralisés sur les sites Walrus. À utiliser lorsque l'utilisateur doit déployer une interface sur les sites Walrus, exécuter un portail local pour testnet, déboguer les erreurs du constructeur de site, configurer ws-resources.json ou gérer le cycle de vie des objets du site (mettre à jour, détruire, étendre les blobs). À utiliser également lorsque l'utilisateur pose des questions sur le constructeur de site, les sites Walrus, la configuration du portail ou l'hébergement d'une dApp sur Walrus. Pour le stockage blob sans le framework Sites (téléchargement/téléchargement brut), consultez walrus.md de la compétence « accès aux données ».
