Verwenden Sie die PlanetScale-CLI (pscale) von automatisierten Agenten mit --format json, Authentifizierungsprüfung, pscale sql und pro Befehl --force. Führen Sie vor anderen PlanetScale-Skills aus, wenn Sie pscale direkt steuern. Verwenden Sie diese Option, wenn der Benutzer pscale automatisieren, CLI-Befehle kopflos ausführen oder die pscale-Authentifizierung von einem Agenten überprüfen möchte.
