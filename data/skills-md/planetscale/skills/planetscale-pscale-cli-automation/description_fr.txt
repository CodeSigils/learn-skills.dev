Utilisez la CLI PlanetScale (pscale) à partir d'agents automatisés avec --format json, auth check, pscale sql et par commande --force. Exécutez avant les autres compétences PlanetScale lorsque vous conduisez directement pscale. À utiliser lorsque l'utilisateur demande d'automatiser pscale, d'exécuter des commandes CLI sans tête ou de vérifier l'authentification pscale à partir d'un agent.
