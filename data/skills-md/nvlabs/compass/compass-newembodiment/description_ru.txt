Подключите новую платформу роботов к COMPASS: сгенерируйте ArticulationCfg робота + env_cfg для каждого варианта реализации, зарегистрируйтесь в EmbodimentEnvCfgMap, выполните дымовое тестирование создания с помощью --num_envs 1. Используйте всякий раз, когда пользователь хочет добавить нового робота, зарегистрировать вариант реализации или расширить COMPASS своей платформой. НЕ для переключения между встроенными вариантами (используйте --embodiment) или для добавления новой сцены (навык `компас` охватывает SAGE → регистр).
