Mermaid diagram drawing assistant. Used when the user explicitly asks to draw a Mermaid diagram or mentions flowcharts, architecture diagrams, sequence diagrams, state diagrams, Gantt charts, ER diagrams, user journey maps, or class diagrams and wants the Mermaid code block output directly. It first determines the most suitable diagram type, then generates renderable, clearly structured Mermaid code, and provides brief explanations or iteration suggestions when necessary. Not suitable for high-fidelity visual design drafts.
