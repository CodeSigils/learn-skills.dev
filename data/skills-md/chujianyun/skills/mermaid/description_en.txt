Mermaid diagram assistant. Used when the user explicitly requests drawing a Mermaid diagram, or mentions flowcharts, architecture diagrams, sequence diagrams, state diagrams, Gantt charts, ER diagrams, user-journey maps, or class diagrams and wants the Mermaid code block output directly. It first determines the most suitable diagram type, then generates renderable, well-structured Mermaid code and, when necessary, adds brief explanations or iteration suggestions. Not suitable for scenarios requiring high-fidelity visual designs.
