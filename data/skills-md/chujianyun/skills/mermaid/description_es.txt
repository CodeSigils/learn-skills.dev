Asistente de diagrama de sirena. Se utiliza cuando el usuario solicita explícitamente dibujar un diagrama de Mermaid, o menciona diagramas de flujo, diagramas de arquitectura, diagramas de secuencia, diagramas de estado, diagramas de Gantt, diagramas ER, mapas de viaje del usuario o diagramas de clases y desea que el bloque de código de Mermaid genere directamente. Primero determina el tipo de diagrama más adecuado, luego genera código Mermaid bien estructurado y renderizable y, cuando es necesario, agrega breves explicaciones o sugerencias de iteración. No apto para escenarios que requieren diseños visuales de alta fidelidad.
