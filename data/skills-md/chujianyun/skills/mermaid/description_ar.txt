مساعد رسم مخطط حورية البحر. يُستخدم عندما يطلب المستخدم صراحةً رسمًا تخطيطيًا لحورية البحر أو يذكر مخططات انسيابية أو مخططات معمارية أو مخططات تسلسلية أو مخططات حالة أو مخططات جانت أو مخططات ER أو خرائط رحلة المستخدم أو مخططات الفصل ويريد إخراج كود حورية البحر مباشرة. فهو يحدد أولاً نوع المخطط الأكثر ملاءمة، ثم يقوم بإنشاء رمز حورية البحر قابل للعرض ومنظم بشكل واضح، وعند الضرورة، يضيف تفسيرات مختصرة أو اقتراحات للتكرار. غير مخصص لمسودات التصميم المرئي عالية الدقة.
