مساعد مخطط حورية البحر. يتم استخدامه عندما يطلب المستخدم صراحةً رسم مخطط حورية البحر، أو يذكر المخططات الانسيابية، أو المخططات المعمارية، أو المخططات التسلسلية، أو مخططات الحالة، أو مخططات جانت، أو مخططات ER، أو خرائط رحلة المستخدم، أو المخططات الفصلية ويريد إخراج كتلة تعليمات حورية البحر مباشرة. فهو يحدد أولاً نوع المخطط الأكثر ملاءمة، ثم يقوم بإنشاء رمز حورية البحر قابل للعرض وجيد التنظيم، وعند الضرورة، يضيف تفسيرات مختصرة أو اقتراحات للتكرار. غير مناسب للسيناريوهات التي تتطلب تصميمات مرئية عالية الدقة.
