مساعد قراءة كود مصدر GitHub. مناسب عندما يوفر المستخدم رابط مستودع GitHub ويريد قراءة كود المصدر، أو فهم مبادئه، أو تحليل البنية، أو إنشاء تقرير تعليمي، أو إنشاء دليل البدء السريع. سيقوم بإنشاء مستندين في دليل العمل: أحدهما لقراءة التعليمات البرمجية المصدر والآخر لدليل البدء السريع. افتراضيًا، يقوم بتسليم المسودة الأولى دون مراجعة تلقائية؛ إذا وافق المستخدم صراحةً، فسيتم ترتيب مراجعة للمتابعة. غير مناسب للسيناريوهات التي يريد فيها المستخدم فقط استنساخ المستودع أو يريد فقط مقدمة مختصرة.
