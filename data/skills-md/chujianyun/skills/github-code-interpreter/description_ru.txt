Помощник по чтению исходного кода GitHub. Подходит, когда пользователь предоставляет ссылку на репозиторий GitHub и хочет интерпретировать исходный код, понять принципы, проанализировать архитектуру, создать отчеты об обучении или создать документацию для быстрого запуска. Он создаст два документа — интерпретацию исходного кода и краткое руководство — в рабочем каталоге. По умолчанию он доставляет первый черновик без автоматического рассмотрения; если пользователь явно согласен, будет организована последующая проверка. Не подходит для сценариев, где требуется только клонирование репозитория или краткое описание.
