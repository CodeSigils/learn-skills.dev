GitHub Source Code Reading Assistant. Suitable when a user provides a GitHub repository link and wants to read the source code, understand its principles, analyze its architecture, generate a learning report, or create a quick-start guide. It produces two documents in the working directory: a source-code reading guide and a quick-start guide. By default, it first delivers a draft without automatic review; only if the user explicitly agrees will a follow-up review be scheduled. Not intended for merely cloning a repository or for one-sentence summaries.
