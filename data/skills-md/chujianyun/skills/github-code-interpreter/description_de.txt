Assistent zur Interpretation des GitHub-Quellcodes. Wird verwendet, wenn ein Benutzer einen GitHub-Repository-Link bereitstellt und den Quellcode interpretieren, seine Prinzipien verstehen, seine Architektur analysieren, einen Lernbericht erstellen oder eine Kurzanleitung erstellen möchte. Es werden zwei Dokumente im Arbeitsverzeichnis generiert: Quellcode-Interpretation und Kurzanleitung. Standardmäßig wird ein erster Entwurf ohne automatische Überprüfung bereitgestellt. Stimmt der Nutzer ausdrücklich zu, wird eine Nachprüfung vereinbart. Nicht geeignet für Szenarien, in denen nur das Klonen des Repositorys oder eine Zusammenfassung in einem Satz erforderlich ist.
