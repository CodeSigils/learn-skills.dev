Assistente alla lettura del codice sorgente GitHub. Utilizzato quando un utente fornisce un collegamento al repository GitHub e desidera leggere il codice sorgente, comprenderne i principi, analizzare l'architettura, generare un report di apprendimento o creare una guida rapida. Verranno generati due documenti nella directory di lavoro: uno per la lettura del codice sorgente e uno per l'avvio rapido. Per impostazione predefinita, fornisce una prima bozza senza revisione automatica; se l'utente acconsente esplicitamente, verrà programmata una revisione di follow-up. Non adatto a scenari in cui è necessaria solo la clonazione del repository o una breve introduzione.
