Asistente de lectura de código fuente de GitHub. Adecuado cuando un usuario proporciona un enlace al repositorio de GitHub y desea leer el código fuente, comprender sus principios, analizar su arquitectura, generar un informe de aprendizaje o crear una guía de inicio rápido. Generará dos documentos en el directorio de trabajo: una lectura del código fuente y una guía de inicio rápido. De forma predeterminada, entrega un primer borrador sin revisión automática; si el usuario acepta explícitamente, se organizará una revisión de seguimiento. No es adecuado para escenarios en los que solo se necesita clonar el repositorio o una introducción de una frase.
