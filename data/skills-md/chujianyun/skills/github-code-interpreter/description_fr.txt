Assistant de lecture du code source GitHub. Utilisé lorsque l'utilisateur fournit un lien vers le référentiel GitHub et souhaite lire le code source, comprendre les principes, analyser l'architecture, générer des rapports d'étude ou créer une documentation de démarrage rapide. Il génère deux documents dans le répertoire de travail : lecture du code source et démarrage rapide. Par défaut, il délivre une première ébauche sans révision automatique ; si l'utilisateur l'accepte explicitement, un examen de suivi sera organisé. Ne convient pas aux scénarios où seul le clonage du référentiel ou une introduction en une phrase est nécessaire.
