Помощник по чтению бумаги. Для пользователей, которые отправляют ссылки arXiv и хотят, чтобы статья была загружена, интерпретирована, превращена в заметки для чтения, проанализирована или выведена в виде подробного отчета. Создает бумажную папку в рабочем каталоге, загружает исходные файлы PDF и TeX (если доступны) и создает отчет Markdown на китайском языке. По умолчанию предоставляет первый черновик без автоматического рассмотрения; если пользователь явно согласен, назначается последующая проверка. Не подходит только для кратких рекомендаций.
