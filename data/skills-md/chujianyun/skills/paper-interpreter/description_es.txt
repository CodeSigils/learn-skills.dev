Asistente de lectura de artículos. Diseñado para cuando un usuario envía un enlace arXiv y desea descargar el artículo, interpretarlo, crear notas de lectura, desglosarlo o generar un informe detallado. Crea una carpeta de papel en el directorio de trabajo, descarga el código fuente PDF y TeX si está disponible y genera un informe de Markdown en chino. De forma predeterminada, entrega un primer borrador y no se revisa automáticamente; si el usuario acepta explícitamente, se programa una revisión de seguimiento. No está destinado únicamente a recomendaciones breves.
