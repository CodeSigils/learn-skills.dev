Paper Reading Assistant.  
For when a user sends an arXiv link and wants the paper downloaded, interpreted, turned into reading notes, dissected, or output as a detailed report.  
Creates a paper folder in the working directory, downloads the PDF and TeX source (if available), and produces a Chinese Markdown report.  
Delivers a first draft by default without automatic review; proceeds to scheduled follow-up reviews only if the user explicitly agrees.  
Not intended for brief recommendations.
