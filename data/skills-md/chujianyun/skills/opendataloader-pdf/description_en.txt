PDF data extraction tool. Use when the user mentions "PDF extraction", "PDF to Markdown", "PDF parsing", "extract PDF content", "PDF to JSON", "RAG PDF". OpenDataLoader PDF is currently the top-ranked PDF parser in benchmarks, supporting local mode (fast, deterministic) and hybrid AI mode (complex tables, scanned documents, formulas), outputting Markdown, JSON (with bounding boxes), HTML. Suitable for scenarios requiring structured data extraction from PDFs for RAG/LLM pipelines or batch processing of PDF documents.
