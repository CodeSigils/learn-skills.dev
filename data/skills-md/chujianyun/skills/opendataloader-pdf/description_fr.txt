Outil d'extraction de données PDF. À utiliser lorsque l'utilisateur mentionne « Extraction PDF », « PDF vers Markdown », « Analyse PDF », « Extraire le contenu PDF », « PDF vers JSON » ou « RAG PDF ». OpenDataLoader PDF est actuellement l'analyseur PDF le mieux classé dans les benchmarks, prenant en charge le mode local (rapide, déterministe) et le mode IA hybride (tableaux complexes, analyses, formules), produisant Markdown, JSON (avec cadres de délimitation) et HTML. Idéal pour extraire des données structurées à partir de PDF pour les pipelines RAG/LLM ou pour le traitement par lots de documents PDF.
