Überprüfen oder entwerfen Sie die Projektkonfiguration von Claude Code. Verwenden Sie diese Option, wenn der Benutzer „.claude“, „CLAUDE.md“, Claude-Konfigurationsdateien, benutzerdefinierte Claude-Konfiguration auf Projektebene erwähnt, ob die Konfigurationsstruktur angemessen ist, welche Konfigurationsdateien erstellt werden sollen oder ob er die Claude-Konfiguration von Grund auf planen möchte. Standardmäßig zuerst überprüfen oder diagnostizieren und dann einen Plan bereitstellen; Geben Sie die empfohlene Struktur oder Beispieldateien nur aus, wenn der Benutzer dies ausdrücklich fragt.
