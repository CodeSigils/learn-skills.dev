Réviser ou concevoir les configurations du projet Claude Code. À utiliser lorsque l'utilisateur mentionne `.claude`, `CLAUDE.md`, les fichiers de configuration Claude, la personnalisation de Claude au niveau du projet, si la structure de configuration est raisonnable, quels fichiers de configuration créer ou s'il souhaite planifier la configuration de Claude à partir de zéro. Par défaut, examinez ou diagnostiquez d'abord, puis proposez une solution ; n'affiche la structure recommandée ou les fichiers d'exemple que lorsque l'utilisateur le demande explicitement.
