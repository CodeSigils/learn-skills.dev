Consultant en conception d'agents et outil de révision. Basé sur les meilleures pratiques AgentOps à 12 facteurs, il est utilisé pour : (1) explorer les solutions de conception d'architecture d'agent ; (2) examiner les conceptions d'agent/compétence/workflow existantes, identifier les problèmes et proposer des suggestions d'amélioration. Phrases de déclenchement : « examiner mon agent », « aidez-moi à analyser cette compétence », « conception d'agent », « optimisation d'agent », « aidez-moi à examiner ce flux de travail », « quels problèmes cet agent a-t-il », « comment concevoir un agent », « conseil en architecture d'agent ».
