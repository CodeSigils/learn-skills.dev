Консультант по дизайну агентов и инструмент для проверки. Основанный на передовом опыте 12-Factor AgentOps, он используется для: (1) изучения решений по проектированию архитектуры агентов; (2) рассмотрение существующих структур агентов/навыков/рабочих процессов, выявление проблем и предложение предложений по улучшению. Триггерные фразы: «проверьте моего агента», «помогите мне проанализировать этот навык», «разработка агента», «оптимизация агента», «помогите мне просмотреть этот рабочий процесс», «какие проблемы есть у этого агента», «как спроектировать агента», «консультирование по архитектуре агента».
