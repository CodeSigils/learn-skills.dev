Strumento Programmatic Grounded Theory Coding (Grounded Theory Coding). Esegue sistematicamente codifica aperta (identificare eventi → perfezionare categorie → analizzare categorie), codifica assiale (analisi delle relazioni del modello paradigmatico) e codifica selettiva (categoria principale → domanda di ricerca → trama → dialogo teorico) sulle trascrizioni delle interviste o altri dati qualitativi. Una volta completata, ogni intervista viene salvata automaticamente come file Markdown; una volta completate tutte le interviste, genera un riepilogo Excel secondo necessità. Questa abilità viene attivata quando l'utente menziona la necessità di codifica fondata/codifica teorica fondata/codifica aperta/codifica qualitativa, o menziona la necessità di codificare e analizzare dati qualitativi/dell'intervista, o carica/fornisce un percorso di file locale per i record dell'intervista. Anche se l’utente dice solo vagamente “aiutami a codificare questa intervista”, “analisi di codifica fondata”, “esegui codifica aperta durante l’intervista”, “codifica dei dati qualitativa” o “aiutami a fare analisi teorica fondata”, l’abilità dovrebbe comunque essere attivata.
