Programmatic Grounded Theory Coding tool. Systematically performs open coding (identify events → refine categories → analyze categories), axial coding (paradigm model relationship analysis), and selective coding (core category → research question → storyline → theoretical dialogue) on interview transcripts or other qualitative data. After each interview is completed, it automatically saves as a Markdown file; after all interviews are completed, it generates a summary Excel as needed. This skill is triggered when the user mentions needing grounded coding/grounded theory coding/open coding/qualitative coding, or mentions needing to code/analyze interview or qualitative data, or uploads/provides a local file path to interview records. Even if the user simply says “help me code this interview,” “grounded coding analysis,” “do open coding on the interview,” “qualitative data coding,” or “help me do grounded theory analysis,” this skill should be triggered.
