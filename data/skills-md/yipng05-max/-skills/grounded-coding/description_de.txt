Programmatic Grounded Theory-Codierungstool. Führt systematisch offene Kodierung (Ereignisse identifizieren → Kategorien verfeinern → Kategorien analysieren), axiale Kodierung (Paradigmenmodell-Beziehungsanalyse) und selektive Kodierung (Kernkategorie → Forschungsfrage → Handlung → theoretischer Dialog) an Interviewtranskripten oder anderen qualitativen Daten durch. Nach Abschluss jedes Interviews wird es automatisch als Markdown-Datei gespeichert. Nachdem alle Interviews abgeschlossen sind, wird bei Bedarf eine zusammenfassende Excel-Datei erstellt. Diese Fähigkeit wird ausgelöst, wenn der Benutzer angibt, dass er Grounded Coding/Grounded Theory Coding/Open Coding/qualitative Codierung benötigt, oder erwähnt, dass Interviews oder qualitative Daten codiert/analysiert werden müssen, oder einen lokalen Dateipfad zu Interviewdatensätzen hochlädt/bereitstellt. Auch wenn der Benutzer einfach sagt: „Hilf mir, dieses Interview zu programmieren“, „Grounded-Coding-Analyse“, „Offenes Coding für das Interview durchführen“, „Qualitative Datencodierung“ oder „Hilf mir, eine Grounded-Theorie-Analyse durchzuführen“, sollte diese Fähigkeit ausgelöst werden.
