Ein programmierbares Grounded-Theory-Codierungstool. It systematically performs open coding (identifying events → refining categories → analyzing categories), axial coding (paradigmatic model relationship analysis), and selective coding (core category → research question → storyline → theoretical dialogue) on interview transcripts or other qualitative data. Nach Abschluss jedes Interviews werden die Ergebnisse automatisch als Markdown-Datei gespeichert; Sobald alle Interviews abgeschlossen sind, wird bei Bedarf eine zusammenfassende Excel-Datei erstellt. This skill is triggered when the user mentions the need for grounded coding / grounded theory coding / open coding / qualitative coding, or indicates a need to code and analyze interview / qualitative material, or uploads / provides a local file path to interview records. Even if the user simply says “help me code this interview,” “grounded coding analysis,” “do open coding on the interview,” “qualitative data coding,” or “help me do grounded theory analysis,” the skill should be activated.
