Outil de codage de théorie programmatique fondée. Effectue systématiquement un codage ouvert (identifier les événements → affiner les catégories → analyser les catégories), un codage axial (analyse paradigmatique des relations avec le modèle) et un codage sélectif (catégorie principale → question de recherche → scénario → dialogue théorique) sur les transcriptions d'entretiens ou d'autres données qualitatives. Une fois chaque entretien terminé, il est automatiquement enregistré sous forme de fichier Markdown ; une fois tous les entretiens terminés, il génère un fichier Excel récapitulatif selon les besoins. Cette compétence est déclenchée lorsque l'utilisateur mentionne avoir besoin d'un codage fondé / d'un codage théorique fondé / d'un codage ouvert / d'un codage qualitatif, ou mentionne avoir besoin d'une analyse de codage des données d'entretien / données qualitatives, ou télécharge / fournit un chemin de fichier local vers les enregistrements d'entretien. Même si l'utilisateur dit simplement « aidez-moi à coder cet entretien », « analysez le codage fondé », « faites du codage ouvert sur l'entretien », « codifiez les données qualitatives » ou « aidez-moi à faire une analyse théorique fondée », cette compétence doit être déclenchée.
