Herramienta de codificación de teoría fundamentada programática (Codificación de teoría fundamentada). Realiza sistemáticamente codificación abierta (identificar eventos → refinar categorías → analizar categorías), codificación axial (análisis de relaciones de modelos paradigmáticos) y codificación selectiva (categoría central → pregunta de investigación → argumento → diálogo teórico) en transcripciones de entrevistas u otros datos cualitativos. Una vez completada cada entrevista, se guarda automáticamente como un archivo Markdown; Una vez completadas todas las entrevistas, genera un archivo Excel resumido a pedido. Esta habilidad se activa cuando el usuario menciona la necesidad de codificación fundamentada/codificación de teoría fundamentada/codificación abierta/codificación cualitativa, o indica la necesidad de codificar y analizar entrevistas o material cualitativo, o carga/proporciona una ruta de archivo local a los registros de entrevistas. Incluso si el usuario simplemente dice "ayúdame a codificar esta entrevista", "análisis de codificación fundamentada", "realiza codificación abierta en la entrevista", "codificación de material cualitativo" o "ayúdame a realizar un análisis de teoría fundamentada", la habilidad debe activarse.
