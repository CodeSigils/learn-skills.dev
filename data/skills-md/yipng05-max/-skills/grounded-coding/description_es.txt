Herramienta de codificación de teoría fundamentada programática. Realiza sistemáticamente codificación abierta (identificar eventos → refinar categorías → analizar categorías), codificación axial (análisis de relaciones del modelo paradigmático) y codificación selectiva (categoría central → pregunta de investigación → argumento → diálogo teórico) en transcripciones de entrevistas u otros datos cualitativos. Una vez completada cada entrevista, se guarda automáticamente como un archivo Markdown; Una vez completadas todas las entrevistas, genera un resumen de Excel según sea necesario. Esta habilidad se activa cuando el usuario menciona que necesita codificación fundamentada/codificación de teoría fundamentada/codificación abierta/codificación cualitativa, o menciona la necesidad de codificar/analizar entrevistas o datos cualitativos, o carga/proporciona una ruta de archivo local para los registros de entrevistas. Incluso si el usuario simplemente dice "ayúdame a codificar esta entrevista", "análisis de codificación fundamentada", "realiza codificación abierta en la entrevista", "codificación de datos cualitativos" o "ayúdame a realizar un análisis de teoría fundamentada", esta habilidad debe activarse.
