Argument Structure Review Tool (Argument Auditor). Conduct a structural review of argument units (paragraphs/sections/chapters) in academic writing, checking the completeness of claim‑evidence‑reasoning, identifying issues such as logical jumps, circular reasoning, insufficient evidence, and providing actionable revision suggestions. This skill is triggered when the user says “Help me look at this argument,” “Is the logic here correct,” “Review this section,” “Is there any problem with the argument,” “Is this reasoning rigorous,” “Help me check the argument structure,” or “Is this passage persuasive enough.” Note: This is not a language polishing tool, but a deep‑review tool specifically for argumentative logic. Issues with language expression are outside the scope of this skill.
