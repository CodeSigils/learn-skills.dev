Herramienta de revisión de estructura de argumentos (Argument Auditor). Realiza una revisión estructural de unidades argumentativas (párrafos/secciones/capítulos) en escritos académicos, verificando la integridad del razonamiento de afirmación-evidencia, identificando problemas como saltos lógicos, razonamiento circular, evidencia insuficiente y brindando sugerencias de revisión procesables. Esta habilidad se activa cuando el usuario dice "ayúdame a analizar este argumento", "la lógica es correcta aquí", "revisa esta sección", "hay algún problema con el argumento", "este razonamiento es riguroso", "ayúdame a verificar la estructura del argumento" o "este pasaje es lo suficientemente persuasivo". Nota: Esta no es una herramienta para pulir el lenguaje, sino una herramienta de revisión profunda dirigida específicamente a la lógica argumentativa. Las cuestiones de expresión del lenguaje están fuera del alcance de esta habilidad.
