Foreign-language academic literature search tool (social science focus). Based on the OpenAlex open API (no institutional account required, no API key needed), it performs a three-stage search: ① Primary combined search (most specific group main search + post‑filtering of other groups' text, achieving true AND semantics) ② Independent supplementary search (background literature on the research subject + core theoretical literature) ③ Consolidated deduplication and classification in Excel. Simultaneously generates WoS/Scopus Boolean search strings for users with institutional access. Trigger conditions: user mentions needing to search foreign/English/SSCI literature, search foreign academic databases, help me find English papers, foreign literature search, search SSCI/SCI papers, etc.
