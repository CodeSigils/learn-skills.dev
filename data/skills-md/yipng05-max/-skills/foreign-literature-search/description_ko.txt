외국 학술 문헌 검색 도구(사회 과학 중심). OpenAlex 오픈 API(기관 계정 불필요, API 키 불필요)를 기반으로 3단계 검색을 수행합니다. ① 1차 통합 검색(가장 구체적인 그룹 1차 검색 + 다른 그룹의 텍스트 사후 필터링, true AND 의미 달성) ② 독립적 보충 검색(연구 주제에 대한 배경 문헌 + 핵심 이론 문헌) ③ 요약, 중복 제거, Excel로 분류합니다. 기관 접근 권한이 있는 사용자를 위한 WoS/Scopus 부울 검색 문자열을 동시에 생성합니다. 트리거 조건: 사용자가 외국/영어/SSCI 문헌 검색, 외국 학술 데이터베이스 검색, 영어 논문 검색 지원, 외국 문헌 검색, SSCI/SCI 논문 검색 등이 필요하다고 언급하는 경우.
