Инструмент поиска академической литературы на иностранном языке (социальные науки). На основе открытого API OpenAlex (не требуется институциональная учетная запись, не требуется ключ API) он выполняет трехэтапный поиск: ① первичный комбинированный поиск (основной поиск по наиболее конкретной группе + последующая фильтрация текста другими группами, достижение истинной семантики AND) ② независимый дополнительный поиск (справочная литература по объекту исследования + основная теоретическая литература) ③ агрегированная дедупликация и категоризация в Excel. Одновременно генерирует логические строки поиска WoS/Scopus для пользователей с институциональным доступом. Условия срабатывания: пользователь упоминает о необходимости поиска зарубежной/английской/SSCI литературы, поиска в зарубежных академических базах данных, помощи в поиске английской литературы, поиска иностранной литературы, поиска статей SSCI/SCI и т. д.
