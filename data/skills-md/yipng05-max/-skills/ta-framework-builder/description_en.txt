TA (Theme Analysis) exclusive theoretical framework construction tool. Guides researchers to clarify theoretical positioning (theory-driven/experience-driven/sensitivity concept) before data analysis, assess candidate theories, determine core concepts and their operational definitions, and output a framework document for direct use by the ta-framework-writer. It is triggered when users mention the need to build a theoretical framework for a theme analysis study, select a theoretical perspective, determine theoretical positioning, or reach the "theoretical framework construction" checkpoint in the ta-research-workflow.
