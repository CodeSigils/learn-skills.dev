Ein Tool zur qualitativen Forschungsunterstützung, das auf dem reflexiven thematischen Analyserahmen von Braun & Clarke basiert.  
Unterstützt zwei Eingabemodi:  
1. Stellen Sie den rohen Interviewtext direkt bereit → Der Skill führt Stück für Stück die anfängliche TA-Codierung durch und aggregiert sie dann zur Themenidentifizierung.  
2. Stellen Sie einen vorhandenen Pool von Anfangscodes bereit → Fahren Sie direkt mit dem Clustering-, Überprüfungs- und Benennungsvorschlags-Workflow fort.  

Gibt eine strukturierte Kandidaten-Thementabelle aus, in der mehrdeutig begrenzte Codes und Benennungsvorschläge bis zur Entscheidung des Forschers klar gekennzeichnet sind.  

Die Fertigkeit wird ausgelöst, wenn der Benutzer „Themenanalyse“, „Themenkodierung“, „Hilf mir, Codes zu gruppieren“, „Themen aus Codes ableiten“, „BraunClarke“, „Kandidatenthemen“, „wie man diese Codes Themen zuordnet“, „hilft mir, die Themenstruktur zu betrachten“, „durchführen einer thematischen Analyse des Interviews“ usw. erwähnt.  

Beachten Sie den Unterschied zum Grounded-Coding: Grounded-Coding zielt auf den prozeduralen Aufbau von Grounded-Theory-Klassen und theoretischen Beziehungen ab; Die thematische Analyse folgt dem Braun&Clarke-Weg zur semantischen Themenidentifizierung und gibt eine Themenstruktur statt theoretischer Aussagen aus.
