Theory Fit Assessment tool. Before a researcher decides to use a particular theory, it systematically evaluates the degree of match between that theory and the research question: core mechanisms, boundary conditions, epistemological compatibility, empirical operability, and comparison with alternative theories. It prevents “label‑sticking” use of theory. This skill is triggered when the user says “I want to use XX theory,” “Is this theory suitable for my research?” “Bourdieu or Foucault?” “Can this theory explain my phenomenon?” “Help me choose a theory,” “How should I select a theoretical framework?” “Does the theory fit?” “Can this theory be used here?” Note: This is not a theory introduction tool (use concept-clarifier for concept introductions), but a decision‑support tool specifically for assessing the fit between a particular theory and a specific research problem.
