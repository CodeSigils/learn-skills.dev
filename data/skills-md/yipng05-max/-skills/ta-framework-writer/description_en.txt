TA (Topic Analysis) theoretical framework chapter writing tool. It converts the results of constructing a theoretical framework into the main body chapters of a paper, automatically generating chapter text in the appropriate form based on theoretical positioning (A: theory‑driven, B: experience‑driven, C: sensitivity concept). It is triggered when the user needs to insert the theoretical framework into a paper, write the theoretical framework chapter, or reaches the “theoretical framework chapter writing” checkpoint in the ta‑research‑workflow.
