Tool, das Excel-Tabellen (.xlsx) aus strukturierten Textinhalten generiert. Unterstützt das Parsen verschiedener vom Benutzer bereitgestellter strukturierter Texte (Tabellen, Listen, Schlüsselwertpaare, CSV, Markdown-Tabellen, JSON usw.), das automatische Erkennen von Kopfzeilen und Datenzeilen sowie das Generieren sauber formatierter Excel-Dateien. Unterstützt mehrere Blätter, verbundene Zellen, Stileinstellungen, eingefrorene Bereiche, automatische Filter, bedingte Formatierung, Datenvalidierung, Diagrammerstellung und alle anderen Funktionen. Wird ausgelöst, wenn der Benutzer eines der folgenden Szenarios erwähnt: (1) Text/Daten/Inhalt müssen in eine Excel-/Tabellen-/XLSX-Datei konvertiert werden; (2) Muss eine Excel-Tabelle erstellen; (3) Muss eine Tabelle erstellen; (4) Bietet strukturierte Daten und fordert die Ausgabe als Excel an; (5) Anfragen, Daten in einer Tabelle zu organisieren; (6) Informationen müssen für den Export in eine Tabelle umgewandelt werden. Schlüsselwörter: Excel, Tabellenkalkulation, XLSX, elektronische Tabellenkalkulation, Tabelle exportieren, Tabelle generieren, in Tabelle umwandeln, in Tabelle konvertieren, in Tabelle organisieren.
