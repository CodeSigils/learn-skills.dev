Tool that generates Excel spreadsheets (.xlsx) from structured text content. Supports parsing various structured texts provided by the user (tables, lists, key‑value pairs, CSV, Markdown tables, JSON, etc.), automatically recognizing headers and data rows, and generating neatly formatted Excel files. Supports multiple sheets, merged cells, style settings, frozen panes, auto‑filter, conditional formatting, data validation, chart generation, and all other functions. Triggers when the user mentions any of the following scenarios: (1) Needs to convert text/data/content into an Excel/spreadsheet/xlsx file; (2) Needs to generate an Excel spreadsheet; (3) Needs to create a spreadsheet; (4) Provides structured data and requests output as Excel; (5) Requests to organize data into a table; (6) Needs to make information into a table for export. Keywords: Excel, spreadsheet, xlsx, electronic spreadsheet, export table, generate table, make into table, convert into table, organize into table.
