一種從結構化文字內容產生 Excel 電子表格 (.xlsx) 的工具。 It supports parsing various structured texts provided by the user (tables, lists, key‑value pairs, CSV, Markdown tables, JSON, etc.), automatically recognizing headers and data rows, and producing neatly formatted Excel files. It offers full functionality such as multiple sheets, merged cells, style settings, frozen panes, auto‑filter, conditional formatting, data validation, chart creation, and more. The tool is triggered when the user mentions any of the following scenarios: (1) needing to convert text/data/content into an Excel/spreadsheet/xlsx file; (2)需要生成Excel表格； (3) 需要制作电子表格； （4）提供结构化数据并要求Excel输出； (5)想要将数据组织成表格； (6)需要将信息导出为表格。關鍵字：Excel、電子表格、xlsx、電子表格、匯出表格、產生表格、製作表格、轉換為表格、組織成表格。
