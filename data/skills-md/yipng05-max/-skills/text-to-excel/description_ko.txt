구조화된 텍스트 콘텐츠에서 Excel 스프레드시트(.xlsx)를 생성하기 위한 도구입니다. 사용자가 제공한 다양한 구조화된 텍스트(테이블, 목록, 키-값 쌍, CSV, 마크다운 테이블, JSON 등) 구문 분석, 헤더 및 데이터 행 자동 인식, 올바른 형식의 Excel 파일 생성을 지원합니다. 여러 시트, 병합된 셀, 스타일 설정, 고정 창, 자동 필터, 조건부 서식, 데이터 유효성 검사, 차트 생성 등과 같은 모든 기능을 지원합니다. 사용자가 다음 시나리오 중 하나를 언급할 때 트리거됩니다. (1) 텍스트/데이터/콘텐츠를 Excel/스프레드시트/xlsx 파일로 변환해야 합니다. (2) Excel 스프레드시트를 생성해야 합니다. (3) 스프레드시트를 만들어야 합니다. (4) 구조화된 데이터를 제공하고 Excel로 출력을 요청합니다. (5) 데이터를 테이블로 정리하도록 요청합니다. (6) 정보를 테이블로 내보내야 합니다. 키워드: Excel, 스프레드시트, xlsx, 전자 스프레드시트, 테이블 내보내기, 테이블 생성, 테이블로 만들기, 테이블로 변환, 테이블로 구성.
