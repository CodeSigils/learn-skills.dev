Installateur de compétences. Installez les compétences Claude Code à partir de diverses sources, avec un processus d'examen de sécurité intégré qui exécute automatiquement le protocole Skill‑vetter avant l'installation. Prise en charge : chemins du référentiel GitHub (propriétaire/dépôt/nom de la compétence), URL de fichiers bruts, chemins de fichiers locaux et collage direct du contenu SKILL.md. Cette compétence est déclenchée lorsque l'utilisateur dit « installer cette compétence », « installer la compétence », « aidez-moi à installer ceci », « installer la compétence depuis GitHub », « installer cette compétence » ou « installer le propriétaire/le dépôt/le nom de la compétence ». Remarque : Toutes les installations doivent passer un examen de sécurité avant l'écriture de fichiers ; toute source inaccessible sera refusée pour l'installation.
