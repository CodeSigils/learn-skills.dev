Installatore di competenze. Installa le competenze di Claude Code da più fonti, con un processo di revisione della sicurezza integrato che esegue automaticamente il protocollo di controllo delle competenze prima dell'installazione. Supporta: percorsi di repository GitHub (proprietario/repo/nome competenza), URL di file non elaborati, percorsi di file locali e incollamento diretto del contenuto SKILL.md. Questa competenza viene attivata quando l'utente dice "installa questa competenza", "installa competenza", "aiutami a installarla", "installa competenza da GitHub", "installa questa competenza", "installa proprietario/repo/nome competenza". Nota: tutte le installazioni devono essere sottoposte a un controllo di sicurezza prima di scrivere i file; qualsiasi fonte il cui contenuto non può essere recuperato viene rifiutata per l'installazione.
