Skill Installer. Install Claude Code skills from various sources, with a built‑in security review process that automatically runs the skill‑vetter protocol before installation. Supports: GitHub repository paths (owner/repo/skill-name), raw file URLs, local file paths, and directly pasting SKILL.md content. This skill is triggered when the user says "install this skill", "install skill", "help me install this", "install skill from GitHub", "install this skill", or "install owner/repo/skill-name". Note: All installations must pass a security review before any files are written; any source that cannot be accessed will be refused for installation.
