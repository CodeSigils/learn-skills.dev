Навык Монтажник. Устанавливайте навыки Claude Code из нескольких источников с помощью встроенного процесса проверки безопасности, который автоматически запускает протокол проверки навыков перед установкой. Поддерживается: пути к репозиторию GitHub (владелец/репо/имя навыка), необработанные URL-адреса файлов, пути к локальным файлам и непосредственно вставленное содержимое SKILL.md. Этот навык срабатывает, когда пользователь говорит «установить этот навык», «установить навык», «помогите мне установить это», «установить навык из GitHub», «установить этот навык» или «установить владельца/репо/имя навыка». Примечание. Все установки должны пройти проверку безопасности перед записью файлов; любой источник, который невозможно получить, будет отклонен для установки.
