Skill-Installer. Installieren Sie Claude Code-Skills aus verschiedenen Quellen mit einem integrierten Sicherheitsüberprüfungsprozess, der vor der Installation automatisch das Skill-Vetter-Protokoll ausführt. Unterstützt: GitHub-Repository-Pfade (Besitzer/Repository/Skill-Name), Rohdatei-URLs, lokale Dateipfade und das direkte Einfügen von SKILL.md-Inhalten. Dieser Skill wird ausgelöst, wenn der Benutzer „Diesen Skill installieren“, „Skill installieren“, „Hilf mir bei der Installation“, „Skill von GitHub installieren“, „Diesen Skill installieren“ oder „Besitzer/Repo/Skill-Name installieren“ sagt. Hinweis: Alle Installationen müssen eine Sicherheitsüberprüfung bestehen, bevor Dateien geschrieben werden. Jede Quelle, auf die nicht zugegriffen werden kann, wird von der Installation ausgeschlossen.
