Instalador de habilidades. Instala habilidades de Claude Code desde múltiples fuentes, con un proceso de revisión de seguridad incorporado que ejecuta automáticamente el protocolo de verificación de habilidades antes de la instalación. Admite: rutas del repositorio de GitHub (propietario/repositorio/nombre de habilidad), URL de archivos sin formato, rutas de archivos locales y contenido SKILL.md pegado directamente. Esta habilidad se activa cuando el usuario dice "instalar esta habilidad", "instalar habilidad", "ayúdame a instalar esto", "instalar habilidad desde GitHub", "instalar esta habilidad" o "instalar propietario/repo/nombre-skill". Nota: Todas las instalaciones deben pasar una revisión de seguridad antes de escribir cualquier archivo; cualquier fuente que no pueda recuperarse será rechazada para la instalación.
