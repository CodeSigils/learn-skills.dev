Batch extract bibliographic information (title, author, year, journal, volume/issue/pages, DOI, abstract) from multiple PDF papers in a folder and import it into Feishu multidimensional tables. This is triggered when a user needs to consolidate the bibliographic and citation information of a batch of PDF papers into Feishu Base / multidimensional tables. Keywords: PDF, paper, citation, bibliography, batch import, Feishu multidimensional tables.
