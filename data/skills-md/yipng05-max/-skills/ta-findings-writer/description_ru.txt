Инструмент для написания глав результатов исследований TA (тематический анализ). Преобразуйте сводную таблицу тем из тематического анализа в раскрывающее повествование, создайте полный параграф анализа для каждой темы на основе теоретического позиционирования (A/B/C) и структуры повествования (параллельная/последовательная), с цитатами, служащими для анализа, без накопления. Срабатывает, когда пользователю необходимо написать главу о результатах исследования или когда он достигает контрольной точки «Написание результатов исследования» в рабочем процессе ta-research-workflow.
