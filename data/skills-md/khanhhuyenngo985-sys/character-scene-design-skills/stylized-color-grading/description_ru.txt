Стилизованная цветокоррекция: преобразуйте классические стили цветокоррекции в видеоподсказки с использованием искусственного интеллекта.  
Триггерные слова: «цветокоррекция», «стилизованная цветокоррекция», «Бирюзовый-Оранжевый», «Фильм-Нуар», «Киберпанк», «Блич-Обход», «Тон Вонг Кар-вая», «Тон Такеши Китано», «эмоциональная цветокоррекция».

Основные функции:  
1. Параметры значения цвета HEX для 12 классических стилей цветокоррекции.  
2. Шаблоны видеоподсказок AI (Seedance/Vidu/Kling)  
3. Процесс принятия решения колористом (семь эмоций×линия стиля×режиссерское слияние)  
4. Варианты слияния режиссерского стиля (Вонг Карвай / Такеши Китано / Ху Цзиньцюань / Энг Ли)

Сотрудничество: агент-колорист, вики-вики по эмоциональной цветокоррекции, навык «оттенок по подсказке».
