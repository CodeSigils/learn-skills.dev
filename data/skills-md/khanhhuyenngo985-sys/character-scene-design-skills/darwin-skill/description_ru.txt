Darwin Skill (达尔文.skill): автономный оптимизатор навыков, вдохновленный автоисследованиями Карпати. Оценивает файлы SKILL.md по восьмимерной шкале (структура + эффективность), выполняет анализ с помощью контроля версий git, проверяет улучшения с помощью тестовых подсказок и генерирует визуальные карты результатов. Используйте, когда пользователь упоминает «优化skill», «skill评分», «自动优化», «автооптимизация», «skill质量检查», «达尔文», «darwin», «帮我改改skill», «skill怎么样», «提升навык质量», «обзор навыков», «навык打分».
