Этот навык следует использовать при реализации каналов IPC (межпроцессная связь) для операций PDF в Electron. Запускается по запросам на создание функций слияния, редактирования или преобразования PDF-файлов, реализацию API-интерфейсов предварительной загрузки или настройку связи Main-Renderer для операций с файлами.
