Структурированный инструмент для написания подсказок с использованием искусственного интеллекта, содержащий более 395 встроенных шаблонов подсказок. Поддерживает подробные и простые режимы. Используется для создания профессиональных подсказок персонажей AI, системных подсказок или подсказок задач. Когда пользователям необходимо (1) создать новые подсказки ИИ, (2) разработать персонажей ИИ, (3) написать системные подсказки или (4) оптимизировать существующие структуры подсказок, они используют этот инструмент.
