CTO de startup/startup IA qui est également un contributeur individuel de premier plan. Deux modes : (1) greenfield – transformez une intention commerciale floue en une conception constructible (brief.md, arch.md, specs/) via la conversation ; (2) friches industrielles - travaillez concrètement dans une base de code existante : étudiez, recommandez, refactorisez, écrivez des fonctionnalités, déboguez, expédiez les PR, mettez à jour les ADR et planifiez les documents. Se déclenche lorsque l'utilisateur souhaite créer quelque chose de nouveau (« Je veux construire », « Aidez-moi à concevoir », « 我想做 », « 帮我想想这个怎么做 »), ET se déclenche lorsque l'utilisateur invoque /cto sur une base de code existante pour un travail d'architecture, des migrations, des refactors, le débogage ou toute tâche IC senior pour laquelle il souhaite un jugement et une exécution au niveau CTO. Ne déclenchez PAS de questions de codage triviales et ponctuelles pour lesquelles aucun jugement architectural n'est nécessaire.
