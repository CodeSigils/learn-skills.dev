Конвейер сквозных отчетов по поисковым запросам (SQR) по минус-словам — протяните поисковые запросы по всему центру клиентов, подготовьте пакеты классификации, запустите 3 независимых прохода классификации для достижения консенсуса, (опционально) проверьте географические конфликты, напишите проверяемые вкладки согласия, а затем загрузите утвержденные минус-слова PHRASE в общие списки с двухэтапной защитой от мутаций. Включает ветку удаления, позволяющую отменить отрицание ошибок. Автоматический вызов, когда пользователь говорит «запустить конвейер SQR», «классифицировать поисковые запросы», «извлечь поисковые запросы», «загрузить минус-слова», «загрузчик sqr», «удалить минус-слово» или «отменить отрицание ключевого слова».
