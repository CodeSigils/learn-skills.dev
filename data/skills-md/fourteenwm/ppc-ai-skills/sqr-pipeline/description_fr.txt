Pipeline de mots clés négatifs du rapport de requête de recherche (SQR) de bout en bout : extrayez les termes de recherche dans votre MCC, préparez des lots de classification, exécutez 3 passes de classification indépendantes pour obtenir un consensus, (éventuellement) vérifiez les conflits géographiques, rédigez des onglets d'accord révisables, puis téléchargez les négatifs PHRASE approuvés vers des listes partagées avec une sécurité de mutation en deux étapes. Comprend une branche de suppression pour annuler les erreurs. Invocation automatique lorsque l'utilisateur dit "exécuter le pipeline SQR", "classifier les requêtes de recherche", "extraire les termes de recherche", "télécharger les éléments négatifs", "sqr uploader", "supprimer les éléments négatifs" ou "annuler le mot clé".
