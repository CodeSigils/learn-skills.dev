シートベースの Google 広告共有予算の自動化。 Google スプレッドシートのタブに行 (CID、共有予算 ID、金額) を追加して、予算の変更を承認します。毎日の GitHub Actions cron は、campaignBudgets:mutate (金額のみ) を介してプッシュし、行を完了としてマークし、失敗した行に対して 1 つの統合 Slack アラートを送信します。失敗した行は次回の実行を再試行します。 $0 以下の金額は API に到達しません。このスキルは、ユーザーが「共有予算アップデーターの設定」、「シートからの予算変更のプッシュ」、「スケジュール上の共有予算の一括更新」を要求した場合、またはスプレッドシートで承認された予算パイプラインを希望した場合に使用します。
