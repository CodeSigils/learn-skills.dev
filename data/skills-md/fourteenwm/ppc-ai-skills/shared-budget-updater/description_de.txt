Tabellengesteuerte Automatisierung des gemeinsamen Budgets von Google Ads. Genehmigen Sie eine Budgetänderung, indem Sie einer Google Sheet-Registerkarte eine Zeile (CID, gemeinsame Budget-ID, Betrag) hinzufügen. Ein täglicher GitHub Actions-Cron sendet es über CampaignBudgets:mutate (nur Betrag), markiert die Zeile als erledigt und sendet eine konsolidierte Slack-Benachrichtigung für alle fehlgeschlagenen Zeilen. Fehlgeschlagene Zeilen wiederholen den nächsten Lauf; Beträge von 0 $ oder weniger erreichen nie die API. Verwenden Sie diese Fähigkeit, wenn der Benutzer „Gemeinsame Budgetaktualisierung einrichten“, „Budgetänderungen von einem Blatt aus übertragen“, „Gemeinsame Budgets in großen Mengen nach einem Zeitplan aktualisieren“ möchte oder eine von der Tabellenkalkulation genehmigte Budgetpipeline wünscht.
