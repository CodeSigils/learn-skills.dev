Automatización del presupuesto compartido de Google Ads basada en hojas. Apruebe un cambio de presupuesto agregando una fila (CID, ID de presupuesto compartido, monto) a una pestaña de Google Sheet; un cron diario de GitHub Actions lo envía a través de CampaignBudgets:mutate (solo monto), marca la fila como completada y envía una alerta consolidada de Slack para cualquier fila fallida. Las filas fallidas vuelven a intentar la siguiente ejecución; cantidades de $0 o menos nunca llegan a la API. Utilice esta habilidad cuando el usuario solicite "configurar un actualizador de presupuesto compartido", "impulsar cambios de presupuesto desde una hoja", "actualizar presupuestos compartidos en masa según un cronograma" o desee un proceso de presupuesto aprobado por una hoja de cálculo.
