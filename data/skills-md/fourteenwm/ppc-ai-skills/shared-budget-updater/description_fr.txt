Automatisation du budget partagé Google Ads basée sur des feuilles. Approuvez une modification de budget en ajoutant une ligne (CID, ID de budget partagé, montant) à un onglet Google Sheet ; un cron quotidien de GitHub Actions le pousse via CampaignBudgets:mutate (montant uniquement), marque la ligne comme terminée et envoie une alerte Slack consolidée pour toutes les lignes ayant échoué. Les lignes ayant échoué réessayent la prochaine exécution ; les montants de 0 $ ou moins n’atteignent jamais l’API. Utilisez cette compétence lorsque l'utilisateur demande « configurer un programme de mise à jour du budget partagé », « pousser les modifications budgétaires à partir d'une feuille », « mettre à jour en masse les budgets partagés selon un calendrier » ou souhaite un pipeline budgétaire approuvé par une feuille de calcul.
