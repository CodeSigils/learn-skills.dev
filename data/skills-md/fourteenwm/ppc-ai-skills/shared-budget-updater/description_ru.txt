Автоматизация общего бюджета Google Рекламы на основе таблиц. Утвердите изменение бюджета, добавив строку (CID, идентификатор общего бюджета, сумму) на вкладку Google Таблицы; ежедневный хрон GitHub Actions отправляет его через CampaignBudgets:mutate (только сумма), отмечает выполненную строку и отправляет одно консолидированное оповещение Slack о любых неудачных строках. Неудачные строки повторяют попытку при следующем запуске; суммы в размере 0 долларов США или меньше никогда не доходят до API. Используйте этот навык, когда пользователь просит «настроить средство обновления общего бюджета», «издать изменения бюджета из таблицы», «массовое обновление общих бюджетов по расписанию» или хочет использовать бюджетный конвейер, утвержденный в электронной таблице.
