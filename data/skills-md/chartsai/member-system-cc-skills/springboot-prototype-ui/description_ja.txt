ユーザーが「UI のプロトタイプを作成する」、「ページをモックアップする」、「最初にインターフェイスを設計する」、「静的 HTML モックアップを作成する」、「アプリがどのように見えるかを見せて」、「springboot-prototype-ui を実行する」などと言った場合、またはバックエンド コードを設定する前に UI を確認したい場合にトリガーされます。また、ユーザーが「デザインの検証」、「視覚的なプレビューの取得」、「偽のデータ ページの生成」、または「デザインから開始」を要求したときにもトリガーされます。このスキルは、短いインタラクティブなデザイン セッションとして実行され、サーバーやビルド ステップを必要とせずに任意のブラウザで開く自己完結型の HTML プロトタイプを生成します。
