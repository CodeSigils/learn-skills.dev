قم بتطبيق نظام تصميم منتج مقيد ومتأثر بالسويسرية/اليابانية/الاسكندنافية/الألمانية عند إنشاء واجهة المستخدم أو تحسينها في React وNext.js وTypeScript وshadcn/ui. يُستخدم عندما يطلب المستخدم إنشاء أو تحسين أو نقد أو إعادة تصميم أو مراجعة صفحة أو شاشة أو مكون أو نموذج أو جدول أو لوحة معلومات أو تخطيط أو واجهة أمامية أخرى، خاصة في المشروعات التي تستخدم shadcn/ui. لا تستخدمه لمواقع التسويق، أو الصفحات المقصودة، أو الأعمال التي لا تتعلق بواجهة المستخدم، أو طلبات الجماليات الجريئة أو المرحة أو القصوى أو التعبيرية بأي شكل آخر.
