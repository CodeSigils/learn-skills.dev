Utilizzalo ogni volta che lavori in un progetto che utilizza better-update (una dipendenza `@better-update/cli`, un comando `better-update …`, `expo.extra.betterUpdate.projectId` in app.json o un URL manifest `updates.jmango360.dev`), OPPURE quando l'utente chiede di pubblicare/inviare un aggiornamento OTA, organizzare un'implementazione o ripristinare una versione, tagliare una release candidate, promuovere un aggiornamento tra canali, creare un IPA/APK/AAB localmente, gestire archivi di chiavi/certificati di distribuzione/profili di provisioning/chiavi push APN o configurare segreti per ambiente, anche se non pronunciano mai le parole "aggiornamento migliore". Copre ogni comando, ogni flag e il modello di pubblicazione → ramo → canale → routing del dispositivo.
