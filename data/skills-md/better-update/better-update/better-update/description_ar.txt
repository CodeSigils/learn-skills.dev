قم بقيادة واجهة سطر الأوامر للتحديث الأفضل (@better-update/cli، الأمر "better-update") لشحن تحديثات OTA JS/asset، وتشغيل إصدارات iOS/Android الأصلية المحلية، وإدارة مخزن بيانات اعتماد التوقيع المشفر من طرف إلى طرف، وتعيين متغيرات env من جانب الخادم، وتوجيه الإصدارات عبر القنوات/الفروع مع عمليات الطرح المرحلية والتراجع الفوري - لتطبيقات Expo وReact Native وKotlin Multiplatform والتطبيقات الأصلية (أي نوع مشروع عبر أوامر البناء المخصصة). استخدم هذا كلما كنت تعمل في مشروع يستخدم تحديثًا أفضل (تبعية `@better-update/cli`، أو أمر `better-update...`، أو `expo.extra.betterUpdate.projectId` في app.json، أو عنوان URL للبيان `updates.jmango360.dev`)، أو عندما يطلب المستخدم نشر / شحن تحديث عبر الهواء، أو إطلاق تحديث أو التراجع عن إصدار، أو قص مرشح إصدار، الترويج لتحديث بين القنوات، أو إنشاء IPA/APK/AAB محليًا، أو إدارة مخازن المفاتيح / شهادات التوزيع / ملفات تعريف التوفير / مفاتيح دفع APNs، أو تكوين الأسرار الخاصة بالبيئة - حتى لو لم يقولوا أبدًا عبارة "تحديث أفضل". يغطي كل أمر وكل علامة ونموذج توجيه الجهاز للنشر → الفرع → القناة →.
