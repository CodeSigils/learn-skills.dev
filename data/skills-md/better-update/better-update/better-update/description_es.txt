Impulsa la CLI de mejor actualización (@better-update/cli, el comando `better-update`) para enviar actualizaciones OTA JS/activos, ejecutar compilaciones nativas locales de iOS/Android, administrar una bóveda de credenciales de firma cifrada de extremo a extremo, configurar variables de entorno del lado del servidor y enrutar lanzamientos a través de canales/sucursales con implementaciones por etapas y reversión instantánea, para Expo, React Native, Kotlin Multiplatform y aplicaciones nativas (cualquier tipo de proyecto). mediante comandos de compilación personalizados). Utilice esto siempre que esté trabajando en un proyecto que utilice una mejor actualización (una dependencia `@better-update/cli`, un comando `better-update...`, `expo.extra.betterUpdate.projectId` en app.json, o una URL de manifiesto `updates.jmango360.dev`), O cuando el usuario solicite publicar/enviar una actualización OTA, preparar una implementación o revertir una versión, eliminar una versión candidata, promover una actualización entre canales, cree un IPA/APK/AAB localmente, administre almacenes de claves/certificados de distribución/perfiles de aprovisionamiento/claves de inserción de APN, o configure secretos por entorno, incluso si nunca dicen las palabras "mejor actualización". Cubre cada comando, cada indicador y el modelo de enrutamiento de publicación → rama → canal → dispositivo.
