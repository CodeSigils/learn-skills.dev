قم بإنشاء مجموعات شرائح HTML بنمط العرض التقديمي الأكاديمي وتقارير المتصفح من ملفات PDF أو نص منظم أو Markdown أو ملخصات ورقية أو مخططات تفصيلية أو ملاحظات بحثية. استخدمه عندما يريد المستخدم تحويل ملف PDF للورقة العلمية مباشرة إلى تقرير HTML تفاعلي، أو عرض تقديمي على الويب قابل للنقر، أو مجموعة متصفح قابلة للمشاركة، أو مخرجات HTML تشبه PPT مع الأشكال والرؤى المنظمة وصفحات الأقسام ومخرجات دليل المجموعة غير المتصلة. في مجموعة Aut_Sci_Write، اختر هذه المهارة عندما يريد المستخدم إخراج HTML/الويب؛ اختر sci-ppt عندما يحتاجون بشكل صريح إلى ملف .pptx.
