Genere presentaciones de diapositivas HTML con estilo académico e informes de navegador a partir de archivos PDF, texto estructurado, Markdown, resúmenes de artículos, esquemas o notas de investigación. Úselo siempre que el usuario quiera convertir un PDF de un artículo científico directamente en un informe HTML interactivo, una presentación web en la que se puede hacer clic, una plataforma de navegador que se puede compartir o una salida HTML similar a PPT con figuras, información estructurada, páginas de sección y salida de directorio de plataforma sin conexión. En la suite Aut_Sci_Write, elija esta habilidad cuando el usuario desee salida HTML/web; elija sci-ppt cuando necesiten explícitamente un archivo .pptx.
