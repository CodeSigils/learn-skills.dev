Generieren Sie HTML-Foliendecks und Browserberichte im akademischen Präsentationsstil aus PDFs, strukturiertem Text, Markdown, Papierzusammenfassungen, Gliederungen oder Forschungsnotizen. Verwenden Sie es immer dann, wenn der Benutzer eine wissenschaftliche Arbeit im PDF-Format direkt in einen interaktiven HTML-Bericht, eine anklickbare Webpräsentation, ein gemeinsam nutzbares Browser-Deck oder eine PPT-ähnliche HTML-Ausgabe mit Abbildungen, strukturierten Erkenntnissen, Abschnittsseiten und einer Offline-Deck-Verzeichnisausgabe umwandeln möchte. Wählen Sie in der Aut_Sci_Write-Suite diese Fähigkeit aus, wenn der Benutzer eine HTML-/Webausgabe wünscht; Wählen Sie sci-ppt, wenn sie ausdrücklich eine PPTX-Datei benötigen.
