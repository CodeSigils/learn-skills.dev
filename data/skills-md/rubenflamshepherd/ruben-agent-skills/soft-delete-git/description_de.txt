Löschen Sie einen zusammengeführten Git-Zweig sicher vorläufig, indem Sie zum Standardzweig wechseln, „Latest“ abrufen und „git branch -d“ ausführen. Verwenden Sie diese Option, wenn der Benutzer nach dem Zusammenführen einen lokalen Zweig bereinigen, entfernen oder löschen möchte oder sagt: „Diesen Zweig vorläufig löschen“ / „meinen Zweig löschen“. Eskaliert an den Benutzer, anstatt das Löschen zu erzwingen, wenn der Zweig nicht zusammengeführt wird, außer Squash-zusammengeführte PRs, die über „gh“ überprüft wurden.
