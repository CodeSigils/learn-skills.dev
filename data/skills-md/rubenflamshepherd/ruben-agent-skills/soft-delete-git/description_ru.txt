Безопасно мягко удалите объединенную ветку Git, переключившись на ветку по умолчанию, вытащив последнюю версию и запустив `git Branch -d`. Используйте, когда пользователь хочет очистить, удалить или удалить локальную ветку после слияния или говорит «мягко удалить эту ветку» / «удалить мою ветку». Передается пользователю вместо принудительного удаления, если ветка не объединена, за исключением объединенных PR, проверенных через `gh`.
