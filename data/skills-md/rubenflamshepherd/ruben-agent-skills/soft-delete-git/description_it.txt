Elimina in modo sicuro un ramo Git unito passando al ramo predefinito, estraendo l'ultimo ed eseguendo `git branch -d`. Da utilizzare quando l'utente desidera ripulire, rimuovere o eliminare un ramo locale dopo la fusione o dice "elimina gradualmente questo ramo"/"elimina il mio ramo". Viene inoltrato all'utente invece di forzare l'eliminazione se il ramo non è unito, ad eccezione dei PR uniti tramite squash verificati tramite "gh".
