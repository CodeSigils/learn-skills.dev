Supprimez de manière logicielle en toute sécurité une branche Git fusionnée en basculant vers la branche par défaut, en extrayant la dernière version et en exécutant « git branch -d ». À utiliser lorsque l'utilisateur souhaite nettoyer, supprimer ou supprimer une branche locale après la fusion, ou dit "supprimer cette branche" / "supprimer ma branche". Transmis à l'utilisateur au lieu de forcer la suppression si la branche n'est pas fusionnée, à l'exception des PR fusionnés par écrasement vérifiés via « gh ».
