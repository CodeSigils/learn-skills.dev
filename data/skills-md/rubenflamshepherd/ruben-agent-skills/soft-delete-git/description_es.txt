Elimine de forma segura una rama de Git fusionada cambiando a la rama predeterminada, extrayendo la última versión y ejecutando `git branch -d`. Úselo cuando el usuario quiera limpiar, eliminar o eliminar una rama local después de fusionarla, o diga "eliminar temporalmente esta rama"/"eliminar mi rama". Se escala al usuario en lugar de forzar la eliminación si la rama no está fusionada, excepto los PR fusionados por squash verificados mediante `gh`.
