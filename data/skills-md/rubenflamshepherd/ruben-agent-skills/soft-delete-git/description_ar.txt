يمكنك الحذف الآمن لفرع Git المدمج عن طريق التبديل إلى الفرع الافتراضي، وسحب الأحدث، وتشغيل git Branch -d. يُستخدم عندما يريد المستخدم تنظيف فرع محلي أو إزالته أو حذفه بعد الدمج، أو عندما يقول "حذف هذا الفرع بشكل ناعم" / "احذف فرعي". يتم التصعيد إلى المستخدم بدلاً من فرض الحذف إذا تم إلغاء دمج الفرع، باستثناء العلاقات العامة المدمجة في الاسكواش والتي تم التحقق منها عبر `gh`.
