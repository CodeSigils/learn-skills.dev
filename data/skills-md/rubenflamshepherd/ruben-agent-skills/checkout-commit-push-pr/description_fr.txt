Exécutez le workflow git complet de bout en bout sans invite : créez une branche datée à partir de la branche par défaut (si nécessaire), effectuez et validez les modifications avec un message descriptif, poussez vers l'origine, ouvrez un PR (en respectant tout modèle de PR de dépôt) et surveillez les vérifications CI jusqu'à ce qu'elles réussissent. À utiliser lorsque l'utilisateur demande de valider et d'ouvrir un PR, d'envoyer une modification, de pousser et de PR, ou d'exécuter le flux checkout-commit-push-pr.
