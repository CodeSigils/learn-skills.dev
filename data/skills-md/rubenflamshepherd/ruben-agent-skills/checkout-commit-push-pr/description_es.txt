Ejecute el flujo de trabajo completo de Git de un extremo a otro sin que se le solicite: cree una rama fechada a partir de la rama predeterminada (si es necesario), prepare y confirme los cambios con un mensaje descriptivo, envíe al origen, abra un PR (respetando cualquier plantilla de PR de repositorio) y supervise las comprobaciones de CI hasta que se aprueben. Úselo cuando el usuario solicite confirmar y abrir un PR, enviar un cambio, enviar un PR, o ejecutar el flujo checkout-commit-push-pr.
