Esegui l'intero flusso di lavoro git end-to-end senza chiedere conferma: crea un ramo con data dal ramo predefinito (se necessario), metti in stage e conferma le modifiche con un messaggio descrittivo, invia all'origine, apri un PR (onorando qualsiasi modello PR di repository) e monitora i controlli CI finché non vengono superati. Da utilizzare quando l'utente chiede di impegnarsi e aprire un PR, inviare una modifica, inviare e PR o eseguire il flusso checkout-commit-push-pr.
