Führen Sie den vollständigen Git-Workflow durchgängig ohne Aufforderung aus: Erstellen Sie einen datierten Zweig vom Standardzweig (falls erforderlich), stellen Sie Änderungen mit einer beschreibenden Nachricht bereit und schreiben Sie sie fest, übertragen Sie sie an den Ursprung, öffnen Sie eine PR (unter Berücksichtigung aller Repo-PR-Vorlagen) und überwachen Sie die CI-Prüfungen, bis sie erfolgreich sind. Verwenden Sie diese Option, wenn der Benutzer einen Commit und das Öffnen einer PR, das Versenden einer Änderung, Push und PR oder die Ausführung des Ablaufs „checkout-commit-push-pr“ anfordert.
