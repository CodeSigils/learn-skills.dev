قم بتشغيل سير عمل git الكامل من البداية إلى النهاية دون مطالبة: أنشئ فرعًا مؤرخًا من الفرع الافتراضي (إذا لزم الأمر)، وقم بتنفيذ التغييرات وتنفيذها برسالة وصفية، وادفع إلى الأصل، وافتح PR (تكريم أي قالب repo PR)، ومراقبة فحوصات CI حتى يتم اجتيازها. يُستخدم عندما يطلب المستخدم الالتزام بفتح PR، أو إرسال تغيير، أو الدفع والعلاقات العامة، أو تشغيل تدفق checkout-commit-push-pr.
