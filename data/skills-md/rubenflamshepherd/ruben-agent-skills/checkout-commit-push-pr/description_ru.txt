Запустите полный рабочий процесс git от начала до конца без подсказок: создайте датированную ветку на основе ветки по умолчанию (при необходимости), подготовьте и зафиксируйте изменения с описательным сообщением, отправьте их в источник, откройте PR (с учетом любого шаблона PR репозитория) и отслеживайте проверки CI, пока они не пройдут. Используйте, когда пользователь просит зафиксировать и открыть PR, отправить изменение, отправить и PR или запустить поток checkout-commit-push-pr.
