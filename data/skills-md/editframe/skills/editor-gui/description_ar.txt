قم ببناء واجهات تحرير الفيديو باستخدام مكونات الويب الخاصة بواجهة المستخدم الرسومية الخاصة بـ Editframe. قم بتجميع عناصر التحكم في المخطط الزمني والجهاز وشريط الأفلام والمعاينة والتشغيل مثل طوب الليغو. يُستخدم عند إنشاء برامج تحرير الفيديو، أو أدوات التحرير، أو عندما يذكر المستخدم المخطط الزمني، أو شريط التمرير، أو المعاينة، أو عناصر التحكم في التشغيل، أو مقابض القطع، أو يريد إنشاء واجهات مستخدم للتحرير.
