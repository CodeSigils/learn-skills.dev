Cree interfaces de edición de video utilizando los componentes web GUI de Editframe. Reúna controles de línea de tiempo, depurador, tira de película, vista previa y reproducción como si fueran ladrillos de Lego. Úselo al crear editores de video, herramientas de edición o cuando el usuario mencione la línea de tiempo, el depurador, la vista previa, los controles de reproducción, los controles de recorte o quiera crear interfaces de usuario de edición.
