Utilisez cette compétence chaque fois qu'un agent LLM a besoin de rechercher, parcourir ou télécharger des modèles 3D à partir de Poly Pizza (poly.pizza) à l'aide de son API REST. Se déclenche sur toute tâche impliquant : trouver des modèles 3D low-poly gratuits, rechercher dans le catalogue Poly Pizza, récupérer des métadonnées de modèles ou des URL de téléchargement, récupérer des modèles populaires ou télécharger des fichiers .glb depuis Poly Pizza. Utilisez cette compétence de manière proactive chaque fois que l'agent a besoin d'obtenir des ressources 3D par programmation, même si l'utilisateur dit simplement « trouvez-moi un modèle 3D de X » sans mentionner Poly Pizza par son nom.
