Используйте этот навык всякий раз, когда агенту LLM необходимо найти, просмотреть или загрузить 3D-модели из Poly Pizza (poly.pizza), используя их REST API. Запускается при выполнении любой задачи, связанной с поиском бесплатных низкополигональных 3D-моделей, поиском в каталоге Poly Pizza, получением метаданных модели или URL-адресами загрузки, поиском популярных моделей или загрузкой файлов .glb из Poly Pizza. Используйте этот навык заранее, когда агенту необходимо получить 3D-ресурсы программным способом, даже если пользователь просто говорит «найдите мне 3D-модель X», не упоминая Poly Pizza по имени.
