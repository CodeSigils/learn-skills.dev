Utilizza questa competenza ogni volta che un agente LLM deve cercare, sfogliare o scaricare modelli 3D da Poly Pizza (poly.pizza) utilizzando la propria API REST. Si attiva qualsiasi attività che coinvolga: ricerca di modelli 3D low-poly gratuiti, ricerca nel catalogo Poly Pizza, recupero di metadati del modello o download di URL, recupero di modelli popolari o download di file .glb da Poly Pizza. Utilizza questa capacità in modo proattivo ogni volta che l'agente ha bisogno di ottenere risorse 3D in modo programmatico, anche se l'utente dice semplicemente "trovami un modello 3D di X" senza menzionare Poly Pizza per nome.
