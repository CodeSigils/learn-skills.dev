استخدم هذه المهارة عندما يحتاج وكيل LLM إلى البحث عن نماذج ثلاثية الأبعاد أو تصفحها أو تنزيلها من Poly Pizza (poly.pizza) باستخدام REST API الخاص به. تشغيل أي مهمة تتضمن: العثور على نماذج ثلاثية الأبعاد مجانية منخفضة التضليع، أو البحث في كتالوج Poly Pizza، أو جلب بيانات تعريف النموذج أو تنزيل عناوين URL، أو استرداد النماذج الشائعة، أو تنزيل ملفات ‎.glb من Poly Pizza. استخدم هذه المهارة بشكل استباقي عندما يحتاج الوكيل إلى الحصول على أصول ثلاثية الأبعاد برمجيًا، حتى لو قال المستخدم فقط "اعثر لي على نموذج ثلاثي الأبعاد لـ X" دون ذكر Poly Pizza بالاسم.
