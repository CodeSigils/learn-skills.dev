LLM エージェントが REST API を使用して Poly Pizza (poly.pizza) から 3D モデルを検索、参照、またはダウンロードする必要がある場合は、このスキルを使用します。無料のローポリ 3D モデルの検索、Poly Pizza カタログの検索、モデルのメタデータまたはダウンロード URL の取得、人気のあるモデルの取得、Poly Pizza からの .glb ファイルのダウンロードなどのタスクをトリガーします。ユーザーが Poly Pizza の名前を挙げずに「X の 3D モデルを探して」と言っただけの場合でも、エージェントがプログラムで 3D アセットを取得する必要があるときは常に、このスキルを積極的に使用してください。
