Utilice esta habilidad siempre que un agente de LLM necesite buscar, explorar o descargar modelos 3D de Poly Pizza (poly.pizza) utilizando su API REST. Activa cualquier tarea que implique: encontrar modelos 3D gratuitos de baja poli, buscar en el catálogo de Poly Pizza, obtener metadatos de modelos o descargar URL, recuperar modelos populares o descargar archivos .glb de Poly Pizza. Utilice esta habilidad de forma proactiva siempre que el agente necesite obtener activos 3D mediante programación, incluso si el usuario simplemente dice "búsqueme un modelo 3D de X" sin mencionar Poly Pizza por su nombre.
