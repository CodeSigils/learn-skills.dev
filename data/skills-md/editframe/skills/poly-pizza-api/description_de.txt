Verwenden Sie diese Fähigkeit immer dann, wenn ein LLM-Agent mithilfe seiner REST-API 3D-Modelle von Poly Pizza (poly.pizza) suchen, durchsuchen oder herunterladen muss. Wird bei jeder Aufgabe ausgelöst, die Folgendes umfasst: Finden kostenloser Low-Poly-3D-Modelle, Durchsuchen des Poly Pizza-Katalogs, Abrufen von Modellmetadaten oder Download-URLs, Abrufen beliebter Modelle oder Herunterladen von GLB-Dateien von Poly Pizza. Nutzen Sie diese Fähigkeit proaktiv, wenn der Agent programmgesteuert 3D-Assets abrufen muss, auch wenn der Benutzer nur sagt: „Such mir ein 3D-Modell von X“, ohne Poly Pizza namentlich zu erwähnen.
