الحفاظ على نظام المهارات كمستندات الخاص بـ Editframe وتأليفه. يغطي بنية الملف، ومخططات الواجهة، واصطلاحات العرض (عروض HTML المباشرة، ووسائل الشرح، وبيانات تعريف واجهة برمجة التطبيقات)، وخط أنابيب الإنشاء، وسير عمل الإنشاء/الدفع. يُستخدم عند إنشاء أو تحرير ملفات المهارات، أو الوثائق المرجعية، أو المواد الأمامية، أو كتل html المباشرة، أو بيانات تعريف واجهة برمجة التطبيقات، أو العمل على عارض ويب المهارات.
