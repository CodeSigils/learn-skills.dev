Верстка паблик аккаунта | Уценка в HTML | Набор тем | Стили абзацев — инструмент набора текста одним щелчком мыши для общедоступных учетных записей, который преобразует документы Markdown в HTML, который можно вставить в серверную часть WeChat, поддерживает несколько тем, различные размеры шрифта и переключение стилей абзацев, WYSIWYG. Предназначено для редакторов общедоступных источников, независимых авторов и наборщиков. Триггерные слова: «набор текста», «макет», «украсить», «формат», «размер шрифта», «стиль абзаца», «изменить тему набора текста», «изменить макет», «конвертировать в HTML», «улучшить внешний вид», «отрегулировать формат». Для переключения предустановленных пакетов/пакетов брендов/полных цветовых схем темы используйте aws-wechat-article-assets; для многоэтапного рабочего процесса (написание+редактирование+набор текста+сопоставление изображений+публикация) используйте aws‑wechat‑article‑main.
