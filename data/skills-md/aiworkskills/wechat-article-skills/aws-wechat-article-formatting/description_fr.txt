Composition de comptes publics | Démarquage au format HTML | Thèmes de composition | Styles de paragraphe — Un outil de composition en un clic pour les comptes publics, convertissant les manuscrits Markdown en HTML pouvant être collés dans le backend WeChat, avec plusieurs thèmes, tailles de police et commutateurs de style de paragraphe, WYSIWYG. Destiné aux éditeurs de comptes publics, aux auteurs indépendants et au personnel de composition. Mots déclencheurs : « composition », « mise en page », « embellir », « format », « taille de police », « style de paragraphe », « modifier le thème de composition », « modifier la mise en page », « convertir en HTML », « améliorer l'apparence », « ajuster le format ». Pour modifier les packs prédéfinis/packs de marque/schémas de couleurs de thème complets, utilisez aws‑wechat‑article‑assets ; pour les flux de travail en plusieurs étapes (écriture+révision+composition+ajout d'images+publication), utilisez aws‑wechat‑article‑main.
