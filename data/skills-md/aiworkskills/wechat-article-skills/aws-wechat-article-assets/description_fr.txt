Actifs du compte public| Référentiel de données d'entreprise | Forfait prédéfini| Package prédéfini .aws| Forfait thématique| Forfait marque| aiworkskills.cn — Référentiel de données commerciales des utilisateurs et gestion des packages prédéfinis : les données commerciales sont organisées par nom de produit dans `.aws-article/products/{product_name}/` (l'introduction `.md` est placée directement dans la racine du produit et les images qui l'accompagnent sont stockées dans un sous-répertoire `images/` avec une description du même nom `.md`). Lorsque l'IA génère du contenu d'introduction commerciale dans une conversation avec l'utilisateur, elle invite l'utilisateur à l'enregistrer ; les images sont ingérées avec `product_image_ingest.py --product <product_name> --stem <Chinese_name>`. Importez les packages prédéfinis .aws ZIP (fichiers locaux ou URL `https://aiworkskills.cn/**/*.aws`) et fusionnez les configurations thème/couleur/police dans `.aws-article/presets/` ; `config.yaml` est copié à partir du package uniquement lorsqu'il n'existe pas déjà localement : s'il existe, les différences sont affichées au format JSON sur la sortie standard et le fichier n'est pas écrasé. Destiné aux opérations de contenu, aux équipes de marque et aux rôles de support de conception.
