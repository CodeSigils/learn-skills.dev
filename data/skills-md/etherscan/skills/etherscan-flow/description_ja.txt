Etherscan API V2 を介してオンチェーンのマネー フローをトレースし、単一の Etherscan Flow Case JSON ファイル (ノード + エッジ) を書き込みます。入力: tx ハッシュ、ウォレット/契約アドレス、ビジネス/エンティティ スコープ (「ENS DAO をビジネスとして表示」)、貼り付けられたメモ/下書き、またはライブで検証されたアドレスとフロー クレームを含むユーザーが入力したリンク (要点、ツイート/X、記事)。 2 つのモード: TX/住所調査のための厳密な追跡と、収入/支出/財務に関する質問のためのビジネス/エンティティ プロファイル。ユーザーが「この TX を追跡する」、「このトランザクションを視覚化する」、「資金を追跡する」、「この詐欺のケースを作成する」、「この DAO の収入と支出を表示する」と言う場合、または 0x ハッシュ/アドレスを貼り付ける場合に使用します。出力は JSON のみです。すべてのアドレス、金額、txhash は、決して発明されたものではなく、ライブ API 応答から取得されます。デフォルトではイーサリアム、他の EVM チェーンがサポートされます。セキュリティ ケースでは、証拠に裏付けられたインシデント メカニズム、信頼性、損失、代替案も再構築されます。トランスポートの優先順位: 公式の etherscan CLI、Etherscan MCP、インライン apikey=、次に他の HTTP キー ソース。
