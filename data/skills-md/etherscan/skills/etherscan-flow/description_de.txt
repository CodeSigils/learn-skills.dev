Verfolgen Sie den Geldfluss in der Kette über die Etherscan API V2 und schreiben Sie eine einzelne Etherscan Flow Case JSON-Datei (Knoten + Kanten). Eingabe: ein Sende-Hash, eine Wallet-/Vertragsadresse, ein Geschäfts-/Entitätsbereich („ENS DAO als Unternehmen anzeigen“), eingefügte Notizen/Entwürfe oder ein vom Benutzer eingegebener Link (Gist, Tweet/X, Artikel) mit live überprüften Adressen und Flussansprüchen. Zwei Modi: strikte Verfolgung für Sende-/Adressuntersuchungen und Geschäfts-/Entitätsprofil für Einnahmen-/Ausgaben-/Finanzfragen. Wird verwendet, wenn der Benutzer sagt: „Diese Sendung verfolgen“, „Diese Transaktion visualisieren“, „dem Geld folgen“, „einen Fall für diesen Betrug erstellen“, „Einnahmen und Ausgaben dieses DAO anzeigen“ oder einen 0x-Hash/eine 0x-Adresse einfügt. Die Ausgabe erfolgt nur in JSON; Jede Adresse, jeder Betrag und jeder Txhash stammt aus einer Live-API-Antwort, die nie erfunden wurde. Ethereum standardmäßig, andere EVM-Ketten werden unterstützt. Sicherheitsfälle rekonstruieren auch einen evidenzbasierten Vorfallmechanismus, Vertrauen, Verluste und Alternativen. Transportpriorität: offizielle Etherscan-CLI, Etherscan-MCP, inline apikey=, dann andere HTTP-Schlüsselquellen.
