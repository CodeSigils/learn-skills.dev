Отслеживайте денежный поток в цепочке с помощью Etherscan API V2 и записывайте один JSON-файл Etherscan Flow Case (узлы + ребра). Входные данные: хеш передачи, адрес кошелька/контракта, сфера деятельности компании/субъекта («показать ENS DAO как бизнес»), вставленные примечания/черновик или введенная пользователем ссылка (суть, твит/X, статья) с адресами и утверждениями потока, проверенными в реальном времени. Два режима: строгое отслеживание для проверки отправок/адресов и профиль компании/организации для вопросов о доходах/расходах/казначействе. Используйте, когда пользователь говорит «отследить эту транзакцию», «визуализировать эту транзакцию», «следить за деньгами», «составить обоснование для этого мошенничества», «показать доходы и расходы этого DAO» или вставить хэш/адрес 0x. Вывод осуществляется только в формате JSON; каждый адрес, сумма и txhash исходят из живого ответа API, который никогда не придумывался. Ethereum по умолчанию, поддерживаются другие цепочки EVM. Дела, связанные с безопасностью, также реконструируют механизм инцидентов, подтвержденный фактами, доверие, потери и альтернативы. Приоритет транспорта: официальный CLI etherscan, Etherscan MCP, встроенный apikey=, затем другие источники ключей HTTP.
