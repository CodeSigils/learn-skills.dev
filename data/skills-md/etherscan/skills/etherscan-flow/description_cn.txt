通过 Etherscan API V2 跟踪链上资金流并编写单个 Etherscan Flow Case JSON 文件（节点 + 边）。输入：交易哈希、钱包/合约地址、企业/实体范围（“将 ENS DAO 显示为企业”）、粘贴的注释/草稿或用户输入的链接（要点、tweet/X、文章），其中包含实时验证的地址和流量声明。两种模式：严格追踪交易/地址调查，以及针对收入/支出/财务问题的业务/实体概况。当用户说“追踪这笔交易”、“可视化这笔交易”、“跟踪资金”、“为这个骗局建立一个案例”、“显示这个 DAO 的收入和支出”或粘贴 0x 哈希值/地址时使用。输出仅为 JSON；每个地址、金额和 txhash 都来自实时 API 响应，从未被发明。默认以太坊，支持其他EVM链。安全案例还重建了有证据支持的事件机制、信心、损失和替代方案。传输优先级：官方 etherscan CLI、Etherscan MCP、内联 apikey=，然后是其他 HTTP 密钥源。
