透過 Etherscan API V2 追蹤鏈上資金流並編寫單一 Etherscan Flow Case JSON 檔案（節點 + 邊）。輸入：交易雜湊、錢包/合約地址、企業/實體範圍（「將 ENS DAO 顯示為企業」）、貼上的註釋/草稿或用戶輸入的連結（要點、tweet/X、文章），其中包含即時驗證的地址和流量聲明。兩種模式：嚴格追蹤交易/地址調查，以及針對收入/支出/財務問題的業務/實體概況。當用戶說「追蹤這筆交易」、「視覺化這筆交易」、「追蹤資金」、「為這個騙局建立一個案例」、「顯示這個 DAO 的收入和支出」或貼上 0x 哈希值/地址時使用。輸出僅為 JSON；每個位址、金額和 txhash 都來自即時 API 回應，從未被發明。預設以太坊，支援其他EVM鏈。安全案例也重建了有證據支持的事件機制、信心、損失和替代方案。傳輸優先：官方 etherscan CLI、Etherscan MCP、內聯 apikey=，然後是其他 HTTP 金鑰來源。
