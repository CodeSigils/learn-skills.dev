تتبع تدفق الأموال على السلسلة عبر Etherscan API V2 واكتب ملف Etherscan Flow Case JSON واحد (العقد + الحواف). الإدخال: تجزئة tx، أو عنوان محفظة/عقد، أو نطاق عمل/كيان ("إظهار ENS DAO كعمل تجاري")، أو ملاحظات/مسودة ملصقة، أو رابط يكتبه المستخدم (Gist، tweet/X، مقالة) مع العناوين ومطالبات التدفق التي تم التحقق منها مباشرة. وضعان: تتبع صارم للتحقيق في الإرسال/العنوان، وملف تعريف الأعمال/الكيان للأسئلة المتعلقة بالدخل/الإنفاق/الخزانة. يُستخدم عندما يقول المستخدم "تتبع هذا الإرسال"، أو "تصور هذه المعاملة"، أو "اتبع الأموال"، أو "أنشئ حالة لعملية الاحتيال هذه"، أو "أظهر دخل DAO وإنفاقه"، أو يلصق تجزئة/عنوان 0x. الإخراج هو JSON فقط؛ يأتي كل عنوان ومبلغ وtxhash من استجابة واجهة برمجة التطبيقات المباشرة، والتي لم يتم اختراعها مطلقًا. بشكل افتراضي، يتم دعم سلاسل EVM الأخرى. تقوم القضايا الأمنية أيضًا بإعادة بناء آلية الحادث المدعومة بالأدلة والثقة والخسائر والبدائل. أولوية النقل: etherscan CLI الرسمي، وEtherscan MCP، وinline apikey=، ثم مصادر مفاتيح HTTP الأخرى.
