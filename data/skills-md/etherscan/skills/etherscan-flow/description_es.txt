Rastree el flujo de dinero en cadena a través de Etherscan API V2 y escriba un único archivo JSON de Etherscan Flow Case (nodos + bordes). Entrada: un hash de tx, una dirección de billetera/contrato, un alcance de empresa/entidad ("mostrar ENS DAO como una empresa"), notas/borrador pegados o un enlace escrito por el usuario (esencia, tweet/X, artículo) con direcciones y reclamos de flujo verificados en vivo. Dos modos: seguimiento estricto para investigación de tx/dirección y perfil de empresa/entidad para preguntas de ingresos/gastos/tesorería. Úselo cuando el usuario diga "rastrear este envío", "visualizar esta transacción", "seguir el dinero", "crear un caso para esta estafa", "mostrar los ingresos y gastos de este DAO" o pegue un hash/dirección 0x. La salida es sólo JSON; cada dirección, cantidad y txhash provienen de una respuesta API en vivo, nunca inventada. Ethereum por defecto, se admiten otras cadenas EVM. Los casos de seguridad también reconstruyen un mecanismo de incidentes respaldado por evidencia, confianza, pérdidas y alternativas. Prioridad de transporte: CLI oficial de etherscan, Etherscan MCP, apikey= en línea y luego otras fuentes de claves HTTP.
