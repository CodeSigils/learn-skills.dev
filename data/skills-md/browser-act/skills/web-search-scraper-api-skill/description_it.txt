Questa competenza aiuta gli utenti a estrarre automaticamente il contenuto Markdown completo da qualsiasi sito Web tramite l'API BrowserAct Web Search Scraper. L'agente dovrebbe applicare in modo proattivo questa capacità quando gli utenti esprimono esigenze come estrarre il markdown completo da un sito Web specifico, raschiare il contenuto di un collegamento a un articolo, ottenere il testo da un URL di destinazione, convertire una pagina Web in formato markdown, recuperare il contenuto principale di un post di blog, estrarre dati da una determinata pagina Web, analizzare l'html di un sito Web in markdown, scaricare il testo leggibile da un articolo di notizie, ottenere il contenuto di una pagina tutorial, estrarre tutto il testo di markdown da qualsiasi URL http o https, raschiare la documentazione da un collegamento Web o prendi il testo di una singola pagina Web.
