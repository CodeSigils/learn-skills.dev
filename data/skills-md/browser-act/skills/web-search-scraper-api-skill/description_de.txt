Dieser Skill hilft Benutzern, über die BrowserAct Web Search Scraper API automatisch vollständige Markdown-Inhalte von jeder Website zu extrahieren. Der Agent sollte diese Fähigkeit proaktiv anwenden, wenn Benutzer Bedürfnisse äußern, wie z. B. vollständiges Markdown von einer bestimmten Website extrahieren, den Inhalt eines Artikellinks extrahieren, den Text von einer Ziel-URL abrufen, eine Webseite in das Markdown-Format konvertieren, den Hauptinhalt eines Blog-Beitrags abrufen, Daten von einer bestimmten Webseite extrahieren, den HTML-Code einer Website in Markdown analysieren, den lesbaren Text aus einem Nachrichtenartikel herunterladen, den Inhalt einer Tutorial-Seite abrufen, den gesamten Markdown-Text von einer beliebigen http- oder https-URL extrahieren, scrapen Sie können die Dokumentation über einen Weblink abrufen oder den Text einer einzelnen Webseite abrufen.
