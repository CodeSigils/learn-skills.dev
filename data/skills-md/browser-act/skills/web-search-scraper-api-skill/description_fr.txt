Cette compétence aide les utilisateurs à extraire automatiquement le contenu Markdown complet de n'importe quel site Web via l'API BrowserAct Web Search Scraper. L'agent doit appliquer cette compétence de manière proactive lorsque les utilisateurs expriment des besoins tels qu'extraire une démarque complète d'un site Web spécifique, extraire le contenu d'un lien d'article, obtenir le texte d'une URL cible, convertir une page Web au format markdown, récupérer le contenu principal d'un article de blog, extraire des données d'une page Web donnée, analyser le code HTML d'un site Web en markdown, télécharger le texte lisible d'un article d'actualité, obtenir le contenu d'une page de didacticiel, extraire tout le texte de démarque de n'importe quelle URL http ou https, gratter la documentation. à partir d'un lien Web ou récupérez le texte d'une seule page Web.
