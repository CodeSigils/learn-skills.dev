Этот навык помогает пользователям автоматически извлекать полный контент Markdown с любого веб-сайта через API-интерфейс BrowserAct Web Search Scraper. Агент должен активно применять этот навык, когда пользователи выражают такие потребности, как извлечение полной уценки с определенного веб-сайта, очистка содержимого ссылки на статью, получение текста из целевого URL-адреса, преобразование веб-страницы в формат уценки, получение основного содержимого сообщения в блоге, извлечение данных с заданной веб-страницы, анализ html веб-сайта в уценку, загрузка читаемого текста из новостной статьи, получение содержимого учебной страницы, извлечение всего текста уценки из любого URL-адреса http или https, очистка документации. по веб-ссылке или получить текст одной веб-страницы.
