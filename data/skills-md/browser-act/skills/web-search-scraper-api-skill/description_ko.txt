이 기술을 사용하면 사용자는 BrowserAct Web Search Scraper API를 통해 모든 웹사이트에서 전체 Markdown 콘텐츠를 자동으로 추출할 수 있습니다. 에이전트는 사용자가 특정 웹사이트에서 전체 마크다운 추출, 기사 링크 콘텐츠 스크랩, 대상 URL에서 텍스트 가져오기, 웹페이지를 마크다운 형식으로 변환, 블로그 게시물의 주요 콘텐츠 가져오기, 지정된 웹페이지에서 데이터 추출, 웹사이트 HTML을 마크다운으로 구문 분석, 뉴스 기사에서 읽을 수 있는 텍스트 다운로드, 튜토리얼 페이지 콘텐츠 가져오기, http 또는 https URL에서 모든 마크다운 텍스트 추출, 웹에서 문서 스크랩과 같은 요구 사항을 표현할 때 이 기술을 사전에 적용해야 합니다. 링크를 걸거나 단일 웹페이지의 텍스트를 가져옵니다.
