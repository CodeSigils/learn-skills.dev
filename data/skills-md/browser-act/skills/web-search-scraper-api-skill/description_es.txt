Esta habilidad ayuda a los usuarios a extraer automáticamente el contenido completo de Markdown de cualquier sitio web a través de la API BrowserAct Web Search Scraper. El Agente debe aplicar esta habilidad de manera proactiva cuando los usuarios expresan necesidades como extraer el descuento completo de un sitio web específico, extraer el contenido de un enlace de artículo, obtener el texto de una URL de destino, convertir una página web al formato de descuento, obtener el contenido principal de una publicación de blog, extraer datos de una página web determinada, analizar el html de un sitio web en descuento, descargar el texto legible de un artículo de noticias, obtener el contenido de una página de tutorial, extraer todo el texto de descuento de cualquier URL http o https, extraer documentación de un enlace web o tomar el texto de una sola página web.
