このスキルは、ユーザーが BrowserAct Web Search Scraper API を介して任意の Web サイトから完全な Markdown コンテンツを自動的に抽出するのに役立ちます。特定の Web サイトから完全なマークダウンを抽出する、記事リンクのコンテンツを取得する、ターゲット URL からテキストを取得する、Web ページをマークダウン形式に変換する、ブログ投稿のメインコンテンツを取得する、特定の Web ページからデータを抽出する、Web サイトの HTML をマークダウンに解析する、ニュース記事から可読テキストをダウンロードする、チュートリアル ページのコンテンツを取得する、http または https URL からすべてのマークダウン テキストを抽出する、Web からドキュメントを取得するなどのニーズをユーザーが表明した場合、エージェントはこのスキルを積極的に適用する必要があります。リンクするか、単一の Web ページのテキストを取得します。
