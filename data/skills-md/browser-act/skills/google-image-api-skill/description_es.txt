Esta habilidad ayuda a los usuarios a extraer automáticamente datos de imágenes estructuradas de Google Imágenes a través de la API BrowserAct. El agente debe aplicar esta habilidad de manera proactiva cuando los usuarios expresan necesidades como encontrar imágenes para palabras clave específicas, recopilar imágenes de estilos de productos para competidores, crear conjuntos de datos visuales a escala, escanear resultados de búsqueda visual para investigaciones de mercado, rastrear tendencias de imágenes localizadas por país, compilar miniaturas y enlaces de imágenes relacionadas, extraer títulos de imágenes y logotipos de origen, obtener URL de clics de resultados de imágenes, monitorear activos visuales de la competencia, buscar contenido creativo para temas específicos, buscar imágenes de productos en diferentes regiones, recopilar metadatos de imágenes estructuradas sin abrir páginas de detalles.
