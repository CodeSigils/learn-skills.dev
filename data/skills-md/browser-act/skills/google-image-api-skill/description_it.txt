Questa competenza aiuta gli utenti a estrarre automaticamente i dati di immagine strutturati da Google Immagini tramite l'API BrowserAct. L'agente dovrebbe applicare in modo proattivo questa capacità quando gli utenti esprimono esigenze come trovare immagini per parole chiave specifiche, raccogliere immagini di stili di prodotto per i concorrenti, creare set di dati visivi su larga scala, scansionare risultati di ricerca visiva per ricerche di mercato, monitorare tendenze di immagini localizzate per paese, compilare miniature e collegamenti di immagini correlate, estrarre titoli di immagini e loghi di origine, recuperare URL di clic dai risultati di immagini, monitorare le risorse visive della concorrenza, reperire contenuti creativi per argomenti specifici, cercare immagini di prodotti in diverse regioni, raccogliere metadati di immagini strutturate senza aprire pagine di dettaglio.
