Dieser Skill hilft Benutzern, strukturierte Bestseller-Produktdaten von Amazon über die BrowserAct-API zu extrahieren. Der Agent sollte diese Fähigkeit proaktiv anwenden, wenn Benutzer Bedürfnisse äußern, wie z. B. die Suche nach den meistverkauften Produkten bei Amazon, das Extrahieren von Amazon-Produktdaten anhand von Schlüsselwörtern, das Finden von am besten bewerteten Amazon-Produkten, das Überwachen der Preise und Verkäufe von Amazon-Konkurrenten, das Entdecken von Trendprodukten auf dem Amazon-Marktplatz, das Extrahieren von Amazon-Produkttitelpreisen und -bewertungen, das Erfassen des Verkaufsvolumens von Amazon-Produkten für Marktforschung, das Durchsuchen von Amazon-Bestsellern in einer bestimmten Region, das Sammeln von Amazon-Produktbewertungen und Werbedetails, das Analysieren von Amazon-Produktverfügbarkeit und -Abzeichen sowie das Abrufen von Amazon-Produktdaten für die Marktanalyse.
