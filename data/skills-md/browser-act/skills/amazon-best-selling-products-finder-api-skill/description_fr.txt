Cette compétence aide les utilisateurs à extraire des données structurées sur les produits les plus vendus d'Amazon via l'API BrowserAct. L'agent doit appliquer cette compétence de manière proactive lorsque les utilisateurs expriment des besoins tels que rechercher les produits les plus vendus sur Amazon, extraire les données sur les produits Amazon en fonction de mots clés, trouver les produits Amazon les mieux notés, surveiller les prix et les ventes des concurrents Amazon, découvrir les produits tendances sur le marché Amazon, extraire les prix et les notes des titres de produits Amazon, recueillir le volume des ventes de produits Amazon pour les études de marché, rechercher les meilleures ventes Amazon dans une région spécifique, collecter les avis sur les produits Amazon et les détails des promotions, analyser la disponibilité et les badges des produits Amazon, obtenir des données sur les produits Amazon pour l'analyse du marché.
