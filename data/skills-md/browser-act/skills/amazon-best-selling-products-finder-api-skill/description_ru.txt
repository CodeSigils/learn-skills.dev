Этот навык помогает пользователям извлекать структурированные данные о самых продаваемых продуктах из Amazon через API BrowserAct. Агент должен активно применять этот навык, когда пользователи выражают такие потребности, как поиск самых продаваемых продуктов на Amazon, извлечение данных о продуктах Amazon на основе ключевых слов, поиск продуктов Amazon с самым высоким рейтингом, мониторинг цен и продаж конкурентов Amazon, обнаружение трендовых продуктов на рынке Amazon, извлечение цен и рейтингов продуктов Amazon, сбор объемов продаж продуктов Amazon для исследования рынка, поиск бестселлеров Amazon в определенном регионе, сбор обзоров продуктов Amazon и подробностей продвижения, анализ доступности продуктов Amazon и значков, получение данных о продуктах Amazon для анализа рынка.
