このスキルは、ユーザーが BrowserAct API を介して Amazon から構造化されたベストセラー商品データを抽出するのに役立ちます。エージェントは、Amazon でのベストセラー商品の検索、キーワードに基づいた Amazon 商品データの抽出、最高評価の Amazon 商品の検索、Amazon の競合他社の価格と売上の監視、Amazon マーケットプレイスでのトレンド商品の発見、Amazon 商品タイトルの価格と評価の抽出、市場調査のための Amazon 商品の販売量の収集、特定の地域での Amazon ベストセラーの検索、Amazon 製品のレビューとプロモーションの詳細の収集、Amazon 製品の在庫状況とバッジの分析、市場分析のための Amazon 製品データの取得などのニーズをユーザーが表明したときに、エージェントはこのスキルを積極的に適用する必要があります。
