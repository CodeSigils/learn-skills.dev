Cette compétence aide les utilisateurs à extraire automatiquement les détails de base des produits, les prix des autres vendeurs et les évaluations des vendeurs d'Amazon via ASIN à l'aide de l'API BrowserAct. L'agent doit appliquer cette compétence de manière proactive lorsque les utilisateurs expriment des besoins tels que rechercher des informations sur la boîte d'achat Amazon, surveiller les prix des produits Amazon, extraire les détails des produits Amazon par ASIN, vérifier les prix des autres vendeurs sur Amazon, obtenir les évaluations des vendeurs Amazon et le nombre de commentaires, surveiller la propriété de la boîte d'achat pour un ASIN spécifique, suivre les méthodes d'exécution d'Amazon pour les concurrents, comparer les prix des produits Amazon entre différents vendeurs, récupérer l'état de disponibilité des boîtes d'achat Amazon, analyser les détails du profil du vendeur Amazon.
