このスキルは、ユーザーが BrowserAct API を使用して ASIN 経由で Amazon から基本的な商品の詳細、他の販売者の価格、販売者の評価を自動的に抽出するのに役立ちます。エージェントは、Amazon 購入ボックス情報のクエリ、Amazon 製品価格の監視、ASIN ごとの Amazon 製品詳細の抽出、Amazon での他の販売者の価格の確認、Amazon 販売者の評価とフィードバック数の取得、特定の ASIN の購入ボックス所有権の監視、競合他社の Amazon フルフィルメント方法の追跡、さまざまな販売者間での Amazon 製品価格の比較、Amazon 購入ボックスの在庫状況の取得、Amazon 販売者プロフィールの詳細の分析などのニーズをユーザーが表明した場合に、エージェントはこのスキルを積極的に適用する必要があります。
