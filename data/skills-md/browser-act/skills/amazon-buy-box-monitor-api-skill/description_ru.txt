Этот навык помогает пользователям автоматически извлекать основные сведения о продуктах, цены других продавцов и рейтинги продавцов из Amazon через ASIN с использованием API BrowserAct. Агент должен активно применять этот навык, когда пользователи выражают свои потребности, например, запрашивают информацию о ящиках для покупок Amazon, отслеживают цены на продукты Amazon, извлекают сведения о продуктах Amazon по ASIN, проверяют цены других продавцов на Amazon, получают рейтинги продавцов Amazon и количество отзывов, отслеживают владение ящиками для покупок для конкретного ASIN, отслеживают методы выполнения заказов Amazon для конкурентов, сравнивают цены на продукты Amazon у разных продавцов, получают статус доступности ящиков для покупок Amazon, анализируют данные профиля продавца Amazon.
