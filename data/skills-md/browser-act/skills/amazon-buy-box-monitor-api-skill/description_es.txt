Esta habilidad ayuda a los usuarios a extraer detalles básicos del producto, precios de otros vendedores y calificaciones del vendedor de Amazon a través de ASIN automáticamente utilizando la API BrowserAct. El agente debe aplicar esta habilidad de manera proactiva cuando los usuarios expresan necesidades como consultar información de la Buy Box de Amazon, monitorear los precios de los productos de Amazon, extraer detalles de los productos de Amazon por ASIN, verificar los precios de otros vendedores en Amazon, obtener calificaciones de vendedores de Amazon y recuento de comentarios, monitorear la propiedad de la Buy Box para un ASIN específico, rastrear los métodos de cumplimiento de Amazon para los competidores, comparar los precios de los productos de Amazon entre diferentes vendedores, recuperar el estado de disponibilidad de la Buy Box de Amazon, analizar los detalles del perfil del vendedor de Amazon.
