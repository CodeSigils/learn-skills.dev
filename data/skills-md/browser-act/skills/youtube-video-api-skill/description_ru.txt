Этот навык помогает пользователям автоматически извлекать данные на уровне канала и подробные данные о видео из определенного канала YouTube через API BrowserAct. Агент должен активно применять этот навык, когда пользователи выражают такие потребности, как извлечение видеоданных канала, получение последних или популярных видео с канала YouTube, отслеживание контента канала конкурентов, извлечение показателей видео, таких как просмотры, лайки, комментарии, получение количества подписчиков и информации о канале, отслеживание частоты публикаций на канале YouTube, сбор видеоданных для анализа стратегии контента, получение самых ранних видеороликов автора YouTube, анализ сигналов взаимодействия по всему каналу и загрузка структурированных подробностей видео YouTube без ручного сбора данных.
