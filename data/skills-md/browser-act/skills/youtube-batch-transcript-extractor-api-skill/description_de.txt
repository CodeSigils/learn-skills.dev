Dieser Skill hilft Benutzern, automatisch YouTube-Videotranskripte und Metadaten im Stapel über die BrowserAct-API zu extrahieren. Der Agent sollte diese Fähigkeit proaktiv anwenden, wenn Benutzer Bedürfnisse äußern, wie z. B. Batch-Extrahierung vollständiger Transkripte aus YouTube-Videos für bestimmte Schlüsselwörter, Scraping von YouTube-Untertiteln für eine Liste von Videos, Batch-Video-Metadaten und Likes-Zählungen zur Analyse, Automatisierung der YouTube-Suche und Untertitel-Extraktion, Sammeln mehrerer in dieser Woche veröffentlichter Video-Transkripte, Herunterladen von YouTube-Video-Untertiteln in großen Mengen, ohne Crawler-Skripte zu schreiben, Erstellen eines Datensatzes von Transkripten aus Top-YouTube-Videos, Extrahieren von YouTube-Video-URLs und Publisher-Informationen im Batch, Sammeln vollständiger Videos Inhalte für KI-Zusammenfassungspipelines, überwachen Sie aktuelle YouTube-Videos und extrahieren Sie deren Transkripte, rufen Sie strukturierte Untertiteldaten für die Medienrecherche stapelweise ab und extrahieren Sie automatisch Transkripte aus angesagten YouTube-Inhalten.
