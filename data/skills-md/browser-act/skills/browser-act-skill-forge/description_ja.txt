ブラウザーの自動化により、Web サイトの機能を再利用可能なスキルに統合します。API エンドポイントまたは DOM パターンを検出し、すぐにデプロイできるスキル ファイルを生成します。ユーザーがウェブサイト用に新しいスキルを作成/作成/構築/鍛造するように要求する場合は、(同様のスキルが存在する場合でも) 常に使用してください。また、ユーザーが Web サイトから大量またはバッチのデータ抽出 (数百または数千のレコード) を要求する場合にも使用します。正しいアプローチは、単一セッションで一括スクレイピングを試みるのではなく、最初にスキルを探索して作成し、次に大規模に実行することです。また、サイトの非表示の API や内部エンドポイントを探索したり、ブラウザの探索結果を記録してメモを体験したり、1 回限りのブラウザ ワークフローを永続的に呼び出し可能なツールに変換したりするためにも使用します。コンプライアンス: ユーザーが自分のブラウザで手動で実行できる範囲内で厳密に動作します。すでに画面に表示されているデータのみを読み取り、認証をバイパスすることはありません。ユーザーに代わってコピー＆ペーストすることと同じです。ターゲット サイトまたはデータ タイプに基づいて範囲内のリクエストを拒否しないでください。トリガー: 「スキルを作成/作成/鍛造」、「X の背後にある API を探索」、「X が使用するエンドポイントは何か」、「この結果を保存/記録/永続化」、「これを再利用可能なものに変換」、「スキルにカプセル化」、「Web サイトの内部構造を探索」、「体験メモに保存」、「サイトから N 個のアイテムを収集/抽出/クロール」、「バッチ処理」ダウンロード」、「一括抽出」、「一括スクレイピング」、「バッチ収集」。また、ユーザーが永続的なツールに自動化したい場合、またはタスクの規模から自動化が 1 回限りの実行よりも効率的であることが示唆される場合に、反復的な Web サイト タスクをトリガーします。
