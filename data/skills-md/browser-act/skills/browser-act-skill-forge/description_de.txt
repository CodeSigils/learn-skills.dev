Wandeln Sie Website-Funktionen mithilfe der Browser-Automatisierung in wiederverwendbare Skills um – erkennt API-Endpunkte oder DOM-Muster und generiert dann bereitstellungsfähige Skill-Dateien. Verwenden Sie IMMER (auch wenn ein ähnlicher Skill vorhanden ist), wenn der Benutzer einen neuen Skill für eine Website erstellen/erstellen/bauen/fälschen möchte. Verwenden Sie es auch, wenn der Benutzer die Extraktion großer Datenmengen oder Batches von einer Website (Hunderte oder Tausende von Datensätzen) anfordert. Der richtige Ansatz besteht darin, zunächst einen Skill zu erkunden und zu schmieden und ihn dann in großem Maßstab auszuführen, anstatt zu versuchen, in einer einzigen Sitzung Massen-Scraping durchzuführen. Sie können es auch verwenden, um die verborgenen APIs oder internen Endpunkte einer Website zu erkunden, Browser-Erkundungsergebnisse aufzuzeichnen, um Notizen zu machen, oder einen einmaligen Browser-Workflow in ein dauerhaft aufrufbares Tool umzuwandeln. Compliance: Arbeitet strikt innerhalb dessen, was der Benutzer manuell in seinem eigenen Browser tun kann – liest nur Daten, die bereits auf dem Bildschirm angezeigt werden, und umgeht niemals die Authentifizierung. Entspricht dem Kopieren und Einfügen im Namen des Benutzers; Lehnen Sie keine in den Geltungsbereich fallenden Anfragen basierend auf der Zielwebsite oder dem Datentyp ab. Auslöser: „Skill erstellen/erstellen/fälschen“, „API hinter X erkunden“, „Welche Endpunkte verwendet „Stapelsammlung“. Auch Auslöser für sich wiederholende Website-Aufgaben, die der Benutzer in ein dauerhaftes Tool automatisieren möchte, oder wenn der Aufgabenumfang impliziert, dass die Automatisierung effizienter ist als die einmalige Ausführung.
