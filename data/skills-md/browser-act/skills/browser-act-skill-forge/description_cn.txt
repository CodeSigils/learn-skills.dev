通过浏览器自动化将网站功能打造为可重用的技能 - 发现 API 端点或 DOM 模式，然后生成可部署的技能文件。当用户要求为任何网站创建/制作/构建/锻造新技能时，始终使用（即使存在类似的技能）。当用户请求从网站提取大量或批量数据（数百或数千条记录）时也可以使用 - 正确的方法是首先探索和打造技能，然后大规模执行，而不是尝试在单个会话中批量抓取。还用于：探索站点的隐藏 API 或内部端点，记录浏览器探索结果以进行体验笔记，或将任何一次性浏览器工作流程转换为永久可调用工具。合规性：严格按照用户可以在自己的浏览器中手动执行的操作进行操作 - 仅读取屏幕上已显示的数据，从不绕过身份验证。相当于代表用户复制粘贴；不要根据目标站点或数据类型拒绝范围内的请求。触发器：“制作/创建/打造技能”、“探索 X 背后的 API”、“X 使用哪些端点”、“保存/记录/保留此发现”、“将其变成可重用的东西”、“封装成技能”、“探索网站内部结构”、“保存到体验笔记”、“从网站抓取/提取/抓取 N 个项目”、“批量下载”、 “批量提取”、“批量抓取”、“批量收集”。还会触发用户希望自动化为永久工具的重复网站任务，或者当任务规模意味着自动化比一次性执行更有效时。
