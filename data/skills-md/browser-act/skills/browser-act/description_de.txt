Browser-Automatisierungs-CLI für KI-Agenten mit Anti-Erkennungs-Stealth-Browsing, Captcha-Lösung und paralleler Unterstützung mehrerer Browser. Wird verwendet, wenn der Benutzer mit Websites interagieren muss, einschließlich Seitennavigation, Ausfüllen von Formularen, Klicken auf Schaltflächen, Erstellen von Screenshots, Extrahieren von Daten, Scraping von Websites mit Bot-Erkennung oder Automatisieren einer beliebigen Browseraufgabe. Verwenden Sie es auch, wenn der Benutzer eine Verbindung zu seiner bestehenden Chrome-Sitzung herstellen, Proxy-basiertes Stealth-Browsing konfigurieren oder parallele Browsersitzungen ausführen muss. Wird bei Anfragen zum Öffnen einer Website, zum Ausfüllen eines Formulars, zum Klicken auf eine Schaltfläche, zum Erstellen eines Screenshots, zum Scrapen von Daten von einer Seite, zum Anmelden bei einer Website, zum Automatisieren von Browseraktionen, zum Behandeln von Captcha-Herausforderungen oder bei jeder Aufgabe, die eine programmatische Webinteraktion erfordert, ausgelöst.
