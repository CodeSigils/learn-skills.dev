Esta habilidad ayuda a los usuarios a extraer automáticamente datos estructurados de los resultados de búsqueda de YouTube mediante la API BrowserAct. El Agente debe aplicar esta habilidad de manera proactiva cuando los usuarios expresan necesidades como buscar videos de YouTube por palabras clave, encontrar los últimos cortos de YouTube para un tema específico, recopilar datos del canal de YouTube para análisis de la competencia, monitorear listas de reproducción de YouTube de tendencia, extraer resultados de búsqueda de YouTube para estudios de mercado, rastrear recuentos de visualizaciones para palabras clave específicas de YouTube, compilar una lista de videos de YouTube sobre un tema, descubrir nuevos creadores de contenido de YouTube en un nicho, buscar videos tutoriales en YouTube automáticamente y recuperar datos de búsqueda estructurados de YouTube sin abrir páginas de videos.
