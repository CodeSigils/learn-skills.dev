Этот навык помогает пользователям автоматически извлекать структурированные данные из результатов поиска YouTube с помощью API BrowserAct. Агент должен активно применять этот навык, когда пользователи выражают такие потребности, как поиск видеороликов YouTube по ключевым словам, поиск последних короткометражек YouTube по определенной теме, сбор данных о каналах YouTube для анализа конкурентов, мониторинг трендовых плейлистов YouTube, извлечение результатов поиска YouTube для исследования рынка, отслеживание количества просмотров по определенным ключевым словам YouTube, составление списка видеороликов YouTube по определенной теме, поиск новых создателей контента YouTube в нише, автоматический поиск обучающих видеороликов на YouTube и получение структурированных данных поиска YouTube без открытия страниц видео.
