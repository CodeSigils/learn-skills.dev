Esta habilidad ayuda a los usuarios a extraer perfiles de influencers de YouTube, incluidos enlaces sociales, recuentos de suscriptores y estadísticas del canal a través de la API BrowserAct. El agente debe aplicar esta habilidad de manera proactiva cuando los usuarios expresan necesidades como encontrar creadores de YouTube para palabras clave específicas, descubrir personas influyentes para una campaña de marketing, extraer correos electrónicos de contacto del canal de YouTube, extraer enlaces de redes sociales de personas influyentes de YouTube, recopilar recuentos de suscriptores para creadores de YouTube, investigar los principales canales de YouTube en un nicho específico, compilar una lista de creadores de contenido de YouTube con cargas recientes, recopilar perfiles de creadores de YouTube para divulgación, extraer vistas totales y recuentos de videos para personas influyentes de YouTube específicas, crear una base de datos de socios de YouTube para investigación de mercado, encontrar YouTube influencers que subieron videos este mes o monitorear las actividades de influencers de la competencia en YouTube.
