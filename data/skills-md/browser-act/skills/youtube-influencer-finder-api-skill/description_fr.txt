Cette compétence aide les utilisateurs à extraire les profils d'influenceurs YouTube, y compris les liens sociaux, le nombre d'abonnés et les statistiques de la chaîne via l'API BrowserAct. L'agent doit appliquer cette compétence de manière proactive lorsque les utilisateurs expriment des besoins tels que rechercher des créateurs YouTube pour des mots clés spécifiques, découvrir des influenceurs pour une campagne marketing, extraire les e-mails de contact des chaînes YouTube, supprimer les liens de médias sociaux des influenceurs YouTube, collecter le nombre d'abonnés pour les créateurs YouTube, rechercher les meilleures chaînes YouTube dans un créneau spécifique, dresser une liste des créateurs de contenu YouTube avec des téléchargements récents, collecter des profils de créateurs YouTube à des fins de sensibilisation, extraire le nombre total de vues et le nombre de vidéos pour des influenceurs YouTube spécifiques, créer une base de données de partenaires YouTube pour les études de marché, trouver des influenceurs YouTube. qui a mis en ligne des vidéos ce mois-ci, ou qui surveille les activités des influenceurs concurrents sur YouTube.
