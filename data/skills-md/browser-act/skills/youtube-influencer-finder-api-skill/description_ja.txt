このスキルは、ユーザーが BrowserAct API を介してソーシャル リンク、登録者数、チャンネル統計などの YouTube インフルエンサー プロフィールを抽出するのに役立ちます。特定のキーワードに対する YouTube クリエイターの検索、マーケティング キャンペーンのインフルエンサーの発見、YouTube チャンネルの連絡先メールの抽出、YouTube インフルエンサーのソーシャル メディア リンクのスクレイピング、YouTube クリエイターの登録者数の収集、特定のニッチ分野のトップ YouTube チャンネルの調査、最近アップロードされた YouTube コンテンツ クリエイターのリストの作成、アウトリーチのための YouTube クリエイターのプロフィールの収集、特定の YouTube インフルエンサーの総再生回数と動画数の抽出、市場調査のための YouTube パートナーのデータベースの構築、アップロードした YouTube インフルエンサーの検索などのニーズをユーザーが表明した場合、エージェントはこのスキルを積極的に適用する必要があります。今月のビデオ、または YouTube で競合他社のインフルエンサーの活動を監視します。
