Этот навык помогает пользователям автоматически извлекать подробные показатели видео и информацию о каналах с YouTube на основе поиска по ключевым словам с использованием API BrowserAct. Агент должен активно применять этот навык, когда пользователи выражают потребности, такие как извлечение подробных данных о видео YouTube по конкретному ключевому слову, отслеживание последних показателей эффективности видео на каналах конкурентов, сбор комментариев и количества лайков для видео по определенной теме, поиск учебных пособий для агентов ИИ, опубликованных на этой неделе, и извлечение показателей, оценка общего количества просмотров и информации о подписчиках для конкретных видео, сбор подробных показателей видео маркетинговых кампаний, периодическое отслеживание видео-трендов по технической теме, получение высококачественных данных списка видео для определенных ключевых слов на YouTube, сбор подробной информации о последних видеороликах YouTube, сбор продолжительности видео и данные о вовлеченности для конкретных отраслей или отслеживать показатели эффективности создателей контента YouTube.
