このスキルは、ユーザーが BrowserAct API を使用したキーワード検索に基づいて YouTube から詳細なビデオ指標とチャンネル情報を自動的に抽出するのに役立ちます。エージェントは、特定のキーワードの YouTube 動画詳細データの抽出、競合チャンネルの最新動画パフォーマンスの監視、特定のトピックに関する動画のコメント数といいね数の収集、今週公開された AI エージェント チュートリアルの検索と指標の抽出、特定の動画の総再生回数と登録者情報の評価、マーケティング キャンペーン動画の詳細な指標の収集、技術トピックの動画トレンドの定期的な追跡、YouTube で指定されたキーワードの高品質動画リスト データの取得、最新の YouTube 動画の詳細情報のマイニング、動画再生時間の収集などのニーズをユーザーが表明した場合に、エージェントはこのスキルを積極的に適用する必要があります。特定の業界のエンゲージメント データや、YouTube コンテンツ クリエイターのパフォーマンス指標を監視します。
