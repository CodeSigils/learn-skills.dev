Exécuter le runbook de réponse aux incidents de sécurité LGPD (Art. 48 LGPD + Resolução CD/ANPD nº 15/2024). À utiliser lorsque l'utilisateur dit « tivemos um incidente », « vazamento de dados », « data violation », « préciso comunicar a ANPD », « incident response LGPD » ou dans le cadre d'un pipeline d'audit préparant le runbook à l'avance. Encode le délai de 3 jours ouvrables pour informer l'ANPD et les personnes concernées, les 12 éléments obligatoires pour la notification de l'ANPD, les 7 éléments pour la notification du sujet et l'exigence de conservation de 5 ans pour TOUS les enregistrements d'incidents (notifiés ou non). Citer explicitement la résolution 15/2024 dans les résultats.
