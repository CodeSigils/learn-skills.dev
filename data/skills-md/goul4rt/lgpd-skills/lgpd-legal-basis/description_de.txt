Wählen und dokumentieren Sie die Rechtsgrundlage (base legal) für jede Aktivität zur Verarbeitung personenbezogener Daten gemäß LGPD Art. 7 (gemeinsame Daten) oder Art. 11 (sensible Daten). Verwenden Sie diese Option, wenn der Benutzer eine neue Funktion entwirft, die personenbezogene Daten verarbeitet, eine bestehende Aktivität überprüft, „qual base legal usar“, „consentimento ou legítimo interesse“, „podemos coletar isso“ fragt oder einen LGPD-Prüfungsschritt durchführt. Erzeugt „.lgpd/legal-basis.md“ mit einem Eintrag pro Aktivität. Zitieren Sie immer den Artikel. Verwenden Sie es immer dann, wenn jemand Code schreiben möchte, der persönliche Daten berührt.
