Erstellen und pflegen Sie ein Dateninventar (Mapa de Dados) aller personenbezogenen Datenverarbeitungsaktivitäten im Projekt. Wird verwendet, wenn der Benutzer „Mapa de Dados“, „Data Mapping LGPD“, „Que Dados Pessoais Coletamos“, „Inventário de Tratamento“ oder als Teil einer LGPD-Prüfungspipeline fragt. Erzeugt „.lgpd/data-map.md“. Besonders wichtig für Legacy-Systeme, bei denen das Inventar durch Reverse Engineering aus Code erstellt wird (Prisma-Schemas, API-Endpunkte, SDKs von Drittanbietern, Protokollanweisungen).
