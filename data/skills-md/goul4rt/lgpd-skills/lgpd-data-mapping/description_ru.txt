Создайте и поддерживайте реестр данных (mapa de dados) всех действий по обработке персональных данных в проекте. Используйте, когда пользователь запрашивает «карта данных», «сопоставление данных LGPD», «que dados pessoais coletamos», «inventário de tratamento» или как часть конвейера аудита LGPD. Создает `.lgpd/data-map.md`. Особенно важно для устаревших систем, в которых инвентаризация создается методом реверс-инжиниринга на основе кода (схемы Prisma, конечные точки API, сторонние SDK, операторы журналов).
