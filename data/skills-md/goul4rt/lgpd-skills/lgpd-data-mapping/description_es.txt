Construir y mantener un inventario de datos (mapa de datos) de todas las actividades de procesamiento de datos personales en el proyecto. Úselo cuando el usuario pregunte "mapa de dados", "data mapeo LGPD", "que dados pessoais coletamos", "inventário de tratamento" o como parte de un proceso de auditoría LGPD. Produce `.lgpd/data-map.md`. Especialmente importante para sistemas heredados donde el inventario se crea mediante ingeniería inversa a partir de código (esquemas Prisma, puntos finales API, SDK de terceros, declaraciones de registro).
