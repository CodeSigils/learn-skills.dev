Construire et maintenir un inventaire de données (mapa de dados) de toutes les activités de traitement de données personnelles dans le cadre du projet. À utiliser lorsque l'utilisateur demande "mapa de dados", "data mapping LGPD", "que dados pessoais coletamos", "inventário de tratamento" ou dans le cadre d'un pipeline d'audit LGPD. Produit `.lgpd/data-map.md`. Particulièrement important pour les systèmes existants où l'inventaire est construit par ingénierie inverse à partir du code (schémas Prisma, points de terminaison d'API, SDK tiers, instructions de journal).
