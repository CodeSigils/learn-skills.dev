このスキルは、ユーザーが RSI の底値釣り、売られすぎの買い、RSI 戦略、または「RSI の底値」、「売られすぎの買い」、「RSI 戦略」、「底値ハンター」、「RSI 取引を開始」、「底値の魚を助けて」、「RSI が低いときに購入」などのリクエストを要求するときに使用します。 RSIを自動監視し、売られ過ぎゾーンで買い、ストップロスとテイクプロフィットを実行します。誤ったシグナルを減らすために、多次元確認 (MACD、スーパートレンド、ダイバージェンス、サポート/レジスタンス、ローソク足パターン) のデータ ソースとして bingx-technical-analysis を呼び出します。 bingx-swap-market、bingx-swap-trade、bingx-swap-account に依存します。
