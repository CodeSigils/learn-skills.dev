Используйте этот навык, когда пользователь запрашивает ловлю RSI на дне, покупку при перепроданности, стратегию RSI или любой запрос типа «дно RSI», «купить при перепроданности», «стратегия RSI», «охотник за дном», «начать торговлю RSI», «помогите мне ловить рыбу на дне», «покупать, когда RSI низкий». Автоматически отслеживает RSI, покупает в зоне перепроданности, выполняет стоп-лосс и тейк-профит. Вызывает технический анализ Bingx в качестве источника данных для многомерного подтверждения (MACD, Supertrend, дивергенция, поддержка/сопротивление, свечные модели) для уменьшения ложных сигналов. Зависит от bingx-swap-market, bingx-swap-trade, bingx-swap-account.
