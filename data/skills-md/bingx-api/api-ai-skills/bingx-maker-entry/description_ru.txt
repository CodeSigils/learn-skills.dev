Используйте этот навык, когда пользователь хочет открыть позицию, используя лимитные ордера вместо рыночных ордеров, или любой запрос типа «вход лимитного ордера», «вход создателя», «открытие лимитного ордера», «сэкономить комиссию при входе», «помочь мне разместить лимитные ордера», «автолимитные ордера», «избежать рыночного ордера», «айсбергский ордер», «ввод разделенного ордера». Сканирует глубину книги заказов, размещает многоуровневые лимитные ордера вблизи лучшей цены и динамически корректирует ее по мере движения цены. Экономит комиссию тейкера и снижает влияние на рынок. Зависит от bingx-swap-market, bingx-swap-trade, bingx-swap-account.
