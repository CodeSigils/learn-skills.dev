墨墨背单词 MaiMemo Навыки использования открытого API для изучения словарного запаса. Управляет: поиск словаря 单词 (voc_id), интерпретации 释义 (CRUD), мнемоника/заметки 助记, блокноты 云词本/списки слов, фразы 例句/примеры предложений, ход обучения 学习数据/график обучения/записи. Запускается по: 墨墨, маймемо, 背单词, 释义, 助记, 云词本, 例句, прогрессу обучения, графику проверки, просроченным словам, забытым словам, времени обучения, экспорту данных исследования.
