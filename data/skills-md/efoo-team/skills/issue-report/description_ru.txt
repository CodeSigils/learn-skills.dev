Используйте только тогда, когда пользователь явно вызывает /issue-report (или $issue-report в Кодексе). Никогда не вызывайте автоматически. Навык, который принимает несколько отчетов об ошибках и запросы функций одновременно, проводит параллельные исследования для каждого случая с использованием субагентов, группирует их по перекрывающимся областям ожидаемых изменений и либо создает новые проблемы GitHub, либо объединяет их в существующие проблемы. Его цель — организовать проблемы в блоки, которые не будут конфликтовать во время параллельной разработки рабочего дерева. Он собирает информацию от журналистов, не являющихся инженерами, простым языком, получает одобрение плана регистрации, а затем записывает проблему с помощью gh CLI. Он не принимает решения по решениям или спецификациям реализации. Пожалуйста, всегда отвечайте на языке пользователя.
