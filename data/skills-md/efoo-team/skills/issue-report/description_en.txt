Only use when the user explicitly invokes /issue-report (or $issue-report in Codex). Never auto-invoke. A skill that accepts multiple bug reports and feature requests at once, conducts parallel investigations for each case using sub‑agents, groups them by overlapping areas of anticipated change, and either creates new GitHub issues or consolidates them into existing issues. Its purpose is to organize issues into units that do not conflict during parallel work‑tree development. It gathers information from non‑engineer reporters in plain language, obtains approval for the registration plan, and then writes the issue using the gh CLI. It does not decide on solutions or implementation specifications. Please always respond in user's language.
