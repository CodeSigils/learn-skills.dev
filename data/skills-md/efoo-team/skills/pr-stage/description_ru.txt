Используйте только тогда, когда пользователь явно вызывает /pr-stage (или $pr-stage в Кодексе). Никогда не вызывайте автоматически. Фиксируйте только те изменения, которые уже были проиндексированы (git add завершен), а при необходимости также создайте ветку функции, отправьте ее и создайте PR. Определенные процедуры и меры безопасности относятся к навыку PR, и этот навык представляет собой тонкую оболочку, которая определяет только разницу — обработку только поэтапных изменений.
