Una guía para la verificación de la API del marco Mastra, la búsqueda de la documentación más reciente y la migración de versiones. Se utiliza para verificar las especificaciones actuales antes de escribir código Mastra, verificar firmas API, crear agentes/flujos de trabajo/herramientas/memoria/RAG y manejar migraciones como v0.x→v1.x. Trate el conocimiento interno como desactualizado y verifíquelo siempre utilizando las definiciones de tipo de la versión instalada o la documentación oficial. Utilice reglas de arquitectura de mastra-ai para decisiones de diseño como la separación de responsabilidades.
