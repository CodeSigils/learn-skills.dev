Un guide pour la vérification de l'API du framework Mastra, la recherche de la dernière documentation et la migration de version. Il est utilisé pour vérifier les spécifications actuelles avant d'écrire du code Mastra, vérifier les signatures API, créer des agents/workflows/outils/mémoire/RAG et gérer les migrations telles que v0.x→v1.x. Considérez les connaissances internes comme obsolètes et vérifiez toujours à l'aide des définitions de type de la version installée ou de la documentation officielle. Utilisez les règles d'architecture mastra‑ai pour les décisions de conception telles que la séparation des responsabilités.
