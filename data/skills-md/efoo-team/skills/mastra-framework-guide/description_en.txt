A guide for Mastra framework API verification, searching the latest documentation, and version migration. It is used to check the current specifications before writing Mastra code, verify API signatures, build agents / workflows / tools / memory / RAG, and handle migrations such as v0.x → v1.x. Treat internal knowledge as outdated and always verify using the type definitions of the installed version or the official documentation. Use mastra‑ai‑architecture‑rules for design decisions such as separation of responsibilities.
