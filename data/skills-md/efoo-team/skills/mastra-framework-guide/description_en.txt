Guide for API validation, latest documentation lookup, and version migration of the Mastra framework. Used for confirming the current specifications before writing Mastra code, validating API signatures, building agents, workflows, tools, memory, and RAG, and migrating from v0.x to v1.x, etc. Treat internal knowledge as outdated, and always verify using the type definitions of the installed version or the official documentation. Use mastra-ai-architecture-rules for design decisions such as separation of responsibilities.
