Runtime‑independent design charter for designing, implementing, and procuring an AI agent harness (agent loop, tool surface, context management, authorization, state, termination conditions, evaluation, observability). Used in scenarios such as “design the agent platform/harness,” “decide whether to build it yourself, use an SDK, or adopt an off‑the‑shelf solution,” “how to handle compaction,” and “whether to make it multi‑agent.” For repository‑side design, see agent-native-project-design; for design on Mastra, refer to mastra-ai-architecture-rules.
