يُستخدم فقط عندما يستدعي المستخدم صراحةً /pr-body (أو $pr-body في Codex). عدم الاستدعاء التلقائي مطلقًا. قم بتحليل التغييرات التي ينفذها الذكاء الاصطناعي باستخدام بنية تجريد هرمية وإخراجها كجسم GitHub PR منظم (قم بإنشاء الجسم فقط؛ لا تقم بتنفيذ أي عمليات Git. الاسم السابق: github-pull-request). حتى بالنسبة للتغييرات واسعة النطاق، قم بالتنظيم من المجرد إلى الملموس بالترتيب: مخطط بنية النظام ← بنية البيانات ← واجهة برمجة التطبيقات ← تدفق المعالجة ← تفاصيل التنفيذ. قم أيضًا بتغطية كيفية إنشاء نص العلاقات العامة الذي يتضمن أدلة الصور.
