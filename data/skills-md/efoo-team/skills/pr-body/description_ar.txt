يُستخدم فقط عندما يستدعي المستخدم صراحةً /pr-body (أو $pr-body في Codex). عدم الاستدعاء التلقائي مطلقًا. قم بتحليل التغييرات التي ينفذها الذكاء الاصطناعي في بنية تجريد هرمية وإخراجها كجسم GitHub PR منظم (إنشاء الجسم فقط؛ لا يتم تنفيذ أي عمليات Git. كان يُسمى سابقًا طلب github-pull-request). حتى بالنسبة للتغييرات الكبيرة، قم بالتنظيم من المجرد إلى الملموس بالترتيب: مخطط بنية النظام ← بنية البيانات ← واجهة برمجة التطبيقات ← تدفق المعالجة ← تفاصيل التنفيذ. قم أيضًا بتغطية كيفية تجميع نص العلاقات العامة الذي يتضمن أدلة الصور. يرجى الرد دائمًا بلغة المستخدم.
