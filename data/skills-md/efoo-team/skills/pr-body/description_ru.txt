Используйте только тогда, когда пользователь явно вызывает /pr-body (или $pr-body в Кодексе). Никогда не вызывайте автоматически. Анализируйте изменения, реализованные ИИ, с помощью иерархической структуры абстракции и выводите их в виде структурированного тела PR GitHub (генерируйте только тело; не выполняйте никаких операций Git. Ранее это называлось github-pull-request). Даже масштабные изменения организуйте от абстрактного к конкретному в следующем порядке: схема архитектуры системы → структуры данных → API → последовательность операций → детали реализации. Также расскажите, как составить PR-организацию, включающую имиджевые доказательства.
