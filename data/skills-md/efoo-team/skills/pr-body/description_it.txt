Da utilizzare solo quando l'utente invoca esplicitamente /pr-body (o $pr-body nel Codex). Non eseguire mai l'invocazione automatica. Analizza le modifiche implementate dall'intelligenza artificiale in una struttura di astrazione gerarchica e generale come corpo GitHub PR strutturato (genera solo il corpo; non eseguire operazioni Git. Nome precedente: github-pull-request). Anche per modifiche su larga scala, organizzare dall'astratto al concreto nell'ordine: diagramma dell'architettura del sistema → struttura dei dati → API → flusso di elaborazione → dettagli di implementazione. Gestisci anche come assemblare un corpo PR che includa prove di immagini.
