Même pour les changements importants (plus de 10 000 lignes), organisez de l'abstrait au concret dans l'ordre diagramme d'architecture système → structure de données → API → flux de traitement → détails d'implémentation. Expliquez également comment assembler une description de relations publiques comprenant des preuves d'image. Utilisez-le dans des situations telles que « rédiger une description de PR », « transformer ce changement en PR » ou « Je souhaite créer un PR pour le contenu implémenté ».
