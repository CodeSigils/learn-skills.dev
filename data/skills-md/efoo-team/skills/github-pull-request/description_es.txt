Analice los cambios implementados por la IA utilizando una estructura jerárquica de niveles de abstracción y generelos como un cuerpo estructurado de relaciones públicas de GitHub. Incluso para cambios a gran escala (más de 10,000 líneas), organícelos de abstracto a concreto en el orden de diagrama de arquitectura del sistema → estructuras de datos → API → flujo de procesamiento → detalles de implementación. Cubra también cómo construir un cuerpo de relaciones públicas que incluya evidencia de imagen. Se utiliza en situaciones como "escribir el cuerpo de relaciones públicas", "convertir este cambio en un PR" o "Quiero crear un PR para el contenido implementado".
