Analysieren Sie die in der KI umgesetzten Änderungen mithilfe einer hierarchischen Abstraktionsstruktur und geben Sie sie als strukturierte GitHub-PR-Beschreibung aus. Auch bei großen Änderungen (mehr als 10.000 Zeilen) organisieren Sie von abstrakt zu konkret in der Reihenfolge Systemarchitekturdiagramm → Datenstruktur → API → Verarbeitungsfluss → Implementierungsdetails. Behandeln Sie außerdem, wie Sie eine PR-Beschreibung zusammenstellen, die Bildbeweise enthält. Verwenden Sie dies in Situationen wie „Eine PR-Beschreibung schreiben“, „Diese Änderung in eine PR umwandeln“ oder „Ich möchte eine PR für den implementierten Inhalt erstellen“.
