Анализируйте изменения, реализованные ИИ, используя иерархическую структуру абстракции, и выводите их в виде структурированного тела PR GitHub. Даже большие изменения (более 10 000 строк) организуйте от абстрактного к конкретному в следующем порядке: схема архитектуры системы → структура данных → API → поток обработки → детали реализации. Также расскажите, как составить документ по связям с общественностью, включающий имиджевые доказательства. Его используют в таких ситуациях, как «написать текст PR», «превратить это изменение в PR» или «я хочу создать PR для реализованного контента».
