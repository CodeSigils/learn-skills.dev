قم بتحليل التغييرات التي ينفذها الذكاء الاصطناعي باستخدام هيكل هرمي لمستويات التجريد وإخراجها كوصف منظم لـ GitHub PR. حتى بالنسبة للتغييرات الكبيرة (أكثر من 10000 سطر)، قم بالتنظيم من الملخص إلى الملموس بترتيب مخطط بنية النظام ← بنية البيانات ← واجهة برمجة التطبيقات ← تدفق المعالجة ← تفاصيل التنفيذ. قم أيضًا بتغطية كيفية تجميع وصف العلاقات العامة الذي يتضمن أدلة الصور. يتم استخدامه في مواقف مثل "اكتب وصفًا للعلاقات العامة" أو "تحويل هذا التغيير إلى علاقات عامة" أو "أريد إنشاء علاقات عامة للمحتوى الذي تم تنفيذه".
