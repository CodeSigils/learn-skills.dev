Analizza i cambiamenti implementati dall'intelligenza artificiale utilizzando una struttura di astrazione gerarchica e generali come un corpo PR GitHub strutturato. Anche per modifiche su larga scala (oltre 10.000 righe), organizzare dall'astratto al concreto nell'ordine: diagramma dell'architettura del sistema → strutture dati → API → flusso di elaborazione → dettagli di implementazione. Copri anche come costruire un corpo di pubbliche relazioni che includa prove di immagini. Viene utilizzato in situazioni come "scrivi una descrizione PR", "trasforma questa modifica in una PR" o "Voglio creare una PR per il contenuto implementato".
