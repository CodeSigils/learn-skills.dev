Навык, который разделяет обработку проверки PR на работника по сбору данных, субагента по классификации и исполнителя для координации. Сбор данных выполняется работником по сбору данных, который запускает `gh pr-review-check`; классификация, группировка и генерация рабочих пакетов обрабатываются субагентом классификации (пример по умолчанию: Oracle); фактическая работа, такая как реализация, ответ и разрешение, делегируется исполнителю, в то время как родительский элемент управляет шлюзом полноты, резервной активацией и циклом опроса. В средах без механизма субагента родительский элемент сам выполняет ухудшенное выполнение.
