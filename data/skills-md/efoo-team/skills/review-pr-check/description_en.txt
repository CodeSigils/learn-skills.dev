Only use when the user explicitly invokes /review-pr-check (or $review-pr-check in Codex). Never auto-invoke. Skill that separates PR review handling into a collection worker, a classification sub‑agent, and an execution worker, and orchestrates them. Collection is performed by a collection worker that runs `gh pr-review-check`; classification, grouping, and work packet generation are handled by a classification sub‑agent (the default example is Oracle); the actual work such as implementation, replying, and resolve is delegated to an execution worker, while the parent manages the completeness gate, fallback activation, and the polling loop. In environments without a sub‑agent mechanism, the parent itself performs a degraded execution.
