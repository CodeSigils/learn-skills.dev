Only use when the user explicitly invokes /review-pr-check (or $review-pr-check in Codex). Never auto-invoke. A skill that separates PR review handling into a collector worker, a classification sub‑agent, and an execution worker, and orchestrates them. Collection is handled by a collector worker that runs `gh pr-review-check`; classification, grouping, and work‑packet generation are delegated to a classification sub‑agent (Oracle is the default example); actual work such as implementation, replying, and resolving is delegated to the execution worker, while the parent manages the completeness gate, fallback activation, and the polling loop. In environments without the sub‑agent mechanism, the parent itself performs degraded execution.
