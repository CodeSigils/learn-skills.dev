Only use when the user explicitly invokes /create-skill (or $create-skill in Codex). Never auto‑invoke. A skill for interactively creating a new Agent Skill from scratch. Use it in situations such as “I want to make a skill” or “I want to turn this task into a skill.” After probing the user with questions to determine their intent (the problem they want to solve, the situation they want the skill to trigger, the scope of use), it consistently performs: judging whether the task should become a skill, deciding the deployment layer (common layer / project layer) and the name, designing and writing SKILL.md, and validating with the checker. The canonical source for general principles of skill authoring (progressive disclosure, description writing, etc.) is the agent‑native‑project‑design document, and this skill provides a creation workflow that applies those principles.
