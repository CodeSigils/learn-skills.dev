Only use when the user explicitly invokes /create-skill (or $create-skill in Codex). Never auto-invoke. A skill for interactively creating a new Agent Skill from scratch. Use it in situations like “I want to create a skill” or “I want to turn this task into a skill.” After questioning the user to discern the intention (the problem to solve, the scenario where it should be triggered, the scope of use), it consistently performs the decision of whether to make it a skill, determines the placement layer (common layer / project layer) and name, designs and writes the SKILL.md, and verifies it with a checker. The definitive source for general principles of skill writing (progressive disclosure, description writing, etc.) is agent-native-project-design, and this skill provides a creation workflow that applies those principles.
