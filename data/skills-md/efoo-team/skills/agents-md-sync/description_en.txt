Only use when the user explicitly invokes /agents‑md‑sync (or $agents‑md‑sync in Codex). Never auto‑invoke. A skill that parses the entire repository and generates/updates an AGENTS.md knowledge base for each hierarchy (the root and subdirectories selected by scoring). Each time it runs, it detects divergences between the existing AGENTS.md and the code base, brings it up to date, and also maintains the CLAUDE.md bridge for Claude Code. Use it when you need to organize, initialize, or update AGENTS.md or to build a knowledge base equivalent to init‑deep. For design principles on what to write in the instruction file, see agent‑native‑project‑design.  

Please always respond in the user's language.
