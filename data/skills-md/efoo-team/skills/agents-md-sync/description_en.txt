Only use when the user explicitly invokes /agents-md-sync (or $agents-md-sync in Codex). Never auto-invoke. A skill that analyzes the entire repository and generates/updates a hierarchical AGENTS.md knowledge base (the root and subdirectories selected by scoring). Each time it runs, it detects divergences between the existing AGENTS.md and the code base, brings them up to date, and also maintains the CLAUDE.md bridge for Claude Code. It is used when you need to maintain, initialize, or update AGENTS.md, or build a knowledge base equivalent to init-deep. For design principles on what to write in the instruction file, refer to agent-native-project-design.
