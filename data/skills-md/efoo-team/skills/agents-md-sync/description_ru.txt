Используйте только тогда, когда пользователь явно вызывает /agents‑md‑sync(или $agents‑md‑sync в Кодексе). Никогда не вызывайте автоматически. Навык, который анализирует весь репозиторий и генерирует/обновляет базу знанийAGENTS.md для каждой иерархии (корневой каталог и подкаталоги, выбранные путем оценки). При каждом запуске он обнаруживает расхождения между существующим файломAGENTS.md и базой кода, обновляет его, а также поддерживает CLAUDE.mdbridge для Claude Code. Используйте его, когда вам нужно организовать, инициализировать или обновитьAGENTS.mdor для создания базы знаний, эквивалентной глубине инициализации. Принципы проектирования и сведения о том, что писать в файле инструкций, см. в разделе Agent-native-project-design.
