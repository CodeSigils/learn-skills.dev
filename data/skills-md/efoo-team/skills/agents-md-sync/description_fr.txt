À utiliser uniquement lorsque l'utilisateur invoque explicitement/agents‑md‑sync(ou$agents‑md‑syncin Codex). Ne jamais invoquer automatiquement. Une compétence qui analyse l'intégralité du référentiel et génère/met à jour une base de connaissances AGENTS.md pour chaque hiérarchie (la racine et les sous-répertoires sélectionnés par notation). Chaque fois qu'il s'exécute, il détecte les divergences entre le fichier AGENTS.md existant et la base de code, le met à jour et maintient également le pont CLAUDE.md pour Claude Code. Utilisez-le lorsque vous devez organiser, initialiser ou mettre à jourAGENTS.mdor pour créer une base de connaissances équivalente à init‑deep. Pour connaître les principes de conception sur ce qu’il faut écrire dans le fichier d’instructions, voir agent‑native‑project‑design.  

Veuillez toujours répondre dans la langue de l'utilisateur.
