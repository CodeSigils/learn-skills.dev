A skill for designing, organizing, and pruning the repository/project side (CLAUDE.md / AGENTS.md, Agent Skills, hooks, subagents) that runs on off‑the‑shelf AI agent harnesses such as Claude Code / Codex. It is used for requests like “design/organize CLAUDE.md,” “I want to delegate this work to an agent,” “I want to create a skill,” or “the agent doesn’t follow instructions.” For development of the harness/runtime itself, see agent‑harness‑engineering.
