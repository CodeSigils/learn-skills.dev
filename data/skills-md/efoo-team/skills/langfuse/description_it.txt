Esegui query, esegui il debug e analizza i dati di osservabilità LLM da Langfuse tramite API REST. Copre tracce, osservazioni, sessioni, punteggi, prompt e set di dati. Da utilizzare durante l'analisi del comportamento dell'agente, il debug delle chiamate LLM, l'analisi dei costi/latenza, la revisione delle versioni dei prompt o il controllo delle esecuzioni dell'agente Mastra.
