Используйте только тогда, когда пользователь явно вызывает /dependabot-sweep (или $dependabot-sweep в Кодексе). Никогда не вызывайте автоматически. Проанализируйте все запросы на обновление зависимостей, созданные Dependabot, и создайте единый запрос на обновление, который объединяет все обновления в одну ветку. Вместо того, чтобы объединять каждый PR Dependabot по отдельности, объедините их в единый PR и закройте исходные PR комментарием.
