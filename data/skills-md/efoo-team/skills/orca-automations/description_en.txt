Only use when the user explicitly invokes /orca-automations (or $orca-automations in Codex). Never auto-invoke. A skill to create and manage Orca automations with the orca CLI. It is used when, in an Orca environment, you need to “do ○○ at 9 am every morning,” “create an automation that runs periodically or on a schedule,” or “list, view execution history, or delete automations.” Flag specifications are delegated to queries to the installed CLI, following the latest specifications. Do not use it for OS cron, CI scheduling, or periodic execution of Claude Code itself.
