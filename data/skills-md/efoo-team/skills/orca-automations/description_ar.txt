يُستخدم فقط عندما يستدعي المستخدم بشكل صريح /orca-automations (أو $orca-automations في Codex). عدم الاستدعاء التلقائي مطلقًا. مهارة لإنشاء وإدارة عمليات التشغيل الآلي لـ Orca باستخدام Orca CLI. استخدمه عندما تتطلب بيئة Orca مهام مثل "تنفيذ ◯◯ في الساعة 9 صباحًا كل صباح" أو "إنشاء عملية أتمتة تعمل بشكل دوري أو وفقًا لجدول زمني" أو "القائمة أو عرض سجل التنفيذ أو حذف عمليات الأتمتة." يتم تفويض مواصفات العلامة إلى الاستعلامات إلى واجهة سطر الأوامر (CLI) المثبتة، باتباع أحدث المواصفات. لا تستخدمه لكرون نظام التشغيل، أو جدولة CI، أو التنفيذ الدوري لـ Claude Code نفسه.

يرجى الرد دائمًا بلغة المستخدم.
