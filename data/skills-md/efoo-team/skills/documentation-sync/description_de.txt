Eine Fähigkeit zum Überprüfen und Synchronisieren der Dokumentationskonsistenz, die mit Codeänderungen einhergeht. Es klassifiziert Änderungskategorien aus Git Diff, bestimmt pro Kategorie, ob eine Dokumentationssynchronisierung erforderlich ist, generiert automatisch generierte Dokumente neu, prüft auf defekte Links und erstellt Berichte in einem Tabellenformat. Verwenden Sie es, wenn Sie eine Synchronisierung der Dokumentation, eine Überprüfung der Dokumentationskonsistenz oder die Erkennung verpasster Aktualisierungen benötigen. Wenn die Generierung oder Aktualisierung der AGENTS.md-Hierarchie selbst im Mittelpunkt steht, verwenden Sie Agents-md-sync (explizit aufgerufen).
