A skill for verifying and synchronizing document consistency associated with code changes. It classifies change categories from git diff, determines on a per‑category basis whether document synchronization is required, regenerates automatically generated documents, checks for broken links, and reports in tabular form. Use it when document synchronization, document consistency verification, or missed‑update detection is needed. When the generation or updating of the AGENTS.md hierarchy itself is the focus, use agents‑md‑sync (explicit invocation).
