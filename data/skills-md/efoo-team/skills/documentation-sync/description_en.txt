A skill for verifying and syncing documentation consistency that accompanies code changes. It classifies change categories from git diff, determines per category whether documentation synchronization is needed, regenerates automatically generated documents, checks for broken links, and reports in a table format. Use it when you need documentation synchronization, documentation consistency verification, or detection of missed updates. When the generation or updating of the AGENTS.md hierarchy itself is the focus, use agents‑md‑sync (explicitly invoked).
