UI, 화면, 탐색 흐름에 관한 디자인 결정을 내리는 기술입니다. 새로운 화면을 만들거나 기능을 추가할 때 UI 디자인 및 작업 배치, 기존 UI 구성 및 단순화, 요구 사항 단계의 화면 전환 및 정보 디자인, UI 디자인 검토에 사용됩니다. "UI 디자인"에 대해 명시적으로 지시하지 않은 경우에도 마찬가지입니다. 항목 통합, 점진적 공개, 배치 결정에 대한 검토 절차(객체 → 구조 → 흐름 → 데이터 상태 → UI)와 기준을 제공합니다. 색상, 타이포그래피 등 시각적 표현의 창작은 범위를 벗어난다. 코드 경계 디자인에는 module-boundary-design을 사용하세요. API 디자인을 위한 userestful-api-design.
