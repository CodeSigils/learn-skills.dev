UI, 화면, 사용자 흐름에 대한 디자인 결정을 내리는 기술입니다. 새로운 화면을 만들거나 기능을 추가할 때의 UI 디자인 및 액션 배치, 기존 UI의 정리 및 단순화, 요구사항 단계의 화면 전환 및 정보 디자인, UI 디자인 검토 등 명시적으로 'UI 디자인'을 요청하지 않고도 적용할 수 있습니다. 항목 통합, 단계적 공개, 레이아웃 결정을 위한 심의 프로세스(객체 → 구조 → 흐름 → 데이터 상태 → UI)와 기준을 제공합니다. 색상, 타이포그래피 등 세밀한 시각적 표현은 범위를 벗어납니다. 코드 경계 디자인에는 module‑boundary‑design을 사용합니다. API 디자인의 경우 사용자 친화적인 API 디자인입니다.
