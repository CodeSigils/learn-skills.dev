Habilidad para tomar decisiones de diseño sobre UI, pantallas y flujos de navegación. Se utiliza para el diseño de la interfaz de usuario y la ubicación de acciones al crear nuevas pantallas o agregar funciones, para organizar y simplificar la interfaz de usuario existente, para la transición de pantalla y el diseño de información en la etapa de requisitos, y en revisiones del diseño de la interfaz de usuario, incluso cuando no se le indique explícitamente "diseñar la interfaz de usuario". Proporciona un proceso de deliberación (objeto → estructura → flujo → estado de datos → UI) y criterios para decisiones sobre integración de entrada, divulgación por etapas y ubicación. La expresión visual detallada, como el color y la tipografía, está fuera de alcance. Para el diseño de límites de código, utilicemodule‑boundary‑design; para diseño de API, userestful‑api‑design.
