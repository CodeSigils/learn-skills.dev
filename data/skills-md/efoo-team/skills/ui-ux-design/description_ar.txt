المهارة في اتخاذ قرارات التصميم لواجهة المستخدم والشاشات وتدفق المستخدم. بالنسبة للشاشات الجديدة أو إضافات الميزات، يتضمن تصميم واجهة المستخدم، ووضع الإجراء، وتنظيم واجهة المستخدم الحالية وتبسيطها، وانتقال الشاشة وهندسة المعلومات أثناء مرحلة المتطلبات، ومراجعات تصميم واجهة المستخدم، المستخدمة حتى عندما لا يتم توجيهها صراحةً "لتصميم واجهة المستخدم". يوفر إجراء النظر (الكائن → الهيكل → التدفق → حالة البيانات → واجهة المستخدم) ومعايير تكامل الإدخال والكشف المرحلي وقرارات التنسيب. يعد إنشاء التعبيرات المرئية مثل اللون والطباعة خارج النطاق. يستخدم تصميم حدود التعليمات البرمجية تصميم حدود الوحدة، ويستخدم تصميم واجهة برمجة التطبيقات تصميمًا مريحًا.
