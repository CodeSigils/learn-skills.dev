مهارة اتخاذ قرارات التصميم بشأن واجهة المستخدم والشاشات وتدفقات المستخدم. ويمكن تطبيقه على تصميم واجهة المستخدم وموضع الإجراء عند إنشاء شاشات جديدة أو إضافة ميزات، وتنظيم واجهة المستخدم الحالية وتبسيطها، وفحص الانتقال وتصميم المعلومات في مرحلة المتطلبات، ومراجعات تصميم واجهة المستخدم - حتى بدون طلب صريح "لتصميم واجهة المستخدم". فهو يوفر عملية التداول (الكائن → الهيكل → التدفق → حالة البيانات → واجهة المستخدم) ومعايير القرارات المتعلقة بتكامل الإدخال والكشف المرحلي والتخطيط. التعبيرات المرئية التفصيلية مثل اللون والطباعة خارج النطاق. لتصميم حدود التعليمات البرمجية، استخدمmodule‑boundary‑design؛ لتصميم واجهة برمجة التطبيقات، تصميم واجهة المستخدم المريح.
