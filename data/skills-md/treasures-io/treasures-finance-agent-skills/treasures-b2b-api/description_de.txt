Verwenden Sie diese Funktion, um einen KI-Agenten auf der öffentlichen B2B-API von Treasures aufzubauen – entdecken Sie tokenisierte Aktien, quotieren/führen Sie Trades aus, überbrücken Sie USDC zwischen Solana und Ethereum und lesen Sie Portfolio- und Handelshistorie für ein einzelnes Endbenutzer-Wallet-Paar. Umfasst Endpunktauswahl, eigentumssicheres Signieren (inkl. eingebetteter Wallets), Handels-/Bridge-Ausführung und Fehlerbehandlung.
