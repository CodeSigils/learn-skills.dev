تشغيل محفظة Treasures المفوضة عبر واجهة برمجة التطبيقات HTTP: الإعداد (إنشاء محفظة + إنشاء مفتاح API محدود النطاق)، الحصول على الأسعار، تنفيذ عمليات الشراء/البيع (غير متزامن، موقّع من الخادم — الوكيل لا يوقع أبدًا)، قراءة الأرصدة/المحفظة/سجل الصفقات، وإدارة مفاتيح API. يتم التحفيز كلما احتاج الوكيل إلى تداول الأسهم المرمَّزة (xStocks / Ondo) مقابل USDC على محفظة Treasures، أو فحص رصيد محفظة Treasures أو الأرباح والخسائر، أو إعداد وصول إلى محفظة Treasures. يحتاج الوكيل فقط إلى HTTPS + مفتاح API — لا مكتبات web3، لا مفاتيح خاصة، لا RPC.
