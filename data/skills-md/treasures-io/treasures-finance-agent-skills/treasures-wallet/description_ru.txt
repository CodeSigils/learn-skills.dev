Оперировать делегированным кошельком Treasures через HTTP API: регистрация (создание кошелька + выпуск ограниченного API‑ключа), получение котировок, выполнение покупок/продаж (асинхронно, подпись сервером — агент НИКОГДА не подписывает), чтение балансов/портфеля/истории сделок и управление API‑ключами. Вызывайте, когда агенту нужно торговать токенизированными акциями (xStocks / Ondo) против USDC в кошельке Treasures, проверить баланс или P&L кошелька Treasures, либо настроить доступ к кошельку Treasures. Агенту требуется только HTTPS + API‑ключ — без библиотек web3, без приватных ключей, без RPC.
