Gestire un wallet delegato Treasures tramite l'API HTTP: onboarding (creare un wallet + generare una chiave API limitata), ottenere quotazioni, eseguire acquisti/vendite (asincroni, firmati dal server — l'agente NON firma mai), leggere saldi/portafoglio/storia delle operazioni e gestire le chiavi API. Attivare ogni volta che un agente deve scambiare azioni tokenizzate (xStocks / Ondo) contro USDC su un wallet Treasures, controllare il saldo o il P&L di un wallet Treasures, o configurare l'accesso al wallet Treasures. L'agente ha bisogno solo di HTTPS + una chiave API — nessuna libreria web3, nessuna chiave privata, nessun RPC.
