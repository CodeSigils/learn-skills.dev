Gérez un portefeuille délégué Treasures via l'API HTTP : intégrez (fournissez un portefeuille + créez une clé API étendue), obtenez des devis, exécutez des achats/ventes (asynchrones, signés par le serveur - l'agent ne signe JAMAIS), lisez les soldes/portefeuille/historique des échanges et gérez les clés API. Déclenchez-le chaque fois qu'un agent a besoin d'échanger des actions tokenisées (xStocks / Ondo) contre USDC sur un portefeuille Treasures, de vérifier le solde ou le P&L d'un portefeuille Treasures, ou de configurer l'accès au portefeuille Treasures. L'agent n'a besoin que de HTTPS + une clé API : pas de bibliothèques web3, pas de clés privées, pas de RPC.
