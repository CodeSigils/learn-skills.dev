Treasures の委任ウォレットを HTTP API 経由で操作します。オンボード (ウォレットのプロビジョニング + スコープ指定された API キーのミント)、相場の取得、売買の実行 (非同期、サーバー署名 - エージェントは決して署名しません)、残高/ポートフォリオ/取引履歴の読み取り、API キーの管理を行います。エージェントが Treasures ウォレットでトークン化された株式 (xStocks / Ondo) と USDC を取引する必要がある場合、Treasures ウォレットの残高または損益を確認する場合、または Treasures ウォレットへのアクセスを設定する必要がある場合にトリガーします。エージェントに必要なのは HTTPS + API キーのみです。Web3 ライブラリ、秘密キー、RPC は必要ありません。
