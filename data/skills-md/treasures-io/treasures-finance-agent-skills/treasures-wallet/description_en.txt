Operate a Treasures delegated wallet over the HTTP API: onboard (provision a wallet + mint a scoped API key), get quotes, execute buys/sells (async, server-signed — the agent NEVER signs), read balances/portfolio/trade-history, and manage API keys. The agent needs only HTTPS + an API key — no web3 libraries, no private keys, no RPC.
