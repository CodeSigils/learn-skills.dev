Комплексный конвейер для добавления коротких анимированных наложений B-roll к записи экрана ScreenKite с использованием расширенного макета сцены DSL. Транскрибирует звук микрофона с помощью ElevenLabs Scribe, корректирует названия продуктов с помощью веб-поиска, планирует краткие визуальные моменты в угловом изображении, генерирует каждый визуальный элемент с помощью гиперкадров (HTML + GSAP) с помощью параллельных субагентов, выполняет рендеринг в MP4 и компонует с помощью setSceneLayout от ScreenKite с переходами MagicMove. Используйте, когда (1) пользователь открывает или ссылается на запись .skbundle ScreenKite и хочет использовать анимированные акценты B-ролика поверх экрана + камеры, (2) пользователь говорит «добавить B-ролл», «расширенный макет», «наложение визуальных эффектов», «запланировать визуальные эффекты для этой записи», «ScreenKite DSL», (3) пользователь хочет визуальное планирование на основе стенограммы, где визуальные эффекты представляют собой краткие угловые акценты, а не полнокадровые дубли.
