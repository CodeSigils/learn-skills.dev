Capacità di integrazione di React per la gestione degli utenti one-shot di EmblemAI. Da utilizzare quando l'utente desidera aggiungere l'autenticazione del sito Web e gli utenti abilitati al portafoglio a un'app React con EmblemAuthProvider, ConnectButton, accesso social/e-mail/portafoglio, componenti di chat, hook di autenticazione React, modelli di composizione React o hook React Migrate.fun.
