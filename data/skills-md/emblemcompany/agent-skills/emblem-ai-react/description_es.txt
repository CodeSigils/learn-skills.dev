Habilidad de integración de React para la gestión de usuarios de una sola vez de EmblemAI. Úselo cuando el usuario desee agregar autenticación de sitio web más usuarios habilitados para billetera a una aplicación React con EmblemAuthProvider, ConnectButton, inicio de sesión social/correo electrónico/billetera, componentes de chat, enlaces de autenticación de React, patrones de composición de React o enlaces de React de Migrate.fun.
