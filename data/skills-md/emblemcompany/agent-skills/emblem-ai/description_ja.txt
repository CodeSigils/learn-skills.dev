アプリのワンショット ユーザー管理、マルチチェーン ウォレット認証、AI を活用したアシスタント、AI アプリ イントロスペクション。ユーザーがウェブサイトのユーザーにウォレット、電子メール/パスワード、またはソーシャル ログインを使用してサインインさせ、各ユーザーにウォレット対応アカウントを与え、その後 EmblemAI チャット サーフェスを埋め込んだり、プラグインを接続したり、再帰オブザーバビリティを追加したりする場合に使用します。 React コンポーネント、TypeScript SDK、セッションベースの認証、および特殊なワークフローのための React およびエージェント ウォレット スキルへのポインタを提供します。
