Шаблон безопасности для делегирования криптографических операций и управления ключами внешней службе. Используйте при проектировании систем, которые не должны напрямую обладать криптографическими ключами. Реализация шаблона управления криптографическими ключами. Примеры включают хранилище ключей Android, цепочку ключей iOS, AWS KMS, Azure Key Vault, Google Cloud KMS. Снижает риск утечки ключей и неправильной конфигурации шифрования.
