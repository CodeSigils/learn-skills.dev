Anti-modèle de sécurité pour les vulnérabilités d’extension de longueur de hachage (CWE-328). À utiliser lors de la génération ou de la révision de code qui utilise un hachage (secret + message) pour l'authentification, les signatures API ou la vérification de l'intégrité. Détecte les utilisations abusives du hachage Merkle-Damgard.
