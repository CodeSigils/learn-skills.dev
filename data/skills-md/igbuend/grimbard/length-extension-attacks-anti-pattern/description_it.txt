Anti-pattern di sicurezza per le vulnerabilità dell'estensione della lunghezza hash (CWE-328). Da utilizzare durante la generazione o la revisione del codice che utilizza l'hash (segreto + messaggio) per l'autenticazione, le firme API o la verifica dell'integrità. Rileva l'uso improprio dell'hash Merkle-Damgard.
