Sicherheitsmuster für eigenständige Token-Authentifizierung (z. B. JWT). Verwenden Sie es, wenn Sie eine zustandslose Authentifizierung implementieren, Token mit eingebetteten Ansprüchen entwerfen oder Systeme erstellen, bei denen Token Hauptinformationen enthalten und ohne serverseitige Speicherung überprüft werden können. Spezialisierung auf Authentifizierungsmuster.
