Шаблон безопасности для аутентификации с помощью автономного токена (например, JWT). Используйте при реализации аутентификации без отслеживания состояния, разработке токенов со встроенными утверждениями или создании систем, в которых токены содержат основную информацию и могут быть проверены без хранилища на стороне сервера. Специализация шаблона аутентификации.
