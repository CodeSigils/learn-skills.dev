Sicherheits-Anti-Pattern zum Timing von Seitenkanal-Schwachstellen (CWE-208). Wird zum Generieren oder Überprüfen von Code verwendet, der Geheimnisse, Token, Passwörter oder kryptografische Werte vergleicht. Erkennt Early-Exit-Vergleiche, bei denen aufgrund von Zeitunterschieden Informationen verloren gehen.
