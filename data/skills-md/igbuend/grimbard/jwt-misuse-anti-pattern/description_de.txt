Sicherheits-Anti-Pattern für JWT-Missbrauchsschwachstellen (CWE-287). Wird zum Generieren oder Überprüfen von Code verwendet, der JSON-Web-Tokens erstellt, validiert oder verwendet. Erkennt „keine“ Algorithmusangriffe, schwache Geheimnisse, vertrauliche Daten in Nutzdaten und fehlendes Ablaufdatum.
