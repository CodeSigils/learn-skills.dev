Anti-modèle de sécurité pour les vulnérabilités d'utilisation abusive de JWT (CWE-287). À utiliser lors de la génération ou de la révision de code qui crée, valide ou utilise des jetons Web JSON. Détecte les attaques d'algorithme « aucune », les secrets faibles, les données sensibles dans les charges utiles et les expirations manquantes.
