Шаблон безопасности для шифрования определенных данных перед передачей. Используйте, когда только определенные элементы данных нуждаются в шифровании, реализуя шифрование на уровне поля для передачи или когда субъекты должны активно управлять решениями о шифровании. Устранена проблема «Запрос на действие по утечке или передача данных».
