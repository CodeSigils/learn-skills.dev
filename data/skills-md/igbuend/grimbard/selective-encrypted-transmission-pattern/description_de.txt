Sicherheitsmuster zur Verschlüsselung bestimmter Daten vor der Übertragung. Verwenden Sie diese Option, wenn nur bestimmte Datenelemente verschlüsselt werden müssen, eine Verschlüsselung auf Feldebene für die Übertragung implementiert wird oder wenn Entitäten Verschlüsselungsentscheidungen aktiv verwalten müssen. Behebt das Problem „Aktionsanforderung oder Daten während der Übertragung durchsickern“.
