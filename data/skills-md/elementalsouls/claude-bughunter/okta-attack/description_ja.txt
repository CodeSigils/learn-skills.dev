IdP としての Okta レッドチームの攻撃チェーン — テナントの検出、ユーザーの列挙 (複数のベクトル)、認証フロー分析 (要素の列挙、プッシュ通知疲労、SMS バイパス)、ロックアウト規律を伴うパスワード スプレー、Okta 固有のフィッシング プリミティブ (キット、FastPass の悪用、OIDC redirect_uri 改ざん)、MFA の列挙、侵害後の管理 API サーフェス。多くの企業組織では、Entra ID の代わりに (または Entra ID と一緒に) Okta を使用しています。明確なエンドポイント、明確な律速、明確な因子フロー。 Recon で「<tenant>.okta.com」、「<tenant>.okta-emea.com」、「<tenant>.oktapreview.com」、または Okta IdP を指す自動検出スタイルのレコードが表示される場合に使用します。
