Vulnerabilidades específicas de Hunt Spring Boot: puntos finales del actuador (heapdump, env, registradores, asignaciones, apagado), inyección de Spring Expression Language (SpEL) → RCE, consola H2 RCE, exposición a Jolokia JMX, Spring4Shell (CVE-2022-22965), Spring Cloud Function SPEL (CVE-2022-22963), extracción de credenciales de volcado de montón. Úselo cuando el destino ejecuta Spring Boot: se detecta a través del encabezado X-Application-Context, /actuator, página de error Whitelabel o seguimientos de pila de Java.
