ثغرات أمنية معينة في Hunt Spring Boot - نقاط نهاية المشغل (heapdump، env، المسجلات، التعيينات، إيقاف التشغيل)، حقن لغة Spring Expression Language (SpEL) → RCE، H2 console RCE، التعرض لـ Jolokia JMX، Spring4Shell (CVE-2022-22965)، Spring Cloud Function SPEL (CVE-2022-22963)، استخراج بيانات اعتماد تفريغ الكومة. يُستخدم عندما يقوم الهدف بتشغيل Spring Boot - يتم اكتشافه عبر رأس X-Application-Context، أو /actuator، أو Whitelabel Error Page، أو تتبعات مكدس Java.
