Vulnerabilità specifiche di Hunt Spring Boot: endpoint attuatore (heapdump, env, logger, mappature, shutdown), iniezione Spring Expression Language (SpEL) → RCE, console H2 RCE, esposizione Jolokia JMX, Spring4Shell (CVE-2022-22965), Spring Cloud Function SPEL (CVE-2022-22963), estrazione credenziali heap dump. Da utilizzare quando la destinazione esegue Spring Boot: rilevato tramite l'intestazione X-Application-Context, /actuator, pagina di errore Whitelabel o analisi dello stack Java.
