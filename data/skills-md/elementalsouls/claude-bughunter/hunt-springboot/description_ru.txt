Hunt Spring Boot специфические уязвимости — конечные точки исполнительного механизма (дампы памяти, env, регистраторы, сопоставления, выключение), внедрение Spring Expression Language (SpEL) → RCE, консоль H2 RCE, воздействие Jolokia JMX, Spring4Shell (CVE-2022-22965), Spring Cloud Function SPEL (CVE-2022-22963), извлечение учетных данных из дампа кучи. Используйте, когда цель запускает Spring Boot — обнаруживается через заголовок X-Application-Context, /actuator, страницу ошибок Whitelabel или трассировку стека Java.
