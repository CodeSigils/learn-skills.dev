Cerca l'iniezione di modelli lato server (SSTI) su Jinja2 (Flask/Django), Twig (Symfony), Freemarker (Java), ERB (Rails), Spring, Velocity, Mako, Thymeleaf, Smarty. Le sonde di rilevamento utilizzano espressioni matematiche double-curly e dollaro-curly valutate lato server. Una volta rilevata l'impronta digitale di un motore, passare a RCE tramite il class walker, il callback-registrar o i modelli di utilità Execute specifici del motore documentati nei report divulgati. Modelli di rilevamento: i messaggi di errore rivelano il motore, la valutazione vuota o numerica rivela la modalità di espressione. Obiettivi: modelli di posta elettronica, generatori di PDF/report, funzionalità di anteprima CMS, pagine di errore con input dell'utente. Da utilizzare durante la ricerca di RCE tramite il rendering del modello, quando il contenuto mostra le impronte digitali del motore, quando si trovano endpoint che compongono stringhe con l'input dell'utente prima del rendering.
