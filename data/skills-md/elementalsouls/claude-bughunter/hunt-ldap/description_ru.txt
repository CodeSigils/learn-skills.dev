Поиск LDAP-инъекций и XPath-инъекций — обход аутентификации, слепая посимвольная фильтрация атрибутов, перечисление пользователей/групп AD, обход XPath в XML-хранилище. Охватывает набор специальных символов LDAP (* ( ) \ NUL /), контекст фильтра поиска и внедрение DN, балансировку скобок, логику фильтра И/ИЛИ и удаление пароля пользователя {SSHA}/{CRYPT} в каталогах, не относящихся к AD. Используйте, когда цель использует аутентификацию LDAP/AD, корпоративный единый вход с серверной частью каталога, API адресной книги/поиска людей или хранилища данных на основе XML, запрашиваемые с помощью XPath.
