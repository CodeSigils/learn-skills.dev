Hunt LDAP Injection et XPath Injection – contournement d’authentification, exfiltration aveugle d’attributs caractère par caractère, énumération d’utilisateurs/groupes AD, contournement XPath du magasin XML. Couvre le jeu de caractères spéciaux LDAP (* ( ) \ NUL /), le contexte de filtre de recherche par rapport à l'injection DN, l'équilibrage des parenthèses, la logique de filtre AND/OR et l'exfil de mot de passe utilisateur {SSHA}/{CRYPT} sur les répertoires non AD. À utiliser lorsque la cible utilise l'authentification LDAP/AD, l'authentification unique d'entreprise avec un backend d'annuaire, une API de carnet d'adresses/de recherche de personnes ou des magasins de données XML interrogés avec XPath.
