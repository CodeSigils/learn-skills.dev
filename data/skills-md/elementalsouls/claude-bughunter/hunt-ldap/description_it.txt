Hunt LDAP Injection e XPath Injection: bypass dell'autenticazione, esfiltrazione cieca degli attributi carattere per carattere, enumerazione di utenti/gruppi AD, bypass XPath dell'archivio XML. Copre il set di caratteri speciali LDAP (* ( ) \ NUL /), contesto del filtro di ricerca rispetto all'iniezione DN, bilanciamento delle parentesi, logica del filtro AND/OR ed estrazione della password utente {SSHA}/{CRYPT} su directory non AD. Da utilizzare quando la destinazione utilizza l'autenticazione LDAP/AD, SSO aziendale con un backend di directory, un'API per rubrica/ricerca persone o archivi dati basati su XML interrogati con XPath.
