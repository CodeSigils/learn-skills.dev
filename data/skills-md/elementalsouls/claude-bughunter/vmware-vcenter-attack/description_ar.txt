مصفوفة الهجوم الخارجي لـ VMware vSphere / vCenter Server - بصمة الإصدار، وسلسلة CVE عالية التأثير (CVE-2021-21972 vRealize unauth file upload، CVE-2021-21985 vSAN plugin RCE، CVE-2022-22954 Workspace ONE SSTI، CVE-2023-20887 Aria RCE، CVE-2024-37085 تجاوز ESXi AD، CVE-2024-22273 Aria SSRF)، بيانات الاعتماد الافتراضية، الكشف عن تكوين SSO، تعداد vmdir LDAP، سجل ESXi Open SLP RCE. فقط لمثيلات vCenter / Workspace ONE / Aria المعرضة للإنترنت - vCenter للشبكة الداخلية خارج النطاق وفقًا للحدود الخارجية فقط. يُستخدم عندما يُظهر recon المنفذ 443 مع شعار vCenter أو إعادة التوجيه `/ui` أو `/websso/SAML2/Metadata` أو بصمات منتجات VMware.
