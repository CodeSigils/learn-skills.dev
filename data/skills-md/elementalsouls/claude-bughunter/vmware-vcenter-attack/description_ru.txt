Матрица внешних атак на VMware vSphere / vCenter Server — снятие отпечатков версий, высокоэффективная цепочка CVE (CVE-2021-21972 vRealize загрузка файла unauth, CVE-2021-21985 плагин vSAN RCE, CVE-2022-22954 Workspace ONE SSTI, CVE-2023-20887 Aria RCE, CVE-2024-37085 Обход ESXi AD, CVE-2024-22273 Aria SSRF), учетные данные по умолчанию, раскрытие конфигурации SSO, перечисление vmdir LDAP, история ESXi Open SLP RCE. ТОЛЬКО для экземпляров vCenter/Workspace ONE/Aria, подключенных к Интернету — vCenter внутренней сети выходит за рамки границ, установленных только для внешней сети. Используйте, когда разведка показывает порт 443 с баннером vCenter, перенаправлением `/ui`, `/websso/SAML2/Metadata` или отпечатками продуктов VMware.
