Сквозной конвейер Red-Team для Android APK — автоматическое получение APK (Play Store + apkpure + запасной вариант apkmirror), декомпиляция jadx, grep secret/URL/JWT/Firebase, извлечение закрепленных сертификатов, перечисление экспортированных компонентов, шаблоны инструментов среды выполнения Frida, пробы внедрения намерений. Создано на основе авторизованного внешнего взаимодействия с красной командой, в ходе которого 7 APK-файлов были извлечены вручную, 4 попытки загрузки были сокращены, а из одного из приложений были восстановлены жестко запрограммированные конечные точки внутреннего API JWT + 30. Используйте, когда у цели есть каталог мобильных приложений (страница разработчика Play Store), когда вы обнаруживаете URL-адрес APK, размещенный на веб-сервере, или когда после рекогносцировки в области видимости упоминается «мобильное приложение».
