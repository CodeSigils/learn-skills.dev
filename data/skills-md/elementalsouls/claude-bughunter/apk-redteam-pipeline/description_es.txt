Canalización del equipo rojo de APK de Android de extremo a extremo: adquisición automatizada de APK (Play Store + apkpure + respaldo de apkmirror), descompilación de jadx, grep secreto/URL/JWT/Firebase, extracción de certificados anclados, enumeración de componentes exportados, plantillas de instrumentación de tiempo de ejecución de Frida, sondas de inyección de intención. Creado a partir de un compromiso externo autorizado del equipo rojo donde se extrajeron 7 APK manualmente, se truncaron 4 intentos de descarga y se recuperaron un JWT codificado + 30 puntos finales API internos de una de las aplicaciones. Úselo cuando el objetivo tenga un catálogo de aplicaciones móviles (página de desarrollador de Play Store), cuando encuentre una URL de APK alojada en un servidor web o cuando después del reconocimiento mencione "aplicación móvil" en el alcance.
