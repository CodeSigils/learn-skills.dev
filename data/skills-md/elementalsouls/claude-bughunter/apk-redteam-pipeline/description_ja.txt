エンドツーエンドの Android APK レッドチーム パイプライン — 自動 APK 取得 (Play ストア + apkpure + apkmirror フォールバック)、jadx 逆コンパイル、secret/URL/JWT/Firebase grep、ピン留めされた証明書の抽出、エクスポートされたコンポーネントの列挙、Frida ランタイム インストルメンテーション テンプレート、インテント インジェクション プローブ。これは、7 つの APK が手動で取得され、4 回のダウンロード試行が切り詰められ、ハードコードされた JWT + 30 の内部 API エンドポイントがアプリの 1 つから復元された、承認された外部レッドチームの取り組みから構築されました。ターゲットにモバイル アプリ カタログ (Play ストア開発者ページ) がある場合、Web サーバーでホストされている APK URL を見つけた場合、または調査後のスコープで「モバイル アプリ」が言及されている場合に使用します。
