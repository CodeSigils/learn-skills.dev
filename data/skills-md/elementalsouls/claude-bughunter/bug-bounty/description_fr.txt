Workflow complet de bug bounty — reconnaissance (énumération de sous-domaines, découverte d'actifs, empreintes digitales, portée HackerOne, audit du code source), apprentissage préalable (rapports divulgués, recherche de pile technologique, cartes mentales, modélisation des menaces), recherche de vulnérabilités (IDOR, SSRF, XSS, contournement d'authentification, CSRF, conditions de concurrence, SQLi, XXE, téléchargement de fichiers, logique métier, GraphQL, contrebande HTTP, empoisonnement du cache, OAuth, canaux latéraux de synchronisation, OIDC, SSTI, prise de contrôle de sous-domaine, mauvaise configuration du cloud, chaînes ATO, IA agentique), tests de sécurité LLM/AI (IDOR de chatbot, injection rapide, injection indirecte, contrebande ASCII, canaux exfil, RCE via des outils de code, extraction d'invite système, ASI01-ASI10), chaînage de bogues A à B (IDOR → contournement d'authentification, SSRF → métadonnées cloud, XSS → ATO, redirection ouverte → vol OAuth, S3 → bundle → secret → OAuth), tables de contournement (contournement IP SSRF, contournement de redirection ouverte, contournement de téléchargement de fichiers), grep spécifique au langage (pollution du prototype JS, pickle Python, jonglerie de type PHP, Go template.HTML, Ruby YAML.load, Rust unwrap) et reporting (7-Question Gate, 4 portes de validation, écriture de ton humain, modèles par classe vuln, CVSS 3.1, génération PoC, toujours rejeté liste, table de chaîne conditionnelle, liste de contrôle de soumission). À utiliser pour TOUTE tâche de bug bounty : démarrer une nouvelle cible, effectuer une reconnaissance, rechercher des vulnérabilités spécifiques, auditer le code source, tester les fonctionnalités de l'IA, valider les résultats ou rédiger des rapports. 中文触发词：漏洞赏金、安全测试、渗透测试、漏洞挖掘、信息收集、 Logiciels XSS, SQL et SSRF
