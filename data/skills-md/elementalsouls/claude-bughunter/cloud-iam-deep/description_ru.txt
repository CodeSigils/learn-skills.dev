Цепочка атак красной команды Cloud IAM на AWS, Azure, GCP — сосредоточена на ВНЕШНИХ путях эксплуатации и анализе привилегий после обнаружения учетных данных. Охватывает перечисление IAM (aws iam, az role, gcloud iam), цепочку STS/AssumeRole, злоупотребление управляемыми удостоверениями Azure (через SSRF/утечку), злоупотребление JSON сервисной учетной записи GCP, атаки IMDSv1/v2 через SSRF, удаление токена K8s ServiceAccount, запутанную политику ролей-доверия, перечисление предполагаемых ролей между учетными записями, шаблоны повышения привилегий IAM (24+ AWS, 8+ Azure, 6+ GCP). Создан для случая, когда разведка дает учетные данные (ключ, JSON, токен), и вам нужно знать, что она предоставляет и как их расширить. Используйте, когда ключ AWS/секрет Azure/служебный аккаунт GCP JSON/токен SA K8s появляется из репозитория кода, пакета JS, APK, корпуса нарушений или цепочки SSRF.
