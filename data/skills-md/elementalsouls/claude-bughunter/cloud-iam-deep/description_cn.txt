跨 AWS、Azure、GCP 的 Cloud IAM 红队攻击链 — 重点关注外部利用路径和凭证发现后特权分析。涵盖 IAM 枚举（aws iam、az role、gcloud iam）、STS/AssumeRole 链接、Azure 托管身份滥用（通过 SSRF/泄漏）、GCP 服务账户 JSON 滥用、通过 SSRF 的 IMDSv1/v2 攻击、K8s ServiceAccount 令牌 exfil、角色信任策略混淆代理、跨账户假设角色枚举、IAM 权限升级模式（24+ AWS、 8+ Azure、6+ GCP）。专为 recon 生成凭证（密钥、JSON、令牌）的情况而构建，您需要知道它授予什么以及如何升级。当 AWS 密钥/Azure 密钥/GCP 服务帐户 JSON/K8s SA 令牌从代码存储库、JS 捆绑包、APK、违规语料库或 SSRF 链出现时使用。
