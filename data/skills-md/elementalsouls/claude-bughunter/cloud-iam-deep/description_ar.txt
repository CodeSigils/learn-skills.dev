سلسلة هجمات الفريق الأحمر Cloud IAM عبر AWS وAzure وGCP - تركز على مسارات الاستغلال الخارجية وتحليل امتيازات ما بعد اكتشاف بيانات الاعتماد. يغطي تعداد IAM (aws iam، az role، gcloud iam)، وتسلسل STS/AssumeRole، وإساءة استخدام الهوية المُدارة من Azure (عبر SSRF/تسرب)، وإساءة استخدام حساب خدمة GCP JSON، وهجمات IMDSv1/v2 عبر SSRF، وملف رمز مميز لـ K8s ServiceAccount، ونائب مرتبك لسياسة الثقة في الأدوار، وتعداد الأدوار عبر الحسابات، وأنماط تصعيد امتيازات IAM (24+ AWS، 8+ Azure، 6+ GCP). مصمم للحالة التي ينتج فيها recon بيانات اعتماد (مفتاح، JSON، رمز مميز) وتحتاج إلى معرفة ما يمنحه وكيفية تصعيده. يُستخدم عندما يظهر رمز JSON / K8s SA المميز لحساب خدمة GCP لمفتاح AWS / Azure Secret / GCP من مستودع التعليمات البرمجية، أو حزمة JS، أو APK، أو مجموعة الاختراق، أو سلسلة SSRF.
