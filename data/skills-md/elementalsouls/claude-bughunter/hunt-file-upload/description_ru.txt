Поиск ошибок загрузки файлов — RCE через веб-шелл, XSS через SVG/HTML, SSRF через XXE в DOCX, обход пути через имя файла. Таблицы обхода (10 методов): двойное расширение (shell.php.jpg, если сервер проверяет только последний ext), подмена магических байтов (заголовок PNG на PHP), нулевой байт (shell.php .jpg), регистр (PHP, .Php, .pHP), загрузка .htaccess для включения выполнения, SVG с <script>, HTML/SVG XSS, DOCX со встроенным XXE, ZIP-слип (../../../etc/passwd в архиве), полиглотные файлы. Обнаружение: любая /upload, /avatar, /profile-picture, /attachment, /import конечная точка. Тест: загрузите оболочки PHP/JSP/ASPX, запросите через прямой URL-адрес, проверьте ответ. Проверка: фактическое выполнение кода (вывод whoami) для RCE; отражен XSS в URL-адресе фотографии профиля. Используйте при тестировании функций загрузки файлов, конечных точек аватара/вложения, функций импорта/экспорта, процессоров XML/DOCX/ZIP. Реальные платные примеры.
