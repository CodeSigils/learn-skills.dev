寻找金融科技特定的 GraphQL 漏洞：资金流动突变（转账、赎回、取款、卡充值）、账本/余额/投资组合查询 IDOR、小数精度和舍入滥用、幂等密钥旁路实现双花、KYC/PII 字段级授权差距以及可通过批量分配实现的管理覆盖突变。与 Hunt-graphql 不同，后者拥有通用的 GraphQL 发现和 IDOR/变异方法——该技能拥有当 GraphQL 层位于账本、钱包、支付、银行、经纪或贷款后端前面时引入的增量，其中解析器错误会移动真实资金而不仅仅是泄漏数据。当寻找公开 GraphQL API 的金融科技、银行、支付、钱包、新银行、经纪或贷款目标时，或者当架构/响应包含余额、转账、分类帐、赎回、报价、KYC 或帐户链接字段时使用。
