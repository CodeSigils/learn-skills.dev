尋找金融科技特定的 GraphQL 漏洞：資金流動突變（轉帳、贖回、提款、卡充值）、帳本/餘額/投資組合查詢 IDOR、小數精度和捨入濫用、冪等密鑰旁路實現雙花、KYC/PII 字段級授權差距以及可透過批量分配實現的管理覆蓋突變。與 Hunt-graphql 不同，後者擁有通用的 GraphQL 發現和 IDOR/變異方法——該技能擁有當 GraphQL 層位於賬本、錢包、支付、銀行、經紀或貸款後端前面時引入的增量，其中解析器錯誤會移動真實資金而不僅僅是洩漏數據。當尋找公開 GraphQL API 的金融科技、銀行、支付、錢包、新銀行、經紀或貸款目標時，或當架構/回應包含餘額、轉帳、分類帳、贖回、報價、KYC 或帳戶連結欄位時使用。
