フィンテック特有の GraphQL 脆弱性をハントします: 資金移動の突然変異 (送金、償還、引き出し、カードのチャージ)、元帳/残高/ポートフォリオのクエリ IDOR、小数精度と丸めの不正使用、二重支払いを可能にする冪等性キーのバイパス、KYC/PII フィールド レベルの認証ギャップ、一括割り当て経由で到達可能な管理者オーバーライドの突然変異。汎用の GraphQL 検出および IDOR/ミューテーション手法を所有する Hunt-graphql とは異なります。このスキルは、GraphQL レイヤーが台帳、ウォレット、支払い、銀行取引、仲介、または融資のバックエンドの前に配置されるときに導入されるデルタを所有します。そこでは、リゾルバーのバグにより、単なるデータ漏洩ではなく実際のお金が移動します。 GraphQL API を公開するフィンテック、銀行業務、決済、ウォレット、ネオバンク、証券会社、または融資ターゲットを探す場合、またはスキーマ/応答に残高、転送、元帳、償還、見積書、KYC、またはアカウントリンクフィールドが含まれる場合に使用します。
