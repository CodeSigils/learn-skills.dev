اصطياد ثغرات GraphQL الخاصة بالتكنولوجيا المالية: طفرات حركة الأموال (التحويلات، عمليات الاسترداد، عمليات السحب، تعبئة البطاقات)، معرف الاستعلام عن دفتر الأستاذ/الرصيد/المحفظة، الدقة العشرية وإساءة استخدام التقريب، تجاوز مفتاح العجز الذي يتيح الإنفاق المزدوج، فجوات التفويض على مستوى حقل KYC/PII، وطفرات تجاوز المسؤول التي يمكن الوصول إليها عبر التعيين الجماعي. تختلف عن Hunt-graphql، التي تمتلك منهجية اكتشاف GraphQL العامة ومنهجية IDOR/الطفرة - تمتلك هذه المهارة الدلتا التي يتم تقديمها عندما تكون طبقة GraphQL أمام دفتر الأستاذ أو المحفظة أو المدفوعات أو الخدمات المصرفية أو الوساطة المالية أو الواجهة الخلفية للإقراض، حيث ينقل خطأ المحلل الأموال الحقيقية بدلاً من مجرد تسريب البيانات. يُستخدم عند البحث عن هدف للتكنولوجيا المالية أو الخدمات المصرفية أو المدفوعات أو المحفظة أو البنك الجديد أو الوساطة أو الإقراض الذي يكشف واجهة برمجة تطبيقات GraphQL، أو عندما يتضمن المخطط/الاستجابة حقول الرصيد أو التحويل أو دفتر الأستاذ أو الاسترداد أو الاقتباس أو KYC أو ربط الحساب.
