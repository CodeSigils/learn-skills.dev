Traquez la mauvaise gestion des conditions exceptionnelles : alimentez une entrée mal formée/inattendue d'un point de terminaison (mauvais type, JSON cassé, champ surdimensionné, octet nul) et faites-le échouer OPEN ou fuir les composants internes : une page d'erreur de trace de pile/de framework détaillée qui divulgue les composants internes de l'ORM, les chemins de fichiers du serveur, les versions de bibliothèque ou un traçage de langage. À utiliser sur n'importe quel point de terminaison acceptant les entrées (API JSON, formulaires, paramètres de requête). Moyen-Élevé lorsque la fuite expose une structure interne qui arme une attaque plus profonde.
