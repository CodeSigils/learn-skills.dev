Hunt Insecure Deserialization — سلاسل أدوات Java (ysoserial)، وحقن كائن PHP (phpggc)، وPython Pickle RCE، و.NET BinaryFormatter، وRuby Marshal.load، وJNDI/Log4Shell. يعد RCE عبر إلغاء التسلسل أمرًا بالغ الأهمية دائمًا. يُستخدم عندما يقوم الهدف بتشغيل Java أو PHP serialization أو Python Pickle أو .NET أو Ruby on Rails.
