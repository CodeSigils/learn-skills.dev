ハント HTML インジェクション — ユーザーが指定した入力はサニタイズなしで応答内で生の HTML としてレンダリングされ、攻撃者が任意の HTML タグ (ただし JavaScript である必要はない) を挿入できるようになります。 XSS より重大度は低くなりますが、挿入されたフォームを介したフィッシング、UI 操作、資格情報の収集が可能になります。テキスト表示面 (検索結果、プロフィール フィールド、コメント、エラー メッセージ、フィードバック フォーム) をテストするときに使用します。 JavaScript を実行するマークアップの場合は、hunt-xss にエスカレーションします。
