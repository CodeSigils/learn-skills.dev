Inyección HTML de Hunt: la entrada proporcionada por el usuario se representa como HTML sin procesar en la respuesta sin desinfección, lo que permite a un atacante inyectar etiquetas HTML arbitrarias (pero no necesariamente JavaScript). Menor gravedad que XSS pero permite phishing, manipulación de la interfaz de usuario y recolección de credenciales a través de formularios inyectados. Utilícelo al probar superficies de visualización de texto (resultados de búsqueda, campos de perfil, comentarios, mensajes de error, formularios de comentarios). Para el marcado que ejecuta JavaScript, escale a Hunt-xss.
