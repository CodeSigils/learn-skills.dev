ثغرات Hunt WebSocket — اختطاف WebSocket عبر المواقع (CSWSH)، فقدان/ضعف التحقق من صحة الأصل على مصافحة WS، عدم وجود مصادقة لكل رسالة، التلاعب بالرسائل، تجاوز مساحة الاسم/تفويض الغرفة، وتهريب ترقية طبقة المصافحة. يُستخدم عندما يكون لدى الهدف نقاط نهاية WebSocket (ws:// أو wss://)، أو المقبس.io / SignalR / Phoenix Channels، أو ميزات الوقت الفعلي، أو الدردشة، أو لوحات المعلومات المباشرة، أو الإشعارات، أو منصات التداول.
