Hunt debilidades de almacenamiento de vectores/capa de incrustación en canalizaciones RAG (OWASP LLM08 Vector and Embedding Weaknesses): envenenamiento persistente del corpus que sobrevive entre sesiones y usuarios (a diferencia de la inyección rápida indirecta de un solo disparo, que es propiedad de Hunt-llm-ai), IDOR de base de datos de vectores entre inquilinos (consultas no autenticadas o sin alcance contra Pinecone/Weaviate/Chroma/Milvus/Qdrant/pgvector), fuga de texto fuente/metadatos en resultados de búsqueda de similitud y secuestro de recuperación a través de proximidad de incrustación adversaria ("envenenamiento SEO" para RAG). Objetivos: cualquier aplicación con una base de conocimientos compartida, carga de documentos que alimente un chatbot o un puerto de base de datos vectorial de acceso directo. Validar: una segunda sesión/cuenta limpia debe heredar un resultado envenenado, o un artefacto entre inquilinos debe ser verificable de forma independiente; la confabulación no es un hallazgo, la misma barra que Hunt-llm-ai. Úselo cuando el destino esté respaldado por RAG, exponga un puerto de base de datos vectorial o permita a los usuarios cargar documentos que las consultas de otros usuarios recuperan más tarde.
