Chassez les attaques SAML/SSO. Modèles : XML Signature Wrapping (XSW1-XSW8) – modifier l'assertion tout en gardant la signature valide en déplaçant l'élément signé, injection de commentaires dans NameID (admin@target.com<!--evil-->@attacker.com → certains analyseurs voient admin@target.com), suppression de signature (supprimer entièrement l'élément de signature, le serveur devrait le rejeter mais ne le fait pas), confusion de clé (signée par l'IdP de l'attaquant, acceptée par le SP), non-restriction d'audience validé, attaque par relecture (même assertion acceptée deux fois dans la fenêtre de validité). Outils : extension SAML Raider Burp, samlmagic, manipulation XML manuelle. Détection : tout point de terminaison /saml, /Shibboleth.sso, /sso/saml/, points de terminaison Microsoft ADFS. Valider : prise de contrôle du compte via un NameID modifié, injection du rôle d'administrateur via un AttributeStatement modifié. Exemples réels payants sur Auth0, Okta, Microsoft, implémentations SAML personnalisées. À utiliser lors de la recherche de flux SSO, lorsque SAML AssertionConsumerService est accessible, lors de la chaîne de confiance IdP à l'emprunt d'identité SP.
