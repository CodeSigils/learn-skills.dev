Поиск уязвимостей DOM на стороне клиента — DOM Clobbering (перезапись глобальных переменных JS посредством внедрения HTML), перехват PostMessage (отсутствует проверка происхождения), злоупотребление Service Worker (перехват запросов из сценария того же происхождения), CSS-инъекция/эксфильтрация (селекторы атрибутов → посимвольный токен через OOB), внедрение шаблонов на стороне клиента, опасноSetInnerHTML. Основано на известных публичных исследованиях: Gareth Heyes / PortSwigger DOM-clobbering + DOM-Invader, Michał Bentkowski DOMPurify обходы стирания, jQuery htmlPrefilter XSS (CVE-2020-11022 / CVE-2020-11023), исследование d0nut CSS-exfil. Используйте при поиске DOM-XSS, обходе аутентификации на стороне клиента или краже токена без взаимодействия с сервером.
