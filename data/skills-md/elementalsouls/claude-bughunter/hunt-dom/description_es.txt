Busque vulnerabilidades DOM del lado del cliente: DOM Clobbering (sobrescribe JS global mediante inyección HTML), secuestro de PostMessage (falta verificación de origen), abuso de Service Worker (intercepta solicitudes de secuencias de comandos del mismo origen), inyección/exfiltración de CSS (selectores de atributos → token char-by-char vía OOB), inyección de plantilla del lado del cliente, peligrosamenteSetInnerHTML. Basado en investigaciones públicas nombradas: Gareth Heyes / PortSwigger DOM-clobbering + DOM-Invader, Michał Bentkowski DOMPurify clobbering bypasses, jQuery htmlPrefilter XSS (CVE-2020-11022 / CVE-2020-11023), investigación d0nut CSS-exfil. Úselo cuando busque DOM-XSS, omita la autenticación del lado del cliente o extraiga tokens sin interacción del lado del servidor.
