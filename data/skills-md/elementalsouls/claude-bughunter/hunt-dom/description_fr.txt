Chasser les vulnérabilités DOM côté client - DOM Clobbering (écrasement des globaux JS via injection HTML), détournement de PostMessage (vérification d'origine manquante), abus de Service Worker (interception des demandes d'un script de même origine), injection/exfiltration CSS (sélecteurs d'attributs → jeton char par caractère via OOB), injection de modèle côté client, dangereusementSetInnerHTML. Fondé sur des recherches publiques nommées : Gareth Heyes / PortSwigger DOM-clobbering + DOM-Invader, Michał Bentkowski DOMPurify contournements de cognement, jQuery htmlPrefilter XSS (CVE-2020-11022 / CVE-2020-11023), recherche d0nut CSS-exfil. À utiliser lors de la recherche de DOM-XSS, du contournement d'authentification côté client ou de l'exfiltration de jetons sans interaction côté serveur.
