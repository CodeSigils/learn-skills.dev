Выявляйте сбои криптографии JWT — удаление подписи alg:none и путаница ключей RS256 → HS256, которая позволяет злоумышленнику подделать токен для любого удостоверения личности (например, администратора), не зная секрета. Используйте, когда приложение проверяет подлинность с помощью веб-токена JSON (токен носителя `eyJ...` в заголовке авторизации, файле cookie или ответе на вход). Этот навык ВЛАДЕЕТ подписью/криптоподделкой JWT (алг: нет, путаница ключей, внедрение заголовка kid/jku); Hunt-ato охватывает JWT как один путь ATO, Hunter-auth-bypass охватывает доверие к токенам SSO/SAML, Hunter-api-misconfig охватывает обработку JWT без шифрования. Критически важно, когда поддельный токен предоставляет доступ к данным другого пользователя или конечной точке только для администратора.
