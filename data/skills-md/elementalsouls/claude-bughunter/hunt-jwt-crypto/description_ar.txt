اصطياد حالات فشل تشفير JWT - alg:none - تجريد التوقيع وارتباك المفاتيح RS256 → HS256 الذي يسمح للمهاجم بتزوير رمز مميز لأي هوية (على سبيل المثال، مسؤول) دون معرفة سر. يُستخدم عند مصادقة التطبيق باستخدام JSON Web Token (رمز حامل `eyJ...` في رأس التفويض، أو ملف تعريف الارتباط، أو استجابة تسجيل الدخول). تمتلك هذه المهارة تزوير توقيع/تشفير JWT (alg:none، ارتباك المفتاح، حقن رأس kid/jku)؛ يغطيhunt-ato JWT كمسار ATO واحد، ويغطيhunt-auth-bypass الثقة في رمز SSO/SAML، ويغطيhunt-api-misconfig معالجة JWT غير المشفرة. يعد أمرًا بالغ الأهمية عندما يمنح الرمز المميز الوصول إلى بيانات مستخدم آخر أو نقطة نهاية للمسؤول فقط.
