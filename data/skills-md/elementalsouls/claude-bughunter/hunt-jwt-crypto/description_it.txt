Caccia ai guasti crittografici JWT: alg:none rimozione della firma e confusione delle chiavi RS256→HS256 che consentono a un utente malintenzionato di creare un token per qualsiasi identità (ad esempio un amministratore) senza conoscere un segreto. Da utilizzare quando l'app esegue l'autenticazione con un token Web JSON (un token di connessione `eyJ...` nell'intestazione di autorizzazione, un cookie o una risposta di accesso). Questa abilità PROPRIETÀ la falsificazione di firma/criptovaluta JWT (alg:none, confusione di chiavi, iniezione di intestazione kid/jku); hunt-ato copre JWT come un percorso ATO, hunt-auth-bypass copre l'attendibilità del token SSO/SAML, hunt-api-misconfig copre la gestione JWT non crittografica. Fondamentale quando un token contraffatto concede l'accesso ai dati di un altro utente o a un endpoint riservato all'amministratore.
