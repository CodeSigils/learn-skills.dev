Pipeline di ricognizione Web2: enumerazione dei sottodomini (subfinder, Chaos API, assetfinder), rilevamento host live (dnsx, httpx), scansione degli URL (katana, waybackurls, gau), fuzzing delle directory (ffuf), analisi JS (LinkFinder, SecretFinder), monitoraggio continuo (avvisi di nuovi sottodomini, rilevamento delle modifiche JS, GitHub commit watch). Da utilizzare quando si avvia la ricognizione su qualsiasi destinazione Web2 o quando viene chiesto informazioni sul rilevamento delle risorse, sull'enumerazione dei sottodomini o sulla mappatura della superficie di attacco.
