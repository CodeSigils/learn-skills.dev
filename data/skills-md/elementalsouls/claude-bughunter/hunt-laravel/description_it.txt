Vulnerabilità specifiche di Hunt Laravel: perdita della modalità debug (APP_DEBUG=true espone l'intera traccia dello stack + env vars), accesso non autorizzato al dashboard Laravel Telescope/Horizon, Ignition RCE (CVE-2021-3129), manipolazione di URL firmati, abuso di Queue Worker, assegnazione di massa tramite Eloquent, deserializzazione tramite cookie, esposizione di file .env. Da utilizzare quando la destinazione esegue Laravel (PHP): rilevato tramite X-Powered-By, cookie di sessione Laravel o percorsi /storage/.
