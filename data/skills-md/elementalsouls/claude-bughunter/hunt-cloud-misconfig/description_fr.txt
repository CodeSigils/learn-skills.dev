Traquez les mauvaises configurations du cloud/infrastructure. AWS : compartiments S3 publics (s3 : GetObject anonyme), politiques de compartiment permissives (PutObjectAcl public-write), origine CloudFront exposée, URL de fonction Lambda publique, instantané RDS public, informations d'identification IAM dans les bundles JS, métadonnées AWS accessibles via SSRF. GCP : compartiments GCS publics, services Cloud Run exposés, fuite du compte de service JSON. Azure : conteneurs d'objets blob publics, application de fonction exposée. K8s : kubelet 10250 unauth, etcd 2379, tableau de bord public, API de services publique, service de métadonnées de pod. CI/CD : console Jenkins /script, jeton d'enregistrement GitLab Runner, workflow GitHub Actions avec injection pull_request_target. Conteneur : démon Docker 2375, API Kubernetes anonyme. Détection : dorking ciblé, transparence des certificats, extraction des secrets du bundle JS, analyse des ports pour les ports de service connus. Valider : lecture/écriture/RCE des données réelles. À utiliser lors de la recherche d'une surface d'attaque native du cloud.
