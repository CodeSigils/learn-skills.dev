尋找雲端/基礎架構配置錯誤。 AWS：公用 S3 儲存桶（s3:GetObject 匿名）、寬鬆的儲存桶策略（PutObjectAcl 公用寫入）、公開的 CloudFront 來源、公用 Lambda 函數 URL、公用 RDS 快照、JS 組合包中的 IAM 憑證、可透過 SSRF 存取的公用 RDS 快照、JS 組合包中的 IAM 憑證、可透過 SSRF 存取的資料庫資料。 GCP：公共 GCS 儲存桶、暴露的 Cloud Run 服務、外洩的服務帳戶 JSON。 Azure：公用 blob 容器，公開的 Function App。 K8s：kubelet 10250 unauth、etcd 2379、公共儀表板、公共服務 API、pod 元資料服務。 CI/CD：Jenkins /腳本控制台、GitLab Runner 註冊令牌、帶有 pull_request_target 注入的 GitHub Actions 工作流程。容器：Docker 守護程式 2375，Kubernetes API 匿名。偵測：定向攻擊、憑證透明、JS捆綁包秘密提取、連接埠掃描已知服務連接埠。驗證：實際資料讀取/寫入/RCE。尋找雲端原生攻擊面時使用。
