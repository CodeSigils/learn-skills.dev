مطاردة التكوينات الخاطئة للسحابة/البنية التحتية. AWS: مجموعات S3 العامة (s3:GetObject مجهول)، وسياسات الحاوية المسموح بها (PutObjectAcl public-write)، وأصل CloudFront المكشوف، وعنوان URL لوظيفة Lambda العامة، ولقطات RDS العامة، وبيانات اعتماد IAM في حزم JS، وبيانات تعريف AWS التي يمكن الوصول إليها عبر SSRF. GCP: مجموعات GCS العامة، وخدمات Cloud Run المكشوفة، وحساب الخدمة المسرب JSON. Azure: حاويات blob العامة، وتطبيق الوظائف المكشوف. K8s: kubelet 10250 unauth، etcd 2379، لوحة المعلومات العامة، خدمات API العامة، خدمة البيانات الوصفية pod. CI/CD: وحدة تحكم Jenkins /script، ورمز تسجيل GitLab Runner، وسير عمل GitHub Actions مع حقن pull_request_target. الحاوية: Docker daemon 2375، Kubernetes API مجهول. الكشف: دوركينغ المستهدف، شفافية الشهادة، استخراج سر حزمة JS، فحص المنافذ لمنافذ الخدمة المعروفة. التحقق من الصحة: ​​قراءة / كتابة البيانات الفعلية / RCE. يُستخدم عند صيد سطح الهجوم السحابي الأصلي.
