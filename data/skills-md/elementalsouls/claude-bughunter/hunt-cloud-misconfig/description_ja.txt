クラウド/インフラストラクチャの構成ミスを追跡します。 AWS: パブリック S3 バケット (s3:GetObject anonymous)、寛容バケット ポリシー (PutObjectAcl public-write)、公開された CloudFront オリジン、パブリック Lambda 関数 URL、パブリック RDS スナップショット、JS バンドルの IAM 認証情報、SSRF 経由でアクセス可能な AWS メタデータ。 GCP: パブリック GCS バケット、公開された Cloud Run サービス、漏洩したサービス アカウント JSON。 Azure: パブリック BLOB コンテナー、公開された Function App。 K8s: kubelet 10250 unauth、etcd 2379、ダッシュボード パブリック、サービス API パブリック、ポッド メタデータ サービス。 CI/CD: Jenkins /script コンソール、GitLab Runner 登録トークン、pull_request_target インジェクションを使用した GitHub Actions ワークフロー。コンテナ: Docker デーモン 2375、Kubernetes API 匿名。検出: ターゲットを絞ったドーキング、証明書の透過性、JS バンドルの秘密抽出、既知のサービス ポートのポート スキャン。検証: 実際のデータの読み取り/書き込み/RCE。クラウドネイティブの攻撃対象領域を探索するときに使用します。
