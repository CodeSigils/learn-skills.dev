Pipeline de l'équipe rouge iOS de bout en bout - acquisition IPA (extraction App Store, TestFlight, entreprise/chargement ad hoc), analyse statique de vidage de classe/Hopper/Ghidra, Info.plist + droits + extraction de secret de trousseau, mauvaise configuration de App Transport Security (ATS) + contournement d'épinglage de certificat (frida-ios-dump, objection, SSL Kill Switch 2), détournement de schéma d'URL / Universal Link, énumération de services exportés, instrumentation d'exécution Frida. Compagnon de apk-redteam-pipeline pour le côté iOS d'un catalogue d'applications mobiles. À utiliser lorsque la cible dispose d'une application iOS (liste App Store, lien TestFlight, distribution MDM d'entreprise), lorsqu'une URL IPA est trouvée hébergée sur un serveur Web, ou lorsque la post-reconnaissance mentionne « application iOS » / « application mobile » dans la portée à côté d'un compte de développeur Apple.
