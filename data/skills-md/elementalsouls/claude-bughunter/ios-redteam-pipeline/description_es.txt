Canalización del equipo rojo de iOS de extremo a extremo: adquisición de IPA (extracción de App Store, TestFlight, carga lateral empresarial/ad-hoc), análisis estático de volcado de clases/Hopper/Ghidra, Info.plist + derechos + extracción de secretos de llavero, configuración incorrecta de App Transport Security (ATS) + omisión de fijación de certificados (frida-ios-dump, objeción, SSL Kill Switch 2), esquema de URL/secuestro de enlace universal, enumeración de servicios exportados, tiempo de ejecución de Frida instrumentación. Compañero de apk-redteam-pipeline para el lado iOS de un catálogo de aplicaciones móviles. Úselo cuando el objetivo tenga una aplicación de iOS (lista de App Store, enlace TestFlight, distribución de MDM empresarial), cuando se encuentre una URL de IPA alojada en un servidor web o cuando después del reconocimiento se mencione "aplicación de iOS"/"aplicación móvil" en el alcance junto con una cuenta de desarrollador de Apple.
