ハント ホスト ヘッダー インジェクション — パスワード リセット ポイズニング → ATO、キーなしホスト/X-Forwarded-Host による Web キャッシュ ポイズニング、ルーティング ベースの SSRF (ホストが上流を選択 → クラウド メタデータ/内部サービス)、パス オーバーライド SSRF/ACL バイパス (X-Original-URL/X-Rewrite-URL)、OAuth redirect_uri/issuer ポイズニング、および電子メール内の絶対 URL リンク ポイズニング。 ATO または大量キャッシュ ポイズニングに達すると高から重大になります。公開されたホスト ヘッダーの研究 (PortSwigger の「実用的な Web キャッシュ ポイズニング」+ James Kettle、および古典的なパスワード リセット ポイズニング クラス) に基づいて構築されています。パスワードを忘れた場合のフロー、CDN/リバース プロキシ フロント アプリ、OAuth/OIDC エンドポイント、または電子メール内の絶対 URL 機能で使用します。
