Hunt Host Header Injection — empoisonnement par réinitialisation de mot de passe → ATO, empoisonnement du cache Web via un hôte/X-Forwarded-Host sans clé, SSRF basé sur le routage (l'hôte sélectionne en amont → métadonnées cloud/services internes), contournement SSRF/ACL par remplacement de chemin (X-Original-URL/X-Rewrite-URL), OAuth redirect_uri/émetteur empoisonnement et empoisonnement de lien d'URL absolue dans les e-mails. Élevé à Critique lorsqu'il atteint l'ATO ou un empoisonnement massif du cache. Construit sur la recherche publique sur l'en-tête de l'hôte (PortSwigger « empoisonnement pratique du cache Web » + James Kettle et la classe classique d'empoisonnement de réinitialisation de mot de passe). À utiliser sur n'importe quel flux de mot de passe oublié, application CDN/proxy inverse, point de terminaison OAuth/OIDC ou fonctionnalité d'URL absolue dans l'e-mail.
