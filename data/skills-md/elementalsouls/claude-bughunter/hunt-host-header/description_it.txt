Hunt Host Header Injection: avvelenamento da reimpostazione password → ATO, avvelenamento della cache Web tramite Host/X-Forwarded-Host senza chiave, SSRF basato su routing (l'host preleva upstream → metadati cloud/servizi interni), override SSRF/ACL-bypass (X-Original-URL/X-Rewrite-URL), OAuth reindirizzamento_uri/avvelenamento dell'emittente e avvelenamento del collegamento URL assoluto nelle e-mail. Da elevato a critico quando raggiunge l'ATO o l'avvelenamento della cache di massa. Basato sulla ricerca pubblica sull'intestazione dell'host (PortSwigger 'Avvelenamento pratico della cache web' + James Kettle e la classica classe di avvelenamento della reimpostazione della password). Utilizzabile su qualsiasi flusso di password dimenticata, app CDN/proxy inverso, endpoint OAuth/OIDC o funzionalità URL assoluto nell'e-mail.
