Комплексная методология OSINT для операций внешних красных групп и авторизованных оценок поверхностей атак. Охватывает 5-этапный конвейер разведки (начальное обнаружение, расширение активов, обогащение, анализ подверженности, отчетность), дисциплину графа активов с 29 типами активов, рубрику серьезности (CRITICAL/HIGH/MEDIUM/LOW/INFO), рабочие процессы повышения уверенности, бюджетирование времени, правила сортировки на уровне активов, тактику на основе масштабирования, сопоставление идентичности (Entra/Okta/ADFS/Google/SAML/M365 Teams+SharePoint+OAuth), API и методология карты аутентификации, глубокий анализ JavaScript, поверхность мобильных атак, поверхность облачных атак, корреляция нарушений × идентичности, маркировка обнаруживаемости, зондирование с учетом обнаружения (откат, ротация персон), дисциплина валидатора только для чтения, обход WAF/CDN + обнаружение источника, приоритезация уязвимостей (CVE/EPSS/KEV), планирование фишинговой инфраструктуры + разработка предлогов, шаблоны отправки отчетов об ошибках, шаблоны результатов для клиента с преобразованием рисков, расследование субъектов угроз (вкл. Развороты RU/CN), отслеживание криптовалют, криминалистика изображений/видео, хронолокация. Используйте при планировании или проведении разведки против авторизованных целей, картировании внешней поверхности атаки организации, расследовании физического/субъектного лица, отслеживании криптопотоков, геолокации носителей или выполнении работы по атрибуции.
