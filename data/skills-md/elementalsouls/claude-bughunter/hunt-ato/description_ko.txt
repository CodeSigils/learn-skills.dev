계정 탈취 분류 체계 — ATO로 향하는 9가지 개별 경로와 체인. 경로: (1) 비밀번호 재설정 결함(호스트 헤더 삽입이 토큰을 공격자에게 리디렉션, 예측 가능한 토큰, 리퍼러에서 유출된 토큰, 재설정 링크의 경합 조건), (2) 재인증 없이 이메일 변경, (3) OAuth 계정 링크 CSRF, (4) MFA 우회(hunt-mfa-bypass별), (5) 세션 수정, (6) JWT 조작, (7) 단계 없이 비밀번호 변경(비밀번호 oracle이 포함된 체인), (8) 사회 회복 질문 남용, (9) SSO 하위 도메인 인수. 체인 프리미티브: 쿠키 도난 + 비밀번호 oracle + 누락된 스텝업 = 지속적인 ATO; OAuth 공개 리디렉션 + 리디렉션_uri = 인증 코드 도용 = ATO; OAuth 리디렉션_uri = ATO에서 하위 도메인 인수. 검증: 공격자 A의 세션에서 테스트 계정 B에 대한 실제 계정 탈취 시연. 각 경로에 대한 실제 유료 예시입니다. ATO 체인을 찾을 때, 비밀번호 재설정/이메일 변경/MFA/OAuth/세션을 테스트할 때, 기본 요소를 Critical로 연결할 때 사용합니다.
