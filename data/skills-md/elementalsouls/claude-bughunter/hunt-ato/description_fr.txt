Taxonomie de prise de contrôle de compte Hunt – 9 chemins distincts vers ATO, plus des chaînes. Chemins : (1) failles de réinitialisation du mot de passe (l'injection d'en-tête de l'hôte redirige le jeton vers l'attaquant, jeton prévisible, fuite du jeton dans le référent, condition de concurrence sur le lien de réinitialisation), (2) changement d'e-mail sans ré-authentification, (3) CSRF de lien de compte OAuth, (4) contournement MFA (par hunt-mfa-bypass), (5) correction de session, (6) manipulation JWT, (7) changement de mot de passe sans intensification (chaîne avec oracle de mot de passe), (8) abus de questions de récupération sociale, (9) prise de contrôle du sous-domaine SSO. Primitives de chaîne : vol de cookie + oracle de mot de passe + progression manquante = ATO persistant ; Redirection ouverte OAuth + redirect_uri = vol de code d'authentification = ATO ; prise de contrôle du sous-domaine chez OAuth redirect_uri = ATO. Valider : démonstration réelle de prise de contrôle de compte sur le compte test B à partir de la session de l'attaquant A. De vrais exemples payants pour chaque chemin. À utiliser lors de la recherche de chaînes ATO, lors du test de réinitialisation de mot de passe/changement d'e-mail/MFA/OAuth/session, lors de l'enchaînement de primitives vers Critical.
