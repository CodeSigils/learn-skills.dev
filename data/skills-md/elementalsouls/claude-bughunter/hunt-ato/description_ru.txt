Таксономия захвата учетных записей — 9 различных путей к ATO, а также цепочки. Пути: (1) недостатки сброса пароля (внедрение заголовка хоста перенаправляет токен злоумышленнику, предсказуемый токен, утечка токена в реферере, состояние гонки при ссылке сброса), (2) смена электронной почты без повторной аутентификации, (3) CSRF связи с учетной записью OAuth, (4) обход MFA (для каждого обхода Hunt-MFA), (5) фиксация сеанса, (6) манипулирование JWT, (7) смена пароля без повышения (цепочка с оракулом пароля), (8) злоупотребление вопросами социального восстановления, (9) захват поддомена SSO. Примитивы цепочки: кража файлов cookie + оракул пароля + отсутствие шага = постоянное ATO; Открытое перенаправление OAuth + redirect_uri = кража кода аутентификации = ATO; захват поддомена в OAuth redirect_uri = ATO. Проверка: фактическая демонстрация захвата учетной записи на тестовой учетной записи B из сеанса злоумышленника A. Реальные платные примеры для каждого пути. Используйте при поиске цепочек ATO, при тестировании сброса пароля/смены электронной почты/MFA/OAuth/сеанса, при связывании примитивов с критическими.
