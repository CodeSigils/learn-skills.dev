Caccia all'errata configurazione della sicurezza API: assegnazione di massa, attacchi JWT, inquinamento dei prototipi, CORS, manomissione dei verbi HTTP. Assegnazione di massa: invia {is_admin:true, role:admin, verify:true} su profilo/account/reimposta endpoint: il server si applica ciecamente. JWT: alg=none, forza bruta HMAC debole, attraversamento del percorso del bambino, iniezione JWK, confusione dei token. Inquinamento del prototipo: __proto__ injection in JSON merge / Object.assign / lodash _.merge → il prototipo inquinato raggiunge il sink (RCE nel nodo, XSS nel browser). CORS: carattere jolly con credenziali, origine nulla, regex con acquisizione del sottodominio, controlli dell'origine postMessage. Verbo HTTP: GET-bypass-CSRF, X-HTTP-Method-Override, TRACE abilitato. Rilevamento: risposte API con campi aggiuntivi, JWT nelle intestazioni (decodifica su jwt.io), risposte preflight CORS. Da utilizzare durante la ricerca di configurazioni errate dell'API, difetti JWT, assegnazione di massa, inquinamento dei prototipi, bypass CORS.
