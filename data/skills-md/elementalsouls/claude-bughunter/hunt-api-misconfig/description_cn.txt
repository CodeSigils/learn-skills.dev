Hunt API 安全配置错误 — 批量分配、JWT 攻击、原型污染、CORS、HTTP 动词篡改。批量分配：在配置文件/帐户/重置端点上发送 {is_admin:true, role:admin, verify:true} - 服务器盲目应用。 JWT：alg=none、弱 HMAC 暴力破解、kid 路径遍历、JWK 注入、令牌混淆。原型污染：JSON merge / Object.assign / lodash _.merge 中的 __proto__ 注入 → 污染的原型到达接收器（Node 中的 RCE，浏览器中的 XSS）。 CORS：带凭据的通配符、空源、带子域接管的正则表达式、postMessage 源检查。 HTTP 谓词：GET-bypass-CSRF、X-HTTP-Method-Override、启用 TRACE。检测：带有额外字段的 API 响应、标头中的 JWT（在 jwt.io 上解码）、CORS 预检响应。在寻找 API 错误配置、JWT 缺陷、批量分配、原型污染、CORS 绕过时使用。
