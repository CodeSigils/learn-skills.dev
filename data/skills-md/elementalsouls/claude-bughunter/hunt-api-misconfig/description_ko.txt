헌트 API 보안 구성 오류 — 대량 할당, JWT 공격, 프로토타입 오염, CORS, HTTP 동사 변조. 대량 할당: 프로필/계정/재설정 엔드포인트에 {is_admin:true, role:admin, verify:true}를 보냅니다. 서버는 맹목적으로 적용됩니다. JWT: alg=none, 약한 HMAC 무차별 대입, 하위 경로 순회, JWK 주입, 토큰 혼란. 프로토타입 오염: JSON merge / Object.ass / lodash _.merge에서 __proto__ 주입 → 오염된 프로토타입이 싱크에 도달합니다(노드에서는 RCE, 브라우저에서는 XSS). CORS: 자격 증명이 포함된 와일드카드, null 원본, 하위 도메인 인수가 포함된 정규식, postMessage 원본 확인. HTTP 동사: GET-bypass-CSRF, X-HTTP-Method-Override, TRACE 활성화. 감지: 추가 필드가 포함된 API 응답, 헤더의 JWT(jwt.io에서 디코딩), CORS 실행 전 응답. API 구성 오류, JWT 결함, 대량 할당, 프로토타입 오염, CORS 우회를 찾을 때 사용합니다.
