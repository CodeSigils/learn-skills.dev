Configuración incorrecta de la seguridad de la API de Hunt: asignación masiva, ataques JWT, contaminación de prototipos, CORS, manipulación de verbos HTTP. Asignación masiva: envíe {is_admin:true, role:admin, verificado:true} en el perfil/cuenta/restablecer puntos finales; el servidor se aplica ciegamente. JWT: alg=ninguno, fuerza bruta HMAC débil, recorrido de ruta infantil, inyección JWK, confusión de tokens. Contaminación del prototipo: inyección de __proto__ en JSON merge / Object.assign / lodash _.merge → el prototipo contaminado llega al sumidero (RCE en Node, XSS en el navegador). CORS: comodín con credenciales, origen nulo, expresión regular con toma de control de subdominio, comprobaciones de origen postMessage. Verbo HTTP: GET-bypass-CSRF, X-HTTP-Method-Override, TRACE habilitado. Detección: respuestas API con campos adicionales, JWT en encabezados (decodificar en jwt.io), respuestas de verificación previa CORS. Úselo para buscar configuraciones erróneas de API, fallas de JWT, asignaciones masivas, contaminación de prototipos, omisiones de CORS.
