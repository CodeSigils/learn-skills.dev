Mauvaise configuration de la sécurité de l'API Hunt : affectation de masse, attaques JWT, pollution des prototypes, CORS, falsification des verbes HTTP. Affectation de masse : envoyez {is_admin:true, role:admin, verify:true} sur les points de terminaison de profil/compte/réinitialisation – le serveur s'applique aveuglément. JWT : alg = aucun, force brute HMAC faible, traversée du chemin enfant, injection JWK, confusion des jetons. Pollution du prototype : injection __proto__ en JSON merge / Object.assign / lodash _.merge → le prototype pollué atteint le puits (RCE dans Node, XSS dans le navigateur). CORS : caractère générique avec informations d'identification, origine nulle, regex avec reprise de sous-domaine, vérifications de l'origine postMessage. Verbe HTTP : GET-bypass-CSRF, X-HTTP-Method-Override, TRACE activé. Détection : réponses API avec des champs supplémentaires, JWT dans les en-têtes (décodage sur jwt.io), réponses de contrôle en amont CORS. À utiliser lors de la recherche de erreurs de configuration d'API, de failles JWT, d'affectation de masse, de pollution de prototypes, de contournements CORS.
