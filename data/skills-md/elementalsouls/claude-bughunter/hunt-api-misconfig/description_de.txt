Fehlkonfiguration der Hunt-API-Sicherheit – Massenzuweisung, JWT-Angriffe, Prototypenverschmutzung, CORS, Manipulation von HTTP-Verben. Massenzuweisung: Senden Sie {is_admin:true, Role:admin, verifiziert:true} an Profil-/Konto-/Reset-Endpunkte – der Server wendet blind an. JWT: alg=none, schwache HMAC-Bruteforce, Kid Path Traversal, JWK-Injection, Token-Verwirrung. Prototypenverschmutzung: __proto__-Injektion in JSON merge / Object.assign / lodash _.merge → Der verunreinigte Prototyp erreicht die Senke (RCE im Knoten, XSS im Browser). CORS: Platzhalter mit Anmeldeinformationen, Null-Ursprung, Regex mit Subdomain-Übernahme, PostMessage-Ursprungsprüfungen. HTTP-Verb: GET-bypass-CSRF, X-HTTP-Method-Override, TRACE aktiviert. Erkennung: API-Antworten mit zusätzlichen Feldern, JWTs in Headern (Dekodierung bei jwt.io), CORS-Preflight-Antworten.
