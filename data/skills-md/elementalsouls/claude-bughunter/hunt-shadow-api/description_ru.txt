Выслеживайте теневую/зомби/недокументированную поверхность API (OWASP API9 Improper Inventory Management) — перечисляйте полную историю версий API (пути v1/v2/beta/legacy, управление версиями на основе заголовков и субдоменов), извлекайте и сравнивайте каждую доступную спецификацию OpenAPI/Swagger (включая те, которые можно найти только через Wayback Machine) и поведенчески различайте старые и текущие версии для регрессий аутентификации/ограничения скорости/проверки, а не просто различия в форме ответа. В отличие от Hunter-api-misconfig, который управляет эксплуатацией, если у вас есть спецификация или конечная точка (массовое назначение, JWT, OData, атаки Swagger-chain); отличается от поддомена охоты, которому принадлежит обнаружение на уровне хоста. Этот навык отвечает за сам рабочий процесс инвентаризации версий и поведенческих различий. Используйте, если у цели есть версионные пути API, несколько спецификаций, журнал изменений, ссылающийся на устаревшие конечные точки, или мобильное приложение, жестко запрограммированные внутренние вызовы которого выглядят старше, чем текущее веб-приложение.
