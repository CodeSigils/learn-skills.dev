寻找影子/僵尸/未记录的 API 表面（OWASP API9 不正确的库存管理）——枚举完整的 API 版本历史记录（v1/v2/beta/legacy 路径、基于标头和子域的版本控制）、拉取和区分每个可访问的 OpenAPI/Swagger 规范（包括只能通过 Wayback Machine 找到的规范），以及在行为上区分旧版本与当前版本的身份验证/速率限制/验证回归，而不仅仅是响应形状差异。与 Hunt-api-misconfig 不同，一旦您拥有规范或端点（批量分配、JWT、OData、Swagger-chain 攻击），它就会被利用；与 Hunt-subdomain 不同，后者拥有主机级发现。该技能拥有版本库存和行为差异工作流程本身。当目标具有版本化 API 路径、多个规范、引用已弃用端点的变更日志或硬编码后端调用看起来比当前 Web 应用程序旧的移动应用程序时使用。
