Jagd auf Schatten-/Zombie-/undokumentierte API-Oberflächen (OWASP API9 Improper Inventory Management) – Zählen Sie den vollständigen API-Versionsverlauf auf (v1/v2/beta/Legacy-Pfade, Header- und Subdomain-basierte Versionierung), rufen Sie alle erreichbaren OpenAPI/Swagger-Spezifikationen ab und vergleichen Sie diese (einschließlich derjenigen, die nur über die Wayback Machine auffindbar sind) und unterscheiden Sie alte und aktuelle Versionen verhaltensmäßig nicht nur für Authentifizierungs-/Ratenbegrenzungs-/Validierungsregressionen Unterschiede in der Antwortform. Im Gegensatz zu hunt-api-misconfig, das die Ausnutzung übernimmt, sobald Sie eine Spezifikation oder einen Endpunkt haben (Massenzuweisung, JWT, OData, Swagger-Chain-Angriffe); unterscheidet sich von der Hunt-Subdomain, die über die Erkennung auf Hostebene verfügt. Dieser Skill besitzt den Versionsinventar- und Verhaltensunterschied-Workflow selbst. Verwenden Sie diese Option, wenn das Ziel über versionierte API-Pfade, mehrere Spezifikationen, ein Änderungsprotokoll, das auf veraltete Endpunkte verweist, oder eine mobile App verfügt, deren fest codierte Backend-Aufrufe älter aussehen als die der aktuellen Web-App.
