Caccia shadow/zombi/superficie API non documentate (OWASP API9 Improper Inventory Management): enumera la cronologia completa delle versioni API (percorsi v1/v2/beta/legacy, controllo delle versioni basato su intestazione e sottodominio), estrae e confronta ogni specifica OpenAPI/Swagger raggiungibile (incluse quelle trovabili solo tramite Wayback Machine) e differenzia a livello comportamentale le versioni vecchie rispetto a quelle attuali per regressioni di autenticazione/limite di velocità/convalida anziché semplicemente differenze nella forma della risposta. Distinto da hunt-api-misconfig, che possiede lo sfruttamento una volta che si dispone di una specifica o di un endpoint (assegnazione di massa, JWT, OData, attacchi Swagger-chain); distinto dal sottodominio hunt, che possiede la scoperta a livello di host. Questa competenza possiede lo stesso flusso di lavoro dell'inventario delle versioni e delle differenze comportamentali. Da utilizzare quando la destinazione dispone di percorsi API con versione, specifiche multiple, un log delle modifiche che fa riferimento a endpoint deprecati o un'app mobile le cui chiamate backend codificate sembrano più vecchie di quelle dell'app Web corrente.
