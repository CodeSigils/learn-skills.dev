Caza sombra/zombi/superficie de API indocumentada (OWASP API9 Improper Inventory Management): enumera el historial completo de versiones de API (rutas v1/v2/beta/heredadas, control de versiones basado en encabezados y subdominios), extrae y diferencia todas las especificaciones de OpenAPI/Swagger accesibles (incluidas las que solo se pueden encontrar a través de Wayback Machine) y diferencia por comportamiento las versiones antiguas de las actuales para regresiones de autenticación/límite de velocidad/validación en lugar de solo diferencias en la forma de respuesta. A diferencia de Hunt-api-misconfig, que posee la explotación una vez que se tiene una especificación o punto final (asignación masiva, JWT, OData, ataques Swagger-chain); distinto del subdominio de búsqueda, que posee el descubrimiento a nivel de host. Esta habilidad posee el propio flujo de trabajo de inventario de versiones y diferencias de comportamiento. Úselo cuando el destino tenga rutas de API versionadas, múltiples especificaciones, un registro de cambios que haga referencia a puntos finales obsoletos o una aplicación móvil cuyas llamadas de backend codificadas parezcan más antiguas que las de la aplicación web actual.
