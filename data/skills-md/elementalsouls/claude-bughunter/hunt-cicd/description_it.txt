Caccia alle vulnerabilità della pipeline CI/CD: iniezione del flusso di lavoro GitHub Actions (pull_request_target Pwnrequest + ${{ }}-into-shell), avvelenamento da runner self-hosted, abuso della policy di attendibilità OIDC, lettura di file RCE e CVE-2024-23897 della console di script Jenkins, registrazione del token runner CI GitLab, perdita di file di stato Terraform, perdita di segreti di artefatti/log, divulgazione env-var della pipeline. Da utilizzare quando la destinazione ha un'organizzazione GitHub/GitLab pubblica, dashboard CI esposti (Jenkins/TeamCity/Drone/Argo) o artefatti/immagini di build sono raggiungibili.
