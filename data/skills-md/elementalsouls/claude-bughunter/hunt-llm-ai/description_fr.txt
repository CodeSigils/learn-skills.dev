Chassez les bogues des fonctionnalités LLM/AI : injection rapide, injection indirecte, exfiltration via l'utilisation d'outils, contrebande ASCII, cadre de sécurité de l'IA agentique (ASI01-ASI10). Modèles : injection d'invite directe dans la saisie de l'utilisateur (contourner l'invite du système avec "ignorer les instructions précédentes"), injection indirecte via des documents/pages Web lues par le modèle, contrebande ASCII (bloc de balises Unicode U+E0000-U+E007F invisible pour les humains, visible pour le modèle), exfiltration d'utilisation d'outils (le modèle a un outil fetch_url, l'attaquant injecte une URL, le modèle exfiltre l'historique des discussions), extraction d'invites système (manipuler le modèle pour révéler des instructions cachées), extraction de données d'entraînement, IDOR-via-AI (le modèle lit les données des autres utilisateurs via la confusion des invites du système). Outils : chatbots, points de terminaison RAG, synthèse, copilotes agentiques. Détection : tout point de terminaison basé sur LLM, téléchargement de documents déclenchant le traitement de l'IA, agent autonome doté d'outils. Valider : fuite de données entre utilisateurs, invite du système révélée, exfil d'utilisation de l'outil démontré. À utiliser lors de la recherche de fonctionnalités d'IA, de chatbots, de RAG et de systèmes agents.
