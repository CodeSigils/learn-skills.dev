Поиск ошибок в функциях LLM/ИИ — быстрое внедрение, непрямое внедрение, утечка с помощью инструментов, контрабанда ASCII, агентная система безопасности ИИ (ASI01-ASI10). Шаблоны: прямое внедрение подсказок в пользовательский ввод (обход системного приглашения с помощью «игнорировать предыдущие инструкции»), непрямое внедрение через документы/веб-страницы, которые читает модель, контрабанда ASCII (блок тегов Unicode U+E0000-U+E007F невидим для людей, видим для модели), эксфильтрация с использованием инструментов (модель имеет инструмент fetch_url, злоумышленник вводит URL-адрес, модель удаляет историю чата), извлечение системных подсказок (манипулирование моделью для выявления скрытых инструкций), обучающие данные извлечение, IDOR-через AI (модель считывает данные других пользователей через путаницу в системных подсказках). Инструменты: чат-боты, конечные точки RAG, обобщение, агентные вторые пилоты. Обнаружение: любая конечная точка, поддерживаемая LLM, загрузка документов, запускающая обработку ИИ, автономный агент с инструментами. Проверка: утечка данных между пользователями, обнаружение системного запроса, демонстрация результатов использования инструмента. Используйте при поиске функций ИИ, чат-ботов, RAG, агентских систем.
