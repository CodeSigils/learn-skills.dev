Поиск обхода MFA/2FA — 7 различных шаблонов. (1) MFA не применяется на конфиденциальных конечных точках (смена пароля, изменение электронной почты принимается без запроса MFA), (2) пропуск этапа MFA через прямую навигацию по URL-адресу после входа в систему, (3) воспроизведение токена MFA (один и тот же код принимается дважды), (4) подбор 6-значного OTP без ограничения скорости (10^6 попыток на скорости сервера), (5) состояние гонки при проверке OTP, (6) дамп кода восстановления через /api/me, (7) понижение резервного коэффициента (коэффициент SMS без ограничения скорости). Плюс цепочка: кража файлов cookie + оракул пароля + отсутствие повышения уровня = ATO без проверки MFA. Обнаружение: отслеживание потока аутентификации в Burp, поиск каждого перехода состояний, проверка, является ли MFA управляемым промежуточным программным обеспечением или для каждой конечной точки, проверка энтропии OTP и ограничения скорости при проверке OTP. Проверка: сеанс злоумышленника достигает состояния после MFA. Используйте при поиске обхода аутентификации, потоки MFA объединяют примитивы в цепочку с ATO.
