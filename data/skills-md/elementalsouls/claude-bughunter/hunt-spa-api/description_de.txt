Entdecken Sie die versteckte Backend-API einer Single-Page-App in ihrem öffentlichen JS-Bundle und testen Sie diese API dann auf fehlerhafte Zugriffskontrolle/fehlende Authentifizierung. Eines der ertragsstärksten Web-Spiele in der modernen Aufklärung: SPAs übermitteln ihre gesamte Backend-Routenkarte an den Browser, und der API dahinter fehlt häufig die Authentifizierungs-Middleware, die die Anmeldeseite impliziert. Entstanden aus einem autorisierten Auftrag, bei dem dieses Spiel eine nicht authentifizierte Finanz-API fand, die bei einem ASM-Scan, der Hunderte von „Kritischen“ meldete, völlig übersehen wurde. Wird immer dann verwendet, wenn ein Ziel ein JS-lastiges SPA (React/Vue/Angular/Next), eine „App“/„Konsole“/„Dashboard“/„Portal“-Subdomäne oder einen beliebigen „*api*“-Host in Recon bereitstellt. Durchgesickerte Build-Artefakte (Quellkarten / .env / .git / asset-manifest) sind Eigentum von hunt-source-leak; API-Versionsinventar und Verhaltensunterschiede durch hunt-shadow-api; Dieser Skill umfasst die Zuordnung der Back-End-Routen eines Live-SPA aus seinem JS-Bundle und deren Prüfung auf fehlerhafte Zugriffskontrolle/fehlende Authentifizierung.
