Découvrez l'API backend cachée d'une application d'une seule page à partir de son ensemble JS public, puis testez cette API pour déceler un contrôle d'accès rompu ou une authentification manquante. L'un des jeux Web les plus rentables de la reconnaissance moderne : les SPA envoient l'intégralité de leur carte de route backend au navigateur, et l'API derrière eux manque souvent du middleware d'authentification qu'implique la page de connexion. Construit à partir d'un engagement autorisé dans lequel cette pièce a trouvé une API financière non authentifiée qu'une analyse ASM signalant des centaines de « critiques » a complètement manqué. À utiliser chaque fois qu'une cible dessert un SPA lourd en JS (React/Vue/Angular/Next), un sous-domaine « app »/« console »/« tableau de bord »/« portail », ou tout hôte « *api* » apparaît en reconnaissance. Les artefacts de construction divulgués (cartes sources/.env/.git/asset-manifest) appartiennent à hunt-source-leak ; Inventaire des versions de l'API et différences comportementales par hunt-shadow-api ; cette compétence possède la cartographie des routes backend d'un SPA en direct à partir de son bundle JS et les teste pour un contrôle d'accès cassé/une authentification manquante.
