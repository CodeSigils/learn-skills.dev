シングルページ アプリの非表示のバックエンド API をパブリック JS バンドルから検出し、その API に壊れたアクセス制御や認証の欠如がないかテストします。最新の偵察で最も収益の高い Web プレイの 1 つです。SPA はバックエンド ルート マップ全体をブラウザに送信しますが、その背後にある API には、ログイン ページが示す認証ミドルウェアが欠落していることがよくあります。このプレイは、何百もの「クリティカル」を報告する ASM スキャンが完全に見逃していた未認証の金融 API を発見した、承認されたエンゲージメントに基づいて構築されました。ターゲットが JS を多用する SPA (React/Vue/Angular/Next)、「アプリ」/「コンソール」/「ダッシュボード」/「ポータル」サブドメイン、または任意の `*api*` ホストを提供する場合に使用します。漏洩したビルド アーティファクト (ソース マップ/.env/.git/asset-manifest) は、hunt-source-leak によって所有されます。 Hunt-Shadow-API による API バージョン インベントリと動作の差分。このスキルは、JS バンドルからライブ SPA のバックエンド ルートをマッピングし、壊れたアクセス コントロールや認証の欠如をテストします。
