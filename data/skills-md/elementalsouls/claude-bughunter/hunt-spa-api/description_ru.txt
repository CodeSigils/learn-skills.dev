Откройте для себя скрытый серверный API одностраничного приложения из общедоступного пакета JS, а затем протестируйте этот API на наличие нарушенного контроля доступа или отсутствия аутентификации. Одна из самых эффективных веб-игр в современной разведке — SPA отправляют всю свою внутреннюю карту маршрутов в браузер, а в API, стоящем за ними, часто отсутствует промежуточное программное обеспечение для аутентификации, которое подразумевает страница входа. Создано на основе авторизованного взаимодействия, в ходе которого эта игра обнаружила неаутентифицированный финансовый API, который при сканировании ASM полностью пропустил сотни «критических показателей». Используйте всякий раз, когда цель обслуживает SPA с большим количеством JS (React/Vue/Angular/Next), поддомен «приложение»/«консоль»/«панель мониторинга»/«портал» или любой хост `*api*`, обнаруживаемый при разведке. Утекшие артефакты сборки (исходные карты/.env/.git/assets-manifest) принадлежат компании Hunter-Source-Leak; Инвентаризация версий API и поведенческое различие с помощью Hunter-Shadow-API; этот навык владеет отображением внутренних маршрутов живого SPA из его пакета JS и проверкой их на предмет нарушения контроля доступа/отсутствия аутентификации.
