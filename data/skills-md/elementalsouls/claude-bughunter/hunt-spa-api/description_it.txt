Scopri l'API backend nascosta di un'app a pagina singola dal relativo bundle JS pubblico, quindi testa l'API per il controllo degli accessi interrotto/l'autenticazione mancante. Uno dei giochi web a più alto rendimento nella ricognizione moderna: le SPA inviano l'intera mappa del percorso di backend al browser e all'API dietro di loro spesso manca il middleware di autenticazione implicato dalla pagina di accesso. Costruito da un impegno autorizzato in cui questo gioco ha trovato un'API finanziaria non autenticata che una scansione ASM che segnalava centinaia di "critici" non aveva completamente rilevato. Da utilizzare ogni volta che una destinazione serve una SPA con uso intensivo di JS (React/Vue/Angular/Next), un sottodominio "app"/"console"/"dashboard"/"portale" o qualsiasi host "*api*" viene visualizzato in ricognizione. Gli artefatti di build trapelati (mappe sorgente / .env / .git / asset-manifest) sono di proprietà di hunt-source-leak; Inventario delle versioni API e differenze comportamentali tramite hunt-shadow-api; questa competenza prevede la mappatura dei percorsi di backend di una SPA live dal suo bundle JS e il test per verificare il controllo degli accessi interrotto/l'autenticazione mancante.
