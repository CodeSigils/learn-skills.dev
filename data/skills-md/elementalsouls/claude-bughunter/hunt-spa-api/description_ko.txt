공개 JS 번들에서 단일 페이지 앱의 숨겨진 백엔드 API를 발견한 다음 해당 API에 손상된 액세스 제어/누락된 인증이 있는지 테스트하세요. 현대 정찰에서 가장 높은 수익을 내는 웹 플레이 중 하나입니다. SPA는 전체 백엔드 경로 맵을 브라우저에 제공하며, 그 뒤에 있는 API에는 로그인 페이지에서 암시하는 인증 미들웨어가 누락되는 경우가 많습니다. 이 플레이는 수백 개의 "중요한 사항"을 보고하는 ASM 스캔에서 완전히 누락된 인증되지 않은 금융 API를 발견한 승인된 참여를 통해 구축되었습니다. 대상이 JS가 많은 SPA(React/Vue/Angular/Next), "app"/"console"/"dashboard"/"portal" 하위 도메인 또는 `*api*` 호스트가 정찰에 나타날 때마다 사용하세요. 유출된 빌드 아티팩트(소스 맵/.env/.git/asset-manifest)는 Hunt-source-leak의 소유입니다. Hunt-shadow-api를 통한 API 버전 인벤토리 및 동작 비교; 이 기술은 JS 번들에서 라이브 SPA의 백엔드 경로를 매핑하고 액세스 제어가 손상되거나 인증이 누락되었는지 테스트하는 데 사용됩니다.
