從其公共 JS 套件中發現單頁應用程式的隱藏後端 API，然後測試該 API 是否有損壞的存取控制/缺少身份驗證。現代偵察中收益最高的網路遊戲之一——SPA 將其整個後端路由映射發送到瀏覽器，而其背後的 API 經常缺少登錄頁面暗示的身份驗證中間件。建立在授權參與的基礎上，該遊戲發現了未經身份驗證的金融 API，ASM 掃描報告了數百個「關鍵」完全錯過了。每當目標服務於 JS 密集型 SPA (React/Vue/Angular/Next)、「app」/「console」/「dashboard」/「portal」子網域或任何「*api*」主機出現在 recon 中時，請使用。洩漏的建置工件（來源對應 / .env / .git / asset-manifest）歸 Hunt-source-leak 所有； Hunt-shadow-api 的 API 版本清單和行為差異；此技能擁有從 JS 套件對應即時 SPA 的後端路由並測試它們是否有損壞的存取控制/缺少身分驗證。
