Descubra la API de backend oculta de una aplicación de una sola página desde su paquete JS público y luego pruebe esa API para detectar control de acceso roto o autenticación faltante. Uno de los juegos web de mayor rendimiento en el reconocimiento moderno: los SPA envían todo su mapa de ruta de backend al navegador, y a la API detrás de ellos con frecuencia le falta el middleware de autenticación que implica la página de inicio de sesión. Creado a partir de un compromiso autorizado donde esta obra encontró una API financiera no autenticada que un escaneo de ASM que reportó cientos de "Críticos" pasó por alto por completo. Úselo siempre que un objetivo proporcione un SPA con mucho JS (React/Vue/Angular/Next), un subdominio "aplicación"/"consola"/"tablero"/"portal" o cualquier host `*api*` aparezca en el reconocimiento. Los artefactos de compilación filtrados (mapas fuente/.env/.git/asset-manifest) son propiedad dehunt-source-leak; Inventario de versiones de API y diferenciación de comportamiento por Hunt-shadow-api; Esta habilidad permite mapear las rutas de backend de un SPA en vivo desde su paquete JS y probarlas para detectar control de acceso roto o autenticación faltante.
