Vulnerabilità specifiche di Hunt Next.js: esecuzione di funzioni arbitrarie di Azioni server, bypass di autenticazione del middleware tramite percorsi di risorse statiche, avvelenamento della cache ISR, ottimizzazione delle immagini SSRF (/_next/image), perdita di payload RSC, iniezione getServerSideProps, esposizione della mappa di origine, perdita di endpoint di debug. Da utilizzare quando il target esegue Next.js 13/14/15 o qualsiasi framework React SSR.
