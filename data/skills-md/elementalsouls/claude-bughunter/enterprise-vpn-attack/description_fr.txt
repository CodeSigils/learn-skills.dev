Matrice d'attaque VPN SSL externe/appliance d'accès à distance — Cisco ASA/AnyConnect, Fortinet FortiGate/FortiOS, Citrix NetScaler/ADC, Palo Alto GlobalProtect, Pulse Secure/Ivanti Connect Secure, SonicWall, F5 Big-IP. Couvre les empreintes digitales de version, la matrice CVE (2018-2026), l'identification du backend AAA, les informations d'identification par défaut, les chemins de divulgation de configuration, les exploits RCE/SSRF/path-traversal de pré-authentification, le cas échéant. Construit à partir de tests Cisco ASA avec engagement autorisé et du paysage CVE VPN d'entreprise 2024-2026. À utiliser chaque fois que le périmètre de la cible expose une appliance VPN SSL ou une passerelle d'accès à distance : il s'agit des points d'accès initiaux les plus courants dans les TTP d'acteurs 2024-2026.
