التعامل مع عملية ترخيص تسجيل الدخول DeepScan. يدعم تسجيل الدخول عن طريق مسح رمز الاستجابة السريعة أو عن طريق توفير مفتاح API مباشرة. يتم تشغيله عندما يحتاج المستخدم إلى تسجيل الدخول، أو توفير مفتاح API، أو طلب التفويض قبل الدخول إلى صفحة المسح، أو انتهاء صلاحية الرمز المميز، أو عند الاستخدام الأول.
