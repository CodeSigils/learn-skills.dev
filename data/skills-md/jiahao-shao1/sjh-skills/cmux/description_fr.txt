Orchestration de terminal cmux multi-volets/multi-agents via cmux CLI (Bash ne peut pas diviser les volets ni générer d'agents). À utiliser pour les volets parallèles, les fractionnements, la génération de sous-agents Claude/Codex, l'envoi de clés (y compris ctrl-c) entre les volets, la sortie du volet de lecture, les mises à jour de la barre latérale, les volets de navigateur/markdown. Déclencheurs : "en parallèle", "volet divisé", "agent d'apparition", "fan out", "volet du navigateur", "barre latérale", "分屏", "并行", "volet 开个". Pas pour le bash simple ou le tmux générique.
