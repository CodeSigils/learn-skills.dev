اكتشاف/تصفية/قراءة الأوراق الأكاديمية عبر Scholar Inbox API + Notebooklm-py CLI. استخدم لتصفح أوراق اليوم، والتوصيات، والمعدل/الجمع، والقراءة العميقة عبر NotebookLM، وطرح أسئلة حول الأوراق، والاتجاهات. المشغلات: "صندوق بريد الباحث العلمي"، و"ملخص الورق"، و"看论文"، و"读论文"، و"论文推荐"، و"تقييم الأوراق"، و"今天有什么论文"، و"ورقة قراءة عميقة"، و"帮我筛选论文". ليس لقراءة ملفات PDF، أو المراجعات المضاءة، أو الملاحظات العامة.
