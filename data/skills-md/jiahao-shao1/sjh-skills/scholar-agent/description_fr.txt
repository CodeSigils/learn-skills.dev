Découverte/filtrage/lecture d'articles académiques via l'API Scholar Inbox + CLI notebooklm-py. À utiliser pour parcourir les articles d'aujourd'hui, les recommandations, évaluer/collecter, lire en profondeur via NotebookLM, poser des questions sur les articles et les tendances. Déclencheurs : "boîte de réception universitaire", "résumé papier", "看论文", "读论文", "论文推荐", "évaluer les documents", "今天有什么论文", "lecture approfondie du document", '帮我筛选论文'. Pas pour la lecture de PDF, les critiques éclairées ou les notes générales.
