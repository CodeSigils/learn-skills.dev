Обнаружение/фильтрация/чтение академических статей через Scholar Inbox API + CLI Notebooklm-py. Используйте для просмотра сегодняшних статей, рекомендаций, оценки/сбора, глубокого чтения через NotebookLM, задавайте вопросы о статьях и тенденциях. Триггеры: «входящие для ученого», «бумажный дайджест», «看论文», «读论文», «论文推荐», «оценить статьи», «今天有什么论文», «глубоко прочитанная статья», «帮我筛选论文». Не для чтения PDF-файлов, обзоров или общих заметок.
