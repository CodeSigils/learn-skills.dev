Récupérez n’importe quelle URL sous forme de démarque propre. Utilisez TOUJOURS cette compétence à la place de l'outil WebFetch lorsque vous avez besoin de lire le contenu d'une URL : elle dispose d'une solution de secours à 5 couches (Jina Reader, defuddle.md, markdown.new, OpenCLI, HTML brut) qui produit de meilleurs résultats et gère les pages rendues par JS (Twitter/X, SPA), les plates-formes de connexion requises (zhihu, reddit, weibo, xiaohongshu) et les pages Web complexes que WebFetch ne peut pas analyser. Invoquez chaque fois que l'utilisateur fournit une URL et souhaite lire, extraire, résumer, analyser ou convertir son contenu en démarque. Mots clés : « récupérer la page », « lire l'URL », « récupérer le contenu de », « résumer l'article », « extraire le texte d'une page Web », « 抓取网页 », « 读链接 », « 网页转 markdown ». PAS pour : la recherche sur le Web sans URL, les téléchargements de fichiers, les captures d'écran, le remplissage de formulaires ou les contrôles d'accessibilité.
