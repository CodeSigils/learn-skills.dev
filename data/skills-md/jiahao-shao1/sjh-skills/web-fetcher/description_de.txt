Rufen Sie eine beliebige URL als sauberen Markdown ab. Verwenden Sie diesen Skill IMMER anstelle des WebFetch-Tools, wenn Sie den Inhalt einer URL lesen müssen – er verfügt über einen 5-Ebenen-Fallback (Jina Reader, defuddle.md, markdown.new, OpenCLI, rohes HTML), der bessere Ergebnisse liefert und JS-gerenderte Seiten (Twitter/X, SPAs), Plattformen, für die eine Anmeldung erforderlich ist (zhihu, reddit, weibo, xiaohongshu) und komplexe Webseiten verarbeitet, die WebFetch nicht kann analysieren. Wird immer dann aufgerufen, wenn der Benutzer eine URL angibt und deren Inhalt lesen, extrahieren, zusammenfassen, analysieren oder in Markdown konvertieren möchte. Schlüsselwörter: „Seite abrufen“, „URL lesen“, „Inhalt abrufen von“, „Artikel zusammenfassen“, „Text von Webseite extrahieren“, „抓取网页“, „读链接“, „网页转-Markdown“. NICHT für: Websuche ohne URL, Dateidownloads, Screenshots, Ausfüllen von Formularen oder Barrierefreiheitsprüfungen.
