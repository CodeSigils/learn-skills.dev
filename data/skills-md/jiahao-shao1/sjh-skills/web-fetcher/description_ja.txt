任意の URL をクリーンなマークダウンとしてフェッチします。 URL のコンテンツを読み取る必要がある場合は、WebFetch ツールの代わりに常にこのスキルを使用してください。このスキルには 5 層のフォールバック (Jina Reader、defddle.md、markdown.new、OpenCLI、生の HTML) があり、より良い結果を生成し、JS でレンダリングされたページ (Twitter/X、SPA)、ログインが必要なプラットフォーム (zhihu、reddit、weibo、xiaohongshu)、WebFetch では処理できない複雑な Web ページを処理できます。解析する。ユーザーが URL を提供し、そのコンテンツを読み取り、抽出、要約、分析、またはマークダウンに変換したいときに呼び出します。キーワード: 'ページの取得'、'URL の読み取り'、'コンテンツの取得'、'記事の要約'、'Web ページからのテキストの抽出'、'抓取网页'、'读链接'、'网页转マークダウン'。対象外: URL なしの Web 検索、ファイルのダウンロード、スクリーンショット、フォーム入力、アクセシビリティ チェック。
