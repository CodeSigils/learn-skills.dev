اسأل عنصر المستخدم بندًا عن الخطة أو مواصفات المنتج أو التصميم أو الحل الفني أو خطة التنفيذ أو قرارات الإصدار وقم بتسجيل القرارات. وينطبق هذا عندما يكون للمهمة نطاق أو أولويات أو مقايضات أو مخاطر أو معايير قبول أو تبعيات غير واضحة، أو عندما يستخدم المستخدم كلمات مثل "استجواب" أو "استجواب" أو "اختبار الإجهاد"؛ ولا يجوز استخدامه للاستفسارات الواقعية البحتة أو عمليات الإعدام المؤكدة منخفضة المخاطر.
