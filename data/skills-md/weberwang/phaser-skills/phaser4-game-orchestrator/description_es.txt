Un controlador integral de ciclo completo para juegos 2D móviles creado con Phaser4, TypeScript, Vite y Capacitor. Se utiliza para mover un juego desde el concepto hasta una entrega lista para revisión para minijuegos, iOS, GooglePlay u otros canales de distribución, y para coordinar la planificación de producción, la arquitectura técnica, la jugabilidad, el equilibrio, el arte, el audio, el rendimiento de las pruebas y las funciones de cumplimiento de versiones.
