Función de integración de recursos, producción y diseño artístico de juegos 2D móviles de Phaser4. Es necesario establecer una línea de base visual global, progresando desde una estructura de código de baja fidelidad hasta fondos sin bordes, maquetas de alta fidelidad, revisiones de maquetas, confirmación de selección de una sola imagen, generación final de una sola imagen, registro de recursos y contratos de integración, o realizar una reconstrucción visual limitada por contratos funcionales utilizando capturas de pantalla de referencia, grabaciones de pantalla y código ejecutado; y revisar la funcionalidad relacionada con el juego y el ensamblaje estructurado, las licencias, la usabilidad de Phaser y el rendimiento móvil. Las escenas oficiales, las casas prefabricadas y el código funcional deben modificarse exclusivamente mediante el desarrollo del juego.
