Función de integración de recursos, producción y diseño artístico de juegos 2D para dispositivos móviles Phaser 4. Es necesario establecer una línea de base visual global, avanzando desde estructuras de código de baja fidelidad hasta fondos de bloqueo de bordes, maquetas de alta fidelidad, revisión de maquetas, confirmación de selección de una sola imagen, generación oficial de una sola imagen, registro de recursos y contratos de integración o, basándose en capturas de pantalla de referencia, grabaciones de pantalla y código ejecutado, realizar una reconstrucción visual limitada por contratos funcionales y revisar la funcionalidad y el ensamblaje estructurado completado por los roles de juego, la autorización, la usabilidad de Phaser y el uso del rendimiento móvil; Las escenas oficiales, las casas prefabricadas y el código funcional se modifican exclusivamente mediante el desarrollo del juego.
