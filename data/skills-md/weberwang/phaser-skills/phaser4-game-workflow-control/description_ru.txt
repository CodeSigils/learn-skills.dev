Единственный глобальный интерфейс управления рабочим процессом репозитория игр Phaser 4. Он обрабатывает локальные задачи с низким уровнем риска на основе авторизации задач и детерминированной классификации рисков, различает решения пользователей по разъяснениям и сохраняет точное явное одобрение только для конкретных операций и воздействий A4-A6.
