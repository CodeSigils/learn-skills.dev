Se utiliza para generar mapas de reemplazo para cada región/celda de un atlas de textura/atlas de columna vertebral de Phaser 4, realizar actualizaciones incrementales, reconstruir texturas nuevas o validar que no hay respaldo para texturas antiguas; requiere preservar los rayos UV del esqueleto, el accesorio y la malla, y poder recuperarse de forma segura si alguna célula falla.
