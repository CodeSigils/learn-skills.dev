Manual image asset optimization task for a Phaser 4 project. It should be used only when the user explicitly invokes $phaser4-game-image-optimization, to inventory runtime bitmaps, generate compression candidates, verify visual quality and channel compatibility, and replace them with smaller resources in a rollback‑able manner; it must not be triggered implicitly by the master controller, build, test, release, A1‑to‑A6, or G0‑to‑G3.
