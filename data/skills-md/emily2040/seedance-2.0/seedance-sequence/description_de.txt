Diese Fähigkeit sollte verwendet werden, wenn es sich bei einer Seedance 2.0-Anfrage um eine lange Geschichte, einen zusammenhängenden Satz von Clips, eine Szene mit mehreren Generationen, eine Kampagnensequenz, ein dichtes Storyboard, einen fortsetzungsbereiten Plan oder eine andere Idee handelt, die in zustandsbehaftete Clips unterteilt werden muss.
