Modèle de référentiel dans Kotlin Multiplatform — la couche de données entre la logique de domaine et le stockage/réseau. Couvre : l'interface du référentiel dans :feature:x:api, l'implémentation dans :feature:x:data, la source unique de vérité via SQLDelight Flow, les trois stratégies de récupération (réseau d'abord, cache d'abord, hors ligne d'abord), le mappage NetworkResult-to-domain à la limite du référentiel, les mises à jour optimistes et les erreurs courantes de fuite des types de réseau dans le domaine et d'ignorance du cache local. Nécessite kotlin-multiplatform-network-layer et kotlin-multiplatform-sqldelight-setup.
