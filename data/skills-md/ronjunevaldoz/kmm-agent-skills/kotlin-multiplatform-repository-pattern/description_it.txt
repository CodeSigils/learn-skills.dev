Modello di repository in Kotlin Multiplatform: il livello dati tra la logica del dominio e l'archiviazione/rete. Copre: interfaccia del repository in :feature:x:api, implementazione in :feature:x:data, unica fonte di verità tramite SQLDelight Flow, le tre strategie di recupero (network-first, cache-first, offline-first), mappatura NetworkResult-to-domain al limite del repository, aggiornamenti ottimistici ed errori comuni derivanti dalla perdita di tipi di rete nel dominio e dal salto della cache locale. Richiede kotlin-multiplatform-network-layer e kotlin-multiplatform-sqldelight-setup.
