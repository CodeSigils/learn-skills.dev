Шаблон репозитория в Kotlin Multiplatform — уровень данных между логикой предметной области и хранилищем/сетью. Охватывает: интерфейс репозитория в :feature:x:api, реализацию в :feature:x:data, единый источник достоверной информации через SQLDelight Flow, три стратегии выборки (сначала сеть, сначала кэш, сначала автономно), сопоставление NetworkResult с доменом на границе репозитория, оптимистичные обновления и распространенные ошибки, связанные с утечкой типов сетей в домен и пропуском локального кэша. Требуется kotlin-multiplatform-network-layer и kotlin-multiplatform-sqldelight-setup.
