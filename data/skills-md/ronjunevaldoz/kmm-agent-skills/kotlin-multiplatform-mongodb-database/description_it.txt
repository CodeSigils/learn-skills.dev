Modello di driver MongoDB Kotlin Coroutine per app full-stack multipiattaforma Kotlin. Copre: accesso MongoDB lato server, mappatura dei documenti, limiti del repository, errori del database digitati, letture reattive con Flow, flussi di modifica e uno script di scaffold per la configurazione ripetuta del database. Utilizzalo per il livello dati backend, non per la persistenza del client condiviso.
