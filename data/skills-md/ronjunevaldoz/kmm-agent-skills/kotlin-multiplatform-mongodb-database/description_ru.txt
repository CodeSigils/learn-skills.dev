Шаблон драйвера MongoDB Kotlin Coroutine для полнофункциональных многоплатформенных приложений Kotlin. Охватывает: доступ к MongoDB на стороне сервера, сопоставление документов, границы репозитория, типизированные ошибки базы данных, реактивное чтение с помощью Flow, потоки изменений и сценарий scaffold для повторной настройки базы данных. Используйте это для внутреннего уровня данных, а не для общего сохранения клиента.
