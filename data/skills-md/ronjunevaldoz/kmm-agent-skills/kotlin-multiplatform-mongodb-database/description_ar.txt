نمط برنامج تشغيل MongoDB Kotlin Coroutine لتطبيقات Kotlin Multiplatform الكاملة. يغطي: الوصول إلى MongoDB من جانب الخادم، وتخطيط المستندات، وحدود المستودع، وأخطاء قاعدة البيانات المكتوبة، والقراءات التفاعلية مع التدفق، وتغيير التدفقات، والبرنامج النصي السقالة لإعداد قاعدة البيانات المتكررة. استخدم هذا لطبقة البيانات الخلفية، وليس لاستمرارية العميل المشترك.
