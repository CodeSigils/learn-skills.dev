Configura SQLDelight 2 in un progetto multipiattaforma Kotlin. Copre: configurazione del plug-in Gradle, file di schema (.sq), migrazioni, adattatori di tipo, driver specifici della piattaforma tramite wait/actual (Android, iOS, Desktop/JVM, Web/JS), query di flusso di coroutine e cablaggio Koin all'interno di :core:database. Presuppone che il progetto sia stato impalcato con kotlin-multiplatform-feature-scaffold.
