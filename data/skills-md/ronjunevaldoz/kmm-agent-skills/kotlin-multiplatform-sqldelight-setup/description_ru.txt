Настраивает SQLDelight 2 в многоплатформенном проекте Kotlin. Охватывает: конфигурацию плагина Gradle, файлы схемы (.sq), миграции, адаптеры типов, драйверы для конкретной платформы через ожидаемые/фактические (Android, iOS, Desktop/JVM, Web/JS), запросы сопрограмм Flow и подключение Koin внутри :core:database. Предполагается, что проект был создан с помощью kotlin-multiplatform-feature-scaffold.
