Создает XCFramework из общего многоплатформенного модуля Kotlin и публикует его как двоичный целевой объект Swift Package Manager (SPM). Охватывает: конфигурацию Gradle XCFramework, задачу assembleReleaseXCFramework, локальный SPM Package.swift для разработки, удаленную двоичную цель SPM для распространения (выпуски GitHub) и интеграцию проекта Xcode. Предполагается AGP 9+ и структура проекта из kotlin-multiplatform-feature-scaffold.
