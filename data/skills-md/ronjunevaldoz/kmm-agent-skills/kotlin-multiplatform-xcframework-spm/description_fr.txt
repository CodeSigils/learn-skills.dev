Construit un XCFramework à partir d'un module partagé Kotlin Multiplatform et le publie en tant que cible binaire Swift Package Manager (SPM). Couvre : la configuration Gradle XCFramework, la tâche assembleReleaseXCFramework, le SPM Package.swift local pour le développement, la cible SPM binaire distante pour la distribution (versions GitHub) et l'intégration du projet Xcode. Suppose AGP 9+ et la structure du projet de kotlin-multiplatform-feature-scaffold.
