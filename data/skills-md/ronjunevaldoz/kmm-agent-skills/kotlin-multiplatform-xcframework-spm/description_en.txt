Builds an XCFramework from a Kotlin Multiplatform shared module and publishes it as a Swift Package Manager (SPM) binary target. Covers: Gradle XCFramework configuration, assembleReleaseXCFramework task, local SPM Package.swift for development, remote binary SPM target for distribution (GitHub Releases), and Xcode project integration. Assumes AGP 9+ and the project structure from kotlin-multiplatform-feature-scaffold.
