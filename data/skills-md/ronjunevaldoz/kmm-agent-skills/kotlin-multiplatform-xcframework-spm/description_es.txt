Crea un XCFramework a partir de un módulo compartido multiplataforma de Kotlin y lo publica como un destino binario de Swift Package Manager (SPM). Cubre: configuración de Gradle XCFramework, tarea ensamblarReleaseXCFramework, paquete SPM local.swift para desarrollo, destino SPM binario remoto para distribución (versiones de GitHub) e integración de proyectos Xcode. Asume AGP 9+ y la estructura del proyecto de kotlin-multiplatform-feature-scaffold.
