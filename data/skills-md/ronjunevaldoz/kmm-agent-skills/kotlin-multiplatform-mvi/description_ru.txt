Шаблон архитектуры MVI (Model-View-Intent) для Kotlin Multiplatform + Compose Multiplatform. Охватывает: шаблон контракта (состояние/намерение/эффект на экран), базовый класс MviViewModel с StateFlow для состояния и каналом для одноразовых эффектов, атомарные обновления состояния, разделение экрана и содержимого, тестирование моделей представления с помощью Turbine и наиболее распространенные ошибки MVI в KMP. Ноль новых зависимостей — основан на androidx.lifecycle.ViewModel и kotlinx.coroutines, уже присутствующих в Feature-Scaffold.
