Modèle d'architecture MVI (Model-View-Intent) pour Kotlin Multiplatform + Compose Multiplatform. Couvre : le modèle de contrat (état/intention/effet par écran), la classe de base MviViewModel avec StateFlow pour l'état et Channel pour les effets ponctuels, les mises à jour de l'état atomique, la répartition écran/contenu Compose, le test des ViewModels avec Turbine et les pièges MVI les plus courants dans KMP. Zéro nouvelle dépendance - s'appuie sur androidx.lifecycle.ViewModel et kotlinx.coroutines déjà présents dans l'échafaudage de fonctionnalités.
