Настраивает многоплатформенное хранилище данных для KMP: варианты Preferences (ключ-значение) и Proto (типизированный, управляемый схемой). Охватывает createDataStore {} ожидаемое/фактическое для каждой платформы, чтение на основе потока, запись сопрограммы, миграцию из SharedPreferences и подключение Koin, поэтому функциональные модули никогда не создают DataStore напрямую.
