Рабочий процесс разработки на основе предварительного просмотра (PDD) для KMP: сначала напишите составные элементы контента, выполните итерацию на предварительных просмотрах JVM для настольных компьютеров (в 3–5 раз быстрее, чем Android), охватите все состояния с помощью @PreviewParameterProvider, затем продвигайте предварительные просмотры непосредственно в тесты скриншотов Roborazzi.
