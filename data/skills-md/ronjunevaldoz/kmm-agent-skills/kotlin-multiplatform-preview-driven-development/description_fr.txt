Workflow de développement piloté par aperçu (PDD) pour KMP : écrivez d'abord des composables de contenu, itérez sur les aperçus de la JVM de bureau (3 à 5 fois plus rapide qu'Android), couvrez tous les états avec @PreviewParameterProvider, puis promouvez les aperçus directement vers les tests de capture d'écran Roborazzi.
