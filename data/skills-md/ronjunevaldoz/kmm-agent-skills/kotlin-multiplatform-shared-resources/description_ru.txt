Настраивает Compose Multiplatform Resources (compose-resources) для совместного использования строк, множественного числа, изображений, шрифтов и необработанных файлов во всех целевых объектах KMP (Android, iOS, Desktop, Интернет). Охватывает: структуру каталогов ресурсов, локализацию строк, множественное число, ресурсы изображений, пользовательские шрифты, доступ к ресурсам из составного и некомпонуемого кода, а также настройку модуля ресурсов. Предполагается, что проект был построен с помощью kotlin-multiplatform-feature-scaffold.
