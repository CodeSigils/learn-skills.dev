Определяет шестиуровневый контракт чистой архитектуры для функциональных модулей KMP: :model / :api / :domain / :data / :presenter / :ui. Охватывает правила зависимостей слоев, разделение :model и :api, обеспечение внутренней видимости и функции приспособленности архитектуры Detekt, которые приводят к сбою сборки из-за нарушений.
