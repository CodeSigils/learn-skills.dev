Patrón de servicio de autenticación basado en Ktor para aplicaciones full-stack multiplataforma de Kotlin. Cubre: autenticación de portador y JWT, sesiones cuando las sesiones de estilo navegador con estado son más adecuadas, Ktor RPC cuando el cliente y el servidor son Kotlin primero, errores de autenticación escritos, protecciones de ruta, flujos de actualización/cierre de sesión y un pequeño script de andamio para la configuración repetida del módulo de autenticación. Utilice esto para la autenticación del lado del servidor, no para el estado de autenticación de la interfaz de usuario compartida.
