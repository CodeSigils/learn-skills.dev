Шаблон службы аутентификации на основе Ktor для полнофункциональных многоплатформенных приложений Kotlin. Охватывает: аутентификацию на предъявителя и JWT, сеансы, когда лучше подходят сеансы в стиле браузера с отслеживанием состояния, Ktor RPC, когда клиент и сервер оба работают на Kotlin, типизированные ошибки аутентификации, защиту маршрутов, потоки обновления/выхода и небольшой скрипт scaffold для повторной настройки модуля аутентификации. Используйте это для аутентификации на стороне сервера, а не для состояния аутентификации общего пользовательского интерфейса.
