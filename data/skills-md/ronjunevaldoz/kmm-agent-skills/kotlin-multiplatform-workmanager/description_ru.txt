Планирование фоновых задач для Kotlin Multiplatform — WorkManager (Android) и BGTaskScheduler/BGProcessingTask (iOS) за ожидаемым/фактическим BackgroundScheduler. Охватывает однократную работу, периодическую работу, повторную попытку с отсрочкой, данные ввода/вывода и цепную работу на Android. iOS использует BGAppRefreshTask для коротких частых задач и BGProcessingTask для длительных задач сети или обслуживания.
