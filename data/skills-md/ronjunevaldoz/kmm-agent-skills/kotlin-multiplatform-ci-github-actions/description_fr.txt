Configure GitHub Actions CI pour un projet Kotlin Multiplatform (KMP). Produit deux fichiers de workflow : ci.yml (lint, tests Android, tests iOS, tests Desktop JVM, tests Web JS + WasmJs, cache Gradle) et release.yml (build XCFramework + artefact de téléchargement). Toutes les plateformes cibles sont couvertes. Suppose AGP 9+ et la structure du projet de kotlin-multiplatform-feature-scaffold.
