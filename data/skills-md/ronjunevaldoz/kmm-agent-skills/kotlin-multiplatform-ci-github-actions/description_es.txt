Configura GitHub Actions CI para un proyecto Kotlin Multiplatform (KMP). Produce dos archivos de flujo de trabajo: ci.yml (lint, pruebas de Android, pruebas de iOS, pruebas de JVM de escritorio, pruebas de Web JS + WasmJs, caché de Gradle) y release.yml (compilación de XCFramework + artefacto de carga). Todas las plataformas de destino están cubiertas. Asume AGP 9+ y la estructura del proyecto de kotlin-multiplatform-feature-scaffold.
