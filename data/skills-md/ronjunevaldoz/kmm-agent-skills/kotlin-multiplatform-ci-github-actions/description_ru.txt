Настраивает GitHub Actions CI для многоплатформенного проекта Kotlin (KMP). Создает два файла рабочего процесса: ci.yml (lint, тесты Android, тесты iOS, тесты JVM для настольных компьютеров, тесты Web JS + WasmJs, кеш Gradle) и Release.yml (сборка XCFramework + артефакт загрузки). Охвачены все целевые платформы. Предполагается AGP 9+ и структура проекта из kotlin-multiplatform-feature-scaffold.
