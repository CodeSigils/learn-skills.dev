Configura l'CI di GitHub Actions per un progetto Kotlin Multiplatform (KMP). Produce due file del flusso di lavoro: ci.yml (lint, test Android, test iOS, test JVM desktop, test Web JS + WasmJs, cache Gradle) e release.yml (build XCFramework + artefatto di caricamento). Tutte le piattaforme target sono coperte. Presuppone AGP 9+ e la struttura del progetto da kotlin-multiplatform-feature-scaffold.
