Оценка флага функции для Kotlin Multiplatform — перечисление FeatureFlag и интерфейс FeatureFlagProvider в commonMain, Firebase Remote Config в качестве бэкэнда по умолчанию, типы вариантов A/B, резервные настройки по умолчанию для автономного режима, оценка флага на уровне :domain и поддержка аварийного отключения для быстрого отключения.
