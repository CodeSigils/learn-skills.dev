Évaluation des indicateurs de fonctionnalités pour Kotlin Multiplatform : une énumération FeatureFlag et une interface FeatureFlagProvider dans commonMain, Firebase Remote Config comme backend par défaut, les types de variantes A/B, les valeurs par défaut de secours hors ligne, l'évaluation des indicateurs dans la couche :domain et la prise en charge du kill-switch pour une désactivation rapide.
