Внедрение зависимостей KMP с помощью Koin — сначала рекомендуется использовать ручные модули, а затем аннотированный режим, если предпочтительнее меньшее количество проводов. Охватывает границы области приложения/функции, внедрение конструктора, организацию модулей, запуск платформы, переопределения тестов и антишаблоны, которые скрывают проблемы архитектуры за DI. Используйте это, решая, как связать зависимости KMP, вместо того, чтобы повторять настройку Koin для других навыков.
