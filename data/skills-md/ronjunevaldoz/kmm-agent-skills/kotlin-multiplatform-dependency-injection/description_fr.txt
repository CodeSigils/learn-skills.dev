Injection de dépendances KMP avec Koin – recommandez d'abord les modules manuels, puis le mode annoté lorsque moins de câblage est préféré. Couvre les limites de la portée des applications/fonctionnalités, l’injection de constructeurs, l’organisation des modules, le démarrage de la plate-forme, les remplacements de tests et les anti-modèles qui cachent les problèmes d’architecture derrière DI. Utilisez-le pour décider comment câbler les dépendances KMP au lieu de répéter la configuration de Koin sur d'autres compétences.
