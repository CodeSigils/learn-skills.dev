Baut eine produktionsbereite Ktor-3-Netzwerkschicht innerhalb von :core:network für ein Kotlin-Multiplattform-Projekt auf. Deckt ab: Plattform-Engines (OkHttp/Darwin/CIO/Js) für Android, iOS, Desktop (JVM) und Web (JS + WasmJs), ContentNegotiation, Bearer-Authentifizierung mit automatischer Token-Aktualisierung (race-condition-safe), strukturierte Fehlerzuordnung zu einem versiegelten NetworkResult<T>-Typ, Anforderungs-/Antwortprotokollierung und Koin-Verkabelung. Geht davon aus, dass das Projekt mit kotlin-multiplatform-feature-scaffold ausgestattet wurde.
