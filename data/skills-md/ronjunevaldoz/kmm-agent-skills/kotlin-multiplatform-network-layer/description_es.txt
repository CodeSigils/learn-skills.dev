Desarrolla una capa de red Ktor 3 lista para producción dentro de :core:network para un proyecto multiplataforma Kotlin. Cubre: motores de plataforma (OkHttp/Darwin/CIO/Js) para Android, iOS, escritorio (JVM) y Web (JS + WasmJs), ContentNegotiation, autenticación de portador con actualización automática de token (condición de carrera segura), mapeo de errores estructurado a un tipo sellado NetworkResult<T>, registro de solicitudes/respuestas y cableado Koin. Se supone que el proyecto fue estructurado con kotlin-multiplatform-feature-scaffold.
