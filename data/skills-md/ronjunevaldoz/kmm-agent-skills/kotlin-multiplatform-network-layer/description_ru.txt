Создает готовый к работе сетевой уровень Ktor 3 внутри :core:network для многоплатформенного проекта Kotlin. Охватывает: механизмы платформы (OkHttp/Darwin/CIO/Js) для Android, iOS, настольных компьютеров (JVM) и Интернета (JS + WasmJs), ContentNegotiation, аутентификацию носителя с автоматическим обновлением токена (безопасно для условий гонки), структурированное сопоставление ошибок с запечатанным типом NetworkResult<T>, ведение журнала запросов/ответов и подключение Koin. Предполагается, что проект был построен с помощью kotlin-multiplatform-feature-scaffold.
