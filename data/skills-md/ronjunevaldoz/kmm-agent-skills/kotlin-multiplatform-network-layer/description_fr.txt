Échafaude une couche réseau Ktor 3 prête pour la production à l'intérieur de :core:network pour un projet Kotlin Multiplatform. Couvre : les moteurs de plate-forme (OkHttp/Darwin/CIO/Js) pour Android, iOS, Desktop (JVM) et Web (JS + WasmJs), ContentNegociation, Bearer auth avec actualisation automatique du jeton (sûr en fonction des conditions de course), mappage d'erreur structuré vers un type scellé NetworkResult<T>, journalisation des requêtes/réponses et câblage Koin. Suppose que le projet a été échafaudé avec Kotlin-multiplatform-feature-scaffold.
