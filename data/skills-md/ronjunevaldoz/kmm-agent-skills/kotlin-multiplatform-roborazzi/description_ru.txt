Полное тестирование уровня пользовательского интерфейса для KMP: теги семантического тестирования для составных элементов, тесты взаимодействия Compose пользовательского интерфейса (createComposeRule, onNodeWithTag, PerformClick, AssertIsDisplayed) и тесты снимков экрана Roborazzi, которые фиксируют составные элементы @Preview на JVM/Desktop для обнаружения визуальной регрессии. Охватывает весь стек: от соглашений testTag до различий между золотыми изображениями CI. Заменяет kotlin-multiplatform-testing-robot для регрессионного тестирования пользовательского интерфейса.
