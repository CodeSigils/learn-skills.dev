Contrat d'architecture de projet TypeScript pour un monorepo Next.js/Node — ligne de base en mode strict tsconfig, configuration plate ESLint + plus joli, espaces de travail pnpm + disposition Turborepo et règles de délimitation des packages. Il s'agit de l'analogue TS d'un graphe de module Gradle : TS n'a pas de limite de module imposée par le compilateur, donc la disposition de l'espace de travail et les règles de lint ensemble *sont* le contrat d'architecture que supposent toutes les autres compétences.
