TypeScript-Projektarchitekturvertrag für ein Next.js/Node-Monorepo – tsconfig-Strict-Mode-Baseline, ESLint-Flachkonfiguration + Prettier, PNPM-Arbeitsbereiche + Turborepo-Layout und Paketgrenzenregeln. Dies ist das TS-Analogon eines Gradle-Moduldiagramms: TS hat keine vom Compiler erzwungene Modulgrenze, daher *sind* das Arbeitsbereichslayout und die Lint-Regeln zusammen der Architekturvertrag, den jeder andere Skill voraussetzt.
