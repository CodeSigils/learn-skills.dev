Контракт на архитектуру проекта TypeScript для монорепозитория Next.js/Node — базовый план строгого режима tsconfig, плоская конфигурация ESLint + Prettier, рабочие области pnpm + макет Turborepo и граничные правила пакета. Это TS-аналог графа модуля Gradle: TS не имеет границы модуля, обеспечиваемой компилятором, поэтому макет рабочей области и правила проверки вместе *являются* архитектурным контрактом, который предполагает каждый другой навык.
