Contrato de arquitectura de proyecto TypeScript para un monorepo Next.js/Node: línea base de modo estricto tsconfig, configuración plana ESLint + Prettier, espacios de trabajo pnpm + diseño Turborepo y reglas de límites de paquetes. Este es el análogo TS de un gráfico de módulo Gradle: TS no tiene límites de módulo impuestos por el compilador, por lo que el diseño del espacio de trabajo y las reglas de pelusa juntas *son* el contrato de arquitectura que asumen todas las demás habilidades.
