Развертывание Vercel для приложения Next.js — конфигурация проекта через vercel.json, переменные среды, ограниченные областью разработки/предварительного просмотра/производства, автоматическое развертывание предварительного просмотра для каждого PR и выбор времени выполнения Edge или Node.js для каждого маршрута. Охватывает случай монорепозитория Turborepo, когда пересобирать нужно только затронутое приложение, а также риск утечки секрета, связанный с сохранением файлов env даже в частном репозитории.
