Vercel-Bereitstellung für eine Next.js-App – Projektkonfiguration über vercel.json, auf Entwicklung/Vorschau/Produktion beschränkte Umgebungsvariablen, automatische Vorschaubereitstellungen pro PR und die Laufzeitauswahl Edge vs. Node.js pro Route. Deckt den Turborepo-Monorepo-Fall ab, bei dem nur die betroffene App neu erstellt werden sollte, und das Geheimnisleckrisiko, wenn Env-Dateien sogar in ein privates Repo übertragen werden.
