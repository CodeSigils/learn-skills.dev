Déploiement Vercel pour une application Next.js — configuration du projet via vercel.json, variables d'environnement étendues à Développement/Aperçu/Production, déploiements d'aperçu automatiques par PR et choix d'exécution Edge vs Node.js par route. Couvre le cas du monorepo Turborepo dans lequel seule l'application affectée doit être reconstruite, ainsi que le risque de fuite secrète lié à la validation des fichiers d'environnement même dans un dépôt privé.
