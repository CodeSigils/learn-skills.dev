새로운 1인칭 C/C++ 소스를 위한 스캐폴드와 구조를 제공하여 Kotlin Multiplatform 라이브러리의 네이티브 코어(직접 작성하는 커스텀 렌더러, 코덱, 엔진 등)를 구축합니다 — 디렉터리 레이아웃, CMake 설정, 공개 C‑ABI 헤더 설계, 그리고 네이티브 측 테스트. kmp-jni-pro의 Phase 0 발견이 기대하는 아티팩트를 생성합니다. Kotlin을 네이티브 코드와 연결하는 작업은 포함되지 않습니다 — 이는 kmp-jni-pro의 역할이며, 이 스킬 뒤에 항상 사용되고 절대 대체되지 않습니다. 기존 서드파티 C/C++ 라이브러리를 래핑하는 것도 포함되지 않습니다 — 이것 역시 jni-pro의 작업이며 (Phase 0 라이브러리‑우선 발견), 이 스킬의 범위가 아닙니다.
