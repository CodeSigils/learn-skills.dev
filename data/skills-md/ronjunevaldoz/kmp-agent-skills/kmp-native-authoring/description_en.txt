Scaffolds and structures brand-new, first-party C/C++ source for a Kotlin Multiplatform library's native core (a custom renderer, codec, or engine you are writing yourself) — directory layout, CMake setup, public C-ABI header design, and native-side testing. Produces the artifact kmp-jni-pro's Phase 0 discovery expects to find. Does NOT cover bridging Kotlin to native code — that is kmp-jni-pro's job, always used after this skill, never instead of it. Does NOT cover wrapping an existing 3rd-party C/C++ library — that is also jni-pro's job (its Phase 0 library-first discovery), not this skill's.
