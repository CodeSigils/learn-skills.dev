Создаёт каркас и структуру совершенно нового, собственного C/C++ кода для нативного ядра библиотеки Kotlin Multiplatform (кастомного рендерера, кодека или движка, который вы пишете сами) — структура каталогов, настройка CMake, проектирование публичного заголовка C‑ABI и тестирование на нативной стороне. Генерирует артефакт, который ожидает обнаружить Phase 0 в kmp‑jni‑pro. НЕ охватывает мост между Kotlin и нативным кодом — это задача kmp‑jni‑pro, всегда используется после этого навыка, никогда вместо него. НЕ охватывает обёртывание существующей сторонней C/C++ библиотеки — это также задача jni‑pro (его Phase 0, ориентированное на библиотеку), а не этого навыка.
