يُنشئ ويُهيكل مصدر C/C++ جديد من الطرف الأول لمكتبة Kotlin Multiplatform للجوهر الأصلي (مُرسم مخصص أو مشفر أو محرك تقوم بكتابته بنفسك) — تنظيم المجلدات، إعداد CMake، تصميم رأس C‑ABI العام، واختبار الجانب الأصلي. ينتج القطعة التي تتوقع مرحلة 0 من kmp‑jni‑pro العثور عليها. لا يغطي جسر Kotlin إلى الكود الأصلي — فهذا عمل kmp‑jni‑pro، يُستخدم دائمًا بعد هذه المهارة، ولا بدلاً منها. لا يغطي تغليف مكتبة C/C++ الطرف الثالث الموجودة — فهذا أيضًا عمل jni‑pro (اكتشاف مرحلة 0 أولاً للمكتبة)، وليس هذه المهارة.
