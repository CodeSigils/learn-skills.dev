Erstellt Gerüste und Strukturen für brandneuen, eigenen C/C++‑Quellcode des nativen Kerns einer Kotlin‑Multiplatform‑Bibliothek (ein benutzerdefinierter Renderer, Codec oder eine Engine, die Sie selbst schreiben) – Verzeichnislayout, CMake‑Konfiguration, öffentliches C‑ABI‑Header‑Design und Tests auf der nativen Seite. Produziert das Artefakt, das die Phase‑0‑Entdeckung von kmp‑jni‑pro zu finden erwartet. Deckt NICHT die Brücke zwischen Kotlin und nativem Code ab – das ist die Aufgabe von kmp‑jni‑pro, immer nach dieser Fähigkeit verwendet, niemals anstelle davon. Deckt NICHT das Einbinden einer bestehenden Drittanbieter‑C/C++‑Bibliothek ab – das ist ebenfalls Aufgabe von jni‑pro (seine Phase‑0‑Library‑First‑Entdeckung), nicht dieser Fähigkeit.
