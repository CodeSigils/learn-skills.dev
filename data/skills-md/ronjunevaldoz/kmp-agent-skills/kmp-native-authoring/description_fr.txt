Échafaudages et structures une toute nouvelle source C/C++ propriétaire pour le noyau natif d'une bibliothèque Kotlin Multiplatform (un moteur de rendu personnalisé, un codec ou un moteur que vous écrivez vous-même) : disposition des répertoires, configuration de CMake, conception d'en-tête C-ABI publique et tests côté natif. Produit l'artefact que la découverte de phase 0 de kmp-jni-pro s'attend à trouver. Ne couvre PAS le pont entre Kotlin et le code natif - c'est le travail de kmp-jni-pro, toujours utilisé après cette compétence, jamais à sa place. Ne couvre PAS l'encapsulation d'une bibliothèque C/C++ tierce existante - c'est également le travail de jni-pro (sa première découverte de la bibliothèque de phase 0), pas celui de cette compétence.
