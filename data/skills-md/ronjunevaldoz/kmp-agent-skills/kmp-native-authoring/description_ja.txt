新規の、ファーストパーティ製 C/C++ ソースを Kotlin Multiplatform ライブラリのネイティブコア（自分で作成するカスタムレンダラ、コーデック、エンジン）向けに足場を組み、構造化します — ディレクトリ構成、CMake 設定、公開 C-ABI ヘッダー設計、そしてネイティブ側テスト。kmp-jni-pro の Phase 0 discovery が期待するアーティファクトを生成します。Kotlin とネイティブコードのブリッジは対象外です — それは kmp-jni-pro の仕事であり、このスキルの後に必ず使用され、代わりに使用されることはありません。既存のサードパーティ C/C++ ライブラリのラッピングも対象外です — それも jni-pro の仕事（Phase 0 の library‑first discovery）であり、このスキルの範囲ではありません。
