Paging 3 dans Kotlin Multiplatform : PagingSource, Pager, PagingData et collectAsLazyPagingItems pour le chargement de liste basé sur le curseur et le décalage. Couvre le placement des couches (PagingSource dans :data, Pager dans :presenter, LazyPagingItems dans :ui), la gestion de l'état de charge, RemoteMediator pour réseau + DB, le câblage Koin et le test de PagingSource de manière isolée. Maintient PagingData hors de UiState.
