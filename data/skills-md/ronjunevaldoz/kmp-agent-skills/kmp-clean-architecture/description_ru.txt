Определяет шестиуровневый контракт чистой архитектуры для функциональных модулей KMP: :model / :api / :domain / :data / :presenter / :ui. Охватывает правила зависимостей слоев, разделение :model и :api, обеспечение внутренней видимости, границу конфигурации Gradle api()/implementation() (утечка ABI/типа, приспособления пользовательской компиляции, области фасада), обнаружение цикла зависимостей и функции пригодности архитектуры Detectekt, которые приводят к сбою сборки при нарушениях.
