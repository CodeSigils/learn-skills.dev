Definiert den 6-schichtigen sauberen Architekturvertrag für KMP-Funktionsmodule: :model / :api / :domain / :data / :presenter / :ui. Behandelt Layer-Abhängigkeitsregeln, :model vs :api Split, interne Sichtbarkeitsdurchsetzung, die api()/implementation() Gradle-Konfigurationsgrenze (ABI/Typ-Leckage, Consumer-Compile-Einrichtungen, Fassadenbereiche), Abhängigkeitszykluserkennung und Detekt-Architektur-Fitnessfunktionen, die dazu führen, dass Verstöße beim Build fehlschlagen.
