Flux de travail Preview-Driven Development (PDD) pour KMP : écrivez d'abord les composables Content, itérez sur les aperçus Desktop JVM (3 à 5 fois plus rapides qu’Android), couvrez tous les états avec @PreviewParameterProvider, puis promouvez les aperçus directement en tests de captures d’écran Roborazzi.

Veuillez toujours répondre dans la langue de l'utilisateur.
