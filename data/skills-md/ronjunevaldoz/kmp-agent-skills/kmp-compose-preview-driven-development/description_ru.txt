Рабочий процесс Preview‑Driven Development (PDD) для KMP: сначала пишите composable‑элементы Content, итеративно проверяйте их в превью Desktop JVM (в 3–5 раз быстрее, чем на Android), покрывайте все состояния с помощью @PreviewParameterProvider, затем напрямую переводите превью в скриншот‑тесты Roborazzi.

Пожалуйста, всегда отвечайте на языке пользователя.
