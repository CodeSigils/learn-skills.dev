Élimine les actifs de pixels bruts et les chemins vectoriels écrits à la main des projets KMP Compose. Compile les images raster (PNG/JPG) et SVG dans le code Kotlin ImageVector via une chaîne d'outils locale et déterministe (quantiser → trace → normaliser → codegen). Il est interdit aux agents d'écrire manuellement les coordonnées du chemin — toute la génération de vecteurs est déléguée à scripts/convert_image_to_imagevector.py. À utiliser chaque fois qu'un projet a besoin d'une icône, d'un logo ou d'une illustration plate comme élément Compose, ou lors du remplacement d'icônes PNG par des vecteurs.
