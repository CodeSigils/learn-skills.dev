Legge i file docs/lessons/*.md da uno o più progetti KMP consumer e propone modifiche concrete alle skill di origine in kmp-agent-skills. Usa questa skill quando l'utente vuole incorporare il feedback dei consumer nella collezione di skill, quando le lezioni si sono accumulate in un progetto e hanno bisogno di essere portate a monte, o quando si esegue una revisione della governance delle skill. Produce un report di modifica strutturato e, opzionalmente, redige i diff effettivi delle skill. Si attiva quando l'utente dice "harvest lessons", "upstream the lessons", "incorporate feedback", "update skills from consumer projects" o "skills review". Si attiva anche proattivamente quando vedi una directory docs/lessons/ con file non processati.
