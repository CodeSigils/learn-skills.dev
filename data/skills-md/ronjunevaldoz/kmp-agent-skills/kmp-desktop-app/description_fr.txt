Préoccupations spécifiques au bureau pour les applications KMP Compose Multiplatform — gestion des fenêtres, barre d’état système, sélecteur de fichiers, raccourcis clavier, barre de menus native, glisser‑déposer et empaquetage. Couvre les écarts du ciblage Desktop par rapport à Android/iOS : les entrées/sorties de fichiers synchrones sur le thread principal sont sûres sur le Desktop, `LocalContext` n’existe pas, et l’état de la fenêtre doit être géré différemment de l’état d’une Activity Android.
