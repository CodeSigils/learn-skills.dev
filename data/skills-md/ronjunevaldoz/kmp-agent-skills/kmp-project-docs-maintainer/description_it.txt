Mantiene solo la documentazione del progetto KMP rivolta ai consumatori downstream: README, GETTING_STARTED, INSTALL, RELEASING, pagine docs/reference, guide di onboarding, note architetturali e diagrammi architetturali. Usa questa competenza quando la documentazione del progetto deve corrispondere al codice reale, ai comandi, alla configurazione, alla struttura delle cartelle o all’architettura dell’app/biblioteca. NON copre la generazione di note di rilascio per i consumatori, i changelog per skill specifiche o la documentazione del repository delle skill.
