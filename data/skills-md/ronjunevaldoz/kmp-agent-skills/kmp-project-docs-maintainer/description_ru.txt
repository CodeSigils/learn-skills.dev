Поддерживает только документацию проекта KMP, ориентированную на конечных потребителей: README, GETTING_STARTED, INSTALL, RELEASING, страницы docs/reference, руководства по внедрению, заметки об архитектуре и архитектурные диаграммы. Используйте этот навык, когда документация проекта должна соответствовать реальному коду, командам, конфигурации, структуре папок или структуре приложения/библиотеки. НЕ охватывает генерацию релизных заметок для потребителей, changelog‑и по отдельным навыкам или документацию репозитория навыков.
