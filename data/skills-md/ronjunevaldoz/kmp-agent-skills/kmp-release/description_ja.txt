エンドツーエンドの KMP ライブラリおよびアプリのリリースパイプライン。バージョン管理戦略（gradle.properties を唯一の真実として）や、vanniktech プラグインによる Maven Central への公開、GPG 署名、Sonatype Central Portal、git‑cliff と Conventional Commits を用いたチェンジログ生成、GitHub Release の作成、シークレット管理パターン、そしてアプリ対象の場合は単一の semver ソースからプラットフォーム固有のバージョンフィールド（Android の versionCode、iOS の CFBundleVersion）を導出することをカバーしています。CI スキル（workflow YAML を管理）や xcframework‑spm スキル（SPM バイナリ配布を管理）とは別物です。
