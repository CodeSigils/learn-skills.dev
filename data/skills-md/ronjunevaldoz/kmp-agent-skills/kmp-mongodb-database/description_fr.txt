Modèle de pilote MongoDB Kotlin Coroutine pour les applications full-stack Kotlin Multiplatform. Couvre : l'accès MongoDB côté serveur, le mappage de documents, les limites du référentiel, les erreurs de base de données typées, les lectures réactives avec Flow, les flux de modifications et un script d'échafaudage pour la configuration répétée de la base de données. Utilisez-le pour la couche de données back-end, et non pour la persistance du client partagé.
