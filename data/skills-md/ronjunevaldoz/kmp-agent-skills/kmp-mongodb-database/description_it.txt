Modello del driver MongoDB Kotlin Coroutine per app full‑stack Kotlin Multiplatform. Copre: accesso a MongoDB lato server, mappatura dei documenti, confini del repository, errori di database tipizzati, letture reattive con Flow, change stream e uno script di scaffolding per la configurazione ripetuta del database. Usa questo per lo strato dati backend, non per la persistenza condivisa del client.
