Patrón MongoDB Kotlin Coroutine Driver para aplicaciones de pila completa multiplataforma Kotlin. Cubre: acceso a MongoDB del lado del servidor, mapeo de documentos, límites del repositorio, errores escritos en la base de datos, lecturas reactivas con Flow, flujos de cambios y un script de andamio para la configuración repetida de la base de datos. Úselo para la capa de datos backend, no para la persistencia del cliente compartido.
