Шаблон драйвера MongoDB Kotlin Coroutine для полно‑стековых приложений Kotlin Multiplatform. Охватывает: доступ к MongoDB на стороне сервера, отображение документов, границы репозитория, типизированные ошибки базы данных, реактивные чтения с Flow, потоки изменений и скрипт‑скелет для повторной настройки базы данных. Используйте его для слоя данных бэкенда, а не для общей клиентской персистенции.
