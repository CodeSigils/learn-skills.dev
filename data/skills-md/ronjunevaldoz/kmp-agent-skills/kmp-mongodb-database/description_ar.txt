نمط سائق MongoDB Kotlin Coroutine لتطبيقات Kotlin Multiplatform المتكاملة. يشمل: الوصول إلى MongoDB من جانب الخادم، تحويل المستندات، حدود المستودعات، أخطاء قاعدة البيانات ذات الأنواع المحددة، القراءات التفاعلية باستخدام Flow، تدفقات التغيير، وسكريبت إعداد قاعدة البيانات المتكرر. استخدمه لطبقة البيانات الخلفية، وليس لتخزين البيانات المشترك على العميل.
