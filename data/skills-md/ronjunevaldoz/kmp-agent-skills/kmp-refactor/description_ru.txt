Определяет, безопасно ли выполнять переименование/перемещение/копирование/удаление с помощью простого текстового прохода (markdown, конфиги, скрипты, каталоги навыков) или это следует делегировать реальному инструменту, учитывающему символы (Android Studio / IntelliJ Refactor для кода Kotlin). Описывает проверенную процедуру текстового переименования (git mv, исправление frontmatter/заголовков, массовый поиск и замена с помощью regex, проверка остатков, полный запуск тестов и проверок). Также включает чек‑лист перемещения модуля в соответствии с 6‑слойным контрактом чистой архитектуры этого набора. НЕ реализует механизм переименования на уровне AST для Kotlin — для этого предназначены инструменты рефакторинга IDE.
