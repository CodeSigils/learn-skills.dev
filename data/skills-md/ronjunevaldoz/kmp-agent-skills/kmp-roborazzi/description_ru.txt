Полное тестирование UI‑слоя для KMP: семантические тестовые теги в composable‑элементах, тесты взаимодействия Compose UI в commonTest (runComposeUiTest, onNodeWithTag, performClick, assertIsDisplayed), которые запускаются на всех целевых платформах — JVM, Android instrumented, iOS‑симулятор, Wasm — и скриншот‑тесты Roborazzi, захватывающие composable‑элементы @Preview на JVM/Desktop для обнаружения визуальных регрессий. Охватывает весь стек от конвенций testTag до диффов золотых изображений в CI. Заменяет kmp-testing-robot для UI‑регрессионного тестирования.
