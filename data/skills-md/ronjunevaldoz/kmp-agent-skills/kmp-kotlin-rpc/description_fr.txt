Kotlin RPC pour les applications full-stack Kotlin Multiplatform. Explique quand utiliser Kotlin RPC au lieu de REST ou gRPC, les contrats de requête/réponse partagés, la disposition du module client/serveur, les limites d'authentification, la conception de l'interface de service et un script d'échafaudage pour la configuration initiale du projet RPC. Utilisez-le pour les limites du service Kotlin à Kotlin, en particulier lorsque le client et le serveur vivent tous deux dans le même écosystème KMP.
