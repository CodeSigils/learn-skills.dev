Kotlin RPC für Kotlin Multiplattform-Full-Stack-Apps. Behandelt, wann Kotlin RPC anstelle von REST oder gRPC verwendet werden sollte, gemeinsame Anforderungs-/Antwortverträge, Client-/Server-Modullayout, Authentifizierungsgrenzen, Serviceschnittstellendesign und ein Gerüstskript für die anfängliche RPC-Projekteinrichtung. Verwenden Sie dies für Kotlin-zu-Kotlin-Dienstgrenzen, insbesondere wenn sich Client und Server beide im selben KMP-Ökosystem befinden.
