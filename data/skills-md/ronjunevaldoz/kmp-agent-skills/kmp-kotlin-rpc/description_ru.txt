Kotlin RPC для полнофункциональных многоплатформенных приложений Kotlin. Описывает, когда следует использовать Kotlin RPC вместо REST или gRPC, общие контракты запросов/ответов, макет модуля клиент/сервер, границы аутентификации, дизайн интерфейса службы и сценарий scaffold для начальной настройки проекта RPC. Используйте это для границ сервисов Kotlin-to-Kotlin, особенно когда клиент и сервер живут в одной экосистеме KMP.
