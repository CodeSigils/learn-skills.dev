Kotlin RPC per app full-stack multipiattaforma Kotlin. Descrive quando utilizzare Kotlin RPC anziché REST o gRPC, contratti di richiesta/risposta condivisi, layout del modulo client/server, limiti di autenticazione, progettazione dell'interfaccia di servizio e uno script di scaffold per la configurazione iniziale del progetto RPC. Utilizzalo per i limiti del servizio Kotlin-to-Kotlin, soprattutto quando il client e il server risiedono entrambi nello stesso ecosistema KMP.
