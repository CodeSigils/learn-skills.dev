Kotlin RPC para aplicaciones full‑stack de Kotlin Multiplatform. Cubre cuándo usar Kotlin RPC en lugar de REST o gRPC, contratos compartidos de solicitud/respuesta, la distribución de módulos cliente/servidor, límites de autenticación, diseño de la interfaz del servicio y un script de scaffolding para la configuración inicial del proyecto RPC. Úsalo para los límites de servicio Kotlin‑a‑Kotlin, especialmente cuando el cliente y el servidor viven en el mismo ecosistema KMP.
