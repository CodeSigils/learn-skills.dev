Construir un procesador de anotaciones KSP (Kotlin Symbol Processing) personalizado que genere código fuente Kotlin con KotlinPoet — constructores FileSpec/TypeSpec/FunSpec/PropertySpec, especificadores de formato, la estructura de procesador de dos módulos, registro ServiceLoader y el módulo de interoperabilidad kotlinpoet‑ksp para convertir KSType/KSClassDeclaration de KSP en TypeName/ClassName de KotlinPoet. Úselo cuando un proyecto quiera generación de código en tiempo de compilación a partir de anotaciones en lugar de reflexión en tiempo de ejecución. NO cubre el consumo de un procesador KSP existente (modo anotado de Koin, Room, etc.) — eso es uso de dependencia ordinario; esta habilidad es para crear un procesador nuevo.
