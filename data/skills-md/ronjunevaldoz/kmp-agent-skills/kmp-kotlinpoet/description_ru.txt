Создание пользовательского обработчика аннотаций KSP (Kotlin Symbol Processing), который генерирует исходный код Kotlin с помощью KotlinPoet — построители FileSpec/TypeSpec/FunSpec/ PropertySpec, спецификаторы формата, двухмодульная структура процессора, регистрация ServiceLoader и модуль взаимодействия kotlinpoet-ksp для преобразования KSType/KSClassDeclaration KSP в TypeName/ClassName KotlinPoet. Используйте, когда проект хочет генерировать код во время компиляции из аннотаций вместо отражения во время выполнения. НЕ распространяется на использование существующего процессора KSP (аннотированный режим Koin, Room и т. д.) — это обычное использование зависимостей; этот навык предназначен для разработки нового процессора.
