Modèle de service d'authentification basé sur Ktor pour les applications full-stack Kotlin Multiplatform. Couvre : l'authentification du porteur et JWT, les sessions lorsque les sessions de style navigateur avec état conviennent mieux, Ktor RPC lorsque le client et le serveur sont tous deux Kotlin-first, les erreurs d'authentification tapées, les gardes de route, les flux d'actualisation/déconnexion et un petit script d'échafaudage pour la configuration répétée du module d'authentification. Utilisez-le pour l'authentification côté serveur, et non pour l'état d'authentification de l'interface utilisateur partagée.
