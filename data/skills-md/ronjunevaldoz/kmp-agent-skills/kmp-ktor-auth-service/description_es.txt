Patrón de servicio de autenticación basado en Ktor para aplicaciones full‑stack multiplataforma con Kotlin. Incluye: autenticación bearer y JWT, sesiones cuando las sesiones con estado estilo navegador son más adecuadas, Ktor RPC cuando cliente y servidor son ambos Kotlin‑first, errores de autenticación tipados, guardas de rutas, flujos de actualización/cierre de sesión y un pequeño script de scaffolding para la configuración repetida del módulo de autenticación. Úsalo para la autenticación del lado del servidor, no para el estado de autenticación compartido en la UI.
