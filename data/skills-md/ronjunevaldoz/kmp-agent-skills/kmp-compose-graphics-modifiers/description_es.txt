Modificadores de gráficos Jetpack Compose para KMP y CMP: utilice gráficosLayer para transformaciones, recorte, alfa, elevación y efectos de capa; use Canvas, drawBehind y drawWithCache para realizar dibujos personalizados reales. Recomendado para editores de flujo de trabajo, UI basadas en nodos y otras superficies donde un elemento componible necesita un caparazón transformable alrededor de un interior personalizado.
