Jetpack Compose-Grafikmodifikatoren für KMP und CMP – verwenden Sie GraphicsLayer für Transformationen, Clipping, Alpha, Höhe und Ebeneneffekte; Verwenden Sie Canvas, drawBehind und drawWithCache für tatsächliche benutzerdefinierte Zeichnungen. Empfohlen für Workflow-Editoren, knotenbasierte Benutzeroberflächen und andere Oberflächen, bei denen ein zusammensetzbares Element eine umwandelbare Hülle um ein individuell gezeichnetes Inneres benötigt.
