Графические модификаторы Jetpack Compose для KMP и CMP — используйте graphicsLayer для трансформаций, обрезки, альфа‑канала, подъёма и эффектов слоёв; используйте Canvas, drawBehind и drawWithCache для реального пользовательского рисования. Рекомендуется для редакторов рабочих процессов, UI на основе узлов и других поверхностей, где компонуемому элементу требуется трансформируемая оболочка вокруг пользовательски нарисованного внутреннего содержимого.
