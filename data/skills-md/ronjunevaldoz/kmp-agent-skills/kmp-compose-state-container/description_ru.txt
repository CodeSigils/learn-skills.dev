Выбор правильного контейнера состояний в Compose Multiplatform: Remember vs RememberSaveable vs ViewModel vs RememberCoroutineScope. Обложки: что переживает рекомпозицию, изменения конфигурации и смерть процесса; когда применяется каждый контейнер; RememberSaveable с пользовательской Saver для сложных типов; Область ViewModel для навигации по записям обратного стека; и наиболее распространенные неправильные варианты (ViewModel для раскрывающегося списка, помните о данных формы, которые должны выдерживать вращение). Ноль новых зависимостей.
