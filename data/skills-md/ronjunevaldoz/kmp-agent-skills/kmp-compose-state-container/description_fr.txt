Choisir le bon conteneur d'état dans Compose Multiplatform : Remember vs RememberSaveable vs ViewModel vs RememberCoroutineScope. Couvre : ce qui survit à la recomposition, aux changements de configuration et à la mort du processus ; quand chaque conteneur s'applique ; RememberSaveable avec un économiseur personnalisé pour les types complexes ; Portée de ViewModel pour naviguer dans les entrées de la pile arrière ; et les mauvais choix les plus courants (ViewModel pour l'état déroulant, n'oubliez pas pour les données de formulaire qui doivent survivre à la rotation). Zéro nouvelle dépendance.
