Model Context Protocol (MCP) per Kotlin Multiplatform utilizzando il modelcontextprotocol/kotlin-sdk ufficiale (mantenuto con JetBrains). Riguarda la creazione di un server MCP che espone strumenti/risorse/prompt a un client LLM (Claude, Claude Code, MCP Inspector), la creazione di un client MCP che si connette a un server MCP esterno da un'app Kotlin, la selezione del trasporto (STDIO, Streamable HTTP, SSE, WebSocket, ChannelTransport per i test) e il cablaggio Ktor poiché l'SDK non raggruppa un motore Ktor in modo transitivo. Ha come target JVM, Native, JS e Wasm da commonMain.
