Protocolo de Contexto de Modelo (MCP) para Kotlin Multiplatform usando el SDK oficial modelcontextprotocol/kotlin-sdk (mantenido con JetBrains). Cubre la creación de un servidor MCP que expone herramientas/recursos/prompts a un cliente LLM (Claude, Claude Code, MCP Inspector), la creación de un cliente MCP que se conecta a un servidor MCP externo desde una aplicación Kotlin, la selección de transporte (STDIO, HTTP transmitible, SSE, WebSocket, ChannelTransport para pruebas) y la configuración de Ktor ya que el SDK no incluye de forma transitiva un motor Ktor. Apunta a JVM, Native, JS y Wasm desde commonMain.
