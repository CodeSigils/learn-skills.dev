Model Context Protocol (MCP) pour Kotlin Multiplatform utilisant le modelcontextprotocol/kotlin-sdk officiel (maintenu avec JetBrains). Couvre la création d'un serveur MCP qui expose des outils/ressources/invites à un client LLM (Claude, Claude Code, MCP Inspector), la création d'un client MCP qui se connecte à un serveur MCP externe à partir d'une application Kotlin, la sélection du transport (STDIO, Streamable HTTP, SSE, WebSocket, ChannelTransport pour les tests) et le câblage Ktor puisque le SDK ne regroupe pas de manière transitive un moteur Ktor. Cible JVM, Native, JS et Wasm de commonMain.
