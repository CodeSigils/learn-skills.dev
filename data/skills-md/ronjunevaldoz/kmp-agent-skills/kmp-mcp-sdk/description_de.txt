Model Context Protocol (MCP) für Kotlin Multiplattform unter Verwendung des offiziellen modelcontextprotocol/kotlin-sdk (gepflegt von JetBrains). Behandelt den Aufbau eines MCP-Servers, der Tools/Ressourcen/Prompts für einen LLM-Client (Claude, Claude Code, MCP Inspector) bereitstellt, den Aufbau eines MCP-Clients, der sich von einer Kotlin‑App aus mit einem externen MCP-Server verbindet, die Auswahl des Transports (STDIO, streambares HTTP, SSE, WebSocket, ChannelTransport für Tests) und das Ktor‑Wiring, da das SDK keinen Ktor‑Engine transitiv bündelt. Zielplattformen sind JVM, Native, JS und Wasm aus commonMain.
