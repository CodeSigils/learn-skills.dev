بروتوكول السياق النموذجي (MCP) لـ Kotlin Multiplatform باستخدام modelcontextprotocol/kotlin-sdk الرسمي (الذي تتم صيانته باستخدام JetBrains). يغطي إنشاء خادم MCP الذي يعرض الأدوات/الموارد/المطالبات لعميل LLM (Claude، Claude Code، MCP Inspector)، وإنشاء عميل MCP يتصل بخادم MCP خارجي من تطبيق Kotlin، واختيار النقل (STDIO، وStreamable HTTP، وSSE، وWebSocket، وChannelTransport للاختبارات)، وأسلاك Ktor نظرًا لأن SDK لا تقوم بتجميع محرك Ktor بشكل عابر. يستهدف JVM وNative وJS وWasm من commonMain.
