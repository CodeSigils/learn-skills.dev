Протокол контекста модели (MCP) для Kotlin Multiplatform с использованием официального modelcontextprotocol/kotlin-sdk (поддерживается JetBrains). Охватывает создание сервера MCP, который предоставляет инструменты/ресурсы/подсказки клиенту LLM (Claude, Claude Code, MCP Inspector), создание клиента MCP, который подключается к внешнему серверу MCP из Kotlin‑приложения, выбор транспорта (STDIO, Streamable HTTP, SSE, WebSocket, ChannelTransport для тестов) и настройку Ktor, поскольку SDK не включает Ktor‑движок транзитивно. Поддерживает JVM, Native, JS и Wasm из commonMain. Пожалуйста, всегда отвечайте на языке пользователя.
