Pubblica una libreria multipiattaforma Kotlin su Maven Central, sui pacchetti GitHub o su entrambi. Copre: configurazione del plug-in vanniktech maven-publish, metadati POM, staging Sonatype OSSRH, distinta base multi-artefatto, monitoraggio API kotlinx-binary-compatibility-validator, SNAPSHOT rispetto ai canali stabili e un elenco di controllo del rilascio. Si accoppia con kmp-xcframework-spm per la distribuzione iOS/SPM.
