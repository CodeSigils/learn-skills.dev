Опубликуйте библиотеку Kotlin Multiplatform в Maven Central, GitHub Packages или в оба репозитория. Охватывается: настройка плагина vanniktech maven‑publish, метаданные POM, стейджинг в Sonatype OSSRH, многокомпонентный BOM, отслеживание API с помощью kotlinx‑binary‑compatibility‑validator, каналы SNAPSHOT и стабильные версии, а также чек‑лист релиза. Партнёрствует с kmp‑xcframework‑spm для распространения на iOS/SPM.
