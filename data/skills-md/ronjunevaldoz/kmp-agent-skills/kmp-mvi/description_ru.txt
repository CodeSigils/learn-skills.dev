MVI (Model-View-Intent) — архитектурный паттерн для Kotlin Multiplatform + Compose Multiplatform. Охватывает: паттерн Contract (State/Intent/Effect для каждого экрана), базовый класс MviViewModel с StateFlow для состояния и Channel для одноразовых эффектов, атомарные обновления состояния, разбиение экрана/контента в Compose, тестирование ViewModel с помощью Turbine и наиболее распространённые подводные камни MVI в KMP. Никаких новых зависимостей — построено на androidx.lifecycle.ViewModel и kotlinx.coroutines, уже присутствующих в feature-scaffold.
