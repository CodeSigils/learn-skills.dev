Das Slot-API-Muster in Compose Multiplatform – Entwerfen von Komponenten mit zusammensetzbaren Lambda-Parametern (Slots) anstelle von Datenparametern. Behandelt: einzelne und benannte Slots, bereichsbezogene Slots mit Empfängertypen (RowScope, ColumnScope), Trailing-Lambda-Konvention, Slot-basierter Komponentenbibliotheksentwurf, CompositionLocal als Deep-Slot-Alternative, Leistungsmerkmale und wann keine Slots verwendet werden sollten. Keine neuen Abhängigkeiten.
