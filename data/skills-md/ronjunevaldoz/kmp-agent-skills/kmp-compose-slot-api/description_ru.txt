Шаблон Slot API в Compose Multiplatform — проектирование компонентов с параметрами‑лямбда (слотами) вместо параметров‑данных. Охватывает: одиночные и именованные слоты, слоты с областью действия и типами получателя (RowScope, ColumnScope), соглашение о завершающей лямбда‑функции, проектирование библиотек компонентов на основе слотов, CompositionLocal как альтернативу глубоким слотам, характеристики производительности и случаи, когда НЕ следует использовать слоты. Никаких новых зависимостей.
