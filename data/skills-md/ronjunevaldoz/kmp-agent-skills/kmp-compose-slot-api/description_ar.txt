نمط Slot API في Compose Multiplatform - تصميم المكونات باستخدام معلمات lambda (الفتحات) القابلة للتركيب بدلاً من معلمات البيانات. الأغطية: الفتحات الفردية والمسماة، والفتحات ذات النطاق مع أنواع أجهزة الاستقبال (RowScope، ColumnScope)، واتفاقية lambda اللاحقة، وتصميم مكتبة المكونات القائمة على الفتحة، وCompositionLocal كبديل للفتحة العميقة، وخصائص الأداء، ومتى لا يتم استخدام الفتحات. صفر تبعيات جديدة.
