Le modèle d’API Slot dans Compose Multiplatform — conception de composants avec des paramètres lambda composables (slots) au lieu de paramètres de données. Couvre : les slots simples et nommés, les slots à portée avec des types de récepteur (RowScope, ColumnScope), la convention du lambda final, la conception d’une bibliothèque de composants basée sur les slots, CompositionLocal comme alternative aux slots profonds, les caractéristiques de performance, et quand NE PAS utiliser les slots. Aucune nouvelle dépendance.
