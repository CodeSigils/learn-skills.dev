Настраивает мультиплатформенный DataStore для KMP: варианты Preferences (ключ‑значение) и Proto (типизированный, основанный на схеме). Охватывает createDataStore {} expect/actual для каждой платформы, чтение через Flow, запись с помощью корутин, миграцию из SharedPreferences и подключение Koin, чтобы модуль функций никогда не создавал DataStore напрямую.
