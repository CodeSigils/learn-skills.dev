Guide d'adoption incrémentielle pour les équipes qui déplacent un projet Android ou KMP existant vers l'architecture kmp-agent-skills. Couvre l'évaluation de l'état actuel, l'ordre d'adoption des compétences par priorité, les chemins de migration de MVVM+LiveData vers MVI, du monolithe vers le multi-module et comment migrer sans interrompre une application en direct. Utilisez cette compétence lorsqu'un projet existe déjà et que l'équipe souhaite adopter les compétences KMP une fonctionnalité ou une couche à la fois.
