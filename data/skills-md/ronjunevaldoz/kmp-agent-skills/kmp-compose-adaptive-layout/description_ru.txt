Адаптивный UI для Kotlin Multiplatform — макеты, управляемые WindowSizeClass, корректно реагирующие на точки прерывания Compact (телефон), Medium (планшет) и Expanded (десктоп). Охватывает разделение списка и детали, адаптивную навигацию (нижняя панель → рейка → выдвижное меню), единое распространение WindowSizeClass и тесты Roborazzi для каждой точки прерывания. Обеспечивает согласованность паттерна между сессиями, так чтобы каждый экран в проекте использовал одну и ту же адаптивную стратегию.
