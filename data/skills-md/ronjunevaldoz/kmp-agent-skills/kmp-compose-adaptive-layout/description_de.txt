Adaptive Benutzeroberfläche für Kotlin Multiplatform – WindowSizeClass-gesteuerte Layouts, die korrekt auf die Haltepunkte Compact (Telefon), Medium (Tablet) und Expanded (Desktop) reagieren. Deckt Listen-Detail-Aufteilungen, adaptive Navigation (untere Leiste → Schiene → Schublade), WindowSizeClass-Weitergabe aus einer einzigen Quelle und Roborazzi-Tests für jeden Haltepunkt ab. Erzwingt die sitzungsübergreifende Musterkonsistenz, sodass jeder Bildschirm im Projekt dieselbe adaptive Strategie verwendet.
