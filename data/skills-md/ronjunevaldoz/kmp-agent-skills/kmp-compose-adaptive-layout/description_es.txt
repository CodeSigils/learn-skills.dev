Interfaz de usuario adaptable para Kotlin multiplataforma: diseños basados ​​en WindowSizeClass que responden correctamente a los puntos de interrupción Compacto (teléfono), Medio (tableta) y Expandido (escritorio). Cubre divisiones de lista y detalles, navegación adaptativa (barra inferior → riel → cajón), propagación de WindowSizeClass de fuente única y pruebas de Roborazzi para cada punto de interrupción. Hace cumplir la coherencia del patrón entre sesiones para que cada pantalla del proyecto utilice la misma estrategia adaptativa.
