Interface utilisateur adaptative pour Kotlin Multiplatform : dispositions basées sur WindowSizeClass qui répondent correctement aux points d'arrêt Compact (téléphone), Medium (tablette) et Expanded (ordinateur de bureau). Couvre les divisions de détails de liste, la navigation adaptative (barre inférieure → rail → tiroir), la propagation WindowSizeClass à source unique et les tests Roborazzi pour chaque point d'arrêt. Applique la cohérence des modèles entre sessions afin que chaque écran du projet utilise la même stratégie adaptative.
