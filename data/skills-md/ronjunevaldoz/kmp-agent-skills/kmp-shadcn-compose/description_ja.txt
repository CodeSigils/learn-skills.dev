公開されている shadcn-compose ライブラリ（io.github.ronjunevaldoz:shadcn-compose）を使用します — shadcn/ui に触発された Compose Multiplatform コンポーネントライブラリで、70 以上のコンポーネントが含まれています。Maven Central の設定、必須の @OptIn(ExperimentalFoundationStyleApi::class)、ShadcnTheme ラッパーとその preset／baseColor／accent／isDark／baseRadius／ring パラメータ、そしてライブラリのソースと照らし合わせて検証された実際のコンポーネント使用例（ShadcnButton、ShadcnCard など）をカバーしています。kmp-compose-design-system の生成／所有アプローチの代替手段です — 同一プロジェクトで両方を併用しないでください。このスキルが特に開示している実際のリスクは、実験的な Compose Foundation Styles API へのハード依存があり、任意の CMP アップグレードで破壊的になる可能性があることです。上流の shadcn-compose リリース以外に修正手段はありません。
