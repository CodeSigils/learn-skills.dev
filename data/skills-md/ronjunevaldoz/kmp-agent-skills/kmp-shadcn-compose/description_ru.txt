Потребляет опубликованную библиотеку shadcn-compose (io.github.ronjunevaldoz:shadcn-compose) — библиотеку компонентов Compose Multiplatform, вдохновлённую shadcn/ui, с более чем 70 компонентами. Охватывает настройку Maven Central, обязательный @OptIn(ExperimentalFoundationStyleApi::class), обёртку ShadcnTheme и её параметры preset/baseColor/accent/isDark/baseRadius/ring, а также реальное использование компонентов (ShadcnButton, ShadcnCard и т.п.), проверенное по исходному коду библиотеки. Альтернатива подходу kmp-compose-design-system с генерацией/владением — нельзя использовать оба в одном проекте. Существует реальный риск, раскрытый этим навыком: жёсткая зависимость от экспериментального API Compose Foundation Styles, который может сломаться при любом обновлении CMP, и исправление доступно только в виде нового upstream‑релиза shadcn-compose.
