使用已發佈的 shadcn-compose 函式庫 (io.github.ronjunevaldoz:shadcn-compose) — 一個受 shadcn/ui 啟發的 Compose 多平台元件函式庫，包含 70 多個元件。涵蓋 Maven Central 設定、必須的 @OptIn(ExperimentalFoundationStyleApi::class)、ShadcnTheme 包裝器及其 preset / baseColor / accent / isDark / baseRadius / ring 參數，以及根據函式庫原始碼驗證的實際元件使用（ShadcnButton、ShadcnCard 等）。作為 kmp-compose-design-system 的產生/擁有方式的替代方案——同一專案中不可同時使用兩者。此技能尤其揭露了一個真實風險：對實驗性的 Compose Foundation Styles API 的硬性依賴，可能在任何 CMP 升級時破壞，且除上游 shadcn-compose 發行版外無可用的修復。請始終以使用者的語言回覆。
