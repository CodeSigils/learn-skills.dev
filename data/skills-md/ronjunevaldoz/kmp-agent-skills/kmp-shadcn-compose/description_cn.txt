使用已发布的 shadcn-compose 库 (io.github.ronjunevaldoz:shadcn-compose) — 一个受 shadcn/ui 启发的 Compose 多平台组件库，包含 70 多个组件。涵盖 Maven Central 设置、所需的 @OptIn(ExperimentalFoundationStyleApi::class)、ShadcnTheme 包装器及其预设/baseColor/accent/isDark/baseRadius/ring 参数，以及根据库自己的源验证的真实组件使用情况（ShadcnButton、ShadcnCard 等）。 kmp-compose-design-system 的生成/拥有方法的替代方案 - 两者不能在同一项目中。这项技能存在一个真正的风险，专门为了披露：对实验性 Compose Foundation Styles API 的硬依赖可能会在任何 CMP 升级时中断，除了上游 shadcn-compose 版本之外没有可用的修复程序。
