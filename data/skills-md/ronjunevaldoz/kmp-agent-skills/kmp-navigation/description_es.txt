Configura la navegación con seguridad de tipos en un proyecto Kotlin Multiplatform Compose usando Jetpack Navigation Compose para KMP (org.jetbrains.androidx.navigation). Cubre: definiciones de ruta con kotlinx.serialization, configuración de NavHost en un gráfico de navegación :app:shared o :feature:*:ui, argumentos de tipo seguro, enlaces profundos y cableado de navegación inferior. Funciona en Android, iOS, escritorio (JVM) y web (JS/WasmJs). Se supone que el proyecto fue estructurado con kmp-feature-scaffold.
