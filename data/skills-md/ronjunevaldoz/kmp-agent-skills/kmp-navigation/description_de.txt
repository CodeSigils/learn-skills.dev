Richtet typsichere Navigation in einem Kotlin‑Multiplattform‑Compose‑Projekt ein, das Jetpack Navigation Compose für KMP (org.jetbrains.androidx.navigation) verwendet. Behandelt: Routendefinitionen mit kotlinx.serialization, NavHost‑Einrichtung in einem :app:shared‑ oder :feature:*:ui‑Navigationsgraphen, typsichere Argumente, Deep Links und die Verkabelung der Bottom‑Navigation. Funktioniert auf Android, iOS, Desktop (JVM) und Web (JS/WasmJs). Es wird davon ausgegangen, dass das Projekt mit kmp-feature-scaffold erstellt wurde. Bitte immer in der Sprache des Benutzers antworten.
