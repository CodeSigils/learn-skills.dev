Настраивает типобезопасную навигацию в проекте Kotlin Multiplatform Compose с использованием Jetpack Navigation Compose для KMP (org.jetbrains.androidx.navigation). Охватывает: определения маршрутов с помощью kotlinx.serialization, настройку NavHost в графе навигации :app:shared или :feature:*:ui, типобезопасные аргументы, глубокие ссылки и привязку нижней навигации. Работает на Android, iOS, Desktop (JVM) и Web (JS/WasmJs). Предполагает, что проект был создан с помощью kmp-feature-scaffold.
