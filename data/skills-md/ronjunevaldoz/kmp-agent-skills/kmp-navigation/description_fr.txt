Configure une navigation sécurisée dans un projet Kotlin Multiplatform Compose à l'aide de Jetpack Navigation Compose pour KMP (org.jetbrains.androidx.navigation). Couvre : les définitions d'itinéraire avec kotlinx.serialization, la configuration de NavHost dans un graphique de navigation :app:shared ou :feature:*:ui, les arguments de type sécurisé, les liens profonds et le câblage de navigation inférieur. Fonctionne sur Android, iOS, Desktop (JVM) et Web (JS/WasmJs). Suppose que le projet a été échafaudé avec kmp-feature-scaffold.
