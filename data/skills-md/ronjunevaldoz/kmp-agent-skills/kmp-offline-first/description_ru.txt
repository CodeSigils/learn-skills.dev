Архитектура «offline-first» для приложений Kotlin Multiplatform — локальные чтения в первую очередь, фоновая синхронизация, оптимистичные обновления, разрешение конфликтов и отслеживание состояния синхронизации. Охватывает: единственный источник правды через SQLDelight, паттерн SyncManager с использованием WorkManager/BGTaskScheduler, оптимистичные изменения с откатом и запечатлённый (sealed) класс SyncState, предоставляемый UI через MVI. Не охватывает синхронизацию, инициируемую FCM (см. push-notifications), или потоковую работу RPC (см. kotlin-rpc). Пожалуйста, всегда отвечайте на языке пользователя.
