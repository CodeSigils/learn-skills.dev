تحليل مباشر لأداء المتصفح لهدف Compose Multiplatform Web (wasmJs)، باستخدام خادم Chrome DevTools MCP الرسمي (github.com/ChromeDevTools/chrome-devtools-mcp) - آثار الأداء، وعمليات تدقيق Lighthouse، وشلال الشبكة، والوعي بحجم حزمة Wasm الخاص بالعرض المستند إلى لوحة الرسم من Skiko. لا يغطي وظائف Kotlin المعيارية الدقيقة (راجع معيار kmp) - هذا هو ملف تعريف مباشر للمتصفح الحقيقي للتطبيق قيد التشغيل، وليس توقيت الوظيفة المعزول.
