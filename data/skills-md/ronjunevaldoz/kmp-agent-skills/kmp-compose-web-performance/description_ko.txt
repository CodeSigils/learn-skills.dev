공식 Chrome DevTools MCP 서버(github.com/ChromeDevTools/chrome-devtools-mcp)를 사용한 Compose Multiplatform Web(wasmJs) 대상의 실시간 브라우저 성능 분석 — 성능 트레이스, Lighthouse 감사, 네트워크 워터폴, 그리고 Skiko의 캔버스 기반 렌더링에 특화된 Wasm 번들 크기 인식. Kotlin 함수의 마이크로 벤치마킹은 포함되지 않음(kmp-benchmark 참조) — 이는 실행 중인 앱의 실시간 실제 브라우저 프로파일링이며, 개별 함수 타이밍이 아님.
