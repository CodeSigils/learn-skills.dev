Analisi delle prestazioni del browser in tempo reale per un target Compose Multiplatform Web (wasmJs), utilizzando il server MCP Chrome DevTools ufficiale (github.com/ChromeDevTools/chrome-devtools-mcp): tracce delle prestazioni, controlli Lighthouse, cascata di rete e consapevolezza della dimensione del bundle Wasm specifica per il rendering basato su tela di Skiko. NON copre le funzioni Kotlin di micro-benchmarking (vedi kmp-benchmark): si tratta di profilazione in tempo reale del browser reale dell'app in esecuzione, non di tempistica di funzioni isolate.
