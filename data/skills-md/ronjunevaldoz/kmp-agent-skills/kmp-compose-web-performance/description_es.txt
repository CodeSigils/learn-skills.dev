Análisis de rendimiento del navegador en vivo para un objetivo Compose Multiplatform Web (wasmJs), utilizando el servidor MCP oficial Chrome DevTools (github.com/ChromeDevTools/chrome-devtools-mcp): seguimientos de rendimiento, auditorías de Lighthouse, cascada de red y conocimiento del tamaño del paquete Wasm específico para la representación basada en lienzo de Skiko. NO cubre las funciones de Kotlin de microevaluación comparativa (consulte kmp-benchmark): se trata de un perfil en vivo y en un navegador real de la aplicación en ejecución, no de una sincronización de funciones aislada.
