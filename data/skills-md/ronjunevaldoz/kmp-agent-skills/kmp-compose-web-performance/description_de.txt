Live-Browser-Performance-Analyse für ein Compose Multiplatform Web (wasmJs)-Ziel, unter Verwendung des offiziellen Chrome DevTools MCP-Servers (github.com/ChromeDevTools/chrome-devtools-mcp) — Performance‑Traces, Lighthouse‑Audits, Netzwerk‑Waterfall und Wasm‑Bundle‑Größenbewusstsein, speziell für Skikos canvas‑basiertes Rendering.
