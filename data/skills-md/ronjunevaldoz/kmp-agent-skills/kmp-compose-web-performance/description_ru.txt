Живой анализ производительности браузера для цели Compose Multiplatform Web (wasmJs) с использованием официального сервера Chrome DevTools MCP (github.com/ChromeDevTools/chrome-devtools-mcp) — трассировки производительности, аудиты Lighthouse, сетевой водопад и осведомлённость о размере Wasm‑бандла, специфичная для рендеринга на основе canvas в Skiko. НЕ включает микро‑бенчмаркинг функций Kotlin (см. kmp-benchmark) — это живое профилирование в реальном браузере работающего приложения, а не измерение времени изолированных функций.
