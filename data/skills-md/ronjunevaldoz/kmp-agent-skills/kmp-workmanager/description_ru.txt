Планирование фоновых задач для Kotlin Multiplatform — WorkManager (Android) и BGTaskScheduler / BGProcessingTask (iOS) через expect/actual BackgroundScheduler. Охватывает однократную работу, периодическую работу, повторные попытки с экспоненциальным откатом, ввод/вывод данных и цепочку задач на Android. iOS использует BGAppRefreshTask для коротких частых задач и BGProcessingTask для длительных сетевых или обслуживающих заданий.
