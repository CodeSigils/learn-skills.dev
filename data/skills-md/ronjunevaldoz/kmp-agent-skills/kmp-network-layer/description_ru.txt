Создаёт готовый к продакшну сетевой слой Ktor 3 в :core:network для проекта Kotlin Multiplatform. Охватывает: платформенные движки (OkHttp/Darwin/CIO/Js) для Android, iOS, Desktop (JVM) и Web (JS + WasmJs), ContentNegotiation, аутентификацию Bearer с автоматическим обновлением токена (защищённым от гонок), структурированное сопоставление ошибок в запечатлённый тип NetworkResult<T>, логирование запросов/ответов и настройку Koin. Предполагается, что проект был скафолдирован с помощью kmp-feature-scaffold.
