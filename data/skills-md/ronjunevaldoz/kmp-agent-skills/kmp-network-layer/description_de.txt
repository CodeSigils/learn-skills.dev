Erstellt eine produktionsreife Ktor‑3‑Netzwerkschicht in :core:network für ein Kotlin‑Multiplattform‑Projekt. Beinhaltet: Plattform‑Engines (OkHttp/Darwin/CIO/Js) für Android, iOS, Desktop (JVM) und Web (JS + WasmJs), ContentNegotiation, Bearer‑Authentifizierung mit automatischer Token‑Erneuerung (race‑condition‑sicher), strukturierte Fehlermapping zu einem versiegelten Typ NetworkResult<T>, Request/Response‑Logging und Koin‑Verdrahtung. Es wird davon ausgegangen, dass das Projekt mit kmp‑feature‑scaffold erstellt wurde.
