Genera una layer di rete Ktor 3 pronta per la produzione all’interno di :core:network per un progetto Kotlin Multiplatform. Copre: engine di piattaforma (OkHttp/Darwin/CIO/Js) per Android, iOS, Desktop (JVM) e Web (JS + WasmJs), ContentNegotiation, autenticazione Bearer con aggiornamento automatico del token (senza condizioni di gara), mappatura strutturata degli errori in un tipo sealed NetworkResult<T>, logging di richieste/risposte e wiring di Koin. Si assume che il progetto sia stato creato con kmp-feature-scaffold.
