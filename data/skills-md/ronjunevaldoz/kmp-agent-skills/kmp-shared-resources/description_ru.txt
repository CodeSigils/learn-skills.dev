Настраивает Compose Multiplatform Resources (compose-resources) для совместного использования строк, множественного числа, изображений, шрифтов и сырых файлов во всех целевых платформах KMP (Android, iOS, Desktop, Web). Охватывает: структуру каталогов ресурсов, локализацию строк, множественное число, графические ресурсы, пользовательские шрифты, доступ к ресурсам из Composable и не‑Composable кода, а также настройку модуля ресурсов. Предполагается, что проект был создан с помощью kmp-feature-scaffold.
