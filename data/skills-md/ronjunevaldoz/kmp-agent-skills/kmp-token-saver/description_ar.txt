سير عمل توفير الرمز المميز لعمل وكيل KMP. يُستخدم عندما يطلب المستخدم تقليل استخدام الرمز المميز، أو تقصير الردود، أو ضغط مخرجات الأداة المزعجة، أو اختيار أصغر حل صحيح. يغطي Ponytail لـ YAGNI والفحوصات الهندسية الزائدة، وCaveman للردود المقتضبة، وRTK لضغط مخرجات الصدفة، وHeadroom لضغط الأداة/السجل/الملف/RAG عندما يكون المضيف قد تم تكوينه بالفعل. يبقى الإرتفاع اختياريًا حتى يتوفر الإعداد؛ لا تمنع المهمة عليه.
