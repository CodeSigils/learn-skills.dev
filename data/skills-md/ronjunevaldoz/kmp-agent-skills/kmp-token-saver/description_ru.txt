Процесс экономии токенов для работы агента KMP. Используйте, когда пользователь просит сократить использование токенов, укорачивать ответы, сжимать шумный вывод инструментов или выбирать наименьшее корректное решение. Включает Ponytail для проверок YAGNI и избыточного проектирования, Caveman для лаконичных ответов, RTK для сжатия вывода оболочки и Headroom для сжатия инструментов/логов/файлов/RAG, когда хост уже настроен. Headroom остаётся опциональным, пока настройка не выполнена; не блокируйте задачу из‑за него.
