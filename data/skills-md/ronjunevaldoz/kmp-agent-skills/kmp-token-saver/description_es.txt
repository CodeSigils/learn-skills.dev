Flujo de trabajo para ahorrar tokens en el trabajo del agente KMP. Incluye Ponytail para verificaciones YAGNI y de sobreingeniería, Caveman para respuestas concisas, RTK para compresión de salida de shell y Headroom para compresión de herramienta, registro, archivo o RAG cuando el host ya está configurado. Headroom permanece opcional hasta que exista la configuración; no bloquee la tarea por ello.

Por favor, responda siempre en el idioma del usuario.
