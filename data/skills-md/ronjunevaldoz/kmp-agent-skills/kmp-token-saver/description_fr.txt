Flux de travail économisant les jetons pour le travail des agents KMP. À utiliser lorsque l'utilisateur demande de réduire l'utilisation des jetons, de raccourcir les réponses, de compresser la sortie bruyante de l'outil ou de choisir la plus petite solution correcte. Couvre Ponytail pour YAGNI et les contrôles de suringénierie, Caveman pour les réponses concises, RTK pour la compression de sortie du shell et Headroom pour la compression outil/journal/fichier/RAG lorsque l'hôte est déjà configuré. La marge reste facultative jusqu'à ce que la configuration soit disponible ; ne bloquez pas la tâche dessus.
