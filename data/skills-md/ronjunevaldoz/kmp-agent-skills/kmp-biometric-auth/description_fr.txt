Authentification biométrique pour Kotlin Multiplatform — un type scellé BiometricResult dans commonMain, expect/actual BiometricAuthenticator, Android BiometricPrompt avec CryptoObject, iOS LocalAuthentication (LAContext.evaluatePolicy), configuration Koin, et recours élégant au code PIN/mot de passe de l’appareil lorsque les données biométriques sont indisponibles.
