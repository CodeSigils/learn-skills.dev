Составляет и поддерживает документацию по макету экрана KMP в docs/layout-system/. Создает одну спецификацию уценки и каркас SVG для каждого экрана, а также общий реестр компонентов. Используйте для новых экранов, изменений макета, проверки макета или проектов, в которых отсутствуют спецификации макета; создайте документацию до или во время реализации.
