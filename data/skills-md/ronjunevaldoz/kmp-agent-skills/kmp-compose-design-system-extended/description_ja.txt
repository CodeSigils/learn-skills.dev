:core:designsystem（kmp-compose-design-system から）を拡張し、Compose Styles API を使用して 28 の本番レベルのコンポーネントを提供します。対象は、Icon、IconButton、Label、Separator、Avatar、TopAppBar、NavigationBar、Tabs、Checkbox、RadioButton、Switch、Slider、Select/Dropdown、Progress（linear + circular）、Skeleton、Spinner、Alert、Toast/Snackbar システム（AppToastHostState + Scaffold スロット）、Dialog、AlertDialog、Sheet（BottomSheet）、Tooltip、Popover、Accordion/Collapsible、ScrollArea（Desktop のみのスクロールバーを expect/actual で実装）、ResizablePanelGroup（ドラッグ可能な分割線）です。すべてのコンポーネントは CMP プリミティブ上に構築されており、Material3 は使用していません。「App」はプレースホルダーのプレフィックスです——プロジェクト名からどのように解決されるかはベーススキルの Step 0（scripts/derive_component_prefix.py）を参照してください。kmp-compose-design-system スキルが必要です。
