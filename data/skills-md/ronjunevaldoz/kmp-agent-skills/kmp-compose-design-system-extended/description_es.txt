Amplía :core:designsystem (de kmp-compose-design-system) con 28 componentes listos para producción utilizando la API Compose Styles. Cubiertas: Icono, IconButton, Etiqueta, Separador, Avatar, TopAppBar, NavigationBar, Pestañas, Casilla de verificación, RadioButton, Interruptor, Control deslizante, Seleccionar/Desplegable, Progreso (lineal + circular), Esqueleto, Girador, Alerta, Sistema Toast/Snackbar (AppToastHostState + ranura Scaffold), Diálogo, AlertDialog, Hoja (BottomSheet), Información sobre herramientas, Ventana emergente, Acordeón/Plegable, Área de desplazamiento (barra de desplazamiento solo de escritorio a través de expect/actual), ResizablePanelGroup (divisor arrastrable). Todos los componentes se basan en primitivas CMP (sin Material3). "Aplicación" es un prefijo de marcador de posición; consulte el Paso 0 de la habilidad base para saber cómo se resuelve a partir del nombre del proyecto (scripts/derive_component_prefix.py). Requiere habilidad kmp-compose-design-system.
