扩展 :core:designsystem（来自 kmp-compose-design-system），使用 Compose Styles API 提供 28 个可直接投产的组件。覆盖：图标、图标按钮、标签、分割线、头像、TopAppBar、NavigationBar、标签页、复选框、单选按钮、开关、滑块、选择/下拉列表、进度（线性 + 环形）、骨架屏、加载指示器、警告、Toast/Snackbar 系统（AppToastHostState + Scaffold 插槽）、对话框、AlertDialog、底部弹出层（BottomSheet）、Tooltip、Popover、手风琴/折叠面板、滚动区域（仅桌面滚动条 via expect/actual）、可伸缩面板组（可拖动分隔线）。所有组件基于 CMP 原语实现（不使用 Material3）。“App” 为占位前缀——参见基础技能 Step 0，了解如何从项目名称解析（scripts/derive_component_prefix.py）。需要 kmp-compose-design-system 技能。
