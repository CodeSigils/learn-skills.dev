Расширяет :core:designsystem (из kmp-compose-design-system) 28 готовыми к использованию в продакшене компонентами с использованием Compose Styles API. Включает: Icon, IconButton, Label, Separator, Avatar, TopAppBar, NavigationBar, Tabs, Checkbox, RadioButton, Switch, Slider, Select/Dropdown, Progress (linear + circular), Skeleton, Spinner, Alert, Toast/Snackbar system (AppToastHostState + Scaffold slot), Dialog, AlertDialog, Sheet (BottomSheet), Tooltip, Popover, Accordion/Collapsible, ScrollArea (Desktop‑only scrollbar via expect/actual), ResizablePanelGroup (draggable divider). Все компоненты построены на примитивах CMP (без Material3). «App» — это заполнительный префикс; см. Шаг 0 базового навыка, чтобы понять, как он определяется из названия проекта (scripts/derive_component_prefix.py). Требуется навык kmp-compose-design-system.
