Estende :core:designsystem (da kmp-compose-design-system) con 28 componenti pronti per la produzione utilizzando l'API Compose Styles. Copertine: Icona, IconButton, Etichetta, Separatore, Avatar, TopAppBar, NavigationBar, Schede, Casella di controllo, RadioButton, Switch, Slider, Seleziona/Dropdown, Progresso (lineare + circolare), Scheletro, Spinner, Avviso, Sistema Toast/Snackbar (AppToastHostState + slot Scaffold), Finestra di dialogo, AlertDialog, Foglio (BottomSheet), Descrizione comando, Popover, Accordion/Collapsible, ScrollArea (Barra di scorrimento solo desktop tramite previsto/attuale), ResizablePanelGroup (divisore trascinabile). Tutti i componenti costruiti su primitive CMP (no Material3). "App" è un prefisso segnaposto: consulta il passaggio 0 della competenza di base per sapere come viene risolto dal nome del progetto (scripts/derive_component_prefix.py). Richiede competenze nel sistema di progettazione kmp-compose.
