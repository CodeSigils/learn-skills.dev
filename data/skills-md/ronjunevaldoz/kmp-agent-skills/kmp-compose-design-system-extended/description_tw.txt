使用 Compose Styles API 擴充 :core:designsystem（來自 kmp-compose-design-system），提供 28 個可投入生產的元件。涵蓋：Icon、IconButton、Label、Separator、Avatar、TopAppBar、NavigationBar、Tabs、Checkbox、RadioButton、Switch、Slider、Select/Dropdown、Progress（線性與環形）、Skeleton、Spinner、Alert、Toast/Snackbar 系統（AppToastHostState + Scaffold slot）、Dialog、AlertDialog、Sheet（BottomSheet）、Tooltip、Popover、Accordion/Collapsible、ScrollArea（僅桌面版捲軸，透過 expect/actual）、ResizablePanelGroup（可拖曳的分隔線）。所有元件皆基於 CMP 原始元件構建（不使用 Material3）。「App」為佔位字首——請參閱基礎技能 Step 0，了解如何從專案名稱解析（scripts/derive_component_prefix.py）。需要 kmp-compose-design-system 技能。
