Étend :core:designsystem (de kmp-compose-design-system) avec 28 composants prêts pour la production à l'aide de l'API Compose Styles. Couvre : Icône, IconButton, Étiquette, Séparateur, Avatar, TopAppBar, NavigationBar, Onglets, Case à cocher, RadioButton, Switch, Slider, Select/Dropdown, Progress (linéaire + circulaire), Skeleton, Spinner, Alert, Toast/Snackbar system (AppToastHostState + Scaffold slot), Dialog, AlertDialog, Sheet (BottomSheet), Tooltip, Popover, Accordion/Collapsible, ScrollArea. (Barre de défilement du bureau uniquement via attendu/réel), ResizingPanelGroup (diviseur déplaçable). Tous les composants construits sur des primitives CMP (pas de Material3). « App » est un préfixe d'espace réservé — consultez l'étape 0 de la compétence de base pour savoir comment il est résolu à partir du nom du projet (scripts/derive_component_prefix.py). Nécessite la compétence kmp-compose-design-system.
