Создает полноценную мультиплатформенную систему дизайна Compose в :core:designsystem с использованием экспериментального API Compose Styles. Создает токены семантического дизайна, AppTheme, средства доступа к стилю, варианты запечатанных компонентов и базовые примитивы App* без Material. Префикс приложения основан на имени проекта и может быть настроен.
