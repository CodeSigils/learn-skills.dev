Stellt ein vollständig eigenes Compose Multiplattform-Designsystem in :core:designsystem unter Verwendung der experimentellen Compose Styles API bereit. Erzeugt semantische Design-Tokens, AppTheme, Stil-Accessoren, versiegelte Komponentenvarianten und Kern-App*-Grundelemente ohne Material. Das App-Präfix leitet sich vom Namen des Projekts ab und kann angepasst werden.
