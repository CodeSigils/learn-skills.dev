KMP 專屬的 Google 官方 `android` CLI 整合指南。CLI 本身的指令參考已於 github.com/android/skills/tree/main/devtools/android-cli 以真實、官方維護的 skill 形式存在（可透過 `android skills add android-cli` 安裝）——此 skill 並未重新編寫該表面的文件。它說明了 Kotlin Multiplatform 專案的特定內容：在多模組六層圖中定位 Android 目標、為何在執行 `kmp-feature-scaffold` 後 `android create` 不再適用，以及在現有 Android/iOS/Desktop/Web 矩陣下的 CI 串接方式。
