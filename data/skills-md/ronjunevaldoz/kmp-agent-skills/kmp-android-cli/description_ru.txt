Специальное руководство по интеграции KMP для официального интерфейса командной строки Android от Google. Собственная ссылка на команды CLI уже существует как реальный, официально поддерживаемый навык на github.com/android/skills/tree/main/devtools/android-cli (устанавливается через `androidkills add android-cli`) — этот навык не документирует эту поверхность повторно. В нем рассматриваются особенности многоплатформенного проекта Kotlin: расположение цели Android внутри многомодульного 6-слойного графа, почему `android create` не применяется после запуска `kmp-feature-scaffold`, а также подключение CI к существующей матрице Android/iOS/Desktop/Web.
