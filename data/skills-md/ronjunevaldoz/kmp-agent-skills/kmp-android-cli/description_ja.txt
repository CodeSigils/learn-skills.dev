Google の公式 `android` CLI の KMP 固有の統合ガイド。 CLI 独自のコマンド リファレンスは、実際に公式に管理されているスキルとして github.com/android/skills/tree/main/devtools/android-cli にすでに存在しています (`android skill add android-cli` 経由でインストール可能)。このスキルはその表面を再文書化するものではありません。 Kotlin マルチプラットフォーム プロジェクトに固有の内容、つまりマルチモジュール 6 層グラフ内の Android ターゲットの配置、「kmp-feature-scaffold」が実行されると「android create」が適用されない理由、および既存の Android/iOS/Desktop/Web マトリックスと並行した CI の接続について説明します。
