Guía de integración específica de KMP para la CLI oficial de "android" de Google. La propia referencia de comando de la CLI ya existe como una habilidad real mantenida oficialmente en github.com/android/skills/tree/main/devtools/android-cli (instalable a través de `android skills add android-cli`): esta habilidad no vuelve a documentar esa superficie. Cubre lo que es específico de un proyecto multiplataforma de Kotlin: ubicar el destino de Android dentro de un gráfico de 6 capas de múltiples módulos, por qué "android create" no se aplica una vez que "kmp-feature-scaffold" se ha ejecutado y el cableado de CI junto con la matriz Android/iOS/Desktop/Web existente.
