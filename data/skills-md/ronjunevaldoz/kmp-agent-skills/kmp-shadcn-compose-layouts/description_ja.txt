shadcn-compose の個々の Shadcn* コンポーネントを、ログイン/認証フォーム、汎用データ入力フォーム、データテーブル画面、管理ダッシュボードシェルなどのフルページレイアウトに組み立てます — ライブラリ自体の実際のソースに対して直接検証されたレシピを使用し、実際の shadcn/ui の React ブロックとの類推で想定することはありません。また、既存の画面を監査し、shadcn-compose のプリミティブが十分に活用されていない箇所（ShadcnField の代わりに手作りのフォームフィールド、ShadcnTable の代わりに手作りのテーブル、ShadcnSidebar が欠如した管理シェル）を特定し、具体的な移行方法を提案します。kmp-shadcn-compose の補完であり、個々のコンポーネントの検証で止まり、ページレベルの構成はカバーしていません。
