Crea una arquitectura de módulo de funciones múltiples Kotlin Multiplatform (KMP) lista para producción. Crea un proyecto completo generando a partir de la línea base oficial de Kotlin/kmp-wizard AGP 9, generalmente la rama `all-targets` para Android, iOS, web, escritorio y servidor, o agrega un nuevo grupo de módulos de funciones (:model/:api/:domain/:data/:presenter/:ui) a un proyecto KMP existente. Utiliza AGP 9+, complementos de convención de lógica de compilación, un catálogo de versiones TOML (`gradle/libs.versions.toml`), Compose Multiplatform y Koin 4 (DI anotado o manual).
