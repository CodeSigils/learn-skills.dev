يقوم بتقليد *شكل* API العام (نقاط دخول DSL، كائنات مُعدِّلات قابلة للسلسلة، لامبدا للفتحات، تعليقات توضيحية علامة، بانيون بنطاق) لواجهة برمجة تطبيقات مرجعية معروفة — Jetpack Compose، SwiftUI، Retrofit، Room، إلخ — عند بناء مكتبة Kotlin متعددة المنصات من الصفر على بيئة تشغيل مختلفة (محرك عرض Vulkan/Metal مخصص، محرك RPC مخصص، محرك تخزين دائم مخصص). لا يغطي استهلاك أو تغليف المكتبة المرجعية الفعلية — فهذا هو الاستخدام الاعتيادي للتابع. لا يغطي بناء مكوّن plugin بأسلوب Compose‑compiler الحقيقي؛ يقتصر صراحةً على تقليد DSL للوظائف البسيطة ويوثّق ما تفقده من إعادة تركيب/تخطي حقيقي عندما لا تكتب واحدًا.
