よく知られたリファレンス API（Jetpack Compose、SwiftUI、Retrofit、Room など）の公開 API の形（DSL エントリーポイント、チェーン可能な修飾子オブジェクト、スロットラムダ、マーカーアノテーション、スコープ付きビルダー）を模倣し、別のランタイム（カスタム Vulkan/Metal レンダラー、カスタム RPC エンジン、カスタム永続化エンジン）上でゼロから Kotlin Multiplatform ライブラリを構築する際に使用します。実際のリファレンスライブラリを消費またはラップすることは対象外です―それは通常の依存関係の使用です。Compose コンパイラスタイルのプラグインを構築することも対象外であり、純粋な関数 DSL の模倣に限定し、プラグインを作成しないことによって失われる実際の再構成／スキップ機能について文書化します。
