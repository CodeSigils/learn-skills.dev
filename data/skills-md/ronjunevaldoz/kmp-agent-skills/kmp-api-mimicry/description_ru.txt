Имитирует *форму* общедоступного API (точки входа DSL, цепочки объектов-модификаторов, лямбда-выражения слотов, аннотации маркеров, построители с ограниченной областью действия) известного эталонного API — Jetpack Compose, SwiftUI, Retrofit, Room и т. д. — при создании с нуля многоплатформенной библиотеки Kotlin в другой среде выполнения (собственный модуль рендеринга Vulkan/Metal, собственный механизм RPC, собственный механизм сохранения). НЕ охватывает использование или перенос реальной справочной библиотеки — это обычное использование зависимостей. НЕ охватывает создание настоящего плагина в стиле компилятора Compose; явно ограничивается простой имитацией DSL и документирует, от какой реальной рекомпозиции/пропуска вы отказываетесь, не написав ее.
