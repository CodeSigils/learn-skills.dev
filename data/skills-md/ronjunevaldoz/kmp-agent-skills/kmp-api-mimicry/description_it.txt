Imita la *forma* dell'API pubblica (punti di ingresso DSL, oggetti modificatori concatenabili, lambda di slot, annotazioni marcatore, builder con ambito) di un'API di riferimento ben nota — Jetpack Compose, SwiftUI, Retrofit, Room, ecc. — quando si costruisce da zero una libreria Kotlin Multiplatform su un runtime diverso (un renderer Vulkan/Metal personalizzato, un motore RPC personalizzato, un motore di persistenza personalizzato). Non copre il consumo o il wrapping della libreria di riferimento reale — quello è un uso normale delle dipendenze. Non copre la costruzione di un vero plugin in stile Compose‑compiler; si limita esplicitamente all'imitazione di DSL a funzioni plain e documenta quale ricomposizione/skipping reale si rinuncia a causa del non averne scritto uno.
