Injection de dépendances KMP avec Koin — recommandez d'abord les modules manuels, puis le mode annoté lorsque moins de câblage est souhaité. Couvre les limites de portée de l'application/feature, l'injection par constructeur, l'organisation des modules, le démarrage de la plateforme, les surcharges de tests, et les anti‑patterns qui cachent les problèmes d'architecture derrière l'injection de dépendances. Utilisez ceci pour décider comment câbler les dépendances KMP au lieu de répéter la configuration de Koin dans d'autres compétences.
