Gestion des autorisations d'exécution pour Kotlin Multiplatform : un type PermissionState scellé dans commonMain, PermissionController attendu/réel, un lanceur basé sur l'activité Android, des clés iOS Info.plist et une utilisation d'AVFoundation/CoreLocation, et une interface utilisateur Compose multiplateforme pour les boîtes de dialogue de justification.
