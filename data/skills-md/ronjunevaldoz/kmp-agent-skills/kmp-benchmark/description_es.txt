Configura kotlinx-benchmark para la medición del rendimiento de Kotlin Multiplataforma. Cubre: complemento Gradle + cableado completamente abierto, un conjunto de fuentes de referencia separadas (nunca mezcladas con commonMain/commonTest), convenciones @State/@Benchmark/@Setup/@TearDown, registro por objetivo (JVM/Native/JS/Wasm), ejecución de pruebas comparativas y lectura de salida JSON/CSV. Utilice esto siempre que una reclamación de rendimiento necesite un número real en lugar de una suposición: este es el primer paso del "perfil" al que se dirige el árbol de decisiones de rendimiento de kmp-experto cuando una solicitud no tiene nombre o necesita un objetivo concreto antes de seguir enrutando.
