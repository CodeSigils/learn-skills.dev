Configure Kotlinx-benchmark pour la mesure des performances de Kotlin Multiplatform. Couvre : plugin Gradle + câblage allopen, un ensemble de sources de référence séparé (jamais mélangé dans commonMain/commonTest), les conventions @State/@Benchmark/@Setup/@TearDown, l'enregistrement par cible (JVM/Native/JS/Wasm), l'exécution de tests de performance et la lecture de la sortie JSON/CSV. Utilisez-le chaque fois qu'une réclamation de performance nécessite un nombre réel au lieu d'une supposition - il s'agit de la première étape du "profil" vers laquelle l'arbre de décision de performance de kmp-expert se dirige lorsqu'une requête n'a pas de nom ou nécessite une cible concrète avant un acheminement ultérieur.
