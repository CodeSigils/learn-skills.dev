Создание шаблонов мультиплатформенной анимации — AnimatedVisibility с переходами входа и выхода, animateContentSize, Crossfade для переходов на уровне экрана, animateFloatAsState/animateDpAsState для анимации свойств и переходов общих элементов (Compose 1.7+). Описывает, когда использовать каждый API и как обеспечить доступность анимации с поддержкой замедленного движения.
