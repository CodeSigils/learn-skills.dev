أنماط الرسوم المتحركة في Compose Multiplatform — AnimatedVisibility مع انتقالات الدخول/الخروج، animateContentSize، Crossfade لتبديلات الشاشة، animateFloatAsState / animateDpAsState للرسوم المتحركة للخصائص، وانتقالات العناصر المشتركة (Compose 1.7+). يغطي متى يُستخدم كل API وكيفية الحفاظ على إمكانية الوصول للرسوم المتحركة مع دعم تقليل الحركة.
