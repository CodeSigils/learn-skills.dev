GitHub Pages にデプロイされた、公開された Kotlin マルチプラットフォーム ライブラリ用の公開開発者ガイド Web サイト (スタートガイド、ガイド、コード サンプル、API リファレンス) をセットアップします。手書きのガイド コンテンツ用の MkDocs マテリアル、自動生成された API リファレンス用の Dokka HTML、コード サンプルが古くならないようにするコンパイラ検証済みのスニペット抽出手法、および CI デプロイ ワークフローについて説明します。ライブラリのみ — 開発者ガイドを作成する外部コンシューマーが存在しないアプリ プロジェクトには適用されません。 kmp-library-publishing (Maven Central パイプラインを所有) および kmp-project-docs-maintainer (内部の非公開計画ドキュメントを所有) とは異なります。
