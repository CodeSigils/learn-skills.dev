Configura un sito Web pubblico con guida per sviluppatori (operazioni iniziali, guide, esempi di codice, riferimento API) per una libreria multipiattaforma Kotlin pubblicata, distribuita su GitHub Pages. Copre il materiale MkDocs per il contenuto della guida scritta a mano, l'HTML Dokka per il riferimento API generato automaticamente, una tecnica di estrazione di snippet verificata dal compilatore in modo che gli esempi di codice non possano diventare obsoleti e il flusso di lavoro di distribuzione CI. Solo libreria: non si applica ai progetti di app che non hanno consumatori esterni per cui scrivere una guida per sviluppatori. Distinto da kmp-library-publishing (possiede la pipeline Maven Central) e kmp-project-docs-maintainer (possiede documenti di pianificazione interni, non pubblici).
