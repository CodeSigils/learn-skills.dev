Richtet eine öffentliche Entwickler‑Guide‑Website (Getting Started, Anleitungen, Code‑Beispiele, API‑Referenz) für eine veröffentlichte Kotlin‑Multiplatform‑Bibliothek ein, die auf GitHub Pages bereitgestellt wird. Behandelt MkDocs Material für handgeschriebene Guide‑Inhalte, Dokka‑HTML für automatisch generierte API‑Referenz, eine compiler‑validierte Snippet‑Extraktionstechnik, sodass Code‑Beispiele nicht veralten, sowie den CI‑Deploy‑Workflow. Nur für Bibliotheken – gilt nicht für App‑Projekte, die keine externen Konsumenten haben, für die ein Entwickler‑Guide nötig wäre. Unterscheidet sich von kmp‑library‑publishing (verantwortlich für die Maven‑Central‑Pipeline) und kmp‑project‑docs‑maintainer (verantwortlich für interne, nicht‑öffentliche Planungs‑Docs).
