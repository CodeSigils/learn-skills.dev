Configura un sitio web público de guía para desarrolladores (introducción, guías, ejemplos de código, referencia de API) para una biblioteca multiplataforma Kotlin publicada, implementada en GitHub Pages. Cubre el material MkDocs para contenido de guía escrito a mano, Dokka HTML para referencia de API generada automáticamente, una técnica de extracción de fragmentos verificada por el compilador para que los ejemplos de código no queden obsoletos y el flujo de trabajo de implementación de CI. Solo biblioteca: no se aplica a proyectos de aplicaciones, que no tienen consumidores externos para quienes escribir una guía para desarrolladores. A diferencia de kmp-library-publishing (propietario del oleoducto Maven Central) y kmp-project-docs-maintainer (propietario de documentos de planificación internos y no públicos).
