Kotlin Multiplatform 라이브러리를 위한 공개 개발자 가이드 웹사이트(시작하기, 가이드, 코드 예제, API 레퍼런스)를 구축하고 GitHub Pages에 배포합니다. 손으로 작성한 가이드 콘텐츠에는 MkDocs Material을, 자동 생성된 API 레퍼런스에는 Dokka HTML을 사용하며, 컴파일러가 검증하는 스니펫 추출 기법을 도입해 코드 예제가 오래되게 방치되지 않도록 하고, CI 배포 워크플로도 포함합니다. 라이브러리 전용으로, 외부 사용자가 없어 개발자 가이드를 작성할 필요가 없는 앱 프로젝트에는 적용되지 않습니다. kmp-library-publishing( Maven Central 파이프라인을 담당) 및 kmp-project-docs-maintainer( 내부 비공개 기획 문서를 담당)와는 별개입니다.
