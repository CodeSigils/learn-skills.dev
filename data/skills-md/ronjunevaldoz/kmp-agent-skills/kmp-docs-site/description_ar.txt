يُنشئ موقع دليل مطورين عام (بدء الاستخدام، الأدلة، أمثلة الشيفرة، مرجع الـ API) لمكتبة Kotlin Multiplatform مُنشرة، مُستضاف على GitHub Pages. يغطي MkDocs Material لمحتوى الأدلة المكتوبة يدويًا، وDokka HTML للمرجع الـ API المُولَّد تلقائيًا، وتقنية استخراج مقتطفات معتمدة على المترجم لضمان عدم تقادم أمثلة الشيفرة، بالإضافة إلى سير عمل النشر عبر CI. يخص المكتبة فقط — لا ينطبق على مشاريع التطبيقات التي لا يوجد لها مستهلكون خارجيون لكتابة دليل مطورين لها. مختلف عن kmp-library-publishing (يمتلك خط أنابيب Maven Central) وkmp-project-docs-maintainer (يمتلك وثائق التخطيط الداخلية غير العامة).
