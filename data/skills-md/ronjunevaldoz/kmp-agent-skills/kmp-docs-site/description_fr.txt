Met en place un site public de guide développeur (prise en main, guides, exemples de code, référence API) pour une bibliothèque Kotlin Multiplatform publiée, déployé sur GitHub Pages. Couvre MkDocs Material pour le contenu de guide rédigé à la main, Dokka HTML pour la référence API générée automatiquement, une technique d'extraction d'extraits vérifiée par le compilateur afin que les exemples de code ne deviennent pas obsolètes, ainsi que le workflow de déploiement CI. Réservé aux bibliothèques — ne s'applique pas aux projets d'application, qui n'ont pas de consommateurs externes pour lesquels rédiger un guide développeur. Distinct de kmp-library-publishing (qui possède le pipeline Maven Central) et de kmp-project-docs-maintainer (qui possède les docs de planification internes, non publics).
