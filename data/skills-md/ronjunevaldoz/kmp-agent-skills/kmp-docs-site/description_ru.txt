Настраивает общедоступный веб-сайт с руководствами для разработчиков (начало работы, руководства, примеры кода, справочник по API) для опубликованной многоплатформенной библиотеки Kotlin, развернутой на страницах GitHub. Охватывает MkDocs Material для рукописного содержания руководств, Dokka HTML для автоматически создаваемых ссылок на API, проверенную компилятором технику извлечения фрагментов, чтобы примеры кода не могли устареть, а также рабочий процесс CI-развертывания. Только для библиотеки — не применяется к проектам приложений, у которых нет внешних потребителей, для которых можно было бы написать руководство для разработчиков. В отличие от kmp-library-publishing (владеет центральным конвейером Maven) и kmp-project-docs-maintainer (владеет внутренней, закрытой документацией по планированию).
