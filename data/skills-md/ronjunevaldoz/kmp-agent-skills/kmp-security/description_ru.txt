Безопасность мобильных приложений для Kotlin Multiplatform, выходящая за пределы лишь Android‑обфускации R8 — привязка сертификатов/SSL (expect/actual, нативной кроссплатформенной поддержки Ktor нет), обнаружение root/jailbreak/вмешательства через реальный вариант freeRASP для KMP, зашифрованное локальное хранилище через KSafe, обрезка символов в релизных бинарниках iOS/ Kotlin‑Native, а также карта охвата OWASP Mobile Top 10 2024 для этой коллекции. **Не покрывает** обфускацию R8/ProGuard, специфичную для Android — это область kmp-proguard-r8, здесь лишь кросс‑ссылка вместо дублирования. **Не покрывает** сканирование секретов в исходном коде (gitleaks pre‑commit) — это вариант F в kmp-setup-hooks.
