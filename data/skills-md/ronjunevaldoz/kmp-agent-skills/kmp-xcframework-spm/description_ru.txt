Создаёт XCFramework из общего модуля Kotlin Multiplatform и публикует его как бинарный таргет Swift Package Manager (SPM). Охватывает: конфигурацию Gradle для XCFramework, задачу assembleReleaseXCFramework, локальный Package.swift для разработки SPM, удалённый бинарный таргет SPM для распространения (GitHub Releases) и интеграцию с проектом Xcode. Предполагает AGP 9+ и структуру проекта из kmp‑feature‑scaffold.
