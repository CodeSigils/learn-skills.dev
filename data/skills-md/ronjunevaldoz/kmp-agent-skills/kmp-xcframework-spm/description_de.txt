Erstellt ein XCFramework aus einem Kotlin‑Multiplattform‑Shared‑Modul und veröffentlicht es als binäres Ziel für den Swift Package Manager (SPM). Behandelt: Gradle‑XCFramework‑Konfiguration, assembleReleaseXCFramework‑Task, lokales SPM‑Package.swift für die Entwicklung, Remote‑Binary‑SPM‑Target für die Distribution (GitHub Releases) und die Integration in ein Xcode‑Projekt. Setzt AGP 9+ und die Projektstruktur von kmp-feature-scaffold voraus.
