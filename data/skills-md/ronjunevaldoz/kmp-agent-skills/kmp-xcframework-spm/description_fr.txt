Construit un XCFramework à partir d’un module partagé Kotlin Multiplatform et le publie en tant que cible binaire Swift Package Manager (SPM). Couvre : la configuration Gradle de l’XCFramework, la tâche assembleReleaseXCFramework, le Package.swift SPM local pour le développement, la cible SPM binaire distante pour la distribution (GitHub Releases), et l’intégration au projet Xcode. Suppose AGP 9+ et la structure du projet provenant de kmp‑feature‑scaffold.
