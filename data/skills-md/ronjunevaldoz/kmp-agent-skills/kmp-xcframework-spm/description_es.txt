Construye un XCFramework a partir de un módulo compartido Kotlin Multiplatform y lo publica como un objetivo binario de Swift Package Manager (SPM). Cubre: configuración de XCFramework en Gradle, tarea assembleReleaseXCFramework, Package.swift local de SPM para desarrollo, objetivo binario remoto de SPM para distribución (GitHub Releases) e integración con el proyecto Xcode. Se asume AGP 9+ y la estructura del proyecto de kmp-feature-scaffold.
