قم بإعداد وتشغيل storescreens-cli لأتمتة التقاط لقطة شاشة App Store لتطبيقات iOS. يدعم أيضًا لقطات الشاشة المستهدفة لإجراء فحوصات بصرية سريعة أثناء التطوير. استخدم هذه المهارة عندما يريد المستخدم تثبيت storescreens-cli، أو تكوين أتمتة لقطات الشاشة لمشروع Xcode، أو إضافة اختبارات واجهة المستخدم التي تلتقط لقطات الشاشة، أو كتابة ScreenshotTests.swift أو تحديثها، أو تشغيل التقاط لقطات الشاشة، أو التقاط لقطة شاشة سريعة للمحاكي، أو استكشاف أخطاء أتمتة لقطات الشاشة وإصلاحها. مشغلات لطلبات مثل "إعداد لقطات شاشة متجر التطبيقات"، أو "أتمتة لقطات الشاشة باستخدام شاشات المتجر"، أو "إضافة اختبارات واجهة المستخدم للقطة الشاشة"، أو "التقاط لقطات شاشة لـ App Store Connect"، أو "تكوين شاشات المتجر"، أو "التقاط لقطة شاشة لجهاز المحاكاة"، أو "أرني كيف يبدو التطبيق".
