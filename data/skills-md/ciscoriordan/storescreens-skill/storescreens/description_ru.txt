Настройте и запустите storescreens-cli, чтобы автоматизировать захват снимков экрана App Store для приложений iOS. Также поддерживает целевые снимки экрана для быстрой визуальной проверки во время разработки. Используйте этот навык, когда пользователь хочет установить storescreens-cli, настроить автоматизацию снимков экрана для проекта Xcode, добавить тесты пользовательского интерфейса, которые захватывают снимки экрана, написать или обновить ScreenshotTests.swift, запустить захват снимков экрана, сделать быстрый снимок экрана симулятора или устранить неполадки автоматизации снимков экрана. Триггеры для таких запросов, как «настроить снимки экрана App Store», «автоматизировать снимки экрана с помощью экранов магазина», «добавить скриншоты тестов пользовательского интерфейса», «сделать снимки экрана для App Store Connect», «настроить экраны магазина», «сделать снимок экрана симулятора» или «показать мне, как выглядит приложение».
