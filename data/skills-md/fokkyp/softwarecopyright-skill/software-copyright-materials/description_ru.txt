Создавайте управляемые материалы для заявок на авторские права на китайское программное обеспечение на основе реального проекта. Используйте этот навык, когда пользователь запрашивает 软件著作权, 软著申请资料, 软著代码材料, 操作手册, 申请表信息 или хочет использовать материалы Word/TXT для регистрации авторских прав на программное обеспечение. Рабочий процесс анализирует импортированный проект, извлекает реальный исходный код, создает черновики Markdown для подтверждения пользователя, а затем использует встроенные инструменты DOCX для создания окончательных документов Word и TXT.
