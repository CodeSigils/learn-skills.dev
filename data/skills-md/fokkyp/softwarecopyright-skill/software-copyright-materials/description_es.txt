Genere materiales guiados de solicitud de derechos de autor de software chino a partir de un proyecto real. Utilice esta habilidad cuando el usuario solicite 软件著作权, 软著申请资料, 软著代码材料, 操作手册, 申请表信息 o desee materiales Word/TXT para el registro de derechos de autor del software. El flujo de trabajo analiza el proyecto importado, extrae el código fuente real, crea borradores de Markdown para la confirmación del usuario y luego utiliza herramientas DOCX incluidas para producir documentos finales de Word y TXT.
