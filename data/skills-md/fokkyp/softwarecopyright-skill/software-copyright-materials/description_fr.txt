Générez du matériel de demande de droit d'auteur sur des logiciels chinois guidés à partir d'un projet réel. Utilisez cette compétence lorsque l'utilisateur demande 软件著作权, 软著申请资料, 软著代码材料, 操作手册, 申请表信息, ou souhaite des documents Word/TXT pour l'enregistrement des droits d'auteur du logiciel. Le flux de travail analyse le projet importé, extrait le code source réel, crée des brouillons Markdown pour confirmation de l'utilisateur, puis utilise les outils DOCX fournis pour produire les documents Word et TXT finaux.
