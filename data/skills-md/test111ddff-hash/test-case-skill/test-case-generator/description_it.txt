Genera casi di test QA attraverso un rigoroso flusso di lavoro in 5 passaggi (需求分析 → 测试点提取 → 用例细化 → 反向挑刺 → 覆盖度自评), facendo una pausa dopo ogni passaggio per la conferma dell'utente. I casi finali vengono emessi come tabelle di ribasso pronte per essere incollate in Excel / 飞书多维表格 / Numbers. Da utilizzare quando l'utente fornisce un requisito di prodotto/funzionalità e chiede di generare casi di test, estrarre punti di test, scomporre requisiti, scrivere casi di QA o menziona 测试用例 / 测试点 / 需求拆解 / QA / 用例评审 / 测试覆盖.
