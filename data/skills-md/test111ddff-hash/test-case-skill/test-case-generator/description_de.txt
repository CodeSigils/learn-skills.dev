Generieren Sie QA-Testfälle durch einen strikten 5-Schritte-Workflow (需求分析 → 测试点提取 → 用例细化 → 反向挑刺 → 覆盖度自评), wobei nach jedem Schritt eine Pause zur Benutzerbestätigung eingelegt wird. Endgültige Fälle werden als Markdown-Tabellen ausgegeben, die zum Einfügen in Excel / 飞书多维表格 / Numbers bereit sind. Wird verwendet, wenn der Benutzer eine Produkt-/Funktionsanforderung bereitstellt und darum bittet, Testfälle zu generieren, Testpunkte zu extrahieren, Anforderungen zu zerlegen, QA-Fälle zu schreiben oder 测试用例 / 测试点 / 需求拆解 / QA / 用例评审 / 测试覆盖 zu erwähnen.
