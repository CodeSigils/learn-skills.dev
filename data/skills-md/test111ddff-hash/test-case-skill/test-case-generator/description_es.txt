Genere casos de prueba de control de calidad a través de un estricto flujo de trabajo de 5 pasos (需求分析 → 测试点提取 → 用例细化 → 反向挑刺 → 覆盖度自评), haciendo una pausa después de cada paso para la confirmación del usuario. Los casos finales se emiten como tablas de rebajas listas para pegar en Excel/飞书多维表格/Numbers. Úselo cuando el usuario proporciona un requisito de producto/característica y solicita generar casos de prueba, extraer puntos de prueba, descomponer requisitos, escribir casos de control de calidad o menciona 测试用例 / 测试点 / 需求拆解 / QA / 用例评审 / 测试覆盖.
