Generate QA test cases through a strict 5-step workflow (需求分析 → 测试点提取 → 用例细化 → 反向挑刺 → 覆盖度自评), pausing after each step for user confirmation. Final cases are emitted as markdown tables ready to paste into Excel / 飞书多维表格 / Numbers. Use when the user provides a product/feature requirement and asks to generate test cases, extract test points, decompose requirements, write QA cases, or mentions 测试用例 / 测试点 / 需求拆解 / QA / 用例评审 / 测试覆盖.
