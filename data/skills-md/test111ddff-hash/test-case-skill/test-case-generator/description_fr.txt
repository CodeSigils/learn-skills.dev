Générez des cas de test d'assurance qualité via un flux de travail strict en 5 étapes (需求分析 → 测试点提取 → 用例细化 → 反向挑刺 → 覆盖度自评), en faisant une pause après chaque étape pour confirmation de l'utilisateur. Les cas finaux sont émis sous forme de tableaux de démarques prêts à être collés dans Excel / 飞书多维表格 / Numbers. À utiliser lorsque l'utilisateur fournit une exigence de produit/fonctionnalité et demande de générer des cas de test, d'extraire des points de test, de décomposer les exigences, de rédiger des cas d'assurance qualité ou de mentionner 测试用例 / 测试点 / 需求拆解 / QA / 用例评审 / 测试覆盖.
