Gérez les environnements Dynatrace à l'aide de dtctl : installez/mettez à jour la CLI, configurez l'authentification avec les jetons de trousseau du système d'exploitation et exécutez des opérations de style kubectl (get/describe/edit/apply/delete/query/exec/commands) pour les flux de travail, les tableaux de bord, les blocs-notes, le DQL, les SLO, les paramètres, les compartiments, les recherches, OpenPipeline et Davis AI. À utiliser lorsque l'utilisateur souhaite contrôler les ressources Dynatrace via dtctl.
