Effectuez un examen qualité approfondi d’une pull request ou d’une branche de fonctionnalité avant la fusion. Utilisez cette compétence chaque fois que l'utilisateur demande à réviser un PR, à vérifier si le code est prêt pour la production, à évaluer la qualité, à vérifier que les documents sont mis à jour ou demande « est-ce prêt à fusionner ? », « réviser ce PR », « vérifier la qualité », « cette production est-elle prête ? », ou similaire. À utiliser également lorsque vous révisez votre propre travail avant de le soumettre.
