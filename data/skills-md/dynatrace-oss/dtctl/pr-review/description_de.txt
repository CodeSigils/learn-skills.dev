Führen Sie vor dem Zusammenführen eine gründliche Qualitätsprüfung einer Pull-Anfrage oder eines Feature-Branchs durch. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine PR überprüfen, prüfen möchte, ob der Code produktionsbereit ist, die Qualität beurteilen, überprüfen möchte, ob Dokumente aktualisiert sind, oder fragt: „Ist dies bereit für die Zusammenführung?“, „Diese PR überprüfen“, „Qualität prüfen“, „Ist diese Produktion bereit?“ oder Ähnliches. Verwenden Sie es auch, wenn Sie Ihre eigene Arbeit vor dem Einreichen überprüfen.
