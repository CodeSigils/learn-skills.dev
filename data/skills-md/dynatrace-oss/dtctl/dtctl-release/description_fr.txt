Expédiez une nouvelle version de dtctl : modifiez la version, rédigez les entrées du journal des modifications, exécutez des tests, validez, marquez, poussez et rédigez des notes de version GitHub. Utilisez cette compétence chaque fois que l'utilisateur dit « publier », « expédier », « couper une version », « nouvelle version », « modifier la version », « publier » ou pose des questions sur le processus de publication dtctl. À utiliser également lorsque l'utilisateur souhaite mettre à jour CHANGELOG.md pour une version ou rédiger des notes de version GitHub.
