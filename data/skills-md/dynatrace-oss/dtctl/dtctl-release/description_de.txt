Versenden Sie eine neue dtctl-Version – Bump-Version, schreiben Sie Änderungsprotokolleinträge, führen Sie Tests aus, schreiben Sie ein Commit, taggen Sie, pushen Sie und schreiben Sie GitHub-Versionshinweise. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer „Freigeben“, „Versenden“, „Ein Release ausschneiden“, „Neue Version“, „Bump-Version“, „Veröffentlichen“ sagt oder nach dem dtctl-Veröffentlichungsprozess fragt. Verwenden Sie es auch, wenn der Benutzer CHANGELOG.md für eine Version aktualisieren oder GitHub-Versionshinweise schreiben möchte.
