قم بتحليل التغييرات الحقيقية لشجرة عمل Git، وتعرف على أسلوب التزام المستودع، وقم بإنشاء رسائل التزام تقليدية مفصلة ثنائية اللغة الصينية-الإنجليزية مع نص، وقم بإنشاء التزامات محلية آمنة. يُستخدم عندما يطلب المستخدم من وكيل الالتزام، أو الالتزام التلقائي، أو حفظ التغييرات في git، أو إنشاء التزام، أو إنشاء رسالة التزام، أو تشغيل مراجعة التزام جاف، أو استدعاء git-auto-commit بشكل صريح.
