Руководство и создатель проектов NetSuite с TypeScript с использованием Clean Architecture.
США, когда: пользователь хочет создать проект NetSuite, классический класс (pequeño/mediano/grande),
Прежде чем начать строить архитектуру, или необходимо создать кодовую структуру.

Эти навыки помогут вам:
- Представьте, что это чистая архитектура и что вы используете NetSuite
- Классификация вашего проекта с простыми вопросами
- Создайте правильную структуру в следующем году.
- Клонировать шаблон репозитория и автоматически настраивать его.

Примеры:
- пользователь: «quiero crear un proyecto netsuite» → hacer PREGUNTA 1 пример
- пользователь: «создать продажи проектов» → hacer preguntas de clasificación
- пользователь: "nuevo proyecto para facturacion" → hacer preguntas + crear estructura
