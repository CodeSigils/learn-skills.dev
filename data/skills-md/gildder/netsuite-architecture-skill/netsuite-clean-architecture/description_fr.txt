Guide et créateur de projets NetSuite avec TypeScript en utilisant Clean Architecture.
Utilisez-le quand : l'utilisateur souhaite créer un projet NetSuite, classifier tamaño (petit/mediano/grand),
pensez à l'architecture, ou vous avez besoin d'une structure de code.

Cette compétence vous aidera à :
- Entender qu'es Clean Architecture et por qué se utiliser en NetSuite
- Classifier votre projet avec des questions simples
- Créer la structure correcte selon la taille
- Cloner le modèle de référentiel et le configurer automatiquement

Exemples :
- utilisateur : "quiero crear un proyecto netsuite" → faire PREGUNTA 1 primero
- utilisateur : "créer des ventes de projets" → faire des questions de classification
- utilisateur : "nuevo proyecto para facturacion" → hacer preguntas + crear estructura
