دليل منشئ مشاريع NetSuite مع TypeScript باستخدام الهندسة المعمارية النظيفة.
عندما: المستخدم يريد إنشاء مشروع NetSuite، التصنيف الحجم (صغير/متوسط/كبير)،
اسأل عن الهندسة المعمارية، أو تحتاج إلى بنية الكود.

هذه المهارة تساعدك على:
- أعرف ما هي الهندسة المعمارية النظيفة ولماذا يتم استخدامها على NetSuite
- تصنيف مشروعك بأسئلة بسيطة
- إنشاء الهيكل الصحيح حسب الحجم
- استنساخ قالب المستودع وتكوينه تلقائيًا

أمثلة:
- المستخدم: "quiero crear un proyecto netsuite" → hacer PREGUNTA 1 primero
- المستخدم: "إنشاء مشروع مبيعات" → قم بإجراء أسئلة التصنيف
- المستخدم: "مشروع جديد للتصنيع" → hacer preguntas + إنشاء البنية
