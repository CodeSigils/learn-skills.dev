TypeScript를 사용하여 Clean Architecture를 사용하는 NetSuite 프로젝트를 만드는 도구입니다.
미국: usuario quiere crear proyecto NetSuite, clasificar tamaño(pequeño/mediano/grande),
preguntar sobre arquitectura, o necesita estructura de codigo.

당신의 기술은 다음과 같습니다:
- NetSuite의 Clean Architecture에 대한 참가자입니다.
- 단순하고 단순한 프로젝트에 대한 Clasificar tu proyecto
- Crear la estructura Correcta según el tamaño
- 클로나 저장소 템플릿 및 자동 구성 구성

예:
- 사용자: "quiero crear un proyecto netsuite" → hacer PREGUNTA 1 primeo
- 사용자: "crear proyecto sales" → hacer preguntas de clasificación
- 사용자: "nuevo proyecto parafacturacion" → hacer preguntas + crear estructura
