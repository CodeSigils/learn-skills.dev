X/Twitter CDP Tweet Scraper — 브라우저 CDP 프로토콜을 통해 사용자의 전체 트윗 기록을 스크랩합니다. 사용자가 특정 Twitter/X 사용자의 모든 트윗을 완전하고 정확하게 수집해야 할 때 사용합니다. 적용 가능한 시나리오: 특정 연도 동안 사용자의 모든 트윗 수집, 트위터 타임라인 내보내기, 분석을 위해 트윗 데이터 대량 가져오기. 전체 길이의 트윗, 정확한 타임스탬프 또는 더 높은 완성도가 필요한 경우 x-tweet-fetcher(Nitter 기반)보다 선호됩니다. Arc, Chrome, Edge, Brave 및 모든 Chromium 기반 브라우저를 지원합니다. 사용자는 브라우저에서 Twitter에 로그인해야 합니다.
