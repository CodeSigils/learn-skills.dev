X/Twitter CDP Tweet Scraper: extrae el historial completo de tweets de un usuario a través del protocolo CDP del navegador. Utilícelo cuando el usuario necesite recopilar de forma completa y precisa todos los tweets de un usuario específico de Twitter/X. Escenarios aplicables: recopilar todos los tweets de un usuario durante un año determinado, exportar una línea de tiempo de Twitter, obtener datos de tweets de forma masiva para su análisis. Se prefiere a x-tweet-fetcher (basado en Nitter) cuando se requieren tweets completos de formato largo, marcas de tiempo precisas o una mayor integridad. Admite Arc, Chrome, Edge, Brave y todos los navegadores basados ​​en Chromium. Requiere que el usuario inicie sesión en Twitter en el navegador.
