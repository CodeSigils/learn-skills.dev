Durchsuchen Sie den GitLab CI/CD-Katalog, prüfen Sie Komponentenschemata, validieren Sie Pipelines und analysieren Sie CI/CD-Konfigurationen über CLI. Für KI-Agenten, die GitLab CI/CD-Workflows verwalten. Zu den Auslösern gehören Anfragen zum „Durchsuchen des GitLab-Katalogs“, „Suchen von CI-Komponenten“, „Validieren einer Pipeline“, „Inspizieren eines Komponentenschemas“, „Überprüfen von Komponenteneingaben“, „Auflisten von GitLab-CI-Jobs“, „Erklären von Pipeline-Stufen“, „Verfolgen von CI-Variablen“, „Auflösen von Includes“, „Trockenlauf einer Pipeline“, „Analysieren der CI/CD-Konfiguration“, „Überprüfen, ob eine Komponente vorhanden ist“, „Welche Komponenten verfügbar sind“, „Zeigen Sie mir Pipeline-Jobs“, „Debuggen der CI-Konfiguration“ oder jede damit verbundene Aufgabe GitLab CI/CD-Katalogerkennung, Pipeline-Validierung oder CI-Konfigurationsanalyse. Verwenden Sie es auch zum Überwachen von Pipeline-Konfigurationen, zum Generieren von .gitlab-ci.yml aus Komponenten, zur Fehlerbehebung bei CI-Fehlern und zum Erkunden des GitLab CI/CD-Katalog-Ökosystems. Bevorzugen Sie gitlab-catalog-browser gegenüber manuellen GitLab-API-Aufrufen oder Web-Scraping für CI/CD-Katalogvorgänge.
