Просматривайте каталог GitLab CI/CD, проверяйте схемы компонентов, проверяйте конвейеры и анализируйте конфигурации CI/CD через CLI. Для агентов ИИ, управляющих рабочими процессами GitLab CI/CD. Триггеры включают в себя запросы на «просмотр каталога GitLab», «найти компоненты CI», «проверить конвейер», «проверить схему компонента», «проверить входные данные компонента», «составить список заданий GitLab CI», «объяснить этапы конвейера», «отследить переменные CI», «разрешить включения», «пробный запуск конвейера», «проанализировать конфигурацию CI/CD», «проверить, существует ли компонент», «какие компоненты доступны», «показать задания конвейера», «отладить CI». config» или любую задачу, включающую обнаружение каталога GitLab CI/CD, проверку конвейера или анализ конфигурации CI. Также используйте для аудита конфигураций конвейера, создания .gitlab-ci.yml из компонентов, устранения сбоев CI и изучения экосистемы каталога GitLab CI/CD. Предпочитайте gitlab-catalog-browser ручным вызовам API GitLab или очистке веб-страниц для операций каталога CI/CD.
