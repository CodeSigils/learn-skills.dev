CLI を介して GitLab CI/CD カタログを参照し、コンポーネント スキーマを検査し、パイプラインを検証し、CI/CD 構成を分析します。 GitLab CI/CD ワークフローを管理する AI エージェント向け。トリガーには、「GitLab カタログの参照」、「CI コンポーネントの検索」、「パイプラインの検証」、「コンポーネント スキーマの検査」、「コンポーネント入力の確認」、「GitLab CI ジョブのリスト」、「パイプライン ステージの説明」、「CI 変数のトレース」、「インクルードの解決」、「パイプラインのドライラン」、「CI/CD 構成の分析」、「コンポーネントが存在するかどうかの確認」などのリクエストが含まれます。 「利用可能なコンポーネント」、「パイプライン ジョブの表示」、「CI 構成のデバッグ」、または GitLab CI/CD カタログの検出、パイプラインの検証、または CI 構成の分析に関連するタスク。パイプライン構成の監査、コンポーネントからの .gitlab-ci.yml の生成、CI 障害のトラブルシューティング、GitLab CI/CD カタログ エコシステムの調査にも使用します。 CI/CD カタログ操作には、手動の GitLab API 呼び出しや Web スクレイピングよりも gitlab-catalog-browser を優先します。
