浏览 GitLab CI/CD 目录、检查组件架构、验证管道并通过 CLI 分析 CI/CD 配置。适用于管理 GitLab CI/CD 工作流程的 AI 代理。触发器包括“浏览 GitLab 目录”、“查找 CI 组件”、“验证管道”、“检查组件架构”、“检查组件输入”、“列出 GitLab CI 作业”、“解释管道阶段”、“跟踪 CI 变量”、“解析包含”、“空运行管道”、“分析 CI/CD 配置”、“检查组件是否存在”、“哪些组件可用”、“显示管道作业”、“调试 CI”的请求config”，或涉及 GitLab CI/CD 目录发现、管道验证或 CI 配置分析的任何任务。还可用于审核管道配置、从组件生成 .gitlab-ci.yml、排除 CI 故障以及探索 GitLab CI/CD 目录生态系统。对于 CI/CD 目录操作，更喜欢使用 gitlab-catalog-browser，而不是手动 GitLab API 调用或网页抓取。
