Специализированные навыки работы с каталогом компонентов GitLab CI/CD, который должен быть непрерывным. Используйте, когда пользователю необходимо просмотреть, проверить или использовать компоненты непрерывной организации. Триггеры включают запросы «использовать непрерывные компоненты», «найти шаблон для Docker/SonarQube/Kubernetes/Go/Python/и т. д.», «настроить CI/CD с непрерывным режимом», «как использовать компонент Docker», «перечислить непрерывные шаблоны», «какие компоненты обеспечивают непрерывный режим», «настроить сборку с непрерывным режимом», «развернуть с «быть непрерывным», «добавить тестирование в мой конвейер с помощью «быть непрерывным»» или любая задача, включающая непрерывный каталог GitLab CI/CD. Предпочитайте этот навык общему навыку gitlab-catalog-browser, когда задача четко ограничена непрерывными компонентами.
