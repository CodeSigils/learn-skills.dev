Compétence spécialisée pour le catalogue de composants GitLab CI/CD à venir. À utiliser lorsque l'utilisateur a besoin de parcourir, d'inspecter ou d'utiliser des composants de l'organisation qui doit être continue. Les déclencheurs incluent des requêtes pour « utiliser des composants à être continus », « trouver un modèle pour Docker/SonarQube/Kubernetes/Go/Python/etc », « configurer CI/CD avec à être continu », « comment utiliser le composant Docker », « lister les modèles à être continus », « quels composants fournit à être continu », « configurer une construction avec être continu », « déployer avec être continu », « ajouter tester mon pipeline avec "to-be-continuous", ou toute tâche impliquant le catalogue GitLab CI/CD à être continu. Préférez cette compétence à la compétence générique gitlab-catalog-browser lorsque la tâche est clairement limitée aux composants devant être continus.
