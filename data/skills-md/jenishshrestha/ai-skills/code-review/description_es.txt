Orientación integral de expertos para revisiones de código en el proyecto. Admite revisiones tanto de arquitectura como de seguridad. Utilice esta habilidad siempre que el usuario solicite una "revisión de código", una "verificación de seguridad", una "refactorización" o quiera verificar si el código coincide con los estándares del proyecto. Esta habilidad hace cumplir estrictamente la arquitectura FDD, los patrones de composición de React, las mejores prácticas de Tailwind v4 y la desinfección de la seguridad.
