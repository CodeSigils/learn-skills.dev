Conseils d’experts complets pour les révisions de code dans le projet. Prend en charge les examens d'architecture et de sécurité. Utilisez cette compétence chaque fois que l'utilisateur demande une « révision du code », un « contrôle de sécurité », une « refactorisation » ou souhaite vérifier si le code correspond aux normes du projet. Cette compétence applique strictement l'architecture FDD, les modèles de composition React, les meilleures pratiques Tailwind v4 et la désinfection de la sécurité.
