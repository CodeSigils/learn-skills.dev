Kompetente Anleitung zum Schreiben von hochwertigem, wartbarem Tailwind CSS v4-Code. Verwenden Sie diese Fähigkeit, wenn Benutzer Tailwind CSS, CSS-Stil, Designsysteme oder Theme-Konfiguration erwähnen oder nach Styling-Komponenten fragen. Wird auch ausgelöst, wenn Benutzer an der @theme-Konfiguration, Design-Tokens, OKLCH-Farben, Komponenten-Styling-Mustern oder der Migration von Tailwind v3 auf v4 arbeiten. Verwenden Sie diese Fähigkeit immer, wenn Sie CSS überprüfen oder schreiben, das Tailwind-Dienstprogramme umfasst, auch wenn der Benutzer „Tailwind“ nicht ausdrücklich erwähnt, aber eindeutig an einem Tailwind-Projekt arbeitet.
