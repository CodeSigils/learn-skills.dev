Conseils d'experts pour écrire du code Tailwind CSS v4 de haute qualité et maintenable. Utilisez cette compétence lorsque les utilisateurs mentionnent Tailwind CSS, le style CSS, les systèmes de conception, la configuration du thème ou posent des questions sur les composants de style. Déclenchez également lorsque les utilisateurs travaillent sur la configuration @theme, les jetons de conception, les couleurs OKLCH, les modèles de style de composants ou la migration de Tailwind v3 vers v4. Utilisez toujours cette compétence lors de la révision ou de l'écriture de CSS impliquant les utilitaires Tailwind, même si l'utilisateur ne mentionne pas explicitement « Tailwind » mais travaille clairement dans un projet Tailwind.
