إرشادات الخبراء لكتابة كود Tailwind CSS v4 عالي الجودة وقابل للصيانة. استخدم هذه المهارة عندما يذكر المستخدمون Tailwind CSS، أو تصميم CSS، أو أنظمة التصميم، أو تكوين السمة، أو عندما يسألون عن مكونات التصميم. يتم تشغيله أيضًا عندما يعمل المستخدمون على تكوين @theme، أو الرموز المميزة للتصميم، أو ألوان OKLCH، أو أنماط تصميم المكونات، أو الترحيل من Tailwind v3 إلى v4. استخدم هذه المهارة دائمًا عند مراجعة أو كتابة CSS التي تتضمن أدوات مساعدة Tailwind، حتى إذا لم يذكر المستخدم "Tailwind" صراحةً ولكنه يعمل بشكل واضح في مشروع Tailwind.
