Genera una wiki strutturata in stile DeepWiki per qualsiasi base di codice per accelerare l'onboarding degli sviluppatori. Utilizza questa competenza ogni volta che un utente desidera comprendere, documentare o eseguire l'onboarding in un repository non familiare, comprese richieste come "spiega questa base di codice", "genera documentazione per questo repository", "aiutami a capire questo progetto", "crea una guida all'onboarding", "mappa l'architettura" o "come funziona questa base di codice". Si attiva anche quando un utente fornisce un URL del repository o una struttura di file e richiede l'analisi oppure quando inserisce nuovi membri del team in basi di codice esistenti. Anche se l'utente non dice "wiki" o "onboarding", attiva questa abilità se desidera una comprensione strutturata di una base di codice.
