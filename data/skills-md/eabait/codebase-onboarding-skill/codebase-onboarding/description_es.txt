Genere un wiki estructurado estilo DeepWiki para cualquier base de código para acelerar la incorporación de desarrolladores. Utilice esta habilidad siempre que un usuario quiera comprender, documentar o incorporarse a un repositorio desconocido, incluidas solicitudes como "explicar este código base", "generar documentación para este repositorio", "ayúdame a comprender este proyecto", "crear una guía de incorporación", "trazar la arquitectura" o "cómo funciona este código base". También se activa cuando un usuario proporciona una URL de repositorio o un árbol de archivos y solicita un análisis, o cuando incorpora nuevos miembros del equipo a bases de código existentes. Incluso si el usuario no dice "wiki" o "incorporación", active esta habilidad si desea una comprensión estructurada de una base de código.
