Generieren Sie ein strukturiertes Wiki im DeepWiki-Stil für jede Codebasis, um das Entwickler-Onboarding zu beschleunigen. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer ein unbekanntes Repository verstehen, dokumentieren oder einbinden möchte – einschließlich Anfragen wie „Diese Codebasis erklären“, „Dokumentation für dieses Repo generieren“, „Hilf mir, dieses Projekt zu verstehen“, „Einen Onboarding-Leitfaden erstellen“, „Architektur abbilden“ oder „Wie funktioniert diese Codebasis“. Wird auch ausgelöst, wenn ein Benutzer eine Repo-URL oder einen Dateibaum angibt und um eine Analyse bittet, oder wenn neue Teammitglieder in bestehende Codebasen integriert werden. Auch wenn der Benutzer nicht „Wiki“ oder „Onboarding“ sagt, lösen Sie diesen Skill aus, wenn er ein strukturiertes Verständnis einer Codebasis möchte.
