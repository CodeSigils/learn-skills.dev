Générez un wiki structuré de style DeepWiki pour n'importe quelle base de code afin d'accélérer l'intégration des développeurs. Utilisez cette compétence chaque fois qu'un utilisateur souhaite comprendre, documenter ou intégrer un référentiel inconnu, y compris des requêtes telles que « expliquer cette base de code », « générer de la documentation pour ce référentiel », « m'aider à comprendre ce projet », « créer un guide d'intégration », « cartographier l'architecture » ou « comment fonctionne cette base de code ». Déclenchez également lorsqu'un utilisateur fournit une URL de dépôt ou une arborescence de fichiers et demande une analyse, ou lors de l'intégration de nouveaux membres de l'équipe dans des bases de code existantes. Même si l'utilisateur ne dit pas « wiki » ou « intégration », déclenchez cette compétence s'il souhaite une compréhension structurée d'une base de code.
