Refactoriser le code pour réduire la complexité cyclomatique afin qu’il reste lisible, maintenable et aligné avec la vision à long terme du codebase, et pas seulement optimisé pour la compréhension par l’IA. Utilisez cela chaque fois que l’utilisateur demande de refactoriser, simplifier, nettoyer ou revoir la qualité du code ; mentionne la complexité, la maintenabilité, la lisibilité, le code spaghetti, la logique profondément imbriquée ou les fonctions dieux ; ou demande de vérifier le code généré par l’IA avant de le fusionner. Utilisez-le également de manière proactive après avoir écrit toute fonction non triviale avec de nombreuses branches.

Veuillez toujours répondre dans la langue de l’utilisateur.
