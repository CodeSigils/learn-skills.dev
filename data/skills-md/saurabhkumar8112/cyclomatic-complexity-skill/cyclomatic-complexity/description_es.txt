Refactoriza el código para reducir la complejidad ciclomática, de modo que sea legible, mantenible y esté alineado con la visión a largo plazo de la base de código, no solo optimizado para la comprensión de IA. Utilízalo siempre que el usuario solicite refactorizar, simplificar, limpiar o revisar la calidad del código; mencione complejidad, mantenibilidad, legibilidad, código espagueti, lógica profundamente anidada o funciones dios; o pida revisar código generado por IA antes de fusionarlo. También úsalo proactivamente después de escribir cualquier función no trivial con ramificaciones intensas.
