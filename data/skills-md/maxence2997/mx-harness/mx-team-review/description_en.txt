Multi-perspective code review for local changes or entire files. Reviews git diffs (staged, commit ranges, branch comparisons) or whole files/directories. Three parallel review perspectives (Senior Engineer, SRE Guardian, Future Maintainer) feed into a Tech Lead who synthesizes the final report with noise filtering and conflict resolution. Auto-detects language from file extensions and loads language-specific review standards. Supports parallel subagents (Claude Code) or single-pass fallback (Copilot, Cursor, etc.). Usage: /team-review [diff-spec] or /team-review --repo <path> Supported languages: Go (.go), C# .NET 8 (.cs)
