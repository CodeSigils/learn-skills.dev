Revisión de código desde múltiples perspectivas para cambios locales o archivos completos. Revisa diferencias de git (por etapas, rangos de confirmación, comparaciones de ramas) o archivos/directorios completos. Tres perspectivas de revisión paralelas (ingeniero sénior, guardián de SRE, mantenedor del futuro) alimentan a un líder técnico que sintetiza el informe final con filtrado de ruido y resolución de conflictos. Detecta automáticamente el idioma de las extensiones de archivos y carga estándares de revisión específicos del idioma. Admite subagentes paralelos (Claude Code) o respaldo de un solo paso (Copilot, Cursor, etc.). Uso: /team-review [diff-spec] o /team-review --repo <ruta> Idiomas admitidos: Go (.go), C# .NET 8 (.cs)
