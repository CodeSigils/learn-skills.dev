Результаты сортировочной проверки из двух источников: локальные отчеты mx-team-review (--source review) или комментарии по связям с общественностью GitHub/GitLab (--source pr <id|url>). Классифицирует каждое обнаружение по достоверности, серьезности (P0–P3) и стоимости реализации, а затем сортирует по сегментам исправлений/отслеживания/пропуска. Представляет отчет для утверждения пользователем перед выполнением каких-либо изменений. При вызове без аргументов автоматически определяет источник или запрашивает у пользователя. Используйте после проверки mx-team или при обработке отзывов по связям с общественностью перед слиянием.
