Implémentez une tâche du plan à l’aide du développement piloté par les tests. Lit la prochaine tâche en attente à partir de ~/.mx/<project>/<name>/plan.md, écrit d'abord un test qui échoue, implémente le code minimal pour le transmettre, refactorise, puis valide avec /mx-commit. Utilise des tranches verticales (un test → un impl), jamais de découpage horizontal. À utiliser pour chaque tâche du plan une fois que /mx-worktree est prêt.
