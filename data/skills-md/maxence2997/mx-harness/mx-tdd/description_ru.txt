Реализуйте одну задачу из плана, используя разработку через тестирование. Считывает следующую ожидающую задачу из ~/.mx/<project>/<name>/plan.md, сначала записывает неудачный тест, реализует минимальный код для его прохождения, выполняет рефакторинг, затем фиксирует с помощью /mx-commit. Используются вертикальные срезы (один тест → одно внедрение), а не горизонтальные срезы. Используйте для каждой задачи в плане после того, как /mx-worktree будет готов.
