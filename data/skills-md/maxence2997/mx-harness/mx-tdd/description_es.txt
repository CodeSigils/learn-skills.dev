Implemente una tarea del plan utilizando un desarrollo basado en pruebas. Lee la siguiente tarea pendiente de ~/.mx/<proyecto>/<nombre>/plan.md, primero escribe una prueba fallida, implementa el código mínimo para pasarla, refactoriza y luego confirma con /mx-commit. Utiliza cortes verticales (una prueba → una impl), nunca cortes horizontales. Úselo para cada tarea del plan después de que /mx-worktree esté listo.
