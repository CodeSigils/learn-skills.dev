Recherchez et inspectez le contenu enregistré dans un espace de travail Cube (classeurs, tableaux de bord, rapports, dossiers et notifications planifiées) à l'aide de la CLI Cube. À utiliser chaque fois que quelqu'un souhaite savoir ce qui existe déjà plutôt que de créer quelque chose de nouveau : recherchez un tableau de bord, répertoriez les rapports, voyez ce qu'un rapport interroge, trouvez à qui une notification est adressée ou vérifiez quel contenu enregistré fait référence à un champ de modèle avant de le renommer. Déclencheurs sur « de quels tableaux de bord disposons-nous », « trouver le rapport sur les revenus », « où se trouve ce classeur », « qu'y a-t-il dans ce dossier », « qui obtient ce rapport planifié », « est-ce que quelque chose utilise ce champ ». Pour créer ou modifier du contenu, utilisez cube-build-content ; pour inspecter le modèle sémantique lui-même, utilisez cube-explore-model.
