Inspeccione y ajuste el agente de IA integrado en el producto de Cube (sus reglas, consultas certificadas y habilidades del agente) mediante la creación de rebajas en el modelo semántico con la CLI de Cube. Úselo cuando alguien quiera que el agente de Cube responda mejor: enséñele una definición de negocio, evite que cometa un error recurrente, certifique una consulta confiable, capture un flujo de trabajo repetible como una habilidad o descubra por qué respondió de la forma en que lo hizo. Activadores sobre "el agente sigue cometiendo X mal", "enseñarle eso al agente", "hacer que el agente siempre sea", "agregar una consulta certificada", "crear una habilidad de agente", "por qué el agente dijo eso", "qué reglas tiene el agente". Para cambiar el modelo subyacente, utilice cube-build-model; para explorar qué se puede consultar, utilice cube-explore-model.
