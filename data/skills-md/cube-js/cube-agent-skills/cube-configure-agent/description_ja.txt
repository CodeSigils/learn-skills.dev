Cube CLI を使用してセマンティック モデルでマークダウンを作成することにより、Cube の製品内 AI エージェント (そのルール、認定されたクエリ、およびエージェント スキル) を検査および調整します。 Cube エージェントにもっと適切に答えてもらいたいときはいつでも使用します。ビジネス定義を教えたり、繰り返される間違いをやめたり、信頼できるクエリを証明したり、反復可能なワークフローをスキルとして取得したり、エージェントがそのように答えた理由を調べたりする場合に使用します。トリガーは、「エージェントが X を間違え続ける」、「エージェントにそれを教える」、「エージェントを常にさせる」、「認定済みクエリを追加する」、「エージェント スキルを作成する」、「エージェントがなぜそう言ったか」、「エージェントにはどのようなルールがあるか」などです。基礎となるモデルを変更するには、cube-build-model を使用します。クエリ可能なものを調べるには、cube-explore-model を使用します。
