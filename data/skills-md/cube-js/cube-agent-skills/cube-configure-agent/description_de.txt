Überprüfen und optimieren Sie den produktinternen KI-Agenten von Cube – seine Regeln, zertifizierten Abfragen und Agentenfähigkeiten –, indem Sie mit der Cube-CLI Markdown im semantischen Modell erstellen. Verwenden Sie es immer dann, wenn jemand möchte, dass der Cube-Agent besser antwortet: Bringen Sie ihm eine Geschäftsdefinition bei, verhindern Sie, dass er wiederkehrende Fehler macht, zertifizieren Sie eine vertrauenswürdige Abfrage, erfassen Sie einen wiederholbaren Workflow als Fertigkeit oder finden Sie heraus, warum er so geantwortet hat, wie er es getan hat. Löst aus: „Der Agent versteht immer wieder X falsch“, „Bringen Sie dem Agenten das bei“, „Machen Sie den Agenten immer“, „Fügen Sie eine zertifizierte Abfrage hinzu“, „Erstellen Sie eine Agentenfähigkeit“, „Warum hat der Agent das gesagt“, „Welche Regeln hat der Agent?“ Um das zugrunde liegende Modell zu ändern, verwenden Sie „cube-build-model“. Um herauszufinden, was abfragbar ist, verwenden Sie das Cube-Explore-Modell.
