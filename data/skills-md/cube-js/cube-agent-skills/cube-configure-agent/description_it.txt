Ispeziona e ottimizza l'agente AI integrato di Cube — le sue regole, le query certificate e le Skill dell’agente — creando markdown nel modello semantico con il Cube CLI. Usalo ogni volta che qualcuno vuole che l’agente Cube risponda meglio: insegna una definizione di business, fermalo dal commettere un errore ricorrente, certifica una query affidabile, cattura un flusso di lavoro ripetibile come skill o scopri perché ha risposto in quel modo. Si attiva con “l’agente continua a sbagliare X”, “insegna all’agente che”, “fai in modo che l’agente faccia sempre …”, “aggiungi una query certificata”, “crea una skill per l’agente”, “perché l’agente ha detto quello” o “quali regole ha l’agente”. Per modificare il modello di base usa cube‑build‑model; per esplorare ciò che è interrogabile usa cube‑explore‑model.  

Rispondi sempre nella lingua dell’utente.
