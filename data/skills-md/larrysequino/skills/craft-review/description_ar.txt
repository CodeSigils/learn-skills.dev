مراجعة صارمة للتصميم المرئي وتصميم تجربة المستخدم لشاشات واجهة المستخدم وتدفقاتها. يُستخدم عندما يطلب المستخدم مراجعة تصميم ما، أو نقد الشاشة، أو تدقيق واجهة المستخدم، أو التحقق من التباعد، أو المحاذاة، أو التسلسل الهرمي، أو الطباعة، أو اللون، أو التباين أو إمكانية الوصول، أو يسأل عما إذا كان شيء ما يبدو مصقولًا أو معطلاً أو تم إنشاؤه بواسطة الذكاء الاصطناعي بشكل عام، أو يشارك لقطة شاشة أو عنوان URL لـ Figma للحصول على تعليقات. التدابير قبل أن تحكم، وتبلغ عن النتائج المصنفة حسب الخطورة مع إصلاحات رقمية. ليس لتحويل السخرية إلى صفحة قرار (استخدم أداة القرار) وليس للنثر (استخدم الكتابة الطبيعية).
