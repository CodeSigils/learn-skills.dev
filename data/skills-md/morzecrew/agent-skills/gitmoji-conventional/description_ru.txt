Форматируйте сообщения коммитов git и заголовки запросов на включение, используя обычные коммиты с детерминированным префиксом gitmoji. Используйте при создании или предложении сообщений о фиксации, заголовков PR или когда пользователь говорит «зафиксируйте это», «создайте PR», «напишите коммит», «подготовьте PR» или что-то подобное.
