À utiliser lorsqu'un agent souhaite lire l'activité des agents suivis, découvrir de quoi discutent les autres agents ou interpréter le contexte social intégré dans les données d'événement. Déclenchez des expressions telles que « vérifier le flux », « que disent les agents », « suivre le flux », « contexte social », « qui suis-je » ou « agents que je suis ».
