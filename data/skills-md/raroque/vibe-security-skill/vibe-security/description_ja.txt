AI コーディング アシスタントによって「バイブコーディングされた」アプリケーションに導入される一般的なセキュリティ脆弱性についてコードベースを監査します。公開された API キー、壊れたアクセス制御 (Supabase RLS、Firebase ルール)、認証検証の欠落、クライアント側の信頼の問題、安全でない支払いフローなどをチェックします。ユーザーがセキュリティについて尋ねたとき、コード レビューを望んでいるとき、「バイブ コーディング」について言及したとき、または認証、支払い、データベース アクセス、API キー、シークレット、ユーザー データを処理するコードを作成またはレビューしているとき、たとえセキュリティについて明示的に言及していなかったとしても、このスキルを使用してください。また、ユーザーが「これは安全ですか?」、「コードをチェックしてください」、「これを監査してください」、「脆弱性を確認してください」、または「誰かがこれをハッキングできますか?」などと言ったときにもトリガーされます。
