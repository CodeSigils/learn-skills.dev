Überprüft Codebasen auf häufige Sicherheitslücken, die KI-Codierungsassistenten in „Vibe-codierte“ Anwendungen einführen. Prüft auf offengelegte API-Schlüssel, fehlerhafte Zugriffskontrolle (Supabase RLS, Firebase-Regeln), fehlende Authentifizierungsvalidierung, clientseitige Vertrauensprobleme, unsichere Zahlungsflüsse und mehr. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer nach Sicherheit fragt, eine Codeüberprüfung wünscht, „Vibe Coding“ erwähnt oder wenn Sie Code schreiben oder überprüfen, der Authentifizierung, Zahlungen, Datenbankzugriff, API-Schlüssel, Geheimnisse oder Benutzerdaten verwaltet – auch wenn Sicherheit nicht ausdrücklich erwähnt wird. Wird auch ausgelöst, wenn der Benutzer Dinge wie „Ist das sicher?“, „Überprüfe meinen Code“, „Überprüfe dies“, „Überprüfe auf Schwachstellen“ oder „Kann jemand das hacken?“ sagt.
