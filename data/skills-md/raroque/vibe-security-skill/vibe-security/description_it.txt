Controlla le basi di codice per le vulnerabilità di sicurezza comuni che gli assistenti di codifica AI introducono nelle applicazioni "codificate con Vibe". Verifica la presenza di chiavi API esposte, controllo degli accessi non funzionante (Supabase RLS, regole Firebase), convalida dell'autenticazione mancante, problemi di attendibilità lato client, flussi di pagamento non sicuri e altro ancora. Utilizza questa competenza ogni volta che l'utente chiede informazioni sulla sicurezza, desidera una revisione del codice, menziona "vibe coding" o quando scrivi o rivedi codice che gestisce l'autenticazione, i pagamenti, l'accesso al database, le chiavi API, i segreti o i dati utente, anche se non menzionano esplicitamente la sicurezza. Si attiva anche quando l'utente dice cose come "è sicuro?", "controlla il mio codice", "controllalo", "verifica eventuali vulnerabilità" o "qualcuno può hackerarlo?".
