Audite les bases de code pour détecter les vulnérabilités de sécurité courantes que les assistants de codage IA introduisent dans les applications « codées par vibration ». Vérifie les clés API exposées, les contrôles d'accès brisés (Supabase RLS, règles Firebase), la validation d'authentification manquante, les problèmes de confiance côté client, les flux de paiement non sécurisés, etc. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur la sécurité, souhaite une révision du code, mentionne le « codage dynamique » ou lorsque vous écrivez ou révisez du code qui gère l'authentification, les paiements, l'accès à la base de données, les clés API, les secrets ou les données utilisateur, même s'ils ne mentionnent pas explicitement la sécurité. Déclenchez également lorsque l'utilisateur dit des choses comme « est-ce sûr ? », « vérifier mon code », « auditer ceci », « examiner les vulnérabilités » ou « quelqu'un peut-il pirater ceci ?
