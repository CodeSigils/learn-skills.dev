Audita las bases de código en busca de vulnerabilidades de seguridad comunes que los asistentes de codificación de IA introducen en aplicaciones "codificadas por vibración". Comprueba si hay claves API expuestas, control de acceso roto (Supabase RLS, reglas de Firebase), falta de validación de autenticación, problemas de confianza del lado del cliente, flujos de pago inseguros y más. Utilice esta habilidad siempre que el usuario pregunte sobre seguridad, quiera una revisión del código, mencione "codificación de vibración" o cuando esté escribiendo o revisando código que maneja autenticación, pagos, acceso a bases de datos, claves API, secretos o datos de usuario, incluso si no mencionan explícitamente la seguridad. También se activa cuando el usuario dice cosas como "¿es seguro?", "revisa mi código", "audita esto", "revisa vulnerabilidades" o "¿alguien puede hackear esto?".
