WeChat Remote Control для Claude Code. Три подкоманды:
- вход: аутентификация учетной записи WeChat (сканирование QR-кода). Запустите один раз перед первым использованием
          или после окончания сеанса.
- Attach: зарегистрировать этот сеанс Claude Code в качестве удаленной цели WeChat.
          Демон моста запускается в фоновом режиме; он просматривает файл сеанса CC
          и пересылает выходные данные помощника в WeChat.
- Синхронизация: отображение истории разговоров WeChat с момента последнего подключения для контекста.
Используйте, когда отходите от терминала и переходите к WeChat.
