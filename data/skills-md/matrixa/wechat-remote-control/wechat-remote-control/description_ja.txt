Claude Code の WeChat リモート コントロール。 3 つのサブコマンド:
- ログイン: WeChat アカウントを認証します (QR コードをスキャンします)。初めて使用する前に 1 回実行する
          またはセッションの有効期限が切れた後。
- アタッチ: このクロード コード セッションを WeChat リモート ターゲットとして登録します。
          ブリッジ デーモンはバックグラウンドで起動します。 CCセッションファイルを監視します
          アシスタントの出力を WeChat に転送します。
- 同期: 最後に接続してからの WeChat 会話履歴をコンテキストのために表示します。
端末から離れて WeChat に切り替えるときに使用します。
