Генератор подсказок Seedance 2. Превратите любое творческое задание в идеальные подсказки Seedance 2.0, следуя официальной 6-уровневой архитектуре (Предмет → Действие → Окружающая среда → Камера → Стиль → Ограничения). Поддерживает создание нескольких кадров с помощью скобок, блокировку символов по ссылке, собственные звуковые сигналы и положительные ограничения. Используйте этот навык всякий раз, когда Тиму нужны подсказки Seedance 2 — для зацепок, пошаговых руководств, кадров действий, кадров продукта, сцен с персонажами или последовательностей из нескольких кадров.
