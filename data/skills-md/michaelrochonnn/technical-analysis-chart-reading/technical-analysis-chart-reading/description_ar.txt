التحليل الفني على غرار مورفي لتداول السوق الثانوية. يُستخدم عندما يحتاج Codex إلى قراءة الرسوم البيانية/خطوط K (K线)، أو خطوط الاتجاه، أو الدعم/المقاومة، أو أنماط الرسم البياني، أو الحجم، أو الفائدة المفتوحة، أو المتوسطات المتحركة، أو مؤشرات التذبذب، أو الزخم، أو التباعد، أو منطق النقطة والرقم، أو الدورات، أو المؤشرات الفنية للأسهم، أو العقود الآجلة، أو العملات المشفرة، أو العملات الأجنبية، أو الأسعار، أو السلع، أو صناديق الاستثمار المتداولة، أو أي سوق سائل. استخدم أيضًا عندما يُطلب منك تحويل بيانات OHLCV/OHLCVI إلى تحليل فني، أو إنشاء قائمة مرجعية لقراءة الرسم البياني، أو تجميع الإشارات من إطار التحليل الفني الخاص بـ John J. Murphy.
