Da utilizzare quando si configura un sito per CloudCannon per una delle seguenti operazioni. Scarica gli schemi JSON prima di scrivere qualsiasi configurazione (vedi all'inizio di SKILL.md).
- Configurazione di cloudcannon.config.yml o .cloudcannon/initial-site-settings.json - Generazione di una baseline con la CLI di CloudCannon - Aggiunta o modifica di raccolte, input, strutture o selezione di dati - Configurazione di strutture per input di array e oggetti - Configurazione degli URL di raccolta - Risoluzione dei problemi relativi a campi mancanti o tipi di input
