À utiliser lors de la configuration d'un site pour CloudCannon pour l'un des éléments suivants. Téléchargez les schémas JSON avant d'écrire une configuration (voir le haut de SKILL.md).
- Configuration de cloudcannon.config.yml ou .cloudcannon/initial-site-settings.json - Génération d'une référence avec la CLI CloudCannon - Ajout ou modification de collections, d'entrées, de structures ou de données sélectionnées - Configuration de structures pour les entrées de tableau et d'objet - Configuration des URL de collection - Dépannage des champs ou des types d'entrée manquants
