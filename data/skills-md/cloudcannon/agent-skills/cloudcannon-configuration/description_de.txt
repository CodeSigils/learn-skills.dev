Verwenden Sie diese Option, wenn Sie eine Site für CloudCannon für einen der folgenden Zwecke konfigurieren. Laden Sie die JSON-Schemas herunter, bevor Sie eine Konfiguration schreiben (siehe oben in SKILL.md).
- Einrichten von cloudcannon.config.yml oder .cloudcannon/initial-site-settings.json - Generieren einer Baseline mit der CloudCannon-CLI - Hinzufügen oder Ändern von Sammlungen, Eingaben, Strukturen oder ausgewählten Daten - Einrichten von Strukturen für Array- und Objekteingaben - Konfigurieren von Sammlungs-URLs - Fehlerbehebung bei fehlenden Feldern oder Eingabetypen
