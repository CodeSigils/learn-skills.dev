Используйте при настройке сайта для CloudCannon для любого из следующих действий. Прежде чем писать какую-либо конфигурацию, загрузите схемы JSON (см. начало SKILL.md).
- Настройка cloudcannon.config.yml или .cloudcannon/initial-site-settings.json - Создание базовой линии с помощью CloudCannon CLI - Добавление или изменение коллекций, входных данных, структур или выборочных данных - Настройка структур для входных данных массива и объекта - Настройка URL-адресов коллекций - Устранение неполадок с отсутствующими полями или типами входных данных
