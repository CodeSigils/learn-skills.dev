Générez un fichier d'histoires Storybook conforme pour le composant React donné. À utiliser lorsque l'utilisateur a besoin de créer des histoires Storybook pour un composant, de présenter l'utilisation d'un composant ou de générer de la documentation sur les composants. Les expressions déclencheurs incluent : « créer des histoires pour ce composant », « générer un livre d’histoires », « écrire un livre d’histoires », etc.
