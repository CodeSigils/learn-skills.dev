Générez des histoires Storybook conformes aux spécifications du composant React donné. À utiliser lorsque l'utilisateur doit créer des histoires Storybook pour un composant, démontrer l'utilisation d'un composant ou générer une documentation sur un composant. Les expressions déclencheurs incluent : « créer des histoires pour ce composant », « générer un livre d’histoires », « écrire un livre d’histoires », etc.

Veuillez toujours répondre dans la langue de l'utilisateur.
