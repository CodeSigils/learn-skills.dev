Genera un file di storie Storybook conforme per il componente React specificato. Da utilizzare quando l'utente deve creare storie di Storybook per un componente, mostrare l'utilizzo del componente o generare la documentazione del componente. Le frasi trigger includono: "crea storie per questo componente", "genera libro di fiabe", "scrivi libro di fiabe", ecc.
