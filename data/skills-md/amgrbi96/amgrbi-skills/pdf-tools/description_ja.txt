pymupdf では実行できない PDF 出力側エンジニアリング: Puppeteer による HTML から PDF への生成 (印刷 CSS、Web フォント、React テンプレート)、ghostscript および verapdf による PDF/A アーカイブへの準拠、@signpdf による PKCS#7 デジタル署名、および qpdf 暗号化/修復/線形化。コンテンツ抽出には使用できません。parse-docs スキルを使用してください。日常的なページ編集 (マージ、分割、回転、クロップ、透かし、フォーム、墨消し) にはスキルは必要ありません。pymupdf を直接使用してください。
