Проектирование вывода PDF для того, чего не может сделать pymupdf: генерация HTML-PDF с помощью Puppeteer (печать CSS, веб-шрифты, шаблоны React), соответствие архивному формату PDF/A с помощью Ghostscript и verapdf, цифровая подпись PKCS#7 с помощью @signpdf и шифрование/восстановление/линеаризация qpdf. НЕ для извлечения контента — используйте навык парсинга документов. Рутинное редактирование страниц (объединение, разделение, поворот, обрезка, водяные знаки, формы, редактирование) не требует навыков — используйте напрямую pymupdf.
