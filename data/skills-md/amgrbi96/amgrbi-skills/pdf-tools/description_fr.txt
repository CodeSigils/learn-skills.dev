Ingénierie côté sortie PDF pour ce que pymupdf ne peut pas faire : génération HTML vers PDF avec Puppeteer (impression CSS, polices Web, modèles React), conformité d'archivage PDF/A via ghostscript et verapdf, signature numérique PKCS#7 avec @signpdf et cryptage/réparation/linéarisation qpdf. PAS pour l'extraction de contenu - utilisez la compétence parse-docs. Les modifications de routine de pages (fusion, fractionnement, rotation, recadrage, filigrane, formulaires, rédaction) ne nécessitent aucune compétence : utilisez directement pymupdf.
