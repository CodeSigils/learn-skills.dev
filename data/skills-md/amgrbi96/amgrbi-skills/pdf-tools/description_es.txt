Ingeniería del lado de salida de PDF para lo que pymupdf no puede hacer: generación de HTML a PDF con Puppeteer (impresión CSS, fuentes web, plantillas React), cumplimiento de archivos PDF/A a través de ghostscript y verapdf, firma digital PKCS#7 con @signpdf y cifrado/reparación/linealización de qpdf. NO para extracción de contenido: utilice la habilidad parse-docs. Las ediciones rutinarias de páginas (combinar, dividir, rotar, recortar, marcas de agua, formularios, redacción) no necesitan ninguna habilidad: use pymupdf directamente.
