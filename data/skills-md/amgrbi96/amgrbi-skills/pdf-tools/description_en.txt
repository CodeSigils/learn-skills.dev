PDF output-side engineering for what pymupdf cannot do: HTML-to-PDF generation with Puppeteer (print CSS, web fonts, React templates), PDF/A archival compliance via ghostscript and verapdf, PKCS#7 digital signing with @signpdf, and qpdf encryption/repair/linearization. NOT for content extraction — use the parse-docs skill. Routine page edits (merge, split, rotate, crop, watermark, forms, redaction) need no skill — use pymupdf directly.
