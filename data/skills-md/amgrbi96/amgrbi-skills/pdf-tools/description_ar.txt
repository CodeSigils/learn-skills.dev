هندسة جانب إخراج PDF لما لا يستطيع pymupdf فعله: إنشاء HTML إلى PDF باستخدام Puppeteer (طباعة CSS وخطوط الويب وقوالب React)، والامتثال الأرشيفي لـ PDF/A عبر Ghostscript وverapdf، والتوقيع الرقمي PKCS#7 باستخدام @signpdf، وتشفير/إصلاح/خطي qpdf. ليس لاستخراج المحتوى، استخدم مهارة التحليل والمستندات. لا تحتاج عمليات التحرير الروتينية للصفحة (الدمج، والتقسيم، والتدوير، والاقتصاص، والعلامة المائية، والنماذج، والتنقيح) إلى أي مهارة — استخدم pymupdf مباشرةً.
