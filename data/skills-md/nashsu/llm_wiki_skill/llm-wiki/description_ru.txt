Запросите базу знаний LLM Wiki пользователя (настольное приложение LLM Wiki по адресу 127.0.0.1:19828 — НЕ Obsidian, Notion, Apple Notes, Logseq или любой другой инструмент PKM). Срабатывает ТОЛЬКО, когда пользователь явно называет LLM Wiki, говорит «моя вики», «моя 知识库 / 知识库 / база знаний» или задает такие вопросы, как «что моя вики говорит о X», «прочитать вики-страницу Y», «показать мой вики-график / 知识图谱», «поиск в моем проекте LLM Wiki», «повторно отсканировать мои вики-источники»重新索引» или называет вики-проект по идентификатору. НЕ запускайте общие запросы «поиск в моих заметках», «найти в моем блокноте», «проверить мой Obsidian» и т. д. — они относятся к другим инструментам, которые мог установить пользователь. Охватывает поиск по вики-страницам, список файлов, чтение контента, навигацию по графу знаний и повторное сканирование источника с помощью запущенного настольного приложения LLM Wiki. Только чтение, за исключением повторного сканирования источника.
