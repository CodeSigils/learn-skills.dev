Controle una instancia interna de Claude Code a través de la CLI `claude` para ejecutar tareas de codificación de forma autónoma. Úselo al organizar flujos de trabajo de Claude a Claude, canalizaciones de codificación automatizadas o delegación de tareas de múltiples agentes a través del protocolo CLI. Activadores: claude driver, claude interno, claude cli, delegar tarea, ejecutar claude, orquestar claude
