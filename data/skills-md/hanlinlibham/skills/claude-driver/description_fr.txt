Pilotez une instance interne de Claude Code via la CLI « claude » pour exécuter des tâches de codage de manière autonome. À utiliser lors de l'orchestration de flux de travail Claude à Claude, de pipelines de codage automatisés ou de délégation de tâches multi-agents via le protocole CLI. Déclencheurs : Claude Driver, Claude intérieur, Claude cli, déléguer la tâche, exécuter Claude, orchestrer Claude
