Manuel de référence des appels de l'API HTTP iFinD. Utilisez cette compétence lorsque l'utilisateur doit écrire du code qui utilise l'API HTTP TongHuaShun iFinD pour obtenir des données financières. Couvre les URL, les paramètres, les indicateurs et les exemples pour les 18 points de terminaison de l'API. Prend en charge les actions, les fonds, les obligations, les contrats à terme, les options et les données macro. Mots déclencheurs : ifind, iFinD, API TongHuaShun, données TongHuaShun, quantapi.
