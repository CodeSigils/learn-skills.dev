الدليل المرجعي للاتصال بـ iFinD HTTP API. استخدم هذه المهارة عندما يحتاج المستخدم إلى كتابة تعليمات برمجية تستخدم TongHuaShun iFinD HTTP API للحصول على البيانات المالية. يغطي عناوين URL والمعلمات والمؤشرات والأمثلة لجميع نقاط نهاية واجهة برمجة التطبيقات البالغ عددها 18 نقطة. يدعم الأسهم والصناديق والسندات والعقود الآجلة والخيارات والبيانات الكلية. كلمات التشغيل: ifind، iFinD، TongHuaShun API، TongHuaShun data، quantapi.
