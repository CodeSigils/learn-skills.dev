Охватывает URL-адреса, параметры, индикаторы и примеры для всех 18 конечных точек API. Поддерживает акции, фонды, облигации, фьючерсы, опционы и макроданные. Триггерные слова: ifind, iFinD, API TongHuaShun, данные TongHuaShun, quantapi.
