Utilisez le package cknow/laravel-money pour les projets Laravel qui doivent modéliser, conserver, diffuser, formater, comparer ou calculer de l'argent en toute sécurité. Déclenchez lorsque vous travaillez sur des applications Laravel qui gèrent la devise, les prix, les totaux, les factures, la facturation, le paiement, les remises, les taxes, les soldes, les conversions monétaires ou toute demande mentionnant la gestion de l'argent, le formatage de la devise, les unités mineures entières, les objets de valeur monétaire ou « laravel-money ». Préférez ceci aux flotteurs bruts pour les valeurs monétaires dans Laravel.
