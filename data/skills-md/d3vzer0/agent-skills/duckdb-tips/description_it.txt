Ottimizza, rivedi e risolvi i problemi relativi ai layout SQL e dati di DuckDB. Da utilizzare quando un agente di codifica deve migliorare una query DuckDB lenta, ridurre la memoria o l'I/O, analizzare EXPLAIN o profilare l'output, scegliere join o indici, ottimizzare aggregazioni e scansioni, ottimizzare il parallelismo o progettare tabelle e dati Parquet per query analitiche selettive.
