Optimice, revise y solucione problemas de diseños de datos y SQL de DuckDB. Úselo cuando un agente de codificación debe mejorar una consulta lenta de DuckDB, reducir la memoria o la E/S, analizar EXPLAIN o generar perfiles, elegir uniones o índices, optimizar agregaciones y escaneos, ajustar el paralelismo o diseñar tablas y datos de Parquet para consultas analíticas selectivas.
