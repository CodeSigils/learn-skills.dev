تحسين ومراجعة واستكشاف أخطاء DuckDB SQL وتخطيطات البيانات وإصلاحها. يُستخدم عندما يتعين على وكيل الترميز تحسين استعلام DuckDB البطيء، أو تقليل الذاكرة أو الإدخال/الإخراج، أو تحليل الشرح أو إخراج ملفات التعريف، أو اختيار الصلات أو الفهارس، أو تحسين التجميعات والمسح، أو ضبط التوازي، أو تصميم الجداول وبيانات Parquet للاستعلامات التحليلية الانتقائية.
