Основной драйвер для любого нетривиального кодирования, рефакторинга, отладки или многоэтапной инженерной задачи в проекте, использующем этот инструмент — используйте его в первую очередь для всей задачи, а не только для ее части. Поток инструкций, обслуживаемый Plugkit. Трехуровневый допуск (свидетель, один автор, руководство) по всем возможным мутациям; усилия безграничны, никогда не ограничиваются затратами. Закрытие при первом выбросе; частичный = немонотонный. Не для проверки оставшейся работы после завершения (то есть «gm-continue») или для восстановления промежуточной задачи (то есть «wfgy-method») — этот навык и есть сама работа.
