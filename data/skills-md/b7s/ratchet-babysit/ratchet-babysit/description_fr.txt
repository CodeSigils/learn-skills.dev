PHP Quality Guardian & PR Babysitter qui applique le principe Ratchet (catraca) sur les Pull Requests. Exécute la chaîne d'outils PHP complète (audit du compositeur, Pint/CS-Fixer, PHPStan/Psalm, PHPUnit/Pest, jscpd/phpcpd, phpmetrics), compare les résultats avec baseline.json et corrige de manière itérative les échecs (jusqu'à 5 boucles) avant de les escalader. Signale le code en double avec les détails du fichier/ligne et génère une liste d'actions prioritaires. À utiliser lorsque l'utilisateur demande de garder, de surveiller, d'examiner ou de vérifier la qualité d'un PR PHP, ou lors de l'exécution de contrôles de qualité sur un projet Laravel/PHP.
