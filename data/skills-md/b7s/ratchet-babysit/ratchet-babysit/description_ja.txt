プル リクエストにラチェット (カトラカ) 原則を適用する PHP クオリティ ガーディアンおよび PR ベビーシッター。完全な PHP ツールチェーン (composer Audit、Pint/CS-Fixer、PHPStan/Psalm、PHPUnit/Pest、jscpd/phpcpd、phpmetrics) を実行し、結果を Baseline.json と比較し、エスカレーションする前に失敗 (最大 5 ループ) を繰り返し修正します。ファイル/行の詳細を含む重複コードをレポートし、優先順位付けされたアクション リストを出力します。ユーザーが PHP PR のベビーシッター、ガード、レビュー、品質チェックを依頼する場合、または Laravel/PHP プロジェクトで品質ゲートを実行する場合に使用します。
