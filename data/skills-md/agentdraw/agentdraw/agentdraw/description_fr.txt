Utilisez AgentDraw lorsque l'utilisateur souhaite créer un diagramme modifiable local ou une explication visuelle à partir d'une invite, d'un article, d'un document, d'une note technique ou d'un résumé de révision. Idéal pour les diagrammes structurés pris en charge par Mermaid, tels que les organigrammes/séquences/classes/états, et les visuels explicatifs basés sur SVG tels que les images d'articles, les explicatifs d'architecture, les diagrammes de mécanismes, les cartes de structure et les visuels d'une seule page de type diapositive.
