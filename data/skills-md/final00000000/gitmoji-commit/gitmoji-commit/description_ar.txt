قم بإنشاء التزامات git المحمولة، والعلاقات العامة، وتدفقات الإصدار باستخدام الالتزامات التقليدية والرموز التعبيرية الاختيارية. يُستخدم عندما يطلب المستخدم الالتزام باستخدام الأيقونات، أو gitmoji، أو التاريخ الأجمل، أو تجنب إسناد المؤلف المشارك للذكاء الاصطناعي، أو العمل عبر العديد من واجهات سطر الأوامر الخاصة بالذكاء الاصطناعي، أو إدارة سير عمل GitHub، وGitLab، وAzure DevOps، وGitea/Forgejo، وCodeberg، وBitbucket. يدعم مخرجات ASCII الآمنة، والتدريج الآمن، والتعامل مع الحالة المختلطة، وسير عمل واجهة سطر الأوامر (CLI) عبر المضيف، واستعادة إعادة الأساس/الصراع، ومعالجة الالتزام الأولي، وإرشادات التعديل/الرجوع، وعمليات فحص الدفع الاختيارية.
