Diagnostique y repare aplicaciones Goldsky Compose rotas de forma interactiva. Activadores de: redactar la aplicación en estado de error, bucles de fallas, no se ejecuta, no procesa tareas, cron no se activa, disparador HTTP que devuelve 500, eventos faltantes en el detector de eventos en cadena, errores de billetera, fallas de patrocinio de gas, 'No hay proveedor de paquete disponible', errores de validación de manifiesto, fallas de agrupación/compilación, falta de secreto, 'No se puede usar una billetera inteligente en el desarrollo local', 'Error en el recibo de transacción con el estado'. Úselo también cuando el usuario menciona el nombre de una aplicación de redacción junto con un problema, incluso si no dice "componer" explícitamente, si se refiere a los comandos "goldsky compose" (no a "goldsky turbo" o "goldsky pipeline"). Ejecuta `status`/`logs`/`secret list`/`wallet list` para identificar la causa raíz y ofrece soluciones. Para crear una nueva aplicación desde cero, utilice /compose en su lugar. Para búsquedas de campo de manifiesto/indicador CLI/API sin un problema activo, use /compose-reference en su lugar. NO active si hay problemas en la tubería Turbo o Mirror.
