Diagnostiquez et réparez les applications Goldsky Compose cassées de manière interactive. Déclencheurs sur : composition de l'application en état d'erreur, crashlooping, non en cours d'exécution, pas de traitement des tâches, cron ne se déclenche pas, déclencheur HTTP renvoyant 500, événements manquants de l'écouteur d'événements onchain, erreurs de portefeuille, échecs de parrainage de gaz, "Aucun fournisseur de bundler disponible", erreurs de validation du manifeste, échecs de regroupement/esbuild, secret manquant, "Vous ne pouvez pas utiliser un portefeuille intelligent dans le développement local", "Échec du reçu de transaction avec statut". À utiliser également lorsque l'utilisateur mentionne le nom d'une application Compose à côté d'un problème, même s'il ne dit pas explicitement « composer », s'il fait référence aux commandes « goldsky compose » (et non à « goldsky turbo » ou « goldsky pipeline »). Exécute `status`/`logs`/`secret list`/`wallet list` pour identifier la cause première et propose des correctifs. Pour créer une nouvelle application à partir de zéro, utilisez plutôt /compose. Pour les recherches de champ manifeste/indicateur CLI/API sans problème actif, utilisez plutôt /compose-reference. Ne déclenchez PAS les problèmes de pipeline Turbo ou Mirror.
