تشخيص وإصلاح تطبيقات Goldsky Compose المعطلة بشكل تفاعلي. تشغيل المشغلات: إنشاء تطبيق في حالة خطأ، تعطل، عدم التشغيل، عدم تشغيل المهام، عدم تشغيل cron، مشغل HTTP يعيد 500، أحداث مفقودة لمستمع حدث onchain، أخطاء المحفظة، فشل رعاية الغاز، "لا يتوفر موفر حزمة"، أخطاء التحقق من الصحة، فشل التجميع/الإنشاء، السر المفقود، "لا يمكنك استخدام محفظة ذكية في التطوير المحلي"، "فشل إيصال المعاملة مع الحالة". يُستخدم أيضًا عندما يذكر المستخدم اسم تطبيق Compose جنبًا إلى جنب مع مشكلة ما، حتى إذا لم يذكر "إنشاء" بشكل صريح، إذا كانوا يشيرون إلى أوامر "goldsky compose" (وليس "goldsky Turbo" أو "goldsky Pipeline"). تشغيل `الحالة`/`السجلات`/`القائمة السرية`/`قائمة المحفظة` لتحديد السبب الجذري وتقديم الإصلاحات. لإنشاء تطبيق جديد من البداية، استخدم /compose بدلاً من ذلك. بالنسبة لعمليات البحث عن حقول البيان / علامة CLI / API بدون مشكلة نشطة، استخدم /compose-reference بدلاً من ذلك. لا تقم بتشغيل مشاكل خط أنابيب Turbo أو Mirror.
