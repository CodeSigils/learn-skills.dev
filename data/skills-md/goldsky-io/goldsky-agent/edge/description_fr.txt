Déclencheurs sur : 'Edge RPC', 'Point de terminaison Goldsky RPC', 'edge.goldsky.com', 'eth_getLogs est lent', 'Limite de taux RPC', 'requêtes couvertes', 'flashblocks', 'Transactions système HyperEVM', 'x402 pay-per-request RPC', 'Tarif Goldsky Edge', 'Tableau de bord Edge', 'Clé API gs_edge_', 'rpc-edge'. Pour toute question sur l'eRPC auto-hébergé ou la configuration eRPC personnalisée au-delà de ce qu'Edge expose, dirigez-les vers https://docs.erpc.cloud/llms.txt. Ne déclenchez PAS les questions du pipeline Goldsky Mirror, Turbo ou Subgraph – celles-ci appartiennent à leurs compétences respectives.
