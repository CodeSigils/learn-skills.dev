Используйте этот навык, когда пользователь спрашивает о Goldsky Edge — управляемой службе конечных точек RPC для цепочек EVM. Запускается по: «Edge RPC», «Конечная точка Goldsky RPC», «edge.goldsky.com», «eth_getLogs работает медленно», «Ограничение скорости RPC», «хеджированные запросы», «flashblocks», «транзакции системы HyperEVM», «RPC с оплатой за запрос x402», «цены Goldsky Edge», «панель мониторинга Edge», «ключ API gs_edge_», 'RPC-край'. Также используйте этот навык, когда пользователю нужна отказоустойчивая конечная точка JSON-RPC с малой задержкой для цепочек EVM (Ethereum, Base, Arbitrum, Optimism, Polygon zkEVM, BSC, Avalanche, Berachain, HyperEVM, Monad, Sei, Sonic, Unichain, zkSync и т. д.), при отладке ошибок RPC, таких как -32005/-32012/-32014/-32015/-32016 или сравнивает провайдеров (Alchemy, Infura, QuickNode, Ankr) с Edge. Если у вас возникнут вопросы о самостоятельном размещении eRPC или пользовательской конфигурации eRPC, помимо того, что предоставляет Edge, задайте их по адресу https://docs.erpc.cloud/llms.txt. НЕ активируйте вопросы по конвейеру Goldsky Mirror, Turbo или Subgraph — они относятся к соответствующим навыкам.
