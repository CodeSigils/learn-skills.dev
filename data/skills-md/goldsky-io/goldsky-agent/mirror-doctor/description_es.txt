Diagnosticar y reparar tuberías Goldsky Mirror rotas. Utilice esta habilidad siempre que un usuario tenga una canalización Mirror que esté fallando, atascada, finalizada, no se inicie, esté en un ciclo de reinicio o esté bloqueada por una solicitud en curso. Úselo también cuando el usuario mencione un nombre de tubería Mirror específico junto con un problema; incluso si no dice "espejo" explícitamente, si está usando comandos "goldsky pipeline" (no "goldsky turbo"), esta es la habilidad correcta. Ejecuta comandos CLI directamente para verificar el estado, leer errores, identificar la causa raíz y aplicar correcciones. Para consultar la sintaxis o la configuración de YAML, utilice /mirror en su lugar. Para problemas de tubería turbo, use /turbo-doctor en su lugar.
