Справочник по операциям турбоконвейера — команды жизненного цикла (пауза, возобновление, перезапуск, удаление), состояния конвейера, поведение контрольных точек, различия потоковой передачи и режима задания, синтаксис CLI для проверки/журналов, ярлыки TUI и поиск шаблонов ошибок. Срабатывает при: «как мне приостановить/перезапустить/удалить», «удаление приведет к потере моих данных», «что означает эта ошибка», «проверить ярлыки TUI». Для интерактивной диагностики неисправности трубопровода используйте /turbo-doctor.
