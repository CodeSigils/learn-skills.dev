在用户自己的帐户下构建并部署 Goldsky Compose VRF（可验证随机函数）示例 - 一个 Compose 应用程序，用于侦听 EVM 合约上的“RandomnessRequested”事件，从 drand 信标中获取可验证的随机性，并通过带有 drand 轮 + BLS 签名的“fulfillRandomness”将其写回到链上，以便任何人都可以验证它。触发条件：“构建 VRF”、“可验证的随机函数”、“链上随机性”、“可证明公平的随机数”、“drand oracle”、“链上随机数生成器”、“设置/部署 VRF 示例”、“撰写 VRF”。推荐 Base Sepolia 上共享的、完全未经许可的 RandomnessConsumer，因此无需部署任何内容。该技能携带完整的应用程序源（清单、合同、ABI、任务、drand lib），因此助手可以现成部署或自定义它。对于不是此 VRF 的自定义/新颖 Compose 应用程序，请使用 /compose。要调试已部署的应用程序，请使用 /compose-doctor。对于清单/CLI/API 字段查找，请使用 /compose-reference。
