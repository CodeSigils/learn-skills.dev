Créez et déployez l'exemple Goldsky Compose VRF (fonction aléatoire vérifiable) sous le propre compte de l'utilisateur - une application Compose qui écoute un événement « RandomnessRequested » sur un contrat EVM, récupère le caractère aléatoire vérifiable de la balise drand et l'écrit en chaîne via « fulfillRandomness » avec la signature drand round + BLS afin que tout le monde puisse le vérifier. Déclencheurs sur : « construire un VRF », « fonction aléatoire vérifiable », « caractère aléatoire en chaîne », « nombres aléatoires prouvés justes », « oracle drand », « générateur de nombres aléatoires en chaîne », « configurer/déployer l'exemple VRF », « composer vrf ». Recommande le RandomnessConsumer partagé et entièrement non autorisé sur Base Sepolia afin qu'il n'y ait rien à déployer. Cette compétence contient la source complète de l'application (manifeste, contrat, ABI, tâches, drand lib) afin que l'assistant puisse la déployer directement ou la personnaliser. Pour une application Compose personnalisée/nouvelle qui n’est pas ce VRF, utilisez /compose. Pour déboguer une application déjà déployée, utilisez /compose-doctor. Pour les recherches de champs manifeste/CLI/API, utilisez /compose-reference.
