在用戶自己的帳戶下構建並部署 Goldsky Compose VRF（可驗證隨機函數）示例 - 一個 Compose 應用程序，用於偵聽 EVM 合約上的“RandomnessRequested”事件，從 drand 信標中獲取可驗證的隨機性，並通過帶有 drand 輪 + BLS 簽名的“fulfillRandomness”都可以驗證它。觸發條件：「建構 VRF」、「可驗證的隨機函數」、「鏈上隨機性」、「可證明公平的隨機數」、「drand oracle」、「鏈上隨機數產生器」、「設定/部署 VRF 範例」、「撰寫 VRF」。推薦 Base Sepolia 上共享的、完全未經許可的 RandomnessConsumer，因此無需部署任何內容。此技能攜帶完整的應用程式來源（清單、合約、ABI、任務、drand lib），因此助手可以現成部署或自訂它。對於不是此 VRF 的自訂/新穎 Compose 應用程序，請使用 /compose。若要偵錯已部署的應用程序，請使用 /compose-doctor。對於清單/CLI/API 欄位查找，請使用 /compose-reference。
