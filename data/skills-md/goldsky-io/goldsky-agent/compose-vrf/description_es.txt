Cree e implemente el ejemplo de Goldsky Compose VRF (función aleatoria verificable) bajo la propia cuenta del usuario: una aplicación Compose que escucha un evento "RandomnessRequested" en un contrato EVM, obtiene aleatoriedad verificable de la baliza drand y la vuelve a escribir en la cadena a través de "fulfillRandomness" con la firma drand round + BLS para que cualquiera pueda verificarla. Activadores en: 'construir un VRF', 'función aleatoria verificable', 'aleatoriedad en cadena', 'números aleatorios demostrablemente justos', 'drand oracle', 'generador de números aleatorios en cadena', 'configurar/implementar el ejemplo de VRF', 'componer vrf'. Recomienda el RandomnessConsumer compartido y sin permisos en Base Sepolia para que no haya nada que implementar. Esta habilidad incluye el código fuente completo de la aplicación (manifiesto, contrato, ABI, tareas, drand lib) para que el asistente pueda implementarla lista para usar o personalizarla. Para una aplicación Compose personalizada/novedosa que no sea este VRF, use /compose. Para depurar una aplicación ya implementada, use /compose-doctor.
