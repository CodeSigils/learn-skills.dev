손상된 Goldsky 하위 그래프를 진단하고 수정합니다. 사용자에게 실패, 정지, 동기화 중단, 인덱싱 불가, 자동 일시 중지, 오류 반환 또는 배포되지 않는 하위 그래프가 있을 때마다 이 기술을 사용하세요. 트리거: '하위 그래프 동기화가 중지됨', '하위 그래프가 블록에 멈춤', '하위 그래프 정지', '하위 그래프 배포 실패', '인덱싱 오류', 'SubgraphSyncingFailure', '처리기의 예기치 않은 null', '네트워크 없음', '배포가 이미 존재함', '하위 그래프가 데이터를 반환하지 않음', '하위 그래프 끝점 404', '하위 그래프 제한에 도달함', '속도 제한됨'. 사용자가 문제와 함께 하위 그래프의 이름을 지정할 때도 사용합니다. CLI 명령을 직접 실행하여 상태를 확인하고, 로그를 읽고, 근본 원인을 식별하고, 수정 사항을 적용합니다. 건강하지만 느린 하위 그래프(예: 너무 많은 eth_call)를 빌드, 작성, 배포, 엔드포인트/태그 참조 또는 최적화하려면 /subgraph-builder를 대신 사용하세요.
