Диагностируйте и исправляйте сломанные подграфы Гольдски. Используйте этот навык всякий раз, когда у пользователя есть подграф, который дает сбой, зависает, зависает в синхронизации, не индексируется, автоматически приостанавливается, возвращает ошибки или не развертывается. Срабатывает при: «синхронизация подграфа прекращена», «подграф завис в блоке», «подграф остановлен», «не удалось развернуть подграф», «ошибка индексации», «SubgraphSyncingFailure», «неожиданный нуль в обработчике», «сеть не найдена», «развертывание уже существует», «подграф не возвращает данные», «конечная точка подграфа 404», «достигнут предел подграфа», «ограничена скорость». Также используйте, когда пользователь называет подграф рядом с проблемой. Запускает команды CLI напрямую для проверки состояния, чтения журналов, определения основной причины и применения исправлений. Для создания, создания, развертывания, ссылки на конечную точку/тег или оптимизации работоспособного, но медленного подграфа (например, слишком большого количества eth_calls) вместо этого используйте /subgraph-builder. Для перехода из The Graph вместо этого используйте /subgraph-migrate.
