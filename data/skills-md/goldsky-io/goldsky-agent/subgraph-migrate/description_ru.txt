Перенесите подграф из The Graph в Goldsky в качестве замены — никаких изменений кода не требуется. Используйте этот навык, когда пользователь хочет переместить, переключить, портировать или перенести подграф из The Graph (размещенный сервис, Subgraph Studio или децентрализованную сеть) в Goldsky или когда конечная точка подграфа, на которую он полагался (например, размещенный сервис The Graph), вышла из строя. Срабатывает при: «мигрировать из The Graph», «переместить мой подграф в Goldsky», «выключить The Graph», «переразвернуть подграф TheGraph», «конечная точка моего подграфа исчезла», «from-url», «from-ipfs-hash», «вставная замена для The Graph». Для диагностики подграфа, который вышел из строя после миграции, используйте /subgraph-doctor. Для сборки/авторской разработки или общей ссылки на развертывание/тег/конечную точку используйте /subgraph-builder.
