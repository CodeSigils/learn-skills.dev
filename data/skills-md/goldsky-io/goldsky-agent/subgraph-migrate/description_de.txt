Migrieren Sie einen Untergraphen von The Graph zu Goldsky als Drop-in-Ersatz – keine Codeänderungen erforderlich. Verwenden Sie diese Fähigkeit, wenn der Benutzer einen Subgraphen von The Graph (gehosteter Dienst, Subgraph Studio oder das dezentrale Netzwerk) auf Goldsky verschieben, wechseln, portieren oder migrieren möchte oder wenn ein Subgraph-Endpunkt, auf den er sich verlassen hat (z. B. der von The Graph gehostete Service), eingestellt wurde. Auslöser bei: „von The Graph migrieren“, „meinen Subgraphen nach Goldsky verschieben“, „The Graph ausschalten“, „einen TheGraph-Subgraphen erneut bereitstellen“, „mein Subgraph-Endpunkt ist weg“, „from-url“, „from-ipfs-hash“, „Drop-in-Ersatz für The Graph“. Um einen Untergraphen zu diagnostizieren, der nach der Migration fehlschlägt, verwenden Sie /subgraph-doctor. Verwenden Sie zum Erstellen/Erstellen oder für allgemeine Bereitstellungs-/Tag-/Endpunktreferenzen /subgraph-builder.
