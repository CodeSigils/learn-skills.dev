Используйте этот навык, когда пользователь спрашивает о Goldsky Compose — фреймворке TypeScript для оффчейн-ончейн для ончейн-оракулов, хранителей, автоматических выключателей и межцепочной автоматизации. Запускается по: 'goldsky Compose', 'compose.yaml', 'compose Deploy/init/dev', 'Compose Task', 'Cron Task onchain', 'спонсируемый газ', 'writeContract из TypeScript', 'создание ценового оракула', 'решение рынка прогнозирования', 'прослушиватель событий onchain', 'задача, активируемая HTTP', 'умный кошелек'. Также используйте, когда пользователь хочет запустить TypeScript для цепочек EVM с управляемым газом, запланировать запись в цепочке через cron, реагировать на события в цепочке или развернуть бессерверную задачу с секретами и умным кошельком. Для отладки неработающего приложения используйте /compose-doctor. Для поиска манифеста/CLI/API используйте /compose-reference. НЕ запускайте триггеры Goldsky Turbo, Mirror, Subgraphs, Edge или Datasets — они относятся к соответствующим навыкам.
