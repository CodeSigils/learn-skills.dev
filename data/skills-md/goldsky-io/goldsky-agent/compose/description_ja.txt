ユーザーが Goldsky Compose (オンチェーン オラクル、キーパー、サーキット ブレーカー、クロスチェーン オートメーション用のオフチェーンからオンチェーンへの TypeScript フレームワーク) について尋ねたときにこのスキルを使用します。トリガー対象: 「goldsky compose」、「compose.yaml」、「composedeploy/init/dev」、「compose task」、「cron task onchain」、「スポンサー付きガス」、「writeContract from TypeScript」、「価格オラクルの構築」、「予測市場の解決」、「オンチェーン イベント リスナー」、「HTTP トリガー タスク」、「スマート ウォレット」。また、ユーザーがマネージド ガスを使用して EVM チェーンに対して TypeScript を実行する場合、cron を介してオンチェーン書き込みをスケジュールする場合、オンチェーン イベントに反応する場合、またはシークレットとスマート ウォレットを使用してサーバーレス タスクをデプロイする場合にも使用します。壊れたアプリをデバッグするには、/compose-doctor を使用します。マニフェスト/CLI/API ルックアップの場合は、/compose-reference を使用します。 Goldsky Turbo、Mirror、Subgraphs、Edge、または Dataset ではトリガーしないでください。これらはそれぞれのスキルに属します。
