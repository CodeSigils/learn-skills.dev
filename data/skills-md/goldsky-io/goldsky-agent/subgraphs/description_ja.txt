このスキルは、ユーザーが Goldsky サブグラフ (サブグラフのデプロイ、管理、クエリ) について尋ねたときに使用します。トリガー: 「サブグラフのデプロイ」、「グラフからの移行」、「サブグラフとは」、「GraphQL エンドポイント」、「ローコードまたはノーコードのサブグラフ」、「サブグラフ タグ」、「サブグラフ Webhook」、「クロスチェーン サブグラフ」、「サブグラフ ストール」、「サブグラフ API キー」、「初期サブグラフ」、「足場サブグラフ」、「サブグラフ」ログ」、「サブグラフの一時停止」、「サブグラフの開始」、「サブグラフのグラフト」。ユーザーがオンチェーン データ上に GraphQL API を構築する場合、インデックス付きブロックチェーン データで dApp フロントエンドを強化する場合、または Goldsky 上の既存の TheGraph サブグラフを再利用する場合にも、このスキルを使用します。 GraphQL を使用せずに生のチェーン データをデータベースに直接ストリーミングすることに関する質問については、代わりにターボ ビルダーまたはミラー スキルを使用してください。
