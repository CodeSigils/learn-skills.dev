Utilisez cette compétence lorsque l'utilisateur pose des questions sur les pipelines Goldsky Mirror : création, déploiement, exploitation ou dépannage de Mirror. Déclencheurs sur : « Pipeline miroir », « Application du pipeline Goldsky », « Synchronisation du sous-graphe avec la base de données », « Miroir vs Turbo », « Indexation directe », « Pipeline miroir YAML », « Pause/arrêt/redémarrage du pipeline miroir ». Utilisez également cette compétence lorsque l'utilisateur souhaite synchroniser un sous-graphe Goldsky dans une base de données ou une file d'attente de messages — Mirror est le seul produit de pipeline qui prend en charge les sources de sous-graphes. Pour les nouveaux pipelines qui n’ont pas besoin d’une source de sous-graphe, la compétence Turbo-Builder est généralement mieux adaptée. Ne déclenchez PAS sur les commandes « goldsky turbo » ou les requêtes génériques « construire un pipeline » sans contexte de sous-graphe – celles-ci appartiennent aux compétences turbo.
