Utilice esta habilidad cuando el usuario pregunte sobre las canalizaciones de Goldsky Mirror: creación, implementación, operación o solución de problemas de Mirror. Activadores en: 'canalización espejo', 'aplicación de canalización goldsky', 'sincronizar subgrafo con la base de datos', 'espejo vs turbo', 'indexación directa', 'canalización espejo YAML', 'pausa/detención/reinicio de canalización espejo'. Utilice también esta habilidad cuando el usuario quiera sincronizar un subgrafo Goldsky en una base de datos o cola de mensajes: Mirror es el único producto de canalización que admite fuentes de subgrafo. Para tuberías nuevas que no necesitan una fuente de subgrafo, la habilidad de turboconstructor suele ser una mejor opción. NO active los comandos 'goldsky turbo' ni las solicitudes genéricas de 'construir una tubería' sin contexto de subgrafo; esas pertenecen a las habilidades turbo.
