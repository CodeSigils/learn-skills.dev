Используйте этот навык, когда пользователь спрашивает о поле, флаге, типе или форме API Goldsky Compose — справочник по поиску полей compose.yaml, каждого флага CLI `goldsky Compose`, API TaskContext (env, fetch, callTask, logEvent, evm, Collection), API-интерфейсов кошелька (умный кошелек, BYO EOA), газового спонсорства, создания кода контракта, URL-адреса информационной панели и цен. Запускается по: «полям compose.yaml», «синтаксису cron для составления», «аутентификации триггера HTTP», «формату onchain_event», «TaskContext API», «опциям evm.wallet», «sponsorGas default», «методам IWallet», «методам сбора», «сочинению кода», «ценам составления», «составлению статуса вывода JSON», «флагам составления goldsky». Проконсультируйтесь, прежде чем предлагать поле, флаг или форму API — избегайте галлюцинаций несуществующих вариантов. Для пошаговой сборки используйте /compose. Для отладки используйте /compose-doctor. НЕ активируйте поиск в режиме Турбо, Зеркало, Подграфы или Край — они относятся к их собственным справочным навыкам.
