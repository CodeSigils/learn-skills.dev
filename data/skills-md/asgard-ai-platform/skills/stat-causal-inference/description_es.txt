Aplicar métodos de inferencia causal (marco contrafactual, variables instrumentales, emparejamiento de puntajes de propensión y diferencias en diferencias) para estimar los efectos causales a partir de datos observacionales. Utilice esta habilidad cuando el usuario necesite determinar si X causó Y a partir de datos no experimentales, evaluar el impacto de un programa/política sin un ensayo aleatorio o controlar los factores de confusión, incluso si dice "¿este cambio causó la mejora?", "cómo medimos el impacto sin un experimento" o "es esta correlación o causalidad".
