Realice una planificación de escenarios para prepararse para múltiples futuros plausibles utilizando fuerzas impulsoras, ejes de incertidumbre y la matriz de escenarios 2x2. Utilice esta habilidad cuando el usuario se enfrenta a una gran incertidumbre, necesita probar una estrategia frente a diferentes futuros o preparar planes de contingencia, incluso si dice "¿qué pasa si las cosas van mal?", "cómo podría ser el futuro", "cómo nos preparamos para la incertidumbre" o "probamos nuestra estrategia".
