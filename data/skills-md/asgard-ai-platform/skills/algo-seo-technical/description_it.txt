Ottimizza i Core Web Vitals (LCP, INP, CLS) per migliorare il posizionamento nei motori di ricerca e l'esperienza utente. Usa questa competenza quando l'utente deve diagnosticare problemi di velocità della pagina, migliorare il Largest Contentful Paint, ridurre lo spostamento del layout o soddisfare i segnali di esperienza pagina di Google — anche se dice “il mio sito è lento”, “Core Web Vitals falliti” o “ottimizzazione della velocità della pagina”.
