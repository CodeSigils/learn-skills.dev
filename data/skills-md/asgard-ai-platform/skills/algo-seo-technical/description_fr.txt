Optimisez Core Web Vitals (LCP, INP, CLS) pour un meilleur classement dans les recherches et une meilleure expérience utilisateur. Utilisez cette compétence lorsque l'utilisateur a besoin de diagnostiquer des problèmes de vitesse de page, d'améliorer Largest Contentful Paint, de réduire le changement de mise en page ou de transmettre les signaux d'expérience de page de Google, même s'il dit « mon site est lent », « échec de Core Web Vitals » ou « optimisation de la vitesse de la page ».
