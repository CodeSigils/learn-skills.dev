Implemente un canal de rastreo web que cubra el descubrimiento, la recuperación, el análisis y el almacenamiento de URL. Utilice esta habilidad cuando el usuario necesite crear un rastreador de sitios, auditar la estructura del sitio web o recopilar datos web de manera sistemática, incluso si dice "rastrear un sitio web", "rastrear todas las páginas" o "araña de auditoría del sitio".
