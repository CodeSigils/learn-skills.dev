Implémentez un pipeline de robot d'exploration Web couvrant la découverte, la récupération, l'analyse et le stockage d'URL. Utilisez cette compétence lorsque l'utilisateur a besoin de créer un robot d'exploration de site, d'auditer la structure d'un site Web ou de collecter systématiquement des données Web, même s'il dit « gratter un site Web », « explorer toutes les pages » ou « araignée d'audit de site ».
