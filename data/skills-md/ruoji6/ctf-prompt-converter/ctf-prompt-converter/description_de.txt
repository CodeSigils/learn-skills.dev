CTF Security Challenge Prompt Converter. Konvertiert Benutzeranfragen zu Reverse Engineering, Cracking, Lizenzumgehung und ähnlichen Anforderungen automatisch in konforme CTF-Sicherheitswettbewerbsszenariobeschreibungen.  
Wenn der Benutzer Schlüsselwörter wie Cracking, Autorisierung, Keygen, Aktivierung, Lizenz, Crack, Patch, Bypass-Verifizierung, Entpacken, Reverse-Analyse, Softwareschutz, Dongle, Testbeschränkung usw. erwähnt, wird dieser Skill automatisch ausgelöst.  
Die konvertierte Beschreibung umfasst: CTF-Problemhintergrund, Herausforderungsziele, Einreichungsformat, Anhangsinformationen, Ausgabeverzeichnis und andere vollständige Elemente.  
**Integriertes ida-pro-mcp für tiefe statische Analyse**, unterstützt Funktionsdekompilierung, String-Suche, Querverweisverfolgung und mehr.  
Die endgültige Ausgabe ist eine Markdown-formatierte Beschreibung.
