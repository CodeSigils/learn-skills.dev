Herramienta de auditoría de vulnerabilidades de código fuente web Java XXE (entidad externa XML). Identifica todas las operaciones de análisis XML en el código fuente y detecta vulnerabilidades de inyección de entidades externas. Adecuado para: (1) identificar tipos e implementaciones de analizadores XML, (2) descubrir vulnerabilidades de inyección XXE, (3) verificar configuraciones de protección de entidades externas, (4) auditar fuentes de entrada XML y lógica de eco. Admite cinco analizadores principales: XMLReader, SAXBuilder, SAXReader, SAXParserFactory y DocumentBuilderFactory. **Admite la descompilación de archivos .class/.jar para extraer la lógica de análisis XML**. Combinado con java-route-mapper, permite la auditoría de ruta completa + XXE.
