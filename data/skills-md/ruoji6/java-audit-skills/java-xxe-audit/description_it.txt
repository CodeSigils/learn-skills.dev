Strumento di controllo delle vulnerabilità del codice sorgente Web Java XXE (Entità esterna XML). Identifica tutte le operazioni di analisi XML nel codice sorgente e rileva le vulnerabilità di inserimento di entità esterne. Adatto per: (1) identificare tipi e implementazioni di parser XML, (2) scoprire vulnerabilità di tipo XXE injection, (3) controllare le configurazioni di protezione di entità esterne, (4) controllare le origini di input XML e la logica dell'eco. Supporta cinque parser tradizionali: XMLReader, SAXBuilder, SAXReader, SAXParserFactory e DocumentBuilderFactory. **Supporta la decompilazione di file .class/.jar per estrarre la logica di analisi XML**. Combinato con Java-Route-Mapper, consente il percorso completo + auditing XXE.
