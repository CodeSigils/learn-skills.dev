Java Web ソースコード XXE (XML 外部エンティティ) 脆弱性監査ツール。ソース コード内のすべての XML 解析操作を識別し、外部エンティティ インジェクションの脆弱性を検出します。用途: (1) XML パーサーのタイプと実装の識別、(2) XXE インジェクションの脆弱性の発見、(3) 外部エンティティ保護構成のチェック、(4) XML 入力ソースとエコー ロジックの監査。 XMLReader、SAXBuilder、SAXReader、SAXParserFactory、DocumentBuilderFactory の 5 つの主流パーサーをサポートします。 **XML 解析ロジックを抽出するための .class/.jar ファイルの逆コンパイルをサポート**。 java-route-mapper と組み合わせると、完全なルート + XXE 監査が可能になります。
