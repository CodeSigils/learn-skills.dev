Outil d'audit de vulnérabilité du code source XXE (XML External Entity) Java Web. Identifie toutes les opérations d'analyse XML dans le code source et détecte les vulnérabilités d'injection d'entités externes. Convient pour : (1) l'identification des types et des implémentations d'analyseurs XML, (2) la découverte des vulnérabilités d'injection XXE, (3) la vérification des configurations de protection des entités externes, (4) l'audit des sources d'entrée XML et de la logique d'écho. Prend en charge cinq analyseurs traditionnels : XMLReader, SAXBuilder, SAXReader, SAXParserFactory et DocumentBuilderFactory. **Prend en charge la décompilation des fichiers .class/.jar pour extraire la logique d'analyse XML**. Combiné avec java-route-mapper, il permet un audit d'itinéraire complet + XXE.
