Инструмент аудита уязвимостей исходного кода Java Web XXE (XML external Entity). Идентифицирует все операции синтаксического анализа XML в исходном коде и обнаруживает уязвимости внедрения внешних сущностей. Подходит для: (1) определения типов и реализаций анализаторов XML, (2) обнаружения уязвимостей внедрения XXE, (3) проверки конфигураций защиты внешних объектов, (4) аудита источников ввода XML и логики эха. Поддерживает пять основных анализаторов: XMLReader, SAXBuilder, SAXReader, SAXParserFactory и DocumentBuilderFactory. **Поддерживает декомпиляцию файлов .class/.jar для извлечения логики синтаксического анализа XML**. В сочетании с java-route-mapper он обеспечивает полный аудит маршрута + XXE.
