أداة تدقيق الثغرات الأمنية لرمز ويب Java XXE (كيان خارجي XML). يحدد جميع عمليات تحليل XML في الكود المصدري ويكتشف الثغرات الأمنية في حقن الكيان الخارجي. مناسب لـ: (1) تحديد أنواع وتطبيقات محلل XML، (2) اكتشاف ثغرات حقن XXE، (3) التحقق من تكوينات حماية الكيان الخارجي، (4) تدقيق مصادر إدخال XML ومنطق الصدى. يدعم خمسة موزعين رئيسيين: XMLReader، وSAXBuilder، وSAXReader، وSAXParserFactory، وDocumentBuilderFactory. ** يدعم فك ملفات .class/.jar لاستخراج منطق تحليل XML **. بالاشتراك مع Java-route-mapper، فإنه يتيح تدقيق المسار الكامل + XXE.
