Java Web source-code XXE (XML External Entity) vulnerability audit tool. Identifies all XML parsing operations in the source code and detects external-entity injection vulnerabilities. Suitable for: (1) identifying XML parser types and implementations, (2) discovering XXE injection vulnerabilities, (3) checking external-entity protection configurations, (4) auditing XML input sources and echo logic. Supports five mainstream parsers: XMLReader, SAXBuilder, SAXReader, SAXParserFactory, and DocumentBuilderFactory. **Supports decompiling .class/.jar files to extract XML parsing logic**. Combined with java-route-mapper, it enables full route + XXE auditing.
