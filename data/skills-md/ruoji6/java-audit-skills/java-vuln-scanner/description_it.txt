Strumento di rilevamento delle vulnerabilità della versione del componente Java. Esamina le dipendenze di terze parti nei file pom.xml, build.gradle o jar, soddisfa le regole di vulnerabilità note (CVE) e genera report di rilevamento delle vulnerabilità. Adatto per: (1) controllo di sicurezza delle dipendenze del progetto Java, (2) identificazione delle vulnerabilità dei componenti ad alto rischio come Log4j, Fastjson, Shiro, Spring, (3) estrazione delle dipendenze dopo la decompilazione del pacchetto jar. Supporta il raggruppamento gerarchico per directory e supporta l'estrazione di informazioni sulle dipendenze dai file .class/.jar tramite java-decompile-mcp.
