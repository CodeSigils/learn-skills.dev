Java component version vulnerability detection tool. Scans third-party dependencies in pom.xml, build.gradle, or jar files, matches known vulnerability rules (CVE), and generates vulnerability detection reports. Suitable for: (1) security auditing of Java project dependencies, (2) identifying high-risk component vulnerabilities such as Log4j, Fastjson, Shiro, Spring, (3) dependency extraction after jar package decompilation. Supports hierarchical grouping by directory, and supports extracting dependency information from .class/.jar files via java-decompile-mcp.
