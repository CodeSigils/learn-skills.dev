Javaコンポーネントバージョンの脆弱性検出ツール。 pom.xml、build.gradle、または jar ファイル内のサードパーティの依存関係をスキャンし、既知の脆弱性ルール (CVE) と照合して、脆弱性検出レポートを生成します。用途: (1) Java プロジェクトの依存関係のセキュリティ監査、(2) Log4j、Fastjson、Shiro、Spring などの高リスク コンポーネントの脆弱性の特定、(3) jar パッケージの逆コンパイル後の依存関係の抽出。ディレクトリによる階層グループ化をサポートし、java-decompile-mcp を介して .class/.jar ファイルから依存関係情報を抽出することをサポートします。
