Инструмент обнаружения уязвимостей версий компонентов Java. Сканирует сторонние зависимости в файлах pom.xml, build.gradle или jar, сопоставляет известные правила уязвимостей (CVE) и создает отчеты об обнаружении уязвимостей. Подходит для: (1) аудита безопасности зависимостей проекта Java, (2) выявления уязвимостей компонентов высокого риска, таких как Log4j, Fastjson, Shiro, Spring, (3) извлечения зависимостей после декомпиляции jar-пакета. Поддерживает иерархическую группировку по каталогам и поддерживает извлечение информации о зависимостях из файлов .class/.jar с помощью java-decompile-mcp.
