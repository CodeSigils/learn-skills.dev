Se utiliza cuando un usuario solicita una auditoría del código fuente de Java, .NET o PHP, artefactos de implementación, artefactos descompilados o hallazgos de seguridad, y requiere directorios de salida de script predeterminados, directorios de salida de informes, referencias de descompilación y desofuscación de Java/.NET, escaneos de coincidencia de expresiones regulares YAML de componentes Java, criterios de determinación de vulnerabilidad confirmados, cargas útiles de seguridad y evidencia del paquete de solicitud HTTP original de BurpSuite. Destinado únicamente a auditoría de código autorizado y verificación de seguridad defensiva.
