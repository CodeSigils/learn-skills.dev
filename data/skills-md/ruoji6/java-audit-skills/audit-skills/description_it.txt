Quando l'utente richiede il controllo del codice sorgente Java, .NET o PHP, degli artefatti di distribuzione, degli artefatti decompilati o dei risultati di sicurezza e necessita della directory di output dello script predefinita, della directory di output del report, della decompilazione Java/.NET e dei riferimenti di deoffuscamento, della scansione di corrispondenza regex YAML del componente Java, della conferma dei criteri di determinazione della vulnerabilità, dei payload di sicurezza e delle prove dei pacchetti di richieste HTTP non elaborate BurpSuite. Viene utilizzato esclusivamente per il controllo del codice autorizzato e la verifica difensiva della sicurezza.
