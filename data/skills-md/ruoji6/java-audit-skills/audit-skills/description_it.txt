Utilizzato quando l'utente richiede il controllo del codice sorgente Java, .NET o PHP, degli artefatti di distribuzione, degli artefatti decompilati o dei risultati di sicurezza e richiede la directory di output dello script predefinita, la directory di output del report, la decompilazione Java/.NET e i riferimenti di deoffuscamento, le scansioni di corrispondenza regex YAML del componente Java, la conferma dei criteri di determinazione della vulnerabilità, i payload sicuri e le prove dei pacchetti di richieste HTTP grezze BurpSuite. Destinato esclusivamente agli audit del codice autorizzati e alla verifica difensiva della sicurezza.
