Wenn der Benutzer eine Prüfung von Java-, .NET- oder PHP-Quellcode/Bereitstellungsartefakten/dekompilierten Artefakten/Sicherheitsergebnissen anfordert und das Standard-Skriptausgabeverzeichnis, das Berichtsausgabeverzeichnis, Java/.NET-Dekompilierungs- und De-Verschleierungsreferenzen, einen YAML-Regex-Matching-Scan für Java-Komponenten, eine Bestätigung der Schwachstellenbestimmungskriterien, Sicherheitsnutzlasten und Beweise für BurpSuite-Roh-HTTP-Anforderungspakete benötigt. Es wird ausschließlich für autorisierte Codeprüfungen und defensive Sicherheitsüberprüfungen verwendet.
