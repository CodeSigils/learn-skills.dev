Когда пользователь запрашивает аудит исходного кода Java, .NET или PHP, артефактов развертывания, декомпилированных артефактов или результатов безопасности, и ему требуется каталог вывода сценария по умолчанию, каталог вывода отчета, ссылки на декомпиляцию и деобфускацию Java/.NET, сканирование на соответствие регулярным выражениям YAML компонента Java, подтверждение критериев определения уязвимости, полезные данные безопасности и необработанные доказательства пакета HTTP-запроса BurpSuite. Он используется исключительно для авторизованного аудита кода и защитной проверки безопасности.
