Java Web ソース コード認証メカニズムの監査ツール。すべての認証実装をソース コードから識別し、認証バイパスの脆弱性と過剰特権アクセスの欠陥を検出します。 (1) 認証フレームワークと実装方法の認識、(2) 認証バイパスの脆弱性の発見、(3) 過剰な特権アクセスの欠陥の検出、(4) 許可検証ロジックの監査に適しています。 Kiri、Spring Security、JWT、フィルター/インターセプター、カスタム認証などをサポートします。 **認証ロジックを抽出するための .class/.jar ファイルの逆コンパイルをサポートします**。 java-route-mapper と一緒に使用すると、完全なルートと認証の監査が可能になります。
