Инструмент аудита механизма аутентификации исходного кода Java Web. Идентифицирует все реализации аутентификации из исходного кода, обнаруживает уязвимости обхода аутентификации и дефекты несанкционированного доступа. Подходит для: (1) идентификации инфраструктур аутентификации и методов реализации, (2) обнаружения уязвимостей обхода аутентификации, (3) обнаружения дефектов несанкционированного доступа, (4) аудита логики проверки разрешений. Поддерживает Shiro, Spring Security, JWT, Filter/Interceptor, пользовательскую аутентификацию и т. д. **Поддерживает декомпиляцию файлов .class/.jar для извлечения логики аутентификации**. При использовании вместе с java-route-mapper он может обеспечить полный аудит маршрута + аутентификации.
