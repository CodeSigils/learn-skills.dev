أداة تدقيق آلية مصادقة رمز مصدر الويب Java. فهو يحدد جميع تطبيقات المصادقة من الكود المصدري ويكتشف نقاط الضعف في تجاوز المصادقة وعيوب الوصول غير المصرح به. مناسب لـ: (1) تحديد أطر المصادقة وطرق التنفيذ، (2) اكتشاف ثغرات تجاوز المصادقة، (3) اكتشاف عيوب الوصول غير المصرح بها، (4) منطق التحقق من صحة إذن التدقيق. يدعم Shiro وSpring Security وJWT وFilter/Interceptor والمصادقة المخصصة وما إلى ذلك. **يدعم فك ملفات .class/.jar لاستخراج منطق المصادقة**. بالاشتراك مع Java-route-mapper، يمكنه تحقيق مسار شامل + تدقيق المصادقة.
