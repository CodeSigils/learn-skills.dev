Strumento di controllo del meccanismo di autenticazione del codice sorgente Web Java. Identifica tutte le implementazioni di autenticazione dal codice sorgente, rileva le vulnerabilità di bypass dell'autenticazione e i difetti di escalation dei privilegi. Adatto per: (1) identificare framework di autenticazione e metodi di implementazione, (2) scoprire vulnerabilità di bypass dell'autenticazione, (3) rilevare difetti di escalation dei privilegi, (4) controllare la logica di verifica delle autorizzazioni. Supporta Shiro, Spring Security, JWT, Filter/Interceptor, autenticazione personalizzata, ecc. **Supporta la decompilazione di file .class/.jar per estrarre la logica di autenticazione**. Combinato con java-route-mapper, consente il controllo completo del percorso e dell'autenticazione.
