Herramienta de auditoría del mecanismo de autenticación del código fuente web Java. Identifica todas las implementaciones de autenticación desde el código fuente y detecta vulnerabilidades de omisión de autenticación y defectos de acceso no autorizado. Aplicable a: (1) identificar marcos de autenticación y métodos de implementación, (2) descubrir vulnerabilidades de omisión de autenticación, (3) detectar defectos de acceso no autorizado, (4) auditar la lógica de verificación de permisos. Admite Shiro, Spring Security, JWT, Filter/Interceptor, autenticación personalizada, etc. **Admite la descompilación de archivos .class/.jar para extraer la lógica de autenticación**. Combinado con java-route-mapper, permite una auditoría completa de enrutamiento + autenticación.
