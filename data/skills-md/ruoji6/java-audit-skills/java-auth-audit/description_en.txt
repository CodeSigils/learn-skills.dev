Java Web source code authentication mechanism audit tool. It identifies all authentication implementations from the source code, detects authentication bypass vulnerabilities and over‑privilege access defects. Suitable for: (1) recognizing authentication frameworks and implementation methods, (2) discovering authentication bypass vulnerabilities, (3) detecting over‑privilege access defects, (4) auditing permission‑validation logic. Supports Shiro, Spring Security, JWT, Filter/Interceptor, custom authentication, etc. **Supports decompiling .class/.jar files to extract authentication logic**. When used together with java‑route‑mapper, it enables complete route‑plus‑authentication auditing.
