Java 웹 소스 코드 인증 메커니즘 감사 도구입니다. 소스 코드에서 모든 인증 구현을 식별하고 인증 우회 취약점 및 무단 액세스 결함을 탐지합니다. (1) 인증 프레임워크 및 구현 방법 식별, (2) 인증 우회 취약성 발견, (3) 무단 액세스 결함 감지, (4) 권한 확인 논리 감사에 적합합니다. Shiro, Spring Security, JWT, 필터/인터셉터, 사용자 정의 인증 등을 지원합니다. **인증 로직을 추출하기 위해 .class/.jar 파일 디컴파일을 지원합니다**. java-route-mapper와 함께 사용하면 완전한 라우팅+인증 감사를 달성할 수 있습니다.
