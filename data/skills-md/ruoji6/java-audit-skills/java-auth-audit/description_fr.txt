Outil d'audit du mécanisme d'authentification du code source Web Java. Il identifie toutes les implémentations d'authentification à partir du code source, détecte les vulnérabilités de contournement d'authentification et les défauts d'accès surprivilégiés. Convient pour : (1) reconnaître les cadres d'authentification et les méthodes de mise en œuvre, (2) découvrir les vulnérabilités de contournement d'authentification, (3) détecter les défauts d'accès par privilèges excessifs, (4) auditer la logique de validation des autorisations. Prend en charge Shiro, Spring Security, JWT, Filter/Interceptor, l'authentification personnalisée, etc. **Prend en charge la décompilation des fichiers .class/.jar pour extraire la logique d'authentification**. Lorsqu'il est utilisé avec Java‑route‑mapper, il permet un audit complet de route plus authentification.
