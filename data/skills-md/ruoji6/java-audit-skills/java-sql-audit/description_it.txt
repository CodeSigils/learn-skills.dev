Strumento di controllo delle vulnerabilità SQL injection del codice sorgente Web Java. Individua ogni voce di esecuzione SQL nel codice sorgente e rileva i difetti di injection. Casi d'uso: (1) identificare framework di esecuzione SQL e modelli di implementazione, (2) scoprire vulnerabilità di SQL injection, (3) verificare l'utilizzo di query con parametri, (4) individuare bug di concatenazione SQL dinamica. Supporta i tre framework principali: JDBC, MyBatis, Hibernate. **Può decompilare file .class/.jar per estrarre la logica SQL**. Combinato con java-route-mapper, consente il routing completo + controllo dell'iniezione SQL.
