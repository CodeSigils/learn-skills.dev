Java Web ソースコードの SQL インジェクション脆弱性監査ツール。ソース コード内のすべての SQL 実行エントリを特定し、インジェクションの欠陥を検出します。ユースケース: (1) SQL 実行フレームワークと実装パターンの特定、(2) SQL インジェクションの脆弱性の発見、(3) パラメーター化されたクエリの使用の検証、(4) 動的 SQL 連結のバグの特定。 JDBC、MyBatis、Hibernate の 3 つの主流フレームワークをサポートします。 **.class/.jar ファイルを逆コンパイルして SQL ロジックを抽出できます**。 java-route-mapper と組み合わせると、完全なルーティング + SQL インジェクション監査が可能になります。
