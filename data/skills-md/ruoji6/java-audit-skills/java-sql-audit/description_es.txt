Herramienta de auditoría de vulnerabilidades de inyección SQL de código fuente web Java. Localiza cada entrada de ejecución de SQL en el código fuente y detecta fallas de inyección. Casos de uso: (1) identificar marcos de ejecución de SQL y patrones de implementación, (2) descubrir vulnerabilidades de inyección de SQL, (3) verificar el uso de consultas parametrizadas, (4) detectar errores de concatenación dinámica de SQL. Admite los tres marcos principales: JDBC, MyBatis, Hibernate. **Puede descompilar archivos .class/.jar para extraer la lógica SQL**. Combinado con java-route-mapper, permite enrutamiento completo + auditoría de inyección SQL.
