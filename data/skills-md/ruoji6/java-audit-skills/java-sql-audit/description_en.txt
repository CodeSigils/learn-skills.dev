Java Web source-code SQL injection vulnerability audit tool. Locates every SQL execution entry in the source code and detects injection flaws. Use cases: (1) identify SQL execution frameworks and implementation patterns, (2) uncover SQL injection vulnerabilities, (3) verify parameterized-query usage, (4) spot dynamic SQL concatenation bugs. Supports the three mainstream frameworks: JDBC, MyBatis, Hibernate. **Can decompile .class/.jar files to extract SQL logic**. Combined with java-route-mapper, it enables full routing + SQL-injection auditing.
