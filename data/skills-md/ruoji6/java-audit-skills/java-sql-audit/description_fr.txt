Outil d'audit de vulnérabilité d'injection SQL de code source Web Java. Localise chaque entrée d'exécution SQL dans le code source et détecte les failles d'injection. Cas d'utilisation : (1) identifier les cadres d'exécution SQL et les modèles d'implémentation, (2) découvrir les vulnérabilités d'injection SQL, (3) vérifier l'utilisation des requêtes paramétrées, (4) repérer les bogues de concaténation SQL dynamique. Prend en charge les trois frameworks principaux : JDBC, MyBatis, Hibernate. **Peut décompiler les fichiers .class/.jar pour extraire la logique SQL**. Combiné avec java-route-mapper, il permet un routage complet + un audit par injection SQL.
