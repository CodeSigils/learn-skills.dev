Java 웹 소스 코드 SQL 주입 취약점 감사 도구. 소스 코드에서 모든 SQL 실행 항목을 찾아 주입 결함을 탐지합니다. 사용 사례: (1) SQL 실행 프레임워크 및 구현 패턴 식별, (2) SQL 주입 취약점 발견, (3) 매개변수화된 쿼리 사용 확인, (4) 동적 SQL 연결 버그 발견. JDBC, MyBatis, Hibernate의 세 가지 주요 프레임워크를 지원합니다. **.class/.jar 파일을 디컴파일하여 SQL 로직을 추출할 수 있습니다**. java-route-mapper와 결합하면 전체 라우팅 + SQL 주입 감사가 가능합니다.
