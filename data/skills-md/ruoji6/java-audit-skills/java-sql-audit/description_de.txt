Schwachstellenprüfungstool für SQL-Injection im Java-Web-Quellcode. Lokalisiert jeden SQL-Ausführungseintrag im Quellcode und erkennt Injektionsfehler. Anwendungsfälle: (1) SQL-Ausführungsframeworks und Implementierungsmuster identifizieren, (2) SQL-Injection-Schwachstellen aufdecken, (3) die Verwendung parametrisierter Abfragen überprüfen, (4) dynamische SQL-Verkettungsfehler erkennen. Unterstützt die drei gängigen Frameworks: JDBC, MyBatis, Hibernate. **Kann .class/.jar-Dateien dekompilieren, um SQL-Logik zu extrahieren**. In Kombination mit Java-Route-Mapper ermöglicht es vollständiges Routing + SQL-Injection-Auditing.
