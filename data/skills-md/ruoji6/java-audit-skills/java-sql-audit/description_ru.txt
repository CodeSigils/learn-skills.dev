Инструмент аудита уязвимостей с помощью SQL-инъекций в исходном коде Java Web. Находит каждую запись выполнения SQL в исходном коде и обнаруживает ошибки внедрения. Варианты использования: (1) определить структуры выполнения SQL и шаблоны реализации, (2) выявить уязвимости SQL-инъекций, (3) проверить использование параметризованных запросов, (4) обнаружить ошибки динамической конкатенации SQL. Поддерживает три основные платформы: JDBC, MyBatis, Hibernate. **Можно декомпилировать файлы .class/.jar для извлечения логики SQL**. В сочетании с java-route-mapper он обеспечивает полную маршрутизацию + аудит SQL-инъекций.
