أداة تدقيق الثغرات الأمنية لحقن SQL لرمز Java Web المصدر. يحدد موقع كل إدخال تنفيذ SQL في التعليمات البرمجية المصدر ويكتشف عيوب الحقن. حالات الاستخدام: (1) تحديد أطر عمل تنفيذ SQL وأنماط التنفيذ، (2) الكشف عن الثغرات الأمنية في حقن SQL، (3) التحقق من استخدام الاستعلام ذي المعلمات، (4) اكتشاف أخطاء تسلسل SQL الديناميكي. يدعم الأطر الثلاثة الرئيسية: JDBC، MyBatis، Hibernate. ** يمكن فك ملفات .class/.jar لاستخراج منطق SQL **. بالاشتراك مع Java-route-mapper، فإنه يتيح التوجيه الكامل + تدقيق حقن SQL.
