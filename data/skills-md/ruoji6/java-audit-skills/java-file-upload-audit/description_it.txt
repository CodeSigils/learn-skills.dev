Strumento di controllo delle vulnerabilità per il caricamento del file del codice sorgente Web Java. Utilizzato per identificare tutti i punti di ingresso del caricamento dei file nel codice sorgente e verificare la presenza di vulnerabilità nei percorsi di caricamento, nella gestione dei nomi dei file e nella logica di convalida. Applicabile a: (1) identificare le implementazioni di caricamento Servlet/Commons FileUpload e Spring Boot MultipartFile, (2) scoprire le vulnerabilità di caricamento arbitrario di file, attraversamento del percorso e caricamento di file eseguibili, (3) verificare se la convalida di nome/directory/tipo/dimensione del file è mancante o ignorabile, (4) controllare le directory di caricamento e i controlli di accesso. **Supporta la decompilazione di file .class/.jar per estrarre la logica di caricamento**. Combinato con Java-Route-Mapper, consente il routing completo e il controllo del caricamento dei file.
