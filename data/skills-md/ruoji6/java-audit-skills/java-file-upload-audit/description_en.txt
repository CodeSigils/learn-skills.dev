Java Web source code file upload vulnerability auditing tool. It identifies all file upload entry points in the source code and checks for vulnerabilities in upload paths, file name handling, and validation logic. Suitable for: (1) detecting Servlet/Commons FileUpload and Spring Boot MultipartFile upload implementations, (2) discovering arbitrary file upload, path traversal, and executable file upload vulnerabilities, (3) verifying whether file name/directory/type/size validation is missing or bypassable, (4) auditing upload directories and access control. **Supports decompiling .class/.jar files to extract upload logic**. Combined with java-route-mapper, it enables comprehensive routing and file upload auditing.
