Tool zur Prüfung von Sicherheitslücken beim Hochladen von Java-Web-Quellcodedateien. Es identifiziert alle Datei-Upload-Einstiegspunkte im Quellcode und prüft die Upload-Pfade, die Dateinamenverarbeitung und die Validierungslogik auf Schwachstellen. Geeignet für: (1) Erkennen von Servlet/Commons FileUpload- und Spring Boot MultipartFile-Upload-Implementierungen, (2) Erkennen von Schwachstellen beim Hochladen beliebiger Dateien, beim Pfaddurchlauf und beim Hochladen ausführbarer Dateien, (3) Überprüfen, ob die Validierung von Dateiname/Verzeichnis/Typ/Größe fehlt oder umgangen werden kann, (4) Überwachen von Upload-Verzeichnissen und Zugriffskontrolle. **Unterstützt das Dekompilieren von .class/.jar-Dateien, um die Upload-Logik zu extrahieren**. In Kombination mit Java-Route-Mapper ermöglicht es eine umfassende Routing- und Datei-Upload-Prüfung.
