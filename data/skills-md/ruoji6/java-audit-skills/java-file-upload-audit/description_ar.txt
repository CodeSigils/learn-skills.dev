أداة تدقيق الثغرات الأمنية لتحميل ملفات التعليمات البرمجية المصدرية لـ Java Web. يُستخدم لتحديد جميع نقاط إدخال تحميل الملفات من التعليمات البرمجية المصدر والتحقق من مسار التحميل ومعالجة اسم الملف ومنطق التحقق من الثغرات الأمنية. مناسب لـ: (1) الكشف عن تطبيقات تحميل Servlet/Commons FileUpload وSpring Boot MultipartFile، (2) اكتشاف التحميل العشوائي للملفات، واجتياز المسار، ونقاط الضعف في تحميل الملفات القابلة للتنفيذ، (3) التحقق مما إذا كان التحقق من صحة اسم الملف/الدليل/النوع/الحجم مفقودًا أو يمكن تجاوزه، (4) تدقيق أدلة التحميل والتحكم في الوصول. ** يدعم فك ملفات .class/.jar لاستخراج منطق التحميل **. ومن خلال دمجه مع java‑route‑mapper، يمكنه تحقيق التوجيه الكامل + تدقيق تحميل الملفات.
