Outil d'audit de vulnérabilité de téléchargement de fichiers de code source Web Java. Il identifie tous les points d'entrée de téléchargement de fichiers dans le code source et vérifie les vulnérabilités dans les chemins de téléchargement, la gestion des noms de fichiers et la logique de validation. Convient pour : (1) détecter les implémentations de téléchargement de Servlet/Commons FileUpload et Spring Boot MultipartFile, (2) découvrir les vulnérabilités de téléchargement de fichiers arbitraires, de traversée de chemin et de téléchargement de fichiers exécutables, (3) vérifier si la validation du nom/répertoire/type/taille du fichier est manquante ou contournable, (4) auditer les répertoires de téléchargement et le contrôle d'accès. **Prend en charge la décompilation des fichiers .class/.jar pour extraire la logique de téléchargement**. Combiné avec Java-route-mapper, il permet un audit complet du routage et du téléchargement de fichiers.
