Инструмент аудита уязвимостей для загрузки файла исходного веб-кода Java. Он определяет все точки входа для загрузки файлов из исходного кода и проверяет наличие уязвимостей в пути загрузки, обработке имен файлов и логике проверки. Подходит для: (1) обнаружения реализаций загрузки Servlet/Commons FileUpload и Spring Boot MultipartFile, (2) поиска уязвимостей произвольной загрузки файлов, обхода путей и загрузки исполняемых файлов, (3) проверки отсутствия или обходимости проверок имени файла/каталога/типа/размера, (4) аудита каталогов загрузки и контроля доступа. **Поддерживает декомпиляцию файлов .class/.jar для извлечения логики загрузки**. В сочетании с java-route-mapper он обеспечивает комплексную маршрутизацию и аудит загрузки файлов.
