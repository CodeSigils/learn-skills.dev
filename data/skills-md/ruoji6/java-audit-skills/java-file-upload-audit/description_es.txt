Herramienta de auditoría de vulnerabilidades de carga de archivos de código fuente web Java. Se utiliza para identificar todos los puntos de entrada de carga de archivos desde el código fuente y verificar vulnerabilidades en las rutas de carga, el manejo de nombres de archivos y la lógica de validación. Adecuado para: (1) identificar implementaciones de carga de Servlet/Commons FileUpload y Spring Boot MultipartFile, (2) descubrir vulnerabilidades de carga de archivos arbitrarios, recorrido de ruta y carga de archivos ejecutables, (3) verificar si falta la validación de nombre de archivo/directorio/tipo/tamaño o se puede omitir, (4) auditar directorios de carga y control de acceso. **Admite la descompilación de archivos .class/.jar para extraer la lógica de carga**. Combinado con java-route-mapper, puede lograr una auditoría completa de enrutamiento + carga de archivos.
