Java Web ソース コード ファイルのアップロード脆弱性監査ツール。ソース コード内のすべてのファイル アップロード エントリ ポイントを識別し、アップロード パス、ファイル名の処理、および検証ロジックの脆弱性をチェックします。用途: (1) Servlet/Commons FileUpload および Spring Boot MultipartFile アップロード実装の検出、(2) 任意のファイル アップロード、パス トラバーサル、および実行可能ファイル アップロードの脆弱性の検出、(3) ファイル名/ディレクトリ/タイプ/サイズの検証が欠落しているかバイパス可能かどうかの検証、(4) アップロード ディレクトリとアクセス制御の監査。 **アップロード ロジックを抽出するための .class/.jar ファイルの逆コンパイルをサポートします**。 java-route-mapper と組み合わせると、包括的なルーティングとファイル アップロードの監査が可能になります。
