Java Web-Full-Link-Pipeline für automatisierte Sicherheitsüberprüfungen. Verwendet ein Agententeam, um mehrere Prüffähigkeiten zu orchestrieren und automatisch Routenextraktion → Autorisierungsprüfung → Komponentenschwachstelle → Kreuzfilterung → Anrufkettenverfolgung → detaillierte Schwachstellenerkennung → Qualitätsvalidierung durchzuführen. Geeignet für: (1) vollständige Sicherheitsprüfung eines Java-Projekts mit einem Klick, (2) automatische Identifizierung von Hochrisikorouten ohne Autorisierung und genaue Erkennung von Schwachstellen, (3) präzise Schwachstellenprüfung auf Call-Chain-Basis (Reduzierung von Fehlalarmen), (4) automatische Validierung der Ausgabequalität jedes Schritts. Benutzer müssen nur Quellcode und Ausgabepfade angeben.
