Java 웹 전체 링크 자동화 보안 감사 파이프라인. 에이전트 팀을 사용하여 여러 감사 기술을 조율하고 경로 추출 → 권한 부여 감사 → 구성 요소 취약성 → 교차 필터링 → 호출 체인 추적 → 심층 취약성 감지 → 품질 검증을 자동으로 수행합니다. 적합: (1) Java 프로젝트의 원클릭 전체 보안 감사, (2) 인증 없이 고위험 경로를 자동으로 식별하고 취약점을 정확하게 탐지, (3) 콜 체인 기반 정밀 취약점 감사(오탐 감소), (4) 각 단계의 출력 품질을 자동으로 검증합니다. 사용자는 소스 코드와 출력 경로만 제공하면 됩니다.
