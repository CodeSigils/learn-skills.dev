Java Web full-link automated security auditing pipeline. Uses an agent team to orchestrate multiple audit skills, automatically performing route extraction → authorization audit →component vulnerability → cross-filtering → call-chain tracing → in-depth vulnerability detection → quality validation. Suitable for: (1) one-click full security audit of a Java project, ( (2) automatically identifying high-risk routes without authorization and accurately detecting vulnerabilities, (3) call-chain-based precise vulnerability auditing (reducing false positives), (4) automatically validating the output quality of each step. Users need only provide source code and output paths.
