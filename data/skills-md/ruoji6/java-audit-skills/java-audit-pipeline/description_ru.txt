Полноканальный автоматизированный конвейер аудита безопасности Java Web. Использует команду агентов для координации нескольких навыков аудита, автоматически выполняя извлечение маршрутов → аудит авторизации → уязвимости компонентов → перекрестную фильтрацию → отслеживание цепочки вызовов → углубленное обнаружение уязвимостей → проверку качества. Подходит для: (1) полного аудита безопасности Java-проекта в один клик, (2) автоматического определения маршрутов высокого риска без авторизации и точного обнаружения уязвимостей, (3) точного аудита уязвимостей на основе цепочки вызовов (сокращение количества ложных срабатываний), (4) автоматической проверки качества выходных данных каждого шага. Пользователям нужно только предоставить исходный код и пути вывода.
