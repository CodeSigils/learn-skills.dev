Pipeline d’audit de sécurité automatisé à lien complet Java Web. Utilise une équipe d'agents pour orchestrer plusieurs compétences d'audit, en effectuant automatiquement l'extraction d'itinéraire → audit d'autorisation → vulnérabilité des composants → filtrage croisé → traçage de la chaîne d'appels → détection approfondie des vulnérabilités → validation de la qualité. Convient pour : (1) un audit de sécurité complet en un clic d'un projet Java, ( (2) l'identification automatique des itinéraires à haut risque sans autorisation et la détection précise des vulnérabilités, (3) un audit précis des vulnérabilités basé sur la chaîne d'appels (réduction des faux positifs), (4) la validation automatique de la qualité de sortie de chaque étape. Les utilisateurs n'ont qu'à fournir le code source et les chemins de sortie.
