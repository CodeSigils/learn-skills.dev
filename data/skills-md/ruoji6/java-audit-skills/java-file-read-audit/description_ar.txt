Java Web Source Code ملف تعسفي لقراءة أداة تدقيق الثغرات الأمنية. يحدد جميع عمليات قراءة الملفات من التعليمات البرمجية المصدر ويكتشف الثغرات الأمنية في اجتياز المسار. مناسب لـ: (1) تحديد أطر عمل قراءة الملفات وتطبيقاتها، ((2) اكتشاف الثغرات الأمنية في قراءة الملفات التعسفية، (3) اكتشاف عيوب اجتياز المسار، (4) تدقيق التحقق من صحة معلمات مسار الملف. يدعم BufferedReader، وScanner، وFiles.lines/readAllLines/readAllBytes، والمزيد. **يدعم فك ملفات .class/.jar لاستخراج منطق تشغيل الملف**. مدمج مع Java-route-mapper، يكمل المسار الكامل + تدقيق قراءة الملف.
