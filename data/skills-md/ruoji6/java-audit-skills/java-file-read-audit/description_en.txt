Java Web source code arbitrary file read vulnerability auditing tool. Identifies all file read operations from source code and detects path-traversal vulnerabilities. Suitable for: (1) identifying file-read frameworks and implementations, ((2) discovering arbitrary file read vulnerabilities, (3) detecting path-traver­sal flaws, (4) auditing file-path parameter validation. Supports BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes, and more. **Supports decompiling .class/.jar files to extract file-operation logic**. Combined with java-route-mapper, completes full route + file-read audit.
