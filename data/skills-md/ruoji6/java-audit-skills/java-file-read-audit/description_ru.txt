Инструмент аудита уязвимостей для чтения произвольных файлов с исходным кодом Java Web. Идентифицирует все операции чтения файлов из исходного кода и обнаруживает уязвимости обхода путей. Подходит для: (1) выявления инфраструктур и реализаций чтения файлов, (2) обнаружения уязвимостей чтения произвольных файлов, (3) обнаружения ошибок обхода пути, (4) аудита проверки параметров пути к файлу. Поддерживает BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes и т. д. **Поддерживает декомпиляцию файлов .class/.jar для извлечения логики работы с файлами**. Комбинировано с помощью java-route-mapper завершает полный аудит маршрута + чтения файлов.
