Java Webソースコード任意ファイル読み取り脆弱性監査ツール。ソース コードからすべてのファイル読み取り操作を識別し、パス トラバーサルの脆弱性を検出します。用途: (1) ファイル読み取りフレームワークと実装の特定、(2) 任意のファイル読み取り脆弱性の発見、(3) パストラバーサルの欠陥の検出、(4) ファイルパスパラメータ検証の監査。BufferedReader、Scanner、Files.lines/readAllLines/readAllBytes などをサポート。 **ファイル操作ロジックを抽出するための .class/.jar ファイルの逆コンパイルをサポート**。 java-route-mapper を使用すると、完全なルート + ファイル読み取り監査が完了します。
