Schwachstellenprüfungstool für das Lesen beliebiger Dateien im Java-Web-Quellcode. Identifiziert alle Dateilesevorgänge aus dem Quellcode und erkennt Path-Traversal-Schwachstellen. Geeignet für: (1) Identifizieren von Datei-Lese-Frameworks und -Implementierungen, ((2) Erkennen beliebiger Datei-Lese-Schwachstellen, (3) Erkennen von Path-Traversal-Fehlern, (4) Überwachen der Dateipfad-Parametervalidierung. Unterstützt BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes und mehr. **Unterstützt die Dekompilierung von .class/.jar-Dateien, um Dateioperationslogik zu extrahieren**. Kombiniert mit Java-Route-Mapper, Schließt die vollständige Routen- und Dateileseprüfung ab.
