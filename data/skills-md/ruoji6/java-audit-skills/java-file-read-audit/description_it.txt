Strumento di controllo delle vulnerabilità di lettura del file arbitrario del codice sorgente Web Java. Identifica tutte le operazioni di lettura dei file dal codice sorgente e rileva le vulnerabilità di attraversamento del percorso. Adatto per: (1) identificare framework e implementazioni di lettura di file, (2) scoprire vulnerabilità di lettura di file arbitrarie, (3) rilevare difetti di attraversamento del percorso, (4) controllare la convalida dei parametri del percorso di file. Supporta BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes e altro. **Supporta la decompilazione di file .class/.jar per estrarre la logica delle operazioni sui file**. Combinato con java-route-mapper, completa il percorso completo + controllo della lettura del file.
