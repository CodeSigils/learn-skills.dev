Outil d'audit de vulnérabilité de lecture de fichiers arbitraires de code source Web Java. Identifie toutes les opérations de lecture de fichiers à partir du code source et détecte les vulnérabilités de parcours. Convient pour : (1) l'identification des cadres et des implémentations de lecture de fichiers, ((2) la découverte de vulnérabilités de lecture de fichiers arbitraires, (3) la détection des défauts de cheminement, (4) l'audit de la validation des paramètres de chemin de fichier. Prend en charge BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes, et plus encore. **Prend en charge la décompilation des fichiers .class/.jar pour extraire la logique d'opération de fichier**. Combiné avec java-route-mapper, complète itinéraire complet + audit de lecture de fichier.
