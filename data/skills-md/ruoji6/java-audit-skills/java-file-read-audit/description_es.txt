Herramienta de auditoría de vulnerabilidades de lectura de archivos arbitrarios de código fuente web Java. Identifica todas las operaciones de lectura de archivos desde el código fuente y detecta vulnerabilidades de recorrido de ruta. Adecuado para: (1) identificar marcos e implementaciones de lectura de archivos, (2) descubrir vulnerabilidades de lectura de archivos arbitrarios, (3) detectar fallas de recorrido de ruta, (4) auditar la validación de parámetros de ruta de archivo. Admite BufferedReader, Scanner, Files.lines/readAllLines/readAllBytes y más. **Admite la descompilación de archivos .class/.jar para extraer la lógica de operación de archivos**. Combinado con java-route-mapper, completa la ruta completa + auditoría de lectura de archivos.
