Java Web source code multi-level call-chain tracking tool. Given a user-specified route path, it traces the complete invocation chain from Controller/Action down to the DAO layer, outputting the file location, method signature and passable parameters for every level. Suitable for parameter-flow tracking of multiple vulnerability types: (1) SQL injection – trace parameters to SQL concatenation points, (2) command injection – trace parameters to Runtime.exec(), (3) SSRF – trace parameters to HTTP requests, (4) XSS – trace parameters to response output, (5) file operations – trace parameters to File operations, (6) XXE/deserialization/LDAP injection/expression injection, etc. Supports Spring MVC, Struts 2, Servlet, JAX-RS and other frameworks. **Supports decompiling .class/.jar files to extract call chains**. Combined with java-route-mapper it enables complete route + call-chain auditing.
