Outil de suivi de la chaîne d'appels à plusieurs niveaux du code source Web Java. Étant donné un chemin de route spécifié par l'utilisateur, il retrace la chaîne d'invocation complète depuis le contrôleur/action jusqu'à la couche DAO, en affichant l'emplacement du fichier, la signature de la méthode et les paramètres passables pour chaque niveau. Convient au suivi du flux de paramètres de plusieurs types de vulnérabilités : (1) injection SQL – tracer les paramètres vers des points de concaténation SQL, (2) injection de commandes – tracer les paramètres vers Runtime.exec(), (3) SSRF – tracer les paramètres vers les requêtes HTTP, (4) XSS – tracer les paramètres vers la sortie de réponse, (5) opérations de fichier – tracer les paramètres vers les opérations de fichier, (6) XXE/désérialisation/injection LDAP/injection d'expression, etc. Prend en charge Spring MVC, Struts 2, Servlet, JAX-RS et autres frameworks. **Prend en charge la décompilation des fichiers .class/.jar pour extraire les chaînes d'appel**. Combiné avec Java-route-mapper, il permet un audit complet de l'itinéraire + de la chaîne d'appels.
