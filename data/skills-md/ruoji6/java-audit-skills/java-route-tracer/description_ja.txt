Java Web ソース コードのマルチレベル コール チェーン追跡ツール。ユーザー指定のルート パスを指定すると、コントローラー/アクションから DAO レイヤーまでの完全な呼び出しチェーンをトレースし、ファイルの場所、メソッドの署名、およびレベルごとに渡せるパラメーターを出力します。複数の脆弱性タイプのパラメータ フロー追跡に適しています: (1) SQL インジェクション – SQL 連結ポイントまでパラメータをトレース、(2) コマンド インジェクション – Runtime.exec() までパラメータをトレース、(3) SSRF – HTTP リクエストまでパラメータをトレース、(4) XSS – 応答出力までパラメータをトレース、(5) ファイル操作 – ファイル操作までパラメータをトレース、(6) XXE/デシリアライゼーション/LDAP インジェクション/式インジェクションなど。 Spring MVC、Struts をサポート2、サーブレット、JAX-RS、その他のフレームワーク。 **呼び出しチェーンを抽出するための .class/.jar ファイルの逆コンパイルをサポートします**。 java-route-mapper と組み合わせると、完全なルートとコールチェーンの監査が可能になります。
