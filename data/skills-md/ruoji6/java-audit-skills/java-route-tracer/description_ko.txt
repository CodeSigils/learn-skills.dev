Java 웹 소스 코드 다단계 호출 체인 추적 도구입니다. 사용자가 지정한 경로 경로가 주어지면 컨트롤러/작업에서 DAO 계층까지 전체 호출 체인을 추적하여 모든 수준에 대해 파일 위치, 메서드 서명 및 통과 가능한 매개 변수를 출력합니다. 여러 취약점 유형의 매개변수 흐름 추적에 적합합니다. (1) SQL 주입 – SQL 연결 지점까지 매개변수 추적, (2) 명령 주입 – Runtime.exec()까지 매개변수 추적, (3) SSRF – HTTP 요청에 대한 매개변수 추적, (4) XSS – 응답 출력까지 매개변수 추적, (5) 파일 작업 – 파일 작업에 대한 매개변수 추적, (6) XXE/역직렬화/LDAP 주입/표현 주입 등. Spring MVC, Struts 2, Servlet을 지원합니다. JAX-RS 및 기타 프레임워크. **콜 체인 추출을 위해 .class/.jar 파일 디컴파일을 지원합니다**. java-route-mapper와 결합하면 완전한 경로 + 호출 체인 감사가 가능합니다.
