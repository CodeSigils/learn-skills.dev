Многоуровневый инструмент отслеживания цепочки вызовов с исходным кодом Java Web. Учитывая заданный пользователем путь маршрута, он отслеживает полную цепочку вызовов от контроллера/действия до уровня DAO, выводя местоположение файла, сигнатуру метода и проходимые параметры для каждого уровня. Подходит для отслеживания потока параметров нескольких типов уязвимостей: (1) SQL-инъекция — трассировка параметров в точки конкатенации SQL, (2) внедрение команд — трассировка параметров в Runtime.exec(), (3) SSRF — трассировка параметров для HTTP-запросов, (4) XSS — трассировка параметров для вывода ответа, (5) файловые операции — трассировка параметров для файловых операций, (6) XXE/десериализация/внедрение LDAP/выражение и т. д. Поддерживает Spring MVC, Struts 2, Servlet, JAX-RS и другие платформы. **Поддерживает декомпиляцию файлов .class/.jar для извлечения цепочек вызовов**. В сочетании с java-route-mapper он обеспечивает полный аудит маршрута + цепочки вызовов.
