Strumento di monitoraggio della catena di chiamate multilivello del codice sorgente Web Java. Dato un percorso di instradamento specificato dall'utente, traccia la catena di chiamata completa da Controller/Azione fino al livello DAO, emettendo la posizione del file, la firma del metodo e i parametri passabili per ogni livello. Adatto per il tracciamento del flusso di parametri di più tipi di vulnerabilità: (1) SQL injection – traccia parametri su punti di concatenazione SQL, (2) command injection – traccia parametri su Runtime.exec(), (3) SSRF – traccia parametri su richieste HTTP, (4) XSS – traccia parametri sull'output della risposta, (5) operazioni su file – traccia parametri su operazioni file, (6) XXE/deserializzazione/LDAP injection/expression injection, ecc. Supporta Spring MVC, Struts 2, Servlet, JAX-RS e altri framework. **Supporta la decompilazione di file .class/.jar per estrarre catene di chiamate**. Combinato con Java-Route-Mapper consente il controllo completo del percorso e della catena di chiamate.
