أداة تتبع سلسلة الاتصال متعددة المستويات لشفرة مصدر الويب Java. نظرًا لمسار المسار المحدد من قبل المستخدم، فإنه يتتبع سلسلة الاستدعاء الكاملة من وحدة التحكم/الإجراء وصولاً إلى طبقة DAO، ويخرج موقع الملف وتوقيع الطريقة والمعلمات المقبولة لكل مستوى. مناسب لتتبع تدفق المعلمات لأنواع متعددة من الثغرات الأمنية: (1) حقن SQL - تتبع المعلمات إلى نقاط تسلسل SQL، (2) إدخال الأوامر - تتبع المعلمات إلى Runtime.exec()، (3) SSRF - تتبع المعلمات لطلبات HTTP، (4) XSS - معلمات التتبع لمخرجات الاستجابة، (5) عمليات الملف - تتبع المعلمات إلى عمليات الملف، (6) XXE/إلغاء التسلسل/حقن LDAP/حقن التعبير، وما إلى ذلك. يدعم Spring MVC، وStruts 2، وServlet، JAX-RS وأطر أخرى. ** يدعم فك ملفات .class/.jar لاستخراج سلاسل الاتصال **. بالاشتراك مع Java-route-mapper، فإنه يتيح تدقيق المسار الكامل + سلسلة الاتصال.
