Herramienta de seguimiento de cadena de llamadas multinivel con código fuente web Java. Dada una ruta de ruta especificada por el usuario, rastrea la cadena de invocación completa desde el Controlador/Acción hasta la capa DAO, generando la ubicación del archivo, la firma del método y los parámetros aceptables para cada nivel. Adecuado para el seguimiento del flujo de parámetros de múltiples tipos de vulnerabilidad: (1) inyección de SQL: parámetros de seguimiento a puntos de concatenación de SQL, (2) inyección de comandos: parámetros de seguimiento a Runtime.exec(), (3) SSRF: parámetros de seguimiento a solicitudes HTTP, (4) XSS: parámetros de seguimiento a la salida de respuesta, (5) operaciones de archivos: parámetros de seguimiento a operaciones de archivos, (6) XXE/deserialización/inyección LDAP/inyección de expresión, etc. Soporta Spring MVC, Struts 2, Servlet, JAX-RS y otros marcos. **Admite la descompilación de archivos .class/.jar para extraer cadenas de llamadas**. Combinado con java-route-mapper, permite una auditoría completa de ruta + cadena de llamadas.
