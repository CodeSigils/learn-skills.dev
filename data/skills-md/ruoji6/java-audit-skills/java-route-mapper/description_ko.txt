Java 웹 소스 코드 경로 및 매개변수 매핑 분석 도구. 소스 코드에서 **모든** HTTP 경로와 매개변수를 추출하고, 완전한 Burp Suite 요청 템플릿을 생성하고, 자동으로 MD 문서로 저장합니다. 다음에 적합합니다: (1) API 문서 없이 프로젝트의 완전한 인터페이스 매핑, (2) 모든 인터페이스에 대한 Burp 테스트 요청 생성, (3) 소스 코드의 전체 엔드포인트 분석. Spring MVC, Servlet, JAX-RS, Struts 2, CXF 웹 서비스 등을 포함한 프레임워크를 지원합니다. **웹 서비스의 전체 SOAP 메소드를 포함하여 모든 인터페이스를 아무것도 생략하지 않고 출력해야 합니다**.
