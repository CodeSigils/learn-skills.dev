Analysetool für Java-Web-Quellcoderoute und Parameterzuordnung. Extrahiert **alle** HTTP-Routen und Parameter aus dem Quellcode, generiert vollständige Burp Suite-Anfragevorlagen und speichert sie automatisch als MD-Dokumente. Geeignet für: (1) vollständige Schnittstellenzuordnung von Projekten ohne API-Dokumentation, (2) Generierung von Burp-Testanfragen für alle Schnittstellen, (3) vollständige Endpunktanalyse des Quellcodes. Unterstützt Frameworks wie Spring MVC, Servlet, JAX-RS, Struts 2, CXF Web Services usw. **Muss alle Schnittstellen ausgeben, ohne etwas auszulassen, einschließlich vollständiger SOAP-Methoden von Web Services**.
