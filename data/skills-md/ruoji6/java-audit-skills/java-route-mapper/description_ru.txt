Инструмент анализа маршрутов веб-исходного кода Java и сопоставления параметров. Извлекает **все** HTTP-маршруты и параметры из исходного кода, генерирует полные шаблоны запросов Burp Suite и автоматически сохраняет их как документы MD. Подходит для: (1) полного сопоставления интерфейсов проектов без документации API, (2) генерации запросов тестирования Burp для всех интерфейсов, (3) полного анализа конечных точек исходного кода. Поддерживает такие платформы, как Spring MVC, Servlet, JAX-RS, Struts 2, веб-службы CXF и т. д. **Необходимо выводить все интерфейсы, ничего не пропуская, включая полные методы SOAP веб-служб**.
