Outil d'analyse de l'itinéraire du code source Web Java et du mappage des paramètres. Extrait **tous** les itinéraires et paramètres HTTP du code source, génère des modèles de requête Burp Suite complets et les enregistre automatiquement en tant que documents MD. Convient pour : (1) le mappage complet des interfaces de projets sans documentation API, (2) la génération de requêtes de test Burp pour toutes les interfaces, (3) l'analyse complète des points finaux du code source. Prend en charge les frameworks tels que Spring MVC, Servlet, JAX-RS, Struts 2, CXF Web Services, etc. **Doit afficher toutes les interfaces sans rien omettre, y compris les méthodes SOAP complètes des services Web**.
