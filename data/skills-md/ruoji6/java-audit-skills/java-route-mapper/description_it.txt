Strumento di analisi del percorso del codice sorgente Web Java e della mappatura dei parametri. Estrae **tutti** i percorsi e i parametri HTTP dal codice sorgente, genera modelli di richiesta Burp Suite completi e li salva automaticamente come documenti MD. Adatto per: (1) mappatura completa dell'interfaccia di progetti senza documentazione API, (2) generazione di richieste di test Burp per tutte le interfacce, (3) analisi completa dell'endpoint del codice sorgente. Supporta framework tra cui Spring MVC, Servlet, JAX-RS, Struts 2, CXF Web Services, ecc. **Deve restituire tutte le interfacce senza omettere nulla, inclusi i metodi SOAP completi dei servizi Web**.
