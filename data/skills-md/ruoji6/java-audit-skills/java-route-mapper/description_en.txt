Java Web Source Code Route and Parameter Mapping Analysis Tool. Extracts **all** HTTP routes and parameters from source code, generates complete Burp Suite request templates, and automatically saves them as MD documents. Suitable for: (1) complete interface mapping of projects without API documentation, (2) generating Burp test requests for all interfaces, (3) full endpoint analysis of source code. Supports frameworks including Spring MVC, Servlet, JAX-RS, Struts 2, CXF Web Services, etc. **Must output all interfaces without omitting anything, including full SOAP methods of Web Services**.
