Herramienta de análisis de mapeo de parámetros y rutas de código fuente web Java. Extrae **todas** las rutas y parámetros HTTP del código fuente, genera plantillas de solicitud completas de Burp Suite y las guarda automáticamente como documentos MD. Adecuado para: (1) mapeo completo de interfaces de proyectos sin documentación API, (2) generar solicitudes de prueba Burp para todas las interfaces, (3) análisis completo de puntos finales del código fuente. Admite marcos que incluyen Spring MVC, Servlet, JAX-RS, Struts 2, CXF Web Services, etc. **Debe generar todas las interfaces sin omitir nada, incluidos los métodos SOAP completos de los servicios web**.
