Java Web Source Code Route وأداة تحليل تعيين المعلمات. يستخرج **جميع** مسارات HTTP ومعلماته من التعليمات البرمجية المصدر، وينشئ قوالب طلب Burp Suite كاملة، ويحفظها تلقائيًا كمستندات MD. مناسب لـ: (1) رسم خرائط واجهة كاملة للمشاريع بدون وثائق واجهة برمجة التطبيقات (API)، (2) إنشاء طلبات اختبار Burp لجميع الواجهات، (3) تحليل كامل لنقطة النهاية لكود المصدر. يدعم أطر العمل بما في ذلك Spring MVC، وServlet، وJAX-RS، وStruts 2، وCXF Web Services، وما إلى ذلك. **يجب إخراج جميع الواجهات دون حذف أي شيء، بما في ذلك أساليب SOAP الكاملة لخدمات الويب**.
