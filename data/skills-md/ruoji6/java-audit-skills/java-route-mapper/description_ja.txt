Java Web ソース コード ルートおよびパラメータ マッピング分析ツール。 **すべて** HTTP ルートとパラメータをソース コードから抽出し、完全な Burp Suite リクエスト テンプレートを生成し、それらを MD ドキュメントとして自動的に保存します。以下に適しています: (1) API ドキュメントなしでプロジェクトの完全なインターフェイス マッピング、(2) すべてのインターフェイスに対する Burp テスト リクエストの生成、(3) ソース コードの完全なエンドポイント分析。 Spring MVC、Servlet、JAX-RS、Struts 2、CXF Web Services などのフレームワークをサポートします。 **Web サービスの完全な SOAP メソッドを含む、すべてのインターフェイスを省略せずに出力する必要があります**。
