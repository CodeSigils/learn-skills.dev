Интерфейс командной строки запроса журнала Kibana для агентов AI, который ищет и объединяет журналы ELK через прокси-сервер Kibana Console. Триггеры для Kibana, ELK, поиска по журналам, агрегирования журналов, поиска идентификаторов трассировки, обнаружения полей шаблонов индексов, переключения многосистемного контекста и диагностики Kibana.
