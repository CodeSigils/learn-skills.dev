Cuenta CLIProxyAPI y CLI de protección de cuotas del Codex para agentes de IA. Úselo para guardar o borrar de forma segura una sesión de administración, enumerar registros de autenticación, inspeccionar la asignación de Codex/ChatGPT, habilitar o deshabilitar de manera segura un registro, ejecutar un pase de protección de cuotas de solo observación, llamar a una ruta de API de administración relativa o actualizar la CLI y la habilidad incluida. Activar la API de administración CLIProxyAPI, inicio/cierre de sesión, archivo de autenticación, agotamiento de cuota, cambios de estado de cuenta, evaluación de protección de cuota o avisos de actualización de cliproxyapi-cli.
