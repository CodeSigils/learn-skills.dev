L'account CLIProxyAPI e la CLI di protezione delle quote Codex per gli agenti AI. Utilizzare per salvare o cancellare in modo sicuro una sessione di gestione, elencare i record di autenticazione, ispezionare la quota Codex/ChatGPT, abilitare o disabilitare in modo sicuro un record, eseguire un passaggio di protezione quota di sola osservazione, chiamare un percorso API di gestione relativo o aggiornare la CLI e la competenza in bundle. Attivazione su API di gestione CLIProxyAPI, accesso/disconnessione, file di autenticazione, esaurimento quota, modifiche dello stato dell'account, valutazione della protezione della quota o avvisi di aggiornamento cliproxyapi-cli.
