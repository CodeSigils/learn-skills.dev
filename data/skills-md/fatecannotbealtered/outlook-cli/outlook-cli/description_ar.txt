Outlook Exchange CLI للبريد الإلكتروني والتقويم والمجلدات والقواعد وجهات الاتصال والغرف وOOF واستجابات الاجتماعات والتشخيصات والتحديث الذاتي؛ يُستخدم عندما تشير المهام إلى Outlook أو Exchange أو البريد أو البريد الوارد أو التقويم أو الاجتماعات أو التوفر أو الغرف أو المجلدات أو القواعد أو الرد التلقائي.
