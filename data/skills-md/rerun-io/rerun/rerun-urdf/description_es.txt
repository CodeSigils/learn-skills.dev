Controle la API Rerun URDF (rerun.urdf.UrdfTree) para ingerir un URDF como una capa Transform3D en una grabación de robot. Léalo cuando registre un modelo de robot, ejecute cinemática directa desde estados conjuntos, componga una cadena fija para sensores extrínsecos o cuando el árbol de transformación no se conecte solo a partir de los datos. Se basa en el procesamiento de fragmentos de repetición (mecánica de flujo/lente) y el modelo de datos de repetición (rutas de entidad, línea de tiempo, base versus capa).
