Основная механика API обработки Rerun Chunk (rerun.experimental) — конвейеры LazyChunkStream, Chunk, линзы (MutateLens/DeriveLens/Selector), RrdReader, запись оптимизированных RRD. Прочтите ПЕРЕД написанием любого кода приема/преобразования/предобработки (преобразование MCAP, построение записи из набора данных, предварительная обработка .rrd, перенос старого конвертера): он требует использования конвейеров чтения + линзы и избегает созданных вручную фрагментов - нет Chunk.from_columns для данных, которые может генерировать считыватель/линза, нет rr.log для каждого сообщения, нет ручной сборки pa.array. Знания, специфичные для источника, содержатся в навыках импортера (rerun-mcap, rerun-urdf, rerun-parquet, rerun-lerobot); сначала прочитайте rerun-data-model, чтобы решить, какими должны стать данные.
