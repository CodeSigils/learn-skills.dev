Rerun Chunk Processing API (rerun.experimental) の中核的な仕組み — LazyChunkStream パイプライン、チャンク、レンズ (MutateLens/DeriveLens/Selector)、RrdReader、最適化された RRD の作成。取り込み/変換/前処理コード (MCAP の変換、データセットからの記録の構築、.rrd の前処理、古いコンバーターの移植) を作成する前にお読みください。リーダーとレンズのパイプラインが義務付けられ、手作りのチャンクから遠ざけられます。リーダー/レンズが生成できるデータの Chunk.from_columns はなく、メッセージごとの rr.log、手動の pa.array アセンブリはありません。ソース固有の知識はインポーター スキル (rerun-mcap、rerun-urdf、rerun-parquet、rerun-lerobot) に組み込まれています。最初に rerun-data-model を読み取って、データがどうなるかを決定します。
