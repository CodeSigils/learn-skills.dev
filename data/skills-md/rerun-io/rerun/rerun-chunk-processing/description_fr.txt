Mécanismes de base de l'API Rerun Chunk Processing (rerun.experimental) — pipelines LazyChunkStream, Chunk, lentilles (MutateLens/DeriveLens/Selector), RrdReader, écriture de RRD optimisés. Lisez AVANT d'écrire un code d'ingestion/conversion/prétraitement (convertir un MCAP, créer un enregistrement à partir d'un ensemble de données, prétraiter un .rrd, porter un ancien convertisseur) : il impose des pipelines lecteur + objectif et évite les morceaux construits à la main - pas de Chunk.from_columns pour les données qu'un lecteur/objectif peut produire, pas de rr.log par message, pas d'assemblage pa.array manuel. Les connaissances spécifiques à la source résident dans les compétences de l'importateur (rerun-mcap, rerun-urdf, rerun-parquet, rerun-lerobot) ; lisez d'abord rerun-data-model pour décider ce que doivent devenir les données.
