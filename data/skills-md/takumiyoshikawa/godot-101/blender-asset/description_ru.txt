Генерируйте 3D-ресурсы `.glb` без головы с помощью Blender Python (`blender --background --python`). Используйте, когда проекту Godot/Unity/Unreal требуется процедурная сетка/реквизит/кусок комнаты. Skill предоставляет только тонкие помощники (prelude.py,export.py); Сценарии генерации для конкретного проекта находятся в `assets/modeling/`. Не используйте для живого редактирования Blender или создания персонажей-героев.
