أنشئ نموذجًا أوليًا للواجهة الأمامية يعتمد على الأسئلة وقابل للاختبار بواسطة المتصفح باستخدام ملف Index.html واحد وأصول نقطية تم تنزيلها محليًا. يُستخدم عند تحويل فكرة المنتج أو التطبيق الحالي أو المستودع أو لقطة الشاشة أو عنوان URL المباشر إلى صفحة مقصودة أو نموذج أولي لواجهة المستخدم قبل تنفيذ الإنتاج. افحص حقيقة المنتج، واطرح أسئلة محددة حول المدخل، وابحث وحدد اتجاه DESIGN.md المناسب، وحدد كيفية استخدام لقطات الشاشة الحقيقية، أو الصور الفوتوغرافية، أو الصور التي تم إنشاؤها، أو الرسوم التوضيحية، ثم قم بإنشاء ملف Index.html، وDESIGN.md، وملف Makefile، وأي أصول مطلوبة، وتحقق من النتيجة على عرض سطح المكتب والهاتف المحمول. لا تستخدمه في هندسة تطبيقات الإنتاج أو العمل الخلفي أو الاستنساخ المثالي للبكسل.
