Erstellen Sie einen fragengesteuerten, browsertestbaren Frontend-Prototyp mit einer einzigen index.html und lokal heruntergeladenen Raster-Assets. Verwenden Sie diese Option, wenn Sie eine Produktidee, eine vorhandene App, ein Repository, einen Screenshot oder eine Live-URL vor der Produktionsimplementierung in eine Zielseite oder einen UI-Prototyp umwandeln. Prüfen Sie die Produktwahrheit, stellen Sie konkrete Eingangsfragen, recherchieren und wählen Sie eine geeignete DESIGN.md-Richtung aus, entscheiden Sie, wie echte Screenshots, Fotos, generierte Bilder oder Illustrationen verwendet werden sollen, erstellen Sie dann index.html, DESIGN.md, ein Makefile und alle erforderlichen Assets und überprüfen Sie das Ergebnis auf Desktop- und Mobilgeräten. Nicht für Produktionsanwendungsarchitekturen, Backend-Arbeiten oder pixelgenaues Klonen verwenden.
