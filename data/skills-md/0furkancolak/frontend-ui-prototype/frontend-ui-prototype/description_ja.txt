単一のindex.htmlとローカルにダウンロードしたラスターアセットを使用して、質問主導型でブラウザーでテスト可能なフロントエンドプロトタイプを構築します。製品のアイデア、既存のアプリ、リポジトリ、スクリーンショット、またはライブ URL を、運用環境の実装前にランディング ページまたは UI プロトタイプに変換するときに使用します。製品の真実を検査し、具体的な質問をし、適切な DESIGN.md の方向性を調査して選択し、実際のスクリーンショット、写真、生成された画像、またはイラストをどのように使用するかを決定し、index.html、DESIGN.md、Makefile、および必要なアセットを作成し、デスクトップとモバイルの幅で結果を検証します。運用アプリケーションのアーキテクチャ、バックエンド作業、またはピクセルパーフェクトなクローン作成には使用しないでください。
