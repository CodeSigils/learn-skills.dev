Ограждения безопасности, предупреждающие о разрушительных командах. Используйте для защиты новичков от случайного выполнения опасных операций, таких как rm -rf, DROP TABLE, git push --force или git reset --hard. Предоставляет доступные для начинающих объяснения того, ПОЧЕМУ команда опасна, и предлагает более безопасные альтернативы. Активируйте, когда пользователь упоминает безопасность, осторожный режим, ограждения, защиту или когда работает с новичками над задачами, связанными с удалением файлов, изменением базы данных или операциями git.
