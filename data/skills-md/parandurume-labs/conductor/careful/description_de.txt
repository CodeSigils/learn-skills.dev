Sicherheitsleitplanken, die vor zerstörerischen Befehlen warnen. Wird verwendet, um Anfänger davor zu schützen, versehentlich gefährliche Operationen wie rm -rf, DROP TABLE, git push --force oder git reset --hard auszuführen. Bietet anfängerfreundliche Erklärungen, WARUM ein Befehl gefährlich ist, und schlägt sicherere Alternativen vor. Aktivieren Sie diese Option, wenn der Benutzer Sicherheit, Vorsichtsmodus, Leitplanken oder Schutz erwähnt oder wenn er mit Anfängern an Aufgaben arbeitet, die das Löschen von Dateien, Datenbankänderungen oder Git-Vorgänge umfassen.
