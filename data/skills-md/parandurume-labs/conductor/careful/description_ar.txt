حواجز السلامة التي تحذر قبل الأوامر التدميرية. يُستخدم لحماية المبتدئين من تشغيل العمليات الخطيرة عن طريق الخطأ مثل rm -rf أو DROP TABLE أو git Push --force أو gitset --hard. يوفر تفسيرات سهلة للمبتدئين حول سبب خطورة الأمر ويقترح بدائل أكثر أمانًا. يتم التنشيط عندما يذكر المستخدم الأمان، أو الوضع الحذر، أو حواجز الحماية، أو الحماية، أو عند العمل مع مبتدئين في مهام تتضمن حذف ملف، أو تغيير قاعدة البيانات، أو عمليات git.
