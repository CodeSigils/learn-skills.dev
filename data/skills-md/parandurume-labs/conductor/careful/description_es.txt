Barandillas de seguridad que avisan ante órdenes destructivas. Úselo para proteger a los principiantes de ejecutar accidentalmente operaciones peligrosas como rm -rf, DROP TABLE, git push --force o git reset --hard. Proporciona explicaciones para principiantes de POR QUÉ un comando es peligroso y sugiere alternativas más seguras. Actívelo cuando el usuario mencione seguridad, modo cuidadoso, barreras de seguridad, protección o cuando trabaje con principiantes en tareas que impliquen eliminación de archivos, cambios en bases de datos u operaciones de git.
