بنية سحابة Azure وأفضل ممارسات النشر. يُستخدم عند إنشاء خدمات Azure أو نشرها أو تكوينها، بما في ذلك تطبيقات الحاوية وخدمة التطبيقات وAzure Functions وCosmos DB وAzure OpenAI وAI Foundry والهوية المُدارة وKey Vault وBicep وقوالب ARM واتحاد هوية عبء العمل وخدمة Azure Kubernetes. يغطي الأمن والهوية والشبكات وتحسين التكلفة والاستعداد للإنتاج. قم بالتنشيط عندما يتم ذكر Azure أو النشر السحابي أو البنية التحتية كرمز.
