Modelli di integrazione di Microsoft 365 per l'automazione di Teams, SharePoint e Outlook. Da utilizzare durante la creazione di bot di Teams, l'invio di notifiche del canale di Teams, la creazione di flussi di lavoro di documenti di SharePoint, la gestione di schede adattive, l'automazione della posta elettronica di Outlook o l'utilizzo dell'API Microsoft Graph. Copre le convenzioni del server MCP, gli ID dei siti composti, la gestione degli ID dei canali, i limiti delle dimensioni delle carte adattive e la gestione dell'ora standard coreana. Attiva ogni volta che viene menzionato Microsoft 365, Teams, SharePoint, Outlook o API Graph.
