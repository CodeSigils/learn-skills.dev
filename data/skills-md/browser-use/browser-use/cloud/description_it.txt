Riferimento alla documentazione per l'utilizzo di Browser Use Cloud: l'API ospitata e l'SDK per l'automazione del browser. Utilizza questa competenza ogni volta che l'utente ha bisogno di aiuto con Cloud REST API (v2 o v3), browser-use-sdk (Python o TypeScript), autenticazione X-Browser-Use-API-Key, sessioni cloud, profili browser, sincronizzazione dei profili, connessioni CDP WebSocket, browser invisibili, proxy residenziali, gestione CAPTCHA, webhook, aree di lavoro, marketplace delle competenze, streaming liveUrl, prezzi o modelli di integrazione (interfaccia utente chat, agente secondario, aggiunta browser strumenti agli agenti esistenti). Attiva anche domande sull'integrazione di n8n/Make/Zapier, Drammaturgo/Burattinaio/Selenium sull'infrastruttura cloud o sull'integrazione di 1Password Vault. NON utilizzarlo per la libreria Python open source (agente, browser, configurazione degli strumenti): utilizza invece la competenza open source.
