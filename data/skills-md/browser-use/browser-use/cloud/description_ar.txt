مرجع التوثيق لاستخدام Browser Use Cloud - واجهة برمجة التطبيقات المستضافة وSDK لأتمتة المتصفح. استخدم هذه المهارة عندما يحتاج المستخدم إلى مساعدة في Cloud REST API (الإصدار 2 أو الإصدار 3)، أو sdk لاستخدام المتصفح (Python أو TypeScript)، أو مصادقة X-Browser-Use-API-Key، أو الجلسات السحابية، أو ملفات تعريف المتصفح، أو مزامنة ملف التعريف، أو اتصالات CDP WebSocket، أو المتصفحات الخفية، أو الوكلاء السكنيين، أو معالجة CAPTCHA، أو خطافات الويب، أو مساحات العمل، أو سوق المهارات، أو تدفق LiveUrl، أو التسعير، أو أنماط التكامل (واجهة مستخدم الدردشة، وكيل فرعي، وإضافة أدوات المتصفح إلى الوكلاء الحاليين). يمكنك أيضًا طرح أسئلة حول تكامل n8n/Make/Zapier، أو Playwright/ Puppeteer/Selenium على البنية التحتية السحابية، أو تكامل 1Password vault. لا تستخدم هذا لمكتبة Python مفتوحة المصدر (Agent، Browser، Tools config) - استخدم مهارة مفتوحة المصدر بدلاً من ذلك.
