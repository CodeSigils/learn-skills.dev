Référence à la documentation pour l'utilisation de Browser Use Cloud : l'API et le SDK hébergés pour l'automatisation du navigateur. Utilisez cette compétence chaque fois que l'utilisateur a besoin d'aide avec l'API Cloud REST (v2 ou v3), le SDK d'utilisation du navigateur (Python ou TypeScript), l'authentification X-Browser-Use-API-Key, les sessions cloud, les profils de navigateur, la synchronisation des profils, les connexions CDP WebSocket, les navigateurs furtifs, les proxys résidentiels, la gestion des CAPTCHA, les webhooks, les espaces de travail, le marché des compétences, le streaming liveUrl, la tarification ou les modèles d'intégration (interface utilisateur de chat, sous-agent, ajout d'outils de navigateur aux agents existants). Déclenchez également des questions sur l'intégration de n8n/Make/Zapier, Playwright/Puppeteer/Selenium sur l'infrastructure cloud ou l'intégration du coffre-fort 1Password. Ne l'utilisez PAS pour la bibliothèque Python open source (configuration de l'agent, du navigateur, des outils) - utilisez plutôt la compétence open source.
