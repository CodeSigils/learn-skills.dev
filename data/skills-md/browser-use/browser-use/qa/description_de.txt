Führen Sie einen QA-Test einer Website oder Web-App durch und geben Sie einen Qualitätsfaktor von 1 bis 5 (5 = einwandfrei, 1 = fehlerhaft) mit Beweisen zurück. Verwenden Sie diese Option, wenn der Benutzer eine Website, eine Seite, einen Flow oder eine App testen, qualitätssichern, bewerten, bewerten oder „überprüfen“ möchte – einschließlich eines lokalen Entwicklungsservers (z. B. „qa test localhost:5173“, „Funktioniert der Checkout?“, „Diese Zielseite bewerten“). Steuert einen echten Browser. Verwenden Sie einen Cloud-Browser und tunneln Sie Localhost automatisch.
