Realice una prueba de control de calidad de un sitio web o una aplicación web y obtenga una puntuación de calidad de 1 a 5 (5 = impecable, 1 = rota) con evidencia. Úselo cuando el usuario quiera probar, realizar controles de calidad, evaluar, calificar o "comprobar qué tan bueno" es un sitio, una página, un flujo o una aplicación, incluido un servidor de desarrollo local (por ejemplo, "prueba de control localhost:5173", "¿funciona el pago?", "califique esta página de destino"). Maneja un navegador real. Utilice el navegador en la nube, haciendo un túnel localhost automáticamente.
