Testare il QA di un sito Web o di un'app Web e restituire un punteggio di qualità da 1 a 5 (5 = impeccabile, 1 = non funzionante) con prove. Da utilizzare quando l'utente desidera testare, eseguire il QA, valutare, assegnare un punteggio o "verificare la qualità" di un sito, di una pagina, di un flusso o di un'app, incluso un server di sviluppo locale (ad esempio "qa test localhost:5173", "funziona il checkout?", "valuta questa pagina di destinazione"). Guida un browser reale Utilizza il browser cloud, eseguendo automaticamente il tunneling dell'host locale.
