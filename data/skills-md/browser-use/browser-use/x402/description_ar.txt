قم بإعداد المتصفح استخدم المدفوعات السحابية مع x402 - ادفع لكل طلب من محفظة تشفير (USDC على الشبكة الرئيسية الأساسية)، بدون اشتراك أو مفتاح API. يتم تنفيذ إعدادين مقدمًا - "فقط استخدمها" (قم بإعداد محفظة حتى تتمكن أنت أو Claude Code من تشغيل مهام المتصفح السحابي المدفوعة من المحفظة - يكتب كلود ويدير نصوصًا برمجية سريعة، ولا يمس أي شيء قاعدة التعليمات البرمجية الخاصة بك) أو "قم بإنشائها" (قم بتثبيت SDK واكتب المفتاح + الكود في مشروعك). يستعرض إعداد المحفظة، والتمويل، و.env، واختبار التشغيل بقيمة 1 دولار تقريبًا. يُستخدم عندما يسأل المستخدم عن x402، أو الدفع لكل استخدام، أو مدفوعات USDC، أو يريد أن يستخدم المتصفح السحابة بدون مفتاح API. بالنسبة للاشتراك في الطبقة المجانية (عكس CAPTCHA → مفتاح API)، استخدم "الاشتراك السحابي باستخدام المتصفح" أو مهارة "السحابة" بدلاً من ذلك.
