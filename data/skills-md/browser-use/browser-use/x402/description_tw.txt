使用 x402 設定瀏覽器使用雲端支付 — 根據加密錢包（Base 主網路上的 USDC）的請求付費，無需註冊或 API 金鑰。它預先設定了兩個設定 - “只需使用它”（設定一個錢包，以便您或 Claude Code 可以運行從錢包支付的雲端瀏覽器任務 - Claude 編寫並運行一次性腳本，不會觸及您的程式碼庫）或「建置它」（安裝 SDK 並將金鑰 + 程式碼寫入您的專案）。逐步完成錢包設定、資金、.env 和約 1 美元的測試運行。當用戶詢問 x402、按使用付費、USDC 付款或希望在沒有 API 金鑰的情況下瀏覽器使用雲端時使用。對於免費層註冊（反向驗證碼 → API 金鑰），請改用「瀏覽器使用雲端註冊」或「雲端」技能。
