Configure pagos en la nube con uso del navegador con x402: pago por solicitud desde una billetera criptográfica (USDC en la red principal base), sin registro ni clave API. Hay dos configuraciones que funciona desde el principio: "solo úselo" (configure una billetera para que usted o Claude Code puedan ejecutar tareas del navegador en la nube pagadas desde la billetera; Claude escribe y ejecuta scripts desechables, nada toca su base de código) o "constrúyalo" (instale el SDK y escriba la clave + código en su proyecto). Explica la configuración de la billetera, la financiación, .env y una ejecución de prueba de ~$1. Úselo cuando el usuario pregunte sobre x402, pago por uso, pagos en USDC o quiera Browser Use Cloud sin una clave API. Para el registro de nivel gratuito (CAPTCHA inverso → clave API), utilice "registro en la nube para uso del navegador" o la habilidad "nube" en su lugar.
