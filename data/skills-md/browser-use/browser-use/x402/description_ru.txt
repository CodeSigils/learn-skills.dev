Настройте платежи в облаке через браузер с помощью x402 — оплата за запрос из криптокошелька (USDC в основной сети Base), без регистрации или ключа API. Он работает с двумя настройками: «просто используйте его» (настройте кошелек, чтобы вы или Клод Код могли запускать задачи облачного браузера, оплачиваемые из кошелька — Клод пишет и запускает одноразовые скрипты, ничто не затрагивает вашу кодовую базу) или «встройте его» (установите SDK и впишите ключ + код в свой проект). Описывается настройка кошелька, финансирование, .env и тестовый запуск стоимостью около 1 доллара. Используйте, когда пользователь спрашивает о x402, оплате по факту использования, платежах в долларах США или хочет использовать облако браузера без ключа API. Для регистрации бесплатного уровня (обратная капча → ключ API) вместо этого используйте «облачную регистрацию с использованием браузера» или навык «облака».
