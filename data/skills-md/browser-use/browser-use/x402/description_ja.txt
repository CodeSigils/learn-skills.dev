ブラウザをセットアップする x402 でクラウド支払いを使用します。サインアップや API キーは不要で、暗号ウォレット (Base メインネット上の USDC) からのリクエストごとに支払います。事前に実行される 2 つのセットアップ — 「そのまま使用する」 (ウォレットをセットアップして、ユーザーまたはクロード コードがウォレットから支払われるクラウド ブラウザ タスクを実行できるようにする — クロードは使い捨てスクリプトを作成して実行し、コードベースには何も触れません) または「ビルドイン」 (SDK をインストールし、プロジェクトにキーとコードを書き込む) です。ウォレットのセットアップ、資金調達、.env、および ~$1 のテスト実行について説明します。ユーザーが x402、従量課金制、USDC 支払いについて質問する場合、または API キーなしでブラウザーでクラウドを使用することを希望する場合に使用します。無料枠のサインアップ (リバース CAPTCHA → API キー) の場合は、代わりに「ブラウザー使用のクラウド サインアップ」または「クラウド」スキルを使用してください。
