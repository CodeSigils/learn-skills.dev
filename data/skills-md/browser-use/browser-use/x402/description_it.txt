Configura i pagamenti cloud per l'utilizzo del browser con x402: pagamento per richiesta da un portafoglio crittografico (USDC sulla rete principale Base), nessuna registrazione o chiave API. Due configurazioni che funziona in anticipo: "usalo e basta" (imposta un portafoglio in modo che tu o Claude Code possiate eseguire attività del browser cloud pagate dal portafoglio - Claude scrive ed esegue script usa e getta, niente tocca la tua base di codice) o "integralo" (installa l'SDK e scrivi la chiave + il codice nel tuo progetto). Esamina la configurazione del portafoglio, i finanziamenti, il file .env e un test di ~$1. Da utilizzare quando l'utente richiede pagamenti x402, pay-per-use, USDC o desidera utilizzare il browser Cloud senza una chiave API. Per l'iscrizione al livello gratuito (CAPTCHA inverso → chiave API), utilizza invece "iscrizione cloud per uso browser" o la competenza "cloud".
