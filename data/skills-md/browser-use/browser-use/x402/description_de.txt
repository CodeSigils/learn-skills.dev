Richten Sie den Browser ein. Nutzen Sie Cloud-Zahlungen mit x402 – zahlen Sie pro Anfrage aus einer Krypto-Wallet (USDC im Base-Mainnet), ohne Anmeldung oder API-Schlüssel. Zwei Setups funktionieren im Vorfeld: „Einfach verwenden“ (richten Sie eine Wallet ein, damit Sie oder Claude Code aus der Wallet bezahlte Cloud-Browser-Aufgaben ausführen können – Claude schreibt und führt Wegwerfskripte aus, nichts berührt Ihre Codebasis) oder „Einbauen“ (installieren Sie das SDK und schreiben Sie den Schlüssel + Code in Ihr Projekt). Führt durch die Einrichtung des Wallets, die Finanzierung, .env und einen Testlauf für ca. 1 $. Verwenden Sie diese Option, wenn der Benutzer nach x402, Pay-per-Use oder USDC-Zahlungen fragt oder die Browser-Nutzung der Cloud ohne API-Schlüssel wünscht. Für die kostenlose Anmeldung (Reverse-CAPTCHA → API-Schlüssel) verwenden Sie stattdessen „Cloud-Anmeldung über den Browser nutzen“ oder den „Cloud“-Skill.
