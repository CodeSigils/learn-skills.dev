x402로 브라우저 사용 클라우드 결제를 설정하세요. 가입이나 API 키 없이 암호화폐 지갑(기본 메인넷의 USDC)에서 요청별로 결제하세요. 두 가지 설정이 미리 작동합니다. "그냥 사용"(귀하 또는 Claude Code가 지갑에서 지불되는 클라우드 브라우저 작업을 실행할 수 있도록 지갑 설정 - Claude는 일회용 스크립트를 작성하고 실행하며 코드베이스에는 아무것도 건드리지 않음) 또는 "빌드 인"(SDK를 설치하고 프로젝트에 키 + 코드 작성). 지갑 설정, 자금 조달, .env 및 ~$1 테스트 실행을 안내합니다. 사용자가 x402, 종량제 결제, USDC 결제에 대해 문의하거나 API 키 없이 브라우저 사용 클라우드를 원하는 경우에 사용하세요. 무료 가입(역방향 CAPTCHA → API 키)의 경우 '브라우저 사용 클라우드 가입' 또는 '클라우드' 스킬을 대신 사용하세요.
