Configurez les paiements Cloud par navigateur avec x402 : payez par demande à partir d'un portefeuille cryptographique (USDC sur le réseau principal de base), sans inscription ni clé API. Deux configurations fonctionnent dès le départ : "utilisez-le simplement" (configurez un portefeuille pour que vous ou Claude Code puissiez exécuter des tâches de navigateur cloud payées à partir du portefeuille - Claude écrit et exécute des scripts jetables, rien ne touche votre base de code) ou "intégrez-le" (installez le SDK et écrivez la clé + le code dans votre projet). Présentation de la configuration du portefeuille, du financement, du .env et d'un test d'environ 1 $. À utiliser lorsque l'utilisateur pose des questions sur x402, le paiement à l'utilisation, les paiements USDC ou souhaite que le navigateur utilise le cloud sans clé API. Pour l'inscription gratuite (CAPTCHA inversé → clé API), utilisez plutôt « inscription dans le cloud via le navigateur » ou la compétence « cloud ».
