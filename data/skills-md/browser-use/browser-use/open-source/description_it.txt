Riferimento alla documentazione per scrivere codice Python utilizzando la libreria open source per l'uso del browser. Utilizza questa competenza ogni volta che l'utente ha bisogno di aiuto con la configurazione dell'agente, del browser o degli strumenti, scrive codice che importa da browser_use, chiede informazioni sulla distribuzione @sandbox, modelli LLM supportati, API Actor, strumenti personalizzati, hook del ciclo di vita, configurazione del server MCP o monitoraggio/osservabilità con Laminar o OpenLIT. Attiva anche domande sull'installazione dell'utilizzo del browser, sulle strategie di richiesta o sulla gestione dei dati sensibili. NON utilizzare questa opzione per l'utilizzo o i prezzi dell'API Cloud/SDK: utilizza invece la competenza cloud. NON utilizzarlo per automatizzare direttamente un browser tramite comandi CLI: utilizzare invece la capacità di utilizzo del browser.
