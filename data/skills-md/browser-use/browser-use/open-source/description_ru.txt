Справочник документации по написанию кода Python с использованием библиотеки с открытым исходным кодом, используемой браузером. Используйте этот навык всякий раз, когда пользователю нужна помощь с настройкой агента, браузера или инструментов, он пишет код, который импортируется из браузера_use, спрашивает о развертывании @sandbox, поддерживаемых моделях LLM, Actor API, пользовательских инструментах, перехватчиках жизненного цикла, настройке сервера MCP или мониторинге/наблюдении с помощью Laminar или OpenLIT. Также вызывает вопросы об установке с использованием браузера, стратегиях подсказок или обработке конфиденциальных данных. НЕ используйте это для использования Cloud API/SDK или ценообразования — вместо этого используйте навыки работы с облаком. НЕ используйте это для непосредственной автоматизации браузера с помощью команд CLI — вместо этого используйте навык использования браузера.
