Dokumentationsreferenz zum Schreiben von Python-Code mithilfe der browserbasierten Open-Source-Bibliothek. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Hilfe bei der Konfiguration von Agenten, Browsern oder Tools benötigt, Code schreibt, der aus browser_use importiert, nach @sandbox-Bereitstellung, unterstützten LLM-Modellen, Actor-API, benutzerdefinierten Tools, Lebenszyklus-Hooks, MCP-Server-Setup oder Überwachung/Beobachtbarkeit mit Laminar oder OpenLIT fragt. Lösen Sie auch Fragen zur Browserinstallation, zu Eingabeaufforderungsstrategien oder zum Umgang mit sensiblen Daten aus. Verwenden Sie dies NICHT für die Cloud-API/SDK-Nutzung oder Preisgestaltung – nutzen Sie stattdessen den Cloud-Skill. Verwenden Sie dies NICHT, um einen Browser direkt über CLI-Befehle zu automatisieren – verwenden Sie stattdessen die Fähigkeit zur Browsernutzung.
