Modifiez n'importe quelle vidéo par conversation. Transcrivez, coupez, étalonnez les couleurs, générez des animations de superposition, gravez des sous-titres — pour les têtes parlantes, les montages, les tutoriels, les voyages, les interviews. Pas de préréglages, pas de menus. Posez des questions, confirmez le plan, exécutez, itérez, persistez. Les règles d’exactitude de la production sont difficiles ; tout le reste est liberté artistique.
