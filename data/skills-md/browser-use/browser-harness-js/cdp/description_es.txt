Conduzca Chrome a través del protocolo DevTools desde JavaScript. Ejecute fragmentos de JS a través de la CLI `browser-harness-js`: genera automáticamente un servidor HTTP bun de larga duración que contiene una `Session` CDP completamente escrita, y cada llamada (`browser-harness-js 'await session.Page.navigate(...)'`) se ejecuta en la misma conexión persistente. La sesión, el objetivo activo y los globales sobreviven entre llamadas. Úselo cuando el usuario desee automatizar, crear secuencias de comandos o inspeccionar un navegador Chrome a través de CDP: pestaña única o pestañas múltiples, adjuntar a Chrome existente o a uno nuevo iniciado con --remote-debugging-port.
