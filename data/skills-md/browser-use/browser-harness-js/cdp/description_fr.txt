Pilotez Chrome via le protocole DevTools à partir de JavaScript. Exécutez des extraits JS via la CLI `browser-harness-js` - il génère automatiquement un serveur HTTP bun de longue durée contenant une `Session` CDP entièrement typée, et chaque appel (`browser-harness-js 'await session.Page.navigate(...)'`) s'exécute sur la même connexion persistante. La session, la cible active et les variables globales survivent à travers les appels. À utiliser lorsque l'utilisateur souhaite automatiser, créer un script ou inspecter un navigateur Chrome via CDP : onglet unique ou multi-onglets, attacher à Chrome existant ou à un nouveau lancé avec --remote-debugging-port.
