Steuern Sie Chrome über das DevTools-Protokoll von JavaScript. Führen Sie JS-Snippets über die „browser-harness-js“-CLI aus – sie erzeugt automatisch einen langlebigen Bun-HTTP-Server, der eine vollständig typisierte CDP-„Sitzung“ hält, und jeder Aufruf („browser-harness-js ‚await session.Page.navigate(...)‘‘) wird für dieselbe dauerhafte Verbindung ausgeführt. Sitzung, aktives Ziel und Globals bleiben über alle Aufrufe hinweg bestehen. Verwenden Sie diese Option, wenn der Benutzer einen Chrome-Browser über CDP automatisieren, skripten oder überprüfen möchte – mit einem oder mehreren Tabs, an bestehendes Chrome anhängen oder an ein neues anhängen, das mit --remote-debugging-port gestartet wurde.
