Управляйте Chrome через протокол DevTools из JavaScript. Запускайте фрагменты JS через CLI `browser-harness-js` — он автоматически создает долгоживущий HTTP-сервер, содержащий полностью типизированный `Session` CDP, и каждый вызов (`browser-harness-js 'await session.Page.navigate(...)'`) выполняется с использованием одного и того же постоянного соединения. Сеанс, активная цель и глобальные переменные сохраняются при вызовах. Используйте, когда пользователь хочет автоматизировать, создать сценарий или проверить браузер Chrome через CDP — с одной вкладкой или несколькими вкладками, подключиться к существующему Chrome или к новому, запущенному с помощью --remote-debugging-port.
