يُعرف أيضًا باسم Skill Auto Router، أو Skill_auto_router، أو رسام الخرائط القديم الماهر. يُستخدم قبل العمل الجوهري عندما يجب تحديد المهارات المثبتة، أو تدقيقها، أو تعيينها، أو عكسها في تعليمات المشروع، أو مراجعتها بحثًا عن أخطاء التوجيه. يقوم بمسح المهارات المحلية المتوافقة مع الدستور الغذائي، ويستخرج الأوصاف/المشغلات/السيناريوهات/التداخلات، ويوجه المهمة الحالية إلى قائمة قصيرة من أفضل المهارات الملائمة، ويعرض إشعارات مرئية لاستخدام المهارات/الصراع/التصحيح، ويسجل آثار التعليقات المحلية، ويقترح أو يطبق إرشادات تعليمات المشروع بأمان.
