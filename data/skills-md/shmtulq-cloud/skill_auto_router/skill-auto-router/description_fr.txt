Également connu sous le nom de Skill Auto Router, Skill_auto_router ou d'ancien Skill-Router-cartographer. À utiliser avant un travail substantiel lorsque les compétences installées doivent être sélectionnées, auditées, cartographiées, reflétées dans les instructions du projet ou examinées pour détecter les erreurs de routage. Analyse les compétences locales compatibles avec le Codex, extrait les descriptions/déclencheurs/scénarios/chevauchements, achemine la tâche en cours vers une courte liste de compétences les mieux adaptées, affiche des avis visibles d'utilisation/conflit/correction des compétences, enregistre les traces de commentaires locaux et suggère ou applique en toute sécurité des conseils d'instructions de projet.
