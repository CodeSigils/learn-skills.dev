También conocido como Skill Auto Router, Skill_auto_router o Skill-router-cartographer heredado. Úselo antes de trabajos sustanciales cuando las habilidades instaladas deben seleccionarse, auditarse, mapearse, reflejarse en las instrucciones del proyecto o revisarse para detectar errores de ruta. Escanea habilidades locales compatibles con el Codex, extrae descripciones/desencadenantes/escenarios/superposiciones, dirige la tarea actual a una breve lista de habilidades que mejor se adaptan, muestra avisos visibles de uso/conflicto/corrección de habilidades, registra seguimientos de comentarios locales y sugiere o aplica de forma segura orientación de instrucciones de proyecto.
