Richten Sie ein Repository auf die Agent-Skills-Bibliothek Ihrer Organisation und verwalten Sie angebotene Skills mit der „skillrig“-CLI – binden/wählen Sie den Ursprung („init“), suchen/entdecken Sie darin Skills („search“), bieten Sie einen Skill an/fügen Sie ihn hinzu („add“, lokal oder remote, mit einem optionalen unveränderlichen „--pin“), überprüfen Sie, ob die bereitgestellten Skills genau das sind, was genehmigt wurde („verify“), und generieren Sie den Katalog des Ursprungs („index“). Verwenden Sie diese Funktion immer dann, wenn der Benutzer einen Agenten-Skill aus einer Skills-Bibliothek suchen, suchen, entdecken, installieren, hinzufügen, anbieten, abrufen, sperren oder anheften möchte. Fähigkeiten nach Thema filtern; festlegen/konfigurieren, woher Fertigkeiten kommen, oder den Fehler „Kein Ursprung konfiguriert“ beheben; Richten Sie ein Repo auf ein Skills-Repo (OWNER/REPO[@branch]) oder verwenden Sie SKILLRIG_ORIGIN; Abruf von einem privaten/Remote-Ursprung oder Debug-Authentifizierung/nicht erreichbar/nicht gefunden/keine solche Version. Abruffehler; oder überprüfen/prüfen/überwachen Sie, dass die verkauften Fertigkeiten nicht manipuliert wurden (ein CI-Gate) und beheben Sie „Nichtübereinstimmung“/„Verwaist“/„Fehlend“/„Schmutzig“-Urteile. Discovery und Vendoring erfordern einen Ursprung, daher steht „skillrig init“ an erster Stelle. Wird auch dann ausgelöst, wenn der Befehl keinen Namen hat – z. B. „Zeigen Sie dieses Repo auf unsere Fertigkeiten“, „Welche Fertigkeiten hat unsere Bibliothek für Terraform“, „ziehen Sie die Terraform-Review-Fähigkeit ein“, „heften Sie sie an v1.4.0“, „stellen Sie sicher, dass niemand unsere Fertigkeiten geändert hat“, „Warum ist die Fertigkeitsprüfung in CI fehlgeschlagen“, „Unser Agenten-Fähigkeit wurde bearbeitet“.
