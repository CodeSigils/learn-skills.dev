Führen Sie einen Codierungsagenten in einer autonomen Schleife über einen /ralph-Befehl aus, der durch eine Preflight-Prüfung gesteuert wird, die sicherstellt, dass jede CLI installiert, verknüpft und authentifiziert ist. Verwenden Sie es, wenn Sie eine langfristige autonome Entwicklung von einer umfassenden, ergebnisorientierten Eingabeaufforderung aus vorantreiben.
