Ajoutez la facturation Polar à une application TypeScript/JavaScript à l'aide du package @polar-sh/sdk. Utilisez cette compétence chaque fois que l'utilisateur souhaite ajouter un point de terminaison Checkout, un point de terminaison de portail client ou un point de terminaison Webhooks pour Polar à n'importe quel framework : Next.js, Express, Hono, Astro, SvelteKit, Remix, TanStack Start, Nuxt, Fastify, Elysia, Deno, Supabase Edge Functions, Cloudflare Workers, Bun, etc.
