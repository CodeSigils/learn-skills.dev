Добавьте биллинг Polar в приложение TypeScript/JavaScript, используя пакет @polar-sh/sdk. Используйте этот навык всякий раз, когда пользователь хочет добавить конечную точку Checkout, конечную точку клиентского портала или конечную точку Webhooks для Polar в любую платформу — Next.js, Express, Hono, Astro, SvelteKit, Remix, TanStack Start, Nuxt, Fastify, Elysia, Deno, Supabase Edge Functions, Cloudflare Workers, Bun и т. д.
