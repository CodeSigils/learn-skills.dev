Agregue la facturación Polar a una aplicación TypeScript/JavaScript usando el paquete @polar-sh/sdk. Utilice esta habilidad siempre que el usuario desee agregar un punto final de Checkout, un punto final del Portal del cliente o un punto final de Webhooks para Polar a cualquier marco: Next.js, Express, Hono, Astro, SvelteKit, Remix, TanStack Start, Nuxt, Fastify, Elysia, Deno, Supabase Edge Functions, Cloudflare Workers, Bun, etc.
