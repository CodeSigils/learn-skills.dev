처음부터 Polar 결제 통합을 설정하는 대화형 온보딩 마법사입니다. 다음과 같은 경우에 이 기술을 사용하십시오. (1) 사용자가 프로젝트에서 "Polar 설정" 또는 "Polar 통합"을 원합니다. (2) 사용자가 Polar를 새로 시작하고 안내 설정이 필요합니다. (3) 사용자가 "Polar를 시작하려면 어떻게 해야 하나요?"라고 묻습니다. (4) 사용자가 Polar를 사용하여 앱에 결제/구독/체크아웃을 추가하려고 합니다. (5) 사용자가 첫 번째 Polar 제품을 만들고 결제하는 데 도움이 필요합니다. 이 기술은 MCP 설치, 인증, 제품 생성을 안내하고 프레임워크별 통합 코드를 생성합니다.
