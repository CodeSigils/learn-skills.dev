Asistente de incorporación interactivo para configurar la integración de pagos Polar desde cero. Utilice esta habilidad cuando: (1) El usuario quiera "configurar Polar" o "integrar Polar" en su proyecto; (2) El usuario está comenzando de nuevo con Polar y necesita una configuración guiada; (3) El usuario pregunta "¿cómo empiezo a utilizar Polar"; (4) El usuario desea agregar pagos/suscripciones/pagos a su aplicación usando Polar; (5) El usuario necesita ayuda para crear su primer producto Polar y realizar el pago. Esta habilidad le guía a través de la instalación, autenticación y creación de productos de MCP y genera código de integración específico del marco.
