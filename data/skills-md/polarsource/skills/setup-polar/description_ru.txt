Интерактивный мастер регистрации для настройки интеграции платежей Polar с нуля. Используйте этот навык, когда: (1) Пользователь хочет «настроить Polar» или «интегрировать Polar» в свой проект; (2) Пользователь начинает работу с Polar заново и нуждается в пошаговой настройке; (3) Пользователь спрашивает: «Как мне начать работу с Polar»; (4) Пользователь хочет добавить платежи/подписки/оформление заказа в свое приложение с помощью Polar; (5) Пользователю нужна помощь в создании первого продукта Polar и оформлении заказа. Этот навык охватывает установку MCP, аутентификацию, создание продукта и создание кода интеграции для конкретной платформы.
