Guide pour tester les intégrations de paiement Polar à l'aide de l'environnement sandbox. Utilisez cette compétence lorsque : (1) Configuration du bac à sable Polar pour le développement ; (2) Tester les flux de paiement sans paiements réels ; (3) Utilisation de cartes de test Stripe avec Polar ; (4) Rédaction de tests d'intégration de flux de paiement ; (5) Tester les webhooks localement avec ngrok ; (6) Se moquer de Polar dans les tests unitaires ; (7) Mise en place de pipelines CI/CD avec Polar sandbox ; (8) Débogage des problèmes de paiement dans le bac à sable.
