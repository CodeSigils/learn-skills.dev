Tailscale、headscale、および Tailscale 製品ファミリーのインストール、構成、管理に関するガイド。コア メッシュ VPN (出口ノード、サブネット ルーター、アクセス制御、SSH、MagicDNS)、Docker と Kubernetes の統合、CI/CD パイプライン、エフェメラル ノード、インフラストラクチャ アクセス、サイト間ネットワーキング、アプリ コネクタ、Aperture (ガバナンスのための AI/LLM ゲートウェイ、コスト管理、使用状況の可視化)、デバイス ポスチャ、MDM、SCIM プロビジョニング、SSH および kubectl セッション記録、tsrecorder、 Taildrop、Tailscale Serve、Funnel、および tsnet ライブラリを介して Tailscale を組み込む Go アプリケーションの構築。 Tailscale ネットワーク、メッシュ VPN、VPN の置き換え、コンテナ、Kubernetes オペレーター、CI/CD ランナー、デバイス管理、セッション記録、監査ログ、LLM API アクセス、AI コスト管理、ファイル共有、内部サービスの公開、またはテールネットに独自のデバイスとして参加する Go プログラムの作成について質問する場合に使用します。製品の名前を付けずにシナリオを説明する場合でも使用します。
