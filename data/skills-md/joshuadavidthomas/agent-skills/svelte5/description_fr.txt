Réinitialisation du modèle mental pour Svelte 5. À utiliser lors de l'écriture ou de la révision des composants Svelte pour passer de « ça marche » à « pense en Svelte ». Déclencheurs lors de la révision du code Svelte, "est-ce idiomatique", "voie Svelte", migration Svelte 5 ou odeurs reportées de React/Vue/Svelte 4 - l'effet attribue l'état, accessoire copié dans $state, magasin global par défaut, $bindable partout, div cliquable, createEventDispatcher, export let, on:click, API en forme de slot, code basé sur le cycle de vie, câblage DOM impératif, cérémonie de mise à jour immuable, valeur de contexte remplacement ou des API de composants qui masquent la propriété. Il s'agit du point d'entrée à usage général pour la révision des composants Svelte ; délègue à sveltekit pour les problèmes de routes/charge/actions/serveur et à des références ciblées pour plus de détails.
