Сброс ментальной модели для Svelte 5. Используйте при написании или обзоре компонентов Svelte, чтобы перейти от «работает» к «думает в Svelte». Триггеры при проверке кода Svelte, «это идиоматично», «способ Svelte», миграция Svelte 5 или запахи, перенесенные из React/Vue/Svelte 4 — эффект присваивает состояние, свойство копируется в $state, глобальное хранилище по умолчанию, $bindable везде, кликабельный div, createEventDispatcher, экспорт let, on:click, слот-образные API, код, управляемый жизненным циклом, императивное подключение DOM, церемония неизменяемого обновления, значение контекста замена или API-интерфейсы компонентов, скрывающие право собственности. Это универсальная отправная точка для проверки компонентов Svelte; делегаты в sveltekit для решения проблем с маршрутами/нагрузкой/действиями/сервером и в специализированные ссылки для получения подробной информации.
