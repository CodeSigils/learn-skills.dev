Restablecimiento del modelo mental para Svelte 5. Úselo al escribir o revisar componentes de Svelte para pasar de "funciona" a "piensa en Svelte". Activadores en la revisión del código de Svelte, "es esto idiomático", "manera de Svelte", migración de Svelte 5 u olores transferidos de React/Vue/Svelte 4: efecto asigna estado, accesorio copiado a $state, tienda global de forma predeterminada, $bindable en todas partes, div en el que se puede hacer clic, createEventDispatcher, export let, on:click, API con forma de ranura, código impulsado por el ciclo de vida, cableado DOM imperativo, ceremonia de actualización inmutable, valor de contexto API de reemplazo o componentes que ocultan la propiedad. Este es el punto de entrada de uso general para la revisión de componentes de Svelte; delega a sveltekit para inquietudes sobre rutas/carga/acciones/servidor y a referencias enfocadas para obtener detalles.
