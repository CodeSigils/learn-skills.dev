Ripristino del modello mentale per Svelte 5. Da utilizzare durante la scrittura o la revisione dei componenti di Svelte per passare da "funziona" a "pensa in Svelte". Trigger sulla revisione del codice Svelte, "è idiomatico", "Svelte way", migrazione Svelte 5 o odori trasferiti da React/Vue/Svelte 4: effetto assegna stato, prop copiato in $state, archivio globale per impostazione predefinita, $bindable ovunque, div cliccabile, createEventDispatcher, export let, on:click, API a forma di slot, codice basato sul ciclo di vita, cablaggio DOM imperativo, cerimonia di aggiornamento immutabile, sostituzione del valore del contesto o API dei componenti che nascondono la proprietà. Questo è il punto di ingresso generale per la revisione dei componenti Svelte; delega a sveltekit per percorsi/carico/azioni/problemi sul server e a riferimenti mirati per i dettagli.
