SvelteKit アプリのメンタルモデル リセット。ルート、レイアウト、ロード関数、フォームアクション、リモート関数、フック、認証、Cookie、エンドポイント、リダイレクト、エラー、SSR、プログレッシブエンハンスメント、またはアプリレベルのデータフローを作成またはレビューするときに使用します。 SvelteKit、+page、+layout、+server、+page.server.ts、+layout.server.ts、hooks.server.ts、load、アクション、fail()、redirect()、error()、Cookie、ローカル、ルート グループ、保護されたルート、セッション、フォーム アクション、拡張、リモート関数、command()、query()、form()、getRequestEvent()、SSR、ハイドレーション、およびシリアル化でトリガーします。コンポーネントレベルのルーン、スニペット、アクセシビリティ、アクション、トランジション、およびコンポーネント API レビューには svelte5 を使用します。
