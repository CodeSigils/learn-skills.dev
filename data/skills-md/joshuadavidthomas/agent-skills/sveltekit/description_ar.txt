إعادة ضبط النموذج العقلي لتطبيقات SvelteKit. يُستخدم عند كتابة أو مراجعة المسارات أو التخطيطات أو وظائف التحميل أو إجراءات النموذج أو الوظائف عن بعد أو الخطافات أو المصادقة أو ملفات تعريف الارتباط أو نقاط النهاية أو عمليات إعادة التوجيه أو الأخطاء أو SSR أو التحسين التدريجي أو تدفق البيانات على مستوى التطبيق. المشغلات على SvelteKit، +page، +layout، +server، +page.server.ts، +layout.server.ts، Hooks.server.ts، التحميل، الإجراءات، Fail()، redirect()، error()، ملفات تعريف الارتباط، السكان المحليين، مجموعات المسار، المسارات المحمية، الجلسات، إجراءات النموذج، التعزيز، الوظائف عن بعد، Command()، query()، form()، getRequestEvent()، SSR، الترطيب، والتسلسل. استخدم svelte5 للوحدات الرونية والمقتطفات وإمكانية الوصول والإجراءات والانتقالات ومراجعة واجهة برمجة تطبيقات المكونات على مستوى المكونات.
