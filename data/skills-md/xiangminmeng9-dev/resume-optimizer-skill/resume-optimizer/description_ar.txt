تحسين السيرة الذاتية المدعومة بالذكاء الاصطناعي لصناعة التكنولوجيا/الإنترنت الصينية، وخاصة أدوار مدير منتجات الذكاء الاصطناعي. استخدم هذه المهارة عندما يريد المستخدم تحسين السيرة الذاتية، أو إعادة كتابة النقاط النقطية للسيرة الذاتية، أو تخصيص السيرة الذاتية لـ JD أو شركة معينة، أو تحسين التوافق مع ATS، أو إضافة تعليقات توضيحية جريئة للتغييرات، أو إنشاء سيرة ذاتية معدلة مع التغييرات المتعقبة. استخدم أيضًا عندما يذكر المستخدم 简历优化، 简历修改، 简历改写، JD匹配، ATS评分، أو استئناف الخياطة - حتى لو لم يذكروا صراحةً "مُحسِّن الاستئناف".
