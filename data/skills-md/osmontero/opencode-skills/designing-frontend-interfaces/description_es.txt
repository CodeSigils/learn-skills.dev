Úselo al crear o cambiar el estilo de cualquier interfaz web (páginas de destino, paneles de control, sitios de marketing, aplicaciones web, componentes React/Vue, diseños HTML/CSS, artefactos, carteles) o cuando se le solicite hacer que una interfaz de usuario se vea mejor, más pulida, más distintiva, menos genérica o menos "generada por IA". Utilícelo también cuando se necesite un resumen de diseño, dirección de arte, identidad visual, escala tipográfica o sistema de color antes de la implementación.
