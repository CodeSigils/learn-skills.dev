يُستخدم عند إنشاء أو إعادة تصميم أي واجهة ويب - الصفحات المنتقل إليها، ولوحات المعلومات، ومواقع التسويق، وتطبيقات الويب، ومكونات React/Vue، وتخطيطات HTML/CSS، والعناصر، والملصقات - أو عندما يُطلب منك جعل واجهة المستخدم تبدو أفضل، أو أكثر صقلًا، أو أكثر تميزًا، أو أقل عمومية، أو أقل "إنشاءًا بواسطة الذكاء الاصطناعي". استخدمه أيضًا عندما تكون هناك حاجة إلى ملخص تصميم أو اتجاه فني أو هوية مرئية أو مقياس كتابة أو نظام ألوان قبل التنفيذ.
