Úselo cuando cambie cualquier cosa de la que ya dependan otros sistemas o datos almacenados: editar un archivo .proto, escribir una migración de base de datos, agregar o eliminar una columna, cambiar el nombre de un campo, cambiar la forma de una respuesta, cambiar una enumeración o alterar el formato de un mensaje de cola. Los desencadenantes incluyen "esto interrumpirá los clientes", "es compatible con versiones anteriores", "rotura de buf", "ALTER TABLE", "migración", "desaprobará este punto final" y cualquier cambio en una versión de API publicada.
