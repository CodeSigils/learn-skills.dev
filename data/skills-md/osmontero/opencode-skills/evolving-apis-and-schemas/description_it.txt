Da utilizzare quando si modifica qualsiasi cosa da cui dipendono già altri sistemi o dati archiviati: modifica di un file .proto, scrittura di una migrazione di database, aggiunta o eliminazione di una colonna, ridenominazione di un campo, modifica di una forma di risposta, modifica di un'enumerazione o alterazione del formato di un messaggio in coda. I trigger includono "interromperà i client", "è compatibile con le versioni precedenti", "interruzione buf", "ALTER TABLE", "migrazione", "depreca questo endpoint" e qualsiasi modifica a una versione API pubblicata.
