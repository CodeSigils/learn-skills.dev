À utiliser pour modifier tout ce dont dépendent déjà d'autres systèmes ou données stockées : modification d'un fichier .proto, écriture d'une migration de base de données, ajout ou suppression d'une colonne, renommage d'un champ, modification d'une forme de réponse, modification d'une énumération ou modification du format d'un message de file d'attente. Les déclencheurs incluent « cela va-t-il casser les clients », « est-ce rétrocompatible », « rupture de buf », « ALTER TABLE », « migration », « déprécier ce point de terminaison » et toute modification apportée à une version publiée de l'API.
