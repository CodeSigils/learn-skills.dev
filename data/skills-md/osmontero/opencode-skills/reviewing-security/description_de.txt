Verwenden Sie diese Option, wenn Sie den Code vor dem Zusammenführen oder Versenden auf Sicherheit überprüfen und wenn eine Änderung nicht vertrauenswürdige Eingaben, Authentifizierung, Autorisierung, Geheimnisse, SQL, Unterprozessausführung, Dateipfade, ausgehende Anforderungen, Deserialisierung, Uploads oder Abhängigkeiten von Drittanbietern betrifft. Zu den Auslösern gehören „Sicherheitsüberprüfung“, „Ist das sicher“, „Kann das ausgenutzt werden“, „Überprüfung auf Schwachstellen“ und das Hinzufügen einer neuen externen Schnittstelle – eines Endpunkts, eines Webhooks, eines Plugins oder eines Tools, das ein LLM aufrufen kann.
