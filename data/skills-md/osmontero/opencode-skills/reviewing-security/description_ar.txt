يُستخدم عند مراجعة التعليمات البرمجية للأمان قبل الدمج أو الشحن، وعندما يمس التغيير الإدخال غير الموثوق به، أو المصادقة، أو التفويض، أو الأسرار، أو SQL، أو تنفيذ العملية الفرعية، أو مسارات الملفات، أو الطلبات الصادرة، أو إلغاء التسلسل، أو التحميلات، أو تبعيات الطرف الثالث. تتضمن المشغلات "مراجعة الأمان"، و"هل هذا آمن"، و"هل يمكن استغلال ذلك"، و"تدقيق هذا بحثًا عن نقاط الضعف"، وإضافة أي واجهة خارجية جديدة - نقطة نهاية، أو خطاف ويب، أو مكون إضافي، أو أداة يمكن لـ LLM الاتصال بها.
