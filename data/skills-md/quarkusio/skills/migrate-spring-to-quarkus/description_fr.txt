Migre les applications Spring Boot vers Quarkus en utilisant une approche modulaire basée sur des portes. Prend en charge les extensions de compatibilité Spring et les chemins de migration complets de Quarkus. À utiliser lorsque l'utilisateur souhaite migrer, convertir ou porter une application Spring Boot vers Quarkus, mentionne "spring to quarkus", "quarkus migration", "remplace spring" ou pose des questions sur la migration de "pom.xml", "build.gradle", "Spring MVC", "Spring Data JPA", "Thymeleaf", "@SpringBootApplication".
