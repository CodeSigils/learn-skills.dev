Revisión técnica de control de calidad de sitios web de marketing frente a la barra de lanzamiento de una agencia. Úselo siempre que el usuario solicite realizar un control de calidad, revisar, auditar o verificar un sitio web o una URL provisional, incluida "verificación previa al lanzamiento", "revisión del sitio", "auditoría técnica de SEO", "está listo para lanzar", "verificar esta migración" o cualquier solicitud para verificar la calidad de un sitio de marketing. Cubre indexabilidad, metadatos, datos estructurados, accesibilidad, rendimiento, semántica HTML, formularios y seguridad, con módulos específicos de la plataforma para Webflow y pilas personalizadas (Astro, Next.js). Sólo lectura. Informa los hallazgos, no los soluciona.
