Travaillez d'abord avec les espaces de connaissances Nabu auto-hébergés via MCP distant natif, y compris les liens de connexion propriétaire-agent, l'authentification du porteur, les invitations en espace partagé, les informations d'identification étendues, la traversée des notes et les mutations prenant en compte les révisions. À utiliser lorsqu'un agent doit découvrir, authentifier, lire, écrire, partager, échanger ou vérifier des données Nabu, ou utiliser l'API HTTP car MCP n'est pas disponible ou est explicitement demandé.
