اعمل مع مساحات المعرفة Nabu المستضافة ذاتيًا من خلال MCP الأصلي البعيد أولاً، بما في ذلك روابط اتصال المالك والوكيل، ومصادقة الحامل، ودعوات المساحة المشتركة، وبيانات الاعتماد المحددة النطاق، واجتياز الملاحظات، والطفرات المدركة للمراجعة. يُستخدم عندما يتعين على الوكيل اكتشاف بيانات Nabu أو المصادقة عليها أو قراءتها أو كتابتها أو مشاركتها أو استردادها أو التحقق منها، أو استخدام HTTP API لأن MCP غير متاح أو مطلوب بشكل صريح.
