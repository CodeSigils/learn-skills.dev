Bereiten Sie eine Pull-Anfrage aus dem aktuellen Zweig vor und erstellen Sie sie. Verwenden Sie diese Option, wenn der Benutzer eine PR erstellen, eine Pull-Anfrage öffnen, einen Zweig für die Überprüfung vorbereiten oder Änderungen über PR versenden möchte. Führen Sie Projektvalidierungen durch, rufen Sie $code-review auf, selektieren Sie P0-P2-Ergebnisse, beheben Sie blockierende Fehler, führen Sie Prüfungen erneut durch, pushen Sie den Zweig und erstellen Sie eine standardisierte PR mit Zusammenfassung, Umfang, Tests, Testplan und lokalen Überprüfungsergebnissen.
