Préparez et créez une pull request à partir de la branche actuelle. À utiliser lorsque l'utilisateur demande à créer un PR, à ouvrir une pull request, à préparer une branche pour révision ou à envoyer des modifications via PR. Exécutez les validations de projet, invoquez $code-review, triez les résultats P0-P2, corrigez les bogues bloquants, réexécutez les vérifications, poussez la branche et créez un PR standardisé avec un résumé, une portée, des tests, un plan de test et des résultats d'examen local.
