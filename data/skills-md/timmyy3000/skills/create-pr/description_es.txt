Prepare y cree una solicitud de extracción desde la rama actual. Úselo cuando el usuario solicite crear un PR, abrir una solicitud de extracción, preparar una rama para revisión o enviar cambios a través de PR. Ejecute validaciones de proyectos, invoque $code-review, clasifica los resultados P0-P2, corrija errores de bloqueo, vuelva a ejecutar comprobaciones, impulse la rama y cree un PR estandarizado con resumen, alcance, pruebas, plan de pruebas y resultados de revisión local.
