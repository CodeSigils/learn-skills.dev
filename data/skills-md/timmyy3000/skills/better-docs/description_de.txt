Bearbeiten Sie vorhandene Produktdokumententwürfe in klare, prägnante und verständliche Texte und bewahren Sie dabei deren beabsichtigte Bedeutung, Fakten, Produktterminologie, Dokumenttyp und Autorenstimme. Verwenden Sie es, wenn Sie dazu aufgefordert werden, ein PRD, eine Produktspezifikation, eine User Story, ein Entscheidungsdokument, eine Produktbeschreibung, einen RFC, einen Einführungsplan, eine Produktphilosophie oder einen ähnlichen produktbezogenen Entwurf zu verbessern, zu verfeinern, zu straffen, umzuschreiben oder leichter lesbar zu machen. Verwenden Sie es nicht, um ein Dokument von Grund auf zu erstellen, eine Vorlage vorzuschreiben oder die zugrunde liegende Produktstrategie zu bewerten.
