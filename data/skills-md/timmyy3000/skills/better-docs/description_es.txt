Edite borradores de documentos de productos existentes para convertirlos en textos claros, concisos y digeribles, preservando al mismo tiempo el significado previsto, los hechos, la terminología del producto, el tipo de documento y la voz del autor. Úselo cuando se le solicite mejorar, pulir, ajustar, reescribir o facilitar la lectura de un PRD, especificaciones de producto, historia de usuario, documento de decisión, resumen de producto, RFC, plan de lanzamiento, filosofía de producto o borrador similar de producto. No lo utilice para crear un documento desde cero, imponer una plantilla o evaluar la estrategia subyacente del producto.
