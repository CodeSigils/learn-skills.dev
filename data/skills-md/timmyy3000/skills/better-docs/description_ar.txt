قم بتحرير مسودات مستندات المنتج الحالية إلى كتابة واضحة وموجزة وسهلة الفهم مع الحفاظ على المعنى المقصود والحقائق ومصطلحات المنتج ونوع المستند وصوت المؤلف. استخدمه عندما يُطلب منك تحسين أو صقل أو تشديد أو إعادة كتابة أو تسهيل قراءة PRD أو مواصفات المنتج أو قصة المستخدم أو مستند القرار أو ملخص المنتج أو RFC أو خطة الإطلاق أو فلسفة المنتج أو مسودة مماثلة تواجه المنتج. لا تستخدم لإنشاء مستند من الصفر، أو فرض قالب، أو تقييم استراتيجية المنتج الأساسية.
