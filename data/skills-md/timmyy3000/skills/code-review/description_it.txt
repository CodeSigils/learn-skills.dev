Revisione del codice pre-PR per modifiche alle filiali locali. Da utilizzare quando l'utente chiede di rivedere le modifiche prima di un PR, controllare il ramo corrente, ispezionare un diff per problemi o eseguire una revisione del codice. Analizzare la differenza del ramo rispetto alla sua base per individuare bug di correttezza, modalità di errore, rischi per la sicurezza, violazioni delle linee guida del progetto, regressioni e test mancanti. Segnala solo risultati utilizzabili con riferimenti a file e righe.
