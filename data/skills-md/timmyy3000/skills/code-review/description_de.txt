Überprüfung des Codes vor der PR für lokale Zweigstellenänderungen. Verwenden Sie diese Option, wenn der Benutzer Änderungen vor einem PR überprüfen, den aktuellen Zweig überprüfen, einen Diff auf Probleme untersuchen oder eine Codeüberprüfung durchführen möchte. Analysieren Sie den Branch-Differenz mit seiner Basis auf Korrektheitsfehler, Fehlermodi, Sicherheitsrisiken, Verstöße gegen Projektrichtlinien, Regressionen und fehlende Tests. Melden Sie nur umsetzbare Ergebnisse mit Datei- und Zeilenverweisen.
