Révision du code pré-PR pour les changements dans les succursales locales. À utiliser lorsque l'utilisateur demande à examiner les modifications avant un PR, à vérifier la branche actuelle, à inspecter une différence pour détecter des problèmes ou à exécuter une révision de code. Analysez la différence de branche par rapport à sa base pour détecter les bogues d'exactitude, les modes de défaillance, les risques de sécurité, les violations des directives du projet, les régressions et les tests manquants. Signalez uniquement les résultats exploitables avec des références de fichiers et de lignes.
