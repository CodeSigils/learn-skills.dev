Предварительная проверка кода PR для изменений в местном филиале. Используйте, когда пользователь просит просмотреть изменения перед PR, проверить текущую ветку, проверить разницу на наличие проблем или запустить проверку кода. Проанализируйте разницу ветки с ее базовой на предмет ошибок корректности, режимов сбоя, рисков безопасности, нарушений правил проекта, регрессий и отсутствующих тестов. Сообщайте только о практических результатах со ссылками на файлы и строки.
