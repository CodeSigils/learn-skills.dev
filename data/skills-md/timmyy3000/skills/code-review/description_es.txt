Revisión del código previo al PR para cambios en las sucursales locales. Úselo cuando el usuario solicite revisar los cambios antes de un PR, verificar la rama actual, inspeccionar una diferencia en busca de problemas o ejecutar una revisión de código. Analice la diferencia de rama con su base en busca de errores de corrección, modos de falla, riesgos de seguridad, violaciones de las pautas del proyecto, regresiones y pruebas faltantes. Informe solo hallazgos procesables con referencias de archivos y líneas.
