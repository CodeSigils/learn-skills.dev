ابدأ سير عمل هندسة IC بدءًا من النية الأولية وحتى التخطيط والمراجعات المستقلة والبساطة والتنفيذ وإنشاء طلبات السحب ومراقبة المراجعة. يُستخدم عندما يستدعي المستخدم /kickoff أو $kickoff، أو يريد بدء عمل الميزة، أو إصلاح الأخطاء، أو التحسينات، أو إعادة البناء، أو الإصلاحات العاجلة، أو التحقيقات، أو الاستكشافات، أو يطلب خطة كاملة يراجعها الإنسان أو خطة Markdown سريعة يراجعها الوكيل قبل التنفيذ. عندما يكون تكوين العامل مفقودًا، اطلب تكوين الوكيل الفرعي للاستخدام الأول قبل توجيه العمل.
