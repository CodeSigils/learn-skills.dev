Diese Fähigkeit sollte verwendet werden, um Aufgaben über die Befehlszeile an Agenten der Agentar-Plattform zu delegieren. Verwenden Sie es, wenn eine Aufgabe die Installation oder Überprüfung der Agentar-CLI, die Installation des Agentar-Skills, die Ausführung von Agentar-Chat-Befehlen, die Konfiguration von Anmeldeinformationen, das Delegieren von Büroarbeiten wie PPTs, Forschungsdokumenten oder Tabellen, das Generieren von Bildern, das Erstellen von Videos, das Testen von Anhängen oder Sitzungen oder die Fehlerbehebung bei der normalen Agentar-CLI-Nutzung umfasst.
