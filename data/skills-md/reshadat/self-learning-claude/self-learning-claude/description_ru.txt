Платформа Self-Learning Claude (SLC) для создания самоусовершенствующихся систем LLM посредством развивающихся контекстных сборников сценариев. Используйте этот навык при создании агентов, рабочих процессов или систем, ориентированных на предметную область, которым необходимо накапливать знания с течением времени, при оптимизации подсказок/системных инструкций посредством итерации, при реализации систем памяти для агентов LLM или когда вам нужны структурированные подходы для предотвращения коллапса контекста и смещения краткости при итеративном уточнении LLM.
