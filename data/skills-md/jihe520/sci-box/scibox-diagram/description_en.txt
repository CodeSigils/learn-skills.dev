Create and edit editable draw.io/diagrams.net schematics (.drawio XML), producing .drawio plus PNG/PDF. Three approaches: apply built‑in templates (five‑band technology roadmap, three‑column research framework diagram, three‑column stage flowchart, landscape task pipeline diagram), write XML from scratch, or faithfully recreate a reference diagram. Use when the user requests a technology roadmap, full‑text overview, research framework diagram, paper flowchart, algorithm flowchart, model/system architecture diagram, method illustration, a single diagram summarizing a paper or project, a presentation diagram, or asks for a draw.io diagram, to redraw an image as an editable vector diagram, or to fix a diagram (text overflow, arrow errors, inconsistent colors, misaligned layout). For line charts, heatmaps, and other data visualizations, switch to scibox-figure.
