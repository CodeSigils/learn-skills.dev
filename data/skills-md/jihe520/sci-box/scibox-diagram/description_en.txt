Create and edit editable draw.io/diagrams.net schematics (.drawio XML), outputting .drawio + PNG/PDF. Three approaches: apply built‑in templates (five‑step technology roadmap, three‑column research framework diagram, three‑column stage flowchart, landscape task pipeline diagram), write XML from scratch, or faithfully recreate a reference diagram. Use when the user requests a technology roadmap, full‑paper overview, research framework diagram, paper workflow diagram, algorithm flowchart, model/system architecture diagram, method illustration, a single‑page summary of a paper or project, a defense slide, or asks for a draw.io diagram, a redraw of an existing image into an editable vector format, or image fixes (text overflow/arrow misplacement/color inconsistency/misaligned layout). For line charts, heat maps, and other data visualizations, switch to scibox‑figure.
