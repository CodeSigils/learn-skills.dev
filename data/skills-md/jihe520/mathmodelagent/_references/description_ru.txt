Общая база знаний по стандартам. Включает справочные материалы, такие как инструкции по написанию руководств для соревнований по математическому моделированию, быстрые проверки предотвращения ошибок для типов задач, стандарты диаграмм и многое другое. Другие навыки доступны по запросу во время выполнения и не требуют отдельной активации.
