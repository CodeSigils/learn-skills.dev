Общая база знаний по стандартам. Он включает в себя справочный контент, например, рекомендации по написанию руководств для соревнований по математическому моделированию, быстрые проверки на предмет ошибок для типов задач, стандарты диаграмм и многое другое. Другие навыки доступны по требованию во время выполнения, без необходимости запуска отдельно.
