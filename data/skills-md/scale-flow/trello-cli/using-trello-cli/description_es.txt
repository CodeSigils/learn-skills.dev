Opere Trello a través de la herramienta CLI local. Utilice esta habilidad siempre que el usuario solicite crear, actualizar, mover, archivar, buscar o inspeccionar tableros, listas, tarjetas, comentarios, listas de verificación, archivos adjuntos, etiquetas, miembros o campos personalizados de Trello, o cuando mencione la CLI de Trello, el comando `trello` o quiera administrar Trello desde la terminal. Úselo también cuando trabaje en el repositorio Trello_CLI y necesite ejercitar el binario.
