Utilisez Trello via l'outil CLI local. Utilisez cette compétence chaque fois que l'utilisateur demande à créer, mettre à jour, déplacer, archiver, rechercher ou inspecter des tableaux, listes, cartes, commentaires, listes de contrôle, pièces jointes, étiquettes, membres ou champs personnalisés Trello - ou lorsqu'il mentionne la CLI Trello, la commande «trello», ou souhaite gérer Trello à partir du terminal. Utilisez-le également lorsque vous travaillez dans le référentiel Trello_CLI et que vous devez exercer le binaire.
