Utilizza Trello tramite lo strumento CLI locale. Utilizza questa abilità ogni volta che l'utente chiede di creare, aggiornare, spostare, archiviare, cercare o ispezionare bacheche, elenchi, schede, commenti, liste di controllo, allegati, etichette, membri o campi personalizzati di Trello — o quando menziona la CLI di Trello, il comando "trello" o desidera gestire Trello dal terminale. Usalo anche quando lavori nel repository Trello_CLI e hai bisogno di esercitare il binario.
