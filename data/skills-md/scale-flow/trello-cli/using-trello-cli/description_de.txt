Betreiben Sie Trello über das lokale CLI-Tool. Verwenden Sie diesen Skill immer dann, wenn der Benutzer Trello-Boards, Listen, Karten, Kommentare, Checklisten, Anhänge, Labels, Mitglieder oder benutzerdefinierte Felder erstellen, aktualisieren, verschieben, archivieren, durchsuchen oder überprüfen möchte – oder wenn er die Trello-CLI oder den „trello“-Befehl erwähnt oder Trello vom Terminal aus verwalten möchte. Verwenden Sie dies auch, wenn Sie im Trello_CLI-Repository arbeiten und die Binärdatei ausführen müssen.
