قم بتشغيل Trello من خلال أداة CLI المحلية. استخدم هذه المهارة عندما يطلب المستخدم إنشاء أو تحديث أو نقل أو أرشفة أو بحث أو فحص لوحات Trello أو القوائم أو البطاقات أو التعليقات أو قوائم المراجعة أو المرفقات أو التصنيفات أو الأعضاء أو الحقول المخصصة - أو عندما يذكرون واجهة سطر أوامر Trello، أو أمر `trello`، أو يريدون إدارة Trello من الوحدة الطرفية. استخدم هذا أيضًا عند العمل في مستودع Trello_CLI والحاجة إلى ممارسة الثنائي.
