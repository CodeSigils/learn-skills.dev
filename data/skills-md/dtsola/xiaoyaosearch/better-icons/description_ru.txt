Используйте при работе с иконками в любом проекте. Предоставляет интерфейс командной строки для поиска более чем в 200 библиотеках значков (Iconify) и получения файлов SVG. Команды: `better-icons search <query>` для поиска значков, `better-icons get <id>` для получения SVG. Также доступен как сервер MCP для агентов ИИ.
