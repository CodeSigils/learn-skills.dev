À utiliser lorsque vous travaillez avec des icônes dans n'importe quel projet. Fournit une CLI pour rechercher plus de 200 bibliothèques d’icônes (Iconify) et récupérer des SVG. Commandes : `better-icons search <query>` pour trouver des icônes, `better-icons get <id>` pour obtenir SVG. Également disponible en tant que serveur MCP pour les agents IA.
