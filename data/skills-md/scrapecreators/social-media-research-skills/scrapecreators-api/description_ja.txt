ScrapeCreators REST API を使用して、27 以上のソーシャル メディア プラットフォームから公開データをスクレイピングして抽出します。 TikTok、Instagram、YouTube、LinkedIn、Facebook、Twitter/X、Reddit、Threads、Bluesky、Pinterest、Snapchat、Twitch、Kick、Truth Social、TikTok Shop、Google、およびリンクインバイオ サービス (Linktree、Komi、Pillar、Linkbio、Linkme、Amazon Shop) をカバーします。ユーザーがソーシャル メディア プロフィール、投稿、ビデオ、リール、コメント、トランスクリプト、フォロワー、広告、ハッシュタグ、トレンド コンテンツ、またはエンゲージメント指標をソーシャル プラットフォームからスクレイピング、フェッチ、抽出、検索、または参照するように要求する場合に使用します。ユーザーが ScrapeCreators、ソーシャル メディア API、広告ライブラリ、クリエイター データに言及する場合にも使用します。
