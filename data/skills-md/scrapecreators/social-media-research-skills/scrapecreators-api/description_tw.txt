使用 ScrapeCreators REST API 從超過 27 個社群媒體平台抓取並提取公共資料。涵蓋 TikTok、Instagram、YouTube、LinkedIn、Facebook、Twitter/X、Reddit、Threads、Bluesky、Pinterest、Snapchat、Twitch、Kick、Truth Social、TikTok Shop、Google 和連結生物服務（Linktree、Komi、Pillar、Linkbio、Linkme、Amazon Shop）。當使用者要求從任何社群平台抓取、取得、擷取、搜尋或尋找社群媒體檔案、貼文、影片、捲軸、評論、文字記錄、追蹤者、廣告、主題標籤、趨勢內容或參與度指標時使用。當使用者提及 ScrapeCreators、社群媒體 API、廣告庫或建立者資料時也可使用。
