ScrapeCreators REST API를 사용하여 27개 이상의 소셜 미디어 플랫폼에서 공개 데이터를 스크랩하고 추출합니다. TikTok, Instagram, YouTube, LinkedIn, Facebook, Twitter/X, Reddit, Threads, Bluesky, Pinterest, Snapchat, Twitch, Kick, Truth Social, TikTok Shop, Google 및 link-in-bio 서비스(Linktree, Komi, Pillar, Linkbio, Linkme, Amazon Shop)를 다룹니다. 사용자가 모든 소셜 플랫폼에서 소셜 미디어 프로필, 게시물, 비디오, 릴, 댓글, 스크립트, 팔로어, 광고, 해시태그, 인기 콘텐츠 또는 참여 지표를 스크랩, 가져오기, 추출, 검색 또는 조회하도록 요청할 때 사용합니다. 사용자가 ScrapeCreators, 소셜 미디어 API, 광고 라이브러리 또는 제작자 데이터를 언급할 때도 사용합니다.
