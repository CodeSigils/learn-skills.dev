قم باستخراج البيانات العامة واستخراجها من أكثر من 27 منصة وسائط اجتماعية باستخدام ScrapeCreators REST API. يغطي TikTok وInstagram وYouTube وLinkedIn وFacebook وTwitter/X وReddit وThreads وBluesky وPinterest وSnapchat وTwitch وKick وTruth Social وTikTok Shop وGoogle وخدمات Link-in-bio (Linktree وKomi وPillar وLinkbio وLinkme وAmazon Shop). يُستخدم عندما يطلب المستخدم استخراج أو جلب أو استخراج أو البحث أو البحث عن ملفات تعريف الوسائط الاجتماعية أو المنشورات أو مقاطع الفيديو أو البكرات أو التعليقات أو النصوص أو المتابعين أو الإعلانات أو علامات التصنيف أو المحتوى الرائج أو مقاييس التفاعل من أي منصة اجتماعية. يُستخدم أيضًا عندما يذكر المستخدم ScrapeCreators أو واجهة برمجة تطبيقات الوسائط الاجتماعية أو مكتبة الإعلانات أو بيانات المنشئ.
