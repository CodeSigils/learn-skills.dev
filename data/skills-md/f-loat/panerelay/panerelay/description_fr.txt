Utilisez Panerelay comme point d'entrée d'agent unique pour la récupération HTTP authentifiée par le navigateur, la connexion au moteur d'automatisation, la configuration, la vérification, le routage et le dépannage via la session Chrome ou Microsoft Edge existante de l'utilisateur. À utiliser lorsqu'un agent doit réutiliser l'état de connexion du navigateur, les cookies, les extensions ou les onglets explicitement autorisés via Panerelay.
