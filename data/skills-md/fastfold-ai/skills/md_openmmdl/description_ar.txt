قم بتشغيل سير عمل الديناميكيات الجزيئية OpenMMDL عبر FastFold Workflows API (`openmmdl_v1`) من الهيكل المحلي + ملفات الارتباط الاختيارية، وقم بإعداد مسودات البرامج النصية، وتنفيذ المسودات، والانتظار حتى الاكتمال، وجلب القطع الأثرية/المقاييس، واستخراج إطارات المسار. يُستخدم عندما يطلب المستخدمون إعداد OpenMMDL، أو Protein-ligand MD، أو البرنامج النصي OpenMMDL، أو إعادة تشغيل `/openmmdl/results/<workflow_id>`.
