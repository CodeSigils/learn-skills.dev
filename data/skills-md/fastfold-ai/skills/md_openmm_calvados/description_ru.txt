Запускайте моделирование молекулярной динамики (МД) через API FastFold Workflows. Today поддерживает рабочий процесс CALVADOS+OpenMM (calvados_openmm_v1) либо из существующего задания сгиба (структура AF + автоматическое разрешение PAE), либо из ручной загрузки PDB+PAE, затем ожидает завершения, извлекает метрики/графики/артефакты CSV и извлекает кадры траектории в виде файлов PDB. Используйте при запуске моделирования MD с помощью FastFold, CALVADOS + OpenMM, считывании показателей/графиков MD, извлечении кадров или написании сценариев «Отправка → ожидание» → результаты для прогона MD.
