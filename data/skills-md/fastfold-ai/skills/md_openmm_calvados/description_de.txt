Führen Sie Simulationen der Molekulardynamik (MD) über die FastFold Workflows API durch. Today unterstützt den CALVADOS+OpenMM-Workflow (calvados_openmm_v1) entweder von einem vorhandenen Faltjob (AF-Struktur + automatisch aufgelöste PAE) oder vom manuellen PDB+PAE-Upload, wartet dann auf den Abschluss, ruft Metriken/Plots/CSV-Artefakte ab und extrahiert Trajektorienrahmen als PDB-Dateien. Verwenden Sie diese Option, wenn Sie eine MD-Simulation mit FastFold, CALVADOS + OpenMM ausführen, MD-Metriken/Plots lesen, Frames extrahieren oder Skripts zum Senden → Warten → Ergebnissen für einen MD-Lauf erstellen.
