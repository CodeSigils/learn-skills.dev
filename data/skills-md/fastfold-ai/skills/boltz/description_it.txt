Esegui i flussi di lavoro API Boltz tramite la CLI ufficiale `boltz-api`: struttura e legame, progettazione/schermata di proteine, progettazione/schermata di piccole molecole, previsione ADME e stato/ripristino del lavoro. Da utilizzare quando l'utente desidera stimare, inviare, monitorare, recuperare risultati, interrompere o ripristinare un lavoro API Boltz.
