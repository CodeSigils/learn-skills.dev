Ottimizza e perfeziona i suggerimenti dell'intelligenza artificiale attraverso una pipeline di esperti in due fasi. La Fase 1 (Lyra) costruisce una bozza strutturata da idee grezze, la Fase 2 (Meta) la perfeziona profondamente con tecniche avanzate di ingegneria rapida. Utilizza questa competenza quando l'utente desidera migliorare un prompt, scrivere un prompt di sistema migliore, ottimizzare le istruzioni LLM o creare prompt IA di alta qualità. Si attivano anche quando gli utenti chiedono informazioni sulla progettazione dei prompt, sull'ottimizzazione dei prompt, sulla creazione di prompt più efficaci o robusti, sulla scrittura di prompt di sistema, sulla creazione di istruzioni per l'agente o sulla progettazione di prompt di competenze, anche se non dicono esplicitamente "prompt migliore".
