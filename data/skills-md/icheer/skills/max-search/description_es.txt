Ejecuta una búsqueda web completa para "maximizar la cobertura de información": descompone la pregunta en lenguaje natural de un usuario en palabras clave de búsqueda ortogonales, ejecuta búsquedas Tavily paralelas y sintetiza una respuesta citada y fundamentada.
**Comando de barra diagonal**: `/max-search <pregunta>`
Activar en: /max-search, "深度搜索", "max search", "全面搜索", "最大化搜索", "做个调研", "帮我调查一下", "最新动态是什么", "最近有什么进展", "对比一下", "分析一下", "做个对比分析", o cualquier pregunta que sea objetiva, multifacética o que se beneficie de múltiples consultas de búsqueda ortogonales. Específicamente: investigación de empresas/tecnología, análisis de mercado, verificación de datos, comparación de opiniones, investigación de tendencias, análisis competitivo o cualquier pregunta en la que una sola consulta de búsqueda no sea suficiente. También se activa cuando el usuario dice cosas como "帮我深度搜索一下 DeepSeek" o "我想要全面了解一下 某话题" o pregunta "最近 XXX 有什么新消息". Esta habilidad es el punto de entrada autorizado para la búsqueda profunda impulsada por Tavily en este código base. NO utilice las antiguas habilidades de tavily-keyword-extractor o tavily-max-search; usa este.
