`21st` CLI (`@21st-dev/cli`) を使用して 21st.dev カタログからコードを検索、インストールし、プルします。React/shadcn コンポーネント、テーマ、テンプレートを検索し、コンポーネントのコードまたはテーマの CSS を印刷し、プロジェクトに項目をインストールするか、21st AI で新しいコンポーネントを生成します。ユーザーが「21 日にコンポーネント/テーマを検索/見つける」、「チームのボタンをインストールする」、「@user/slug を追加する」、「そのコンポーネントのコードをプルする」、「21 日に」、「поставь наз компонент」と言う場合、またはシェル/CI からカタログ アクセスをスクリプト化する場合に使用します。プロジェクトに `components.json` がある場合に自動アクティブ化します。手書き UI の前の 21 番目を検索します。
