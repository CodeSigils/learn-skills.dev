Busque, instale y extraiga código del catálogo 21st.dev con la CLI `21st` (`@21st-dev/cli`): busque componentes, temas y plantillas de React/shadcn, imprima el código de un componente o el CSS de un tema, instale un elemento en el proyecto o genere un nuevo componente con 21st AI. Úselo siempre que el usuario diga "buscar/encontrar un componente/tema en 21", "instalar el botón de nuestro equipo", "agregar @usuario/slug", "extraer el código de ese componente", "найди компонент на 21st", "поставь наш компонент", o quiera acceder al catálogo de secuencias de comandos desde el shell/CI. Se activa automáticamente cuando un proyecto tiene `components.json`: busque el puesto 21 antes de escribir la interfaz de usuario a mano.
