Recherchez, installez et extrayez le code du catalogue 21st.dev avec la CLI `21st` ($`@21st-dev/cli`) : recherchez des composants, des thèmes et des modèles React/shadcn, imprimez le code d'un composant ou le CSS d'un thème, installez un élément dans le projet ou générez un nouveau composant avec 21st AI. À utiliser chaque fois que l'utilisateur dit "rechercher/trouver un composant/thème le 21", "installer le bouton de notre équipe", "ajouter @user/slug", "extraire le code de ce composant", "installer un composant sur le 21", "installer un composant", ou souhaite créer un script d'accès au catalogue à partir du shell/CI. Activation automatique lorsqu'un projet a un « components.json » – recherchez le 21 avant d'écrire manuellement l'interface utilisateur.
