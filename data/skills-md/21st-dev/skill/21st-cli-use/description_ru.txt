Найдите, установите и извлеките код из каталога 21st.dev с помощью интерфейса командной строки `@21st-dev/cli`: найдите компоненты, темы и шаблоны React/shadcn, распечатайте код компонента или CSS темы, установите элемент в проект или сгенерируйте новый компонент с помощью 21st AI. Используйте всякий раз, когда пользователь говорит «найти/найти компонент/тему 21-го числа», «установить кнопку нашей команды», «добавить @user/slug», «вытащить код этого компонента», «найди компонент 21-го числа», «поставить наш компонент» или хочет создать сценарий доступа к каталогу из оболочки/CI. Автоматически активировать, если в проекте есть `comComponents.json` — выполните поиск по 21-му номеру, прежде чем писать пользовательский интерфейс от руки.
