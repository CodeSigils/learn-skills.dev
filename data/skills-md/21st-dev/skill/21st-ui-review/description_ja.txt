プロジェクトの設計コンテキスト、アクセシビリティの期待、応答性の高い動作、インタラクションの品質、および信頼性の高い制作ルールに照らして既存の UI をレビューします。 UI 監査、デザイン QA、フロントエンド レビュー、アクセシビリティ レビュー、一貫性チェック、または視覚的な欠陥を見つけて安全に修正するためのリクエストに使用します。 「この UI をレビューする」、「このページを監査する」、「設計上の問題を見つける」、「応答性をチェックする」、「明らかな UX の問題を修正する」などのリクエストをトリガーします。リクエストが主に新しい UI を作成することである場合は、21st-ui-build を使用します。
