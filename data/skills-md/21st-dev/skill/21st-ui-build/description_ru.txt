Создавайте или существенно меняйте UI для продакшна, используя текущий дизайн‑контекст проекта, существующие компоненты и обоснованное вдохновение 21st. Применяйте это при реализации страницы, секции, компонента, адаптивного редизайна или визуального полирования в существующем веб‑проекте. Триггером служат запросы вроде «создай этот UI», «реализуй этот экран», «сделай эту страницу готовой к продакшену» или «используй 21st для создания интерфейса». Сначала используйте 21st‑ui‑explore, когда визуальное направление намеренно не определено, и 21st‑ui‑review для работы, ограниченной только критикой.
