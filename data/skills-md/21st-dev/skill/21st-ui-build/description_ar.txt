قم بإنشاء أو تعديل كبير لواجهة المستخدم الإنتاجية باستخدام سياق تصميم المشروع الحالي، والمكونات الموجودة، وإلهام القرن الحادي والعشرين المستند. استخدم ذلك عند تنفيذ صفحة أو قسم أو مكوّن أو إعادة تصميم استجابة أو تحسين بصري في مشروع ويب موجود. يُستَخدم لهذا النوع من الطلبات مثل «أنشئ هذه الواجهة»، «نفّذ هذه الشاشة»، «اجعل هذه الصفحة جاهزة للإنتاج»، أو «استخدم 21st لإنشاء الواجهة». استخدم 21st‑ui‑explore أولاً عندما يكون الاتجاه البصري غير محدد عمداً، واستخدم 21st‑ui‑review لأعمال النقد فقط.
