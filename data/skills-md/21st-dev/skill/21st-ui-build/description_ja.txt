現在のプロジェクトの設計コンテキスト、既存のコンポーネント、根拠のある 21 番目のインスピレーションを使用して、実稼働 UI を構築または大幅に変更します。既存の Web プロジェクトでページ、セクション、コンポーネント、レスポンシブな再デザイン、または視覚的な洗練を実装するときに使用します。 「この UI を構築する」、「この画面を実装する」、「このページを本番環境に対応させる」、または「21 日を使用してインターフェースを作成する」などのリクエストのトリガー。視覚的な方向性が意図的に決まっていない場合は 21st-ui-explore を最初に使用し、批評のみの作業には 21st-ui-review を使用します。
