Construisez ou modifiez de façon substantielle l'interface utilisateur de production en utilisant le contexte de conception du projet actuel, les composants existants et l'inspiration 21st ancrée. Utilisez-le lors de la mise en œuvre d’une page, d’une section, d’un composant, d’une refonte responsive ou d’un raffinement visuel dans un projet web existant. Déclenchez-le pour des demandes telles que « construire cette UI », « implémenter cet écran », « rendre cette page prête pour la production » ou « utiliser 21st pour créer l’interface ». Utilisez 21st‑ui‑explore en premier quand la direction visuelle est intentionnellement indécise, et 21st‑ui‑review pour un travail de critique uniquement.
