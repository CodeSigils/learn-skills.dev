Publique su propio trabajo en 21st.dev y adminístrelo desde la terminal con la CLI `21st` ($@21st-dev/cli`): publique un componente de React en una biblioteca de equipo, publique un tema CSS o una lista de plantillas, edite/anule la publicación/elimine sus elementos publicados y lea/reemplace su página de perfil público (tablero bento). Se activa cuando el usuario dice "publicar/compartir/cargar esto en el 21", "залей в наш регистр", "опубликуй компонент/тему/темплейт", "compartir con el equipo", "hacer esto reutilizable", "anular la publicación/editar/eliminar mi componente", "cambiar su visibilidad", "agregar esto a mi 21". perfil/bento", "actualizar mi página de perfil", "обнови мой профиль на 21st", "добавь блок в бенто". Para buscar e instalar elementos existentes, utilice `21st-cli-use`; para convertir los tokens de diseño de un proyecto en un tema, utilice `21st-design-sync`.
