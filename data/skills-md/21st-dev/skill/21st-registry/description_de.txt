Veröffentlichen Sie Ihre eigene Arbeit auf 21st.dev und verwalten Sie sie vom Terminal aus mit der „21st“-CLI („@21st-dev/cli“): Veröffentlichen Sie eine React-Komponente in einer Teambibliothek, veröffentlichen Sie ein CSS-Theme oder eine Vorlagenliste, bearbeiten/veröffentlichen/löschen Sie Ihre veröffentlichten Elemente und lesen/ersetzen Sie Ihre öffentliche Profilseite (Bento-Board). Wird ausgelöst, wenn der Benutzer sagt: „Veröffentlichen/teilen/hochladen Sie dies auf 21st“, „In unserem Register registrieren“, „Mit Team teilen“, „Wiederverwendbar machen“, „Veröffentlichung aufheben/bearbeiten/löschen meiner Komponente“, „Sichtbarkeit ändern“, „Füge dies zu meinem 21st-Profil/Bento hinzu“, „Aktualisiere meine Profilseite“, „Ich habe mein Profil auf 21st erstellt“, „einen Block hinzufügen“. Zum Suchen und Installieren vorhandener Elemente verwenden Sie „21st-cli-use“; Um die Design-Tokens eines Projekts in ein Thema umzuwandeln, verwenden Sie „21st-design-sync“.
