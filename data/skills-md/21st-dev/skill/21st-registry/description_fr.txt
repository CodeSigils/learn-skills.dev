Publiez votre propre travail sur 21st.dev et gérez-le depuis le terminal avec la CLI `21st` (`@21st-dev/cli`) : publiez un composant React dans une bibliothèque d'équipe, publiez un thème CSS ou une liste de modèles, modifiez/dépublier/supprimez vos éléments publiés et lisez/remplacez votre page de profil public (tableau bento). Se déclenche lorsque l'utilisateur dit « publier/partager/télécharger ceci sur le 21 », « insérer dans votre registre », « опубликуй компонент/тему/темплейт », « partager avec l'équipe », « rendre ceci réutilisable », « dépublier/modifier/supprimer mon composant », « modifier sa visibilité », « ajouter ceci à mon 21e profil/bento », « mettre à jour mon profil ». page", "обнови мой профиль на 21st", "добавь блок в бенто". Pour rechercher et installer des éléments existants, utilisez « 21st-cli-use » ; pour transformer les jetons de conception d'un projet en thème, utilisez « 21st-design-sync ».
