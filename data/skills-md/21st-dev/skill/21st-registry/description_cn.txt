将您自己的作品发布到 21st.dev 并使用 `21st` CLI (`@21st-dev/cli`) 从终端管理它：将 React 组件发布到团队库，发布 CSS 主题或模板列表，编辑/取消发布/删除您发布的项目，以及读取/替换您的公共个人资料页面（便当板）。当用户说“发布/共享/上传此至 21 日”、“залей в наш регистр”、“опубликуй компонент/тему/темплейт”、“与团队共享”、“使其可重用”、“取消发布/编辑/删除我的组件”、“更改其可见性”时触发“将此添加到我的第21个个人资料/便当”，“更新我的个人资料页面”，“обнови мой профиль на 21st”，“добавь блок в бенто”。要查找并安装现有项目，请使用“21st-cli-use”；要将项目的设计标记转变为主题，请使用“21st-design-sync”。
