자신의 작업을 21st.dev에 게시하고 `21st` CLI(`@21st-dev/cli`)를 사용하여 터미널에서 관리합니다. React 구성 요소를 팀 라이브러리에 게시하고, CSS 테마 또는 템플릿 목록을 게시하고, 게시된 항목을 편집/게시 취소/삭제하고, 공개 프로필 페이지(도시락 보드)를 읽거나 교체합니다. 사용자가 "이 항목을 21st에 게시/공유/업로드", "залей в наш регистр", "опубликуй компонент/тему/темплейт", "팀과 공유", "재사용 가능하게 설정", "내 구성 요소 게시 취소/편집/삭제", "표시 유형 변경"이라고 말하면 트리거됩니다. "이것을 내 21번째 프로필/도시락에 추가하세요", "내 프로필 페이지 업데이트", "обнови мой профиль на 21st", "добавь блок в бенто". For finding and installing existing items use `21st-cli-use`; for turning a project's design tokens into a theme use `21st-design-sync`.
