將您自己的作品發佈到 21st.dev 並使用 `21st` CLI (`@21st-dev/cli`) 從終端管理它：將 React 組件發佈到團隊庫，發布 CSS 主題或模板列表，編輯/取消發布/刪除您發布的項目，以及讀取/替換您的公共個人資料頁面（便當板）。當用戶說「發布/分享/上傳此至 21 日」、「залей в наш регистр」、「опубликуй компонент/тему/темплейт”、“與團隊共享”、“使其可重用”、“取消發布/編輯/刪除我的組件”、“更改其可見性”時觸發“將此添加到我的第21個個人資料/便當”，“更新我的個人資料頁面”，“обнн 21st”，“добавь блок в бенто”。若要尋找並安裝現有項目，請使用「21st-cli-use」；若要將專案的設計標記轉換為主題，請使用「21st-design-sync」。
