Публикуйте свою собственную работу на 21st.dev и управляйте ею с терминала с помощью `21st` CLI (@21st-dev/cli`): публикуйте компонент React в библиотеке команды, публикуйте тему CSS или список шаблонов, редактируйте/отменяйте публикацию/удаляйте опубликованные элементы и читайте/заменяйте общедоступную страницу профиля (доску Bento). Срабатывает, когда пользователь говорит "опубликовать/поделиться/загрузить это на 21st", "залей в наш регистр", "опубликовать компонент/тему/темплейт", "поделиться с командой", "сделать это многоразовым", "отменить публикацию/редактировать/удалить мой компонент", "изменить его видимость", "добавить это в мой 21-й профиль/bento", "обновить страницу моего профиля", "обновить мой профиль на 21st", "добавь блок" в бенто». Для поиска и установки существующих элементов используйте `21st-cli-use`; для превращения жетонов дизайна проекта в тему используйте «21st-design-sync».
