Générez et itérez sur l'interface utilisateur avec la 21e IA à partir du terminal via la « 21e » CLI (« @21st-dev/cli ») : esquissez une interface utilisateur à partir d'une invite, prévisualisez les variantes dans le navigateur, modifiez toute variante en place avec un changement de langage naturel et extrayez le code final dans le projet. À utiliser chaque fois que l'utilisateur souhaite CONSTRUIRE/ESCROYER une nouvelle interface utilisateur (« esquisser une page de tarification », « générer un héros avec le 21 », « faire de moi une section <X> »), ITÉRER sur un brouillon généré (« modifier la troisième variante », « ajouter une bascule à cette prise ») ou saisir le code d'un brouillon (« extraire le code de cette variante », « сгенери UI на 21st », « поправь третий вариант", "забери код того наброска"). Pour rechercher/installer des composants existants, utilisez la compétence « 21st-cli-use » ; pour publier votre propre « 21e registre ».
