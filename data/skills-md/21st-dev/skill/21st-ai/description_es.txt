Genere e itere la interfaz de usuario con 21st AI desde la terminal a través de la CLI `21st` (“@21st-dev/cli`): dibuje una interfaz de usuario desde un mensaje, obtenga una vista previa de las variantes en el navegador, edite cualquier variante con un cambio de lenguaje natural e introduzca el código final en el proyecto. Úselo siempre que el usuario quiera CONSTRUIR / DIBUJAR una nueva interfaz de usuario ("dibujar una página de precios", "generar un héroe con 21", "hacerme una sección <X>"), ITERAR un borrador generado ("editar la tercera variante", "agregar un interruptor a esa toma"), o TOMAR el código de un borrador ("extraer el código de esa variante", "сгенери UI на 21st", "поправь третий вариант", "забери код того наброска"). Para buscar/instalar componentes existentes, utilice la habilidad `21st-cli-use`; para publicar el suyo propio, "registro 21".
