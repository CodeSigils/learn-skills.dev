Создавайте и итерируйте пользовательский интерфейс с помощью 21-го AI из терминала через `21st` CLI (@21st-dev/cli`): нарисуйте пользовательский интерфейс из командной строки, просмотрите варианты в браузере, отредактируйте любой вариант на месте с изменением естественного языка и вставьте окончательный код в проект. Используйте всякий раз, когда пользователь хочет СОЗДАТЬ/СОЗДАТЬ новый пользовательский интерфейс («нарисовать страницу с ценами», «создать героя с 21-м числом», «сделать мне раздел <X>»), ПЕРЕДАТЬ сгенерированный черновик («отредактировать третий вариант», «добавить переключатель к этому варианту») или ЗАБРАТЬ код черновика («вытащить код этого варианта», «сгенерировать пользовательский интерфейс на 21-е место», «поправить третий вариант», «забрать код того наброска»). Для поиска/установки существующих компонентов используйте навык «21st-cli-use»; опубликовать свой собственный «21-й реестр».
