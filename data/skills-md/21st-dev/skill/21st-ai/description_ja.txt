`21st` CLI (`@21st-dev/cli`) を介してターミナルから 21st AI を使用して UI を生成および反復します。プロンプトから UI をスケッチし、ブラウザーでバリアントをプレビューし、自然言語の変更を加えて適切なバリアントを編集し、最終コードをプロジェクトにプルします。ユーザーが新しい UI を構築/スケッチする場合 (「価格設定ページをスケッチする」、「21 番目のヒーローを生成する」、「<X> セクションにする」)、生成されたドラフトを反復処理する (「3 番目のバリアントを編集する」、「そのテイクにトグルを追加する」)、またはドラフトのコードを取得する (「そのバリアントのコードをプルする」、「21 番目の UI を使用する」、 「поправь третий вариант」、「забери код того наброска」）。既存のコンポーネントを検索/インストールするには、「21st-cli-use」スキルを使用します。独自の「21st-registry」を公開します。
