Используйте всякий раз, когда пользователь хочет создать или изменить чат, агента или вызов инструментов.
Пользовательский интерфейс в проекте React 19 + Tailwind v4 — особенно если код импортируется из
`@/comComponents/agent-elements/*` или эта папка есть в проекте на диске.
Триггеры: «чат агента», «пользовательский интерфейс вызова инструмента», «потоковая трансляция чата», «утверждение плана»,
«AgentChat», «InputBar», «средство визуализации инструментов», упоминания об элементах агента или
запросы на добавление новой поверхности агента с помощью shadcn.

НЕ используйте для простых интерфейсов чата, которым не нужны карточки инструментов/планов/утверждений или
для проектов, уже использующих другой комплект пользовательского интерфейса агента.
