Publiez un composant React dans la bibliothèque d'équipe de l'utilisateur sur 21st.dev afin que les coéquipiers puissent l'installer avec une seule commande ou en installer un existant. Se déclenche lorsque l'utilisateur dit des choses comme « publier/partager/télécharger ceci sur le 21 », « залей в наш регистр », « опубликуй компонент », « partager avec l'équipe », « rendre ceci réutilisable », « installer notre bouton », « utiliser le bouton d'équipe ».
