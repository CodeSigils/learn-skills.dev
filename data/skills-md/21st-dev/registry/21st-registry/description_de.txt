Veröffentlichen Sie eine React-Komponente in der Teambibliothek des Benutzers auf 21st.dev, damit Teamkollegen sie mit einem einzigen Befehl installieren oder eine vorhandene installieren können. Wird ausgelöst, wenn der Benutzer Dinge sagt wie „Veröffentlichen/teilen/hochladen Sie dies auf 21st“, „Im Registrierungsverzeichnis registrieren“, „Komponente hinzufügen“, „Mit Team teilen“, „Wiederverwendbar machen“, „Unseren Button installieren“ oder „Team-Button verwenden“.
