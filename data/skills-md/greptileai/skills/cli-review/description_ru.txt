Запускает проверку CLI Greptile для текущей локальной ветки, при необходимости устанавливает или аутентифицирует CLI, а затем обобщает результаты JSON для пользователя. Используйте, когда пользователь хочет получить обратную связь от Greptile перед открытием PR, вне процесса проверки размещенного PR или непосредственно при локальной оформлении заказа.
