Exécute un examen Greptile CLI pour la branche locale actuelle, installe ou authentifie la CLI si nécessaire, puis résume les résultats JSON pour l'utilisateur. À utiliser lorsque l'utilisateur souhaite obtenir des commentaires sur Greptile avant d'ouvrir un PR, en dehors d'un flux de révision de PR hébergé ou directement à partir d'une caisse locale.
