Gestisci un browser live con gli strumenti MCP di Playwright: naviga tra le pagine, fai clic, compila moduli, acquisisci screenshot, ispeziona console/rete e diagnostica i problemi dell'interfaccia utente in modo interattivo. Utilizza questa competenza ogni volta che un'attività prevede l'apertura di un URL, l'interazione con una pagina Web, l'acquisizione dell'aspetto di una pagina, il debug del comportamento del frontend o la verifica dello stato dell'interfaccia utente senza eseguire una suite di test completa.
