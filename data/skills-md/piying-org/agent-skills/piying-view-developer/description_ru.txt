Документация по разработке форм Piying-view — для создания форм в различных средах с использованием Schema + Valibot. Используйте, когда вам нужно: автоматическое преобразование требований естественного языка в схему piying, регистрация пользовательских компонентов/элементов управления, проверка формы, обработка динамического поведения (условное отключение/скрытие/прослушивание значений/связывание полей), управление макетом (композиция оболочки/смещение макета/группировка контейнеров), преобразование значений и контроль вывода (transformer/debounce/updateOn).
