Flujo de trabajo para depurar entornos de desarrollo local mediante la CLI de persecución. Utilice esta habilidad siempre que el usuario quiera investigar registros, depurar un servicio en ejecución, descubrir por qué algo se rompió, verificar errores recientes o validar el estado del servicio, incluso si no menciona "persecución" explícitamente. Active frases como "verifique los registros", "algo no funciona", "por qué falla X", "muéstreme errores", "qué está pasando con el servicio", "la aplicación no funciona", "clasificar esto" o "obténme una instantánea de depuración". Especialmente útil en proyectos que utilizan Chase para la gestión de registros.
