Leitfaden zum Erstellen von Funktionen, Seiten, Tabellen, Formularen, Themen und Navigation in dieser Next.js 16-Shadcn-Dashboard-Vorlage. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine neue Seite hinzufügen, ein Funktionsmodul erstellen, eine Datentabelle erstellen, ein Formular hinzufügen, Navigationselemente konfigurieren, ein Thema hinzufügen, eine RBAC-Zugriffskontrolle einrichten oder mit den Mustern und Konventionen des Dashboards arbeiten möchte. Wird auch beim Hinzufügen von Routen unter /dashboard, beim Arbeiten mit Clerk auth/orgs/billing, beim Erstellen von Schein-APIs oder beim Ändern der Seitenleiste ausgelöst. Auch wenn der Benutzer „Dashboard“ nicht explizit erwähnt – wenn er diesem Projekt Benutzeroberflächen, Seiten oder Funktionen hinzufügt, nutzen Sie diese Fähigkeit.
