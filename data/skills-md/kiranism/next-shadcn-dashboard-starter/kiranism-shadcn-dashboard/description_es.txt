Guía para crear funciones, páginas, tablas, formularios, temas y navegación en esta plantilla de panel shadcn de Next.js 16. Utilice esta habilidad siempre que el usuario desee agregar una nueva página, crear un módulo de funciones, crear una tabla de datos, agregar un formulario, configurar elementos de navegación, agregar un tema, configurar el control de acceso RBAC o trabajar con los patrones y convenciones del panel. También se activa al agregar rutas en /dashboard, trabajar con Clerk auth/orgs/billing, crear API simuladas o modificar la barra lateral. Incluso si el usuario no menciona explícitamente el "panel de control", si agrega interfaz de usuario, páginas o funciones a este proyecto, utilice esta habilidad.
