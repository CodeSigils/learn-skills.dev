Guida per la creazione di funzionalità, pagine, tabelle, moduli, temi e navigazione in questo modello di dashboard shadcn Next.js 16. Utilizza questa competenza ogni volta che l'utente desidera aggiungere una nuova pagina, creare un modulo di funzionalità, creare una tabella di dati, aggiungere un modulo, configurare elementi di navigazione, aggiungere un tema, impostare il controllo dell'accesso RBAC o utilizzare i modelli e le convenzioni del dashboard. Si attiva anche quando si aggiungono percorsi in /dashboard, si lavora con Clerk auth/orgs/billing, si creano API fittizie o si modifica la barra laterale. Anche se l'utente non menziona esplicitamente "dashboard", se sta aggiungendo interfaccia utente, pagine o funzionalità a questo progetto, utilizza questa competenza.
