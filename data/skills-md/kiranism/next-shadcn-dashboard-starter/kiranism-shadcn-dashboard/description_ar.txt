دليل لإنشاء الميزات والصفحات والجداول والنماذج والموضوعات والتنقل في قالب لوحة المعلومات Next.js 16 shadcn هذا. استخدم هذه المهارة عندما يريد المستخدم إضافة صفحة جديدة، أو إنشاء وحدة ميزات، أو إنشاء جدول بيانات، أو إضافة نموذج، أو تكوين عناصر التنقل، أو إضافة سمة، أو إعداد التحكم في الوصول إلى RBAC، أو العمل مع أنماط واصطلاحات لوحة المعلومات. يتم تشغيله أيضًا عند إضافة مسارات ضمن /dashboard، أو العمل مع Clerk auth/orgs/billing، أو إنشاء واجهات برمجة تطبيقات وهمية، أو تعديل الشريط الجانبي. حتى إذا لم يذكر المستخدم "لوحة المعلومات" بشكل صريح - إذا كان يضيف واجهة مستخدم أو صفحات أو ميزات إلى هذا المشروع، فاستخدم هذه المهارة.
