Руководство по созданию функций, страниц, таблиц, форм, тем и навигации в этом шаблоне панели мониторинга Next.js 16 shadcn. Используйте этот навык всякий раз, когда пользователь хочет добавить новую страницу, создать функциональный модуль, построить таблицу данных, добавить форму, настроить элементы навигации, добавить тему, настроить контроль доступа RBAC или поработать с шаблонами и соглашениями панели мониторинга. Также срабатывает при добавлении маршрутов в /dashboard, работе с Clerk auth/orgs/billing, создании макетов API или изменении боковой панели. Даже если пользователь не упоминает «панель мониторинга» явно — если он добавляет пользовательский интерфейс, страницы или функции в этот проект, используйте этот навык.
