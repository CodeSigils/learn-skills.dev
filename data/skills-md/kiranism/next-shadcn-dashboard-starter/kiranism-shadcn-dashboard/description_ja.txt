この Next.js 16 shadcn ダッシュボード テンプレートで機能、ページ、テーブル、フォーム、テーマ、ナビゲーションを構築するためのガイド。ユーザーが新しいページの追加、機能モジュールの作成、データ テーブルの構築、フォームの追加、ナビゲーション項目の構成、テーマの追加、RBAC アクセス制御の設定、またはダッシュボードのパターンと規則の操作を行う場合には、このスキルを使用します。 /dashboard の下にルートを追加するとき、Clerk auth/orgs/billing を操作するとき、モック API を作成するとき、またはサイドバーを変更するときにもトリガーされます。ユーザーが「ダッシュボード」について明示的に言及していなくても、UI、ページ、または機能をこのプロジェクトに追加している場合は、このスキルを使用します。
