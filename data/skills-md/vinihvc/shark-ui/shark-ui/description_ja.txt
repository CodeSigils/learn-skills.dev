Ark UI ベースの shadcn スタイル レジストリ用の Shark UI スキル。コンポーネント (オーバーレイ、メニュー、ポップオーバー、シート、ダイアログ)、コレクション駆動コントロール (コンボボックス、選択、リスト パターン)、フィールド/フォーム、サイドバーまたはチャート ドキュメント パターン、Tailwind v4 トークンを実装またはデバッグする場合、または Radix/shadcn サンプルを Shark に移行する場合に使用します。 `@shark/*`、`components.json`、またはレジストリ スタイルの追加/検索/差分ワークフローで shadcn CLI を使用する場合にも適用されます。
