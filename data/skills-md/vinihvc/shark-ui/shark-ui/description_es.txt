Habilidad Shark UI para el registro estilo shadcn basado en Ark UI. Úselo al implementar o depurar componentes (superposiciones, menús, ventanas emergentes, hojas, cuadros de diálogo), controles basados ​​en colecciones (cuadro combinado, selección, patrones de lista), campos/formularios, patrones de documentos de gráficos o barras laterales, tokens Tailwind v4 o migrar ejemplos de Radix/shadcn a Shark. También se aplica cuando se utiliza la CLI de shadcn con `@shark/*`, `components.json` o flujos de trabajo add/search/diff de estilo registro.
