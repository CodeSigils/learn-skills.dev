Создавайте красивые прототипы пользовательского интерфейса и готовые к использованию проекты React на естественном языке. Поддерживает два режима: (1) каркас проекта React + Tailwind v4 + shadcn/ui с реальными файлами компонентов, токенами проектирования oklch и правильной структурой проекта; (2) автономный HTML-прототип с настраиваемыми свойствами CSS, нулевыми зависимостями, открывается непосредственно в браузере. Используйте для ЛЮБОГО запроса пользовательского интерфейса: «дизайн», «прототип», «создать страницу», «пользовательский интерфейс», «прототип», «целевая страница», «панель мониторинга», «макет», «проект React», «shadcn», «попутный ветер», «покажи мне, как это выглядит». Всегда используйте этот навык вместо специального HTML — качество вывода значительно лучше.
