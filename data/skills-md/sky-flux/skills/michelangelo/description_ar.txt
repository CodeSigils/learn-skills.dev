قم بإنشاء نماذج أولية جميلة لواجهة المستخدم ومشاريع React جاهزة للإنتاج من اللغة الطبيعية. يدعم وضعين: (1) React + Tailwind v4 + shadcn/ui مشروع سقالة مع ملفات المكونات الحقيقية، ورموز تصميم oklch، وبنية المشروع المناسبة؛ (2) نموذج HTML قائم بذاته مع خصائص CSS مخصصة، بدون تبعيات، يفتح مباشرة في المتصفح. يُستخدم لأي طلب واجهة مستخدم: "تصميم"، "نموذج أولي"، "إنشاء صفحة"، "واجهة مستخدم"، "نموذج أولي"، "صفحة مقصودة"، "لوحة معلومات"، "نموذج نموذجي"، "مشروع تفاعلي"، "shadcn"، "Tailwind"، "أرني كيف يبدو". استخدم دائمًا هذه المهارة بدلاً من لغة HTML المخصصة، حيث تكون جودة الإخراج أفضل بشكل كبير.
