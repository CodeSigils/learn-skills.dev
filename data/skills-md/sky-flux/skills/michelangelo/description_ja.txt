自然言語から美しい UI プロトタイプと本番環境に対応した React プロジェクトを生成します。 2 つのモードをサポートします: (1) 実際のコンポーネント ファイル、oklch デザイン トークン、および適切なプロジェクト構造を使用した React + Tailwind v4 + shadcn/ui プロジェクト スキャフォールド。 (2) CSS カスタム プロパティを備えた自己完結型 HTML プロトタイプで、依存関係はなく、ブラウザーで直接開きます。あらゆる UI リクエストに使用します:「デザイン」、「プロトタイプ」、「ページの作成」、「UI」、「プロトタイプ」、「ランディング ページ」、「ダッシュボード」、「モックアップ」、「React プロジェクト」、「shadcn」、「Tailwind」、「見た目を見せて」。常にアドホック HTML ではなくこのスキルを使用してください。出力品質は大幅に向上します。
