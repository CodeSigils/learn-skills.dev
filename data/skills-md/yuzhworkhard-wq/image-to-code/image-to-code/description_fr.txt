Flux de travail d'image vers code de 750 px au niveau des pixels et de découpage haute résolution. Utilisez-le lorsque le Codex doit convertir l'image d'interface utilisateur, la capture d'écran, la maquette de conception d'application/Web, l'exportation Figma ou la conception d'une image longue actuellement sélectionnée en code et générer des actifs de tranche PNG transparents indépendants. Il convient à une restauration proportionnelle stricte 1:1, une largeur de plan de travail précise de 750 pixels, un découpage amélioré haute résolution, une suppression du flou et de l'arrière-plan, l'utilisation d'image2/imagegen pour extraire le PNG transparent si nécessaire, du texte modifiable, des graphiques simples en tant que vecteurs/codes natifs, le code final nécessitant une adaptation réactive, ou pour les tâches qui nécessitent d'exporter/importer le travail fini vers Figma sous forme de couches modifiables.
