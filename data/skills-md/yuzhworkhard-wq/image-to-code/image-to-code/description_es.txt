Flujo de trabajo de corte de imagen a código de 750 píxeles con perfección de píxeles y de alta definición. Se utiliza cuando Codex necesita convertir la imagen de la interfaz de usuario, la captura de pantalla, la maqueta de aplicación/diseño web, la exportación de Figma o la imagen de diseño larga actualmente seleccionada en código y generar recursos de corte PNG transparentes independientes. Adecuado para una reproducción proporcional estricta 1:1, ancho de la mesa de trabajo exactamente 750 px, corte mejorado de alta definición, antidesenfoque y eliminación de fondo, uso de image2/imagegen para extraer PNG transparente cuando sea necesario, texto editable, gráficos simples como vector/código nativo, con el código final que necesita una adaptación responsiva, o tareas que requieren exportar/importar el trabajo terminado hacia/desde Figma como capas editables.
