Преобразование изображения на уровне 750 пикселей в код и рабочий процесс нарезки с высоким разрешением. Используйте это, когда Кодексу необходимо преобразовать выбранное в данный момент изображение пользовательского интерфейса, снимок экрана, макет дизайна приложения/веб-сайта, экспортировать Figma или спроектировать длинное изображение в код и вывести независимые прозрачные ресурсы фрагментов PNG. Он подходит для строгого пропорционального восстановления 1:1, ширины артборда точно 750 пикселей, масштабирования срезов с высоким разрешением, защиты от размытия и удаления фона, использования image2/imagegen для извлечения прозрачного PNG, когда это необходимо, редактируемого текста, простой графики в виде собственных векторов/кода, с конечным кодом, требующим адаптивной адаптации, или для задач, требующих экспорта/импорта готовой работы в Figma в виде редактируемых слоев.
