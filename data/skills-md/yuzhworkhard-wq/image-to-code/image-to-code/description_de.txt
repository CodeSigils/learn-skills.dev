750-Pixel-Bild-zu-Code und hochauflösender Slicing-Workflow auf Pixelebene. Verwenden Sie dies, wenn Codex das aktuell ausgewählte UI-Bild, den Screenshot, das App-/Webdesign-Mockup, den Figma-Export oder das Design-Langbild in Code konvertieren und unabhängige transparente PNG-Slice-Assets ausgeben muss. Es eignet sich für eine strikte proportionale 1:1-Wiederherstellung, eine Zeichenflächenbreite von genau 750 Pixel, hochskaliertes Slicing mit hoher Auflösung, Anti-Unschärfe und Hintergrundentfernung, die Verwendung von image2/imagegen zum Extrahieren von transparentem PNG bei Bedarf, bearbeitbaren Text, einfache Grafiken als native Vektoren/Code, wobei der endgültige Code eine reaktionsfähige Anpassung erfordert, oder für Aufgaben, bei denen das fertige Werk als bearbeitbare Ebenen nach Figma exportiert/importiert werden muss.
