مستوى البكسل 750 بكسل من الصورة إلى الكود وسير عمل التقطيع عالي الدقة. استخدم هذا عندما يحتاج Codex إلى تحويل صورة واجهة المستخدم المحددة حاليًا، أو لقطة الشاشة، أو نموذج تصميم التطبيق/الويب، أو تصدير Figma، أو تصميم صورة طويلة إلى كود وإخراج أصول شريحة PNG شفافة مستقلة. إنها مناسبة للاستعادة التناسبية الصارمة بنسبة 1:1، وعرض اللوحة الفنية بدقة 750 بكسل، والتقطيع عالي الدقة، ومكافحة التمويه وإزالة الخلفية، باستخدام image2/imagegen لاستخراج PNG الشفاف عند الضرورة، ونص قابل للتحرير، ورسومات بسيطة كمتجهات/كود أصلي، مع الكود النهائي الذي يحتاج إلى تكيف سريع الاستجابة، أو للمهام التي تتطلب تصدير/استيراد العمل النهائي إلى Figma كطبقات قابلة للتحرير.
