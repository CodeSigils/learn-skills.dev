Realiza una revisión de relaciones públicas de alto nivel por parte de un ingeniero senior de los cambios de código, clasifica qué tan críticas son las superficies modificadas y decide si las relaciones públicas pueden autofusionarse o deben acudir a un revisor humano. Utilice esta habilidad para revisiones de solicitudes de extracción, diferencias de ramas, diferencias pegadas, cambios no confirmados, URL de PR de GitHub o solicitudes como "revisar mis cambios", "verificar este PR", "está listo", "puedo fusionar esto", "necesita un revisor", "qué tan riesgoso es este cambio", "qué podría romper", "auditar esta diferencia", "verificación de cordura antes de presionar" o "se ve limpio". Cubre corrección, seguridad, contratos, radio de explosión, correcciones fallidas anteriores en la misma ruta de código, pruebas, mantenibilidad y regresiones, evitando agresivamente falsos positivos ruidosos. Diseñado para funcionar de manera confiable incluso con modelos más pequeños/baratos.
