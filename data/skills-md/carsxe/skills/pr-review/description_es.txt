Utilice esta habilidad para revisiones de solicitudes de extracción, diferencias de ramas, diferencias pegadas, cambios no confirmados, URL de PR de GitHub o solicitudes como "revisar mis cambios", "verificar este PR", "está listo", "puedo fusionar esto", "necesita un revisor", "qué tan riesgoso es este cambio", "qué podría romper", "auditar esta diferencia", "verificación de cordura antes de presionar" o "se ve limpio". Cubre la corrección, la seguridad, los contratos, el radio de explosión, las correcciones fallidas anteriores en la misma ruta del código, las pruebas, la mantenibilidad y las regresiones, al tiempo que se evitan agresivamente los falsos positivos ruidosos. Diseñado para funcionar de manera confiable incluso con modelos más pequeños/baratos.
