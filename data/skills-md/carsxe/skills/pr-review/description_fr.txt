Effectue un examen des relations publiques par un ingénieur senior à haut signal sur les modifications de code, classe le degré de critique des surfaces modifiées et décide si les relations publiques peuvent être auto-fusionnées ou doivent être confiées à un réviseur humain. Utilisez cette compétence pour les révisions de demandes d'extraction, les différences de branche, les différences collées, les modifications non validées, les URL de PR GitHub ou les requêtes telles que « vérifier mes modifications », « vérifier ce PR », « est-ce prêt », « puis-je fusionner ceci », « cela a-t-il besoin d'un réviseur », « à quel point ce changement est-il risqué », « qu'est-ce que ce changement pourrait casser », « auditer cette différence », « vérification d'intégrité avant de pousser » ou « est-ce que cela a l'air propre ». Couvre l'exactitude, la sécurité, les contrats, le rayon d'explosion, les correctifs ayant échoué dans le même chemin de code, les tests, la maintenabilité et les régressions tout en évitant de manière agressive les faux positifs bruyants. Conçu pour fonctionner de manière fiable même avec des modèles plus petits/moins chers.
