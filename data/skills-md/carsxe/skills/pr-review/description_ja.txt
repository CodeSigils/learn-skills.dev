コード変更の高信号シニア エンジニア PR レビューを実行し、変更されたサーフェスの重要度を分類し、PR を自己マージできるか、人間のレビュー担当者に依頼する必要があるかを決定します。このスキルは、プル リクエストのレビュー、ブランチの差分、貼り付けられた差分、コミットされていない変更、GitHub PR URL、または「変更を確認する」、「この PR を確認する」、「準備はできていますか」、「これをマージできますか」、「レビュー担当者は必要ですか」、「この変更のリスクはどれくらいですか」、「これは何が壊れる可能性がありますか」、「この差分を監査します」、「プッシュする前の健全性チェック」、または「これはきれいに見えますか」などのリクエストに使用します。ノイズの多い誤検知を積極的に回避しながら、正確性、セキュリティ、コントラクト、爆発範囲、同じコード パスで以前に失敗した修正、テスト、保守性、回帰をカバーします。小型/安価なモデルでも確実に動作するように設計されています。
