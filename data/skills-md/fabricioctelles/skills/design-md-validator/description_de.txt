Validieren Sie DESIGN.md-Dateien anhand der offiziellen Google-Spezifikation mithilfe des CLI-Linters „@google/design.md“. Funktioniert mit lokalen Dateien und Remote-URLs. Verwenden Sie diese Option, wenn der Benutzer eine DESIGN.md linten, die Spezifikationskonformität überprüfen, fehlerhafte Token-Referenzen finden, WCAG-Kontrastverhältnisse überprüfen, zwei Versionen unterscheiden, Token in das Tailwind- oder DTCG-Format exportieren oder eine Design-Systemdatei auf strukturelle Korrektheit prüfen möchte. Wird bei Erwähnungen von „Validate DESIGN.md“, „Lint DESIGN.md“, „Check My Design.md“, „Design.md Spec Compliance“, „WCAG Contrast Check“, „Broken Token References“, „Design Token Validation“, „Export Design Tokens“, „Diff Design Systems“, „Design.md Audit“, „@google/design.md“, „npx design.md Lint“, „Design System Validation“, „Frontmatter Tokens“ oder jede andere Anfrage ausgelöst um eine DESIGN.md-Datei zu überprüfen.
