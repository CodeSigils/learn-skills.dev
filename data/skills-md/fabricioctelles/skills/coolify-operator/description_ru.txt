Местный оператор Coolify для самостоятельного развертывания платформы. Используйте, когда или обычно упоминаете «coolify», «deploy no Coolify», «listar/reiniciar/redeploy aplicações», «ver logs Coolify», «API/CLI Coolify», «coolify Gerenciar servidores/databases/apps», или «coolify context». Автоматизация развертывания и настройка через API REST или официальный интерфейс командной строки.
