Cette compétence doit être utilisée lorsque l'utilisateur choisit d'utiliser l'API Pier Cloud (Lighthouse) pour la gestion des clients dans un nouveau — y compris l'authentification JWT, la liste des contextes, les espaces de travail et les visualisations de données FinOps. Actionner toujours ce qui est nécessaire d'intégrer, d'automatiser ou de supprimer des applications sur la plate-forme Pier Cloud via Python, Node.js ou cURL.
