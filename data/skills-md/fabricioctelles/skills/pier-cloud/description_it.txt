Questa abilità deve essere utilizzata quando l'utente ha bisogno di utilizzare un'API Pier Cloud (Lighthouse) per la gestione dei clienti in negozio, inclusa l'autenticazione JWT, l'elenco dei contesti, le aree di lavoro e la visualizzazione dei dati FinOps. Agisci sempre se hai bisogno di integrare, automatizzare o depurare le chiamate sulla piattaforma Pier Cloud tramite Python, Node.js o cURL.
