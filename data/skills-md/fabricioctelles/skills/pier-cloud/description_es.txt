Esta habilidad debe usarse cuando el usuario necesita consumir una API Pier Cloud (Lighthouse) para la gestión de clientes en la nube, incluida la autenticación JWT, listas de contextos, espacios de trabajo y visualizaciones de datos FinOps. Siempre es necesario integrar, automatizar o depurar chamadas en la plataforma Pier Cloud a través de Python, Node.js o cURL.
