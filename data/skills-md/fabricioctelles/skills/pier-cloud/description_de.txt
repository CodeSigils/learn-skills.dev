Diese Fähigkeit muss verwendet werden, wenn der Benutzer die API Pier Cloud (Lighthouse) nutzt, um neue Benutzer zu verwalten – einschließlich JWT-Authentifizierung, Kontextlisten, Arbeitsbereichen und Visualisierungen von FinOps-Daten. Es ist immer notwendig, Daten über Python, Node.js oder cURL auf die Pier Cloud-Plattform zu integrieren, zu automatisieren oder abzurufen.
