Эти навыки необходимо использовать, когда или обычно вы используете API Pier Cloud (Lighthouse) для создания учетных записей в новых — включая аутентификацию JWT, списки контекстов, рабочие области и визуализацию данных FinOps. Всегда существует необходимость интеграции, автоматизации или очистки платформы Pier Cloud через Python, Node.js или cURL.
