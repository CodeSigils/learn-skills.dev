Cree, valide y enriquezca paquetes Open Knowledge Format (OKF): la especificación abierta para representar el conocimiento organizacional como archivos de rebajas con contenido frontal YAML. Úselo cuando el usuario mencione 'OKF', 'Formato abierto de conocimiento', 'paquete de conocimientos', 'paquete OKF', 'crear una base de conocimientos para agentes', 'validar OKF', 'convertir a OKF', 'enriquecer documentos de conocimientos', 'conocimientos legibles por agentes', 'wiki LLM', 'catálogo de conocimientos', 'kcmd', o desea estructurar el conocimiento como archivos de rebajas para el consumo de agentes de IA. También se utiliza cuando el usuario tiene un directorio de archivos de rebajas y desea hacerlos interoperables o conformes con el estándar OKF. Incluso para solicitudes simples como "hacer que esta carpeta cumpla con OKF", la habilidad tiene reglas estructurales críticas que el agente necesita.
