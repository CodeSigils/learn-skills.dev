Crea, convalida e arricchisci i bundle OKF (Open Knowledge Format): le specifiche aperte per rappresentare la conoscenza organizzativa come file markdown con frontmatter YAML. Da utilizzare quando l'utente menziona "OKF", "Open Knowledge Format", "pacchetto di conoscenze", "pacchetto OKF", "crea una base di conoscenza per gli agenti", "convalida OKF", "converti in OKF", "arricchisci documenti di conoscenza", "conoscenza leggibile dall'agente", "wiki LLM", "catalogo della conoscenza", "kcmd" o desidera strutturare la conoscenza come file di markdown per l'agente AI consumo. Da utilizzare anche quando l'utente dispone di una directory di file markdown e desidera renderli interoperabili o conformi allo standard OKF. Anche per richieste semplici come "rendi questa cartella conforme a OKF": l'abilità ha regole strutturali critiche di cui l'agente ha bisogno.
