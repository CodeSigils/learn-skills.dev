Создавайте, проверяйте и обогащайте пакеты Open Knowledge Format (OKF) — открытую спецификацию для представления организационных знаний в виде файлов уценки с интерфейсом YAML. Используйте, когда пользователь упоминает «OKF», «Открытый формат знаний», «Пакет знаний», «Пакет OKF», «создать базу знаний для агентов», «проверить OKF», «преобразовать в OKF», «обогатить документы знаний», «знания, читаемые агентом», «LLM wiki», «каталог знаний», «kcmd» или хочет структурировать знания в виде файлов уценки для использования агентом ИИ. Также используйте, когда у пользователя есть каталог файлов уценки и он хочет сделать их совместимыми или совместимыми со стандартом OKF. Даже для простых запросов типа «сделать эту папку соответствующей OKF» — навык имеет важные структурные правила, необходимые агенту.
