Créez, validez et enrichissez les bundles Open Knowledge Format (OKF) — la spécification ouverte pour représenter les connaissances organisationnelles sous forme de fichiers markdown avec le frontmatter YAML. À utiliser lorsque l'utilisateur mentionne « OKF », « Open Knowledge Format », « knowledge bundle », « OKF bundle », « créer une base de connaissances pour les agents », « valider OKF », « convertir en OKF », « enrichir les documents de connaissances », « connaissances lisibles par l'agent », « wiki LLM », « catalogue de connaissances », « kcmd » ou souhaite structurer les connaissances sous forme de fichiers markdown pour la consommation des agents IA. À utiliser également lorsque l'utilisateur dispose d'un répertoire de fichiers markdown et souhaite les rendre interopérables ou conformes à la norme OKF. Même pour des requêtes simples telles que « rendre ce dossier conforme à OKF » : la compétence comporte des règles structurelles critiques dont l'agent a besoin.
