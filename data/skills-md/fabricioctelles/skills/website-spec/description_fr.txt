Version hors ligne autonome de The Website Spécification : fonctionne sans accès au réseau, idéale pour les environnements isolés, les flux de travail à confidentialité maximale et les projets internes. Auditez, validez et corrigez les sites Web sur 128 sujets couvrant les fondements HTML, le référencement, l'accessibilité (WCAG), les en-têtes de sécurité, les URI bien connus, la préparation des agents (llms.txt, MCP, A2A), les performances (Core Web Vitals), la confidentialité, la résilience et i18n. Chaque sujet est étiqueté obligatoire/recommandé/facultatif/à éviter avec des conseils de mise en œuvre et des étapes de vérification. À utiliser lorsque l'utilisateur demande « auditer mon site », « que devrait contenir mon site Web », « X est-il requis », « vérifier l'accessibilité », « examen des en-têtes de sécurité », « état de préparation des agents », « liste de contrôle frontale », « ce qui manque », « meilleures pratiques pour les sites Web » ou toute question sur la qualité du site soutenue par les normes WHATWG, W3C, IETF et WCAG. Vérifiez https://spécification.website/ pour la version en ligne et mise à jour.
