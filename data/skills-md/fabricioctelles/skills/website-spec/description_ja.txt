Web サイト仕様の自己完結型オフライン バージョン — ネットワーク アクセスなしで実行され、エアギャップ環境、最大限のプライバシーのワークフロー、および内部プロジェクトに最適です。 HTML 基盤、SEO、アクセシビリティ (WCAG)、セキュリティ ヘッダー、既知の URI、エージェントの準備状況 (llms.txt、MCP、A2A)、パフォーマンス (Core Web Vitals)、プライバシー、復元力、i18n を含む 128 のトピックに対して Web サイトを監査、検証、修正します。各トピックには必須/推奨/オプション/回避のタグが付けられており、実装のガイダンスと検証手順が示されています。ユーザーが「サイトを監査してください」、「Web サイトに何を備えるべきか」、「X は必要ですか」、「アクセシビリティの確認」、「セキュリティ ヘッダーのレビュー」、「エージェントの準備状況」、「フロントエンド チェックリスト」、「不足しているもの」、「Web サイトのベスト プラクティス」、または WHATWG、W3C、IETF、および WCAG 標準に裏付けられたサイト品質に関する質問をする場合に使用します。オンラインおよび更新バージョンについては、https://specation.website/ を確認してください。
