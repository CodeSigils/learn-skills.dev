Esta habilidad debe usarse cuando un desarrollador o equipo necesita revisar, validar o auditar el código de front-end antes de lanzar un sitio web o una página HTML a producción. Se activan solicitudes como "ejecutar la lista de verificación del front-end", "validar mi front-end", "revisar mi sitio antes del lanzamiento" o cuando el usuario solicita una revisión estructurada de HTML, CSS, JavaScript, accesibilidad, rendimiento, seguridad o calidad del diseño.
