Diese Fähigkeit sollte verwendet werden, wenn ein Entwickler oder ein Team den Front-End-Code überprüfen, validieren oder prüfen muss, bevor er eine Website oder HTML-Seite in die Produktion bringt. Wird bei Anfragen wie „Front-End-Checkliste ausführen“, „Mein Front-End validieren“, „Meine Website vor dem Start prüfen“ ausgelöst oder wenn der Benutzer eine strukturierte Überprüfung von HTML, CSS, JavaScript, Barrierefreiheit, Leistung, Sicherheit oder Designqualität anfordert.
