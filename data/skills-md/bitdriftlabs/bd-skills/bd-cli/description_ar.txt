دليل لتشغيل bitdrift bd CLI وتحليل بيانات حساب bitdrift المباشرة - سير العمل، والمخططات، والجلسات، والمشكلات، والمفاتيح، والموصلات، والتحقيقات في صحة التطبيق. يتم التشغيل عندما يريد المستخدم تشغيل أوامر bd، أو فحص بيانات النظام الأساسي المباشرة، أو تصحيح أخطاء أحد التطبيقات باستخدام bitdrift، أو إنشاء سير عمل أو تحريره، أو قراءة المخططات أو المقاييس، أو أعطال الفرز، أو فحص الجداول الزمنية للجلسة، أو أتمتة عمليات bitdrift من واجهة سطر الأوامر.
