ابحث عن وثائق bitdrift وفسرها لسلوك المنتج وإعداد SDK وواجهة برمجة التطبيقات ومستندات الخدمة وأفضل الممارسات. يُستخدم عندما يسأل المستخدم عن كيفية عمل bitdrift، أو كيفية إعداد SDK، أو كيفية تكوين ميزة، أو ما تفعله واجهة برمجة التطبيقات أو الخدمة، أو للحصول على إرشادات مفاهيمية حول bitdrift - حتى لو لم يذكروا الوثائق صراحةً. يتم تشغيله أيضًا عندما يذكر المستخدم /bd-docs أو يسأل عن مفاهيم bitdrift أو البنية أو أدلة التكامل.
