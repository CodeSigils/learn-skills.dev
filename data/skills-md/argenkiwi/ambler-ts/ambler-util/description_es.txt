Crea o extrae módulos de utilidades en el directorio utils/ de un proyecto de Ambler. Use esto siempre que las defaultUtils de un nodo necesiten dependencias externas de npm/jsr, contengan lógica reutilizable en múltiples nodos o tengan implementaciones demasiado complejas para incorporarlas en línea, incluso si el usuario simplemente dice "agregar una utilidad", "extraer este asistente", "compartir esta función", "crear una utilidad" o "este código se está volviendo demasiado largo para el nodo". Cuando un usuario crea un nodo que importa un paquete npm o tiene una lógica asíncrona compleja, sugiera de forma proactiva el uso de esta habilidad.
