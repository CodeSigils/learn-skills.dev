Crée ou extrait des modules utilitaires dans le répertoire utils/ d'un projet Ambler. Utilisez-le chaque fois que defaultUtils d'un nœud a besoin de dépendances npm/jsr externes, contient une logique réutilisable sur plusieurs nœuds ou a des implémentations trop complexes à intégrer - même si l'utilisateur dit simplement « ajouter un util », « extraire cet assistant », « partager cette fonction », « créer un utilitaire » ou « ce code devient trop long pour le nœud ». Lorsqu'un utilisateur crée un nœud qui importe un package npm ou qui possède une logique asynchrone complexe, suggérez de manière proactive d'utiliser cette compétence.
