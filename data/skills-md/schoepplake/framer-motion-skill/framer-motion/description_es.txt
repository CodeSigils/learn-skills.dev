Patrones de animación de nivel de producción para React y Next.js usando Motion (anteriormente Framer Motion). Utilice esta habilidad siempre que el usuario solicite animar componentes, agregar transiciones, crear efectos activados por desplazamiento, implementar transiciones de página, animaciones de diseño, interacciones de gestos o cualquier tipo de movimiento/animación en un proyecto de React o Next.js. También se activa cuando el código importa 'framer-motion', 'motion/react' o 'motion/react-client', o cuando el usuario menciona: animación, transición, aparición gradual, diapositiva, paralaje, animación de desplazamiento, animación de salida, AnimatePresence, motion.div, resorte, gesto, arrastre, animación de desplazamiento, escalonamiento, whileInView o animación de diseño.
