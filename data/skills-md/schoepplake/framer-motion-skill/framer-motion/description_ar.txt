أنماط الرسوم المتحركة على مستوى الإنتاج لـ React وNext.js باستخدام Motion (المعروفة سابقًا باسم Framer Motion). استخدم هذه المهارة عندما يطلب المستخدم تحريك المكونات، أو إضافة انتقالات، أو إنشاء تأثيرات يتم تشغيلها بالتمرير، أو تنفيذ انتقالات الصفحة، أو رسوم تخطيطية متحركة، أو تفاعلات الإيماءات، أو أي نوع من الحركة/الرسوم المتحركة في مشروع React أو Next.js. يتم تشغيله أيضًا عندما يستورد الكود "framer-motion"، أو "motion/react"، أو "motion/react-client"، أو عندما يذكر المستخدم: الرسوم المتحركة، أو الانتقال، أو التلاشي، أو الشريحة، أو اختلاف المنظر، أو الرسوم المتحركة للتمرير، أو الرسوم المتحركة للخروج، أو AnimatePresence، أوmotion.div، أو الربيع، أو الإيماءة، أو السحب، أو الرسوم المتحركة بالتحويم، أو stagger، أو whileInView، أو الرسوم المتحركة للتخطيط.
