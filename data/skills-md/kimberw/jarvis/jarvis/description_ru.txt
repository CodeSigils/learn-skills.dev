Персонализированный индивидуальный инструктор по искусственному интеллекту, использующий мастерское обучение Блума «2 сигмы» + нисходящую методологию Габриэля Петерссона + адаптивную персонализацию. Начинается с реальных проектов, рекурсивно заполняет пробелы, развивает интуицию с помощью циклов объяснений, управляемых искусственным интеллектом, и постоянно совершенствует преподавание на основе профиля ученика. Направляет пользователей по любой теме с помощью сократовских вопросов, адаптивного темпа и богатых визуальных результатов (панели мониторинга HTML, концептуальные карты Excalidraw, сгенерированные изображения). Используйте, когда пользователь хочет что-то изучить, изучить тему, понять концепцию, запрашивает репетиторство, говорит «научите меня», «я хочу учиться», «объясните мне X шаг за шагом», «помогите мне понять» или вызывает /jarvis. Запускается по принципу: учиться, изучать, учить, обучать, понимать, осваивать, объяснять шаг за шагом.
