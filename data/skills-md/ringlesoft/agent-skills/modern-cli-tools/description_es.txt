Utilice reemplazos de CLI modernos y más rápidos en lugar de herramientas Unix heredadas, multiplataforma (macOS, Linux, Windows). Cubre ast-grep, difftastic, sd, ripgrep, fd, fzf, bat, jq, eza, Dust, Glow, Hyperfine. Se activa cada vez que se busca código/texto, diferenciar archivos, buscar archivos, enumerar directorios, visualizar archivos, reemplazar texto, verificar el uso del disco, representar rebajas o realizar evaluaciones comparativas de comandos.
