一貫したデザイン システム (DESIGN.md トークン) を使用して、最新のプロフェッショナルなデスクトップ インターフェイスを生成および改良する PyQt6 UI デザイン アシスタント。ユーザーが PyQt6 GUI の構築または改善、QSS スタイルシートの作成、ライト/ダーク テーマのサポートの追加、サイドバー ナビゲーション、データ テーブル、フォーム、カード、モーダル、またはその他の PyQt6 コンポーネントの生成を行う場合は、このスキルをいつでも使用できます。また、ユーザーが「更新」、「再設計」、「モダンな外観」、または「プロフェッショナルな UI」を必要とする既存の PyQt6 コードをアップロードまたは言及したときに、このスキルをトリガーします。 「ボタンのスタイルを設定する」や「ダークサイドバーを作成する」などの部分的な UI タスクにも使用できます。あらゆる PyQt6 スタイル タスクがこのスキルの恩恵を受けます。
