PyQt6-UI-Design-Assistent, der moderne, professionelle Desktop-Oberflächen mithilfe eines konsistenten Designsystems (DESIGN.md-Tokens) generiert und verfeinert. Verwenden Sie diese Fähigkeit, wann immer der Benutzer eine PyQt6-GUI erstellen oder verbessern, QSS-Stylesheets schreiben, Unterstützung für helle/dunkle Themen hinzufügen, Seitenleistennavigation, Datentabellen, Formulare, Karten, Modalitäten oder andere PyQt6-Komponenten generieren möchte. Lösen Sie diese Fähigkeit auch aus, wenn der Benutzer vorhandenen PyQt6-Code hochlädt oder erwähnt, der eine „Aktualisierung“, „Neugestaltung“, „modernes Aussehen“ oder „professionelle Benutzeroberfläche“ benötigt. Verwenden Sie diese Fähigkeit sogar für teilweise UI-Aufgaben wie „Meine Schaltfläche gestalten“ oder „Eine dunkle Seitenleiste erstellen“ – jede PyQt6-Styling-Aufgabe profitiert von dieser Fähigkeit.
