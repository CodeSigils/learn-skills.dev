مساعد تصميم PyQt6 UI الذي يقوم بإنشاء وتحسين واجهات سطح المكتب الحديثة والمهنية باستخدام نظام تصميم متسق (رموز DESIGN.md). استخدم هذه المهارة كلما أراد المستخدم: إنشاء واجهة المستخدم الرسومية PyQt6 أو تحسينها، أو كتابة أوراق أنماط QSS، أو إضافة دعم السمة الفاتحة/الغامقة، أو إنشاء التنقل في الشريط الجانبي، أو جداول البيانات، أو النماذج، أو البطاقات، أو الوسائط، أو أي مكون آخر من مكونات PyQt6. قم أيضًا بتشغيل هذه المهارة عندما يقوم المستخدم بتحميل أو ذكر كود PyQt6 الحالي الذي يحتاج إلى "تحديث" أو "إعادة تصميم" أو "مظهر حديث" أو "واجهة مستخدم احترافية". استخدمها حتى في مهام واجهة المستخدم الجزئية مثل "تصميم الزر الخاص بي" أو "إنشاء شريط جانبي مظلم" - أي مهمة تصميم في PyQt6 تستفيد من هذه المهارة.
