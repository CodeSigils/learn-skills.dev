Asistente de diseño de interfaz de usuario PyQt6 que genera y perfecciona interfaces de escritorio profesionales y modernas utilizando un sistema de diseño consistente (tokens DESIGN.md). Utilice esta habilidad siempre que el usuario quiera: crear o mejorar una GUI de PyQt6, escribir hojas de estilo QSS, agregar soporte para temas claros/oscuros, generar navegación en la barra lateral, tablas de datos, formularios, tarjetas, modales o cualquier otro componente de PyQt6. También active esta habilidad cuando el usuario cargue o mencione un código PyQt6 existente que necesite una "actualización", un "rediseño", una "apariencia moderna" o una "IU profesional". Úselo incluso para tareas parciales de la interfaz de usuario como "darle estilo a mi botón" o "crear una barra lateral oscura": cualquier tarea de estilo de PyQt6 se beneficia de esta habilidad.
