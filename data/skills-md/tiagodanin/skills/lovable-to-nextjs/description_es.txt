Convierta proyectos de Lovable/Vite React a Next.js App Router con exportación estática para páginas de GitHub. Maneja la reestructuración completa del proyecto: enrutamiento, SEO (metadatos, OpenGraph, JSON-LD), mapa del sitio, canalización de CI/CD de GitHub Actions, datos/carpetas como CMS basado en archivos y límites adecuados de "uso del cliente". Utilice esta habilidad siempre que el usuario mencione la conversión de un proyecto de Vite a Next.js, la migración de Lovable a Next.js, la reestructuración de un React SPA para exportación estática, la configuración de un sitio de Next.js con SEO y la implementación de GitHub Pages, o quiera convertir un proyecto de Vite/React en un sitio de Next.js estático listo para producción. También se activa cuando el usuario tiene un proyecto generado por Lovable y desea una mejor configuración de SEO, rendimiento o implementación.
