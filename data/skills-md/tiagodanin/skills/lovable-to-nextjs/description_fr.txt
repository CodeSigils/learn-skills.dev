Convertissez les projets Lovable/Vite React en Next.js App Router avec exportation statique pour les pages GitHub. Gère la restructuration complète du projet : routage, référencement (métadonnées, OpenGraph, JSON-LD), plan du site, pipeline CI/CD GitHub Actions, données/dossier en tant que CMS basé sur des fichiers et limites appropriées d'utilisation du client. Utilisez cette compétence chaque fois que l'utilisateur mentionne la conversion d'un projet Vite vers Next.js, la migration de Lovable vers Next.js, la restructuration d'un React SPA pour l'exportation statique, la configuration d'un site Next.js avec le déploiement de pages SEO et GitHub, ou souhaite transformer un projet Vite/React en un site Next.js statique prêt pour la production. Déclenchez également lorsque l'utilisateur a un projet généré par Lovable et souhaite une meilleure configuration de référencement, de performances ou de déploiement.
