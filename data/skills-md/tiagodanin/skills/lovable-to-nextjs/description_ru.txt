Преобразование проектов Lovable/Vite React в маршрутизатор приложений Next.js со статическим экспортом для страниц GitHub. Выполняет полную реструктуризацию проекта: маршрутизацию, SEO (метаданные, OpenGraph, JSON-LD), карту сайта, конвейер CI/CD GitHub Actions, данные/папки в виде файловой CMS и правильные границы использования клиента. Используйте этот навык всякий раз, когда пользователь упоминает о преобразовании проекта Vite в Next.js, переходе с Lovable на Next.js, реструктуризации React SPA для статического экспорта, настройке сайта Next.js с SEO и развертыванием страниц GitHub или хочет превратить проект Vite/React в готовый к работе статический сайт Next.js. Также срабатывает, когда у пользователя есть проект, созданный Lovable, и он хочет улучшить SEO, производительность или настройку развертывания.
