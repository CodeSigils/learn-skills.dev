تحويل مشاريع Lovable/Vite React إلى Next.js App Router مع تصدير ثابت لصفحات GitHub. يتعامل مع إعادة هيكلة المشروع بالكامل: التوجيه، وتحسين محركات البحث (البيانات التعريفية، OpenGraph، JSON-LD)، وخريطة الموقع، وخط أنابيب GitHub Actions CI/CD، والبيانات/المجلد كنظام إدارة محتوى قائم على الملفات، وحدود "استخدام العميل" المناسبة. استخدم هذه المهارة عندما يذكر المستخدم تحويل مشروع Vite إلى Next.js، أو الانتقال من Lovable إلى Next.js، أو إعادة هيكلة React SPA للتصدير الثابت، أو إعداد موقع Next.js مع نشر SEO وGitHub Pages، أو يريد تحويل مشروع Vite/React إلى موقع Next.js ثابت جاهز للإنتاج. يتم تشغيله أيضًا عندما يكون لدى المستخدم مشروع تم إنشاؤه بشكل محبوب ويريد تحسين محركات البحث أو الأداء أو إعداد النشر.
