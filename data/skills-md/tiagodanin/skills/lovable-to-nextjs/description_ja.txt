GitHub Pages の静的エクスポートを使用して、Lovable/Vite React プロジェクトを Next.js App Router に変換します。プロジェクト全体の再構築を処理します: ルーティング、SEO (メタデータ、OpenGraph、JSON-LD)、サイトマップ、GitHub Actions CI/CD パイプライン、ファイルベースの CMS としてのデータ/フォルダー、および適切な「使用クライアント」境界。ユーザーが Vite プロジェクトの Next.js への変換、Lovable から Next.js への移行、静的エクスポート用の React SPA の再構築、SEO および GitHub Pages 展開を備えた Next.js サイトのセットアップについて言及する場合、または Vite/React プロジェクトを本番環境に対応した静的 Next.js サイトに変換したい場合には、必ずこのスキルを使用してください。また、ユーザーが Lovable で生成されたプロジェクトを所有しており、より良い SEO、パフォーマンス、またはデプロイメント設定を望んでいる場合にもトリガーされます。
