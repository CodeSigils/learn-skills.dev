Sumsub 検証ウィジェットがない独自の Web ページに、Sumsub Device Intelligence (Fisherman JS モジュール) を追加します。ログイン、サインアップ、パスワード リセット、2FA、チェックアウト、または不正行為を検出したい価値の高いアクションです。ユーザーが「ログイン/サインアップにデバイス インテリジェンスを追加する」、「カスタム ページでデバイスのフィンガープリントを行う」、「Fisherman スタンドアロン/セルフホストを使用する」、「プラットフォーム イベントの継続的な監視」、「KYC 前のデバイス チェック」、「サインアップ時にマルチアカウントを検出する」、または「キャプチャされたデバイスで金融トランザクションを送信する」を要求したときにトリガーされます。ループ全体 (動作アクセス トークン、@sumsub/fisherman init + フィンガープリント、イベントの確認 (プラットフォーム イベント / 金融トランザクション / 作成申請者)、結果の読み取り、サンドボックス、ゴーライブ) をカバーします。ページにすでに Sumsub WebSDK が埋め込まれている場合はスキップします。デバイス インテリジェンスが内部に組み込まれている場合は、`sumsub-integrate-dint-websdk` を使用します。
