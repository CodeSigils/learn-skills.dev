Registrieren Sie die Krypto-Wallet-Adressen, die von einer Organisation kontrolliert werden, sodass Sumsub den Adresseigentum ohne einen Menschen klären kann. Importiert Adressen in großen Mengen in das Wallet-Adressbuch über „POST /resources/kyt/walletAddress/import“ und registriert eine einzelne Adresse für einen bestimmten Antragsteller über „POST /resources/api/applicants/{applicantId}/zahlungen“. TRIGGER, wenn der Benutzer fragt: „Unsere Wallet-Adressen hochladen/importieren/registrieren“, „Adressen zum Wallet-Adressbuch hinzufügen“, „das Krypto-Wallet eines Benutzers als Zahlungsmethode registrieren“, sagt, dass Reiseregelanfragen „nicht automatisch abgeglichen“ werden oder „immer in der manuellen Überprüfung landen“ oder fragt, wie man die manuelle Bestätigung derselben Adresse bei jedem Austausch stoppen kann. SKIP zum Nachschlagen, welcher VASP eine *Gegenpartei*-Adresse besitzt (d. h. Zuordnung – verwenden Sie „sumsub-api-generic“ gegen „/resources/api/wallet-attribution“), zum Bestätigen des Eigentums an einer bestimmten Transaktion (verwenden Sie „sumsub-integrate-travel-rule“) und zum Löschen von Adressen (kein öffentlicher Endpunkt – verwenden Sie das Dashboard).
