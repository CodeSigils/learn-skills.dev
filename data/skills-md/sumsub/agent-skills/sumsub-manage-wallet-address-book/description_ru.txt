Зарегистрируйте адреса криптокошелька, которые контролирует организация, чтобы Sumsub мог определить право собственности на адрес без участия человека. Массовый импорт адресов в адресную книгу кошелька через POST /resources/kyt/walletAddress/import и регистрация одного адреса для конкретного заявителя через POST /resources/api/applicants/{applicantId}/pays. ТРИГГЕР, когда пользователь просит «загрузить/импортировать/зарегистрировать адреса нашего кошелька», «добавить адреса в адресную книгу кошелька», «зарегистрировать криптокошелек пользователя в качестве способа оплаты», говорит, что запросы Travel Rule «не совпадают автоматически» или «всегда попадают на проверку вручную», или спрашивает, как прекратить подтверждать один и тот же адрес вручную при каждом обмене. SKIP для поиска того, какой VASP владеет адресом *контрагента* (то есть атрибуции — используйте sumsub-api-generic вместо /resources/api/wallet-attribution), для подтверждения владения одной конкретной транзакцией (используйте sumsub-integrate-travel-rule) и для удаления адресов (нет общедоступной конечной точки — используйте панель управления).
