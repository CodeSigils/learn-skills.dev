Sumsub가 지원하는 신원 문서를 쿼리하고 편집합니다. 내장된 카탈로그(documentsByCountries)를 읽으십시오. 국가별로 지원되는 문서 유형, 양면인지 여부, 기본 OCR 필드와 사용 가능한 OCR 필드를 읽어보세요. 전역 설정 API를 통해 클라이언트 자체 지원 문서 재정의(idDocSettings.countryMappings)를 편집합니다. 사용자가 "어느 국가/문서 유형이 필드 X를 지원하는지", "DEU에서 여권에 대해 어떤 필드를 수집할 수 있는지", "프랑스에서 ID 카드가 양면인지"라고 묻는 경우 또는 지원되는 문서를 변경하거나 문서 유형을 전환하거나 국가에 대해 수집된 필드를 편집하려는 경우 TRIGGER. 레벨이나 설문지를 생성하려면 건너뛰세요(전용 기술 사용).
