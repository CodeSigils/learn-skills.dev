Запросить И отредактировать поддерживаемые Sumsub документы, удостоверяющие личность. ПРОЧИТАЙТЕ встроенный каталог (documentsByCountries) — какие типы документов поддерживаются в каждой стране, являются ли они двусторонними, какие поля OCR используются по умолчанию, а какие доступны. РЕДАКТИРОВАНИЕ собственных переопределений поддерживаемых документов клиента (idDocSettings.countryMappings) через API глобальных настроек. ТРИГГЕР, когда пользователь спрашивает «какие страны/типы документов поддерживают поле X», «какие поля я могу собрать для паспорта в DEU», «является ли удостоверение личности двусторонним во Франции», ИЛИ хочет изменить поддерживаемые документы/переключить тип документа/отредактировать собранные поля для страны. ПРОПУСТИТЕ создание уровней или анкет (используйте специальные навыки).
