Consulta Y edita los documentos de identidad admitidos por Sumsub. LEA el catálogo integrado (documentsByCountries): qué tipos de documentos se admiten por país, si son de doble cara, qué campos de OCR son predeterminados y qué campos están disponibles. EDITAR las anulaciones de documentos compatibles del propio cliente (idDocSettings.countryMappings) a través de la API de configuración global. DISPARA cuando el usuario pregunta "qué países/tipos de documentos admiten el campo X", "qué campos puedo recopilar para un pasaporte en DEU", "el documento de identidad es de doble cara en Francia" O quiere cambiar los documentos admitidos/alternar un tipo de documento/editar los campos recopilados para un país. SALTAR para crear niveles o cuestionarios (use las habilidades dedicadas).
