Sumsub でサポートされている ID ドキュメントをクエリおよび編集します。組み込みカタログ (documentsByCountries) を読んでください。国ごとにどの文書タイプがサポートされているか、両面であるかどうか、どの OCR フィールドがデフォルトか使用可能かがわかります。グローバル設定 API を使用して、クライアント独自のサポートされているドキュメントのオーバーライド (idDocSettings.countryMappings) を編集します。ユーザーが「どの国 / 文書タイプがフィールド X をサポートしているか」、「DEU のパスポートでどのフィールドを収集できるか」、「フランスでは ID カードは両面ですか」を尋ねた場合、またはサポートされている文書を変更するか、文書タイプを切り替えるか、または国の収集フィールドを編集したい場合にトリガーされます。レベルまたはアンケートを作成する場合はスキップします (専用のスキルを使用します)。
