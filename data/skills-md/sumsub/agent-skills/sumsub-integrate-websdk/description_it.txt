Ricetta end-to-end per aggiungere Sumsub KYC a un sito Web o a un'app Web tramite Sumsub WebSDK. TRIGGER quando l'utente chiede di "integrare/incorporare/aggiungere Sumsub", "mostrare il widget KYC", "aggiungere WebSDK", "verificare gli utenti con Sumsub sul frontend", fornisce un levelName esistente che desidera inserire in una pagina o chiede come collegare token di accesso/eventi del ciclo di vita/webhook per la verifica di Sumsub in un progetto arbitrario. Copre l'intero ciclo: configurazione del livello, firma del token di accesso lato server, init snsWebSdk (vanilla canonical, ricetta React), eventi del ciclo di vita del client, aggiornamento del token, fonte di verità tramite webhook + richiedente GET, test sandbox, elenco di controllo go-live. SKIP per creare il payload preimpostato livello/questionario/POA stesso (utilizzare le competenze di pari livello) o per chiamate API solo backend senza frontend (utilizzare `sumsub-api-generic`).
