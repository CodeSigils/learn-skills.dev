Recette de bout en bout pour ajouter Sumsub KYC à un site Web ou une application Web via le Sumsub WebSDK. DÉCLENCHEMENT lorsque l'utilisateur demande "intégrer/intégrer/ajouter Sumsub", "afficher le widget KYC", "ajouter WebSDK", "vérifier les utilisateurs avec Sumsub sur le frontend", fournit un nom de niveau existant qu'il souhaite brancher sur une page, ou demande comment câbler les jetons d'accès/événements de cycle de vie/webhooks pour la vérification Sumsub dans un projet arbitraire. Couvre toute la boucle : configuration du niveau, signature du jeton d'accès côté serveur, init snsWebSdk (canonique vanille, recette React), événements du cycle de vie du client, actualisation du jeton, source de vérité via webhooks + candidat GET, test du bac à sable, liste de contrôle de mise en ligne. SKIP pour créer la charge utile de niveau/questionnaire/POA-preset elle-même (utilisez les compétences frères) ou pour les appels d'API backend uniquement sans frontend (utilisez `sumsub-api-generic`).
