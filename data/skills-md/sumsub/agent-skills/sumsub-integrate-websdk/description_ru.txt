Комплексный рецепт добавления Sumsub KYC на веб-сайт или веб-приложение с помощью Sumsub WebSDK. ТРИГГЕР, когда пользователь запрашивает «интегрировать/встроить/добавить Sumsub», «показать виджет KYC», «добавить WebSDK», «проверить пользователей с помощью Sumsub на внешнем интерфейсе», предоставляет существующее имя уровня, которое они хотят подключить к странице, или спрашивает, как подключить токены доступа/события жизненного цикла/веб-перехватчики для проверки Sumsub в произвольном проекте. Охватывает весь цикл — настройку уровня, подписание токена доступа на стороне сервера, инициализацию snsWebSdk (ванильный канонический вариант, рецепт React), события жизненного цикла клиента, обновление токена, источник истины через веб-перехватчики + GET заявителя, тестирование в песочнице, контрольный список для ввода в эксплуатацию. ПРОПУСТИТЕ для создания самой полезной нагрузки уровня/вопросника/POA (используйте родственные навыки) или для вызовов API только для серверной части без внешнего интерфейса (используйте sumsub-api-generic).
