Komplettes Rezept zum Hinzufügen von Sumsub KYC zu einer Website oder Web-App über das Sumsub WebSDK. TRIGGER, wenn der Benutzer nach „Sumsub integrieren/einbetten/hinzufügen“, „KYC-Widget anzeigen“, „WebSDK hinzufügen“ oder „Benutzer mit Sumsub im Frontend überprüfen“ fragt, einen vorhandenen LevelNamen angibt, den er in eine Seite einbinden möchte, oder fragt, wie Zugriffstoken/Lebenszyklusereignisse/Webhooks für die Sumsub-Verifizierung in einem beliebigen Projekt verknüpft werden sollen. Deckt die gesamte Schleife ab – Level-Setup, serverseitige Zugriffstoken-Signatur, snsWebSdk-Init (Vanilla Canonical, React-Rezept), Client-Lebenszyklusereignisse, Token-Aktualisierung, Source-of-Truth über Webhooks + Bewerber-GET, Sandbox-Tests, Go-Live-Checkliste. SKIP zum Erstellen der Level-/Fragebogen-/POA-voreingestellten Nutzlast selbst (verwenden Sie die Geschwister-Skills) oder für reine Backend-API-Aufrufe ohne Frontend (verwenden Sie „sumsub-api-generic“).
