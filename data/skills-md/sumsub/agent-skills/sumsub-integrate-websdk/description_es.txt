Receta de extremo a extremo para agregar Sumsub KYC a un sitio web o aplicación web a través de Sumsub WebSDK. DISPARADOR cuando el usuario solicita "integrar/incrustar/agregar Sumsub", "mostrar el widget KYC", "agregar WebSDK", "verificar usuarios con Sumsub en la interfaz", proporciona un nombre de nivel existente que desean conectar a una página o pregunta cómo conectar tokens de acceso/eventos de ciclo de vida/webhooks para la verificación de Sumsub en un proyecto arbitrario. Cubre todo el ciclo: configuración de nivel, firma de token de acceso del lado del servidor, inicio de snsWebSdk (canónico básico, receta de React), eventos del ciclo de vida del cliente, actualización de token, fuente de verdad a través de webhooks + GET del solicitante, pruebas de espacio aislado, lista de verificación de puesta en marcha. SALTE para crear el nivel/cuestionario/carga útil preestablecida de POA (use las habilidades de hermanos), o para llamadas API solo de backend sin interfaz (use `sumsub-api-generic`).
