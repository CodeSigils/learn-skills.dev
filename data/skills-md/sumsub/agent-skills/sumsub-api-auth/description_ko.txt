앱 토큰 + 비밀 키(HMAC-SHA256 요청 서명)를 사용하여 Sumsub API에 인증합니다. 사용자가 "Sumsub API 요청 호출/서명/인증"을 요청하거나, `api.sumsub.com`에 대한 `401 Unauthorized`/서명 오류를 디버그하거나 `X-App-Token` / `X-App-Access-Sig` / `X-App-Access-Ts` 헤더가 있는 작업 요청 예시가 필요한 경우 TRIGGER. 이 저장소의 보다 구체적인 기술(설문지/레벨/워크플로/POA 사전 설정/일반)이 이미 사용자의 실제 작업을 다루는 경우에만 건너뛰십시오. 이러한 기술은 요청에 동일한 방식으로 서명하며 인증 심층 분석에만 이 기술이 필요합니다.
