App Token + 秘密キー (HMAC-SHA256 リクエスト署名) を使用して Sumsub API に対して認証します。ユーザーが「Sumsub API リクエストの呼び出し/署名/認証」を要求した場合、「401 Unauthorized」/「api.sumsub.com」に対する署名エラーをデバッグした場合、または「X-App-Token」/「X-App-Access-Sig」/「X-App-Access-Ts」ヘッダーを使用した動作するリクエストの例が必要な場合にトリガーされます。このリポジトリのより具体的なスキル (アンケート/レベル/ワークフロー/POA プリセット/ジェネリック) がユーザーの実際のタスクをすでにカバーしている場合にのみスキップします。これらのスキルは同じ方法でリクエストに署名しており、認証の詳細を確認する場合にのみこのスキルが必要です。
