Autenticazione all'API Sumsub con un token app + chiave segreta (firma della richiesta HMAC-SHA256). SI ATTIVA quando l'utente chiede di "chiamare/firmare/autenticare le richieste API Sumsub", esegue il debug di "401 Unauthorized"/errori di firma su "api.sumsub.com" o necessita di un esempio di richiesta funzionante con intestazioni "X-App-Token" / "X-App-Access-Sig" / "X-App-Access-Ts". SALTA solo quando una competenza più specifica in questo repository (questionario/livello/flusso di lavoro/preimpostazione POA/generico) copre già l'attività effettiva dell'utente: tali competenze firmano le richieste allo stesso modo e necessitano solo di questa per approfondimenti di autenticazione.
