قم بالمصادقة على Sumsub API باستخدام رمز التطبيق + المفتاح السري (توقيع طلب HMAC-SHA256). TRIGGER عندما يطلب المستخدم "الاتصال / التوقيع / مصادقة طلبات Sumsub API"، أو تصحيح أخطاء التوقيع 401 Unauthorized / مقابل `api.sumsub.com`، أو يحتاج إلى مثال طلب عمل مع رؤوس `X-App-Token` / `X-App-Access-Sig` / `X-App-Access-Ts`. تخطي فقط عندما تغطي مهارة أكثر تحديدًا في هذا الريبو (الاستبيان/المستوى/سير العمل/توكيل رسمي محدد مسبقًا/عام) بالفعل المهمة الفعلية للمستخدم - توقع هذه المهارات الطلبات بنفس الطريقة وتحتاج فقط إلى هذه المهمة للتعمق في المصادقة.
