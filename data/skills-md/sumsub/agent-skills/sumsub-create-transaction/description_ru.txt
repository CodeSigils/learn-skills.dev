Отправьте транзакцию в Sumsub Transaction Monitoring (KYT) через ApplicantResource API. ТРИГГЕР, когда пользователь запрашивает «отправить/создать/отправить/записать транзакцию», «проверить правило KYT с транзакцией», опубликовать фиатный или криптографический платеж для мониторинга, прикрепить данные правила путешествия к переводу, зарегистрировать событие пользовательской платформы (регистрация/вход/сброс пароля/2FA-сброс) для мониторинга или отправить транзакцию для заявителя, который еще не существует (запрос создает их). SKIP для редактирования произвольных полей в существующей транзакции, для массового импорта (`/kyt/misc/txns/import`), для выборки/утверждения/отклонения транзакций, для управления правилами KYT или для потоков обмена данными по правилам путешествий, которые не являются созданием транзакции.
