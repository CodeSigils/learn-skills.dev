Soumettez une transaction à Sumsub Transaction Monitoring (KYT) via l'API ApplyResource. DÉCLENCHEMENT lorsque l'utilisateur demande de « soumettre/créer/envoyer/enregistrer une transaction », de « tester une règle KYT avec une transaction », de publier un paiement fiduciaire ou crypté pour la surveillance, de joindre des données de règle de voyage à un transfert, d'enregistrer un événement de plate-forme utilisateur (inscription/connexion/réinitialisation du mot de passe/réinitialisation 2FA) pour la surveillance, ou de soumettre une transaction pour un demandeur qui n'existe pas encore (la demande les crée). SKIP pour modifier des champs arbitraires sur une transaction existante, pour une importation groupée (`/kyt/misc/txns/import`), pour récupérer/approuver/rejeter des transactions, pour la gestion des règles KYT ou pour les flux d'échange de données Travel Rule qui ne sont pas une création de transaction.
