Envíe una transacción a Sumsub Transaction Monitoring (KYT) a través de la API ApplicantResource. DISPARAR cuando el usuario solicita "enviar/crear/enviar/registrar una transacción", "probar una regla KYT con una transacción", publicar un pago fiduciario o criptográfico para monitoreo, adjuntar datos de regla de viaje a una transferencia, registrar un evento de plataforma de usuario (registro/inicio de sesión/restablecimiento de contraseña/restablecimiento de 2FA) para monitoreo, o enviar una transacción para un solicitante que aún no existe (la solicitud los crea). SALTAR para editar campos arbitrarios en una transacción existente, para importación masiva (`/kyt/misc/txns/import`), para buscar/aprobar/rechazar transacciones, para administración de reglas KYT o para flujos de intercambio de datos de reglas de viaje que no son creación de transacciones.
