Invia una transazione a Sumsub Transaction Monitoring (KYT) tramite l'API ApplicantResource. SI ATTIVA quando l'utente chiede di "inviare/creare/inviare/registrare una transazione", "testare una regola KYT con una transazione", pubblicare un pagamento fiat o crittografico per il monitoraggio, allegare i dati della regola di viaggio a un trasferimento, registrare un evento della piattaforma utente (iscrizione/accesso/reimpostazione password/reimpostazione 2FA) per il monitoraggio o inviare una transazione per un richiedente che non esiste ancora (la richiesta li crea). SKIP per modificare campi arbitrari su una transazione esistente, per l'importazione di massa (`/kyt/misc/txns/import`), per recuperare/approvare/rifiutare transazioni, per la gestione delle regole KYT o per flussi di scambio dati di regole di viaggio che non sono la creazione di transazioni.
