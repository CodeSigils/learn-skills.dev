分析本机移动应用程序的设计系统（颜色、字体、圆角半径、边距、亮/暗）并生成主题 Sumsub Mobile SDK 与之匹配的代码 — iOS 上的 Swift（SNSTheme 子类）、Android 上的 Kotlin (SNSTheme DSL)。每当用户希望 Sumsub 验证/KYC 屏幕匹配其应用程序的外观时，请使用此选项 - “Sumsub SDK 的主题/品牌/样式”、“使验证屏幕与我的应用程序匹配”、“匹配我的 KYC 流程颜色和字体”、“自定义 SNSMobileSDK 外观” - 包括当他们不说“主题”但要求将 SDK 的颜色/字体与其应用程序对齐时。从项目中检测平台（iOS Xcode/Swift 与 Android Gradle/Kotlin）。扫描设计标记（iOS — asset-catalog `.colorset`、`Color`/`UIColor` 和 `Font` 扩展、重音/色调；Android — `colors.xml` / `themes.xml` / `values-night`、Compose `ColorScheme` / `Typography`），派生完整的调色板，并写入主题文件。跳过对主机应用程序本身进行主题化（这仅对 Sumsub SDK 进行样式化）、Web 主题化和 SDK 集成/设置（使用“sumsub-integrate-msdk”）。
