Analysieren Sie das Designsystem einer nativen mobilen App (Farben, Schriftarten, Eckenradien, Ränder, Hell/Dunkel) und generieren Sie Code, der das Sumsub Mobile SDK entsprechend thematisiert – Swift (SNSTheme-Unterklasse) auf iOS, Kotlin (SNSTheme DSL) auf Android. Verwenden Sie dies immer dann, wenn der Benutzer möchte, dass die Sumsub-Verifizierungs-/KYC-Bildschirme zum Aussehen seiner App passen – „Thema/Marke/Stil des Sumsub SDK“, „Verifizierungsbildschirm an meine App anpassen“, „meine KYC-Flow-Farben und -Schriftarten anpassen“, „SNSMobileSDK-Erscheinungsbild anpassen“ – auch wenn er nicht „Thema“ sagt, sondern darum bittet, die Farben/Schriftarten des SDK an seine App anzupassen. Erkennt die Plattform aus dem Projekt (iOS Xcode/Swift vs. Android Gradle/Kotlin). Sucht nach Design-Tokens (iOS – Asset-Katalog „.colorset“, „Color“/„UIColor“ und „Font“-Erweiterungen, Akzent/Farbton; Android – „colors.xml“ / „themes.xml“ / „values-night“, Compose „ColorScheme“ / „Typography“), leitet eine vollständige Palette ab und schreibt die Designdatei. ÜBERSPRINGEN Sie das Design der Host-App selbst (dadurch wird nur das Sumsub SDK formatiert), das Web-Design und die SDK-Integration/-Einrichtung (verwenden Sie „sumsub-integrate-msdk“).
