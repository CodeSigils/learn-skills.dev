قم بتحليل نظام تصميم تطبيق الهاتف المحمول الأصلي (الألوان، الخطوط، نصف قطر الزاوية، الهوامش، الضوء/الظلام) وقم بإنشاء تعليمات برمجية تحدد سمة Sumsub Mobile SDK لمطابقتها - Swift (فئة فرعية SNSTheme) على iOS، وKotlin (SNSTheme DSL) على Android. استخدم هذا عندما يريد المستخدم أن تتطابق شاشات التحقق من Sumsub / KYC مع مظهر تطبيقه - "المظهر / العلامة التجارية / نمط Sumsub SDK"، "جعل شاشة التحقق تتطابق مع تطبيقي"، "مطابقة ألوان وخطوط تدفق KYC"، "تخصيص مظهر SNSMobileSDK" - بما في ذلك عندما لا يقولون "المظهر" ولكن يطلبون محاذاة ألوان / خطوط SDK مع التطبيق الخاص بهم. يكتشف النظام الأساسي من المشروع (iOS Xcode/Swift vs Android Gradle/Kotlin). يقوم بالبحث عن الرموز المميزة للتصميم (iOS - كتالوج الأصول `.colorset`، `Color`/`UIColor` و`Font` ملحقات، لهجة / صبغة؛ Android - `colors.xml` / `themes.xml` / `values-night`، Compose `ColorScheme` / `Typography`)، يستمد لوحة كاملة، ويكتب ملف السمة. تخطي تصميم التطبيق المضيف نفسه (هذا فقط تصميم Sumsub SDK)، وتصميم الويب، وتكامل / إعداد SDK (استخدم `sumsub-integrate-msdk`).
