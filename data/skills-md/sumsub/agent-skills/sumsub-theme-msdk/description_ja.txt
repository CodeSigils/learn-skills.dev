ネイティブ モバイル アプリのデザイン システム (色、フォント、角の半径、余白、明暗) を分析し、それに一致するように Sumsub Mobile SDK のテーマを設定するコードを生成します。iOS では Swift (SNSTheme サブクラス)、Android では Kotlin (SNSTheme DSL) を使用します。ユーザーが Sumsub 検証 / KYC 画面を自分のアプリの外観に一致させたいとき（「Sumsub SDK のテーマ / ブランド / スタイル」、「認証画面を自分のアプリに一致させる」、「KYC フローの色とフォントに一致させる」、「SNSMobileSDK の外観をカスタマイズする」など）に使用します。これには、「テーマ」とは言わないが、SDK の色 / フォントをアプリに合わせるように要求する場合も含まれます。プロジェクトからプラットフォームを検出します (iOS Xcode/Swift と Android Gradle/Kotlin)。デザイン トークン (iOS — アセット カタログ `.colorset`、`Color`/`UIColor` & `Font` 拡張子、アクセント / 色合い、Android — `colors.xml` / `themes.xml` / `values-night`、Compose `ColorScheme` / `Typography`) をスキャンし、完全なパレットを導出し、テーマ ファイルを書き込みます。ホスト アプリ自体のテーマ (これは Sumsub SDK のスタイルのみを設定します)、Web テーマ、および SDK の統合/セットアップ (`sumsub-integrate-msdk` を使用します) の場合はスキップします。
