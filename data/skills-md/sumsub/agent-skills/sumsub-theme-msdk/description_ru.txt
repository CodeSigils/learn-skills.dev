Проанализируйте собственную систему дизайна мобильного приложения (цвета, шрифты, радиусы углов, поля, светлый/темный) и сгенерируйте код, который создаст темы Sumsub Mobile SDK в соответствии с ней — Swift (подкласс SNSTheme) на iOS, Kotlin (SNSTheme DSL) на Android. Используйте это всякий раз, когда пользователь хочет, чтобы экраны проверки Sumsub / KYC соответствовали внешнему виду его приложения — «тема / бренд / стиль Sumsub SDK», «сделать экран проверки соответствующим моему приложению», «соответствовать цветам и шрифтам моего потока KYC», «настроить внешний вид SNSMobileSDK» — в том числе когда он не говорит «тема», но просит привести цвета / шрифты SDK в соответствие со своим приложением. Определяет платформу проекта (iOS Xcode/Swift или Android Gradle/Kotlin). Сканирует токены дизайна (iOS — каталог ресурсов `.colorset`, расширения `Color`/`UIColor` и `Font`, акцент/оттенок; Android — `colors.xml` / `themes.xml` / `values-night`, Compose `ColorScheme` / `Typography`), получает полную палитру и записывает файл темы. ПРОПУСТИТЕ тематику самого хост-приложения (это касается только Sumsub SDK), веб-тем и интеграции/настройки SDK (используйте `sumsub-integrate-msdk`).
