分析本機行動應用程式的設計系統（顏色、字體、圓角半徑、邊距、亮/暗）並產生主題 Sumsub Mobile SDK 與之相符的程式碼 — iOS 上的 Swift（SNSTheme 子類）、Android 上的 Kotlin (SNSTheme DSL)。每當用戶希望 Sumsub 驗證/KYC 螢幕匹配其應用程式的外觀時，請使用此選項 - “Sumsub SDK 的主題/品牌/樣式”、“使驗證畫面與我的應用程式匹配”、“匹配我的 KYC 流程顏色和字體”、“自訂 SNSMobileSDK 外觀” - 包括當他們不說“字體/S SDK 字體時將他們不說/ SDK 外觀” - 包括當他們不說“字體/ SDK 字體時將與其主題對齊” - 包括當他們不說“字體/ SDK 字體”從專案中偵測平台（iOS Xcode/Swift 與 Android Gradle/Kotlin）。掃描設計標記（iOS — asset-catalog `.colorset`、`Color`/`UIColor` 和 `Font` 擴充、重音/色調；Android — `colors.xml` / `themes.xml` / `values-night`、Compose `orScheme` /`Typoy` /`Typo`、Compose `orScheme` /`Typography /` 主題。跳過對主機應用程式本身進行主題化（這僅對 Sumsub SDK 進行樣式化）、Web 主題化和 SDK 整合/設定（使用“sumsub-integrate-msdk”）。
