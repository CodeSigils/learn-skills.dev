Analysez le système de conception d'une application mobile native (couleurs, polices, rayons des coins, marges, clair/foncé) et générez du code qui thématise le SDK Sumsub Mobile pour qu'il corresponde : Swift (sous-classe SNSTheme) sur iOS, Kotlin (SNSTheme DSL) sur Android. Utilisez-le chaque fois que l'utilisateur souhaite que les écrans de vérification/KYC Sumsub correspondent à l'apparence de leur application — « thème/marque/style du SDK Sumsub », « faire en sorte que l'écran de vérification corresponde à mon application », « faire correspondre les couleurs et les polices de mon flux KYC », « personnaliser l'apparence de SNSMobileSDK » — y compris lorsqu'il ne dit pas « thème » mais demande d'aligner les couleurs/polices du SDK avec son application. Détecte la plateforme du projet (iOS Xcode/Swift vs Android Gradle/Kotlin). Analyse les jetons de conception (iOS — catalogue d'actifs `.colorset`, extensions `Color`/`UIColor` et `Font`, accent/teinte ; Android — `colors.xml` / `themes.xml` / `values-night`, Compose `ColorScheme` / `Typography`), dérive une palette complète et écrit le fichier de thème. SKIP pour le thème de l'application hôte elle-même (cela ne stylise que le SDK Sumsub), le thème Web et l'intégration/configuration du SDK (utilisez « sumsub-integrate-msdk »).
