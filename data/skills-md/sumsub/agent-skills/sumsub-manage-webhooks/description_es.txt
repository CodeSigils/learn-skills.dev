Administrar Sumsub `clientWebhooks` (suscripciones a eventos para solicitanteRevisado / solicitantePendiente / kytTxn / etc.): lee a través de `/resources/api/clientWebhooks`, escribe a través de `/resources/api/agent/clientWebhooks`. **Solo Sandbox**: los webhooks de producción deben ser creados por un humano directamente en el panel de Sumsub. DISPARAR cuando el usuario solicita "enumerar/recuperar/mostrar webhooks", "crear/agregar/registrar un webhook", "actualizar/editar/cambiar un objetivo de webhook/lista de eventos/secreto/algoritmo de firma" o "deshabilitar/volver a habilitar un webhook" en su inquilino de sandbox. SALTAR para la configuración de webhook de producción (remita al usuario al panel), para superficies de webhook no relacionadas (Stripe / videoIdent / Fireblocks / NFC / rutas de recepción específicas del socio en `/resources/webhooks/...`), para probar la entrega única (use el punto final `inspectionCallbacks/testWebhook` directamente) y para el enrutamiento de webhook solo KYT (que se administra en la sección KYT del panel de Sumsub). La API pública no expone estadísticas de eliminación o entrega por webhook; para eso, remita al usuario a la interfaz de usuario del panel de Sumsub.
