Управление Sumsub `clientWebhooks` (подписки на события для заявителяReviewed/claimPending/kytTxn/и т.д.) — читает через `/resources/api/clientWebhooks`, записывает через `/resources/api/agent/clientWebhooks`. **Только для песочницы** — рабочие вебхуки должны создаваться человеком непосредственно в панели управления Sumsub. ТРИГГЕР, когда пользователь запрашивает «составить список/получить/показать веб-перехватчики», «создать/добавить/зарегистрировать веб-перехватчик», «обновить/редактировать/изменить цель веб-перехватчика/список событий/секретный алгоритм/алгоритм подписи» или «отключить/повторно включить веб-перехватчик» для своего клиента песочницы. SKIP для настройки производственного веб-перехватчика (направьте пользователя на панель управления), для несвязанных поверхностей веб-перехватчика (Stripe / videoIdent / Fireblocks / NFC / пути получения для конкретного партнера в каталоге `/resources/webhooks/...`), для тестирования однократной доставки (используйте конечную точку `inspectionCallbacks/testWebhook` напрямую) и для маршрутизации веб-перехватчика только для KYT (управляется в KYT на панели управления Sumsub). раздел). Публичный API не предоставляет статистику удалений или доставки по каждому веб-перехватчику — для этого отправьте пользователя к пользовательскому интерфейсу панели управления Sumsub.
