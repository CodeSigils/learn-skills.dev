Sumsub `clientWebhooks` (applicantReviewed / applicantPending / kytTxn / などのイベント サブスクリプション) を管理します — `/resources/api/clientWebhooks` 経由で読み取り、`/resources/api/agent/clientWebhooks` 経由で書き込みます。 **サンドボックスのみ** — 運用 Webhook は人間が Sumsub ダッシュボードで直接作成する必要があります。ユーザーがサンドボックス テナントに対して「Webhook の一覧表示 / 取得 / 表示」、「Webhook の作成 / 追加 / 登録」、「Webhook ターゲット / イベント リスト / シークレット / 署名アルゴリズムの更新 / 編集 / 変更」、または「Webhook の無効化 / 再有効化」を要求したときにトリガーされます。 SKIP: 実稼働 Webhook セットアップ (ユーザーにダッシュボードを参照する)、無関係な Webhook サーフェス (Stripe / videoIdent / Fireblocks / NFC / `/resources/webhooks/...` にあるパートナー固有の受信パス)、1 回限りの配信のテスト (`inspectionCallbacks/testWebhook` エンドポイントを直接使用)、および KYT のみの Webhook ルーティング (Sumsub で管理される) の場合ダッシュボードのKYTセクション)。パブリック API は、削除や Webhook ごとの配信統計を公開しません。これらについては、ユーザーに Sumsub ダッシュボード UI を参照してください。
