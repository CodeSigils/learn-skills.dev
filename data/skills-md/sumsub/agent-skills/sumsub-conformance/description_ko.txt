테넌트의 DEPLOYED Sumsub 구성이 실제로 규정/정책 문서를 충족하는지 확인합니다. 각 요구 사항이 수집되고, 점수가 매겨지고, 시행되는 위치까지 추적하고 "수집되었지만 시행되지 않은" 격차에 플래그를 지정합니다. 사용자가 규정/정책/요구 사항 문서(PDF 또는 텍스트)를 가지고 있고 라이브 구성이 일치하는지 확인하고, 규정 준수 규칙에 대해 클라이언트 설정을 감사하고, "내 구성이 이 규정을 충족합니까?", "적합성/간격 분석 확인"을 원하거나 create-* 기술로 구성한 후 루프를 닫고 싶을 때 트리거합니다. 구성 구축(sumsub-create-*) 또는 규정에서 구성 계획 생성(sumsub-analyze-regulation)은 건너뛰세요. 규제가 없는 순수한 위생 린팅의 경우 이 기술의 번들 lint_config.py 하위 패스를 직접 실행하세요.
