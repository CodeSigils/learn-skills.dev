Verifique si la configuración de Sumsub IMPLEMENTADA de un inquilino realmente cumple con un documento de regulación/política, rastreando cada requisito hasta donde se recopila, califica y APLICA, y marca las brechas "recopiladas pero no aplicadas". DISPARAR cuando el usuario tiene un documento de regulación/política/requisitos (PDF o texto) y desea verificar que la configuración en vivo coincida con ella, auditar la configuración de un cliente según las reglas de cumplimiento, "mi configuración cumple con esta regulación", "verificar conformidad/análisis de brechas" o cerrar el ciclo después de configurar con las habilidades create-*. SALTAR para crear configuración (sumsub-create-*) o para generar un plan de configuración a partir de una regulación (sumsub-analyze-regulation). Para una eliminación de pelusa puramente higiénica y sin regulación, ejecute directamente el subpaso lint_config.py incluido en esta habilidad.
