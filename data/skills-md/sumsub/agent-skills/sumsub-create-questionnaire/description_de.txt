Erstellen oder aktualisieren Sie eine Sumsub KYC-Fragebogendefinition. POST „/resources/api/agent/questionnaires“ zum Erstellen eines neuen Pfads (fehlschlägt 409, wenn die ID vorhanden ist), PATCH des gleichen Pfads zum Aktualisieren (fehlschlägt 404, wenn die ID unbekannt ist), GET „/resources/api/agent/questionnaires/{id}“, um einen zurückzulesen. TRIGGER, wenn der Benutzer „einen Sumsub-Fragebogen erstellen/hinzufügen/erstellen/aktualisieren/bearbeiten“ auffordert oder eine Liste von Fragen/Abschnitten bereitstellt, die für einen Sumsub-Bewerberfluss bestimmt sind, oder auf eine Fragebogen-ID/Definition verweist, die gepostet oder gepatcht werden soll. SKIP für andere Sumsub-Entitäten (Ebenen, Arbeitsabläufe, Bewerber), Übermittlung von Fragebogendaten (Antworten) oder Nicht-Sumsub-Formularersteller.
