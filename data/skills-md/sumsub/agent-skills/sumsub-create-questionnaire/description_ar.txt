قم بإنشاء أو تحديث تعريف استبيان Sumsub KYC. POST `/resources/api/agent/questionnaires` لإنشاء جديد (فشل 409 إذا كان المعرف موجودًا)، تصحيح نفس المسار للتحديث (فشل 404 إذا كان المعرف غير معروف)، GET `/resources/api/agent/questionnaires/{id}` لقراءة واحدة مرة أخرى. يتم تشغيله عندما يطلب المستخدم "إنشاء / إضافة / بناء / تحديث / تحرير استبيان Sumsub"، أو يقدم قائمة بالأسئلة / الأقسام المخصصة لتدفق مقدم طلب Sussub، أو يشير إلى معرف / تعريف الاستبيان المراد نشره أو تصحيحه. تخطي لكيانات Sumsub الأخرى (المستويات، ومهام سير العمل، والمتقدمين)، أو إرسال بيانات الاستبيان (الإجابات)، أو منشئي النماذج غير Sumsub.
