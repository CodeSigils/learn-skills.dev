Cree o actualice una definición de cuestionario Sumsub KYC. POST `/resources/api/agent/questionnaires` para crear uno nuevo (falla en 409 si existe la identificación), PATCH la misma ruta para actualizar (falla en 404 si la identificación es desconocida), GET `/resources/api/agent/questionnaires/{id}` para volver a leer uno. DISPARA cuando el usuario solicita "crear/agregar/construir/actualizar/editar un cuestionario de Sumsub", o proporciona una lista de preguntas/secciones destinadas a un flujo de solicitantes de Sumsub, o hace referencia a una identificación/definición de cuestionario para PUBLICAR o PARCHEAR. SALTE para otras entidades de Sumsub (niveles, flujos de trabajo, solicitantes), envío de datos de cuestionarios (respuestas) o creadores de formularios que no sean de Sumsub.
