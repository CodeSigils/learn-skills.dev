Sumsub KYC アンケート定義を作成または更新します。新規作成するには `/resources/api/agent/questionnaires` を POST (ID が存在する場合は失敗 409)、更新するには同じパスに PATCH (ID が不明の場合は失敗 404)、1 つ読み戻すには GET `/resources/api/agent/questionnaires/{id}` を実行します。ユーザーが「Sumsub アンケートの作成 / 追加 / 構築 / 更新 / 編集」を要求したとき、または Sumsub 申請者フロー向けの質問のリスト / セクションを提供したとき、または POST または PATCH されるアンケート ID / 定義を参照したときにトリガーします。他の Sumsub エンティティ (レベル、ワークフロー、応募者)、アンケート データ (回答) 送信、または非 Sumsub フォーム ビルダーの場合はスキップします。
