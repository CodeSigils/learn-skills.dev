Fallback generale per qualsiasi attività API Sumsub che NON corrisponde a una competenza più specifica (ad esempio `create-sumsub-level`, `sumsub-create-questionnaire`, `sumsub-api-auth`). TRIGGER quando l'utente desidera chiamare, ispezionare o eseguire il debug di un endpoint API Sumsub non altrimenti coperto: recupero di candidati, elenco di livelli, revisione di hit AML, esportazione di dati, generazione di token SDK, qualsiasi cosa contro "api.sumsub.com". La procedura: individua l'endpoint corretto nello schema OpenAPI, leggi la sua forma di richiesta/risposta, crea il payload, firma con App Token e convalida. SALTA ogni volta che una competenza Sumsub più ristretta copre già la richiesta.
