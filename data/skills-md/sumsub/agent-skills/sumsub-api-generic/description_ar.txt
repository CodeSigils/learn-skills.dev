احتياطي التقاط الكل لأي مهمة Sumsub API لا تتطابق مع مهارة أكثر تحديدًا (على سبيل المثال، `create-sumsub-level`، `sumsub-create-questionnaire`، `sumsub-api-auth`). يتم تشغيله عندما يريد المستخدم الاتصال بنقطة نهاية Sumsub API التي لم تتم تغطيتها بطريقة أخرى أو فحصها أو تصحيح أخطائها — جلب المتقدمين، وإدراج المستويات، ومراجعة نتائج مكافحة غسل الأموال (AML)، وتصدير البيانات، وإنشاء رموز SDK المميزة، وأي شيء ضد `api.sumsub.com`. الإجراء — تحديد نقطة النهاية الصحيحة في مخطط OpenAPI، وقراءة شكل الطلب/الاستجابة، وإنشاء الحمولة، والتوقيع باستخدام App Token، والتحقق من الصحة. قم بالتخطي عندما تغطي مهارة Sumsub الأضيق الطلب بالفعل.
