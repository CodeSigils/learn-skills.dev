Catch-All-Fallback für jede Sumsub-API-Aufgabe, die NICHT mit einer spezifischeren Fähigkeit übereinstimmt (z. B. „create-sumsub-level“, „sumsub-create-questionnaire“, „sumsub-api-auth“). TRIGGER, wenn der Benutzer einen Sumsub-API-Endpunkt aufrufen, prüfen oder debuggen möchte, der nicht anderweitig abgedeckt ist – Bewerber abrufen, Ebenen auflisten, AML-Treffer überprüfen, Daten exportieren, SDK-Token generieren, alles gegen „api.sumsub.com“. Das Verfahren: Suchen Sie den richtigen Endpunkt im OpenAPI-Schema, lesen Sie seine Anforderungs-/Antwortform, erstellen Sie die Nutzlast, signieren Sie mit App-Token und validieren Sie. ÜBERSPRINGEN, wenn eine engere Sumsub-Fertigkeit die Anfrage bereits abdeckt.
