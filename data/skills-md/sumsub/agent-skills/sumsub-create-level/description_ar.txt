POST `/resources/applicants/-/levels` لإنشاء مسار جديد، تصحيح نفس المسار للتحديث (المعرف في النص)، احصل على `/resources/applicants/-/levels/{id}` لقراءة واحدة مرة أخرى. TRIGGER عندما يطلب المستخدم "إنشاء / إضافة / بناء / تحديث / تحرير مستوى Sumsub"، يقدم قائمة بالخطوات المطلوبة لتدفق مقدم الطلب (الهوية / الصورة الشخصية / إثبات الإقامة / الاستبيان / طرق الدفع / التحقق من البريد الإلكتروني أو الهاتف / KYB / التوقيع الإلكتروني)، أو يريد مستوى مرتبطًا باستبيان محدد DefId. تخطي لكيانات Sumsub الأخرى (الاستبيانات، وسير العمل، والمتقدمين) أو لتعديلات الإعدادات الفرعية لمرة واحدة التي لا تغطيها المواصفات المدمجة (استخدم `sumsub-api-generic` لتلك).
