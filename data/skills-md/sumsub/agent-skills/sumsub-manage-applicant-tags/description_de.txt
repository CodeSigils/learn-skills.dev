Fügen Sie Tags in einem Sumsub-Bewerberprofil über die öffentliche API hinzu, ersetzen oder entfernen Sie sie – „POST /resources/applicants/{applicantId}/tags/add“ (additiv), „POST .../tags“ (den vollständigen Satz überschreiben), „DELETE .../tags“ (entfernen), Zurücklesen über „GET .../one“. TRIGGER, wenn der Benutzer auffordert, „einen Bewerber zu markieren/die Markierung aufzuheben“, „Bewerber-Tags hinzuzufügen/zu entfernen/zu löschen“, „ein Bewerberprofil zu kennzeichnen“ oder „den Tag-Satz eines Bewerbers zu ersetzen“. SKIP für Transaktions-Tags, Tag-Definitionen mit Bewertungsgewichtungen oder Bewerberrisikobewertung (verwenden Sie „sumsub-create-kyt-rules“), für automatisiertes Tagging innerhalb von Verifizierungsworkflows (verwenden Sie „sumsub-create-workflow“) und zum Abonnieren von Tag-Change-Webhooks (verwenden Sie „sumsub-manage-webhooks“).
