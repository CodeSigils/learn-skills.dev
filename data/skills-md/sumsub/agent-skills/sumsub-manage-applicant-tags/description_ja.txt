パブリック API を介して Sumsub 申請者プロファイルのタグを追加、置換、または削除します。 — `POST /resources/applicants/{applicantId}/tags/add` (追加)、`POST .../tags` (フルセットを上書き)、`DELETE .../tags` (削除)、`GET .../one` によるリードバック。ユーザーが「応募者にタグを付ける/タグを外す」、「応募者のタグを追加/削除/クリアする」、「応募者のプロフィールにラベルを付ける」、または「応募者のタグセットを置き換える」を要求したときにトリガーされます。トランザクション タグ、スコアリング ウェイトを使用したタグ定義、または申請者のリスク評価 (`sumsub-create-kyt-rules` を使用)、検証ワークフロー内の自動タグ付け (`sumsub-create-workflow` を使用)、およびタグ変更 Webhook のサブスクライブ (`sumsub-manage-webhooks`) の場合は SKIP。
