Aggiungi, sostituisci o rimuovi tag sul profilo di un candidato Sumsub tramite l'API pubblica: `POST /resources/applicants/{applicantId}/tags/add` (additivo), `POST .../tags` (sovrascrivi il set completo), `DELETE .../tags` (rimuovi), rileggi tramite `GET .../one`. SI ATTIVA quando l'utente chiede di "taggare/staggare un richiedente", "aggiungere/rimuovere/cancellare i tag del richiedente", "etichettare il profilo di un candidato" o "sostituire il set di tag di un richiedente". SALTA per i tag delle transazioni, le definizioni dei tag con pesi di punteggio o la valutazione del rischio del richiedente (utilizza "sumsub-create-kyt-rules"), per la codifica automatizzata all'interno dei flussi di lavoro di verifica (utilizza "sumsub-create-workflow") e per la sottoscrizione ai webhook di modifica dei tag (utilizza "sumsub-manage-webhooks").
