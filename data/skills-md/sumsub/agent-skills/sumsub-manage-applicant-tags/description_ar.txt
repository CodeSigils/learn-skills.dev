إضافة علامات أو استبدالها أو إزالتها في ملف تعريف مقدم الطلب Sumsub عبر واجهة برمجة التطبيقات العامة - `POST /resources/applicants/{applicantId}/tags/add` (إضافة)، `POST .../tags` (الكتابة فوق المجموعة الكاملة)، `DELETE .../tags` (إزالة)، إعادة القراءة عبر `GET .../one`. يتم تشغيله عندما يطلب المستخدم "وضع علامة على مقدم الطلب/إلغاء تمييزه"، أو "إضافة/إزالة/مسح علامات مقدم الطلب"، أو "تسمية ملف تعريف مقدم الطلب"، أو "استبدال مجموعة علامات مقدم الطلب". تخطي لعلامات المعاملات، أو تعريفات العلامات مع أوزان التسجيل، أو تقييم مخاطر مقدم الطلب (استخدم `sumsub-create-kyt-rules`)، ولوضع العلامات التلقائي داخل سير عمل التحقق (استخدم `sumsub-create-workflow`)، وللاشتراك في خطافات الويب لتغيير العلامات (استخدم `sumsub-manage-webhooks`).
