Agregue, reemplace o elimine etiquetas en un perfil de solicitante de Sumsub a través de la API pública: `POST /resources/applicants/{applicantId}/tags/add` (aditivo), `POST .../tags` (sobrescribir el conjunto completo), `DELETE .../tags` (eliminar), lectura posterior a través de `GET .../one`. DISPARA cuando el usuario solicita "etiquetar/desetiquetar a un solicitante", "agregar/eliminar/borrar etiquetas de solicitante", "etiquetar un perfil de solicitante" o "reemplazar el conjunto de etiquetas de un solicitante". SALTE para etiquetas de transacciones, definiciones de etiquetas con ponderaciones de puntuación o evaluación de riesgos del solicitante (use `sumsub-create-kyt-rules`), para etiquetado automatizado dentro de flujos de trabajo de verificación (use `sumsub-create-workflow`) y para suscribirse a webhooks de cambio de etiquetas (use `sumsub-manage-webhooks`).
