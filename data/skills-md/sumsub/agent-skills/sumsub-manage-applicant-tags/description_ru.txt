Добавляйте, заменяйте или удаляйте теги в профиле заявителя Sumsub через общедоступный API — `POST /resources/applicants/{applicantId}/tags/add` (добавка), `POST .../tags` (перезаписать полный набор), `DELETE .../tags` (удалить), обратное чтение через `GET .../one`. ТРИГГЕР, когда пользователь просит «отметить/отметить заявителя», «добавить/удалить/очистить теги заявителя», «пометить профиль заявителя» или «заменить набор тегов заявителя». ПРОПУСК для тегов транзакций, определений тегов с оценочными весами или оценки рисков заявителя (используйте sumsub-create-kyt-rules), для автоматической пометки тегов внутри рабочих процессов проверки (используйте sumsub-create-workflow) и для подписки на веб-перехватчики для изменения тегов (используйте sumsub-manage-webhooks).
