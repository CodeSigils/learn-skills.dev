Erstellen, bearbeiten, neu anordnen, löschen und veröffentlichen Sie Sumsub-AML-Auflösungsregeln (die AML-Auflösungsregelkette), die AML-Screening-Treffer automatisch überprüfen. TRIGGER, wenn der Benutzer Falsch-Positiv-Ergebnisse automatisch löschen, Richtig-Positiv-Ergebnisse automatisch bestätigen, frühere AML-Überprüfungen übertragen, AML-Treffer kennzeichnen oder die AML-Regelkette einrichten/überprüfen/veröffentlichen möchte. SKIP für Transaktionsüberwachungsregeln (KYT), Workflow-Routing oder AML-Prüfeinstellungen auf einer Ebene (diese werden durch separate Fähigkeiten abgedeckt).
