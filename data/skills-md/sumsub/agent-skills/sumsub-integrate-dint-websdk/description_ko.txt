Sumsub WebSDK를 사용하여 이미 사용자를 확인하는 웹 프로젝트에 Sumsub Device Intelligence(Fisherman 모듈)를 추가합니다. 사용자가 "장치 인텔리전스 추가", "WebSDK에서 장치 캡처/지문 인식 활성화", "Fisherman 켜기", "검증 흐름에서 장치 사기/다중 계정 감지"를 요청하거나 장치 위험 라벨이 WebSDK를 통해 확인된 신청자에게 어떻게 전달되는지 묻는 경우 TRIGGER. 전체 루프를 포괄합니다. 레벨에서 장치 데이터 캡처, 자동 SDK 내 Fisherman 라이프사이클, 고급 자체 렌더링 배선, 장치 신호 읽기(장치 탭, 장치 검사, 위험 레이블, 웹후크), 샌드박스 테스트, 가동 체크리스트를 활성화합니다. WebSDK 위젯이 없는 페이지(로그인/가입/체크아웃)에서 장치 인텔리전스를 건너뛰려면 'sumsub-integrate-dint-standalone'을 사용하세요. 기본 WebSDK 자체 삽입을 건너뛰려면 'sumsub-integrate-websdk'를 사용하세요.
