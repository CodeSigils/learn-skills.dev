Sumsub WebSDK でユーザーをすでに検証している Web プロジェクトに、Sumsub Device Intelligence (Fisherman モジュール) を追加します。ユーザーが「デバイス インテリジェンスの追加」、「WebSDK でのデバイス キャプチャ/フィンガープリンティングの有効化」、「フィッシャーマンの有効化」、「検証フローでのデバイス不正/マルチアカウンティングの検出」を要求したとき、または WebSDK を通じて検証された申請者にデバイス リスク ラベルがどのように適用されるかを尋ねたときにトリガーされます。ループ全体をカバーします。レベルでのデバイス データのキャプチャ、自動 SDK 内フィッシャーマン ライフサイクル、高度な自己レンダリング配線、デバイス信号の読み取り ([デバイス] タブ、デバイス チェック、リスク ラベル、Webhook)、サンドボックス テスト、ゴーライブ チェックリストを有効にします。 WebSDK ウィジェットがないページ (ログイン / サインアップ / チェックアウト) のデバイス インテリジェンスをスキップ — `sumsub-integrate-dint-standalone` を使用します。基本 WebSDK 埋め込み自体の場合はスキップします。「sumsub-integrate-websdk」を使用します。
