Verifique que el paquete de habilidades del agente Sumsub instalado localmente sea compatible con la versión publicada antes de realizar cualquier trabajo con Sumsub. DISPARAR al comienzo de cualquier tarea que afecte a Sumsub: herramientas Sumsub Dev MCP (mcp__Sumsub_Dev__*), flujos de trabajo KYC/AML, solicitantes, cheques, transacciones, niveles de verificación, enlaces de verificación, cuestionarios, red de fraude, listas VASP o cualquier cosa relacionada con Sumsub, para que se advierta al usuario antes de que un paquete de habilidades obsoleto produzca resultados incorrectos. Utilice también esta habilidad cuando el usuario pregunte explícitamente "¿mis habilidades de Sumsub están actualizadas?", "hay una versión más nueva de las habilidades de Sumsub" o algo similar. Omita la actualización real (el usuario ejecuta `npx skills add SumSubstance/agent-skills --all` ellos mismos) y omita cualquier otra API de Sumsub o tarea de entidad; esas tienen sus propias habilidades.
