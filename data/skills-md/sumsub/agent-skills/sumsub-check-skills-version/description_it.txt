Verificare che il pacchetto delle competenze dell'agente Sumsub installato localmente sia compatibile con la versione pubblicata prima di eseguire qualsiasi operazione con Sumsub. TRIGGER all'inizio di qualsiasi attività che tocca Sumsub - strumenti Sumsub Dev MCP (mcp__Sumsub_Dev__*), flussi di lavoro KYC/AML, richiedenti, assegni, transazioni, livelli di verifica, collegamenti di verifica, questionari, rete antifrode, elenchi VASP o qualsiasi cosa relativa a Sumsub - in modo che l'utente venga avvisato prima che un pacchetto di competenze obsoleto produca risultati errati. Utilizza questa abilità anche quando l'utente chiede esplicitamente "le mie abilità Sumsub sono aggiornate/attuali", "esiste una versione più recente delle abilità Sumsub" o simili. Salta l'aggiornamento vero e proprio (l'utente esegue `npx skills add SumSubstance/agent-skills --all` da solo) e salta qualsiasi altra API Sumsub o attività di entità: quelle hanno le proprie competenze.
