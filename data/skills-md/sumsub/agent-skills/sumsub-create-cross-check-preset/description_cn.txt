通过 `POST/PATCH /resources/api/agent/crossCheckPresets` 和 `GET /resources/api/agent/crossCheckPresets/{id}` 创建或更新 Sumsub 交叉检查预设（POI 和 POA 文档之间的名称/地址比较规则）。 **仅**当用户明确要求覆盖交叉检查比较姓名或地址的方式时触发 - 例如“将名称匹配切换为严格”、“允许模糊地址匹配”、“忽略中间名不匹配”、“创建自定义交叉检查预设”。默认跳过 — Sumsub 提供了合理的默认设置，以实现最佳转化和批准率，因此大多数客户不应创建自定义预设。对于一般 KYC 配置或任何未明确命名“交叉检查规则”、“名称比较”或“地址比较”的请求，跳过级别创建（默认交叉检查预设自动应用于每个级别）。
