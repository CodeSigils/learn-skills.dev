`POST/PATCH /resources/api/agent/crossCheckPresets` 및 `GET /resources/api/agent/crossCheckPresets/{id}`를 통해 Sumsub 교차 검사 사전 설정(POI와 POA 문서 간의 이름/주소 비교 규칙)을 생성하거나 업데이트합니다. TRIGGER **ONLY** 사용자가 교차 확인에서 이름이나 주소를 비교하는 방법을 재정의하도록 명시적으로 요청하는 경우 — 예: "이름 일치를 엄격하게 전환", "퍼지 주소 일치 허용", "중간 이름 불일치 무시", "사용자 정의 교차 확인 사전 설정 생성". 기본적으로 건너뛰기 — Sumsub는 최고의 전환율과 승인률을 위해 조정된 합리적인 기본값을 제공하므로 대부분의 클라이언트는 사용자 정의 사전 설정을 생성해서는 안 됩니다. 레벨 생성(기본 교차 확인 사전 설정은 모든 레벨에 자동 적용됨), 일반 KYC 구성 또는 "교차 확인 규칙", "이름 비교" 또는 "주소 비교"를 구체적으로 지정하지 않은 요청의 경우 건너뛰십시오.
