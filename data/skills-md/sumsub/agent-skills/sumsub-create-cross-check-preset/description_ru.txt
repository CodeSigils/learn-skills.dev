Создайте или обновите настройку перекрестной проверки Sumsub (правила сравнения имени/адреса между документами POI и POA) с помощью `POST/PATCH/resources/api/agent/crossCheckPresets` и `GET/resources/api/agent/crossCheckPresets/{id}`. ТРИГГЕР **ТОЛЬКО**, когда пользователь ЯВНО запрашивает переопределить способ перекрестной проверки для сравнения имен или адресов — например. «переключить соответствие имени на строгое», «разрешить нечеткое совпадение адресов», «игнорировать несоответствие отчества», «создать собственный набор настроек перекрестной проверки». ПРОПУСК по умолчанию — Sumsub предлагает разумные настройки по умолчанию, настроенные на лучший коэффициент конверсии и одобрения, поэтому большинству клиентов НЕ следует создавать собственные настройки. ПРОПУСТИТЕ для создания уровня (предустановка перекрестной проверки по умолчанию автоматически применяется к каждому уровню), для общей конфигурации KYC или для любого запроса, который конкретно не называет «правила перекрестной проверки», «сравнение имен» или «сравнение адресов».
