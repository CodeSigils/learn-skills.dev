ユーザーが SDK に名前を付けていない場合でも、Sumsub Mobile SDK (IdensicMobileSDK / SNSMobileSDK) を iOS アプリに統合します (例: 「Sumsub/KYC を iPhone アプリに追加する」、「iOS で検証画面を表示する」、「ビュー コントローラーから Sumsub を起動する」)。インストール、権限、初期化、トークンの更新、フローの提示について説明します。 Web 用の SKIP (`sumsub-integrate-websdk`)、バックエンド / API 専用トークン署名 (`sumsub-api-generic`)、テーマ設定 (`sumsub-theme-msdk`)、および非 iOS — Android / React Native / Flutter (サポートされていません)。 iOSのみ。
