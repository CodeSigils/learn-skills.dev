Intégrez le SDK Sumsub Mobile (IdensicMobileSDK / SNSMobileSDK) dans une application iOS, même lorsque l'utilisateur ne nomme pas le SDK (par exemple « ajouter Sumsub/KYC à mon application iPhone », « afficher l'écran de vérification sur iOS », « lancer Sumsub à partir d'un contrôleur de vue »). Couvre l'installation, les autorisations, l'initialisation, l'actualisation du jeton et la présentation du flux. SKIP pour le Web (`sumsub-integrate-websdk`), la signature de jetons backend/API uniquement (`sumsub-api-generic`), les thèmes (`sumsub-theme-msdk`) et non-iOS — Android / React Native / Flutter (non pris en charge). iOS uniquement.
