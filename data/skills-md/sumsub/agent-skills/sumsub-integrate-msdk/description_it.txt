Integra Sumsub Mobile SDK (IdensicMobileSDK / SNSMobileSDK) in un'app iOS, anche quando l'utente non nomina l'SDK (ad esempio "aggiungi Sumsub/KYC alla mia app per iPhone", "mostra la schermata di verifica su iOS", "avvia Sumsub da un controller di visualizzazione"). Copre l'installazione, le autorizzazioni, l'inizializzazione, l'aggiornamento del token e la presentazione del flusso. SKIP per il Web (`sumsub-integrate-websdk`), firma token backend/solo API (`sumsub-api-generic`), temi (`sumsub-theme-msdk`) e non iOS: Android/React Native/Flutter (non supportato). Solo iOS.
