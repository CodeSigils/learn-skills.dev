Integre el SDK móvil de Sumsub (IdensicMobileSDK / SNSMobileSDK) en una aplicación de iOS, incluso cuando el usuario no nombra el SDK (por ejemplo, "agregar Sumsub/KYC a mi aplicación de iPhone", "mostrar la pantalla de verificación en iOS", "iniciar Sumsub desde un controlador de vista"). Cubre la instalación, los permisos, el inicio, la actualización del token y la presentación del flujo. SKIP para web (`sumsub-integrate-websdk`), firma de token backend/solo API (`sumsub-api-generic`), tematización (`sumsub-theme-msdk`) y no iOS: Android/React Native/Futter (no compatible). Solo iOS.
