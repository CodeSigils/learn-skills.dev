قم بدمج Sumsub Mobile SDK (IdensicMobileSDK / SNSMobileSDK) في تطبيق iOS - حتى عندما لا يقوم المستخدم بتسمية SDK (على سبيل المثال، "أضف Sumsub/KYC إلى تطبيق iPhone الخاص بي"، "إظهار شاشة التحقق على iOS"، "تشغيل Sumsub من وحدة تحكم العرض"). يغطي التثبيت، والأذونات، والحرف الأول، وتحديث الرمز المميز، وتقديم التدفق. تخطي للويب (`sumsub-integrate-websdk`)، وتوقيع الرمز المميز للواجهة الخلفية / API فقط (`sumsub-api-generic`)، والسمات (`sumsub-theme-msdk`)، وغير iOS - Android / React Native / Flutter (غير مدعوم). دائرة الرقابة الداخلية فقط.
