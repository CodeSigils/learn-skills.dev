將 Sumsub 行動 SDK (IdensicMobileSDK / SNSMobileSDK) 整合到 iOS 應用程式中 - 即使使用者沒有命名 SDK（例如「將 Sumsub/KYC 新增至我的 iPhone 應用程式」、「在 iOS 上顯示驗證畫面」、「從視圖控制器啟動 Sumsub」）。涵蓋安裝、權限、初始化、令牌刷新、呈現流程。跳過 Web (`sumsub-integrate-websdk`)、後端/僅 API 令牌簽名 (`sumsub-api-generic`)、主題 (`sumsub-theme-msdk`) 和非 iOS — Android / React Native / Flutter（不支援）。僅限 iOS。
