Создайте рабочий процесс кандидата Sumsub — маршрут проверки (уровни, ветви, правила страны/возраста, этапы окончательного отклонения или ручной проверки) или рабочий процесс действий (теги после проверки, примечания, изменения исходного ключа). TRIGGER по запросам на создание/построение/добавление рабочего процесса или описания маршрутизации в виде блок-схемы. Создает, проверяет и сохраняет черновик, а затем публикует его (с учетом текущего трафика) автоматически, когда трафик рабочего процесса низкий, и только после явного подтверждения, когда он высокий. Публикация изменений LIVE-трафика — см. раздел Опасности. SKIP для редактирования произвольных полей существующей ревизии, либо для анкет/уровней (отдельных навыков).
