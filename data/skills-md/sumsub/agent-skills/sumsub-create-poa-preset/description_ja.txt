Sumsub Proof-of-Address (POA) プリセットを作成または更新します。 POST `/resources/api/agent/poaStepSettings` で新しい作成し、同じパス (本文の ID) を PATCH して更新し、GET `/resources/api/agent/poaStepSettings/{id}` で 1 つ読み戻します。ユーザーが「POA プリセットの作成 / 追加 / 構築 / 構成 / 更新 / 編集」または「PoA ステップ設定」を要求したときにトリガーします。受け入れられる住所証明書類の種類 (公共料金請求書、銀行取引明細書、税金請求書など) を設定し、プロバイダー タイプごとに有効期間を設定し、POI-as-POA を有効化 (ID 書類を住所証明として受け入れる)、クロスバリデータの調整 (POI と住所間の名前/住所のあいまい一致) POA)、または国ごとの POA オーバーライドを追加します。レベルにプリセットをアタッチする場合 (代わりに、「sumsub-create-level」を介してレベルに「poaStepSettingsId」を設定する)、または非 POA プリセット (クロスチェック プリセット、権限プリセットなど) の場合は SKIP。
