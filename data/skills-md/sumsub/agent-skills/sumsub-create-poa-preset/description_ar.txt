قم بإنشاء أو تحديث الإعداد المسبق لإثبات العنوان (POA) لـ Sumsub. POST `/resources/api/agent/poaStepSettings` لإنشاء مسار جديد، تصحيح نفس المسار للتحديث (المعرف في النص)، GET `/resources/api/agent/poaStepSettings/{id}` لقراءة واحدة مرة أخرى. تشغيل عندما يطلب المستخدم "إنشاء / إضافة / إنشاء / تكوين / تحديث / تحرير إعداد مسبق لـ POA" أو "إعدادات خطوة PoA"، وتكوين أنواع مستندات إثبات العنوان المقبولة (فواتير الخدمات، وكشوفات الحسابات المصرفية، وفواتير الضرائب، وما إلى ذلك)، وتعيين فترات الصلاحية لكل نوع مزود، وتمكين POI-as-POA (قبول مستند الهوية كدليل على العنوان)، وضبط المدقق المتبادل (تطابق غامض للاسم / العنوان بين POI وPOA)، أو قم بإضافة تجاوزات التوكيل الرسمي لكل دولة. تخطي لإرفاق إعداد مسبق بمستوى (اضبط `poaStepSettingsId` على المستوى بدلاً من ذلك، عبر `sumsub-create-level`)، أو للإعدادات المسبقة غير POA (التحقق من الإعدادات المسبقة، والإعدادات المسبقة للأذونات، وما إلى ذلك).
