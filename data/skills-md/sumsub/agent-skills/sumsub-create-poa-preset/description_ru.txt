Создайте или обновите набор настроек Sumsub Proof-of-Address (POA). POST `/resources/api/agent/poaStepSettings`, чтобы создать новый, PATCH тот же путь для обновления (идентификатор в теле), GET `/resources/api/agent/poaStepSettings/{id}`, чтобы прочитать его обратно. ТРИГГЕР, когда пользователь запрашивает «создать / добавить / построить / настроить / обновить / отредактировать предустановку POA» или «Настройки шага PoA», настроить, какие типы документов, подтверждающих адрес, принимаются (счета за коммунальные услуги, банковские выписки, налоговые счета и т. д.), установить периоды действия для каждого типа поставщика, включить POI-as-POA (принять идентификационный документ в качестве доказательства адреса), настроить перекрестный валидатор (нечеткое совпадение имени / адреса между POI и POA) или добавить переопределения POA для каждой страны. SKIP для присоединения пресета к уровню (вместо этого установите `poaStepSettingsId` на уровне, через `sumsub-create-level`) или для пресетов, не относящихся к POA (пресеты перекрестной проверки, пресеты разрешений и т. д.).
