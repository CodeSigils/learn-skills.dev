Erstellen oder aktualisieren Sie eine Sumsub Proof-of-Address (POA)-Voreinstellung. POST `/resources/api/agent/poaStepSettings`, um ein neues zu erstellen, PATCH den gleichen Pfad zum Aktualisieren (ID im Text), GET `/resources/api/agent/poaStepSettings/{id}`, um einen zurückzulesen. TRIGGER, wenn der Benutzer „eine POA-Voreinstellung erstellen/hinzufügen/erstellen/konfigurieren/aktualisieren/bearbeiten“ oder „PoA-Schritteinstellungen“ auffordert, konfigurieren, welche Arten von Adressnachweisdokumenten akzeptiert werden (Rechnungen von Versorgungsunternehmen, Kontoauszügen, Steuerrechnungen usw.), Gültigkeitszeiträume pro Anbietertyp festlegen, POI-als-POA aktivieren (Identitätsdokument als Adressnachweis akzeptieren), den Kreuzvalidator optimieren (Name/Adresse-Fuzzy-Match zwischen POI und POA) oder pro Land hinzufügen POA-Überschreibungen. SKIP zum Anhängen einer Voreinstellung an eine Ebene (setzen Sie stattdessen „poaStepSettingsId“ auf der Ebene über „sumsub-create-level“) oder für Nicht-POA-Voreinstellungen (Gegenprüfungsvoreinstellungen, Berechtigungsvoreinstellungen usw.).
