Sumsub POA(주소 증명) 사전 설정을 만들거나 업데이트합니다. POST `/resources/api/agent/poaStepSettings`를 사용하여 새 경로를 만들고 업데이트할 동일한 경로(본문의 ID)를 패치하고, 다시 읽으려면 `/resources/api/agent/poaStepSettings/{id}`를 GET하세요. 사용자가 "POA 사전 설정 생성/추가/구축/구성/업데이트/편집" 또는 "PoA 단계 설정"을 요청하면 TRIGGER, 허용되는 주소 증명 문서 유형(공과금 청구서, 은행 명세서, 세금 고지서 등) 구성, 공급자 유형별로 유효 기간 설정, POI-as-POA 활성화(주소 증명으로 신원 문서 허용), 교차 유효성 검사기 조정(POI와 POA 간의 이름/주소 퍼지 일치) 또는 국가별 추가 POA가 재정의됩니다. 프리셋을 레벨에 연결하거나(대신 `sumsub-create-level`을 통해 레벨에 `poaStepSettingsId` 설정) POA가 아닌 프리셋(교차 확인 프리셋, 권한 프리셋 등)을 연결하려면 건너뛰세요.
