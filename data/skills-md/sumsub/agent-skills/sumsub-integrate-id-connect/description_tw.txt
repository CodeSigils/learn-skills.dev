整合 Sumsub ID Connect 的端到端秘訣 — 基於 OIDC 的「使用 Sumsub ID 進行驗證」流程，使用戶可以與您的應用程式共用先前驗證的身份聲明。當使用者要求「整合 Sumsub ID Connect」、「新增使用 Sumsub-ID 驗證按鈕」、「透過 OIDC 重複使用 Sumsub KYC」、「交換 Sumsub 授權代碼」、「建立 Sumsub ID 共用令牌」或詢問如何連接 `@sumsub/id-connect`、DC `code → OI/c核時觸發，共享令牌/合作夥伴同意流程，或共享連結重定向。涵蓋先決條件清單、自動預檢、前端按鈕（庫按鈕 + 原始重定向替代方案）、後端代幣代碼交換、共享代幣鑄造、合作夥伴同意共享連結流程以及透過「/resources/api/reusableIdentity/reuse」實現申請人。跳過獨立的 WebSDK / KYC 小工具（使用「sumsub-integrate-websdk」），或簡單的可重複使用 KYC-via-API，其中捐贈者和接收者都是您自己的租戶，無需用戶介導的 OIDC 步驟。
