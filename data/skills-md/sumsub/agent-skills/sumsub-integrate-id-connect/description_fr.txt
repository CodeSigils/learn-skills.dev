Recette de bout en bout pour l'intégration de Sumsub ID Connect — le flux « Vérifier avec Sumsub ID » basé sur OIDC qui permet à un utilisateur de partager des revendications d'identité précédemment vérifiées avec votre application. DÉCLENCHEMENT lorsque l'utilisateur demande "d'intégrer Sumsub ID Connect", "d'ajouter le bouton Vérifier avec Sumsub-ID", de "réutiliser Sumsub KYC via OIDC", "d'échanger le code d'autorisation Sumsub", de "créer un jeton de partage Sumsub ID", ou demande comment câbler `@sumsub/id-connect`, l'échange OIDC `code → access_token` (`/api/snsId/oauth/token`), le flux de jeton de partage/consentement du partenaire, ou redirection de lien de partage. Couvre la liste de contrôle des conditions préalables, le contrôle en amont automatisé, le bouton frontal (bouton de bibliothèque + alternative de redirection brute), l'échange de code backend contre jeton, la frappe de jeton de partage, le flux shareLink de consentement du partenaire et la matérialisation du candidat via `/resources/api/reusableIdentity/reuse`. SKIP pour le widget WebSDK / KYC autonome (utilisez `sumsub-integrate-websdk`), ou pour un KYC-via-API réutilisable simple où le donateur et le destinataire sont tous deux vos propres locataires sans étape OIDC médiée par l'utilisateur.
