Комплексный рецепт интеграции Sumsub ID Connect — потока «Проверка с помощью Sumsub ID» на основе OIDC, который позволяет пользователю делиться ранее проверенными утверждениями об идентичности с вашим приложением. ТРИГГЕР, когда пользователь запрашивает «интегрировать Sumsub ID Connect», «добавить кнопку Verify-with-Sumsub-ID», «повторно использовать Sumsub KYC через OIDC», «обменять код авторизации Sumsub», «выпустить общий токен Sumsub ID» или спрашивает, как подключить `@sumsub/id-connect`, обмен OIDC `code → access_token` (`/api/snsId/oauth/token`), поток общего токена/согласия партнера или перенаправление общей ссылки. Охватывает контрольный список предварительных условий, автоматическую предварительную проверку, кнопку внешнего интерфейса (кнопка библиотеки + альтернатива необработанного перенаправления), внутренний обмен кодом на токен, выпуск токенов общего доступа, поток обмена ссылками с согласия партнера и материализацию заявителя через `/resources/api/reusableIdentity/reuse`. ПРОПУСТИТЕ для автономного виджета WebSDK/KYC (используйте sumsub-integrate-websdk) или для простого многоразового KYC-через API, где донор и получатель являются вашими собственными арендаторами без действия OIDC, опосредованного пользователем.
