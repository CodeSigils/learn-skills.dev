Ricetta end-to-end per l'integrazione di Sumsub ID Connect: il flusso "Verifica con Sumsub ID" basato su OIDC che consente a un utente di condividere rivendicazioni di identità precedentemente verificate con la tua app. TRIGGER quando l'utente chiede di "integrare Sumsub ID Connect", "aggiungere il pulsante Verify-with-Sumsub-ID", "riutilizzare Sumsub KYC tramite OIDC", "scambiare il codice di autorizzazione Sumsub", "coniare un token di condivisione ID Sumsub", o chiede come collegare `@sumsub/id-connect`, lo scambio di `codice → access_token` OIDC (`/api/snsId/oauth/token`), il flusso token di condivisione/consenso del partner o reindirizzamento del collegamento di condivisione. Copre l'elenco di controllo delle precondizioni, il preflight automatizzato, il pulsante frontend (pulsante della libreria + alternativa di reindirizzamento non elaborato), lo scambio di codici per token backend, la creazione di token condivisi, il flusso shareLink del consenso del partner e la materializzazione del richiedente tramite "/resources/api/reusableIdentity/reuse". SALTA per il widget WebSDK/KYC autonomo (usa `sumsub-integrate-websdk`) o per il semplice Reusable-KYC-via-API in cui il donatore e il destinatario sono entrambi i tuoi inquilini senza un passaggio OIDC mediato dall'utente.
