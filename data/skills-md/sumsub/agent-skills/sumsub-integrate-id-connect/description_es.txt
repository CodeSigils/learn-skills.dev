Receta de extremo a extremo para integrar Sumsub ID Connect: el flujo "Verificar con Sumsub ID" basado en OIDC que permite a un usuario compartir afirmaciones de identidad previamente verificadas con su aplicación. DISPARADOR cuando el usuario solicita "integrar Sumsub ID Connect", "agregar el botón Verificar con Sumsub-ID", "reutilizar Sumsub KYC a través de OIDC", "intercambiar el código de autorización de Sumsub", "acuñar un token compartido de Sumsub ID" o pregunta cómo conectar `@sumsub/id-connect`, el intercambio de `código OIDC → access_token` (`/api/snsId/oauth/token`), el flujo de token compartido/consentimiento de socio, o la redirección de enlace compartido. Cubre la lista de verificación de condiciones previas, la verificación previa automatizada, el botón de interfaz (botón de biblioteca + alternativa de redireccionamiento sin formato), el código de backend para el intercambio de tokens, la acuñación de tokens compartidos, el flujo de shareLink con consentimiento de los socios y la materialización del solicitante a través de `/resources/api/reusableIdentity/reuse`. SALTE para el widget WebSDK/KYC independiente (use `sumsub-integrate-websdk`), o para KYC-vía-API reutilizable simple donde el donante y el destinatario son sus propios inquilinos sin un paso OIDC mediado por el usuario.
