Analice un documento normativo (PDF o texto) y produzca un plan de configuración de Sumsub, asignando los requisitos normativos a las entidades de Sumsub (niveles, cuestionarios, ajustes preestablecidos de PoA, reglas de TM, flujos de trabajo). DISPARA cuando el usuario proporciona un PDF normativo, acto jurídico o documento de requisitos de cumplimiento y quiere saber qué configurar en Sumsub. Actúa como punto de entrada antes de invocar sumsub-create-level, sumsub-create-questionnaire, sumsub-create-poa-preset, sumsub-create-workflow y otras habilidades. SALTAR para solicitudes directas de creación de entidades (sin contexto regulatorio) o llamadas a la API de Sumsub.
