قم بتحليل مستند تنظيمي (PDF أو نص) وإنتاج خطة تكوين Sumsub - تعيين المتطلبات التنظيمية لكيانات Sumsub (المستويات والاستبيانات وإعدادات PoA المسبقة وقواعد TM ومسارات العمل). TRIGGER عندما يقدم المستخدم مستند PDF تنظيميًا أو قانونًا قانونيًا أو مستند متطلبات الامتثال ويريد معرفة ما يجب تكوينه في Sumsub. يعمل كنقطة دخول قبل استدعاء sumsub-create-level، وsumsub-create-questionnaire، وsumsub-create-poa-preset، وsumsub-create-workflow، ومهارات أخرى. تخطي لطلبات إنشاء الكيانات المباشرة (بدون سياق تنظيمي) أو مكالمات Sumsub API.
