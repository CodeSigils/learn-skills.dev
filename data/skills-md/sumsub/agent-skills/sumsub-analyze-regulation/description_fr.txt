Analysez un document réglementaire (PDF ou texte) et produisez un plan de configuration Sumsub — mappant les exigences réglementaires aux entités Sumsub (niveaux, questionnaires, préréglages PoA, règles TM, workflows). DÉCLENCHEUR lorsque l'utilisateur fournit un PDF de réglementation, un acte juridique ou un document d'exigence de conformité et souhaite savoir quoi configurer dans Sumsub. Agit comme point d'entrée avant d'invoquer sumsub-create-level, sumsub-create-questionnaire, sumsub-create-poa-preset, sumsub-create-workflow et d'autres compétences. SKIP pour les demandes de création d'entité directe (pas de contexte réglementaire) ou les appels API Sumsub.
