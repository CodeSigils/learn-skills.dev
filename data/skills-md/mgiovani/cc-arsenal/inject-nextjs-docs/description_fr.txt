Exécutez le codemod Next.js agents-md pour injecter la documentation du framework compressé dans CLAUDE.md ou AGENTS.md du projet actuel. Cette compétence doit être utilisée lorsqu'un utilisateur souhaite ajouter des documents de framework Next.js à son projet pour les agents de codage IA, exécuter le codemod Vercel agents-md ou améliorer les performances des agents IA sur les projets Next.js.
