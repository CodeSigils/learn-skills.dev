Sicheres Codebasis-Refactoring mit Charakterisierungstests, inkrementellen Änderungen und kontinuierlicher Überprüfung. Wird automatisch aktiviert, wenn Benutzer Code umgestalten, Methoden/Klassen extrahieren, die Logik vereinfachen, Duplikate reduzieren, die Benennung verbessern, Module neu strukturieren oder technische Schulden bereinigen möchten.
