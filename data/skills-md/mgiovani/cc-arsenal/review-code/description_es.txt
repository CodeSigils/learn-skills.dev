Realice una revisión integral del código de múltiples agentes para relaciones públicas, confirmaciones o bases de código completas. Esta habilidad debe usarse cuando un usuario desea una revisión exhaustiva del código que abarque la corrección, el rendimiento, el estilo del código, la cobertura de las pruebas y el manejo de errores. Solo análisis: identifica problemas sin modificar el código.
