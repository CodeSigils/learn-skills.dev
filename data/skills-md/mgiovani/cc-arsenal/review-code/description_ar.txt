قم بإجراء مراجعة شاملة للتعليمات البرمجية متعددة الوكلاء للعلاقات العامة أو الالتزامات أو قواعد التعليمات البرمجية بأكملها. يجب استخدام هذه المهارة عندما يريد المستخدم مراجعة شاملة للتعليمات البرمجية تغطي الصحة والأداء ونمط التعليمات البرمجية وتغطية الاختبار ومعالجة الأخطاء. التحليل فقط - يحدد المشكلات دون تعديل التعليمات البرمجية.
