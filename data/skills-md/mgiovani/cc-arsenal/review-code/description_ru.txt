Выполняйте комплексную многоагентную проверку кода для PR, коммитов или всей кодовой базы. Этот навык следует использовать, когда пользователю нужен тщательный анализ кода, охватывающий корректность, производительность, стиль кода, покрытие тестами и обработку ошибок. Только анализ — выявляет проблемы без изменения кода.
