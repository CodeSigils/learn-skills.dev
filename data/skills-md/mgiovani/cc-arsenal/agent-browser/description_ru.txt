Безголовый интерфейс командной строки для автоматизации браузера, оптимизированный для агентов ИИ. Использует систему моментальных снимков + ссылок, что позволяет на 93% меньше накладных расходов на контекст по сравнению с Playwright. Специально создан для веб-тестирования, автоматизации форм, создания снимков экрана и извлечения данных.
