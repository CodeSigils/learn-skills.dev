أعد كتابة النثر وصياغته ومراجعته بحيث يكون واضحًا ومحددًا وإنسانيًا ومناسبًا للسياق. استخدم هذه المهارة عند تحسين رسائل البريد الإلكتروني أو المقالات أو المستندات أو التقارير أو نسخة واجهة المستخدم أو النسخة التسويقية أو المنشورات أو أي نص قد يبدو عامًا أو مكتوبًا بالذكاء الاصطناعي أو مفرط الصقل أو مطولًا أو بيعيًا أو مراوغًا أو ذو صيغة هيكلية. يدعم معايرة الصوت، وعمليات التدقيق المضادة للانزلاق، وقرارات الذوق المدركة للسياق، والفحوصات النهائية قبل الرحلة.
