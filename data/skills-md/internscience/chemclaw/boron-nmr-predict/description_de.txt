Sagen Sie die chemische Verschiebung von 11B (Bor-11) NMR für borhaltige Moleküle mithilfe einer lokalen CPU-Inferenzpipeline voraus. Verwenden Sie diese Option, wenn der Benutzer die Vorhersage von Bor-NMR oder einer chemischen 11B-Verschiebung wünscht und ein Molekül wie eine SMILES-Zeichenfolge bereitstellt. Der Skill kann bei der ersten Verwendung Modellgewichte von Hugging Face herunterladen, eine lokale CPU-Inferenz ausführen und ein markiertes Molekülbild generieren, sodass jede vorhergesagte Verschiebung einem bestimmten Boratom zugeordnet werden kann.
