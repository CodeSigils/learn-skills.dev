Prediga el cambio químico de RMN 11B (boro-11) para moléculas que contienen boro utilizando una tubería de inferencia de CPU local. Úselo cuando el usuario solicite predecir la RMN de boro o el cambio químico de 11B y proporcione una molécula como una cadena SMILES. La habilidad puede descargar pesos de modelos de Hugging Face en el primer uso, ejecutar inferencia de CPU local y generar una imagen de molécula etiquetada para que cada cambio predicho pueda relacionarse con un átomo de boro específico.
