Estrai dati sulle reazioni chimiche da documenti PDF, in particolare informazioni sull'ottimizzazione delle condizioni di reazione. Supporta l'estrazione di reagenti, prodotti, catalizzatori, solventi, temperatura, tempo, resa, ecc. e genera file CSV strutturati. Utilizza MinerU + NLP + corrispondenza delle regole per un'estrazione accurata.
