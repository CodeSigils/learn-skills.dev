Конвертируйте PDF-файлы в Markdown с помощью MinerU API. 
Используйте MinerU API в формате PDF и в формате Markdown.
Используйте, когда Кими необходимо извлечь структурированный текст, изображения, таблицы и формулы из документов PDF, сохраняя при этом макет и форматирование документа. 
适用于需要提取结构化文本、图 фото、表格和公式并保留文档布局的场景。
Поддерживает пакетное преобразование и выводит Full.md с изображениями/, метаданными JSON и другими извлеченными ресурсами. 
Загрузите файл 转换，输出full.md、images/目录、JSON元数据等。
Теперь поддерживает большие PDF-файлы (более 600 страниц) путем автоматического разделения и объединения.
现已支持大文件(600+页)自动拆分和合并处理。
