MinerU API を使用して PDF ファイルを Markdown 形式に変換します。
キミが文書のレイアウトと書式を維持しながら、PDF 文書から構造化テキスト、画像、表、数式を抽出する必要がある場合に使用します。 
構造化された文書、図、表形式、および公式を抽出し、文書配置のフィールドを保持する必要がある場合に適しています。
バッチ変換をサポートし、images/、JSON メタデータ、およびその他の抽出されたアセットを含む full.md を出力します。 
批量转换、出力full.md、images/目录、JSON元データなどをサポートします。
