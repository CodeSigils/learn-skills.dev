Herramienta de conversión de formato de archivos químicos. Admite la conversión mutua entre .xyz, .gjf (gaussiano), .mol, .sdf, .pdb, .mol2 y otros formatos. Utiliza Open Babel o RDKit para la conversión. Se activa cuando el usuario proporciona un archivo químico y solicita la conversión de formato, genera archivos en diferentes formatos o menciona la conversión de archivos.
