Konvertierungstool für chemische Dateiformate. Unterstützt die gegenseitige Konvertierung zwischen .xyz, .gjf (Gauß), .mol, .sdf, .pdb, .mol2 und anderen Formaten. Verwendet Open Babel oder RDKit zur Konvertierung. Wird ausgelöst, wenn ein Benutzer eine chemische Datei bereitstellt und eine Formatkonvertierung, die Generierung von Dateien in anderen Formaten anfordert oder eine Dateikonvertierung erwähnt.
