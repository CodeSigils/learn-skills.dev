Strumento di conversione del formato di file chimici. Supporta la conversione reciproca tra .xyz, .gjf (gaussiano), .mol, .sdf, .pdb, .mol2 e altri formati. Utilizza Open Babel o RDKit per la conversione. Si attiva quando l'utente fornisce un file chimico e richiede la conversione del formato, la generazione di file in formati diversi o menziona la conversione del file.
