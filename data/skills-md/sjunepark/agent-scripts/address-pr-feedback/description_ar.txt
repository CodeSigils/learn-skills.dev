التصرف بناءً على تعليقات طلب سحب GitHub الحالية من البداية إلى النهاية. يُستخدم عندما يحتاج Codex إلى قراءة تعليقات مراجعة العلاقات العامة، وإصدار التعليقات، وهيئات المراجعة، وملخصات الروبوتات، وأقسام المراجعة الخارجية، وإصلاح التعليمات البرمجية محليًا، وتشغيل تصاريح المراجعة المحلية، وإجراء التزامات المتابعة، ودفع فرع العلاقات العامة، والرد على تعليقات العلاقات العامة بما تم التعامل معه.
