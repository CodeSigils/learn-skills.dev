Informieren Sie den Benutzer manuell über die aktuelle Aufgabe oder Sitzung, damit er die nächste Entscheidung treffen kann, ohne die gesamte Codebasis neu laden zu müssen. Nur verwenden, wenn der Benutzer ausdrücklich nach einem Briefing, einer Aktualisierung, dem aktuellen Stand, einer relevanten Architektur oder einem Implementierungskontext fragt. Bevorzugen Sie diese Fähigkeit für die aufgabenbezogene Kontextwiederherstellung, wenn die Konversation lang ist, sich der Code geändert hat oder der Benutzer die relevanten Details ohne lange Erklärung möchte.
