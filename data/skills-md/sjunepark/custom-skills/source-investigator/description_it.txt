Esamina librerie esterne, framework e repository sconosciuti clonando il repository esatto in uno spazio di lavoro temporaneo locale del progetto, ignorando quell'area di lavoro in git e delegando la lettura del codice ad agenti secondari focalizzati in modo che il thread principale rimanga pulito. Da utilizzare ogni volta che i documenti sono incompleti, il comportamento specifico della versione è importante, è necessario imparare come funziona una base di codice o l'esplorazione di molte fonti in linea inquinerebbe il contesto principale.
