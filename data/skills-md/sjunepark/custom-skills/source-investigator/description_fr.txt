Examinez les bibliothèques externes, les frameworks et les référentiels inconnus en clonant le dépôt exact dans un espace de travail temporaire local du projet, en ignorant cet espace de travail dans git et en déléguant la lecture du code aux sous-agents ciblés afin que le thread principal reste propre. À utiliser chaque fois que les documents sont incomplets, que le comportement spécifique à la version est important, que vous devez apprendre comment fonctionne une base de code, ou que l'exploration de nombreuses sources en ligne polluerait le contexte principal.
