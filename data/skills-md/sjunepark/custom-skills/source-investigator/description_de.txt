Untersuchen Sie externe Bibliotheken, Frameworks und unbekannte Repositorys, indem Sie das genaue Repo in einen projektlokalen temporären Arbeitsbereich klonen, diesen Arbeitsbereich in Git ignorieren und das Lesen des Codes an fokussierte Subagenten delegieren, damit der Hauptthread sauber bleibt. Verwenden Sie es immer dann, wenn Dokumente unvollständig sind, versionenspezifisches Verhalten wichtig ist, Sie lernen müssen, wie eine Codebasis funktioniert, oder wenn die Inline-Untersuchung vieler Quellen den Hauptkontext verunreinigen würde.
