Investigue bibliotecas externas, marcos y repositorios desconocidos clonando el repositorio exacto en un espacio de trabajo temporal local del proyecto, ignorando ese espacio de trabajo en git y delegando la lectura de código a subagentes enfocados para que el hilo principal se mantenga limpio. Úselo siempre que los documentos estén incompletos, el comportamiento específico de la versión sea importante, necesite aprender cómo funciona una base de código o explorar muchas fuentes en línea contaminaría el contexto principal.
