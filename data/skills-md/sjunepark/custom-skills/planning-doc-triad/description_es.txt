Mantenga la planificación del proyecto con tres documentos distintos: una hoja de ruta general, una lista de tareas pendientes a corto plazo y un plan detallado activo. Utilice esta habilidad cuando el usuario desee crear, limpiar o restablecer documentos de planificación del repositorio, como una hoja de ruta, un archivo TODO o un plan activo, o cuando esas funciones estén borrosas en los archivos existentes. No lo utilice para solicitudes genéricas de prioridades, próximos pasos o un plan de implementación a menos que el usuario solicite explícitamente actualizar o establecer documentos de planificación.
