Mantieni la pianificazione del progetto con tre documenti distinti: una roadmap generale, un elenco di cose da fare a breve termine e un piano dettagliato attivo. Utilizza questa competenza quando l'utente desidera creare, pulire o reimpostare documenti di pianificazione del repository come una roadmap, un file TODO o un piano attivo o quando tali ruoli sono confusi tra i file esistenti. Non utilizzarlo per richieste generiche di priorità, passaggi successivi o piano di implementazione a meno che l'utente non chieda esplicitamente di aggiornare o stabilire documenti di pianificazione.
