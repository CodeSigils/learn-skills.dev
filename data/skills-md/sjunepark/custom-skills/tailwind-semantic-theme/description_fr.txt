Configurez ou refactorisez le thème de l'application Tailwind v4 autour de jetons CSS sémantiques compatibles shadcn sans utiliser shadcn lui-même. À utiliser uniquement lorsque l'utilisateur demande explicitement cette compétence par son nom ou demande explicitement cette méthodologie exacte : variables de thème OKLCH dans `:root` et `.dark`, mode sombre basé sur la classe, `@theme inline` et dénomination de jeton compatible shadcn pour une future compatibilité avec l'interface utilisateur.
