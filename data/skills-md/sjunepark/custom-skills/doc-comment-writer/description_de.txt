Fügen Sie Dokumentkommentare in den genannten Quelldateien hinzu oder verbessern Sie sie, ohne den Code mit offensichtlichen Neuformulierungen zu füllen. Verwenden Sie es immer dann, wenn der Benutzer Code dokumentieren, Dokumentkommentare hinzufügen, Module/Funktionen/Typen für zukünftige Betreuer erklären, einen nützlichen Überblick auf Dateiebene hinzufügen oder eine Datei verständlich machen möchte, ohne ihre interne Logik nachzuvollziehen, auch wenn er nicht ausdrücklich „Dokumentkommentare“ sagt.
