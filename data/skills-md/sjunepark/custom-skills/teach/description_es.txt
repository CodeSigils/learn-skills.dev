Enseñe al usuario cómo funciona el código, un subsistema o un concepto técnico relevante en un orden de aprendizaje claro, con fragmentos integrados y diagramas ASCII cuando mejoren materialmente la comprensión. Úselo siempre que el usuario solicite que se le enseñe una parte del código base actual, un flujo de funciones, un área de arquitectura, un módulo, un límite de API, un flujo de datos o una biblioteca o concepto de marco relevante necesario para comprender el código. Prefiera esta habilidad cuando el usuario quiera explicación, comprensión o aprendizaje guiado en lugar de implementación, y cuando quiera fragmentos en lugar de referencias de archivos o líneas. Si la solicitud es específicamente sobre qué cambió en una diferencia, confirmación o parche, prefiera "explicador de cambios".
