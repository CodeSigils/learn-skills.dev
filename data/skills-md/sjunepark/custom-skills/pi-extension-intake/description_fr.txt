Évaluez, importez, vendez, forkez et renforcez les extensions Pi tierces avec un flux de travail axé sur le contrôle. À utiliser chaque fois que l'utilisateur souhaite copier une extension pi dans son propre dépôt, décider entre la vente, le fork interne, le package de correctifs et la dépendance directe, auditer le code d'extension faiblement entretenu, supprimer le comportement d'auto-installation ou d'installation réseau, ou comprendre la véritable limite de confiance derrière un petit package wrapper. À utiliser également lorsque l'utilisateur dit des choses comme « dois-je simplement copier cette extension », « fournisseur de ce dépôt », « fork vs patch-package », « je ne veux pas faire confiance à ce package npm » ou « apporter cette extension pi en interne ».
