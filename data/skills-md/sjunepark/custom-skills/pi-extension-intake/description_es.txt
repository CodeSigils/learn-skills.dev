Evalúe, importe, proporcione, bifurque y refuerce extensiones pi de terceros con un flujo de trabajo centrado en el control. Úselo siempre que el usuario desee copiar una extensión pi en su propio repositorio, decidir entre proveedor, bifurcación interna, paquete de parche o dependencia directa, auditar el código de extensión con mantenimiento débil, eliminar el comportamiento de autoinstalación o instalación en red, o comprender el límite de confianza real detrás de un pequeño paquete contenedor. Utilícelo también cuando el usuario diga cosas como "¿debería simplemente copiar esta extensión?", "proveedor de este repositorio", "fork vs patch-package", "no quiero confiar en este paquete npm" o "traer esta extensión pi internamente".
