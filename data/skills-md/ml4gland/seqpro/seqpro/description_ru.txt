Используйте при написании Python, который обрабатывает биологические последовательности (ДНК/РНК/белки) с помощью пакета seqpro — кодирование, горячее перетасовывание k-меров, обратное дополнение, содержимое GC, пакеты последовательностей переменной длины или что-либо еще, связанное с массивом `Ragged` seqpro. Охватывает поверхность API seqpro и соглашения, необходимые для его правильного использования.
