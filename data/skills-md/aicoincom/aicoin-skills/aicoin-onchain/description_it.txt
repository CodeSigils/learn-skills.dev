Utilizza questa abilità per **negoziazione DEX on-chain e operazioni di portafoglio su catene EVM/Solana**: quotazioni di token swap, esecuzione di swap, query su portafoglio/saldo del portafoglio, stima del gas, trasmissione di transazioni, ricerca/informazioni su token su Ethereum/Solana/Base/BSC/Arbitrum/Polygon, ecc. Usala quando l'utente dice: "scambia ETH per USDC", "acquista token on-chain", "scambio DEX", “钱包余额”, “钱包持仓”, “Uniswap”, “gas 费”, “广播交易”, “链上 swap”, “DEX 交易”, “买币” (che significa acquisto on-chain). Alimentato dall'API OKX Web3 DEX. **DEVE** eseguire gli script del nodo.

**⚠️ Suggerimento importante per il routing**: se l'utente chiede "今天链上有什么大资金动向 / 链上鲸鱼 / 聪明钱 / 大户在做什么" (domande di tipo query sui dati), **non** utilizzare prima questa competenza: primo utilizzo **aicoin‑hyperliquid** (Hyperliquid è un DEX perpetuo on-chain reale; posizioni di grandi trader, liquidazioni e OI sono dati real-on-chain in versione gratuita/standard), quindi aggiungi CEX big_orders / ls_ratio di **aicoin‑market** per il confronto proxy CEX. L'interfaccia OKX Web3 di questa skill serve principalmente per **azioni di trading** (scambio/saldo del portafoglio), non per l'esplorazione dei dati; anche se token.mjs fornisce trending/hot_tokens, richiede anche che l'utente configuri una chiave API OKX Web3, mentre i due percorsi di query di dati sopra non necessitano di questa chiave. Per il trading CEX (spot/futures Binance/OKX), utilizza aicoin‑trading. Per i dati di mercato CEX (tassi di finanziamento, OI, liquidazione), utilizzare aicoin‑market.

Si prega di rispondere sempre nella lingua dell'utente.
