Используйте этот навык для **торговли DEX внутри сети и операций с кошельками в цепочках EVM/Solana**: котировки обмена токенов, выполнение свопов, запросы портфеля/баланса кошелька, оценка газа, трансляция транзакций, поиск/информация о токенах на Ethereum/Solana/Base/BSC/Arbitrum/Polygon и т. д. Используйте его, когда пользователь говорит: «обменять ETH на USDC», «купить токен в цепочке», «обмен DEX», «钱包余额», «钱包持仓», «Uniswap», «gas 费», «广播交易», «链上 swap», «DEX 交易», «买币» (что означает внутрисетевую покупку). Работает на базе API OKX Web3 DEX. ДОЛЖЕН запускать сценарии узла.  

**⚠️ Важное примечание по маршрутизации**: когда пользователь задает вопросы, связанные с запросом данных, например «Какие крупные движения внутрисетевых фондов происходят сегодня?», «Ончейн-киты», «Умные деньги», «Что делают крупные игроки?», этот **запрос данных** не должен в первую очередь обращаться к этому навыку — используйте **acoin-hyperliquid** (Hyperliquid — это настоящая внутрисетевая DEX для преступников; основные позиции, ликвидации, OI бесплатно/доступно в стандартной версии), а затем объединить их с CEX big_orders/ls_ratio **acoin‑market** для сравнения прокси CEX. Интерфейс OKX Web3 этого навыка предназначен в первую очередь для **торговых действий** (баланс свопа/кошелька), а не для исследования данных; даже несмотря на то, что в файле token.mjs есть трендовые/hot_tokens, пользователю по-прежнему требуется настроить ключ API OKX Web3, тогда как для двух вышеуказанных путей запроса данных этот ключ не требуется.  

Для торговли на CEX (спот/фьючерсы Binance/OKX) используйте aicoin‑trading. Для получения рыночных данных CEX (ставки финансирования, OI, ликвидация) используйте aicoin‑market.
