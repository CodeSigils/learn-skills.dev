Используйте этот навык для **торговли DEX внутри сети и операций с кошельками в цепочках EVM/Solana**: котировки обмена токенов, выполнение свопов, запросы портфеля/баланса кошелька, оценка газа, трансляция транзакций, поиск/информация о токенах на Ethereum/Solana/Base/BSC/Arbitrum/Polygon и т. д. Используйте его, когда пользователь говорит: «обменять ETH на USDC», «купить токен в цепочке», «обмен DEX», «钱包余额», «钱包持仓», «Uniswap», «gas 费», «广播交易», «链上 swap», «DEX 交易», «买币» (что означает внутрисетевую покупку). Работает на базе API OKX Web3 DEX. **ДОЛЖЕН** запускать сценарии узлов.

**⚠️ Важный совет по маршрутизации**: если пользователь задает вопрос «今天链上有什么大资金动向 / 链上鲸鱼 / 聪明钱 / 大户在做什么» (вопросы типа запроса данных), **не** используйте этот навык. сначала используйте **acoin‑hyperliquid** (Hyperliquid — это настоящая бессрочная DEX в цепочке; позиции крупных трейдеров, ликвидация, OI — это бесплатные/стандартные данные в реальной цепочке), затем добавьте CEX big_orders/ls_ratio **acoin‑market** для сравнения прокси CEX. Интерфейс OKX Web3 этого навыка в основном служит для **торговых действий** (своп/баланс кошелька), а не для исследования данных; даже если token.mjs предоставляет тренды/hot_tokens, он также требует от пользователя настроить ключ API OKX Web3, тогда как для двух вышеуказанных путей запроса данных этот ключ не требуется. Для торговли на CEX (спот/фьючерсы Binance/OKX) используйте aicoin‑trading. Для получения рыночных данных CEX (ставки финансирования, OI, ликвидация) используйте aicoin‑market.
