Utilisez cette compétence pour **le trading DEX en chaîne et les opérations de portefeuille sur les chaînes EVM/Solana** : cotations d'échange de jetons, exécution de swap, requêtes de portefeuille/solde de portefeuille, estimation du gaz, diffusion de transactions, recherche/informations de jetons sur Ethereum/Solana/Base/BSC/Arbitrum/Polygon, etc. Utilisez-la lorsque l'utilisateur dit : "échanger ETH contre USDC", "acheter un jeton en chaîne", "DEX swap", "钱包余额", « 钱包持仓 », « Uniswap », « gas 费 », « 广播交易 », « 链上 swap », « DEX 交易 », « 买币 » (ce qui signifie achat en chaîne). Propulsé par l'API OKX Web3 DEX. **DOIT** exécuter des scripts de nœud.

**⚠️ Conseil de routage important** : Si l'utilisateur pose « 今天链上有什么大资金动向 / 链上鲸鱼 / 聪明钱 / 大户在做什么 » (questions de type requête de données), n'utilisez **pas** cette compétence en premier. utilisez **aicoin‑hyperliquid** (Hyperliquid est un véritable DEX perpétuel en chaîne ; les positions des grands commerçants, les liquidations et les OI sont des données réelles en chaîne en version gratuite/standard), puis ajoutez le CEX big_orders / ls_ratio de **aicoin‑market** pour la comparaison par proxy CEX. L'interface OKX Web3 de cette compétence sert principalement aux **actions de trading** (solde de swap/portefeuille), et non à l'exploration de données ; même si token.mjs fournit des Trending/hot_tokens, il nécessite également que l'utilisateur configure une clé API OKX Web3, alors que les deux chemins de requête de données ci-dessus n'ont pas besoin de cette clé. Pour le trading CEX (Binance/OKX spot/futures), utilisez aicoin‑trading. Pour les données du marché CEX (taux de financement, OI, liquidation), utilisez aicoin‑market.

Veuillez toujours répondre dans la langue de l’utilisateur.
