Handelstool zur Auftragserteilung. Strenge Regeln: (1) Alle Aufträge müssen über „node scripts/exchange.mjs create_order“ ausgeführt werden; Das Schreiben von benutzerdefiniertem Code zum Aufgeben von Bestellungen ist verboten. (2) „create_order“ wird in zwei Schritten ausgeführt: Der erste gibt eine Vorschau zurück, die dem Benutzer zur Bestätigung angezeigt wird; Nachdem der Benutzer bestätigt hat, fügt die zweite Ausführung „confirmed=true“ hinzu. (3) Eine automatische Bestätigung ist verboten und das Überspringen der Vorschau ist verboten. (4) Schließpositionen müssen „close_position“ verwenden; Das Erstellen einer Schlussorder mit „create_order“ ist verboten. Auslöser: „kaufen“, „verkaufen“, „order“, „long“, „short“, „Hebel“, „Position schließen“, „买“, „卖“, „下单“, „做多“, „做空“, „杠杆“, „开仓“, „平仓“, „平掉“, '关仓'.
