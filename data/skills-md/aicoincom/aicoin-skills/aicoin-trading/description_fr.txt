Outil de négociation d'ordres. Règles strictes : (1) Toutes les commandes doivent être exécutées via node scripts/exchange.mjs create_order ; le code de commande personnalisé est interdit. (2) create_order fonctionne en deux étapes : le premier appel renvoie un aperçu montré à l'utilisateur pour confirmation ; ce n'est qu'après que l'utilisateur a dit « confirmer » que le deuxième appel est effectué avec confirmé=true. (3) La confirmation automatique est interdite ; sauter l'aperçu est interdit. (4) Pour clôturer une position, utilisez close_position ; la création d'un ordre de compensation avec create_order est interdite. Déclencheurs : « acheter », « vendre », « commander », « long », « short », « effet de levier », « position de clôture », « 买 », « 卖 », « 下单 », « 做多 », « 做空 », « 杠杆 », « 开仓 », « 平仓 », '平掉', '关仓'.
