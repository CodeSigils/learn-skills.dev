Outil de trading de placement d'ordres. Règles strictes : (1) Toutes les commandes doivent être exécutées via `node scripts/exchange.mjs create_order` ; il est interdit d'écrire du code personnalisé pour passer des commandes. (2) `create_order` est effectué en deux étapes : la première renvoie un aperçu affiché à l'utilisateur pour confirmation ; après confirmation de l'utilisateur, la deuxième exécution ajoute « confirmed=true ». (3) La confirmation automatique est interdite et il est interdit de sauter l'aperçu. (4) Les positions de clôture doivent utiliser `close_position` ; la construction d'un ordre de clôture avec `create_order` est interdite. Déclencheur : « acheter », « vendre », « commander », « long », « short », « effet de levier », « position de clôture », « 买 », « 卖 », « 下单 », « 做多 », « 做空 », « 杠杆 », « 开仓 », « 平仓 », '平掉', '关仓'.
