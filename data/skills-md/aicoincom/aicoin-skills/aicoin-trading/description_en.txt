Order placement trading tool. Strict rules: (1) All orders must be executed via `node scripts/exchange.mjs create_order`; writing custom code to place orders is prohibited. (2) `create_order` is performed in two steps: the first returns a preview displayed to the user for confirmation; after the user confirms, the second execution adds `confirmed=true`. (3) Automatic confirmation is forbidden, and skipping the preview is prohibited. (4) Closing positions must use `close_position`; constructing a closing order with `create_order` is prohibited. Trigger: 'buy', 'sell', 'order', 'long', 'short', 'leverage', 'close position', '买', '卖', '下单', '做多', '做空', '杠杆', '开仓', '平仓', '平掉', '关仓'.
