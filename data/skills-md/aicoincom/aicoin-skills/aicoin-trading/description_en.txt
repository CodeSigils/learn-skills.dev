Order-trading tool. Strict rules: (1) All orders must be executed via node scripts/exchange.mjs create_order; custom order code is forbidden. (2) create_order works in two steps: the first call returns a preview shown to the user for confirmation; only after the user says “confirm” is the second call made with confirmed=true. (3) Auto-confirmation is forbidden; skipping the preview is forbidden. (4) To close a position, use close_position; creating an offsetting order with create_order is forbidden. Triggers: 'buy', 'sell', 'order', 'long', 'short', 'leverage', 'close position', '买', '卖', '下单', '做多', '做空', '杠杆', '开仓', '平仓', '平掉', '关仓'.
