Торговый инструмент для размещения ордеров. Строгие правила: (1) Все ордера должны исполняться через `node scripts/exchange.mjs create_order`; написание собственного кода для размещения заказов запрещено. (2) `create_order` выполняется в два этапа: первый возвращает предварительный просмотр, отображаемый пользователю для подтверждения; после того, как пользователь подтвердит, второе выполнение добавляет `confirmed=true`. (3) Автоматическое подтверждение запрещено, а пропуск предварительного просмотра запрещен. (4) Для закрытия позиций необходимо использовать close_position; построение ордера на закрытие с помощью create_order запрещено. Триггер: «купить», «продать», «ордер», «длинная позиция», «короткая позиция», «кредитное плечо», «закрыть позицию», «买», «卖», «下单», «做多», «做空», «杠杆», «开仓», «平仓», «平掉», '关仓'.
