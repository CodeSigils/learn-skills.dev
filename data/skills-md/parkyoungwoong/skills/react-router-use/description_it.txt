(heropy) Da utilizzare quando si aggiunge React Router (modalità dati) a un progetto React (Vite/CSR) esistente, si configurano percorsi/layout/navigazione o si implementano funzionalità a livello di percorso come caricatori, percorsi protetti, segmenti dinamici, routing nidificato, pagine 404, caricamento lento, animazioni di transizione di pagina o reindirizzamenti di hosting SPA (Vercel/Netlify/Firebase).
