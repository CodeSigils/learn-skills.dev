(heropy) React 프로젝트에서 Zustand(주스탠드)로 전역 상태(스토어)를 설계, 작성할 때 사용한다. 사용자가 "zustand", "주스탠드", "전역 상태", "스토어 분리", "스토어 생성", "스토어 만들어 줘", "OO 스토어 생성", "상태 관리 라이브러리", "create 함수", "useShallow", "persist/immer/devtools 미들웨어"를 언급하거나, React 컴포넌트 간 prop drilling을 해소하려 할 때 반드시 이 스킬을 따른다. 스토어 정의 패턴(액션 분리, 초기화, 삭제), 선택자 사용 규칙, 미들웨어 합성 순서, TypeScript 작성법, 트리거 입력으로 스토어 파일을 자동 생성하는 절차까지 포함한다.
