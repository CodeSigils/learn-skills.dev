(heropy) Используется при проектировании и написании глобального состояния (магазина) с помощью Zustand (주스탠드) в проекте React. Когда пользователь упоминает «zustand», «주스탠드», «глобальное состояние», «разделение хранилища», «создание хранилища», «создание магазина», «создание объектно-ориентированного хранилища», «библиотеку управления состоянием», «создать функцию», «useShallow», «промежуточное программное обеспечение persist/immer/devtools» или пытается решить проблему детализации свойств между компонентами React, необходимо следовать этому навыку. Он включает в себя шаблоны определения хранилища (разделение действий, инициализация, удаление), правила использования селекторов, порядок композиции промежуточного программного обеспечения, рекомендации по написанию TypeScript и процедуру автоматического создания файлов хранилища из входных данных триггера.
