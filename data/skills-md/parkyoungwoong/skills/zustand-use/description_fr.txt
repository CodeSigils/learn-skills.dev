(heropy) Il est utilisé lors de la conception et de l'écriture d'un état global (magasin) avec Zustand (Juststand) dans un projet React. Lorsque l'utilisateur mentionne « zustand », « 주스탠드 », « état global », « séparation de magasin », « création de magasin », « créer un magasin », « création de magasin OO », « bibliothèque de gestion d'état », « créer une fonction », « useShallow » ou « middleware persist/immer/devtools », ou tente d'éliminer le perçage d'accessoires entre les composants React, cette compétence doit être suivie. Il comprend le modèle de définition du magasin (séparation des actions, initialisation, suppression), les règles d'utilisation du sélecteur, l'ordre de composition du middleware, les directives d'écriture TypeScript et la procédure pour générer automatiquement un fichier de magasin à partir d'une entrée de déclencheur.
