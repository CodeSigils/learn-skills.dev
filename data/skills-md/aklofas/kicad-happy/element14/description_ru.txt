Ищите электронные компоненты в Newark, Farnell и element14 — находите детали по MPN или номеру детали дистрибьютора, проверяйте цены/наличие на складе, загружайте технические описания, анализируйте спецификации. Один унифицированный API охватывает все три витрины (Newark для США, Farnell для Великобритании/ЕС, element14 для Азиатско-Тихоокеанского региона). Бесплатный ключ API, простая аутентификация по параметрам запроса, без OAuth. Таблицы данных загружаются непосредственно с CDN Farnell.com без защиты от ботов. Синхронизируйте и поддерживайте локальный каталог таблиц для проекта KiCad. Используйте этот навык, когда пользователь упоминает Ньюарк, Фарнелл, element14, ему нужны детали от дистрибьютора за пределами США, он хочет сравнить цены в разных регионах или ему нужны таблицы данных из источника, который не требует сложной аутентификации API. Для получения информации о таблицах перекрестных ссылок пакетов и рабочем процессе спецификации см. навык bom.
