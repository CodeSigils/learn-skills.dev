Newark、Farnell、Element14 で電子部品を検索します。MPN または代理店の部品番号で部品を検索し、価格/在庫を確認し、データシートをダウンロードし、仕様を分析します。 1 つの統合 API で 3 つのストアフロント (米国の場合は Newark、英国/EU の場合は Farnell、APAC の場合は element14) をすべてカバーします。無料の API キー、単純なクエリパラメータ認証、OAuth なし。データシートはボット保護なしで farnell.com CDN から直接ダウンロードされます。 KiCad プロジェクトのローカル データシート ディレクトリを同期して維持します。このスキルは、ユーザーが Newark、Farnell、element14 について言及した場合、米国以外の代理店からの部品が必要な場合、地域間の価格を比較したい場合、または複雑な API 認証を必要としないソースからのデータシートが必要な場合に使用します。パッケージ相互参照テーブルと BOM ワークフローについては、「bom」スキルを参照してください。
