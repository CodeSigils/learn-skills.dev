Verwenden Sie diese Option, wenn der Benutzer mithilfe von kimi-webbridge ein CLI-Tool erstellen möchte, um Browserinteraktionen auf einer bestimmten Website zu automatisieren. Wird aufgerufen, wenn der Benutzer sagt: „Erstelle eine CLI für X-Site“, „Erstelle ein Tool zur Automatisierung von X“ oder möchte eine Website programmgesteuert über einen KI-Agenten steuern.
