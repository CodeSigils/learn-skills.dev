Используйте, когда пользователь хочет создать инструмент CLI для автоматизации взаимодействия браузера на определенном веб-сайте с помощью kimi-webbridge. Вызывается, когда пользователь говорит «создать CLI для сайта X», «создать инструмент для автоматизации X» или хочет управлять веб-сайтом программно через агента искусственного интеллекта.
