Assistente intelligente per la pulizia dell'unità Windows C. Utilizzare questa abilità quando l'utente deve pulire l'unità C, liberare spazio su disco, eliminare file spazzatura, pulire file temporanei del sistema, cancellare le cache delle applicazioni, ottimizzare lo spazio su disco o eseguire qualsiasi attività correlata alla pulizia del sistema Windows. Supporta varie modalità di pulizia come pulizia sicura, anteprima simulata, backup e ripristino. Anche se la "pulizia" non è menzionata esplicitamente, purché la richiesta coinvolga la gestione dello spazio su disco, la gestione dei file spazzatura, l'ottimizzazione del sistema, ecc., questa abilità dovrebbe essere utilizzata.
