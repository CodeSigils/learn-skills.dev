Windows Cドライブクリーンアップスマートアシスタント。このスキルは、ユーザーが C ドライブのクリーンアップ、ディスク領域の解放、ジャンク ファイルの削除、システム一時ファイルのクリーンアップ、アプリケーション キャッシュのクリア、ディスク領域の最適化、または Windows システムのクリーンアップ関連タスクを実行する必要がある場合に使用します。安全なクリーニング、シミュレートされたプレビュー、バックアップと復元などのさまざまなクリーニング モードをサポートしています。 「クリーンアップ」について明示的に言及されていない場合でも、ディスク領域の管理、ジャンク ファイルの処理、システムの最適化などが必要な場合には、このスキルを使用する必要があります。
