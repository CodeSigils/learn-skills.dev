Извлеките исходные таблицы CSV и XLSX для импорта с отслеживанием Rye. Используйте, когда пользователю необходимо проверить табличные исходные файлы, выдать NDJSON на уровне строк с происхождением, сопоставить исходные поля с целевыми записями, сгруппировать множество исходных строк в родительские записи с происхождением source_set, поэтапно извлечь данные или создать навык приема для конкретной предметной области поверх общих табличных примитивов.
