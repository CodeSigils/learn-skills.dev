NousResearch Hermes Agent Abilità di integrazione universale. Richiama le funzionalità principali di Hermes Agent tramite CLI:
- 🚀 Sistema di abilità di auto-miglioramento (crea automaticamente abilità riutilizzabili dalle attività)
- 🧠 Memoria persistente (ricerca full-text FTS5 + riepilogo LLM)
- 🤖 Delega del sub-agente (isolamento delle attività ed elaborazione parallela)
- 🔌Integrazione bidirezionale MCP
- 🌐Automazione del browser
- 💻 Esecuzione del codice
- 🔍Ricerche sul web
- 📦 Installazione completamente portatile con un clic per qualsiasi istanza di Claw/WorkBuddy
