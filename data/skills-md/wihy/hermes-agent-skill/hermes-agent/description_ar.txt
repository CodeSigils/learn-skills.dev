NousResearch Hermes وكيل مهارة التكامل العالمي. استدعاء القدرات الأساسية لوكيل Hermes عبر واجهة سطر الأوامر (CLI):
- 🚀 نظام مهارات التحسين الذاتي (إنشاء مهارات قابلة لإعادة الاستخدام تلقائيًا من المهام)
- 🧠 الذاكرة المستمرة (بحث النص الكامل FTS5 + تلخيص LLM)
- 🤖 تفويض الوكيل الفرعي (عزل المهام والمعالجة المتوازية)
- 🔌 التكامل ثنائي الاتجاه MCP
- 🌐 أتمتة المتصفح
- 💻 تنفيذ الكود
- 🔍 بحث الويب
- 📦 محمول بالكامل، تثبيت بنقرة واحدة لأي مثيل Claw/WorkBuddy
