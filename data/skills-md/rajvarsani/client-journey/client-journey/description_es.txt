Genere un recorrido sintético de varios años para el cliente de asesoramiento financiero como transcripciones completas de reuniones. Produce un archivo inicial delgado de detalles básicos del cliente como líneas de valores clave que se pueden copiar y pegar, luego una larga conversación de asesor a cliente por reunión, una incorporación seguida de revisiones anuales, cada una de las cuales incluye todos los datos de ese año en el diálogo mismo. Úselo para obtener datos de prueba de búsqueda de hechos realistas, historiales de clientes de demostración o datos reales para procesos de extracción de documentos.
