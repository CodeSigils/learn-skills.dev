Générez un parcours client synthétique sur plusieurs années en matière de conseils financiers sous forme de transcriptions complètes des réunions. Produit un mince fichier de départ contenant les détails de base du client sous forme de lignes clé-valeur copiées-collées, puis une longue conversation conseiller-client par réunion, une intégration suivie d'examens annuels, chacun comportant tous les faits de cette année dans le dialogue lui-même. À utiliser pour des données de test réalistes, des historiques de clients de démonstration ou une vérité terrain pour les pipelines d'extraction de documents.
