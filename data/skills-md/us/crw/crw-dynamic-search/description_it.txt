Ricerca web programmatica e scraping con isolamento del contesto. Utilizzare per qualsiasi ricerca
attività in cui è necessario effettuare ricerche sul Web, filtrare risultati ed estrarre specifici
informazioni, senza inondare la finestra di contesto con HTML grezzo e boilerplate.
Questo è il più grande risparmio di token nel set di abilità crw. Attivato da "search
per", "cerca", "trova", "ricerca", "quali sono le ultime novità" o qualsiasi altra domanda in merito
richiede informazioni web aggiornate. Utilizzare anche quando viene chiesto di "cercare e filtrare", "trova
le parti importanti" o qualsiasi attività in cui si sospetta che l'output grezzo sarà di grandi dimensioni
(scrap multipagina, aggregazione di notizie, ricerca competitiva).
