Raschia, scansiona, mappa, cerca, analizza ed estrai dati web con fastCRW: il
Alternativa Firecrawl open source e auto-ospitabile (singolo binario Rust, ~6 MB
RAM, API /v1 + /v2 compatibile con Firecrawl). Utilizzare ogni volta che l'utente ha bisogno della pagina
contenuto, estrazione a livello di sito, rilevamento URL, ricerca web, analisi PDF,
JSON strutturato dalle pagine o rilevamento delle modifiche. Utilizzare anche quando l'utente
menziona Firecrawl, Tavily, Crawl4AI o "scrape/crawl/map/fetch/get the"
pagina/leggi questo sito/cerca nel Web" — crw è un drop-in per gli SDK di Firecrawl.
