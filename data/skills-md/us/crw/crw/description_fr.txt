Grattez, explorez, mappez, recherchez, analysez et extrayez des données Web avec fastCRW — le
alternative Firecrawl open source et auto-hébergable (un seul binaire Rust, ~ 6 Mo)
RAM, API /v1 + /v2 compatible Firecrawl). Utiliser chaque fois que l'utilisateur a besoin d'une page
contenu, extraction à l'échelle du site, découverte d'URL, recherche sur le Web, analyse PDF,
JSON structuré à partir de pages ou suivi des modifications. À utiliser également lorsque l'utilisateur
mentionne Firecrawl, Tavily, Crawl4AI ou "scrape/crawl/map/fetch/get the
page/lire ce site/rechercher sur le Web" — crw est un complément pour les SDK Firecrawl.
