Extraiga, rastree, mapee, busque, analice y extraiga datos web con fastCRW: el
Alternativa Firecrawl de código abierto y autohospedable (binario Rust único, ~6 MB
RAM, API /v1 + /v2 compatible con Firecrawl). Úselo siempre que el usuario necesite la página.
contenido, extracción de todo el sitio, descubrimiento de URL, búsqueda web, análisis de PDF,
JSON estructurado a partir de páginas o seguimiento de cambios. También se utiliza cuando el usuario
menciona Firecrawl, Tavily, Crawl4AI o "scrape/crawl/map/fetch/get the
página/leer este sitio/buscar en la web" — crw es un complemento para los SDK de Firecrawl.
