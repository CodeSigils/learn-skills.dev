Собирайте, сканируйте, сопоставляйте, ищите, анализируйте и извлекайте веб-данные с помощью fastCRW —
самостоятельная альтернатива Firecrawl с открытым исходным кодом (один двоичный файл Rust, ~6 МБ)
ОЗУ, API-интерфейс /v1 + /v2, совместимый с Firecrawl). Используйте всякий раз, когда пользователю нужна страница
контент, извлечение по всему сайту, обнаружение URL-адресов, веб-поиск, анализ PDF-файлов,
структурированный JSON со страниц или отслеживание изменений. Также используйте, когда пользователь
упоминает Firecrawl, Tavily, Crawl4AI или «очистить/сканировать/картировать/извлечь/получить
страница/прочитайте этот сайт/поищите в Интернете» — crw — это дополнительный модуль для Firecrawl SDK.
