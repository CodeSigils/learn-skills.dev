Разберите локальный или удаленный ФАЙЛ (PDF) в уценку или структурированный JSON с помощью
быстрыйCRW. Используйте, когда источником является файл на диске — «разобрать этот PDF-файл», «извлечь
текст из этого документа», «прочитать этот отчет», «конвертировать PDF в уценку».
Правило маршрутизации: URL → использовать crw-scrape; файл на диске → используйте crw-parse. Шаг 5
лестницы рабочего процесса crw.
