FUI Web モジュールを開発、構造化、レビュー、または変更するときにこのスキルを使用します。これは、メタデータ駆動型アーキテクチャ (module.json)、必須のグリッド レイアウト システム、アクション プロトコル、および環境を考慮したワークフロー ルールに関する厳格なガイドラインを提供します。 Apply the canonical module structure in both editor and chat contexts.ワークスペースにアクセスできるエディターまたは拡張コンテキストで、実際のモジュール ファイルを操作します。ワークスペースにアクセスできないチャットまたはエージェント チャット コンテキストでは、応答内の同じモジュール構造を仮想化しながら、貼り付けられた成果物から作業します。
