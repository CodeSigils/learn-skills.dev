Создает готовые к использованию структуры каталогов для проектов агентного ИИ с использованием Agent-OS v3 (методы Builder). Используйте, когда пользователь запрашивает настройку, сборку, инициализацию или реструктуризацию проекта для агентной разработки, включая монорепозитории, одиночные репозитории, многоязычные репозитории, проекты с полным стеком, серверной частью, интерфейсом или промежуточным программным обеспечением. Триггеры по «каталогу scaffold», «структуре проекта», «агентному каркасу», «макету проекта», «инициализации проекта AI», «структуре каталогов», «настройке агента-ОС», «макету монорепозитория», «структуре IaC».
