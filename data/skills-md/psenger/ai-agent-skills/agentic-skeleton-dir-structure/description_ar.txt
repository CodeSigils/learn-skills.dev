السقالات هياكل الدليل الجاهزة للإنتاج لمشاريع الذكاء الاصطناعي الوكيل باستخدام Agent-OS v3 (طرق الإنشاء). يُستخدم عندما يطلب المستخدم إعداد مشروع أو دعمه أو تهيئته أو إعادة هيكلته للتطوير الوكيل - بما في ذلك اتفاقيات إعادة الشراء الأحادية أو اتفاقيات إعادة الشراء الفردية أو اتفاقيات إعادة الشراء متعددة اللغات أو المشاريع الكاملة أو الواجهة الخلفية أو الواجهة الأمامية أو البرامج الوسيطة. المشغلات على "دليل السقالة"، و"بنية المشروع"، و"السقالة الوكيلة"، و"تخطيط المشروع"، و"تهيئة مشروع الذكاء الاصطناعي"، و"بنية الدليل"، و"إعداد وكيل نظام التشغيل"، و"تخطيط mono-repo"، و"بنية IaC".
