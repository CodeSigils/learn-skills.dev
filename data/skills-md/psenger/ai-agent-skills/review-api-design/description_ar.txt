يقوم بمراجعة تصميمات REST API أثناء مرحلة التخطيط مقابل الأمان والمرونة والتصميم وأفضل الممارسات التشغيلية. يُستخدم عند فحص تصميم واجهة برمجة التطبيقات (API)، أو مراجعة مواصفات OpenAPI، أو نقد بنية نقطة النهاية، أو تقييم عقود واجهة برمجة التطبيقات (API) قبل التنفيذ. مشغلات على "مراجعة واجهة برمجة التطبيقات الخاصة بي" أو "مراجعة تصميم واجهة برمجة التطبيقات" أو "مراجعة REST" أو "فحص واجهة برمجة التطبيقات هذه". يتم تنشيطه بشكل طبيعي أثناء وضع الخطة عندما يتم تصميم نقاط نهاية API أو العقود أو حدود الخدمة. تأكد من استخدام هذه المهارة عندما يتم تقديم تصميم واجهة برمجة التطبيقات (API)، أو قائمة نقاط النهاية، أو مواصفات OpenAPI للحصول على التعليقات.
