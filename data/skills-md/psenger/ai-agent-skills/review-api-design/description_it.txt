Esamina i progetti delle API REST durante la fase di pianificazione rispetto a sicurezza, resilienza, progettazione e best practice operative. Da utilizzare durante il controllo della progettazione di un'API, la revisione di una specifica OpenAPI, la critica della struttura dell'endpoint o la valutazione dei contratti API prima dell'implementazione. Si attiva su "revisione della mia API", "revisione della progettazione API", "revisione REST" o "controlla questa API". Si attiva naturalmente durante la modalità di pianificazione durante la progettazione degli endpoint API, dei contratti o dei limiti del servizio. Assicurati di utilizzare questa competenza ogni volta che viene presentata una progettazione API, un elenco di endpoint o una specifica OpenAPI per ottenere feedback.
