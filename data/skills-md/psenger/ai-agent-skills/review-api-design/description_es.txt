Revisa los diseños de API REST durante la fase de planificación comparándolos con las mejores prácticas operativas, de seguridad, de resiliencia y de diseño. Úselo al examinar un diseño de API, revisar una especificación de OpenAPI, criticar la estructura de puntos finales o evaluar contratos de API antes de la implementación. Activadores de "revisar mi API", "revisión de diseño de API", "revisión REST" o "examinar esta API". Se activa de forma natural durante el modo de plan cuando se diseñan puntos finales de API, contratos o límites de servicios. Asegúrese de utilizar esta habilidad siempre que se presente un diseño de API, una lista de puntos finales o una especificación de OpenAPI para recibir comentarios.
