На этапе планирования проверяет проекты REST API на предмет соответствия лучшим практикам безопасности, отказоустойчивости, проектирования и эксплуатации. Используйте при проверке проекта API, просмотре спецификации OpenAPI, критике структуры конечных точек или оценке контрактов API перед реализацией. Триггеры: «проверка моего API», «проверка дизайна API», «проверка REST» или «проверка этого API». Активируется естественным образом в режиме планирования, когда разрабатываются конечные точки API, контракты или границы служб. Обязательно используйте этот навык всякий раз, когда проект API, список конечных точек или спецификация OpenAPI представляются для обратной связи.
