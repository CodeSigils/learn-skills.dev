Überprüft REST-API-Designs während der Planungsphase im Hinblick auf Sicherheit, Belastbarkeit, Design und betriebliche Best Practices. Verwenden Sie es, wenn Sie ein API-Design überprüfen, eine OpenAPI-Spezifikation überprüfen, die Endpunktstruktur kritisieren oder API-Verträge vor der Implementierung bewerten. Wird bei „meine API überprüfen“, „API-Designüberprüfung“, „REST-Überprüfung“ oder „überprüfen Sie diese API“ ausgelöst. Wird im Planmodus auf natürliche Weise aktiviert, wenn API-Endpunkte, Verträge oder Servicegrenzen entworfen werden. Stellen Sie sicher, dass Sie diese Fertigkeit verwenden, wenn ein API-Design, eine Endpunktliste oder eine OpenAPI-Spezifikation zur Rückmeldung vorgelegt wird.
