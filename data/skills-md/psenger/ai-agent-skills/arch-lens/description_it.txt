Esplora una base di codice per l'attrito architetturale attraverso la lente del principio del modulo profondo di Ousterhout (interfaccia piccola, implementazione di grandi dimensioni). Flusso di lavoro interattivo in sette passaggi: un agente secondario Explore naviga nella base di codice in modo organico: l'attrito che sperimenta È il segnale. Presenta i cluster candidati con motivi di accoppiamento, modelli di chiamata, tipi condivisi, categorie di dipendenza e test esistenti che un test di confine verrebbe sostituito. L'utente sceglie cosa esplorare, inquadra il problema, quindi 3-4 sottoagenti paralleli progettano interfacce concorrenti del modulo profondo. Il progetto scelto diventa un file di azione RFC strutturato leggibile da GitHub MCP o ROVO (Jira) MCP. Da utilizzare quando l'utente dice "revisione dell'arco", "trova moduli poco profondi", "profondità del modulo", "modulo profondo", "Ousterhout", "verifica di testabilità", "accoppiamento di superficie", "interfacce di progettazione", "problemi RFC" o "attrito architettonico".
