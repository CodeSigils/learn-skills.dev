Ousterhout의 심층 모듈 원칙(작은 인터페이스, 대규모 구현)을 통해 아키텍처 마찰에 대한 코드베이스를 탐색합니다. 7단계 대화형 작업 흐름: Explore 하위 에이전트는 코드베이스를 유기적으로 탐색합니다. 여기서 경험하는 마찰은 신호입니다. 결합 이유, 호출 패턴, 공유 유형, 종속성 범주 및 경계 테스트가 대체할 기존 테스트를 사용하여 후보 클러스터를 표시합니다. 사용자는 탐색할 대상을 선택하고 문제의 틀을 잡은 다음 3~4개의 병렬 하위 에이전트가 경쟁하는 심층 모듈 인터페이스를 설계합니다. 선택한 디자인은 GitHub MCP 또는 ROVO(Jira) MCP에서 읽을 수 있는 구조화된 RFC 작업 파일이 됩니다. 사용자가 "아치 검토", "얕은 모듈 찾기", "모듈 깊이", "깊은 모듈", "Ousterhout", "테스트 가능성 감사", "표면 결합", "디자인 인터페이스", "RFC 문제" 또는 "건축적 마찰"이라고 말할 때 사용합니다.
