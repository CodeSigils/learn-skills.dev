Explora una base de código para la fricción arquitectónica a través de la lente del principio de módulo profundo de Ousterhout (interfaz pequeña, implementación grande). Flujo de trabajo interactivo de siete pasos: un subagente de Explore navega por el código base de forma orgánica; la fricción que experimenta ES la señal. Muestra grupos candidatos con razones de acoplamiento, patrones de llamadas, tipos compartidos, categorías de dependencia y pruebas existentes que una prueba de límites reemplazaría. El usuario elige qué explorar, enmarca el problema y luego, entre 3 y 4 subagentes paralelos diseñan interfaces de módulo profundo competitivas. El diseño elegido se convierte en un archivo de acción RFC estructurado legible por GitHub MCP o ROVO (Jira) MCP. Úselo cuando el usuario diga "revisión de arco", "buscar módulos poco profundos", "profundidad de módulo", "módulo profundo", "Ousterhout", "auditoría de capacidad de prueba", "acoplamiento de superficie", "interfaces de diseño", "problemas de RFC" o "fricción arquitectónica".
