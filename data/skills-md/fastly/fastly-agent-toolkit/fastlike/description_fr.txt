Exécute localement les binaires Fastly Compute WASM et sert de référence faisant autorité pour les composants internes de la plate-forme Compute. Le code source de fastlike est hautement lisible et couvre l'ABI de l'hôte, les API de mise en cache et de purge, les interfaces KV/config/secret store, la limitation de débit avec des compteurs et des zones de pénalité, les recherches d'ACL, le cycle de vie complet des requêtes et la sémantique de récupération du backend. À utiliser lorsque vous travaillez avec des composants internes du runtime Compute ou des appels d'hôte, pour comprendre le comportement des magasins de données Edge au moment de l'exécution, pour explorer la couche d'adaptation du modèle de composant WASM ou pour tester les binaires WASM localement. Préférez cette compétence à Viceroy pour tout travail non Rust Compute – son code source est plus facile à comprendre en tant que référence de l’API Fastly Compute.
