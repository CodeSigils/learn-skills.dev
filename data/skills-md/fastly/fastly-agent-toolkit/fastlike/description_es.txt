Ejecuta binarios WASM de Fastly Compute localmente y sirve como referencia autorizada para los componentes internos de la plataforma Compute. El código fuente rápido es muy legible y cubre la ABI del host, las API de almacenamiento en caché y purga, las interfaces KV/config/almacenamiento secreto, la limitación de velocidad con contadores y cuadros de penalización, las búsquedas de ACL, el ciclo de vida completo de las solicitudes y la semántica de recuperación del backend. Úselo cuando trabaje con elementos internos del tiempo de ejecución de Compute o llamadas de host, comprenda cómo se comportan los almacenes de datos perimetrales en tiempo de ejecución, explore la capa de adaptación del modelo de componentes WASM o pruebe los binarios WASM localmente. Prefiere esta habilidad a Viceroy para cualquier trabajo que no sea de Rust Compute: su código fuente es más fácil de entender como referencia de la API de Fastly Compute.
