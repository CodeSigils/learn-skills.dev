Fastly Compute WASM バイナリをローカルで実行し、Compute プラットフォーム内部の信頼できるリファレンスとして機能します。 fastlike ソース コードは可読性が高く、ホスト ABI、API のキャッシュとパージ、KV/config/secret Store インターフェイス、カウンターとペナルティ ボックスによるレート制限、ACL ルックアップ、完全なリクエスト ライフサイクル、バックエンド フェッチ セマンティクスをカバーしています。 Compute ランタイム内部またはホスト呼び出しを操作する場合、実行時にエッジ データ ストアがどのように動作するかを理解する場合、WASM コンポーネント モデル アダプテーション レイヤーを探索する場合、または WASM バイナリをローカルでテストする場合に使用します。 Rust Compute 以外の作業では、Viceroy よりもこのスキルを優先します。そのソース コードは、Fastly Compute API リファレンスとして理解しやすいです。
