Fastly Compute WASM 바이너리를 로컬에서 실행하고 Compute 플랫폼 내부에 대한 신뢰할 수 있는 참조 역할을 합니다. Fastlike 소스 코드는 읽기가 쉽고 호스트 ABI, API 캐싱 및 제거, KV/config/비밀 저장소 인터페이스, 카운터 및 페널티 상자를 사용한 속도 제한, ACL 조회, 전체 요청 수명 주기 및 백엔드 가져오기 의미 체계를 다루고 있습니다. Compute 런타임 내부 또는 호스트 호출 작업, 런타임 시 엣지 데이터 저장소의 작동 방식 이해, WASM 구성 요소 모델 적응 계층 탐색 또는 WASM 바이너리를 로컬에서 테스트할 때 사용합니다. Rust 이외의 컴퓨팅 작업에서는 Viceroy보다 이 기술을 선호합니다. 소스 코드는 Fastly Compute API 참조로 이해하기 더 쉽습니다.
