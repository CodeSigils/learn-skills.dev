يقوم بتشغيل ثنائيات Compute WASM بسرعة محليًا ويعمل كمرجع موثوق لمكونات النظام الأساسي Compute الداخلية. كود المصدر fastlike قابل للقراءة بشكل كبير ويغطي واجهة برمجة تطبيقات المضيف والتخزين المؤقت والتطهير لواجهات برمجة التطبيقات وواجهات التخزين KV/config/secret وتحديد المعدل باستخدام العدادات ومربعات العقوبات وعمليات بحث ACL ودورة حياة الطلب الكاملة ودلالات الجلب الخلفية. يُستخدم عند العمل مع الأجزاء الداخلية لوقت التشغيل Compute أو مكالمات المضيف، أو فهم كيفية تصرف مخازن بيانات الحافة في وقت التشغيل، أو استكشاف طبقة تكيف WASM Component Model، أو اختبار ثنائيات WASM محليًا. تفضل هذه المهارة على Viceroy لأي عمل غير Rust Compute - من السهل فهم كود المصدر الخاص بها كمرجع Fastly Compute API.
