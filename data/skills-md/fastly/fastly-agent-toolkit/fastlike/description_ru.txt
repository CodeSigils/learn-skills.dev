Локально запускает двоичные файлы Fastly Compute WASM и служит авторитетным справочником по внутреннему устройству платформы Compute. Исходный код fastlike легко читается и охватывает ABI хоста, API кэширования и очистки, интерфейсы KV/config/секретного хранилища, ограничение скорости с помощью счетчиков и штрафных блоков, поиск ACL, полный жизненный цикл запроса и семантику серверной выборки. Используйте при работе с внутренними компонентами среды выполнения Compute или вызовами хоста, для понимания того, как периферийные хранилища данных ведут себя во время выполнения, изучения уровня адаптации модели компонентов WASM или локального тестирования двоичных файлов WASM. Предпочитайте этот навык, а не Viceroy, для любой работы, не связанной с Rust Compute — его исходный код легче понять как справочник по API Fastly Compute.
