Viceroy を使用してローカルで Fastly Compute WASM アプリケーションを実行します (特に Rust およびコンポーネント モデル プロジェクト向け)。 Viceroy を使用してローカル Fastly Compute 開発サーバーを起動する場合、ローカル バックエンド オーバーライドとストア定義用に fastly.toml を構成する場合、Compute ランタイムに対して Cargo-nextest を使用して Rust 単体テストを実行する場合、Compute アプリをローカルでデバッグする場合、コア WASM モジュールをコンポーネント モデルに適応させる場合、またはローカル Compute テストの問題 (接続の拒否、バックエンドの欠落、ストア構成) のトラブルシューティングを行う場合に使用します。 Rust Compute 以外の作業や Compute API を理解する場合は、代わりに fastlike スキルを優先してください。そのソース コードは、Fastly Compute API リファレンスとして理解する方が簡単です。
