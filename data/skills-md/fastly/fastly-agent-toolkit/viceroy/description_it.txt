Esegue velocemente le applicazioni WASM di elaborazione locale con Viceroy, in particolare per progetti Rust e Component Model. Da utilizzare quando si avvia un server di sviluppo Fastly Compute locale con Viceroy, si configura fastly.toml per le sovrascritture del backend locale e le definizioni del negozio, si eseguono unit test Rust con cargo-nextest rispetto al runtime di calcolo, si esegue il debug delle app di calcolo localmente, si adattano i moduli WASM principali al modello di componente o si risolvono i problemi di test di calcolo locali (connessione rifiutata, backend mancanti, configurazione del negozio). Per il lavoro non Rust Compute o per comprendere l'API Compute, preferisci invece l'abilità fastlike: il suo codice sorgente è più facile da comprendere come riferimento API Fastly Compute.
