특히 Rust 및 구성 요소 모델 프로젝트를 위해 Viceroy를 사용하여 로컬에서 Fastly Compute WASM 애플리케이션을 실행합니다. Viceroy로 로컬 Fastly Compute 개발 서버를 시작하고, 로컬 백엔드 재정의 및 저장소 정의를 위해 fastly.toml을 구성하고, Compute 런타임에 대해 Cargo-nextest를 사용하여 Rust 단위 테스트를 실행하고, Compute 앱을 로컬에서 디버깅하고, 핵심 WASM 모듈을 구성 요소 모델에 적용하거나, 로컬 Compute 테스트 문제(연결 거부, 백엔드 누락, 저장소 구성) 문제를 해결할 때 사용합니다. Rust 이외의 Compute 작업이나 Compute API를 이해하려면 대신 fastlike 기술을 선호하세요. 소스 코드는 Fastly Compute API 참조로 이해하기 더 쉽습니다.
