Запускает приложения Fastly Compute WASM локально с помощью Viceroy, специально для проектов Rust и моделей компонентов. Используйте при запуске локального сервера разработки Fastly Compute с Viceroy, настройке fastly.toml для локальных переопределений серверной части и определений хранилища, запуске модульных тестов Rust с грузом-nextest для среды выполнения Compute, локальной отладке приложений Compute, адаптации основных модулей WASM к модели компонентов или устранении неполадок локального тестирования Compute (отказ в соединении, отсутствие серверных частей, конфигурация хранилища). Для работы, не связанной с Rust Compute, или для понимания Compute API, отдайте предпочтение навыку fastlike — его исходный код легче понять как справочник по Fastly Compute API.
