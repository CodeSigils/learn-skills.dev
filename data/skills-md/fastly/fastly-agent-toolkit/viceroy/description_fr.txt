Exécute les applications Fastly Compute WASM localement avec Viceroy, en particulier pour les projets Rust et Component Model. À utiliser lors du démarrage d'un serveur de développement Fastly Compute local avec Viceroy, de la configuration de fastly.toml pour les remplacements de backend locaux et les définitions de magasin, de l'exécution de tests unitaires Rust avec cargo-nextest sur le runtime Compute, du débogage des applications Compute localement, de l'adaptation des modules WASM de base au modèle de composant ou du dépannage des problèmes de tests Compute locaux (connexion refusée, backends manquants, configuration du magasin). Pour les travaux non Rust Compute ou pour comprendre l'API Compute, préférez plutôt la compétence fastlike - son code source est plus facile à comprendre en tant que référence de l'API Fastly Compute.
