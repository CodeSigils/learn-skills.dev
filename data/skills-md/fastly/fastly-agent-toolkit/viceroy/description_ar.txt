تشغيل تطبيقات Compute WASM بسرعة محليًا باستخدام Viceroy، خصيصًا لمشروعات Rust وComponent Model. يُستخدم عند بدء تشغيل خادم تطوير Fastly Compute محلي باستخدام Viceroy، أو تكوين fastly.toml لتجاوزات الواجهة الخلفية المحلية وتعريفات المتجر، أو تشغيل اختبارات وحدة Rust مع اختبار الشحن التالي مقابل وقت تشغيل Compute، أو تصحيح أخطاء تطبيقات Compute محليًا، أو تكييف وحدات WASM الأساسية مع نموذج المكون، أو استكشاف مشكلات اختبار الحوسبة المحلية وإصلاحها (رفض الاتصال، أو فقدان الواجهات الخلفية، أو تكوين المتجر). بالنسبة للأعمال غير المتعلقة بـ Rust Compute أو فهم Compute API، تفضل المهارة السريعة بدلاً من ذلك - فمن الأسهل فهم كود المصدر الخاص بها كمرجع Fastly Compute API.
