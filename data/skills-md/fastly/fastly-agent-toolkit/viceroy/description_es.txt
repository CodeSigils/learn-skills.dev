Ejecuta aplicaciones Fastly Compute WASM localmente con Viceroy, específicamente para proyectos de Rust y Component Model. Úselo al iniciar un servidor de desarrollo local de Fastly Compute con Viceroy, configurar fastly.toml para anulaciones de backend local y definiciones de tienda, ejecutar pruebas unitarias de Rust con cargo-nextest contra el tiempo de ejecución de Compute, depurar aplicaciones de Compute localmente, adaptar módulos WASM principales al modelo de componentes o solucionar problemas de pruebas de Compute locales (conexión rechazada, backends faltantes, configuración de tienda). Para trabajos que no sean de Rust Compute o para comprender la API de Compute, prefiera la habilidad fastlike: su código fuente es más fácil de entender como referencia de la API de Fastly Compute.
