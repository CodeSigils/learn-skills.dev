Fastly CDN プラットフォームの構成、管理、デバッグを行います。これには、サービスとバックエンドのセットアップ、キャッシュと VCL、DDoS/WAF/NGWAF/レート制限/ボット管理などのセキュリティ機能、TLS 証明書とキャッシュのパージ、コンピューティング プラットフォーム、REST API が含まれます。 Fastly サービスまたはドメインの操作、エッジ キャッシュまたはオリジン シールドの設定、セキュリティ機能の構成、Fastly API 呼び出しの実行、製品の有効化、または Fastly ドキュメントの検索を行うときに使用します。 Fastly での 503 エラーまたは SSL/TLS 証明書の不一致のトラブルシューティングや、ログ エンドポイント、ロード バランシング、ACL、またはエッジ ディクショナリの構成にも適用されます。
