Configura, gestiona y depura la plataforma Fastly CDN, que abarca la configuración del servicio y del backend, el almacenamiento en caché y VCL, funciones de seguridad como DDoS/WAF/NGWAF/limitación de velocidad/gestión de bots, certificados TLS y purga de caché, la plataforma Compute y la API REST. Úselo cuando trabaje con servicios o dominios de Fastly, configure el almacenamiento en caché perimetral o el blindaje de origen, configure funciones de seguridad, realice llamadas a la API de Fastly, habilite productos o busque documentación de Fastly. También se aplica al solucionar problemas de errores 503 o discrepancias de certificados SSL/TLS en Fastly y para configurar puntos finales de registro, equilibrio de carga, ACL o diccionarios perimetrales.
