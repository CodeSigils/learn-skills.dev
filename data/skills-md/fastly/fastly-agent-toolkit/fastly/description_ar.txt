يقوم بتكوين وإدارة وتصحيح نظام Fastly CDN - الذي يغطي إعداد الخدمة والواجهة الخلفية، والتخزين المؤقت وVCL، وميزات الأمان مثل DDoS/WAF/NGWAF/تحديد المعدل/إدارة الروبوت، وشهادات TLS وتطهير ذاكرة التخزين المؤقت، ومنصة Compute، وREST API. يُستخدم عند العمل مع خدمات أو مجالات Fastly، أو إعداد التخزين المؤقت للحافة أو حماية المصدر، أو تكوين ميزات الأمان، أو إجراء استدعاءات Fastly API، أو تمكين المنتجات، أو البحث عن وثائق Fastly. ينطبق أيضًا عند استكشاف أخطاء 503 وإصلاحها أو عدم تطابق شهادة SSL/TLS على Fastly، ولتكوين نقاط نهاية التسجيل، أو موازنة التحميل، أو قوائم ACL، أو قواميس الحافة.
