Lintaglia, testa, simula e formatta il codice Fastly VCL utilizzando lo strumento falco. Serve anche come riferimento VCL autorevole tramite il sorgente falco Go, che implementa il dialetto VCL completo di Fastly. Da utilizzare durante la convalida della sintassi VCL, l'esecuzione di linting VCL, il test locale di VCL, la simulazione della gestione delle richieste VCL, la formattazione di file VCL, la scrittura di unit test VCL con asserzioni, il debug di errori logici VCL, la ricerca di firme di funzioni VCL o ambiti variabili, la comprensione del comportamento delle subroutine VCL o l'esecuzione di `falco lint`/`falco simula`/`falco test`/`falco fmt`. Si applica anche quando si lavora con errori di sintassi VCL, tipi non corrispondenti nella VCL, si sceglie quale subroutine VCL utilizzare o si imposta un ambiente di sviluppo e test VCL locale.
