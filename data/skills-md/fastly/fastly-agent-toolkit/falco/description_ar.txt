فحص واختبار ومحاكاة وتنسيق كود VCL بسرعة باستخدام أداة falco. يعمل أيضًا كمرجع VCL معتمد عبر مصدر falco Go، الذي يطبق لهجة VCL الكاملة الخاصة بـ Fastly. يُستخدم عند التحقق من صحة بناء جملة VCL، أو تشغيل فحص VCL، أو اختبار VCL محليًا، أو محاكاة معالجة طلب VCL، أو تنسيق ملفات VCL، أو كتابة اختبارات وحدة VCL مع التأكيدات، أو تصحيح أخطاء منطق VCL، أو البحث عن توقيعات وظائف VCL أو النطاقات المتغيرة، أو فهم سلوك الروتين الفرعي VCL، أو تشغيل `falco lint`/`falco simulate`/`falco test`/`falco fmt`. ينطبق أيضًا عند التعامل مع أخطاء بناء جملة VCL، أو عدم تطابق الكتابة في VCL، أو اختيار روتين VCL الفرعي المطلوب استخدامه، أو إعداد بيئة تطوير واختبار VCL محلية.
