Lintiza, prueba, simula y formatea código VCL de Fastly utilizando la herramienta falco. También sirve como referencia autorizada de VCL a través de la fuente falco Go, que implementa el dialecto VCL completo de Fastly. Úselo al validar la sintaxis de VCL, ejecutar VCL linting, probar VCL localmente, simular el manejo de solicitudes de VCL, formatear archivos VCL, escribir pruebas unitarias de VCL con aserciones, depurar errores lógicos de VCL, buscar firmas de funciones de VCL o alcances variables, comprender el comportamiento de subrutinas de VCL o ejecutar `falco lint`/`falco simular`/`falco test`/`falco fmt`. También se aplica cuando se trabaja con errores de sintaxis de VCL, discrepancias de tipos en VCL, elección de qué subrutina de VCL utilizar o configuración de un entorno de prueba y desarrollo de VCL local.
