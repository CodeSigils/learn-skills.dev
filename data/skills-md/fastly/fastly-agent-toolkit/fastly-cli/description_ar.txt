ينفذ أوامر CLI بسرعة لإدارة خدمات CDN وعمليات نشر الحوسبة والبنية التحتية للحافة. يُستخدم عند تشغيل أوامر Fastly CLI، أو إنشاء خدمات Fastly أو إدارتها من الوحدة الطرفية، أو نشر تطبيقات Fastly Compute، أو إدارة الواجهات الخلفية/المجالات/مقتطفات VCL عبر سطر الأوامر، أو تطهير ذاكرة التخزين المؤقت، أو تكوين تدفق السجل، أو إعداد شهادات TLS، أو إدارة مخازن KV/config/secret، أو التحقق من إحصائيات الخدمة، أو المصادقة باستخدام Fastly SSO، أو العمل مع fastly.toml. ينطبق أيضًا عند العمل مع معرفات خدمة Fastly في سياق واجهة سطر الأوامر (CLI)، أو مع "خدمة Fastly"، أو "الحساب السريع"، أو "مصادقة Fastly"، أو أي أمر فرعي من Fastly CLI. يغطي خدمة CRUD، وإدارة الإصدار، والاستنساخ التلقائي، واستكشاف أخطاء CLI الشائعة وإصلاحها.
