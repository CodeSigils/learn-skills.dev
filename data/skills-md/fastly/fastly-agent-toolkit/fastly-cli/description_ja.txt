CDN サービス、コンピューティング デプロイ、エッジ インフラストラクチャを管理するために Fastly CLI コマンドを実行します。 「fastly」CLI コマンドの実行、端末からの Fastly サービスの作成または管理、Fastly Compute アプリケーションのデプロイ、コマンド ラインによるバックエンド/ドメイン/VCL スニペットの管理、キャッシュの削除、ログ ストリーミングの構成、TLS 証明書のセットアップ、KV/config/secret ストアの管理、サービス統計の確認、Fastly SSO での認証、または fastly.toml の操作を行うときに使用します。 CLI コンテキストで Fastly サービス ID を使用する場合、または「fastly service」、「fastly compute」、「fastly auth」、または任意の Fastly CLI サブコマンドを使用する場合にも適用されます。サービス CRUD、バージョン管理、自動クローン作成、および一般的な CLI エラーのトラブルシューティングについて説明します。
