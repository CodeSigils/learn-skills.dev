إنشاء عمليات تكامل Box واستكشاف أخطائها وإصلاحها لعمليات التحميل والمجلدات وقوائم المجلدات والتنزيلات والمعاينات والارتباطات المشتركة وعمليات التعاون والبحث والبيانات التعريفية وعمليات التشغيل الآلي المستندة إلى الأحداث وتدفقات استرجاع Box AI. يُستخدم عندما يحتاج الوكيل إلى إضافة Box APIs أو SDKs إلى تطبيق ما، أو توصيل سير عمل المستندات المدعومة بـ Box، أو تنظيم المحتوى أو مشاركته، أو التفاعل مع الملفات الجديدة، أو جلب محتوى Box للبحث أو التلخيص أو الاستخراج أو الإجابة على الأسئلة.
