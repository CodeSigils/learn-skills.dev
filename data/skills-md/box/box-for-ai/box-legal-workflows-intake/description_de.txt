Automatisieren Sie die Aufnahme und das Onboarding von Rechtsmandanten mit Box MCP – überprüfen Sie Aufnahmedokumente auf Vollständigkeit anhand der Unternehmensanforderungen, fassen Sie Risiken für die Anwaltsprüfung zusammen, leiten Sie unvollständige oder risikoreiche Einreichungen an den richtigen Anwalt weiter, extrahieren Sie Mandanten- und Sachverhaltsmetadaten in Box und erstellen Sie Auftragsschreiben aus Box DocGen-Vorlagen. Verwenden Sie diese Fähigkeit, wenn der Benutzer die Aufnahme von Kunden, das Onboarding von Kunden, die Bewertung neuer Kunden, Aufnahmedokumente oder Verpflichtungsschreiben erwähnt.
