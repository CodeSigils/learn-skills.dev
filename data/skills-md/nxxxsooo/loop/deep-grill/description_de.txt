Nutzen Sie den Entdeckungsmodus für Rohideen, Erläuterungen, „Grill Me“ oder eine unvollendete Produktbeschreibung; Verwenden Sie den Prüfmodus für ein formuliertes Ziel, das ein Urteil oder eine Überarbeitung benötigt. Setzen Sie jede Antwort in einer aktiven Deep-Grill-Sitzung fort, bis die Produktbeschreibung oder das Urteil bestätigt ist, ohne dass der Benutzer die Fertigkeit erneut benennen muss.
