Conservez les fichiers d'outils d'IA (.claude, .codex, .cursor, .windsurf, .augment, .kiro, .cline, .roo, .gemini, etc.) sur la branche dev mais excluez-les de main/master. À utiliser lors de la gestion de branches, de la création de PR vers le principal, de la fusion vers le principal ou de la configuration d'une stratégie de branche d'un dépôt pour le développement assisté par l'IA. Déclencheurs sur les opérations git merge/PR ciblant main ou master.
