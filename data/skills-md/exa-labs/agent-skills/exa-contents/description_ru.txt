Вызовите Exa Contents напрямую с помощью cURL или необработанного HTTP. Используйте, когда у агента уже есть URL-адреса и ему требуется POST/contents без SDK для извлеченного текста, выделения, сводок, ссылок, ссылок на изображения, подстраниц, сканирования с контролем актуальности или обработки статуса каждого URL-адреса.
