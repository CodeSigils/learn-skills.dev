أنشئ تطبيقات ووكلاء باستخدام واجهة برمجة تطبيقات Exa: البحث، واستخراج المحتويات، والإجابة، والسياق، وواجهة برمجة تطبيقات الوكيل، والشاشات، ومجموعات الويب، ونقاط النهاية المتوافقة مع OpenAI، ومجموعات SDK exa-py/exa-js. يُستخدم عند اختيار نقاط نهاية Exa، أو كتابة مكالمات Exa API، أو دمج بحث الويب الدلالي أو البحث في المنتجات، أو تصحيح أخطاء أشكال طلب Exa.
