اتصل بـ Exa Search مباشرة باستخدام cURL أو HTTP الخام. يُستخدم عندما يحتاج الوكيل إلى استرجاع Exa على الويب الدلالي من POST /search بدون SDK، بما في ذلك النتائج المصنفة، أو عوامل تصفية المجال أو الفئة، أو محتوى النتائج المدرك للحداثة، أو التمييز أو استخراج النص، أو المخرجات المنظمة، أو استجابات البحث المتدفقة.
