Utilisez Exa Agent pour la recherche Web en plusieurs étapes, la création de listes, l'enrichissement, la sortie structurée, la poursuite de l'exécution et la validation de la couverture. Exa Agent peut accéder à des fournisseurs de données supplémentaires : fibre, Financial_datasets, similarweb, baselayer, affilié, particule et jinko.
