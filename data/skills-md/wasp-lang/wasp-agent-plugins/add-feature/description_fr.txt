Ajoutez les fonctionnalités intégrées de Wasp à votre application : authentification, courrier électronique, tâches et bien plus encore. Il s’agit de fonctionnalités complètes, comprenant des piles, que Wasp gère pour vous. À utiliser lorsque l'utilisateur souhaite ajouter des balises méta, une authentification (e-mail, fournisseurs d'authentification sociale), l'envoi d'e-mails, la configuration d'une base de données, un style (tailwind, shadcn) ou d'autres fonctionnalités alimentées par Wasp.
