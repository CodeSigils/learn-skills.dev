أضف ميزات Wasp المضمنة إلى تطبيقك - المصادقة والبريد الإلكتروني والوظائف والمزيد. هذه هي الميزات الكاملة المضمنة بالبطاريات والتي يتعامل معها Wasp نيابةً عنك. يُستخدم عندما يريد المستخدم إضافة علامات التعريف، أو المصادقة (البريد الإلكتروني، أو موفري المصادقة الاجتماعية)، أو إرسال البريد الإلكتروني، أو إعداد قاعدة البيانات، أو التصميم (tailwind، أو shadcn)، أو وظائف أخرى تعمل بنظام Wasp.
