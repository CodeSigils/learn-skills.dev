分析SonarQube质量门故障的原因并提供改进建议。

在以下情况下使用此技能：
- 用户提供 Sonar URL 或项目密钥并询问质量门状态
- 需要排查声纳质量门故障的原因
- 需要分析代码质量指标（覆盖率、重复、问题等）
- 声纳检查拉取请求失败

该技能将：
1.检查环境变量SUPERMAP_SONAR_TOKEN
2.解析Sonar URL，提取项目密钥和PR号（如果有）
3.调用Sonar API查询质量门状态
4.如果质量门通过：返回简洁的成功消息（包括覆盖率、重复率）
5. 如果质量门失败：检索具体的失败指标、问题列表、分析并提供改进建议

需要：curl、SUPERMAP_SONAR_TOKEN 环境变量
与 Windows、macOS 和 Linux 兼容。

请始终使用用户的语言进行回复。
