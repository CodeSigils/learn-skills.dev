SonarQube 품질 게이트 실패 원인을 분석하고 개선 제안을 제공합니다.

다음과 같은 경우에 이 기술을 사용하십시오.
- 사용자가 Sonar URL 또는 프로젝트 키를 제공하고 품질 게이트 상태에 대해 질문합니다.
- Sonar 품질 게이트 실패 원인 해결 필요
- 코드 품질 지표(커버리지, 중복, 문제 등)를 분석해야 합니다.
- Pull Request에 대한 Sonar 검사가 실패했습니다.

기술은 다음과 같습니다.
1. 환경 변수 SUPERMAP_SONAR_TOKEN을 확인하세요.
2. Sonar URL을 구문 분석하고 프로젝트 키와 PR 번호(있는 경우)를 추출합니다.
3. Sonar API를 호출하여 품질 게이트 상태를 쿼리합니다.
4. 품질 게이트를 통과한 경우: 간결한 성공 메시지를 반환합니다(적용 범위, 중복 포함).
5. 품질 게이트가 실패하는 경우: 실패한 특정 측정항목, 문제 목록을 검색하고 개선 제안을 분석 및 제공합니다.

필요: 컬, SUPERMAP_SONAR_TOKEN 환경 변수
Windows, macOS, Linux와 호환됩니다.

항상 사용자의 언어로 응답하시기 바랍니다.
