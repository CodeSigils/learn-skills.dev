SonarQube Quality Gate 실패 원인을 분석하고 개선 제안을 제공합니다.

다음과 같은 경우에 이 기술을 사용하십시오.
- 사용자가 Sonar URL 또는 프로젝트 키를 제공하고 Quality Gate 상태에 대해 질문합니다.
- Sonar Quality Gate 실패 원인을 해결해야 함
- 코드 품질 지표(커버리지, 중복, 문제 등)를 분석해야 합니다.
- Pull Request에 대한 Sonar 검사가 통과되지 않았습니다.

기술은 다음과 같습니다.
1. SUPERMAP_SONAR_TOKEN 환경 변수를 확인하세요.
2. Sonar URL을 구문 분석하고 프로젝트 키와 PR 번호(있는 경우)를 추출합니다.
3. Sonar API를 호출하여 Quality Gate 상태를 쿼리합니다.
4. Quality Gate 통과 시: 간결한 성공 정보 반환(적용 범위, 중복 포함)
5. 품질 게이트가 실패하는 경우: 구체적인 실패한 측정 항목, 문제 목록을 얻고 개선 제안을 분석 및 제공합니다.

필요: 컬, SUPERMAP_SONAR_TOKEN 환경 변수
Windows, macOS, Linux와 호환됩니다.
