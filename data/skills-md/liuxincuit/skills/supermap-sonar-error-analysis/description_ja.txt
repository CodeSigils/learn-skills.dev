SonarQube 品質ゲート障害の原因を分析し、改善提案を提供します。

このスキルは次の場合に使用します。
- ユーザーは Sonar URL またはプロジェクト キーを提供し、品質ゲートのステータスについて質問します。
- Sonar 品質ゲート障害の原因をトラブルシューティングする必要がある
- コードの品質指標 (カバレッジ、重複、問題など) を分析する必要がある
- プルリクエストのソナーチェックが失敗しました

スキルは次のことを行います。
1. 環境変数 SUPERMAP_SONAR_TOKEN を確認します。
2. Sonar URL を解析し、プロジェクト キーと PR 番号 (存在する場合) を抽出します。
3. Sonar API を呼び出して品質ゲートのステータスをクエリする
4. 品質ゲートに合格した場合: 簡潔な成功メッセージを返します (カバレッジ、重複を含む)
5. 品質ゲートが失敗した場合: 失敗した特定の指標、問題のリストを取得し、分析して改善提案を提供します。

必要なもの:curl、SUPERMAP_SONAR_TOKEN 環境変数
Windows、macOS、Linuxと互換性があります。

常にユーザーの言語で応答してください。
