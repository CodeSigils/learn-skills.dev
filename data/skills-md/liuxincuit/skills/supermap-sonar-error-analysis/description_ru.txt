Проанализируйте причины сбоев контроля качества SonarQube и предоставьте предложения по улучшению.

Используйте этот навык, когда:
- Пользователь предоставляет URL-адрес Sonar или ключ проекта и спрашивает о статусе контроля качества.
- Необходимо устранить причины сбоев в работе ворот качества сонара.
- Необходимость анализа показателей качества кода (охват, дублирование, проблемы и т. д.).
- Сонарная проверка запроса на включение не удалась.

Навык будет:
1. Проверьте переменную среды SUPERMAP_SONAR_TOKEN.
2. Разберите URL-адрес Sonar, извлеките ключ проекта и номер PR (если есть).
3. Вызовите Sonar API, чтобы запросить статус контроля качества.
4. Если контроль качества пройден: верните краткое сообщение об успехе (включая охват и дублирование).
5. Если контроль качества не работает: извлеките конкретные неудовлетворительные показатели, список проблем, проанализируйте и предоставьте предложения по улучшению.

Требуется: Curl, переменная среды SUPERMAP_SONAR_TOKEN.
Совместимость с Windows, macOS и Linux.

Пожалуйста, всегда отвечайте на языке пользователя.
