Analyze the reasons for SonarQube quality gate failures and provide improvement suggestions.

Use this skill when:
- The user provides a Sonar URL or project key and asks about the quality gate status
- Need to troubleshoot the reasons for Sonar quality gate failures
- Need to analyze code quality metrics (coverage, duplication, issues, etc.)
- Sonar check for a Pull Request has failed

The skill will:
1. Check the environment variable SUPERMAP_SONAR_TOKEN
2. Parse the Sonar URL, extract the project key and PR number (if any)
3. Call the Sonar API to query the quality gate status
4. If the quality gate passes: return a concise success message (including coverage, duplication)
5. If the quality gate fails: retrieve specific failing metrics, list of issues, analyze and provide improvement suggestions

Requires: curl, SUPERMAP_SONAR_TOKEN environment variable
Compatible with Windows, macOS, and Linux.

Please always respond in the user's language.
