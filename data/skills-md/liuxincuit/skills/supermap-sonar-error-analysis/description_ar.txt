تحليل أسباب فشل بوابة الجودة SonarQube وتقديم اقتراحات التحسين.

استخدم هذه المهارة عندما:
- يقوم المستخدم بتوفير عنوان URL لـ Sonar أو مفتاح المشروع ويسأل عن حالة بوابة الجودة
- الحاجة إلى استكشاف أسباب فشل بوابة جودة السونار وإصلاحها
- الحاجة إلى تحليل مقاييس جودة الكود (التغطية، والتكرار، والمشكلات، وما إلى ذلك)
- فشل فحص السونار لطلب السحب

المهارة سوف:
1. تحقق من متغير البيئة SUPERMAP_SONAR_TOKEN
2. تحليل عنوان URL الخاص بالسونار، واستخراج مفتاح المشروع ورقم العلاقات العامة (إن وجد)
3. اتصل بـ Sonar API للاستعلام عن حالة بوابة الجودة
4. في حالة اجتياز بوابة الجودة: قم بإرجاع رسالة نجاح موجزة (بما في ذلك التغطية والتكرار)
5. في حالة فشل بوابة الجودة: قم باسترجاع مقاييس الفشل المحددة، وقائمة المشكلات، وقم بالتحليل وتقديم اقتراحات التحسين

يتطلب: حليقة، متغير البيئة SUPERMAP_SONAR_TOKEN
متوافق مع أنظمة التشغيل Windows وmacOS وLinux.

يرجى الرد دائمًا بلغة المستخدم.
