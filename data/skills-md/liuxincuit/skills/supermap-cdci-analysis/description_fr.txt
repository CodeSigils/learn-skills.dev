Analysez les raisons des échecs de build TeamCity CI/CD et proposez des solutions.

Utilisez cette compétence lorsque :
- L'utilisateur fournit une URL de build TeamCity et demande la cause de l'échec de la build
- Besoin de résoudre les problèmes de pipeline CI/CD
- Besoin d'analyser l'état de la construction
- Après un échec de build, une identification rapide du problème est requise

La compétence :
1. Analysez l'URL de TeamCity pour extraire les informations de configuration de build
2. Détectez et essayez automatiquement plusieurs méthodes d'authentification (Bearer Token, Basic Auth)
3. Appelez l'API REST TeamCity pour obtenir le dernier état de la build
4. Construction réussie : renvoie un message de réussite concis
5. Échec de la construction : récupérer progressivement les journaux, utiliser l'analyse intelligente LLM, fournir des solutions temporaires et à long terme
6. Lorsque les journaux ne peuvent pas être récupérés : effectuez une analyse dégradée basée sur le texte d'état et les informations sur le problème.

Nécessite : Node.js
Variables d'environnement :
- SUPERMAP_CDCI_TOKEN : pour cdci.ispeco.com :90
- SUPERMAP_CI_TOKEN : pour ci.ispeco.com:90 ou ci.ispeco.com:90
Compatible avec Windows, macOS et Linux.

Veuillez toujours répondre dans la langue de l'utilisateur.
