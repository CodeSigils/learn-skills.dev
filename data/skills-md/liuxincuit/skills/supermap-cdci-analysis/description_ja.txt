TeamCity CI/CD ビルドの失敗の理由を分析し、解決策を提供します。

このスキルは次の場合に使用します。
- ユーザーは TeamCity ビルド URL を提供し、ビルド失敗の原因を尋ねます
- CI/CD パイプラインの問題をトラブルシューティングする必要がある
- ビルドステータスを分析する必要がある
- ビルドが失敗した後、問題を迅速に特定する必要がある

スキルは次のことを行います。
1. TeamCity URL を解析してビルド構成情報を抽出します。
2. 複数の認証方法 (Bearer Token、Basic Auth) を自動的に検出して試行します。
3. TeamCity REST API を呼び出して最新のビルド ステータスを取得します
4. ビルド成功: 簡潔な成功情報を返します。
5. ビルドの失敗: ログを段階的に取得し、LLM インテリジェント分析を使用して、一時的および長期的な解決策を提供します。
6. ログが取得できない場合：statusTextと問題情報を基に縮退解析を行う

必要なもの: Node.js
環境変数:
- SUPERMAP_CDCI_TOKEN: cdci.ispeco.com の場合:90
- SUPERMAP_CI_TOKEN: ci.iserver.com:90 または ci.ispeco.com:90 の場合
Windows、macOS、Linux と互換性があります。

常にユーザーの言語で応答してください。
