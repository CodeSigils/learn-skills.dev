Помощник по удаленному подключению SSH (поддерживает только вход без пароля на основе ключей). Используется, когда пользователю необходимо подключиться к удаленному серверу, выполнять удаленные команды и управлять удаленными файлами. Начинает настройку SSH с создания удаленного пользователя, обеспечивая полный процесс настройки и предупреждения безопасности.
