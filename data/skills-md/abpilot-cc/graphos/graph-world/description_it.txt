Strumento di progettazione logica mondiale per GraphOS. Progetta modelli grafici Mondo/Contesto/Variante/Sistema/Evento/EventSystem per qualsiasi gioco o app, concentrandoti sulla logica del dominio, sui sistemi del ciclo di vita, sugli eventi bootstrap e sull'inizializzazione del contesto basata sugli eventi. Dipende dalle competenze di gestione dei grafici per le API di lettura/applicazione dei grafici.
