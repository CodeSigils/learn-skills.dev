Guía de pruebas y modelado de máquinas de estados de Fizz para las API de integración @tdreyno/fizz runtime y @tdreyno/fizz-react. Utilice esta habilidad al diseñar o refactorizar máquinas Fizz, cablear createMachine/createRuntime/createInitialContext, modelar transiciones asincrónicas y programadas, escribir o revisar pruebas de Fizz, revisar flujos de acciones y efectos o integrar una máquina con useMachine o createMachineContext en React.
