Понимание видео вулкана. Используйте API понимания видео Volcano Ark для анализа видеоконтента. Загружайте видео через Files API (рекомендуется), поддерживая большие файлы (до 512 МБ), подходящие для анализа контента, распознавания объектов и понимания действий. Активируйте этот навык, когда пользователям необходимо анализировать видео, понимать контент или извлекать информацию.
