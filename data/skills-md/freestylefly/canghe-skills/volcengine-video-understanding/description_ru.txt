Понимание видео Volcano — использует API понимания видео Volcano Ark для анализа видеоконтента. Загружайте видео через Files API (рекомендуется), поддерживая большие файлы размером до 512 МБ, для таких задач, как анализ видеоконтента, распознавание объектов и понимание действий. Активируйте этот навык, когда пользователям необходимо анализировать видео, понимать видеоконтент или извлекать видеоинформацию.
