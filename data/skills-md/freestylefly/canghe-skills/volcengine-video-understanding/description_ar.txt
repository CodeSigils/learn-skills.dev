فهم فيديو Volcano – يستخدم واجهة برمجة تطبيقات فهم الفيديو Volcano Ark لتحليل محتوى الفيديو. يمكنك تحميل مقاطع الفيديو عبر Files API (موصى به)، ودعم الملفات الكبيرة التي يصل حجمها إلى 512 ميجابايت، لمهام مثل تحليل محتوى الفيديو، والتعرف على الكائنات، وفهم الإجراء. قم بتنشيط هذه المهارة عندما يحتاج المستخدمون إلى تحليل مقاطع الفيديو أو فهم محتوى الفيديو أو استخراج معلومات الفيديو.
