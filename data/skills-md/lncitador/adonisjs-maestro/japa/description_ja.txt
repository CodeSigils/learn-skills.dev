ユーザーが Japa を使用して AdonisJS アプリケーションでテストを作成、デバッグ、または構成するときは常に、このスキルを使用します。あらゆるテスト タスクのトリガー: API テストの作成、ブラウザ テスト (Playwright)、コンソール/コマンド テスト、データベース状態のセットアップ、テスト ダブル (フェイク、スワップ、時間)、ファクトリの使用法、またはテスト層に関する質問。また、「テストの作成」、「テスト方法」、「メーラーの偽装」、「loginAs」、「データベースの切り捨て」、「withGlobalTransaction」、「emitter.fake」、「hash.fake」、「drive.fake」、「コンテナのスワップ」、「フリーズ時間」、「timeTravel」、「useFake」、「raw モード」、「レコード モード」、または任意の Japa 固有の概念のトリガーにもなります。テスト内で使用される AdonisJS バックエンド パターン (モデル、ファクトリー、認証) の場合は、このスキルと一緒に adonisjs スキルを使用します。
