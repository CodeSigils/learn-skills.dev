AdSpaceSDK-Integration (AdMob Next-Gen-Wrapper) für Android. Deckt alle Anzeigentypen ab (Banner, Native, Interstitial, Rewarded, Rewarded Interstitial, Open App), CMP-Zustimmung (UMP/GDPR), Firebase Remote Config, Lebenslaufanzeigen. Sowohl View API (XML/Kotlin) als auch Jetpack Compose. Min. SDK 26, Java 21.
