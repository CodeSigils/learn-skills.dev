Integrazione di AdSpaceSDK (wrapper AdMob Next-Gen) per Android. Copre tutti i tipi di annunci (Banner, Nativi, Interstitial, Con premio, Interstitial con premio, App aperta), consenso CMP (UMP/GDPR), Firebase Remote Config, riprendi annunci. Sia View API (XML/Kotlin) che Jetpack Compose. SDK minimo 26, Java 21.
