Integración de AdSpaceSDK (contenedor AdMob Next-Gen) para Android. Cubre todos los tipos de anuncios (banner, nativos, intersticiales, recompensados, intersticiales recompensados, aplicaciones abiertas), consentimiento de CMP (UMP/GDPR), Firebase Remote Config y anuncios de currículum. Tanto View API (XML/Kotlin) como Jetpack Compose. SDK mínimo 26, Java 21.
