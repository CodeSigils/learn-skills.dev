Интеграция AdSpaceSDK (оболочка AdMob Next-Gen) для Android. Охватывает все типы объявлений (баннеры, нативные, межстраничные объявления, с вознаграждением, межстраничные объявления с вознаграждением, открытое приложение), согласие CMP (UMP/GDPR), удаленную настройку Firebase, возобновление рекламы. И View API (XML/Kotlin), и Jetpack Compose. Минимальный SDK 26, Java 21.
