Intégration AdSpaceSDK (AdMob Next-Gen wrapper) pour Android. Couvre tous les types d'annonces (bannière, native, interstitielle, avec récompense, interstitielle avec récompense, application ouverte), consentement CMP (UMP/RGPD), configuration à distance Firebase, reprise des annonces. View API (XML/Kotlin) et Jetpack Compose. SDK minimum 26, Java 21.
