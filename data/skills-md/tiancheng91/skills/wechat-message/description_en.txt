This skill is used to automate sending WeChat messages via scripts on macOS/Windows. It is used when the user needs to "send WeChat messages", "send messages to WeChat friends", "automatically send on WeChat", "send messages in WeChat groups", or mentions "WeChat message", "WeChat automation". On macOS, it uses AppleScript + cliclick, and on Windows, it uses PowerShell; the appropriate script is selected based on the platform.
