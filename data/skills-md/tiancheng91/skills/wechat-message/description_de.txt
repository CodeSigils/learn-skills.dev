Dieser Skill wird verwendet, um das Senden von WeChat-Nachrichten über Skripte unter macOS/Windows zu automatisieren. Es wird verwendet, wenn der Benutzer „WeChat-Nachrichten senden“, „Nachrichten an WeChat-Freunde senden“, „automatisch auf WeChat senden“ oder „Nachrichten in WeChat-Gruppen senden“ muss oder „WeChat-Nachricht“ oder „WeChat-Automatisierung“ erwähnt. Unter macOS verwendet es AppleScript + Click und unter Windows PowerShell. Je nach Plattform wird das passende Skript ausgewählt.
