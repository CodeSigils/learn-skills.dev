Machen Sie einen Schnappschuss von einer Xiaomi-Kamera. Verwenden Sie diese Funktion, wenn der Benutzer das Echtzeitvideo einer Xiaomi-Kamera ansehen, einen Kamera-Screenshot erstellen, die Kameraansicht überwachen möchte oder „Xiaomi-Kamera“, „Kamera-Schnappschuss“, „Kamera-Screenshot“ oder „Kameraansicht“ erwähnt. Es unterstützt das Auflisten von Kameras, das Abrufen von Bildern von einer bestimmten Kamera, benutzerdefinierte Dateinamen und mehr.
