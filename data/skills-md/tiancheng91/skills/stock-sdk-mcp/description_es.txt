Servicio de datos del mercado de valores: admite cotizaciones en tiempo real, gráficos de velas, indicadores técnicos y datos sectoriales para acciones A, acciones de Hong Kong y acciones de EE. UU. Utilice esta función cuando el usuario consulte acciones, fondos, datos de mercado, análisis técnicos, datos sectoriales, descripción general del mercado, selección de acciones o seguimiento de cartera.
