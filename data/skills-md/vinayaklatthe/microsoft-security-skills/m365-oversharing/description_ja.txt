Secure & Governed Data Foundation ブループリントを使用して Microsoft 365 (SharePoint、OneDrive、Teams、Exchange) 全体の過剰共有を修復するためのガイダンス。これは、SharePoint Advanced Management のデータ アクセス ガバナンス、機密性とコンテナーのラベル、デフォルトで安全なラベル付け、制限付きアクセス制御、および Microsoft Purview に基づいて構築された 3 本柱プログラム (過剰共有の修復、ガードレールの設定、規制への準拠) です。時期: Microsoft 365 オーバーシェアリング、M365 オーバーシェアリング、安全で管理されたデータ基盤、ブループリントのオーバーシェアリング、SharePoint にアクセスできるユーザーが多すぎる、外部ユーザーを除く EEEU すべてのユーザー、アクセス許可の強化、データ アクセス ガバナンス レポート、制限されたコンテンツ検出、デフォルトでセキュリティ保護されたラベル、データ基盤の準備、共有リンクのスプロールの削減、管理されたデータ資産。 Copilot 固有の Readiness フレーミングのみ (purview-copilot-oversharing を使用) または広範な DLP プログラムの構築 (purview-dlp-policy を使用) には使用しないでください。
