Руководство по устранению чрезмерного общего доступа в Microsoft 365 (SharePoint, OneDrive, Teams, Exchange) с использованием плана Secure & Governed Data Foundation — трехкомпонентной программы (устранение чрезмерного общего доступа, установка ограждений, соблюдение нормативных требований), построенной на управлении доступом к данным SharePoint Advanced Management, конфиденциальности и метках контейнеров, метках безопасности по умолчанию, ограниченном управлении доступом и Microsoft Purview. КОГДА: чрезмерный общий доступ к Microsoft 365, чрезмерный общий доступ к M365, безопасная и управляемая основа данных, план совместного использования, слишком много людей имеют доступ к SharePoint, EEEU для всех, кроме внешних пользователей, ужесточение разрешений, отчет об управлении доступом к данным, ограниченное обнаружение контента, безопасность меток по умолчанию, подготовка основания данных, сокращение разрастания ссылок для общего доступа, управляемое хранилище данных. НЕ ИСПОЛЬЗУЙТЕ только для формирования готовности к работе с Copilot (используйте purview-copilot-oversharing) или создания широкой программы DLP (используйте purview-dlp-policy).
