Orientación para corregir el uso compartido excesivo en Microsoft 365 (SharePoint, OneDrive, Teams, Exchange) utilizando el modelo Secure & Governed Data Foundation: un programa de tres pilares (corregir el uso compartido excesivo, configurar barreras de seguridad, cumplir con las regulaciones) basado en la gobernanza de acceso a datos de SharePoint Advanced Management, etiquetas de confidencialidad y contenedores, etiquetado seguro por defecto, control de acceso restringido y Microsoft Purview. CUÁNDO: uso compartido excesivo de Microsoft 365, uso compartido excesivo de M365, base de datos gobernada y segura, plan de uso compartido excesivo, demasiadas personas tienen acceso a SharePoint, EEEU para todos excepto los usuarios externos, permisos estrictos, informe de control de acceso a datos, descubrimiento de contenido restringido, etiquetas seguras de forma predeterminada, preparación de la base de datos, reducción de la expansión de los enlaces de uso compartido, patrimonio de datos gobernados. NO LO UTILICE solo para enmarcar la preparación específica de Copilot (use purview-copilot-oversharing) ni para crear un programa DLP amplio (use purview-dlp-policy).
