إرشادات لإدارة هويات وكلاء الذكاء الاصطناعي والهويات غير البشرية (NHIs) — وكلاء Microsoft 365 Copilot Studio، ووكلاء Microsoft Foundry، ووكلاء الذكاء الاصطناعي المخصصون، ومبادئ الخدمة التقليدية/الهويات المُدارة — خلال دورة حياتهم الكاملة. يغطي الملكية ووضع العلامات، والأذونات والموافقات المحددة النطاق (التفويض مقابل التطبيق؛ Sites.Selected؛ الرسم البياني على نطاق صندوق البريد)، وسلامة بيانات الاعتماد (بيانات الاعتماد الموحدة، والشهادات، وعدم وجود أسرار)، والوصول المشروط لأحمال العمل، ومراجعات الوصول على مستوى الوكيل عبر حوكمة معرف Entra، وسير عمل دورة الحياة لإيقاف تشغيل الوكيل، والتدقيق (مطالبات الوكيل، وإجراءات الوكيل، وتسجيلات هوية الوكيل)، والاستجابة للحوادث عندما يتم اختراق الوكيل، والتكامل مع Purview AI Hub لإشارات الاستخدام. متى: حوكمة هوية وكيل الذكاء الاصطناعي، وحوكمة الهوية غير البشرية، ودورة حياة NHI، وهوية وكيل Copilot Studio، وحوكمة وكيل المسبك، ومدير خدمة الوكيل، ووكيل أذونات الرسم البياني المحدد، ومراجعة وصول الوكيل، ووكيل الذكاء الاصطناعي للخروج من الخدمة، وتناوب بيانات اعتماد الوكيل، واستجابة الوكيل المخترقة. لا تستخدمه لأنماط اتحاد هوية عبء العمل وحدها (استخدم هوية عبء العمل الداخلي)، أو إدارة معرف Entra للبشر (استخدم حوكمة معرف إنترا)، أو وكيل Copilot Studio يبني إرشادات لا علاقة لها بالأمان.
