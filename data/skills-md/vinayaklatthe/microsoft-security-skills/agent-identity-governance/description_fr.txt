Conseils pour gérer les identités des agents IA et des identités non humaines (NHI) — agents Microsoft 365 Copilot Studio, agents Microsoft Foundry, agents IA personnalisés et principaux de service/identités gérées traditionnelles — tout au long de leur cycle de vie complet. Couvre la propriété et le marquage, les autorisations et le consentement étendus (délégué ou application ; Sites.Selected ; graphique à l'échelle de la boîte aux lettres), l'hygiène des informations d'identification (informations d'identification fédérées, certificats, aucun secret), l'accès conditionnel pour les charges de travail, les examens d'accès au niveau de l'agent via Entra ID Governance, les workflows du cycle de vie pour la mise hors service des agents, l'audit (invites de l'agent, actions de l'agent, connexions d'identité de l'agent), la réponse aux incidents lorsqu'un agent est compromis et l'intégration avec Purview AI Hub pour les signaux d'utilisation. QUAND : gouvernance de l'identité de l'agent IA, gouvernance de l'identité non humaine, cycle de vie NHI, identité de l'agent Copilot Studio, gouvernance de l'agent Foundry, principal du service d'agent, agent d'autorisations Graph étendu, examen de l'accès de l'agent, déclassement de l'agent IA, rotation des informations d'identification de l'agent, réponse de l'agent compromise. NE PAS UTILISER uniquement pour les modèles de fédération d'identité de charge de travail (utilisez entra-workload-identity), Entra ID Governance pour les humains (utilisez entra-id-governance) ou les conseils de création d'agent Copilot Studio sans rapport avec la sécurité.
