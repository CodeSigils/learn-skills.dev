AI エージェントと人間以外の ID (NHI) (Microsoft 365 Copilot Studio エージェント、Microsoft Foundry エージェント、カスタム AI エージェント、従来のサービス プリンシパル/マネージド ID) の ID をライフサイクル全体にわたって管理するためのガイダンス。所有権とタグ付け、範囲指定されたアクセス許可と同意 (委任とアプリケーション、Sites.Selected、メールボックス範囲のグラフ)、資格情報の衛生状態 (フェデレーテッド資格情報、証明書、シークレットなし)、ワークロードの条件付きアクセス、Entra ID ガバナンスによるエージェント レベルのアクセス レビュー、エージェント廃止のライフサイクル ワークフロー、監査 (エージェント プロンプト、エージェントのアクション、エージェント ID サインイン)、エージェントが次の場合のインシデント対応をカバーします。侵害されており、使用状況シグナルのために Purview AI Hub と統合されています。いつ: AI エージェント ID ガバナンス、人間以外の ID ガバナンス、NHI ライフサイクル、Copilot Studio エージェント ID、Foundry エージェント ガバナンス、エージェント サービス プリンシパル、スコープ付き Graph 権限エージェント、エージェント アクセス レビュー、AI エージェントの廃止、エージェント資格情報のローテーション、侵害されたエージェントの応答。 Workload Identity フェデレーション パターンのみ (entra-workload-identity を使用)、人間用の Entra ID Governance (entra-id-governance を使用)、またはセキュリティに関係のない Copilot Studio エージェントのビルド ガイダンスには使用しないでください。
