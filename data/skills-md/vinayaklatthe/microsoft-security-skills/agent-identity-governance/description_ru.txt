Руководство по управлению удостоверениями агентов ИИ и нечеловеческих удостоверений (NHI) — агентов Microsoft 365 Copilot Studio, агентов Microsoft Foundry, пользовательских агентов ИИ и традиционных субъектов службы/управляемых удостоверений — на протяжении всего их жизненного цикла. Охватывает владение и тегирование, ограниченные разрешения и согласие (делегированное против приложения; Sites.Selected; Graph на уровне почтового ящика), гигиену учетных данных (федеративные учетные данные, сертификаты, отсутствие секретов), условный доступ для рабочих нагрузок, проверки доступа на уровне агента через Entra ID Governance, рабочие процессы жизненного цикла для вывода агента из эксплуатации, аудит (подсказки агента, действия агента, вход в систему с идентификацией агента), реагирование на инциденты, когда агент скомпрометирован, и интеграцию с Purview AI Хаб для сигналов использования. КОГДА: управление идентификацией агента ИИ, управление идентификацией, не относящейся к человеку, жизненный цикл NHI, идентификация агента Copilot Studio, управление агентом Foundry, субъект службы агента, агент разрешений графа с ограниченной областью, проверка доступа агента, вывод из эксплуатации агента ИИ, ротация учетных данных агента, ответ скомпрометированного агента. НЕ ИСПОЛЬЗУЙТЕ только шаблоны федерации удостоверений рабочей нагрузки (используйте entra-workload-identity), Entra ID Governance для людей (используйте entra-id-governance) или руководство по созданию агента Copilot Studio, не связанное с безопасностью.
