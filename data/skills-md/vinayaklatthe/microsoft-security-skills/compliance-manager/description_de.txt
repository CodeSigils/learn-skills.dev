Leitfaden für Microsoft Purview Compliance Manager – kontinuierlicher Compliance-Status für Microsoft- und Nicht-Microsoft-Assets, abgebildet auf über 360 regulatorische Vorlagen (ISO 27001/27018/27701, SOC 2, NIST 800-53/171/CSF, PCI DSS, HIPAA, DSGVO, FedRAMP, IRAP, Essential Eight, DORA, EU AI Act usw.). Umfasst Compliance-Bewertung, Verbesserungsmaßnahmen (von Microsoft verwaltet oder vom Kunden verwaltet), Beweiserfassung, Bewertungserstellung (benutzerdefinierte Vorlagen aus CSV), Gruppierung mehrerer Bewertungen, automatisiertes Testen technischer Kontrollen über Microsoft 365/Defender for Cloud/Entra, Beweis-Repository, revisionsbereite Berichte und kontinuierliche Bewertung im Vergleich zu Zeitpunkten. WANN: Compliance Manager, Compliance-Score, behördliche Bewertung Purview, NIST 800-53-Bewertung, ISO 27001-Beweis, FedRAMP-Bewertung, benutzerdefinierte Compliance-Vorlage, Verbesserungsmaßnahme, technische Kontrollautomatisierung, Auditnachweise M365, DORA-Bewertung, Bewertung des EU-KI-Gesetzes. NICHT nur für das regulatorische Dashboard von Defender für Cloud (Verwenden Sie Defender-for-Cloud-Hardening), die Datensatzverwaltung (Verwenden Sie Purview-Records-Management) oder den sicheren M365-Score verwenden.
