Microsoft Purview 合規管理器指南 — 跨 Microsoft 和非 Microsoft 資產的持續合規狀況，映射到 360 多個監管模板（ISO 27001/27018/27701、SOC 2、NIST 800-53/171/CSF、PCI DSS、HIPAA、GDPREUFedRAMPential、$APRAential、EURA 等）。涵蓋合規性評分、改進措施（Microsoft 管理與客戶管理）、證據收集、評估創作（來自 CSV 的自訂範本）、多重評估分組、透過 Microsoft 365/Defender for Cloud/Entra 進行的技術控制自動測試、證據儲存庫、稽核就緒報告以及持續評估與時間點評估。時間：合規經理、合規評分、監管評估 Purview、NIST 800-53 評估、ISO 27001 證據、FedRAMP 評估、自訂合規模板、改進行動、技術控制自動化、審計證據 M365、DORA 評估、歐盟 AI 法案評估。請勿僅用於 Defender for Cloud 監管儀表板（使用 Defender-for-cloud-hardening）、記錄管理（使用 purview-records-management）或 M365 安全分數。
