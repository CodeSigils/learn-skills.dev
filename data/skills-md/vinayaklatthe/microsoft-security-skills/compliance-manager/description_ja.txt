Microsoft Purview Compliance Manager のガイダンス — Microsoft および Microsoft 以外の資産にわたる継続的なコンプライアンス体制。360 以上の規制テンプレート (ISO 27001/27018/27701、SOC 2、NIST 800-53/171/CSF、PCI DSS、HIPAA、GDPR、FedRAMP、IRAP、Essential Eight、DORA、EU AI Act など) にマッピングされています。コンプライアンス スコア、改善アクション (Microsoft 管理と顧客管理)、証拠収集、評価オーサリング (CSV からのカスタム テンプレート)、複数評価のグループ化、Microsoft 365 / Defender for Cloud / Entra を介した技術的コントロールの自動テスト、証拠リポジトリ、監査対応レポート、継続的評価とポイントインタイムをカバーします。時期: コンプライアンス マネージャー、コンプライアンス スコア、規制評価 Purview、NIST 800-53 評価、ISO 27001 証拠、FedRAMP 評価、カスタム コンプライアンス テンプレート、改善アクション、技術的制御の自動化、監査証拠 M365、DORA 評価、EU AI 法の評価。 Defender for Cloud 規制ダッシュボード (defender-for-cloud-hardening を使用)、レコード管理 (purview-records-management を使用)、または M365 セキュア スコアのみには使用しないでください。
