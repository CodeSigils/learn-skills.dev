Руководство для Microsoft Purview Compliance Manager — положение о постоянном соблюдении требований для активов Microsoft и сторонних компаний, сопоставленное с более чем 360 нормативными шаблонами (ISO 27001/27018/27701, SOC 2, NIST 800-53/171/CSF, PCI DSS, HIPAA, GDPR, FedRAMP, IRAP, Essential Eight, DORA, EU AI Act и т. д.). Охватывает оценку соответствия, действия по улучшению (под управлением Microsoft или под управлением клиента), сбор доказательств, создание оценок (пользовательские шаблоны из CSV), группировку нескольких оценок, автоматическое тестирование технических средств контроля через Microsoft 365 / Defender for Cloud / Entra, хранилище доказательств, готовые к аудиту отчеты и непрерывную оценку на определенный момент времени. КОГДА: менеджер по обеспечению соответствия, оценка соответствия, нормативная оценка Purview, оценка NIST 800-53, доказательства ISO 27001, оценка FedRAMP, индивидуальный шаблон соответствия, действия по улучшению, автоматизация технического контроля, аудиторские доказательства M365, оценка DORA, оценка Закона ЕС об искусственном интеллекте. НЕ ИСПОЛЬЗУЙТЕ только для нормативной информационной панели Defender for Cloud (используйте защитник для защиты облака), управления записями (используйте управление записями разрешений) или оценки безопасности M365.
