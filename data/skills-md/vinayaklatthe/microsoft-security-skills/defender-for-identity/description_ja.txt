Microsoft Defender for Identity (MDI) のガイダンス — センサーを使用した、オンプレミスの Active Directory、AD CS、AD FS、Entra Connect 全体にわたる ID 脅威検出 (ITDR)。センサーの配置、前提条件、姿勢評価、横方向の動きの検出について説明します。時期: Defender for Identity、MDI、MDI センサー、水平移動の検出、オンプレミス AD 脅威検出、ID セキュリティ体制、AD CS 監視、ADCS 悪用、ドメイン コントローラー センサー、Kerberoasting、DCSync、ゴールデン チケット、ID ITDR、ハニートークン、gMSA ディレクトリ サービス アカウント、不審な LDAP、ESC1 ESC8 の検出。目標が Entra ID でのクラウド ID 保護 (entra-id-protection を使用) またはクロスワークロード インシデントの関連付け (defender-xdr を使用) である場合は使用しないでください。
