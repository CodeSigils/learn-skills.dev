إرشادات لـ Microsoft Defender for Identity (MDI) — اكتشاف تهديدات الهوية (ITDR) عبر Active Directory المحلي، وAD CS، وAD FS، وEntra Connect باستخدام أجهزة الاستشعار. يغطي وضع المستشعر، والمتطلبات الأساسية، وتقييمات الوضعية، واكتشاف الحركة الجانبية. متى: Defender for Identity، MDI، مستشعرات MDI، اكتشاف الحركة الجانبية، اكتشاف تهديدات الإعلانات المحلية، وضع أمان الهوية، مراقبة AD CS، إساءة استخدام ADCS، مستشعر وحدة التحكم بالمجال، اكتشاف Kerberoasting، DCSync، Golden Ticket، الهوية ITDR، honeytoken، حساب خدمة دليل gMSA، LDAP المشبوه، ESC1 ESC8. لا تستخدمه عندما يكون الهدف هو حماية الهوية السحابية في Entra ID (استخدم حماية معرف الدخول) أو ربط حوادث أحمال العمل المشتركة (استخدم المدافع-xdr).
