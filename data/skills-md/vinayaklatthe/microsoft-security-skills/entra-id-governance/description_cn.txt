Microsoft Entra ID 治理指南 — 通过权利管理（访问包）、访问审查、加入者-移动者-离开者的生命周期工作流程、职责分离和来宾访问治理，实现身份生命周期和访问的自动化。涵盖何时使用访问包与直接组分配、审阅者选择和后备操作以及与 PIM 集成以实现特权访问。何时：Entra ID 治理、权利管理、访问包、访问审查、生命周期工作流程、加入者移动者离开者、JML、认证访问、职责分离、管理访客访问、B2B 访客过期、身份生命周期自动化、发起人批准、重新认证访问。请勿用于基于风险的检测（使用 entra-id-protection）、CA 策略创作（使用条件访问-mfa）或 PIM 激活（使用 azure-pim）。
