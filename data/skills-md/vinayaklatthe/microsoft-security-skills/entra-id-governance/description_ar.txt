إرشادات لإدارة معرف Microsoft Entra - أتمتة دورة حياة الهوية والوصول إليها من خلال إدارة الاستحقاقات (حزم الوصول)، ومراجعات الوصول، وسير عمل دورة الحياة للمنضمين والمنتقلين، والفصل بين الواجبات، وإدارة وصول الضيف. يغطي متى يتم استخدام حزم الوصول مقابل التعيين المباشر للمجموعة واختيار المراجع والإجراءات الاحتياطية والتكامل مع PIM للوصول المميز. متى: حوكمة معرف Entra، وإدارة الاستحقاقات، وحزم الوصول، ومراجعات الوصول، وسير عمل دورة الحياة، ومغادرة المحرك المشترك، وJML، واعتماد الوصول، وفصل الواجبات، والتحكم في وصول الضيف، وانتهاء صلاحية ضيف B2B، وأتمتة دورة حياة الهوية، وموافقة الراعي، وإعادة مصادقة الوصول. لا تستخدمه للكشف القائم على المخاطر (استخدم حماية معرف الدخول)، أو تأليف سياسة CA (استخدم الوصول المشروط-mfa)، أو تنشيط PIM (استخدم azure-pim).
