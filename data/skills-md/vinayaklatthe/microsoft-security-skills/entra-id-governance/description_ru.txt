Руководство по управлению Microsoft Entra ID — автоматизация жизненного цикла удостоверений и доступа с помощью управления правами (пакеты доступа), проверки доступа, рабочих процессов жизненного цикла для присоединения, перемещения и ухода, разделения обязанностей и управления гостевым доступом. Описывает, когда следует использовать пакеты доступа, а не прямое назначение групп, выбор рецензента и резервные действия, а также интеграцию с PIM для привилегированного доступа. КОГДА: Управление Entra ID, управление правами, пакеты доступа, проверки доступа, рабочие процессы жизненного цикла, выход из процесса присоединения, JML, сертификация доступа, разделение обязанностей, управление гостевым доступом, истечение срока действия гостя B2B, автоматизация жизненного цикла удостоверений, одобрение спонсора, повторная сертификация доступа. НЕ ИСПОЛЬЗУЙТЕ для обнаружения на основе рисков (используйте защиту внутри идентификатора), разработки политики ЦС (используйте условный доступ-mfa) или активации PIM (используйте azure-pim).
