Microsoft Entra ID 治理指南 — 透過權利管理（存取包）、存取審查、加入者-移動者-離開者的生命週期工作流程、職責分離和來賓存取治理，實現身分生命週期和存取的自動化。涵蓋何時使用存取包與直接群組分配、審查者選擇和後備操作以及與 PIM 整合以實現特權存取。何時：Entra ID 治理、權利管理、訪問包、訪問審查、生命週期工作流程、加入者移動者離開者、JML、認證訪問、職責分離、管理訪客​​訪問、B2B 訪客過期、身份生命週期自動化、發起人批准、重新認證訪問。請勿用於基於風險的檢測（使用 entra-id-protection）、CA 策略創作（使用條件存取-mfa）或 PIM 活化（使用 azure-pim）。
