إرشادات لـ Microsoft Defender for IoT - اكتشاف شبكة OT/ICS بدون وكيل والاستجابة لها في البيئات الصناعية، بالإضافة إلى حماية إنترنت الأشياء (EIoT) للمؤسسات المتكاملة مع Defender XDR. يغطي نشر مستشعرات التكنولوجيا التشغيلية (المادية/الافتراضية، SPAN/TAP)، ومحاذاة نموذج Purdue، ووحدة التحكم الإدارية المحلية، وأجهزة الاستشعار المُدارة عبر السحابة، وEIoT (الطابعات، والكاميرات، وVoIP) التي تم اكتشافها من خلال MDE، وجرد الأصول، وبيانات الثغرات الأمنية، وذكاء التهديدات، والتكامل مع Sentinel وDefender XDR. متى: المدافع عن IoT، وأمن OT، وأمن ICS، ومراقبة SCADA، وأمان شبكة طراز Purdue، ونشر مستشعر OT، ومراقبة منفذ SPAN، واكتشاف إنترنت الأشياء للمؤسسة، وحماية الأجهزة غير المُدارة، وأمن أرض المصنع، وNDR لـ OT، واكتشاف تهديدات ICS، وجرد أصول IoT. لا تستخدمه لأمان مستوى بيانات IoT Hub (منصة Azure)، أو تقوية جهاز Azure Sphere، أو EDR لنقطة النهاية العامة (استخدم المدافع مقابل نقطة النهاية).
