Conseils pour Microsoft Defender pour IoT : détection et réponse de réseau OT/ICS sans agent pour les environnements industriels, ainsi qu'une protection IoT d'entreprise (EIoT) intégrée à Defender XDR. Couvre le déploiement de capteurs OT (physiques/virtuels, SPAN/TAP), l'alignement du modèle Purdue, la console de gestion sur site, les capteurs gérés dans le cloud, l'EIoT (imprimantes, caméras, VoIP) découverts via MDE, l'inventaire des actifs, les données de vulnérabilité, les renseignements sur les menaces et l'intégration avec Sentinel et Defender XDR. QUAND : Defender pour l'IoT, sécurité OT, sécurité ICS, surveillance SCADA, sécurité du réseau modèle Purdue, déploiement de capteurs OT, surveillance des ports SPAN, découverte de l'IoT d'entreprise, protection des appareils non gérés, sécurité de l'usine, NDR pour OT, détection des menaces ICS, inventaire des actifs IoT. NE PAS UTILISER pour la sécurité du plan de données IoT Hub (plateforme Azure), le renforcement des appareils Azure Sphere ou l'EDR de point de terminaison générique (utiliser Defender-for-endpoint).
