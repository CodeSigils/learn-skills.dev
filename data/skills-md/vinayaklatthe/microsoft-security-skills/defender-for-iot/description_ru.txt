Руководство по Microsoft Defender для Интернета вещей — безагентное обнаружение сетей OT/ICS и реагирование на них для промышленных сред, а также защита корпоративного Интернета вещей (EIoT), интегрированная с Defender XDR. Охватывает развертывание датчиков OT (физический/виртуальный, SPAN/TAP), согласование модели Purdue, локальную консоль управления, датчики с облачным управлением, EIoT (принтеры, камеры, VoIP), обнаруженные через MDE, инвентаризацию активов, данные об уязвимостях, анализ угроз и интеграцию с Sentinel и Defender XDR. КОГДА: Defender для IoT, безопасность OT, безопасность ICS, мониторинг SCADA, сетевая безопасность модели Purdue, развертывание датчиков OT, мониторинг портов SPAN, обнаружение корпоративного IoT, защита неуправляемых устройств, безопасность на заводе, NDR для OT, обнаружение угроз ICS, инвентаризация активов IoT. НЕ ИСПОЛЬЗУЙТЕ для безопасности уровня данных Центра Интернета вещей (платформа Azure), усиления защиты устройств Azure Sphere или общего EDR конечной точки (используйте защитник для конечной точки).
