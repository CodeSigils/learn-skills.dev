Microsoft Defender for IoT에 대한 지침 - 산업 환경을 위한 에이전트 없는 OT/ICS 네트워크 감지 및 대응과 Defender XDR과 통합된 엔터프라이즈 IoT(EIoT) 보호 기능을 제공합니다. OT 센서 배포(물리적/가상, SPAN/TAP), Purdue 모델 정렬, 온프레미스 관리 콘솔, 클라우드 관리 센서, MDE를 통해 검색된 EIoT(프린터, 카메라, VoIP), 자산 인벤토리, 취약성 데이터, 위협 인텔리전스, Sentinel 및 Defender XDR과의 통합을 다룹니다. 시기: IoT용 Defender, OT 보안, ICS 보안, SCADA 모니터링, Purdue 모델 네트워크 보안, OT 센서 배포, SPAN 포트 모니터링, 엔터프라이즈 IoT 검색, 관리되지 않는 장치 보호, 공장 현장 보안, OT용 NDR, ICS 위협 탐지, IoT 자산 인벤토리. IoT Hub 데이터 평면 보안(Azure 플랫폼), Azure Sphere 장치 강화 또는 일반 엔드포인트 EDR(엔드포인트 방어자 사용)에는 사용하지 마세요.
