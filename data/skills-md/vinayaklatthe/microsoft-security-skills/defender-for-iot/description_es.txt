Guía para Microsoft Defender para IoT: detección y respuesta de redes OT/ICS sin agentes para entornos industriales, además de protección de IoT empresarial (EIoT) integrada con Defender XDR. Cubre la implementación de sensores OT (físicos/virtuales, SPAN/TAP), alineación del modelo Purdue, consola de administración local, sensores administrados en la nube, EIoT (impresoras, cámaras, VoIP) descubiertos a través de MDE, inventario de activos, datos de vulnerabilidad, inteligencia sobre amenazas e integración con Sentinel y Defender XDR. CUÁNDO: Defender para IoT, seguridad OT, seguridad ICS, monitoreo SCADA, seguridad de red modelo Purdue, implementación de sensores OT, monitoreo de puertos SPAN, descubrimiento de IoT empresarial, protección de dispositivos no administrados, seguridad de fábrica, NDR para OT, detección de amenazas ICS, inventario de activos de IoT. NO LO USE para seguridad del plano de datos de IoT Hub (plataforma Azure), protección de dispositivos Azure Sphere o EDR de punto final genérico (use defensor para punto final).
