Guía para Microsoft Entra External ID: la plataforma de colaboración externa y administración unificada de acceso e identidad del cliente (CIAM) que reemplaza a Azure AD B2C (para nuevos inquilinos) y consolida los escenarios de invitados B2B. Cubre la creación de inquilinos externos, flujos de usuarios (registro/inicio de sesión, restablecimiento de contraseña), marca personalizada, proveedores de identidad (Google, Facebook, Apple, SAML/OIDC), OTP de correo electrónico y compatibilidad con claves de acceso, atributos personalizados, extensiones de autenticación personalizadas (reemplaza las políticas personalizadas de B2C), conectores API, acceso condicional para usuarios externos, registro de autoservicio en inquilinos de fuerza laboral, colaboración B2B frente a conexión directa B2B, configuración de acceso entre inquilinos y consideraciones de migración desde Azure AD B2C. CUÁNDO: ID externo de Entra, CIAM Microsoft, identidad del cliente, reemplazo de Azure AD B2C, usuario invitado B2B, conexión directa B2B, configuración de acceso entre inquilinos, inquilino externo, registro de autoservicio, extensión de autenticación personalizada, proveedor de identidad social, colaboración de socios Entra, ciclo de vida del usuario externo, vencimiento del usuario invitado. NO LO UTILICE para la identidad de la fuerza laboral (use entra-id), la gobernanza de la fuerza laboral (use entra-id-governance) o la CA de la fuerza laboral (use conditional-access-mfa).
