إرشادات لمعرف Microsoft Entra الخارجي — هوية العميل الموحدة وإدارة الوصول (CIAM) ونظام التعاون الأساسي الخارجي الذي يحل محل Azure AD B2C (للمستأجرين الجدد) ويدمج سيناريوهات ضيوف B2B. يغطي إنشاء المستأجر الخارجي، وتدفقات المستخدم (التسجيل/تسجيل الدخول، وإعادة تعيين كلمة المرور)، والعلامات التجارية المخصصة، وموفري الهوية (Google، وFacebook، وApple، وSAML/OIDC)، ودعم OTP للبريد الإلكتروني ومفتاح المرور، والسمات المخصصة، وملحقات المصادقة المخصصة (تحل محل السياسات المخصصة B2C)، وموصلات API، والوصول المشروط للمستخدمين الخارجيين، وتسجيل الخدمة الذاتية في مستأجري القوى العاملة، والتعاون B2B مقابل الاتصال المباشر B2B، وإعدادات الوصول عبر المستأجرين، واعتبارات الترحيل من Azure إعلان B2C. متى: معرف Entra الخارجي، CIAM Microsoft، هوية العميل، استبدال Azure AD B2C، مستخدم ضيف B2B، الاتصال المباشر B2B، إعدادات الوصول عبر المستأجرين، المستأجر الخارجي، تسجيل الخدمة الذاتية، ملحق المصادقة المخصص، موفر الهوية الاجتماعية، تعاون الشريك Entra، دورة حياة المستخدم الخارجي، انتهاء صلاحية المستخدم الضيف. لا تستخدم لهوية القوى العاملة (استخدم entra-id)، أو حوكمة القوى العاملة (استخدم entra-id-governance)، أو CA للقوى العاملة (استخدم الوصول المشروط-mfa).
