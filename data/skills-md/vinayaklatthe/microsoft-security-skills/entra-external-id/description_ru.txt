Руководство по внешнему идентификатору Microsoft Entra — унифицированной платформе управления идентификацией и доступом клиентов (CIAM) и внешней платформой совместной работы, которая заменяет Azure AD B2C (для новых клиентов) и объединяет гостевые сценарии B2B. Охватывает создание внешнего клиента, потоки пользователей (регистрация/вход, сброс пароля), индивидуальный брендинг, поставщики удостоверений (Google, Facebook, Apple, SAML/OIDC), поддержку одноразовых паролей по электронной почте и паролей, настраиваемые атрибуты, настраиваемые расширения аутентификации (заменяют пользовательские политики B2C), соединители API, условный доступ для внешних пользователей, самостоятельную регистрацию в арендаторах рабочей силы, совместную работу B2B по сравнению с прямым подключением B2B, настройки межклиентского доступа и вопросы миграции из Azure AD. B2C. КОГДА: внешний идентификатор Entra, CIAM Microsoft, удостоверение клиента, замена Azure AD B2C, гостевой пользователь B2B, прямое подключение B2B, настройки межклиентского доступа, внешний клиент, самостоятельная регистрация, настраиваемое расширение аутентификации, поставщик социальных удостоверений, сотрудничество с партнерами Entra, жизненный цикл внешнего пользователя, истечение срока действия гостевого пользователя. НЕ ИСПОЛЬЗУЙТЕ для идентификации рабочей силы (используйте entra-id), управления рабочей силой (используйте entra-id-governance) или CA рабочей силы (используйте условный доступ-mfa).
