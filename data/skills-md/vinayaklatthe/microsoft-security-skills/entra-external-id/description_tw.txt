Microsoft Entra 外部 ID 指南 — 統一客戶身分和存取管理 (CIAM) 以及外部協作平台，取代 Azure AD B2C（適用於新租用戶）並整合 B2B 來賓方案。涵蓋外部租用戶建立、使用者流程（註冊/登入、密碼重設）、自訂品牌、身分識別提供者（Google、Facebook、Apple、SAML/OIDC）、電子郵件 OTP 和金鑰支援、自訂屬性、自訂身分驗證擴充功能（取代 B2C 自訂原則）、API 連接器、外部使用者的條件存取、員工租用戶中的自助服務註冊、B2C 自訂原則）、API 連接器、外部使用者的條件存取權、員工租用戶中的自助服務註冊、B2B 直接與用戶移轉的存取。何時：Entra 外部 ID、CIAM Microsoft、客戶身分、取代 Azure AD B2C、B2B 來賓使用者、B2B 直接連線、跨租用戶存取設定、外部租用戶、自助註冊、自訂身分驗證擴充功能、社群身分提供者、合作夥伴協作 Entra、外部使用者生命週期、來賓使用者到期。請勿用於員工身分（使用 entra-id）、員工治理（使用 entra-id-governance）或員工 CA（使用條件存取-MFA）。
