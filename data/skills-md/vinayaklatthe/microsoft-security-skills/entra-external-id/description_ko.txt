Microsoft Entra 외부 ID에 대한 지침 — Azure AD B2C(새 테넌트용)를 대체하고 B2B 게스트 시나리오를 통합하는 CIAM(통합 고객 ID 및 액세스 관리) 및 외부 공동 작업 플랫폼입니다. 외부 테넌트 생성, 사용자 흐름(가입/로그인, 암호 재설정), 사용자 지정 브랜딩, ID 공급자(Google, Facebook, Apple, SAML/OIDC), 이메일 OTP 및 암호 키 지원, 사용자 지정 특성, 사용자 지정 인증 확장(B2C 사용자 지정 정책 대체), API 커넥터, 외부 사용자를 위한 조건부 액세스, 직원 테넌트의 셀프 서비스 등록, B2B 공동 작업과 B2B 직접 연결, 교차 테넌트 액세스 설정 및 Azure AD의 마이그레이션 고려 사항을 다룹니다. B2C. 시기: Entra 외부 ID, CIAM Microsoft, 고객 ID, Azure AD B2C 교체, B2B 게스트 사용자, B2B 직접 연결, 테넌트 간 액세스 설정, 외부 테넌트, 셀프 서비스 가입, 사용자 지정 인증 확장, 소셜 ID 공급자, 파트너 협업 Entra, 외부 사용자 수명 주기, 게스트 사용자 만료. 직원 ID(entra-id 사용), 직원 거버넌스(entra-id-governance 사용) 또는 직원 CA(conditional-access-mfa 사용)에는 사용하지 마세요.
