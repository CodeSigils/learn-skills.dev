Microsoft Entra 外部 ID 指南 — 统一客户身份和访问管理 (CIAM) 以及外部协作平台，取代 Azure AD B2C（适用于新租户）并整合 B2B 来宾方案。涵盖外部租户创建、用户流（注册/登录、密码重置）、自定义品牌、身份提供商（Google、Facebook、Apple、SAML/OIDC）、电子邮件 OTP 和密钥支持、自定义属性、自定义身份验证扩展（替换 B2C 自定义策略）、API 连接器、外部用户的条件访问、员工租户中的自助注册、B2B 协作与 B2B 直接连接、跨租户访问设置以及 Azure AD B2C 的迁移注意事项。何时：Entra 外部 ID、CIAM Microsoft、客户身份、替换 Azure AD B2C、B2B 来宾用户、B2B 直接连接、跨租户访问设置、外部租户、自助注册、自定义身份验证扩展、社交身份提供商、合作伙伴协作 Entra、外部用户生命周期、来宾用户到期。请勿用于员工身份（使用 entra-id）、员工治理（使用 entra-id-governance）或员工 CA（使用条件访问-MFA）。
