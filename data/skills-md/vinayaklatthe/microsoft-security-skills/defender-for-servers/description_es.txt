Guía para Microsoft Defender para servidores (Plan 1 y Plan 2): protección específica del servidor en Microsoft Defender para la nube. Cubre la selección de planes, escaneo sin agente versus basado en agente, integración de MDE para servidores, monitoreo de integridad de archivos (FIM a través de MDE), acceso a VM justo a tiempo, evaluación de vulnerabilidades, controles de aplicaciones adaptables, refuerzo de red e ingesta gratuita de datos a Sentinel/Log Analytics. Se aplica a máquinas virtuales de Azure, servidores habilitados para Azure Arc (locales, AWS EC2, GCP Compute) y Azure VMSS. CUÁNDO: Defender para servidores, MDE para servidores, EDR de servidor, FIM, monitoreo de integridad de archivos, acceso JIT a VM, acceso justo a tiempo, servidores de escaneo sin agentes, evaluación de vulnerabilidades para VM, protección de servidores híbridos, seguridad de servidores habilitados para Arc, AWS EC2 en Defender for Cloud, GCP Compute en Defender for Cloud, fortalecimiento de servidores Azure, servidores Plan 1 vs Plan 2. NO LO USE para dispositivos cliente de punto final (use defensor para punto final), postura genérica de recursos de Azure (use defensor para endurecimiento de la nube) ni hosts de contenedores (use defensor para contenedores).
