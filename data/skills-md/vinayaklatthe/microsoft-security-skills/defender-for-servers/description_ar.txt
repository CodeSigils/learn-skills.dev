إرشادات لـ Microsoft Defender للخوادم (الخطة 1 والخطة 2) - الحماية الخاصة بالخادم في Microsoft Defender for Cloud. يغطي اختيار الخطة، والفحص بدون وكيل مقابل الفحص المستند إلى الوكيل، وتكامل MDE للخوادم، ومراقبة سلامة الملفات (FIM عبر MDE)، والوصول إلى الأجهزة الافتراضية في الوقت المناسب، وتقييم نقاط الضعف، وعناصر التحكم في التطبيقات التكيفية، وتقوية الشبكة، واستيعاب البيانات مجانًا إلى Sentinel/Log Analytics. ينطبق على أجهزة Azure VMs والخوادم التي تدعم Azure Arc (المحلية، AWS EC2، GCP Compute)، وAzure VMSS. متى: Defender للخوادم، MDE للخوادم، EDR للخادم، FIM، مراقبة سلامة الملفات، الوصول إلى JIT VM، الوصول في الوقت المناسب، خوادم المسح بدون وكيل، تقييم الثغرات الأمنية للأجهزة الافتراضية، حماية الخادم المختلط، أمان الخوادم التي تدعم Arc، AWS EC2 في Defender for Cloud، GCP Compute في Defender for Cloud، تقوية الخادم Azure، خوادم الخطة 1 مقابل خوادم الخطة 2. لا تستخدمه لأجهزة عميل نقطة النهاية (استخدم المدافع مقابل نقطة النهاية)، أو وضع موارد Azure العام (استخدم المدافع مقابل تقوية السحابة)، أو مضيفي الحاويات (استخدم المدافع مقابل الحاويات).
