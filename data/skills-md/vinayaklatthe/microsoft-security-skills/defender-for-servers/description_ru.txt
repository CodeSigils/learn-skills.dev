Руководство по Microsoft Defender для серверов (план 1 и план 2) — защита конкретного сервера в Microsoft Defender для облака. Охватывает выбор плана, сканирование без агента или на основе агента, интеграцию MDE для серверов, мониторинг целостности файлов (FIM через MDE), своевременный доступ к виртуальным машинам, оценку уязвимостей, адаптивный контроль приложений, усиление защиты сети и бесплатную загрузку данных в Sentinel/Log Analytics. Применяется к виртуальным машинам Azure, серверам с поддержкой Azure Arc (локальным, AWS EC2, GCP Compute) и Azure VMSS. КОГДА: Defender для серверов, MDE для серверов, EDR серверов, FIM, мониторинг целостности файлов, JIT-доступ к виртуальным машинам, своевременный доступ, серверы сканирования без агентов, оценка уязвимостей для виртуальных машин, защита гибридных серверов, безопасность серверов с поддержкой Arc, AWS EC2 в Defender для облака, GCP Compute в Defender для облака, усиление защиты серверов Azure, серверы плана 1 и плана 2. НЕ ИСПОЛЬЗУЙТЕ для клиентских устройств конечной точки (используйте защитник для конечной точки), общего состояния ресурсов Azure (используйте защитник для защиты в облаке) или узлов контейнеров (используйте защитник для контейнеров).
