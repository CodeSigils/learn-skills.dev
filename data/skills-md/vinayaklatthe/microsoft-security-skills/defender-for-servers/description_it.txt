Linee guida per Microsoft Defender for Servers (Piano 1 e Piano 2): protezione specifica del server in Microsoft Defender for Cloud. Copre la selezione del piano, la scansione senza agente o basata su agente, l'integrazione di MDE per server, il monitoraggio dell'integrità dei file (FIM tramite MDE), l'accesso just-in-time alle VM, la valutazione delle vulnerabilità, i controlli delle applicazioni adattivi, il rafforzamento della rete e l'inserimento gratuito di dati in Sentinel/Log Analytics. Si applica alle macchine virtuali di Azure, ai server abilitati per Azure Arc (on-premise, AWS EC2, GCP Compute) e Azure VMSS. QUANDO: Defender for Servers, MDE for Servers, server EDR, FIM, monitoraggio dell'integrità dei file, accesso JIT alle VM, accesso just-in-time, server di scansione senza agente, valutazione della vulnerabilità per le VM, protezione dei server ibridi, sicurezza dei server abilitati per Arc, AWS EC2 in Defender for Cloud, elaborazione GCP in Defender for Cloud, rafforzamento dei server Azure, server Piano 1 vs Piano 2. NON UTILIZZARE per dispositivi client endpoint (usare Defender-for-endpoint), comportamento generico delle risorse di Azure (usare Defender-for-cloud-hardening) o host contenitori (usare Defender-for-containers).
