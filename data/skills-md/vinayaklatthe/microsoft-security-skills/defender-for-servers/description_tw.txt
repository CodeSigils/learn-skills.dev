Microsoft Defender for Servers 指南（計畫 1 和計畫 2）- Microsoft Defender for Cloud 中的伺服器特定保護。涵蓋計劃選擇、無代理與基於代理的掃描、伺服器整合的 MDE、文件完整性監控（透過 MDE 的 FIM）、即時 VM 存取、漏洞評估、自適應應用程式控制、網路強化以及免費將資料引入 Sentinel/Log Analytics。適用於 Azure VM、啟用 Azure Arc 的伺服器（本機、AWS EC2、GCP 運算）和 Azure VMSS。時間：Defender for Servers、MDE for Servers、伺服器 EDR、FIM、檔案完整性監控、JIT VM 存取、即時存取、無代理掃描伺服器、VM 漏洞評估、混合式伺服器保護、啟用 Arc 的伺服器安全性、Defender for Cloud 中的 AWS EC2、Defender for Cloud 伺服器中的 GCP 計算、伺服器請勿用於端點用戶端裝置（使用 Defender-for-Endpoint）、通用 Azure 資源狀態（使用 Defender-for-cloud-hardening）或容器主機（使用 Defender-for-containers）。
