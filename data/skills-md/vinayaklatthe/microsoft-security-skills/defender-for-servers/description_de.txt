Leitfaden für Microsoft Defender für Server (Plan 1 und Plan 2) – serverspezifischer Schutz in Microsoft Defender für Cloud. Umfasst Planauswahl, agentenloses vs. agentenbasiertes Scannen, MDE für Server-Integration, Dateiintegritätsüberwachung (FIM über MDE), Just-in-Time-VM-Zugriff, Schwachstellenbewertung, adaptive Anwendungskontrollen, Netzwerkhärtung und kostenlose Datenaufnahme in Sentinel/Log Analytics. Gilt für Azure-VMs, Azure Arc-fähige Server (lokal, AWS EC2, GCP Compute) und Azure VMSS. WANN: Defender für Server, MDE für Server, Server-EDR, FIM, Dateiintegritätsüberwachung, JIT-VM-Zugriff, Just-in-Time-Zugriff, agentenlose Scanserver, Schwachstellenbewertung für VMs, Hybridserverschutz, Arc-fähige Serversicherheit, AWS EC2 in Defender für Cloud, GCP Compute in Defender für Cloud, Serverhärtung in Azure, Plan 1 vs. Plan 2-Server. NICHT für Endpunkt-Clientgeräte (verwenden Sie Defender-for-Endpoint), generische Azure-Ressourcenhaltung (verwenden Sie Defender-for-Cloud-Hardening) oder Container-Hosts (verwenden Sie Defender-for-Container) verwenden.
