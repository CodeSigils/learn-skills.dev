Microsoft Defender for Servers のガイダンス (プラン 1 およびプラン 2) — Microsoft Defender for Cloud のサーバー固有の保護。プランの選択、エージェントレスとエージェントベースのスキャン、MDE for Servers の統合、ファイル整合性監視 (MDE 経由の FIM)、ジャストインタイム VM アクセス、脆弱性評価、適応型アプリケーション制御、ネットワーク強化、Sentinel/Log Analytics への無料データ取り込みをカバーします。 Azure VM、Azure Arc 対応サーバー (オンプレミス、AWS EC2、GCP コンピューティング)、および Azure VMSS に適用されます。時期: Defender for Servers、MDE for Servers、サーバー EDR、FIM、ファイル整合性監視、JIT VM アクセス、ジャストインタイム アクセス、エージェントレス スキャン サーバー、VM の脆弱性評価、ハイブリッド サーバー保護、Arc 対応サーバー セキュリティ、Defender for Cloud の AWS EC2、Defender for Cloud の GCP コンピューティング、Azure サーバーの強化、プラン 1 サーバーとプラン 2 サーバー。エンドポイント クライアント デバイス (defender-for-endpoint を使用)、汎用 Azure リソース ポスチャ (defender-for-cloud-hardening を使用)、またはコンテナー ホスト (defender-for-containers を使用) には使用しないでください。
