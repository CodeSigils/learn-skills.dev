Microsoft Defender for Servers 指南（计划 1 和计划 2）- Microsoft Defender for Cloud 中的服务器特定保护。涵盖计划选择、无代理与基于代理的扫描、服务器集成的 MDE、文件完整性监控（通过 MDE 的 FIM）、即时 VM 访问、漏洞评估、自适应应用程序控制、网络强化以及免费将数据引入到 Sentinel/Log Analytics。适用于 Azure VM、启用 Azure Arc 的服务器（本地、AWS EC2、GCP 计算）和 Azure VMSS。时间：Defender for Servers、MDE for Servers、服务器 EDR、FIM、文件完整性监控、JIT VM 访问、即时访问、无代理扫描服务器、VM 漏洞评估、混合服务器保护、启用 Arc 的服务器安全、Defender for Cloud 中的 AWS EC2、Defender for Cloud 中的 GCP 计算、服务器强化 Azure、计划 1 与计划 2 服务器。请勿用于端点客户端设备（使用 Defender-for-Endpoint）、通用 Azure 资源状态（使用 Defender-for-cloud-hardening）或容器主机（使用 Defender-for-containers）。
