Conseils pour Microsoft Defender pour serveurs (Plan 1 et Plan 2) : protection spécifique au serveur dans Microsoft Defender pour Cloud. Couvre la sélection du plan, l'analyse sans agent ou basée sur agent, l'intégration de MDE pour serveurs, la surveillance de l'intégrité des fichiers (FIM via MDE), l'accès juste à temps aux machines virtuelles, l'évaluation des vulnérabilités, les contrôles d'application adaptatifs, le renforcement du réseau et l'ingestion gratuite de données vers Sentinel/Log Analytics. S'applique aux machines virtuelles Azure, aux serveurs compatibles Azure Arc (sur site, AWS EC2, GCP Compute) et à Azure VMSS. QUAND : Defender pour les serveurs, MDE pour les serveurs, EDR des serveurs, FIM, surveillance de l'intégrité des fichiers, accès aux machines virtuelles JIT, accès juste à temps, serveurs d'analyse sans agent, évaluation de la vulnérabilité des machines virtuelles, protection des serveurs hybrides, sécurité des serveurs compatibles Arc, AWS EC2 dans Defender pour Cloud, GCP Compute dans Defender pour Cloud, renforcement des serveurs Azure, serveurs Plan 1 vs Plan 2. NE PAS UTILISER pour les appareils clients de point de terminaison (utilisez Defender-for-endpoint), la posture de ressource Azure générique (utilisez Defender-for-cloud-hardening) ou les hôtes de conteneurs (utilisez Defender-for-containers).
