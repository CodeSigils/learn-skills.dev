إرشادات لإدارة دورة حياة بيانات Microsoft Purview وإدارة السجلات - تسميات الاستبقاء وسياسات الاحتفاظ بالمحتوى وحذفه عبر Microsoft 365، بالإضافة إلى الإعلان عن السجلات. يغطي استراتيجية الاحتفاظ، والنطاقات التكيفية مقابل الثابتة، ومبدأ الأسبقية، ومراجعة التصرف، والسجلات التنظيمية. متى: إدارة دورة حياة البيانات، سياسة الاستبقاء، تسمية الاستبقاء، إدارة السجلات، إعلان السجل، مراجعة التصرف، النطاقات التكيفية، الاحتفاظ بالمحتوى وحذفه، خطة الملف، الاحتفاظ التنظيمي، السجلات غير القابلة للتغيير.
