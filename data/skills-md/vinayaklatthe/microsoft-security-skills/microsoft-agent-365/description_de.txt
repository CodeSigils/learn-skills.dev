Leitfaden für die Verwaltung von KI-Agenten auf Unternehmensebene mit Microsoft Agent 365 – der Steuerungsebene, die es Administratoren ermöglicht, jeden Agenten (Microsoft, Copilot Studio und Drittanbieter) von einer einzigen Registrierung aus zu beobachten, zu steuern und zu schützen, wobei Microsoft Entra Agent ID für die Identität, Microsoft Purview für die Datensicherheit und Microsoft Defender für den Laufzeitschutz vor Bedrohungen verwendet werden. WANN: Microsoft Agent 365, Agent 365, Agenten im großen Maßstab verwalten, Agentensteuerungsebene, Agentenregistrierung, Agentenzuordnung, Überwachung sicherer Agenten, Entra-Agenten-ID, Lebenszyklus der Agentenidentität, Agenten-Governance von Drittanbietern, mandantenweite sichere KI-Agenten, Agentenausbreitung, Agenteninventur. NICHT für reine Purview-Datenkontrollen auf einem einzelnen Agenten (verwenden Sie purview-agent-365-security) oder für Endbenutzer-Copilot-Oversharing (verwenden Sie purview-copilot-oversharing) VERWENDEN.
