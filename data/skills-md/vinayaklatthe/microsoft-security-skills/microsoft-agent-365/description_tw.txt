使用 Microsoft Agent 365 管理企業規模的 AI 代理程式的指南 - 控制平面可讓管理員從單一登錄檔觀察、管理和保護每個代理程式（Microsoft、Copilot Studio 和第三方），使用 Microsoft Entra Agent ID 進行身分識別，使用 Microsoft Purview 進行資料安全，並使用 Microsoft Defender 執行執行時威脅防護。時間：Microsoft Agent 365、Agent 365、大規模管理代理、代理控制平面、代理註冊表、代理映射、觀察管理安全代理、Entra Agent ID、代理身份生命週期、第三方代理治理、租戶範圍內的安全 AI 代理、代理蔓延、代理庫存。請勿用於單一代理程式上的僅 Purview 資料控制（使用 purview-agent-365-security）或最終使用者 Copilot 過度共用（使用 purview-copilot-oversharing）。
