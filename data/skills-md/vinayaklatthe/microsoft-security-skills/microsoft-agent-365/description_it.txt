Linee guida per la gestione degli agenti IA su scala aziendale con Microsoft Agent 365: il piano di controllo che consente agli amministratori di osservare, governare e proteggere ogni agente (Microsoft, Copilot Studio e terze parti) da un unico registro, utilizzando l'ID agente Microsoft Entra per l'identità, Microsoft Purview per la sicurezza dei dati e Microsoft Defender per la protezione dalle minacce in fase di esecuzione. QUANDO: Microsoft Agent 365, Agent 365, gestione degli agenti su larga scala, piano di controllo degli agenti, registro degli agenti, mappa degli agenti, osservazione della governance degli agenti sicuri, ID agente Entra, ciclo di vita dell'identità dell'agente, governance degli agenti di terze parti, agenti IA protetti a livello di tenant, espansione degli agenti, inventario degli agenti. NON UTILIZZARE per controlli dati solo Purview su un singolo agente (utilizzare purview-agent-365-security) o per l'oversharing Copilot dell'utente finale (utilizzare purview-copilot-oversharing).
