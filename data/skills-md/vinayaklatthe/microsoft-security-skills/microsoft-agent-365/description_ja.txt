Microsoft Agent 365 を使用してエンタープライズ規模で AI エージェントを管理するためのガイダンス。管理者はこのコントロール プレーンを使用して、ID に Microsoft Entra Agent ID、データ セキュリティに Microsoft Purview、ランタイム脅威保護に Microsoft Defender を使用して、単一のレジストリからすべてのエージェント (Microsoft、Copilot Studio、およびサードパーティ) を監視、管理、セキュリティで保護できます。時期: Microsoft Agent 365、Agent 365、大規模なエージェントの管理、エージェント コントロール プレーン、エージェント レジストリ、エージェント マップ、安全なエージェントの監視、Entra エージェント ID、エージェント ID ライフサイクル、サードパーティ エージェント ガバナンス、テナント全体の安全な AI エージェント、エージェントのスプロール化、エージェント インベントリ。単一エージェント上の Purview 専用データ コントロール (purview-agent-365-security を使用) またはエンドユーザーの Copilot のオーバーシェアリング (purview-copilot-oversharing を使用) には使用しないでください。
