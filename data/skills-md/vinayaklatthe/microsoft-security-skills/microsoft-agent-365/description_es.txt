Guía para administrar agentes de IA a escala empresarial con Microsoft Agent 365: el plano de control que permite a los administradores observar, gobernar y proteger a cada agente (Microsoft, Copilot Studio y terceros) desde un único registro, utilizando Microsoft Entra Agent ID para identidad, Microsoft Purview para seguridad de datos y Microsoft Defender para protección contra amenazas en tiempo de ejecución. CUÁNDO: Microsoft Agent 365, Agent 365, administrar agentes a escala, plano de control de agentes, registro de agentes, mapa de agentes, observar el gobierno de agentes seguros, Entra Agent ID, ciclo de vida de identidad de agentes, gobierno de agentes de terceros, agentes de IA seguros en todo el inquilino, expansión de agentes, inventario de agentes. NO LO USE para controles de datos exclusivos de Purview en un solo agente (use purview-agent-365-security) o para compartir en exceso Copilot con el usuario final (use purview-copilot-oversharing).
