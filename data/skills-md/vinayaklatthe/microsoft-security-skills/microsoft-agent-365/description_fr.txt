Conseils pour la gestion des agents IA à l'échelle de l'entreprise avec Microsoft Agent 365 : le plan de contrôle qui permet aux administrateurs d'observer, de gouverner et de sécuriser chaque agent (Microsoft, Copilot Studio et tiers) à partir d'un seul registre, en utilisant l'ID d'agent Microsoft Entra pour l'identité, Microsoft Purview pour la sécurité des données et Microsoft Defender pour la protection contre les menaces d'exécution. QUAND : Microsoft Agent 365, Agent 365, gestion des agents à grande échelle, plan de contrôle des agents, registre des agents, carte des agents, observation des agents sécurisés, Entra Agent ID, cycle de vie de l'identité de l'agent, gouvernance des agents tiers, sécurisation des agents IA à l'échelle du locataire, prolifération des agents, inventaire des agents. NE PAS UTILISER pour les contrôles de données Purview uniquement sur un seul agent (utilisez purview-agent-365-security) ou pour le partage excessif de Copilot par l'utilisateur final (utilisez purview-copilot-oversharing).
