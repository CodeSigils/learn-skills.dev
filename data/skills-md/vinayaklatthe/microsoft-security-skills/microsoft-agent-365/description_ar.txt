إرشادات لإدارة وكلاء الذكاء الاصطناعي على مستوى المؤسسة باستخدام Microsoft Agent 365 - مستوى التحكم الذي يتيح للمسؤولين مراقبة كل وكيل وإدارته وتأمينه (Microsoft وCopilot Studio والجهات الخارجية) من سجل واحد، باستخدام معرف Microsoft Entra Agent للهوية، وMicrosoft Purview لأمان البيانات، وMicrosoft Defender للحماية من التهديدات في وقت التشغيل. متى: Microsoft Agent 365، Agent 365، إدارة الوكلاء على نطاق واسع، ومستوى التحكم في الوكيل، وسجل الوكيل، وخريطة الوكيل، ومراقبة الوكلاء الآمنين، ومعرف وكيل Entra، ودورة حياة هوية الوكيل، وحوكمة وكيل الطرف الثالث، ووكلاء الذكاء الاصطناعي الآمنين على مستوى المستأجر، وامتداد الوكيل، ومخزون الوكيل. لا تستخدمه لعناصر التحكم في بيانات Purview فقط على وكيل واحد (استخدم Purview-agent-365-security) أو مشاركة Copilot للمستخدم النهائي (استخدم Purview-copilot-oversharing).
