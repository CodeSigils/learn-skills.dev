使用 Microsoft Agent 365 管理企业规模的 AI 代理的指南 - 控制平面允许管理员从单个注册表观察、管理和保护每个代理（Microsoft、Copilot Studio 和第三方），使用 Microsoft Entra Agent ID 进行身份识别，使用 Microsoft Purview 进行数据安全，并使用 Microsoft Defender 进行运行时威胁防护。时间：Microsoft Agent 365、Agent 365、大规模管理代理、代理控制平面、代理注册表、代理映射、观察管理安全代理、Entra Agent ID、代理身份生命周期、第三方代理治理、租户范围内的安全 AI 代理、代理蔓延、代理库存。请勿用于单个代理上的仅 Purview 数据控制（使用 purview-agent-365-security）或最终用户 Copilot 过度共享（使用 purview-copilot-oversharing）。
