Руководство по управлению агентами ИИ в масштабе предприятия с помощью Microsoft Agent 365 — плоскости управления, которая позволяет администраторам наблюдать, управлять и защищать каждый агент (Microsoft, Copilot Studio и сторонние) из единого реестра, используя идентификатор агента Microsoft Entra для идентификации, Microsoft Purview для безопасности данных и Microsoft Defender для защиты от угроз во время выполнения. КОГДА: Microsoft Agent 365, Agent 365, управление агентами в масштабе, плоскость управления агентами, реестр агентов, карта агентов, наблюдение за управлением безопасными агентами, идентификатор агента Entra, жизненный цикл удостоверения агента, управление сторонними агентами, безопасные агенты AI для всего клиента, разрастание агентов, инвентаризация агентов. НЕ ИСПОЛЬЗУЙТЕ для контроля данных только для Purview на одном агенте (используйте purview-agent-365-security) или для совместного использования Copilot конечного пользователя (используйте purview-copilot-oversharing).
