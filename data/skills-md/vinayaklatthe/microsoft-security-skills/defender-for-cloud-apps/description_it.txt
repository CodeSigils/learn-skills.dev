Linee guida per Microsoft Defender for Cloud Apps (MDA): CASB per l'individuazione SaaS, la governance delle app, i controlli delle sessioni e il rilevamento delle minacce. Copre l'individuazione del cloud tramite l'integrazione di Defender for Endpoint, la governance delle app OAuth, il controllo delle app per l'accesso condizionale (criteri di sessione proxy inverso) e il comportamento di sicurezza SaaS (SSPM). QUANDO: Defender per app cloud, MDA, CASB, rilevamento shadow IT, governance delle app cloud, rischio app OAuth, controllo sessioni, controllo app ad accesso condizionale, gestione del livello di sicurezza SaaS, SSPM, app con sanzioni o non sanzioni, catalogo app cloud, connettori app. NON UTILIZZARE per la postura IaaS/PaaS (usare Defender-for-Cloud-Harening), EDR endpoint (usare Defender-for-Endpoint) o DLP (usare Purview-dlp-policy).
