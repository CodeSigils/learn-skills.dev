Leitfaden für Microsoft Defender für Cloud Apps (MDA) – das CASB für SaaS-Erkennung, App-Governance, Sitzungskontrollen und Bedrohungserkennung. Deckt Cloud Discovery über Defender für Endpoint-Integration, OAuth-App-Governance, Conditional Access App Control (Reverse-Proxy-Sitzungsrichtlinien) und SaaS-Sicherheitsstatus (SSPM) ab. WANN: Defender für Cloud-Apps, MDA, CASB, Schatten-IT-Erkennung, Cloud-App-Governance, OAuth-App-Risiko, Sitzungskontrolle, App-Kontrolle für bedingten Zugriff, SaaS-Sicherheitslagemanagement, SSPM, Sanktions- oder Nichtsanktions-App, Cloud-App-Katalog, App-Konnektoren. NICHT für IaaS/PaaS-Status (verwenden Sie Defender-for-Cloud-Hardening), Endpunkt-EDR (verwenden Sie Defender-for-Endpoint) oder DLP (verwenden Sie Purview-DLP-Policy) verwenden.
