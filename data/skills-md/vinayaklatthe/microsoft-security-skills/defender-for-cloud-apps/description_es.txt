Guía para Microsoft Defender para aplicaciones en la nube (MDA): el CASB para el descubrimiento de SaaS, el gobierno de aplicaciones, los controles de sesión y la detección de amenazas. Cubre Cloud Discovery a través de Defender para la integración de endpoints, gobernanza de aplicaciones OAuth, control de aplicaciones de acceso condicional (políticas de sesión de proxy inverso) y postura de seguridad de SaaS (SSPM). CUÁNDO: Defender para aplicaciones en la nube, MDA, CASB, descubrimiento de TI en la sombra, gobernanza de aplicaciones en la nube, riesgo de aplicaciones OAuth, control de sesión, control de aplicaciones de acceso condicional, gestión de la postura de seguridad de SaaS, SSPM, aplicación de sanción o no sanción, catálogo de aplicaciones en la nube, conectores de aplicaciones. NO LO USE para la postura IaaS/PaaS (use defender-for-cloud-hardening), endpoint EDR (use defender-for-endpoint) o DLP (use purview-dlp-policy).
