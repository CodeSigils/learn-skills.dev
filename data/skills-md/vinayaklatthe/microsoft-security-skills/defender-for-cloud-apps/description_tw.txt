Microsoft Defender for Cloud Apps (MDA) 指南 — 用於 SaaS 發現、應用程式治理、會話控制和威脅偵測的 CASB。涵蓋透過 Defender 實現端點整合的雲端發現、OAuth 應用程式治理、條件存取應用程式控制（反向代理會話策略）和 SaaS 安全態勢 (SSPM)。何時：Defender for Cloud Apps、MDA、CASB、影子 IT 發現、雲端應用程式治理、OAuth 應用程式風險、會話控制、條件存取應用程式控制、SaaS 安全態勢管理、SSPM、核准或取消核准應用程式、雲端應用程式目錄、應用程式連接器。請勿用於 IaaS / PaaS 狀態（使用 Defender-for-cloud-hardening）、端點 EDR（使用 Defender-for-endpoint）或 DLP（使用 purview-dlp-policy）。
