Microsoft Defender for Cloud Apps (MDA) 指南 — 用于 SaaS 发现、应用程序治理、会话控制和威胁检测的 CASB。涵盖通过 Defender 实现端点集成的云发现、OAuth 应用程序治理、条件访问应用程序控制（反向代理会话策略）和 SaaS 安全态势 (SSPM)。何时：Defender for Cloud Apps、MDA、CASB、影子 IT 发现、云应用治理、OAuth 应用风险、会话控制、条件访问应用控制、SaaS 安全态势管理、SSPM、批准或取消批准应用、云应用目录、应用连接器。请勿用于 IaaS / PaaS 状态（使用 Defender-for-cloud-hardening）、端点 EDR（使用 Defender-for-endpoint）或 DLP（使用 purview-dlp-policy）。
