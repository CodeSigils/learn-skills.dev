Microsoft Defender for Cloud Apps (MDA) のガイダンス — SaaS 検出、アプリ ガバナンス、セッション制御、脅威検出のための CASB。 Defender for Endpoint 統合によるクラウド検出、OAuth アプリ ガバナンス、条件付きアクセス アプリ制御 (リバース プロキシ セッション ポリシー)、および SaaS セキュリティ体制 (SSPM) をカバーします。いつ: Defender for Cloud Apps、MDA、CASB、シャドウ IT 検出、クラウド アプリ ガバナンス、OAuth アプリのリスク、セッション制御、条件付きアクセス アプリ制御、SaaS セキュリティ体制管理、SSPM、アプリの認可または不認可、クラウド アプリ カタログ、アプリ コネクタ。 IaaS / PaaS ポスチャ (defender-for-cloud-hardening を使用)、エンドポイント EDR (defender-for-endpoint を使用)、または DLP (purview-dlp-policy を使用) には使用しないでください。
