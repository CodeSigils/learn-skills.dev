Руководство по Microsoft Defender для облачных приложений (MDA) — CASB для обнаружения SaaS, управления приложениями, управления сеансами и обнаружения угроз. Охватывает обнаружение облака через Defender для интеграции конечных точек, управление приложениями OAuth, контроль приложений с условным доступом (политики сеансов обратного прокси-сервера) и состояние безопасности SaaS (SSPM). КОГДА: Защитник для облачных приложений, MDA, CASB, обнаружение теневых ИТ, управление облачными приложениями, риски приложений OAuth, контроль сеансов, контроль приложений с условным доступом, управление состоянием безопасности SaaS, SSPM, приложение с санкциями или несанкционированием, каталог облачных приложений, соединители приложений. НЕ ИСПОЛЬЗУЙТЕ для IaaS/PaaS (используйте защитник для защиты от облака), EDR конечной точки (используйте защитник для конечной точки) или DLP (используйте политику purview-dlp).
