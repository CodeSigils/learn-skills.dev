Conseils pour Microsoft Defender for Cloud Apps (MDA) — le CASB pour la découverte SaaS, la gouvernance des applications, les contrôles de session et la détection des menaces. Couvre la découverte du cloud via l'intégration de Defender pour Endpoint, la gouvernance des applications OAuth, le contrôle des applications à accès conditionnel (politiques de session de proxy inverse) et la posture de sécurité SaaS (SSPM). QUAND : Defender pour les applications cloud, MDA, CASB, découverte du shadow IT, gouvernance des applications cloud, risque des applications OAuth, contrôle de session, contrôle des applications à accès conditionnel, gestion de la posture de sécurité SaaS, SSPM, application de sanction ou de non-sanction, catalogue d'applications cloud, connecteurs d'application. NE PAS UTILISER pour la posture IaaS/PaaS (utilisez Defender-for-Cloud-hardening), Endpoint EDR (utilisez Defender-for-endpoint) ou DLP (utilisez Purview-dlp-policy).
