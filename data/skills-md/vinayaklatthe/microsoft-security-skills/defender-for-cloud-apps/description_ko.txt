MDA(클라우드 앱용 Microsoft Defender)에 대한 지침 — SaaS 검색, 앱 거버넌스, 세션 제어 및 위협 감지를 위한 CASB입니다. Defender for Endpoint 통합, OAuth 앱 거버넌스, 조건부 액세스 앱 제어(역방향 프록시 세션 정책) 및 SaaS 보안 상태(SSPM)를 통한 Cloud Discovery를 다룹니다. 시기: Defender for Cloud Apps, MDA, CASB, 섀도우 IT 검색, 클라우드 앱 거버넌스, OAuth 앱 위험, 세션 제어, 조건부 액세스 앱 제어, SaaS 보안 상태 관리, SSPM, 제재 또는 비제재 앱, 클라우드 앱 카탈로그, 앱 커넥터. IaaS/PaaS 상태(클라우드 강화를 위한 방어자 사용), 엔드포인트 EDR(엔드포인트를 위한 방어자 사용) 또는 DLP(purview-dlp-policy 사용)에는 사용하지 마십시오.
