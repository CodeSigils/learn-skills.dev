إرشادات لـ Microsoft Defender لتطبيقات السحابة (MDA) - CASB لاكتشاف SaaS وإدارة التطبيق وعناصر التحكم في الجلسة واكتشاف التهديدات. يغطي Cloud Discovery عبر Defender لتكامل نقطة النهاية، وإدارة تطبيق OAuth، والتحكم في تطبيق الوصول المشروط (سياسات جلسة الوكيل العكسي)، والوضع الأمني ​​SaaS (SSPM). متى: Defender for Cloud Apps، وMDA، وCASB، واكتشاف تكنولوجيا المعلومات الظلية، وإدارة التطبيقات السحابية، ومخاطر تطبيقات OAuth، والتحكم في الجلسة، والتحكم في تطبيقات الوصول المشروط، وإدارة موقف أمان SaaS، وSSPM، وتطبيق العقوبات أو عدم الموافقة، وكتالوج تطبيقات السحابة، وموصلات التطبيقات. لا تستخدمه في وضع IaaS / PaaS (استخدم المدافع مقابل تقوية السحابة)، أو EDR لنقطة النهاية (استخدم المدافع مقابل نقطة النهاية)، أو DLP (استخدم سياسة Purview-dlp).
