Microsoft Entra 条件付きアクセス (CA) および多要素認証に関するガイダンス — ユーザー、デバイス、場所、アプリ、およびリスク信号に基づいて許可/ブロックの決定を強制するゼロトラスト ポリシー エンジンです。ベースラインの 6 つのポリシー セット、フィッシング耐性のある MFA の認証強度、レポートのみのロールアウト、ブレークグラスの除外、セッション制御、およびポリシーのライフサイクルをカバーします。いつ: 条件付きアクセス、MFA 強制、準拠デバイスの要求、レガシー認証のブロック、ゼロトラスト アクセス ポリシー、フィッシング耐性 MFA、FIDO2、パスキー、セッション制御、サインイン頻度、CA ポリシー設計、管理者に MFA を必須、ベースライン CA ポリシー、レポート専用モード、What If ツール、ブレークグラス、名前付き場所、アプリ保護ポリシー付与、使用条件を除外。リスクベースの検出信号ソース (entra-id-protection を使用) または PIM アクティブ化 (azure-pim を使用) には使用しないでください。
