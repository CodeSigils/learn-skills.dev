Руководство по условному доступу (CA) Microsoft Entra и многофакторной аутентификации — механизму политики нулевого доверия, который обеспечивает принятие решений о предоставлении или блокировке на основе сигналов пользователя, устройства, местоположения, приложения и рисков. Охватывает базовый набор из 6 политик, уровни аутентификации для устойчивого к фишингу MFA, развертывание только для отчетов, исключения взлома, элементы управления сеансами и жизненный цикл политики. КОГДА: условный доступ, применение MFA, требуется совместимое устройство, блокировка устаревшей аутентификации, политика доступа с нулевым доверием, устойчивый к фишингу MFA, FIDO2, ключ доступа, элементы управления сеансами, частота входа, разработка политики CA, требуется MFA для администраторов, базовые политики CA, режим только для отчетов, инструмент «Что, если», исключение «разбитого стекла», именованные местоположения, предоставление политики защиты приложений, условия использования. НЕ ИСПОЛЬЗУЙТЕ для источников сигналов обнаружения на основе рисков (используйте защиту внутри идентификатора) или активации PIM (используйте azure-pim).
