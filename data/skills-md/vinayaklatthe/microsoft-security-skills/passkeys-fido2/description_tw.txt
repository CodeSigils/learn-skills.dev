在 Microsoft Entra ID 中推出萬用金鑰（裝置綁定和同步）和 FIDO2 安全金鑰作為主要的防網路釣魚身分驗證方法的指南。涵蓋金鑰類型（Microsoft Authenticator 中的裝置綁定、透過平台供應商同步的金鑰、硬體安全金鑰）、條件存取身分驗證強度、註冊活動、臨時存取通行證 (TAP) 引導、生命週期（裝置遺失、證明）、需要防網釣魚 MFA 的條件存取、停用舊方法（簡訊、語音、較弱的應用程式）以及與 Windows Hello 企業版的應用程式設計。時間：金鑰推出、FIDO2 金鑰、防網釣魚 MFA、Microsoft Authenticator 金鑰、裝置綁定金鑰、同步金鑰、臨時存取通行證、TAP、條件存取驗證強度、終止 SMS MFA、退出語音 MFA、無密碼推出、FIDO2 證明、安全金鑰註冊。請勿用於一般 CA 原則創作（使用條件存取 mfa）、Windows 桌面登入設計端對端（使用 windows-hello）或驗證 ID 發行（使用 entra-verified-id）。
