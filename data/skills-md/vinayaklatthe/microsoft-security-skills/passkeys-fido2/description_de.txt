Leitfaden für die Einführung von Hauptschlüsseln (gerätegebunden und synchronisiert) und FIDO2-Sicherheitsschlüsseln in Microsoft Entra ID als primäre Phishing-resistente Authentifizierungsmethode. Behandelt Passkey-Typen (gerätegebunden in Microsoft Authenticator, synchronisierte Passkeys über Plattformanbieter, Hardware-Sicherheitsschlüssel), Authentifizierungsstärke für bedingten Zugriff, Registrierungskampagnen, TAP-Bootstrapping (Temporary Access Pass), Lebenszyklus (verlorenes Gerät, Nachweis), bedingter Zugriff, der Phishing-resistente MFA erfordert, Außerbetriebnahme älterer Methoden (SMS, Sprache, schwächerer App-Push) und Integration mit Windows Hello for Business. WANN: Rollout des Passkeys, FIDO2-Schlüssel, Phishing-resistente MFA, Microsoft Authenticator-Passkey, gerätegebundener Passkey, synchronisierter Passkey, temporärer Zugriffspass, TAP, Authentifizierungsstärke für bedingten Zugriff, Kill-SMS-MFA, Einstellung der Sprach-MFA, passwortlose Rollout, FIDO2-Nachweis, Registrierung des Sicherheitsschlüssels. NICHT für die allgemeine Erstellung von CA-Richtlinien (verwenden Sie Conditional-Access-MFA), das End-to-End-Design der Windows-Desktop-Anmeldung (verwenden Sie Windows-Hello) oder die Ausstellung einer verifizierten ID (verwenden Sie entra-verified-id) VERWENDEN.
