Руководство по развертыванию ключей доступа (привязанных к устройству и синхронизированных) и ключей безопасности FIDO2 в Microsoft Entra ID в качестве основного метода аутентификации, устойчивого к фишингу. Охватывает типы ключей доступа (привязка к устройству в Microsoft Authenticator, ключи доступа, синхронизированные через поставщиков платформ, аппаратные ключи безопасности), надежность проверки подлинности условного доступа, регистрационные кампании, загрузку временного доступа (TAP), жизненный цикл (потеря устройства, аттестация), условный доступ, требующий устойчивого к фишингу MFA, вывод из эксплуатации устаревших методов (SMS, голосовая связь, более слабая отправка приложений) и интеграция с Windows Hello для бизнеса. КОГДА: развертывание ключа доступа, ключи FIDO2, устойчивый к фишингу MFA, ключ доступа Microsoft Authenticator, ключ доступа, привязанный к устройству, синхронизированный ключ доступа, временный пароль доступа, TAP, сила аутентификации условного доступа, отключение SMS MFA, отказ от голосового MFA, развертывание без пароля, аттестация FIDO2, регистрация ключа безопасности. НЕ ИСПОЛЬЗУЙТЕ для разработки общей политики CA (используйте условный доступ-mfa), сквозного проектирования входа в систему на рабочем столе Windows (используйте windows-hello) или выдачи проверенного идентификатора (используйте entra-verified-id).
