إرشادات لطرح مفاتيح المرور (المرتبطة بالجهاز والمتزامنة) ومفاتيح أمان FIDO2 في معرف Microsoft Entra باعتبارها طريقة المصادقة الأساسية المقاومة للتصيد الاحتيالي. يغطي أنواع مفاتيح المرور (المرتبطة بالجهاز في Microsoft Authenticator، ومفاتيح المرور المتزامنة عبر موفري الأنظمة الأساسية، ومفاتيح أمان الأجهزة)، وقوة مصادقة الوصول المشروط، وحملات التسجيل، وتمهيد تمهيد الوصول المؤقت (TAP)، ودورة الحياة (الجهاز المفقود، والشهادة)، والوصول المشروط الذي يتطلب MFA المقاوم للتصيد الاحتيالي، وطرق إيقاف التشغيل القديمة (الرسائل النصية القصيرة، والصوت، ودفع التطبيق الأضعف)، والتكامل مع Windows Hello for Business. متى: طرح مفتاح المرور، مفاتيح FIDO2، MFA المقاوم للتصيد الاحتيالي، مفتاح مرور Microsoft Authenticator، مفتاح المرور المرتبط بالجهاز، مفتاح المرور المتزامن، ممر الوصول المؤقت، TAP، قوة مصادقة الوصول المشروط، إيقاف SMS MFA، إيقاف MFA الصوتي، طرح بدون كلمة مرور، شهادة FIDO2، تسجيل مفتاح الأمان. لا تستخدمه لتأليف سياسة CA العامة (استخدم الوصول المشروط-mfa)، أو تصميم تسجيل الدخول الشامل لسطح مكتب Windows (استخدم windows-hello)، أو إصدار معرف تم التحقق منه (استخدم معرف التحقق من الدخول).
