在 Microsoft Entra ID 中推出万能密钥（设备绑定和同步）和 FIDO2 安全密钥作为主要的防网络钓鱼身份验证方法的指南。涵盖密钥类型（Microsoft Authenticator 中的设备绑定、通过平台提供商同步的密钥、硬件安全密钥）、条件访问身份验证强度、注册活动、临时访问通行证 (TAP) 引导、生命周期（设备丢失、证明）、需要防网络钓鱼 MFA 的条件访问、停用旧方法（短信、语音、较弱的应用推送）以及与 Windows Hello 企业版集成。时间：密钥推出、FIDO2 密钥、防网络钓鱼 MFA、Microsoft Authenticator 密钥、设备绑定密钥、同步密钥、临时访问通行证、TAP、条件访问身份验证强度、终止 SMS MFA、退出语音 MFA、无密码推出、FIDO2 证明、安全密钥注册。请勿用于一般 CA 策略创作（使用条件访问 mfa）、Windows 桌面登录设计端到端（使用 windows-hello）或验证 ID 颁发（使用 entra-verified-id）。
