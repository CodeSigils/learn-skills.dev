ASR(Azure Site Recovery)에 대한 지침 — 오케스트레이션된 장애 조치(failover)를 위해 Azure VM 및 온프레미스 머신을 보조 지역에 복제하는 서비스형 재해 복구입니다. RPO/RTO 설계, 복제 설정, 시작 순서 및 스크립트를 포함한 복구 계획, 테스트 장애 조치 규칙, 랜섬웨어 복원력을 위한 DR(ASR)과 백업(Azure Backup) 간의 분리를 다룹니다. 시기: Azure 사이트 복구, ASR, 재해 복구, DR 복제, 장애 조치, 복구 계획, 비즈니스 연속성, RPO RTO, 테스트 장애 조치, 지역 장애 조치, 랜섬웨어 복원력 DR, 쌍을 이루는 지역, 장애 조치 및 장애 복구. 특정 시점 백업/복원(Azure Backup 사용), 데이터베이스 HA/지역 복제 전용(SQL 지역 복제 사용) 또는 Azure 기울기가 없는 일반 BCDR 설계에는 사용하지 마세요.
