Conseils pour Azure Site Recovery (ASR) : reprise après sinistre en tant que service qui réplique les machines virtuelles Azure et les machines sur site vers une région secondaire pour un basculement orchestré. Couvre la conception RPO/RTO, la configuration de la réplication, les plans de récupération avec ordre de démarrage et scripts, la discipline de test de basculement et la séparation entre DR (ASR) et sauvegarde (Azure Backup) pour la résilience aux ransomwares. QUAND : Azure Site Recovery, ASR, reprise après sinistre, réplication DR, basculement, plan de récupération, continuité d'activité, RPO RTO, test de basculement, basculement régional, résilience après sinistre après sinistre, région couplée, basculement et restauration automatique. NE PAS UTILISER pour la sauvegarde/restauration à un moment donné (utilisez Azure Backup), la haute disponibilité/géo-réplication de base de données uniquement (utilisez la géo-réplication SQL) ou la conception BCDR générale sans inclinaison Azure.
