Azure Site Recovery (ASR) のガイダンス — Azure VM とオンプレミス マシンをセカンダリ リージョンにレプリケートして、フェールオーバーを調整するサービスとしてのディザスター リカバリー。 RPO / RTO の設計、レプリケーションのセットアップ、起動順序とスクリプトによる復旧計画、フェールオーバーのテスト規則、ランサムウェアの回復力を高めるための DR (ASR) とバックアップ (Azure Backup) の分離について説明します。時期: Azure Site Recovery、ASR、ディザスター リカバリー、DR レプリケーション、フェールオーバー、復旧計画、ビジネス継続性、RPO RTO、テスト フェールオーバー、リージョン フェールオーバー、ランサムウェア回復力 DR、ペアになったリージョン、フェールオーバーとフェールバック。ポイントインタイム バックアップ/復元 (Azure Backup を使用)、データベース HA/geo レプリケーションのみ (SQL geo レプリケーションを使用)、または Azure チルトを使用しない一般的な BCDR 設計には使用しないでください。
