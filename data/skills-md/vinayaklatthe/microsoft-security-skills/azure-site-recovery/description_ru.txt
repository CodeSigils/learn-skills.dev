Руководство по Azure Site Recovery (ASR) — аварийное восстановление как услуга, которая реплицирует виртуальные машины Azure и локальные компьютеры в дополнительный регион для организованного переключения при сбое. Охватывает проектирование RPO/RTO, настройку репликации, планы восстановления с порядком запуска и сценариями, дисциплину тестирования отказоустойчивости и разделение между аварийным восстановлением (ASR) и резервным копированием (Azure Backup) для обеспечения устойчивости к программам-шантажистам. КОГДА: Azure Site Recovery, ASR, аварийное восстановление, репликация аварийного восстановления, отработка отказа, план восстановления, непрерывность бизнеса, RPO RTO, тестовая отработка отказа, отработка отказа региона, устойчивость к атакам программ-шантажистов, аварийное восстановление, парный регион, отработка отказа и восстановление после сбоя. НЕ ИСПОЛЬЗУЙТЕ для резервного копирования и восстановления на определенный момент времени (используйте Azure Backup), только для обеспечения высокой доступности или георепликации базы данных (используйте георепликацию SQL) или общего дизайна BCDR без наклона Azure.
