Leitfaden für Azure Site Recovery (ASR) – Disaster-Recovery-as-a-Service, das Azure-VMs und lokale Maschinen für ein orchestriertes Failover in eine sekundäre Region repliziert. Behandelt RPO/RTO-Design, Replikationseinrichtung, Wiederherstellungspläne mit Startreihenfolge und Skripten, Test-Failover-Disziplin und die Trennung zwischen DR (ASR) und Backup (Azure Backup) für Ransomware-Resilienz. WANN: Azure Site Recovery, ASR, Notfallwiederherstellung, DR-Replikation, Failover, Wiederherstellungsplan, Geschäftskontinuität, RPO RTO, Test-Failover, Regions-Failover, Ransomware-Resilienz-DR, gepaarte Region, Failover und Failback. NICHT für Sicherungen/Wiederherstellungen zu einem bestimmten Zeitpunkt (verwenden Sie Azure Backup), nur für Datenbank-HA/Georeplikation (verwenden Sie SQL-Georeplikation) oder für allgemeines BCDR-Design ohne Azure-Neigung VERWENDEN.
