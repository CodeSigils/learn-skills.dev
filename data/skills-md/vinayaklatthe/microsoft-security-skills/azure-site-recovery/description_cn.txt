Azure 站点恢复 (ASR) 指南 — 灾难恢复即服务，将 Azure VM 和本地计算机复制到辅助区域以进行精心安排的故障转移。涵盖 RPO/RTO 设计、复制设置、具有启动顺序和脚本的恢复计划、测试故障转移规则以及灾难恢复 (ASR) 和备份（Azure 备份）之间的分离以实现勒索软件恢复能力。时间：Azure 站点恢复、ASR、灾难恢复、DR 复制、故障转移、恢复计划、业务连续性、RPO RTO、测试故障转移、区域故障转移、勒索软件弹性 DR、配对区域、故障转移和故障恢复。请勿用于时间点备份/还原（使用 Azure 备份）、仅数据库 HA/异地复制（使用 SQL 异地复制）或不带 Azure 倾斜的常规 BCDR 设计。
