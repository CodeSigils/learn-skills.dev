Azure 站台復原 (ASR) 指南 — 災難復原即服務，將 Azure VM 和本機電腦複製到輔助區域以進行精心排程的故障轉移。涵蓋 RPO/RTO 設計、複製設定、具有啟動順序和腳本的復原計劃、測試故障轉移規則以及災難復原 (ASR) 和備份（Azure 備份）之間的分離以實現勒索軟體復原能力。時間：Azure 站點復原、ASR、災難復原、DR 複製、故障轉移、復原計畫、業務連續性、RPO RTO、測試故障轉移、區域故障轉移、勒索軟體彈性 DR、配對區域、故障轉移和故障復原。請勿用於時間點備份/還原（使用 Azure 備份）、僅資料庫 HA/異地複製（使用 SQL 異地複製）或不帶 Azure 傾斜的常規 BCDR 設計。
