Guía para Azure Site Recovery (ASR): recuperación ante desastres como servicio que replica máquinas virtuales de Azure y máquinas locales en una región secundaria para una conmutación por error orquestada. Cubre el diseño de RPO/RTO, configuración de replicación, planes de recuperación con secuencias de comandos y pedidos de inicio, disciplina de conmutación por error de prueba y la separación entre DR (ASR) y copia de seguridad (Azure Backup) para la resistencia al ransomware. CUÁNDO: Azure Site Recovery, ASR, recuperación ante desastres, replicación de DR, conmutación por error, plan de recuperación, continuidad del negocio, RPO RTO, conmutación por error de prueba, conmutación por error de región, DR de resiliencia de ransomware, región emparejada, conmutación por error y conmutación por recuperación. NO LO USE para copia de seguridad/restauración en un momento determinado (use Azure Backup), HA de base de datos/replicación geográfica únicamente (use replicación geográfica de SQL) o diseño BCDR general sin una inclinación de Azure.
