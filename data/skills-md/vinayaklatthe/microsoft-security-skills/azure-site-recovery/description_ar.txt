إرشادات لاستعادة موقع Azure (ASR) — التعافي من الكوارث كخدمة تقوم بنسخ أجهزة Azure الافتراضية والأجهزة المحلية إلى منطقة ثانوية لتجاوز الفشل المنسق. يغطي تصميم RPO / RTO، وإعداد النسخ المتماثل، وخطط الاسترداد مع طلب بدء التشغيل والبرامج النصية، ونظام اختبار تجاوز الفشل، والفصل بين DR (ASR) والنسخ الاحتياطي (Azure Backup) لمرونة برامج الفدية. متى: Azure Site Recovery، ASR، التعافي من الكوارث، النسخ المتماثل لـ DR، تجاوز الفشل، خطة الاسترداد، استمرارية الأعمال، RPO RTO، تجاوز فشل الاختبار، تجاوز فشل المنطقة، مرونة برامج الفدية DR، المنطقة المقترنة، تجاوز الفشل وإعادة الفشل. لا تستخدمه للنسخ الاحتياطي/الاستعادة في نقطة زمنية محددة (استخدم النسخ الاحتياطي Azure)، أو النسخ المتماثل لقاعدة البيانات/الموقع الجغرافي فقط (استخدم النسخ المتماثل الجغرافي لـ SQL)، أو تصميم BCDR العام بدون إمالة Azure.
