إرشادات للحوسبة السرية في Azure - حماية البيانات المستخدمة من خلال بيئات التنفيذ الموثوقة القائمة على الأجهزة (TEEs). يغطي أجهزة افتراضية سرية (AMD SEV-SNP، Intel TDX)، وحاويات سرية على AKS (Kata + AMD SEV-SNP)، وأجهزة افتراضية GPU سرية (NVIDIA H100 مع TDX)، وAzure Key Vault Managed HSM وPremium مع إصدار مفتاح آمن لأحمال العمل السرية، والشهادة (خدمة Microsoft Azure Attestation)، ودفتر الأستاذ السري، والسيناريوهات (مشاركة البيانات متعددة الأطراف، عزل عبء العمل المنظم، وتدريب الذكاء الاصطناعي على البيانات الحساسة)، وسياسات إصدار المفاتيح التي تربط الأسرار بحالة TEE المعتمدة، ومعايير القرار مقابل CMK/مفتاح العميل. متى: الحوسبة السرية من Azure، AMD SEV-SNP، Intel TDX، VM السري، حاوية AKS السرية، GPU H100 السري، Azure Attestation، إصدار المفتاح الآمن، الحساب متعدد الأطراف، الذكاء الاصطناعي السري، الذاكرة المشفرة Azure، منطقة الأجهزة Azure. لا تستخدمه مع CMK العام للبيانات غير النشطة (استخدم azure-key-vault)، أو SDK لتشفير التطبيقات فقط، أو تصميم غير Azure TEE.
