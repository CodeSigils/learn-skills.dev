Руководство по конфиденциальным вычислениям Azure — защита используемых данных с помощью аппаратных доверенных сред выполнения (TEE). Охватывает конфиденциальные виртуальные машины (AMD SEV-SNP, Intel TDX), конфиденциальные контейнеры на AKS (Kata + AMD SEV-SNP), конфиденциальные виртуальные машины с графическим процессором (NVIDIA H100 с TDX), Azure Key Vault Managed HSM и Premium с безопасным выпуском ключей для конфиденциальных рабочих нагрузок, аттестацию (служба аттестации Microsoft Azure), конфиденциальный реестр, сценарии (многосторонний обмен данными, регулируемая изоляция рабочей нагрузки, обучение ИИ работе с конфиденциальными данными), политики выпуска ключей, связывающие секреты с подтвержденным состоянием TEE, а также критерии принятия решений по сравнению с CMK/ключом клиента. КОГДА: конфиденциальные вычисления Azure, AMD SEV-SNP, Intel TDX, конфиденциальная виртуальная машина, конфиденциальный контейнер AKS, конфиденциальный графический процессор H100, аттестация Azure, выпуск безопасного ключа, многосторонние вычисления, конфиденциальный искусственный интеллект, зашифрованная память Azure, аппаратный анклав Azure. НЕ ИСПОЛЬЗУЙТЕ для общих хранимых данных CMK (используйте azure-key-vault), только SDK для шифрования приложений или не-Azure TEE.
