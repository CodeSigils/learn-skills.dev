Azure Confidential Computing のガイダンス — ハードウェアベースの信頼された実行環境 (TEE) を通じて使用中のデータを保護します。機密 VM (AMD SEV-SNP、Intel TDX)、AKS 上の機密コンテナー (Kata + AMD SEV-SNP)、機密 GPU VM (TDX を搭載した NVIDIA H100)、機密ワークロードのセキュア キー解放機能を備えた Azure Key Vault マネージド HSM およびプレミアム、構成証明 (Microsoft Azure Attestation サービス)、機密台帳、シナリオ (マルチパーティ データ共有、規制されたワークロード) をカバーします。分離、機密データに関する AI トレーニング）、秘密を証明された TEE 状態に結び付けるキーリリース ポリシー、および CMK/顧客キーに対する決定基準。時期: Azure Confidential Computing、AMD SEV-SNP、Intel TDX、機密 VM、機密 AKS コンテナ、機密 GPU H100、Azure Attestation、安全なキーのリリース、マルチパーティ コンピューティング、機密 AI、暗号化メモリ Azure、ハードウェア エンクレーブ Azure。一般的な保存データ CMK (azure-key-vault を使用)、アプリケーション暗号化 SDK のみ、または Azure 以外の TEE 設計には使用しないでください。
