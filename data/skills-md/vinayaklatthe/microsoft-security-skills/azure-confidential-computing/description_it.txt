Linee guida per Azure Confidential Computing: protezione dei dati in uso tramite Trusted Execution Environments (TEE) basati su hardware. Copre VM riservate (AMD SEV-SNP, Intel TDX), contenitori riservati su AKS (Kata + AMD SEV-SNP), VM GPU riservate (NVIDIA H100 con TDX), HSM gestito di Azure Key Vault e Premium con rilascio della chiave sicura per carichi di lavoro riservati, attestazione (servizio di attestazione Microsoft Azure), registro riservato, scenari (condivisione dati tra più parti, isolamento regolamentato dei carichi di lavoro, formazione AI su dati sensibili), politiche di rilascio delle chiavi che collegano i segreti allo stato TEE attestato e criteri decisionali rispetto a CMK/chiave del cliente. QUANDO: Azure Confidential Computing, AMD SEV-SNP, Intel TDX, VM riservata, contenitore AKS riservato, GPU H100 riservata, attestazione di Azure, rilascio di chiave sicura, calcolo multi-party, intelligenza artificiale riservata, memoria crittografata Azure, enclave hardware Azure. NON UTILIZZARE per CMK dati inattivi generali (usare azure-key-vault), solo SDK di crittografia dell'applicazione o progettazione TEE non di Azure.
