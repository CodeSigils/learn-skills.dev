Leitfaden für Azure Confidential Computing – Schutz der verwendeten Daten durch hardwarebasierte Trusted Execution Environments (TEEs). Deckt vertrauliche VMs (AMD SEV-SNP, Intel TDX), vertrauliche Container auf AKS (Kata + AMD SEV-SNP), vertrauliche GPU-VMs (NVIDIA H100 mit TDX), Azure Key Vault Managed HSM und Premium mit sicherer Schlüsselfreigabe für vertrauliche Arbeitslasten, Bescheinigung (Microsoft Azure Attestation-Dienst), vertrauliches Hauptbuch, Szenarien (Mehrparteien-Datenfreigabe, regulierte Arbeitslastisolierung, KI-Training für sensible Daten), Schlüsselfreigaberichtlinien ab Verknüpfung von Geheimnissen mit dem bestätigten TEE-Status und Entscheidungskriterien im Vergleich zu CMK/Kundenschlüssel. WANN: Azure Confidential Computing, AMD SEV-SNP, Intel TDX, vertrauliche VM, vertraulicher AKS-Container, vertrauliche GPU H100, Azure Attestation, sichere Schlüsselfreigabe, Mehrparteienberechnung, vertrauliche KI, verschlüsselter Speicher Azure, Hardware-Enklave Azure. NICHT für allgemeine Data-at-Rest-CMKs (verwenden Sie Azure-Key-Vault), nur für das Anwendungsverschlüsselungs-SDK oder für Nicht-Azure-TEE-Designs verwenden.
