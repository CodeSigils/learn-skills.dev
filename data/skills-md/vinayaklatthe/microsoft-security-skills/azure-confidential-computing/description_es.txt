Guía para la informática confidencial de Azure: protección de los datos en uso a través de entornos de ejecución confiables (TEE) basados ​​en hardware. Cubre máquinas virtuales confidenciales (AMD SEV-SNP, Intel TDX), contenedores confidenciales en AKS (Kata + AMD SEV-SNP), máquinas virtuales GPU confidenciales (NVIDIA H100 con TDX), HSM administrado por Azure Key Vault y Premium con liberación segura de claves para cargas de trabajo confidenciales, atestación (servicio de atestación de Microsoft Azure), libro de contabilidad confidencial, escenarios (intercambio de datos entre varias partes, aislamiento de cargas de trabajo reguladas, capacitación de IA en datos confidenciales), políticas de liberación de claves. vincular secretos con el estado de TEE certificado y criterios de decisión frente a CMK/clave de cliente. CUÁNDO: Azure Confidential Computing, AMD SEV-SNP, Intel TDX, VM confidencial, contenedor AKS confidencial, GPU H100 confidencial, Azure Attestation, liberación de clave segura, computación multipartita, IA confidencial, memoria cifrada Azure, enclave de hardware Azure. NO LO USE para CMK de datos en reposo generales (use azure-key-vault), SDK de cifrado de aplicaciones únicamente o diseño TEE que no sea de Azure.
