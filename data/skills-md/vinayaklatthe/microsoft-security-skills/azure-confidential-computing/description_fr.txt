Conseils pour Azure Confidential Computing : protection des données utilisées via des environnements d'exécution sécurisés (TEE) basés sur le matériel. Couvre les machines virtuelles confidentielles (AMD SEV-SNP, Intel TDX), les conteneurs confidentiels sur AKS (Kata + AMD SEV-SNP), les machines virtuelles GPU confidentielles (NVIDIA H100 avec TDX), Azure Key Vault Managed HSM et Premium avec libération de clé sécurisée pour les charges de travail confidentielles, l'attestation (service d'attestation Microsoft Azure), le grand livre confidentiel, les scénarios (partage de données multipartites, isolation de charge de travail réglementée, formation IA sur les données sensibles), les politiques de libération de clé. lier les secrets à l'état TEE attesté et aux critères de décision par rapport à CMK/clé client. QUAND : Azure Confidential Computing, AMD SEV-SNP, Intel TDX, machine virtuelle confidentielle, conteneur AKS confidentiel, GPU H100 confidentiel, attestation Azure, libération de clé sécurisée, calcul multipartite, IA confidentielle, mémoire chiffrée Azure, enclave matérielle Azure. NE PAS UTILISER pour la clé CMK générale de données au repos (utilisez Azure-Key-Vault), le SDK de chiffrement d'application uniquement ou la conception TEE non Azure.
