Microsoft Entra 特权身份管理 (PIM) 指南 — Entra 角色、Azure 资源角色和特权组的即时、有时限、基于批准、经过审核的提升。涵盖合格任务与活动任务、激活控制（MFA + 批准 + 理由 + 票证）、访问审核、群组 PIM 以及删除常设访问权限。何时：特权身份管理、PIM、即时访问、有时限的角色、合格的分配、需要批准才能激活、特权角色激活、组的 PIM、访问审查特权角色、减少常设访问权限、如何删除永久管理员权限、临时管理员访问权限、管理员不应拥有常设全局管理员、Azure 角色的 JIT 访问权限、PIM 激活警报、角色激活审核。请勿用于资源访问包的权利管理（使用 entra-id-governance）或风险检测（使用 entra-id-protection）。
