Guía para Microsoft Entra Privileged Identity Management (PIM): elevación auditada, justo a tiempo, con límite de tiempo, basada en aprobación para roles de Entra, roles de recursos de Azure y grupos privilegiados. Cubre asignaciones elegibles versus activas, controles de activación (MFA + aprobación + justificación + ticket), revisiones de acceso, PIM para grupos y eliminación del acceso permanente. CUÁNDO: Gestión de identidad privilegiada, PIM, acceso justo a tiempo, función con límite de tiempo, asignación elegible, requiere aprobación para activar, activación de función privilegiada, PIM para grupos, revisión de acceso a funciones privilegiadas, reducción del acceso permanente, cómo elimino derechos de administrador permanentes, acceso de administrador temporal, los administradores no deben tener administrador global permanente, acceso JIT para funciones de Azure, alerta de activación de PIM, auditoría de activación de funciones. NO UTILIZAR para la gestión de derechos de paquetes de acceso a recursos (use entra-id-governance) o la detección de riesgos (use entra-id-protection).
