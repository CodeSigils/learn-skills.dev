Microsoft Entra 特權身分管理 (PIM) 指南 — Entra 角色、Azure 資源角色和特權群組的即時、有時限、基於批准、經過審核的提升。涵蓋合格任務與活動任務、啟動控制（MFA + 批准 + 理由 + 票證）、存取審核、群組 PIM 以及刪除常設存取權限。何時：特權身分管理、PIM、即時存取、有時限的角色、合格的分配、需要批准才能啟動、特權角色啟動、群組的 PIM、存取審查特權角色、減少常設存取權限、如何刪除永久管理員權限、臨時管理員存取權限、管理員不應擁有常設全域管理員、Azure 角色的 JIT 存取權限、PIM 啟動警報、角色啟動稽核。請勿用於資源存取包的權利管理（使用 entra-id-governance）或風險檢測（使用 entra-id-protection）。
