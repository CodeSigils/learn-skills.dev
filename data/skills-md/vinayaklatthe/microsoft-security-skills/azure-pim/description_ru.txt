Руководство по управлению привилегированными пользователями Microsoft Entra (PIM) — оперативное, ограниченное по времени, на основе утверждения и проверенное повышение прав для ролей Entra, ролей ресурсов Azure и привилегированных групп. Охватывает подходящие и активные назначения, элементы управления активацией (MFA + утверждение + обоснование + билет), проверки доступа, PIM для групп и удаление постоянного доступа. КОГДА: управление привилегированными пользователями, PIM, своевременный доступ, ограниченная по времени роль, подходящее назначение, требуется одобрение для активации, активация привилегированной роли, PIM для групп, просмотр доступа к привилегированным ролям, сокращение постоянного доступа, как удалить постоянные права администратора, временный доступ администратора, администраторы не должны иметь постоянного глобального администратора, JIT-доступ для ролей Azure, предупреждение об активации PIM, аудит активации ролей. НЕ ИСПОЛЬЗУЙТЕ для управления правами пакетов доступа к ресурсам (используйте entra-id-governance) или обнаружения рисков (используйте entra-id-protection).
