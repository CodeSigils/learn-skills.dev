Microsoft Entra PIM(Privileged Identity Management)에 대한 지침 — Entra 역할, Azure 리소스 역할 및 권한 있는 그룹에 대한 적시, 시간 제한, 승인 기반, 감사된 상승. 적격 할당과 활성 할당, 활성화 제어(MFA + 승인 + 정당성 + 티켓), 액세스 검토, 그룹용 PIM 및 고정 액세스 제거를 다룹니다. 시기: 권한 있는 ID 관리, PIM, 적시 액세스, 시간 제한 역할, 적격 할당, 활성화하려면 승인 필요, 권한 있는 역할 활성화, 그룹에 대한 PIM, 액세스 검토 권한 있는 역할, 고정 액세스 감소, 영구 관리자 권한을 제거하는 방법, 임시 관리자 액세스, 관리자는 고정 전역 관리자, Azure 역할에 대한 JIT 액세스, PIM 활성화 경고, 역할 활성화 감사를 가져서는 안 됩니다. 리소스 액세스 패키지의 자격 관리(entra-id-governance 사용) 또는 위험 감지(entra-id-protection 사용)에는 사용하지 마십시오.
