Microsoft Defender for Endpoint (MDE) 指南 — 具有下一代 AV、EDR、攻击面减少 (ASR)、Defender 漏洞管理、自动调查和修复 (AIR) 以及实时响应的企业端点安全。涵盖计划 1 与计划 2 选择、加入路径（Intune、Configuration Manager、GPO、脚本）、审核→阻止中的 ASR 规则推出、阻止模式下的 EDR、篡改保护、设备组和 RBAC 以及响应操作（隔离、限制、实时响应）。何时：Defender for Endpoint、MDE、MDE 加入、端点 EDR、攻击面减少规则、ASR 规则审核模式、下一代防病毒策略、设备隔离、端点漏洞管理、EDR 阻止模式、篡改保护、Defender 板载设备、实时响应、MDE 计划 1 与计划 2、安全设置管理、适用于 Linux 的 MDE、适用于 macOS 的 MDE、受控文件夹访问。请勿用于非端点 Defender 工作负载（对跨工作负载使用 Defender-xdr，对 Azure 资源使用 Defender-for-cloud-hardening）。
