Microsoft Defender for Endpoint (MDE) 指南 — 具有新一代 AV、EDR、攻擊面減少 (ASR)、Defender 漏洞管理、自動調查和修復 (AIR) 以及即時回應的企業端點安全性。涵蓋計劃 1 與計劃 2 選擇、加入路徑（Intune、Configuration Manager、GPO、腳本）、審核→阻止中的 ASR 規則推出、阻止模式下的 EDR、篡改保護、設備群組和 RBAC 以及回應操作（隔離、限制、即時回應）。何時：Defender for Endpoint、MDE、MDE 加入、端點 EDR、攻擊面減少規則、ASR 規則審核模式、下一代防毒策略、設備隔離、端點漏洞管理、EDR 阻止模式、篡改保護、Defender 板載設備、實時響應、MDE 計劃 1 與計劃 2、安全設定管理、受控適用於 Linux 的 MDE、實時響應請勿用於非端點 Defender 工作負載（對跨工作負載使用 Defender-xdr，對 Azure 資源使用 Defender-for-cloud-hardening）。
