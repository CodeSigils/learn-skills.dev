Leitfaden für die sichere Remote-VM-Verwaltung in Azure mithilfe von Azure Bastion in Kombination mit dem Just-in-Time-VM-Zugriff (JIT) von Defender für Cloud. Deckt die Bastion-SKU-Auswahl (Entwickler/Basic/Standard/Premium), IP-basierte und gemeinsam nutzbare Linkverbindungen, nativen Client (RDP/SSH vom lokalen Computer über eine z-CLI), Sitzungsaufzeichnung (Premium), rein private Bereitstellung, JIT-Anfrageworkflow und -richtlinie, RBAC für Verbindungsvorgänge, Integration mit bedingtem Zugriff (über Bastion + Entra-Anmeldung auf der VM), Azure Policy-Durchsetzung, um Bastion + JIT zu erfordern und öffentliche IP auf VMs zu verbieten, und Migration von VPN/Jump-Box-Mustern ab. WANN: Azure Bastion-Design, Bastion-SKU-Vergleich, JIT-VM-Zugriff, Just-in-Time-Zugriff auf Azure, gemeinsam nutzbarer Bastion-Link, nativer Client-Bastion, Sitzungsaufzeichnung Bastion, Eliminierung öffentlicher IP-Adressen auf VMs, Ersatz des Jump-Hosts durch Bastion, sicheres RDP SSH Azure, Bastion Premium-Aufzeichnung. NICHT für Hybrid-/SD-WAN-VPN-Design, GSA Private Access (verwenden Sie entra-global-secure-access) oder Cluster-only-K8s-Zugriff verwenden.
