Conseils pour la gestion sécurisée des machines virtuelles à distance dans Azure à l’aide d’Azure Bastion combiné à l’accès juste à temps (JIT) aux machines virtuelles Defender pour Cloud. Couvre la sélection du SKU Bastion (Développeur/Basique/Standard/Premium), les connexions basées sur IP et à lien partageable, le client natif (RDP/SSH depuis une machine locale via az CLI), l'enregistrement de session (Premium), le déploiement privé uniquement, le flux de travail et la politique de demande JIT, le RBAC pour les opérations de connexion, l'intégration avec l'accès conditionnel (via la connexion Bastion + Entra sur la VM), l'application de la politique Azure pour exiger Bastion + JIT et interdire l'IP publique sur les VM, et la migration hors des modèles VPN/jump-box. QUAND : conception Azure Bastion, comparaison des SKU Bastion, accès aux VM JIT, accès juste à temps Azure, lien partageable Bastion, client natif Bastion, enregistrement de session Bastion, élimination des adresses IP publiques sur les machines virtuelles, remplacement de l'hôte de saut par Bastion, RDP SSH Azure sécurisé, enregistrement Bastion Premium. NE PAS UTILISER pour une conception VPN hybride/SD-WAN, un accès privé GSA (utilisez entra-global-secure-access) ou un accès K8 en cluster uniquement.
