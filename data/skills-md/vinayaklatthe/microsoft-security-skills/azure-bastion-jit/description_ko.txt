Defender for Cloud JIT(Just-In-Time) VM 액세스와 결합된 Azure Bastion을 사용하여 Azure에서 안전한 원격 VM 관리에 대한 지침입니다. Bastion SKU 선택(개발자/기본/표준/프리미엄), IP 기반 및 공유 가능 링크 연결, 기본 클라이언트(az CLI를 통해 로컬 컴퓨터의 RDP/SSH), 세션 기록(프리미엄), 프라이빗 전용 배포, JIT 요청 워크플로 및 정책, 연결 작업을 위한 RBAC, 조건부 액세스와의 통합(VM에서 Bastion + Entra 로그인을 통해), Bastion + JIT를 요구하고 VM에서 공용 IP를 금지하는 Azure Policy 적용, 마이그레이션 해제를 다룹니다. VPN/점프박스 패턴. 시기: Azure Bastion 설계, Bastion SKU 비교, JIT VM 액세스, 적시 액세스 Azure, Bastion 공유 가능 링크, 기본 클라이언트 Bastion, 세션 기록 Bastion, VM에서 공용 IP 제거, 점프 호스트를 Bastion으로 교체, 보안 RDP SSH Azure, Bastion Premium 녹화. 하이브리드/SD-WAN VPN 설계, GSA 비공개 액세스(전역 보안 액세스 사용) 또는 클러스터 전용 K8s 액세스에는 사용하지 마세요.
