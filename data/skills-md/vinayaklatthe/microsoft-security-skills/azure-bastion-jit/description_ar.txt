إرشادات لإدارة الأجهزة الافتراضية الآمنة عن بعد في Azure باستخدام Azure Bastion مع إمكانية الوصول إلى الأجهزة الافتراضية (VM) في الوقت المناسب (JIT) لـ Defender for Cloud. يغطي اختيار Bastion SKU (المطور / الأساسي / القياسي / المميز)، واتصالات الارتباط القائمة على IP والقابلة للمشاركة، والعميل الأصلي (RDP/SSH من الجهاز المحلي عبر az CLI)، وتسجيل الجلسة (Premium)، والنشر الخاص فقط، وسير عمل وسياسة طلب JIT، وRBAC لعمليات الاتصال، والتكامل مع الوصول المشروط (عبر تسجيل الدخول Bastion + Entra على الجهاز الظاهري)، وإنفاذ سياسة Azure للمطالبة Bastion + JIT وحظر IP العام على الأجهزة الافتراضية، وإيقاف الترحيل أنماط VPN/صندوق القفز. متى: تصميم Azure Bastion، مقارنة Bastion SKU، الوصول إلى JIT VM، الوصول في الوقت المناسب إلى Azure، رابط Bastion القابل للمشاركة، العميل الأصلي Bastion، تسجيل الجلسة Bastion، إزالة IP العام على الأجهزة الافتراضية، استبدال Jump Host بـ Bastion، تأمين RDP SSH Azure، تسجيل Bastion Premium. لا تستخدمه لتصميم VPN المختلط/SD-WAN، أو الوصول الخاص لـ GSA (استخدم الوصول الآمن العالمي)، أو الوصول إلى K8 للمجموعة فقط.
