Orientación para la administración remota segura de máquinas virtuales en Azure mediante Azure Bastion combinado con el acceso a máquinas virtuales justo a tiempo (JIT) de Defender for Cloud. Cubre la selección de SKU de Bastion (Desarrollador/Básico/Estándar/Premium), conexiones basadas en IP y de enlaces compartibles, cliente nativo (RDP/SSH desde una máquina local a través de az CLI), grabación de sesiones (Premium), implementación solo privada, política y flujo de trabajo de solicitud JIT, RBAC para operaciones de conexión, integración con acceso condicional (a través de Bastion + inicio de sesión de Entra en la VM), aplicación de Azure Policy para requerir Bastion + JIT y prohibir la IP pública en las VM, y migración fuera de patrones de VPN/jump-box. CUÁNDO: diseño de Azure Bastion, comparación de SKU de Bastion, acceso JIT a VM, acceso justo a tiempo a Azure, enlace compartible de Bastion, cliente nativo Bastion, grabación de sesiones de Bastion, eliminar IP pública en VM, reemplazar jump host con Bastion, proteger RDP SSH Azure, grabación de Bastion Premium. NO LO USE para diseño de VPN híbrida/SD-WAN, acceso privado GSA (use acceso entra-global-secure) o acceso K8 solo en clúster.
