Руководство по безопасному удаленному управлению виртуальными машинами в Azure с помощью Azure Bastion в сочетании с JIT-доступом к виртуальным машинам в Защитнике для облака. Охватывает выбор SKU Bastion (для разработчиков / Basic / Standard / Premium), подключения на основе IP и по общим ссылкам, собственный клиент (RDP/SSH с локального компьютера через az CLI), запись сеанса (Premium), частное развертывание, рабочий процесс и политику JIT-запросов, RBAC для операций подключения, интеграцию с условным доступом (через вход Bastion + Entra на виртуальной машине), применение политики Azure для требования Bastion + JIT и запрета публичного IP-адреса на виртуальных машинах, а также миграцию. Шаблоны VPN/джампбокса. КОГДА: проектирование Azure Bastion, сравнение SKU Bastion, JIT-доступ к виртуальной машине, своевременный доступ к Azure, общая ссылка Bastion, собственный клиент Bastion, запись сеанса Bastion, исключение общедоступных IP-адресов на виртуальных машинах, замена узла перехода на Bastion, безопасный RDP SSH Azure, запись Bastion Premium. НЕ ИСПОЛЬЗУЙТЕ для гибридного/SD-WAN VPN, частного доступа GSA (используйте внутриглобальный безопасный доступ) или доступа K8s только для кластера.
