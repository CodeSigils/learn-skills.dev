Linee guida per la gestione sicura delle VM remote in Azure usando Azure Bastion combinato con l'accesso alle VM just-in-time (JIT) di Defender for Cloud. Copre la selezione dello SKU Bastion (sviluppatore/base/standard/premium), connessioni basate su IP e con collegamento condivisibile, client nativo (RDP/SSH dal computer locale tramite az CLI), registrazione della sessione (Premium), distribuzione solo privata, flusso di lavoro e criteri di richiesta JIT, RBAC per operazioni di connessione, integrazione con accesso condizionale (tramite accesso Bastion + Entra sulla VM), applicazione di criteri di Azure per richiedere Bastion + JIT e vietare l'IP pubblico sulle macchine virtuali e migrazione da modelli VPN/jump-box. QUANDO: progettazione Azure Bastion, confronto SKU Bastion, accesso JIT alle VM, accesso just-in-time Azure, collegamento condivisibile Bastion, client nativo Bastion, registrazione sessioni Bastion, eliminazione IP pubblico sulle VM, sostituzione host jump con Bastion, protezione RDP SSH Azure, registrazione Bastion Premium. NON UTILIZZARE per la progettazione VPN ibrida/SD-WAN, l'accesso privato GSA (utilizzare entra-global-secure-access) o l'accesso K8 solo cluster.
