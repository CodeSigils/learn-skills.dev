Microsoft Entra 驗證 ID 指南 — 基於開放標準（W3C 可驗證憑證、DID、OpenID4VC）的可驗證憑證核發與驗證平台。涵蓋發行者設定（租戶配置、DID 註冊、Key Vault 中的簽名密鑰）、憑證架構設計、規則和顯示文件、發行流程（QR/深層鏈接）、驗證流程、面部檢查生物識別匹配、與 Entra ID 集成以實現員工入職和訪問、與驗證合作夥伴集成以及用例（員工驗證、遠程入職、低摩擦帳戶驗證、供應商/承包商身份驗證）。時間：Entra 驗證 ID、可驗證憑證、去中心化身分、DID 發行、頒發憑證 Entra、驗證憑證、臉部檢查、遠端入職身分證明、使用 VC 復原帳戶、承包商身分驗證、供應商驗證、員工入職 VC。請勿用於 B2C/CIAM（使用 entra-external-id）、員工身分管理（使用 entra-id）或 PKI/憑證設計（使用 pki-design）。
