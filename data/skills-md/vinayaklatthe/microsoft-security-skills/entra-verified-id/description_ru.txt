Руководство для Microsoft Entra Verified ID — проверяемая платформа выдачи и проверки учетных данных на основе открытых стандартов (W3C Verifying Credentials, DID, OpenID4VC). Охватывает настройку эмитента (конфигурацию клиента, регистрацию DID, ключ подписи в Key Vault), разработку схемы учетных данных, правила и файлы отображения, потоки выдачи (QR/глубокая ссылка), потоки проверки, биометрическое сопоставление Face Check, интеграцию с Entra ID для адаптации и доступа сотрудников, интеграцию с партнерами по проверке и варианты использования (проверка сотрудников, удаленная адаптация, простое восстановление учетной записи, проверка личности поставщика/подрядчика). КОГДА: Entra проверенный идентификатор, проверяемые учетные данные, децентрализованная идентификация, выдача DID, выдача учетных данных Entra, проверка учетных данных, проверка лица, удаленное подтверждение личности, восстановление учетной записи с помощью VC, проверка личности подрядчика, проверка поставщика, адаптация персонала к VC. НЕ ИСПОЛЬЗУЙТЕ для B2C/CIAM (используйте entra-external-id), администратора удостоверений рабочей силы (используйте entra-id) или разработки PKI/сертификатов (используйте pki-design).
