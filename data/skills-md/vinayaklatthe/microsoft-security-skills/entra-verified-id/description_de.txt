Leitfaden für Microsoft Entra Verified ID – eine Plattform zur Ausstellung und Verifizierung verifizierbarer Anmeldeinformationen, die auf offenen Standards basiert (W3C Verifiable Credentials, DIDs, OpenID4VC). Behandelt die Einrichtung des Ausstellers (Mandantenkonfiguration, DID-Registrierung, Signaturschlüssel im Key Vault), das Design des Anmeldeinformationsschemas, Regeln und Anzeigedateien, Ausstellungsabläufe (QR/Deep Link), Verifizierungsabläufe, biometrischen Abgleich mit Gesichtsprüfung, Integration mit Entra ID für Mitarbeiter-Onboarding und -Zugriff, Integration mit Verifizierungspartnern und Anwendungsfälle (Mitarbeiterüberprüfung, Remote-Onboarding, reibungslose Kontowiederherstellung, Identitätsprüfung von Anbietern/Auftragnehmern). WANN: Entra-verifizierter Ausweis, überprüfbare Anmeldeinformationen, dezentrale Identität, DID-Ausstellung, Entra-Anmeldeinformationen ausstellen, Anmeldeinformationen überprüfen, Gesichtsprüfung, Remote-Onboarding-Identitätsprüfung, Kontowiederherstellung mit VC, Überprüfung der Auftragnehmeridentität, Lieferantenüberprüfung, Mitarbeiter-Onboarding VC. NICHT für B2C/CIAM (entra-external-id verwenden), Workforce Identity Admin (entra-id verwenden) oder PKI/Zertifikatdesign (pki-design verwenden) verwenden.
