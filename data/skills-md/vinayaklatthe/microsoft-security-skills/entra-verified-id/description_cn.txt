Microsoft Entra 验证 ID 指南 — 基于开放标准（W3C 可验证凭据、DID、OpenID4VC）的可验证凭据颁发和验证平台。涵盖发行者设置（租户配置、DID 注册、Key Vault 中的签名密钥）、凭证架构设计、规则和显示文件、发行流程（QR/深层链接）、验证流程、面部检查生物识别匹配、与 Entra ID 集成以实现员工入职和访问、与验证合作伙伴集成以及用例（员工验证、远程入职、低摩擦帐户恢复、供应商/承包商身份验证）。时间：Entra 验证 ID、可验证凭证、去中心化身份、DID 发行、颁发凭证 Entra、验证凭证、面部检查、远程入职身份证明、使用 VC 恢复帐户、承包商身份验证、供应商验证、员工入职 VC。请勿用于 B2C/CIAM（使用 entra-external-id）、员工身份管理（使用 entra-id）或 PKI/证书设计（使用 pki-design）。
