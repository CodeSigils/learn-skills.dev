Orientación para la plataforma de operaciones de seguridad unificada de Microsoft que reúne Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence y Microsoft Security Exposure Management en el portal de Microsoft Defender. Cubre los requisitos previos, la incorporación de Sentinel, la cola de incidentes unificada, la búsqueda avanzada en SIEM+XDR y RBAC. CUÁNDO: SecOps unificadas, integración del portal de Sentinel a Defender, panel de SOC único, cola de incidentes unificada, conectar el espacio de trabajo de Sentinel a Defender XDR, administración de exposición, portal unificado, fusionar Sentinel y Defender XDR, reducir el cambio de contexto para los analistas, panel único, salir del portal de Azure Sentinel. NO LO USE para el diseño de espacios de trabajo exclusivo de Sentinel (use sentinel) o para la investigación de incidentes exclusivo de Defender XDR (use defender-xdr).
