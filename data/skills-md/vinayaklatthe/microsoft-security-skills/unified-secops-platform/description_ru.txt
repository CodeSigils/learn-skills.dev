Руководство по единой платформе управления безопасностью Microsoft, которая объединяет Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence и Microsoft Security Exposure Management на портале Microsoft Defender. Охватывает предварительные требования, подключение Sentinel, единую очередь инцидентов, расширенный поиск в SIEM+XDR и RBAC. КОГДА: унифицированный отдел безопасности, встроенный портал Sentinel в Defender, единая панель SOC, унифицированная очередь инцидентов, подключение рабочего пространства Sentinel к Defender XDR, управление рисками, единый портал, объединение Sentinel и Defender XDR, сокращение переключений контекста для аналитиков, единая панель управления, отказ от портала Azure Sentinel. НЕ ИСПОЛЬЗУЙТЕ для проектирования рабочего пространства только для Sentinel (используйте Sentinel) или для расследования инцидентов только с помощью Defender XDR (используйте defender-xdr).
