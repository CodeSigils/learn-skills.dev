Microsoft 统一安全操作平台指南，该平台将 Microsoft Sentinel、Microsoft Defender XDR、Security Copilot、威胁情报和 Microsoft 安全暴露管理整合到 Microsoft Defender 门户中。涵盖先决条件、Sentinel 加入、统一事件队列、跨 SIEM+XDR 的高级搜索和 RBAC。何时：统一 SecOps、板载 Sentinel 到 Defender 门户、单一 SOC 管理平台、统一事件队列、将 Sentinel 工作区连接到 Defender XDR、暴露管理、统一门户、合并 Sentinel 和 Defender XDR、减少分析师的上下文切换、单一管理平台、移出 Azure Sentinel 门户。请勿用于仅限 Sentinel 的工作区设计（使用 Sentinel）或仅限 Defender XDR 的事件调查（使用 Defender-xdr）。
