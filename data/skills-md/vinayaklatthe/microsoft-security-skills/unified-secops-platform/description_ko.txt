Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence 및 Microsoft Security Exposure Management를 Microsoft Defender 포털에 함께 제공하는 Microsoft 통합 보안 운영 플랫폼에 대한 지침입니다. 전제 조건, Sentinel 온보딩, 통합 인시던트 대기열, SIEM+XDR 전반의 고급 헌팅 및 RBAC를 다룹니다. 시기: 통합 SecOps, Sentinel을 Defender 포털에 온보드, 단일 SOC 창, 통합 인시던트 큐, Sentinel 작업 영역을 Defender XDR에 연결, 노출 관리, 통합 포털, Sentinel 및 Defender XDR 병합, 분석가를 위한 컨텍스트 전환 감소, 단일 창, Azure Sentinel 포털에서 이동. Sentinel 전용 작업 공간 디자인(sentinel 사용) 또는 Defender XDR 전용 사고 조사(defender-xdr 사용)에는 사용하지 마세요.
