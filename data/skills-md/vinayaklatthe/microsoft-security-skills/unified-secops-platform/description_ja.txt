Microsoft Sentinel、Microsoft Defender XDR、Security Copilot、Threat Intelligence、および Microsoft Security Exposure Management を Microsoft Defender ポータルに統合する Microsoft 統合セキュリティ運用プラットフォームのガイダンス。前提条件、Sentinel のオンボーディング、統合インシデント キュー、SIEM+XDR 全体の高度なハンティング、RBAC について説明します。時期: 統合 SecOps、Sentinel を Defender ポータルにオンボード、単一 SOC ペイン、統合インシデント キュー、Sentinel ワークスペースを Defender XDR に接続、エクスポージャー管理、統合ポータル、Sentinel と Defender XDR をマージ、アナリストのコンテキスト切り替えを削減、単一ペイン、Azure Sentinel ポータルから移行。 Sentinel のみのワークスペース設計 (sentinel を使用) または Defender XDR のみのインシデント調査 (defender-xdr を使用) には使用しないでください。
