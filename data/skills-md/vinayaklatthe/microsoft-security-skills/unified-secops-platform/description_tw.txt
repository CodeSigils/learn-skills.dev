Microsoft 統一安全操作平台指南，該平台將 Microsoft Sentinel、Microsoft Defender XDR、Security Copilot、威脅情報和 Microsoft 安全性暴露管理整合到 Microsoft Defender 入口網站中。涵蓋先決條件、Sentinel 加入、統一事件佇列、跨 SIEM+XDR 的進階搜尋和 RBAC。何時：統一 SecOps、板載 Sentinel 到 Defender 入口網站、單一 SOC 管理平台、統一事件佇列、將 Sentinel 工作區連接到 Defender XDR、暴露管理、統一入口網站、合併 Sentinel 和 Defender XDR、減少分析師的上下文切換、單一管理平台、移出 Azure Sentinel 入口網站。請勿用於僅限 Sentinel 的工作區設計（使用 Sentinel）或僅限 Defender XDR 的事件調查（使用 Defender-xdr）。
