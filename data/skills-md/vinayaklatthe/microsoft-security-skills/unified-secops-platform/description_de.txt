Leitfaden für die einheitliche Sicherheitsbetriebsplattform von Microsoft, die Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence und Microsoft Security Exposure Management im Microsoft Defender-Portal zusammenführt. Deckt Voraussetzungen, Onboarding von Sentinel, einheitliche Vorfallwarteschlange, erweiterte Suche über SIEM+XDR und RBAC ab. WANN: einheitliches SecOps, integriertes Sentinel-zu-Defender-Portal, einzelne SOC-Glasscheibe, einheitliche Vorfallwarteschlange, Sentinel-Arbeitsbereich mit Defender XDR verbinden, Gefährdungsmanagement, einheitliches Portal, Sentinel und Defender NICHT für die reine Sentinel-Arbeitsbereichsgestaltung (verwenden Sie Sentinel) oder die ausschließliche Untersuchung von Vorfällen mit Defender XDR (verwenden Sie Defender-xdr) verwenden.
