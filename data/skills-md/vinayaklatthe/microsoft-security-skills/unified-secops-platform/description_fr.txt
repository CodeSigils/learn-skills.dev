Conseils pour la plateforme d’opérations de sécurité unifiée Microsoft qui rassemble Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence et Microsoft Security Exposure Management dans le portail Microsoft Defender. Couvre les conditions préalables, l'intégration de Sentinel, la file d'attente d'incidents unifiée, la recherche avancée sur SIEM+XDR et RBAC. QUAND : SecOps unifié, portail Sentinel vers Defender intégré, panneau de contrôle SOC unique, file d'attente d'incidents unifiée, connexion de l'espace de travail Sentinel à Defender XDR, gestion de l'exposition, portail unifié, fusion de Sentinel et Defender XDR, réduction du changement de contexte pour les analystes, panneau de contrôle unique, quitter le portail Azure Sentinel. NE PAS UTILISER pour la conception d’un espace de travail Sentinel uniquement (utilisez Sentinel) ou pour une enquête sur les incidents Defender XDR uniquement (utilisez Defender-xdr).
