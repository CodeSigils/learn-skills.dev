Linee guida per la piattaforma operativa di sicurezza unificata Microsoft che riunisce Microsoft Sentinel, Microsoft Defender XDR, Security Copilot, Threat Intelligence e Microsoft Security Exposure Management nel portale Microsoft Defender. Copre i prerequisiti, l'onboarding di Sentinel, la coda unificata degli incidenti, la ricerca avanzata su SIEM+XDR e RBAC. QUANDO: SecOps unificati, portale Sentinel integrato nel portale Defender, riquadro SOC singolo, coda incidenti unificata, connessione dell'area di lavoro Sentinel a Defender XDR, gestione dell'esposizione, portale unificato, unione di Sentinel e Defender XDR, riduzione del cambio di contesto per gli analisti, riquadro singolo, uscita dal portale Azure Sentinel. NON UTILIZZARE per la progettazione dell'area di lavoro solo Sentinel (utilizzare Sentinel) o l'indagine sugli incidenti solo per Defender XDR (utilizzare Defender-xdr).
