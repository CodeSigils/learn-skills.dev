Leitfaden für den Azure DDoS-Schutz – Netzwerkschutz- (pro VNet) und IP-Schutzebenen (pro öffentliche IP), die auf derselben ständig verfügbaren Microsoft-Plattform basieren. Umfasst die Auswahl der Stufen im Vergleich zum kostenlosen Basis-Infrastrukturschutz, den Umfang (VNet vs. einzelne IP), die automatische Abstimmung von Verkehrsprofilen und Abschwächungsrichtlinien, Angriffsanalysen und -metriken, Angriffswarnungen an Sentinel, DDoS Rapid Response-Engagement, Integration mit Azure WAF und Front Door, Kostenschutzgarantie, Abschwächungsberichte für Compliance und Kapazitätsplanung pro Region. WANN: Azure DDoS-Schutz, DDoS-Netzwerkschutz, DDoS-IP-Schutz, Layer 3/4 DDoS, Angriffsanalyse Azure, schnelle DDoS-Reaktion, Kostenschutz DDoS, DDoS-Metriken, Schadensminderungsbericht, DDoS-Simulation Azure. NICHT allein zur Angriffsabwehr auf Ebene 7/App-Ebene (Azure-WAF verwenden), Azure Firewall-Design (Azure-Firewall verwenden) oder hybrides Netzwerk-DDoS über lokale Appliances verwenden.
