Guía para Azure DDoS Protection: niveles de protección de red (por VNet) y protección IP (por IP pública) creados en la misma plataforma Microsoft siempre activa. Cubre la selección de niveles frente a la protección de la infraestructura básica gratuita, el alcance (VNet frente a una IP única), perfiles de tráfico y ajuste automático de políticas de mitigación, análisis y métricas de ataques, alertas de ataques a Sentinel, participación de respuesta rápida DDoS, integración con Azure WAF y Front Door, garantía de protección de costos, informes de mitigación para el cumplimiento y planificación de capacidad por región. CUÁNDO: Azure DDoS Protection, DDoS Network Protection, DDoS IP Protection, capa 3/4 DDoS, análisis de ataques Azure, respuesta rápida DDoS, protección de costos DDoS, métricas DDoS, informe de mitigación, simulación de DDoS Azure.
