إرشادات لحماية Azure DDoS - طبقات حماية الشبكة (لكل شبكة VNet) وحماية IP (لكل IP عام) المبنية على نفس نظام Microsoft الأساسي الذي يعمل دائمًا. يغطي اختيار الطبقة مقابل حماية البنية التحتية الأساسية المجانية، والنطاق (VNet مقابل IP الفردي)، وملفات تعريف حركة المرور والضبط التلقائي لسياسة التخفيف، وتحليلات ومقاييس الهجوم، وتنبيهات الهجوم إلى Sentinel، ومشاركة الاستجابة السريعة لـ DDoS، والتكامل مع Azure WAF وFront Door، وضمان حماية التكلفة، وتقارير التخفيف للامتثال، وتخطيط السعة لكل منطقة. متى: حماية Azure DDoS، حماية شبكة DDoS، حماية DDoS IP، طبقة 3/4 DDoS، تحليلات الهجوم Azure، الاستجابة السريعة لـ DDoS، حماية التكلفة DDoS، مقاييس DDoS، تقرير التخفيف، محاكاة DDoS Azure. لا تستخدمه لتخفيف هجمات الطبقة 7 / طبقة التطبيق فقط (استخدم azure-waf)، أو تصميم Azure Firewall (استخدم جدار الحماية azure)، أو DDoS للشبكة المختلطة عبر الأجهزة المحلية.
