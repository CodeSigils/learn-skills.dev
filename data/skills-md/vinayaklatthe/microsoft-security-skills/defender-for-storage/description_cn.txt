Microsoft Defender for Storage 指南 — Azure 存储帐户（Blob、文件、Data Lake Gen2）的威胁保护。涵盖 v2（每个存储帐户）计划、由 Defender Antivirus 提供支持的上传恶意软件扫描、敏感数据威胁检测（与 Purview 分类集成）、基于活动的威胁检测、覆盖每个存储帐户、排除大容量帐户、针对扫描结果的事件网格集成以及成本控制（每 GB 扫描上限）。时间：Defender for Storage、Azure 存储恶意软件扫描、Blob 恶意软件扫描、敏感数据威胁检测、上传扫描、Defender for Storage v2、存储帐户威胁防护、扫描结果事件网格、Purview 分类存储、恶意 Blob 上传、渗漏警报存储、不受信任的上传扫描。请勿用于 SQL/Cosmos DB 保护（使用 Defender-for-cloud-hardening）、VM 磁盘恶意软件（使用 Defender-for-servers 无代理扫描）或 M365 SharePoint/OneDrive（使用 Defender-for-office-365）。
