Leitfaden für Microsoft Defender for Storage – Bedrohungsschutz für Azure Storage-Konten (Blob, Dateien, Data Lake Gen2). Deckt den v2-Plan (pro Speicherkonto), On-Upload-Malware-Scans mit Defender Antivirus, Erkennung sensibler Datenbedrohungen (integriert in die Purview-Klassifizierung), aktivitätsbasierte Bedrohungserkennung, Außerkraftsetzung pro Speicherkonto, Ausschluss von Konten mit hohem Volumen, Event Grid-Integration für Scanergebnisse und Kostenkontrollen (Scan-Obergrenze pro GB) ab. WANN: Defender für Storage, Azure Storage-Malware-Scan, Blob-Malware-Scan, Bedrohungserkennung für sensible Daten, On-Upload-Scan, Defender für Storage v2, Bedrohungsschutz für Speicherkonten, Event Grid für Scanergebnisse, Purview-Klassifizierungsspeicher, Upload bösartiger Blobs, Speicherung von Exfiltrationswarnungen, Scan auf nicht vertrauenswürdige Uploads. NICHT VERWENDEN für SQL/Cosmos DB-Schutz (verwenden Sie Defender-for-Cloud-Hardening), VM-Festplatten-Malware (verwenden Sie Defender-for-Servers, agentenlosen Scan) oder M365 SharePoint/OneDrive (verwenden Sie Defender-for-Office-365).
