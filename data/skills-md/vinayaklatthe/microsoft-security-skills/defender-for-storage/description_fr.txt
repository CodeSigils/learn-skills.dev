Conseils pour Microsoft Defender pour le stockage : protection contre les menaces pour les comptes de stockage Azure (Blob, Fichiers, Data Lake Gen2). Couvre le plan v2 (par compte de stockage), l'analyse des logiciels malveillants lors du téléchargement optimisée par Defender Antivirus, la détection des menaces liées aux données sensibles (intégrée à la classification Purview), la détection des menaces basée sur l'activité, le remplacement par compte de stockage, l'exclusion des comptes à volume élevé, l'intégration d'Event Grid pour les résultats d'analyse et le contrôle des coûts (plafond d'analyse par Go). QUAND : Defender pour le stockage, analyse des logiciels malveillants du stockage Azure, analyse des logiciels malveillants Blob, détection des menaces liées aux données sensibles, analyse lors du téléchargement, Defender pour Storage v2, protection contre les menaces du compte de stockage, grille d'événements des résultats de l'analyse, stockage de classification Purview, téléchargement de blob malveillants, stockage des alertes d'exfiltration, analyse de téléchargement non fiable. NE PAS UTILISER pour la protection SQL/Cosmos DB (utilisez Defender-for-Cloud-hardening), les logiciels malveillants de disque de machine virtuelle (utilisez l'analyse sans agent Defender-for-servers) ou M365 SharePoint/OneDrive (utilisez Defender-for-Office-365).
