Microsoft Defender for Storage のガイダンス — Azure ストレージ アカウント (Blob、ファイル、Data Lake Gen2) の脅威保護。 v2 (ストレージ アカウントごと) プラン、Defender Antivirus を利用したアップロード時のマルウェア スキャン、機密データの脅威検出 (Purview 分類と統合)、アクティビティ ベースの脅威検出、ストレージ アカウントごとのオーバーライド、大容量アカウントの除外、スキャン結果の Event Grid 統合、およびコスト制御 (GB ごとのスキャン キャップ) をカバーします。時期: Defender for Storage、Azure Storage マルウェア スキャン、BLOB マルウェア スキャン、機密データの脅威検出、アップロード時スキャン、Defender for Storage v2、ストレージ アカウントの脅威保護、スキャン結果 Event Grid、Purview 分類ストレージ、悪意のある BLOB アップロード、漏洩アラート ストレージ、信頼できないアップロード スキャン。 SQL/Cosmos DB 保護 (defender-for-cloud-hardening を使用)、VM ディスク マルウェア (defender-for-servers エージェントレス スキャンを使用)、または M365 SharePoint/OneDrive (defender-for-office-365 を使用) には使用しないでください。
