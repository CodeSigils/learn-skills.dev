Microsoft Defender for Storage 指南 — Azure 儲存體帳戶（Blob、檔案、Data Lake Gen2）的威脅保護。涵蓋 v2（每個儲存帳戶）計劃、由 Defender Antivirus 提供支援的上傳惡意軟體掃描、敏感資料威脅偵測（與 Purview 分類整合）、基於活動的威脅偵測、覆蓋每個儲存帳戶、排除大容量帳戶、針對掃描結果的事件網格整合以及成本控制（每 GB 掃描上限）。時間：Defender for Storage、Azure 儲存惡意軟體掃描、Blob 惡意軟體掃描、敏感資料威脅偵測、上傳掃描、Defender for Storage v2、儲存帳號威脅防護、掃描結果事件網格、Purview 分類儲存、惡意 Blob 上傳、滲漏警報儲存、不受信任的上傳掃描。請勿用於 SQL/Cosmos DB 保護（使用 Defender-for-cloud-hardening）、VM 磁碟惡意軟體（使用 Defender-for-servers 無代理掃描）或 M365 SharePoint/OneDrive（使用 Defender-for-office-365）。
