Руководство по Microsoft Defender для хранилища — защита от угроз для учетных записей хранения Azure (Blob, файлы, Data Lake Gen2). Охватывает план v2 (для каждой учетной записи хранения), сканирование вредоносных программ при загрузке с помощью антивирусной программы Defender, обнаружение угроз для конфиденциальных данных (интегрировано с классификацией Purview), обнаружение угроз на основе активности, переопределение для каждой учетной записи хранения, исключение учетных записей большого объема, интеграцию с сеткой событий для результатов сканирования и контроль затрат (ограничение сканирования на каждый ГБ). КОГДА: Защитник для хранилища, сканирование вредоносных программ в хранилище Azure, сканирование вредоносных программ Blob, обнаружение угроз для конфиденциальных данных, сканирование при загрузке, Защитник для хранилища v2, защита от угроз учетной записи хранения, результаты сканирования. Сетка событий, хранилище классификации Purview, загрузка вредоносных больших двоичных объектов, хранилище предупреждений об эксфильтрации, сканирование ненадежных загрузок. НЕ ИСПОЛЬЗУЙТЕ для защиты SQL/Cosmos DB (используйте защитник для защиты в облаке), вредоносных программ на дисках виртуальных машин (используйте сканирование без агента с помощью защитника для серверов) или M365 SharePoint/OneDrive (используйте защитник для офиса-365).
