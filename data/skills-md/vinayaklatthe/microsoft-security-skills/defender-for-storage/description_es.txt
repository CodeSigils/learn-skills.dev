Guía para Microsoft Defender for Storage: protección contra amenazas para cuentas de Azure Storage (Blob, Files, Data Lake Gen2). Cubre el plan v2 (por cuenta de almacenamiento), escaneo de malware durante la carga con tecnología de Defender Antivirus, detección de amenazas de datos confidenciales (integrada con la clasificación de Purview), detección de amenazas basada en actividades, anulación por cuenta de almacenamiento, exclusión de cuentas de gran volumen, integración de Event Grid para resultados de escaneo y controles de costos (límite de escaneo por GB). CUÁNDO: Defender for Storage, análisis de malware de Azure Storage, análisis de malware de Blob, detección de amenazas de datos confidenciales, análisis durante la carga, Defender for Storage v2, protección contra amenazas de la cuenta de Storage, resultados del análisis Event Grid, almacenamiento de clasificación de Purview, carga de blobs maliciosos, almacenamiento de alertas de exfiltración, análisis de cargas que no son de confianza. NO LO UTILICE para protección SQL/Cosmos DB (use defender-for-cloud-hardening), malware de disco de VM (use defender-for-servers escaneo sin agente) o M365 SharePoint/OneDrive (use defender-for-office-365).
