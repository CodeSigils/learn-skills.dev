إرشادات لـ Microsoft Defender للتخزين - الحماية من التهديدات لحسابات Azure Storage (Blob، Files، Data Lake Gen2). يغطي خطة v2 (لكل حساب تخزين)، وفحص البرامج الضارة عند التحميل المدعوم من Defender Antivirus، واكتشاف تهديدات البيانات الحساسة (متكامل مع تصنيف Purview)، واكتشاف التهديدات المستندة إلى النشاط، والتجاوز لكل حساب تخزين، واستبعاد الحسابات ذات الحجم الكبير، وتكامل Event Grid لنتائج الفحص، وضوابط التكلفة (الحد الأقصى للمسح لكل جيجابايت). متى: Defender للتخزين، فحص البرامج الضارة لـ Azure Storage، فحص البرامج الضارة لـ Blob، اكتشاف تهديدات البيانات الحساسة، فحص عند التحميل، Defender for Storage v2، الحماية من تهديدات حساب التخزين، نتائج المسح، Event Grid، تخزين تصنيف Purview، تحميل Blob الضار، تخزين تنبيه الترشيح، فحص التحميل غير الموثوق به. لا تستخدمه لحماية SQL/Cosmos DB (استخدم Defender-for-Cloud-hardening)، أو البرامج الضارة لقرص VM (استخدم فحص بدون وكيل لـ Defender-for-Servers)، أو M365 SharePoint/OneDrive (استخدم Defender-for-office-365).
