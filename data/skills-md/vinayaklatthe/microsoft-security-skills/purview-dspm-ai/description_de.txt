Leitfaden für Microsoft Purview Data Security Posture Management for AI (DSPM for AI) – Erkennung, Überwachung und Schutz sensibler Dateninteraktionen mit generativen KI-Apps wie Microsoft 365 Copilot, Security Copilot, Copilot Studio-Agenten und Drittanbieter-KI (ChatGPT, Gemini). Deckt die Sichtbarkeit der KI-Nutzung, One-Click-Empfehlungen, das Risiko einer übermäßigen Weitergabe an die KI und DLP für KI ab. WANN: DSPM für KI, KI-Datensicherheitsstatus, Copilot-Datenrisiko, Überwachung von KI-Eingabeaufforderungen, sensible Daten in KI, generativer KI-Datenschutz, Sichtbarkeit der KI-Nutzung durch Dritte, Sicherung von Copilot-Daten, welche sensiblen Daten an AI gesendet werden, Überwachung, was Benutzer in Copilot-Eingabeaufforderungen eingeben, Erkennung sensibler Daten in KI-Antworten, ChatGPT-Datenleckrisiko. NICHT VERWENDEN, wenn das Ziel darin besteht, übermäßig freigegebene SharePoint-Inhalte vor der Copilot-Einführung zu korrigieren (verwenden Sie „purview-copilot-oversharing“) oder IRM-Richtlinien für ausscheidende Benutzer zu erstellen (verwenden Sie „insider-risk-baseline“).
