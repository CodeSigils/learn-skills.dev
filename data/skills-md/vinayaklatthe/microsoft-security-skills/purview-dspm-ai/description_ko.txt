Microsoft Purview AI용 DSPM(Data Security Posture Management for AI)에 대한 지침 - Microsoft 365 Copilot, Security Copilot, Copilot Studio 에이전트 및 타사 AI(ChatGPT, Gemini)와 같은 생성 AI 앱과의 중요한 데이터 상호 작용을 검색, 모니터링 및 보호합니다. AI 사용 가시성, 원클릭 권장 사항, AI에 나타나는 과도한 위험 공유 및 AI용 DLP를 다룹니다. 시기: AI용 DSPM, AI 데이터 보안 상태, Copilot 데이터 위험, AI 프롬프트 모니터링, AI의 민감한 데이터, 생성적 AI 데이터 보호, 제3자 AI 사용 가시성, Copilot 데이터 보안, AI로 전송되는 민감한 데이터, 사용자가 Copilot 프롬프트에 입력하는 내용 모니터링, AI 응답에서 민감한 데이터 감지, ChatGPT 데이터 유출 위험. 목표가 Copilot 롤아웃(purview-copilot-oversharing 사용) 전에 과도하게 공유된 SharePoint 콘텐츠를 수정하거나 퇴사하는 사용자를 위한 IRM 정책을 구축하는 것(내부자 위험 기준 사용)인 경우에는 사용하지 마십시오.
