Conseils pour Microsoft Purview Data Security Posture Management for AI (DSPM for AI) - découverte, surveillance et protection des interactions de données sensibles avec des applications d'IA génératives telles que Microsoft 365 Copilot, Security Copilot, les agents Copilot Studio et l'IA tierce (ChatGPT, Gemini). Couvre la visibilité de l'utilisation de l'IA, les recommandations en un clic, le risque de partage excessif lié à l'IA et le DLP pour l'IA. QUAND : DSPM pour l'IA, posture de sécurité des données de l'IA, risque lié aux données du Copilot, surveillance des invites de l'IA, données sensibles dans l'IA, protection des données de l'IA générative, visibilité de l'utilisation de l'IA par des tiers, données sécurisées du Copilot, quelles données sensibles sont envoyées à l'IA, surveillance de ce que les utilisateurs mettent dans les invites du Copilot, détection des données sensibles dans les réponses de l'IA, risque de fuite de données ChatGPT. NE PAS UTILISER lorsque l'objectif est de corriger le contenu SharePoint sur-partagé avant le déploiement de Copilot (utilisez purview-copilot-oversharing) ou de créer des politiques IRM pour les utilisateurs sortants (utilisez la ligne de base des risques internes).
