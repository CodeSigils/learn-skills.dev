Руководство по управлению состоянием безопасности данных Microsoft Purview для ИИ (DSPM для ИИ) — обнаружение, мониторинг и защита взаимодействия конфиденциальных данных с генеративными приложениями ИИ, такими как Microsoft 365 Copilot, Security Copilot, агенты Copilot Studio и сторонним ИИ (ChatGPT, Gemini). Охватывает прозрачность использования ИИ, рекомендации в один клик, чрезмерное распределение рисков, связанных с ИИ, и DLP для ИИ. КОГДА: DSPM для ИИ, состояние безопасности данных ИИ, риск данных Copilot, мониторинг подсказок ИИ, конфиденциальные данные в ИИ, генеративная защита данных ИИ, видимость использования стороннего ИИ, безопасность данных Copilot, какие конфиденциальные данные отправляются в ИИ, мониторинг того, что пользователи вводят в подсказки Copilot, обнаружение конфиденциальных данных в ответах ИИ, риск утечки данных ChatGPT. НЕ ИСПОЛЬЗУЙТЕ, если целью является исправление чрезмерно общего содержимого SharePoint перед развертыванием Copilot (используйте Purview-copilot-oversharing) или создание политик IRM для уходящих пользователей (используйте базовый уровень внутреннего риска).
