Linee guida per Microsoft Purview Data Security Posture Management for AI (DSPM for AI): individuazione, monitoraggio e protezione delle interazioni dei dati sensibili con app di intelligenza artificiale generativa come Microsoft 365 Copilot, Security Copilot, agenti Copilot Studio e intelligenza artificiale di terze parti (ChatGPT, Gemini). Copre la visibilità sull'utilizzo dell'intelligenza artificiale, i consigli con un clic, il rischio di condivisione eccessiva emerso per l'intelligenza artificiale e la DLP per l'intelligenza artificiale. QUANDO: DSPM per AI, comportamento di sicurezza dei dati AI, rischio dei dati di Copilot, monitorare i prompt dell'AI, dati sensibili nell'AI, protezione dei dati dell'AI generativa, visibilità sull'utilizzo dell'AI di terze parti, proteggere i dati di Copilot, quali dati sensibili vengono inviati all'AI, monitorare ciò che gli utenti inseriscono nei prompt di Copilot, rilevare i dati sensibili nelle risposte dell'AI, rischio di perdita di dati ChatGPT. NON UTILIZZARE quando l'obiettivo è correggere il contenuto di SharePoint sovracondiviso prima dell'implementazione di Copilot (utilizzare purview-copilot-oversharing) o creare criteri IRM per gli utenti che se ne vanno (utilizzare insider-risk-baseline).
