إرشادات لإدارة سجلات Microsoft Purview - الإعلان عن السجلات وإدارتها والتخلص منها عبر SharePoint وOneDrive وExchange وTeams. يغطي تسميات الاستبقاء مع خيارات السجل/السجل التنظيمي، واستيراد خطة الملف، والاحتفاظ المستند إلى الحدث (إجازات الموظفين، وانتهاء العقد)، ومراجعة التصرف (مرحلة واحدة ومتعددة المراحل)، وإثبات الحذف/سجلات التصرف، وسياسات تسميات الاستبقاء مقابل سياسات التطبيق التلقائي (KQL/أنواع المعلومات الحساسة/المصنفات القابلة للتدريب)، وDLP المدرك للتسمية، والتكامل مع إدارة المعلومات مقابل ترخيص إدارة السجلات، وفصل الأدوار بين مديري السجلات والمسؤولين. متى: نطاق إدارة السجلات، خطة الملف، سجل تسمية الاستبقاء، السجل التنظيمي، الاحتفاظ المستند إلى الحدث، مراجعة التصرف، إقرار السجل SharePoint، السجلات غير القابلة للتغيير، الحذف المقاوم للتدقيق، استيراد خطة الملف. لا تستخدمه لدورة حياة البيانات غير المتعلقة بالسجلات (استخدم دورة حياة البيانات، أو سياسات DLP (استخدم سياسة Purview-dlp)، أو eDiscovery (استخدم Purview-ediscovery).
