Руководство по проектированию рабочих станций с привилегированным доступом (PAW) и стратегия привилегированного доступа Microsoft (корпоративная модель доступа, принцип чистого исходного кода, многоуровневая изоляция администратора). Описывает, когда следует использовать профили устройств Enterprise, Specialized и Privileged, усиление защиты (Entra-join, Intune, белый список приложений, Credential Guard), принудительное применение условного доступа и развертывание. КОГДА: рабочая станция с привилегированным доступом, рабочая станция с привилегированным доступом, защищенная рабочая станция администратора, модель корпоративного доступа, стратегия привилегированного доступа, изоляция администратора, защищенная рабочая станция, принцип чистого источника, защита уровня 0, плоскость управления, выделенное устройство администратора, защищенная рабочая станция, Credential Guard, администратор FIDO2.
