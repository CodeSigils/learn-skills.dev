PAW (Privileged Access Workstation) と Microsoft の特権アクセス戦略 (エンタープライズ アクセス モデル、クリーン ソースの原則、段階的管理分離) を設計するためのガイダンス。 Enterprise デバイス プロファイル、特殊デバイス プロファイル、特権デバイス プロファイルをいつ使用するか、強化 (Entra-join、Intune、アプリの許可リスト、Credential Guard)、条件付きアクセスの適用、ロールアウトについて説明します。対象となる場合: 特権アクセス ワークステーション、PAW、安全な管理ワークステーション、エンタープライズ アクセス モデル、特権アクセス戦略、管理者の分離、安全なワークステーション、クリーン ソースの原則、Tier 0 保護、コントロール プレーン、専用の管理デバイス、強化されたワークステーション、Credential Guard、FIDO2 管理。一般的なエンドポイントの強化 (defender-for-endpoint を使用) またはデバイス コンプライアンス ポリシー (intune-device-mgmt を使用) には使用しないでください。
