适用于容器的 Microsoft Defender 指南 - 跨 AKS、启用 Azure Arc 的 Kubernetes、EKS、GKE 和 OpenShift 的 Kubernetes 和容器安全性。涵盖无代理发现、图像和运行容器的无代理漏洞评估（由 Microsoft Defender 漏洞管理提供支持）、通过 Defender 传感器（Linux 上的 eBPF）进行运行时威胁检测、使用 Azure Policy/Gatekeeper 进行 Kubernetes 数据平面强化、ACR/ECR/GAR 注册表扫描、准入控制、攻击路径分析和 Sentinel 集成。时间：Defender for Containers、AKS 安全、容器运行时威胁检测、Kubernetes 准入控制、图像漏洞扫描、ACR 扫描、Defender for Cloud 中的 EKS GKE 安全、K8s 状态、容器攻击路径、Defender 容器传感器、Gatekeeper Azure Policy AKS、无代理容器扫描。请勿用于虚拟机/主机强化（使用服务器防御者）、AKS 网络设计（使用 azure-network-security-design）或与安全无关的常规 AKS day-2 操作。
