إرشادات لـ Microsoft Defender للحاويات — Kubernetes وأمان الحاويات عبر AKS وKubernetes التي تدعم Azure Arc وEKS وGKE وOpenShift. يغطي الاكتشاف بدون وكيل، وتقييم الثغرات الأمنية بدون وكيل للصور والحاويات قيد التشغيل (المدعوم من إدارة الثغرات الأمنية في Microsoft Defender)، واكتشاف التهديدات في وقت التشغيل عبر مستشعر Defender (eBPF على Linux)، وتقوية مستوى بيانات Kubernetes باستخدام Azure Policy / Gatekeeper، ومسح التسجيل لـ ACR / ECR / GAR، والتحكم في القبول، وتحليل مسار الهجوم، وتكامل Sentinel. متى: Defender للحاويات، أمان AKS، اكتشاف تهديدات وقت تشغيل الحاوية، التحكم في قبول Kubernetes، فحص ثغرات الصورة، فحص ACR، أمان EKS GKE في Defender for Cloud، وضعية K8s، مسار هجوم الحاوية، مستشعر حاوية Defender، Gatekeeper Azure Policy AKS، فحص الحاويات بدون وكيل. لا تستخدمه لتقوية الأجهزة الافتراضية/المضيف (استخدم المدافع مقابل الخوادم)، أو تصميم شبكات AKS (استخدم تصميم أمان الشبكة azure)، أو عمليات AKS العامة لليوم الثاني التي لا علاقة لها بالأمان.
