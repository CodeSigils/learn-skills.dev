Leitfaden für Microsoft Defender für Container – Kubernetes und Containersicherheit in AKS, Azure Arc-fähigem Kubernetes, EKS, GKE und OpenShift. Umfasst agentenlose Erkennung, agentenlose Schwachstellenbewertung für Images und laufende Container (unterstützt von Microsoft Defender Vulnerability Management), Laufzeitbedrohungserkennung über den Defender-Sensor (eBPF unter Linux), Kubernetes-Datenebenenhärtung mit Azure Policy/Gatekeeper, Registrierungsscan für ACR/ECR/GAR, Zugangskontrolle, Angriffspfadanalyse und Sentinel-Integration. WANN: Defender für Container, AKS-Sicherheit, Bedrohungserkennung zur Containerlaufzeit, Kubernetes-Zugangskontrolle, Image-Schwachstellenscan, ACR-Scan, EKS GKE-Sicherheit in Defender für Cloud, K8s-Haltung, Containerangriffspfad, Defender-Containersensor, Gatekeeper Azure Policy AKS, agentenloser Containerscan. NICHT für VM-/Host-Härtung (verwenden Sie Defender-for-Servers), AKS-Netzwerkdesign (verwenden Sie Azure-Network-Security-Design) oder allgemeine AKS-Day-2-Operationen ohne Bezug zur Sicherheit verwenden.
