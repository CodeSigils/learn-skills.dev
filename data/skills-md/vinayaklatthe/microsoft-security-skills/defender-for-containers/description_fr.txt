Conseils pour Microsoft Defender pour les conteneurs : Kubernetes et sécurité des conteneurs dans AKS, Kubernetes avec Azure Arc, EKS, GKE et OpenShift. Couvre la découverte sans agent, l'évaluation des vulnérabilités sans agent pour les images et les conteneurs en cours d'exécution (optimisés par Microsoft Defender Vulnerability Management), la détection des menaces d'exécution via le capteur Defender (eBPF sur Linux), le renforcement du plan de données Kubernetes avec Azure Policy/Gatekeeper, l'analyse du registre pour ACR/ECR/GAR, le contrôle d'admission, l'analyse du chemin d'attaque et l'intégration de Sentinel. QUAND : Defender pour les conteneurs, sécurité AKS, détection des menaces d'exécution des conteneurs, contrôle d'admission Kubernetes, analyse des vulnérabilités d'image, analyse ACR, sécurité EKS GKE dans Defender pour Cloud, posture K8s, chemin d'attaque des conteneurs, capteur de conteneur Defender, Gatekeeper Azure Policy AKS, analyse des conteneurs sans agent. NE PAS UTILISER pour le renforcement des machines virtuelles/hôtes (utilisez Defender-for-servers), la conception de réseau AKS (utilisez Azure-network-security-design) ou les opérations générales AKS jour 2 sans rapport avec la sécurité.
