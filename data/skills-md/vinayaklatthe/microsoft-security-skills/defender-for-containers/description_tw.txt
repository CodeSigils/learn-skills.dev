適用於容器的 Microsoft Defender 指南 - 跨 AKS、啟用 Azure Arc 的 Kubernetes、EKS、GKE 和 OpenShift 的 Kubernetes 和容器安全性。涵蓋無代理程式發現、映像檔和執行容器的無代理漏洞評估（由 Microsoft Defender 漏洞管理提供支援）、透過 Defender 感測器（Linux 上的 eBPF）進行執行時間威脅偵測、使用 Azure Policy/Gatekeeper 進行 Kubernetes 資料平面強化、ACR/ECR/GAR 登錄機碼掃描、存取控制、攻擊路徑分析和 Sentinel 資料平面強化。時間：Defender for Containers、AKS 安全性、容器執行時間威脅偵測、Kubernetes 存取控制、映像漏洞掃描、ACR 掃描、Defender for Cloud 中的 EKS GKE 安全性、K8s 狀態、容器攻擊路徑、Defender 容器感測器、Gatekeeper Azure Policy AKS、無代理容器掃描。請勿用於虛擬機器/主機強化（使用伺服器防禦者）、AKS 網路設計（使用 azure-network-security-design）或與安全性無關的常規 AKS day-2 操作。
