Guía para Microsoft Defender para contenedores: Kubernetes y seguridad de contenedores en AKS, Kubernetes habilitado para Azure Arc, EKS, GKE y OpenShift. Cubre el descubrimiento sin agentes, la evaluación de vulnerabilidades sin agentes para imágenes y contenedores en ejecución (con tecnología de Microsoft Defender Vulnerability Management), detección de amenazas en tiempo de ejecución a través del sensor Defender (eBPF en Linux), fortalecimiento del plano de datos de Kubernetes con Azure Policy/Gatekeeper, escaneo de registro para ACR/ECR/GAR, control de admisión, análisis de rutas de ataque e integración de Sentinel. CUÁNDO: Defender para contenedores, seguridad de AKS, detección de amenazas en tiempo de ejecución de contenedores, control de admisión de Kubernetes, escaneo de vulnerabilidades de imágenes, escaneo ACR, seguridad EKS GKE en Defender para la nube, postura de K8, ruta de ataque de contenedores, sensor de contenedores de Defender, Gatekeeper Azure Policy AKS, escaneo de contenedores sin agentes. NO LO UTILICE para reforzar máquinas virtuales/host (use defender-for-servers), diseño de redes de AKS (use azure-network-security-design) ni operaciones generales del día 2 de AKS que no estén relacionadas con la seguridad.
