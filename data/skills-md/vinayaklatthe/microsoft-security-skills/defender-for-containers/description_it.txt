Linee guida per Microsoft Defender per contenitori: Kubernetes e sicurezza dei contenitori in AKS, Kubernetes abilitato per Azure Arc, EKS, GKE e OpenShift. Copre rilevamento senza agente, valutazione della vulnerabilità senza agente per immagini e contenitori in esecuzione (con tecnologia Microsoft Defender Vulnerability Management), rilevamento delle minacce in runtime tramite il sensore Defender (eBPF su Linux), rafforzamento del piano dati Kubernetes con criteri di Azure/Gatekeeper, scansione del registro per ACR/ECR/GAR, controllo di ammissione, analisi del percorso di attacco e integrazione di Sentinel. QUANDO: Defender for Containers, sicurezza AKS, rilevamento delle minacce in runtime del container, controllo di ammissione Kubernetes, scansione della vulnerabilità dell'immagine, scansione ACR, sicurezza EKS GKE in Defender for Cloud, postura K8s, percorso di attacco del container, sensore del container Defender, Gatekeeper Azure Policy AKS, scansione del container senza agente. NON UTILIZZARE per la protezione avanzata di VM/host (usare Defender-for-Servers), progettazione di rete AKS (usare azure-network-security-design) o operazioni generali AKS day-2 non correlate alla sicurezza.
