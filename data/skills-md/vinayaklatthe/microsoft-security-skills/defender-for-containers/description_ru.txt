Руководство по Microsoft Defender для контейнеров — Kubernetes и безопасность контейнеров в AKS, Kubernetes с поддержкой Azure Arc, EKS, GKE и OpenShift. Охватывает безагентное обнаружение, безагентную оценку уязвимостей для образов и запущенных контейнеров (на базе Microsoft Defender Vulnerability Management), обнаружение угроз во время выполнения с помощью датчика Defender (eBPF в Linux), усиление плоскости данных Kubernetes с помощью Azure Policy/Gatekeeper, сканирование реестра на предмет ACR/ECR/GAR, контроль допуска, анализ пути атаки и интеграцию Sentinel. КОГДА: Защитник для контейнеров, безопасность AKS, обнаружение угроз во время выполнения контейнера, контроль доступа Kubernetes, сканирование уязвимостей образов, сканирование ACR, безопасность EKS GKE в Защитнике для облака, положение K8s, путь атаки контейнера, датчик контейнера Защитника, Политика Azure Gatekeeper AKS, сканирование контейнера без агента. НЕ ИСПОЛЬЗУЙТЕ для усиления защиты виртуальных машин и хостов (используйте защитник для серверов), проектирования сети AKS (используйте azure-network-security-design) или общих операций AKS второго дня, не связанных с безопасностью.
