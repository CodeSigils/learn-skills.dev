Azure Arc のガイダンス — オンプレミス、マルチクラウド (AWS/GCP)、エッジ サーバー、Kubernetes、データ サービスを Azure Resource Manager に投影して、統合ガバナンス、セキュリティ、管理を実現します。 Arc 対応サーバーのオンボーディング、Defender for Cloud と Azure Policy の非 Azure マシンへの拡張、および Arc 対応 Kubernetes について説明します。時期: Azure Arc、Azure からのオンプレミス サーバーの管理、ハイブリッド管理、Arc 対応サーバー、Arc Kubernetes、Defender for Cloud のオンプレミスへの拡張、マルチクラウド マシンの管理、Connected Machine エージェント、Arc エージェント、ハイブリッド セキュリティ体制、マシン構成、ゲスト構成。 Azure ネイティブ VM のみ (Azure Resource Manager を直接使用)、Intune で管理されたエンドポイント (intune-device-mgmt を使用)、または特に Azure Stack HCI (別の製品) には使用しないでください。
