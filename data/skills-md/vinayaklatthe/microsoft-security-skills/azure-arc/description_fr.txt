Conseils pour Azure Arc : projection de serveurs locaux, multicloud (AWS/GCP) et Edge, Kubernetes et services de données dans Azure Resource Manager pour une gouvernance, une sécurité et une gestion unifiées. Couvre l’intégration des serveurs compatibles Arc, l’extension de Defender pour Cloud et Azure Policy aux machines non Azure et Kubernetes compatible Arc. QUAND : Azure Arc, gérer les serveurs sur site à partir d'Azure, gestion hybride, serveurs compatibles Arc, Arc Kubernetes, étendre Defender for Cloud sur site, gouverner les machines multicloud, agent de machine connectée, agent Arc, posture de sécurité hybride, configuration de machine, configuration d'invité. NE PAS UTILISER uniquement pour les machines virtuelles natives Azure (utilisez directement Azure Resource Manager), les points de terminaison gérés par Intune (utilisez intune-device-mgmt) ou spécifiquement Azure Stack HCI (produit distinct).
