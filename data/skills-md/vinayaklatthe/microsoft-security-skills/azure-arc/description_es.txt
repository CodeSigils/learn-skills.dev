Guía para Azure Arc: proyección de servidores locales, multinube (AWS/GCP) y perimetrales, Kubernetes y servicios de datos en Azure Resource Manager para lograr gobernanza, seguridad y administración unificadas. Cubre la incorporación de servidores habilitados para Arc, la extensión de Defender for Cloud y Azure Policy a máquinas que no son de Azure y Kubernetes habilitado para Arc. CUÁNDO: Azure Arc, administrar servidores locales desde Azure, administración híbrida, servidores habilitados para Arc, Arc Kubernetes, extender Defender for Cloud a local, gobernar máquinas multinube, agente de Connected Machine, agente de Arc, postura de seguridad híbrida, configuración de máquinas, configuración de invitados. NO LO USE solo para máquinas virtuales nativas de Azure (use Azure Resource Manager directamente), puntos finales administrados por Intune (use intune-device-mgmt) o Azure Stack HCI específicamente (producto separado).
