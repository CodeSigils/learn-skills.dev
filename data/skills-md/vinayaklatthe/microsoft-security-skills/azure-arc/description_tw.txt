Azure Arc 指南 — 将本地、多云 (AWS/GCP) 和边缘服务器、Kubernetes 和数据服务投影到 Azure 资源管理器中，以实现统一治理、安全和管理。涵蓋啟用 Arc 的伺服器加入、將 Defender for Cloud 和 Azure Policy 擴展到非 Azure 電腦以及啟用 Arc 的 Kubernetes。时间：Azure Arc，从 Azure 管理本地服务器、混合管理、支持 Arc 的服务器、Arc Kubernetes、将 Defender for Cloud 扩展到本地、管理多云计算机、互联机器代理、Arc 代理、混合安全态势、机器配置、来宾配置。请勿仅用于 Azure 本机 VM（直接使用 Azure 资源管理器）、Intune 托管终结点（使用 intune-device-mgmt）或专门用于 Azure Stack HCI（单独的产品）。
