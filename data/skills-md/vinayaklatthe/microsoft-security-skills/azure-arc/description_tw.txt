Azure Arc 指南 — 將本機、多雲 (AWS/GCP) 和邊緣伺服器、Kubernetes 和資料服務投影到 Azure 資源管理器中，以實現統一治理、安全性和管理。涵蓋啟用 Arc 的伺服器加入、將 Defender for Cloud 和 Azure Policy 擴展到非 Azure 電腦以及啟用 Arc 的 Kubernetes。時間：Azure Arc，從 Azure 管理本機伺服器、混合式管理、支援 Arc 的伺服器、Arc Kubernetes、將 Defender for Cloud 擴展到本機、管理多雲電腦、連網機器代理程式、Arc 代理程式、混合安全態勢、機器配置、來賓設定。請勿僅用於 Azure 本機 VM（直接使用 Azure 資源管理器）、Intune 託管結束點（使用 intune-device-mgmt）或專門用於 Azure Stack HCI（單獨的產品）。
