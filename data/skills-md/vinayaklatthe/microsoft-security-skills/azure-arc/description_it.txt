Linee guida per Azure Arc: proiezione di server locali, multicloud (AWS/GCP) ed edge, Kubernetes e servizi dati in Azure Resource Manager per governance, sicurezza e gestione unificate. Copre l'onboarding dei server abilitati per Arc, l'estensione di Defender for Cloud e i criteri di Azure a macchine non Azure e Kubernetes abilitati per Arc. QUANDO: Azure Arc, gestire server locali da Azure, gestione ibrida, server abilitati per Arc, Arc Kubernetes, estendere Defender for Cloud a locali, governare macchine multicloud, agente macchina connessa, agente Arc, atteggiamento di sicurezza ibrido, configurazione macchina, configurazione guest. NON UTILIZZARE solo per VM native di Azure (usare direttamente Azure Resource Manager), endpoint gestiti da Intune (usare intune-device-mgmt) o Azure Stack HCI in modo specifico (prodotto separato).
