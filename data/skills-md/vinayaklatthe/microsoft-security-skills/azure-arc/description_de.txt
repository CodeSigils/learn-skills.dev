Leitfaden für Azure Arc – Projizieren von lokalen, Multicloud- (AWS/GCP) und Edge-Servern, Kubernetes und Datendiensten in Azure Resource Manager für einheitliche Governance, Sicherheit und Verwaltung. Deckt das Onboarding von Arc-fähigen Servern, die Erweiterung von Defender für Cloud und Azure Policy auf Nicht-Azure-Maschinen sowie Arc-fähiges Kubernetes ab. WANN: Azure Arc, lokale Server von Azure aus verwalten, Hybridverwaltung, Arc-fähige Server, Arc Kubernetes, Defender für Cloud auf lokal erweitern, Multicloud-Maschinen verwalten, Connected Machine-Agent, Arc-Agent, hybride Sicherheitslage, Maschinenkonfiguration, Gastkonfiguration. NICHT nur für Azure-native VMs (verwenden Sie Azure Resource Manager direkt), von Intune verwaltete Endpunkte (verwenden Sie intune-device-mgmt) oder speziell für Azure Stack HCI (separates Produkt) verwenden.
