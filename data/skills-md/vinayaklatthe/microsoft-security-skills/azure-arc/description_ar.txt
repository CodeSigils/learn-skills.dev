إرشادات لـ Azure Arc - عرض الخوادم المحلية والسحابية المتعددة (AWS/GCP) والخوادم الطرفية وKubernetes وخدمات البيانات في Azure Resource Manager للحوكمة والأمان والإدارة الموحدة. يغطي إعداد الخوادم التي تدعم Arc، وتوسيع نطاق Defender for Cloud وAzure Policy ليشمل الأجهزة غير التابعة لـ Azure، وKubernetes التي تدعم Arc. متى: Azure Arc، إدارة الخوادم المحلية من Azure، الإدارة المختلطة، الخوادم التي تدعم Arc، Arc Kubernetes، توسيع Defender for Cloud ليشمل المحلي، التحكم في الأجهزة متعددة السحابة، وكيل الجهاز المتصل، وكيل Arc، وضع الأمان المختلط، تكوين الجهاز، تكوين الضيف. لا تستخدمه مع أجهزة Azure الأصلية فقط (استخدم Azure Resource Manager مباشرةً)، أو نقاط النهاية المُدارة بواسطة Intune (استخدم intune-device-mgmt)، أو Azure Stack HCI على وجه التحديد (منتج منفصل).
