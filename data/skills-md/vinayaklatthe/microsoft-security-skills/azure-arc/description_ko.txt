Azure Arc에 대한 지침 — 통합 거버넌스, 보안 및 관리를 위해 온-프레미스, 멀티 클라우드(AWS/GCP), 에지 서버, Kubernetes 및 데이터 서비스를 Azure Resource Manager에 프로젝션합니다. Arc 지원 서버 온보딩, Defender for Cloud 및 Azure Policy를 비 Azure 컴퓨터 및 Arc 지원 Kubernetes로 확장하는 방법을 다룹니다. 시기: Azure Arc, Azure에서 온프레미스 서버 관리, 하이브리드 관리, Arc 지원 서버, Arc Kubernetes, Defender for Cloud를 온프레미스로 확장, 멀티클라우드 머신 관리, 연결된 머신 에이전트, Arc 에이전트, 하이브리드 보안 상태, 머신 구성, 게스트 구성. Azure 네이티브 VM(Azure Resource Manager 직접 사용), Intune 관리 엔드포인트(intune-device-mgmt 사용) 또는 특히 Azure Stack HCI(별도 제품)에만 사용하지 마세요.
