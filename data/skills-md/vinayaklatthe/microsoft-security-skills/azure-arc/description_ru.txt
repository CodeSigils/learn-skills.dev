Руководство по Azure Arc — проецирование локальных, мультиоблачных (AWS/GCP) и пограничных серверов, Kubernetes и служб данных в Azure Resource Manager для унифицированного управления, безопасности и управления. Охватывает подключение серверов с поддержкой Arc, распространение Defender для облака и Политики Azure на компьютеры, не использующие Azure, а также Kubernetes с поддержкой Arc. КОГДА: Azure Arc, управление локальными серверами из Azure, гибридное управление, серверы с поддержкой Arc, Arc Kubernetes, расширение Defender for Cloud до локальной среды, управление мультиоблачными компьютерами, агент подключенного компьютера, агент Arc, гибридная безопасность, конфигурация компьютера, гостевая конфигурация. НЕ ИСПОЛЬЗУЙТЕ только собственные виртуальные машины Azure (используйте Azure Resource Manager напрямую), конечные точки, управляемые Intune (используйте intune-device-mgmt), или специально Azure Stack HCI (отдельный продукт).
