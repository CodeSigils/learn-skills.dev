Conseils pour la gestion de la surface d'attaque externe de Microsoft Defender (Defender EASM) : découvre et inventorie les actifs Internet d'une organisation (domaines, hôtes, adresses IP, certificats SSL, ASN, pages Web, contacts) de l'extérieur vers l'intérieur. Couvre la découverte basée sur les semences, les informations sur la surface d'attaque (CVE, certificats expirés, technologies obsolètes, cloud non autorisé), les étiquettes et les groupes, l'intégration avec Defender for Cloud (CSPM), Defender XDR et Sentinel, ainsi que le modèle de tarification (par actif). QUAND : Defender EASM, gestion de la surface d'attaque externe, inventaire accessible sur Internet, découverte du Shadow IT, découverte SSL expirée, découverte RDP exposée, sous-domaine inconnu, informations sur la surface d'attaque, découverte basée sur les semences, analyse externe, risque d'actifs tiers, découverte d'actifs M&A. NE PAS UTILISER pour la découverte d'actifs internes (utilisez Defender-for-cloud-hardening / Defender XDR), l'analyse des vulnérabilités des points de terminaison (utilisez Defender-for-endpoint MDVM) ou la recherche de Sentinel seule.
