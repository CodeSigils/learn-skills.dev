Microsoft Defender 外部攻击面管理 (Defender EASM) 指南 — 从外到内发现并清点组织面向互联网的资产（域、主机、IP、SSL 证书、ASN、网页、联系人）。涵盖基于种子的发现、攻击面洞察（CVE、过期证书、已弃用的技术、未经批准的云）、标签和组、与 Defender for Cloud (CSPM)、Defender XDR 和 Sentinel 的集成以及定价模型（每项资产）。何时：Defender EASM、外部攻击面管理、面向互联网的库存、影子 IT 发现、过期 SSL 发现、暴露的 RDP 发现、未知子域、攻击面洞察、基于种子的发现、由外向内扫描、第三方资产风险、并购资产发现。请勿用于内部资产发现（使用 Defender-for-cloud-hardening/Defender XDR）、端点漏洞扫描（使用 Defender-for-endpoint MDVM）或单独的 Sentinel 搜寻。
