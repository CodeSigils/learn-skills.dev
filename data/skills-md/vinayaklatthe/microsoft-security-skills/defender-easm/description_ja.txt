Microsoft Defender 外部攻撃対象領域管理 (Defender EASM) のガイダンス — 組織のインターネットに接続されている資産 (ドメイン、ホスト、IP、SSL 証明書、ASN、Web ページ、連絡先) をアウトサイドインから検出し、インベントリを作成します。シードベースの検出、攻撃対象領域の洞察 (CVE、期限切れの証明書、非推奨のテクノロジー、未承認のクラウド)、ラベルとグループ、Defender for Cloud (CSPM)、Defender XDR、Sentinel との統合、価格モデル (資産ごと) をカバーします。時期: Defender EASM、外部攻撃対象領域管理、インターネットに接続されたインベントリ、シャドー IT 検出、期限切れ SSL 検出、公開された RDP 検出、未知のサブドメイン、攻撃対象領域の洞察、シードベースの検出、アウトサイドイン スキャン、サードパーティ資産リスク、M&A 資産検出。内部資産検出 (defender-for-cloud-hardening / Defender XDR を使用)、エンドポイント脆弱性スキャン (defender-for-endpoint MDVM を使用)、または Sentinel ハンティングのみには使用しないでください。
