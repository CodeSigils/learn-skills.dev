Microsoft Defender 外部攻擊面管理 (Defender EASM) 指南 — 從外到內發現並清點組織面向網際網路的資產（網域、主機、IP、SSL 憑證、ASN、網頁、聯絡人）。涵蓋基於種子的發現、攻擊面洞察（CVE、過期證書、已棄用的技術、未經批准的雲端）、標籤和群組、與 Defender for Cloud (CSPM)、Defender XDR 和 Sentinel 的整合以及定價模型（每項資產）。何時：Defender EASM、外部攻擊面管理、面向互聯網的庫存、影子 IT 發現、過期 SSL 發現、暴露的 RDP 發現、未知子域、攻擊面洞察、基於種子的發現、由外向內掃描、第三方資產風險、併購資產發現。請勿用於內部資產發現（使用 Defender-for-cloud-hardening/Defender XDR）、端點漏洞掃描（使用 Defender-for-endpoint MDVM）或單獨的 Sentinel 搜尋。
