Microsoft Entra ID (旧 Azure AD) のガイダンス — クラウド ID とアクセス管理、およびゼロ トラストのコントロール プレーン。テナントと ID モデル、認証方法 (パスキー、FIDO2、証明書ベース)、Entra Connect または Cloud Sync によるハイブリッド ID、アプリの登録と同意ガバナンス、グループと管理単位、非常事態アカウント、ゼロトラスト ID 基盤をカバーします。対象となる場合: Microsoft Entra ID、Azure AD、アイデンティティ プロバイダーのセットアップ、SSO、ハイブリッド ID、Entra Connect、クラウド同期、認証方法、パスワードレス、パスキー、FIDO2、証明書ベースの認証、アプリ登録、エンタープライズ アプリケーション、不正な同意の付与、非常事態アカウント、緊急アクセス、管理単位、SSPR、パスワード ライトバック。リスクベースの検出 (entra-id-protection を使用)、条件付きアクセス設計 (conditional-access-mfa を使用)、PIM (azure-pim を使用)、または ID ガバナンス ライフサイクル (entra-id-governance を使用) には使用しないでください。
