Microsoft Entra ID（以前稱為 Azure AD）指南 — 雲端身分和存取管理以及零信任控制平面。涵蓋租用戶和身分模型、身分驗證方法（金鑰、FIDO2、基於憑證）、Entra Connect 或 Cloud Sync 的混合身分、應用程式註冊和同意治理、群組和管理單位、打破玻璃帳戶和零信任身分基礎。時間：Microsoft Entra ID、Azure AD、身分識別提供者設定、SSO、混合身分、Entra Connect、雲端同步、驗證方法、無密碼、金鑰、FIDO2、基於憑證的驗證、應用程式註冊、企業應用程式、非法同意授予、打破玻璃帳戶、緊急存取、管理單位、SSPR、密碼寫回。請勿用於基於風險的檢測（使用 entra-id-protection）、條件存取設計（使用條件存取-mfa）、PIM（使用 azure-pim）或身分治理生命週期（使用 entra-id-governance）。
