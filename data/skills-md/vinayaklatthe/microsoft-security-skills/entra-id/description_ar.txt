إرشادات لمعرف Microsoft Entra (Azure AD سابقًا) — الهوية السحابية وإدارة الوصول ومستوى التحكم لـ Zero Trust. يغطي نموذج المستأجر والهوية، وطرق المصادقة (مفاتيح المرور، FIDO2، المستندة إلى الشهادة)، والهوية الهجينة مع Entra Connect أو Cloud Sync، وتسجيلات التطبيقات وإدارة الموافقة، والمجموعات والوحدات الإدارية، وحسابات كسر الزجاج، وأسس هوية Zero Trust. متى: Microsoft Entra ID، Azure AD، إعداد موفر الهوية، SSO، الهوية المختلطة، Entra Connect، Cloud Sync، طرق المصادقة، بدون كلمة مرور، مفتاح المرور، FIDO2، المصادقة المستندة إلى الشهادة، تسجيل التطبيق، تطبيق المؤسسة، منح الموافقة غير المشروعة، حساب كسر الزجاج، الوصول في حالات الطوارئ، الوحدات الإدارية، SSPR، إعادة كتابة كلمة المرور. لا تستخدمه للكشف القائم على المخاطر (استخدم حماية معرف الهوية)، أو تصميم الوصول المشروط (استخدم الوصول المشروط-mfa)، أو PIM (استخدم azure-pim)، أو دورة حياة إدارة الهوية (استخدم حوكمة معرف الهوية).
