Linee guida per Microsoft Entra ID (in precedenza Azure AD): gestione dell'identità e degli accessi nel cloud e piano di controllo per Zero Trust. Copre modello di tenant e identità, metodi di autenticazione (passkey, FIDO2, basata su certificato), identità ibrida con Entra Connect o Cloud Sync, registrazioni di app e governance del consenso, gruppi e unità amministrative, account break-glass e basi di identità Zero Trust. QUANDO: Microsoft Entra ID, Azure AD, configurazione del provider di identità, SSO, identità ibrida, Entra Connect, Cloud Sync, metodi di autenticazione, senza password, passkey, FIDO2, autenticazione basata su certificato, registrazione dell'app, applicazione aziendale, concessione di consenso illecito, account break-glass, accesso di emergenza, unità amministrative, SSPR, writeback della password. NON UTILIZZARE per il rilevamento basato sul rischio (usare entra-id-protection), la progettazione dell'accesso condizionale (usare conditional-access-mfa), PIM (usare azure-pim) o il ciclo di vita della governance delle identità (usare entra-id-governance).
