Руководство для Microsoft Entra ID (ранее Azure AD) — облачное управление идентификацией и доступом, а также плоскость управления для нулевого доверия. Охватывает модель арендатора и удостоверения, методы аутентификации (пароли, FIDO2, на основе сертификатов), гибридную идентификацию с Entra Connect или Cloud Sync, регистрацию приложений и управление согласием, группы и административные единицы, учетные записи «разбитого стекла» и основы идентификации с нулевым доверием. КОГДА: Microsoft Entra ID, Azure AD, настройка поставщика удостоверений, единый вход, гибридная идентификация, Entra Connect, Cloud Sync, методы аутентификации, без пароля, ключ доступа, FIDO2, проверка подлинности на основе сертификата, регистрация приложения, корпоративное приложение, предоставление незаконного согласия, учетная запись с разбитым стеклом, экстренный доступ, административные единицы, SSPR, обратная запись пароля. НЕ ИСПОЛЬЗУЙТЕ для обнаружения на основе рисков (используйте защиту внутри идентификатора), разработки условного доступа (используйте условно-доступ-mfa), PIM (используйте azure-pim) или жизненного цикла управления идентификацией (используйте управление внутри идентификаторов).
