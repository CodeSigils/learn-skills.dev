Conseils pour Microsoft Entra ID (anciennement Azure AD) : gestion des identités et des accès cloud et plan de contrôle pour Zero Trust. Couvre le locataire et le modèle d'identité, les méthodes d'authentification (clés d'authentification, FIDO2, basées sur des certificats), l'identité hybride avec Entra Connect ou Cloud Sync, les enregistrements d'applications et la gouvernance des consentements, les groupes et unités administratives, les comptes brisés et les fondations d'identité Zero Trust. QUAND : Microsoft Entra ID, Azure AD, configuration du fournisseur d'identité, SSO, identité hybride, Entra Connect, Cloud Sync, méthodes d'authentification, sans mot de passe, mot de passe, FIDO2, authentification basée sur un certificat, enregistrement d'application, application d'entreprise, octroi de consentement illicite, compte brisé, accès d'urgence, unités administratives, SSPR, écriture de mot de passe. NE PAS UTILISER pour la détection basée sur les risques (utilisez entra-id-protection), la conception d'accès conditionnel (utilisez conditional-access-mfa), le PIM (utilisez azure-pim) ou le cycle de vie de la gouvernance des identités (utilisez entra-id-governance).
