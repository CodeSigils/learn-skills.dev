Guía para Microsoft Entra ID (anteriormente Azure AD): gestión de identidad y acceso a la nube y plano de control para Zero Trust. Cubre el modelo de identidad y inquilino, métodos de autenticación (claves de acceso, FIDO2, basado en certificados), identidad híbrida con Entra Connect o Cloud Sync, registros de aplicaciones y gobernanza del consentimiento, grupos y unidades administrativas, cuentas de emergencia y bases de identidad Zero Trust. CUÁNDO: Microsoft Entra ID, Azure AD, configuración del proveedor de identidad, SSO, identidad híbrida, Entra Connect, Cloud Sync, métodos de autenticación, sin contraseña, clave de acceso, FIDO2, autenticación basada en certificado, registro de aplicaciones, aplicación empresarial, concesión de consentimiento ilícito, cuenta de emergencia, acceso de emergencia, unidades administrativas, SSPR, reescritura de contraseña. NO UTILIZAR para detección basada en riesgos (use entra-id-protection), diseño de acceso condicional (use conditional-access-mfa), PIM (use azure-pim) o ciclo de vida de gobierno de identidad (use entra-id-governance).
