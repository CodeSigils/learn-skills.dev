Leitfaden für Microsoft Entra ID (ehemals Azure AD) – Cloud-Identitäts- und Zugriffsverwaltung und die Steuerungsebene für Zero Trust. Deckt Mieter- und Identitätsmodelle, Authentifizierungsmethoden (Passschlüssel, FIDO2, zertifikatsbasiert), Hybrididentität mit Entra Connect oder Cloud Sync, App-Registrierungen und Einwilligungs-Governance, Gruppen und Verwaltungseinheiten, Break-Glass-Konten und Zero-Trust-Identitätsgrundlagen ab. WANN: Microsoft Entra ID, Azure AD, Einrichtung des Identitätsanbieters, SSO, Hybrididentität, Entra Connect, Cloud Sync, Authentifizierungsmethoden, passwortlos, Hauptschlüssel, FIDO2, zertifikatbasierte Authentifizierung, App-Registrierung, Unternehmensanwendung, unerlaubte Einwilligungserteilung, Break-Glass-Konto, Notfallzugriff, Verwaltungseinheiten, SSPR, Passwort-Rückschreibung. NICHT für risikobasierte Erkennung (verwenden Sie entra-id-protection), bedingten Zugriffsentwurf (verwenden Sie bedingten Zugriff-MFA), PIM (verwenden Sie azure-pim) oder den Identitätsgovernance-Lebenszyklus (verwenden Sie entra-id-governance) VERWENDEN.
