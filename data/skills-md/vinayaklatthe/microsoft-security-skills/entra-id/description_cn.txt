Microsoft Entra ID（以前称为 Azure AD）指南 — 云身份和访问管理以及零信任控制平面。涵盖租户和身份模型、身份验证方法（密钥、FIDO2、基于证书）、Entra Connect 或 Cloud Sync 的混合身份、应用程序注册和同意治理、组和管理单位、打破玻璃帐户和零信任身份基础。时间：Microsoft Entra ID、Azure AD、身份提供商设置、SSO、混合身份、Entra Connect、云同步、身份验证方法、无密码、密钥、FIDO2、基于证书的身份验证、应用程序注册、企业应用程序、非法同意授予、打破玻璃帐户、紧急访问、管理单位、SSPR、密码写回。请勿用于基于风险的检测（使用 entra-id-protection）、条件访问设计（使用条件访问-mfa）、PIM（使用 azure-pim）或身份治理生命周期（使用 entra-id-governance）。
