Conseils pour Microsoft Security Copilot - la plateforme de sécurité d'IA générative qui aide les analystes à enquêter, rechercher, résumer et répondre à l'aide du langage naturel, des plug-ins, des guides d'invite et des expériences intégrées. Couvre le provisionnement SCU, les plug-ins, les guides d'invite, la gouvernance et le choix de l'expérience autonome ou intégrée. QUAND : Microsoft Security Copilot, AI pour SOC, unités de copilote de sécurité SCU, guides d'invite, plugins Copilot, enquête en langage naturel, résumé d'un incident avec l'IA, configuration de Copilot for Security, comment utiliser l'IA dans mon SOC, expliquer une requête KQL avec l'IA, résumer une alerte pour une partie prenante. NE PAS UTILISER lorsque l’objectif est de configurer des agents de tri ou de remédiation autonomes (utilisez des agents de copilote de sécurité).
