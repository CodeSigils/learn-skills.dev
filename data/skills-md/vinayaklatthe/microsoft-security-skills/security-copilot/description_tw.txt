Microsoft Security Copilot 指南 - 生成式 AI 安全平台，可協助分析師使用自然語言、外掛程式、提示手冊和嵌入式體驗進行調查、搜尋、總結和回應。涵蓋 SCU 配置、外掛程式、提示手冊、治理以及獨立與嵌入式體驗選擇。時間：Microsoft Security Copilot、面向 SOC 的 AI、安全副駕駛單元 SCU、提示手冊、Copilot 外掛程式、自然語言調查、使用 AI 總結事件、Copilot for Security 設定、如何在 SOC 中使用 AI、使用 AI 解釋 KQL 查詢、總結針對利害關係人的警報。當目標是配置自主分類或補救代理時，請勿使用（使用 security-copilot-agents）。
