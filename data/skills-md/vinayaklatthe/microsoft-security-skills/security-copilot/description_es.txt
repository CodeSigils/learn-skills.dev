Guía para Microsoft Security Copilot: la plataforma de seguridad de IA generativa que ayuda a los analistas a investigar, buscar, resumir y responder utilizando lenguaje natural, complementos, libros de indicaciones y experiencias integradas. Cubre el aprovisionamiento de SCU, complementos, libros de avisos, gobernanza y la elección de experiencia independiente o integrada. CUÁNDO: Microsoft Security Copilot, AI para SOC, unidades de copiloto de seguridad SCU, libros de avisos, complementos de Copilot, investigación de lenguaje natural, resumir incidente con AI, configuración de Copilot para seguridad, cómo uso AI en mi SOC, explicar una consulta KQL con AI, resumir una alerta para una parte interesada. NO LO USE cuando el objetivo sea configurar agentes de clasificación o remediación autónomos (use agentes de copiloto de seguridad).
