إرشادات لـ Microsoft Security Copilot - النظام الأساسي لأمان الذكاء الاصطناعي التوليدي الذي يساعد المحللين على التحقيق والبحث والتلخيص والاستجابة باستخدام اللغة الطبيعية والمكونات الإضافية وكتب التوجيهات والتجارب المضمنة. يغطي توفير وحدة SCU، والمكونات الإضافية، وكتب التوجيه، والحوكمة، واختيار التجربة المستقلة مقابل التجربة المضمنة. متى: Microsoft Security Copilot، AI for SOC، وحدات مساعد الأمان SCU، كتب التوجيه، المكونات الإضافية Copilot، التحقيق في اللغة الطبيعية، تلخيص الحادث باستخدام الذكاء الاصطناعي، إعداد Copilot for Security، كيف يمكنني استخدام الذكاء الاصطناعي في SOC الخاص بي، شرح استعلام KQL باستخدام الذكاء الاصطناعي، تلخيص تنبيه لأصحاب المصلحة. لا تستخدمه عندما يكون الهدف هو تكوين وكلاء الفرز أو المعالجة المستقلين (استخدم وكلاء مساعدي الأمان).
