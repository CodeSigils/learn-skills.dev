Microsoft Security Copilot에 대한 지침 - 분석가가 자연어, 플러그인, 프롬프트북 및 내장된 경험을 사용하여 조사, 검색, 요약 및 대응하는 데 도움이 되는 생성적 AI 보안 플랫폼입니다. SCU 프로비저닝, 플러그인, 프롬프트북, 거버넌스, 독립형 및 임베디드 환경 선택을 다룹니다. 시기: Microsoft Security Copilot, SOC용 AI, 보안 부조종사 단위 SCU, 프롬프트북, Copilot 플러그인, 자연어 조사, AI 관련 사건 요약, 보안용 Copilot 설정, SOC에서 AI를 사용하는 방법, AI로 KQL 쿼리 설명, 이해 관계자를 위한 경고 요약. 자율 분류 또는 교정 에이전트를 구성하는 것이 목표인 경우에는 사용하지 마십시오(security-copilot-agents 사용).
