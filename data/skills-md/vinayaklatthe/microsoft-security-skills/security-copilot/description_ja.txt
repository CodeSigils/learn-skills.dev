Microsoft Security Copilot のガイダンス - アナリストが自然言語、プラグイン、プロンプトブック、組み込みエクスペリエンスを使用して調査、探索、要約、対応できるようにする生成 AI セキュリティ プラットフォームです。 SCU プロビジョニング、プラグイン、プロンプトブック、ガバナンス、スタンドアロンと組み込みエクスペリエンスの選択について説明します。時期: Microsoft Security Copilot、AI for SOC、セキュリティ コパイロット ユニット SCU、プロンプトブック、Copilot プラグイン、自然言語調査、AI によるインシデントの要約、Copilot for Security のセットアップ、SOC での AI の使用方法、AI を使用した KQL クエリの説明、関係者向けのアラートの要約。自律的なトリアージまたは修復エージェントを構成することが目的の場合は使用しないでください (security-copilot-agents を使用します)。
