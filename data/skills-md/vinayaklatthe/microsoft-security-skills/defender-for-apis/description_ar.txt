إرشادات لـ Microsoft Defender لواجهات برمجة التطبيقات — خطة Defender for Cloud التي تكتشف واجهات برمجة التطبيقات المنشورة في Azure API Management وتحدد أولوياتها حسب المخاطر وتحميها من التهديدات وإساءة الاستخدام. يغطي الإعداد والنتائج الأمنية واكتشاف التهديدات. متى: Defender لواجهات برمجة التطبيقات، والحماية من تهديدات واجهة برمجة التطبيقات، وواجهات برمجة التطبيقات الآمنة في إدارة واجهة برمجة التطبيقات، والوضع الأمني ​​لواجهة برمجة التطبيقات، واكتشاف إساءة استخدام واجهة برمجة التطبيقات، وواجهات برمجة التطبيقات المدمجة إلى Defender، واكتشاف هجمات واجهة برمجة التطبيقات، والتعرض للبيانات الحساسة في واجهات برمجة التطبيقات.
