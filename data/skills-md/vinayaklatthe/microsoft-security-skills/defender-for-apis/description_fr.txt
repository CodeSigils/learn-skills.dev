Conseils pour Microsoft Defender pour les API : un plan Defender pour Cloud qui découvre, hiérarchise par risque et protège les API publiées dans Azure API Management contre les menaces et les abus. Couvre l’intégration, les résultats de sécurité et la détection des menaces. QUAND : Defender pour les API, protection contre les menaces des API, sécurisation des API dans la gestion des API, posture de sécurité des API, détection des abus d'API, intégration des API dans Defender, détection des attaques d'API, exposition de données sensibles dans les API.
