Руководство для Microsoft Defender для API — план Защитника для облака, который обнаруживает, определяет приоритетность рисков и защищает API, опубликованные в службе управления API Azure, от угроз и злоупотреблений. Охватывает регистрацию, выводы по безопасности и обнаружение угроз. КОГДА: Защитник для API, защита API от угроз, безопасные API в управлении API, состояние безопасности API, обнаружение злоупотреблений API, встроенные API в Защитник, обнаружение атак API, раскрытие конфиденциальных данных в API.
