Leitfaden für Microsoft Defender für APIs – ein Defender für Cloud-Plan, der in Azure API Management veröffentlichte APIs erkennt, nach Risiken priorisiert und vor Bedrohungen und Missbrauch schützt. Deckt Onboarding, Sicherheitsergebnisse und Bedrohungserkennung ab. WANN: Defender für APIs, Schutz vor API-Bedrohungen, sichere APIs in der API-Verwaltung, API-Sicherheitsstatus, Erkennung von API-Missbrauch, Integration von APIs in Defender, Erkennung von API-Angriffen, Offenlegung sensibler Daten in APIs.
