Guía para Microsoft Defender para API: un plan de Defender para la nube que descubre, prioriza según el riesgo y protege las API publicadas en Azure API Management contra amenazas y abusos. Cubre la incorporación, los hallazgos de seguridad y la detección de amenazas. CUÁNDO: Defender para API, protección contra amenazas de API, API seguras en Administración de API, postura de seguridad de API, detección de abuso de API, API integradas en Defender, detección de ataques de API, exposición de datos confidenciales en API.
