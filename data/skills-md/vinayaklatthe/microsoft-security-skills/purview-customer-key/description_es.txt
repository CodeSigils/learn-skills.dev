Guía para la clave de cliente de Microsoft Purview y el cifrado de doble clave (DKE): cifrado controlado por el cliente para datos del lado del servicio (clave de cliente para Exchange/SharePoint/OneDrive/Teams/Purview) y cifrado doble del lado del cliente para documentos altamente confidenciales (DKE a través de etiquetas de confidencialidad y un servicio de clave alojado por el cliente). Cubre la configuración de Azure Key Vault (respaldada por HSM, recuperable, eliminación temporal, protección de purga, regiones redundantes), políticas de cifrado de datos (DEP) para servicios M365, rotación y revocación de claves, implementación del servicio DKE (servicio de liberación de claves en contenedores), creación de etiquetas DKE, compensaciones de la experiencia del usuario final (sin eDiscovery en el contenido DKE) y criterios de decisión versus cifrado administrado por Microsoft. CUÁNDO: Clave de cliente M365, BYOK Exchange, DKE Microsoft, cifrado de doble clave, claves administradas por el cliente SharePoint OneDrive Teams, clave de cliente de rotación de claves, alternativa HYOK, cifrado de soberanía, cifrado controlado por regulador, etiqueta de confidencialidad DKE. NO LO USE para CMK de recursos de Azure (use azure-key-vault), etiquetas de confidencialidad generales (use purview-information-governance) o cumplimiento sin cifrado (use cumplimiento-manager).
