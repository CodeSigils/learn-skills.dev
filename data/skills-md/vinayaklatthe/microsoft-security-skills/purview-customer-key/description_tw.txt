Microsoft Purview 用戶金鑰與雙金鑰加密 (DKE) 指南 — 客戶控制的服務端資料加密（Exchange/SharePoint/OneDrive/Teams/Purview 的客戶金鑰）和高度敏感文件的用戶端雙重加密（DKE 透過敏感度標籤和客戶託管的金鑰服務）。涵蓋 Azure Key Vault 設定（HSM 支援、可恢復、軟刪除、清除保護、冗餘區域）、M365 服務的資料加密策略 (DEP)、金鑰輪換和撤銷保護、DKE 服務部署（容器化金鑰發布服務）、DKE 標籤創作、最終用戶體驗（不對 DKE 內容進行權衡資料展示和資料展示時間：客戶金鑰 M365、BYOK Exchange、DKE Microsoft、雙金鑰加密、客戶管理的金鑰 SharePoint OneDrive Teams、金鑰輪換客戶金鑰、HYOK 替代、主權加密、監管機構控制的加密、敏感度標籤 DKE。請勿用於 Azure 資源 CMK（使用 azure-key-vault）、一般敏感度標籤（使用 purview-information-governance）或非加密合規性（使用合規性管理器）。
