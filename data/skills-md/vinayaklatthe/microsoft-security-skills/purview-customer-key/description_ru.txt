Руководство по ключу клиента Microsoft Purview и шифрованию двойным ключом (DKE) — управляемое клиентом шифрование данных на стороне службы (ключ клиента для Exchange/SharePoint/OneDrive/Teams/Purview) и двойное шифрование на стороне клиента для особо конфиденциальных документов (DKE с помощью меток конфиденциальности и службы ключей, размещаемой клиентом). Охватывает настройку Azure Key Vault (с поддержкой HSM, с возможностью восстановления, мягкое удаление, защиту от очистки, избыточные регионы), политики шифрования данных (DEP) для служб M365, ротацию и отзыв ключей, развертывание службы DKE (служба выпуска контейнерных ключей), создание меток DKE, компромиссы для конечного пользователя (отсутствие обнаружения электронных данных в содержимом DKE) и критерии принятия решения по сравнению с шифрованием, управляемым Microsoft. КОГДА: ключ клиента M365, BYOK Exchange, DKE Microsoft, шифрование с двойным ключом, ключи, управляемые клиентом, SharePoint OneDrive Teams, ротация ключей, ключ клиента, альтернатива HYOK, суверенное шифрование, шифрование, контролируемое регулятором, метка конфиденциальности DKE. НЕ ИСПОЛЬЗУЙТЕ для ресурса Azure CMK (используйте azure-key-vault), общие метки конфиденциальности (используйте управление информацией о ведении) или соответствие требованиям, не связанным с шифрованием (используйте диспетчер соответствия).
