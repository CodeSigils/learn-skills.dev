Microsoft Purview 客户密钥和双密钥加密 (DKE) 指南 — 客户控制的服务端数据加密（Exchange/SharePoint/OneDrive/Teams/Purview 的客户密钥）和高度敏感文档的客户端双重加密（DKE 通过敏感度标签和客户托管的密钥服务）。涵盖 Azure Key Vault 设置（HSM 支持、可恢复、软删除、清除保护、冗余区域）、M365 服务的数据加密策略 (DEP)、密钥轮换和撤销、DKE 服务部署（容器化密钥发布服务）、DKE 标签创作、最终用户体验权衡（不对 DKE 内容进行电子数据展示）以及决策标准与 Microsoft 托管加密。时间：客户密钥 M365、BYOK Exchange、DKE Microsoft、双密钥加密、客户管理的密钥 SharePoint OneDrive Teams、密钥轮换客户密钥、HYOK 替代、主权加密、监管机构控制的加密、敏感度标签 DKE。请勿用于 Azure 资源 CMK（使用 azure-key-vault）、一般敏感度标签（使用 purview-information-governance）或非加密合规性（使用合规性管理器）。
