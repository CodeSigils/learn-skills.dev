إرشادات لوكلاء Microsoft Security Copilot - وكلاء الذكاء الاصطناعي المستقلين والمخصصين (على سبيل المثال، فرز التصيد الاحتيالي، وفرز التنبيهات، وتحسين الوصول المشروط، ومعالجة الثغرات الأمنية) التي تعمل ضمن Security Copilot. يغطي الوكلاء المتاحين والهوية/الأذونات والإشراف. متى: وكلاء مساعدو الأمان، وكيل SOC المستقل، وكيل فرز التصيد الاحتيالي، وكيل فرز التنبيهات، هوية الوكيل، الإشراف على وكيل الذكاء الاصطناعي، أمان الوكيل، أذونات وكيل المساعد، أتمتة فرز التصيد الاحتيالي، وكيل الذكاء الاصطناعي لـ SOC، فرز التنبيهات الذاتية، فرز عدم التدخل للتنبيهات ذات الحجم الكبير. لا تستخدمه لإعداد Security Copilot الأساسي أو توفير SCU أو دفاتر التوجيه (استخدم Security-copilot).
