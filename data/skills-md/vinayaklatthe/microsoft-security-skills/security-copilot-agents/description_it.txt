Linee guida per gli agenti Microsoft Security Copilot: agenti IA autonomi e specifici (ad esempio, classificazione del phishing, classificazione degli avvisi, ottimizzazione dell'accesso condizionale, correzione delle vulnerabilità) che funzionano all'interno di Security Copilot. Copre agenti disponibili, identità/autorizzazioni e supervisione. QUANDO: agenti Copilot di sicurezza, agente SOC autonomo, agente di triage phishing, agente di triage avvisi, identità dell'agente, supervisione dell'agente AI, sicurezza agenti, autorizzazioni agente Copilot, triage automatizzato del phishing, agente AI per SOC, triage avvisi autonomo, triage automatico di avvisi a volume elevato. NON UTILIZZARE per la configurazione di base di Security Copilot, il provisioning di SCU o i promptbook (utilizzare security-copilot).
