Conseils pour les agents Microsoft Security Copilot : agents d'IA autonomes et spécialement conçus (par exemple, triage du phishing, triage des alertes, optimisation de l'accès conditionnel, correction des vulnérabilités) qui fonctionnent dans Security Copilot. Couvre les agents disponibles, l’identité/les autorisations et la supervision. QUAND : agents Security Copilot, agent SOC autonome, agent de triage du phishing, agent de tri des alertes, identité de l'agent, superviser l'agent IA, sécurité agent, autorisations de l'agent Copilot, automatiser le tri du phishing, agent IA pour SOC, triage des alertes autonome, tri manuel des alertes à volume élevé. NE PAS UTILISER pour la configuration de base de Security Copilot, le provisionnement de SCU ou les manuels d'invite (utilisez security-copilot).
