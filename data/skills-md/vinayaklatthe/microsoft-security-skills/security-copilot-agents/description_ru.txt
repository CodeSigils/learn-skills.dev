Руководство для агентов Microsoft Security Copilot — автономных, специально созданных агентов искусственного интеллекта (например, сортировка по фишингу, сортировка предупреждений, оптимизация условного доступа, устранение уязвимостей), которые работают в Security Copilot. Охватывает доступных агентов, идентификацию/разрешения и контроль. КОГДА: агенты безопасности Copilot, автономный агент SOC, агент сортировки фишинга, агент сортировки предупреждений, удостоверение агента, контролирующий агент AI, агентная безопасность, разрешения агента Copilot, автоматическая сортировка фишинга, агент AI для SOC, автономная сортировка оповещений, автоматическая сортировка больших объемов оповещений. НЕ ИСПОЛЬЗУЙТЕ для базовой настройки Security Copilot, подготовки SCU или книг подсказок (используйте Security-Copilot).
