Guía para los agentes de Microsoft Security Copilot: agentes de IA autónomos y diseñados específicamente (por ejemplo, clasificación de phishing, clasificación de alertas, optimización del acceso condicional, corrección de vulnerabilidades) que funcionan dentro de Security Copilot. Cubre agentes disponibles, identidad/permisos y supervisión. CUÁNDO: Agentes de Security Copilot, agente SOC autónomo, agente de clasificación de phishing, agente de clasificación de alertas, identidad del agente, supervisar agente de IA, seguridad de agente, permisos del agente Copilot, automatización de clasificación de phishing, agente de IA para SOC, clasificación de alertas autónoma, clasificación sin intervención de alertas de gran volumen. NO LO USE para la configuración básica de Security Copilot, aprovisionamiento de SCU o libros de avisos (use security-copilot).
