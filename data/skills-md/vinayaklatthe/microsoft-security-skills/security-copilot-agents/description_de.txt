Leitfaden für Microsoft Security Copilot-Agenten – autonome, speziell entwickelte KI-Agenten (z. B. Phishing-Triage, Alarm-Triage, bedingte Zugriffsoptimierung, Schwachstellenbehebung), die innerhalb von Security Copilot arbeiten. Deckt verfügbare Agenten, Identität/Berechtigungen und Aufsicht ab. WANN: Sicherheits-Copilot-Agenten, autonomer SOC-Agent, Phishing-Triage-Agent, Alarm-Triage-Agent, Agent-Identität, Überwachung des KI-Agenten, Agentensicherheit, Copilot-Agent-Berechtigungen, Automatisierung der Phishing-Triage, KI-Agent für SOC, autonome Alarm-Triage, manuelle Triage von umfangreichen Warnungen. NICHT für die grundlegende Einrichtung von Security Copilot, SCU-Bereitstellung oder Promptbooks verwenden (verwenden Sie security-copilot).
