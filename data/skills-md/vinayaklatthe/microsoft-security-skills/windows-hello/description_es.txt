Guía para Windows Hello para empresas (WHfB): autenticación sin contraseña y resistente al phishing mediante un PIN o datos biométricos respaldados por una clave o certificado asimétrico. Cubre la selección del modelo de confianza (confianza de Kerberos en la nube predeterminada para híbridos; legado de confianza de claves; nicho de confianza de certificados), requisitos previos (unión a Entra, registro de MFA, Entra Kerberos para la confianza de Kerberos en la nube), aprovisionamiento basado en Intune, desbloqueo multifactor y fortalezas de la autenticación de acceso condicional. CUÁNDO: Windows Hello para empresas, WHfB, Windows sin contraseña, inicio de sesión biométrico, inicio de sesión con PIN, confianza de Kerberos en la nube, confianza de clave, confianza de certificado, inicio de sesión híbrido, Entra Kerberos, desbloqueo multifactor, aprovisionamiento FIDO2 vs Hello, Hello. NO LO USE para claves de seguridad FIDO2 (use entra-id), creación de políticas de CA (use conditional-access-mfa) o línea base de cumplimiento de Intune (use intune-device-mgmt).
