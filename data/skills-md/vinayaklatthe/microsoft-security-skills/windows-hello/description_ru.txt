Руководство для Windows Hello для бизнеса (WHfB) — проверка подлинности без пароля и защита от фишинга с использованием ПИН-кода или биометрических данных, подкрепленных асимметричным ключом или сертификатом. Охватывает выбор модели доверия (доверие по умолчанию для облака Kerberos для гибридной среды; наследие доверия ключей; ниша доверия сертификатов), предварительные требования (присоединение к Entra, регистрация MFA, Entra Kerberos для доверия облака Kerberos), подготовку на основе Intune, многофакторную разблокировку и сильные стороны проверки подлинности условного доступа. КОГДА: Windows Hello для бизнеса, WHfB, Windows без пароля, биометрический вход, вход с помощью PIN-кода, доверие облачного Kerberos, доверие ключей, доверие сертификата, гибридный вход, Entra Kerberos, многофакторная разблокировка, FIDO2 против Hello, подготовка Hello. НЕ ИСПОЛЬЗУЙТЕ для ключей безопасности FIDO2 (используйте entra-id), разработки политики CA (используйте условный доступ-mfa) или базового уровня соответствия Intune (используйте intune-device-mgmt).
