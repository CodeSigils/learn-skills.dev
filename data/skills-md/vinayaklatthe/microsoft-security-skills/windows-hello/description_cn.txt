Windows Hello 企业版 (WHfB) 指南 — 使用非对称密钥或证书支持的 PIN 或生物识别进行无密码、防网络钓鱼的身份验证。涵盖信任模型选择（混合云 Kerberos 信任默认值；密钥信任传统；证书信任利基）、先决条件（Entra 加入、MFA 注册、云 Kerberos 信任的 Entra Kerberos）、基于 Intune 的配置、多因素解锁和条件访问身份验证优势。时间：Windows Hello 企业版、WHfB、无密码 Windows、生物识别登录、PIN 登录、云 Kerberos 信任、密钥信任、证书信任、混合登录、Entra Kerberos、多因素解锁、FIDO2 与 Hello、Hello 配置。请勿用于 FIDO2 安全密钥（使用 entra-id）、CA 策略创作（使用条件访问-mfa）或 Intune 合规性基线（使用 intune-device-mgmt）。
