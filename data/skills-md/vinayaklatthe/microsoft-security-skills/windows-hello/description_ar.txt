إرشادات لـ Windows Hello for Business (WHfB) - مصادقة بدون كلمة مرور ومقاومة للتصيد الاحتيالي باستخدام رقم التعريف الشخصي أو المقاييس الحيوية المدعومة بمفتاح أو شهادة غير متماثلة. يغطي اختيار نموذج الثقة (الثقة الافتراضية في السحابة Kerberos للمختلط؛ إرث الثقة الرئيسية؛ مكانة الثقة بالشهادة)، المتطلبات الأساسية (انضمام Entra، تسجيل MFA، Entra Kerberos لثقة Kerberos السحابية)، التزويد المستند إلى Intune، إلغاء القفل متعدد العوامل، ونقاط قوة مصادقة الوصول المشروط. متى: Windows Hello for Business، WHfB، Windows بدون كلمة مرور، تسجيل الدخول البيومتري، تسجيل الدخول برقم PIN، ثقة Kerberos السحابية، ثقة المفتاح، ثقة الشهادة، تسجيل الدخول المختلط، Entra Kerberos، فتح متعدد العوامل، FIDO2 vs Hello، توفير Hello. لا تستخدمه مع مفاتيح أمان FIDO2 (استخدم معرف entra)، أو تأليف سياسة CA (استخدم الوصول المشروط-mfa)، أو الخط الأساسي للامتثال لـ Intune (استخدم intune-device-mgmt).
