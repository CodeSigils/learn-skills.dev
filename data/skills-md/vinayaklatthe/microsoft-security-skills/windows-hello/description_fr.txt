Conseils pour Windows Hello for Business (WHfB) : authentification sans mot de passe et résistante au phishing à l'aide d'un code PIN ou d'une biométrie soutenue par une clé ou un certificat asymétrique. Couvre la sélection du modèle de confiance (confiance Cloud Kerberos par défaut pour hybride ; héritage de confiance de clé ; niche de confiance de certificat), les conditions préalables (adhésion Entra, enregistrement MFA, Entra Kerberos pour la confiance Cloud Kerberos), le provisionnement basé sur Intune, le déverrouillage multifacteur et les points forts de l'authentification d'accès conditionnel. QUAND : Windows Hello for Business, WHfB, Windows sans mot de passe, connexion biométrique, connexion par code PIN, confiance Kerberos dans le cloud, confiance de clé, confiance de certificat, connexion hybride, Entra Kerberos, déverrouillage multifacteur, FIDO2 vs Hello, approvisionnement Hello. NE PAS UTILISER pour les clés de sécurité FIDO2 (utilisez entra-id), la création de politiques CA (utilisez conditional-access-mfa) ou la ligne de base de conformité Intune (utilisez intune-device-mgmt).
