Linee guida per Windows Hello for Business (WHfB): autenticazione senza password e resistente al phishing tramite PIN o dati biometrici supportati da una chiave o un certificato asimmetrico. Copre la selezione del modello di trust (trust cloud Kerberos predefinito per ibrido; legacy trust chiave; nicchia di trust certificato), prerequisiti (Entra join, registrazione MFA, Entra Kerberos per cloud Kerberos trust), provisioning basato su Intune, sblocco a più fattori e punti di forza dell'autenticazione con accesso condizionale. QUANDO: Windows Hello for Business, WHfB, Windows senza password, accesso biometrico, accesso PIN, attendibilità Kerberos cloud, attendibilità chiave, attendibilità certificato, accesso ibrido, Entra Kerberos, sblocco a più fattori, FIDO2 vs Hello, provisioning Hello. NON UTILIZZARE per chiavi di sicurezza FIDO2 (utilizzare entra-id), creazione di criteri CA (utilizzare accesso condizionale-mfa) o linea di base di conformità di Intune (utilizzare intune-device-mgmt).
