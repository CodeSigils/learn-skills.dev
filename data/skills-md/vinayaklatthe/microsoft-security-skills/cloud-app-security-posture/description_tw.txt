雲端和 SaaS 安全態勢管理指南 - 結合 Defender for Cloud CSPM (IaaS/PaaS) 和 Defender for Cloud Apps SSPM (SaaS) 來評估和強化跨雲和 SaaS 應用程式的態勢。涵蓋安全評分、MCSB、攻擊路徑分析、SSPM 建議和治理。何時：雲端安全態勢、SaaS 安全態勢管理、SSPM、CSPM、安全雲端應用程式、態勢建議、強化 SaaS 設定、應用程式安全態勢、多雲和 SaaS 強化、強化 Microsoft 365 SaaS 設定、尋找設定錯誤的 Salesforce 或 ServiceNow 設定、SaaS 應用程式錯誤。請勿用於 IaaS/PaaS 工作負載威脅保護計畫（使用 Defender-for-cloud-hardening）或僅用於 SaaS 威脅偵測（使用 Defender-for-cloud-apps）。
