云和 SaaS 安全态势管理指南 - 结合 Defender for Cloud CSPM (IaaS/PaaS) 和 Defender for Cloud Apps SSPM (SaaS) 来评估和强化跨云和 SaaS 应用程序的态势。涵盖安全评分、MCSB、攻击路径分析、SSPM 建议和治理。何时：云安全态势、SaaS 安全态势管理、SSPM、CSPM、安全云应用程序、态势建议、强化 SaaS 配置、应用程序安全态势、多云和 SaaS 强化、强化 Microsoft 365 SaaS 设置、查找配置错误的 Salesforce 或 ServiceNow 设置、SaaS 应用程序配置错误。请勿用于 IaaS/PaaS 工作负载威胁保护计划（使用 Defender-for-cloud-hardening）或仅用于 SaaS 威胁检测（使用 Defender-for-cloud-apps）。
