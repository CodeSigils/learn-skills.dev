Руководство по управлению состоянием безопасности облака и SaaS — объединение Defender для Cloud CSPM (IaaS/PaaS) и Defender для Cloud Apps SSPM (SaaS) для оценки и усиления состояния облачных и SaaS-приложений. Охватывает Secure Score, MCSB, анализ путей атак, рекомендации SSPM и управление. КОГДА: состояние безопасности облака, управление состоянием безопасности SaaS, SSPM, CSPM, безопасные облачные приложения, рекомендации по состоянию, усиление конфигурации SaaS, состояние безопасности приложений, усиление безопасности мультиоблака и SaaS, усиление настроек Microsoft 365 SaaS, обнаружение неправильно настроенных параметров Salesforce или ServiceNow, неправильная конфигурация приложения SaaS. НЕ ИСПОЛЬЗУЙТЕ для планов защиты от угроз рабочих нагрузок IaaS/PaaS (используйте защитник для защиты в облаке) или только для обнаружения угроз SaaS (используйте защитник для облачных приложений).
