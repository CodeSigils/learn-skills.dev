إرشادات لإدارة الوضع الأمني ​​للسحابة وSaaS - الجمع بين Defender for Cloud CSPM (IaaS/PaaS) وDefender for Cloud Apps SSPM (SaaS) لتقييم الموقف عبر السحابة وتطبيقات SaaS وتقويته. يغطي النقاط الآمنة وMCSB وتحليل مسار الهجوم وتوصيات SSPM والحوكمة. متى: وضع أمان السحابة، وإدارة موقف أمان SaaS، وSSPM، وCSPM، وتطبيقات السحابة الآمنة، وتوصيات الموقف، وتقوية تكوين SaaS، ووضع أمان التطبيق، وتقوية السحابة المتعددة وSaaS، وتشديد إعدادات Microsoft 365 SaaS، والعثور على إعدادات Salesforce أو ServiceNow التي تم تكوينها بشكل خاطئ، والتكوين الخاطئ لتطبيق SaaS. لا تستخدمه مع خطط الحماية من تهديدات أحمال عمل IaaS/PaaS (استخدم المدافع مقابل تقوية السحابة) أو لاكتشاف تهديدات SaaS فقط (استخدم المدافع مقابل تطبيقات السحابة).
