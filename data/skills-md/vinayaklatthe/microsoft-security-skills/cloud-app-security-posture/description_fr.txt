Conseils pour la gestion de la posture de sécurité dans le cloud et SaaS : combinant Defender pour Cloud CSPM (IaaS/PaaS) et Defender pour Cloud Apps SSPM (SaaS) pour évaluer et renforcer la posture dans les applications cloud et SaaS. Couvre le score de sécurité, le MCSB, l'analyse du chemin d'attaque, les recommandations SSPM et la gouvernance. QUAND : posture de sécurité du cloud, gestion de la posture de sécurité SaaS, SSPM, CSPM, applications cloud sécurisées, recommandations de posture, renforcement de la configuration SaaS, posture de sécurité des applications, renforcement multicloud et SaaS, renforcement des paramètres Microsoft 365 SaaS, recherche de paramètres Salesforce ou ServiceNow mal configurés, mauvaise configuration de l'application SaaS. NE PAS UTILISER pour les plans de protection contre les menaces des charges de travail IaaS/PaaS (utilisez Defender-for-cloud-hardening) ou pour la détection des menaces SaaS uniquement (utilisez Defender-for-cloud-apps).
