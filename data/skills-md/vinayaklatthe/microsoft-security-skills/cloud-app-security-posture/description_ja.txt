クラウドおよび SaaS のセキュリティ体制管理のガイダンス - Defender for Cloud CSPM (IaaS/PaaS) と Defender for Cloud Apps SSPM (SaaS) を組み合わせて、クラウドおよび SaaS アプリ全体の体制を評価し、強化します。セキュア スコア、MCSB、攻撃パス分析、SSPM の推奨事項、ガバナンスについて説明します。いつ: クラウド セキュリティ体制、SaaS セキュリティ体制管理、SSPM、CSPM、安全なクラウド アプリ、姿勢の推奨事項、SaaS 構成の強化、アプリのセキュリティ体制、マルチクラウドと SaaS の強化、Microsoft 365 SaaS 設定の強化、誤った Salesforce または ServiceNow 設定の検出、SaaS アプリの誤った構成。 IaaS/PaaS ワークロードの脅威保護計画 (defender-for-cloud-hardening を使用) または SaaS 脅威の検出のみ (defender-for-cloud-apps を使用) には使用しないでください。
