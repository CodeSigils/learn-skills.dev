Linee guida per la gestione del comportamento di sicurezza cloud e SaaS: combinazione di Defender for Cloud CSPM (IaaS/PaaS) e Defender for Cloud Apps SSPM (SaaS) per valutare e rafforzare il comportamento nelle app cloud e SaaS. Copre Secure Score, MCSB, analisi del percorso di attacco, raccomandazioni SSPM e governance. QUANDO: comportamento di sicurezza cloud, gestione del comportamento di sicurezza SaaS, SSPM, CSPM, proteggere le app cloud, consigli sul comportamento, rafforzare la configurazione SaaS, comportamento di sicurezza delle app, rafforzamento multicloud e SaaS, rafforzare le impostazioni SaaS di Microsoft 365, trovare impostazioni Salesforce o ServiceNow configurate in modo errato, configurazione errata dell'app SaaS. NON UTILIZZARE per piani di protezione dalle minacce dei carichi di lavoro IaaS/PaaS (utilizzare Defender-for-Cloud-Harening) o solo per il rilevamento delle minacce SaaS (utilizzare Defender-For-Cloud-Apps).
