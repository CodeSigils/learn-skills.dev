Руководство по разработке обнаружения в Microsoft Sentinel — создание, тестирование, развертывание и поддержка правил аналитики, поисковых запросов и автоматизации SOAR. Охватывает модель решения Content Hub, сопоставление MITRE ATT&CK, аналитику по расписанию, почти в реальном времени (NRT) и Fusion, а также аналитику аномалий, шаблоны обнаружения KQL (объединяет, суммирует, группирует, материализует), сопоставление сущностей и обогащение инцидентов, пользовательские обнаружения из Defender XDR и только Sentinel, правила автоматизации, сборники сценариев (Logic Apps), списки наблюдения, сопоставление данных об угрозах, контент как код с репозиториями Azure DevOps/GitHub. жизненный цикл интеграции и обнаружения (проверка → настройка → версия). КОГДА: правило аналитики Sentinel, обнаружение KQL, сопоставление MITRE, концентратор контента Sentinel, запланированная аналитика, правило NRT, поисковый запрос, правило автоматизации Sentinel, сборник сценариев приложения Logic, пользовательское обнаружение, репозитории Sentinel CI/CD, обнаружение как код, список наблюдения, аналитика сопоставления угроз, объединенные оповещения, аномалии, обогащение инцидентов, сопоставление объектов. НЕ ИСПОЛЬЗУЙТЕ для архитектуры/адаптации Sentinel (используйте Sentinel), только для пользовательских обнаружений Defender XDR (перекрытие — используйте сторону, владеющую данными) или общего обучения KQL.
