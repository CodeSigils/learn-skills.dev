إرشادات لهندسة الكشف في Microsoft Sentinel - إنشاء قواعد التحليلات واختبارها ونشرها وصيانتها، واستعلامات البحث، وأتمتة SOAR. يغطي نموذج حل Content Hub، ورسم خرائط MITRE ATT&CK، والتحليلات المجدولة مقابل الوقت شبه الحقيقي (NRT) مقابل تحليلات Fusion مقابل الحالات الشاذة، وأنماط اكتشاف KQL (الانضمام والتلخيص والحاوية والتجسيد)، ورسم خرائط الكيانات وإثراء الحوادث، والاكتشافات المخصصة من Defender XDR مقابل Sentinel-only، وقواعد التشغيل الآلي، وكتب التشغيل (Logic Apps)، وقوائم المراقبة، ومطابقة المعلومات المتعلقة بالتهديدات، والمحتوى كرمز مع Azure DevOps / GitHub تكامل المستودعات ودورة حياة الكشف (التحقق من صحة → ضبط → الإصدار). متى: قاعدة تحليلات Sentinel، اكتشاف KQL، تعيين MITRE، مركز محتوى Sentinel، التحليلات المجدولة، قاعدة NRT، استعلام البحث، قاعدة أتمتة Sentinel، دليل تطبيق المنطق، الكشف المخصص، المستودعات Sentinel CI/CD، الكشف كرمز، قائمة مراقبة، تحليلات مطابقة معلومات التهديد، تنبيهات الدمج، الحالات الشاذة، إثراء الحادث، تعيين الكيانات. لا تستخدمه في بنية Sentinel/الإعداد (استخدم Sentinel)، أو الاكتشافات المخصصة لـ Defender XDR فقط (التداخل - استخدم الجانب الذي يملك البيانات)، أو تدريب KQL العام.
