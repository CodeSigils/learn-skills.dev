Guía para la ingeniería de detección en Microsoft Sentinel: creación, prueba, implementación y mantenimiento de reglas de análisis, consultas de búsqueda y automatización SOAR. Cubre el modelo de solución Content Hub, mapeo MITRE ATT&CK, análisis programado vs casi en tiempo real (NRT) vs Fusion vs anomalías, patrones de detección KQL (uniones, resumen, agrupación, materialización), mapeo de entidades y enriquecimiento de incidentes, detecciones personalizadas de Defender XDR vs Sentinel-only, reglas de automatización, guías (Logic Apps), listas de vigilancia, coincidencia de información sobre amenazas, contenido como código con integración de repositorios Azure DevOps/GitHub y ciclo de vida de detección. (validar → sintonizar → versión). CUÁNDO: regla de análisis Sentinel, detección KQL, mapeo MITRE, centro de contenido Sentinel, análisis programados, regla NRT, consulta de búsqueda, regla de automatización Sentinel, manual de estrategias de la aplicación lógica, detección personalizada, repositorios Sentinel CI/CD, detección como código, lista de vigilancia, análisis de coincidencia de información sobre amenazas, alertas de fusión, anomalías, enriquecimiento de incidentes, mapeo de entidades. NO LO UTILICE para la arquitectura/incorporación de Sentinel (use sentinel), solo para detecciones personalizadas de Defender XDR (superposición: use el lado propietario de los datos) ni para capacitación genérica de KQL.
