Anleitung zum Entwerfen einer sicheren Azure-Netzwerkarchitektur – Hub-Spoke-Topologie (oder Virtual WAN), Segmentierung mit NSGs/ASGs, private Endpunkte/Private Link für PaaS, Ausgang über Azure Firewall, DDoS-Schutz, WAF auf Front Door/App Gateway und zentralisiertes privates DNS. Ausgerichtet auf die Zero-Trust-Netzwerksäule. WANN: Azure-Netzwerksicherheit, Hub-Spoke, Virtual WAN, Netzwerksegmentierung, NSG-ASG-Design, privater Endpunkt, Private Link, DDoS-Schutz, sicheres virtuelles Netzwerk, Ausgangskontrolle, Zero-Trust-Netzwerk, privates Konnektivitätsdesign, Bastion, JIT-VM-Zugriff. NICHT für die Firewall selbst (verwenden Sie Azure-Firewall), die Härtung auf VM-Ebene (verwenden Sie Defender-for-Cloud-Hardening) oder nur für das Key Vault-Netzwerk (verwenden Sie Azure-Key-Vault) verwenden.
