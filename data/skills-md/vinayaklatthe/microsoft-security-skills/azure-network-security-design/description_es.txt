Orientación para diseñar una arquitectura de red Azure segura: topología radial (o WAN virtual), segmentación con NSG/ASG, puntos finales privados/Private Link para PaaS, salida a través de Azure Firewall, protección DDoS, WAF en Front Door/App Gateway y DNS privado centralizado. Alineado al pilar de la red Zero Trust. CUÁNDO: seguridad de red de Azure, radio central, WAN virtual, segmentación de red, diseño NSG ASG, punto final privado, vínculo privado, protección DDoS, red virtual segura, control de salida, red Zero Trust, diseño de conectividad privada, Bastion, acceso JIT VM. NO LO USE para el firewall en sí (use azure-firewall), el refuerzo a nivel de VM (use defender-for-cloud-hardening) o redes de Key Vault únicamente (use azure-key-vault).
