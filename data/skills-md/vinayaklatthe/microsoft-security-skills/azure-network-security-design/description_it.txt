Linee guida per la progettazione di un'architettura di rete sicura di Azure: topologia hub-spoke (o WAN virtuale), segmentazione con NSG/ASG, endpoint privati/collegamento privato per PaaS, uscita tramite firewall di Azure, protezione DDoS, WAF su front door/gateway app e DNS privato centralizzato. Allineato al pilastro della rete Zero Trust. QUANDO: sicurezza di rete di Azure, hub speak, WAN virtuale, segmentazione di rete, progettazione ASG NSG, endpoint privato, collegamento privato, protezione DDoS, rete virtuale sicura, controllo in uscita, rete Zero Trust, progettazione di connettività privata, Bastion, accesso VM JIT. NON UTILIZZARE per il firewall stesso (usare azure-firewall), per la protezione avanzata a livello di VM (usare Defender-for-Cloud-Harening) o solo per la rete Key Vault (usare azure-key-vault).
