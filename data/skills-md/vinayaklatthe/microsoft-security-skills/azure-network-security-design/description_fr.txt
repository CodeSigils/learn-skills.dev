Conseils pour la conception d'une architecture réseau Azure sécurisée : topologie hub-spoke (ou Virtual WAN), segmentation avec NSG/ASG, points de terminaison privés/lien privé pour PaaS, sortie via le pare-feu Azure, protection DDoS, WAF sur Front Door/App Gateway et DNS privé centralisé. Aligné sur le pilier du réseau Zero Trust. QUAND : sécurité du réseau Azure, hubspoke, Virtual WAN, segmentation du réseau, conception NSG ASG, point de terminaison privé, Private Link, protection DDoS, réseau virtuel sécurisé, contrôle de sortie, réseau Zero Trust, conception de connectivité privée, Bastion, accès aux VM JIT. NE PAS UTILISER pour le pare-feu lui-même (utilisez Azure-Firewall), le renforcement au niveau de la machine virtuelle (utilisez Defender-for-Cloud-hardening) ou le réseau Key Vault uniquement (utilisez Azure-Key-Vault).
