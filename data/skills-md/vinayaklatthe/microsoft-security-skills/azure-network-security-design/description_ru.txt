Руководство по проектированию безопасной сетевой архитектуры Azure — звездчатая топология (или виртуальная глобальная сеть), сегментация с помощью NSG/ASG, частные конечные точки/частный канал для PaaS, выход через брандмауэр Azure, защита от DDoS, WAF на передней двери/шлюзе приложений и централизованный частный DNS. Соответствует принципу сети Zero Trust. КОГДА: сетевая безопасность Azure, распределенный концентратор, виртуальная глобальная сеть, сегментация сети, проектирование NSG ASG, частная конечная точка, частный канал, защита от DDoS, безопасная виртуальная сеть, контроль исходящего трафика, сеть с нулевым доверием, проектирование частного подключения, Bastion, доступ к виртуальной машине JIT. НЕ ИСПОЛЬЗУЙТЕ для самого брандмауэра (используйте azure-firewall), усиления защиты на уровне виртуальной машины (используйте защитник для защиты в облаке) или только для сети Key Vault (используйте azure-key-vault).
