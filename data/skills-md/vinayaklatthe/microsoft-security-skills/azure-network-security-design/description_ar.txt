إرشادات لتصميم بنية شبكة Azure الآمنة - الهيكل المحوري (أو شبكة WAN الافتراضية)، والتجزئة باستخدام NSGs/ASGs، ونقاط النهاية الخاصة / الارتباط الخاص لـ PaaS، والخروج من خلال جدار حماية Azure، وحماية DDoS، وWAF على الباب الأمامي/بوابة التطبيقات، وDNS الخاص المركزي. تتماشى مع ركيزة شبكة الثقة المعدومة. متى: أمان شبكة Azure، المتحدث المحوري، شبكة WAN الافتراضية، تجزئة الشبكة، تصميم NSG ASG، نقطة النهاية الخاصة، الرابط الخاص، حماية DDoS، شبكة افتراضية آمنة، التحكم في الخروج، شبكة Zero Trust، تصميم الاتصال الخاص، Bastion، الوصول إلى JIT VM. لا تستخدمه لجدار الحماية نفسه (استخدم جدار الحماية azure)، أو التعزيز على مستوى الجهاز الافتراضي (استخدم المدافع مقابل التعزيز السحابي)، أو شبكة Key Vault فقط (استخدم azure-key-vault).
