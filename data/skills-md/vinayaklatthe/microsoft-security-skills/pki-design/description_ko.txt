Azure 및 하이브리드 환경에서 PKI(공개 키 인프라) 및 인증서 관리 설계에 대한 지침입니다. CA 전략(오프라인 루트 + 발급 CA, AD CS 대 관리/타사 대 공용 CA), Azure Key Vault 인증서, HSM 키 보호, Entra 인증서 기반 인증(CBA), 인증서 수명 주기(발급, 갱신, 순환, 해지) 및 Intune SCEP/PKCS 배포를 다룹니다. 시기: PKI 설계, 인증 기관, 루트 CA 오프라인, 발급 CA, 인증서 관리, Key Vault 인증서, 인증서 기반 인증, CBA, 인증서 수명 주기, 인증서 발급 및 순환, mTLS 인증서, 코드 서명, CRL OCSP, 인증서 만료, 인증서 순환, AD CS, HSM, 관리형 HSM. Entra ID ID 모델(entra-id 사용) 또는 Key Vault 비밀/키에만 사용하지 마세요(azure-key-vault 사용).
