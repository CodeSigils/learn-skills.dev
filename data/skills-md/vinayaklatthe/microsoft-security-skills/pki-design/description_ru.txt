Руководство по проектированию инфраструктуры открытых ключей (PKI) и управлению сертификатами в Azure и гибридных средах. Охватывает стратегию ЦС (автономный корневой + выдающий ЦС, AD CS против управляемого/стороннего или общедоступного ЦС), сертификаты Azure Key Vault, защиту ключей HSM, аутентификацию на основе сертификатов Entra (CBA), жизненный цикл сертификата (выпуск, обновление, ротация, отзыв) и распространение Intune SCEP/PKCS. КОГДА: проектирование PKI, центр сертификации, корневой центр сертификации в автономном режиме, выдающий центр сертификации, управление сертификатами, сертификаты Key Vault, проверка подлинности на основе сертификатов, CBA, жизненный цикл сертификата, выдача и ротация сертификатов, сертификаты mTLS, подписание кода, CRL OCSP, истечение срока действия сертификата, ротация сертификатов, AD CS, HSM, управляемый HSM. НЕ ИСПОЛЬЗУЙТЕ для модели идентификации Entra ID (используйте entra-id) или только для секретов/ключей Key Vault (используйте azure-key-vault).
