Azure 防火牆指南 — 託管雲端原生 L3-L7 狀態網路防火牆，用於集中出口、東西向和入口控制。涵蓋 SKU 選擇（基本、標準、高級）、防火牆策略層級結構、應用程式/網路/DNAT 規則、威脅情報和 IDPS、TLS 檢查、使用 UDR 的中心輻射部署以及強制隧道。時間：Azure 防火牆、網路防火牆、出口過濾、FQDN 過濾、防火牆策略、IDPS、TLS 檢查、強制隧道、中央網路控制、防火牆 SKU 進階標準基本、中心輻射防火牆、透過防火牆的 UDR、DNAT 入站。請勿用於 L7 Web 應用程式保護（使用前門/應用程式閘道 WAF）、子網路微分段（在 azure-network-security-design 中使用 NSG）或第三方 NVA 設計。
