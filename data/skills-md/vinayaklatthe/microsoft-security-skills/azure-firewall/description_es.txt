Guía para Azure Firewall: firewall de red con estado L3-L7 nativo de la nube administrado para control centralizado de salida, este-oeste y entrada. Cubre la elección de SKU (Básico, Estándar, Premium), jerarquía de políticas de firewall, reglas de aplicaciones/redes/DNAT, inteligencia de amenazas e IDPS, inspección de TLS, implementación de hub-spoke con UDR y tunelización forzada. CUÁNDO: Azure Firewall, firewall de red, filtrado de salida, filtrado FQDN, política de firewall, IDPS, inspección TLS, tunelización forzada, control de red central, firewall SKU Premium Standard Basic, firewall radial, UDR a través del firewall, entrada DNAT. NO LO USE para protección de aplicaciones web L7 (use Front Door/Application Gateway WAF), microsegmentación de subred (use NSG en azure-network-security-design) o diseño NVA de terceros.
