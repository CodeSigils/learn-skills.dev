Azure 防火墙指南 — 托管云原生 L3-L7 状态网络防火墙，用于集中出口、东西向和入口控制。涵盖 SKU 选择（基本、标准、高级）、防火墙策略层次结构、应用程序/网络/DNAT 规则、威胁情报和 IDPS、TLS 检查、使用 UDR 的中心辐射部署以及强制隧道。时间：Azure 防火墙、网络防火墙、出口过滤、FQDN 过滤、防火墙策略、IDPS、TLS 检查、强制隧道、中央网络控制、防火墙 SKU 高级标准基本、中心辐射防火墙、通过防火墙的 UDR、DNAT 入站。请勿用于 L7 Web 应用程序保护（使用前门/应用程序网关 WAF）、子网微分段（在 azure-network-security-design 中使用 NSG）或第三方 NVA 设计。
