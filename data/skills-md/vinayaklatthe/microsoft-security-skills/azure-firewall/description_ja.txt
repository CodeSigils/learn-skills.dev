Azure Firewall のガイダンス — 出口、東西、入口を一元的に制御する、管理されたクラウドネイティブの L3 ～ L7 ステートフル ネットワーク ファイアウォール。 SKU の選択 (Basic、Standard、Premium)、ファイアウォール ポリシー階層、アプリケーション/ネットワーク/DNAT ルール、脅威インテリジェンスと IDPS、TLS インスペクション、UDR を使用したハブスポーク展開、および強制トンネリングをカバーします。対象: Azure ファイアウォール、ネットワーク ファイアウォール、下りフィルタリング、FQDN フィルタリング、ファイアウォール ポリシー、IDPS、TLS インスペクション、強制トンネリング、中央ネットワーク制御、ファイアウォール SKU Premium Standard Basic、ハブ スポーク ファイアウォール、ファイアウォールを介した UDR、DNAT 受信。 L7 Web アプリケーション保護 (Front Door / Application Gateway WAF を使用)、サブネット マイクロセグメンテーション (azure-network-security-design で NSG を使用)、またはサードパーティの NVA 設計には使用しないでください。
