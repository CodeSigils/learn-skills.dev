إرشادات لجدار حماية Azure - جدار حماية شبكة L3-L7 أصلي سحابي مُدار للتحكم في الخروج المركزي والشرق والغرب والدخول. يغطي اختيار SKU (Basic vs Standard vs Premium)، والتسلسل الهرمي لسياسة جدار الحماية، وقواعد التطبيق/الشبكة/DNAT، وذكاء التهديدات وIDPS، وفحص TLS، والنشر المحوري باستخدام UDRs، والنفق القسري. متى: جدار حماية Azure، جدار حماية الشبكة، تصفية الخروج، تصفية FQDN، سياسة جدار الحماية، IDPS، فحص TLS، النفق القسري، التحكم المركزي في الشبكة، جدار الحماية SKU Premium Standard Basic، جدار حماية محوري، UDR من خلال جدار الحماية، DNAT الوارد. لا تستخدمه لحماية تطبيق الويب L7 (استخدم الباب الأمامي / بوابة التطبيق WAF)، أو التجزئة الدقيقة للشبكة الفرعية (استخدم NSGs في تصميم أمان الشبكة azure)، أو تصميم NVA لجهة خارجية.
