Conseils pour le pare-feu Azure : pare-feu réseau géré avec état L3-L7 natif du cloud pour un contrôle centralisé des sorties, est-ouest et des entrées. Couvre le choix du SKU (Basic vs Standard vs Premium), la hiérarchie des politiques de pare-feu, les règles application/réseau/DNAT, les informations sur les menaces et l'IDPS, l'inspection TLS, le déploiement hub-spoke avec UDR et le tunneling forcé. QUAND : Pare-feu Azure, pare-feu réseau, filtrage de sortie, filtrage FQDN, stratégie de pare-feu, IDPS, inspection TLS, tunneling forcé, contrôle réseau central, pare-feu SKU Premium Standard Basic, pare-feu hub-spoke, UDR via pare-feu, DNAT entrant. NE PAS UTILISER pour la protection des applications Web L7 (utilisez Front Door / Application Gateway WAF), la microsegmentation de sous-réseau (utilisez les NSG dans la conception de sécurité réseau Azure) ou la conception NVA tierce.
