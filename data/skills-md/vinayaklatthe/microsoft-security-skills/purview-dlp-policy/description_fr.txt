Couvre les emplacements, les conditions (SIT/étiquettes/classificateurs), les actions classées par niveau de gravité, le mode de simulation, la gestion des exceptions, l'intégration d'Endpoint DLP et le réglage. QUAND : Purview DLP, stratégie de prévention contre la perte de données, prévention de l'exfiltration de données, Endpoint DLP, conditions des règles DLP, mode de simulation DLP, blocage du partage sensible, conseils de stratégie, DLP dans Microsoft 365, réglage des faux positifs DLP.
