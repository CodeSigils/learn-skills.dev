Руководство по карте данных Microsoft Purview — основе, которая сканирует и сопоставляет источники данных в мультиоблачных и локальных средах для обеспечения каталогизации и управления. Охватывает регистрацию источника, среду выполнения интеграции (управляемую или локальную), наборы правил сканирования, классификации, коллекции и контроль затрат. КОГДА: Карта данных Purview, сканирование источников данных, регистрация источника данных, обнаружение данных, среда выполнения интеграции, отображение корпоративных данных, сканирование мультиоблачных данных, классификационное сканирование, коллекции, глоссарий.
