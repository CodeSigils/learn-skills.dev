إرشادات لاستخدام الجانب الأمني لـ Azure Monitor وLog Analytics - تصميم إستراتيجية مساحة العمل التي تغذي Microsoft Sentinel وDefender for Cloud، واختيار التحليلات مقابل طبقات السجل الأساسية مقابل طبقات السجل المساعدة، والاحتفاظ والأرشفة، والتحويلات على مستوى الجدول لإسقاط الضوضاء قبل الاستيعاب، وقواعد جمع البيانات (DCRs) وAzure Monitor Agent (AMA)، وطوبولوجيا مساحة العمل (فردية مقابل إقليمية مقابل سيادية)، ومستويات الالتزام والتحكم في التكاليف، ومفاتيح يديرها العميل لـ مساحة العمل، وRBAC بما في ذلك RBAC على مستوى الجدول، والتكامل مع Sentinel (متطلبات مساحة العمل)، وإيقاف تشغيل MMA القديم. متى: تصميم مساحة عمل Log Analytics، وبيانات أمان Azure Monitor، ومساحة عمل Sentinel، والمساعد الأساسي لطبقة السجل، ووكيل مراقبة AMA Azure، وقاعدة جمع بيانات DCR، وتحويل استيعاب الأعمدة المسقطة، وأرشيف الاحتفاظ بالسجل، وCMK لمساحة العمل، وRBAC على مستوى الجدول، والتحكم في تكلفة استيعاب السجل. لا تستخدمه لتأليف اكتشاف Sentinel (استخدم هندسة اكتشاف الحارس)، أو أدوات App Insights (استخدم أدوات appinsights)، أو إمكانية المراقبة غير الأمنية.
