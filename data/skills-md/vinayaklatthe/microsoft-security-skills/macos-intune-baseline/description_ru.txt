Руководство по усилению защиты конечных точек macOS, управляемых Microsoft Intune — автоматическая регистрация устройств через Apple Business Manager (ABM), единый вход на платформу (PSSO) с Entra ID, условное депонирование шифрования диска FileVault, профили конфигурации безопасности (Gatekeeper, XProtect, список разрешенных системных расширений, брандмауэр, окно входа в систему, контроль политики предпочтений конфиденциальности / PPPC), Microsoft Defender для конечной точки на macOS, управление приложениями (VPP / управляемые приложения / сценарии оболочки через Intune), стратегия исправлений (управляемые обновления программного обеспечения / DDM), сигнал соответствия условному доступу и кросс-платформенная модель идентификации. КОГДА: базовый уровень Mac Intune, усиление защиты macOS Intune, условное депонирование FileVault, ABM Apple Business Manager, единый вход платформы macOS, PSSO Entra, MDE на Mac, Gatekeeper Intune, системные расширения Intune, PPPC Intune, условный доступ, соответствующий требованиям macOS. НЕ ИСПОЛЬЗУЙТЕ для общего комплексного управления устройствами Intune (используйте intune-device-mgmt), только конфигурации MDE (используйте защитник для конечной точки) или управления устройствами iOS.
