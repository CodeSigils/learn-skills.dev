Microsoft Intune によって管理される macOS エンドポイントを強化するためのガイダンス — Apple Business Manager (ABM) による自動デバイス登録、Entra ID によるプラットフォーム シングル サインオン (PSSO)、FileVault ディスク暗号化エスクロー、セキュリティ構成プロファイル (Gatekeeper、XProtect、システム拡張機能のホワイトリスト、ファイアウォール、ログイン ウィンドウ、プライバシー設定ポリシー制御/PPPC)、macOS 上の Microsoft Defender for Endpoint、アプリ管理 (Intune 経由の VPP / マネージド アプリ / シェル スクリプト)、パッチ適用戦略 (マネージド ソフトウェア アップデート/DDM)、条件付きアクセス コンプライアンス シグナル、およびクロスプラットフォーム ID モデル。時期: Mac Intune ベースライン、macOS 強化 Intune、FileVault エスクロー、ABM Apple Business Manager、プラットフォーム SSO macOS、PSSO Entra、Mac 上の MDE、Gatekeeper Intune、システム拡張機能 Intune、PPPC Intune、macOS コンプライアンス条件付きアクセス。一般的な Intune デバイス管理のエンドツーエンド (intune-device-mgmt を使用)、MDE 構成単独 (defender-for-endpoint を使用)、または iOS デバイス管理には使用しないでください。
