Руководство для Microsoft Defender для бизнеса (MDB) — продукта для обеспечения безопасности конечных точек в сегменте SMB (до 300 сотрудников), входящего в состав Microsoft 365 Business Premium и доступного как отдельный номер SKU. Охватывает то, что включено в план 1/2 по сравнению с планом MDE 1/2 (AV нового поколения, EDR с упрощенной конфигурацией, ASR, автоматическое исследование и реагирование, управление уязвимостями, фильтрация веб-контента, уменьшение количества атак, надстройка защиты от мобильных угроз), адаптация с помощью мастера, надстройка сервера для SMB-серверов, упрощенный интерфейс портала по сравнению с полной версией Defender XDR, путь перехода к MDE P2/E5 по мере роста организации и интеграция с Microsoft 365 Lighthouse для доставки MSP. КОГДА: Defender для бизнеса, MDB, безопасность конечных точек SMB, безопасность M365 Business Premium, надстройка сервера MDB, упрощенный EDR для малого бизнеса, MSP Defender для бизнеса, M365 Lighthouse Defender, обновление SMB до MDE Plan 2. НЕ ИСПОЛЬЗУЙТЕ для корпоративного EDR (используйте защитник для конечной точки), межпродуктового исследования Defender XDR (используйте defender-xdr) или Defender для серверов/облака (используйте защитник для серверов).
