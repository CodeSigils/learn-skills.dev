Azure Key Vault 指南 — 使用 RBAC、網路隔離、託管身分存取、軟刪除/清除保護和輪換安全儲存和管理機密、金鑰和憑證。涵蓋何時使用標準 Key Vault 與託管 HSM (FIPS 140-3 Level 3)、每個應用一個保管庫的爆炸半徑原則以及應用服務/功能中的 Key Vault 參考。時間：Azure Key Vault、儲存機密、管理憑證、加密金鑰、機密輪調、Key Vault RBAC、清除保護、軟體刪除、專用終端 Key Vault、託管身分存取機密、託管 HSM、Key Vault 引用、BYOK CMK。請勿用於憑證授權單位設計（使用 pki-design）、僅 entra 應用程式憑證（使用 entra-id）或 PaaS 網路拓撲（使用 azure-network-security-design）。
