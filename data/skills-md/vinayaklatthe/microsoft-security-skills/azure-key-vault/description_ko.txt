Azure Key Vault에 대한 지침 - RBAC, 네트워크 격리, 관리 ID 액세스, 일시 삭제/제거 보호 및 순환을 통해 비밀, 키 및 인증서를 안전하게 저장하고 관리합니다. 표준 Key Vault와 관리형 HSM(FIPS 140-3 수준 3)을 사용하는 경우, 앱당 하나의 자격 증명 모음 폭발 반경 원칙 및 App Service/Functions의 Key Vault 참조를 사용하는 경우를 다룹니다. 시기: Azure Key Vault, 비밀 저장, 인증서 관리, 암호화 키, 비밀 순환, Key Vault RBAC, 제거 보호, 일시 삭제, 프라이빗 엔드포인트 Key Vault, 관리 ID 액세스 비밀, 관리형 HSM, Key Vault 참조, BYOK CMK. 인증 기관 설계(pki-design 사용), entra 앱 자격 증명 전용(entra-id 사용) 또는 PaaS 네트워킹 토폴로지(azure-network-security-design 사용)에는 사용하지 마세요.
