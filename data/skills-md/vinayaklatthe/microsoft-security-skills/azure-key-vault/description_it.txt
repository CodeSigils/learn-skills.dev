Linee guida per Azure Key Vault: archiviazione e gestione sicura di segreti, chiavi e certificati con RBAC, isolamento della rete, accesso alle identità gestite, protezione da eliminazione/eliminazione temporanea e rotazione. Descrive quando usare Key Vault standard rispetto a HSM gestito (FIPS 140-3 livello 3), il principio del raggio di esplosione di un vault per app e i riferimenti a Key Vault nel servizio app/funzioni. QUANDO: Azure Key Vault, archiviazione segreti, gestione certificati, chiavi di crittografia, rotazione dei segreti, RBAC di Key Vault, protezione da eliminazione, eliminazione temporanea, Key Vault endpoint privato, segreti di accesso identità gestite, HSM gestito, riferimenti Key Vault, BYOK CMK. NON UTILIZZARE per la progettazione dell'autorità di certificazione (usare pki-design), solo per le credenziali dell'app entra (usare entra-id) o per la topologia di rete PaaS (usare azure-network-security-design).
