Linee guida per la protezione delle pipeline Infrastructure-as-Code (Bicep, ARM, Terraform e ACI/Container) su Azure: scansione con spostamento a sinistra, policy-as-code, igiene segreta, identità per pipeline, rilevamento della deriva e catena di fornitura. Copre Microsoft Defender per Cloud DevOps Security (connettori GitHub/Azure DevOps), estensione Microsoft Security DevOps (MSDO), specifiche del linter e dei modelli Bicep, best practice Terraform su Azure (gestione dello stato, rafforzamento del backend, versioni del provider), criteri di Azure come gate del tempo di distribuzione e del tempo CI, GitOps con Flux/ArgoCD su AKS, scansione dei segreti e revisione delle dipendenze, commit firmati/firma degli artefatti, federazione OIDC per l'identità della pipeline (nessun client segreti) e l'integrazione con la postura di Defender for Cloud. QUANDO: sicurezza IaC, sicurezza Bicep, sicurezza Terraform Azure, Defender for Cloud DevOps Security, MSDO, Microsoft Security DevOps, spostamento a sinistra Azure, policy come codice, OIDC GitHub Actions Azure, segreti in IaC, rilevamento della deriva, firmato Bicep, supply chain Azure. NON UTILIZZARE solo per il controllo dell'ammissione Kubernetes (utilizzare Defender-for-Containers), la progettazione CI/CD generica o la sicurezza a livello di applicazione.
