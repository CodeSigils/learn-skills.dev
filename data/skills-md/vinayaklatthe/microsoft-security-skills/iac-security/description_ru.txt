Руководство по обеспечению безопасности конвейеров «Инфраструктура как код» (Bicep, ARM, Terraform и ACI/Container) в Azure — сканирование со сдвигом влево, политика как код, секретная гигиена, удостоверение для конвейеров, обнаружение отклонений и цепочка поставок. Охватывает Microsoft Defender для Cloud DevOps Security (разъемы GitHub/Azure DevOps), расширение Microsoft Security DevOps (MSDO), характеристики линтера и шаблонов Bicep, лучшие практики Terraform в Azure (управление состоянием, усиление серверной части, версии поставщиков), политику Azure в качестве шлюза времени развертывания и времени CI, GitOps с Flux/ArgoCD на AKS, секретное сканирование и проверку зависимостей, подписанные фиксации/подпись артефактов, федерацию OIDC для идентификации конвейера (нет) секреты клиента) и интеграцию с Defender for Cloud. КОГДА: безопасность IaC, безопасность Bicep, безопасность Terraform Azure, Defender for Cloud DevOps Security, MSDO, Microsoft Security DevOps, сдвиг влево Azure, политика как код, OIDC GitHub Actions Azure, секреты в IaC, обнаружение отклонений, подписанный Bicep, цепочка поставок Azure. НЕ ИСПОЛЬЗУЙТЕ только для контроля доступа Kubernetes (используйте защитник для контейнеров), общего дизайна CI/CD или безопасности на уровне приложений.
