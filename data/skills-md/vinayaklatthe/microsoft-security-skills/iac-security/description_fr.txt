Conseils pour sécuriser les pipelines Infrastructure-as-Code (Bicep, ARM, Terraform et ACI/Container) sur Azure : analyse par décalage vers la gauche, stratégie en tant que code, hygiène secrète, identité des pipelines, détection des dérives et chaîne d'approvisionnement. Couvre Microsoft Defender pour la sécurité Cloud DevOps (connecteurs GitHub / Azure DevOps), l'extension Microsoft Security DevOps (MSDO), les spécifications du linter et des modèles Bicep, les meilleures pratiques Terraform sur Azure (gestion de l'état, renforcement du backend, versions du fournisseur), Azure Policy en tant que porte temporelle de déploiement et CI, GitOps avec Flux/ArgoCD sur AKS, analyse secrète et examen des dépendances, validations signées/signature d'artefacts, fédération OIDC pour l'identité du pipeline (aucun secret client) et intégration avec la posture Defender pour Cloud. QUAND : sécurité IaC, sécurité Bicep, sécurité Terraform Azure, Defender for Cloud DevOps Security, MSDO, Microsoft Security DevOps, shift-left Azure, stratégie en tant que code, OIDC GitHub Actions Azure, secrets dans IaC, détection de dérive, signé Bicep, chaîne d'approvisionnement Azure. NE PAS UTILISER uniquement pour le contrôle d’admission Kubernetes (utilisez Defender-for-containers), la conception CI/CD générique ou la sécurité de la couche d’application.
