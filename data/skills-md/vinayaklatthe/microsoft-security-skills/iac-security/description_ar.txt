إرشادات لتأمين خطوط أنابيب البنية التحتية كرمز (Bicep، وARM، وTerraform، وACI/Container) على Azure - المسح الضوئي لليسار، والسياسة كرمز، والنظافة السرية، وهوية خطوط الأنابيب، واكتشاف الانجراف، وسلسلة التوريد. يغطي Microsoft Defender لـ Cloud DevOps Security (موصلات GitHub / Azure DevOps)، وملحق Microsoft Security DevOps (MSDO)، وBicep linter ومواصفات القالب، وأفضل ممارسات Terraform على Azure (إدارة الحالة، وتقوية الواجهة الخلفية، وإصدارات الموفر)، وسياسة Azure كوقت النشر وبوابة وقت CI، وGitOps مع Flux/ArgoCD على AKS، والمسح السري ومراجعة التبعية، والالتزامات الموقعة / التوقيع الاصطناعي، OIDC الاتحاد لهوية خطوط الأنابيب (لا توجد أسرار للعميل)، والتكامل مع Defender for Cloud posture. متى: أمان IaC، وأمان Bicep، وأمان Terraform Azure، وDefender for Cloud DevOps Security، وMSDO، وMicrosoft Security DevOps، وshift-left Azure، والسياسة كرمز، وOIDC GitHub Actions Azure، والأسرار في IaC، واكتشاف الانجراف، وBicep الموقعة، وسلسلة التوريد Azure. لا تستخدمه للتحكم في قبول Kubernetes وحده (استخدم المدافع عن الحاويات)، أو تصميم CI/CD العام، أو أمان طبقة التطبيق.
