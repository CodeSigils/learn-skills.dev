Azure 上のコードとしてのインフラストラクチャ (Bicep、ARM、Terraform、ACI/コンテナー) パイプラインをセキュリティで保護するためのガイダンス — シフトレフト スキャン、コードとしてのポリシー、機密衛生管理、パイプラインの ID、ドリフト検出、サプライ チェーン。 Microsoft Defender for Cloud DevOps Security (GitHub / Azure DevOps コネクタ)、Microsoft Security DevOps (MSDO) 拡張機能、Bicep リンターとテンプレート仕様、Azure での Terraform ベスト プラクティス (状態管理、バックエンド強化、プロバイダー バージョン)、デプロイ時および CI 時ゲートとしての Azure Policy、AKS での Flux/ArgoCD を使用した GitOps、シークレット スキャンと依存関係レビュー、署名済みコミット / アーティファクト署名、パイプライン ID のための OIDC フェデレーション (クライアント シークレットなし)、および Defender for Cloud ポスチャとの統合。時期: IaC セキュリティ、Bicep セキュリティ、Terraform Azure セキュリティ、Defender for Cloud DevOps セキュリティ、MSDO、Microsoft Security DevOps、シフトレフト Azure、コードとしてのポリシー、OIDC GitHub Actions Azure、IaC のシークレット、ドリフト検出、署名された Bicep、サプライ チェーン Azure。 Kubernetes アドミッション コントロールのみ (コンテナ用のディフェンダーを使用)、汎用 CI/CD 設計、またはアプリ層セキュリティには使用しないでください。
