Orientación para proteger las canalizaciones de infraestructura como código (Bicep, ARM, Terraform y ACI/Container) en Azure: escaneo con desplazamiento hacia la izquierda, política como código, higiene secreta, identidad para canalizaciones, detección de deriva y cadena de suministro. Cubre Microsoft Defender para Cloud DevOps Security (conectores GitHub/Azure DevOps), extensión Microsoft Security DevOps (MSDO), especificaciones de plantilla y linter de Bicep, prácticas recomendadas de Terraform en Azure (administración de estado, refuerzo de backend, versiones de proveedores), Azure Policy como puerta de tiempo de implementación y de CI, GitOps con Flux/ArgoCD en AKS, escaneo secreto y revisión de dependencias, confirmaciones firmadas/firma de artefactos, federación OIDC para identidad de canalización (sin cliente). secretos) e integración con Defender para la postura en la nube. CUÁNDO: seguridad IaC, seguridad Bicep, seguridad Terraform Azure, Defender for Cloud DevOps Security, MSDO, Microsoft Security DevOps, desplazamiento hacia la izquierda Azure, política como código, OIDC GitHub Actions Azure, secretos en IaC, detección de deriva, Bicep firmado, cadena de suministro Azure. NO LO UTILICE solo para el control de admisión de Kubernetes (use defensor para contenedores), el diseño genérico de CI/CD o la seguridad de la capa de aplicaciones.
