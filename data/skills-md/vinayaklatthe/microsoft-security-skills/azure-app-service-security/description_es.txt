Orientación para proteger las API y las aplicaciones web de Azure App Service: identidad administrada, Easy Auth con Microsoft Entra ID, aislamiento de red a través de puntos de conexión privados + integración de VNet, refuerzo de HTTPS/TLS, referencias de Key Vault para secretos y WAF (puerta principal/puerta de enlace de aplicaciones) de front-end. CUÁNDO: Seguridad de App Service, aplicación web segura en Azure, Easy Auth, identidad administrada de App Service, aplicación web de punto final privado, integración de VNet, App Service TLS, referencias de Key Vault, refuerzo de App Service, desactivación de FTP, WAF frente a App Service, restricciones de acceso. NO LO UTILICE solo para detalles específicos de Azure Functions (similar pero separado), cargas de trabajo de AKS (plataforma diferente) o aplicaciones web alojadas en VM.
