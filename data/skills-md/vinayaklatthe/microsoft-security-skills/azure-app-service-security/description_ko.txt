Azure App Service 웹 앱 및 API 보안을 위한 지침 - 관리형 ID, Microsoft Entra ID를 통한 간편한 인증, 프라이빗 엔드포인트를 통한 네트워크 격리 + VNet 통합, HTTPS/TLS 강화, 비밀에 대한 Key Vault 참조 및 프런트 엔드 WAF(프론트 도어/앱 게이트웨이). 시기: App Service 보안, Azure의 보안 웹앱, 간편한 인증, App Service 관리 ID, 프라이빗 엔드포인트 웹앱, VNet 통합, App Service TLS, Key Vault 참조, App Service 강화, FTP 비활성화, App Service 앞의 WAF, 액세스 제한. Azure Functions 관련 항목(유사하지만 별도), AKS 워크로드(다른 플랫폼) 또는 VM 호스팅 웹앱에만 사용하지 마세요.
