Azure App Service Web アプリと API をセキュリティで保護するためのガイダンス — マネージド ID、Microsoft Entra ID による簡単認証、プライベート エンドポイント + VNet 統合によるネットワーク分離、HTTPS / TLS 強化、シークレット用の Key Vault 参照、およびフロントエンド WAF (フロント ドア / アプリ ゲートウェイ)。いつ: App Service セキュリティ、Azure 上の安全な Web アプリ、Easy Auth、App Service マネージド ID、プライベート エンドポイント Web アプリ、VNet 統合、App Service TLS、Key Vault 参照、App Service の強化、FTP の無効化、App Service の前の WAF、アクセス制限。 Azure Functions の仕様のみ (類似しているが別個)、AKS ワークロード (異なるプラットフォーム)、または VM でホストされる Web アプリには使用しないでください。
