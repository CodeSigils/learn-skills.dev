Anleitung zum Sichern von Azure App Service-Webanwendungen und -APIs – verwaltete Identität, Easy Auth mit Microsoft Entra ID, Netzwerkisolation über private Endpunkte + VNet-Integration, HTTPS/TLS-Härtung, Key Vault-Referenzen für Geheimnisse und Front-End-WAF (Front Door/App Gateway). WANN: App Service-Sicherheit, sichere Web-App auf Azure, Easy Auth, verwaltete App Service-Identität, private Endpunkt-Web-App, VNet-Integration, App Service TLS, Key Vault-Referenzen, App Service härten, FTP-Deaktivierung, WAF vor App Service, Zugriffsbeschränkungen. NICHT nur für Azure Functions-Spezifika (ähnlich, aber getrennt), AKS-Workloads (andere Plattform) oder VM-gehostete Web-Apps verwenden.
