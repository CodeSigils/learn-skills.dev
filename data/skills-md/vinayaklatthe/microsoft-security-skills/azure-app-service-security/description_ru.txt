Руководство по обеспечению безопасности веб-приложений и API Службы приложений Azure — управляемое удостоверение, простая проверка подлинности с помощью Microsoft Entra ID, сетевая изоляция через частные конечные точки + интеграция виртуальной сети, усиление защиты HTTPS/TLS, ссылки на хранилище ключей для секретов и интерфейсный WAF (передняя дверь/шлюз приложений). КОГДА: безопасность службы приложений, безопасное веб-приложение в Azure, простая проверка подлинности, управляемое удостоверение службы приложений, веб-приложение частной конечной точки, интеграция виртуальной сети, TLS службы приложений, ссылки на хранилище ключей, усиление защиты службы приложений, отключение FTP, WAF перед службой приложений, ограничения доступа. НЕ ИСПОЛЬЗУЙТЕ только для конкретных функций Azure (похожих, но отдельных), рабочих нагрузок AKS (другая платформа) или веб-приложений, размещенных на виртуальной машине.
