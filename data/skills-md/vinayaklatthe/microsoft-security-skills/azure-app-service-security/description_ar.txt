إرشادات لتأمين تطبيقات الويب وواجهات برمجة التطبيقات الخاصة بخدمة Azure App Service - الهوية المُدارة، والمصادقة السهلة باستخدام معرف Microsoft Entra، وعزل الشبكة عبر نقاط النهاية الخاصة + تكامل VNet، وتقوية HTTPS / TLS، ومراجع Key Vault للأسرار، وWAF الأمامية (الباب الأمامي / بوابة التطبيقات). متى: أمان خدمة التطبيقات، تطبيق ويب آمن على Azure، Easy Auth، الهوية المُدارة لخدمة التطبيقات، تطبيق ويب نقطة النهاية الخاصة، تكامل VNet، خدمة التطبيقات TLS، مراجع Key Vault، خدمة التطبيقات الصلبة، تعطيل FTP، WAF أمام خدمة التطبيقات، قيود الوصول. لا تستخدمه مع تفاصيل وظائف Azure فقط (مشابهة ولكن منفصلة)، أو أحمال عمل AKS (نظام أساسي مختلف)، أو تطبيقات الويب المستضافة بواسطة جهاز افتراضي.
