Conseils pour sécuriser les applications Web et les API Azure App Service : identité gérée, Easy Auth avec Microsoft Entra ID, isolation du réseau via des points de terminaison privés + intégration de réseau virtuel, renforcement HTTPS/TLS, références Key Vault pour les secrets et WAF frontal (Front Door/App Gateway). QUAND : sécurité App Service, application Web sécurisée sur Azure, Easy Auth, identité managée App Service, application Web de point de terminaison privé, intégration VNet, App Service TLS, références Key Vault, renforcement d'App Service, désactivation FTP, WAF devant App Service, restrictions d'accès. NE PAS UTILISER uniquement pour les spécificités d’Azure Functions (similaires mais distinctes), les charges de travail AKS (plateforme différente) ou les applications Web hébergées par une machine virtuelle.
