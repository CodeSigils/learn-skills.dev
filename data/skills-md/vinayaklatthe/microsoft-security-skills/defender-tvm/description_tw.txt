Microsoft Defender 威脅情報 (Defender TI) 和 Microsoft Defender 漏洞管理 (MDVM) 指南 — Defender XDR 的威脅和漏洞層。涵蓋 MDVM 暴露評分、具有威脅洞察和主動活動的 CVE 優先權、安全基線 (CIS/STIG)、瀏覽器擴充功能和憑證清單、網路共用評估、硬體/韌體清單、安全建議和補救任務（Intune 整合）以及用於對手追蹤指標的 Defender TI、英特爾設定檔、基礎設施樞軸和 MDTI API。時間：Defender 漏洞管理、MDVM、MDVM 附加元件、暴露評分、威脅感知漏洞優先權、CIS 基準 CVE、安全基線評估、瀏覽器擴充清單、韌體漏洞、Microsoft Defender 威脅情報、MDTI、英特爾設定檔、威脅參與者追蹤、IOC 旋轉、MDTI API、英特爾威脅搜尋。請勿用於端點 EDR 設定（使用 Defender-for-Endpoint）、Sentinel 偵測（使用 Sentinel-Detection-engineering）或外部資產發現（使用 Defender-easm）。
