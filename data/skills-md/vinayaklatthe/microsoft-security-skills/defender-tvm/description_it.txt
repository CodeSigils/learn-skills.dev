Linee guida per Microsoft Defender Threat Intelligence (Defender TI) e Microsoft Defender Vulnerability Management (MDVM): il livello di minacce e vulnerabilità di Defender XDR. Copre il punteggio di esposizione MDVM, la definizione delle priorità CVE con approfondimenti sulle minacce e campagne attive, linee di base di sicurezza (CIS/STIG), estensioni del browser e inventario dei certificati, valutazione della condivisione di rete, inventario hardware/firmware, raccomandazioni sulla sicurezza e attività di risoluzione (integrazione di Intune) e Defender TI per indicatori tracciati dagli avversari, profili Intel, rotazione dell'infrastruttura e API MDTI. QUANDO: gestione delle vulnerabilità di Defender, MDVM, componente aggiuntivo MDVM, punteggio di esposizione, definizione delle priorità delle vulnerabilità in base alle minacce, CVE benchmark CIS, valutazione delle linee di base di sicurezza, inventario delle estensioni del browser, vulnerabilità del firmware, Microsoft Defender Threat Intelligence, MDTI, profili Intel, monitoraggio degli attori delle minacce, rotazione IOC, API MDTI, caccia alle minacce con Intel. NON UTILIZZARE per la configurazione EDR dell'endpoint (utilizzare Defender-for-Endpoint), i rilevamenti Sentinel (utilizzare Sentinel-Detection-Engineering) o il rilevamento di risorse esterne (utilizzare Defender-Easm).
