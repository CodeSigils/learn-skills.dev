Microsoft Defender 威胁情报 (Defender TI) 和 Microsoft Defender 漏洞管理 (MDVM) 指南 — Defender XDR 的威胁和漏洞层。涵盖 MDVM 暴露评分、具有威胁洞察和主动活动的 CVE 优先级、安全基线 (CIS/STIG)、浏览器扩展和证书清单、网络共享评估、硬件/固件清单、安全建议和补救任务（Intune 集成）以及用于对手跟踪指标的 Defender TI、英特尔配置文件、基础设施枢轴和 MDTI API。时间：Defender 漏洞管理、MDVM、MDVM 附加组件、暴露评分、威胁感知漏洞优先级、CIS 基准 CVE、安全基线评估、浏览器扩展清单、固件漏洞、Microsoft Defender 威胁情报、MDTI、英特尔配置文件、威胁参与者跟踪、IOC 旋转、MDTI API、英特尔威胁搜寻。请勿用于端点 EDR 配置（使用 Defender-for-Endpoint）、Sentinel 检测（使用 Sentinel-Detection-engineering）或外部资产发现（使用 Defender-easm）。
