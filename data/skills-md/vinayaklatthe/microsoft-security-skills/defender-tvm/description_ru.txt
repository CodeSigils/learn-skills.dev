Руководство по анализу угроз в Microsoft Defender (Defender TI) и управлению уязвимостями в Microsoft Defender (MDVM) — уровне угроз и уязвимостей Defender XDR. Охватывает оценку подверженности MDVM, определение приоритетов CVE с анализом угроз и активными кампаниями, базовые показатели безопасности (CIS/STIG), инвентаризацию расширений браузера и сертификатов, оценку сетевых ресурсов, инвентаризацию аппаратного и встроенного ПО, рекомендации по безопасности и задачи по устранению (интеграция с Intune), а также Defender TI для индикаторов отслеживания злоумышленников, профили разведки, поворот инфраструктуры и API-интерфейсы MDTI. КОГДА: управление уязвимостями в Defender, MDVM, надстройка MDVM, оценка подверженности, приоритезация уязвимостей с учетом угроз, эталонные тесты CVE CIS, оценка базовых показателей безопасности, инвентаризация расширений браузера, уязвимости встроенного ПО, Microsoft Defender Threat Intelligence, MDTI, профили Intel, отслеживание субъектов угроз, поворот IOC, API MDTI, поиск угроз с помощью Intel. НЕ ИСПОЛЬЗУЙТЕ для конфигурации EDR конечной точки (используйте защитник для конечной точки), обнаружения Sentinel (используйте Sentinel-detection-engineering) или обнаружения внешних активов (используйте защитник-easm).
