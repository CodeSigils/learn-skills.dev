Microsoft Defender Threat Intelligence (Defender TI) および Microsoft Defender Vulnerability Management (MDVM) (Defender XDR の脅威と脆弱性レイヤー) に関するガイダンス。 MDVM エクスポージャー スコア、脅威の洞察とアクティブなキャンペーンによる CVE の優先順位付け、セキュリティ ベースライン (CIS/STIG)、ブラウザー拡張機能と証明書インベントリ、ネットワーク共有評価、ハードウェア/ファームウェア インベントリ、セキュリティ推奨事項と修復タスク (Intune 統合)、敵対者追跡インジケーター用の Defender TI、インテル プロファイル、インフラストラクチャ ピボット、MDTI API をカバーします。時期: Defender 脆弱性管理、MDVM、MDVM アドオン、露出スコア、脅威を認識した脆弱性の優先順位付け、CIS ベンチマーク CVE、セキュリティ ベースライン評価、ブラウザー拡張機能インベントリ、ファームウェア脆弱性、Microsoft Defender Threat Intelligence、MDTI、インテル プロファイル、脅威アクター追跡、IOC ピボット、MDTI API、インテルによる脅威ハンティング。エンドポイント EDR 構成 (defender-for-endpoint を使用)、Sentinel 検出 (sentinel-detection-engineering を使用)、または外部資産検出 (defender-easm を使用) には使用しないでください。
