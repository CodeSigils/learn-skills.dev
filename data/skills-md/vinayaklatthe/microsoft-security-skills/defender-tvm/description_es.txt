Guía para Microsoft Defender Threat Intelligence (Defender TI) y Microsoft Defender Vulnerability Management (MDVM): la capa de amenazas y vulnerabilidades de Defender XDR. Cubre la puntuación de exposición a MDVM, la priorización de CVE con información sobre amenazas y campañas activas, líneas de base de seguridad (CIS/STIG), inventario de certificados y extensiones de navegador, evaluación de recursos compartidos de red, inventario de hardware/firmware, recomendaciones de seguridad y tareas de remediación (integración de Intune) y Defender TI para indicadores rastreados por adversarios, perfiles de inteligencia, pivotación de infraestructura y API de MDTI. CUÁNDO: Defender Vulnerability Management, MDVM, complemento MDVM, puntuación de exposición, priorización de vulnerabilidades con reconocimiento de amenazas, CVE de referencia CIS, evaluación de líneas base de seguridad, inventario de extensiones del navegador, vulnerabilidad de firmware, Microsoft Defender Threat Intelligence, MDTI, perfiles de inteligencia, seguimiento de actores de amenazas, pivotación de IOC, API MDTI, búsqueda de amenazas con inteligencia. NO LO UTILICE para la configuración de EDR de endpoints (use defender-for-endpoint), detecciones Sentinel (use ingeniería de detección de centinelas) o descubrimiento de activos externos (use defender-easm).
