Conseils pour Microsoft Defender Threat Intelligence (Defender TI) et Microsoft Defender Vulnerability Management (MDVM) — la couche de menace et de vulnérabilité de Defender XDR. Couvre le score d'exposition MDVM, la priorisation CVE avec informations sur les menaces et campagnes actives, les lignes de base de sécurité (CIS/STIG), l'inventaire des extensions de navigateur et des certificats, l'évaluation du partage réseau, l'inventaire du matériel/micrologiciel, les recommandations de sécurité et les tâches de correction (intégration Intune), et Defender TI pour les indicateurs suivis par les adversaires, les profils Intel, le pivotement de l'infrastructure et les API MDTI. QUAND : Defender Vulnerability Management, MDVM, module complémentaire MDVM, score d'exposition, priorisation des vulnérabilités tenant compte des menaces, CVE de référence CIS, évaluation des bases de sécurité, inventaire des extensions de navigateur, vulnérabilité du micrologiciel, Microsoft Defender Threat Intelligence, MDTI, profils Intel, suivi des acteurs menaçants, pivotement IOC, API MDTI, recherche des menaces avec Intel. NE PAS UTILISER pour la configuration EDR du point de terminaison (utilisez Defender-for-endpoint), les détections Sentinel (utilisez Sentinel-detection-engineering) ou la découverte d'actifs externes (utilisez Defender-easm).
