إرشادات لجدار حماية تطبيق الويب Azure - يتم نشره على Azure Front Door (العالمي، طبقة الحافة) أو بوابة تطبيق Azure (الإقليمية، المتكاملة مع مجموعات الواجهة الخلفية). يغطي تصميم سياسة WAF مع مجموعات القواعد المُدارة (مجموعة القواعد الافتراضية لـ Microsoft، Bot Manager، OWASP CRS)، والقواعد المخصصة (حد المعدل، والحظر الجغرافي، والسماح/رفض IP)، وتصميم الاستبعاد (مهمة الضبط الطويلة التي تقرر ما إذا كان WAF سيبقى في حالة المنع)، وتحدي JSON / CAPTCHA، وتكامل تحليلات السجل، وسير عمل الفرز الإيجابي الكاذب، والتكامل مع Defender for Cloud وSentinel، والمفاضلة الإقليمية مقابل العالمية، والهجرة من جهة خارجية واف. متى: Azure WAF، Front Door WAF، بوابة التطبيق WAF، OWASP CRS Azure، bot manager Azure، قواعد WAF المخصصة، تحديد معدل WAF، الإيجابيات الخاطئة لـ WAF، استثناءات WAF، منع WAF مقابل الاكتشاف، تحدي JSON WAF، الحظر الجغرافي WAF. لا تستخدمه مع DDoS L3/L4 (استخدم حماية azure-ddos)، أو تصميم جدار الحماية Azure (استخدم جدار الحماية azure)، أو أحمال العمل غير HTTP.
