Azure Web 應用程式防火牆指南 — 部署在 Azure 前門（全球、邊緣層）或 Azure 應用程式閘道（區域、與後端池整合）上。涵蓋使用託管規則集（Microsoft 預設規則集、機器人管理器、OWASP CRS）的 WAF 策略設計、自訂規則（速率限制、地理阻止、IP 允許/拒絕）、排除設計（決定 WAF 是否處於預防狀態的長尾調整任務）、JSON 質詢/驗證碼、日誌分析集成、誤報時間：Azure WAF、前門 WAF、應用程式閘道 WAF、OWASP CRS Azure、機器人管理器 Azure、WAF 自訂規則、WAF 速率限制、WAF 誤報、WAF 排除、WAF 預防與偵測、JSON 質疑 WAF、地理封鎖 WAF。請勿用於 L3/L4 DDoS（使用 azure-ddos-protection）、Azure 防火牆設計（使用 azure-firewall）或非 HTTP 工作負載。
