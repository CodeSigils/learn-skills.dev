Leitfaden für Azure Web Application Firewall – bereitgestellt auf Azure Front Door (global, Edge-Tier) oder Azure Application Gateway (regional, integriert mit Back-End-Pools). Behandelt den WAF-Richtlinienentwurf mit verwalteten Regelsätzen (Microsoft Default Rule Set, Bot Manager, OWASP CRS), benutzerdefinierten Regeln (Ratenbegrenzung, geografische Blockierung, IP-Zulassen/-Verweigerung), Ausschlussentwurf (die Long-Tail-Tuning-Aufgabe, die entscheidet, ob WAF in der Prävention verbleibt), JSON-Challenge/CAPTCHA, Protokollanalyseintegration, False-Positive-Triage-Workflow, Integration mit Defender für Cloud und Sentinel, regionaler vs. globaler Kompromiss und Migration von Drittanbieter-WAF. WANN: Azure WAF, Front Door WAF, Application Gateway WAF, OWASP CRS Azure, Bot Manager Azure, benutzerdefinierte WAF-Regeln, WAF-Ratenbegrenzung, WAF-False-Positives, WAF-Ausschlüsse, WAF-Prävention vs. -Erkennung, JSON-Challenge-WAF, Geoblock-WAF. NICHT für L3/L4-DDoS (verwenden Sie azure-ddos-protection), Azure Firewall-Design (verwenden Sie azure-firewall) oder Nicht-HTTP-Workloads verwenden.
