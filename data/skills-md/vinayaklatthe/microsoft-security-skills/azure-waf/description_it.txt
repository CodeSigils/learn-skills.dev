Linee guida per Firewall applicazione Web di Azure: distribuito sulla porta anteriore di Azure (globale, a livello perimetrale) o sul gateway applicazione di Azure (regionale, integrato con pool back-end). Copre la progettazione dei criteri WAF con set di regole gestite (set di regole predefinite di Microsoft, Bot Manager, OWASP CRS), regole personalizzate (limite di velocità, blocco geografico, autorizzazione/rifiuto IP), progettazione dell'esclusione (l'attività di ottimizzazione della coda lunga che decide se WAF rimane in Prevenzione), sfida JSON/CATCHA, integrazione dell'analisi dei log, flusso di lavoro di triage dei falsi positivi, integrazione con Defender per Cloud e Sentinel, compromesso regionale vs globale e migrazione da WAF di terze parti. QUANDO: Azure WAF, Front Door WAF, Application Gateway WAF, OWASP CRS Azure, bot manager Azure, regole personalizzate WAF, limitazione della velocità WAF, falsi positivi WAF, esclusioni WAF, prevenzione e rilevamento WAF, sfida JSON WAF, blocco geografico WAF. NON UTILIZZARE per DDoS L3/L4 (usare azure-ddos-protection), progettazione di firewall di Azure (usare azure-firewall) o carichi di lavoro non HTTP.
