Azure Web アプリケーション ファイアウォールのガイダンス — Azure Front Door (グローバル、エッジ層) または Azure Application Gateway (リージョン、バックエンド プールと統合) にデプロイされます。マネージド ルール セット (Microsoft Default Rule Set、Bot Manager、OWASP CRS)、カスタム ルール (レート制限、地域ブロック、IP 許可/拒否)、除外設計 (WAF を防御状態に維持するかどうかを決定するロングテール調整タスク)、JSON チャレンジ / CAPTCHA、ログ分析の統合、誤検知のトリアージ ワークフロー、Defender for Cloud および Sentinel との統合、地域とグローバルのトレードオフ、サードパーティからの移行を使用した WAF ポリシー設計をカバーします。 WAF。対象: Azure WAF、Front Door WAF、Application Gateway WAF、OWASP CRS Azure、ボット マネージャー Azure、WAF カスタム ルール、WAF レート制限、WAF 誤検知、WAF 除外、WAF の防止と検出、JSON チャレンジ WAF、地域ブロック WAF。 L3/L4 DDoS (azure-ddos-protection を使用)、Azure Firewall 設計 (azure-firewall を使用)、または非 HTTP ワークロードには使用しないでください。
