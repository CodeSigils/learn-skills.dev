Azure Web 应用程序防火墙指南 — 部署在 Azure 前门（全球、边缘层）或 Azure 应用程序网关（区域、与后端池集成）上。涵盖使用托管规则集（Microsoft 默认规则集、机器人管理器、OWASP CRS）的 WAF 策略设计、自定义规则（速率限制、地理阻止、IP 允许/拒绝）、排除设计（决定 WAF 是否处于预防状态的长尾调整任务）、JSON 质询/验证码、日志分析集成、误报分类工作流程、与 Defender for Cloud 和 Sentinel 集成、区域与全球权衡以及从第三方 WAF 迁移。时间：Azure WAF、前门 WAF、应用程序网关 WAF、OWASP CRS Azure、机器人管理器 Azure、WAF 自定义规则、WAF 速率限制、WAF 误报、WAF 排除、WAF 预防与检测、JSON 质询 WAF、地理封锁 WAF。请勿用于 L3/L4 DDoS（使用 azure-ddos-protection）、Azure 防火墙设计（使用 azure-firewall）或非 HTTP 工作负载。
