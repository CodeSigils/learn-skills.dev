Conseils pour Azure Web Application Firewall — déployé sur Azure Front Door (global, niveau Edge) ou Azure Application Gateway (régional, intégré aux pools back-end). Couvre la conception des politiques WAF avec des ensembles de règles gérés (ensemble de règles par défaut Microsoft, Bot Manager, OWASP CRS), les règles personnalisées (limite de débit, géoblocage, autorisation/refus d'adresse IP), la conception d'exclusion (la tâche de réglage à longue traîne qui décide si le WAF reste en prévention), la contestation JSON/CAPTCHA, l'intégration de l'analyse des journaux, le flux de travail de tri des faux positifs, l'intégration avec Defender pour Cloud et Sentinel, le compromis régional/mondial et la migration à partir d'un WAF tiers. QUAND : Azure WAF, Front Door WAF, Application Gateway WAF, OWASP CRS Azure, gestionnaire de bots Azure, règles personnalisées WAF, limitation de débit WAF, faux positifs WAF, exclusions WAF, prévention/détection WAF, défi JSON WAF, géoblocage WAF. NE PAS UTILISER pour les DDoS L3/L4 (utilisez azure-ddos-protection), la conception du pare-feu Azure (utilisez le pare-feu azure) ou les charges de travail non HTTP.
