Guía para Azure Web Application Firewall: implementada en Azure Front Door (global, de nivel perimetral) o Azure Application Gateway (regional, integrado con grupos de backend). Cubre el diseño de políticas WAF con conjuntos de reglas administradas (Conjunto de reglas predeterminadas de Microsoft, Bot Manager, OWASP CRS), reglas personalizadas (límite de velocidad, bloqueo geográfico, permitir/denegar IP), diseño de exclusión (la tarea de ajuste de cola larga que decide si WAF permanece en Prevención), desafío JSON/CAPTCHA, integración de análisis de registros, flujo de trabajo de clasificación de falsos positivos, integración con Defender para Cloud y Sentinel, compensación regional versus global y migración desde WAF de terceros. CUÁNDO: Azure WAF, Front Door WAF, Application Gateway WAF, OWASP CRS Azure, administrador de bots Azure, reglas personalizadas de WAF, limitación de tasa de WAF, falsos positivos de WAF, exclusiones de WAF, prevención versus detección de WAF, WAF de desafío JSON, WAF de bloqueo geográfico. NO LO USE para DDoS L3/L4 (use azure-ddos-protection), diseño de Azure Firewall (use azure-firewall) o cargas de trabajo que no sean HTTP.
