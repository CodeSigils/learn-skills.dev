Руководство по брандмауэру веб-приложений Azure — развертывается на Azure Front Door (глобальном, пограничном уровне) или на шлюзе приложений Azure (региональном, интегрированном с серверными пулами). Охватывает разработку политики WAF с управляемыми наборами правил (набор правил по умолчанию Microsoft, менеджер ботов, OWASP CRS), пользовательские правила (ограничение скорости, геоблокировка, разрешение/запрет IP), дизайн исключений (задача настройки с длинным хвостом, которая решает, останется ли WAF в режиме предотвращения), вызов JSON/CAPTCHA, интеграция аналитики журналов, рабочий процесс сортировки ложноположительных результатов, интеграция с Defender для Cloud и Sentinel, региональный и глобальный компромисс и миграция от сторонних поставщиков. ВАФ. КОГДА: Azure WAF, Front Door WAF, шлюз приложений WAF, OWASP CRS Azure, диспетчер ботов Azure, пользовательские правила WAF, ограничение скорости WAF, ложные срабатывания WAF, исключения WAF, предотвращение или обнаружение WAF, вызов JSON WAF, геоблокировка WAF. НЕ ИСПОЛЬЗУЙТЕ для DDoS-атак L3/L4 (используйте azure-ddos-protection), брандмауэра Azure (используйте azure-firewall) или рабочих нагрузок, отличных от HTTP.
