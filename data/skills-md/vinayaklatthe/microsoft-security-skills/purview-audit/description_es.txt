CUÁNDO: Auditoría de Purview, búsqueda de registros de auditoría, auditoría de Microsoft 365, Auditoría Premium, investigación de la actividad del usuario, retención de registros de auditoría, API de auditoría de Microsoft Graph, registro forense, eventos de auditoría cruciales, MailItemsAccessed.
