Охватывает различия между уровнями, стандартное и расширенное хранение, важные события, пользовательский интерфейс аудита поиска, API Office 365 Management Activity / API аудита Microsoft Graph и интеграцию Sentinel/SIEM. КОГДА: аудит Purview, поиск в журнале аудита, аудит Microsoft 365, аудит Premium, исследование активности пользователей, сохранение журнала аудита, API аудита Microsoft Graph, судебно-медицинское ведение журнала, важные события аудита, MailItemsAccessed.
