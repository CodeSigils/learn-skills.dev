إرشادات لـ Microsoft Purview Audit (القياسي والمميز) - تسجيل نشاط المستخدم/المسؤول والبحث فيه عبر Microsoft 365 لإجراء التحقيقات والامتثال. يغطي اختلافات الطبقة، والاحتفاظ الافتراضي والممتد، والأحداث ذات القيمة العالية، وتجربة بحث التدقيق، وواجهة برمجة تطبيقات نشاط إدارة Office 365 / واجهة برمجة تطبيقات تدقيق Microsoft Graph، وتكامل Sentinel/SIEM. متى: Purview Audit، البحث في سجل التدقيق، تدقيق Microsoft 365، Audit Premium، التحقق من نشاط المستخدم، الاحتفاظ بسجل التدقيق، واجهة برمجة التطبيقات لتدقيق Microsoft Graph، تسجيل الطب الشرعي، أحداث التدقيق المهمة، MailItemsAccessed.
