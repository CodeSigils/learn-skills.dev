Руководство по обнаружению электронных данных Microsoft Purview (унифицированный опыт, объединяющий предыдущие версии Standard и Premium) — выявление, сохранение, сбор, проверка, анализ и экспорт контента в Microsoft 365 для судебных дел, запросов регулирующих органов и расследований. Охватывает дела, хранителей, юридические блокировки, поиски, наборы проверок, аналитику и экспорт. КОГДА: обнаружение электронных данных, юридическое удержание, сохранение контента, сбор для судебного разбирательства, набор проверки, экспорт доказательств, дело об обнаружении электронных данных, хранитель, поиск и хранение Microsoft 365, юридическое расследование, рабочий процесс EDRM, обоснованный сбор.
