إرشادات لـ Microsoft Purview eDiscovery (تجربة موحدة لدمج Standard وPremium السابقين) - تحديد المحتوى وحفظه وجمعه ومراجعته وتحليله وتصديره عبر Microsoft 365 للقضايا القانونية والطلبات التنظيمية والتحقيقات. يغطي الحالات والأوصياء والاحتجاز القانوني وعمليات البحث ومجموعات المراجعة والتحليلات والتصدير. متى: eDiscovery، الحجز القانوني، الاحتفاظ بالمحتوى، التجميع للتقاضي، مجموعة المراجعة، تصدير الأدلة، حالة eDiscovery، الوصي، البحث والاحتفاظ بـ Microsoft 365، التحقيق القانوني، سير عمل EDRM، المجموعة التي يمكن الدفاع عنها.
