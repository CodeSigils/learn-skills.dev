إرشادات لمعيار Microsoft Cloud Security Benchmark (MCSB) — مجموعة Microsoft الأساسية من عناصر التحكم لأفضل ممارسات الأمان السحابي التي تم تعيينها لأطر عمل الصناعة ومراقبتها في Microsoft Defender for Cloud. يغطي مجالات التحكم، وتطبيق المعيار، وتتبع الامتثال. متى: Microsoft Cloud Security Benchmark، MCSB، Azure Security Benchmark، عناصر التحكم الأساسية للأمان، تعيين CIS NIST، الامتثال التنظيمي لـ Defender for Cloud، أفضل ممارسات الأمان السحابي، إطار عمل الضوابط الأمنية.
