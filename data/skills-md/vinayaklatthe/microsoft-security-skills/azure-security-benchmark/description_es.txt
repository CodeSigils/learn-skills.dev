Guía para Microsoft Cloud Security Benchmark (MCSB): el conjunto canónico de controles de mejores prácticas de seguridad en la nube de Microsoft asignados a marcos de la industria y monitoreados en Microsoft Defender para la nube. Cubre los dominios de control, la aplicación del punto de referencia y el seguimiento del cumplimiento. CUÁNDO: Microsoft Cloud Security Benchmark, MCSB, Azure Security Benchmark, controles básicos de seguridad, mapeo CIS NIST, cumplimiento normativo de Defender for Cloud, mejores prácticas de seguridad en la nube, marco de controles de seguridad.
