Leitfaden für den Microsoft Cloud Security Benchmark (MCSB) – Microsofts kanonischer Satz von Best-Practice-Kontrollen für die Cloud-Sicherheit, die Branchen-Frameworks zugeordnet und in Microsoft Defender for Cloud überwacht werden. Deckt Kontrollbereiche, die Anwendung des Benchmarks und die Compliance-Verfolgung ab. WANN: Microsoft Cloud Security Benchmark, MCSB, Azure Security Benchmark, Sicherheitsgrundlinienkontrollen, CIS NIST-Zuordnung, Defender for Cloud-Konformität mit gesetzlichen Bestimmungen, Best Practices für Cloud-Sicherheit, Sicherheitskontroll-Framework.
