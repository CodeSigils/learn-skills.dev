Conseils pour le Microsoft Cloud Security Benchmark (MCSB) : ensemble canonique de contrôles de bonnes pratiques de sécurité cloud de Microsoft, mappés aux cadres du secteur et surveillés dans Microsoft Defender for Cloud. Couvre les domaines de contrôle, l’application du benchmark et le suivi de la conformité. QUAND : Microsoft Cloud Security Benchmark, MCSB, Azure Security Benchmark, contrôles de base de sécurité, mappage CIS NIST, conformité réglementaire Defender for Cloud, meilleures pratiques de sécurité cloud, cadre de contrôles de sécurité.
