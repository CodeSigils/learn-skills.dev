Руководство по тесту Microsoft Cloud Security Benchmark (MCSB) — канонический набор передовых методов управления облачной безопасностью Microsoft, сопоставленный с отраслевыми платформами и отслеживаемый в Microsoft Defender для облака. Охватывает области управления, применение тестов и отслеживание соответствия. КОГДА: Microsoft Cloud Security Benchmark, MCSB, Azure Security Benchmark, базовые элементы управления безопасностью, сопоставление CIS NIST, соответствие нормативным требованиям Defender for Cloud, передовые методы облачной безопасности, структура контроля безопасности.
