Руководство по безопасности контента Azure AI — программная модерация контента для текста, изображений, мультимодальных и генеративных ограждений AI. Охватывает категории безопасности контента (ненависть, насилие, сексуальное насилие, членовредительство) с уровнями серьезности, Prompt Shields для взлома и непрямого обнаружения быстрого внедрения, обнаружение обоснованности (проверка галлюцинаций или источники заземления), обнаружение защищенных материалов (текст и код), пользовательские категории, черные списки, Content Safety Studio для настройки, интеграция с Azure OpenAI в качестве фильтров ввода/вывода (встроенные плюс настраиваемые), компромиссы между задержкой и стоимостью, защитные ограждения агентов и шаблоны развертывания (коляска в приложении, интегрированная с Azure).
