إرشادات لسلامة محتوى Azure AI - الإشراف الآلي على المحتوى للنصوص والصور والوسائط المتعددة وحواجز حماية الذكاء الاصطناعي التوليدية. يغطي فئات أمان المحتوى (الكراهية، والعنف، والجنس، وإيذاء النفس) مع مستويات الخطورة، والدروع الفورية لكسر الحماية والكشف الفوري غير المباشر، واكتشاف التأريض (فحص الهلوسة مقابل مصادر التأريض)، واكتشاف المواد المحمية (النص والتعليمات البرمجية)، والفئات المخصصة، وقوائم الحظر، واستوديو أمان المحتوى للضبط، والتكامل مع Azure OpenAI كمرشحات الإدخال/الإخراج (مدمجة بالإضافة إلى مخصص)، ومقايضات زمن الوصول/التكلفة، وحواجز حماية الوكيل، وأنماط النشر (السيارة الجانبية في التطبيق، المدمجة) مع Azure OpenAI). متى: سلامة محتوى Azure AI، والدروع الفورية، واكتشاف كسر الحماية، والحقن السريع غير المباشر، والتحقق من التأريض، والكشف عن المواد المحمية، والإشراف على المحتوى، وحواجز حماية الذكاء الاصطناعي التوليدية، وفئات المحتوى الضار، وقائمة الحظر المخصصة AI، وحواجز حماية الوكيل. لا تستخدمه للكشف عن تهديدات أعباء عمل الذكاء الاصطناعي / تنبيهات SOC (استخدم المدافع مقابل السحابة ai)، أو إدارة استخدام الذكاء الاصطناعي للمستخدم النهائي (استخدم Purview-ai-hub)، أو تصميم تطبيق الذكاء الاصطناعي العام الذي لا علاقة له بالسلامة.
