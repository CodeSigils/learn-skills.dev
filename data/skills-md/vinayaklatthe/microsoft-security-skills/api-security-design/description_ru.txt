Руководство по разработке безопасных API в Azure — аутентификация, авторизация, элементы управления шлюзом, проверка входных данных, ограничение скорости, управление секретами и обнаружение угроз во время выполнения — в соответствии с 10 основными правилами безопасности API OWASP и управлением API Azure. КОГДА: разработка безопасности API, безопасный API, топ-10 OWASP API, аутентификация API, безопасность шлюза API, ограничение скорости, проверка JWT, защита серверного API, политики безопасности управления API, безопасная архитектура API, BOLA, BFLA. НЕ ИСПОЛЬЗУЙТЕ для общей безопасности приложений или проектирования веб-приложений (используйте архитектуру безопасности/моделирование угроз) или только для обнаружения во время выполнения API (используйте защитник для API).
