Linee guida per la progettazione di API sicure su Azure: autenticazione, autorizzazione, controlli gateway, convalida dell'input, limitazione della velocità, gestione dei segreti e rilevamento delle minacce in fase di esecuzione, allineate alla Top 10 di sicurezza API OWASP e alla gestione API di Azure. QUANDO: progettazione della sicurezza API, API sicura, API OWASP Top 10, autenticazione API, sicurezza del gateway API, limitazione della velocità, convalida JWT, protezione dell'API backend, policy di sicurezza di gestione API, architettura API sicura, BOLA, BFLA. NON UTILIZZARE per la sicurezza generale delle applicazioni o la progettazione di app Web (utilizzare architettura di sicurezza/modellazione delle minacce) o solo per il rilevamento del runtime API (utilizzare Defender-for-Apis).
