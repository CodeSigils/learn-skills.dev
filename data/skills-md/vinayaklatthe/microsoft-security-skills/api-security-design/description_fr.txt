Conseils pour la conception d'API sécurisées sur Azure - authentification, autorisation, contrôles de passerelle, validation des entrées, limitation de débit, gestion des secrets et détection des menaces d'exécution - alignés sur OWASP API Security Top 10 et Azure API Management. QUAND : conception de la sécurité des API, API sécurisée, OWASP API Top 10, authentification API, sécurité de la passerelle API, limitation de débit, validation de JWT, protection de l'API backend, politiques de sécurité de gestion des API, architecture API sécurisée, BOLA, BFLA. NE PAS UTILISER pour la sécurité générale des applications ou la conception d'applications Web (utilisez l'architecture de sécurité/modélisation des menaces) ou pour la détection de l'exécution de l'API uniquement (utilisez Defender-for-apis).
