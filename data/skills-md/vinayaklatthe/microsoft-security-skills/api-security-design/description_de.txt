Anleitung zum Entwerfen sicherer APIs in Azure – Authentifizierung, Autorisierung, Gateway-Kontrollen, Eingabevalidierung, Ratenbegrenzung, Geheimverwaltung und Bedrohungserkennung zur Laufzeit – abgestimmt auf OWASP API Security Top 10 und Azure API Management. WANN: API-Sicherheitsdesign, sichere API, OWASP API Top 10, API-Authentifizierung, API-Gateway-Sicherheit, Ratenbegrenzung, Validierung von JWT, Schutz der Backend-API, API-Management-Sicherheitsrichtlinien, sichere API-Architektur, BOLA, BFLA. NICHT für allgemeine Anwendungssicherheit oder Web-App-Design verwenden (Sicherheitsarchitektur/Bedrohungsmodellierung verwenden) oder nur zur API-Laufzeiterkennung (Verteidiger für APIs verwenden).
