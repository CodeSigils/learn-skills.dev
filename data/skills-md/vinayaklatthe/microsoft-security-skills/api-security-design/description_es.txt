Guía para diseñar API seguras en Azure (autenticación, autorización, controles de puerta de enlace, validación de entradas, limitación de velocidad, administración de secretos y detección de amenazas en tiempo de ejecución) alineadas con OWASP API Security Top 10 y Azure API Management. CUÁNDO: diseño de seguridad de API, API segura, OWASP API Top 10, autenticación de API, seguridad de puerta de enlace de API, limitación de velocidad, validación de JWT, protección de API de backend, políticas de seguridad de gestión de API, arquitectura de API segura, BOLA, BFLA. NO LO UTILICE para seguridad general de aplicaciones o diseño de aplicaciones web (use arquitectura de seguridad/modelado de amenazas) o solo para detección de tiempo de ejecución de API (use defender-for-apis).
