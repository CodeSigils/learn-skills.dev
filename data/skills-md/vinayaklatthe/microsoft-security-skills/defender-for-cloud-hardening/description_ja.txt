Microsoft Defender for Cloud のガイダンス — Azure、AWS、GCP にわたるクラウド セキュリティ体制管理 (CSPM) とクラウド ワークロード保護 (CWPP)。 Foundational と Defender の CSPM、セキュア スコア、Defender プラン (サーバー、ストレージ、コンテナー、データベース、App Service、Key Vault、API、AI)、エージェントレス スキャン、攻撃パス分析、修復の優先順位付けをカバーします。時期: Defender for Cloud、CSPM、クラウド ワークロード保護、セキュア スコア、クラウド ポスチャの強化、Defender 計画、攻撃パス分析、マルチクラウド セキュリティ、推奨事項の修復、クラウド セキュリティの強化、Azure セキュア スコアの向上、Azure サブスクリプションの強化、VM とコンテナの保護、AWS および GCP にわたるマルチクラウド CSPM、クラウド セキュリティ グラフ。 SaaS ポスチャ (cloud-app-security-posture を使用)、Sentinel SIEM (sentinel を使用)、または Azure をオンプレミス サーバーに拡張する (azure-arc を使用) には使用しないでください。
