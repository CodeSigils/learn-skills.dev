Microsoft Defender for Cloud 指南 - 跨 Azure、AWS 和 GCP 的雲端安全態勢管理 (CSPM) 和雲端工作負載保護 (CWPP)。涵蓋 Foundational 與 Defender CSPM、安全分數、Defender 計畫（伺服器、儲存、容器、資料庫、應用服務、Key Vault、API、AI）、無代理掃描、攻擊路徑分析和修復優先順序。時間：Defender for Cloud、CSPM、雲端工作負載保護、安全性評分、強化雲端態勢、Defender 計畫、攻擊路徑分析、多雲安全性、修復建議、雲端安全性強化、提高 Azure 安全性評分、強化 Azure 訂閱、保護虛擬機器和容器、跨 AWS 和 GCP 的多雲 CSPM、雲端安全圖。請勿用於 SaaS 狀態（使用 cloud-app-security-position）、Sentinel SIEM（使用 Sentinel）或將 Azure 擴展到本機伺服器（使用 azure-arc）。
