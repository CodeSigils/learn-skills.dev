Руководство по Microsoft Defender для облака — управление состоянием безопасности облака (CSPM) и защита облачных рабочих нагрузок (CWPP) в Azure, AWS и GCP. Охватывает базовый CSPM по сравнению с Defender, Secure Score, планы Defender (серверы, хранилище, контейнеры, базы данных, служба приложений, хранилище ключей, API, искусственный интеллект), безагентное сканирование, анализ путей атак и определение приоритетов исправлений. КОГДА: Defender для облака, CSPM, защита облачных рабочих нагрузок, Secure Score, усиление состояния облака, планы Defender, анализ путей атак, многооблачная безопасность, рекомендации по устранению, усиление облачной безопасности, улучшение Azure Secure Score, усиление подписки Azure, защита виртуальных машин и контейнеров, мультиоблачный CSPM в AWS и GCP, график облачной безопасности. НЕ ИСПОЛЬЗУЙТЕ для SaaS-позиции (используйте Cloud-App-Security-Posture), Sentinel SIEM (используйте Sentinel) или расширения Azure на локальные серверы (используйте azure-arc).
