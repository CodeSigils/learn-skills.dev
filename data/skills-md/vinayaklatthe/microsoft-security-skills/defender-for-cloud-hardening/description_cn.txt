Microsoft Defender for Cloud 指南 - 跨 Azure、AWS 和 GCP 的云安全态势管理 (CSPM) 和云工作负载保护 (CWPP)。涵盖 Foundational 与 Defender CSPM、安全分数、Defender 计划（服务器、存储、容器、数据库、应用服务、Key Vault、API、AI）、无代理扫描、攻击路径分析和修复优先级。时间：Defender for Cloud、CSPM、云工作负载保护、安全评分、强化云态势、Defender 计划、攻击路径分析、多云安全、修复建议、云安全强化、提高 Azure 安全评分、强化 Azure 订阅、保护虚拟机和容器、跨 AWS 和 GCP 的多云 CSPM、云安全图。请勿用于 SaaS 状态（使用 cloud-app-security-position）、Sentinel SIEM（使用 Sentinel）或将 Azure 扩展到本地服务器（使用 azure-arc）。
