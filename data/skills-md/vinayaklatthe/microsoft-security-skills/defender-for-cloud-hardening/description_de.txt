Leitfaden für Microsoft Defender für Cloud – Cloud Security Posture Management (CSPM) und Cloud Workload Protection (CWPP) in Azure, AWS und GCP. Deckt Foundational vs. Defender CSPM, Secure Score, Defender-Pläne (Server, Speicher, Container, Datenbanken, App Service, Key Vault, APIs, KI), agentenloses Scannen, Angriffspfadanalyse und Behebungspriorisierung ab. WANN: Defender für Cloud, CSPM, Cloud-Workload-Schutz, Secure Score, Cloud-Status härten, Defender-Pläne, Angriffspfadanalyse, Multicloud-Sicherheit, Behebungsempfehlungen, Cloud-Sicherheitshärtung, Azure Secure Score verbessern, Azure-Abonnement härten, VMs und Container schützen, Multicloud-CSPM über AWS und GCP, Cloud-Sicherheitsdiagramm. NICHT für SaaS-Status (verwenden Sie cloud-app-security-posture), Sentinel SIEM (verwenden Sie Sentinel) oder die Erweiterung von Azure auf lokale Server (verwenden Sie azure-arc) verwenden.
