Microsoft Defender XDR 指南 — 統一的擴充功能偵測和回應套件，可將端點、身分、電子郵件和雲端應用程式之間的訊號關聯到具有攻擊圖上下文的優先事件中。涵蓋四個核心工作負載、事件調查、KQL 中的進階搜尋、自訂偵測規則、自動攻擊中斷、AIR 和統一 RBAC。時間：Microsoft Defender XDR、XDR 事件調查、跨工作負載關聯警報、進階搜尋 KQL、自動攻擊中斷、AIR、Defender 入口網站事件、跨網域偵測、如何調查跨多個 Microsoft 365 產品的攻擊、跨終點和身分的警報關聯、統一事件檢視、攻擊圖、自訂偵測規則、統一 RBAC。當需要從第三方來源取得 SIEM 日誌或自訂 KQL 偵測（使用 Sentinel）、將 Sentinel 合併至 Defender 入口網站（使用 Unified-secops-platform）或僅限端點的 EDR（使用 Defender-for-endpoint）時，請勿使用。
