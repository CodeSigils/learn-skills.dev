Руководство для Microsoft Defender XDR — унифицированного расширенного пакета обнаружения и реагирования, который сопоставляет сигналы между конечными точками, удостоверениями, электронной почтой и облачными приложениями с приоритетными инцидентами с контекстом графа атак. Охватывает внедрение четырех основных рабочих нагрузок, расследование инцидентов, расширенный поиск в KQL, настраиваемые правила обнаружения, автоматическое прекращение атак, AIR и унифицированный RBAC. КОГДА: Microsoft Defender XDR, расследование инцидентов XDR, корреляция оповещений по рабочим нагрузкам, расширенный поиск KQL, автоматическое прерывание атак, AIR, инциденты на портале Defender, междоменное обнаружение, как расследовать атаки на несколько продуктов Microsoft 365, корреляция оповещений между конечной точкой и удостоверением, единое представление инцидентов, график атак, настраиваемое правило обнаружения, унифицированный RBAC. НЕ ИСПОЛЬЗУЙТЕ, когда требуется прием журналов SIEM или пользовательское обнаружение KQL из сторонних источников (используйте Sentinel), объединение Sentinel с порталом Defender (используйте единую платформу Secops) или EDR только для конечных точек (используйте Defender для конечной точки).
