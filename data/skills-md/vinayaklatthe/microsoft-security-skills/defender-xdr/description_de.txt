Leitfaden für Microsoft Defender Umfasst das Onboarding der vier Kernarbeitslasten, die Untersuchung von Vorfällen, die erweiterte Suche in KQL, benutzerdefinierte Erkennungsregeln, die automatische Angriffsunterbrechung, AIR und einheitliches RBAC. WANN: Microsoft Defender NICHT VERWENDEN, wenn die Aufnahme von SIEM-Protokollen oder benutzerdefinierte KQL-Erkennungen von Drittanbieterquellen (Verwenden Sie Sentinel), das Zusammenführen von Sentinel mit dem Defender-Portal (Verwenden Sie die Unified-Secops-Plattform) oder EDR nur für den Endpunkt (Verwenden Sie Defender-for-Endpoint) erforderlich sind.
