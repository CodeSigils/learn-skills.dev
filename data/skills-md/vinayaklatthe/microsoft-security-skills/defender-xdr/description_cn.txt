Microsoft Defender XDR 指南 — 统一的扩展检测和响应套件，可将端点、身份、电子邮件和云应用程序之间的信号关联到具有攻击图上下文的优先事件中。涵盖四个核心工作负载、事件调查、KQL 中的高级搜索、自定义检测规则、自动攻击中断、AIR 和统一 RBAC。时间：Microsoft Defender XDR、XDR 事件调查、跨工作负载关联警报、高级搜寻 KQL、自动攻击中断、AIR、Defender 门户事件、跨域检测、如何调查跨多个 Microsoft 365 产品的攻击、跨终结点和身份的警报关联、统一事件视图、攻击图、自定义检测规则、统一 RBAC。当需要从第三方源获取 SIEM 日志或自定义 KQL 检测（使用 Sentinel）、将 Sentinel 合并到 Defender 门户（使用 Unified-secops-platform）或仅限端点的 EDR（使用 Defender-for-endpoint）时，请勿使用。
