Microsoft Defender XDR のガイダンス — エンドポイント、ID、電子メール、クラウド アプリにわたるシグナルを、攻撃グラフのコンテキストを使用して優先順位付けされたインシデントに関連付ける、統合された拡張検出および対応スイートです。 4 つのコア ワークロードのオンボーディング、インシデント調査、KQL での高度なハンティング、カスタム検出ルール、自動攻撃中断、AIR、および統合 RBAC について説明します。時期: Microsoft Defender XDR、XDR インシデント調査、ワークロード間のアラートの関連付け、高度なハンティング KQL、自動攻撃中断、AIR、Defender ポータル インシデント、クロスドメイン検出、複数の Microsoft 365 製品にわたる攻撃を調査する方法、エンドポイントと ID 間のアラートの関連付け、統合インシデント ビュー、攻撃グラフ、カスタム検出ルール、統合 RBAC。サードパーティ ソースからの SIEM ログの取り込みやカスタム KQL 検出 (sentinel を使用)、Sentinel の Defender ポータルへのマージ (統合セコプス プラットフォームを使用)、またはエンドポイントのみの EDR (defender-for-endpoint を使用) が必要な場合は使用しないでください。
