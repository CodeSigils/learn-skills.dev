Conseils pour Microsoft Defender XDR — la suite étendue unifiée de détection et de réponse qui corrèle les signaux sur les points de terminaison, les identités, la messagerie électronique et les applications cloud en incidents prioritaires avec un contexte de graphique d'attaque. Couvre l'intégration des quatre charges de travail principales, l'enquête sur les incidents, la recherche avancée dans KQL, les règles de détection personnalisées, l'interruption automatique des attaques, AIR et RBAC unifié. QUAND : Microsoft Defender XDR, enquête sur les incidents XDR, corrélation des alertes entre les charges de travail, recherche avancée KQL, interruption automatique des attaques, AIR, incidents du portail Defender, détection inter-domaines, comment enquêter sur une attaque sur plusieurs produits Microsoft 365, corrélation des alertes entre le point de terminaison et l'identité, vue unifiée des incidents, graphique d'attaque, règle de détection personnalisée, RBAC unifié. NE PAS UTILISER lorsque le besoin est l'ingestion de journaux SIEM ou les détections KQL personnalisées à partir de sources tierces (utiliser sentinel), la fusion de Sentinel dans le portail Defender (utiliser la plateforme unifiée-secops) ou l'EDR pour le point de terminaison uniquement (utiliser le défenseur pour le point de terminaison).
