إرشادات لـ Microsoft Defender XDR - مجموعة الكشف والاستجابة الموسعة الموحدة التي تربط الإشارات عبر نقاط النهاية والهويات والبريد الإلكتروني والتطبيقات السحابية بالحوادث ذات الأولوية مع سياق الرسم البياني للهجوم. يغطي تأهيل أعباء العمل الأربعة الأساسية، والتحقيق في الحوادث، والصيد المتقدم في KQL، وقواعد الكشف المخصصة، وتعطيل الهجوم التلقائي، وAIR، وRBAC الموحد. متى: Microsoft Defender XDR، التحقيق في حوادث XDR، ربط التنبيهات عبر أعباء العمل، البحث المتقدم KQL، تعطيل الهجوم التلقائي، AIR، حوادث مدخل Defender، الاكتشاف عبر المجال، كيف يمكنني التحقيق في هجوم عبر منتجات Microsoft 365 المتعددة، ارتباط التنبيه عبر نقطة النهاية والهوية، عرض موحد للحادث، رسم بياني للهجوم، قاعدة الكشف المخصصة، RBAC موحد. لا تستخدمه عندما تكون الحاجة إلى استيعاب سجل SIEM أو اكتشافات KQL المخصصة من مصادر خارجية (استخدم Sentinel)، أو دمج Sentinel في بوابة Defender (استخدم النظام الأساسي الموحد secops)، أو EDR لنقطة النهاية فقط (استخدم المدافع مقابل نقطة النهاية).
