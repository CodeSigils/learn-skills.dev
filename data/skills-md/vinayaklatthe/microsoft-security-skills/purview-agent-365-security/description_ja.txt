Microsoft Purview を使用して AI エージェント (Microsoft 365 Copilot エージェント、Copilot Studio エージェント、および Security Copilot エージェント) を保護および管理するためのガイダンス - AI、DLP、機密ラベル、通信コンプライアンス、監査とエージェントのデータ対話と ID に DSPM を適用します。いつ: AI エージェントの保護、Copilot エージェントの管理、エージェントの Purview、エージェント データ セキュリティ、エージェントの DLP、エージェント インタラクションの監査、Copilot Studio エージェント セキュリティ、エージェントの過剰共有、エージェントのコンプライアンス、エージェント ID ガバナンス。
