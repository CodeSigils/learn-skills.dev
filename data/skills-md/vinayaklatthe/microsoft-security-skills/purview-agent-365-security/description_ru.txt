Руководство по обеспечению безопасности и управлению агентами искусственного интеллекта (агенты Microsoft 365 Copilot, агенты Copilot Studio и агенты Security Copilot) с помощью Microsoft Purview — применение DSPM для искусственного интеллекта, DLP, меток конфиденциальности, соответствия требованиям связи и аудита взаимодействия агентов с данными и удостоверений. КОГДА: защита агентов ИИ, управление агентами Copilot, Purview для агентов, безопасность данных агентов, DLP для агентов, аудит взаимодействия агентов, безопасность агентов Copilot Studio, совместное использование агентов, соответствие требованиям агентов, управление идентификацией агентов.
