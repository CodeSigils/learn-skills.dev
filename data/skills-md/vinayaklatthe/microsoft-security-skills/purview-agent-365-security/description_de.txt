Anleitung zum Sichern und Steuern von KI-Agenten (Microsoft 365 Copilot-Agenten, Copilot Studio-Agenten und Security Copilot-Agenten) mit Microsoft Purview – Anwenden von DSPM für KI, DLP, Vertraulichkeitsbezeichnungen, Kommunikationscompliance und Prüfung auf Agentendateninteraktionen und -identitäten. WANN: KI-Agenten sichern, Copilot-Agenten verwalten, Purview für Agenten, Agentendatensicherheit, DLP für Agenten, Agenteninteraktionen prüfen, Copilot Studio-Agentensicherheit, Agenten-Oversharing, Agenten-Compliance, Agentenidentitäts-Governance.
