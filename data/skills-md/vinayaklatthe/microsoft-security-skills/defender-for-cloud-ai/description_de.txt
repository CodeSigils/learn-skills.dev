Leitfaden für Microsoft Defender für Cloud – KI-Workload-Schutz (AI-SPM und Laufzeitbedrohungserkennung für generative KI). Deckt das KI-Sicherheitsstatusmanagement ab (Erkennung von Azure OpenAI-/Azure AI Foundry-/Amazon Bedrock-/Google Vertex-KI-Ressourcen, Identifizierung der Gefährdung von Grunddaten, Modellbereitstellungsstatus), Laufzeitbedrohungserkennung auf Azure OpenAI (prompte Injektions-/Jailbreak-Versuche, Verlust vertraulicher Daten in Eingabeaufforderungen/Antworten, Wallet-Missbrauch, Verlust von Anmeldeinformationen), Integration mit Azure AI Content Safety Prompt Shields, Angriffspfadanalyse für KI-Workloads, Warnungsuntersuchung in Defender XDR und Kopplung mit Purview DSPM für AI (Benutzerseite) und Azure AI Content Safety (Modellseite). WANN: Defender für Cloud AI, AI-SPM, AI-Workload-Schutz, Azure OpenAI-Bedrohungserkennung, sofortige Injektionswarnung, Jailbreak-Warnung Azure OpenAI, AI-Wallet-Missbrauch, AI-Workload-Status, Amazon Bedrock-Status, Vertex AI-Status, generative KI-Sicherheit Azure. NICHT für Endbenutzer-KI-Nutzungssteuerung (verwenden Sie purview-ai-hub), Inhaltsmoderations-API (verwenden Sie azure-ai-content-safety) oder M365 Copilot-Rollout (verwenden Sie copilot-for-m365-readiness) verwenden.
