Conseils pour Microsoft Defender pour Cloud — Protection des charges de travail de l’IA (AI-SPM et détection des menaces d’exécution pour l’IA générative). Couvre la gestion de la posture de sécurité de l'IA (découverte des ressources Azure OpenAI / Azure AI Foundry / Amazon Bedrock / Google Vertex AI, identification de l'exposition des données de base, posture de déploiement du modèle), la détection des menaces d'exécution sur Azure OpenAI (tentatives d'injection/jailbreak rapide, fuite de données sensibles dans les invites/réponses, abus de portefeuille, fuite d'informations d'identification), l'intégration avec Azure AI Content Safety Prompt Shields, l'analyse du chemin d'attaque pour les charges de travail d'IA, l'enquête d'alerte dans Defender XDR et le couplage avec Purview DSPM pour AI (côté utilisateur) et Azure AI Content Safety (côté modèle). QUAND : Defender pour Cloud AI, AI-SPM, protection de la charge de travail IA, détection des menaces Azure OpenAI, alerte d'injection rapide, alerte de jailbreak Azure OpenAI, abus de portefeuille IA, posture de charge de travail IA, posture Amazon Bedrock, posture Vertex AI, sécurité IA générative Azure. NE PAS UTILISER pour la gouvernance de l'utilisation de l'IA par l'utilisateur final (utilisez purview-ai-hub), l'API de modération de contenu (utilisez azure-ai-content-safety) ou le déploiement de M365 Copilot (utilisez copilot-for-m365-readiness).
