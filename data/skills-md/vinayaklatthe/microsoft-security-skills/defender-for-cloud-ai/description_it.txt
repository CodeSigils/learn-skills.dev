Linee guida per Microsoft Defender for Cloud: protezione del carico di lavoro AI (AI-SPM e rilevamento delle minacce in fase di esecuzione per l'intelligenza artificiale generativa). Copre la gestione della posizione di sicurezza dell'intelligenza artificiale (scoperta di Azure OpenAI/Azure AI Foundry/Amazon Bedrock/Google Vertex risorse AI, identificazione dell'esposizione dei dati di base, posizione di distribuzione del modello), rilevamento delle minacce in runtime su Azure OpenAI (prompt injection/tentativi di jailbreak, perdita di dati sensibili in prompt/risposte, abuso del portafoglio, perdita di credenziali), integrazione con Azure AI Content Safety Prompt Shields, analisi del percorso di attacco per carichi di lavoro AI, indagine degli avvisi in Defender XDR e associazione con Purview DSPM per AI (lato utente) e Azure AI Content Safety (lato modello). QUANDO: Defender for Cloud AI, AI-SPM, protezione del carico di lavoro AI, rilevamento delle minacce Azure OpenAI, avviso di prompt injection, avviso jailbreak Azure OpenAI, abuso del portafoglio AI, postura del carico di lavoro AI, postura Amazon Bedrock, postura Vertex AI, sicurezza AI generativa Azure. NON UTILIZZARE per la governance dell'utilizzo dell'intelligenza artificiale da parte dell'utente finale (usare purview-ai-hub), l'API di moderazione dei contenuti (usare azure-ai-content-safety) o l'implementazione di M365 Copilot (usare copilot-for-m365-readiness).
