إرشادات لـ Microsoft Defender for Cloud - حماية أحمال عمل الذكاء الاصطناعي (AI-SPM واكتشاف تهديدات وقت التشغيل للذكاء الاصطناعي التوليدي). يغطي إدارة الوضع الأمني للذكاء الاصطناعي (اكتشاف موارد Azure OpenAI / Azure AI Foundry / Amazon Bedrock / Google Vertex AI، وتحديد التعرض للبيانات الأرضية، ووضعية نشر النموذج)، واكتشاف التهديدات في وقت التشغيل على Azure OpenAI (محاولات الحقن الفوري / كسر الحماية، وتسرب البيانات الحساسة في المطالبات / الاستجابات، وإساءة استخدام المحفظة، وتسرب بيانات الاعتماد)، والتكامل مع Azure AI Content Safety Prompt Shields، وتحليل مسار الهجوم لأحمال عمل الذكاء الاصطناعي، والتحقيق في التنبيهات في Defender XDR، والاقتران مع Purview DSPM للذكاء الاصطناعي (جانب المستخدم) وAzure AI Content Safety (جانب الطراز). متى: Defender for Cloud AI، وAI-SPM، وحماية عبء عمل الذكاء الاصطناعي، واكتشاف تهديدات Azure OpenAI، وتنبيه الحقن الفوري، وتنبيه كسر الحماية Azure OpenAI، وإساءة استخدام محفظة الذكاء الاصطناعي، ووضعية أعباء عمل الذكاء الاصطناعي، ووضعية Amazon Bedrock، ووضعية Vertex AI، وأمان الذكاء الاصطناعي التوليدي Azure. لا تستخدمه لإدارة استخدام الذكاء الاصطناعي للمستخدم النهائي (استخدم Purview-ai-hub)، أو واجهة برمجة تطبيقات الإشراف على المحتوى (استخدم azure-ai-content-safety)، أو طرح M365 Copilot (استخدم copilot-for-m365-readiness).
