Microsoft Defender for Cloud のガイダンス — AI ワークロード保護 (AI-SPM および生成 AI のランタイム脅威検出)。 AI セキュリティ体制管理 (Azure OpenAI / Azure AI Foundry / Amazon Bedrock / Google Vertex AI リソースの検出、グラウンディング データ漏洩の特定、モデル デプロイメント姿勢)、Azure OpenAI でのランタイム脅威検出 (プロンプト インジェクション / ジェイルブレイク試行、プロンプト/レスポンスでの機密データ漏洩、ウォレット悪用、資格情報漏洩)、Azure AI Content Safety Prompt Shields との統合、AI ワークロードの攻撃パス分析、Defender XDR でのアラート調査、およびAI 用の Purview DSPM (ユーザー側) と Azure AI Content Safety (モデル側)。いつ: Defender for Cloud AI、AI-SPM、AI ワークロード保護、Azure OpenAI 脅威検出、プロンプト インジェクション アラート、ジェイルブレイク アラート Azure OpenAI、AI ウォレットの悪用、AI ワークロードの姿勢、Amazon Bedrock の姿勢、Vertex AI の姿勢、生成 AI セキュリティ Azure。エンドユーザーの AI 使用ガバナンス (purview-ai-hub を使用)、コンテンツ モデレーション API (azure-ai-content-safety を使用)、または M365 Copilot ロールアウト (copilot-for-m365-readiness を使用) には使用しないでください。
