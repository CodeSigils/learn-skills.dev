Guía para Microsoft Defender para la nube: protección de cargas de trabajo de IA (AI-SPM y detección de amenazas en tiempo de ejecución para IA generativa). Cubre la gestión de la postura de seguridad de la IA (descubrimiento de recursos de Azure OpenAI/Azure AI Foundry/Amazon Bedrock/Google Vertex AI, identificación de exposición de datos de conexión a tierra, postura de implementación del modelo), detección de amenazas en tiempo de ejecución en Azure OpenAI (inyección rápida/intentos de jailbreak, fuga de datos confidenciales en solicitudes/respuestas, abuso de billetera, fuga de credenciales), integración con Azure AI Content Safety Prompt Shields, análisis de ruta de ataque para cargas de trabajo de IA, investigación de alertas en Defender XDR y emparejamiento con Purview DSPM para IA (usuario). lado) y Azure AI Content Safety (lado del modelo). CUÁNDO: Defender para Cloud AI, AI-SPM, protección de cargas de trabajo de AI, detección de amenazas de Azure OpenAI, alerta de inyección rápida, alerta de jailbreak Azure OpenAI, abuso de billetera de AI, postura de carga de trabajo de AI, postura de Amazon Bedrock, postura de Vertex AI, seguridad de AI generativa Azure. NO UTILIZAR para la gobernanza del uso de la IA del usuario final (use purview-ai-hub), la API de moderación de contenido (use azure-ai-content-safety) o la implementación de M365 Copilot (use copilot-for-m365-readiness).
