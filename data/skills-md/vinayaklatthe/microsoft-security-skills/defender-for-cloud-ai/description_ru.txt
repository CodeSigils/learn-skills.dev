Руководство по Microsoft Defender для облака — защита рабочих нагрузок ИИ (AI-SPM и обнаружение угроз во время выполнения для генеративного ИИ). Охватывает управление состоянием безопасности ИИ (обнаружение ресурсов ИИ Azure OpenAI/Azure AI Foundry/Amazon Bedrock/Google Vertex, выявление обоснованных уязвимостей данных, состояние развертывания модели), обнаружение угроз во время выполнения в Azure OpenAI (быстрое внедрение/попытки джейлбрейка, утечка конфиденциальных данных в подсказках/ответах, злоупотребление кошельком, утечка учетных данных), интеграция с Azure AI Content Safety Prompt Shields, анализ пути атаки для рабочих нагрузок ИИ, исследование предупреждений в Defender XDR и сопряжение с Purview DSPM для AI (на стороне пользователя) и безопасности содержимого Azure AI (на стороне модели). КОГДА: Защитник для облачного ИИ, AI-SPM, защита рабочих нагрузок ИИ, обнаружение угроз Azure OpenAI, оповещение о быстром внедрении, оповещение о джейлбрейке Azure OpenAI, злоупотребление кошельком ИИ, состояние рабочей нагрузки ИИ, положение Amazon Bedrock, положение Vertex AI, генеративная безопасность ИИ Azure. НЕ ИСПОЛЬЗУЙТЕ для управления использованием ИИ конечными пользователями (используйте purview-ai-hub), API модерации контента (используйте azure-ai-content-safety) или развертывания M365 Copilot (используйте copilot-for-m365-readiness).
