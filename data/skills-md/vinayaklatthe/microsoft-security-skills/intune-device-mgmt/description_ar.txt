إرشادات لإدارة أجهزة Microsoft Intune - التسجيل والتكوين والتوافق والأمان الأساسي عبر أنظمة التشغيل Windows وmacOS وiOS/iPadOS وAndroid. يغطي تسجيل الطيار الآلي مقابل الشركات مقابل BYOD، وسياسات الامتثال التي تغذي الوصول المشروط، وخطوط أساس أمان Intune، وتحديث الحلقات / التصحيح التلقائي، واستخدام عوامل التصفية وعمليات الطرح المستندة إلى الحلقات لتجنب عمليات التأمين. متى: Microsoft Intune، MDM، تسجيل الجهاز، Autopilot، Apple ABM، Android Enterprise، سياسة الامتثال، خط الأساس للأمان، ملف تعريف التكوين، كتالوج الإعدادات، إدارة الأجهزة، امتثال الجهاز للوصول المشروط، إدارة نقطة النهاية، Windows Autopatch، حلقات التحديث. لا تستخدمه لحماية التطبيق فقط على BYOD (استخدم حماية التطبيق intune)، أو اكتشاف نقطة النهاية / EDR (استخدم المدافع مقابل نقطة النهاية)، أو تشفير القرص فقط (استخدم تصميم bitlocker).
