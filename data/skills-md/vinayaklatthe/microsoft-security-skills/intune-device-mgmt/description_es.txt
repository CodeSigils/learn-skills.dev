Guía para la administración de dispositivos Microsoft Intune: inscripción, configuración, cumplimiento y líneas base de seguridad en Windows, macOS, iOS/iPadOS y Android. Cubre la inscripción de piloto automático versus corporativo versus BYOD, políticas de cumplimiento que alimentan el acceso condicional, líneas base de seguridad de Intune, anillos de actualización/parche automático y el uso de filtros e implementaciones basadas en anillos para evitar bloqueos. CUÁNDO: Microsoft Intune, MDM, inscripción de dispositivos, Autopilot, Apple ABM, Android Enterprise, política de cumplimiento, línea base de seguridad, perfil de configuración, catálogo de configuraciones, administración de dispositivos, cumplimiento de dispositivos para acceso condicional, administración de terminales, Windows Autopatch, anillos de actualización. NO LO USE para protección solo de aplicaciones en BYOD (use protección de aplicaciones intune), detección de endpoints/EDR (use defender-for-endpoint) o cifrado de disco únicamente (use bitlocker-design).
