Microsoft Entra ID 보호에 대한 지침 — 사용자 및 로그인 위험을 감지하고 교정을 자동화하는 위험 기반 ID 보안입니다. 위험 감지, 위험 기반 조건부 액세스, MFA를 통한 자체 해결/보안 비밀번호 변경, 위험한 사용자 조사 및 Sentinel로의 위험 스트리밍을 다룹니다. 시기: Entra ID 보호, 신원 위험 정책, 위험한 사용자, 위험한 로그인, 사용자 위험 정책, 로그인 위험 정책, 위험 기반 조건부 액세스, 자격 증명 유출, 익명 IP 감지, 비정형 여행, 신원 수정 자동화, 자격 증명 유출에 대한 경고, 위험한 사용자로 표시됨, 손상된 계정에 대한 암호 재설정 강제, 신원 위험이 높을 때 로그인 차단, EID P2 위험 정책. 온프레미스 AD 공격 탐지(ID를 위한 방어자 사용), 위험 신호 없는 CA 정책 작성(조건부 액세스-mfa 사용) 또는 PIM 활성화(azure-pim 사용)에는 사용하지 마십시오.
