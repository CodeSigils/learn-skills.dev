Руководство по защите Microsoft Entra ID — безопасность идентификации на основе рисков, которая обнаруживает риски для пользователей и входа в систему и автоматизирует исправление. Охватывает обнаружение рисков, условный доступ на основе рисков, самостоятельное исправление с помощью MFA/безопасной смены пароля, расследование действий рискованных пользователей и потоковую передачу рисков в Sentinel. КОГДА: защита Entra ID, политика риска идентификации, рискованные пользователи, рискованный вход в систему, политика риска пользователя, политика риска входа в систему, условный доступ на основе риска, утечка учетных данных, обнаружение анонимного IP-адреса, нетипичные поездки, автоматическое восстановление личности, оповещение об утечке учетных данных, пользователь помечен как рискованный, принудительный сброс пароля для скомпрометированных учетных записей, блокировка входа при высоком риске идентификации, политика риска EID P2. НЕ ИСПОЛЬЗУЙТЕ для обнаружения локальных атак AD (используйте защитник для идентификации), разработки политики CA без сигналов риска (используйте условный доступ-mfa) или активации PIM (используйте azure-pim).
