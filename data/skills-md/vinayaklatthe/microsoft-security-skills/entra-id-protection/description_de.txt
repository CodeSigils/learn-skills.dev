Leitfaden für Microsoft Entra ID Protection – risikobasierte Identitätssicherheit, die Benutzer- und Anmelderisiken erkennt und die Behebung automatisiert. Deckt Risikoerkennungen, risikobasierten bedingten Zugriff, Selbstbehebung über MFA/sichere Passwortänderung, Untersuchung riskanter Benutzer und Streaming-Risiken an Sentinel ab. WANN: Entra-ID-Schutz, Identitätsrisikorichtlinie, riskante Benutzer, riskante Anmeldungen, Benutzerrisikorichtlinie, Anmelderisikorichtlinie, risikobasierter bedingter Zugriff, durchgesickerte Anmeldeinformationen, anonyme IP-Erkennung, atypische Reisen, automatische Identitätskorrektur, Benachrichtigung über durchgesickerte Anmeldeinformationen, als riskant gekennzeichneter Benutzer, erzwingen Sie das Zurücksetzen des Passworts für kompromittierte Konten, blockieren Sie die Anmeldung, wenn das Identitätsrisiko hoch ist, EID P2-Risikorichtlinie. NICHT für die lokale AD-Angriffserkennung (Verwenden Sie Defender-for-Identity), die Erstellung von CA-Richtlinien ohne Risikosignale (Verwenden Sie Conditional-Access-MFA) oder die PIM-Aktivierung (Verwenden Sie Azure-Pim) verwenden.
