Microsoft Entra ID 保护指南 — 基于风险的身份安全，可检测用户和登录风险并自动进行修复。涵蓋風險檢測、基於風險的條件存取、透過 MFA/安全密碼變更進行自我修復、有風險的用戶調查以及將風險串流傳輸到 Sentinel。何時：Entra ID 保護、身分風險策略、有風險的使用者、有風險的登入、使用者風險策略、登入風險策略、基於風險的條件存取、洩露的憑證、匿名 IP 偵測、非典型旅行、自動身分補救、有關洩漏的憑證的警報、使用者標記為有風險、強制重設帳戶的密碼、身分較高風險時阻止登入、EID P2 風險登入。請勿用於本機 AD 攻擊偵測（使用 Defender-for Identity）、沒有風險訊號的 CA 策略編寫（使用條件存取-MFA）或 PIM 啟動（使用 azure-pim）。
