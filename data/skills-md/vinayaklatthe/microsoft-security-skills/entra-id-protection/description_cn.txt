Microsoft Entra ID 保护指南 — 基于风险的身份安全，可检测用户和登录风险并自动进行修复。涵盖风险检测、基于风险的条件访问、通过 MFA/安全密码更改进行自我修复、有风险的用户调查以及将风险流式传输到 Sentinel。何时：Entra ID 保护、身份风险策略、有风险的用户、有风险的登录、用户风险策略、登录风险策略、基于风险的条件访问、泄露的凭据、匿名 IP 检测、非典型旅行、自动身份补救、有关泄露的凭据的警报、用户标记为有风险、强制重置受损帐户的密码、身份风险较高时阻止登录、EID P2 风险策略。请勿用于本地 AD 攻击检测（使用 Defender-for Identity）、没有风险信号的 CA 策略编写（使用条件访问-MFA）或 PIM 激活（使用 azure-pim）。
