Microsoft Entra 权限管理 (CIEM) 指南 — 跨 Microsoft Azure、AWS 和 Google Cloud 发现、调整大小并监控权限。涵盖云上线、权限蔓延指数 (PCI)、根据观察到的活动生成最低权限策略、按需权限授予和工作负载身份覆盖。时间：Entra 权限管理、CIEM、多云权限、权限蠕变索引、PCI、适当大小的权限、未使用的权限、跨 AWS GCP Azure 的最小权限、云权利管理、过度特权的工作负载身份、IAM 适当大小、多云 IAM 状态。请勿用于仅限 Azure 的 RBAC 角色选择（使用 azure-role-selector）或 Defender for Cloud 安全态势（使用 Defender-for-cloud-hardening）。
