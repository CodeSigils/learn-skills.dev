Руководство по управлению разрешениями Microsoft Entra (CIEM) — обнаруживает, корректирует и отслеживает разрешения в Microsoft Azure, AWS и Google Cloud. Охватывает подключение к облаку, индекс ограничения разрешений (PCI), создание политик с наименьшими привилегиями на основе наблюдаемой активности, предоставление разрешений по требованию и покрытие идентификации рабочей нагрузки. КОГДА: Entra Permissions Management, CIEM, мультиоблачные разрешения, Permission Creep Index, PCI, разрешения нужного размера, неиспользуемые разрешения, минимальные привилегии в AWS GCP Azure, управление облачными правами, сверхпривилегированная идентификация рабочей нагрузки, правильный размер IAM, положение мультиоблачного IAM. НЕ ИСПОЛЬЗУЙТЕ для выбора роли RBAC только для Azure (используйте azure-role-selector) или защитника для обеспечения безопасности в облаке (используйте защитник для защиты от облака).
