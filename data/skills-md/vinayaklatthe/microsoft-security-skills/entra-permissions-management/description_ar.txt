إرشادات لإدارة أذونات Microsoft Entra (CIEM) - تكتشف الأذونات وتضبط حجمها وتراقبها عبر Microsoft Azure وAWS وGoogle Cloud. يغطي الإعداد السحابي، ومؤشر زحف الأذونات (PCI)، وإنشاء سياسات الامتيازات الأقل من النشاط الملحوظ، ومنح الأذونات عند الطلب، وتغطية هوية عبء العمل. متى: إدارة أذونات Entra، وCIEM، وأذونات السحابة المتعددة، وPermission Creep Index، وPCI، وأذونات الحجم الصحيح، والأذونات غير المستخدمة، وأقل الامتيازات عبر AWS GCP Azure، وإدارة استحقاقات السحابة، وهوية عبء العمل ذات الامتيازات الزائدة، وضبط حجم IAM الصحيح، ووضعية IAM متعددة السحابات. لا تستخدمه لاختيار دور RBAC الخاص بـ Azure فقط (استخدم محدد الأدوار azure) أو Defender لموقف الأمان السحابي (استخدم المدافع مقابل تقوية السحابة).
