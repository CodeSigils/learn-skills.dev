Microsoft CIEM(Entra Permissions Management)에 대한 지침 — Microsoft Azure, AWS 및 Google Cloud 전반에 걸쳐 권한을 검색하고, 적절한 크기를 지정하고, 모니터링합니다. 클라우드 온보딩, PCI(Permission Creep Index), 관찰된 활동에서 최소 권한 정책 생성, 주문형 권한 부여 및 워크로드 아이덴티티 범위를 다룹니다. 시기: Entra 권한 관리, CIEM, 멀티클라우드 권한, 권한 증가 지수, PCI, 적절한 크기 권한, 사용되지 않은 권한, AWS GCP Azure 전반에 걸친 최소 권한, 클라우드 자격 관리, 과도한 권한이 부여된 워크로드 아이덴티티, IAM 적절한 크기 조정, 멀티클라우드 IAM 상태. Azure 전용 RBAC 역할 선택(azure-role-selector 사용) 또는 Defender for Cloud 보안 상태(defender-for-cloud-hardening 사용)에는 사용하지 마세요.
