Microsoft Entra 權限管理 (CIEM) 指南 — 跨 Microsoft Azure、AWS 和 Google Cloud 發現、調整大小並監控權限。涵蓋雲端上線、權限蔓延指數 (PCI)、根據觀察到的活動產生最低權限策略、按需權限授予和工作負載身分覆蓋。時間：Entra 權限管理、CIEM、多雲權限、權限蠕動索引、PCI、適當大小的權限、未使用的權限、跨 AWS GCP Azure 的最小權限、雲端權利管理、過度特權的工作負載身分、IAM 適當大小、多雲 IAM 狀態。請勿用於僅限 Azure 的 RBAC 角色選擇（使用 azure-role-selector）或 Defender for Cloud 安全態勢（使用 Defender-for-cloud-hardening）。
