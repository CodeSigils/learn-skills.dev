Microsoft Entra Permissions Management (CIEM) のガイダンス — Microsoft Azure、AWS、Google Cloud 全体のアクセス許可を検出、適切なサイズ設定、監視します。クラウドのオンボーディング、Permission Creep Index (PCI)、観察されたアクティビティからの最小権限ポリシーの生成、オンデマンドの権限付与、ワークロード ID のカバレッジをカバーします。時期: Entra Permissions Management、CIEM、マルチクラウド アクセス許可、Permission Creep Index、PCI、適切なサイズのアクセス許可、未使用のアクセス許可、AWS GCP Azure 全体の最小権限、クラウド エンタイトルメント管理、過剰な権限を持つワークロード ID、IAM の適切なサイジング、マルチクラウド IAM ポスチャ。 Azure のみの RBAC ロールの選択 (azure-role-selector を使用) または Defender for Cloud セキュリティ体制 (defender-for-cloud-hardening を使用) には使用しないでください。
