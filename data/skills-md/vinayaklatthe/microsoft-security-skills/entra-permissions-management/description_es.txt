Guía para la administración de permisos de Microsoft Entra (CIEM): descubre, ajusta el tamaño y monitorea los permisos en Microsoft Azure, AWS y Google Cloud. Cubre la incorporación a la nube, el índice de dispersión de permisos (PCI), la generación de políticas de privilegios mínimos a partir de la actividad observada, concesiones de permisos bajo demanda y cobertura de identidad de cargas de trabajo. CUÁNDO: Entra Permissions Management, CIEM, permisos multinube, Permission Creep Index, PCI, permisos del tamaño adecuado, permisos no utilizados, privilegios mínimos en AWS GCP Azure, gestión de derechos en la nube, identidad de carga de trabajo con privilegios excesivos, tamaño adecuado de IAM, postura de IAM multinube. NO LO USE para la elección de rol RBAC exclusivo de Azure (use azure-role-selector) o la postura de seguridad de Defender para la nube (use defender-for-cloud-hardening).
