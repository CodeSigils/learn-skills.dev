إرشادات لكتالوج Microsoft Purview Unified (كتالوج البيانات) - الاكتشاف المناسب للأعمال، ومجالات الإدارة، ومنتجات البيانات، ومصطلحات المسرد، وجودة البيانات أعلى خريطة البيانات. يغطي مجالات الحوكمة ومنتجات البيانات والتنظيم. متى: عرض كتالوج البيانات، والكتالوج الموحد، ومنتجات البيانات، ومجال الحوكمة، ومسرد الأعمال، وجودة البيانات، واكتشاف البيانات للمحللين، وتنظيم أصول البيانات، وإدارة البيانات.
