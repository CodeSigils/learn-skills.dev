إرشادات لسياسة Azure - فرض ومراجعة حواجز الحوكمة والأمن على نطاق واسع عبر Azure مع التعريفات والمبادرات والواجبات ومهام الإصلاح. يغطي التأثيرات (التدقيق، والرفض، والإلحاق، والتعديل، وDeployIfNotExists، وAuditIfNotExists)، ووراثة مجموعة الإدارة، وطرح التدقيق أولاً، والسياسات القابلة لإعادة الاستخدام ذات المعلمات، ونظام الاستبعاد. Powers Defender للامتثال التنظيمي السحابي. متى: سياسة Azure، وحواجز حماية الحوكمة، وفرض الامتثال، ومبادرة السياسة، ورفض الموارد، وتكوين التدقيق، ومهمة الإصلاح، ونشر IfNotExists، وسياسة مجموعة الإدارة، وإنفاذ خط الأساس للأمان، ومبادرة MCSB، والامتثال التنظيمي Azure. لا تستخدمه لاختيار دور RBAC للمورد (استخدم محدد الدور الأزرق السماوي)، أو وضعية المدافع فقط (استخدم المدافع مقابل تقوية السحابة)، أو قوالب Bicep / IaC.
