Azure Policy のガイダンス — 定義、イニシアチブ、割り当て、修復タスクを使用して、Azure 全体にわたる大規模なガバナンスとセキュリティ ガードレールを適用および監査します。効果 (監査、拒否、追加、変更、DeployIfNotExists、AuditIfNotExists)、管理グループの継承、監査優先ロールアウト、パラメータ化された再利用可能なポリシー、および除外規律をカバーします。 Defender for Cloud の規制コンプライアンスを強化します。いつ: Azure Policy、ガバナンス ガードレール、コンプライアンスの強制、ポリシー イニシアチブ、リソースの拒否、監査構成、修復タスク、deployIfNotExists、管理グループ ポリシー、セキュリティ ベースラインの強制、MCSB イニシアチブ、規制コンプライアンス Azure。リソース RBAC ロールの選択 (azure-role-selector を使用)、Defender ポスチャのみ (defender-for-cloud-hardening を使用)、または Bicep / IaC テンプレートには使用しないでください。
