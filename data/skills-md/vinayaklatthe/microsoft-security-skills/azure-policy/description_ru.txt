Руководство по политике Azure — обеспечение соблюдения и аудит мер управления и безопасности в масштабе Azure с определениями, инициативами, назначениями и задачами по исправлению. Охватывает эффекты (Audit, Deny, Append, Modify, DeployIfNotExists, AuditIfNotExists), наследование группы управления, развертывание сперва аудита, параметризованные политики многократного использования и дисциплину исключения. Обеспечивает Defender соответствие нормативным требованиям Cloud. КОГДА: политика Azure, защитные меры управления, обеспечение соблюдения требований, инициатива политики, запрет ресурса, конфигурация аудита, задача исправления, развертываниеIfNotExists, политика группы управления, обеспечение соблюдения базовых показателей безопасности, инициатива MCSB, соответствие нормативным требованиям Azure. НЕ ИСПОЛЬЗУЙТЕ для выбора роли ресурса RBAC (используйте селектор ролей Azure), только позиции защитника (используйте защитник для защиты в облаке) или шаблонов Bicep/IaC.
