Guía para Azure Policy: aplicación y auditoría de barreras de seguridad y gobernanza a escala en Azure con definiciones, iniciativas, asignaciones y tareas de corrección. Cubre los efectos (Auditar, Denegar, Agregar, Modificar, DeployIfNotExists, AuditIfNotExists), herencia del grupo de administración, implementación de auditoría primero, políticas reutilizables parametrizadas y disciplina de exclusión. Impulsa Defender para el cumplimiento normativo de la nube. CUÁNDO: Azure Policy, barreras de gobernanza, aplicación del cumplimiento, iniciativa de políticas, denegación de recursos, configuración de auditoría, tarea de corrección, implementaciónSiNotExists, política de grupo de administración, aplicación de la línea base de seguridad, iniciativa MCSB, cumplimiento normativo de Azure. NO LO USE para la elección de rol de RBAC de recursos (use azure-role-selector), solo la postura del defensor (use defender-for-cloud-hardening) o plantillas de Bicep/IaC.
