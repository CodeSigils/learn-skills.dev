Azure 策略指南 — 透過定義、規劃、指派和補救任務在 Azure 中大規模實施和審核治理和安全性護欄。涵蓋效果（審核、拒絕、追加、修改、DeployIfNotExists、AuditIfNotExists）、管理群組繼承、審核優先部署、參數化可重複使用原則和排除規則。為 Defender 提供雲端法規遵循支援。時間：Azure 原則、治理護欄、強制合規性、策略計畫、拒絕資源、審核設定、修復任務、deployIfNotExists、管理群組原則、安全基線強制執行、MCSB 計畫、法規遵循 Azure。請勿用於資源 RBAC 角色選擇（使用 azure-role-selector）、僅 Defender 姿勢（使用 Defender-for-cloud-hardening）或 Bicep / IaC 模板。
