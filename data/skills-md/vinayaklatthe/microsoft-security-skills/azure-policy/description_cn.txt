Azure 策略指南 — 通过定义、计划、分配和补救任务在 Azure 中大规模实施和审核治理和安全护栏。涵盖效果（审核、拒绝、追加、修改、DeployIfNotExists、AuditIfNotExists）、管理组继承、审核优先部署、参数化可重用策略和排除规则。为 Defender 提供云法规遵从性支持。时间：Azure 策略、治理护栏、强制合规性、策略计划、拒绝资源、审核配置、修复任务、deployIfNotExists、管理组策略、安全基线强制执行、MCSB 计划、法规遵从性 Azure。请勿用于资源 RBAC 角色选择（使用 azure-role-selector）、仅 Defender 姿势（使用 Defender-for-cloud-hardening）或 Bicep / IaC 模板。
