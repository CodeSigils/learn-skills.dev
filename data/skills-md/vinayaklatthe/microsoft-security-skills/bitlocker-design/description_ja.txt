Microsoft Intune 経由で管理される Windows エンドポイント向けの BitLocker ドライブ暗号化の設計に関するガイダンス — 暗号化ポリシー、サイレント有効化、Entra ID への回復キー エスクロー、TPM、起動前認証のトレードオフ、およびリムーバブル メディアの BitLocker To Go。条件付きアクセスおよび回復ワークフローとのコンプライアンスの統合について説明します。対象: BitLocker、ディスク暗号化、Windows 暗号化ポリシー、BitLocker 回復キー、サイレント BitLocker の有効化、Intune ディスク暗号化、TPM 2.0、エスクロー回復キー、エンドポイントの暗号化、XTS-AES、BitLocker To Go、起動前認証、リムーバブル ドライブの暗号化。一般的な Intune デバイス管理 (intune-device-mgmt を使用)、Linux/macOS 暗号化 (intune-device-mgmt FileVault を使用)、または Azure ディスク暗号化 (azure-key-vault を使用) には使用しないでください。
