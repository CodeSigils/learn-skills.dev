针对通过 Microsoft Intune 管理的 Windows 端点设计 BitLocker 驱动器加密的指南 — 加密策略、静默启用、恢复密钥托管到 Entra ID、TPM、预启动身份验证权衡以及适用于可移动媒体的 BitLocker To Go。涵盖与条件访问和恢复工作流程的合规性集成。时间：BitLocker、磁盘加密、Windows 加密策略、BitLocker 恢复密钥、静默 BitLocker 启用、Intune 磁盘加密、TPM 2.0、托管恢复密钥、加密端点、XTS-AES、BitLocker To Go、预启动身份验证、可移动驱动器加密。请勿用于一般 Intune 设备管理（使用 intune-device-mgmt）、Linux/macOS 加密（使用 intune-device-mgmt FileVault）或 Azure 磁盘加密（使用 azure-key-vault）。
