Conseils pour la conception du chiffrement de lecteur BitLocker pour les points de terminaison Windows gérés via Microsoft Intune : politique de chiffrement, activation silencieuse, dépôt de clé de récupération sur Entra ID, TPM, compromis d'authentification avant démarrage et BitLocker To Go pour les supports amovibles. Covers compliance integration with Conditional Access and recovery workflows. QUAND : BitLocker, chiffrement de disque, stratégie de chiffrement Windows, clé de récupération BitLocker, activation silencieuse de BitLocker, chiffrement de disque Intune, TPM 2.0, clé de récupération de dépôt, chiffrement des points de terminaison, XTS-AES, BitLocker To Go, authentification avant démarrage, chiffrement de lecteur amovible. NE PAS UTILISER pour la gestion générale des appareils Intune (utilisez intune-device-mgmt), le chiffrement Linux/macOS (utilisez intune-device-mgmt FileVault) ou le chiffrement de disque Azure (utilisez azure-key-vault).
