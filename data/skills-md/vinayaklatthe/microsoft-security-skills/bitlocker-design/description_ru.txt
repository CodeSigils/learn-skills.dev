Руководство по разработке шифрования диска BitLocker для конечных точек Windows, управляемых через Microsoft Intune — политика шифрования, автоматическое включение, депонирование ключа восстановления для Entra ID, TPM, компромиссные варианты проверки подлинности перед загрузкой и BitLocker To Go для съемных носителей. Охватывает интеграцию соответствия требованиям с условным доступом и рабочими процессами восстановления. КОГДА: BitLocker, шифрование диска, политика шифрования Windows, ключ восстановления BitLocker, автоматическое включение BitLocker, шифрование диска Intune, TPM 2.0, ключ восстановления условного депонирования, шифрование конечных точек, XTS-AES, BitLocker To Go, проверка подлинности перед загрузкой, шифрование съемного диска. НЕ ИСПОЛЬЗУЙТЕ для общего управления устройствами Intune (используйте intune-device-mgmt), шифрования Linux/macOS (используйте intune-device-mgmt FileVault) или шифрования дисков Azure (используйте azure-key-vault).
