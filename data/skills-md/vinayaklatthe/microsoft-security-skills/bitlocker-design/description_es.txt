Guía para diseñar el cifrado de unidades BitLocker para terminales Windows administrados a través de Microsoft Intune: política de cifrado, habilitación silenciosa, depósito de claves de recuperación para Entra ID, TPM, compensaciones de autenticación previa al arranque y BitLocker To Go para medios extraíbles. Cubre la integración del cumplimiento con el acceso condicional y los flujos de trabajo de recuperación. CUÁNDO: BitLocker, cifrado de disco, política de cifrado de Windows, clave de recuperación de BitLocker, habilitación silenciosa de BitLocker, cifrado de disco de Intune, TPM 2.0, clave de recuperación de depósito en garantía, cifrado de endpoints, XTS-AES, BitLocker To Go, autenticación previa al arranque, cifrado de unidades extraíbles. NO LO USE para la administración general de dispositivos Intune (use intune-device-mgmt), cifrado de Linux/macOS (use intune-device-mgmt FileVault) o cifrado de disco de Azure (use azure-key-vault).
