Windows 11 企业安全基线指南 - Microsoft 建议通过 Intune（设置目录/安全基线）或 GPO 部署的安全设置。涵盖基于硬件的核心控制（TPM 2.0、安全启动、基于虚拟化的安全性/VBS、管理程序保护的代码完整性/HVCI、内存完整性、Credential Guard、本地安全机构保护）、Windows LAPS（Microsoft 的现代本地管理员密码解决方案，替代旧版 LAPS）、智能应用程序控制、个人数据加密 (PDE)、Windows Hello 企业版部署、受控文件夹访问、漏洞利用保护、BitLocker 基线、应用程序控制WDAC、可移动存储控制以及与 Intune 合规性和 Defender for Endpoint 的集成。时间：Windows 11 基准、Windows 安全基准、VBS HVCI 内存完整性、Credential Guard、LSA 保护、Windows LAPS、替换旧版 LAPS、智能应用程序控制、WDAC、漏洞利用保护、PDE Windows 11、Intune 安全基准。请勿用于端点 EDR 配置（使用 Defender-for-endpoint）、端到端 Intune 设备管理（使用 intune-device-mgmt）或仅用于 BitLocker 设计（使用 bitlocker-design）。
