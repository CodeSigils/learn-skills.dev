Linee guida per la linea di base di sicurezza aziendale di Windows 11: impostazioni di sicurezza consigliate da Microsoft distribuite tramite Intune (catalogo delle impostazioni/basi di sicurezza) o oggetto Criteri di gruppo. Copre i principali controlli hardware rooted (TPM 2.0, avvio sicuro, sicurezza basata su virtualizzazione/VBS, integrità del codice protetta da hypervisor/HVCI, integrità della memoria, protezione delle credenziali, protezione dell'autorità di sicurezza locale), Windows LAPS (la moderna soluzione con password di amministratore locale di Microsoft, sostituzione di LAPS legacy), controllo intelligente delle app, crittografia dei dati personali (PDE), distribuzione di Windows Hello for Business, accesso controllato alle cartelle, protezione dagli exploit, linea di base BitLocker, controllo delle app con WDAC, controlli di archiviazione rimovibili e integrazione con la conformità di Intune e Defender per Endpoint. QUANDO: linea di base di Windows 11, linea di base di sicurezza di Windows, integrità della memoria VBS HVCI, protezione delle credenziali, protezione LSA, Windows LAPS, sostituzione LAPS legacy, controllo intelligente delle app, WDAC, protezione dagli exploit, PDE Windows 11, linea di base di sicurezza di Intune. NON UTILIZZARE per la configurazione EDR dell'endpoint (usare Defender-for-endpoint), la gestione dei dispositivi Intune end-to-end (usare intune-device-mgmt) o solo la progettazione BitLocker (usare bitlocker-design).
