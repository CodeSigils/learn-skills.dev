Windows 11 エンタープライズ セキュリティ ベースラインのガイダンス — Intune (設定カタログ/セキュリティ ベースライン) または GPO 経由で展開される Microsoft の推奨セキュリティ設定。コアのハードウェアベースの制御 (TPM 2.0、セキュア ブート、仮想化ベースのセキュリティ / VBS、ハイパーバイザーで保護されたコードの整合性 / HVCI、メモリの整合性、資格情報ガード、ローカル セキュリティ機関の保護)、Windows LAPS (Microsoft の最新のローカル管理者パスワード ソリューション、従来の LAPS の代替)、Smart App Control、個人データ暗号化 (PDE)、Windows Hello for Business の展開、制御されたフォルダー アクセス、エクスプロイト保護、BitLocker ベースライン、 WDAC によるアプリ制御、リムーバブル ストレージ制御、Intune コンプライアンスと Defender for Endpoint との統合。時期: Windows 11 ベースライン、Windows セキュリティ ベースライン、VBS HVCI メモリ整合性、Credential Guard、LSA 保護、Windows LAPS、従来の LAPS の置き換え、Smart App Control、WDAC、エクスプロイト保護、PDE Windows 11、Intune セキュリティ ベースライン。エンドポイント EDR 構成 (defender-for-endpoint を使用)、Intune デバイス管理エンドツーエンド (intune-device-mgmt を使用)、または BitLocker 設計のみ (bitlocker-design を使用) には使用しないでください。
