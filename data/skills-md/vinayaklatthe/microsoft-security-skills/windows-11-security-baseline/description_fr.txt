Conseils pour la base de référence de sécurité d'entreprise Windows 11 : paramètres de sécurité recommandés par Microsoft déployés via Intune (catalogue de paramètres/lignes de base de sécurité) ou GPO. Couvre les contrôles matériels de base (TPM 2.0, Secure Boot, sécurité basée sur la virtualisation/VBS, intégrité du code protégé par hyperviseur/HVCI, intégrité de la mémoire, Credential Guard, protection des autorités de sécurité locales), Windows LAPS (la solution moderne de mot de passe d'administrateur local de Microsoft, remplacement des LAPS existants), Smart App Control, Personal Data Encryption (PDE), déploiement de Windows Hello for Business, accès contrôlé aux dossiers, protection contre les exploits, base de référence BitLocker, contrôle des applications avec WDAC, contrôles de stockage amovibles et intégration avec la conformité Intune et Defender for Endpoint. QUAND : référence de Windows 11, référence de sécurité Windows, intégrité de la mémoire VBS HVCI, Credential Guard, protection LSA, Windows LAPS, remplacement des LAPS hérités, Smart App Control, WDAC, protection contre les exploits, PDE Windows 11, référence de sécurité Intune. NE PAS UTILISER pour la configuration EDR du point de terminaison (utilisez Defender-for-endpoint), la gestion des appareils Intune de bout en bout (utilisez Intune-device-mgmt) ou la conception BitLocker uniquement (utilisez la conception Bitlocker).
