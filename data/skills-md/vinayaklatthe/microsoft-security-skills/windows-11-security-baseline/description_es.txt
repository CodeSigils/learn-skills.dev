Guía para la línea base de seguridad empresarial de Windows 11: configuración de seguridad recomendada por Microsoft implementada a través de Intune (catálogo de configuración/líneas base de seguridad) o GPO. Cubre los controles básicos basados en hardware (TPM 2.0, arranque seguro, seguridad basada en virtualización/VBS, integridad de código protegido por hipervisor/HVCI, integridad de la memoria, protección de credenciales, protección de la autoridad de seguridad local), Windows LAPS (la moderna solución de contraseña de administrador local de Microsoft, reemplazo de LAPS heredados), control inteligente de aplicaciones, cifrado de datos personales (PDE), implementación de Windows Hello para empresas, acceso controlado a carpetas, protección contra exploits, base de BitLocker, control de aplicaciones con WDAC, controles de almacenamiento extraíbles e integración con el cumplimiento de Intune y Defender for Endpoint. CUÁNDO: Línea base de Windows 11, línea base de seguridad de Windows, integridad de memoria VBS HVCI, Credential Guard, protección LSA, Windows LAPS, reemplazar LAPS heredados, Smart App Control, WDAC, protección contra exploits, PDE Windows 11, línea base de seguridad de Intune. NO LO UTILICE para la configuración de EDR de endpoints (use defender-for-endpoint), la administración de dispositivos de Intune de un extremo a otro (use intune-device-mgmt) o solo el diseño de BitLocker (use bitlocker-design).
