إرشادات للخط الأساسي لأمان المؤسسة لنظام التشغيل Windows 11 - إعدادات الأمان الموصى بها من Microsoft والتي يتم نشرها عبر Intune (كتالوج الإعدادات / خطوط الأساس للأمان) أو GPO. يغطي عناصر التحكم الأساسية ذات جذور الأجهزة (TPM 2.0، التمهيد الآمن، الأمان القائم على المحاكاة الافتراضية / VBS، سلامة التعليمات البرمجية المحمية بواسطة Hypervisor / HVCI، سلامة الذاكرة، حارس بيانات الاعتماد، حماية هيئة الأمن المحلي)، Windows LAPS (حل كلمة مرور المسؤول المحلي الحديث من Microsoft، استبدال LAPS القديم)، التحكم في التطبيقات الذكية، تشفير البيانات الشخصية (PDE)، نشر Windows Hello for Business، الوصول إلى المجلدات التي يتم التحكم فيها، الحماية من الاستغلال، خط الأساس لـ BitLocker، التطبيق التحكم باستخدام WDAC، وعناصر التحكم في التخزين القابلة للإزالة، والتكامل مع توافق Intune وDefender for Endpoint. متى: Windows 11 الأساسي، خط الأساس لأمان Windows، VBS HVCI Memory Integrity، Credential Guard، حماية LSA، Windows LAPS، استبدال LAPS القديم، Smart App Control، WDAC، الحماية من الاستغلال، PDE Windows 11، Intune Security baseline. لا تستخدمه لتكوين EDR لنقطة النهاية (استخدم المدافع مقابل نقطة النهاية)، أو إدارة جهاز Intune من البداية إلى النهاية (استخدم intune-device-mgmt)، أو تصميم BitLocker فقط (استخدم تصميم bitlocker).
