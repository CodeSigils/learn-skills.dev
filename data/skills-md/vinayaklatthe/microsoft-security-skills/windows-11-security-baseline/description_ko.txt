Windows 11 엔터프라이즈 보안 기준에 대한 지침 — Intune(설정 카탈로그/보안 기준) 또는 GPO를 통해 배포되는 Microsoft의 권장 보안 설정입니다. 핵심 하드웨어 기반 제어(TPM 2.0, 보안 부팅, 가상화 기반 보안/VBS, 하이퍼바이저 보호 코드 무결성/HVCI, 메모리 무결성, Credential Guard, 로컬 보안 기관 보호), Windows LAPS(Microsoft의 최신 로컬 관리자 암호 솔루션, 레거시 LAPS 대체), 스마트 앱 제어, 개인 데이터 암호화(PDE), 비즈니스용 Windows Hello 배포, 제어된 폴더 액세스, 악용 방지, BitLocker 기준, 앱 제어를 다룹니다.
