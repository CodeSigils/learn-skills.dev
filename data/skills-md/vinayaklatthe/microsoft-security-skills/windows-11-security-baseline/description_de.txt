Leitfaden für die Windows 11-Sicherheitsgrundlinie für Unternehmen – die von Microsoft empfohlenen Sicherheitseinstellungen, die über Intune (Einstellungskatalog/Sicherheitsgrundlinien) oder GPO bereitgestellt werden. Deckt zentrale hardwarebasierte Kontrollen ab (TPM 2.0, Secure Boot, virtualisierungsbasierte Sicherheit/VBS, Hypervisor-Protected Code Integrity/HVCI, Memory Integrity, Credential Guard, Local Security Authority-Schutz), Windows LAPS (Microsofts moderne Lösung für lokale Administratorkennwörter, Ersatz für Legacy-LAPS), Smart App Control, Personal Data Encryption (PDE), Windows Hello for Business-Bereitstellung, kontrollierter Ordnerzugriff, Exploit-Schutz, BitLocker-Baseline, App-Steuerung mit WDAC, Wechselspeicher Kontrollen und Integration mit Intune-Compliance und Defender for Endpoint. WANN: Windows 11-Basislinie, Windows-Sicherheitsbasislinie, VBS HVCI-Speicherintegrität, Credential Guard, LSA-Schutz, Windows LAPS, Legacy-LAPS ersetzen, Smart App Control, WDAC, Exploit-Schutz, PDE Windows 11, Intune-Sicherheitsbasislinie. NICHT für die Endpunkt-EDR-Konfiguration (verwenden Sie Defender-for-Endpoint), die End-to-End-Intune-Geräteverwaltung (verwenden Sie intune-device-mgmt) oder nur das BitLocker-Design (verwenden Sie bitlocker-design) verwenden.
