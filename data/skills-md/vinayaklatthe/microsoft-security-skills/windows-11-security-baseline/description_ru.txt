Руководство по базовым показателям корпоративной безопасности Windows 11 — рекомендуемые Microsoft параметры безопасности, развертываемые через Intune (каталог параметров/базовые показатели безопасности) или объект групповой политики. Охватывает основные аппаратные элементы управления (TPM 2.0, безопасная загрузка, безопасность на основе виртуализации / VBS, целостность кода, защищенного гипервизором / HVCI, целостность памяти, Credential Guard, защита локального органа безопасности), Windows LAPS (современное решение Microsoft для паролей локального администратора, замена устаревшим LAPS), Smart App Control, шифрование личных данных (PDE), развертывание Windows Hello для бизнеса, контролируемый доступ к папкам, защита от эксплойтов, базовый уровень BitLocker, контроль приложений с помощью WDAC, элементы управления съемными хранилищами и интеграция с соответствием требованиям Intune и Defender for Endpoint. КОГДА: базовый уровень Windows 11, базовый уровень безопасности Windows, целостность памяти VBS HVCI, Credential Guard, защита LSA, Windows LAPS, замена устаревших LAPS, Smart App Control, WDAC, защита от эксплойтов, PDE Windows 11, базовый уровень безопасности Intune. НЕ ИСПОЛЬЗУЙТЕ для конфигурации EDR конечной точки (используйте защитник для конечной точки), комплексного управления устройствами Intune (используйте intune-device-mgmt) или только дизайна BitLocker (используйте bitlocker-design).
