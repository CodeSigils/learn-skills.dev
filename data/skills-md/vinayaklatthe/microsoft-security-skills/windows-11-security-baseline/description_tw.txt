Windows 11 企業安全基準指南 - Microsoft 建議透過 Intune（設定目錄/安全性基準）或 GPO 部署的安全性設定。涵蓋基於硬體的核心控制（TPM 2.0、安全啟動、基於虛擬化的安全性/VBS、管理程式保護的程式碼完整性/HVCI、記憶體完整性、Credential Guard、本機安全機構保護）、Windows LAPS（Microsoft 的現代本機管理員密碼解決方案，取代舊版 LAPS）、智慧型應用程式控制、個人資料存取權 (PDE)、Windows Hello 部署基線、應用程式控制WDAC、可移動儲存控制以及與 Intune 合規性和 Defender for Endpoint 的整合。時間：Windows 11 基準、Windows 安全基準、VBS HVCI 記憶體完整性、Credential Guard、LSA 保護、Windows LAPS、取代舊版 LAPS、智慧型應用程式控制、WDAC、漏洞保護、PDE Windows 11、Intune 安全基準。請勿用於端點 EDR 設定（使用 Defender-for-endpoint）、端對端 Intune 裝置管理（使用 intune-device-mgmt）或僅用於 BitLocker 設計（使用 bitlocker-design）。
