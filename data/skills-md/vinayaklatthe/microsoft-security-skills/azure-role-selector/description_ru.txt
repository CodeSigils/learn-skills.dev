Руководство по выбору правильной роли Azure RBAC с наименьшими привилегиями: сопоставление необходимых действий со встроенными ролями, принятие решения о необходимости использования настраиваемой роли, правильное определение области назначений и выбор между ролями плоскости управления и плоскости данных. Охватывает уровни области (группа управления → ресурс), группы в сравнении с прямым назначением и PIM для привилегированных ролей. КОГДА: какая роль Azure, роль с наименьшими привилегиями, выбор роли Azure RBAC, встроенная или настраиваемая роль, назначение роли области, роль для управляемого удостоверения, роль плоскости данных, назначение минимальных разрешений, конструкция RBAC, плоскость управления и плоскость данных, считыватель данных BLOB-объектов хранилища или считыватель. НЕ ИСПОЛЬЗУЙТЕ для ролей каталога Entra ID (используйте entra-id) или для ролей администратора Microsoft 365 (используйте m365-govern-manage).
