إرشادات لاختيار دور Azure RBAC المناسب بأقل الامتيازات - تعيين الإجراءات المطلوبة للأدوار المضمنة، وتحديد متى تكون هناك حاجة إلى دور مخصص، وتحديد نطاق التعيينات بشكل صحيح، والاختيار بين أدوار مستوى التحكم وأدوار مستوى البيانات. يغطي مستويات النطاق (مجموعة الإدارة → المورد)، والمجموعات مقابل التعيين المباشر، وPIM للأدوار المميزة. متى: أي دور Azure، الدور الأقل امتيازًا، تحديد دور Azure RBAC، الدور المضمن مقابل الدور المخصص، تعيين دور النطاق، دور الهوية المُدارة، دور مستوى البيانات، تعيين الحد الأدنى من الأذونات، تصميم RBAC، مستوى التحكم مقابل مستوى البيانات، قارئ بيانات Blob للتخزين مقابل القارئ. لا تستخدمه لأدوار دليل Entra ID (استخدم معرف entra) أو لأدوار مسؤول Microsoft 365 (استخدم m365-govern-manage).
