Conseils pour sélectionner le bon rôle Azure RBAC avec le moindre privilège : mapper les actions requises aux rôles intégrés, décider quand un rôle personnalisé est nécessaire, définir correctement la portée des affectations et choisir entre les rôles de plan de contrôle et de plan de données. Couvre les niveaux de portée (groupe de gestion → ressource), les groupes par rapport à l'affectation directe et le PIM pour les rôles privilégiés. QUAND : quel rôle Azure, rôle de moindre privilège, sélection du rôle Azure RBAC, rôle intégré ou personnalisé, attribution du rôle de portée, rôle pour l'identité managée, rôle du plan de données, attribution d'autorisations minimales, conception RBAC, plan de contrôle par rapport au plan de données, lecteur de données Blob de stockage vs lecteur. NE PAS UTILISER pour les rôles d'annuaire Entra ID (utilisez entra-id) ou pour les rôles d'administrateur Microsoft 365 (utilisez m365-govern-manage).
