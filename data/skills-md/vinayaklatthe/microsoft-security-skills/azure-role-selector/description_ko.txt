최소한의 권한으로 올바른 Azure RBAC 역할을 선택하기 위한 지침 - 필요한 작업을 기본 제공 역할에 매핑하고, 사용자 지정 역할이 필요한 시기를 결정하고, 할당 범위를 올바르게 지정하고, 제어 평면과 데이터 평면 역할 중에서 선택합니다. 범위 수준(관리 그룹 → 리소스), 그룹 및 직접 할당, 권한 있는 역할에 대한 PIM을 다룹니다. 시기: Azure 역할, 최소 권한 역할, Azure RBAC 역할 선택, 기본 제공 역할과 사용자 지정 역할, 범위 역할 할당, 관리 ID 역할, 데이터 평면 역할, 최소 권한 할당, RBAC 설계, 제어 평면과 데이터 평면, Storage Blob 데이터 판독기와 판독기. Entra ID 디렉터리 역할(entra-id 사용) 또는 Microsoft 365 관리자 역할(m365-govern-manage 사용)에는 사용하지 마세요.
