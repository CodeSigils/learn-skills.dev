Руководство по политикам защиты приложений Microsoft Intune (MAM) — защита корпоративных данных внутри мобильных приложений с регистрацией устройств или без нее. Охватывает MAM-WE для BYOD и APP на управляемых устройствах, элементы управления перемещением данных (вырезание/копирование/вставка, сохранение как, шифрование), PIN-код приложения/биометрический и автономный режим, выборочное удаление корпоративных данных и сопряжение с контролем предоставления условного доступа «Требовать политику защиты приложений». КОГДА: политика защиты приложений Intune, политика защиты приложений, APP, MAM, MAM-WE, MAM без регистрации, защита данных в мобильных приложениях, защита данных BYOD, выборочная очистка, ограничение копирования и вставки, условный доступ на основе приложений, управление приложениями без регистрации, приложения Intune SDK. НЕ ИСПОЛЬЗУЙТЕ для полного управления устройством (используйте intune-device-mgmt) или шифрования диска (используйте bitlocker-design).
