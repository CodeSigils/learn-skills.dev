Microsoft Intune アプリ保護ポリシー (MAM) のガイダンス — デバイスの登録の有無にかかわらず、モバイル アプリ内の企業データを保護します。管理対象デバイス上の BYOD と APP の MAM-WE、データ再配置制御 (カット/コピー/ペースト、名前を付けて保存、暗号化)、アプリの PIN/生体認証とオフライン猶予、企業データの選択的ワイプ、および条件付きアクセス許可制御「アプリ保護ポリシーが必要」とのペアリングをカバーします。時期: Intune アプリ保護ポリシー、アプリ保護ポリシー、APP、MAM、MAM-WE、登録なしの MAM、モバイル アプリのデータ保護、BYOD データ保護、選択的ワイプ、コピー貼り付けの制限、アプリベースの条件付きアクセス、登録なしのアプリの管理、Intune SDK アプリ。完全なデバイス管理 (intune-device-mgmt を使用) またはディスク暗号化 (bitlocker-design を使用) には使用しないでください。
