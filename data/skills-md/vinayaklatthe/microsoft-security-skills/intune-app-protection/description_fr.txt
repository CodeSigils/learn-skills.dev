Conseils sur les politiques de protection des applications (MAM) de Microsoft Intune : protection des données d'entreprise dans les applications mobiles avec ou sans inscription d'appareil. Couvre MAM-WE pour BYOD vs APP sur les appareils gérés, les contrôles de relocalisation des données (couper/copier/coller, enregistrer sous, cryptage), le code PIN/biométrique et hors ligne de l'application, l'effacement sélectif des données d'entreprise et le couplage avec le contrôle d'octroi d'accès conditionnel « Exiger une politique de protection des applications ». QUAND : politique de protection des applications Intune, politique de protection des applications, APP, MAM, MAM-WE, MAM sans inscription, protection des données dans les applications mobiles, protection des données BYOD, effacement sélectif, restriction du copier-coller, accès conditionnel basé sur les applications, gestion des applications sans inscription, applications Intune SDK. NE PAS UTILISER pour la gestion complète des appareils (utilisez intune-device-mgmt) ou le chiffrement de disque (utilisez bitlocker-design).
