Anleitung zum Entwerfen einer Sicherheitsarchitektur mit Zero Trust, den Microsoft Cybersecurity Reference Architectures (MCRA), der Cloud Adoption Framework Secure-Methodik und der Well-Architected Security-Säule. Deckt die sechs Zero-Trust-Säulen, Defense-in-Depth und die Ausrichtung der Referenzarchitektur ab. WANN: Sicherheitsarchitektur, Zero-Trust-Design, MCRA, Tiefenverteidigung, Sicherheitsreferenzarchitektur, sichere CAF-Methodik, Well-Architected-Sicherheitssäule, End-to-End-Sicherheitsdesign, Sicherheitsstrategie, Zielzustand. NICHT für die taktische Produktkonfiguration (verwenden Sie die produktspezifische Fertigkeit) oder für das SOC-Tooling-Design (verwenden Sie Sentinel / Unified-Secops-Plattform) verwenden.
