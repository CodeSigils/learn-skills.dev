إرشادات لهويات حمل عمل Microsoft Entra - الهويات المُدارة، ومبادئ الخدمة، واتحاد هوية حمل العمل. يغطي الهوية المُدارة المعينة من قبل النظام مقابل الهوية المُدارة التي يعينها المستخدم، وبيانات الاعتماد الموحدة (GitHub Actions، وAzure DevOps، وKubernetes، ومُصدري OIDC الآخرين) لإزالة الأسرار، وWorkload Identities Premium (الوصول المشروط لأحمال العمل، واكتشاف المخاطر، ومراجعات دورة الحياة)، وسلامة بيانات الاعتماد (لا توجد أسرار للعميل حيث يعمل الاتحاد)، وRBAC الأقل امتيازًا، والتكامل مع Defender for Cloud / Microsoft Entra Permissions Management. متى: الهوية المُدارة، والهوية المعينة من قبل النظام، والهوية المعينة من قبل المستخدم، وتقوية مبدأ الخدمة، واتحاد هوية عبء العمل، وGitHub OIDC إلى Azure، وAzure DevOps OIDC، وهوية عبء عمل AKS، وأسرار العميل، وبيانات الاعتماد الموحدة، وهويات عبء العمل المميزة، والوصول المشروط لأعباء العمل، وحوكمة الهوية غير البشرية، وNHI، وتشديد تسجيل التطبيق. لا تستخدمه لهوية المستخدم/الإنسان (استخدم معرف entra)، أو اكتشاف الأذونات عبر السحابة (استخدم إدارة أذونات الدخول)، أو حوكمة NHI الشاملة (استخدم حوكمة هوية الوكيل).
