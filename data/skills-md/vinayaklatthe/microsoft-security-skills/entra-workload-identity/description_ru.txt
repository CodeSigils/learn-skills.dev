Руководство по удостоверениям рабочей нагрузки Microsoft Entra — управляемые удостоверения, субъекты-службы и федерация удостоверений рабочей нагрузки. Охватывает управляемое удостоверение, назначенное системой и пользователем, федеративные учетные данные (GitHub Actions, Azure DevOps, Kubernetes, другие эмитенты OIDC) для устранения секретов, Workload Identities Premium (условный доступ для рабочих нагрузок, обнаружения рисков, проверок жизненного цикла), гигиену учетных данных (нет клиентских секретов при работе федерации), RBAC с наименьшими привилегиями и интеграцию с Defender для Cloud/Microsoft Entra Permissions Management. КОГДА: управляемое удостоверение, назначенное системой удостоверение, назначенное пользователем удостоверение, усиление принципала службы, федерация удостоверений рабочей нагрузки, GitHub OIDC в ​​Azure, Azure DevOps OIDC, удостоверение рабочей нагрузки AKS, удаление секретов клиента, федеративные учетные данные, Workload Identities Premium, условный доступ для рабочих нагрузок, нечеловеческое управление идентификацией, NHI, усиление безопасности регистрации приложений. НЕ ИСПОЛЬЗУЙТЕ для идентификации пользователя/человека (используйте entra-id), обнаружения разрешений в облаках (используйте управление входными разрешениями) или сквозного управления NHI (используйте управление идентификацией агента).
