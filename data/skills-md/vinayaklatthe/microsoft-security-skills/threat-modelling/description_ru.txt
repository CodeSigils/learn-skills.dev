Руководство по моделированию угроз с использованием STRIDE и жизненного цикла разработки безопасности Microsoft (SDL). Охватывает диаграммы потоков данных, границы доверия, категории STRIDE, карты смягчения последствий и инструменты (Microsoft Threat Modeling Tool). КОГДА: моделирование угроз, STRIDE, диаграмма потока данных, граница доверия, выявление угроз, моделирование угроз SDL, проверка проекта безопасности, моделирование угроз в системе, сопоставление мер по снижению рисков, инструмент моделирования угроз Microsoft, проверка безопасного проектирования, безопасность во время разработки. НЕ ИСПОЛЬЗУЙТЕ для архитектуры безопасности всей организации (используйте Security-Architecture) или для обнаружения во время выполнения (используйте Sentinel/Defender-XDR).
