Leitfaden für die Bedrohungsmodellierung mit STRIDE und dem Microsoft Security Development Lifecycle (SDL). Behandelt Datenflussdiagramme, Vertrauensgrenzen, die STRIDE-Kategorien, Risikominderungszuordnung und Tools (Microsoft Threat Modeling Tool). WANN: Bedrohungsmodellierung, STRIDE, Datenflussdiagramm, Vertrauensgrenze, Bedrohungen identifizieren, SDL-Bedrohungsmodellierung, Sicherheitsentwurfsüberprüfung, Bedrohungsmodellierung eines Systems, Schadensminderungszuordnung, Microsoft Threat Modeling Tool, sichere Entwurfsüberprüfung, Entwurfszeitsicherheit. NICHT für die organisationsweite Sicherheitsarchitektur (verwenden Sie security-architecture) oder zur Laufzeiterkennung (verwenden Sie sentinel/defender-xdr) VERWENDEN.
