Defender 포털을 통해 제공되는 클라우드 기반 SIEM 및 SOAR인 Microsoft Sentinel을 설계하고 운영하기 위한 지침입니다. 작업 공간 디자인, 데이터 커넥터, 수집 계층(분석/기본/보조/ADX), 분석 규칙, 헌팅, 관심 목록, 자동화 플레이북 및 비용/약정 계층 최적화를 다룹니다. 시기: Microsoft Sentinel 배포, SIEM 설계, 온보드 데이터 커넥터, 분석 규칙 작성, KQL 감지, Sentinel 플레이북, SOAR 자동화, Sentinel 비용 최적화, 로그 수집 계층, 약정 계층, Sentinel 작업 영역 설계, SIEM 설정 방법, 타사 도구에서 로그 수집, 방화벽 또는 Linux syslog를 Azure에 수집, 탐지 규칙 작성, 사고 대응 자동화, Sentinel 비용은 얼마입니까, 보조 로그, 기본 로그, ADX 아카이브, 코드리스 커넥터. 목표가 Microsoft 365 XDR 경고를 사건과 연관시키거나(defender-xdr 사용) Sentinel을 통합 Defender 포털에 온보딩하는 것(통합-secops-플랫폼 사용)인 경우에는 사용하지 마십시오.
