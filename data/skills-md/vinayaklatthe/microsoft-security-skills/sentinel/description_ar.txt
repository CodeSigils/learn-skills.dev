إرشادات لتصميم وتشغيل Microsoft Sentinel، وSIEM وSOAR السحابي الأصلي الذي يتم تقديمه من خلال بوابة Defender. يغطي تصميم مساحة العمل، وموصلات البيانات، ومستويات الاستيعاب (التحليلات/الأساسية/المساعدة/ADX)، وقواعد التحليلات، والصيد، وقوائم المراقبة، وإرشادات التشغيل الآلي، وتحسين مستوى التكلفة/الالتزام. متى: نشر Microsoft Sentinel، وتصميم SIEM، وموصلات البيانات المدمجة، وكتابة قاعدة التحليلات، واكتشاف KQL، وSentinel Playbook، وأتمتة SOAR، وتحسين تكلفة Sentinel، وطبقات استيعاب السجل، وطبقة الالتزام، وتصميم مساحة عمل Sentinel، وكيف أقوم بإعداد SIEM، وجمع السجلات من أدوات الطرف الثالث، واستيعاب جدار الحماية أو سجل نظام Linux في Azure، وكتابة قاعدة اكتشاف، وأتمتة الاستجابة للحوادث، وما مقدار ذلك؟ تكلفة الحراسة، والسجلات المساعدة، والسجلات الأساسية، وأرشيف ADX، والموصل بدون تعليمات برمجية. لا تستخدمه عندما يكون الهدف هو ربط تنبيهات Microsoft 365 XDR بالحوادث (استخدم المدافع-xdr) أو إعداد Sentinel في بوابة Defender الموحدة (استخدم النظام الأساسي الموحد-secops).
