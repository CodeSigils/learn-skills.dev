Defender ポータルを通じて提供されるクラウドネイティブ SIEM および SOAR である Microsoft Sentinel の設計と運用に関するガイダンス。ワークスペースの設計、データ コネクタ、取り込み層 (分析/基本/補助/ADX)、分析ルール、ハンティング、ウォッチリスト、自動化プレイブック、コスト/コミットメント層の最適化をカバーします。時期: Microsoft Sentinel のデプロイ、SIEM の設計、オンボード データ コネクタ、分析ルールの作成、KQL 検出、Sentinel プレイブック、SOAR 自動化、Sentinel コストの最適化、ログ取り込み層、コミットメント層、Sentinel ワークスペースの設計、SIEM の設定方法、サードパーティ ツールからのログ収集、ファイアウォールまたは Linux syslog の Azure への取り込み、検出ルールの作成、インシデント対応の自動化、Sentinel の費用はいくらですかコスト、補助ログ、基本ログ、ADX アーカイブ、コードレス コネクタ。 Microsoft 365 XDR アラートをインシデントに関連付けること (defender-xdr を使用)、または統合 Defender ポータルに Sentinel をオンボードすること (unified-secops-platform を使用) が目的の場合は使用しないでください。
