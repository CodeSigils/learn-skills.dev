Conseils pour la conception et l’exploitation de Microsoft Sentinel, le SIEM et SOAR cloud natifs fournis via le portail Defender. Couvre la conception de l'espace de travail, les connecteurs de données, les niveaux d'ingestion (Analytics/Basic/Auxiliary/ADX), les règles d'analyse, la recherche, les listes de surveillance, les playbooks d'automatisation et l'optimisation des coûts/niveaux d'engagement. QUAND : déployer Microsoft Sentinel, concevoir SIEM, intégrer des connecteurs de données, écrire une règle d'analyse, détection KQL, playbook Sentinel, automatisation SOAR, optimisation des coûts Sentinel, niveaux d'ingestion de journaux, niveau d'engagement, conception d'espace de travail Sentinel, comment configurer un SIEM, collecter des journaux à partir d'outils tiers, ingérer un pare-feu ou un syslog Linux dans Azure, écrire une règle de détection, automatiser la réponse aux incidents, combien coûte Sentinel, journaux auxiliaires, de base journaux, archives ADX, connecteur sans code. NE PAS UTILISER lorsque l'objectif est de corréler les alertes Microsoft 365 XDR avec des incidents (utilisez Defender-xdr) ou d'intégrer Sentinel dans le portail Defender unifié (utilisez la plateforme unified-secops).
