Microsoft Purview IRM(내부자 위험 관리)에 대한 지침 — M365, Entra, Defender, Windows 엔드포인트, HR 시스템 및 Adaptive Protection의 신호를 사용하여 위험한 사용자 활동(퇴사 직원에 의한 데이터 도난, 지적 재산 유출, 보안 정책 위반)을 감지, 조사 및 조치합니다. 정책 템플릿(떠나는 사용자에 의한 데이터 도용, 데이터 유출, 보안 정책 위반), HRIS 커넥터 설정, 표시기 선택, 시퀀스 감지, 이상 감지, 경고 분류, 콘텐츠 탐색기를 사용한 사례 조사, eDiscovery 및 통신 규정 준수와의 통합, Adaptive Protection의 자동 DLP 정책 조정, 개인 정보 보호 제어(가명화), 역할 분리 및 테넌트 허용 목록을 다룹니다. 시기: 내부자 위험 관리, IRM 정책, 데이터 도용 출발 사용자, IP 누출 감지, HRIS 커넥터 Purview, Adaptive Protection, 내부자 위험 표시기, 시퀀스 감지 Purview, IRM 사례 조사, IRM 개인 정보 보호 제어, IRM 가명화, 내부자 위험 Sentinel. DLP 정책 작성(purview-dlp-policy / purview-advanced-dlp 사용), eDiscovery 전용(purview-ediscovery 사용) 또는 일반 내부자 위험 전략(insider-risk-baseline 사용)에는 사용하지 마십시오.
