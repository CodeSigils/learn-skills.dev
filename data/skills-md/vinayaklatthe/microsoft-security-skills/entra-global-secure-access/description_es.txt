Guía para Microsoft Entra Global Secure Access (GSA): Security Service Edge (SSE) de Microsoft que combina Entra Internet Access (SWG/Secure Web Gateway) y Entra Private Access (reemplazo de ZTNA para VPN). Cubre la implementación de clientes (Windows, macOS, iOS, Android), perfiles de reenvío de tráfico (Microsoft, Internet, Privado), acceso condicional para tráfico de red, restauración de IP de origen, descubrimiento de aplicaciones, acceso rápido y acceso por aplicación para acceso privado, implementación de conectores, conectividad de sitios de sucursales (IPSec), inspección de TLS e integración de CA universal. CUÁNDO: Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, reemplazar VPN con ZTNA, puerta de enlace web segura Entra, acceso condicional en la red, restauración de IP de origen, aplicación Quick Access, conector de acceso privado, rama IPSec a Microsoft, implementación del cliente GSA. NO LO USE para el diseño de políticas generales de acceso condicional (use conditional-access-mfa), el diseño de Azure VPN/ExpressRoute o la configuración de SSE de terceros (Zscaler/Netskope).
