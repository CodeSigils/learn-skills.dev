Microsoft Entra Global Secure Access (GSA) 指南 — Microsoft 的安全服務邊緣 (SSE) 結合了 Entra Internet Access（SWG/安全 Web 閘道）和 Entra Private Access（VPN 的 ZTNA 替代方案）。涵蓋用戶端部署（Windows、macOS、iOS、Android）、流量轉送設定檔（Microsoft、Internet、專用）、網路流量的條件存取、來源 IP 復原、應用程式發現、專用存取的快速存取和每應用程式存取、連接器部署、分支網站連線 (IPSec)、TLS 檢查和通用 CA 整合。時間：Entra Global Secure Access、GSA、Microsoft SSE、Entra Internet Access、Entra Private Access、ZTNA Microsoft、以 ZTNA 取代 VPN、安全 Web 閘道 Entra、網路條件存取、來源 IP 復原、快速存取應用程式、私人存取連接器、分支 IPSec 到 Microsoft、GSA 用戶端推出。請勿用於一般條件存取策略設計（使用條件存取 mfa）、Azure VPN/ExpressRoute 設計或第三方 SSE (Zscaler/Netskope) 設定。
