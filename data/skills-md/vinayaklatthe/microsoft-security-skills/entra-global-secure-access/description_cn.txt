Microsoft Entra Global Secure Access (GSA) 指南 — Microsoft 的安全服务边缘 (SSE) 结合了 Entra Internet Access（SWG/安全 Web 网关）和 Entra Private Access（VPN 的 ZTNA 替代品）。涵盖客户端部署（Windows、macOS、iOS、Android）、流量转发配置文件（Microsoft、Internet、专用）、网络流量的条件访问、源 IP 恢复、应用程序发现、专用访问的快速访问和每应用程序访问、连接器部署、分支站点连接 (IPSec)、TLS 检查和通用 CA 集成。时间：Entra Global Secure Access、GSA、Microsoft SSE、Entra Internet Access、Entra Private Access、ZTNA Microsoft、用 ZTNA 替换 VPN、安全 Web 网关 Entra、网络条件访问、源 IP 恢复、快速访问应用程序、私有访问连接器、分支 IPSec 到 Microsoft、GSA 客户端推出。请勿用于一般条件访问策略设计（使用条件访问 mfa）、Azure VPN/ExpressRoute 设计或第三方 SSE (Zscaler/Netskope) 配置。
