Conseils pour Microsoft Entra Global Secure Access (GSA) — Security Service Edge (SSE) de Microsoft combinant Entra Internet Access (SWG/Secure Web Gateway) et Entra Private Access (remplacement ZTNA pour VPN). Couvre le déploiement de clients (Windows, macOS, iOS, Android), les profils de transfert de trafic (Microsoft, Internet, privé), l'accès conditionnel pour le trafic réseau, la restauration de l'adresse IP source, la découverte d'applications, l'accès rapide et l'accès par application pour l'accès privé, le déploiement de connecteurs, la connectivité des sites de succursales (IPSec), l'inspection TLS et l'intégration de l'autorité de certification universelle. QUAND : Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, remplacement du VPN par ZTNA, passerelle Web sécurisée Entra, accès conditionnel sur le réseau, restauration de l'IP source, application Quick Access, connecteur d'accès privé, branche IPSec vers Microsoft, déploiement du client GSA. NE PAS UTILISER pour la conception générale de politiques d’accès conditionnel (utilisez conditional-access-mfa), la conception Azure VPN/ExpressRoute ou la configuration SSE tierce (Zscaler/Netskope).
