إرشادات للوصول الآمن العالمي لـ Microsoft Entra (GSA) — Microsoft Security Service Edge (SSE) الذي يجمع بين Entra Internet Access (SWG/Secure Web Gateway) وEntra Private Access (استبدال ZTNA لـ VPN). يغطي نشر العميل (Windows وmacOS وiOS وAndroid)، وملفات تعريف إعادة توجيه حركة المرور (Microsoft، والإنترنت، والخاص)، والوصول المشروط لحركة مرور الشبكة، واستعادة IP المصدر، واكتشاف التطبيق، والوصول السريع والوصول لكل تطبيق للوصول الخاص، ونشر الموصل، واتصال موقع الفرع (IPSec)، وفحص TLS، وتكامل CA الشامل. متى: Entra Global Secure Access، GSA، Microsoft SSE، Entra Internet Access، Entra Private Access، ZTNA Microsoft، استبدال VPN بـ ZTNA، بوابة الويب الآمنة Entra، الوصول المشروط على الشبكة، استعادة IP المصدر، تطبيق الوصول السريع، موصل الوصول الخاص، فرع IPSec إلى Microsoft، طرح عميل GSA. لا تستخدمه لتصميم نهج الوصول المشروط العام (استخدم الوصول المشروط-mfa)، أو تصميم Azure VPN/ExpressRoute، أو تكوين SSE (Zscaler/Netskope) لجهة خارجية.
