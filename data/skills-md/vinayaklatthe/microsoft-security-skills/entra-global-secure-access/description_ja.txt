Microsoft Entra Global Secure Access (GSA) のガイダンス — Entra Internet Access (SWG/Secure Web Gateway) と Entra Private Access (VPN の ZTNA 代替) を組み合わせた Microsoft の Security Service Edge (SSE)。クライアント展開 (Windows、macOS、iOS、Android)、トラフィック転送プロファイル (Microsoft、インターネット、プライベート)、ネットワーク トラフィックの条件付きアクセス、ソース IP の復元、アプリの検出、プライベート アクセスのクイック アクセスとアプリごとのアクセス、コネクタの展開、ブランチ サイト接続 (IPSec)、TLS 検査、およびユニバーサル CA 統合をカバーします。時期: Entra Global Secure Access、GSA、Microsoft SSE、Entra Internet Access、Entra Private Access、ZTNA Microsoft、VPN を ZTNA に置き換え、セキュア Web ゲートウェイ Entra、ネットワーク上の条件付きアクセス、ソース IP の復元、クイック アクセス アプリ、プライベート アクセス コネクタ、Microsoft へのブランチ IPSec、GSA クライアントのロールアウト。一般的な条件付きアクセス ポリシーの設計 (条件付きアクセス-mfa を使用)、Azure VPN/ExpressRoute 設計、またはサードパーティの SSE (Zscaler/Netskope) 構成には使用しないでください。
