Руководство для Microsoft Entra Global Secure Access (GSA) — Microsoft Security Service Edge (SSE), сочетающее Entra Internet Access (SWG/Secure Web Gateway) и Entra Private Access (замена ZTNA для VPN). Охватывает развертывание клиента (Windows, macOS, iOS, Android), профили переадресации трафика (Microsoft, Интернет, частный), условный доступ для сетевого трафика, восстановление исходного IP-адреса, обнаружение приложений, быстрый доступ и доступ для каждого приложения для частного доступа, развертывание соединителя, подключение к сайту филиала (IPSec), проверку TLS и интеграцию с универсальным центром сертификации. КОГДА: Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, замена VPN на ZTNA, безопасный веб-шлюз Entra, условный доступ в сети, восстановление исходного IP-адреса, приложение быстрого доступа, соединитель частного доступа, разветвление IPSec на Microsoft, развертывание клиента GSA. НЕ ИСПОЛЬЗУЙТЕ для общей разработки политики условного доступа (используйте условный доступ-mfa), разработки Azure VPN/ExpressRoute или сторонней конфигурации SSE (Zscaler/Netskope).
