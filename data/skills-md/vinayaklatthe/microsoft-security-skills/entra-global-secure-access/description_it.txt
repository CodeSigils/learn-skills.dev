Linee guida per Microsoft Entra Global Secure Access (GSA): Security Service Edge (SSE) di Microsoft che combina Entra Internet Access (SWG/Secure Web Gateway) ed Entra Private Access (sostituzione ZTNA per VPN). Copre la distribuzione client (Windows, macOS, iOS, Android), i profili di inoltro del traffico (Microsoft, Internet, Privato), l'accesso condizionale per il traffico di rete, il ripristino dell'IP di origine, il rilevamento delle app, l'accesso rapido e l'accesso per app per l'accesso privato, la distribuzione dei connettori, la connettività del sito di filiale (IPSec), l'ispezione TLS e l'integrazione della CA universale. QUANDO: Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, sostituzione VPN con ZTNA, gateway web sicuro Entra, Accesso condizionale sulla rete, ripristino IP di origine, app Quick Access, connettore di accesso privato, ramo IPSec verso Microsoft, implementazione del client GSA. NON UTILIZZARE per la progettazione generale dei criteri di accesso condizionale (usare l'accesso condizionale-mfa), la progettazione di VPN/ExpressRoute di Azure o la configurazione SSE di terze parti (Zscaler/Netskope).
