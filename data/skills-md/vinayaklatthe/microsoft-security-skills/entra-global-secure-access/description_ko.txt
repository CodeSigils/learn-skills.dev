Microsoft Entra GSA(Global Secure Access)에 대한 지침 - Entra Internet Access(SWG/보안 웹 게이트웨이)와 Entra Private Access(VPN의 ZTNA 대체)를 결합한 Microsoft의 SSE(Security Service Edge)입니다. 클라이언트 배포(Windows, macOS, iOS, Android), 트래픽 전달 프로필(Microsoft, 인터넷, 개인), 네트워크 트래픽을 위한 조건부 액세스, 소스 IP 복원, 앱 검색, 개인 액세스를 위한 빠른 액세스 및 앱별 액세스, 커넥터 배포, IPSec(분기 사이트 연결), TLS 검사 및 Universal CA 통합을 다룹니다. 시기: Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, VPN을 ZTNA로 교체, 보안 웹 게이트웨이 Entra, 네트워크의 조건부 액세스, 소스 IP 복원, 빠른 액세스 앱, 개인 액세스 커넥터, IPSec를 Microsoft로 분기, GSA 클라이언트 롤아웃. 일반 조건부 액세스 정책 설계(conditional-access-mfa 사용), Azure VPN/ExpressRoute 설계 또는 타사 SSE(Zscaler/Netskope) 구성에는 사용하지 마세요.
