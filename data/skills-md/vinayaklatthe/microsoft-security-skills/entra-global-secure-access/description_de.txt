Leitfaden für Microsoft Entra Global Secure Access (GSA) – Microsofts Security Service Edge (SSE), der Entra Internet Access (SWG/Secure Web Gateway) und Entra Private Access (ZTNA-Ersatz für VPN) kombiniert. Umfasst Client-Bereitstellung (Windows, macOS, iOS, Android), Verkehrsweiterleitungsprofile (Microsoft, Internet, Privat), bedingten Zugriff für Netzwerkverkehr, Quell-IP-Wiederherstellung, App-Erkennung, Schnellzugriff und Zugriff pro App für privaten Zugriff, Connector-Bereitstellung, Zweigstellenkonnektivität (IPSec), TLS-Inspektion und universelle CA-Integration. WANN: Entra Global Secure Access, GSA, Microsoft SSE, Entra Internet Access, Entra Private Access, ZTNA Microsoft, VPN durch ZTNA ersetzen, sicheres Web-Gateway Entra, bedingter Zugriff im Netzwerk, Quell-IP-Wiederherstellung, Quick Access-App, Private Access Connector, Verzweigung von IPSec zu Microsoft, GSA-Client-Rollout. NICHT für den allgemeinen Richtlinienentwurf für bedingten Zugriff (verwenden Sie Conditional-Access-MFA), den Azure VPN/ExpressRoute-Entwurf oder die SSE-Konfiguration (Zscaler/Netskope) eines Drittanbieters verwenden.
