إرشادات لتصنيف بيانات Microsoft Purview وتسميات الحساسية - أنواع المعلومات الحساسة (SITs)، والمصنفات القابلة للتدريب، والمطابقة الدقيقة للبيانات، وتصنيف ملصقات الحساسية مع وضع العلامات التلقائية. يغطي بناء تصنيف الملصقات واختيار طرق الكشف ونشر العلامات التلقائية في المحاكاة. متى: تصنيف البيانات، تسميات الحساسية، أنواع المعلومات الحساسة، SIT، المصنف القابل للتدريب، مطابقة البيانات الدقيقة EDM، وضع العلامات التلقائية، تصنيف الملصقات، تصنيف البيانات، تسميات حماية المعلومات، تسميات MIP.
