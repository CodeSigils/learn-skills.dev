Guía para la clasificación de datos y etiquetas de confidencialidad de Microsoft Purview: tipos de información confidencial (SIT), clasificadores entrenables, coincidencia exacta de datos y taxonomía de etiquetas de confidencialidad con etiquetado automático. Cubre la creación de una taxonomía de etiquetas, la elección de métodos de detección y la implementación del etiquetado automático en simulación. CUÁNDO: clasificación de datos, etiquetas de confidencialidad, tipos de información confidencial, SIT, clasificador entrenable, coincidencia exacta de datos EDM, etiquetado automático, taxonomía de etiquetas, clasificación de datos, etiquetas de protección de información, etiquetas MIP.
