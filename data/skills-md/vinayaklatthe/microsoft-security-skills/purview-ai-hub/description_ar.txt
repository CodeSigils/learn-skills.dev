إرشادات لـ Microsoft Purview AI Hub (الآن جزء من Data Security Posture Management for AI) - اكتشاف وإدارة وحماية البيانات الحساسة المتدفقة إلى تطبيقات الذكاء الاصطناعي (Microsoft 365 Copilot، ووكلاء Copilot Studio، وChatGPT، وGemini، والذكاء الاصطناعي المولد من طرف ثالث). يغطي اكتشاف تطبيقات الذكاء الاصطناعي عبر Defender for Cloud Apps + إشارات نقطة النهاية، وسطح مخاطر البيانات الحساسة، وسياسات جاهزة للاستخدام للمشاركة المفرطة لـ Copilot واستخدام الذكاء الاصطناعي المحفوف بالمخاطر، وDLP لنقاط نهاية الذكاء الاصطناعي التوليدية (حظر المتصفح)، وتدقيق المطالبة/الاستجابة، والتكامل مع IRM (استخدام الذكاء الاصطناعي الخطير)، وتقارير Sentinel، والاختلاف مقابل Defender for Cloud AI حماية أعباء العمل. متى: Purview AI Hub، DSPM للذكاء الاصطناعي، اكتشاف تطبيقات الذكاء الاصطناعي، تسرب بيانات ChatGPT، Gemini DLP، مخاطر الذكاء الاصطناعي التوليدية، التدقيق الفوري، حوكمة وكيل Copilot Studio، البيانات الحساسة للذكاء الاصطناعي، الظل AI، مخاطر بيانات الوكيل. لا تستخدمه لحماية أعباء عمل Defender for Cloud AI (استخدم Defender-for-cloud-ai)، أو Azure AI Content Safety (استخدم azure-ai-content-safety)، أو طرح Microsoft 365 Copilot (استخدم copilot-for-m365-readiness).
