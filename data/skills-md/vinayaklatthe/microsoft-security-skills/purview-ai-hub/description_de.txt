Leitfaden für Microsoft Purview AI Hub (jetzt Teil von Data Security Posture Management for AI) – Erkennen, steuern und schützen Sie sensible Daten, die in KI-Anwendungen fließen (Microsoft 365 Copilot, Copilot Studio-Agenten, ChatGPT, Gemini, generative KI von Drittanbietern). Deckt die KI-App-Erkennung über Defender für Cloud-Apps + Endpunktsignale, die Risikooberfläche sensibler Daten, gebrauchsfertige Richtlinien für Copilot-Oversharing und riskante KI-Nutzung, DLP für generative KI-Endpunkte (Browserblockierung), Prompt-/Response-Überwachung, Integration mit IRM (riskante KI-Nutzung), Sentinel-Berichterstellung und den Unterschied zum Defender für Cloud-KI-Workload-Schutz ab. WANN: Purview AI Hub, DSPM für KI, KI-App-Erkennung, ChatGPT-Datenleck, Gemini DLP, generatives KI-Risiko, sofortige Prüfung, Copilot Studio-Agenten-Governance, sensible Daten für KI, Schatten-KI, Agentendatenrisiko. NICHT für den KI-Workload-Schutz von Defender for Cloud (verwenden Sie Defender-for-Cloud-AI), Azure AI Content Safety (verwenden Sie Azure-AI-Content-Safety) oder den Rollout von Microsoft 365 Copilot (verwenden Sie Copilot-for-m365-readiness) verwenden.
