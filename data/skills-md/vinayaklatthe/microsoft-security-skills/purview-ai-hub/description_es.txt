Guía para Microsoft Purview AI Hub (ahora parte de Data Security Posture Management para AI): descubra, gobierne y proteja los datos confidenciales que fluyen hacia aplicaciones de AI (Microsoft 365 Copilot, agentes Copilot Studio, ChatGPT, Gemini, AI generativa de terceros). Cubre el descubrimiento de aplicaciones de IA a través de Defender para aplicaciones en la nube + señales de endpoints, superficie de riesgo de datos confidenciales, políticas listas para usar para el uso compartido excesivo de Copilot y el uso riesgoso de AI, DLP para endpoints de AI generativa (bloqueo de navegador), auditoría de avisos/respuestas, integración con IRM (uso riesgoso de AI), informes Sentinel y la diferencia con Defender para la protección de cargas de trabajo de AI en la nube. CUÁNDO: Purview AI Hub, DSPM para IA, descubrimiento de aplicaciones de IA, fuga de datos ChatGPT, Gemini DLP, riesgo de IA generativa, auditoría rápida, gobernanza de agentes de Copilot Studio, datos confidenciales para IA, IA en la sombra, riesgo de datos de agentes. NO LO USE para la protección de cargas de trabajo de IA de Defender for Cloud (use defender-for-cloud-ai), Azure AI Content Safety (use azure-ai-content-safety) o la implementación de Microsoft 365 Copilot (use copilot-for-m365-readiness).
