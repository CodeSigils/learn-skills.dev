Conseils pour Microsoft Purview AI Hub (qui fait désormais partie de Data Security Posture Management for AI) : découvrez, gouvernez et protégez les données sensibles circulant dans les applications d'IA (Microsoft 365 Copilot, agents Copilot Studio, ChatGPT, Gemini, IA générative tierce). Couvre la découverte d'applications d'IA via Defender pour Cloud Apps + signaux de point de terminaison, la surface de risque des données sensibles, les politiques prêtes à l'emploi pour le partage excessif de Copilot et l'utilisation à risque de l'IA, le DLP pour les points de terminaison d'IA génératifs (blocage du navigateur), l'audit d'invite/réponse, l'intégration avec IRM (utilisation à risque de l'IA), les rapports Sentinel et la différence par rapport à Defender pour la protection des charges de travail de l'IA dans le cloud. QUAND : Purview AI Hub, DSPM pour l'IA, découverte d'applications IA, fuite de données ChatGPT, Gemini DLP, risque IA génératif, audit rapide, gouvernance des agents Copilot Studio, données sensibles pour l'IA, IA fantôme, risque lié aux données des agents. NE PAS UTILISER pour la protection de la charge de travail IA de Defender pour Cloud (utilisez Defender-for-cloud-ai), Azure AI Content Safety (utilisez azure-ai-content-safety) ou le déploiement Microsoft 365 Copilot (utilisez copilot-for-m365-readiness).
