Руководство для Microsoft Purview AI Hub (теперь часть Data Security Posture Management для AI) — обнаружение, управление и защита конфиденциальных данных, поступающих в приложения AI (Microsoft 365 Copilot, агенты Copilot Studio, ChatGPT, Gemini, сторонний генеративный искусственный интеллект). Охватывает обнаружение приложений ИИ с помощью Defender для облачных приложений + сигналы конечных точек, поверхность риска конфиденциальных данных, готовые к использованию политики для совместного использования Copilot и рискованного использования ИИ, DLP для конечных точек генеративного ИИ (блокировка браузера), аудит запросов/ответов, интеграцию с IRM (рискованное использование ИИ), отчеты Sentinel и разницу с Defender для защиты рабочих нагрузок облачного ИИ. КОГДА: Purview AI Hub, DSPM для ИИ, обнаружение приложений ИИ, утечка данных ChatGPT, Gemini DLP, риск генеративного ИИ, оперативный аудит, управление агентами Copilot Studio, конфиденциальные данные для ИИ, теневой ИИ, риск данных агента. НЕ ИСПОЛЬЗУЙТЕ для защиты рабочих нагрузок искусственного интеллекта в Defender for Cloud (используйте защитник-для-cloud-ai), Azure AI Content Safety (используйте azure-ai-content-safety) или развертывания Microsoft 365 Copilot (используйте copilot-for-m365-readiness).
