Úselo al crear o modificar un complemento de Halo CMS: escribir código de backend de Java, configurar plugin.yaml, definir extensiones personalizadas (GVK), crear API personalizadas (CustomEndpoint, controladores MVC), crear una interfaz de usuario basada en Vue con @halo-dev/ui-shared, configurar compilaciones de Gradle con DevTools, definir plantillas de roles RBAC, generar clientes de API desde OpenAPI, registrar API de Finder del lado del tema o manejar el ciclo de vida del complemento (iniciar/detener/eliminar).
