Da utilizzare durante la creazione o la modifica di un plug-in Halo CMS: scrittura di codice backend Java, configurazione plugin.yaml, definizione di estensioni personalizzate (GVK), creazione di API personalizzate (CustomEndpoint, controller MVC), creazione di un'interfaccia utente basata su Vue con @halo-dev/ui-shared, configurazione di build Gradle con DevTools, definizione di modelli di ruolo RBAC, generazione di client API da OpenAPI, registrazione di API Finder lato tema o gestione del ciclo di vita del plug-in (avvia/interrompi/elimina).
