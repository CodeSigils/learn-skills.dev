Verwendung beim Erstellen oder Ändern eines Halo CMS-Plugins: Schreiben von Java-Backend-Code, Konfigurieren von Plugin.yaml, Definieren benutzerdefinierter Erweiterungen (GVK), Erstellen benutzerdefinierter APIs (CustomEndpoint, MVC-Controller), Erstellen einer Vue-basierten Benutzeroberfläche mit @halo-dev/ui-shared, Einrichten von Gradle-Builds mit DevTools, Definieren von RBAC-Rollenvorlagen, Generieren von API-Clients aus OpenAPI, Registrieren themenseitiger Finder-APIs oder Verwalten des Plugin-Lebenszyklus (Starten/Stoppen/Löschen).
