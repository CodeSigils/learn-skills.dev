À utiliser lors de la création ou de la modification d'un plugin Halo CMS : écriture de code backend Java, configuration de plugin.yaml, définition d'extensions personnalisées (GVK), création d'API personnalisées (CustomEndpoint, contrôleurs MVC), création d'une interface utilisateur basée sur Vue avec @halo-dev/ui-shared, configuration de builds Gradle avec DevTools, définition de modèles de rôle RBAC, génération de clients API à partir d'OpenAPI, enregistrement des API Finder côté thème ou gestion du cycle de vie du plugin (démarrage/arrêt/suppression).
