Verwendung beim Erstellen oder Ändern eines Halo-CMS-Themes: Schreiben von Thymeleaf-Vorlagen, Konfigurieren von theme.yaml oder Settings.yaml, Aufrufen von Finder-APIs, Verwenden von vite-plugin-halo-theme, Definieren von Theme-Einstellungsformularen, Referenzieren statischer Assets, Implementieren von halo:comment- oder halo:footer-Erweiterungspunkten oder Definieren von Modellanmerkungsfeldern (AnnotationSetting).
