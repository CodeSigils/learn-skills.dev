Úselo al crear o modificar un tema de Halo CMS: escribir plantillas de Thymeleaf, configurar theme.yaml o settings.yaml, llamar a las API de Finder, usar vite-plugin-halo-theme, definir formularios de configuración de temas, hacer referencia a recursos estáticos, implementar puntos de extensión halo:comment o halo:footer o definir campos de anotación de modelo (AnnotationSetting).
