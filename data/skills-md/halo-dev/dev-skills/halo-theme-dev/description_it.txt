Da utilizzare durante la creazione o la modifica di un tema Halo CMS: scrittura di modelli Thymeleaf, configurazione di theme.yaml o settings.yaml, chiamata delle API del Finder, utilizzo di vite-plugin-halo-theme, definizione di moduli di impostazioni del tema, riferimento a risorse statiche, implementazione di punti di estensione halo:comment o halo:footer o definizione di campi di annotazione del modello (AnnotationSetting).
