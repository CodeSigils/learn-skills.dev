Personalice el tema, los tokens y el sistema de diseño de Chakra UI v3. Úselo cuando el usuario desee personalizar el tema, crear tokens de diseño, tokens semánticos, recetas de componentes, recetas de tragamonedas o modificar colores/espaciados/tipografía a nivel del tema. Activadores para "personalizar tema", "cambiar colores", "crear tokens de diseño", "anular estilos de componentes", "agregar colores de marca", "definir componentes personalizados" o cuando se trabaja con createSystem, defineConfig o archivos de configuración de temas.
