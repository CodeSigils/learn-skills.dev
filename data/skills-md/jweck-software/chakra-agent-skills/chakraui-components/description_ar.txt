بناء واجهة المستخدم مع مكونات Chakra UI v3. يُستخدم عندما يذكر المستخدم Chakra UI، أو يسأل عن مكونات Chakra (الزر، أو الحوار، أو الجدول، أو القائمة، أو علامات التبويب، أو الإدخال، وما إلى ذلك)، أو يحتاج إلى عناصر النموذج، أو التراكبات، أو التنقل، أو مكونات عرض البيانات. يُستخدم أيضًا عند تنفيذ التخطيطات (Flex، أو Grid، أو Stack)، أو الطباعة (النص، أو العنوان)، أو أي تصميم لمكونات React باستخدام Chakra. مشغلات لعبارات مثل "كيف أقوم بإجراء حوار"، أو "إنشاء نموذج"، أو "إضافة قائمة"، أو "إظهار جدول"، أو عندما يحتوي الكود على عمليات استيراد @chakra-ui/react.
