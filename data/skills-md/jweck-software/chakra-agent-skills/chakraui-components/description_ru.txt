Создайте пользовательский интерфейс с помощью компонентов Chakra UI v3. Используйте, когда пользователь упоминает пользовательский интерфейс Chakra, спрашивает о компонентах Chakra (кнопка, диалоговое окно, таблица, меню, вкладки, ввод и т. д.), ему нужны элементы формы, наложения, навигация или компоненты отображения данных. Также используйте при реализации макетов (Flex, Grid, Stack), типографики (текст, заголовок) или любого стиля компонентов React с помощью Chakra. Запускает такие фразы, как «как создать диалоговое окно», «создать форму», «добавить меню», «показать таблицу» или когда код содержит импорт @chakra-ui/react.
