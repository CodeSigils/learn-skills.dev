Chakra UI v3 구성 요소를 사용하여 UI를 빌드합니다. 사용자가 Chakra UI를 언급하고, Chakra 구성 요소(버튼, 대화 상자, 테이블, 메뉴, 탭, 입력 등)에 대해 질문하고, 양식 요소, 오버레이, 탐색 또는 데이터 표시 구성 요소가 필요할 때 사용합니다. 또한 Chakra를 사용하여 레이아웃(Flex, Grid, Stack), 타이포그래피(텍스트, 제목) 또는 React 구성 요소 스타일을 구현할 때 사용합니다. "대화 상자를 만드는 방법", "양식 만들기", "메뉴 추가", "테이블 표시"와 같은 문구 또는 코드에 @chakra-ui/react 가져오기가 포함된 경우에 대해 트리거됩니다.
