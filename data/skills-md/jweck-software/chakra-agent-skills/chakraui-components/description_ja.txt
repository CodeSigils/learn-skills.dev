Chakra UI v3 コンポーネントを使用して UI を構築します。ユーザーが Chakra UI について言及する場合、Chakra コンポーネント (ボタン、ダイアログ、テーブル、メニュー、タブ、入力など) について尋ねる場合、フォーム要素、オーバーレイ、ナビゲーション、またはデータ表示コンポーネントが必要な場合に使用します。レイアウト (フレックス、グリッド、スタック)、タイポグラフィー (テキスト、見出し)、または Chakra を使用した React コンポーネントのスタイルを実装するときにも使用します。 「ダイアログの作成方法」、「フォームの作成」、「メニューの追加」、「テーブルの表示」などのフレーズ、またはコードに @chakra-ui/react imports が含まれている場合のトリガー。
