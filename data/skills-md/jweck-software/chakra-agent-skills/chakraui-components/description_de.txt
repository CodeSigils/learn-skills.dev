Erstellen Sie eine Benutzeroberfläche mit Chakra UI v3-Komponenten. Wird verwendet, wenn der Benutzer die Chakra-Benutzeroberfläche erwähnt, nach Chakra-Komponenten fragt (Schaltfläche, Dialog, Tabelle, Menü, Registerkarten, Eingabe usw.) und Formularelemente, Überlagerungen, Navigation oder Datenanzeigekomponenten benötigt. Verwenden Sie es auch bei der Implementierung von Layouts (Flex, Grid, Stack), Typografie (Text, Überschrift) oder einem beliebigen React-Komponentenstil mit Chakra. Auslöser für Ausdrücke wie „Wie erstelle ich einen Dialog“, „Erstelle ein Formular“, „Füge ein Menü hinzu“, „zeige eine Tabelle“ oder wenn Code @chakra-ui/react-Importe enthält.
