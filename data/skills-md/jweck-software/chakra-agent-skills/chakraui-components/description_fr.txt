Créez une interface utilisateur avec les composants Chakra UI v3. À utiliser lorsque l'utilisateur mentionne Chakra UI, pose des questions sur les composants Chakra (bouton, boîte de dialogue, tableau, menu, onglets, saisie, etc.), a besoin d'éléments de formulaire, de superpositions, de composants de navigation ou d'affichage de données. À utiliser également lors de l'implémentation de mises en page (Flex, Grid, Stack), de typographie (Texte, Titre) ou de tout style de composant React avec Chakra. Déclencheurs pour des expressions telles que « comment créer une boîte de dialogue », « créer un formulaire », « ajouter un menu », « afficher un tableau » ou lorsque le code contient des importations @chakra-ui/react.
