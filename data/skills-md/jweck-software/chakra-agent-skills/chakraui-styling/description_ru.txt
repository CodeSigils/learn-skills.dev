Применяйте шаблоны стилей Chakra UI v3, реквизиты стиля и адаптивный дизайн. Используйте, когда пользователь спрашивает о стиле Chakra, свойствах CSS (отступы, поля, фон, цвет), адаптивных точках останова, условных стилях (_hover, _focus, _dark) или стилях макета. Триггеры для «как создать стиль», «сделать его отзывчивым», «добавить эффект наведения», «стили темного режима», «центрировать элемент div» или при использовании таких свойств стиля, как p="", m="", bg="", rounded="", или адаптивного синтаксиса.
