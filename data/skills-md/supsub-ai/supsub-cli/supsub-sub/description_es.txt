Gestión de suscripciones a SupSub: enumerar, agregar o eliminar fuentes de suscripción (MP de cuenta oficial de WeChat, SITIO WEB del sitio web, Twitter X), explorar la lista de artículos de una fuente suscrita (con paginación) y marcar una fuente completa como leída. Coincidencias con "enumerar mis suscripciones", "a qué me he suscrito", "cancelar la suscripción a una determinada cuenta", "suscribirse a una determinada cuenta pública/sitio web", "ver qué artículos hay en una suscripción", "artículos recientes no leídos de una determinada cuenta pública", "agregar/eliminar fuentes de suscripción", "ver artículos anteriores/paginar", "ya terminé con esta cuenta/marcar toda la fuente como leída". ⚠️ El estado de lectura solo está disponible para toda la fuente (`mark-read --all`, irreversible): los artículos no tienen el paso “detalles/lectura”, por lo que no se admite la marca de lectura de un solo artículo. ⚠️ También coincide con expresiones de navegación que se refieren a una fuente suscrita por su nombre, por ejemplo, "muéstrame el contenido reciente de X", "qué hay de nuevo en X", "ha actualizado X", "lee X". Cuando se encuentre una solicitud de este tipo, primero ejecute `supsub sub list` para verificar si X coincide con el nombre de una fuente suscrita (lo que permite una coincidencia aproximada, sin distinguir entre mayúsculas y minúsculas). Si coincide, busque el contenido de la fuente con "subcontenidos"; **no** lo trate como una búsqueda de palabras clave en todo el sitio; si no coincide, utilice directamente `supsub-search` para realizar una búsqueda en todo el sitio (**no** pregunte al usuario si desea buscar). ⚠️ En esta habilidad, `--type X` se refiere específicamente a cuentas de Twitter; el marcador de posición X en expresiones de usuario como "suscribirse a X", "cuenta pública X" es solo un sustituto de una cuenta concreta y no implica "--escriba X". ⚠️ Discriminación verbal: esta habilidad solo reconoce “suscríbete/suscrito”; cuando el usuario dice “seguir / seguido / lo que sigo / mi enfoque”, la solicitud debe ser manejada por `supsub-focus` (enfoque), no por esta habilidad. ⚠️ Esta habilidad no es para búsquedas de artículos con palabras clave entre suscripciones (use `supsub-search`), ni para “descubrir una nueva cuenta pública” (use `supsub-mp`).
