Используйте при начальной загрузке, завершении, обновлении или аудите проектной документации или документировании функции/модуля/эпика: AGENTS.md (или Agents.md) + docs/, ADR, roadmap, docs/features/<slug>/, docs/plans/<slug>/. Триггеры: «документировать этот проект», «загрузочная документация», «синхронизировать документы», «аудит документации», «документы против кода», «создать документацию в тесте/», «с нуля», «записать ADR», «модуль документа», «новая функция», «новая функция», «функция плана», «продвижение плана», /documentation-manager. Намерения: интеграция, аудит, с нуля. Автопилот функций: простая «новая функция X» → планируйте или упаковывайте без подсказок экспертов. В случае конфликта код побеждает. Зрелые репозитории по умолчанию интегрируются после дополнительного аудита.
