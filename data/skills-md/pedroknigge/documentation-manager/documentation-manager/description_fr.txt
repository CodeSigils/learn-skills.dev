À utiliser lors du démarrage, de la complétion, de la mise à jour ou de l'audit de la documentation du projet, ou de la documentation d'une fonctionnalité/module/épopée : AGENTS.md (ou agents.md) + docs/, ADR, feuille de route, docs/features/<slug>/, docs/plans/<slug>/. Déclencheurs : "documenter ce projet", "bootstrap docs", "sync docs", "audit docs", "docs vs code", "generate docs in test/", "from zero", "write ADRs", "document module", "new feature", "nouvelle feature", "plan feature", "promové el plan", /documentation-manager. Intentions : intégrer, auditer, à partir de zéro. Pilote automatique de fonctionnalité : simple "nouvelle fonctionnalité X" → planifier ou emballer sans invites d'experts. En cas de conflit, le code gagne. Les dépôts matures sont intégrés par défaut après un audit facultatif.
