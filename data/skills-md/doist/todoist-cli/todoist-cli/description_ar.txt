قم بإدارة مهام تودويست، ومشروعاته، والتسميات، والمرشحات، والأقسام، والتعليقات، والتذكيرات، ومساحات العمل عبر سطر الأوامر `td`. يُستخدم عندما يريد المستخدم عرض عناصر Todoist أو إنشائها أو تحديثها أو إكمالها أو تنظيمها، أو الإشارة إلى المهام أو البريد الوارد أو اليوم أو المشاريع القادمة أو التصنيفات أو المرشحات.
