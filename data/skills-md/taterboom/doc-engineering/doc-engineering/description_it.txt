Impostare e mantenere un sistema di documentazione strutturato (Document Engineering) per i progetti software. Utilizzare questa competenza ogni volta che l'utente desidera: impalcare un albero di prodotto/documentazione con PRD, codice, QA e CHANGELOG per funzione; generare o aggiornare uno qualsiasi di questi file doc dopo una modifica del codice; aggiungere una regola CLAUDE.md che impone gli aggiornamenti dei documenti come parte della Definizione di Fatto; installare un hook pre-commit git che avvisa quando le modifiche al codice non corrispondono agli aggiornamenti dei documenti; oppure esegui un controllo periodico che confronti i timestamp del log git con i timestamp dei file doc per far emergere commit non sincronizzati. Si attiva anche quando l'utente dice "ingegneria dei documenti", "ingegneria dei documenti", "mantieni i miei documenti", "mantieni i documenti sincronizzati", "deriva dei documenti" o chiede di impostare la struttura della documentazione per una base di codice.
