Настройка и поддержка системы структурированной документации (Document Engineering) для проектов программного обеспечения. Используйте этот навык всякий раз, когда пользователь хочет: сформировать дерево продукта/документации с помощью PRD, Code, QA и CHANGELOG для каждой функции; генерировать или обновлять любой из этих файлов документов после изменения кода; добавить правило CLAUDE.md, которое обеспечивает обновление документов в рамках определения готовности; установите перехватчик предварительной фиксации git, который предупреждает, когда изменениям кода не хватает соответствующих обновлений документации; или запускайте периодический аудит, который сравнивает временные метки журнала git с временными метками файла doc, чтобы выявить несинхронизированные коммиты. Также срабатывает, когда пользователь говорит «разработка документации», «разработка документации», «поддерживать мои документы», «синхронизировать документы», «дрейф документации» или просит настроить структуру документации для базы кода.
