Aufbau und Pflege eines strukturierten Dokumentationssystems (Document Engineering) für Softwareprojekte. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer: einen Produkt-/Dokumentbaum mit PRD, Code, Qualitätssicherung und CHANGELOG pro Funktion aufbauen möchte; Generieren oder aktualisieren Sie eine dieser Dokumentdateien nach einer Codeänderung. Fügen Sie eine CLAUDE.md-Regel hinzu, die Dokumentaktualisierungen als Teil der Definition of Done erzwingt. Installieren Sie einen Git-Pre-Commit-Hook, der warnt, wenn bei Codeänderungen keine passenden Dokumentaktualisierungen vorhanden sind. Oder führen Sie eine regelmäßige Prüfung durch, bei der die Zeitstempel des Git-Protokolls mit den Zeitstempeln der Dokumentdatei verglichen werden, um nicht synchronisierte Commits aufzudecken. Wird auch ausgelöst, wenn der Benutzer „Doc Engineering“, „Document Engineering“, „Meine Dokumente verwalten“, „Dokumente synchronisieren“, „Doc Drift“ sagt oder die Einrichtung einer Dokumentationsstruktur für eine Codebasis anfordert.
