Configurar y mantener un sistema de documentación estructurado (Ingeniería Documental) para proyectos de software. Utilice esta habilidad siempre que el usuario desee: crear un árbol de productos/documentos con PRD, código, control de calidad y CHANGELOG por función; generar o actualizar cualquiera de esos archivos doc después de un cambio de código; agregue una regla CLAUDE.md que aplique actualizaciones de documentos como parte de la Definición de Hecho; instalar un gancho de confirmación previa de git que advierte cuando los cambios de código carecen de actualizaciones de documentos coincidentes; o ejecute una auditoría periódica que compare las marcas de tiempo de los registros de git con las marcas de tiempo de los archivos doc para mostrar confirmaciones no sincronizadas. También se activa cuando el usuario dice "ingeniería de documentos", "ingeniería de documentos", "mantener mis documentos", "mantener los documentos sincronizados", "derivación de documentos" o solicita configurar la estructura de documentación para una base de código.
