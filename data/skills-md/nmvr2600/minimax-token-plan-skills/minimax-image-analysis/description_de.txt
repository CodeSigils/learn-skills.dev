Wenn der Benutzer den Bildinhalt verstehen, ein Bild beschreiben, Text aus einem Bild extrahieren (OCR), einen Screenshot erkennen oder visuelle Elemente analysieren muss, wird dies ausgelöst, indem er „Bild analysieren“, „Bild verstehen“, „Text aus Bild extrahieren“, „Bildinhalt erkennen“, „dieses Bild beschreiben“ oder „Was ist im Bild“ sagt.
