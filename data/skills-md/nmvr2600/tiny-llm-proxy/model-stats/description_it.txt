Statistiche delle chiamate del modello di query sul gateway tiny-llm-proxy (conteggio chiamate, consumo di token, aggregati per modello/ora/protocollo, ecc.). Si attiva quando gli utenti dicono "controlla l'utilizzo del modello", "riepiloga i dati del gateway", "visualizza i volumi delle chiamate del modello" o "classifica delle chiamate del modello" quando devono visualizzare le statistiche delle chiamate del modello del gateway, le classifiche di utilizzo o le tendenze di consumo.
