Méthodologie de test de sécurité du protocole MCP (Model Context Protocol). Il est déclenché lorsque l'environnement cible utilise le serveur MCP pour intégrer des outils externes, doit évaluer la sécurité des descriptions d'outils MCP ou teste les limites de sécurité lorsqu'un agent appelle des outils via MCP. Couverture : empoisonnement de description d'outil, arnaque en tapis (falsification dynamique), écrasement de commandes (Shadow Tool), commandes cachées (ANSI/Unicode), attaques inter-serveurs, vol de jetons, manipulation de schéma, débordement de contexte.
