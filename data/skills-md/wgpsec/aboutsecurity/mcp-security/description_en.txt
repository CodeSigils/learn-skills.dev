MCP (Model Context Protocol) protocol security testing methodology. It is triggered when the target environment uses MCP Server to integrate external tools, needs to assess the security of MCP tool descriptions, or tests the security boundaries when an Agent invokes tools via MCP. Coverage: tool description poisoning, carpet‑scam (dynamic tampering), command overwriting (Shadow Tool), hidden commands (ANSI/Unicode), cross‑Server attacks, token theft, schema manipulation, context overflow.
