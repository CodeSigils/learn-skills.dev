MCP (Model Context Protocol) protocol security testing methodology. It is triggered when the target environment uses the MCP Server to integrate external tools, needs to assess the security of MCP tool descriptions, or tests the security boundaries of an Agent invoking tools via MCP. Coverage includes: tool description poisoning, carpet‑style scams (dynamic tampering), command overriding (Shadow Tool), hidden commands (ANSI/Unicode), cross‑Server attacks, token theft, schema manipulation, and context overflow.
