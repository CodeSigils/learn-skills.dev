Методика тестирования безопасности протокола MCP (Model Context Protocol). Он срабатывает, когда целевая среда использует сервер MCP для интеграции внешних инструментов, необходимо оценить безопасность описаний инструментов MCP или проверить границы безопасности, когда агент вызывает инструменты через MCP. Охват: отравление описания инструмента, ковровое мошенничество (динамическое вмешательство), перезапись команд (Shadow Tool), скрытые команды (ANSI/Unicode), межсерверные атаки, кража токенов, манипулирование схемой, переполнение контекста.
