Методика тестирования безопасности протокола MCP (Model Context Protocol). Он срабатывает, когда целевая среда использует сервер MCP для интеграции внешних инструментов, необходимо оценить безопасность описаний инструментов MCP или проверить границы безопасности агента, вызывающего инструменты через MCP. Охват включает в себя: отравление описаний инструментов, ковровое мошенничество (динамическое вмешательство), переопределение команд (Shadow Tool), скрытые команды (ANSI/Unicode), межсерверные атаки, кражу токенов, манипулирование схемой и переполнение контекста.
