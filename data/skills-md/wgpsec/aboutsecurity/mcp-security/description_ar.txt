منهجية اختبار أمان بروتوكول MCP (بروتوكول السياق النموذجي). يتم تشغيله عندما تستخدم البيئة المستهدفة خادم MCP لدمج الأدوات الخارجية، أو تحتاج إلى تقييم أمان أوصاف أداة MCP، أو اختبار حدود الأمان عندما يستدعي الوكيل الأدوات عبر MCP. التغطية: تسمم وصف الأداة، احتيال السجاد (التلاعب الديناميكي)، الكتابة فوق الأوامر (أداة الظل)، الأوامر المخفية (ANSI/Unicode)، الهجمات عبر الخادم، سرقة الرمز المميز، معالجة المخطط، تجاوز السياق.
