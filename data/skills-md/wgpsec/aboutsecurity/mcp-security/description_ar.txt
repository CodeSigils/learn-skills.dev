منهجية اختبار أمان بروتوكول MCP (بروتوكول السياق النموذجي). يتم تشغيله عندما تستخدم البيئة المستهدفة خادم MCP لدمج الأدوات الخارجية، أو تحتاج إلى تقييم أمان أوصاف أداة MCP، أو اختبار حدود الأمان عندما يستدعي الوكيل الأدوات عبر MCP. تشمل التغطية: تسميم وصف الأداة، والاحتيال (التلاعب الديناميكي)، وتجاوز الأوامر (أداة الظل)، والأوامر المخفية (ANSI/Unicode)، والهجمات عبر الخادم، وسرقة الرمز المميز، ومعالجة المخطط، وتجاوز السياق.
