Metodologia di test di sicurezza del protocollo MCP (Model Context Protocol). Viene attivato quando l'ambiente di destinazione utilizza il server MCP per integrare strumenti esterni, deve valutare la sicurezza delle descrizioni degli strumenti MCP o testare i limiti di sicurezza quando un agente richiama strumenti tramite MCP. Copertura: avvelenamento da descrizione dello strumento, carpet‑scam (manomissione dinamica), sovrascrittura dei comandi (Shadow Tool), comandi nascosti (ANSI/Unicode), attacchi tra server, furto di token, manipolazione dello schema, overflow del contesto.
