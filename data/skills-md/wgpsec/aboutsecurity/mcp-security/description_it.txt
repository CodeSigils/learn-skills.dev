Metodologia di test di sicurezza del protocollo MCP (Model Context Protocol). Viene attivato quando l'ambiente di destinazione utilizza un server MCP per integrare strumenti esterni, deve valutare la sicurezza delle descrizioni degli strumenti MCP o testare i limiti di sicurezza quando un agente richiama strumenti tramite MCP. La copertura include: avvelenamento da descrizione dello strumento, truffe a tappeto (manomissione dinamica), override dei comandi (Shadow Tool), comandi nascosti (ANSI/Unicode), attacchi tra server, furto di token, manipolazione dello schema e overflow del contesto.
