Metodología de prueba de seguridad del protocolo MCP (Model Context Protocol). Se activa cuando el entorno de destino utiliza el servidor MCP para integrar herramientas externas, necesita evaluar la seguridad de las descripciones de las herramientas MCP o prueba los límites de seguridad cuando un agente invoca herramientas a través de MCP. Cobertura: envenenamiento de descripción de herramientas, estafa de alfombra (manipulación dinámica), sobrescritura de comandos (Herramienta Sombra), comandos ocultos (ANSI/Unicode), ataques entre servidores, robo de tokens, manipulación de esquemas, desbordamiento de contexto.
