Metodología de prueba de seguridad del protocolo MCP (Model Context Protocol). Se activa cuando el entorno de destino utiliza un servidor MCP para integrar herramientas externas, necesita evaluar la seguridad de las descripciones de las herramientas MCP o prueba los límites de seguridad de un agente que invoca herramientas a través de MCP. La cobertura incluye: envenenamiento de descripción de herramientas, estafa de alfombra (manipulación dinámica), anulación de comandos (Herramienta Sombra), comandos ocultos (ANSI/Unicode), ataques entre servidores, robo de tokens, manipulación de esquemas y desbordamiento de contexto.
