Sicherheitstestmethode für das MCP-Protokoll (Model Context Protocol). Es wird ausgelöst, wenn die Zielumgebung den MCP-Server zur Integration externer Tools verwendet, die Sicherheit von MCP-Toolbeschreibungen bewerten muss oder die Sicherheitsgrenzen testet, wenn ein Agent Tools über MCP aufruft. Abdeckung: Tool-Description-Poisoning, Carpet-Scam (dynamische Manipulation), Befehlsüberschreibung (Shadow Tool), versteckte Befehle (ANSI/Unicode), serverübergreifende Angriffe, Token-Diebstahl, Schemamanipulation, Kontextüberlauf.
