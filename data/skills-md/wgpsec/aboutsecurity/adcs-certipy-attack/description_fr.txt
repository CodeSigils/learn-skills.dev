Attaques de certificats des services de certificats Active Directory (ADCS). À utiliser lorsqu'un serveur CA, une inscription Web ADCS ou un modèle de certificat mal configuré est trouvé dans le domaine. Couvre tous les chemins d'abus de certificat ESC1‑ESC11, la chaîne d'outils Certipy, la falsification de certificat et le relais NTLM vers ADCS. Lorsqu’un contenu lié à ADCS/CA/certificate/certsrv est découvert, cette technique doit être utilisée.
