Ataques a certificados de Servicios de certificados de Active Directory (ADCS). Utilícelo cuando se encuentre en el dominio un servidor CA, inscripción web ADCS o una plantilla de certificado mal configurada. Cubre todas las rutas de abuso de certificados ESC1‑ESC11, la cadena de herramientas Certipy, la falsificación de certificados y la retransmisión NTLM a ADCS. Cuando se descubre contenido relacionado con ADCS/CA/certificate/certsrv, se debe emplear esta técnica.
