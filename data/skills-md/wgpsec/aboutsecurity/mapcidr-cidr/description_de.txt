Verwenden Sie Mapcidr für die CIDR-Netzwerksegmentverarbeitung. Verwenden Sie es, wenn Sie ein CIDR in eine IP-Liste erweitern, IPs in CIDR aggregieren, Netzwerksegmente aufteilen, IPs zählen oder die IP-Reihenfolge zufällig festlegen müssen. mapcidr ist ein CIDR-Verarbeitungstool von ProjectDiscovery, das IPv4/IPv6 unterstützt. Jedes Szenario, das CIDR-Berechnungen, die Verarbeitung von IP-Listen oder die Aufteilung von Netzwerksegmenten umfasst, sollte diese Funktion nutzen.
