AD domain environment persistence techniques. Used when domain admin or local admin privileges have been obtained and persistent access needs to be established to ensure you can return to the target environment after a reboot or password change. Covers host‑level persistence (scheduled tasks, registry Run keys, COM hijacking, WMI event subscriptions, Windows services, startup folder), domain‑level persistence (Golden Ticket, Silver Ticket, Skeleton Key, DSRM, AdminSDHolder), advanced techniques such as DCShadow and Golden GMSA, as well as cleanup commands and detection evasion.
