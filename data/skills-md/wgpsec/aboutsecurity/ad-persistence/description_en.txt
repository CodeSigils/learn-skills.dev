AD domain environment persistence techniques. Used when domain admin or local administrator privileges have been obtained and persistent access needs to be established to ensure that after a reboot or password change you can still return to the target environment. Covers host‑level persistence (scheduled tasks, registry Run, COM hijacking, WMI event subscriptions, Windows services, startup folder), domain‑level persistence (Golden Ticket, Silver Ticket, Skeleton Key, DSRM, AdminSDHolder), advanced techniques such as DCShadow/GoldenGMSA, cleanup commands and detection evasion.
