以下是英文翻译:

Metodologia di test sulla sicurezza dei dati del sistema AI. Si attiva quando si valuta il rischio di perdita di dati, la sicurezza dei dati di training o l'integrità dei dati del database RAG/vettoriale per i sistemi LLM/AI. Copre: perdita di prompt di sistema (meta prompt/giochi di ruolo/targeting per parole chiave), inferenza ed estrazione di dati di addestramento, attacchi di inferenza di appartenenza, attacchi di inversione di modello, avvelenamento di dati RAG, perdita di informazioni API, attacchi di allucinazioni a cascata, perdita di informazioni da fonti di dati esterne.
