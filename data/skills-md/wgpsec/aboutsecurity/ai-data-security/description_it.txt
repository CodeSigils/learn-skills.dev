Metodologia di test sulla sicurezza dei dati del sistema AI. Si attiva quando è necessario valutare il rischio di perdita di dati, la sicurezza dei dati di training o l'integrità dei dati di archivio RAG/vettoriale dei sistemi LLM/AI. Copre: fuga di prompt di sistema (meta prompt/giochi di ruolo/targeting per parole chiave), inferenza ed estrazione di dati di addestramento, attacchi di inferenza di appartenenza, attacchi di inversione di modello, avvelenamento di dati RAG, fuga di informazioni API, attacchi di allucinazioni a cascata, fuga di informazioni da fonti di dati esterne.
