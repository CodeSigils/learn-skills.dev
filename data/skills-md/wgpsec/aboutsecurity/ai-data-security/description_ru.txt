以下是英文翻译:

Методика тестирования безопасности данных системы искусственного интеллекта. Срабатывает при оценке риска утечки данных, безопасности обучающих данных или целостности данных RAG/векторной базы данных для систем LLM/AI. Охватывает: утечку системных подсказок (мета-подсказки/ролевые игры/таргетинг на ключевые слова), вывод и извлечение обучающих данных, атаки на основе вывода о членстве, атаки на инверсию модели, отравление данных RAG, утечку информации API, каскадные атаки галлюцинаций, утечку информации из внешних источников данных.
