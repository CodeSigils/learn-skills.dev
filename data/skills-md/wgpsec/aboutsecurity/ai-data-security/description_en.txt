AI system data security testing methodology. Triggered when evaluating the data leakage risk, training data security, or RAG/vector store data integrity of LLM/AI systems. Covers: system prompt leakage (meta‑prompt/role‑playing/keyword targeting), training data inference and extraction, membership inference attacks, model inversion attacks, RAG data poisoning, API information leakage, cascading hallucination attacks, and external data source information leakage.
