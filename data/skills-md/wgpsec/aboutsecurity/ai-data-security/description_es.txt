以下是英文翻译:

Metodología de prueba de seguridad de datos del sistema de IA. Se activa al evaluar el riesgo de fuga de datos, la seguridad de los datos de capacitación o la integridad de los datos de la base de datos RAG/vectorial para sistemas LLM/AI. Cubre: fuga de avisos del sistema (meta aviso/juego de roles/orientación por palabras clave), inferencia y extracción de datos de entrenamiento, ataques de inferencia de membresía, ataques de inversión de modelos, envenenamiento de datos RAG, fuga de información de API, ataques de alucinaciones en cascada, fuga de información de fuentes de datos externas.
