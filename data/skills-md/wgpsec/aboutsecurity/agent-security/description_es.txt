Metodología de prueba de seguridad del sistema AI Agent. Se activa cuando el sistema de destino utiliza agentes de IA para realizar llamadas de herramientas, colaboración entre múltiples agentes o toma de decisiones autónoma. Cubre el OWASP Agentic AI Security Top10 (ASI01-ASI10): secuestro de objetivos, uso indebido de herramientas, identidad y permisos, cadena de suministro, ejecución de código, envenenamiento de la memoria, comunicación entre múltiples agentes, fallas en cascada, explotación de la confianza entre humanos y máquinas, agente fuera de control.
