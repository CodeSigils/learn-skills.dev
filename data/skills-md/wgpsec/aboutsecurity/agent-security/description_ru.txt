Методика тестирования безопасности системы агента ИИ. Запускается, когда целевая система использует агенты ИИ для вызова инструментов, совместной работы нескольких агентов или автономного принятия решений. Охватывает список OWASP Agentic AI Security Top10 (ASI01‑ASI10): захват цели, неправильное использование инструментов, идентификацию и разрешения, цепочку поставок, выполнение кода, отравление памяти, межагентную связь, каскадные сбои, эксплуатацию доверия человек-машина, вышедшие из-под контроля агенты.
