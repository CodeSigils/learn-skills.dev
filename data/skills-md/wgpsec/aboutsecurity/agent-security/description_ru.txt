Методика тестирования безопасности системы агента ИИ. Запускается, когда целевая система использует агенты ИИ для выполнения вызовов инструментов, совместной работы нескольких агентов или автономного принятия решений. Охватывает топ-10 OWASP Agentic AI Security Top10 (ASI01‑ASI10): перехват цели, злоупотребление инструментами, идентификационные данные и разрешения, цепочку поставок, выполнение кода, отравление памяти, многоагентную связь, каскадные сбои, эксплуатацию доверия человек-машина, выход из-под контроля агента.
