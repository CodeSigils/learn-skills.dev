AI Agent System Security Testing Methodology. Triggered when the target system uses AI Agents to execute tool calls, multi‑agent collaboration, or autonomous decision‑making. Covers the OWASP Agentic AI Security Top 10 (ASI01‑ASI10): Target hijacking, Tool abuse, Identity and permissions, Supply chain, Code execution, Memory poisoning, Multi‑agent communication, Cascading failures, Human‑machine trust exploitation, Out‑of‑control Agent.
