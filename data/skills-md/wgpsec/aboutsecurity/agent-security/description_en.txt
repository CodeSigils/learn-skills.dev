AI Agent System Security Testing Methodology. Triggered when the target system uses AI Agents to perform tool invocation, multi‑agent collaboration, or autonomous decision‑making. Covers the OWASP Agentic AI Security Top 10 (ASI01‑ASI10): target hijacking, tool misuse, identity and permissions, supply chain, code execution, memory poisoning, multi‑agent communication, cascading failures, human‑machine trust exploitation, out‑of‑control agents.
