منهجية اختبار أمان نظام وكيل الذكاء الاصطناعي. يتم تشغيله عندما يستخدم النظام المستهدف وكلاء الذكاء الاصطناعي لإجراء استدعاءات الأدوات، أو التعاون متعدد الوكلاء، أو اتخاذ القرار المستقل. يغطي OWASP Agentic AI Security Top10 (ASI01‑ASI10): اختطاف الأهداف، وإساءة استخدام الأدوات، والهوية والأذونات، وسلسلة التوريد، وتنفيذ التعليمات البرمجية، وتسميم الذاكرة، والاتصال متعدد الوكلاء، والفشل المتتالي، واستغلال الثقة في الآلة البشرية، والوكيل الخارج عن السيطرة.
