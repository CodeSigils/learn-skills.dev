Use Adinfo for Active Directory information gathering. When you have obtained domain user credentials and need to quickly collect domain environment information, use this tool. Adinfo is a fast AD information collection utility that outputs key data—domain controller list, domain admin users, trust relationships, GPOs, SPNs, delegation configurations, and more—with a single command, much faster than manual LDAP queries. After discovering the domain environment, this skill is used for the initial information‑gathering step.
