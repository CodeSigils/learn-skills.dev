Use Adinfo for Active Directory information gathering. It is employed when you need to quickly collect domain environment data after obtaining domain user credentials. Adinfo is a fast AD information‑gathering tool that outputs key details—such as the list of domain controllers, domain admin users, trust relationships, GPOs, SPNs, delegation configurations, and more—with a single command, which is far quicker than manual LDAP queries. This capability is used for the initial information‑gathering step after discovering a domain environment.
