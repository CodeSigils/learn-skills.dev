Utilice Adinfo para recopilar información de Active Directory. Se utiliza cuando necesita recopilar rápidamente información del entorno del dominio después de obtener las credenciales de usuario del dominio. Adinfo es una herramienta rápida de recopilación de información de AD que genera información clave, como la lista de controladores de dominio, usuarios administradores de dominio, relaciones de confianza, GPO, SPN, configuraciones de delegación, etc., con un solo comando, mucho más rápido que las consultas LDAP manuales. Esta habilidad se utiliza para el primer paso de recopilación de información después de descubrir el entorno del dominio.
