Utilice Adinfo para recopilar información de Active Directory. Se emplea cuando necesita recopilar rápidamente datos del entorno del dominio después de obtener las credenciales de usuario del dominio. Adinfo es una herramienta rápida de recopilación de información de AD que genera detalles clave, como la lista de controladores de dominio, usuarios administradores de dominio, relaciones de confianza, GPO, SPN, configuraciones de delegación y más, con un solo comando, que es mucho más rápido que las consultas LDAP manuales. Esta capacidad se utiliza para el paso inicial de recopilación de información después de descubrir un entorno de dominio.
