Utilisez Adinfo pour la collecte d'informations Active Directory. Il est utilisé lorsque vous devez collecter rapidement des données sur l'environnement du domaine après avoir obtenu les informations d'identification de l'utilisateur du domaine. Adinfo est un outil rapide de collecte d'informations AD qui génère des détails clés, tels que la liste des contrôleurs de domaine, les utilisateurs administrateurs de domaine, les relations de confiance, les GPO, les SPN, les configurations de délégation, etc., avec une seule commande, ce qui est beaucoup plus rapide que les requêtes LDAP manuelles. Cette fonctionnalité est utilisée pour l’étape initiale de collecte d’informations après la découverte d’un environnement de domaine.
