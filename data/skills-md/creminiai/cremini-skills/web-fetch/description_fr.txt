Récupérez le contenu de la page Web via le protocole Chrome DevTools (CDP). Rendu JS complet, gère les redirections (y compris Google News). À utiliser lorsque vous devez lire le contenu textuel d'une page Web, extraire des articles ou extraire des informations à partir d'URL. Zéro dépendance – Python 3 stdlib uniquement. Multiplateforme (Mac, Windows, Linux).
