جلب محتوى صفحة الويب عبر بروتوكول Chrome DevTools (CDP). عرض JS كامل، ويتعامل مع عمليات إعادة التوجيه (بما في ذلك أخبار Google). استخدمه عندما تحتاج إلى قراءة المحتوى النصي لصفحة ويب، أو استخراج المقالات، أو استخراج المعلومات من عناوين URL. التبعيات الصفرية - Python 3 stdlib فقط. عبر الأنظمة الأساسية (ماك، ويندوز، لينكس).
