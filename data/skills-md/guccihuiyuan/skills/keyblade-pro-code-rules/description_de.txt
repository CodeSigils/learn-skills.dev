Wenn ein Benutzer anfordert, Vue3+TypeScript+Arco Design-Teilprojektcode zu generieren, zu ändern oder zu überprüfen, wird dieser Auslöser angewendet. Es überschreibt die Verwendungsspezifikationen für kb-pro-table / useTable / useForm und die Arco Design+UnoCSS-Stilregeln. Es behandelt Modulorganisations- und Namenskonventionen, Aufzählungs- und Typeinschränkungen, ref-first-reaktive Spezifikationen usw. Unabhängig davon, ob der Benutzer explizit „Spezifikationen“ oder „Regeln“ erwähnt, sollte beim Schreiben von Code im Rahmen des Vue3+TypeScript+Arco Design-Unterprojekts diese Fähigkeit verwendet werden.
