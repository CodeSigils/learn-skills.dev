Limite les normes d'écriture pour les cas de tests automatisés basés sur Midscene.js, en particulier la gestion de la compatibilité pour l'environnement du programme Android WeChat Mini.  
Lorsque les utilisateurs doivent écrire, modifier ou réviser des scripts de test ou des scénarios de test Midscene.js, ils doivent utiliser cette compétence.  
S'applique au test de génération et de révision de code pour trois plates-formes : PC (ordinateur de bureau Web), Web (Puppeteer) et Android (application/mini-programme).  
Si l'utilisateur mentionne « écrire un test », « tests automatisés », « midscene », « cas de test », « aiTap », « aiAssert », etc., déclenchez immédiatement cette compétence.
