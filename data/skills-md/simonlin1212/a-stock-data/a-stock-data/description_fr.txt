Boîte à outils de données complète A-Share — couvrant six couches de sources de données : données de marché (mootdx+Tencent), rapports de recherche (EastMoney+iWenCai), signaux (sujets d'actualité de Tonghuashun+flux vers le nord+BaiduPAE+liste Dragon-Tiger+déblocages d'actions+industrie), actualités (akshare), données fondamentales (mootdx Financial/F10) et annonces (Juchao). Il intègre tout le code d'appel, est autonome sans dépendance de fichier externe et convient à des scénarios tels que l'évaluation d'actions individuelles, la récupération de rapports de recherche, l'attribution de thèmes, le suivi de liste Dragon-Tiger, les avertissements de déverrouillage, la rotation industrielle, la recherche sur la chaîne industrielle, le filtrage par lots, etc.
