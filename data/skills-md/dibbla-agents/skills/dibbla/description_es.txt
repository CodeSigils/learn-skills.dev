Utilice la CLI de Dibbla para desarrollar proyectos, ejecutar canalizaciones dibbla-task.yaml localmente (ejecución de dibbla), instalar plantillas de proyecto (lista/instalación de plantillas de dibbla), instalar esta habilidad en un proyecto para que otros agentes de codificación de IA también la lean (las habilidades de dibbla instalan dibbla), implementar aplicaciones, administrar aplicaciones/bases de datos/secretos y diseñar/iterar flujos de trabajo en la plataforma Dibbla. Úselo cuando el usuario desee ejecutar un archivo de tarea local o una plantilla desde una URL, instalar una plantilla inicial, instalar la habilidad dibbla en un proyecto o directorio de inicio para Claude Code/Cursor/Gemini CLI/Opencode/Codex, iniciar sesión (incluso desde contextos que no sean TTY a través de `dibbla login --browser`), implementar, administrar aplicaciones/bases de datos/secretos, o diseñar y operar flujos de trabajo: cree un flujo de trabajo YAML delgado que conecte un agente LLM a las herramientas. validarlo con `dibbla wf validar`, implementarlo con `wf create`/`wf update`, iterarlo mediante `nodes add`/`edges add`/`inputs set`/`tools add`, tomar una instantánea con `revisions create`, revertir con `revisions restablecimiento` y ejecutar mediante `wf ejecutar` o el punto final HTTP expuesto por `wf api-docs`.
