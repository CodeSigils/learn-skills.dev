Verwenden Sie die Dibbla-CLI, um ein Gerüst für Projekte zu erstellen, dibbla-task.yaml-Pipelines lokal auszuführen (dibbla run), Projektvorlagen zu installieren (dibbla template list/install), diesen Skill in einem Projekt zu installieren, damit andere KI-Codierungsagenten ihn auch lesen (dibbla skills install dibbla), Apps bereitzustellen, Apps/Datenbanken/Geheimnisse zu verwalten und Workflows auf der Dibbla-Plattform zu entwerfen/iterieren. Verwenden Sie diese Option, wenn der Benutzer eine lokale Aufgabendatei oder Vorlage von einer URL ausführen, eine Startervorlage installieren, den Dibbla-Skill in einem Projekt oder Home-Verzeichnis für Claude Code/Cursor/Gemini CLI/Opencode/Codex installieren, sich anmelden (auch aus Nicht-TTY-Kontexten über „dibbla login --browser“), Apps/Datenbanken/Geheimnisse bereitstellen, verwalten oder Workflows entwerfen und betreiben möchte – erstellen Sie einen schlanken YAML-Workflow, der einen LLM-Agenten mit Tools verbindet, Validieren Sie es mit „dibbla wf validieren“, stellen Sie es mit „wf create“/„wf update“ bereit, iterieren Sie es über „nodes add“/„edges add“/„inputs set“/„tools add“, erstellen Sie einen Snapshot mit „revisions create“, führen Sie ein Rollback mit „revisions restart“ durch und führen Sie es über „wfexecute“ oder den von „wf api-docs“ bereitgestellten HTTP-Endpunkt aus.
