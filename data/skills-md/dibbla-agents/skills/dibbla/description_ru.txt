Используйте интерфейс командной строки Dibbla для формирования проектов, локального запуска конвейеров dibbla-task.yaml (запуск dibbla), установки шаблонов проектов (список шаблонов dibbla/установка), установки этого навыка в проект, чтобы другие агенты кодирования ИИ тоже его читали (навыки dibbla устанавливают dibbla), развертывания приложений, управления приложениями/базами данных/секретами, а также проектирования/повторения рабочих процессов на платформе Dibbla. Используйте, когда пользователь хочет запустить локальный файл задачи или шаблон по URL-адресу, установить стартовый шаблон, установить навык dibbla в проект или домашний каталог для Claude Code/Cursor/Gemini CLI/Opencode/Codex, войти в систему (в том числе из контекстов без TTY через `dibbla login --browser`), развернуть, управлять приложениями/базами данных/секретами или разработать и использовать рабочие процессы — создайте тонкий рабочий процесс YAML, который связывает Агент LLM в инструменты, проверить его с помощью `dibbla wf validate`, развернуть его с помощью `wf create`/`wf update`, выполнить итерацию через `nodes add`/`edges add`/`inputs set`/`tools add`, сделать снимок с `revisions create`, откатить его с `revisions restoration` и выполнить через `wf Execute` или конечную точку HTTP, предоставляемую `wf api-docs`.
