Utilisez la CLI Dibbla pour échafauder des projets, exécuter des pipelines dibbla-task.yaml localement (exécution de dibbla), installer des modèles de projet (liste/installation de modèles dibbla), installer cette compétence dans un projet afin que d'autres agents de codage d'IA la lisent également (les compétences dibbla installent dibbla), déployez des applications, gérez des applications/bases de données/secrets et concevez/itérez des flux de travail sur la plateforme Dibbla. À utiliser lorsque l'utilisateur souhaite exécuter un fichier de tâches local ou un modèle à partir d'une URL, installer un modèle de démarrage, installer la compétence dibbla dans un projet ou un répertoire personnel pour Claude Code/Cursor/Gemini CLI/Opencode/Codex, se connecter (y compris à partir de contextes non TTY via `dibbla login --browser`), déployer, gérer des applications/bases de données/secrets, ou concevoir et exploiter des workflows — créez un workflow YAML mince qui connecte un agent LLM aux outils, validez-le avec `dibbla wf validate`, déployez-le avec `wf create`/`wf update`, itérez-le via `nodes add`/`edges add`/`inputs set`/`tools add`, instantané avec `revisions create`, restaurez-le avec `revisions restaurer` et exécutez via `wf exécuté` ou le point de terminaison HTTP exposé par `wf api-docs`.
