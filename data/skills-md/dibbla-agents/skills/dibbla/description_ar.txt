استخدم Dibbla CLI لدعم المشاريع، وتشغيل خطوط أنابيب dibbla-task.yaml محليًا (تشغيل dibbla)، وتثبيت قوالب المشروع (قائمة/تثبيت قوالب dibbla)، وتثبيت هذه المهارة في مشروع حتى يقرأها وكلاء ترميز الذكاء الاصطناعي الآخرون أيضًا (مهارات dibbla تثبيت dibbla)، ونشر التطبيقات، وإدارة التطبيقات/قواعد البيانات/الأسرار، وتصميم/تكرار سير العمل على منصة Dibbla. يُستخدم عندما يريد المستخدم تشغيل ملف مهمة محلي أو قالب من عنوان URL، أو تثبيت قالب بداية، أو تثبيت مهارة dibbla في مشروع أو دليل منزلي لـ Claude Code/Cursor/Gemini CLI/Opencode/Codex، أو تسجيل الدخول (بما في ذلك من سياقات غير TTY عبر `dibbla تسجيل الدخول --browser`)، أو نشر التطبيقات/قواعد البيانات/الأسرار أو تصميمها وتشغيلها - قم بتأليف سير عمل YAML رفيع المستوى وكيل LLM للأدوات، والتحقق من صحته باستخدام `dibbla wf validate`، ونشره باستخدام `wf create`/`wf update`، وتكراره عبر ``nodes add`/`edges add`/`inputs set`/`tools add`، واللقطة باستخدام `revisions create`، والتراجع باستخدام `revisionsstore`، والتنفيذ عبر ``wf تنفيذ`` أو نقطة نهاية HTTP المكشوفة بواسطة `wf API-مستندات".
