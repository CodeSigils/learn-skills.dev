Use the infra-go Go infrastructure library to build services in business projects. It covers conf (configuration loading), logger (structured logging), orm (MySQL/PostgreSQL/SQLite), redisx (Redis and distributed locks), cache (unified cache: memory/Redis), httpx (HTTP service, parameter binding, unified Response[T] response, middleware: circuit breaking/timeout/rate limiting/encryption/load shedding), jwt (authentication middleware), ratelimit (memory/Redis rate limiting), breaker (circuit breaker), retry (retry), taskq (asynchronous task queue), storage (OSS/COS/KODO object storage), websocket (real‑time communication), trace (trace linking), hash (password/digest/encryption/HMAC signing), cast (type conversion), stringx (string), syncx (concurrency primitives), service (ServiceGroup service orchestration). Use when: when writing business services in Go you need to select/initialize/assemble infra-go modules, need to combine conf + logger + orm + redisx + httpx + jwt, or need unified responses, middleware, graceful shutdown, and other infrastructure.
