Calcule manuellement l'exécution d'un système avec un état explicite à chaque étape. À utiliser lors du débogage de courses, de machines à états, de bogues asynchrones, de régressions ; tester un correctif sous contrainte ; fonctionnalités de cadrage sur l’état existant ; ou approcher un code inconnu. Particulièrement utile pour les bogues impliquant le séquençage client/serveur, les actualisations en arrière-plan, les chemins de récupération, les files d'attente ou plusieurs acteurs évoluant ensemble. Se déclenche également sur "pourquoi est-ce cassé", "parcourir le flux", "cela fonctionnait auparavant", "que se passe-t-il quand" ou "tester ce plan sous contrainte".
