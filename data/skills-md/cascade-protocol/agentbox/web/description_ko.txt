유료 API를 통한 웹 스크래핑 및 검색: 계단식 에스컬레이션(빠른 HTTP -> 브라우저 -> 스텔스+프록시)으로 모든 URL을 크롤링하고, 여러 URL을 대량 크롤링하고, Exa를 통해 웹을 검색합니다. 자동 USDC 소액 결제를 위해 x_pay 도구를 사용합니다(크롤링당 $0.005, 검색당 $0.01). 내장된 web_fetch가 실패하거나 차단된 경우 에스컬레이션으로 사용합니다. 다음 경우에 사용하세요: (1) web_fetch가 비어 있거나 차단된 콘텐츠를 반환한 경우, (2) JS 렌더링 또는 안티 봇으로 보호된 페이지를 스크랩한 경우, (3) 여러 URL을 대량 크롤링하는 경우, (4) Exa를 통해 쿼리로 웹을 검색하는 경우입니다.
