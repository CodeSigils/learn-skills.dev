Scraping Web et recherche via une API payante : explorez n'importe quelle URL avec une escalade en cascade (HTTP rapide -> navigateur -> furtif + proxy), analysez en masse plusieurs URL et effectuez une recherche sur le Web via Exa. Utilise l'outil x_payment pour les micropaiements automatiques USDC (0,005 $/exploration, 0,01 $/recherche). À utiliser comme escalade lorsque le web_fetch intégré échoue ou est bloqué. À utiliser lorsque : (1) web_fetch a renvoyé du contenu vide/bloqué, (2) grattage de pages rendues par JS ou protégées contre les robots, (3) analyse groupée de plusieurs URL, (4) recherche sur le Web par requête via Exa.
