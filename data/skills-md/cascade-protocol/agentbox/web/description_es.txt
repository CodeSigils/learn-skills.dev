Raspado web y búsqueda a través de API paga: rastree cualquier URL con escalada en cascada (HTTP rápido -> navegador -> sigilo+proxy), rastree de forma masiva varias URL y busque en la web a través de Exa. Utiliza la herramienta x_paid para micropagos automáticos en USDC ($0,005/rastreo, $0,01/búsqueda). Utilícelo como escalamiento cuando el web_fetch integrado falle o esté bloqueado. Úselo cuando: (1) web_fetch devolvió contenido vacío/bloqueado, (2) extrajo páginas renderizadas por JS o protegidas contra robots, (3) rastreo masivo de múltiples URL, (4) búsqueda en la web mediante consulta a través de Exa.
