Web scraping e ricerca tramite API a pagamento: scansione di qualsiasi URL con escalation a cascata (HTTP veloce -> browser -> stealth+proxy), scansione in blocco di più URL ed ricerca sul Web tramite Exa. Utilizza lo strumento x_payment per micropagamenti automatici USDC ($ 0,005/crawl, $ 0,01/ricerca). Utilizzare come escalation quando web_fetch integrato non funziona o è bloccato. Da utilizzare quando: (1) web_fetch ha restituito contenuti vuoti/bloccati, (2) scraping di pagine con rendering JS o protette da anti-bot, (3) scansione in blocco di più URL, (4) ricerca nel Web tramite query tramite Exa.
