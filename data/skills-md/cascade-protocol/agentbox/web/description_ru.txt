Веб-скрапинг и поиск через платный API: сканируйте любой URL-адрес с каскадной эскалацией (быстрый HTTP -> браузер -> стелс+прокси), массовое сканирование нескольких URL-адресов и поиск в Интернете через Exa. Использует инструмент x_paying для автоматических микроплатежей в долларах США (0,005 доллара США за сканирование, 0,01 доллара США за поиск). Используйте в качестве эскалации, когда встроенная функция web_fetch завершается сбоем или блокируется. Используйте, когда: (1) web_fetch возвращает пустой/заблокированный контент, (2) очищает страницы, обработанные JS или защищенные от ботов, (3) массовое сканирование нескольких URL-адресов, (4) поиск в Интернете по запросу через Exa.
