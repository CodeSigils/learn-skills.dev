有料 API を介した Web スクレイピングと検索: カスケード エスカレーション (高速 HTTP -> ブラウザ -> ステルス + プロキシ) で任意の URL をクロールし、複数の URL を一括クロールし、Exa を介して Web を検索します。自動 USDC マイクロペイメントには x_payment ツールを使用します (クロールあたり 0.005 ドル、検索あたり 0.01 ドル)。組み込みの web_fetch が失敗するかブロックされた場合のエスカレーションとして使用します。次の場合に使用します: (1) web_fetch が空の/ブロックされたコンテンツを返した場合、(2) JS レンダリングされたページまたはボット対策で保護されたページをスクレイピングする場合、(3) 複数の URL を一括クロールする場合、(4) Exa 経由でクエリによって Web を検索する場合。
