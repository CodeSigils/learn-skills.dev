Web-Scraping und Suche über kostenpflichtige API: Crawlen Sie jede URL mit Kaskadeneskalation (schnelles HTTP -> Browser -> Stealth+Proxy), crawlen Sie mehrere URLs in großen Mengen und durchsuchen Sie das Web über Exa. Verwendet das x_paid-Tool für automatische USDC-Mikrozahlungen (0,005 $/Crawl, 0,01 $/Suche). Als Eskalation verwenden, wenn der integrierte web_fetch fehlschlägt oder blockiert ist. Wird verwendet, wenn: (1) web_fetch leeren/blockierten Inhalt zurückgegeben hat, (2) JS-gerenderte oder Anti-Bot-geschützte Seiten gescrapt hat, (3) mehrere URLs massenhaft gecrawlt hat, (4) das Web per Abfrage über Exa durchsucht hat.
