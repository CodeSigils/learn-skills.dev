使用 Surf 按使用付費 API 進行建置 - Twitter 資料、Reddit 資料、LLM 推理和 surf.cascade.fyi 上的網頁抓取。每當使用 Surf 端點、Twitter/X 資料提取、Reddit 資料、網路爬行/搜尋或按請求付費的 LLM 推理時，請使用此技能。也可以在為 Surf 服務設定 @x402/fetch、將 x402-proxy 與 Surf URL 結合使用，或提及 twitter.surf、reddit.surf、inference.surf 或 web.surf 網域時使用。即使用戶只是說「取得推文」、「搜尋 reddit」或「抓取頁面」並且 Surf 位於專案上下文中，也可以使用此技能。
