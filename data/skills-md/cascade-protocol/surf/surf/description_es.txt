Cree con API de pago por uso de Surf: datos de Twitter, datos de Reddit, inferencia de LLM y web scraping en surf.cascade.fyi. Utilice esta habilidad siempre que trabaje con puntos finales de Surf, extracción de datos de Twitter/X, datos de Reddit, rastreo/búsqueda web o inferencia de LLM de pago por solicitud. Úselo también al configurar @x402/fetch para servicios de Surf, al usar x402-proxy con URL de Surf o cualquier mención de los dominios twitter.surf, reddit.surf, inference.surf o web.surf. Incluso si el usuario simplemente dice "obtener tweets", "buscar en reddit" o "rastrear una página" y navegar está en el contexto del proyecto, utilice esta habilidad.
