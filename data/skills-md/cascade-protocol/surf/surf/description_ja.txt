Surf の従量制 API (Twitter データ、Reddit データ、LLM 推論、surf.cascade.fyi の Web スクレイピング) を使用して構築します。 Surf エンドポイント、Twitter/X データ抽出、Reddit データ、Web クローリング/検索、またはペイパーリクエスト LLM 推論を操作する場合は常に、このスキルを使用します。 Surf サービス用に @x402/fetch を設定する場合、Surf URL で x402-proxy を使用する場合、または twitter.surf、reddit.surf、inference.surf、または web.surf ドメインに言及する場合にも使用します。ユーザーが「ツイートを取得する」、「reddit を検索する」、または「ページをクロールする」だけで、Surf がプロジェクト コンテキスト内にある場合でも、このスキルを使用してください。
