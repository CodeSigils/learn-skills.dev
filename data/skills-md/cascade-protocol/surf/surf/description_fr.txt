Créez avec les API Surf payantes à l'utilisation - données Twitter, données Reddit, inférence LLM et web scraping sur surf.cascade.fyi. Utilisez cette compétence lorsque vous travaillez avec des points de terminaison Surf, l'extraction de données Twitter/X, les données Reddit, l'exploration/recherche Web ou l'inférence LLM au paiement par demande. À utiliser également lors de la configuration de @x402/fetch pour les services Surf, en utilisant le proxy x402 avec les URL Surf ou toute mention des domaines twitter.surf, reddit.surf, inference.surf ou web.surf. Même si l'utilisateur dit simplement « obtenir des tweets », « rechercher sur Reddit » ou « parcourir une page » et que Surf est dans le contexte du projet, utilisez cette compétence.
