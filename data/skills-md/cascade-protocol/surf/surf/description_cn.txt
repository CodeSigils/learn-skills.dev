使用 Surf 按使用付费 API 进行构建 - Twitter 数据、Reddit 数据、LLM 推理和 surf.cascade.fyi 上的网页抓取。每当使用 Surf 端点、Twitter/X 数据提取、Reddit 数据、网络爬行/搜索或按请求付费的 LLM 推理时，请使用此技能。还可以在为 Surf 服务设置 @x402/fetch、将 x402-proxy 与 Surf URL 结合使用，或提及 twitter.surf、reddit.surf、inference.surf 或 web.surf 域时使用。即使用户只是说“获取推文”、“搜索 reddit”或“抓取页面”并且 Surf 位于项目上下文中，也可以使用此技能。
