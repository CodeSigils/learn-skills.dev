ローカルの画像やその他のファイル (PDF、zip、ログなど) を GitHub にアップロードし、プル リクエストの説明、問題、またはコメントに埋め込みます。これにより、正規の github.com/user-attachments URL が生成されます (プライベート リポジトリのアップロードは非公開のままです)。 「PR にスクリーンショットを添付する」、「PR の説明に画像を追加する」、「問題にこの画像を挿入する」、「問題にこの PDF/ログ/zip を添付する」、「PR にテスト結果を表示する」、「前後のスクリーンショットを埋め込む」、または GitHub 上の変更を視覚的に文書化するか、ファイルを添付するよう要求された場合に使用します。 「gh-image」gh CLI 拡張機能を利用します。
