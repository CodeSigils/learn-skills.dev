قم بتحميل الصور المحلية والملفات الأخرى (PDF، zip، log، ...) إلى GitHub وقم بتضمينها في وصف طلب السحب أو المشكلة أو التعليق - مما ينتج عناوين URL الأساسية لـ github.com/user-attachments (تظل تحميلات الريبو الخاص خاصة). يُستخدم عندما يُطلب منك "إرفاق لقطة شاشة للعلاقات العامة"، أو "إضافة صورة إلى وصف العلاقات العامة"، أو "وضع هذه الصورة في المشكلة"، أو "إرفاق ملف PDF/log/zip هذا بالمشكلة"، أو "إظهار نتائج الاختبار في العلاقات العامة"، أو "تضمين لقطات الشاشة قبل/بعد"، أو أي طلب لتوثيق أو إرفاق ملفات بالتغييرات على GitHub بشكل مرئي. مدعوم من امتداد `gh-image` gh CLI.
