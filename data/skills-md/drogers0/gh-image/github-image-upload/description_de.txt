Laden Sie lokale Bilder und andere Dateien (PDF, ZIP, Protokoll usw.) auf GitHub hoch und betten Sie sie in eine Pull-Request-Beschreibung, ein Problem oder einen Kommentar ein – so entstehen kanonische github.com/user-attachments-URLs (Private-Repo-Uploads bleiben privat). Verwenden Sie diese Option, wenn Sie aufgefordert werden, „einen Screenshot an die PR anzuhängen“, „ein Bild zur PR-Beschreibung hinzuzufügen“, „dieses Bild in das Problem einzufügen“, „dieses PDF/Protokoll/zip an das Problem anzuhängen“, „Testergebnisse in der PR anzuzeigen“, „Vorher/Nachher-Screenshots einzubetten“ oder bei jeder Anforderung, Änderungen auf GitHub visuell zu dokumentieren oder Dateien anzufügen. Unterstützt durch die gh-CLI-Erweiterung „gh-image“.
