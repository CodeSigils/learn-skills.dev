Téléchargez des images locales et d'autres fichiers (PDF, zip, journal, …) sur GitHub et intégrez-les dans une description de demande d'extraction, un problème ou un commentaire – produisant des URL canoniques github.com/user-attachments (les téléchargements de dépôts privés restent privés). À utiliser lorsqu'on vous demande de « joindre une capture d'écran au PR », « ajouter une image à la description du PR », « mettre cette image dans le problème », « joindre ce PDF/log/zip au problème », « afficher les résultats des tests dans le PR », « intégrer des captures d'écran avant/après » ou toute demande de documenter visuellement ou de joindre des fichiers aux modifications sur GitHub. Propulsé par l'extension CLI `gh-image`.
