Cargue imágenes locales y otros archivos (PDF, zip, registro, etc.) a GitHub e incorpórelos en una descripción de solicitud de extracción, un problema o un comentario, lo que producirá URL canónicas de github.com/user-attachments (las cargas de repositorios privados permanecen privadas). Úselo cuando se le solicite "adjuntar una captura de pantalla al PR", "agregar una imagen a la descripción del PR", "poner esta imagen en el problema", "adjuntar este PDF/log/zip al problema", "mostrar resultados de pruebas en el PR", "incrustar capturas de pantalla antes/después" o cualquier solicitud para documentar visualmente o adjuntar archivos a los cambios en GitHub. Desarrollado por la extensión CLI de gh `gh-image`.
