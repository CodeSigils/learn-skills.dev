تصميم أو تدقيق عناصر التحكم في اللعبة، وشاشة عرض المعلومات (HUD)، والقوائم، والتعليقات، ورسم خرائط الإدخال، والشفافية، والعصارة، والقنوات، والأوضاع، والاستعارات. يُستخدم عند تنفيذ واجهة المستخدم، أو عناصر التحكم، أو الكاميرا، أو البرامج التعليمية، أو شاشات عرض الحالة، أو تعليقات إمكانية الوصول، أو عندما يشعر اللاعبون بالارتباك بشأن ما حدث.
