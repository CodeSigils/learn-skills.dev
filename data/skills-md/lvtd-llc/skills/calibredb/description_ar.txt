قم بإدارة مكتبات Caliber والاستعلام عنها باستخدام calibredb CLI (المسارات المحلية أو عناوين URL لخادم Caliber Content). يُستخدم عند إدراج الكتب، أو البحث/تصفية سجلات المكتبة، أو قراءة/تحديث بيانات التعريف، أو إضافة/إزالة التنسيقات، أو تصدير الكتب، أو صيانة الأعمدة المخصصة، أو تشغيل فحوصات المكتبة، أو إدارة فهرسة/بحث FTS، أو إنشاء كتالوجات/نسخ احتياطية من مكتبة Caliber.
