Gestisci ed esegui query sulle librerie Calibre con la CLI calibredb (percorsi locali o URL del server dei contenuti Calibre). Da utilizzare per elencare libri, cercare/filtrare record di libreria, leggere/aggiornare metadati, aggiungere/rimuovere formati, esportare libri, mantenere colonne personalizzate, eseguire controlli di libreria, gestire indicizzazione/ricerca FTS o creare cataloghi/backup da una libreria Calibre.
