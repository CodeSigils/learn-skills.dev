تصميم ومراجعة التزامن Rust القائم على الخيوط مع خيارات الملكية والمشاركة والمزامنة الصريحة. يُستخدم عند الكتابة أو إعادة البناء أو مراجعة سلاسل الرسائل أو سلاسل الرسائل المحددة النطاق أو القنوات أو Arc أو Mutex أو RwLock أو Condvar أو atomics أو OneLock أو LazyLock أو Send أو Sync أو حالة توقف تام أو الحالة المشتركة.
