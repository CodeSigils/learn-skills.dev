Двухактное закрепление плана с живой документацией. АКТ 1 (вы ↔ Клод) — Клод неустанно беседует с вами о плане, по одному вопросу за раз, сравнивая его с существующей моделью предметной области и глоссарием вашего проекта (CONTEXT.md), уточняя нечеткие термины, стресс-тестирование с конкретными сценариями, перекрестные ссылки на код и встроенное обновление CONTEXT.md + ADR по мере принятия решений. АКТ 2 (Клод ↔ Кодекс) — Клод записывает заблокированный план в PLAN.md, а OpenAI Codex состязательно просматривает его в изолированной программной среде, доступной только для чтения (VERDICT:APPROVED/REVISE), Клод редактирует и повторно отправляет в тот же сеанс Кодекса до тех пор, пока не будет APPROVED или не будет достигнуто ограничение MAX_ROUNDS, после чего вы подписываете код перед любым кодом. Используйте, когда пользователь говорит «/grill-with-docs-codex», «проверьте меня по документам, а затем проведите проверку кодекса», «проведите стресс-тестирование по нашей модели предметной области, а затем получите вторую модель на ней» или собирается создать что-то важное в проекте с установленной терминологией/нежелательными рекомендациями и хочет согласования, документации и проверки работоспособности перекрестной модели. Создан на основе «Гриль с документами» Мэтта Покока (MIT). НЕ для проверки уже написанного кода (используйте /codex:review) и НЕ для тривиальных изменений.
