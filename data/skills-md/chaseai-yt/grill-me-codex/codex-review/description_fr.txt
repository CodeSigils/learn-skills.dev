Une boucle de révision de PLAN contradictoire autonome dans laquelle Claude Code (constructeur) et OpenAI Codex (critique en lecture seule) associent un plan de mise en œuvre avant l'écriture de tout code. Utilisez-le lorsque vous avez DÉJÀ un plan ou une idée claire et que vous souhaitez simplement passer un test de résistance inter-modèles – aucun entretien sur les exigences au préalable. Claude rédige/charge le plan dans PLAN.md, le Codex l'examine dans un bac à sable en lecture seule et renvoie VERDICT : APPROVED ou VERDICT : REVISE, Claude révise et le soumet à nouveau à la MÊME session Codex (contexte préservé) jusqu'à ce qu'APPROUVÉ ou qu'un plafond MAX_ROUNDS configurable soit atteint. L'humain approuve le plan convergé avant le code. À utiliser lorsque l'utilisateur dit "/codex-review", "codex review my plan", "demander au Codex review my plan", "argumenter sur ce plan avec le Codex", "review contradictoire du plan", "faire en sorte que Claude et le Codex se disputent/se battent pour le plan", ou est sur le point de construire quelque chose à enjeux élevés (authentification, schéma, concurrence, migrations, paiements) et souhaite un deuxième modèle de vérification de l'intégrité du PLAN avant la mise en œuvre. Pour un entretien guidé sur les exigences AVANT l’examen, utilisez plutôt /grill-me-codex. PAS pour réviser le CODE déjà écrit (c'est-à-dire le /codex:review du plugin Codex) et PAS pour des modifications triviales.
