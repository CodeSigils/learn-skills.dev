コードが記述される前に、Claude Code (ビルダー) と OpenAI Codex (読み取り専用批評家) がタッグを組んで実装計画を作成する、スタンドアロンの敵対的 PLAN レビュー ループ。すでに計画や明確なアイデアがあり、クロスモデルのストレス テストだけが必要な場合に、これを使用します。最初に要件をインタビューする必要はありません。クロードはプランを草案して PLAN.md にロードし、Codex は読み取り専用サンドボックスでそれをレビューし、VERDICT:APPROVED または VERDICT:REVISE を返します。クロードは修正して、APPROVED または構成可能な MAX_ROUNDS の上限に達するまで、同じ Codex セッションに再送信します (コンテキストは保持されます)。人間はコードを書く前に、統合された計画を承認します。ユーザーが「/codex-review」、「コーデックスに私の計画をレビューしてもらう」、「コーデックスに私の計画をレビューしてもらう」、「この計画をコーデックスと議論する」、「敵対的な計画のレビュー」、「クロードとコーデックスに計画をめぐって議論/争わせる」、または一か八かの何か (認証、スキーマ、同時実行、移行、支払い) を構築しようとしており、実装前に PLAN の 2 番目のモデルの健全性チェックを希望する場合に使用します。レビュー前のガイ​​ド付き要件インタビューの場合は、代わりに /grill-me-codex を使用してください。すでに書かれたコード (つまり、Codex プラグインの /codex:review) をレビューするためではなく、些細な変更を行うためでもありません。
