Eine eigenständige kontradiktorische PLAN-Überprüfungsschleife, in der Claude Code (Ersteller) und OpenAI Codex (schreibgeschützter Kritiker) einen Implementierungsplan erstellen, bevor Code geschrieben wird. Verwenden Sie dies, wenn Sie BEREITS einen Plan oder eine klare Vorstellung haben und zunächst nur den modellübergreifenden Stresstest durchführen möchten – kein Anforderungsgespräch. Claude entwirft/lädt den Plan in PLAN.md, Codex überprüft ihn in einer schreibgeschützten Sandbox und gibt VERDICT:APPROVED oder VERDICT:REVISE zurück, Claude überarbeitet ihn und sendet ihn erneut an die GLEICHE Codex-Sitzung (Kontext bleibt erhalten), bis APPROVED oder eine konfigurierbare MAX_ROUNDS-Obergrenze erreicht wird. Der Mensch genehmigt den konvergierten Plan vor dem Code. Verwenden Sie dies, wenn der Benutzer „/codex-review“, „codex meinen Plan überprüfen lassen“, „Codex meinen Plan überprüfen lassen“, „diesen Plan mit Codex besprechen“, „kontradiktorische Planüberprüfung“ sagt, „Claude und Codex über den Plan streiten/streiten lassen“ sagt oder im Begriff ist, etwas zu erstellen, bei dem viel auf dem Spiel steht (Authentifizierung, Schema, Parallelität, Migrationen, Zahlungen) und vor der Implementierung eine Plausibilitätsprüfung des zweiten Modells für den PLAN wünscht. Für ein geführtes Anforderungsinterview VOR der Überprüfung verwenden Sie stattdessen /grill-me-codex. NICHT zum Überprüfen von bereits geschriebenem CODE (das ist /codex:review des Codex-Plugins) und NICHT für triviale Änderungen.
