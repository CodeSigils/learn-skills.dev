Автономный цикл состязательного анализа ПЛАНА, в котором Claude Code (разработчик) и OpenAI Codex (критик только для чтения) объединяют план реализации перед написанием любого кода. Используйте это, когда у вас УЖЕ есть план или ясная идея и вы просто хотите провести стресс-тест по нескольким моделям — без предварительного собеседования по требованиям. Клод составляет черновик/загружает план в PLAN.md, Кодекс просматривает его в изолированной программной среде только для чтения и возвращает VERDICT:APPROVED или VERDICT:REVISE, Клод пересматривает и повторно отправляет план в ТО ЖЕ сеанс Кодекса (контекст сохраняется) до тех пор, пока APPROVED или не будет достигнуто настраиваемое ограничение MAX_ROUNDS. Человек утверждает конвергентный план перед написанием кода. Используйте, когда пользователь говорит: «/codex-review», «Кодекс рассмотрит мой план», «Пусть Кодекс рассмотрит мой план», «Спорьте об этом плане с Кодексом», «Просмотр состязательного плана», «Заставьте Клода и Кодекс спорить/спорить по поводу плана» или собирается построить что-то важное (аутентификация, схема, параллелизм, миграция, платежи) и хочет выполнить вторую модель проверки работоспособности ПЛАНА перед реализацией. Для собеседования по требованиям ПЕРЕД проверкой используйте вместо этого /grill-me-codex. НЕ для просмотра уже написанного КОДА (то есть /codex:review плагина Кодекса) и НЕ для тривиальных изменений.
