قم بإنشاء أو توظيف وكلاء Paperclip باستخدام سير العمل الأصلي المدرك للحوكمة. يُستخدم عندما يطلب المستخدم إنشاء وكيل Paperclip جديد أو استئجاره أو توفيره أو صياغته أو تكوينه، بما في ذلك اختيار الدور وخط التقارير وتكوين المحول والمهارات المطلوبة وحزمة التعليمات والميزانية وإعدادات نبضات القلب ومعالجة الموافقة.
