Conventions de projet pour les projets Laravel, y compris le code d'application, PHP de support de projet, les shells Inertia Blade, les modèles React Email, les modèles basés sur des schémas et le routage des tests Pest. À utiliser lors de la création ou de la modification d'itinéraires, de configuration, de localisation, de points d'entrée publics/amorçage, de seeders, d'outils racine PHP, de modèles, de migrations, de relations, de conversions, d'usines, de ressources, d'actions, de commandes de console, de middleware, d'écouteurs, de politiques, de fournisseurs, de classes de support, de ressources/vues, de shells de lame, de ressources/modèles/exportations de courrier électronique de réaction ou de tests sous Unité, Intégration, Fonctionnalité ou Architecture, plus Navigateur uniquement lorsqu'une véritable suite de navigateur existe. Encode le PHP typé strict, les modèles Eloquent non gardés, les clés de route publiques NanoID, les colonnes *_id indexées sans contraintes de clé étrangère de base de données, les migrations sans méthodes down(), l'ordre des tests de fonctionnalités du contrôleur/API et les tests d'intégration de modèle de logique système.
