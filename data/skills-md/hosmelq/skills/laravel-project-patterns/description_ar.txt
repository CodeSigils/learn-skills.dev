اصطلاحات المشروع لمشاريع Laravel، بما في ذلك كود التطبيق، وPHP الداعم للمشروع، وأصداف Inertia Blade، وقوالب React Email، والنماذج المدعومة بالمخطط، وتوجيه اختبار Pest. يُستخدم عند إنشاء أو تغيير المسارات، أو التكوين، أو الترجمة، أو نقاط التمهيد/الدخول العامة، أو البذارات، أو أدوات الجذر PHP، أو النماذج، أو عمليات الترحيل، أو العلاقات، أو القوالب، أو المصانع، أو الموارد، أو الإجراءات، أو أوامر وحدة التحكم، أو البرامج الوسيطة، أو المستمعين، أو السياسات، أو مقدمي الخدمة، أو فئات الدعم، أو الموارد/طرق العرض، أو أغطية Blade، أو الموارد/قوالب البريد الإلكتروني التفاعلي/الصادرات، أو الاختبارات ضمن الوحدة أو التكامل أو الميزة أو الهندسة المعمارية، بالإضافة إلى المتصفح فقط عند وجود مجموعة متصفح حقيقية. يشفر لغة PHP المكتوبة بشكل صارم، ونماذج Eloquent غير المحمية، ومفاتيح توجيه NanoID العامة، وأعمدة *_id المفهرسة بدون قيود المفتاح الخارجي لقاعدة البيانات، وعمليات الترحيل بدون أساليب down()، وترتيب اختبار ميزات وحدة التحكم/واجهة برمجة التطبيقات، واختبارات تكامل نموذج منطق النظام.
