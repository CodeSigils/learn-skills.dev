Escribe pruebas de funciones de Pest para controladores HTTP de Laravel con patrones repetibles para flujos web/de sesión y API/JSON. Se activa para pruebas de funciones centradas en el controlador (especialmente en pruebas/Función/Http/Controladores/**), matrices de acciones CRUD, comprobaciones de enlace de rutas anidadas, resultados de autorización (403 frente a 404), conjuntos de datos de validación y aserciones de persistencia. Tiene prioridad sobre las pruebas de plagas para las pruebas de funciones centradas en el controlador.
