نشر وتكوين خوادم بروكسي Xray. يُستخدم عندما يطلب المستخدم إعداد وكلاء VLESS أو VMess أو Trojan أو Shadowsocks، أو تكوين نقل Reality أو TLS، أو نشر Xray مع XTLS، أو إعداد التوجيه الاحتياطي، أو إدارة الوصول متعدد المستخدمين، أو تكوين قواعد توجيه حركة المرور، أو إعداد الأنفاق المستندة إلى CDN، أو إنشاء روابط اشتراك لتطبيقات العميل، أو مراقبة حركة مرور Xray، أو تجاوز قيود الشبكة. يغطي جميع بروتوكولات الأشعة السينية الرئيسية وعمليات النقل وأنماط النشر.
