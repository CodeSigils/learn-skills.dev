Automatizza e crea script per i flussi di lavoro di DaVinci Resolve. Da utilizzare quando un utente richiede di creare script per DaVinci Resolve tramite API Python/Lua, automatizzare la gradazione del colore, progetti di rendering in batch, gestire le sequenze temporali a livello di programmazione, automatizzare l'importazione di contenuti multimediali, creare code di rendering, creare composizioni Fusion tramite script, automatizzare l'elaborazione audio Fairlight, gestire database di progetti, creare script di strumenti personalizzati o integrare Resolve nelle pipeline di produzione. Copre l'API Resolve Scripting (Python/Lua), lo scripting Fusion e l'automazione del flusso di lavoro.
