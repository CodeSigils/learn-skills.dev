أتمتة وبرمجة برنامج DaVinci لحل سير العمل. يُستخدم عندما يطلب المستخدم كتابة DaVinci Resolve عبر Python/Lua API، أو أتمتة تصنيف الألوان، أو مشاريع تقديم الدفعات، أو إدارة المخططات الزمنية برمجيًا، أو أتمتة استيراد الوسائط، أو إنشاء قوائم انتظار العرض، أو إنشاء تركيبات Fusion عبر البرنامج النصي، أو أتمتة معالجة Fairlight الصوتية، أو إدارة قواعد بيانات المشروع، أو إنشاء برامج نصية للأدوات المخصصة، أو دمج Resolve في خطوط أنابيب الإنتاج. يغطي Resolve Scripting API (Python/Lua)، والبرمجة النصية Fusion، وأتمتة سير العمل.
