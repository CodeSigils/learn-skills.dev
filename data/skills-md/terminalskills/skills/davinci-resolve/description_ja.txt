DaVinci Resolve ワークフローを自動化してスクリプト化します。ユーザーが、Python/Lua API を介した DaVinci Resolve のスクリプト作成、カラー グレーディングの自動化、バッチ レンダー プロジェクト、プログラムによるタイムラインの管理、メディア インポートの自動化、レンダー キューの構築、スクリプトによる Fusion コンポジションの作成、Fairlight オーディオ処理の自動化、プロジェクト データベースの管理、カスタム ツール スクリプトの構築、または Resolve のプロダクション パイプラインへの統合を要求する場合に使用します。 Resolve Scripting API (Python/Lua)、Fusion スクリプト、ワークフロー自動化について説明します。
