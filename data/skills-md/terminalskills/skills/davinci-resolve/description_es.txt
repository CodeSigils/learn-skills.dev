Automatiza y programa flujos de trabajo de DaVinci Resolve. Úsalo cuando un usuario solicite programar DaVinci Resolve mediante la API Python/Lua, automatizar la corrección de color, renderizar proyectos en lote, gestionar líneas de tiempo programáticamente, automatizar la importación de medios, crear colas de render, generar composiciones Fusion mediante scripts, automatizar el procesamiento de audio en Fairlight, gestionar bases de datos de proyectos, crear scripts de herramientas personalizadas o integrar Resolve en pipelines de producción. Cubre la API de scripting de Resolve (Python/Lua), el scripting de Fusion y la automatización de flujos de trabajo.
