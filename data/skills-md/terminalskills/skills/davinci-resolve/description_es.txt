Automatice y programe flujos de trabajo de DaVinci Resolve. Úselo cuando un usuario solicite crear un script de DaVinci Resolve a través de Python/Lua API, automatizar la gradación de color, renderizar proyectos por lotes, administrar líneas de tiempo mediante programación, automatizar la importación de medios, crear colas de renderizado, crear composiciones de Fusion mediante script, automatizar el procesamiento de audio Fairlight, administrar bases de datos de proyectos, crear scripts de herramientas personalizadas o integrar Resolve en procesos de producción. Cubre la API Resolve Scripting (Python/Lua), scripting Fusion y automatización del flujo de trabajo.
