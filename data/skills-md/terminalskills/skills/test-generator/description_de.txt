Generieren Sie Unit-, Integrations- und End-to-End-Tests für vorhandenen Code. Verwenden Sie diese Option, wenn ein Benutzer Tests schreiben, Testabdeckung hinzufügen, Komponententests erstellen, Integrationstests generieren, E2E-Tests erstellen, Codeabdeckung verbessern, Spezifikationen schreiben oder Tests zu einem Projekt hinzufügen möchte. Unterstützt Jest, Vitest, Pytest, Playwright, React Testing Library und Cypress. Analysiert Code, um aussagekräftige Behauptungen, Randfälle und Schein-Setups zu erstellen.
