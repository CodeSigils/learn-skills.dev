Создавайте модульные, интеграционные и сквозные тесты для существующего кода. Используйте, когда пользователь просит написать тесты, добавить тестовое покрытие, создать модульные тесты, сгенерировать интеграционные тесты, построить тесты e2e, улучшить покрытие кода, написать спецификации или добавить тестирование в проект. Поддерживает Jest, Vitest, Pytest, Playwright, библиотеку тестирования React и Cypress. Анализирует код для создания осмысленных утверждений, крайних случаев и макетов настроек.
