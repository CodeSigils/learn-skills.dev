Genera test unitari, di integrazione e end-to-end per il codice esistente. Da utilizzare quando un utente chiede di scrivere test, aggiungere copertura di test, creare unit test, generare test di integrazione, creare test e2e, migliorare la copertura del codice, scrivere specifiche o aggiungere test a un progetto. Supporta Jest, Vitest, Pytest, Playwright, React Testing Library e Cypress. Analizza il codice per produrre asserzioni significative, casi limite e configurazioni fittizie.
