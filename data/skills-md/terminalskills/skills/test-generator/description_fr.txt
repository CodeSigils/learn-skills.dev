Générez des tests unitaires, d'intégration et de bout en bout pour le code existant. À utiliser lorsqu'un utilisateur demande d'écrire des tests, d'ajouter une couverture de test, de créer des tests unitaires, de générer des tests d'intégration, de créer des tests e2e, d'améliorer la couverture de code, d'écrire des spécifications ou d'ajouter des tests à un projet. Prend en charge Jest, Vitest, Pytest, Playwright, React Testing Library et Cypress. Analyse le code pour produire des assertions significatives, des cas extrêmes et des configurations fictives.
