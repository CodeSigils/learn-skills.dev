أضف ذاكرة ثابتة إلى عوامل ترميز الذكاء الاصطناعي - أنظمة ذاكرة البحث القائمة على الملفات والمتجهات والدلالية التي تبقى بين الجلسات. يُستخدم عندما يطلب المستخدم "تذكر هذا"، أو "إضافة ذاكرة إلى وكيلي"، أو "مواصلة السياق بين الجلسات"، أو "إنشاء قاعدة معرفية لوكيلي"، أو "إعداد ذاكرة الوكيل"، أو "جعل الذكاء الاصطناعي الخاص بي يتذكر الأشياء". يغطي الذاكرة المستندة إلى الملفات (MEMORY.md)، وSQLite مع التضمينات، وقواعد البيانات المتجهة (ChromaDB، وPinecone)، والبحث الدلالي، وتوحيد الذاكرة، وحقن السياق تلقائيًا.
