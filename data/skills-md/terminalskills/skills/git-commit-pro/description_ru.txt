Пишите хорошо структурированные сообщения о коммитах git в соответствии со стандартом обычных коммитов. Используйте, когда пользователь просит зафиксировать изменения, написать сообщение о фиксации, подготовить и зафиксировать, улучшить сообщение о фиксации или следовать соглашениям о фиксации. Анализирует различия для создания точных и содержательных сообщений о фиксации.
