Analizza e ottimizza le query SQL per le prestazioni. Da utilizzare quando un utente chiede di ottimizzare una query, velocizzare una query lenta, analizzare un piano di query, aggiungere indici, correggere query N+1, ridurre i tempi delle query, ottimizzare le prestazioni del database o riscrivere SQL per aumentare l'efficienza. Supporta PostgreSQL, MySQL e SQLite.
