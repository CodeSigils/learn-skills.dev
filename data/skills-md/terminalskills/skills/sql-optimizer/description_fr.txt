Analysez et optimisez les requêtes SQL pour les performances. À utiliser lorsqu'un utilisateur demande d'optimiser une requête, d'accélérer une requête lente, d'analyser un plan de requête, d'ajouter des index, de corriger des requêtes N+1, de réduire le temps de requête, d'ajuster les performances de la base de données ou de réécrire SQL pour plus d'efficacité. Prend en charge PostgreSQL, MySQL et SQLite.
