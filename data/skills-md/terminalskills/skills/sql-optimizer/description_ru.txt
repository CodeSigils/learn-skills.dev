Анализируйте и оптимизируйте SQL-запросы для повышения производительности. Используйте, когда пользователь просит оптимизировать запрос, ускорить медленный запрос, проанализировать план запроса, добавить индексы, исправить запросы N+1, сократить время запроса, настроить производительность базы данных или переписать SQL для повышения эффективности. Поддерживает PostgreSQL, MySQL и SQLite.
