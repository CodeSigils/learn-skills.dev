Analysieren und optimieren Sie SQL-Abfragen hinsichtlich der Leistung. Verwenden Sie diese Option, wenn ein Benutzer eine Abfrage optimieren, eine langsame Abfrage beschleunigen, einen Abfrageplan analysieren, Indizes hinzufügen, N+1-Abfragen korrigieren, die Abfragezeit reduzieren, die Datenbankleistung optimieren oder SQL für mehr Effizienz neu schreiben möchte. Unterstützt PostgreSQL, MySQL und SQLite.
