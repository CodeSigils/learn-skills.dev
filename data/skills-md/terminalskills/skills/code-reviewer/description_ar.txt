قم بإجراء مراجعات شاملة للتعليمات البرمجية مع تعليقات قابلة للتنفيذ وذات أولوية. يُستخدم عندما يطلب المستخدم مراجعة التعليمات البرمجية، أو التحقق من جودة التعليمات البرمجية، أو العثور على الأخطاء، أو مراجعة طلب سحب، أو تدقيق التعليمات البرمجية بحثًا عن المشكلات، أو الحصول على تعليقات حول التنفيذ. يغطي الصحة والأمان والأداء وسهولة القراءة وأفضل الممارسات عبر اللغات.
