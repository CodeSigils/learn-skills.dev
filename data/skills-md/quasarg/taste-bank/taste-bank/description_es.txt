La biblioteca de estilos de interfaz para agentes de codificación. Utilice la CLI del banco de gustos para buscar estilos de diseño seleccionados (tokens de diseño + reglas + plantillas) e insertarlos en el proyecto actual. Invocar cuando el usuario desea orientación sobre diseño/estilo, referencias o aplicar un estilo visual guardado a una interfaz. Comandos: lista de banco de gustos / habilidad <slug> / uso <slug>.
