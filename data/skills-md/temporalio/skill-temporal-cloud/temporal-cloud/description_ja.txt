Temporal Cloud の接続、認証、構成の問題を修正します。ユーザーがログインに失敗した場合、クラウドに接続できない場合、x509/TLS エラーが発生した場合、名前空間またはエンドポイントの不一致がある場合、壊れた SDK 接続スニペットを貼り付けた場合、どのエンドポイントを使用するか混乱している場合、「ポーラーがありません」または RESOURCE_EXHAUSTED が表示される場合、PrivateLink/PSC で苦労する場合、または新しい名前空間のセットアップに支援が必要な場合に使用します。 HA 名前空間のフェイルオーバーや DNS の問題にも使用します。ワーカーのパフォーマンスの調整やスケーリングを目的としたものではありません。
