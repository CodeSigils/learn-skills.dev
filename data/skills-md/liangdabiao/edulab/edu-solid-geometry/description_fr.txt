Convertir un problème de géométrie solide en une page Web d’enseignement interactive autonome : analyse pas à pas en MathJax sur le côté gauche, modèle 3D interactif Three.js sur le côté droit (mise en évidence progressive + changement de caméra). Prend en charge trois méthodes d’entrée — problème fourni sous forme de texte, génération aléatoire de problème, téléchargement d’une image du problème pour reconnaissance et résolution. Couvre les types de problèmes sur les cubes/parallélépipèdes rectangles, les pyramides/prismes, les cylindres/cônes tels que les angles ligne‑plan, les angles diédraux, les angles entre droites gauches, la distance point‑plan, le volume, etc., en les traitant uniformément avec la « construction par coordonnées + méthode vectorielle », alimentés par des calculs précis de SymPy (les réponses, les coordonnées 3D, les valeurs des étapes sont constamment générées). D’autres agents peuvent également invoquer cette capacité pour générer de telles pages Web. Mots déclencheurs : géométrie solide, angle ligne‑plan, angle diédral, droite gauche, distance au plan, pyramide tétraédrique régulière, calcul d’angle de cube, résoudre ce problème de géométrie, générer un problème de géométrie solide aléatoire, le problème de géométrie solide dans cette image ; géométrie solide, angle ligne‑plan, angle diédral, angle entre droites gauches, distance au plan, page de solution de géométrie interactive.
