Преобразовать химическую реакцию в автономную микроскопическую 3D‑интерактивную демонстрацию в виде веб‑страницы: левая/верхняя часть отображает интерактивную анимацию молекулы на Three.js (перетаскивайте ползунок, чтобы увидеть разрыв связей, их образование, переустановку атомов, пошаговое выделение), правая сторона показывает уравнение реакции в KaTeX + пошаговое объяснение + подсчёт сохранения атомов + при желании график прогресса энергии‑реакции. Поддерживает три способа ввода — по заданному текстовому уравнению/реакции, генерация случайной реакции или загрузка изображения для распознавания и демонстрации. Охватывает горения, синтез/разложение/замещение‑одиночное/замещение‑двойное, окислительно‑восстановительные процессы (визуализация переноса электронов), органические механизмы (например, этерификация с каталитами и переходными состояниями). Одинаково управляется SymPy с точностью до символов: автоматически уравнивает уравнения, проверяет сохранение атомов и их сопоставление, выводит разрывы/образования связей; ответы геометрически гомологичны. Встроено два движка, которые выбираются автоматически: morph (деформация атомов, показывающая сохранение атомов) и mechanism (ключевые кадры механизма, показывающие катализ/переходные состояния). Смешанная геометрия: по умолчанию собственная библиотека молекул VSEPR; если в окружении установлен RDKit, могут генерироваться конформации из SMILES (никогда не устанавливается автоматически). Другие агенты также могут вызвать эту возможность для создания подобных веб‑страниц. Форма работает параллельно с edu‑solid‑geometry / edu‑analytic‑geometry, но использует Three.js + KaTeX для демонстрации молекулярных реакций. Триггер‑слова: 化学反应, 微观演示, 分子动画, 燃烧, 甲烷燃烧, 氢气燃烧, 电解水, 氧化还原, 电子转移, 酯化反应, 反应机理, 断键成键, 原子守恒, 质量守恒, 化学方程式配平, 解这个化学反应, 随机出一个化学反应, 这张图里的化学反应; химическая реакция, микроскопическая/молекулярная анимация, горение, электролиз, окислительно‑восстановительный перенос электронов, механизм этерификации, разрыв и образование связей, сохранение атомов, уравнивание уравнения, интерактивная страница химической реакции.
