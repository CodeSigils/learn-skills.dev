Cree una página web de demostración interactiva en 3D microscópica autónoma de una reacción química: el panel izquierdo/superior muestra una animación molecular interactiva de Three.js (arrastre los controles deslizantes para ver la ruptura de enlaces, la formación de enlaces, la reorganización atómica y el resaltado paso a paso); el panel derecho muestra una ecuación de reacción KaTeX junto con una explicación paso a paso, un recuento de conservación de átomos y una curva de progreso de reacción de energía opcional. Se admiten tres métodos de entrada: proporcionar una reacción/ecuación textual, generar un problema aleatorio o cargar una imagen para su reconocimiento y luego demostrarla. Cubre combustión, síntesis/descomposición/desplazamiento/doble desplazamiento, redox (visualización de transferencia de electrones), mecanismos orgánicos (por ejemplo, esterificación con catalizadores o estados de transición). Impulsado uniformemente por SymPy para cálculos exactos: equilibre ecuaciones automáticamente, verifique la conservación y el mapeo de átomos, derive la ruptura/formación de enlaces; las respuestas son geométricamente consistentes. Se proporcionan dos motores integrados con selección automática: morfo (deformación del átomo, que muestra la conservación del átomo) y mecanismo (fotogramas clave del mecanismo, que muestra el catalizador/estado de transición). Geometría mixta: por defecto, una biblioteca molecular VSEPR de construcción propia; si el entorno tiene RDKit, puede generar conformaciones desde SMILES (nunca se instala automáticamente). Otros agentes también pueden invocar esta capacidad para generar dichas páginas web. El formato es paralelo a edu‑solid‑geometry / edu‑analytic‑geometry, pero utiliza Three.js + KaTeX para demostrar reacciones moleculares.
