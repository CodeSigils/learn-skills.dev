해석기하 문제를 자체적인 인터랙티브 교육 웹페이지로 전환한다: 왼쪽 패널에는 문제 진술 + 동적 콘솔(기하량을 실시간으로 재계산하는 가변 파라미터 슬라이더 + 이론적 범위/고정값 표시)이 나타나고, 가운데 패널에는 단계별 KaTeX 분석을 보여주며, 오른쪽 패널에는 2D Canvas 동적 기하 보드(타원/쌍곡선/포물선/원 + 이동하는 직선/이동점 + 벡터 + 주석 + 자유그림)가 배치된다. 세 가지 입력 모드—텍스트로 된 문제 제공, 무작위 문제 생성, 문제 사진 업로드 후 인식·해결—를 지원한다. 표준 방정식 찾기, 현 길이, 벡터 내적의 범위·고정값, 삼각형 면적의 극값, 고정점, 기울기의 곱이라는 고정값, 점궤적, 이심률 등과 같은 문제 유형을 다루며, “x = my + c 형태의 직선을 설정하고 동시에 해결 + Vieta + 대입/상수 분리”라는 패턴으로 통일되고, 정밀한 SymPy 계산(답, 좌표, 단계값, 인터랙티브 엔진의 이론적 범위 모두 일관되게 제공)으로 구동된다. 다른 에이전트도 이 스킬을 호출해 해당 웹페이지를 생성할 수 있다. 형식은 edu‑solid‑geometry와 유사하지만 Canvas‑2D + KaTeX(Three.js 대신)를 사용한다. 트리거 단어: 해석기하, 원뿔곡선, 타원, 쌍곡선, 포물선, 직선과 원뿔곡선, 초점 현, 현 길이, 내적 범위, 벡터 내적, 고정점 문제, 고정값 문제, 기울기의 곱, 삼각형 면적 극값, 점궤적 방정식, 이심률, 이 해석기하 문제를 풀어라, 원뿔곡선 문제를 무작위 생성, 이 그림의 해석기하 문제; 해석기하, 원뿔곡선, 타원, 쌍곡선, 포물선, 현 길이, 내적 범위, 고정점, 고정값, 점궤적, 이심률, 인터랙티브 해석기하 솔루션 페이지.
