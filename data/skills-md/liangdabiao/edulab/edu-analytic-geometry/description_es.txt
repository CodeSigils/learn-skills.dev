Convierte un problema de geometría analítica en una página web de enseñanza interactiva y autónoma: la columna izquierda muestra el enunciado del problema más una consola dinámica (un deslizador de parámetro variable que impulsa el recálculo en tiempo real de una magnitud geométrica e indica el rango teórico o el valor fijo), la columna central presenta el análisis paso a paso en KaTeX, y la columna derecha ofrece un tablero de geometría dinámica en Canvas 2D (elipse/hipérbola/ parábola/círculo + línea móvil/punto móvil + vectores + anotaciones + dibujo a mano alzada). Soporta tres métodos de entrada: proporcionar un problema en texto, generar aleatoriamente un problema o subir una foto de un problema para su reconocimiento y solución. Cubre tipos de problemas como encontrar ecuaciones estándar, longitudes de cuerdas, rangos o valores fijos del producto punto de vectores, áreas extremales de triángulos, puntos fijos, valores fijos (producto de pendientes), lugares geométricos, excentricidades, etc., utilizando un enfoque unificado de “establecer una línea con un parámetro x = my + c, combinar ecuaciones, aplicar Vieta, sustituir/cambiar variables o separar constantes”, impulsado por cálculos exactos de Sympy (las respuestas, coordenadas, valores intermedios y el rango teórico del motor interactivo se derivan de forma coherente). Otros agentes también pueden invocar esta capacidad para generar dichas páginas web. El formato es paralelo a edu‑solid‑geometry pero emplea Canvas‑2D + KaTeX (no Three.js).
