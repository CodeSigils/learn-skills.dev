Преобразовать задачу аналитической геометрии в автономную интерактивную обучающую веб‑страницу: левая колонка – условие задачи + динамическая консоль (ползунок переменной‑параметра, запускающий пересчёт геометрической величины в реальном времени + индикатор теоретического диапазона/фиксированного значения), средняя колонка – пошаговый разбор KaTeX, правая колонка – динамическая геометрическая доска на 2D‑Canvas (эллипс / гипербола / парабола / окружность + подвижная прямая / подвижная точка + векторы + аннотации + рисунки кистью). Поддерживает три режима ввода — задана текстовая задача, случайная генерация задачи, загрузка изображения задачи для распознавания и решения. Охватывает типы задач, такие как нахождение стандартных уравнений, длина хорды, диапазон/фиксированное значение скалярного произведения векторов, экстремальная площадь треугольника, фиксированная точка, фиксированное значение (произведение наклонов), места точек, эксцентриситет и т.п., объединённые принципом «задать параметрическую прямую x = my + c + решить систему + Вьета + подстановка/разделение констант», и основанные на точных вычислениях SymPy (ответы, координаты, промежуточные значения и теоретический диапазон интерактивного движка берутся из единого источника). Другие агенты также могут вызывать эту возможность для генерации таких страниц. Макет аналогичен edu‑solid‑geometry, но использует Canvas‑2D + KaTeX (а не Three.js). Триггерные слова: аналитическая геометрия, конические сечения, эллипс, гипербола, парабола, прямая и конические сечения, фокальная хорда, длина хорды, диапазон значений скалярного произведения, векторное скалярное произведение, задача о фиксированной точке, задача о фиксированном значении, произведение наклонов, экстремальная площадь треугольника, уравнение места точек, эксцентриситет, решить эту задачу аналитической геометрии, сгенерировать случайную задачу о конических сечениях, задача аналитической геометрии на этой картинке; аналитическая геометрия, конические сечения, эллипс, гипербола, парабола, длина хорды, диапазон скалярного произведения, фиксированная точка, фиксированное значение, место точек, эксцентриситет, интерактивная страница решения задач аналитической геометрии.
