Turn an analytic geometry problem into a self‑contained interactive teaching web page: left column problem statement + dynamic console (a variable‑parameter slider that drives real‑time recomputation of a geometric quantity + theoretical range/fixed‑value indicator), middle column KaTeX step‑by‑step solution, right column 2D Canvas dynamic geometry board (ellipse/hyperbola/parabola/circle + moving line/moving point + vectors + annotations + freehand drawing). Supports three entry methods—given a text problem, randomly generate a problem, or upload an image of a problem for recognition and solving. Covers problem types such as finding standard equations, chord length, vector dot‑product range/fixed value, extremal triangle area, fixed point, fixed value (product of slopes), locus, eccentricity, etc., unifying them with “set a parametric line x = my + c + system of equations + Vieta + substitution/constant separation,” and driven by exact computations from SymPy (answers, coordinates, step numeric values, interactive engine’s theoretical range are all consistent at the source). Other agents can also invoke this capability to generate such pages. The format parallels edu‑solid‑geometry but uses Canvas‑2D + KaTeX (not Three.js).
