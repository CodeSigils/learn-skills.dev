Convertir un problème de géométrie analytique en une page web d’enseignement interactive autonome : colonne de gauche énoncé du problème + console dynamique (un curseur à paramètre variable qui déclenche le recalcul en temps réel d’une grandeur géométrique + indicateur de plage théorique/valeur fixe), colonne du milieu analyse pas à pas avec KaTeX, colonne de droite tableau de géométrie dynamique sur Canvas 2D (ellipse/hyperbole/parabole/cercle + droite mobile/point mobile + vecteurs + annotations + griffonnages). Prend en charge trois modes d’entrée — problème donné sous forme de texte, génération aléatoire de problème, téléchargement d’une image de problème pour reconnaissance puis résolution. Couvre des types de problèmes tels que la recherche d’équations standards, la longueur de corde, la plage ou la valeur fixe du produit scalaire de vecteurs, l’extrémum de l’aire d’un triangle, le point fixe, la valeur fixe (produit des pentes), le lieu, l’excentricité, etc., unifiés par « définir une droite avec le paramètre x = my + c + système d’équations + Vieta + substitution/séparation de constantes », et pilotés par des calculs exacts de Sympy (réponses, coordonnées, valeurs intermédiaires, la plage théorique du moteur interactif sont cohérents à la source). D’autres agents peuvent également invoquer cette capacité pour générer de telles pages. Le format s’inspire de edu‑solid‑geometry, mais utilise Canvas‑2D + KaTeX (pas Three.js). Mots‑déclencheurs : géométrie analytique, coniques, ellipse, hyperbole, parabole, droite et coniques, corde focale, longueur de corde, plage de valeurs du produit scalaire, produit scalaire de vecteurs, problème de point fixe, problème de valeur fixe, produit des pentes, extrémum de l’aire d’un triangle, équation du lieu, excentricité, résoudre ce problème de géométrie analytique, générer un problème aléatoire de conique, le problème de géométrie analytique sur cette image ; géométrie analytique, coniques, ellipse, hyperbole, parabole, longueur de corde, plage du produit scalaire, point fixe, valeur fixe, lieu, excentricité, page de solution interactive de géométrie analytique.
