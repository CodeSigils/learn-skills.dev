Навыки популяризации визуального представления науки: превратить любую математическую или научную концепцию (солнечное затмение, лунное затмение, солнечная система, времена года, фазы Луны, приливы, орбиты спутников, тектоника плит, преломление света, радуга, часовые пояса, полярный день и ночь, окислительно‑восстановительные реакции, реакция термита, …) в одностраничный «одинарный интерактивный научно‑популярный HTML». Использовать стиль научного справочника (тёплый офф‑вайтовый фон бумаги + глубокая морская синяя экспериментальная область + красные/янтарные акценты + крупные заголовки в стиле Songti + моноширинные параметры). Основной рабочий процесс: проверка фактов → интуитивная модель → формальное определение → интерактивный эксперимент (ползунок + обратная связь в реальном времени) → уточнение границ → трассировка источников → сборка в один файл → самопроверка доставки. Использовать Three.js (карта импорта CDN) для 3D, HTML Canvas для 2D; каждая тема предоставляет самостоятельный .html, который можно открыть напрямую в браузере. Триггерные слова: визуализация науки, визуальная популяризация, интерактивный научный эксперимент, научная интерактивная демонстрация, превратить XX в интерактивную страницу, создать научно‑популярную страницу как гипотеза GuGu, страница популяризации науки; Ключевые слова тем: солнечное затмение, лунное затмение, приливы, орбита спутника, тектоника плит, преломление света, преломление, полное внутреннее отражение, солнечная система, времена года, фаза Луны, радуга, окислительно‑восстановительные реакции, уравновешивание, химическое уравнение, химическая реакция, реакция термита, сгорание, сжигание полоски магния, магний, Эль‑Ниньо, Ла‑Нинья, ENSO, климат, океанские течения; Английский: interactive science visualization, science experiment page, science popularization page.
