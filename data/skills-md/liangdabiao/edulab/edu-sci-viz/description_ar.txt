مهارات تبسيط التصور العلمي: تحويل أي مفهوم رياضي أو علمي (كسوف، كسوف قمري، نظام الشمس، الفصول، مراحل القمر، المد والجزر، مدارات الأقمار الصناعية، حركة الصفائح، انكسار الضوء، قوس قزح، المناطق الزمنية، النهار/الليل القطبي، تفاعلات الأكسدة والاختزال، تفاعلات الثيرميت، إلخ) إلى صفحة HTML تفاعلية مستقلة من صفحة واحدة. استخدم نمط دليل العلوم التحريري (خلفية بيضاء دافئة + منطقة تجريبية زرقاء داكنة + تظليل أحمر/كهرماني + عناوين كبيرة بنمط سونغ + معلمات بخط أحادي). سير العمل الأساسي: التحقق من الحقيقة → نموذج حدسي → تعريف رسمي → تجربة تفاعلية (شريط تمرير + تغذية راجعة في الوقت الفعلي) → وصف الحدود → تتبع المصدر → تجميع ملف واحد → تسليم ذاتي التحقق. استخدم Three.js (خريطة استيراد CDN) للثلاثية الأبعاد، وHTML Canvas للثنائية الأبعاد؛ يتم تسليم كل موضوع كملف .html مستقل يمكن فتحه مباشرة في المتصفح. كلمات مفتاحية للتفعيل: التصور العلمي، التبسيط البصري، تجربة علمية تفاعلية، عرض تفاعل علمي، تحويل XX إلى صفحة تفاعلية، إنشاء صفحة علمية شعبية مثل فرضية Guagu، صفحة تبسيط علمي؛ كلمات مفتاحية للموضوع: كسوف، كسوف قمر، مد وجزر، مدارات الأقمار الصناعية، حركة الصفائح، انكسار الضوء، الانعكاس الكلي الداخلي، نظام الشمس، الفصول، مراحل القمر، قوس قزح، الأكسدة والاختزال، التوازن، المعادلات الكيميائية، التفاعلات الكيميائية، تفاعل الثيرميت، الاحتراق، احتراق شريط المغنيسيوم، المغنيسيوم، النينيو، اللانيا، ENSO، المناخ، التيارات المحيطية؛ الإنجليزية: تصور علمي تفاعلي، صفحة تجربة علمية، صفحة تبسيط علمي.
