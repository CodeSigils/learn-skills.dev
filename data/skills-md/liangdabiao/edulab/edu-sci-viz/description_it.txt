Abilità di popolarizzazione della visualizzazione scientifica: trasformare qualsiasi concetto matematico o scientifico (eclissi solare, eclissi lunare, sistema solare, stagioni, fasi lunari, maree, orbite dei satelliti, tettonica delle placche, rifrazione della luce, arcobaleni, fusi orari, giorno e notte polari, reazioni redox, reazioni termite, …) in un HTML di divulgazione scientifica interattivo a pagina unica. Utilizzare lo stile del manuale scientifico editoriale (sfondo carta avorio caldo + area sperimentale navy profondo + evidenziature rosse/ambra + intestazioni SimSun grandi + parametri a larghezza fissa). Flusso di lavoro principale: verifica dei fatti → modello intuitivo → definizione formale → esperimento interattivo (slider + feedback in tempo reale) → descrizione dei limiti → tracciamento delle fonti → assemblaggio a file unico → consegna con autoverifica. Usare Three.js (mappa di importazione CDN) per 3D, HTML Canvas per 2D; ogni argomento genera un .html autonomo che può essere aperto direttamente nel browser. Parole chiave di attivazione: visualizzazione scientifica, visualizzazione popolare, esperimento scientifico interattivo, demo scientifica interattiva, trasformare XX in una pagina interattiva, creare una pagina di scienza popolare come la congettura “Gua Gu”, pagina di popolarizzazione scientifica; Parole chiave del soggetto: eclissi solare, eclissi lunare, maree, orbita del satellite, movimento delle placche, rifrazione della luce, rifrazione, riflessione totale interna, sistema solare, stagioni, fasi lunari, arcobaleno, ossidoriduzione, bilanciamento, equazioni chimiche, reazioni chimiche, reazione termite, combustione, striscia di magnesio in fiamma, magnesio, El Niño, La Niña, ENSO, clima, correnti oceaniche; Inglese: visualizzazione scientifica interattiva, pagina di esperimento scientifico, pagina di divulgazione scientifica.
