Gestisce spartan/ui, la libreria Angular UI: aggiunge, compone, corregge, esegue il debug e definisce lo stile dell'interfaccia utente con i livelli Brain (primitivi senza testa) e Helm (con stile). Fornisce il contesto del progetto, le API dei componenti e gli esempi di utilizzo. Si applica quando si lavora con spartan/ui, @spartan-ng/brain, @spartan-ng/helm, i generatori @spartan-ng/cli o qualsiasi progetto Angular con un file Components.json. Si attiva anche per "spartan init", "aggiungi un componente spartan" o "imposta spartan/ui".
