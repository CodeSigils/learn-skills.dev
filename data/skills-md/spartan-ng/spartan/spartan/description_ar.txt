يدير مكتبة spartan/ui، ومكتبة Angular UI - إضافة واجهة مستخدم وتأليفها وإصلاحها وتصحيح الأخطاء وتصميمها باستخدام طبقات Brain (الأوليات مقطوعة الرأس) وطبقات Helm (المصممة). يوفر سياق المشروع وواجهات برمجة التطبيقات للمكونات وأمثلة الاستخدام. ينطبق عند العمل مع spartan/ui، أو @spartan-ng/brain، أو @spartan-ng/helm، أو مولدات @spartan-ng/cli، أو أي مشروع Angular يحتوي على ملف parts.json. مشغلات أيضًا لـ "spartan init" أو "إضافة مكون spartan" أو "إعداد spartan/ui".
