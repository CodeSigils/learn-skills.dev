Administra spartan/ui, la biblioteca de Angular UI: agrega, compone, corrige, depura y diseña la UI con las capas Brain (primitivas sin cabeza) y Helm (con estilo). Proporciona contexto del proyecto, API de componentes y ejemplos de uso. Se aplica cuando se trabaja con spartan/ui, @spartan-ng/brain, @spartan-ng/helm, los generadores @spartan-ng/cli o cualquier proyecto de Angular con un archivo componentes.json. También activadores de "spartan init", "agregar un componente spartan" o "configurar spartan/ui".
