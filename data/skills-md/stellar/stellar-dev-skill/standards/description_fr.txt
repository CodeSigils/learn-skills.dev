Normes, écosystème et référence stellaires. Couvre les SEP (Stellar Ecosystem Proposals), les CAP (Core Advancement Proposals) et une carte rapide pour choisir la bonne norme pour les portefeuilles, les ancres, les paiements, les dépôts/retraits, la fédération, les liens profonds et le KYC. Regroupe également des références d'écosystème (protocoles DeFi, outils de développement, portefeuilles, infrastructures, projets communautaires) et des liens de documentation sélectionnés. À utiliser lorsque vous avez besoin de savoir quel SEP s'applique ou si vous souhaitez un point de départ pour les intégrations d'écosystèmes et les documents officiels.
