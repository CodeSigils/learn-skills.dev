Agenten- und Maschine-zu-Maschine-Zahlungen auf Stellar. Deckt x402 (kostenpflichtige HTTP 402-APIs über OZ Channels Facilitator, gebührenpflichtige Kunden) und MPP (Machine Payments Protocol) sowohl im Gebührenmodus (Soroban SAC pro Anfrage) als auch im Kanalmodus (Off-Chain-Commits, Hochfrequenz) ab. Standardmäßig USDC (SEP-41 SAC) auf „stellar:testnet“/„stellar:pubnet“ (CAIP-2). Verwenden Sie diese Option, wenn Sie eine kostenpflichtige API an KI-Agenten verkaufen, einen x402-Client erstellen oder eine Zahlungskanalarchitektur für hochfrequenten Agentenverkehr entwerfen.
