Агентские и межмашинные платежи на Stellar. Охватывает x402 (платные API-интерфейсы HTTP 402 через посредника каналов OZ, клиентов, спонсируемых комиссией) и MPP (протокол машинных платежей) как в режиме оплаты (Soroban SAC по запросу), так и в режиме канала (фиксации вне цепочки, высокая частота). По умолчанию используется USDC (SEP-41 SAC) в `stellar:testnet`/`stellar:pubnet` (CAIP-2). Используйте при продаже платного API агентам ИИ, создании клиента x402 или разработке архитектуры платежного канала для высокочастотного трафика агентов.
