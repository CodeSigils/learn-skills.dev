Stellar でのエージェントおよびマシン間の支払い。チャージ モード (リクエストごとのそろばん SAC) とチャネル モード (オフチェーン コミット、高頻度) の両方で、x402 (OZ チャネル ファシリテーター、有料クライアントを介した HTTP 402 有料 API) と MPP (マシン ペイメント プロトコル) をカバーします。デフォルトは、`stellar:testnet`/`stellar:pubnet` (CAIP-2) の USDC (SEP-41 SAC) です。 AI エージェントに有料 API を販売する場合、x402 クライアントを構築する場合、または高頻度のエージェント トラフィック用の支払いチャネル アーキテクチャを設計する場合に使用します。
