Applicare e verificare l'aderenza ai nostri principi di progettazione API durante la progettazione, la creazione o
revisione delle API. Utilizza sempre questa competenza per la progettazione di endpoint API, revisioni di contratti o schemi,
controlli di sicurezza e controllo degli accessi, versioning e compatibilità con le versioni precedenti, integrazione
validazione dei confini e osservabilità. Usalo anche quando l'utente non lo richiede esplicitamente
una revisione basata sui principi: qualsiasi discussione sulla progettazione dell'API, revisione del codice che tocca un livello API o
il dialogo sull'architettura che coinvolge i confini del servizio dovrebbe basarsi su questi principi.
Copre: progettazione API, API come prodotto, compatibilità con le versioni precedenti, esperienza del consumatore, sicurezza,
osservabilità, coerenza del tipo, convalida dei confini ed efficienza.
