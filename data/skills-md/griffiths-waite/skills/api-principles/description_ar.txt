قم بتطبيق ومراجعة الالتزام بمبادئ هندسة API الخاصة بنا عند التصميم أو البناء أو
مراجعة واجهات برمجة التطبيقات. استخدم دائمًا هذه المهارة لتصميم نقطة النهاية لواجهة برمجة التطبيقات (API)، أو مراجعات العقد أو المخطط،
فحوصات الأمان والتحكم في الوصول وإصدار الإصدارات والتوافق مع الإصدارات السابقة والتكامل
التحقق من صحة الحدود، وإمكانية الملاحظة. استخدمه حتى عندما لا يطلب المستخدم ذلك صراحةً
مراجعة قائمة على المبادئ - أي مناقشة حول تصميم واجهة برمجة التطبيقات، أو مراجعة التعليمات البرمجية التي تلامس طبقة واجهة برمجة التطبيقات، أو
يجب أن ترتكز محادثة الهندسة المعمارية التي تتضمن حدود الخدمة على هذه المبادئ.

إمكانية الملاحظة، واتساق النوع، والتحقق من الحدود، والكفاءة.
