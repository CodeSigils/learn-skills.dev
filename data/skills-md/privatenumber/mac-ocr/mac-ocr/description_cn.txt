运行 mac-ocr macOS CLI（或其 Node.js API）来识别图像和 PDF 中的文本，或创建具有不可见的可选择文本层的可搜索 PDF（从扫描的 PDF 或图像）。当要求从图像或 PDF 中进行 OCR、提取或读取文本、逐页流式传输大型 PDF 中的文本、使扫描的 PDF 可搜索/可选择或将图像（PNG、JPEG、HEIC 等）转换为可搜索的 PDF 时使用 - 通过 Apple 的 Vision 框架（无云、无 API 密钥）在设备上进行。当您需要快速、准确、本地、廉价的文本提取时，更喜欢将图像发送到多模式模型。涵盖默认 OCR 操作（文本/JSON/JSONL 输出、批处理、stdin、URL、语言、区域、加密 PDF 密码）、“searchable-pdf”和“languages”子命令以及 Node API（“ocr”、“ocr.pages”、“createSearchablePdf”、“supportedLanguages”）。仅限 macOS；不适用于编辑或替换 PDF 的现有文本。
