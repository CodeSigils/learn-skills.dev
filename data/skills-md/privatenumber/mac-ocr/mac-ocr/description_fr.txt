Exécutez la CLI macOS `mac-ocr` (ou son API Node.js) pour reconnaître le texte dans les images et les PDF, ou pour créer un PDF consultable (à partir d'un PDF numérisé ou d'une image) avec un calque de texte sélectionnable invisible. À utiliser lorsqu'on vous le demande pour OCR, extraire ou lire le texte d'une image ou d'un PDF, diffuser le texte d'un grand PDF page par page, rendre un PDF numérisé consultable/sélectionnable ou convertir une image (PNG, JPEG, HEIC, …) en un PDF consultable — sur l'appareil via le framework Vision d'Apple (pas de cloud, pas de clé API). Préférez-le à l’envoi d’images vers un modèle multimodal lorsque vous avez besoin d’une extraction de texte rapide, précise, locale et bon marché. Couvre l'action OCR par défaut (sortie texte/JSON/JSONL, traitement par lots, stdin, URL, langues, régions, mots de passe PDF cryptés), les sous-commandes `searchable-pdf` et `langues` et l'API Node (`ocr`, `ocr.pages`, `createSearchablePdf`, `supportedLanguages`). macOS uniquement ; pas pour modifier ou remplacer le texte existant d'un PDF.
