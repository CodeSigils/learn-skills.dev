Ejecute la CLI de macOS `mac-ocr` (o su API Node.js) para reconocer texto en imágenes y archivos PDF, o para crear un PDF con capacidad de búsqueda (a partir de un PDF escaneado o una imagen) con una capa de texto seleccionable invisible. Úselo cuando se le solicite realizar OCR, extraer o leer texto de una imagen o PDF, transmitir texto de un PDF grande página por página, hacer que un PDF escaneado se pueda buscar/seleccionar o convertir una imagen (PNG, JPEG, HEIC,...) en un PDF con capacidad de búsqueda, en el dispositivo a través del marco Vision de Apple (sin nube, sin clave API). Prefiérelo a enviar imágenes a un modelo multimodal cuando necesite una extracción de texto rápida, precisa, local y económica. Cubre la acción de OCR predeterminada (salida de texto/JSON/JSONL, procesamiento por lotes, estándar, URL, idiomas, regiones, contraseñas de PDF cifrado), los subcomandos `searchable-pdf` e `languages`, y la API de Node (`ocr`, `ocr.pages`, `createSearchablePdf`, `supportedLanguages`). Solo MacOS; no para editar o reemplazar el texto existente de un PDF.
