運行 mac-ocr macOS CLI（或其 Node.js API）來識別圖像和 PDF 中的文本，或創建具有不可見的可選擇文本層的可搜尋 PDF（從掃描的 PDF 或圖像）。當要求從圖像或 PDF 中進行 OCR、提取或讀取文字、逐頁串流大型 PDF 中的文字、使掃描的 PDF 可搜尋/可選擇或將圖像（PNG、JPEG、HEIC 等）轉換為可搜尋的 PDF 時使用 - 透過 Apple 的 Vision 框架（無雲、無 API 金鑰）在裝置上進行。當您需要快速、準確、本地、廉價的文字擷取時，請偏好將圖像傳送到多模式模型。涵蓋預設 OCR 操作（文字/JSON/JSONL 輸出、批次、stdin、URL、語言、區域、加密 PDF 密碼）、「searchable-pdf」和「languages」子指令以及 Node API（「ocr」、「ocr.pages」、「createSearchablePdf」、「supportedLanguages」）。僅限 macOS；不適用於編輯或替換 PDF 的現有文字。
