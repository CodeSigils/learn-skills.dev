'mac-ocr' macOS CLI(또는 해당 Node.js API)를 실행하여 이미지와 PDF의 텍스트를 인식하거나 선택 가능한 보이지 않는 텍스트 레이어가 있는 검색 가능한 PDF(스캔한 PDF 또는 이미지에서)를 생성합니다. Apple의 Vision 프레임워크(클라우드 없음, API 키 없음)를 통해 기기에서 OCR, 이미지 또는 PDF에서 텍스트 추출 또는 읽기, 큰 PDF의 텍스트를 페이지별로 스트리밍, 스캔한 PDF를 검색/선택 가능하게 만들거나 이미지(PNG, JPEG, HEIC 등)를 검색 가능한 PDF로 변환하라는 메시지가 표시될 때 사용합니다. 빠르고 정확하며 로컬이며 저렴한 텍스트 추출이 필요한 경우 이미지를 다중 모달 모델로 보내는 것보다 선호합니다. 기본 OCR 작업(텍스트/JSON/JSONL 출력, 일괄 처리, stdin, URL, 언어, 지역, 암호화된 PDF 비밀번호), `searchable-pdf` 및 `언어` 하위 명령, 노드 API(`ocr`, `ocr.pages`, `createSearchablePdf`, `supportedLanguages`)를 다룹니다. macOS만 해당; PDF의 기존 텍스트를 편집하거나 바꾸는 용도가 아닙니다.
