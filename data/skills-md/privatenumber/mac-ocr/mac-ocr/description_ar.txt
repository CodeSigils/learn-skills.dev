قم بتشغيل `mac-ocr` macOS CLI (أو Node.js API الخاص به) للتعرف على النص في الصور وملفات PDF، أو لإنشاء ملف PDF قابل للبحث (من ملف PDF ممسوح ضوئيًا أو صورة) مع طبقة نص غير مرئية قابلة للتحديد. استخدمه عندما يُطلب منك التعرف الضوئي على الحروف، أو استخراج أو قراءة نص من صورة أو ملف PDF، أو دفق النص من صفحة PDF كبيرة بصفحة، أو جعل ملف PDF ممسوحًا ضوئيًا قابلاً للبحث/التحديد، أو تحويل صورة (PNG، JPEG، HEIC، ...) إلى ملف PDF قابل للبحث - على الجهاز عبر إطار عمل Apple's Vision (بدون سحابة، لا يوجد مفتاح API). تفضل ذلك على إرسال الصور إلى نموذج متعدد الوسائط عندما تحتاج إلى استخراج نص سريع ودقيق ومحلي ورخيص. يغطي إجراء OCR الافتراضي (إخراج النص/JSON/JSONL، والتجميع، وstdin، وعناوين URL، واللغات، والمناطق، وكلمات مرور PDF المشفرة)، والأوامر الفرعية `searchable-pdf` و`languages`، وواجهة برمجة التطبيقات Node (`ocr`، `ocr.pages`، `createSearchablePdf`، `supportedLanguages`). ماك فقط؛ ليس لتحرير أو استبدال النص الموجود في ملف PDF.
