`mac-ocr` macOS CLI (またはその Node.js API) を実行して、画像や PDF 内のテキストを認識したり、非表示の選択可能なテキスト レイヤーを含む検索可能な PDF (スキャンされた PDF または画像から) を作成したりできます。 Apple の Vision フレームワーク (クラウドなし、API キーなし) 経由でデバイス上で、OCR、画像や PDF からのテキストの抽出、読み取り、大きな PDF からページごとのテキストのストリーミング、スキャンされた PDF の検索/選択可能化、または画像 (PNG、JPEG、HEIC など) の検索可能な PDF への変換を要求された場合に使用します。高速、正確、ローカル、安価なテキスト抽出が必要な場合は、マルチモーダル モデルに画像を送信するよりも優先してください。デフォルトの OCR アクション (テキスト/JSON/JSONL 出力、バッチ処理、標準入力、URL、言語、地域、暗号化 PDF パスワード)、`searchable-pdf` および ` languages` サブコマンド、およびノー​​ド API (`ocr`、`ocr.pages`、`createSearchablePdf`、`supportedLanguages`) について説明します。 macOS のみ。 PDF の既存のテキストを編集または置換するためのものではありません。
