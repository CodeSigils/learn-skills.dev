Управление ходом проекта с помощью GitHub Projects. Организуйте задачи в иерархии: Веха → Проблема → Подзадача. Глубина не фиксирована; Подвопросы можно разделить на несколько подвопросов в зависимости от сложности задачи. Отслеживайте активность каждого разработчика. Используйте, когда: (1) создание/управление вехами, (2) создание родительских задач (разделение на основе анализа кодовой базы), (3) создание подзадач (разбиение на конкретные задачи разработки), (4) проверка хода проекта и статус обновления, (5) проверка активности разработчика («Что делает ○○?», «Кто что делает?»), (6) такие ключевые слова, как «создать проблему», «разделить задачи», «отслеживать прогресс», «веха».
