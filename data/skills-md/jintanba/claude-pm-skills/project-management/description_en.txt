Project progress management using GitHub Projects. Organize tasks in a hierarchy of Milestone → Issue → Sub-issue. The depth is not fixed; Sub-issues can be further split into more Sub-issues depending on task complexity. Track each developer’s activity. Use when: (1) creating/managing milestones, (2) creating parent Issues (split based on codebase analysis), (3) creating Sub-issues (breaking into concrete dev tasks), (4) checking project progress and updating status, (5) checking developer activity (“What is ○○ doing?”, “Who is doing what?”), (6) keywords like “create an Issue,” “split tasks,” “track progress,” “milestone.”
