Project progress management using GitHub Projects. Organize tasks in a hierarchy of Milestone → Issue → Sub-issue. The depth is not fixed; Sub-issues can be further split into more Sub-issues according to task complexity. Also track each developer’s activity. Usage timing: (1) Creating and managing milestones (2) Creating parent Issues (split based on codebase analysis) (3) Creating Sub-issues (breaking down into concrete development tasks) (4) Checking project progress and updating status (5) Checking developer activity (“What is ○○ doing?” “Who is doing what?”) (6) Keywords like “create an Issue,” “split tasks,” “track progress,” “milestone.”
