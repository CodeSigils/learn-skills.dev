GitHub 프로젝트를 사용한 프로젝트 진행 관리. Milestone → Issue → Sub-issue 계층으로 작업을 정리합니다. 계층 구조의 깊이를 고정하지 마십시오. 하위 이슈는 작업 복잡성에 따라 하위 이슈로 더 나눌 수 있습니다. 또한 각 개발자의 활동을 추적합니다.

사용 시기:  
(1) 마일스톤 생성 및 관리  
(2) 상위 이슈 생성(코드베이스 분석을 기반으로 분할)  
(3) 하위 이슈 생성(구체적인 개발 작업으로 세분화)  
(4) 프로젝트 진행상황 확인 및 업데이트 현황  
(5) 개발자 활동 확인(“○○은 무엇을 하고 있나요?”, “누가 무엇을 하고 있나요?”)  
(6) 키워드: "이슈 생성", "작업 분할", "진행 상황 추적", "마일스톤"
