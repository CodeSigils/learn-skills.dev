GitHub 프로젝트를 사용한 프로젝트 진행 관리. Milestone → Issue → Sub-issue 계층으로 작업을 정리합니다. 깊이는 고정되어 있지 않습니다. 하위 문제는 작업 복잡성에 따라 더 많은 하위 문제로 분할될 수 있습니다. 각 개발자의 활동을 추적하세요. 다음의 경우에 사용하세요: (1) 마일스톤 생성/관리, (2) 상위 이슈 생성(코드베이스 분석을 기반으로 분할), (3) 하위 이슈 생성(구체적인 개발 작업 분할), (4) 프로젝트 진행 상황 및 상태 업데이트 확인, (5) 개발자 활동 확인(“○○은 무엇을 하고 있나요?”, “누가 무엇을 하고 있나요?”), (6) “이슈 생성”, “작업 분할”, “진행 상황 추적”, “마일스톤”과 같은 키워드.
