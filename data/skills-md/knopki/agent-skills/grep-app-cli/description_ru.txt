Выполняйте поиск общедоступного кода GitHub с помощью интерфейса командной строки grep.app MCP, чтобы найти реальные шаблоны реализации, конкретное использование API, совпадения кода на основе регулярных выражений и примеры на уровне репозитория. Используйте, когда задача требует буквального поиска кода, а не поиска документации, особенно для проверки того, как библиотеки, платформы, файлы конфигурации или языковые функции используются в реальных проектах.
