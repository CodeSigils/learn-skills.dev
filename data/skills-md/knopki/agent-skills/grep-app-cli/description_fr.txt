Recherchez du code GitHub public avec la CLI grep.app MCP pour trouver de véritables modèles d'implémentation, une utilisation concrète de l'API, des correspondances de code basées sur les expressions régulières et des exemples à l'échelle du référentiel. À utiliser lorsqu'une tâche nécessite une recherche littérale de code plutôt qu'une recherche de documentation, en particulier pour vérifier comment les bibliothèques, les frameworks, les fichiers de configuration ou les fonctionnalités du langage sont utilisés dans des projets réels.
