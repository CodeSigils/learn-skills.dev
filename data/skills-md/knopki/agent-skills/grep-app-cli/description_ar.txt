ابحث عن كود GitHub العام باستخدام grep.app MCP CLI للعثور على أنماط التنفيذ الحقيقية، واستخدام واجهة برمجة التطبيقات الملموسة، ومطابقات التعليمات البرمجية المستندة إلى regex، والأمثلة على مستوى المستودع. يُستخدم عندما تحتاج المهمة إلى بحث حرفي عن التعليمات البرمجية بدلاً من البحث عن الوثائق، خاصة للتحقق من كيفية استخدام المكتبات أو أطر العمل أو ملفات التكوين أو ميزات اللغة في المشاريع الحقيقية.
