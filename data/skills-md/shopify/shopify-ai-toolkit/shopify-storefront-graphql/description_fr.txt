À utiliser pour les vitrines personnalisées nécessitant des requêtes/mutations directes GraphQL pour la récupération de données et les opérations de panier. Choisissez cette option lorsque vous avez besoin d'un contrôle total sur la récupération des données et le rendu de votre propre interface utilisateur. PAS pour les composants Web - si l'invite mentionne des balises HTML telles que <shopify-store>, <shopify-cart>, utilisez plutôt storefront-web-components.
