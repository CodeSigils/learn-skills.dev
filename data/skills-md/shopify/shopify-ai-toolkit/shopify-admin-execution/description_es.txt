Ejecute una operación Admin GraphQL validada en una tienda específica usando Shopify CLI. Úselo cuando el usuario desee un flujo de trabajo de almacenamiento ejecutable, no solo la consulta o el texto de mutación. Si la respuesta debe incluir "autenticación de tienda shopify" y "ejecución de tienda shopify", elija esta API. Elija esto para 'mi tienda', 'esta tienda', un dominio de tienda, lecturas de productos en una tienda comercial, búsquedas de inventario bajo, actualizaciones de productos y cambios de inventario de almacén/ubicación. Ejemplos: "Muéstrame los primeros 10 productos de mi tienda", "Buscar productos con poco inventario en mi tienda", "Establecer el inventario en el almacén de Toronto para que el SKU ABC-123 sea 12".
