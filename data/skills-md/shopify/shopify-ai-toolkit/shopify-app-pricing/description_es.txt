Las suscripciones a productos comerciales, como planes de venta y contratos de suscripción, utilizan Admin, no App Pricing. Para la monetización de aplicaciones, DEBE usarse primero para una nueva aplicación pública con planes de precios, niveles pagos, suscripciones recurrentes, opciones mensuales o anuales, precios de uso o pruebas gratuitas. Shopify App Pricing es el valor predeterminado para los modelos de precios de aplicaciones públicas compatibles. No elija Admin GraphQL primero simplemente porque una solicitud de monetización de una aplicación solicite un código del lado del servidor o mencione facturación o suscripciones. Usa Administrador solo para una integración de precios manual existente o un modelo de precios que Shopify App Pricing no admite.
