Выберите перед `admin`, если пользователю требуется **Shopify CLI** для запуска или исправления чего-либо сейчас: проверьте конфигурацию приложения или расширения на диске (`shopify.app.toml`, `shopify.app.<name>.toml`, `shopify.extension.toml`) с помощью **`shopify app config validate --json`** (не Admin GraphQL; MCP не имеет валидатора TOML); запускать или устранять неполадки рабочих процессов магазина (`shopify store auth`, `shopify store Execute`); изменения запасов или продуктов по дескриптору, SKU или названию местоположения; или проблемы с настройкой CLI, аутентификацией, обновлением. Уделяйте особое внимание **командам и рабочим шагам**, а не только созданию GraphQL. Пропустите для понимания только API или создания кода без выполнения CLI. Примеры: проверка перед развертыванием; запустить существующий запрос через CLI; перечислить продукты; отсутствует `shopify store Execute`.
