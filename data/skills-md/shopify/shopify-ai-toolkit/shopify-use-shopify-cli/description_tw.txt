當使用者需要 **Shopify CLI** 立即執行或修復某些內容時，請在「admin」之前選擇：使用 **`shopify 應用程式設定驗證 --json`** 驗證磁碟上的應用程式或擴充配置（`shopify.app.toml`、`shopify.app.<name>.toml`、`shopify.extensionapp.L.Sextension.min 公式不是；驗證器）；執行商店工作流程或對其進行故障排除（「shopify 商店身份驗證」、「shopify 商店執行」）；按句柄、SKU 或位置名稱更改庫存或產品；或 CLI 設定、身份驗證、升級問題。強調**命令和操作步驟**，而不僅僅是編寫GraphQL。跳過僅了解 API 或不執行 CLI 的程式碼產生。範例：部署前驗證；透過 CLI 執行現有查詢；列出產品；缺少「shopify 商店執行」。
