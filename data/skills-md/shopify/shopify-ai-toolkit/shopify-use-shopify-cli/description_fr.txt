Choisissez avant « admin » lorsque l'utilisateur a besoin de **Shopify CLI** pour exécuter ou réparer quelque chose maintenant : validez la configuration de l'application ou de l'extension sur le disque (`shopify.app.toml`, `shopify.app.<name>.toml`, `shopify.extension.toml`) avec **`shopify app config validate --json`** (pas Admin GraphQL ; MCP n'a pas de validateur TOML) ; exécuter ou dépanner les workflows du magasin (« shopify store auth », « shopify store perform » ); modifications de l'inventaire ou du produit par poignée, SKU ou nom d'emplacement ; ou configuration CLI, authentification, problèmes de mise à niveau. Insistez sur les **commandes et étapes opérationnelles**, et pas seulement sur la création de GraphQL. Ignorez la compréhension de l'API uniquement ou du codegen sans exécution CLI. Exemples : valider avant de déployer ; exécuter une requête existante via CLI ; lister les produits ; il manque « exécution du magasin Shopify ».
