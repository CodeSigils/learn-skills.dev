اختر قبل "admin" عندما يحتاج المستخدم إلى **Shopify CLI** لتشغيل أو إصلاح شيء ما الآن: التحقق من صحة تكوين التطبيق أو الامتداد على القرص (`shopify.app.toml`, `shopify.app.<name>.toml`, `shopify.extension.toml`) مع **`shopify app config validate --json`** (ليس Admin GraphQL؛ MCP ليس لديه مدقق TOML)؛ تشغيل سير عمل المتجر أو استكشاف أخطاءه وإصلاحها (`مصادقة متجر Shopify`، `تنفيذ متجر Shopify`)؛ تغييرات المخزون أو المنتج حسب المقبض أو SKU أو اسم الموقع؛ أو مشكلات إعداد CLI أو المصادقة أو الترقية. أكد على **الأوامر والخطوات التشغيلية**، وليس فقط تأليف GraphQL. انتقل إلى فهم واجهة برمجة التطبيقات (API) فقط أو إنشاء التعليمات البرمجية بدون تنفيذ واجهة سطر الأوامر (CLI). أمثلة: التحقق من الصحة قبل النشر؛ تشغيل استعلام موجود عبر سطر الأوامر؛ قائمة المنتجات؛ مفقود `تنفيذ متجر Shopify`.
