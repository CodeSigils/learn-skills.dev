Elija antes de `admin` cuando el usuario necesite **Shopify CLI** para ejecutar o arreglar algo ahora: validar la configuración de la aplicación o extensión en el disco (`shopify.app.toml`, `shopify.app.<nombre>.toml`, `shopify.extension.toml`) con **`shopify app config validar --json`** (no Admin GraphQL; MCP no tiene validador TOML); ejecutar o solucionar problemas de flujos de trabajo de la tienda (`shopify store auth`, `shopify store run`); cambios de inventario o producto por identificador, SKU o nombre de ubicación; o problemas de configuración, autenticación y actualización de CLI. Enfatice **comandos y pasos operativos**, no solo la creación de GraphQL. Omita para comprender solo API o generar código sin ejecución de CLI. Ejemplos: validar antes de implementar; ejecutar una consulta existente a través de CLI; enumerar productos; Falta "ejecución de tienda Shopify".
