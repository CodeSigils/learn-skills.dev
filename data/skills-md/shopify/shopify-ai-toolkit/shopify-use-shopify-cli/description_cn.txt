当用户需要 **Shopify CLI** 立即运行或修复某些内容时，请在“admin”之前选择：使用 **`shopify 应用程序配置验证 --json`** 验证磁盘上的应用程序或扩展配置（`shopify.app.toml`、`shopify.app.<name>.toml`、`shopify.extension.toml`）（不是 Admin GraphQL；MCP 没有 TOML 验证器）；运行商店工作流程或对其进行故障排除（“shopify 商店身份验证”、“shopify 商店执行”）；按句柄、SKU 或位置名称更改库存或产品；或 CLI 设置、身份验证、升级问题。强调**命令和操作步骤**，而不仅仅是编写GraphQL。跳过仅了解 API 或不执行 CLI 的代码生成。示例：部署前验证；通过 CLI 运行现有查询；列出产品；缺少“shopify 商店执行”。
