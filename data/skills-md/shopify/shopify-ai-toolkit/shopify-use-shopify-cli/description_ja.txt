ユーザーが今すぐ何かを実行または修正するために **Shopify CLI** を必要とする場合は、「admin」の前を選択します。 **`shopify app config validate --json`** を使用して、ディスク上のアプリまたは拡張機能の構成 (`shopify.app.toml`、`shopify.app.<name>.toml`、`shopify.extension.toml`) を検証します (Admin GraphQL ではありません。MCP には TOML バリデーターがありません)。ストアワークフローの実行またはトラブルシューティング (「shopify ストア認証」、「shopify ストア実行」)。ハンドル、SKU、または場所名による在庫または製品の変更。または CLI のセットアップ、認証、アップグレードの問題。 GraphQL の作成だけでなく、**コマンドと操作手順**を強調します。 API のみを理解する場合、または CLI を実行しないコード生成についてはスキップしてください。例: デプロイ前に検証します。 CLI 経由で既存のクエリを実行します。製品をリストアップします。 「shopify ストアの実行」がありません。
