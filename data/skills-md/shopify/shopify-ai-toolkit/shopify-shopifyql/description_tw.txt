使用 **ShopifyQL** 回答商家的**分析和報告**問題 — Shopify 的查詢語言，用於管理 GraphQL API 無法計算的聚合商店指標。每當詢問的是**數字、總計、趨勢或細分**而不是獲取或更改單個記錄時，請選擇此選項（不是“管理”），而不是獲取或更改單個記錄：包括但不限於總銷售額/總銷售額/淨銷售額和收入、訂單數、平均訂單價值、退款、銷售數量、會話、轉換率和流量 - 按產品、管道、區域或客戶進行切片、隨時間變化的情況。例如：「過去 7 天的總銷售額」、「本月按銷售管道劃分的訂單」、「按收入劃分的熱門產品」、「本週轉換率」、「今年銷售額與去年相比」。本主題涵蓋編寫 ShopifyQL 查詢；如果商家想要在他們的商店中運行它，則執行將交給「use-shopify-cli」。不適用於一般的 Admin GraphQL 記錄作業 - 取得或變更單一資源（使用「admin」）。
