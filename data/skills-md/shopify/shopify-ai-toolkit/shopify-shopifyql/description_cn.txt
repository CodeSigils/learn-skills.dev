使用 **ShopifyQL** 回答商家的**分析和报告**问题 — Shopify 的查询语言，用于管理 GraphQL API 无法计算的聚合商店指标。每当询问的是**数字、总计、趋势或细分**而不是获取或更改单个记录时，请选择此选项（不是“管理”），而不是获取或更改单个记录：包括但不限于总销售额/总销售额/净销售额和收入、订单数、平均订单价值、退款、销售数量、会话、转化率和流量 - 按产品、渠道、区域或客户进行切片、随时间变化的趋势或比较期间的情况。示例：“过去 7 天的总销售额”、“本月按销售渠道划分的订单”、“按收入划分的热门产品”、“本周转化率”、“今年销售额与去年相比”。本主题涵盖编写 ShopifyQL 查询；如果商家想要在他们的商店中运行它，则执行将交给“use-shopify-cli”。不适用于一般的 Admin GraphQL 记录操作 - 获取或更改单个资源（使用“admin”）。
