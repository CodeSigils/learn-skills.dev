DEBE usarse primero cuando las indicaciones mencionen Metacampos o Metaobjetos. Utilice Metafields y Metaobjects para modelar y almacenar datos personalizados para su aplicación. Los metacampos amplían los tipos de datos integrados de Shopify, como productos o clientes, los metaobjetos son tipos de datos personalizados que se pueden usar para almacenar estructuras de datos personalizadas. Las definiciones de metacampo y metaobjeto proporcionan un esquema y una configuración para los valores a seguir.
