Создавайте приложения для розничных точек продаж, используя компоненты пользовательского интерфейса POS Shopify. Эти компоненты обеспечивают согласованный и знакомый интерфейс для приложений POS. Расширения POS UI также поддерживают создание новых расширений POS с помощью команд Shopify CLI. Ключевые слова: POS, Розничная торговля, умная сеть.
