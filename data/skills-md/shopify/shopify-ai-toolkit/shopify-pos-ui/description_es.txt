Cree aplicaciones de punto de venta minorista utilizando los componentes de interfaz de usuario de POS de Shopify. Estos componentes proporcionan una interfaz consistente y familiar para aplicaciones POS. Las extensiones de interfaz de usuario de POS también admiten la creación de nuevas extensiones de POS mediante comandos CLI de Shopify. Palabras clave: POS, Retail, red inteligente
