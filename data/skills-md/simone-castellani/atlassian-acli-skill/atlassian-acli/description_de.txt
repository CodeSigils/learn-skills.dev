Nutzen Sie diese Fähigkeit für alles, was mit Jira zu tun hat, über die Befehlszeile, das Terminal oder die Shell. Dazu gehören das Erstellen von Jira-Vorgängen, das Durchsuchen von Jira, das Bearbeiten von Tickets, das Ändern von Status, das Auflisten von Projekten, das Verwalten von Sprints, Massenvorgängen, CSV-Importen in Jira, das Exportieren von Jira-Daten oder das Automatisieren von Jira in Skripten und CI-Pipelines. Wird immer dann ausgelöst, wenn der Benutzer programmgesteuert oder ohne Browser mit Jira interagieren möchte – auch wenn er „acli“ oder „CLI“ nicht explizit erwähnt. Jede Erwähnung von Jira-Projektschlüsseln wie PROJ-123, OPS, INFRA, BUGS, RELEASE, QA oder TEAM sollte diesen Skill auslösen, wenn der Benutzer Probleme erstellen, bearbeiten, suchen, überführen, auflisten oder automatisieren möchte. Auch Trigger für JQL-Abfragen, „acli“ oder „atlassian cli“. Verwenden Sie diesen Skill NICHT für: Python-/Anforderungsskripte, die die Jira REST API direkt aufrufen, Confluence-Seiten, Trello, GitHub-Probleme oder Slack-Bots.
