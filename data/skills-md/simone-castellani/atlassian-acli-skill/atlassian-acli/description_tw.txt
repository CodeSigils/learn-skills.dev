透過命令列、終端或 shell 對涉及 Jira 的任何內容使用此技能。這包括建立 Jira 問題、搜尋 Jira、編輯票證、更改狀態、列出項目、管理衝刺、批次操作、將 CSV 匯入 Jira、匯出 Jira 資料或在腳本和 CI 管道中自動化 Jira。每當用戶想要以程式設計方式或不使用瀏覽器與 Jira 互動時觸發 - 即使他們沒有明確提及「acli」或「CLI」。如果使用者想要建立、編輯、搜尋、轉換、列出或自動化問題，任何提及 Jira 項目鍵（例如 PROJ-123、OPS、INFRA、BUGS、RELEASE、QA 或 TEAM）都應該觸發此技能。也觸發 JQL 查詢、「acli」或「atlassian cli」。請勿將此技能用於：直接呼叫 Jira REST API 的 Python/請求腳本、Confluence 頁面、Trello、GitHub Issues 或 Slack 機器人。
