通过命令行、终端或 shell 对涉及 Jira 的任何内容使用此技能。这包括创建 Jira 问题、搜索 Jira、编辑票证、更改状态、列出项目、管理冲刺、批量操作、将 CSV 导入 Jira、导出 Jira 数据或在脚本和 CI 管道中自动化 Jira。每当用户想要以编程方式或不使用浏览器与 Jira 交互时触发 - 即使他们没有明确提及“acli”或“CLI”。如果用户想要创建、编辑、搜索、转换、列出或自动化问题，任何提及 Jira 项目键（例如 PROJ-123、OPS、INFRA、BUGS、RELEASE、QA 或 TEAM）都应该触发此技能。还触发 JQL 查询、“acli”或“atlassian cli”。请勿将此技能用于：直接调用 Jira REST API 的 Python/请求脚本、Confluence 页面、Trello、GitHub Issues 或 Slack 机器人。
