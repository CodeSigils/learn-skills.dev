Usa questa abilità per qualsiasi cosa coinvolga Jira dalla riga di comando, dal terminale o dalla shell. Ciò include la creazione di problemi Jira, la ricerca in Jira, la modifica di ticket, la modifica degli stati, l'elenco di progetti, la gestione di sprint, operazioni in blocco, importazioni CSV in Jira, esportazione di dati Jira o automazione di Jira in script e pipeline CI. Si attiva ogni volta che l'utente desidera interagire con Jira a livello di codice o senza un browser, anche se non menziona esplicitamente "acli" o "CLI". Qualsiasi menzione delle chiavi del progetto Jira come PROJ-123, OPS, INFRA, BUGS, RELEASE, QA o TEAM dovrebbe attivare questa abilità se l'utente desidera creare, modificare, cercare, eseguire la transizione, elencare o automatizzare i problemi. Attiva anche query JQL, "acli" o "atlassian cli". NON utilizzare questa competenza per: script Python/richieste che chiamano direttamente l'API REST Jira, pagine Confluence, Trello, problemi di GitHub o bot Slack.
