استخدم هذه المهارة لأي شيء يتضمن Jira من سطر الأوامر أو الوحدة الطرفية أو الصدفة. يتضمن ذلك إنشاء مشكلات Jira، أو البحث في Jira، أو تحرير التذاكر، أو تغيير الحالات، أو إدراج المشاريع، أو إدارة الدورات السريعة، أو العمليات المجمعة، أو استيراد ملف CSV إلى Jira، أو تصدير بيانات Jira، أو أتمتة Jira في البرامج النصية وخطوط أنابيب CI. يتم تشغيله عندما يريد المستخدم التفاعل مع Jira برمجيًا أو بدون متصفح - حتى لو لم يذكر "acli" أو "CLI" صراحة. أي ذكر لمفاتيح مشروع Jira مثل PROJ-123 أو OPS أو INFRA أو BUGS أو RELEASE أو QA أو TEAM يجب أن يؤدي إلى تشغيل هذه المهارة إذا أراد المستخدم إنشاء المشكلات أو تحريرها أو البحث فيها أو نقلها أو إدراجها أو تشغيلها تلقائيًا. يمكنك أيضًا تشغيل استعلامات JQL أو "acli" أو "atlassian cli". لا تستخدم هذه المهارة من أجل: Python/طلبات البرامج النصية التي تستدعي Jira REST API مباشرةً، أو صفحات Confluence، أو Trello، أو مشكلات GitHub، أو برامج Slack bots.
