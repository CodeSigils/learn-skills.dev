Utilice esta habilidad para cualquier cosa que involucre a Jira desde la línea de comando, terminal o shell. This includes creating Jira issues, searching Jira, editing tickets, changing statuses, listing projects, managing sprints, bulk operations, CSV imports to Jira, exporting Jira data, or automating Jira in scripts and CI pipelines. Trigger whenever the user wants to interact with Jira programmatically or without a browser — even if they don't mention "acli" or "CLI" explicitly. Any mention of Jira project keys like PROJ-123, OPS, INFRA, BUGS, RELEASE, QA, or TEAM should trigger this skill if the user wants to create, edit, search, transition, list, or automate issues. También activa consultas JQL, "acli" o "atlassian cli". NO utilice esta habilidad para: scripts de Python/solicitudes que llamen directamente a la API REST de Jira, páginas de Confluence, Trello, problemas de GitHub o bots de Slack.
