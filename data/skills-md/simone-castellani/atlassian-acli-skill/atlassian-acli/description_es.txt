Utilice esta habilidad para cualquier cosa que involucre a Jira desde la línea de comando, terminal o shell. Esto incluye crear problemas de Jira, buscar en Jira, editar tickets, cambiar estados, enumerar proyectos, administrar sprints, operaciones masivas, importar CSV a Jira, exportar datos de Jira o automatizar Jira en scripts y canalizaciones de CI. Se activa cada vez que el usuario quiere interactuar con Jira mediante programación o sin un navegador, incluso si no menciona "acli" o "CLI" explícitamente. Cualquier mención de las claves del proyecto Jira como PROJ-123, OPS, INFRA, BUGS, RELEASE, QA o TEAM debería activar esta habilidad si el usuario desea crear, editar, buscar, realizar transiciones, enumerar o automatizar problemas. También activa consultas JQL, "acli" o "atlassian cli". NO utilice esta habilidad para: scripts de Python/solicitudes que llamen directamente a la API REST de Jira, páginas de Confluence, Trello, problemas de GitHub o bots de Slack.
