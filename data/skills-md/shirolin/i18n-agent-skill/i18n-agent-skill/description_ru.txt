Предназначен для инженерных задач интернационализации интерфейса (i18n). Основные сильные стороны: извлечение на уровне синтаксиса на основе Tree-sitter AST, 100% физически изолированные комментарии, поддержка вложенных литералов шаблонов и текстовых узлов JSX/Vue. Идеально подходит для полного аудита, точного извлечения, автоматической синхронизации и проверки стандартов макета.
