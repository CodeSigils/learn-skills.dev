Leitfaden für die Arbeit mit Microsoft Fabric IQ (Vorschau), dem semantischen Intelligenz-Workload für einheitliche Daten und Geschäftsvokabular. Zum Erstellen oder Verwalten von Ontologieelementen, zum Definieren von Entitätstypen, zum Binden von Daten an Ontologien, zum Erstellen von Beziehungstypen, zum Konfigurieren von Datenagenten mit Ontologiequellen, zum Arbeiten mit Graph in Microsoft Fabric, zum Verwalten von Fabric IQ-Mandanteneinstellungen, zum Abfragen von Ontologiediagrammen, zum Generieren von Ontologien aus Power BI-Semantikmodellen oder zum Korrigieren von Fabric IQ-Vorschaufunktionen. Deckt Ontologie, Diagramm, Datenagenten, Betriebsagenten und semantische Modellelemente ab.
