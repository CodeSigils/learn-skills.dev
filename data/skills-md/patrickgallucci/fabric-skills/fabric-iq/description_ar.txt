دليل للعمل مع Microsoft Fabric IQ (معاينة)، وعبء عمل الذكاء الدلالي للبيانات الموحدة ومفردات الأعمال. يُستخدم عند إنشاء عناصر علم الوجود أو إدارتها، أو تعريف أنواع الكيانات، أو ربط البيانات بالوجودات، أو إنشاء أنواع العلاقات، أو تكوين وكلاء البيانات بمصادر الوجود، أو العمل مع Graph في Microsoft Fabric، أو إدارة إعدادات مستأجر Fabric IQ، أو الاستعلام عن الرسوم البيانية الوجودية، أو إنشاء أنطولوجيات من النماذج الدلالية Power BI، أو معالجة ميزات معاينة Fabric IQ. يغطي علم الوجود، الرسم البياني، وكيل البيانات، وكيل العمليات، وعناصر النموذج الدلالي.
