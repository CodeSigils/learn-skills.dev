Guida per lavorare con Microsoft Fabric IQ (anteprima), il carico di lavoro di intelligenza semantica per dati unificati e vocabolario aziendale. Utilizzare durante la creazione o la gestione di elementi di ontologia, la definizione di tipi di entità, l'associazione di dati a ontologie, la creazione di tipi di relazione, la configurazione di agenti dati con origini ontologiche, l'utilizzo di Graph in Microsoft Fabric, la gestione delle impostazioni del tenant di Fabric IQ, l'esecuzione di query su grafici di ontologia, la generazione di ontologie da modelli semantici di Power BI o la correzione delle funzionalità di anteprima di Fabric IQ. Copre ontologia, grafico, agente dati, agente operativo e elementi del modello semantico.
