Guía para trabajar con Microsoft Fabric IQ (versión preliminar), la carga de trabajo de inteligencia semántica para datos unificados y vocabulario empresarial. Úselo al crear o administrar elementos de ontología, definir tipos de entidades, vincular datos a ontologías, crear tipos de relaciones, configurar agentes de datos con orígenes de ontologías, trabajar con Graph en Microsoft Fabric, administrar la configuración de inquilinos de Fabric IQ, consultar gráficos de ontologías, generar ontologías a partir de modelos semánticos de Power BI o corregir características de vista previa de Fabric IQ. Cubre elementos de ontología, gráficos, agente de datos, agente de operaciones y modelo semántico.
