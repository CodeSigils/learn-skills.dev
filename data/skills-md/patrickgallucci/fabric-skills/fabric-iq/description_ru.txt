Руководство по работе с Microsoft Fabric IQ (предварительная версия), рабочей нагрузкой семантического анализа для унифицированных данных и бизнес-лексики. Используйте при создании или управлении элементами онтологии, определении типов сущностей, привязке данных к онтологиям, создании типов отношений, настройке агентов данных с источниками онтологий, работе с Graph в Microsoft Fabric, управлении настройками клиента Fabric IQ, запросе графиков онтологий, создании онтологий из семантических моделей Power BI или исправлении функций предварительного просмотра Fabric IQ. Охватывает онтологию, граф, агент данных, агент операций и элементы семантической модели.
