Esamina un repository e proponi o applica GitHub Informazioni sugli aggiornamenti dei metadati. Da utilizzare quando Codex deve dedurre una descrizione concisa del repository e un set di argomenti dal codice sorgente, dai metadati del pacchetto, dalla configurazione dei documenti o dal file README corrente, quindi visualizzare in anteprima ed eventualmente eseguire `gh repo edit`.
