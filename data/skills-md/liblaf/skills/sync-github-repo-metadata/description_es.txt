Inspeccionar un repositorio y proponer o aplicar actualizaciones de metadatos de GitHub Acerca de. Úselo cuando Codex necesite inferir una descripción concisa del repositorio y un conjunto de temas a partir del código fuente, metadatos del paquete, configuración de documentos o el archivo README actual, luego obtenga una vista previa y, opcionalmente, ejecute `gh repo edit`.
