Ejecute secuencialmente comandos de noticias opencli configurables, omita comandos fallidos, normalice historias JSON y deduplica globalmente por URL antes de producir noticias recientes diarias y resúmenes de rebajas de noticias recientes por ejecución. Úselo cuando el usuario desee una agregación repetible de noticias de múltiples fuentes con comandos fáciles de agregar/eliminar a través de commands.json y requiera una traducción controlada por el modelo (sin API de traducción de terceros).
