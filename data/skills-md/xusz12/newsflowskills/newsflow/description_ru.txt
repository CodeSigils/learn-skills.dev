Последовательно запускайте настраиваемые команды новостей opencli, пропускайте неудачные команды, нормализуйте истории JSON и глобально дедуплицируйте по URL-адресу перед созданием ежедневных свежих новостей и дайджестов с уценкой свежих новостей для каждого запуска. Используйте, когда пользователю нужна повторяемая агрегация новостей из нескольких источников с простым добавлением/удалением команд через команды.json и требуется перевод, управляемый моделью (без стороннего API перевода).
