Verwenden Sie diese Option, wenn der Benutzer sich informieren, ein neues Repository verstehen, die Architektur verstehen, eine Funktion oder ein Verhalten nachverfolgen, lokale Konventionen lernen, aktuelle Commits der letzten Tage überprüfen, sich auf ein Rebase vorbereiten oder Code verstehen möchte, bevor er plant, bearbeitet, überprüft oder debuggt.
