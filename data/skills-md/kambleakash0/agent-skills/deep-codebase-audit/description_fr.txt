Trouvez des opportunités d'approfondissement dans une base de code, faites ressortir les frictions architecturales et proposez des refactors qui transforment les modules superficiels en modules profonds. À utiliser lorsque l'utilisateur souhaite améliorer l'architecture, rendre une base de code plus testable, consolider des modules étroitement couplés ou rendre plus sûre la navigation et les modifications des agents d'IA.
