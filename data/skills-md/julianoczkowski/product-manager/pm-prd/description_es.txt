Reúna un documento de requisitos de producto (PRD) completo e impulsado por el mercado de manera pragmática: el problema antes que la solución, basado en evidencia y primero la persona. Úselo cuando el PM solicite un PRD, especificaciones de producto, documento de características, "escriba el documento de requisitos" o "reúna todo para el equipo". Incorpora personas existentes, posicionamiento, problemas de mercado, requisitos y escenarios de uso, si están presentes, y reúne todo lo que falta en línea. Produce un documento de requisitos del producto como un artefacto Markdown o Word .docx.
