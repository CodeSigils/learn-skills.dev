قم ببناء خطة تواصل عملية مع أصحاب المصلحة وتحديثات الحالة التي تكشف المخاطر مبكرًا وتتحدث لغة كل جمهور. يُستخدم عندما يطلب مدير المشروع إدارة أصحاب المصلحة، أو التخطيط للاتصالات، أو كتابة تحديث الحالة/التنفيذي، أو تقرير حالة المشروع، أو تحديث اللجنة التوجيهية، أو "الحفاظ على توافق الجميع". يغطي تحديد → تحليل → خطوات التواصل، ومصفوفة التأثير × الأهمية، والفئات المترية الأربع. إنتاج خطة تواصل مع أصحاب المصلحة وتحديث الحالة كأداة Markdown أو Word .docx.
