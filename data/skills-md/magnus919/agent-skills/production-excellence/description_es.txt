Genere evidencia de producción entre dominios desde la preparación, la migración, la recuperación, la capacidad/costo y el aprendizaje de incidentes hasta las decisiones operativas o de lanzamiento. No uses esta habilidad para el paquete de riesgo y la puerta de lanzamiento de un solo especialista; utilice "preparación para la producción" para esa revisión de preparación.
