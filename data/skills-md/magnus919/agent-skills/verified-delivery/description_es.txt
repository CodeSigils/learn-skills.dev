Implemente y entregue un cambio autorizado de principio a fin (verifique, abra el PR, fusione y confirme el estado posterior a la fusión) utilizando puertas de estado activo, transferencias de interrupción duraderas y reanudación primero del estado activo. Úselo cuando un usuario otorga autoridad de entrega de un extremo a otro para un cambio específico y el trabajo puede cruzar los límites de llamadas de herramientas, el agotamiento del contexto, la pérdida de trabajadores o las interrupciones de sesión antes de que se alcance el límite de entrega. No lo use para correcciones simples sin directiva de entrega, para otorgar autoridad de fusión o posterior a la fusión que el usuario no otorgó, o para diseñar canales de lanzamiento (use ingeniería de lanzamiento para eso).
