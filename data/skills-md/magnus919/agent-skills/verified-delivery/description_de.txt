Implementieren und liefern Sie eine autorisierte Änderung durchgängig – überprüfen, PR öffnen, zusammenführen und Post-Merge-Status bestätigen – mithilfe von Live-State-Gates, dauerhaften Unterbrechungsübergaben und Live-State-First-Wiederaufnahme. Verwenden Sie diese Option, wenn ein Benutzer eine End-to-End-Bereitstellungsberechtigung für eine bestimmte Änderung erteilt und die Arbeit möglicherweise Tool-Call-Limits, Kontexterschöpfung, Worker-Verlust oder Sitzungsunterbrechungen überschreitet, bevor die Bereitstellungsgrenze erreicht wird. Nicht für einfache Korrekturen ohne Lieferanweisung, für die Gewährung von Merge- oder Post-Merge-Berechtigungen, die der Benutzer nicht gewährt hat, oder für den Entwurf von Release-Pipelines verwenden (verwenden Sie dazu Release-Engineering).
