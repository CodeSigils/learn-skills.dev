Concevez et exécutez un pipeline de développement piloté par les spécifications (SDD) pour les usines de logiciels d'IA - où les spécifications structurées constituent l'entrée, les agents d'IA génèrent le code et les contrôles de qualité garantissent l'exactitude à chaque phase : SPÉCIFIER → DÉCOMPOSER → IMPLÉMENTER → VÉRIFIER → LIVRE. À utiliser lors de la création ou du perfectionnement d'un pipeline basé sur les spécifications, tout outil de codage d'IA (Claude Code, Cursor, Hermes Agent, Devin, OpenHands, droid) peut suivre, ou lorsque vous avez besoin de portes de qualité de spécifications, de verdicts de portes de phase, d'encodage NFR ou de traduction de format. Ne pas utiliser pour un seul petit changement avec un objectif clair (classer d'abord via bmad), pour le protocole du plan de contrôle des contrats d'intention, du contrôle d'autonomie et du routage des pannes autour d'un pipeline (bmad), ou pour des problèmes non validés (découverte de produit).
