قم بتصميم وتشغيل مسار التطوير المبني على المواصفات (SDD) لمصانع برمجيات الذكاء الاصطناعي - حيث تكون المواصفات المنظمة هي المدخلات، ويقوم وكلاء الذكاء الاصطناعي بإنشاء التعليمات البرمجية، وتفرض بوابات الجودة الصحة في كل مرحلة: تحديد → تحليل → التنفيذ → التحقق → التسليم. استخدمه عند إنشاء أو تحسين مسار يعتمد على المواصفات، يمكن لأي أداة ترميز تعمل بالذكاء الاصطناعي (Claude Code، أو Cursor، أو Hermes Agent، أو Devin، أو OpenHands، أو droid) أن تتبعها، أو عندما تحتاج إلى بوابات جودة المواصفات، أو أحكام بوابة الطور، أو تشفير NFR، أو ترجمة التنسيق. لا تستخدم لتغيير صغير واحد له هدف واضح (التصنيف أولاً عبر bmad)، أو لبروتوكول مستوى التحكم الخاص بعقود النوايا، وبوابة الحكم الذاتي، وتوجيه الفشل حول خط أنابيب (bmad)، أو للمشكلات التي لم يتم التحقق من صحتها (اكتشاف المنتج).
