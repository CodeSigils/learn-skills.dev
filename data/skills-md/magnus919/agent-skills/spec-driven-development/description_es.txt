Diseñe y ejecute un proceso de desarrollo basado en especificaciones (SDD) para fábricas de software de IA, donde las especificaciones estructuradas son la entrada, los agentes de IA generan el código y las puertas de calidad imponen la corrección en cada fase: ESPECIFICAR → DESCOMPONER → IMPLEMENTAR → VERIFICAR → ENTREGAR. Úselo al construir o perfeccionar una canalización basada en especificaciones que cualquier herramienta de codificación de IA (Claude Code, Cursor, Hermes Agent, Devin, OpenHands, droid) pueda seguir, o cuando necesite puertas de calidad de especificaciones, veredictos de puerta de fase, codificación NFR o traducción de formato. No lo use para un solo cambio pequeño con un objetivo claro (clasificar primero a través de bmad), para el protocolo del plano de control de contratos de intención, activación de autonomía y enrutamiento de fallas alrededor de una tubería (bmad) o para problemas no validados (descubrimiento de productos).
