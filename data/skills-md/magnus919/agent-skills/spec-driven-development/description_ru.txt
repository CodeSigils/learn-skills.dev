Спроектируйте и запустите конвейер разработки на основе спецификаций (SDD) для фабрик программного обеспечения для искусственного интеллекта — где структурированные спецификации являются входными данными, агенты искусственного интеллекта генерируют код, а контроль качества обеспечивает правильность на каждом этапе: УКАЗАТЬ → РАЗДЕЛИТЬ → РЕАЛИЗОВАТЬ → ПРОВЕРИТЬ → ДОСТАВИТЬ. Используйте при построении или доработке конвейера, управляемого спецификациями, любой инструмент кодирования AI (Claude Code, Cursor, Hermes Agent, Devin, OpenHands, droid), которому может следовать, или когда вам нужны элементы качества спецификации, вердикты фазовых вентилей, кодирование NFR или преобразование формата. Не используйте для одного небольшого изменения с четкой целью (сначала классифицируйте через bmad), для протокола контрактов о намерениях на уровне управления, шлюзования автономии и маршрутизации ошибок по конвейеру (bmad) или для непроверенных проблем (обнаружение продукта).
