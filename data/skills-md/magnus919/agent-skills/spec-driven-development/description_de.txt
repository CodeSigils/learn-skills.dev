Entwerfen und betreiben Sie eine Spec-Driven Development (SDD)-Pipeline für KI-Softwarefabriken – wobei strukturierte Spezifikationen die Eingabe sind, KI-Agenten den Code generieren und Qualitätstore die Korrektheit in jeder Phase erzwingen: SPECIFY → DECOMPOSE → IMPLEMENT → VERIFY → LIEFER. Verwenden Sie es beim Erstellen oder Verfeinern einer spezifikationsgesteuerten Pipeline, dem jedes beliebige KI-Codierungstool (Claude Code, Cursor, Hermes Agent, Devin, OpenHands, Droid) folgen kann, oder wenn Sie Spezifikationsqualitäts-Gates, Phase-Gate-Urteile, NFR-Codierung oder Formatübersetzung benötigen. Nicht für eine einzelne kleine Änderung mit einem klaren Ziel (zuerst klassifizieren über bmad), für das Steuerungsebenenprotokoll von Absichtsverträgen, Autonomie-Gating und Fehlerrouting um eine Pipeline (bmad) oder für nicht validierte Probleme (Produkterkennung) verwenden.
