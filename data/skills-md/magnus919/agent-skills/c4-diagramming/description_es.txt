Cree y revise diagramas de arquitectura de software C4 utilizando Mermaid o Structurizr. Úselo cuando los equipos necesiten una vista a nivel de código, contenedor, componente o contexto del sistema lista para la comunicación, incluida la audiencia, la narrativa, la jerarquía, las etiquetas, las leyendas, la accesibilidad y la incertidumbre. No lo utilice para trabajos de representación/sintaxis de Mermaid sin modelado C4, decisiones de arquitectura o revisiones completas de conformidad de accesibilidad.
