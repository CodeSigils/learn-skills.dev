استخدمه عند تصميم البرامج أو تنفيذها بشكل آمن: تحديد متطلبات الأمان، أو تصميم نموذج تهديد، أو اختيار الإعدادات الافتراضية الآمنة، أو مصادقة التصميم والترخيص، أو التعامل مع البيانات والأسرار غير الموثوق بها، أو تقييم التبعيات، أو تصميم حدود ثقة متعددة المستأجرين، أو مراجعة التغييرات الحساسة للأمان. الاستخدام للوقاية أثناء المتطلبات والتصميم والتنفيذ والمراجعة؛ ليس من أجل تقييمات الأمان بعد الإنشاء أو مسح قاعدة التعليمات البرمجية الموجودة.
