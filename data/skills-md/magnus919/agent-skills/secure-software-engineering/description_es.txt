Utilícelo al diseñar o implementar software de forma segura: defina requisitos de seguridad, modele una característica contra amenazas, elija valores predeterminados seguros, diseñe autenticación y autorización, maneje datos y secretos que no sean de confianza, evalúe dependencias, diseñe límites de confianza para múltiples inquilinos o revise cambios sensibles a la seguridad. Úselo para prevención durante los requisitos, el diseño, la implementación y la revisión; no para evaluaciones de seguridad posteriores a la compilación ni para escanear una base de código existente.
