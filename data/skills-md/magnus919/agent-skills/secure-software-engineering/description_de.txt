Verwendung beim sicheren Entwerfen oder Implementieren von Software: Definieren Sie Sicherheitsanforderungen, erstellen Sie ein Bedrohungsmodell für eine Funktion, wählen Sie sichere Standardeinstellungen, entwerfen Sie Authentifizierung und Autorisierung, verarbeiten Sie nicht vertrauenswürdige Daten und Geheimnisse, bewerten Sie Abhängigkeiten, entwerfen Sie Vertrauensgrenzen für mehrere Mandanten oder überprüfen Sie sicherheitsrelevante Änderungen. Verwendung zur Prävention bei Anforderungen, Design, Implementierung und Überprüfung; Nicht für Sicherheitsbewertungen nach dem Build oder zum Scannen einer vorhandenen Codebasis.
