Découvrez votre flux de travail réel par le biais de conversations ou d'observations, puis générez un ensemble de compétences sur mesure qui le code sous forme de compétences d'agent chargeables avec des conditions de déclenchement. À utiliser lorsque vous souhaitez comprendre votre propre processus, le formaliser ou le partager avec des collaborateurs. À utiliser également lorsqu'une session semble sans but : cette compétence lui donne une structure. N'utilisez pas cette compétence pour des demandes sans rapport ; itinéraire vers le spécialiste nommé le plus proche.
