Concevoir et exploiter l'infrastructure de données : opérations de base de données (vecteur, relationnel, graphique, séries chronologiques), conception de pipeline ETL/ELT (modèles dbt, chargement incrémentiel), modèles analytiques SQL, surveillance de la qualité des données, migration de schéma et gestion de l'infrastructure de stockage. Ne pas utiliser pour l’analyse statistique ou le développement de modèles ML.
