تصميم وتشغيل البنية التحتية للبيانات - عمليات قاعدة البيانات (المتجهات، والعلائقية، والرسم البياني، والسلاسل الزمنية)، وتصميم خطوط أنابيب ETL/ELT (أنماط dbt، والتحميل التزايدي)، وأنماط SQL التحليلية، ومراقبة جودة البيانات، وترحيل المخطط، وإدارة البنية التحتية للتخزين. لا تستخدم للتحليل الإحصائي أو تطوير نموذج تعلم الآلة.
