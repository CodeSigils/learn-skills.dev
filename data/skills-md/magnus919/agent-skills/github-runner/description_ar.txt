نشر وإدارة واستكشاف أخطاء مشغلي GitHub Actions المستضافين ذاتيًا وإصلاحها. يغطي خدمة systemd وحاويات Docker وKubernetes (وحدة التحكم في مشغل الإجراءات) وعميل مجموعة القياس. يُستخدم عند إعداد مشغل CI، أو تصحيح أخطاء التسجيل، أو تصميم القياس التلقائي، أو تقوية أمان المشغل. لا تستخدم هذه المهارة لطلبات غير ذات صلة؛ الطريق إلى أقرب متخصص اسمه.
