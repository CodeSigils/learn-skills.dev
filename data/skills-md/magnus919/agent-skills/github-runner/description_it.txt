Distribuisci, gestisci e risolvi i problemi dei runner GitHub Actions self-hosted. Copre il servizio systemd, i contenitori Docker, Kubernetes (controller di Actions Runner) e il client del set di scalabilità. Da utilizzare durante la configurazione di un runner CI, il debug degli errori di registrazione, la progettazione della scalabilità automatica o il rafforzamento della sicurezza del runner. Non utilizzare questa abilità per richieste non correlate; recarsi allo specialista nominato più vicino.
