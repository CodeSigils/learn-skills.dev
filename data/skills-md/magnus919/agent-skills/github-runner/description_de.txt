Bereitstellen, verwalten und beheben Sie selbst gehostete GitHub Actions-Runner. Deckt den Systemd-Dienst, Docker-Container, Kubernetes (Actions Runner Controller) und den Scale Set Client ab. Verwenden Sie diese Fähigkeit nicht für nicht zusammenhängende Anfragen. Route zum nächstgelegenen benannten Spezialisten.
