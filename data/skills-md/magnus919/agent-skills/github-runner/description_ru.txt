Развертывайте, управляйте и устраняйте неполадки самостоятельных средств запуска GitHub Actions. Охватывает службу systemd, контейнеры Docker, Kubernetes (контроллер выполнения действий) и клиент масштабируемого набора. Используйте при настройке бегуна CI, отладке ошибок регистрации, разработке автоматического масштабирования или усилении безопасности бегуна. Не используйте этот навык для несвязанных запросов; маршрут к ближайшему поименованному специалисту.
