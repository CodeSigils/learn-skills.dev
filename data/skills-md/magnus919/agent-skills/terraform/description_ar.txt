قم بتشغيل Terraform وOpenTofu عبر دورة حياة البنية التحتية بأكملها: هيكل الوحدة النمطية، والواجهات الخلفية للحالة والقفل، وتخطيط/تطبيق سير العمل، واكتشاف الانجراف، والحالة البعيدة، وتدفقات الترقية وإعادة البناء، والتشخيصات القائمة على الأدلة. يُستخدم عند تشغيل أو فحص خطط terraform، أو التطبيقات، أو ملفات الحالة، أو الواردات، أو جراحة الحالة، أو عندما يتعين على البرنامج النصي tfops المجمّع التعامل مع المهمة. لا تستخدمه لمنهجية IaC أو قرارات التصميم السحابي - فهي تصل إلى هندسة النظام الأساسي.
