استخدم هذه المهارة لتقييم وتصميم وتطوير بنيات البيانات، بما في ذلك منصات البيانات ومنتجات البيانات واعتماد شبكة البيانات وتدفقات البيانات المستندة إلى الأحداث والحوكمة والنمذجة وقرارات الترحيل. قم بتحميله عندما تحتاج الفرق إلى مقايضات قائمة على عبء العمل، أو اتفاقيات الملكية والجودة، أو بنية البيانات الحالية إلى الهدف. لا تستخدمه لعمليات خطوط الأنابيب أو النظام الأساسي، أو تفاصيل التنفيذ، أو دلالات عقد الواجهة، أو ضبط SQL، أو النمذجة الإحصائية؛ قم بتوجيه هؤلاء إلى هندسة البيانات، أو هندسة المنصات، أو تصميم وتطوير واجهة برمجة التطبيقات، أو postgres، أو عالم البيانات.
