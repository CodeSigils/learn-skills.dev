Utilizza questa competenza per valutare, progettare ed evolvere architetture di dati, tra cui piattaforme dati, prodotti dati, adozione di mesh di dati, flussi di dati basati sugli eventi, governance, modellazione e decisioni di migrazione. Caricalo quando i team necessitano di compromessi basati sul carico di lavoro, accordi di proprietà e qualità o un'architettura dati attuale-obiettiva. Non utilizzarlo per operazioni di pipeline o piattaforma, dettagli di implementazione, semantica del contratto di interfaccia, ottimizzazione SQL o modellazione statistica; indirizzarli a ingegneria dei dati, ingegneria delle piattaforme, progettazione ed evoluzione delle API, postgres o data scientist.
