操作作為一個單元部署的可觀察性堆疊：Prometheus 抓取配置、記錄和警報規則、重新標記、保留和高可用性； OpenTelemetry Collector 管道（接收器、處理器、導出器、採樣、跟踪/跨度關聯）； Loki 攝取、LogQL、保留和標籤設計 - 帶有捆綁的唯讀性遙測檢查腳本，用於 Prometheus 健全性。在執行、調整 Prometheus、OpenTelemetry Collector 或 Loki 部署或對其進行故障排除時使用，或在檢查收集/攝取/保留層（包括有界 PromQL 和 LogQL 查詢構造、語義檢查和無資料診斷）時使用。請勿用於可觀察性策略、SLI/SLO 設計或分頁策略（即平台工程）、Grafana 儀表板、面板和 Grafana 端警報（即 grafana）或 Tempo/追蹤操作，這些操作仍然推遲到未來的命名工具技能。
