تصميم وتطوير بنيات المؤسسة من خلال ربط قدرات الأعمال وتدفقات القيمة والتطبيقات والمعلومات والتكنولوجيا ونماذج التشغيل وخيارات الانتقال. يُستخدم عند تعيين مجموعة مشاريع، أو مقارنة الحالات الحالية والمستهدفة، أو تسلسل بنيات الانتقال، أو تحديد حقوق اتخاذ القرار بشأن البنية الموحدة والتواصل مع أصحاب المصلحة. لا تستخدم لتصميم النظام أو الحل، أو تصميم واجهة برمجة التطبيقات أو منصة البيانات، أو التصميم التنظيمي أو تصميم المواهب، أو خرائط طريق المنتج، أو اعتماد التكنولوجيا، أو استراتيجية الشركة؛ قم بتوجيه هؤلاء إلى المهارات المتخصصة المذكورة.
