Progetta ed evolvi architetture aziendali collegando capacità aziendali, flussi di valore, applicazioni, informazioni, tecnologia, modelli operativi e scelte di transizione. Da utilizzare quando si mappa un portafoglio aziendale, si confrontano gli stati attuali e quelli target, si sequenziano le architetture di transizione o si definiscono i diritti decisionali dell'architettura federata e la comunicazione con le parti interessate. Non utilizzare per la progettazione di sistemi o soluzioni, progettazione di API o piattaforme dati, progettazione organizzativa o di talenti, roadmap di prodotti, adozione di tecnologie o strategia aziendale; indirizzarli alle competenze specialistiche indicate.
