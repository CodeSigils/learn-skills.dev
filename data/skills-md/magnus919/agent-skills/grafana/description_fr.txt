Exploitez, configurez, provisionnez, sécurisez et dépannez Grafana OSS, Enterprise et Cloud, y compris les tableaux de bord, les dossiers, les sources de données, les annotations, les règles d'alerte, les points de contact, les politiques de notification, les silences, les délais de mise en sourdine, les comptes de service, RBAC, les plugins, les API et les flux de travail en tant que code. À utiliser pour le travail sur les produits Grafana et les intégrations côté Grafana. Ne pas utiliser pour définir des SLO ou une politique de pagination, pour exploiter les backends Prometheus/Loki/Tempo/InfluxDB, pour les travaux génériques Docker/Kubernetes/Terraform/reverse-proxy, pour le développement de plugins ou pour les évaluations de sécurité autorisées ; utiliser la compétence spécialisée correspondante.
