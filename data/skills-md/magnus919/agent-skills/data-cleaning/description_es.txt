Limpie, perfile, valide, remodele y documente datos tabulares, de texto, JSON y relacionales desordenados a través de un flujo de trabajo reproducible que prioriza la evidencia. Úselo al preparar datos para análisis, informes, modelado, ingesta, migración o comparación. No lo utilice para modelado estadístico, diseño de paneles ni para operar una plataforma de datos con nombre; dirija esas tareas a un científico de datos, ingeniería de datos o la habilidad de herramienta relevante.
