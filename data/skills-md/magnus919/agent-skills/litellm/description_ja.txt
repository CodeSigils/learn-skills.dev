LiteLLM AI ゲートウェイ (プロキシ) と Python SDK の操作、構成、保護、トラブルシューティングを行います。プロキシを実行し (litellm --config)、1 つの OpenAI 互換 API を介して 100 以上のプロバイダーにルーティングし、モデル リストとルーティング/信頼性、仮想キー、チーム、予算、レート制限、キャッシュ、ガードレール、可観測性、支出を構成し、リクエストの失敗を診断します。 LiteLLM プロキシまたはゲートウェイ (config.yaml、ghcr.io/berriai/litellm) をデプロイまたは実行する場合、それを介して Python SDK または OpenAI SDK を接続する場合、または公開デプロイメントを強化する場合に使用します。単一の推論エンジン (vllm、llama-cpp) の操作、エンジン選択方法 (ml エンジニアリング)、または LLM API 上でのアプリケーションの構築 (バックエンド/フロントエンド エンジニアリング) には使用しないでください。
