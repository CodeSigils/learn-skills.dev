Эксплуатируйте, настраивайте, защищайте и устраняйте неполадки AI-шлюза LiteLLM (прокси) и Python SDK: запускайте прокси-сервер (litellm --config), направляйтесь к более чем 100 поставщикам через один OpenAI-совместимый API, настраивайте списки моделей, маршрутизацию/надежность, виртуальные ключи, команды, бюджеты, ограничения скорости, кэширование, ограждения, наблюдаемость и расходы, а также диагностируйте сбои запросов. Используйте при развертывании или запуске прокси-сервера или шлюза LiteLLM (config.yaml, ghcr.io/berriai/litellm), подключении через него Python SDK или OpenAI SDK или усилении общедоступного развертывания. Не используйте для работы с одним механизмом вывода (vllm, llama-cpp), для методологии выбора механизма (ml-инжиниринг) или для создания приложений поверх API LLM (бэкэнд-/фронтенд-инжиниринг).
