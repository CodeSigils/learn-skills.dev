تشغيل وتكوين وتأمين واستكشاف أخطاء بوابة LiteLLM AI (الوكيل) وPython SDK: تشغيل الوكيل (litellm --config)، والتوجيه إلى أكثر من 100 موفر من خلال واجهة برمجة تطبيقات واحدة متوافقة مع OpenAI، وتكوين قوائم النماذج والتوجيه/الموثوقية، والمفاتيح الافتراضية، والفرق، والميزانيات، وحدود الأسعار، والتخزين المؤقت، وحواجز الحماية، وقابلية المراقبة، والإنفاق، وتشخيص حالات فشل الطلب. يُستخدم عند نشر أو تشغيل وكيل أو بوابة LiteLLM (config.yaml، ghcr.io/berriai/litellm)، أو توصيل Python SDK أو OpenAI SDK من خلاله، أو تقوية النشر العام. لا تستخدم لتشغيل محرك استدلال واحد (vllm، llama-cpp)، أو لمنهجية اختيار المحرك (هندسة ml)، أو لبناء تطبيقات أعلى LLM API (هندسة الواجهة الخلفية/الواجهة الأمامية).
