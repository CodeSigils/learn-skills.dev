Exploitez, configurez, sécurisez et dépannez la passerelle LiteLLM AI (proxy) et le SDK Python : exécutez le proxy (litellm --config), acheminez vers plus de 100 fournisseurs via une API compatible OpenAI, configurez les listes de modèles et le routage/fiabilité, les clés virtuelles, les équipes, les budgets, les limites de débit, la mise en cache, les garde-fous, l'observabilité et les dépenses, et diagnostiquez les échecs des demandes. À utiliser lors du déploiement ou de l'exécution d'un proxy ou d'une passerelle LiteLLM (config.yaml, ghcr.io/berriai/litellm), du câblage du SDK Python ou du SDK OpenAI via celui-ci, ou du renforcement d'un déploiement public. Ne pas utiliser pour faire fonctionner un seul moteur d'inférence (vllm, lama-cpp), pour une méthodologie de sélection de moteur (ml-engineering) ou pour créer des applications au-dessus d'une API LLM (ingénierie backend/frontend).
