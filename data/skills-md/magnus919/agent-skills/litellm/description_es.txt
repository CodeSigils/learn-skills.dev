Opere, configure, proteja y solucione problemas de la puerta de enlace LiteLLM AI (proxy) y Python SDK: ejecute el proxy (litellm --config), enrute a más de 100 proveedores a través de una API compatible con OpenAI, configure listas de modelos y enrutamiento/confiabilidad, claves virtuales, equipos, presupuestos, límites de velocidad, almacenamiento en caché, barreras de seguridad, observabilidad y gasto, y diagnostique fallas en las solicitudes. Úselo al implementar o ejecutar un proxy o puerta de enlace LiteLLM (config.yaml, ghcr.io/berriai/litellm), conectar el SDK de Python o el SDK de OpenAI a través de él, o reforzar una implementación pública. No lo use para operar un único motor de inferencia (vllm, llama-cpp), para metodología de selección de motor (ml-engineering) o para crear aplicaciones sobre una API LLM (ingeniería backend/frontend).
