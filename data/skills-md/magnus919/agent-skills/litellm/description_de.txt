Betreiben, konfigurieren, sichern und beheben Sie Probleme mit dem LiteLLM AI-Gateway (Proxy) und dem Python SDK: Führen Sie den Proxy aus (litellm --config), leiten Sie über eine OpenAI-kompatible API an über 100 Anbieter weiter, konfigurieren Sie Modelllisten und Routing/Zuverlässigkeit, virtuelle Schlüssel, Teams, Budgets, Ratenlimits, Caching, Leitplanken, Beobachtbarkeit und Ausgaben und diagnostizieren Sie Anforderungsfehler. Verwenden Sie diese Option, wenn Sie einen LiteLLM-Proxy oder -Gateway (config.yaml, ghcr.io/berriai/litellm) bereitstellen oder ausführen, das Python SDK oder OpenAI SDK darüber verkabeln oder eine öffentlich zugängliche Bereitstellung härten. Nicht für den Betrieb einer einzelnen Inferenz-Engine (vllm, llama-cpp), für die Engine-Auswahlmethodik (ML-Engineering) oder für die Erstellung von Anwendungen auf einer LLM-API (Backend/Frontend-Engineering) verwenden.
