Concevez, gouvernez, documentez, révisez et faites évoluer les API et les interfaces d'événements destinées aux consommateurs. À utiliser lors du choix de REST/HTTP, GraphQL, RPC, d'événements, de webhooks ou de streaming ; rédiger des contrats OpenAPI ou AsyncAPI ; évaluer un paysage d'API, la propriété, la duplication, le cycle de vie, la découvrabilité, le retrait, les passerelles, les maillages de services, le trafic nord-sud ou est-ouest, le routage, la politique, l'observabilité ou les limites de défaillance ; définir des schémas, une pagination, des mutations, des erreurs, une idempotence ou une compatibilité ; ou planifier la gestion des versions, la dépréciation et la migration. Ne pas utiliser pour la découverte de produits, les opérations de plateforme, l'évaluation complète de la sécurité, la création d'ADR ou les portes de livraison ; les acheminer vers les compétences spécialisées voisines.
