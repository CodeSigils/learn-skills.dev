Diseñe, gobierne, documente, revise y evolucione API e interfaces de eventos orientadas al consumidor. Úselo al elegir REST/HTTP, GraphQL, RPC, eventos, webhooks o streaming; redactar contratos OpenAPI o AsyncAPI; evaluar un panorama de API, propiedad, duplicación, ciclo de vida, capacidad de descubrimiento, retiro, puertas de enlace, mallas de servicios, tráfico norte-sur o este-oeste, enrutamiento, política, observabilidad o límites de fallas; definir esquemas, paginación, mutaciones, errores, idempotencia o compatibilidad; o planificar el control de versiones, la desactivación y la migración. No lo utilice para descubrimiento de productos, operaciones de plataforma, evaluación de seguridad completa, creación de ADR o puertas de entrega; enrútelos a las habilidades especializadas vecinas.
