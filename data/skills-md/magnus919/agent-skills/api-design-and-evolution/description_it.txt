Progetta, governa, documenta, rivedi ed evolvi le API e le interfacce degli eventi rivolte ai consumatori. Da utilizzare quando si sceglie REST/HTTP, GraphQL, RPC, eventi, webhook o streaming; scrivere contratti OpenAPI o AsyncAPI; valutazione del panorama API, proprietà, duplicazione, ciclo di vita, rilevabilità, ritiro, gateway, mesh di servizi, traffico nord-sud o est-ovest, instradamento, policy, osservabilità o limiti di errore; definire schemi, impaginazione, mutazioni, errori, idempotenza o compatibilità; o pianificare il controllo delle versioni, la deprecazione e la migrazione. Non utilizzare per il rilevamento di prodotti, operazioni sulla piattaforma, valutazione completa della sicurezza, creazione di ADR o gate di consegna; indirizzarli alle competenze specialistiche limitrofe.
