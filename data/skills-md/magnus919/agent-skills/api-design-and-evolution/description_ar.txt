تصميم وإدارة وتوثيق ومراجعة وتطوير واجهات برمجة التطبيقات وواجهات الأحداث التي تواجه المستهلك. يُستخدم عند اختيار REST/HTTP، أو GraphQL، أو RPC، أو الأحداث، أو خطافات الويب، أو البث؛ كتابة عقود OpenAPI أو AsyncAPI؛ تقييم مشهد واجهة برمجة التطبيقات (API)، أو الملكية، أو الازدواجية، أو دورة الحياة، أو قابلية الاكتشاف، أو التقاعد، أو البوابات، أو شبكات الخدمة، أو حركة المرور من الشمال إلى الجنوب أو من الشرق إلى الغرب، أو التوجيه، أو السياسة، أو إمكانية الملاحظة، أو حدود الفشل؛ تحديد المخططات، أو ترقيم الصفحات، أو الطفرات، أو الأخطاء، أو العجز، أو التوافق؛ أو التخطيط لإصدار الإصدارات والإهمال والترحيل. لا تستخدم لاكتشاف المنتج، أو عمليات النظام الأساسي، أو التقييم الأمني ​​الكامل، أو تأليف ADR، أو بوابات التسليم؛ توجيه تلك إلى المهارات المتخصصة المجاورة.
