消費者向け API とイベント インターフェイスを設計、管理、文書化、レビュー、進化させます。 REST/HTTP、GraphQL、RPC、イベント、Webhook、またはストリーミングを選択するときに使用します。 OpenAPI または AsyncAPI コントラクトを作成する。 API ランドスケープ、所有権、重複、ライフサイクル、検出可能性、廃止、ゲートウェイ、サービス メッシュ、南北または東西のトラフィック、ルーティング、ポリシー、可観測性、または障害境界を評価します。スキーマ、ページネーション、突然変異、エラー、冪等性、または互換性を定義します。またはバージョン管理、非推奨化、移行の計画。製品検出、プラットフォーム操作、完全なセキュリティ評価、ADR オーサリング、または配信ゲートには使用しないでください。それらを隣接する専門スキルにルーティングします。
