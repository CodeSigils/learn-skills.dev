Administre y solucione problemas de sistemas remotos Linux, FreeBSD, NetBSD, OpenBSD y macOS de forma segura, un host o una flota a la vez. Úselo cuando una tarea requiera SSH, Ansible, Paramiko, diagnósticos POSIX, administración de servicios, actualizaciones de software, configuración del sistema, cambios en el firewall u operaciones remotas basadas en evidencia. No lo utilice para la administración de escritorios solo local, la orquestación de contenedores o clústeres (enrutamiento a Kubernetes) ni para consolas en la nube que no exponen ningún shell remoto.
