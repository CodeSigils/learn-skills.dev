Utilizzare questa competenza per decodificare un sistema software esistente, mapparne l'architettura, il flusso di dati, la posizione sulla privacy, l'accoppiamento, le caratteristiche di qualità e la superficie delle funzionalità, quindi produrre un documento di progettazione della camera bianca basato sull'evidenza, un PRD o un piano di migrazione sotto nuovi vincoli. Utilizzare per l'archeologia della base di codice, l'estrazione di contratti impliciti, la valutazione dello stato dell'architettura o l'analisi della preparazione alla decomposizione. Non utilizzare per la progettazione di architetture greenfield, la revisione diretta del codice, la ricerca di bug, il controllo della sicurezza o l'implementazione di API, dati, piattaforma o modifiche alla migrazione; indirizzarli alla competenza vicina pertinente.
