Используйте этот навык для обратного проектирования существующей программной системы, отображения ее архитектуры, потока данных, состояния конфиденциальности, связи, качественных характеристик и поверхности функций, а затем создайте обоснованный документ о проектировании чистых помещений, PRD или план миграции с учетом новых ограничений. Используйте для археологии кодовой базы, неявного извлечения контрактов, оценки работоспособности архитектуры или анализа готовности к декомпозиции. Не используйте для проектирования новой архитектуры, прямой проверки кода, поиска ошибок, аудита безопасности или внедрения изменений API, данных, платформы или миграции; направьте их к соответствующему соседнему навыку.
