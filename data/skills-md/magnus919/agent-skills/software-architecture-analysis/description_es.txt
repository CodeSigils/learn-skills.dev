Utilice esta habilidad para aplicar ingeniería inversa a un sistema de software existente, mapear su arquitectura, flujo de datos, postura de privacidad, acoplamiento, características de calidad y superficie de características, y luego producir un documento de diseño de sala limpia, PRD o plan de migración basado en evidencia bajo nuevas restricciones. Úselo para arqueología de base de código, extracción de contratos implícitos, evaluación del estado de la arquitectura o análisis de preparación para la descomposición. No lo utilice para diseño de arquitectura totalmente nueva, revisión directa de código, búsqueda de errores, auditoría de seguridad o implementación de API, datos, plataforma o cambios de migración; enrútelos a la habilidad vecina relevante.
