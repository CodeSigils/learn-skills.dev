استخدم هذه المهارة لإجراء هندسة عكسية لنظام برمجي موجود، ورسم خريطة لبنيته، وتدفق البيانات، ووضعية الخصوصية، والاقتران، وخصائص الجودة، وسطح الميزات، ثم إنتاج مستند تصميم غرفة نظيفة قائم على الأدلة، أو PRD، أو خطة ترحيل في ظل قيود جديدة. يُستخدم لعلم آثار قاعدة التعليمات البرمجية، أو استخراج العقود الضمنية، أو تقييم صحة الهندسة المعمارية، أو تحليل جاهزية التحلل. لا تستخدم لتصميم البنية التأسيسية أو المراجعة المباشرة للتعليمات البرمجية أو البحث عن الأخطاء أو تدقيق الأمان أو تنفيذ تغييرات واجهة برمجة التطبيقات أو البيانات أو النظام الأساسي أو الترحيل؛ قم بتوجيه هؤلاء إلى المهارة المجاورة ذات الصلة.
