Cree o refactorice herramientas CLI orientadas al agente con comandos no interactivos, contratos --help y --json estables, operaciones idempotentes y vistas previas de ejecución en seco. Úselo para diseño CLI, refactorizaciones de fricción de agentes, depuración de código de salida/salida o seguridad de automatización. No lo utilice para diseño de GUI/TUI, herramientas conversacionales, diseño de servidor MCP o arquitectura API general; utilice api-design-and-evolution para este último.
