Crea o esegui il refactoring di strumenti CLI rivolti agli agenti con comandi non interattivi, contratti --help e --json stabili, operazioni idempotenti e anteprime --dry-run. Utilizzare per la progettazione della CLI, i refactor di attrito dell'agente, il debug del codice di output/uscita o la sicurezza dell'automazione. Non utilizzare per la progettazione di GUI/TUI, strumenti di conversazione, progettazione di server MCP o architettura API generale; utilizzare api-design-and-evolution per quest'ultimo.
