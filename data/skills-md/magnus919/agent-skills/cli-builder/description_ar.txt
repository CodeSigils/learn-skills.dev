قم ببناء أو إعادة تصميم أدوات واجهة سطر الأوامر (CLI) التي تواجه الوكيل باستخدام أوامر غير تفاعلية، وعقود --help و --json مستقرة، وعمليات غير فعالة، ومعاينات --dry-run. يُستخدم لتصميم واجهة سطر الأوامر (CLI)، أو عوامل إعادة بناء عوامل الاحتكاك، أو تصحيح أخطاء كود الإخراج/الخروج، أو سلامة التشغيل الآلي. لا تستخدمه لتصميم واجهة المستخدم الرسومية/TUI، أو أدوات المحادثة، أو تصميم خادم MCP، أو بنية واجهة برمجة التطبيقات العامة؛ استخدم تصميم واجهة برمجة التطبيقات والتطور للأخير.
