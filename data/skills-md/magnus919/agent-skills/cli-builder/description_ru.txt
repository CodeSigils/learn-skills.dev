Создавайте или реорганизуйте инструменты CLI, работающие с агентами, с помощью неинтерактивных команд, стабильных контрактов --help и --json, идемпотентных операций и предварительного просмотра --dry-run. Используйте для проектирования CLI, рефакторинга агентов, отладки кода вывода/выхода или обеспечения безопасности автоматизации. Не используйте для проектирования графического пользовательского интерфейса/TUI, диалоговых инструментов, проектирования сервера MCP или общей архитектуры API; для последнего используйте API-дизайн и эволюцию.
