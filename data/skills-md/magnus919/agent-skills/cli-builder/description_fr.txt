Créez ou refactorisez des outils CLI destinés aux agents avec des commandes non interactives, des contrats stables --help et --json, des opérations idempotentes et des aperçus --dry-run. À utiliser pour la conception CLI, les refactoristes de friction d'agent, le débogage de code de sortie/de sortie ou la sécurité de l'automatisation. Ne pas utiliser pour la conception GUI/TUI, les outils conversationnels, la conception de serveur MCP ou l'architecture API générale ; utilisez api-design-and-evolution pour ce dernier.
