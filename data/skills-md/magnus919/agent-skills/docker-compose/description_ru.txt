Используйте Docker Compose для определения, запуска, отладки и усиления защиты многоконтейнерных приложений. Загрузите файл compose.yaml для проектирования, сети, томов, секретов, профилей, переопределений, режима просмотра, операций жизненного цикла или устранения неполадок. Не используйте этот навык для несвязанных запросов; маршрут к ближайшему поименованному специалисту.
