Utilisez Docker Compose pour définir, exécuter, déboguer et renforcer des applications multi-conteneurs. Chargez pour la conception compose.yaml, la mise en réseau, les volumes, les secrets, les profils, les remplacements, le mode de surveillance, les opérations de cycle de vie ou le dépannage. N'utilisez pas cette compétence pour des demandes sans rapport ; itinéraire vers le spécialiste nommé le plus proche.
