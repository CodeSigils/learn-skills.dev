Utilizza Docker Compose per definire, eseguire, eseguire il debug e rafforzare le applicazioni multi-contenitore. Carica per progettazione compose.yaml, rete, volumi, segreti, profili, sostituzioni, modalità di controllo, operazioni del ciclo di vita o risoluzione dei problemi. Non utilizzare questa abilità per richieste non correlate; recarsi allo specialista nominato più vicino.
