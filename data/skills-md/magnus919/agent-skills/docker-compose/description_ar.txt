استخدم Docker Compose لتحديد التطبيقات متعددة الحاويات وتشغيلها وتصحيح أخطائها وتقويتها. قم بالتحميل لتصميم compose.yaml أو الشبكات أو وحدات التخزين أو الأسرار أو الملفات الشخصية أو التجاوزات أو وضع المراقبة أو عمليات دورة الحياة أو استكشاف الأخطاء وإصلاحها. لا تستخدم هذه المهارة لطلبات غير ذات صلة؛ الطريق إلى أقرب متخصص اسمه.
