تشغيل واستكشاف الأخطاء وإصلاحها وتأمين وترقية وأتمتة مجموعات Kubernetes وأحمال العمل بأمان عبر Kubernetes وk3s وRKE2 وMicroK8s وk0s وTalos وOpenShift/OKD وkind وMinikube والمجموعات التي تديرها Rancher وEKS وAKS وGKE. يُستخدم عندما تتضمن المهمة kubectl أو Kubernetes APIs أو Pods أو Deployments أو StatefulSets أو Services أو Ingress أو Gateway API أو CRDs أو RBAC أو NetworkPolicy أو التخزين أو الجدولة أو القياس التلقائي أو دورة حياة المجموعة أو الوكيل المجمع أولاً k8s-cli. لا تستخدم هذه المهارة لطلبات غير ذات صلة؛ الطريق إلى أقرب متخصص اسمه.
