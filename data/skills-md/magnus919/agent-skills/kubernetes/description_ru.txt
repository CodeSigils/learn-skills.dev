Безопасно эксплуатируйте, устраняйте неполадки, защищайте, обновляйте и автоматизируйте кластеры и рабочие нагрузки Kubernetes в вышестоящих Kubernetes, k3s, RKE2, MicroK8s, k0s, Talos, OpenShift/OKD, kind, Minikube, кластерах под управлением Rancher, EKS, AKS и GKE. Используйте, когда задача включает в себя kubectl, API Kubernetes, модули Pod, развертывания, StatefulSets, службы, API Ingress или Gateway, CRD, RBAC, NetworkPolicy, хранилище, планирование, автомасштабирование, жизненный цикл кластера или связанный с агентом k8s-cli. Не используйте этот навык для несвязанных запросов; маршрут к ближайшему поименованному специалисту.
