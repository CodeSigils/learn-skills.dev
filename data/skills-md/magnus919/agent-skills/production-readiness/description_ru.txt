Определите пакеты доказательств со шкалой риска и запустите шлюзы «годен/не годен/отсрочка/исключение» с подотчетными владельцами. Не используйте этот навык для междоменной производственной композиции; используйте «production-excellence» для сбора данных о миграции, восстановлении, емкости и инцидентах.
