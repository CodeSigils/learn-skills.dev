Cree interfaces frontales distintivas y de calidad de producción con alta calidad de diseño. Genera código creativo y pulido que evita la estética genérica de la IA. Úselo cuando el usuario solicite crear componentes web, páginas, artefactos, carteles o aplicaciones, o cuando alguna habilidad de diseño requiera el contexto del proyecto. Llame con "artesanía" para dar forma y luego construir, "enseñar" para configurar el contexto de diseño o "extraer" para incorporar componentes y tokens reutilizables al sistema de diseño.
