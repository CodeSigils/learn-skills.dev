Crea flussi di lavoro multi-agente per la CLI Atomic utilizzando defineWorkflow().run().compile() con ctx.stage() per l'orchestrazione delle sessioni tra gli SDK Claude, Copilot e OpenCode. Da utilizzare ogni volta che l'utente desidera creare, modificare o eseguire il debug di flussi di lavoro, creare pipeline di agenti, definire automazioni a più fasi, impostare cicli di revisione, dichiarare input di flussi di lavoro o menzionare .atomic/workflows/, defineWorkflow, ctx.stage, ctx.inputs o il selettore di flussi di lavoro atomici.
