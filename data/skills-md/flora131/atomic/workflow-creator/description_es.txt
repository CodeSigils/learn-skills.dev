Cree flujos de trabajo de múltiples agentes para Atomic CLI usando defineWorkflow().run().compile() con ctx.stage() para la orquestación de sesiones en los SDK de Claude, Copilot y OpenCode. Úselo siempre que el usuario desee crear, editar o depurar flujos de trabajo, crear canalizaciones de agentes, definir automatizaciones de varias etapas, configurar bucles de revisión, declarar entradas de flujo de trabajo o mencionar .atomic/workflows/, defineWorkflow, ctx.stage, ctx.inputs o el selector de flujo de trabajo atómico.
