قم بإنشاء مسارات عمل متعددة الوكلاء لـ Atomic CLI باستخدام DefineWorkflow().run().compile() مع ctx.stage() لتنسيق الجلسة عبر حزم SDK لـ Claude وCopilot وOpenCode. يُستخدم عندما يريد المستخدم إنشاء مسارات عمل أو تحريرها أو تصحيح أخطاءها، أو إنشاء مسارات وكيل، أو تحديد عمليات أتمتة متعددة المراحل، أو إعداد حلقات مراجعة، أو الإعلان عن مدخلات سير العمل، أو الإشارة إلى .atomic/workflows/، أو تعريف سير العمل، أو ctx.stage، أو ctx.inputs، أو منتقي سير العمل الذري.
