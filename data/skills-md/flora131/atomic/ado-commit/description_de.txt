Erstellen Sie gut formatierte konventionelle Commits in einem Repository, das auf Azure DevOps (ADO/Azure Repos) gehostet wird. Verwenden Sie dies immer dann, wenn der Benutzer Änderungen festschreiben möchte und sich das Projekt auf Azure DevOps befindet – dev.azure.com, visualstudio.com oder explizite Erwähnungen von ADO, Azure Repos oder Arbeitselement-IDs wie „AB#1234“. Fügt automatisch „AB#<id>“-Arbeitselement-Trailer hinzu, wenn der Zweigname oder die bereitgestellten Änderungen auf einen verweisen, und weist die KI-gestützte Urheberschaft zu.
