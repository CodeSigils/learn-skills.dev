Créez des commits conventionnels bien formatés dans un référentiel hébergé sur Azure DevOps (ADO / Azure Repos). Utilisez-le chaque fois que l'utilisateur demande de valider les modifications et que le projet est sur Azure DevOps — dev.azure.com, visualstudio.com ou des mentions explicites d'ADO, Azure Repos ou des ID d'élément de travail comme « AB#1234 ». Ajoute automatiquement les bandes-annonces d'éléments de travail `AB#<id>` lorsque le nom de la branche ou les modifications planifiées en font référence, et attribue la paternité assistée par l'IA.
