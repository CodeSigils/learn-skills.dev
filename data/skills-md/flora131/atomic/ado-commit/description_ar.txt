قم بإنشاء التزامات تقليدية جيدة التنسيق في مستودع مستضاف على Azure DevOps (ADO / Azure Repos). استخدم هذا عندما يطلب المستخدم تنفيذ التغييرات ويكون المشروع على Azure DevOps — dev.azure.com، أو visualstudio.com، أو إشارات صريحة إلى ADO، أو Azure Repos، أو معرفات عناصر العمل مثل `AB#1234`. يقوم تلقائيًا بإلحاق مقاطع دعائية لعنصر العمل `AB#<id>` عندما يشير اسم الفرع أو التغييرات المرحلية إلى أحد العناصر، وينسب التأليف بمساعدة الذكاء الاصطناعي.
