Зафиксируйте, отправьте и откройте запрос на включение в Azure DevOps. Используйте каждый раз, когда пользователь хочет открыть, обновить или составить черновой вариант PR, а проект размещен в Azure DevOps (dev.azure.com,visualstudio.com или явные упоминания ADO, Azure Repos или идентификаторы рабочих элементов, например AB#1234). Связывает рабочие элементы с PR, назначает рецензентов и поддерживает черновик по умолчанию.
