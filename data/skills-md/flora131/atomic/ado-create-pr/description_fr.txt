Validez, envoyez et ouvrez une pull request dans Azure DevOps. À utiliser chaque fois que l'utilisateur souhaite ouvrir, mettre à jour ou rédiger un PR et que le projet est hébergé sur Azure DevOps (`dev.azure.com`, `visualstudio.com` ou mentions explicites d'ADO, Azure Repos ou des ID d'élément de travail comme `AB#1234`). Relie les éléments de travail au PR, définit les réviseurs et prend en charge le brouillon par défaut.
