Esegui il commit, invia e apri una richiesta pull in Azure DevOps. Da utilizzare ogni volta che l'utente desidera aprire, aggiornare o redigere una PR e il progetto è ospitato su Azure DevOps ("dev.azure.com`, "visualstudio.com" o menzioni esplicite di ADO, Azure Repos o ID di elementi di lavoro come "AB#1234"). Collega gli elementi di lavoro al PR, imposta i revisori e supporta la bozza per impostazione predefinita.
