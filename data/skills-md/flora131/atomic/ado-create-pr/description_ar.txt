تنفيذ طلب سحب ودفعه وفتحه في Azure DevOps. يُستخدم عندما يريد المستخدم فتح تقرير علاقات عامة أو تحديثه أو مسودته ويتم استضافة المشروع على Azure DevOps (`dev.azure.com` أو `visualstudio.com` أو إشارات صريحة إلى ADO أو Azure Repos أو معرفات عناصر العمل مثل `AB#1234`). ربط عناصر العمل بالعلاقات العامة، وتعيين المراجعين، ودعم المسودة بشكل افتراضي.
