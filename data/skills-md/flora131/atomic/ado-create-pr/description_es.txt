Confirme, envíe y abra una solicitud de extracción en Azure DevOps. Úselo siempre que el usuario quiera abrir, actualizar o redactar un PR y el proyecto esté alojado en Azure DevOps (`dev.azure.com`, `visualstudio.com` o menciones explícitas de ADO, Azure Repos o ID de elementos de trabajo como `AB#1234`). Vincula elementos de trabajo al PR, establece revisores y admite borradores de forma predeterminada.
