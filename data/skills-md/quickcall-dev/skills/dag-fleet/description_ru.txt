Постоянный, бюджетный, управляемый DAG исполнитель для параллельных рабочих процессов `claude -p` или `codex exec` в tmux. Используйте ТОЛЬКО, если вам нужна постоянство между сеансами, ограничения бюджета для каждого работника, порядок зависимостей или смешанные модели/поставщики для каждого работника. Для специальных параллельных субагентов внутри живого разговора вместо этого используйте встроенный инструмент агента Claude Code.
