Persistenter, budgetierter, von der DAG bestellter Runner für parallele „claude -p“- oder „codex exec“-Worker in tmux. Verwenden Sie NUR, wenn Sie sitzungsübergreifende Beständigkeit, Budgetobergrenzen pro Worker, Abhängigkeitsreihenfolge oder gemischte Modelle/Anbieter pro Worker benötigen. Für parallele Ad-hoc-Subagenten innerhalb einer Live-Konversation verwenden Sie stattdessen das integrierte Agenten-Tool von Claude Code.
