عداء مستمر ومحدد بالميزانية وأمر DAG للعاملين المتوازيين `clude -p` أو `codex exec` في tmux. استخدم فقط عندما تحتاج إلى الاستمرارية عبر الجلسات، أو حدود الميزانية لكل عامل، أو ترتيب التبعية، أو النماذج/المقدمين المختلطين لكل عامل. بالنسبة للوكلاء الفرعيين المتوازيين المخصصين داخل المحادثة المباشرة، استخدم أداة الوكيل المدمجة في Claude Code بدلاً من ذلك.
