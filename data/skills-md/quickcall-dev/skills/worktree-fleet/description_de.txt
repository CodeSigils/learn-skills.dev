Unabhängigkeitsvalidierte Parallelflotte, die jeden Worker (claude -p oder codex exec) in seinem eigenen Git-Worktree ausführt. Verwenden Sie diese Option, wenn Aufgaben nicht überlappende Dateien betreffen und Sie eine zusammenführungssichere Isolierung benötigen (jeder Worker in einem eigenen Zweig). Für von der DAG bestellte Einzelarbeiter mit Budget verwenden Sie dag-fleet. Für eine Headless-Iteration mit einer Reviewer-Schleife verwenden Sie iterative-fleet.
