Écrivez, refactorisez ou révisez le code TypeScript avec des types stricts, précis et maintenables et sans « aucun », assertions de type ou suppressions de type inutiles. À utiliser lorsque vous travaillez sur des fichiers `.ts` ou `.tsx`, des API publiques, des génériques, des unions discriminées, des gardes de type, des paramètres tsconfig/module, du code orienté vers la déclaration ou tout changement où la qualité du type TypeScript affecte l'exactitude dans le dépôt Remix.
