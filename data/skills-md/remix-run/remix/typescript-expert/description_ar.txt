قم بكتابة كود TypeScript أو إعادة تصميمه أو مراجعته بأنواع صارمة ودقيقة وقابلة للصيانة وبدون "أي" غير ضروري أو تأكيدات الكتابة أو منع الكتابة. يُستخدم عند العمل على ملفات `.ts` أو `.tsx`، أو واجهات برمجة التطبيقات العامة، أو الأدوية العامة، أو النقابات المميزة، أو حراس الكتابة، أو إعدادات tsconfig/module، أو التعليمات البرمجية التي تواجه الإعلان، أو أي تغيير حيث تؤثر جودة نوع TypeScript على الصحة في Remix repo.
