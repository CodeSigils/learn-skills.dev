Исправьте ошибку в React Router, о которой сообщалось из GitHub. Используйте, когда пользователь предоставляет URL-адрес проблемы GitHub и просит исправить ошибку, изучить проблему или воспроизвести проблему. Осуществляет полный рабочий процесс: выявление проблемы, поиск ее копии, написание неудачного теста и внедрение исправления.
