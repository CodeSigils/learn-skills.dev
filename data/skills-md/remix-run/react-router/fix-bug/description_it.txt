Correggi un bug segnalato in React Router da una issue su GitHub. Usa quando l'utente fornisce l'URL di una issue su GitHub e chiede di correggere un bug, investigare un problema o riprodurre un errore. Gestisce l'intero flusso di lavoro: recuperare la issue, trovare la riproduzione, scrivere un test fallente e implementare la correzione.

Per favore rispondi sempre nella lingua dell'utente.
