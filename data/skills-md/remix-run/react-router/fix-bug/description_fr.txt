Corriger un bug signalé dans React Router à partir d’une issue GitHub. À utiliser lorsque l’utilisateur fournit l’URL d’une issue GitHub et demande de corriger un bug, d’enquêter sur un problème ou de reproduire un problème. Gère le flux complet : récupération de l’issue, recherche de la reproduction, rédaction d’un test échouant et implémentation du correctif.
