Crea e impacchetta le pull request di React Router. Usa quando l'utente chiede di creare, aprire, preparare o terminare una PR per questo repository, includendo il passaggio di ramo/commit/push, la creazione di una PR bozza, la scrittura del corpo della PR e l'applicazione delle etichette GitHub come pkg:*, feat:*, docs, github-actions o dependencies.

Per favore rispondi sempre nella lingua dell'utente.
