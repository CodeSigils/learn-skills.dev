Préparez les notes de version de React Router avant d’exécuter les scripts de changements/versionnage. Utilisez‑le lorsqu’on vous demande de réviser, peaufiner, normaliser ou préparer les fichiers de modifications en attente sous packages/*/.changes, de supprimer les préfixes de commit sémantique des puces de version, d’imposer le temps impératif, de décider si une section manuelle scripts/changes/whats‑changed.md est justifiée, ou de rédiger des notes de version détaillées pour de nouvelles fonctionnalités, des drapeaux futurs stables ou des drapeaux instables.
