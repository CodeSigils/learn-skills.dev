قم بإعداد ملاحظات إصدار React Router قبل تشغيل سكريبتات التغييرات/الإصدار. استخدم ذلك عندما يُطلب منك مراجعة أو صقل أو توحيد أو إعداد ملفات التغييرات المعلقة تحت ‎packages/*/.changes، إزالة بادئات الالتزام الدلالية من نقاط الإصدار، فرض صيغة الأمر، تحديد ما إذا كان قسم ‎scripts/changes/whats-changed.md اليدوي مطلوبًا، أو صياغة ملاحظات إصدار مطولة للميزات الجديدة أو العلامات المستقبلية المستقرة أو العلامات غير المستقرة.  

يرجى دائمًا الرد بلغة المستخدم.
