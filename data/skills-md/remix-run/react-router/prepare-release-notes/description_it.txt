Preparare le note sulla versione di React Router prima di eseguire gli script di modifica/versione. Da utilizzare quando viene richiesto di rivedere, perfezionare, normalizzare o preparare file di modifiche in sospeso in packages/*/.changes, rimuovere i prefissi di commit semantici dai punti elenco di rilascio, applicare il tempo imperativo, decidere se è garantita una sezione manuale scripts/changes/whats-changed.md o redigere note di rilascio in formato lungo per nuove funzionalità, flag futuri stabili o flag instabili.
