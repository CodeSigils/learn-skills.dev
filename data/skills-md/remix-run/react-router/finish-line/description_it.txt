Porta una pull request bloccata della community di React Router al traguardo. Usalo quando l'utente invoca `/finish-line` o `$finish-line`, fornisce un numero di PR o un URL, e chiede a Codex di risolvere i blocchi di merge, come un file di modifica mancante, documentazione mancante, test mancanti o un follow‑up del contributore obsoleto. Gestisce la valutazione del blocco e l'applicazione di piccole correzioni del maintainer sul ramo della PR del contributore quando autorizzato.

Per favore rispondi sempre nella lingua dell'utente.
