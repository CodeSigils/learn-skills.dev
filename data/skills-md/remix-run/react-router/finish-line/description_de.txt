Bringen Sie eine blockierte Pull-Anfrage der React Router-Community über die Ziellinie. Wird verwendet, wenn der Benutzer „/finish-line“ oder „$finish-line“ aufruft, eine PR-Nummer oder URL angibt und Codex auffordert, Zusammenführungsblocker wie eine fehlende Änderungsdatei, fehlende Dokumentation, fehlende Tests oder veraltete Nachverfolgung von Mitwirkenden aufzulösen. Behandelt die Evaluierung des Blockers und die Weitergabe kleiner Betreuer-Korrekturen an einen PR-Zweig des Mitwirkenden, sofern dies autorisiert ist.
