Faire avancer une pull request bloquée de la communauté React Router jusqu'à la ligne d'arrivée. Utiliser lorsque l'utilisateur invoque `/finish-line` ou `$finish-line`, fournit un numéro ou une URL de PR, et demande à Codex de résoudre les bloqueurs de fusion tels qu'un fichier de modification manquant, une documentation manquante, des tests manquants ou un suivi de contributeur obsolète. Gère l'évaluation du bloqueur et l'application de petites corrections de mainteneur sur la branche PR du contributeur lorsqu'elle est autorisée.
