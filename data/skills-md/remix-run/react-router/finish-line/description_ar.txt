أحضر طلب سحب مجتمع React Router المحظور عبر خط النهاية. يُستخدم عندما يستدعي المستخدم `/finish-line` أو `$finish-line`، ويقدم رقم PR أو عنوان URL، ويطلب من Codex حل أدوات حظر الدمج مثل ملف التغيير المفقود، أو الوثائق المفقودة، أو الاختبارات المفقودة، أو متابعة المساهمين الذين لا معنى لهم. يتولى تقييم أداة الحظر ودفع إصلاحات المشرف الصغيرة إلى فرع العلاقات العامة المساهم عند التصريح بذلك.
