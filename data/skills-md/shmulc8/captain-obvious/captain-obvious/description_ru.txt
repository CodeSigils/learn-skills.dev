Находит и удаляет тесты «Капитана Очевидность» — тесты, которые никогда не могут дать сбой или ничего не проверить. Он улавливает утверждения, которые уже гарантирует средство проверки типов (typeof/isinstance/toBeDefined для типизированных значений), тесты без утверждений, тавтологии (expect(true).toBe(true), Assert x == x, len >= 0), эхо-упорядочение (const x = 5; ожидаемое(x).toBe(5)), тесты ложного эха, неожиданные асинхронные утверждения, мертвые/проглоченные/условные утверждения, слишком широкий pytest.raises(Exception) и повторяющиеся тела тестов. Используйте его всякий раз, когда пользователь хочет очистить набор тестов, удалить избыточные/бесполезные/тавтологические/сгенерированные искусственным интеллектом тесты, упоминает тесты, которые «никогда не терпят неудачу» или «ничего не тестируют», или говорит «капитан очевидно». Работает на TypeScript (Jest/Vitest/bun:test) и Python (pytest + mypy). Обнаружение является полностью детерминированным — всегда запускайте встроенные сценарии и никогда не сканируйте тестовые файлы один за другим самостоятельно.
