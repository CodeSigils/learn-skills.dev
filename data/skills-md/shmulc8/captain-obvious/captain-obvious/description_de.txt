Findet und löscht „Captain Obvious“-Tests – Tests, die niemals fehlschlagen oder nichts überprüfen können. Es fängt Behauptungen ab, die der Typprüfer bereits garantiert (typeof/isinstance/toBeDefined für typisierte Werte), zusicherungsfreie Tests, Tautologien (expect(true).toBe(true), Assert x == x, len >= 0), Arrangement-Assert-Echos (const x = 5; Expect(x).toBe(5)), Mock-Echo-Tests, unerwartete asynchrone Assertionen, tot/verschluckt/bedingt Behauptungen, zu weit gefasste pytest.raises(Exception) und doppelte Testkörper. Verwenden Sie es immer dann, wenn der Benutzer eine Testsuite bereinigen, redundante/nutzlose/tautologische/KI-generierte Tests entfernen möchte, Tests erwähnt, die „nie fehlschlagen“ oder „nichts testen“, oder „Captain Offensichtlich“ sagt. Funktioniert mit TypeScript (Jest/Vitest/bun:test) und Python (pytest + mypy). Die Erkennung ist vollständig deterministisch – führen Sie immer die gebündelten Skripte aus, scannen Sie die Testdateien niemals einzeln einzeln.
