查找并删除“Captain Obvious”测试 - 永远不会失败或不检查任何内容的测试。它捕获类型检查器已经保证的断言（类型值上的 typeof/isinstance/toBeDefined）、无断言测试、同义反复（expect(true).toBe(true)、assert x == x、len >= 0)、排列断言回显（const x = 5;expect(x).toBe(5)）、模拟回显测试、未等待的异步断言、死亡/吞没/条件断言、过于广泛的 pytest.raises(Exception) 和重复的测试主体。每当用户想要清理测试套件、删除冗余/无用/同义反复/AI 生成的测试、提及“永不失败”或“不测试任何内容”的测试或说“显而易见”时使用。适用于 TypeScript (Jest/Vitest/bun:test) 和 Python (pytest + mypy)。检测是完全确定性的 - 始终运行捆绑的脚本，永远不要自己逐一扫描测试文件。
