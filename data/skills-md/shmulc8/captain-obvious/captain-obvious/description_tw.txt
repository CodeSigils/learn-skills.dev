尋找並刪除“Captain Obvious”測試 - 永遠不會失敗或不檢查任何內容的測試。它捕獲類型檢查器已經保證的斷言（類型值上的 typeof/isinstance/toBeDefined）、無斷言測試、同義反复（expect(true).toBe(true)、assert x == x、len >= 0)、排列斷言回顯（const x = 5;expect(x).toBe(5)）、不同的條件下斷言回顯pytest.raises(Exception) 和重複的測試主體。每當用戶想要清理測試套件、刪除冗餘/無用/同義反覆/AI 產生的測試、提及「永不失敗」或「不測試任何內容」的測試或說「顯而易見」時使用。適用於 TypeScript (Jest/Vitest/bun:test) 和 Python (pytest + mypy)。檢測是完全確定性的 - 始終運行捆綁的腳本，永遠不要自己逐一掃描測試文件。
