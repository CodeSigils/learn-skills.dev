「Captain Obvious」テスト (決して失敗しない、または何もチェックしないテスト) を検索して削除します。型チェッカーがすでに保証しているアサーション (型指定された値の typeof/isinstance/toBeDefined)、アサーションフリー テスト、トートロジー (expect(true).toBe(true)、assert x == x、len >= 0)、アレンジアサート エコー (const x = 5; Expect(x).toBe(5))、モックエコー テスト、待機されていない非同期アサーションをキャッチします。デッド/飲み込まれた/条件付きアサーション、広すぎる pytest.raises(Exception)、および重複したテスト本体。ユーザーがテスト スイートをクリーンアップする場合、冗長/役に立たない/トートロジー/AI 生成のテストを削除する場合、「絶対に失敗しない」テストまたは「何もテストしない」テストについて言及する場合、または「キャプテン 明らか」と言う場合に使用します。 TypeScript (Jest/Vitest/bun:test) および Python (pytest + mypy) で動作します。検出は完全に決定的です。常にバンドルされたスクリプトを実行し、自分でテスト ファイルを 1 つずつスキャンすることはありません。
