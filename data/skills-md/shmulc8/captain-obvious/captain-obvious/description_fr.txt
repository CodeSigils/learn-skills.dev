Recherche et supprime les tests « Captain Obvious » — des tests qui ne peuvent jamais échouer ou ne rien vérifier. Il détecte les assertions que le vérificateur de type garantit déjà (typeof/isinstance/toBeDefined sur les valeurs typées), les tests sans assertion, les tautologies (expect(true).toBe(true), assert x == x, len >= 0), les échos d'arrangement-assert (const x = 5; expect(x).toBe(5)), les tests d'écho simulé, les assertions asynchrones inattendues, les assertions mortes/avalées/conditionnelles, pytest.raises(Exception) trop large et corps de test en double. À utiliser chaque fois que l'utilisateur souhaite nettoyer une suite de tests, supprimer les tests redondants/inutiles/tautologiques/générés par l'IA, mentionne des tests qui « n'échouent jamais » ou « ne testent rien », ou dit « capitaine évident ». Fonctionne sur TypeScript (Jest/Vitest/bun:test) et Python (pytest + mypy). La détection est entièrement déterministe : exécutez toujours les scripts fournis, n'analysez jamais vous-même les fichiers de test un par un.
