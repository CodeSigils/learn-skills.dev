Trova ed elimina i test "Captain Obvious": test che non possono mai fallire o non controllare nulla. Rileva asserzioni che il controllo del tipo già garantisce (typeof/isinstance/toBeDefined su valori digitati), test senza asserzioni, tautologie (expect(true).toBe(true), assert x == x, len >= 0), echi di disposizione-asserzione (const x = 5; wait(x).toBe(5)), test mock-echo, asserzioni asincrone inattese, dead/swallowed/conditional asserzioni, pytest.raises(Exception) eccessivamente ampio e corpi di test duplicati. Da utilizzare ogni volta che l'utente desidera ripulire una suite di test, rimuovere test ridondanti/inutili/tautologici/generati dall'intelligenza artificiale, menziona test che "non falliscono mai" o "non testano nulla" o dice "capitano ovvio". Funziona su TypeScript (Jest/Vitest/bun:test) e Python (pytest + mypy). Il rilevamento è completamente deterministico: esegui sempre gli script in bundle, non scansiona mai i file di test uno per uno.
