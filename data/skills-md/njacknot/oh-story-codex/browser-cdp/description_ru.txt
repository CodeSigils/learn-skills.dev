Используйте этот навык, когда вам нужно управлять браузером Chrome через CDP (протокол Chrome DevTools) для повторного использования существующих сеансов входа в систему. Охватывает: запуск Chrome в режиме отладки, открытие URL-адресов, ожидание загрузки страницы, оценку JavaScript, создание снимков и извлечение токенов аутентификации. Триггерные фразы: автоматизация браузера, CDP, агент-браузер, 浏览器操作, 操作浏览器, Chrome CDP, 复用登录态, извлечение токена из браузера.
