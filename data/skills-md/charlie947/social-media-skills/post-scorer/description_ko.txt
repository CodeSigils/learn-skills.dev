실제 성과 데이터를 사용하여 LinkedIn 게시물에 점수를 매깁니다. Apify를 통해 사용자 자신의 게시물 기록을 가져와(또는 캐시된 데이터를 사용하여) 실제로 수행되는 작업을 식별한 다음 해당 패턴에 대해 초안의 점수를 매깁니다. 사용자가 "내 게시물 점수 매기기", "내 게시물 검토", "이 게시물 평가", "피드백 제공", "이 게시물이 얼마나 좋은지"라고 말하거나 LinkedIn 게시물을 붙여넣고 비평을 요청할 때마다 이 기술을 사용하세요. 일반적인 조언이 아닌 실제 데이터를 기준으로 점수를 매깁니다. 이벤트 및 일상적인 사후 검토에서 실시간 채점을 위해 설계되었습니다.
