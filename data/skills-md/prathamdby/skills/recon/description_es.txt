recon construye una memoria persistente de una base de código y la mantiene actualizada. El arranque en frío explora lo desconocido; cada ejecución posterior explora solo la deriva. Desencadenantes: /recon, explorar o mapear una base de código, reorientar en un repositorio después de un tiempo fuera. Banderas: --refresh y un argumento de enfoque posicional.
