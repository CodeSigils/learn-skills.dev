recon construit une mémoire persistante d'une base de code et la maintient à jour. Le démarrage à froid explore l'inconnu ; chaque exécution ultérieure explore uniquement la dérive. Déclencheurs : /recon, explorer ou cartographier une base de code, se réorienter dans un dépôt après une absence. Indicateurs : --refresh et un argument de focus positionnel.
