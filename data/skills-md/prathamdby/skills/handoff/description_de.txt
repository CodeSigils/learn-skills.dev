Komprimieren Sie die aktuelle Konversation in einem Übergabedokument, damit ein neuer Agent die Arbeit fortsetzen oder den Kontext einer zuvor gespeicherten Übergabe wiederherstellen kann. Verwenden Sie diese Option, wenn der Benutzer /handoff eingibt, den Sitzungskontext speichern, an einen neuen Agenten übergeben oder von einer Übergabedatei aus fortfahren möchte. Unterstützt --resume <Pfad>, --path <Pfad> und ein Positionsfokusargument.
