Клонируйте, обновляйте и осуществляйте поиск в репозиториях git локально, делегируя всю работу по репозиториям субагентам. Основной поток является только координатором. Используйте, когда пользователь передает URL-адрес VCS (GitHub, GitLab, Bitbucket и т. д.) или упоминает ранее клонированное имя репозитория. Поддерживает --persist для сохранения ссылки в AGENTS.md рабочего каталога, --update для принудительного извлечения и --list для отображения клонированных репозиториев.
