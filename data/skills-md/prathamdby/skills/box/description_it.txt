Clona, ​​aggiorna e cerca i repository git localmente delegando tutto il lavoro di repository ai subagenti. Il thread principale è solo un coordinatore. Da utilizzare quando l'utente passa un URL VCS (GitHub, GitLab, Bitbucket e così via) o menziona il nome di un repository precedentemente clonato. Supporta --persist per salvare un riferimento in AGENTS.md della directory di lavoro, --update per forzare il pull e --list per mostrare repository clonati.
