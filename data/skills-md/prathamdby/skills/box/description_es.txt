Clone, actualice y busque repositorios de git localmente delegando todo el trabajo del repositorio a subagentes. El hilo principal es sólo un coordinador. Úselo cuando el usuario pasa una URL de VCS (GitHub, GitLab, Bitbucket, etc.) o menciona un nombre de repositorio previamente clonado. Admite --persist para guardar una referencia en AGENTS.md del directorio de trabajo, --update para forzar la extracción y --list para mostrar repositorios clonados.
