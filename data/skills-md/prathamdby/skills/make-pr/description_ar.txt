قم بإنشاء طلب سحب بعناوين باللغة الإنجليزية البسيطة بشكل افتراضي. يُستخدم عندما يطلب المستخدم فتح PR، أو إنشاء طلب سحب، أو إرسال PR، أو دمج فرع. يدعم --target <branch> (الافتراضي: main)، --ticket <id> (البادئة العنوان برقم التذكرة، معطلة افتراضيًا)، و--conventional (تنسيق عنوان الالتزام التقليدي، معطل افتراضيًا).
