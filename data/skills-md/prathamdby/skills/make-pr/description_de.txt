Erstellen Sie standardmäßig eine Pull-Anfrage mit einfach-englischen Titeln. Verwenden Sie diese Option, wenn der Benutzer eine PR öffnen, eine Pull-Anfrage erstellen, eine PR senden oder einen Zweig zusammenführen möchte. Unterstützt --target <branch> (Standard: main), --ticket <id> (stellt dem Titel die Ticketnummer voran, standardmäßig deaktiviert) und --conventional (konventionelles Commit-Titelformat, standardmäßig deaktiviert).
