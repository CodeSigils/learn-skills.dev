По умолчанию создайте запрос на включение с простыми английскими заголовками. Используйте, когда пользователь просит открыть PR, создать запрос на включение, отправить PR или объединить ветку. Поддерживает --target <branch> (по умолчанию: main), --ticket <id> (префикс заголовка с номером заявки, отключен по умолчанию) и --conventional (традиционный формат заголовка фиксации, отключен по умолчанию).
