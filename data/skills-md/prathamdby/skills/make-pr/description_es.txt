Cree una solicitud de extracción con títulos en inglés sencillo de forma predeterminada. Úselo cuando el usuario solicite abrir un PR, crear una solicitud de extracción, enviar un PR o fusionar una sucursal. Admite --target <branch> (predeterminado: principal), --ticket <id> (prefija el título con el número de ticket, desactivado de forma predeterminada) y --conventional (formato de título de confirmación convencional, desactivado de forma predeterminada).
