Генерируйте сообщения о фиксации только из различий git и фиксируйте изменения в git. Игнорирует контекст сеанса, такой как обзоры или обсуждения. Используйте, когда пользователь вводит /commit, просит зафиксировать изменения, сохранить работу в git, создать фиксацию или написать сообщение о фиксации. Поддерживает флаги --staged/--unstaged для области различий и --conventional/--simple для стиля сообщения.
