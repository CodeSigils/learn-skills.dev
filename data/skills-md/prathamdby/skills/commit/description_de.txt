Generieren Sie Commit-Nachrichten nur aus dem Git-Diff und übernehmen Sie Änderungen an Git. Ignoriert Sitzungskontext wie Rezensionen oder Diskussionen. Wird verwendet, wenn der Benutzer /commit eingibt, Änderungen festschreiben, Arbeit in Git speichern, einen Commit erstellen oder eine Commit-Nachricht schreiben möchte. Unterstützt die Flags --staged/--unstaged für den Diff-Bereich und --conventional/--simple für den Nachrichtenstil.
