Genere mensajes de confirmación únicamente desde git diff y confirme los cambios en git. Ignora el contexto de la sesión, como revisiones o debates. Úselo cuando el usuario escribe /commit, solicita confirmar cambios, guardar trabajo en git, crear una confirmación o escribir un mensaje de confirmación. Admite indicadores --staged/--unstaged para alcance de diferenciación y --conventional/--simple para estilo de mensaje.
