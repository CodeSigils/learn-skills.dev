Générez des messages de validation à partir du git diff uniquement et validez les modifications dans git. Ignore le contexte de la session tel que les critiques ou les discussions. À utiliser lorsque l'utilisateur tape /commit, demande de valider les modifications, enregistre le travail sur git, crée une validation ou écrit un message de validation. Prend en charge les indicateurs --staged/--unstaged pour la portée différentielle et --conventional/--simple pour le style de message.
