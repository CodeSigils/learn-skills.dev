قم بتحويل متطلب معقد ومدروس إلى مستند خطة تنفيذ تفصيلية بالإضافة إلى مطالبة مشغل مستقل لجلسة وكيل جديدة. يُستخدم عندما يقدم المستخدم متطلبًا طويلًا (في الدردشة أو الملف) ويريد خطة قبل التنفيذ، أو يذكر موجه 执行计划 / 计划文档 / 新会话执行 / 交接. يفتقد التفاصيل أولاً (بيئة التشغيل، والمسارات، وفلسفة التحقق)، ويطبق ذوق ذيل الحصان، ولا ينفذ الخطة نفسها أبدًا.
