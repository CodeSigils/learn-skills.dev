Verwenden Sie diese Option, wenn der Benutzer eine HTML-Datei/ein HTML-Artefakt erstellen, dichte Informationen in lesbares HTML umwandeln, Inhalte visualisieren, eine Spezifikation/einen Bericht/einen Plan/eine Überprüfung leichter lesbar machen oder eine interaktive Wegwerf-HTML-Oberfläche zum Verstehen oder Bearbeiten von Informationen erstellen möchte. Dieser Skill ist für Artefakte gedacht, nicht für Websites oder Landingpages.
