Cree artefactos HTML de un solo archivo pulidos y legibles por humanos a partir del contenido, planes, especificaciones, informes, reseñas, notas, conjuntos de datos o explicaciones proporcionados. Úselo cuando el usuario solicite crear un archivo/artefacto HTML, convertir información densa en HTML legible, visualizar contenido, hacer que una especificación/informe/plan/revisión sea más fácil de leer o producir una superficie HTML interactiva desechable para comprender o editar información. Esta habilidad es para artefactos, no para sitios web o páginas de destino.
