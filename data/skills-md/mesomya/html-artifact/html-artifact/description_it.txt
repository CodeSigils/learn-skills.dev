Crea artefatti HTML a file singolo raffinati e leggibili da contenuti, piani, specifiche, report, recensioni, note, set di dati o spiegazioni forniti. Da utilizzare quando l'utente chiede di creare un file/artefatto HTML, convertire informazioni dense in HTML leggibile, visualizzare contenuti, rendere più facili da leggere specifiche/report/piani/revisioni o produrre una superficie HTML interattiva usa e getta per comprendere o modificare le informazioni. Questa competenza riguarda gli artefatti, non i siti Web o le pagine di destinazione.
