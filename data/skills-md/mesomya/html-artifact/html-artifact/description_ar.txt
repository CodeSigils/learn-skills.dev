قم بإنشاء عناصر HTML مصقولة وقابلة للقراءة من قبل الإنسان من المحتوى أو الخطط أو المواصفات أو التقارير أو المراجعات أو الملاحظات أو مجموعات البيانات أو التفسيرات المتوفرة. يُستخدم عندما يطلب المستخدم إنشاء ملف/عنصر HTML، أو تحويل المعلومات الكثيفة إلى HTML قابل للقراءة، أو تصور المحتوى، أو تسهيل قراءة المواصفات/التقرير/الخطة/المراجعة، أو إنتاج سطح HTML تفاعلي لفهم المعلومات أو تحريرها. هذه المهارة مخصصة للقطع الأثرية، وليس لمواقع الويب أو الصفحات المقصودة.
