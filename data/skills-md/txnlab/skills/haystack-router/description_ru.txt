Используйте при создании интерфейсов обмена, получении лучших ценовых предложений по нескольким протоколам Algorand DEX и LST, выполнении атомарных обменов, интеграции обмена токенов в приложения React с помощью use-кошелька, автоматизации обмена из Node.js или миграции с @txnlab/deflex.
