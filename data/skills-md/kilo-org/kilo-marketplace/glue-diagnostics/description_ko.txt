이 기술을 사용하면 구조화된 Runbook에 따라 ETL 작업, 크롤러, 연결, 데이터 카탈로그, DPU 사용률, Spark 실행 및 작업 북마크를 분석하여 AWS Glue 문제를 조사하고 해결할 수 있습니다. 다음 경우 활성화: 작업 실패, 작업 시간 초과, OOM 오류, Spark 실행기 또는 드라이버 충돌, 크롤러 실패, 스키마 감지 문제, 파티션 문제, JDBC 연결 실패, VPC/서브넷 연결, S3 엔드포인트 액세스, 데이터 카탈로그 동기화 문제, 스키마 발전 충돌, DPU 크기 조정 문제, 셔플 병목 현상, 데이터 왜곡, 변환 오류, 북마크 문제, 데이터 품질 오류, IAM 권한 오류, 암호화 문제, Glue Studio 시각적 편집기 오류, 작업 생성 실패 또는 사용자가 말하는 경우 특정 증상을 언급하지 않고 Glue에 문제가 있습니다.
