Используйте этот навык для исследования и устранения проблем AWS Glue путем анализа заданий ETL, сканеров, подключений, каталога данных, использования DPU, выполнения Spark и закладок заданий с помощью структурированных модулей Runbook. Активируйте, когда: сбои заданий, тайм-ауты заданий, ошибки OOM, сбои исполнителя или драйвера Spark, сбои сканера, проблемы с обнаружением схемы, проблемы с разделами, сбои подключения JDBC, подключение VPC/подсети, доступ к конечной точке S3, проблемы синхронизации каталога данных, конфликты эволюции схемы, проблемы с размером DPU, узкие места при перетасовке, перекос данных, ошибки преобразования, проблемы с закладками, сбои качества данных, ошибки разрешения IAM, проблемы шифрования, ошибки визуального редактора Glue Studio, сбои при создании задания или пользователь говорит, что с Glue что-то не так, не называя конкретных симптомов.
