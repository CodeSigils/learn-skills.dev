Создайте конвейер сбора измененных данных в реальном времени из транзакционной базы данных (Aurora DSQL, Aurora Postgres, RDS) в Redshift Serverless, S3 или любой другой приемник через Kinesis Data Streams (или MSK). Охватывает настройку производителя, правильность Lambda потребителя, шаблон журнала событий только для добавления + шаблон реконструкции, обработку смещения схемы с помощью SUPER + JSON_PARSE и эксплуатационные ошибки (ограничения параметров Redshift Data API, опрос асинхронных операторов, обработку подозрительных записей, повторную попытку и разделение пополам). Используйте, когда пользователь запрашивает «CDC в Redshift», «Сбор данных об изменении потока», «Aurora CDC», «DSQL CDC», «Репликация Postgres на S3» или «Создание потребителя Lambda для Kinesis CDC». Особенности общедоступной предварительной версии Aurora DSQL отмечены; остальное не зависит от источника.
