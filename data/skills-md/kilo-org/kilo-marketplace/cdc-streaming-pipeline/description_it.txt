Crea una pipeline di acquisizione dati di modifica in tempo reale da un database transazionale (Aurora DSQL, Aurora Postgres, RDS) a Redshift Serverless, S3 o qualsiasi altro sink, tramite Kinesis Data Streams (o MSK). Copre la configurazione del produttore, la correttezza Lambda del consumatore, il registro eventi di sola aggiunta + modello di ricostruzione, la gestione della deriva dello schema con SUPER + JSON_PARSE e i trucchi operativi (limiti dei parametri API Redshift Data, polling delle istruzioni asincrone, gestione dei record non elaborabili, retry-and-bisect). Da utilizzare quando l'utente richiede "CDC to Redshift", "stream change data capture", "Aurora CDC", "DSQL CDC", "replica Postgres su S3" o "crea un consumer Lambda per Kinesis CDC". Le specifiche dell'anteprima pubblica di Aurora DSQL sono contrassegnate; il resto è indipendente dalla fonte.
