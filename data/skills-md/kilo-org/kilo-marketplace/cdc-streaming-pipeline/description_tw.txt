透過 Kinesis Data Streams（或 MSK）建立從事務資料庫（Aurora DSQL、Aurora Postgres、RDS）到 Redshift Serverless、S3 或任何其他接收器的即時變更資料擷取管道。涵蓋生產者設定、消費者 Lambda 正確性、僅附加事件日誌 + 重建模式、使用 SUPER + JSON_PARSE 進行模式漂移處理以及操作陷阱（Redshift Data API 參數上限、非同步語句輪詢、有害記錄處理、重試和二分）。當使用者要求「CDC 到 Redshift」、「流更改資料擷取」、「Aurora CDC」、「DSQL CDC」、「Postgres 複製到 S3」或「為 Kinesis CDC 建立 Lambda 使用方」時使用。 Aurora DSQL 公共預覽版細節已標記；其餘的與來源無關。
