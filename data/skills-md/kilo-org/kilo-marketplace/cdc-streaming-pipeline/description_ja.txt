Kinesis Data Streams (または MSK) を介して、トランザクションデータベース (Aurora DSQL、Aurora Postgres、RDS) から Redshift Serverless、S3、またはその他のシンクへのリアルタイム変更データキャプチャパイプラインを構築します。プロデューサーのセットアップ、コンシューマー Lambda の正確性、追加専用のイベント ログと再構築パターン、SUPER + JSON_PARSE によるスキーマ ドリフトの処理、および運用上の注意点 (Redshift Data API パラメーターの上限、非同期ステートメントのポーリング、ポイズン レコードの処理、再試行と二分化) について説明します。ユーザーが「CDC から Redshift」、「ストリーム変更データキャプチャ」、「Aurora CDC」、「DSQL CDC」、「S3 への Postgres レプリケーション」、または「Kinesis CDC 用の Lambda コンシューマーの構築」を要求する場合に使用します。 Aurora DSQL パブリックプレビューの詳細にはフラグが付けられています。残りはソースに依存しません。
