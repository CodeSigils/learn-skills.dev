أنشئ مسارًا لالتقاط بيانات التغيير في الوقت الفعلي من قاعدة بيانات المعاملات (Aurora DSQL، أو Aurora Postgres، أو RDS) إلى Redshift Serverless، أو S3، أو أي مصدر آخر، عبر Kinesis Data Streams (أو MSK). يغطي إعداد المنتج، وصحة Lambda للمستهلك، وسجل أحداث الإلحاق فقط + نمط إعادة البناء، ومعالجة انجراف المخطط باستخدام SUPER + JSON_PARSE، والمشاكل التشغيلية (قبعات معلمات Redshift Data API، واستقصاء البيانات غير المتزامنة، ومعالجة السجلات السامة، وإعادة المحاولة والتقسيم). يُستخدم عندما يطلب المستخدم "CDC to Redshift"، أو "التقاط بيانات تغيير الدفق"، أو "Aurora CDC"، أو "DSQL CDC"، أو "نسخ Postgres إلى S3"، أو "إنشاء مستهلك Lambda لـ Kinesis CDC". يتم وضع علامة على تفاصيل المعاينة العامة لـ Aurora DSQL؛ والباقي لا يعرف المصدر.
