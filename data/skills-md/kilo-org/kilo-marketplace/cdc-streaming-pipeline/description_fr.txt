Créez un pipeline de capture de données modifiées en temps réel à partir d'une base de données transactionnelle (Aurora DSQL, Aurora Postgres, RDS) vers Redshift Serverless, S3 ou tout autre récepteur, via Kinesis Data Streams (ou MSK). Couvre la configuration du producteur, l'exactitude de Lambda du consommateur, le journal des événements en ajout uniquement + le modèle de reconstruction, la gestion des dérives de schéma avec SUPER + JSON_PARSE et les pièges opérationnels (plafonds des paramètres de l'API Redshift Data, interrogation des instructions asynchrones, gestion des enregistrements de poison, nouvelle tentative et bisect). À utiliser lorsque l'utilisateur demande « CDC vers Redshift », « capture de données de modification de flux », « Aurora CDC », « DSQL CDC », « réplication Postgres vers S3 » ou « créer un consommateur Lambda pour Kinesis CDC ». Les spécificités de la version préliminaire publique d'Aurora DSQL sont signalées ; le reste est indépendant de la source.
