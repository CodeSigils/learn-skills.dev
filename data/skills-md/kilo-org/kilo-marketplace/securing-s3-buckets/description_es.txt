Cree y proteja depósitos S3 siguiendo las mejores prácticas de AWS para control de acceso, cifrado, monitoreo y corrección de configuraciones incorrectas. Úselo cuando el usuario desee proteger un depósito nuevo, auditar un depósito existente, corregir un hallazgo de seguridad, configurar el cifrado o habilitar el registro y la supervisión. NO lo use para operaciones generales de datos de S3, configuración de tablas de S3 o descubrimiento de activos de datos existentes.
