Erstellen und sichern Sie S3-Buckets gemäß den Best Practices von AWS für Zugriffskontrolle, Verschlüsselung, Überwachung und Behebung von Fehlkonfigurationen. Verwenden Sie diese Option, wenn der Benutzer einen neuen Bucket sichern, einen vorhandenen Bucket prüfen, einen Sicherheitsbefund beheben, die Verschlüsselung konfigurieren oder Protokollierung und Überwachung aktivieren möchte. NICHT für allgemeine S3-Datenoperationen, die Einrichtung von S3-Tabellen oder das Erkennen vorhandener Datenbestände verwenden.
