Databricks モデルのサービス提供エンドポイントのライフサイクルと運用。 CRUD サービス エンドポイント (CLI または MLflow Deployments クライアント)。 A/B / カナリア デプロイおよびダウンタイムなしのバージョン スワップのためのトラフィック ルーティングを構成します。 OpenAPI スキーマを取得します。ログ、メトリクス、または権限を検査します。 AI ゲートウェイのレート制限を管理します。実行時に Foundation Model API エンドポイントを検出します。エンドポイントを Databricks アプリに統合します。または、オフプラットフォーム クライアント (Vercel AI SDK v6、スタンドアロン Node.js) からストリーミングします。対象外: トレーニング、MLflow 自動ロギング、UC 登録、カスタム PyFunc/ResponsesAgent オーサリング (databricks-ml-training)。ナレッジ アシスタント/スーパーバイザー エージェント (databricks-agent-bricks); MLflow 評価 (databricks-mlflow-evaluation)。
