نموذج Databricks الذي يخدم دورة حياة نقطة النهاية والعمليات. استخدم عندما يُطلب منك: نقاط نهاية خدمة CRUD (عميل CLI أو MLflow Deployments)؛ تكوين توجيه حركة المرور لعمليات النشر A/B/canary ومقايضة الإصدارات بدون توقف؛ استرداد مخططات OpenAPI؛ فحص السجلات أو المقاييس أو الأذونات؛ إدارة حدود معدل بوابة الذكاء الاصطناعي؛ اكتشاف نقاط نهاية Foundation Model API في وقت التشغيل؛ ودمج نقاط النهاية في تطبيقات Databricks؛ أو البث من عملاء خارج النظام الأساسي (Vercel AI SDK v6، Node.js المستقل). ليس من أجل: التدريب، والتسجيل التلقائي لـ MLflow، وتسجيل UC، وتأليف PyFunc/ResponsesAgent المخصص (databricks-ml-training)؛ مساعدو المعرفة / الوكلاء المشرفون (طوب البيانات-الوكيل-الطوب) ؛ تقييم MLflow (تقييم databricks-mlflow).
