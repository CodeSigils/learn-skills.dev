Modèle Databricks servant le cycle de vie et les opérations des points de terminaison. À utiliser lorsque vous y êtes invité : CRUD servant des points de terminaison (client CLI ou MLflow Deployments) ; configurer le routage du trafic pour les déploiements A/B/Canary et les échanges de versions sans temps d'arrêt ; récupérer les schémas OpenAPI ; inspecter les journaux, les métriques ou les autorisations ; gérer les limites de débit d'AI Gateway ; découvrir les points de terminaison de l'API Foundation Model au moment de l'exécution ; intégrer les points de terminaison dans les applications Databricks ; ou diffusez à partir de clients hors plate-forme (Vercel AI SDK v6, Node.js autonome). PAS pour : la formation, la journalisation automatique MLflow, l'enregistrement UC, la création PyFunc/ResponsesAgent personnalisée (databricks-ml-training) ; Assistants de connaissances/agents superviseurs (databricks-agent-bricks) ; Évaluation MLflow (databricks-mlflow-evaluation).
