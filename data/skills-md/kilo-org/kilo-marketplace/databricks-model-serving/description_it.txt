Modello Databricks che serve il ciclo di vita e le operazioni dell'endpoint. Utilizzare quando richiesto per: endpoint di servizio CRUD (client CLI o MLflow Deployments); configurare il routing del traffico per distribuzioni A/B/Canary e scambi di versioni senza tempi di inattività; recuperare schemi OpenAPI; ispezionare registri, parametri o autorizzazioni; gestire i limiti di velocità di AI Gateway; scoprire gli endpoint API Foundation Model in fase di runtime; integrare gli endpoint nelle app Databricks; o eseguire lo streaming da client fuori piattaforma (Vercel AI SDK v6, Node.js autonomo). NON per: training, registrazione automatica MLflow, registrazione UC, creazione PyFunc/ResponsesAgent personalizzata (databricks-ml-training); Assistenti della conoscenza/Agenti supervisori (databricks-agent-bricks); Valutazione MLflow (databricks-mlflow-evaluation).
