透過 Microsoft Graph 設定 Microsoft Entra 代理程式藍圖、BlueprintPrincipals 和每個實例代理身份，並設定 OAuth 2.0 令牌交換（fmi_path、OBO、跨租用戶），包括適用於 AgentID sidecar 的 Microsoft Entra SDK。用於：代理身份藍圖、BlueprintPrincipal、代理 OAuth、fmi_path 令牌交換、代理 OBO、代理的工作負載身份聯合、多語言代理身份驗證、Microsoft.Identity.Web.AgentIdentities。請勿用於：標準 Entra 應用程式註冊（使用 entra-app-registration）、Azure RBAC（使用 azure-rbac）、Microsoft Foundry 代理程式創作（使用 microsoft-foundry）。
