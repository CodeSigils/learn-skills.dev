Fornisci modelli di identità dell'agente Microsoft Entra, BlueprintPrincipal e identità dell'agente per istanza tramite Microsoft Graph e configura lo scambio di token OAuth 2.0 (fmi_path, OBO, cross-tenant) incluso il sidecar Microsoft Entra SDK per AgentID. UTILIZZARE PER: Agent Identity Blueprint, BlueprintPrincipal, agente OAuth, scambio token fmi_path, agente OBO, Federazione delle identità del carico di lavoro per agenti, autenticazione agente poliglotta, Microsoft.Identity.Web.AgentIdentities. NON UTILIZZARE PER: registrazione dell'app Entra standard (usare entra-app-registration), RBAC di Azure (usare azure-rbac), creazione di agenti Microsoft Foundry (usare microsoft-foundry).
