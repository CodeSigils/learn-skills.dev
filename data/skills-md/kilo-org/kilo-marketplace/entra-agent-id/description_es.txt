Aprovisione Microsoft Entra Agent Identity Blueprints, BlueprintPrincipals e identidades de agente por instancia a través de Microsoft Graph, y configure el intercambio de tokens OAuth 2.0 (fmi_path, OBO, cross-tenant), incluido el SDK de Microsoft Entra para el sidecar AgentID. USO PARA: Agent Identity Blueprint, BlueprintPrincipal, agente OAuth, intercambio de tokens fmi_path, agente OBO, Workload Identity Federation para agentes, autenticación de agente políglota, Microsoft.Identity.Web.AgentIdentities. NO UTILIZAR PARA: registro de la aplicación Entra estándar (use entra-app-registration), Azure RBAC (use azure-rbac), creación del agente Microsoft Foundry (use microsoft-foundry).
