توفير مخططات هوية وكيل Microsoft Entra، وBlueprintPrincipals، وهويات الوكيل لكل مثيل عبر Microsoft Graph، وتكوين تبادل الرموز المميزة لـ OAuth 2.0 (fmi_path، وOBO، والمستأجر المتقاطع) بما في ذلك Microsoft Entra SDK لـ AgentID Sidecar. الاستخدام من أجل: مخطط هوية الوكيل، BlueprintPrincipal، وكيل OAuth، تبادل الرمز المميز fmi_path، وكيل OBO، اتحاد هوية حمل العمل للوكلاء، مصادقة الوكيل متعدد اللغات، Microsoft.Identity.Web.AgentIdentities. لا تستخدمه من أجل: تسجيل تطبيق Entra القياسي (استخدم تسجيل التطبيق entra)، وAzure RBAC (استخدم azure-rbac)، وتأليف وكيل Microsoft Foundry (استخدم Microsoft Foundry).
