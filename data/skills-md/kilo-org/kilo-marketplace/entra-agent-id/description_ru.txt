Предоставьте чертежи идентификаторов агента Microsoft Entra, BlueprintPrincipals и идентификаторы агентов для каждого экземпляра через Microsoft Graph, а также настройте обмен токенами OAuth 2.0 (fmi_path, OBO, межклиентский), включая Microsoft Entra SDK для боковой панели AgentID. ИСПОЛЬЗОВАНИЕ ДЛЯ: Blueprint Identity Blueprint, BlueprintPrincipal, OAuth агента, обмена токенами fmi_path, OBO агента, Федерации идентификации рабочей нагрузки для агентов, аутентификации агента-полиглота, Microsoft.Identity.Web.AgentIdentities. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: стандартной регистрации приложения Entra (используйте entra-app-registration), Azure RBAC (используйте azure-rbac), разработки агента Microsoft Foundry (используйте microsoft-foundry).
