Importieren Sie Daten aus S3-Dateien, lokalen Uploads, JDBC-Datenbanken (Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB oder vorhandenen Glue-Katalogtabellen in den AWS Data Lake (Migration). Das Standardziel sind S3-Tabellen. Standard-Iceberg auf einem Allzweck-Bucket wird unterstützt, wenn S3-Tabellen nicht übernommen werden. Behandelt einmalige Ladevorgänge, wiederkehrende Pipelines und Migrationen. Auslöser bei: Daten importieren, Daten laden, aufnehmen, Datenbank synchronisieren, Tabelle migrieren, Daten nach AWS verschieben, Pipeline einrichten, ETL, aus Snowflake abrufen, BigQuery in S3 abfragen, DynamoDB exportieren, CTAS, nach Iceberg konvertieren. Nicht zum Einrichten oder Beheben von Problemen mit Glue-Verbindungen (verwenden Sie „connecting-to-data-source“), zum Erstellen leerer Tabellen (verwenden Sie „creating-data-lake-table“), zum Ausführen von Abfragen (verwenden Sie „querying-data-lake“), zum Suchen von Tabellen anhand von Fuzzy-Namen (verwenden Sie „finding-data-lake-assets“), zur Katalogprüfung (verwenden Sie „exploring-data-catalog“) oder für SaaS-Plattformen wie Salesforce, ServiceNow, SAP, MongoDB, Kafka.
