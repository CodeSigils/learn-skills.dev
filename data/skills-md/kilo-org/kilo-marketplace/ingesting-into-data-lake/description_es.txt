Importe datos al lago de datos de AWS desde archivos S3, cargas locales, bases de datos JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB o tablas de catálogo de Glue existentes (migración). El destino predeterminado son las tablas S3; Se admite Iceberg estándar en un cubo de uso general donde no se adoptan tablas S3. Maneja cargas únicas, canalizaciones recurrentes y migraciones. Activadores de: importar datos, cargar datos, ingerir, sincronizar bases de datos, migrar tablas, mover datos a AWS, configurar canalización, ETL, extraer de Snowflake, consultar BigQuery en S3, exportar DynamoDB, CTAS, convertir a Iceberg. NO lo use para configurar o solucionar problemas de conexiones de Glue (use conexión a fuente de datos), crear tablas vacías (use creación de tabla de lago de datos), ejecutar consultas (use consulta de lago de datos), buscar tablas por nombre difuso (use búsqueda de activos de lago de datos), auditoría de catálogo (use exploración de catálogo de datos) o plataformas SaaS como Salesforce, ServiceNow, SAP, MongoDB, Kafka.
