Importa dati nel data Lake AWS da file S3, caricamenti locali, database JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB o tabelle del catalogo Glue esistenti (migrazione). La destinazione predefinita è S3 Tables; L'Iceberg standard su un bucket per uso generale è supportato laddove non sono adottate le tabelle S3. Gestisce carichi una tantum, pipeline ricorrenti, migrazioni. Trigger su: importazione dati, caricamento dati, acquisizione, sincronizzazione database, migrazione tabella, spostamento dati in AWS, configurazione pipeline, ETL, pull da Snowflake, query BigQuery in S3, esportazione DynamoDB, CTAS, conversione in Iceberg. NON utilizzare per l'impostazione o la risoluzione dei problemi delle connessioni Glue (usa connessione a-data-source), creazione di tabelle vuote (usa creazione-data-lake-tabella), esecuzione di query (usa query-data-lake), ricerca di tabelle per nome fuzzy (usa ricerca-data-lake-assets), audit del catalogo (usa esplorazione-data-catalogo) o piattaforme SaaS come Salesforce, ServiceNow, SAP, MongoDB, Kafka.
