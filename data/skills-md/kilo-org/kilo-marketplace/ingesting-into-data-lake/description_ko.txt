S3 파일, 로컬 업로드, JDBC 데이터베이스(Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB 또는 기존 Glue 카탈로그 테이블(마이그레이션)에서 AWS 데이터 레이크로 데이터를 가져옵니다. 기본 대상은 S3 테이블입니다. S3 테이블이 채택되지 않은 경우 범용 버킷의 표준 Iceberg가 지원됩니다. 일회성 로드, 반복 파이프라인, 마이그레이션을 처리합니다. 트리거 조건: 데이터 가져오기, 데이터 로드, 수집, 데이터베이스 동기화, 테이블 마이그레이션, AWS로 데이터 이동, 파이프라인 설정, ETL, Snowflake에서 가져오기, S3로 BigQuery 쿼리, DynamoDB, CTAS 내보내기, Iceberg로 변환. Glue 연결 설정 또는 문제 해결(데이터 소스에 연결 사용), 빈 테이블 생성(creating-data-lake-table 사용), 쿼리 실행(querying-data-lake 사용), 퍼지 이름으로 테이블 찾기(finding-data-lake-assets 사용), 카탈로그 감사(탐색 데이터 카탈로그 사용) 또는 Salesforce, ServiceNow, SAP, MongoDB, Kafka와 같은 SaaS 플랫폼에는 사용하지 마십시오.
