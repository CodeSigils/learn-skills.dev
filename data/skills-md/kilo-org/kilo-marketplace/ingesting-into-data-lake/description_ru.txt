Импортируйте данные в озеро данных AWS из файлов S3, локальных загрузок, баз данных JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB или существующих таблиц каталога Glue (миграция). Целью по умолчанию являются таблицы S3; стандартный Iceberg в корзине общего назначения поддерживается там, где не используются таблицы S3. Обрабатывает разовые загрузки, повторяющиеся конвейеры и миграции. Запускается при: импорте данных, загрузке данных, приеме, синхронизации базы данных, переносе таблицы, перемещении данных в AWS, настройке конвейера, ETL, извлечении данных из Snowflake, запросе BigQuery в S3, экспорте DynamoDB, CTAS, преобразовании в Iceberg. НЕ используйте для настройки или устранения неполадок соединений Glue (используйте соединение с источником данных), создания пустых таблиц (используйте создание таблицы-data-lake), выполнения запросов (используйте query-data-lake), поиска таблиц по нечеткому имени (используйте find-data-lake-assets), аудита каталога (используйте исследование каталога данных) или платформ SaaS, таких как Salesforce, ServiceNow, SAP, MongoDB, Kafka.
