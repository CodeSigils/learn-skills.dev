قم باستيراد البيانات إلى مستودع بيانات AWS من ملفات S3 أو التحميلات المحلية أو قواعد بيانات JDBC (Oracle أو SQL Server أو PostgreSQL أو MySQL أو RDS أو Aurora) أو Amazon Redshift أو Snowflake أو BigQuery أو DynamoDB أو جداول كتالوج Glue الموجودة (الترحيل). الهدف الافتراضي هو جداول S3؛ يتم دعم Iceberg القياسي في دلو للأغراض العامة حيث لا يتم اعتماد جداول S3. يتعامل مع الأحمال لمرة واحدة، وخطوط الأنابيب المتكررة، والترحيلات. المشغلات: استيراد البيانات، وتحميل البيانات، والاستيعاب، ومزامنة قاعدة البيانات، وترحيل الجدول، ونقل البيانات إلى AWS، وإعداد خط الأنابيب، وETL، والسحب من Snowflake، والاستعلام عن BigQuery إلى S3، وتصدير DynamoDB، وCTAS، والتحويل إلى Iceberg. لا تستخدم لإعداد أو استكشاف أخطاء اتصالات الغراء (استخدم الاتصال بمصدر البيانات)، أو إنشاء جداول فارغة (استخدم إنشاء جدول بحيرة البيانات)، أو تشغيل الاستعلامات (استخدم الاستعلام عن بحيرة البيانات)، أو البحث عن الجداول حسب اسم غامض (استخدم العثور على أصول بحيرة البيانات)، أو تدقيق الكتالوج (استخدم استكشاف كتالوج البيانات)، أو منصات SaaS مثل Salesforce، أو ServiceNow، أو SAP، أو MongoDB، أو Kafka.
