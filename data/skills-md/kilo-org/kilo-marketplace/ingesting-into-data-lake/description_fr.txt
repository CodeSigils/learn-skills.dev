Importez des données dans le lac de données AWS à partir de fichiers S3, de téléchargements locaux, de bases de données JDBC (Oracle, SQL Server, PostgreSQL, MySQL, RDS, Aurora), Amazon Redshift, Snowflake, BigQuery, DynamoDB ou de tables de catalogue Glue existantes (migration). La cible par défaut est les tables S3 ; L'Iceberg standard sur un compartiment à usage général est pris en charge là où les tables S3 ne sont pas adoptées. Gère les charges ponctuelles, les pipelines récurrents et les migrations. Déclencheurs sur : importer des données, charger des données, ingérer, synchroniser la base de données, migrer la table, déplacer les données vers AWS, configurer le pipeline, ETL, extraire de Snowflake, interroger BigQuery dans S3, exporter DynamoDB, CTAS, convertir en Iceberg. Ne PAS utiliser pour configurer ou dépanner les connexions Glue (utilisez la connexion à la source de données), la création de tables vides (utilisez la création de données-lake-table), l'exécution de requêtes (utilisez la requête de données-lake), la recherche de tables par nom flou (utilisez la recherche d'actifs de lac de données), l'audit de catalogue (utilisez l'exploration de catalogue de données) ou des plateformes SaaS comme Salesforce, ServiceNow, SAP, MongoDB, Kafka.
