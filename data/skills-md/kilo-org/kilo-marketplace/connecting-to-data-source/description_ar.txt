قم بإنشاء واستكشاف أخطاء اتصالات AWS Glue بقواعد بيانات JDBC (Oracle وSQL Server وPostgreSQL وMySQL وRDS) وRedshift وSnowflake وBigQuery. يجمع تلميحات الاتصال من المستخدم، ويكتشف الاتصالات الحالية ومرشحي RDS/Redshift، ويسجل بيانات الاعتماد في Secrets Manager أو مصادقة IAM DB، ويكوّن VPC، ويجري الاختبارات. المشغلات: الاتصال بقاعدة البيانات، وإعداد اتصال الغراء، وتسجيل مصدر البيانات، والاتصال بـ Snowflake/BigQuery/RDS، وانتهاء مهلة الاتصال، واختبار الاتصال، واستكشاف أخطاء الاتصال وإصلاحها. لا تستخدم لنقل البيانات (استخدم الدخول إلى بحيرة البيانات)، أو إنشاء الجداول (استخدم إنشاء جدول بحيرة البيانات)، أو الاستعلامات (استخدم الاستعلام عن بحيرة البيانات)، أو استكشاف الكتالوج (استخدم كتالوج استكشاف البيانات)، أو SaaS (Salesforce، ServiceNow، SAP، MongoDB، Kafka).
