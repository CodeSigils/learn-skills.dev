JDBC 데이터베이스(Oracle, SQL Server, PostgreSQL, MySQL, RDS), Redshift, Snowflake 및 BigQuery에 대한 AWS Glue 연결을 생성하고 문제를 해결합니다. 사용자로부터 연결 힌트를 수집하고, 기존 연결 및 RDS/Redshift 후보를 검색하고, Secrets Manager 또는 IAM DB 인증에 자격 증명을 등록하고, VPC를 구성하고, 테스트합니다. 트리거 대상: 데이터베이스 연결, Glue 연결 설정, 데이터 소스 등록, Snowflake/BigQuery/RDS 연결, 연결 시간 초과, 연결 테스트, 연결 문제 해결. 데이터 이동(데이터 레이크로 수집 사용), 테이블 생성(데이터 레이크 테이블 생성 사용), 쿼리(데이터 레이크 쿼리 사용), 카탈로그 탐색(데이터 카탈로그 탐색 사용) 또는 SaaS(Salesforce, ServiceNow, SAP, MongoDB, Kafka)에는 사용하지 마십시오.
