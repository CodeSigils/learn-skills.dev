خبرة معالجة تدفق Apache Flink لإجراء حسابات ذات حالة عبر التدفقات المحدودة وغير المحدودة. يُستخدم عندما يذكر المستخدم Flink، أو Flink SQL، أو Table API، أو DataStream API، أو CDC، أو خطوط أنابيب Kafka-to-Flink، أو نقاط التفتيش، أو نقاط الحفظ، أو العلامات المائية، أو windows، أو Flink Kubernetes Operator، أو تكاملات Flink مع Iceberg، أو Paimon، أو Fluss.
