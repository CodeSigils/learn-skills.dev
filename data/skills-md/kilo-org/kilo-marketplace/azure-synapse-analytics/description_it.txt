Conoscenza approfondita dello sviluppo di Azure Synapse Analytics, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, architettura e modelli di progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare quando si lavora con pool SQL Synapse, pool Spark, Synapse Link, PolyBase ELT o integrazioni Cosmos DB e altre attività di sviluppo correlate ad Azure Synapse Analytics. Non per Azure Data Factory (usare azure-data-factory), Esplora dati di Azure (usare azure-data-explorer), Azure Databricks (usare azure-databricks), Azure HDInsight (usare azure-hdinsight).
