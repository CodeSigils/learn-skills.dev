Экспертные знания для разработки Azure Synapse Analytics, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при работе с пулами Synapse SQL, пулами Spark, интеграциями Synapse Link, PolyBase ELT или Cosmos DB, а также с другими задачами разработки, связанными с Azure Synapse Analytics. Не для фабрики данных Azure (используйте azure-data-factory), Azure Data Explorer (используйте azure-data-explorer), Azure Databricks (используйте azure-databricks), Azure HDInsight (используйте azure-hdinsight).
