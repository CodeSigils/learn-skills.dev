Connaissance approfondie du développement d'Azure Synapse Analytics, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lorsque vous travaillez avec des pools Synapse SQL, des pools Spark, des intégrations Synapse Link, PolyBase ELT ou Cosmos DB et d'autres tâches de développement liées à Azure Synapse Analytics. Pas pour Azure Data Factory (utilisez azure-data-factory), Azure Data Explorer (utilisez azure-data-explorer), Azure Databricks (utilisez azure-databricks), Azure HDInsight (utilisez azure-hdinsight).
