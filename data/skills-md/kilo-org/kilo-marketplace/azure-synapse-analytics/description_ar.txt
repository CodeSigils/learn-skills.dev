معرفة الخبراء لتطوير Azure Synapse Analytics بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند العمل مع مجموعات Synapse SQL، أو مجموعات Spark، أو Synapse Link، أو PolyBase ELT، أو عمليات تكامل Cosmos DB، ومهام التطوير الأخرى ذات الصلة بـ Azure Synapse Analytics. ليس لـ Azure Data Factory (استخدم azure-data-factory)، وAzure Data Explorer (استخدم azure-data-explorer)، وAzure Databricks (استخدم azure-databricks)، وAzure HDInsight (استخدم azure-hdinsight).
