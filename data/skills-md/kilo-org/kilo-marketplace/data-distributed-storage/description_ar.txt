استخدم هذه المهارة عند تصميم التخزين الموزع لـ HDFS أو S3 أو ADLS أو GCS أو MinIO أو NFS أو أي نظام ملفات موزع لأحمال عمل البيانات. تفرض هذه المهارة ما يلي: اختيار الواجهة الخلفية للتخزين، ومتانة البيانات ونسخها، واختيار تنسيق الملف، والتقسيم والضغط، وسياسات دورة الحياة، وتقسيم طبقات التخزين، وتحسين التكلفة. لا تستخدمه مع: محركات تخزين قاعدة البيانات، أو ضبط نظام الملفات المحلي، أو شبكات توصيل المحتوى.
