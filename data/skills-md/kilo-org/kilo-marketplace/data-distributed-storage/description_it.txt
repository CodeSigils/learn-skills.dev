Utilizza questa competenza durante la progettazione dello storage distribuito per HDFS, S3, ADLS, GCS, MinIO, NFS o qualsiasi file system distribuito per carichi di lavoro di dati. Questa competenza applica: selezione del backend di archiviazione, durabilità e replica dei dati, selezione del formato di file, partizionamento e compressione, policy del ciclo di vita, suddivisione in livelli di archiviazione e ottimizzazione dei costi. NON utilizzare per: motori di archiviazione di database, ottimizzazione del file system locale o reti di distribuzione di contenuti.
