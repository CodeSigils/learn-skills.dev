Eine Fähigkeit zum Abfragen von Tableau-Datenquellen, der „letzten Meile“ der Analyse in einer Organisation. Wenn Geschäftsanwender an Unternehmensdaten denken, denken sie oft an eine Visualisierung oder einen Datensatz auf der BI-Plattform, der mit nützlicher Semantik auf ihre Bedürfnisse zugeschnitten ist, statt an Rohdaten in einem Warehouse.
