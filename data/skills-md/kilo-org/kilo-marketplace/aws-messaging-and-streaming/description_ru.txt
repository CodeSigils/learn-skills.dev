Руководства по использованию сервисов обмена сообщениями и потоковой передачи AWS. Охватывает Amazon SQS, Amazon SNS, Amazon EventBridge, Amazon MQ, Amazon Kinesis Data Streams, Amazon Data Firehose, Amazon Managed Service для Apache Flink и Amazon Managed Streaming для Apache Kafka (MSK). Используйте при реализации шаблонов обмена сообщениями и потоковой передачи.
