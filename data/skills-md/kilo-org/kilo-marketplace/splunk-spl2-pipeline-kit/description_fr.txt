Rendu et lint des modèles de pipeline SPL2 réutilisables pour Cisco Data Fabric, Splunk Ingest Processor et Edge Processor, y compris le routage, la rédaction, l'échantillonnage, les recherches, les métriques, l'OCSF, le décryptage, les statistiques, les modèles personnalisés, la compatibilité SPL vers SPL2 et les contrôles de migration PCRE2. À utiliser lorsque l'utilisateur a besoin de création de pipeline SPL2, de révision de conversion, de linting de compatibilité ou de modèles partagés pour les flux de travail du processeur d'ingestion ou du processeur Edge, y compris les demandes de gestion de pipeline Cisco Data Fabric ou de télémétrie qui nécessitent une logique de pipeline SPL2 réutilisable.
