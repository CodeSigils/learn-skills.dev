Направляет операции, связанные со Snowflake, в Cortex Code CLI для получения специализированной экспертизы Snowflake. Используйте, когда пользователь спрашивает о базах данных Snowflake, хранилищах данных, SQL-запросах в Snowflake, функциях Cortex AI, Snowpark, динамических таблицах, управлении данными в Snowflake, безопасности Snowflake или явно упоминает «Cortex». НЕ используйте для общего программирования, операций с локальными файлами, баз данных, не относящихся к Snowflake, веб-разработки или инфраструктурных задач, не связанных со Snowflake.
