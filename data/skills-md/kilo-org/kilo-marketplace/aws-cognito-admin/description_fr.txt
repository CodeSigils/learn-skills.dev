Administration du pool d'utilisateurs Cognito : recherchez des utilisateurs, confirmez les comptes, réinitialisez les mots de passe, mettez à jour les attributs personnalisés, désactivez/activez les comptes et décrivez la configuration du pool. Découvre les groupes d’utilisateurs au moment de l’exécution. Déclenchez sur « rechercher un utilisateur », « Cognito », « réinitialiser le mot de passe », « désactiver un compte », « corriger l'abonnement » ou /aws-cognito-admin.
