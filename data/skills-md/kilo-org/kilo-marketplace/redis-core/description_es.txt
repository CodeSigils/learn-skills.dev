Guía de modelado principal de Redis: elija la estructura de datos correcta (cadena, hash, lista, conjunto, conjunto ordenado, JSON, secuencia, conjunto de vectores) y utilice nombres de clave consistentes separados por dos puntos. Úselo al diseñar un modelo de datos de Redis, almacenar en caché objetos, decidir entre Hash y JSON, crear contadores, tablas de clasificación, conjuntos de membresía o almacenes de sesiones, o al revisar/limpiar nombres de claves de Redis.
