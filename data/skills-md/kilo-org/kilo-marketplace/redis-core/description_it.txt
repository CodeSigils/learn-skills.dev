Guida alla modellazione Core Redis: scegli la struttura dati corretta (stringa, hash, elenco, set, set ordinato, JSON, flusso, set vettoriale) e utilizza nomi di chiavi coerenti separati da due punti. Da utilizzare durante la progettazione di un modello di dati Redis, la memorizzazione nella cache di oggetti, la decisione tra Hash e JSON, la creazione di contatori, classifiche, set di appartenenze o archivi di sessioni oppure durante la revisione/pulizia della denominazione delle chiavi Redis.
