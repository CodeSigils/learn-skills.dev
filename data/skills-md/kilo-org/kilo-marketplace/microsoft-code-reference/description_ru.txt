Используйте всякий раз, когда пользователь пишет, отлаживает или просматривает код, который затрагивает какой-либо Microsoft SDK, библиотеку .NET, клиентскую библиотеку Azure или Microsoft API, даже если он не запрашивает «ссылку». Отлавливает галлюцинированные методы, неправильные сигнатуры и устаревшие шаблоны. Если задача предполагает создание или исправление кода, связанного с Microsoft, это правильный навык.
