ابحث عن نماذج التعليمات البرمجية العاملة، وتحقق من توقيعات واجهة برمجة التطبيقات (API)، وأصلح أخطاء Microsoft SDK باستخدام المستندات الرسمية. يُستخدم عندما يقوم المستخدم بكتابة أو تصحيح الأخطاء أو مراجعة التعليمات البرمجية التي تلامس أي Microsoft SDK أو مكتبة .NET أو مكتبة عميل Azure أو Microsoft API - حتى لو لم يطلبوا "مرجعًا". يمسك الأساليب المهلوسة والتوقيعات الخاطئة والأنماط المهملة. إذا كانت المهمة تتضمن إنتاج أو إصلاح تعليمات برمجية متعلقة بشركة Microsoft، فهذه هي المهارة المناسبة.
