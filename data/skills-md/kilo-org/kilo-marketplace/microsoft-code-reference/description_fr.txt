Recherchez des exemples de code fonctionnel, vérifiez les signatures d'API et corrigez les erreurs du SDK Microsoft à l'aide de documents officiels. À utiliser chaque fois que l'utilisateur écrit, débogue ou révise du code qui touche un SDK Microsoft, une bibliothèque .NET, une bibliothèque client Azure ou une API Microsoft, même s'il ne demande pas de « référence ». Détecte les méthodes hallucinées, les signatures erronées et les modèles obsolètes. Si la tâche implique de produire ou de corriger du code lié à Microsoft, c'est la bonne compétence.
