Finden Sie funktionierende Codebeispiele, überprüfen Sie API-Signaturen und beheben Sie Microsoft SDK-Fehler mithilfe offizieller Dokumente. Verwenden Sie es immer dann, wenn der Benutzer Code schreibt, debuggt oder überprüft, der ein Microsoft SDK, eine .NET-Bibliothek, eine Azure-Clientbibliothek oder eine Microsoft-API berührt – auch wenn er nicht nach einer „Referenz“ fragt. Erkennt halluzinierte Methoden, falsche Signaturen und veraltete Muster. Wenn die Aufgabe darin besteht, Microsoft-bezogenen Code zu erstellen oder zu reparieren, ist dies die richtige Fähigkeit.
