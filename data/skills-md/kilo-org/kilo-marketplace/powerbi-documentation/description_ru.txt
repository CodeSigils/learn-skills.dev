Создавайте стандартизированную документацию для семантических моделей и отчетов Power BI. Используйте, когда пользователь запрашивает документацию для проекта Power BI, семантической модели или отчета (например, «задокументировать эту модель», «создать документацию для этого проекта Power BI», «создать документацию»). Этот навык работает с сервером powerbi-modeling-mcp для извлечения метаданных модели и создания профессиональных документов Word.
