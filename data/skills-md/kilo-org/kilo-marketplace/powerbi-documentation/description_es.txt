Cree documentación estandarizada para modelos e informes semánticos de Power BI. Úselo cuando el usuario solicita documentación para un proyecto, modelo semántico o informe de Power BI (por ejemplo, "documentar este modelo", "crear documentación para este proyecto de Power BI", "generar documentación"). Esta habilidad funciona con el servidor powerbi-modeling-mcp para extraer metadatos del modelo y generar documentos de Word profesionales.
