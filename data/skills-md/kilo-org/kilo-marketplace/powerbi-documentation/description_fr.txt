Créez une documentation standardisée pour les modèles sémantiques et les rapports Power BI. À utiliser lorsque l'utilisateur demande de la documentation pour un projet Power BI, un modèle sémantique ou un rapport (par exemple, « documenter ce modèle », « créer une documentation pour ce projet Power BI », « générer de la documentation »). Cette compétence fonctionne avec le serveur powerbi-modeling-mcp pour extraire les métadonnées du modèle et générer des documents Word professionnels.
