Crea documentazione standardizzata per modelli semantici e report di Power BI. Utilizzare quando l'utente richiede la documentazione per un progetto Power BI, un modello semantico o un report (ad esempio, "documenta questo modello", "crea documentazione per questo progetto Power BI", "genera documentazione"). Questa competenza funziona con il server powerbi-modeling-mcp per estrarre metadati del modello e generare documenti Word professionali.
