当用户拥有表格数据（pandas DataFrame、parquet、csv、Arrow、json）并想要过滤、分组、聚合、联接或加速慢速 pandas 时使用。提供 chDB DataStore — 相同的 pandas API，底层为 ClickHouse 引擎。还可以处理从 S3、MySQL、PostgreSQL、MongoDB、ClickHouse Cloud、Iceberg、Delta Lake 作为 DataFrame 的读取以及跨源连接。触发时间：用户提及 DataFrame、parquet、csv、“fast pandas”、“speed up pandas”或跨源 DataFrame 连接；用户导入“chdb.datastore”或“from datastore import DataStore”。对于原始 SQL 语法（改为使用 chdb-sql）、ClickHouse 服务器管理或非 Python DataStore API 工作，请跳过此技能。
