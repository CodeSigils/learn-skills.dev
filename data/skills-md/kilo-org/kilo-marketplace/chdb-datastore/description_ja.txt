ユーザーが表形式のデータ (pandas DataFrame、parquet、csv、Arrow、json) を持っていて、遅い pandas をフィルター、グループ化、集計、結合、または高速化したい場合に使用します。 chDB DataStore を提供します。同じ pandas API、その下に ClickHouse エンジンがあります。 S3、MySQL、PostgreSQL、MongoDB、ClickHouse Cloud、Iceberg、Delta Lake からの DataFrame としての読み取りや、ソース間での結合も処理します。トリガーされるタイミング: ユーザーが DataFrame、parquet、csv、「高速パンダ」、「高速パンダ」、またはクロスソース DataFrame 結合に言及した場合。ユーザーは `chdb.datastore` または `from datastore import DataStore` をインポートします。生の SQL 構文 (代わりに chdb-sql を使用)、ClickHouse サーバー管理、または Python 以外の DataStore API 作業の場合は、このスキルをスキップしてください。
