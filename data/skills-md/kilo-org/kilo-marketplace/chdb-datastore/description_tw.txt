當使用者擁有表格資料（pandas DataFrame、parquet、csv、Arrow、json）並想要過濾、分組、聚合、聯接或加速慢速 pandas 時使用。提供 chDB DataStore — 相同的 pandas API，底層為 ClickHouse 引擎。也可以處理從 S3、MySQL、PostgreSQL、MongoDB、ClickHouse Cloud、Iceberg、Delta Lake 作為 DataFrame 的讀取以及跨來源連接。觸發時間：使用者提及 DataFrame、parquet、csv、「fast pandas」、「speed up pandas」或跨來源 DataFrame 連線；使用者匯入「chdb.datastore」或「from datastore import DataStore」。對於原始 SQL 語法（改為使用 chdb-sql）、ClickHouse 伺服器管理或非 Python DataStore API 工作，請跳過此技能。
