Utilizzare quando l'utente dispone di dati tabulari (panda DataFrame, parquet, csv, Arrow, json) e desidera filtrare, raggruppare, aggregare, unire o accelerare i panda lenti. Fornisce chDB DataStore: stessa API Panda, motore ClickHouse sottostante. Gestisce anche la lettura da S3, MySQL, PostgreSQL, MongoDB, ClickHouse Cloud, Iceberg, Delta Lake come DataFrames e l'unione tra origini. ATTIVA quando: l'utente menziona DataFrame, parquet, csv, "panda veloci", "panda velocizzati" o join DataFrame tra sorgenti; l'utente importa "chdb.datastore" o "dal datastore importa DataStore". SALTA questa competenza per la sintassi SQL grezza (utilizza invece chdb-sql), l'amministrazione del server ClickHouse o il lavoro API DataStore non Python.
