À utiliser lorsque l'utilisateur dispose de données tabulaires (pandas DataFrame, parquet, csv, Arrow, json) et souhaite filtrer, regrouper, agréger, joindre ou accélérer les pandas lents. Fournit chDB DataStore - même API pandas, moteur ClickHouse en dessous. Gère également la lecture de S3, MySQL, PostgreSQL, MongoDB, ClickHouse Cloud, Iceberg, Delta Lake en tant que DataFrames et la jonction entre sources. DÉCLENCHEMENT lorsque : l'utilisateur mentionne DataFrame, parquet, csv, "fast pandas", "speed up pandas" ou des jointures DataFrame multi-sources ; l'utilisateur importe `chdb.datastore` ou `from datastore import DataStore`. Ignorez cette compétence pour la syntaxe SQL brute (utilisez plutôt chdb-sql), l'administration du serveur ClickHouse ou le travail de l'API DataStore non Python.
