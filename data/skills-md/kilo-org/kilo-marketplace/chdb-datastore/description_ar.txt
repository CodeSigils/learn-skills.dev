يُستخدم عندما يكون لدى المستخدم بيانات جدولية (pandas DataFrame أو parquet أو csv أو Arrow أو json) ويريد تصفية الباندا البطيئة أو تجميعها أو تجميعها أو الانضمام إليها أو تسريعها. يوفر chDB DataStore - نفس واجهة برمجة تطبيقات الباندا، ومحرك ClickHouse الموجود أسفلها. يتعامل أيضًا مع القراءة من S3 وMySQL وPostgreSQL وMongoDB وClickHouse Cloud وIceberg وDelta Lake كإطارات بيانات والانضمام عبر المصادر. يتم تشغيله عندما: يذكر المستخدم DataFrame أو parquet أو csv أو "fast pandas" أو "تسريع الباندا" أو انضمام DataFrame عبر المصدر؛ يقوم المستخدم باستيراد "chdb.datastore" أو "من مخزن البيانات استيراد DataStore". تخطي هذه المهارة بالنسبة إلى بناء جملة SQL الأولي (استخدم chdb-sql بدلاً من ذلك)، أو إدارة خادم ClickHouse، أو العمل غير التابع لـPython DataStore API.
