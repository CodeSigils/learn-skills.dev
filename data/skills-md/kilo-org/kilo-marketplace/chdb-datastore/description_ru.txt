Используйте, когда у пользователя есть табличные данные (Pandas DataFrame, Parquet, CSV, Arrow, JSON) и он хочет фильтровать, группировать, агрегировать, объединять или ускорять медленные панды. Предоставляет хранилище данных chDB — тот же API pandas, под которым находится движок ClickHouse. Также обрабатывает чтение из S3, MySQL, PostgreSQL, MongoDB, ClickHouse Cloud, Iceberg, Delta Lake как DataFrames и объединение между источниками. ТРИГГЕР, когда: пользователь упоминает DataFrame, паркет, csv, «быстрые панды», «ускорить панды» или объединения DataFrame между исходными кодами; пользователь импортирует `chdb.datastore` или `из хранилища данных импортировать DataStore`. ПРОПУСТИТЕ этот навык для необработанного синтаксиса SQL (вместо этого используйте chdb-sql), администрирования сервера ClickHouse или работы с API DataStore, отличным от Python.
