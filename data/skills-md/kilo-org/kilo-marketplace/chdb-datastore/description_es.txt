Úselo cuando el usuario tenga datos tabulares (pandas DataFrame, parquet, csv, Arrow, json) y quiera filtrar, agrupar, agregar, unir o acelerar pandas lentos. Proporciona chDB DataStore: la misma API de pandas, motor ClickHouse debajo. También maneja la lectura de S3, MySQL, PostgreSQL, MongoDB, ClickHouse Cloud, Iceberg, Delta Lake como DataFrames y la unión entre fuentes. DISPARAR cuando: el usuario menciona DataFrame, parquet, csv, "pandas rápidos", "acelerar pandas" o uniones de DataFrame de fuentes cruzadas; el usuario importa `chdb.datastore` o `desde el almacén de datos import DataStore`. OMITIR esta habilidad para la sintaxis SQL sin formato (use chdb-sql en su lugar), la administración del servidor ClickHouse o el trabajo de la API DataStore que no sea Python.
