Services de stockage Azure, notamment le stockage Blob, les partages de fichiers, le stockage de files d'attente, le stockage de tables et Data Lake. Répond aux questions sur les niveaux d'accès au stockage (chaud, froid, froid, archive), quand utiliser chaque niveau et la comparaison des niveaux. Fournit le stockage d'objets, les partages de fichiers SMB, la messagerie asynchrone, la valeur-clé NoSQL et l'analyse Big Data. Inclut la gestion du cycle de vie. UTILISER POUR : stockage d'objets blob, partages de fichiers, stockage de files d'attente, stockage de tables, lac de données, téléchargement de fichiers, téléchargement d'objets blob, comptes de stockage, niveaux d'accès, niveaux de stockage, archive chaude/froide, comparaison des niveaux de stockage, quand utiliser les niveaux de stockage, gestion du cycle de vie, concepts de stockage Azure. NE PAS UTILISER POUR : bases de données SQL, Cosmos DB (utilisez Azure-prepare), messagerie avec Event Hubs ou Service Bus (utilisez Azure-messaging).
