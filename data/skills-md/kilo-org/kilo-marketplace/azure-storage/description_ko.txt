Blob Storage, 파일 공유, Queue Storage, Table Storage 및 Data Lake를 포함한 Azure Storage 서비스입니다. 스토리지 액세스 계층(핫, 쿨, 콜드, 아카이브), 각 계층 사용 시기 및 계층 비교에 대한 질문에 답변합니다. 객체 스토리지, SMB 파일 공유, 비동기 메시징, NoSQL 키-값 및 빅 데이터 분석을 제공합니다. 수명주기 관리가 포함됩니다. 사용 대상: Blob Storage, 파일 공유, 큐 스토리지, 테이블 스토리지, 데이터 레이크, 파일 업로드, Blob 다운로드, 스토리지 계정, 액세스 계층, 스토리지 계층, 핫 쿨 콜드 아카이브, 스토리지 계층 비교, 스토리지 계층 사용 시기, 수명 주기 관리, Azure Storage 개념. 사용하지 마십시오: SQL 데이터베이스, Cosmos DB(azure-prepare 사용), Event Hubs 또는 Service Bus를 통한 메시징(azure-messaging 사용).
