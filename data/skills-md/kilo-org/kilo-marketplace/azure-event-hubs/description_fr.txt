Connaissance approfondie du développement d'Azure Event Hubs, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation de clients/flux Kafka, du SDK .NET, de Flink/Spark, de géo-DR/réplication ou de la mise à l'échelle automatique dans Event Hubs et d'autres tâches de développement liées à Azure Event Hubs. Pas pour Azure Service Bus (utilisez azure-service-bus), Azure Event Grid (utilisez azure-event-grid), Azure Notification Hubs (utilisez azure-notification-hubs), Azure Stream Analytics (utilisez azure-stream-analytics).
