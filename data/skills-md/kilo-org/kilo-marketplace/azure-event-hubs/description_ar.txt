معرفة الخبراء بتطوير Azure Event Hubs بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام عملاء/تدفقات Kafka، أو .NET SDK، أو Flink/Spark، أو Geo-DR/النسخ المتماثل، أو مقياس التضخيم التلقائي في مراكز الأحداث، ومهام التطوير الأخرى ذات الصلة بمراكز أحداث Azure. ليس لـ Azure Service Bus (استخدم azure-service-bus)، وAzure Event Grid (استخدم azure-event-grid)، ومراكز إعلام Azure (استخدم مراكز إعلام azure)، وAzure Stream Analytics (استخدم تحليلات تدفق azure).
