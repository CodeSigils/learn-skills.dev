Azure 事件中心開發的專業知識，包括故障排除、最佳實踐、決策、體系結構和設計模式、限制和配額、安全性、配置、整合和編碼模式以及部署。在事件中心中使用 Kafka 用戶端/流、.NET SDK、Flink/Spark、異地災難復原/複製或自動膨脹縮放以及其他 Azure 事件中心相關開發任務時使用。不適用於 Azure 服務匯流排（使用 azure-service-bus）、Azure 事件網格（使用 azure-event-grid）、Azure 通知中心（使用 azure-notification-hubs）、Azure 流程分析（使用 azure-stream-analytics）。
