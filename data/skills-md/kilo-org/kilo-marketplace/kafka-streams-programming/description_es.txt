Diseñe, cree y depure aplicaciones Kafka Streams (procesamiento de secuencias integrado en JVM). Úselo cuando el usuario mencione KStream, KTable, topología, TopologyTestDriver, StreamsBuilder, consultas interactivas, GlobalKTable, uniones/ventanas/agregaciones o problemas de depuración (reequilibrio, almacenes de estado, retrasos, errores de deserialización). Úselo también cuando el usuario quiera optimizar Kafka Streams para WarpStream o ajustar la configuración del cliente Kafka Streams para WarpStream. NO active para Flink, conectores, CDC o simple productor/consumidor.
