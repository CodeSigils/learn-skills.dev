تصميم وبناء وتصحيح تطبيقات Kafka Streams (معالجة التدفق المضمنة في JVM). يُستخدم عندما يذكر المستخدم KStream، أو KTable، أو الهيكل، أو TopologyTestDriver، أو StreamsBuilder، أو الاستعلامات التفاعلية، أو GlobalKTable، أو عمليات الانضمام/النوافذ/التجميعات، أو مشكلات تصحيح الأخطاء (إعادة التوازن، أو مخازن الحالة، أو التأخر، أو أخطاء إلغاء التسلسل). يُستخدم أيضًا عندما يريد المستخدم تحسين Kafka Streams لـ WarpStream أو ضبط تكوين عميل Kafka Streams لـ WarpStream. لا تقم بتشغيل Flink أو الموصلات أو CDC أو المنتج/المستهلك العادي.
