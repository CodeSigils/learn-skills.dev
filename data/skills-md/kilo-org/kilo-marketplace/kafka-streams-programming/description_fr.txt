Architectez, créez et déboguez des applications Kafka Streams (traitement de flux intégré à la JVM). À utiliser lorsque l'utilisateur mentionne KStream, KTable, la topologie, TopologyTestDriver, StreamsBuilder, les requêtes interactives, GlobalKTable, les jointures/fenêtres/agrégations ou les problèmes de débogage (rééquilibrage, magasins d'état, décalage, erreurs de désérialisation). À utiliser également lorsque l'utilisateur souhaite optimiser Kafka Streams pour WarpStream ou régler la configuration du client Kafka Streams pour WarpStream. Ne déclenchez PAS pour Flink, les connecteurs, le CDC ou le simple producteur/consommateur.
