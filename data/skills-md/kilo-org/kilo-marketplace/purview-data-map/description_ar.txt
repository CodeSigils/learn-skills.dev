إرشادات لـ Microsoft Purview Data Map - الأساس الذي يقوم بمسح مصادر البيانات وتعيينها عبر المناطق متعددة السحابية والمحلية لدعم الفهرسة والحوكمة. يغطي تسجيل المصدر، وأوقات تشغيل التكامل (المُدارة مقابل الاستضافة الذاتية)، ومجموعات قواعد الفحص، والتصنيفات، والمجموعات، والتحكم في التكاليف. متى: عرض خريطة البيانات، ومسح مصادر البيانات، وتسجيل مصدر البيانات، واكتشاف البيانات، ووقت تشغيل التكامل، وتعيين بيانات المؤسسة، ومسح البيانات متعددة السحابات، وفحص التصنيف، والمجموعات، والمسرد.
