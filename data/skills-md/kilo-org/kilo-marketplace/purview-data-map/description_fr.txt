Conseils pour Microsoft Purview Data Map - la base qui analyse et mappe les sources de données dans les domaines multicloud et sur site pour alimenter le catalogage et la gouvernance. Couvre l'enregistrement des sources, les environnements d'exécution d'intégration (gérés ou auto-hébergés), les ensembles de règles d'analyse, les classifications, les collections et le contrôle des coûts. QUAND : Purview Data Map, analyse des sources de données, enregistrement de la source de données, découverte des données, runtime d'intégration, cartographie des données d'entreprise, analyse des données multicloud, analyse de classification, collections, glossaire.
