Guía para Microsoft Purview Data Map: la base que escanea y asigna fuentes de datos en entornos multinube y locales para potenciar la catalogación y la gobernanza. Cubre el registro de origen, los tiempos de ejecución de integración (administrados o autohospedados), conjuntos de reglas de escaneo, clasificaciones, colecciones y control de costos.
