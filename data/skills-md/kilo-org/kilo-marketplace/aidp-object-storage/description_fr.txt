Lisez et écrivez le stockage d'objets OCI de manière native à partir d'un bloc-notes AIDP à l'aide du schéma d'URI `oci://`. À utiliser lorsque l'utilisateur mentionne OCI Object Storage, « oci:// », des volumes externes, des tables externes sauvegardées par Object Storage, des fichiers CSV/Parquet/JSON/Delta dans un compartiment, ou souhaite transférer des données dans des compartiments OCI. L'authentification est implicite via l'identité IAM de l'espace de travail — aucune clé dans le notebook.
