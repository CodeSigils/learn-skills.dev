Lea y escriba almacenamiento de objetos OCI de forma nativa desde un cuaderno AIDP utilizando el esquema URI `oci://`. Úselo cuando el usuario mencione OCI Object Storage, "oci://", volúmenes externos, tablas externas respaldadas por Object Storage, archivos CSV/Parquet/JSON/Delta en un depósito o desee obtener datos en depósitos OCI. La autenticación está implícita a través de la identidad IAM del espacio de trabajo: no hay claves en el cuaderno.
