Lesen und schreiben Sie OCI Object Storage nativ aus einem AIDP-Notebook unter Verwendung des URI-Schemas „oci://“. Verwenden Sie diese Option, wenn der Benutzer OCI Object Storage, „oci://“, externe Volumes, externe Tabellen, die durch Object Storage unterstützt werden, CSV/Parquet/JSON/Delta-Dateien in einem Bucket erwähnt oder Daten in OCI-Buckets landen möchte. Die Authentifizierung erfolgt implizit über die IAM-Identität des Arbeitsbereichs – keine Schlüssel im Notebook.
