Чтение и запись объектного хранилища OCI непосредственно из записной книжки AIDP с использованием схемы URI `oci://`. Используйте, когда пользователь упоминает объектное хранилище OCI, «oci://», внешние тома, внешние таблицы, поддерживаемые объектным хранилищем, файлы CSV/Parquet/JSON/Delta в корзине или хочет поместить данные в корзины OCI. Аутентификация осуществляется неявно через идентификатор IAM рабочей области — в записной книжке нет ключей.
