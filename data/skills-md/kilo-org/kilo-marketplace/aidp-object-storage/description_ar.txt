يمكنك قراءة وكتابة OCI Object Storage محليًا من دفتر ملاحظات AIDP باستخدام مخطط URI `oci://`. يُستخدم عندما يذكر المستخدم OCI Object Storage، أو "oci://"، أو وحدات التخزين الخارجية، أو الجداول الخارجية المدعومة بواسطة Object Storage، أو ملفات CSV/Parquet/JSON/Delta في مجموعة، أو يريد وضع البيانات في مجموعات OCI. المصادقة ضمنية عبر هوية IAM الخاصة بمساحة العمل - لا توجد مفاتيح في دفتر الملاحظات.
