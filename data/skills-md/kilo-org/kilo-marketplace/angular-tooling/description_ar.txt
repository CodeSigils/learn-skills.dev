استخدم Angular CLI وأدوات التطوير بشكل فعال في مشاريع Angular v20+. يُستخدم لإعداد المشروع وإنشاء التعليمات البرمجية والبناء والاختبار والتكوين. مشغلات عند إنشاء مشاريع جديدة، أو إنشاء مكونات/خدمات/وحدات، أو تكوين البنيات، أو تشغيل الاختبارات، أو تحسين بنيات الإنتاج. لا تستخدم أوامر مساحة عمل Nx، أو تكوينات Webpack المخصصة، أو أنظمة بناء CLI غير Angular مثل Vite المستقل أو الاستخدام المباشر.
