Utilice Angular CLI y herramientas de desarrollo de manera efectiva en proyectos Angular v20+. Úselo para la configuración de proyectos, generación de código, construcción, pruebas y configuración. Activadores para crear nuevos proyectos, generar componentes/servicios/módulos, configurar compilaciones, ejecutar pruebas u optimizar compilaciones de producción. No lo use para comandos del espacio de trabajo de Nx, configuraciones personalizadas de Webpack o sistemas de compilación de CLI que no sean de Angular, como Vite independiente o uso directo de esbuild.
