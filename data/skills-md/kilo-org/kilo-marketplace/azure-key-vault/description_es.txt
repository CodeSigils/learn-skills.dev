Guía para Azure Key Vault: almacenamiento y administración segura de secretos, claves y certificados con RBAC, aislamiento de red, acceso a identidades administradas, protección contra eliminación/purga temporal y rotación. Cubre cuándo usar Key Vault estándar frente a Managed HSM (FIPS 140-3 nivel 3), el principio de radio de explosión de un almacén por aplicación y referencias de Key Vault en App Service/Funciones. CUÁNDO: Azure Key Vault, almacenar secretos, administrar certificados, claves de cifrado, rotación de secretos, Key Vault RBAC, protección de purga, eliminación temporal, Key Vault de punto final privado, secretos de acceso a identidades administradas, HSM administrado, referencias de Key Vault, BYOK CMK. NO LO USE para el diseño de autoridad de certificación (use pki-design), credenciales de la aplicación entra únicamente (use entra-id) o topología de red PaaS (use azure-network-security-design).
