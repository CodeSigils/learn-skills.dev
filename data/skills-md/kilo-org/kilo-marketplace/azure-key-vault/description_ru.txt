Руководство по Azure Key Vault — безопасное хранение и управление секретами, ключами и сертификатами с помощью RBAC, сетевой изоляции, управляемого доступа к удостоверениям, защиты от обратимого удаления/очистки и ротации. Описывает, когда следует использовать стандартное Key Vault или управляемый HSM (FIPS 140-3, уровень 3), принцип радиуса взрыва «одно хранилище для каждого приложения» и ссылки на Key Vault в Службе приложений и функциях. КОГДА: Azure Key Vault, хранение секретов, управление сертификатами, ключи шифрования, ротация секретов, Key Vault RBAC, защита от очистки, обратимое удаление, частная конечная точка Key Vault, секреты управляемого доступа к удостоверениям, управляемый HSM, ссылки на Key Vault, BYOK CMK. НЕ ИСПОЛЬЗУЙТЕ для проектирования центра сертификации (используйте pki-design), только учетных данных приложения entra (используйте entra-id) или топологии сети PaaS (используйте azure-network-security-design).
