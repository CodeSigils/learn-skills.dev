Руководства по регистрации приложения Microsoft Entra ID, аутентификации OAuth 2.0 и интеграции MSAL. ИСПОЛЬЗОВАНИЕ ДЛЯ: создания регистрации приложения, регистрации приложения Azure AD, настройки OAuth, настройки аутентификации, добавления разрешений API, создания субъекта-службы, примера MSAL, аутентификации консольного приложения, настройки Entra ID, аутентификации Azure AD. НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: Azure RBAC или назначения ролей (используйте azure-rbac), секретов Key Vault (используйте azure-keyvault-expiration-audit), общих рекомендаций по безопасности ресурсов Azure.
