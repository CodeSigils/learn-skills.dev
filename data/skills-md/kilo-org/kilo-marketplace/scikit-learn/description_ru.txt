Машинное обучение на Python с помощью scikit-learn. Используйте при работе с контролируемым обучением (классификация, регрессия), неконтролируемым обучением (кластеризация, уменьшение размерности), оценкой модели, настройкой гиперпараметров, предварительной обработкой или построением конвейеров машинного обучения. Предоставляет исчерпывающую справочную документацию по алгоритмам, методам предварительной обработки, конвейерам и передовым практикам.
