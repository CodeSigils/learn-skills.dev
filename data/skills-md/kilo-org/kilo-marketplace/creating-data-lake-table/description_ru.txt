Создавайте управляемые таблицы Iceberg с помощью таблиц Amazon S3 (пространство имен API s3tables) с автоматическим сжатием и управлением моментальными снимками. Настраивает сегмент таблицы, пространство имен, таблицу, схему, регистрацию каталога Glue, секционирование, контроль доступа IAM. Запускается по: созданию таблицы, таблице озера данных, аналитической таблице, структурированному хранилищу данных, таблицам S3, Iceberg, таблице Athena, стратегии секционирования, разрешениям доступа. НЕ используйте для: импорта файлов (используйте прием в озеро данных), векторного хранилища (используйте векторы хранения и запроса), запроса существующих таблиц (используйте озеро запросов данных) или поиска существующей таблицы (используйте активы озера данных поиска).
