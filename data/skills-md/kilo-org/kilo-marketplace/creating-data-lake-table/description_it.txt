Crea tabelle Iceberg gestite utilizzando Amazon S3 Tables (spazio dei nomi API s3tables) con compattazione automatica e gestione degli snapshot. Imposta il bucket della tabella, lo spazio dei nomi, la tabella, lo schema, la registrazione del catalogo Glue, il partizionamento, il controllo dell'accesso IAM. Trigger su: creazione tabella, tabella data Lake, tabella di analisi, archiviazione dati strutturati, tabelle S3, Iceberg, tabella Athena, strategia di partizionamento, autorizzazioni di accesso. NON utilizzare per: importazione di file (utilizzare ingesting-into-data-lake), archiviazione di vettori (utilizzare vettori di archiviazione e query), interrogare tabelle esistenti (utilizzare querying-data-lake) o individuare tabelle esistenti (utilizzare find-data-lake-assets).
