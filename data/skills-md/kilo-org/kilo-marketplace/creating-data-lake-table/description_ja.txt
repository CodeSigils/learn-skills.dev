自動圧縮とスナップショット管理を備えた Amazon S3 テーブル (s3tables API 名前空間) を使用して、管理対象の Iceberg テーブルを作成します。テーブルバケット、ネームスペース、テーブル、スキーマ、Glueカタログ登録、パーティショニング、IAMアクセス制御を設定します。トリガー: テーブルの作成、データレイクテーブル、分析テーブル、構造化データストレージ、S3 テーブル、Iceberg、Athena テーブル、パーティショニング戦略、アクセス権限。ファイルのインポート (ingesting-into-data-lake を使用)、ベクター ストレージ (storage-and-querying-vectors を使用)、既存のテーブルのクエリ (querying-data-lake を使用)、または既存のテーブルの検索 (finding-data-lake-assets を使用) には使用しないでください。
