Cree tablas Iceberg administradas utilizando Amazon S3 Tables (espacio de nombres API s3tables) con compactación automática y administración de instantáneas. Configura el depósito de tablas, el espacio de nombres, la tabla, el esquema, el registro del catálogo de Glue, la partición y el control de acceso de IAM. Activadores de: creación de tabla, tabla de lago de datos, tabla de análisis, almacenamiento de datos estructurados, tablas S3, Iceberg, tabla Athena, estrategia de partición, permisos de acceso. NO lo use para: importar archivos (use ingesta en lago de datos), almacenamiento de vectores (use vectores de almacenamiento y consulta), consulta de tablas existentes (use consulta de lago de datos) o localización de tablas existentes (use búsqueda de activos de lago de datos).
