Créez des tables Iceberg gérées à l'aide d'Amazon S3 Tables (espace de noms API s3tables) avec compactage automatique et gestion des instantanés. Configure le compartiment de table, l'espace de noms, la table, le schéma, l'enregistrement du catalogue Glue, le partitionnement et le contrôle d'accès IAM. Déclencheurs sur : créer une table, une table de lac de données, une table d'analyse, un stockage de données structuré, des tables S3, Iceberg, une table Athena, une stratégie de partitionnement, des autorisations d'accès. Ne PAS utiliser pour : l'importation de fichiers (utilisez l'ingestion dans un lac de données), le stockage vectoriel (utilisez des vecteurs de stockage et de requête), l'interrogation de tables existantes (utilisez le lac de données de requête) ou la localisation d'une table existante (utilisez la recherche d'actifs de lac de données).
