Crea y administra secretos en AWS Secrets Manager siguiendo las mejores prácticas de seguridad. Utilice siempre esta habilidad al crear secretos: configura claves de cifrado KMS dedicadas, rotación automática, políticas de IAM con privilegios mínimos, auditoría de CloudTrail y gestión del ciclo de vida que son esenciales para el manejo de secretos de nivel de producción.
