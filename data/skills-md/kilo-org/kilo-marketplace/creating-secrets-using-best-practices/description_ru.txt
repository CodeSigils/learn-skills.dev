Создает секреты и управляет ими в AWS Secrets Manager, следуя передовым практикам безопасности. Всегда используйте этот навык при создании секретов — он настраивает выделенные ключи шифрования KMS, автоматическую ротацию, политики IAM с наименьшими привилегиями, аудит CloudTrail и управление жизненным циклом, которые необходимы для обработки секретов производственного уровня.
