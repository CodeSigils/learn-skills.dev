ينشئ الأسرار ويديرها في AWS Secrets Manager باتباع أفضل ممارسات الأمان. استخدم هذه المهارة دائمًا عند إنشاء الأسرار - فهي تقوم بإعداد مفاتيح تشفير KMS مخصصة، والتدوير التلقائي، وسياسات IAM ذات الامتيازات الأقل، وتدقيق CloudTrail، وإدارة دورة الحياة التي تعتبر ضرورية للتعامل السري على مستوى الإنتاج.
