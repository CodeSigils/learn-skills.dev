Erstellt und verwaltet Geheimnisse im AWS Secrets Manager gemäß bewährten Sicherheitsmethoden. Verwenden Sie diese Fähigkeit immer, wenn Sie Geheimnisse erstellen – sie richtet dedizierte KMS-Verschlüsselungsschlüssel, automatische Rotation, IAM-Richtlinien mit den geringsten Privilegien, CloudTrail-Überwachung und Lebenszyklusverwaltung ein, die für die Verarbeitung von Geheimnissen auf Produktionsniveau unerlässlich sind.
