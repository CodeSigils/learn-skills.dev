Steuern Sie die „airbyte-agent“-CLI, um Airbyte-Konnektoren, Arbeitsbereiche und Organisationen zu verwalten. Führen Sie Listen-/Abruf-/Such-/Erstellungs-/Aktualisierungsaktionen für Connector-Daten (HubSpot, Salesforce, Slack, GitHub usw.) aus, installieren Sie neue Connectors über den Anmeldeinformationsfluss des Browsers, listen Sie Arbeitsbereiche auf und wechseln Sie, listen Sie Organisationen auf, überprüfen Sie Connector-Metadaten, lesen Sie Skill-Dokumente oder drucken Sie das zusammengeführte CLI- und OpenAPI-Schema für jeden Vorgang. Verwenden Sie diese Option, wenn der Benutzer Airbyte, die „airbyte-agent“-CLI, Konnektoren, Synchronisierungen, Arbeitsbereiche, Organisationen erwähnt oder das Lesen/Schreiben von Daten von einem verbundenen SaaS-Produkt anfordert.
