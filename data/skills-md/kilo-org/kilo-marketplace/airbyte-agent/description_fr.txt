Pilotez la CLI « airbyte-agent » pour gérer les connecteurs, les espaces de travail et les organisations Airbyte. Exécutez des actions list/get/search/create/update sur les données des connecteurs (HubSpot, Salesforce, Slack, GitHub, etc.), installez de nouveaux connecteurs via le flux d'informations d'identification du navigateur, répertoriez et changez d'espaces de travail, répertoriez les organisations, inspectez les métadonnées des connecteurs, lisez les documents de compétences ou imprimez le schéma CLI + OpenAPI fusionné pour toute opération. À utiliser lorsque l'utilisateur mentionne Airbyte, la CLI « airbyte-agent », les connecteurs, les synchronisations, les espaces de travail, les organisations ou demande de lire/écrire des données à partir d'un produit SaaS connecté.
