Maneje la CLI `airbyte-agent` para administrar conectores, espacios de trabajo y organizaciones de Airbyte. Ejecute acciones de lista/obtener/buscar/crear/actualizar contra los datos del conector (HubSpot, Salesforce, Slack, GitHub, etc.), instale nuevos conectores a través del flujo de credenciales del navegador, enumere y cambie espacios de trabajo, enumere organizaciones, inspeccione los metadatos del conector, lea documentos de habilidades o imprima el esquema CLI + OpenAPI combinado para cualquier operación. Úselo cuando el usuario mencione Airbyte, la CLI `airbyte-agent`, conectores, sincronizaciones, espacios de trabajo, organizaciones o solicite leer/escribir datos de un producto SaaS conectado.
