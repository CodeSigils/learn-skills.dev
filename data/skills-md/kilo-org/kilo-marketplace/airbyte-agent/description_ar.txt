قم بقيادة واجهة سطر الأوامر "airbyte-agent" لإدارة موصلات Airbyte ومساحات العمل والمؤسسات. قم بتشغيل إجراءات القائمة/الحصول على/البحث/الإنشاء/التحديث على بيانات الموصل (HubSpot، وSalesforce، وSlack، وGitHub، وما إلى ذلك)، أو تثبيت موصلات جديدة عبر تدفق بيانات اعتماد المتصفح، أو إدراج مساحات العمل وتبديلها، أو قائمة المؤسسات، أو فحص بيانات تعريف الموصل، أو قراءة مستندات المهارات، أو طباعة مخطط CLI + OpenAPI المدمج لأي عملية. يُستخدم عندما يذكر المستخدم Airbyte، أو واجهة سطر الأوامر "airbyte-agent"، أو الموصلات، أو المزامنة، أو مساحات العمل، أو المؤسسات، أو عندما يطلب قراءة/كتابة البيانات من منتج SaaS متصل.
