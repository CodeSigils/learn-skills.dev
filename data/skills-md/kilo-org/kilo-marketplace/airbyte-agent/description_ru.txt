Используйте интерфейс командной строки airbyte-agent для управления коннекторами, рабочими пространствами и организациями Airbyte. Выполняйте действия по списку/получению/поиску/созданию/обновлению данных соединителей (HubSpot, Salesforce, Slack, GitHub и т. д.), устанавливайте новые соединители через поток учетных данных браузера, составляйте списки и переключайте рабочие области, составляйте списки организаций, проверяйте метаданные соединителей, читайте документацию по навыкам или распечатывайте объединенную схему CLI + OpenAPI для любой операции. Используйте, когда пользователь упоминает Airbyte, интерфейс командной строки airbyte-agent, соединители, синхронизацию, рабочие области, организации или запрашивает чтение/запись данных из подключенного продукта SaaS.
