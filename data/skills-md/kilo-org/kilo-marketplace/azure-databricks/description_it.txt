Conoscenza approfondita dello sviluppo di Azure Databricks, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usa Unity Catalog, Lakeflow/Lakebase, warehouse SQL, Model Serving o Lakehouse Federation e altre attività di sviluppo correlate ad Azure Databricks. Non per Azure Synapse Analytics (usare azure-synapse-analytics), Azure HDInsight (usare azure-hdinsight), Azure Machine Learning (usare azure-machine-learning), Azure Data Factory (usare azure-data-factory).
