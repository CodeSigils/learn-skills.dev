Genera código que transforma conjuntos de datos entre esquemas de aprendizaje automático para el entrenamiento o la evaluación de modelos. Úselo cuando el usuario diga "transformar", "convertir", "reformatear", "cambiar el formato" o cuando el esquema de un conjunto de datos deba cambiar para coincidir con el formato de destino; utilice siempre esta habilidad para cambios de formato en lugar de escribir código de transformación en línea. Admite chat OpenAI, SageMaker SFT/DPO/RLVR/RLAIF, preferencia HuggingFace, Bedrock Nova, VERL y formatos JSONL personalizados desde archivos locales o S3.
