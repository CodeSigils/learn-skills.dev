Génère du code qui transforme les ensembles de données entre les schémas ML pour la formation ou l'évaluation de modèles. À utiliser lorsque l'utilisateur dit « transformer », « convertir », « reformater », « changer le format » ou lorsque le schéma d'un ensemble de données doit être modifié pour correspondre au format cible — utilisez toujours cette compétence pour les changements de format plutôt que d'écrire du code de transformation en ligne. Prend en charge le chat OpenAI, SageMaker SFT/DPO/RLVR/RLAIF, la préférence HuggingFace, Bedrock Nova, VERL et les formats JSONL personnalisés à partir de fichiers locaux ou S3.
