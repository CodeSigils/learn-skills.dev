Genera codice che trasforma i set di dati tra schemi ML per l'addestramento o la valutazione del modello. Da utilizzare quando l'utente dice "trasforma", "converti", "riformatta", "modifica il formato" o quando lo schema di un set di dati deve essere modificato per corrispondere al formato di destinazione: utilizza sempre questa capacità per le modifiche al formato anziché scrivere codice di trasformazione in linea. Supporta chat OpenAI, SageMaker SFT/DPO/RLVR/RLAIF, preferenza HuggingFace, Bedrock Nova, VERL e formati JSONL personalizzati da file locali o S3.
