Interagisce con i servizi Google Cloud utilizzando la CLI gcloud in modo sicuro ed efficiente. Copre la convalida dei comandi, la riduzione dei dati, i guardrail di sicurezza con una lista negata e i flussi di lavoro per il rilevamento e l'indagine. DEVI leggere questa Skill prima di invocare qualsiasi comando gcloud. Da utilizzare durante la gestione delle risorse cloud, l'esecuzione di query sulle configurazioni o la risoluzione dei problemi tramite gcloud. Non utilizzare durante la scrittura o il debug del codice della libreria client Google Cloud o delle interazioni API REST/gRPC non elaborate.
