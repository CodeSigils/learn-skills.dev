Взаимодействует с сервисами Google Cloud с помощью интерфейса командной строки gcloud безопасно и эффективно. Охватывает проверку команд, сокращение данных, защитные меры безопасности со списком запрещенных данных и рабочие процессы для обнаружения и расследования. Вы ДОЛЖНЫ прочитать этот навык перед вызовом любой команды gcloud. Используйте при управлении облачными ресурсами, запросе конфигураций или устранении неполадок через gcloud. Не используйте при написании или отладке кода клиентской библиотеки Google Cloud или необработанных взаимодействий API REST/gRPC.
