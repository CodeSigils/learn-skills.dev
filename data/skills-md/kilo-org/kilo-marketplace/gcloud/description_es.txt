Interactúa con los servicios de Google Cloud mediante la CLI de gcloud de forma segura y eficiente. Cubre la validación de comandos, la reducción de datos, las barreras de seguridad con una lista de denegados y los flujos de trabajo para el descubrimiento y la investigación. DEBES leer esta habilidad antes de invocar cualquier comando de gcloud. Úselo al administrar recursos de la nube, consultar configuraciones o solucionar problemas a través de gcloud. No lo use al escribir o depurar el código de la biblioteca cliente de Google Cloud o las interacciones sin procesar de la API REST/gRPC.
