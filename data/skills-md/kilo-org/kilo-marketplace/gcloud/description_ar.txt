يتفاعل مع خدمات Google Cloud باستخدام gcloud CLI بأمان وكفاءة. يغطي التحقق من صحة الأمر، وتقليل البيانات، وحواجز السلامة مع قائمة الرفض، وسير العمل للاكتشاف والتحقيق. يجب عليك قراءة هذه المهارة قبل استدعاء أي أمر gcloud. يُستخدم عند إدارة الموارد السحابية، أو الاستعلام عن التكوينات، أو استكشاف المشكلات وإصلاحها عبر gcloud. لا تستخدمه عند كتابة أو تصحيح أخطاء رمز مكتبة عميل Google Cloud أو تفاعلات REST/gRPC API الأولية.
