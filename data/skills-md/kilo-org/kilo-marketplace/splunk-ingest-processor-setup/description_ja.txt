SPL2 パイプライン、ソース タイプ、宛先、ライフサイクル ハンドオフ、キューとモニタリングの検索、メトリクス、OCSF、復号化、S3 アーカイブ、カスタム パイプライン テンプレート、AI を活用したデータ管理の準備状況、およびダウンストリームの準備状況チェックを使用して、Cisco Data Fabric の取り込み時ルーティング ワークフローと Splunk Cloud Platform Ingest Processor セットアップ プランをレンダリングします。 Splunk Cloud の取り込み時のルーティングと変換を伴う Cisco データ ファブリックまたはテレメトリ パイプライン管理リクエストを含む、取り込みプロセッサの構成、取り込みプロセッサ パイプラインの作成、取り込み時のデータのルーティングまたは変換、取り込みプロセッサの準備状況の検証、または取り込みプロセッサとエッジ プロセッサおよびデータ マネージャとの比較をユーザーが要求する場合に使用します。
