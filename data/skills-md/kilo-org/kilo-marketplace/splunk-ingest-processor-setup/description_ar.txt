قم بتقديم سير عمل توجيه وقت استيعاب Cisco Data Fabric وخطط إعداد Splunk Cloud Platform Ingest Processor مع خطوط أنابيب SPL2، وأنواع المصادر، والوجهات، وعمليات تسليم دورة الحياة، وعمليات البحث في قائمة الانتظار والمراقبة، والمقاييس، وOCSF، وفك التشفير، وأرشيف S3، وقوالب خطوط الأنابيب المخصصة، وجاهزية إدارة البيانات المدعومة بالذكاء الاصطناعي، وفحوصات الاستعداد النهائية. يُستخدم عندما يطلب المستخدم تكوين Ingest Processor، أو تأليف خطوط أنابيب Ingest Processor، أو توجيه البيانات أو تحويلها في وقت الاستيعاب، أو التحقق من صحة جاهزية Ingest Processor، أو مقارنة Ingest Processor مع Edge Processor وData Manager، بما في ذلك Cisco Data Fabric أو طلبات إدارة خطوط أنابيب القياس عن بعد التي تتضمن توجيه وتحويل وقت استيعاب Splunk Cloud.
