Esegui il rendering dei flussi di lavoro di routing in fase di acquisizione di Cisco Data Fabric e dei piani di configurazione del processore di acquisizione di Splunk Cloud Platform con pipeline SPL2, tipi di origine, destinazioni, trasferimenti del ciclo di vita, ricerche di code e monitoraggio, parametri, OCSF, decrittografia, archivio S3, modelli di pipeline personalizzati, disponibilità della gestione dei dati basata sull'intelligenza artificiale e controlli di idoneità downstream. Da utilizzare quando l'utente richiede di configurare il processore di ingest, creare pipeline del processore di ingest, instradare o trasformare i dati al momento dell'assimilazione, convalidare la disponibilità del processore di ingest o confrontare il processore di ingest con Edge Processor e Data Manager, incluse Cisco Data Fabric o le richieste di gestione della pipeline di telemetria che coinvolgono il routing e la trasformazione in fase di ingest di Splunk Cloud.
