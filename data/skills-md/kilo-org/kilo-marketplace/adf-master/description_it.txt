CI/CD, distribuzione e sviluppo della pipeline di Azure Data Factory (ADF). Attivazione PROATTIVA per: (1) configurazione CI/CD ADF (convalida npm, esportazione modello ARM), (2) distribuzione del modello ARM ADF, (3) convalida della build npm ADF in CI, (4) PrePostDeploymentScript per trigger e pulizia delle risorse, (5) flussi di lavoro ADF GitHub, (6) pipeline ADF Azure DevOps, (7) integrazione ADF Git (collaborazione vs ramo di pubblicazione), (8) parametrizzazione dei servizi collegati e set di dati in ambienti, (9) trigger ADF (pianificazione, finestra a cascata, evento), (10) slot di distribuzione e blu-verde per ADF. Fornisce: YAML CI/CD completo per azioni GitHub e Azure DevOps, riferimento PrePostDeploymentScript, modelli di parametrizzazione e ricette di gestione dei trigger.
