CI/CD, implementación y desarrollo de canalizaciones de Azure Data Factory (ADF). Active PROACTIVAMENTE para: (1) configuración de ADF CI/CD (validación de npm, exportación de plantillas de ARM), (2) implementación de plantillas de ADF ARM, (3) validación de compilación de ADF npm en CI, (4) PrePostDeploymentScript para activación y limpieza de recursos, (5) flujos de trabajo de ADF GitHub Actions, (6) canalizaciones de ADF Azure DevOps, (7) integración de ADF Git (colaboración frente a rama de publicación), (8) parametrización de servicios vinculados y conjuntos de datos en todos los entornos, (9) activadores de ADF (programación, ventana de caída, evento), (10) ranuras de implementación y azul-verde para ADF. Proporciona: CI/CD YAML completo para GitHub Actions y Azure DevOps, referencia de PrePostDeploymentScript, patrones de parametrización y recetas de administración de desencadenadores.
