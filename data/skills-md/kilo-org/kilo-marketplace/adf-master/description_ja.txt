Azure Data Factory (ADF) CI/CD、デプロイ、およびパイプライン開発。 (1) ADF CI/CD セットアップ (npm 検証、ARM テンプレートのエクスポート)、(2) ADF ARM テンプレートのデプロイ、(3) CI での ADF npm ビルド検証、(4) トリガーとリソースのクリーンアップ用の PrePostDeploymentScript、(5) ADF GitHub Actions ワークフロー、(6) ADF Azure DevOps パイプライン、(7) ADF Git 統合 (コラボレーションとパブリッシュ ブランチ)、 (8) 環境全体でリンクされたサービスとデータセットのパラメータ化、(9) ADF トリガー (スケジュール、タンブリング ウィンドウ、イベント)、(10) ADF のデプロイメント スロットとブルーグリーン。 GitHub Actions および Azure DevOps 用の完全な CI/CD YAML、PrePostDeploymentScript リファレンス、パラメータ化パターン、トリガー管理レシピが提供されます。
