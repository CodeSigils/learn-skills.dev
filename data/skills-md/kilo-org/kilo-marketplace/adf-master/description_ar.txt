Azure Data Factory (ADF) CI/CD والنشر وتطوير المسارات. التنشيط بشكل استباقي لـ: (1) إعداد ADF CI/CD (التحقق من صحة npm، تصدير قالب ARM)، (2) نشر قالب ADF ARM، (3) التحقق من صحة بناء ADF npm في CI، (4) PrePostDeploymentScript لتنظيف المشغل والموارد، (5) سير عمل ADF GitHub Actions، (6) خطوط أنابيب ADF Azure DevOps، (7) تكامل ADF Git (التعاون مقابل فرع النشر)، (8) تحديد معلمات الخدمات ومجموعات البيانات المرتبطة عبر البيئات، (9) مشغلات ADF (الجدول الزمني، النافذة المتراجعة، الحدث)، (10) فتحات النشر والأزرق والأخضر لـ ADF. يوفر: CI/CD YAML الكامل لإجراءات GitHub وAzure DevOps ومرجع PrePostDeploymentScript وأنماط تحديد المعلمات ووصفات إدارة التشغيل.
