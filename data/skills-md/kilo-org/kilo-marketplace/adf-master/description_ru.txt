Azure Data Factory (ADF) CI/CD, развертывание и разработка конвейера. ПРОАКТИВНО активируйте для: (1) настройки ADF CI/CD (проверка npm, экспорт шаблона ARM), (2) развертывания шаблона ADF ARM, (3) проверки сборки ADF npm в CI, (4) PrePostDeploymentScript для триггеров и очистки ресурсов, (5) рабочих процессов ADF GitHub Actions, (6) конвейеров ADF Azure DevOps, (7) интеграции ADF Git (совместная работа или ветвь публикации), (8) параметризация связанных сервисов и наборов данных в разных средах, (9) триггеры ADF (расписание, переключающееся окно, событие), (10) слоты развертывания и сине-зеленый цвет для ADF. Содержит: полный YAML CI/CD для GitHub Actions и Azure DevOps, справочник по PrePostDeploymentScript, шаблоны параметризации и рецепты управления триггерами.
