Azure 数据工厂 (ADF) CI/CD、部署和管道开发。主动激活：(1) ADF CI/CD 设置（npm 验证、ARM 模板导出）、(2) ADF ARM 模板部署、(3) CI 中的 ADF npm 构建验证、(4) 用于触发器和资源清理的 PrePostDeploymentScript、(5) ADF GitHub Actions 工作流、(6) ADF Azure DevOps 管道、(7) ADF Git 集成（协作与发布分支）、(8) 跨环境参数化链接服务和数据集、 (9) ADF 触发器（计划、滚动窗口、事件），(10) ADF 部署槽和蓝绿色。提供：用于 GitHub Actions 和 Azure DevOps 的完整 CI/CD YAML、PrePostDeploymentScript 参考、参数化模式和触发器管理配方。
