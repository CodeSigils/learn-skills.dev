Используйте, когда пользователь спрашивает об использовании Gemini в корпоративной среде или явно упоминает Vertex AI, Google Cloud или платформу агентов. Руководства по использованию API Gemini на платформе агентов с помощью Google Gen AI SDK. Охватывает использование SDK (Python, JS/TS, Go, Java, C#), такие возможности, как мультимодальные входные данные, инструменты, создание мультимедиа, кэширование, пакетное прогнозирование и Live API.
