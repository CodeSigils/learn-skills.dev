À utiliser lorsque l'utilisateur demande comment utiliser Gemini dans un environnement d'entreprise ou mentionne explicitement Vertex AI, Google Cloud ou Agent Platform. Guide l'utilisation de l'API Gemini sur Agent Platform avec le SDK Google Gen AI. Couvre l'utilisation du SDK (Python, JS/TS, Go, Java, C#), des fonctionnalités telles que les entrées multimodales, les outils, la génération de médias, la mise en cache, la prédiction par lots et l'API Live.
