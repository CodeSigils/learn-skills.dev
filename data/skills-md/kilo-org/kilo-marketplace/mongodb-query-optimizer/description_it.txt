Aiuto con l'ottimizzazione e l'indicizzazione delle query MongoDB. Utilizzare solo quando l'utente richiede ottimizzazione o prestazioni: "Come ottimizzo questa query?", "Come posso indicizzarla?", "Perché questa query è lenta?", "Puoi correggere le mie query lente?", "Quali sono le query lente sul mio cluster?", ecc. Non invocare la scrittura generale di query MongoDB a meno che l'utente non chieda assistenza sulle prestazioni o sull'indicizzazione. Preferire l'indicizzazione come strategia di ottimizzazione. Utilizza MongoDB MCP quando disponibile.
