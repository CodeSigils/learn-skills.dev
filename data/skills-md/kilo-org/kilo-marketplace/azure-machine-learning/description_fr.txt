Connaissance approfondie du développement d'Azure Machine Learning, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de l'utilisation d'espaces de travail Azure ML, de clusters de calcul, de pipelines, d'AutoML, de points de terminaison en ligne/par lots ou de flux d'invites, ainsi que d'autres tâches de développement liées à Azure Machine Learning. Pas pour Azure Databricks (utilisez azure-databricks), Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure HDInsight (utilisez azure-hdinsight), Azure Data Science Virtual Machines (utilisez azure-data-science-vm).
