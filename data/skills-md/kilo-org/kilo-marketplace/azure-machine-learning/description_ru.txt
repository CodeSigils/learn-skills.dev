Экспертные знания для разработки машинного обучения Azure, включая устранение неполадок, лучшие практики, принятие решений, шаблоны архитектуры и проектирования, ограничения и квоты, безопасность, конфигурацию, интеграцию и шаблоны кодирования, а также развертывание. Используйте при использовании рабочих областей машинного обучения Azure, вычислительных кластеров, конвейеров, AutoML, онлайн-/пакетных конечных точек или потока подсказок, а также других задач разработки, связанных с машинным обучением Azure. Не для Azure Databricks (используйте azure-databricks), Azure Synapse Analytics (используйте azure-synapse-analytics), Azure HDInsight (используйте azure-hdinsight), виртуальных машин Azure Data Science (используйте azure-data-science-vm).
