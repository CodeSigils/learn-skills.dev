معرفة الخبراء بتطوير Azure Machine Learning بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند استخدام مساحات عمل Azure ML، أو مجموعات الحوسبة، أو خطوط الأنابيب، أو AutoML، أو نقاط النهاية عبر الإنترنت/الدفعة، أو التدفق الفوري، ومهام التطوير الأخرى ذات الصلة بالتعلم الآلي من Azure. ليس لـ Azure Databricks (استخدم azure-databricks)، وAzure Synapse Analytics (استخدم azure-synapse-analytics)، وAzure HDInsight (استخدم azure-hdinsight)، والأجهزة الظاهرية لـ Azure Data Science (استخدم azure-data-science-vm).
