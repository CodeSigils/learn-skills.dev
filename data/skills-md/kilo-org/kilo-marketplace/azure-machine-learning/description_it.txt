Conoscenza approfondita dello sviluppo di Azure Machine Learning, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da usare quando si usano aree di lavoro di Azure ML, cluster di calcolo, pipeline, AutoML, endpoint online/batch o Prompt Flow e altre attività di sviluppo correlate ad Azure Machine Learning. Non per Azure Databricks (usare azure-databricks), Azure Synapse Analytics (usare azure-synapse-analytics), Azure HDInsight (usare azure-hdinsight), Azure Data Science Virtual Machines (usare azure-data-science-vm).
