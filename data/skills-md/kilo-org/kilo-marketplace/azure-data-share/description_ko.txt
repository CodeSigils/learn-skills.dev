문제 해결, 의사 결정, 보안, 구성 및 배포를 포함한 Azure Data Share 개발에 대한 전문 지식입니다. 데이터 공유 비용 추정, 초대/RBAC 관리, 지역 간 배포, 데이터 세트 매핑 또는 자동화, 기타 Azure Data Share 관련 개발 작업에 사용합니다. Azure Data Box(azure-data-box-family 사용), Azure Import 내보내기(azure-import-export 사용), Azure Open Datasets(azure-open-datasets 사용), Azure Data Explorer(azure-data-explorer 사용)에는 적합하지 않습니다.
