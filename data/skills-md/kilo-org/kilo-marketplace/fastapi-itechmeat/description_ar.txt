إطار عمل FastAPI بيثون. يغطي واجهات برمجة تطبيقات REST والتحقق من الصحة والتبعيات والأمن. يُستخدم عند إنشاء واجهات برمجة تطبيقات ويب Python باستخدام FastAPI، أو تكوين نماذج Pydantic، أو تنفيذ حقن التبعية، أو إعداد مصادقة OAuth2/JWT. الكلمات الرئيسية: FastAPI، Pydantic، غير المتزامن، OAuth2، JWT، REST API.
