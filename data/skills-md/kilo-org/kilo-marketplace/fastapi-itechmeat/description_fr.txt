Cadre Python FastAPI. Couvre les API REST, la validation, les dépendances et la sécurité. À utiliser lors de la création d'API Web Python avec FastAPI, de la configuration de modèles Pydantic, de la mise en œuvre de l'injection de dépendances ou de la configuration de l'authentification OAuth2/JWT. Mots clés : FastAPI, Pydantic, async, OAuth2, JWT, API REST.
