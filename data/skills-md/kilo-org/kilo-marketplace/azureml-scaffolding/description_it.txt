Supporta, struttura e gestisci progetti AI/ML eseguiti su AzureML. Copre l'inizializzazione del progetto (spazi di lavoro uv, devcontainer, Makefile), pacchettizzazione Python con dipendenze esplicite, esecuzione locale e nel cloud, riproducibilità degli esperimenti e modelli di estensibilità (pipeline, set di dati, linting). Usa questa competenza ogni volta che l'utente chiede di creare, modificare, eseguire, testare o distribuire un progetto di machine learning basato su AzureML o quando ha bisogno di indicazioni sul layout del progetto, sulla gestione delle dipendenze o sull'invio di processi cloud con Azure Machine Learning.
