دعم وبناء وإدارة مشاريع الذكاء الاصطناعي/تعلم الآلة التي تعمل على AzureML. يغطي تهيئة المشروع (مساحات عمل الأشعة فوق البنفسجية، وحاويات التطوير، وMakefile)، وتغليف Python مع تبعيات واضحة، والتنفيذ المحلي والسحابي، وإمكانية تكرار التجارب، وأنماط التوسعة (خطوط الأنابيب، ومجموعات البيانات، والفحص). استخدم هذه المهارة عندما يطلب المستخدم إنشاء مشروع تعلم الآلة المستند إلى AzureML أو تعديله أو تشغيله أو اختباره أو نشره - أو عندما يحتاج إلى إرشادات حول تخطيط المشروع أو إدارة التبعية أو إرسال المهام السحابية باستخدام Azure Machine Learning.
