AzureML 上で実行される AI/ML プロジェクトの足場、構造、管理を行います。プロジェクトの初期化 (UV ワークスペース、devcontainers、Makefile)、明示的な依存関係を含む Python パッケージ化、ローカルおよびクラウド実行、実験の再現性、拡張性パターン (パイプライン、データセット、lint) について説明します。ユーザーが AzureML ベースの ML プロジェクトの作成、変更、実行、テスト、デプロイを要求するとき、またはプロジェクトのレイアウト、依存関係管理、または Azure Machine Learning を使用したクラウド ジョブの送信に関するガイダンスが必要なときは、このスキルを使用します。
