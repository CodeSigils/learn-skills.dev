Помогает пользователям найти подходящую роль Azure RBAC для удостоверения с наименьшими привилегиями доступа, а затем генерировать команды CLI и код Bicep для ее назначения. Также приведены рекомендации по разрешениям, необходимым для предоставления ролей. КОГДА: бицепс для назначения роли, какую роль мне следует назначить, роль с наименьшими привилегиями, роль RBAC для, роль для чтения больших двоичных объектов, роль для управляемого удостоверения, пользовательское определение роли, назначить роль удостоверению, какую роль мне нужно предоставить доступ, разрешения для назначения ролей.
