Surveillez, interrogez et gérez les données d’observabilité New Relic via la CLI newrelic. Couvre les requêtes NRQL, le tri des performances APM, les marqueurs de déploiement, la gestion des politiques et des conditions d'alerte, la configuration des canaux de notification, la surveillance de l'infrastructure et les diagnostics des agents. À utiliser lorsque l'utilisateur pose des questions sur les performances des applications, les taux d'erreur, les transactions lentes, le suivi du déploiement, la configuration des alertes ou la configuration de New Relic.
