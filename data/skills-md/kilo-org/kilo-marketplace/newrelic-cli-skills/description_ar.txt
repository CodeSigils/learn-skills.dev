مراقبة بيانات إمكانية ملاحظة New Relic والاستعلام عنها وإدارتها عبر واجهة سطر الأوامر الجديدة. يغطي استعلامات NRQL وفرز أداء APM وعلامات النشر وسياسة التنبيه وإدارة الحالة وإعداد قناة الإشعارات ومراقبة البنية التحتية وتشخيصات الوكيل. يُستخدم عندما يسأل المستخدم عن أداء التطبيق، أو معدلات الخطأ، أو المعاملات البطيئة، أو تتبع النشر، أو تكوين التنبيه، أو إعداد New Relic.
