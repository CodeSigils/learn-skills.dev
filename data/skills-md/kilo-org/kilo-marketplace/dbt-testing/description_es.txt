Estrategias de prueba de dbt que utilizan dbt_constraints para la aplicación a nivel de base de datos, pruebas genéricas y pruebas singulares. Utilice esta habilidad al implementar controles de calidad de datos, agregar restricciones de clave primaria/externa, crear pruebas personalizadas o establecer marcos de prueba integrales en capas de bronce/plata/oro.
