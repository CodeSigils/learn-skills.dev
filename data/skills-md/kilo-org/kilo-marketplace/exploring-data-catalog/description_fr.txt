Inventaire complet et audit des actifs AWS Glue Data Catalog dans les tables S3, les catalogues fédérés par Redshift et Iceberg distants. Déclencheurs sur : inventorier le catalogue, auditer les bases de données, répertorier toutes les tables, aperçu du catalogue, paysage de données, énumérer les catalogues, inventaire des données, rechercher dans le catalogue. Ne PAS utiliser pour rechercher des données spécifiques (utilisez Finding-Data-lake-Assets), exécuter des requêtes (utilisezQuerying-Data-lake) ou créer des tables (utilisez Create-Data-lake-table).
