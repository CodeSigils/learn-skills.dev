أنماط تطوير AWS SDK لـ Python (boto3/botocore). يجب عليك استخدام هذه المهارة عند كتابة كود Python الذي يستخدم خدمات AWS عبر boto3 أو botocore. يتضمن ذلك إنشاء عملاء الخدمة أو الموارد، وتكوين الجلسات وبيانات الاعتماد، ومعالجة الأخطاء باستخدام ClientError، واستخدام مرقّم الصفحات والنادل، وعمليات نقل ملفات S3 وعناوين URL الموقعة مسبقًا، وعمليات جدول DynamoDB، وأي تكوين عميل boto3/botocore. استخدم هذه المهارة عندما يقوم كود Python باستيراد boto3 أو botocore، أو عندما يسأل المستخدم عن عمليات AWS في Python.
