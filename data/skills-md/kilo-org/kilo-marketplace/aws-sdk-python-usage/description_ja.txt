AWS SDK for Python (boto3/botocore) 開発パターン。 boto3 または botocore 経由で AWS サービスを使用する Python コードを作成する場合は、このスキルを使用する必要があります。これには、サービスクライアントまたはリソースの作成、セッションと認証情報の設定、ClientError によるエラーの処理、ページネーターとウェイターの使用、S3 ファイル転送と署名付き URL、DynamoDB テーブル操作、および boto3/botocore クライアント設定が含まれます。 Python コードで boto3 または botocore をインポートするとき、またはユーザーが Python での AWS の操作について質問するときは常に、このスキルを使用します。
