Modèles de développement AWS SDK pour Python (boto3/botocore). Vous DEVEZ utiliser cette compétence lors de l'écriture de code Python qui utilise les services AWS via boto3 ou botocore. Cela inclut la création de clients ou de ressources de service, la configuration de sessions et d'informations d'identification, la gestion des erreurs avec ClientError, l'utilisation de paginateurs et de serveurs, les transferts de fichiers S3 et les URL présignées, les opérations de table DynamoDB et toute configuration client boto3/botocore. Utilisez cette compétence chaque fois que du code Python importe boto3 ou botocore, ou lorsque l'utilisateur pose des questions sur les opérations AWS en Python.
