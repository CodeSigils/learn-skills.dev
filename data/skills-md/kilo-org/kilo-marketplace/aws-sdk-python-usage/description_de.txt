Entwicklungsmuster für AWS SDK für Python (boto3/botocore). Sie MÜSSEN diese Fähigkeit verwenden, wenn Sie Python-Code schreiben, der AWS-Dienste über boto3 oder botocore nutzt. Dazu gehören das Erstellen von Service-Clients oder -Ressourcen, das Konfigurieren von Sitzungen und Anmeldeinformationen, die Behandlung von Fehlern mit ClientError, die Verwendung von Paginatoren und Waitern, S3-Dateiübertragungen und vorsignierten URLs, DynamoDB-Tabellenoperationen und jegliche Boto3/Botocore-Client-Konfiguration. Verwenden Sie diese Fähigkeit immer dann, wenn Python-Code boto3 oder botocore importiert oder wenn der Benutzer nach AWS-Vorgängen in Python fragt.
