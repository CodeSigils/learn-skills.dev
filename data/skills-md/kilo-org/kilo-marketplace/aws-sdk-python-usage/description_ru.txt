AWS SDK для шаблонов разработки Python (boto3/botocore). Вы ДОЛЖНЫ использовать этот навык при написании кода Python, который использует сервисы AWS через boto3 или botocore. Сюда входит создание клиентов или ресурсов службы, настройка сеансов и учетных данных, обработка ошибок с помощью ClientError, использование разбиений на страницы и ожидающих, передача файлов S3 и заранее назначенные URL-адреса, операции с таблицами DynamoDB и любая конфигурация клиента boto3/botocore. Используйте этот навык всякий раз, когда код Python импортирует boto3 или botocore или когда пользователь спрашивает об операциях AWS в Python.
