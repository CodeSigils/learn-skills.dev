Patrones de desarrollo de AWS SDK para Python (boto3/botocore). DEBE utilizar esta habilidad al escribir código Python que utilice servicios de AWS a través de boto3 o botocore. Esto incluye la creación de clientes o recursos de servicio, la configuración de sesiones y credenciales, el manejo de errores con ClientError, el uso de paginadores y camareros, transferencias de archivos S3 y URL prefirmadas, operaciones de tablas de DynamoDB y cualquier configuración de cliente boto3/botocore. Utilice esta habilidad siempre que el código Python importe boto3 o botocore, o cuando el usuario pregunte sobre las operaciones de AWS en Python.
