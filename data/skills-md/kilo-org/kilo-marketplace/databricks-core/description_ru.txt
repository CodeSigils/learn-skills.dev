Операции интерфейса командной строки Databricks и навыки родительской/точки входа для всех операций Databricks: аутентификация, выбор профиля, исследование данных, пакеты и вопросы и ответы Genie по данным на естественном языке. Загрузите это сначала для любой задачи Databricks (CLI, аутентификация, профили, изучение каталогов/таблиц), затем загрузите соответствующий навык продукта. Содержит актуальные рекомендации для задач CLI, связанных с Databricks.
