إرشادات Oracle Database لـ SQL وPL/SQL وSQLcl وORDS والإدارة وتطوير التطبيقات والأداء والأمان وعمليات الترحيل وسير عمل قاعدة البيانات الآمنة للوكيل. يُستخدم عندما يطلب المستخدم كتابة SQL أو تحريره أو إعادة كتابته أو مراجعته أو تنسيقه أو تصحيحه أو ضبطه أو شرحه؛ إنشاء أو إعادة بناء PL/SQL؛ استخدام SQLcl، أو Liquibase، أو ORDS، أو JDBC، أوnode-oracledb، أو Python، أو Java، أو .NET، أو أطر عمل قواعد البيانات؛ استكشاف أخطاء الاستعلامات وإصلاحها أو الجلسات أو الأقفال أو الانتظار أو الفهارس أو خطط المحسن أو AWR أو ASH أو عمليات الترحيل أو المخططات أو المستخدمين أو الأدوار أو الامتيازات أو النسخ الاحتياطي أو الاسترداد أو Data Guard أو RAC أو المستأجرين المتعددين أو الحاويات أو المراقبة أو التدقيق أو التشفير أو VPD أو عمليات قاعدة بيانات الوكيل الآمن.
