يرشد محللي البيانات من خلال سير عمل إنشاء لوحة معلومات Tableau متعدد الخطوات - إعداد العلامة التجارية، واستكشاف البيانات، وتخطيط لوحة المعلومات، وإنشاء نموذج HTML التفاعلي، ومواصفات تنفيذ Tableau، وإنشاء مصنف TWB التجريبي. يُستخدم عندما يريد المستخدم إنشاء لوحة معلومات Tableau، أو إنشاء نموذج لوحة معلومات، أو تخطيط مؤشرات الأداء الرئيسية والمخططات، أو إنشاء مستند تنفيذ Tableau.
