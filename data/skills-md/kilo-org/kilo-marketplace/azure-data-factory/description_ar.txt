معرفة الخبراء بتطوير Azure Data Factory بما في ذلك استكشاف الأخطاء وإصلاحها وأفضل الممارسات واتخاذ القرار وأنماط الهندسة والتصميم والحدود والحصص والأمان والتكوين والتكامل وأنماط الترميز والنشر. يُستخدم عند تصميم خطوط أنابيب ADF، أو تدفقات البيانات، أو أوقات تشغيل التكامل، أو عمليات نشر SAP CDC، أو CI/CD، أو عمليات ترحيل SSIS، ومهام التطوير الأخرى ذات الصلة بـ Azure Data Factory. ليس لـ Azure Synapse Analytics (استخدم تحليلات azure-synapse)، وAzure Databricks (استخدم azure-databricks)، وAzure Stream Analytics (استخدم تحليلات الدفق azure)، ووظائف Azure (استخدم وظائف azure).
