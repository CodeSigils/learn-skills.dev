문제 해결, 모범 사례, 의사 결정, 아키텍처 및 디자인 패턴, 제한 및 할당량, 보안, 구성, 통합 및 코딩 패턴, 배포를 포함한 Azure Data Factory 개발에 대한 전문 지식입니다. Azure Synapse Analytics(azure-synapse-analytics 사용), Azure Databricks(azure-databricks 사용), Azure Stream Analytics(azure-stream-analytics 사용), Azure Functions(azure-functions 사용)에는 적합하지 않습니다.
