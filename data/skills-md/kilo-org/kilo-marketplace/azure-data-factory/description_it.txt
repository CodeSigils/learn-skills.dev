Conoscenza approfondita dello sviluppo di Azure Data Factory, tra cui risoluzione dei problemi, procedure consigliate, processo decisionale, modelli di architettura e progettazione, limiti e quote, sicurezza, configurazione, integrazioni e modelli di codifica e distribuzione. Da utilizzare durante la progettazione di pipeline ADF, flussi di dati, runtime di integrazione, SAP CDC, distribuzioni CI/CD o migrazioni SSIS e altre attività di sviluppo correlate ad Azure Data Factory. Non per Analisi sinapsi di Azure (usare azure-synapse-analytics), Azure Databricks (usare azure-databricks), Analisi di flusso di Azure (usare azure-stream-analytics), Funzioni di Azure (usare funzioni di azure).
