Connaissance approfondie du développement d'Azure Data Factory, y compris le dépannage, les meilleures pratiques, la prise de décision, les modèles d'architecture et de conception, les limites et quotas, la sécurité, la configuration, les intégrations et les modèles de codage, ainsi que le déploiement. À utiliser lors de la conception de pipelines ADF, de flux de données, de runtimes d'intégration, de déploiements SAP CDC, CI/CD ou de migrations SSIS, ainsi que d'autres tâches de développement liées à Azure Data Factory. Pas pour Azure Synapse Analytics (utilisez azure-synapse-analytics), Azure Databricks (utilisez azure-databricks), Azure Stream Analytics (utilisez azure-stream-analytics), Azure Functions (utilisez azure-functions).
