Наблюдаемость за базами данных Grafana Cloud — анализ производительности MySQL и PostgreSQL на уровне запросов. Охватывает настройку с помощью Grafana Alloy, примеры запросов, планы визуального объяснения, метрики RED, интеграцию pg_stat_statements и Performance Schema, а также корреляцию с трассировками приложений. Используйте при мониторинге производительности базы данных, диагностике медленных запросов, настройке наблюдаемости базы данных для MySQL или PostgreSQL (самоуправляемая, RDS, Aurora, Azure, Cloud SQL) или при сопоставлении метрик БД с данными APM.
