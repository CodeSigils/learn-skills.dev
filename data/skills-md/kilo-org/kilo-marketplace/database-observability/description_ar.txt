Grafana Cloud Database Observability - رؤى الأداء على مستوى الاستعلام لـ MySQL وPostgreSQL. يغطي الإعداد باستخدام Grafana Alloy وعينات الاستعلام وخطط الشرح المرئي ومقاييس RED وpg_stat_statements وتكامل مخطط الأداء والارتباط مع آثار التطبيق. يُستخدم عند مراقبة أداء قاعدة البيانات، أو تشخيص الاستعلامات البطيئة، أو إعداد إمكانية ملاحظة قاعدة البيانات لـ MySQL أو PostgreSQL (الإدارة الذاتية، أو RDS، أو Aurora، أو Azure، أو Cloud SQL)، أو ربط مقاييس قاعدة البيانات ببيانات APM.
