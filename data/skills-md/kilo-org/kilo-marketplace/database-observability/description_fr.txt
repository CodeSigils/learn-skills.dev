Grafana Cloud Database Observability : informations sur les performances au niveau des requêtes pour MySQL et PostgreSQL. Couvre la configuration avec Grafana Alloy, les exemples de requêtes, les plans d'explication visuels, les métriques RED, l'intégration de pg_stat_statements et de Performance Schema, ainsi que la corrélation avec les traces d'application. À utiliser pour surveiller les performances de la base de données, diagnostiquer les requêtes lentes, configurer l'observabilité de la base de données pour MySQL ou PostgreSQL (autogéré, RDS, Aurora, Azure, Cloud SQL) ou corréler les métriques de base de données avec les données APM.
