Grafana Cloud Database Observability — MySQL および PostgreSQL のクエリレベルのパフォーマンスに関する洞察。 Grafana Alloy を使用したセットアップ、クエリ サンプル、ビジュアル Explain プラン、RED メトリクス、pg_stat_statements とパフォーマンス スキーマの統合、アプリケーション トレースとの相関関係について説明します。データベースのパフォーマンスの監視、遅いクエリの診断、MySQL または PostgreSQL (セルフマネージド、RDS、Aurora、Azure、Cloud SQL) のデータベースの可観測性の設定、または DB メトリクスと APM データの関連付けを行う場合に使用します。
