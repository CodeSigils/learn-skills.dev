Escriba pruebas unitarias y de integración para aplicaciones Angular v20+ utilizando Vitest o Jasmine con TestBed y patrones de prueba modernos. Úselo para probar componentes con señales, detección de cambios OnPush, servicios con inject() e interacciones HTTP. Activadores en la creación de pruebas, prueba de componentes basados ​​en señales, dependencias simuladas o configuración de infraestructura de prueba. No lo use para pruebas E2E con Cypress o Playwright, ni para probar código JavaScript/TypeScript que no sea Angular.
