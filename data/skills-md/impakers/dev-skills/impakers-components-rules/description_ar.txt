임패커스 UI 컴포넌트 개발 규칙 (shadcn/ui + Tailwind 기반). كلود 가 .tsx/.jsx 편집، Dialog/Modal/AlertDialog/Sheet/Drawer/Popover 생성، النموذج (react-hook-form+zod) 구현، Table(TanStack/shadcn) 작성، الزر/تحديد/صندوق تحرير وسرد/القائمة المنسدلة/شارة/هيكل عظمي/تلميح الأداة، Sonner toast، 서버 액션 후 쿼리 يبطل 등을 수행할 때 자동 발동. 트리거 키워드 — shadcn، 모달، 다이얼로그، حوار، مشروط، ورقة، درج، popover، نموذج، useForm، zodResolver، DataTable، useQuery، validateQueries، revalidatePath، toast، sonner، 컴포넌트 규칙، واجهة المستخدم، COMPONENTS_RULES، 디자인 규칙. استخدمه عند تحرير كود React/Next.js UI في أي مشروع واجهة أمامية لـ impakers (trusflow، place-real، lomelo-admin، dexter-krema،traction-13، وما إلى ذلك).
