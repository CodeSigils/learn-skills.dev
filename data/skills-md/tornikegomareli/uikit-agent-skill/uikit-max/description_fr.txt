Examine de manière approfondie le code UIKit pour connaître les meilleures pratiques en matière d'API, d'architecture et de performances modernes. À utiliser lors de la lecture, de l'écriture ou de la révision de projets iOS basés sur UIKit, notamment UIViewController, UITableView, UICollectionView, Auto Layout ou le code d'interface utilisateur programmatique. À utiliser également lors de la migration des modèles UIKit existants vers des équivalents modernes. Ne pas utiliser pour les projets SwiftUI uniquement ou pour la logique Combine uniquement sans dépendance UIKit.
