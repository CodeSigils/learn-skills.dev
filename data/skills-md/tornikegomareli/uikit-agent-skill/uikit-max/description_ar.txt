يراجع كود UIKit بشكل شامل للحصول على أفضل الممارسات بشأن واجهات برمجة التطبيقات الحديثة والهندسة المعمارية والأداء. يُستخدم عند القراءة أو الكتابة أو مراجعة مشاريع iOS المستندة إلى UIKit، بما في ذلك UIViewController أو UITableView أو UICollectionView أو Auto Layout أو كود واجهة المستخدم البرمجي. استخدمه أيضًا عند ترحيل أنماط UIKit القديمة إلى معادلاتها الحديثة. لا تستخدمه لمشاريع SwiftUI فقط أو منطق الدمج فقط بدون تبعية UIKit.
