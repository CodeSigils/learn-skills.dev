Revisa exhaustivamente el código UIKit para conocer las mejores prácticas sobre API, arquitectura y rendimiento modernos. Úselo al leer, escribir o revisar proyectos de iOS basados ​​en UIKit, incluidos UIViewController, UITableView, UICollectionView, Auto Layout o código de UI programático. Úselo también al migrar patrones UIKit heredados a equivalentes modernos. No lo use para proyectos solo de SwiftUI o lógica de solo Combine sin dependencia de UIKit.
