قم بتحميل متغيرات البيئة من ملف .env إلى ملفprocess.env لتطبيقات Node.js. يُستخدم عند تكوين التطبيقات بأسرار خاصة بالبيئة، أو إعداد بيئات التطوير المحلية، أو إدارة مفاتيح API وعناوين URL لقاعدة البيانات، أو تحليل محتويات ملف .env، أو تعبئة متغيرات البيئة برمجيًا. يتم تشغيل الطلبات التي تتضمن ملفات .env، أو معالجة.env، أو تحميل متغير البيئة، أو تكوين التطبيق المكون من اثني عشر عاملاً، أو إدارة أسرار Node.js.
