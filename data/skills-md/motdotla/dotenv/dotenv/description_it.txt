Carica le variabili di ambiente da un file .env in process.env per le applicazioni Node.js. Da utilizzare durante la configurazione di app con segreti specifici dell'ambiente, la configurazione di ambienti di sviluppo locali, la gestione di chiavi API e URL di database, l'analisi del contenuto di file .env o il popolamento di variabili di ambiente a livello di codice. Si attiva su richieste che coinvolgono file .env, process.env, caricamento di variabili di ambiente, configurazione dell'app a dodici fattori o gestione dei segreti Node.js.
