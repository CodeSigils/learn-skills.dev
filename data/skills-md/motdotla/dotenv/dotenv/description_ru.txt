Загрузите переменные среды из файла .env в процесс.env для приложений Node.js. Используйте при настройке приложений с секретами, специфичными для среды, настройке локальных сред разработки, управлении ключами API и URL-адресами базы данных, анализе содержимого файла .env или программном заполнении переменных среды. Запускается по запросам, включающим файлы .env,process.env, загрузку переменных среды, двенадцатифакторную конфигурацию приложения или управление секретами Node.js.
