أنشئ تطبيقات الذكاء الاصطناعي للفيديو في الوقت الفعلي باستخدام حزم SDK الخاصة بـ Reactor. يُستخدم عند استيراد التعليمات البرمجية `@reactor-team/js-sdk` أو `reactor-sdk`؛ عند توصيل واجهة الويب/الهاتف المحمول بنموذج Reactor الذي يعمل بوحدة معالجة الرسومات (Helios وغيرها)؛ عند بث الفيديو عبر WebRTC مع التحكم القائم على الأوامر؛ عند نشر مدخلات كاميرا الويب لتحويلات الفيديو إلى الفيديو؛ عند التعامل مع مصادقة JWT للمفاعل؛ أو عند تصحيح دورة حياة اتصال المفاعل (قطع الاتصال → الاتصال → الانتظار → جاهز). تخطي عندما يستخدم المشروع WebRTC غير ذي صلة (على سبيل المثال، مكالمات الفيديو العادية)، أو خطوط أنابيب الفيديو التي لا تلمس Reactor.
