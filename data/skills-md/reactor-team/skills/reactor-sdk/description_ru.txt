Создавайте приложения искусственного интеллекта для видео в реальном времени с помощью Reactor SDK. Используйте, когда код импортирует `@reactor-team/js-sdk` или `reactor-sdk`; при подключении веб-/мобильного интерфейса к модели Reactor на базе графического процессора (Helios и другие); при потоковой передаче видео через WebRTC с командным управлением; при публикации данных с веб-камеры для преобразования видео в видео; при обработке аутентификации JWT для Reactor; или при отладке жизненного цикла соединения Reactor (отключено → подключение → ожидание → готово). ПРОПУСТИТЕ, если проект использует несвязанный WebRTC (например, обычные видеовызовы) или видеоконвейеры, не связанные с Reactor.
