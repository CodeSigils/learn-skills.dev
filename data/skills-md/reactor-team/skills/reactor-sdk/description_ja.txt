Reactor SDK を使用してリアルタイム ビデオ AI アプリケーションを構築します。コードが `@reactor-team/js-sdk` または `reactor-sdk` をインポートする場合に使用します。 Web/モバイル フロントエンドを GPU 搭載の Reactor モデル (Helios など) に接続する場合。コマンドベースの制御を使用して WebRTC 経由でビデオをストリーミングする場合。ビデオからビデオへの変換のために Web カメラ入力をパブリッシュするとき。 Reactor の JWT 認証を処理するとき。または、Reactor 接続ライフサイクル (切断→接続→待機→準備完了) をデバッグするとき。プロジェクトが無関係な WebRTC (通常のビデオ通話など)、または Reactor に触れないビデオ パイプラインを使用する場合はスキップします。
