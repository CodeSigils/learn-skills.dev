قم بتحويل فكرة مشهد فضفاض (حتى جملة قصيرة واحدة، الإنجليزية أو الصينية) إلى مشهد متعدد الطبقات من LingBot-World 2 جاهز للإنتاج: StructuredExample JSON - طبقات أساسية / كاميرا / حركة مع متغيرات ثابتة + ديناميكية، وأحداث مفتاح تعليق قابلة للتكديس (المفاتيح 1..9)، ومطالبات القفز/الانحناء/الوقوف لكل مشهد - والتي تنخفض مباشرة إلى حالات lib/lingbot/ للواجهة الأمامية، بالإضافة إلى مطالبة الصورة الأولية المشتقة. يمكن أيضًا إصدار مطالبة مستقلة مؤلفة واحدة عندما يريد المستخدم مطالبة واحدة فقط. استخدمه عندما يذكر المستخدم LingBot 2، أو LingBot-World 2، أو lingbot-world-2، أو Reactor/lingbot-world-2، أو مشهد الطبقات، أو StructuredScene، أو composePrompt، أو isMoving، أو طبقات القاعدة/الكاميرا/ الحركة، أو الضغط على المفاتيح، أو مفاتيح الأحداث، أو JumpPrompt/crouchPrompt، أو lib/lingbot-cases، أو مطالبة فيديو "شخصية قابلة للتشغيل"، أو إعطاء فكرة تقريبية يريدون توسيعها إلى موجه نموذج عالمي تفاعلي ("اصنع مشهد lingbot 2 لفارس في الصحراء"). يتعامل أيضًا مع الطلبات المصاغة بتنسيق تصدير فتحة action.json / f-g القديم (راجع المراجع/legacy-sessions.md). تغطي مهارة lingbot-world المنفصلة تنسيق آلة الحالة V1 JSON.
