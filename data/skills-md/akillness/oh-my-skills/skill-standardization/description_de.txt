Standardisieren und validieren Sie SKILL.md-Dateien anhand der Agent Skills-Spezifikation (agentskills.io). Verwenden Sie es, wenn Sie neue Fertigkeiten erstellen, vorhandene Fertigkeiten auf Spezifikationskonformität überprüfen, ältere Fertigkeitsformate in eine Standardstruktur umwandeln oder Beschreibungen für eine zuverlässige Auslösung verbessern. Wird ausgelöst bei: „Skill validieren“, „SKILL.md erstellen“, „Skill-Format standardisieren“, „Skill-Spezifikation prüfen“, „Skill-Frontmatter“, „Skill-Beschreibung verbessern“, „Bewertungen zum Skill hinzufügen“.
