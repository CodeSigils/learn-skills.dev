Установите и настройте React-Grab для захвата контекста компонента React (путь к файлу, имя компонента, разметка HTML) из любого элемента пользовательского интерфейса браузера для агентов кодирования AI. Используйте, если вы хотите указать на элемент пользовательского интерфейса в браузере и мгновенно скопировать имя его компонента React, путь к исходному файлу и HTML в буфер обмена для Claude Code, Cursor, Copilot, Gemini или Codex. Запускается при: реакции-захвате, захвате, захвате контекста элемента, копировании компонента в AI, указании и копировании в Claude, буфере обмена контекста пользовательского интерфейса, элементе в агенте AI, щелчке копии компонента, захвате компонента пользовательского интерфейса, инспекторе компонентов реагирования, контексте элемента браузера, исходном файле компонента, копировании контекста элемента, элементе подачи в AI, средстве выбора элементов, захвате компонента реагирования, проверке элемента AI, компоненте в буфере обмена, реагировании на инструменты разработчика AI.
