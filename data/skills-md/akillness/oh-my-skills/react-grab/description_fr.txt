Installez et configurez React-Grab pour capturer le contexte du composant React (chemin du fichier, nom du composant, balisage HTML) à partir de n'importe quel élément de l'interface utilisateur du navigateur pour les agents de codage IA. À utiliser lorsque vous souhaitez pointer sur un élément de l'interface utilisateur dans le navigateur et copier instantanément son nom de composant React, son chemin de fichier source et son code HTML dans le presse-papiers pour Claude Code, Cursor, Copilot, Gemini ou Codex. Déclencheurs sur : réagir-saisir, saisir, saisir le contexte de l'élément, copier le composant vers ai, pointer et copier vers claude, presse-papiers de contexte d'interface utilisateur, élément vers agent ai, cliquer sur la copie du composant, saisir le composant d'interface utilisateur, inspecteur de composant de réaction, contexte d'élément de navigateur, fichier source du composant, copier le contexte de l'élément, alimenter l'élément vers ai, sélecteur d'élément, saisir le composant de réaction, inspecter l'élément ai, le composant dans le presse-papiers, réagir aux outils de développement ai.
