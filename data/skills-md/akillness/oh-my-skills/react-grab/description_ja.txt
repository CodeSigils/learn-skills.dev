AI コーディング エージェントのブラウザ UI 要素から React コンポーネント コンテキスト (ファイル パス、コンポーネント名、HTML マークアップ) をキャプチャするために、react-grab をインストールして構成します。ブラウザーで UI 要素をポイントし、その React コンポーネント名、ソース ファイル パス、および HTML を即座に Claude Code、Cursor、Copilot、Gemini、または Codex のクリップボードにコピーする場合に使用します。トリガー: 反応グラブ、グラブ、要素コンテキストのグラブ、コンポーネントを AI にコピー、ポイントしてクロードにコピー、UI コンテキスト クリップボード、要素を AI エージェントに、コンポーネントのコピーをクリック、UI コンポーネントをグラブ、コンポーネント インスペクタに反応、ブラウザ要素コンテキスト、コンポーネント ソース ファイル、要素コンテキストをコピー、要素を AI にフィード、要素ピッカー、反応コンポーネントをグラブ、要素 AI を検査、コンポーネントをクリップボードに反応、devtools AI に反応。
