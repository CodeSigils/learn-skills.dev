قم بتثبيت أداة التفاعل وتكوينها لالتقاط سياق مكون React (مسار الملف، اسم المكون، علامة HTML) من أي عنصر واجهة مستخدم للمتصفح لوكلاء ترميز الذكاء الاصطناعي. يُستخدم عندما تريد الإشارة إلى عنصر واجهة مستخدم في المتصفح ونسخ اسم مكون React الخاص به ومسار الملف المصدر وHTML على الفور إلى الحافظة لـ Claude Code أو Cursor أو Copilot أو Gemini أو Codex. المشغلات على: انتزاع رد الفعل، والاستيلاء، والاستيلاء على سياق العنصر، ونسخ المكون إلى ai، والإشارة والنسخ إلى claude، وحافظة سياق واجهة المستخدم، والعنصر إلى وكيل ai، والنقر فوق نسخة المكون، والاستيلاء على مكون واجهة المستخدم، ومفتش مكون التفاعل، وسياق عنصر المتصفح، وملف مصدر المكون، ونسخ سياق العنصر، وعنصر التغذية إلى ai، ومنتقي العنصر، والاستيلاء على مكون التفاعل، وفحص العنصر ai، والمكون إلى الحافظة، والتفاعل مع أدوات تطوير الذكاء الاصطناعي.
