قم بتشخيص فشل إجراءات GitHub عبر واجهة سطر الأوامر `gh` - قم بإحضار السجلات وتصنيف السبب الجذري والتوصية بالإصلاح. يُستخدم عند فشل تشغيل سير العمل ويحتاج المستخدم إلى معرفة السبب، عند اكتشاف الاختبارات غير المستقرة عبر عمليات التشغيل الأخيرة، أو تحديد الخطوات البطيئة، أو تحليل سجل الفشل، أو مشاهدة التشغيل المباشر. توقف عن النقر خلال واجهة مستخدم GitHub.
