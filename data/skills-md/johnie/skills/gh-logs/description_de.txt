Diagnostizieren Sie GitHub Actions-Fehler über die „gh“-CLI – rufen Sie Protokolle ab, klassifizieren Sie die Grundursache und empfehlen Sie eine Lösung. Verwenden Sie diese Funktion, wenn eine Workflow-Ausführung fehlgeschlagen ist und der Benutzer wissen muss, warum, z. B. wenn er fehlerhafte Tests in den letzten Ausführungen erkennt, langsame Schritte profiliert, den Fehlerverlauf analysiert oder eine Live-Ausführung beobachtet. Hören Sie auf, sich durch die GitHub-Benutzeroberfläche zu klicken.
