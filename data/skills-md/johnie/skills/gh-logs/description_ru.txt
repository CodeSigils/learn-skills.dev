Диагностируйте сбои GitHub Actions с помощью CLI `gh` — получайте журналы, классифицируйте основную причину и рекомендуйте исправление. Используйте его, когда выполнение рабочего процесса завершилось неудачей и пользователю необходимо знать причину, при обнаружении нестабильных тестов в последних запусках, профилировании медленных шагов, анализе истории ошибок или просмотре живого выполнения. Перестаньте нажимать на пользовательский интерфейс GitHub.
