非同期パターン、エラー処理、ストリーム、モジュール、テスト、パフォーマンス、キャッシュ、ロギングなどをカバーする、Node.js 開発のドメイン固有のベスト プラクティスを提供します。 Node.js プロジェクトをセットアップするとき、またはユーザーが Node.js でのエラー処理、正常なシャットダウン、不安定なテスト、プロファイリング、または環境構成に関するガイダンスが必要なときに使用します。 tsconfig.json または jsonconfig.json の構成、package.json スクリプトのセットアップ、モジュール解決の処理と拡張機能のインポート、および完全な Node.js スタック全体への堅牢なパターンの適用を支援します。
