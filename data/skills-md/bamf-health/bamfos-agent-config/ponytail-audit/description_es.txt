Auditoría de todo el repositorio por sobreingeniería. Al igual que ponytail-review, pero escanea toda la base de código en lugar de un diff: una lista clasificada de qué eliminar, simplificar o reemplazar con stdlib/equivalentes nativos. Úselo cuando el usuario diga "auditar esta base de código", "auditar por sobreingeniería", "qué puedo eliminar de este repositorio", "encontrar hinchazón", "auditoría de cola de caballo" o "/auditoría de cola de caballo". Informe único, no aplica correcciones.
