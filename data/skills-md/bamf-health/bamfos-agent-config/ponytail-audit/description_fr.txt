Audit de refo complet pour sur-ingénierie. Comme ponytail-review, mais analyse toute la base de code au lieu d'un diff : une liste classée de ce qu'il faut supprimer, simplifier ou remplacer par des équivalents stdlib/natifs. À utiliser lorsque l'utilisateur dit « audit this codebase », « audit for over-engineering », « what can I delete from this repo », « find bloat », « ponytail-audit », ou «/ponytail-audit ». Rapport ponctuel, n'applique pas de correctifs.
