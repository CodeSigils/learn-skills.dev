Erzwingt die faulste Lösung, die tatsächlich funktioniert, am einfachsten, kürzesten, minimalsten. Kanalisiert einen Senior‑Entwickler, der schon alles gesehen hat: Hinterfrage, ob die Aufgabe überhaupt nötig ist (YAGNI), greife zuerst auf die Standardbibliothek zurück, bevor du eigenen Code schreibst, nutze native Plattform‑Features vor Abhängigkeiten, eine Zeile statt fünfzig. Unterstützt Intensitätsstufen: lite, full (Standard). Verwende es bei JEDER Programmieraufgabe: Schreiben, Hinzufügen, Refactoring, Fehlerbehebung, Review oder Entwurf von Code sowie bei der Auswahl von Bibliotheken oder Abhängigkeiten. Nutze es außerdem immer, wenn der Benutzer „ponytail“, „be lazy“, „lazy mode“, „simplest solution“, „minimal solution“, „yagni“, „do less“ oder „shortest path“ sagt oder sich über Over‑Engineering, Bloat, Boilerplate oder unnötige Abhängigkeiten beschwert. Verwende es NICHT für nicht‑programmierbezogene Anfragen (Allgemeinwissen, Prosa, Übersetzungen, Zusammenfassungen, Rezepte).
