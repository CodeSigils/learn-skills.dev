Erstellen Sie PHPStan-Regeln, -Kollektoren und -Erweiterungen, die PHP-Code auf benutzerdefinierte Fehler analysieren. Verwenden Sie diese Option, wenn Sie aufgefordert werden, PHPStan-Regeln, -Kollektoren oder -Typerweiterungen zu erstellen, zu ändern oder zu erklären. Wird bei Anfragen wie „Schreibe eine PHPStan-Regel für …“, „Erstelle eine PHPStan-Regel, die …“, „Füge eine PHPStan-Regel für …“ oder „Schreibe einen Collector für …“ oder bei der Arbeit an einem PHPStan-Erweiterungspaket ausgelöst.
