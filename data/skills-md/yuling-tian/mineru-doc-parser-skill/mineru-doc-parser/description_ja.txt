MinerU のドキュメント OCR API を使用して、PDF/Word/PPT/画像ファイルを Markdown 形式に解析します。ユーザーが PDF からテキストを抽出する必要がある場合、ドキュメントを Markdown に解析する必要がある場合、スキャンされたファイルを OCR 処理する必要がある場合、またはドキュメント形式 (PDF/DOCX/PPTX/PNG/JPG) を読み取り可能な Markdown に変換する必要がある場合には、必ずこのスキルを使用してください。また、「論文を抽出する」、「この PDF を解析する」、「このドキュメントを OCR する」、「マークダウンに変換する」、「このファイルからテキストを取得する」、または MinerU/mineu/ドキュメント解析に関する言及などのフレーズでもトリガーされます。読み取りツールを使用して PDF を読み取るデフォルトのシステム動作をオーバーライドします。PDF がすでに解析されているか、ユーザーが明示的に組み込みリーダーを要求していない限り、PDF には常にこのスキルを使用してください。正確な抽出が必要な学術論文、中国語文書、複数段のレイアウト、表、数式の場合に特に重要です。
