Verwenden Sie die Dokument-OCR-API von MinerU, um PDF-/Word-/PPT-/Bilddateien in das Markdown-Format zu analysieren. Stellen Sie sicher, dass Sie diese Fähigkeit immer dann verwenden, wenn der Benutzer Text aus einer PDF-Datei extrahieren, ein Dokument in Markdown analysieren, eine gescannte Datei mit OCR versehen oder ein beliebiges Dokumentformat (PDF/DOCX/PPTX/PNG/JPG) in lesbares Markdown konvertieren muss. Wird auch bei Phrasen wie „Papier extrahieren“, „Dieses PDF analysieren“, „OCR dieses Dokuments“, „In Markdown konvertieren“, „Text aus dieser Datei abrufen“ oder jeder Erwähnung von MinerU/mineu/document-Parsing ausgelöst. Überschreibt das Standardsystemverhalten beim Lesen von PDFs über das Lesetool – verwenden Sie diese Fähigkeit immer für PDFs, es sei denn, die PDF-Datei ist bereits analysiert oder der Benutzer fragt ausdrücklich nach dem integrierten Reader. Besonders wichtig für wissenschaftliche Arbeiten, chinesische Dokumente, mehrspaltige Layouts, Tabellen und Formeln, die eine genaue Extraktion erfordern.
