Аудит и преобразование CSS для использования логических свойств для поддержки RTL/двунаправленного макета. Используйте, когда пользователь просит «сделать CSS RTL-безопасным», «использовать логические свойства», «заменить левое/правое на начало/конец», «проверить CSS для i18n», «интернационализацию CSS», «исправить CSS для RTL», «преобразовать в логические свойства» или при настройке любого проекта, ориентированного на локали RTL (арабский, иврит, персидский, урду). Работает с Tailwind, модулями CSS, ванильным CSS, CSS-in-JS и встроенными стилями. Независимость от библиотеки — работает с любой настройкой i18n.
