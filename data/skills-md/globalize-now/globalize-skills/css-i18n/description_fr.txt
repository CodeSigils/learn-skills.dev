Auditez et convertissez CSS pour utiliser des propriétés logiques pour la prise en charge de la mise en page RTL/bidirectionnelle. À utiliser lorsque l'utilisateur demande de « rendre CSS RTL-safe », « d'utiliser des propriétés logiques », « de remplacer gauche/droite par début/fin », « d'auditer CSS pour i18n », « d'internationaliser CSS », de « corriger CSS pour RTL », de « convertir en propriétés logiques » ou lors de la configuration d'un projet ciblant les paramètres régionaux RTL (arabe, hébreu, persan, ourdou). Fonctionne avec Tailwind, les modules CSS, le CSS Vanilla, le CSS-in-JS et les styles en ligne. Indépendant de la bibliothèque : fonctionne avec n'importe quelle configuration i18n.
