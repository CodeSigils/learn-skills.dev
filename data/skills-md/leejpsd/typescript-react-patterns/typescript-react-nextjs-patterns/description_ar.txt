مرجع TypeScript على مستوى الإنتاج لتطوير الواجهة الأمامية لـ React وNext.js. يغطي تضييق النوع، ودعائم المكونات، والخطافات العامة، والاتحادات التمييزية، مثل const، والإرضاء، والتحقق من Zod، واستعلام TanStack، وحدود الخادم/العميل، والنماذج، وإدارة الحالة، والأداء، وإمكانية الوصول، وتصحيح الأخطاء، ومراجعة التعليمات البرمجية. يُستخدم عندما يعمل المستخدم مع TypeScript في React أو Next.js: أخطاء الكتابة، أو تصميم Props، أو الأدوية العامة، أو كتابة API، أو حدود SSR/CSR، أو مشكلات الترطيب، أو التحقق من صحة النموذج، أو إدارة الحالة، أو الأداء، أو مراجعة التعليمات البرمجية. استخدم أيضًا "كيف يجب أن أكتب هذا؟"، أو "لماذا يحدث هذا الخطأ في النوع؟"، أو أي قرار معماري يتضمن TypeScript في سياق الواجهة الأمامية.
