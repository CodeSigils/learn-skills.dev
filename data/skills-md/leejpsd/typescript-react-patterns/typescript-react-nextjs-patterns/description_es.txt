Referencia de TypeScript de nivel de producción para el desarrollo frontend de React y Next.js. Cubre la reducción de tipos, accesorios de componentes, enlaces genéricos, uniones discriminadas, como constante, satisface, validación de Zod, consulta TanStack, límites de servidor/cliente, formularios, gestión de estado, rendimiento, accesibilidad, depuración y revisión de código. Úselo cuando el usuario trabaja con TypeScript en React o Next.js: errores de tipo, diseño de accesorios, genéricos, escritura de API, límites SSR/CSR, problemas de hidratación, validación de formularios, gestión de estado, rendimiento o revisión de código. Úselo también para "¿cómo debo escribir esto?", "¿por qué ocurre este error de tipo?" o cualquier decisión arquitectónica que involucre TypeScript en un contexto de interfaz.
