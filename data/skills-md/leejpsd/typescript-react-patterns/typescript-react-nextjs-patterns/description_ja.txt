React および Next.js フロントエンド開発のためのプロダクション グレードの TypeScript リファレンス。型の絞り込み、コンポーネント Props、汎用フック、判別共用体、as const、satisfies、Zod 検証、TanStack クエリ、サーバー/クライアント境界、フォーム、状態管理、パフォーマンス、アクセシビリティ、デバッグ、コード レビューをカバーします。ユーザーが React または Next.js で TypeScript を操作する場合に使用します: 型エラー、Props デザイン、ジェネリックス、API タイピング、SSR/CSR 境界、ハイドレーションの問題、フォーム検証、状態管理、パフォーマンス、またはコード レビュー。また、「これをどのように入力すればよいですか?」、「このタイプ エラーが発生するのはなぜですか?」、またはフロントエンド コンテキストでの TypeScript に関係するアーキテクチャ上の決定にも使用します。
