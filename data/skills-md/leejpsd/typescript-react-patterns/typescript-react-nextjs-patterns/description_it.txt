Riferimento TypeScript di livello produttivo per lo sviluppo frontend React e Next.js. Copre restringimento del tipo, componenti Prop, hook generici, unioni discriminate, as const, soddisfa, convalida Zod, query TanStack, limiti server/client, moduli, gestione dello stato, prestazioni, accessibilità, debug e revisione del codice. Da utilizzare quando l'utente lavora con TypeScript in React o Next.js: errori di tipo, progettazione Props, generici, tipizzazione API, limiti SSR/CSR, problemi di idratazione, convalida dei moduli, gestione dello stato, prestazioni o revisione del codice. Utilizzare anche per "come dovrei digitarlo?", "perché si verifica questo errore di tipo?" o qualsiasi decisione architetturale che coinvolga TypeScript in un contesto frontend.
