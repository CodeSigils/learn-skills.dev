Référence TypeScript de qualité production pour le développement frontend React et Next.js. Couvre le rétrécissement du type, les accessoires de composants, les hooks génériques, les unions discriminées, comme const, satisfait, la validation Zod, la requête TanStack, les limites serveur/client, les formulaires, la gestion de l'état, les performances, l'accessibilité, le débogage et la révision du code. À utiliser lorsque l'utilisateur travaille avec TypeScript dans React ou Next.js : erreurs de type, conception d'accessoires, génériques, typage d'API, limites SSR/CSR, problèmes d'hydratation, validation de formulaire, gestion d'état, performances ou révision de code. Utilisez également pour "comment dois-je taper ceci ?", "pourquoi cette erreur de type se produit-elle ?", ou toute décision architecturale impliquant TypeScript dans un contexte frontal.
