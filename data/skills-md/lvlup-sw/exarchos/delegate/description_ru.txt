Отправляйте задачи реализации коллегам по команде агентов в рабочих деревьях git. Триггеры: «делегировать», «отправить задачи», «назначить работу» или /delegate. Создает товарищей по команде, создает рабочие деревья, отслеживает прогресс. Поддерживает флаг --fixes. НЕ используйте для внесения изменений в один файл или для полированного рефакторинга.
