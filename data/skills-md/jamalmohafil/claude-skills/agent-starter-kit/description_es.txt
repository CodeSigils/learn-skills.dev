Configuración de un solo comando para un nuevo agente de codificación de IA. Instala las habilidades iniciales esenciales (find-skills, agent-browser, karpathy-guidelines, ui-ux-pro-max, cavernícola, arabic-design) en más de 70 agentes, además de los complementos/MCP principales de Claude Code (diseño de interfaz, superpoderes, revisión de código, dramaturgo, github, claude-md-management). Úselo cuando el usuario está configurando un nuevo proyecto o un nuevo agente y solicita "las habilidades/MCP con las que debo comenzar", un "paquete de inicio" o "configurar mi agente".
