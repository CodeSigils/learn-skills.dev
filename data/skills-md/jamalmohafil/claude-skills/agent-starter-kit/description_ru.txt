Настройка нового агента кодирования AI с помощью одной команды. Устанавливает основные стартовые навыки (find-skills, агент-браузер, karpathy-guidelines, ui-ux-pro-max, пещерный человек, арабский-дизайн) для более чем 70 агентов, а также основные плагины/MCP Claude Code (дизайн интерфейса, суперспособности, проверка кода, драматург, github, claude-md-management). Используйте, когда пользователь настраивает новый проект или нового агента и запрашивает «навыки/MCP, с которых мне следует начать», «стартовый пакет» или «настроить моего агента».
