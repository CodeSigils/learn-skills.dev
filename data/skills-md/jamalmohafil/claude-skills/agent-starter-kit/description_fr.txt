Configuration en une seule commande pour un nouvel agent de codage IA. Installe les compétences de démarrage essentielles (find-skills, agent-browser, karpathy-guidelines, ui-ux-pro-max, caveman, arabic-design) sur plus de 70 agents, ainsi que les principaux plugins/MCP Claude Code (frontend-design, superpuissances, révision de code, dramaturge, github, claude-md-management). À utiliser lorsque l'utilisateur configure un nouveau projet ou un nouvel agent et demande « les compétences/MCP avec lesquels je devrais commencer », un « pack de démarrage » ou « configurer mon agent ».
