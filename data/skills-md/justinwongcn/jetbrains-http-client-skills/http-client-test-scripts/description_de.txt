Schreiben Sie Automatisierungstestskripte für die *.http-Dateien des IntelliJ-HTTP-Clients. Verwenden Sie diese Funktion, wenn der Benutzer .http-Dateien erstellen, bearbeiten oder debuggen muss, einschließlich: Schreiben von HTTP/GraphQL/WebSocket-Anfragen, Hinzufügen von Antwortassertionstests, Verwenden von Variablen und Umgebungskonfigurationen, Schreiben von Pre-Request- und Response-Handler-Skripten, Konfigurieren von Schleifenanfragen und Importen und Konvertieren von Anfragen von cURL/OpenAPI/Postman. Auch wenn der Benutzer nur „http-Anfrage“, „Schnittstellentest“, „API-Test“, „REST-Test“, „.http-Datei“ oder „HTTP-Client“ erwähnt, sollte diese Funktion aktiviert werden.
