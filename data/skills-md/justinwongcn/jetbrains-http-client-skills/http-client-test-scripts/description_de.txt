Schreiben Sie Automatisierungstestskripte für die *.http-Dateien des IntelliJ-HTTP-Clients. Verwenden Sie diese Fähigkeit, wenn der Benutzer .http-Dateien erstellen, bearbeiten oder debuggen muss, einschließlich: HTTP/GraphQL/WebSocket-Anfragen schreiben, Antwortassertionstests hinzufügen, Variablen und Umgebungskonfigurationen verwenden, Vorabanfrage- und Antworthandlerskripte schreiben, Schleifenanfragen und Importe konfigurieren und Anfragen von cURL/OpenAPI/Postman konvertieren. Auch wenn der Benutzer nur „http-Anfrage“, „Schnittstellentest“, „API-Test“, „REST-Test“, „.http-Datei“ oder „HTTP-Client“ erwähnt, sollte dieser Skill ausgelöst werden.
