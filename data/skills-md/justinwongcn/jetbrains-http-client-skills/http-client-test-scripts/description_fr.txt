Écrivez des scripts de test d'automatisation (*.http) pour le client HTTP IntelliJ. Utilisez cette compétence lorsque l'utilisateur a besoin de créer, modifier ou déboguer des fichiers .http, notamment : écrire des requêtes HTTP/GraphQL/WebSocket, ajouter des tests d'assertion de réponse, utiliser des variables et des configurations d'environnement, écrire des scripts de pré-requête et de gestionnaire de réponse, configurer des requêtes et des importations de boucles et convertir des requêtes à partir de cURL/OpenAPI/Postman. Même si l'utilisateur mentionne uniquement « requête http », « tests d'interface », « tests API », « tests REST », « fichier .http » ou « client HTTP », cette compétence doit être déclenchée.
