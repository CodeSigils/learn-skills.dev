Écrivez des scripts de test d'automatisation pour les fichiers *.http du client HTTP IntelliJ. Utilisez cette fonctionnalité lorsque l'utilisateur a besoin de créer, modifier ou déboguer des fichiers .http, notamment : écrire des requêtes HTTP/GraphQL/WebSocket, ajouter des tests d'assertion de réponse, utiliser des variables et des configurations d'environnement, écrire des scripts de pré-requête et de gestionnaire de réponse, configurer des requêtes et des importations en boucle et convertir des requêtes à partir de cURL/OpenAPI/Postman. Même si l'utilisateur mentionne uniquement « requête http », « test d'interface », « test API », « test REST », « fichier .http » ou « client HTTP », cette fonctionnalité doit être déclenchée.
