IntelliJ HTTP クライアントの *.http ファイル用の自動テスト スクリプトを作成します。この機能は、ユーザーが .http ファイルを作成、編集、またはデバッグする必要がある場合に使用します。これには、HTTP/GraphQL/WebSocket リクエストの作成、レスポンス アサーション テストの追加、変数と環境設定の使用、プレリクエストおよびレスポンス ハンドラ スクリプトの作成、ループされたリクエストとインポートの設定、cURL/OpenAPI/Postman からのリクエストの変換が含まれます。ユーザーが「http リクエスト」、「インターフェイス テスト」、「API テスト」、「REST テスト」、「.http ファイル」、または「HTTP クライアント」のみを指定した場合でも、この機能はトリガーされる必要があります。
