Escriba scripts de prueba de automatización para los archivos *.http del cliente HTTP IntelliJ. Utilice esta capacidad cuando el usuario necesite crear, editar o depurar archivos .http, lo que incluye: escribir solicitudes HTTP/GraphQL/WebSocket, agregar pruebas de aserción de respuesta, usar variables y configuraciones de entorno, escribir scripts de solicitud previa y controlador de respuesta, configurar solicitudes e importaciones en bucle y convertir solicitudes de cURL/OpenAPI/Postman. Incluso si el usuario solo menciona "solicitud http", "prueba de interfaz", "prueba de API", "prueba REST", "archivo .http" o "Cliente HTTP", esta capacidad debe activarse.
