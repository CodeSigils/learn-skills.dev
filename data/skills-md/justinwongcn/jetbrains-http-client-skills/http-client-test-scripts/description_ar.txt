اكتب نصوص اختبار الأتمتة لملفات *.http الخاصة بـ IntelliJ HTTP Client. استخدم هذه الإمكانية عندما يحتاج المستخدم إلى إنشاء ملفات .http أو تحريرها أو تصحيح أخطاءها، بما في ذلك: كتابة طلبات HTTP/GraphQL/WebSocket، وإضافة اختبارات تأكيد الاستجابة، واستخدام المتغيرات وتكوينات البيئة، وكتابة البرامج النصية للطلب المسبق ومعالج الاستجابة، وتكوين الطلبات المتكررة والواردات، وتحويل الطلبات من cURL/OpenAPI/Postman. حتى إذا ذكر المستخدم فقط "طلب http" أو "اختبار الواجهة" أو "اختبار API" أو "اختبار REST" أو "ملف .http" أو "عميل HTTP"، فيجب تفعيل هذه الإمكانية.
