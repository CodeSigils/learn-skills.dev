اكتب نصوص اختبار الأتمتة لملفات *.http في IntelliJ HTTP Client. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء ملفات .http أو تحريرها أو تصحيح أخطائها، بما في ذلك: كتابة طلبات HTTP/GraphQL/WebSocket، وإضافة اختبارات تأكيد الاستجابة، واستخدام المتغيرات وتكوينات البيئة، وكتابة البرامج النصية للطلب المسبق ومعالج الاستجابة، وتكوين طلبات الحلقة وعمليات الاستيراد، وتحويل الطلبات من cURL/OpenAPI/Postman. حتى لو ذكر المستخدم فقط "طلب http" أو "اختبار الواجهة" أو "اختبار API" أو "اختبار REST" أو "ملف .http" أو "عميل HTTP"، فيجب تفعيل هذه المهارة.
