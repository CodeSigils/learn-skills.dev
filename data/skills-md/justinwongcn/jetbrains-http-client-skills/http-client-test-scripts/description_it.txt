Scrivere script di test di automazione per i file *.http di IntelliJ HTTP Client. Utilizza questa funzionalità quando l'utente deve creare, modificare o eseguire il debug di file .http, tra cui: scrivere richieste HTTP/GraphQL/WebSocket, aggiungere test di asserzione della risposta, utilizzare variabili e configurazioni di ambiente, scrivere script di gestione pre-richiesta e risposta, configurare richieste e importazioni in loop e convertire richieste da cURL/OpenAPI/Postman. Anche se l'utente menziona solo "richiesta http", "test dell'interfaccia", "test API", "test REST", "file .http" o "client HTTP", questa funzionalità dovrebbe essere attivata.
