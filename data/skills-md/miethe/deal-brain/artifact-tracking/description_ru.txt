Используйте этот навык при создании, обновлении или запросе артефактов отслеживания, оптимизированных для искусственного интеллекта (файлы прогресса, контекстные примечания, исправления ошибок, журналы наблюдений) в гибридном формате YAML+Markdown для сокращения количества токенов на 95%. Вызов для: создания отслеживания хода выполнения фазы, обновления статуса задачи и блокировщиков, запроса незавершенной работы по этапам, создания отчетов о передаче сеанса, проверки полноты артефакта или переноса существующих файлов уценки в гибридный формат. Предоставляет три встроенных агента (отслеживание артефактов, запрос артефактов и средство проверки артефактов), а также инструменты миграции Python для эффективного многоэтапного отслеживания проектов.
