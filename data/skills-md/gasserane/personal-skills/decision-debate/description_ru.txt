Проведите официальную многоаспектную дискуссию по одному оспариваемому проектному решению MEL/SRHR, а затем передайте Ане читаемый синтез, на основании которого она выберет. Три-пять персон-агентов, каждый из которых сопоставлен с объективом настоящего специалиста, исследуют вызов независимо и слепо друг к другу, затем обсуждают один раунд, затем записывается синтез в форме записки о решении (контекст, варианты, рекомендации, риски, обратимость), при этом соглашения и подлинные разногласия остаются видимыми. Используйте, когда Ане говорит: «обсудите это», «проведите дебаты по принятию решений», «Я не могу сделать выбор между X и Y», «спорьте обе стороны в этом вопросе проектирования», «дайте мне независимые точки зрения на этот вопрос» или называет действительно оспариваемый выбор дизайна MEL, с которым разумные эксперты не согласились бы. Задумано много токенов: резерв для реальных решений. Ни для оттачивания проекта, на который Ане уже опирается (используйте /grill-mel), ни для новых сетевых сборок (используйте мозговой штурм), ни для простого документа с вариантами на телефонной встрече, которую вы не хотите обсуждать (используйте /decision-memo), и никогда для создания чего-либо.
