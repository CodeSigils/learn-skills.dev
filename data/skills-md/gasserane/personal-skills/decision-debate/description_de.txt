Führen Sie eine formelle, multiperspektivische Debatte über eine einzelne umstrittene MEL/SRHR-Entwurfsentscheidung und geben Sie Ane dann eine lesbare Zusammenfassung, für die sie sich entscheidet. Drei bis fünf Persona-Agenten, die jeweils einer echten Spezialistenlinse zugeordnet sind, recherchieren den Anruf unabhängig und blind füreinander, debattieren dann eine Runde, dann wird eine Synthese in Form eines Entscheidungsmemos verfasst (Kontext, Optionen, Empfehlung, Risiken, Reversibilität), wobei Vereinbarungen und echte Meinungsverschiedenheiten beide sichtbar bleiben. Wird verwendet, wenn Ane sagt: „Debattieren Sie darüber“, „führen Sie eine Entscheidungsdebatte durch“, „Ich kann mich nicht zwischen Von Natur aus Token-lastig: Reserve für echte Entscheidungen. Nicht zum Verfeinern eines Designs, auf das sich Ane bereits stützt (verwenden Sie /grill-mel), nicht für Netz-Neukonstruktionen (verwenden Sie Brainstorming), nicht für ein einfaches Optionspapier bei einem Anruf, über den Sie nicht debattieren müssen (verwenden Sie /decision-memo) und niemals zum Erstellen von etwas.
