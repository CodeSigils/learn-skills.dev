Run the qa-reviewer maker-checker gate against one finished text deliverable, without a full Ann orchestration. Use when Ane types "/check-deliverable <file>", or says "check this deliverable", "run the qa gate on this file", "qa-review this brief", "run qa-reviewer on this file", or wants a finished markdown brief checked against the full qa gate on its own. Spawns the existing qa-reviewer agent alone against a single markdown or text file, sets the audience tier (default Tier 1 / colleague; override with --tier 2 and --subgroup), and returns a BLUF verdict plus the full qa_block. Read-only: it rewrites nothing and writes nothing to disk. Not for producing a deliverable (use /ann), not for voice rewriting (use /ane-voice), not for code review (use /code-review). Refuses Office binaries (.docx/.xlsx/.pptx) because qa-reviewer cannot parse them.
