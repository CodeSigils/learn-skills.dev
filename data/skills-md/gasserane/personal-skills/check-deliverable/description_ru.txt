Запустите программу проверки создателя-проверщика qa-reviewer для одного готового текстового результата без полной оркестровки Энн. Используйте, когда Ане вводит «/check-deliverable <file>» или говорит «проверьте этот результат», «запустите контроль качества для этого файла», «qa-review this Brief», «запустите qa-reviewer для этого файла» или хочет, чтобы готовый бриф уценки самостоятельно проверился по полному контрольному шлюзу. Создает существующий агент qa-reviewer отдельно для одного уценочного или текстового файла, устанавливает уровень аудитории (уровень 1 по умолчанию / коллега; переопределить с помощью --tier 2 и --subgroup) и возвращает вердикт BLUF плюс полный qa_block. Только для чтения: ничего не перезаписывает и ничего не записывает на диск. Не для создания результата (используйте /ann), не для переписывания голоса (используйте /ane-voice), не для проверки кода (используйте /code-review). Отклоняет двоичные файлы Office (.docx/.xlsx/.pptx), поскольку qa-reviewer не может их проанализировать.
