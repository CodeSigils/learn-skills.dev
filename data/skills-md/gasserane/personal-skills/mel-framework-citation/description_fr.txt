Appliquer les citations standard des publications IPPF/UNFPA/ONUSIDA sur les résultats MEL/SRHR. À utiliser chaque fois qu'Ane produit une théorie du changement, une conception d'évaluation, un ensemble d'indicateurs, un rapport de donateur ou une analyse de programme SDSR. Injecte les versions actuelles du framework faisant autorité avec l'auteur et l'année, signale les versions obsolètes et applique le protocole data-gap. Ne pas utiliser pour des travaux non MEL.
