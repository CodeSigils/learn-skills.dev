Преобразуйте краткое изложение доказательств исследователя в один из четырех типов результатов обучения: двухстраничное краткое изложение для MA, пакет семинаров / CoP, региональное учебное описание или памятку для доноров / руководства. Используйте, когда Ане запрашивает «учебный продукт», «обучающее краткое описание», «Магистерское краткое изложение из этого краткого обзора доказательств», «пакет семинаров», «пакет CoP», «региональное учебное краткое описание», «записку для донора по результатам исследования», «управленческую записку по результатам исследования» или напрямую называет один из четырех типов результатов. Читается из одного раздела Researcher Evidence Brief в разделе `literature-reviews/<slug>/`. Повторно использует только проверенные источники резюме; никогда не фабрикует цитат. Применяет шаблон бренда IPPF Visual Identity 2025 и рабочий реестр уровня 1.
