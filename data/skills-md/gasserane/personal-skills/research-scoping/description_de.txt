Eine schnelle Single-Pass-Scoping-Map, die die Perspektiven aufzeigt, die eine MEL/SRHR-Frage erfordert, wo diese Perspektiven in Konflikt stehen und ob die Frage eine vollständige Orchestrierung wert ist – bevor Token für eine festgelegt werden. Erstellt eine Karte und ein Triage-Urteil, niemals Zitate oder Feststellungen. Verwenden Sie diese Option, wenn Ane sagt: „Umfassen Sie dies“, „Forschungsumfang“, „zeichnen Sie die Blickwinkel ab“, „Welche Perspektiven sind dafür erforderlich“, „Ist das einen vollständigen /ann-Lauf wert“, „Selektieren Sie dies, bevor ich es baue“ oder möchte einen günstigen ersten Blick auf eine Frage, einen Vorschlagswinkel, eine Lernfrage oder einen Bewertungsrahmen. Kein Interview mit Ane (verwenden Sie /grill-mel), kein Liefergegenstand oder irgendwelche Quellenbeweise (verwenden Sie /ann, /researcher oder /evidence-synthesize) und keine Multi-Agenten-Debatte (verwenden Sie /decision-debate).
