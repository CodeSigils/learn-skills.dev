Busque más de 250 millones de trabajos académicos directamente a través de la API de OpenAlex: búsqueda rápida, prueba de duplicación, mapa de debate (artículos de anclaje), obtención forense de una afirmación específica, división de época en un año, además de una escalada de consenso para búsquedas filtradas por diseño (tipo de estudio, tamaño de muestra, nivel de revista). Úselo cuando Ane quiera encontrar literatura publicada, obtener una afirmación, artículos de referencia o saber si ya se ha respondido una pregunta. Para una revisión de evidencia estructurada completa, utilice /evidence-síntesis; para un investigador/uso breve de evidencia de nivel COMPLEJO. No para gestión de referencias (Zotero vía /li) ni para la propia biblioteca de Ane (búsqueda de conocimiento mcp).
