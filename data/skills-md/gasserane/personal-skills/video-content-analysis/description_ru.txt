Преобразуйте видеофайлы FGD/вебинара/SBCC в структурированный пакет артефактов (расшифровку, кадры, манифест, сводку BLUF уровня 1), который могут использовать существующие специалисты MEL. Используйте, когда Ане просит «проанализировать видео», «расшифровать фокус-группу», «обработать запись вебинара», «подвести итог записи собрания» или запустить `/analyze-video <path>`. Многоуровневая транскрипция (локальный Whisper для конфиденциальных данных; поток M365 для внутренних/общедоступных). Конфиденциальность + согласие, подтвержденное конструкцией. Подсказка обратной связи для каждого запуска поддерживает цикл самосовершенствования.
