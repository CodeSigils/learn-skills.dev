Crea artefatti Power BI con marchio IPPF da input analitici. Da utilizzare quando Ane chiede di creare, eseguire il supporto o aggiornare un dashboard di Power BI, un modello semantico, misure DAX o un progetto .pbip. Applica il marchio IPPF Visual Identity 2025, le misure DAX standard MEL e tre ricette di pagine standard (dashboard degli indicatori, disaggregazione del patrimonio netto, scheda metodologica). Richiede la CLI pbi (pbi-cli-tool, nome comando `pbi`) installata e Power BI Desktop in esecuzione con un file .pbip aperto.
