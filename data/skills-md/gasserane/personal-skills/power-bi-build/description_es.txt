Cree artefactos Power BI con la marca IPPF a partir de datos analíticos. Úselo cuando Ane solicite crear, desarrollar o actualizar un panel de Power BI, un modelo semántico, medidas DAX o un proyecto .pbip. Aplica la marca IPPF Visual Identity 2025, medidas DAX estándar MEL y tres recetas de páginas estándar (panel de indicadores, desagregación de equidad, tarjeta de metodología). Requiere la CLI de pbi (pbi-cli-tool, nombre de comando `pbi`) instalada y Power BI Desktop ejecutándose con un .pbip abierto.
