قم ببناء منتجات Power BI التي تحمل العلامة التجارية IPPF من المدخلات التحليلية. يُستخدم عندما يطلب Ane إنشاء لوحة معلومات Power BI أو نموذج دلالي أو مقاييس DAX أو مشروع .pbip أو دعمها أو تحديثها. يطبق العلامة التجارية IPPF Visual Identity 2025 ومقاييس DAX القياسية MEL وثلاث وصفات قياسية للصفحات (لوحة معلومات المؤشر، وتصنيف الأسهم، وبطاقة المنهجية). يتطلب تثبيت pbi CLI (أداة pbi-cli، اسم الأمر `pbi`) وتشغيل Power BI Desktop مع فتح .pbip.
