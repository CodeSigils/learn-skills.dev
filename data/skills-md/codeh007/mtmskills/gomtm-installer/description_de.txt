Verwenden Sie diese Option, wenn Sie einen neuen Linux-Server mit gomtm install über SSH initialisieren, gomtm install-Befehlsverträge validieren oder entscheiden, ob gomtm install oder gomtm install --dev ausgeführt werden soll. Wird auch verwendet, wenn Sie gomtm-Installationsdokumente reparieren oder veraltete --stage/installer --target-Workflows vermeiden.
