Используйте при инициализации нового сервера Linux с установкой gomtm через SSH, проверке контрактов команд установки gomtm или принятии решения о запуске gomtm install или gomtm install --dev. Также используйте при исправлении документации по установке gomtm или при отказе от устаревших рабочих процессов --stage/installer --target.
