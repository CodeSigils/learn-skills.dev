Utilisez le navigateur d'agent avec le protocole Chrome DevTools pour automatiser les applications de bureau Electron (VS Code, Slack, Discord, Figma, Notion, Spotify, etc.). Il est utilisé lorsque les utilisateurs doivent interagir avec les applications Electron, automatiser les applications de bureau, se connecter à une application en cours d'exécution, contrôler les applications natives ou tester les applications Electron. Les phrases de déclenchement incluent « automatiser l'application Slack », « contrôler VS Code », « interagir avec l'application Discord », « tester cette application Electron », « se connecter à l'application de bureau » et toutes les tâches nécessitant l'automatisation des applications Electron natives.
