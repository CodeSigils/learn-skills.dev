Utilisez le navigateur d'agent pour automatiser les applications de bureau Electron (VSCode, Slack, Discord, Figma, Notion, Spotify, etc.) via le protocole Chrome DevTools. Il est utilisé lorsque les utilisateurs doivent interagir avec une application Electron, automatiser une application de bureau, se connecter à une application en cours d'exécution, contrôler une application native ou tester une application Electron. Les phrases de déclenchement incluent « automatiser l'application Slack », « contrôler VSCode », « interagir avec l'application Discord », « tester cette application Electron », « se connecter à l'application de bureau » et toute tâche nécessitant l'automatisation d'une application Electron native.
