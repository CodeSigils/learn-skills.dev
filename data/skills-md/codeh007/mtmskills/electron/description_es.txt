Utilice el navegador agente con el protocolo Chrome DevTools para automatizar las aplicaciones de escritorio de Electron (VS Code, Slack, Discord, Figma, Notion, Spotify, etc.). Se utiliza cuando el usuario necesita interactuar con una aplicación de Electron, automatizar aplicaciones de escritorio, conectarse a una aplicación en ejecución, controlar aplicaciones nativas o probar aplicaciones de Electron. Las frases desencadenantes incluyen "automatizar la aplicación Slack", "controlar VS Code", "interactuar con la aplicación Discord", "probar esta aplicación Electron", "conectarse a la aplicación de escritorio" y cualquier tarea que requiera automatizar aplicaciones nativas de Electron.
