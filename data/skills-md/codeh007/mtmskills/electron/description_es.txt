Utilice el navegador de agentes para automatizar las aplicaciones de escritorio de Electron (VSCode, Slack, Discord, Figma, Notion, Spotify, etc.) a través del protocolo Chrome DevTools. Se utiliza cuando los usuarios necesitan interactuar con una aplicación de Electron, automatizar una aplicación de escritorio, conectarse a una aplicación en ejecución, controlar una aplicación nativa o probar una aplicación de Electron. Las frases desencadenantes incluyen "automatizar la aplicación Slack", "controlar VSCode", "interactuar con la aplicación Discord", "probar esta aplicación Electron", "conectarse a la aplicación de escritorio" y cualquier tarea que requiera automatizar una aplicación Electron nativa.
