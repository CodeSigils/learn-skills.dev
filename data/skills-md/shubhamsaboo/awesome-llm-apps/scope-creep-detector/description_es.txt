Analiza git diffs frente a una intención declarada de detectar cambios en el alcance, archivos no relacionados, solicitudes de extracción amplias, cambios que crecieron más allá de una solución, adiciones de dependencias, cambios de nombre de API públicas, ediciones de configuración o CI, fragmentos de gran tamaño y archivos de solo formato. Úselo cuando el usuario pregunta si un cambio superó la solución, si un PR es demasiado amplio o qué cosas no relacionadas tocaron y quiere mantener, dividir o justificar la orientación. Opera localmente y fuera de línea.
