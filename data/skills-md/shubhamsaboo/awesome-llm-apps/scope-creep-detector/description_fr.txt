Analyse les différences de git par rapport à une intention déclarée de détecter la dérive de la portée, les fichiers non liés, les demandes d'extraction larges, les modifications qui se sont développées au-delà d'un correctif, les ajouts de dépendances, les renommages d'API publiques, les modifications de configuration ou de CI, les morceaux surdimensionnés et les fichiers de formatage uniquement. À utiliser lorsque l'utilisateur demande si un changement a dépassé le correctif, si un PR est trop large ou quels éléments sans rapport il a touchés et souhaite conserver, diviser ou justifier des conseils. Fonctionne localement et hors ligne.
