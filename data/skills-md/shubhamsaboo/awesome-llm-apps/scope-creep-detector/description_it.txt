Analizza le differenze git rispetto a un intento dichiarato per rilevare spostamenti dell'ambito, file non correlati, richieste pull generiche, modifiche cresciute oltre una correzione, aggiunte di dipendenze, ridenominazioni di API pubbliche, modifiche di configurazione o CI, blocchi di grandi dimensioni e file di sola formattazione. Da utilizzare quando l'utente chiede se un cambiamento è andato oltre la correzione, un PR è troppo ampio o quali elementi non correlati hanno toccato e desidera mantenere, dividere o giustificare la guida. Funziona localmente e offline.
