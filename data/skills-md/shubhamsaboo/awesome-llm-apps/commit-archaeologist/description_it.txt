Ricostruisce il motivo per cui esiste il codice dalla cronologia git locale, incluso il commit introduttivo, le modifiche successive, gli autori attuali, i file associati ripetuti e il probabile intento. Da utilizzare quando l'utente chiede "perché esiste questo codice", "chi ha scritto questa funzione e perché" o per "spiegare la storia di questa funzione" prima di una riscrittura, un refactoring o una modifica rischiosa. Funziona interamente a livello locale.
