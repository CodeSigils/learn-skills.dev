Comprueba los manifiestos de dependencia de requisitos.txt, pyproject.toml y package.json para detectar armas de dependencia directa a nivel de superficie: pines de seguimiento de biblioteca estándar, backports abandonados, dependencias no fijadas y conflictos intramanifiestos obvios, además de versiones eliminadas de PyPI opcionales. Úselo cuando el usuario solicita verificar un manifiesto para detectar problemas de dependencia, pregunta por qué las dependencias no se instalan o si hay algún problema con sus dependencias, quiere una autopsia de dependencia o sospecha que el manifiesto de dependencia está podrido. Se ejecuta sin conexión de forma predeterminada como una herramienta local para el propio proyecto del usuario, no como CI del repositorio.
