Analysez un référentiel et générez un rapport d'analyse approfondi et fondé sur des preuves couvrant l'architecture, la pile technologique, les fonctionnalités de base et les risques. À utiliser lorsque l'utilisateur souhaite une « analyse de projet », une « analyse du code source », une « révision de la base de code », une « analyse de l'architecture », une « analyse de la pile technologique », un « rapport de présentation du projet », un « audit de code » ou demande à comprendre un projet dans son ensemble. Se déclenche également lorsque l'utilisateur fournit un chemin de répertoire et demande une analyse, une révision ou une compréhension du projet.
