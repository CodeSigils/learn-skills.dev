ينشئ امتدادات موفر السياق لتطبيقات Wix CLI - مكونات منطقية (بدون واجهة مستخدم) تعرض الحالة والوظائف والتكوين المشترك لمكونات الموقع الفرعي عبر خطافات React وربط المحرر. يُستخدم عند إنشاء موفر سياق، أو مشاركة الحالة بين المكونات، أو إنشاء رابط سياق (useContext)، أو إنشاء نمط موفر/مستهلك، أو توصيل تبعيات السياق، أو استخدام Editor Binding للسياق. يمكن لمكونات الموقع فقط استهلاك موفري السياق — لا تستخدمه مع عناصر واجهة المستخدم أو المكونات الإضافية للموقع.
