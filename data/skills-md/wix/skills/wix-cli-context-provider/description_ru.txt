Создает расширения поставщика контекста для приложений Wix CLI — логические компоненты (без пользовательского интерфейса), которые предоставляют общее состояние, функции и конфигурацию компонентам дочернего сайта через перехватчики React и привязку редактора. Используйте при создании поставщика контекста, совместном использовании состояния между компонентами, создании привязки контекста (useContext), построении шаблона поставщика/потребителя, подключении контекстных зависимостей или использовании привязки редактора для контекста. Только компоненты сайта могут использовать поставщиков контекста — НЕ используйте для виджетов сайта или плагинов сайта.
