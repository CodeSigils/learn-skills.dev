Crea extensiones de proveedor de contexto para aplicaciones Wix CLI: componentes lógicos (sin interfaz de usuario) que exponen el estado, las funciones y la configuración compartidos a los componentes del sitio secundario a través de enlaces de React y Editor Binding. Úselo al crear un proveedor de contexto, compartir el estado entre componentes, crear un enlace de contexto (useContext), crear un patrón de proveedor/consumidor, conectar dependencias de contexto o usar el enlace del editor para el contexto. Solo los componentes del sitio pueden consumir proveedores de contexto; NO los use para widgets o complementos del sitio.
