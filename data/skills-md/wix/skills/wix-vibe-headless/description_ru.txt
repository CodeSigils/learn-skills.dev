Только клиентские, независимые шаблоны REST для подключения уже созданного внешнего интерфейса (приложение с кодом Vibe, проект HTML/JSX/Vite, экспорт инструментов дизайна) к действующему сайту Wix через общедоступный WIX_CLIENT_ID сайта — браузер взаимодействует с Wix напрямую, без SDK, без серверной части, без этапа сборки. Один навык, охватывающий каждое бизнес-решение Wix: Магазины/витрина электронной коммерции (продукты, корзина, оформление заказа), Бронирование (услуги, места, встречи), Блог (публикации, категории, теги), События и билеты (просмотр, RSVP, продажа билетов), Портфолио (коллекции, проекты, галереи), Рестораны (меню, онлайн-заказ, бронирование), Данные CMS/Wix (список, детали, фильтр, формы, CRUD), Планы ценообразования (членство, подписки, оформление заказа) и Участники (настраиваемый вход в систему — электронная почта+пароль, Google/Facebook и пользовательский единый вход — плюс области учетной записи и контент, доступный участникам). Каждая вертикаль поставляется с копией уровня REST и инструкциями по подключению. Доступно только для чтения содержимого владельца — никогда не подготавливает и не имитирует данные. Триггеры: подключить мой магазин/магазин Wix, создать витрину через Wix, добавить корзину и оформить заказ, подключить Wix Bookings, назначать встречи/бронировать, показывать мой блог Wix, перечислять мои мероприятия Wix, продавать билеты, принимать ответы, создавать портфолио из портфолио Wix, показывать меню моего ресторана/заказывать онлайн/бронировать столик, отображать мою коллекцию Wix CMS, подключать контактную форму к Wix, продавать планы членства/подписки, добавлять логин/регистрацию участника, let участники входят в систему с помощью Google или Facebook, настраиваемая страница входа, страница учетной записи/профиля, вход в контент после входа в систему, вход с помощью SSO/Okta, «вот мой WIX_CLIENT_ID», подключение этого приложения к моему сайту Wix через REST.
