サイトのパブリック WIX_CLIENT_ID を介して、構築済みのフロントエンド (バイブコーディングされたアプリ、HTML/JSX/Vite プロジェクト、デザインツールのエクスポート) をライブ Wix サイトに接続するための、クライアントのみの依存関係のない REST スキャフォールドです。ブラウザは、SDK、バックエンド、ビルドステップなしで Wix と直接通信します。すべての Wix ビジネス ソリューションをカバーする 1 つのスキル: 店舗/eコマース店頭 (商品、カート、チェックアウト)、予約 (サービス、スロット、予約)、ブログ (投稿、カテゴリ、タグ)、イベントとチケット (閲覧、RSVP、発券)、ポートフォリオ (コレクション、プロジェクト、ギャラリー)、レストラン (メニュー、オンライン注文、予約)、CMS / Wix データ (リスト、詳細、フィルター、フォーム、CRUD)、価格設定プラン (メンバーシップ、サブスクリプション、チェックアウト)、およびメンバー (カスタム ログイン - 電子メール + パスワード、Google/Facebook、カスタム SSO - およびアカウント エリアとメンバー ゲート コンテンツ)。各バーティカルには、そのままコピーした REST レイヤーと配線手順が同梱されています。所有者のコンテンツに対する読み取り専用 - データをプロビジョニングしたり、モックしたりすることはありません。トリガー: Wix ストア/ショップに接続する、Wix 上にストアフロントを構築する、カートとチェックアウトを追加する、Wix ブッキングに接続する、アポイントメント/予約を取る、Wix ブログを表示する、Wix イベントをリストする、チケットを販売する、出欠確認を取る、Wix ポートフォリオからポートフォリオを作成する、レストランのメニューを表示する/オンラインで注文する/テーブルを予約する、Wix CMS コレクションを表示する、Wix に問い合わせフォームを送信する、メンバーシップ/サブスクリプション プランを販売する、メンバー ログイン/サインアップを追加する、メンバーに許可するGoogle または Facebook でログイン、カスタム ログイン ページ、アカウント / プロフィール ページ、ログインの背後にあるゲート コンテンツ、SSO/Okta でサインイン、「ここに私の WIX_CLIENT_ID があります」、このアプリを REST 経由で私の Wix サイトに接続します。これは、既存のサイト上の CLIENT-ONLY REST 統合に使用します。 SDK + Wix CLI のビルド、ホスティング、およびワンプロンプトの新しいサイトの作成には、代わりに「wix-headless」を使用してください。
