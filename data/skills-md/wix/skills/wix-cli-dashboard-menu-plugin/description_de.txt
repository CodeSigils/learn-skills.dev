MUSS immer dann verwendet werden, wenn der Benutzer einen anklickbaren Menüpunkt, eine Aktion oder eine Option zum Menü „Mehr Aktionen“, „Massenaktionen“ oder Kontextmenü einer vorhandenen Wix-Dashboard-Seite hinzufügen möchte. Dazu gehört jede Anfrage zum Hinzufügen von Aktionen/Optionen/Elementen zu Menüs auf den Dashboard-Seiten Wix Stores (Produkte, Inventar), Wix Bookings (Kalender, Dienstleistungen, Mitarbeiter, Buchungsliste), Wix Blog (Beiträge, Kategorien, Tags), Wix eCommerce (Bestellungen), Wix Events, Wix CRM (Kontakte) oder Wix Restaurants (Reservierungen, Online-Bestellungen, Menüs). Auslösen bei Phrasen wie: Menüelement hinzufügen, Aktion zum Menü hinzufügen, Option zu weiteren Aktionen hinzufügen, Massenaktion, benutzerdefinierte Aktion im Dashboard-Menü, Dashboard-Menü erweitern, Dashboard-Menü-Plugin, Kontextmenü-Aktion auf Dashboard-Seite. NICHT verwenden für: visuelle Widgets/Plugins, die in Dashboard-Seitenslots eingebettet sind (verwenden Sie wix-cli-dashboard-plugin), eigenständige Dashboard-Seiten (verwenden Sie wix-cli-dashboard-page), eigenständige Modalitäten (verwenden Sie wix-cli-dashboard-modal) oder Website-bezogene Benutzeroberflächen.
