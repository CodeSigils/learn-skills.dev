每當使用者想要為現有 Wix 儀表板頁面的更多操作選單、批次操作選單或上下文選單新增可點選選單項目、操作或選項時，必須使用。這包括向 Wix 商店（產品、庫存）、Wix 預訂（日曆、服務、員工、預訂清單）、Wix 部落格（貼文、類別、標籤）、Wix 電子商務（訂單）、Wix 活動、Wix CRM（聯絡人）或 Wix 餐廳（預訂、線上訂單、菜單）儀表板頁面上的菜單添加/選項/項目的任何要求。觸發以下短語：新增選單項目、新增操作、新增至更多操作選項、批次操作、儀表板選單中的自訂操作、擴充儀表板選單、儀表板選單外掛程式、儀表板頁面上的上下文選單操作。請勿用於：儀表板頁面槽中嵌入的可視化小部件/插件（使用 wix-cli-dashboard-plugin）、獨立儀表板頁面（使用 wix-cli-dashboard-page）、獨立模態（使用 wix-cli-dashboard-modal）或面向網站的 UI。
