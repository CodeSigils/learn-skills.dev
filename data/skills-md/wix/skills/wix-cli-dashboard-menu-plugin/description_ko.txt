사용자가 기존 Wix 대시보드 페이지의 추가 작업 메뉴, 대량 작업 메뉴 또는 컨텍스트 메뉴에 클릭 가능한 메뉴 항목, 작업 또는 옵션을 추가하려고 할 때마다 사용해야 합니다. 여기에는 Wix Stores(제품, 재고), Wix Bookings(캘린더, 서비스, 직원, 예약 목록), Wix 블로그(게시물, 카테고리, 태그), Wix 전자상거래(주문), Wix 이벤트, Wix CRM(연락처) 또는 Wix 레스토랑(예약, 온라인 주문, 메뉴) 대시보드 페이지의 메뉴에 작업/옵션/항목을 추가하라는 요청이 포함됩니다. 메뉴 항목 추가, 메뉴에 작업 추가, 더 많은 작업에 옵션 추가, 대량 작업, 대시보드 메뉴의 사용자 지정 작업, 대시보드 메뉴 확장, 대시보드 메뉴 플러그인, 대시보드 페이지의 상황에 맞는 메뉴 작업과 같은 문구에 대해 트리거합니다. 다음에는 사용하지 마십시오: 대시보드 페이지 슬롯에 포함된 시각적 위젯/플러그인(wix-cli-dashboard-plugin 사용), 독립형 대시보드 페이지(wix-cli-dashboard-page 사용), 독립형 모달(wix-cli-dashboard-modal 사용) 또는 사이트 지향 UI.
