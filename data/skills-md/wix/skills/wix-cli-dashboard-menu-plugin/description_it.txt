DEVE essere utilizzato ogni volta che l'utente desidera aggiungere una voce di menu, un'azione o un'opzione cliccabile al menu Altre azioni, al menu Azioni collettive o al menu contestuale di una pagina Wix Dashboard esistente. Ciò include qualsiasi richiesta di aggiungere azioni/opzioni/elementi ai menu su Wix Stores (prodotti, inventario), Wix Bookings (calendario, servizi, personale, elenco prenotazioni), Wix Blog (post, categorie, tag), Wix eCommerce (ordini), Wix Events, Wix CRM (contatti) o pagine dashboard di Wix Restaurants (prenotazioni, ordini online, menu). Attiva frasi come: aggiungi voce di menu, aggiungi azione al menu, aggiungi opzione a più azioni, azione collettiva, azione personalizzata nel menu del dashboard, estendi menu del dashboard, plug-in del menu del dashboard, azione del menu contestuale sulla pagina del dashboard. NON utilizzare per: widget/plugin visivi incorporati negli slot della pagina del dashboard (utilizzare wix-cli-dashboard-plugin), pagine del dashboard autonome (utilizzare wix-cli-dashboard-page), modalità autonome (utilizzare wix-cli-dashboard-modal) o interfaccia utente rivolta al sito.
