DOIT être utilisé chaque fois que l'utilisateur souhaite ajouter un élément de menu, une action ou une option cliquable au menu plus d'actions, au menu d'actions groupées ou au menu contextuel d'une page de tableau de bord Wix existante. Cela inclut toute demande d'ajout d'actions/options/éléments aux menus sur les pages du tableau de bord Wix Stores (produits, inventaire), Wix Bookings (calendrier, services, personnel, liste de réservation), Wix Blog (articles, catégories, tags), Wix eCommerce (commandes), Wix Events, Wix CRM (contacts) ou Wix Restaurants (réservations, commandes en ligne, menus). Déclenchez des expressions telles que : ajouter un élément de menu, ajouter une action au menu, ajouter une option à plus d'actions, action groupée, action personnalisée dans le menu du tableau de bord, étendre le menu du tableau de bord, plug-in du menu du tableau de bord, action du menu contextuel sur la page du tableau de bord. Ne PAS utiliser pour : les widgets/plugins visuels intégrés dans les emplacements de page de tableau de bord (utilisez wix-cli-dashboard-plugin), les pages de tableau de bord autonomes (utilisez wix-cli-dashboard-page), les modaux autonomes (utilisez wix-cli-dashboard-modal) ou l'interface utilisateur orientée site.
