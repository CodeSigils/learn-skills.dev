يجب استخدامه عندما يريد المستخدم إضافة عنصر قائمة قابل للنقر أو إجراء أو خيار إلى قائمة الإجراءات الإضافية أو قائمة الإجراءات المجمعة أو قائمة السياق لصفحة لوحة تحكم Wix الحالية. يتضمن ذلك أي طلب لإضافة إجراءات/خيارات/عناصر إلى القوائم في متاجر Wix (المنتجات والمخزون)، أو Wix Bookings (التقويم، الخدمات، الموظفون، قائمة الحجز)، مدونة Wix (المشاركات، الفئات، العلامات)، Wix eCommerce (الطلبات)، أحداث Wix، Wix CRM (جهات الاتصال)، أو مطاعم Wix (الحجوزات، الطلبات عبر الإنترنت، القوائم) صفحات لوحة المعلومات. تشغيل عبارات مثل: إضافة عنصر قائمة، إضافة إجراء إلى القائمة، إضافة خيار لمزيد من الإجراءات، الإجراء المجمع، الإجراء المخصص في قائمة لوحة المعلومات، توسيع قائمة لوحة المعلومات، البرنامج المساعد لقائمة لوحة المعلومات، إجراء قائمة السياق على صفحة لوحة المعلومات. لا تستخدمه مع: الأدوات المرئية/المكونات الإضافية المضمنة في فتحات صفحة لوحة المعلومات (استخدم wix-cli-dashboard-plugin)، أو صفحات لوحة المعلومات المستقلة (استخدم wix-cli-dashboard-page)، أو الوسائط المستقلة (استخدم wix-cli-dashboard-modal)، أو واجهة المستخدم المواجهة للموقع.
