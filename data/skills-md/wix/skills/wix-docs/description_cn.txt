在编写 Wix 代码之前查找 Wix API/SDK 文档以确认确切的端点、HTTP 方法、请求/响应形状、字段、枚举或错误 - 永远不要凭记忆猜测 Wix API。查找是一个简短的流程：找到正确的页面，然后阅读它。两种方式：(1) 普通的“curl”（零依赖） - 通过**语义搜索**（“POST /mcp-docs-search/v1/docs/search”，自然语言“{ search_term, document_type }”）**或通过从“llms.txt”根浏览**文档树作为菜单（将“.md”附加到任何文档路径），然后通过将“.md”附加到其 URL 来读取页面； (2) Wix MCP 文档工具（如果您的代理拥有）。触发器：查找 Wix API、查找 Wix 端点/方法、确认 Wix 请求正文或字段、验证 Wix API 形状、探索 Wix 文档、我调用哪个 Wix API、读取 Wix 方法架构。
