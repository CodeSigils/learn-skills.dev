Wix 코드를 작성하기 전에 Wix API/SDK 문서를 찾아 정확한 엔드포인트, HTTP 메서드, 요청/응답 형태, 필드, 열거형 또는 오류를 확인하세요. 절대 메모리에서 Wix API를 추측하지 마세요. 조회는 짧은 흐름입니다. 올바른 페이지를 찾은 다음 읽으세요. 두 가지 방법: (1) 일반 `curl`(종속성 없음) — **의미 체계 검색**(`POST /mcp-docs-search/v1/docs/search`, 자연어 `{ search_term, document_type }`)으로 페이지를 찾거나 `llms.txt` 루트에서 메뉴로 문서 트리를 탐색**하여(모든 문서 경로에 `.md` 추가) URL에 `.md`를 추가하여 페이지를 읽습니다. (2) 대리인이 보유하고 있는 Wix MCP 문서 도구. 트리거: Wix API 조회, Wix 엔드포인트/메서드 찾기, Wix 요청 본문 또는 필드 확인, Wix API 형태 확인, Wix API를 호출하는 Wix 문서 탐색, Wix 메서드 스키마 읽기.
