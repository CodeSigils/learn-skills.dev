Schauen Sie in der API/SDK-Dokumentation von Wix nach, um einen genauen Endpunkt, eine HTTP-Methode, eine Anforderungs-/Antwortform, ein Feld, eine Enumeration oder einen Fehler zu bestätigen, bevor Sie Wix-Code schreiben – erraten Sie niemals eine Wix-API aus dem Gedächtnis. Eine Suche ist ein kurzer Ablauf: Finden Sie die richtige Seite und lesen Sie sie dann. Zwei Möglichkeiten: (1) einfaches „Curl“ (keine Abhängigkeiten) – Finden Sie eine Seite durch **semantische Suche** („POST /mcp-docs-search/v1/docs/search“, natürliche Sprache „{ search_term, document_type}“) **oder durch Durchsuchen** des Dokumentenbaums als Menü aus dem Stammverzeichnis „llms.txt“ (hängen Sie „.md“ an einen beliebigen Dokumentenpfad an) und lesen Sie dann die Seite nach Anhängen von „.md“ an seine URL; und (2) die MCP-Dokumentationstools von Wix, sofern Ihr Agent über diese verfügt. Auslöser: Suchen Sie nach einer Wix-API, finden Sie den Endpunkt/die Methode von Wix, bestätigen Sie den Text oder das Feld einer Wix-Anfrage, überprüfen Sie ein Wix-API-Shape, erkunden Sie Wix-Dokumente, welche Wix-API rufe ich auf, lesen Sie ein Wix-Methodenschema.
