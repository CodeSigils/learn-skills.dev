Wix コードを記述する前に、Wix API/SDK ドキュメントを参照して、正確なエンドポイント、HTTP メソッド、リクエスト/レスポンスの形状、フィールド、列挙型、またはエラーを確認してください。Wix API を記憶から推測しないでください。ルックアップは短いフローです。適切なページを見つけて、それを読みます。 2 つの方法: (1) プレーンな `curl` (依存関係なし) — **セマンティック検索** (`POST /mcp-docs-search/v1/docs/search`、自然言語 `{ search_term, document_type }`) **または、`llms.txt` ルートからメニューとしてドキュメント ツリーを参照**してページを検索し (任意のドキュメント パスに `.md` を追加)、 `.md` をその URL に追加します。 (2) Wix MCP ドキュメント ツール (エージェントが持っている場合)。トリガー: Wix API の検索、Wix エンドポイント/メソッドの検索、Wix リクエストの本文またはフィールドの確認、Wix API の形状の検証、Wix ドキュメントの探索、どの Wix API を呼び出すか、Wix メソッドのスキーマの読み取り。
