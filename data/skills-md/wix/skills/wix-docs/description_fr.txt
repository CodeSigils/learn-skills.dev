Recherchez la documentation de l'API/SDK Wix pour confirmer un point de terminaison exact, une méthode HTTP, une forme de requête/réponse, un champ, une énumération ou une erreur avant d'écrire du code Wix — ne devinez jamais une API Wix de mémoire. Une recherche est un court processus : trouvez la bonne page, puis lisez-la. Deux manières : (1) simple `curl` (zéro dépendance) — recherchez une page par **recherche sémantique** (`POST /mcp-docs-search/v1/docs/search`, langage naturel `{ search_term, document_type }`) **ou en parcourant** l'arborescence des documents sous forme de menu à partir de la racine `llms.txt` (ajoutez `.md` à n'importe quel chemin de documentation), puis lisez la page en ajoutant `.md` à son URL ; et (2) les outils de documentation Wix MCP lorsque votre agent les dispose. Déclencheurs : recherchez une API Wix, trouvez le point de terminaison/la méthode Wix, confirmez le corps ou le champ d'une requête Wix, vérifiez la forme d'une API Wix, explorez la documentation Wix, quelle API Wix dois-je appeler, lisez un schéma de méthode Wix.
