Прежде чем писать код Wix, просмотрите документацию Wix API/SDK, чтобы подтвердить точную конечную точку, метод HTTP, форму запроса/ответа, поле, перечисление или ошибку — никогда не угадывайте API Wix по памяти. Поиск — это короткий процесс: найдите нужную страницу, затем прочитайте ее. Два способа: (1) простой `curl` (нулевые зависимости) — найдите страницу с помощью **семантического поиска** (`POST /mcp-docs-search/v1/docs/search`, естественного языка `{ search_term, document_type }`) **или просматривая** дерево документов в виде меню из корня `llms.txt` (добавьте `.md` к любому пути к документу), затем прочитайте страницу, добавив `.md` на его URL-адрес; и (2) инструменты документации Wix MCP, если они есть у вашего агента. Триггеры: поиск API Wix, нахождение конечной точки/метода Wix, подтверждение тела или поля запроса Wix, проверка формы API Wix, изучение документации Wix, какой API Wix я вызываю, чтение схемы метода Wix.
