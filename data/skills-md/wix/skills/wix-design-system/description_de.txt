Komponentenreferenz für das Wix Design System. Verwenden Sie es, wenn Sie eine Benutzeroberfläche mit @wix/design-system erstellen, Komponenten auswählen, Requisiten und Beispiele überprüfen oder Tests mit Komponententestkits schreiben. Löst auf „Welche Komponente“, „Wie mache ich“, „WDS“, „Zeige mir Requisiten“, „Testkit“, „Treiber“ oder Komponentennamen wie Schaltfläche, Karte, Modal, Box, Text aus.
