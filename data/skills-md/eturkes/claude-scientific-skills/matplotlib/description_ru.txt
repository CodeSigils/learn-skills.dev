Библиотека низкоуровневого построения графиков для полной настройки. Используйте его, когда вам нужен детальный контроль над каждым элементом графика, создание новых типов графиков или интеграция с конкретными научными рабочими процессами. Экспортируйте в PNG/PDF/SVG для публикации. Для быстрых статистических графиков используйте seaborn; для интерактивных графиков используйтеploly; для готовых к публикации многопанельных рисунков в журнальном стиле используйте научную визуализацию.
