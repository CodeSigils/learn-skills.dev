Low-Level-Plotbibliothek für vollständige Anpassung. Verwenden Sie es, wenn Sie eine detaillierte Kontrolle über jedes Plotelement, die Erstellung neuer Plottypen oder die Integration in bestimmte wissenschaftliche Arbeitsabläufe benötigen. Zur Veröffentlichung nach PNG/PDF/SVG exportieren. Für schnelle statistische Darstellungen verwenden Sie Seaborn; für interaktive Plots verwenden Sie plotly; Für publikationsreife Multi-Panel-Abbildungen im Zeitschriftenstil verwenden Sie Scientific-Visualisierung.
