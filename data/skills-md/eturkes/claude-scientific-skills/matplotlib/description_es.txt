Biblioteca de trazado de bajo nivel para una personalización completa. Úselo cuando necesite un control detallado sobre cada elemento de la trama, creando tipos de trama novedosos o integrándolos con flujos de trabajo científicos específicos. Exporte a PNG/PDF/SVG para su publicación. Para gráficos estadísticos rápidos utilice seaborn; para tramas interactivas utilice plotly; para figuras de varios paneles listas para publicar con estilo de revista, utilice visualización científica.
