Настройте нагрузочное тестирование артиллерии для любого проекта. Определяет менеджер пакетов и тип проекта, создает тестовый сценарий TypeScript (браузер HTTP или Playwright), настраивает Artillery Cloud и предоставляет команду запуска. Используйте, когда пользователь хочет добавить в свой проект нагрузочное тестирование, тестирование производительности или нагрузочное тестирование на основе браузера.
