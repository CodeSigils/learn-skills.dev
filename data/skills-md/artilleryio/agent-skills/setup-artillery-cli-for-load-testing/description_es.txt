Configure pruebas de carga de artillería para cualquier proyecto. Detecta el administrador de paquetes y el tipo de proyecto, crea un script de prueba TypeScript (HTTP o navegador Playwright), configura Artillery Cloud y proporciona el comando de ejecución. Úselo cuando el usuario desee agregar pruebas de carga, pruebas de rendimiento o pruebas de carga basadas en navegador a su proyecto.
