قم بإعداد اختبار الحمل المدفعي لأي مشروع. يكتشف مدير الحزم ونوع المشروع، وينشئ برنامج نصي لاختبار TypeScript (متصفح HTTP أو Playwright)، ويقوم بتكوين Artillery Cloud، ويوفر أمر التشغيل. يُستخدم عندما يريد المستخدم إضافة اختبار التحميل، أو اختبار الأداء، أو اختبار التحميل المستند إلى المستعرض إلى مشروعه.
