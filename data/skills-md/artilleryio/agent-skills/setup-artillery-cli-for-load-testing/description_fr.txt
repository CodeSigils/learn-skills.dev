Configurez des tests de charge d’artillerie pour n’importe quel projet. Détecte le gestionnaire de packages et le type de projet, crée un script de test TypeScript (navigateur HTTP ou Playwright), configure Artillery Cloud et fournit la commande d'exécution. À utiliser lorsque l'utilisateur souhaite ajouter des tests de charge, des tests de performances ou des tests de charge basés sur un navigateur à son projet.
