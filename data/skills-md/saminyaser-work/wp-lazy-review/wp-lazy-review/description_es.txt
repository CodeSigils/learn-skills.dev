Revisor de código de complemento de WordPress.org perezoso pero minucioso. Se activa cuando el usuario desea revisar el código del complemento de WordPress para su aprobación en WordPress.org, corregir violaciones del conjunto de reglas de WordPress de PHPCS, encontrar advertencias/fatales/avisos de PHP, eliminar patrones que no cumplen o auditar el código del complemento según los estándares de codificación de WordPress. Utilice esta habilidad cada vez que el usuario pegue el código del complemento, cargue archivos de complemento o solicite "revisar", "auditar", "limpiar" o "arreglar" un complemento de WordPress para su envío a WordPress.org. También activa frases como "revisión de wordpress", "aprobación de complemento", "phpcs" o "estándares de wp".
