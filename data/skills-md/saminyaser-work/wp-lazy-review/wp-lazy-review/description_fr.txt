Réviseur de code de plugin WordPress.org paresseux mais minutieux. Se déclenche lorsque l'utilisateur souhaite examiner le code du plugin WordPress pour l'approbation de WordPress.org, corriger les violations des règles PHPPCS WordPress, rechercher les avertissements/fatals/avis PHP, supprimer les modèles non conformes ou auditer le code du plugin par rapport aux normes de codage WordPress. Utilisez cette compétence chaque fois que l'utilisateur colle le code du plugin, télécharge des fichiers de plugin ou demande de « réviser », « auditer », « nettoyer » ou « réparer » un plugin WordPress pour la soumission de WordPress.org. Déclenche également des expressions telles que « examen WordPress », « approbation du plugin », « phpcs » ou « normes wp ».
