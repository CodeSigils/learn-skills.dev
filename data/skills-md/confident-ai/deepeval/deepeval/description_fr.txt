Workflow d'évaluation DeepEval pour les agents IA et les applications LLM. DÉCLENCHEMENT lorsque l'utilisateur souhaite évaluer ou améliorer un agent IA, un workflow utilisant un outil, un chatbot multi-tours, un pipeline RAG ou une application LLM ; ajouter des évaluations ; générer des ensembles de données ou des goldens ; utilisez la génération deepeval ; utiliser un test approfondi ; ajoutez un traçage ou @observe ; envoyer les résultats à Confident AI ; surveiller la production; exécuter des évaluations en ligne ; inspecter les traces ; ou itérer sur les invites, les outils, la récupération ou le comportement de l'agent à partir d'échecs d'évaluation. Les agents IA constituent le principal cas d’utilisation. Couvre le SDK Python, les suites d'évaluation pytest, la génération CLI, le traçage, les rapports Confident AI et les boucles d'amélioration pilotées par les agents. NE PAS DÉCLENCHER pour un pytest générique non lié, une configuration de test non-IA ou un travail d'observabilité non-DeepEval, à moins que l'utilisateur ne demande à comparer ou à migrer vers DeepEval.
