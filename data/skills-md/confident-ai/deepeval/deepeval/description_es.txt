Flujo de trabajo de evaluación de DeepEval para agentes de IA y aplicaciones LLM. DISPARAR cuando el usuario quiera evaluar o mejorar un agente de IA, un flujo de trabajo que utiliza herramientas, un chatbot de múltiples turnos, un canal RAG o una aplicación LLM; agregar evaluaciones; generar conjuntos de datos o goldens; utilizar generación profunda; utilizar la ejecución de prueba profunda; agregue seguimiento o @observe; enviar resultados a Confident AI; monitorear la producción; ejecutar evaluaciones en línea; inspeccionar rastros; o iterar sobre indicaciones, herramientas, recuperación o comportamiento del agente a partir de fallas de evaluación. Los agentes de IA son el caso de uso principal. Cubre Python SDK, pytest eval suites, generación de CLI, seguimiento, informes de Confident AI y ciclos de mejora impulsados ​​por agentes. NO DISPARE para pytest genérico no relacionado, configuración de pruebas que no sean de IA o trabajos de observabilidad que no sean de DeepEval, a menos que el usuario solicite comparar o migrar a DeepEval.
