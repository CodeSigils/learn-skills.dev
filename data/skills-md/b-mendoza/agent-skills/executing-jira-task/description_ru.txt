Выполняйте одну задачу из плана задач Jira, используя готовые артефакты планирования и структурированный конвейер специализированных субагентов: реализация, документация, проверка требований, проверка качества кода, проверка архитектуры и аудит безопасности. Пользователь должен указать номер задачи, которую необходимо выполнить. Используйте, когда пользователь говорит «выполнить задачу 3», «работать над задачей 2», «реализовать задачу 1», «запустить задачу 5 для ПРОЕКТА-1234» или «запустить задачу N». Также запускается навыком оркестрации рабочих процессов Jira в качестве этапа 7 сквозного конвейера (вызывается один раз для каждой задачи). Требуется, чтобы план задачи существовал в docs/<TICKET_KEY>-tasks.md И чтобы существовали артефакты планирования (краткое описание выполнения, план выполнения, спецификация тестирования, план рефакторинга) — создаваемые навыком планирования jira-task на этапе 5. Выполняет ТОЛЬКО указанную задачу — никогда не переходит к следующей без явного одобрения пользователя.
