Retrieve ALL information from a Jira ticket (description, comments, subtasks, attachments metadata, labels, sprint, status, assignee, reporter, etc.) and persist it as a single Markdown file. Use when the user says "fetch ticket", "retrieve Jira", "pull ticket info", "get ticket details", or provides a Jira ticket URL or key like PROJECT-1234.
