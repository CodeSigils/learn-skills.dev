Crea commit atomic git revisionabili da percorsi espliciti di file o cartelle dopo che l'utente ha chiesto di eseguire il commit. Da utilizzare durante il commit di file selezionati, la conservazione del lavoro non correlato, la suddivisione di modifiche generali in commit logici, il commit di lavoro con ambito ticket o la preparazione di una serie di revisioni pulite tramite ispezione mirata, pianificazione dei limiti, verifica delle differenze a fasi ed esecuzione di commit.
