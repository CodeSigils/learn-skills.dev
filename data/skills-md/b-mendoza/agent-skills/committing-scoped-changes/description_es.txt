Crea confirmaciones atómicas de git revisables a partir de rutas explícitas de archivos o carpetas después de que el usuario solicita la confirmación. Úselo al confirmar archivos seleccionados, preservar trabajos no relacionados, dividir cambios amplios en confirmaciones lógicas, confirmar trabajos con alcance de ticket o preparar una serie de revisiones limpias mediante inspección de alcance, planificación de límites, verificación de diferencias por etapas y ejecución de confirmaciones.
