Erstellt überprüfbare atomare Git-Commits aus expliziten Datei- oder Ordnerpfaden, nachdem der Benutzer zum Commit aufgefordert hat. Verwenden Sie diese Option, wenn Sie ausgewählte Dateien festschreiben, nicht verwandte Arbeiten beibehalten, umfassende Änderungen in logische Festschreibungen aufteilen, Ticket-bezogene Arbeiten festschreiben oder eine saubere Überprüfungsreihe durch bereichsbezogene Inspektion, Grenzplanung, abgestufte Diff-Überprüfung und Festschreibungsausführung vorbereiten.
