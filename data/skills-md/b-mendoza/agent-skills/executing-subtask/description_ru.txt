Выполните одну подзадачу из плана задач Jira. Пользователь должен указать номер задачи, которую необходимо выполнить. Используйте, когда пользователь говорит «выполнить задачу 3», «работать над задачей 2», «реализовать задачу 1», «запустить задачу 5 для ПРОЕКТА-1234» или «запустить подзадачу N». Требуется, чтобы план задач существовал в docs/<TICKET_KEY>-tasks.md. Выполняет ТОЛЬКО указанную задачу — никогда не переходит к следующей без явного разрешения пользователя.
