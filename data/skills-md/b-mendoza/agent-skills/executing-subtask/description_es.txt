Ejecute una única subtarea de un plan de tareas de Jira. El usuario debe especificar qué número de tarea ejecutar. Úselo cuando el usuario diga "ejecutar tarea 3", "trabajar en la tarea 2", "implementar tarea 1", "iniciar tarea 5 para PROYECTO-1234" o "ejecutar subtarea N". Requiere que el plan de tareas exista en docs/<TICKET_KEY>-tasks.md. Ejecuta SÓLO la tarea especificada; nunca continúa con la siguiente sin la aprobación explícita del usuario.
