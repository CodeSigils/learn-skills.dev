Crea subtareas en Jira a partir de un plan de tareas generado previamente. Lee el plan de docs/<TICKET_KEY>-tasks.md y crea una subtarea de Jira por tarea en el ticket principal. Úselo cuando el usuario diga "crear subtareas", "enviar tareas a Jira", "sincronizar plan con Jira", "crear tickets de Jira", "crear subtareas para PROJECT-1234" o cualquier cosa sobre convertir un plan en problemas de Jira. También se activa mediante la habilidad Orchestrating-Jira-Workflow como Fase 4. Requiere que el plan de tareas ya exista (ejecute Planning-Jira-tasks primero si no es así). Utilice esta habilidad incluso si el usuario simplemente dice "enviar a Jira" o "crear los tickets" después de una fase de planificación; esas son solicitudes de creación de subtareas.
