قم بإنشاء مهام فرعية في Jira من خطة مهمة تم إنشاؤها مسبقًا. يقرأ الخطة من docs/<TICKET_KEY>-tasks.md وينشئ مهمة فرعية واحدة لـ Jira لكل مهمة ضمن التذكرة الرئيسية. يُستخدم عندما يقول المستخدم "إنشاء مهام فرعية"، أو "ادفع المهام إلى Jira"، أو "مزامنة الخطة مع Jira"، أو "إنشاء تذاكر Jira"، أو "إنشاء مهام فرعية لـ PROJECT-1234"، أو أي شيء يتعلق بتحويل الخطة إلى مشكلات Jira. يتم تشغيلها أيضًا بواسطة مهارة سير عمل jira التنسيقية باعتبارها المرحلة 4. تتطلب أن تكون خطة المهمة موجودة بالفعل (قم بتشغيل مهام التخطيط jira أولاً إذا لم تكن موجودة). استخدم هذه المهارة حتى إذا قال المستخدم فقط "اضغط إلى Jira" أو "أنشئ التذاكر" بعد مرحلة التخطيط - فهي طلبات إنشاء مهمة فرعية.
