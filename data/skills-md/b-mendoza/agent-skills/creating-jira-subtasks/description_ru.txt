Создавайте подзадачи в Jira на основе ранее созданного плана задач. Считывает план из docs/<TICKET_KEY>-tasks.md и создает одну подзадачу Jira для каждой задачи в родительском билете. Используйте, когда пользователь говорит «создать подзадачи», «отправить задачи в Jira», «синхронизировать план с Jira», «создать билеты Jira», «создать подзадачи для ПРОЕКТА-1234» или что-либо о превращении плана в задачи Jira. Также активируется навыком оркестрации рабочих процессов Jira в качестве этапа 4. Требуется, чтобы план задач уже существовал (сначала запустите Planning-Jira-Tasks, если его нет). Используйте этот навык, даже если пользователь просто говорит «отправьте в Jira» или «создайте заявки» после этапа планирования — это запросы на создание подзадач.
