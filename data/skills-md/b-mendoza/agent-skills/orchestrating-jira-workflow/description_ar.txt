منسق رفيع المستوى لسير عمل تذاكر Jira الشامل. استخدم هذه المهارة عندما يقول المستخدم "العمل على تذكرة PROJECT-1234"، أو "بدء سير عمل Jira"، أو "التعامل مع هذه التذكرة من النهاية إلى النهاية"، أو "تنسيق PROJECT-1234"، أو "التقاط PROJECT-1234"، أو توفير مفتاح/عنوان URL لتذكرة Jira دون تحديد مرحلة معينة. قم أيضًا بتشغيل "تذكرة استئناف PROJECT-1234"، أو "أين توقفنا عند PROJECT-1234"، أو "مواصلة PROJECT-1234"، أو "ما هي حالة PROJECT-1234". تنسق هذه المهارة جميع المهارات النهائية والوكلاء الفرعيين - فهي لا تقوم مطلقًا بتشغيل استدعاءات الأدوات، أو أوامر CLI، أو قراءات الملفات، أو عمليات البحث على الويب، أو استدعاءات MCP مباشرة.
