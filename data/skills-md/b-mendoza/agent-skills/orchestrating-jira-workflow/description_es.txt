Orquestador de nivel superior para flujos de trabajo de tickets de Jira de un extremo a otro. Utilice esta habilidad cuando el usuario diga "trabajar en el ticket PROJECT-1234", "iniciar el flujo de trabajo de Jira", "manejar este ticket de principio a fin", "orquestar PROJECT-1234", "recoger PROJECT-1234" o proporcione una clave/URL de ticket de Jira sin especificar una fase en particular. También se activa "reanudar ticket PROYECTO-1234", "¿dónde lo dejamos en PROYECTO-1234", "continuar PROYECTO-1234" o "cuál es el estado de PROYECTO-1234". Esta habilidad coordina todas las habilidades y subagentes posteriores; nunca ejecuta llamadas a herramientas, comandos CLI, lecturas de archivos, búsquedas web o llamadas MCP directamente.
