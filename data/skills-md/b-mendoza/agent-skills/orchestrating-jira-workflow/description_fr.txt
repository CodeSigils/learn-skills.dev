Orchestrateur de haut niveau pour les workflows de tickets Jira de bout en bout. Utilisez cette compétence lorsque l'utilisateur dit « travailler sur le ticket PROJET-1234 », « démarrer le workflow Jira », « gérer ce ticket de bout en bout », « orchestrer le PROJET-1234 », « récupérer le PROJET-1234 » ou fournit une clé/URL de ticket Jira sans spécifier de phase particulière. Déclenchez également sur "reprendre le ticket PROJET-1234", "où avons-nous arrêté le PROJET-1234", "continuer le PROJET-1234" ou "quel est l'état du PROJET-1234". Cette compétence coordonne toutes les compétences et sous-agents en aval : elle n'exécute jamais directement les appels d'outils, les commandes CLI, les lectures de fichiers, les recherches sur le Web ou les appels MCP.
