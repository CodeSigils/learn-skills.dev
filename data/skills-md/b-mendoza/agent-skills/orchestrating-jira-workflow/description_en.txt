Top-level orchestrator for end-to-end Jira ticket workflows. Use this skill when the user says "work on ticket PROJECT-1234", "start the Jira workflow", "handle this ticket end to end", "orchestrate PROJECT-1234", "pick up PROJECT-1234", or provides a Jira ticket key/URL without specifying a particular phase. Also trigger on "resume ticket PROJECT-1234", "where did we leave off on PROJECT-1234", "continue PROJECT-1234", or "what's the status of PROJECT-1234". This skill coordinates all downstream skills and subagents — it never runs tool calls, CLI commands, file reads, web searches, or MCP calls directly.
