Überprüfen Sie eine Pull-Anfrage über einen eigenständigen, nach und nach offengelegten Workflow. Wird verwendet, wenn der Benutzer darum bittet, eine PR zu überprüfen, eine Pull-Anfrage zu prüfen, GitHub-Überprüfungskommentare vorzubereiten, Feedback zu Anforderungsänderungen zu entwerfen, eine PR-Überprüfungsdatei zu schreiben oder optional genehmigte Überprüfungskommentare zu veröffentlichen. Dieser Skill verwaltet genau einen PR; Bitten Sie den Benutzer, eine PR auszuwählen, wenn mehrere PR-URLs angegeben werden.
