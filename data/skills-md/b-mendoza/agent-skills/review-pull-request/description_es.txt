Revise una solicitud de extracción a través de un flujo de trabajo independiente y divulgado progresivamente. Úselo cuando el usuario solicite revisar un PR, auditar una solicitud de extracción, preparar comentarios de revisión de GitHub, redactar comentarios de cambios de solicitud, escribir un archivo de revisión de PR o, opcionalmente, publicar comentarios de revisión aprobados. Esta habilidad maneja exactamente un PR; Solicite al usuario que elija un PR cuando se proporcionen varias URL de PR.
