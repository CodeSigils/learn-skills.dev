Examinez une pull request via un flux de travail autonome et progressivement divulgué. À utiliser lorsque l'utilisateur demande à réviser une PR, à auditer une pull request, à préparer des commentaires de révision GitHub, à rédiger des commentaires sur les modifications de demande, à rédiger un fichier de révision de PR ou, éventuellement, à publier des commentaires de révision approuvés. Cette compétence gère exactement un PR ; demandez à l'utilisateur de choisir un PR lorsque plusieurs URL PR sont fournies.
