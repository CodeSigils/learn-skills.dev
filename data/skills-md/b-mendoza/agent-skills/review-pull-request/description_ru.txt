Просмотрите один запрос на включение в рамках автономного, постепенно раскрываемого рабочего процесса. Используйте, когда пользователь просит просмотреть PR, проверить запрос на включение, подготовить комментарии к обзору GitHub, составить отзыв о запросе на изменения, написать файл обзора PR или, при необходимости, опубликовать утвержденные комментарии к обзору. Этот навык обрабатывает ровно один PR; попросите пользователя выбрать один PR, если указано несколько URL-адресов PR.
