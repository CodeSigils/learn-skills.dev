قم بمراجعة طلب سحب واحد من خلال سير عمل مستقل يتم الكشف عنه تدريجيًا. يُستخدم عندما يطلب المستخدم مراجعة العلاقات العامة، أو تدقيق طلب سحب، أو إعداد تعليقات مراجعة GitHub، أو صياغة تعليقات تغييرات الطلب، أو كتابة ملف مراجعة العلاقات العامة، أو نشر تعليقات المراجعة المعتمدة بشكل اختياري. تتعامل هذه المهارة مع علاقات عامة واحدة بالضبط؛ اطلب من المستخدم اختيار PR واحد عند توفير عناوين URL متعددة للعلاقات العامة.
