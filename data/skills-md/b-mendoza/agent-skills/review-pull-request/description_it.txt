Esamina una richiesta pull attraverso un flusso di lavoro autonomo e progressivamente divulgato. Da utilizzare quando l'utente chiede di rivedere una PR, controllare una richiesta pull, preparare commenti di revisione GitHub, bozza di feedback sulle modifiche alle richieste, scrivere un file di revisione PR o, facoltativamente, pubblicare commenti di revisione approvati. Questa abilità gestisce esattamente un PR; chiedere all'utente di scegliere un PR quando vengono forniti più URL PR.
