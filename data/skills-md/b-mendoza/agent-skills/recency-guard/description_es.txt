Un marco de validación que garantiza que las respuestas de Claude sean actuales, precisas, completas y claras. Utilice esta habilidad siempre que el usuario haga una pregunta objetiva o de investigación, solicite análisis o recomendaciones (por ejemplo, "¿Cuál es el mejor marco para X?", "Comparar opciones para Y") o cualquier mensaje donde la actualidad y la precisión sean importantes. También se activa cuando el usuario solicita explícitamente respuestas validadas, verificadas o verificadas. Esta habilidad debería activarse ampliamente: si la respuesta depende de hechos que podrían haber cambiado en los últimos meses, úsela. Incluso las preguntas que parecen sencillas ("¿X sigue siendo el enfoque recomendado?") se benefician del proceso de validación de esta habilidad. NO active escrituras puramente creativas, charlas informales o tareas que estén completamente basadas en opiniones sin afirmaciones fácticas.
