Génère un package de transfert de démarrage à froid pouvant être repris à partir d'une conversation, d'une révision, d'une session de débogage ou d'une enquête en cours. À utiliser lorsque l'utilisateur dit « créer un document de transfert », « enregistrer ceci pour plus tard », « documenter ce que nous avons trouvé », « mettre à jour le fichier de reprise » ou souhaite qu'un nouvel agent reprenne sans historique de discussion.
