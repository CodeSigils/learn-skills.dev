Erzeugt ein fortsetzbares Kaltstart-Übergabepaket aus einer laufenden Konversation, Überprüfung, Debugging-Sitzung oder Untersuchung. Verwenden Sie diese Option, wenn der Benutzer sagt: „Erstellen Sie ein Übergabedokument“, „Speichern Sie dies für später“, „Dokumentieren Sie, was wir gefunden haben“, „Aktualisieren Sie die Wiederaufnahmedatei“ oder möchte, dass ein neuer Agent ohne Chat-Verlauf fortfährt.
