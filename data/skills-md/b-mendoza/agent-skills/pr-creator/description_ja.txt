自動生成されたタイトル、説明、レビュー担当者、ラベルを使用して、現在のブランチから GitHub プル リクエストを作成します。ユーザーが PR を作成する場合、プル リクエストを開く場合、レビューのためにコードを送信する場合、マージのために変更をプッシュする場合、または「PR」、「プル リクエスト」、「コード レビュー」、または「マージ リクエスト」について言及する場合は常に、このスキルを使用します。また、ユーザーが「この機能は終了しました」、「送信する準備ができました」、「PR の下書きを開いてください」、または「レビューのためにこれを送信してください」などと言ったときにもトリガーされます。デフォルトでは GitHub CLI で動作し、GitLab および Bitbucket のガイダンスが提供されます。
