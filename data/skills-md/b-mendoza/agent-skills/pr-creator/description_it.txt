Crea richieste pull GitHub dal ramo corrente con titoli, descrizioni, revisori ed etichette generati automaticamente. Utilizza questa competenza ogni volta che l'utente desidera creare un PR, aprire una richiesta pull, inviare codice per la revisione, inviare modifiche per l'unione o menziona "PR", "richiesta pull", "revisione del codice" o "richiesta di unione". Si attiva anche quando l'utente dice cose come "Ho finito con questa funzione", "pronto per l'invio", "apri una bozza di PR" o "invia questo per la revisione". Funziona con la CLI GitHub per impostazione predefinita, con indicazioni per GitLab e Bitbucket.
