قم بإنشاء طلبات سحب GitHub من الفرع الحالي بالعناوين والأوصاف والمراجعين والتسميات التي تم إنشاؤها تلقائيًا. استخدم هذه المهارة عندما يريد المستخدم إنشاء PR، أو فتح طلب سحب، أو إرسال رمز للمراجعة، أو دفع التغييرات للدمج، أو ذكر "PR"، أو "طلب سحب"، أو "مراجعة الكود"، أو "طلب دمج". يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "لقد انتهيت من استخدام هذه الميزة" أو "جاهز للإرسال" أو "فتح مسودة العلاقات العامة" أو "إرسال هذا للمراجعة". يعمل مع GitHub CLI بشكل افتراضي، مع توجيهات لـ GitLab وBitbucket.
