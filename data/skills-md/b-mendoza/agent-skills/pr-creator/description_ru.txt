Создавайте запросы на извлечение GitHub из текущей ветки с автоматически создаваемыми заголовками, описаниями, рецензентами и метками. Используйте этот навык всякий раз, когда пользователь хочет создать PR, открыть запрос на включение, отправить код на проверку, отправить изменения для слияния или упомянуть «PR», «запрос на включение», «проверку кода» или «запрос на слияние». Также срабатывает, когда пользователь говорит такие вещи, как «Я закончил с этой функцией», «Готов отправить», «Открыть черновой вариант PR» или «Отправить на рассмотрение». По умолчанию работает с интерфейсом командной строки GitHub, есть рекомендации для GitLab и Bitbucket.
