Cree solicitudes de extracción de GitHub desde la rama actual con títulos, descripciones, revisores y etiquetas generados automáticamente. Utilice esta habilidad siempre que el usuario quiera crear un PR, abrir una solicitud de extracción, enviar código para revisión, enviar cambios para fusión o mencione "PR", "solicitud de extracción", "revisión de código" o "solicitud de fusión". También se activa cuando el usuario dice cosas como "Terminé con esta función", "listo para enviar", "abrir un borrador de PR" o "enviar esto para revisión". Funciona con GitHub CLI de forma predeterminada, con orientación para GitLab y Bitbucket.
