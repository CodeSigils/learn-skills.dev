Créez des demandes d'extraction GitHub à partir de la branche actuelle avec des titres, des descriptions, des réviseurs et des étiquettes générés automatiquement. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un PR, ouvrir une demande d'extraction, soumettre du code pour révision, pousser des modifications pour fusion ou mentionner « PR », « demande d'extraction », « révision de code » ou « demande de fusion ». Déclenchez également lorsque l'utilisateur dit des choses telles que « J'en ai terminé avec cette fonctionnalité », « prêt à soumettre », « ouvrir un brouillon de PR » ou « envoyer ceci pour examen ». Fonctionne par défaut avec GitHub CLI, avec des conseils pour GitLab et Bitbucket.
