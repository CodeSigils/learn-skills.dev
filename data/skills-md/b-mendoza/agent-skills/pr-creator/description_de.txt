Erstellen Sie GitHub-Pull-Anfragen aus dem aktuellen Branch mit automatisch generierten Titeln, Beschreibungen, Prüfern und Labels. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine PR erstellen, eine Pull-Anfrage öffnen, Code zur Überprüfung übermitteln, Änderungen zur Zusammenführung pushen möchte oder „PR“, „Pull-Anfrage“, „Codeüberprüfung“ oder „Zusammenführungsanfrage“ erwähnt. Wird auch ausgelöst, wenn der Benutzer Dinge sagt wie „Ich bin mit dieser Funktion fertig“, „Bereit zum Senden“, „Öffnen Sie einen PR-Entwurf“ oder „Senden Sie dies zur Überprüfung“. Funktioniert standardmäßig mit GitHub CLI, mit Anleitung für GitLab und Bitbucket.
