Assist in writing high‑quality technical solution documents. When users need to write a technical solution, technical design, solution review, R&D design document, interface plan, database schema change plan, deployment plan, or wish to organize PRD/requirements/code context into a document that conforms to the “technical solution template,” they must use this skill. It first clarifies the user’s current requirement and may ask the user to provide the PRD/requirements document/interface document/code repository address. Then, combined with the code, domain terminology, ADR, interfaces, SQL schema, distributed high‑concurrency and deployment constraints, it conducts a thorough clarification and ultimately produces a complete technical solution that conforms to the template.
