Ayude a los usuarios novatos a través de todo el flujo de trabajo de Vibecoding. Se activa cuando el usuario dice "Quiero crear un producto", "ayúdame a crear una herramienta", "Tengo una idea", "ayúdame a crear vibecode" o "constrúyeme una aplicación/sitio web/herramienta". Guíe al usuario desde una idea vaga hasta un paquete de documentos completo listo para ser entregado a Cursor/Trae a través de tres roles de Agente: recopilación de requisitos → refinamiento de PRD → UI + arquitectura técnica.
