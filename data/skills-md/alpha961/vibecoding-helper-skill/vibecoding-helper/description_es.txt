Ayude a los usuarios novatos a través de todo el flujo de trabajo de vibecoding. Se activa cuando el usuario dice "Quiero crear un producto", "Ayúdame a crear una herramienta", "Tengo una idea", "Ayúdame a codificar por vibración" o "Constrúyeme una aplicación/sitio web/herramienta". Guíe al usuario desde una idea vaga hasta un paquete de documentación completo listo para pasar a Cursor/Trae a través de tres roles de Agente: recopilación de requisitos → refinamiento de PRD → UI + arquitectura tecnológica.
