Ayude a los usuarios novatos durante todo el proceso de Vibecoding. Se activa cuando el usuario dice "Quiero crear un producto", "Ayúdame a crear una herramienta", "Tengo una idea", "Ayúdame a codificar por vibración" o "Ayúdame a crear una aplicación/sitio web/herramienta". Utilice tres roles de agente (recopilación de requisitos → refinamiento de PRD → UI + arquitectura técnica) para guiar al usuario desde una idea vaga hasta un paquete de documentación completo que se puede entregar directamente a Cursor/Trae para su desarrollo.
