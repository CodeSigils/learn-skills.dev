Assistez les utilisateurs novices tout au long du processus Vibecoding. Déclenché lorsque l'utilisateur dit « Je veux créer un produit », « Aidez-moi à créer un outil », « J'ai une idée », « Aidez-moi à vibecoder » ou « Aidez-moi à créer une application/un site Web/un outil ». Utilisez trois rôles d'agent (collecte des exigences → raffinement PRD → UI + architecture technique) pour guider l'utilisateur d'une idée vague à un package de documentation complet qui peut être transmis directement à Cursor/Trae pour le développement.
