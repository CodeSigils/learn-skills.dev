Helfen Sie unerfahrenen Benutzern durch den gesamten Vibecoding-Workflow. Wird ausgelöst, wenn der Benutzer sagt: „Ich möchte ein Produkt erstellen“, „Helfen Sie mir, ein Tool zu erstellen“, „Ich habe eine Idee“, „Helfen Sie mir beim Vibecoding“ oder „Erstellen Sie mir eine App/Website/ein Tool“. Führen Sie den Benutzer über drei Agentenrollen von einer vagen Idee zu einem vollständigen Dokumentationspaket, das zur Übergabe an Cursor/Trae bereit ist: Anforderungserfassung → PRD-Verfeinerung → Benutzeroberfläche + technische Architektur.
