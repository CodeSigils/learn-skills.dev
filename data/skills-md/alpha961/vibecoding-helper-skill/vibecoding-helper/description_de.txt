Unterstützen Sie unerfahrene Benutzer durch den gesamten Vibecoding-Prozess. Wird ausgelöst, wenn der Benutzer sagt: „Ich möchte ein Produkt erstellen“, „Helfen Sie mir, ein Tool zu erstellen“, „Ich habe eine Idee“, „Helfen Sie mir beim Vibecoding“ oder „Helfen Sie mir, eine App/Website/ein Tool zu erstellen“. Verwenden Sie drei Agentenrollen (Anforderungserfassung → PRD-Verfeinerung → Benutzeroberfläche + technische Architektur), um den Benutzer von einer vagen Idee zu einem vollständigen Dokumentationspaket zu führen, das direkt an Cursor/Trae zur Entwicklung übergeben werden kann.
