Helfen Sie unerfahrenen Benutzern durch den gesamten Vibecoding-Workflow. Wird ausgelöst, wenn der Benutzer sagt: „Ich möchte ein Produkt erstellen“, „Helfen Sie mir, ein Tool zu erstellen“, „Ich habe eine Idee“, „Helfen Sie mir beim Vibecoding“ oder „Erstellen Sie mir eine App/Website/ein Tool“. Drei Agentenrollen – Anforderungserfassung → PRD-Verfeinerung → Benutzeroberfläche + technische Architektur – führen den Benutzer von einer vagen Idee zu einem vollständigen Dokumentpaket, das zur Übergabe an Cursor/Trae bereit ist.
