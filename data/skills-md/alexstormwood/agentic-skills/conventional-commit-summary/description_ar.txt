قم بإنشاء ملخصات التزام تقليدية موجزة من سطر واحد للعمل الذي أكمله وكيل الذكاء الاصطناعي. يُستخدم عندما يحتاج Codex إلى تلخيص تغييرات التعليمات البرمجية، أو تعديلات الملفات، أو تحديثات الوثائق، أو الاختبارات، أو إعادة البناء، أو الإصلاحات، أو الأصول التي تم إنشاؤها، أو تغيير التغييرات، أو أعمال المستودع الأخرى كرسالة التزام git مختصرة مع النوع، والنطاق الاختياري، وعلامة تغيير التغيير الاختيارية، وبدون وصف موسع.
