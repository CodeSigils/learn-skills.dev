Guide de changement sécurisé pour le dépôt darkmatter/gitops — validation avant le commit (kubeconform avec les mêmes drapeaux que CI, yq, git diff --check), images verrouillées par SHA, règles d’édition des secrets KSOPS/SOPS, restauration via revert, et le fonctionnement de la réconciliation par ArgoCD. Utiliser pour TOUTE modification du darkmatter/gitops (manifests, valeurs Helm, apps/*.yaml, secrets), lorsqu’on demande d’augmenter un tag d’image, de configurer un secret, ou de revenir à un déploiement. L’utiliser également lorsqu’on est tenté d’exécuter kubectl apply/edit/patch sur quoi que ce soit — la réponse est non.
