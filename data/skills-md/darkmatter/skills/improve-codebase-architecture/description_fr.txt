Trouvez des opportunités d'approfondissement dans une base de code, en vous appuyant sur le langage métier présent dans CONTEXT.md et les décisions dans docs/adr/. Utilisez cette approche lorsque l'utilisateur souhaite améliorer l’architecture, identifier des opportunités de refactorisation, consolider des modules fortement couplés ou rendre une base de code plus testable et navigable par l’IA.

Veuillez toujours répondre dans la langue de l'utilisateur.
