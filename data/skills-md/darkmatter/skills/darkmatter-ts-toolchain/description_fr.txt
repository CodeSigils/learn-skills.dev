Le contrat de chaîne d'outils TypeScript de darkmatter – Bun (jamais npm/pnpm), tsgo typecheck, vitest, oxlint/biome, changesets, Effect pour les I/O, déploiements Alchemy (wrangler.toml est interdit), merge‑queue mains et la règle no‑tiny‑functions. Utilisez‑le lors de l’écriture, la correction, la construction ou la diffusion de TypeScript dans n’importe quel dépôt darkmatter (platform, nixmac‑web, omp‑chat, genesis) : « corriger les erreurs TS », « rendre le CI vert », « ajouter un paquet », « déployer ce worker », les plaintes concernant le lockfile, ou le choix de bibliothèques pour du code fortement I/O‑intensif. NE l’utilisez PAS pour le style TS générique (coding‑standards) ou les modèles Effect profonds (effect‑typescript) — cette compétence est la colle de la chaîne d’outils propre à l’organisation autour de ceux‑ci.
