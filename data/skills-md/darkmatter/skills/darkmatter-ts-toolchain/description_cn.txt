darkmatter TypeScript 工具链约定 - Bun（绝不使用 npm/pnpm），tsgo 类型检查，vitest，oxlint/biome，changesets，Effect 用于 I/O，Alchemy 部署（禁止使用 wrangler.toml），merge-queue 主分支，以及 no‑tiny‑functions 规则。 在任何 darkmatter 仓库（platform、nixmac‑web、omp‑chat、genesis）中编写、修复、构建或发布 TypeScript 时使用：“fix TS errors”“make CI green”“add a package”“deploy this worker”，处理 lockfile 投诉，或为 I/O 密集型代码选择库。 请勿用于通用 TS 风格（coding‑standards）或深度 Effect 模式（effect‑typescript）——此技能是围绕这些的组织特定工具链粘合层。
