Mantieni le schermate React leggere e il pacchetto UI condiviso del monorepo (packages/ui, importato come @repo/ui) come sede per i componenti riutilizzabili. Si attiva quando si crea o si rimodella una pagina, rotta, schermata o componente in un’app che fa parte di un monorepo con un pacchetto UI condiviso — soprattutto quando un file tende a diventare un muro di markup Tailwind semplice con `<div className="...">`. Preferisci riutilizzare le primitive @repo/ui esistenti e trasformare le nuove unità riutilizzabili dalle schermate in @repo/ui, evitando l'estrazione prematura eccessiva. NON attivare per codice non‑React, per app a pacchetto unico senza pacchetto UI condiviso, o per la modifica degli interni di un componente esistente.
