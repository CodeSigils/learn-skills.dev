احتفظ بواجهات React رقيقة واعتبر حزمة UI المشتركة في المستودع الأحادي (packages/ui، المستوردة كـ @repo/ui) هي الموطن للمكونات القابلة لإعادة الاستخدام. يتم التحفيز عند إنشاء أو إعادة تنسيق صفحة أو مسار أو شاشة أو مكوّن في تطبيق يندرج ضمن مستودع أحادي يحتوي على حزمة UI مشتركة — خصوصًا عندما يميل الملف إلى احتوائه على جدران من وسوم <div className="..."> بسيطة باستخدام Tailwind. يُفضَّل إعادة استخدام البُنى الأساسية الموجودة في @repo/ui وتطوير وحدات جديدة قابلة لإعادة الاستخدام من الشاشات إلى @repo/ui، مع تجنّب الاستخراج المفرط المبكر. لا تُطلق الإشارة على شفرة غير React، أو على تطبيقات حزمة واحدة بدون حزمة UI مشتركة، أو عند تعديل داخل مكوّن موجود بالفعل.
