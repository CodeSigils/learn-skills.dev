Gardez les écrans React fins et le paquet UI partagé du monorepo (packages/ui, importé sous @repo/ui) comme lieu de résidence des composants réutilisables. Déclencheurs lors de la création ou du relooking d’une page, d’une route, d’un écran ou d’un composant dans une application faisant partie d’un monorepo doté d’un paquet UI partagé — en particulier lorsque le fichier a tendance à s’accumuler en murs de simples balises <div className="…"> avec du markup Tailwind. Privilégiez la réutilisation des primitives existantes de @repo/ui et la promotion de nouvelles unités réutilisables des écrans vers @repo/ui, tout en évitant une extraction prématurée excessive. NE déclenchez PAS pour du code non‑React, pour des applications à paquet unique sans paquet UI partagé, ou pour la modification de l’interne d’un composant existant.
