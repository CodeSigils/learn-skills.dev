React の画面は薄く保ち、モノレポの共有 UI パッケージ（packages/ui、@repo/ui としてインポート）を再利用可能コンポーネントの拠点にします。ページ、ルート、画面、またはコンポーネントを作成・リスタイリングする際にトリガーし、特にファイルが単なる `<div className="...">` の Tailwind マークアップの壁に近づいているときに発動します。既存の @repo/ui プリミティブを再利用し、画面から新しい再利用可能ユニットを @repo/ui に昇格させることを優先し、早すぎる過剰抽出は避けてください。非 React コード、共有 UI パッケージがない単一パッケージアプリ、既存コンポーネントの内部を編集する場合はトリガーしません。
