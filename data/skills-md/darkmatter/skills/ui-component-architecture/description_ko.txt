React 화면은 가볍게 유지하고, 모노레포의 공유 UI 패키지(packages/ui, @repo/ui 로 임포트) 를 재사용 가능한 컴포넌트의 저장소로 삼으세요. 모노레포 내에서 공유 UI 패키지를 사용하는 앱의 페이지, 라우트, 화면, 혹은 컴포넌트를 새로 만들거나 스타일을 다시 적용할 때, 특히 파일이 순수 <div className="..."> Tailwind 마크업으로 가득 차게 될 조짐이 보이면 트리거됩니다. 기존 @repo/ui 프리미티브를 재사용하고, 화면에 있던 새로운 재사용 가능 단위를 @repo/ui 로 옮기는 쪽으로 편향하되, 조기 과도 추출은 피하세요. React가 아닌 코드, 공유 UI 패키지가 없는 단일 패키지 앱, 혹은 기존 컴포넌트 내부를 수정하는 경우에는 트리거되지 않도록 합니다.
