Сохраняйте экраны React тонкими, а общий пакет пользовательского интерфейса monorepo (packages/ui, импортированный как @repo/ui) — домом для повторно используемых компонентов. Срабатывает при создании или изменении стиля страницы, маршрута, экрана или компонента в приложении, которое является частью монорепозитория с общим пакетом пользовательского интерфейса, особенно когда файл стремится к стенам простой разметки <div className="..."> Tailwind. Склонность к повторному использованию существующих примитивов @repo/ui и переводу новых повторно используемых модулей за пределы экранов в @repo/ui, избегая при этом преждевременного чрезмерного извлечения. НЕ запускайте запуск для кода, отличного от React, для приложений с одним пакетом без общего пакета пользовательского интерфейса или для редактирования внутренних компонентов одного существующего компонента.
