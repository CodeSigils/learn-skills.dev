Mantén las pantallas de React ligeras y el paquete UI compartido del monorepo (packages/ui, importado como @repo/ui) como el hogar de los componentes reutilizables. Se activa al crear o rediseñar una página, ruta, pantalla o componente en una aplicación que forma parte de un monorepo con un paquete UI compartido, especialmente cuando un archivo tiende a convertirse en muros de marcado Tailwind sencillo con `<div className="...">`. Prioriza reutilizar los primitivos existentes de @repo/ui y trasladar nuevas unidades reutilizables de las pantallas a @repo/ui, evitando una extracción prematura excesiva. NO se debe activar para código que no sea React, para aplicaciones de paquete único sin paquete UI compartido, ni para editar la internals de un componente existente.
