Orientar el trabajo de UI a instalar componentes existentes de los registros shadcn configurados (el registro gratuito @shadcn y el registro de bloques de pago @shadcnblocks) antes de crearlos manualmente. Se activa al construir o rediseñar UI de React en un proyecto que tiene un components.json con los registros configurados — héroes, barras de navegación, pies de página, tablas de precios, cuadrículas de funciones, tableros, formularios, pantallas de autenticación, secciones de marketing, tablas de datos y otros bloques comunes. Usa las herramientas shadcn MCP para buscar, previsualizar y añadir, y siempre ensambla al menos tres variaciones construibles con una superficie de comparación lado a lado antes de decidirte por una. NO se activa para componentes realmente a medida o específicos de dominio que ningún registro contenga, para pilas que no sean React, o para proyectos sin registro configurado.
