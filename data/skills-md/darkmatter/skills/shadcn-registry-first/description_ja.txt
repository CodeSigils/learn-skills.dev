UI 作業は、ハンドロールする前に、設定された shadcn レジストリ（無料の @shadcn レジストリと有料の @shadcnblocks ブロックレジストリ）から既存のコンポーネントをインストールする方向にバイアスをかけます。components.json にレジストリが設定されているプロジェクトで React UI を構築またはリスタイリングする際にトリガーされます — ヒーロー、ナビバー、フッター、価格表、機能グリッド、ダッシュボード、フォーム、認証画面、マーケティングセクション、データテーブル、その他一般的なブロック。shadcn MCP ツールを使用して検索、プレビュー、追加を行い、必ず 3 つ以上の構築可能なバリエーションを横並びで比較できるように用意してからひとつを選択してください。レジストリに存在しない本当にカスタムな、ドメイン固有のコンポーネントや、React 以外のスタック、またはレジストリが設定されていないプロジェクトではトリガーしないでください。
