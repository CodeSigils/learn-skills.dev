UI 작업을 기존에 구성된 shadcn 레지스트리(무료 @shadcn 레지스트리와 유료 @shadcnblocks 블록 레지스트리)에서 구성 요소를 설치하는 방향으로 진행하고, 직접 구현하는 경우는 최소화하세요. 프로젝트에 components.json 파일이 있고 레지스트리가 구성되어 있는 경우—예: 히어로, 네비게이션 바, 푸터, 가격표, 기능 그리드, 대시보드, 폼, 인증 화면, 마케팅 섹션, 데이터 테이블 및 기타 일반 블록—React UI를 빌드하거나 스타일을 재설정할 때 트리거됩니다. shadcn MCP 도구를 사용해 검색, 미리보기 및 추가하고, 최소 세 가지 빌드 가능한 변형을 나란히 비교해 본 후 하나를 선택하세요. 레지스트리에 포함되지 않을 정도로 완전히 맞춤형이거나 도메인 특화된 컴포넌트, React가 아닌 스택, 혹은 레지스트리가 구성되지 않은 프로젝트에 대해서는 트리거하지 마세요.
