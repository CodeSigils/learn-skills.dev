Richten Sie die UI-Arbeit darauf aus, vorhandene Komponenten aus konfigurierten shadcn-Registries (dem kostenlosen @shadcn-Registry und dem kostenpflichtigen @shadcnblocks-Block-Registry) zu installieren, bevor Sie sie selbst erstellen. Wird ausgelöst, wenn React UI in einem Projekt gebaut oder neu gestaltet wird, das eine components.json mit konfigurierten Registries enthält – Helden, Navigationsleisten, Fußzeilen, Preis‑Tabellen, Feature‑Raster, Dashboards, Formulare, Auth‑Screens, Marketing‑Abschnitte, Datentabellen und andere gängige Blöcke. Verwenden Sie die shadcn MCP‑Tools, um zu suchen, eine Vorschau anzuzeigen und hinzuzufügen, und stellen Sie immer mindestens drei baubare Varianten mit einer Nebeneinander‑Vergleichsansicht zusammen, bevor Sie sich für eine entscheiden. Lösen Sie NICHT aus für wirklich maßgeschneiderte oder domänenspezifische Komponenten, die keine Registry bereitstellt, für Nicht‑React‑Stacks oder für Projekte ohne konfigurierte Registry.
