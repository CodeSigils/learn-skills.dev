Пользовательский интерфейс Bias направлен на установку существующих компонентов из настроенных реестров shadcn (бесплатный реестр @shadcn и платный блочный реестр @shadcnblocks) перед их ручным развертыванием. Срабатывает при создании или изменении пользовательского интерфейса React в проекте, в котором есть файлComponents.json с настроенными реестрами — героями, навигационными панелями, нижними колонтитулами, таблицами цен, сетками функций, панелями мониторинга, формами, экранами аутентификации, маркетинговыми разделами, таблицами данных и другими распространенными блоками. Используйте инструменты shadcn MCP для поиска, предварительного просмотра и добавления и всегда собирайте как минимум три готовых варианта с параллельной поверхностью сравнения, прежде чем остановиться на одном. НЕ запускайте запуск для действительно заказных или специфичных для предметной области компонентов, которые не будут содержаться в реестре, для стеков, отличных от React, или для проектов, для которых не настроен реестр.
