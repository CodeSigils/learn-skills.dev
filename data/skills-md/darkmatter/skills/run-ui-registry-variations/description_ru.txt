Навык ручного вызова — запускается только тогда, когда пользователь явно запрашивает «run-ui-registry-variations» или вызывает его как косую черту. Не запускайте автоматический запуск по смежным темам. Принудительная работа пользовательского интерфейса через shadcnblocks, Aceternity или https://shadcn.darkmatter.io; проверять доступ к частному реестру перед использованием; создайте ровно три варианта, доступные для просмотра пользователем.
