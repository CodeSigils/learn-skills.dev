تم الاستدعاء بواسطة /tidy-code. يراجع الكود المصدري لانتهاكات الجودة الهيكلية (التبعيات المخفية، والوظائف الإلهية، والفشل الصامت، والتداخل العميق) عبر أي لغة. يُنتج تقرير نتائج للقراءة فقط مع اقتراحات إعادة هيكلة ملموسة. يتخطى كل دليل يبدأ بـ `.` (على سبيل المثال، `.git`، `.venv`، `.rdf`، `.agents`، `.claude`، IDE/agent scaffolding) بالإضافة إلى `node_modules` المعتادة، `vendor`، `dist`، `build`، `coverage`، `target`.
