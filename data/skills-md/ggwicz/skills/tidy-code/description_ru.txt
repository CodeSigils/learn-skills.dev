Вызывается /tidy-code. Проверяет исходный код на наличие структурных нарушений качества (скрытые зависимости, функции бога, скрытые сбои, глубокая вложенность) на любом языке. Создает отчет о результатах, доступный только для чтения, с конкретными предложениями по рефакторингу. Пропускает все каталоги, начинающиеся с `.` (например, `.git`, `.venv`, `.rdf`, `.agents`, `.claude`, IDE/agent scaffolding), а также обычные `node_modules`, `vendor`, `dist`, `build`, `coverage`, `target`.
