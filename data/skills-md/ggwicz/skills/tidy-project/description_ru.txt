Используйте, когда пользователь явно вызывает /tidy-project. Запускает трехэтапный аудит структуры проекта только для чтения для упрощения обслуживания одиночной разработки. Выявляет мертвый код, дублирование, преждевременную абстракцию, чрезмерную вложенность, чрезмерную связь, рудиментарные каркасы инфраструктуры, устаревшие маркеры и дрейф документации/кода. Создает единый консолидированный план выполнения в `docs/ГГГГ-ММ-ДД-tidy-project-plan.md` (или в корне репозитория, если нет `docs/`) — не изменяет исходные файлы. Пропускает все каталоги, начинающиеся с `.` (например, `.git`, `.venv`, `.rdf`, `.agents`, `.claude`, `.github`, IDE/CI/agent scaffolding), а также обычные `node_modules`, `vendor`, `dist`, `build`, `coverage`, `target`.
