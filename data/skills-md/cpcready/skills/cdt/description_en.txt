Crear y gestionar imágenes .cdt de cassette tape para Amstrad CPC desde automatizaciones. Usar cuando el usuario pida operar cintas CDT/TZX con ia2cdt (new, save, cat, check), cuando necesite control avanzado de velocidades de baudios (1000-6000), métodos TZX (turbo/pure data/standard), o codificación de datos (blocks/headerless/spectrum/two-blocks). Herramienta Python multiplataforma.
