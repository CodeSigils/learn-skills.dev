قم ببناء وصيانة دفاتر وتنبؤات واضحة لانتهاء صلاحية إعادة تعيين رصيد الدستور الغذائي والمحافظة عليها، مع مراعاة المنطقة الزمنية. يُستخدم عندما يطلب المستخدم جلب فترات انتهاء صلاحية إعادة تعيين الحساب بالضبط، أو تتبع أرصدة إعادة تعيين Tibo/Codex، أو استنتاج انتهاء الصلاحية من عدد مرئي لإعادة تعيين البنك، أو تعيين أرصدة إعادة تعيين لإعلانات إعادة تعيين Tibo/OpenAI، أو فحص انتهاء صلاحية إعادة تعيين البنك، أو التعامل مع نوافذ إعادة التعيين لمدة 30 يومًا، أو تحليل عناوين URL لإعلان إعادة تعيين X/Twitter، أو عرض جداول العد التنازلي، أو إصدار دفاتر إعادة تعيين Markdown/JSON لأدوات التصدير النهائية.
