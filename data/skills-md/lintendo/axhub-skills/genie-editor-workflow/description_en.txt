Achieve a complete closed-loop workflow for web-editor todos through the Axhub AI Extension (Chrome extension) together with the @axhub/genie CLI. It guides users to install the extension and check connection status, discovers online editor clients, reads user annotations and todo nodes, exports contextual screenshots and images, sets edit states (four-state lifecycle: editing/idle/completed/error), finishes code modifications and writes back the final state. Supports CLI auto-retry, exponential-backoff reconnect, tab visibility awareness, task-state persistence, and other communication stability guarantees. Used when a user annotates a webpage modification todo via Genie Editor and wants the AI to handle it.
