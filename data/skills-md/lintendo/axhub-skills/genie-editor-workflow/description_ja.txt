Axhub AI Extension (Chrome 拡張機能) と @axhub/genie CLI を使用して、ウェブページエディターの To-Do の完全な閉ループ ワークフローを実現します。ユーザーに拡張機能のインストールと接続ステータスの確認を指示し、オンライン エディター クライアントを検出し、ユーザーの注釈と To Do ノードを読み取り、コンテキストに応じたスクリーンショットと画像をエクスポートし、編集状態 (4 つの状態のライフサイクル: 編集/アイドル/完了/エラー) を設定し、コードの変更を完了して最終状態を書き戻します。 CLI 自動再試行、指数バックオフ再接続、タブ表示認識、タスク状態の永続化、その他の通信安定性保護機能をサポートします。ユーザーが Genie Editor で Web ページの変更 To-Do に注釈を付け、AI にそれらを処理してもらいたい場合に使用されます。
