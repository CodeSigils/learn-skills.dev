Axhub AI Extension (Chrome 拡張機能) と @axhub/genie CLI を使用して、Web ページ エディターの ToDo の完全な閉ループ ワークフローを実現します。拡張機能のインストールと接続ステータスの確認、オンライン エディター クライアントの検出、ユーザーの注釈と Todo ノードの読み取り、コンテキストのスクリーンショットと画像のエクスポート、編集状態 (4 つの状態のライフサイクル: 編集/アイドル/完了/エラー) の設定、コードの変更の完了、最終状態の書き戻しをユーザーにガイドします。 CLI 自動再試行、指数関数的バックオフ再接続、タブ表示の認識、タスク状態の永続性などの通信安定性の保証が含まれます。ユーザーが Genie エディターで Web ページの変更 ToDo に注釈を付け、AI にそれを処理させたい場合に使用されます。
