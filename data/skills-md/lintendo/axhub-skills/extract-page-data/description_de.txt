Extrahieren Sie mit Playwright strukturierte Daten aus jeder Webseite – Screenshots, Design-Tokens, Seitentext als Markdown, interaktive Elementkarten und ganzseitige Datenpakete. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Webseiten-Screenshot (ganze Seite oder Element) erfassen, CSS-Design-Tokens oder Designinformationen extrahieren, Seiteninhalte in Markdown konvertieren, Links und interaktive Elemente von einer Seite sammeln oder ein vollständiges Seitenanalysepaket exportieren möchte. Wird bei jeder URL ausgelöst, die kein Axure-Prototyp ist – verwenden Sie für Axure-URLs stattdessen extract-axure-data.
