Estrai dati strutturati da qualsiasi pagina web utilizzando Playwright: screenshot, token di progettazione, testo della pagina come Markdown, mappe di elementi interattivi e pacchetti di dati di pagine intere. Utilizza questa competenza ogni volta che l'utente desidera acquisire uno screenshot di una pagina Web (pagina intera o elemento), estrarre token di progettazione CSS o informazioni sul tema, convertire il contenuto della pagina in Markdown, raccogliere collegamenti ed elementi interattivi da una pagina o esportare un pacchetto completo di analisi della pagina. Si attiva su qualsiasi URL che non sia un prototipo Axure: per gli URL Axure utilizza invece extract-axure-data.
