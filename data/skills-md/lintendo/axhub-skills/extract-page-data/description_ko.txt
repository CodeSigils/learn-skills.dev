Playwright를 사용하여 모든 웹페이지에서 스크린샷, 디자인 토큰, 마크다운으로 된 페이지 텍스트, 대화형 요소 맵, 전체 페이지 데이터 팩 등 구조화된 데이터를 추출합니다. 사용자가 웹 페이지 스크린샷(전체 페이지 또는 요소)을 캡처하고, CSS 디자인 토큰 또는 테마 정보를 추출하고, 페이지 콘텐츠를 마크다운으로 변환하고, 페이지에서 링크 및 대화형 요소를 수집하거나, 전체 페이지 분석 패키지를 내보내고 싶을 때마다 이 기술을 사용하세요. Axure 프로토타입이 아닌 모든 URL에서 트리거합니다. Axure URL의 경우 대신 extract-axure-data를 사용합니다.
