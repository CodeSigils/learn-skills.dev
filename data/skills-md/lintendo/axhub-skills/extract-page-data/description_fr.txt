Extrayez des données structurées de n'importe quelle page Web à l'aide de Playwright : captures d'écran, jetons de conception, texte de page au format Markdown, cartes d'éléments interactives et packs de données pleine page. Utilisez cette compétence chaque fois que l'utilisateur souhaite capturer une capture d'écran d'une page Web (page entière ou élément), extraire des jetons de conception CSS ou des informations sur le thème, convertir le contenu d'une page en Markdown, collecter des liens et des éléments interactifs à partir d'une page ou exporter un package complet d'analyse de page. Se déclenche sur n'importe quelle URL qui n'est pas un prototype Axure — pour les URL Axure, utilisez plutôt extract-axure-data.
