Extraiga datos estructurados de cualquier página web utilizando Playwright: capturas de pantalla, tokens de diseño, texto de página como Markdown, mapas de elementos interactivos y paquetes de datos de página completa. Utilice esta habilidad siempre que el usuario desee realizar una captura de pantalla de una página web (página completa o elemento), extraer tokens de diseño CSS o información del tema, convertir el contenido de la página a Markdown, recopilar enlaces y elementos interactivos de una página o exportar un paquete completo de análisis de página. Se activa en cualquier URL que no sea un prototipo de Axure; para las URL de Axure, utilice extract-axure-data en su lugar.
