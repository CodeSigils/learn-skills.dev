استخرج البيانات المنظمة من أي صفحة ويب باستخدام Playwright — لقطات الشاشة، ورموز التصميم، ونص الصفحة كـ Markdown، وخرائط العناصر التفاعلية، وحزم بيانات الصفحة الكاملة. استخدم هذه المهارة عندما يريد المستخدم التقاط لقطة شاشة لصفحة ويب (صفحة كاملة أو عنصر)، أو استخراج رموز تصميم CSS أو معلومات السمة، أو تحويل محتوى الصفحة إلى Markdown، أو جمع الروابط والعناصر التفاعلية من الصفحة، أو تصدير حزمة تحليل صفحة كاملة. المشغلات على أي عنوان URL ليس نموذجًا أوليًا لـ Axure - بالنسبة لعناوين URL لـ Axure، استخدم بيانات extract-axure بدلاً من ذلك.
