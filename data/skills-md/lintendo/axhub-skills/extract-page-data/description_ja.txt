Playwright を使用して、あらゆる Web ページから構造化データ (スクリーンショット、デザイン トークン、マークダウンとしてのページ テキスト、インタラクティブな要素マップ、フル ページ データ パック) を抽出します。ユーザーが Web ページのスクリーンショット (ページ全体または要素) をキャプチャしたり、CSS デザイン トークンやテーマ情報を抽出したり、ページ コンテンツを Markdown に変換したり、ページからリンクやインタラクティブな要素を収集したり、完全なページ分析パッケージをエクスポートしたりする場合には、このスキルを使用します。 Axure プロトタイプではない URL でトリガーします。Axure URL の場合は、代わりに extract-axure-data を使用します。
