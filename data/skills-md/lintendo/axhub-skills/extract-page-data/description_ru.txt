Извлекайте структурированные данные с любой веб-страницы с помощью Playwright — снимки экрана, маркеры дизайна, текст страницы в формате Markdown, интерактивные карты элементов и полностраничные пакеты данных. Используйте этот навык всякий раз, когда пользователь хочет сделать снимок экрана веб-страницы (полную страницу или элемент), извлечь токены дизайна CSS или информацию о теме, преобразовать содержимое страницы в Markdown, собрать ссылки и интерактивные элементы со страницы или экспортировать полный пакет анализа страницы. Запускается по любому URL-адресу, который не является прототипом Axure — вместо этого для URL-адресов Axure используйте Extract-axure-data.
