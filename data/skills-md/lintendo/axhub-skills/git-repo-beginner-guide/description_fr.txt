Pour les utilisateurs non techniques tels que les chefs de produit, les concepteurs, le personnel opérationnel et les auteurs de documentation qui ne sont pas familiers avec Git, fournissez des conseils sur l'initialisation du référentiel, l'autorisation, le clonage, la synchronisation des validations, la résolution des conflits, la récupération de version et le transfert de collaboration sur GitHub, GitLab, Gitee, Bitbucket et les plateformes Git auto-hébergées.
