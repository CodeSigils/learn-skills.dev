Для нетехнических пользователей, таких как менеджеры по продуктам, дизайнеры, операционный персонал и авторы документации, которые незнакомы с Git, предоставьте рекомендации по инициализации репозитория, авторизации, клонированию, синхронизации фиксации, разрешению конфликтов, восстановлению версий и передаче совместной работы на GitHub, GitLab, Gitee, Bitbucket и самостоятельных платформах Git.
