Clonación de páginas web de alta precisión. Utiliza Playwright para recopilar progresivamente datos de la página (estructura DOM, estilos, capturas de pantalla, recursos) y luego reconstruye una réplica HTML/CSS completa por etapas. Admite modos de restauración rápidos y de alta precisión. Utilice esta habilidad cuando los usuarios necesiten clonar, replicar, restaurar o imitar una página web. Cuando un usuario proporciona una URL y solicita "crear una página idéntica", "clonar esta página", "hacer referencia al diseño de este sitio" o "restaurar esta página", utilice siempre esta habilidad.
