High-precision webpage cloning. Uses Playwright to progressively collect page data (DOM structure, styles, screenshots, resources), then reconstructs a complete HTML/CSS replica in stages. Supports both fast and high-precision restoration modes. Use this skill when users need to clone, replicate, restore, or imitate a webpage. When a user provides a URL and asks to "make an identical page," "clone this page," "reference this site's design," or "restore this page," always use this skill.
