High-precision webpage cloning. Uses Playwright to progressively collect page data (DOM structure, styles, screenshots, resources), then reconstructs the complete HTML/CSS in stages. Supports both fast and high-precision restoration modes. Use this skill when users need to clone, replicate, restore, or imitate a webpage. Whenever a user provides a URL and asks to "make the same page," "clone this page," "reference this site's design," or "restore this page," be sure to use this skill.
