استنساخ صفحات الويب بدقة عالية. يستخدم Playwright لجمع بيانات الصفحة تدريجيًا (بنية DOM، والأنماط، ولقطات الشاشة، والموارد)، ثم يعيد بناء HTML/CSS الكامل على مراحل. يدعم أوضاع الاستعادة السريعة والعالية الدقة. استخدم هذه المهارة عندما يحتاج المستخدم إلى استنساخ صفحة ويب أو نسخها أو استعادتها أو تقليدها. عندما يقدم المستخدم عنوان URL ويطلب "إنشاء صفحة مماثلة" أو "استنساخ هذه الصفحة" أو "الإشارة إلى تصميم هذا الموقع" أو "استعادة هذه الصفحة"، قم دائمًا بتطبيق هذه المهارة.
