استنساخ صفحات الويب بدقة عالية. يستخدم Playwright لجمع بيانات الصفحة تدريجيًا (بنية DOM، والأنماط، ولقطات الشاشة، والموارد)، ثم يعيد بناء نسخة متماثلة كاملة من HTML/CSS على مراحل. يدعم أوضاع الاستعادة السريعة والعالية الدقة. استخدم هذه المهارة عندما يحتاج المستخدمون إلى استنساخ صفحة ويب أو نسخها أو استعادتها أو تقليدها. عندما يقدم المستخدم عنوان URL ويطلب "إنشاء صفحة مماثلة" أو "استنساخ هذه الصفحة" أو "الرجوع إلى تصميم هذا الموقع" أو "استعادة هذه الصفحة"، استخدم هذه المهارة دائمًا.
