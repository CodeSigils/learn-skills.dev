Estrai token di progettazione da una pagina Web e genera una specifica DESIGN.md completa più un file di tema CSS Tailwind.  
Usalo quando un utente fornisce un URL e chiede di "estrarre il tema", "generare specifiche di progettazione", "esportare sistema di progettazione", "estrarre token di progettazione da questo sito", "costruirmi un tema" o "analizzare lo stile di questa pagina".  
L'output include DESIGN.md (formato Google Stitch) e globals.css (Tailwind CSS v4), ciascuna categoria di token con regole consigliate/consentite/vietate, pronte per essere inserite nella root del progetto per gli strumenti di codifica AI.
