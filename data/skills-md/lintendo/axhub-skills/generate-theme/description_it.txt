Estrai i token di progettazione dalla pagina Web e genera una specifica DESIGN.md completa oltre a un file di tema CSS Tailwind.  
Utilizzalo quando l'utente fornisce un URL e chiede di "estrarre il tema", "generare specifiche di progettazione", "esportare il sistema di progettazione", "estrarre token di progettazione da questo sito", "costruirmi un tema" o "analizzare lo stile di progettazione di questa pagina".  
L'output include DESIGN.md (formato Google Stitch) e globals.css (Tailwind CSS v4), ciascuna categoria di token contiene regole consigliate/consentite/vietate, pronte per essere inserite nella root del progetto per gli strumenti di codifica AI.
