Соберите дизайнерские токены с веб-страницы и создайте полную спецификацию DESIGN.md, а также файл темы CSS Tailwind.  
Используйте его, когда пользователь предоставляет URL-адрес и просит «извлечь тему», «создать спецификацию дизайна», «экспортировать систему дизайна», «извлечь токены дизайна с этого сайта», «создать мне тему» ​​или «проанализировать стиль этой страницы».  
Выходные данные включают в себя DESIGN.md (формат Google Stitch) и globals.css (Tailwind CSS v4), каждую категорию токенов с рекомендуемыми/разрешенными/запрещенными правилами, готовыми к отправке в корень проекта для инструментов кодирования AI.
