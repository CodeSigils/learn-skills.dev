Grattez les jetons de conception d'une page Web et générez une spécification DESIGN.md complète ainsi qu'un fichier de thème CSS Tailwind.  
Utilisez-le lorsqu'un utilisateur fournit une URL et demande « d'extraire le thème », de « générer des spécifications de conception », « d'exporter le système de conception », « d'extraire des jetons de conception de ce site », de « me créer un thème » ou « d'analyser le style de cette page ».  
La sortie inclut DESIGN.md (format Google Stitch) et globals.css (Tailwind CSS v4), chaque catégorie de jetons avec des règles recommandées/autorisées/interdites, prêtes à être déposées dans la racine du projet pour les outils de codage d'IA.
