Supprimez les jetons de conception de la page Web et générez une spécification DESIGN.md complète ainsi qu'un fichier de thème CSS Tailwind. À utiliser lorsque l'utilisateur fournit une URL et demande "d'extraire le thème", de "générer des spécifications de conception", "d'exporter le système de conception", "d'extraire les jetons de conception de ce site", de "me créer un thème" ou "d'analyser le style de conception de cette page". La sortie inclut DESIGN.md (format Google Stitch) et globals.css (Tailwind CSS v4), avec des règles recommandées/autorisées/interdites pour chaque catégorie de jetons, prêts à être déposés dans la racine du projet pour les outils de codage d'IA.
