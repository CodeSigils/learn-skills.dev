Extraiga tokens de diseño de cualquier página web y genere una especificación DESIGN.md completa más un archivo de tema CSS Tailwind. Se activa cuando el usuario proporciona una URL y solicita "extraer tema", "generar especificaciones de diseño", "exportar sistema de diseño", "extraer tokens de diseño", "construirme un tema" o "analizar el estilo de esta página". La salida incluye DESIGN.md (formato Google Stitch) y globals.css (Tailwind CSS v4), cada categoría de token lleva reglas recomendadas/permitidas/prohibidas, listas para colocarse en la raíz del proyecto para herramientas de codificación de IA.
