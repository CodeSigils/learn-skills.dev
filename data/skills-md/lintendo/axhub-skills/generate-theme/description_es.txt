Extraiga tokens de diseño de una página web y genere una especificación DESIGN.md completa más un archivo de tema CSS Tailwind.  
Úselo cuando un usuario proporcione una URL y solicite "extraer el tema", "generar especificaciones de diseño", "exportar sistema de diseño", "extraer tokens de diseño de este sitio", "construirme un tema" o "analizar el estilo de esta página".  
La salida incluye DESIGN.md (formato Google Stitch) y globals.css (Tailwind CSS v4), cada categoría de token con reglas recomendadas/permitidas/prohibidas, listas para colocarse en la raíz del proyecto para herramientas de codificación de IA.
