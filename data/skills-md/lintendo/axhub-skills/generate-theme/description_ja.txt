Web ページからデザイン トークンを抽出し、完全な DESIGN.md 仕様と Tailwind CSS テーマ ファイルを生成します。  
ユーザーが URL を指定して「テーマの抽出」、「デザイン仕様の生成」、「デザイン システムのエクスポート」、「このサイトからデザイン トークンを取得」、「テーマを構築」、または「このページのデザイン スタイルを分析」を要求する場合に使用します。  
出力には DESIGN.md (Google Stitch 形式) と globals.css (Tailwind CSS v4) が含まれており、各トークン カテゴリには推奨/許可/禁止のルールが含まれており、AI コーディング ツールのプロジェクト ルートにドロップする準備ができています。
