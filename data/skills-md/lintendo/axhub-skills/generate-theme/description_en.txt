Scrape design tokens from a web page and generate a complete DESIGN.md spec plus a Tailwind CSS theme file.  
Use it when a user supplies a URL and asks to “extract the theme”, “generate design spec”, “export design system”, “pull design tokens from this site”, “build me a theme”, or “analyze this page’s style”.  
Output includes DESIGN.md (Google Stitch format) and globals.css (Tailwind CSS v4), each token category with recommended / allowed / forbidden rules, ready to drop into project root for AI coding tools.
