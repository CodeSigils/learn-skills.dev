Scrape design tokens from any webpage and generate a complete DESIGN.md spec plus a Tailwind CSS theme file.  
Use when the user supplies a URL and asks to “extract the theme”, “generate design guidelines”, “export the design system”, “pull design tokens from this site”, “build me a theme”, or “analyze this page’s style”.  
Deliverables: DESIGN.md (Google Stitch format) and globals.css (Tailwind CSS v4), each token category carrying recommended/allowed/forbidden rules, ready to drop into project root for AI coding tools.
