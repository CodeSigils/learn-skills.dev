Entfernen Sie Design-Tokens von der Webseite und generieren Sie eine vollständige DESIGN.md-Spezifikation sowie eine Tailwind-CSS-Designdatei.  
Verwenden Sie diese Option, wenn der Benutzer eine URL angibt und nach „Theme extrahieren“, „Designspezifikation generieren“, „Designsystem exportieren“, „Design-Tokens dieser Website extrahieren“, „Mir ein Design erstellen“ oder „Designstil dieser Seite analysieren“ fragt.  
Die Ausgabe umfasst DESIGN.md (Google Stitch-Format) und globals.css (Tailwind CSS v4), jede Token-Kategorie mit empfohlenen/erlaubten/verbotenen Regeln, bereit zum Ablegen im Projektstamm für KI-Codierungstools.
