Scrapen Sie Design-Tokens von einer Webseite und generieren Sie eine vollständige DESIGN.md-Spezifikation sowie eine Tailwind-CSS-Designdatei.  
Verwenden Sie es, wenn ein Benutzer eine URL angibt und auffordert, „das Thema zu extrahieren“, „Designspezifikation zu generieren“, „Designsystem zu exportieren“, „Design-Tokens von dieser Website abzurufen“, „mir ein Thema zu erstellen“ oder „den Stil dieser Seite zu analysieren“.  
Die Ausgabe umfasst DESIGN.md (Google Stitch-Format) und globals.css (Tailwind CSS v4), jede Token-Kategorie mit empfohlenen/erlaubten/verbotenen Regeln, bereit zum Ablegen im Projektstammverzeichnis für KI-Codierungstools.
