Konvertieren Sie jede React-Komponente oder -Anwendung in eine Standardprojektstruktur, die in Figma Make bearbeitet und exportiert werden kann. Ideal für bestehende React-Projekte, die zur visuellen Bearbeitung, Teamzusammenarbeit oder zum Generieren von .fig-Dateien in Figma Make importiert werden müssen. Verwenden Sie diese Option, wenn Benutzer erwähnen, dass sie React in Figma konvertieren, nach Figma Make exportieren, .fig-Dateien erstellen oder vorhandenen React-Code in Figma Make bearbeiten möchten.
