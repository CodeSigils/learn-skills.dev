Konvertieren Sie jede React-Komponente oder -Anwendung in eine Standardprojektstruktur, die in Figma Make bearbeitet und exportiert werden kann. Geeignet für Szenarien, in denen ein vorhandenes React-Projekt zur visuellen Bearbeitung, Teamzusammenarbeit oder zum Generieren einer .fig-Datei in Figma Make importiert werden muss. Verwenden Sie diese Option, wenn Benutzer erwähnen, dass sie React in Figma konvertieren, nach Figma Make exportieren, eine .fig-Datei generieren oder vorhandenen React-Code in Figma Make bearbeiten möchten.
