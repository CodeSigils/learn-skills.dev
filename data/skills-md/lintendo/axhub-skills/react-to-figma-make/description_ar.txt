قم بتحويل أي مكون أو تطبيق React إلى بنية مشروع قياسية يمكن تحريرها وتصديرها في Figma Make. مثالي لاستيراد مشاريع React الموجودة إلى Figma Make للتحرير المرئي أو التعاون الجماعي أو إنشاء ملفات .Figa. يُستخدم عندما يذكر المستخدمون تحويل React إلى Figma، أو التصدير إلى Figma Make، أو إنشاء ملفات .fig، أو الرغبة في تحرير كود React الموجود في Figma Make.
