Convierta cualquier componente o aplicación de React en una estructura de proyecto estándar que pueda editarse y exportarse en Figma Make. Adecuado para escenarios en los que es necesario importar un proyecto de React existente a Figma Make para edición visual, colaboración en equipo o generar un archivo .fig. Úselo cuando los usuarios mencionen convertir React a Figma, exportar a Figma Make, generar un archivo .fig o querer editar el código de React existente en Figma Make.
