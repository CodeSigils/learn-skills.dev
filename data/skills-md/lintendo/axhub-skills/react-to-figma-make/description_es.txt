Convierta cualquier componente o aplicación de React en una estructura de proyecto estándar que pueda editarse y exportarse en Figma Make. Ideal para escenarios en los que es necesario importar un proyecto de React existente a Figma Make para edición visual, colaboración en equipo o generación de archivos .fig. Úselo cuando los usuarios mencionen convertir React a Figma, exportar a Figma Make, generar archivos .fig o querer editar el código de React existente en Figma Make.
