Converti qualsiasi componente o applicazione React in una struttura di progetto standard che può essere modificata ed esportata in Figma Make. Adatto a scenari in cui un progetto React esistente deve essere importato in Figma Make per l'editing visivo, la collaborazione in team o la generazione di un file .fig. Da utilizzare quando gli utenti menzionano la conversione di React in Figma, l'esportazione in Figma Make, la generazione di un file .fig o il desiderio di modificare il codice React esistente in Figma Make.
