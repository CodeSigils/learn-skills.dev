Convertissez n'importe quel composant ou application React en une structure de projet standard qui peut être modifiée et exportée dans Figma Make. Convient aux scénarios dans lesquels un projet React existant doit être importé dans Figma Make pour l'édition visuelle, la collaboration en équipe ou la génération d'un fichier .fig. À utiliser lorsque les utilisateurs mentionnent la conversion de React en Figma, l'exportation vers Figma Make, la génération d'un fichier .fig ou la volonté de modifier le code React existant dans Figma Make.
