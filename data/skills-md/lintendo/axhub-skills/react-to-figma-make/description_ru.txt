Преобразуйте любой компонент или приложение React в стандартную структуру проекта, которую можно редактировать и экспортировать в Figma Make. Подходит для сценариев, когда существующий проект React необходимо импортировать в Figma Make для визуального редактирования, совместной работы или создания файла .fig. Используйте, когда пользователи упоминают преобразование React в Figma, экспорт в Figma Make, создание файла .fig или желание отредактировать существующий код React в Figma Make.
