Mettez à niveau une application Strapi vers une nouvelle version. TOUJOURS examine d'abord les modifications importantes pertinentes (via le serveur MCP strapi-docs, ou en récupérant les documents directement si le MCP n'est pas disponible), puis effectue la mise à niveau à l'aide de l'outil officiel @strapi/upgrade. À utiliser chaque fois que l'utilisateur souhaite mettre à niveau, mettre à jour ou modifier sa version de Strapi.
