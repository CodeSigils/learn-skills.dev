Aktualisieren Sie eine Strapi-Anwendung auf eine neue Version. Überprüfen Sie IMMER zuerst die relevanten Breaking Changes (über den strapi-docs MCP-Server oder durch direktes Abrufen der Dokumente, wenn der MCP nicht verfügbar ist) und führen Sie dann das Upgrade mit dem offiziellen @strapi/upgrade-Tool durch. Verwenden Sie es immer dann, wenn der Benutzer seine Strapi-Version aktualisieren, aktualisieren oder erweitern möchte.
