Actualice una aplicación Strapi a una nueva versión. SIEMPRE revisa los cambios de interrupción relevantes primero (a través del servidor MCP de strapi-docs, o buscando los documentos directamente si el MCP no está disponible), luego realiza la actualización utilizando la herramienta oficial @ strapi/upgrade. Úselo siempre que el usuario desee actualizar, actualizar o mejorar su versión de Strapi.
