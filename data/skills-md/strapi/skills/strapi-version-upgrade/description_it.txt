Aggiorna un'applicazione Strapi a una nuova versione. Esamina SEMPRE prima le modifiche rilevanti (tramite il server MCP strapi-docs o recuperando direttamente i documenti se MCP non è disponibile), quindi esegui l'aggiornamento utilizzando lo strumento ufficiale @strapi/upgrade. Utilizzare ogni volta che l'utente desidera aggiornare, aggiornare o aumentare la propria versione Strapi.
