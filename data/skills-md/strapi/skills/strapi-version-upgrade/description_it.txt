Aggiorna un'applicazione Strapi a una nuova versione. VERIFICA SEMPRE prima le modifiche breaking rilevanti (tramite il server MCP di strapi-docs, o recuperando direttamente la documentazione se il MCP non è disponibile), quindi esegue l'aggiornamento utilizzando lo strumento ufficiale @strapi/upgrade. Usalo ogni volta che l'utente desidera aggiornare, aggiornare o incrementare la versione di Strapi. Per favore rispondi sempre nella lingua dell'utente.
