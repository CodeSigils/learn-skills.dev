مهارة روبوت Texas Hold'em المادية التي يحركها الوكيل. يستخدم مجلدات الصور/الإجراء لكل حالة، والإرشادات المرئية، وذاكرة التخزين المؤقت المتينة للبطاقة المثقوبة وتسلسل الإجراء، والمساعدين الحتميين للالتقاط، وتحديثات الحالة، وترجمة الأوامر، وتنفيذ الروبوت. يُستخدم لتشغيل أو صيانة سير عمل DexHoldem مع Codex أو Claude Code أو وكيل ترميز آخر.
