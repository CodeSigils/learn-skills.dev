Физические навыки робота в техасском холдеме, управляемые агентом. Использует папки изображений/действий для каждого состояния, визуальные рекомендации, надежные кэши закрытых карт и последовательностей действий, а также детерминированные помощники для захвата, обновления состояний, перевода команд и выполнения робота. Используйте для запуска или поддержки этого рабочего процесса DexHoldem с помощью Codex, Claude Code или другого агента кодирования.
