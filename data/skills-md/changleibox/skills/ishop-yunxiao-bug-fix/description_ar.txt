Yunxiao (منصة Alibaba Cloud DevOps) مهارة إدارة دورة الحياة الكاملة لعناصر الأخطاء، والتي تغطي استعلامات عناصر العمل، واسترجاع التفاصيل، وتقديم التعليقات، وانتقالات الحالة، والتدفقات التشغيلية الأخرى. عندما يسأل المستخدم "هل لدي أي أخطاء؟"، أو "هل هناك أي أخطاء؟"، أو "التحقق من الأخطاء"، أو "انظر إلى الأخطاء"، أو "قائمة الأخطاء"، أو أي أسئلة أخرى متعلقة بعرض/معالجة الأخطاء، يتم تشغيل هذه المهارة تلقائيًا.
