ダイナミック アイランド スタイルのノッチ UI を macOS アプリに追加します。ユーザーがノッチ オーバーレイ、ノッチ エクステンダー、Dynamic Island for Mac、ノッチ インジケーター、または MacBook のノッチ領域から拡張する UI を作成したい場合は常に、このスキルを使用します。また、ユーザーが「ノッチ形状」、「ノッチウィンドウ」、「ノッチカットアウト」、「ノッチパネル」、「ノッチ近くの録音インジケーター」、「ダイナミックアイランドスタイル」に言及した場合、またはハードウェアノッチから現れるように見えるステータス/コンテンツを表示したい場合にもトリガーされます。これには、NSPanel セットアップ、凹型ベジェ イヤー カーブを備えた NotchShape、画面位置計算、スプリング アニメーション、および振り付けの表示/非表示が含まれます。
