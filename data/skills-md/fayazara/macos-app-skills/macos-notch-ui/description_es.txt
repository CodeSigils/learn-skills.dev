Agregue una interfaz de usuario con muesca estilo Dynamic Island a una aplicación macOS. Utilice esta habilidad siempre que el usuario quiera crear una superposición de muesca, un extensor de muesca, una isla dinámica para Mac, un indicador de muesca o cualquier interfaz de usuario que se extienda desde el área de muesca del MacBook. También se activa cuando el usuario menciona "forma de muesca", "ventana de muesca", "recorte de muesca", "panel de muesca", "indicador de grabación cerca de la muesca", "estilo de isla dinámica" o quiere mostrar el estado/contenido que parece emerger de la muesca del hardware. Esto cubre la configuración de NSPanel, NotchShape con curvas de oreja cóncavas de Bezier, matemáticas de posicionamiento de pantalla, animaciones de resorte y coreografía de mostrar/ocultar.
