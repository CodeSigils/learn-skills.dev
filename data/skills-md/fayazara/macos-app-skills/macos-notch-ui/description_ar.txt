أضف واجهة مستخدم ذات نمط الجزيرة الديناميكية إلى تطبيق macOS. استخدم هذه المهارة عندما يريد المستخدم إنشاء تراكب الحز، أو موسع الحز، أو Dynamic Island لنظام التشغيل Mac، أو مؤشر الحز، أو أي واجهة مستخدم تمتد من منطقة الحز في MacBook. يتم تشغيله أيضًا عندما يذكر المستخدم "شكل الحز"، أو "نافذة الحز"، أو "قطع الحز"، أو "لوحة الحز"، أو "مؤشر التسجيل بالقرب من الحز"، أو "نمط الجزيرة الديناميكي"، أو يريد إظهار الحالة/المحتوى الذي يبدو وكأنه يخرج من حز الأجهزة. يغطي هذا إعداد NSPanel، وNotchShape مع منحنيات أذن Bezier المقعرة، ورياضيات تحديد موضع الشاشة، والرسوم المتحركة الربيعية، وتصميم الرقصات لإظهار/إخفاء.
