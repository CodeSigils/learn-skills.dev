Fügen Sie einer macOS-App eine Notch-Benutzeroberfläche im Dynamic Island-Stil hinzu. Verwenden Sie diesen Skill immer dann, wenn der Benutzer ein Notch-Overlay, einen Notch-Extender, Dynamic Island für Mac, einen Notch-Indikator oder eine andere Benutzeroberfläche erstellen möchte, die über den Notch-Bereich des MacBook hinausgeht. Wird auch ausgelöst, wenn der Benutzer „Notch-Form“, „Notch-Fenster“, „Notch-Ausschnitt“, „Notch-Panel“, „Aufnahmeanzeige in der Nähe der Notch“, „Dynamic Island-Stil“ erwähnt oder Status/Inhalte anzeigen möchte, die aus der Hardware-Notch hervortreten. Dies umfasst das NSPanel-Setup, die NotchShape mit konkaven Bezier-Ohrkurven, die Berechnung der Bildschirmpositionierung, Federanimationen und die Choreografie zum Ein-/Ausblenden.
