Ajoutez une interface utilisateur à encoche de style Dynamic Island à une application macOS. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer une superposition d'encoche, une extension d'encoche, Dynamic Island pour Mac, un indicateur d'encoche ou toute interface utilisateur s'étendant à partir de la zone d'encoche du MacBook. Déclenchez également lorsque l'utilisateur mentionne "forme d'encoche", "fenêtre d'encoche", "découpe d'encoche", "panneau d'encoche", "indicateur d'enregistrement près de l'encoche", "style d'îlot dynamique" ou souhaite afficher l'état/le contenu qui semble émerger de l'encoche matérielle. Cela couvre la configuration NSPanel, le NotchShape avec les courbes d'oreille concaves de Bézier, les mathématiques de positionnement de l'écran, les animations à ressort et la chorégraphie afficher/masquer.
