Добавьте в приложение macOS пользовательский интерфейс с вырезом в стиле Dynamic Island. Используйте этот навык всякий раз, когда пользователь хочет создать наложение выреза, расширитель выреза, динамический остров для Mac, индикатор выреза или любой пользовательский интерфейс, выходящий за пределы области выреза MacBook. Также срабатывает, когда пользователь упоминает «форму выреза», «окно выреза», «вырез выреза», «панель выреза», «индикатор записи рядом с вырезом», «стиль динамического острова» или хочет показать статус/контент, который появляется из аппаратного выреза. Сюда входят настройка NSPanel, NotchShape с вогнутыми кривыми Безье, математические расчеты позиционирования экрана, пружинная анимация и хореография показа/скрытия.
