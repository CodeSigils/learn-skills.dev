Rilascia un'app macOS nativa su GitHub con il pacchetto DMG e gli aggiornamenti Sparkle appcast. Utilizza questa competenza ogni volta che l'utente desidera pubblicare una nuova versione, creare una versione, spedire un aggiornamento, inviare una versione a GitHub o aggiornare l'appcast. Si attivano anche quando l'utente menziona la creazione DMG, la firma Sparkle, l'autenticazione, l'archiviazione o qualsiasi cosa relativa alla distribuzione di una nuova versione della propria app macOS. Copre l'intera pipeline di rilascio: archiviazione, autenticazione, esportazione, creazione DMG, firma con Sparkle EdDSA, aggiornamento appcast.xml, git push e creazione della versione GitHub.
