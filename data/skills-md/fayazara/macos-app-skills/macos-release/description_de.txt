Veröffentlichen Sie eine native macOS-App auf GitHub mit DMG-Paketierung und Sparkle-Appcast-Updates. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine neue Version veröffentlichen, ein Release erstellen, ein Update versenden, ein Release an GitHub pushen oder den Appcast aktualisieren möchte. Wird auch ausgelöst, wenn der Benutzer DMG-Erstellung, Sparkle-Signierung, Beglaubigung, Archivierung oder alles andere im Zusammenhang mit der Verteilung einer neuen Version seiner macOS-App erwähnt. Dies deckt die gesamte Release-Pipeline ab: Archivieren, Beglaubigen, Exportieren, DMG erstellen, Signieren mit Sparkle EdDSA, Aktualisieren von appcast.xml, Git Push und GitHub-Release-Erstellung.
