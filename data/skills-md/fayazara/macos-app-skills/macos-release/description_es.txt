Lanza una aplicación macOS nativa en GitHub con paquetes DMG y actualizaciones de aplicaciones Sparkle. Utilice esta habilidad siempre que el usuario desee publicar una nueva versión, crear una versión, enviar una actualización, enviar una versión a GitHub o actualizar el appcast. También se activa cuando el usuario menciona la creación de DMG, la firma de Sparkle, la certificación notarial, el archivado o cualquier cosa relacionada con la distribución de una nueva versión de su aplicación macOS. Esto cubre todo el proceso de lanzamiento: archivar, certificar ante notario, exportar, crear DMG, firmar con Sparkle EdDSA, actualizar appcast.xml, git push y creación de lanzamientos en GitHub.
