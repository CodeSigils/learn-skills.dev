Выпустите собственное приложение macOS на GitHub с пакетом DMG и обновлениями приложения Sparkle. Используйте этот навык всякий раз, когда пользователь хочет опубликовать новую версию, создать выпуск, отправить обновление, отправить выпуск на GitHub или обновить приложение. Также срабатывает, когда пользователь упоминает создание DMG, подписание Sparkle, нотариальное заверение, архивирование или что-либо, связанное с распространением новой версии своего приложения для macOS. Это охватывает полный конвейер выпуска: архивирование, нотариальное заверение, экспорт, создание DMG, подписание с помощью Sparkle EdDSA, обновление appcast.xml, git push и создание выпуска GitHub.
