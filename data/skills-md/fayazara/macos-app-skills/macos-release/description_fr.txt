Publiez une application macOS native sur GitHub avec le packaging DMG et les mises à jour de l’appcast Sparkle. Utilisez cette compétence chaque fois que l'utilisateur souhaite publier une nouvelle version, créer une version, envoyer une mise à jour, envoyer une version vers GitHub ou mettre à jour l'appcast. Déclenchez également lorsque l'utilisateur mentionne la création DMG, la signature Sparkle, la notarisation, l'archivage ou tout ce qui concerne la distribution d'une nouvelle version de son application macOS. Cela couvre l'ensemble du pipeline de versions : archiver, légaliser, exporter, créer un DMG, signer avec Sparkle EdDSA, mettre à jour appcast.xml, git push et créer une version GitHub.
