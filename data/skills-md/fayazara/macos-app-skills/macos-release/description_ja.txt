DMG パッケージ化と Sparkle アプリキャストの更新を使用して、ネイティブ macOS アプリを GitHub にリリースします。ユーザーが新しいバージョンの公開、リリースの作成、アップデートの配布、GitHub へのリリースのプッシュ、またはアプリキャストの更新を行う場合は常に、このスキルを使用します。また、ユーザーが DMG の作成、Sparkle 署名、公証、アーカイブ、または macOS アプリの新しいバージョンの配布に関連するものに言及したときにもトリガーされます。これは、アーカイブ、公証、エクスポート、DMG の作成、Sparkle EdDSA による署名、appcast.xml の更新、git プッシュ、GitHub リリースの作成といった完全なリリース パイプラインをカバーしています。
