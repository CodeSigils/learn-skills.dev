أضف دعم التحديث التلقائي لـ Sparkle إلى تطبيق macOS الأصلي. استخدم هذه المهارة عندما يريد المستخدم إضافة تحديثات تلقائية، أو تنفيذ Sparkle، أو إعداد موجز بث التطبيق، أو إضافة "التحقق من وجود تحديثات" إلى تطبيقه، أو دمج التحقق التلقائي من التحديثات. يتم تشغيله أيضًا عندما يذكر المستخدم إشعارات Sparkle أو appcast أو SUFeedURL أو توقيع EdDSA أو التحديث. يغطي هذا الإعداد الكامل: إضافة تبعية Sparkle SPM، وإنشاء ملف UpdaterManager المفرد، وتوصيلها إلى مفوض التطبيق وواجهة المستخدم، وتكوين Info.plist، وإنشاء ملف appcast.xml الأولي.
