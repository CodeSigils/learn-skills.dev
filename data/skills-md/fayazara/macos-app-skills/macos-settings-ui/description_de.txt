Erstellen Sie ein ordnungsgemäßes macOS-Einstellungs-/Voreinstellungsfenster mit Flüssigglas-Unterstützung für macOS 26 (Tahoe). Verwenden Sie diesen Skill immer dann, wenn der Benutzer ein Einstellungsfenster, eine Benutzeroberfläche für Einstellungen, eine Einstellungsansicht oder einen Einstellungsbereich für eine macOS-App erstellen möchte. Wird auch ausgelöst, wenn der Benutzer „Flüssigglas-Einstellungen“, „NavigationSplitView-Einstellungen“, „Einstellungen für gruppierte Formulare“, „Layout der macOS-Einstellungen“ erwähnt oder einen Einstellungsbildschirm in einer nativen macOS SwiftUI-App hinzufügen/reparieren/neu erstellen möchte. Dazu gehören Sätze wie „Einstellungen zu meiner App hinzufügen“, „ein Einstellungsfenster erstellen“, „meine Einstellungen sehen falsch aus“, „die Benutzeroberfläche meiner Einstellungen korrigieren“ oder einfach nur „Ich benötige eine Einstellungsansicht“. Wenn der Benutzer eine macOS-App erstellt und Einstellungen oder Präferenzen in irgendeinem Kontext erwähnt, verwenden Sie diese Fähigkeit.
