أنشئ نافذة إعدادات/تفضيلات مناسبة لنظام التشغيل macOS مع دعم الزجاج السائل لنظام التشغيل macOS 26 (Tahoe). استخدم هذه المهارة عندما يطلب المستخدم إنشاء نافذة إعدادات أو واجهة مستخدم تفضيلات أو عرض إعدادات أو جزء تفضيلات لتطبيق macOS. يتم تشغيله أيضًا عندما يذكر المستخدم "إعدادات الزجاج السائل"، أو "إعدادات NavigationSplitView"، أو "إعدادات النماذج المجمعة"، أو "تخطيط إعدادات macOS"، أو يريد إضافة/إصلاح/إعادة إنشاء شاشة إعدادات في أي تطبيق macOS SwiftUI أصلي. يتضمن ذلك عبارات مثل "إضافة إعدادات إلى تطبيقي" أو "إنشاء نافذة تفضيلات" أو "تبدو إعداداتي خاطئة" أو "إصلاح واجهة مستخدم الإعدادات" أو حتى "أحتاج إلى عرض الإعدادات". إذا كان المستخدم يقوم بإنشاء تطبيق macOS وذكر الإعدادات أو التفضيلات في أي سياق، فاستخدم هذه المهارة.
