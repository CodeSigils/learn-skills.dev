macOS 26 (Tahoe) 用の液体ガラスをサポートする適切な macOS 設定/環境設定ウィンドウを構築します。ユーザーが macOS アプリの設定ウィンドウ、基本設定 UI、設定ビュー、または基本設定ペインの作成を要求するときは常に、このスキルを使用します。また、ユーザーが「液体ガラス設定」、「NavigationSplitView 設定」、「グループ化されたフォーム設定」、「macOS 設定レイアウト」に言及した場合、またはネイティブ macOS SwiftUI アプリで設定画面を追加/修正/再構築したい場合にもトリガーされます。これには、「アプリに設定を追加する」、「設定ウィンドウを作成する」、「設定が間違っているように見える」、「設定 UI を修正する」、または単に「設定ビューが必要」などのフレーズが含まれます。ユーザーが macOS アプリを構築していて、何らかのコンテキストで設定や環境設定について言及している場合は、このスキルを使用します。
