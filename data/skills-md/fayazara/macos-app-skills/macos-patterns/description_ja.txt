Web 開発者が知らない重要なネイティブ macOS 開発パターン。ユーザーが macOS アプリを構築していてネイティブ パターンに関するガイダンスが必要なとき、またはメニュー バー アプリ、フローティング パネル、ウィンドウ レベル、キーボード ショートカット、ファイル ピッカー、クリップボード、ドラッグ アンド ドロップ、画面キャプチャ、アクティベーション ポリシー、クイック ルック、ログイン時の起動、または macOS 固有の API について尋ねられるときは、必ずこのスキルを使用してください。また、ユーザーが Web 開発パターンを macOS に適用していると思われる場合にもトリガーされます (たとえば、Windows の z-index 思考を使用している、単純なクリップボード API を期待している、またはフォーカス/アクティベーションを理解していない)。これは、AI が自信を持って間違ったコードを生成するのを防ぐための「macOS 上で実際にどのように動作するか」に関するリファレンスです。ネイティブ macOS アプリを構築するときは常に、このスキルを積極的に使用してください。
