Modelli di sviluppo macOS nativi essenziali di cui gli sviluppatori web non sono a conoscenza. Utilizza questa competenza ogni volta che l'utente sta creando un'app macOS e ha bisogno di indicazioni sui modelli nativi o quando chiede informazioni su app della barra dei menu, pannelli mobili, livelli di finestra, scorciatoie da tastiera, selettori di file, appunti, trascinamento della selezione, acquisizione dello schermo, criteri di attivazione, Visualizzazione rapida, avvio all'accesso o qualsiasi API specifica di macOS. Si attivano anche quando l'utente sembra applicare modelli di sviluppo web a macOS (ad esempio, utilizzando il pensiero z-index per Windows, aspettandosi semplici API degli appunti o non comprendendo la messa a fuoco/attivazione). Questo è il riferimento "come funzionano effettivamente le cose su macOS" che impedisce all'intelligenza artificiale di generare codice sicuro ma sbagliato. Utilizza questa competenza in modo proattivo ogni volta che crei un'app macOS nativa.
