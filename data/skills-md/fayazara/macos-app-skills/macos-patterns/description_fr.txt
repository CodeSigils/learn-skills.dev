Modèles de développement macOS natifs essentiels que les développeurs Web ne connaissent pas. Utilisez cette compétence chaque fois que l'utilisateur crée une application macOS et a besoin de conseils sur les modèles natifs, ou lorsqu'il pose des questions sur les applications de la barre de menus, les panneaux flottants, les niveaux de fenêtre, les raccourcis clavier, les sélecteurs de fichiers, le presse-papiers, le glisser-déposer, la capture d'écran, la politique d'activation, l'aperçu rapide, le lancement à la connexion ou toute API spécifique à macOS. Se déclenche également lorsque l'utilisateur semble appliquer des modèles de développement Web à macOS (par exemple, en utilisant la réflexion z-index pour Windows, en s'attendant à de simples API de presse-papiers ou en ne comprenant pas le focus/l'activation). Il s'agit de la référence « comment les choses fonctionnent réellement sur macOS » qui empêche l'IA de générer un code sûr mais erroné. Utilisez cette compétence de manière proactive lors de la création d’une application macOS native.
