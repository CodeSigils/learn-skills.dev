Wesentliche native macOS-Entwicklungsmuster, die Webentwickler nicht kennen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine macOS-App erstellt und Anleitung zu nativen Mustern benötigt oder wenn er nach Menüleisten-Apps, schwebenden Panels, Fensterebenen, Tastaturkürzeln, Dateiauswahl, Zwischenablage, Drag & Drop, Bildschirmaufnahme, Aktivierungsrichtlinie, Quick Look, Start bei Anmeldung oder einer beliebigen macOS-spezifischen API fragt. Wird auch ausgelöst, wenn der Benutzer scheinbar Webentwicklungsmuster auf macOS anwendet (z. B. Z-Index-Denken für Windows verwendet, einfache Zwischenablage-APIs erwartet oder Fokus/Aktivierung nicht versteht). Dies ist die Referenz „Wie die Dinge tatsächlich unter macOS funktionieren“, die verhindert, dass die KI sicheren, aber falschen Code generiert. Nutzen Sie diese Fähigkeit proaktiv, wenn Sie eine native macOS-App erstellen.
