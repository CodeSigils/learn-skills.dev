Patrones de desarrollo nativos esenciales de macOS que los desarrolladores web desconocen. Utilice esta habilidad siempre que el usuario esté creando una aplicación macOS y necesite orientación sobre patrones nativos, o cuando pregunte sobre aplicaciones de barra de menú, paneles flotantes, niveles de ventanas, atajos de teclado, selectores de archivos, portapapeles, arrastrar y soltar, captura de pantalla, política de activación, Vista rápida, inicio al iniciar sesión o cualquier API específica de macOS. También se activa cuando el usuario parece estar aplicando patrones de desarrollo web a macOS (por ejemplo, usando el pensamiento de índice z para Windows, esperando API de portapapeles simples o no entendiendo el enfoque/activación). Esta es la referencia "cómo funcionan realmente las cosas en macOS" que evita que la IA genere código confiable pero incorrecto. Utilice esta habilidad de forma proactiva siempre que cree cualquier aplicación nativa de macOS.
