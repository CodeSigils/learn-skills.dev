Основные шаблоны разработки для macOS, о которых веб-разработчики не знают. Используйте этот навык всякий раз, когда пользователь создает приложение для macOS и нуждается в руководстве по собственным шаблонам, или когда он спрашивает о приложениях в строке меню, плавающих панелях, уровнях окон, сочетаниях клавиш, средствах выбора файлов, буфере обмена, перетаскивании, захвате экрана, политике активации, быстром просмотре, запуске при входе в систему или любом API, специфичном для macOS. Также срабатывает, когда пользователь применяет шаблоны веб-разработки к macOS (например, использует z-index для Windows, ожидает простых API-интерфейсов буфера обмена или не понимает фокус/активацию). Это справочник «как на самом деле все работает в macOS», который не позволяет ИИ генерировать уверенный, но неправильный код. Активно используйте этот навык при создании любого собственного приложения для macOS.
