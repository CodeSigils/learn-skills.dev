Créez une application macOS native à l'aide de xcodebuild à partir de la ligne de commande. Utilisez cette compétence chaque fois que l'utilisateur demande à créer, compiler ou vérifier si son projet macOS se compile correctement. Utilisez-le également lorsque l'utilisateur demande de corriger les erreurs de build, de vérifier la compilation des modifications ou d'exécuter une build de débogage. Déclenchez des expressions telles que "créer l'application", "est-ce qu'elle compile", "exécuter xcodebuild", "corriger les erreurs de construction" ou même simplement "construire".
