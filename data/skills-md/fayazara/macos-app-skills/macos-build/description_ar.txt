قم بإنشاء تطبيق macOS أصلي باستخدام xcodebuild من سطر الأوامر. استخدم هذه المهارة عندما يطلب المستخدم إنشاء مشروع macOS الخاص به أو تجميعه أو التحقق من نجاحه. استخدمه أيضًا عندما يطلب المستخدم إصلاح أخطاء البناء، أو التحقق من ترجمة التغييرات، أو تشغيل بناء تصحيح الأخطاء. قم بتشغيل عبارات مثل "إنشاء التطبيق"، أو "هل يتم تجميعه"، أو "تشغيل xcodebuild"، أو "إصلاح أخطاء البناء"، أو حتى "إنشاء" فقط.
