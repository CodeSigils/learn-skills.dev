Erstellen Sie eine native macOS-App mit xcodebuild über die Befehlszeile. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer sein macOS-Projekt erstellen, kompilieren oder überprüfen möchte, ob es erfolgreich kompiliert werden soll. Verwenden Sie es auch, wenn der Benutzer Build-Fehler beheben, Änderungen bei der Kompilierung überprüfen oder einen Debug-Build ausführen möchte. Triggern Sie auf Phrasen wie „App erstellen“, „Kompiliert sie“, „xcodebuild ausführen“, „Build-Fehler beheben“ oder einfach nur „Build“.
