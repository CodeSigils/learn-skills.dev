Навык генератора строительных лесов. Используйте, когда пользователь хочет создать новый навык агента (разработать описание, определить структуру каталогов, сгенерировать файлы, использовать тонкую оболочку с несколькими инструментами, проверить доставку) или отдельно разработать описание навыка/проверить существующий навык. Следуйте трем элементам (подсказка/контекст/обвязка) + строгое разделение каталогов + совместимость между инструментами (CLAUDE.md/GEMINI.md/AGENTS.md). Триггерные слова: создать навык, сгенерировать навык, написать навык, генератор навыков, фабрика навыков, создать навык, матрица навыков, описание дизайна, подтвердить навык.
