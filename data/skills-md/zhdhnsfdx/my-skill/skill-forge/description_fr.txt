Générateur d'échafaudages de compétences. À utiliser lorsque l'utilisateur souhaite créer une nouvelle compétence d'agent (concevoir une description, décider de la structure des répertoires, générer des fichiers, une coque légère multi-outils, valider la livraison) ou concevoir la description d'une compétence séparément/valider une compétence existante. Suivez les trois éléments (Invite/Contexte/Harness)+séparation stricte des répertoires+compatibilité entre outils (CLAUDE.md/GEMINI.md/AGENTS.md). Mots déclencheurs : créer une compétence, générer une compétence, écrire une compétence, générateur de compétences, usine de compétences, créer une compétence, échafaudage de compétences, description de conception, valider une compétence
