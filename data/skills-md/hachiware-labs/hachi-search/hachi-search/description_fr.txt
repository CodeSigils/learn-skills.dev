Recherche fédérée orientée LLM local dans les dossiers locaux spécifiés, connaissances facultatives hachiware-labs/wiki-garden, fournisseurs de recherche Web et enrichissement d'URL. À utiliser lorsqu'un LLM local ou un agent local a besoin de preuves attribuées à la source à partir de fichiers de projet, de documents locaux, de notes de wiki-garden ou du Web avec une sélection de source configurable, une récupération de contenu d'URL, un ordre de recherche et une fusion de résultats.
