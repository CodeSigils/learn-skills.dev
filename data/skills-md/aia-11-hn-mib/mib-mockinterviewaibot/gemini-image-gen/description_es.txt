Guía para implementar la generación de imágenes de la API de Google Gemini: cree imágenes de alta calidad a partir de mensajes de texto utilizando el modelo de imagen flash gemini-2.5. Úselo al generar imágenes, crear contenido visual o implementar funciones de conversión de texto a imagen. Admite conversión de texto a imagen, edición de imágenes, composición de múltiples imágenes y refinamiento iterativo.
