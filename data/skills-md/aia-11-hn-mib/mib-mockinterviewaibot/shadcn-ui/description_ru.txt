Руководство по реализации shadcn/ui — коллекции красиво оформленных и доступных компонентов пользовательского интерфейса, созданных с помощью Radix UI и Tailwind CSS. Используйте при создании пользовательских интерфейсов, добавлении компонентов пользовательского интерфейса или реализации систем проектирования в приложениях на основе React.
