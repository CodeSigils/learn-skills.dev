دليل لتنفيذ Google Cloud SDK (gcloud CLI) - أداة سطر أوامر لإدارة موارد Google Cloud. يُستخدم عند تثبيت/تكوين gcloud، أو المصادقة مع Google Cloud، أو إدارة المشاريع/التكوينات، أو نشر التطبيقات، أو العمل مع Compute Engine/GKE/App Engine/Cloud Storage، أو البرمجة النصية لعمليات gcloud، أو تنفيذ خطوط أنابيب CI/CD، أو استكشاف أخطاء عمليات نشر Google Cloud وإصلاحها.
