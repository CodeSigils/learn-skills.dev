Esta habilidad debe usarse al sembrar bases de datos con datos falsos realistas para entornos de desarrollo, pruebas o preparación. Admite PostgreSQL, MySQL, SQLite, MongoDB con siembra basada en ORM (SQLAlchemy, Django, Prisma) y biblioteca Faker para generar datos de prueba realistas. Úselo cuando el usuario necesite completar bases de datos con datos de muestra, crear dispositivos de prueba o configurar entornos de desarrollo/puesta en escena con datos realistas.
