Questa competenza dovrebbe essere utilizzata quando si seminano database con dati falsi realistici per ambienti di sviluppo, test o gestione temporanea. Supporta PostgreSQL, MySQL, SQLite, MongoDB con seeding basato su ORM (SQLAlchemy, Django, Prisma) e la libreria Faker per generare dati di test realistici. Da utilizzare quando l'utente ha bisogno di popolare i database con dati campione, creare dispositivi di test o impostare ambienti di sviluppo/staging con dati realistici.
