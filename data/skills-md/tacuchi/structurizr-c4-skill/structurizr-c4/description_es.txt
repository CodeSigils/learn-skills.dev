Genere, valide y vea diagramas de arquitectura de software C4 como código con Structurizr DSL (la implementación de referencia de C4), localmente y sin Docker. Úselo cuando el usuario desee crear, actualizar o revisar diagramas de arquitectura (modelo C4: contexto del sistema, contenedor, componente, implementación, dinámico), escribir o corregir un espacio de trabajo Structurizr.dsl, exportar diagramas a Mermaid/PlantUML/C4-PlantUML o ejecutar un visor de diagramas local. Activadores: "C4", "Structurizr", "diagrama de arquitectura", "diagrama de arquitectura", "workspace.dsl", "diagramas como código". Requiere Java 21 y la CLI strz incluida, que crea automáticamente Structurizr vNext desde el código fuente.
