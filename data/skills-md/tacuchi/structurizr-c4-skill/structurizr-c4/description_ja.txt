Docker を使用せずに、Structurizr DSL (C4 リファレンス実装) を使用してコードとして C4 ソフトウェア アーキテクチャ図を生成、検証、表示します。ユーザーがアーキテクチャ ダイアグラム (C4 モデル - システム コンテキスト、コンテナ、コンポーネント、デプロイ、動的) を作成、更新、またはレビューする場合、Structurizr workspace.dsl を作成または修正する場合、ダイアグラムを Mermaid/PlantUML/C4-PlantUML にエクスポートする場合、またはローカル ダイアグラム ビューアを実行する場合に使用します。トリガー - 「C4」、「Structurizr」、「アーキテクチャ図」、「アーキテクチャ図」、「workspace.dsl」、「コードとしての図」。 Java 21 と、ソースから Structurizr vNext を自動ビルドするバンドルされた strz CLI が必要です。
