قم بإنشاء مخططات بنية برامج C4 والتحقق من صحتها وعرضها كرمز باستخدام Structurizr DSL (التنفيذ المرجعي لـ C4)، محليًا وبدون Docker. يُستخدم عندما يريد المستخدم إنشاء مخططات بنية أو تحديثها أو مراجعتها (نموذج C4 - سياق النظام، الحاوية، المكون، النشر، الديناميكي)، أو كتابة أو إصلاح Structurizr Workspace.dsl، أو تصدير المخططات إلى Mermaid/PlantUML/C4-PlantUML، أو تشغيل عارض مخطط محلي. المشغلات - "C4"، "Structurizr"، "مخطط معماري"، "diagrama de arquitectura"، "workspace.dsl"، "المخططات كرمز". يتطلب Java 21 وstrz CLI المجمعة، والتي تقوم بالإنشاء التلقائي لـ Structurizr vNext من المصدر.
