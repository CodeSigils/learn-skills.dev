Generieren, validieren und zeigen Sie C4-Softwarearchitekturdiagramme als Code mit Structurizr DSL (der C4-Referenzimplementierung) an, lokal und ohne Docker. Verwenden Sie diese Option, wenn der Benutzer Architekturdiagramme (C4-Modell – Systemkontext, Container, Komponente, Bereitstellung, dynamisch) erstellen, aktualisieren oder überprüfen, eine Structurizr workspace.dsl schreiben oder korrigieren, Diagramme nach Mermaid/PlantUML/C4-PlantUML exportieren oder einen lokalen Diagramm-Viewer ausführen möchte. Auslöser – „C4“, „Structurizr“, „Architekturdiagramm“, „Diagrama de Arquitectura“, „workspace.dsl“, „Diagramme als Code“. Erfordert Java 21 und die gebündelte strz-CLI, die Structurizr vNext automatisch aus der Quelle erstellt.
