Docker 없이 로컬에서 Structurizr DSL(C4 참조 구현)을 사용하여 C4 소프트웨어 아키텍처 다이어그램을 코드로 생성, 검증 및 확인합니다. 사용자가 아키텍처 다이어그램(C4 모델 - 시스템 컨텍스트, 컨테이너, 구성 요소, 배포, 동적)을 생성, 업데이트 또는 검토하고, Structurizr 작업 공간.dsl을 작성 또는 수정하고, 다이어그램을 Mermaid/PlantUML/C4-PlantUML로 내보내거나, 로컬 다이어그램 뷰어를 실행하려는 경우에 사용합니다. 트리거 - "C4", "Structurizr", "아키텍처 다이어그램", "diagrama de arquitectura", "workspace.dsl", "diagrams as code". 소스에서 Structurizr vNext를 자동 빌드하는 Java 21 및 번들 strz CLI가 필요합니다.
