مرجع URL المركزي للمساعدة لمعالجة إمكانية الوصول. يقوم بتعيين معرفات القواعد الأساسية للمحور إلى صفحات أمثلة معلومات Accessibility Insights، ومعرفات قواعد المستندات إلى صفحات تعليمات Microsoft Office وAdobe PDF، ومعايير WCAG إلى مستندات فهم W3C. يُستخدم عند إنشاء عمليات تصدير بتنسيق CSV أو تقارير تخفيض السعر أو أي مخرجات تربط النتائج بوثائق المعالجة الخارجية.
