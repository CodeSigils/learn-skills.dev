Централизованная ссылка на URL-адрес справки для устранения проблем с доступностью. Сопоставляет идентификаторы правил Axe-Core со страницами информационных примеров Accessibility Insights, идентификаторы правил документов со страницами справки Microsoft Office и Adobe PDF, а критерии WCAG с документами W3C понимания. Используйте при создании экспорта CSV, отчетов об уценке или любых выходных данных, которые связывают результаты с внешней документацией по исправлению.
