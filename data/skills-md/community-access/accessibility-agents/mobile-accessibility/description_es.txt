Datos de referencia de accesibilidad móvil para auditoría de React Native, Expo, iOS y Android. Cubre la etiqueta de accesibilidad, el rol de accesibilidad, la sugerencia de accesibilidad, los tamaños de los objetivos táctiles (mínimo 44 x 44 puntos), la compatibilidad con lectores de pantalla y la semántica específica de la plataforma. Úselo al revisar cualquier código móvil nativo o React Native para verificar su accesibilidad.
