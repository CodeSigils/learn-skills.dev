Datos de referencia de accesibilidad móvil para auditoría de React Native, Expo, iOS y Android. Cubre etiqueta de accesibilidad, función de accesibilidad, sugerencia de accesibilidad, tamaños de destino táctil (mínimo 44 x 44 puntos), compatibilidad con lectores de pantalla y semántica específica de la plataforma. Úselo al revisar cualquier código móvil nativo o React Native para verificar su accesibilidad.
