البيانات المرجعية لإمكانية الوصول عبر الهاتف المحمول لتدقيق React Native وExpo وiOS وAndroid. يغطي تسمية إمكانية الوصول، ودور إمكانية الوصول، وتلميح إمكانية الوصول، وأحجام أهداف اللمس (44 × 44 نقطة كحد أدنى)، وتوافق قارئ الشاشة، والدلالات الخاصة بالنظام الأساسي. استخدمه عند مراجعة أي كود React Native أو كود جوال أصلي لسهولة الوصول إليه.
