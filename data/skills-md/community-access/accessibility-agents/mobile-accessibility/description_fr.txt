Données de référence sur l'accessibilité mobile pour l'audit React Native, Expo, iOS et Android. Couvre l'accessibilitéLabel, l'accessibilitéRole, l'accessibilitéHint, les tailles des cibles tactiles (44 x 44 pt minimum), la compatibilité des lecteurs d'écran et la sémantique spécifique à la plate-forme. À utiliser lors de la révision de tout code mobile React Native ou natif pour l'accessibilité.
