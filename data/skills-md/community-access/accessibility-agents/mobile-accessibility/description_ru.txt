Справочные данные о доступности мобильных устройств для аудита React Native, Expo, iOS и Android. Охватывает accessibilityLabel, accessibilityRole, accessibilityHint, размеры сенсорных целей (минимум 44x44pt), совместимость средств чтения с экрана и семантику, специфичную для платформы. Используйте при проверке любого React Native или собственного мобильного кода на предмет доступности.
