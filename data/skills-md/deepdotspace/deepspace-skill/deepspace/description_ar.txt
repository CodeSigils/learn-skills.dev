يُستخدم عند إنشاء تطبيقات تعاونية في الوقت الفعلي أو صيانتها باستخدام DeepSpace SDK على Cloudflare Workers - لدعم التطبيقات الجديدة وإضافة ميزات وتصحيح أخطاء `worker.ts` الذي يستورد من `deepspace` / `deepspace/worker` أو يستخدم `RecordRoom` أو `__DO_MANIFEST__` أو `npx Deepspace`. استخدمه أيضًا عندما يذكر المستخدم DeepSpace أو app.space، أو يطلب أي شيء يتضمن المزامنة في الوقت الفعلي، أو حالة تعدد اللاعبين، أو المؤشرات المباشرة/التواجد، أو لوحات المعلومات أو اللوحات القماشية، أو التحرير التعاوني للنص (Yjs)، أو الدردشة القائمة على القناة، أو أذونات كل دور (RBAC)، أو غرف الكائنات الدائمة، أو الاشتراكات المدعومة بالشريط / جدران الاشتراك غير المدفوع / المنتجات لمرة واحدة / النصائح / المبالغ المستردة، أو نشر حزمة واحدة إلى `.app.space` - حتى لو كانوا لا تذكر اسم DeepSpace بشكل صريح.
