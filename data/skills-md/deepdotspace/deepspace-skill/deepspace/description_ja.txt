Cloudflare Workers 上の DeepSpace SDK を使用してリアルタイムの共同作業アプリを構築または保守するときに使用します。新しいアプリのスキャフォールディング、機能の追加、「deepspace」/「deepspace/worker」からインポートする「worker.ts」のデバッグ、または「RecordRoom」、「__DO_MANIFEST__」、または「npx deepspace」を使用します。また、ユーザーが DeepSpace または app.space について言及したり、リアルタイム同期、マルチプレイヤー状態、ライブ カーソル / プレゼンス、ホワイトボードまたはキャンバス、共同テキスト編集 (Yjs)、チャネル ベースのチャット、ロールごとの権限 (RBAC)、デュラブル オブジェクト ルーム、Stripe ベースのサブスクリプション / ペイウォール / ワンタイム製品 / ヒント / 返金、または `.app.space` へのワンパッケージ デプロイに関連するものを要求した場合にも使用します (名前を付けていない場合でも)。 DeepSpace を明示的に指定します。
