يقوم بتشفير اصطلاحات التزام git الخاصة بالمستخدم (الالتزامات التقليدية بعنوان قصير ونص نقطي موجز، والالتزامات الذرية التي تتم فقط عند اكتمال التغيير المنطقي). يُستخدم عند كتابة رسائل التزام، أو تنظيم التغييرات أو تنفيذها، أو سحقها، أو عندما يُطلب منك "تنفيذ هذا"، أو "كتابة رسالة التزام"، أو "إجراء التزام".
