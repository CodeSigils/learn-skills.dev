Соглашения по созданию и поддержке рабочих процессов GitHub Actions. Прикрепите каждое действие к его последней версии, прочтите версию Node из .node-version (в противном случае — последнюю версию LTS) и настройте pnpm с помощью действия setup-pnpm вместо corepack. Используйте при создании рабочего процесса, добавлении или редактировании заданий или шагов или обновлении версий действий в существующем рабочем процессе.
