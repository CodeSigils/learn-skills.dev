Konventionen zum Erstellen und Verwalten von GitHub Actions-Workflows. Hängen Sie jede Aktion an ihre neueste Version an, lesen Sie die Node-Version aus .node-version (ansonsten neuestes LTS) und richten Sie pnpm über die Aktion setup-pnpm anstelle von corepack ein. Verwenden Sie diese Option, wenn Sie einen Workflow erstellen, Jobs oder Schritte hinzufügen oder bearbeiten oder Aktionsversionen in einem vorhandenen Workflow aktualisieren.
