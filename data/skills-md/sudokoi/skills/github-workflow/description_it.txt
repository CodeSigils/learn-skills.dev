Convenzioni per la creazione e la manutenzione dei flussi di lavoro di GitHub Actions. Fissa ciascuna azione alla versione più recente, leggi la versione del nodo da .node-version (altrimenti l'ultima LTS) e configura pnpm tramite l'azione setup-pnpm anziché corepack. Da utilizzare durante la creazione di un flusso di lavoro, l'aggiunta o la modifica di processi o passaggi o l'aggiornamento delle versioni delle azioni in un flusso di lavoro esistente.
