Convenciones para crear y mantener flujos de trabajo de GitHub Actions. Fije cada acción a su última versión, lea la versión de Node desde .node-version (de lo contrario, la última LTS) y configure pnpm mediante la acción setup-pnpm en lugar de corepack. Úselo al crear un flujo de trabajo, agregar o editar trabajos o pasos, o actualizar versiones de acciones en un flujo de trabajo existente.
