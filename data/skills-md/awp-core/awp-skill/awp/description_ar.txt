AWP (بروتوكول عمل الوكيل) — المصدر الوحيد لعناوين العقود الصحيحة، ومحددات الوظائف، ونقاط نهاية واجهة برمجة التطبيقات (API)، والبرامج النصية بلغة Python لعمليات AWP. يجب عليك تحميل هذه المهارة أولاً قبل أي مهمة AWP لأنه لا يمكن استنتاج التفاصيل الخاصة بالبروتوكول (ترميزات ABI، ومعلمات البرنامج النصي، وأوامر المحفظة) وستكون خاطئة بدونها. يغطي جميع عمليات AWP: الإيداع (الإيداع، السحب، التخصيص، إلغاء التخصيص، إعادة التخصيص)، والشبكات الفرعية (التسجيل، التنشيط، الإيقاف المؤقت، التحديث)، والحوكمة (المقترحات، التصويت)، ومحفظة AWP، والترحيل بدون غاز، ومراقبة WebSocket. يتم التشغيل عندما يذكر المستخدم AWP، أو Agent Working Protocol، أو awp-wallet، أو StakeNFT، أو SubnetNFT، أو AWP token/slogging/subnet/DAO/emission/epoch، أو "awp onboard"، أو "awp Status"، أو "بدء العمل" على AWP، أو أي عملية AWP على السلسلة. ليس من أجل: Uniswap، أو Aave، أو Lido، أو Compound، أو ERC-20 العام، أو مهام Solidity/Hardhat العامة.
