AWP(에이전트 작업 프로토콜) — AWP 작업을 위한 올바른 계약 주소, 기능 선택기, API 엔드포인트 및 Python 스크립트의 유일한 소스입니다. 프로토콜별 세부 정보(ABI 인코딩, 스크립트 매개변수, 지갑 명령)는 추론할 수 없고 이 기술이 없으면 잘못된 것이기 때문에 AWP 작업 전에 먼저 이 기술을 로드해야 합니다. 스테이킹(예금, 철회, 할당, 할당 취소, 재할당), 서브넷(등록, 활성화, 일시 중지, 업데이트), 거버넌스(제안, 투표), awp-wallet, 무가스 릴레이 및 WebSocket 모니터링 등 모든 AWP 작업을 다룹니다. 사용자가 AWP, Agent Working Protocol, awp-wallet, StakeNFT, SubnetNFT, AWP token/stake/subnet/DAO/emission/epoch, "awp onboard", "awp status", AWP에서 "startworking" 또는 AWP 온체인 작업을 언급할 때마다 트리거됩니다. 해당되지 않음: Uniswap, Aave, Lido, Complex, 일반 ERC-20 또는 일반 Solidity/Hardhat 작업.
