Общий набор инструментов для создания отдельных эталонных изображений (привязок) и последовательностей ключевых кадров с помощью flux2 i2i/i2i2/multi-reference. Используйте, когда любой конвейер — музыкальное видео, драматическое видео, одноразовый рендеринг — требует привязки к конкретной сцене, листа позы персонажа или первого/последнего ключевых кадров для перехода. Предоставляет CLI `generate_anchor` + руководство по подсказкам, которое оператор должен просмотреть перед написанием подсказок. Все якоря производственного качества в этом развертывании проходят этот навык.
