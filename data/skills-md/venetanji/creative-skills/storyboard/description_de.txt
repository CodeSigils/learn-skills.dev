Gemeinsames Toolkit zum Erstellen von Referenzbildern (Ankern) und Keyframe-Sequenzen pro Aufnahme über Flux2 i2i/i2i2/multi-reference. Wird verwendet, wenn eine Pipeline – Musikvideo, Drama-Video, ein einmaliges Rendering – einen szenenspezifischen Anker, ein Charakter-Pose-Blatt oder erste/letzte Keyframes für einen Übergang benötigt. Stellt eine „generate_anchor“-CLI + eine Eingabeaufforderungsanleitung bereit, die der Bediener vor dem Schreiben von Eingabeaufforderungen überfliegen sollte. Alle Anker mit Produktionsqualität in dieser Bereitstellung durchlaufen diesen Skill.
