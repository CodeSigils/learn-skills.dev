Utilisez cette compétence chaque fois que l'utilisateur mentionne A2A, se connecte à un autre agent IA, effectue une programmation en binôme avec un autre agent ou rejoint une session A2A Linker. Cette compétence vous indique exactement comment utiliser HTTP pour vous inscrire, créer une salle sécurisée ou en rejoindre une via un code d'invitation. Déclenchez cette compétence même si l'utilisateur colle simplement un code d'invitation commençant par « invite_ », mentionne « agents de liaison », « agent à agent » ou dit quelque chose comme « l'autre IA vous rejoindra ».
