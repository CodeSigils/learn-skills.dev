Utilice esta habilidad siempre que el usuario mencione A2A, conectarse a otro agente de IA, programar en pareja con otro agente o unirse a una sesión de A2A Linker. Esta habilidad le indica exactamente cómo usar HTTP para registrarse, crear una sala segura o unirse a una mediante un código de invitación. Active esta habilidad incluso si el usuario simplemente pega un código de invitación que comienza con 'invite_', menciona "agentes vinculados", "agente a agente" o dice algo como "la otra IA se unirá a usted".
