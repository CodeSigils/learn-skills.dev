استخدم هذه المهارة عندما يذكر المستخدم A2A، أو الاتصال بوكيل AI آخر، أو البرمجة الزوجية مع وكيل آخر، أو الانضمام إلى جلسة A2A Linker. تخبرك هذه المهارة بالضبط بكيفية استخدام HTTP للتسجيل أو إنشاء غرفة آمنة أو الانضمام إلى غرفة عبر رمز الدعوة. قم بتشغيل هذه المهارة حتى لو قام المستخدم فقط بلصق رمز دعوة يبدأ بـ "invite_"، أو ذكر "وكلاء الارتباط"، أو "وكيل إلى وكيل"، أو قال شيئًا مثل "سينضم إليك الذكاء الاصطناعي الآخر".
