أنماط واتفاقيات تحسين محركات البحث لتطبيقات الويب. يُستخدم عند تنفيذ العلامات الوصفية، أو البيانات المنظمة، أو مؤشرات أداء الويب الأساسية، أو خرائط الموقع، أو الرسم البياني المفتوح، أو تحسين الصفحات لمحركات البحث. يتم تشغيلها على المهام التي تتضمن تحسين محركات البحث، أو تحسين البحث، أو ترميز المخطط، أو العلامات الوصفية للمشاركة الاجتماعية.
