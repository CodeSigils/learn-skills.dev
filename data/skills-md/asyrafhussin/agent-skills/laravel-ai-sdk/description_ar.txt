Laravel AI SDK لبناء ميزات مدعومة بالذكاء الاصطناعي. يُستخدم عند إنشاء الوكلاء، أو إنشاء الصور أو الصوت، أو العمل مع التضمينات، أو البحث عن المتجهات، أو اختبار ميزات الذكاء الاصطناعي. يتم تشغيلها في المهام التي تتضمن laravel/ai، أو وكلاء الذكاء الاصطناعي، أو استدعاء الأدوات، أو المخرجات المنظمة، أو التدفق، أو التضمين، أو إعادة الترتيب، أو تزييف الذكاء الاصطناعي في الاختبارات.
