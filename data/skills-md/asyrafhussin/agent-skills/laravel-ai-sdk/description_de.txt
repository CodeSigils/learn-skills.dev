Laravel AI SDK zum Erstellen KI-gestützter Funktionen. Verwenden Sie es beim Erstellen von Agenten, beim Generieren von Bildern oder Audio, beim Arbeiten mit Einbettungen, bei der Vektorsuche oder beim Testen von KI-Funktionen. Wird bei Aufgaben ausgelöst, die Laravel/KI, KI-Agenten, Tool-Aufrufe, strukturierte Ausgabe, Streaming, Einbettungen, Neuranking oder KI-Fälschungen in Tests umfassen.
