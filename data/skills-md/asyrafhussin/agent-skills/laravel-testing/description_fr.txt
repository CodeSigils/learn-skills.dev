Tests Laravel 13 avec Pest PHP 4 ou PHPUnit 12. À utiliser lors de l'écriture de tests de fonctionnalités, de tests unitaires ou de tout code de test dans une application Laravel. Se déclenche sur des tâches impliquant des tests HTTP, des fabriques de modèles, des assertions de base de données, des façades moqueuses, des tests d'authentification ou des modèles d'organisation de test.
