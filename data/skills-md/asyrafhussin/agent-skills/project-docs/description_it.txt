Ciclo di vita della documentazione del progetto per progetti PHP/Laravel e Node/TypeScript/React: bootstrap di documenti essenziali, convenzioni di denominazione e cartella, aggiornamento e pulizia di file spazzatura e obsoleti generati dall'intelligenza artificiale. Da utilizzare quando si avvia un nuovo progetto, si impostano documenti/struttura, si controllano i file di markdown, si pulisce la cartella dei documenti o si decide quali documenti conservare, archiviare o eliminare. Si attiva su "imposta documenti", "controlla documenti", "ripulisci markdown", "di quali documenti ha bisogno questo progetto", "organizza la cartella dei documenti", "trova documenti obsoleti".
