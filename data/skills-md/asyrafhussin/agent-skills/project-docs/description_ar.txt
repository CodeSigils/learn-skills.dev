دورة حياة وثائق المشروع لمشاريع PHP/Laravel وNode/TypeScript/React - تمهيد المستندات الأساسية، واصطلاحات التسمية والمجلدات، والحداثة، وتنظيف الملفات غير المرغوب فيها والقديمة التي تم إنشاؤها بواسطة الذكاء الاصطناعي. يُستخدم عند بدء مشروع جديد، أو إعداد المستندات/البنية، أو تدقيق ملفات تخفيض السعر، أو تنظيف مجلد المستندات، أو تحديد المستندات التي سيتم الاحتفاظ بها أو أرشفتها أو حذفها. مشغلات على "إعداد المستندات"، و"تدقيق المستندات"، و"تنظيف تخفيض السعر"، و"ما المستندات التي يحتاجها هذا المشروع"، و"تنظيم مجلد المستندات"، و"العثور على المستندات القديمة".
