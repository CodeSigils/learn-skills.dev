جرد الديون الفنية وتحديد الأولويات والتدقيق لمشاريع PHP/Laravel (MySQL) وNode/TypeScript/React. يُستخدم عند تقييم صحة التعليمات البرمجية، أو تحديد المرشحين لإعادة البناء، أو التخطيط لسداد الديون، أو مراجعة قاعدة التعليمات البرمجية للديون المتراكمة. مشغلات على "تدقيق الديون الفنية"، أو "العثور على الديون التقنية"، أو "جرد الديون"، أو "ما الذي يجب أن نعيد هيكلته أولاً"، أو المهام التي تتضمن صحة التعليمات البرمجية، أو الديون الأمنية، أو ديون الأداء، أو ديون البيانات، أو ديون القابلية للملاحظة، أو تحديد أولويات الديون، أو تخطيط الإصلاح.
