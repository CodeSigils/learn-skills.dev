Обнаружение шаблонов кода, сгенерированных ИИ («отбросы») в исходных текстах PHP/Laravel и TypeScript/React — комментарии в комментариях, общие имена, преждевременные интерфейсы, защитная передозировка, имитационные тесты и отсутствие человеческих «шрамов». Используйте при проверке PR с помощью ИИ, проверке кода на вкус/качество (не показатели — это технический долг) или при уточнении контрольного списка проверки кода. Триггеры по «проверке ошибок ИИ», «нахождению шаблонов ИИ», «проверке кода на человечность», «проверке качества кода».
