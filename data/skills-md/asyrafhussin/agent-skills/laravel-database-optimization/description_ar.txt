أنماط تحسين قاعدة بيانات Laravel يُستخدم عند كتابة استعلامات Eloquent، أو إنشاء عمليات الترحيل، أو تكوين التخزين المؤقت، أو تصحيح أخطاء الاستعلامات البطيئة، أو تحسين أداء قاعدة البيانات. يتم تشغيلها على المهام التي تتضمن استعلامات N+1، أو الفهرسة، أو التخزين المؤقت لـ Redis، أو ترقيم الصفحات، أو معاملات قاعدة البيانات.
