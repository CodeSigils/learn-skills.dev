Шаблоны оптимизации базы данных Laravel. Используйте при написании запросов Eloquent, создании миграций, настройке кэширования, отладке медленных запросов или оптимизации производительности базы данных. Запускается при выполнении задач, включающих запросы N+1, индексирование, кэширование Redis, разбиение на страницы или транзакции базы данных.
