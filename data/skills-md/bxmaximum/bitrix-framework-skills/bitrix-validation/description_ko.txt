Bitrix의 입력 데이터 유효성 검사 — ValidationService(main.validation.service), 속성 #[NotEmpty], #[Email], #[Length], #[Range], #[RegExp], #[InArray], ValidationParameter autowire를 통한 DTO 요청, 컨트롤러 작업 매개 변수의 규칙 속성, AbstractPropertyValidationAttribute + ValidatorInterface를 통한 사용자 지정 유효성 검사기, ErrorCollection의 오류 집계를 다룹니다. 컨트롤러, 서비스 및 CLI 명령 입력, 양식 유효성 검사, DTO 및 작업 메서드 매개 변수를 확인할 때 적용됩니다. 주요 용어 — ValidationService, NotEmpty, 이메일, 길이, ValidationParameter, 요청 DTO, 유효성 검사기, 제약 조건.
