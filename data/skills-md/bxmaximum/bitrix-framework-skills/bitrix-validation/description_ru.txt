Охватывает проверку входных данных в Битрикс — ValidationService (main.validation.service), атрибуты #[NotEmpty], #[Email], #[Length], #[Range], #[RegExp], #[InArray], Request DTO через автопроводку ValidationParameter, атрибуты правил для параметров действий контроллера, пользовательские валидаторы через AbstractPropertyValidationAttribute + ValidatorInterface, агрегацию ошибок в Коллекция ошибок. Применяется при проверке ввода контроллеров, служб и команд CLI, проверке форм, DTO и параметров метода действия. Ключевые термины — ValidationService, NotEmpty, Email, Длина, ValidationParameter, Request DTO, валидатор, ограничение.
