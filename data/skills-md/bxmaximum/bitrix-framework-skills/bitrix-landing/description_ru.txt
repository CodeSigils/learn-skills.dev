Модуль Covers Landing — сайты/лендинги, репозиторий блоков, поток публикации/отмены публикации, хуки (Метрика/GA/пиксели), ограничения настройки по сравнению с классической CMS. Применяется для Сайтов24/лендингов, витрин, баз знаний по лендингу. Ключевые термины — Лендинг, Сайт, Блок, BlockRepo, публикация, непубличный, хуки, СТРАНИЦА, МАГАЗИН.
