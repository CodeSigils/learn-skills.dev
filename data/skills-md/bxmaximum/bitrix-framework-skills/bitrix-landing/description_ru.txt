Модуль Covers Landing — сайты/лендинги, репозиторий блоков, процесс публикации/отмены публикации, хуки (Метрика/GA/пиксели), ограничения настройки по сравнению с классической CMS. Применяется для Сайтов24/лендингов, витрин, баз знаний по лендингам. Ключевые термины — Лендинг, Сайт, Блок, BlockRepo, публикация, непубличный, хуки, СТРАНИЦА, МАГАЗИН.
