Bitrix UI ライブラリをカバー — main.popup、main.sidepanel、ui.system.dialog、ui.dialogs.messagebox、ui.system.menu、ui.system.input、ui.alerts、ui.notification (トースト)、ui.entity-selector (ダイアログ、TagSelector、プロバイダー)、main.ui.grid、main.ui.filter、ui.icon-set、 ui.lottie、ui.a11y、タイポグラフィ。カーネル コンポーネントを使用して管理インターフェイスとパブリック UI を構築するときに適用されます。主要な用語 — Extension::load、Popup、SidePanel、システム ダイアログ、メッセージ ボックス、ui.alerts、エンティティ セレクター、グリッド、フィルター、ui.a11y、UI キット。
