Deckt das Bitrix-Modul sprint.migration ab – Versionsmigrationen, HelperManager (Iblock/Hlblock/Option/Agent/…), Builder (Ausführen), CLI migrate.php (add/ls/up/down/redo/mark), Konfigurationsmigrationen.*.php, neu startbare Batches, Austauschverzeichnisse. Wird zum Erstellen oder Anwenden von DB-/Schema-/Inhaltsmigrationen, zum Exportieren von iblock/HL/options über Builder oder zum Debuggen des Migrationsstatus verwendet. Schlüsselbegriffe – sprint.migration, Version, up/down, HelperManager, saveIblock, saveHlblock, migrate.php, Version Builders, migration_dir.
