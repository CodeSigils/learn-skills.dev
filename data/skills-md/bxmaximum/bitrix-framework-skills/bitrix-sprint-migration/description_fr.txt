Couvre le module Bitrix sprint.migration — migrations de Version, HelperManager (Iblock/Hlblock/Option/Agent/…), constructeurs (exécution), CLI migrate.php (add/ls/up/down/redo/mark), configurations migrations.*.php, lots redémarrables, répertoires d’échange. À utiliser lors de la création ou de l’application de migrations de base de données/schéma/contenu, de l’exportation d’iblock/HL/options via les constructeurs, ou du débogage de l’état des migrations. Termes clés : sprint.migration, Version, up/down, HelperManager, saveIblock, saveHlblock, migrate.php, constructeurs de version, migration_dir.
