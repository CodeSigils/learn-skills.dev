Охватывает модуль SEO — создание карты сайта, robots.txt, веб-мастера/поисковые системы, ориентация на ключевые слова/инструменты; ссылки на iblock IPROPERTY/InheritedProperty для мета страницы. Применяется для карт сканирования, подключения веб-мастеров/консоли поиска, инструментов SEO. Ключевые термины — Карта сайта, Генератор, Работа, RobotsFile, Веб-мастер, SearchEngine, InheritedProperty, IPROPERTY_TEMPLATES.
