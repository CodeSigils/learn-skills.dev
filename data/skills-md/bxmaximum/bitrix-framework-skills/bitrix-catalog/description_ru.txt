Модуль Covers Trade Catalog — товары, артикул/предложения, цены, инвентарь, скидки, комплекты, экспорт/импорт, выбор API каталога. Применяется для функций электронной коммерции, требующих интеграции цен, запасов и продаж. Ключевые термины — каталог, товар, артикул, предложение, тип цены, CCatalogProduct, модуль каталога.
