Couvre le travail direct sur la base de données dans Bitrix — Application::getConnection(), Connection, MysqliConnection, SqlHelper, SqlExpression, les requêtes SQL brutes via query()/queryExecute()/queryScalar(), les transactions (startTransaction/commitTransaction/rollbackTransaction), les migrations DDL et de schéma, les opérations en masse (insertBatch, addMulti), les connexions supplémentaires via la section de connexions dans .settings.php. Appliqué lorsque ORM est insuffisant : opérations en masse, SQL brut, migrations, utilisation de bases de données externes et création de requêtes personnalisées. Termes clés — Connexion, SqlHelper, SqlExpression, transaction, SQL brut, insertion en bloc, DDL, migration.
