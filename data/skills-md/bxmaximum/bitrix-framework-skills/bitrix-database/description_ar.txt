يغطي العمل المباشر لقاعدة البيانات في Bitrix — Application::getConnection(), Connection, MysqliConnection, SqlHelper, SqlExpression، واستعلامات SQL الأولية عبر query()/queryExecute()/queryScalar()، والمعاملات (startTransaction/commitTransaction/rollbackTransaction)، وترحيلات DDL والمخطط، والعمليات المجمعة (insertBatch، addMulti)، والاتصالات الإضافية عبر قسم الاتصالات في .settings.php. يتم تطبيقه عندما يكون ORM غير كافٍ - العمليات المجمعة، وSQL الأولية، وعمليات الترحيل، والعمل مع قواعد البيانات الخارجية، وإنشاء استعلامات مخصصة. المصطلحات الأساسية - الاتصال، SqlHelper، SqlExpression، المعاملة، SQL الخام، الإدراج المجمع، DDL، الترحيل.
