Охватывает прямую работу с базой данных в Битриксе — Application::getConnection(), Connection, MysqliConnection, SqlHelper, SqlExpression, сырые SQL-запросы через query()/queryExecute()/queryScalar(), транзакции (startTransaction/commitTransaction/rollbackTransaction), миграции DDL и схемы, массовые операции (insertBatch, addMulti), дополнительные подключения через раздел подключений в .settings.php. Применяется, когда ORM недостаточно — массовые операции, сырой SQL, миграции, работа с внешними базами данных и построение пользовательских запросов. Ключевые термины — соединение, SqlHelper, SqlExpression, транзакция, необработанный SQL, массовая вставка, DDL, миграция.
