Охватывает инструменты Bitrix CLI — php bitrix/bitrix.php, генераторы make:module/make:controller/make:tablet/make:entity/make:service/make:event/make:eventhandler/make:message/make:messagehandler/make:comComponent/make:request, команды ядра (orm:annotate, Messenger:consume, Translate:index, update:*, dev:locator-codes, dev:module-skeleton), создание пользовательских команд на консоли Symfony и регистрация их в разделе консоли модуля .settings.php. Применяется для создания нового кода, задач cron, написания пользовательских команд CLI и запуска обработчиков очередей. Ключевые термины — bitrix.php, команда make, консоль Symfony, CLI, команда, пространство имен консоли.
