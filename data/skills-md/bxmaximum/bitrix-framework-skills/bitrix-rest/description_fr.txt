Couvre le module REST - enregistrement des méthodes à partir d'un module personnalisé, étendues, présentation du webhook et d'OAuth, paramètres rest/restIntegration, lien vers les contrôleurs Engine et ActionFilter\Scope::REST. Appliqué lors de l'exposition des API de module à des applications, des webhooks ou des intégrations de Marketplace. Termes clés : rest, OnRestServiceBuildDescription, CRestUtil, scope, webhook, OAuth, APAuth, restIntegration, Scope :: REST, BX.rest.callMethod.
