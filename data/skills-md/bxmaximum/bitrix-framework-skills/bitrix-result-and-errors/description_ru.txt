Охватывает результаты унифицированных операций Битрикс — Bitrix\Main\Result, Error, ErrorCollection, типизированные потомки (AddResult, UpdateResult, DeleteResult, EventResult), разницу между Result и исключениями, возврат ошибок от контроллеров через addError и объединение ошибок сервиса. Применяется при разработке сервисных API и вариантов использования, возвращает ошибки из методов модуля и контроллеров без создания исключений. Ключевые термины — Result, Error, ErrorCollection, isSuccess, getErrors, AddResult, UpdateResult, addError.
