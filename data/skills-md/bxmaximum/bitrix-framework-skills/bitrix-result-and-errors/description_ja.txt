Bitrix 統合操作の結果 — Bitrix\Main\Result、Error、ErrorCollection、型付き子孫 (AddResult、UpdateResult、DeleteResult、EventResult)、Result と例外の違い、addError を介してコントローラーから返されるエラー、結合サービス エラーをカバーします。サービス API とユースケースを設計するときに適用され、例外をスローせずにモジュール メソッドとコントローラーからエラーを返します。重要な用語 — Result、Error、ErrorCollection、isSuccess、getErrors、AddResult、UpdateResult、addError。
