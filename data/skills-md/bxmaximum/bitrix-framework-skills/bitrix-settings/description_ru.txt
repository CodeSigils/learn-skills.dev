Охватывает конфигурацию ядра — разделы .settings.php (соединения, кэш, сеанс, криптография, обработка исключений, маршрутизация, мессенджер, pull, smtp, регистраторы, композитор), .settings_extra.php, флаг только для чтения. Применяется при настройке поведения ядра. Ключевые термины — .settings.php, настройки, только чтение, соединения, обработка исключений.
