Bitrix イベント システム — 新しいモデル (Bitrix\Main\Event、EventResult、EventManager::addEventHandler、make:event、make:eventhandler) と古いモデル (CIBlock、CUser、CSale、およびその他のクラシック API の OnBefore*/OnAfter* フック) をカバーします。モジュールの統合、エンティティのライフサイクル フック、カスタム イベントの公開、および他のモジュールのイベントのサブスクライブ時に適用されます。重要な用語 — Event、EventManager、EventResult、OnBefore、OnAfter、ハンドラー、サブスクライバー、addEventHandler。
