Optimieren und verbessern Sie Eingabeaufforderungen, bevor Sie sie an Claude Code senden. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer „Aufforderung optimieren“, „Diese Aufforderung verbessern“, „Hilf mir, diese Anweisung neu zu schreiben“, „Wie schreibe ich diese Aufforderung besser“ sagt oder eine andere Aufforderung/Anweisung, die er Claude geben möchte, verfeinern, polieren oder verbessern möchte. Wird auch ausgelöst, wenn der Benutzer eine Entwurfsaufforderung bereitstellt und um Feedback oder Verbesserungen bittet, auch wenn er das Wort „Aufforderung“ nicht explizit verwendet.
