Se conecta a navegadores remotos sin cabeza de Oxylabs a través del protocolo Chrome DevTools (CDP) usando Playwright o Puppeteer. Proporciona antidetección, manejo de CAPTCHA, servidores proxy residenciales y orientación geográfica integrados. Úselo cuando la automatización del navegador necesite ejecución remota, capacidades sigilosas, páginas renderizadas, capturas de pantalla, archivos PDF o interacción compleja de JavaScript.
