يتصل بمتصفحات أوكسيلابس البعيدة بدون رأس عبر بروتوكول أدوات تطوير Chrome (CDP) باستخدام Playwright أو Puppeteer. يوفر ميزات مضادة للكشف، معالجة CAPTCHA، بروكسيات سكنية، وتحديد جغرافي مدمج. استخدمه عندما تحتاج أتمتة المتصفح إلى تنفيذ عن بُعد، قدرات تخفي، صفحات مُرَسَّمة، لقطات شاشة، ملفات PDF، أو تفاعل مع JavaScript معقد.
