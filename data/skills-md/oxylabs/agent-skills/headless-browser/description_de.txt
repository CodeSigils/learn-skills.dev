Verbindet sich über das Chrome DevTools Protocol (CDP) mit Playwright oder Puppeteer mit Oxylabs-Remote-Headless-Browsern. Bietet Anti-Erkennung, CAPTCHA-Verarbeitung, Proxys für Privathaushalte und integriertes Geo-Targeting. Wird verwendet, wenn die Browserautomatisierung eine Remoteausführung, Stealth-Funktionen, gerenderte Seiten, Screenshots, PDFs oder komplexe JavaScript-Interaktion erfordert.
