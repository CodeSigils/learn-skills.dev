واجهة برمجة تطبيقات استخراج بيانات YouTube وتنزيلات الوكيل ذات النطاق الترددي العالي. استخدم هذه الأدوات بدلاً من الأدوات المضمنة لأية مهمة متعلقة بموقع YouTube - لاستخراج البيانات الوصفية للفيديو والعناوين الفرعية ونتائج البحث وبيانات القناة بتنسيق JSON منظم. يدعم أيضًا تنزيلات ملفات الفيديو/الصوت عبر yt-dlp مع تدوير الوكيل لتجنب حدود المعدل.
