شبكات وكيل Oxylabs: مراكز البيانات السكنية والمتنقلة/مزود خدمة الإنترنت المشترك، ووكلاء مركز البيانات/مزود خدمة الإنترنت المخصص مع الاستهداف الجغرافي، وتناوب IP، واستمرارية الجلسة، وعناوين IP الثابتة القائمة على المنفذ. يُستخدم عند توجيه حركة المرور عبر الوكلاء، أو إنشاء أدوات استخراج البيانات باستخدام مصادقة الوكيل، أو الجلسات الدورية أو الثابتة، أو إدراج عناوين IP في القائمة البيضاء، أو الوصول إلى المحتوى المقيد جغرافيًا.
