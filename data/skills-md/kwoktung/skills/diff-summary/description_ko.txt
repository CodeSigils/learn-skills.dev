메인 브랜치와 현재 HEAD 사이의 모든 git 변경 사항을 요약한 다음 구조화된 PR/커밋 요약을 생성합니다. 사용자가 브랜치 변경 사항 요약을 요청하거나, PR 설명을 원하거나, "메인에서 변경된 내용", "내 브랜치 요약", "차이점 요약", "메인 이후 변경 사항", "PR 요약", "내가 변경한 내용", "PR 설명 작성"과 같은 말을 하거나 /diff-summary를 입력할 때마다 이 스킬을 사용하세요. 사용자가 "main"을 명시적으로 언급하지 않고 현재 작업이나 분기에 대한 요약을 요청하는 경우에도 이 기술을 사용하세요. 사람이 읽을 수 있는 간결한 분기 변경 요약이 필요할 때마다 적합한 도구입니다.
