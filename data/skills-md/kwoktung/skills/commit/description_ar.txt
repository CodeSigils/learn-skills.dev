يُنشئ رسالة التزام بنمط الالتزامات التقليدية من تغييرات git المرحلية و/أو غير المرحلية، دون تشغيل git الالتزام. استخدم هذه المهارة عندما يريد المستخدم رسالة التزام، أو يطلب "تحضير التزام"، أو يقول "ماذا يجب أن ألتزم؟"، أو يكتب /commit، أو يطلب المساعدة في كتابة رسالة التزام git بناءً على تغييراته الحالية.
