Genera un mensaje de confirmación de estilo Commits convencionales a partir de cambios de git preparados y/o no preparados, sin ejecutar git commit. Utilice esta habilidad siempre que el usuario quiera un mensaje de confirmación, solicite "preparar una confirmación", diga "¿qué debo confirmar?", escriba /commit o solicite ayuda para escribir un mensaje de confirmación de git basado en sus cambios actuales.
