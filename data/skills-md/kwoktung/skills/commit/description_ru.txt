Генерирует сообщение фиксации в стиле обычных коммитов из проиндексированных и/или непроиндексированных изменений git без запуска git commit. Используйте этот навык всякий раз, когда пользователь хочет получить сообщение о фиксации, просит «подготовить фиксацию», говорит «что мне следует зафиксировать?», вводит /commit или просит помочь написать сообщение о фиксации git на основе текущих изменений.
