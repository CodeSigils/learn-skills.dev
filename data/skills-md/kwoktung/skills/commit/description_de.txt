Erzeugt eine Commit-Nachricht im herkömmlichen Commits-Stil aus bereitgestellten und/oder nicht bereitgestellten Git-Änderungen, ohne Git Commit auszuführen. Verwenden Sie diesen Skill immer dann, wenn der Benutzer eine Commit-Nachricht möchte, fragt, ob er „einen Commit vorbereiten“ möchte, sagt „Was soll ich committen?“, „/commit“ eingibt oder um Hilfe beim Schreiben einer Git-Commit-Nachricht basierend auf seinen aktuellen Änderungen bittet.
