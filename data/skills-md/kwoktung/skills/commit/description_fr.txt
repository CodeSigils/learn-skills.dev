Génère un message de validation de style Conventional Commits à partir de modifications git planifiées et/ou non planifiées, sans exécuter git commit. Utilisez cette compétence chaque fois que l'utilisateur souhaite un message de validation, demande de « préparer une validation », dit « que dois-je valider ? », tape /commit ou demande de l'aide pour rédiger un message de validation git en fonction de ses modifications actuelles.
