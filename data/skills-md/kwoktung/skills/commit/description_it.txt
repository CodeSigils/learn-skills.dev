Genera un messaggio di commit in stile Commit convenzionale da modifiche git in stage e/o non in stage, senza eseguire git commit. Usa questa abilità ogni volta che l'utente desidera un messaggio di commit, chiede di "preparare un commit", dice "cosa dovrei impegnare?", digita /commit o chiede aiuto per scrivere un messaggio di commit git in base alle modifiche attuali.
