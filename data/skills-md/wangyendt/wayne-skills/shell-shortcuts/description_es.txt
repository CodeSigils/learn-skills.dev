Configure comandos de acceso directo de terminal multiplataforma en una máquina nueva, incluidos proxy_on/proxy_off (env vars + git global proxy), goto (atajos de salto de ruta persistentes), gpu (asistente nvidia-smi) y activación automática opcional de Conda. Úselo al configurar el perfil de Windows PowerShell/CMD AutoRun, o al agregar funciones a archivos rc de shell de macOS/Linux.
