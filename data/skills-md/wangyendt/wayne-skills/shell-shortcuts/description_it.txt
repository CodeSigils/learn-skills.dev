Configura i comandi di scelta rapida del terminale multipiattaforma su una nuova macchina, inclusi proxy_on/proxy_off (env vars + git global proxy), goto (scorciatoie di salto del percorso persistente), gpu (helper nvidia-smi) e attivazione automatica Conda opzionale. Da utilizzare durante la configurazione del profilo Windows PowerShell/esecuzione automatica CMD o l'aggiunta di funzioni ai file rc della shell macOS/Linux.
