Konfigurieren Sie plattformübergreifende Terminal-Verknüpfungsbefehle auf einem neuen Computer, einschließlich „proxy_on/proxy_off“ (env vars + git globaler Proxy), „goto“ (persistente Pfadsprungverknüpfungen), „gpu“ (nvidia-smi helper) und optionale automatische Conda-Aktivierung. Verwenden Sie diese Option, wenn Sie Windows PowerShell Profile/CMD AutoRun einrichten oder Funktionen zu macOS/Linux-Shell-RC-Dateien hinzufügen.
