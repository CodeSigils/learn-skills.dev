Настройте кроссплатформенные команды ярлыков терминала на новом компьютере, включая proxy_on/proxy_off (env vars + git global proxy), goto (постоянные ярлыки перехода по пути), gpu (помощник nvidia-smi) и дополнительную автоматическую активацию Conda. Используйте при настройке профиля Windows PowerShell / автозапуска CMD или добавлении функций в файлы rc оболочки macOS/Linux.
