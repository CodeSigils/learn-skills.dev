Configurez les commandes de raccourci de terminal multiplateforme sur une nouvelle machine, y compris proxy_on/proxy_off (env vars + git global proxy), goto (raccourcis de saut de chemin persistants), GPU (assistant nvidia-smi) et l'activation automatique facultative de Conda. À utiliser lors de la configuration du profil Windows PowerShell/CMD AutoRun ou de l'ajout de fonctions aux fichiers rc du shell macOS/Linux.
