قم بتكوين أوامر الاختصارات الطرفية عبر الأنظمة الأساسية على جهاز جديد، بما في ذلك proxy_on/proxy_off (env vars + git global proxy)، وgoto (اختصارات الانتقال المستمر للمسار)، وgpu (مساعد nvidia-smi)، والتنشيط التلقائي Conda الاختياري. يُستخدم عند إعداد Windows PowerShell Profile / CMD AutoRun، أو إضافة وظائف إلى ملفات rc الخاصة بنظام التشغيل macOS/Linux.
