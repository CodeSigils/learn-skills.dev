Универсальные навыки создания обучающего видео, основанные на знаниях, создание анимационных видеороликов Motion Canvas с озвучкой.
Основной рабочий процесс: анализ контента → сценарий раскадровки → звук TTS → обновление проверки → код Motion Canvas → проверка рендеринга.
Триггерное условие: необходимость создания обучающих видеороликов по любой теме, научных объяснений или демонстрации технических принципов.
