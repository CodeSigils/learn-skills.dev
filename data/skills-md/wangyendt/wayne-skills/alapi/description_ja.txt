バンドルされている完全な ALAPI OpenAPI カタログをカバーする包括的な ALAPI スキル。ユーザーが ALAPI、alapi、ALAPI_TOKEN、openapi.json、または /api/... などの ALAPI パスについて言及する場合、またはビジネス ニーズに一致する ALAPI API を見つけること、類似した ALAPI エンドポイントから選択すること、リクエスト フィールドについて説明すること、リクエストを準備または実行すること、または ALAPI レスポンスのトラブルシューティングを行うことを求める場合に使用します。インスピレーションを与えるコンテンツ、記事、ニュースとホットリスト、AI チャット/翻訳/NLP、OCR と文書認識、天気とカレンダーのデータ、IP/電話/ID/ドメイン/ICP/企業の検索と検証、金融/為替/金/石油/仮想通貨市場データ、音楽/メディア/ビデオ/TTS、URL/QR ツール、および関連ユーティリティ API をカバーします。
