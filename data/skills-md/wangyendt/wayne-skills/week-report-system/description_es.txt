Sistema de informes de trabajo semanales de IA que registra automáticamente cada conversación (mensajes de usuario comprimidos + resúmenes de IA) en un repositorio de GitHub organizado por año/semana y genera informes semanales completos. SIEMPRE utilice esta habilidad cuando el usuario mencione 周报, informe semanal, informe semanal, 本周总结, 工作总结, 写周报, 生成周报, 帮我写周报, 本周工作,上周周报, 查看周报, 周报系统, 记录工作, o pide resumir o revisar el trabajo semanal. También utilícelo para CADA conversación de usuario para grabarla silenciosamente en Git en segundo plano. Active cualquier chat relacionado con el trabajo para mantener el registro actualizado.
