KI-System für wöchentliche Arbeitsberichte, das automatisch jede Konversation (komprimierte Benutzernachrichten + KI-Zusammenfassungen) in einem nach Jahr/Woche geordneten GitHub-Repository aufzeichnet und umfassende wöchentliche Berichte erstellt. Verwenden Sie diese Fähigkeit IMMER, wenn der Benutzer 周报, Wochenbericht, Wochenbericht, 本周总结, 工作总结, 写周报, 生成周报, 帮我写周报, 本周工作,上周周报, 查看周报, 周报系统, 记录工作, oder bittet darum, die wöchentliche Arbeit zusammenzufassen/zu überprüfen. Verwenden Sie es auch für JEDES Benutzergespräch, um es stillschweigend im Hintergrund in Git aufzuzeichnen. Lösen Sie bei jedem arbeitsbezogenen Chat aus, um das Protokoll auf dem neuesten Stand zu halten.
