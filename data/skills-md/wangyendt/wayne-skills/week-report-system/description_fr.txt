Système de rapport de travail hebdomadaire d'IA qui enregistre automatiquement chaque conversation (messages utilisateur compressés + résumés d'IA) dans un référentiel GitHub organisé par année/semaine et génère des rapports hebdomadaires complets. Utilisez TOUJOURS cette compétence lorsque l'utilisateur mentionne 周报, rapport hebdomadaire, rapport hebdomadaire, 本周总结, 工作总结, 写周报, 生成周报, 帮我写周报, 本周工作,上周周报, 查看周报, 周报系统, 记录工作, ou demande de résumer/réviser le travail hebdomadaire. Utilisez également pour CHAQUE conversation utilisateur pour l'enregistrer silencieusement sur Git en arrière-plan. Déclenchez n’importe quelle discussion liée au travail pour maintenir le journal à jour.
