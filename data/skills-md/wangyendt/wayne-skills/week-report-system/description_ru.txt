Система еженедельных отчетов о работе ИИ, которая автоматически записывает каждый разговор (сжатые сообщения пользователей + сводки ИИ) в репозиторий GitHub, организованный по годам/неделям, и генерирует подробные еженедельные отчеты. ВСЕГДА используйте этот навык, когда пользователь упоминает 周报, недельный отчет, еженедельный отчет, 本周总结, 工作总结, 写周报, 生成周报, 帮我写周报, 本周工作,上周周报, 查看周报, 周报系统, 记录工作 или просит подвести итог/пересмотреть работу за неделю. Также используйте для КАЖДОГО разговора пользователя, чтобы незаметно записывать его в Git в фоновом режиме. Запустите любой чат, связанный с работой, чтобы поддерживать журнал в актуальном состоянии.
