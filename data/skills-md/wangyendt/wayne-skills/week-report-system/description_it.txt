Sistema di report di lavoro settimanale AI che registra automaticamente ogni conversazione (messaggi utente compressi + riepiloghi AI) in un repository GitHub organizzato per anno/settimana e genera report settimanali completi. Usa SEMPRE questa abilità quando l'utente menziona 周报, report settimanale, report settimanale, 本周总结, 工作总结, 写周报, 生成周报, 帮我写周报, 本周工作,上周周报, 查看周报, 周报系统, 记录工作, oppure chiede di riassumere/revisionare il lavoro settimanale. Utilizzalo anche per OGNI conversazione dell'utente per registrarla silenziosamente su Git in background. Attiva qualsiasi chat relativa al lavoro per mantenere aggiornato il registro.
