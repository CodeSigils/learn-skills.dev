مهارات المعلم الفردي لحل المشكلات الرياضية وإنشاء مستندات شرح بتنسيق HTML ومقاطع فيديو الرسوم المتحركة المروية.
سير العمل الأساسي: تحليل الرياضيات ← تصور HTML ← نص القصة المصورة ← صوت TTS ← تحديث التحقق من الصحة ← السقالات ← كود مانيم ← التحقق من صحة العرض
شرط التفعيل: يقوم الطالب بلصق صورة مسألة رياضية، أو يحتاج إلى فيديو تعليمي، أو يحتاج إلى مواد توضيحية بتنسيق HTML
【مهم】يجب أن يتضمن الفيديو الذي تم إنشاؤه سرد تحويل النص إلى كلام (TTS)؛ هذا إلزامي ولا يمكن تخطيه
