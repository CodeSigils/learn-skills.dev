Habilidades de tutor individual para resolver problemas matemáticos, generar documentos explicativos HTML y videos de animación narrados de Manim.
Flujo de trabajo principal: análisis matemático → visualización HTML → script de guión gráfico → audio TTS → actualización de validación → andamiaje → código Manim → validación de renderizado
Condición desencadenante: el estudiante pega la imagen de un problema matemático, necesita un video instructivo o necesita materiales explicativos en HTML
【Importante】El video generado debe incluir narración TTS; esto es obligatorio y no se puede omitir
