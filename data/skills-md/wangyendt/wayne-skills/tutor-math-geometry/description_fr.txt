Compétences de tuteur individuel pour résoudre des problèmes mathématiques, générer des documents d'explication HTML et des vidéos d'animation Manim commentées.
Flux de travail principal : analyse mathématique → visualisation HTML → script de storyboard → audio TTS → mise à jour de validation → échafaudage → code Manim → validation de rendu
Condition de déclenchement : l'élève colle une image de problème mathématique, a besoin d'une vidéo pédagogique ou a besoin de matériel d'explication HTML
【Important】 La vidéo générée doit inclure une narration TTS ; ceci est obligatoire et ne peut être ignoré
