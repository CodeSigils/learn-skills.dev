Навыки индивидуального обучения для решения математических задач, создания пояснительных документов в формате HTML и анимационных видеороликов Manim с озвучкой.
Основной рабочий процесс: математический анализ → визуализация HTML → сценарий раскадровки → аудио TTS → обновление проверки → строительные леса → код Manim → проверка рендеринга.
Условие срабатывания: учащийся вставляет изображение математической задачи, ему требуется обучающее видео или поясняющие материалы в формате HTML.
【Важно】Сгенерированное видео должно включать повествование TTS; это обязательно и не может быть пропущено
