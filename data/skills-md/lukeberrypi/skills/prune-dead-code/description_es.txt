Audite una base de código en busca de código inactivo o que sea seguro de eliminar, e informe cada hallazgo para su aprobación. Úselo cuando se le solicite encontrar código inactivo o no utilizado, deduplicar constantes repetidas, reemplazar literales mágicos que duplican una constante con nombre o eliminar límites, umbrales o tiempos de espera arbitrarios.
