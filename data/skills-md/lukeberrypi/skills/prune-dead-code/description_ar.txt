قم بمراجعة قاعدة التعليمات البرمجية بحثًا عن التعليمات البرمجية الميتة والتي يمكن إزالتها بأمان، والإبلاغ عن كل نتيجة للموافقة عليها. استخدمه عندما يُطلب منك العثور على تعليمات برمجية ميتة أو غير مستخدمة، أو إلغاء تكرار الثوابت المتكررة، أو استبدال القيم الحرفية السحرية التي تكرر ثابتًا مسمىًا، أو إزالة الأحرف الاستهلالية أو الحدود أو المهلات العشوائية.
