استخدم هذه المهارة عندما يحتاج نائب رئيس قسم الرواتب، أو رئيس عمليات الأفراد، أو مدير الرواتب إلى إدارة جميع تدفقات تعويضات الموظفين والمقاولين - بما في ذلك عمليات الرواتب، وإدارة الرواتب، والخصومات القانونية، وإدارة المزايا، ومنح الأسهم والاستحقاقات، ومكافآت الأجور المتغيرة، ومعالجة فواتير المقاولين، والامتثال الكامل لكشوف الرواتب عبر الولايات القضائية. تنظم هذه المهارة المهارة الفرعية لإدارة الرواتب. يتم التشغيل عند تشغيل كشوف المرتبات، أو إعداد الموظفين بحزم التعويضات، أو معالجة تغييرات الرواتب، أو حساب المكافآت، أو إدارة جداول الأسهم، أو معالجة مدفوعات المقاولين، أو التعامل مع ملفات ضرائب الرواتب، أو إنتاج تقارير التعويضات الإجمالية لقيادة الأفراد والشؤون المالية.
