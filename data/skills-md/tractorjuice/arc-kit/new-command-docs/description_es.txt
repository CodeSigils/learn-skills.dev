Esta habilidad debe usarse cuando se agregó un nuevo comando de ArcKit y es necesario actualizar la documentación en todo el repositorio. Activadores: actualizar la documentación para un nuevo comando, actualizar el recuento de comandos, agregar un comando a README, actualizar DEPENDENCY-MATRIX, actualizar docs/index.html, nueva lista de verificación de documentación de comandos, actualizar todos los documentos para un nuevo comando, agregar un comando a la matriz de dependencia, actualizar tablas de comandos, sincronizar la documentación después de agregar un comando, agregué un nuevo comando, ¿qué debo actualizar?, documentación posterior al comando, nuevos documentos de comando con barra diagonal.
