استخدم LOPJLB، وهي طبقة بحث كمي (ليست واجهة برمجة تطبيقات بيانات السوق الخام): الإشارات التي تم اختبارها ليلاً، ونظام HMM، ونتائج العوامل، وتوليف CallCard للأرباح، والتصنيف العالمي لأكثر من 12000 اسم أمريكي عبر BFF REST، أو lopjlb CLI/PyPI، أو Enterprise HTTP MCP. يُستخدم عندما يريد المستخدم آراء بحثية، أو سياق النظام، أو القوائم المختصرة للفرز، أو بطاقة الإشارة، أو LOPJLB API/MCP - وليس عندما يحتاج فقط إلى OHLCV (يفضل yfinance/broker). لا تستخدمه لتدفق الخيارات، أو التمويل اللامركزي على السلسلة، أو العقود الآجلة، أو الأسواق غير الأمريكية، أو النصائح الاستثمارية المخصصة، أو تنفيذ التجارة.
