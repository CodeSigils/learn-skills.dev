Control Hikvision NVRs (e.g., DS-7804N-Z1) on the LAN via the ISAPI protocol. Supports: device info query, camera channel management, recording search, real-time preview stream URL acquisition, PTZ control, snapshot capture, alarm event query. Use when users need to view live feeds, play back recordings, control PTZ cameras, or grab screenshots. Not for: Hikvision cloud services (Ezviz) or remote public network access (requires extra configuration).
