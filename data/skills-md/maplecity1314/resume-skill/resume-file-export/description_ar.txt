قم بتصدير محتوى السيرة الذاتية كملف PDF أو Word جاهز للإرسال، وتوفير مخرجات Markdown عادية وطرق تحويل متعددة. يتم تشغيله عندما يقول المستخدم "تصدير سيرتي الذاتية" أو "إنشاء ملف السيرة الذاتية" أو "كيفية تحويل السيرة الذاتية إلى PDF" أو "كيفية إنشاء سيرة ذاتية في Word" أو "ساعدني في تنسيقها" أو "إنشاء Markdown للسيرة الذاتية". يمكن أيضًا أن تكون بمثابة مهارة التنفيذ للوضع C (إنشاء ملف) في محرر السيرة الذاتية.
