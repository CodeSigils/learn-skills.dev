Exportez le contenu du CV sous forme de fichier PDF ou Word prêt à envoyer, fournissez une sortie Markdown normalisée et plusieurs méthodes de conversion. Déclenché lorsque l'utilisateur dit « exporter mon CV », « générer un fichier de CV », « comment convertir un CV en PDF », « comment créer un CV dans Word », « aidez-moi à le formater » ou « générer un CV Markdown ». Peut également servir de compétence d'exécution pour le mode C (générer un fichier) dans l'éditeur de CV.
