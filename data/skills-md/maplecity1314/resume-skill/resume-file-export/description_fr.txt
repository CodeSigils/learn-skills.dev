Exportez le contenu du CV sous forme de fichier PDF ou Word livrable, fournissez une sortie normalisée Markdown et plusieurs méthodes de conversion. Déclenché lorsque l'utilisateur dit « exporter mon CV pour moi », « générer un fichier de CV », « comment convertir un CV en PDF », « comment créer un CV Word », « le formater pour moi » ou « générer un CV Markdown ». Peut également servir de compétence d'exécution pour le mode C (générer un fichier) dans l'éditeur de CV.
