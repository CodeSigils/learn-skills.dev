Realiza una entrevista de admisión de marca estructurada y luego realiza una investigación web para crear un documento de contexto de marca completo. Utilice esto siempre que el usuario diga que está trabajando en un nuevo cliente, quiera crear un contexto de marca o diga "realizar el consumo de marca", "realizar una investigación de marca" o "crear un contexto de marca para [marca]". También se activa cuando el usuario inicia un flujo de trabajo de estrategia creativa para una marca que aún no tiene un documento de contexto en el proyecto. Esto debe ejecutarse ANTES de cualquier motor de estrategia creativa, redacción de ganchos u otro trabajo de ejecución; es la capa de contexto de requisito previo para toda estrategia creativa posterior.
