استخدم Scrapfly RPA API لتشغيل الرسوم البيانية لسير العمل المكتوبة على المتصفحات السحابية المُدارة، واسترداد العناصر المنتجة (لقطات HTML، والتنزيلات، ونصوص استجابة HTTP، وقيم إرجاع JS)، وتوجيه تلك العناصر إلى حاوية Scrapfly المُدارة أو حاوية GCS أو S3 الخاصة بالعميل الخاص بك. يُستخدم عندما يطلب المستخدم "تشغيل سير عمل RPA"، أو "جلب العناصر من التشغيل"، أو "تكوين تخزين BYOS"، أو "إعداد GCS أو S3 للعميل لـ RPA"، أو "اختبار وجهة تخزين"، أو أي مهمة تتضمن نقاط النهاية /v2/rpa/*.
