Regole d'oro multistrumento per un agente web Scrapfly autonomo connesso al server MCP Scrapfly (web_scrape, screenshot, estratto, classifica_blocco, ciclo di vita del browser cloud, istantanea/clic/riempimento/digitazione/pressione/scorrimento/seleziona/trascinamento e WebMCP). Da utilizzare quando un agente LLM ha accesso al set di strumenti MCP Scrapfly e deve scegliere tra lo scraping senza stato e una sessione del browser cloud con stato, decidere quando chiamare browser_unblock o coordinare i flussi multi-strumento.
