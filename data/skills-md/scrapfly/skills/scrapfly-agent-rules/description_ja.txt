Scrapfly MCP サーバーに接続された自律型 Scrapfly Web エージェントのツール間のゴールデン ルール (web_scrape、スクリーンショット、抽出、classify_block、クラウド ブラウザのライフサイクル、スナップショット/クリック/入力/入力/プレス/スクロール/選択/ドラッグ、および WebMCP)。 LLM エージェントが Scrapfly MCP ツールセットにアクセスでき、ステートレス スクレイピングとステートフル クラウド ブラウザ セッションのどちらかを選択する必要がある場合、browser_unblock を呼び出すタイミングを決定する場合、またはマルチツール フローを調整する必要がある場合に使用します。
