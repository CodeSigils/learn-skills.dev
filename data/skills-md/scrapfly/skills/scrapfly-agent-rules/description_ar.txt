القواعد الذهبية للأدوات المشتركة لوكيل ويب Scrapfly المستقل المتصل بخادم Scrapfly MCP (web_scrape، لقطة الشاشة، الاستخراج، classify_block، دورة حياة Cloud Browser، لقطة/نقر/ملء/نوع/ضغط/تمرير/تحديد/سحب، وWebMCP). يُستخدم عندما يكون لدى وكيل LLM حق الوصول إلى مجموعة أدوات Scrapfly MCP ويحتاج إلى الاختيار بين الاستخراج عديم الحالة وجلسة Cloud Browser ذات الحالة، أو تحديد وقت الاتصال بـ browser_unblock، أو تنسيق تدفقات الأدوات المتعددة.
