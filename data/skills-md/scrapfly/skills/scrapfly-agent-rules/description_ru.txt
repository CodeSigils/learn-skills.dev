Золотые правила кросс-инструментов для автономного веб-агента Scrapfly, подключенного к серверу Scrapfly MCP (web_scrape, снимок экрана, извлечение, classify_block, жизненный цикл Cloud Browser, снимок/щелчок/заполнение/тип/нажатие/прокрутка/выбор/перетаскивание и WebMCP). Используйте, когда агент LLM имеет доступ к набору инструментов Scrapfly MCP и ему необходимо выбирать между очисткой данных без сохранения состояния и сеансом Cloud Browser с сохранением состояния, решать, когда вызывать браузер_unblock или координировать потоки работы с несколькими инструментами.
