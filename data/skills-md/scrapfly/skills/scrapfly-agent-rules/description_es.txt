Reglas de oro de herramientas cruzadas para un agente web autónomo de Scrapfly conectado al servidor MCP de Scrapfly (web_scrape, captura de pantalla, extracción, classify_block, ciclo de vida del navegador en la nube, instantánea/hacer clic/rellenar/escribir/presionar/desplazarse/seleccionar/arrastrar y WebMCP). Úselo cuando un agente de LLM tiene acceso al conjunto de herramientas Scrapfly MCP y necesita elegir entre scraping sin estado y una sesión de Cloud Browser con estado, decidir cuándo llamar a browser_unblock o coordinar flujos de múltiples herramientas.
