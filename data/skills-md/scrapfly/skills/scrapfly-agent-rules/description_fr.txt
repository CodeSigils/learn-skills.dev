Règles d'or multi-outils pour un agent web Scrapfly autonome connecté au serveur Scrapfly MCP (web_scrape, capture d'écran, extrait, classify_block, le cycle de vie du Cloud Browser, instantané/clic/remplir/type/press/scroll/select/drag et WebMCP). À utiliser lorsqu'un agent LLM a accès à l'ensemble d'outils Scrapfly MCP et doit choisir entre un scraping sans état et une session Cloud Browser avec état, décider quand appeler browser_unblock ou coordonner des flux multi-outils.
