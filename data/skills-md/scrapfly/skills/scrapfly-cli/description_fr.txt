Utilisez la CLI Scrapfly (« scrapfly ») pour gratter des pages Web, capturer des captures d'écran, extraire des données structurées avec l'IA, explorer des sites entiers et piloter un navigateur cloud sur CDP à partir d'un shell. Enveloppe JSON sur la sortie standard pour chaque commande. À utiliser lorsque l'utilisateur demande de « gratter une URL », « capturer une page », « extraire des données du HTML », « explorer un site », « piloter un navigateur avec Playwright/CDP », « contourner l'anti-bot » ou toute tâche impliquant la commande « scrapfly ».
