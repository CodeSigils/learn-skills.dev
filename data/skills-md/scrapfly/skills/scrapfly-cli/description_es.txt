Utilice la CLI de Scrapfly ("scrapfly") para extraer páginas web, capturar capturas de pantalla, extraer datos estructurados con IA, rastrear sitios completos y ejecutar un navegador en la nube a través de CDP desde un shell. Sobre JSON en la salida estándar para cada comando. Úselo cuando el usuario solicite "extraer una URL", "capturar una pantalla de una página", "extraer datos de HTML", "rastrear un sitio", "manejar un navegador con Playwright/CDP", "evitar anti-bot" o cualquier tarea que involucre el comando `scrapfly`.
