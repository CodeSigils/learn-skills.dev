Используйте интерфейс командной строки Scrapfly («scrapfly») для очистки веб-страниц, создания снимков экрана, извлечения структурированных данных с помощью ИИ, сканирования целых сайтов и управления облачным браузером через CDP из оболочки. Конверт JSON на стандартном выводе для каждой команды. Используйте, когда пользователь просит «очистить URL-адрес», «сделать снимок экрана страницы», «извлечь данные из HTML», «сканировать сайт», «управлять браузером с помощью Playwright/CDP», «обойти антибот» или выполнить любую задачу, включающую команду Scrapfly.
