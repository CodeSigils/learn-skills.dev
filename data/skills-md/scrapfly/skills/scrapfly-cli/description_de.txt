Verwenden Sie die Scrapfly-CLI („scrapfly“), um Webseiten zu scrappen, Screenshots zu erfassen, strukturierte Daten mit KI zu extrahieren, ganze Websites zu crawlen und einen Cloud-Browser über CDP von einer Shell aus zu steuern. JSON-Umschlag auf stdout für jeden Befehl. Wird verwendet, wenn der Benutzer „eine URL scrapen“, „einen Screenshot einer Seite machen“, „Daten aus HTML extrahieren“, „eine Website crawlen“, „einen Browser mit Playwright/CDP steuern“, „Anti-Bot umgehen“ oder eine andere Aufgabe mit dem „scrapfly“-Befehl ausführen möchte.
