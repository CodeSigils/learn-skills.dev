استخدم Scrapfly CLI (`scrapfly`) لاستخراج صفحات الويب، والتقاط لقطات الشاشة، واستخراج البيانات المنظمة باستخدام الذكاء الاصطناعي، والزحف إلى المواقع بأكملها، وتشغيل متصفح سحابي عبر CDP من الصدفة. مغلف JSON على stdout لكل أمر. يُستخدم عندما يطلب المستخدم "نسخ عنوان URL"، أو "لقطة شاشة لصفحة"، أو "استخراج البيانات من HTML"، أو "الزحف إلى موقع"، أو "قيادة المتصفح باستخدام Playwright/CDP"، أو "تجاوز برنامج مكافحة الروبوت"، أو أي مهمة تتضمن الأمر `scrapfly`.
