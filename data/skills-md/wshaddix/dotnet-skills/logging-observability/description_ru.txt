Шаблоны ведения журналов и наблюдения производственного уровня для страниц ASP.NET Core Razor. Охватывает структурированное ведение журнала с помощью Serilog, идентификаторы корреляции, проверки работоспособности, ведение журнала запросов, интеграцию OpenTelemetry и передовые методы диагностики. Используйте при настройке структурированного ведения журнала в приложениях ASP.NET Core, реализации распределенной трассировки с помощью OpenTelemetry или настройке проверок работоспособности и наблюдаемости.
