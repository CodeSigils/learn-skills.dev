Richtlinien zum Organisieren von .NET-Projekten, einschließlich Lösungsstruktur, Projektverweisen, Ordnerkonventionen, .slnx-Format, zentralisierten Build-Eigenschaften und zentraler Paketverwaltung. Verwenden Sie es, wenn Sie eine neue .NET-Lösung mit modernen Best Practices einrichten, zentralisierte Build-Eigenschaften über mehrere Projekte hinweg konfigurieren, eine zentrale Paketversionsverwaltung implementieren oder SourceLink zum Debuggen einrichten.
