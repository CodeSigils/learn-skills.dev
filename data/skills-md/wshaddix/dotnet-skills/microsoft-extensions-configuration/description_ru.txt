Шаблоны конфигурации с использованием Microsoft.Extensions.Configuration. Охватывает поставщиков конфигурации, привязку, проверку и лучшие практики для приложений .NET. Используйте при настройке конфигурации в приложениях .NET, реализации проверки конфигурации с помощью IValidateOptions или управлении параметрами в различных средах.
