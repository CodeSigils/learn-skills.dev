قم بإنشاء ملفات Dockerfiles وتحسينها باستخدام BuildKit والإنشاءات متعددة المراحل والتخزين المؤقت المتقدم والأمان. استخدم هذه المهارة عندما تحتاج إلى إنشاء أو تعديل أو تحسين ملف Dockerfile أو ملف Docker Compose. يتم تشغيله أيضًا عندما يناقش المستخدم صور الحاوية، أو أداء البناء، أو أمان Docker - حتى إذا لم يذكر "Dockerfile" صراحةً.
