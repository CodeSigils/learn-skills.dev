從主機（本機或透過 SSH）建立、設定和編輯 OpenClaw 代理程式。每當用戶想要新增新的 OpenClaw 代理程式、為企業或組織建置代理程式（客戶服務、內部服務台、預訂機器人等）、鷹架代理程式工作區檔案（SOUL.md / AGENTS.md / IDENTITY.md / USER.md）、有線通道（LINE / WhatsApp / Discord / Telegram /ack 等代理(RAG)、強化代理以防止提示注入和身分混淆時，都可以使用此功能，或編輯/重新配置/重新調整現有的 OpenClaw 代理程式。觸發任何提及 OpenClaw 代理、openclaw.json、代理綁定、代理工作區、「新增代理」、「建置機器人」、「編一個代理」、「做一個客服機器人」的行為 - 以及每當工作主機中存在 ~/.openclaw 或 openclaw.json 文件時觸發，即使 OpenClaw 未命名。
