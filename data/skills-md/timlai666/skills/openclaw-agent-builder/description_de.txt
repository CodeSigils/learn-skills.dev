Erstellen, konfigurieren und bearbeiten Sie OpenClaw-Agenten von einem Host-Computer aus (lokal oder über SSH). Verwenden Sie dies immer dann, wenn der Benutzer einen neuen OpenClaw-Agenten hinzufügen, einen Agenten für ein Unternehmen oder eine Organisation erstellen (Kundenservice, interner Helpdesk, Buchungs-Bot usw.), Arbeitsbereichsdateien für Agenten (SOUL.md / AGENTS.md / IDENTITY.md / USER.md), Wire-Kanäle (LINE / WhatsApp / Discord / Telegram / Slack und andere) und Bindungen erstellen, eine Agenten-Wissensdatenbank (RAG) einrichten, einen Agenten gegen Prompt-Injection und Identitätsverwechslungen absichern oder bearbeiten möchte / einen vorhandenen OpenClaw-Agenten neu konfigurieren/abstimmen. Wird bei jeder Erwähnung von OpenClaw-Agenten, openclaw.json, Agent-Bindungen, Agent-Arbeitsbereich, „Add an agent“, „Build a bot“, „編一個 agent“, „做一個客服 bot“ ausgelöst – und auch immer dann, wenn ~/.openclaw oder eine openclaw.json-Datei im Arbeitshost vorhanden ist, auch wenn OpenClaw nicht benannt ist.
