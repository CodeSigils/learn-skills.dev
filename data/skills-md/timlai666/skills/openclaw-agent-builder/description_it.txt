Crea, configura e modifica gli agenti OpenClaw da una macchina host (localmente o tramite SSH). Utilizzalo ogni volta che l'utente desidera aggiungere un nuovo agente OpenClaw, creare un agente per un'azienda o un'organizzazione (servizio clienti, helpdesk interno, bot di prenotazione, ecc.), file dell'area di lavoro dell'agente scaffold (SOUL.md / AGENTS.md / IDENTITY.md / USER.md), canali cablati (LINE / WhatsApp / Discord / Telegram / Slack e altri) e collegamenti, impostare una base di conoscenza dell'agente (RAG), rafforzare un agente contro l'iniezione tempestiva e la confusione dell'identità, o modificare/riconfigurare/risintonizzare un agente OpenClaw esistente. Si attiva su qualsiasi menzione di agenti OpenClaw, openclaw.json, associazioni di agenti, area di lavoro dell'agente, "aggiungi un agente", "crea un bot", "agente 編一個", "做一個客服 bot" e anche ogni volta che ~/.openclaw o un file openclaw.json è presente nell'host funzionante anche se OpenClaw non è nominato.
