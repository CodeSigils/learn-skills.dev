호스트 머신에서(로컬로 또는 SSH를 통해) OpenClaw 에이전트를 생성, 구성 및 편집합니다. 사용자가 새로운 OpenClaw 에이전트를 추가하고, 비즈니스 또는 조직을 위한 에이전트(고객 서비스, 내부 헬프 데스크, 예약 봇 등), 스캐폴드 에이전트 작업 공간 파일(SOUL.md / AGENTS.md / IDENTITY.md / USER.md), 유선 채널(LINE / WhatsApp / Discord / Telegram / Slack 등) 및 바인딩을 구축하고, 에이전트 지식 베이스(RAG)를 설정하고, 프롬프트 주입에 대해 에이전트를 강화하고, 신원 혼란을 방지하거나 기존 OpenClaw 에이전트를 편집/재구성/재조정할 수 있습니다. OpenClaw 에이전트, openclaw.json, 에이전트 바인딩, 에이전트 작업 영역, "에이전트 추가", "봇 빌드", "編一個 에이전트", "做一個客服 봇"에 대한 언급이 있을 때마다 트리거됩니다. 또한 OpenClaw의 이름이 지정되지 않은 경우에도 ~/.openclaw 또는 openclaw.json 파일이 작업 호스트에 존재할 때마다 트리거됩니다.
