Créez, configurez et modifiez les agents OpenClaw à partir d'une machine hôte (localement ou via SSH). Utilisez-le chaque fois que l'utilisateur souhaite ajouter un nouvel agent OpenClaw, créer un agent pour une entreprise ou une organisation (service client, service d'assistance interne, robot de réservation, etc.), des fichiers d'espace de travail d'agent d'échafaudage (SOUL.md / AGENTS.md / IDENTITY.md / USER.md), des canaux filaires (LINE / WhatsApp / Discord / Telegram / Slack et autres) et des liaisons, configurer une base de connaissances d'agent (RAG), renforcer un agent contre l'injection rapide et la confusion d'identité, ou modifier/reconfigurer/réajuster un agent OpenClaw existant. Déclenchez toute mention d'agents OpenClaw, openclaw.json, liaisons d'agent, espace de travail d'agent, "ajouter un agent", "créer un bot", "編一個 agent", "做一個客服 bot" - et également chaque fois que ~/.openclaw ou un fichier openclaw.json est présent dans l'hôte de travail même si OpenClaw n'est pas nommé.
