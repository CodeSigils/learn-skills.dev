إنشاء وتكوين وتحرير وكلاء OpenClaw من جهاز مضيف (محليًا أو عبر SSH). استخدم هذا عندما يريد المستخدم إضافة وكيل OpenClaw جديد، وإنشاء وكيل لشركة أو مؤسسة (خدمة العملاء، ومكتب المساعدة الداخلي، وروبوت الحجز، وما إلى ذلك)، وملفات مساحة عمل وكيل السقالة (SOUL.md / AGENTS.md / IDENTITY.md / USER.md)، والقنوات السلكية (LINE / WhatsApp / Discord / Telegram / Slack وغيرها) والروابط، وإعداد قاعدة معارف الوكيل (RAG)، وتقوية الوكيل ضد الحقن الفوري و ارتباك الهوية، أو تحرير / إعادة تكوين / إعادة ضبط وكيل OpenClaw الموجود. قم بتشغيل أي ذكر لوكلاء OpenClaw، وopenclaw.json، وروابط الوكيل، ومساحة عمل الوكيل، و"إضافة وكيل"، و"إنشاء روبوت"، و"وكيل 編一個"، و"روبوت bot" - وأيضًا عندما يكون ~/.openclaw أو ملف openclaw.json موجودًا في المضيف العامل حتى لو لم يتم تسمية OpenClaw.
