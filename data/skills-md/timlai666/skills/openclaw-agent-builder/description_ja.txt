ホスト マシンから (ローカルまたは SSH 経由で) OpenClaw エージェントを作成、構成、編集します。ユーザーが新しい OpenClaw エージェントの追加、ビジネスまたは組織のエージェントの構築 (カスタマー サービス、内部ヘルプデスク、予約ボットなど)、エージェント ワークスペース ファイル (SOUL.md / AGENTS.md / IDENTITY.md / USER.md)、ワイヤー チャネル (LINE / WhatsApp / Discord / Telegram / Slack など) およびバインディングの足場、エージェント ナレッジ ベース (RAG) のセットアップ、プロンプトに対するエージェントの強化を希望する場合は常にこれを使用します。インジェクションと ID の混乱、または既存の OpenClaw エージェントの編集/再構成/再調整。 OpenClaw エージェント、openclaw.json、エージェント バインディング、エージェント ワークスペース、「エージェントの追加」、「ボットの構築」、「編一個エージェント」、「做一個客服ボット」に関する言及があった場合にトリガーされます。また、OpenClaw という名前が付けられていない場合でも、~/.openclaw または openclaw.json ファイルが動作中のホストに存在する場合にもトリガーされます。
