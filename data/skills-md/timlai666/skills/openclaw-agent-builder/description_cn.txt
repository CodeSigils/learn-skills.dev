从主机（本地或通过 SSH）创建、配置和编辑 OpenClaw 代理。每当用户想要添加新的 OpenClaw 代理、为企业或组织构建代理（客户服务、内部帮助台、预订机器人等）、脚手架代理工作区文件（SOUL.md / AGENTS.md / IDENTITY.md / USER.md）、有线通道（LINE / WhatsApp / Discord / Telegram / Slack 等）和绑定、设置代理知识库 (RAG)、强化代理以防止提示注入和身份混淆时，都可以使用此功能，或编辑/重新配置/重新调整现有的 OpenClaw 代理。触发任何提及 OpenClaw 代理、openclaw.json、代理绑定、代理工作区、“添加代理”、“构建机器人”、“编一个代理”、“做一个客服机器人”的行为 - 以及每当工作主机中存在 ~/.openclaw 或 openclaw.json 文件时触发，即使 OpenClaw 未命名。
