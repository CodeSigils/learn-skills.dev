Cree, configure y edite agentes OpenClaw desde una máquina host (localmente o a través de SSH). Utilice esto siempre que el usuario desee agregar un nuevo agente OpenClaw, crear un agente para una empresa u organización (servicio al cliente, servicio de asistencia interna, robot de reservas, etc.), archivos de espacio de trabajo del agente (SOUL.md / AGENTS.md / IDENTITY.md / USER.md), canales de conexión (LINE / WhatsApp / Discord / Telegram / Slack y otros) y enlaces, configurar una base de conocimiento del agente (RAG), fortalecer un agente contra la inyección rápida y la confusión de identidad. o editar/reconfigurar/recalibrar un agente OpenClaw existente. Se activa ante cualquier mención de agentes OpenClaw, openclaw.json, enlaces de agentes, espacio de trabajo del agente, "agregar un agente", "crear un bot", "編一個 agente", "做一個客服 bot", y también cuando ~/.openclaw o un archivo openclaw.json esté presente en el host de trabajo, incluso si OpenClaw no tiene nombre.
