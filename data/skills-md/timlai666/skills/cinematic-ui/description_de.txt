Entwerfen und erstellen Sie filminspirierte visuelle Arbeiten – Websites UND PowerPoint-Präsentationen (.pptx). Verwenden Sie diese Option, wenn der Benutzer nach einer filmischen Website, einer Landingpage im Filmstil, einer vom Regisseur inspirierten Benutzeroberfläche, Film Noir, Science-Fiction, Romantik, Thriller, Action, Animation oder einer filmähnlichen Webästhetik fragt. Verwenden Sie es auch, wenn der Benutzer eine Präsentation, ein Deck oder eine Präsentation mit einem filmischen oder redaktionellen visuellen System neu gestalten möchte oder /cinematic-ui vor einer folienbezogenen Anfrage verwendet. Auslöser auf filmischer Website, filmischem Deck, Filmmaterial, Filmmaterial, redaktioneller Präsentation, Wes Anderson-Folien, noir pptx oder einer beliebigen Kombination aus Filmsprache mit Folien/Deck/pptx/Bild/Bild. Nicht für generisches Webdesign oder generisches Foliendesign verwenden, es sei denn, der Benutzer möchte ausdrücklich eine Film- oder Regisseurreferenz.
