Utilice esta habilidad cuando el usuario tenga archivos de reseñas de productos y desee: (1) calificar cada reseña en un conjunto de atributos utilizando una escala de prominencia (0 a 7) y exportar una matriz de reseña × atributo como .xlsx; (2) ejecutar PCA para reducir los atributos a dimensiones latentes; (3) agrupar reseñas en segmentos de clientes con K-means. Activar solicitudes como 「逐則評論評分」、「顯著度矩陣」、「salience scoring」、「主成分分析」、 「PCA」、「顧客分群」、「K-means」、「評論×屬性 Excel」, o cualquier combinación de los mismos. También se activa cuando este paso sigue un flujo de trabajo de descubrimiento de atributos y el usuario desea datos puntuados, reducción de dimensionalidad o segmentación. Utilice esta habilidad incluso si el usuario solo menciona parte del proceso.
