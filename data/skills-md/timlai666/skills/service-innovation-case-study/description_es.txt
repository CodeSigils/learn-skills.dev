Ejecute un informe completo de estudio de caso de innovación de servicios, aplicable a cualquier marca, aplicación, plataforma o servicio. Comenzando con la investigación de antecedentes de la empresa, complete secuencialmente un mapa del ecosistema, PESTEL, Five Forces, SWOT, STP, Business Model Canvas (BMC), personalidad del cliente, plan de servicio, mapa del recorrido del cliente (CJM) y, finalmente, la evaluación del efecto de creación y la extracción de conocimientos subyacentes, entregando el resultado completo como un informe Markdown estructurado.

Escenarios aplicables:
- El usuario solicita "Ayúdame a investigar la marca/servicio/aplicación X".
- El usuario proporciona los requisitos del formato del aula (nombre del caso, tipo de innovación, público objetivo, etc.) y solicita un análisis completo.
- El usuario dice "Crea un análisis de caso como Doji".
- El usuario solicita PESTEL, SWOT, STP, BMC o cualquier combinación de marcos de análisis para la innovación de servicios.
- El usuario carga diapositivas o capturas de pantalla del aula y solicita un análisis según el formato.

Documentos de referencia obligatorios (cargue según sea necesario):
- `references/01-research-protocol.md` — Estándares de verificación de datos y proceso de validación de fuentes
- `references/02-analysis-chain.md` — Lógica completa de la cadena de análisis (PESTEL → Five Forces → SWOT → STP → BMC → Persona → Blueprint → CJM)
- `references/03-section-specs.md` — Especificaciones detalladas y estándares de calidad para cada sección del informe
- `references/04-quality-checklist.md` — Lista de autocomprobación antes de la salida
- `assets/report-template.md` — Plantilla de informe en blanco

Antes de comenzar cada nuevo caso, primero lea `references/01-research-protocol.md` y `references/02-analysis-chain.md`.

Por favor responda siempre en el idioma del usuario.
