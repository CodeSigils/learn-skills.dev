Suite de revisión para cualquier proyecto de software. Modos: código (revisión lógica y de diferencias), diseño (auditoría de calidad UI/UX), seguridad (exploración de vulnerabilidades y superficies de amenazas). Se activa cuando se revisa un PR o una diferencia, se audita la calidad de la interfaz de usuario o se verifican problemas de seguridad antes de fusionarlos o enviarlos.
