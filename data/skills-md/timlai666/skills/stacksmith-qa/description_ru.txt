Процесс контроля качества для любого программного проекта. В режиме по умолчанию выполняется полный цикл «тестирование-исправление-проверка»; Доступны только отчеты и быстрые варианты. Срабатывает при запуске тестов, проверке исправления ошибки, проверке покрытия тестами или выполнении этапа контроля качества перед выпуском.
