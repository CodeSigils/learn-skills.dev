Flujo de control de calidad para cualquier proyecto de software. El modo predeterminado ejecuta el ciclo completo de prueba-reparación-verificación; Variantes rápidas y de solo informe disponibles. Se activa cuando se ejecutan pruebas, se verifica una corrección de errores, se audita la cobertura de las pruebas o se realiza una prueba de control de calidad antes de un lanzamiento.
