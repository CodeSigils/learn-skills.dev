يُستخدم عند إنشاء صفحات مقصودة عالية التحويل مع تأثيرات مرئية حديثة، بما في ذلك الرسوم المتحركة SVG/WebGL وتحسين التكرار المتعدد المستقل وأوضاع الإخراج المزدوجة (ملف HTML فردي أو مشروع React). تشغيل طلبات مثل الصفحة المقصودة، أو LP، أو إنشاء قسم البطل، أو صفحة التسويق المتحركة، أو إعادة تصميم صفحة التحويل، أو متغيرات النمط A-L/مخصص.
