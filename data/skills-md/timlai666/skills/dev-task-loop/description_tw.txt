當使用者想要使用已知專案/分支/合併目標/任務追蹤器/設計參考工作流程端對端處理積壓的開發票證，但不提交到任何特定平台（Jira / Linear / GitHub Issues / Notion / Figma / Zeplin /等）時使用。觸發諸如「幫我跑任務」、「照我的流程把積壓做完」、「審核失敗的全部處理掉」、「用我那套開發流程做事」、「處理我的任務清單」、「執行我的開發循環」、「端對端處理我的工單」等請求。請務必預先詢問使用者項目根、工作分支、合併目標、任務清單位置、設計參考位置以及如何標記任務已完成 - 然後循環執行票證實施 → 驗證 → 提交 → 開啟 PR → 合併 → 同步 → 更新追蹤器。切勿烘焙特定於平台的 API 呼叫；在運行時從使用者的答案中找出這些內容。
