Используйте, когда пользователь хочет обработать накопившиеся заявки на разработку сквозным образом с известным проектом/ветвью/целью слияния/отслеживанием задач/эталонным рабочим процессом проектирования, но без привязки к какой-либо конкретной платформе (Jira/Linear/GitHub Issues/Notion/Figma/Zeplin/и т. д.). Запуск по таким запросам, как 「幫我跑任務」、「照我的流程把 невыполненная работа 做完」、「не удалось просмотреть的全部處理掉」、「用我那套開發流程做事」、"работать с моим списком задач", "запустить цикл разработки", "сквозная обработка моих заявок". Всегда заранее запрашивает у пользователя корень проекта, рабочую ветвь, цель слияния, расположение списка задач, расположение ссылки на проект и способ пометки задачи как выполненную — затем последовательно выполняет реализацию заявок → проверку → фиксацию → открытие PR → слияние → синхронизацию → обновление трекера. Никогда не добавляйте вызовы API, специфичные для платформы; выясните это во время выполнения из ответов пользователя.
