当用户想要使用已知项目/分支/合并目标/任务跟踪器/设计参考工作流程端到端处理积压的开发票证，但不提交到任何特定平台（Jira / Linear / GitHub Issues / Notion / Figma / Zeplin /等）时使用。触发诸如「帮我跑任务」、「照我的流程把积压做完」、「审核失败的全部处理掉」、「用我那套开发流程做事」、「处理我的任务列表」、「运行我的开发循环」、「端到端处理我的工单」等请求。始终预先询问用户项目根、工作分支、合并目标、任务列表位置、设计参考位置以及如何标记任务已完成 - 然后循环执行票证实施 → 验证 → 提交 → 打开 PR → 合并 → 同步 → 更新跟踪器。切勿烘焙特定于平台的 API 调用；在运行时从用户的答案中找出这些内容。
