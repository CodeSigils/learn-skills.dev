Набор инструментов для отладки Android ADB со сценариями автоматизации. Интеллектуальная фильтрация logcat по пакету/тегу/уровню, снимку экрана, записи экрана, экспорту данных приложения (SharedPreferences, база данных), профилированию памяти/ЦП. Используйте при отладке приложений Android, записи журналов, создании снимков экрана, записи экрана, выгрузке данных приложений, проверке информации об устройстве, профилировании производительности. Охватывает управление устройствами, установку/удаление приложений, команды оболочки, намеренное срабатывание. Работает с эмулятором и физическими устройствами. Чистый bash — никаких зависимостей.
