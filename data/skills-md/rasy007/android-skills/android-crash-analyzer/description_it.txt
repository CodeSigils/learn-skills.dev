Registro degli arresti anomali di Android e analizzatore di stacktrace ANR. Analizza stacktrace di crash, identifica il tipo di crash (NPE, OOM, ANR, SecurityException), estrae fotogrammi chiave, trova la causa principale, genera suggerimenti di correzione. Da utilizzare quando l'utente incolla registri di arresti anomali, errori logcat, tracce ANR, file contrassegnati per rimozione definitiva, OutOfMemoryError, NullPointerException, ClassNotFoundException, segnale irreversibile, SIGSEGV, arresto anomalo nativo, violazione StrictMode. Supporta eccezioni Java/Kotlin, arresti anomali nativi, tracce ANR. Zero dipendenze esterne: libreria standard Python pura.
