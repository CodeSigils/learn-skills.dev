Android Gradle build problem diagnosis and optimization tool. Analyze dependency conflicts, detect version mismatches, scan build.gradle issues, generate optimization suggestions for faster builds. Use when build fails, dependency conflict, version mismatch, slow build, Gradle sync error, duplicate class, incompatible library versions, Could not resolve, Configuration cache, build cache, parallel execution. Supports build.gradle (Groovy) and build.gradle.kts (Kotlin DSL). Analyzes ./gradlew dependencies output, checks common misconfigurations. Zero external dependencies — pure Python standard library.
