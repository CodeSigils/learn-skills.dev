Система мониторинга состояния работы агентов и автоматической активации. Срабатывает при мониторинге состояния выполнения субагента, обнаружении длительных состояний «зависания» без ответа и их автоматической активации для возобновления работы. Подходит для мониторинга длительных задач, автоматизированных операций, проверки работоспособности агентов и подобных сценариев.
