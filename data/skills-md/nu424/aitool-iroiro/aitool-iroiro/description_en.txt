Skill for using the set of tools (aitool-iroiro) that execute multimodal AI tasks from the CLI via the OpenRouter API / Google GenAI API.  
When image generation, image recognition, video understanding, speech‑to‑text, or speech synthesis is needed, or when a task that uses the `aitool` command arises, always refer to this skill.  
Specifically, requests such as “edit an image,” “summarize this video,” “convert this audio to text,” “read the text aloud,” “describe the image,” etc., are the target.
