Fertigkeit zur Verwendung der Tools (aitool-iroiro), die multimodale KI-Aufgaben von der CLI über die OpenRouter API / Google GenAI API ausführen.  
Wenn Bilderzeugung, Bilderkennung, Videoverständnis, Sprache-zu-Text oder Sprachsynthese erforderlich sind oder wenn eine Aufgabe entsteht, die den Befehl „aitool“ verwendet, greifen Sie immer auf diese Fähigkeit zurück.  
Insbesondere Anfragen wie „Bild bearbeiten“, „Dieses Video zusammenfassen“, „Audio in Text umwandeln“, „Text laut vorlesen“, „Bild beschreiben“ usw. sind das Ziel.
