Habilidad para el uso del conjunto de herramientas (aitool-iroiro) que ejecutan tareas de IA multimodal desde la CLI a través de la API OpenRouter / API Google GenAI.  
Cuando sea necesaria la generación de imágenes, el reconocimiento de imágenes, la comprensión de videos, la conversión de voz a texto o la síntesis de voz, o cuando surja una tarea que utilice el comando "aitool", consulte siempre esta habilidad.  
Específicamente, solicitudes como "editar una imagen", "resumir este video", "convertir este audio en texto", "leer el texto en voz alta", "describir la imagen", etc., son el objetivo.
