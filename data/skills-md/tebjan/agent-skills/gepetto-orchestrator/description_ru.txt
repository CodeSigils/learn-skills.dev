Организует и консультирует занятия по планированию Gepetto. Используйте, когда пользователь хочет тщательно спланировать функцию перед кодированием, спрашивает: «Должен ли я использовать для этого Gepetto?», хочет создать файл спецификации для Gepetto или не знает, что делать с выходными данными Gepetto. Помогает оценить, стоит ли вложений полный 17-шаговый конвейер Gepetto, составляет проект файла спецификации, направляет пользователя через рабочий процесс и дает рекомендации по выполнению полученного плана (вручную, ralph-loop или Ralphy CLI). Коротко о контексте: Gepetto сама берет на себя тяжелую работу через субагентов.
