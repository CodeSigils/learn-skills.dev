Orchestra e fornisce consulenza sulle sessioni di pianificazione di Gepetto. Da utilizzare quando l'utente vuole pianificare accuratamente una funzionalità prima di scrivere il codice, chiede "devo usare Gepetto per questo?", vuole creare un file di specifiche per Gepetto o non è sicuro di cosa fare con l'output di Gepetto. Aiuta a valutare se l'intera pipeline in 17 passaggi di Gepetto vale l'investimento, redige il file delle specifiche, guida l'utente attraverso il flusso di lavoro e consiglia come eseguire il piano risultante (manuale, Ralph-loop o Ralphy CLI). Mantiene il contesto breve: Gepetto stesso gestisce il lavoro pesante tramite subagenti.
