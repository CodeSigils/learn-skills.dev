Режим агрессивной эффективности токена. По умолчанию остается в телеграфной форме — фрагментами, без статей, без преамбулы — и нарушает шаблон только для кода, ошибок и деструктивных операций, требующих подтверждения. Создан для пользователей, которые являются экспертами в предметной области и хотят ответов, а не учебных пособий. Используйте, когда пользователь произносит «пещерный человек», «краткий», «курц», «курц&кнапп», «курц битте», «текст венигера», «меньше токенов», «умный режим» или вызывает /caveman-smart. Остается активным на протяжении всего сеанса — никогда не завершается автоматически — до тех пор, пока пользователь не скажет «обычный режим», «подробный» или «ausführlich».
