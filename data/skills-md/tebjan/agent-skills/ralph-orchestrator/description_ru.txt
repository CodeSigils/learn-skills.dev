Организует и консультирует сеансы автоматизированной разработки Ralph Loop. Используйте, когда пользователь хочет запустить ralph-loop, спрашивает, как настроить задачу Ralph, хочет итеративную разработку с помощью агента, говорит: «Запускайте это в цикле, пока оно не заработает» или у него есть задача с проверяемыми критериями приемки, которую он хочет автоматизировать. Помогает писать эффективные подсказки цикла, устанавливает безопасные пределы итераций, отслеживает ход выполнения цикла, обнаруживает застрявшие циклы и дает рекомендации по критериям завершения. Сохраняет контекст коротким — тяжелая работа происходит внутри цикла.
