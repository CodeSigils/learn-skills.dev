ينسق تطوير البرامج الشاملة باستخدام إطار مهارات addyosmani/agent. يرشد المستخدم من خلال التحديد ← الخطة ← البناء ← التحقق ← المراجعة ← مراحل الشحن، وإنشاء وكلاء فرعيين لكل خطوة، وتتبع الحالة باستمرار، ولا يفقد التركيز أبدًا على إكمال سير العمل. يُستخدم عندما يقول المستخدم "دعونا نبني X"، أو "ساعدني في تنفيذ X"، أو "أرشدني خلال X"، أو يريد إرشادات تطوير منظمة متعددة المراحل. يتم تشغيله أيضًا عندما تكون المهمة غير تافهة بشكل واضح وتستفيد من التنفيذ المرحلي.
