Orquesta el desarrollo de software de un extremo a otro utilizando el marco addyosmani/agent-skills. Guía al usuario a través de las fases de definir → planificar → construir → verificar → revisar → enviar, genera subagentes para cada paso, rastrea el estado de manera persistente y nunca pierde el enfoque en la finalización del flujo de trabajo. Úselo cuando el usuario diga "construyamos X", "ayúdeme a implementar X", "guíeme a través de X" o quiera una guía de desarrollo estructurada de varias fases. También se activa cuando una tarea claramente no es trivial y se beneficiaría de una ejecución por fases.
