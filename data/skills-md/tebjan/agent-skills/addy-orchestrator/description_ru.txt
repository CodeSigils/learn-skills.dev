Организует комплексную разработку программного обеспечения с использованием платформы addyosmani/agent-skills. Проводит пользователя через этапы определения → планирования → сборки → проверки → проверки → поставки, запускает субагенты для каждого шага, постоянно отслеживает состояние и никогда не теряет внимания к завершению рабочего процесса. Используйте, когда пользователь говорит «давайте создадим X», «помогите мне реализовать X», «проведите меня через X» или хочет получить структурированное многоэтапное руководство по разработке. Также срабатывает, когда задача явно нетривиальна и требует поэтапного выполнения.
