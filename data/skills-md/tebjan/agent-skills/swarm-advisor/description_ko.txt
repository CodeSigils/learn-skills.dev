Claude Code의 TeammateTool 및 작업 시스템을 사용하여 다중 에이전트 군집 설계에 대해 조언합니다. 사용자가 에이전트 전체에서 작업을 병렬화하려고 하거나, '이 작업을 위해 떼를 사용해야 하나요?'라고 묻고, 팀 토폴로지 설계에 도움이 필요하고, 작업을 병렬 작업 스트림으로 나누어야 하거나, 떼 조정을 시작하는 경우에 사용하세요. 떼가 오버헤드를 감당할 가치가 있는지 평가하고, 팀 규모와 구조를 권장하며, 올바른 종속성을 사용하여 작업을 분해하는 데 도움을 주고, 떼 상태를 추적합니다. '생성하기 전에 생각하기' 레이어를 추가하여 떼 조정 기술을 보완합니다.
