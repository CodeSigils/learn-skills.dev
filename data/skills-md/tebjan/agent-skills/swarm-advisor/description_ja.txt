Claude Code の TeammateTool とタスク システムを使用したマルチエージェント群の設計についてアドバイスします。ユーザーがエージェント間で作業を並列化したい場合、「これには swarm を使用する必要があるか?」と尋ねる場合、チーム トポロジの設計を支援したい場合、タスクを並列ワークストリームに分割する必要がある場合、または swarm オーケストレーションを始めている場合に使用します。 swarm がオーバーヘッドに見合う価値があるかどうかを評価し、チームのサイズと構造を推奨し、正しい依存関係を持つタスクの分解を支援し、swarm の健全性を追跡します。 「スポーン前に考える」レイヤーを追加することで、群れのオーケストレーション スキルを補完します。
