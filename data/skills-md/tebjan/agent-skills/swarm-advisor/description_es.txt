Asesora sobre el diseño de enjambres de múltiples agentes utilizando el sistema TeammateTool y Task de Claude Code. Úselo cuando el usuario quiera paralelizar el trabajo entre agentes, pregunte "¿debería usar un swarm para esto?", necesite ayuda para diseñar la topología del equipo, necesite dividir una tarea en flujos de trabajo paralelos o esté comenzando con la orquestación de swarm. Evalúa si vale la pena los gastos generales de un enjambre, recomienda el tamaño y la estructura del equipo, ayuda a descomponer las tareas con las dependencias correctas y realiza un seguimiento del estado del enjambre. Complementa la habilidad de orquestación de enjambres añadiendo la capa "piensa antes de generar".
