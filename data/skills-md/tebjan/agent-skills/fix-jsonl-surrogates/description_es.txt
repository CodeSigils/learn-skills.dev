Diagnosticar y reparar errores de API de 'suplente alto no válido' en sesiones de chat de Claude Code. Utilice esta habilidad cuando el usuario encuentre el error API 400 con "suplente alto no válido en cadena", "JSON no válido", errores relacionados con el sustituto o quiera arreglar/escanear/reparar un archivo de chat JSONL de Claude Code roto. Utilícelo también cuando una sesión se niegue a reanudarse debido a errores de codificación JSON o cuando el usuario mencione los ID de solicitud (req_...) junto con errores de análisis de JSON.
