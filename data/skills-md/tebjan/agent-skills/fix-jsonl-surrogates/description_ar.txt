تشخيص وإصلاح أخطاء واجهة برمجة التطبيقات "بديلة عالية غير صالحة" في جلسات محادثة Claude Code. استخدم هذه المهارة عندما يواجه المستخدم خطأ API 400 مع "بديل عالي غير صالح في السلسلة"، أو "JSON غير صالح"، أو أخطاء متعلقة بالبديل، أو يريد إصلاح/مسح/إصلاح ملف دردشة Claude Code JSONL معطل. يُستخدم أيضًا عندما ترفض الجلسة الاستئناف بسبب أخطاء ترميز JSON، أو عندما يذكر المستخدم معرفات الطلب (req_...) إلى جانب فشل تحليل JSON.
