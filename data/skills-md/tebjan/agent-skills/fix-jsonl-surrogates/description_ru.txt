Диагностика и исправление ошибок API «неверный высокий суррогат» в сеансах чата Claude Code. Используйте этот навык, когда пользователь сталкивается с ошибкой API 400 с «недопустимым старшим суррогатным кодом в строке», «недопустимым JSON», ошибками, связанными с суррогатным кодом, или хочет исправить/сканировать/восстановить испорченный файл чата Claude Code JSONL. Также используйте, когда сеанс отказывается возобновить из-за ошибок кодирования JSON или когда пользователь упоминает идентификаторы запросов (req_...) наряду с ошибками анализа JSON.
