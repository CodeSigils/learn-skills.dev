Diagnostiquer et réparer les erreurs d'API « de substitution élevée non valide » dans les sessions de discussion Claude Code. Utilisez cette compétence lorsque l'utilisateur rencontre l'erreur API 400 avec « substitut élevé non valide dans la chaîne », « JSON non valide », des erreurs liées au substitut, ou lorsqu'il souhaite réparer/analyser/réparer un fichier de discussion Claude Code JSONL cassé. À utiliser également lorsqu'une session refuse de reprendre en raison d'erreurs d'encodage JSON, ou lorsque l'utilisateur mentionne les ID de demande (req_...) à côté des échecs d'analyse JSON.
