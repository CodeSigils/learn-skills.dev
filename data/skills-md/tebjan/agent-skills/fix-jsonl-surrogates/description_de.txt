Diagnostizieren und reparieren Sie „ungültige hohe Ersatzwerte“-API-Fehler in Claude Code-Chatsitzungen. Verwenden Sie diesen Skill, wenn der Benutzer auf API-Fehler 400 mit „ungültiger hoher Ersatzwert in der Zeichenfolge“, „nicht gültiger JSON“ oder Ersatzfehler stößt oder eine defekte Claude Code JSONL-Chat-Datei reparieren/scannen/reparieren möchte. Wird auch verwendet, wenn eine Sitzung aufgrund von JSON-Kodierungsfehlern nicht fortgesetzt werden kann oder wenn der Benutzer neben JSON-Analysefehlern auch Anforderungs-IDs (req_...) erwähnt.
