Diagnostica e ripara gli errori API "surrogato alto non valido" nelle sessioni di chat di Claude Code. Utilizza questa competenza quando l'utente riscontra l'errore API 400 con "surrogato alto non valido nella stringa", "JSON non valido", errori relativi al surrogato o desidera correggere/scansionare/riparare un file di chat JSONL del codice Claude danneggiato. Da utilizzare anche quando una sessione si rifiuta di riprendere a causa di errori di codifica JSON o quando l'utente menziona gli ID di richiesta (req_...) insieme agli errori di analisi JSON.
