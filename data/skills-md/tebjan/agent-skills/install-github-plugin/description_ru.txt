Устанавливает плагины Claude Code из репозиториев GitHub, в которых отсутствует манифест торговой площадки. Используйте этот навык всякий раз, когда установка плагина Claude завершается сбоем из-за ошибок ключа SSH, отсутствия .claude-plugin/marketplace.json или репозитория GitHub, который не был разработан как торговая площадка плагинов Claude. Также используйте, когда пользователь говорит «установить плагин из GitHub», «добавить навыки из репозитория» или «не удалось установить плагин». Осуществляет полный рабочий процесс: клонирование через gh CLI, проверку структуры репозитория, создание манифеста торговой площадки и запуск установки.
