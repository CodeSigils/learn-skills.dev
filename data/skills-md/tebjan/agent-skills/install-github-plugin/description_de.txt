Installiert Claude Code-Plugins von GitHub-Repos, denen ein Marktplatz-Manifest fehlt. Verwenden Sie diesen Skill immer dann, wenn eine „Claude-Plugin-Installation“ aufgrund von SSH-Schlüsselfehlern, fehlendem „.claude-plugin/marketplace.json“ oder einem GitHub-Repo, das nicht als Claude-Plugin-Marktplatz konzipiert wurde, fehlschlägt. Wird auch verwendet, wenn der Benutzer sagt: „Plugin von GitHub installieren“, „Skills aus einem Repo hinzufügen“ oder „Die Plugin-Installation ist fehlgeschlagen“. Verwaltet den gesamten Arbeitsablauf: Klonen über die GH-CLI, Überprüfen der Repo-Struktur, Generieren des Marktplatz-Manifests und Ausführen der Installation.
