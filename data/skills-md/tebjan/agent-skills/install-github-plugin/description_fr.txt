Installe les plugins Claude Code à partir des dépôts GitHub qui ne disposent pas d'un manifeste de marché. Utilisez cette compétence chaque fois qu'une « installation de plugin Claude » échoue en raison d'erreurs de clé SSH, de l'absence de « .claude-plugin/marketplace.json » ou d'un dépôt GitHub qui n'a pas été conçu comme un marché de plugins Claude. À utiliser également lorsque l'utilisateur dit « installer le plugin depuis GitHub », « ajouter des compétences à partir d'un dépôt » ou « l'installation du plugin a échoué ». Gère l'intégralité du flux de travail : clonage via gh CLI, inspection de la structure du dépôt, génération du manifeste du marché et exécution de l'installation.
