Instala complementos de Claude Code desde repositorios de GitHub que carecen de un manifiesto de mercado. Utilice esta habilidad siempre que falle una `instalación del complemento de Claude` debido a errores de clave SSH, falta `.claude-plugin/marketplace.json` o un repositorio de GitHub que no fue diseñado como un mercado de complementos de Claude. Utilícelo también cuando el usuario diga "instalar el complemento desde GitHub", "agregar habilidades desde un repositorio" o "falló la instalación del complemento". Maneja el flujo de trabajo completo: clonación a través de gh CLI, inspeccionando la estructura del repositorio, generando el manifiesto del mercado y ejecutando la instalación.
