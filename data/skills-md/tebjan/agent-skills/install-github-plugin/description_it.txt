Installa i plug-in Claude Code dai repository GitHub privi di un manifest del marketplace. Utilizza questa competenza ogni volta che un'installazione del plugin Claude fallisce a causa di errori della chiave SSH, della mancanza di `.claude-plugin/marketplace.json o di un repository GitHub che non è stato progettato come marketplace dei plugin Claude. Da utilizzare anche quando l'utente dice "installa plug-in da GitHub", "aggiungi competenze da un repository" o "installazione del plug-in non riuscita". Gestisce l'intero flusso di lavoro: clonazione tramite gh CLI, ispezione della struttura del repository, generazione del manifest del marketplace ed esecuzione dell'installazione.
