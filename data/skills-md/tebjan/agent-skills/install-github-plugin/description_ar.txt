تثبيت مكونات Claude Code الإضافية من مستودعات GitHub التي تفتقر إلى بيان السوق. استخدم هذه المهارة عندما يفشل "تثبيت المكون الإضافي claude" بسبب أخطاء في مفتاح SSH، أو فقدان ".claude-plugin/marketplace.json"، أو مستودع GitHub الذي لم يتم تصميمه ليكون سوقًا للمكونات الإضافية لـ Claude. استخدمه أيضًا عندما يقول المستخدم "تثبيت المكون الإضافي من GitHub"، أو "إضافة مهارات من الريبو"، أو "فشل تثبيت المكون الإضافي". يتعامل مع سير العمل بالكامل: الاستنساخ عبر gh CLI، وفحص بنية الريبو، وإنشاء بيان السوق، وتشغيل التثبيت.
