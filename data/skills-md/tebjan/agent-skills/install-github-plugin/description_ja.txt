マーケットプレイス マニフェストのない GitHub リポジトリから Claude Code プラグインをインストールします。 SSH キーのエラー、`.claude-plugin/marketplace.json` の欠落、または Claude プラグイン マーケットプレイスとして設計されていない GitHub リポジトリが原因で「claude プラグインのインストール」が失敗する場合は、必ずこのスキルを使用してください。ユーザーが「GitHub からプラグインをインストールする」、「リポジトリからスキルを追加する」、または「プラグインのインストールに失敗した」という場合にも使用します。完全なワークフローを処理します: gh CLI によるクローン作成、リポジトリ構造の検査、マーケットプレイス マニフェストの生成、インストールの実行。
