Servizio EAS (a pagamento). Distribuisci i siti Web Expo e i percorsi API Expo Router a EAS Hosting: esporta il pacchetto Web, esegui eas deploy per la produzione e gli URL di anteprima PR, gestisci i segreti dell'ambiente e i domini personalizzati e lavora all'interno del runtime Cloudflare Workers. Copre anche la creazione di percorsi API (+ gestori api.ts, metodi HTTP, gestione delle richieste, CORS). Da utilizzare durante la distribuzione di un'app Web Expo o percorsi API, l'impostazione di EAS Hosting o la configurazione di ambienti e domini di hosting. Non per build native o versioni dello store: utilizza la capacità eas-app-store per quelle.
