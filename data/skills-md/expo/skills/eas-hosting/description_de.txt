EAS-Service (kostenpflichtig). Stellen Sie Expo-Websites und Expo-Router-API-Routen für EAS-Hosting bereit – exportieren Sie das Webpaket, führen Sie EAS Deploy für Produktions- und PR-Vorschau-URLs aus, verwalten Sie Umgebungsgeheimnisse und benutzerdefinierte Domänen und arbeiten Sie innerhalb der Cloudflare Workers-Laufzeit. Behandelt auch das Erstellen von API-Routen (+api.ts-Handler, HTTP-Methoden, Anforderungsverarbeitung, CORS). Verwenden Sie diese Option, wenn Sie eine Expo-Web-App oder API-Routen bereitstellen, EAS-Hosting einrichten oder Hosting-Umgebungen und Domänen konfigurieren. Nicht für native Builds oder Store-Releases – verwenden Sie dafür den eas-app-stores-Skill.
