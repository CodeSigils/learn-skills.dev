EAS 서비스(유료)입니다. Expo 웹 사이트 및 Expo Router API 경로를 EAS 호스팅에 배포합니다. 웹 번들을 내보내고, 프로덕션 및 PR 미리 보기 URL에 대해 EAS 배포를 실행하고, 환경 비밀 및 사용자 지정 도메인을 관리하고, Cloudflare Workers 런타임 내에서 작업합니다. 또한 API 경로 작성(+api.ts 핸들러, HTTP 메소드, 요청 처리, CORS)을 다룹니다. Expo 웹 앱 또는 API 경로를 배포하거나 EAS 호스팅을 설정하거나 호스팅 환경 및 도메인을 구성할 때 사용합니다. 네이티브 빌드나 스토어 릴리스에는 적합하지 않습니다. 이에 대해서는 eas-app-stores 기술을 사용하세요.
