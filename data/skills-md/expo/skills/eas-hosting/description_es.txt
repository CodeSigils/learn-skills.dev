Servicio EAS (de pago). Implemente sitios web de Expo y rutas de API de Expo Router en EAS Hosting: exporte el paquete web, ejecute EAS Implementación para URL de vista previa de producción y relaciones públicas, administre secretos de entorno y dominios personalizados, y trabaje dentro del tiempo de ejecución de Cloudflare Workers. También cubre la creación de rutas API (+controladores api.ts, métodos HTTP, manejo de solicitudes, CORS). Úselo al implementar una aplicación web Expo o rutas API, configurar EAS Hosting o configurar entornos y dominios de hosting. No para compilaciones nativas o lanzamientos de tiendas; use la habilidad eas-app-stores para eso.
