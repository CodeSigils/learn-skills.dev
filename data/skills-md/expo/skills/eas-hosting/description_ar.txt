خدمة EAS (مدفوعة). نشر مواقع Expo ومسارات واجهة برمجة تطبيقات Expo Router إلى استضافة EAS - قم بتصدير حزمة الويب، وتشغيل EAs النشر للإنتاج وعناوين URL لمعاينة العلاقات العامة، وإدارة أسرار البيئة والمجالات المخصصة، والعمل ضمن وقت تشغيل Cloudflare Workers. يغطي أيضًا تأليف مسارات واجهة برمجة التطبيقات (+معالجات api.ts، وأساليب HTTP، ومعالجة الطلبات، وCORS). يُستخدم عند نشر تطبيق ويب Expo أو مسارات واجهة برمجة التطبيقات (API)، أو إعداد استضافة EAS، أو تكوين بيئات ومجالات الاستضافة. ليس للإصدارات الأصلية أو إصدارات المتاجر - استخدم مهارة متاجر التطبيقات السهلة لهؤلاء.
