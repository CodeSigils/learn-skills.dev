Услуга ЕАС (платная). Развертывайте веб-сайты Expo и маршруты API Expo Router на хостинге EAS — экспортируйте веб-пакет, запускайте eas Deploy for Production и URL-адреса предварительного просмотра PR, управляйте секретами среды и пользовательскими доменами, а также работайте в среде выполнения Cloudflare Workers. Также рассматривается создание маршрутов API (обработчики +api.ts, методы HTTP, обработка запросов, CORS). Используйте при развертывании веб-приложения Expo или маршрутов API, настройке хостинга EAS или настройке сред и доменов хостинга. Не для собственных сборок или выпусков для магазинов — для них используйте навык eas-app-stores.
