EASサービス（有料）。 Expo WebサイトとExpo Router APIルートをEASホスティングにデプロイします - Webバンドルをエクスポートし、本番およびPRプレビューURL用にeaデプロイを実行し、環境シークレットとカスタムドメインを管理し、Cloudflare Workersランタイム内で作業します。 API ルート (+api.ts ハンドラー、HTTP メソッド、リクエスト処理、CORS) の作成についても説明します。 Expo Web アプリまたは API ルートのデプロイ時、EAS ホスティングのセットアップ時、またはホスティング環境とドメインの構成時に使用します。ネイティブ ビルドやストア リリースには対応していません。これらには eas-app-stores スキルを使用してください。
