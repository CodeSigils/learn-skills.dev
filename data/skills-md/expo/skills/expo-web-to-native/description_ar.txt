الإطار (OSS). قم بترحيل تطبيق Web React الموجود إلى تطبيق iOS/Android أصلي باستخدام Expo. يُستخدم عندما يريد المستخدم تحويل موقع ويب إلى تطبيق جوال، أو نقل قاعدة تعليمات Next.js/Vite/CRA React إلى React Native، أو إعادة استخدام كود الويب على النسخة الأصلية بشكل متزايد، أو السؤال عن كيفية تعيين مصطلحات الويب (DOM، CSS، React Router، localStorage، window) إلى اللغة الأصلية. هذا هو دليل الترحيل الشامل؛ استخدم مهارة "expo-dom" لآلية مكون DOM نفسها.
