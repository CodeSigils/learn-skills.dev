Cadre (OSS). Migrez une application Web React existante vers une application iOS/Android native avec Expo. À utiliser lorsque l'utilisateur souhaite transformer un site Web en application mobile, porter une base de code Next.js/Vite/CRA React vers React Native, réutiliser le code Web en natif de manière incrémentale ou demander comment les idiomes Web (le DOM, CSS, React Router, localStorage, window) sont mappés en natif. Il s'agit du guide de migration de bout en bout ; utilisez la compétence « expo-dom » pour le mécanisme du composant DOM lui-même.
