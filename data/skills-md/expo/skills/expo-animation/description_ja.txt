フレームワーク（OSS）。 React Native と Expo でアニメーションを構築し、適切に感じられるかどうかを決定する順序で決定を下します。アニメーション化するかどうか、どのスレッドで実行するか、どのプロパティ、スプリングまたはタイミング、ジェスチャがどのように制御されるか、どのように劣化するかなどです。 Reanimated、Gesture Handler、Expo Router、expo-haptics を使用して実装を作成します。 Expo アプリで何かをアニメーション化する場合、ジェスチャー、シート、画面遷移を追加する場合、プレス フィードバックや触覚を追加する場合、またはデバイス上で途切れるモーションを修正する場合に使用します。 Web アニメーションには「animate」を使用します。
