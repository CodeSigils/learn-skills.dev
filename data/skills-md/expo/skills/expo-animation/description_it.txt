Quadro (OSS). Costruisci animazioni in React Native ed Expo, prendendo le decisioni nell'ordine che determina se sono giuste: se animarsi, su quale thread viene eseguito, quali proprietà, molla o tempistica, come si trasmette il gesto, come si degrada. Scrive l'implementazione con Reanimated, Gesture Handler, Expo Router ed expo-haptics. Da utilizzare per animare qualsiasi cosa in un'app Expo, aggiungere gesti, fogli, transizioni dello schermo, feedback stampa o aspetti tattili o correggere movimenti che balbettano sul dispositivo. Per l'animazione web usa "animate".
