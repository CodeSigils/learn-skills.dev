Перенесите существующее веб-приложение React в собственное приложение для iOS/Android с помощью Expo. Используйте, когда пользователь хочет превратить веб-сайт в мобильное приложение, портировать кодовую базу React Next.js/Vite/CRA в React Native, постепенно повторно использовать веб-код в нативном коде или спрашивает, как веб-идиомы (DOM, CSS, React Router, localStorage, window) сопоставляются с нативным. Это комплексное руководство по миграции; используйте навык `use-dom` для самого механизма DOM-компонента.
