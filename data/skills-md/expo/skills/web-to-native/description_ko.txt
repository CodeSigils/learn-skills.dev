Expo를 사용하여 기존 웹 React 앱을 기본 iOS/Android 앱으로 마이그레이션합니다. 사용자가 웹사이트를 모바일 앱으로 전환하거나, Next.js/Vite/CRA React 코드베이스를 React Native로 포팅하거나, 네이티브에서 웹 코드를 점진적으로 재사용하거나, 웹 관용구(DOM, CSS, React Router, localStorage, window)가 네이티브에 어떻게 매핑되는지 묻고 싶을 때 사용하세요. 이는 엔드투엔드 마이그레이션 가이드입니다. DOM 구성 요소 메커니즘 자체에 'use-dom' 기술을 사용하세요.
