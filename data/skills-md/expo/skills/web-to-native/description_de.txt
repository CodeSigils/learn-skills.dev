Migrieren Sie mit Expo eine vorhandene Web-React-App zu einer nativen iOS-/Android-App. Verwenden Sie diese Option, wenn der Benutzer eine Website in eine mobile App umwandeln, eine Next.js/Vite/CRA React-Codebasis auf React Native portieren, Webcode auf Native inkrementell wiederverwenden möchte oder fragt, wie Web-Idiome (DOM, CSS, React Router, localStorage, Window) auf Native abgebildet werden. Dies ist der End-to-End-Migrationsleitfaden; Verwenden Sie die Fähigkeit „use-dom“ für den DOM-Komponentenmechanismus selbst.
