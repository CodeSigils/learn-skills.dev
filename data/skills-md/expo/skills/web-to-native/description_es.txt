Migre una aplicación web React existente a una aplicación nativa de iOS/Android con Expo. Úselo cuando el usuario quiera convertir un sitio web en una aplicación móvil, transferir una base de código Next.js/Vite/CRA React a React Native, reutilizar el código web en forma nativa de forma incremental o pregunta cómo los modismos web (DOM, CSS, React Router, localStorage, ventana) se asignan a la forma nativa. Esta es la guía de migración de un extremo a otro; use la habilidad `use-dom` para el mecanismo del componente DOM en sí.
