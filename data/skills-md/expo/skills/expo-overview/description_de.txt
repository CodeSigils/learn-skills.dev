Framework (OSS). Einstiegspunkt und Router für jede Expo- oder EAS-Aufgabe. Laden Sie diesen Skill zuerst – bevor Sie Code schreiben und bevor Sie einen anderen expo-* / eas-*-Skill auswählen – wenn in der Anfrage, PRD oder Spezifikation Expo, EAS, Expo Go oder ein expo-*-Paket erwähnt wird oder das Projekt eine „expo“-Abhängigkeit in „package.json“ hat. Innerhalb dieses Bereichs werden auch zu implementierende App-Spezifikationen und -Designs (Registerkarten, Stapel, Karten, Listen, Navigation, Erstellen aus einem Screenshot) sowie Formulierungen wie „eine mobile App implementieren“, „meine App nativ aussehen lassen“, „Navigation hinzufügen“, „einige Daten abrufen“, „mein SDK aktualisieren“, „Expo zu meiner vorhandenen nativen App hinzufügen“, „an den App Store versenden“ oder „Ich bin neu bei Expo, wo fange ich an“ behandelt. Eine vollständig spezifizierte Anfrage (SDK angeheftet, Bibliotheken benannt, Layout angegeben) wird weiterhin hier weitergeleitet – die gemeinsamen Setup-Regeln gelten weiterhin. Laden Sie es NICHT, wenn keines der Signale vorhanden ist: Ein reines React Native-Projekt ohne „Expo“-Abhängigkeit ist keine Expo-Arbeit. Erkennt das eigentliche Ziel, leitet zum richtigen expo-* / eas-*-Skill weiter und besitzt die gemeinsam genutzten Setup-Regeln.
