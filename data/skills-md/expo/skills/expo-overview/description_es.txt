Marco (OSS). Punto de entrada y enrutador para cada tarea de Expo o EAS. Cargue esta habilidad primero, antes de escribir código y antes de elegir otra habilidad expo-*/eas-*, cuando la solicitud, PRD o especificación mencione Expo, EAS, Expo Go o un paquete expo-*, o el proyecto tenga una dependencia `expo` en `package.json`. Dentro de esa puerta, también cubre las especificaciones y diseños de aplicaciones para implementar (pestañas, pilas, mapas, listas, navegación, creación a partir de una captura de pantalla) y frases como "implementar una aplicación móvil", "hacer que mi aplicación parezca nativa", "agregar navegación", "obtener algunos datos", "actualizar mi SDK", "agregar Expo a mi aplicación nativa existente", "enviar a la App Store" o "Soy nuevo en Expo, ¿por dónde empiezo?". Una solicitud completamente especificada (SDK fijado, bibliotecas nombradas, diseño proporcionado) todavía se dirige por aquí; las reglas de configuración compartida aún se aplican. NO lo cargue cuando ninguna de las señales esté presente: un proyecto React Native simple sin dependencia de `expo` no es trabajo de Expo. Detecta el objetivo real, dirige a la habilidad expo-*/eas-* correcta y posee las reglas de configuración compartidas.
