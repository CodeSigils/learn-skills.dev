Cadre (OSS). Point d'entrée et routeur pour chaque tâche Expo ou EAS. Chargez d'abord cette compétence - avant d'écrire du code et avant de choisir une autre compétence expo-* / eas-* - lorsque la demande, le PRD ou la spécification mentionne Expo, EAS, Expo Go ou un package expo-*, ou que le projet a une dépendance « expo » dans « package.json ». Dans cette porte, il couvre également les spécifications et les conceptions des applications à implémenter (onglets, piles, cartes, listes, navigation, création à partir d'une capture d'écran) et des expressions telles que « implémenter une application mobile », « donner à mon application un aspect natif », « ajouter de la navigation », « récupérer des données », « mettre à niveau mon SDK », « ajouter Expo à mon application native existante », « expédier vers l'App Store » ou « Je suis nouveau sur Expo, par où commencer ». Une requête entièrement spécifiée (SDK épinglé, bibliothèques nommées, mise en page donnée) passe toujours par ici — les règles de configuration partagées s'appliquent toujours. Ne le chargez PAS lorsqu'aucun signal n'est présent : un projet React Native nu sans dépendance "expo" n'est pas un travail d'Expo. Détecte le véritable objectif, dirige vers la bonne compétence expo-* / eas-* et possède les règles de configuration partagées.
