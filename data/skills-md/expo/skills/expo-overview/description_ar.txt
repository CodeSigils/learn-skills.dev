الإطار (OSS). نقطة الدخول وجهاز التوجيه لكل مهمة Expo أو EAS. قم بتحميل هذه المهارة أولاً - قبل كتابة التعليمات البرمجية وقبل اختيار مهارة expo-* / eas-* أخرى - عندما يذكر الطلب أو PRD أو المواصفات Expo أو EAS أو Expo Go أو حزمة expo-*، أو عندما يكون لدى المشروع تبعية "expo" في "package.json". داخل هذه البوابة، يغطي أيضًا مواصفات التطبيق والتصميمات المراد تنفيذها (علامات التبويب، والمجموعات، والخرائط، والقوائم، والتنقل، والإنشاء من لقطة شاشة)، وعبارات مثل "تنفيذ تطبيق جوال"، أو "جعل تطبيقي يبدو أصليًا"، أو "إضافة التنقل"، أو "جلب بعض البيانات"، أو "ترقية SDK الخاصة بي"، أو "إضافة Expo إلى تطبيقي الأصلي الحالي"، أو "الشحن إلى متجر التطبيقات"، أو "أنا جديد في Expo، من أين أبدأ". لا يزال هناك طلب محدد بالكامل (SDK مثبت، تسمية المكتبات، التخطيط المعطى) يتم توجيهه من هنا - لا تزال قواعد الإعداد المشتركة مطبقة. لا تقم بتحميله في حالة عدم وجود أي إشارة: مشروع React Native المجرد بدون تبعية `expo` لا يعد عمل Expo. يكتشف الهدف الحقيقي، ويوجه إلى مهارة Expo-* / eas-* الصحيحة، ويمتلك قواعد الإعداد المشتركة.
