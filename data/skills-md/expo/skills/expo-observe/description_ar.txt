الاستخدام لأي شيء متعلق بـ EAS Observe - إضافة `expo-observe` إلى مشروع Expo (AppMetricsRoot/ObserveRoot HOC، وmarkInteractive، وخطاف useObserve، وتكاملات Expo Router / React Navigation للمقاييس لكل مسار)، والاستعلام عبر واجهة سطر أوامر EAS (`ملاحظة سهلة: ملخص المقاييس`، `ملاحظة: قياسات`، `ملاحظة: مسارات`، `ملاحظة: الأحداث`، `ملاحظة: الإصدارات`)، أو تفسير المقاييس الناتجة (التشغيل البارد/الدافئ، TTR، TTI، التنقل البارد/الدافئ TTR، تنزيل التحديث، ومعلمات TTI FrameRate لفرز عمليات بدء التشغيل البطيئة).
