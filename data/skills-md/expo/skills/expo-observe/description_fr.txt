À utiliser pour tout ce qui concerne EAS Observe — ajout d'expo-observe à un projet Expo (AppMetricsRoot/ObserveRoot HOC, markInteractive, le hook useObserve et les intégrations Expo Router / React Navigation pour les métriques par itinéraire), interrogation via la CLI EAS (`eas observe:metrics-summary`, `observe:metrics`, `observe:routes`, `observe:events`, `observer:versions`), ou interpréter les métriques résultantes (lancement à froid/à chaud, TTR, TTI, TTR de navigation à froid/à chaud, téléchargement de mise à jour et paramètres TTI frameRate pour trier les démarrages lents).
