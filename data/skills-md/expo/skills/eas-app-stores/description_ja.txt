EASサービス（有料）。 EAS を使用して Expo アプリをアプリ ストアにデプロイします。iOS App Store、Google Play ストア、および TestFlight をビルドして送信し、eas.json のビルドとプロファイルを構成して送信し、アプリのバージョンとビルド番号を管理し、App Store メタデータと ASO を公開します。ユーザーがアプリを運用環境またはアプリ ストアにデプロイ、リリース、または出荷する場合、運用ビルドの準備をする場合、eas build または eas submit を実行する場合、TestFlight に配布する場合、バージョン番号またはビルド番号を変更する場合、またはストアの掲載情報のメタデータを設定する場合に使用します。 Expo Web サイトまたは API ルートをデプロイするには、eas-hosting スキルを使用します。
