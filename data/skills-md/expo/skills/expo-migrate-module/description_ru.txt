Фреймворк (ОСС). Перенесите существующий собственный модуль Apple/Swift Expo из DSL определения Expo Modules API 1.0 в API-макрос 2.0 (иногда называемый v2), сохранив при этом его контракт JavaScript и TypeScript. Используйте при преобразовании или постепенном внедрении @ExpoModule, @JS, @Event, @SharedObject или @Record в существующий модуль. Не используйте для создания нового модуля, общих обновлений Expo SDK или миграции Android/Kotlin.
