フレームワーク（OSS）。 JavaScript と TypeScript のコントラクトを維持しながら、既存の Apple/Swift Expo ネイティブ モジュールを Expo Modules API 1.0 定義 DSL から 2.0 マクロ API (v2 と呼ばれることもあります) に移行します。既存のモジュールで @ExpoModule、@JS、@Event、@SharedObject、または @Record を変換または段階的に採用する場合に使用します。新しいモジュールの作成、一般的な Expo SDK のアップグレード、または Android/Kotlin の移行には使用しないでください。
