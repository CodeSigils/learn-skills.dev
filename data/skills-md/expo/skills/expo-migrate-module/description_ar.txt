الإطار (OSS). قم بترحيل وحدة أصلية موجودة من Apple/Swift Expo من DSL تعريف Expo Modules API 1.0 إلى واجهة برمجة تطبيقات الماكرو 2.0 (تسمى أحيانًا الإصدار 2) مع الحفاظ على عقد JavaScript وTypeScript الخاص بها. يُستخدم عند التحويل أو الاعتماد المتزايد على @ExpoModule أو @JS أو @Event أو @SharedObject أو @Record في وحدة نمطية موجودة. لا تستخدم لإنشاء وحدة نمطية جديدة، أو ترقيات Expo SDK العامة، أو عمليات ترحيل Android/Kotlin.
