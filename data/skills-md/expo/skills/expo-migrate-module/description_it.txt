Quadro (OSS). Migrare un modulo nativo Apple/Swift Expo esistente dalla definizione DSL Expo Modules API 1.0 all'API macro 2.0 (a volte chiamata v2) preservandone il contratto JavaScript e TypeScript. Da utilizzare durante la conversione o l'adozione incrementale di @ExpoModule, @JS, @Event, @SharedObject o @Record in un modulo esistente. Non utilizzare per la creazione di un nuovo modulo, aggiornamenti generali dell'SDK di Expo o migrazioni Android/Kotlin.
