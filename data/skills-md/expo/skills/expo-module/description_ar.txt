دليل لكتابة الوحدات وطرق العرض الأصلية لـ Expo باستخدام Expo Modules API (Swift وKotlin وTypeScript). يغطي تعريف الوحدة النمطية DSL، وطرق العرض الأصلية، والكائنات المشتركة، ومكونات التكوين الإضافية، وخطافات دورة الحياة، والربط التلقائي، ونوع النظام. يُستخدم عند إنشاء الوحدات النمطية الأصلية أو تعديلها لـ Expo.
