Руководство по написанию собственных модулей и представлений Expo с использованием API модулей Expo (Swift, Kotlin, TypeScript). Охватывает DSL определения модуля, собственные представления, общие объекты, плагины конфигурации, перехватчики жизненного цикла, автоматическое связывание и систему типов. Используйте при создании или изменении собственных модулей для Expo.
