Запускайте и управляйте пользовательским приложением на удаленном симуляторе iOS/Android, размещенном в облаке EAS. Всегда читайте перед выполнением любых команд `eas Simulator:*` — там есть текущий синтаксис для этого экспериментального API. Используйте всякий раз, когда пользователю нужен симулятор, который он не может запустить локально — «запустите мое приложение в облачном симуляторе», «используйте симулятор eas для запуска/установки/снимка экрана моего приложения», «Я использую Linux/Cursor и мне нужно устройство iOS», «на этом компьютере нет SIM-карты / безголовый CI», «позволить агенту просмотреть мое приложение и сделать снимок экрана», «проверить мою сборку разработки на удаленном SIM-карте с живой перезагрузкой», «транслировать экран сима на мой браузер» — даже если там не написано «EAS Simulator» или «облако». На хосте БЕЗ локального симулятора (Linux, CI, облачная песочница) это значение по умолчанию — просто используйте его; в macOS НЕ используйте автоматический запуск для простого «запуска на симуляторе» — используйте его только для облачного/удаленного/совместно используемого симулятора, версии iOS, которой им не хватает, или сеанса, управляемого агентом. НЕ для локальных симов (запуск выставки: ios, Xcode, Android Studio), сборки/обновления EAS, предварительного просмотра в Интернете или физических устройств.
