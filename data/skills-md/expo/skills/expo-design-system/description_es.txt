Marco (OSS). Cree y mantenga un sistema de diseño dentro de una aplicación Expo: un tema reutilizable de tokens de diseño (color, espaciado, tipografía, radio, sombra, movimiento), estructura de componentes reutilizable con convenciones de variante/tamaño/estado y reglas sobre cuándo extraer una vista repetida en un componente compartido. Úselo al crear u organizar archivos de temas y tokens de diseño (theme.ts / theme/), ampliar un tema existente o una biblioteca de estilos (NativeWind, Tamagui, Restyle, Unistyles) en su propio lenguaje, estandarizar estilos para que las pantallas (incluidas las generadas por IA) se vean consistentes y pulidas, crear una biblioteca de componentes en la aplicación o auditar una aplicación para detectar variaciones en el sistema de diseño (colores codificados, espaciado, fuentes). Para detalles de estilo de plataforma (colores semánticos, reglas HIG, controles nativos), utilice expo-native-ui; para la configuración Tailwind/CSS utilice expo-tailwind-setup; para el diseño de carpetas de una nueva aplicación, utilice expo-project-structure.
