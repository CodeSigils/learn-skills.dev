Erstellen und pflegen Sie ein Designsystem innerhalb einer Expo-App – ein wiederverwendbares Thema aus Design-Tokens (Farbe, Abstand, Typografie, Radius, Schatten, Bewegung), einer wiederverwendbaren Komponentenstruktur mit Varianten-/Größen-/Status-Requisitenkonventionen und Regeln dafür, wann eine wiederholte Ansicht in eine gemeinsam genutzte Komponente extrahiert werden soll. Verwenden Sie diese Option, wenn Sie Themendateien und Design-Tokens (theme.ts / theme/) erstellen oder organisieren, ein vorhandenes Thema oder eine Stilbibliothek (NativeWind, Tamagui, Restyle, Unistyles) in einer eigenen Sprache erweitern, Stile standardisieren, damit Bildschirme (einschließlich KI-generierter) konsistent und ausgefeilt aussehen, eine In-App-Komponentenbibliothek erstellen oder eine App auf Abweichungen vom Designsystem prüfen (hartcodierte Farben, Abstände, Schriftarten). Für Besonderheiten des Plattformstils (semantische Farben, HIG-Regeln, native Steuerelemente) verwenden Sie expo-native-ui; für Tailwind/CSS-Setup verwenden Sie expo-tailwind-setup; Für das Ordnerlayout einer neuen App verwenden Sie expo-project-structure.
