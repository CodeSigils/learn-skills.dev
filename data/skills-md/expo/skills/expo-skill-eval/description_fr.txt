Évaluez les compétences Expo dans ce référentiel de bout en bout : précision du déclenchement, qualité du code généré et captures d'écran d'exécution sur le simulateur iOS et l'émulateur Android via Expo Go (web facultatif). À utiliser lorsque l'utilisateur souhaite évaluer une compétence Expo, tester qu'une compétence produit du code fonctionnel, comparer une compétence avec des captures d'écran de l'appareil ou vérifier correctement les rendus de sortie d'une compétence.
