Создайте собственный пользовательский интерфейс с помощью пакета @expo/ui: настоящий SwiftUI на iOS и Jetpack Compose на Android, созданный из React в приложении Expo или React Native. Охватывает универсальные кроссплатформенные компоненты (Host, Column, Row, Button, Text, List и другие, импортированные из @expo/ui), замены для популярных библиотек сообщества React Native (BottomSheet, DateTimePicker, Slider, Menu и т. д.), а также деревья и модификаторы SwiftUI (@expo/ui/swift-ui) и Jetpack Compose (@expo/ui/jetpack-compose) для конкретной платформы. Используйте при добавлении или просмотре деревьев @expo/ui Host/RNHostView, создании естественного пользовательского интерфейса там, где стандартные компоненты React Native не справляются (списки с действиями и разделами смахивания, формы настроек с переключателями, меню, листы, средства выбора, ползунки), выбор между универсальными и специфичными для платформы компонентами или замена библиотеки пользовательского интерфейса сообщества RN на собственный эквивалент @expo/ui. Не для пользовательских собственных модулей, навигации Expo Router, реанимации или получения данных.
