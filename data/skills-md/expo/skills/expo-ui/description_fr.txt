Créez une interface utilisateur native avec le package @expo/ui : véritable SwiftUI sur iOS et Jetpack Compose sur Android rendu à partir de React dans une application Expo ou React Native. Couvre les composants multiplateformes universels (hôte, colonne, ligne, bouton, texte, liste et plus importés de @expo/ui), les remplacements instantanés des bibliothèques communautaires React Native populaires (BottomSheet, DateTimePicker, Slider, Menu, etc.) et les arbres et modificateurs SwiftUI spécifiques à la plate-forme (@expo/ui/swift-ui) et Jetpack Compose (@expo/ui/jetpack-compose). À utiliser lors de l'ajout ou de la révision d'arborescences @expo/ui Host/RNHostView, de la création d'une interface utilisateur native là où les composants React Native standard sont insuffisants (listes avec actions et sections de balayage, formulaires de paramètres avec bascules, menus, feuilles, sélecteurs, curseurs), du choix entre des composants universels et spécifiques à la plate-forme, ou du remplacement d'une bibliothèque d'interface utilisateur de la communauté RN par un équivalent natif @expo/ui. Pas pour les modules natifs personnalisés, la navigation Expo Router, Reanimated ou la récupération de données.
