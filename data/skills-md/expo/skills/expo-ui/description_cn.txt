使用 @expo/ui 包构建本机 UI：iOS 上的真实 SwiftUI 和 Android 上的 Jetpack Compose 从 Expo 或 React Native 应用程序中的 React 渲染。涵盖通用跨平台组件（Host、Column、Row、Button、Text、List 等从 @expo/ui 导入的组件）、流行的 React Native 社区库（BottomSheet、DateTimePicker、Slider、Menu 等）的直接替代品，以及特定于平台的 SwiftUI (@expo/ui/swift-ui) 和 Jetpack Compose (@expo/ui/jetpack-compose) 树和修饰符。在添加或审查 @expo/ui Host/RNHostView 树、构建标准 React Native 组件不足的原生 UI（带有滑动操作和部分的列表、带有切换的设置表单、菜单、工作表、选择器、滑块）、在通用组件和特定于平台的组件之间进行选择，或者用本机 @expo/ui 等效项替换 RN 社区 UI 库时使用。不适用于自定义本机模块、Expo Router 导航、Reanimated 或数据获取。
