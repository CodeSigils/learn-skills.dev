أنشئ واجهة مستخدم أصلية باستخدام حزمة @expo/ui: واجهة SwiftUI الحقيقية على iOS وJetpack Compose على Android المقدمة من React في تطبيق Expo أو React Native. يغطي المكونات العامة عبر الأنظمة الأساسية (المضيف، والعمود، والصف، والزر، والنص، والقائمة، والمزيد المستوردة من @expo/ui)، والبدائل المنسدلة لمكتبات مجتمع React Native الشائعة (BottomSheet، وDateTimePicker، وSlider، وMenu، وما إلى ذلك)، وأشجار SwiftUI الخاصة بالنظام الأساسي (@expo/ui/swift-ui) وJetpack Compose (@expo/ui/jetpack-compose) والمعدلات. يُستخدم عند إضافة أو مراجعة أشجار @expo/ui Host/RNHostView، أو بناء واجهة مستخدم ذات طابع أصلي حيث تكون مكونات React Native القياسية قصيرة (قوائم تحتوي على إجراءات وأقسام تمرير، ونماذج إعدادات مع مفاتيح تبديل، وقوائم، وأوراق، ومنتقيات، ومنزلقات)، والاختيار بين المكونات العامة والمحددة للنظام الأساسي، أو استبدال مكتبة واجهة مستخدم مجتمع RN بمكافئ @expo/ui الأصلي. ليس للوحدات الأصلية المخصصة، أو التنقل في Expo Router، أو Reanimated، أو جلب البيانات.
