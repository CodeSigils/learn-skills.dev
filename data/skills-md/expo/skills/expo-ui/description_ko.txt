@expo/ui 패키지를 사용하여 네이티브 UI를 빌드하세요. iOS의 실제 SwiftUI와 Expo 또는 React Native 앱의 React에서 렌더링된 Android의 Jetpack Compose입니다. 범용 크로스 플랫폼 구성 요소(@expo/ui에서 가져온 호스트, 열, 행, 버튼, 텍스트, 목록 등), 인기 있는 React Native 커뮤니티 라이브러리(BottomSheet, DateTimePicker, Slider, Menu 등)에 대한 드롭인 교체, 플랫폼별 SwiftUI(@expo/ui/swift-ui) 및 Jetpack Compose(@expo/ui/jetpack-compose) 트리 및 수정자를 다룹니다. @expo/ui Host/RNHostView 트리를 추가하거나 검토할 때, 표준 React Native 구성 요소가 부족한 네이티브 느낌의 UI를 구축할 때(스와이프 동작 및 섹션이 있는 목록, 토글, 메뉴, 시트, 선택기, 슬라이더가 있는 설정 양식), 범용 구성 요소와 플랫폼별 구성 요소 중에서 선택하거나 RN 커뮤니티 UI 라이브러리를 기본 @expo/ui에 상응하는 것으로 교체할 때 사용합니다. 사용자 정의 기본 모듈, Expo Router 탐색, Reanimated 또는 데이터 가져오기에는 적합하지 않습니다.
