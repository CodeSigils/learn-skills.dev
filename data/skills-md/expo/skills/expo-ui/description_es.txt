Cree una interfaz de usuario nativa con el paquete @expo/ui: SwiftUI real en iOS y Jetpack Compose en Android renderizados desde React en una aplicación Expo o React Native. Cubre componentes universales multiplataforma (Host, Columna, Fila, Botón, Texto, Lista y más importados de @expo/ui), reemplazos directos para bibliotecas populares de la comunidad React Native (BottomSheet, DateTimePicker, Slider, Menu, etc.) y árboles y modificadores SwiftUI (@expo/ui/swift-ui) y Jetpack Compose (@expo/ui/jetpack-compose) específicos de la plataforma. Úselo al agregar o revisar árboles @expo/ui Host/RNHostView, crear una interfaz de usuario con sensación nativa donde los componentes estándar de React Native se quedan cortos (listas con secciones y acciones de deslizamiento, formularios de configuración con alternancias, menús, hojas, selectores, controles deslizantes), elegir entre componentes universales y específicos de la plataforma, o reemplazar una biblioteca de interfaz de usuario de la comunidad RN con un equivalente nativo de @expo/ui. No para módulos nativos personalizados, navegación Expo Router, Reanimated o recuperación de datos.
