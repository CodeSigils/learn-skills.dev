تطوير برامج استخدام الأراضي وتحسين مزيج الاستخدامات للمناطق الحضرية والأحياء والمباني الفردية. يُستخدم عندما يسأل المستخدم عن برمجة استخدام الأراضي، أو نسب مزيج الاستخدام، أو توزيع البرنامج، أو حجم البيع بالتجزئة، أو متطلبات المساحة المكتبية، أو التوازن السكني التجاري، أو إستراتيجية المستأجر الأساسي، أو تخطيط المرافق المجتمعية، أو عند تطوير برنامج تطوير لموقع ما. استخدمه أيضًا عندما يحتاج المستخدم إلى تحديد الاستخدامات وأين يتم استخدامها، أو مقدار كل استخدام مطلوب، أو كيفية إنشاء بيئات متعددة الاستخدامات نابضة بالحياة.
