تقدير تكاليف البناء وتكاليف البنية التحتية والتكاليف الناعمة وتكاليف التطوير الإجمالية لمشاريع التصميم الحضري. يغطي تكلفة تشييد المباني لكل متر مربع حسب التصنيف، وتكلفة البنية التحتية لكل متر طولي ولكل مسكن، وإعداد الموقع، والمناظر الطبيعية، والرسوم المهنية، وتحليل الجدوى المالية. يُستخدم عندما يسأل المستخدم عن تكلفة المشروع، أو تكلفة البناء، أو ميزانية البنية التحتية، أو جدوى التطوير، أو التكلفة لكل وحدة، أو التكلفة لكل متر مربع، أو الإنفاق الرأسمالي، أو النفقات التشغيلية، أو قياس التكلفة، أو هندسة القيمة، أو تكاليف المراحل، أو أي سؤال حول مقدار تكلفة مشروع التصميم الحضري أو مكوناته. استخدم أيضًا لتقدير الميزانية الأولي، أو ترتيب التكاليف حسب الحجم، أو مقارنة التكلفة بين بدائل التصميم، أو تحسين تكلفة المخططات الرئيسية.
