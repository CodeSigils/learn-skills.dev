تصميم شوارع كاملة ذات مقاطع عرضية مناسبة، وتخصيص الممرات، والبنية التحتية للمشاة وركوب الدراجات، وتصميم التقاطعات، وعناصر منظر الشوارع باستخدام NACTO والمعايير العالمية. يُستخدم عندما يطلب المستخدم تصميم شارع، أو إنشاء مقطع عرضي، أو تحديد عرض الطريق، أو تصميم تقاطع، أو تخطيط ممر للدراجات، أو تصميم رصيف، أو إنشاء جادة، أو تصميم شارع مشترك، أو التخطيط لتهدئة حركة المرور، أو تحديد عناصر منظر الشارع. يُستخدم أيضًا لتصنيف التسلسل الهرمي للشوارع، أو تخصيص حق الطريق، أو أي سؤال حول أبعاد الشارع ومعاييره.
