تصميم الكتل الحضرية وتحسين الكثافة باستخدام التحليل النموذجي وحسابات FAR واستراتيجيات تكوين البناء. يُستخدم عندما يسأل المستخدم عن أبعاد الكتلة، أو تخطيط الكتلة، أو حسابات الكثافة، أو تحسين FAR، أو تغطية بصمة المبنى، أو علاقات الارتفاع والكثافة، أو أنواع الكتلة، أو تصميم الكتلة المحيطة، أو كتل الفناء، أو تكوينات المنصة البرجية، أو دراسات الكتلة. يُستخدم أيضًا عندما يحتاج المستخدم إلى فهم عدد الوحدات المناسبة للموقع، أو حساب الكثافة الإجمالية مقابل الكثافة الصافية، أو تحسين خطة الكتلة لضوء النهار والخصوصية.
