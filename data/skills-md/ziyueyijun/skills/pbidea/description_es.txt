Habilidad de consulta de API del marco PbIdea. Activado manualmente por el comando /pbidea. Cubre: uo_json (análisis/generación y conversión de JSON con DataWindow), uo_httpclient / uo_curl (cliente HTTP, carga/descarga), cifrado y codificación (uo_crypto/uo_rsa/Chinese SM2/SM3/SM4/base64), base de datos (uo_database/uo_recordset), uo_datawindowex, uo_bson, uo_csv, uo_compress, uo_thread y otros componentes de WebSuite, así como objetos en bibliotecas como sciter, web, web_client, haikang y pintor.
