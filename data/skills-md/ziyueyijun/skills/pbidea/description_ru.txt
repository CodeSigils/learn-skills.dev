Навыки выполнения запросов к API платформы PbIdea. Запускается вручную командой /pbidea. Охватывает: uo_json (синтаксический анализ/генерация и преобразование JSON с помощью DataWindow), uo_httpclient / uo_curl (HTTP-клиент, загрузка/выгрузка), шифрование и кодирование (uo_crypto / uo_rsa / китайский национальный SM2 / SM3 / SM4 / base64), база данных (uo_database / uo_recordset), uo_datawindowex, uo_bson, uo_csv, uo_compress, uo_thread и другие компоненты WebSuite, а также объекты в таких библиотеках, как sciter, web, web_client, haikang и Painter.
