PbIdea framework API query capability. Manually triggered by the /pbidea command. Covers: uo_json (JSON parsing/generation/interconversion with DataWindow), uo_httpclient / uo_curl (HTTP client, upload/download), encryption and encoding (uo_crypto / uo_rsa / Chinese national standards SM2 / SM3 / SM4 / base64), database (uo_database / uo_recordset), uo_datawindowex, uo_bson, uo_csv, uo_compress, uo_thread and other WebSuite components, as well as objects in the sciter, web, web_client, haikang, and painter libraries.
