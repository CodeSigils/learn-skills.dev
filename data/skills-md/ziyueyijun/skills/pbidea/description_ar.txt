ميزة استعلام API لإطار عمل PbIdea. يتم تشغيله يدويًا بواسطة الأمر /pbidea. ويغطي: uo_json (تحليل/إنشاء JSON وتحويله باستخدام DataWindow)، uo_httpclient / uo_curl (عميل HTTP، التحميل/التنزيل)، التشفير والتشفير (uo_crypto/uo_rsa/الوطنية الصينية SM2/SM3/SM4/base64)، قاعدة البيانات (uo_database/uo_recordset)، uo_datawindowex، uo_bson، uo_csv، uo_compress وuo_thread ومكونات WebSuite الأخرى، بالإضافة إلى الكائنات الموجودة في مكتبات sciter وweb وweb_client وhaikang والرسام.
