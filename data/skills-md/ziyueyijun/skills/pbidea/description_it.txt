Funzionalità di query dell'API del framework PbIdea. Attivato manualmente dal comando /pbidea. Copre: uo_json (analisi/generazione/interconversione JSON con DataWindow), uo_httpclient / uo_curl (client HTTP, caricamento/download), crittografia e codifica (uo_crypto/uo_rsa/algoritmi nazionali cinesi SM2/SM3/SM4/base64), database (uo_database/uo_recordset), uo_datawindowex, uo_bson, uo_csv, uo_compress, uo_thread e altri componenti WebSuite, nonché oggetti nelle librerie sciter, web, web_client, haikang e Painter.
