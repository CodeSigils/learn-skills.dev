قم بإنشاء مطالبة تالية موجزة واعية بالسياق تخبر Codex بما يجب فعله بعد ذلك. يُستخدم عندما يطلب المستخدم مطالبة تالية، أو مطالبة أفضل، أو مطالبة بالاستمرار، أو مطالبة تسليم، أو مطالبة دردشة جديدة، أو مطالبة استئناف، أو نقل السياق، أو يريد مواصلة العمل أو توجيهه أو إعادة تشغيله مع الحفاظ على نظام سير عمل القوى العظمى ذي الصلة.
