Cree, inspeccione, sincronice y gobierne ramas de GitHub/Git utilizando un modelo de rama principal/desarrollo/lanzamiento. Úselo cuando el usuario solicite crear o elegir una rama, nombrar una característica/corrección de errores/revisión/rama de lanzamiento, verificar la seguridad de la rama, sincronizar una rama base, preparar una solicitud de extracción, proteger las ramas principal/desarrollo/lanzamiento o decidir si la preparación/UAT/prueba debe ser una rama o un entorno de implementación.
