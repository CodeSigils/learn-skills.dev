Permite a los agentes registrar, administrar y ejecutar tareas programadas utilizando el programador nativo del sistema operativo (crontab para Linux/WSL, launchd para macOS). Sin git, sin banderas peligrosas, sin dependencia de sesión. Las tareas se ejecutan sin cabeza, se generan en archivos de registro y el usuario las lee cuando está listo.
Utilice esta habilidad cuando: - El usuario quiera programar tareas recurrentes con lenguaje natural - El usuario mencione "every day at", "cada hora", "schedule", "programar", "automatizar" - El usuario necesite que las tareas se ejecuten sin sesión abierta (headless) - El usuario quiera programación a nivel de sistema operativo (crontab/launchd) - El usuario mencione "cada minuto durante la próxima hora" o intervalos temporales
ACTIVAR cuando el usuario mencione: "schedule", "programar", "cron", "cada día", "every hour", "automate", "tarea programada", "ejecutar automáticamente", "recordatorio", "cada minuto durante", "durante la próxima", "intervalo", "tarea en segundo plano"
NO UTILIZAR para: operaciones de git, permisos peligrosos, dependencia de muestreo de MCP.
