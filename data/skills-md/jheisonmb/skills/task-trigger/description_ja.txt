エージェントが OS ネイティブ スケジューラ (Linux/WSL の場合は crontab、macOS の場合は launchd) を使用して、スケジュールされたタスクを登録、管理、実行できるようにします。 git、危険なフラグ、セッション依存関係はありません。タスクはヘッドレスで実行され、ログ ファイルに出力され、準備ができたらユーザーが読み取ります。
このスキルは次の場合に使用します。 - ユーザーが自然言語で定期的なタスクをスケジュールしたい - ユーザーが「毎日」、「時間」、「スケジュール」、「プログラマ」、「オートマティザー」と言及する - ユーザーがセッションを開いていない (ヘッドレス) でタスクを実行する必要がある - ユーザーが OS レベルのスケジューリング (crontab/launchd) を希望する - ユーザーが「時間間隔」または時間間隔について言及する
ユーザーが「スケジュール」、「プログラマー」、「クロン」、「カレンダー」、「毎時」、「自動化」、「プログラム自動化」、「自動自動化」、「記録」、「継続的継続」、「継続的」、「インターバル」、「タスク スケジューラ」、「オープンコード ヘッドレス」、 「キロスケジュール」、「バックグラウンドタスク」、「タレアアンセグンドプランノ」
git 操作、危険な権限、MCP サンプリングの依存関係には使用しないでください。
