Позволяет агентам регистрироваться, управлять и выполнять запланированные задачи с помощью встроенного планировщика ОС (crontab для Linux/WSL, launchd для macOS). Никакого git, никаких опасных флагов, никакой зависимости от сеанса. Задачи выполняются в автономном режиме, выводятся в файлы журналов, пользователь читает, когда готов.
Используйте этот навык, когда: - Пользователь хочет запланировать повторяющиеся задачи на естественном языке - Пользователь упоминает «каждый день в», «cada hora», «schedule», «programar», «automatizar» - Пользователю нужно, чтобы задачи выполнялись без открытого сеанса (без головы) - Пользователь хочет планирование на уровне ОС (crontab/launchd) - Пользователь упоминает «cada minuto durante la próxima hora» или временные интервалы
АКТИВИРОВАТЬ, когда пользователь упоминает: «расписание», «программирование», «cron», «каждый день», «каждый час», «автоматизировать», «программируемая программа», «автоматический запуск», «запись», «каждая минута в течение продолжительного времени», «в течение ближайшего времени», «интервал», «планировщик задач», «открытый код без головы», «запланированное задание», «фоновая задача», «вторая задача». плано"
НЕ ИСПОЛЬЗУЙТЕ для: операций git, опасных разрешений, зависимости выборки MCP.
