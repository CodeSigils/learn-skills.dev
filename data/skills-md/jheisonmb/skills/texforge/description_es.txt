Herramienta CLI para compilar documentos LaTeX a PDF sin TeX Live, MiKTeX o cualquier distribución externa de LaTeX. Utilice esta habilidad siempre que el usuario desee crear un proyecto LaTeX, compilar archivos .tex en PDF, formatear o eliminar documentos LaTeX, administrar plantillas o trabajar con la CLI de texforge. Se activa cuando el usuario menciona "texforge new", "texforge build", "texforge fmt", "texforge check", "texforge init", "texforge template", creando una tesis o documento académico, compilando LaTeX sin instalar TeX Live, usando tectonic como motor LaTeX, configuración project.toml o cualquier flujo de trabajo que involucre archivos .tex y la herramienta texforge.
