أداة CLI لتجميع مستندات LaTeX إلى PDF بدون TeX Live أو MiKTeX أو أي توزيع LaTeX خارجي. استخدم هذه المهارة عندما يريد المستخدم إنشاء مشروع LaTeX، أو تجميع ملفات .tex إلى PDF، أو تنسيق مستندات LaTeX أو فحصها، أو إدارة القوالب، أو العمل باستخدام واجهة سطر أوامر texforge. يتم التنشيط عندما يذكر المستخدم "texforge new"، أو "texforge build"، أو "texforge fmt"، أو "texforge check"، أو "texforge init"، أو "قالب texforge"، أو إنشاء أطروحة أو مستند أكاديمي، أو تجميع LaTeX دون تثبيت TeX Live، أو استخدام التكتونية كمحرك LaTeX، أو تكوين project.toml، أو أي سير عمل يتضمن ملفات .tex وأداة texforge.
