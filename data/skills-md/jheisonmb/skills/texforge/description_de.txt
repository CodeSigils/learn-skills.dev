CLI-Tool zum Kompilieren von LaTeX-Dokumenten in PDF ohne TeX Live, MiKTeX oder eine externe LaTeX-Distribution. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein LaTeX-Projekt erstellen, .tex-Dateien in PDF kompilieren, LaTeX-Dokumente formatieren oder linten, Vorlagen verwalten oder mit der texforge-CLI arbeiten möchte. Aktivieren Sie diese Option, wenn der Benutzer „texforge new“, „texforge build“, „texforge fmt“, „texforge check“, „texforge init“, „texforge template“, das Erstellen einer Abschlussarbeit oder eines akademischen Dokuments, das Kompilieren von LaTeX ohne Installation von TeX Live, die Verwendung von tectonic als LaTeX-Engine, die project.toml-Konfiguration oder einen beliebigen Workflow mit .tex-Dateien und dem texforge-Tool erwähnt.
