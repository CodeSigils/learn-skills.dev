Strumento CLI per compilare documenti LaTeX in PDF senza TeX Live, MiKTeX o qualsiasi distribuzione LaTeX esterna. Utilizza questa abilità ogni volta che l'utente desidera creare un progetto LaTeX, compilare file .tex in PDF, formattare o lint documenti LaTeX, gestire modelli o lavorare con la CLI di texforge. Attiva quando l'utente menziona "texforge new", "texforge build", "texforge fmt", "texforge check", "texforge init", "texforge template", creando una tesi o un documento accademico, compilando LaTeX senza installare TeX Live, utilizzando tectonic come motore LaTeX, configurazione project.toml o qualsiasi flusso di lavoro che coinvolga file .tex e lo strumento texforge.
