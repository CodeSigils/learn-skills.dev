Комплексные навыки планирования и реализации разработки программного обеспечения.

Запускается при: создании нового программного обеспечения Python с интерфейсами CLI/GUI/Web, планировании архитектуры и модулей программного обеспечения, разработке научных или инженерных приложений, настройке двуязычной документации и публикации PyPI или необходимости разработки функций на основе академических исследований.

Возможности: планирование и исследование перед разработкой, многоинтерфейсный дизайн (CLI + PySide6 GUI + Flask Web), научная визуализация с помощью pyqtgraph, проектирование функций на основе научной литературы, создание образцов данных и тестовой документации, двуязычный README со структурированными разделами, лицензирование GPLv3 и настройка публикации PyPI.
