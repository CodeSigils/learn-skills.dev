Habilidad integral de planificación e implementación del desarrollo de software.

Se activa cuando: se crea un nuevo software Python con interfaces CLI/GUI/Web, se planifican módulos y arquitectura de software, se diseñan aplicaciones científicas o de ingeniería, se configura documentación bilingüe y publicación PyPI, o se necesita un diseño de funciones basado en investigaciones académicas.

Capacidades: planificación e investigación previas al desarrollo, diseño de múltiples interfaces (CLI + PySide6 GUI + Flask Web), visualización científica con pyqtgraph, diseño de características basadas en literatura académica, datos de muestra y generación de documentación de prueba, README bilingüe con secciones estructuradas, licencia GPLv3 y configuración de publicación PyPI.
