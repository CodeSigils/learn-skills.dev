مهارات تخطيط وتطوير البرمجيات الشاملة.

يتم التشغيل عند: إنشاء برنامج Python جديد مع واجهات CLI/GUI/Web، أو تخطيط بنية البرامج والوحدات النمطية، أو تصميم التطبيقات العلمية أو الهندسية، أو إعداد وثائق ثنائية اللغة ونشر PyPI، أو الحاجة إلى تصميم ميزات قائم على البحث الأكاديمي.

القدرات: التخطيط المسبق للتطوير والبحث، والتصميم متعدد الواجهات (CLI + PySide6 GUI + Flask Web)، والتصور العلمي باستخدام pyqtgraph، وتصميم الميزات المستندة إلى الأدبيات الأكاديمية، وعينة البيانات وتوليد وثائق الاختبار، وREADME ثنائي اللغة مع أقسام منظمة، وترخيص GPLv3 وإعداد نشر PyPI.
