包括的なソフトウェア開発計画と実装スキル。

トリガーとなる場合: CLI/GUI/Web インターフェイスを使用した新しい Python ソフトウェアの作成、ソフトウェア アーキテクチャとモジュールの計画、科学または工学アプリケーションの設計、バイリンガル ドキュメントと PyPI 公開の設定、または学術研究ベースの機能設計が必要な場合。

機能: 開発前の計画と調査、マルチインターフェイス設計 (CLI + PySide6 GUI + Flask Web)、pyqtgraph による科学的視覚化、学術文献ベースの機能設計、サンプル データとテスト ドキュメントの生成、構造化セクションを含むバイリンガル README、GPLv3 ライセンス、および PyPI 公開セットアップ。
