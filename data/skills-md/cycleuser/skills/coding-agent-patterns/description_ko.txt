Claude Code, Codex, Cline, Aider, OpenCode 분석을 기반으로 한 AI 코딩 에이전트의 핵심 패턴입니다.

**다음의 경우에 트리거됩니다.**
- AI 코딩 에이전트 또는 어시스턴트 구축
- 도구 호출 루프 구현
- LLM에 대한 컨텍스트 창 관리
- 에이전트 메모리 또는 스킬 시스템 설정
- 다중 제공자 LLM 추상화 설계

**기능:**
- 핵심 에이전트 루프: 도구 실행과 함께 while(true)
- 컨텍스트 관리: 가지치기, 압축, 저장소 맵
- 도구 안전: 샌드박싱, 승인 흐름, 둠 루프 감지
- 다중 공급자 추상화: 다양한 LLM을 위한 통합 API
- 메모리 시스템: 프로젝트 규칙, 자동 메모리, 스킬 로딩
- 세션 지속성: SQLite 대 JSONL 패턴
