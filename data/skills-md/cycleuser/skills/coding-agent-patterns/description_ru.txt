Основные шаблоны для агентов кодирования ИИ на основе анализа Claude Code, Codex, Cline, Aider, OpenCode.

**Срабатывает, когда:**
- Создание агента или помощника по кодированию ИИ.
- Реализация циклов вызова инструментов.
- Управление контекстными окнами для LLM.
- Настройка памяти агента или системы навыков
- Проектирование абстракции LLM с несколькими поставщиками

**Возможности:**
- Цикл основного агента: while(true) с выполнением инструмента.
- Управление контекстом: обрезка, сжатие, карты репо.
- Безопасность инструментов: изолированная программная среда, потоки утверждения, обнаружение ошибок.
- Абстракция нескольких провайдеров: унифицированный API для разных LLM.
- Системы памяти: правила проекта, автозапоминание, загрузка навыков.
- Сохранение сеанса: шаблоны SQLite и JSONL.
