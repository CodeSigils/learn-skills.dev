Claude Code、Codex、Cline、Aider、OpenCode の分析に基づく AI コーディング エージェントのコア パターン。

**次の場合にトリガーされます:**
- AI コーディング エージェントまたはアシスタントの構築
- ツール呼び出しループの実装
- LLM のコンテキスト ウィンドウの管理
- エージェントのメモリまたはスキル システムのセットアップ
- マルチプロバイダー LLM 抽象化の設計

**能力:**
- コアエージェントループ: while(true) とツールの実行
- コンテキスト管理: プルーニング、圧縮、リポジトリ マップ
- ツールの安全性: サンドボックス、承認フロー、ドゥーム ループ検出
- マルチプロバイダーの抽象化: さまざまな LLM 用の統合 API
- 記憶システム: プロジェクト ルール、自動記憶、スキル読み込み
- セッション永続性: SQLite パターンと JSONL パターン
