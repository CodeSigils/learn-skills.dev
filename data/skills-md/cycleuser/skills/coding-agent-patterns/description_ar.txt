الأنماط الأساسية لوكلاء تشفير الذكاء الاصطناعي بناءً على تحليل Claude Code وCodex وCline وAider وOpenCode.

**يتم التشغيل عندما:**
- بناء وكيل أو مساعد ترميز الذكاء الاصطناعي
- تنفيذ حلقات استدعاء الأدوات
- إدارة نوافذ السياق لـ LLMs
- إعداد ذاكرة الوكيل أو أنظمة المهارات
- تصميم تجريد LLM متعدد الموفرين

**القدرات:**
- حلقة الوكيل الأساسية: while(true) مع تنفيذ الأداة
- إدارة السياق: التقليم، والضغط، وخرائط الريبو
- سلامة الأدوات: وضع الحماية، وتدفقات الموافقة، والكشف عن حلقة الموت
- تجريد متعدد الموفرين: واجهة برمجة التطبيقات الموحدة لمختلف دورات LLM
- أنظمة الذاكرة: قواعد المشروع، الذاكرة التلقائية، تحميل المهارات
- استمرارية الجلسة: أنماط SQLite مقابل JSONL
