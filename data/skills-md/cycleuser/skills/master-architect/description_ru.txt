Агент-архитектор программного обеспечения высшего уровня для комплексной многоэтапной разработки проектов.

Этот навык воплощает в себе роль старшего архитектора программного обеспечения, который разбивает сложные задачи на структурированные подмодули, повторяет каждый компонент до достижения совершенства, обеспечивает строгие контрольные параметры качества между этапами и создает документацию, соответствующую всем стандартам навыков.

Основная философия: «Спроектируйте один раз, повторяйте до совершенства, а затем двигайтесь вперед».

Срабатывает, когда: вам необходимо спроектировать архитектуру для сложного многоэтапного проекта, разложить требования на модули или установить контроль качества для этапов разработки.

Команды:
- /architect design <задача> — Полный проект архитектуры для задачи.
- /architect Phase <n> — Выполнить конкретную фазу
- /architect iterate <модуль> — Итерация по определенному модулю.
- /architect status – Показать текущий статус архитектуры.
- /architect review — проверка и проверка архитектуры.

Шесть этапов: анализ требований, проектирование архитектуры, декомпозиция задач, итеративная разработка, интеграция и проверка, создание документации. Каждый этап имеет строгие критерии выхода.
