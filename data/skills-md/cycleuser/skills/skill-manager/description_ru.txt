Центральный реестр навыков и система управления. Автоматически загружается при каждом сеансе.

**Автоматически загружается при запуске**. Этот навык загружается автоматически, чтобы обеспечить
возможности открытия и применения навыков.

**Команды:**
- `/skills` — список всех доступных навыков с описаниями.
- `/skill <имя>` — загрузить и активировать определенный навык.
- `/skill reload` - Обновить реестр навыков.
- `/skill help <имя>` - Показать подробную справку по навыку

**Возможности:**
- Автоматическое обнаружение всех навыков в рабочей области
- Унифицированный вызов навыков с помощью команды /skill.
- Реестр навыков с метаданными и описаниями.
- Отслеживание версий и управление зависимостями
