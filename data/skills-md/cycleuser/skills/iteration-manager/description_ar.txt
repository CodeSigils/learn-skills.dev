مشرف الاختبار التكراري والتحقق والتحسين.

يتم التشغيل عندما: يطلب المستخدم اختبارًا وتحسينًا متكررًا، أو تكون هناك حاجة إلى مراجعة وضمان جودة التعليمات البرمجية، أو تكون هناك حاجة إلى اختبار آلي وحلقات تعليقات، أو يتم تحديد جولات متعددة من التحسين.

الأوامر:
- /iterate <n> - قم بتشغيل تكرارات دورة تحسين الاختبار
- / توقف التكرار - إيقاف حلقة التكرار الحالية
- / حالة التكرار - عرض حالة التكرار الحالية
- / تقرير التكرار - إنشاء تقرير التكرار

القدرات: تنفيذ الاختبار الآلي وتحليل النتائج، وتتبع مقاييس الجودة عبر التكرارات، وتوليد اقتراحات التحسين، واكتشاف التقارب، وتقارير التكرار التفصيلية.
