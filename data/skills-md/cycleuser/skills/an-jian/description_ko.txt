설치 전 스킬에 대한 보안 검토.

트리거: 새 스킬을 설치하기 전에 설치된 스킬을 주기적으로 검토하거나 스킬에 보안 문제가 있다고 의심합니다.

보안 점검:
- 위험한 명령: rm -rf, sudo, 컬|bash 등
- 네트워크 요청: 잠재적인 데이터 유출
- 파일 쓰기: 민감한 위치에 쓰기
- 자격 증명: API 키/비밀번호 유출 위험
- 자원 고갈: 무한 루프
- 권한 상승: 권한 상승을 시도합니다.
- 외부 종속성: 의심스러운 종속성

명령:
- /security <skill-path> - 스킬 보안 검토
- /security 스캔 <경로> - 딥 스캔
- /security list - 설치된 스킬의 위험 목록을 나열합니다.
- /security fix <skill> - 보안 문제 수정
- /security <skill-path> - 영어 명령어

작업:
- 자동 수정: 위험한 코드 제거 또는 교체
- 비활성화: 위험한 기능을 비활성화합니다.
- 사용자 확인: 사용자가 진행 여부를 선택합니다.
- 차단 : 심각한 위험에 대비한 차단 설치

기능: 정적 코드 분석, 위험한 패턴 인식, 위험 평가, 자동 복구, 사용자 대화형 의사 결정.
