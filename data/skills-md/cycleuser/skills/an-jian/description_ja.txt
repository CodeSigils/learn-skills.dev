インストール前にスキルのセキュリティをレビューします。

トリガー: 新しいスキルをインストールする前、インストールされているスキルを定期的に確認する前、またはスキルにセキュリティ上の問題があると疑われる場合。

セキュリティチェック:
- 危険なコマンド: rm -rf、sudo、curl|bash など。
- ネットワークリクエスト: データ漏洩の可能性
- ファイル書き込み: 機密性の高い場所への書き込み
- 認証情報: API キー/パスワード漏洩のリスク
- リソースの枯渇: 無限ループ
- 権限昇格: 権限の昇格を試みます。
- 外部依存関係: 疑わしい依存関係

コマンド:
- /security <skill-path> - スキルのセキュリティを確認する
- /security scan <パス> - ディープスキャン
- /security list - インストールされているスキルのリスクをリストします
- /security fix <スキル> - セキュリティ問題を修正します
- /security <スキルパス> - 英語コマンド

アクション:
- 自動修正: 危険なコードを削除または置き換えます
- 無効: 危険な機能を無効にします
- ユーザー確認: ユーザーは続行するかどうかを選択します
- ブロック: 重大なリスクがある場合は設置をブロックします。

機能: 静的コード分析、危険なパターン認識、リスク評価、自動修復、ユーザー対話型の意思決定。
