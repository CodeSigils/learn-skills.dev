Spécification complète de développement multi-projets Python pour les outils CLI/GUI.

Se déclenche lorsque : création d'un nouveau projet Python avec prise en charge CLI et GUI, configuration de pyproject.toml avec la publication README et PyPI, implémentation d'une API unifiée avec le modèle ToolResult, ajout de l'intégration d'outils d'appel de fonctions OpenAI ou écriture de tests et de documentation standardisés.

Capacités : conseils sur la structure du projet depuis la migration d'un fichier unique vers un package, indicateurs unifiés CLI (-V, -v, -o, --json, -q), API Python avec modèle de classe de données ToolResult, appel de fonction avec TOOLS + modèle de répartition, documentation README bilingue avec captures d'écran automatiques et tests pytest avec structure de test unifiée.
