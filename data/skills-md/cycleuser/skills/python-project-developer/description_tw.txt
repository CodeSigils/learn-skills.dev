CLI/GUI 工具的完整 Python 多專案開發規格。

在以下情況下觸發：建立具有 CLI 和 GUI 支援的新 Python 專案、使用 README 和 PyPI 發佈設定 pyproject.toml、使用 ToolResult 模式實作統一 API、新增 OpenAI 函數呼叫工具整合或編寫標準化測試和文件。

功能：從單一文件到套件​​遷移的專案結構指導、CLI 統一標誌（-V、-v、-o、--json、-q）、具有 ToolResult 資料類別模式的 Python API、使用 TOOLS + 調度模式進行函數呼叫、具有自動螢幕截圖的雙語 README 文件以及具有統一測試結構的 pytest 測試。
