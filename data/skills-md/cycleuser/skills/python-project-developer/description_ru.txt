Полная спецификация многопроектной разработки Python для инструментов CLI/GUI.

Срабатывает при: создании нового проекта Python с поддержкой CLI и GUI, настройке pyproject.toml с помощью README и публикации PyPI, реализации унифицированного API с шаблоном ToolResult, добавлении интеграции инструментов вызова функций OpenAI или написании стандартизированных тестов и документации.

Возможности: руководство по структуре проекта от миграции одного файла к пакету, унифицированные флаги CLI (-V, -v, -o, --json, -q), API Python с шаблоном класса данных ToolResult, вызов функций с шаблоном диспетчеризации ИНСТРУМЕНТЫ +, двуязычная документация README с автоматическими скриншотами и тестирование pytest с унифицированной структурой тестирования.
