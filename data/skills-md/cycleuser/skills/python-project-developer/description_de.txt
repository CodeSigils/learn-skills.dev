Vollständige Python-Multiprojekt-Entwicklungsspezifikation für CLI/GUI-Tools.

Wird ausgelöst, wenn: Erstellen eines neuen Python-Projekts mit CLI- und GUI-Unterstützung, Einrichten von pyproject.toml mit README- und PyPI-Veröffentlichung, Implementieren einer einheitlichen API mit ToolResult-Muster, Hinzufügen der Integration von OpenAI-Funktionsaufruftools oder Schreiben standardisierter Tests und Dokumentation.

Fähigkeiten: Anleitung zur Projektstruktur von der Einzeldatei- bis zur Paketmigration, einheitliche CLI-Flags (-V, -v, -o, --json, -q), Python-API mit ToolResult-Datenklassenmuster, Funktionsaufruf mit TOOLS + Dispatch-Muster, zweisprachige README-Dokumentation mit automatischen Screenshots und Pytest-Tests mit einheitlicher Teststruktur.
