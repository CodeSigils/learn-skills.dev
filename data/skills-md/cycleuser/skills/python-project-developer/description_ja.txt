CLI/GUI ツール用の完全な Python マルチプロジェクト開発仕様。

トリガーされるタイミング: CLI および GUI サポートを使用した新しい Python プロジェクトの作成、README および PyPI 公開による pyproject.toml のセットアップ、ToolResult パターンによる統合 API の実装、OpenAI 関数呼び出しツール統合の追加、または標準化されたテストとドキュメントの作成。

機能: 単一ファイルからパッケージへの移行までのプロジェクト構造のガイダンス、CLI 統合フラグ (-V、-v、-o、--json、-q)、ToolResult データクラス パターンを使用した Python API、TOOLS + ディスパッチ パターンを使用した関数呼び出し、自動スクリーンショット付きのバイリンガル README ドキュメント、および統合テスト構造を使用した pytest テスト。
