Completar la especificación de desarrollo multiproyecto de Python para herramientas CLI/GUI.

Se activa cuando: se crea un nuevo proyecto Python con soporte CLI y GUI, se configura pyproject.toml con README y publicación PyPI, se implementa una API unificada con el patrón ToolResult, se agrega integración de herramientas de llamada de funciones OpenAI o se escriben pruebas y documentación estandarizadas.

Capacidades: guía de estructura de proyecto desde migración de un solo archivo a paquete, indicadores unificados de CLI (-V, -v, -o, --json, -q), API de Python con patrón de clase de datos ToolResult, llamada de funciones con patrón de envío TOOLS +, documentación README bilingüe con capturas de pantalla automáticas y pruebas de pytest con estructura de prueba unificada.
