Schreibe ein kontextbezogenes Commit, das Absicht, Entscheidungsfindung und Einschränkungen zusammen mit den Code‑Änderungen erfasst. Verwende es beim Committen, wenn eine Aufgabe abgeschlossen ist oder wenn ein Benutzer ein Commit anfordert. Durch die Erweiterung von Conventional Commits und das Hinzufügen einer strukturierten Aktionszeile zum Commit‑Body bewahren wir nicht nur, was geändert wurde, sondern auch, warum der Code geschrieben wurde.
