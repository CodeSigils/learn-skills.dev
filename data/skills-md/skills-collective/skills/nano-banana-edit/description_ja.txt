RunComfy 上の Google Nano Banana 2 (画像間編集エンドポイント) を使用して画像を編集します。 Nano Banana Edit の強み (被写体のアイデンティティの保持、背景の交換、空間言語による編集のローカライズ、最大 20 入力までの複数画像のバッチ編集)、スキーマ、および代わりに GPT Image 2 edit / Flux Kontext / Nano Banana 2 t2i にルーティングするタイミングについて説明します。ローカルの RunComfy CLI を介して「runco​​mfy run google/nano-banana-2/edit」を呼び出します。 「ナノ バナナ編集」、「ナノ バナナで編集」、「イメージ編集ナノ バナナ」、またはこのモデルで編集するという明示的な要求でトリガーされます。
