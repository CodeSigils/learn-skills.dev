编辑 RunComfy 上的现有视频 - 该技能是一个智能路由器，可将用户的意图与 RunComfy 目录中的正确编辑模型相匹配。选择 Wan 2.7 Edit-Video（一般重新设计/背景交换/包装交换、身份+运动保留）、Kling 2.6 Pro Motion Control（将参考视频的精确运动转移到目标角色）或 Lucy Edit Restyle（轻量级身份稳定重新设计/服装交换）。捆绑每个模型记录的提示模式，以便技能得到更清晰的编辑，而无需在错误的模型上进行迭代。通过本地 RunComfy CLI 调用 `runco​​mfy run <vendor>/<model>/<endpoint>`。在“视频编辑”、“编辑视频”、“重新设计视频”、“交换视频背景”、“动作控制”、“服装交换视频”或任何明确的视频转换要求时触发。
