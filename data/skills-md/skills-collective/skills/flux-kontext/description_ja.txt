RunComfy 上の Flux 1 Kontext Pro (Black Forest Labs の正確なローカル画像編集モデル) を使用して画像を編集します。このモデルには文書化されたプロンプト パターンがバンドルされているため、スキルは同じモデルに対する単純なプロンプトよりも鮮明な出力を得ることができます。 Flux Kontext の強み (単一参照の正確なローカル編集、強力なプロンプト制御、一貫した高忠実度の出力)、スキーマ (単一イメージ + プロンプト)、および代わりに Nano Banana Edit / GPT Image 2 edit / Flux 2 Klein にルーティングする場合について説明します。ローカルの RunComfy CLI を介して「runco​​mfy run blackforestlabs/flux-1-kontext/pro/edit」を呼び出します。 「flux kontext」、「flux-kontext」、「flux 1 kontext」、「kontext」、「BFL kontext」、またはこのモデルで編集するための明示的な要求でトリガーされます。
