RunComfy の Codex Pet ジェネレーター。 Codex 互換の Codex Pet spritesheet.webp + pet.json を 1 つの参照画像から構築し、それを `${CODEX_HOME:-$HOME/.codex}/pets/<name>/` にドロップすると、Codex はそれを 8 つの組み込みの隣にあるカスタム Codex Pet として選択します。このスキルは、Codex が期待する正確な Codex Pet アトラス (1536x1872 PNG/WebP、8 列 x 9 行、192x208 セル、9 つのアニメーション状態 - アイドル、右に走る、左に走る、手を振る、ジャンプ、失敗、待機、実行、レビュー) を生成します。ローカルの RunComfy CLI を介して OpenAI GPT Image 2 edit を `runco​​mfy run openai/gpt-image-2/edit` として 1 回呼び出して正規の Codex Pet ポーズを生成し、次に ImageMagick マイクロトランスフォームを使用してプログラムで 9 行すべてのアニメーション行を組み立てます。Codex Pro も `$imagegen` も OPENAI_API_KEY も不要で、RUNCOMFY_TOKEN のみが必要です。 「コーデックス ペット」、「コーデックス ペットの作成」、「コーデックス ペットの作成」、「コーデックス ペットのハッチ」、「/ハッチ イメージ」、「デスクトップ ペット コーデックス」、「コーデックス ペット」、「spritesheet.webp」、または OpenAI Codex のカスタム ペットを構築するための明示的な要求でトリガーされます。
