Da utilizzare durante la scrittura di test E2E con Selenium WebDriver e Cucumber BDD in Java, la configurazione dell'infrastruttura di test BDD con Maven o Gradle, la scrittura di file di funzionalità Gherkin, l'implementazione di definizioni di passaggi in Java, la configurazione del modello di oggetti di pagina o del modello di sceneggiatura, l'impostazione dell'esecuzione parallela, la generazione di report nativi ExtentReports o Cucumber o l'integrazione di test con GitHub Actions e Docker/Selenium Grid. Invoca per Cucumber Java, Selenium 4, Gherkin, Given When Then, Page Object, Screenplay, TestNG, JUnit, WebDriverManager, PicoContainer, sviluppo guidato dal comportamento in Java, BDD Java, selenium grid, docker selenium, test parallelo Java o qualsiasi configurazione del framework di automazione che coinvolga test Java + browser. Assicurati di utilizzare questa abilità ogni volta che l'utente chiede informazioni sull'automazione del browser basata su Selenium, Cucumber o Java, anche se dice semplicemente "pruebas automatizadas en Java" o "test E2E con Java".
