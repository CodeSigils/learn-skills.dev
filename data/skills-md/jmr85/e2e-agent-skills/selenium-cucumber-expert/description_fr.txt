À utiliser lors de l'écriture de tests E2E avec Selenium WebDriver et Cucumber BDD en Java, de la configuration de l'infrastructure de test BDD avec Maven ou Gradle, de l'écriture de fichiers de fonctionnalités Gherkin, de l'implémentation de définitions d'étapes en Java, de la configuration du modèle d'objet de page ou du modèle de scénario, de la configuration de l'exécution parallèle, de la génération de rapports natifs ExtentReports ou Cucumber ou de l'intégration de tests avec GitHub Actions et Docker/Selenium Grid. Invoquez Cucumber Java, Selenium 4, Gherkin, Given When Then, Page Object, Screenplay, TestNG, JUnit, WebDriverManager, PicoContainer, le développement axé sur le comportement en Java, BDD Java, Selenium Grid, Docker Selenium, les tests parallèles Java ou toute configuration de cadre d'automatisation impliquant des tests Java + navigateur. Assurez-vous d'utiliser cette compétence chaque fois que l'utilisateur pose des questions sur l'automatisation du navigateur basé sur Selenium, Cucumber ou Java, même s'il dit simplement "pruebas automatizadas en Java" ou "test E2E con Java".
