يُستخدم عند كتابة اختبارات E2E باستخدام Selenium WebDriver وCucumber BDD في Java، أو إعداد البنية الأساسية لاختبار BDD باستخدام Maven أو Gradle، أو كتابة ملفات ميزات Gherkin، أو تنفيذ تعريفات الخطوة في Java، أو تكوين نموذج كائن الصفحة أو نمط السيناريو، أو إعداد التنفيذ المتوازي، أو إنشاء تقارير ExtentReports أو تقارير Cucumber الأصلية، أو دمج الاختبارات مع إجراءات GitHub وDocker/Selenium Grid. استدعاء Cucumber Java، وSelenium 4، وGherkin، وGive When When، وPage Object، وScreenplay، وTestNG، وJUnit، وWebDriverManager، وPicoContainer، والتطوير القائم على السلوك في Java، وBDD Java، وشبكة السيلينيوم، وdocker selenium، والاختبار المتوازي Java، أو أي إعداد إطار عمل أتمتة يتضمن اختبار Java + المتصفح. تأكد من استخدام هذه المهارة عندما يسأل المستخدم عن أتمتة المتصفح المستندة إلى السيلينيوم أو الخيار أو Java، حتى لو قال فقط "pruebas automatizadas en Java" أو "test E2E con Java".
