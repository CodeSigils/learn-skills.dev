Генерирует страницы ZUL ZK Framework (.zul) посредством структурированного четырехэтапного рабочего процесса: уточнение требований, генерация ZUL, проверка и генерация контроллера. Поддерживает шаблоны MVC (на основе Composer) и MVVM (на основе ViewModel), ZK 9/10, а также визуальный анализ для преобразования снимков экрана в ZUL. Используйте, когда пользователь просит создать страницу ZUL, создать компоненты пользовательского интерфейса ZK (формы, сетки, информационные панели, рамки) или преобразовать изображение/макет в код ZUL.
