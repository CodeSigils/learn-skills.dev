Generiert ZK Framework ZUL-Seiten (.zul) durch einen strukturierten 4-Schritte-Workflow: Anforderungsklärung, ZUL-Generierung, Validierung und Controller-Generierung. Unterstützt sowohl MVC- (Composer-basierte) als auch MVVM- (ViewModel-basierte) Muster, ZK 9/10 und visuelle Analyse für die Konvertierung von Screenshots in ZUL. Verwenden Sie diese Option, wenn der Benutzer eine ZUL-Seite erstellen, ZK-UI-Komponenten (Formulare, Raster, Dashboards, Rahmenlayouts) erstellen oder ein Bild/Mockup in ZUL-Code konvertieren möchte.
