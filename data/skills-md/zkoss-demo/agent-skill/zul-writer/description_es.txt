Genera páginas ZK Framework ZUL (.zul) a través de un flujo de trabajo estructurado de 4 pasos: aclaración de requisitos, generación de ZUL, validación y generación de controladores. Admite patrones MVC (basado en Composer) y MVVM (basado en ViewModel), ZK 9/10 y análisis visual para conversión de captura de pantalla a ZUL. Úselo cuando el usuario solicite crear una página ZUL, crear componentes de interfaz de usuario ZK (formularios, cuadrículas, paneles, diseños de bordes) o convertir una imagen/maqueta a código ZUL.
