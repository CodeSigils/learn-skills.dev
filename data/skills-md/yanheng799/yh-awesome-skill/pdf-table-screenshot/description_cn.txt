从PDF文档的指定章节、页面范围中检测表格，将每个表格保存为PNG图片。
从 PDF 文档中的指定章节、部分或页面范围中提取并裁剪表格屏幕截图。
当用户要求执行以下操作时使用此技能：
- “截取PDF中第3章的表格”或“从第3章中提取表格”
- “把这个PDF第2章的表格截图保存下来”
- “截图PDF中10-20页的所有表格”
- “提取 PDF 表格为图片”或“将 PDF 表格另存为图像”
- “把这个PDF中3.2节的表格截出来”
- 任何涉及 PDF 表格提取、表格屏幕截图、表格裁剪或表格图像捕获的请求
特点：
- 通过书签、目录或文本模式匹配进行章节/章节检测
- 直接页面范围规范作为后备
- 使用 pdfplumber 自动表检测
- 通过 PyMuPDF 进行高质量表格图像裁剪（无需 Poppler）
- 支持中英文章节模式
- 可配置 DPI 以保证输出图像质量
- 自动检测单列/双列页面布局
- 合并双栏 PDF 中的拆分表
