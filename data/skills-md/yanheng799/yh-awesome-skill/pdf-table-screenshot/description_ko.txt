从PDF문서는 页face范围中检测表格, 并将每个表格裁剪保存为PNG이미지입니다.
PDF 문서의 지정된 장, 섹션 또는 페이지 범위에서 표 스크린샷을 추출하고 자릅니다.
사용자가 다음을 요청할 때 이 기술을 사용하세요.
- "截取PDF中第3章的表格" 또는 "3장에서 표 추출"
- "PDF第2章的表格截图保存下来"
- "截图PDF中10-20页的所有表格"
- "提取PDF表格为图picture" 또는 "PDF 테이블을 이미지로 저장"
- "PDF中3.2节的表格截来"
- PDF 테이블 추출, 테이블 스크린샷, 테이블 자르기 또는 테이블 이미지 캡처와 관련된 모든 요청
특징:
- 북마크, 목차 또는 텍스트 패턴 일치를 통한 장/섹션 감지
- 폴백으로 직접 페이지 범위 지정
- pdfplumumber를 사용한 자동 테이블 감지
- PyMuPDF를 통한 고품질 테이블 이미지 자르기(Poppler 필요 없음)
- 중국어, 영어 챕터 패턴 지원
- 출력 이미지 품질을 위해 구성 가능한 DPI
- 단일/이중 열 페이지 레이아웃 자동 감지
- 이중 열 PDF에서 분할 테이블 병합
