Особенности:
- Обнаружение глав/разделов с помощью закладок, оглавления или сопоставления текстовых шаблонов.
- Прямое указание диапазона страниц в качестве резервного варианта.
- Автоматическое обнаружение стола с помощью pdfplumber
- Высококачественная обрезка изображений таблиц с помощью PyMuPDF (попплер не требуется)
- Поддерживает шаблоны глав на китайском и английском языках.
- Настраиваемый DPI для качества выходного изображения
- Автоматическое определение макетов страниц с одной или двумя колонками.
- Объединение разделенных таблиц в PDF-файлы с двумя столбцами.
