Enseña a los agentes a utilizar un registro de puntos finales MPP (Protocolo de pagos automáticos): buscar antes de pagar, informar puntos finales de pago HTTP 402 recién descubiertos y enviar revisiones después de cada uso. Úselo cuando trabaje con MPP, HTTP 402, API de pago por solicitud, pagos de máquina a máquina o descubrimiento de MPP basado en registro.
