Обучает агентов использовать реестр конечных точек MPP (протокол машинных платежей): выполнять поиск перед оплатой, сообщать о вновь обнаруженных конечных точках платежей HTTP 402 и отправлять отзывы после каждого использования. Используйте при работе с MPP, HTTP 402, API с оплатой за запрос, межмашинными платежами или обнаружением MPP на основе реестра.
