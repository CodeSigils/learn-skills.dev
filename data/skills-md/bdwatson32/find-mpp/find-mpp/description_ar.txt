يعلم الوكلاء كيفية استخدام سجل نقطة النهاية MPP (بروتوكول مدفوعات الآلة): ابحث قبل الدفع، وأبلغ عن نقاط نهاية الدفع HTTP 402 المكتشفة حديثًا، وأرسل المراجعات بعد كل استخدام. يُستخدم عند العمل مع MPP أو HTTP 402 أو واجهات برمجة تطبيقات الدفع لكل طلب أو الدفعات من جهاز إلى جهاز أو اكتشاف MPP المستند إلى التسجيل.
