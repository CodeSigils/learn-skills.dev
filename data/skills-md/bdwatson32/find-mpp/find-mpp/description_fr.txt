Apprenez aux agents à utiliser un registre de points de terminaison MPP (Machine Payments Protocol) : effectuez une recherche avant de payer, signalez les points de terminaison de paiement HTTP 402 nouvellement découverts et soumettez des avis après chaque utilisation. À utiliser lorsque vous travaillez avec MPP, HTTP 402, les API de paiement à la demande, les paiements de machine à machine ou la découverte MPP basée sur le registre.
