Insegna agli agenti a utilizzare un registro degli endpoint MPP (Machine Payments Protocol): effettua ricerche prima di pagare, segnala gli endpoint di pagamento HTTP 402 appena scoperti e invia recensioni dopo ogni utilizzo. Da utilizzare quando si lavora con MPP, HTTP 402, API pay-per-request, pagamenti da macchina a macchina o rilevamento MPP basato sul registro.
