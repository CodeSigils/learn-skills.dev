Escanee el código base y clasifique cada hecho por etapa del ciclo de vida: etiquete @draft, @spec o @implemented según lo que realmente muestra el código. Agregue datos faltantes, corrija los inexactos y elimine los obsoletos. Úselo cuando se le solicite descubrir hechos, iniciar o actualizar una hoja informativa, escanear la base del código en busca de verdades, sincronizar hechos para que coincidan con el código o auditar la hoja informativa para verificar su precisión.
