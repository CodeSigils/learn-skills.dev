Scannen Sie die Codebasis und klassifizieren Sie jeden Fakt nach Lebenszyklusphase – markieren Sie @draft, @spec oder @implemented basierend auf dem, was der Code tatsächlich zeigt. Fügen Sie fehlende Fakten hinzu, korrigieren Sie ungenaue und entfernen Sie veraltete. Verwenden Sie es, wenn Sie dazu aufgefordert werden, Fakten zu ermitteln, ein Faktenblatt zu booten oder zu aktualisieren, die Codebasis nach Wahrheiten zu durchsuchen, Fakten zu synchronisieren, damit sie mit dem Code übereinstimmen, oder das Faktenblatt auf Richtigkeit zu prüfen.
