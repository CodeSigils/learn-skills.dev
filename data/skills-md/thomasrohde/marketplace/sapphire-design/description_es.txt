Aproxima el sistema de diseño Danske Bank Sapphire usando CSS y HTML simples, sin instalar paquetes @danske/sapphire-*. Utilice esta habilidad siempre que el usuario solicite crear una interfaz de usuario que debería parecerse a Sapphire, coincidir con el sistema de diseño de Danske Bank, crear componentes con estilo Sapphire o quiera una interfaz de usuario bancaria/fintech con un lenguaje de diseño escandinavo. También se activa cuando el usuario menciona "tokens de zafiro", "componentes de zafiro" o quiere crear prototipos de interfaz de usuario que sigan el estilo visual de Zafiro. Esta habilidad es independiente del marco y funciona con cualquier pila de interfaz.
