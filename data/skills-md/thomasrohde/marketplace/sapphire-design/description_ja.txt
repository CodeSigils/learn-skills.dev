@danske/sapphire-* パッケージをインストールせずに、プレーンな CSS と HTML を使用して Danske Bank Sapphire デザイン システムを近似します。ユーザーが、Sapphire に似た UI の構築、Danske Bank のデザイン システムとの一致、Sapphire スタイルのコンポーネントの作成、またはスカンジナビアのデザイン言語を使用した銀行/フィンテック UI の作成を要求する場合は常に、このスキルを使用します。また、ユーザーが「サファイア トークン」や「サファイア コンポーネント」に言及した場合、または Sapphire のビジュアル スタイルに従う UI プロトタイプを作成したい場合にもトリガーされます。このスキルはフレームワークに依存せず、あらゆるフロントエンド スタックで動作します。
