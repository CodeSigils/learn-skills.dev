从 PRD 文件生成独立的、代理可执行的执行计划 (ExecPlans)。每当用户想要“创建计划”、“生成执行计划”、“将 PRD 转换为计划”、“编写 ExecPlan”、“从 PRD 创建实施计划”、“将 PRD 分解为步骤”、“从需求制定计划”、“将 PRD 转换为计划”，或在从需求文档生成计划的上下文中提及“ExecPlan”、“执行计划”或“实施计划”时，请使用此技能。当用户拥有 PRD.md 文件并想要可操作的后续步骤（例如“计划实施”、“从该 PRD 创建里程碑”或“如何实施该 PRD”时）也会触发。这项技能生成的计划可供无状态编码代理或人类新手从上到下遵循，以提供有效的、可观察的结果。
