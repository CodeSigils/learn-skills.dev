Создавайте автономные, исполняемые агентом планы выполнения (ExecPlans) из файлов PRD. Используйте этот навык всякий раз, когда пользователь хочет «создать план», «сгенерировать план выполнения», «превратить PRD в план», «написать ExecPlan», «создать план реализации из PRD», «разбить PRD на этапы», «составить план из требований», «преобразовать PRD в план» или упоминает «ExecPlan», «план выполнения» или «план реализации» в контексте создания плана из документа с требованиями. Также срабатывает, когда у пользователя есть файл PRD.md и он хочет выполнить следующие действия, например: «Спланировать реализацию», «Создать этапы на основе этого PRD» или «Как мне реализовать этот PRD». Этот навык создает планы, которым агент кодирования без сохранения состояния или человек-новичок может следовать сверху донизу, чтобы получить работающие, наблюдаемые результаты.
