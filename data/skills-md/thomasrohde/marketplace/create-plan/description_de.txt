Generieren Sie eigenständige, vom Agenten ausführbare Ausführungspläne (ExecPlans) aus PRD-Dateien. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer „einen Plan erstellen“, „einen Ausführungsplan generieren“, „eine PRD in einen Plan umwandeln“, „einen ExecPlan schreiben“, „einen Implementierungsplan aus einer PRD erstellen“, „eine PRD in Schritte aufteilen“, „einen Plan aus Anforderungen erstellen“, „PRD in einen Plan umwandeln“ möchte oder „ExecPlan“, „Ausführungsplan“ oder „Implementierungsplan“ im Zusammenhang mit der Erstellung eines Plans aus einem Anforderungsdokument erwähnt. Wird auch ausgelöst, wenn der Benutzer über eine PRD.md-Datei verfügt und umsetzbare nächste Schritte wünscht, z. B. „Planen Sie die Implementierung“, „Erstellen Sie Meilensteine ​​aus diesem PRD“ oder „Wie implementieren Sie diesen PRD“. Diese Fähigkeit erstellt Pläne, die ein zustandsloser Programmieragent oder ein menschlicher Neuling von oben bis unten befolgen kann, um funktionierende, beobachtbare Ergebnisse zu liefern.
