Entdecken, prüfen, abgleichen, ändern und löschen Sie GitHub Copilot-Anpassungen sowohl in Copilot IDE (VS Code) als auch in Copilot CLI-Umgebungen. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „Copilot-Anpassungen auflisten“, „Copilot-Dateien finden“, „Copilot-Setup prüfen“, „welche Copilot-Konfigurationen ich habe“, „Copilot-IDE und CLI abgleichen“, „Copilot-Dateien bereinigen“, „Copilot-Agent löschen“, „Copilot-Anweisungen anzeigen“, „Copilot-Konfigurationen vergleichen“, „nicht verwendete Copilot-Anpassungen entfernen“, „Copilot-Drift“, „Copilot-Inventar“, „Was sieht Copilot“, „Copilot verwalten“, „Copilot Hygiene“ oder jede Anfrage, die das Untersuchen, Überprüfen, Ändern oder Entfernen vorhandener Copilot-Anpassungsdateien beinhaltet. Wird auch ausgelöst, wenn der Benutzer Konflikte zwischen Copilot IDE und Copilot CLI oder Probleme mit der gegenseitigen Lesbarkeit erwähnt oder verstehen möchte, welche Dateien jede Copilot-Variante sieht. Löst NICHT die Erstellung neuer Anpassungen von Grund auf aus (verwenden Sie stattdessen die Fertigkeit „Copilot-Anpassung“).
