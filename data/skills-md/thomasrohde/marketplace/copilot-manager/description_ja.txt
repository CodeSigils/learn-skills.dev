Copilot IDE (VS Code) と Copilot CLI 環境の両方で、GitHub Copilot のカスタマイズを検出、監査、調整、変更、削除します。このスキルは、ユーザーが「コパイロットのカスタマイズの一覧表示」、「コパイロット ファイルの検索」、「コパイロットのセットアップの監査」、「どのようなコパイロット構成があるか」、「コパイロット IDE と CLI の調整」、「コパイロット ファイルのクリーンアップ」、「コパイロット エージェントの削除」、「コパイロットの指示の表示」、「コパイロット構成の比較」、「未使用のコパイロット カスタマイズの削除」を行う場合に使用します。 「副操縦士のドリフト」、「副操縦士のインベントリ」、「副操縦士が何を参照しているか」、「副操縦士の管理」、「副操縦士の衛生状態」、または既存の副操縦士カスタマイズ ファイルの探索、検査、変更、または削除を含むあらゆる要求。また、ユーザーが Copilot IDE と Copilot CLI 間の競合、相互可読性の問題について言及した場合、または各 Copilot バリアントがどのファイルを参照するかを理解したい場合にもトリガーされます。新しいカスタマイズを最初から作成する場合はトリガーされません (代わりに、copilot-customization スキルを使用してください)。
