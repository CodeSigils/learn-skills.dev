Примените рубрику EAROS к артефакту архитектуры, используя шаблон трехпроходной оценки агента (Extractor, Evaluator, Challenger). Используйте этот навык всякий раз, когда пользователь хочет «оценить архитектурный артефакт», «применить критерий», «рассмотреть архитектурный документ», «оценить архитектурный артефакт», «провести оценку EAROS», «оценить качество архитектуры», «применить критерий архитектуры решения», «оценить этот ADR», «просмотреть эту карту возможностей», «проверить это по критерию», «запустить обзор архитектуры» или упоминает «оценить», «оценить», «оценить», «пересмотреть» или «применить». рубрика» в контексте применения рубрики EAROS к конкретному артефакту. Также срабатывает, когда пользователь говорит: «Как оценивается этот артефакт», «Достаточно ли хорош этот архитектурный документ», «Запустите трехпроходную оценку», «Извлеките доказательства из этого документа» или любой запрос на систематическую оценку конкретного рабочего продукта архитектуры по определенным критериям. НЕ срабатывает для создания рубрик (используйте для этого Earos-Rubric), общего моделирования архитектуры или создания диаграмм.
