قم بتطبيق نموذج تقييم EAROS على قطعة أثرية معمارية باستخدام نمط تقييم الوكيل ثلاثي التمريرات (Extractor، Evaluator، Challenger). استخدم هذه المهارة عندما يريد المستخدم "تقييم عنصر معماري" أو "تطبيق نموذج تقييم" أو "مراجعة مستند معماري" أو "تسجيل عنصر معماري" أو "تشغيل تقييم EAROS" أو "تقييم جودة التصميم المعماري" أو "تطبيق نموذج تقييم تصميم الحل" أو "تقييم ADR" أو "مراجعة خريطة القدرة هذه" أو "التحقق من ذلك مقابل نموذج التقييم" أو "تشغيل مراجعة البنية" أو ذكر "تقييم" أو "تسجيل نقاط" أو "تقييم" أو "مراجعة" أو "تطبيق عنوان التقييم" في سياق تطبيق عنوان تقييم EAROS على قطعة أثرية معينة. يتم تشغيله أيضًا عندما يقول المستخدم "كيف يتم تسجيل هذه القطعة الأثرية"، أو "هل مستند الهندسة هذا جيد بما فيه الكفاية"، أو "تشغيل التقييم ثلاثي المراحل"، أو "استخراج الأدلة من هذا المستند"، أو أي طلب لإجراء تقييم منهجي لمنتج عمل معماري محدد مقابل معايير محددة. لا يتم تشغيله لإنشاء نماذج تقييم (استخدم نموذج تقييم الأذن لذلك)، أو نمذجة الهندسة المعمارية العامة، أو إنشاء المخططات.
