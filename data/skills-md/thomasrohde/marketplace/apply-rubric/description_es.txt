Aplique una rúbrica EAROS a un artefacto de arquitectura utilizando el patrón de evaluación de agentes de tres pasos (Extractor, Evaluador, Challenger). Utilice esta habilidad siempre que el usuario quiera "evaluar un artefacto de arquitectura", "aplicar una rúbrica", "revisar un documento de arquitectura", "calificar un artefacto de arquitectura", "ejecutar una evaluación EAROS", "evaluar la calidad de la arquitectura", "aplicar la rúbrica de arquitectura de la solución", "evaluar este ADR", "revisar este mapa de capacidades", "comprobar esto con la rúbrica", "ejecutar la revisión de arquitectura" o mencione "evaluar", "calificar", "evaluar", "revisar" o "aplicar". rúbrica" en el contexto de la aplicación de una rúbrica EAROS a un artefacto específico. También se activa cuando el usuario dice "¿cómo califica este artefacto?", "este documento de arquitectura es lo suficientemente bueno", "ejecuta la evaluación de tres pasos", "extrae evidencia de este documento" o cualquier solicitud para evaluar sistemáticamente un producto de trabajo de arquitectura específico según criterios definidos. NO se activa para la creación de rúbricas (use earos-rubric para eso), el modelado de arquitectura general o la creación de diagramas.
