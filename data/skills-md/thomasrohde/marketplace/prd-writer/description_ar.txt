كتابة مستندات متطلبات المنتج (PRDs) الجاهزة للمؤسسة والقابلة للتنفيذ من قبل الوكيل. استخدم هذه المهارة عندما يريد المستخدم "كتابة PRD" أو "إنشاء PRD" أو "مسودة متطلبات المنتج" أو "إنشاء مواصفات منتج" أو "كتابة متطلبات لميزة جديدة" أو "إنشاء مستند منتج" أو "كتابة PRD وكيل" أو "إنشاء مستند متطلبات" أو "صياغة PRD لوكلاء الترميز" أو "التخطيط لمنتج أو ميزة جديدة" أو ذكر "PRD" أو "وثيقة متطلبات المنتج" أو "مواصفات المنتج" في سياق كتابة أو إنشاء واحد. يتم تشغيله أيضًا عندما يقول المستخدم "ساعدني في التخطيط لميزة ما" أو "نطاق المشروع" أو "حدد متطلبات" شيء ما. تنتج هذه المهارة PRDs التي يمكن لوكلاء الترميز تنفيذها بانجراف منخفض، وإعادة صياغة منخفضة، وحوكمة قوية.
