Intégrez des compétences sous forme de plugins dans la place de marché des plugins Claude Code. Utilisez cette compétence chaque fois que l'utilisateur souhaite « ajouter une compétence au marché », « créer un plugin à partir d'une compétence », « empaqueter une compétence en tant que plugin », « enregistrer un plugin », « intégrer une compétence », « convertir une compétence en plugin », « échafauder un plugin » ou mentionne l'ajout de quelque chose au répertoire des plugins. Activez également lorsque l'utilisateur dispose d'un SKILL.md qu'il souhaite publier, souhaite mettre à jour Marketplace.json ou travaille sur la structure du plugin dans ce référentiel.
