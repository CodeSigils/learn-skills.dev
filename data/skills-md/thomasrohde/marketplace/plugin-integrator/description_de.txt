Integrieren Sie Fähigkeiten als Plugins in den Plugin-Marktplatz von Claude Code. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „einen Skill zum Marktplatz hinzufügen“, „ein Plugin aus einem Skill erstellen“, „einen Skill als Plugin verpacken“, „ein Plugin registrieren“, „einen Skill integrieren“, „einen Skill in ein Plugin umwandeln“, „ein Plugin aufbauen“ möchte oder erwähnt, dass er etwas zum Plugin-Verzeichnis hinzufügen möchte. Aktivieren Sie diese Funktion auch, wenn der Benutzer über eine SKILL.md verfügt, die er veröffentlichen möchte, wenn er marketplace.json aktualisieren möchte oder an der Plugin-Struktur in diesem Repository arbeitet.
