إنشاء معايير جديدة لتقييم البنية (ملفات التعريف والتراكبات) استنادًا إلى المعيار التشغيلي لقاعدة تقييم البنية المؤسسية (EAROS). استخدم هذه المهارة عندما يريد المستخدم "إنشاء قاعدة تقييم"، "إضافة ملف تعريف عنوان"، "كتابة عنوان تقييم معماري"، "تحديد معايير التسجيل لعناصر الهندسة المعمارية"، "إنشاء ملف تعريف EAROS"، "إضافة تراكب"، "إنشاء تراكب أمان"، "إنشاء تراكب بيانات"، "تقييم عناصر الهندسة المعمارية"، "إعداد معايير مراجعة البنية"، "إنشاء نموذج تقييم لهندسة الحلول"، "إنشاء نموذج تقييم ADR"، "إنشاء نموذج تقييم خريطة القدرات"، "تحديد معايير جودة الهندسة المعمارية"، أو يذكر "EAROS" أو "نموذج التقييم" أو "تقييم البنية" أو "ملف تعريف النقاط" أو "معايير مراجعة البنية" في سياق إنشاء معايير التقييم أو توسيعها. يتم تشغيله أيضًا عندما يقول المستخدم "ساعدني في تقييم مستندات الهندسة المعمارية"، أو "حدد معايير المراجعة لمنتجنا"، أو "توحيد مراجعة الهندسة المعمارية"، أو "إنشاء قائمة مراجعة للمراجعة"، أو أي طلب لتقييم جودة منتجات عمل الهندسة المعمارية بشكل منهجي. لا يتم تشغيله لنمذجة البنية العامة أو إنشاء المخططات أو عمل ArchiMate - فقط لإنشاء التقييم/قواعد التقييم.
