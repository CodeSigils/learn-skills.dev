Создавайте корпоративные презентации PowerPoint с помощью инструментов CLI `pptx` и `excal`. Используйте этот навык всякий раз, когда пользователь хочет создать презентацию PowerPoint, создать слайды на основе шаблона, создать презентацию с диаграммами или создать контент слайдов в консультационном стиле. Также триггеры для запросов, включающих файлы .pptx, наборы слайдов, создание презентаций, диаграммы Excalidraw для слайдов или результаты McKinsey/консультационного стиля. Если пользователь упоминает «pptx», «excal», «слайды», «колоду», «презентацию» или «PowerPoint» в контексте создания результатов, используйте этот навык.
