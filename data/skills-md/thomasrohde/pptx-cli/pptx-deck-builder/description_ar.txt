أنشئ مجموعات PowerPoint للمؤسسة باستخدام أدوات `pptx` و`excal` CLI. استخدم هذه المهارة عندما يريد المستخدم إنشاء عرض تقديمي لـ PowerPoint، أو إنشاء شرائح من قالب، أو إنشاء مجموعة تحتوي على رسوم بيانية، أو إنتاج محتوى شرائح بنمط استشاري. يتم أيضًا تشغيل الطلبات التي تتضمن ملفات .pptx، أو مجموعات الشرائح، أو إنشاء العروض التقديمية، أو مخططات Excalidraw للشرائح، أو تسليمات نمط McKinsey/الاستشارات. إذا ذكر المستخدم "pptx" أو "excal" أو "slides" أو "deck" أو "presentation" أو "PowerPoint" في سياق إنشاء المخرجات، فاستخدم هذه المهارة.
