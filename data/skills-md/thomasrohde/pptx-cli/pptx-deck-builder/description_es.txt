Cree presentaciones de PowerPoint empresariales utilizando las herramientas CLI `pptx` y `excal`. Utilice esta habilidad siempre que el usuario quiera crear una presentación de PowerPoint, generar diapositivas a partir de una plantilla, crear una plataforma con diagramas o producir contenido de diapositivas con estilo de consultoría. También desencadena solicitudes que involucran archivos .pptx, presentaciones de diapositivas, generación de presentaciones, diagramas Excalidraw para diapositivas o entregables estilo McKinsey/consultoría. Si el usuario menciona "pptx", "excal", "diapositivas", "deck", "presentación" o "PowerPoint" en el contexto de la creación de resultados, utilice esta habilidad.
