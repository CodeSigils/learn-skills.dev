Herramienta de traducción automática de documentos PDF. Utiliza el motor BabelDOC para traducir documentos PDF en inglés al chino conservando el diseño original (los gráficos, las fórmulas y las posiciones de las imágenes permanecen sin cambios), y el archivo de salida recibe automáticamente el nombre del título chino del artículo. Admite URL de arXiv, ID de arXiv o ruta de PDF local como entrada. Se activa cuando el usuario envía un enlace arXiv, carga un archivo PDF o dice "traducir el documento", "traducir este PDF", "traducir el documento", "traducir el documento al chino", etc.
