Herramienta de traducción automática de documentos PDF. Utiliza el motor BabelDOC para traducir documentos PDF en inglés al chino conservando el diseño original (los gráficos, las fórmulas y las posiciones de las imágenes permanecen sin cambios) y el archivo de salida recibe automáticamente el nombre del título chino del documento. Admite URL de arXiv, ID de arXiv y rutas de PDF locales como entrada. Se activa cuando un usuario envía un enlace arXiv, carga un archivo PDF o dice frases como "traducir el documento", "traducir este PDF", "traducir el documento" o "traducir el documento al chino".
