Strumento di traduzione automatica di documenti PDF. Utilizza il motore BabelDOC per tradurre documenti PDF dall'inglese in cinese preservando il layout originale (figure, formule e posizioni delle immagini rimangono invariate) e nomina automaticamente il file di output con il titolo cinese del documento. Supporta URL arXiv, ID arXiv e percorsi PDF locali come input. Si attiva quando l'utente invia un collegamento arXiv, carica un file PDF o dice "traduci documento", "traduci questo PDF", "traduci documento" o "traduci il documento in cinese".
