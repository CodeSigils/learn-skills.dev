Strumento di traduzione automatica di documenti PDF. Utilizza il motore BabelDOC per tradurre documenti PDF dall'inglese in cinese preservando il layout originale (grafici, formule e posizioni delle immagini rimangono invariati) e il file di output viene automaticamente denominato con il titolo cinese del documento. Supporta URL arXiv, ID arXiv e percorsi PDF locali come input. Si attiva quando un utente invia un collegamento arXiv, carica un file PDF o pronuncia frasi come "traduci documento", "traduci questo PDF", "traduci documento" o "traduci il documento in cinese".
