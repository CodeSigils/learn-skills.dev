PDF paper automatic translation tool. Uses the BabelDOC engine to translate English PDF papers into Chinese while preserving the original layout (charts, formulas, and image positions remain unchanged), and the output file is automatically named with the paper's Chinese title. Supports arXiv URLs, arXiv IDs, and local PDF paths as input. Triggered when a user sends an arXiv link, uploads a PDF file, or says phrases like “translate paper,” “translate this PDF,” “translate paper,” or “translate the paper into Chinese.”
