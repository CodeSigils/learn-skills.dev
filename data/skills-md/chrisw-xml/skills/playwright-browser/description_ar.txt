ابدأ جلسة متصفح Playwright للفحص البصري وتصحيح الأخطاء والتفاعل مع خادم تطوير الواجهة الأمامية المحلي. يعرض لقطة الشاشة، والنقر، والكتابة، والتمرير، وسجل وحدة التحكم، وDOM، وأدوات إمكانية الوصول عبر خادم HTTP محلي. يُستخدم عندما يريد المستخدم منك "رؤية" واجهة المستخدم، أو تصحيح المشكلات المرئية، أو التحقق من تغييرات واجهة المستخدم، أو التفاعل مع الواجهة الأمامية قيد التشغيل، أو يذكر "فتح المتصفح"، أو "أرني الصفحة"، أو "التحقق من شكلها"، أو "كيف تبدو".
