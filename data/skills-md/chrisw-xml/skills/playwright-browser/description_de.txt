Starten Sie eine Playwright-Browsersitzung mit Kopf, um den lokalen Frontend-Entwicklungsserver visuell zu überprüfen, zu debuggen und mit ihm zu interagieren. Stellt Screenshot-, Klick-, Eingabe-, Bildlauf-, Konsolenprotokoll-, DOM- und Barrierefreiheitstools über einen lokalen HTTP-Server bereit. Verwenden Sie diese Option, wenn der Benutzer möchte, dass Sie die Benutzeroberfläche „sehen“, visuelle Probleme beheben, Änderungen an der Benutzeroberfläche überprüfen, mit dem laufenden Frontend interagieren oder „den Browser öffnen“, „zeigen Sie mir die Seite“, „überprüfen, wie sie aussieht“, „wie sieht sie aus“ erwähnt.
