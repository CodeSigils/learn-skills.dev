Démarrez une session de navigateur Playwright dirigée pour inspecter visuellement, déboguer et interagir avec le serveur de développement frontend local. Expose les outils de capture d'écran, de clic, de saisie, de défilement, de journal de console, DOM et d'accessibilité via un serveur HTTP local. À utiliser lorsque l'utilisateur souhaite que vous « voyiez » l'interface utilisateur, déboguiez les problèmes visuels, vérifiiez les modifications de l'interface utilisateur, interagiez avec l'interface en cours d'exécution ou mentionniez « ouvrir le navigateur », « me montrer la page », « vérifier à quoi elle ressemble », « à quoi ressemble-t-elle ».
