Inicie una sesión de navegador Playwright para inspeccionar, depurar e interactuar visualmente con el servidor de desarrollo frontend local. Expone capturas de pantalla, clics, escritura, desplazamiento, registro de consola, DOM y herramientas de accesibilidad a través de un servidor HTTP local. Úselo cuando el usuario quiera que "vea" la interfaz de usuario, depure problemas visuales, verifique los cambios de la interfaz de usuario, interactúe con la interfaz en ejecución o mencione "abrir el navegador", "muéstrame la página", "verificar cómo se ve", "cómo se ve".
