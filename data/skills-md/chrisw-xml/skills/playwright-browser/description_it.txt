Avvia una sessione del browser intestata di Playwright per ispezionare visivamente, eseguire il debug e interagire con il server di sviluppo frontend locale. Espone screenshot, clic, digitazione, scorrimento, registro della console, DOM e strumenti di accessibilità tramite un server HTTP locale. Da utilizzare quando l'utente desidera che tu "veda" l'interfaccia utente, esegua il debug di problemi visivi, verifichi le modifiche dell'interfaccia utente, interagisca con il frontend in esecuzione o menzioni "apri il browser", "mostrami la pagina", "controlla come appare", "che aspetto ha".
