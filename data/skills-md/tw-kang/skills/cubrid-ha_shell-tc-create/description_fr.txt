Utilisez-le chaque fois que quelqu'un dit "ha shell tc 만들어줘", "ha shell tc 초안 작성해줘", "create ha shell tc", "draft HA shell test", "새 ha 테스트케이스", "HA shell 테스트케이스". 작성", ou "créer un brouillon ha shell tc pour CBRD-XXXXX", même s'ils ne disent pas "testcase". Ils donnent généralement un numéro CBRD, le comportement HA à tester et parfois un répertoire de version cible. PAS pour : les tests shell réguliers (utilisez cubrid-shell-tc-create), les tests ha_repl au format SQL (utilisez cubrid-ha_repl-tc-create), la révision/débogage des tests existants, l'exécution de tests ou la configuration CTP.
