Cree, redacte o cree una nueva prueba unitaria CUBRID CTP: una prueba unitaria C/C++ de bajo nivel compilada a partir del código fuente CUBRID. Utilice esto siempre que alguien diga "unittest tc 만들어줘", "unit test 작성", "새 유닛테스트", "C unit test 추가", "crear unittest para CUBRID" o "borrador de prueba unitaria", incluso si no dicen "testcase". NO para: pruebas CCI (use cubrid-cci-tc-create), pruebas de shell (use cubrid-shell-tc-create), pruebas JDBC (use cubrid-jdbc-tc-create), revisión/ejecución de pruebas existentes o configuración CTP.
