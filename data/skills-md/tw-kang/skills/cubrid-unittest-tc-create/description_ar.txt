قم بإنشاء أو صياغة أو دعم اختبار وحدة CUBRID CTP جديد - وهو اختبار وحدة C/C++ منخفض المستوى تم تجميعه من مصدر CUBRID. استخدم هذا عندما يقول شخص ما "unittest tc 만들어줘"، أو "unit test 작성"، أو "새 유닛테스트"، أو "اختبار وحدة C 추가"، أو "إنشاء اختبار وحدة لـ CUBRID"، أو "اختبار وحدة المسودة"، حتى لو لم يقول "حالة اختبار". ليس من أجل: اختبارات CCI (استخدم cubrid-cci-tc-create)، أو اختبارات Shell (استخدم cubrid-shell-tc-create)، أو اختبارات JDBC (استخدم cubrid-jdbc-tc-create)، أو مراجعة/تشغيل الاختبارات الحالية، أو تكوين CTP.
