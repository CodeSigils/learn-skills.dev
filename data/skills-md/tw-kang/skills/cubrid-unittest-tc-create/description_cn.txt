创建、起草或构建新的 CUBRID CTP 单元测试 - 从 CUBRID 源编译的低级 C/C++ 单元测试。每当有人说“unittest tc 만들어줘”、“unit test 작성”、“새 유닛테스트”、“C unit test 추у”、“create unittest for CUBRID”或“draft unit test”时，即使他们没有说“testcase”，也可以使用此选项。不适用于：CCI 测试（使用 cubrid-cci-tc-create）、shell 测试（使用 cubrid-shell-tc-create）、JDBC 测试（使用 cubrid-jdbc-tc-create）、检查/运行现有测试或 CTP 配置。
