Créez, rédigez ou échafaudez un nouveau test unitaire CUBRID CTP — un test unitaire C/C++ de bas niveau compilé à partir de la source CUBRID. Utilisez-le chaque fois que quelqu'un dit "unittest tc 만들어줘", "unittest 작성", "새 유닛테스트", "C unit test 추가", "create unittest for CUBRID" ou "draft unit test", même s'il ne dit pas "testcase". PAS pour : les tests CCI (utilisez cubrid-cci-tc-create), les tests shell (utilisez cubrid-shell-tc-create), les tests JDBC (utilisez cubrid-jdbc-tc-create), la révision/l'exécution de tests existants ou la configuration CTP.
