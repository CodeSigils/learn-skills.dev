Créez, rédigez ou échafaudez un nouveau scénario de test d'isolation CUBRID CTP (.ctl) à partir de zéro - pour une correction de bogue ou une fonctionnalité CBRD. Utilisez-le chaque fois que quelqu'un dit "isolation tc 만들어줘", "isolation tc 초안 작성해줘", "create isolation tc", "draft isolation test", "새 isolation testcase", "isolation testcase 작성", ou "create draft isolation tc for CBRD-XXXXX", même s'il ne prononce pas le mot "testcase". Ils donnent généralement un numéro CBRD, le comportement de concurrence à tester et les niveaux d'isolement impliqués. PAS pour : exécuter/réviser les tests d'isolement existants, la configuration CTP ou les cas de test SQL/shell/JDBC/CCI.
