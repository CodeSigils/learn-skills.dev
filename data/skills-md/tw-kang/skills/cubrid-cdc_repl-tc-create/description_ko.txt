CBRD 버그 수정 또는 기능을 위해 처음부터 새로운 CUBRID CTP CDC 복제 테스트 케이스(.sql)를 생성, 초안 작성 또는 스캐폴드합니다. "testcase"라는 단어를 말하지 않더라도 누군가가 "cdc_repl tc 만들어줘", "cdc tc 초안 작성해줘", "create cdc repl tc", "draft cdc test", "새 cdc 테스트케이스", "createdraft cdc tc for CBRD-XXXXX"라고 말할 때마다 이 방법을 사용하세요. 일반적으로 CBRD 번호, 캡처할 동작, 때로는 대상 릴리스 디렉터리를 제공합니다. 해당되지 않음: 기존 CDC 테스트 실행/검토, CTP 구성, HA/로그 복제(cubrid-ha-* 기술 사용) 또는 SQL/shell/JDBC 테스트 케이스.
