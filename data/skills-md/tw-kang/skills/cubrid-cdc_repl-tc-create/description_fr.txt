Créez, rédigez ou échafaudez un nouveau scénario de test de réplication CUBRID CTP CDC (.sql) à partir de zéro – pour une correction de bogue ou une fonctionnalité CBRD. Utilisez-le chaque fois que quelqu'un dit "cdc_repl tc 만들어줘", "cdc tc 초안 작성해줘", "create cdc repl tc", "draft cdc test", "새 cdc 테스트케이스", ou "create draft cdc tc for CBRD-XXXXX", même s'il ne prononcez pas le mot « cas de test ». Ils donnent généralement un numéro CBRD, le comportement à capturer et parfois un répertoire de sortie cible. PAS pour : exécuter/réviser les tests CDC existants, la configuration CTP, la réplication HA/logs (utiliser les compétences cubrid-ha-*) ou les cas de test SQL/shell/JDBC.
