Führen Sie einen CUBRID CTP-Shell-Testfall auf diesem Computer aus, beurteilen Sie OK/NOK und diagnostizieren Sie bei einem Fehler die Grundursache. Wird immer dann verwendet, wenn jemand einen bestimmten Shell-Test physisch ausführen und wissen möchte, ob er erfolgreich ist und warum – Koreanisch: „돌려봐“, „수행해줘“, „실행해봐“, „패스하는지 확인“, „검증해줘“, „실패 원인 알려줘"; Englisch: „run“, „execute“, „verify“, „prüfen, ob es erfolgreich ist“. Eine CUBRID-Build-URL neben einem Testnamen oder .sh-Pfad ist ein starkes Signal – rufen Sie diesen Skill auf. NICHT für: Überprüfen/Bearbeiten von Testcode, Erstellen neuer Tests, Ausschlusslisten oder ganzer Regressionssuiten (ein Multi-Failure-Halbierungsbericht ist eine andere Aufgabe).
