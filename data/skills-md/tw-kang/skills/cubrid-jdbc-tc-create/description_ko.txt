CBRD 버그 수정(기본값) 또는 JDBC 사양/기능을 위해 새로운 CUBRID JDBC 테스트 케이스를 표준 JUnit 4 클래스로 생성, 초안 작성 또는 스캐폴드합니다. "testcase"라는 단어가 없어도 누군가가 "jdbc tc 만들어줘", "jdbc tc 초안 작성해줘", "jdbc 테스트케이스 작성", "create jdbc test", "draft jdbc testcase", "create jdbc tc for CBRD-XXXXX"라고 말할 때마다 사용하세요. 일반적으로 CBRD 번호, 테스트할 동작, 때로는 대상 범주를 제공합니다. 해당되지 않음: 기존 JDBC 테스트 실행/검토(cubrid-jdbc-tc-verify 사용) 또는 쉘/SQL/CCI/HA 테스트케이스(일치하는 cubrid-*-tc-* 스킬 사용).
