قم بإنشاء أو صياغة أو دعم حالة اختبار CUBRID JDBC جديدة كفئة JUnit 4 القياسية - لإصلاح أخطاء CBRD (افتراضي) أو مواصفات/ميزة JDBC. يُستخدم عندما يقول شخص ما "jdbc tc 만들어줘"، أو "jdbc tc 초안 작성해줘"، أو "jdbc 테스트케이스 작성"، أو "إنشاء اختبار jdbc"، أو "مسودة اختبار jdbc"، أو "إنشاء jdbc tc لـ" CBRD-XXXX"، حتى بدون كلمة "testcase". وعادةً ما يقدمون رقم اتفاقية التنوع البيولوجي، والسلوك المطلوب اختباره، وأحيانًا فئة مستهدفة. ليس من أجل: تشغيل/مراجعة اختبارات JDBC الحالية (استخدم cubrid-jdbc-tc-verify)، أو حالات اختبار Shell/SQL/CCI/HA (استخدم مهارة cubrid-*-tc-* المطابقة).
