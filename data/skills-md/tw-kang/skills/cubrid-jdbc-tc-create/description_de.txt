Erstellen, entwerfen oder erstellen Sie ein Gerüst für einen neuen CUBRID-JDBC-Testfall als Standard-JUnit-4-Klasse – für eine CBRD-Fehlerbehebung (Standard) oder eine JDBC-Spezifikation/-Funktion. Wird immer dann verwendet, wenn jemand „jdbc tc 만들어줘“, „jdbc tc 초안 작성해줘“, „jdbc 테스트케이스 작성“, „jdbc test erstellen“, „jdbc testcase entwerfen“ oder „jdbc tc erstellen“ sagt für CBRD-XXXXX“, auch ohne das Wort „Testcase“. Sie geben normalerweise eine CBRD-Nummer, das zu testende Verhalten und manchmal eine Zielkategorie an. NICHT für: das Ausführen/Überprüfen bestehender JDBC-Tests (verwenden Sie cubrid-jdbc-tc-verify) oder Shell/SQL/CCI/HA-Testfälle (verwenden Sie den passenden cubrid-*-tc-*-Skill).
