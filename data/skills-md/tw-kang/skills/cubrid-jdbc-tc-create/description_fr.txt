Créez, rédigez ou échafaudez un nouveau scénario de test CUBRID JDBC en tant que classe JUnit 4 standard — pour une correction de bogue CBRD (par défaut) ou une spécification/fonctionnalité JDBC. À utiliser chaque fois que quelqu'un dit "jdbc tc 만들어줘", "jdbc tc 초안 작성해줘", "jdbc 테스트케이스 작성", "create jdbc test", "draft jdbc testcase" ou "create jdbc tc for CBRD-XXXXX", même sans le mot "cas de test". Ils donnent généralement un numéro CBRD, le comportement à tester et parfois une catégorie cible. PAS pour : exécuter/réviser des tests JDBC existants (utilisez cubrid-jdbc-tc-verify) ou des cas de test shell/SQL/CCI/HA (utilisez la compétence cubrid-*-tc-* correspondante).
