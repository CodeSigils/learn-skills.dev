قم بإنشاء أو صياغة أو سقالة حالة اختبار shell CUBRID CTP (.sh) جديدة من البداية - لإصلاح أخطاء CBRD أو ميزة. استخدم هذا عندما يقول شخص ما "shell tc 만들어줘"، أو "shell tc 초안 작성해줘"، أو "إنشاء shell tc"، أو "مسودة اختبار الصدفة"، أو "새 shell testcase"، أو "إنشاء مسودة shell tc لـ CBRD-XXXXX"، حتى لو لم يذكر كلمة "testcase". عادةً ما يعطون رقم CBRD، والسلوك المطلوب اختباره، وأحيانًا دليل الإصدار المستهدف. ليس من أجل: مراجعة/تصحيح الاختبارات الموجودة، أو تشغيل الاختبارات، أو تكوين CTP، أو اختبارات HA/النسخ المتماثل (استخدم مهارات cubrid-ha-*)، أو حالات اختبار SQL/JDBC/CCI.
