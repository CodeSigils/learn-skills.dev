Crea, crea una bozza o costruisci da zero un nuovo test case CUBRID CTP shell (.sh) per una correzione di bug o una funzionalità CBRD. Usalo ogni volta che qualcuno dice "shell tc 만들어줘", "shell tc 초안 작성해줘", "create shell tc", "draft shell test", "새 shell testcase" o "create draft shell tc for CBRD-XXXXX", anche se non dice la parola "testcase". Di solito forniscono un numero CBRD, il comportamento da testare e talvolta una directory di rilascio target. NON per: revisione/debug di test esistenti, esecuzione di test, configurazione CTP, test HA/replica (utilizzare competenze cubrid-ha-*) o test case SQL/JDBC/CCI.
