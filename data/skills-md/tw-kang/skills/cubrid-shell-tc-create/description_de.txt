Erstellen, entwerfen oder erstellen Sie einen neuen CUBRID CTP-Shell-Testfall (.sh) von Grund auf – für eine CBRD-Fehlerbehebung oder -Funktion. Verwenden Sie dies immer dann, wenn jemand „Shell tc 만들어줘“, „Shell tc 초안 작성해줘“, „Shell tc erstellen“, „Shell-Testentwurf erstellen“, „Shell-Testfall erstellen“ oder „Shell-Tc-Entwurf für CBRD-XXXXX erstellen“ sagt, auch wenn er das Wort „Testfall“ nicht sagt. Sie geben normalerweise eine CBRD-Nummer, das zu testende Verhalten und manchmal ein Ziel-Release-Verzeichnis an. NICHT für: Überprüfen/Debuggen vorhandener Tests, Ausführen von Tests, CTP-Konfiguration, HA-/Replikationstests (cubrid-ha-*-Kenntnisse verwenden) oder SQL/JDBC/CCI-Testfälle.
