Cree, redacte o diseñe un nuevo caso de prueba de shell CUBRID CTP (.sh) desde cero, para corregir un error o una característica de CBRD. Utilice esto cada vez que alguien diga "shell tc 만들어줘", "shell tc 초안 작성해줘", "crear shell tc", "draft shell test", "새 shell testcase" o "crear borrador shell tc para CBRD-XXXXX", incluso si no dice la palabra "testcase". Por lo general, brindan un número CBRD, el comportamiento a probar y, a veces, un directorio de lanzamiento objetivo. NO para: revisar/depurar pruebas existentes, ejecutar pruebas, configuración de CTP, pruebas de HA/replicación (use habilidades cubrid-ha-*) o casos de prueba de SQL/JDBC/CCI.
