CBRD 버그 수정 또는 기능을 위해 처음부터 새로운 CUBRID CTP 쉘 테스트케이스(.sh)를 생성, 초안 작성 또는 스캐폴드합니다. "testcase"라는 단어를 말하지 않더라도 누군가가 "shell tc 만들어줘", "shell tc 초안 작성해줘", "create shell tc", "draft shell test", "새 shell testcase", "createdraft shell tc for CBRD-XXXXX"라고 말할 때마다 이 코드를 사용하세요. 일반적으로 CBRD 번호, 테스트할 동작, 때로는 대상 릴리스 디렉토리를 제공합니다. 해당되지 않음: 기존 테스트 검토/디버깅, 테스트 실행, CTP 구성, HA/복제 테스트(cubrid-ha-* 기술 사용) 또는 SQL/JDBC/CCI 테스트 케이스.
