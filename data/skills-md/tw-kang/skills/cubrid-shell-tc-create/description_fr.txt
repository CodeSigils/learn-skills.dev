Créez, rédigez ou échafaudez un nouveau scénario de test de shell CUBRID CTP (.sh) à partir de zéro – pour une correction de bogue ou une fonctionnalité CBRD. Utilisez-le chaque fois que quelqu'un dit "shell tc 만들어줘", "shell tc 초안 작성해줘", "create shell tc", "draft shell test", "새 shell testcase" ou "create draft shell tc for CBRD-XXXXX", même s'il ne prononce pas le mot "testcase". Ils donnent généralement un numéro CBRD, le comportement à tester et parfois un répertoire de version cible. PAS pour : réviser/déboguer les tests existants, exécuter des tests, la configuration CTP, les tests HA/réplication (utiliser les compétences cubrid-ha-*) ou les cas de test SQL/JDBC/CCI.
