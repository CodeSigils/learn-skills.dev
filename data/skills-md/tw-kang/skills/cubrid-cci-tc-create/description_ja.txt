CBRD バグ修正または C クライアント インターフェイス (libcascci) を実行する機能のために、新しい CUBRID CTP CCI テストケース (シェル + C ソース、オプションで応答ファイル) を最初から作成、ドラフト、またはスキャフォールディングします。誰かが「cci tc 만들어줘」、「cci 테스트케이스 작성」、「새 cci 테스트케이스」、「create cci testcase」、または「draft cci test for CBRD-XXXXX」と言ったときは、たとえその言葉を言わなくても、これを使用してください。 「テストケース」。通常、CBRD 番号、テスト対象の CCI 動作、および場合によってはターゲット カテゴリが示されます。対象外: cci_compatibility テスト (cubrid-cci-compatibility-tc-create を使用)、JDBC テスト (cubrid-jdbc-tc-create を使用)、プレーン シェル テスト (cubrid-shell-tc-create を使用)、または HA/レプリケーション テスト (cubrid-ha-* スキルを使用)。
