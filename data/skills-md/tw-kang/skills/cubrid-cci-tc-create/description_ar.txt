قم بإنشاء أو صياغة أو دعم حالة اختبار CUBRID CTP CCI جديدة (مصدر Shell + C، ملف إجابات اختياريًا) من البداية - لإصلاح أخطاء CBRD أو ميزة ممارسة واجهة عميل C (libcascci). استخدم هذا عندما يقول شخص ما "cci tc 만들어줘"، أو "cci 테스트케이스 작성"، أو "새 cci 테스트케이스"، أو "إنشاء حالة اختبار cci"، أو "مسودة اختبار cci لـ CBRD-XXXXX"، حتى لو لم ينطق كلمة "testcase". عادةً ما يقدمون رقم CBRD، وسلوك CCI الذي سيتم اختباره، وأحيانًا فئة مستهدفة. ليس من أجل: اختبارات توافق cci_compatibility (استخدم cubrid-cci-compatibility-tc-create)، أو اختبارات JDBC (استخدم cubrid-jdbc-tc-create)، أو اختبارات الصدفة البسيطة (استخدم cubrid-shell-tc-create)، أو اختبارات HA/النسخ المتماثل (استخدم مهارات cubrid-ha-*).
