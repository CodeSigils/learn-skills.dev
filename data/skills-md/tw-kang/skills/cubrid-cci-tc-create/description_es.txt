Cree, redacte o cree un nuevo caso de prueba CUBRID CTP CCI (shell + código fuente C, opcionalmente un archivo de respuesta) desde cero, para corregir un error CBRD o utilizar la función C Client Interface (libcascci). Utilice esto cada vez que alguien diga "cci tc 만들어줘", "cci 테스트케이스 작성", "새 cci 테스트케이스", "crear cci testcase" o "draft cci test for CBRD-XXXXX", incluso si no dice la palabra "testcase". Por lo general, proporcionan un número CBRD, el comportamiento del CCI a probar y, a veces, una categoría objetivo. NO para: pruebas cci_compatibility (use cubrid-cci-compatibility-tc-create), pruebas JDBC (use cubrid-jdbc-tc-create), pruebas de shell simple (use cubrid-shell-tc-create) o pruebas de HA/replicación (use habilidades cubrid-ha-*).
