Créez, rédigez ou échafaudez un nouveau scénario de test CUBRID CTP CCI (shell + source C, éventuellement un fichier de réponses) à partir de zéro - pour une correction de bogue CBRD ou une fonctionnalité exerçant l'interface client C (libcascci). Utilisez-le chaque fois que quelqu'un dit "cci tc 만들어줘", "cci 테스트케이스 작성", "새 cci 테스트케이스", "create cci testcase" ou "draft cci test for CBRD-XXXXX", même s'il ne prononce pas le mot "testcase". Ils donnent généralement un numéro CBRD, le comportement CCI à tester et parfois une catégorie cible. PAS pour : les tests de compatibilité cci (utilisez cubrid-cci-compatibility-tc-create), les tests JDBC (utilisez cubrid-jdbc-tc-create), les tests shell simples (utilisez cubrid-shell-tc-create) ou les tests HA/réplication (utilisez les compétences cubrid-ha-*).
