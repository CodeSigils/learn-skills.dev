Crea, crea una bozza o costruisci un nuovo test case CUBRID CTP CCI (shell + sorgente C, facoltativamente un file di risposte) da zero - per una correzione di bug CBRD o una funzionalità che esercita l'interfaccia client C (libcascci). Usalo ogni volta che qualcuno dice "cci tc 만들어줘", "cci 테스트케이스 작성", "새 cci 테스트케이스", "crea cci testcase" o "draft cci test for CBRD-XXXXX", anche se non dice la parola "testcase". Di solito forniscono un numero CBRD, il comportamento della CCI da testare e talvolta una categoria target. NON per: test cci_compatibility (usa cubrid-cci-compatibility-tc-create), test JDBC (usa cubrid-jdbc-tc-create), test plain shell (usa cubrid-shell-tc-create) o test HA/replica (usa competenze cubrid-ha-*).
