Создайте, набросайте или создайте новый тестовый пример CUBRID CTP CCI (оболочка + исходный код C, опционально файл ответов) с нуля — для исправления ошибок CBRD или функции, реализующей клиентский интерфейс C (libcascci). Используйте это каждый раз, когда кто-то говорит «cci tc 만들어줘», «cci 테스트케이스 작성», «새 cci 테스트이스», «создать тестовый пример cci» или «проектировать тест cci для CBRD-XXXXX», даже если он не произносит слово «тестовый пример». Обычно они указывают номер CBRD, поведение CCI для проверки, а иногда и целевую категорию. НЕ для: тестов cci_compatibility (используйте cubrid-cci-compatibility-tc-create), тестов JDBC (используйте cubrid-jdbc-tc-create), простых тестов оболочки (используйте cubrid-shell-tc-create) или тестов HA/репликации (используйте навыки cubrid-ha-*).
