從頭開始建立、起草或建立新的 CUBRID CTP CCI 測試案例（shell + C 原始碼，選用答案檔）－用於 CBRD 錯誤修復或行使 C 用戶端介面 (libcascci) 的功能。每當有人說「cci tc 만들어줘」、「cci 테스트케 Been스 작성」、「새 cci 테스트케스」、「create c testcase test ccift CBRD-XXXXX」時，即使他們沒有說出這些字詞，也可以使用此選項「測試案例」。他們通常會給予 CBRD 編號、要測試的 CCI 行為，有時還會給予目標類別。不適用於：cci_compatibility 測試（使用 cubrid-cci-compatibility-tc-create）、JDBC 測試（使用 cubrid-jdbc-tc-create）、普通 shell 測試（使用 cubrid-shell-tc-create）或 HA/複製測試（使用 cubrid-ha-* 技能）。
