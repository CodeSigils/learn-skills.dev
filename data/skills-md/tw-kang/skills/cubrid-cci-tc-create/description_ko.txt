CBRD 버그 수정 또는 C 클라이언트 인터페이스(libcascci) 실행 기능을 위해 새로운 CUBRID CTP CCI 테스트케이스(셸 + C 소스, 선택적으로 응답 파일)를 처음부터 생성, 초안 작성 또는 스캐폴드합니다. 누군가가 "testcase"라는 단어를 말하지 않더라도 "cci tc 만들어줘", "cci 테스트케이스 작성", "새 cci 테스트케이스", "create cci testcase" 또는 "draft cci test for CBRD-XXXXX"라고 말할 때마다 이 코드를 사용하세요. 일반적으로 CBRD 번호, 테스트할 CCI 동작, 때로는 대상 범주를 제공합니다. 해당되지 않음: cci_compatibility 테스트(cubrid-cci-compatibility-tc-create 사용), JDBC 테스트(cubrid-jdbc-tc-create 사용), 일반 셸 테스트(cubrid-shell-tc-create 사용) 또는 HA/복제 테스트(cubrid-ha-* 스킬 사용).
