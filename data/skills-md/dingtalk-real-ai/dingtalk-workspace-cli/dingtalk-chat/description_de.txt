Dingtalk-Gruppenchat und Nachrichten. Verwenden Sie diese Option, wenn der Benutzer das Senden von Nachrichten / privaten Chat / Gruppenchat / das Erstellen einer Gruppe / das Hinzufügen von Personen zu einer Gruppe / das Ändern des Gruppennamens / das Durchsuchen von Gruppen / die Verwaltung von Gruppenmitgliedern / @Erwähnungen / das Zurückziehen von Nachrichten / Bot-Massennachrichten / Webhook-Benachrichtigungen / das Senden von Bildern oder Dateien an die Gruppe erwähnt. Unterscheidet sich von dingtalk-ding (dringende DING-Nachrichten/SMS/Telefon), dingtalk-mail (E-Mail), dingtalk-edu-group (Klassengruppe). Befehlspräfix: dws chat.

Bitte antworten Sie immer in der Sprache des Benutzers.
