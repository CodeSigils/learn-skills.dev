Chat grupal y mensajes de DingTalk. Úselo cuando el usuario menciona enviar mensajes / chat individual / chat grupal / crear un grupo / agregar personas a un grupo / cambiar el nombre de un grupo / buscar grupos / administración de miembros del grupo / mensajes @ / recuperar mensajes / mensajería masiva de bots / notificaciones de Webhook / enviar imágenes o archivos a un grupo. Distinto de dingtalk-ding (mensajes DING / SMS / llamadas urgentes), dingtalk-mail (correo electrónico), dingtalk-edu-group (grupos de clase). Prefijo de comando: dws chat.
