DingTalk Docs (documents cloud). À utiliser lorsque l'utilisateur dit écrire un document / lire un document / créer un document / modifier un document / rechercher un document / bloquer un document / bloquer une modification / écrire un Markdown / télécharger un fichier vers un document. Distinct de dingtalk-drive (stockage de fichiers DingPan), dingtalk-aitable (tables de données), dingtalk-wiki (espace de base de connaissances). Préfixe de commande : dws doc.
