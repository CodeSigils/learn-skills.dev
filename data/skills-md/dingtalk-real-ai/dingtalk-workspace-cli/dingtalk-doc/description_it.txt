DingTalk Docs (documenti cloud). Da utilizzare quando l'utente dice scrivi documento/leggi documento/crea documento/modifica documento/cerca documento/blocca documento/modifica blocco/scrivi Markdown/carica file nel documento. Distinto da dingtalk-drive (archiviazione di file DingTalk), dingtalk-aitable (tabelle di dati), dingtalk-wiki (spazio della knowledge base). Prefisso comando: dws doc.
