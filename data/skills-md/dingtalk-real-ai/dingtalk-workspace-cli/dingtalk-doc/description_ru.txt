DingTalk Docs (облачные документы). Используйте, когда пользователь говорит: написать документ/прочитать документ/создать документ/редактировать документ/поиск документа/блок документа/редактирование блока/ввод Markdown/загрузить файл в документ. В отличие от dingtalk-drive (хранилище файлов DingTalk), dingtalk-aitable (таблицы данных), dingtalk-wiki (пространство базы знаний). Префикс команды: dws doc.
