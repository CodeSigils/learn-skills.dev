Calendario DingTalk y salas de reuniones. Úselo cuando el usuario diga programar una reunión / consultar agenda / reservar una sala de reuniones / verificar disponibilidad / agregar participantes / reprogramar / cancelar una reunión / agenda de hoy / agenda semanal / tiempo libre común. Distinto de dingtalk-conference (inicio de videoconferencia/reserva/invitación para unirse/control durante la reunión), dingtalk- Minutes (actas de la reunión), dingtalk-todo (tareas pendientes). Prefijo de comando: calendario dws.
