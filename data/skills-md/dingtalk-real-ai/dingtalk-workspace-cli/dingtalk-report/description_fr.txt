Journaux DingTalk (rapport quotidien/rapport hebdomadaire/rapport mensuel). À utiliser lorsque l'utilisateur dit écrire un rapport quotidien / rédiger un rapport hebdomadaire / rédiger un rapport mensuel / soumettre un journal / vérifier le journal / le journal de la boîte de réception / le journal envoyé / lire les statistiques / résumer le rapport par sujet. Distinct de dingtalk-doc (document ordinaire), dingtalk-todo (à faire), dingtalk-minutes (procès-verbal de réunion). Préfixe de commande : rapport dws (alias journal dws).
