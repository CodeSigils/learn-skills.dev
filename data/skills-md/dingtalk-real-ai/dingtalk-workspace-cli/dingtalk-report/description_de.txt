DingTalk-Protokolle (Tagesbericht / Wochenbericht / Monatsbericht). Verwenden Sie diese Option, wenn der Benutzer sagt: „Tagesbericht schreiben“, „Wochenbericht schreiben“, „Monatsbericht schreiben“, „Protokoll senden“, „Protokoll prüfen“, „Posteingangsprotokoll“, „Gesendetes Protokoll“, „Statistiken lesen“, „Bericht nach Thema zusammenfassen“. Unterscheidet sich von dingtalk-doc (normales Dokument), dingtalk-todo (to-do), dingtalk-minutes (Besprechungsprotokoll). Befehlspräfix: dws report (alias dws log).
