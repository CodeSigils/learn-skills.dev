Журналы DingTalk (ежедневный отчет/еженедельный отчет/ежемесячный отчет). Используйте, когда пользователь говорит: написать ежедневный отчет / написать еженедельный отчет / написать ежемесячный отчет / отправить журнал / проверить журнал / журнал входящих / журнал отправленных / прочитать статистику / сводный отчет по темам. В отличие от dingtalk-doc (обычные документы), dingtalk-todo (задачи), dingtalk-минуты (протоколы встреч). Префикс команды: отчет dws (псевдоним журнала dws).
