Strukturierte Codeüberprüfung anhand von Anforderungen, Qualitäts- und Sicherheitsstandards. Nach bedeutenden Codeänderungen oder vor der Zusammenführung aufrufen. Wird ausgelöst bei: „Meinen Code überprüfen“, „Codeüberprüfung“, „Überprüfen Sie dies vor dem Zusammenführen“, „Sicherheitsüberprüfung“, „Ist das sicher“, „Sehen Sie sich meine Änderungen an“, „Zweites Augenpaar“, „Überprüfen Sie den Unterschied“. Umgeleitet durch die Nutzung von Superkräften oder die Ausführung von Plänen nach der Implementierung.
