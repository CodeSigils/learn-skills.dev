Attivare per l'esecuzione giornaliera della valutazione del repository o quando l'utente richiede di valutare gli errori dell'elemento della configurazione, i problemi aperti o i commit recenti. Legge i segnali di ieri, deduplica contro il file di stato, bozza le correzioni in alberi di lavoro isolati con un passaggio di revisione, apre PR sul verde e tiene le persone fuori dal limbo con commenti nella voce del manutentore. Il file di stato è la spina dorsale: ricorda cosa è stato provato, cosa è passato e cosa è ancora aperto, quindi ogni esecuzione riprende da dove si era interrotta l'ultima.
