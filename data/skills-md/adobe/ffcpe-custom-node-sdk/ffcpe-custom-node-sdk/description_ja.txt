Adobe App Builder 開発者が @adobe/ffcpe-custom-node-core および @adobe/ffcpe-custom-node-app-builder を使用して FFCPE (Firefly Creative Production for Enterprise) カスタム アクションを構築できるようにします (OpenWhisk Web + ワーカー アクション、Hono、送信/ステータス HTTP コントラクト、入力/出力、IMS 対応ルート)。ユーザーが App Builder でカスタム アクション アプリを接続する場合、FfcpeNodeWorkerHandler を実装する場合、mountFfcpeNodeRoutes を使用してルートをマウントする場合、Web: raw OpenWhisk アクションを構成する場合、submit/statusUrl ポーリングをデバッグする場合、Text/Image/Video/Json 入力を処理する場合、または実行ワークフローのアクション出力を生成する場合に使用します。 category-entry.json および aio ffcpe カタログ CLI の場合は、adobe/aio-cli-plugin-ffcpe のコンパニオン スキルを使用します。
