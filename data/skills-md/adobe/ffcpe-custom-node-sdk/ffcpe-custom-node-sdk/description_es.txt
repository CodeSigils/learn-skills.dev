Ayuda a los desarrolladores de Adobe App Builder a crear acciones personalizadas FFCPE (Firefly Creative Production for Enterprise) utilizando @adobe/ffcpe-custom-node-core y @adobe/ffcpe-custom-node-app-builder (OpenWhisk web + acciones de trabajador, Hono, contrato HTTP de envío/estado, entradas/salidas, rutas compatibles con IMS). Úselo cuando el usuario está cableando una aplicación de acción personalizada en App Builder, implementando FfcpeNodeWorkerHandler, montando rutas con mountFfcpeNodeRoutes, configurando web: acciones sin procesar de OpenWhisk, depurando el sondeo de envío/statusUrl, manejando entradas de texto/imagen/vídeo/Json o produciendo salidas de acción para ejecutar flujo de trabajo. Para catalog-entry.json y aio ffcpe catalog CLI, utilice habilidades complementarias de adobe/aio-cli-plugin-ffcpe.
