Помогает разработчикам Adobe App Builder создавать настраиваемые действия FFCPE (Firefly Creative Production for Enterprise) с использованием @adobe/ffcpe-custom-node-core и @adobe/ffcpe-custom-node-app-builder (веб-действия OpenWhisk + рабочие действия, Hono, HTTP-контракт отправки/статуса, входы/выходы, маршруты с поддержкой IMS). Используйте, когда пользователь подключает приложение с настраиваемыми действиями в App Builder, реализует FfcpeNodeWorkerHandler, монтирует маршруты с помощью mountFfcpeNodeRoutes, настраивает веб-интерфейс: необработанные действия OpenWhisk, отлаживает опрос submit/statusUrl, обрабатывает входные данные Text/Image/Video/Json или создает выходные данные действий для рабочего процесса запуска. Для каталога-entry.json и CLI каталога aio ffcpe используйте сопутствующие навыки из adobe/aio-cli-plugin-ffcpe.
