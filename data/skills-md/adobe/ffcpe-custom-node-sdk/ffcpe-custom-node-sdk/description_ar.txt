يساعد مطوري Adobe App Builder على إنشاء إجراءات مخصصة لـ FFCPE (Firefly Creative Production for Enterprise) باستخدام @adobe/ffcpe-custom-node-core و@adobe/ffcpe-custom-node-app-builder (OpenWhisk web + إجراءات العامل، Hono، إرسال/حالة عقد HTTP، المدخلات/المخرجات، المسارات المدركة لـ IMS). يُستخدم عندما يقوم المستخدم بتوصيل تطبيق إجراء مخصص في App Builder، أو تنفيذ FfcpeNodeWorkerHandler، أو توصيل المسارات باستخدام mountFfcpeNodeRoutes، أو تكوين الويب: إجراءات OpenWhisk الأولية، أو تصحيح أخطاء استقصاء الإرسال/الحالة، أو التعامل مع مدخلات النص/الصورة/الفيديو/Json، أو إنتاج مخرجات الإجراء لتشغيل سير العمل. بالنسبة إلى catalog-entry.json وaio ffcpe catalogue CLI، استخدم المهارات المصاحبة من adobe/aio-cli-plugin-ffcpe.
