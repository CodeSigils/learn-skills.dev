Hilft Adobe App Builder-Entwicklern beim Erstellen benutzerdefinierter FFCPE-Aktionen (Firefly Creative Production for Enterprise) mit @adobe/ffcpe-custom-node-core und @adobe/ffcpe-custom-node-app-builder (OpenWhisk Web + Worker-Aktionen, Hono, Submit-/Status-HTTP-Vertrag, Ein-/Ausgaben, IMS-fähige Routen). Wird verwendet, wenn der Benutzer eine App mit benutzerdefinierten Aktionen in App Builder verbindet, FfcpeNodeWorkerHandler implementiert, Routen mit mountFfcpeNodeRoutes bereitstellt, Web-OpenWhisk-Rohaktionen konfiguriert, Submit-/StatusUrl-Abfragen debuggt, Text-/Bild-/Video-/Json-Eingaben verarbeitet oder Aktionsausgaben für den Run-Workflow erstellt. Verwenden Sie für die Datei „catalog-entry.json“ und „aio ffcpe Catalogue CLI“ Begleitfähigkeiten von „adobe/aio-cli-plugin-ffcpe“.
