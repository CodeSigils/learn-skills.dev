Aiuta gli sviluppatori di Adobe App Builder a creare azioni personalizzate FFCPE (Firefly Creative Production for Enterprise) utilizzando @adobe/ffcpe-custom-node-core e @adobe/ffcpe-custom-node-app-builder (azioni OpenWhisk web + lavoratore, Hono, contratto HTTP di invio/stato, input/output, percorsi compatibili con IMS). Da utilizzare quando l'utente collega un'app con azioni personalizzate in App Builder, implementa FfcpeNodeWorkerHandler, monta percorsi con mountFfcpeNodeRoutes, configura web: azioni OpenWhisk non elaborate, esegue il debug del polling di invio/statusUrl, gestisce input di testo/immagine/video/JSON o produce output di azioni per il flusso di lavoro di esecuzione. Per catalog-entry.json e aio ffcpe catalog CLI, utilizza le competenze complementari di adobe/aio-cli-plugin-ffcpe.
