Aide les développeurs d'Adobe App Builder à créer des actions personnalisées FFCPE (Firefly Creative Production for Enterprise) à l'aide de @adobe/ffcpe-custom-node-core et @adobe/ffcpe-custom-node-app-builder (OpenWhisk web + actions de travail, Hono, soumission/statut du contrat HTTP, entrées/sorties, routes compatibles IMS). À utiliser lorsque l'utilisateur câble une application d'action personnalisée dans App Builder, implémente FfcpeNodeWorkerHandler, monte des routes avec mountFfcpeNodeRoutes, configure le Web : actions OpenWhisk brutes, débogage de l'interrogation submit/statusUrl, gestion des entrées texte/image/vidéo/Json ou production de sorties d'action pour le workflow d'exécution. Pour catalog-entry.json et la CLI du catalogue aio ffcpe, utilisez les compétences associées d'adobe/aio-cli-plugin-ffcpe.
