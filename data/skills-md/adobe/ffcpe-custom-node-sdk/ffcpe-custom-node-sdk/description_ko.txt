Adobe App Builder 개발자가 @adobe/ffcpe-custom-node-core 및 @adobe/ffcpe-custom-node-app-builder(OpenWhisk 웹 + 작업자 작업, Hono, 제출/상태 HTTP 계약, 입력/출력, IMS 인식 경로)를 사용하여 FFCPE(Firefly Creative Production for Enterprise) 사용자 정의 작업을 구축할 수 있도록 지원합니다. 사용자가 App Builder에서 사용자 정의 작업 앱 연결, FfcpeNodeWorkerHandler 구현, mountFfcpeNodeRoutes로 경로 마운트, 웹 구성: 원시 OpenWhisk 작업, 제출/상태 Url 폴링 디버깅, 텍스트/이미지/비디오/Json 입력 처리 또는 작업 흐름 실행을 위한 작업 출력 생성 시 사용합니다.
