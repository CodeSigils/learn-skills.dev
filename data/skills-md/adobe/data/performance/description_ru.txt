Используйте при оптимизации горячего пути в @adobe/data, особенно когда интерфейс (Column, TypedBuffer, ManagedArray и т. д.) имеет множество конкретных экземпляров, созданных из фабрик, возвращающих замыкание, и отправляется из жесткого цикла для каждой строки. Предоставляет шаблон рефакторинга замыкание → класс, обоснование скрытого класса V8, критерии принятия/отклонения и дисциплину, которая сохраняет открытый API свободным от закрытия, даже если реализации основаны на классах.
