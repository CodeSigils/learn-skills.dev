Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer browserbasierte End-to-End-Tests für eine Adobe App Builder-Anwendung wünscht. Behandelt Playwright E2E-Tests für ExC Shell SPAs, AEM-Erweiterungs-UIs und Full-Stack-Flows. Verwenden Sie, wenn der Benutzer Folgendes erwähnt: „E2E-Test“, „End-to-End-Test“, „Playwright“, „Browsertest“, „Testen Sie meine SPA im Browser“, „Testen Sie meine AEM-Erweiterung“, „Testen Sie den vollständigen Ablauf“, „Integrationstest mit Benutzeroberfläche“, „Headless-Browser-Test“, „E2E in CI“. Dieser Skill ist nur für BROWSER-basierte Tests vorgesehen. Verwenden Sie für Jest-Komponententests von Aktionen oder React-Komponenten stattdessen appbuilder-testing.
