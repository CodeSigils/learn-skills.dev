Utilisez cette compétence chaque fois que l'utilisateur souhaite effectuer des tests de bout en bout basés sur un navigateur pour une application Adobe App Builder. Couvre les tests Playwright E2E pour les SPA ExC Shell, les interfaces utilisateur d’extension AEM et les flux full-stack. À utiliser lorsque l'utilisateur mentionne : "Test E2E", "test de bout en bout", "Playwright", "test du navigateur", "tester mon SPA dans le navigateur", "tester mon extension AEM", "tester le flux complet", "test d'intégration avec l'interface utilisateur", "test du navigateur sans tête", "E2E dans CI". Cette compétence est uniquement destinée aux tests basés sur le NAVIGATEUR. Pour les tests unitaires Jest des actions ou des composants React, utilisez plutôt appbuilder-testing.
