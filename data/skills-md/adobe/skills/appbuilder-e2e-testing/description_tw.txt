當使用者需要對 Adob​​e App Builder 應用程式進行基於瀏覽器的端對端測試時，請使用此技能。涵蓋 ExC Shell SPA、AEM 擴充 UI 和全堆疊流程的 Playwright E2E 測試。當使用者提及以下內容時使用：「E2E 測試」、「端對端測試」、「Playwright」、「瀏覽器測試」、「在瀏覽器中測試我的 SPA」、「測試我的 AEM 擴充功能」、「測試完整流程」、「與 UI 的整合測試」、「無頭瀏覽器測試」、「CI 中的 E2E」。此技能僅適用於基於瀏覽器的測試。對於操作或 React 元件的 Jest 單元測試，請改用 appbuilder-testing。
