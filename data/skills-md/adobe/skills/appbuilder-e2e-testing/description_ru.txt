Используйте этот навык всякий раз, когда пользователю требуется сквозное тестирование приложения Adobe App Builder на основе браузера. Охватывает тестирование Playwright E2E для ExC Shell SPA, пользовательских интерфейсов расширений AEM и полнофункциональных потоков. Используйте, когда пользователь упоминает: «тест E2E», «сквозной тест», «Драматург», «тест браузера», «проверьте мой SPA в браузере», «проверьте мое расширение AEM», «проверьте полный поток», «тест интеграции с пользовательским интерфейсом», «тест безголового браузера», «E2E в CI». Этот навык предназначен только для тестирования в БРАУЗЕРЕ. Для модульных тестов действий или компонентов React в Jest используйте вместо этого appbuilder-testing.
