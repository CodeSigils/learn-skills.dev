Создавайте компоненты пользовательского интерфейса React Spectrum для SPA-интерфейсов Adobe Experience Cloud Shell и расширений пользовательского интерфейса AEM. Предоставляет шаблоны для страниц, форм, таблиц данных, диалоговых окон и навигации с использованием @adobe/react-spectrum. Руководства по интеграции ExC Shell с @adobe/exc-app, включая runtime.done(), передачу токена IMS и оформление тем оболочки. Руководства по разработке расширения пользовательского интерфейса AEM с помощью @adobe/uix-guest для консоли фрагмента контента, редактора CF, универсального редактора и поверхностей просмотра ресурсов. Запуск по: созданию пользовательского интерфейса App Builder, компонентам React Spectrum, страницам оболочки ExC, формам, таблицам данных, диалоговым окнам, модальным окнам, навигации, темам, веб-источникам, системе дизайна Spectrum, @adobe/exc-app, расширению AEM, расширению пользовательского интерфейса AEM, консоли фрагмента контента, расширению универсального редактора, uix-guest, @adobe/uix-guest, точкам расширения для AEM, настройке поверхностей AEM.
