Genera componenti dell'interfaccia utente di React Spectrum per Adobe Experience Cloud Shell SPA e estensioni dell'interfaccia utente di AEM. Fornisce modelli per pagine, moduli, tabelle dati, finestre di dialogo e navigazione utilizzando @adobe/react-spectrum. Guida l'integrazione di ExC Shell con @adobe/exc-app, inclusi runtime.done(), passthrough token IMS e temi della shell. Guida lo sviluppo dell'estensione dell'interfaccia utente AEM con @adobe/uix-guest per la console dei frammenti di contenuto, l'editor CF, l'editor universale e le superfici di visualizzazione delle risorse. Attivazione su: creazione dell'interfaccia utente di App Builder, componenti React Spectrum, pagine ExC Shell, moduli, tabelle dati, finestre di dialogo, modali, navigazione, temi, web-src, sistema di progettazione Spectrum, @adobe/exc-app, estensione AEM, estensione UI AEM, console dei frammenti di contenuto, estensione Universal Editor, uix-guest, @adobe/uix-guest, punti di estensione per AEM, personalizzazione delle superfici AEM.
