Générez des composants d’interface utilisateur React Spectrum pour les SPA Adobe Experience Cloud Shell et les extensions d’interface utilisateur AEM. Fournit des modèles pour les pages, les formulaires, les tables de données, les boîtes de dialogue et la navigation à l'aide de @adobe/react-spectrum. Guide l’intégration d’ExC Shell avec @adobe/exc-app, y compris runtime.done(), le relais de jeton IMS et la thématique du shell. Guide le développement de l’extension d’interface utilisateur AEM avec @adobe/uix-guest pour les surfaces Content Fragment Console, CF Editor, Universal Editor et Assets View. Déclenchez sur : la création de l'interface utilisateur d'App Builder, les composants React Spectrum, les pages ExC Shell, les formulaires, les tables de données, les boîtes de dialogue, les modaux, la navigation, les thèmes, le web-src, le système de conception Spectrum, @adobe/exc-app, l'extension AEM, l'extension de l'interface utilisateur AEM, la console Content Fragment, l'extension Universal Editor, uix-guest, @adobe/uix-guest, les points d'extension pour AEM, la personnalisation des surfaces AEM.
