قم بإنشاء مكونات React Spectrum UI لـ Adobe Experience Cloud Shell SPAs وAEM UI Extensions. يوفر أنماطًا للصفحات والنماذج وجداول البيانات ومربعات الحوار والتنقل باستخدام @adobe/react-spectrum. يرشد تكامل ExC Shell مع @adobe/exc-app بما في ذلك runtime.done() وعبور رمز IMS المميز وميزات Shell. يرشد تطوير AEM UI Extension باستخدام @adobe/uix-guest لوحدة تحكم جزء المحتوى، ومحرر CF، والمحرر العالمي، وأسطح عرض الأصول. تشغيل: إنشاء واجهة مستخدم App Builder، ومكونات React Spectrum، وصفحات ExC Shell، والنماذج، وجداول البيانات، ومربعات الحوار، والنماذج، والتنقل، والسمات، وweb-src، ونظام تصميم Spectrum، @adobe/exc-app، وملحق AEM، وملحق AEM UI، وContent Fragment Console، وملحق Universal Editor، وuix-guest، @adobe/uix-guest، ونقاط التمديد لـ AEM، وتخصيص أسطح AEM.
