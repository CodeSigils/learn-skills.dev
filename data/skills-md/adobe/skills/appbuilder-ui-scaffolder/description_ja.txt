Adobe Experience Cloud Shell SPA および AEM UI Extensions 用の React Spectrum UI コンポーネントを生成します。 @adobe/react-spectrum を使用して、ページ、フォーム、データテーブル、ダイアログ、ナビゲーションのパターンを提供します。 runtime.done()、IMS トークン パススルー、シェル テーマなど、ExC Shell と @adobe/exc-app の統合をガイドします。 @adobe/uix-guest を使用した Content Fragment Console、CF Editor、Universal Editor、Assets View サーフェス用の AEM UI Extension 開発をガイドします。トリガー：App Builder UI、React Spectrum コンポーネント、ExC Shell ページ、フォーム、データテーブル、ダイアログ、モーダル、ナビゲーション、テーマ、web-src、Spectrum デザインシステム、@adobe/exc-app、AEM 拡張機能、AEM UI 拡張機能、Content Fragment Console、Universal Editor 拡張機能、uix-guest、@adobe/uix-guest、AEM の拡張ポイント、AEM サーフェスのカスタマイズ。
