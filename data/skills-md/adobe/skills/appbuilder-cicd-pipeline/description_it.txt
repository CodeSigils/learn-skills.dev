Configura pipeline CI/CD per i progetti Adobe App Builder. Genera flussi di lavoro GitHub Actions utilizzando adobe/aio-cli-setup-action@3 e adobe/aio-apps-action@3.3.0, oltre a modelli per Azure DevOps e GitLab CI. Gestisce l'inserimento di segreti OAuth S2S, la promozione di più aree di lavoro (stage → prod), la distribuzione del gating con convalida del manifest. Utilizza questa competenza ogni volta che l'utente menziona CI/CD per App Builder, GitHub Actions per aio deploy, pipeline di distribuzione automatizzata, integrazione continua, distribuzione continua, automazione della distribuzione, promozione multi-ambiente, aio app add ci o desidera automatizzare il processo di creazione e rilascio di App Builder. Si attiva anche quando gli utenti menzionano flussi di lavoro di distribuzione, pipeline di rilascio o segreti GitHub per App Builder.
