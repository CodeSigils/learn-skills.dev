قم بإعداد مسارات CI/CD لمشروعات Adobe App Builder. يُنشئ سير عمل إجراءات GitHub باستخدام adobe/aio-cli-setup-action@3 وadobe/aio-apps-action@3.3.0، بالإضافة إلى أنماط Azure DevOps وGitLab CI. يتعامل مع حقن أسرار OAuth S2S، وتعزيز مساحات العمل المتعددة (المرحلة → المنتج)، ونشر البوابة مع التحقق من صحة البيان. استخدم هذه المهارة عندما يذكر المستخدم CI/CD لـ App Builder، أو GitHub Actions for aio Publish، أو مسارات النشر الآلي، أو التكامل المستمر، أو التسليم المستمر، أو النشر الآلي، أو الترويج للبيئات المتعددة، أو إضافة تطبيق aio ci، أو يريد أتمتة عملية إنشاء وإصدار App Builder الخاص به. يتم تشغيله أيضًا عندما يذكر المستخدمون نشر مسارات العمل أو مسارات الإصدار أو أسرار GitHub لـ App Builder.
