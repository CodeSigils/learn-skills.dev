Configure canales de CI/CD para proyectos de Adobe App Builder. Genera flujos de trabajo de GitHub Actions usando adobe/aio-cli-setup-action@3 y adobe/aio-apps-action@3.3.0, además de patrones para Azure DevOps y GitLab CI. Maneja la inyección de secretos de OAuth S2S, la promoción de múltiples espacios de trabajo (etapa → producción), implementa la activación con validación de manifiesto. Utilice esta habilidad siempre que el usuario mencione CI/CD para App Builder, GitHub Actions para implementación aio, canalizaciones de implementación automatizadas, integración continua, entrega continua, automatización de implementación, promoción multientorno, aplicación aio add ci, o quiera automatizar su proceso de creación y lanzamiento de App Builder. También se activa cuando los usuarios mencionan implementar flujos de trabajo, canales de lanzamiento o secretos de GitHub para App Builder.
