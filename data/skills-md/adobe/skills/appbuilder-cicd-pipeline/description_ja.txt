Adobe App Builder プロジェクトの CI/CD パイプラインを設定します。 adobe/aio-cli-setup-action@3 および adobe/aio-apps-action@3.3.0 に加え、Azure DevOps および GitLab CI のパターンを使用して GitHub Actions ワークフローを生成します。 OAuth S2S シークレットのインジェクション、マルチワークスペースのプロモーション (ステージ→本番)、マニフェスト検証を使用したゲーティングのデプロイを処理します。ユーザーが App Builder の CI/CD、AIO デプロイ用の GitHub Actions、自動デプロイメント パイプライン、継続的インテグレーション、継続的デリバリー、デプロイの自動化、マルチ環境のプロモーション、AIO アプリの追加 CI について言及する場合、または App Builder のビルドおよびリリース プロセスを自動化したい場合には、このスキルを使用します。ユーザーがワークフローのデプロイ、パイプラインのリリース、または App Builder の GitHub シークレットに言及したときにもトリガーされます。
