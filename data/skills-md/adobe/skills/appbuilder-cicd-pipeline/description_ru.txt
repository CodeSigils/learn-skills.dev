Настройте конвейеры CI/CD для проектов Adobe App Builder. Создает рабочие процессы GitHub Actions с использованием adobe/aio-cli-setup-action@3 и adobe/aio-apps-action@3.3.0, а также шаблонов для Azure DevOps и GitLab CI. Управляет внедрением секретов OAuth S2S, продвижением в нескольких рабочих пространствах (этап → продукт), развертыванием шлюзования с проверкой манифеста. Используйте этот навык всякий раз, когда пользователь упоминает CI/CD для App Builder, действия GitHub для развертывания aio, автоматизированные конвейеры развертывания, непрерывную интеграцию, непрерывную доставку, автоматизацию развертывания, продвижение в нескольких средах, добавление приложения aio ci или хочет автоматизировать процесс сборки и выпуска App Builder. Также срабатывает, когда пользователи упоминают рабочие процессы развертывания, конвейеры выпуска или секреты GitHub для App Builder.
