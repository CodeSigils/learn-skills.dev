Configurez des pipelines CI/CD pour les projets Adobe App Builder. Génère des workflows GitHub Actions à l'aide d'adobe/aio-cli-setup-action@3 et adobe/aio-apps-action@3.3.0, ainsi que des modèles pour Azure DevOps et GitLab CI. Utilisez cette compétence chaque fois que l'utilisateur mentionne CI/CD pour App Builder, GitHub Actions pour le déploiement aio, les pipelines de déploiement automatisés, l'intégration continue, la livraison continue, l'automatisation du déploiement, la promotion multi-environnements, l'application aio add ci, ou souhaite automatiser son processus de création et de publication d'App Builder. Déclenchez également lorsque les utilisateurs mentionnent des workflows de déploiement, des pipelines de publication ou des secrets GitHub pour App Builder.
