À utiliser lorsque vous travaillez avec le plug-in Adobe I/O CLI @adobe/aio-cli-plugin-ffcpe (FFCPE — Firefly Creative Production for Enterprise). Couvre l'installation, l'authentification, les remplacements d'environnement et toutes les commandes « aio ffcpe catalog ». À utiliser pour les flux de travail du terminal, les modifications du catalogue de scripts ou pour expliquer comment les développeurs doivent appeler ce plugin. Certains utilisateurs disent encore **Workflow Builder** ; ce nom faisait référence au même domaine de produit — le sujet CLI est **`ffcpe`** (`aio ffcpe`).
