Verwendung bei der Arbeit mit dem Adobe I/O CLI-Plugin @adobe/aio-cli-plugin-ffcpe (FFCPE – Firefly Creative Production for Enterprise). Behandelt Installation, Authentifizierung, Umgebungsüberschreibungen und alle „aio ffcpe-Katalog“-Befehle. Verwenden Sie es für Terminal-Workflows, zum Erstellen von Skripten für Katalogänderungen oder zum Erklären, wie Entwickler dieses Plugin aufrufen sollten. Einige Benutzer sagen immer noch **Workflow Builder**; dieser Name bezog sich auf denselben Produktbereich – das CLI-Thema ist **`ffcpe`** (`aio ffcpe`).
