استخدمه عند العمل مع البرنامج الإضافي Adobe I/O CLI @adobe/aio-cli-plugin-ffcpe (FFCPE — Firefly Creative Production for Enterprise). يغطي التثبيت والمصادقة وتجاوزات env وجميع أوامر `aio ffcpe catalog`. يُستخدم لسير العمل الطرفي، أو تغييرات كتالوج البرمجة النصية، أو شرح كيفية استدعاء المطورين لهذا البرنامج الإضافي. لا يزال بعض المستخدمين يقولون **Workflow Builder**; يشير هذا الاسم إلى نفس منطقة المنتج - موضوع واجهة سطر الأوامر هو **`ffcpe`** (`aio ffcpe`).
