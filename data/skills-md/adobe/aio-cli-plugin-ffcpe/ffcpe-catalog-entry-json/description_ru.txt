Используйте при разработке или проверке файла каталога-entry.json настраиваемого действия FFCPE (Firefly Creative Production for Enterprise) для службы запуска рабочего процесса (действия App Builder). Охватывает установку Adobe I/O CLI и этого плагина, форму схемы, org/auth, обнаружение агента, customActionConfig, проверку, использование рабочего процесса и устранение неполадок. Используйте **`aio ffcpe Catalog`** для проверки/регистрации — никогда не используйте необработанный завиток. В старых поисковых запросах может быть указано **Workflow Builder**; тот же плагин и тема **`ffcpe`**.
