Wird zum Erstellen oder Validieren einer FFCPE (Firefly Creative Production for Enterprise) benutzerdefinierten Aktion „catalog-entry.json“ für den Run-Workflow-Dienst (App Builder-Aktionen) verwendet. Behandelt die Installation der Adobe I/O CLI und dieses Plugins, Schema-Shape, org/auth, Agent-Erkennung, customActionConfig, Validierung, Workflow-Nutzung und Fehlerbehebung. Verwenden Sie zum Validieren/Registrieren den **`aio ffcpe-Katalog`** – niemals Raw Curl. Bei älteren Suchanfragen steht möglicherweise **Workflow Builder**; gleiches Plugin und Thema **`ffcpe`**.
