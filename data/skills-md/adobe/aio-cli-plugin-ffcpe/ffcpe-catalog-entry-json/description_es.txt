Utilícelo al crear o validar un archivo-entry.json de acción personalizada FFCPE (Firefly Creative Production for Enterprise) para el servicio de flujo de trabajo de ejecución (acciones de App Builder). Cubre la instalación de Adobe I/O CLI y este complemento, forma de esquema, organización/autenticación, descubrimiento de agentes, customActionConfig, validación, uso del flujo de trabajo y solución de problemas. Utilice **`aio ffcpe catalog`** para validar/registrar, nunca rizos sin formato. Las búsquedas más antiguas pueden decir **Workflow Builder**; mismo complemento y tema **`ffcpe`**.
