التحليل المعماري العميق، والتنظيف القوي، والنموذجية، وإنفاذ الاختبار - اجترار قاعدة التعليمات البرمجية لتحديد التعليمات البرمجية الميتة، والتكرار، والمنطق المكرر، والإفراط في التجريد، وفجوات الاختبار، والملفات التي تتجاوز 300 سطر والتي تحتاج إلى التقسيم. التخلص من الهدر بشكل منهجي، وفرض البنية المعيارية، والتأكد من أن جميع الوظائف لديها اختبارات تكامل مقابلة. يُستخدم عندما يطلب المستخدم تحسين قاعدة التعليمات البرمجية، أو تقليص حجمها، أو تنظيفها، أو تدقيقها، أو إلغاء تكرارها، أو تشديدها، أو توحيدها. استخدمه أيضًا عندما يُطلب منك العثور على التعليمات البرمجية الميتة، أو تقليل عدد الأسطر، أو التخلص من التكرار، أو تقسيم الملفات الكبيرة، أو فرض البنية، أو جعل التعليمات البرمجية أصغر حجمًا، أو تغطية اختبار التدقيق. يتم تشغيل عبارات مثل "تدقيق قاعدة التعليمات البرمجية"، أو "التنظيف"، أو "العثور على التعليمات البرمجية الميتة"، أو "إلغاء التكرار"، أو "جعلها أصغر حجمًا"، أو "تقليص الدهون"، أو "تحسين التعليمات البرمجية"، أو "الترتيب"، أو "إزالة التكرارات"، أو "إعادة البناء من أجل قابلية الصيانة"، أو "النموذجية"، أو "تقسيم الملفات الكبيرة"، أو "مراجعة البنية"، أو "الملفات كبيرة جدًا"، أو "تقسيم هذا". اقترح بشكل استباقي استخدام هذه المهارة قبل إنشاء العلاقات العامة.
