Analyse architecturale approfondie, nettoyage agressif, modularisation et application des tests : réfléchissez à la base de code pour identifier le code mort, les redondances, la logique dupliquée, les abstractions excessives, les lacunes dans les tests et les fichiers dépassant 300 lignes qui doivent être fractionnés. Éliminez systématiquement le gaspillage, appliquez une architecture modulaire et assurez-vous que toutes les fonctionnalités disposent de tests d'intégration correspondants. À utiliser chaque fois que l'utilisateur demande à optimiser, alléger, nettoyer, auditer, dédupliquer, resserrer ou modulariser une base de code. Utilisez également lorsqu'on vous le demande pour rechercher du code mort, réduire le nombre de lignes, éliminer les redondances, diviser des fichiers volumineux, appliquer l'architecture, alléger le code ou auditer la couverture des tests. Déclencheurs sur des expressions telles que « auditer la base de code », « nettoyer », « trouver le code mort », « dédupliquer », « le rendre plus léger », « réduire le gras », « optimiser le code », « ranger », « supprimer les redondances », « refactoriser pour la maintenabilité », « modulariser », « diviser les gros fichiers », « révision de l'architecture », « les fichiers sont trop gros » ou « brisez ça ». Suggérez de manière proactive d'utiliser cette compétence avant de créer un PR.
