Exécutez un workflow PR : validez les modifications, transférez-les vers une branche, créez un PR GitHub, attendez que les vérifications CI réussissent (pas de contournement), fusionnez le PR et nettoyez tous les statuts git, branches et fichiers de travail. À utiliser lorsqu'un utilisateur demande à s'engager, à faire des relations publiques et à nettoyer.
