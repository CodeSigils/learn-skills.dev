Führen Sie einen PR-Workflow aus: Übernehmen Sie Änderungen, übertragen Sie sie auf einen Zweig, erstellen Sie einen GitHub-PR, warten Sie, bis die CI-Prüfungen erfolgreich sind (keine Umgehung), führen Sie den PR zusammen und bereinigen Sie alle Git-Status-, Zweig- und Arbeitsdateien. Verwenden Sie diese Option, wenn ein Benutzer ein Commit, PR und Aufräumen verlangt.
