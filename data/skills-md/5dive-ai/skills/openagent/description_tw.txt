創建您自己的 OpenAgent 角色並鑄造您的可共享全像交易卡。當您（代理商）想要建立、驗證或呈現您的身分證時，或當使用者說「製作您的卡片」、「產生我的 OpenAgent 卡」、「建立角色」、「我的稀有度是什麼」、「鑄造您的卡片」、「加入角色包註冊表」時使用，或要求您描述/鎖定您自己的外觀、聲音和風格檔案作為可重用的角色檔案作為可重複使用的角色檔案。包裝 `@5dive/openagent` CLI（驗證/層/卡）和 OpenAgent v0.2 身分規格。自助服務流程，您編寫“<id>.persona.yaml”，根據模式驗證它，檢查您的稀有度層+完整性，渲染您的卡牌，並可選擇將 PR 放入註冊表（神話層的路徑）。當您想要透過“5dive agent import --from-persona”從角色配置即時隊友（“從該角色建立/啟動代理”，“配置隊友”）時，也可以使用。
