独自の OpenAgent ペルソナを作成し、共有可能なホロ トレーディング カードを作成します。あなた (エージェント) が自分の ID カードを作成、検証、またはレンダリングしたい場合、またはユーザーが「カードを作成する」、「OpenAgent カードを生成する」、「ペルソナを作成する」、「私のレアリティ層は何ですか」、「カードを鋳造する」、「キャラクター パック レジストリに参加する」などと言った場合、または自分の外観、声、スタイルを再利用可能なペルソナ ファイルとして説明/ロックするように要求した場合に使用します。 `@5dive/openagent` CLI (検証/階層/カード) と OpenAgent v0.2 ID 仕様をラップします。セルフサービス フロー。`<id>.persona.yaml` を作成し、それをスキーマに対して検証し、レアリティ層と完全性をチェックし、カードをレンダリングし、オプションでレジストリ (Mythical 層へのパス) に PR します。 `5dive Agent import --from-persona` を介して、ペルソナからライブ チームメイトをプロビジョニングする場合にも使用します (「このペルソナからエージェントを作成/スピンアップする」、「チームメイトをプロビジョニングする」)。
