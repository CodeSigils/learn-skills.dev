Utilice la CLI local `5dive` en una máquina virtual en tiempo de ejecución de 5dive para generar, inspeccionar, enviar y eliminar agentes hermanos. Se activa cuando el usuario desea un trabajador, un subagente, una tarea secundaria, una ejecución paralela, una distribución en abanico o para delegar, o nombra un agente hermano ("preguntar a X", "hacer ping a X", "decir a X", "entregar a X", "coordinar con X"); confirme que existe a través de `5dive agent list --json`, luego `agent send`. También para inspeccionar/reiniciar/emparejar un agente existente, una verificación de estado legible por máquina (`5dive doctor --json`), la cola de tareas compartida del host + organigrama (`5dive task`, `5dive org`), trabajo recurrente/programado (`task add --recurring`, `5dive heartbeat`), estacionar una pregunta en un humano (`task need`), o flotas declarativas (`5dive up`, `5importación de equipo de buceo`). Cuando llega una solicitud a través de un canal de chat (etiqueta `<channel>` de Telegram/Discord) y otro agente debe manejarla, pasa el contexto del chat a través de `--reply-to-chat=<id> --reply-to-msg=<id>` para que el agente responda desde su propio bot; no lo transmita. Prefiera siempre `5dive` a ejecutar CLI de codificación a mano.
