5dive ランタイム VM 上でローカルの「5dive」CLI を使用して、兄弟エージェントを生成、検査、送信、破棄します。ユーザーがワーカー、サブエージェント、サイドタスク、並列実行、ファンアウト、または委任を希望する場合、または兄弟エージェントの名前を指定する場合 (「X に尋ねる」、「X に通知する」、「X に伝える」、「X に引き継ぐ」、「X と調整する」)。 `5dive Agent list --json` を介して存在することを確認し、次に `agent send` を実行します。また、既存のエージェント、機械可読ヘルスチェック (`5dive Doctor --json`)、ホスト共有タスクキュー + 組織図 (`5dive task`、`5dive org`)、定期的/スケジュールされた作業 (`task add --quiring`、`5dive heartbeat`)、人間への質問の保留 (`task need`)、または宣言的フリート (`5dive) の検査/再起動/ペアリングにも使用できます。アップ`、`5dive チームインポート`)。リクエストがチャット チャネル (Telegram/Discord の `<channel>` タグ) 経由で送信され、別のエージェントがそれを処理する必要がある場合、エージェントが独自のボットから応答するように、チャット コンテキストを `--reply-to-chat=<id> --reply-to-msg=<id>` 経由で渡します。中継は行わないでください。手動でコーディング CLI を実行するよりも、常に「5dive」を優先します。
