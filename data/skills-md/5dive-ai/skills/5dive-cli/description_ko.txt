5dive 런타임 VM에서 로컬 `5dive` CLI를 사용하여 형제 에이전트를 생성, 검사, 전송 및 해제합니다. 사용자가 작업자, 하위 에이전트, 부가 작업, 병렬 실행, 팬아웃 또는 위임을 원할 때 트리거하거나 형제 에이전트의 이름을 지정할 때 트리거합니다("X에게 물어보기", "X ping", "X에 알리기", "X에 전달", "X와 조정"). `5dive Agent list --json`을 통해 존재하는지 확인한 다음 `agent send`를 통해 존재하는지 확인하세요. 또한 기존 에이전트 검사/재시작/페어링을 위해 기계 판독 가능 상태 확인(`5dive doctor --json`), 호스트 공유 작업 대기열 + 조직 차트(`5dive task`, `5dive org`), 반복/예약된 작업(`task add --recurring`, `5dive heartbeat`), 사람에게 질문 주차(`task need`) 또는 선언적 플릿(`5dive up`, `5dive 팀 가져오기`). 요청이 채팅 채널(Telegram/Discord `<channel>` 태그)을 통해 왔고 다른 에이전트가 이를 처리해야 하는 경우 에이전트가 자체 봇에서 응답할 수 있도록 `--reply-to-chat=<id> --reply-to-msg=<id>`를 통해 채팅 컨텍스트를 전달합니다. 릴레이하지 마세요. 코딩 CLI를 직접 실행하는 것보다 항상 '5dive'를 선호하세요.
