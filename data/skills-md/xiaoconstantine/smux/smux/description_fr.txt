Contrôlez les volets tmux et communiquez entre les agents IA. Utilisez cette compétence chaque fois que l'utilisateur mentionne les volets tmux, la communication entre volets, l'envoi de messages à d'autres agents, la lecture d'autres volets, la gestion de sessions tmux ou l'interaction avec des processus exécutés dans tmux. Inclut la CLI tmux-bridge pour la messagerie agent à agent et les commandes tmux brutes pour le contrôle direct de session.
