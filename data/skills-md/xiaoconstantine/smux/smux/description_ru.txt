Управляйте панелями tmux и общайтесь между агентами ИИ. Используйте этот навык всякий раз, когда пользователь упоминает панели tmux, межпанельную связь, отправку сообщений другим агентам, чтение других панелей, управление сеансами tmux или взаимодействие с процессами, выполняющимися в tmux. Включает CLI tmux-bridge для обмена сообщениями между агентами и необработанные команды tmux для прямого управления сеансом.
