Erstellen oder lesen Sie Statsig-Dashboards über die Konsolen-API. Wird verwendet, wenn Sie einen gültigen „POST /console/v1/dashboards“-Körper erstellen, „GET /console/v1/dashboards/{id}“ in eine erstellungskompatible Form lesen oder Dashboard-Widgets über die zugehörigen Widget-Endpunkte anhängen oder ersetzen.
