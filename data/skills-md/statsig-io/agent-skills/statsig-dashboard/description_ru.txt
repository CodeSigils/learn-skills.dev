Создавайте или читайте информационные панели Statsig через API консоли. Используйте при создании допустимого тела POST /console/v1/dashboards, чтении GET /console/v1/dashboards/{id} в форму, совместимую с созданием, а также при добавлении или замене виджетов информационной панели через связанные конечные точки виджетов.
