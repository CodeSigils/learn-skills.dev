Инструмент для мозгового штурма историй, который быстро составляет резюме из одного предложения (Шаг 1) → план из пяти предложений (Шаг 2) на этапе разработки концепции. Он автоматически активируется, когда пользователь говорит «история мозгового штурма», «проверить идею», «концепция истории», «помогите мне придумать историю» или «конспект». Идеально подходит для быстрой проверки идеи без полного выполнения процесса Snowflake. Его можно использовать независимо или вызывать в рамках основного рабочего процесса создания снежинок.
