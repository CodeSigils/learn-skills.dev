استخدم هذه المهارة عندما يريد المستخدم مراجعة أفضل ممارسات إرسال البريد الإلكتروني أو تدقيقها أو تحسينها أو التخطيط لها. يتضمن ذلك إمكانية التسليم، أو وضع البريد الوارد، أو سمعة المرسل، أو الموافقة، أو نظافة القائمة، أو سطور الموضوع، أو معاينة النص، أو مراكز التفضيلات، أو رسائل البريد الإلكتروني، أو رسائل البريد الإلكتروني الخاصة بدورة الحياة، أو تحديثات المنتج، أو الاختيار بين البريد الإلكتروني التسويقي والبريد الإلكتروني للمعاملات. إنه يعمل مع أي حزمة بريد إلكتروني، ولكن عندما يتعلق الأمر بـ Loops، استخدم سلوك Loops ومستنداته كمصدر للحقيقة. قم بتشغيل عبارات مثل "إمكانية تسليم البريد الإلكتروني"، أو "وضع البريد الوارد"، أو "سمعة المرسل"، أو "الاشتراك المزدوج"، أو "إلغاء الاشتراك"، أو "مراجعة سطر الموضوع"، أو "معاينة النص"، أو "رسائل البريد الإلكتروني الخاصة بدورة الحياة"، أو "رسائل البريد الإلكتروني المدمجة"، أو "البريد الإلكتروني لتحديث المنتج"، أو "المعاملات مقابل التسويق"، أو "أفضل ممارسات إرسال البريد الإلكتروني". لا تفضل هذه المهارة لتطبيق واجهة برمجة التطبيقات (API) فقط؛ استخدم مهارة Loops API للحصول على تفاصيل التكامل.
