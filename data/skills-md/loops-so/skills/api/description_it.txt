Utilizza questa competenza ogni volta che l'utente desidera integrare loop dal codice dell'applicazione, dai servizi backend, dai gestori webhook o dall'automazione lato server. Ciò include l'API HTTP Loops e gli SDK ufficiali per contatti lato server, proprietà dei contatti, mailing list, eventi, convalida della chiave API e flussi di lavoro di posta elettronica transazionale. Attiva frasi come "API Loops", "SDK Loops", "invia un evento Loops dalla mia app", "aggiungi un contatto a Loops in un webhook", "invia un'e-mail transazionale dal codice backend" o ogni volta che l'utente desidera integrare Loops nella propria app, backend, webhook o automazione. Non eseguire l'attivazione per CLI o richieste solo shell.
