Utilice esta habilidad siempre que el usuario quiera integrar Loops desde el código de la aplicación, servicios backend, controladores de webhooks o automatización del lado del servidor. Esto incluye la API HTTP de Loops y los SDK oficiales para flujos de trabajo de contacto del lado del servidor, propiedad de contacto, lista de correo, evento, validación de clave API y correo electrónico transaccional. Active frases como "API de Loops", "SDK de Loops", "enviar un evento de Loops desde mi aplicación", "agregar un contacto a Loops en un webhook", "enviar un correo electrónico transaccional desde el código de backend" o en cualquier momento en que el usuario quiera integrar Loops en su aplicación, backend, webhook o automatización. No lo active para CLI o solicitudes de solo shell.
