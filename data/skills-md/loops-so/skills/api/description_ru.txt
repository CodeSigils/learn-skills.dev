Используйте этот навык всякий раз, когда пользователь хочет интегрировать циклы из кода приложения, серверных служб, обработчиков веб-перехватчиков или автоматизации на стороне сервера. Сюда входят API Loops HTTP и официальные SDK для контактов на стороне сервера, свойств контактов, списков рассылки, событий, проверки ключей API и рабочих процессов транзакционной электронной почты. Запускайте такие фразы, как «Loops API», «Loops SDK», «отправить событие Loops из моего приложения», «добавить контакт в Loops в веб-перехватчике», «отправить транзакционное электронное письмо из внутреннего кода» или в любое время, когда пользователь хочет интегрировать Loops в свое приложение, серверную часть, веб-перехватчик или систему автоматизации. Не запускайте запросы CLI или только оболочки.
