Используйте этот навык всякий раз, когда пользователь хочет работать с интерфейсом командной строки Loops с терминала. Сюда входит установка или обновление интерфейса командной строки, аутентификация, хранение и выбор ключей API, проверка учетных данных и запуск команд для контактов, свойств контактов, списков, событий и транзакционной электронной почты. Запускайте такие фразы, как «Loops CLI», «loops auth login», «loops Контакты создают», «Loops Update», «Loops Events send», «Loops Transactional Send», «Loops api-key», «brew install Loops-so/tap/loops» или в любое время, когда пользователь хочет использовать Loops из оболочки вместо кода приложения.
