استخدم هذه المهارة عندما يريد المستخدم العمل مع Loops CLI من الجهاز. يتضمن ذلك تثبيت أو تحديث واجهة سطر الأوامر (CLI)، والمصادقة على مفاتيح API وتخزينها واختيارها، والتحقق من صحة بيانات الاعتماد، وتشغيل الأوامر لجهات الاتصال، وخصائص جهة الاتصال، والقوائم، والأحداث، والبريد الإلكتروني للمعاملات. قم بتشغيل عبارات مثل "Loops CLI"، أو "تسجيل الدخول إلى مصادقة الحلقات"، أو "إنشاء جهات اتصال الحلقات"، أو "تحديث جهات اتصال الحلقات"، أو "إرسال أحداث الحلقات"، أو "إرسال معاملات الحلقات"، أو "مفتاح واجهة برمجة التطبيقات"، أو "حلقات تثبيت الشراب-so/tap/loops"، أو في أي وقت يريد المستخدم استخدام حلقات من الغلاف بدلاً من رمز التطبيق.
