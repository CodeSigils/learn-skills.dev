ユーザーが端末から Loops CLI を操作する場合は常に、このスキルを使用します。これには、CLI のインストールまたは更新、API キーの認証、保存と選択、認証情報の検証、連絡先、連絡先プロパティ、リスト、イベント、トランザクション電子メールに対するコマンドの実行が含まれます。 「Loops CLI」、「loops auth login」、「loops contacts create」、「loops contacts update」、「loops events send」、「loopstransactional send」、「loops api-key」、「brew install Loops-so/tap/loops」などのフレーズ、またはユーザーがアプリケーション コードではなくシェルから Loops を使用したいときにトリガーします。
