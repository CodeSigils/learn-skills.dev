Utilizza questa abilità ogni volta che l'utente desidera lavorare con la CLI Loops dal terminale. Ciò include l'installazione o l'aggiornamento della CLI, l'autenticazione, l'archiviazione e la selezione delle chiavi API, la convalida delle credenziali e l'esecuzione di comandi per contatti, proprietà dei contatti, elenchi, eventi ed e-mail transazionali. Attivazione di frasi come "Loops CLI", "loops auth login", "loops contatti creati", "loops contatti aggiornamento", "loops eventi invia", "loops invio transazionale", "loops api-key", "brew install loops-so/tap/loops" o ogni volta che l'utente desidera utilizzare i loop dalla shell anziché il codice dell'applicazione.
