Utilisez cette compétence chaque fois que l'utilisateur souhaite intégrer des boucles à partir du code d'application, des services backend, des gestionnaires de webhooks ou de l'automatisation côté serveur. Cela inclut l'API HTTP Loops et les SDK officiels pour les flux de travail de contact côté serveur, de propriété de contact, de liste de diffusion, d'événement, de validation de clé API et de courrier électronique transactionnel. Déclenchez des expressions telles que « API Loops », « SDK Loops », « envoyer un événement Loops depuis mon application », « ajouter un contact à Loops dans un webhook », « envoyer un e-mail transactionnel à partir du code backend » ou à chaque fois que l'utilisateur souhaite intégrer Loops dans son application, backend, webhook ou automatisation. Ne déclenchez pas pour les requêtes CLI ou shell uniquement.
