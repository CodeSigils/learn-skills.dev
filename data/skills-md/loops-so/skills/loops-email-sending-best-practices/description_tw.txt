當使用者想要查看、審核、改進或規劃電子郵件發送最佳實務時，請使用此技能。這包括送達率、收件匣放置、寄件者信譽、同意、清單衛生、主題行、預覽文字、偏好中心、入職電子郵件、生命週期電子郵件、產品更新或在行銷和交易電子郵件之間做出決定。它適用於任何電子郵件堆棧，但當涉及循環時，請使用循環行為和文件作為事實來源。觸發「電子郵件送達率」、「收件匣放置」、「寄件者信譽」、「雙重選擇加入」、「取消訂閱」、「主旨行審核」、「預覽文字」、「生命週期電子郵件」、「入門電子郵件」、「產品更新電子郵件」、「交易與行銷」或「電子郵件發送最佳實踐」等短語。對於純 API 實現，不喜歡使用此技能；使用 Loops API 技能來了解整合細節。
