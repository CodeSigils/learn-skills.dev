ユーザーが電子メール送信のベスト プラクティスを確認、監査、改善、または計画したい場合は、このスキルを使用します。これには、配信可能性、受信箱の配置、送信者の評判、同意、リストの健全性、件名、プレビュー テキスト、プリファレンス センター、オンボーディング電子メール、ライフサイクル電子メール、製品更新、またはマーケティング電子メールとトランザクション電子メールのどちらの決定が含まれます。これはどのメール スタックでも機能しますが、Loops が関係する場合は、Loops の動作とドキュメントを信頼できる情報源として使用してください。 「電子メールの到達性」、「受信箱の配置」、「送信者の評判」、「ダブル オプトイン」、「購読解除」、「件名行のレビュー」、「テキストのプレビュー」、「ライフサイクル メール」、「オンボーディング メール」、「製品更新メール」、「トランザクションとマーケティング」、または「電子メール送信のベスト プラクティス」などのフレーズをトリガーします。純粋な API 実装にはこのスキルを好まないでください。統合の詳細については、Loops API スキルを使用してください。
