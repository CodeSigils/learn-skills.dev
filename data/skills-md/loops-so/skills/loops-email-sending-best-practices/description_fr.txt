Utilisez cette compétence lorsque l'utilisateur souhaite examiner, auditer, améliorer ou planifier les meilleures pratiques d'envoi d'e-mails. Cela inclut la délivrabilité, le placement dans la boîte de réception, la réputation de l'expéditeur, le consentement, l'hygiène de la liste, les lignes d'objet, le texte d'aperçu, les centres de préférences, les e-mails d'intégration, les e-mails de cycle de vie, les mises à jour de produits ou le choix entre les e-mails marketing et transactionnels. Cela fonctionne pour n'importe quelle pile de courrier électronique, mais lorsque Loops est impliqué, utilisez le comportement et la documentation de Loops comme source de vérité. Déclenchez des expressions telles que « délivrabilité des e-mails », « placement dans la boîte de réception », « réputation de l'expéditeur », « double opt-in », « désabonnement », « examen de la ligne d'objet », « texte d'aperçu », « e-mails de cycle de vie », « e-mails d'intégration », « e-mail de mise à jour du produit », « transactionnel ou marketing » ou « meilleures pratiques d'envoi d'e-mails ». Ne préférez pas cette compétence pour une implémentation pure d’API ; utilisez la compétence API Loops pour les détails de l'intégration.
