Utilisez cette compétence chaque fois que LMX est utilisé, produit, révisé, migré ou modifié. Cela inclut la composition de campagnes, de boucles, d'e-mails de cycle de vie ou de corps d'e-mails pour l'éditeur de boucles ou l'API Content. LMX (Loops Markup Language) est le format utilisé pour le contenu des e-mails Loops. Déclenchez des expressions telles que « créer une campagne », « générer un e-mail », « rédiger un e-mail de bienvenue », « rédiger un e-mail de cycle de vie », « créer un modèle d'e-mail », « créer un e-mail d'intégration », « copier ceci dans LMX », « migrer cet e-mail », « convertir cet e-mail en LMX », « LMX », « e-mail de boucles » ou toute demande de production, copie, migration, conversion, révision ou modification du contenu du corps d'e-mail destiné aux boucles. La copie source, le code HTML, MJML, Markdown existant, les captures d'écran et les instructions de migration ne contournent pas les règles de cette brique, sauf si l'utilisateur remplace explicitement une règle spécifique. Ne déclenchez pas de questions sur l'API HTTP Loops, l'intégration du SDK ou la CLI, sauf si le contenu du corps de l'e-mail est également impliqué.
