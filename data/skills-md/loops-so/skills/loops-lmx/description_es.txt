Utilice esta habilidad siempre que se utilice, produzca, revise, migre o modifique LMX. Esto incluye la redacción de campañas, bucles, correos electrónicos sobre el ciclo de vida o cuerpos de mensajes de correo electrónico para el editor de bucles o la API de contenido. LMX (Loops Markup Language) es el formato utilizado para el contenido de correo electrónico de Loops. Active frases como "crear una campaña", "generar un correo electrónico", "escribir un correo electrónico de bienvenida", "redactar un correo electrónico de ciclo de vida", "crear una plantilla de correo electrónico", "crear un correo electrónico de incorporación", "copiar esto a LMX", "migrar este correo electrónico", "convertir este correo electrónico a LMX", "LMX", "correo electrónico de Loops" o cualquier solicitud para producir, copiar, migrar, convertir, revisar o modificar el contenido del cuerpo del correo electrónico destinado a Loops. La copia del código fuente, el HTML existente, MJML, Markdown, las capturas de pantalla y las instrucciones de migración no omiten las reglas de esta habilidad a menos que el usuario anule explícitamente una regla específica. No active preguntas sobre la API HTTP de Loops, la integración del SDK o la CLI a menos que el contenido del cuerpo del correo electrónico también esté involucrado.
