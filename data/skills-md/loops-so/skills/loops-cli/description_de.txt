Verwenden Sie diesen Skill immer dann, wenn der Benutzer vom Terminal aus mit der Loops-CLI arbeiten möchte. Dazu gehören die Installation oder Aktualisierung der CLI, die Authentifizierung, Speicherung und Auswahl von API-Schlüsseln, die Validierung von Anmeldeinformationen und die Ausführung von Befehlen für Kontakte, Kontakteigenschaften, Listen, Ereignisse und Transaktions-E-Mails. Wird bei Ausdrücken wie „Loops CLI“, „Loops Auth Login“, „Loops Contacts Create“, „Loops Contacts Update“, „Loops Events Send“, „Loops Transactional Send“, „Loops API-Key“, „Brew Install Loops-So/Tap/Loops“ oder jederzeit dann ausgelöst, wenn der Benutzer Loops aus der Shell anstelle von Anwendungscode verwenden möchte.
