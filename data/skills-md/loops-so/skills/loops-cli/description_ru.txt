Используйте этот навык всякий раз, когда пользователь хочет работать с интерфейсом командной строки Loops с терминала. Сюда входит установка или обновление интерфейса командной строки, аутентификация, хранение и выбор ключей API, проверка учетных данных и запуск команд для контактов, свойств контактов, списков, событий и транзакционной электронной почты. Запуск по таким фразам, как «Loops CLI», «loops auth login», «loops contacts create», «loops update», «loops send», «loopsтранзакционная отправка», «loops api-key», «brew installloops-so/tap/loops» или в любой момент, когда пользователь хочет использовать Loops из оболочки вместо кода приложения.
