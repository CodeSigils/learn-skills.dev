Transfiera un modelo de Blender (a través de BlenderMCP) a Unity (a través de MCP para Unity): exporte el modelo actual de Blender, impórtelo a través de import_model_file y colóquelo en la escena abierta. Úselo cuando el usuario tiene BlenderMCP y MCP para Unity conectados y desea incorporar un modelo de Blender a Unity. NO impulsa los propios generadores de Blender; BlenderMCP es dueño de cómo llegó el modelo a Blender.
