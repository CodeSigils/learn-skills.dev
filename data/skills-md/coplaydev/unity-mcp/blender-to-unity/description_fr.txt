Transférez un modèle de Blender (via BlenderMCP) vers Unity (via MCP pour Unity) - exportez le modèle Blender actuel, importez-le via import_model_file et placez-le dans la scène ouverte. À utiliser lorsque l'utilisateur a tous deux connectés BlenderMCP et MCP pour Unity et souhaite importer un modèle Blender dans Unity. Ne pilote PAS les propres générateurs de Blender ; BlenderMCP est propriétaire de la manière dont le modèle est entré dans Blender.
