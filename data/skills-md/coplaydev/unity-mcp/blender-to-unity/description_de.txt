Übergeben Sie ein Modell von Blender (über BlenderMCP) an Unity (über MCP für Unity) – exportieren Sie das aktuelle Blender-Modell, importieren Sie es über import_model_file und platzieren Sie es in der offenen Szene. Verwenden Sie diese Option, wenn der Benutzer sowohl BlenderMCP als auch MCP für Unity verbunden hat und ein Blender-Modell in Unity integrieren möchte. Treibt NICHT die eigenen Generatoren von Blender an; BlenderMCP ist dafür verantwortlich, wie das Modell in Blender gelangt ist.
