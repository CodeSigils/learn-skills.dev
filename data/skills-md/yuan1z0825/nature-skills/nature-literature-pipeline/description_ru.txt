Полный автоматизированный процесс поиска литературы: поиск по нескольким источникам → шестимерная оценка → хорошее чтение → форматированная доставка → архивирование.
Сочетает в себе настраиваемый механизм с ежедневным уровнем приложений, управляемым cron. Работает с Feishu, Telegram или любой платформой обмена сообщениями.
