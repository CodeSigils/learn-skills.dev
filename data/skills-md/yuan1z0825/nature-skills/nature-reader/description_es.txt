Cree archivos de lectura Markdown bilingües de texto completo, con reconocimiento de figuras y basados ​​en fuentes para artículos de revistas o conferencias desde PDF, DOI, arXiv, HTML del editor o texto pegado. Úselo siempre que el usuario solicite traducir un artículo completo, crear un lector de rebajas completo, preservar la ubicación de figuras o tablas cerca de la prosa relevante o mantener anclajes de fuente exactos para cada bloque. No utilice esto para resúmenes, notas de palabras clave con viñetas o tareas de solo citas.
