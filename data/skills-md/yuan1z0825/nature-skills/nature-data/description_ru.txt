Подготовьте, проверите или пересмотрите заявления о доступности данных Nature-ready, планы хранилищ данных, ссылки на наборы данных и контрольные списки метаданных FAIR для рукописей. Используйте, когда пользователь спрашивает о доступности данных Nature, совместном использовании исследовательских данных, выборе репозитория, инвентарных номерах, ограниченных или конфиденциальных данных, исходных данных, дополнительных наборах данных, ссылках на наборы данных в стиле DataCite, метаданных FAIR для академических публикаций или формулировке доступности данных с китайского на английский для китайскоязычных авторов, готовящих материалы для семейства Nature.
