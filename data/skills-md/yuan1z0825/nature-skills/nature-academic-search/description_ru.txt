Поиск литературы по нескольким источникам, проверка цитирования, стратегия поиска MeSH, управление файлами цитирования (преобразование .nbib/.ris/.bib) и управление ссылками (BibTeX, связанные статьи, преобразование идентификаторов) с помощью инструментов MCP (PubMed, CrossRef, arXiv). Используйте, когда пользователю необходимы скоординированные многоэтапные рабочие процессы с литературой, выходящие за рамки одного вызова MCP.
