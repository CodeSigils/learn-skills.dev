ユーザー独自の有料 TikHub API を使用して、公開ソーシャル メディア クリエイター、アカウント、投稿、ビデオ、コメント、トランスクリプト、トピック、パフォーマンス データを調査し、追跡可能な JSON、Markdown、CSV、または Excel アセットをエクスポートします。ユーザーが生姜调研、全平台调研、博主调研、对标账号、抓作品、抓评论、逐字、TikHub、抖音、小红书、ビデオ号、TikTok、YouTube、B站、微博、Instagram、X、Reddit、知乎、または社媒公开データ台监控。有料のバッチ収集の前に、常に API 料金を公開し、リクエスト数とコストのプレビューを表示します。
