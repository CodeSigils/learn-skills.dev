MNE-Python لخطوط أنابيب تحليل MEG/EEG/iEEG/fNIRS، بدءًا من تحميل الإشارات الأولية إلى العصر والمعالجة المسبقة وتحليل التردد الزمني والنمذجة العكسية وإعداد التقارير. يُستخدم عند العمل مع mne.create_info، أو mne.io.RawArray، أو mne.Epochs، أو mne.compute_covariance، أو mne.preprocessing.ICA، أو mne.time_frequency.psd_array_welch، أو mne.make_sphere_model، أو mne.Report، أو سير عمل المستشعر/مساحة المصدر، أو التحكم في جودة الفيزيولوجيا الكهربية.
