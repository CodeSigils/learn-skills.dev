Audite y mejore las pruebas automatizadas de un proyecto de software existente como protección de regresión. Úselo cuando Codex necesite evaluar la calidad de las pruebas, asignar pruebas a capacidades visibles para el usuario o contratos documentados, encontrar pruebas acopladas a la implementación, excesivamente simuladas, inactivas, duplicadas, frágiles o de bajo valor, reducir el costo de CI, diseñar un plan de migración de pruebas o refactorizar pruebas preservando una cobertura significativa. Se aplica a unidades, integración, contratos, componentes y suites de un extremo a otro en todos los lenguajes y marcos.
