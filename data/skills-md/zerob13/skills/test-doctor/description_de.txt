Prüfen und verbessern Sie die automatisierten Tests eines bestehenden Softwareprojekts als Regressionsschutz. Verwenden Sie Codex, wenn Codex die Testqualität bewerten, Tests auf für den Benutzer sichtbare Funktionen oder dokumentierte Verträge abbilden, an die Implementierung gekoppelte, übermockte, tote, doppelte, fragile oder minderwertige Tests finden, CI-Kosten reduzieren, einen Testmigrationsplan entwerfen oder Tests umgestalten und gleichzeitig eine aussagekräftige Abdeckung beibehalten muss. Gilt für Unit-, Integrations-, Vertrags-, Komponenten- und End-to-End-Suites in allen Sprachen und Frameworks.
