Выполните реверс-инжиниринг поведенческих спецификаций из существующего исходного кода. Читает кодовую базу,
группирует общедоступную поверхность по доменам и записывает ДОЛЖНЫ/СЛЕДУЕТ/НЕ ДОЛЖНЫ спецификации из
что на самом деле делает код. Все выходные данные помечены как ВЫПОЛНЕННЫЕ и требуют вмешательства человека.
обзор. Предназначен для устаревших проектов без существующих спецификаций. Запустите один раз, чтобы установить
базовый уровень, а затем используйте /reflect-specs, чтобы поддерживать их в актуальном состоянии.
