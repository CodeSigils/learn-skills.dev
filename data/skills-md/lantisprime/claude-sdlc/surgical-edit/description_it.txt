Usa questa abilità su OGNI chiamata dello strumento di modifica, scrittura o modifica del codice. Applica la disciplina della differenza minima: tocca solo i file elencati nell'elenco nell'ambito del piano, modifica solo le funzioni elencate nelle funzioni nell'ambito del piano, non modificare mai le funzioni adiacenti, non eseguire mai il refactoring o rinominare il codice non correlato, non "aggiustare mai mentre sei qui". I bug non correlati vengono registrati nel file di follow-up, non risolti in linea. Questa abilità è il meccanismo principale per la regola fondamentale del progetto "tocca solo il codice che deve essere modificato, non modificare le funzioni adiacenti".
