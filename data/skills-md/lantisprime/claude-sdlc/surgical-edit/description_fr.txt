Utilisez cette compétence pour CHAQUE appel d’outil d’édition, d’écriture ou de modification de code. Applique une discipline de différence minimale : touchez uniquement les fichiers répertoriés dans la liste dans la portée du plan, modifiez uniquement les fonctions répertoriées dans les fonctions dans la portée du plan, ne modifiez jamais les fonctions adjacentes, ne refactorisez ou ne renommez jamais le code sans rapport, ne "corrigez jamais pendant que vous êtes ici". Les bogues non liés sont enregistrés dans le fichier de suivi et ne sont pas corrigés en ligne. Cette compétence est le mécanisme principal de la règle fondamentale du projet « ne touchez que le code qui doit être modifié, ne modifiez pas les fonctions adjacentes ».
