Используйте, когда пользователь хочет ДОБАВИТЬ НОВЫЕ события отслеживания в свою кодовую базу, ему нужен план отслеживания или после установки Infer SDK. Триггеры «что мне отслеживать», «предложить события», «план отслеживания», «добавить отслеживание». НЕ используйте для проверки текущих данных или запроса существующих событий — для этого используйте инструмент MCP get_top_events.
