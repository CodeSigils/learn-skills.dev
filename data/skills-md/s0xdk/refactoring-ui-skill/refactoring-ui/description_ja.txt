リファクタリング UI (Wathan & Schoger) の具体的なルール (制約された間隔/タイプ/色/影のスケール、サイズではなく重みと色による視覚的な階層、エミュレートされたライトによる深さ) を使用してユーザー インターフェイスを設計および改善します。 UI (Web、アプリ、ダッシュボード、ランディング ページ、コンポーネント) を構築またはスタイル設定するとき、フォント サイズ、間隔、色、影、または境界線の半径を選択するとき、カラー パレットやデザイン トークンをデザインするとき、誰かが UI が「見た目が悪い」、「素人っぽく見える」、「乱雑/地味/未完成な感じ」と言ったとき、または「見栄えをよくする」ように要求されたときに使用します。
