قم بتصميم واجهات المستخدم وتحسينها باستخدام القواعد الملموسة من Refactoring UI (Wathan & Schoger) - التباعد المقيد/النوع/اللون/مقاييس الظل، والتسلسل الهرمي المرئي من خلال الوزن واللون بدلاً من الحجم، والعمق من خلال محاكاة الضوء. يُستخدم عند إنشاء أو تصميم أي واجهة مستخدم (ويب، تطبيق، لوحة معلومات، صفحة مقصودة، مكون)، عند اختيار أحجام الخطوط أو التباعد أو الألوان أو الظلال أو نصف قطر الحدود، عند تصميم لوحة ألوان أو رموز تصميم مميزة، وعندما يقول شخص ما أن واجهة المستخدم "تبدو بعيدة"، أو "تبدو هواة"، أو "تبدو مزدحمة/بسيطة/غير مكتملة"، أو يطلب "جعل هذا يبدو أفضل".
