Utilice esta habilidad cuando el usuario escriba "/notas" o "@notas" con frases como "guardar esto", "documentar esto", "archivar esto en <proyecto/cliente>", "extraer decisiones", "extraer elementos de acción" o "actualizar notas de esta discusión". La habilidad genera el subagente bibliotecario de notas para extraer conocimiento duradero y archivarlo en la página Docmost correcta utilizando la estructura del espacio de trabajo existente. Vuelve a una página de bandeja de entrada configurada cuando la confianza es baja.
