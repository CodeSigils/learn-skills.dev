Consulta, resume, exporta, crea y edita las notas flomo de un usuario a través de la autenticación de escritorio local y la API flomo, sin automatización de la interfaz de usuario de Chrome. Úselo cuando el usuario desee una búsqueda rápida de notas, filtrado de etiquetas, exportación de rebajas, creación de notas ligeras o ediciones directas de texto en notas existentes.
