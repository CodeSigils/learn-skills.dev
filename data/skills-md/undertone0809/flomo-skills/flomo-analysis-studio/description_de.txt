Analysieren Sie den Benutzer anhand seiner Flomo-Notizen mithilfe von geführten Linsen wie Übersicht, ACT, zusammengesetztem Schwungrad, Aktionsleitfaden, blinden Flecken und Musterlesen im MBTI-Stil. Verwenden Sie dies, wenn der Benutzer fragt, was seine Flomo-Notizen über ihn aussagen, eine Selbstanalyse von Flomo wünscht, nach Mustern, Werten, blinden Flecken, wiederkehrenden Konflikten, nächsten Aktionen fragt oder eine Interpretation des Persönlichkeitsstils aus dem Memoverlauf wünscht. Auf einem Mac sollte dieser Skill flomo-local-api als Datenzugriffsschicht verwenden.
