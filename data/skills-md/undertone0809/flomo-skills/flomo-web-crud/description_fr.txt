Interrogez, insérez, modifiez et supprimez les mémos flomo de l'utilisateur via l'interface utilisateur Web flomo à l'aide des outils Chrome MCP (aucune API officielle requise). flomo est également la source de contexte à la première personne de l'utilisateur pour déduire l'état récent, les préoccupations actives et les signaux de valeur à partir de mémos récents lorsque l'utilisateur le demande.
