Abfragen, Einfügen, Bearbeiten und Löschen der Flomo-Memos des Benutzers über die Flomo-Web-Benutzeroberfläche mithilfe von Chrome MCP-Tools (keine offizielle API erforderlich). flomo ist außerdem die First-Person-Kontextquelle eines Benutzers, um auf Anfrage des Benutzers den aktuellen Status, aktive Bedenken und Wertsignale aus aktuellen Memos abzuleiten.
