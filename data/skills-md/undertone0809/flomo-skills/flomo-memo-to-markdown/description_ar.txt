تحويل مذكرات flomo من مصادقة سطح المكتب المحلي/واجهة برمجة التطبيقات (API) إلى ملفات Markdown مجمعة لقراءة AI/NotebookLM، بالإضافة إلى إحصائيات علامات Markdown التي يمكن قراءتها بواسطة الإنسان مع إجماليات الشجرة. يُستخدم عندما يطلب المستخدم تصدير ملاحظات flomo إلى Markdown، أو تقسيم المذكرات حسب الشهر/الربع/السنة، أو إنشاء أرشيفات متوافقة مع NotebookLM، أو إنتاج أعداد/تجميع علامات flomo.
