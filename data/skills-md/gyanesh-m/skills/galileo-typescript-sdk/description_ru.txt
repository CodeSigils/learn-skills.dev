Полный справочник по TypeScript/JS SDK платформы Galileo AI для оценки, наблюдения и защиты приложений GenAI. Используйте при создании приложений Node.js или TypeScript, которым требуется оценка LLM, возможность наблюдения за производством, трассировка или ограничения времени выполнения с помощью Galileo.
