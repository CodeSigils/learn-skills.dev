Gérer le cycle complet de développement des modules du projet : analyse des besoins → mise à jour de la solution technique → confirmation des spécifications → développement → acceptation → clôture. Condition de déclenchement : un document de spécification existe dans le cadre du projet et la demande de l'utilisateur implique des modifications de code (ajout de fonctionnalités, correction de bugs, modification des exigences, ajustement de l'interface, refactorisation, ajout/suppression de champs), sans exiger que l'utilisateur spécifie explicitement le processus.
