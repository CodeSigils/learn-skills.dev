Gérer le cycle complet de développement des modules du projet : analyse des besoins → mise à jour de la solution technique → confirmation des spécifications → développement → acceptation → clôture. Condition de déclenchement : il existe un document de spécification dans le cadre du projet et la demande de l'utilisateur implique des modifications de code (nouvelles fonctionnalités, corrections de bogues, modifications des exigences, ajustements de l'interface, refactorisation, ajouts ou suppressions de champs) ; aucune instruction utilisateur explicite pour le processus n’est nécessaire.
