إدارة دورة التطوير الكاملة لوحدات المشروع: تحليل المتطلبات ← تحديث الحل الفني ← تأكيد المواصفات ← التطوير ← القبول ← الإغلاق. شرط التشغيل: يوجد مستند المواصفات ضمن المشروع، ويتضمن طلب المستخدم تغييرات في التعليمات البرمجية (إضافة ميزة، إصلاح الأخطاء، تغيير المتطلبات، تعديل الواجهة، إعادة الهيكلة، إضافة/إزالة الحقل)، دون مطالبة المستخدم بتحديد العملية بشكل صريح.
