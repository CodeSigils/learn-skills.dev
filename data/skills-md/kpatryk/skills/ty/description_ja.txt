ty に関する専門家によるガイダンス — Astral (ruff と uv のメーカー) によって Rust で書かれた非常に高速な Python 型チェッカーです。現在ベータ版です。ユーザーが ty について言及した場合、Python コードの型チェックを希望している場合、Python の型チェックについて質問している場合、mypy または Pyright から移行したい場合、型チェック ルールを設定する必要がある場合、プロジェクトに型チェッカーを統合したい場合、型チェックのパフォーマンスについて尋ねる場合、または型チェック エラーと診断に関するサポートが必要な場合には、このスキルを使用してください。ユーザーが高速 Python ツールや Astral のツール全般について尋ねたときにもトリガーされます。
