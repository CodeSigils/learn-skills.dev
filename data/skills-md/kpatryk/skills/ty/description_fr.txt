Conseils d'experts pour ty - le vérificateur de type Python extrêmement rapide écrit en Rust par Astral (créateur de ruff et uv). Actuellement en version bêta. Utilisez cette compétence chaque fois que l'utilisateur mentionne ty, souhaite vérifier le code Python, pose des questions sur la vérification de type Python, souhaite migrer depuis mypy ou Pyright, doit configurer des règles de vérification de type, souhaite intégrer un vérificateur de type dans son projet, pose des questions sur les performances de vérification de type ou a besoin d'aide pour les erreurs de vérification de type et les diagnostics. Déclenchez également lorsque l'utilisateur pose des questions sur les outils Python rapides ou sur les outils d'Astral en général.
