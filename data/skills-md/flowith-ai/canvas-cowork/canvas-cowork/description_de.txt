Steuern Sie einen räumlichen Canvas über die CLI – erstellen Sie Canvases, generieren Sie Bilder/Texte/Videos/Agentenantworten, lesen Sie Ergebnisse, erinnern Sie sich an vergangene Arbeiten und verwalten Sie Knoten. Die Leinwand ist ein gemeinsamer Arbeitsbereich, der im Browser sichtbar ist. Mit dieser Fertigkeit erhalten Sie einen Live-Cursor darauf. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer mit der Canvas-Plattform interagieren möchte, Bilder oder Videos auf der Leinwand generieren möchte, „Leinwand“, „Neo“, „Agent Neo“ erwähnt, visuelle Inhalte auf der räumlichen Leinwand zeichnen/erstellen/generieren möchte, auf frühere Leinwandarbeiten verweist oder etwas sagt, das die Arbeit auf der Leinwand impliziert. Wird auch auf /canvas-cowork ausgelöst.
