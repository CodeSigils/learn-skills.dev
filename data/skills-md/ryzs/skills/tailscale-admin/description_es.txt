Úselo cuando el usuario desee administrar su tailnet de Tailscale a través de la API de administración: enumerar dispositivos, volver a etiquetar o eliminar nodos, administrar claves de autenticación, leer ACL o auditar la red de cola para detectar dispositivos obsoletos y claves no utilizadas. Llama a la API de administración de Tailscale en api.tailscale.com utilizando la var de entorno TAILSCALE_API_TOKEN. Realiza escrituras en vivo en la red trasera del usuario. Para operaciones CLI de nodo local (escala final arriba/abajo/servicio/embudo), consulte la habilidad de escala final de majiayu000/claude-skill-registry.
