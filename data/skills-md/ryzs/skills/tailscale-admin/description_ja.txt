ユーザーが管理 API 経由で Tailscale テールネットを管理する場合に使用します。デバイスの一覧表示、ノードの再タグ付けまたは削除、認証キーの管理、ACL の読み取り、または古いデバイスや未使用のキーのテールネットの監査などです。 TAILSCALE_API_TOKEN 環境変数を使用して、api.tailscale.com で Tailscale Admin API を呼び出します。ユーザーのテールネットに対してライブ書き込みを実行します。ローカルノードの CLI 操作 (テールスケール アップ/ダウン/サーブ/ファネル) については、代わりに majiayu000/claude-skill-registry のテールスケール スキルを参照してください。
