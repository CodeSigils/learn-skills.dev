Verwenden Sie diese Option, wenn der Benutzer sein Tailscale-Tailnet über die Admin-API verwalten möchte – Geräte auflisten, Knoten neu kennzeichnen oder entfernen, Authentifizierungsschlüssel verwalten, ACLs lesen oder das Tailnet auf veraltete Geräte und nicht verwendete Schlüssel prüfen möchte. Ruft die Tailscale Admin API unter api.tailscale.com unter Verwendung der Umgebungsvariable TAILSCALE_API_TOKEN auf. Führt Live-Schreibvorgänge im Tailnet des Benutzers durch. Informationen zu CLI-Vorgängen für lokale Knoten (Tailscale nach oben/unten/Serve/Funnel) finden Sie stattdessen im Tailscale-Skill von majiayu000/claude-skill-registry.
