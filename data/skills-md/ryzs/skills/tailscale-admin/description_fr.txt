À utiliser lorsque l'utilisateur souhaite gérer son tailnet Tailscale via l'API Admin : répertorier les appareils, relocaliser ou supprimer des nœuds, gérer les clés d'authentification, lire les ACL ou auditer le tailnet pour les appareils obsolètes et les clés inutilisées. Appelle l'API Tailscale Admin sur api.tailscale.com à l'aide de la variable d'environnement TAILSCALE_API_TOKEN. Effectue des écritures en direct sur le tailnet de l'utilisateur. Pour les opérations CLI de nœud local (tailscale up/down/serve/funnel), consultez plutôt la compétence tailscale de majiayu000/claude-skill-registry.
