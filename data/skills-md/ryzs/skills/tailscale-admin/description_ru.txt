Используйте, когда пользователь хочет управлять своей хвостовой сетью Tailscale через API администратора — выводить список устройств, перемаркировать или удалять узлы, управлять ключами аутентификации, читать списки управления доступом или проверять хвостовую сеть на наличие устаревших устройств и неиспользуемых ключей. Вызывает API администратора Tailscale на сайте api.tailscale.com, используя переменную среды TAILSCALE_API_TOKEN. Выполняет оперативную запись в хвостовую сеть пользователя. Для операций CLI на локальном узле (постепенное масштабирование вверх/вниз/обслуживание/воронка) вместо этого см. навык Tailscale majiayu000/claude-skill-registry.
