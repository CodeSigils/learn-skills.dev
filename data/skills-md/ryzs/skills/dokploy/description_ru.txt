Используйте, когда пользователь хочет взаимодействовать с самостоятельным PaaS Dokploy — развертывать приложения, обновлять переменные окружения, повторно развертывать сервисы, проверять статус развертывания или формировать готовые для Dokploy файлы Dockerfile. Вызывает REST API Dokploy напрямую, используя переменные окружения DOKPLOY_URL и DOKPLOY_API_TOKEN. Выполняет оперативную запись на сервер Dokploy пользователя.
