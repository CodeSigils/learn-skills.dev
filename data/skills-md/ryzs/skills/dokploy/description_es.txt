Úselo cuando el usuario desee interactuar con una PaaS autohospedada de Dokploy: implementar aplicaciones, actualizar variables de entorno, volver a implementar servicios, verificar el estado de la implementación o crear andamios Dockerfiles listos para Dokploy. Llama a la API REST de Dokploy directamente usando DOKPLOY_URL y DOKPLOY_API_TOKEN env vars. Realiza escrituras en vivo en el servidor Dokploy del usuario.
