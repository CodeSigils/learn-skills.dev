スキルを検証、修正し、GitHub リポジトリとして公開します。忠実に実行するためのワークフロー スキルを構造化します。シンボリックリンクを介してプラットフォーム全体でスキルを登録し、初回使用時のオンボーディングをガイドします。ユーザーが「スキルを作成する」、「スキルを鍛造する」、「このスキル リポジトリを確認する」、「このスキルを監査する」、「すべてのスキルを監査する」、「このプロジェクトを監査する」、「スキルをクリーンアップする」、「スキルをチェックする」、「このスキルを公開する」、「これを GitHub にプッシュする」、「ワークフロー スキルを構造化する」、「このフォルダからスキルを抽出する」、「プロトタイプをスキルに変換する」、またはプロジェクト ディレクトリを指す場合に使用します。スキルとルールが混在したもの、またはスキルがプロトタイプ化されていたエンジニアリング フォルダーに保存されます。 Forge: トリアージ → 発見 → 分類 → 検証 → 修正 → ローカルで準備完了。ワークショップでのインプット→監査前にトリアージでスキルを抽出。何も見つかりませんでした → オンボード ユーザー、スキャフォールド、そして同じパイプライン。要求されたら GitHub に公開します (ステップ 4)。
