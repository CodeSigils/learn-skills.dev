تصميم صور المنتج الرئيسية المتوافقة مع أمازون وأنواع الصور الثانوية السبعة (مخطط معلوماتي / متعدد الزوايا / لقطة تفصيلية / نمط الحياة / المتغيرات / محتويات الصندوق / مرجع الحجم) - مع قواعد الصورة الرئيسية الإلزامية للنظام الأساسي، وأنواع ثانوية مضبوطة بمعدل التحويل لكل فئة منتج، وتناسق الصور المتعددة المرتبط بعنوان URL الرئيسي للصورة. يُستخدم عندما يقول المستخدم "صورة Amazon الرئيسية"، أو "亚马逊主图"، أو "الصورة الرئيسية للمنتج"، أو "صورة المنتج ذات الخلفية البيضاء"، أو "صورة قائمة Amazon"، أو "الصور الثانوية"، أو "الصور الدائرية للمنتج"، أو أي طلب لمجموعة صور المنتج 1:1 الموجودة في مكتبة تفاصيل صفحة Amazon. بالنسبة لوحدات المحتوى / صفحة التفاصيل A+ (الشعار الرئيسي 21:9 وتخطيطات الوحدة 3:2)، راجع مهارة "صفحة تفاصيل لقطات المنتج".
