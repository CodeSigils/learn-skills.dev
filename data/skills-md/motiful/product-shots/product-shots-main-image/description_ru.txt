Создает совместимые с Amazon основные изображения продуктов и 7 типов вторичных изображений (инфографика, многоракурсное изображение, детальный снимок, образ жизни, варианты, содержимое коробки, указание размера) — с обязательными для платформы правилами для основного изображения, вторичными типами с настройкой коэффициента конверсии для каждой категории продуктов и согласованностью нескольких изображений, привязанной к URL-адресу основного изображения. Используйте, когда пользователь произносит «Основное изображение Amazon», «亚马逊主图», «Основное изображение продукта», «Изображение продукта на белом фоне», «Изображение списка Amazon», «亚马逊副图», «Дополнительные изображения», «Изображения карусели продуктов» или любой запрос на набор изображений продукта 1:1, который находится на карусели страницы сведений Amazon. Для модулей содержания A+/страницы с подробными сведениями (макет баннера героя 21:9 и макета модуля 3:2) см. навык `снимки продукта-страница с подробными сведениями`.
