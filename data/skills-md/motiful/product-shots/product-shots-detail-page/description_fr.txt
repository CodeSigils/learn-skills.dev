Conçoit du contenu Amazon A+ (anciennement Enhanced Brand Content) — la suite de 8 modules qui apparaît sous le carrousel de produits standard pour les vendeurs de marque enregistrée. Couvre la bannière du héros (21:9 / 2388 × 1024), les points douloureux / les arguments de vente / la technologie / les données / le mode d'emploi / les variantes (3:2 / 1536 × 1024) et l'approbation (21:9), avec une règle de zone de sécurité mobile, un plancher de texte de 30 points et une cohérence inter-modules ancrée à l'URL de l'image principale. À utiliser lorsque l'utilisateur dit « Page A+ », « Contenu A+ », « Amazon A+ », « Contenu de marque », « Contenu de marque amélioré », « 亚马逊详情页 », « A+ 详情页 », « Bannière 21:9 », « Bannière Hero », « Module de page de détail Amazon » ou toute demande de suite de modules de page de détail enregistrée par marque. Pour l'image principale 1:1 et les images secondaires du carrousel, consultez la compétence « product-shots-main-image ».
