تصميمات محتوى Amazon A+ (محتوى العلامة التجارية المحسّن سابقًا) — مجموعة الوحدات المكونة من 8 وحدات التي تظهر أسفل مكتبة المنتج القياسية للبائعين المسجلين للعلامة التجارية. يغطي شعار البطل (21:9 / 2388×1024)، ونقاط الألم / نقاط البيع / التكنولوجيا / البيانات / كيفية الاستخدام / المتغيرات (3:2 / 1536×1024)، والمصادقة (21:9)، مع قاعدة المنطقة الآمنة المتنقلة، وأرضية نص 30pt، والتناسق عبر الوحدات المرتكز على عنوان URL الرئيسي للصورة. يُستخدم عندما يقول المستخدم "صفحة A+"، أو "محتوى A+"، أو "Amazon A+"، أو "محتوى العلامة التجارية"، أو "محتوى العلامة التجارية المحسّن"، أو "亚马逊详情页"، أو "A+ 详情页"، أو "بانر 21:9"، أو "Hero Banner"، أو "وحدة صفحة تفاصيل Amazon"، أو أي طلب لمجموعة وحدات صفحة التفاصيل المسجلة للعلامة التجارية. بالنسبة للصورة الرئيسية بنسبة 1:1 والصور الثانوية الدائرية، راجع مهارة "لقطات المنتج-الصورة الرئيسية".
