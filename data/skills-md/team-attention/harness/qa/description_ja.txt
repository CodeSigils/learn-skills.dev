Web アプリ、ネイティブ macOS アプリ、Electron アプリ、CLI ツールなど、あらゆるアプリケーションを体系的に QA テストします。
インタラクティブな REPL、または画面上のあらゆるもの。 3 つのモード: ブラウザ (エージェント ブラウザ/Playwright、高速、DOM レベル)、
コンピューター (MCP コンピューター使用、スクリーンショット + ピクセル クリック、任意のアプリ)、および cli (tmux、send-keys +
対話型端末の場合はキャプチャ ペイン)。モードを自動選択するか、--browser / --computer / --cli オーバーライドを受け入れます。
「QA」、「QA」、「このサイトをテストする」、「このアプリをテストする」、「バグを見つける」、
「テストと修正」、「壊れているものを修正する」、「ドッグフード」、「探索的テスト」、「バグハント」、
"このアプリの QA"、"사이트 테스트"、"앱 테스트"、"브라우저 QA"、"화면 보고 테스트해줘"、
「네이티브 앱 테스트」、「スクリーンテスト」。
3 段階: クイック (クリティカル/高のみ)、標準 (+ 中)、徹底的 (+ 外観)。
前後のヘルススコア、修正の証拠、および船舶の準備状況の概要を生成します。
