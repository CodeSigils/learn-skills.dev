Используйте этот навык для генеративного редактирования видео, преобразования текста в видео, создания видео с привязкой к изображению и анимации перехода от первого кадра к видео с помощью официального SDK google-genai. Включает рабочие процессы для предварительной обработки/оптимизации видео с высоким разрешением или длинным исходным кодом с помощью ffmpeg, удаления звука для полной регенерации звука, а также пошагового редактирования видео и параллельного выполнения.
