Stratégie d'approvisionnement en données pour la robotique et l'IA physique : choisissez entre des ensembles de données hors ligne (hub HuggingFace, Open X-Embodiment et similaires), des données générées par simulation et une collecte téléop/robot réel ; planifiez les formats de stockage, la structure des épisodes et la gestion des versions des ensembles de données. À utiliser lorsque : "où obtenons-nous les données", "données de formation pour le robot", "ensemble de données pour la manipulation", "générer des données dans la simulation", "collecter des démonstrations", planifier tout pipeline de données pour l'apprentissage du robot. Compétence parapluie ; la mécanique vit en aval : opérations de hub dans huggingface, formats LeRobot dans lerobot, génération synthétique dans isaac-sim/gazebo. Pas pour : la formation du modèle lui-même (lerobot, isaac-lab) ou la recherche d'appareils/actifs de test (test-assets).
