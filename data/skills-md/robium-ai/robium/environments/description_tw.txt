機器人專案的虛擬環境優先設定：決定 uv/venv 與 Docker，使本機和遠端伺服器運作以相同方式再現，處理 GPU 直通和無頭/顯示轉送。使用時間：設定任何新的機器人專案環境； 'uv'、'venv'、'virtualenv'、'此專案的 docker'、'可重現的環境'、'在本地工作但不在伺服器上'、'容器中的 GPU'、'此專案應該使用 uv 或 Docker'。在任何 robium 建造中儘早加載，緊接在建築師之後。決策經驗法則：純 Python ML 堆疊 → uv；任何需要 ROS 2 或系統依賴的東西 → Docker。不適用於：多模組應用程式 Dockerfile 和組合佈線（整合技能），或配置 RunPod 資源並對其進行故障排除（runpod 技能）。
