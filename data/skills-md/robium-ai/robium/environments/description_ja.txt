ロボティクス プロジェクト向けの仮想環境ファーストのセットアップ: uv/venv と Docker を決定し、ローカルとリモート サーバーの実行を同一に再現し、GPU パススルーとヘッドレス/ディスプレイ転送を処理します。次の場合に使用します: 新しいロボット プロジェクト環境をセットアップする場合。 'uv'、'venv'、'virtualenv'、'このプロジェクトの docker'、'再現可能な環境'、'ローカルで動作するがサーバー上では動作しない'、'コンテナ内の GPU'、'このプロジェクトは uv または Docker を使用するべきか'。 robium ビルドの早い段階で、アーキテクトの直後にロードします。経験則の決定: 純粋な Python ML スタック → UV; ROS 2 または system deps → Docker を必要とするもの。対象外: マルチモジュール アプリケーションの Dockerfile と構成ワイヤリング (統合スキル)、または RunPod リソースのプロビジョニングとトラブルシューティング (runpod スキル)。
