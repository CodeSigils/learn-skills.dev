مواصفات HyperFrames الصينية للفيديو القصير والمعالجة المسبقة للتخطيط (شاشة رأسية يمكن قراءتها على Douyin/Xiaohongshu). ينطبق على مقاطع الفيديو الروائية الصينية مع أي عدد من اللقطات. يجب عليك أولاً قراءة هذه المهارة، ثم قراءة الإطارات التشعبية، والإطارات التشعبية ‑ cli، وgsap؛ قبل كتابة HTML، يجب عليك قراءة التصميم والذوق والواجهة الأمامية (مهارة الذوق)، والقوالب/مكافحة slop-motion-scheme.md، والقوالب/hyperframes-zh-checklist.md، والرسوم المتحركة لـ css، ومبادئ حركة التصميم، وطباعة الويب، والقوالب/visual-style-guide.md. لكل مشروع، يجب عليك إنتاج ملف design.md (بما في ذلك خطة الحركة) وتدوير الأنماط المرئية؛ يحظر إعادة استخدام نفس القالب.

قواعد التصميم الثابت: يجب أن تكون الترجمات السفلية دائمًا سطرًا واحدًا، ويجب ألا يتداخل نص الصفحة، ويجب أن يستخدم الصينيون الخطوط المحلية/ + @font‑face (PingFang، وMicrosoft YaHei، وGoogle Fonts محظورة)، ويحظر استخدام الرموز التعبيرية بنمط الذكاء الاصطناعي أو الرسوم التوضيحية بنمط الميم؛ الرسوم المتحركة: خلفية ثابتة L0 `#root` + مدخل L1 + محاذاة دلالية L2. يعد تحويل النص إلى كلام (TTS) إلزاميًا (يُحظر استخدام تقنية CSS Infinite Ambient لكل لقطة).

قبل التسليم، يجب عليك تشغيل checklist.py check-delivery-checklist.py + Verified‑index‑encoding.py + npm run check (بدون أخطاء). يتم تعيين TTS الصيني افتراضيًا على Edge TTS (generate‑tts.py)؛ بعد تحويل النص إلى كلام (TTS)، يجب عليك تشغيل align‑subtitles.py (الطوابع الزمنية على مستوى الكلمة ذات الهمس الأسرع) ثم application‑audio‑schedule.mjs؛ الوسائط التشعبية غير مطلوبة.

يجب على الوكيل إكمال البيئة بأكملها تلقائيًا وعملية البناء (الفحص المسبق، والسقالات، وتحويل النص إلى كلام، والمحاذاة، والجدول الزمني، والتحقق من الصحة)؛ يحتاج المستخدم فقط إلى تشغيل npm run dev يدويًا للمعاينة. يُحظر العرض/التصدير التلقائي إلى MP4 — يجب أن ينتظر التصدير تأكيد المستخدم.

يتم فصل الصوت (الصوت) والترجمة (الترجمة): يتم إنشاء تحويل النص إلى كلام (TTS) لكل جملة منطوقة، ولا يجب تقسيم تحويل النص إلى كلام (TTS) للوفاء بحدود السطر الواحد للترجمة. قم بتقسيم النص المنطوق للمستخدم بشكل دلالي إلى مشاهد متعددة، وإنشاء نسخة على الشاشة، وتخطيط التخطيط، وتخصيص المدة، وتحديد التحولات والرسوم المتحركة، وتنسيق التعليق الصوتي/BGM/ترتيب المؤثرات الصوتية.
