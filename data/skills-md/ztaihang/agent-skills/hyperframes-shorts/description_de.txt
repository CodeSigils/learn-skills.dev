HyperFrames chinesische Kurzvideo-Visual- und Layout-Vorverarbeitungsspezifikation (vertikaler Bildschirm lesbar auf Douyin/Xiaohongshu). Anwendbar auf chinesische Erzählvideos mit beliebig vielen Aufnahmen. Muss zuerst diese Fähigkeit lesen, dann Hyperframes, Hyperframes-Cli, Gsap; Bevor Sie HTML schreiben, müssen Sie design-taste-frontend (taste-skill), templates/anti-slop-motion-scheme.md, templates/hyperframes-zh-checklist.md, css-animations, design-motion-principles, web-typography und templates/visual-style-guide.md lesen. Für jedes Projekt müssen Sie eine design.md (einschließlich eines Bewegungsplans) erstellen und visuelle Stile drehen; Die Wiederverwendung derselben Vorlage ist verboten.

Strenge Regeln für das Layout: Untertitel müssen immer einzeilig sein, Seitentext darf sich nicht überlappen, Chinesisch muss lokale Schriftarten/ + @font‑face verwenden (PingFang, Microsoft YaHei, Google Fonts sind verboten), Emoji- oder Meme-Illustrationen im KI-Stil sind verboten; Animationen: L0 „#root“ statischer Hintergrund + L1 Eingang + L2 semantische Ausrichtung. TTS ist obligatorisch (CSS Infinite Ambient per Shot ist verboten).

Vor der Zustellung müssen Sie „Verify‑delivery‑checklist.py“ + „Verify‑index‑encoding.py“ + „npm run check“ ausführen (keine Fehler). Chinesisches TTS ist standardmäßig Edge TTS (generate‑tts.py); nach TTS müssen Sie align-subtitles.py ausführen (schnellere Whisper-Zeitstempel auf Wortebene) und dann apply-audio-schedule.mjs; hyperframes-media ist nicht erforderlich.

Der Agent muss den gesamten Umgebungs- und Erstellungsprozess automatisch abschließen (Vorprüfung, Gerüstbau, TTS, Ausrichtung, Zeitleiste, Validierung); Der Benutzer muss lediglich npm run dev manuell ausführen, um eine Vorschau anzuzeigen. Das automatische Rendern/Exportieren in MP4 ist verboten – der Export muss auf die Bestätigung des Benutzers warten.

Stimme (Stimme) und Untertitel (Untertitel) sind getrennt: TTS wird pro gesprochenem Satz generiert und TTS darf nicht geteilt werden, um die Grenzwerte für Untertitel in einer Zeile einzuhalten. Teilen Sie das gesprochene Skript des Benutzers semantisch in mehrere Szenen auf, erstellen Sie eine Kopie auf dem Bildschirm, planen Sie das Layout, weisen Sie die Dauer zu, legen Sie Übergänge und Animationen fest und koordinieren Sie die Anordnung von Voice-Over/Hintergrundmusik/Soundeffekten.
