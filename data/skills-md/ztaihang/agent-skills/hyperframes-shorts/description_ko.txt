HyperFrames 중국어 단편 비디오 시각적 및 레이아웃 전처리 사양(Douyin/Xiaohongshu에서 읽을 수 있는 수직 화면). 샷 수에 관계없이 중국어 내레이션 비디오에 적용할 수 있습니다. 먼저 이 기술을 읽어야 하며 그런 다음 hyperframes, hyperframes‑cli, gsap을 읽어야 합니다. HTML을 작성하기 전에 디자인-테이스트-프론트엔드(테이스트-스킬), template/anti-slop-motion-scheme.md, template/hyperframes-zh-checklist.md, css-animations, design-motion-principles, web-typography 및 template/visual-style-guide.md를 읽어야 합니다. 각 프로젝트에 대해 design.md(모션 계획 포함)를 생성하고 시각적 스타일을 회전해야 합니다. 동일한 템플릿을 재사용하는 것은 금지되어 있습니다.

하드 레이아웃 규칙: 하단 자막은 항상 한 줄이어야 하고, 페이지 텍스트가 겹쳐서는 안 되며, 중국어는 현지 글꼴을 사용해야 합니다. + @font-face(PingFang, Microsoft YaHei, Google Fonts는 금지됨), AI 스타일 이모티콘 또는 밈 스타일 일러스트레이션은 금지됩니다. 애니메이션: L0 `#root` 정적 배경 + L1 입구 + L2 의미 정렬. TTS는 필수입니다(샷당 CSS 무한 주변 환경은 금지됩니다).

전달하기 전에 verify‑delivery‑checklist.py + verify‑index‑encoding.py + npm run check(오류 없음)를 실행해야 합니다. 중국어 TTS는 기본적으로 Edge TTS(generate‑tts.py)로 설정됩니다. TTS 후에는 align‑subtitles.py(빠른 속삭임 단어 수준 타임스탬프)를 실행한 다음 apply‑audio‑schedule.mjs를 실행해야 합니다. 하이퍼프레임 미디어는 필요하지 않습니다.

에이전트는 전체 환경 및 빌드 프로세스(사전 확인, 스캐폴딩, TTS, 정렬, 타임라인, 검증)를 자동으로 완료해야 합니다. 사용자는 미리 보려면 npm run dev를 수동으로 실행하기만 하면 됩니다. 자동 렌더링/MP4로 내보내기는 금지됩니다. 내보내기는 사용자 확인을 기다려야 합니다.

음성(음성)과 자막(자막)이 분리됩니다. TTS는 음성 문장별로 생성되며 자막 한 줄 제한을 충족하기 위해 TTS를 분할해서는 안 됩니다. 사용자의 음성 스크립트를 의미론적으로 여러 장면으로 분할하고, 화면 사본을 생성하고, 레이아웃을 계획하고, 지속 시간을 할당하고, 전환 및 애니메이션을 지정하고, 음성 해설/BGM/사운드 효과 배열을 조정합니다.
