HyperFrames 中文短视频视觉与版式预处理规范（抖音/小红书竖屏可读）。适用于任意镜头数量的中文解说视频。必须先读本 Skill，再读 hyperframes、hyperframes-cli、gsap；写 HTML 前必须读 design-taste-frontend（taste-skill）、templates/anti-slop-motion-scheme.md、templates/hyperframes-zh-checklist.md、css-animations、design-motion-principles、web-typography 与 templates/visual-style-guide.md，每项目须产出 design.md（含 Motion Plan）并轮换视觉风格，禁止套同一模板。硬性版式：底部字幕永远单行、页面文字不得重叠、中文须本地 fonts/ + @font-face（禁 PingFang/微软雅黑/Google Fonts）、禁止 AI 风 emoji/表情包式插图；动效：L0 `#root` 静态背景 + L1 入场 + L2 语义对齐 TTS 必做（禁止每镜 CSS infinite ambient）。交付前必须跑 verify-delivery-checklist.py + verify-index-encoding.py + npm run check（0 error）。中文 TTS 默认 Edge TTS（generate-tts.py）；TTS 后必须 align-subtitles.py（faster-whisper 词级时间戳）再 apply-audio-schedule.mjs；不需要 hyperframes-media。Agent 须自动跑完全部环境与构建（预检、脚手架、TTS、对齐、时间轴、校验），用户只需手动 npm run dev 预览；禁止自动 render 导出 MP4，须等用户确认后再导出。口播（voice）与字幕（subtitle）分离：TTS 按口播整句生成，禁止为字幕单行上限拆分 TTS。将用户的口播稿按语义拆分为多个场景，生成上屏文案、规划布局、分配时长、指定转场和动效，并统筹配音/BGM/音效编排。
