HyperFrames — китайская спецификация визуальных эффектов и предварительной обработки макета короткого видео (для чтения на вертикальном экране на Douyin/Xiaohongshu). Применимо к видео с повествованием на китайском языке с любым количеством кадров. Необходимо сначала прочитать этот навык, затем прочитать гиперфреймы, гиперфреймы‑cli, gsap; перед написанием HTML вы должны прочитать design-taste-frontend (taste-skill), templates/anti-slop-motion-scheme.md, templates/hyperframes-zh-checklist.md, css-animations, design-motion-principles, web-typography и templates/visual-style-guide.md. Для каждого проекта вы должны создать файл design.md (включая план движения) и выполнить ротацию визуальных стилей; повторное использование одного и того же шаблона запрещено.

Жесткие правила макета: нижние субтитры всегда должны быть одной строкой, текст на странице не должен перекрываться, китайский язык должен использовать местные шрифты/ + @font‑face (PingFang, Microsoft YaHei, Google Fonts запрещены), эмодзи в стиле AI или иллюстрации в стиле мемов запрещены; анимации: статический фон L0 `#root` + вход L1 + семантическое выравнивание L2. TTS обязателен (бесконечное окружение CSS для каждого кадра запрещено).

Перед доставкой необходимо запустить проверку‑delivery‑checklist.py +verify‑index‑encoding.py + проверку запуска npm (ноль ошибок). По умолчанию для китайского TTS используется Edge TTS (generate‑tts.py); после TTS необходимо запустить align-subtitles.py (временные метки на уровне слов fast-whisper), а затем применить-audio-schedule.mjs; Hyperframes‑media не требуется.

Агент должен автоматически завершить всю среду и процесс сборки (предварительная проверка, создание строительных лесов, TTS, согласование, график, проверка); пользователю нужно только вручную запустить npm run dev для предварительного просмотра. Автоматический рендеринг/экспорт в MP4 запрещен — экспорт должен дождаться подтверждения пользователя.

Голос (голос) и субтитры (субтитры) разделены: TTS генерируется для каждого произнесенного предложения, и TTS не должен разделяться, чтобы соответствовать ограничениям на количество одной строки субтитров. Семантически разделяйте произносимый пользователем сценарий на несколько сцен, создавайте копии на экране, планируйте макет, распределяйте продолжительность, указывайте переходы и анимацию, а также координируйте расположение закадрового голоса, фоновой музыки и звуковых эффектов.
