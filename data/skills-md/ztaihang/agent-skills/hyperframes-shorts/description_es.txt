Especificación de preprocesamiento de diseño y visualización de videos cortos chinos de HyperFrames (legible en pantalla vertical en Douyin/Xiaohongshu). Aplicable a vídeos de narración china con cualquier número de tomas. Primero debe leer esta habilidad, luego leer hipercuadros, hipercuadros‑cli, gsap; antes de escribir HTML debe leer design‑taste‑frontend (taste‑skill), templates/anti‑slop‑motion‑scheme.md, templates/hyperframes‑zh‑checklist.md, css‑animations, design‑motion‑principles, web‑typography y templates/visual‑style‑guide.md. Para cada proyecto debe producir un design.md (incluido un plan de movimiento) y rotar estilos visuales; Está prohibido reutilizar la misma plantilla.

Reglas estrictas de diseño: los subtítulos inferiores siempre deben ser de una sola línea, el texto de la página no debe superponerse, los chinos deben usar fuentes locales/ + @font‑face (PingFang, Microsoft YaHei y Google Fonts están prohibidos), los emoji de estilo AI o las ilustraciones de estilo meme están prohibidos; animaciones: fondo estático L0 `#root` + entrada L1 + alineación semántica L2. TTS es obligatorio (se prohíbe CSS ambiental infinito por toma).

Antes de la entrega, debe ejecutar verificar‑delivery‑checklist.py + verificar‑index‑encoding.py + npm run check (cero errores). El TTS chino por defecto es Edge TTS (generate‑tts.py); después de TTS, debe ejecutar align‑subtitles.py (marcas de tiempo más rápidas a nivel de palabra) y luego aplicar‑audio‑schedule.mjs; Hyperframes‑media no es necesario.

El Agente debe completar automáticamente todo el entorno y el proceso de construcción (verificación previa, andamiaje, TTS, alineación, cronograma, validación); el usuario solo necesita ejecutar npm run dev manualmente para obtener una vista previa. La renderización/exportación automática a MP4 está prohibida; la exportación debe esperar la confirmación del usuario.

La voz (voz) y los subtítulos (subtítulos) están separados: el TTS se genera por oración hablada y el TTS no debe dividirse para cumplir con los límites de subtítulos de una sola línea. Divida semánticamente el guión hablado del usuario en múltiples escenas, genere una copia en pantalla, planifique el diseño, asigne la duración, especifique transiciones y animaciones y coordine la disposición de voz en off, música de fondo y efectos de sonido.
