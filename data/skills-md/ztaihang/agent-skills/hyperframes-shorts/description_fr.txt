Spécification de prétraitement visuel et de mise en page des courtes vidéos chinoises HyperFrames (lisible sur écran vertical sur Douyin/Xiaohongshu). Applicable aux vidéos de narration chinoise avec un nombre quelconque de plans. Doit d'abord lire cette compétence, puis lire les hyperframes, hyperframes‑cli, gsap ; avant d'écrire du HTML, vous devez lire design‑taste‑frontend (taste‑skill), templates/anti‑slop‑motion‑scheme.md, templates/hyperframes‑zh‑checklist.md, css‑animations, design‑motion‑principles, web‑typography et templates/visual‑style‑guide.md. Pour chaque projet, vous devez produire un design.md (incluant un plan de mouvement) et faire pivoter les styles visuels ; la réutilisation du même modèle est interdite.

Règles de mise en page strictes : les sous-titres du bas doivent toujours être sur une seule ligne, le texte de la page ne doit pas se chevaucher, le chinois doit utiliser des polices locales/ + @font‑face (PingFang, Microsoft YaHei, Google Fonts sont interdits), les emoji de style IA ou les illustrations de style mème sont interdites ; animations : fond statique L0 `#root` + entrée L1 + alignement sémantique L2. Le TTS est obligatoire (le CSS ambiant infini par tir est interdit).

Avant la livraison, vous devez exécuter verify‑delivery‑checklist.py + verify‑index‑encoding.py + npm run check (zéro erreur). La TTS chinoise est par défaut Edge TTS (generate‑tts.py) ; après TTS, vous devez exécuter align‑subtitles.py (horodatages plus rapides au niveau des mots), puis apply‑audio‑schedule.mjs ; les hyperframes‑media ne sont pas requis.

L'agent doit compléter automatiquement l'ensemble de l'environnement et du processus de construction (vérification préalable, échafaudage, TTS, alignement, chronologie, validation) ; l'utilisateur n'a qu'à exécuter manuellement npm run dev pour prévisualiser. Le rendu/l'exportation automatique vers MP4 est interdit : l'exportation doit attendre la confirmation de l'utilisateur.

La voix (voix) et les sous-titres (sous-titres) sont séparés : le TTS est généré par phrase prononcée et le TTS ne doit pas être divisé pour respecter les limites des sous-titres sur une seule ligne. Divisez sémantiquement le script parlé de l'utilisateur en plusieurs scènes, générez une copie à l'écran, planifiez la mise en page, attribuez la durée, spécifiez les transitions et les animations et coordonnez la disposition des voix off/BGM/effets sonores.
