الحفاظ على ذاكرة الاستنتاج ذاتية التطور على مستوى المشروع. استخدمه في مهام المستودع غير التافهة مثل التحقيق أو التشخيص أو التنفيذ أو التحقق أو الصيانة أو اتخاذ قرارات المشروع طويلة الأجل؛ اقرأ ذاكرة المشروع في البداية، وبعد الانتهاء، قم بترسيخ الحقائق التي تم التحقق منها، والقرارات طويلة المدى، والمزالق القابلة للتكرار التي يجب تجنبها. عندما يطلب المستخدم صراحةً جرد التجارب التي تستحق الحفاظ عليها، أدخل سؤالًا واحدًا في كل مرة "الشواء"؛ عندما يطلبون تنظيم ذاكرة المشروع أو تبسيطها أو تنظيفها، أدخل سؤالًا واحدًا في كل مرة "اقتطاع". الاستخدام في أعمال المستودع غير التافهة مثل التحقيق أو التشخيص أو التنفيذ أو التحقق أو الصيانة أو القرارات الدائمة؛ اقرأ ذاكرة المشروع أولاً واحصل على استنتاجات قابلة لإعادة الاستخدام تم التحقق منها عند الانتهاء. أدخل سؤالًا واحدًا في كل مرة Grilling عندما يسأل المستخدم صراحةً عن التجربة التي تستحق الذاكرة، أو Trim عندما يطلب دمج ذاكرة المشروع أو تنظيفها.
