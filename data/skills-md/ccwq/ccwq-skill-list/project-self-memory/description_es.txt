Mantener una memoria de conclusiones autoevolutiva a nivel de proyecto. Úselo para tareas de repositorio no triviales, como investigación, diagnóstico, implementación, verificación, mantenimiento o establecimiento de decisiones de proyectos a largo plazo; Lea la memoria del proyecto al principio y, al finalizar, solidifique los hechos verificados, las decisiones a largo plazo y los obstáculos reproducibles que se deben evitar. Cuando el usuario solicite explícitamente hacer un inventario de experiencias que valga la pena preservar, ingrese una pregunta a la vez "Grilling"; cuando soliciten organizar, optimizar o limpiar la memoria del proyecto, ingrese una pregunta a la vez "Recortar". Úselo para trabajos de repositorio no triviales, como investigación, diagnóstico, implementación, verificación, mantenimiento o decisiones duraderas; lea primero la memoria del proyecto y capture conclusiones reutilizables verificadas al finalizar. Ingrese Grilling de una pregunta a la vez cuando el usuario pregunte explícitamente qué experiencia merece memoria, o Trim cuando solicite consolidar o limpiar la memoria del proyecto.
