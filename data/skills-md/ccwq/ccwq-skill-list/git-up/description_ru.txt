Комплексный инструмент фиксации коммитов Git: анализируйте изменения, планируйте разделение коммитов, генерируйте стандартизированные сообщения о коммитах и ​​выполняйте коммит непосредственно в оболочке.  
Используйте его, когда пользователь упоминает любой из следующих запросов:  
- «отправить код», «зафиксировать один раз», «помогите мне выполнить git commit», «git up»  
- «разделить изменения на несколько коммитов», «планировать коммиты», «разделить коммит», «пакетный коммит»  
- «создать сообщение о фиксации», «записать информацию о фиксации»  
- «обсудить/изменить план фиксации», «--plan/-p», «--discuss», «--modify», «--commit/-c»  
- «запланировать и зафиксировать», «одноэтапное принятие», «--plan --commit», «-pc»  

Пожалуйста, всегда отвечайте на языке пользователя.
