أداة Git Commit الشاملة: تحلل التغييرات، وتخطط لتقسيم الالتزام، وتولد رسائل التزام قياسية، وتنفذ الالتزام مباشرة عبر Shell.  
استخدمه عندما يذكر المستخدم أيًا من الطلبات التالية:  
- "إرسال الرمز"، "الالتزام قليلاً"، "ساعدني في الالتزام بـ git"، "git up"  
- "تقسيم التغييرات إلى عدة التزامات"، "التزامات الخطة"، "الالتزام المقسم"، "الالتزام المجمع"  
- "إنشاء رسالة التزام"، "كتابة معلومات الالتزام"  
- "مناقشة/تعديل خطة الالتزام"، "--الخطة/-p"، "--مناقشة"، "--تعديل"، "--الالتزام/-ج"  
- "التخطيط والالتزام"، "الالتزام بخطوة واحدة"، "--التخطيط --الالتزام"، "-pc"  

يرجى الرد دائمًا بلغة المستخدم.
