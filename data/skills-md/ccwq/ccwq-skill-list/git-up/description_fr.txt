Outil complet de validation Git : analyse les modifications, planifie le fractionnement des validations, génère des messages de validation standard et exécute la validation directement via le shell.  
Utilisez-le lorsque l'utilisateur mentionne l'une des demandes suivantes :  
- "soumettre le code", "commit un peu", "aidez-moi git commit", "git up"  
- "diviser les modifications en plusieurs commits", "plan commits", "split commit", "batch commit"  
- "générer un message de validation", "écrire des informations de validation"  
- « discuter/modifier le plan de validation », « --plan/-p », « --discuss », « --modify », « --commit/-c »  
- « planifier et valider », « commit en une étape », « --plan --commit », « -pc »  

Veuillez toujours répondre dans la langue de l’utilisateur.
