Strumento completo di commit Git: analizza le modifiche, pianifica la suddivisione del commit, genera messaggi di commit standard ed esegue il commit direttamente tramite shell.  
Utilizzalo quando l'utente menziona una delle seguenti richieste:  
- "invia codice", "impegna un po'", "aiutami a git commit", "git up"  
- "dividi modifiche in più commit", "commit pianificati", "commit diviso", "commit batch"  
- "genera messaggio di commit", "scrivi informazioni di commit"  
- “discuss/modify commit plan”, “--plan/-p”, “--discuss”, “--modify”, “--commit/-c”  
- "pianifica e conferma", "commit in un solo passaggio", "--plan --commit", "-pc"  

Si prega di rispondere sempre nella lingua dell'utente.
