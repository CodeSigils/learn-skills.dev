Git コミット包括ツール: 変更を分析し、コミット分割を計画し、標準コミット メッセージを生成し、シェル経由で直接コミットを実行します。  
ユーザーが次のいずれかのリクエストに言及する場合に使用します。  
- 「コードを送信してください」、「少しコミットしてください」、「git commit を手伝ってください」、「git up」  
- 「変更を複数のコミットに分割」、「プランコミット」、「分割コミット」、「バッチコミット」  
- 「コミットメッセージの生成」、「コミット情報の書き込み」  
- 「コミット計画の議論/変更」、「--plan/-p」、「--議論」、「--modify」、「--commit/-c」  
- 「計画とコミット」、「ワンステップコミット」、「--plan --commit」、「-pc」  

常にユーザーの言語で応答してください。
