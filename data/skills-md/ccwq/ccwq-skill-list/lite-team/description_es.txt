Habilidad ligera de colaboración entre múltiples agentes, que utiliza un tablero de colaboración docs/bbs/lite-team-bbs.md para transferir información manualmente entre diferentes agentes/sesiones. Úselo cuando el usuario especifica o cambia manualmente los roles de desarrollo (producto, desarrollo, pruebas, arquitectura, auditoría de seguridad, etc.), requiere transferencia de roles entre sesiones, necesita leer/escribir o inicializar el tablero de colaboración docs/bbs/lite-team-bbs.md, o desea finalizar/archivar la colaboración ligera. No se utiliza para tareas ordinarias de un solo agente ni para la orquestación automática de múltiples agentes.
