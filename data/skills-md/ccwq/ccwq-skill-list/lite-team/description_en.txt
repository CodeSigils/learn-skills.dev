A lightweight multi-agent collaboration skill that uses a docs/bbs/lite-team-bbs.md collaboration board to manually hand off information between different agents/sessions. Use it when the user manually specifies or switches development roles (product, development, testing, architecture, security audit, etc.), requires cross-session role handovers, needs to read/write or initialize the docs/bbs/lite-team-bbs.md collaboration board, or wants to end/archive the lightweight collaboration. It is not used for ordinary single-agent tasks or automatic multi-agent orchestration.
