Wird immer dann verwendet, wenn ein Backend-HTTP-Endpunkt in einem Test verwendet wird – zum Schreiben, Ausführen, Überprüfen oder einfach zum Aufrufen. Der Skill besitzt die strukturierte Form, die jede API-Interaktion erzeugen sollte: Statuscode-Erwartungen, Antwortschema-Assertion, Fehlerhüllenvalidierung, Header-Abdeckung. Es wird automatisch bei Auslösern mit expliziter Absicht aktiviert (Vertragstest, Schematest, Pakt, OpenAPI-Konformität, API-Vertrag sperren, API-Form überprüfen, Erkennung von Breaking Changes, verbrauchergesteuerter Vertrag, Anbieterüberprüfung, API-Kompatibilität, Spezifikationskonformität, sicherstellen, dass sich die API nicht geändert hat) UND bei jedem Test oder geplanten Test, der „steps.apiGet“, „steps.apiPost“, „steps.apiPut“ aufruft. „steps.apiDelete“, „steps.apiPatch“, „steps.apiHead“, „steps.verifyApiStatus“ oder „steps.verifyApiHeader“ – sogar innerhalb einer UI-Flow-Spezifikation. Der Grundgedanke: Jeder Backend-Aufruf verdient mindestens einen Statuscode + eine Fehlerumschlagszusicherung; Ohne diese besteht der Test stillschweigend, wenn der Endpunkt zurückgeht. Wird auch bei Phrasen aktiviert, die signalisieren, dass eine Backend-Interaktion bald landen wird: „Rufen Sie die API in einem Test auf“, „Testen Sie gegen das Backend“, „verbrauchen Sie die API“, „überprüfen Sie die Antwort“, „bestätigen Sie die JSON-Form“, „validieren Sie die API-Antwort“, „Sperren Sie die Antwort des Backends“, „Endpunkt sollte zurückkehren“ und jede Erwähnung eines HTTP-Verbs gegenüber einer Projekt-URL innerhalb eines Spezifikationskontexts. Echte Routen in: der Companion-Skills-Tabelle von Element-Interactions (die die Vertragsabsicht hier weiterleitet), der direkten Benutzerabsicht und der Step-3-Implementierungsregel des Test-Composers, die diese Fertigkeit über das Skill-Tool aufruft, wenn eine Variante „steps.api*“-Zeilen ausgibt, anstatt die Vertragsform als optional zu behandeln. Nicht für: reine UI-Flow-Behauptungen, Abdeckungserweiterung auf Reiseebene, Fehlersuche auf Seitenebene oder fehlgeschlagene Testdiagnose – diese führen zu ihren eigenen Fähigkeiten.
