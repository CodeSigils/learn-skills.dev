Используйте всякий раз, когда серверная конечная точка HTTP используется в тесте — записывайте, запускайте, просматривайте или просто вызывайте. Навык имеет структурированную форму, которую должно создавать каждое взаимодействие API: ожидания кода состояния, утверждение схемы ответа, проверка конверта ошибок, покрытие заголовка. Он автоматически активируется по триггерам с явным намерением (тест контракта, тест схемы, договор, соответствие OpenAPI, блокировка контракта API, проверка формы API, обнаружение разрыва изменений, контракт, управляемый потребителем, проверка поставщика, совместимость API, соответствие спецификации, гарантия того, что API не изменился) И на любом тесте или запланированном тесте, который вызывает `steps.apiGet`, `steps.apiPost`, `steps.apiPut`, `steps.apiDelete`, «steps.apiPatch», «steps.apiHead», «steps.verifyApiStatus» или «steps.verifyApiHeader» — даже внутри спецификации потока пользовательского интерфейса. Обоснование: каждый внутренний вызов заслуживает как минимум утверждения кода состояния + конверта ошибки; без них тест молча проходит, когда конечная точка регрессирует. Также активируется на фразах, которые сигнализируют о скором взаимодействии с серверной частью: «вызвать API в тесте», «проверить на серверной части», «использовать API», «проверить ответ», «подтвердить форму JSON», «проверить ответ API», «заблокировать ответ серверной части», «конечная точка должна вернуться» и любое упоминание глагола HTTP против URL-адреса проекта внутри контекста спецификации. Реальные маршруты в: таблице компаньонов-навыков element-interactions (которая направляет сюда намерение контракта), прямом намерении пользователя и правиле реализации Step-3 Test-composer, которое вызывает этот навык через инструмент Skill всякий раз, когда вариант выдает строки `steps.api*` вместо того, чтобы рассматривать форму контракта как необязательную. Не для: чисто утверждений потока пользовательского интерфейса, расширения охвата в рамках цикла, поиска ошибок на уровне страницы или диагностики неудачных тестов — все это зависит от их собственных навыков.
