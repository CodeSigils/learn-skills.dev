Cree, revise o mejore la persistencia de Core Data en aplicaciones que no han adoptado SwiftData. Úselo cuando trabaje con subclases de NSMangedObject, NSFetchedResultsController para UI basada en listas, NSBatchInsertRequest / NSBatchDeleteRequest / NSBatchUpdateRequest para operaciones masivas, NSPersistentHistoryChangeRequest para seguimiento de historial persistente y sincronización de múltiples objetivos, NSStaggedMigrationManager para migraciones de esquemas por etapas (iOS 17+), NSCompositeAttributeDescription para atributos compuestos (iOS 17+), o al integrar subprocesos de Core Data con Swift Concurrency. Para la coexistencia o migración de Core Data + SwiftData, consulte la habilidad swiftdata en su lugar.
