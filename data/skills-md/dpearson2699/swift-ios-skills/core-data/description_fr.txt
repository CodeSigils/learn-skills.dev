Créez, révisez ou améliorez la persistance des données de base dans les applications qui n'ont pas adopté SwiftData. À utiliser lorsque vous travaillez avec les sous-classes NSManagedObject, NSFetchedResultsController pour l'interface utilisateur basée sur des listes, NSBatchInsertRequest / NSBatchDeleteRequest / NSBatchUpdateRequest pour les opérations en masse, NSPersistentHistoryChangeRequest pour le suivi de l'historique persistant et la synchronisation multi-cibles, NSStagedMigrationManager pour les migrations de schémas par étapes (iOS 17+), NSCompositeAttributeDescription pour les attributs composites. (iOS 17+), ou lors de l'intégration du thread Core Data avec Swift Concurrency. Pour la coexistence ou la migration de Core Data + SwiftData, consultez plutôt la compétence Swiftdata.
