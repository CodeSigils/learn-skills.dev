Создавайте, проверяйте или улучшайте сохранение основных данных в приложениях, которые не поддерживают SwiftData. Используйте при работе с подклассами NSManagedObject, NSFetchedResultsController для пользовательского интерфейса, управляемого списком, NSBatchInsertRequest/NSBatchDeleteRequest/NSBatchUpdateRequest для массовых операций, NSPersistentHistoryChangeRequest для постоянного отслеживания истории и многоцелевой синхронизации, NSStagedMigrationManager для поэтапной миграции схемы (iOS 17+), NSCompositeAttributeDescription для составные атрибуты (iOS 17+) или при интеграции потоков Core Data с Swift Concurrency. Чтобы узнать о сосуществовании или миграции Core Data + SwiftData, см. навык SwiftData.
