Crea, rivedi o migliora la persistenza dei Core Data nelle app che non hanno adottato SwiftData. Da utilizzare quando si lavora con le sottoclassi NSManagedObject, NSFetchedResultsController per l'interfaccia utente basata su elenchi, NSBatchInsertRequest/NSBatchDeleteRequest/NSBatchUpdateRequest per operazioni di massa, NSPersistentHistoryChangeRequest per il monitoraggio persistente della cronologia e la sincronizzazione multi-target, NSStagedMigrationManager per migrazioni di schemi a fasi (iOS 17+), NSCompositeAttributeDescription per attributi compositi (iOS 17+) o quando si integra il threading Core Data con Swift Concurrency. Per la coesistenza o la migrazione di Core Data + SwiftData, consulta invece la competenza swiftdata.
