Erstellen, überprüfen oder verbessern Sie die Persistenz von Kerndaten in Apps, die SwiftData nicht übernommen haben. Verwendung bei der Arbeit mit NSManagedObject-Unterklassen, NSFetchedResultsController für listengesteuerte Benutzeroberfläche, NSBatchInsertRequest/NSBatchDeleteRequest/NSBatchUpdateRequest für Massenvorgänge, NSPersistentHistoryChangeRequest für persistente Verlaufsverfolgung und Synchronisierung mehrerer Ziele, NSStagedMigrationManager für gestaffelte Schemamigrationen (iOS 17+), NSCompositeAttributeDescription für zusammengesetzte Attribute (iOS 17+) oder bei der Integration von Core Data Threading mit Swift Concurrency. Informationen zur Koexistenz oder Migration von Core Data + SwiftData finden Sie stattdessen im Swiftdata-Skill.
