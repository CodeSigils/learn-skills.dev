Incorpora e controlla i contenuti web in SwiftUI con WebKit per SwiftUI, inclusi WebView, WebPage, criteri di navigazione, esecuzione JavaScript, stato osservabile della pagina, intercettazione di collegamenti, HTML locale o caricamento di dati e schemi URL personalizzati. Da utilizzare durante la creazione di visualizzazioni di articoli/dettagli per iOS 26+, centri assistenza, documentazione in-app o altre esperienze web integrate supportate da HTML, CSS e JavaScript.
