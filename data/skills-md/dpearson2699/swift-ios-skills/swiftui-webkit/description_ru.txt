Встраивает и контролирует веб-контент в SwiftUI с помощью WebKit для SwiftUI, включая WebView, WebPage, политики навигации, выполнение JavaScript, наблюдаемое состояние страницы, перехват ссылок, локальный HTML или загрузку данных, а также пользовательские схемы URL-адресов. Используйте при создании представлений статей/подробных сведений для iOS 26+, справочных центров, документации в приложении или других встроенных веб-интерфейсов, поддерживаемых HTML, CSS и JavaScript.
