Incorpore et contrôle le contenu Web dans SwiftUI avec WebKit pour SwiftUI, y compris WebView, WebPage, les politiques de navigation, l'exécution de JavaScript, l'état de la page observable, l'interception de liens, le HTML local ou le chargement de données et les schémas d'URL personnalisés. À utiliser lors de la création de vues d'articles/détails sur iOS 26+, de centres d'aide, de documentation intégrée à l'application ou d'autres expériences Web intégrées soutenues par HTML, CSS et JavaScript.
