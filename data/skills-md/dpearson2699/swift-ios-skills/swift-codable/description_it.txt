Implementa modelli Swift Codable per JSON e codifica e decodifica di elenchi di proprietà con JSONDecoder, JSONEncoder, CodingKeys e init(from:) o encode(to:) personalizzati. Da utilizzare durante l'analisi delle risposte API, la rimappatura delle chiavi, l'appiattimento di JSON nidificati, la gestione di strategie di decodifica di dati o dati, la decodifica di array eterogenei o l'integrazione di Codable con URLSession, SwiftData o UserDefaults.
