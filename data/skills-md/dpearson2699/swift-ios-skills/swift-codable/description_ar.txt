قم بتنفيذ نماذج Swift Codable لتشفير وفك تشفير JSON وقائمة الخصائص باستخدام JSONDecoder وJSONEncoder وCodingKeys وinit(from:) أو encode(to:) المخصص. يُستخدم عند تحليل استجابات واجهة برمجة التطبيقات (API)، أو إعادة تعيين المفاتيح، أو تسوية JSON المتداخلة، أو التعامل مع استراتيجيات فك تشفير البيانات أو التاريخ، أو فك تشفير المصفوفات غير المتجانسة، أو دمج Codable مع URLSession، أو SwiftData، أو UserDefaults.
