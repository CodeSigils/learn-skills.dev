Configure et applique SwiftLint dans les projets Swift à l'aide de plugins d'outils de construction, d'exécution de scripts et de CI. Couvre la configuration .swiftlint.yml, les règles désactivées, opt_in_rules, only_rules, analyser_rules, les lignes de base, la correction automatique, Swiftlint : désactiver les suppressions, les formats de rapport (sarif, json, checkstyle), les modes strict et indulgent, SwiftLintBuildToolPlugin via SimplyDanny/SwiftLintPlugins, le plugin de package Swift Swiftlint, les phases de script d'exécution Xcode, l'intégration CI, plusieurs fichiers de configuration et le déploiement. stratégies pour les bases de code existantes. À utiliser lors de la configuration de SwiftLint, de la configuration des règles de charpie, de la suppression des avertissements, de la création de lignes de base, du choix entre le plug-in de l'outil de construction et l'exécution du script, ou de l'intégration de SwiftLint dans CI.
