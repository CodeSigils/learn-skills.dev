Transfiera datos de aplicaciones entre plataformas usando AppMigrationKit. Úselo al implementar una migración de datos única desde Android u otras plataformas a iOS, administrar sesiones de transferencia multiplataforma con AppMigrationExtension, empaquetar y archivar datos de usuario para exportar, importar recursos en el dispositivo de destino, rastrear el progreso de la transferencia, manejar errores de migración o crear flujos de incorporación que importen datos de usuario existentes.
