Переносите данные приложения между платформами с помощью AppMigrationKit. Используйте при реализации однократной миграции данных с Android или других платформ на iOS, управлении сеансами межплатформенной передачи с помощью AppMigrationExtension, упаковке и архивировании пользовательских данных для экспорта, импорте ресурсов на целевое устройство, отслеживании хода передачи, обработке ошибок миграции или построении потоков адаптации, которые импортируют существующие пользовательские данные.
