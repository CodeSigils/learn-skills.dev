أنشئ تطبيقات تدعم CarPlay باستخدام إطار عمل CarPlay. يُستخدم عند إنشاء تطبيقات الملاحة أو الصوت أو الاتصالات أو شحن المركبات الكهربائية أو مواقف السيارات أو طلب الطعام لشاشة السيارة، أو العمل مع CPTemplateApplicationScene، أو CPListTemplate، أو CPMapTemplate، أو CPNowPlayingTemplate، أو تكوين استحقاقات CarPlay، أو التكامل مع CarPlay Simulator للاختبار.
