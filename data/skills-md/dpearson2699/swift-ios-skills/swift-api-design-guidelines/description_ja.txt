Swift API 設計ガイドラインを適用して、Swift API に名前を付け、ラベルを付け、文書化します。引数のラベル規則 (前置詞句規則、文法句規則、最初のラベルの省略)、変異/非変異ペアの命名 (-ed/-ing 分詞パターン、形式接頭語、ソート/ソート、formUnion/union)、副作用の命名 (純粋の名詞、変異の動詞)、ドキュメントのコメント構造 (宣言の種類による要約、O(1) 複雑さの規則)、呼び出しサイトでの明確さ、役割ベースの命名、プロトコルの命名をカバーします。 (-able/-ible/-ing)、メソッド ファミリ、大文字と小文字の規則、および用語に対するデフォルトの引数。新しい Swift API の設計、名前付けと引数ラベルの確認、ドキュメント コメントの作成、または呼び出しサイトを明確にするためのリファクタリングを行うときに使用します。
