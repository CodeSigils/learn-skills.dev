Применяйте рекомендации по проектированию Swift API для именования, маркировки и документирования Swift API. Охватывает правила меток аргументов (правило предложной фразы, правило грамматической фразы, пропуск первой метки), именование мутирующих/немутирующих пар (образец причастия -ed/-ing, префикс form-, сортировка/сортировка, formUnion/union), именование побочных эффектов (существительное для чистого, глагол для мутации), структуру комментариев к документации (сводка по типу объявления, правило сложности O(1), ясность на месте вызова, именование на основе ролей, именование протоколов (-able/-ible/-ing), аргументы по умолчанию для семейств методов, соглашения о регистре и терминология. Используйте при разработке новых API-интерфейсов Swift, проверке именования и меток аргументов, написании комментариев к документации или рефакторинге для ясности сайта вызова.
