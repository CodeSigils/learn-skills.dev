Aplique las pautas de diseño de API de Swift para nombrar, etiquetar y documentar las API de Swift. Cubre reglas de etiquetas de argumentos (regla de frase preposicional, regla de frase gramatical, omisión de primera etiqueta), denominación de pares mutantes/no mutantes (patrón de participio -ed/-ing, prefijo de forma, clasificación/ordenación, unión/unión), denominación de efectos secundarios (sustantivo para puro, verbo para mutación), estructura de comentarios de documentación (resumen por tipo de declaración, regla de complejidad O(1), claridad en el sitio de llamada, denominación basada en roles, denominación de protocolo (-able/-ible/-ing), argumentos predeterminados sobre familias de métodos, convenciones de mayúsculas y minúsculas y terminología. Úselo al diseñar nuevas API de Swift, revisar etiquetas de nombres y argumentos, escribir comentarios de documentación o refactorizar para lograr claridad en el sitio de llamadas.
