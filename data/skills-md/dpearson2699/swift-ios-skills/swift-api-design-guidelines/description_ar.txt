قم بتطبيق إرشادات تصميم Swift API لتسمية وتسمية وتوثيق واجهات برمجة تطبيقات Swift. يغطي قواعد تسمية الوسيطة (قاعدة عبارة حرف الجر، قاعدة العبارة النحوية، حذف التسمية الأولى)، تسمية الزوج المتحولة/غير المتغيرة (-ed/-ing نمط النعت، بادئة النموذج، الفرز/الفرز، formUnion/union)، تسمية التأثير الجانبي (اسم نقي، فعل للطفرات)، بنية تعليق التوثيق (ملخص حسب نوع الإعلان، قاعدة التعقيد O(1))، الوضوح في موقع الاتصال، والتسمية القائمة على الأدوار، وتسمية البروتوكول (-able/-ible/-ing)، والوسائط الافتراضية عبر عائلات الطرق، واصطلاحات الحالة، والمصطلحات. يُستخدم عند تصميم واجهات برمجة تطبيقات Swift جديدة، أو مراجعة تسميات التسمية والوسائط، أو كتابة تعليقات الوثائق، أو إعادة البناء من أجل وضوح موقع الاتصال.
