Applica le linee guida per la progettazione delle API Swift per denominare, etichettare e documentare le API Swift. Copre le regole per l'etichettatura degli argomenti (regola della frase preposizionale, regola della frase grammaticale, omissione della prima etichetta), denominazione delle coppie mutanti/non mutanti (modello del participio -ed/-ing, prefisso forma-, ordinamento/ordinato, formUnion/unione), denominazione degli effetti collaterali (sostantivo per puro, verbo per mutante), struttura dei commenti della documentazione (riepilogo per tipo di dichiarazione, regola di complessità O(1), chiarezza sul sito di chiamata, denominazione basata sui ruoli, denominazione del protocollo (-able/-ible/-ing), argomenti predefiniti sulle famiglie di metodi, convenzioni sull'uso dell'involucro e terminologia. Da utilizzare durante la progettazione di nuove API Swift, la revisione delle etichette di nomi e argomenti, la scrittura di commenti sulla documentazione o il refactoring per la chiarezza del sito di chiamata.
