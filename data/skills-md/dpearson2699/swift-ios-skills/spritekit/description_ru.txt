Создавайте 2D-игры и анимацию с помощью SpriteKit. Используйте при создании игровых сцен с помощью SKScene и SKView, добавлении спрайтов с помощью SKSpriteNode, анимации с помощью последовательностей SKAction, моделировании физики с помощью SKPhysicsBody и обнаружении контактов, создании эффектов частиц с помощью SKEmitterNode, построении тайловых карт, использовании SKCameraNode или интеграции сцен SpriteKit в SwiftUI с помощью SpriteView.
