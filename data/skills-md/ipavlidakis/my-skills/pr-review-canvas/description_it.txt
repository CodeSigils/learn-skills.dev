Visualizza una revisione delle differenze PR come un canvas HTML che raggruppa le modifiche in base all'importanza del revisore, separa il boilerplate dalla logica di base ed evidenzia il codice complicato o inaspettato. Da utilizzare durante la revisione di una richiesta pull, il riepilogo di una differenza per la revisione o quando l'utente richiede un quadro di revisione PR, una procedura dettagliata delle differenze o una panoramica del set di modifiche.
