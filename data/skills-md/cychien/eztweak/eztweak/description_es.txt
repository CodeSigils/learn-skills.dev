Ejecute un bucle de revisión visual en una aplicación de desarrollo en vivo: el usuario anota elementos y texto directamente en el navegador, la retroalimentación fluye con las ubicaciones de origen exactas, el agente edita el código, HMR actualiza la página y repite. Úselo después de generar o modificar la interfaz de usuario que el usuario debe revisar visualmente, o cuando el usuario solicite revisar/anotar una página en ejecución.
