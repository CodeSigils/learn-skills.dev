Durchsuchen Sie das Web mit mehreren Ausgabeformaten mithilfe der Qryma-API. Verwenden Sie diese Fähigkeit, wenn der Benutzer das Web durchsuchen, Informationen zu einem bestimmten Thema finden möchte, „Suchen“, „Nachschlagen“, „Informationen finden“, „Websuche“ sagt oder schnelle Antworten aus dem Internet benötigt. Unterstützt das Markdown-Format für bessere Lesbarkeit, JSON für strukturierte Daten und das Brave-Suchformat.
