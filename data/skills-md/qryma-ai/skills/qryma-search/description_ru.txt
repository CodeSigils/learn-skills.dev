Выполняйте поиск в Интернете в нескольких форматах вывода с помощью API Qryma. Используйте этот навык, когда пользователь хочет выполнить поиск в Интернете, найти информацию по определенной теме, говорит «поиск», «поиск», «найти информацию», «поиск в Интернете» или ему нужны быстрые ответы в Интернете. Поддерживает формат Markdown для удобства чтения, JSON для структурированных данных и формат поиска Brave.
