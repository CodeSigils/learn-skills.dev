Recherchez sur le Web avec plusieurs formats de sortie à l'aide de l'API Qryma. Utilisez cette compétence lorsque l'utilisateur souhaite effectuer une recherche sur le Web, trouver des informations sur un sujet spécifique, dit « rechercher », « rechercher », « trouver des informations », « rechercher sur le Web » ou a besoin de réponses rapides sur Internet. Prend en charge le format Markdown pour la lisibilité, JSON pour les données structurées et le format de type recherche Brave.
