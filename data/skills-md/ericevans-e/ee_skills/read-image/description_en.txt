Read and analyze images using a vision-capable model. Supports custom focus: user can specify what to focus on (layout, code, errors, data, etc.) via prompt parameter. Use when the user asks to read, describe, analyze, or transcribe content from an image file (PNG, JPG, GIF, WebP, BMP, TIFF). Trigger keywords: read image, describe image, analyze image, what's in this image, look at this, 读图, 看图, 分析图片, 描述图片, 截图, 图片内容, 关注排版, 重点看.
