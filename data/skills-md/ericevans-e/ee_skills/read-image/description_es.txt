Lea y analice imágenes utilizando un modelo con capacidad de visión. Admite enfoque personalizado: el usuario puede especificar en qué centrarse (diseño, código, errores, datos, etc.) mediante un parámetro de solicitud. Se utiliza cuando el usuario solicita leer, describir, analizar o transcribir contenido de un archivo de imagen (PNG, JPG, GIF, WebP, BMP, TIFF). Palabras clave de activación: leer imagen, describir imagen, analizar imagen, qué hay en esta imagen, mirar esto, 读图, 看图, 分析图片, 描述图片, 截图, 图片内容, 关注排版, 重点看.
