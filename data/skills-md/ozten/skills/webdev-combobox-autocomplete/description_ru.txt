Базовые шаблоны для создания доступных компонентов автозаполнения и списка со списком с управлением состоянием, шаблонами ARIA, навигацией с помощью клавиатуры, асинхронными предложениями и реализацией, не зависящей от платформы. Используйте при создании входных данных автозаполнения, палитр команд, входных данных поиска, выбора замен или любого раскрывающегося списка с навигацией с помощью клавиатуры и предложениями.
