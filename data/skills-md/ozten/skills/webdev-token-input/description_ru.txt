Шаблоны ввода многозначных токенов/чипов для ввода тегов, панелей фильтров и полей «Кому» электронной почты. Создан на основе webdev-combobox-autocomplete с управлением состоянием токена, анализом ключа:значения, контекстно-зависимыми предложениями и шаблонами редактирования токенов. Используйте при создании входных фильтров, селекторов тегов, фишек с множественным выбором или любых входных данных, которые создают визуальные токены/таблетки из текста.
