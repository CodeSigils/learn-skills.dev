Построение фильтрующих запросов для конкретного домена с представлением AST, обработкой операторов, сериализацией запросов и входными данными для конкретных типов полей. Используйте при создании расширенных пользовательских интерфейсов фильтров для инструментов наблюдения, анализа данных, интерфейсов поиска или любой системы, требующей построения структурированных запросов с логической логикой, операторами сравнения и сериализацией URL-адресов и строк.
