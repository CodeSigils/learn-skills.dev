Creazione di query di filtri specifici del dominio con rappresentazione AST, gestione degli operatori, serializzazione delle query e input specifici del tipo di campo. Da utilizzare durante la creazione di interfacce utente di filtro avanzate per strumenti di osservabilità, analisi dei dati, interfacce di ricerca o qualsiasi sistema che richieda la costruzione di query strutturate con logica booleana, operatori di confronto e serializzazione di URL/stringhe.
