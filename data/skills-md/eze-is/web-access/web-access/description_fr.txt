Toutes les opérations réseau doivent être gérées via cette compétence, y compris : la recherche, le scraping Web, les opérations post-connexion, les interactions réseau, etc. Scénarios de déclenchement : lorsque l'utilisateur demande une recherche d'informations, la visualisation de contenu Web, l'accès à des sites Web nécessitant une connexion, l'exploitation d'interfaces Web, le scraping de contenu de médias sociaux (Xiaohongshu, Weibo, Twitter, etc.), la lecture de pages rendues dynamiquement et toute tâche réseau nécessitant un véritable environnement de navigateur.
