Todas las operaciones de red deben manejarse a través de esta habilidad, incluyendo: búsqueda, web scraping, acciones posteriores al inicio de sesión, interacciones de red, etc. Escenarios desencadenantes: cuando el usuario solicita buscar información, ver contenido web, visitar sitios web que requieren inicio de sesión, operar interfaces web, extraer contenido de redes sociales (Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente y cualquier tarea de red que requiera un entorno de navegador real.
