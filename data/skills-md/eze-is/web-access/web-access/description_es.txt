Todas las operaciones de red deben manejarse a través de esta habilidad, incluyendo: búsqueda, web scraping, operaciones posteriores al inicio de sesión, interacciones de red, etc. Escenarios desencadenantes: cuando el usuario solicita búsqueda de información, visualización de contenido web, acceso a sitios web que requieren inicio de sesión, operación de interfaces web, scraping de contenido de redes sociales (Xiaohongshu, Weibo, Twitter, etc.), lectura de páginas renderizadas dinámicamente y cualquier tarea de red que requiera un entorno de navegador real.
