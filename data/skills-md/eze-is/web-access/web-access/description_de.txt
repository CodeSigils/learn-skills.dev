Alle Netzwerkvorgänge müssen über diese Fertigkeit abgewickelt werden, einschließlich: Suchen, Web-Scraping, Post-Login-Vorgänge, Netzwerkinteraktionen usw. Auslöseszenarien: wenn der Benutzer eine Informationssuche anfordert, Webinhalte anzeigt, auf Websites zugreift, die eine Anmeldung erfordern, Webschnittstellen bedienen, Social-Media-Inhalte (Xiaohongshu, Weibo, Twitter usw.) scrapen, dynamisch gerenderte Seiten lesen und alle Netzwerkaufgaben, die eine echte Browserumgebung erfordern.
