Alle Netzwerkvorgänge müssen diese Fähigkeit durchlaufen, einschließlich: Suchen, Web-Scraping, Post-Login-Aktionen, Netzwerkinteraktionen usw. Auslöseszenarien: wenn der Benutzer eine Informationssuche anfordert, Webinhalte anzeigen, auf Websites zugreifen, die eine Anmeldung erfordern, Webschnittstellen bedienen, Social-Media-Inhalte (Xiaohongshu, Weibo, Twitter usw.) scrapen, dynamisch gerenderte Seiten lesen und jede Netzwerkaufgabe, die eine echte Browserumgebung erfordert.
