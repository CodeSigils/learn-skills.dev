Créez des applications de bureau natives avec NativePHP for Desktop v2 (nativephp/desktop) sur Laravel. Cela couvre l'installation, les fenêtres, les menus, les notifications, les dialogues, les API système, les bases de données SQLite, les files d’attente, les processus enfants, la diffusion, la construction, la publication et la sécurité. Utilisez-le lors de la création d’applications de bureau NativePHP, d’applications Electron+Laravel, de façades Native\Desktop, ou avec php artisan native:run/native:build.
