Crea applicazioni desktop native con NativePHP for Desktop v2 (nativephp/desktop) su Laravel. Copre installazione, finestre, menu, notifiche, dialoghi, API di sistema, database SQLite, code, processi figli, broadcasting, compilazione, pubblicazione e sicurezza. Da utilizzare quando si costruiscono app desktop NativePHP, app Electron+Laravel, facciate Native\Desktop o php artisan native:run/native:build.
