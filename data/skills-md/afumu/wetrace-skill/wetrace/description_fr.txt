Assistant d'analyse des journaux de discussion WeChat, utilisé pour interroger, analyser et exporter les données de discussion à partir de la base de données WeChat locale. Scénarios applicables : (1) Afficher les messages de discussion avec des contacts ou des groupes spécifiques, (2) Rechercher dans les conversations par mot-clé, (3) Analyser les modèles de discussion, les tendances d'activité ou la dynamique des relations, (4) Exporter les enregistrements de discussion dans plusieurs formats (HTML/PDF/DOCX/CSV/XLSX), (5) Obtenir des informations sur les interactions sociales et les habitudes de communication, (6) Gérer les relations clients et les rappels de suivi, (7) Générer des rapports annuels ou des statistiques, (8) Créer des pages HTML visuelles raffinées. Mots déclencheurs : wetrace, WeChat, journal de discussion, wechat, analyse de chat, exportation de chat, génération de rapports, génération de tableaux de bord ou toute demande impliquant l'analyse des données de chat WeChat, la recherche de messages ou les informations sur les relations.
