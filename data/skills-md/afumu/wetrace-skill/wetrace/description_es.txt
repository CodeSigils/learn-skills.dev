Asistente de análisis de registros de chat de WeChat, utilizado para consultar, analizar y exportar datos de chat desde la base de datos local de WeChat. Escenarios aplicables: (1) Ver mensajes de chat con contactos o grupos específicos, (2) Buscar conversaciones por palabra clave, (3) Analizar patrones de chat, tendencias de actividad o dinámica de relaciones, (4) Exportar registros de chat en múltiples formatos (HTML/PDF/DOCX/CSV/XLSX), (5) Obtener información sobre interacciones sociales y hábitos de comunicación, (6) Administrar relaciones con clientes y recordatorios de seguimiento, (7) Generar informes o estadísticas anuales, (8) Crear páginas HTML visuales pulidas. Palabras desencadenantes: wetrace, WeChat, registro de chat, wechat, análisis de chat, exportación de chat, generación de informes, generación de paneles o cualquier solicitud que implique análisis de datos de chat de WeChat, búsqueda de mensajes o información sobre relaciones.
