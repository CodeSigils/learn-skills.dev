Meta-Fähigkeit: Erforschen Sie den Denkrahmen gründlich und synthetisieren Sie dann einen neuen
Claude-Code-Fähigkeit, die ihr Denken auf Geschäftsideen anwendet. Nimmt eine Aufforderung entgegen
wie „/add-thinker Andy Grove – Only the Paranoid Survive“ und produziert ein neues
Skill unter .claude/skills/<thinker>/SKILL.md, der wie /munger funktioniert.
Wird verwendet, wenn der Benutzer „Denker hinzufügen“, „Neuen Denker hinzufügen“, „Denken von X kodifizieren“ sagt.
oder „Erstellen Sie eine Fertigkeit für das Framework von <Person>“.
