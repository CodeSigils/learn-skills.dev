Escriba, valide, cree, obtenga una vista previa, inspeccione, instale y depure flujos de trabajo de artefactos ahtml `.agent.html`. Utilícelo cuando produzca documentos dirigidos a agentes que necesiten una estructura más rica, una lectura más clara, una interacción o un uso compartido más fácil de lo que Markdown puede ofrecer; al instalar o reparar el tiempo de ejecución administrado; o al diagnosticar errores de tiempo de ejecución, compilación, vista previa o validación.
