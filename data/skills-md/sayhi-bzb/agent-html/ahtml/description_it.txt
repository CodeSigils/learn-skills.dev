Scrivi, convalida, crea, visualizza in anteprima, ispeziona, installa ed esegui il debug dei flussi di lavoro degli artefatti ahtml `.agent.html`. Da utilizzare quando si producono documenti rivolti agli agenti che necessitano di una struttura più ricca, una lettura più chiara, un'interazione o una condivisione più semplice di quanto Markdown possa fornire; durante l'installazione o la riparazione del runtime gestito; o durante la diagnosi di errori di runtime, compilazione, anteprima o convalida.
