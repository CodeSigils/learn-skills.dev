HTML/CSS/JavaScript/React を使用して、Web ページ、ランディング ページ、ダッシュボード、インタラクティブ プロトタイプ、HTML スライド デッキ、アニメーション デモ、UI モックアップ、データ ビジュアライゼーションなど、高品質のビジュアル Web 成果物を構築します。
ユーザーのリクエストに次のようなビジュアル、インタラクティブ、またはフロントエンドの成果物が含まれる場合は常に、このスキルを使用します。
- Web ページ、ランディング ページ、ダッシュボード、マーケティング ページの作成
- インタラクティブなプロトタイプまたは UI モックアップの構築 (デバイス フレームを使用)
- HTML スライドデッキ/プレゼンテーションの作成
- CSS/JS アニメーションまたはタイムライン駆動のアニメーション デモの作成
- デザインのモックアップ、スクリーンショット、または PRD をインタラクティブな実装に変換する
- データの視覚化 (Chart.js / D3 など)
- デザインシステム/UIキットの探索
ユーザーが「HTML」または「Web ページ」と明示的に言わなくても、このスキルは、視覚的、インタラクティブ、またはプレゼンテーション的なものを作成することを目的とする場合には常に適用されます。
該当なし: 純粋なバックエンド ロジック、CLI ツール、データ処理スクリプト、非ビジュアル コード タスク、コマンド ライン デバッグ。
