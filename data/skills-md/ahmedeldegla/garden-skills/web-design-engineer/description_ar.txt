أنشئ عناصر ويب مرئية عالية الجودة باستخدام HTML/CSS/JavaScript/React - صفحات الويب، والصفحات المقصودة، ولوحات المعلومات، والنماذج الأولية التفاعلية، ومجموعات شرائح HTML، والعروض التوضيحية المتحركة، ونماذج واجهة المستخدم، وتصورات البيانات، والمزيد.
استخدم هذه المهارة عندما يتضمن طلب المستخدم تسليمًا مرئيًا أو تفاعليًا أو أماميًا، بما في ذلك:
- إنشاء صفحات الويب والصفحات المقصودة ولوحات المعلومات وصفحات التسويق
- بناء نماذج تفاعلية أو نماذج بالحجم الطبيعي لواجهة المستخدم (مع إطارات الجهاز)
- إنشاء مجموعات شرائح / عروض تقديمية بتنسيق HTML
- إنشاء رسوم متحركة CSS/JS أو عروض توضيحية متحركة تعتمد على الجدول الزمني
- تحويل نماذج التصميم أو لقطات الشاشة أو PRDs إلى تطبيقات تفاعلية
- تصور البيانات (Chart.js / D3، وما إلى ذلك)
- نظام التصميم / استكشاف أدوات واجهة المستخدم
حتى إذا لم يذكر المستخدم صراحةً "HTML" أو "صفحة ويب"، تنطبق هذه المهارة عندما يكون القصد هو إنتاج شيء مرئي أو تفاعلي أو عرضي.
غير قابل للتطبيق: المنطق الخلفي الخالص، وأدوات واجهة سطر الأوامر (CLI)، والنصوص البرمجية لمعالجة البيانات، ومهام التعليمات البرمجية غير المرئية، وتصحيح أخطاء سطر الأوامر.
