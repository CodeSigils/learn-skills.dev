Собственные результаты рукописи, предназначенные только для оценки, без переписывания: полный научный обзор, выставление оценок, отчеты рецензентов, диагностика проблем, AC/мета-обзор, оценка готовности, обзор написания/формата и сравнение перекрестных версий. Использовать для полного обзора, научного обзора, не переписывать, только оценка, рецензирование статьи, отклонение оценок, обзор движущейся цели,写作评审, LaTeX检查.
