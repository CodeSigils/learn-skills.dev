Выполняйте реверс-инжиниринг и клонируйте веб-сайт за один раз — извлекайте ресурсы, CSS и контент по разделам и заранее отправляйте агенты параллельного построения в рабочие деревья по мере их выполнения. Используйте это всякий раз, когда пользователь хочет клонировать, реплицировать, перестраивать, реконструировать или копировать любой веб-сайт. Также срабатывает на такие фразы, как «сделать копию этого сайта», «перестроить эту страницу», «точное клонирование». Укажите целевой URL-адрес в качестве аргумента.
