Выполняйте реверс-инжиниринг и клонирование веб-сайта за один раз — извлекайте ресурсы, CSS и контент по разделам и активно распределяйте агенты параллельного построения в рабочих деревьях по мере их выполнения. Используйте это всякий раз, когда пользователь хочет клонировать, реплицировать, перестраивать, реконструировать или копировать любой веб-сайт. Также срабатывает на такие фразы, как «сделать копию этого сайта», «перестроить эту страницу», «точное клонирование». Укажите целевой URL-адрес в качестве аргумента.
