Cree páginas de actividades color por número a partir de un tema, un conjunto de colores opcional y una imagen de referencia opcional. Para cada página se genera una versión a todo color y una versión en blanco y negro correspondiente con regiones numeradas listas para colorear. Úselo cuando el usuario desee hojas de trabajo para colorear por números, libros de actividades o páginas para colorear numeradas temáticas.
