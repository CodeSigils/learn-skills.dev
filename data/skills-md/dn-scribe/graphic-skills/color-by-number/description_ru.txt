Создавайте страницы занятий с раскрашиванием по номерам на основе темы, дополнительного набора цветов и дополнительного эталонного изображения. Для каждой страницы создается полноцветная версия и соответствующая черно-белая версия с пронумерованными областями, готовыми к раскраске. Используйте, когда пользователю нужны листы с раскрашиванием по номерам, тетради или тематические пронумерованные раскраски.
