استخدم سطر الأوامر "المهمة الرئيسية" لإدارة المهام في مشاريع البرامج - إنشاء المهام والمهام الفرعية وإدراجها وتحديثها وتوسيعها وتتبعها من سطر الأوامر. قم بتشغيل هذه المهارة عندما يريد المستخدم إدارة المهام عبر "المهمة الرئيسية"، أو يسأل عن كيفية إنشاء/تحديث/قائمة/توسيع/تحديد أولويات المهام أو المهام الفرعية، أو تتبع التقدم، أو إدارة التبعيات، أو تحليل التعقيد، أو تهيئة مشروع جديد باستخدام Task Master، أو تشغيل سير عمل الطيار الآلي TDD (دورة RED → GREEN → COMMIT). يتم التشغيل أيضًا عندما يذكر المستخدم Taskmaster، أو TaskMaster، أو TM، أو parse-prd، أو tm autopilot، أو يريد أتمتة إدارة المهام المستندة إلى الذكاء الاصطناعي.
