Используйте интерфейс командной строки Task-Master для управления задачами в программных проектах — создания, перечисления, обновления, расширения и отслеживания задач и подзадач из командной строки. Активируйте этот навык всякий раз, когда пользователь хочет управлять задачами через Task-master, спрашивает, как создавать/обновлять/перечислять/расширять/приоритизировать задачи или подзадачи, отслеживать прогресс, управлять зависимостями, анализировать сложность, инициализировать новый проект с помощью Task Master или запускать рабочий процесс автопилота TDD (цикл КРАСНЫЙ → ЗЕЛЕНЫЙ → COMMIT). Также срабатывает, когда пользователь упоминает Task-master, TaskMaster, TM, parse-prd, tm autopilot или хочет автоматизировать управление задачами с помощью ИИ.
