Utilice la CLI `task-master` para gestionar tareas en proyectos de software: crear, enumerar, actualizar, ampliar y realizar un seguimiento de tareas y subtareas desde la línea de comandos. Active esta habilidad siempre que el usuario quiera administrar tareas a través de `task-master`, pregunte cómo crear/actualizar/enumerar/expandir/priorizar tareas o subtareas, realizar un seguimiento del progreso, administrar dependencias, analizar la complejidad, inicializar un nuevo proyecto con Task Master o ejecutar el flujo de trabajo del piloto automático TDD (ciclo ROJO → VERDE → COMMIT). También se activa cuando el usuario menciona task-master, TaskMaster, TM, parse-prd, tm autopilot o quiere automatizar la gestión de tareas impulsada por IA.
