Работайте с сервером Model Context Protocol (MCP) для интеграции помощника AI. Предоставляет функции GitLab как инструменты для ИИ-помощников (например, Claude Code) для взаимодействия с проектами, задачами, мерж-реквестами и конвейерами. Используйте при интеграции AI-помощников с GitLab или работе с серверами MCP. Триггеры по MCP, протоколу контекста модели, интеграции помощника искусственного интеллекта, обслуживанию glab mcp.
