Используйте быстрые действия GitLab — текстовые команды с косой чертой в комментариях, описаниях и телах MR/задач — через интерфейс командной строки glab. Быстрые действия выполняются автоматически при сохранении. В одном комментарии можно объединить несколько команд, что делает их эффективными для пакетной обработки изменений состояния за один вызов API. Запускается при быстрых действиях, командах с косой чертой, пакетном обновлении, /assign, /label, /merge, /approve, /close, /estimate.
