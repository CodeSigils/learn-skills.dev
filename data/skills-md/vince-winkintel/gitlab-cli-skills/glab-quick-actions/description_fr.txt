Utilisez les actions rapides de GitLab (commandes slash basées sur du texte dans les commentaires, les descriptions et les corps de MR/problème) via glab CLI. Les actions rapides s'exécutent automatiquement une fois enregistrées. Plusieurs commandes peuvent être combinées dans un seul commentaire, ce qui les rend puissantes pour regrouper les changements d'état dans un seul appel d'API. Déclencheurs sur des actions rapides, des commandes slash, des mises à jour par lots, /assign, /label, /merge, /approve, /close, /estimate.
