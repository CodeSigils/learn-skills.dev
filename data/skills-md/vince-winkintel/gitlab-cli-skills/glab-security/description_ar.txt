قم بتكوين ملفات تعريف الفحص الأمني ​​لمشروع GitLab باستخدام glab. يُستخدم عند تمكين أو تعطيل أو التحقق من ملفات تعريف فحص أمان GitLab مثل SAST أو فحص التبعية أو الكشف السري أو فحص الحاويات أو المعالجة التلقائية لمسح التبعية. المشغلات في تكوين أمان GitLab، وملف تعريف فحص الأمان، وتمكين SAST، وفحص التبعية، والكشف السري، وأمان glab.
