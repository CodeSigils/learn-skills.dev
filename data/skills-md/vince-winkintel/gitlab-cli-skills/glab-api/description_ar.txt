قم بإجراء مكالمات GitLab REST API المباشرة للاستعلامات والعمليات المتقدمة التي لا تغطيها أوامر glab الأخرى. يُستخدم عند الوصول إلى نقاط نهاية GitLab API مباشرة، أو تقديم طلبات API مخصصة، أو جلب البيانات بتنسيق JSON. مشغلات عند استدعاء واجهة برمجة التطبيقات (API)، وREST API، وGitLab API، واستعلام JSON، والاستعلام المتقدم.
