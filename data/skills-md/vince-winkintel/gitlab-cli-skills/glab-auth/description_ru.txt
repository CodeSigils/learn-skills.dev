Управляйте аутентификацией GitLab CLI, включая вход и выход из системы, проверку статуса аутентификации, переключение учетных записей и настройку доступа к реестру Docker. Используйте при первой настройке glab, устранении проблем с аутентификацией, переключении экземпляров/учетных записей GitLab или настройке Docker для извлечения данных из реестра GitLab. Запускает аутентификацию, вход в систему, выход из системы, аутентификацию, учетные данные, токен, реестр Docker.
