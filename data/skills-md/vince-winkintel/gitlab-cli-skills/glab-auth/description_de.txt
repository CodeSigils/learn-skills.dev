Verwalten Sie die GitLab-CLI-Authentifizierung, einschließlich Anmeldung/Abmeldung, überprüfen Sie den Authentifizierungsstatus, wechseln Sie Konten und konfigurieren Sie den Docker-Registrierungszugriff. Verwenden Sie diese Option, wenn Sie Glab zum ersten Mal einrichten, Authentifizierungsprobleme beheben, GitLab-Instanzen/-Konten wechseln oder Docker für den Abruf aus der GitLab-Registrierung konfigurieren. Wird bei Authentifizierung, Anmeldung, Abmeldung, Authentifizierung, Anmeldeinformationen, Token und Docker-Registrierung ausgelöst.
