Erstellen, Anzeigen, Aktualisieren und Verwalten von GitLab-Problemen. Verwenden Sie diese Option, wenn Sie mit der Problemverfolgung, Fehlerberichten, Funktionsanfragen oder der Aufgabenverwaltung arbeiten. Zu den Vorgängen gehören das Erstellen von Problemen, das Auflisten mit Filtern, das Anzeigen von Details, das Hinzufügen von Kommentaren/Notizen, das Aktualisieren von Beschriftungen/Beauftragten/Meilensteinen, das Schließen/Wiederöffnen und die Board-Verwaltung. Löst auf Problem, Fehler, Aufgabe, Ticket, Funktionsanfrage, Probleme auflisten, Problem erstellen aus.
