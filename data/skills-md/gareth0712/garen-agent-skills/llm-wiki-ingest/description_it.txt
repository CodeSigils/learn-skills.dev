Inserisci file sorgente non elaborati in un llm-wiki (wiki singolo o monorepo). Da utilizzare quando l'utente aggiunge file a raw/, dice "ingest this", "process this source", "aggiungi questo al wiki", "batch-process this directory" o chiede come gestire un nuovo formato sorgente. Gestisce triage, conversione del formato (PDF/MHTML/HTML/SRT/Notion), creazione di pagine, aggiornamenti di indici/log, controlli di qualità, confronti tra domini, consolidamento di newsletter e ristrutturazione monorepo.
