Аудит и оптимизация файлов инструкций CLAUDE.md. Запускается ТОЛЬКО явной командой /garen-memory-clean-up — НЕ запускается автоматически. Оценивает глобальные (~/.claude/CLAUDE.md), файлы проекта (.claude/CLAUDE.md) и локальные (CLAUDE.local.md) файлы области действия на соответствие рекомендациям из статьи «Файл CLAUDE.md, который в 10 раз увеличил мои выходные данные». Создает систему показателей аудита, обнаружение анти-шаблонов, отчет о дублировании в разных областях и список задач по оптимизации с предлагаемыми изменениями.
