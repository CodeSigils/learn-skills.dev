Verwenden Sie diese Option, wenn der Benutzer auf Japanisch schreibt, japanische Korrekturen anfordert, japanische Vokabeln oder Grammatik lernen möchte oder japanische Sprachthemen bespricht. Scannen Sie jeden japanischen Satz automatisch auf Fehler und korrigieren Sie ihn mit der Beschriftung „日語修正“. Lösen Sie diesen Skill immer dann aus, wenn IRGENDWELCHER japanischer Text in der Nachricht des Benutzers vorkommt – auch wenn das Hauptthema Programmierung, Infrastruktur oder etwas ganz anderes ist. Verwenden Sie es auch, wenn der Benutzer fragt „Wie sagt man X auf Japanisch“, „Ist das richtig“ oder 日語/日本語 erwähnt.
