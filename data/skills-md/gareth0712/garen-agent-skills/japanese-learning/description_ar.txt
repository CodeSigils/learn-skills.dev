يُستخدم عندما يكتب المستخدم باللغة اليابانية، أو يطلب تصحيحات باللغة اليابانية، أو يريد تعلم المفردات أو قواعد اللغة اليابانية، أو يناقش موضوعات اللغة اليابانية. قم بمسح كل جملة يابانية تلقائيًا بحثًا عن الأخطاء وقم بتوفير التصحيحات باستخدام تسميات 【日語修正】. قم بتفعيل هذه المهارة كلما ظهر أي نص ياباني في رسالة المستخدم - حتى لو كان الموضوع الرئيسي هو البرمجة أو البنية التحتية أو أي شيء آخر تمامًا. يُستخدم أيضًا عندما يسأل المستخدم "كيف تقول X باللغة اليابانية"، "هل هذا صحيح"، أو يذكر 日語/日本語.
