Comprobación periódica del estado de un llm-wiki (single-wiki o monorepo). Úselo cuando el usuario diga "limpiar el wiki", "verificar el estado del wiki", "encontrar contradicciones", "verificar huérfanos", "encontrar páginas obsoletas", "sugerir lagunas", "qué debo ingerir a continuación" o solicita una auditoría estructural/semántica. Produce un informe de pelusa con veredicto (APROBADO/ADVERTENCIA/FALLO), soluciona automáticamente problemas estructurales, señala problemas semánticos para revisión del usuario y agrega semillas de curiosidad a questions.md.
