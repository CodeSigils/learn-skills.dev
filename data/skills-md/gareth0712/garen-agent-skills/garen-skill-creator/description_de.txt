(Garen-Gabel) Erstellen Sie neue Fertigkeiten, ändern und verbessern Sie vorhandene Fertigkeiten und messen Sie die Fertigkeitsleistung. Verwenden Sie diese Funktion, wenn Benutzer eine Fertigkeit von Grund auf neu erstellen, eine vorhandene Fertigkeit bearbeiten oder optimieren, Evaluierungen durchführen möchten, um eine Fertigkeit zu testen, die Fertigkeitsleistung mit einer Varianzanalyse vergleichen oder die Beschreibung einer Fertigkeit für eine bessere Auslösegenauigkeit optimieren möchten.
