Организация многораундовых структурированных дебатов для оценки конкурирующих решений. Используйте, когда пользователь не уверен, какой подход лучше, спрашивает 該用 A 還是 B, хочет сравнить подходы, говорит «не уверен в архитектуре» или явно вызывает /garen-debate. Организатор опрашивает пользователя о сценарии, назначает N агентов защиты (3–6), каждый из которых отстаивает один подход, запускает динамические раунды защиты + контратаки + усиления до тех пор, пока не будет достигнут консенсус или не будет достигнуто отсутствие новых точек, затем синтезирует вердикт с полной таблицей компромиссов и последующими действиями. Обязательно используйте этот навык ВСЕГДА, когда пользователю приходится выбирать между несколькими нетривиальными техническими подходами, включая «должен ли я использовать X или Y», «оценить варианты», «решить между», «сравнить подходы», «не уверен в архитектуре».
