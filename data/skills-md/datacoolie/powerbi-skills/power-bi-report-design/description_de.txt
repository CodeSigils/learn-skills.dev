Entwerfen Sie Power BI-Berichtslayouts, wählen Sie Diagrammtypen aus, planen Sie Seitenstrukturen, wählen Sie Themen aus und wenden Sie Data Storytelling-Prinzipien an, BEVOR Sie PBIR-JSON-Dateien generieren. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Bericht entwerfen, ein Dashboard-Layout planen, Visualisierungen auswählen, sich für Diagrammtypen entscheiden, Storytelling auf Daten anwenden, ein Thema oder eine Farbpalette auswählen, die Seitennavigation planen oder Berichtsseiten für ein Power BI-Projekt strukturieren möchte. Verwenden Sie es auch, wenn der Benutzer vor der Generierung Anforderungen stellt und eine Spezifikation für das Berichtsdesign benötigt, oder wenn Sie das visuelle Design, das Layout oder die Benutzeroberfläche eines vorhandenen Berichts überprüfen/verbessern. Dieser Skill erstellt eine Designspezifikation – einen strukturierten Plan aus Seiten, Bildern, Layout, Thema und Navigation – der in den Skill „power-bi-pbip-report“ für die JSON-Generierung einfließt. NICHT zum Generieren von PBIR-JSON-Dateien, zum Validieren der Berichtsstruktur oder zum Erstellen des semantischen Modells verwenden. Verwenden Sie für die JSON-Generierung „power-bi-pbip-report“.
