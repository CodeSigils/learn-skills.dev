PBIR JSON ファイルを生成する前に、Power BI レポートのレイアウトを設計し、グラフの種類を選択し、ページ構造を計画し、テーマを選択し、データ ストーリーテリングの原則を適用します。ユーザーがレポートのデザイン、ダッシュボード レイアウトの計画、視覚エフェクトの選択、グラフの種類の決定、データへのストーリーテリングの適用、テーマやカラー パレットの選択、ページ ナビゲーションの計画、または Power BI プロジェクトのレポート ページの構造を要求するときは常に、このスキルを使用します。また、ユーザーが要件を提示し、生成前にレポートのデザイン仕様が必要な場合や、既存のレポートのビジュアル デザイン、レイアウト、UX を確認/改善する場合にも使用します。このスキルは、JSON 生成のための「power-bi-pbip-report」スキルにフィードされるデザインスペック (ページ、ビジュアル、レイアウト、テーマ、ナビゲーションの構造化された計画) を生成します。 PBIR JSON ファイルの生成、レポート構造の検証、またはセマンティック モデルの構築には使用しないでください。 JSON 生成には、「power-bi-pbip-report」を使用します。
