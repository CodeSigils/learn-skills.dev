在生成 PBIR JSON 文件之前，设计 Power BI 报告布局、选择图表类型、规划页面结构、选择主题并应用数据讲述原则。每当用户要求设计报表、规划仪表板布局、选择可视化、决定图表类型、将故事讲述到数据、选择主题或调色板、规划页面导航或构建 Power BI 项目的报表页面时，请使用此技能。当用户在生成之前提供需求并需要报告设计规范时，或者在审查/改进现有报告的视觉设计、布局或用户体验时，也可以使用。该技能会生成一个设计规范（页面、视觉效果、布局、主题和导航的结构化计划），并将其输入到“power-bi-pbip-report”技能中以生成 JSON。请勿用于生成 PBIR JSON 文件、验证报告结构或构建语义模型。对于 JSON 生成，请使用“power-bi-pbip-report”。
