قم بتصميم تخطيطات تقرير Power BI، وحدد أنواع المخططات، وتخطيط هياكل الصفحة، واختر السمات، وقم بتطبيق مبادئ سرد البيانات قبل إنشاء ملفات PBIR JSON. استخدم هذه المهارة عندما يطلب المستخدم تصميم تقرير، أو تخطيط تخطيط لوحة المعلومات، أو اختيار تصورات، أو تحديد أنواع المخططات، أو تطبيق سرد القصص على البيانات، أو تحديد سمة أو لوحة ألوان، أو التخطيط للتنقل في الصفحة، أو هيكلة صفحات التقرير لمشروع Power BI. يُستخدم أيضًا عندما يقدم المستخدم المتطلبات ويحتاج إلى مواصفات تصميم التقرير قبل الإنشاء، أو عند مراجعة/تحسين التصميم المرئي أو التخطيط أو تجربة المستخدم لتقرير موجود. تنتج هذه المهارة مواصفات التصميم - وهي خطة منظمة للصفحات والمرئيات والتخطيط والموضوع والتنقل - والتي تغذي مهارة "تقرير power-bi-pbip" لإنشاء JSON. لا تستخدم لإنشاء ملفات PBIR JSON، أو التحقق من صحة بنية التقرير، أو بناء النموذج الدلالي. لإنشاء JSON، استخدم تقرير power-bi-pbip.
