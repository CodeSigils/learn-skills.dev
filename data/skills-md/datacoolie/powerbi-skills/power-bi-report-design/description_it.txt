Progetta layout di report di Power BI, seleziona tipi di grafici, pianifica strutture di pagine, scegli temi e applica i principi di narrazione dei dati PRIMA di generare file PBIR JSON. Utilizzare questa competenza ogni volta che l'utente chiede di progettare un report, pianificare il layout di un dashboard, scegliere visualizzazioni, decidere i tipi di grafici, applicare la narrazione ai dati, selezionare un tema o una tavolozza di colori, pianificare la navigazione nelle pagine o strutturare le pagine del report per un progetto Power BI. Da utilizzare anche quando l'utente fornisce requisiti e necessita di specifiche di progettazione del report prima della generazione o durante la revisione/miglioramento della progettazione visiva, del layout o dell'UX di un report esistente. Questa competenza produce una specifica di progettazione, ovvero un piano strutturato di pagine, elementi visivi, layout, tema e navigazione, che alimenta la competenza "power-bi-pbip-report" per la generazione di JSON. NON utilizzare per generare file PBIR JSON, convalidare la struttura del report o creare il modello semantico. Per la generazione JSON, utilizzare "power-bi-pbip-report".
