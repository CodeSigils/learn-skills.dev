在產生 PBIR JSON 檔案之前，設計 Power BI 報告佈局、選擇圖表類型、規劃頁面結構、選擇主題並應用資料敘述原則。每當使用者要求設計報表、規劃儀表板佈局、選擇視覺化、決定圖表類型、將故事講述到資料、選擇主題或調色板、規劃頁面導航或建立 Power BI 專案的報表頁面時，請使用此技能。當使用者在生成之前提供需求並需要報告設計規格時，或在審查/改進現有報告的視覺設計、佈局或使用者體驗時，也可以使用。此技能會產生一個設計規格（頁面、視覺效果、佈局、主題和導航的結構化計劃），並將其輸入到「power-bi-pbip-report」技能中以產生 JSON。請勿用於產生 PBIR JSON 檔案、驗證報表結構或建立語意模型。對於 JSON 生成，請使用“power-bi-pbip-report”。
