Создавайте макеты отчетов Power BI, выбирайте типы диаграмм, планируйте структуры страниц, выбирайте темы и применяйте принципы повествования данных ПЕРЕД созданием файлов PBIR JSON. Используйте этот навык всякий раз, когда пользователь просит разработать отчет, спланировать макет информационной панели, выбрать визуализацию, определиться с типами диаграмм, применить повествование к данным, выбрать тему или цветовую палитру, спланировать навигацию по страницам или структурировать страницы отчета для проекта Power BI. Также используйте, когда пользователь предоставляет требования и нуждается в спецификации дизайна отчета перед созданием или при проверке/улучшении визуального дизайна, макета или пользовательского интерфейса существующего отчета. Этот навык создает спецификацию дизайна — структурированный план страниц, визуальных элементов, макета, темы и навигации — который используется в навыке power-bi-pbip-report для генерации JSON. НЕ используйте для создания файлов PBIR JSON, проверки структуры отчета или построения семантической модели. Для генерации JSON используйте power-bi-pbip-report.
