Diseñe diseños de informes de Power BI, seleccione tipos de gráficos, planifique estructuras de páginas, elija temas y aplique principios de narración de datos ANTES de generar archivos PBIR JSON. Utilice esta habilidad siempre que el usuario solicite diseñar un informe, planificar un diseño de panel, elegir visualizaciones, decidir tipos de gráficos, aplicar narración a los datos, seleccionar un tema o paleta de colores, planificar la navegación de páginas o estructurar páginas de informes para un proyecto de Power BI. Úselo también cuando el usuario proporcione requisitos y necesite una especificación de diseño de informe antes de su generación, o cuando revise/mejore el diseño visual, el diseño o la UX de un informe existente. Esta habilidad produce una especificación de diseño (un plan estructurado de páginas, imágenes, diseño, tema y navegación) que alimenta la habilidad "power-bi-pbip-report" para la generación de JSON. NO lo utilice para generar archivos PBIR JSON, validar la estructura del informe o crear el modelo semántico. Para la generación JSON, utilice `power-bi-pbip-report`.
