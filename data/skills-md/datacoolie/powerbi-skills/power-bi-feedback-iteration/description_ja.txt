Power BI プロジェクトのフィードバックと反復フェーズ用のリファレンス キット。分類分類、優先順位付けマトリックス、取り込みテンプレート、変更の影響範囲、変更後の検証チェックリスト、A/B バリアント テスト ワークフロー、正式な UAT ワークフロー、PBIP Git diff ガイド、変更ログ テンプレート、およびパフォーマンス クイック チェック ポインターを提供します。ユーザーが既存の Power BI レポートに関するフィードバックを提供する場合、反復を要求する場合、UAT を実行したい場合、または変更を文書化する必要がある場合には、このスキルを使用します。ルーティング (フィードバック → 正しいダウンストリーム スキル) は、このスキルではなく、パワーバイ開発エージェントによって所有されます。トリガーには、「ユーザー フィードバック」、「レポートの改善」、「レポートの修正」、「レポートの反復」、「レポートのレビュー」、「レポートの再構築」、「UAT」、「変更ログ」、「リリース ノート」、「ユーザーの苦情」、「パフォーマンスの問題」、「既存のレポートのページ/測定/ビジュアルの追加/削除/変更」が含まれます。このスキルはまったく新しいプロジェクトには使用しないでください (ゼロから始めるには power-bi-business-analysis を使用してください)。
