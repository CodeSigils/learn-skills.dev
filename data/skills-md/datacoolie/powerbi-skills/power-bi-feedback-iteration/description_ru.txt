Справочный комплект для обратной связи и этапа итерации проекта Power BI. Содержит классификационную таксономию, матрицу приоритетов, шаблон приема, область влияния изменений, контрольный список проверки после изменений, рабочий процесс тестирования вариантов A/B, формальный рабочий процесс UAT, руководство по различиям PBIP Git, шаблон журнала изменений и указатель для быстрой проверки производительности. Используйте этот навык всякий раз, когда пользователь оставляет отзыв о существующем отчете Power BI, запрашивает итерацию, хочет запустить UAT или ему необходимо документировать изменения. Маршрутизация (обратная связь → правильный нижестоящий навык) принадлежит агенту power-bi-разработчика, а не этому навыку. Триггеры включают в себя: «обратная связь с пользователем», «улучшить отчет», «исправить отчет», «переработать отчет», «проверка отчета», «перестроить отчет», «UAT», «журнал изменений», «примечания к выпуску», «пользователи жалуются», «проблема с производительностью», «добавить/удалить/изменить страницу/меру/визуальный элемент в существующем отчете». НЕ используйте этот навык для совершенно новых проектов (используйте мощный би-бизнес-анализ, чтобы начать с нуля).
