使用「powerbi-report-author」和「powerbi-desktop」 CLI 建立和修改 PBIR/PBIP 格式的 Power BI 報表檔案。當使用者想要執行下列操作時使用：(1) 實作核准的報表規格或設計簡介，(2) 新增或編輯頁面、視覺效果、篩選器、切片器、書籤、主題或格式，(3) 驗證 PBIR 並驗證 Power BI Desktop 中的呈現。對於開放式視覺設計，請先使用「power-bi-report-design」。對於端到端需求和審核工作流程，請先使用「powerbi-report-planning」。觸發器：「編輯 PBIR」、「建立 Power BI 報表頁面」、「為 PBIP 新增視覺物件」、「格式化報表視覺物件」、「驗證 Power BI 報表」、「重新載入桌面螢幕截圖」、「實作已核准的 PBIP 報表規格」、「編輯 PBIR 頁面/視覺物件」。
