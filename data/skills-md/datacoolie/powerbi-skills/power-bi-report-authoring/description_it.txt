Crea e modifica file di report di Power BI in formato PBIR/PBIP utilizzando le CLI "powerbi-report-author" e "powerbi-desktop". Utilizzare quando l'utente desidera: (1) implementare una specifica di report o una descrizione della progettazione approvata, (2) aggiungere o modificare pagine, oggetti visivi, filtri, filtri dei dati, segnalibri, temi o formattazione, (3) convalidare PBIR e verificare il rendering in Power BI Desktop. Per una progettazione visiva aperta, utilizzare prima `power-bi-report-design`. Per i requisiti end-to-end e il flusso di lavoro di approvazione, utilizzare prima "powerbi-report-planning". Trigger: "modifica PBIR", "crea pagina di report Power BI", "aggiungi oggetto visivo a PBIP", "formatta oggetto visivo report", "convalida report Power BI", "ricarica screenshot del desktop", "implementa una specifica di report PBIP approvata", "modifica pagine/oggetti visivi PBIR".
