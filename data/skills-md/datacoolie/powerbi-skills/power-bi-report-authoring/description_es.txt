Cree y modifique archivos de informes de Power BI en formato PBIR/PBIP mediante las CLI `powerbi-report-author` y `powerbi-desktop`. Úselo cuando el usuario desee: (1) implementar una especificación de informe aprobada o un resumen de diseño, (2) agregar o editar páginas, objetos visuales, filtros, segmentaciones, marcadores, temas o formato, (3) validar PBIR y verificar la representación en Power BI Desktop. Para un diseño visual abierto, utilice primero "power-bi-report-design". Para conocer los requisitos de un extremo a otro y el flujo de trabajo de aprobación, utilice primero "powerbi-report-planning". Activadores: "editar PBIR", "crear página de informe de Power BI", "agregar objeto visual a PBIP", "formatear objeto visual de informe", "validar informe de Power BI", "recargar captura de pantalla de Desktop", "implementar una especificación de informe PBIP aprobada", "editar páginas/objetos visuales de PBIR".
