使用“powerbi-report-author”和“powerbi-desktop” CLI 创建和修改 PBIR/PBIP 格式的 Power BI 报告文件。当用户想要执行以下操作时使用：(1) 实施批准的报表规范或设计简介，(2) 添加或编辑页面、视觉效果、筛选器、切片器、书签、主题或格式，(3) 验证 PBIR 并验证 Power BI Desktop 中的呈现。对于开放式视觉设计，请首先使用“power-bi-report-design”。对于端到端需求和审批工作流程，请首先使用“powerbi-report-planning”。触发器：“编辑 PBIR”、“创建 Power BI 报告页面”、“向 PBIP 添加视觉对象”、“格式化报告视觉对象”、“验证 Power BI 报告”、“重新加载桌面屏幕截图”、“实施已批准的 PBIP 报告规范”、“编辑 PBIR 页面/视觉对象”。
