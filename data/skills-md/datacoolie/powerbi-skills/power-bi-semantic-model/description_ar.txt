قم بتصميم وبناء نماذج دلالية Power BI باستخدام مبادئ المخطط النجمي وأدوات PowerBI Modeling MCP. استخدم هذه المهارة عندما يريد المستخدم إنشاء نموذج دلالي، أو إنشاء نموذج بيانات، أو تصميم مخطط نجمي، أو إضافة جداول أو أعمدة، أو إنشاء علاقات أو تعديلها، أو تكوين أوضاع التخزين (استيراد، أو DirectQuery، أو DirectLake، أو مركب)، أو تنفيذ RLS (أمان مستوى الصف)، أو تحسين أداء النموذج، أو استكشاف مصادر البيانات الموجودة للنمذجة. تتضمن المشغلات: "إنشاء نموذج دلالي"، "إنشاء نموذج بيانات"، "مخطط النجمة"، "إضافة جدول"، "إنشاء علاقة"، "وضع تخزين"، "DirectLake"، "نموذج مركب"، "RLS"، "تحسين النموذج"، "مراجعة النموذج"، "استكشاف البيانات"، "الاتصال بالطبقة الذهبية"، "توسيع النموذج"، "إضافة بُعد"، "إضافة جدول حقائق". لا تستخدم لإنشاء مقياس DAX (استخدم تطوير power-bi-dax) أو إنشاء التقارير (استخدم تقرير power-bi-pbip).
