Diseñe y cree modelos semánticos de Power BI utilizando principios de esquema en estrella y las herramientas MCP de modelado de PowerBI. Utilice esta habilidad siempre que el usuario desee crear un modelo semántico, crear un modelo de datos, diseñar un esquema en estrella, agregar tablas o columnas, crear o modificar relaciones, configurar modos de almacenamiento (Importar, DirectQuery, DirectLake, Compuesto), implementar RLS (seguridad de nivel de fila), optimizar el rendimiento del modelo o explorar fuentes de datos existentes para modelado. Los activadores incluyen: "crear modelo semántico", "crear modelo de datos", "esquema en estrella", "agregar tabla", "crear relación", "modo de almacenamiento", "DirectLake", "modelo compuesto", "RLS", "optimizar modelo", "revisión de modelo", "explorar datos", "conectarse a la capa dorada", "extender modelo", "agregar dimensión", "agregar tabla de hechos". NO lo use para la creación de medidas DAX (use power-bi-dax-development) o la generación de informes (use power-bi-pbip-report).
