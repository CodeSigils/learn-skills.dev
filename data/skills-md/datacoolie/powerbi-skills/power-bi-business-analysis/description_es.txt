Analizar los requisitos comerciales y definir la estrategia de BI para proyectos de Power BI. Utilice esta habilidad siempre que el usuario quiera analizar los requisitos empresariales, identificar KPI, definir qué información debe ofrecer un informe, proponer una estructura de panel para un dominio empresarial o recopilar requisitos antes de crear un informe o modelo semántico de Power BI. Los desencadenantes incluyen: "analizar los requisitos comerciales", "qué KPI debemos rastrear", "qué conocimientos podemos obtener", "análisis del dominio comercial", "recopilación de requisitos", "qué debemos medir", "qué problemas podemos resolver", "proponer un panel", "qué informes necesitamos", "estrategia de BI", "definir métricas". NO lo use para la creación de modelos reales (use power-bi-semantic-model), escritura DAX (use power-bi-dax-development) o generación de informes (use power-bi-pbip-report).
