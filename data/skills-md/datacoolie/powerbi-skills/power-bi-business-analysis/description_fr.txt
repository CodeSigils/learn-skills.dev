Analyser les besoins métier et définir la stratégie BI pour les projets Power BI. Utilisez cette compétence chaque fois que l'utilisateur souhaite analyser les exigences métier, identifier les KPI, définir les informations qu'un rapport doit fournir, proposer une structure de tableau de bord pour un domaine métier ou rassembler les exigences avant de créer un rapport Power BI ou un modèle sémantique. Les déclencheurs incluent : « analyser les exigences métier », « quels KPI devons-nous suivre », « quelles informations pouvons-nous obtenir », « analyse du domaine métier », « collecte des exigences », « que devons-nous mesurer », « quels problèmes pouvons-nous résoudre », « proposer un tableau de bord », « de quels rapports avons-nous besoin », « stratégie BI », « définir des métriques ». Ne PAS utiliser pour la création de modèles réels (utilisez le modèle power-bi-sémantique), l'écriture DAX (utilisez power-bi-dax-development) ou la génération de rapports (utilisez power-bi-pbip-report).
