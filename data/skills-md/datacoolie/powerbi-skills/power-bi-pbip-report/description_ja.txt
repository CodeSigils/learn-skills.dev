必要なすべての JSON ファイル (report.json、page.json、visual.json、pages.json など) を含む完全な .Report/ フォルダー構造を作成することにより、PBIP/PBIR 形式で Power BI レポートを生成します。デザインスペックの準備ができており、ユーザーが Power BI レポート用の実際の PBIR JSON ファイルの生成、スキャフォールディング、または構築を要求する場合は常に、このスキルを使用します。既存の PBIP レポートにページやビジュアルを追加する場合、またはデザインを PBIR フォルダー出力に変換する場合にも使用します。このスキルは JSON の生成と検証のみを処理し、設計上の決定は処理しません。レポートのデザイン (グラフの選択、レイアウト、テーマ、ストーリーテリング) には、最初に「power-bi-report-design」を使用します。
