أنشئ تقارير Power BI بتنسيق PBIP/PBIR عن طريق إنتاج بنية المجلد/التقرير الكاملة مع جميع ملفات JSON المطلوبة (report.json، وpage.json، وvisual.json، وpages.json، وما إلى ذلك). استخدم هذه المهارة عندما تكون مواصفات التصميم جاهزة ويطلب المستخدم إنشاء ملفات PBIR JSON الفعلية أو دعمها أو إنشاءها لتقرير Power BI. يُستخدم أيضًا عند إضافة صفحات أو عناصر مرئية إلى تقرير PBIP موجود، أو تحويل تصميم إلى مخرجات مجلد PBIR. تتعامل هذه المهارة مع إنشاء JSON والتحقق من صحته فقط، وليس قرارات التصميم. لتصميم التقرير (اختيار الرسم البياني، والتخطيط، والموضوع، وسرد القصص)، استخدم "power-bi-report-design" أولاً.
