Создавайте отчеты Power BI в формате PBIP/PBIR, создавая полную структуру папок .Report/ со всеми необходимыми файлами JSON (report.json, page.json, Visual.json,pages.json и т. д.). Используйте этот навык всякий раз, когда спецификация проекта готова, и пользователь просит сгенерировать, создать или построить фактические файлы JSON PBIR для отчета Power BI. Также используйте при добавлении страниц или визуальных элементов в существующий отчет PBIP или при преобразовании дизайна в выходные данные папки PBIR. Этот навык касается только генерации и проверки JSON, а не проектных решений. Для дизайна отчета (выбор диаграммы, макета, темы, повествования) сначала используйте power-bi-report-design.
