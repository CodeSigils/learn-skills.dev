透過產生包含所有必要 JSON 檔案（report.json、page.json、visual.json、pages.json 等）的完整 .Report/ 資料夾結構，產生 PBIP/PBIR 格式的 Power BI 報表。每當設計規格準備就緒且使用者要求為 Power BI 報表產生、建置或建置實際 PBIR JSON 檔案時，請使用此技能。也可在向現有 PBIP 報告新增頁面或視覺效果，或將設計轉換為 PBIR 資料夾輸出時使用。此技能僅處理 JSON 產生和驗證，而不處理設計決策。對於報告設計（圖表選擇、佈局、主題、說故事），請先使用「power-bi-report-design」。
