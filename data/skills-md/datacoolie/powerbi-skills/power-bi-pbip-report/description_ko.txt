필요한 모든 JSON 파일(report.json, page.json, Visual.json, Pages.json 등)을 사용하여 전체 .Report/ 폴더 구조를 생성하여 PBIP/PBIR 형식으로 Power BI 보고서를 생성합니다. 디자인 사양이 준비되고 사용자가 Power BI 보고서에 대한 실제 PBIR JSON 파일을 생성, 스캐폴드 또는 빌드하도록 요청할 때마다 이 기술을 사용하세요. 또한 기존 PBIP 보고서에 페이지나 시각 자료를 추가하거나 디자인을 PBIR 폴더 출력으로 변환할 때도 사용합니다. 이 기술은 JSON 생성 및 검증만 처리하며 디자인 결정은 처리하지 않습니다. 보고서 디자인(차트 선택, 레이아웃, 테마, 스토리텔링)을 위해서는 `power-bi-report-design`을 먼저 사용하세요.
