Genere informes de Power BI en formato PBIP/PBIR generando la estructura completa de carpetas .Report/ con todos los archivos JSON necesarios (report.json, page.json, visual.json, pages.json, etc.). Utilice esta habilidad siempre que una especificación de diseño esté lista y el usuario solicite generar, desarrollar o construir los archivos PBIR JSON reales para un informe de Power BI. Úselo también al agregar páginas o elementos visuales a un informe PBIP existente, o al convertir un diseño en una salida de carpeta PBIR. Esta habilidad maneja únicamente la generación y validación de JSON, no las decisiones de diseño. Para el diseño de informes (selección de gráficos, diseño, tema, narración), utilice primero "power-bi-report-design".
