Genera report Power BI in formato PBIP/PBIR producendo la struttura completa delle cartelle .Report/ con tutti i file JSON richiesti (report.json, page.json, visual.json, pagine.json e così via). Utilizza questa competenza ogni volta che una specifica di progettazione è pronta e l'utente chiede di generare, eseguire lo scaffolding o creare i file PBIR JSON effettivi per un report di Power BI. Da utilizzare anche quando si aggiungono pagine o elementi visivi a un report PBIP esistente o si converte un progetto nell'output di una cartella PBIR. Questa competenza gestisce solo la generazione e la convalida di JSON, non le decisioni di progettazione. Per la progettazione del report (selezione del grafico, layout, tema, narrazione), utilizzare prima "power-bi-report-design".
