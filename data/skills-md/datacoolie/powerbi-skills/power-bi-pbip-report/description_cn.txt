通过生成包含所有必需 JSON 文件（report.json、page.json、visual.json、pages.json 等）的完整 .Report/ 文件夹结构，生成 PBIP/PBIR 格式的 Power BI 报告。每当设计规范准备就绪并且用户要求为 Power BI 报告生成、搭建或构建实际 PBIR JSON 文件时，请使用此技能。也可在向现有 PBIP 报告添加页面或视觉效果，或将设计转换为 PBIR 文件夹输出时使用。该技能仅处理 JSON 生成和验证，而不处理设计决策。对于报告设计（图表选择、布局、主题、讲故事），请首先使用“power-bi-report-design”。
