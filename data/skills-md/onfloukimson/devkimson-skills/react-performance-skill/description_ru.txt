Проверяет и оптимизирует производительность рендеринга React посредством архитектурной диагностики повторного рендеринга, размещения состояний, эффектов, мемоизации, контекста, списков и разделения кода. Используйте при проверке производительности React, ненужных повторных рендерингах, решениях memo/useMemo/useCallback, больших списках, результатах React Profiler или задержке рендеринга.
