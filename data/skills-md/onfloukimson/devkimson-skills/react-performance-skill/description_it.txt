Esamina e ottimizza le prestazioni di rendering di React attraverso la diagnosi dell'architettura di nuovi rendering, posizionamento dello stato, effetti, memorizzazione, contesto, elenchi e suddivisione del codice. Da utilizzare durante la revisione delle prestazioni di React, nuovi rendering non necessari, decisioni memo/useMemo/useCallback, elenchi di grandi dimensioni, risultati di React Profiler o ritardo di rendering.
