React Flow (@xyflow/react) Implementierungshandbuch für die Node-Edge-Graph-Benutzeroberfläche. Wird für benutzerdefinierte Knoten/Kanten, Handles, kontrollierten Zustand, TypeScript, Unterflüsse/Gruppen, Layout, Zustandsintegration und die Anwendung der React Flow UI (shadcn) verwendet. Wird auf React Flow-, xyflow-, Flow Canvas- und Node-Editor-Aufgaben angewendet.
