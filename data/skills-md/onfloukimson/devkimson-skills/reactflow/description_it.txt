Guida all'implementazione dell'interfaccia utente del grafico del bordo del nodo React Flow (@xyflow/react). Utilizzato per nodi/bordi personalizzati, maniglie, stato controllato, TypeScript, flussi/gruppi secondari, layout, integrazione Zustand e applicazione dell'interfaccia utente di React Flow (shadcn). Applicato alle attività React Flow, xyflow, flow canvas e editor dei nodi.
