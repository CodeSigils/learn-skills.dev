Руководство по реализации пользовательского интерфейса графа узлов React Flow (@xyflow/react). Используется для пользовательских узлов/ребер, дескрипторов, контролируемого состояния, TypeScript, подпотоков/групп, макета, интеграции с Zustand и применения пользовательского интерфейса React Flow (shadcn). Применяется к задачам React Flow, xyflow, холста потока и редактора узлов.
