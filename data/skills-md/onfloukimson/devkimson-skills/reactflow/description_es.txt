Guía de implementación de la interfaz de usuario del gráfico de borde de nodo de React Flow (@xyflow/react). Se utiliza para nodos/bordes personalizados, identificadores, estado controlado, TypeScript, subflujos/grupos, diseño, integración de Zustand y aplicación de la interfaz de usuario de React Flow (shadcn). Se aplica a tareas de React Flow, xyflow, lienzo de flujo y editor de nodos.
