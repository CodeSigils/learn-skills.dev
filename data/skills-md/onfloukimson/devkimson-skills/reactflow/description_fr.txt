Guide de mise en œuvre de l'interface utilisateur du graphique nœud-bord de React Flow (@xyflow/react). Utilisé pour les nœuds/bords personnalisés, les poignées, l'état contrôlé, TypeScript, les sous-flux/groupes, la mise en page, l'intégration Zustand et l'application de l'interface utilisateur React Flow (shadcn). Appliqué aux tâches React Flow, xyflow, flow canevas et éditeur de nœuds.
