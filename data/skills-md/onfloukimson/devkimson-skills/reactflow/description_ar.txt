React Flow (@xyflow/react) دليل تنفيذ واجهة المستخدم للرسم البياني لحافة العقدة. يُستخدم للعقد/الحواف المخصصة، والمقابض، والحالة الخاضعة للتحكم، وTypeScript، والتدفقات الفرعية/المجموعات، والتخطيط، وتكامل Zustand، وتطبيق React Flow UI (shadcn). يتم تطبيقه على React Flow وxyflow وflow Canvas ومهام محرر العقدة.
