À utiliser lorsque vous travaillez avec @atscript/db, @atscript/db-{sqlite,postgres,mysql,mongo}, @atscript/db-sql-tools, @atscript/moost-db, @atscript/db-client ou des modèles .as avec des annotations @db.*. Couvre DbSpace, le câblage de l'adaptateur, le CRUD de table/vue, les filtres de requête, les opérations de patch/champ/tableau, les relations, les vues, la synchronisation de schéma, les capacités spécifiques au moteur, la sous-classe BaseDbAdapter, les routes REST moost-db, les actions déclaratives, la syntaxe de requête d'URL, le client de navigateur, client.action() et la validation de base de données. La portée est uniquement la base de données ; utilisez la compétence atscript pour la syntaxe .as, @meta.*, @expect.*, asc, unplugin ou VSCode.
