يُستخدم عند العمل مع @atscript/db، أو @atscript/db-{sqlite,postgres,mysql,mongo}، أو @atscript/db-sql-tools، أو @atscript/moost-db، أو @atscript/db-client، أو نماذج .as مع التعليقات التوضيحية @db.*. يغطي DbSpace، وأسلاك المحول، والجدول/العرض CRUD، ومرشحات الاستعلام، وعمليات التصحيح/الحقل/المصفوفة، والعلاقات، وطرق العرض، ومزامنة المخطط، والإمكانات الخاصة بالمحرك، والفئات الفرعية BaseDbAdapter، ومسارات moost-db REST، والإجراءات التعريفية، وبناء جملة استعلام URL، وعميل المتصفح، وclient.action()، والتحقق من صحة قاعدة البيانات. النطاق هو قاعدة البيانات فقط؛ استخدم مهارة النص البرمجي لصيغة .as، أو @meta.*، أو @expect.*، أو asc، أو unplugin، أو VSCode.
