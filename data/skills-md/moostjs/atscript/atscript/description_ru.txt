Используйте при работе с пакетами `@atscript/*` или файлами `.as`. `.as` = единый источник достоверных данных для типов, метаданных и ограничений проверки. Охватывает синтаксис `.as`, `@meta.*` / `@expect.*` / пользовательские аннотации, примитивы, `asc` CLI + `atscript.config.*`, сгенерированные `.as.d.ts` / `.as.js` / `atscript.d.ts`, помощники времени выполнения (`Validator`, JSON Schema, сериализация), `unplugin-atscript`, `@atscript/moost-validator`, VSCode LSP и разработка плагинов.
