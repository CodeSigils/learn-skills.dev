Da utilizzare quando si lavora con pacchetti `@atscript/*` o file `.as`. `.as` = unica fonte di verità per tipi, metadati e vincoli di convalida. Copre la sintassi `.as`, `@meta.*` / `@expect.*` / annotazioni personalizzate, primitive, la CLI `asc` + `atscript.config.*`, `.as.d.ts` / `.as.js` / `atscript.d.ts` generati, helper runtime (`Validator`, schema JSON, serialize), `unplugin-atscript`, `@atscript/moost-validator`, VSCode LSP e creazione di plug-in.
