À utiliser lorsque vous travaillez avec le framework Moost (moost, @moostjs/event-http/cli/wf/ws, @moostjs/swagger, @moostjs/otel, @moostjs/arbac, @moostjs/vite, create-moost) pour créer des applications TypeScript pilotées par un décorateur pour HTTP, CLI, WebSocket, des événements Workflow ou des adaptateurs personnalisés. Couvre les contrôleurs, les décorateurs de gestionnaires/paramètres/réponses, la DI, les intercepteurs, les tuyaux, les gardes d'authentification, les erreurs de structure, les décorateurs de métadonnées courants, les composables Wooks, la création d'adaptateurs, les applications rapides, les sorties de flux de travail/stratégies d'état, les salles/tests WebSocket, la journalisation et le contexte/portée des événements.
