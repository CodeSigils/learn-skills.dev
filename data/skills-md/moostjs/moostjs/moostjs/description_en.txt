Use when working with the Moost framework (moost, @moostjs/event-http/cli/wf/ws, @moostjs/swagger, @moostjs/otel, @moostjs/arbac, @moostjs/vite, create-moost) to build decorator-driven TypeScript apps for HTTP, CLI, WebSocket, Workflow events, or custom adapters. Covers controllers, handler/parameter/response decorators, DI, interceptors, pipes, auth guards, framework errors, common metadata decorators, Wooks composables, adapter authoring, quick apps, workflow outlets/state strategies, WebSocket rooms/testing, logging, and event context/scoping.
