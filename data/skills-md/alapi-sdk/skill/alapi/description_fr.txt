Assistant d'intégration d'interface ALAPI. Aide les développeurs à rechercher des interfaces ALAPI, à lire la documentation ALAPI, à extraire des paramètres, à générer du code d'intégration ALAPI et à appeler les interfaces ALAPI après que l'utilisateur a explicitement fourni un jeton et confirmé. Il est déclenché lorsque l'utilisateur mentionne « ALAPI », « alapi.cn », une URL de documentation ALAPI, un jeton ALAPI, un exemple d'interface ALAPI, ou souhaite intégrer une interface de plateforme ALAPI.
