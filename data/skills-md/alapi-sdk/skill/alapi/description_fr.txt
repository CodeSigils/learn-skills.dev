Assistant d'intégration d'interface ALAPI. Il aide les développeurs à rechercher les interfaces ALAPI, à lire la documentation ALAPI, à extraire les paramètres, à générer le code d'intégration ALAPI et à appeler l'interface ALAPI après que l'utilisateur a explicitement fourni un jeton et confirmé. Il se déclenche lorsque l'utilisateur mentionne « ALAPI », « alapi.cn », une URL de documentation ALAPI, un token ALAPI, un exemple d'interface ALAPI, ou souhaite intégrer l'interface de la plateforme ALAPI.
