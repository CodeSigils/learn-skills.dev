ALAPI interface integration assistant. It helps developers search ALAPI interfaces, read ALAPI documentation, extract parameters, generate ALAPI integration code, and call the ALAPI interface after the user explicitly provides a token and confirms. It is triggered when the user mentions "ALAPI", "alapi.cn", an ALAPI documentation URL, an ALAPI token, an ALAPI interface example, or wishes to integrate the ALAPI platform interface.
