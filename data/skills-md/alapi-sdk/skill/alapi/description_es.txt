Asistente de integración de interfaz ALAPI. Ayuda a los desarrolladores a buscar interfaces ALAPI, leer la documentación de ALAPI, extraer parámetros, generar código de integración ALAPI e invocar interfaces ALAPI después de que el usuario proporcione explícitamente un token y lo confirme. Se activa cuando el usuario menciona "ALAPI", "alapi.cn", una URL de documentación de ALAPI, un token de ALAPI, un ejemplo de interfaz de ALAPI o desea integrarse con la interfaz de la plataforma ALAPI.
