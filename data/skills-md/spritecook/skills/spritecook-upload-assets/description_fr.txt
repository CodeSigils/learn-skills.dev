Téléchargez des fichiers image locaux dans SpriteCook via MCP sans clés API ni journaux base64. À utiliser lorsque l'utilisateur fournit un chemin de fichier local qui doit devenir un actif SpriteCook pour les références de génération, les guides de style, les jeux de tuiles, l'animation, la suppression d'arrière-plan, les préréglages ou l'organisation des actifs.
