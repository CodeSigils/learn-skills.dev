Загрузите локальные файлы изображений в SpriteCook через MCP без ключей API или журналов base64. Используйте, когда пользователь предоставляет путь к локальному файлу, который должен стать ресурсом SpriteCook для ссылок на создание, руководств по стилю, наборов плиток, анимации, удаления фона, пресетов или организации ресурсов.
