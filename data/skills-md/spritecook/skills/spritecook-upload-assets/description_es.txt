Cargue archivos de imagen locales en SpriteCook a través de MCP sin claves API ni registros base64. Úselo cuando el usuario proporciona una ruta de archivo local que debería convertirse en un recurso de SpriteCook para referencias de generación, guías de estilo, conjuntos de mosaicos, animaciones, eliminación de fondo, ajustes preestablecidos u organización de activos.
