Carica file di immagine locali in SpriteCook tramite MCP senza chiavi API o log base64. Da utilizzare quando l'utente fornisce un percorso di file locale che dovrebbe diventare una risorsa SpriteCook per riferimenti di generazione, guide di stile, set di riquadri, animazioni, rimozione dello sfondo, preimpostazioni o organizzazione delle risorse.
