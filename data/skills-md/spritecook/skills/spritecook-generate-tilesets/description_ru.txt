Руководство по созданию набора тайлов для SpriteCook. Используйте со spritecook-workflow-essentials при создании наборов автоматических плиток через SpriteCook MCP/API, выборе размеров плиток, использовании идентификаторов ресурсов ссылки/редактирования/стиля и сохранении идентификаторов созданных ресурсов набора плиток.
