Guida alla generazione del Tileset per SpriteCook. Utilizzare con spritecook-workflow-essentials durante la generazione di set di riquadri automatici tramite SpriteCook MCP/API, scegliendo le dimensioni dei riquadri, utilizzando ID risorsa di riferimento/modifica/stile e salvando gli ID di risorsa del set di riquadri generati.
