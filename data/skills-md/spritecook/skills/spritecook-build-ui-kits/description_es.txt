Primer concepto de sistema de interfaz de usuario y guía de creación de kits para SpriteCook. Úselo con spritecook-workflow-essentials al crear una pantalla de interfaz de usuario completa, menú, HUD, diálogo, inventario, pantalla de configuración, superposición o sistema de interfaz de usuario cohesivo; generar o seleccionar un concepto antes de extraer componentes reutilizables; continuando desde un ID de activo conceptual existente de SpriteCook; o producir controles con nombre, estados y metadatos de 9 segmentos a través de las herramientas MCP del kit de interfaz de usuario SpriteCook. Prefiera esto a generate_game_art mode='ui' para pantallas o sistemas completos.
