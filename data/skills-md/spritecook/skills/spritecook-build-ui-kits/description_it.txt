Sistema di interfaccia utente concept first e guida alla creazione di kit per SpriteCook. Utilizzare con spritecook-workflow-essentials durante la creazione di una schermata dell'interfaccia utente di gioco completa, un menu, un HUD, una finestra di dialogo, un inventario, una schermata delle impostazioni, una sovrapposizione o un sistema di interfaccia utente coerente; generare o selezionare un concetto prima di estrarre componenti riutilizzabili; continuare da un ID risorsa concetto SpriteCook esistente; o produrre controlli con nome, stati e metadati a 9 sezioni tramite gli strumenti MCP del kit UI di SpriteCook. Preferisci questo a generate_game_art mode='ui' per schermate o sistemi completi.
