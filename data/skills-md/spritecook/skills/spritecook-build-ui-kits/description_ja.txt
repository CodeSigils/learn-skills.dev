SpriteCook のコンセプトファーストの UI システムとキット構築ガイド。完全なゲーム UI 画面、メニュー、HUD、ダイアログ、インベントリ、設定画面、オーバーレイ、または統合 UI システムを作成する場合は、spritecook-workflow-essentials とともに使用します。再利用可能なコンポーネントを抽出する前にコンセプトを生成または選択します。既存の SpriteCook コンセプトのアセット ID を継続します。または、SpriteCook UI-kit MCP ツールを使用して、名前付きコントロール、状態、9 スライス メタデータを生成します。完全な画面またはシステムの場合は、generate_game_art mode='ui' よりもこれを優先します。
