Encuentre errores lógicos en un solo archivo o función mediante un seguimiento de ejecución semiformal (Premisas → Seguimiento → Divergencia → Desencadenador → Remedio). Se activa cuando un usuario comparte código y sospecha que algo anda mal sin nombrar una falla concreta: frases como "revisar esto", "se ve bien", "verificar esta función", "auditar este código", "las pruebas pasan pero el producto falla". REGLA DIFÍCIL DE ALCANCE: un archivo o una sola función. Para un directorio o módulo completo, utilice logic-health; para una falla confirmada (rastreo de pila, prueba fallida, valor incorrecto específico), use la localización lógica; para dos versiones utilice logic-diff; para la reparación autónoma en todo el repositorio, utilice logic-fix-all. NO active para: estilo/formato, escaneo de seguridad, rendimiento, generación de pruebas, arquitectura o preguntas de diseño.
