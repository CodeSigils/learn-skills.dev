Finden Sie Logikfehler in einer einzelnen Datei oder Funktion mithilfe der semiformalen Ausführungsverfolgung (Voraussetzungen → Trace → Divergenz → Auslöser → Abhilfe). Wird ausgelöst, wenn ein Benutzer Code teilt und vermutet, dass etwas nicht stimmt, ohne einen konkreten Fehler zu nennen – Formulierungen wie „Überprüfen Sie dies“, „Sieht das richtig aus“, „Überprüfen Sie diese Funktion“, „Überprüfen Sie diesen Code“, „Tests bestehen, aber das Produkt schlägt fehl“. HARTE REGEL DES ANWENDUNGSBEREICHS: nur eine Datei oder nur eine Funktion. Für ein Verzeichnis oder ein ganzes Modul verwenden Sie „logic-health“. für einen bestätigten Fehler (Stack-Trace, fehlgeschlagener Test, bestimmter falscher Wert) verwenden Sie „logic-locate“; für zwei Versionen verwenden Sie Logic-Diff; Für repoweite autonome Reparaturen verwenden Sie Logic-Fix-All. NICHT auslösen für: Stil/Formatierung, Sicherheitsüberprüfung, Leistung, Testgenerierung, Architektur- oder Designfragen.
