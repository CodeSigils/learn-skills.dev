Trova bug logici in un singolo file o funzione tramite tracciamento dell'esecuzione semi-formale (Premesse → Traccia → Divergenza → Trigger → Rimedio). Si attiva quando un utente condivide il codice e sospetta che qualcosa non va senza menzionare un errore concreto: frasi come "rivedi questo", "sembra giusto", "controlla questa funzione", "controlla questo codice", "i test passano ma il prodotto fallisce". REGOLA DIFFUSA DELL'AMBITO: un solo file o una sola funzione. Per una directory o un intero modulo utilizzare Logic-Health; per un errore confermato (analisi dello stack, test non riuscito, valore errato specifico) utilizzare logica-localizzazione; per due versioni utilizzare logica-diff; per la correzione autonoma a livello di repository utilizzare Logic-Fix-All. NON attivare per: stile/formattazione, scansione di sicurezza, prestazioni, generazione di test, domande sull'architettura o sulla progettazione.
