Expliquez ce qu'un morceau de code spécifique fait réellement pour une entrée donnée en produisant une trace d'exécution étape par étape (interprocédurale, avec résolution de nom et transitions de type). Déclenchez lorsque l'utilisateur est confus quant au comportement ou demande pourquoi le code produit X au lieu de Y - "guidez-moi à travers cela", "tracez X avec l'entrée Y", "pourquoi cela renvoie X", "que fait rendement-from ici", "expliquez le chemin d'exécution". SCOPE HARD RULE : une fonction spécifique + un scénario de saisie spécifique. Si l'utilisateur souhaite rechercher des bogues sans scénario en tête, utilisez logic-review ; la comparaison à deux versions utilise la logique-diff ; les échecs concrets utilisent la localisation logique ; L'audit à l'échelle de la base de code utilise la santé logique. Ne déclenchez PAS pour : la recherche de bogues sans une question de comportement, une discussion sur le style ou la conception, ou des explications de concepts non liées à un code spécifique.
