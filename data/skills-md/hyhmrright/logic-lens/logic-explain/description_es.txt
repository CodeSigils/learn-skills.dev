Explique qué hace realmente un fragmento de código específico para una entrada determinada generando un seguimiento de ejecución paso a paso (interprocedimiento, con resolución de nombres y transiciones de tipos). Se activa cuando el usuario está confundido acerca del comportamiento o pregunta por qué el código produce X en lugar de Y: "guíame a través de esto", "rastrea X con la entrada Y", "por qué esto devuelve X", "qué hace aquí el rendimiento", "explica la ruta de ejecución". REGLA DURA DE ALCANCE: una función específica + un escenario de entrada específico. Si el usuario quiere encontrar errores sin un escenario en mente, utilice la revisión lógica; la comparación de dos versiones usa logic-diff; las fallas concretas utilizan la localización lógica; La auditoría de toda la base de código utiliza lógica-salud. NO active para: encontrar errores sin una pregunta de comportamiento, discusión de estilo o diseño, o explicaciones de conceptos no vinculadas a un código específico.
