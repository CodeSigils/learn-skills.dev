Spiegare cosa fa effettivamente una parte specifica di codice per un dato input producendo una traccia di esecuzione passo passo (interprocedurale, con risoluzione dei nomi e transizioni di tipo). Si attiva quando l'utente è confuso sul comportamento o chiede perché il codice produce X anziché Y: "guidami attraverso questo", "traccia X con l'input Y", "perché restituisce X", "cosa fa yield-from qui", "spiega il percorso di esecuzione". AMBITO REGOLA DIFFICILE: una funzione specifica + uno scenario di input specifico. Se l'utente vuole trovare bug senza uno scenario in mente, usa la revisione logica; il confronto tra due versioni utilizza la differenza logica; i fallimenti concreti utilizzano la logica di localizzazione; Il controllo a livello di codebase utilizza l'integrità logica. NON attivare per: ricerca di bug senza una domanda comportamentale, discussione sullo stile o sul design o spiegazioni di concetti non legate a un codice specifico.
