Durchsuchen Sie ein Verzeichnis, ein Modul oder eine vollständige Codebasis auf logische Richtigkeit und erstellen Sie ein bewertetes Integritäts-Dashboard mit systemischen Mustern. Wird ausgelöst, wenn der Benutzer eine Zustandsansicht anfordert – „Überprüfen Sie die gesamte Codebasis“, „Gesundheitsprüfung“, „Gesundheitsübersicht“, „Übersicht über den Logikzustand“, „Audit src/“, „Prüfung von Authentifizierungs- und Zahlungsmodulen“, „Wo soll ich mich auf Tests konzentrieren“, „Onboarding-Überprüfung“, „Logikübersicht vor der Auslieferung“, „Geben Sie mir einen Zustandsüberblick über dieses Modul“. ANWENDUNGSBEREICH: Bevorzugen Sie mehrere Dateien. wird auch für ein einzelnes Modul ausgelöst, wenn der Benutzer explizit „Health Check“, „Health Overview“ oder „Logic Health“ verwendet – ein konkreter Fehler verwendet Logic-Locate; zwei Versionen verwenden Logic-Diff; Zum Erklären eines Pfads wird die Logik-Erklärung verwendet. „Alles reparieren“ verwendet Logic-Fix-All. NICHT auslösen für: reine Stil-/Architekturprüfungen, reine Sicherheitsscans, reine Leistungsprüfungen.
