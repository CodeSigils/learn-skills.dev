Busque un directorio, módulo o código base completo para comprobar la corrección lógica y produzca un panel de control de estado puntuado con patrones sistémicos. Se activa cuando el usuario solicita una vista de estado: "auditar todo el código base", "verificación de estado", "descripción general de estado", "descripción general de estado lógico", "auditar src/", "auditar módulos de autenticación y pagos", "dónde debo centrar las pruebas", "revisión de incorporación", "descripción general de lógica antes de enviar", "darme una descripción general de estado de este módulo". REGLA DE ALCANCE: prefiera archivos múltiples; también se activa para un solo módulo cuando el usuario usa explícitamente "verificación de estado", "descripción general de estado" o "estado lógico"; una falla concreta usa localización lógica; dos versiones usan logic-diff; explicar un camino utiliza lógica-explicar; "arreglar todo" usa lógica-arreglar-todo. NO active para: auditorías solo de estilo/arquitectura, análisis solo de seguridad, auditorías solo de rendimiento.
