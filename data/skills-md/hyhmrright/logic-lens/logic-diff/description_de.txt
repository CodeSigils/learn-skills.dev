Vergleichen Sie zwei Codeversionen auf semantische Äquivalenz durch semiformales Tracing beider Versionen nebeneinander. Wird ausgelöst, wenn der Benutzer einen Refactor, ein Rewrite, eine Migration oder eine A/B-Implementierung teilt und bestätigen möchte, dass das Verhalten unverändert ist – „Habe ich etwas kaputt gemacht“, „ist das äquivalent“, „sind diese äquivalent“, „semantisch äquivalent“, „sind diese beiden Implementierungen semantisch äquivalent“, „überprüfe meinen Refactor“, „gleiches Verhalten nach der Änderung?“, „produziert mein Rewrite die gleiche Ausgabe“, „von X auf Y umgestellt – gleiche Ergebnisse?“. SCOPE HARD RULE: erfordert zwei Codeversionen (A und B). Eine einzelne Version zur Fehlersuche verwendet die Logiküberprüfung. eine Version + ein fehlgeschlagener Test verwendet Logic-Locate; Um zu erklären, was ein Teil des Codes tut, wird Logic-Explain verwendet. Codebase Audit verwendet Logic-Health. Lösen Sie NICHT aus für: Einzelversionsüberprüfung, Leistungsvergleich, Designqualitätsvergleich oder „Was ist besser geschrieben?“-Fragen.
