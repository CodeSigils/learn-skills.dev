Compare dos versiones de código para determinar la equivalencia semántica mediante un rastreo semiformal de ambas versiones una al lado de la otra. Se activa cuando el usuario comparte una implementación de refactorización, reescritura, migración o A/B y quiere confirmar que el comportamiento no ha cambiado: "¿rompí algo", "es esto equivalente", "son equivalentes", "semánticamente equivalentes", "son semánticamente equivalentes estas dos implementaciones", "verifique mi refactorización", "¿el mismo comportamiento después del cambio?", "¿mi reescritura produce el mismo resultado", "cambié de X a Y - ¿los mismos resultados?". REGLA DIFÍCIL DE ALCANCE: requiere dos versiones de código (A y B). Una versión única para la búsqueda de errores utiliza la revisión lógica; una versión + una prueba fallida usa localización lógica; explicar lo que hace un fragmento de código utiliza la explicación lógica; La auditoría de la base de código utiliza lógica-salud. NO active para: revisión de una sola versión, comparación de rendimiento, comparación de calidad de diseño o preguntas sobre "cuál está mejor escrito".
