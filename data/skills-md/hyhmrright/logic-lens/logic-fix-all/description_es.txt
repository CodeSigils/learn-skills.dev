Proceso autónomo de auditoría y reparación en todo el repositorio: salud → revisar → localizar/explicar → corregir → verificar diferencias → iterar hasta que esté limpio. Comienza con una solicitud de consentimiento obligatoria (con uso intensivo de tokens); después del consentimiento funciona con manos libres. Se activa cuando el usuario quiere que se encuentren y solucionen TODOS los problemas lógicos: "arreglar todo", "arreglar todos los problemas lógicos", "arreglar todos los problemas lógicos en este código", "limpiar todos los problemas lógicos", "auditar y arreglar todo el repositorio", "corregir todos los errores automáticamente" o frustración con errores recurrentes que desean un pase de una sola vez. REGLA DE ALCANCE: todo el repositorio de forma predeterminada; También activa un fragmento de código pegado cuando el usuario dice "arreglar todo": genera el informe de reparación completo (registro de reparación, antes/después de la puntuación lógica). Las solicitudes de solo análisis utilizan logic-health o logic-review. La falla única utiliza la localización lógica. Dos versiones utilizan logic-diff. Una explicación de ruta utiliza la explicación lógica. NO active para: solo análisis ("muéstreme los errores"), problemas de estilo/pelusa/formato o para corregir un solo hallazgo con nombre.
