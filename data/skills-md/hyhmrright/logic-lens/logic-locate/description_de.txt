Lokalisieren Sie die Grundursache eines BESTÄTIGTEN Fehlers mithilfe einer halbformalen Vorwärts- und Rückwärtsverfolgung. Wird ausgelöst, wenn der Benutzer einen Stack-Trace, eine fehlgeschlagene Behauptung, eine Fehlermeldung oder eine bestimmte Beobachtung mit einem falschen Wert bereitstellt – „den Fehler finden“, „dieser Test schlägt fehl“, „diesen Absturz aufspüren“, „warum schlägt dieser Test fehl“, „KeyError in Zeile 89“, „70 erwartet, 100 erhalten“, „NoneType hat kein Attribut X“, „Warenkorb wird geleert, wenn der zweite Tab geöffnet wird“. HARTE REGEL DES ANWENDUNGSBEREICHS: erfordert einen konkreten Fehler (Ausnahme, fehlgeschlagener Test oder bestimmte falsche Ausgabe). Ein vager Verdacht ohne Beweise erfordert eine logische Überprüfung; Verhaltenserklärung verwendet Logik-Erklärung; Refactor-Vergleich verwendet Logic-Diff; Codebase Audit verwendet Logic-Health. Lösen Sie NICHT aus: vage „Was ist los“ ohne konkretes Symptom, Stilfragen oder Leistungsprobleme.
