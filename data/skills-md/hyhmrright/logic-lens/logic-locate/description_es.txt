Localice la causa raíz de una falla CONFIRMADA mediante un rastreo semiformal hacia atrás y hacia adelante. Se activa cuando el usuario proporciona un seguimiento de la pila, una aserción fallida, un mensaje de error u una observación específica de un valor incorrecto: "encontrar el error", "esta prueba está fallando", "rastrear este bloqueo", "por qué falla esta prueba", "KeyError en la línea 89", "se esperaba 70, obtuve 100", "Ningunotipo no tiene atributo X", "el carrito se vacía cuando se abre la segunda pestaña". REGLA DURA DE ALCANCE: requiere una falla concreta (excepción, prueba fallida o salida incorrecta específica). La sospecha vaga sin evidencia utiliza la revisión lógica; la explicación del comportamiento utiliza la lógica-explica; la comparación de refactorización utiliza lógica-diff; La auditoría de la base de código utiliza lógica-salud. NO active la respuesta ante: "qué está mal" vago sin un síntoma concreto, preguntas de estilo o problemas de rendimiento.
