Führen Sie die Content-Eval-Pipeline von Logic-Lens für eine Iteration aus und erstellen Sie eine bewertete summary.json – verwenden Sie diese, um eine Fähigkeitsänderung zu messen. Umschließt scripts/run-content-evals.sh (Runner, kostet Token) und scripts/grade-iteration.py (Grader, kostenlos, erneut ausführbar). Synchronisieren Sie IMMER zuerst den Plugin-Cache. Verwenden Sie diese Option, wenn der Benutzer „die Auswertungen ausführen“, „diese Iteration bewerten“, „die Fähigkeitsänderung messen“, „vor dem vollständigen Durchlauf einen Rauchtest durchführen“ oder „vorhandene Ausgaben neu bewerten“ möchte.
