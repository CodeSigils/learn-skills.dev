منسق الصيانة للمكون الإضافي Brooks-lint نفسه. تشغيل مسار وكيل فرعي متسلسل - المؤلف → التقييم → ضمان الجودة → تدقيق المشغل → الإصدار - لإضافة مهارة أو تحريرها، وتحديث مجموعة التقييم، والاحتفاظ بالبيانات الأربعة + README + CHANGELOG + AGENTS/GEMINI متزامنة، ومراجعة حدود التشغيل، وقطع الإصدارات. يقود الوكلاء الخمسة في .claude/agents/ (مؤلف المهارات، أمين التقييم، الاتساق-QA، مشغل الحدود-المدقق، مدير الإصدار). المشغلات عندما يطلب المشرف العمل على Brooks-lint نفسها: "إضافة مهارة جديدة"، "تحرير دليل ديون Brooks"، "تحديث مجموعة التقييم"، "إصلاح أوصاف المشغلات"، "إجراء هذا التغيير والتحقق من صحته"، "تحرير Brooks-lint"، "توزيع ونشر"، والمتابعات: "إعادة التشغيل"، "إعادة التحقق من الصحة"، "تحديث تلك المهارة"، "إعادة التدقيق"، "إجراء الجزء X مرة أخرى". لا تقم بتشغيل ما يلي: استخدام مهارات تحليل Brooks-lint في بعض قواعد التعليمات البرمجية المستهدفة (مثل brooks-review / brooks-audit / brooks-debt / brooks-test / brooks-health / brooks-sweep)؛ الأسئلة العامة حول Brooks-lint التي لا تطلب تغييرها؛ أو صيانة مكون إضافي مختلف.
