brooks-lint プラグイン自体のメンテナンス オーケストレーター。シーケンシャルなサブエージェント パイプライン (作成者 → 評価 → QA → トリガー監査 → リリース) を実行して、スキルの追加または編集、評価スイートの更新、4 つのマニフェスト + README + CHANGELOG + AGENTS/GEMINI の同期の維持、トリガー境界の監査、リリースのカットを行います。 .claude/agents/ 内の 5 つのエージェント (skill-author、eval-curator、consistency-qa、trigger-boundary-auditor、release-manager) を駆動します。メンテナが brooks-lint 自体に対する作業を要求したときにトリガーされます: 「新しいスキルを追加する」、「brooks-debt ガイドを編集する」、「評価スイートを更新する」、「トリガーの説明を修正する」、「この変更を加えて検証する」、「brooks-lint をリリースする」、「バンプして公開する」、およびフォローアップ: 「再実行」、「再検証」、「スキルを更新」、「再実行」監査」、「X の部分をもう一度実行してください」。次の場合はトリガーしないでください: 一部のターゲット コードベースで brooks-lint 分析スキルを使用する (brooks-review / brooks-audit / brooks-debt / brooks-test / brooks-health / brooks-スイープ)。変更を求めるものではない、brooks-lint に関する一般的な質問。または別のプラグインのメンテナンス。
