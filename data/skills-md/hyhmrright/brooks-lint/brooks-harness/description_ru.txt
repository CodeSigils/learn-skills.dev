Оркестратор обслуживания самого плагина brooks-lint. Запускает последовательный конвейер субагента — автор → оценка → контроль качества → триггер-аудит → выпуск — для добавления или редактирования навыка, обновления пакета оценки, синхронизации четырех манифестов + README + CHANGELOG + AGENTS/GEMINI, проверки границ триггеров и сокращения выпусков. Управляет пятью агентами в .claude/agents/ (автор навыков, куратор оценки, согласованность-QA, триггер-границы-аудитор, менеджер релизов). Срабатывает, когда сопровождающий запрашивает работу над самим Brooks-Lint: «добавить новый навык», «отредактировать руководство по Brooks-Debt», «обновить пакет оценки», «исправить описания триггеров», «внести это изменение и подтвердить его», «выпустить Brooks-Lint», «поднять и опубликовать» и последующие действия: «перезапустить», «повторно проверить», «обновить этот навык», «переделать аудит», «сделать X-часть еще раз». НЕ срабатывает для: ИСПОЛЬЗОВАНИЯ навыков анализа Brooks-Lint в какой-либо целевой базе кода (это Brooks-Review / Brooks-audit / Brooks-Debt / Brooks-Test / Brooks-Health / Brooks-Sweep); общие вопросы о Brooks-Lint, которые не просят изменить его; или поддержка другого плагина.
