Orquestador de mantenimiento para el propio complemento brooks-lint. Ejecuta una canalización de subagente secuencial (autor → evaluación → control de calidad → auditoría de activación → lanzamiento) para agregar o editar una habilidad, actualizar el conjunto de evaluación, mantener sincronizados los cuatro manifiestos + README + CHANGELOG + AGENTES/GEMINI, auditar los límites de los activadores y cortar las versiones. Impulsa los cinco agentes en .claude/agents/ (skill-author, eval-curator, consistente-qa, trigger-boundary-auditor, release-manager). Se activa cuando el mantenedor solicita trabajar EN brooks-lint: "agregar una nueva habilidad", "editar la guía de deuda de brooks", "actualizar la suite de evaluación", "corregir las descripciones de los activadores", "realizar este cambio y validarlo", "liberar brooks-lint", "realzar y publicar" y seguimientos: "volver a ejecutar", "revalidar", "actualizar esa habilidad", "rehacer la auditoría", "hacer la parte X nuevamente". NO active para: UTILIZAR las habilidades de análisis de brooks-lint en alguna base de código de destino (es decir, brooks-review / brooks-audit / brooks-debt / brooks-test / brooks-health / brooks-sweep); preguntas genéricas sobre brooks-lint que no solicitan cambiarlo; o mantenimiento de un complemento diferente.
