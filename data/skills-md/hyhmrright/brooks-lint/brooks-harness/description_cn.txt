brooks-lint 插件本身的维护协调器。运行顺序子代理管道 - 作者 → 评估 → QA → 触发审核 → 发布 - 以添加或编辑技能、刷新评估套件、保持四个清单 + README + CHANGELOG + AGENTS/GEMINI 同步、审核触发器边界并削减版本。驱动 .claude/agents/ 中的五个代理（技能作者、评估策展人、一致性质量保证、触发边界审核员、发布经理）。当维护者要求在 brooks-lint 本身上工作时触发：“添加新技能”、“编辑 brooks-debt 指南”、“更新评估套件”、“修复触发器描述”、“进行此更改并验证它”、“发布 brooks-lint”、“发布并发布”以及后续操作：“重新运行”、“重新验证”、“更新该技能”、“重做审核”、“执行 X”再次分开”。不要触发： 在某些目标代码库上使用 brooks-lint 分析技能（即 brooks-review / brooks-audit / brooks-debt / brooks-test / brooks-health / brooks-sweep）；关于 brooks-lint 的一般问题，不要求更改它；或维护不同的插件。
