Orchestrateur de maintenance pour le plugin brooks-lint lui-même. Exécute un pipeline de sous-agents séquentiels — auteur → évaluation → QA → déclencheur-audit → version — pour ajouter ou modifier une compétence, actualiser la suite d'évaluation, conserver les quatre manifestes + README + CHANGELOG + AGENTS/GEMINI synchronisés, auditer les limites des déclencheurs et supprimer les versions. Pilote les cinq agents dans .claude/agents/ (skill-author, eval-curator, consistent-qa, trigger-boundary-auditor, release-manager). Se déclenche lorsque le responsable demande de travailler sur brooks-lint lui-même : "ajouter une nouvelle compétence", "modifier le guide brooks-debt", "mettre à jour la suite d'évaluation", "corriger les descriptions des déclencheurs", "effectuer cette modification et la valider", "libérer brooks-lint", "bogner et publier", et suivis : "réexécuter", "revalider", "mettre à jour cette compétence", "refaire l'audit", "refaire la partie X". Ne déclenchez PAS pour : UTILISER les compétences d'analyse brooks-lint sur une base de code cible (c'est-à-dire brooks-review / brooks-audit / brooks-debt / brooks-test / brooks-health / brooks-sweep) ; des questions génériques sur Brooks-Lint qui ne demandent pas de le changer ; ou maintenance d'un autre plugin.
