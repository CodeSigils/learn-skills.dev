قم بدعم مهارة تحليل Brooks-lint الجديدة بحيث تجتاز `npm run validate` و`npm run Evals` في المحاولة الأولى - وتولد المهارات/{name}/SKILL.md (مع جملة "لا تقم بالتشغيل لـ:" الإلزامية وقسم العملية الذي يستشهد بنطاقات خطوات الدليل) بالإضافة إلى المهارات/{name}/{name}-guide.md (خطوات مرقمة بالتسلسل)، ثم تلحق سيناريوهات التقييم المقترنة. يتم تشغيله عندما يطلب المشرف "إضافة مهارة جديدة"، أو "دعم مهارة"، أو "إنشاء وضع Brooks-lint". لا تقم بتشغيل ما يلي: تحرير محتوى مهارة موجودة، أو إضافة تقييم واحد لمهارة موجودة، أو مهارات التأليف لبعض المكونات الإضافية الأخرى.
