Cree una nueva habilidad de análisis de brooks-lint para que pase `npm run validar` y `npm run evals` en el primer intento: genera habilidades/{nombre}/SKILL.md (con la cláusula obligatoria "NO activar para:" y una sección de Proceso que cita los rangos de pasos de la guía) más habilidades/{nombre}/{nombre}-guide.md (pasos numerados secuencialmente), luego agrega escenarios de evaluación emparejados. Se activa cuando el mantenedor solicita "agregar una nueva habilidad", "desarrollar una habilidad" o "crear un modo Brooks-lint". NO active para: editar el contenido de una habilidad existente, agregar una única evaluación a una habilidad existente o crear habilidades para algún otro complemento.
