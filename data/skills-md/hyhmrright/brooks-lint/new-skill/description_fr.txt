Élaborez une nouvelle compétence d'analyse brooks-lint afin qu'elle réussisse `npm run validate` et `npm run evals` du premier coup — génère skills/{name}/SKILL.md (avec la clause obligatoire "Ne PAS déclencher pour :" et une section Processus citant les plages d'étapes du guide) plus skills/{name}/{name}-guide.md (étapes numérotées séquentiellement), puis ajoute des scénarios d'évaluation appariés. Se déclenche lorsque le responsable demande « d'ajouter une nouvelle compétence », « d'échafauder une compétence » ou de « créer un mode Brooks-Lint ». Ne déclenchez PAS pour : la modification du contenu d'une compétence existante, l'ajout d'une seule évaluation à une compétence existante ou la création de compétences pour un autre plugin.
