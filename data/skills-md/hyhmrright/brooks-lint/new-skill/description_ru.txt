Формируйте новый навык анализа brooks-lint, чтобы он проходил `npm run validate` и `npm run evals` с первой попытки — генерирует навыки/{name}/SKILL.md (с обязательным условием "Do NOT Trigger for:" и разделом процесса, в котором указаны диапазоны шагов руководства) плюс навыки/{name}/{name}-guide.md (последовательно пронумерованные шаги), а затем добавляет парные сценарии оценки. Срабатывает, когда сопровождающий просит «добавить новый навык», «закрепить навык» или «создать режим Brooks-Lint». НЕ активируйте: редактирование содержимого существующего навыка, добавление одной оценки к существующему навыку или создание навыков для какого-либо другого плагина.
