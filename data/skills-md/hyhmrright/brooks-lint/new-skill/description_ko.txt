새로운 brooks-lint 분석 기술을 스캐폴드하여 첫 번째 시도에서 `npm run verify` 및 `npm run evals`를 통과합니다. Skill/{name}/SKILL.md(필수 "Do NOT Trigger for:" 절 및 가이드 단계 범위를 인용하는 프로세스 섹션 포함)와 Skill/{name}/{name}-guide.md(순차 번호가 매겨진 단계)를 생성한 다음 쌍을 이루는 평가 시나리오를 추가합니다. 관리자가 "새 기술 추가", "기술 발판" 또는 "브룩스-린트 모드 생성"을 요청할 때 트리거됩니다. 트리거하지 마십시오: 기존 스킬의 콘텐츠 편집, 기존 스킬에 단일 평가 추가 또는 다른 플러그인에 대한 스킬 작성.
