新しい brooks-lint 分析スキルを足場にして、最初の試行で「npm run validate」と「npm run evals」に合格するようにします。skills/{name}/SKILL.md (必須の「Do NOT Trigger for:」句と、ガイド ステップ範囲を引用する Process セクションを含む) と skill/{name}/{name}-guide.md (連番のステップ) を生成し、ペアの評価シナリオを追加します。メンテナが「新しいスキルの追加」、「スキルの足場」、または「brooks-lint モードの作成」を要求したときにトリガーされます。既存のスキルのコンテンツの編集、既存のスキルに単一の評価を追加、または他のプラグインのスキルを作成する場合はトリガーしないでください。
