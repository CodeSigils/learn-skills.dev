وضع المسح الكامل: يقوم بإجراء تحليل موحد عبر جميع أبعاد الجودة - تسوس التعليمات البرمجية، والهندسة المعمارية، والديون التقنية، وجودة الاختبار - ثم يطبق الإصلاحات مباشرة على قاعدة التعليمات البرمجية. يتم تطبيق التغييرات الآمنة تلقائيًا؛ يتم تأكيد التغييرات المحفوفة بالمخاطر قبل التنفيذ. بالاعتماد على اثني عشر كتابًا هندسيًا كلاسيكيًا. يتم التشغيل عندما يريد المستخدم "إصلاح كل شيء"، أو "مسح قاعدة التعليمات البرمجية"، أو "الإصلاح التلقائي لجميع المشكلات"، أو "تشغيل جميع عمليات التحقق وإصلاحها"، أو "تنظيف المشروع بأكمله"، أو يطلب أمرًا واحدًا لتشخيص مشكلات الجودة وعلاجها. لا تقم بتشغيل ما يلي: عمليات التدقيق للقراءة فقط أو التقارير الصحية حيث يريد المستخدم فقط النتائج دون تغييرات في التعليمات البرمجية؛ المراجعات أحادية البعد (استخدم المهارة المركزة بدلاً من ذلك: brooks-review / brooks-audit / brooks-debt / brooks-test)؛ فحوصات صحة الخادم، أو نقاط نهاية HTTP / الصحية، أو تحقيقات Kubernetes، أو وقت تشغيل التطبيق.
