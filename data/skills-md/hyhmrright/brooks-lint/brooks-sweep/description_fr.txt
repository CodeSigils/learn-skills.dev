Mode balayage complet : exécute une analyse unifiée sur toutes les dimensions de la qualité : dégradation du code, architecture, dette technologique et qualité des tests, puis applique les correctifs directement à la base de code. Les modifications sécurisées sont appliquées automatiquement ; les changements risqués sont confirmés avant l’exécution. S'appuyant sur douze livres d'ingénierie classiques. Se déclenche lorsque : l'utilisateur souhaite "tout réparer", "parcourir la base de code", "réparer automatiquement tous les problèmes", "exécuter toutes les vérifications et les corriger", "nettoyer l'ensemble du projet" ou demande une seule commande qui diagnostique et corrige les problèmes de qualité. Ne déclenchez PAS les éléments suivants : audits en lecture seule ou rapports d'intégrité pour lesquels l'utilisateur souhaite uniquement des résultats sans modification du code ; examens monodimensionnels (utilisez plutôt la compétence ciblée : brooks-review / brooks-audit / brooks-debt / brooks-test) ; vérifications de l'état du serveur, points de terminaison HTTP/health, sondes Kubernetes ou disponibilité des applications.
