Tableau de bord combiné de l'état de la base de code qui évalue un projet sur les quatre dimensions de qualité : qualité des relations publiques, architecture, dette technologique et qualité des tests, en un seul passage, en s'appuyant sur douze livres d'ingénierie classiques. Se déclenche lorsque : l'utilisateur souhaite une évaluation globale de la qualité, demande "dans quelle mesure cette base de code est-elle saine ?", "exécute toutes les vérifications", "donne-moi un rapport global sur la qualité", "J'ai besoin d'un score de santé avant la publication", "quel est l'état général de notre code ?", ou souhaite intégrer une nouvelle équipe avec un aperçu de la qualité. Ne déclenchez PAS pour : les vérifications de l'état du serveur, les points de terminaison de l'état HTTP, les sondes d'activité/préparation de Kubernetes, l'état de la base de données ou la disponibilité de l'application. Ne déclenchez pas non plus lorsque l'utilisateur demande spécifiquement une seule dimension - utilisez plutôt la compétence ciblée correspondante (brooks-review / brooks-audit / brooks-debt / brooks-test).
