brooks-lint リリースをカットします。package.json でバージョンを設定し、4 つのプラグイン マニフェストすべてと README バッジにそれを伝播し、CHANGELOG エントリを書き込み、検証してから、GitHub リリースをコミット、プッシュ、タグ付けして公開します。メンテナが brooks-lint を「リリース」、「リリースのカット」、「新しいバージョンの出荷」、または「バンプして公開」するように要求したときにトリガーされます。次の場合はトリガーしないでください: リリースせずに既に決定されたバージョンを伝播する (「npm run dump」を直接使用する)、CHANGELOG 編集のみ、または実行を要求しないリリース プロセスに関する質問。
