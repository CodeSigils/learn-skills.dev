Schneiden Sie ein Brooks-Lint-Release: Legen Sie die Version in package.json fest, verbreiten Sie sie über alle vier Plugin-Manifeste + README-Badge, schreiben Sie den CHANGELOG-Eintrag, validieren Sie, schreiben Sie dann das GitHub-Release fest, pushen Sie es, taggen Sie es und veröffentlichen Sie es. Wird ausgelöst, wenn der Betreuer „Release“, „Cut a Release“, „Shipping a New Version“ oder „Bump and Publishing“ auffordert, Brooks-Lint. NICHT auslösen für: die Weitergabe einer bereits beschlossenen Version ohne Veröffentlichung (verwenden Sie „npm run Bump“ direkt), CHANGELOG-Änderungen allein oder Fragen zum Veröffentlichungsprozess, bei denen keine Durchführung erforderlich ist.
