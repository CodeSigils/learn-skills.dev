Coupez une version brooks-lint : définissez la version dans package.json, propagez-la dans les quatre manifestes du plugin + badge README, écrivez l'entrée CHANGELOG, validez, puis validez, poussez, marquez et publiez la version GitHub. Se déclenche lorsque le responsable demande de "libérer", "couper une version", "expédier une nouvelle version" ou "bogner et publier" brooks-lint. Ne déclenchez PAS pour : la propagation d'une version déjà décidée sans la publier (utilisez directement `npm run bump`), les modifications CHANGELOG seules ou les questions sur le processus de publication qui ne demandent pas de l'exécuter.
