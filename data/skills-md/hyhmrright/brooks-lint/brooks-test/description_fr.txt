Examen de la qualité des tests s'appuyant sur douze livres d'ingénierie classiques - avec un accent principal sur les modèles de test xUnit, l'art des tests unitaires, la manière dont Google teste les logiciels et le travail efficace avec le code hérité - qui diagnostique les problèmes structurels dans une suite de tests existante : fragilité, abus simulés, illusions de couverture, exécution lente, mauvaise lisibilité. Se déclenche lorsque : l'utilisateur pose des questions sur la qualité des tests, partage des fichiers de test pour examen ou exprime sa frustration : "les tests continuent de s'interrompre chaque fois que je change quelque chose", "nos tests prennent une éternité", "je ne comprends pas ce que fait ce test", "les tests réussissent mais les bugs atteignent toujours la production", "nous avons trop de simulations". Ne déclenchez PAS pour : l'écriture de nouveaux tests à partir de zéro (utilisez le flux de travail d'écriture de tests habituel) ou les questions de cadre de test/syntaxe : cette compétence examine une suite existante pour détecter les problèmes de qualité structurelle, et non la création de tests individuels.
