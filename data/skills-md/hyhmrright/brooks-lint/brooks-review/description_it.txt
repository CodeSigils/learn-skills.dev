Si attiva anche quando l'utente menziona: odori di codice / refactoring / architettura pulita / DDD / progettazione basata sul dominio / principi SOLID / Legge di Hyrum / moduli profondi / programmazione tattica / integrità concettuale / Legge di Brooks / Mitico mese dell'uomo / effetto del secondo sistema. NON attivare per: domande su come scrivere codice da zero, domande sulla sintassi del linguaggio o domande su framework/strumenti in cui non è condiviso alcun codice esistente.
