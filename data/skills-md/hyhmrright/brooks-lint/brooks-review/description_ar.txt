مراجعة كود العلاقات العامة التي توضح مخاطر تسوس الأسطح وروائح التصميم ومشاكل الصيانة مع الخرسانة الأعراض → المصدر → النتيجة → نتائج العلاج، بالاعتماد على اثني عشر كتابًا هندسيًا كلاسيكيًا. يتم تشغيله عندما: يطلب المستخدم مراجعة الكود، أو التحقق من العلاقات العامة، أو مشاركة رمز فرق أو لصقه ويسأل "هل يبدو هذا صحيحًا؟" / "هل هناك أي مشاكل هنا؟" / "هل أنت جاهز للدمج؟"، أو يطلب منك تقديم تعليقات حول وظيفة أو فئة أو ملف. يتم تشغيله أيضًا عندما يذكر المستخدم: روائح التعليمات البرمجية / إعادة البناء / الهندسة المعمارية النظيفة / DDD / التصميم المستند إلى المجال / مبادئ SOLID / قانون Hyrum / الوحدات العميقة / البرمجة التكتيكية / التكامل المفاهيمي / قانون بروكس / شهر الرجل الأسطوري / تأثير النظام الثاني. لا تقم بتشغيل: أسئلة حول كيفية كتابة التعليمات البرمجية من البداية، أو أسئلة بناء جملة اللغة، أو أسئلة إطار العمل/الأداة حيث لا تتم مشاركة أي تعليمات برمجية موجودة.
