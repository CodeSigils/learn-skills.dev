Architekturprüfung, die Modulabhängigkeiten abbildet, die Schichtintegrität überprüft und strukturellen Verfall in einer Codebasis kennzeichnet, basierend auf zwölf klassischen Ingenieurbüchern. Wird ausgelöst, wenn: der Benutzer darum bittet, die Architektur zu prüfen, die Ordner-/Modulstruktur zu überprüfen, auf zirkuläre Importe zu prüfen, zu verstehen, wie die Codebasis organisiert ist, oder fragt: „Entspricht dies einer sauberen Architektur?“, „Warum hängt alles von allem ab?“, „Sind unsere Ebenen korrekt?“, „Wo soll dieser Code leben?“. Auch Auslöser für Onboarding-Anfragen: „Erklären Sie einem neuen Entwickler diese Codebasis“ oder „Geben Sie mir eine Codebasis-Tour“ (Onboarding-Modus verwenden). Lösen Sie NICHT aus für: Codeüberprüfung auf PR-Ebene (verwenden Sie Brooks-Review) oder Refactoring-Fragen auf Zeilenebene – dieser Skill analysiert Bedenken auf Struktur-/Modulebene, nicht auf einzelne Funktionen.
