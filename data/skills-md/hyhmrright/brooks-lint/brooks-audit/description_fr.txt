Audit d'architecture qui cartographie les dépendances des modules, vérifie l'intégrité des couches et signale la dégradation structurelle dans une base de code, en s'appuyant sur douze livres d'ingénierie classiques. Se déclenche lorsque : l'utilisateur demande d'auditer l'architecture, de revoir la structure des dossiers/modules, de vérifier les importations circulaires, de comprendre comment la base de code est organisée, ou demande "cela suit-il une architecture propre ?", "pourquoi tout dépend de tout ?", "nos couches sont-elles correctes ?", "où ce code doit-il résider ?" Déclenche également les demandes d'intégration : "expliquez cette base de code à un nouveau développeur" ou "faites-moi visiter la base de code" (utilisez le mode d'intégration). Ne déclenchez PAS pour : la révision du code au niveau PR (utilisez brooks-review) ou les questions de refactorisation au niveau de la ligne – cette compétence analyse les problèmes structurels/au niveau du module, et non les fonctions individuelles.
