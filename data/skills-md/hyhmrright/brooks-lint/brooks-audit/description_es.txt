Auditoría de arquitectura que mapea las dependencias de los módulos, verifica la integridad de las capas y señala el deterioro estructural en una base de código, basándose en doce libros de ingeniería clásicos. Se activa cuando: el usuario solicita auditar la arquitectura, revisar la estructura de carpetas/módulos, comprobar si hay importaciones circulares, comprender cómo está organizada la base de código o pregunta "¿sigue esto una arquitectura limpia?", "¿por qué todo depende de todo?", "¿nuestras capas son correctas?", "¿dónde debería residir este código?". También activadores de solicitudes de incorporación: "explica este código base a un nuevo desarrollador" o "dame un recorrido por el código base" (usa el modo de incorporación). NO active para: revisión de código a nivel de relaciones públicas (use brooks-review) o preguntas de refactorización a nivel de línea: esta habilidad analiza inquietudes estructurales/a nivel de módulo, no funciones individuales.
