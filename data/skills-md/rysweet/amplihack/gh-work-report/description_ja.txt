すべての認証されたアカウントにわたる包括的な GitHub アクティビティ レポートを生成します。構成可能な期間 (1/5/7/30/90 日) のリポジトリ、PR、機能、およびテーマを収集します。表、マーメイドチャート、エグゼクティブサマリーを使用して共有可能なマークダウンを生成します。 GitHub Actions 自動化と GitHub Pages アグリゲーション サイトを使用してプライベート リポジトリを作成できます。 「github レポート」、「作業レポート」、「アクティビティの概要」、「何に取り組んだか」、「gh-work-report」、「私の github アクティビティを表示する」場合に使用します。
