Создает подробные отчеты о деятельности GitHub по всем аутентифицированным учетным записям. Собирает репозитории, PR, функции и темы для настраиваемых периодов времени (1/5/7/30/90 дней). Создает общую уценку с таблицами, диаграммами-русалками и краткими обзорами. Можно создать частное репозиторий с помощью автоматизации GitHub Actions и сайта агрегации GitHub Pages. Используйте, когда: «отчет github», «отчет о работе», «сводка активности», «над чем я работал», «gh-work-report», «показать мою активность на github».
