Orchestration de flotte pour les agents de codage distribués sur les machines virtuelles Azure.
Invoqué comme `/fleet <command>`. Couvre toutes les opérations de la flotte : statut, scout,
avancer, adopter, regarder, instantané, essai à sec, démarrer, ajouter une tâche, file d'attente, authentification,
tableau de bord, tui, et plus encore. À utiliser lorsque : l'utilisateur mentionne la flotte, les agents, les VM,
sessions, ou demande "que font mes agents".
