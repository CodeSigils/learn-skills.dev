Migration automatisée de Python vers Rust via des boucles de convergence itératives.
Traite la base de code Python comme la spécification vivante et produit un
Équivalent Rust entièrement testé avec validation de parité de tolérance zéro.
À utiliser lors de la migration de modules, de bibliothèques ou de CLI Python vers Rust.
S'active pour : migration, oxydation, python vers rouille, portage vers rouille, réécriture dans rouille.
