Автоматизированный переход с Python на Rust посредством итеративных циклов конвергенции.
Рассматривает кодовую базу Python как живую спецификацию и создает
полностью протестированный эквивалент Rust с проверкой четности с нулевым допуском.
Используйте при переносе модулей, библиотек или интерфейсов командной строки Python в Rust.
Активируется для: миграции, окисления, перевода Python в Rust, переноса в Rust, перезаписи в Rust.
