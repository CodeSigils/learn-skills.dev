الترحيل الآلي من Python إلى Rust عبر حلقات التقارب التكرارية.
يتعامل مع قاعدة تعليمات Python باعتبارها المواصفات الحية وينتج ملف
مكافئ الصدأ الذي تم اختباره بالكامل مع التحقق من تكافؤ عدم التسامح.
يُستخدم عند ترحيل وحدات Python أو المكتبات أو واجهات سطر الأوامر (CLI) إلى Rust.
يتم التنشيط من أجل: الهجرة، والأكسدة، والبايثون إلى الصدأ، والمنفذ إلى الصدأ، وإعادة الكتابة في الصدأ.
