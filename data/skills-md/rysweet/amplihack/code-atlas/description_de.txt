Erstellt umfassende, lebendige Code-Atlanten als abgeleitete mehrschichtige Architekturdokumente
Code-First-Wahrheit. Standardmäßig sind sowohl Graphviz DOT als auch Mermaid eingestellt. Der Benutzer kann das Einzelformat überschreiben.
Sprachunabhängig (Go, TypeScript, Python, .NET, Rust, Java). Dateiprobleme mit
Etikett „code-atlas-bughunt“. Behandelt die Atlaserstellung als eine Reise zur Fehlersuche mit mehreren Agenten:
Das Denken in Diagrammform deckt strukturelle Fehler, Routen-/DTO-Nichtübereinstimmungen und verwaiste Umgebungsvariablen auf.
tote Codepfade und veraltete Dokumentation, die bei der linearen Überprüfung übersehen wird. Insektenjagd in drei Durchgängen
mit PASS/FAIL/NEEDS_ATTENTION-Urteilen pro Fahrt.
Verwendung bei: Architekturdokumentation erstellen, unbekannte Codebasen untersuchen,
Suchen Sie nach strukturellen Fehlern, richten Sie die Aktualisierung von CI/CD-Diagrammen ein oder veröffentlichen Sie sie auf GitHub Pages/mkdocs.
