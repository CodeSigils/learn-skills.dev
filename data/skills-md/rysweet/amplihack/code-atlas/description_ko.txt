다음에서 파생된 다층 아키텍처 문서로 포괄적이고 살아있는 코드 아틀라스를 구축합니다.
코드 우선 진실. Graphviz DOT와 Mermaid가 모두 기본값입니다. 사용자는 단일 형식으로 재정의할 수 있습니다.
언어에 구애받지 않습니다(Go, TypeScript, Python, .NET, Rust, Java). 파일 문제
'code-atlas-bughunt' 라벨. 아틀라스 구축을 다중 에이전트 버그 사냥 여정으로 간주합니다.
그래프 형식 추론은 구조적 버그, 경로/DTO 불일치, 고아 환경 변수를 노출합니다.
데드 코드 경로, 선형 검토에서 놓친 오래된 문서 등이 있습니다. 3단계 버그 사냥
여정별 PASS/FAIL/NEEDS_ATTENTION 판정을 사용합니다.
사용 시기: 아키텍처 문서 작성, 익숙하지 않은 코드베이스 조사,
구조적 버그 찾기, CI/CD 다이어그램 새로 고침 설정 또는 GitHub 페이지/mkdocs에 게시.
