建構全面的、動態的程式碼圖集作為源自以下內容的多層架構文檔
代碼優先的真理。預設為 Graphviz DOT 和 Mermaid。使用者可以覆蓋為單一格式。
與語言無關（Go、TypeScript、Python、.NET、Rust、Java）。文件問題
“代碼圖集-bughunt”標籤。將圖集建構視為多智能體錯誤搜尋之旅：
圖形形式推理暴露了結構錯誤、路由/DTO 不符、孤立的環境變數、
線性審查會遺漏的死程式碼路徑和陳舊文件。三次錯誤搜尋
每趟旅程的 PASS/FAIL/NEEDS_ATTENTION 判決。
使用場合：建立架構文件、調查不熟悉的程式碼庫、
尋找結構錯誤、設定 CI/CD 圖表刷新或發佈到 GitHub Pages/mkdocs。
