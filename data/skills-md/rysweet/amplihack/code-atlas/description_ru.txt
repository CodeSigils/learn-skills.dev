Создает комплексные, живые атласы кода в виде многоуровневых архитектурных документов, полученных на основе
истина, основанная на коде. По умолчанию используется как Graphviz DOT, так и Mermaid. Пользователь может переопределить единый формат.
Независимость от языка (Go, TypeScript, Python, .NET, Rust, Java). Проблемы с файлами
Ярлык «code-atlas-bughunt». Рассматривает построение атласа как многоагентную операцию по поиску ошибок:
рассуждения в форме графа выявляют структурные ошибки, несоответствия маршрутов и DTO, потерянные переменные окружения,
пути к мертвому коду и устаревшая документация, которую пропускает линейная проверка. Поиск ошибок в три прохода
с вердиктами PASS/FAIL/NEEDS_ATTENTION для каждой поездки.
Используйте при: создании документации по архитектуре, исследовании незнакомых кодовых баз,
поиск структурных ошибок, настройка обновления диаграммы CI/CD или публикация на GitHub Pages/mkdocs.
