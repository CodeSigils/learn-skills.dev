Autenticación de flujo de dispositivo OAuth para la API CareMax Health. Esta habilidad es un PRERREQUISITO para todas las demás habilidades de caremax-*: invócala automáticamente cuando no se encuentre ningún token. NO le pregunte al usuario, simplemente ejecute el flujo de autenticación. Términos de activación: inicio de sesión de Caremax, autenticación de Caremax, token de API de salud, autorizar a Caremax, conectar datos de salud, indicador de salud, análisis de sangre, registro médico, carga de informe.
