Аутентификация потока устройства OAuth для API CareMax Health. Этот навык является ПРЕДВАРИТЕЛЬНЫМ ТРЕБОВАНИЕМ для всех других навыков caremax-* — он вызывается автоматически, когда токен не найден. НЕ спрашивайте пользователя, просто запустите процесс аутентификации. Триггерные условия: вход в систему Caremax, аутентификация Caremax, токен API здоровья, авторизация Caremax, подключение данных о состоянии здоровья, индикатор здоровья, анализ крови, медицинская карта, загрузка отчета.
