Autenticazione del flusso del dispositivo OAuth per l'API CareMax Health. Questa abilità è un PREREQUISITO per tutte le altre abilità caremax-*: invocala automaticamente quando non viene trovato alcun token. NON chiedere all'utente, esegui semplicemente il flusso di autenticazione. Termini di attivazione: login caremax, autenticazione caremax, token API sanitario, autorizzazione caremax, connessione dati sanitari, indicatore sanitario, esame del sangue, cartella clinica, caricamento report.
