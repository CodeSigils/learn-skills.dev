Cree ramas de Git siguiendo la especificación de rama convencional (feature/, bugfix/, hotfix/, release/, chore/, más prefijos de agentes de IA ai/, copilot/, cursor/, claude/, codex/). Úselo al crear una nueva sucursal, nombrar una sucursal o verificar si el nombre de una sucursal cumple con la especificación. Utilícelo también junto con commit-check para una validación automática.
