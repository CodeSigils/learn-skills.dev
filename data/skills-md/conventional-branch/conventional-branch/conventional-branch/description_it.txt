Crea rami Git seguendo la specifica del ramo convenzionale (feature/, bugfix/, hotfix/, release/, chore/, più i prefissi dell'agente AI ai/, copilot/, cursor/, claude/, codex/). Da utilizzare quando si crea un nuovo ramo, si assegna un nome a un ramo o si controlla se il nome di un ramo è conforme alle specifiche. Utilizzare anche insieme a commit-check per la convalida automatizzata.
