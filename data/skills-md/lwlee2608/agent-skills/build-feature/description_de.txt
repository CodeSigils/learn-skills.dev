Verwenden Sie diese Option, wenn Sie eine Funktionsplandatei implementieren, die in Phasen mit Aufgaben-Kontrollkästchen unterteilt ist. Erstellt eine Phase pro Zweig, öffnet einen PR für einen funktionsweiten Integrationszweig, überprüft ihn zweimal in einem Subagenten, repariert nur das, was es wert ist, repariert zu werden, und führt dann zusammen, bevor die nächste Phase gestartet wird. Nach der letzten Phase demonstriert es die gesamte Funktion so, wie der Benutzer es wünscht, und überlässt die endgültige Zusammenführung ihm.
