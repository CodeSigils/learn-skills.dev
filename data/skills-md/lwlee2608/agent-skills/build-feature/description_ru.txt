Используйте при реализации файла плана функций, разделенного на этапы с помощью флажков задач. Создает одну фазу для каждой ветки, открывает заявку на заявку на полнофункциональную интеграционную ветвь, дважды проверяет ее в субагенте, исправляет только то, что стоит исправить, затем объединяет перед началом следующей фазы. После последнего этапа он демонстрирует всю функцию так, как просит пользователь, и оставляет окончательное слияние на усмотрение пользователя.
