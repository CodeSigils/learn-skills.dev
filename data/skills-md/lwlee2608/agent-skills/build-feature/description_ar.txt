يُستخدم عند تنفيذ ملف خطة ميزات مقسم إلى مراحل باستخدام مربعات اختيار المهمة. يبني مرحلة واحدة لكل فرع، ويفتح PR مقابل فرع تكامل على مستوى الميزة، ويراجعه مرتين في وكيل فرعي، ويصلح فقط ما يستحق الإصلاح، ثم يدمج قبل بدء المرحلة التالية. بعد المرحلة الأخيرة، يقوم بعرض الميزة بأكملها بالطريقة التي يطلبها المستخدم، ويترك الدمج النهائي رئيسيًا لهم.
