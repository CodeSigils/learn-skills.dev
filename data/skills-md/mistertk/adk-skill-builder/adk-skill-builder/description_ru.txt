Развивайте навыки агентов производственного качества для использования Google's Agent Development Kit (ADK). Создает полные каталоги навыков (SKILL.md + скрипты/ + ссылки/ + активы/), которые используют специфичные для ADK возможности, такие как adk_additional_tools, развертывание GCS, внедрение двоичных ресурсов и выполнение сценариев в изолированной программной среде. Используйте этот навык всякий раз, когда кто-то просит создать навык для ADK, создать навык агента ADK, создать навык Google ADK, написать навык для агентов Gemini, создать навык SkillToolset или любой вариант «создать навык, который работает с google.adk». Также используйте, когда у кого-то есть существующий навык и он хочет сделать его совместимым с ADK или спрашивает, чем навыки ADK отличаются от навыков Claude/Cursor/Codex.
