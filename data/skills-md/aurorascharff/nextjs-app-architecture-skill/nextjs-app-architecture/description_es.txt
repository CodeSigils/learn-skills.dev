Patrones de arquitectura para aplicaciones Next.js 16 App Router. Úselo al crear una nueva aplicación, agregar una característica, refactorizar código en carpetas de características, decidir dónde residen las consultas/acciones/componentes, colocar límites de suspenso, elegir el límite cliente/servidor, diseñar esqueletos, evitar CLS o habilitar componentes de caché. Úselo también cuando el usuario pregunte sobre la composición de RSC, `params.then()`, `'use cache'`, `cacheTag`, `updateTag` o prerendering de shell estático.
