Erstellen oder prüfen Sie Next.js 16 App Router-Apps mithilfe einer React Server Components-Architektur im Next-Beats-Stil. Wird verwendet, wenn Sie ein Gerüst für eine neue App erstellen, eine Funktion hinzufügen, eine vorhandene App überprüfen, Route-Loader-förmige Seiten in funktionseigene asynchrone Serverkomponenten umgestalten, entscheiden, wo Abfragen/Aktionen/Komponenten leben, Seiten mit „params.then()“ synchron halten, Suspense-Grenzen platzieren, die Client/Server-Grenze auswählen, Grundgerüste entwerfen, CLS verhindern oder Cache-Komponenten aktivieren. Wird auch verwendet, wenn der Benutzer nach der RSC-Zusammensetzung fragt, nach Komponenten, die IDs anstelle von Routenparametern erhalten, nach „Cache verwenden“, „cacheTag“, „updateTag“, statischem Shell-Prerendering oder nach einer einfacheren Änderung einer App für KI-Agenten.
