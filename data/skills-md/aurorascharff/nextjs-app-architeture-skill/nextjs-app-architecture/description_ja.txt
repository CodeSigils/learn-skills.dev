Next Beats スタイルの React Server Components アーキテクチャを使用して、Next.js 16 App Router アプリを構築または監査します。新しいアプリのスキャフォールディング、機能の追加、既存のアプリのレビュー、ルートローダー形式のページの機能所有の非同期サーバー コンポーネントへのリファクタリング、クエリ/アクション/コンポーネントが存在する場所の決定、`params.then()` によるページの同期の維持、サスペンス境界の配置、クライアント/サーバー境界の選択、スケルトンの設計、CLS の防止、またはキャッシュ コンポーネントの有効化を行うときに使用します。ユーザーが RSC 構成、ルート パラメーターの代わりに ID を受け取るコンポーネント、「キャッシュの使用」、「cacheTag」、「updateTag」、静的シェルのプリレンダリング、または AI エージェントがアプリを変更しやすくすることについてユーザーが尋ねたときにも使用します。
