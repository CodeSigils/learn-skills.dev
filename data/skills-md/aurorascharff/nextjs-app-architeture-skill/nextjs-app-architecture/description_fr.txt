Créez ou auditez des applications Next.js 16 App Router à l’aide d’une architecture de composants React Server de style Next-Beats. À utiliser pour échafauder une nouvelle application, ajouter une fonctionnalité, réviser une application existante, refactoriser des pages en forme de chargeur de route en composants de serveur asynchrone appartenant à des fonctionnalités, décider où se trouvent les requêtes/actions/composants, garder les pages synchrones avec `params.then()`, placer des limites de suspense, choisir la limite client/serveur, concevoir des squelettes, empêcher CLS ou activer les composants de cache. À utiliser également lorsque l'utilisateur pose des questions sur la composition RSC, les composants recevant des ID au lieu des paramètres de route, « utiliser le cache », « cacheTag », « updateTag », le pré-rendu de shell statique ou pour faciliter la modification d'une application par les agents IA.
