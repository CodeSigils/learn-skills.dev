قم ببناء أو تدقيق تطبيقات Next.js 16 App Router باستخدام بنية React Server Components ذات النمط التالي. يُستخدم عند دعم تطبيق جديد، أو إضافة ميزة، أو مراجعة تطبيق موجود، أو إعادة هيكلة الصفحات على شكل أداة تحميل المسار إلى مكونات خادم غير متزامنة مملوكة للميزات، أو تحديد مكان تواجد الاستعلامات/الإجراءات/المكونات، أو الاحتفاظ بالصفحات متزامنة مع `params.then()`، أو وضع حدود معلقة، أو اختيار حدود العميل/الخادم، أو تصميم الهياكل العظمية، أو منع CLS، أو تمكين مكونات ذاكرة التخزين المؤقت. استخدمه أيضًا عندما يسأل المستخدم عن تكوين RSC، أو المكونات التي تتلقى معرفات بدلاً من معلمات المسار، أو ``استخدام ذاكرة التخزين المؤقت''، أو `cacheTag`، أو `updateTag`، أو العرض المسبق للصدفة الثابتة، أو تسهيل تعديل التطبيق على وكلاء الذكاء الاصطناعي.
