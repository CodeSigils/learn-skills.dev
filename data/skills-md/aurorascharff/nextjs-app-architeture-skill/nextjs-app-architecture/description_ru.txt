Создавайте или проверяйте приложения Next.js 16 App Router, используя новейшую архитектуру React Server Components. Используйте при создании нового приложения, добавлении функции, проверке существующего приложения, рефакторинге страниц в форме загрузчика маршрутов в принадлежащие функциям асинхронные серверные компоненты, принятии решения о том, где находятся запросы/действия/компоненты, поддержании синхронизации страниц с помощью params.then(), размещении границ приостановки, выборе границы клиент/сервер, разработке скелетов, предотвращении CLS или включении компонентов кэша. Также используйте, когда пользователь спрашивает о составе RSC, компонентах, получающих идентификаторы вместо параметров маршрута, `'использовать кэш'`, `cacheTag`, `updateTag`, предварительную отрисовку статической оболочки или упрощать модификацию приложения для агентов ИИ.
