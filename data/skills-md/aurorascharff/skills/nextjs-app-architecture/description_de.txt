Architekturmuster für Next.js 16 App Router-Apps. Wird verwendet, wenn Sie ein Gerüst für eine neue App erstellen, eine Funktion hinzufügen, Code in Funktionsordner umgestalten, entscheiden, wo Abfragen/Aktionen/Komponenten gespeichert sind, Suspense-Grenzen platzieren, die Client/Server-Grenze auswählen, Skelette entwerfen, CLS verhindern oder Cache-Komponenten aktivieren. Wird auch verwendet, wenn der Benutzer nach RSC-Zusammensetzung, „params.then()“, „cache verwenden“, „cacheTag“, „updateTag“ oder statischem Shell-Prerendering fragt.
