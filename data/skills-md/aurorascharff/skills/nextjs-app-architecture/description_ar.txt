أنماط البنية لتطبيقات Next.js 16 App Router. يُستخدم عند دعم تطبيق جديد، أو إضافة ميزة، أو إعادة بناء التعليمات البرمجية في مجلدات الميزات، أو تحديد مكان تواجد الاستعلامات/الإجراءات/المكونات، أو وضع حدود التشويق، أو اختيار حدود العميل/الخادم، أو تصميم الهياكل العظمية، أو منع CLS، أو تمكين مكونات ذاكرة التخزين المؤقت. يُستخدم أيضًا عندما يسأل المستخدم عن تكوين RSC، أو `params.then()`، أو ``استخدام ذاكرة التخزين المؤقت``، أو `cacheTag`، أو `updateTag`، أو العرض المسبق للصدفة الثابتة.
