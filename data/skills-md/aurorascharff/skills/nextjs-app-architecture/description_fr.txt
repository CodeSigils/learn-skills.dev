Modèles d'architecture pour les applications Next.js 16 App Router. À utiliser pour échafauder une nouvelle application, ajouter une fonctionnalité, refactoriser le code dans des dossiers de fonctionnalités, décider de l'emplacement des requêtes/actions/composants, placer des limites de Suspense, choisir la limite client/serveur, concevoir des squelettes, empêcher CLS ou activer les composants de cache. À utiliser également lorsque l'utilisateur pose des questions sur la composition RSC, `params.then()`, ``use cache'`, `cacheTag`, `updateTag` ou le prérendu de shell statique.
