Diagnostica, conteni e ripara l'integrità di oggetti Git, pacchetti, riferimenti, alternative, superficiali o promittenti danneggiati utilizzando una fonte sana verificata e il ripristino additivo. Utilizzare per oggetti non validi, BLOB/alberi/commit mancanti, riferimenti interrotti, danneggiamento di pacchetti/indici o un clone superficiale/parziale esistente che non può materializzare gli oggetti richiesti. Non utilizzare per lavori intatti semplicemente irraggiungibili, errori solo LFS, configurazione di clonazione di routine, ottimizzazione o potatura.
