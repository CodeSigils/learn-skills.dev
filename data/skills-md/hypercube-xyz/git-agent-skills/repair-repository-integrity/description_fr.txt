Diagnostiquez, contenez et réparez l'intégrité des objets, packs, références, alternatives, superficiels ou prometteurs Git endommagés à l'aide d'une source saine vérifiée et d'une récupération additive. À utiliser pour les objets défectueux, les blobs/arbres/commits manquants, les références cassées, la corruption de pack/index ou un clone superficiel/partiel existant qui ne peut pas matérialiser les objets requis. Ne pas utiliser pour un travail intact simplement inaccessible, des échecs LFS uniquement, une configuration de clone de routine, une optimisation ou un élagage.
