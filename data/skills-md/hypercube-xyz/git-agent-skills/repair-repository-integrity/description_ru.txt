Диагностика, локализация и восстановление поврежденных объектов Git, упаковка, ссылка, альтернативы, поверхностная или обещанная целостность с использованием проверенного работоспособного источника и аддитивного восстановления. Используйте для плохих объектов, отсутствующих больших двоичных объектов/деревьев/фиксаций, неработающих ссылок, повреждения пакета/индекса или существующего поверхностного/частичного клона, который не может материализовать требуемые объекты. Не используйте для просто недоступной неповрежденной работы, сбоев только LFS, рутинной настройки клонирования, оптимизации или сокращения.
