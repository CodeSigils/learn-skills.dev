تشخيص واحتواء وإصلاح كائن Git التالف أو الحزمة أو المرجع أو البدائل أو التكامل الضحل أو الواعد باستخدام مصدر صحي تم التحقق منه واسترداد إضافي. يُستخدم للكائنات السيئة، أو النقط/الأشجار/الالتزامات المفقودة، أو المراجع المعطلة، أو تلف الحزمة/الفهرس، أو الاستنساخ الضحل/الجزئي الموجود الذي لا يمكنه تحقيق الكائنات المطلوبة. لا تستخدمه فقط للعمل السليم الذي لا يمكن الوصول إليه، أو حالات فشل LFS فقط، أو إعداد النسخ الروتيني، أو التحسين، أو التقليم.
