Diagnostica, contiene y repara la integridad dañada de objetos, paquetes, referencias, alternativas, superficiales o promisores de Git utilizando una fuente saludable verificada y recuperación de aditivos. Úselo para objetos defectuosos, blobs/árboles/confirmaciones faltantes, referencias rotas, corrupción de paquetes/índices o un clon superficial/parcial existente que no puede materializar los objetos requeridos. No lo use para trabajos intactos simplemente inalcanzables, fallas solo de LFS, configuración de clonación de rutina, optimización o poda.
