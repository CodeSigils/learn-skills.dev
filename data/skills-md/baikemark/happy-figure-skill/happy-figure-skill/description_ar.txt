يُستخدم عندما يريد المستخدم إنشاء مطالبات رسم علمية قابلة للنسخ تعتمد على الذكاء الاصطناعي بناءً على الأوراق أو مستندات البحث أو نصوص البحث أو التسميات التوضيحية التوضيحية أو مواد الاقتراح/الدفاع أو الصور المرجعية التي تستوفي شروط القراءة؛ تتضمن السيناريوهات القابلة للتطبيق الرسوم التوضيحية الورقية، والرسومات العلمية، والملخصات الرسومية، والملخصات الرسومية، ومخططات الآليات، ومخططات خارطة الطريق الفنية، ومخططات الإعداد التجريبية، ومخططات بنية النماذج، وأشكال المقارنة متعددة اللوحات، وأرقام النظرة العامة على التقرير، ونقل نمط الصورة المرجعية، وإنشاء قالب رئيسي غير معروف للمجال، أو تحميل/استشهاد بملفات PDF، ومستندات Word، وLaTeX، وMarkdown، والملخصات، وأقسام الأساليب، والتسميات التوضيحية للأشكال، وأوصاف المشاريع، وخطط البحث، والصور المرجعية. استخدمه أيضًا عندما يطلب المستخدم مطالبات الأشكال العلمية، أو مطالبات التوضيحات البحثية، أو المطالبات المجردة الرسومية، أو مخططات الآليات، أو خرائط الطريق الفنية، أو مخططات الإعداد التجريبية، أو المخططات التخطيطية لهندسة النماذج، أو الأشكال العلمية متعددة اللوحات، أو الأشكال الورقية/المؤتمرات، أو مطالبات صور الذكاء الاصطناعي المستندة إلى الأوراق، أو مستندات البحث، أو الملخصات، أو أقسام الأساليب، أو التسميات التوضيحية للأشكال، أو المقترحات، أو الصور المرجعية، أو ملفات PDF، أو مستندات Word، أو ملفات LaTeX، أو ملفات Markdown، أو خطط البحث.
