A complete workflow for processing Bilibili video subtitles. When a user provides a Bilibili video link or BVID, use this skill. Capabilities include: (1) guiding the user to scan a QR code to log in and obtain cookies; (2) automatically retrieving video subtitles (prioritizing AI subtitles, automatically falling back to CC subtitles); (3) generating a summary of the video content; (4) when the user asks "at what time segment does a certain content appear," accurately locate the timestamp from the subtitle file. Whenever the user mentions Bilibili links, BVID, "Bilibili subtitles," "help me watch the video," "where in the video is it mentioned," etc., be sure to use this skill.
