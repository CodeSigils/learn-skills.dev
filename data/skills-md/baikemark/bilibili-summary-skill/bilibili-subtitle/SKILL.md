# B 站视频字幕 Skill

## 一、核心能力概览

| 场景 | 你需要做什么 |
|------|------------|
| 用户给链接/BVID，想要字幕或摘要 | 检查登录 → 获取字幕 → 生成摘要 |
| 用户问"某内容在几分几秒" | 获取字幕（如已有则跳过）→ 搜索 SRT 时间戳 |
| 用户 cookie 失效或首次使用 | 引导扫码登录 → 重新获取字幕 |

---

## 二、工作流

### 第一步：解析 BVID

从用户输入中提取 BVID（格式：`BVxxxxxxxxxx`）。

- 支持纯 BVID：`BV1ZL411o7LZ`
- 支持完整链接：`https://www.bilibili.com/video/BV1ZL411o7LZ`
- 支持短链：`https://b23.tv/xxxxxxx`（先告知用户需要完整链接或 BVID）

如果无法提取 BVID，询问用户提供。

### 第二步：检查字幕缓存

检查 `subtitles_output/<BVID>/<BVID>.txt` 是否已存在：

- **存在**：直接使用缓存文件，跳过第三步。告知用户"已找到本地缓存字幕"。
- **不存在**：进入第三步获取字幕。

### 第三步：获取字幕

运行获取脚本：

```bash
python .agents/skills/bilibili-subtitle/scripts/fetch_subtitle.py <BVID>
```

**常见错误处理：**

- **Cookie 不存在 / 无效**：提示用户需要登录，进入「扫码登录」流程（见下方）。
- **该视频没有字幕**：告知用户该视频无字幕（硬字幕需 OCR 工具，请用户知晓）。
- **网络超时**：提示用户检查网络，建议重试。

### 扫码登录流程（仅在需要时执行）

当 cookie.txt 不存在或已失效时：

1. 告知用户："需要登录 B 站账号才能获取 AI 字幕，请按以下步骤操作。"
2. 运行登录脚本：
   ```bash
   cd <项目根目录> && python cookie_auto_login.py
   ```
3. 脚本会在终端打印 ASCII 二维码，提示用户用 B 站 App 扫码。
4. 登录成功后，脚本自动保存 Cookie 到 `cookie.txt`。
5. 提示用户"登录成功！"后，继续执行第三步。

> **注意**：如果当前环境无法运行 Python 终端脚本，告知用户手动将 cookie 写入 `cookie.txt`，格式为：`SESSDATA=xxx; bili_jct=xxx`

### 第四步：生成摘要

读取 `subtitles_output/<BVID>/<BVID>.txt` 文件内容，基于纯文本字幕生成结构化摘要：

**摘要格式：**
```
## 视频摘要：[BVID]

### 核心主题
（一句话概括视频主要讲了什么）

### 主要内容
1. [要点一]
2. [要点二]
3. [要点三]
...

### 关键结论
（视频最后强调或总结的观点）
```

字幕文本很长时，注意：
- 按内容逻辑分段，不要平均切割
- 识别视频中明显的"话题切换"，作为章节分隔点
- 摘要长度以能覆盖主要观点为准，不强求统一长度

### 第五步：时间戳查询

当用户问"xxx 在哪个时间段"或"视频里什么时候讲到了 xxx"时：

1. 确认已有 SRT 文件（`subtitles_output/<BVID>/<BVID>.srt`）
2. 运行时间戳搜索脚本：
   ```bash
   python .agents/skills/bilibili-subtitle/scripts/search_timestamp.py \
     subtitles_output/<BVID>/<BVID>.srt "<关键词>" --context 2
   ```
3. 将输出整理成对用户友好的格式：
   - "视频在 **01:23** 左右提到了这个内容"
   - 如果有多处匹配，列出所有时间点
   - 关键词找不到时，尝试近义词或分拆词搜索，仍无结果则诚实告知

> **时间戳格式提示**：SRT 时间格式为 `HH:MM:SS,mmm`。向用户展示时，可简化为 `MM:SS`（小时不为零时保留）。

## 三、项目目录结构参考

```
bilibili-subtitle-studio/          ← 项目根目录
├── cookie_auto_login.py           ← 扫码登录脚本
├── subtitle_extractor.py          ← 字幕提取核心库
├── cookie.txt                     ← 登录 Cookie（不提交 git）
└── subtitles_output/
    └── <BVID>/
        ├── <BVID>.txt             ← 纯文本字幕（用于摘要）
        ├── <BVID>.srt             ← 带时间戳字幕（用于时间定位）
        └── <BVID>.vtt             ← VTT 格式字幕
```

## 四、注意事项

- **B 站 AI 字幕需要登录**：未登录只能获取 UP 主手动上传的 CC 字幕，大多数视频的 AI 字幕必须登录才能访问。
- **Cookie 有效期**：B 站 Cookie 通常有效期较长（数月），但账号异常登出会导致失效。
- **字幕类型判断**：如果获取到的字幕条数极少（< 10 条），可能是 CC 字幕而非完整 AI 字幕，可提示用户。
- **硬字幕**：若视频字幕是烧录在画面中的（如很多综艺、电影），本工具无法获取，需 OCR 工具处理。
