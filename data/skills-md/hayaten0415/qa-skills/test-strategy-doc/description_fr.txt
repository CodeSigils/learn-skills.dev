Générez un document de stratégie de test aligné sur ISTQB et ISO/IEC 25010:2023 à partir d'un PRD, d'une spécification de fonctionnalité ou d'une base de code. Comprend une évaluation prioritaire obligatoire des caractéristiques de qualité couvrant les neuf caractéristiques ISO 25010:2023, les niveaux/types de tests, les critères d'entrée/sortie et la portée basée sur les risques. À utiliser lorsque : « stratégie de test », « テスト戦略 », « plan d'assurance qualité », « approche de test », « quelle est notre approche globale de test » ou toute demande de documentation de planification de test. Pas pour : prioriser/ordonner les efforts de test sous pression de temps – utiliser des tests basés sur les risques ; ou concevoir des cas de test individuels - utilisez les compétences en conception de tests. Connexes : tests basés sur les risques, analyse des valeurs limites.
