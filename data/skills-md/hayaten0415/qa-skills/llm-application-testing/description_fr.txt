Testez les fonctionnalités des applications LLM/IA générative (chatbots, RAG, agents, utilisation d'outils) où les résultats sont non déterministes et ouverts. Couvre l'évaluation de l'exactitude/fidélité ET la sécurité/sûreté via le Top 10 OWASP pour les applications LLM (2025). À utiliser lorsque : "tester une fonctionnalité LLM", "LLMのテスト", "évaluation RAG", "test d'hallucinations", "injection rapide", "jailbreak", "LLM-as-juge", "évaluations", "équipe rouge du chatbot" ou l'envoi de toute fonctionnalité construite sur un LLM. Produit un plan d'évaluation + une couverture OWASP LLM Top 10 (mode conception) et des suites d'évaluation/équipe rouge, par ex. promptfoo/DeepEval/Ragas/garak (mode d'implémentation). Pas pour : les tests d'intrusion d'applications/API non LLM (contournement d'authentification, SQLi, analyses de dépendances) – utiliser les tests de sécurité ; ou modèles ML classiques/prédictifs – utilisez ml-system-testing. Connexes : tests du système ml, tests de sécurité.
