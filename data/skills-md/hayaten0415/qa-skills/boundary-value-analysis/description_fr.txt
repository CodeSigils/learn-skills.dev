Concevez et implémentez des tests de valeurs limites pour les plages numériques, les dates, les longueurs de chaînes, les tailles de collection et les limites de pagination. À utiliser lorsque : "valeur limite", "cas extrêmes", "cas extrêmes pour la validation des entrées", "un par un" ou chaque fois que l'utilisateur teste une entrée avec un min/max, une limite de longueur ou une plage, même s'il ne dit pas "limite". Produit à la fois une table de conception de cas de test (mode conception) et des tests paramétrés exécutables (mode implémentation). Pas pour : choisir les entrées à partitionner en premier – utilisez le partitionnement par équivalence. Connexes : partitionnement d'équivalence, tests de table de décision.
