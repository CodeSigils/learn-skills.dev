Progetta e implementa test dei valori limite per intervalli numerici, date, lunghezze di stringhe, dimensioni di raccolte e limiti di impaginazione. Utilizzare quando: "valore limite", "境界値", "casi limite per la convalida dell'input", "off-by-one" o ogni volta che l'utente sta testando qualsiasi input con un limite min/max, lunghezza o intervallo, anche se non dice "limite". Produce sia una tabella di progettazione del caso di test (modalità di progettazione) che test parametrizzati eseguibili (modalità di implementazione). Non per: scegliere quali input partizionare per primi: utilizzare il partizionamento per equivalenza. Correlati: partizionamento di equivalenza, test delle tabelle decisionali.
