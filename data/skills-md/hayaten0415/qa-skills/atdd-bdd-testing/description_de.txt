Leiten Sie Akzeptanztests gemeinsam aus User Stories und Akzeptanzkriterien ab, test-first, gemäß ISTQB CTFL v4.0 §4.5 (Collaboration-based Test Approaches). Wird verwendet, wenn: „ATDD“, „BDD“, „Akzeptanzkriterien“, „Akzeptanztest“, „Akzeptanztest“, „Testen einer User Story“, „Gegeben/Wann/Dann“, „Drei Amigos“, „Cucumber/SpecFlow/Behave“ oder beim Umwandeln einer Story in ausführbare Spezifikationen. Erstellt User Stories + Akzeptanzkriterien (Designmodus) und ausführbare Akzeptanztests (Implementierungsmodus). Nicht für: Low-Level-Eingabepartitionierung eines einzelnen Feldes – verwenden Sie Äquivalenzpartitionierung/Randwertanalyse. Verwandte Themen: Äquivalenzpartitionierung, Teststrategiedokument.
