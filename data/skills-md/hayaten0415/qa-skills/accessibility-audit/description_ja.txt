WCAG 2.2 に照らして Web UI アクセシビリティを監査およびテストします。これは、ISO/IEC 25010:2023 のインタラクション機能特性 (特に包括性と操作性) のテスト可能な基礎です。 「アクセシビリティ」、「a11y」、「アクセシビリティ」、「WCAG」、「スクリーン リーダー」、「キーボード ナビゲーション」、「カラー コントラスト」、「ADA/セクション 508 準拠」、または障害を持つユーザーの UI を監査する場合に使用します。優先順位付けされた調査結果 (設計モード) と自動 + 手動テスト スイートを含む WCAG 2.2 適合性監査を生成します。 @axe-core/playwright (実装モード)。対象外: クロスエンジン レンダリングのバグ — クロスブラウザー テストを使用してください。関連: クロスブラウザーテスト。
