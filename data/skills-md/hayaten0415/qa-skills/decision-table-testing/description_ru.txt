Разработайте и внедрите тесты таблицы решений для логики, в которых комбинации условий приводят к различным результатам — бизнес-правилам, ценообразованию, приемлемости, разрешениям. Используйте, когда: «таблица решений», «デシジョンテーブル», «бизнес-правила», «комбинации условий», логика «если X и Y, то Z» или матрицы флагов функций/ценообразования/приемлемости. Создает свернутую таблицу решений (режим разработки) и один параметризованный тест для каждого правила (режим реализации). Не для: диапазонов с одним параметром — используйте разделение эквивалентности/анализ граничных значений; для поведения, упорядоченного по событиям, используйте тестирование перехода состояний. Связано: разделение эквивалентности, тестирование перехода состояний.
