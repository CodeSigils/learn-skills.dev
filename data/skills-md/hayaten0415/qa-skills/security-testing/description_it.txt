Progettare e implementare test di sicurezza delle applicazioni basati su OWASP (Top 10, ASVS, WSTG) per la caratteristica di sicurezza ISO/IEC 25010:2023 (riservatezza, integrità, non ripudio, responsabilità, autenticità, resistenza). Utilizzare quando: "test di sicurezza", "セキュリティテスト", "OWASP", "SAST/DAST", "scansione delle vulnerabilità", "ambito del test di penetrazione", "SQL injection", "test del controllo di autenticazione/accesso", "scansione di dipendenze/segreti" o rafforzamento di una pipeline CI. Produce un piano di test basato su ASVS (modalità di progettazione) e gate di sicurezza CI: scansioni SAST/DAST/SCA/segreti (modalità di implementazione). Solo test autorizzati/difensivi. Non per: attacchi specifici di LLM (prompt injection, jailbreak, RAG red-teaming): utilizzare llm-application-testing; o pen-testing infra/rete di terze parti. Correlati: test-strategy-doc, llm-application-testing.
