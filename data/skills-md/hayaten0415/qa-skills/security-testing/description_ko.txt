ISO/IEC 25010:2023 보안 특성(기밀성, 무결성, 부인 방지, 책임, 신뢰성, 저항)에 대해 OWASP(상위 10, ASVS, WSTG)를 기반으로 하는 애플리케이션 보안 테스트를 설계하고 구현합니다. 사용 시기: "보안 테스트", "세큐리티 테스트", "OWASP", "SAST/DAST", "취약성 검사", "침투 테스트 범위", "SQL 주입", "인증/액세스 제어 테스트", "종속성/비밀 검사" 또는 CI 파이프라인 강화. ASVS 기반 테스트 계획(디자인 모드) 및 CI 보안 게이트(SAST/DAST/SCA/비밀 스캔(구현 모드))를 생성합니다. 승인된/방어 테스트만 가능합니다. 해당되지 않음: LLM 관련 공격(즉시 주입, 탈옥, RAG 레드팀 구성) - llm-application-testing을 사용합니다. 또는 제3자의 인프라/네트워크 침투 테스트. 관련 항목: 테스트 전략 문서, llm-응용 프로그램 테스트.
