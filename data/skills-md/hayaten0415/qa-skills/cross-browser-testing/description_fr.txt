Implémenter une couverture de test multi-navigateurs et multi-appareils avec les projets Playwright (Chromium, Firefox, WebKit, émulation mobile). À utiliser lorsque : "multi-navigateur", "クロスブラウザ", "fonctionne dans Safari ?", "test de fenêtre d'affichage mobile", bugs spécifiques au navigateur ou chaque fois que la suite E2E d'une application Web s'exécute sur un seul navigateur. Couvre la caractéristique de compatibilité ISO 25010:2023 (coexistence, interopérabilité de l'interface utilisateur entre les moteurs). Pas pour : les différences visuelles de pixels – utilisez un outil de régression visuelle dédié. Connexes : tests de flexibilité.
