Planen und führen Sie Arbeitsproduktüberprüfungen (Anforderungen, Design, Code, Testgrundlagen) gemäß ISTQB CTFL v4.0 §3 und dem ISO/IEC 20246-Überprüfungsprozess durch – statische Tests, die Fehler finden, bevor Code ausgeführt wird. Wird verwendet, wenn: „statisches Testen“, „Überprüfung“, „Prüfung“, „Anforderungen“, „Anforderungs-/Entwurfsüberprüfung“, „Inspektion“, „Komplettlösung“, „Überprüfungsbesprechung“, „Fehlerbehebung“ oder das frühzeitige Erkennen von Fehlern in einem Arbeitsprodukt. Erstellt einen Überprüfungsplan, Rollen und ein Anomalieprotokoll/-bericht (Entwurfsmodus). Nicht für: Beurteilung der Code-Testbarkeit/Testsuite-Effektivität – verwenden Sie Maintainability-Review; oder die Software ausführen. Verwandte Themen: Wartbarkeitsprüfung, Fehlerbericht.
