Analice y pruebe la seguridad del software para la característica de seguridad ISO/IEC 25010:2023 (restricción operativa, identificación de riesgos, seguridad contra fallas, advertencia de peligro, integración segura), nueva en la edición 2023. Úselo cuando: "seguridad", "安全性", "a prueba de fallas", "estado seguro", "barandillas", "interruptor de apagado", "análisis de peligros", "FMEA", "qué sucede si esta acción destructiva se activa por error" o sistemas de construcción que pueden dañar a las personas/propiedad/medio ambiente o realizar acciones irreversibles. Produce un análisis de peligros + plan de pruebas de seguridad (modo de diseño) y pruebas de seguridad / barandillas (modo de implementación). Para dominios regulados críticos para la seguridad, difiere de los estándares de seguridad funcional. No para: recuperación/disponibilidad después de fallas de infraestructura (DB/nodo caído): use pruebas de confiabilidad; o seguridad contra atacantes: utilice pruebas de seguridad. Relacionado: pruebas de confiabilidad, pruebas de seguridad.
