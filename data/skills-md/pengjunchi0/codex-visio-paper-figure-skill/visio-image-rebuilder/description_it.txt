Ricostruisci o rinnova lo stile dei diagrammi modificabili di Microsoft Visio da immagini di riferimento e file .vsdx esistenti. Da utilizzare quando l'utente chiede a Codex di aprire Visio, ricreare un diagramma da un PNG/JPG/screenshot/immagine di riferimento, abbinare una figura di modello scientifico, aggiornare colori/tipografia/layout in un file .vsdx o rendere un file Visio visivamente coerente con un'immagine preservando le forme modificabili native anziché incorporare l'immagine come immagine piatta.
