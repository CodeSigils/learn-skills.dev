Iterieren Sie Pläne oder Implementierungen durch neue Prüfer-Subagenten bis zur Konvergenz. Verwenden Sie diese Option, wenn der Benutzer ausdrücklich nach einer „frischen Prüferschleife“, einer „Planiterationsschleife“, „Prüfung und Kritik bis zur Bereinigung“, „Beauftragung eines Prüfers zur Überprüfung meiner Änderungen“ oder nach einer Formulierung fragt, bei der das Ziel darin besteht, kontroverse Prüf- und Korrekturzyklen entweder für einen Plan vor dem Code oder für eine funktionierende Implementierung nach dem Code zu delegieren. Jede Runde verwendet einen neuen Subagenten, sodass es keinen Kontext oder Gruppendenken der vorherigen Runde gibt.
