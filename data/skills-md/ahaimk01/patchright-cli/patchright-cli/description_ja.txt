Patchright (未検出の Playwright フォーク) を使用したブラウザ自動検出の防止。 Akamai/Cloudflare で保護されたサイトなど、通常の Playwright/Chrome DevTools をブロックする Web サイトと対話する必要がある場合に使用します。 playwright-cli と同じコマンド インターフェイスを提供しますが、ボット検出をバイパスします。ユーザーがブラウザの自動化、Web サイトのスクレイピング、フォームの記入、サイトへのログイン、スクリーンショットの撮影、または Chrome 自動化に関連する操作を行うように要求するたびに、このスキルを使用します。特に、対象のサイトに Cloudflare や Akamai などのボット保護機能がある場合に使用します。
