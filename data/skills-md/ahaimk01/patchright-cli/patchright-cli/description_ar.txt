أتمتة المتصفح ضد الاكتشاف باستخدام Patchright (شوكة Playwright غير المكتشفة). يُستخدم عندما تحتاج إلى التفاعل مع مواقع الويب التي تحظر أدوات Playwright/Chrome DevTools العادية، مثل مواقع Akamai/Cloudflare المحمية. يوفر نفس واجهة الأوامر مثل playwright-cli ولكنه يتجاوز اكتشاف الروبوتات. استخدم هذه المهارة عندما يطلب المستخدم أتمتة المتصفح، أو استخراج موقع ويب، أو ملء النماذج، أو تسجيل الدخول إلى المواقع، أو التقاط لقطات شاشة، أو القيام بأي شيء يتضمن أتمتة Chrome - خاصة إذا كان الموقع المستهدف يتمتع بحماية الروبوت مثل Cloudflare أو Akamai.
