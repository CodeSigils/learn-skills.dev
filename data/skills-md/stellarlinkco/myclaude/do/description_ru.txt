Этот навык следует использовать для разработки структурированных функций с пониманием кодовой базы. Запускается по команде /do. Обеспечивает пятиэтапный рабочий процесс (понимание, уточнение, проектирование, реализация, завершение) с использованием codeagent-wrapper для параллельной организации проводника кода, архитектора кода, рецензента кода и разработки агентов.
