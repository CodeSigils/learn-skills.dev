Profundice en cualquier base de código y produzca artefactos de conocimiento estructurados que conviertan a un agente de codificación en un especialista en base de código. Esta habilidad debe usarse cuando el usuario solicita "estudiar este repositorio", "comprender este código base", "documentar este proyecto", "incorporarme a este código", "crear conocimiento de código base", "mapear esta arquitectura" o cuando se le solicita que produzca artefactos de conocimiento para cualquier agente que trabaje en un repositorio desconocido.
