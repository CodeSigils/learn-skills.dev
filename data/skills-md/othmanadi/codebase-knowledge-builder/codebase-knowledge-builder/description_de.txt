Tauchen Sie tief in jede Codebasis ein und erstellen Sie strukturierte Wissensartefakte, die einen Coding-Agenten in einen Codebasis-Spezialisten verwandeln. Diese Fähigkeit sollte verwendet werden, wenn der Benutzer darum bittet, „dieses Repo zu studieren“, „diese Codebasis zu verstehen“, „dieses Projekt zu dokumentieren“, „mich in diesen Code einzuarbeiten“, „Codebasiswissen zu erstellen“, „diese Architektur abzubilden“ oder wenn er aufgefordert wird, Wissensartefakte für einen Agenten zu erstellen, der an einem unbekannten Repository arbeitet.
