Manus-style file-based planning system for organizing and tracking complex tasks.  
Create three files: task_plan.md, findings.md, and progress.md.  
Use when the user asks to plan, break down, or organize multi-step projects, research tasks, or work requiring more than 5 tool calls.  
Supports automatic session recovery after /clear.  
Trigger words: task planning, project plan, make a plan, break down tasks, multi-step planning, progress tracking, file planning, help me plan, break down project
