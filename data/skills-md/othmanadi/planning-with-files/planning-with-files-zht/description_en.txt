A Manus-style file planning system for organizing and tracking complex task progress. Create three files: task_plan.md, findings.md, and progress.md. Use when the user requests planning, breaking down, or organizing multi-step projects, research tasks, or work requiring more than five tool calls. Supports automatic session recovery after /clear. Trigger words: task planning, project plan, make a plan, break down tasks, multi-step planning, progress tracking, file planning, help me plan, break down project
