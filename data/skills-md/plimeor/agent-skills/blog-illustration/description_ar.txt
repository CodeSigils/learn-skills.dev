قم بإنشاء مطالبات نموذجية لإنشاء الصور لرسوم توضيحية لمنشورات المدونة بأسلوب رسومي كرتوني ملون مع استعارات شخصية لطيفة ومناطق مرمزة بألوان الباستيل. استخدم هذه المهارة عندما يريد المستخدم إنشاء صورة مرئية أو رسم توضيحي لمنشور مدونة أو مقالة - بنيات النظام، أو سير العمل، أو تفسيرات المفاهيم، أو المقارنات، أو أي فكرة مجردة تحتاج إلى صورة مرئية مرحة. تشغيل الكلمات الرئيسية مثل "画图" أو "插图" أو "图片提示词" أو "配图" أو "توضيح" أو "مخطط معلومات بياني" أو "مطالبة الصورة"، أو عندما يشارك المستخدم محتوى المقالة ويطلب إنشاء صورة أو رسم تخطيطي مصاحب بواسطة نموذج صورة.
