إنشاء وإدارة "مستندات CMS" - ملفات Markdown التي تعمل كواجهة بسيطة لإدارة المحتوى للمتعاونين غير التقنيين في سير عمل Vibecoding. استخدم هذه المهارة عندما يريد المستخدم جرد نسخة الواجهة الأمامية أو مراجعتها أو تحديثها دفعة واحدة (نص واجهة المستخدم، أو تسميات الأزرار، أو نص العنصر النائب، أو رسائل الخطأ، أو تسميات aria، أو عناوين الصفحات، أو مطالبات الذكاء الاصطناعي، أو أي سلاسل أخرى تواجه المستخدم مشفرة في ملفات المصدر). يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "سرد كل النص في تطبيقي"، أو "أريد تغيير الصياغة"، أو "إنشاء مستند نسخة"، أو "إنشاء مخزون محتوى"، أو "السماح لشخص آخر بتحرير النص"، أو "إعادة ملء النسخة من المستند"، أو "تطبيق مستند CMS". تعمل هذه المهارة مع أي إطار عمل للواجهة الأمامية (React وVue وSvelte وNext.js وHTML العادي وما إلى ذلك).
