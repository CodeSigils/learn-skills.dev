Générez et gérez des « documents CMS » : des fichiers Markdown qui servent d'interface de gestion de contenu simple pour les collaborateurs non techniques dans les flux de travail Vibecoding. Utilisez cette compétence chaque fois que l'utilisateur souhaite inventorier, réviser ou mettre à jour par lots une copie frontale (texte de l'interface utilisateur, étiquettes de boutons, texte d'espace réservé, messages d'erreur, étiquettes aria, titres de page, invites IA ou toute autre chaîne destinée à l'utilisateur codée en dur dans les fichiers source). Se déclenche également lorsque l'utilisateur dit des choses telles que "répertorier tout le texte de mon application", "Je souhaite modifier le texte", "faire une copie du document", "générer un inventaire de contenu", "laisser quelqu'un d'autre modifier le texte", "remplir une copie du document" ou "appliquer le document CMS". Cette compétence fonctionne avec n'importe quel framework frontend (React, Vue, Svelte, Next.js, HTML brut, etc.).
