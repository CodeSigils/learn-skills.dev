Genera e gestisci "documenti CMS": file Markdown che fungono da semplice interfaccia di gestione dei contenuti per i collaboratori non tecnici nei flussi di lavoro Vibecoding. Utilizza questa capacità ogni volta che l'utente desidera eseguire l'inventario, rivedere o aggiornare in batch la copia del frontend (testo dell'interfaccia utente, etichette dei pulsanti, testo segnaposto, messaggi di errore, etichette di aria, titoli di pagina, prompt AI o qualsiasi altra stringa rivolta all'utente codificata nei file di origine). Si attiva anche quando l'utente dice cose come "elenca tutto il testo nella mia app", "voglio cambiare il testo", "crea una copia del documento", "genera un inventario dei contenuti", "consenti a qualcun altro di modificare il testo", "riempi la copia dal documento" o "applica il documento CMS". Questa abilità funziona con qualsiasi framework frontend (React, Vue, Svelte, Next.js, HTML semplice, ecc.).
