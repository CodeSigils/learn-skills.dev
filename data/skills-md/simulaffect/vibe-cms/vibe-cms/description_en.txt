Generate and manage "CMS documents" — Markdown files that serve as a simple content management interface for non-technical collaborators in Vibecoding workflows. Use this skill whenever the user wants to inventory, review, or batch-update frontend copy (UI text, button labels, placeholder text, error messages, aria-labels, page titles, AI prompts, or any other user-facing strings hardcoded in source files). Also trigger when the user says things like "list all the text in my app", "I want to change the wording", "make a copy doc", "generate a content inventory", "let someone else edit the text", "backfill copy from the doc", or "apply the CMS document". This skill works with any frontend framework (React, Vue, Svelte, Next.js, plain HTML, etc.).
