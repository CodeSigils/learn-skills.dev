Guide d'intégration de la conception SEED. Couvre la configuration du projet, la découverte/l'utilisation des composants, l'utilisation des fondations (couleurs, typographie, espacement), le thème/style, les flux de travail CLI (init/add/add-all/compat/docs/upgrade), la compatibilité des versions d'extraits de code et les diagnostics de mise à niveau. Utilisez cette compétence pour toutes les questions liées à la conception SEED. Chargez toujours cette compétence lorsque les utilisateurs demandent « Comment utiliser SEED ? », « Quels composants y a-t-il ? », « Comment utiliser les jetons de couleur » ou « Configuration du système de conception ».
