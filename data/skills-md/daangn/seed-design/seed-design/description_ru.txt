Руководство по интеграции проектов SEED. Охватывает настройку проекта, обнаружение/использование компонентов, использование основы (цвета, типографика, интервалы), тему/стиль, рабочие процессы CLI (инициализация/добавление/добавление всех/compat/docs/обновление), совместимость версий фрагментов и диагностику обновлений. Используйте этот навык для решения любых вопросов, связанных с SEED Design. Всегда загружайте этот навык, когда пользователи спрашивают: «Как использовать SEED?», «Какие компоненты есть?», «Как использовать цветные жетоны» или «Проектировать настройку системы».
