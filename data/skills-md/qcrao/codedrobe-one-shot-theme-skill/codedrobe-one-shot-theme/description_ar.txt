قم بإنشاء سمة CodeDrobe الأصلية الكاملة وتعبئتها وتثبيتها ومشاهدتها والتحقق منها لتطبيق OpenAI Codex لسطح المكتب على نظام التشغيل macOS أو Windows من طلب واحد باللغة الطبيعية. يُستخدم عندما يطلب المستخدم مظهرًا/موضوعًا لـ Codex، أو يصف مفهومًا مرئيًا مثل "اجعلني موضوعًا لكرة القدم الكونغ فو"، أو يريد تصميمًا لمنزل ومحادثة مدعومًا بالصور، أو يطلب إنشاء وتثبيت/تطبيق ".codedrobe-theme" مباشرة دون عملية إعداد متعددة الأدوار.
