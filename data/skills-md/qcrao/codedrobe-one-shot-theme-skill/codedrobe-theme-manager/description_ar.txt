قم بتنزيل حزم .codedrobe-theme المخصصة للبيانات فقط وفحصها وتثبيتها وتطبيقها وتبديلها والتحقق منها واستعادتها بأمان من CodexSkins.org من خلال وقت تشغيل CodeDrobe Core المنشور. يُستخدم عندما يقوم المستخدم بتسمية معرف سمة CodexSkins أو عنوان URL، أو يريد تنشيط سمة مثبتة أو تغييرها، أو يسأل عن السمات المثبتة أو النشطة، أو يريد إعادة Codex إلى مظهره الأصلي.
