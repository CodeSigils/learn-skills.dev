Laden Sie .codedrobe-theme-Pakete, die nur für Daten bestimmt sind, sicher von CodexSkins.org über die veröffentlichte CodeDrobe Core-Laufzeit herunter, prüfen Sie sie, installieren Sie sie, wenden Sie sie an, wechseln Sie, überprüfen Sie sie und stellen Sie sie wieder her. Wird verwendet, wenn ein Benutzer eine CodexSkins-Themen-ID oder -URL benennt, ein installiertes Thema aktivieren oder ändern möchte, fragt, welche Themen installiert oder aktiv sind, oder Codex auf sein natives Erscheinungsbild zurücksetzen möchte.
