Вызов моделей ModelGo с помощью ключа API (совместимого с OpenAI). Используйте, когда пользователь хочет запустить чат/завершение, передать ответ в потоковом режиме, составить список моделей, создать встраивания, выполнить визуальные/изображения/аудио/мультимодальные вызовы или обратиться к любой конечной точке /v1/* с помощью ключа API mgk_. Триггеры: 调用模型, 跑模型, чат, 对话补全, 流式, встраивания, 向量, 列模型, модели списков, 多模态, 图片生成, 语音, видение, ключ API调用.
