Chiama i modelli ModelGo con una chiave API (compatibile con OpenAI). Da utilizzare quando l'utente desidera eseguire una chat/un completamento, trasmettere in streaming una risposta, elencare modelli, creare incorporamenti, eseguire chiamate di visione/immagine/audio/multimodali o raggiungere qualsiasi endpoint /v1/* con la chiave API mgk_. Trigger: 调用模型, 跑模型, chat, 对话补全, 流式, incorporamenti, 向量, 列模型, modelli di elenco, 多模态, 图片生成, 语音, visione, chiave API调用.
