Экспертные навыки Jetpack Compose для разработки пользовательского интерфейса Android. Управляет решениями по управлению состоянием (@Composable, Remember, MutableStateOf, DerivedStateOf, Подъем состояния), просмотром композиции и структуры, цепочками модификаторов, ленивыми списками, навигацией, анимацией, побочными эффектами, темами, доступностью и оптимизацией производительности. Подкреплено фактическим анализом исходного кода AndroidX. Используйте этот навык всякий раз, когда пользователь упоминает Compose, @Composable, Remember, LaunchedEffect, Scaffold, NavHost, MaterialTheme, LazyColumn, Modifier, recomposition, Style, styleable, MutableStyleState или любой API Jetpack Compose. Также срабатывает, когда пользователь говорит «Android UI», «Kotlin UI», «создать макет», «создать навигацию», «создать анимацию», «material3», «создать стили», «стили api» или спрашивает о современных шаблонах разработки Android. Даже случайные упоминания, такие как «мой экран создания сообщений работает медленно» или «как мне передавать данные между экранами», должны активировать этот навык.
