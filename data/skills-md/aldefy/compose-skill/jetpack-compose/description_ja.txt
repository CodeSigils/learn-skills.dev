Android UI 開発のための Jetpack Compose エキスパート スキル。状態管理の決定 (@Composable、remember、mutableStateOf、deriveStateOf、State hoisting)、ビューの構成と構造、修飾子チェーン、遅延リスト、ナビゲーション、アニメーション、副作用、テーマ、アクセシビリティ、パフォーマンスの最適化をガイドします。実際の AndroidX ソースコード分析によって裏付けられています。ユーザーが Compose、@Composable、remember、LaunchedEffect、Scaffold、NavHost、MaterialTheme、LazyColumn、Modifier、recomposition、Style、styleable、MutableStyleState、または任意の Jetpack Compose API について言及するたびに、このスキルを使用します。また、ユーザーが「Android UI」、「Kotlin UI」、「レイアウトの作成」、「ナビゲーションの作成」、「アニメーションの作成」、「マテリアル 3」、「スタイルの作成」、「スタイル API」と発言した場合、または最新の Android 開発パターンについて質問した場合にもトリガーされます。 「作成画面が遅い」または「画面間でデータを渡すにはどうすればよいか」などの何気ない言及でも、このスキルがトリガーされるはずです。
