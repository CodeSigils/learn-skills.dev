Compétence experte Jetpack Compose pour le développement de l’interface utilisateur Android. Guide les décisions de gestion de l'état (@Composable, rappelez-vous, mutableStateOf, dérivéStateOf, State hoisting), la composition et la structure des vues, les chaînes de modificateurs, les listes paresseuses, la navigation, l'animation, les effets secondaires, les thèmes, l'accessibilité et l'optimisation des performances. Soutenu par une analyse réelle du code source Androidx. Utilisez cette compétence chaque fois que l'utilisateur mentionne Compose, @Composable, Remember, LaunchedEffect, Scaffold, NavHost, MaterialTheme, LazyColumn, Modifier, recomposition, Style, styleable, MutableStyleState ou toute API Jetpack Compose. Déclenchez également lorsque l'utilisateur dit « Android UI », « Kotlin UI », « composer layout », « composer navigation », « composer animation », « materials3 », « composer styles », « styles api » ou pose des questions sur les modèles de développement Android modernes. Même des mentions informelles telles que « mon écran de rédaction est lent » ou « comment transmettre des données entre les écrans » devraient déclencher cette compétence.
