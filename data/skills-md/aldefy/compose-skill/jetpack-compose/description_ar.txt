Jetpack يؤلف مهارة الخبراء لتطوير واجهة مستخدم Android. يرشد قرارات إدارة الحالة (@Composable، تذكر، mutableStateOf، مشتقةStateOf، رفع الحالة)، عرض التركيب والهيكل، سلاسل التعديل، القوائم البطيئة، التنقل، الرسوم المتحركة، التأثيرات الجانبية، السمات، إمكانية الوصول، وتحسين الأداء. مدعومة بتحليل كود مصدر androidx الفعلي. استخدم هذه المهارة عندما يذكر المستخدم Compose أو @Composable أو تذكر أو LaunchedEffect أو Scaffold أو NavHost أو MaterialTheme أو LazyColumn أو Modifier أو recomposition أو Style أو styleable أو MutableStyleState أو أي واجهة برمجة تطبيقات Jetpack Compose. يتم تشغيله أيضًا عندما يقول المستخدم "Android UI"، أو "Kotlin UI"، أو "إنشاء تخطيط"، أو "إنشاء التنقل"، أو "إنشاء رسوم متحركة"، أو "material3"، أو "إنشاء أنماط"، أو "styles api"، أو يسأل عن أنماط تطوير Android الحديثة. حتى الإشارات غير الرسمية مثل "شاشة الكتابة الخاصة بي بطيئة" أو "كيف أقوم بتمرير البيانات بين الشاشات" يجب أن تؤدي إلى تفعيل هذه المهارة.
