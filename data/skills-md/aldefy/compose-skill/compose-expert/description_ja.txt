Android、デスクトップ、iOS、Web にわたる UI 開発の Compose および Compose マルチプラットフォームのエキスパート。ユーザーが Compose API (@Composable、remember、LaunchedEffect、NavHost、MaterialTheme、LazyColumn、Modifier、recomposition)、Compose Multiplatform (commonMain、expect/actual、Res.*、ComposeUIViewController、UIKitView、ComposeViewport)、Android TV (tv-material、D-pad、focus、Carousel)、マテリアル 3 モーション、アトミック デザイン システム、デザインからコードまでのワークフローに言及するたびに使用します。ページング 3、またはナビゲーション。 GitHub PR URL のレビュー モードを有効にし、フレーズ (「この PR をレビューしてください」、「これの何が間違っているのか」) をレビューします。 session_start で Compose プロジェクトを自動検出します。実際の androidx/androidx および JetBrains/compose-multiplatform-core ソース レシートによって裏付けられています。トリガー面全体については、SKILL.md の「## このスキルが適用される場合」を参照してください。
