Эксперт по Compose и Compose Multiplatform для разработки пользовательского интерфейса для Android, настольных компьютеров, iOS и Интернета. Используйте всякий раз, когда пользователь упоминает API Compose (@Composable, помните, LaunchedEffect, NavHost, MaterialTheme, LazyColumn, Modifier, recomposition), Compose Multiplatform (commonMain, ожидаемый/фактический, Res.*, ComposeUIViewController, UIKitView, ComposeViewport), Android TV (tv-material, D-pad, focus, Carousel), Material 3 motion, системы атомарного дизайна, дизайн в коде рабочие процессы, Paging 3 или навигация. Активирует режим проверки для URL-адресов PR GitHub и фраз проверки («просмотрите этот PR», «что с этим не так»). Автоматически обнаруживает проекты Compose в session_start. Подкреплено реальными исходными квитанциями androidx/androidx и JetBrains/compose-multiplatform-core. Полную информацию о триггерной поверхности см. в разделе «## Когда применяется этот навык» в SKILL.md.
