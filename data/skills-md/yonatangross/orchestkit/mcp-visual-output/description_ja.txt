@json-render/mcp を介したインタラクティブな MCP ビジュアル出力。 Claude、Cursor、ChatGPT の会話内のサンドボックス化された iframe でレンダリングされたインタラクティブなダッシュボードへのプレーンな JSON ツールの応答をアップグレードします。 createMcpApp()、registerJsonRenderTool()、CSP 構成、ストリーミング、およびダッシュボード コンポーネント パターンをカバーします。ビジュアル出力を返す MCP サーバーを構築する場合、対話型 UI を備えた既存の MCP ツールをアップグレードする場合、または評価/監視ダッシュボードを作成する場合に使用します。
