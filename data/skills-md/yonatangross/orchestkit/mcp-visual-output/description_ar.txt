إخراج مرئي تفاعلي لـ MCP عبر @json-render/mcp. قم بترقية استجابات أداة JSON البسيطة إلى لوحات المعلومات التفاعلية المعروضة في إطارات iframe في وضع الحماية داخل محادثات Claude وCursor وChatGPT. يغطي createMcpApp() وregisterJsonRenderTool() وتكوين CSP والتدفق وأنماط مكونات لوحة المعلومات. يُستخدم عند إنشاء خوادم MCP التي تُرجع مخرجات مرئية، أو ترقية أدوات MCP الحالية باستخدام واجهة مستخدم تفاعلية، أو إنشاء لوحات معلومات التقييم/المراقبة.
