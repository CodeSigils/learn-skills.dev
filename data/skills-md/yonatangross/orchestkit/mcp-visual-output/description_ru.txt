Интерактивный визуальный вывод MCP через @json-render/mcp. Обновите простые ответы инструмента JSON до интерактивных панелей мониторинга, отображаемых в изолированных iframe внутри разговоров Claude, Cursor и ChatGPT. Охватывает шаблоны createMcpApp(), RegisterJsonRenderTool(), конфигурации CSP, потоковой передачи и компонентов информационной панели. Используйте при создании серверов MCP, которые возвращают визуальные выходные данные, обновлении существующих инструментов MCP с помощью интерактивного пользовательского интерфейса или создании панелей мониторинга/оценки.
