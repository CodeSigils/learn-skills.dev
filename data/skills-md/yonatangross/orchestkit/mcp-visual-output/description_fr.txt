Sortie visuelle MCP interactive via @json-render/mcp. Mettez à niveau les réponses de l'outil JSON simple vers des tableaux de bord interactifs rendus dans des iframes en bac à sable dans les conversations Claude, Cursor et ChatGPT. Couvre createMcpApp(), registerJsonRenderTool(), les modèles de composants de configuration CSP, de streaming et de tableau de bord. À utiliser lors de la création de serveurs MCP qui renvoient une sortie visuelle, de la mise à niveau des outils MCP existants avec une interface utilisateur interactive ou de la création de tableaux de bord d'évaluation/surveillance.
