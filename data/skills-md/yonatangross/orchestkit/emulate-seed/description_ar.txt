قم بإنشاء تكوينات محاكاة أولية لمحاكاة واجهة برمجة التطبيقات (API) ذات الحالة. يلتف أداة محاكاة Vercel لواجهات برمجة تطبيقات GitHub وVercel وGoogle OAuth وSlack وApple Auth وMicrosoft Entra وAWS (S3/SQS/IAM). ليست نماذج وهمية - أجهزة كاملة الحالة حيث يظهر إنشاء العلاقات العامة ويظهر في القائمة. يُستخدم عند إعداد بيئات الاختبار، أو خطوط أنابيب CI، أو اختبارات التكامل، أو التطوير دون اتصال بالإنترنت.
