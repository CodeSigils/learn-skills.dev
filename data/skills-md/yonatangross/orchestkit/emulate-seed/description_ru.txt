Создайте начальные конфигурации эмуляции для эмуляции API с отслеживанием состояния. Обертывает инструмент эмуляции Vercel для API GitHub, Vercel, Google OAuth, Slack, Apple Auth, Microsoft Entra и AWS (S3/SQS/IAM). Не издевательства — полные государственные машины, в которых создается пиар, и он появляется в списке. Используйте при настройке тестовых сред, конвейеров CI, интеграционных тестов или автономной разработки.
