عناوين URL المسماة .localhost للتنمية المحلية بدون منفذ. يزيل تصادمات المنافذ، ويمكّن عناوين URL الثابتة للوكلاء، ويتكامل مع محاكاة الأسماء المستعارة لمحاكاة واجهة برمجة التطبيقات (API) وأشجار عمل git للنطاقات الفرعية ذات الأسماء الفرعية. يُستخدم عند إعداد بيئات التطوير المحلية، أو تكوين عناوين URL التي يمكن للوكيل الوصول إليها، أو تشغيل إعدادات التطوير متعددة الخدمات. لا تستخدمه لعمليات نشر الإنتاج، أو بيئات CI (اضبط PORTLESS=0)، أو تكوين DNS/الاستضافة.
