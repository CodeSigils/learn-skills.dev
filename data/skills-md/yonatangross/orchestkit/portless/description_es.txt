URL .localhost con nombre para desarrollo local sin puerto. Elimina las colisiones de puertos, habilita URL estables para los agentes, se integra con emulate para alias de emulación de API y árboles de trabajo de git para subdominios con nombres de sucursales. Úselo al configurar entornos de desarrollo local, configurar URL accesibles para agentes o ejecutar configuraciones de desarrollo multiservicio. NO lo use para implementaciones de producción, entornos de CI (establezca PORTLESS=0) o configuración de DNS/hosting.
