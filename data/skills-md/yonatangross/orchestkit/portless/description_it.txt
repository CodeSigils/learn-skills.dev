URL .localhost denominati per lo sviluppo locale con portless. Elimina le collisioni tra porte, abilita URL stabili per gli agenti, si integra con emulate per alias di emulazione API e alberi di lavoro git per sottodomini con nomi di rami. Da utilizzare durante la configurazione di ambienti di sviluppo locali, la configurazione di URL accessibili agli agenti o l'esecuzione di configurazioni di sviluppo multiservizio. NON utilizzare per distribuzioni di produzione, ambienti CI (impostare PORTLESS=0) o configurazione DNS/hosting.
