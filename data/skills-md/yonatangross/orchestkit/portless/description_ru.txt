Именованные URL-адреса .localhost для локальной разработки с использованием portless. Устраняет конфликты портов, обеспечивает стабильные URL-адреса для агентов, интегрируется с emulate для псевдонимов эмуляции API и рабочих деревьев git для поддоменов с именами ветвей. Используйте при настройке локальных сред разработки, настройке URL-адресов, доступных для агентов, или запуске настроек разработки с несколькими сервисами. НЕ используйте для производственных развертываний, сред CI (установите PORTLESS=0) или конфигурации DNS/хостинга.
