URL nommées .localhost pour le développement local avec portless. Élimine les collisions de ports, active des URL stables pour les agents, s'intègre avec émulation pour les alias d'émulation d'API et les arbres de travail git pour les sous-domaines nommés par branche. À utiliser lors de la configuration d'environnements de développement locaux, de la configuration d'URL accessibles aux agents ou de l'exécution de configurations de développement multiservices. Ne PAS utiliser pour les déploiements de production, les environnements CI (définir PORTLESS=0) ou la configuration DNS/hébergement.
