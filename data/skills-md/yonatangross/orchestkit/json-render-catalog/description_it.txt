Modelli di catalogo dei componenti di rendering json per un'interfaccia utente generativa sicura per l'intelligenza artificiale. Definisci cataloghi tipizzati Zod che limitano ciò che l'intelligenza artificiale può generare, utilizza @json-render/shadcn per 29 componenti predefiniti, ottimizza le specifiche per l'efficienza dei token con la modalità YAML. Da utilizzare durante la creazione di interfacce utente generate dall'intelligenza artificiale, la definizione di cataloghi di componenti o l'integrazione di json-render in progetti React/Vue/Svelte/React Native.
