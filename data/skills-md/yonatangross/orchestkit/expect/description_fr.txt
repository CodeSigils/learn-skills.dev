Tests de navigateur AI prenant en charge les différences : analyse les modifications de git, génère des plans de test ciblés et les exécute via un navigateur d'agent. Lit git diff pour déterminer ce qui a changé, mappe les modifications aux pages concernées via une feuille de route, génère un plan de test limité au diff et l'exécute avec des rapports de réussite/échec. À utiliser pour tester les modifications de l'interface utilisateur, vérifier les PR avant la fusion, exécuter des contrôles de régression sur les composants modifiés ou valider que les modifications récentes du code ne interrompent pas l'expérience utilisateur.
