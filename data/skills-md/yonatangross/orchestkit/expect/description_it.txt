Test del browser AI con riconoscimento delle differenze: analizza le modifiche git, genera piani di test mirati e li esegue tramite il browser dell'agente. Legge git diff per determinare cosa è cambiato, mappa le modifiche alle pagine interessate tramite la route map, genera un piano di test con ambito diff e lo esegue con report pass/fail. Da utilizzare durante il test delle modifiche dell'interfaccia utente, la verifica dei PR prima dell'unione, l'esecuzione di controlli di regressione sui componenti modificati o la verifica che le recenti modifiche al codice non interrompano l'esperienza rivolta all'utente.
