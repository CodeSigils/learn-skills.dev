Интеграция сервера Storybook MCP для разработки ИИ с учетом компонентов. Охватывает 6 инструментов из 3 наборов инструментов (разработка, документация, тестирование): обнаружение компонентов с помощью списка всей документации/получения документации, предварительный просмотр историй с помощью предварительных историй и автоматическое тестирование с помощью run-story-tests. Используйте при создании компонентов, которые должны повторно использовать существующие компоненты Storybook, запуске тестов компонентов через MCP или предварительном просмотре историй в чате.
