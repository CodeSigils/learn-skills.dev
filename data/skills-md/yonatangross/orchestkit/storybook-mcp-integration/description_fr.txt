Intégration du serveur Storybook MCP pour le développement d'IA prenant en compte les composants. Couvre 6 outils répartis dans 3 ensembles d'outils (développement, documentation, tests) : découverte de composants via list-all-documentation/get-documentation, aperçus d'histoires via des aperçus d'histoires et tests automatisés via des tests d'exécution d'histoires. À utiliser lors de la génération de composants devant réutiliser des composants Storybook existants, de l'exécution de tests de composants via MCP ou de la prévisualisation d'histoires dans le chat.
