Integrazione del server MCP Storybook per lo sviluppo di intelligenza artificiale consapevole dei componenti. Copre 6 strumenti in 3 set di strumenti (sviluppo, documenti, test): rilevamento dei componenti tramite list-all-documentation/get-documentation, anteprime delle storie tramite Preview-Story e test automatizzati tramite Run-Story-Test. Da utilizzare durante la generazione di componenti che dovrebbero riutilizzare componenti esistenti di Storybook, l'esecuzione di test dei componenti tramite MCP o l'anteprima delle storie in chat.
