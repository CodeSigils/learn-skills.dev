Générez et exécutez des suites de tests complètes : tests unitaires, tests d'intégration avec des services réels (testcontainers/docker-compose) et tests Playwright E2E. Analyse les écarts de couverture, génère des agents générateurs de tests parallèles par niveau, exécute des tests et corrige les échecs (max 3 itérations). À utiliser pour générer des tests pour le code existant, améliorer la couverture après la mise en œuvre ou créer une suite de tests complète à partir de zéro. Enchaîne naturellement après /ork:implement. Ne PAS utiliser pour vérifier/noter des tests existants (utilisez /ork:verify) ou exécuter des tests sans génération (utilisez directement npm test).
