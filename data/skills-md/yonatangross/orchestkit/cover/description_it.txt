Genera ed esegui suite di test complete: test unitari, test di integrazione con servizi reali (testcontainers/docker-compose) e test Playwright E2E. Analizza le lacune di copertura, genera agenti generatori di test paralleli per livello, esegue test e corregge gli errori (massimo 3 iterazioni). Da utilizzare quando si generano test per codice esistente, si migliora la copertura dopo l'implementazione o si crea una suite di test completa da zero. Catene naturalmente dopo /ork:implement. NON utilizzare per verificare/classificare test esistenti (utilizzare /ork:verify) o eseguire test senza generazione (utilizzare direttamente npm test).
