Generieren und führen Sie umfassende Testsuiten aus – Unit-Tests, Integrationstests mit echten Diensten (testcontainers/docker-compose) und Playwright-E2E-Tests. Analysiert Abdeckungslücken, erzeugt parallele Testgenerator-Agenten pro Ebene, führt Tests durch und behebt Fehler (maximal 3 Iterationen). Verwenden Sie es, wenn Sie Tests für vorhandenen Code generieren, die Abdeckung nach der Implementierung verbessern oder eine vollständige Testsuite von Grund auf erstellen. Verkettet sich natürlich nach /ork:implement. NICHT zum Überprüfen/Bewerten bestehender Tests (verwenden Sie /ork:verify) oder zum Ausführen von Tests ohne Generierung (verwenden Sie npm test direkt) verwenden.
