Canalización de maqueta a componente utilizando Google Stitch, 21st.dev y Storybook MCP. Acepta capturas de pantalla, descripciones o URL como entrada y produce componentes React listos para producción. Comprueba los componentes existentes de Storybook antes de generarlos, organiza la extracción del diseño a través de Stitch MCP, la coincidencia de componentes a través del registro 21st.dev, la adaptación a los tokens de diseño del proyecto y la verificación de autorreparación mediante pruebas de ejecución de historias. Úselo al convertir diseños visuales en código, implementar la interfaz de usuario a partir de maquetas o crear componentes a partir de capturas de pantalla.
