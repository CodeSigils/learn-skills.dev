Google Stitch, 21st.dev 및 Storybook MCP를 사용한 목업-컴포넌트 파이프라인. 스크린샷, 설명 또는 URL을 입력으로 받아들이고 프로덕션 준비가 완료된 React 구성 요소를 생성합니다. 생성하기 전에 기존 Storybook 구성 요소를 확인하고, Stitch MCP를 통한 디자인 추출, 21st.dev 레지스트리를 통한 구성 요소 매칭, 프로젝트 디자인 토큰에 대한 적응, 스토리 실행 테스트를 통한 자가 치유 검증을 조율합니다. 시각적 디자인을 코드로 변환하거나, 모형에서 UI를 구현하거나, 스크린샷에서 구성 요소를 구축할 때 사용합니다.
