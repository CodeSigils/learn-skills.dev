Конвейер перехода от макета к компоненту с использованием Google Stitch, 21st.dev и Storybook MCP. Принимает снимки экрана, описания или URL-адреса в качестве входных данных и создает готовые к использованию компоненты React. Проверяет существующие компоненты Storybook перед созданием, организует извлечение проекта с помощью Stitch MCP, сопоставление компонентов через реестр 21st.dev, адаптацию к токенам дизайна проекта и проверку самовосстановления с помощью тестов run-story. Используйте при преобразовании визуального дизайна в код, реализации пользовательского интерфейса из макетов или создании компонентов из снимков экрана.
