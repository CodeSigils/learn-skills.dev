Google Stitch、21st.dev、Storybook MCP を使用したモックアップからコンポーネントへのパイプライン。スクリーンショット、説明、または URL を入力として受け入れ、本番環境に対応した React コンポーネントを生成します。生成前に既存の Storybook コンポーネントをチェックし、Stitch MCP を介したデザイン抽出、21st.dev レジストリを介したコンポーネントのマッチング、プロジェクト デザイン トークンへの適応、および run-story-tests を介した自己修復検証を調整します。ビジュアルデザインをコードに変換する場合、モックアップから UI を実装する場合、またはスクリーンショットからコンポーネントを構築する場合に使用します。
