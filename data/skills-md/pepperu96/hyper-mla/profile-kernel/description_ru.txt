Рабочий процесс профилирования ядра графического процессора для поддерживаемых языков реализации ядра. Предоставляет команды для всех 4 режимов профилирования (аннотация, событие, ncu, nsys), таблицы интерпретации показателей, правила идентификации узких мест и выходной контракт для возврата компактных результатов оркестратору. Используйте при: (1) профилировании версии ядра, (2) интерпретации артефактов/отчетов профилирования, (3) сравнении версий ядра, (4) выявлении узких мест и возможностей оптимизации, (5) документировании производительности в журнале разработки.
