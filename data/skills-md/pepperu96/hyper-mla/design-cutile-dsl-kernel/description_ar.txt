أنماط تنفيذ kernel cuTile Python DSL، ومجمع وقت تشغيل CtKernel، وبوابة الملاءمة، والمزالق الخاصة بـ cuTile. يُستخدم عندما: (1) إنشاء أو تعديل إصدار نواة cuTile Python DSL، (2) تنفيذ التحسين الذي لا يزال يتناسب مع سطح التحكم المكشوف لـ cuTile، (3) تحديد ما إذا كان cuTile لا يزال هو DSL الصحيح، (4) مراجعة أنماط وقت التشغيل الخاصة بـ cuTile. قم دائمًا أيضًا بتحميل /design-kernel للتسمية المشتركة وإصدار الإصدارات وسير العمل.
