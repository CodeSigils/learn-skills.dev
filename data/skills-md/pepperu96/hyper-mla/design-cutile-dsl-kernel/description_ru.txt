Шаблоны реализации ядра Python DSL cuTile, оболочка среды выполнения CtKernel, шлюз пригодности и подводные камни, специфичные для cuTile. Используйте при: (1) создании или изменении версии ядра Python DSL cuTile, (2) реализации оптимизации, которая по-прежнему вписывается в открытую поверхность управления cuTile, (3) принятии решения, является ли cuTile по-прежнему подходящим DSL, (4) анализе шаблонов времени выполнения, специфичных для cuTile. Всегда также загружайте /design-kernel для совместного именования, управления версиями и рабочего процесса.
