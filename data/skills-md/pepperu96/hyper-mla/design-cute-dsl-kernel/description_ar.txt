سير عمل نواة CuTe Python DSL، وغلاف وقت تشغيل CuteKernel، وبوابة الملاءمة، وتوجيهات التبليط، والمزالق الخاصة بـ CuTe. يُستخدم عندما: (1) تخطيط أو تنفيذ kernel في CuTe Python DSL، (2) يحتاج التحسين إلى تحكم أكثر وضوحًا مما يعرضه cuTile ولكن يجب أن يظل في سير عمل يعتمد على Python، (3) تحديد تسمية الحزمة لنواة Cute-dsl، (4) توثيق اختيارات تصميم CuTe Python DSL، (5) تسجيل المعرفة الخاصة باللغة لـ CuTe Python DSL.
