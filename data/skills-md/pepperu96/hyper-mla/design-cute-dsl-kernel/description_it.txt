Flusso di lavoro del kernel DSL CuTe Python, wrapper runtime CuteKernel, gate di idoneità, guida all'affiancamento e insidie ​​specifiche di CuTe. Da utilizzare quando: (1) si pianifica o si implementa un kernel nel CuTe Python DSL, (2) l'ottimizzazione richiede un controllo più esplicito rispetto a quello esposto da cuTile ma dovrebbe rimanere in un flusso di lavoro basato su Python, (3) si definisce la denominazione del pacchetto per i kernel cute-dsl, (4) si documentano le scelte di progettazione di CuTe Python DSL, (5) si registrano le conoscenze specifiche del linguaggio per CuTe Python DSL.
