CuTe Python DSL-Kernel-Workflow, CuteKernel-Laufzeit-Wrapper, Eignungs-Gate, Kachelanleitung und CuTe-spezifische Fallstricke. Wird verwendet, wenn: (1) ein Kernel im CuTe Python DSL geplant oder implementiert wird, (2) die Optimierung eine explizitere Kontrolle erfordert, als cuTile verfügbar macht, aber in einem Python-gesteuerten Workflow bleiben sollte, (3) Paketbenennung für Cute-DSL-Kernel definiert, (4) CuTe Python DSL-Entwurfsentscheidungen dokumentiert, (5) sprachspezifisches Wissen für CuTe Python DSL aufzeichnet.
