Рабочий процесс ядра CuTe Python DSL, оболочка среды выполнения CuteKernel, шлюз пригодности, руководство по мозаике и подводные камни, специфичные для CuTe. Используйте, когда: (1) планирование или реализация ядра в CuTe Python DSL, (2) оптимизация требует более явного контроля, чем предоставляет cuTile, но должна оставаться в рабочем процессе, управляемом Python, (3) определение имен пакетов для ядер cute-dsl, (4) документирование вариантов дизайна CuTe Python DSL, (5) запись знаний о конкретном языке для CuTe Python DSL.
