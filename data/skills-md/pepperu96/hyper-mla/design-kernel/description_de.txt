Gemeinsamer Kernel-Design-Workflow für alle unterstützten Sprachen und DSLs. Bietet eine Sprachauswahltabelle, Namenskonventionen, Versionierungsregeln, KernelPlan-Struktur, Kompositionsmuster, Klon-Workflow, Implementierungs-Workflow, Devlog-Vorlage und Designer-Ausgabevertrag. Verwenden Sie diese Option, wenn: (1) Sie auswählen, welche sprachspezifische Kernel-Design-Fähigkeit geladen werden soll, (2) die beabsichtigte Implementierungssprache noch nicht festgelegt ist, (3) Sie Benennungs- oder Versionierungshinweise benötigen, bevor Sie eine DSL auswählen, (4) Sie einen beliebigen Kernel implementieren, unabhängig von der DSL, (5) Sie Dokumente aktualisieren, die sich auf Kernel-Design-Fähigkeiten beziehen.
