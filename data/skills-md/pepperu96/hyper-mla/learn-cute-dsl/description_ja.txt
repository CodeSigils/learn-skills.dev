CUTLASS Blackwell サンプル カーネルから再利用可能なパターンを読み取り、インポート、プロファイリング、抽出することによって CuTe Python DSL を学習するためのワークフロー。次の場合に使用します: (1) CUTLASS CuTe DSL リファレンス実装を学習する、(2) CUTLASS サンプルをプロジェクト ランタイム インフラストラクチャにインポートする、(3) プロファイリング実験から CuTe DSL ナレッジ ベース エントリを構築する、(4) CuTe DSL API パターン、TMA パイプライン、ワープグループ スケジューリング、または永続的なカーネル構造を理解する。
