Flusso di lavoro per l'apprendimento di CuTe Python DSL leggendo, importando, profilando ed estraendo modelli riutilizzabili dai kernel di esempio CUTLASS Blackwell. Utilizzare quando: (1) studiare le implementazioni di riferimento CUTLASS CuTe DSL, (2) importare esempi CUTLASS nell'infrastruttura di runtime del progetto, (3) creare voci della knowledge base CuTe DSL da esperimenti di profilazione, (4) comprendere modelli API CuTe DSL, pipeline TMA, pianificazione warpgroup o struttura del kernel persistente.
