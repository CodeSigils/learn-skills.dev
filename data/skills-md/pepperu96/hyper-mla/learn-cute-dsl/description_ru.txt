Рабочий процесс изучения CuTe Python DSL путем чтения, импорта, профилирования и извлечения повторно используемых шаблонов из примеров ядер CUTLASS Blackwell. Используйте при: (1) изучении эталонных реализаций CUTLASS CuTe DSL, (2) импорте примеров CUTLASS в инфраструктуру времени выполнения проекта, (3) создании записей базы знаний CuTe DSL на основе экспериментов по профилированию, (4) понимании шаблонов API CuTe DSL, конвейерной обработки TMA, планирования варп-групп или постоянной структуры ядра.
