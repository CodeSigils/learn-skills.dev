Flujo de trabajo para aprender CuTe Python DSL mediante la lectura, importación, creación de perfiles y extracción de patrones reutilizables de núcleos de ejemplo de CUTLASS Blackwell. Úselo cuando: (1) estudie implementaciones de referencia de CUTLASS CuTe DSL, (2) importe ejemplos de CUTLASS a la infraestructura de ejecución del proyecto, (3) cree entradas de la base de conocimientos de CuTe DSL a partir de experimentos de creación de perfiles, (4) comprenda los patrones de API de CuTe DSL, la canalización TMA, la programación de grupos warp o la estructura persistente del kernel.
