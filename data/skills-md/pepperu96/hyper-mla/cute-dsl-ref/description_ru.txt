Справочник по CuTe Python DSL API и шаблоны реализации для программирования ядра NVIDIA GPU. Предоставляет модель выполнения, базовую таблицу API, ключевые ограничения, общие шаблоны и указатель документации. Используйте, когда: (1) пишете или изменяете код ядра CuTe DSL, (2) ищете синтаксис API CuTe DSL, (3) реализуете шаблоны внимания/GEMM/MLA в CuTe DSL, (4) понимаете модель выполнения CuTe DSL и конвейер компиляции, (5) проверяете, что CuTe DSL может и не может делать.
