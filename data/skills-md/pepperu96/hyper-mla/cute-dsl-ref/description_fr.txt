Référence de l'API CuTe Python DSL et modèles d'implémentation pour la programmation du noyau GPU NVIDIA. Fournit un modèle d'exécution, une table API principale, des contraintes clés, des modèles communs et un index de documentation. À utiliser lorsque : (1) écrire ou modifier le code du noyau CuTe DSL, (2) rechercher la syntaxe de l'API CuTe DSL, (3) implémenter des modèles d'attention/GEMM/MLA dans CuTe DSL, (4) comprendre le modèle d'exécution et le pipeline de compilation de CuTe DSL, (5) vérifier ce que CuTe DSL peut et ne peut pas faire.
