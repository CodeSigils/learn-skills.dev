أنماط CuTe Python DSL API المرجعية والتنفيذية لبرمجة نواة NVIDIA GPU. يوفر نموذج التنفيذ وجدول API الأساسي والقيود الرئيسية والأنماط الشائعة وفهرس الوثائق. يُستخدم عندما: (1) كتابة أو تعديل كود kernel لـ CuTe DSL، (2) البحث عن بناء جملة CuTe DSL API، (3) تنفيذ أنماط الانتباه/GEMM/MLA في CuTe DSL، (4) فهم نموذج تنفيذ CuTe DSL وخط أنابيب التجميع، (5) التحقق مما يمكن لـ CuTe DSL فعله وما لا يمكنه فعله.
