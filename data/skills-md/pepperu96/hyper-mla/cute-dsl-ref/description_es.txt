Patrones de implementación y referencia de la API CuTe Python DSL para la programación del kernel de GPU NVIDIA. Proporciona un modelo de ejecución, una tabla de API principal, restricciones clave, patrones comunes e índice de documentación. Úselo cuando: (1) escriba o modifique el código del kernel de CuTe DSL, (2) busque la sintaxis de la API de CuTe DSL, (3) implemente patrones de atención/GEMM/MLA en CuTe DSL, (4) comprenda el modelo de ejecución de CuTe DSL y el proceso de compilación, (5) compruebe lo que CuTe DSL puede y no puede hacer.
