Общее руководство по оптимизации и наложения CuTe Python DSL. Используйте, когда: (1) выбирают оптимизацию для ядра CuTe Python DSL, (2) решают, является ли результат общим или специфичным для cute-dsl, (3) записывают замечания по реализации CuTe Python DSL, (4) рассматривают структуру знаний для работы cute-dsl, (5) отображают общие шаблоны на поверхность реализации CuTe Python DSL.
