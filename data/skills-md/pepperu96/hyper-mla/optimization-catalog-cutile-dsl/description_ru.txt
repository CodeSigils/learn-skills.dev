Общее руководство по оптимизации плюс наложения cuTile Python DSL. Используйте, когда: (1) выбираете оптимизации для ядра Python DSL cuTile, (2) проверяете ловушки реализации, специфичные для cuTile, (3) решаете, относится ли результат профилирования к общим знаниям или наложению cuTile, (4) обновляете документацию по оптимизации cuTile Python DSL, (5) проверяете, как общий шаблон сопоставляется с cuTile.
