Audita los archivos de código fuente en busca de patrones de desperdicio generados por IA: comentarios innecesarios, ingeniería excesiva, sobrecodificación defensiva, marcadores de voz de IA, código inactivo, soluciones alternativas de tipos y patrones detallados. Genera un informe estructurado con referencias de línea y gravedad. Úselo cuando el usuario quiera auditar el código para detectar fallas de IA, verificar la calidad del código, encontrar comentarios innecesarios, detectar ingeniería excesiva o solicite "auditar esto", "verificar fallas", "anti-derivaciones", "revisar patrones de IA".
