Шаблон структуры проекта Bulletproof Expo для приложений React Native. Обеспечивает тонкий уровень маршрутизации, функциональные модули, правила направления зависимостей и соглашения Expo Router. Используйте при создании файлов, создании функций или принятии архитектурных решений в любом проекте Expo/React Native.
