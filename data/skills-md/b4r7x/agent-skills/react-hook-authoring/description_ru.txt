Используйте при написании, проверке или разработке пользовательских перехватчиков React для библиотек компонентов. Охватывает решения по запоминанию, потребительский DX, контролируемые/неконтролируемые шаблоны и стабильность функций. Предотвращает чрезмерное проектирование — начните с простого, добавляйте сложность только тогда, когда этого требует профилировщик. Этот навык следует использовать при создании хуков, которые будут использовать другие разработчики.
