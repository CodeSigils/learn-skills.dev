Проверяет пользовательские перехватчики React на наличие чрезмерного проектирования, проблем с запоминанием, проблем потребительского DX и известных антишаблонов, а затем применяет исправления. Используйте, когда пользователь хочет проверить перехватчики, исправить шаблоны перехватчиков, очистить запоминание или спрашивает «проверить перехватчики», «исправить перехватчики», «проверить мои перехватчики». Применяет принципы авторского реагирования.
