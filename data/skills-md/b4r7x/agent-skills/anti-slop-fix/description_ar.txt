تشغيل تدقيق مكافحة الانزلاق على ملفات التعليمات البرمجية المصدر وتطبيق الإصلاحات تلقائيًا للمشكلات المكتشفة. يستدعي تحليل مقاومة الانزلاق أولاً، ثم يصلح كل مشكلة في مكانها. يُستخدم عندما يريد المستخدم تنظيف انحدار الذكاء الاصطناعي تلقائيًا، أو إصلاح أنماط انحدار، أو يسأل "إصلاح انحدار"، أو "رمز التنظيف"، أو "إصلاح تلقائي انحدار"، أو "إصلاح مضاد انحدار".
