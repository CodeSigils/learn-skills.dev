Запускает проверку отсутствия ошибок в файлах исходного кода и автоматически применяет исправления для обнаруженных проблем. Сначала вызывает анализ предотвращения ошибок, а затем устраняет каждую проблему на месте. Используйте, когда пользователь хочет автоматически устранить ошибки ИИ, исправить шаблоны ошибок или запрашивает «исправить ошибки», «очистить код», «автоматическое исправление ошибок», «исправить антиспам».
