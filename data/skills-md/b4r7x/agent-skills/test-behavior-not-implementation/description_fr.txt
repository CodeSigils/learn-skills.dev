Philosophie de test basée sur le Testing Trophy de Kent C. Dodds et les principes de test de TkDodo. Applique des tests basés sur le comportement, une discipline moqueuse, des requêtes accessibles et le principe « moins de meilleurs tests ». À utiliser lors de l'écriture, de la révision ou de l'audit de tests dans n'importe quel projet TypeScript/React. Déclencheurs sur les fichiers de test, les commandes de test ou les mentions de stratégie de test.
