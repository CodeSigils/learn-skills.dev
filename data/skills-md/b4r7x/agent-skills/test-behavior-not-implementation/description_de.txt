Die Testphilosophie basiert auf der Testing Trophy von Kent C. Dodds und den Testprinzipien von TkDodo. Erzwingt verhaltensbasiertes Testen, spöttische Disziplin, zugängliche Abfragen und das Prinzip „Weniger bessere Tests“. Zum Schreiben, Überprüfen oder Prüfen von Tests in einem beliebigen TypeScript/React-Projekt. Löst auf Testdateien, Testbefehlen oder Erwähnungen einer Teststrategie aus.
