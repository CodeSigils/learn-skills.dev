Высокопроизводительный механизм анализа для наборов данных Excel, содержащих более десяти тысяч строк. Обеспечивает потоковое чтение openpyxl read_only (iter_rows поддерживает более 100 000 строк), ускорение преобразования Parquet, оптимизацию памяти, фрагментированную обработку и режим записи больших файлов. **Активно используйте этот навык при выполнении любого из следующих условий**: ① Количество строк данных ≥ 10 тыс. (инициируется этапом оценки количества строк рабочего процесса sn-da-excel-); ② Пользователь использует слова-триггеры: большой файл / большой объем данных / оптимизация производительности / недостаточно памяти / OOM / миллион строк / сто тысяч строк / потоковое чтение / паркет / фрагментированная обработка / большой файл / большие данные / потоковое чтение / фрагментированная обработка; ③ Прямое использование pd.read_excel() приводит к таймауту или переполнению памяти; ④ Пользователь явно запрашивает высокопроизводительную обработку крупномасштабных наборов данных. Неприменимо для: обычного анализа Excel с количеством строк менее 10 тыс. (вместо этого используйте рабочий процесс sn-da-excel-).
