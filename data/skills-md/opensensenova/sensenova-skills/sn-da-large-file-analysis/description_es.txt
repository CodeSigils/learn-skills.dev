Un motor de análisis de alto rendimiento para conjuntos de datos de Excel con más de diez mil filas. Ofrece lecturas de streaming openpyxl read_only (iter_rows admite más de 100.000 filas), conversión acelerada de Parquet, optimización de la memoria, procesamiento fragmentado y modo de escritura de archivos grandes. **Utilice esta habilidad de forma proactiva siempre que se aplique cualquiera de las siguientes situaciones**: (1) el conjunto de datos tiene ≥10.000 filas (activado por el paso de evaluación del recuento de filas en sn-da-excel-workflow); (2) el usuario menciona términos desencadenantes como archivo grande / gran volumen de datos / optimización del rendimiento / memoria insuficiente / OOM / millones de filas / cien mil filas / lectura en streaming / Parquet / procesamiento fragmentado / archivo grande / big data / lectura en streaming / procesamiento fragmentado; (3) el uso directo de pd.read_excel() provoca un tiempo de espera o un desbordamiento de la memoria; (4) el usuario solicita explícitamente un manejo de alto rendimiento de un conjunto de datos masivo. No se aplica al análisis normal de Excel de menos de 10 000 filas (en su lugar, utilice sn‑da‑excel‑workflow).
