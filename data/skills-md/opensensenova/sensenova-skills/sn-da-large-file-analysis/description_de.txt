Eine leistungsstarke Analyse-Engine für Excel-Datensätze mit mehr als zehntausend Zeilen. Es bietet openpyxl read_only-Streaming-Lesevorgänge (iter_rows unterstützt über 100.000 Zeilen), beschleunigte Parquet-Konvertierung, Speicheroptimierung, Chunked-Verarbeitung und einen Schreibmodus für große Dateien. **Verwenden Sie diesen Skill proaktiv, wenn eine der folgenden Bedingungen erfüllt ist**: ① Der Datensatz enthält ≥10.000 Zeilen (ausgelöst durch den Zeilenanzahl-Auswertungsschritt von sn-da-excel-workflow); ② Der Benutzer erwähnt Auslöserbegriffe wie große Datei / großes Datenvolumen / Leistungsoptimierung / unzureichender Speicher / OOM / Millionen Zeilen / hunderttausend Zeilen / Streaming-Lesevorgang / Parquet / Chunked-Verarbeitung / große Datei / Big Data / Streaming-Lesevorgang / Chunked-Verarbeitung; ③ Die direkte Verwendung von ofpd.read_excel() führt zu einer Zeitüberschreitung oder einem Speicherüberlauf. ④ Der Benutzer fordert explizit eine leistungsstarke Verarbeitung eines riesigen Datensatzes an. Nicht anwendbar für: routinemäßige Excel-Analyse von weniger als 10.000 Zeilen (verwenden Sie stattdessen sn-da-excel-workflow).
