Un motore di analisi ad alte prestazioni per set di dati Excel con più di diecimila righe. Fornisce lettura in streaming openpyxl read_only (iter_rows supporta oltre 100.000 righe), conversione Parquet accelerata, ottimizzazione della memoria, elaborazione in blocchi e modalità di scrittura di file di grandi dimensioni. **Utilizzare in modo proattivo questa competenza ogni volta che viene soddisfatta una delle seguenti condizioni**: ① Conteggio delle righe di dati≥10k (attivato dalla fase di valutazione del conteggio delle righe del flusso di lavoro sn-da-excel); ② L'utente utilizza termini di trigger come file di grandi dimensioni/volume di dati di grandi dimensioni/ottimizzazione delle prestazioni/memoria insufficiente/OOM/milioni di righe/centomila righe/lettura in streaming/Parquet/elaborazione in blocchi/file di grandi dimensioni/big data/lettura in streaming/elaborazione in blocchi; ③ L'uso diretto di pd.read_excel() porta al timeout o all'overflow della memoria; ④ L'utente richiede esplicitamente un'elaborazione ad alte prestazioni di un enorme set di dati. Non applicabile: analisi Excel regolare con meno di 10.000 righe (utilizza invece sn-da-excel-workflow).
