A skill for generating or editing the final Markdown research report based on existing research materials or drafts. Use it in the following situations: (1) when deep‑research outputs such as `synthesis.md`, `plan.json`, and `sub_reports/*.md` already exist and need to be compiled into a final `report.md`; (2) when existing reports, drafts, or manuscript files need to be rewritten, revised, polished, compressed, expanded, restructured, have their abstracts enhanced, or have tables/figures added; (3) when you need to proactively plan and insert visual elements—Markdown tables, Mermaid diagrams, AI‑concept illustrations, etc.—during the report finalization stage. This is intended solely for final‑draft generation and targeted manuscript editing; it is not for zero‑base research, research planning, online evidence gathering, multi‑dimensional studies, or generating `synthesis.md`. If the user merely requests “deep research/investigation/write a research report” without existing materials, `sn-deep-research` should be used as the primary option.
