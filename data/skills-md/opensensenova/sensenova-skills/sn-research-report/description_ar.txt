مهارة إنشاء أو تعديل تقرير بحث Markdown النهائي بناءً على المواد البحثية أو المسودات الموجودة. استخدمه في المواقف التالية: 1) يجب تجميع عناصر البحث العميق الموجودة مثل ` Synthesis.md` و `plan.json` و`sub_reports/*.md` في `report.md` نهائي؛ 2) يتطلب تقرير أو مسودة أو مسار مخطوطة إعادة كتابة أو مراجعة أو تلميع أو تكثيف أو توسيع أو إعادة هيكلة أو تحسين الملخص أو إضافة جداول/أشكال؛ 3) تحتاج إلى التخطيط بشكل استباقي وإدراج جداول Markdown ومخططات حورية البحر والرسوم التوضيحية لمفاهيم الذكاء الاصطناعي والعناصر المرئية الأخرى أثناء مرحلة الانتهاء من التقرير. وهذا مخصص فقط لإعداد التقرير النهائي وتحرير المخطوطات المستهدفة؛ إنه ليس للبحث الصفري، أو تخطيط البحث، أو جمع الأدلة عبر الإنترنت، أو البحث متعدد الأبعاد، أو توليد "SYNTH.MD". إذا طلب المستخدم ببساطة "بحثًا عميقًا/تحقيقًا/كتابة تقرير بحثي" وليس لديه مواد موجودة، فيجب استخدام "sn-deep-research" بشكل تفضيلي.
