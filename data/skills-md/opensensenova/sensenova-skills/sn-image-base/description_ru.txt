Навыки базового уровня для проекта SenseNova-Skills, предоставляющие низкоуровневые API для создания изображений, распознавания (VLM) и оптимизации текста (LLM).
Этот навык не выполняет предварительную обработку входных данных; он только вызывает серверные службы и возвращает результаты.
Этот навык не предназначен для пользователя и предназначен только для навыков верхнего уровня.
