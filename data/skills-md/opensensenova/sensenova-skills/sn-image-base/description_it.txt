Competenza di livello base per il progetto SenseNova-Skills, che fornisce API di basso livello per la generazione, il riconoscimento (VLM) e l'ottimizzazione del testo (LLM) di immagini.
Questa abilità non preelabora gli input; chiama solo servizi di backend e restituisce risultati.
Questa abilità non è rivolta all'utente ed è destinata solo alle abilità di livello superiore.
