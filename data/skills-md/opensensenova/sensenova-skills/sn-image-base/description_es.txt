Habilidad de capa base para el proyecto SenseNova-Skills, que proporciona API de bajo nivel para generación, reconocimiento (VLM) y optimización de texto (LLM) de imágenes.
Esta habilidad no preprocesa las entradas; solo llama a servicios de backend y devuelve resultados.
Esta habilidad no está orientada al usuario y está destinada únicamente a habilidades de nivel superior.
