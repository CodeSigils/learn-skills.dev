Compétence de couche de base pour le projet SenseNova-Skills, fournissant des API de bas niveau pour la génération d'images, la reconnaissance (VLM) et l'optimisation de texte (LLM).
Cette compétence ne prétraite pas les entrées ; il appelle uniquement les services backend et renvoie les résultats.
Cette compétence n'est pas destinée à l'utilisateur et est destinée uniquement aux compétences de niveau supérieur.
