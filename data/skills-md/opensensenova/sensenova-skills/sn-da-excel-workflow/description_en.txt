Excel data analysis multi-step orchestrator. Covers: (1) reading multi‑sheet Excel files and counting rows, (2) large‑file detection (≥10k rows automatic Parquet optimization), (3) data cleaning (missing values, text standardization, invalid characters), (4) conditional filtering and categorical extraction, (5) cross‑sheet statistical aggregation, (6) exporting Excel/CSV and providing download links. Encompasses the entire workflow from data ingestion to report generation, orchestrated step‑by‑step as a capability sub‑skill. **When any of the following situations occurs, proactively use this skill instead of writing a few lines of pandas to answer**: ① The user includes trigger terms: Excel analysis / spreadsheet analysis / data analysis / data cleaning / data statistics / data filtering / data visualization / data export / summary statistics / pivot table / group statistics / cross analysis / trend analysis / comparative analysis / outlier detection / deduplication / missing‑value handling / Excel report / report generation / analyze Excel / data analysis / data cleaning / pivot table; ② The user uploads or specifies a .xlsx / .xls / .csv file and requests analysis, cleaning, statistics, or visualization; ③ The task involves any of multi‑sheet reading, conditional filtering, categorical summarization, or chart generation; ④ The user requests an exported formatted Excel report or a download link. Not applicable for: pure text processing that does not involve tabular data, image analysis (use sn‑da‑image‑caption), simple Q&A that only requires a single formula calculation.
