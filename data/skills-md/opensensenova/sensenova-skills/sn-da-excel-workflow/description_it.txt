Orchestratore multifase per l'analisi dei dati Excel. Comprende: (1) lettura di file Excel multifoglio e conteggio delle righe, (2) rilevamento di file di grandi dimensioni (ottimizzazione automatica Parquet di ≥10.000 righe), (3) pulizia dei dati (valori mancanti, standardizzazione del testo, caratteri non validi), (4) filtraggio condizionale ed estrazione di categorie, (5) aggregazione statistica tra fogli, (6) esportazione di Excel/CSV e fornitura di collegamenti per il download. Comprende l'intero flusso di lavoro, dall'acquisizione dei dati alla generazione di report, orchestrando le capacità secondarie passo dopo passo. **Se si verifica una delle seguenti situazioni, utilizzare in modo proattivo questa abilità e non rispondere scrivendo poche righe di panda**: ① Parole chiave attivate dall'utente: analisi Excel / analisi delle tabelle / analisi dei dati / pulizia dei dati / statistiche dei dati / filtraggio dei dati / visualizzazione dei dati / esportazione dei dati / statistiche di riepilogo / tabella pivot / statistiche di gruppo / analisi incrociata / analisi delle tendenze / analisi comparativa / rilevamento di valori anomali / deduplicazione / gestione dei valori mancanti / report Excel / generazione di report / analisi Excel / analisi dei dati / pulizia dei dati / tabella pivot; ② L'utente carica o specifica un file .xlsx / .xls / .csv e richiede analisi, pulizia, statistiche o visualizzazione; ③ L'attività prevede la lettura di più fogli, il filtraggio condizionale, l'aggregazione di categorie o la generazione di grafici; ④ L'utente richiede l'esportazione di un report Excel formattato o un collegamento per il download. Non applicabile: pura elaborazione del testo non correlata ai dati tabulari, analisi delle immagini (utilizzare la didascalia dell'immagine sn‑da), semplici domande e risposte sul calcolo di una singola formula.
