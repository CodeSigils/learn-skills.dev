Orchestrateur multi-étapes d’analyse de données Excel. Couvre : (1) la lecture de fichiers Excel multi-feuilles et le comptage des lignes, (2) la détection de fichiers volumineux (≥10 000 lignes optimisation automatique de Parquet), (3) le nettoyage des données (valeurs manquantes, normalisation du texte, caractères invalides), (4) le filtrage conditionnel et l'extraction catégorielle, (5) l'agrégation statistique multi-feuilles, (6) l'exportation d'Excel/CSV et la fourniture de liens de téléchargement. Englobe l’ensemble du flux de travail, de l’ingestion des données à la génération de rapports, orchestré étape par étape en tant que sous-compétence de capacité. **Lorsque l'une des situations suivantes se produit, utilisez cette compétence de manière proactive au lieu d'écrire quelques lignes de pandas pour répondre** : ① L'utilisateur inclut des termes déclencheurs : analyse Excel / analyse de feuille de calcul / analyse de données / nettoyage des données / statistiques de données / filtrage des données / visualisation des données / exportation de données / statistiques récapitulatives / tableau croisé dynamique / statistiques de groupe / analyse croisée / analyse des tendances / analyse comparative / détection des valeurs aberrantes / déduplication / gestion des valeurs manquantes / rapport Excel / génération de rapport / analyse Excel / analyse des données / nettoyage des données / tableau croisé dynamique ; ② L'utilisateur télécharge ou spécifie un fichier .xlsx / .xls / .csv et demande une analyse, un nettoyage, des statistiques ou une visualisation ; ③ La tâche implique la lecture de plusieurs feuilles, le filtrage conditionnel, le résumé catégoriel ou la génération de graphiques ; ④ L'utilisateur demande un rapport Excel formaté exporté ou un lien de téléchargement. Non applicable pour : le traitement de texte pur qui n'implique pas de données tabulaires, l'analyse d'images (utilisez sn‑da‑image‑caption), les questions et réponses simples qui ne nécessitent qu'une seule formule de calcul.
