Многоэтапный оркестратор анализа данных Excel. Охватывает: (1) чтение многостраничных файлов Excel и подсчет строк, (2) обнаружение больших файлов (автоматическая оптимизация паркета более 10 тысяч строк), (3) очистка данных (пропущенные значения, стандартизация текста, недопустимые символы), (4) условная фильтрация и извлечение категорий, (5) статистическое агрегирование между таблицами, (6) экспорт Excel/CSV и предоставление ссылок для скачивания. Охватывает весь рабочий процесс от приема данных до создания отчетов, поэтапно организованный в виде дополнительных навыков. **При возникновении любой из следующих ситуаций активно используйте этот навык и не отвечайте, написав несколько строк панд**: ① Пользователь запускает ключевые слова: анализ Excel / анализ таблицы / анализ данных / очистка данных / статистика данных / фильтрация данных / визуализация данных / экспорт данных / сводная статистика / сводная таблица / групповая статистика / перекрестный анализ / анализ тенденций / сравнительный анализ / обнаружение выбросов / обработка отсутствующих значений / отчет Excel / генерация отчета / анализ Excel / анализ данных / очистка данных / сводная таблица; ② Пользователь загружает или указывает файл .xlsx/.xls/.csv и запрашивает анализ, очистку, статистику или визуализацию; ③ Задача включает в себя чтение нескольких листов, условную фильтрацию, суммирование категорий или создание диаграмм; ④ Пользователь запрашивает экспорт отформатированного отчета Excel или ссылку для скачивания. Не применимо для: обработки чистого текста, не связанной с табличными данными, анализа изображений (используйте sn-da-image-caption), простых вопросов и ответов по поводу расчета по одной формуле.
