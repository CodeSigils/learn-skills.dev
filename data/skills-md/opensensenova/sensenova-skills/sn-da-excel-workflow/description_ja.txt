Excel データ分析のマルチステップ オーケストレーター。対象範囲: (1) 複数シートの Excel ファイルの読み取りと行のカウント、(2) 大きなファイルの検出 (10,000 行以上の自動 Parquet 最適化)、(3) データ クリーニング (欠損値、テキストの標準化、無効な文字)、(4) 条件付きフィルタリングとカテゴリ抽出、(5) クロスシートの統計集計、(6) Excel/CSV のエクスポートとダウンロード リンクの提供。データの取り込みからレポートの生成までのワークフロー全体を網羅し、機能のサブスキルとして段階的に調整されます。 **次のいずれかの状況が発生した場合は、数行のパンダで回答する代わりに、このスキルを積極的に使用してください**: ① ユーザーにトリガー用語が含まれています: Excel 分析 / スプレッドシート分析 / データ分析 / データ クリーニング / データ統計 / データ フィルタリング / データ視覚化 / データ エクスポート / 概要統計 / ピボット テーブル / グループ統計 / クロス分析 / 傾向分析 / 比較分析 / 外れ値検出 / 重複排除 / 欠損値処理 / Excel レポート / レポート生成 / Excel 分析 / データ分析 / データ クリーニング / ピボットテーブル。 ② ユーザーは、.xlsx / .xls / .csv ファイルをアップロードまたは指定して、分析、クリーニング、統計、または視覚化を要求します。 ③ タスクには、複数枚の読み取り、条件付きフィルタリング、カテゴリ別要約、またはグラフ生成のいずれかが含まれます。 ④ ユーザーは、エクスポートされた形式の Excel レポートまたはダウンロード リンクを要求します。以下には適用されません: 表形式データを含まない純粋なテキスト処理、画像分析 (sn-da-image-caption を使用)、単一の数式計算のみを必要とする単純な Q&A。
