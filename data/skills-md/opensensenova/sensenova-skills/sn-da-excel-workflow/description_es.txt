Orquestador de varios pasos de análisis de datos de Excel. Cubre: (1) lectura de archivos Excel de varias hojas y recuento de filas, (2) detección de archivos grandes (optimización automática de Parquet de ≥10.000 filas), (3) limpieza de datos (valores faltantes, estandarización de texto, caracteres no válidos), (4) filtrado condicional y extracción categórica, (5) agregación estadística entre hojas, (6) exportación a Excel/CSV y suministro de enlaces de descarga. Abarca todo el flujo de trabajo, desde la ingesta de datos hasta la generación de informes, organizado paso a paso como una subhabilidad de capacidad. **Si ocurre alguna de las siguientes situaciones, use esta habilidad de manera proactiva y no responda escribiendo algunas líneas de pandas**: ① El usuario incluye palabras desencadenantes: análisis de Excel / análisis de hoja de cálculo / análisis de datos / limpieza de datos / estadísticas de datos / filtrado de datos / visualización de datos / exportación de datos / estadísticas resumidas / tabla dinámica / estadísticas de grupo / análisis cruzado / análisis de tendencias / análisis comparativo / detección de valores atípicos / deduplicación / manejo de valores faltantes / informe de Excel / generación de informes / análisis de Excel / análisis de datos / limpieza de datos / tabla dinámica; ② El usuario carga o especifica un archivo .xlsx/.xls/.csv y solicita análisis, limpieza, estadísticas o visualización; ③ La tarea implica lectura de varias hojas, filtrado condicional, resumen categórico o generación de gráficos; ④ El usuario solicita un informe Excel formateado exportado o un enlace de descarga. No aplicable: procesamiento de texto puro que no involucra datos tabulares, análisis de imágenes (use sn-da-image-caption), preguntas y respuestas simples que solo requieren un cálculo de fórmula única.
