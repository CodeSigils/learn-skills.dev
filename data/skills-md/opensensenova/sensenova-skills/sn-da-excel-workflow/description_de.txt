Mehrstufiger Orchestrator für die Excel-Datenanalyse. Behandelt: (1) Lesen von Excel-Dateien mit mehreren Blättern und Zählen von Zeilen, (2) Erkennung großer Dateien (automatische Parquet-Optimierung von ≥ 10.000 Zeilen), (3) Datenbereinigung (fehlende Werte, Textstandardisierung, ungültige Zeichen), (4) bedingte Filterung und kategoriale Extraktion, (5) blattübergreifende statistische Aggregation, (6) Excel/CSV-Export und Bereitstellung von Download-Links. Umfasst den gesamten Arbeitsablauf von der Datenerfassung bis zur Berichtserstellung und wird Schritt für Schritt als Teilfähigkeit einer Fähigkeit orchestriert. **Wenn eine der folgenden Situationen auftritt, nutzen Sie diesen Skill proaktiv, anstatt ein paar Zeilen Pandas zu schreiben, um zu antworten**: ① Der Benutzer gibt Auslösebegriffe ein: Excel-Analyse / Tabellenkalkulationsanalyse / Datenanalyse / Datenbereinigung / Datenstatistik / Datenfilterung / Datenvisualisierung / Datenexport / zusammenfassende Statistik / Pivot-Tabelle / Gruppenstatistik / Kreuzanalyse / Trendanalyse / Vergleichsanalyse / Ausreißererkennung / Deduplizierung / Behandlung fehlender Werte / Excel-Bericht / Berichtserstellung / Excel-Analyse / Datenanalyse / Datenbereinigung / Pivot-Tabelle; ② Der Benutzer lädt eine .xlsx-/.xls-/.csv-Datei hoch oder gibt sie an und fordert Analyse, Bereinigung, Statistik oder Visualisierung an. ③ Die Aufgabe umfasst das Lesen mehrerer Blätter, bedingtes Filtern, kategoriale Zusammenfassung oder Diagrammerstellung. ④ Der Benutzer fordert einen exportierten formatierten Excel-Bericht oder einen Download-Link an. Nicht anwendbar für: reine Textverarbeitung, die keine tabellarischen Daten umfasst, Bildanalyse (verwenden Sie sn-da-image-caption), einfache Fragen und Antworten, die nur eine einzige Formelberechnung erfordern.
