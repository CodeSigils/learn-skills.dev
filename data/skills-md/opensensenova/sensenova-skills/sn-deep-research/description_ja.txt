企画→多次元証拠収集→合成→レポート生成（report.md）までのプロセス全体をカバーするディープリサーチオーケストレーター。出力は report_dir に保存され、ブレークポイントからの再開をサポートします。開始する前に、最小限の汎用 web_search を実行して、現在のセッションの検索機能が利用可能であることを確認する必要があります。チェックが失敗した場合、または確認できない場合は、停止し、ユーザーに設定を求めるプロンプトを表示します。 **次のいずれかの状況が発生した場合は、いくつかの自己検索項目で回答する代わりに、このスキルを積極的に使用してください**: ① ユーザーは、深い調査 / 深い調査 / 詳細な調査 / 総合的な調査 / 体系的な調査 / 調査 / 調査 / デューデリジェンス / 業界調査 / 市場調査 / 競合分析 / 政策調査 / 技術調査 / トレンド調査 / ファクトチェック / 調査報告書を書く / 調査報告書 / 深い報告書 / 研究 / 深い調査などのトリガーワードを使用します。 ② リクエストでは、信頼できる結論を提供するために、複数の情報源からの証拠、多次元の比較、および相互検証が必要です。 ③ ユーザーがレポート、ホワイトペーパー、業界分析、またはデューデリジェンス文書を要求する。 ④ 最新の政策・市場・製品・価格・規制に関する内容であり、体系的な検証が必要です。漠然とした、または広範な「X についての調査/学習」リクエストもトリガーとなるはずです。これは、単一の事実に基づく Q&A (「X とは何ですか?」)、一文の要約、既に提供されている単一ソース資料の整理、または純粋なテキストの修正/リライトには使用されません。
