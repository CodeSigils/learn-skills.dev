Motor de análisis de datos y análisis de documentos Word / PDF / PPT. Cubre la extracción completa de los tres formatos de archivo, la cuantificación de tablas, la comprensión de gráficos y el análisis de resumen de documentos cruzados. **Utilice proactivamente esta habilidad siempre que ocurra cualquiera de las siguientes situaciones**: 1) El usuario carga o especifica un archivo .docx / .doc / .pdf / .pptx / .ppt y solicita análisis, extracción o estadísticas de su contenido; 2) El usuario utiliza términos desencadenantes como análisis de Word/análisis de PDF/extracción de PPT/análisis de documentos/análisis de informes/análisis de diapositivas/extracción de facturas/análisis de contratos/estadísticas de documentos/errores tipográficos/errores gramaticales/verificación del tamaño de fuente/análisis de currículum/comparación de varios documentos; 3) La tarea implica extraer información estructurada de documentos, como tablas, números, gráficos, formato (color/resaltado/tamaño de fuente), estructura organizativa, cronograma, etc. No apto para: análisis de datos Excel/CSV (use sn-da-excel-workflow), análisis puro de imágenes (use sn-da-image-caption).
