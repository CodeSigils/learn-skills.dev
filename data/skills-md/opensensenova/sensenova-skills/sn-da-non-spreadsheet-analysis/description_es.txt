Motor de análisis de datos y análisis de documentos Word / PDF / PPT. Cubre la extracción completa de tres formatos de archivo, conversión numérica de tablas, comprensión de gráficos y análisis de resumen entre documentos. **Utilice proactivamente esta habilidad cuando ocurra cualquiera de las siguientes situaciones**: ① El usuario carga o especifica un archivo .docx / .doc / .pdf / .pptx / .ppt y solicita análisis, extracción o estadísticas de su contenido; ② El usuario activa palabras clave: análisis de palabras / análisis de PDF / extracción de PPT / análisis de documentos / análisis de informes / análisis de diapositivas / extracción de facturas / análisis de contratos / estadísticas de documentos / detección de errores tipográficos / errores gramaticales / verificación del tamaño de fuente / análisis de currículum / comparación de varios documentos; ③ La tarea implica extraer información estructurada como tablas, datos numéricos, gráficos, formato (color/resaltado/tamaño de fuente), estructura organizativa, cronogramas, etc., de los documentos. No debe usarse para: análisis de datos Excel/CSV (use sn-da-excel-workflow), análisis puro de imágenes (use sn-da-image-caption).
