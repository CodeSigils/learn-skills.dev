Word-/PDF-/PPT-Dokumentparsing- und Datenanalyse-Engine. Umfasst die vollständige Extraktion der drei Dateiformate, Tabellenquantifizierung, Diagrammverständnis und dokumentübergreifende Zusammenfassungsanalyse. **Verwenden Sie diesen Skill proaktiv, wenn eine der folgenden Situationen auftritt**: 1) Der Benutzer lädt eine .docx-, .doc-, .pdf-, .pptx- oder .ppt-Datei hoch oder gibt sie an und fordert eine Analyse, Extraktion oder Statistik ihres Inhalts an; 2) Der Benutzer verwendet Triggerbegriffe wie Word-Analyse / PDF-Analyse / PPT-Extraktion / Dokumentenanalyse / Berichtsanalyse / Folienanalyse / Rechnungsextraktion / Vertragsanalyse / Dokumentstatistik / Tippfehler / Grammatikfehler / Schriftgrößenprüfung / Lebenslaufanalyse / Vergleich mehrerer Dokumente; 3) Die Aufgabe umfasst das Extrahieren strukturierter Informationen aus Dokumenten wie Tabellen, Zahlen, Diagrammen, Formatierung (Farbe/Hervorhebung/Schriftgröße), Organisationsstruktur, Zeitleiste usw. Nicht geeignet für: Excel/CSV-Datenanalyse (sn-da-excel-workflow verwenden), reine Bildanalyse (sn-da-image-caption verwenden).
