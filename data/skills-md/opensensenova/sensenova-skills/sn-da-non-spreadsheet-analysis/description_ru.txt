Механизм синтаксического анализа и анализа документов Word / PDF / PPT. Охватывает полное извлечение файлов трех форматов, количественную оценку таблиц, понимание диаграмм и сводный анализ нескольких документов. **Активно используйте этот навык при возникновении любой из следующих ситуаций**: 1) Пользователь загружает или указывает файл .docx/.doc/.pdf/.pptx/.ppt и запрашивает анализ, извлечение или статистику его содержимого; 2) Пользователь использует триггерные термины, такие как анализ Word / анализ PDF / извлечение PPT / анализ документов / анализ отчетов / анализ слайдов / извлечение счетов / анализ контрактов / статистика документов / опечатки / грамматические ошибки / проверка размера шрифта / анализ резюме / сравнение нескольких документов; 3) Задача включает в себя извлечение структурированной информации из документов, такой как таблицы, числа, диаграммы, форматирование (цвет/выделение/размер шрифта), организационная структура, временная шкала и т. д. Не для: анализа данных Excel/CSV (используйте sn-da-excel-workflow), чистого анализа изображений (используйте sn-da-image-caption).
