Word / PDF / PPT ドキュメントの解析およびデータ分析エンジン。 3 つのファイル形式の完全な抽出、表の定量化、グラフの理解、およびクロスドキュメントの概要分析をカバーします。 **次のいずれかの状況が発生した場合は、このスキルを積極的に使用してください**: 1) ユーザーが .docx / .doc / .pdf / .pptx / .ppt ファイルをアップロードまたは指定し、その内容の分析、抽出、または統計を要求します。 2) ユーザーは、Word 分析 / PDF 解析 / PPT 抽出 / 文書分析 / レポート解析 / スライド分析 / 請求書抽出 / 契約分析 / 文書統計 / タイプミス / 文法エラー / フォント サイズ チェック / 履歴書分析 / 複数文書比較などのトリガー用語を使用します。 3) このタスクには、表、数字、チャート、書式設定 (色/ハイライト/フォント サイズ)、組織構造、タイムラインなどの構造化情報を文書から抽出することが含まれます。対象外: Excel/CSV データ分析 (sn‑da‑excel‑workflow を使用)、純粋な画像分析 (sn‑da‑image‑caption を使用)。
