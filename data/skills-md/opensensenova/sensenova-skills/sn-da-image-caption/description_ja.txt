画像の理解とデータ抽出のスキル。画像ファイル (.png/.jpg/.jpeg/.gif/.webp/.bmp) が主な入力であり、ユーザーが画像コンテンツを理解し、データを抽出し、分析する必要がある場合に使用されます。追加の API キー設定を必要とせずに、ビジョン モデルを使用して画像をテキストによる説明に変換する、事前設定されたキャプション スクリプト (scripts/caption.py) を提供します。対象範囲: (1) scripts/caption.py によるチャート/テーブル/スクリーンショット/フローチャートへのキャプション付け、(2) キャプション テキストの構造化された DataFrame への解析、(3) 抽出されたデータに基づくビジュアル チャートの再生成、(4) Excel/CSV へのエクスポート。 **次のいずれかの状況が発生した場合は、このスキルを積極的に使用し、画像の内容を自分で推測しないでください**: ① ユーザーは、画像分析 / チャート抽出 / 表認識 / OCR / 画像説明 / スクリーンショット分析 / チャート データ / 画像からデータを抽出 / 画像から表へ / 画像認識 / 画像キャプション / 画像からデータを抽出 / チャート分析 / 表 OCR などのトリガー ワードを使用します。 ② ユーザーは画像ファイル（.png/.jpg/.jpeg/.gif/.webp/.bmp）をアップロードまたは指定し、理解、データ抽出、または内容分析を要求します。 ③ このタスクでは、チャートのスクリーンショット、表のスクリーンショット、UI スクリーンショット、またはフローチャートから構造化情報を抽出する必要があります。 ④ ユーザーは、画像内のデータを Excel/CSV に変換するか、ビジュアル チャートを再生成するように要求します。画像編集 (トリミング、フィルタリング、サイズ変更)、画像生成、またはデータを含まない風景/ポートレート写真の記述には適用されません。
