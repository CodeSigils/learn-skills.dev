이미지 이해 및 데이터 추출 기술. 이미지 파일(.png/.jpg/.jpeg/.gif/.webp/.bmp)이 기본 입력이고 사용자가 이미지 콘텐츠를 이해, 데이터 추출 또는 분석해야 하는 경우에 사용합니다. 추가 API 키 없이 이미지를 텍스트 설명으로 변환하기 위해 비전 모델을 사용하는 사전 구성된 캡션 스크립트(scripts/caption.py)를 제공합니다. 표지: (1) scripts/caption.py를 통한 차트/테이블/스크린샷/흐름도 캡션 작성, (2) 캡션 텍스트를 구조화된 DataFrame으로 구문 분석, (3) 추출된 데이터를 기반으로 시각적 차트 재생성, (4) Excel/CSV로 내보내기. **다음과 같은 상황이 발생할 때마다 이 스킬을 적극적으로 활용하고, 이미지 내용을 직접 추측하지 마세요**: ① 사용자는 이미지 분석, 차트 추출, 테이블 인식, OCR, 이미지 설명, 스크린샷 분석, 차트 데이터, 이미지에서 데이터 추출, 이미지에서 테이블로, 이미지 인식, 이미지 캡션, 이미지에서 데이터 추출, 차트 분석, 테이블 OCR 등의 트리거 문구를 사용합니다. ② 이용자가 이미지 파일(.png/.jpg/.jpeg/.gif/.webp/.bmp)을 업로드하거나 지정하여 이해, 데이터 추출 또는 내용 분석을 요청하는 경우 ③ 차트 스크린샷, 테이블 스크린샷, UI 스크린샷, 플로우차트 등에서 구조화된 정보를 추출해야 하는 작업입니다. ④ 사용자는 이미지의 데이터를 Excel/CSV로 변환하거나 시각적 차트를 다시 생성하기를 원합니다. 해당되지 않음: 이미지 편집(자르기, 필터, 크기 조정), 이미지 생성, 데이터가 포함되지 않은 풍경 또는 인물 사진 설명.
