Compétence en compréhension d’images et en extraction de données. Utilisé lorsqu'un fichier image (.png/.jpg/.jpeg/.gif/.webp/.bmp) est l'entrée principale et que l'utilisateur a besoin de comprendre, d'extraire des données ou d'analyser le contenu de l'image. Fournit un script de légende préconfiguré (scripts/caption.py) qui utilise un modèle de vision pour convertir l'image en description textuelle, sans nécessiter de configuration de clé API supplémentaire. Couvre : (1) le sous-titrage de graphiques/tableaux/captures d'écran/organigrammes via scripts/caption.py, (2) l'analyse du texte de légende dans un DataFrame structuré, (3) la régénération de graphiques visuels basés sur les données extraites, (4) l'exportation vers Excel/CSV. **Lorsque l'une des situations suivantes se produit, utilisez cette compétence de manière proactive et ne devinez pas vous-même le contenu de l'image** : ① L'utilisateur utilise des mots déclencheurs tels que analyse d'image/extraction de graphique/reconnaissance de tableau/OCR/description d'image/analyse de capture d'écran/données de graphique/extraire des données de l'image/image vers un tableau/reconnaissance d'image/légende d'image/extraire des données de l'image/analyse de graphique/OCR de tableau ; ② L'utilisateur télécharge ou spécifie un fichier image (.png/.jpg/.jpeg/.gif/.webp/.bmp) et demande une compréhension, une extraction de données ou une analyse de contenu ; ③ La tâche nécessite d'extraire des informations structurées à partir de captures d'écran de graphiques, de captures d'écran de tableaux, de captures d'écran d'interface utilisateur ou d'organigrammes ; ④ L'utilisateur demande de convertir les données de l'image en Excel/CSV ou de régénérer un graphique visuel. Ne s'applique pas à : l'édition d'images (recadrage, filtrage, redimensionnement), la génération d'images ou la description de photos de paysage/portrait ne contenant aucune donnée.
