Bildverständnis und Datenextraktionsfähigkeiten. Wird verwendet, wenn eine Bilddatei (.png/.jpg/.jpeg/.gif/.webp/.bmp) die primäre Eingabe ist und der Benutzer den Bildinhalt verstehen, Daten extrahieren oder analysieren muss. Stellt ein vorkonfiguriertes Untertitelskript (scripts/caption.py) bereit, das ein Visionsmodell verwendet, um das Bild in eine Textbeschreibung umzuwandeln, ohne dass eine zusätzliche API-Schlüsselkonfiguration erforderlich ist. Behandelt: (1) Beschriften von Diagrammen/Tabellen/Screenshots/Flussdiagrammen über scripts/caption.py, (2) Parsen des Beschriftungstexts in einen strukturierten DataFrame, (3) Regenerieren visueller Diagramme basierend auf den extrahierten Daten, (4) Exportieren nach Excel/CSV. **Wenn eine der folgenden Situationen auftritt, nutzen Sie diese Fähigkeit proaktiv und erraten Sie den Bildinhalt nicht selbst**: ① Der Benutzer verwendet Triggerwörter wie Bildanalyse / Diagrammextraktion / Tabellenerkennung / OCR / Bildbeschreibung / Screenshot-Analyse / Diagrammdaten / Daten aus Bild extrahieren / Bild in Tabelle / Bilderkennung / Bildunterschrift / Daten aus Bild extrahieren / Diagrammanalyse / Tabellen-OCR; ② Der Benutzer lädt eine Bilddatei (.png/.jpg/.jpeg/.gif/.webp/.bmp) hoch oder gibt sie an und fordert Verständnis, Datenextraktion oder Inhaltsanalyse an; ③ Die Aufgabe erfordert das Extrahieren strukturierter Informationen aus Diagramm-Screenshots, Tabellen-Screenshots, UI-Screenshots oder Flussdiagrammen; ④ Der Benutzer bittet darum, die Daten im Bild in Excel/CSV zu konvertieren oder ein visuelles Diagramm neu zu erstellen. Gilt nicht für: Bildbearbeitung (Zuschneiden, Filtern, Größenänderung), Bildgenerierung oder Beschreibung von Quer-/Hochformatfotos, die keine Daten enthalten.
