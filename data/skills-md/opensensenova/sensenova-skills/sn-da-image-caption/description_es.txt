Habilidad de comprensión de imágenes y extracción de datos. Úselo cuando un archivo de imagen (.png/.jpg/.jpeg/.gif/.webp/.bmp) es la entrada principal y el usuario necesita comprender, extraer datos o analizar el contenido de la imagen. Se proporciona un script de subtítulos preconfigurado (scripts/caption.py), que utiliza un modelo de visión para convertir la imagen en una descripción textual sin requerir una configuración de clave API adicional. Cubre: (1) Subtítulos de gráficos/tablas/capturas de pantalla/diagramas de flujo a través de scripts/caption.py, (2) Análisis del texto del subtítulo en un marco de datos estructurado, (3) Regeneración de gráficos visuales basados ​​en los datos extraídos, (4) Exportación a Excel/CSV. **Utilice esta habilidad de forma proactiva siempre que ocurra cualquiera de las siguientes situaciones; no adivine el contenido de la imagen usted mismo**: ① El usuario incluye palabras desencadenantes: análisis de imagen / extracción de gráfico / reconocimiento de tabla / OCR / descripción de imagen / análisis de captura de pantalla / datos de gráfico / extracción de datos de imagen / imagen a tabla / reconocimiento de imagen / título de imagen / extracción de datos de imagen / análisis de gráfico / OCR de tabla; ② El usuario carga o especifica un archivo de imagen (.png/.jpg/.jpeg/.gif/.webp/.bmp) y solicita comprensión, extracción de datos o análisis de contenido; ③ La tarea requiere extraer información estructurada de capturas de pantalla de gráficos, capturas de pantalla de tablas, capturas de pantalla de UI o diagramas de flujo; ④ El usuario solicita convertir los datos de la imagen a Excel/CSV o regenerar un gráfico visual. No apto para: edición de imágenes (recorte, filtros, escalado), generación de imágenes o descripción de fotografías de paisajes/retratos que no contengan datos.
