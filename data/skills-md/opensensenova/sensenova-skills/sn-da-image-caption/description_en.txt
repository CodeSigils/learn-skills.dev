Image Understanding and Data Extraction skill. Used when an image file (.png/.jpg/.jpeg/.gif/.webp/.bmp) is the primary input and the user needs to understand, extract data, or analyze the image content. Provides a pre‑configured caption script (scripts/caption.py) that uses a vision model to convert the image into a textual description, without requiring additional API‑Key configuration. Covers: (1) captioning charts/tables/screenshots/flowcharts via scripts/caption.py, (2) parsing the caption text into a structured DataFrame, (3) regenerating visual charts based on the extracted data, (4) exporting to Excel/CSV. **When any of the following situations occurs, proactively use this skill and do not guess the image content yourself**: ① The user uses trigger words such as image analysis / chart extraction / table recognition / OCR / image description / screenshot analysis / chart data / extract data from image / image to table / image recognition / image caption / extract data from image / chart analysis / table OCR; ② The user uploads or specifies an image file (.png/.jpg/.jpeg/.gif/.webp/.bmp) and requests understanding, data extraction, or content analysis; ③ The task requires extracting structured information from chart screenshots, table screenshots, UI screenshots, or flowcharts; ④ The user asks to convert the data in the image to Excel/CSV or to regenerate a visual chart. Not applicable for: image editing (cropping, filtering, resizing), image generation, or describing landscape/portrait photos that contain no data.
