Implementieren und prüfen Sie Sicherheitskontrollen für Next.js App Router-Projekte, die Serverkomponenten und Serveraktionen verwenden, wobei der Schwerpunkt auf der Verhinderung einer versehentlichen Offenlegung von Daten liegt. Verwenden Sie es, wenn Sie ein Datenzugriffsmodell entwerfen, den Code „Client verwenden“ oder „Server verwenden“ überprüfen, Aktionseingaben und Autorisierung validieren, Routenhandler oder Middleware prüfen oder eine Next.js-Sicherheitscheckliste vorbereiten.
