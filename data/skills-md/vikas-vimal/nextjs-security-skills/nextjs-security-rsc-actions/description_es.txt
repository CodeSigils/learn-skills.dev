Implemente y audite controles de seguridad para proyectos de Next.js App Router que utilizan componentes de servidor y acciones de servidor, con énfasis en prevenir la exposición accidental de datos. Úselo al diseñar un modelo de acceso a datos, revisar el código "usar cliente" o "usar servidor", validar entradas de acción y autorización, auditar controladores de ruta o middleware o preparar una lista de verificación de seguridad de Next.js.
