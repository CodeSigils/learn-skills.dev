Отправляйте физическую почту (письма и открытки) в США через PostalForm, используя платежи x402 USDC на Base из кошелька агента awal. Используйте, когда пользователь просит отправить почту, опубликовать письмо, отправить документ по почте, отправить открытку, отправить PDF-файл по почте, отправить физическую почту или «отправить это [кому-то]». Поддерживает предоставленные пользователем PDF-файлы, автоматическое создание из текста и создание изображений AI для открыток через fal.ai (также оплачивается с помощью x402). Получатель должен находиться в США. Один получатель на отправку.
