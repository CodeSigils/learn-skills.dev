Úselo cuando el usuario esté implementando, incrustando o depurando un widget de WorkOS, específicamente los widgets de administración de usuarios, perfil de usuario, conexión SSO del portal de administración o verificación de dominio del portal de administración. Maneja la pila completa: detecta la interfaz (Next.js, React, React Router, TanStack Start, Vite, SvelteKit), genera tokens de acceso a través del SDK de backend en uso (Node, Python, Go, Ruby, PHP, Java, .NET) y conecta el componente del widget correctamente según la especificación OpenAPI incluida. Utilícelo también cuando el código se importe desde @workos-inc/widgets o el usuario pegue <UserManagement /> o <UserProfile /> JSX.
