À utiliser lorsque l'utilisateur implémente, intègre ou débogue un widget WorkOS, en particulier les widgets Gestion des utilisateurs, Profil utilisateur, Connexion SSO du portail d'administration ou Vérification de domaine du portail d'administration. Gère la pile complète – en détectant le frontend (Next.js, React, React Router, TanStack Start, Vite, SvelteKit), en générant des jetons d'accès via le SDK backend utilisé (Node, Python, Go, Ruby, PHP, Java, .NET) et en connectant correctement le composant widget selon la spécification OpenAPI fournie. À utiliser également lorsque le code importe depuis @workos-inc/widgets ou que l'utilisateur colle <UserManagement /> ou <UserProfile /> JSX.
