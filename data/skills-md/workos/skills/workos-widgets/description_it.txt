Da utilizzare quando l'utente sta implementando, incorporando o eseguendo il debug di un widget WorkOS, in particolare dei widget Gestione utente, Profilo utente, Connessione SSO del portale di amministrazione o Verifica del dominio del portale di amministrazione. Gestisce lo stack completo: rilevando il frontend (Next.js, React, React Router, TanStack Start, Vite, SvelteKit), generando token di accesso tramite l'SDK di backend in uso (Node, Python, Go, Ruby, PHP, Java, .NET) e collegando correttamente il componente widget in base alle specifiche OpenAPI in bundle. Da utilizzare anche quando il codice viene importato da @workos-inc/widgets o l'utente incolla <UserManagement /> o <UserProfile /> JSX.
