Wird verwendet, wenn der Benutzer ein WorkOS-Widget implementiert, einbettet oder debuggt – insbesondere die Widgets „Benutzerverwaltung“, „Benutzerprofil“, „Admin-Portal-SSO-Verbindung“ oder „Admin-Portal-Domänenüberprüfung“. Verarbeitet den gesamten Stack – erkennt das Frontend (Next.js, React, React Router, TanStack Start, Vite, SvelteKit), generiert Zugriffstoken über das verwendete Backend-SDK (Node, Python, Go, Ruby, PHP, Java, .NET) und verkabelt die Widget-Komponente korrekt gemäß der gebündelten OpenAPI-Spezifikation. Wird auch verwendet, wenn Code aus @workos-inc/widgets importiert wird oder der Benutzer <UserManagement /> oder <UserProfile /> JSX einfügt.
