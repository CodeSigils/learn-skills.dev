Traitez une file d’attente de tickets de suivi prêts pour l’agent sans surveillance — où qu’ils se trouvent selon la documentation du suivi des problèmes du dépôt. Un pré‑vol recueille tout d’emblée, puis, pour chaque ticket, un sous‑agent constructeur implémente, vous réexaminez, un sous‑agent correcteur modifie ; les échecs se rangent sur une branche. Aucun push.
