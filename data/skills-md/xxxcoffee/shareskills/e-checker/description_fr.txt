Excel Configuration Checker : un outil pour vérifier si les données du fichier Excel sont conformes aux règles définies par YAML.  
Scénarios d'utilisation : l'utilisateur dit « vérifier la configuration », « valider Excel », « vérifier les règles », « exécuter la vérification » ou « valider les données » ; l'utilisateur souhaite mettre à jour les fichiers de règles, modifier les règles de validation ou ajouter de nouveaux contrôles ; l'utilisateur demande comment configurer les règles, comment implémenter une certaine validation ou comment utiliser les opérateurs ; implique la validation des données Excel, les vérifications des relations entre les champs, les références croisées, la vérification du format, etc.  
Contrainte clé : si une exigence ne peut être satisfaite avec les règles existantes, les raisons doivent être énumérées ; la modification de validate.py ou de tout script de détection sous src/ est interdite. Les cas irréalisables pour les règles incluent : le besoin d'un tout nouveau type d'opérateur, le besoin de modifier la logique du moteur de base, le besoin d'une logique de code personnalisée, etc.
