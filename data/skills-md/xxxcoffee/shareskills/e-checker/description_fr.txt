Excel Configuration Checker : vérifie que les données Excel sont conformes aux règles définies par YAML.  
Utilisation : l'utilisateur dit « vérifier la configuration », « valider Excel », « vérifier les règles », « exécuter la vérification » ou « valider les données » ; l'utilisateur souhaite mettre à jour les fichiers de règles, modifier les règles de validation ou ajouter de nouveaux contrôles ; l'utilisateur demande comment configurer les règles, comment implémenter une validation ou comment utiliser les opérateurs ; couvre la validation des données Excel, les vérifications des relations entre les champs, les références croisées, les vérifications de format, etc.  
Contrainte critique : si une exigence ne peut être satisfaite avec les règles existantes, énumérer les raisons ; la modification de validate.py ou de tout script de détection sous src/ est interdite. Les cas irréalisables incluent : la nécessité d'un tout nouveau type d'opérateur, la modification de la logique de base du moteur ou la nécessité d'une logique de code personnalisée.
