Comprobador de configuración de Excel para verificar que los datos del archivo Excel cumplan con las reglas definidas por YAML.  
Casos de uso: el usuario dice "verificar configuración", "validar Excel", "verificar reglas", "ejecutar verificación" o "validar datos"; el usuario desea actualizar archivos de reglas, modificar reglas de validación o agregar nuevas comprobaciones; el usuario pregunta cómo configurar reglas, cómo implementar una determinada validación o cómo utilizar operadores; cubre necesidades como validación de datos de Excel, comprobaciones de relaciones de campo, referencias entre hojas, verificación de formato, etc.  
Restricción clave: si un requisito no puede cumplirse con las reglas existentes, se deben enumerar las razones; Está prohibido modificar validar.py o cualquier script de detección en src/. Los casos en los que las reglas no se pueden implementar incluyen: la necesidad de un tipo de operador completamente nuevo, la necesidad de cambios en la lógica central del motor o la necesidad de una lógica de código personalizada.
