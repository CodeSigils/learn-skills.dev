Controllo configurazione Excel: verifica se i dati Excel sono conformi alle regole definite da YAML.  
Casi d'uso: l'utente dice "controlla configurazione", "convalida Excel", "controlla regole", "esegui controllo", "convalida dati"; l'utente desidera aggiornare i file delle regole, modificare le regole di convalida o aggiungere nuovi controlli; user asks how to configure rules, how to implement a validation, how to use operators; copre la convalida dei dati Excel, i controlli delle relazioni tra campi, i riferimenti tra fogli, i controlli del formato, ecc.  
Vincolo chiave: se un requisito non può essere realizzato con le regole esistenti, indicarne il motivo; è vietato modificare validate.py o qualsiasi codice sotto src/. I casi irrealizzabili includono: la necessità di un tipo di operatore completamente nuovo, l'alterazione della logica principale del motore o la necessità di una logica di codice personalizzata.
