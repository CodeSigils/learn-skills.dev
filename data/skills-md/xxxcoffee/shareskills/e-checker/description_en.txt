Excel Configuration Checker: a tool to verify whether Excel file data complies with YAML-defined rules.  
Usage scenarios: user says “check config,” “validate Excel,” “check rules,” “run the check,” or “validate data”; user wants to update rule files, modify validation rules, or add new checks; user asks how to configure rules, how to implement a certain validation, or how to use operators; involves Excel data validation, field-relation checks, cross-sheet references, format verification, etc.  
Key constraint: if a requirement cannot be met with existing rules, the reasons must be listed; modifying validate.py or any detection scripts under src/ is forbidden. Rule-unrealizable cases include: needing a brand-new operator type, needing to change core engine logic, needing custom code logic, etc.
