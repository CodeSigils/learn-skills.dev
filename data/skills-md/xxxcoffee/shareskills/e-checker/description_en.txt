Excel Configuration Check Tool, used to verify whether Excel file data complies with YAML rule definitions.  
Usage scenarios: user says "check config", "validate Excel", "check rules", "run the check", "validate data"; user wants to update rule files, modify validation rules, add new check rules; user asks how to configure rules, how to implement a certain validation, how to use operators; involves Excel data validation, field association checks, cross-sheet reference validation, format verification, etc.  
Important constraints: if the requirement cannot be achieved with existing rules, the reasons must be listed; modifying validate.py or detection scripts under src/ is forbidden; rule-unachievable cases include: requiring a brand-new operator type, needing to modify engine core logic, requiring custom code logic, etc.
