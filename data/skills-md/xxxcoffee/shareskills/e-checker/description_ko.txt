Excel 구성 검사기: YAML 정의 규칙에 대해 Excel 데이터를 확인합니다.  
사용 사례: 사용자가 "구성 확인", "Excel 유효성 검사", "규칙 확인", "검사 실행" 또는 "데이터 유효성 검사"라고 말합니다. 사용자가 규칙 파일을 업데이트하거나, 유효성 검사 규칙을 수정하거나, 새 검사를 추가하기를 원합니다. 사용자는 규칙 구성 방법, 유효성 검사 구현 방법 또는 연산자 사용 방법을 묻습니다. Excel 데이터 유효성 검사, 필드 관계 확인, 시트 간 참조, 형식 확인 등을 다룹니다.  
중요한 제약조건: 기존 규칙으로 요구사항을 실현할 수 없는 경우 이유를 명시합니다. verify.py 또는 src/ 감지 스크립트를 수정하는 것은 금지되어 있습니다. 구현할 수 없는 경우에는 새로운 연산자 유형이 필요하거나, 엔진 핵심 로직을 변경해야 하거나, 사용자 정의 코드 로직이 필요한 경우 등이 있습니다.
