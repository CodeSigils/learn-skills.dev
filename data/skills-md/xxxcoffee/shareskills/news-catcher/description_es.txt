News scraping and aggregation skill that uses a master-agent + sub-agent parallel mode to crawl news from multiple sites.  
Use this skill when users need to batch-scrape news, fetch the latest content from several websites, or aggregate news summaries.  
El agente maestro lee la configuración, genera un subagente para cada sitio para rastrear en paralelo y cada subagente usa Playwright para visitar el sitio y resumir las noticias (≈50 caracteres); finally the master agent consolidates and outputs the results.  
Proactively invoke this skill for news collection, content monitoring, and information aggregation scenarios.
