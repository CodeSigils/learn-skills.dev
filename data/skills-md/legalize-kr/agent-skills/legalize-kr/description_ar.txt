استخدم هذه المهارة عند العمل مع البيانات القانونية العامة لـ Legalize-KR، بما في ذلك القوانين وسوابق المحاكم والقواعد الإدارية والمراسيم المحلية. إنه يوجه الوكلاء للاختيار بين legalize-cli، وstdio المحلي لإضفاء الشرعية على خادم MCP، وسير عمل git clone، والوصول المباشر إلى GitHub للبحث، والاسترجاع، والبحث عن المقالات، وسجل المراجعة، والتحليل المجمع، والعمل دون اتصال بالإنترنت، وبناء سياق LLM.
