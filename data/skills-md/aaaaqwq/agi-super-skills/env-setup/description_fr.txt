Outil de synchronisation en un clic de l'environnement Claude Code. Synchronisez toutes les configurations du référentiel GitHub vers le local : styles de styles de sortie, invites globales CLAUDE.md, configuration du serveur MCP. Convient aux scénarios tels que les environnements unifiés sur plusieurs appareils, la récupération après remplacement d'un ordinateur, les configurations partagées en équipe, etc. Utilisez cette compétence lorsqu'un utilisateur doit synchroniser les paramètres d'environnement Claude Code à partir du référentiel GitHub.
