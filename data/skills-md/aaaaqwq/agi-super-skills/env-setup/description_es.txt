Herramienta de sincronización con un clic de Claude Code Environment. Sincronice todas las configuraciones desde un repositorio de GitHub a local: estilos de salida, indicaciones globales de CLAUDE.md, configuración del servidor MCP. Ideal para unificar entornos en múltiples dispositivos, restaurar después de cambiar de computadora y compartir configuraciones dentro de los equipos. Utilice esta habilidad cuando el usuario necesite sincronizar las configuraciones del entorno de Claude Code desde un repositorio de GitHub.
