Herramienta de sincronización con un solo clic del entorno Claude Code. Sincronice todas las configuraciones del repositorio de GitHub a local: estilos de salida, mensajes globales CLAUDE.md, configuración del servidor MCP. Adecuado para escenarios como entornos unificados en múltiples dispositivos, recuperación de reemplazo de computadoras, configuraciones compartidas en equipo y más. Utilice esta habilidad cuando un usuario necesite sincronizar la configuración del entorno de Claude Code desde el repositorio de GitHub.
