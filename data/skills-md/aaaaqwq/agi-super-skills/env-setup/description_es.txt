Herramienta de sincronización con un solo clic del entorno Claude Code. Sincronice todas las configuraciones desde un repositorio de GitHub con la máquina local: temas de estilos de salida, indicaciones globales de CLAUDE.md y configuración del servidor MCP. Ideal para escenarios como mantener un entorno unificado en múltiples dispositivos, restaurar después de cambiar de computadora y compartir configuraciones dentro de un equipo. Utilice esta habilidad cuando un usuario necesite sincronizar la configuración del entorno de Claude Code desde un repositorio de GitHub.
