Strumento di sincronizzazione con un clic dell'ambiente Claude Code. Sincronizza tutte le configurazioni da un repository GitHub in locale: stili di output, prompt globali CLAUDE.md, impostazioni del server MCP. Ideale per unificare ambienti su più dispositivi, ripristinare dopo aver cambiato computer e condividere configurazioni all'interno dei team. Utilizza questa competenza quando l'utente deve sincronizzare le configurazioni dell'ambiente Claude Code da un repository GitHub.
