Strumento di sincronizzazione con un clic dell'ambiente Claude Code. Sincronizza tutte le configurazioni dal repository GitHub in locale: stili di output, prompt globali CLAUDE.md, configurazione del server MCP. Adatto a scenari come ambienti unificati su più dispositivi, ripristino della sostituzione del computer, configurazioni condivise dal team e altro ancora. Utilizza questa competenza quando un utente deve sincronizzare le impostazioni dell'ambiente Claude Code dal repository GitHub.
