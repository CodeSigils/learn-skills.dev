Инструмент синхронизации среды Claude Code в один клик. Синхронизируйте все конфигурации из репозитория GitHub с локальным компьютером: темы стилей вывода, глобальные подсказки CLAUDE.md и настройки сервера MCP. Идеально подходит для таких сценариев, как поддержка единой среды на нескольких устройствах, восстановление после переключения компьютеров и совместное использование конфигураций внутри команды. Используйте этот навык, когда пользователю необходимо синхронизировать настройки среды Claude Code из репозитория GitHub.
