Инструмент синхронизации среды Claude Code одним щелчком мыши. Синхронизируйте все конфигурации из репозитория GitHub с локальным: стили стилей вывода, глобальные подсказки CLAUDE.md, конфигурацию сервера MCP. Подходит для таких сценариев, как унифицированные среды для нескольких устройств, восстановление компьютеров после замены, общие конфигурации и т. д. Используйте этот навык, когда пользователю необходимо синхронизировать настройки среды Claude Code из репозитория GitHub.
