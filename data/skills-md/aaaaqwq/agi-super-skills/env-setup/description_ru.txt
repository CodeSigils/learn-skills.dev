Инструмент синхронизации среды кода Claude в один клик. Синхронизируйте все конфигурации из репозитория GitHub с локальным: стили вывода, глобальные запросы CLAUDE.md, настройки сервера MCP. Идеально подходит для объединения сред на нескольких устройствах, восстановления после замены компьютеров и совместного использования конфигураций внутри команд. Используйте этот навык, когда пользователю необходимо синхронизировать конфигурации среды Claude Code из репозитория GitHub.
