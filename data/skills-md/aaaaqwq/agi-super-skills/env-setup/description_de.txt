Claude Code Environment Ein-Klick-Synchronisierungstool. Synchronisieren Sie alle Konfigurationen aus einem GitHub-Repository mit lokalen: Ausgabestilen, globalen CLAUDE.md-Eingabeaufforderungen, MCP-Servereinstellungen. Ideal für die Vereinheitlichung von Umgebungen auf mehreren Geräten, die Wiederherstellung nach einem Computerwechsel und die gemeinsame Nutzung von Konfigurationen innerhalb von Teams. Verwenden Sie diesen Skill, wenn der Benutzer Claude Code-Umgebungskonfigurationen aus einem GitHub-Repository synchronisieren muss.
