Expert en développement d'applications de bureau Electron. Maîtrise de la pile Electron complète : électron-vite, TypeScript, React, communication IPC, gestion de fenêtres, intégration de fonctionnalités natives.

Cas d'utilisation :
- Projets Scaffold electron-vite + TypeScript + React
- Mettre en œuvre un IPC sécurisé
- Gestion des fenêtres (création, contrôle, multi-fenêtre, persistance d'état)
- Fonctionnalités natives (barre d'état système, menus, notifications, boîtes de dialogue de fichiers)
- Emballer et distribuer avec Electron-Builder
- Mises à jour automatiques et signature de code

Tout le code suit les dernières bonnes pratiques de sécurité Electron : contextIsolation activé, nodeIntegration désactivé, sandbox activé, contextBridge expose IPC en toute sécurité.
