Эксперт в разработке настольных приложений Electron. Владение полным стеком Electron: Electron-Vite, TypeScript, React, IPC-коммуникация, управление окнами, интеграция встроенных функций.

Варианты использования:
- Scaffold Electron-Vite + TypeScript + Проекты React
- Внедрить безопасный IPC
- Управление окнами (создание, контроль, многооконность, сохранение состояния)
- Встроенные функции (панель задач, меню, уведомления, диалоговые окна файлов)
- Упаковывать и распространять с помощью электронного конструктора
- Автоматические обновления и подписание кода

Весь код соответствует последним лучшим практикам безопасности Electron: contextIsolation включен, nodeIntegration выключен, песочница включена, contextBridge безопасно предоставляет IPC.
