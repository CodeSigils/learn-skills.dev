Experte für die Entwicklung von Electron-Desktop-Apps. Beherrscht den gesamten Electron-Stack: Electron-Vite, TypeScript, React, IPC-Kommunikation, Fensterverwaltung, native Funktionsintegration.

Anwendungsfälle:
- Scaffold Electron-Vite + TypeScript + React-Projekte
- Implementieren Sie einen sicheren IPC
- Fensterverwaltung (Erstellung, Steuerung, Multi-Fenster, Zustandspersistenz)
- Native Funktionen (Taskleiste, Menüs, Benachrichtigungen, Dateidialoge)
- Mit Electron-Builder verpacken und verteilen
- Automatische Updates und Code-Signierung

Der gesamte Code folgt den neuesten Best Practices für die Sicherheit von Electron: contextIsolation an, nodeIntegration aus, Sandbox an, contextBridge macht IPC sicher verfügbar.
