Feishu (Lark/Feishu) and OpenClaw bidirectional integration channel. It receives and sends messages through a Feishu bot, supporting private chats, group chats, @mention detection, card messages, and file transfer. Use this skill when you need to interact with an AI assistant via Feishu, trigger AI responses from Feishu messages, or send messages from OpenClaw to Feishu. Difference from feishu-automation: this skill focuses on message channel integration, whereas feishu-automation focuses on Feishu platform automation tasks (multidimensional tables, documents, etc.).
