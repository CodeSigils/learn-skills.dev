Durchsuchen Sie GitHub und installieren und konfigurieren Sie das MCP-Servertool (Model Context Protocol) automatisch in der Claude-Konfigurationsdatei. Dieser Skill wird ausgelöst, wenn der Benutzer das MCP-Tool installieren muss. Arbeitsablauf: Auf GitHub nach dem MCP-Projekt suchen → Npx-Konfiguration extrahieren → zu ~/.claude.json hinzufügen → API-Schlüssel verarbeiten (falls vorhanden).
