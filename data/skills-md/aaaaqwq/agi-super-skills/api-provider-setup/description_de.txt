Fügen Sie API-Relay-Anbieter von Drittanbietern in OpenClaw hinzu und konfigurieren Sie sie. Diese Funktion wird verwendet, wenn ein Benutzer einen neuen API-Anbieter hinzufügen, ein Relay konfigurieren oder einen benutzerdefinierten Modellendpunkt festlegen muss. Unterstützt Anthropic-kompatible und OpenAI-kompatible API-Formate.
