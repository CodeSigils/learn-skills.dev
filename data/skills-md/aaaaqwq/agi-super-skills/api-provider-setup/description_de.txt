Fügen Sie OpenClaw API-Relay-Anbieter von Drittanbietern hinzu und konfigurieren Sie sie. Dieser Skill wird verwendet, wenn ein Benutzer einen neuen API-Anbieter hinzufügen, ein Relay konfigurieren oder einen benutzerdefinierten Modellendpunkt festlegen muss. Es unterstützt Anthropic-kompatible und OpenAI-kompatible API-Formate.
