OpenClaw-Konfigurationsänderungsassistent. Bevor Sie eine OpenClaw-Konfiguration ändern, müssen Sie die offizielle Dokumentation konsultieren, um sicherzustellen, dass das Format korrekt ist und Systemabstürze oder Funktionsstörungen vermieden werden. Erzwingen Sie den Prozess: Schema prüfen → Dokumentation prüfen → Bestätigen → Ändern.
