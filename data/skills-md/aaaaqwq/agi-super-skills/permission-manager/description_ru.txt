Управляйте глобальной конфигурацией разрешений инструментов Claude Code, автоматически добавляйте команды MCP или другие инструменты в разрешенные инструменты, чтобы избежать ручного утверждения при каждом их использовании. Рабочий процесс: подтвердите команду, которую пользователь хочет добавить → подтвердите уровень добавления (по умолчанию глобальный ~/.claude.json) → выполните добавление → проверьте и предложите перезагрузку.
