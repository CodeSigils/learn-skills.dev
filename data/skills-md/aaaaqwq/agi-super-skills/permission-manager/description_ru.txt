Управляйте глобальными конфигурациями разрешений инструментов для Claude Code, автоматически добавляйте команды MCP или другие инструменты в список разрешенных инструментов, чтобы избежать ручного утверждения при каждом их использовании. Рабочий процесс: подтвердите команду, которую пользователь хочет добавить → подтвердите уровень добавления (по умолчанию глобальный ~/.claude.json) → выполните добавление → проверьте и напомните о перезапуске.
