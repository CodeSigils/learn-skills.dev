Administre la configuración de permisos de herramientas globales de Claude Code, agregue automáticamente comandos MCP u otras herramientas a las herramientas permitidas para evitar la aprobación manual cada vez que se usan. Flujo de trabajo: confirme el comando que el usuario desea agregar → confirme el nivel de adición (predeterminado global~/.claude.json) → ejecute la adición → verifique y solicite un reinicio.
