Cerca nei siti ufficiali come GitHub e SkillsMP competenze di alta qualità che corrispondano alla descrizione dell'utente, presentale affinché l'utente possa sceglierle, quindi clona e installa automaticamente la competenza corrispondente nella directory global~/.claude/skills/. Attiva questa abilità quando l'utente deve cercare o installare una nuova abilità.
