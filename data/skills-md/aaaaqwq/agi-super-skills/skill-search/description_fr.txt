Recherchez sur des sites officiels tels que GitHub et SkillsMP des compétences de haute qualité qui correspondent à la description de l'utilisateur, présentez-les à l'utilisateur pour qu'il puisse les choisir, puis clonez et installez automatiquement la compétence correspondante dans le répertoire global~/.claude/skills/. Cette compétence est déclenchée lorsque l'utilisateur doit rechercher ou installer une nouvelle compétence.
