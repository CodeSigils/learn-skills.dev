Durchsuchen Sie offizielle Websites wie GitHub und SkillsMP nach hochwertigen Fertigkeiten, die der Beschreibung des Benutzers entsprechen, präsentieren Sie sie dem Benutzer zur Auswahl und klonen Sie dann automatisch die entsprechende Fertigkeit und installieren Sie sie im Verzeichnis global~/.claude/skills/. Dieser Skill wird ausgelöst, wenn der Benutzer nach einem neuen Skill suchen oder ihn installieren muss.
