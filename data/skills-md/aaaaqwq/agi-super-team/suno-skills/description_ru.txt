Инструмент создания музыки с искусственным интеллектом. Навыки автоматизации браузера Suno. Использование Playwright для управления веб-сайтом Suno (https://suno.com) для создания песен (включая собственные тексты), управления творениями, загрузки аудио. Сценарии триггера: «Создать песню с помощью Suno», «Создание Suno», «Создание музыки с помощью искусственного интеллекта», «Создать песню в стиле ...», «Загрузить текст в Suno».
