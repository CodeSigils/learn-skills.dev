Eine kleine Assistenten-Konfigurationsvorlage. Angepasst an das xiaomo-Starter-Kit und bietet vorkonfigurierte OpenClaw Assistant-Framework-Dateien. Verwenden Sie diese Fähigkeit, wenn Benutzer schnell einen neuen Assistenten einrichten, die Identität des Assistenten definieren oder eine Assistentenkonfigurationsdatei erstellen müssen.
