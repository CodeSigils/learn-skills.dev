Маленький шаблон конфигурации Assistant. Адаптированный на основе xiaomo-starter-kit, он предоставляет предварительно настроенные файлы инфраструктуры помощника OpenClaw. Этот навык используется, когда пользователю необходимо быстро настроить нового помощника, определить его личность и создать файл конфигурации помощника.
