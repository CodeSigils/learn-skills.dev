Strumento di automazione del browser intelligente basato sull'intelligenza artificiale. Utilizza LLM per comprendere le pagine ed eseguire automaticamente le attività, in modo più intelligente ed efficiente in termini di token rispetto al drammaturgo tradizionale. Adatto per interazioni complesse, pagine dinamiche e operazioni del browser che richiedono un processo decisionale intelligente. Preferibile il browser Chrome.
