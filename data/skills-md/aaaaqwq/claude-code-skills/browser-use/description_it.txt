Strumento di automazione del browser intelligente basato sull'intelligenza artificiale. Utilizza un LLM per comprendere le pagine ed eseguire automaticamente le attività, rendendolo più intelligente ed efficiente in termini di token rispetto al drammaturgo tradizionale. Adatto per interazioni complesse, pagine dinamiche e operazioni del browser che richiedono decisioni intelligenti. Preferibile il browser Chrome.
