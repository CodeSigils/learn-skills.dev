Herramienta de automatización de navegador inteligente impulsada por IA. Utiliza LLM para comprender páginas y ejecutar tareas automáticamente, de forma más inteligente y con mayor eficiencia simbólica que el Playwright tradicional. Adecuado para interacciones complejas, páginas dinámicas y operaciones de navegador que requieren una toma de decisiones inteligente. Preferiblemente el navegador Chrome.
