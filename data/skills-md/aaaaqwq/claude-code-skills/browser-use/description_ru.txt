Интеллектуальный инструмент автоматизации браузера на основе искусственного интеллекта. Он использует LLM для понимания страниц и автоматического выполнения задач, что делает его более умным и более эффективным с использованием токенов, чем традиционный Playwright. Подходит для сложных взаимодействий, динамических страниц и операций браузера, требующих разумных решений. Предпочтителен браузер Chrome.
