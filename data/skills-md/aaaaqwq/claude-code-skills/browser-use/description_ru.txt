Интеллектуальный инструмент автоматизации браузера на основе искусственного интеллекта. Использует LLM для понимания страниц и автоматического выполнения задач, что более умно и эффективно с точки зрения токенов, чем традиционный драматург. Подходит для сложных взаимодействий, динамических страниц и операций браузера, требующих интеллектуального принятия решений. Предпочтителен браузер Chrome.
