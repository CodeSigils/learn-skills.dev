Веб-версия WeChat Video Channel Assistant, полный рабочий процесс публикации видео. Он использует автоматизацию браузера для управленияchannels.weixin.qq.com для обнаружения входа в систему, входа в систему с помощью QR-кода, загрузки видео, заполнения описания и краткого заголовка, подтверждения скриншота, а затем публикации или сохранения в виде черновика. Сценарий триггера: пользователю необходимо опубликовать видео на Видеоканале, опубликовать на Видеоканале, загрузить видео на Видеоканал или опубликовать на Видеоканале.
