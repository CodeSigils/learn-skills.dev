Feishu Cloud Document تحسين المحتوى وتجميل التنسيق. استخدم هذه المهارة عندما يحتاج المستخدمون إلى تحسين تخطيط مستندات Feishu وبنيتها وتنسيقها وجمالياتها. الميزات المدعومة: (1) قراءة محتوى مستند Feishu، (2) تحسين بنية المستند وتسلسله الهرمي، (3) مسح محتوى المستند واستبداله، (4) تحرير المستندات عبر أتمتة المتصفح. كلمات التشغيل: تحسين مستند Feishu، وتجميل المستند، وتنظيم تنسيق المستند، وتخطيط المستند.
