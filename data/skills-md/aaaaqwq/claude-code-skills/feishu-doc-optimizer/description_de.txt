Feishu Cloud-Dokumentinhaltsoptimierung und Formatverschönerung. Nutzen Sie diese Fähigkeit, wenn Benutzer das Layout, die Struktur, das Format und die Ästhetik von Feishu-Dokumenten optimieren müssen. Auslöserwörter: Feishu-Dokument optimieren, Dokument verschönern, Dokumentformat organisieren, Dokumentlayout.
