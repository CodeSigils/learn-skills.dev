OpenClaw-Kommunikation zwischen Instanzen. Nutzen Sie diese Fähigkeit, wenn Sie Nachrichten weiterleiten, Daten synchronisieren oder Befehle aus der Ferne zwischen mehreren OpenClaw-Instanzen ausführen müssen. Es behandelt verschiedene Methoden wie Agent-zu-Agent-Messaging, nodes.run-Remoteausführung, Kommunikation auf Dateiebene und mehr.
