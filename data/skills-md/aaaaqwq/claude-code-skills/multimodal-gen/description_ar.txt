إنشاء محتوى متعدد الوسائط (الصور ومقاطع الفيديو). استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء صور، أو إنشاء صور، أو إنتاج مقاطع فيديو، أو إجراء رسم بالذكاء الاصطناعي، أو تصميم رسومي بالذكاء الاصطناعي، أو رسم صورة، أو إنشاء فيديو، أو إنشاء صور من نص، أو إنشاء مقاطع فيديو من نص. يقوم تلقائيًا باستدعاء الوكيل المتعدد الوسائط للإنشاء.
