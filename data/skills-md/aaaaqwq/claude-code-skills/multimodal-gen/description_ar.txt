إنشاء محتوى متعدد الوسائط (الصور ومقاطع الفيديو). استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء صور، أو إنشاء صور، أو إنتاج مقاطع فيديو، أو تنفيذ الرسم بالذكاء الاصطناعي، أو عمل رسومات الذكاء الاصطناعي، أو رسم صورة، أو إنشاء فيديو، أو تحويل نص إلى صورة، أو تحويل نص إلى فيديو. استدعاء الوكيل المتعدد الوسائط تلقائيًا للإنشاء.
