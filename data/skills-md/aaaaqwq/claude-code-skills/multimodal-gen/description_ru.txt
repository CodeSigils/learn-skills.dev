Генерация мультимодального контента (изображения, видео). Используйте этот навык, когда пользователю необходимо генерировать изображения, создавать изображения, создавать видео, выполнять рисование с использованием ИИ, графический дизайн с использованием ИИ, рисовать изображения, создавать видео, генерировать изображения из текста или создавать видео из текста. Он автоматически вызывает мультимодальный агент для генерации.
