Генерация мультимодального контента (изображения, видео). Используйте этот навык, когда пользователям нужно генерировать изображения, создавать изображения, создавать видео, рисовать с помощью ИИ, создавать рисунки с использованием ИИ, рисовать изображения, создавать видео, преобразовывать текст в изображение или конвертировать текст в видео. Автоматически вызывать мультимодальный агент для генерации.
