النموذج التلقائي الاحتياطي وتجاوز الفشل. عندما يفشل طلب النموذج الأساسي، أو تنتهي المهلة، أو يصل إلى الحد الأقصى للسعر، أو يستنفد حصته، فإنه يتحول تلقائيًا إلى نموذج احتياطي لضمان استمرارية الخدمة. يدعم اختيار الطراز الذكي متعدد البائعين والأولوية، مع مراقبة السلامة وإعادة المحاولة التلقائية وآليات استرداد الأخطاء.
