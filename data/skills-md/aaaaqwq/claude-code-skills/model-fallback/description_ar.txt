نموذج الرجوع إلى إصدار سابق وتجاوز الفشل تلقائيًا. عندما يفشل طلب النموذج الأساسي، أو تنتهي المهلة، أو يصل إلى حدود المعدل، أو يستنفد حصته، فإنه يتحول تلقائيًا إلى نموذج احتياطي لضمان استمرارية الخدمة. يدعم اختيار الطراز الذكي متعدد البائعين والأولوية المتعددة، مما يوفر مراقبة السلامة وإعادة المحاولة التلقائية وآليات استرداد الأخطاء.
