Автоматизация прямого подключения личного кабинета Enterprise WeChat. Реализовано на платформе Wechaty для получения сообщений Enterprise WeChat, автоматического принятия запросов на добавление в друзья, предоставления вопросов и ответов из базы знаний и отправки напоминаний о вмешательстве человека. Подходит для сценариев личных ботов и помощников по автоматизации в Enterprise WeChat.
