Автоматизация прямого подключения для личных учетных записей Enterprise WeChat. Реализовано с помощью инфраструктуры Wechaty для получения сообщений Enterprise WeChat, автоматического принятия запросов на добавление в друзья, предоставления вопросов и ответов из базы знаний и отправки напоминаний о вмешательстве человека. Подходит для личных корпоративных ботов WeChat и сценариев помощников по автоматизации.
