Strumento di pulizia dei file di sistema. Esegue la scansione e identifica file di grandi dimensioni e file spazzatura (file temporanei, cache, registri, backup, ecc.) e fornisce un'interfaccia di pulizia interattiva affinché gli utenti possano scegliere l'eliminazione. Utilizza questa capacità quando gli utenti hanno bisogno di liberare spazio su disco, organizzare file di sistema, trovare file di grandi dimensioni, eliminare file spazzatura o liberare spazio di archiviazione.
