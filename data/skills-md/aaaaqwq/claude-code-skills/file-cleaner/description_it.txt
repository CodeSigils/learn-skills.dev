Strumento per la pulizia dei file di sistema. Esegue la scansione e identifica file di grandi dimensioni e file spazzatura (file temporanei, cache, registri, backup, ecc.), fornisce un'interfaccia di pulizia interattiva che consente agli utenti di selezionare le eliminazioni. Utilizzare questa funzionalità quando l'utente ha bisogno di liberare spazio su disco, organizzare file di sistema, individuare file di grandi dimensioni, eliminare file spazzatura o liberare spazio di archiviazione.
