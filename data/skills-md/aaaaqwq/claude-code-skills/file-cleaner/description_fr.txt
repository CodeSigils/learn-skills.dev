Outil de nettoyage des fichiers système. Analyse et identifie les fichiers volumineux et les fichiers indésirables (fichiers temporaires, caches, journaux, sauvegardes, etc.), fournit une interface de nettoyage interactive permettant aux utilisateurs de sélectionner les suppressions. Utilisez cette fonctionnalité lorsque l'utilisateur a besoin de libérer de l'espace disque, d'organiser les fichiers système, de localiser des fichiers volumineux, de supprimer des fichiers inutiles ou de libérer de l'espace de stockage.
