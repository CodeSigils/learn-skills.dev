Tool zum Bereinigen von Systemdateien. Scannt und identifiziert große Dateien und Junk-Dateien (temporäre Dateien, Caches, Protokolle, Backups usw.) und bietet Benutzern eine interaktive Bereinigungsoberfläche, über die sie Löschvorgänge auswählen können. Verwenden Sie diese Funktion, wenn der Benutzer Speicherplatz freigeben, Systemdateien organisieren, große Dateien suchen, Junk-Dateien löschen oder Speicherplatz freigeben muss.
