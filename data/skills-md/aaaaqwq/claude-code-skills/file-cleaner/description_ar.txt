أداة تنظيف ملفات النظام. يقوم بمسح وتحديد الملفات الكبيرة والملفات غير المرغوب فيها (الملفات المؤقتة، وذاكرة التخزين المؤقت، والسجلات، والنسخ الاحتياطية، وما إلى ذلك)، ويوفر واجهة تنظيف تفاعلية للمستخدمين لتحديد عمليات الحذف. استخدم هذه الإمكانية عندما يحتاج المستخدم إلى تحرير مساحة على القرص، أو تنظيم ملفات النظام، أو تحديد موقع الملفات الكبيرة، أو حذف الملفات غير المرغوب فيها، أو تحرير مساحة التخزين.
