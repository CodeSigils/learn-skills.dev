Herramienta de limpieza de archivos del sistema. Escanea e identifica archivos grandes y archivos basura (archivos temporales, cachés, registros, copias de seguridad, etc.), proporciona una interfaz de limpieza interactiva para que los usuarios seleccionen eliminaciones. Utilice esta capacidad cuando el usuario necesite liberar espacio en el disco, organizar archivos del sistema, localizar archivos grandes, eliminar archivos basura o liberar espacio de almacenamiento.
