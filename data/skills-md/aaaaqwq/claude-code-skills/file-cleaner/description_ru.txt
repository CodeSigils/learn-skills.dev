Инструмент для очистки системных файлов. Сканирует и идентифицирует большие файлы и ненужные файлы (временные файлы, кеши, журналы, резервные копии и т. д.), предоставляет пользователям интерактивный интерфейс очистки для выбора удаления. Используйте эту возможность, когда пользователю необходимо освободить место на диске, упорядочить системные файлы, найти большие файлы, удалить ненужные файлы или освободить место для хранения.
