Инструмент очистки системных файлов. Сканирует и идентифицирует большие файлы и ненужные файлы (временные файлы, кэши, журналы, резервные копии и т. д.), а также предоставляет пользователям интерактивный интерфейс очистки, позволяющий выбрать удаление. Используйте этот навык, когда пользователям нужно освободить место на диске, упорядочить системные файлы, найти большие файлы, удалить ненужные файлы или освободить место для хранения.
