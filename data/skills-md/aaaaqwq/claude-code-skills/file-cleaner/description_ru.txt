Инструмент очистки системных файлов. Сканирует и идентифицирует большие файлы, ненужные файлы (временные файлы, кэш, журналы, резервные копии и т. д.), а также предоставляет пользователям интерактивный интерфейс очистки для выбора удаления. Используйте этот навык, когда пользователям нужно очистить дисковое пространство, упорядочить системные файлы, найти большие файлы, удалить ненужные файлы или освободить место для хранения.
