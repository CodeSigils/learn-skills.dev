الاستعلام عن الحصص والتوازن والاستهلاك لمقدمي/خدمات واجهة برمجة التطبيقات ومراقبتها. يدعم مقدمي الخدمات الرسميين (Gemini، وxAI، وZAI، وMinimax، وOpenRouter، وما إلى ذلك)، والوسطاء (AIXN، وProvider‑A، وما إلى ذلك)، وخدمات الاشتراك (Brave، وTavily، وSerper). كلمات التشغيل: التحقق من الحصة، والتحقق من الرصيد، واستخدام واجهة برمجة التطبيقات، وحصة الموفر، والحصة، والتوازن، والاستخدام، والفوترة.
