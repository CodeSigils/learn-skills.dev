الاستعلام عن حصص مزود/خدمة واجهة برمجة التطبيقات (API)، والأرصدة، والاستهلاك. يدعم مقدمي الخدمات الرسميين (Gemini/xAI/ZAI/Minimax/OpenRouter، وما إلى ذلك)، ومحطات الترحيل (AIXN/Provider-A، وما إلى ذلك)، وخدمات الاشتراك (Brave/Tavily/Serper). كلمات التشغيل: التحقق من الحصة، والتحقق من الرصيد، واستخدام واجهة برمجة التطبيقات، وحصة الموفر، والحصة، والتوازن، والاستخدام، والفوترة.
