Interroga e monitora la quota, il saldo e il consumo di provider/servizi API. Supports official providers (Gemini, xAI, ZAI, Minimax, OpenRouter, etc.), intermediaries (AIXN, Provider‑A, etc.), and subscription services (Brave, Tavily, Serper). Parole chiave: controlla quota, controlla saldo, utilizzo API, quota provider, quota, saldo, utilizzo, fatturazione.
