Collection unifiée de sujets d'actualité à partir de sources d'informations. Obtenez librement du contenu populaire sur six plates-formes majeures : X/Twitter, YouTube, Bilibili, GitHub, Reddit et LinuxDo – et générez un pool de sujets d'actualité standardisés à utiliser dans le pipeline de création de contenu. Le tout en utilisant des API publiques gratuites, aucun paiement requis.
