Strumento di sincronizzazione con un clic dell'ambiente Claude Code. Sincronizza tutte le configurazioni da un repository GitHub in locale: temi di stili di output, prompt globali CLAUDE.md, configurazione del server MCP. Adatto a scenari come ambienti unificati su più dispositivi, ripristino su un nuovo computer, configurazioni condivise dal team, ecc. Utilizzare questa competenza quando un utente deve sincronizzare le impostazioni dell'ambiente Claude Code da un repository GitHub.
