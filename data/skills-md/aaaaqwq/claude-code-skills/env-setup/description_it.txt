Strumento di sincronizzazione con un clic dell'ambiente Claude Code. Sincronizza tutte le configurazioni da un repository GitHub al computer locale: temi degli stili di output, prompt globali CLAUDE.md, impostazioni del server MCP. Adatto a scenari come il mantenimento di un ambiente unificato su più dispositivi, il ripristino dopo aver cambiato computer e la condivisione delle configurazioni all'interno di un team. Utilizza questa competenza quando l'utente deve sincronizzare le configurazioni dell'ambiente Claude Code da un repository GitHub.
