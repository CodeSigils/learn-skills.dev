Ein-Klick-Synchronisierungstool für die Claude Code-Umgebung. Synchronisieren Sie alle Konfigurationen aus einem GitHub-Repository mit lokalen: Ausgabestilthemen, globalen CLAUDE.md-Eingabeaufforderungen, MCP-Serverkonfiguration. Geeignet für Szenarien wie einheitliche Umgebungen auf mehreren Geräten, Wiederherstellung auf einem neuen Computer, vom Team gemeinsam genutzte Konfigurationen usw. Verwenden Sie diese Fähigkeit, wenn ein Benutzer Claude Code-Umgebungseinstellungen aus einem GitHub-Repository synchronisieren muss.
