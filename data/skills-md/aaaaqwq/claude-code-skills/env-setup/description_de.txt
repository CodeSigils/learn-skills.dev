Claude Code Environment Ein-Klick-Synchronisierungstool. Synchronisieren Sie alle Konfigurationen aus einem GitHub-Repository mit lokalen: Ausgabestilen, globalen CLAUDE.md-Eingabeaufforderungen und MCP-Serverkonfigurationen. Ideal für die Vereinheitlichung von Umgebungen auf mehreren Geräten, die Wiederherstellung nach einem Computerwechsel, die gemeinsame Nutzung von Konfigurationen innerhalb von Teams und ähnliche Szenarien. Verwenden Sie diesen Skill, wenn Benutzer Claude Code-Umgebungskonfigurationen aus einem GitHub-Repository synchronisieren müssen.
