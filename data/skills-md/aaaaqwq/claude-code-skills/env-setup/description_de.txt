Ein-Klick-Synchronisierungstool für die Claude Code-Umgebung. Synchronisieren Sie alle Konfigurationen aus einem GitHub-Repository mit dem lokalen Computer: Ausgabestilthemen, globale CLAUDE.md-Eingabeaufforderungen, MCP-Servereinstellungen. Geeignet für Szenarien wie die Aufrechterhaltung einer einheitlichen Umgebung auf mehreren Geräten, die Wiederherstellung nach einem Computerwechsel und die gemeinsame Nutzung von Konfigurationen innerhalb eines Teams. Verwenden Sie diesen Skill, wenn der Benutzer Claude Code-Umgebungskonfigurationen aus einem GitHub-Repository synchronisieren muss.
