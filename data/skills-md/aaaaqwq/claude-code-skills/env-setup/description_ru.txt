Инструмент синхронизации среды Claude Code одним щелчком мыши. Синхронизируйте все конфигурации из репозитория GitHub на локальный компьютер: темы стилей вывода, глобальные подсказки CLAUDE.md, настройки сервера MCP. Подходит для таких сценариев, как поддержка единой среды на нескольких устройствах, восстановление после смены компьютеров и совместное использование конфигураций внутри команды. Используйте этот навык, когда пользователю необходимо синхронизировать конфигурации среды Claude Code из репозитория GitHub.
