Инструмент синхронизации среды Claude Code в один клик. Синхронизируйте все конфигурации из репозитория GitHub с локальным: темы стилей вывода, глобальные подсказки CLAUDE.md, конфигурацию сервера MCP. Подходит для таких сценариев, как объединение сред на нескольких устройствах, восстановление на новом компьютере, общие конфигурации группы и т. д. Используйте этот навык, когда пользователю необходимо синхронизировать параметры среды Claude Code из репозитория GitHub.
