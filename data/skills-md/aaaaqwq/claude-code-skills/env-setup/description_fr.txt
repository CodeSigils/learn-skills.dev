Outil de synchronisation en un clic de Claude Code Environment. Synchronisez toutes les configurations d'un référentiel GitHub vers local : styles de sortie, invites globales CLAUDE.md, configurations du serveur MCP. Idéal pour unifier les environnements sur plusieurs appareils, récupérer après un changement d'ordinateur, partager des configurations au sein d'équipes et des scénarios similaires. Utilisez cette compétence lorsque les utilisateurs doivent synchroniser les configurations de l'environnement Claude Code à partir d'un référentiel GitHub.
