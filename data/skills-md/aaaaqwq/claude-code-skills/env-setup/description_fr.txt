Outil de synchronisation en un clic de l'environnement Claude Code. Synchronisez toutes les configurations d'un référentiel GitHub avec la machine locale : thèmes de styles de sortie, invites globales CLAUDE.md, paramètres du serveur MCP. Convient à des scénarios tels que le maintien d'un environnement unifié sur plusieurs appareils, la restauration après un changement d'ordinateur et le partage de configurations au sein d'une équipe. Utilisez cette compétence lorsque l'utilisateur a besoin de synchroniser les configurations de l'environnement Claude Code à partir d'un référentiel GitHub.
