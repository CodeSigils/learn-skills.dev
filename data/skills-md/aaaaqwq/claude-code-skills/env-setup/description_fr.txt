Outil de synchronisation en un clic de l'environnement Claude Code. Synchronisez toutes les configurations d'un référentiel GitHub vers local : thèmes de styles de sortie, invites globales CLAUDE.md, configuration du serveur MCP. Convient à des scénarios tels que des environnements unifiés sur plusieurs appareils, la restauration sur un nouvel ordinateur, les configurations partagées en équipe, etc. Utilisez cette compétence lorsqu'un utilisateur a besoin de synchroniser les paramètres d'environnement Claude Code à partir d'un référentiel GitHub.
