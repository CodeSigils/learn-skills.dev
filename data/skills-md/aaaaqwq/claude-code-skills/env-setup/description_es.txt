Herramienta de sincronización con un clic de Claude Code Environment. Sincronice todas las configuraciones desde un repositorio de GitHub a local: estilos de salida, mensajes globales CLAUDE.md, configuraciones del servidor MCP. Ideal para unificar entornos en múltiples dispositivos, recuperarse después de cambiar de computadora, compartir configuraciones dentro de equipos y escenarios similares. Utilice esta habilidad cuando los usuarios necesiten sincronizar las configuraciones del entorno de Claude Code desde un repositorio de GitHub.
