Herramienta de sincronización con un solo clic del entorno Claude Code. Sincronice todas las configuraciones desde un repositorio de GitHub al local: temas de estilos de salida, mensajes globales de CLAUDE.md, configuración del servidor MCP. Adecuado para escenarios como entornos unificados en múltiples dispositivos, restauración en una computadora nueva, configuraciones compartidas en equipo, etc. Utilice esta habilidad cuando un usuario necesite sincronizar la configuración del entorno de Claude Code desde un repositorio de GitHub.
