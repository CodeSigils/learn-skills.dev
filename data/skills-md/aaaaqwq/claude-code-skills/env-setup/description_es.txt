Herramienta de sincronización con un solo clic del entorno Claude Code. Sincronice todas las configuraciones desde un repositorio de GitHub con la máquina local: temas de estilos de salida, mensajes globales de CLAUDE.md, configuración del servidor MCP. Adecuado para escenarios como mantener un entorno unificado en múltiples dispositivos, restaurar después de cambiar de computadora y compartir configuraciones dentro de un equipo. Utilice esta habilidad cuando el usuario necesite sincronizar las configuraciones del entorno de Claude Code desde un repositorio de GitHub.
