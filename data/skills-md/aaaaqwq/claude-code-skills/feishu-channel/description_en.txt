A two-way integration channel between Feishu (Lark/Feishu) and OpenClaw. It enables message receiving and sending through a Feishu bot, supporting private chats, group chats, @ mention detection, card messages, and file transfers. Use this skill when you need to interact with an AI assistant via Feishu, trigger AI responses upon receiving Feishu messages, or send messages from OpenClaw to Feishu. Difference from feishu-automation: this skill focuses on message channel integration, while feishu-automation focuses on Feishu platform automation (multi-dimensional tables, documents, etc.).
