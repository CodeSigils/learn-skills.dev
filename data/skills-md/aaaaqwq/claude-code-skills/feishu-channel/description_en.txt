Feishu (Lark/Feishu) and OpenClaw bidirectional integration channel. Receive and send messages via Feishu bot, supporting private chats, group chats, @mention detection, card messages, and file transfers. Use this skill when interacting with an AI assistant through Feishu, receiving Feishu messages to trigger AI responses, or sending messages from OpenClaw to Feishu. Difference from feishu-automation: this skill focuses on message channel integration, while feishu-automation focuses on Feishu platform automation tasks (multidimensional tables, documents, etc.).
