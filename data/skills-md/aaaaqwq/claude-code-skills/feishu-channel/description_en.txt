Feishu (Lark/Feishu) and OpenClaw bidirectional integration channel. Receive and send messages via a Feishu bot, supporting private chats, group chats, @mention detection, card messages, and file transfer. Use this skill when you need to interact with an AI assistant through Feishu, receive Feishu messages that trigger AI responses, or send messages from OpenClaw to Feishu. Difference from feishu-automation: this skill focuses on message channel integration, while feishu-automation focuses on automation operations on the Feishu platform (multidimensional tables, documents, etc.).
