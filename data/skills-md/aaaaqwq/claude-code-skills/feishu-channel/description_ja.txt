Feishu (Lark/Feishu) と OpenClaw 間の双方向統合チャネル。 Feishu ボットを介したメッセージの送受信が可能になり、プライベート チャット、グループ チャット、@ メンション検出、カード メッセージ、ファイル転送がサポートされます。 Feishu 経由で AI アシスタントと対話する必要がある場合、Feishu メッセージの受信時に AI 応答をトリガーする必要がある場合、または OpenClaw から Feishu にメッセージを送信する必要がある場合に、このスキルを使用します。 feishu-automation との違い: このスキルはメッセージ チャネルの統合に重点を置いているのに対し、feishu-automation は Feishu プラットフォームの自動化 (多次元テーブル、ドキュメントなど) に重点を置いています。
