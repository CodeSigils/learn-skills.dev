Ein bidirektionaler Integrationskanal zwischen Feishu (Lark/Feishu) und OpenClaw. Es ermöglicht das Empfangen und Senden von Nachrichten über einen Feishu-Bot und unterstützt private Chats, Gruppenchats, @-Erwähnungserkennung, Kartennachrichten und Dateiübertragungen. Verwenden Sie diese Fähigkeit, wenn Sie über Feishu mit einem KI-Assistenten interagieren, beim Empfang von Feishu-Nachrichten KI-Reaktionen auslösen oder Nachrichten von OpenClaw an Feishu senden müssen. Unterschied zur Feishu-Automation: Diese Fähigkeit konzentriert sich auf die Integration von Nachrichtenkanälen, während sich Feishu-Automation auf die Automatisierung der Feishu-Plattform (mehrdimensionale Tabellen, Dokumente usw.) konzentriert.
