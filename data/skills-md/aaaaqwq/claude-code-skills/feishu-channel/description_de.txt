Bidirektionaler Integrationskanal von Feishu (Lark/Feishu) und OpenClaw. Empfangen und senden Sie Nachrichten über den Feishu-Bot und unterstützen Sie private Chats, Gruppenchats, @mention-Erkennung, Kartennachrichten und Dateiübertragungen. Verwenden Sie diese Fähigkeit, wenn Sie über Feishu mit einem KI-Assistenten interagieren, Feishu-Nachrichten empfangen, um KI-Antworten auszulösen, oder Nachrichten von OpenClaw an Feishu senden. Unterschied zur Feishu-Automation: Diese Fähigkeit konzentriert sich auf die Integration von Nachrichtenkanälen, während sich Feishu-Automation auf Automatisierungsaufgaben der Feishu-Plattform (mehrdimensionale Tabellen, Dokumente usw.) konzentriert.
