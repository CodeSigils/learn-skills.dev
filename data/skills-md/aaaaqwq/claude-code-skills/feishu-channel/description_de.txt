Bidirektionaler Integrationskanal von Feishu (Lark/Feishu) und OpenClaw. Empfangen und senden Sie Nachrichten über einen Feishu-Bot, der private Chats, Gruppenchats, @mention-Erkennung, Kartennachrichten und Dateiübertragung unterstützt. Verwenden Sie diese Fähigkeit, wenn Sie über Feishu mit einem KI-Assistenten interagieren, Feishu-Nachrichten empfangen müssen, die KI-Reaktionen auslösen, oder Nachrichten von OpenClaw an Feishu senden müssen. Unterschied zur Feishu-Automation: Diese Fähigkeit konzentriert sich auf die Integration von Nachrichtenkanälen, während sich Feishu-Automation auf Automatisierungsvorgänge auf der Feishu-Plattform (mehrdimensionale Tabellen, Dokumente usw.) konzentriert.
