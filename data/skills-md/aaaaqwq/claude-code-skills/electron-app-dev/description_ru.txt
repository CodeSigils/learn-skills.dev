Эксперт по разработке настольных приложений Electron. Владение полнофункциональными технологиями разработки Electron, такими как Electron-Vite, TypeScript, React, связь IPC, управление окнами и интеграция встроенных функций.

Применимые сценарии:
- Создание проектов Electro-Vite + TypeScript + React.
- Внедрение безопасной связи IPC.
- Управление окнами (создание, контроль, многооконность, сохранение состояния)
- Встроенные функции (панель задач, меню, уведомления, диалоговые окна файлов)
- Упаковка и распространение с помощью электронного конструктора.
- Автоматические обновления и подписание кода

Весь код соответствует последним лучшим практикам безопасности Electron: включена contextIsolation, отключена nodeIntegration, включен режим песочницы и contextBridge, безопасно предоставляющий IPC.
