Experto en desarrollo de aplicaciones de escritorio de Electron. Competente en electron-vite, TypeScript, React, comunicación IPC, gestión de ventanas, integración de funciones nativas y otras tecnologías de desarrollo completo de Electron.

Escenarios aplicables:
- Crear proyectos electron-vite+TypeScript+React
- Implementar comunicación IPC segura.
- Gestión de ventanas (creación, control, múltiples ventanas, persistencia de estado)
- Funciones nativas (bandeja del sistema, menús, notificaciones, cuadros de diálogo de archivos)
- embalaje y distribución de constructores de electrones
- Actualizaciones automáticas y firma de código.

Todo el código sigue las últimas mejores prácticas de seguridad de Electron: contextIsolation habilitado, nodeIntegration deshabilitado, modo sandbox habilitado, contextBridge expone de forma segura IPC.
