Esperto di sviluppo di applicazioni desktop Electron. Competente nelle tecnologie di sviluppo Electron full-stack come Electron-Vite, TypeScript, React, comunicazione IPC, gestione delle finestre e integrazione di funzionalità native.

Scenari applicabili:
- Creazione di progetti Electron-Vite + TypeScript + React
- Implementazione della comunicazione IPC sicura
- Gestione delle finestre (creazione, controllo, multi-finestra, persistenza dello stato)
- Funzionalità native (barra delle applicazioni, menu, notifiche, finestre di dialogo file)
- Confezionamento e distribuzione con costruttore di elettroni
- Aggiornamenti automatici e firma del codice

Tutto il codice segue le ultime best practice di sicurezza di Electron: contextIsolation abilitato, nodeIntegration disabilitato, modalità sandbox abilitata e contextBridge che espone in modo sicuro IPC.
