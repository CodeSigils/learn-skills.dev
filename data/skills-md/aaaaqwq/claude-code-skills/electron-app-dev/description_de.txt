Experte für die Entwicklung von Electron-Desktopanwendungen. Kenntnisse in Electron-Vite, TypeScript, React, IPC-Kommunikation, Fensterverwaltung, nativer Funktionsintegration und anderen Full-Stack-Electron-Entwicklungstechnologien.

Anwendbare Szenarien:
- Erstellen Sie Electron-Vite+TypeScript+React-Projekte
- Implementieren Sie eine sichere IPC-Kommunikation
- Fensterverwaltung (Erstellung, Steuerung, mehrere Fenster, Statuspersistenz)
- Native Funktionen (Taskleiste, Menüs, Benachrichtigungen, Dateidialoge)
- Verpackung und Vertrieb von Elektronenbildnern
- Automatische Updates und Code-Signierung

Der gesamte Code folgt den neuesten Best Practices für die Sicherheit von Electron: contextIsolation aktiviert, nodeIntegration deaktiviert, Sandbox-Modus aktiviert, contextBridge macht IPC sicher verfügbar.
