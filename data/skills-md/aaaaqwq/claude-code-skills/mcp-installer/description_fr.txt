Recherchez GitHub et installez et configurez automatiquement l'outil serveur MCP (Model Context Protocol) dans le fichier de configuration Claude. Cette compétence est déclenchée lorsque l'utilisateur doit installer l'outil MCP. Workflow : recherchez le projet MCP sur GitHub → extrayez la configuration npx → ajoutez-la à ~/.claude.json → gérez la clé API (le cas échéant).
