Recherchez sur GitHub, installez et configurez automatiquement les outils serveur MCP (Model Context Protocol) dans le fichier de configuration Claude. Déclenchez cette compétence lorsque l'utilisateur doit installer un outil MCP. Workflow : recherchez des projets MCP sur GitHub → Extraire la configuration npx → Ajouter à ~/.claude.json → Gérer les clés API (le cas échéant).
