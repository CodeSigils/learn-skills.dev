Durchsuchen Sie GitHub nach MCP-Servertools (Model Context Protocol) und installieren und konfigurieren Sie diese automatisch in der Claude-Konfigurationsdatei. Lösen Sie diesen Skill aus, wenn der Benutzer ein MCP-Tool installieren muss. Arbeitsablauf: Auf GitHub nach MCP-Projekten suchen → Npx-Konfiguration extrahieren → Zu ~/.claude.json hinzufügen → API-Schlüssel verarbeiten (falls vorhanden).
