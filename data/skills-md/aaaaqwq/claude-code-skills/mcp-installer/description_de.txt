Durchsuchen Sie GitHub und installieren und konfigurieren Sie das MCP-Servertool (Model Context Protocol) automatisch in der Claude-Konfigurationsdatei. Dieser Skill wird ausgelöst, wenn der Benutzer das MCP-Tool installieren muss. Arbeitsablauf: Suchen Sie auf GitHub nach dem MCP-Projekt → extrahieren Sie die npx-Konfiguration → fügen Sie sie zu ~/.claude.json hinzu → verarbeiten Sie den API-Schlüssel (falls vorhanden).
