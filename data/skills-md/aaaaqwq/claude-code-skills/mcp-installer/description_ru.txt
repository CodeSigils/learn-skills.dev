Найдите на GitHub и автоматически установите и настройте серверные инструменты MCP (Model Context Protocol) в файл конфигурации Claude. Активируйте этот навык, когда пользователю необходимо установить инструмент MCP. Рабочий процесс: поиск проектов MCP на GitHub → Извлечение конфигурации npx → Добавить в ~/.claude.json → Обработка ключей API (если есть).
