Найдите GitHub, автоматически установите и настройте серверный инструмент MCP (Model Context Protocol) в файле конфигурации Claude. Этот навык срабатывает, когда пользователю необходимо установить инструмент MCP. Рабочий процесс: найдите проект MCP на GitHub → извлеките конфигурацию npx → добавьте ее в ~/.claude.json → обработайте ключ API (если есть).
