Gérez la configuration globale des autorisations des outils pour Claude Code, en ajoutant automatiquement des commandes MCP ou d'autres outils à AllowTools pour éviter une approbation manuelle à chaque fois qu'ils sont utilisés. Workflow : confirmer la commande que l'utilisateur souhaite ajouter → confirmer le niveau d'ajout (global par défaut ~/.claude.json) → exécuter l'ajout → vérifier et rappeler de redémarrer.
