Gérez la configuration globale des autorisations des outils pour Claude Code, ajoutez automatiquement des commandes MCP ou d'autres outils à AllowTools, évitant ainsi le besoin d'une approbation manuelle à chaque fois qu'ils sont utilisés. Workflow : confirmer la commande que l'utilisateur doit ajouter → confirmer le niveau d'ajout (par défaut global~/.claude.json) → effectuer l'ajout → vérifier et demander un redémarrage.
