Управляйте глобальной конфигурацией разрешений инструментов для Claude Code, автоматически добавляйте команды MCP или другие инструменты в разрешенные инструменты, избегая необходимости ручного утверждения при каждом их использовании. Рабочий процесс: подтвердите команду, которую необходимо добавить пользователю → подтвердите уровень добавления (по умолчанию global~/.claude.json) → выполните добавление → проверьте и предложите перезагрузку.
