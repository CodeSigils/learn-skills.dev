Assistent zur Änderung der OpenClaw-Konfiguration. Bevor Sie eine OpenClaw-Konfiguration ändern, müssen Sie zunächst die offizielle Dokumentation konsultieren, um sicherzustellen, dass das Format korrekt ist und Systemabstürze oder Funktionsstörungen vermieden werden. Erzwungener Arbeitsablauf: Schema prüfen → Dokumentation konsultieren → Bestätigen → Ändern.
