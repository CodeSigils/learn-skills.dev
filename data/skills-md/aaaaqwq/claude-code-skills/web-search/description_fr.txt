Recherche sur le Web et récupération de contenu Web. Utilisez cette compétence lorsque les utilisateurs doivent rechercher des informations sur Internet, obtenir du contenu Web, trouver des données en temps réel ou effectuer des recherches sur le Web. Plusieurs outils de recherche sont pris en charge : WebFetch, compétence Firecrawl, compétence Tavily.
