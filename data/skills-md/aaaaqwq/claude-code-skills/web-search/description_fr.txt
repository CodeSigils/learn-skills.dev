Recherche sur le réseau et récupération du contenu des pages Web. Cette compétence est utilisée lorsque les utilisateurs doivent rechercher des informations sur Internet, récupérer le contenu d'une page Web, trouver des données en temps réel ou effectuer une recherche sur le Web. Prend en charge plusieurs outils de recherche : WebFetch, compétence Firecrawl, compétence Tavily.
