Ricerca in rete e recupero dei contenuti delle pagine web. Questa abilità viene utilizzata quando gli utenti devono cercare informazioni su Internet, recuperare il contenuto di una pagina Web, trovare dati in tempo reale o eseguire una ricerca sul Web. Supporta più strumenti di ricerca: WebFetch, abilità Firecrawl, abilità Tavily.
