Сетевой поиск и получение веб-контента. Используйте этот навык, когда пользователю необходимо выполнить поиск информации в Интернете, получить содержимое веб-страницы, просмотреть данные в реальном времени или выполнить поиск в Интернете. Поддерживает несколько инструментов поиска: WebFetch, навык Firecrawl, навык Tavily.
