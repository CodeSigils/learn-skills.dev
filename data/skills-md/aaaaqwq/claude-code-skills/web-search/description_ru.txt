Сетевой поиск и получение содержимого веб-страниц. Этот навык используется, когда пользователям необходимо выполнить поиск информации в Интернете, получить содержимое веб-страницы, найти данные в реальном времени или выполнить поиск в Интернете. Поддерживает несколько инструментов поиска: WebFetch, навык Firecrawl, навык Tavily.
