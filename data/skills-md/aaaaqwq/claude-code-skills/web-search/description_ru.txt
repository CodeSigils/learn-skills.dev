Поиск в Интернете и получение веб-контента. Используйте этот навык, когда пользователям нужно искать информацию в Интернете, получать веб-контент, находить данные в реальном времени или выполнять поиск в Интернете. Поддерживаются несколько инструментов поиска: WebFetch, навык Firecrawl, навык Tavily.
