Автоматизация браузера драматурга. Используется для сценариев, требующих автоматизации браузера, таких как автоматическое сканирование, сбор данных, заполнение форм, тестирование пользовательского интерфейса и многое другое. Никакого ручного вмешательства не требуется, что делает его пригодным для задач, запланированных cron.
