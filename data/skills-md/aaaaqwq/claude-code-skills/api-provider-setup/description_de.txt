Fügen Sie API-Relay-Anbieter von Drittanbietern in OpenClaw hinzu und konfigurieren Sie sie. Dieser Skill wird verwendet, wenn Benutzer einen neuen API-Anbieter hinzufügen, ein Relay konfigurieren oder einen benutzerdefinierten Modellendpunkt festlegen müssen. Es unterstützt Anthropic-kompatible und OpenAI-kompatible API-Formate.
