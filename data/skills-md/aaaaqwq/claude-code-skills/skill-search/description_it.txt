Cerca su siti ufficiali come GitHub e SkillsMP competenze di alta qualità che corrispondano alla descrizione dell'utente, presentale affinché l'utente possa sceglierle, quindi clona e installa automaticamente la competenza selezionata nella directory globale ~/.claude/skills/ . Questa abilità viene attivata quando l'utente deve cercare o installare una nuova abilità.
