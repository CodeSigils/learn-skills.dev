Найдите на официальных веб-сайтах, таких как GitHub и SkillsMP, высококачественные навыки, соответствующие описанию пользователя, представьте их на выбор пользователя, затем автоматически клонируйте и установите выбранный навык в глобальный каталог ~/.claude/skills/. Активируйте этот навык, когда пользователю нужно найти или установить новый навык.
