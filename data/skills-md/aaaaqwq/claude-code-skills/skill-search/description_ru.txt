Найдите на официальных сайтах, таких как GitHub и SkillsMP, высококачественные навыки, соответствующие описанию пользователя, представьте их на выбор пользователя, а затем автоматически клонируйте и установите выбранный навык в глобальный каталог ~/.claude/skills/. Этот навык срабатывает, когда пользователю необходимо найти или установить новый навык.
