Recherchez sur les sites Web officiels tels que GitHub et SkillsMP des compétences de haute qualité qui correspondent à la description de l'utilisateur, présentez-les à l'utilisateur pour qu'il puisse les choisir, puis clonez et installez automatiquement la compétence sélectionnée dans le répertoire global~/.claude/skills/. Déclenchez cette compétence lorsque l'utilisateur doit rechercher ou installer une nouvelle compétence.
