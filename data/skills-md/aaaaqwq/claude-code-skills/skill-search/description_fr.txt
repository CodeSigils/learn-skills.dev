Recherchez des compétences de haute qualité correspondant à la description de l'utilisateur sur des sites officiels comme GitHub et SkillsMP, présentez-les pour sélection, puis clonez et installez automatiquement la compétence choisie dans le répertoire global ~/.claude/skills/. Cette compétence se déclenche lorsque l'utilisateur doit rechercher ou installer une nouvelle compétence.
