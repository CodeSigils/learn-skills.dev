Durchsuchen Sie offizielle Websites wie GitHub und SkillsMP nach hochwertigen Fertigkeiten, die der Beschreibung des Benutzers entsprechen, präsentieren Sie sie dem Benutzer zur Auswahl und klonen Sie dann automatisch die ausgewählte Fertigkeit und installieren Sie sie im globalen ~/.claude/skills/ Verzeichnis. Dieser Skill wird ausgelöst, wenn der Benutzer nach einem neuen Skill suchen oder ihn installieren muss.
