Universelles Tool zur automatischen Veröffentlichung von Self-Media-Artikeln. Unterstützt automatisierte Veröffentlichungsworkflows für Baijiahao, Sohu und Zhihu. Verwendet das Playwright MCP-Tool zum Navigieren auf Plattformen und zum Aufrufen von Veröffentlichungsseiten und unterstützt den Kontowechsel über die StorageState-Cookie-Verwaltung. Nutzen Sie diese Fähigkeit, wenn Benutzer Artikel auf Self-Media-Plattformen veröffentlichen, Plattformveröffentlichungsseiten öffnen oder Konten wechseln müssen. Arbeitsablauf: 1) Überprüfen und öffnen Sie die angegebene Plattform. 2) Überprüfen Sie den Anmeldestatus. 3) Schließen Sie Anzeigen-Popups automatisch. 4) Navigieren Sie zur Artikelveröffentlichungsseite. 5) Sammeln Sie Veröffentlichungsinformationen. 6) Automatisch ausfüllen und veröffentlichen.
