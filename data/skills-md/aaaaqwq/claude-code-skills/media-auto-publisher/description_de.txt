Universelles Tool zur automatischen Veröffentlichung von Self-Media-Artikeln. Unterstützt automatisierte Veröffentlichungsworkflows für drei Plattformen: Baijiahao, Sohuhao und Zhihu. Nutzt das Playwright MCP-Tool, um auf Plattformen zu navigieren und auf die Veröffentlichungsseiten zuzugreifen, und unterstützt den Kontowechsel durch die Verwaltung von Cookies über storageState. Diese Fähigkeit wird verwendet, wenn ein Benutzer einen Artikel auf einer Self-Media-Plattform veröffentlichen, die Veröffentlichungsseite der Plattform öffnen oder das Self-Media-Konto wechseln muss. Arbeitsablauf: 1) Überprüfen und öffnen Sie die angegebene Plattform. 2) Überprüfen Sie den Anmeldestatus. 3) Schließen Sie Anzeigen-Popups automatisch. 4) Navigieren Sie zur Artikelveröffentlichungsseite. 5) Sammeln Sie Veröffentlichungsinformationen. 6) Automatisch ausfüllen und veröffentlichen.
