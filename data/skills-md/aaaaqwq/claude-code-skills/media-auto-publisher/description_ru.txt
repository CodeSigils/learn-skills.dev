Универсальный автоматизированный инструмент публикации статей для СМИ. Он поддерживает автоматизированные процессы публикации для трех платформ: Baijiahao, Sohuhao и Zhihu. Он использует инструмент Playwright MCP для перехода к платформам и входа на страницу публикации, а также поддерживает переключение учетных записей путем управления файлами cookie через StorageState. Этот навык используется, когда пользователям необходимо публиковать статьи на платформах для самостоятельного использования средств массовой информации, открывать страницу публикации платформы или переключать учетные записи для средств массовой информации. Рабочий процесс: 1) Проверьте и откройте указанную платформу 2) Проверьте статус входа в систему 3) Автоматически закройте всплывающие окна с рекламой 4) Перейдите на страницу публикации статьи 5) Соберите информацию о публикации 6) Автоматически заполните и опубликуйте.
