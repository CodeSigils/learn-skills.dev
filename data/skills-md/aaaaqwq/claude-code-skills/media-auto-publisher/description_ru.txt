Универсальный инструмент для автоматической публикации статей в СМИ. Поддерживает автоматизированные рабочие процессы публикации для трех платформ: Baijiahao, Sohuhao и Zhihu. Использует инструмент Playwright MCP для навигации по платформам и доступа к страницам публикации, а также поддерживает переключение учетных записей путем управления файлами cookie через StorageState. Этот навык используется, когда пользователю необходимо опубликовать статью на платформе самостоятельного распространения информации, открыть страницу публикации платформы или переключить учетную запись средства массовой информации. Рабочий процесс: 1) Проверьте и откройте указанную платформу 2) Проверьте статус входа в систему 3) Автоматически закройте всплывающие окна с рекламой 4) Перейдите на страницу публикации статьи 5) Соберите информацию о публикации 6) Автоматически заполните и опубликуйте.
