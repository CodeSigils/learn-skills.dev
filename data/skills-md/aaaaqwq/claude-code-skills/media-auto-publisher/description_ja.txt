ユニバーサルセルフメディア記事自動公開ツール。 Baijiahao、Sohuhao、Zhihu の 3 つのプラットフォームの自動公開ワークフローをサポートします。 Playwright MCP ツールを利用してプラットフォームを移動し、公開ページにアクセスし、storageState を介して Cookie を管理することでアカウントの切り替えをサポートします。このスキルは、ユーザーがセルフメディア プラットフォームに記事を公開するか、プラットフォームの公開ページを開くか、セルフメディア アカウントを切り替える必要がある場合に使用されます。ワークフロー: 1) 指定されたプラットフォームを確認して開きます 2) ログイン ステータスを確認します 3) 広告ポップアップを自動的に閉じます 4) 記事公開ページに移動します 5) 公開情報を収集します 6) 自動的に入力して公開します。
