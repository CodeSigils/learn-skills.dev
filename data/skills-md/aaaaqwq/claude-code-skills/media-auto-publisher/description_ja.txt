セルフメディア記事のための汎用自動公開ツール。 Baijiahao、Sohuhao、Zhihu の 3 つのプラットフォームの自動公開プロセスをサポートしています。 Playwright MCP ツールを使用してプラットフォームに移動し、公開ページに入り、storageState を通じて Cookie を管理することでアカウントの切り替えをサポートします。このスキルは、ユーザーがセルフメディア プラットフォームに記事を公開したり、プラットフォームの公開ページを開いたり、セルフメディア アカウントを切り替えたりする必要がある場合に使用されます。ワークフロー: 1) 指定されたプラットフォームを確認して開きます 2) ログイン ステータスを確認します 3) 広告ポップアップを自動的に閉じます 4) 記事公開ページに移動します 5) 公開情報を収集します 6) 自動的に入力して公開します。
