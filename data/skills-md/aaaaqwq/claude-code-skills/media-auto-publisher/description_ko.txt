범용 셀프 미디어 기사 자동 게시 도구입니다. Baijiahao, Sohuhao 및 Zhihu의 세 가지 플랫폼에 대한 자동화된 출판 워크플로우를 지원합니다. Playwright MCP 도구를 활용하여 플랫폼을 탐색하고 게시 페이지에 액세스하며, StorageState를 통해 쿠키를 관리하여 계정 전환을 지원합니다. 이 스킬은 사용자가 셀프 미디어 플랫폼에 기사를 게시해야 하거나, 플랫폼의 게시 페이지를 열거나, 셀프 미디어 계정을 전환해야 할 때 사용됩니다. 작업 흐름: 1) 지정된 플랫폼 확인 및 열기 2) 로그인 상태 확인 3) 광고 팝업 자동 닫기 4) 기사 게시 페이지로 이동 5) 게시 정보 수집 6) 자동으로 입력하고 게시합니다.
