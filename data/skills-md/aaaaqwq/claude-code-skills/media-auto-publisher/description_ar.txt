أداة عالمية للنشر التلقائي لمقالات الوسائط الذاتية. يدعم سير عمل النشر الآلي لثلاث منصات: Baijiahao وSohuhao وZhihu. يستخدم أداة Playwright MCP للتنقل بين المنصات والوصول إلى صفحات النشر، ويدعم تبديل الحسابات عن طريق إدارة ملفات تعريف الارتباط عبر StorageState. تُستخدم هذه المهارة عندما يحتاج المستخدم إلى نشر مقال على إحدى منصات الوسائط الذاتية، أو فتح صفحة النشر الخاصة بالمنصة، أو تبديل حسابات الوسائط الذاتية. سير العمل: 1) التحقق من النظام الأساسي المحدد وفتحه 2) التحقق من حالة تسجيل الدخول 3) إغلاق النوافذ المنبثقة للإعلانات تلقائيًا 4) انتقل إلى صفحة نشر المقالة 5) جمع معلومات النشر 6) ملء البيانات ونشرها تلقائيًا.
