أداة نشر آلية عالمية لمقالات الوسائط الذاتية. وهو يدعم عمليات النشر الآلية لثلاث منصات: Baijiahao وSohuhao وZhihu. ويستخدم أداة Playwright MCP للانتقال إلى الأنظمة الأساسية والدخول إلى صفحة النشر، ويدعم تبديل الحسابات عن طريق إدارة ملفات تعريف الارتباط من خلال StorageState. تُستخدم هذه المهارة عندما يحتاج المستخدمون إلى نشر مقالات على منصات الوسائط الذاتية، أو فتح صفحة النشر الخاصة بالمنصة، أو تبديل حسابات الوسائط الذاتية. سير العمل: 1) التحقق من النظام الأساسي المحدد وفتحه 2) التحقق من حالة تسجيل الدخول 3) إغلاق النوافذ المنبثقة للإعلانات تلقائيًا 4) انتقل إلى صفحة نشر المقالة 5) جمع معلومات النشر 6) ملء البيانات ونشرها تلقائيًا.
