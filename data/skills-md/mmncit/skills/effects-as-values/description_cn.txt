重构 TypeScript 的副作用，使失败和 I/O 成为返回类型中的值，而不是抛出异常和隐藏导入。当函数抛出并且调用者无法从签名中分辨出来时，当 try/catch 块嵌套或吞下错误时，当错误类型在到达 UI 时为任何类型或未知时，当验证在第一次失败时停止但表单需要每条消息时，当单元测试无法在没有存根获取或模拟模块的情况下运行时，当异步工作需要重试或取消或排序时，promise 会变得尴尬，或者当有人问“如何在不进行模拟的情况下测试它”时，请使用此技能， '应该在哪里处理错误'，'如何返回错误而不是抛出错误'。提供从普通结果联合到注入解释器的五级采用阶梯，并明确指导哪些级别在生产 TypeScript 中获得回报，哪些是值得学习而不是构建的概念。
