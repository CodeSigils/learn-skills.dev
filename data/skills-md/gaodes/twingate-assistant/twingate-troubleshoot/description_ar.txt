استخدم عندما يبلغ المستخدم عن مشاكل في الاتصال أو فشل الوصول أو مشكلات في حل DNS أو أي خطأ مع Twingate. فعل لهذا: "لا يمكن الاتصال"، "لا يعمل"، "المورد غير موجود"، "تم رفض الوصول"، موصل ميت، DNS لا يحل، حجب الثقة بالجهاز، مشكلات سياسات الأمان، فشل P2P، أو أي تشخيصات Twingate. كما فعل للاستفسارات ذات الشكل العَرَض: نص الخطأ الدقيق للعميل ("اسم شبكة غير معروف"، "عدد الملفات المفتوحة كثير جدًا"، "انتهى معالج الإعداد قبل الأوان"، "غير قادر على الانضمام إلى الشبكة")، أخطاء عميل خاصة بنظام التشغيل على Windows أو macOS أو Linux (Fedora، Ubuntu، NixOS) أو ChromeOS أو Android Auto؛ تعطل أو تجمد أو عدم استجابة العميل؛ تراجع خاص بإصدار معين (إصدار معين يتصرف بشكل غير سليم)؛ مشكلات محول الشبكة TAP/الافتراضي؛ فشل وضعية الجهاز، قفل الشاشة، أو تشفير القرص؛ تعارضات مع برامج مكافحة الفيروسات/EDR/VPN/تصفية DNS من طرف ثالث (CrowdStrike، Zscaler، Elastic AV، Avast، VPN للمستهلك)؛ التقاط الحزم، تقارير النظام، سجلات العميل/الموصل؛ وكذلك التواصل أو رفع الحالة إلى الدعم الفني لـ Twingate. يرجى دائمًا الرد بلغة المستخدم.
