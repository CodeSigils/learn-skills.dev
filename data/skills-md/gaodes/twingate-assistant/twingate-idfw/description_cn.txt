用于 Twingate 身份防火墙（IDFW）和 Twingate 网关——在协议层对 SSH、Kubernetes API 以及自托管/内部 Web 应用进行身份强制，而不仅仅是网络访问。当用户想要授予、保护、单点登录（SSO）或审计自托管/内部 Web 应用时加载——将身份转发/注入到 HTTP 请求中，提供每个请求的审计日志。网关 = 第 7 层反向代理，注入 ES256 JWT（网关访问令牌）或受信任的请求头：JWKS 验证、请求头注入、框架中间件（Express、Django、Next.js、Auth.js）、无代码 SSO（Grafana、Jenkins）。涵盖网关部署；使用短期证书的 SSH 特权访问；供应商/承包商访问；证书颁发机构（X.509/SSH CA，本地或 Vault）；通过网关使用 kubectl；Terraform/Ansible 自动化；会话录制（.cast 回放，扫描危险命令/泄露的密钥）。假设此技能用于“Twingate 能把用户身份传递给我的应用吗？”、“审计谁使用了该应用”，或“我的内部工具的 SSO”。
