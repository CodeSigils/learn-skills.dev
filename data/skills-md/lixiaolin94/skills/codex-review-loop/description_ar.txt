قم بتوجيه طلب سحب GitHub من خلال مراجعة العلاقات العامة عبر الإنترنت الخاصة بـ ChatGPT Codex إلى دمج نظيف: قم بإجراء مراجعة، واستطلاع للحكم (النتائج مقابل التنظيف)، وإصلاح كل نتيجة من خلال التحقق المحلي، والدمج فقط بعد مراجعتين نظيفتين متتاليتين على نفس الالتزام. يُستخدم عند تكرار العلاقات العامة مقابل تعليقات مراجعة الدستور الغذائي، أو عندما يُطلب منك "تشغيل حلقة مراجعة الدستور الغذائي"، أو "التعامل مع نتائج مراجعة الدستور الغذائي"، أو "تنظيف العلاقات العامة هذه ودمجها". الشرط المسبق: تم تمكين تكامل GitHub الخاص بـ ChatGPT Codex في الريبو (bot: chatgpt-codex-connector[bot])؛ يحتاج أيضًا إلى `gh` (مصادق عليه) و`jq`.
