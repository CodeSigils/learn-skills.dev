ChatGPT Codex のオンライン PR レビューを通じて GitHub プル リクエストをクリーン マージに導きます。レビューをトリガーし、判定 (検出結果とクリーン) をポーリングし、ローカル検証で各検出結果を修正し、同じコミットで 2 回連続してクリーン レビューが行われた後にのみマージします。 Codex レビューのコメントに対して PR を反復する場合、または「Codex レビュー ループを実行する」、「Codex レビューの結果を処理する」、または「この PR をクリーンにしてマージする」ように求められた場合に使用します。前提条件: リポジトリでは ChatGPT Codex の GitHub 統合が有効になっています (ボット: chatgpt-codex-connector[bot])。 `gh` (認証済み) と `jq` も必要です。
