Générez une pull request GitHub via l'examen des relations publiques en ligne de ChatGPT Codex pour une fusion propre : déclenchez un examen, interrogez le verdict (résultats ou nettoyage), corrigez chaque résultat avec une vérification locale et fusionnez uniquement après DEUX examens propres consécutifs sur le même commit. À utiliser lors de l'itération d'un PR par rapport aux commentaires de révision du Codex, ou lorsqu'il est demandé de « lancer la boucle de révision du Codex », de « gérer les résultats de la révision du Codex » ou de « nettoyer ce PR et le fusionner ». Condition préalable : l'intégration GitHub de ChatGPT Codex est activée dans le dépôt (bot : chatgpt-codex-connector[bot]) ; a également besoin de « gh » (authentifié) et de « jq ».
