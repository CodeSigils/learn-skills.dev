Guida una richiesta pull di GitHub tramite la revisione PR online di ChatGPT Codex per un'unione pulita: attiva una revisione, sondaggi per il verdetto (risultati vs risultati puliti), correggi ogni risultato con la verifica locale e unisci solo dopo DUE revisioni pulite consecutive sullo stesso commit. Da utilizzare quando si ripete un PR rispetto ai commenti di revisione del Codex o quando viene chiesto di "eseguire il ciclo di revisione del Codex", "gestire i risultati della revisione del Codex" o "pulire questo PR e unirlo". Precondizione: il repository ha l'integrazione GitHub di ChatGPT Codex abilitata (bot: chatgpt-codex-connector[bot]); necessita anche di `gh` (autenticato) e `jq`.
