ChatGPT Codex의 온라인 PR 검토를 통해 GitHub 끌어오기 요청을 깔끔한 병합으로 유도합니다. 검토를 시작하고, 결과에 대한 폴링(발견과 정리)을 수행하고, 로컬 확인을 통해 각 결과를 수정하고, 동일한 커밋에 대해 2번의 연속적인 정리 검토 후에만 병합합니다.
