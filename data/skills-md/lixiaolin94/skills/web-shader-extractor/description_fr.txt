Extrayez le code des effets visuels WebGL/Canvas/Shader de la page Web, désobstruez-le et portez-le dans un projet JS natif autonome.
Condition de déclenchement : l'utilisateur fournit une URL et demande d'extraire un shader, d'extraire des effets, d'extraire des effets d'animation, d'extraire des effets de canevas, de recréer les effets visuels d'un site Web ou "d'arracher l'effet d'arrière-plan de ce site Web", etc.
