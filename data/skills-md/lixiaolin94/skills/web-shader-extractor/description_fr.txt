Extrayez le code des effets visuels WebGL/Canvas/Shader de la page Web, désobstruez-le et portez-le dans un projet JS natif autonome.
Condition de déclenchement : l'utilisateur fournit une URL et demande d'extraire le shader, d'extraire les effets, d'extraire les effets d'animation, d'extraire les effets de canevas, de recréer les effets visuels d'un certain site Web ou "d'arracher l'effet d'arrière-plan de ce site Web", etc.
