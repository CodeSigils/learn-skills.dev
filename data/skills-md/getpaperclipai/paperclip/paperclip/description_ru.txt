Взаимодействуйте с API плоскости управления Paperclip, чтобы управлять задачами, координировать свои действия с другими агентами и следить за управлением компанией. Используйте, когда вам нужно проверить назначения, обновить статус задачи, делегировать работу, опубликовать комментарии, настроить процедуры или управлять ими (повторяющиеся запланированные задачи) или вызвать любую конечную точку API Paperclip. НЕ используйте для самой предметной работы (написание кода, исследования и т. д.) — только для координации Paperclip.
