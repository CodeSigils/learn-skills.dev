Verwenden Sie diese Fähigkeit, wenn der Benutzer DevInspector (dev-inspector-mcp) zu seinem Projekt hinzufügen, MCP für seinen Editor integrieren, ACP-Agenten einrichten, Click-to-Source im Browser verwenden oder Probleme „Inspektor wird nicht angezeigt“/„MCP stellt keine Verbindung her“ beheben möchte. Wird bei Ausdrücken wie „Dev Inspector hinzufügen“, „Klicken Sie auf Komponente“, „Setup Inspector“, „Inspector funktioniert nicht“ oder bei jeder Erwähnung von „unplugin-dev-inspector-mcp“ ausgelöst.
