Используйте этот навык, когда пользователь хочет добавить DevInspector (dev-inspector-mcp) в свой проект, интегрировать MCP для своего редактора, настроить агенты ACP, щелкнуть источник в браузере или отладить проблемы «инспектор не отображается» / «MCP не подключается». Запускается при таких фразах, как «добавить инспектора разработки», «нажмите, чтобы открыть компонент», «инспектор настройки», «инспектор не работает» или при любом упоминании unplugin-dev-inspector-mcp.
