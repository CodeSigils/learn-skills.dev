Utilisez cette compétence lorsque l'utilisateur souhaite ajouter DevInspector (dev-inspector-mcp) à son projet, intégrer MCP pour son éditeur, configurer des agents ACP, cliquer vers la source dans le navigateur ou déboguer les problèmes « l'inspecteur ne s'affiche pas » / « MCP ne se connecte pas ». Se déclenche sur des expressions telles que « ajouter un inspecteur de développement », « cliquer sur un composant », « inspecteur de configuration », « l'inspecteur ne fonctionne pas » ou toute mention de unplugin-dev-inspector-mcp.
