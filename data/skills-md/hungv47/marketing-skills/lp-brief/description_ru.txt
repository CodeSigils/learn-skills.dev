Создает краткое описание кампании по редизайну целевой страницы — гипотезу, поверхностный ритм, спецификации по разделам, места для активов, кандидаты на копирование, подсказки для передачи. Интернализует принципы преобразования lp-оптимизации в качестве критерия оценки. Создает `.agents/mkt/lp-brief/[slug]/brief.md`, готовый для передачи Клоду Дизайну, дизайнеру в Figma, или `design-brief` для спецификации каждого актива. Не для аудита существующей страницы (сначала используйте lp-оптимизацию — ее выходные данные используются для этого навыка). Не для страниц, не имеющих конверсии, таких как блоги или центры документации (которые используют разные рубрики). Не для спецификации отдельного визуального актива (используйте бриф на дизайн).
