Проверка качества после внедрения путем проверки свежим взглядом. Цепочка: реализация → проверка (независимый агент) → решение (при возникновении проблем). Максимум 2 раунда. Автоматические триггеры для кода, чувствительного к безопасности и изменяющего данные. Не для рефакторинга кода (используйте очистку кода). Не для анализа решений (используйте агентскую комнату). Информацию о проверке после развертывания см. в разделе «Развертывание-проверка». Информацию о доставке и PR см. в разделе «Корабль».
