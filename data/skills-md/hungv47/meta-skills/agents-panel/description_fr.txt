Salles de discussion multi-agents : débattez ou interrogez un problème sous plusieurs angles. Autonome ou invoqué par d'autres compétences en tant que sous-routine. Mode=débat : N agents argumentent en rondes, convergent. Mode=sondage : N agents analysent indépendamment, agrégés par consensus. Pas pour la mise en œuvre (utilisez l'architecture système). Pas pour vérification (utilisez un œil neuf). Pour clarifier les exigences, voir découvrir. Pour décomposer le travail après une décision, voir répartition des tâches.
