Многоагентные дискуссионные комнаты — обсуждайте или оцените проблему с разных точек зрения. Автономно или вызывается другими навыками как подпрограмма. Режим = дебаты: N агентов спорят по раундам, сходятся. Режим = опрос: N агентов независимо анализируют, объединяют данные по консенсусу. Не для реализации (используйте системную архитектуру). Не для проверки (используйте свежий взгляд). Для уточнения требований см. раздел Discover. Информацию о декомпозиции работы после принятия решения см. в разделе «Разбивка задач».
