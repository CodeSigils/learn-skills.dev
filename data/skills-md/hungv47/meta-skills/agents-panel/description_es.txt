Salas de discusión con múltiples agentes: debata o sondee un problema desde múltiples perspectivas. Independiente o invocado por otras habilidades como una subrutina. Modo=debate: N agentes discuten en rondas, convergen. Modo=encuesta: N agentes analizan de forma independiente, agregados por consenso. No para implementación (use arquitectura de sistema). No para verificación (use ojos frescos). Para aclarar primero los requisitos, consulte descubrir. Para descomponer el trabajo después de una decisión, consulte desglose de tareas.
