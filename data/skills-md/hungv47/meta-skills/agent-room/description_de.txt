Diskussionsräume mit mehreren Agenten – diskutieren oder befragen Sie ein Problem aus mehreren Perspektiven. Eigenständig oder von anderen Fähigkeiten als Unterroutine aufgerufen. Modus=Debatte: N Agenten diskutieren in Runden, konvergieren. Modus=Umfrage: N Agenten analysieren unabhängig voneinander, aggregieren im Konsens. Nicht zur Implementierung (Systemarchitektur verwenden). Nicht zur Verifizierung (Review-Chain verwenden). Informationen zur Klärung der Anforderungen finden Sie zunächst unter Entdecken. Informationen zur Aufteilung der Arbeit nach einer Entscheidung finden Sie unter Aufgabenaufschlüsselung.
