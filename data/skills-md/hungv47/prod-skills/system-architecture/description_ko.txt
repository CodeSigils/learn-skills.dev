이 기술은 사용자에게 정의된 제품이나 기능이 있고 기술 스택, 데이터베이스 스키마, API 디자인, 파일 구조 또는 배포 계획을 포함한 기술 청사진이 필요할 때 호출되어야 합니다. 트리거에는 '이 앱을 어떻게 구성해야 할까요?', '기술 스택이 무엇인지', '아키텍처 설계', '백엔드 계획', '이 앱을 어떻게 구조화해야 할까요?', '시스템 설계', '이것을 어떻게 배포해야 할까요?', '데이터베이스 선택', '모놀리스 대 마이크로서비스' 또는 'MVP 설계'가 포함됩니다. 단지 '이것을 설계해야 합니다', '어떤 기술을 사용해야 할지 모르겠습니다' 또는 '이게 과도하게 엔지니어링된 것인가요'라고 말하더라도 마찬가지입니다. 모호한 요구 사항이나 정의되지 않은 사양(계획 인터뷰 사용)을 명확히 하거나 아키텍처를 코딩 작업으로 분할(작업 분석 사용)하기 위한 것이 아닙니다.
