Esta habilidad debe invocarse cuando el usuario tiene un producto o característica definida y necesita el plan técnico que incluye la pila tecnológica, el esquema de la base de datos, el diseño de API, la estructura de archivos o el plan de implementación. Los desencadenantes incluyen "cómo debo construir esto", "qué pila tecnológica", "diseñar la arquitectura", "planificar mi backend", "cómo debo estructurar esta aplicación", "diseño del sistema", "cómo debo implementar esto", "elegir una base de datos", "monolito versus microservicios" o "arquitectar mi MVP", incluso si simplemente dicen "arquitectar esto", "no sé qué tecnología usar" o "está sobrediseñado". No para aclarar requisitos vagos o especificaciones indefinidas (use plan-entrevistador) o dividir la arquitectura en tareas de codificación (use desglose de tareas).
