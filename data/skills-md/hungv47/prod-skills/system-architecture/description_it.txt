Questa competenza dovrebbe essere invocata quando l'utente ha un prodotto o una funzionalità definita e necessita del progetto tecnico che include stack tecnologico, schema del database, progettazione dell'API, struttura dei file o piano di distribuzione. I trigger includono "come dovrei costruire questo", "quale stack tecnologico", "progettare l'architettura", "pianificare il mio backend", "come dovrei strutturare questa app", "progettazione del sistema", "come dovrei distribuirlo", "scegliere un database", "monolite vs microservizi" o "architetta il mio MVP" - anche se dicono semplicemente "architetta questo", "non so quale tecnologia usare" o 'è questo troppo ingegnerizzato.' Non per chiarire requisiti vaghi o specifiche non definite (usare plan-interviewer) o suddividere l'architettura in attività di codifica (usare task-breakdown).
