This skill should be invoked when the user has a defined product or feature and needs the technical blueprint including tech stack, database schema, API design, file structure, or deployment plan. Triggers include 'how should I build this', 'what tech stack', 'design the architecture', 'plan my backend', 'how should I structure this app', 'system design', 'how should I deploy this', 'picking a database', 'monolith vs microservices', or 'architect my MVP' -- even if they just say 'architect this', 'I don't know what tech to use', or 'is this overengineered.' Not for clarifying vague requirements or undefined specs (use plan-interviewer) or breaking architecture into coding tasks (use task-breakdown).
