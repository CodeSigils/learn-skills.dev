Cette compétence doit être invoquée lorsque l'utilisateur dispose d'un produit ou d'une fonctionnalité définie et a besoin du plan technique, y compris la pile technologique, le schéma de base de données, la conception d'API, la structure de fichiers ou le plan de déploiement. Les déclencheurs incluent « comment dois-je construire ceci », « quelle pile technologique », « concevoir l'architecture », « planifier mon backend », « comment dois-je structurer cette application », « conception du système », « comment dois-je déployer cela », « choisir une base de données », « monolithe vs microservices » ou « architecter mon MVP » - même s'ils disent simplement « architecte ceci », « je ne sais pas quelle technologie utiliser », ou 'Est-ce que c'est trop sophistiqué ?' Pas pour clarifier des exigences vagues ou des spécifications non définies (utilisez plan-interviewer) ou pour diviser l'architecture en tâches de codage (utilisez la répartition des tâches).
