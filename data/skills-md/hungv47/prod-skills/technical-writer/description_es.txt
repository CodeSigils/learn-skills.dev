Esta habilidad debe invocarse cuando el usuario desea documentación para una base de código o proyecto: archivos README, guías de usuario, referencias de API, documentos de API, guías de configuración, runbooks, registros de cambios, guías de contribución o documentos de arquitectura. Los desencadenantes incluyen "escribir un archivo README", "documentar esto", "no tenemos documentos", "nadie sabe cómo funciona esto", "necesito documentos", "nuestros documentos están desactualizados", "explica este código base", "crea una guía de usuario", "base de conocimientos", "todo es conocimiento tribal" o "documentación de incorporación del desarrollador", incluso si simplemente dicen "un nuevo desarrollador no pudo resolver esto". "Soy el único que sabe cómo funciona esto" o "los nuevos empleados tardan semanas en volverse productivos". No para especificar qué construir (usar plan-entrevistador), reestructurar el código para que sea más legible (usar limpieza de código) o UX de incorporación orientada al usuario (usar flujo de usuarios).
