يجب استدعاء هذه المهارة عندما يريد المستخدم وثائق لقاعدة تعليمات برمجية أو مشروع - القراءات، أو أدلة المستخدم، أو مراجع واجهة برمجة التطبيقات، أو مستندات واجهة برمجة التطبيقات، أو أدلة الإعداد، أو أدلة التشغيل، أو سجلات التغيير، أو الأدلة المساهمة، أو مستندات الهندسة المعمارية. تتضمن المشغلات "كتابة ملف README"، أو "توثيق هذا"، أو "ليس لدينا مستندات"، أو "لا أحد يعرف كيف يعمل هذا"، أو "أحتاج إلى مستندات"، أو "مستنداتنا قديمة"، أو "شرح قاعدة التعليمات البرمجية هذه"، أو "إنشاء دليل مستخدم"، أو "قاعدة المعرفة"، أو "كلها معرفة قبلية"، أو "وثائق تأهيل المطورين" - حتى لو قالوا فقط "لم يتمكن المطور الجديد من فهم ذلك" "، أو "أنا الوحيد الذي يعرف كيف يعمل هذا"، أو "يستغرق الموظفون الجدد أسابيع حتى يصبحوا منتجين". ليس لتحديد ما سيتم إنشاؤه (استخدم برنامج مقابلة الخطة)، أو إعادة هيكلة التعليمات البرمجية لتكون أكثر قابلية للقراءة (استخدم تنظيف التعليمات البرمجية)، أو إعداد تجربة المستخدم التي تواجه المستخدم (استخدم تدفق المستخدم).
