يجب استدعاء هذه المهارة عندما يريد المستخدم تنظيف التعليمات البرمجية الموجودة أو إعادة تصميمها أو تحسينها دون تغيير السلوك أو إصلاح الأخطاء. تتضمن المشغلات "هذا الرمز عبارة عن فوضى"، أو "تنظيف هذا الملف"، أو "تنظيف هذا العلاقات العامة"، أو "مراجعة جودة الكود الخاص بي"، أو "إزالة الكود الميت"، أو "ديون التكنولوجيا"، أو "الكثير من التعقيد"، أو "لقد ورثت كودًا سيئًا"، أو "إصلاح تباطؤ الذكاء الاصطناعي"، أو "غير قابل للصيانة"، أو "الكود القديم"، أو "التكرار"، أو "إعادة البناء"، أو "جعل هذا قابلاً للقراءة" - حتى لو قالوا فقط "هذا قبيح". "تبسيط هذا" أو "من الصعب متابعته" ويعني بنية التعليمات البرمجية نفسها. ليس لتشخيص مشاكل العمل (استخدم تحليل المشكلات) أو كتابة الوثائق لشرح الكود (استخدم الكاتب الفني).
