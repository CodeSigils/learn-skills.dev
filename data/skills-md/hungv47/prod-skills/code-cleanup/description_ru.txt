Этот навык следует использовать, когда пользователь хочет очистить, выполнить рефакторинг или улучшить существующий код без изменения поведения или исправления ошибок. Триггеры включают в себя: «этот код беспорядок», «очистить этот файл», «очистить этот PR», «проверить качество моего кода», «удалить мертвый код», «технический долг», «слишком большая сложность», «я унаследовал плохой код», «исправить ошибки ИИ», «неподдерживаемый», «устаревший код», «дублирование», «рефакторинг» или «сделать это удобочитаемым» — даже если они просто говорят: «это уродливо». «упростите это» или «это трудно уследить» и означают саму структуру кода. Не для диагностики бизнес-проблем (используйте анализ проблем) или написания документации для объяснения кода (используйте технического писателя).
