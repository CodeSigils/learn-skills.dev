يجب استدعاء هذه المهارة عندما يكون لدى المستخدم مواصفات أو بنية أو ميزة محددة ويحتاج إلى تقسيمها إلى مهام قابلة للبناء مع معايير القبول لوكلاء أو مهندسي الذكاء الاصطناعي. تتضمن المشغلات "تقسيم هذا إلى مهام"، أو "إنشاء مهام"، أو "ما الذي أقوم بإنشائه أولاً"، أو "جعل هذا قابلاً للتنفيذ"، أو "إنشاء التذاكر"، أو "التخطيط السريع"، أو "التراكم"، أو "أمر التنفيذ"، أو "تقسيم هذا إلى مهام سريعة" - حتى لو قالوا فقط "هذا كبير جدًا، من أين أبدأ"، أو "أنا مندهش من حجم العمل الذي يجب القيام به"، أو "لدي البنية، فماذا الآن". ليس لتوضيح المتطلبات غير الواضحة (استخدم برنامج مقابلة الخطة)، أو تصميم الهندسة المعمارية (استخدم بنية النظام)، أو الخطط التسويقية/الاستراتيجية (استخدم خطة imc أو تصميم الحلول)، أو تشخيص الأسباب الجذرية (استخدم تحليل المشكلة).
