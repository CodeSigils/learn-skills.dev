يجب استدعاء هذه المهارة عندما يريد المستخدم بناء أو تعريف هوية العلامة التجارية أو النظام المرئي أو نظام التصميم. تتضمن المشغلات "إنشاء علامة تجارية"، أو "أحتاج إلى إرشادات العلامة التجارية"، أو "الشعار"، أو "لوحة الألوان"، أو "الطباعة"، أو "الخطوط"، أو "دليل النمط"، أو "الهوية المرئية"، أو "إعادة العلامة التجارية"، أو "رموز التصميم"، أو "نحن نبدو مثل أي شركة ناشئة أخرى"، أو "تصميمنا يبدو غير متسق"، أو "كيف يجب أن تبدو علامتي التجارية" - حتى لو قالوا فقط "إننا نبدو غير محترفين"، أو "ليس لدينا تصميم متسق"، أو "منتجنا لا يبدو متميزًا". ليس لكتابة نسخة تسويقية (استخدم إنشاء المحتوى) أو رسم خرائط لتدفقات المستخدم (استخدم تدفق المستخدم).
