Cette compétence doit être invoquée lorsque l'utilisateur souhaite cartographier les flux en plusieurs étapes dans le produit pour déterminer la manière dont les utilisateurs naviguent dans une application ou un produit, y compris les écrans, les décisions, les transitions et les cas extrêmes. Les déclencheurs incluent « créer un flux utilisateur », « cartographier le parcours utilisateur », « filaire le flux », « planifier les transitions d'écran », « les utilisateurs se perdent », « le flux est déroutant », « notre intégration dans l'application est nulle », « le flux d'inscription est interrompu », « les utilisateurs abandonnent à l'étape X », « que se passe-t-il après l'inscription » ou « comment l'utilisateur passe-t-il de X à Y » - même s'ils décrivent simplement un fonctionnalité et doivent déterminer de quels écrans ils ont besoin, ou dire « de quels écrans ai-je besoin » ou « quel est le chemin le plus court vers X ». Pas pour la conception visuelle de la marque (utilisez le système de marque), l'optimisation de la conversion sur une seule page (utilisez l'optimisation lp) ou la cartographie de l'entonnoir marketing et du parcours client (utilisez le plan imc).
