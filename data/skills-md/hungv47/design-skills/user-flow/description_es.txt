Esta habilidad debe invocarse cuando el usuario desea mapear flujos de varios pasos dentro del producto sobre cómo los usuarios navegan a través de una aplicación o producto, incluidas pantallas, decisiones, transiciones y casos extremos. Los desencadenantes incluyen "crear un flujo de usuario", "mapear el recorrido del usuario", "estructurar el flujo", "planificar transiciones de pantalla", "los usuarios se están perdiendo", "el flujo es confuso", "nuestra incorporación en la aplicación apesta", "el flujo de registro está roto", "los usuarios abandonan en el paso X", "qué sucede después del registro" o "cómo pasa el usuario de X a Y", incluso si solo describen una función y necesitan descubrir qué pantallas necesita, o diga 'qué pantallas necesito' o 'cuál es el camino más corto hacia X'. No para diseño visual de marca (use brand-system), optimización de conversión de una sola página (use lp-optimization) o embudo de marketing y mapeo del recorrido del cliente (use imc-plan).
