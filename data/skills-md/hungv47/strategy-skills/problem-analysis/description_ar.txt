يجب استدعاء هذه المهارة عندما يواجه المستخدم مشكلة تجارية أو استراتيجية (وليست أخطاء برمجية) لا يفهمها بشكل كامل ويحتاج إلى تشخيص منظم. تشمل المحفزات "لماذا يحدث هذا"، أو "هناك خطأ ما"، أو "تشخيص هذا"، أو "السبب الجذري"، أو "انخفاض أرقامنا"، أو "انخفاض الإيرادات"، أو "التباطؤ مرتفع"، أو "توقف النمو"، أو "نحن ننزف أموالًا"، أو "لا يوجد جذب"، أو "تكلفة العمل المصاحبة لدينا مرتفعة جدًا"، أو "أنا عالق في مشكلة عمل"، أو "شيء تغير ولا أعرف ما هو" - حتى لو كانوا يصفون الأعراض دون سؤال. للتحليل، شارك البيانات وتوقع منك اكتشاف المشكلة، أو وضعها في إطار تهديد تنافسي ("المنافس يأكل غداءنا"). ليس لإعادة هيكلة التعليمات البرمجية (استخدم تنظيف التعليمات البرمجية)، أو تشخيص مشكلات تحويل صفحة معينة (استخدم تحسين lp)، أو حلول العصف الذهني عندما تكون المشكلة واضحة بالفعل (استخدم تصميم الحلول)، أو تحديد أهداف مسار التحويل (استخدم مخطط التحويل).
