이 기술은 사용자가 소셜 게시물, 광고, 이메일, 이메일 시퀀스, 뉴스레터, 블로그 게시물, 사례 연구, 비디오 스크립트, 캐러셀, 스레드, 콜드 이메일 또는 출시 공지를 포함한 새로운 마케팅 콘텐츠 자산을 작성하거나 초안을 작성하려고 할 때 호출되어야 합니다. 트리거에는 '게시물 작성', '...에 대한 콘텐츠가 필요합니다', '콘텐츠 초안', '알려야 할 내용이 있습니다', '무슨 말을 해야 할지 모르겠습니다' 또는 '무엇에 대해 써야 할까요'가 포함됩니다. 'LinkedIn', 'Twitter', 'Instagram', 'TikTok'과 같은 플랫폼 이름이나 '캐러셀' 또는 '릴'과 같은 형식만 지정하더라도 마찬가지입니다. 전문적인 품질의 헤드라인, 후크, CTA 또는 전체 페이지 섹션별 사본의 경우 카피라이팅을 따르세요. 기존 텍스트 편집 또는 수정(humanize 사용), 라이브 랜딩 페이지 감사(lp-optimization 사용), 기존 콘텐츠의 성능이 저하된 이유 진단(SEO 또는 속성 사용) 또는 기술 문서(기술 작성자 사용)에는 적합하지 않습니다.
