يجب استدعاء هذه المهارة عندما يريد المستخدم كتابة أو صياغة أصول محتوى تسويقي جديدة بما في ذلك المنشورات الاجتماعية، أو الإعلانات، أو رسائل البريد الإلكتروني، أو تسلسلات البريد الإلكتروني، أو النشرات الإخبارية، أو منشورات المدونات، أو دراسات الحالة، أو نصوص الفيديو، أو دوارات العرض، أو سلاسل الرسائل، أو رسائل البريد الإلكتروني الباردة، أو إعلانات الإطلاق. تتضمن المشغلات "اكتب لي منشورًا" أو "أحتاج إلى محتوى لـ..." أو "مسودة محتوى" أو "أحتاج إلى الإعلان عن شيء ما" أو "لا أعرف ماذا أقول" أو "ما الذي يجب أن أكتب عنه" - حتى لو قاموا فقط بتسمية منصة مثل "LinkedIn" أو "Twitter" أو "Instagram" أو "TikTok" أو تنسيق مثل "carousel" أو "reel". بالنسبة للعناوين ذات الجودة الحرفية، أو الخطافات، أو عبارات الحث على اتخاذ إجراء، أو نسخة صفحة كاملة قسمًا تلو الآخر، قم بالتأجيل إلى كتابة النصوص. ليس لتحرير أو إصلاح النص الموجود (استخدم الإضفاء الطابع الإنساني)، أو تدقيق الصفحة المقصودة المباشرة (استخدم lp-optimization)، أو تشخيص سبب ضعف أداء المحتوى الحالي (استخدم تحسين محركات البحث أو الإسناد)، أو التوثيق الفني (استخدم الكاتب الفني).
