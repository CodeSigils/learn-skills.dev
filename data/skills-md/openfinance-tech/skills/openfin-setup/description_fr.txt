Vérification d'authentification pour le backend OpenFinance : confirme qu'une clé API est disponible avant l'exécution de toute autre compétence OpenFinance. Utilisez EN PREMIER chaque fois que l'utilisateur est sur le point d'appeler une route /agent/* (Polymarket, Hyperliquid, Relay), qu'il atteint le 401/412 ou qu'il n'a pas encore négocié au cours de cette session. Déclencheurs sur "comment commencer", "Une clé API est requise", "Clé API invalide", "401/412 de /agent/*", "configurer OpenFinance" ou tout premier appel à une compétence de trading. Résout la clé à partir de `OPENFINANCE_API_KEY` (ou valeur équivalente env/fournie par l'utilisateur), confirme le format (`open_…`), vérifie via GET /agent/wallets et dirige autrement l'utilisateur vers https://openfinance.tech pour en émettre une.
