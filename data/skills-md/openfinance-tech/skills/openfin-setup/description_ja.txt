OpenFinance バックエンドの認証チェック — 他の OpenFinance スキルを実行する前に、API キーが利用可能であることを確認します。ユーザーが /agent/* ルート (Polymarket、Hyperliquid、Relay) を呼び出そうとしているとき、401/412 に到達しているとき、またはこのセッションでまだ取引していないときは、必ず FIRST を使用してください。 「開始方法」、「API キーが必要です」、「無効な API キー」、「/agent/* からの 401/412」、「OpenFinance のセットアップ」、または取引スキルへの最初の呼び出しでトリガーされます。 `OPENFINANCE_API_KEY` (または同等の env / ユーザー指定の値) からキーを解決し、形式 (`open_…`) を確認し、GET /agent/wallets 経由で検証し、それ以外の場合はユーザーに https://openfinance.tech を参照してキーを発行します。
