Controllo di autenticazione per il backend OpenFinance: conferma che una chiave API è disponibile prima dell'esecuzione di qualsiasi altra competenza OpenFinance. Utilizza FIRST ogni volta che l'utente sta per chiamare qualsiasi percorso /agent/* (Polymarket, Hyperliquid, Relay), sta chiamando 401/412 o non ha ancora effettuato operazioni di trading in questa sessione. Si attiva su "come iniziare", "è richiesta una chiave API", "chiave API non valida", "401/412 da /agent/*", "configura OpenFinance" o qualsiasi prima chiamata a una competenza di trading. Risolve la chiave da "OPENFINANCE_API_KEY" (o valore equivalente env/fornito dall'utente), conferma il formato (`open_...`), verifica tramite GET /agent/wallets e altrimenti indirizza l'utente a https://openfinance.tech per emetterne uno.
