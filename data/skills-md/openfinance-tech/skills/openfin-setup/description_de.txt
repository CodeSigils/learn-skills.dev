Authentifizierungsprüfung für das OpenFinance-Backend – bestätigt, dass ein API-Schlüssel verfügbar ist, bevor ein anderer OpenFinance-Skill ausgeführt wird. Verwenden Sie FIRST immer dann, wenn der Benutzer eine /agent/*-Route (Polymarket, Hyperliquid, Relay) aufrufen möchte, 401/412 erreicht oder in dieser Sitzung noch nicht gehandelt hat. Auslöser bei „Wie fange ich an“, „API-Schlüssel ist erforderlich“, „Ungültiger API-Schlüssel“, „401/412 von /agent/*“, „OpenFinance einrichten“ oder bei jedem ersten Aufruf eines Handels-Skills. Löst den Schlüssel aus „OPENFINANCE_API_KEY“ (oder einer entsprechenden Umgebung/vom Benutzer bereitgestellten Wert) auf, bestätigt das Format („open_…“), verifiziert über GET /agent/wallets und verweist den Benutzer andernfalls auf https://openfinance.tech, um einen auszugeben.
