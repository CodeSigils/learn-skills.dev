Проверка аутентификации для серверной части OpenFinance — подтверждает доступность ключа API до запуска любого другого навыка OpenFinance. Используйте FIRST всякий раз, когда пользователь собирается позвонить по любому маршруту /agent/* (Polymarket, Hyperliquid, Relay), набирает 401/412 или еще не торговал в этой сессии. Триггеры: «Как начать», «Требуется ключ API», «Неверный ключ API», «401/412 от /agent/*», «Настройка OpenFinance» или любой первый вызов навыка торговли. Разрешает ключ из `OPENFINANCE_API_KEY` (или эквивалентного значения env/user, предоставленного пользователем), подтверждает формат (`open_…`), проверяет через GET /agent/wallets и в противном случае указывает пользователю на https://openfinance.tech для его выдачи.
