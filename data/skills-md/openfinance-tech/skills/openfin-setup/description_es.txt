Verificación de autenticación para el backend de OpenFinance: confirma que hay una clave API disponible antes de que se ejecute cualquier otra habilidad de OpenFinance. Utilice PRIMERO siempre que el usuario esté a punto de llamar a cualquier ruta /agent/* (Polymarket, Hyperliquid, Relay), esté llamando al 401/412 o aún no haya operado en esta sesión. Activadores sobre "cómo empezar", "Se requiere una clave API", "Clave API no válida", "401/412 de /agent/*", "configurar OpenFinance" o cualquier primera llamada a una habilidad comercial. Resuelve la clave de `OPENFINANCE_API_KEY` (o equivalente env/valor proporcionado por el usuario), confirma el formato (`open_…`), verifica a través de GET /agent/wallets y, de lo contrario, dirige al usuario a https://openfinance.tech para emitir una.
