OpenFinance バックエンドのあらゆる既知の障害モード (Polymarket、Relay、Hyperliquid、Privy delegation、Solana RPC の問題) に対するエラーから修正までのプレイブック。これは、呼び出しが失敗したとき、予期しないステータスを返したとき、またはオンチェーン状態と矛盾した動作をしたときに使用します。これらのエラー シグネチャのいずれかをそのまま、または言い換えた場合にトリガーされます。ポリマーケット&#58; 「許容量: 0 ですが、オンチェーンでは最大値が表示されます」、「CLOB は許容量 0 を報告します」、「承認は確認されましたが、注文は拒否されました」、成行注文の「404 アップストリーム」、「ティック サイズ」の拒否、「注文サイズが最小値を下回っている」、USDC.e 対 pUSD 対ネイティブ USDC の混乱、V1 対 V2 為替の混乱。リレー&#58; 「structFallbackNotFound」、「Custom:101」、「Custom:6000」、「AnchorError」、「Blockhash not found」、「TransactionExpired」、「有効な認証署名が提供されていません」、「Solana ウォレットがアプリに委任されていません」、412 委任エラー、見積は成功したが実行失敗、Solana で資金がスタック、クロスチェーンで資金がスタック、topupGas が強制オフ。ハイパーリキッド&#58; 「不十分なPERPアカウントの値」、「範囲外の価格」、WebSocketの古いデータ、スポットとPERPの残高の混乱。一般&#58; 「なぜ X が失敗するのか」、「なぜオンチェーンと API の状態が一致しないのか」、「このエラーは何を意味するのか」。 MCP またはバックエンドのバグを想定する前に、これをお読みください。これらのエラーのほとんどは、既知の修正とともにすでにカタログ化されています。
