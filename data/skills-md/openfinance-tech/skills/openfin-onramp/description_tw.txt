透過 Moonpay 進行法幣到加密貨幣的轉換，預先填入來電者的錢包、鏈、貨幣和法幣金額。每當用戶說他們想用卡片/銀行/Apple Pay/Google Pay 購買加密貨幣、從法定貨幣充值錢包、「用我的卡」為 Hyperliquid/Polymarket/Solana 錢包注資，或「我沒有 USDC，我如何獲得一些」時，就可以使用。觸發器&#58; “用我的卡購買 USDC”、“信用卡入口”、“Apple Pay USDC”、“存入法幣”、“我沒有加密貨幣，我該如何開始”、“用法幣為我的錢包充值”、“用美元在 Base 上購買 ETH”。涵蓋 POST /agent/onramp/moonpay — 傳回一個 Moonpay simple-URL，其中包含鏈/currencyCode/walletAddress/fiat amount。用戶在 Moonpay 的 UI 中打開該 URL 來完成 KYC + 支付；一旦購買清算，資金就會到達用戶在所選鏈上由 OpenFinance 提供的錢包。沒有代理人的鏈上簽名。錢包預設為呼叫者的 OpenFinance 管理的 EVM 位址（或當 chain=solana /currencyCode 以 `_sol` 結尾時的 Solana 位址）。與 openfin-relay（入口匝道後的橋位於與您想要交易的鏈不同的鏈上）和 openfin-setup（API 密鑰檢查）配對。
