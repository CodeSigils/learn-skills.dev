Moonpay を介した法定通貨から暗号通貨への移行。発信者のウォレット、チェーン、通貨、法定通貨の金額が事前に入力されます。ユーザーがカード / 銀行 / Apple Pay / Google Pay で暗号通貨を購入したい、法定通貨からウォレットにチャージしたい、Hyperliquid / Polymarket / Solana ウォレットに「カードで」資金を入金したい、または「USDC を使い果たしているのですが、どうすれば入手できますか」という場合に使用します。トリガー&#58; 「カードでUSDCを購入する」、「クレジットカードでUSDCを購入する」、「Apple Pay USDC」、「法定通貨を入金する」、「仮想通貨を持っていない。どうやって始めればよいか」、「法定通貨でウォレットに資金を入金する」、「USDでBaseでETHを購入する」。 POST /agent/onramp/moonpay をカバーします — チェーン / 通貨コード / ウォレットアドレス / 法定通貨金額が組み込まれた Moonpay の単純な URL を返します。ユーザーは URL を開いて、Moonpay の UI で KYC + 支払いを完了します。購入が完了すると、選択したチェーン上の OpenFinance がプロビジョニングしたユーザーのウォレットに資金が到着します。エージェントによるオンチェーン署名はありません。ウォレットのデフォルトは、呼び出し元の OpenFinance 管理の EVM アドレス (または、chain=solana/currencyCode が `_sol` で終わる場合は Solana アドレス) です。 openfin-relay (取引したい場所とは異なるチェーンにオンランプが着地した後のブリッジ) および openfin-setup (API キーのチェック) と組み合わせます。
