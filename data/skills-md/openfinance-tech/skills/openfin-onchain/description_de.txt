Multi-Chain-On-Chain-Token-Daten – Metadaten, Wallet-Portfolios, Guthaben und USD-Preise – in über 100 EVM- und Solana-Netzwerken über die OpenFinance /agent/onchain/*-Routen (Uniblock-unterstützt). Verwenden Sie diese Option immer dann, wenn ein Agent nachschlagen muss, was ein Token ist, was eine beliebige Adresse enthält oder was etwas in USD kostet, bevor er Angebote/Handel/Anzeigen macht. Auslöser&#58; „Was ist Token 0x …“, „Tokenname und Dezimalstellen nachschlagen“, „Zeige mir Wallet 0x … Portfolio“, „Was enthält diese Adresse“, „USDC-Guthaben auf Polygon / Base / Arbitrum / Optimism“, „Aktueller Preis von ETH / WBTC / SOL“, „USD-Preis von <Vertrag>“, „Batch-Token-Metadaten“, „Batch-USD-Preise“, „Ist dieser Vertrag ein Token“, „Wallet-NFTs“, „Wallet-Bestände auf ChainId X". Deckt GET /agent/onchain/token/metadata, GET /agent/onchain/token/portfolio (nativ + fungibles + NFTs), GET /agent/onchain/token/balances (leichter – keine NFTs, paginiert), GET /agent/onchain/token/price (einzelner oder durch Kommas getrennter Stapel) ab. Schreibgeschützt; keine Unterschrift. Für jeden Aufruf ist „x-api-key“ erforderlich. open_…`. Voraussetzung&#58; openfin-setup. Koppeln Sie es mit openfin-relay, wenn der Benutzer auf das, was er hält, reagieren möchte.
