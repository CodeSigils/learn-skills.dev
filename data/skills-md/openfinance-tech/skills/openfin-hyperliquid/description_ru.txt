Полное руководство по Hyperliquid — бессрочная и спотовая торговля, маржа/кредитное плечо, TWAP, данные WebSocket в реальном времени и исторические свечи. Используйте для любых задач Hyperliquid. Торговые триггеры&#58; размещать перпер/спот-ордера (Gtc/Ioc/Alo), рыночные исполнения, группировать тейк-профит/стоп-лосс, изменять или отменять ордера, пакетную отмену, ордера TWAP (размещать/отслеживать исполнения/завершать), изменять кредитное плечо (перекрестное или изолированное), корректировать изолированную маржу, переводить USDC между спотовыми и перпер-счетами (usd_class_transfer), получать депозитный адрес EVM для финансирования Hyperliquid. Триггеры данных&#58; читать сводную информацию по счету (маржа, позиции, ликвидационная цена, нереализованный PnL), спотовые балансы, портфель, открытые ордера, исторические ордера, статус одного ордера, исполнения (последние или по временному окну), историю финансирования, лимиты ставок, рыночные мета-данные (perp + спот, szDecimals), мета-меты только для перпов (возвращает вселенные по всем перповым DEX — включая токены HIP-3, такие как NVDA, TSLA на `xyz`) dex наряду с криптовалютными преступниками), мета-меты только спот, средние цены на все монеты, книга заказов L2 на монету, сведения о спотовых токенах, снимок allDexsAssetCtxs (цены финансирования/OI/маркировки по активам). WebSocket в реальном времени&#58; wss://api.hyperliquid.xyz/ws с каналами allMids, allDexsAssetCtxs (бэкенд управляет общей подпиской — агент может подписаться/отписаться и прочитать кэшированный снимок), l2Book, trades, свеча, orderUpdates, userFills, userFundings. Исторические свечи OHLCV через прямой POST https://api.hyperliquid.xyz/info {type: 'candleSnapshot'} — поддерживаются интервалы 1м/3м/5м/15м/30м/1ч/2ч/4ч/8ч/12ч/1d/3d/1w/1M до 5000 свечей. Охватывает все маршруты в /agent/trading/* (market/metas|mids|perp-metas|spot-metas|l2-book|token|all-dexs-asset-ctxs, депозит-адрес, аккаунт, аккаунт/спот, портфель, ставка-лимит, ордера, ордера/детали, ордера/история, ордера/:oid/status, twap, twap/fills, twap/:id, fills, исполнения/по времени, финансирование, кредитное плечо, маржа, перевод). Запускается при упоминании Hyperliquid, «HL», perp, бессрочной ставки, ставки финансирования, TWAP, изолированной маржи, перекрестной маржи, «депозита в Hyperliquid», «HIP-3», «HLP» или «хранилища HL». Предварительное условие&#58; openfin-настройка.
