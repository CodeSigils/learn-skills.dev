Erstellen Sie ein Multi-Board-Dashboard für XIAO ESP32S3: Jedes Board verbindet sich mit WLAN (STA-Modus), veröffentlicht seinen Berührungssensorwert über MQTT und akzeptiert LED-Ein-/Aus-Befehle, während ein Browser-Dashboard jedes Board live zeigt und Ihnen das Umschalten jeder LED ermöglicht. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer möchte, dass mehrere ESP32S3-Boards an eine Webseite berichten, ein MQTT-basiertes Sensor-Dashboard, „Esp32S3-Erweiterung“, „MQTT-Funktionalität“ oder Mosquitto/Eclipse MQTT mit einem ESP32S3 erwähnt. Verwenden Sie für ein einzelnes Board ohne Broker stattdessen das SoftAP + Webserver-Beispiel des Skills „xiao-esp32s3“.
