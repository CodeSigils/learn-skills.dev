XIAO ESP32S3 用のマルチボード ダッシュボードを構築します。各ボードは WiFi (STA モード) に参加し、MQTT 経由でタッチ センサー値を公開し、LED オン/オフ コマンドを受け入れます。一方、ブラウザー ダッシュボードにはすべてのボードがライブで表示され、各 LED を切り替えることができます。ユーザーが複数の ESP32S3 ボードから 1 つの Web ページ、MQTT ベースのセンサー ダッシュボード、「여러 esp32s3 대시보드」、「MQTT로 여러 보드 연결」にレポートする場合、または ESP32S3 を使用した Mosquitto/Eclipse MQTT について言及する場合は、このスキルを使用します。ブローカーのない単一ボードの場合は、代わりに「xiao-esp32s3」スキル独自の SoftAP + Web サーバーの例を使用します。
