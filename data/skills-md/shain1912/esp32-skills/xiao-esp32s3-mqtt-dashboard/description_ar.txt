أنشئ لوحة معلومات متعددة اللوحات لـ XIAO ESP32S3: تنضم كل لوحة إلى WiFi (وضع STA)، وتنشر قيمة مستشعر اللمس الخاص بها عبر MQTT، وتقبل أوامر تشغيل/إيقاف LED، بينما تعرض لوحة معلومات المتصفح كل لوحة مباشرة وتتيح لك تبديل كل مؤشر LED. استخدم هذه المهارة عندما يريد المستخدم تقديم تقارير إلى عدة لوحات ESP32S3 إلى صفحة ويب واحدة، أو لوحة معلومات مستشعر تعتمد على MQTT، أو "الإشارة إلى esp32s3 대시보드"، أو "MQTT로 여러 보드 연결"، أو يذكر Mosquitto/Eclipse MQTT مع ESP32S3. بالنسبة للوحة واحدة بدون وسيط، استخدم مثال خادم الويب SoftAP + الخاص بالمهارة `xiao-esp32s3` بدلاً من ذلك.
