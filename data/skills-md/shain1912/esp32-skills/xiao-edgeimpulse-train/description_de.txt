Trainieren und implementieren Sie ein TinyML-Modell für den XIAO ESP32S3 (Sense) nur mit der Edge Impulse REST API – es ist kein Edge-Impulse-CLI erforderlich (die serielle Port-Abhängigkeit kann nicht auf modernen Knoten/Windows aufgebaut werden). Behandelt: Hochladen von Datensätzen, Impulserstellung (Audio-MFCC / Vision-Transfer-Lernen), Trainingsjobs, Herunterladen der Arduino-Bibliothek und die Korrekturen auf dem Gerät, die erforderlich sind, um sie tatsächlich auf dem ESP32-S3 auszuführen. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer ein Modell trainieren/neu trainieren möchte („Ereignis“, „Edge-Impuls“, „TinyML-Erfahrung“, „Erweitert“), einen Datensatz auf Edge Impulse hochladen möchte oder Build-/Laufzeitfehler der EI-Arduino-Bibliothek erhält (mel filterbank, objs.a, tensor arena, EI_MAX_OVERFLOW_BUFFER_COUNT).
