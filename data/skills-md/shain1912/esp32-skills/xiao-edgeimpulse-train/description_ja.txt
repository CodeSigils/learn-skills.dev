Edge Impulse REST API のみを使用して XIAO ESP32S3 (Sense) の TinyML モデルをトレーニングしてデプロイします。edge-impulse-cli は必要ありません (シリアルポート デプロイは最新のノード/Windows 上で構築できません)。対象範囲: データセットのアップロード、インパルス作成 (オーディオ MFCC / ビジョン転送学習)、トレーニング ジョブ、Arduino ライブラリのダウンロード、ESP32-S3 で実際に実行するために必要なデバイス上の修正。ユーザーがモデル (「재훈련」、「edge impulse」、「TinyML 훈련」、「모델 배포」) をトレーニング/再トレーニングする場合、Edge Impulse にデータセットをアップロードする場合、または EI Arduino ライブラリのビルド/ランタイム エラー (mel filterbank、objs.a、tensor arena、 EI_MAX_OVERFLOW_BUFFER_COUNT)。
