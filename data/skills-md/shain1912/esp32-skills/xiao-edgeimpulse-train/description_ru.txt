Обучите и разверните модель TinyML для XIAO ESP32S3 (Sense), используя только Edge Impulse REST API — Edge-impulse-cli не требуется (его последовательный порт не может быть построен на современном Node/Windows). Охватывает: загрузку набора данных, создание импульсов (аудио MFCC / обучение передаче зрения), учебные задания, загрузку библиотеки Arduino и исправления на устройстве, необходимые для фактического запуска ее на ESP32-S3. Используйте этот навык всякий раз, когда пользователь хочет обучить/переобучить модель («재훈련», «edge импульс», «TinyML 훈련», «모델 배포»), загрузить набор данных в Edge Impulse или получить ошибки сборки/выполнения библиотеки EI Arduino (mel filterbank, objs.a, tensor arena, EI_MAX_OVERFLOW_BUFFER_COUNT).
