XIAO ESP32S3 Sense カメラ Web アプリを STA (ルーター) モードで構築してフラッシュします。Teachable-Machine スタイルのデータセット コレクター ページとライブ推論ビューアー ページは、すべてのデバイスがインターネット接続を維持している間、http://<name>.local でアクセスできます。ユーザーが通常の WiFi ネットワーク上でカメラ Web アプリを使用したいとき (自宅/オフィス開発、「인터넷 안 끊기게」、「공유기로」、「mDNS」、または「STA 모드」と言うとき) にこのスキルを使用します。ルーターのない教室のホットスポット展開の場合は、代わりに xiao-webcam-ap スキルを使用してください。
