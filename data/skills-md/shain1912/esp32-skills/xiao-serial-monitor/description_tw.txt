在 Windows 上對 XIAO ESP32S3（或任何 Arduino 板）進行串行監控，在兩種重要模式下：代理可以運行有界讀取來調試其自身的更改，以及向用戶提供持久終端監視器，並提供明確的說明以便稍後檢查輸出。透過 USB 供應商 ID 自動偵測 COM 端口，在每次重置和重新上傳時端口丟失後仍可正常運行，並向 PowerShell 配置文件添加單字“mon”/“flash”快捷方式。每當涉及串行輸出時，請使用此技能：讀取板正在打印的內容、要求“打開串行監視器”、希望它“每次”都可用或作為快捷方式、監視器不斷斷開、每次上傳之前需要 Ctrl+C、選擇了錯誤的 COM 端口，或者每當您要告訴用戶如何自己觀看板時。
