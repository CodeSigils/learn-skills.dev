Diseñe tablas de datos claras y escaneables que sigan las convenciones de UX establecidas en materia de alineación, formato y legibilidad. Utilice esta habilidad al crear tablas de datos, cuadrículas, vistas de lista, paneles, informes o cualquier visualización tabular. También activadores para: "diseñar esta tabla", "cómo debo mostrar estos datos", "diseño de tabla", "alineación de columnas", "diseño de cuadrícula", "cuadrícula de datos", "experiencia de tabla", "tabla de informe", "diseño de hoja de cálculo", "hacer que esta tabla sea más fácil de leer" o "formato de columnas numéricas". Cubre el orden de las columnas, las reglas de alineación, el formato de los números, los indicadores de estado, la densidad de las filas, la clasificación y el comportamiento de respuesta. NO lo use para el diseño de esquemas de bases de datos, diseño de respuestas API (use api-design) o diseño de gráficos/visualizaciones.
