صمم جداول بيانات واضحة وقابلة للمسح الضوئي وتتبع اصطلاحات تجربة المستخدم المعمول بها من أجل المحاذاة والتنسيق وسهولة القراءة. استخدم هذه المهارة عند إنشاء جداول البيانات أو الشبكات أو طرق عرض القائمة أو لوحات المعلومات أو التقارير أو أي عرض جدولي. مشغلات أيضًا لـ: "تصميم هذا الجدول"، أو "كيف يجب أن أعرض هذه البيانات"، أو "تخطيط الجدول"، أو "محاذاة العمود"، أو "تصميم الشبكة"، أو "شبكة البيانات"، أو "جدول UX"، أو "جدول التقارير"، أو "تخطيط جدول البيانات"، أو "جعل هذا الجدول أسهل في القراءة"، أو "تنسيق العمود الرقمي". يغطي ترتيب الأعمدة، وقواعد المحاذاة، وتنسيق الأرقام، ومؤشرات الحالة، وكثافة الصفوف، والفرز، والسلوك سريع الاستجابة. لا تستخدم لتصميم مخطط قاعدة البيانات، أو تصميم استجابة واجهة برمجة التطبيقات (استخدم تصميم واجهة برمجة التطبيقات)، أو تصميم المخطط/التصور.
