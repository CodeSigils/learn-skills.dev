When a user provides a Chinese copy or text file, such as examples/raw_scripts/sample_script_01.txt, and wants to split it into multiple storyboard inputs usable for Nano Banana raw images, this skill is used. It determines how many images to generate, the purpose of each shot, style templates, visual elements, Chinese and English prompt words, negative prompt words, and the standard knowledge sentence for each image. It applies to requests like “help me write Nano Banana prompts,” “split the copy into image storyboards,” “give me raw image inputs for multiple pictures,” “create a Jianying‑style image storyboard video,” and similar.
