Gère les flux de travail MongoDB Atlas Stream Processing (ASP). Gère le provisionnement de l’espace de travail, les connexions source/récepteur de données, les opérations du cycle de vie du processeur, les diagnostics de débogage et le dimensionnement des niveaux. Prend en charge les intégrations Kafka, Atlas clusters, S3, HTTPS et Lambda pour le streaming des charges de travail de données et le traitement des événements. PAS pour les requêtes générales MongoDB ou la gestion du cluster Atlas. Nécessite le serveur MongoDB MCP avec les informations d'identification de l'API Atlas.
