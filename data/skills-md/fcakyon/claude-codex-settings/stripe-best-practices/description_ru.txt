Руководства по принятию решений по интеграции Stripe — выбор API (сеансы Checkout или PaymentIntents), настройка платформы Connect (Accounts v2, свойства контроллера), выставление счетов/подписок, финансовые счета Казначейства, поверхности интеграции (Checkout, Payment Element), переход с устаревших API Stripe и рекомендации по безопасности (управление ключами API, ключи с ограниченным доступом, веб-перехватчики, OAuth). Используйте при создании, изменении или проверке любой интеграции Stripe, включая прием платежей, создание торговых площадок, интеграцию Stripe, обработку платежей, настройку подписок, создание подключенных учетных записей или реализацию безопасной обработки ключей.
