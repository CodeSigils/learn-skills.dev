Guía las decisiones de integración de Stripe: selección de API (sesiones de pago frente a intenciones de pago), configuración de la plataforma Connect (cuentas v2, propiedades del controlador), facturación/suscripciones, cuentas financieras de tesorería, superficies de integración (pago, elemento de pago), migración desde API de Stripe obsoletas y mejores prácticas de seguridad (administración de claves de API, claves restringidas, webhooks, OAuth). Úselo al crear, modificar o revisar cualquier integración de Stripe, incluida la aceptación de pagos, la creación de mercados, la integración de Stripe, el procesamiento de pagos, la configuración de suscripciones, la creación de cuentas conectadas o la implementación de un manejo seguro de claves.
