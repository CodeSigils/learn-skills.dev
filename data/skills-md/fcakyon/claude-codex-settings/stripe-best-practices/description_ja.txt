Stripe 統合の決定に関するガイド — API の選択 (チェックアウト セッションと PaymentIntents)、Connect プラットフォームのセットアップ (アカウント v2、コントローラー プロパティ)、請求/サブスクリプション、財務金融アカウント、統合サーフェス (チェックアウト、支払い要素)、非推奨の Stripe API からの移行、およびセキュリティのベスト プラクティス (API キー管理、制限付きキー、Webhook、OAuth)。 Stripe 統合を構築、変更、またはレビューするときに使用します。これには、支払いの受け入れ、マーケットプレイスの構築、Stripe の統合、支払いの処理、サブスクリプションの設定、接続されたアカウントの作成、または安全なキー処理の実装が含まれます。
