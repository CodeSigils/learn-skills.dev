Guida le decisioni sull'integrazione di Stripe: selezione delle API (sessioni di checkout vs PaymentIntents), configurazione della piattaforma Connect (account v2, proprietà del controller), fatturazione/abbonamenti, conti finanziari di tesoreria, superfici di integrazione (checkout, elemento di pagamento), migrazione da API Stripe deprecate e best practice di sicurezza (gestione delle chiavi API, chiavi limitate, webhook, OAuth). Da utilizzare durante la creazione, la modifica o la revisione di qualsiasi integrazione Stripe, tra cui l'accettazione di pagamenti, la creazione di mercati, l'integrazione di Stripe, l'elaborazione di pagamenti, l'impostazione di abbonamenti, la creazione di account connessi o l'implementazione di una gestione sicura delle chiavi.
