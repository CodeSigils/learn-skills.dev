サポートされているドライバー言語に対して MongoDB クライアント接続構成 (プール、タイムアウト、パターン) を最適化します。このスキルは、MongoDB クライアントをインスタンス化または構成する関数の作業/更新/レビュー (例: 「connect()」 の呼び出し時)、接続プールの構成、接続エラー (ECONNREFUSED、タイムアウト、プール枯渇) のトラブルシューティング、接続に関連するパフォーマンスの問題の最適化を行うときに使用します。これには、MongoDB を使用したサーバーレス関数の構築、MongoDB を使用する API エンドポイントの作成、高トラフィックの MongoDB アプリケーションの最適化、長時間実行タスクと同時実行の作成、接続関連のエラーのデバッグなどのシナリオが含まれます。
