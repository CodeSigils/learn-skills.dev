Optimice la configuración de la conexión del cliente MongoDB (grupos, tiempos de espera, patrones) para cualquier idioma de controlador compatible. Utilice esta habilidad cuando trabaje/actualice/revise funciones que crean instancias o configuran un cliente MongoDB (por ejemplo, al llamar a `connect()`), configurar grupos de conexiones, solucionar errores de conexión (ECONNREFUSED, tiempos de espera, agotamiento de grupos), optimizar problemas de rendimiento relacionados con las conexiones. Esto incluye escenarios como la creación de funciones sin servidor con MongoDB, la creación de puntos finales API que utilizan MongoDB, la optimización de aplicaciones MongoDB de alto tráfico, la creación de tareas de larga duración y simultaneidad, o la depuración de fallas relacionadas con la conexión.
