Genera query MongoDB di sola lettura (trova) o pipeline di aggregazione utilizzando il linguaggio naturale, con contesto dello schema di raccolta e documenti di esempio. Utilizza questa abilità ogni volta che l'utente chiede di scrivere, creare o generare query MongoDB, desidera filtrare/interrogare/aggregare dati in MongoDB, chiede "come faccio a eseguire query...", ha bisogno di aiuto con la sintassi delle query o discute di come trovare/filtrare/raggruppare documenti MongoDB. Utilizzare anche per tradurre richieste di tipo SQL nella sintassi MongoDB. NON gestisce la ricerca Atlas (operatore $search), la ricerca vettoriale/semantica (operatore $vectorSearch), la corrispondenza fuzzy, gli indici di completamento automatico o il punteggio di pertinenza: utilizza search-and-ai per questi. NON analizza o ottimizza le query esistenti: utilizza mongodb-query-optimizer per questo. NON gestisce pipeline di aggregazione che implicano operazioni di scrittura. Richiede il server MCP MongoDB.
