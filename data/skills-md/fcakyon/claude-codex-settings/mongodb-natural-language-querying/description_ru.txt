Создавайте запросы MongoDB только для чтения (поиск) или конвейеры агрегации, используя естественный язык, с контекстом схемы коллекции и примерами документов. Используйте этот навык всякий раз, когда пользователь просит написать, создать или сгенерировать запросы MongoDB, хочет отфильтровать/запросить/агрегировать данные в MongoDB, спрашивает «как мне сделать запрос...», нуждается в помощи с синтаксисом запроса или обсуждает поиск/фильтрацию/группировку документов MongoDB. Также используйте для перевода SQL-подобных запросов в синтаксис MongoDB. НЕ обрабатывает поиск по атласу (оператор $search), векторный/семантический поиск (оператор $vectorSearch), нечеткое сопоставление, индексы автозаполнения или оценку релевантности — для этого используйте search-and-ai. НЕ анализирует и не оптимизирует существующие запросы — для этого используйте mongodb-query-optimizer. НЕ обрабатывает конвейеры агрегации, включающие операции записи. Требуется сервер MongoDB MCP.
