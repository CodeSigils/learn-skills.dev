قم بإنشاء استعلامات MongoDB للقراءة فقط (بحث) أو خطوط تجميع باستخدام اللغة الطبيعية، مع سياق مخطط المجموعة ونماذج المستندات. استخدم هذه المهارة عندما يطلب المستخدم كتابة أو إنشاء أو إنشاء استعلامات MongoDB، أو يريد تصفية/الاستعلام/تجميع البيانات في MongoDB، أو يسأل "كيف يمكنني الاستعلام..."، أو يحتاج إلى مساعدة في بناء جملة الاستعلام، أو يناقش العثور على/تصفية/تجميع مستندات MongoDB. استخدمه أيضًا لترجمة الطلبات المشابهة لـ SQL إلى بناء جملة MongoDB. لا يتعامل مع Atlas Search (مشغل البحث)، أو البحث المتجه/الدلالي (مشغل البحث المتجه)، أو المطابقة الغامضة، أو فهارس الإكمال التلقائي، أو تسجيل مدى الصلة - استخدم البحث والذكاء الاصطناعي لهؤلاء. لا يقوم بتحليل أو تحسين الاستعلامات الموجودة - استخدم mongodb-query-optimizer لذلك. لا يتعامل مع خطوط أنابيب التجميع التي تتضمن عمليات الكتابة. يتطلب خادم MongoDB MCP.
