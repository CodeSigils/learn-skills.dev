Leitfaden zur Verwendung des Agent-Browsers. Lesen Sie dies, bevor Sie Agent-Browser-Befehle ausführen. Behandelt den Snapshot-and-Ref-Workflow, das Navigieren auf Seiten, die Interaktion mit Elementen (Klicken, Ausfüllen, Tippen, Auswählen), das Extrahieren von Text und Daten, das Erstellen von Screenshots, das Verwalten von Registerkarten, den Umgang mit Formularen und der Authentifizierung, das Warten auf Inhalte, das parallele Ausführen mehrerer Browsersitzungen und die Fehlerbehebung bei häufigen Fehlern. Verwenden Sie diese Option, wenn der Benutzer mit einer Website interagieren, ein Formular ausfüllen, auf etwas klicken, Daten extrahieren, einen Screenshot erstellen, sich bei einer Website anmelden, eine Web-App testen oder eine beliebige Browseraufgabe automatisieren möchte.
