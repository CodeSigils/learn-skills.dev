Guía de uso del agente-navegador. Lea esto antes de ejecutar cualquier comando del agente-navegador. Cubre el flujo de trabajo de instantáneas y referencias, navegación por páginas, interacción con elementos (hacer clic, completar, escribir, seleccionar), extraer texto y datos, tomar capturas de pantalla, administrar pestañas, manejar formularios y autenticación, esperar contenido, ejecutar múltiples sesiones de navegador en paralelo y solucionar fallas comunes. Úselo cuando el usuario solicita interactuar con un sitio web, completar un formulario, hacer clic en algo, extraer datos, tomar una captura de pantalla, iniciar sesión en un sitio, probar una aplicación web o automatizar cualquier tarea del navegador.
