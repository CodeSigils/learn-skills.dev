دليل استخدام متصفح الوكيل. اقرأ هذا قبل تشغيل أي أوامر لمتصفح الوكيل. يغطي سير عمل اللقطة والمرجع، والتنقل بين الصفحات، والتفاعل مع العناصر (النقر، والتعبئة، والكتابة، والتحديد)، واستخراج النص والبيانات، والتقاط لقطات الشاشة، وإدارة علامات التبويب، والتعامل مع النماذج والمصادقة، وانتظار المحتوى، وتشغيل جلسات متصفح متعددة بالتوازي، واستكشاف الأخطاء وإصلاحها في حالات الفشل الشائعة. يُستخدم عندما يطلب المستخدم التفاعل مع موقع ويب، أو ملء نموذج، أو النقر فوق شيء ما، أو استخراج البيانات، أو التقاط لقطة شاشة، أو تسجيل الدخول إلى موقع، أو اختبار تطبيق ويب، أو تشغيل أي مهمة في المتصفح تلقائيًا.
