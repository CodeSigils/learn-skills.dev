Этот навык следует использовать, когда пользователь просит «запросить OpenObserve», «создать панель управления OpenObserve», «отредактировать панель OpenObserve», «получить журналы OpenObserve», «запустить поиск OpenObserve», «составить список потоков OpenObserve», «загрузить в OpenObserve» или работает с OpenObserve Cloud / самостоятельным размещением через REST API. Охватывает аутентификацию, поиск/SQL, потоки, информационные панели (CRUD + операции для каждой панели), схему JSON панели v8 и известные ловушки (повторное агрегирование, параллелизм хеширования, микросекундные метки времени).
