Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „OpenObserve abfragen“, „OpenObserve-Dashboard erstellen“, „OpenObserve-Panel bearbeiten“, „OpenObserve-Protokolle abrufen“, „OpenObserve-Suche ausführen“, „OpenObserve-Streams auflisten“, „in OpenObserve aufnehmen“ auffordert oder mit OpenObserve Cloud arbeitet bzw. über die REST-API selbst gehostet wird. Behandelt Authentifizierung, Suche/SQL, Streams, Dashboards (CRUD + Pro-Panel-Operationen), das v8-Panel-JSON-Schema und bekannte Fallstricke (Neuaggregation, Hash-Parallelität, Mikrosekunden-Zeitstempel).
