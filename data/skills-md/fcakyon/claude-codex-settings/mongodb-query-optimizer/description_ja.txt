MongoDB クエリの最適化とインデックス作成を支援します。 「このクエリを最適化するにはどうすればよいですか?」、「このクエリにインデックスを付けるにはどうすればよいですか?」、「このクエリが遅いのはなぜですか?」、「遅いクエリを修正できますか?」、「クラスター上の遅いクエリは何ですか?」など、ユーザーが最適化またはパフォーマンスを要求する場合にのみ使用します。ユーザーがパフォーマンスまたはインデックスのヘルプを求めない限り、一般的な MongoDB クエリの書き込みには呼び出さないでください。最適化戦略としてインデックス作成を優先します。利用可能な場合は MongoDB MCP を使用します。
