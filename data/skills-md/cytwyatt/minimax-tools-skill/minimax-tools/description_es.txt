Integración directa de API MiniMax para síntesis de voz (TTS), clonación de voz, generación de imágenes, generación de videos y generación de música utilizando scripts Python locales en lugar de MCP. Úselo cuando desee flujos de trabajo MiniMax confiables basados ​​en scripts dentro de OpenClaw para: (1) conversión de texto a voz con valores predeterminados integrados en chino/inglés o ID de voz explícitas, (2) clonación de voz con carga + flujos de vista previa, (3) generación de texto a imagen o imagen de referencia, (4) generación de texto a video, imagen a video o primer/último cuadro de video con sondeo/descarga asíncrono y (5) generación de música a partir de indicaciones y letras.
