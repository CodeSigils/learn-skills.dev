MCP 대신 로컬 Python 스크립트를 사용하여 음성 합성(TTS), 음성 복제, 이미지 생성, 비디오 생성 및 음악 생성을 위한 Direct MiniMax API 통합입니다. OpenClaw 내에서 (1) 중국어/영어 기본값 또는 명시적 음성 ID가 내장된 텍스트 음성 변환, (2) 업로드 + 미리 보기 흐름을 통한 음성 복제, (3) 텍스트-이미지 또는 참조 이미지 생성, (4) 텍스트-비디오, 이미지-비디오 또는 비동기 폴링/다운로드를 통한 첫 번째/마지막 프레임 비디오 생성 및 (5) 프롬프트 및 가사에서 음악 생성을 위해 OpenClaw 내에서 신뢰할 수 있는 스크립트 기반 MiniMax 워크플로를 원할 때 사용하십시오.
