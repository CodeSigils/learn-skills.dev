تكامل MiniMax API المباشر لتركيب الكلام (TTS)، واستنساخ الصوت، وتوليد الصور، وتوليد الفيديو، وتوليد الموسيقى باستخدام نصوص Python المحلية بدلاً من MCP. استخدمه عندما تريد سير عمل MiniMax يعتمد على البرنامج النصي داخل OpenClaw من أجل: (1) تحويل النص إلى كلام مع الإعدادات الافتراضية الصينية/الإنجليزية المضمنة أو معرفات الصوت الصريحة، (2) استنساخ الصوت مع تدفقات التحميل + المعاينة، (3) إنشاء نص إلى صورة أو صورة مرجعية، (4) تحويل النص إلى فيديو، أو صورة إلى فيديو، أو إنشاء فيديو الإطار الأول/الأخير مع الاستقصاء/التنزيل غير المتزامن، و(5) إنشاء الموسيقى من المطالبات و كلمات.
