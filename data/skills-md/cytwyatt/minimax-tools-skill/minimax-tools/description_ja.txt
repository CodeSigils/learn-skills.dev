MCP の代わりにローカル Python スクリプトを使用して、音声合成 (TTS)、音声クローン、画像生成、ビデオ生成、および音楽生成のための MiniMax API を直接統合します。 OpenClaw 内で信頼性の高いスクリプトベースの MiniMax ワークフローが必要な場合に使用します。(1) 組み込みの中国語/英語のデフォルトまたは明示的な音声 ID によるテキスト読み上げ、(2) アップロード + プレビュー フローによる音声クローン作成、(3) テキストから画像への変換または参照画像の生成、(4) 非同期ポーリング/ダウンロードによるテキストからビデオへ、画像からビデオへ、または最初/最後のフレームのビデオ生成、(5) プロンプトと歌詞からの音楽生成。
