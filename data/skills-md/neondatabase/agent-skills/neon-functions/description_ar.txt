تم نشر وظائف Node.js HTTP طويلة الأمد وبدون خادم على فرع Neon الخاص بك، مع إدخال DATABASE_URL تلقائيًا والحساب الذي يتم تشغيله بجوار بياناتك. يُستخدم عندما يريد المستخدم استضافة واجهة برمجة التطبيقات، أو وكيل الذكاء الاصطناعي مع استجابات تدفق طويلة، أو خادم WebSocket أو خادم الأحداث المرسلة (SSE)، أو معالج خطاف الويب، أو برنامج Discord الآلي، أو أي حمل عمل للطلب/الاستجابة يخاطر بانتهاء المهلة في وظائف قصيرة بدون خادم على نمط لامدا - ويريد أن يتفرع مع قاعدة البيانات الخاصة به. تتضمن المشغلات "وظيفة بدون خادم"، و"نشر واجهة برمجة التطبيقات"، و"وظيفة طويلة التشغيل"، و"وكيل البث"، و"خادم SSE"، و"خادم WebSocket"، و"معالج webhook"، و"تشغيل التعليمات البرمجية بجوار قاعدة البيانات الخاصة بي"، و"الوظيفة التي لن تنتهي مهلةها"، و"وظائف النيون"، و"حساب النيون".
