Une API et un identifiant pour les LLM frontaliers et open source, intégrés à votre branche Neon et alimentés par Databricks. À utiliser lorsqu'un utilisateur souhaite appeler un LLM, ajouter une IA/un chat/un agent à son application, effectuer un itinéraire entre des fournisseurs de modèles (OpenAI, Anthropic, Google/Gemini, Meta, Alibaba, DeepSeek) ou éviter de jongler avec des clés et des comptes API de fournisseurs distincts, en particulier lorsqu'il utilise déjà Neon et souhaite que les requêtes d'IA soient reliées à son projet. Fonctionne avec le SDK OpenAI, le SDK Anthropic, google-genai, le SDK Vercel AI et Mastra en modifiant uniquement l'URL de base. Les déclencheurs incluent « appeler un LLM », « ajouter l'IA à mon application », « terminer le chat », « le routage du modèle », « proxy/passerelle LLM », « une API pour tous les modèles », « utiliser Claude/GPT/Gemini », « AI SDK », « Agent Mastra », « Neon AI Gateway » et « enregistrer/limiter les appels AI ».
