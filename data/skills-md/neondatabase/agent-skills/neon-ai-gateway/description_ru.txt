Один API и одни учетные данные для передовых программ LLM и программ LLM с открытым исходным кодом, встроенные в вашу ветку Neon и работающие на базе Databricks. Используйте, когда пользователь хочет позвонить в LLM, добавить ИИ/чат/агента в свое приложение, маршрутизировать между поставщиками моделей (OpenAI, Anthropic, Google/Gemini, Meta, Alibaba, DeepSeek) или избежать манипулирования ключами и учетными записями API отдельных поставщиков — особенно если они уже используют Neon и хотят, чтобы запросы ИИ разветвлялись с их проектом. Работает с OpenAI SDK, Anthropic SDK, google-genai, Vercel AI SDK и Mastra, изменяя только базовый URL-адрес. Триггеры включают в себя «вызов LLM», «добавление ИИ в мое приложение», «завершение чата», «маршрутизация модели», «прокси/шлюз LLM», «один API для всех моделей», «использование Claude/GPT/Gemini», «AI SDK», «Агент Mastra», «Neon AI Gateway» и «вызовы AI с ограничением журнала/скорости».
