Una API y una credencial para LLM de código abierto y de frontera, integradas en su sucursal de Neon y con tecnología de Databricks. Úselo cuando un usuario quiera llamar a un LLM, agregar IA/chat/un agente a su aplicación, enrutar entre proveedores de modelos (OpenAI, Anthropic, Google/Gemini, Meta, Alibaba, DeepSeek) o evitar hacer malabarismos con cuentas y claves API de proveedores separados, especialmente cuando ya usan Neon y quieren que las solicitudes de IA se ramifiquen con su proyecto. Funciona con OpenAI SDK, Anthropic SDK, google-genai, Vercel AI SDK y Mastra cambiando solo la URL base. Los activadores incluyen "llamar a un LLM", "agregar AI a mi aplicación", "finalizar chat", "enrutamiento de modelo", "LLM proxy/gateway", "una API para todos los modelos", "usar Claude/GPT/Gemini", "AI SDK", "Agente de Mastra", "Neon AI Gateway" y "registro/llamadas AI con límite de velocidad".
