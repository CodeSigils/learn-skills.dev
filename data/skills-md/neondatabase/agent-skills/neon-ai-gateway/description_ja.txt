フロンティアおよびオープンソース LLM 用の 1 つの API と 1 つの認証情報が Neon ブランチに組み込まれ、Databricks によって強化されます。ユーザーが LLM の呼び出し、アプリへの AI/チャット/エージェントの追加、モデル プロバイダー (OpenAI、Anthropic、Google/Gemini、Meta、Alibaba、DeepSeek) 間のルーティング、または個別のプロバイダー API キーとアカウントのやりくりを回避したい場合に使用します。特に、すでに Neon を使用していて AI リクエストをプロジェクトで分岐させたい場合に使用します。ベース URL のみを変更するだけで、OpenAI SDK、Anthropic SDK、google-genai、Vercel AI SDK、Mastra と連携できます。トリガーには、「LLM の呼び出し」、「アプリへの AI の追加」、「チャット完了」、「モデル ルーティング」、「LLM プロキシ/ゲートウェイ」、「すべてのモデルに 1 つの API」、「Claude/GPT/Gemini の使用」、「AI SDK」、「Mastra エージェント」、「Neon AI ゲートウェイ」、および「AI 呼び出しのログ/レート制限」が含まれます。
