واجهة برمجة تطبيقات واحدة وبيانات اعتماد واحدة لبرامج LLM الرائدة والمفتوحة المصدر، مدمجة في فرع Neon لديك ومدعومة بواسطة Databricks. يُستخدم عندما يريد المستخدم الاتصال بـ LLM، أو إضافة الذكاء الاصطناعي/الدردشة/وكيل إلى تطبيقه، أو التوجيه بين موفري النماذج (OpenAI، وAnthropic، وGoogle/Gemini، وMeta، وAlibaba، وDeepSeek)، أو تجنب التوفيق بين مفاتيح وحسابات API المنفصلة للموفر - خاصة عندما يستخدمون Neon بالفعل ويريدون أن تتفرع طلبات الذكاء الاصطناعي مع مشروعهم. يعمل مع OpenAI SDK، وAnthropic SDK، وgoogle-genai، وVercel AI SDK، وMastra عن طريق تغيير عنوان URL الأساسي فقط. تتضمن المشغلات "الاتصال بـ LLM"، و"إضافة الذكاء الاصطناعي إلى تطبيقي"، و"إكمال الدردشة"، و"توجيه النموذج"، و"وكيل/بوابة LLM"، و"واجهة برمجة تطبيقات واحدة لجميع الطرز"، و"استخدام Claude/GPT/Gemini"، و"AI SDK"، و"Mastra agent"، و"Neon AI Gateway"، و"مكالمات الذكاء الاصطناعي ذات السجل/الحد الأقصى للمعدل".
