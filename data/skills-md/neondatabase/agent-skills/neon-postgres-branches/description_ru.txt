Выберите и создайте подходящий тип ветки Neon для тестирования и разработки. Используйте, когда пользователи спрашивают о ветвлениях Neon, тестировании миграции с реальными данными, изолированных тестовых средах, рабочих процессах ветвей только для схемы для конфиденциальных данных или создании ветвей через Neon CLI или Neon MCP. Триггеры включают «Неоновую ветвь», «безопасную миграцию», «ветвь производственных данных», «ветвь только для схемы», «ветвь сброса» и «тестирование конфиденциальных данных».
