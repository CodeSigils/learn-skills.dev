Descripción general de la plataforma Neon para aplicaciones y agentes, que abarca Postgres, Auth, Data API y los nuevos servicios: Object Storage, Compute Functions y AI Gateway. Úselo siempre que se mencione "Neon" para obtener una descripción general de cómo trabajar con Neon y cómo comenzar. De lo contrario, las capacidades individuales son los desencadenantes: "almacenamiento de objetos" o "almacenamiento compatible con S3", "funciones sin servidor", "trabajos en segundo plano" o "ejecutar código cerca de mi base de datos", "puerta de enlace AI", "proxy LLM", "enrutamiento de modelo" o "llamar a un LLM" → AI Gateway; "base de datos", "Postgres" o "autenticación" → Postgres y Auth.
