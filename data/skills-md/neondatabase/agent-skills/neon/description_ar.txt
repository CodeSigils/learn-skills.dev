نظرة عامة على منصة Neon للتطبيقات والوكلاء، والتي تشمل Postgres وAuth وData API والخدمات الجديدة: تخزين الكائنات ووظائف الحوسبة وبوابة الذكاء الاصطناعي. استخدمه كلما تم ذكر "نيون" للحصول على نظرة عامة حول كيفية العمل مع النيون وكيفية البدء. بخلاف ذلك، فإن القدرات الفردية هي المشغلات: "تخزين الكائنات" أو "التخزين المتوافق مع S3"، أو "الوظائف بدون خادم"، أو "وظائف الخلفية"، أو "تشغيل التعليمات البرمجية بالقرب من قاعدة البيانات الخاصة بي"، أو "بوابة الذكاء الاصطناعي"، أو "وكيل LLM"، أو "توجيه النموذج"، أو "الاتصال بـ LLM" → بوابة الذكاء الاصطناعي؛ "قاعدة البيانات" أو "Postgres" أو "المصادقة" → Postgres وAuth.
