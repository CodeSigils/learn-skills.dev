Présentation de la plateforme Neon pour les applications et les agents, couvrant Postgres, Auth, Data API et les nouveaux services : Object Storage, Compute Functions et AI Gateway. À utiliser chaque fois que « Neon » est mentionné pour un aperçu de la façon de travailler avec Neon et de la façon de commencer. Sinon, les capacités individuelles sont les déclencheurs : "stockage d'objets" ou "stockage compatible S3", "fonctions sans serveur", "tâches en arrière-plan" ou "exécuter du code à proximité de ma base de données", "passerelle AI", "proxy LLM", "routage de modèle" ou "appeler un LLM" → AI Gateway ; "base de données", "Postgres" ou "authentification" → Postgres et Auth.
