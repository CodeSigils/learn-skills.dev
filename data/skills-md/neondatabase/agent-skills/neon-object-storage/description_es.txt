Almacenamiento de objetos compatible con S3 que se ramifica con su proyecto Neon, de modo que los archivos y la base de datos permanecen sincronizados en cada rama. Úselo cuando un usuario desee almacenamiento de objetos, un depósito, almacenamiento de blobs/archivos o un lugar donde colocar cargas, imágenes, documentos, avatares o archivos generados por el usuario para su aplicación o agente, especialmente cuando ya usa (o está configurando) Neon Postgres y no desea agregar un proveedor de almacenamiento independiente como AWS S3, Cloudflare R2 o Supabase Storage. Los activadores incluyen "almacenamiento de objetos", "depósito", "almacenamiento de blobs", "almacenamiento de archivos", "almacenamiento de cargas/imágenes/archivos", "almacenamiento compatible con S3", "URL prefirmada", "dónde coloco los archivos", "Almacenamiento de objetos de neón", "Almacenamiento de neón" y "almacenamiento que se ramifica con mi base de datos".
