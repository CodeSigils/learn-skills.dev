S3-совместимое объектное хранилище, которое разветвляется вместе с вашим проектом Neon, поэтому файлы и база данных синхронизируются в каждой ветке. Используйте, когда пользователю нужно хранилище объектов, корзина, хранилище BLOB-объектов/файлов или где-то для размещения загрузок, изображений, документов, аватаров или созданных пользователем файлов для своего приложения или агента — особенно если он уже использует (или настраивает) Neon Postgres и не хочет добавлять отдельного поставщика хранилища, такого как AWS S3, Cloudflare R2 или Supabase Storage. Триггеры включают «хранилище объектов», «корзину», «хранилище BLOB-объектов», «хранилище файлов», «хранить загрузки/изображения/файлы», «хранилище, совместимое с S3», «заданный URL-адрес», «куда я могу поместить файлы», «Хранилище объектов Neon», «Хранилище Neon» и «хранилище, которое разветвляется с моей базой данных».
