Neon プロジェクトに応じて分岐する S3 互換のオブジェクト ストレージ。ファイルとデータベースはすべての分岐間で同期されます。ユーザーがオブジェクト ストレージ、バケット、BLOB/ファイル ストレージ、またはアプリやエージェントのアップロード、画像、ドキュメント、アバター、またはユーザー生成ファイルを配置する場所が必要な場合、特に Neon Postgres をすでに使用している (またはセットアップ中) が、AWS S3、Cloudflare R2、Supabase Storage などの別のストレージ プロバイダーを追加したくない場合に使用します。トリガーには、「オブジェクト ストレージ」、「バケット」、「BLOB ストレージ」、「ファイル ストレージ」、「アップロード/画像/ファイルの保存」、「S3 互換ストレージ」、「署名付き URL」、「ファイルをどこに置くか」、「Neon オブジェクト ストレージ」、「Neon ストレージ」、「データベースと分岐するストレージ」が含まれます。
