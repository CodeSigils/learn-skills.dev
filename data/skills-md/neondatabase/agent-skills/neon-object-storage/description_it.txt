Archiviazione di oggetti compatibile con S3 che si ramifica con il tuo progetto Neon, in modo che i file e il database rimangano sincronizzati in ogni ramo. Da utilizzare quando un utente desidera l'archiviazione di oggetti, un bucket, un archivio BLOB/file o un posto in cui inserire caricamenti, immagini, documenti, avatar o file generati dall'utente per la propria app o agente, soprattutto quando utilizza già (o sta configurando) Neon Postgres e non desidera aggiungere un provider di archiviazione separato come AWS S3, Cloudflare R2 o Supabase Storage. I trigger includono "archiviazione di oggetti", "bucket", "archiviazione BLOB", "archiviazione di file", "archiviazione di caricamenti/immagini/file", "archiviazione compatibile con S3", "URL prefirmato", "dove metto i file", "Neon Object Storage", "Neon Storage" e "archiviazione che si ramifica con il mio database".
