Stockage d'objets compatible S3 qui se branche avec votre projet Neon, de sorte que les fichiers et la base de données restent synchronisés dans chaque branche. À utiliser lorsqu'un utilisateur souhaite un stockage d'objets, un compartiment, un stockage blob/fichier ou un endroit où placer des téléchargements, des images, des documents, des avatars ou des fichiers générés par l'utilisateur pour son application ou son agent, en particulier lorsqu'il utilise déjà (ou est en train de configurer) Neon Postgres et ne souhaite pas ajouter un fournisseur de stockage distinct comme AWS S3, Cloudflare R2 ou Supabase Storage. Les déclencheurs incluent « stockage d'objets », « compartiment », « stockage blob », « stockage de fichiers », « stockage de téléchargements/images/fichiers », « stockage compatible S3 », « URL présignée », « où dois-je placer les fichiers », « Stockage d'objets Neon », « Stockage Neon » et « stockage qui se branche avec ma base de données ».
