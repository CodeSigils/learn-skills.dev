وحدة تخزين كائنات متوافقة مع S3 والتي تتفرع مع مشروع Neon الخاص بك، بحيث تظل الملفات وقاعدة البيانات متزامنة عبر كل فرع. يُستخدم عندما يريد المستخدم تخزين الكائنات، أو حاوية، أو تخزين كائن كبير/ملف، أو مكان ما لوضع التحميلات أو الصور أو المستندات أو الصور الرمزية أو الملفات التي أنشأها المستخدم لتطبيقه أو وكيله - خاصة عندما يستخدمون بالفعل (أو يقومون بإعداد) Neon Postgres ولا يريدون إضافة موفر تخزين منفصل مثل AWS S3 أو Cloudflare R2 أو Supabase Storage. تتضمن المشغلات "تخزين الكائنات"، و"الحزمة"، و"تخزين البيانات الكبيرة الحجم"، و"تخزين الملفات"، و"تحميلات/صور/ملفات المتجر"، و"التخزين المتوافق مع S3"، و"عنوان URL المحدد مسبقًا"، و"أين أضع الملفات"، و"تخزين كائنات النيون"، و"تخزين نيون"، و"التخزين المتفرع من قاعدة البيانات الخاصة بي".
