S3-kompatibler Objektspeicher, der mit Ihrem Neon-Projekt verzweigt, sodass Dateien und Datenbank in jedem Zweig synchron bleiben. Verwenden Sie diese Option, wenn ein Benutzer Objektspeicher, einen Bucket, Blob-/Dateispeicher oder einen Ort zum Ablegen von Uploads, Bildern, Dokumenten, Avataren oder benutzergenerierten Dateien für seine App oder seinen Agenten möchte – insbesondere, wenn er Neon Postgres bereits verwendet (oder gerade einrichtet) und keinen separaten Speicheranbieter wie AWS S3, Cloudflare R2 oder Supabase Storage hinzufügen möchte. Zu den Auslösern gehören „Objektspeicher“, „Bucket“, „Blob-Speicher“, „Dateispeicher“, „Uploads/Bilder/Dateien speichern“, „S3-kompatibler Speicher“, „vorsignierte URL“, „Wo lege ich Dateien ab“, „Neon-Objektspeicher“, „Neon-Speicher“ und „Speicher, der mit meiner Datenbank verzweigt“.
