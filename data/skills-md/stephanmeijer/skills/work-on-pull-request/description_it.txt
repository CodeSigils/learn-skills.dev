Risolvi gli errori CI, i conflitti di unione e il feedback dei revisori su una richiesta pull GitHub o Forgejo esistente come autore PR. Da utilizzare quando viene richiesto di lavorare su un PR, riparare CI fallito, ribasare un PR in conflitto sul suo ramo di destinazione, affrontare o correggere il feedback PR, classificare thread di revisione non risolti, rispondere o risolvere commenti indirizzati, preparare modifiche di follow-up o spostare un PR verso la fusione.
