Résolvez les échecs de CI, les conflits de fusion et les commentaires des réviseurs sur une demande d'extraction GitHub ou Forgejo existante en tant qu'auteur des relations publiques. À utiliser lorsqu'on vous demande de travailler sur un PR, de réparer un CI défaillant, de rebaser un PR en conflit sur sa branche cible, de traiter ou de corriger les commentaires de PR, de trier les fils de révision non résolus, de répondre ou de résoudre les commentaires adressés, de préparer des modifications de suivi ou de déplacer un PR vers une fusion.
