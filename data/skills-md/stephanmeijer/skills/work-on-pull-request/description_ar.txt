العمل من خلال حالات فشل CI، ودمج الصراعات، وتعليقات المراجعين على طلب سحب GitHub أو Forgejo الحالي كمؤلف للعلاقات العامة. يُستخدم عندما يُطلب منك العمل على العلاقات العامة، أو إصلاح CI الفاشلة، أو إعادة إسناد العلاقات العامة المتعارضة إلى الفرع المستهدف، أو معالجة تعليقات العلاقات العامة أو إصلاحها، أو فرز سلاسل المراجعة التي لم يتم حلها، أو الرد على التعليقات الموجهة أو حلها، أو إعداد تغييرات المتابعة، أو نقل العلاقات العامة نحو الدمج.
