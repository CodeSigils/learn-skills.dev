Работайте над ошибками CI, конфликтами слияния и отзывами рецензентов по существующему запросу на извлечение GitHub или Forgejo в качестве автора PR. Используйте, когда вас просят поработать над PR, исправить сбойный CI, перебазировать конфликтующий PR в его целевую ветку, адресовать или исправить отзывы о PR, отсортировать неразрешенные цепочки проверок, ответить на адресованные комментарии или разрешить их, подготовить последующие изменения или переместить PR в сторону слияния.
