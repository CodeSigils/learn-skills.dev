Examinez et triez les demandes d'extraction sur GitHub et Forgejo, y compris Codeberg, avec des réponses de première classe dans les fils de discussion en ligne de GitHub. À utiliser lorsqu'on vous demande d'examiner un PR, d'inspecter un PR GitHub avec gh, de répondre aux commentaires de ligne de code dans son fil de discussion existant, d'inspecter un PR Forgejo avec fj ou son API REST, d'analyser les échecs de CI, de classer les commentaires non résolus des réviseurs, de préparer des correctifs, de soumettre une révision globale ou de résoudre les fils de révision.
