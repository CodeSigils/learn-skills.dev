مراجعة طلبات السحب وفرزها على GitHub وForgejo، بما في ذلك Codeberg، مع ردود من الدرجة الأولى داخل سلاسل المراجعة المضمنة في GitHub. يُستخدم عند مطالبتك بمراجعة العلاقات العامة، وفحص العلاقات العامة في GitHub باستخدام gh، والرد على تعليقات سطر التعليمات البرمجية في مؤشر الترابط الحالي الخاص به، وفحص Forgejo PR باستخدام fj أو REST API، وتحليل حالات فشل CI، وتصنيف تعليقات المراجعين التي لم يتم حلها، وإعداد الإصلاحات، وإرسال مراجعة شاملة، أو حل سلاسل المراجعة.
