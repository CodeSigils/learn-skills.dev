Überprüfen und selektieren Sie Pull-Anfragen auf GitHub und Forgejo, einschließlich Codeberg, mit erstklassigen Antworten in GitHub-Inline-Review-Threads. Verwenden Sie diese Funktion, wenn Sie aufgefordert werden, eine PR zu überprüfen, eine GitHub-PR mit gh zu überprüfen, auf Codezeilen-Feedback in ihrem vorhandenen Thread zu reagieren, eine Forgejo-PR mit fj oder ihrer REST-API zu überprüfen, CI-Fehler zu analysieren, ungelöstes Reviewer-Feedback zu klassifizieren, Korrekturen vorzubereiten, eine Gesamtüberprüfung einzureichen oder Überprüfungsthreads aufzulösen.
