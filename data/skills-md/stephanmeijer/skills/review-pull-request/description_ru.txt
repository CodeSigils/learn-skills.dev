Просматривайте и сортируйте запросы на включение на GitHub и Forgejo, включая Codeberg, с первоклассными ответами во встроенных цепочках обзора GitHub. Используйте, когда вас попросят просмотреть PR, проверить GitHub PR с помощью gh, ответить на отзывы по строкам кода в существующей ветке, проверить Forgejo PR с помощью fj или его REST API, проанализировать сбои CI, классифицировать неразрешенные отзывы рецензентов, подготовить исправления, отправить общий обзор или разрешить потоки отзывов.
