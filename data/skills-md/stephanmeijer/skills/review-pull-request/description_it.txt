Esamina e valuta le richieste pull su GitHub e Forgejo, incluso Codeberg, con risposte di prima classe all'interno dei thread di revisione in linea di GitHub. Da utilizzare quando viene richiesto di rivedere un PR, ispezionare un PR GitHub con gh, rispondere al feedback della riga di codice nel suo thread esistente, ispezionare un PR Forgejo con fj o la sua API REST, analizzare errori CI, classificare feedback di revisori irrisolti, preparare correzioni, inviare una revisione generale o risolvere thread di revisione.
