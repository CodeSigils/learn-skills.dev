Utilice esta habilidad siempre que el usuario solicite ayuda con composición musical, teoría musical, composición de canciones, armonía, melodía, contrapunto, arreglo, orquestación o análisis musical, en música clásica, jazz, pop, rock, hip-hop, R&B, electrónica, cine/TV, K-pop/J-pop, folk o teatro musical. Los desencadenantes incluyen preguntas teóricas explícitas ("qué escala encaja en Cm7", "explicar ii-V-I", "modular de C a E♭"), preguntas de artesanía ("escribir una progresión de acordes para un puente melancólico", "hacer que esta melodía sea más memorable", "expresar este acorde en el piano") y problemas creativos vagos que se relacionan con técnicas de composición ("el coro se siente débil", "esta transición es incómoda", "mi canción suena genérica"). Utilice esta habilidad incluso cuando el usuario describa el objetivo en términos no técnicos: traducir problemas creativos confusos en movimientos de composición concretos es exactamente para lo que sirve esta habilidad. NO lo use para operación DAW, generación de archivos MIDI, ingeniería de audio, mezcla/masterización, diseño de sonido o interfaz de usuario de software de notación.
