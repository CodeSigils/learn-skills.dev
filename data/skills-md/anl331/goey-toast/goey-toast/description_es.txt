Instale y use goey-toast, un componente de brindis React pegajoso y transformador creado en Sonner con Framer Motion. Úselo cuando agregue una interfaz de usuario de notificación/brindis a una aplicación React (éxito/error/advertencia/información/brindis de promesa), o cuando el usuario mencione una tostada pegajosa/tostada pegajosa.
