Mire cualquier video social (YouTube, X, LinkedIn, TikTok, Vimeo, Reddit, Facebook) entregando la URL al comando local "ver". Skill descarga el vídeo, extrae fotogramas espaciados uniformemente, transcribe el audio y los agrupa como contexto sobre el que razona el agente. Úselo cuando el usuario comparte la URL de un video y quiere que usted vea, analice, resuma, implemente, clone, extraiga arquitectura o cree algo a partir de él. Se activan frases como "ver este video", "analizar esta URL", "implementar esto", "clonar esta interfaz de usuario", "crear lo que hay en este video", "explicar esta charla", "extraer la arquitectura de este video", "convertir este documento en código" o cuando una URL de youtube.com / x.com / twitter.com / linkedin.com / tiktok.com / vimeo.com / reddit.com / facebook.com aparece junto a un verbo.
