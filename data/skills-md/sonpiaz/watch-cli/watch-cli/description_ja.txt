URL をローカルの「watch」コマンドに渡すことで、ソーシャル ビデオ (YouTube、X、LinkedIn、TikTok、Vimeo、Reddit、Facebook) を視聴できます。スキルはビデオをダウンロードし、等間隔のフレームを抽出し、音声を文字に起こし、エージェントが推論したコンテキストとしてそれらをバンドルします。ユーザーがビデオ URL を共有し、それを視聴、分析、要約、実装、クローン作成、アーキテクチャを抽出、またはそこから何かを構築してもらいたい場合に使用します。 「このビデオを見る」、「この URL を分析する」、「これを実装する」、「この UI を複製する」、「このビデオの内容を構築する」、「この講演を説明する」、「このビデオからアーキテクチャを抽出する」、「この論文をコードに変換する」などのフレーズ、または youtube.com / x.com / twitter.com / linkedin.com / tiktok.com / vimeo.com / reddit.com / の URL がトリガーされる場合facebook.com は動詞と一緒に表示されます。
