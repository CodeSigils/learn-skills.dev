通过将 URL 传递给本地“watch”命令来观看任何社交视频（YouTube、X、LinkedIn、TikTok、Vimeo、Reddit、Facebook）。 Skill 下载视频，提取均匀间隔的帧，转录音频，并将它们捆绑为代理推理的上下文。当用户共享视频 URL 并希望您观看、分析、总结、实现、克隆、从中提取架构或构建某些内容时使用。触发诸如“观看此视频”、“分析此 URL”、“实现此”、“克隆此 UI”、“构建此视频中的内容”、“解释此演讲”、“从此视频中提取架构”、“将本文转换为代码”等短语，或者当来自 youtube.com / x.com / twitter.com / linkedin.com / tiktok.com / vimeo.com / reddit.com / facebook.com 的 URL 出现在旁边时触发一个动词。
