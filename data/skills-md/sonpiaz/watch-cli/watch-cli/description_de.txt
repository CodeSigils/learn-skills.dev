Sehen Sie sich beliebige soziale Videos an (YouTube, X, LinkedIn, TikTok, Vimeo, Reddit, Facebook), indem Sie die URL an den lokalen Befehl „watch“ übergeben. Skill lädt das Video herunter, extrahiert gleichmäßig verteilte Frames, transkribiert das Audio und bündelt sie als Kontext, über den der Agent nachdenkt. Verwenden Sie diese Option, wenn der Benutzer eine Video-URL teilt und möchte, dass Sie sie ansehen, analysieren, zusammenfassen, implementieren, klonen, Architektur daraus extrahieren oder etwas daraus erstellen. Wird bei Phrasen wie „dieses Video ansehen“, „diese URL analysieren“, „dies implementieren“, „diese Benutzeroberfläche klonen“, „erstellen, was in diesem Video enthalten ist“, „diesen Vortrag erklären“, „Architektur aus diesem Video extrahieren“, „dieses Papier in Code umwandeln“ ausgelöst oder wenn eine URL von youtube.com / x.com / twitter.com / LinkedIn.com / tiktok.com / vimeo.com / reddit.com / facebook.com neben einem Verb erscheint.
