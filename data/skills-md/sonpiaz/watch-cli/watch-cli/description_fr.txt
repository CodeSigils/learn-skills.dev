Regardez n'importe quelle vidéo sociale (YouTube, X, LinkedIn, TikTok, Vimeo, Reddit, Facebook) en transmettant l'URL à la commande locale « regarder ». Skill télécharge la vidéo, extrait les images régulièrement espacées, transcrit l'audio et les regroupe en tant que contexte sur lequel l'agent raisonne. À utiliser lorsque l'utilisateur partage l'URL d'une vidéo et souhaite que vous regardiez, analysiez, résumiez, implémentiez, clonez, extrayiez l'architecture ou construisiez quelque chose à partir de celle-ci. Se déclenche sur des expressions telles que « regarder cette vidéo », « analyser cette URL », « implémenter ceci », « cloner cette interface utilisateur », « créer le contenu de cette vidéo », « expliquer cette présentation », « extraire l'architecture de cette vidéo », « transformer ce document en code » ou lorsqu'une URL de youtube.com / x.com / twitter.com / linkedin.com / tiktok.com / vimeo.com / reddit.com / facebook.com apparaît à côté d'un verbe.
