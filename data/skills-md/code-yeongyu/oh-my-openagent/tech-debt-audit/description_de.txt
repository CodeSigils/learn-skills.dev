Gründliche, aktenkundige technische Schuldenprüfung über 9 Dimensionen hinweg mit AST-grep (Baumsitter), grep, sprachnativen Tools und optional CodeGraph Knowledge Graph. Erstellt TECH_DEBT_AUDIT.md mit Schweregrad, Aufwandsschätzungen und priorisierten Korrekturen. Verwenden Sie diese Option, wenn Sie um eine Überprüfung des Zustands der Codebasis, Prüfung der technischen Schulden, Überprüfung der Architektur, Bewertung der Codequalität oder Bereinigungsplanung gebeten werden. Auslöser: „Tech Debt“, „Technical Debt“, „Debt Audit“, „Code Health“, „Technical Debt Audit“, „Codebase Health Check“, „Find Tech Debt“, „Debt Analysis“, „Audit Code Quality“.
