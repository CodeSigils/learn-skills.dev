Полный жизненный цикл PR в новом рабочем дереве git, принадлежащем задаче: реализация с помощью навыка ulw-loop с обязательным руководством по обеспечению качества с обоснованием → читаемый рецензентом английский PR → цикл проверки (CI + рецензенты-проверки + Cubic, где Cubic пропускается только тогда, когда его квота исчерпана) → слияние по умолчанию → очистка рабочего дерева. Разбивает одну задачу на мельчайшие атомарные, независимо объединяемые PR и строит независимые задачи одновременно с помощью одного рабочего дерева для каждого PR, управляемого параллельными субагентами или командой. Неограниченный цикл: любой вышедший из строя шлюз отправляет вас обратно на этап «исправление и повторный контроль качества» внутри рабочего дерева этого PR. Используйте всякий раз, когда работа по внедрению должна стать PR. Триггеры: «создать PR», «внедрить и PR», «работать над этим и сделать PR», «реализовать проблему», «оформить это как PR», «разделить на атомарные PR», «параллельные PR», «работать с PR», «рабочий процесс PR», «внедрить сквозной», даже когда пользователь просто говорит «внедрить X», если контекст подразумевает доставку PR.
