Vollständiger PR-Lebenszyklus in einem neuen aufgabeneigenen Git-Arbeitsbaum: Implementierung über den ulw-Loop-Skill mit obligatorischer evidenzgebundener manueller Qualitätssicherung → für Prüfer lesbare englische PR → Verifizierungsschleife (CI + Prüfer für Überprüfungsarbeiten + Cubic, wobei Cubic nur übersprungen wird, wenn sein Kontingent erschöpft ist) → standardmäßig zusammenführen → Bereinigung des Arbeitsbaums. Zerlegt eine Aufgabe in die kleinsten atomaren, unabhängig zusammenfügbaren PRs und erstellt die unabhängigen gleichzeitig über einen Arbeitsbaum pro PR, der von parallelen Subagenten oder einem Team gesteuert wird. Unbegrenzte Schleife: Jedes fehlerhafte Gate schickt Sie zurück zur Fehlerbehebung und erneuten Qualitätssicherung im Arbeitsbaum dieses PR. Verwenden Sie es immer dann, wenn Implementierungsarbeiten als PR landen müssen. Auslöser: „PR erstellen“, „PR implementieren und PR“, „daran arbeiten und PR erstellen“, „Problem implementieren“, „dies als PR landen“, „in atomare PRs aufteilen“, „parallele PRs“, „mit PR arbeiten“, „PR-Workflow“, „durchgehend implementieren“, selbst wenn der Benutzer nur „X implementieren“ sagt, wenn der Kontext die Bereitstellung von PR impliziert.
