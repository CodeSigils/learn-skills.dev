Контроль качества самой версии omo Codex Light (lazycodex / packages/omo-codex), в строгой изоляции, поэтому используется ТОЛЬКО наш плагин, а не настоящий ~/.codex пользователя. Первичный метод управляет реальным «сервером приложений Codex» против изолированного CODEX_HOME плюс ЛОКАЛЬНОЙ фиктивной модели (без реального вызова API) и доказывает срабатывание подключаемого модуля путем утверждения уведомлений об отправке/запуске + перехвате/завершении. А также: проверка изолированной установки, проверка перехвата каждого компонента, дым TUI tmux и наблюдение за журналом времени выполнения (RUST_LOG / logs SQLite / /debug-config). Поставляет протестированные вспомогательные сценарии, каждый из которых снабжен параметром --self-test. Используйте всякий раз, когда кто-то меняет что-либо в packages/omo-codex или хочет провести контроль качества, дымовое тестирование, проверку или отладку плагина Codex, его перехватчиков/компонентов, установщика/config.toml, потока сервера приложений или TUI Codex. Триггеры: codex qa, qa codex, codex-qa, тестовый плагин кодекса, проверка перехватчика кодекса, сервер приложений кодекса, lazycodex qa, изолированный CODEX_HOME, подтверждение срабатывания перехватчика кодекса, проверка codex tui.
