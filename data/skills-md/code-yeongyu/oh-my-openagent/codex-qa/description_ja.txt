omo Codex Light エディション (lazycodex/packages/omo-codex) 自体を QA します。厳密に分離されているため、プラグインのみが実行され、ユーザーの実際の ~/.codex は実行されません。ファーストパーティのメソッドは、分離された CODEX_HOME と LOCAL モック モデル (実際の API 呼び出しなし) に対して実際の「コーデックス アプリ サーバー」を駆動し、フック/開始 + フック/完了通知をアサートすることでプラグイン フックが起動されることを証明します。また、分離されたインストールの検証、コンポーネントごとのフック プローブ、tmux TUI スモーク、およびランタイム ログの観察 (RUST_LOG / logs SQLite / /debug-config)。テスト済みのヘルパー スクリプトをそれぞれ --self-test とともに出荷します。誰かがpackages/omo-codexの下で何かを変更する場合、またはCodexプラグイン、そのフック/コンポーネント、インストーラー/config.toml、アプリサーバーフロー、またはCodex TUIをQA、スモークテスト、検証、またはデバッグしたい場合は常に使用します。トリガー: codex qa、qa codex、codex-qa、codex プラグインのテスト、codex フックの検証、codex アプリサーバー、lazycodex qa、分離された CODEX_HOME、codex フックの起動の証明、codex tui テスト。
