Предварительная публикация 16-ти агентов ядерного уровня. Запускает /get-unpublished-changes для обнаружения всех изменений с момента последнего выпуска npm, запускает до 10 сверхмозговых агентов для глубокого анализа каждого изменения, вызывает /review-work (5 агентов) для целостного анализа и 1 оракул для общего синтеза выпуска. Запускается ТОЛЬКО тогда, когда пользователь явно запрашивает проверку перед публикацией — простой запрос на публикацию/выпуск НЕ ДОЛЖЕН инициировать это; /publish отправляет напрямую. Триггеры: «проверка перед публикацией», «проверка перед публикацией», «проверка выпуска», «проверка перед публикацией», «готова к публикации?», «могу ли я опубликовать?», «предварительная публикация», «безопасно для публикации», «проверка публикации», «проверка перед публикацией».
