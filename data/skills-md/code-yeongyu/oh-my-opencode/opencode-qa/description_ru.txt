Сам QA открытого кода, в каждом случае: проверьте CLI/терминал (запуск открытого кода, база данных, подача, экспорт), докажите конкретный перехват/действие/событие плагина, запущенное через поток событий SSE, дымовое тестирование TUI под tmux и исследуйте сеансы в базе данных SQLite открытого кода по идентификатору, заголовку/имени или тексту сообщения. Поставляет протестированные вспомогательные сценарии (каждый с параметром --self-test), а также ссылки для каждого домена. Используйте всякий раз, когда кто-то хочет провести контроль качества, дымовое тестирование, проверку или отладку CLI, HTTP-сервера, подключаемых модулей/событий или TUI открытого кода, а также для поиска/проверки сеансов открытого кода в базе данных. Триггеры: qa открытого кода, открытый код qa, проверка открытого кода, проверка перехватчика открытого кода, база данных сеанса открытого кода, поиск сеанса открытого кода по идентификатору/имени/тексту, тест tui открытого кода, работоспособность сервера открытого кода, поток событий открытого кода.
