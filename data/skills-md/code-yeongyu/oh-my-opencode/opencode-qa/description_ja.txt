ケースごとにオープンコード自体を QA します。CLI/ターミナル (オープンコードの実行、データベース、サーブ、エクスポート) を検証し、SSE イベント ストリーム経由で起動された特定のプラグイン フック/アクション/イベントを証明し、tmux で TUI をスモーク テストし、ID、タイトル/名前、またはメッセージ テキストによってオープンコードの SQLite DB 内のセッションを調査します。テスト済みのヘルパー スクリプト (それぞれ --self-test 付き) とドメインごとの参照を同梱します。オープンコードの CLI、HTTP サーバー、プラグイン フック/イベント、TUI の QA、スモーク テスト、検証、デバッグを行う場合、またはデータベース内のオープンコード セッションを検索/検査する場合に使用します。トリガー: opencode qa、qa opencode、opencode のテスト、opencode フックの検証、opencode セッション データベース、ID/名前/テキストによる opencode セッションの検索、opencode tui テスト、opencode サーバーの健全性、opencode イベント ストリーム。
