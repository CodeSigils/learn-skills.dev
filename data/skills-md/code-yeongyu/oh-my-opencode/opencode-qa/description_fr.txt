Contrôle qualité de l'opencode lui-même, par cas : vérifiez la CLI/le terminal (exécution, base de données, service, exportation de l'opencode), prouvez un crochet/une action/un événement de plugin spécifique déclenché via le flux d'événements SSE, testez la TUI sous tmux et étudiez les sessions dans la base de données SQLite d'opencode par identifiant, titre/nom ou texte du message. Fournit des scripts d'assistance testés (chacun avec un --self-test) ainsi que des références par domaine. À utiliser chaque fois que quelqu'un souhaite effectuer un contrôle qualité, un test de fumée, une vérification ou un débogage de la CLI, du serveur HTTP, des hooks/événements de plug-in ou de la TUI d'opencode, ou pour rechercher/inspecter des sessions opencode dans la base de données. Déclencheurs : opencode qa, qa opencode, tester l'opencode, vérifier le hook opencode, la base de données de session opencode, rechercher la session opencode par identifiant/nom/texte, test tui opencode, santé du serveur opencode, flux d'événements opencode.
