ضمان الجودة: إصدار omo Codex Light (lazycodex / packages/omo-codex) نفسه، في عزلة تامة، لذلك يتم استخدام المكون الإضافي الخاص بنا فقط، وليس ~/.codex الحقيقي للمستخدم أبدًا. تعمل طريقة الطرف الأول على تشغيل "خادم تطبيق المخطوطة" الحقيقي مقابل CODEX_HOME المعزول بالإضافة إلى نموذج وهمي محلي (لا يوجد استدعاء حقيقي لواجهة برمجة التطبيقات)، وتثبت ربط البرنامج الإضافي عن طريق تأكيد إشعارات الخطاف/البدء + الخطاف/المكتملة. أيضًا: التحقق من التثبيت المعزول، وتحقيقات الخطاف لكل مكون، ودخان tmux TUI، ومراقبة سجل وقت التشغيل (RUST_LOG / logs SQLite / /debug-config). قامت السفن باختبار البرامج النصية المساعدة لكل منها باستخدام اختبار ذاتي. يُستخدم عندما يقوم شخص ما بتغيير أي شيء ضمن الحزم/omo-codex أو يريد ضمان الجودة، أو اختبار الدخان، أو التحقق من، أو تصحيح أخطاء مكون Codex الإضافي، أو خطافاته/مكوناته، أو المثبت/config.toml، أو تدفق خادم التطبيق، أو Codex TUI. المشغلات: Codex qa، qa codex، codex-qa، اختبار البرنامج المساعد لـ Codex، التحقق من ربط Codex، خادم تطبيق Codex، Lazycodex qa، CODEX_HOME المعزول، إثبات إطلاق خطاف Codex، اختبار Codex Tui.
