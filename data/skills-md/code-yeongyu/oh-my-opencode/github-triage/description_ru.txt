Сортировка проблем и запросов на GitHub только для чтения. 1 предмет = 1 фоновое задание (категория: быстрое). Анализирует все открытые элементы и записывает подтвержденные отчеты в /tmp/{datetime}/. Для каждого утверждения требуется постоянная ссылка GitHub в качестве доказательства. НИКОГДА не предпринимайте никаких действий на GitHub — никаких комментариев, никаких слияний, никаких закрытий, никаких меток. Только отчеты. Триггеры: «сортировка», «проблемы сортировки», «сортировка PR», «сортировка GitHub».
