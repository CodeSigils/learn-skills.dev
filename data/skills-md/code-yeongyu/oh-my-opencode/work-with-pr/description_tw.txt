在新的任務擁有的 git 工作樹中實現完整的 PR 生命週期：透過 ulw-loop 技能和強制性證據綁定手動 QA → 審閱者可讀的英語 PR → 驗證循環（CI + 審閱工作審閱者 + Cubic，其中 Cubic 僅在其配額耗盡時才被跳過）→ 合併將一項任務分解為最小的原子、可獨立合併的 PR，並透過由平行子代理或團隊驅動的每個 PR 的一個工作樹同時建立獨立任務。無界循環：任何失敗的門都會將您送回 PR 工作樹內的修復和重新 QA。每當實施工作需要作為 PR 落地時使用。觸發器：“創建 PR”、“實施和 PR”、“處理此問題並製定 PR”、“實施問題”、“將其作為 PR”、“拆分為原子 PR”、“並行 PR”、“與 pr 一起工作”、“PR 工作流程”、“實現端到端”，即使在上下文暗示 PR 交付時用戶只是說“實施 X”。
