Cycle de vie complet des relations publiques dans un nouvel arbre de travail git appartenant à la tâche : implémentation via la compétence ulw-loop avec assurance qualité manuelle obligatoire liée aux preuves → RP en anglais lisible par les réviseurs → boucle de vérification (CI + réviseurs de travail de révision + Cube, où Cube n'est ignoré que lorsque son quota est épuisé) → fusion par défaut → nettoyage de l'arbre de travail. Décompose une tâche en plus petits PR atomiques fusionnables indépendamment et construit les indépendants simultanément via un arbre de travail par PR piloté par des sous-agents parallèles ou une équipe. Boucle illimitée : toute porte défaillante vous renvoie au correctif et à la re-QA à l'intérieur de l'arbre de travail de ce PR. À utiliser chaque fois que le travail de mise en œuvre doit aboutir en tant que PR. Déclencheurs : « créer un PR », « mettre en œuvre et PR », « travailler dessus et créer un PR », « mettre en œuvre un problème », « obtenir cela en tant que PR », « diviser en PR atomiques », « PR parallèles », « travailler avec PR », « flux de travail PR », « mettre en œuvre de bout en bout », même lorsque l'utilisateur dit simplement « mettre en œuvre X » si le contexte implique la livraison de PR.
