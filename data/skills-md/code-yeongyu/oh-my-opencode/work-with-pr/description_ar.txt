دورة حياة كاملة للعلاقات العامة في شجرة عمل git جديدة مملوكة للمهام: التنفيذ عبر مهارة ulw-loop مع دليل ضمان الجودة الإلزامي المرتبط بالأدلة ← علاقات عامة باللغة الإنجليزية يمكن قراءتها بواسطة المراجع ← حلقة التحقق (CI + مراجعي عمل المراجعة + Cubic، حيث يتم تخطي Cubic فقط عند استنفاد حصتها) ← الدمج افتراضيًا ← تنظيف شجرة العمل. يقسم مهمة واحدة إلى أصغر عناصر العلاقات العامة الذرية القابلة للدمج بشكل مستقل ويبني المهام المستقلة بشكل متزامن عبر شجرة عمل واحدة لكل علاقات عامة يقودها وكلاء فرعيون متوازيون أو فريق. حلقة غير محدودة: أي بوابة فاشلة تعيدك إلى عملية الإصلاح وإعادة ضمان الجودة داخل شجرة عمل العلاقات العامة. استخدمه عندما تحتاج أعمال التنفيذ إلى الهبوط كممثل للعلاقات العامة. المشغلات: "إنشاء علاقات عامة"، و"التنفيذ والعلاقات العامة"، و"العمل على هذا وإنشاء علاقات عامة"، و"تنفيذ المشكلة"، و"الحصول على هذا كعلاقات عامة"، و"تقسيم إلى علاقات عامة ذرية"، و"علاقات عامة متوازية"، و"العمل مع العلاقات العامة"، و"سير عمل العلاقات العامة"، و"التنفيذ من البداية إلى النهاية"، حتى عندما يقول المستخدم فقط "تنفيذ X" إذا كان السياق يشير إلى تسليم العلاقات العامة.
