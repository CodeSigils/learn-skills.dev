新しいタスク所有の Git ワークツリーでの完全な PR ライフサイクル: 必須の証拠に拘束された手動 QA を備えた ulw ループ スキルを介して実装 → レビュー担当者が読める英語 PR → 検証ループ (CI + レビュー作業レビュー担当者 + Cubic、クォータがなくなった場合にのみ Cubic がスキップされる) → デフォルトでマージ → ワークツリーのクリーンアップ。 1 つのタスクを最小のアトミックな独立してマージ可能な PR に分解し、並列サブエージェントまたはチームによって駆動される PR ごとに 1 つのワークツリーを介して独立した PR を同時に構築します。無制限のループ: ゲートに障害が発生すると、PR のワークツリー内の修正と再 QA に戻ります。実装作業を PR として実行する必要がある場合は常に使用します。トリガー: 「PR を作成する」、「実装して PR」、「これに取り組んで PR を作成する」、「問題を実装する」、「これを PR として実行する」、「アトミック PR に分割」、「並列 PR」、「PR との作業」、「PR ワークフロー」、「エンドツーエンドで実装」。コンテキストが PR 配信を暗示している場合は、ユーザーが単に「X を実装」と言った場合でも同様です。
