Convertissez n'importe quelle page Web frontale en une page d'entrée d'extension de navigateur avec une entrée HTML. Prend en charge les fenêtres contextuelles, les options, le panneau latéral, les outils de développement, le nouvel onglet, le remplacement des signets, le remplacement de l'historique et les entrées personnalisées. À utiliser lorsque l'utilisateur demande à migrer ou à adapter une page Web existante dans l'interface utilisateur de l'extension.
