Wandeln Sie jede Frontend-Webseite mit einem HTML-Eintrag in eine Browser-Erweiterungs-Einstiegsseite um. Unterstützt Popup, Optionen, Sidepanel, Devtools, Newtab, Lesezeichenüberschreibung, Verlaufsüberschreibung und benutzerdefinierte Einträge. Verwenden Sie diese Option, wenn der Benutzer eine Migration oder Anpassung einer vorhandenen Webseite in die Benutzeroberfläche der Erweiterung anfordert.
