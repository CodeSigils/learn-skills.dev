Converti qualsiasi pagina Web frontend in una pagina di ingresso dell'estensione del browser con una voce HTML. Supporta popup, opzioni, pannello laterale, devtools, newtab, sostituzione dei segnalibri, sostituzione della cronologia e voci personalizzate. Da utilizzare quando l'utente chiede di migrare o adattare una pagina web esistente nell'interfaccia utente dell'estensione.
