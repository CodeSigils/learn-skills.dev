Convierta cualquier página web frontend en una página de entrada de extensión del navegador con una entrada HTML. Admite ventanas emergentes, opciones, panel lateral, herramientas de desarrollo, nueva pestaña, anulación de marcadores, anulación de historial y entradas personalizadas. Úselo cuando el usuario solicite migrar o adaptar una página web existente a la interfaz de usuario de extensión.
