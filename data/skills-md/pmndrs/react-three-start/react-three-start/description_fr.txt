Créez, expliquez et modifiez des applications @react-trois/start qui utilisent la scène React Three Fiber basée sur des fichiers et la composition DOM. À utiliser lorsque vous travaillez dans un projet React-Three-Start, lorsque l'utilisateur mentionne @react-Three/start, React-Three-Start, la structure de l'application R3F, les fichiers .scene.tsx/.dom.tsx, les emplacements Scene/Dom, les wrappers, start.config.ts ou la CLI React-Three-start/r3s.
