Configurez et gérez les portefeuilles Solana pour négocier des actions tokenisées via la CLI rwa. À utiliser lorsque l'utilisateur pose des questions sur la configuration du portefeuille, la génération de clés, l'importation d'une phrase de départ, l'affichage de l'adresse du portefeuille, l'installation de la CLI rwa ou l'envoi/retrait de fonds. Déclencheurs : « créer un portefeuille », « générer des clés », « importer une phrase de départ », « afficher l'adresse », « installer rwa », « portefeuille de fonds », « configurer le trading », « envoyer SOL », « envoyer USDC », « retirer », « transférer des jetons ».
