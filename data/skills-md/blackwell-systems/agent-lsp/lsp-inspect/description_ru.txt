Полный аудит качества кода для файла, пакета или каталога. Поддерживает пакетный режим (прогулка по каталогу с параметром --top Ranking), режим сравнения (--diff для проблем только ветвей), калибровку серьезности по радиусу взрыва, предложения по исправлению и уровни достоверности. Применяет таксономию проверок (неактивные символы, молчаливые сбои, перенос ошибок, пробелы в покрытии, тестовое покрытие, дрейф документации, невосстановленные паники, распространение контекста, безопасность параллелизма) с использованием стратегий LSP-first. Проверки параллелизма охватывают 25 языков из 4 семейств (горутина, поток, асинхронный язык, актер). Создает отчет о результатах по уровням серьезности. Языконезависимый.
