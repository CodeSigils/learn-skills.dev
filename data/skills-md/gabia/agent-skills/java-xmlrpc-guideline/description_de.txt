Wird verwendet, wenn die Java XML-RPC-API-Arbeit Vertragsentscheidungen für die Fehlersignalisierung und Interoperabilität erfordert, einschließlich der Definition von XmlRpcException-basierten Fehlern, dem Ersetzen von ungültigen Rückgaben durch explizite Operationsergebnisse, der Überprüfung von Handlern auf Rückkehrcode-Antimuster und der Migration von DTOs von Serializable zu JAXB.
