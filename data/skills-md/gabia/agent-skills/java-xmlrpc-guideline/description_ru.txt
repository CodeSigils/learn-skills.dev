Используйте, когда работа Java XML-RPC API требует принятия решений по контракту для сигнализации ошибок и совместимости, включая определение сбоев на основе XmlRpcException, замену возвратов void явными результатами операций, проверку обработчиков на наличие антишаблонов кода возврата и миграцию DTO из Serializable в JAXB.
