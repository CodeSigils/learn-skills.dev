Stellen Sie Unsloth Studio auf einem Civo Helios Kubernetes-Cluster mit B200-GPUs bereit. Der Benutzer stellt seine kubeconfig-Datei bereit und der Skill übernimmt automatisch die GPU-Aktivierung, die Erstellung von Namespaces, die Speicherbereitstellung und die Bereitstellung von Unsloth Studio. Wird ausgelöst, wenn der Benutzer Helios, Unsloth oder GPU-Feinabstimmung auf Kubernetes erwähnt oder eine kubeconfig-Datei löscht.
