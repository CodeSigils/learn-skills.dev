Implemente Unsloth Studio en un clúster Civo Helios Kubernetes con GPU B200. El usuario proporciona su archivo kubeconfig y la habilidad maneja la habilitación de GPU, la creación de espacios de nombres, el aprovisionamiento de almacenamiento y la implementación de Unsloth Studio automáticamente. Se activa cuando el usuario menciona Helios, Unsloth, ajuste de GPU en Kubernetes o suelta un archivo de kubeconfig.
