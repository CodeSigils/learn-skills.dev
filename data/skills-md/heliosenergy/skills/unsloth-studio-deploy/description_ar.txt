انشر Unsloth Studio على مجموعة Civo Helios Kubernetes المزودة بوحدات معالجة رسوميات B200. يقدم المستخدم ملف kubeconfig الخاص به وتتعامل المهارة مع تمكين GPU وإنشاء مساحة الاسم وتوفير التخزين ونشر Unsloth Studio تلقائيًا. يتم تشغيله عندما يذكر المستخدم ضبط Helios أو Unsloth أو GPU على Kubernetes، أو يسقط ملف kubeconfig.
