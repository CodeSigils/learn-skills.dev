Da utilizzare per attività backend-for-frontend Next.js sensibili alla sicurezza che coinvolgono gestori di route, proxy, azioni server, webhook, callback, livelli di accesso ai dati, moduli solo server, convalida delle richieste, limiti di velocità o limiti di API pubbliche. Da preferire questa competenza quando un'attività Next.js espone endpoint HTTP o sposta dati privilegiati oltre i confini server/client.
