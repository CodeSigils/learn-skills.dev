Используйте для чувствительной к безопасности работы Next.js с серверной частью для внешнего интерфейса, включая обработчики маршрутов, прокси, действия сервера, веб-перехватчики, обратные вызовы, уровни доступа к данным, модули только для сервера, проверку запросов, ограничения скорости или границы общедоступного API. Предпочитайте этот навык, когда задача Next.js предоставляет конечные точки HTTP или перемещает привилегированные данные через границы сервера/клиента.
