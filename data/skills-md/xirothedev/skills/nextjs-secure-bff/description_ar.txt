يُستخدم في أعمال الواجهة الخلفية للواجهة الأمامية لـ Next.js الحساسة للأمان والتي تتضمن معالجات الطريق، أو الوكيل، أو إجراءات الخادم، أو خطافات الويب، أو عمليات الاسترجاعات، أو طبقات الوصول إلى البيانات، أو الوحدات النمطية للخادم فقط، أو التحقق من صحة الطلب، أو حدود المعدل، أو حدود واجهة برمجة التطبيقات العامة. تفضل هذه المهارة عندما تكشف مهمة Next.js عن نقاط نهاية HTTP أو تنقل البيانات المميزة عبر حدود الخادم/العميل.
