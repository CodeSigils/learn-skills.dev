Úselo para trabajos backend-for-frontend de Next.js sensibles a la seguridad que involucren controladores de ruta, proxy, acciones de servidor, webhooks, devoluciones de llamadas, capas de acceso a datos, módulos solo de servidor, validación de solicitudes, límites de velocidad o límites de API públicas. Prefiere esta habilidad cuando una tarea de Next.js expone puntos finales HTTP o mueve datos privilegiados a través de los límites del servidor/cliente.
