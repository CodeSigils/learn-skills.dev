Configure una nueva base de conocimientos de Obsidian con el patrón LLM Wiki. Úselo cuando el usuario quiera crear un segundo cerebro, inicializar una bóveda, configurar una base de conocimiento personal o decir "a bordo". Guía a través de un asistente interactivo para configurar el nombre del almacén, la ubicación, el dominio, el soporte del agente y las herramientas.
