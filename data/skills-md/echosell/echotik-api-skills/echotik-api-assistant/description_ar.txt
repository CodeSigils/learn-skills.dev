قم بتوجيه طلبات المعلومات التجارية لـ TikTok باللغة الطبيعية إلى سير عمل EchoTik API المعتمد من خلال البرامج النصية المحلية. يُستخدم عندما تتضمن المهمة اكتشاف منشئ المحتوى، أو بحث المنتج، أو تحليل البائع، أو ذكاء الفيديو، أو البحث المباشر، أو البحث، أو إعداد التقارير، أو تعيين المعلمات الموجهة بالوثائق على سطح EchoTik API.
