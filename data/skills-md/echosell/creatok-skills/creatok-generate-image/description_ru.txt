Этот навык следует использовать, когда пользователь просит сгенерировать изображение, создать изображение AI, создать изображение продукта, создать визуальное изображение из подсказки или проверить и продолжить существующую задачу создания изображения. Генерирует изображения с помощью API создания изображений CreatOK, а также может восстанавливать прерванные потоки генерации на основе существующего идентификатора задачи.
