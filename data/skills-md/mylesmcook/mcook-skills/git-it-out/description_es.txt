Utilice esta habilidad cuando el usuario desee explícitamente el cierre final de la sesión y no más ramas o limbo de relaciones públicas: verificación adecuada, confirmaciones adecuadas, aterrizaje principal/línea principal, inserción, pasos de fusión/liberación/implementación/publicación nativos del repositorio, actualizaciones del rastreador, manejo completo/punto de control cuando esté configurado y una transferencia concisa. Consígalo cuando se le indiquen mensajes como "sáquelo", "sáquelo", "envíe esto", "ya terminé", "me voy a la cama", "quítelo de mi plato", "termine la sesión" o "ponga esto en producción". No lo utilice para implementaciones totalmente nuevas, depuración abierta, refactorizaciones amplias o para inventar un proceso de lanzamiento desde cero.
