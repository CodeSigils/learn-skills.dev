Найдите проверенные проекты с открытым исходным кодом на GitHub вместо того, чтобы писать свежий код для решения проблем. Используйте, когда задача достаточно универсальна и, вероятно, существует существующий инструмент или библиотека, особенно для утилит CLI, преобразования файлов, очистки, автоматизации, обработки мультимедиа и рабочих процессов разработчиков.
