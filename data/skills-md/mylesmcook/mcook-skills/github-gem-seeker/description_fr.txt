Trouvez des projets open source testés sur GitHub au lieu d'écrire du nouveau code pour les problèmes résolus. À utiliser lorsqu'une tâche est suffisamment générique pour qu'un outil ou une bibliothèque existante existe, en particulier pour les utilitaires CLI, la conversion de fichiers, le scraping, l'automatisation, la gestion des médias et les flux de travail des développeurs.
