Trova progetti open source testati sul campo su GitHub invece di scrivere nuovo codice per i problemi risolti. Da utilizzare quando un'attività è sufficientemente generica da far sì che probabilmente esista uno strumento o una libreria esistente, in particolare per le utilità CLI, la conversione di file, lo scraping, l'automazione, la gestione dei contenuti multimediali e i flussi di lavoro degli sviluppatori.
