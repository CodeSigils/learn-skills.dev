استخدم هذه المهارة عندما يحتاج المستخدم إلى مقارنة جداول PostgreSQL بين قواعد البيانات المصدر والهدف، أو التحقق من صحة ترحيل PostgreSQL، أو فحص انجراف مخطط المصدر/الهدف، أو مقارنة عدد الصفوف أو تجزئات الجدول الحتمية، أو التوفيق بين نطاقات الجدول مثل المخطط* أو قوائم جدول المخطط، أو تقييم مخاطر الترحيل. تفضل هذه المهارة لفرق بيانات PG/PostgreSQL، ومقارنة قاعدة البيانات، والتحقق من صحة الترحيل، وفحوصات قاعدة بيانات المصدر والهدف، ومقارنة بنية الجدول، ورسم خرائط الجدول البادئ، وتحليل انجراف الإنتاج/التدريج.
