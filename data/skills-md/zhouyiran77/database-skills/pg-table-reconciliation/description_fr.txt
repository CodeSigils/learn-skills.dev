Utilisez cette compétence chaque fois que l'utilisateur a besoin de comparer des tables PostgreSQL entre des bases de données source et cible, de valider une migration PostgreSQL, d'inspecter la dérive du schéma source/cible, de comparer le nombre de lignes ou les hachages de table déterministes, de rapprocher des plages de tables telles que les listes schema.* ou schema.table, ou d'évaluer le risque de migration. Préférez cette compétence pour les différences de données PG/PostgreSQL, la comparaison de bases de données, la validation de migration, les vérifications de bases de données source-cible, la comparaison de structures de tables, le mappage de tables préfixées et l'analyse des dérives de production/stade.
