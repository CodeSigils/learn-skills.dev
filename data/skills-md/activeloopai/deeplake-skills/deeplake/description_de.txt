SDK und CLI zur Aufnahme von Daten in von Deeplake verwaltete Tabellen und zur Bereitstellung eines cloudgestützten Dateisystems für persistenten Agentenspeicher. Verwenden Sie diese Option, wenn Benutzer Daten in Deeplake speichern, aufnehmen, abfragen oder dauerhaften Speicher/Dateisystem einrichten möchten.
