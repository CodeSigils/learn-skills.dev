SDK und CLI für den persistenten Deeplake-Speicher – ein cloudgestütztes Dateisystem für KI-Agenten. Verwenden Sie diese Option, wenn Benutzer persistenten Speicher bereitstellen, verwalten oder verwenden möchten, der über Sitzungen hinweg bestehen bleibt, oder einen beliebigen „Deeplake“-CLI-Befehl ausführen möchten.
