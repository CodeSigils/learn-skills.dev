Калибрует письмо для конкретного читателя, профилируя его знания, проблемы и отношение к теме, а затем переписывает для этого читателя, не меняя сути. Используйте, когда контент слишком технический, слишком простой или предназначен не для той аудитории. Триггеры: «пишите для конкретной аудитории», «калибровка аудитории», «это должно работать для читателей, не разбирающихся в технических вопросах», «аудитория не подходит», «откалибровать это для», «это слишком технически / недостаточно технически», «перекалибровать это для».
