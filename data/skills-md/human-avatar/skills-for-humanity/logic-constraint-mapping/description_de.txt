Bilden Sie die gesamte Einschränkungslandschaft für eine Entscheidung, einen Entwurf oder einen Plan ab – unterscheiden Sie harte Grenzen von weichen Präferenzen, decken Sie versteckte Einschränkungen auf und finden Sie Konflikte zwischen ihnen. Verwenden Sie es, bevor Sie sich auf einen Ansatz festlegen, wenn ein Plan immer wieder auf unerwartete Hindernisse stößt oder wenn unklar ist, was tatsächlich verhandelbar ist. AUSLÖSER: „Die Einschränkungen abbilden“, „Womit arbeiten wir eigentlich“, „Was blockiert das“, „Was können wir ändern“, „Einschränkungsanalyse“, jede Situation, in der die Grenzen des Möglichen verstanden werden müssen, bevor man fortfährt.
