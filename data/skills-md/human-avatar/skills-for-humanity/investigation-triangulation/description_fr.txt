Vérifie une affirmation auprès de sources véritablement indépendantes, en distinguant l’amplification de la véritable corroboration. À utiliser lorsque vous voulez savoir si plusieurs sources confirment réellement quelque chose : « puis-je vérifier cela sous plusieurs angles », « les sources indépendantes sont-elles d'accord », « est-ce confirmé par plus d'une source », « ces sources sont-elles réellement indépendantes », « dans quelle mesure cette affirmation est-elle bien corroborée ».
