ОБЯЗАТЕЛЬНЫЕ ТРИГГЕРЫ: «это логический совет», «проведите логический совет», «проверьте это рассуждение под давлением», «правильно ли мое мышление». СИЛЬНЫЕ ТРИГГЕРЫ: любой сложный аргумент, вывод которого имеет значение, план с неочевидными зависимостями, рассуждения, в которые вы вложили деньги и которые хотите подвергнуть стресс-тестированию. Используйте совет по этике для моральных вопросов, совет по этикету для общих решений — этот совет предназначен специально для проверки правильности самих рассуждений.
