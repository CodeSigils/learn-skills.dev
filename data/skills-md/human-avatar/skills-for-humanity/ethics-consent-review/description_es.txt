Revise un flujo de UX, una práctica de datos o un patrón de comunicación para verificar que el consentimiento del usuario sea genuino: informado, voluntario y significativo. Úselo durante el diseño o implementación de flujos de pago, incorporación, configuración de notificaciones, solicitudes de permisos, términos de servicio, patrones oscuros o cualquier característica donde los usuarios tomen decisiones sobre lo que comparten o aceptan. DESENCADENADORES: 'revisión de consentimiento', 'es este patrón oscuro', 'verifique este flujo de incorporación', '¿es este consentimiento genuino', cualquier UX que implique que los usuarios acepten algo, compartan datos o opten por participar o no.
