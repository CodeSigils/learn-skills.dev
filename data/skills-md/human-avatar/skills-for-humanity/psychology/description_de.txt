Einstiegspunkt für das Psychologie-Toolkit. Wege zur richtigen psychologischen Fähigkeit, basierend auf Ihrer Situation. Verwenden Sie es, wenn Sie sagen „Psychologie“, „Was treibt dieses Verhalten an“, „Warum macht diese Person X“, „Welche Vorurteile spielen eine Rolle“, „Wie ändere ich eine Gewohnheit“, „Wie überzeuge ich“, „Soll ich meinem Bauchgefühl vertrauen“, „Was motiviert sie“ oder wenn Sie eine kognitive/Verhaltensanalyse wünschen, ohne zu wissen, welches spezifische Tool dazu passt.
