Cartographiez les relations causales, tracez les dépendances et raisonnez sur les conséquences avant d’agir. À utiliser lorsque vous avez besoin de comprendre ce qui cause quoi, ce qui se brise si quelque chose change ou ce qui doit être vrai pour qu'un plan fonctionne. DÉCLENCHEURS : « cartographier les dépendances », « qu'est-ce qui cause cela », « qu'est-ce qui se casse si je change X », « tracer la cause première », « si X alors quoi », « qu'est-ce qui doit être vrai pour que cela fonctionne », toute situation impliquant une analyse des causes profondes, une évaluation de l'impact, un traçage des dépendances ou un raisonnement sur les chaînes d'effet.
