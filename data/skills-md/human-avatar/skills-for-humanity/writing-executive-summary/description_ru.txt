Подготавливает краткие обзоры, одностраничные обзоры и документы для совета директоров, излагая ситуацию, ключевые выводы, последствия и рекомендации — сначала ответ, максимум одна страница. Используйте, когда для длинного документа требуется краткое изложение для старшей аудитории, которое поможет принять решение. Триггеры: «резюме», «подведите итог для старшей аудитории», «краткое изложение на 1 страницу», «TL;DR для лидерства», «выделите это», «резюме для доски», «напишите краткое описание».
