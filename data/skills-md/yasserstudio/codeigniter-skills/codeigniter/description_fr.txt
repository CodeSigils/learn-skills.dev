À utiliser lorsque vous travaillez avec des applications CodeIgniter 3 ou CodeIgniter 4 : contrôleurs, modèles, vues, routage, requêtes de base de données, migrations, bibliothèques, assistants, sécurité, téléchargements de fichiers, courrier électronique, mise en cache, tests, services, événements, commandes CLI et déploiement. Déclenchez sur : les projets CI3 avec system/core/CodeIgniter.php ou index.php amorçant CI, les projets CI4 avec app/Config/App.php ou spark CLI, toute mention de CodeIgniter, HMVC dans CI3, Shield auth dans CI4, utilisation du générateur de requêtes CI ou commandes 'php spark'.
