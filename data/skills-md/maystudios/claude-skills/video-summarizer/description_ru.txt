Анализирует локальные видеофайлы MP4 с помощью Gemini API и генерирует структурированные сводки Markdown. Поддерживает пользовательские запросы для извлечения конкретной информации вместо сводки по умолчанию. Используйте, когда пользователь хочет обобщить, проанализировать или извлечь ключевые моменты из видеофайлов. Запускается по таким запросам, как «подвести итоги моих видео», «создать сводки уценок для видео», «проанализировать видео с помощью Gemini», «создать сводки видео» или «извлечь X из моих видео». Требуется, чтобы в системе была установлена ​​переменная среды GEMINI_API_KEY.
