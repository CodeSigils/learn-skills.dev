Leitfaden für die Python-Integration von Unreal Engine 5.x PCG (Procedural Content Generation). Behandelt das PCGPythonInterop-Plugin, den Knoten „Python-Skript ausführen“, die PCG-Python-API (PCGComponent, PCGBlueprintElement, PCGSpatialData, PCGPointData), die Editorautomatisierung, benutzerdefinierte PCG-Knoten über Python und bekannte Einschränkungen. Verwenden Sie diese Option, wenn der Benutzer nach PCG Python, PCGPythonInterop, dem Knoten „Python-Skript ausführen“, Python-Skripten für die prozedurale Generierung, der Automatisierung von PCG-Diagrammen mit Python oder der Erstellung benutzerdefinierter PCG-Knoten mit Python/Blueprint fragt.
