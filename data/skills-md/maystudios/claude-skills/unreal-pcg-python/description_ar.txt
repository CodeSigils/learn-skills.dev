دليل Unreal Engine 5.x PCG (إنشاء المحتوى الإجرائي) وتكامل Python. يغطي البرنامج المساعد PCGPythonInterop، وعقدة Execute Python Script، وPCG Python API (PCGComponent، وPCGBlueprintElement، وPCGSpatialData، وPCGPointData)، وأتمتة المحرر، وعقد PCG المخصصة عبر Python، والقيود المعروفة. يُستخدم عندما يسأل المستخدم عن PCG Python، أو PCGPythonInterop، أو تنفيذ عقدة Python Script، أو البرمجة النصية Python للتوليد الإجرائي، أو أتمتة الرسوم البيانية PCG باستخدام Python، أو إنشاء عقد PCG مخصصة باستخدام Python/Blueprint.
