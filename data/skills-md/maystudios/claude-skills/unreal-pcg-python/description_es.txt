Guía para la integración de Python con Unreal Engine 5.x PCG (generación de contenido procesal). Cubre el complemento PCGPythonInterop, el nodo Ejecutar script de Python, la API de PCG Python (PCGComponent, PCGBlueprintElement, PCGSpatialData, PCGPointData), la automatización del editor, los nodos PCG personalizados a través de Python y las limitaciones conocidas. Úselo cuando el usuario pregunte sobre PCG Python, PCGPythonInterop, nodo Ejecutar script de Python, scripts de Python para generación de procedimientos, automatización de gráficos PCG con Python o creación de nodos PCG personalizados con Python/Blueprint.
