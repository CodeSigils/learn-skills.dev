Руководство по интеграции Python с Unreal Engine 5.x PCG (процедурная генерация контента). Охватывает подключаемый модуль PCGPythonInterop, узел «Выполнение сценария Python», API PCG Python (PCGComponent, PCGBlueprintElement, PCGSpatialData, PCGPointData), автоматизацию редактирования, пользовательские узлы PCG через Python и известные ограничения. Используйте, когда пользователь спрашивает о PCG Python, PCGPythonInterop, узле «Выполнение сценария Python», сценариях Python для процедурной генерации, автоматизации графиков PCG с помощью Python или создании пользовательских узлов PCG с помощью Python/Blueprint.
