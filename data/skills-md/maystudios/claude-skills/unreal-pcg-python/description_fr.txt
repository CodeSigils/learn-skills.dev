Guide pour l'intégration Python d'Unreal Engine 5.x PCG (Procedural Content Generation). Couvre le plugin PCGPythonInterop, le nœud Execute Python Script, l'API PCG Python (PCGComponent, PCGBlueprintElement, PCGSpatialData, PCGPointData), l'automatisation de l'éditeur, les nœuds PCG personnalisés via Python et les limitations connues. À utiliser lorsque l'utilisateur pose des questions sur PCG Python, PCGPythonInterop, le nœud Execute Python Script, les scripts Python pour la génération procédurale, l'automatisation des graphiques PCG avec Python ou la création de nœuds PCG personnalisés avec Python/Blueprint.
