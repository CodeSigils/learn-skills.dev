Guide complet des meilleures pratiques pour le développement moderne d’Unreal Engine 5.x. Couvre l'orientation stratégique d'Epic vers les systèmes modernes (GAS, Enhanced Input, StateTree, MetaSounds, Niagara, PCG, CommonUI, World Partition, Game Feature Plugins, Gameplay Tags), la philosophie de « recherche d'abord » consistant à toujours vérifier les nouveaux systèmes UE avant de les implémenter, la prise de décision C++ vs Blueprint, la conception basée sur les données, la gestion des actifs, l'organisation du projet, les conventions de dénomination, l'optimisation des performances et le débogage avec Unreal Insights. À utiliser lorsque l'utilisateur pose des questions sur les meilleures pratiques UE, les flux de travail UE5 modernes, le système à utiliser, les anciens et les nouveaux systèmes UE, les approches recommandées, la configuration du projet, l'organisation du code, les conseils en matière de performances, les décisions Blueprint vs C++, les conventions de dénomination ou lors du démarrage d'une nouvelle fonctionnalité et ayant besoin de conseils sur le bon système UE à utiliser. Se déclenche également lorsque l'utilisateur demande s'il existe une façon plus récente/meilleure de faire quelque chose dans Unreal Engine, ou lorsqu'il compare les systèmes existants avec les systèmes de remplacement modernes. Couvre les systèmes obsolètes et leurs chemins de migration.
