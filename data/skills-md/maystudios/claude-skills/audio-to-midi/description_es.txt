Convierta archivos de audio MP3/WAV/FLAC a MIDI (.mid) y MusicXML (.musicxml) con análisis musical completo. Dos motores: Basic Pitch (polifónico de uso general) y Piano Model (piano de alta precisión, 96,7% F1). Separación de tallos Demucs opcional. Utilice --engine piano para música de piano/teclado para obtener mejores resultados. Se activa cuando el usuario desea: transcribir audio a MIDI, convertir música en partituras/notas, extraer notas de audio, obtener MusicXML de una grabación, analizar tempo/clave/acordes de una canción, separar temas (voz/batería/bajo) y transcribir cada uno, o cualquier tarea de audio a notación. También activadores de solicitudes como "convertir este MP3 a MIDI", "obtener las notas de esta canción", "en qué clave está esta canción", "transcribir este audio", "separar y transcribir temas".
