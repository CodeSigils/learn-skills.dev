ソフトウェア/CLI ツール、開発者ライブラリ、技術製品のための実稼働グレードのランディング ページを構築します。 「Maxsim スタイル」デザイン システムを使用します: ダーク テーマ、青いアクセントの輝き、フレーマー モーション アニメーション、幾何学的なヒーロー グリッド、マーキー テクノロジー スタック、タブ付きドキュメント、タイムラインの仕組みセクション。ユーザーが「自分のソフトウェアのランディング ページを作成する」、「製品サイトを構築する」、「maxsim-flutter のようなランディング ページを作成する」、「開発者のランディング ページ」、または「CLI ツール Web サイト」と言ったときにトリガーされます。スタック: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React。
