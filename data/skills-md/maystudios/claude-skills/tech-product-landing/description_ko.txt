소프트웨어/CLI 도구, 개발자 라이브러리 및 기술 제품에 대한 프로덕션 등급 랜딩 페이지를 구축하세요. "Maxsim 스타일" 디자인 시스템을 사용합니다: 어두운 테마, 파란색 액센트 글로우, 프레이머 모션 애니메이션, 기하학적 영웅 그리드, 움직이는 기술 스택, 탭 문서 및 타임라인 작동 방식 섹션. 사용자가 "내 소프트웨어에 대한 랜딩 페이지 생성", "제품 사이트 구축", "maxsim-flutter와 같은 랜딩 페이지 만들기", "개발자 랜딩 페이지" 또는 "CLI 도구 웹사이트"라고 말하면 트리거됩니다. 스택: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
