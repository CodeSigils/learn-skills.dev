Crea pagine di destinazione di livello produttivo per strumenti software/CLI, librerie per sviluppatori e prodotti tecnici. Utilizza il sistema di progettazione "stile Maxsim": tema scuro, bagliori blu, animazioni framer-motion, griglia geometrica degli eroi, stack tecnologico di selezione, documenti a schede e sezioni di come funziona della timeline. Si attiva quando l'utente dice "crea una pagina di destinazione per il mio software", "crea un sito di prodotto", "crea una pagina di destinazione come maxsim-flutter", "pagina di destinazione dello sviluppatore" o "sito web dello strumento CLI". Stack: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
