Создавайте целевые страницы промышленного уровня для программного обеспечения/инструментов интерфейса командной строки, библиотек разработчиков и технических продуктов. Использует систему дизайна в стиле «Maxsim»: темная тема, синие акценты, анимация движения кадра, геометрическая сетка героев, стек технологий выделения, документы с вкладками и разделы «Как это работает» на временной шкале. Запускается, когда пользователь говорит: «Создайте целевую страницу для моего программного обеспечения», «Создайте сайт продукта», «Создайте целевую страницу, например maxsim-flutter», «Целевая страница разработчика» или «Веб-сайт инструмента CLI». Стек: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
