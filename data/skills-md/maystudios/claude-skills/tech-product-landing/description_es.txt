Cree páginas de destino de nivel de producción para herramientas de software/CLI, bibliotecas de desarrolladores y productos técnicos. Utiliza el sistema de diseño "estilo Maxsim": tema oscuro, brillos de acento azul, animaciones de movimiento de fotograma, cuadrícula geométrica de héroe, pila de tecnología de marquesina, documentos con pestañas y secciones de cómo funciona en la línea de tiempo. Se activa cuando el usuario dice "crear una página de inicio para mi software", "crear un sitio de producto", "crear una página de inicio como maxsim-flutter", "página de inicio del desarrollador" o "sitio web de la herramienta CLI". Pila: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
