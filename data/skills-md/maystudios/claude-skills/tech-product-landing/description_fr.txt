Créez des pages de destination de qualité production pour les outils logiciels/CLI, les bibliothèques de développeurs et les produits techniques. Utilise le système de conception « de style Maxsim » : thème sombre, lueurs d'accent bleu, animations de mouvement d'encadrement, grille de héros géométrique, pile technologique de chapiteau, documents à onglets et sections de chronologie de fonctionnement. Déclenchez lorsque l'utilisateur dit "créer une page de destination pour mon logiciel", "créer un site de produit", "créer une page de destination comme maxsim-flutter", "page de destination du développeur" ou "site Web de l'outil CLI". Pile : Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
