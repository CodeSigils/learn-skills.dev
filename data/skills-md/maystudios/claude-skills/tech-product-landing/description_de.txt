Erstellen Sie Landingpages in Produktionsqualität für Software/CLI-Tools, Entwicklerbibliotheken und technische Produkte. Verwendet das Designsystem im „Maxsim-Stil“: dunkles Design, blaue Akzente, Framer-Motion-Animationen, geometrisches Heldenraster, Marquee-Tech-Stack, Dokumente mit Registerkarten und Abschnitte zur Funktionsweise auf der Zeitleiste. Wird ausgelöst, wenn der Benutzer sagt: „Eine Landingpage für meine Software erstellen“, „Eine Produktseite erstellen“, „Eine Landingpage wie maxsim-flutter erstellen“, „Entwickler-Landingpage“ oder „CLI-Tool-Website“. Stapel: Vite + React + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide React.
