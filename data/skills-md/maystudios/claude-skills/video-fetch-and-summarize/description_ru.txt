Загружает видео с URL-адресов и генерирует сводку Markdown для каждого из них с помощью API Gemini. Поддерживает пользовательские запросы для извлечения конкретной информации вместо сводки по умолчанию. Каждое видео сохраняется в отдельной подпапке, содержащей файл MP4 и summary.md. Используйте этот навык, когда пользователь напрямую предоставляет URL-адреса видео или файл (Markdown, TXT или любой текстовый файл), содержащий URL-адреса видео, и хочет, чтобы видео было загружено и обобщено. Запускается по таким запросам, как «загрузить и суммировать эти видео», «получить эти ссылки и суммировать», «обработать этот список ссылок на видео», «извлечь X из этих видео» или при получении файла с URL-адресами и запросе сводки. Поддерживает Instagram, YouTube, TikTok, Twitter/X, Facebook и более 1000 других платформ. Требуется переменная среды GEMINI_API_KEY.
