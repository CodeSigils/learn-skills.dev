從 URL 下載影片並使用 Gemini API 為每個影片產生 Markdown 摘要。支援自訂提示來提取特定訊息，而不是預設摘要。每個影片都保存在自己的子資料夾中，其中包含 MP4 檔案和 Summary.md。當使用者直接提供影片 URL 或包含影片 URL 的檔案（Markdown、TXT 或任何文字檔案），並希望下載並彙總影片時，請使用此技能。觸發諸如「下載並總結這些影片」、「取得這些連結並總結」、「處理此影片連結清單」、「從這些影片中提取 X」等請求，或在給定帶有 URL 的檔案並要求提供摘要時觸發。支援 Instagram、YouTube、TikTok、Twitter/X、Facebook 和 1000 多個其他平台。需要 GEMINI_API_KEY 環境變數。
