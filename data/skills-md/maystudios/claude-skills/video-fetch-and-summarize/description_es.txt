Descarga videos de URL y genera un resumen de Markdown para cada uno usando la API de Gemini. Admite indicaciones personalizadas para extraer información específica en lugar del resumen predeterminado. Cada vídeo se guarda en su propia subcarpeta que contiene el archivo MP4 y un resumen.md. Utilice esta habilidad cuando el usuario proporcione las URL del video directamente o un archivo (Markdown, TXT o cualquier archivo de texto) que contenga las URL del video y desee descargar y resumir el video. Se activan solicitudes como "descargar y resumir estos videos", "buscar estos enlaces y resumir", "procesar esta lista de enlaces de videos", "extraer X de estos videos" o cuando se le proporciona un archivo con URL y se solicitan resúmenes. Admite Instagram, YouTube, TikTok, Twitter/X, Facebook y más de 1000 plataformas más. Requiere la variable de entorno GEMINI_API_KEY.
