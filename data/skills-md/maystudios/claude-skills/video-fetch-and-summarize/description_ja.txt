URL からビデオをダウンロードし、Gemini API を使用して各ビデオの Markdown サマリーを生成します。デフォルトの概要の代わりに特定の情報を抽出するためのカスタム プロンプトをサポートします。各ビデオは、MP4 ファイルと summary.md を含む独自のサブフォルダーに保存されます。このスキルは、ユーザーがビデオ URL を直接指定するか、ビデオ URL を含むファイル (Markdown、TXT、または任意のテキスト ファイル) を指定し、ビデオのダウンロードと要約の両方を希望する場合に使用します。 「これらのビデオをダウンロードして要約する」、「これらのリンクを取得して要約する」、「このビデオ リンクのリストを処理する」、「これらのビデオから X を抽出する」などのリクエスト、または URL を含むファイルが与えられ、要約を求められた場合にトリガーされます。 Instagram、YouTube、TikTok、Twitter/X、Facebook、その他 1000 以上のプラットフォームをサポートします。 GEMINI_API_KEY 環境変数が必要です。
