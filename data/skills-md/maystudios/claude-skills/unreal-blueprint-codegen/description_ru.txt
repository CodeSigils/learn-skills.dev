Программно сгенерируйте файлы Unreal Engine 5.x Blueprint и Widget Blueprint .uasset из C++. Используйте при создании генератора контента для образцов Fab/Marketplace, наборов для быстрого старта, учебных ресурсов или утилит редактирования, которые массово производят чертежи, чертежи виджетов с анимацией UMG или ресурсы предметной области (диалоги, квесты, данные о способностях). Охватывает создание UBlueprint с полным созданием графа событий (UK2Node_*, FBlueprintEditorUtils), иерархии UWidgetBlueprint, UWidgetAnimation с дорожками и ключевыми кадрами MovieScene, двухпроходную компиляцию и идиому создания K2Node. Запускается при «создании генератора чертежей», «создании WBP из C++», «программном создании графика событий», «создании ресурсов диалога/квеста из кода», «утилите редактора для создания образцов рынка» или любой задаче, включающей FKismetEditorUtilities::CreateBlueprint, UWidgetBlueprintFactory, FBlueprintEditorUtils::AddMemberVariable или UMovieScene2DTransformTrack.
