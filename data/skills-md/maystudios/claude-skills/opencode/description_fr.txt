Invoquez OpenCode CLI en tant que sous-agent pour exploiter des modèles d'IA alternatifs (GPT-5.x, Codex, modèles locaux) pour l'implémentation, la révision, le débogage, la recherche et les deuxièmes avis du code. À utiliser lorsque l'utilisateur demande "utiliser l'opencode", "obtenir un deuxième avis de GPT/Codex", "implémenter avec opencode", "réviser avec opencode", "laisser opencode gérer cela", "utiliser un modèle différent" ou souhaite une validation inter-modèles. Se déclenche également lorsque l'utilisateur nomme explicitement un modèle OpenCode (par exemple, "utiliser gpt-5.4", "utiliser le codex") ou souhaite déléguer une tâche à un système non-Claude AI. Prend en charge tous les fournisseurs configurés dans l'installation OpenCode de l'utilisateur (OpenAI, GitHub Copilot, modèles locaux via Ollama/LM Studio et les propres modèles gratuits d'OpenCode).
