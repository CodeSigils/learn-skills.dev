قم باستدعاء OpenCode CLI كوكيل فرعي للاستفادة من نماذج الذكاء الاصطناعي البديلة (GPT-5.x وCodex والنماذج المحلية) لتنفيذ التعليمات البرمجية والمراجعة وتصحيح الأخطاء والبحث والآراء الثانية. يُستخدم عندما يطلب المستخدم "استخدام الكود المفتوح"، أو "الحصول على رأي ثانٍ من GPT/Codex"، أو "التنفيذ باستخدام الكود المفتوح"، أو "المراجعة باستخدام الكود المفتوح"، أو "السماح للرمز المفتوح بالتعامل مع هذا"، أو "استخدام نموذج مختلف"، أو يريد التحقق من صحة النماذج المشتركة. يتم تشغيله أيضًا عندما يقوم المستخدم صراحةً بتسمية نموذج OpenCode (على سبيل المثال، "استخدام gpt-5.4"، "استخدام المخطوطة") أو عندما يريد تفويض مهمة إلى نظام ذكاء اصطناعي غير تابع لـ Claude. يدعم جميع مقدمي الخدمة الذين تم تكوينهم في تثبيت OpenCode الخاص بالمستخدم (OpenAI وGitHub Copilot والنماذج المحلية عبر Ollama/LM Studio ونماذج الطبقة المجانية الخاصة بـ OpenCode).
