Rufen Sie OpenCode CLI als Subagent auf, um alternative KI-Modelle (GPT-5.x, Codex, lokale Modelle) für Codeimplementierung, Überprüfung, Debugging, Forschung und Zweitmeinungen zu nutzen. Wird verwendet, wenn der Benutzer „Opencode verwenden“, „eine zweite Meinung von GPT/Codex einholen“, „mit Opencode implementieren“, „mit Opencode überprüfen“, „Opencode damit umgehen lassen“, „ein anderes Modell verwenden“ wünscht oder eine modellübergreifende Validierung wünscht. Wird auch ausgelöst, wenn der Benutzer explizit ein OpenCode-Modell benennt (z. B. „gpt-5.4 verwenden“, „Codex verwenden“) oder eine Aufgabe an ein Nicht-Claude-KI-System delegieren möchte. Unterstützt alle Anbieter, die in der OpenCode-Installation des Benutzers konfiguriert sind (OpenAI, GitHub Copilot, lokale Modelle über Ollama/LM Studio und OpenCodes eigene Free-Tier-Modelle).
