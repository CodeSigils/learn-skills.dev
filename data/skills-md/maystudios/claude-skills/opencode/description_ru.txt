Вызов OpenCode CLI в качестве субагента для использования альтернативных моделей искусственного интеллекта (GPT-5.x, Кодекс, локальные модели) для реализации кода, проверки, отладки, исследования и получения сторонних мнений. Используйте, когда пользователь просит «использовать открытый код», «получить второе мнение от GPT/Codex», «реализовать с открытым кодом», «проверить с открытым кодом», «позволить открытому коду справиться с этим», «использовать другую модель» или хочет проверить перекрестную модель. Также срабатывает, когда пользователь явно называет модель OpenCode (например, «использовать gpt-5.4», «использовать кодекс») или хочет делегировать задачу системе искусственного интеллекта, отличной от Claude. Поддерживает всех поставщиков, настроенных при установке OpenCode пользователя (OpenAI, GitHub Copilot, локальные модели через Ollama/LM Studio и собственные модели бесплатного уровня OpenCode).
