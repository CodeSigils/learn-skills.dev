Invoque OpenCode CLI como subagente para aprovechar modelos de IA alternativos (GPT-5.x, Codex, modelos locales) para la implementación, revisión, depuración, investigación y segundas opiniones del código. Úselo cuando el usuario solicite "usar código abierto", "obtener una segunda opinión de GPT/Codex", "implementar con código abierto", "revisar con código abierto", "dejar que el código abierto se encargue de esto", "usar un modelo diferente" o quiere una validación entre modelos. También se activa cuando el usuario nombra explícitamente un modelo OpenCode (por ejemplo, "usar gpt-5.4", "usar codex") o quiere delegar una tarea a un sistema de IA que no sea Claude. Admite todos los proveedores configurados en la instalación de OpenCode del usuario (OpenAI, GitHub Copilot, modelos locales a través de Ollama/LM Studio y los propios modelos de nivel gratuito de OpenCode).
