دليل llama.cpp، إطار عمل الاستدلال C/C++ LLM بواسطة ggml-org. يغطي C API (llama.h)، وتنسيق GGUF، والتكميم (Q4_K_M، Q8_0، IQ4_XS)، وبنيات CMake، والواجهات الخلفية لوحدة معالجة الرسومات (CUDA، Vulkan، Metal، ROCm)، خادم HTTP مع واجهة برمجة التطبيقات المتوافقة مع OpenAI، والتضمينات، والقيود النحوية، واستدعاء الوظائف، وLoRA، وفك التشفير التخميني، والوسائط المتعددة، وتكامل UE5. يُستخدم عندما: llama.cpp، نماذج GGUF، استدلال LLM محلي، llama.h، llama-server، القياس الكمي، ggml، بناء/ربط llama.cpp، تسريع GPU، تضمينات llama.cpp، إخراج القواعد/JSON، llama.cpp في Unreal Engine، وظائف llama_* API، تنسيق GGUF، تحويل HuggingFace إلى GGUF، أو المقارنة مع vLLM/Ollama/TensorRT-LLM.
