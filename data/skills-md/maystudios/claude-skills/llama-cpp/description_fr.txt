Guide pour llama.cpp, le framework d'inférence C/C++ LLM de ggml-org. Couvre l'API C (llama.h), le format GGUF, la quantification (Q4_K_M, Q8_0, IQ4_XS), les builds CMake, les backends GPU (CUDA, Vulkan, Metal, ROCm), le serveur HTTP avec API compatible OpenAI, les intégrations, les contraintes grammaticales, les appels de fonctions, LoRA, le décodage spéculatif, le multimodal et l'intégration UE5. À utiliser lorsque : llama.cpp, modèles GGUF, inférence LLM locale, lama.h, serveur lama, quantification, ggml, création/liaison de lama.cpp, accélération GPU, intégrations de lama.cpp, sortie grammaire/JSON, lama.cpp dans Unreal Engine, fonctions API lama_*, format GGUF, conversion de HuggingFace en GGUF ou comparaison avec vLLM/Ollama/TensorRT-LLM.
