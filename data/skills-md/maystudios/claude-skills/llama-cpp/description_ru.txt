Руководство по llama.cpp, платформе вывода LLM C/C++ от ggml-org. Охватывает C API (llama.h), формат GGUF, квантование (Q4_K_M, Q8_0, IQ4_XS), сборки CMake, серверные части графического процессора (CUDA, Vulkan, Metal, ROCm), HTTP-сервер с OpenAI-совместимым API, внедрения, грамматические ограничения, вызов функций, LoRA, спекулятивное декодирование, мультимодальность и интеграцию UE5. Используйте, когда: llama.cpp, модели GGUF, локальный вывод LLM, llama.h, llama-server, квантование, ggml, сборка/связывание llama.cpp, ускорение графического процессора, встраивание llama.cpp, вывод грамматики/JSON, llama.cpp в Unreal Engine, функции API llama_*, формат GGUF, преобразование HuggingFace в GGUF или сравнение с vLLM/Оллама/TensorRT-LLM.
