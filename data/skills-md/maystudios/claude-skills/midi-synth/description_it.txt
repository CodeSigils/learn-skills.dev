Synthesize and render MIDI/MusicXML files to audio (WAV/MP3) and generate Strudel live-coding patterns for creative music manipulation. Uses analysis data (tempo, key, chords, dynamics) from audio-to-midi for intelligent ghost-note removal and accurate reproduction. Due flussi di lavoro: (1) Conversione di codice MIDI/MusicXML in Strudel/TidalCycles con durate delle note per modifiche interattive nel browser su strudel.cc, (2) Rendering di MIDI/MusicXML in WAV/MP3 con FluidSynth o sintesi integrata, con controlli per tempo, trasposizione, sostituzione dello strumento e pulizia delle note fantasma. Si attiva quando l'utente desidera: riprodurre un file MIDI, eseguire il rendering del MIDI in audio, sintetizzare il MIDI, convertire il codice MIDI in Strudel, creare pattern di codifica in tempo reale dal MIDI, cambiare strumenti, trasporre o spostare il tempo, pulire le note fantasma o qualsiasi attività di riproduzione/sintesi MIDI.
