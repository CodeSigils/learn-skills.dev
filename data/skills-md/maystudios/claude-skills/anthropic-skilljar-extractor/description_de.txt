Extrahiert jeden Kurs der Anthropic Academy (Skilljar) in einen strukturierten Markdown-Ordner. Wird ausgelöst, wenn der Benutzer eine anthropic.skilljar.com-URL angibt und darum bittet, einen Kurs zu extrahieren, zu recherchieren, herunterzuladen oder in Markdown umzuwandeln. Erstellt eine Markdown-Datei pro Lektion, die in Abschnittsordnern organisiert ist, mit heruntergeladenen und beschriebenen Kursdiagrammen. Wird verwendet, wenn der Benutzer Dinge sagt wie „Diesen Kurs extrahieren“, „In Markdown konvertieren“, „Diesen Skilljar-Link gründlich recherchieren“ oder eine URL von anthropic.skilljar.com angibt.
