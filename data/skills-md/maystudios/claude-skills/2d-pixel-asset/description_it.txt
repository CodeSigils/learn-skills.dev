Genera risorse di gioco pixel art 2D utilizzando Google Gemini tramite l'automazione del browser Chrome. Si attiva quando l'utente desidera creare pixel art, sprite di gioco, set di riquadri, risorse di gioco o modificare grafica di gioco esistente. Supporta il caricamento di immagini di riferimento per coerenza di stile, selezione del modello (Flash/Pro), controllo della risoluzione, rimozione automatica dello sfondo (chroma key, basato su ML tramite BiRefNet o Adobe Express) e rasterizzazione con dimensioni pixel esatte. Utilizzare per richieste come "crea una spada pixel art", "genera uno sprite di caratteri 32x32", "crea un set di tessere" o "modifica questo sprite".
