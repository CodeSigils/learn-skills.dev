Base di conoscenza sui test di sicurezza Web+AI. Integra gli 88.636 casi di WooYun + la metodologia L1‑L4 di Oracle + i 150 rischi di GAARM + OWASP Top10 (LLM/ASI/WSTG).  
TRIGGER quando l'attività è un test pratico di sicurezza: test di penetrazione, scoperta/sfruttamento di vulnerabilità, attacco/difesa del team rosso, controllo di sicurezza (SAST/DAST), CTF, test di sicurezza AI/LLM (prompt injection/jailbreak/MCP/Agent/sandbox escape). L'utente fornisce esplicitamente un obiettivo di test (URL/codice/modello/architettura dell'agente) e l'intento è "testare/controllare/trovare vulnerabilità/sfruttare".  

NON attivare:  
- Discussione sul concetto di sicurezza ("Che cos'è XSS", "Qual è il principio dell'iniezione SQL") → Domande e risposte generali  
- Revisione/debug/ottimizzazione delle prestazioni del codice non di sicurezza → competenza di audit del codice o altro  
- Correzione di errori di sintassi/bug di logica aziendale → assistenza generale alla programmazione  
- Audit del codice white-box web puro (audit Java/JS approfondito) → competenza di audit del codice  
- Solo facendo riferimento a un numero CVE per cercare la documentazione → WebSearch  

Si prega di rispondere sempre nella lingua dell'utente.
