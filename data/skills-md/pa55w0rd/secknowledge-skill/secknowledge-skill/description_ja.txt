Web+AI セキュリティ テストのナレッジ ベース。 WooYun 88,636 件 + Prophet L1‑L4 手法 + GAARM 150 リスク + OWASP Top10 (LLM/ASI/WSTG) を統合します。  
タスクが実践的なセキュリティ テストである場合にトリガーします: ペネトレーション テスト、脆弱性の発見/悪用、レッドチームの攻撃/防御、セキュリティ監査 (SAST/DAST)、CTF、AI/LLM セキュリティ テスト (プロンプト インジェクション/ジェイルブレイク/MCP/エージェント/サンドボックス エスケープ)。ユーザーはテスト対象 (URL/コード/モデル/エージェント アーキテクチャ) を明示的に提供し、その目的は「テスト/監査/脆弱性の発見/エクスプロイト」です。  
次の場合はトリガーしないでください。  
・セキュリティ概念ディスカッション（「XSSとは何か」、「SQLインジェクションの原理とは」）→通常のQ&A  
- セキュリティ以外のコードレビュー/デバッグ/パフォーマンスの最適化 → コード監査スキルまたはその他  
- 構文エラー/ビジネスロジックのバグの修正 → 通常のプログラミング支援  
- 純粋な Web ホワイトボックス コード監査 (Java/JS の詳細な監査) → コード監査スキル  
- CVE 番号のみを参照してドキュメントを検索 → WebSearch  

常にユーザーの言語で応答してください。
