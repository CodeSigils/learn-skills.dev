ТРИГГЕР, когда задачей является практическое тестирование безопасности: тестирование на проникновение, обнаружение/эксплуатация уязвимостей, нападение/защита красной командой, аудит безопасности (SAST/DAST), CTF, тестирование безопасности AI/LLM (мгновенное внедрение/побег из тюрьмы/MCP/агент/побег из песочницы). Пользователь явно указывает цель тестирования (URL/код/модель/архитектуру агента), и целью является «тестирование/проверка/нахождение уязвимостей/эксплуатация».  
НЕ запускайте:  
- Обсуждение концепции безопасности («что такое XSS», «каков принцип SQL-инъекции») → обычные вопросы и ответы  
- Проверка/отладка/оптимизация производительности кода, не связанного с безопасностью → навыки аудита кода или другое  
- Исправление синтаксических ошибок/ошибок бизнес-логики → обычная помощь в программировании.  
- Чистый веб-аудит кода «белого ящика» (глубокий аудит Java/JS) → навыки аудита кода  
- Ссылка только на номер CVE для поиска документации → Интернет-поиск.  

Пожалуйста, всегда отвечайте на языке пользователя.
