База знаний по тестированию безопасности Web+AI. Интегрировано с 88 636 делами WooYun, методологией Prophet L1‑L4, рисками GAARM 150 и OWASP Top10 (LLM/ASI/WSTG).  

ТРИГГЕР, когда задачей является практическое тестирование безопасности: тестирование на проникновение, обнаружение/эксплуатация уязвимостей, нападение/защита красной командой, аудит безопасности (SAST/DAST), CTF, тестирование безопасности AI/LLM (мгновенное внедрение/побег из тюрьмы/MCP/агент/побег из песочницы). Пользователь явно указывает цель тестирования (URL/код/модель/архитектуру агента), а целью является «тестирование/проверка/нахождение уязвимостей/эксплуатация».  

НЕ запускайте:  
- Обсуждение концепции безопасности («Что такое XSS», «Каков принцип SQL-инъекции») → общие вопросы и ответы  
- Проверка/отладка/оптимизация производительности кода, не связанного с безопасностью → навыки аудита кода или другое  
- Исправление синтаксических ошибок/ошибок бизнес-логики → общая помощь в программировании.  
- Чистый веб-аудит кода «белого ящика» (глубокий аудит Java/JS) → навыки аудита кода  
- Ссылка только на номер CVE для поиска документации → Интернет-поиск.  

Пожалуйста, всегда отвечайте на языке пользователя.
