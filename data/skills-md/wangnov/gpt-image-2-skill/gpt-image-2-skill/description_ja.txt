このスキルは、ユーザーが「画像を生成する」、「ロゴを作成する」、「アイコンを描く」、「この写真を編集する」、「背景を透明に変更する」、「背景を削除する」、「GPT 画像を使用する」、「Codex を使用して描画する」、「GPT 画像生成图片」、「Codex 画图」、「帮我生成一张图」、「背景透明変更」を要求する場合に使用する必要があります。 「把这张图编辑一下」、または JSON 結果と JSONL 進行状況イベントを返す構造化 CLI の恩恵を受ける、画像へのプロンプトまたは参照画像編集タスク。 OpenAI `gpt-image-2` (`OPENAI_API_KEY` または OpenAI 互換のベース URL 経由) および Codex `image_generation` (`~/.codex/auth.json` 経由) を 1 つのコマンド サーフェスでサポートし、マスク、最大 4K までのカスタム サイズ、透明な背景、生のリクエスト エスケープ ハッチを備えています。
