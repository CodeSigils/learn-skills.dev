Codex デスクトップ アプリケーション用の「具体化された UI」テーマ スキンを作成します (アプリケーション ファイルを変更せずに、AI 生成のビットマップ アセット + CSS + CDP インジェクション)。これは、ユーザーが Codex アプリの新しいテーマを作成する場合、スキンを変更する場合、コンセプト イメージ/スクリーンショット/IP スタイルを Codex インターフェイスに変換する場合、または Codex-Theme-Studio で既存のテーマを反復処理する場合に使用されます。トリガー フレーズには、コーデックス テーマ、コーデックス スキン、コーデックス スキンの変更、コンセプト イメージ UI の再構築、テーマ スタジオ、XX スタイルのコーデックスの作成が含まれます。
