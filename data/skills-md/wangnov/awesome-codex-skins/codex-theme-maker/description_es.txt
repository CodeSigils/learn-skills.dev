Cree un diseño de tema de “IU materializada” para la aplicación de escritorio Codex (activos de mapa de bits generados por IA + CSS + inyección de CDP, sin modificar los archivos de la aplicación). Se utiliza cuando un usuario desea crear un nuevo tema para la aplicación Codex, cambiar su apariencia, convertir una imagen conceptual/captura de pantalla/estilo de IP en una interfaz Codex, o iterar sobre un tema existente en Codex-Theme-Studio. Las frases desencadenantes incluyen: tema del Códice, aspecto del Códice, cambio de aspecto del Códice, reconstrucción de la interfaz de usuario de la imagen conceptual, estudio de temas, creación de un Códice de estilo XX.
