Создайте обложку темы «материализованного пользовательского интерфейса» для настольного приложения Кодекса (растровые ресурсы, созданные искусственным интеллектом + внедрение CSS + CDP, без изменения файлов приложения). Он используется, когда пользователь хочет создать новую тему для приложения Кодекса, изменить его оформление, превратить концептуальное изображение/скриншот/IP-стиль в интерфейс Кодекса или выполнить итерацию существующей темы в Codex‑Theme‑Studio. Триггерные фразы включают в себя: тема Кодекса, скин Кодекса, изменение скина Кодекса, реконструкция пользовательского интерфейса концептуального изображения, студия тем, создание Кодекса в стиле aXX.
