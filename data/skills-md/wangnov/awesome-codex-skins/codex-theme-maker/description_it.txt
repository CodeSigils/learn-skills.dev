Crea una skin del tema "interfaccia utente materializzata" per l'applicazione desktop Codex (risorse bitmap generate dall'intelligenza artificiale + CSS + iniezione CDP, senza modificare i file dell'applicazione). Viene utilizzato quando un utente desidera creare un nuovo tema per l'app Codex, cambiarne la skin, trasformare un'immagine concettuale/screenshot/stile IP in un'interfaccia Codex o eseguire l'iterazione di un tema esistente in Codex‑Theme‑Studio. Le frasi attivatrici includono: tema del Codex, skin del Codex, modifica della skin del Codex, ricostruzione dell'interfaccia utente dell'immagine concettuale, studio del tema, creazione del Codex in stile XX.
