Crea una skin del tema "interfaccia utente materializzata" per l'applicazione desktop Codex (risorse bitmap generate dall'intelligenza artificiale + CSS + iniezione CDP, senza modificare i file dell'app). Viene utilizzato quando un utente desidera creare un nuovo tema per l'app Codex, cambiare skin, trasformare un'immagine concettuale/screenshot/stile IP in un'interfaccia Codex o ripetere temi esistenti in Codex‑Theme‑Studio. Le frasi trigger includono: tema del Codex, skin del Codex, modifica della skin del Codex, ricreazione dell'interfaccia utente di immagini concettuali, studio del tema, creazione di un Codex in stile XX.
