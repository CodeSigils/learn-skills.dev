Erstellen Sie einen „materialisierten UI“-Design-Skin für die Codex-Desktopanwendung (KI-generierte Bitmap-Assets + CSS + CDP-Injection, ohne die Anwendungsdateien zu ändern). Es wird verwendet, wenn ein Benutzer ein neues Thema für die Codex-App erstellen, deren Skin ändern, ein Konzeptbild/Screenshot/IP-Stil in eine Codex-Schnittstelle umwandeln oder ein vorhandenes Thema in Codex-Theme-Studio iterieren möchte. Zu den Triggerphrasen gehören: Codex-Theme, Codex-Skin, Codex-Skin-Änderung, Rekonstruktion der Konzeptbild-Benutzeroberfläche, Theme-Studio, Codex im aXX-Stil erstellen.
