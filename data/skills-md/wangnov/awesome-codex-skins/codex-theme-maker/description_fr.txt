Créez un skin de thème « interface utilisateur matérialisée » pour l'application de bureau Codex (actifs bitmap générés par l'IA + injection CSS + CDP, sans modifier les fichiers de l'application). Il est utilisé lorsqu'un utilisateur souhaite créer un nouveau thème pour l'application Codex, modifier son habillage, transformer un concept d'image/capture d'écran/style IP en interface Codex, ou itérer sur un thème existant dans Codex‑Theme‑Studio. Les phrases de déclenchement incluent : thème Codex, skin Codex, changement de skin Codex, reconstruction de l'interface utilisateur de l'image conceptuelle, studio de thème, création d'un Codex de style aXX.
