SQL Smart Assistant – Ein natürliches Sprache-zu-SQL-Abfragetool, das wichtige Datenbanken (MySQL, PostgreSQL, SQL Server, MongoDB, Redis, SQLite) und LLM-Anbieter (OpenAI, Claude, Gemini) unterstützt. Hilft Benutzern, Datenbanken abzufragen, SQL-Anweisungen zu generieren und Ausführungspläne in natürlicher Sprache zu erklären.
