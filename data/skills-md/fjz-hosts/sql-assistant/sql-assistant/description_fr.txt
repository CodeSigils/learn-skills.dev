SQL Smart Assistant - Un outil de requête en langage naturel pour SQL prenant en charge les principales bases de données (MySQL, PostgreSQL, SQL Server, MongoDB, Redis, SQLite) et les fournisseurs LLM (OpenAI, Claude, Gemini). Aide les utilisateurs à interroger les bases de données, à générer des instructions SQL et à expliquer les plans d'exécution en langage naturel.
