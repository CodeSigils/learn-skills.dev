SQL Smart Assistant — инструмент запросов на естественном языке SQL, поддерживающий основные базы данных (MySQL, PostgreSQL, SQL Server, MongoDB, Redis, SQLite) и поставщиков LLM (OpenAI, Claude, Gemini). Помогает пользователям запрашивать базы данных, генерировать операторы SQL и объяснять планы выполнения на естественном языке.
