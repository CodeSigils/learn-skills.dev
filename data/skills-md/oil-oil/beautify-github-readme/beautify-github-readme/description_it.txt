Riprogetta le home page README di GitHub o crea decorazioni SVG autonome sicure per GitHub attorno al tema reale di un repository. Da utilizzare quando un utente chiede di abbellire, riprogettare, rinominare, aggiornare visivamente, semplificare o controllare un README GitHub; creare solo un eroe SVG, intestazioni di sezione, diagrammi, badge, moduli vetrina o altre risorse README; oppure trasforma la home page di un repository in una storia visiva coerente. Se la richiesta non distingue chiaramente il lavoro README completo dal lavoro SVG di sole risorse, chiedi quale ambito desidera l'utente prima di modificare qualsiasi cosa.
