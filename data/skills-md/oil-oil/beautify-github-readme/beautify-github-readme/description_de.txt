Gestalten Sie GitHub-README-Homepages neu oder erstellen Sie eigenständige GitHub-sichere SVG-Dekorationen rund um das eigentliche Thema eines Repositorys. Verwenden Sie diese Option, wenn ein Benutzer eine GitHub-README-Datei verschönern, neu gestalten, umbenennen, visuell aktualisieren, vereinfachen oder prüfen möchte. Erstellen Sie nur einen SVG-Helden, Abschnittsüberschriften, Diagramme, Abzeichen, Showcase-Module oder andere README-Assets. oder verwandeln Sie eine Repository-Homepage in eine zusammenhängende visuelle Geschichte. Wenn die Anfrage nicht klar zwischen der gesamten README-Arbeit und der reinen Asset-SVG-Arbeit unterscheidet, fragen Sie den Benutzer, welchen Umfang er haben möchte, bevor er etwas bearbeitet.
