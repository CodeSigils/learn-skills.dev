GitHub README ホームページを再設計するか、リポジトリの実際のテーマに基づいてスタンドアロンの GitHub セーフ SVG デコレーションを作成します。ユーザーが GitHub README の美化、再設計、ブランド変更、視覚的なアップグレード、簡素化、または監査を要求する場合に使用します。 SVG ヒーロー、セクション ヘッダー、図、バッジ、ショーケース モジュール、またはその他の README アセットのみを作成します。または、リポジトリのホームページを一貫した視覚的なストーリーに変えます。リクエストが README 全体の作業とアセットのみの SVG 作業を明確に区別していない場合は、何かを編集する前にユーザーがどの範囲を希望するかを尋ねます。
