قم بإجراء استشارة منظمة حول واجهة المستخدم/تجربة المستخدم من أجل (أ) المشاركة في تصميم نظام تصميم خاص بمشروع وإصدار "design-spec.md"، أو (ب) مراجعة واجهة مستخدم حالية مع إصلاحات ذات أولوية، أو (ج) إصدار قواعد "فعل/لا تفعل" مدمجة لسطح ما. يتم تشغيله عندما يريد المستخدم تحديد / بناء / تحسين نظام تصميم أو رموز تصميم مميزة، أو يطلب مواصفات تصميم، أو يطلب مراجعة كاملة لواجهة المستخدم لشاشة / نموذج بالحجم الطبيعي / العلاقات العامة، أو يريد قواعد تصميم لنوع السطح. لا تقم بطرح أسئلة ضيقة لمرة واحدة ("هل هذا اللون مناسب؟"، "هل يجب أن يكون هذا الزر أكبر؟") - أجب عن تلك الأسئلة مباشرةً دون استدعاء مسار الاستشارة.
