構造化された UI/UX コンサルティングを実行して、(a) プロジェクト固有のデザイン システムを共同設計して「design-spec.md」を発行する、(b) 優先順位を付けた修正を含む既存の UI をレビューする、または (c) サーフェスのコンパクトな「行うべき/禁止する」ルールを発行します。ユーザーがデザイン システムまたはデザイン トークンを定義/構築/洗練したい場合、デザイン仕様を要求する場合、画面/モックアップ/PR の完全な UI レビューを要求する場合、またはサーフェス タイプのデザイン ルールを必要とする場合にトリガーされます。限定的な 1 回限りの質問 (「この色は大丈夫ですか?」、「このボタンは大きくすべきですか?」など) をトリガーしないでください。コンサルテーション フローを呼び出さずに、これらの質問に直接答えてください。
