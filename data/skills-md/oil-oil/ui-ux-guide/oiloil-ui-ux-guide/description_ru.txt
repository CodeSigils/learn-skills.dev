Запустите структурированную консультацию по UI/UX, чтобы либо (а) совместно разработать систему проектирования для конкретного проекта и создать `design-spec.md`, (б) просмотреть существующий пользовательский интерфейс с приоритетными исправлениями, либо (в) составить компактные правила «что можно/нельзя» для поверхности. Срабатывает, когда пользователь хочет определить/создать/уточнить систему дизайна или токены дизайна, запрашивает спецификацию дизайна, запрашивает полную проверку пользовательского интерфейса экрана/макета/PR или хочет определить правила проектирования для типа поверхности. НЕ задавайте узкие одноразовые вопросы («подходит ли этот цвет?», «должна ли эта кнопка быть больше?») — отвечайте на них напрямую, не вызывая поток консультации.
