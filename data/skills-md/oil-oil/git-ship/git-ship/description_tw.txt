自動化的 Git 工作流程一鍵發布助理執行完整的「發布」流程：從最新的主分支→提交→推送→建立 PR→壓縮合併→返回主分支。

僅當使用者明確表達「運送」意圖時才應觸發它，例如：
- 直接說“ship”、“/ship”、“git Ship”
- 明確要求運行完整的 Git 流程：“幫我完成 Git 流程”、“拉取主幹、分支、打開 PR、合併”
- 使用「發佈這些變更」、「將這些變更轉換為 PR 並合併」等措辭

在以下情況下不應觸發它：
- 用戶只想提交
- 使用者只想建立一個 PR
- 使用者只想推送程式碼
- 討論 Git 相關問題或解釋 Git 概念

請始終使用使用者的語言進行回覆。
