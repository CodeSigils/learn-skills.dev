Автоматизированный помощник по выпуску рабочего процесса Git, запускаемый одним щелчком мыши и выполняющий полный процесс «отгрузки»: ответвление от последней основной версии → фиксация → отправка → создание PR → сжатие слияния → возвращение к основной.

Его следует активировать только тогда, когда пользователь явно выражает намерение «отправить», например:
- Прямо говоря «корабль», «/корабль», «корабль git»
- Явно просят запустить весь поток Git: «Помогите мне пройти процесс Git», «Вытащите главную, ветку, откройте PR, объедините».
- Использование формулировок типа «выпустить эти изменения», «превратить эти изменения в PR и объединить»

Его не следует запускать в таких случаях, как:
- Пользователь хочет только совершить
- Пользователь хочет только создать PR
- Пользователь хочет только отправить код
- Обсуждение вопросов, связанных с Git, или объяснение концепций Git.

Пожалуйста, всегда отвечайте на языке пользователя.
