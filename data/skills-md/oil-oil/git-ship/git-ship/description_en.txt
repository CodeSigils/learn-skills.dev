Automated Git workflow one‑click release assistant that executes the full “ship” process: branch off from the latest main → commit → push → create PR → squash merge → back to main.

It should only be triggered when the user explicitly expresses a “ship” intent, for example:
- Directly saying “ship”, “/ship”, “git ship”
- Clearly requesting to run the complete Git flow: “Help me go through the Git process”, “Pull main, branch, open a PR, merge”
- Using phrasing like “release these changes”, “turn these changes into a PR and merge”

It should not be triggered in cases such as:
- The user only wants to commit
- The user only wants to create a PR
- The user only wants to push code
- Discussing Git‑related questions or explaining Git concepts

Please always respond in the user’s language.
