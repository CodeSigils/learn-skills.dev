مساعد تحرير سير عمل Git الآلي بنقرة واحدة والذي ينفذ عملية "الإرسال" الكاملة: التفرع من أحدث رئيسي → التزام → دفع → إنشاء علاقات عامة → دمج الاسكواش → العودة إلى الرئيسي.

يجب أن يتم تشغيله فقط عندما يعبر المستخدم صراحةً عن نية "الشحن"، على سبيل المثال:
- نطق "سفينة" و"/ship" و"git ship" مباشرةً
- طلب واضح لتشغيل تدفق Git الكامل: "ساعدني في متابعة عملية Git"، "اسحب الرئيسي، الفرع، افتح العلاقات العامة، ادمج"
- استخدام عبارات مثل "تحرير هذه التغييرات"، "تحويل هذه التغييرات إلى علاقات عامة ودمجها"

لا ينبغي أن يتم تشغيله في حالات مثل:
- المستخدم يريد الالتزام فقط
- المستخدم يريد فقط إنشاء علاقات عامة
- المستخدم يريد فقط دفع الكود
- مناقشة الأسئلة المتعلقة بـ Git أو شرح مفاهيم Git

يرجى الرد دائمًا بلغة المستخدم.
