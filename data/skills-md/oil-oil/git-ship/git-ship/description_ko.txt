전체 "배송" 프로세스를 실행하는 자동화된 Git 워크플로 원클릭 릴리스 도우미: 최신 메인에서 분기 → 커밋 → 푸시 → PR 생성 → 스쿼시 병합 → 메인으로 돌아갑니다.

사용자가 명시적으로 "배송" 의도를 표현하는 경우에만 트리거되어야 합니다. 예를 들면 다음과 같습니다.
- 직접적으로 “ship”, “/ship”, “git ship”이라고 말합니다.
- 전체 Git 흐름 실행을 명확하게 요청: "Git 프로세스를 진행하도록 도와주세요", "메인 가져오기, 브랜치 가져오기, PR 열기, 병합"
- "이 변경 사항을 릴리스하세요", "이 변경 사항을 PR로 전환하고 병합"과 같은 표현을 사용합니다.

다음과 같은 경우에는 트리거되어서는 안 됩니다.
- 사용자는 커밋만 원합니다.
- 사용자는 PR만 만들고 싶어 합니다.
- 사용자는 코드만 푸시하고 싶어합니다.
- Git 관련 질문에 대해 토론하거나 Git 개념을 설명합니다.

항상 사용자의 언어로 응답하시기 바랍니다.
