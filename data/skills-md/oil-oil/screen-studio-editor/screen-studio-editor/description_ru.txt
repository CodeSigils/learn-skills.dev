Редактируйте записи Screen Studio и записывайте точные субтитры с ИИ-коррекцией в любое видео. Используйте этот навык в ЛЮБОЙ из этих ситуаций — даже если пользователь не упоминает Screen Studio по имени:
- У пользователя есть файл .screenstudio, и он хочет его очистить: удалить паузы, вырезать повторяющееся повествование,
  добавить субтитры. Триггер по: "帮我剪掉停顿", "删重复的内容", "处理这个录屏", "自动剪视频",
  «отредактировать мою запись», «вырезать паузы», упоминание пути .screenstudio.
- У пользователя есть файл .mp4, и он хочет, чтобы в него были записаны субтитры — из записи экрана, видео с iPhone,
  учебник, демонстрация или что-то еще. Запуск по: "帮这个视频加字幕", "给视频加字幕",
  «добавить субтитры», «записать субтитры», «加个字幕» или когда пользователь указывает путь .mp4 и
  упоминает титры/субтитры в любой форме.
- Пользователь хочет объединить два проекта .screenstudio (например, дополнительная перезапись, разделение сеансов).
  Запуск по: "合并工程", "合并两个录屏", "补录合并", "把两个 screenstudio 合并",
  «объединить проекты», «объединить записи», «вставить запись в другую».

Не ждите, пока пользователь скажет «Screen Studio» — запись субтитров работает для любого видео.
