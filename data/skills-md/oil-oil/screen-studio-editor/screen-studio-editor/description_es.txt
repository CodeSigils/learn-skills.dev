Edite grabaciones de Screen Studio y grabe subtítulos precisos corregidos por IA en cualquier video. Utilice esta habilidad para CUALQUIER de estas situaciones, incluso si el usuario no menciona Screen Studio por su nombre:
- El usuario tiene un archivo .screenstudio y quiere limpiarlo: eliminar pausas, cortar narraciones repetidas,
  añadir subtítulos. Activar: "帮我剪掉停顿", "删重复的内容", "处理这个录屏", "自动剪视频",
  "editar mi grabación", "cortar las pausas", menciona la ruta .screenstudio.
- El usuario tiene algún archivo .mp4 y quiere grabar subtítulos, desde una grabación de pantalla, video de iPhone,
  tutorial, demostración o cualquier otra cosa. Activar: "帮这个视频加字幕", "给视频加字幕",
  "agregar subtítulos", "grabar subtítulos", "加个字幕", o cuando el usuario proporciona una ruta .mp4 y
  menciona leyendas/subtítulos en cualquier forma.
- El usuario desea fusionar dos proyectos .screenstudio (por ejemplo, regrabaciones complementarias, sesiones divididas).
  Activar: "合并工程", "合并两个录屏", "补录合并", "把两个 screenstudio 合并",
  "fusionar proyectos", "combinar grabaciones", "insertar grabación en otra".

No espere a que el usuario diga "Screen Studio": la grabación de subtítulos funciona para cualquier vídeo.
