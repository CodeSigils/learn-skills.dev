Bearbeiten Sie Screen Studio-Aufnahmen und brennen Sie präzise KI-korrigierte Untertitel in jedes Video. Verwenden Sie diesen Skill in JEDER dieser Situationen – auch wenn der Benutzer Screen Studio nicht namentlich erwähnt:
- Der Benutzer hat eine .screenstudio-Datei und möchte diese bereinigen: Pausen entfernen, wiederholte Erzählungen ausschneiden,
  Untertitel hinzufügen. Auslöser bei: „帮我剪掉停顿“, „删重复的内容“, „处理这个录屏“, „自动剪视频“,
  „Meine Aufnahme bearbeiten“, „Pausen schneiden“, Erwähnungen des .screenstudio-Pfads.
- Der Benutzer hat eine MP4-Datei und möchte Untertitel einbrennen – von einer Bildschirmaufnahme, einem iPhone-Video usw.
  Tutorial, Demo oder irgendetwas anderes. Auslöser bei: „帮这个视频加字幕“, „给视频加字幕“,
  „Untertitel hinzufügen“, „Untertitel brennen“, „加个字幕“ oder wenn der Benutzer einen .mp4-Pfad angibt und
  erwähnt Bildunterschriften/Untertitel in irgendeiner Form.
- Benutzer möchte zwei .screenstudio-Projekte zusammenführen (z. B. zusätzliche Neuaufnahme, geteilte Sitzungen).
  Auslöser bei: „合并工程“, „合并两个录屏“, „补录合并“, „把两个 screenstudio 合并“,
  „Projekte zusammenführen“, „Aufnahmen kombinieren“, „Aufnahme in eine andere einfügen“.

Warten Sie nicht, bis der Benutzer „Screen Studio“ sagt – das Brennen von Untertiteln funktioniert für jedes Video.
