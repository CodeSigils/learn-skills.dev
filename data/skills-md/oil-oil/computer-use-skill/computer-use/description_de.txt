Steuern Sie einen Mac-Computer: Machen Sie Screenshots, um den Bildschirm anzuzeigen, bewegen Sie die Maus, klicken Sie, geben Sie Text ein, öffnen Sie Apps.
Wird ausgelöst, wenn der Benutzer sagt: „Helfen Sie mir, XX zu öffnen“, „Klicken Sie auf XX“, „Suche XX“, „Bedienen Sie meinen Computer“, „Helfen Sie mir, XX auf dem Bildschirm auszuführen“, „Machen Sie einen Screenshot und zeigen Sie es mir“ oder „Automatisieren Sie diesen Vorgang“. Auch wenn der Benutzer nicht „Computernutzung“ sagt, sollte diese Fähigkeit für jede Aufgabe ausgelöst werden, die die Steuerung von Bildschirm/Maus/Tastatur erfordert.
