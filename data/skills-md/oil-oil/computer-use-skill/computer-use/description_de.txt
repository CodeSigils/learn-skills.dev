Steuern Sie einen Mac-Computer: Machen Sie Screenshots, um den Bildschirm anzuzeigen, bewegen Sie die Maus, klicken Sie, geben Sie Text ein, öffnen Sie Apps.
Wird ausgelöst, wenn der Benutzer sagt: „Öffne XX für mich“, „Klicke auf XX“, „Suche XX“, „Bediene meinen Computer“, „Führe XX auf meinem Bildschirm für mich aus“, „Mache einen Screenshot und zeige es mir“ oder „Automatisiere diese Aktion“. Auch wenn der Benutzer nicht „Computernutzung“ sagt, lösen Sie diese Fähigkeit immer dann aus, wenn eine Aufgabe die Steuerung von Bildschirm/Maus/Tastatur erfordert.
