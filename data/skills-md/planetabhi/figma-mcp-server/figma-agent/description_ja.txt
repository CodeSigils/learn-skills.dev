ユーザーが Figma デザイン リンクを共有するか、Figma について言及し、デザインから UI を構築する場合、フレームをコードに変換する場合、デザイン トークンまたはテーマを抽出する場合、アイコンまたはイメージをエクスポートする場合、測定のためにノードを検査する場合、コンポーネントおよびトークン ライブラリをコードに同期する場合、コンポーネントまたはパターンのドキュメント仕様または使用ガイドラインを生成する場合、またはデザインをレビューしてフィードバックを Figma コメントとして残す場合は、これを使用してください。ユーザーが「Figma」という単語を言わなくても、figma.com リンクを貼り付けるか、デザイン フレーム、コンポーネント、変数、またはデザイン トークンを参照する限り、トリガーされます。
