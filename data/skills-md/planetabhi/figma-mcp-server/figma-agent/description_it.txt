Utilizzalo ogni volta che un utente condivide un collegamento di progettazione Figma o menziona Figma e desidera creare un'interfaccia utente da un progetto, trasformare un frame in codice, estrarre token di progettazione o un tema, esportare icone o immagini, ispezionare un nodo per misurazioni, sincronizzare un componente e libreria di token per codice, generare specifiche di documentazione o linee guida di utilizzo per un componente o modello o rivedere un progetto e lasciare feedback come commenti Figma. Attivalo anche quando l'utente non pronuncia la parola Figma, purché incolli un collegamento figma.com o faccia riferimento a un frame di progettazione, componente, variabili o token di progettazione.
