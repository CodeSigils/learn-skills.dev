استخدم هذا عندما يقوم المستخدم بمشاركة رابط تصميم Figma أو يذكر Figma ويريد إنشاء واجهة مستخدم من تصميم، أو تحويل إطار إلى كود، أو استخراج رموز التصميم المميزة أو السمة، أو تصدير الرموز أو الصور، أو فحص عقدة للقياسات، أو مزامنة مكون ومكتبة الرموز المميزة للتعليمات البرمجية، أو إنشاء مواصفات الوثائق أو إرشادات الاستخدام لمكون أو نمط، أو مراجعة التصميم وترك التعليقات كتعليقات Figma. قم بتشغيله حتى عندما لا يقول المستخدم كلمة Figma، طالما أنه يلصق رابطFigma.com أو يشير إلى إطار تصميم أو مكون أو متغيرات أو رموز تصميم مميزة.
