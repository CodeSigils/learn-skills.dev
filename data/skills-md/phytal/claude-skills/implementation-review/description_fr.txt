Examen approfondi des modifications de code pour en vérifier l'exactitude, l'optimalité et l'élégance à l'aide de sous-agents parallèles. Utilisez cette compétence chaque fois que l'utilisateur demande à examiner une implémentation, à auditer les modifications récentes, à examiner une différence ou un PR, à vérifier la qualité du code ou souhaite un deuxième avis sur les modifications apportées par lui-même ou par quelqu'un d'autre. Déclenchez également lorsque l'utilisateur dit des choses comme « examiner ceci », « à quoi cela ressemble », « vérifier mes modifications », « auditer ce code » ou « réviser l'implémentation » - même s'il ne spécifie pas explicitement les axes.
