Revisión exhaustiva de los cambios de código para determinar su corrección, optimización y elegancia utilizando subagentes paralelos. Utilice esta habilidad siempre que el usuario solicite revisar una implementación, auditar cambios recientes, revisar una diferencia o PR, verificar la calidad del código o quiera una segunda opinión sobre los cambios que él o alguien más realizó. También se activa cuando el usuario dice cosas como "revisar esto", "cómo se ve", "verificar mis cambios", "auditar este código" o "revisar la implementación", incluso si no especifican los ejes explícitamente.
