Gründliche Überprüfung von Codeänderungen auf Korrektheit, Optimalität und Eleganz mithilfe paralleler Subagenten. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer darum bittet, eine Implementierung zu überprüfen, aktuelle Änderungen zu prüfen, einen Unterschied oder eine PR zu überprüfen, die Codequalität zu überprüfen oder eine zweite Meinung zu den von ihm oder einer anderen Person vorgenommenen Änderungen einzuholen. Wird auch ausgelöst, wenn der Benutzer Dinge wie „Überprüfen Sie dies“, „Wie sieht das aus“, „Überprüfen Sie meine Änderungen“, „Überprüfen Sie diesen Code“ oder „Überprüfen Sie die Implementierung“ sagt – auch wenn er die Achsen nicht explizit angibt.
