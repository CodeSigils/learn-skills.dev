أنشئ ملخصًا منظمًا لعملية التنفيذ - المشكلة الأصلية، والحل، والدفاع عن سبب كونه النهج الصحيح عبر الصحة والمثالية والأناقة. استخدم هذه المهارة عندما يطلب المستخدم "تلخيص"، أو "تلخيص التنفيذ"، أو "كتابة التغييرات"، أو "شرح ما فعلناه ولماذا"، أو "توثيق النهج"، أو يريد توضيح الأساس المنطقي وراء مجموعة من التغييرات لوصف العلاقات العامة، أو مستند التصميم، أو تحديث الفريق، أو فهمه الخاص. يتم تشغيله أيضًا عندما يريد المستخدم شرح أو تبرير التنفيذ للآخرين.
