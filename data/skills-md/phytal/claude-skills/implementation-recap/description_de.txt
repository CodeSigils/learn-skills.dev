Erstellen Sie eine strukturierte Zusammenfassung einer Implementierung – das ursprüngliche Problem, die Lösung und eine Verteidigung, warum es sich um den richtigen Ansatz in Bezug auf Korrektheit, Optimalität und Eleganz handelt. Verwenden Sie diese Fähigkeit, wenn der Benutzer eine „Rekapitulation“, „eine Zusammenfassung der Implementierung“, „eine Niederschrift der Änderungen“, „erläutern, was wir getan haben und warum“, „den Ansatz dokumentieren“ möchte oder die Gründe für eine Reihe von Änderungen für eine PR-Beschreibung, ein Designdokument, ein Team-Update oder sein eigenes Verständnis darlegen möchte. Wird auch ausgelöst, wenn der Benutzer anderen eine Implementierung erklären oder rechtfertigen möchte.
