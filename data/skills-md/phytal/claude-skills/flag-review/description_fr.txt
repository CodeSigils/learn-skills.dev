Triez et agissez sur les indicateurs de révision de code générés par l’IA. Utilisez cette compétence chaque fois que l'utilisateur colle une liste d'indicateurs de révision, de résultats de révision de code, de résultats de réviseur IA ou de résultats d'analyse de code automatisée qui doivent être étudiés et résolus. Déclenchez également lorsque l'utilisateur demande de « examiner les indicateurs », de « trier les résultats », de « vérifier ces problèmes » ou de partager un lot de problèmes de code avec les chemins de fichiers et les descriptions, même s'il ne les appelle pas explicitement « indicateurs ».
