Analysieren Sie Feedback zum Code aus beliebigen Quellen – PR-Bewertungen von Teamkollegen, KI-generierte Flags, Ergebnisse von Implementierungsüberprüfungen oder eingefügte Kritik – und überprüfen Sie jeden Punkt auf Richtigkeit, Optimalität und Eleganz, bevor Sie darauf reagieren. Verwendet parallele Subagenten für eine gründliche Untersuchung. Wird bei Phrasen wie „habe dieses Feedback erhalten“, „Bewertung durch einen Teamkollegen“, „Kommentare überprüfen“, „PR-Feedback“, „diese Ergebnisse ansprechen“, „diese Bewertung bearbeiten“ oder wenn der Benutzer nummerierte/mit Aufzählungszeichen versehene Kritik einfügt, eine Ausgabe markiert oder strukturierte Bewertungsergebnisse einfügt, ausgelöst.
