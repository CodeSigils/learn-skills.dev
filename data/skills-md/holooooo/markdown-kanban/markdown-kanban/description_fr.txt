Créez, inspectez et mettez à jour des tableaux de tâches de projet qui utilisent le format d'en-tête et de propriété de tâche Markdown Kanban. À utiliser lorsqu'un projet suit le travail dans les fichiers TODO.md, *.todo.md ou *.kanban.md ; lors du déplacement de tâches entre les colonnes d'état ; lors de l'ajout de métadonnées de tâche ou d'étapes de liste de contrôle ; ou lorsqu'un référentiel peut contenir plusieurs tableaux de tâches Markdown indépendants.
