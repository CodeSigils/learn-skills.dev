Cree, inspeccione y actualice tableros de tareas pendientes del proyecto que utilicen el encabezado Markdown Kanban y el formato de propiedad de la tarea. Úselo cuando un proyecto realiza un seguimiento del trabajo en archivos TODO.md, *.todo.md o *.kanban.md; al mover tareas entre columnas de estado; al agregar metadatos de tareas o pasos de la lista de verificación; o cuando un repositorio puede contener múltiples tableros de tareas pendientes de Markdown independientes.
