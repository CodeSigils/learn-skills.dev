Crea, esamina e aggiorna le schede delle cose da fare del progetto che utilizzano l'intestazione Markdown Kanban e il formato delle proprietà delle attività. Da utilizzare quando un progetto tiene traccia del lavoro nei file TODO.md, *.todo.md o *.kanban.md; quando si spostano le attività tra le colonne di stato; quando si aggiungono metadati dell'attività o passaggi dell'elenco di controllo; o quando un repository può contenere più schede di cose da fare Markdown indipendenti.
