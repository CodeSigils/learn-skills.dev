قم بإنشاء وفحص وتحديث لوحات المهام الخاصة بالمشروع التي تستخدم عنوان Markdown Kanban وتنسيق خاصية المهمة. يتم استخدامه عند عمل مسارات المشروع في ملفات TODO.md، أو *.todo.md، أو *.kanban.md؛ عند نقل المهام بين أعمدة الحالة؛ عند إضافة بيانات تعريف المهمة أو خطوات قائمة المراجعة؛ أو عندما قد يحتوي المستودع على لوحات Markdown todo المستقلة المتعددة.
