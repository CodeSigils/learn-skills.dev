Erstellen, überprüfen und aktualisieren Sie Projekt-ToDo-Boards, die das Markdown-Kanban-Überschriften- und Aufgabeneigenschaftsformat verwenden. Verwenden Sie diese Option, wenn ein Projekt die Arbeit in TODO.md-, *.todo.md- oder *.kanban.md-Dateien verfolgt. beim Verschieben von Aufgaben zwischen Statusspalten; beim Hinzufügen von Aufgabenmetadaten oder Checklistenschritten; oder wenn ein Repository mehrere unabhängige Markdown-ToDo-Boards enthalten kann.
