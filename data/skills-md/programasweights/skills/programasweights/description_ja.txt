自然言語仕様を、ProgramAsWeights (PAW) を使用してローカルで実行される小さなニューラル関数にコンパイルします。正規表現では処理できないが、すべての項目について完全な LLM に送信するには遅すぎる、コストがかかる、または過剰なタスクであるあいまいなテキスト入力/テキスト出力タスクに使用します。テキストの分類、分類、ラベル付け、またはタグ付け (センチメント、緊急度、意図、トピック、スパム、サポート チケット、ALERT と QUIET のログ行)。乱雑なテキスト (電子メール、名前、日付、ID、請求書番号) からフィールドを抽出します。形式 (壊れた JSON、日付) を修復または正規化します。あいまいまたはタイプミスを許容するマッチング、ほぼ重複の検出、および重複排除。スペルミスの値を最も近いオプションにマッピングします。セマンティック検索。ログとエラーのトリアージ。そしてインテントルーティング。ホストされた API で一度コンパイルし、Python またはブラウザ/JavaScript SDK を介して関数をローカルおよびオフラインで実行します。項目ごとに大規模なモデルを呼び出すよりも安くて速いです。長い形式の生成、自由なチャット、コードの作成、または複数ステップの推論には向きません。
