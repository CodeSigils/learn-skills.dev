Compilez une spécification en langage naturel dans une petite fonction neuronale qui s'exécute localement avec ProgramAsWeights (PAW). Utilisez-le pour les tâches d'entrée/sortie de texte floues qu'une regex ne peut pas gérer mais qui sont trop lentes, coûteuses ou excessives pour être envoyées à un LLM complet sur chaque élément - classer, catégoriser, étiqueter ou baliser du texte (sentiment, urgence, intention, sujet, spam, tickets d'assistance, lignes de journal ALERTE vs SILENCIEUX) ; extraire les champs d'un texte désordonné (e-mails, noms, dates, identifiants, numéros de facture) ; réparer ou normaliser les formats (JSON cassé, dates) ; correspondance floue ou tolérante aux fautes de frappe, détection de quasi-doublons et déduplication ; mapper une valeur mal orthographiée à l’option la plus proche ; recherche sémantique ; tri des journaux et des erreurs ; et le routage d'intention. Compilez une fois sur l'API hébergée, puis exécutez la fonction localement et hors ligne via le SDK Python ou navigateur/JavaScript ; moins cher et plus rapide que d'appeler un grand modèle par article. Pas pour la génération de formulaires longs, le chat ouvert, l'écriture de code ou le raisonnement en plusieurs étapes.
