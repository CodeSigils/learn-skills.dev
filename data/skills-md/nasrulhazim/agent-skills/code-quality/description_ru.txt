Набор инструментов для обеспечения качества кода PHP и Laravel — статический анализ с помощью Larastan/PHPStan, соблюдение стиля кода с помощью Pint, автоматический рефакторинг с помощью Rector, базовое управление для устаревших баз кода и интеграция конвейера CI через GitHub Actions. Используйте этот навык всякий раз, когда пользователь просит проверить качество кода, исправить ошибки линтинга, запустить статический анализ, модернизировать PHP-код, настроить контрольные показатели качества CI, управлять базовыми показателями PHPStan, настроить предустановки Pint или применить правила Rector. Триггеры для таких запросов, как «выполнить проверку качества», «исправить мой стиль кода», «проанализировать с помощью larastan», «обновить базовый уровень phpstan», «модернизировать мой PHP-код», «настроить CI для качества», «проверить качество кода», «pint tak jalan», «nak fix phpstan error», «настроить ректор», «стиль кода betulkan», «tambah Quality Gate Dalam CI» или «базовый phpstan untuk устаревший код». В качестве базовой линии принимается Laravel Kickoff — PHPStan, Pint, Rector и GitHub Actions CI уже настроены. Этот навык расширяет и настраивает этот базовый уровень.
