PHP および Laravel コード品質ツールチェーン - Larastan/PHPStan による静的分析、Pint によるコード スタイルの強制、Rector による自動リファクタリング、レガシー コードベースのベースライン管理、GitHub Actions による CI パイプラインの統合。コード品質のチェック、lint エラーの修正、静的分析の実行、PHP コードの最新化、CI 品質ゲートの設定、PHPStan ベースラインの管理、Pint プリセットの構成、または Rector ルールの適用をユーザーが要求する場合は、このスキルを使用します。 「品質チェックを実行する」、「コード スタイルを修正する」、「larastan で分析する」、「phpstan ベースラインを更新する」、「PHP コードを最新化する」、「品質のために CI をセットアップする」、「コード品質をチェックする」、「pint tak jalan」、「nak fix phpstan エラー」、「レクタをセットアップする」、「betulkan コード スタイル」、「tambah 品質ゲート ダラム CI」などのリクエストのトリガー「ベースライン phpstan untuk レガシー コード」。 Laravel Kickoff をベースラインとして想定しています。PHPStan、Pint、Rector、および GitHub Actions CI はすでに構成されています。このスキルは、そのベースラインを拡張およびカスタマイズします。
