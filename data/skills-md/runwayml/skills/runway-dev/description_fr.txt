Base pour créer, modifier, déboguer ou vérifier les intégrations de Runway Dev Platform dans une application : connectez Dev MCP, utilisez llms.txt pour rechercher les ressources actuelles, résoudre le contexte du projet, utiliser les assistants d'attente du SDK et gérer les erreurs. Chargez avec des compétences pertinentes en matière de développement de piste et de surface. Pas pour les scripts de génération multimédia directe ou les raccourcis REST CLI.
