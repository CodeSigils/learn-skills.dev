تشخيص ومقارنة وتحسين تطبيقات Apache Spark واستعلامات SQL باستخدام بيانات Spark History Server. استخدم هذه المهارة عندما يريد المستخدم فهم سبب بطء تطبيق Spark، أو مقارنة تشغيلين معياريين أو نتائج TPC-DS، أو العثور على اختناقات الأداء (الانحراف، أو ضغط GC، أو الانسكاب العشوائي، أو المهام المتقطعة)، أو الحصول على توصيات الضبط، أو تحسين تكوينات Spark/Gluten. يتم التشغيل أيضًا عندما يذكر المستخدم "التشخيص"، أو "مقارنة عمليات التشغيل"، أو "لماذا يكون هذا الاستعلام بطيئًا"، أو "ضبط وظيفة Spark الخاصة بي"، أو "المقارنة المرجعية"، أو "تراجع الأداء"، أو يسأل عن انحراف المنفذ، أو التبديل العشوائي، أو فعالية AQE، أو مشكلات تفريغ الغلوتين.
