Diagnostica, confronta e ottimizza le applicazioni Apache Spark e le query SQL utilizzando i dati di Spark History Server. Utilizza questa competenza ogni volta che l'utente desidera capire perché un'app Spark è lenta, confrontare due esecuzioni di benchmark o risultati TPC-DS, trovare colli di bottiglia nelle prestazioni (disallineamento, pressione GC, fuoriuscita di shuffle, attività ritardata), ottenere consigli di ottimizzazione o ottimizzare le configurazioni Spark/Gluten. Si attiva anche quando l'utente menziona "diagnostica", "confronta esecuzioni", "perché questa query è lenta", "ottimizza il mio lavoro Spark", "confronto benchmark", "regressione delle prestazioni" o chiede informazioni sull'inclinazione dell'esecutore, sul sovraccarico di shuffle, sull'efficacia dell'AQE o sui problemi di scarico del glutine.
