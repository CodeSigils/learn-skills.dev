Eseguire una query su un server di cronologia Apache Spark in esecuzione dalla CLI di Copilot. Utilizzarlo ogni volta che l'utente desidera controllare applicazioni SHS, processi, fasi, esecutori, esecuzioni SQL, dettagli dell'ambiente o registri eventi, in particolare quando menzionano Spark History Server, SHS, cronologia del registro eventi, esecuzioni di benchmark o ID applicazione.
