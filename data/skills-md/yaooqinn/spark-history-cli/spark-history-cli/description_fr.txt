Interrogez un serveur d’historique Apache Spark en cours d’exécution à partir de Copilot CLI. Utilisez-le chaque fois que l'utilisateur souhaite inspecter les applications SHS, les tâches, les étapes, les exécuteurs, les exécutions SQL, les détails de l'environnement ou les journaux d'événements, en particulier lorsqu'ils mentionnent Spark History Server, SHS, l'historique des journaux d'événements, les exécutions de référence ou les ID d'application.
