الاستعلام عن خادم Apache Spark History Server قيد التشغيل من Copilot CLI. استخدم هذا عندما يريد المستخدم فحص تطبيقات SHS، أو المهام، أو المراحل، أو المنفذين، أو عمليات تنفيذ SQL، أو تفاصيل البيئة، أو سجلات الأحداث، خاصة عندما يذكرون Spark History Server، أو SHS، أو سجل سجل الأحداث، أو عمليات التشغيل المعيارية، أو معرفات التطبيق.
