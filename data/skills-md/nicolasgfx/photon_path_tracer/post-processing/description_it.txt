Pipeline di post-elaborazione GPU all'interno di photon_tracer: filtro lucciola (mediana+MAD), fioritura (gaussiana mip-chain), mappatura dei toni (ACES+gamma sRGB), denoiser OptiX. Da utilizzare quando: si correggono artefatti lucciola, si regolano le soglie di fioritura, si regola la mappatura dei toni, si esegue il debug della corruzione dell'output, si integra il denoiser OptiX o si ottimizzano le prestazioni post-FX.
