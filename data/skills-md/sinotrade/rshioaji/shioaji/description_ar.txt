خادم HTTP API مع تدفق SSE، ولوحة معلومات مع تضمين تطبيق مخصص، وSDK متعدد اللغات
التكامل (JavaScript/TypeScript، Go، C/C++، C#، Rust، Java/Kotlin).
يغطي: وضع/تعديل/إلغاء أوامر الأسهم/العقود الآجلة/الخيارات (شراء، بيع، حد، سوق، ROD، IOC، FOK،
الهامش، والبيع على المكشوف، والكميات الفردية، وأوامر التحرير والسرد)، والبث في الوقت الفعلي عبر عمليات رد اتصال Python أو HTTP SSE
(القراد، العرض، الاقتباس)، أشرطة الفيديو التاريخية/القراد/اللقطات، رصيد الحساب/الهامش/المراكز/الربح والخسارة،
قوائم المراقبة والماسحات الضوئية والأوامر الاحتياطية وأنظمة التداول الآلية على TWSE/TPEX/TAIFEX.
