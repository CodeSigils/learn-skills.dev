Utilizza questa abilità per interrogare i dati della blockchain di Solana tramite l'API Solscan Pro. Trigger: cerca l'indirizzo del portafoglio, controlla il prezzo del token, analizza la raccolta NFT, ispeziona la transazione, esplora le attività DeFi, ottieni metadati/etichette/tag dell'account, recupera informazioni sui blocchi, monitora l'utilizzo dell'API, cerca token per parola chiave.
