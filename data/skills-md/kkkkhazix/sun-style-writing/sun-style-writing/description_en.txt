Write in the “Sun Xue” style: an extremely restrained, plain‑description narrative with short‑sentence rhythm, numeric anchoring, objects bearing emotion, and silence as climax. It is suitable for first‑person nonfiction storytelling, long personal‑experience pieces, emotional stories, memoirs, factual essays, and character portraits. When a user requests “Sun Ge style,” “Sun Xue writing,” “cold narrative,” “plain‑description long text,” “restrained emotional expression,” “non‑sentimental story,” “iceberg method,” or “write like ‘My Girlfriend Jing Tian’,” this skill should be used. It also applies when the user wants a Chinese narrative long text that feels “not like AI,” “human‑like,” “sophisticated,” or “literary.” Core techniques include plain description, contrast, repetition, foreshadowing and echo, objects and imagery, montage, negative space, anti‑climax, shifts in address, and looping.
