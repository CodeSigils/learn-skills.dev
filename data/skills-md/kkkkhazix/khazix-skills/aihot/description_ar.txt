AI HOT (aihot.virxact.com) مهارة الاستعلام عن معلومات الذكاء الاصطناعي الصينية. عندما يريد المستخدم معرفة "ما يحدث في دائرة الذكاء الاصطناعي اليوم"، "التقرير اليومي للذكاء الاصطناعي"، "أخبار الذكاء الاصطناعي"، "أخبار الذكاء الاصطناعي"، "النقاط الساخنة للذكاء الاصطناعي"، "أحدث الذكاء الاصطناعي"، "ما أصدرته OpenAI/Anthropic/Google مؤخرًا"، "أخبار الذكاء الاصطناعي اليوم"، "التحقق من اتجاهات صناعة الذكاء الاصطناعي"، "ما هي إصدارات النماذج الكبيرة اليوم"، "دائرة الذكاء الاصطناعي بالأمس"، "راجع العناصر المحددة"، "اختيار الذكاء الاصطناعي الساخن"، "أبحاث الذكاء الاصطناعي من الأسبوع الماضي"، "إصدارات نماذج الذكاء الاصطناعي"، "منتج الذكاء الاصطناعي" الإصدارات، أو "تحديثات صناعة الذكاء الاصطناعي"، أو "نصائح ووجهات نظر الذكاء الاصطناعي"، أو أي استعلام صيني آخر عن معلومات الذكاء الاصطناعي، فيجب استخدام هذه المهارة. حتى لو قال المستخدم فقط "دائرة الذكاء الاصطناعي" أو "أخبار الذكاء الاصطناعي" أو "التقرير اليومي للذكاء الاصطناعي" أو ببساطة سأل "ماذا حدث اليوم" بينما يكون السياق هو الذكاء الاصطناعي / النماذج الكبيرة / ماجستير إدارة الأعمال / ريادة الأعمال، فيجب تفعيل المهارة. ستقوم المهارة مباشرة بتجعيد واجهة REST API العامة لجلب البيانات وتنسيقها في ملخص تخفيض الأسعار الصيني، ولا تتطلب أي مفتاح API أو تكوين خادم MCP من المستخدم. **لا تقم بالتحفيز**—إذا طلب المستخدم معلومات الذكاء الاصطناعي ولم تستدعِ هذه المهارة، فسوف تعتمد على بيانات التدريب القديمة كأخبار اليوم، وهو ما يضر المستخدم.
