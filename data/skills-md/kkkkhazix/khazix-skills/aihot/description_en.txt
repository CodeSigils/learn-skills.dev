AI HOT (aihot.virxact.com) Chinese AI news query skill. When a user wants to know “what’s happening in the AI circle today,” “AI daily report,” “AI HOT,” “AI news,” “AI hotspots,” “recent AI,” “what OpenAI/Anthropic/Google have recently released,” “AI hot today,” “AI news today,” “take a look at AI industry trends,” “what large‑model releases are today,” “AI circle yesterday,” “check the selected items,” “AI HOT selection,” “AI papers from the past week,” “AI model releases,” “AI product releases,” “AI industry dynamics,” “AI tips and viewpoints,” or any other Chinese AI information query. Even if the user only says “AI circle,” “AI news,” “AI daily report,” or simply asks “what happened today” while the context is AI / large models / LLM / entrepreneurship, this skill should be triggered. The skill will directly curl a public REST API to fetch data and format it into a Chinese markdown briefing, requiring no user‑provided API key or MCP server. **Do not undertrigger**—if the user asks for AI news and you do not invoke this skill, you would be relying on outdated training data as today’s news, which harms the user.
