La habilidad de Kazix para escribir artículos extensos en WeChat. Se activa cada vez que el usuario necesita redactar una publicación de WeChat, redactar un manuscrito, continuar/ampliar un artículo o generar un artículo extenso a partir del material fuente. Las frases desencadenantes incluyen, entre otras: "escribir un artículo", "redactar esto", "ayúdame a escribir", "continuar escribiendo", "ampliar esto", "artículo de WeChat", "formato largo", "producir un borrador", "escribir en mi estilo". Incluso si el usuario simplemente dice "convierte esto en un artículo" o "escríbelo en mi tono", actívalo siempre que el contexto implique la creación de contenido para WeChat. También se aplica cuando el usuario coloca un PDF, un resumen, un enlace de noticias, una conversión de voz a texto o cualquier material y dice "ayúdame a escribir un artículo". No lo use para contenido breve (pequeñas publicaciones del libro rojo, tweets, momentos) o generación pura de títulos/resúmenes (use la habilidad wechat-title para esos).
