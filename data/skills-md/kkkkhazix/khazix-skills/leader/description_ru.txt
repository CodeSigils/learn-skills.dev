Разбейте идею, состоящую из одного предложения, в краткое описание целевой задачи, которое ИИ-агент сможет выполнить самостоятельно. Используйте это, когда пользователь говорит: «Помогите мне написать цель для агента», «Подробно разложите эту цель», «Напишите краткое описание задачи для агента», «Напишите подсказку о цели», «Позвольте агенту запустить этот проект самостоятельно» или «Разделите работу между несколькими агентами для параллельной работы». Выполните расширенное тестирование базы кода и, при необходимости, проведите онлайн-исследование, а затем задайте до пяти вопросов за один раз, создав краткое описание задачи длиной не более 4000 символов, которое можно вставить непосредственно в / цель для запуска, включая эмпирически измеренные цифры, границы белого списка, проверку защиты от мошенничества и поддержку возобновления контрольных точек. Задачи типа выполнения и исследования (исследование/выбор/поиск решения) маршрутизируются автоматически.
