Teilen Sie eine Idee aus einem einzigen Satz in eine Zielaufgabe auf, die ein KI-Agent selbstständig erledigen kann. Verwenden Sie dies, wenn der Benutzer sagt: „Helfen Sie mir, ein Ziel für den Agenten zu schreiben“, „Bringen Sie dieses Ziel im Detail auf“, „Schreiben Sie eine Aufgabenbeschreibung für den Agenten“, „Schreiben Sie eine Zielaufforderung“, „Lassen Sie den Agenten dieses Projekt alleine ausführen“ oder „Teilen Sie die Arbeit auf mehrere Agenten auf, um sie parallel auszuführen.“ Führen Sie erweiterte Tests der Codebasis durch und führen Sie bei Bedarf Online-Recherchen durch. Stellen Sie dann bis zu fünf Fragen auf einmal und erstellen Sie eine Aufgabenbeschreibung mit nicht mehr als 4.000 Zeichen, die direkt in das Ziel eingefügt oder ausgeführt werden kann, einschließlich empirisch gemessener Zahlen, Whitelist-Grenzen, Anti-Cheating-Validierung und Checkpoint-Resume-Unterstützung. Aufgaben vom Typ „Ausführung“ und „Erkundung“ (Recherche/Auswahl/Lösungsfindung) werden automatisch weitergeleitet.
