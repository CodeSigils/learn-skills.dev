macOS / Windows read‑only storage analysis assistant (automatically detects the system). Scans the entire disk usage, identifies space hogs, classifies each item into 🟢 automatically cleanable / 🟡 requires manual judgment / 🔴 clean with caution three levels and provides actionable disposal plans, generates a beautifully formatted, collapsible, one‑click‑copy‑command interactive HTML report, and can launch a local service to delete items on the web page with one click (move to recycle bin / delete directly). The scan is read‑only throughout. Must be used in the following scenarios: when the user says “storage analysis”, “disk full”, “C drive / hard drive full”, “not enough space”, “clean space”, “clean disk”, “occupies space”, “what’s taking up space”, “help me look at storage”, “check the computer’s storage/space”, “storage space”, “computer space not enough”, “memory full/insufficient”, “check memory/storage” (in Chinese colloquial speech “memory” often refers to storage space), “storage analysis”, “disk cleanup”, “clear cache”, “disk cleaning”; or when the user complains the computer has no space, wants to know what’s eating the hard drive, wants cleaning suggestions. Note: if the user explicitly refers to runtime memory / RAM (e.g., “which process is using memory”, “high memory usage” wanting to see Activity Monitor), that is RAM, not storage, and is not covered by this skill.
