Помощник по анализу хранилища только для чтения для macOS/Windows (автоматически определяет систему). Сканирует весь объем использования диска, выявляет самые большие объемы памяти, классифицирует каждый элемент по трем уровням — 🟢 очищается автоматически, 🟡 требует ручного решения, 🔴 очищается с осторожностью — и предоставляет исполняемые планы утилизации. Создает красиво отформатированный, складной, интерактивный HTML-отчет с командами, которые можно скопировать одним щелчком мыши, а также запускает локальную службу для удаления элементов на веб-странице одним щелчком мыши (перемещение в корзину/удаление напрямую). Процесс сканирования полностью доступен только для чтения. Должен использоваться в следующих сценариях: когда пользователь говорит «анализ хранилища», «диск заполнен», «диск C/жесткий диск заполнен», «недостаточно места», «освободить место», «очистка диска», «свиньи», «что занимает место», «помогите мне проверить хранилище», «посмотрите на хранилище/пространство компьютера», «место для хранения», «на компьютере недостаточно места», «память заполнена/недостаточно», «проверьте память/хранилище» (в китайской разговорной речи) «память» часто относится к месту хранения), «анализ хранилища», «очистка диска», «очистка кэша», «очистка диска»; или когда пользователь жалуется, что на компьютере недостаточно места, хочет знать, что съедает жесткий диск, или хочет получить предложения по очистке. Примечание. Если пользователь явно ссылается на память/ОЗУ времени выполнения (например, «какой процесс использует память», «высокое использование памяти», желая увидеть Монитор активности), то это ОЗУ, а не хранилище, и этот навык не охватывается.
