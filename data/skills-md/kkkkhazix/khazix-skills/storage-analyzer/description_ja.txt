macOS / Windows 読み取り専用ストレージ分析アシスタント (システムを自動的に検出します)。ディスク使用量全体をスキャンし、スペースを消費しているものを特定し、各アイテムを 🟢 自動的にクリーニング可能 / 🟡 手動判断が必要 / 🔴 慎重にクリーニング の 3 つのレベルに分類し、実用的な廃棄計画を提供します。美しくフォーマットされた折りたたみ可能な、ワンクリック、コピー、コマンドによるインタラクティブな HTML レポートを生成し、Web ページ上のアイテムをワンクリックで削除するローカル サービスを起動できます (ごみ箱に移動/直接削除)。スキャンは全体的に読み取り専用です。次のシナリオで使用する必要があります: ユーザーが「ストレージ分析」、「ディスクがいっぱい」、「C ドライブ / ハードドライブがいっぱい」、「スペースが足りない」、「クリーンなスペース」、「クリーンなディスク」、「スペースを占有している」、「スペースを占有しているもの」、「ストレージを調べるのを手伝ってください」、「コンピュータのストレージ/スペースを確認してください」、「ストレージスペース」、「コンピュータのスペースが十分ではありません」、「メモリがいっぱい/不足しています」、「チェックしてください」と言った場合メモリ/ストレージ」（中国語の口語では、「メモリ」はストレージ領域を指すことがよくあります）、「ストレージ分析」、「ディスク クリーンアップ」、「キャッシュのクリア」、「ディスク クリーニング」。あるいは、ユーザーがコンピューターに空き容量がない、何がハードドライブを消費しているのか知りたい、クリーニングの提案が必要だと不満を言っているときも同様です。注: ユーザーがランタイム メモリ / RAM に明示的に言及する場合 (例: 「どのプロセスがメモリを使用しているか」、「メモリ使用率が高い」などアクティビティ モニターを確認したい場合)、それはストレージではなく RAM であり、このスキルの対象外です。
