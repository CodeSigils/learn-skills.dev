Análisis Horizontal-Vertical: una Habilidad de investigación en profundidad. Concebido por Digital Life Khazix, fusiona el análisis diacrónico-sincrónico de Saussure, el diseño de investigación transversal longitudinal de las ciencias sociales, las ideas centrales de los métodos de estudio de casos de las escuelas de negocios y el análisis de estrategias competitivas.  
Úselo cuando desee investigar sistemáticamente un producto, empresa, concepto, tecnología o persona. Su esencia es un análisis de doble eje: el eje vertical traza el ciclo de vida completo desde el nacimiento hasta el presente (contado como una historia narrativa); el eje horizontal realiza una comparación sistemática lado a lado con rivales o pares en el momento actual. Luego se cruzan los dos ejes para generar conocimientos únicos. El producto final es un informe de investigación en PDF bellamente diseñado.  
Las frases desencadenantes incluyen, entre otras: análisis horizontal-vertical, investiga esto por mí, ayúdame a analizar, investigación profunda, hacer un estudio, investigar, análisis competitivo, ayúdame a ver cómo es esto, cuál es la historia de este producto/empresa/concepto, ayúdame a resolverlo, ayúdame a comprender, haz una investigación profunda por mí.  
Incluso si el usuario simplemente dice "ayúdame a entender XX" o "cuál es el trasfondo de XX", activa la habilidad siempre que el contexto implique la necesidad de una investigación sistemática y profunda (en lugar de una simple definición). También se aplica cuando el usuario deja caer el nombre de un producto, el nombre de una empresa o un término técnico y dice "investiga esto por mí".  
No lo use para explicaciones de sustantivos simples (el usuario simplemente pregunta "¿qué es XX"), no lo use para escribir artículos en WeChat (use khazix-writer para eso), no lo use para generar títulos o resúmenes puros (use el título de wechat).
