وكيل مراقبة الأمن لخوادم Claude Skills وMCP. يقوم بمسح المهارات/MCPs المثبتة لمشروعك مقابل قواعد بيانات متعددة للثغرات الأمنية (GitHub Advisory DB، وactivatedmcp.info، وخلاصات CVE، وmcpscan.ai، وSnyk، وClawHub/VirusTotal)، وتنبيهات المجتمع (Reddit r/ClaudeAI، وDiscord)، وأنماط التهديد المعروفة. يحتفظ بقاعدة بيانات التهديدات المحلية التي تنمو بمرور الوقت. استخدم هذه المهارة عندما: يسأل المستخدم عن أمان مهاراته أو MCPs، أو يريد تدقيق المكونات الإضافية المثبتة، أو يذكر "الضعف"، أو "CVE"، أو "مهارة ضارة"، أو "الفحص الأمني"، أو "التهديد"، أو "التدقيق"، أو يقول "هل هذه المهارة آمنة؟"، أو يطلب التحقق من التبعيات، أو يريد مراقبة أمنية مستمرة. قم أيضًا بالتشغيل بشكل استباقي عندما يكون المستخدم على وشك تثبيت مهارة جديدة أو خادم MCP.
