Sicherheitsüberwachungsagent für Claude Skills- und MCP-Server. Scannt die installierten Skills/MCPs Ihres Projekts anhand mehrerer Schwachstellendatenbanken (GitHub Advisory DB, vulnermcp.info, CVE-Feeds, mcpscan.ai, Snyk, ClawHub/VirusTotal), Community-Warnungen (Reddit r/ClaudeAI, Discord) und bekannten Bedrohungsmustern. Verwaltet eine lokale Bedrohungsdatenbank, die mit der Zeit wächst. Verwenden Sie diesen Skill immer dann, wenn der Benutzer nach der Sicherheit seiner Skills oder MCPs fragt, installierte Plugins prüfen möchte, „Schwachstelle“, „CVE“, „böswilliger Skill“, „Sicherheitsscan“, „Bedrohung“ oder „Prüfung“ erwähnt, fragt „Ist dieser Skill sicher?“, Abhängigkeiten prüfen möchte oder eine fortlaufende Sicherheitsüberwachung wünscht. Wird auch proaktiv ausgelöst, wenn der Benutzer einen neuen Skill oder MCP-Server installieren möchte.
