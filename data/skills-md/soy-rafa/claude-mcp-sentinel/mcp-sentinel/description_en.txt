Security monitoring agent for Claude Skills and MCP servers. Scans your project's installed skills/MCPs against multiple vulnerability databases (GitHub Advisory DB, vulnerablemcp.info, CVE feeds, mcpscan.ai, Snyk, ClawHub/VirusTotal), community alerts (Reddit r/ClaudeAI, Discord), and known threat patterns. Maintains a local threat database that grows over time. Use this skill whenever: the user asks about security of their skills or MCPs, wants to audit installed plugins, mentions "vulnerability", "CVE", "malicious skill", "security scan", "threat", "audit", says "is this skill safe?", asks to check dependencies, or wants ongoing security monitoring. Also trigger proactively when the user is about to install a new skill or MCP server.
