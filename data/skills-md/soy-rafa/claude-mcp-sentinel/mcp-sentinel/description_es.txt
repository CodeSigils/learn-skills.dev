Agente de monitoreo de seguridad para servidores Claude Skills y MCP. Analiza las habilidades/MCP instalados de su proyecto en comparación con múltiples bases de datos de vulnerabilidades (GitHub Advisory DB, vulnerablemcp.info, feeds CVE, mcpscan.ai, Snyk, ClawHub/VirusTotal), alertas de la comunidad (Reddit r/ClaudeAI, Discord) y patrones de amenazas conocidos. Mantiene una base de datos de amenazas local que crece con el tiempo. Utilice esta habilidad siempre que: el usuario pregunte sobre la seguridad de sus habilidades o MCP, quiera auditar los complementos instalados, mencione "vulnerabilidad", "CVE", "habilidad maliciosa", "análisis de seguridad", "amenaza", "auditoría", diga "¿es segura esta habilidad?", solicite verificar las dependencias o desee un monitoreo de seguridad continuo. También se activa de forma proactiva cuando el usuario está a punto de instalar una nueva habilidad o servidor MCP.
