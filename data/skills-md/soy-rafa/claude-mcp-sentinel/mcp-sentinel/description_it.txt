Agente di monitoraggio della sicurezza per Claude Skills e server MCP. Esegue la scansione delle competenze/MCP installate nel tuo progetto rispetto a più database di vulnerabilità (GitHub Advisory DB, vulnerabilimcp.info, feed CVE, mcpscan.ai, Snyk, ClawHub/VirusTotal), avvisi della community (Reddit r/ClaudeAI, Discord) e modelli di minaccia noti. Mantiene un database locale delle minacce che cresce nel tempo. Utilizza questa competenza ogni volta che: l'utente chiede informazioni sulla sicurezza delle proprie competenze o MCP, desidera controllare i plug-in installati, menziona "vulnerabilità", "CVE", "competenza dannosa", "scansione di sicurezza", "minaccia", "controllo", dice "questa competenza è sicura?", chiede di controllare le dipendenze o desidera un monitoraggio continuo della sicurezza. Si attivano anche in modo proattivo quando l'utente sta per installare una nuova competenza o un server MCP.
