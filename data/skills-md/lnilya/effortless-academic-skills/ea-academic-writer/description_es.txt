Critique y mejore la redacción académica a nivel de párrafo o produzca nuevos párrafos académicos desde cero. Utilice esta habilidad siempre que el usuario pegue texto académico y desee comentarios, sugerencias de revisión o una reescritura; cuando piden "mejorar este párrafo", "criticar mi escritura", "hacerlo más académico", "ayúdame a escribir un párrafo sobre X", o pide prosa académica con un argumento específico. También se activa cuando el usuario proporciona un tema, afirmación o notas aproximadas y quiere que se conviertan en un párrafo académico pulido. Úselo siempre para tareas de escritura académica, incluso si la solicitud está redactada de manera informal.
