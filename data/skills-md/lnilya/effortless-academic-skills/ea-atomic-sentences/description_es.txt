Extrae oraciones atómicas de artículos académicos: identifique cada artículo citado, comprima cada cita en una sola afirmación lógica, agrúpelos por subtema y resuma cada grupo. Utilice esta habilidad siempre que el usuario pegue texto académico o cargue un PDF y quiera extraer lo que realmente afirman los artículos citados, mapear la literatura, crear un mapa de citas, extraer argumentos clave de un artículo, atomizar citas o preguntar cosas como "¿qué dice cada artículo?", "extraer las afirmaciones clave", "darme un desglose atómico de este artículo", "sacar todas las referencias y sus argumentos", "resumir las citas por tema" o "elaborar sobre [Año del autor]". También se activa cuando el usuario está preparando una revisión de la literatura, trabajando en Obsidian/Zotero/Notion y necesita bloques de citas estructurados, o carga un PDF con una solicitud para extraer afirmaciones a las que se hace referencia. Esta habilidad es esencial cada vez que alguien trabaja con un texto académico denso y necesita ver lo que realmente argumentan todas las fuentes citadas.
