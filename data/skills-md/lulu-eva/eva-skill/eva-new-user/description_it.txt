Eva New User 2.2.1 Tutorial per principianti indipendente. Utilizzato quando l'utente dice esplicitamente /eva-new-user, Eva New User, sono un nuovo utente, avvia il tutorial per principianti, insegnami come usare Eva o seleziona il tutorial per principianti dopo un semplice messaggio di benvenuto /eva. Prima di iniziare, analizza dinamicamente le sotto-abilità Eva installate nell'ambiente corrente, quindi completa un ciclo minimo di “dimostrazione, follow-along, iniziazione indipendente” attorno all'obiettivo attuale dell'utente; consente all'utente di dire "salta" in qualsiasi momento, specificare le funzionalità da apprendere in anticipo o uscire dal tutorial per gestire direttamente attività reali.
