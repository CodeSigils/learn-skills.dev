Eva New User 2.2.1 Независимое руководство для начинающих. Используется, когда пользователь явно говорит /eva-new-user, Eva New User, я новый пользователь, запускаю учебник для начинающих, научу меня использовать Eva или выбирает учебник для начинающих после простого приветственного сообщения /eva. Перед запуском он динамически сканирует поднавыки Евы, установленные в текущей среде, затем завершает минимальный цикл «демонстрации, последующего и независимого инициирования» вокруг текущей цели пользователя; он позволяет пользователю в любой момент сказать «пропустить», указать функции, которые необходимо изучить заранее, или выйти из учебного пособия, чтобы напрямую решать реальные задачи.
