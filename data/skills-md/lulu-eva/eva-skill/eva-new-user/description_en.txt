Eva New User 2.2.1 Independent Beginner Tutorial. Used when the user explicitly says /eva-new-user, Eva New User, I am a new user, start the beginner tutorial, teach me how to use Eva, or selects the beginner tutorial after a plain /eva welcome message. Before starting, it dynamically scans the Eva sub-skills installed in the current environment, then completes a minimal loop of “demonstration, follow-along, independent initiation” around the user's current goal; it allows the user to say “skip” at any time, specify features to learn in advance, or exit the tutorial to directly handle real tasks.
