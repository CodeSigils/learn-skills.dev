Eva New User 2.2.1 Tutorial independiente para principiantes. Se utiliza cuando el usuario dice explícitamente “/eva‑new‑user”, “Eva New User”, “Soy un nuevo usuario”, “comienza el tutorial para principiantes”, “enséñame a usar Eva” o selecciona el tutorial para principiantes después de un simple mensaje de bienvenida “/eva”. Antes de comenzar, escanea dinámicamente las subhabilidades de Eva instaladas en el entorno actual y luego completa un ciclo mínimo de “demostración, seguimiento e iniciación independiente” centrado en el objetivo actual del usuario; permite al usuario decir "saltar" en cualquier momento, especificar funciones para aprender de antemano o salir del tutorial para manejar tareas reales directamente.
