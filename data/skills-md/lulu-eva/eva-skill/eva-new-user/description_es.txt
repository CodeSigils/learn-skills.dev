Eva New User 2.2.1 Tutorial independiente para principiantes. Se utiliza cuando el usuario dice explícitamente /eva-nuevo-usuario, Eva nuevo usuario, soy un nuevo usuario, inicia el tutorial para principiantes, enséñame cómo usar Eva o selecciona el tutorial para principiantes después de un simple mensaje de bienvenida /eva. Antes de comenzar, escanea dinámicamente las subhabilidades de Eva instaladas en el entorno actual, luego completa un ciclo mínimo de “demostración, seguimiento e iniciación independiente” en torno al objetivo actual del usuario; permite al usuario decir "omitir" en cualquier momento, especificar funciones para aprender de antemano o salir del tutorial para manejar directamente tareas reales.
