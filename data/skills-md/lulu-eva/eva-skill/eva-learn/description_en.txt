Eva Learn 2.2.2 Independent Learning Project Entry. Use it when the user explicitly says “/eva‑learn”, “eva‑learn”, “Eva Learn”, or uses natural language to request “take me to learn and understand / take me to systematic learning / take me to read / thematic reading / continue the last learning”. All Learn tasks must first create or restore a traceable record, then begin instruction in the same session; ordinary explanations, creative work, revisions, titles, commercial drafts, or converting material into short videos/articles are not handled.  

Trigger phrases: “/eva‑learn”, “eva‑learn”, “Eva Learn”, “enter Eva Learn mode”, “take me to learn and understand”, “take me to systematic learning”, “take me to read”, “do question‑based learning”, “do thematic reading”, “continue Eva Learn learning project”, “continue the last learning project”, “continue the previous guided reading”.
