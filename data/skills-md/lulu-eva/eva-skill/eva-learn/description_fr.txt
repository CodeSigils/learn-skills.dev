Eva Learn 2.2.2 Entrée dans un projet d'apprentissage indépendant. Utilisé lorsque l'utilisateur dit explicitement /eva-learn, eva-learn, Eva Learn ou utilise le langage naturel pour demander explicitement « amène-moi à comprendre / amène-moi à un apprentissage systématique / amène-moi à lire / lecture thématique / continuer l'apprentissage précédent. » Toutes les tâches d'apprentissage doivent d'abord créer ou restaurer un enregistrement traçable, puis commencer l'instruction au cours de la même session ; les explications ordinaires, les créations, les révisions, les titres, les brouillons de commandes commerciales ou la conversion de matériel en courtes vidéos/articles ne sont pas traités.  
Méthodes de déclenchement : /eva-learn, eva-learn, Eva Learn, passer en mode Eva Learn, m'amener à comprendre, m'amener à l'apprentissage systématique, m'emmener lire, faire un apprentissage basé sur l'investigation, faire une lecture thématique, continuer le projet d'apprentissage Eva Learn, continuer le projet d'apprentissage précédent, continuer la dernière lecture guidée.
