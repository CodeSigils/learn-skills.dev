Eva Learn 2.2.2 Entrée dans un projet d'apprentissage indépendant. Utilisez-le lorsque l'utilisateur dit explicitement « /eva-learn », « eva-learn », « EvaLearn » ou utilise le langage naturel pour demander « emmène-moi apprendre et comprendre / emmène-moi à l'apprentissage systématique / emmène-moi lire / lecture thématique / continuer le dernier apprentissage ». Toutes les tâches d'apprentissage doivent d'abord créer ou restaurer un enregistrement traçable, puis commencer l'instruction au cours de la même session ; les explications ordinaires, les travaux créatifs, les révisions, les titres, les brouillons commerciaux ou la conversion de matériel en courtes vidéos/articles ne sont pas traités.  

Phrases déclencheurs : « /eva-learn », « eva-learn », « EvaLearn », « entrer en mode EvaLearn », « m’emmener apprendre et comprendre », « m’emmener à l’apprentissage systématique », « m’emmener lire », « faire un apprentissage par questions », « faire une lecture thématique », « continuer le projet d’apprentissage EvaLearn », « continuer le dernier projet d’apprentissage », « continuer la lecture guidée précédente ».
