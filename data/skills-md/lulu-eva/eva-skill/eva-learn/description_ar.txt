Eva Learn 2.2.2 إدخال مشروع التعلم المستقل. يتم استخدامه عندما يقول المستخدم صراحة /eva‑learn، eva‑learn، Eva Learn، أو يستخدم لغة طبيعية ليطلب صراحة "خذني لأفهم / خذني إلى التعلم المنهجي / خذني للقراءة / القراءة الموضوعية / مواصلة التعلم الأخير." يجب أن تقوم جميع مهام Learn أولاً بإنشاء سجل يمكن تتبعه أو استعادته قبل بدء التعليمات في نفس الجلسة؛ ولا يتعامل مع التفسيرات العادية أو الإبداعات أو المراجعات أو العناوين أو المسودات التجارية أو تحويل المواد إلى مقاطع فيديو/مقالات قصيرة. طرق التحفيز: /eva‑learn، eva‑learn، Eva Learn، أدخل وضع Eva Learn، خذني لأفهم، خذني إلى التعلم المنهجي، خذني للقراءة، القيام بالتعلم القائم على الأسئلة، القيام بالقراءة الموضوعية، مواصلة مشروع Eva Learn التعليمي، مواصلة مشروع التعلم الأخير، مواصلة القراءة الموجهة السابقة.
