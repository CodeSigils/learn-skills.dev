Eva Review 2.2.1. Точка входа для полноплатформенного обзора после выпуска. Он используется для проверки уже опубликованного фрагмента контента (короткого видео, статьи Xiaohongshu, общедоступной учетной записи WeChat и т. д.) путем чтения внутренних снимков экрана, Excel, CSV, таблиц Markdown или нескольких исторических записей, принятия решения о том, какой приоритет при тестировании следующего фрагмента, и после первой авторизации пользователя для постоянного поддержания хранилища записей проверки учетной записи для текущего проекта. Триггеры: /eva-review, Eva Review, просмотрите уже опубликованный контент, посмотрите, где этот пост может застрять после публикации, заполните предыдущий результат, повторно посетите недавний контент, обобщите последние шаблоны контента, что я говорю, чтобы работать лучше. Предварительная проверка публикации, непосредственная разработка нового контента и платформ без метафизических проблем цели публикации не входят в этот навык.
