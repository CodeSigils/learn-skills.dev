Eva Brief, unabhängiger kommerzieller Einstiegspunkt für die Demontage von Briefen. Es wird nur verwendet, wenn der Benutzer ausdrücklich ein Marken-Briefing aufschlüsseln möchte, Anforderungen an die Markenkooperation aufschlüsseln, eine Karte mit Einschränkungen für ein kommerzielles Briefing erstellen, einen vorhandenen kommerziellen Entwurf mit dem Briefing vergleichen oder die Struktur von Benchmark-Beispielen für das gleiche Produkt migrieren möchte. Es erstellt lediglich eine Kurzanalyse, einen Verkaufsargumenten-Pool, eine Karte mit Einschränkungen für Werbebriefe oder Übergaben für Überarbeitungen und schreibt nicht direkt einen vollständigen Werbeentwurf, Titel, Eröffnungstext oder Fließtext; Gewöhnliche Anfragen wie „Wie schreibe ich ein kommerzielles Briefing / wie präsentiere ich Verkaufsargumente für Produkte / hilf mir bei der Erstellung kommerzieller Inhalte“ sollten an den Haupt-Erstellungsworkflow von Eva zurückgeleitet werden.  
Triggerphrasen: /eva-brief, eva-brief, kommerzielles Briefing, Markenbrief, Anforderungen an die Markenkooperation, helfen Sie mir, das Briefing aufzuschlüsseln, Karte mit kommerziellen Einschränkungen aufschlüsseln, Briefing gegenprüfen, kann dieser kommerzielle Entwurf eingereicht werden, kommerzieller Entwurf prüfen, kommerzielles Muster des gleichen Produkts, Markenreferenzbeispiel.
