Eva Link est un point d'intégration de workflow local indépendant. Il gère les appels de liens existants, intègre les invites/SOP/méthodologie privée dans Eva, autorise les liens personnalisés et vérifie les liens. Déclencheurs : /eva-link, /eva-link-builder, /eva-link-diy, /eva-link-doctor, compétence Eva personnalisée, créez votre propre lien, intégrez des invites dans Eva, vérifiez le lien local, utilisez l'un de mes liens.
