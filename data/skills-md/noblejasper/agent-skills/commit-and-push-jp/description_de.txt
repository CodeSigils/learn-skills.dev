End-to-End-Workflow – Änderungen überprüfen, ein japanisches Commit per Commit-JP erstellen, pnpm lint && pnpm test ausführen und dann per Push zum Ursprung pushen. Verwenden Sie diese Option, wenn der Benutzer einen Commit und eine Veröffentlichung auf einmal durchführen möchte. Öffnet oder aktualisiert keine PRs – verwenden Sie dazu create-pr-jp.
