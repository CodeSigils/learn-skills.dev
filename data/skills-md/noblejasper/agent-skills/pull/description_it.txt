Unisci l'ultimo ramo predefinito (ad esempio origin/main) nel ramo corrente, risolvi i conflitti di unione e verifica con pnpm lint && pnpm test. Sincronizzazione basata sull'unione (non rebase) a meno che il repository non specifichi diversamente. Da utilizzare quando si sincronizza un ramo di una funzione con l'origine, dopo un push non veloce o quando il ramo è indietro. Non spinge né gestisce i PR: usa push e create-pr-jp per quelli.
