Fusionnez la dernière branche par défaut (par exemple origin/main) dans la branche actuelle, résolvez les conflits de fusion et vérifiez avec pnpm lint && pnpm test. Synchronisation basée sur la fusion (pas de rebase), sauf indication contraire dans le dépôt. À utiliser lors de la synchronisation d'une branche de fonctionnalité avec l'origine, après une poussée sans avance rapide ou lorsque la branche est en retard. Ne pousse ni ne gère les PR : utilisez push et create-pr-jp pour ceux-ci.
