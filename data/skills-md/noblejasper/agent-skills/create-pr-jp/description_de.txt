Erstellen oder aktualisieren Sie eine GitHub-Pull-Anfrage mit einem japanischen Titel und Text, indem Sie .github/pull_request_template.md oder docs/pull_request_template.md verwenden, sofern vorhanden. Verwenden Sie diese Option, wenn der Benutzer eine PR öffnen, eine Pull-Anfrage erstellen oder PR-Metadaten aktualisieren möchte. Erfordert einen Push-Zweig – verwenden Sie zuerst Push (und Pull, falls erforderlich). Verwenden Sie commit-jp für Commits.
