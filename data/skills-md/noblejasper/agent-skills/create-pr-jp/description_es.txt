Cree o actualice una solicitud de extracción de GitHub con un título y cuerpo en japonés, usando .github/pull_request_template.md o docs/pull_request_template.md cuando esté presente. Úselo cuando el usuario solicite abrir un PR, crear una solicitud de extracción o actualizar los metadatos del PR. Requiere una rama empujada: use empujar (y tirar si es necesario) primero; utilice commit-jp para confirmaciones.
