Créez ou mettez à jour une pull request GitHub avec un titre et un corps japonais, en utilisant .github/pull_request_template.md ou docs/pull_request_template.md lorsqu'il est présent. À utiliser lorsque l'utilisateur demande à ouvrir un PR, à créer une demande d'extraction ou à actualiser les métadonnées du PR. Nécessite une branche poussée : utilisez d'abord pousser (et tirer si nécessaire) ; utilisez commit-jp pour les commits.
