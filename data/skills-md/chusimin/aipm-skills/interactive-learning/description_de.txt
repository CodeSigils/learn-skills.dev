Adaptive Eins-zu-eins-Lernmaschine basierend auf der 2-Sigma-Theorie von Bloom. Es sollte sofort ausgelöst werden, wenn ein Benutzer sagt: „Ich möchte X lernen“, „Ich möchte X verstehen“, „Erkläre mir X“, „Hilf mir, X zu verstehen“, „Was ist X“, „Bringe mir X bei“ oder „Lerne X.“ Dies gilt auch für Ausdrücke wie „Ich verstehe dieses Konzept nicht ganz“, „Können Sie mir helfen, X herauszufinden?“ oder „Ich interessiere mich wirklich für X und möchte es eingehend erforschen.“ Selbst wenn der Benutzer einfach „Sprechen Sie über X“ oder „Erzählen Sie mir etwas über Hinweis: Wenn der Benutzer nur eine einfache sachliche Frage stellt (z. B. „Wie sortiert man eine Liste in Python?“), sollte dieser Skill nicht ausgelöst werden; antworte einfach direkt. Diese Fertigkeit wurde speziell für Szenarien entwickelt, die ein tiefes Verständnis und systematisches Lernen erfordern.
