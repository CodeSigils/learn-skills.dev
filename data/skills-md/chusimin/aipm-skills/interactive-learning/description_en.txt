One-on-one adaptive learning engine based on the Bloom 2 Sigma theory. It should be triggered immediately when the user mentions phrases such as “I want to learn X,” “I want to understand X,” “Explain X to me,” “Help me understand X,” “What is X,” “Teach me X,” “Study X.” It also applies to expressions like “I don’t quite understand this concept,” “Can you help me figure out X?” “I’m very interested in X and want to dive deeper,” etc. Even if the user only says “Talk about X” or “Talk about X,” as long as the intent is to learn and comprehend a knowledge domain, this skill should be activated. Note: If the user is only asking a simple factual question (e.g., “How to sort a list in Python”), this skill does not need to be triggered; just answer directly. This skill is specifically designed for scenarios that require deep understanding and systematic learning.
