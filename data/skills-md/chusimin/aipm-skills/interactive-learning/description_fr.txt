Un moteur d’apprentissage adaptatif individuel basé sur la théorie 2 Sigma de Bloom. Il doit être déclenché immédiatement lorsqu'un utilisateur dit « Je veux apprendre X », « Je veux comprendre X », « Expliquez-moi X », « Aide-moi à comprendre X », « Qu'est-ce que X », « Apprends-moi X » ou « Étudier X ». Cela s'applique également à des expressions telles que « Je ne comprends pas très bien ce concept », « Pouvez-vous m'aider à comprendre X ? » ou "Je suis très intéressé par X et je veux approfondir." Même si l'utilisateur dit simplement « Parlez de X » ou « Parlez-moi de X », tant que l'intention est d'apprendre et de comprendre un domaine de connaissances, cette compétence doit être activée. Remarque : Si l'utilisateur pose uniquement une question factuelle simple (par exemple : « Comment trier une liste en Python ? »), cette compétence ne doit pas être déclenchée ; répondez simplement directement. Cette compétence est conçue spécifiquement pour les scénarios qui nécessitent une compréhension approfondie et un apprentissage systématique.
