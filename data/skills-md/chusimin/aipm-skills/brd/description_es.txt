Generador guiado de documentos de requisitos comerciales (BRD): le ayuda a determinar si vale la pena seguir una dirección antes de invertir tiempo. Debe activarse inmediatamente cuando el usuario mencione "escribir un BRD", "documento de requisitos comerciales", "vale la pena seguir esta dirección", "ayúdame a decidir si hacerlo", "evaluar esta dirección", "análisis de viabilidad". También se aplica a expresiones como "Tengo una idea que quiero evaluar", "ayúdame a ver si esto se puede hacer", "es confiable esta dirección", "deberíamos hacer esto", etc. Incluso si el usuario solo dice "Quiero hacerXX, ¿crees que es factible?", siempre que la intención sea evaluar la viabilidad comercial de una dirección de producto/negocio, esta habilidad debe activarse.
