أدلة التطوير باستخدام Skip: تطبيقات ومكتبات iOS/Android ثنائية النظام الأساسي باستخدام Swift وSwiftUI. يُستخدم عند العمل على تخطي المشاريع، أو إصدارات Swift-to-Android، أو تخطي CLI، أو Skip Fuse/Lite، أو SwiftUI-to-Compose، أو توجيهات المترجم (#if os(Android)، #if SKIP)، أو عندما يذكر المستخدم Skip أو Skip.dev أو تخطي create/verify/build.
