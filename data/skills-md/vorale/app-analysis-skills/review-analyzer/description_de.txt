Führen Sie eine intelligente Batch-Analyse von Benutzerbewertungs-/Feedback-Daten durch: Spracherkennung, Übersetzung, Qualitätsbewertung, Themenkategorisierung (vordefiniert + automatische Erkennung), Stimmungsanalyse, Erkennung blockierender Probleme, benutzerdefiniertes Tagging und generieren Sie strukturierte JSON-Ergebnisse und zusammenfassende Berichte. Verwenden Sie diese Fähigkeit, wenn Benutzer Bewertungen analysieren, Benutzerfeedback verstehen, eine öffentliche Meinungsanalyse durchführen oder Spielerprobleme erkennen müssen. Dieser Skill sollte auch dann ausgelöst werden, wenn der Benutzer einfach sagt: „Hilf mir zu sehen, was diese Bewertungen sagen.“

Bitte antworten Sie immer in der Sprache des Benutzers.
