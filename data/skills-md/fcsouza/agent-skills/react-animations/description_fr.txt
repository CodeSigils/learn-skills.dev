Invoquez cette compétence chaque fois que quelqu'un pose des questions sur l'animation, la transition, le mouvement, le mouvement du cadre, le ressort de réaction, le GSAP, les effets d'entrée/sortie, l'animation de défilement, la parallaxe, le geste, le glissement, le retournement de carte, le tremblement de l'écran, la barre de santé, les nombres de dégâts, les états de chargement, les transitions de page, les effets de survol ou tout élément qui doit se déplacer, s'estomper, évoluer ou répondre à une interaction - même s'il n'utilise pas le mot « animation ».
