يُستخدم عند تنفيذ الرسوم المتحركة أو الانتقالات أو تأثيرات الحركة في تطبيقات React. قم باستدعاء هذه المهارة عندما يسأل شخص ما عن الرسوم المتحركة، أو الانتقال، أو الحركة، أو حركة الإطار، أو رد الفعل الربيعي، أو GSAP، أو تأثيرات الدخول/الخروج، أو تحريك التمرير، أو اختلاف المنظر، أو الإيماءة، أو السحب، أو قلب البطاقة، أو اهتزاز الشاشة، أو شريط الصحة، أو أرقام الضرر، أو حالات التحميل، أو انتقالات الصفحة، أو تأثيرات التمرير، أو أي عنصر يجب أن يتحرك أو يتلاشى أو يتسع أو يستجيب للتفاعل - حتى لو لم يستخدم كلمة "رسوم متحركة".
