Erstellen, aktualisieren, bereitstellen oder forken Sie das persönliche Zframes-Markt-Dashboard des Benutzers. Wird verwendet, wenn der Benutzer „/zframes“, „Erstelle mir ein Dashboard“, „Mein Terminal einrichten“, „Mich zu einem Marktterminal erstellen“, „X zu meinem Dashboard hinzufügen“, „Mein Dashboard starten/öffnen/bereitstellen“, „Dieses Dashboard <URL> forken“, „Diesen freigegebenen Zframes-Link ausführen“ sagt oder ein personalisiertes Live-Markt-Dashboard (Krypto + Aktien) wünscht. Wenn sie einen Zframes-Explorer-Link (eine .../dashboard/<id>-URL) angeben, teilen Sie ihn auf ihren Computer. Wenn ein Dashboard bereits vorhanden ist und der Benutzer es nur starten möchte, stellen Sie es bereit – erstellen Sie es nicht von Grund auf neu. Schreibt ein validiertes Dashboard.json und stellt es live mit der CLI bereit – der Agent schreibt nie React.
