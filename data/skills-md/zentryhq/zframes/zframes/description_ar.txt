إنشاء لوحة معلومات سوق إطارات zframes الشخصية للمستخدم أو تحديثها أو تقديمها أو تفرعها. يُستخدم عندما يقول المستخدم "/zframes"، أو "أنشئ لي لوحة معلومات"، أو "قم بإعداد المحطة الطرفية الخاصة بي"، أو "اجعلني محطة سوق"، أو "أضف X إلى لوحة المعلومات الخاصة بي"، أو "بدء/فتح/خدمة لوحة المعلومات الخاصة بي"، أو "تفرع لوحة المعلومات هذه <url>"، أو "تشغيل رابط zframes المشترك هذا"، أو يريد لوحة معلومات مخصصة للسوق المباشر (التشفير + الأسهم). إذا أعطوا رابط مستكشف zframes (عنوان URL .../dashboard/<id>)، فقم بتشعبه على أجهزتهم. إذا كانت لوحة المعلومات موجودة بالفعل وكان المستخدم يريد فقط تشغيلها، فقم بخدمتها — فلا تقم بإعادة البناء من الصفر. يكتب لوحة القيادة.json تم التحقق من صحتها ويقدمها مباشرة مع واجهة سطر الأوامر (CLI) - لا يكتب الوكيل React أبدًا.
