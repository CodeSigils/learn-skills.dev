Una habilidad dedicada a la integración de pagos de Antom, que ayuda a los comerciantes a seleccionar el producto y el enfoque de integración adecuados según las necesidades comerciales y a crear código de nivel de producción. Productos admitidos: Pagos únicos, Pago tokenizado (débito automático recurrente), Pago de suscripción, Escanear a enlace. Modos de integración admitidos: elemento de pago, página de pago (completamente alojada/integrada), integración solo API (APM/tarjeta bancaria).
