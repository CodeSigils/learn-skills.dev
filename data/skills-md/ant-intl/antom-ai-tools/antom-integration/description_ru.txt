Навык, посвященный интеграции платежей Antom, помогающий продавцам выбирать правильный продукт и подход к интеграции в соответствии с потребностями бизнеса, а также создавать код производственного уровня. Поддерживаемые продукты: единовременные платежи, токенизированный платеж (периодический автоматический дебет), оплата подписки, сканирование для ссылки. Поддерживаемые режимы интеграции: платежный элемент, страница оформления заказа (полностью размещенная/встроенная), интеграция только через API (APM/банковская карта).
