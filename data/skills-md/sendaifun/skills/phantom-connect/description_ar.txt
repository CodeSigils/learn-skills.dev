أنشئ تطبيقات متصلة بالمحفظة باستخدام Phantom Connect SDK لـ Solana. يُستخدم عند دمج محافظ Phantom في تطبيقات React أو React Native أو Vanilla JS/TS - بما في ذلك اتصال المحفظة، وتسجيل الدخول الاجتماعي (Google/Apple)، وتوقيع المعاملات، وتوقيع الرسائل، والوصول عبر بوابة الرمز المميز، ومدفوعات التشفير، وسك العملة NFT. يغطي @phantom/react-sdk، و@phantom/react-native-sdk، و@phantom/browser-sdk.
