أنشئ عمليات تكامل مع واجهة برمجة تطبيقات Factorial HR باستخدام أدوات تطوير البرامج (SDK) الرسمية لـ TypeScript (@factorialco/api-client) وPython (factorial-api-client). يُستخدم عند المصادقة، أو استدعاء نقاط النهاية، أو ترقيم صفحات النتائج، أو الاشتراك في خطافات الويب، أو كتابة حمولات معالج خطاف الويب مقابل واجهة برمجة تطبيقات العامل.
