Итеративный, основанный на подтверждении рабочий процесс для сквозного создания процессов и модулей Factorial Code — планирование и подтверждение, сценарии обнаружения, поэтапная реализация, проверенная с помощью инструмента MCP run_code, представление процессов как инструментов MCP, а также методы обеспечения безопасности и обработки ошибок. Используйте, когда вас просят построить, автоматизировать или интегрировать что-то на факториальном коде (fcode), и вам нужен рекомендуемый метод работы.
