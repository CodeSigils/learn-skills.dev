Flusso di lavoro iterativo e basato sulla conferma per la creazione di processi e moduli di codice fattoriale end-to-end: pianificazione e conferma, script di rilevamento, implementazione incrementale convalidata con lo strumento MCP run_code, esposizione dei processi come strumenti MCP, oltre a pratiche di sicurezza e gestione degli errori. Utilizzare quando viene richiesto di creare, automatizzare o integrare qualcosa su Factorial Code (fcode) e è necessario il metodo di lavoro consigliato.
