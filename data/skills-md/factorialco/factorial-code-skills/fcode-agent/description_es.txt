Flujo de trabajo iterativo basado en confirmación para crear procesos y módulos de Código Factorial de principio a fin: planificación y confirmación, scripts de descubrimiento, implementación incremental validada con la herramienta MCP run_code, exposición de procesos como herramientas MCP, además de prácticas de seguridad y manejo de errores. Úselo cuando se le solicite crear, automatizar o integrar algo en Código factorial (fcode) y necesite el método de trabajo recomendado.
