Schémas de paramètres d'entrée de processus Author Factorial Code (parametersSchema.json) - chaque type d'entrée et option de validation pris en charge, avec un échantillon annoté complet. À utiliser lors de la création ou de la modification d'un settingsSchema.json, ou lors de la définition des paramètres d'entrée ou des champs de formulaire d'un processus Factorial Code (fcode).
