Implementazioni di riferimento per Factorial Code: un'integrazione completa del libro paga del marketplace (sincronizzazione in uscita con esportazione di file e consegna push API), un ciclo di vita dell'app personalizzato multi-processo (modulo di configurazione in più passaggi, webhook + installazione pianificata, polling, disinstallazione) e processi di utilità (esportazione CSV con URL firmato + e-mail, arricchimento XML da un file caricato). Utilizzalo quando crei un'integrazione con codice fattoriale (fcode), un'app personalizzata o un'automazione end-to-end e desideri un modello funzionante e collaudato da adattare: leggi il riferimento corrispondente prima di scrivere il codice.
