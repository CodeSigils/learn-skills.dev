Implémentations de référence pour Factorial Code : une intégration complète de la paie sur le marché (synchronisation sortante avec les versions d'exportation de fichiers et de livraison API-push), un cycle de vie d'application personnalisé multi-processus (formulaire de configuration en plusieurs étapes, webhook + installation planifiée, interrogation, désinstallation) et des processus utilitaires (exportation CSV avec URL signée + e-mail, enrichissement XML à partir d'un fichier téléchargé). À utiliser lors de la création d'une intégration Factorial Code (fcode), d'une application personnalisée ou d'une automatisation de bout en bout et que vous souhaitez adapter un modèle de travail éprouvé - lisez la référence correspondante avant d'écrire du code.
