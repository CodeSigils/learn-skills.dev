التطبيقات المرجعية لـ Factorial Code - تكامل كامل لكشوف المرتبات في السوق (مزامنة خارجية مع تصدير الملفات ونكهات التسليم عبر واجهة برمجة التطبيقات)، ودورة حياة تطبيق مخصص متعدد العمليات (نموذج إعداد متعدد الخطوات، وخطاف ويب + جدولة التثبيت، والاستقصاء، وإلغاء التثبيت)، وعمليات الأداة المساعدة (تصدير CSV مع عنوان URL موقع + بريد إلكتروني، وإثراء XML من ملف تم تحميله). استخدمه عند إنشاء تكامل كود العامل (fcode) أو تطبيق مخصص أو أتمتة من النهاية إلى النهاية وتريد نمط عمل مثبتًا للتكيف - اقرأ المرجع المطابق قبل كتابة التعليمات البرمجية.
