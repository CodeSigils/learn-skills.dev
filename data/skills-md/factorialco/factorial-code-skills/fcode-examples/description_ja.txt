Factorial Code のリファレンス実装 - マーケットプレイス給与の完全な統合 (ファイル エクスポートおよび API プッシュ配信フレーバーによるアウトバウンド同期)、マルチプロセス カスタム アプリのライフサイクル (複数ステップのセットアップ フォーム、Webhook + スケジュール インストール、ポーリング、アンインストール)、およびユーティリティ プロセス (署名付き URL + 電子メールによる CSV エクスポート、アップロードされたファイルからの XML エンリッチメント)。 Factorial Code (fcode) 統合、カスタム アプリ、またはオートメーションをエンドツーエンドで構築し、実証済みの機能するパターンを適応させたい場合に使用します。コードを記述する前に、一致するリファレンスを読んでください。
