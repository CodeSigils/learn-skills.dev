팩토리얼 코드에 대한 작업 공간 로케일 및 번역 — i18n/<locale>.yaml 로케일 파일, JavaScript 및 Python의 fcode.i18n(key, args) 런타임 도우미, 양식 스키마의 fcode.i18n("key") 토큰, 실행 로케일 선택(Fcode-Locale 헤더, ?locale=, 일정), 상속 및 기본 로케일 대체, 로케일 버전 관리 및 fcode i18n:* CLI 명령. 로케일 추가, 기존 프로세스 코드 또는 양식 텍스트 번역 또는 국제화, fcode.i18n 호출, fcode run --locale로 테스트 또는 i18n:push로 번역 동기화 시 사용합니다.
