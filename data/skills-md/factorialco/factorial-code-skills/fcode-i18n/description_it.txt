Locali e traduzioni dell'area di lavoro per il codice fattoriale: file locali i18n/<locale>.yaml, helper di runtime fcode.i18n(key, args) in JavaScript e Python, token fcode.i18n("key") negli schemi dei moduli, selezione della locale di esecuzione (intestazione Fcode-Locale, ?locale=, pianificazioni), ereditarietà e fallback della locale primaria, controllo delle versioni locali e comandi CLI fcode i18n:*. Da utilizzare quando si aggiunge una locale, si traduce o si internazionalizza il codice di processo esistente o il testo del modulo, si chiama fcode.i18n, si esegue il test con fcode run --locale o si sincronizzano le traduzioni con i18n:push.
