لغات مساحة العمل والترجمات لرمز العامل — ملفات الإعدادات المحلية i18n/<locale>.yaml، ومساعد وقت التشغيل fcode.i18n(key, args) في JavaScript وPython، والرموز المميزة fcode.i18n("key") في مخططات النماذج، واختيار لغة التنفيذ (رأس Fcode-Locale،؟locale=، الجداول الزمنية)، والوراثة واللغة الاحتياطية الأساسية، واللغة المحلية الإصدار، وأوامر fcode i18n:* CLI. يُستخدم عند إضافة لغة، أو ترجمة أو تدويل كود العملية الموجود أو نص النموذج، أو الاتصال بـ fcode.i18n، أو الاختبار باستخدام fcode run --locale، أو مزامنة الترجمات مع i18n:push.
