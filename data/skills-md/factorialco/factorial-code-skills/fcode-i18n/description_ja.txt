Factorial コードのワークスペース ロケールと翻訳 — i18n/<locale>.yaml ロケール ファイル、JavaScript および Python の fcode.i18n(key, args) ランタイム ヘルパー、フォーム スキーマの fcode.i18n("key") トークン、実行ロケールの選択 (Fcode-Locale ヘッダー、?locale=、スケジュール)、継承とプライマリ ロケール フォールバック、ロケールのバージョン管理、 fcode i18n:* CLI コマンド。ロケールの追加、既存のプロセス コードまたはフォーム テキストの翻訳または国際化、fcode.i18n の呼び出し、fcode run --locale によるテスト、または i18n:push による翻訳の同期を行うときに使用します。
