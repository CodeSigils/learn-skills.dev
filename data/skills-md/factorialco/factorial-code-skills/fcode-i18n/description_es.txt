Configuraciones regionales del espacio de trabajo y traducciones para código factorial: archivos de configuración regional i18n/<locale>.yaml, el asistente de tiempo de ejecución fcode.i18n(key, args) en JavaScript y Python, tokens fcode.i18n("key") en esquemas de formulario, selección de configuración regional de ejecución (encabezado Fcode-Locale, ?locale=, programaciones), herencia y respaldo de configuración regional primaria, versiones de configuración regional y los comandos fcode i18n:* CLI. Úselo al agregar una configuración regional, traducir o internacionalizar código de proceso existente o texto de formulario, llamar a fcode.i18n, probar con fcode run --locale o sincronizar traducciones con i18n:push.
