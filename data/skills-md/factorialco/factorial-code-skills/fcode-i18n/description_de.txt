Arbeitsbereichsgebietsschemas und Übersetzungen für Factorial Code – i18n/<locale>.yaml-Gebietsschemadateien, der Laufzeithelfer fcode.i18n(key, args) in JavaScript und Python, fcode.i18n("key")-Tokens in Formularschemata, Auswahl des Ausführungsgebietsschemas (Fcode-Locale-Header, ?locale=, Zeitpläne), Vererbung und primäres Gebietsschema-Fallback, Gebietsschemaversionierung und der Fcode i18n:* CLI-Befehle. Verwenden Sie diese Option, wenn Sie ein Gebietsschema hinzufügen, vorhandenen Prozesscode oder Formulartext übersetzen oder internationalisieren, fcode.i18n aufrufen, mit fcode run --locale testen oder Übersetzungen mit i18n:push synchronisieren.
