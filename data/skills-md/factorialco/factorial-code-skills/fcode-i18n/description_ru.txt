Локали рабочей области и переводы для факториального кода — файлы локали i18n/<locale>.yaml, помощник времени выполнения fcode.i18n(key, args) в JavaScript и Python, токены fcode.i18n("key") в схемах форм, выбор локали выполнения (заголовок Fcode-Locale, ?locale=, расписания), наследование и резервный вариант основной локали, управление версиями локали и fcode i18n:* Команды CLI. Используйте при добавлении локали, переводе или интернационализации существующего кода процесса или текста формы, вызове fcode.i18n, тестировании с помощью fcode run --locale или синхронизации переводов с помощью i18n:push.
