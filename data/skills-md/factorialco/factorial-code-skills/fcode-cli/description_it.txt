Utilizza la CLI Factorial Code (fcode) per lo sviluppo locale e la sincronizzazione cloud: il flusso pull → add → dependencies:install → run → push, quando eseguire ciascun comando, --force safety, esempi funzionanti e file di configurazione dell'area di lavoro (processa metadata.json con webhook/form/appRole/visibility, team.json, variable.meta.json). Da utilizzare durante l'esecuzione dei comandi CLI di fcode, il test di un processo di codice fattoriale in locale, la distribuzione/sincronizzazione delle risorse di codice fattoriale (fcode) nel cloud o l'attivazione delle impostazioni di webhook, modulo o visibilità di un processo.
