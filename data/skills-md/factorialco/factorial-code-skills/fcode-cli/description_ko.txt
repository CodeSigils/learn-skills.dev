로컬 개발 및 클라우드 동기화를 위해 Factorial Code CLI(fcode)를 사용합니다. 풀 → 추가 → 종속성: 설치 → 실행 → 푸시 흐름, 각 명령 실행 시기, --force 안전, 작업 예제 및 작업 공간 구성 파일(webhook/form/appRole/visibility가 포함된 메타데이터.json 프로세스, team.json, Variable.meta.json). fcode CLI 명령을 실행하거나, 팩토리얼 코드 프로세스를 로컬로 테스트하거나, 팩토리얼 코드(fcode) 리소스를 클라우드에 배포/동기화하거나, 프로세스의 웹후크, 양식 또는 가시성 설정을 활성화할 때 사용합니다.
