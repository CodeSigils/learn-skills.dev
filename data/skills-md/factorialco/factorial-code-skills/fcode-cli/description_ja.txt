ローカル開発とクラウド同期には、Factorial Code CLI (fcode) を使用します。プル → 追加 → 依存関係:インストール → 実行 → プッシュ フロー、各コマンドを実行するタイミング、--force 安全性、動作する例、およびワークスペース構成ファイル (webhook/form/appRole/visibility、team.json、variables.meta.json を使用して metadata.json を処理します)。 fcode CLI コマンドを実行する場合、Factorial Code プロセスをローカルでテストする場合、Factorial Code (fcode) リソースをクラウドにデプロイ/同期する場合、またはプロセスの Webhook、フォーム、または可視性設定をアクティブにする場合に使用します。
