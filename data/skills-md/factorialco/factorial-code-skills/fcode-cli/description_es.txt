Utilice la CLI de código factorial (fcode) para el desarrollo local y la sincronización en la nube: el flujo de extracción → agregar → dependencias: instalar → ejecutar → empujar, cuándo ejecutar cada comando, --force seguridad, ejemplos trabajados y los archivos de configuración del espacio de trabajo (procesar metadata.json con webhook/form/appRole/visibility, team.json, variables.meta.json). Úselo cuando ejecute comandos CLI de fcode, pruebe un proceso de Código factorial localmente, implemente/sincronice recursos de Código factorial (fcode) en la nube o active la configuración de visibilidad, formulario o webhook de un proceso.
