استخدم كود العامل CLI (fcode) للتطوير المحلي والمزامنة السحابية - السحب → إضافة → التبعيات: تثبيت → تشغيل → دفع التدفق، ومتى يتم تشغيل كل أمر، --force Safety، والأمثلة العملية، وملفات تكوين مساحة العمل (معالجة metadata.json مع webhook/form/appRole/visibility، team.json،variables.meta.json). يُستخدم عند تشغيل أوامر fcode CLI، أو اختبار عملية التعليمات البرمجية العاملية محليًا، أو نشر/مزامنة موارد التعليمات البرمجية العاملية (fcode) إلى السحابة، أو تنشيط خطاف الويب أو النموذج أو إعدادات الرؤية الخاصة بالعملية.
