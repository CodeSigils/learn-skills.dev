Verwenden Sie die Factorial Code CLI (fcode) für die lokale Entwicklung und Cloud-Synchronisierung – den Pull → Add → dependencies:install → run → Push-Flow, wann jeder Befehl ausgeführt werden soll, --force Safety, Arbeitsbeispiele und die Workspace-Konfigurationsdateien (verarbeiten Sie metadata.json mit webhook/form/appRole/visibility, team.json, variables.meta.json). Wird verwendet, wenn Sie Fcode-CLI-Befehle ausführen, einen Factorial Code-Prozess lokal testen, Factorial Code (Fcode)-Ressourcen in der Cloud bereitstellen/synchronisieren oder den Webhook, das Formular oder die Sichtbarkeitseinstellungen eines Prozesses aktivieren.
