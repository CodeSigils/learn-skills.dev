Factorial 제품 UI 내부의 버튼으로 Factorial 코드 프로세스를 표시합니다. 즉, 프로세스의 메타데이터.json(위치 ID, 레이블, 아이콘, waitResult)의 `uiTrigger` 블록, 사용자가 클릭할 때 프로세스가 수신하는 내용, 동기 트리거에 대한 `{ data }` / `{errors }` 결과 봉투, 양식 지원 트리거, i18n 레이블, 아이콘 허용 목록 및 Factorial의 `FactorialCodeTrigger` 구성 요소가 이를 렌더링하는 방법입니다. 앱 프로세스가 팩토리얼 페이지의 작업 버튼으로 표시되어야 하는 경우 또는 "팩토리얼 UI에서 트리거됨" 트리거를 연결할 때 사용합니다.
