Factorial プロダクト UI 内のボタンとして Factorial コード プロセスを表示します。プロセスの metadata.json 内の `uiTrigger` ブロック (場所 ID、ラベル、アイコン、awaitResult)、ユーザーがクリックしたときにプロセスが受け取るもの、同期トリガーの `{ data }` / `{errors }` 結果エンベロープ、フォームベースのトリガー、i18n ラベル、アイコン ホワイトリスト、および Factorial の`FactorialCodeTrigger` コンポーネントがそれらをレンダリングします。アプリ プロセスを Factorial ページのアクション ボタンとして表示する必要がある場合、または「Factorial UI からトリガー」トリガーを配線する場合に使用します。
