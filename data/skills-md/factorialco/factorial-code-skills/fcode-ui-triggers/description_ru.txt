Выводит процесс Factorial Code в виде кнопки в пользовательском интерфейсе продукта Factorial — блок `uiTrigger` в файле метаданных процесса.json (идентификатор местоположения, метка, значок, awaitResult), то, что процесс получает при нажатии пользователем, конверт результатов `{ data }` / `{ error }` для синхронных триггеров, триггеры на основе формы, метки i18n, список разрешенных значков и как работает FactorialCodeTrigger` компонент визуализирует их. Используйте, когда процесс приложения должен отображаться в виде кнопки действия на странице Factorial или при подключении триггера «Запускается из пользовательского интерфейса Factorial».
