Presenta un processo Factorial Code come un pulsante all'interno dell'interfaccia utente del prodotto Factorial: il blocco `uiTrigger` nel metadata.json di un processo (ID posizione, etichetta, icona, waitResult), ciò che il processo riceve quando un utente fa clic, la busta dei risultati "{ data }` / "{ errori }` per trigger sincroni, trigger basati su modulo, etichette i18n, la lista consentita delle icone e come funziona il componente "FactorialCodeTrigger" di Factorial. li rende. Da utilizzare quando un processo dell'app deve essere visualizzato come pulsante di azione in una pagina Factorial o quando si collega un trigger "Triggered from Factorial UI".
