Faites apparaître un processus Factorial Code sous la forme d'un bouton dans l'interface utilisateur du produit Factorial - le bloc `uiTrigger` dans le fichier metadata.json d'un processus (identifiant d'emplacement, étiquette, icône, waitResult), ce que le processus reçoit lorsqu'un utilisateur clique, l'enveloppe de résultat `{ data }` / `{ error }` pour les déclencheurs synchrones, les déclencheurs basés sur un formulaire, les étiquettes i18n, la liste d'autorisation des icônes et comment Factorial Le composant `FactorialCodeTrigger` les restitue. À utiliser lorsqu'un processus d'application doit apparaître sous la forme d'un bouton d'action sur une page Factorial, ou lors du câblage d'un déclencheur « Déclenché à partir de l'interface utilisateur Factorial ».
