Muestre un proceso de Código Factorial como un botón dentro de la interfaz de usuario del producto Factorial: el bloque `uiTrigger` en metadata.json de un proceso (identificación de ubicación, etiqueta, icono, awaitResult), lo que recibe el proceso cuando un usuario hace clic, el sobre de resultados `{ data }` / `{ errores }` para activadores sincrónicos, activadores respaldados por formularios, etiquetas i18n, la lista de iconos permitidos y cómo el componente `FactorialCodeTrigger` de Factorial los representa. Úselo cuando el proceso de una aplicación deba aparecer como un botón de acción en una página de Factorial o cuando conecte un disparador "Activado desde la interfaz de usuario de Factorial".
