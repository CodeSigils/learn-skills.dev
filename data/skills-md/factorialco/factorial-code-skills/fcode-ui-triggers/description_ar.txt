قم بإظهار عملية رمز العامل كزر داخل واجهة مستخدم منتج العامل - كتلة `uiTrigger` في البيانات الوصفية للعملية.json (معرف الموقع، التسمية، الرمز، انتظار النتيجة)، وما تتلقاه العملية عندما ينقر المستخدم، ومغلف النتيجة `{ data }` / `{ الأخطاء }` للمشغلات المتزامنة، والمشغلات المدعومة بالنموذج، وعلامات i18n، والقائمة المسموح بها للأيقونات، وكيفية تشغيل العامل يعرضها مكون "FactorialCodeTrigger". يُستخدم عندما تظهر عملية تطبيق كزر إجراء على صفحة العامل، أو عند توصيل مشغل "يتم التشغيل من واجهة مستخدم العامل".
