Intégrez le formulaire de paramètres d'entrée d'un processus Factorial Code sur une page Web : les trois méthodes d'intégration (attributs de données, Fcode.initForm, composant FcodeForm React), le comportement pilotant à partir de la valeur de retour du processus (message/formErrors/redirect/jsCallback/nextProcessId), le style/thèmes, i18n, les flux en plusieurs étapes et les téléchargements automatiques de fichiers vers le stockage. À utiliser lors de l'intégration, de la configuration, du style ou du câblage des rappels de soumission pour un formulaire de code factoriel (fcode).
