Внедрите форму входных параметров процесса Factorial Code на веб-страницу — три метода внедрения (атрибуты данных, Fcode.initForm, компонент FcodeForm React), управление поведением на основе возвращаемого значения процесса (message/formErrors/redirect/jsCallback/nextProcessId), стиль/темы, i18n, многоэтапные потоки и автоматическую загрузку файлов в хранилище. Используйте при внедрении, настройке, стилизации или подключении обратных вызовов отправки для формы факториального кода (fcode).
