Factorial Code プロセスの入力パラメーター フォームを Web ページに埋め込みます。3 つの埋め込みメソッド (データ属性、Fcode.initForm、FcodeForm React コンポーネント)、プロセスの戻り値からの動作の駆動 (message/formErrors/redirect/jsCallback/nextProcessId)、スタイル/テーマ、i18n、マルチステップ フロー、およびストレージへの自動ファイル アップロードです。 Factorial Code (fcode) フォームの送信コールバックを埋め込み、構成、スタイル設定、または接続するときに使用します。
