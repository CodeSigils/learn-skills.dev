Incorpora il modulo dei parametri di input di un processo Factorial Code in una pagina Web: i tre metodi di incorporamento (attributi dei dati, Fcode.initForm, componente FcodeForm React), comportamento di guida dal valore restituito dal processo (message/formErrors/redirect/jsCallback/nextProcessId), stili/temi, i18n, flussi in più fasi e caricamenti automatici di file nello spazio di archiviazione. Da utilizzare per incorporare, configurare, applicare stili o collegare callback di invio per un modulo con codice fattoriale (fcode).
