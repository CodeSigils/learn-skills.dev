Examen approfondi de pré-production d'une application Factorial Code : clonez l'espace de travail en lecture seule, exécutez le catalogue de vérification statique (règles de plate-forme, règles de langage, formulaires et cycle de vie appRole, i18n, sécurité et secrets, réutilisation du module de base, journalisation, hygiène d'installation/désinstallation, préparation à la publication), classez les résultats comme bloqueur/avertissement/suggestion et écrivez APP_VALIDATION_REPORT.md avec un verdict de promotion ✅/❌. À utiliser lors de la validation, de la révision ou de l'audit d'une application ou d'un espace de travail Factorial Code (fcode) avant de demander une version ou une promotion en production, ou lorsqu'on lui demande si une application est prête à être expédiée.
