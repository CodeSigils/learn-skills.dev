Продвигайте код приложения Factorial Code из рабочей области разработки в рабочую область продукта — fcode клонирует рабочую область разработки, удаленно: добавляет рабочую область продукта, извлекает текущие метаданные продукта, затем добавляет и отправляет. Используйте при выпуске, продвижении или развертывании рабочей области разработки приложения Factorial Code (fcode) в рабочей среде или при отправке кода рабочей области разработки в его продукт-аналог.
