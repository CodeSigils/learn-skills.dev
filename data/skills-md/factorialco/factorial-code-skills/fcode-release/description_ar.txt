قم بترويج كود تطبيق Factorial Code من مساحة عمل التطوير الخاصة به إلى مساحة عمل المنتج الخاصة به - قم باستنساخ fcode لمساحة عمل التطوير، عن بعد: أضف مساحة عمل المنتج، واسحب البيانات التعريفية الحالية للمنتج، ثم قم بالإضافة والدفع. يُستخدم عند إطلاق مساحة عمل تطوير تطبيق Factorial Code (fcode) أو الترويج لها أو نشرها في الإنتاج، أو دفع كود مساحة عمل التطوير إلى نظيرتها في المنتج.
