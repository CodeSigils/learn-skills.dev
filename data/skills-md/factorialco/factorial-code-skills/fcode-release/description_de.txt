Fördern Sie den Code einer Factorial Code-App von ihrem Dev-Workspace in ihren Prod-Workspace – fcode klonen Sie den Dev-Workspace, remote: fügen Sie den Prod-Workspace hinzu, ziehen Sie die aktuellen Metadaten des Prods, fügen Sie ihn dann hinzu und pushen Sie ihn. Wird verwendet, wenn Sie den Entwicklungsarbeitsbereich einer Factorial Code (fcode)-App für die Produktion freigeben, bewerben oder bereitstellen oder den Code eines Entwicklungsarbeitsbereichs an sein Produktgegenstück übertragen.
