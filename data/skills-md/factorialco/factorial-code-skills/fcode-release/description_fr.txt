Promouvez le code d'une application Factorial Code de son espace de travail de développement vers son espace de travail de production - fcode clone l'espace de travail de développement, à distance : ajoutez l'espace de travail de production, extrayez les métadonnées actuelles de la production, puis ajoutez et poussez. À utiliser lors de la publication, de la promotion ou du déploiement de l'espace de travail de développement d'une application Factorial Code (fcode) vers la production, ou lors de la transmission du code d'un espace de travail de développement vers son homologue de production.
