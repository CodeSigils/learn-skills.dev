رحلة ودعم مستخدم منصة Factorial Code - طلب الوصول، وفرق التطوير، وإنشاء تطبيق (الاسم، واللغة، ونطاقات OAuth، وإطار عمل التكامل)، وقائمة التحقق من البدء، وإعداد تطبيق OAuth، والتطوير المحلي، والشركات التجريبية، وDev Marketplace، وتثبيت التطبيقات، ونماذج appRole، والإصدارات والترقية إلى الإنتاج، ونشر السوق (DatoCMS، التطبيقات الخاصة)، ومسارات التصعيد. يُستخدم عند الإجابة على أسئلة "كيف يمكنني..." حول استخدام النظام الأساسي لرمز العامل، أو توجيه المستخدم خلال أي مرحلة من مراحل الرحلة، أو العمل كوكيل دعم لرمز العامل.
