Parcours utilisateur et assistance de la plateforme Factorial Code : demande d'accès, équipes de développement, création d'une application (nom, langue, étendues OAuth, cadre d'intégration), liste de contrôle de démarrage, configuration de l'application OAuth, développement local, sociétés de démonstration, Dev Marketplace, installation d'applications, formulaires appRole, versions et promotion en production, publication sur le marché (DatoCMS, applications privées) et chemins d'escalade. À utiliser pour répondre aux questions « Comment puis-je… » sur l'utilisation de la plateforme Factorial Code, guider un utilisateur à travers n'importe quelle étape de son parcours ou agir en tant qu'agent d'assistance Factorial Code.
