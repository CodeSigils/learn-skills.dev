Disegno AutoCAD tramite il server MCP autocad-mcp (8 strumenti: disegno, entità, layer, blocco, annotazione, pid, vista, sistema). Utilizzare durante la creazione o la modifica di disegni AutoCAD, planimetrie, diagrammi P&ID, layout di apparecchiature o qualsiasi automazione CAD tramite gli strumenti AutoCAD-mcp. Copre sia i backend File IPC (live AutoCAD LT) che ezdxf (DXF senza testa). Essenziale per evitare le trappole più comuni: corse parallele di chiamate agli strumenti, timeout LISP, trappole dei dialoghi e dimensionamento dei batch. Utilizzare questa abilità ogni volta che vengono richiamati gli strumenti AutoCAD-MCP.
