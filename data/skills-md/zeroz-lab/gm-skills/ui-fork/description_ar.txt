يتم استخدام واجهة المستخدم الخاصة بـ UI من خلال استخدام رموز التصميم والرموز المميزة للذكاء الاصطناعي.استخدام عند المستخدمين ترغب في تحليل لقطات شاشة واجهة المستخدم، أو تشكيل نمط واجهة، أو إنشاء إرشادات تصميم قابلة لإعادة الاستخدام من الصور، أو استخراج مواصفات نظام التصميم الموجه نحو التنفيذ، أو إنشاء عقود سريعة للصفحات المستقبلية التي يتم إنشاؤها بواسطة الذكاء الاصطناعي.
