Diseño HTML de alta fidelidad y creación de prototipos. Utilice esta habilidad siempre que el usuario solicite diseñar, crear prototipos, simular o crear artefactos visuales en HTML, incluidos presentaciones de diapositivas, prototipos interactivos, páginas de destino, maquetas de interfaz de usuario, animaciones o cualquier trabajo de diseño visual. Úselo también cuando el usuario mencione Figma, sistemas de diseño, kits de interfaz de usuario, estructuras alámbricas, presentaciones o quiera explorar direcciones de diseño visual. Incluso si simplemente dicen "haz que se vea bien" o "diseña una pantalla para X", esta habilidad se aplica.
