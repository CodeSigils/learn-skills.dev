تصميم HTML عالي الدقة وإنشاء النموذج الأولي. استخدم هذه المهارة عندما يطلب المستخدم التصميم أو إنشاء نماذج أولية أو محاكاة أو إنشاء عناصر مرئية بتنسيق HTML - بما في ذلك مجموعات الشرائح أو النماذج الأولية التفاعلية أو الصفحات المقصودة أو نماذج واجهة المستخدم أو الرسوم المتحركة أو أي أعمال تصميم مرئية. استخدمه أيضًا عندما يذكر المستخدم Figma أو أنظمة التصميم أو مجموعات واجهة المستخدم أو الإطارات السلكية أو العروض التقديمية أو يريد استكشاف اتجاهات التصميم المرئي. حتى لو قالوا فقط "اجعلها تبدو جيدة" أو "صمم شاشة لـ X"، تنطبق هذه المهارة.
