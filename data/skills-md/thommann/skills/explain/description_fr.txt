Expliquez un morceau de code, un sous-système ou un concept architectural dans la base de code, fondé sur des fichiers réels. À utiliser lorsque l'utilisateur dit "expliquez ceci", "guidez-moi à travers X", "comment fonctionne Y", "que fait ce module", "aidez-moi à comprendre le flux Z" ou "intégrez-moi sur ce composant". Ne PAS utiliser pour rédiger des documents permanents (utilisez write-doc ou arc42) ou pour la révision du code (utilisez review-diff).
