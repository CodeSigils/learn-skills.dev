Создайте файл SYSTEM_OVERVIEW.md, который поможет старшему инженеру, плохо знакомому с незнакомой кодовой базой, содержать диаграмму архитектуры Mermaid, диаграмму последовательности потоков данных и оценку устаревших шаблонов. Используйте, когда пользователь говорит: «дайте мне обзор системы», «подключите меня к этому репозиторию», «познакомьте меня с этой устаревшей кодовой базой», «задокументируйте высокоуровневую архитектуру» или «создайте SYSTEM_OVERVIEW.md». НЕ используйте для пошаговых руководств по коду (используйте объяснение), глав по постоянной архитектуре (используйте arc42) или ADR (используйте document-decision).
