Generieren Sie ein SYSTEM_OVERVIEW.md, das einen leitenden Ingenieur, der neu in eine unbekannte Codebasis einsteigt, mit einem Mermaid-Architekturdiagramm, einem Sequenzdiagramm für den Datenfluss und einer Bewertung von Legacy-Mustern einführt. Wird verwendet, wenn der Benutzer sagt: „Geben Sie mir einen Systemüberblick“, „Onboarden Sie mich in diesem Repo“, „Führen Sie mich in diese Legacy-Codebasis ein“, „Dokumentieren Sie die High-Level-Architektur“ oder „Erstellen Sie eine SYSTEM_OVERVIEW.md“. NICHT für Code-Komplettlösungen (verwenden Sie „explain“), persistente Architekturkapitel (verwenden Sie „arc42“) oder ADRs (verwenden Sie „document-decision“) verwenden.
