Genere un SYSTEM_OVERVIEW.md que oriente a un ingeniero senior nuevo a una base de código desconocida, con un diagrama de arquitectura Mermaid, un diagrama de secuencia para el flujo de datos y una evaluación de patrones heredados. Úselo cuando el usuario diga "dame una descripción general del sistema", "incorpórame en este repositorio", "llévame a esta base de código heredada", "documenta la arquitectura de alto nivel" o "crea un SYSTEM_OVERVIEW.md". NO lo use para tutoriales de código (use explicación), capítulos de arquitectura persistente (use arc42) o ADR (use documento de decisión).
