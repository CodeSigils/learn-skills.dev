Générez un SYSTEM_OVERVIEW.md qui oriente un ingénieur senior novice dans une base de code inconnue, avec un diagramme d'architecture Mermaid, un diagramme de séquence pour le flux de données et une évaluation des modèles hérités. À utiliser lorsque l'utilisateur dit "donnez-moi un aperçu du système", "intégrez-moi à ce dépôt", "guidez-moi dans cette base de code héritée", "documentez l'architecture de haut niveau" ou "créez un SYSTEM_OVERVIEW.md". Ne PAS utiliser pour les procédures pas à pas de code (utilisez expliquer), les chapitres d'architecture persistante (utilisez arc42) ou les ADR (utilisez la décision de document).
