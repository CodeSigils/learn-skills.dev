Synchronisieren Sie den aktuellen Feature-Branch mit Origin/Main, indem Sie lokale Arbeiten ausführen, Konflikte abrufen, zusammenführen und lösen. Wird verwendet, wenn der Benutzer „Hauptzweig zusammenführen“, „Vom Hauptzweig aktualisieren“, „Mit Hauptzweig synchronisieren“, „Hauptzweig in Zweig ziehen“, „Zweig liegt hinter Hauptzweig“ oder „Meinen Zweig aktualisieren“ sagt. NICHT zum Erstellen von PRs (verwenden Sie „create-pr“), zum Überprüfen von Code (verwenden Sie „review-diff“) oder für einen Rebase-Workflow verwenden – dieser Skill führt Zusammenführungen durch, nicht Rebases.
