Синхронизируйте документацию с изменениями кода. Сканирует README, CLAUDE.md, документы/страницы и навыки, которые ссылаются на поведение, которое модифицирует текущая ветвь, а также обновляет или помечает их. Используйте, когда пользователь говорит: «обновить документы», «синхронизировать документацию», «актуальна ли наша документация», «документы устарели» или «обновить файлы README после этого рефакторинга». НЕ используйте для написания нового документа по функциям (используйте функцию документа) или нового ADR (используйте решение по документу).
