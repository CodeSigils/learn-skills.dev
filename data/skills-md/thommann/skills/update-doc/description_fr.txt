Synchronisez la documentation avec les modifications de code. Analyse les fichiers README, CLAUDE.md, les documents/pages et les compétences qui font référence au comportement modifié par la branche actuelle, et les met à jour ou les signale. À utiliser lorsque l'utilisateur dit « mettre à jour les documents », « synchroniser la documentation », « notre documentation est-elle à jour », « les documents sont obsolètes » ou « mettre à jour les README après ce refactor ». Ne PAS utiliser pour rédiger un nouveau document de fonctionnalité (utiliser document-feature) ou un nouvel ADR (utiliser document-décision).
