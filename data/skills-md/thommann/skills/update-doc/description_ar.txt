مزامنة الوثائق مع تغييرات التعليمات البرمجية. يقوم بالمسح بحثًا عن README وCLAUDE.md والمستندات/الصفحات والمهارات التي تشير إلى السلوك المرجعي الذي يعدله الفرع الحالي ويحدثها أو يضع علامة عليها. يُستخدم عندما يقول المستخدم "تحديث المستندات"، أو "وثائق المزامنة"، أو "هل وثائقنا حديثة"، أو "المستندات قديمة"، أو "تحديث المستندات التمهيدية بعد عملية إعادة البناء هذه". لا تستخدم لكتابة مستند مميز جديد (استخدم ميزة المستند) أو ADR جديد (استخدم قرار المستند).
