Подготовьте код для запроса на включение путем организации синхронизации, форматирования, проверки, тестирования, проверки и обновления документации. Используйте, когда пользователь говорит «создать PR», «подготовить запрос на включение», «готовиться к PR», «подтвердить мои изменения», «подготовиться к проверке», «проверить перед слиянием» или «готово ли это к слиянию». НЕ используйте только для запуска тестов, только для просмотра (используйте review-diff), только для синхронизации с основной (используйте merge-main) или для фактического открытия PR на GitHub — этот навык останавливается на уровне «готово».
