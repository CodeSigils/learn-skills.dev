Bereiten Sie Code für eine Pull-Anfrage vor, indem Sie Synchronisierung, Formatierung, Lint, Test, Überprüfung und Dokumentaktualisierungen orchestrieren. Wird verwendet, wenn der Benutzer sagt: „PR erstellen“, „Pull-Anfrage vorbereiten“, „Bereit für PR“, „Meine Änderungen validieren“, „Zur Überprüfung vorbereiten“, „Prüfungen vor dem Zusammenführen“ oder „Ist dies zum Zusammenführen bereit?“. NICHT verwenden, um nur Tests auszuführen, nur zu überprüfen (review-diff verwenden), nur mit main zu synchronisieren (merge-main verwenden) oder die PR tatsächlich auf GitHub zu öffnen – dieser Skill stoppt bei „ready“.
