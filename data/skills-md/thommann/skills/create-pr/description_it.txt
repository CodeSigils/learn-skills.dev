Prepara il codice per una richiesta pull orchestrando aggiornamenti di sincronizzazione, formato, lint, test, revisione e documentazione. Da utilizzare quando l'utente dice "crea un PR", "prepara una richiesta pull", "preparati per il PR", "convalida le mie modifiche", "prepara per la revisione", "controlli pre-unione" o "è pronto per l'unione". NON utilizzare solo per eseguire test, solo per rivedere (utilizzare review-diff), solo per sincronizzare con main (utilizzare merge-main) o per aprire effettivamente il PR su GitHub: questa abilità si ferma a "pronto".
