قم بإعداد التعليمات البرمجية لطلب السحب من خلال تنسيق تحديثات المزامنة والتنسيق والفحص والاختبار والمراجعة والمستندات. يُستخدم عندما يقول المستخدم "إنشاء علاقات عامة"، أو "إعداد طلب سحب"، أو "الاستعداد للعلاقات العامة"، أو "التحقق من صحة التغييرات"، أو "التحضير للمراجعة"، أو "فحوصات ما قبل الدمج"، أو "هل هذا جاهز للدمج". لا تستخدم فقط لإجراء الاختبارات، أو المراجعة فقط (استخدم review-diff)، أو المزامنة مع الرئيسي فقط (استخدم merge-main)، أو فتح العلاقات العامة فعليًا على GitHub - تتوقف هذه المهارة عند "جاهز".
