Préparez le code pour une pull request en orchestrant la synchronisation, le formatage, le lint, les tests, la révision et les mises à jour de la documentation. À utiliser lorsque l'utilisateur dit « créer un PR », « préparer une demande d'extraction », « se préparer pour le PR », « valider mes modifications », « préparer pour la révision », « contrôles préalables à la fusion » ou « est-ce prêt à fusionner ». Ne pas utiliser uniquement pour exécuter des tests, uniquement pour réviser (utiliser review-diff), uniquement pour synchroniser avec main (utiliser merge-main) ou pour ouvrir réellement le PR sur GitHub - cette compétence s'arrête à "prêt".
