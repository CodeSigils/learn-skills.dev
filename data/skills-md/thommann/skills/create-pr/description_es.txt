Prepare código para una solicitud de extracción organizando sincronización, formato, pelusa, prueba, revisión y actualizaciones de documentos. Úselo cuando el usuario diga "crear un PR", "preparar una solicitud de extracción", "prepararse para el PR", "validar mis cambios", "prepararse para la revisión", "verificaciones previas a la fusión" o "está listo para fusionarse". NO lo use solo para ejecutar pruebas, solo para revisar (use review-diff), solo para sincronizar con main (use merge-main) o para abrir el PR en GitHub; esta habilidad se detiene en "listo".
