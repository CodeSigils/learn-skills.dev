قم بإنشاء سجل قرارات الهندسة المعمارية (ADR) بتنسيق MADR v4 الأساسي الذي يوضح السبب وراء الاختيار الفني المهم. يُستخدم عندما يقول المستخدم "توثيق هذا القرار"، أو "إنشاء ADR"، أو "قرار هندسة السجل"، أو "لماذا اخترنا X"، أو "توثيق الأساس المنطقي"، أو عند إضافة تبعيات رئيسية، أو أطر عمل جديدة، أو تغيير الأنماط الأساسية. لا تستخدمه مع المستندات المميزة التي تواجه المستخدم (استخدم ميزة المستند) أو مزامنة المستندات الموجودة (استخدم تحديث المستند).
