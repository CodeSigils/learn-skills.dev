Превратите проблему GitHub в план реализации — исследуйте кодовую базу, предложите подход, составьте список важных файлов и изменений, наметьте стратегию тестирования. Используйте, когда пользователь говорит: «Спланируйте эту проблему», «Каков подход», «Как бы я ее решил», «План реализации» или «Перед кодированием». НЕ используйте для фактической реализации (пишите код сразу после плана) или для разбиения слишком большой проблемы на подзадачи (используйте задачу сращивания).
