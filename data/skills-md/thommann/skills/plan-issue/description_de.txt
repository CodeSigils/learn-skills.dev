Verwandeln Sie ein GitHub-Problem in einen Implementierungsplan – untersuchen Sie die Codebasis, schlagen Sie einen Ansatz vor, listen Sie kritische Dateien und Änderungen auf und skizzieren Sie die Teststrategie. Verwenden Sie diese Option, wenn der Benutzer sagt: „Dieses Problem planen“, „Was ist der Ansatz“, „Wie würde ich vorgehen“, „Implementierungsplan für“ oder „Vor dem Codieren“. NICHT für die tatsächliche Implementierung (Schreiben Sie den Code direkt nach dem Plan) oder zum Aufteilen eines zu großen Problems in Unterprobleme (verwenden Sie splice-issue) verwenden.
