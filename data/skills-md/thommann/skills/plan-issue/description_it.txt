Trasforma un problema di GitHub in un piano di implementazione: esamina la base di codice, proponi un approccio, elenca file e modifiche critici, delinea la strategia di test. Da utilizzare quando l'utente dice "pianifica questo problema", "qual è l'approccio da adottare", "come lo affronterei", "piano di implementazione per" o "prima della codifica". NON utilizzare per l'effettiva implementazione (scrivere il codice direttamente dopo il piano) o per suddividere un problema troppo grande in sottoproblemi (utilizzare splice-issue).
