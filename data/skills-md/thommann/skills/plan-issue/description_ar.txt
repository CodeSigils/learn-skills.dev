قم بتحويل مشكلة GitHub إلى خطة تنفيذ - قم بالتحقق من قاعدة التعليمات البرمجية، واقتراح نهج، وإدراج الملفات والتغييرات الهامة، وتحديد استراتيجية الاختبار. يُستخدم عندما يقول المستخدم "التخطيط لهذه المشكلة"، أو "ما هو النهج المتبع"، أو "كيف يمكنني التعامل مع ذلك"، أو "خطة التنفيذ لـ"، أو "قبل البرمجة". لا تستخدم للتنفيذ الفعلي (اكتب الكود مباشرة بعد الخطة) أو لتقسيم مشكلة كبيرة جدًا إلى مشكلات فرعية (استخدم مشكلة اللصق).
