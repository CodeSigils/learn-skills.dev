يقوم بتدقيق السطح المواجه للمطور للمكتبة، أو حزمة CLI، أو SDK، أو npm عبر بيئة عمل API وSDK، ورسائل الخطأ التي يراها المطورون، وCLI UX، وبيئة العمل، والتثبيت والتشغيل الأول، وبيئة العمل للتكوين. 27 قاعدة مرسلة بالبادئة؛ تقارير النتائج حسب الملف والموقع مع مستويات التأثير والإصلاحات الملموسة. يُستخدم عندما يُطلب منك "تدقيق سطر الأوامر الخاص بي"، أو "هل واجهة برمجة التطبيقات هذه مريحة"، أو "مراجعة تجربة المطور"، أو "تحسين رسائل الخطأ هذه"، أو "هل من السهل اعتماد SDK هذا"، أو "هل هذه الحزمة سهلة التثبيت"، أو "مراجعة DX لمكتبتي". للحصول على جودة واجهة مستخدم المستخدم النهائي وReact/Next UX، استخدم ui-audit، ولتطبيق Agentic-app UX، استخدم ax-audit، وللتوثيق النثري استخدم كتابة المستندات، ولـ README استخدم readme-creator، ولـ AGENTS.md استخدم agent-md، ولبنية الريبو استخدم Define-architecture.
