Überprüft die entwicklerseitige Oberfläche einer Bibliothek, einer CLI, eines SDK oder eines NPM-Pakets hinsichtlich der API- und SDK-Ergonomie, der Fehlermeldungen, die Entwickler sehen, der CLI-UX, der Typergonomie, des Installations- und Erstausführungs-Onboardings und der Konfigurationsergonomie. 27 Präfix-verteilte Regeln; Meldet Ergebnisse nach Datei und Standort mit Auswirkungsstufen und konkreten Korrekturen. Verwenden Sie diese Option, wenn Sie gefragt werden: „Überprüfen Sie meine CLI“, „Ist diese API ergonomisch“, „Überprüfen Sie die Entwicklererfahrung“, „Verbessern Sie diese Fehlermeldungen“, „Ist dieses SDK einfach zu übernehmen“, „Ist dieses Paket einfach zu installieren“ oder „Überprüfen Sie die DX meiner Bibliothek“. Für die Qualität der Endbenutzer-Benutzeroberfläche und React/Next UX verwenden Sie ui-audit, für Agentic-App UX verwenden Sie ax-audit, für Dokumentationsprosa verwenden Sie docs-writing, für eine README-Datei verwenden Sie readme-creator, für AGENTS.md verwenden Sie Agents-md und für die Repo-Struktur verwenden Sie define-architecture.
