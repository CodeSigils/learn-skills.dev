API および SDK エルゴノミクス、開発者に表示されるエラー メッセージ、CLI UX、タイプ エルゴノミクス、インストールと初回実行のオンボーディング、構成エルゴノミクスにわたって、ライブラリ、CLI、SDK、または npm パッケージの開発者向けの表面を監査します。 27 個のプレフィックスディスパッチ ルール。ファイルおよび場所ごとに、影響レベルと具体的な修正とともに検出結果をレポートします。 「CLI を監査する」、「この API は人間工学に基づいているか」、「開発者エクスペリエンスをレビューする」、「これらのエラー メッセージを改善する」、「この SDK は採用しやすいか」、「このパッケージはインストールしやすいか」、または「ライブラリの DX をレビューする」などの質問をされた場合に使用します。エンドユーザー UI 品質と React/Next UX には ui-audit を使用し、エージェントアプリ UX には ax-audit を使用し、ドキュメント散文には docs-writing を使用し、README には readme-creator を使用し、AGENTS.md には Agents-md を使用し、リポジトリ構造には define-architecture を使用します。
