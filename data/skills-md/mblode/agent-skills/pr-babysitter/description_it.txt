Monitoraggio PR autonomo: esegue sondaggi ogni 2 minuti per conflitti di unione, errori CI/CD tra GitHub Actions, Buildkite, Vercel e Fly.io, esamina i commenti e prepara l'unione. Rileva automaticamente PR dal ramo corrente, corregge ciò che può, notifica i cambiamenti di stato. Nessuna domanda di configurazione. Da utilizzare quando viene chiesto di fare da babysitter a un PR, guardare un PR, monitorare CI, mantenere un PR verde, gestire conflitti di unione, sondare lo stato del PR o eseguire `/pr-babysitter`
