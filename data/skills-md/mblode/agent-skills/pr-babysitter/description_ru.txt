Автономный монитор связей с общественностью — каждые 2 минуты опрашивает конфликты слияний, сбои CI/CD в GitHub Actions, Buildkite, Vercel и Fly.io, просматривает комментарии и проверяет готовность к слиянию. Автоматически обнаруживает PR из текущей ветки, исправляет все, что может, уведомляет об изменениях состояния. Никаких вопросов по настройке. Используйте, когда вас просят присмотреть за PR, посмотреть PR, контролировать CI, поддерживать зеленый PR, обрабатывать конфликты слияния, опросить статус PR или запустить `/pr-babysitter`
