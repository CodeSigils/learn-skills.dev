Autonomer PR-Monitor – fragt alle 2 Minuten nach Zusammenführungskonflikten, CI/CD-Fehlern in GitHub Actions, Buildkite, Vercel und Fly.io ab, prüft Kommentare und prüft die Zusammenführungsbereitschaft. Erkennt PR automatisch aus dem aktuellen Zweig, behebt, was möglich ist, und benachrichtigt bei Statusänderungen. Keine Einrichtungsfragen. Verwenden Sie diese Option, wenn Sie gebeten werden, einen PR zu babysitten, einen PR anzusehen, CI zu überwachen, einen PR grün zu halten, Zusammenführungskonflikte zu behandeln, den PR-Status abzufragen oder „/pr-babysitter“ auszuführen
