Déploie quatre agents de révision simultanés sur la différence actuelle, puis APPLIQUE les correctifs directement à l'arborescence de travail et vérifie la construction. Mute le code ; il ne produit pas de rapport. Couvre la réutilisation (logique dupliquée, stdlib lancé à la main, fonctionnalités de plate-forme réinventées), la qualité (modèles piratés, hygiène React/TypeScript, sur-mémorisation, dépôts exhaustifs, `any`, code mort, violations `CLAUDE.md`/`AGENTS.md`), l'efficacité (travail inutile, concurrence manquée, surcharge du hot-path) et la discipline des tests (corrections de bugs sans test de repro, tests inutiles à supprimer, tests manquants seulement lorsqu'ils empêchent une défaillance nommée). À utiliser lorsque l'utilisateur dit « ranger ça », « simplifier », « nettoyer cette différence », « peaufiner mes modifications », « vérifier les duplications » ou « des opportunités de réutilisation ? Pour un rapport en lecture seule répertoriant les résultats sans toucher aux fichiers, utilisez plutôt « pr-reviewer ».
