Распределяет четыре агента одновременной проверки по текущему различию, затем ПРИМЕНЯЕТ исправления непосредственно к рабочему дереву и проверяет сборку. Мутирует код; он не создает отчет. Охватывает повторное использование (дубликат логики, ручная сборка stdlib, заново изобретенные функции платформы), качество (хакерские шаблоны, гигиена React/TypeScript, чрезмерная мемоизация, исчерпывающие депсы, `любой`, мертвый код, нарушения `CLAUDE.md`/`AGENTS.md`), эффективность (ненужная работа, пропущенный параллелизм, раздувание горячих путей) и дисциплина тестирования (исправления ошибок без повторного теста, бесполезные тесты для удалять пропущенные тесты только тогда, когда они предотвращают именованный сбой). Используйте, когда пользователь говорит «привести в порядок», «упростить», «очистить этот diff», «доработать мои изменения», «проверить дублирование» или «есть ли возможности повторного использования?», т. е. когда намерение состоит в том, чтобы изменения вносились автоматически. Для отчета, доступного только для чтения, в котором перечислены результаты, не затрагивая файлы, вместо этого используйте `pr-reviewer`.
