Überprüft Agentenanwendungen auf zwei Ebenen: agentennative Architektur (Toolparität, atomare Grundelemente, Kontextinjektion, Abschlusssignale, Genehmigungstore) und Agentenerfahrungsdesign (Vertrauensmuster, Vertrauenshinweise, Escape-Luken, Intent-Handshake, adaptive Leinwand, Speichersichtbarkeit). Erstellt ein dreistufiges Urteil zur Schiffsbereitschaft (Release-Blocker / Fix-This-Sprint / Backlog) sowie eine AX-Beziehungszusammenfassung mit Nennung der Entwicklungsstufe, des Vertrauenssignals und der Schlüssellücke. Verwenden Sie diese Funktion vor dem Zusammenführen einer PR für eine Agentenfunktion, wenn Sie gefragt werden: „Ist dieser Agent nativ?“, „AX-Überprüfung“, „AX-Kritik“, „Diese KI-Funktion kritisieren“, „Erzeugt dies das Vertrauen des Benutzers?“, „Ist dieses Design tatsächlich agentenhaft?“, „Vertrauensüberprüfung“, „AX-Musterprüfung“ oder „Überprüfen Sie dies für AX“. Für die herkömmliche UX-Prüfung (Formulare, Zustände, Fokus, Asynchronität, Mikrokopie) verwenden Sie ux-audit.
