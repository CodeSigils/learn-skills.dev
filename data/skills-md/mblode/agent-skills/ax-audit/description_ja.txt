エージェント ネイティブ アーキテクチャ (ツール パリティ、アトミック プリミティブ、コンテキスト インジェクション、完了シグナル、承認ゲート) とエージェント エクスペリエンス設計 (信頼パターン、信頼性の手がかり、エスケープ ハッチ、インテント ハンドシェイク、アダプティブ キャンバス、メモリの可視性) の 2 つの層にわたってエージェント アプリケーションを監査します。 3 段階の出荷準備状況の判定 (リリース ブロッカー / このスプリントの修正 / バックログ) に加えて、進化段階、信頼シグナル、および主要なギャップを示す AX 関係概要を生成します。エージェント機能 PR をマージする前に、「これはエージェントネイティブですか?」、「AX レビュー」、「AX 批評」、「この AI 機能を批評」、「これはユーザーの信頼を獲得していますか?」、「この設計は実際にエージェントですか?」、「信頼レビュー」、「AX パターンのチェック」、または「AX の監査」を尋ねられたときに使用します。従来の UX 監査 (フォーム、状態、フォーカス、非同期、マイクロコピー) の場合は、ux-audit を使用します。
