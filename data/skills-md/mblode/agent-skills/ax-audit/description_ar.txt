يقوم بتدقيق التطبيقات الوكيلة عبر طبقتين: البنية الأصلية للوكيل (تكافؤ الأدوات، والأوليات الذرية، وحقن السياق، وإشارات الإكمال، وبوابات الموافقة) وتصميم تجربة الوكيل (أنماط الثقة، وإشارات الثقة، وبوابات الهروب، والمصافحة المقصودة، واللوحة التكيفية، ورؤية الذاكرة). يُنتج حكمًا لجاهزية السفينة من 3 مستويات (مانع التحرير / إصلاح هذا السباق / تراكم الأعمال) بالإضافة إلى ملخص علاقة AX مع تسمية مرحلة التطور وإشارة الثقة والفجوة الرئيسية. استخدمه قبل دمج ميزة وكيل PR، عند سؤالك "هل هذا الوكيل أصلي؟"، أو "مراجعة AX"، أو "نقد AX"، أو "نقد ميزة الذكاء الاصطناعي هذه"، أو "هل يكسب هذا ثقة المستخدم؟"، أو "هل هذا التصميم وكيل بالفعل؟"، أو "مراجعة الثقة"، أو "التحقق من أنماط AX"، أو "تدقيق هذا لـ AX". بالنسبة لتدقيق تجربة المستخدم التقليدية (النماذج، الحالات، التركيز، غير المتزامن، النسخ المصغر)، استخدم تدقيق تجربة المستخدم.
