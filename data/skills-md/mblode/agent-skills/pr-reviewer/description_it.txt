Esamina il diff o il ramo locale corrente alla fine di una sessione di codifica per verificare bug ad alta sicurezza e conformità del file di istruzioni del repository. Da utilizzare quando viene richiesto di eseguire `/pr-reviewer` prima del commit, prima del push o prima di consegnare le modifiche per la creazione o l'aggiornamento delle PR e quando devono essere riportati solo alcuni risultati utilizzabili mentre il feedback sullo stile viene ignorato.
