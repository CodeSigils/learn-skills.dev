Diseña, profundiza y fortalece la arquitectura base de código TypeScript en tres modos: estructuras de carpetas, contratos de módulos y canales de middleware para una nueva aplicación; profundización del código existente basada en el dominio; y las herramientas de barandilla, puertas CI y señalización que evitan que una estructura se deteriore. Úselo al configurar la estructura del proyecto, organizar un monorepo, diseñar módulos de backend, escribir un resumen de arquitectura, recuperar terminología de dominio, registrar una decisión de arquitectura o preguntar "cómo debo estructurar esta aplicación", "encontrar mejoras de arquitectura", "este módulo es un desastre", "hacer que esta base de código sea compatible con los agentes", "configurar barreras de seguridad para los agentes de codificación", "agregar una verificación de código inactivo" o "mi agente no puede encontrar nada en este repositorio". Para crear un scaffolding de un nuevo repositorio, use scaffold-nextjs o scaffold-cli, para el aislamiento de múltiples inquilinos use multi-tenant-architecture, para el contenido propio del archivo AGENTS.md use agentes-md y para revisar una diferencia local use pr-reviewer.
