Progetta, approfondisce e rafforza l'architettura della base di codice TypeScript in tre modalità: strutture di cartelle, contratti di modulo e pipeline middleware per una nuova app; approfondimento basato sul dominio del codice esistente; e gli strumenti del guardrail, i cancelli CI e l'orientamento che impediscono il decadimento di una struttura. Da utilizzare quando si imposta la struttura del progetto, si organizza un monorepo, si progettano moduli backend, si scrive un brief sull'architettura, si recupera la terminologia del dominio, si registra una decisione sull'architettura o si chiede "come dovrei strutturare questa app", "trova miglioramenti all'architettura", "questo modulo è un disastro", "rendi questa base di codice adatta agli agenti", "imposta i guardrail per gli agenti di codifica", "aggiungi un controllo del codice morto" o "il mio agente non riesce a trovare nulla in questo repository". Per l'impalcatura di un nuovo repository utilizzare scaffold-nextjs o scaffold-cli, per l'isolamento multi-tenant utilizzare l'architettura multi-tenant, per il contenuto proprio del file AGENTS.md utilizzare agenti-md e per la revisione di un differenziale locale utilizzare pr-reviewer.
