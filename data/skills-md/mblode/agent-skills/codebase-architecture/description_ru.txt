Проектирует, углубляет и укрепляет архитектуру базы кода TypeScript в трех режимах: структуры папок, контракты модулей и конвейеры промежуточного программного обеспечения для нового приложения; углубление существующего кода с учетом предметной области; а также инструменты для ограждений, ворота CI и средства навигации, которые предотвращают разрушение конструкции. Используйте при настройке структуры проекта, организации монорепозитория, разработке внутренних модулей, написании краткого описания архитектуры, восстановлении терминологии предметной области, записи решения по архитектуре или при вопросе «как мне структурировать это приложение», «найти улучшения архитектуры», «этот модуль — беспорядок», «сделать эту кодовую базу удобной для агентов», «настроить ограничения для агентов кодирования», «добавить проверку мертвого кода» или «мой агент ничего не может найти в этом репозитории». Для создания нового репозитория используйте scaffold-nextjs или scaffold-cli, для мультитенантной изоляции используйте multi-tenant-architecture, для собственного содержимого файла AGENTS.md используйте агенты-md, а для проверки локальных различий используйте pr-reviewer.
