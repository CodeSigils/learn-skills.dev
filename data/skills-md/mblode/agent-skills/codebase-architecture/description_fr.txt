Conçoit, approfondit et renforce l'architecture de base de code TypeScript dans trois modes : structures de dossiers, contrats de modules et pipelines middleware pour une nouvelle application ; approfondissement du code existant basé sur le domaine ; et l'outillage de garde-corps, les portes CI et l'orientation qui empêchent la décomposition d'une structure. À utiliser lors de la configuration de la structure du projet, de l'organisation d'un monorepo, de la conception de modules backend, de la rédaction d'un brief d'architecture, de la récupération de la terminologie du domaine, de l'enregistrement d'une décision d'architecture ou de la question « comment dois-je structurer cette application », « trouver des améliorations d'architecture », « ce module est un gâchis », « rendre cette base de code conviviale », « mettre en place des garde-fous pour les agents de codage », « ajouter une vérification de code mort » ou « mon agent ne trouve rien dans ce dépôt ». Pour échafauder un nouveau référentiel, utilisez scaffold-nextjs ou scaffold-cli, pour l'isolation multi-tenant, utilisez une architecture multi-tenant, pour le propre contenu du fichier AGENTS.md, utilisez agents-md et pour l'examen d'une différence locale, utilisez pr-reviewer.
