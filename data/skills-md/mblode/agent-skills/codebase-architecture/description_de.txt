Entwirft, vertieft und härtet die TypeScript-Codebasisarchitektur in drei Modi: Ordnerstrukturen, Modulverträge und Middleware-Pipelines für eine neue App; domänenbasierte Vertiefung des vorhandenen Codes; und die Leitplankenwerkzeuge, CI-Tore und Wegweiser, die den Verfall einer Struktur verhindern. Verwenden Sie diese Option, wenn Sie eine Projektstruktur einrichten, ein Monorepo organisieren, Back-End-Module entwerfen, eine Architekturbeschreibung schreiben, Domänenterminologie wiederherstellen, eine Architekturentscheidung aufzeichnen oder fragen: „Wie soll ich diese App strukturieren“, „Architekturverbesserungen finden“, „dieses Modul ist ein Durcheinander“, „diese Codebasis agentenfreundlich gestalten“, „Leitplanken für Codierungsagenten einrichten“, „eine Prüfung auf toten Code hinzufügen“ oder „mein Agent kann in diesem Repo nichts finden“. Zum Gerüstbau eines neuen Repositorys verwenden Sie scaffold-nextjs oder scaffold-cli, für die mehrinstanzenfähige Isolierung verwenden Sie die Multi-Tenant-Architektur, für den eigenen Inhalt der AGENTS.md-Datei verwenden Sie Agents-md und für die Überprüfung eines lokalen Diffs verwenden Sie pr-reviewer.
