Génère des diagrammes Mermaid à partir de bases de code, de sujets, de fichiers, de conversations ou de spécifications. Prend en charge les organigrammes, les diagrammes de séquence, les diagrammes de classes, les diagrammes d'état, les diagrammes ER, l'architecture C4, les cartes mentales, les diagrammes de Gantt, les chronologies, les parcours utilisateur, les gitGraphs, les diagrammes circulaires, les diagrammes quadrants, les diagrammes d'exigences et les types bêta (xychart, sankey, block, architecture). À utiliser lorsqu'on vous le demande pour créer un diagramme Sirène, visualiser un processus ou un système, dessiner un organigramme, un diagramme de séquence, un diagramme de classes, une machine d'état, un ERD, un diagramme d'architecture, une carte mentale, une chronologie, un diagramme de Gantt, un parcours utilisateur, un graphique de branchement git ou toute demande de « diagramme ceci ».
