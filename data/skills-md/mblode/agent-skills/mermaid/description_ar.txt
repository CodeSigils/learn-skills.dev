يُنشئ مخططات حورية البحر من قواعد التعليمات البرمجية أو المواضيع أو الملفات أو المحادثات أو المواصفات. يدعم المخططات الانسيابية، ومخططات التسلسل، ومخططات الفصل، ومخططات الحالة، ومخططات ER، وهندسة C4، والخرائط الذهنية، ومخططات جانت، والجداول الزمنية، ورحلات المستخدم، وgitGraphs، والمخططات الدائرية، والمخططات الرباعية، ومخططات المتطلبات، وأنواع بيتا (xychart، وsankey، وblock، والهندسة المعمارية). استخدمه عندما يُطلب منك إنشاء مخطط حورية البحر، أو تصور عملية أو نظام، أو رسم مخطط انسيابي، أو مخطط تسلسلي، أو مخطط فصلي، أو آلة الحالة، أو ERD، أو مخطط معماري، أو خريطة ذهنية، أو مخطط زمني، أو مخطط جانت، أو رحلة المستخدم، أو رسم بياني متفرع لـ git، أو أي طلب "رسم تخطيطي لهذا".
