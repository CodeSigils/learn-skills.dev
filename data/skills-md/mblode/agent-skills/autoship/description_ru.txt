Автоматизирует рабочие процессы выпуска npm с помощью наборов изменений. Создает набор изменений (патч по умолчанию), записывает запись в журнал изменений, исправляет проблемы с lint/test/typecheck/format, фиксирует и отправляет, отслеживает CI с помощью запланированных задач, находит и объединяет PR пакетов версий и наблюдает за завершением рабочего процесса npm-publish. Используйте, когда пользователь запрашивает отправку, выпуск, публикацию, автоматическую отправку или вырезание выпуска для пакета npm.
