أتمتة سير عمل إصدار npm باستخدام مجموعات التغييرات. ينشئ مجموعة تغييرات (التصحيح الافتراضي)، ويكتب إدخال سجل التغيير، ويصلح مشكلات الوبر/الاختبار/التحقق من النوع/التنسيق، ويلتزم ويدفع، ويراقب CI عبر المهام المجدولة، ويبحث عن العلاقات العامة لحزم الإصدار ويدمجها، ويراقب سير عمل نشر npm حتى الاكتمال. يُستخدم عندما يطلب المستخدم شحن إصدار لحزمة npm أو إصداره أو نشره أو شحنه تلقائيًا أو قصه.
