Automatiza los flujos de trabajo de lanzamiento de npm utilizando conjuntos de cambios. Crea un conjunto de cambios (parche predeterminado), escribe una entrada de registro de cambios, soluciona problemas de pelusa/prueba/verificación de tipo/formato, confirma y envía, monitorea CI a través de tareas programadas, encuentra y fusiona el PR de paquetes de versión y observa el flujo de trabajo de publicación de npm hasta su finalización. Úselo cuando el usuario solicite enviar, liberar, publicar, enviar automáticamente o cortar un lanzamiento para un paquete npm.
