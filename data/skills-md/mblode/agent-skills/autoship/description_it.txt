Automatizza i flussi di lavoro di rilascio npm utilizzando i changeset. Crea un set di modifiche (patch predefinita), scrive una voce nel log delle modifiche, risolve i problemi di lint/test/typecheck/format, esegue commit e push, monitora l'elemento CI tramite attività pianificate, trova e unisce il PR dei pacchetti di versione e osserva il flusso di lavoro npm-publish fino al completamento. Da utilizzare quando l'utente chiede di spedire, rilasciare, pubblicare, spedire automaticamente o tagliare una versione per un pacchetto npm.
