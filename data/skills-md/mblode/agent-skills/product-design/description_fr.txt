Décide ce qu'une interface doit faire avant la création ou l'audit de l'interface utilisateur : choix d'interaction, portée et conséquences de l'action, états accessibles, résilience et accessibilité lors de l'achèvement des tâches. Fonctionne à partir d'un brief, d'une spécification, d'une maquette, d'une intention ou d'une interface utilisateur existante. À utiliser lorsqu'on lui demande "est-ce la bonne interaction", "concevoir le flux", "quel contrôle cela devrait-il utiliser", "qu'est-ce que cette action devrait affecter", "quels états cela devrait-il avoir", "rendre cela résilient" ou "qu'est-ce qui se casse ici". Pour la construction ou le style, utilisez ui-design ; pour les audits de code intégré, utilisez ui-audit ; pour le texte de la copie, utilisez le copywriting.
