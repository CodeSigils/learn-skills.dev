Decide qué debe hacer una interfaz antes de crear o auditar la interfaz de usuario: elección de interacción, alcance y consecuencia de la acción, estados alcanzables, resiliencia y accesibilidad como finalización de la tarea. Funciona a partir de una interfaz de usuario breve, de especificación, de maqueta, de intención o existente. Úselo cuando se le pregunte "¿es esta la interacción correcta?", "diseñar el flujo", "qué control debería usar", "qué debería afectar esta acción", "qué estados debería tener", "hacerlo resiliente" o "qué se rompe aquí". Para construir o diseñar, utilice ui-design; para auditorías de código integrado, utilice ui-audit; para copiar textos, utilice redacción publicitaria.
