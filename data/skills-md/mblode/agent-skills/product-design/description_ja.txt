UI が構築または監査される前にインターフェイスが何をすべきかを決定します。つまり、インタラクションの選択、アクションの範囲と結果、到達可能な状態、復元力、タスク完了時のアクセシビリティなどです。概要、仕様、モックアップ、インテント、または既存の UI から動作します。 「これは正しいインタラクションか」、「フローを設計する」、「どのコントロールを使用する必要があるか」、「このアクションが何に影響を与える必要があるか」、「どの状態を持つ必要があるか」、「これを回復力のあるものにするか」、または「ここで何が壊れるか」を尋ねられたときに使用します。構築またはスタイリングには ui-design を使用します。ビルドされたコードの監査には ui-audit を使用します。コピーの文言にはコピーライティングを使用します。
