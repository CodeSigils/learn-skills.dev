Crea un árbol de trabajo git desde main para un problema lineal. Úselo cuando el usuario pegue una URL lineal (https://linear.app/.../issue/ABC-58/...), una cadena lineal "copiar como mensaje" o simplemente un ID de problema como "ABC-58". Maneja el análisis de URL, la derivación de nombres de sucursales y la creación de árboles de trabajo como un directorio hermano. Utilícelo también cuando se le solicite "crear un árbol de trabajo para ABC-58", "configurar una rama para este problema" o "crear un árbol de trabajo".
