Erstellt einen Git-Arbeitsbaum aus Main für ein lineares Problem. Verwenden Sie diese Option, wenn der Benutzer eine lineare URL (https://linear.app/.../issue/ABC-58/...), eine lineare Zeichenfolge „Als Eingabeaufforderung kopieren“ oder einfach eine Problem-ID wie „ABC-58“ einfügt. Verarbeitet das URL-Parsing, die Ableitung des Zweignamens und die Erstellung des Arbeitsbaums als Geschwisterverzeichnis. Verwenden Sie es auch, wenn Sie aufgefordert werden, „einen Arbeitsbaum für ABC-58 zu erstellen“, „einen Zweig für dieses Problem einzurichten“ oder „einen Arbeitsbaum zu erstellen“.
