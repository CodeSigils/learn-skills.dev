Crée un arbre de travail git à partir de main pour un problème linéaire. À utiliser lorsque l'utilisateur colle une URL linéaire (https://linear.app/.../issue/ABC-58/...), une chaîne linéaire « copier comme invite » ou simplement un ID de problème tel que « ABC-58 ». Gère l'analyse des URL, la dérivation du nom de branche et la création d'un arbre de travail en tant que répertoire frère. À utiliser également lorsqu'on vous demande de « créer un arbre de travail pour ABC-58 », de « créer une branche pour ce problème » ou de « créer un arbre de travail ».
