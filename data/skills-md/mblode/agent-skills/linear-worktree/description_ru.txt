Создает рабочее дерево git из main для линейной проблемы. Используйте, когда пользователь вставляет линейный URL-адрес (https://linear.app/.../issue/ABC-58/...), линейную строку «скопировать как приглашение» или просто идентификатор проблемы, например «ABC-58». Выполняет анализ URL-адресов, получение имен ветвей и создание рабочего дерева как родственного каталога. Также используйте, когда вас просят «создать рабочее дерево для ABC-58», «создать ветку для этой проблемы» или «создать рабочее дерево».
