Effectue l'ingénierie inverse d'une animation d'interface utilisateur à partir d'un enregistrement d'écran : extrait les images, suit le mouvement par image, ajuste les courbes d'assouplissement et de ressort, annote la chorégraphie et émet du code CSS, Motion/Framer Motion, SwiftUI, React Native ou UIKit. À utiliser lorsque l'utilisateur partage ou télécharge un enregistrement d'écran ou une vidéo d'une animation d'interface utilisateur, ou demande de « procéder à l'ingénierie inverse de cette animation », « recréer cette animation », « faire correspondre cet assouplissement », « extraire la courbe d'animation », « comprendre le ressort de cette vidéo », « copier cette transition à partir d'une vidéo », « comment fonctionne cette animation » ou « reproduire ce mouvement ».
