Выполняет реверс-инжиниринг анимации пользовательского интерфейса из записи экрана — извлекает кадры, отслеживает движение для каждого кадра, подгоняет плавные и упругие кривые, аннотирует хореографию и генерирует код CSS, Motion/Framer Motion, SwiftUI, React Native или UIKit. Используйте, когда пользователь делится или загружает запись экрана или видео анимации пользовательского интерфейса или просит «перепроектировать эту анимацию», «воссоздать эту анимацию», «сопоставить это замедление», «извлечь кривую анимации», «вычислить пружину из этого видео», «скопировать этот переход из видео», «как работает эта анимация» или «воспроизвести это движение».
