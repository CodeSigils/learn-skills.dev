画面記録から UI アニメーションをリバース エンジニアリングします。フレームを抽出し、フレームごとのモーションを追跡し、イージング カーブとスプリング カーブをフィットさせ、振り付けに注釈を付け、CSS、モーション/フレーマー モーション、SwiftUI、React Native、または UIKit コードを出力します。ユーザーが UI アニメーションの画面記録やビデオを共有またはアップロードする場合、または「このアニメーションをリバース エンジニアリングする」、「このアニメーションを再作成する」、「このイージングを一致させる」、「アニメーション カーブを抽出する」、「このビデオからスプリングを計算する」、「このトランジションをビデオからコピーする」、「このアニメーションはどのように機能するか」、「このモーションを再現する」などの要求を行う場合に使用します。
