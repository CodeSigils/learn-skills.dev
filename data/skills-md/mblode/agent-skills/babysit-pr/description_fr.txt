Surveille l'état des relations publiques selon un calendrier récurrent : fusionnez les conflits, les échecs CI/CD dans GitHub Actions, Buildkite, Vercel et Fly.io, examinez le tri et la résolution des commentaires et les notifications de préparation à la fusion. Fonctionne également comme un tri des commentaires en une seule fois. À utiliser lorsqu'on vous demande de garder un PR, de surveiller un PR, de surveiller le CI, de corriger les commentaires de PR, de résoudre les commentaires de révision, de trier les fils de discussion, de garder un PR vert, de gérer les conflits de fusion ou d'interroger l'état du PR.
