Monitora lo stato delle PR secondo una pianificazione ricorrente: unisci conflitti, errori CI/CD tra GitHub Actions, Buildkite, Vercel e Fly.io, esamina la classificazione e la risoluzione dei commenti e unisci le notifiche di disponibilità. Funziona anche come valutazione dei commenti one-shot. Utilizzare quando viene chiesto di fare da babysitter a un PR, guardare un PR, monitorare CI, correggere commenti PR, risolvere feedback di revisione, classificare thread di revisione, mantenere un PR verde, gestire conflitti di unione o sondare lo stato di PR.
