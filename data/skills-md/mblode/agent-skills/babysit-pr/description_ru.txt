Отслеживает состояние PR по регулярному графику: конфликты слияний, сбои CI/CD в GitHub Actions, Buildkite, Vercel и Fly.io, просмотр сортировки и разрешения комментариев, а также уведомления о готовности слияния. Также выполняется как одноразовая сортировка комментариев. Используйте, когда вас просят присмотреть за PR, посмотреть PR, отслеживать CI, исправлять комментарии PR, разрешать отзывы о рецензиях, сортировать ветки обзоров, сохранять зеленый PR, обрабатывать конфликты слияний или опросить статус PR.
