Supervisa el estado de las relaciones públicas en un cronograma recurrente: fusiona conflictos, fallas de CI/CD en GitHub Actions, Buildkite, Vercel y Fly.io, revisa la clasificación y resolución de comentarios y fusiona notificaciones de preparación. También se ejecuta como clasificación de comentarios de una sola vez. Úselo cuando se le solicite cuidar un PR, observar un PR, monitorear CI, corregir comentarios de PR, resolver comentarios de revisión, clasificar hilos de revisión, mantener un PR verde, manejar conflictos de fusión o sondear el estado de un PR.
