مراقبة صحة العلاقات العامة وفقًا لجدول زمني متكرر - دمج التعارضات، وفشل CI/CD عبر GitHub Actions، وBuildkite، وVercel، وFly.io، ومراجعة فرز التعليقات وحلها، ودمج إشعارات الاستعداد. يعمل أيضًا كفرز للتعليقات من لقطة واحدة. استخدمه عند مطالبتك بمجالسة العلاقات العامة، أو مشاهدة العلاقات العامة، أو مراقبة CI، أو إصلاح تعليقات العلاقات العامة، أو حل تعليقات المراجعة، أو فرز سلاسل المراجعة، أو الحفاظ على العلاقات العامة الخضراء، أو التعامل مع تعارضات الدمج، أو استطلاع حالة العلاقات العامة.
