يكتب حديثًا أو مدونة أو منشورًا أو محادثة أو عنوان URL أو ملف PDF أو صورة أو ملفًا في ملف تخفيض السعر، ويُعاد قراءته في الدور التالي كسياق، وليس ملخصًا للدردشة أو محادثة تخمينية. يُستخدم عندما يقول المستخدم "احفظ هذا" أو "احفظ هذه المقالة" أو "حوّل هذا" أو "احتفظ بهذا المصدر" أو "احصل على تخفيض السعر" أو "انسخ هذا" أو "استخرج ملف PDF هذا" أو "حوّل هذا إلى تخفيض السعر". لا تستخدمه عندما يستشهدون بعنوان URL كسياق لمهمة الترميز. استخدم الضفيرة والرؤية والقراءة والكتابة والصدفة. اكتب في دليل العمل أو المسار الذي أطلقوا عليه اسم. لا تترك النتيجة إلا في الدردشة. لا تلخيص المصدر بعيدا. لا تخترع نسخة يوتيوب من بيانات التدريب. لا تطلب مفاتيح واجهة برمجة التطبيقات (API) أو تثبت واجهة سطر الأوامر (CLI). لا تتصل بـ Firecrawl أو OpenAI حتى إذا تم تعيين المفاتيح بالفعل.
