Записывает беседу, блог, публикацию, беседу, URL-адрес, PDF-файл, изображение или файл в файл уценки, который на следующем этапе перечитывается как контекст, а не как сводка чата или предполагаемый разговор. Используйте, когда пользователь говорит «сохраните это», «сохраните эту статью», «конвертируйте это», «сохраните этот исходный код», «получите уценку», «расшифруйте это», «извлеките этот PDF-файл» или «превратите это в уценку». Не используйте, когда URL-адрес цитируется в качестве контекста для задачи кодирования. Используйте Curl, Vision, Read, Write и Shell. Запишите рабочий каталог или путь, который они назвали. Не оставляйте результат только в чате. Не суммируйте источник. Не придумывайте расшифровку YouTube из обучающих данных. Не запрашивайте ключи API и не устанавливайте CLI. Не вызывайте Firecrawl или OpenAI, даже если ключи уже установлены.
