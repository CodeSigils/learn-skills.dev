Écrit une discussion, un blog, un article, une conversation, une URL, un PDF, une image ou un fichier dans un fichier markdown que le prochain tour relit comme contexte, et non comme un résumé de discussion ou une discussion devinée. À utiliser lorsque l'utilisateur dit « enregistrer ceci », « enregistrer cet article », « convertir ceci », « conserver cette source », « obtenir la démarque », « transcrire ceci », « extraire ce PDF » ou « transformer ceci en démarque ». Ne pas utiliser lorsqu'ils citent une URL comme contexte pour une tâche de codage. Utilisez curl, vision, lecture, écriture et shell. Écrivez dans le répertoire de travail ou le chemin qu'ils ont nommé. Ne laissez pas le résultat uniquement dans le chat. Ne résumez pas la source. N'inventez pas une transcription YouTube à partir des données de formation. Ne demandez pas de clés API et n’installez pas de CLI. N'appelez pas Firecrawl ou OpenAI même si les clés sont déjà définies.
