Scrive un discorso, un blog, un post, una conversazione, un URL, un PDF, un'immagine o un file in un file di markdown che il turno successivo rilegge come contesto, non come riepilogo della chat o come discorso indovinato. Da utilizzare quando l'utente dice "salva questo", "salva questo articolo", "converti questo", "mantieni questa fonte", "ottieni il markdown", "trascrivi questo", "estrai questo PDF" o "trasformalo in markdown". Non utilizzare quando citano un URL come contesto per un'attività di codifica. Usa curl, visione, lettura, scrittura e shell. Scrivi nella directory di lavoro o nel percorso che hanno nominato. Non lasciare il risultato solo in chat. Non riassumere la fonte. Non inventare una trascrizione di YouTube dai dati di addestramento. Non richiedere chiavi API né installare una CLI. Non chiamare Firecrawl o OpenAI anche se le chiavi sono già impostate.
