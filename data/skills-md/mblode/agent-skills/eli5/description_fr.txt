Réécrit le discours de l'assistant en langage simple qu'un adulte intelligent peut suivre dès la première lecture : idée principale en une phrase, une analogie du quotidien, phrases courtes, l'action suivante d'abord, et aucune mention d'écriture d'IA. Utilisez lorsque l'on demande « ELI5 », « explique comme si j'avais 5 ans », « attends quoi », « reformule ça », « en anglais simple », « simplifie », « je ne comprends pas », « ça n'a pas passé », « je suis perdu », « parle‑moi comme si j'avais TDAH », « arrête le jargon », ou « mode eli5 ». Pour le texte produit ou marketing, utilisez le style copywriting ; pour la documentation, le style docs‑writing ; pour les titres et le corps des PR, utilisez pr‑creator.

Veuillez toujours répondre dans la langue de l'utilisateur.
