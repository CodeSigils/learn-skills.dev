ينشئ طلبات سحب GitHub بأوصاف قصيرة تبدو بشرية. يضيف بادئة معرف الإصدار الخطي عندما يكون ذلك متاحًا، ويبقي العناوين أقل من 60 حرفًا، والإعداد الافتراضي لفقرة قصيرة واحدة بدلاً من الملخصات التي تم إنشاؤها أو أقسام خطة الاختبار. يعيد هيكلة سجل الالتزام الصاخب إلى ترتيب قابل للمراجعة ويضيف إرشادات المراجع للاختلافات الكبيرة. يُستخدم عند "إنشاء علاقات عامة" أو "إنشاء علاقات عامة" أو "فتح طلب سحب" أو "العلاقات العامة هذه" أو "شحنها" أو "جعل هذه العلاقات العامة سهلة المراجعة" أو "تلميع هذه العلاقات العامة" أو "ترتيب العلاقات العامة" أو "تنفيذ الالتزامات" أو "إعادة الهيكلة" أو "تقسيم هذه العلاقات العامة". لمراجعة الفرق بحثًا عن الأخطاء، استخدم pr-reviewer. لمراقبة العلاقات العامة بعد الإنشاء، استخدم pr-babysitter. بالنسبة لإصدارات npm، استخدم autoship.
