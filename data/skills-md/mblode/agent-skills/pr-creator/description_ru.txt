Создает запросы на извлечение GitHub с короткими, понятными человеку описаниями. Добавляет префикс идентификатора линейной проблемы, если он доступен, сохраняет заголовки длиной менее 60 символов и по умолчанию использует один короткий абзац вместо созданных сводок или разделов плана тестирования. Реструктурирует шумную историю коммитов в проверяемый порядок и добавляет рекомендации для рецензентов для больших различий. Используйте, когда «создать PR», «сделать PR», «открыть запрос на включение», «PR это», «отправить», «сделать этот PR удобным для просмотра», «отполировать этот PR», «привести в порядок PR», «очистить коммиты», «реструктурировать коммиты» или «разделить этот PR». Для проверки различий на наличие ошибок используйте pr-reviewer. Для мониторинга PR после создания используйте pr-babysitter. Для выпусков npm используйте autoship.
