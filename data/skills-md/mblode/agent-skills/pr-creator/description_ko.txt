"PR 만들기", "PR 만들기", "풀 요청 열기", "PR 이 PR", "배송", "이 PR을 검토하기 쉽게 만들기", "이 PR 다듬기", "PR 정리", "커밋 정리", "커밋 재구성" 또는 "이 PR 분할"할 때 사용하세요. 버그에 대한 차이점을 검토하려면 pr-reviewer를 사용하세요.
