Crea richieste pull GitHub con descrizioni brevi e dal suono umano. Aggiunge un prefisso ID problema lineare quando disponibile, mantiene i titoli sotto i 60 caratteri e per impostazione predefinita utilizza un paragrafo breve invece dei riepiloghi generati o delle sezioni del piano di test. Ristruttura la cronologia dei commit rumorosi in ordine rivedibile e aggiunge indicazioni al revisore per differenze di grandi dimensioni. Da utilizzare quando "crea un PR", "crea un PR", "apri una richiesta pull", "PR questo", "spediscilo", "rendi questo PR facile da rivedere", "lucida questo PR", "riordina il PR", "ripulisci i commit", "ristruttura i commit" o "dividi questo PR". Per rivedere un differenziale per individuare eventuali bug, utilizzare pr-reviewer. Per monitorare un PR dopo la creazione, usa pr-babysitter. Per le versioni npm, utilizzare la spedizione automatica.
