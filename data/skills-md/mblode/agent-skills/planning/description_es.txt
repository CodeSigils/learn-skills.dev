Crea y prueba planes de implementación en dos modos. El modo Crear escanea códigos y documentos, hace una pregunta a la vez con una respuesta recomendada y luego escribe un archivo de plan. El modo de revisión califica la integridad, la viabilidad, el alcance, la capacidad de prueba, el riesgo y las suposiciones, verifica las afirmaciones verificables y escribe las resoluciones hasta que cada dimensión alcance 5/5. Úselo cuando se le solicite "crear un plan", "planificar esta característica", "Quiero construir X", "preguntarme", "pensar esto", "revisar mi plan", "evadir esto", "realizar una prueba de estrés de este plan", "está listo este plan", "llevar este plan a 5/5", "qué me falta", "verificar esta afirmación", "probar este plan", "verificar los hechos de este plan" o cuando el usuario desea explícitamente un artefacto del plan antes de su implementación. Para revisar el código, utilice pr-reviewer; para resúmenes de arquitectura utilice define-arquitectura.
