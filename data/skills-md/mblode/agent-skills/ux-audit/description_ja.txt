React/Next.js コードの機能レベルの UX 監査。 Lighthouse、axe、ESLint、Storybook が見逃しているもの、つまり状態カバレッジのギャップ (読み込みの欠落/空/エラー)、検証時のフォーム データの損失、フォーカス管理の破損、ロールバックのない楽観的な UI、スケルトンによるレイアウトの変更、あいまいなマイクロコピー、その他 25 以上の最新のフロントエンド UX バグを捕捉します。 Diff-aware (変更されたファイルのみを監査) で、最新の React 19 API (useActionState、useFormStatus、useOptimistic、useTransition、Suspense) を使用した具体的な修正とともに、サーフェスごとにグループ化された 3 層の出荷準備状況判定 (release-blocker / fix-this-sprint / backlog) を生成します。フロントエンド PR をマージする前、機能を出荷する前、または「このチェックアウト/オンボーディング/ダッシュボードの準備はできていますか?」、「UX のバグがないかこの PR を確認してください」、「このコンポーネントを監査してください」、「本番環境で何が問題になるでしょうか?」、「これは出荷する準備ができていますか?」と尋ねられたときに使用します。
