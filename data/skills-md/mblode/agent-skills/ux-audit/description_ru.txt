UX-аудит на уровне функций для кода React/Next.js. Улавливает то, чего не хватает Lighthouse, Axe, ESLint и Storybook — пробелы в покрытии состояния (отсутствует загрузка/пусто/ошибка), потеря данных формы при проверке, нарушенное управление фокусом, оптимистичный пользовательский интерфейс без отката, сдвиг макета, вызванный скелетированием, расплывчатая микрокопия и более 25 других ошибок современного пользовательского интерфейса. С учетом различий (проверяет только измененные файлы) и выдает трехуровневый вердикт о готовности к выпуску (блокировщик выпуска / исправление этого спринта / журнал невыполненной работы), сгруппированный по поверхности, с конкретными исправлениями с использованием современных API-интерфейсов React 19 (useActionState, useFormStatus, useOptimistic, useTransition, Suspense). Используйте перед объединением PR-заявки на внешний интерфейс, перед отправкой функции или при вопросе «Готов ли этот запрос/адаптация/панель мониторинга?», «Проверьте этот PR на наличие ошибок UX», «Проведите аудит этого компонента», «Что может сломаться в производстве?», «Готово ли это к выпуску?»
