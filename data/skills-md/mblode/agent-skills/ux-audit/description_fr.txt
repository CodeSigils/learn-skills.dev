Audit UX au niveau des fonctionnalités pour le code React/Next.js. Capture ce que Lighthouse, Axe, ESLint et Storybook manquent : lacunes de couverture d'état (chargement manquant/vide/erreur), perte de données de formulaire lors de la validation, gestion du focus interrompue, interface utilisateur optimiste sans restauration, changement de disposition induit par le squelette, microcopie vague et plus de 25 autres bugs UX frontend modernes. Prise en compte des différences (audite uniquement les fichiers modifiés) et produit un verdict de préparation à la livraison à 3 niveaux (release-blocker / fix-this-sprint / backlog) regroupé par surface, avec des correctifs concrets utilisant les API React 19 modernes (useActionState, useFormStatus, useOptimistic, useTransition, Suspense). À utiliser avant de fusionner un PR frontend, avant d'expédier une fonctionnalité, ou lorsqu'on vous demande « ce paiement/intégration/tableau de bord est-il prêt ?
