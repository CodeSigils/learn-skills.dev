React/Next.js 程式碼的功能級 UX 審核。捕捉 Lighthouse、axe、ESLint 和 Storybook 所遺漏的內容 — 狀態覆蓋差距（缺少載入/空白/錯誤）、驗證時表單資料遺失、焦點管理損壞、無回滾的樂觀 UI、骨架引起的佈局變更、模糊的微複製以及 25 多個其他現代前端 UX 錯誤。 Diff-aware（僅審核更改的檔案）並產生按表面分組的 3 層交付就緒判定（release-blocker / fix-this-sprint / backlog），並使用現代 React 19 API（useActionState、useFormStatus、useOptimistic、useTransition、Suspense）進行具體修復。在合併前端 PR 之前、發布某個功能之前，或者當被問到“這個結帳/入職/儀表板準備好了嗎？”、“檢查這個 PR 是否存在 UX bug”、“審核這個組件”、“生產中會出現什麼問題？”、“這個準備好發布了嗎？”時使用。
