Auditoría de UX a nivel de funciones para el código React/Next.js. Detecta lo que Lighthouse, axe, ESLint y Storybook pasan por alto: brechas de cobertura de estado (falta carga/vacío/error), pérdida de datos de formulario durante la validación, administración de enfoque interrumpida, interfaz de usuario optimista sin reversión, cambio de diseño inducido por el esqueleto, microcopia vaga y más de 25 errores de UX de interfaz moderna. Tiene en cuenta las diferencias (solo audita archivos modificados) y produce un veredicto de preparación del envío de 3 niveles (bloqueador de liberación/arreglar este sprint/acumulación de pedidos) agrupado por superficie, con correcciones concretas utilizando las API modernas de React 19 (useActionState, useFormStatus, useOptimistic, useTransition, Suspense). Úselo antes de fusionar un PR de frontend, antes de enviar una función o cuando se le pregunte "¿está listo este proceso de pago/incorporación/panel?", "revise este PR para detectar errores de UX", "audite este componente", "¿qué se interrumpiría en la producción?", "¿está listo para enviarse?"
