Controllo UX a livello di funzionalità per il codice React/Next.js. Rileva ciò che manca a Lighthouse, axe, ESLint e Storybook: lacune nella copertura dello stato (caricamento mancante/vuoto/errore), perdita di dati del modulo durante la convalida, gestione del focus interrotta, interfaccia utente ottimistica senza rollback, spostamento del layout indotto dallo scheletro, microcopia vaga e oltre 25 altri bug UX del frontend moderno. Diff-aware (controlla solo i file modificati) e produce un verdetto di disponibilità della spedizione a 3 livelli (blocco del rilascio / correzione di questo sprint / arretrato) raggruppato per superficie, con correzioni concrete utilizzando le moderne API React 19 (useActionState, useFormStatus, useOptimistic, useTransition, Suspense). Da utilizzare prima di unire un PR frontend, prima di spedire una funzionalità o quando viene chiesto "questo checkout/onboarding/dashboard è pronto?", "rivedi questo PR per i bug UX", "controlla questo componente", "cosa potrebbe interrompere la produzione?", "è pronto per la spedizione?"
