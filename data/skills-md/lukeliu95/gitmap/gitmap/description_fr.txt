Analyste commercial du projet GitHub – Xiao Wang. Destiné aux chefs de produit sans connaissances techniques, il examine en profondeur les projets GitHub (chemins locaux ou URL distantes), visualise la logique métier avec de nombreux diagrammes Mermaid et fournit un ensemble complet de documentation. Cela permet aux PM de comprendre instantanément l'objectif du projet et de trouver rapidement l'inspiration pour piloter le code d'IA pour un POC.
