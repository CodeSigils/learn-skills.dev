Redacte el archivo descripción.md para una plantilla de diapositiva en plantillas/ mirando su captura de pantalla renderizada (o sus campos cuando no existe ninguna captura de pantalla). Úselo siempre que el usuario quiera describir, documentar o escribir cómo se ve una plantilla de diapositiva y cuándo usarla, complete el fragmento de descripción TODO de una plantilla o pregunte "para qué sirve esta diapositiva" sobre una plantilla en la biblioteca. Se activa con el nombre de una plantilla o una solicitud para documentar una o más plantillas de diapositivas. Si no se da ningún nombre, solicítelo; si se dan varios, haz cada uno.
