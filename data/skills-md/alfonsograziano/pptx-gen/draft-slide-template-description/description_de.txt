Entwerfen Sie die Beschreibung.md für eine Folienvorlage in templates/, indem Sie sich den gerenderten Screenshot ansehen (oder seine Felder, wenn kein Screenshot vorhanden ist). Verwenden Sie es immer dann, wenn der Benutzer beschreiben, dokumentieren oder aufschreiben möchte, wie eine Folienvorlage aussieht und wann sie verwendet werden soll, den TODO-Beschreibungs-Stub einer Vorlage ausfüllen oder zu einer Vorlage in der Bibliothek fragen möchte, „wofür diese Folie gedacht ist“. Wird durch einen Vorlagennamen oder eine Anforderung zum Dokumentieren einer oder mehrerer Folienvorlagen ausgelöst. Wenn kein Name angegeben ist, fragen Sie danach; Wenn mehrere angegeben sind, machen Sie jedes einzelne.
