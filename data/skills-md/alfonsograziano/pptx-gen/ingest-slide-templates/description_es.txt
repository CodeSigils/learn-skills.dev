Incorpore una o más diapositivas de una plataforma de PowerPoint a la biblioteca de plantillas pptx-gen y documente cada una. Úselo cuando el usuario proporciona un archivo .pptx de origen (a menudo una sola diapositiva o una presentación descargada de Presentaciones de Google) más una lista de números de diapositivas y un nombre de plantilla, y solicita importar, ingerir o agregar diapositivas como plantillas reutilizables en plantillas/. Ejecuta la CLI de ingesta para cada diapositiva y luego ejecuta el flujo de trabajo borrador-diapositiva-plantilla-descripción en cada plantilla importada para que se envíe con una descripción real en lugar de un código auxiliar TODO.
