Genere un plan de implementación PLAN.md a partir de un archivo SPEC.md. Úselo cuando el usuario quiera planificar la implementación de una especificación, diga "[P]" después de crear una especificación o solicite crear un plan de implementación. El plan traduce el "qué" de la especificación en un "cómo" técnico (enfoque, compensaciones, secuenciación y una lista de verificación de tareas) sin escribir ningún código. Se activa cada vez que alguien dice "planeemos esto", "creemos un plan para", "planifiquemos la implementación" o proporcione una ruta de especificación y quiera pasar a la fase de planificación.
