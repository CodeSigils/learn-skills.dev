Generieren Sie einen PLAN.md-Implementierungsplan aus einer SPEC.md-Datei. Verwenden Sie diese Option, wenn der Benutzer die Implementierung einer Spezifikation planen möchte, nach dem Erstellen einer Spezifikation „[P]“ sagt oder um die Erstellung eines Implementierungsplans bittet. Der Plan übersetzt das „Was“ der Spezifikation in ein technisches „Wie“ – Ansatz, Kompromisse, Reihenfolge und eine Aufgabencheckliste –, ohne Code zu schreiben. Wird immer dann ausgelöst, wenn jemand sagt: „Planen wir das“, „Erstellen Sie einen Plan für“, „Planen Sie die Implementierung“ oder gibt einen Spezifikationspfad an und möchte zur Planungsphase übergehen.
