Cree o actualice un archivo CONSTITUTION.md en la carpeta specs/ escaneando el proyecto. La constitución captura el contexto de todo el proyecto del que dependen todas las demás habilidades de nanoespecificación, como la pila tecnológica, los comandos de verificación de cordura, las convenciones de codificación, los archivos clave y las reglas estrictas. Úselo cuando el usuario desee configurar nano-especificaciones para un nuevo proyecto, inicializar la constitución o mantenerla actualizada. Se activa cuando el usuario dice cosas como "crear la constitución", "configurar la constitución del proyecto", "inicializar nano-spec" o "actualizar la constitución".
