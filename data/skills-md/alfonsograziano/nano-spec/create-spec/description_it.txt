Crea un file SPEC.md per una nuova funzionalità, prodotto o sistema utilizzando l'approccio SDD (Spec-Driven Development). Le specifiche funzionano nell'ambito del problema: chiariscono il "cosa", non il "come". Utilizza questa competenza ogni volta che l'utente desidera scrivere una specifica, definire requisiti, acquisire ciò che deve essere creato, creare un documento di specifica o avviare il flusso di lavoro SDD. Si attiva anche se l'utente dice cose come "specificiamolo", "voglio definire cosa stiamo costruendo", "aiutami a riflettere sui requisiti" o "scriviamo una specifica per X".
