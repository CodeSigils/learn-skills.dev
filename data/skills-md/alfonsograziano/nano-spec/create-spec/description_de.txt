Erstellen Sie mithilfe des Spec-Driven Development (SDD)-Ansatzes eine SPEC.md-Datei für eine neue Funktion, ein neues Produkt oder ein neues System. Die Spezifikation arbeitet im Problembereich – sie klärt das „Was“, nicht das „Wie“. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Spezifikation schreiben, Anforderungen definieren, erfassen möchte, was gebaut werden muss, ein Spezifikationsdokument erstellen oder den SDD-Workflow starten möchte. Wird auch dann ausgelöst, wenn der Benutzer Dinge sagt wie „Lass uns das spezifizieren“, „Ich möchte definieren, was wir bauen“, „Hilf mir, die Anforderungen zu durchdenken“ oder „Lass uns eine Spezifikation für X schreiben“.
