Cree un archivo SPEC.md para una nueva función, producto o sistema utilizando el enfoque de desarrollo basado en especificaciones (SDD). La especificación funciona en el espacio del problema: aclara el "qué", no el "cómo". Utilice esta habilidad siempre que el usuario quiera escribir una especificación, definir requisitos, capturar lo que se debe construir, crear un documento de especificación o iniciar el flujo de trabajo SDD. Se activa incluso si el usuario dice cosas como "especifiquemos esto", "quiero definir lo que estamos construyendo", "ayúdame a pensar en los requisitos" o "escribamos una especificación para X".
