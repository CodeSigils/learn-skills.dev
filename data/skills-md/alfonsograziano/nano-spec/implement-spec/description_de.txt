Implementieren Sie eine Spezifikation aus einem specs/-Ordner und folgen Sie dabei der Aufgabenliste PLAN.md, falls vorhanden. Verwenden Sie diese Option, wenn der Benutzer mit dem Codieren beginnen möchte, „[I]“ sagt, nachdem er eine Spezifikation oder einen Plan überprüft hat, einen Spezifikationsordnernamen angibt und eine Implementierung wünscht oder Dinge sagt wie „Lasst uns das implementieren“, „mit dem Codieren beginnen“, „den Plan implementieren“ oder „das erstellen“. Wird immer ausgelöst, wenn ein Spezifikationsordnerpfad und eine Implementierungsabsicht vorhanden sind, auch wenn der Benutzer nur „[I]“ oder „Los“ sagt.
