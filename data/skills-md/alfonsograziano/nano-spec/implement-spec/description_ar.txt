قم بتنفيذ المواصفات من مجلد المواصفات/، باتباع قائمة مهام PLAN.md إذا كانت موجودة. يُستخدم عندما يريد المستخدم بدء البرمجة، أو يقول "[I]" بعد مراجعة المواصفات أو الخطة، أو يقدم اسم مجلد المواصفات ويريد التنفيذ، أو يقول أشياء مثل "دعونا ننفذ هذا"، أو "نبدأ البرمجة"، أو "ننفذ الخطة"، أو "نبني هذا". يتم التشغيل دائمًا عندما يكون هناك مسار مجلد المواصفات وهدف التنفيذ، حتى لو قال المستخدم "[I]" أو "go" فقط.
