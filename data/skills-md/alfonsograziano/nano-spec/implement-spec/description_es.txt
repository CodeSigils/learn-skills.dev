Implemente una especificación desde una carpeta specs/, siguiendo la lista de tareas de PLAN.md si está presente. Úselo cuando el usuario quiera comenzar a codificar, diga "[I]" después de revisar una especificación o un plan, proporcione un nombre de carpeta de especificaciones y desee implementarla, o diga cosas como "implementemos esto", "comencemos a codificar", "implemente el plan" o "construya esto". Siempre se activa cuando hay una ruta de carpeta de especificaciones y una intención de implementación, incluso si el usuario simplemente dice "[I]" o "ir".
