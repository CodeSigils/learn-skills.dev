Algolia نمذجة البيانات وتوجيهات الفهرسة. استخدمه قبل أو بجانب فهرسة السجلات أو إنشاء واجهة مستخدم بحث Algolia للبحث في الشبكة الجديدة أو التصفح أو الإكمال التلقائي أو التجارة الإلكترونية أو التخصيص أو إعادة التصنيف الديناميكي أو التوصيات أو التطبيقات المدركة للتحليلات. يجعل شكل السجل ومعرف الكائن وحقول العرض والواجهات وحقول التصنيف وإسناد الحدث قرارات صريحة. يُستخدم للسجلات، والمتغيرات، ووحدات SKU، والمؤشرات، والنسخ المتماثلة، والسمات القابلة للبحث والواجهات، وإلغاء التسوية، وحقول الترويج، والطوابع الزمنية، والمخزون، وإسناد الأحداث، وخطوط أنابيب الفهرسة، والتحديثات الجزئية، والبيانات الآمنة، والاستراتيجيات متعددة اللغات أو المناطق، وعمليات الترحيل. لا تستخدم للاستيراد المباشر، أو التصدير، أو تسجيل التغييرات، أو تغييرات الإعدادات، أو إجراءات الحساب؛ استخدم algolia-cli أو algolia-mcp. لا تستخدم لتنفيذ واجهة المستخدم الأمامية؛ استخدم algolia-instant-ui-ui، أو algolia-autocomplete، أو algolia-ui-libraries، أو مهارة البحث الفوري الرسمية.
