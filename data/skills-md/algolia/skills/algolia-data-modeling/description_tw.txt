Algolia 資料建模和索引指南。在索引記錄或建立 Algolia 搜尋 UI 之前或同時使用，以實現全新的搜尋、瀏覽、自動完成、電子商務、個人化、動態重新排名、推薦或分析感知實作。做出記錄形狀、objectID、顯示欄位、面向、排名欄位和事件歸因的明確決策。用於記錄、變體、SKU、索引、副本、可搜尋和分面屬性、非規範化、銷售欄位、時間戳、庫存、事件歸因、索引管道、部分更新、安全資料、多語言或多區域策略以及遷移。請勿用於即時匯入、匯出、記錄突變、設定變更或帳戶操作；使用 algolia-cli 或 algolia-mcp。請勿用於前端 UI 實作；使用 algolia-instantsearch-ui、algolia-autocomplete、algolia-ui-libraries 或官方即時搜尋技能。
