Conseils pour la modélisation et l'indexation des données Algolia. À utiliser avant ou parallèlement à l'indexation des enregistrements ou à la création d'une interface utilisateur de recherche Algolia pour de nouvelles recherches, navigations, saisie semi-automatique, commerce électronique, personnalisation, reclassement dynamique, recommandations ou implémentations prenant en compte l'analyse. Rend les décisions explicites en matière de forme d'enregistrement, d'ID d'objet, de champs d'affichage, de facettes, de champs de classement et d'attribution d'événements. À utiliser pour les enregistrements, les variantes, les SKU, les index, les répliques, les attributs de recherche et de facettes, la dénormalisation, les champs de marchandisage, les horodatages, l'inventaire, l'attribution d'événements, les pipelines d'indexation, les mises à jour partielles, les données sécurisées, les stratégies multilingues ou multirégionales et les migrations. Ne PAS utiliser pour les importations, les exportations, les mutations d'enregistrement, les modifications de paramètres ou les actions de compte ; utilisez algolia-cli ou algolia-mcp. Ne PAS utiliser pour la mise en œuvre de l'interface utilisateur frontale ; utilisez algolia-instantsearch-ui, algolia-autocomplete, algolia-ui-libraries ou la compétence officielle de recherche instantanée.
