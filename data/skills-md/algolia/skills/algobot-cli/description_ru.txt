Используйте для всего ИИ/агента/разговора, построенного на Algolia: CLI algobot, Agent Studio, системы RAG, диалоговое обнаружение продуктов, генерация контента genAI из результатов поиска (карусели, описания, заголовки), чат-боты или агенты рекомендаций, использующие Algolia в качестве поиска, рабочие процессы конфигурации как кода, развертывание в нескольких средах (dev/staging/prod), память и персонализация, интеграция инструментов MCP, сохранение истории разговоров / GDPR или добавление виджет чата рядом с InstantSearch. Запуск по: «algobot», «Agent Studio», «RAG with Algolia», «опыт общения», «AI-агент» + Algolia, «карусель genAI», «виджет чата» или создание функций AI поверх поиска Algolia. НЕ используйте для операций с необработанным индексом (записи, синонимы, настройки) — используйте algolia-cli. НЕ используйте для чистого пользовательского интерфейса поиска (InstantSearch, автозаполнение) без слоя AI/агента.
