ユーザーが Algolia のインデックスまたはアカウントに対して操作 (レコードの削除、インデックスのコピー/移行、データのバックアップ、レコードのインポート/エクスポート、API キーの管理、シノニムの編集、ルールの構成、ファセットなどの設定の変更、インデックスのクリア、CI/CD パイプラインでの Algolia の自動化など) を実行する場合は常にこのスキルを使用します。重要なシグナルは、ユーザーが「CLI」または「コマンド ライン」について言及しているかどうかに関係なく、Algolia データまたは構成 (サーバー側 / バックエンド / 管理操作) に * 対応* したいということです。誰かが特定の Algolia インデックスに名前を付け、それを変更、移動、クエリ、または管理したい場合は、このスキルを使用します。フロントエンド検索 UI 作業 (InstantSearch、React コンポーネント、オートコンプリート ウィジェット)、Algolia ダッシュボード GUI の質問、または Algolia と他のプロバイダーの評価には使用しないでください。
