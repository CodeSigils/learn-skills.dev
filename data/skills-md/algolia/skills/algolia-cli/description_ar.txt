استخدم هذه المهارة عندما يريد المستخدم تنفيذ عمليات ضد مؤشرات أو حسابات Algolia - حذف السجلات، أو نسخ/ترحيل المؤشرات، أو النسخ الاحتياطي للبيانات، أو استيراد/تصدير السجلات، أو إدارة مفاتيح API، أو تحرير المرادفات، أو تكوين القواعد، أو تغيير الإعدادات مثل الواجهات، أو مسح المؤشرات، أو أتمتة Algolia في خطوط أنابيب CI/CD. الإشارة الأساسية هي أن المستخدم يريد *التصرف بناءً على* بيانات Algolia أو تكوينها (عمليات جانب الخادم/الواجهة الخلفية/المسؤول)، بغض النظر عما إذا كان يذكر "CLI" أو "سطر الأوامر". إذا قام شخص ما بتسمية فهرس Algolia محددًا وأراد تغييره أو نقله أو الاستعلام عنه أو إدارته، فاستخدم هذه المهارة. لا تستخدمه في عمل واجهة مستخدم البحث الأمامية (البحث الفوري، أو مكونات React، أو عناصر واجهة المستخدم للإكمال التلقائي)، أو أسئلة واجهة المستخدم الرسومية للوحة معلومات Algolia، أو تقييم Algolia مقابل مقدمي الخدمات الآخرين.
