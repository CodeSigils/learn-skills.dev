Utilice esta habilidad siempre que un usuario desee ejecutar operaciones contra índices o cuentas de Algolia: eliminar registros, copiar/migrar índices, realizar copias de seguridad de datos, importar/exportar registros, administrar claves API, editar sinónimos, configurar reglas, cambiar configuraciones como facetas, borrar índices o automatizar Algolia en canalizaciones de CI/CD. La señal clave es que el usuario quiere *actuar sobre* sus datos o configuración de Algolia (operaciones del lado del servidor/backend/administración), independientemente de si mencionan "CLI" o "línea de comando". Si alguien nombra un índice de Algolia específico y quiere cambiarlo, moverlo, consultarlo o administrarlo, utilice esta habilidad. NO lo utilice para el trabajo de la interfaz de usuario de búsqueda frontal (InstantSearch, componentes de React, widgets de autocompletar), preguntas sobre la GUI del panel de Algolia o para evaluar Algolia frente a otros proveedores.
