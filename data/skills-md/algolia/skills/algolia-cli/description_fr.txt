Utilisez cette compétence chaque fois qu'un utilisateur souhaite exécuter des opérations sur des index ou des comptes Algolia : suppression d'enregistrements, copie/migration d'index, sauvegarde de données, importation/exportation d'enregistrements, gestion de clés API, modification de synonymes, configuration de règles, modification de paramètres tels que des facettes, effacement d'index ou automatisation d'Algolia dans les pipelines CI/CD. Le signal clé est que l'utilisateur souhaite *agir sur* ses données ou sa configuration Algolia (opérations côté serveur/backend/administrateur), qu'il mentionne « CLI » ou « ligne de commande ». Si quelqu'un nomme un index Algolia spécifique et souhaite le modifier, le déplacer, l'interroger ou le gérer, utilisez cette compétence. Ne PAS utiliser pour le travail de l'interface utilisateur de recherche frontale (InstantSearch, composants React, widgets de saisie semi-automatique), les questions de l'interface graphique du tableau de bord Algolia ou l'évaluation d'Algolia par rapport à d'autres fournisseurs.
