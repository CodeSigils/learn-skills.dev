يحلل فرع العلاقات العامة المعتمد لإجراء تغييرات جديرة بالقواعد ويقترح قواعد الذكاء الاصطناعي الجديدة أو المحدثة عبر Cursor وClaude Code وGitHub Copilot. يُستخدم عند تحديث قواعد الذكاء الاصطناعي، أو التحقق من قواعد الفرع، أو تحديد ما إذا كان سيتم تحديث قواعد المؤشر/كلود/مساعد الطيار بعد العلاقات العامة.
