Redige e pubblica le voci delle note di rilascio su Confluence dopo l'approvazione di una PR. Classifica le modifiche in modifiche importanti, funzionalità, correzioni di bug ed elementi della pipeline utilizzando il formato canonico della nota di rilascio. Da utilizzare durante l'aggiornamento delle note sulla versione, la stesura delle note sulla versione o l'aggiunta di una voce alla nota sulla versione.
