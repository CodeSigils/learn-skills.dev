Erstellt mithilfe der gh-CLI eine Pull-Anfrage für den aktuellen Zweig. Extrahiert Ticketnummern aus Filialnamen, erstellt Titel und Beschreibung aus dem Diff- und Commit-Verlauf, pusht und öffnet die PR. Verwenden Sie diese Option, wenn Sie eine PR erstellen, eine Pull-Anfrage öffnen, Änderungen zur Überprüfung einreichen oder einen Zweig zur Überprüfung pushen.
