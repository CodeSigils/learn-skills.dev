Создает запрос на включение для текущей ветки с помощью gh CLI. Извлекает номера заявок из названий веток, создает заголовок и описание из истории различий и коммитов, отправляет и открывает PR. Используйте при создании запроса на включение, открытии запроса на включение, отправке изменений на проверку или отправке ветки на проверку.
