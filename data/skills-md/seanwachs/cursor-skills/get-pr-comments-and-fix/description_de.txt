Triage und bearbeite ungelöste PR-Bewertungskommentare. Behebt eindeutige Probleme (Festschreiben + Antworten), verwirft falsche Ergebnisse (Antworten mit Begründung) und stellt unsichere Elemente zur menschlichen Überprüfung bereit. Verwenden Sie diese Option, wenn der Benutzer PR-Kommentare korrigieren, Bewertungsfeedback ansprechen, PR-Threads auflösen oder Vorschläge von Copilot-Rezensenten bearbeiten möchte. Dadurch wird die Fähigkeit „Get-pr-Comments“ erweitert, indem auch auf Kommentare reagiert wird, anstatt sie nur zusammenzufassen.
