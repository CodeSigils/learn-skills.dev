Convenciones de proyecto compartidas, denominación de ramas, descripción general de la arquitectura y metadatos de Jira/GitHub para el proyecto AP (Plataforma de agente). Otras habilidades hacen referencia a este archivo para obtener un contexto transversal. Lea esta habilidad siempre que necesite comprender las convenciones del proyecto, el formato de las ramas, los prefijos de los tickets o la arquitectura de la base del código, especialmente antes de crear relaciones públicas, clasificar comentarios, desarrollar código o proponer actualizaciones de reglas de IA.
