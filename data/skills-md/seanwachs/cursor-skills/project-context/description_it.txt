Convenzioni di progetto condivise, denominazione dei rami, panoramica dell'architettura e metadati Jira/GitHub per il progetto AP (piattaforma agente). Altre competenze fanno riferimento a questo file per un contesto trasversale. Leggi questa Skill ogni volta che hai bisogno di comprendere le convenzioni del progetto, il formato dei rami, i prefissi dei ticket o l'architettura della base di codice, soprattutto prima di creare PR, valutare i commenti, eliminare il codice o proporre aggiornamenti delle regole AI.
