Analice las características del estilo de escritura de un artículo, extraiga las dimensiones del estilo y guárdelas en la biblioteca de materiales de estilo. Se pueden combinar varios materiales de estilo para generar o actualizar el archivo de estilo principal (my_style.json). Utilice esta habilidad cuando el usuario diga "analizar estilo", "extraer estilo de escritura", "aprender este tono", "analizar mi estilo de escritura", "absorber este estilo" o "actualizar mi estilo". Incluso si el usuario sólo comparte un artículo y expresa interés en su estilo, se debe considerar su uso.
