Analysieren Sie die Schreibstilmerkmale eines Artikels, extrahieren Sie Stildimensionen und speichern Sie sie in einer Stilmaterialbibliothek. Mehrere Stilmaterialien können zusammengeführt werden, um ein primäres Stilprofil (my_style.json) zu generieren oder zu aktualisieren. Verwenden Sie diese Funktion, wenn der Benutzer „Stil analysieren“, „Schreibstil extrahieren“, „diesen Ton lernen“, „meinen Schreibstil analysieren“, „diesen Stil absorbieren“ oder „meinen Stil aktualisieren“ sagt. Selbst wenn der Benutzer lediglich einen Artikel teilt und Interesse an seinem Stil bekundet, sollte eine Verwendung in Betracht gezogen werden.
