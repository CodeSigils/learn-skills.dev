Analysez les caractéristiques du style d'écriture d'un article, extrayez les dimensions du style et stockez-les dans une bibliothèque de matériaux de style. Plusieurs matériaux de style peuvent être fusionnés pour générer ou mettre à jour un profil de style principal (my_style.json). Utilisez cette fonctionnalité lorsque l'utilisateur dit « analyser le style », « extraire le style d'écriture », « apprendre ce ton », « analyser mon style d'écriture », « absorber ce style » ou « mettre à jour mon style ». Même si l’utilisateur partage simplement un article et exprime son intérêt pour son style, son utilisation doit être envisagée.
