تحليل خصائص أسلوب الكتابة للمقال، واستخراج أبعاد النمط وتخزينها في مكتبة مواد الأسلوب. يمكن دمج مواد الأنماط المتعددة لإنشاء أو تحديث ملف النمط الرئيسي (my_style.json). استخدم هذه الإمكانية عندما يقول المستخدم "تحليل الأسلوب" أو "استخراج أسلوب الكتابة" أو "تعلم هذه النغمة" أو "تحليل أسلوب كتابتي" أو "استيعاب هذا الأسلوب" أو "تحديث أسلوبي". حتى لو شارك المستخدم مقالًا فقط وأبدى اهتمامًا بأسلوبه، فيجب أخذه بعين الاعتبار للاستخدام.
