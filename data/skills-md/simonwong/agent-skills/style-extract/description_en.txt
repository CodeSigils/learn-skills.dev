Analyze the writing style characteristics of an article, extract style dimensions, and store them in a style material library. Multiple style materials can be merged to generate or update a primary style profile (my_style.json). Use this capability when the user says “analyze style,” “extract writing style,” “learn this tone,” “analyze my writing style,” “absorb this style,” or “update my style.” Even if the user merely shares an article and expresses interest in its style, it should be considered for use.
