Disassemble articles, extract reusable material (opinions, data, cases, memorable quotes, analogies, methodologies), categorize and label it, then store it in the material library. Use this capability when the user says “disassemble material,” “store,” “collect this article,” “extract material,” “analyze the key points of this article,” or provides an article hoping to retain valuable content. Even if the user merely shares an article and says “this one is good,” you should consider whether it needs to be stored.
