كتابة ومراجعة وصيانة وثائق البرامج وتعليقات التعليمات البرمجية التي تتوافق مع التعليمات البرمجية والعقود التي تشرحها وتساعد قارئًا معينًا على فهم النظام الحقيقي أو استخدامه أو تغييره أو تشغيله. يُستخدم عندما يغير التنفيذ السلوك الذي يعتمد عليه القراء؛ عند إنشاء أو تغيير ملفات README، أو أدلة الإعداد، أو البرامج التعليمية، أو الأدلة الإرشادية، أو المراجع، أو مستندات واجهة برمجة التطبيقات أو مستندات الهندسة المعمارية، أو دفاتر التشغيل، أو ملاحظات الترحيل، أو سلاسل المستندات، أو التعليقات المضمنة؛ عند تحديد ما يجب توثيقه وأين ينتمي؛ عند التحقق من الأوامر والأمثلة؛ أو عند إزالة الشرح القديم أو المضلل أو المتكرر.
