تحسين تجربة المطور عند فهم البرامج أو تصميمها أو كتابتها أو تغييرها أو مراجعتها أو اختبارها أو تصحيح الأخطاء أو إنشاءها أو توثيقها أو إصدارها أو صيانتها. يُستخدم عندما يتعين على Codex قراءة مشروع ما أو شرحه بدءًا من الغرض العام والهيكل وحتى التفاصيل المحلية، أو جعل التعليمات البرمجية جميلة وواضحة، أو تنظيم قاعدة التعليمات البرمجية، أو تشكيل واجهة برمجة التطبيقات (API)، أو واجهة سطر الأوامر (CLI)، أو التكوين، أو الخطأ، أو الأداة، أو تقليل الاحتكاك بين الإعداد أو التعليقات، أو تحسين المساهمة والمراجعة، أو الحكم على أي مقايضة تؤثر على كيفية فهم المطورين للنظام وتغييره والتحقق منه وتشغيله. تعامل مع المطورين كمستخدمين وقم بتحسين رحلتهم بأكملها دون التنازل عن الصحة أو السلامة أو سلوك المنتج.
