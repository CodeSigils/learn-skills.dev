Verbessern Sie die Entwicklererfahrung beim Verstehen, Entwerfen, Schreiben, Ändern, Überprüfen, Testen, Debuggen, Erstellen, Dokumentieren, Freigeben oder Warten von Software. Verwenden Sie Codex, wenn Codex ein Projekt vom allgemeinen Zweck und der Struktur bis hin zu lokalen Details lesen oder erläutern, Code schön und klar gestalten, eine Codebasis organisieren, eine API, CLI, Konfiguration, einen Fehler oder ein Tool gestalten, Reibungsverluste bei der Einrichtung oder Rückmeldung reduzieren, Beiträge und Überprüfungen verbessern oder Kompromisse beurteilen muss, die sich darauf auswirken, wie Entwickler ein System verstehen, ändern, überprüfen und betreiben. Behandeln Sie Entwickler als Benutzer und verbessern Sie ihre gesamte Reise, ohne auf Korrektheit, Sicherheit oder Produktverhalten zu verzichten.
