Verwenden Sie beim Entwerfen, Schreiben, Ändern, Überprüfen oder Debuggen von Code effektbewusstes Denken. Machen Sie beobachtbare Arbeit, Abhängigkeiten, Fehler, Zustandsänderungen, Ressourcenlebensdauer, Parallelität, Abbruch und Ausführungsgrenzen explizit. Befolgen Sie die vorhandenen Tools des Projekts, verwenden Sie den passenden Leitfaden für Effect oder ZIO, lernen Sie die genaue öffentliche API kennen, wenn eine Bibliothek beteiligt ist, behalten Sie die Bedeutung vom Entwurf bis zur Ausführung bei und überprüfen Sie das tatsächliche Verhalten. Wenn ein Wirkungssystem Eigentümer der Arbeit ist, behalten Sie alle darin unterstützten Funktionen bei und fordern Sie die ausdrückliche Zustimmung des Benutzers ein, bevor es zu unvermeidlichen, nicht wirksamen Ausbrüchen kommt.
