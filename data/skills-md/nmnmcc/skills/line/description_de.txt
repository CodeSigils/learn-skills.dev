Sorgen Sie dafür, dass alle benötigten Teile einer technischen Domäne einer klaren Regel folgen. Verwenden Sie diese Option, wenn eine Regel, ein gemeinsames Design, eine Schnittstelle, eine Migration oder eine Überprüfung mehrere Teile von Frontend, Backend, Daten, Infrastruktur, Tests, Sicherheit oder einer anderen einzelnen Domäne abdeckt und separate lokale Korrekturen unterschiedlich sein können. Verwenden Sie es mit Punkt für kleine Ursache-Wirkungs-Arbeiten. Verwenden Sie es mit Ebene, wenn die Regel Teil eines Ergebnisses ist, das technische Domänen überschreitet.
