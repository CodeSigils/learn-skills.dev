Destillieren, lehren, wiederverwenden und pflegen Sie projektspezifische Softwaremuster in einem Repository-Root-Muster/Katalog. Ein Muster ist eine lehrbare Beziehung zwischen einer wiederkehrenden Situation, ihren Spannungen, einer anpassungsfähigen Reaktion, ihren Konsequenzen und ihren Grenzen. Zum Verstehen, Entwerfen, Schreiben, Ändern, Überprüfen, Testen oder Veröffentlichen von Software verwenden; Anwenden eines etablierten Projektmusters; Konkrete Projekterfahrung in eine Kandidatenmusterhypothese umwandeln; Testübertragung auf einen anderen Fall; Zusammenführen oder Aufteilen zusammengehöriger Lektionen; oder veraltete Führung in den Ruhestand schicken. Behandeln Sie wiederholten Code, eine Regel, ein Rezept, eine Entscheidung, eine Abstraktion, ein Beispiel oder einen Fehler nicht als eigenständiges Muster.
