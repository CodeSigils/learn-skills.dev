تحسين أي منتج أو خدمة من وجهة نظر المستخدم. اتبع كل لمسة قبل وأثناء وبعد الاستخدام؛ التحقق من النتيجة، والكلمات، والشكل المرئي، والصوت، واللمس، والحركة، والانتظار، والاستجابة، والإعدادات المادية، والأشخاص، والثقة، والتأثيرات اللاحقة؛ وإزالة الأجزاء التي لا تساعد. يُستخدم عند إنشاء أو تغيير أو مراجعة أو إصلاح أي منتج أو ميزة أو تدفق أو شاشة أو واجهة برمجة تطبيقات أو رسالة أو رسوم متحركة أو حالة التحميل أو الإشعارات أو المساعدة أو الدفع أو مسار الدعم أو طريقة المغادرة، أو عند التحقق من السهولة أو الوصول أو العاطفة أو السلامة أو الخصوصية أو السرعة أو الموثوقية أو تغييرها أو مراجعتها أو إصلاحها.
