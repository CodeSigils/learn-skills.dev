Nehmen Sie eine kleine Softwareänderung vor, indem Sie deren Ursache ermitteln und klare Beweise erhalten. Verwenden Sie diese Option, wenn die gewünschte Änderung, der Teil, der sie verursacht, die Grenzen und die bestmögliche Prüfung lokal sind. Beispiele hierfür sind eine Fehlerbehebung, eine kleine Funktion, eine Konfigurationsänderung, eine gezielte Umgestaltung oder ein fehlgeschlagener Test. Verwenden Sie es mit line, wenn eine gemeinsame Regel für eine technische Domäne gelten muss. Verwenden Sie es mit plane, wenn die Änderung Teil eines Ergebnisses ist, das technische Bereiche überschreitet.
