Gestión de activos XT. Úselo cuando el usuario desee verificar los saldos de las cuentas XT/activos totales, realizar transferencias entre cuentas, realizar retiros o buscar cadenas y tarifas de depósito/retiro. Las operaciones de escritura requieren una clave API y deben seguir el flujo de confirmación; Los retiros requieren una segunda confirmación.
