Gestion des actifs XT. À utiliser lorsque l'utilisateur souhaite vérifier les soldes des comptes XT/les actifs totaux, les transferts entre comptes, retirer ou rechercher les chaînes et les frais de dépôt/retrait. Les opérations d'écriture nécessitent une clé API et doivent suivre le flux de confirmation ; les retraits nécessitent une deuxième confirmation.
