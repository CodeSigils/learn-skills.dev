Запросы рыночных данных XT. Используйте, когда пользователь спрашивает о ценах на монеты, данных спотового/фьючерсного рынка, глубине стакана заказов, свечах, ставках финансирования, таблицах лидеров выигравших/проигравших или таблицах лидеров по объемам. На основе инструментов MCP xt-tradekit; ключ API не требуется.
