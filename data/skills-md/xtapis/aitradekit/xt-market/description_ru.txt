Запросы рыночных данных XT. Используйте, когда пользователь спрашивает о ценах монет, данных спотового/фьючерсного рынка, глубине книги заказов, свечах, ставках финансирования, таблицах лидеров выигравших/проигравших или таблицах лидеров по объемам. На основе инструментов MCP xt-tradekit; ключ API не требуется.
