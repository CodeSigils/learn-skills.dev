Requêtes de données de marché XT. À utiliser lorsque l'utilisateur pose des questions sur les prix des pièces, les données du marché au comptant/à terme, la profondeur du carnet de commandes, les chandeliers, les taux de financement, les classements des gagnants/perdants ou les classements des volumes. Basé sur les outils MCP xt-tradekit ; aucune clé API requise.
