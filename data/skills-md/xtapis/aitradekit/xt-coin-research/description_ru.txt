Исследование монет и проверка рисков. Используйте, когда пользователь хочет понять основы монеты (рыночная капитализация / FDV / предложение / обзор проекта), сравнить несколько монет или проверить безопасность контракта токена в цепочке (приманка / ковер / налоговая ставка / концентрация держателей). Ключ API не требуется.
