Effectuez un audit complet des métadonnées SEO sur n'importe quelle page Web ou document HTML, basé sur les 10 balises méta HTML les plus importantes. Utilisez cette compétence chaque fois que l'utilisateur partage une URL, une source HTML ou le contenu d'une page et pose des questions sur le référencement, les métadonnées, les balises de titre, les méta descriptions, les balises canoniques, le balisage de schéma, les balises de graphique ouvert, le partage social, l'optimisation mobile ou pourquoi une page pourrait ne pas être bien classée. Déclenchez également des requêtes telles que « vérifier mon référencement », « vérifier les métadonnées de ma page », « auditer ce site », « améliorer mon classement dans les recherches », « générer un rapport de référencement » ou « qu'est-ce qui ne va pas avec le référencement de ma page ». En cas de doute, utilisez cette compétence : il est préférable d'effectuer un audit partiel plutôt que de répondre aux questions de référencement sans cet audit.
