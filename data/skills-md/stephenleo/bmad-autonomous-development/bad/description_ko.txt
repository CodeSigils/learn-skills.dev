BMad 자율 개발 — 병렬 스토리 구현 파이프라인을 조율합니다. 종속성 그래프를 작성하고, GitHub에서 PR 상태를 업데이트하고, 백로그에서 스토리를 선택하고, 생성 → 개발 → 검토 → PR을 통해 각 스토리를 병렬로 실행합니다. 각 스토리는 새로운 컨텍스트 창이 있는 전용 하위 에이전트를 사용하여 자체 git 작업 트리에 격리됩니다. 선택적 서사시 회고를 통해 전체 스프린트 계획을 일괄적으로 반복합니다. 사용자가 "BAD 실행", "자율 개발 시작", "스프린트 자동화", "파이프라인 실행", "스프린트 시작" 또는 "개발 파이프라인 시작"이라고 말할 때 사용합니다. /bad setup 또는 /badconfigure를 실행하여 모듈을 설치하고 구성합니다.
