BMad Autonomous Development — 並行ストーリー実装パイプラインを調整します。新しいコンテキスト ウィンドウを持つ専用のサブエージェントを使用して、依存関係グラフを構築し、GitHub から PR ステータスを更新し、バックログからストーリーを選択し、作成 → 開発 → レビュー → PR を並行して実行します (各ストーリーは独自の Git ワークツリーに分離されます)。スプリント計画全体をバッチでループし、オプションで壮大な振り返りを行います。ユーザーが「BAD を実行する」、「自律開発を開始する」、「スプリントを自動化する」、「パイプラインを実行する」、「スプリントを開始する」、または「開発パイプラインを開始する」と言うときに使用します。 /bad setup または /bad configure を実行して、モジュールをインストールして構成します。
