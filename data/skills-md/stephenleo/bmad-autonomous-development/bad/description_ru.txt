BMad Autonomous Development — организует параллельные конвейеры реализации историй. Строит график зависимостей, обновляет статус PR из GitHub, выбирает истории из бэклога и запускает каждую из них через создание → разработка → обзор → PR параллельно — каждая история изолирована в собственном рабочем дереве git — с использованием выделенных субагентов со свежими контекстными окнами. Пакетно выполняет весь план спринта с дополнительной эпической ретроспективой. Используйте, когда пользователь говорит «запустить BAD», «начать автономную разработку», «автоматизировать спринт», «запустить конвейер», «начать спринт» или «запустить конвейер разработки». Запустите /bad setup или /bad configure, чтобы установить и настроить модуль.
