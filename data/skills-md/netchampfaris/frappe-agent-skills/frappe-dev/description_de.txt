Erstellt Full-Stack-Frappe-Framework-Anwendungen durchgängig. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Folgendes erwähnt: Erstellen oder Ändern eines DocType, Schreiben eines Controllers oder Lebenszyklus-Hooks, Hinzufügen einer Whitelist-API, Einrichten einer neuen Frappe-App oder Bench-Site, Erstellen eines Desk-Formulars oder einer Listenansicht, Erstellen von Portalseiten, Schreiben von Hintergrundjobs oder geplanten Aufgaben, Verwalten von Berechtigungen oder Rollen, Schreiben von Frappe-Tests oder Arbeiten mit frappe.db / frappe.qb. Gilt auch, wenn der Benutzer Dinge sagt wie „Wie hänge ich mich in Save ein“, „Füge ein Feld zu einem DocType hinzu“, „Erstelle einen REST-Endpunkt in Frappe“, „Führe Bench Migrate aus“ oder „Installiere eine App auf einer Website“ – auch wenn er nicht ausdrücklich „Frappe“ sagt.
