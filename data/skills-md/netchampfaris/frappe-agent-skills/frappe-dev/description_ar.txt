يبني تطبيقات Frappe Framework كاملة المكدس من البداية إلى النهاية. استخدم هذه المهارة في أي وقت يذكر فيه المستخدم: إنشاء أو تعديل DocType، أو كتابة وحدة تحكم أو ربط دورة الحياة، أو إضافة واجهة برمجة تطبيقات قائمة بيضاء، أو إعداد تطبيق Frappe جديد أو موقع مقاعد البدلاء، أو إنشاء نموذج مكتبي أو عرض قائمة، أو إنشاء صفحات بوابة، أو كتابة وظائف الخلفية أو المهام المجدولة، أو إدارة الأذونات أو الأدوار، أو كتابة اختبارات Frappe، أو العمل مع frappe.db / frappe.qb. ينطبق أيضًا عندما يقول المستخدم أشياء مثل "كيف يمكنني الارتباط بالحفظ" أو "إضافة حقل إلى DocType" أو "إنشاء نقطة نهاية REST في Frappe" أو "تشغيل ترحيل البدلاء" أو "تثبيت تطبيق على موقع" - حتى لو لم يقولوا "Frappe" صراحةً.
