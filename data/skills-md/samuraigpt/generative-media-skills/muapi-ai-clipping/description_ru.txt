Превратите длинное видео в N коротких видеороликов, готовых к вирусному распространению, с помощью одного управляемого вызова API. Обертывает конечную точку `/ai-clipping` muapi.ai, которая обрабатывает транскрипцию, ранжирование ярких моментов с помощью структуры виральности (крючок / эмоциональный пик / бомба мнений / откровение / конфликт / цитируемость / пик истории / практическая ценность), дедупликацию перекрытия и автоматическую обрезку вертикального отслеживания лиц на стороне сервера.
