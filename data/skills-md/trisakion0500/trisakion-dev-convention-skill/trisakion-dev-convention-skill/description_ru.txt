Принципы разработки, которым Trisahios следует в каждом проекте (независимо от внутренней структуры): стиль кода (например, 4 пробела вместо табуляции), комментарии JSDoc, документация Swagger, правила Git/commit, подход к тестированию, безопасность документов, методы совместной работы, соглашения по написанию SP/функций (именование, проверки разрешений, возврат результатов, основной поток, TOCTOU, предотвращение взаимоблокировок посредством глобального порядка блокировки таблиц), физическое разделение базы данных журналов, рекурсивное маскирование конфиденциальной информации. проверки условий гонки с трех точек зрения — параллелизм, идемпотентность и переход состояний — модульность кода (удаление дублирования, предварительная реализация общих модулей, отложенная загрузка компонентов пользовательского интерфейса), обработка ошибок ERROR_MAP+BusinessException, версии с фиксированными зависимостями, область воздействия сервера MCP и безопасность (аутентификация S2S HMAC, предотвращение SQL-инъекций, хеширование паролей, защита XSS/CSRF, предотвращение внедрения внешних запросов diff/PR). Они применяются автоматически во время написания, фиксации, проверки и тестирования кода и используются в любом репозитории проекта.
