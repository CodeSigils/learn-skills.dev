Устанавливает git-flow-next (активно поддерживаемый форк Tower/gittower, описанный по адресу https://git-flow.sh/) через бэкэнд mise aqua, инициализирует классическую предустановку Gitflow, настраивает rebase как вышестоящую стратегию слияния для ветвей функций с помощью интерактивной перезагрузки на стороне участника, которая сворачивает ветку в один коммит с рукописным сообщением перед завершением и запускает поток функции/выпуска/исправления с помощью команд `git flow…`.
