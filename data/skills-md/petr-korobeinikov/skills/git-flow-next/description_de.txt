Installiert git-flow-next (den aktiv gewarteten Tower-/Gittower-Fork, dokumentiert unter https://git-flow.sh/) über das Aqua-Backend von Mise, initialisiert die klassische Gitflow-Voreinstellung, konfiguriert Rebase als Upstream-Merge-Strategie für Feature-Branches mit einem interaktiven Rebase auf Mitwirkenderseite, das den Branch in einem einzigen Commit mit einer handgeschriebenen Nachricht vor dem Abschluss zusammenfasst, und führt den Feature-/Release-/Hotfix-Flow mit „git flow …“-Befehlen aus.
