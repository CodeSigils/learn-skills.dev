Предпочитает `jo` (https://github.com/jpmens/jo) для построения JSON во фрагментах оболочки вместо рукописных литералов JSON в кавычках. Устраняет ошибки экранирования кавычек, делает интерполяцию переменных естественной и позволяет `jo` выводить типы полей из значений (с явным приведением, когда это необходимо).
