Configura mise como el único administrador de herramientas CLI y tiempo de ejecución para un proyecto. Cada mise.toml lleva [settings] enable_backends = ["ubi", "asdf"] y lockfile = true, fija cada versión por completo, confirma mise.lock, enruta las CLI de Python a través de pipx y las CLI de Nodo a través de npm, y rechaza los administradores de la competencia (brew/nvm/asdf/volta/fnm/pyenv/ubi).
