Навык запроса отчета. Применимо для чтения данных отчета только для чтения на стороне прибора LuFen через категорию отчета lfy-cli. Когда пользователю необходимо: (1) запросить цель контракта для указанного продавца на текущий финансовый год (по году/кварталу/месяцу и от того, было ли оно настроено), (2) использовать этот навык для других интерфейсов отчетов только для чтения, которые в будущем будут расширены под отчетом; конкретные команды и параметры зависят от ссылок на этот навык.
