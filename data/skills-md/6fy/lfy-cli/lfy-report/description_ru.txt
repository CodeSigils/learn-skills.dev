Навык запроса отчета. Используется для чтения данных отчета Lu-fen-yi, доступных только для чтения, в категории отчетов через lfy-cli. Примените этот навык, когда пользователю необходимо: (1) запросить целевые показатели контракта (годовые/ежеквартальные/ежемесячные, а также настроенные) для указанного продавца в текущем финансовом году, (2) расширить другие интерфейсы отчетов только для чтения в отчете позже; обратитесь к этому навыку для получения точных команд и параметров.
