Навык запроса отчета. Он используется для чтения данных отчета только для чтения на стороне прибора LuFen через категорию отчета lfy-cli. Когда пользователю необходимо: (1) запросить целевой показатель контракта указанного продавца на текущий финансовый год (по году/кварталу/месяцу и от того, было ли оно настроено), (2) использовать этот навык для других интерфейсов отчетов только для чтения, которые будут добавлены в отчет позже; точные команды и параметры определены в справочниках по этому навыку.
