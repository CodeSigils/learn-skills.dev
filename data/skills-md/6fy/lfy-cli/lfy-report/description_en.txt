Report query skill. It is used to read read‑only report data on the LuFen instrument side via the report category of lfy‑cli. When the user needs to: (1) query a specified salesperson’s contract target for the current fiscal year (by year/quarter/month and whether it has been configured), (2) use this skill for other read‑only report interfaces that will be added under report later; the exact commands and parameters are defined in this skill’s references.
