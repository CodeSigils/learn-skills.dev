Report query skill. Applicable for reading read‑only report data on the LuFen instrument side via the report category of lfy-cli. When the user needs: (1) to query the contract target for a specified salesperson for the current fiscal year (by year/quarter/month and whether it has been configured), (2) to use this skill for other read‑only report interfaces that will be expanded under report in the future; the specific commands and parameters are subject to the references of this skill.
