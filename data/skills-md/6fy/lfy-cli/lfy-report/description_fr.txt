Compétence de requête de rapport. Il est utilisé pour lire les données de rapport en lecture seule du côté de l'instrument LuFen via la catégorie de rapport lfy‑cli. Lorsque l'utilisateur doit : (1) interroger l'objectif de contrat d'un vendeur spécifié pour l'exercice en cours (par année/trimestre/mois et s'il a été configuré), (2) utiliser cette compétence pour d'autres interfaces de rapport en lecture seule qui seront ajoutées ultérieurement sous le rapport ; les commandes et paramètres exacts sont définis dans les références de cette compétence.
