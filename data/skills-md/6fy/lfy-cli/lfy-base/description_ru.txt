Базовые данные для сценариев редактирования клиентов (опции раскрывающегося списка). Используется, когда пользователю необходимо получить выбираемые списки идентификаторов для статуса клиента, тегов, региона и отрасли для изменения информации о клиенте; через `lfy-cli base get_options` свойство включает только эти четыре категории; параметр `cli` в API можно опустить (по умолчанию — false); в примере с агентом по-прежнему рекомендуется устанавливать `cli=true`.
