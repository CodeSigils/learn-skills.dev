Données de base pour les scénarios d'édition client (options déroulantes). Utilisé lorsqu'un utilisateur doit récupérer les listes d'ID sélectionnables pour le statut du client, les balises, la région et le secteur afin de modifier les informations sur le client ; via `lfy-cli base get_options`, la propriété inclut uniquement ces quatre catégories ; le paramètre `cli` peut être omis sur l'API (la valeur par défaut est false) ; l'exemple de l'agent recommande toujours de définir `cli=true`.
