Données de base pour le scénario d'édition client (options déroulantes). Utilisé lorsqu'un utilisateur doit récupérer les listes d'ID sélectionnables pour le statut du client, les balises, la région et le secteur afin de modifier les informations sur le client ; via `lfy-cli base get_options`, la propriété ne comprend que quatre catégories ; sur l'API, le paramètre `cli` peut être omis (false par défaut) ; l'exemple de l'agent recommande toujours `cli=true`.
