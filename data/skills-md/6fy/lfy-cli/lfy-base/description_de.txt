Grunddaten für Kundenbearbeitungsszenarien (Dropdown-Optionen). Wird verwendet, wenn ein Benutzer die auswählbaren ID-Listen für Kundenstatus, Tags, Region und Branche abrufen muss, um Kundeninformationen zu ändern. über „lfy-cli base get_options“ umfasst die Eigenschaft nur diese vier Kategorien; Der Parameter „cli“ kann in der API weggelassen werden (Standard ist „false“). Das Agent-Beispiel empfiehlt weiterhin die Einstellung „cli=true“.
