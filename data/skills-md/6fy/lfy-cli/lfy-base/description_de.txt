Grunddaten für das Kundenbearbeitungsszenario (Dropdown-Optionen). Wird verwendet, wenn ein Benutzer die auswählbaren ID-Listen für Kundenstatus, Tags, Region und Branche abrufen muss, um Kundeninformationen zu ändern; über „lfy-cli base get_options“ umfasst die Eigenschaft nur die vier Kategorien; Der Parameter „cli“ kann in der API weggelassen werden (Standard: falsch); Das Agent-Beispiel empfiehlt weiterhin „cli=true“.
