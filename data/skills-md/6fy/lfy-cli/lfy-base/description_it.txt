Dati di base per gli scenari di modifica del cliente (opzioni a discesa). Utilizzato quando un utente deve recuperare gli elenchi di ID selezionabili per stato del cliente, tag, regione e settore per modificare le informazioni sul cliente; tramite `lfy-cli base get_options`, la proprietà include solo queste quattro categorie; il parametro `cli` può essere omesso sull'API (il valore predefinito è false); l'esempio dell'agente consiglia comunque di impostare `cli=true`.
