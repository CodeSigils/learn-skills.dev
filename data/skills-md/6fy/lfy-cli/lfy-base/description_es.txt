Datos básicos para escenarios de edición de clientes (opciones desplegables). Se utiliza cuando un usuario necesita recuperar las listas de ID seleccionables para el estado del cliente, etiquetas, región e industria para modificar la información del cliente; a través de `lfy-cli base get_options`, la propiedad incluye solo estas cuatro categorías; el parámetro `cli` se puede omitir en la API (el valor predeterminado es falso); el ejemplo del Agente todavía recomienda configurar `cli=true`.
