Загрузите приложение Zekra Flutter для macOS с настоящим пакетом Gemma .litertlm (или переключайтесь между пакетами), чтобы вы могли проводить сквозные проверки — цикл агента, вызовы инструментов, персональные ответы — без перепрошивки Pixel. Охватывает пулы с одним экземпляром и N экземпляров, выбор пакета для тестирования (базовый E2B, базовый E4B, точно настроенные варианты LoRA во время выполнения), подключение DDS WebSocket и распространенные сбои во время загрузки с их исправлениями.
