Realiza auditorías de seguridad de código basadas en OWASP en cualquier base de código. Analiza el código fuente según los requisitos de verificación de ASVS 5.0.0, los 10 principales patrones de riesgo de seguridad de API de 2023, las prácticas de codificación segura de OWASP CheatSheet y las metodologías de prueba de WSTG. La entrada es una base de código para revisar; El resultado es un informe detallado de auditoría de seguridad de Markdown. Utilícelo cuando el usuario solicite una auditoría de seguridad, una revisión de seguridad, una evaluación de vulnerabilidad o un análisis de seguridad del código.
