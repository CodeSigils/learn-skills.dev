يقوم بإجراء عمليات تدقيق أمان التعليمات البرمجية المستندة إلى OWASP على أي قاعدة تعليمات برمجية. يحلل التعليمات البرمجية المصدر مقابل متطلبات التحقق ASVS 5.0.0، وأنماط المخاطر العشرة الأوائل لـ API Security لعام 2023، وممارسات الترميز الآمن لـ OWASP CheatSheet، ومنهجيات اختبار WSTG. الإدخال هو قاعدة التعليمات البرمجية للمراجعة؛ الإخراج هو تقرير تدقيق أمان Markdown مفصل. يُستخدم عندما يطلب المستخدم إجراء تدقيق أمني، أو مراجعة أمنية، أو تقييم الثغرات الأمنية، أو تحليل أمان التعليمات البرمجية.
