Effectue des audits de sécurité du code basés sur OWASP sur n'importe quelle base de code. Analyse le code source par rapport aux exigences de vérification ASVS 5.0.0, aux modèles de risque API Security Top 10 2023, aux pratiques de codage sécurisé OWASP CheatSheet et aux méthodologies de test WSTG. L'entrée est une base de code à réviser ; le résultat est un rapport d’audit de sécurité Markdown détaillé. À utiliser lorsque l'utilisateur demande un audit de sécurité, un examen de sécurité, une évaluation des vulnérabilités ou une analyse de la sécurité du code.
