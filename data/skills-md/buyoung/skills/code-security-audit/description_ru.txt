Выполняет аудит безопасности кода на основе OWASP для любой кодовой базы. Анализирует исходный код на соответствие требованиям проверки ASVS 5.0.0, шаблонам рисков API Security Top 10 2023, практикам безопасного кодирования OWASP CheatSheet и методологиям тестирования WSTG. Входные данные — это кодовая база для проверки; Выходные данные — подробный отчет об аудите безопасности Markdown. Используйте, когда пользователь запрашивает аудит безопасности, проверку безопасности, оценку уязвимостей или анализ безопасности кода.
