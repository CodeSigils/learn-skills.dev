@trigger.dev/sdk/ai의 chat.agent를 사용하여 내구성 있는 AI 채팅 에이전트를 작성하고 실행합니다. 턴별 실행 루프, ...chat.toStreamTextOptions()를 먼저 확산해야 하는 이유, StreamTextResult 반환과 chat.pipe() 호출, 두 가지 서버 작업(chat.createStartSessionAction + auth.createPublicToken), useChat을 useTriggerChatTransport에 연결합니다. 채팅 백엔드(에이전트 작업 또는 해당 수명 주기 후크) 또는 해당 React 전송을 빌드, 수정 또는 디버깅할 때, 입력된 도구 또는 사용자 정의 데이터 부분을 선언할 때 또는 일반 AI SDK streamText 경로를 chat.agent로 마이그레이션할 때 이를 로드합니다.
