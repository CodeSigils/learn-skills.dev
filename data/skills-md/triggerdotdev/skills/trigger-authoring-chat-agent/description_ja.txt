@trigger.dev/sdk/ai の chat.agent を使用して耐久性のある AI チャット エージェントを作成して実行します。ターンごとの実行ループ、最初に ...chat.toStreamTextOptions() を広める必要がある理由、StreamTextResult を返すのと chat.pipe() の呼び出し、2 つのサーバー アクション (chat.createStartSessionAction + auth.createPublicToken)、useChat を useTriggerChatTransport に接続する必要があります。チャット バックエンド (エージェント タスクまたはそのライフサイクル フック) またはその React トランスポートを構築、変更、またはデバッグするとき、型付きツールやカスタム データ パーツを宣言するとき、またはプレーン AI SDK streamText ルートを chat.agent に移行するときに、これを読み込みます。
