Crea ed esegui un agente di chat AI durevole con chat.agent da @trigger.dev/sdk/ai: il ciclo di esecuzione per turno, perché DEVI diffondere prima ...chat.toStreamTextOptions(), restituendo uno StreamTextResult rispetto alla chiamata a chat.pipe(), le due azioni del server (chat.createStartSessionAction + auth.createPublicToken) e collegando useChat a useTriggerChatTransport. Caricalo quando crei, modifichi o esegui il debug di un backend di chat (l'attività dell'agente o i suoi hook del ciclo di vita) o del suo trasporto React, quando dichiari strumenti tipizzati o parti di dati personalizzate o quando esegui la migrazione di una semplice route streamText dell'SDK AI a chat.agent.
