قم بتأليف وتشغيل وكيل دردشة AI دائم باستخدام chat.agent من @trigger.dev/sdk/ai: حلقة التشغيل لكل دورة، لماذا يجب عليك نشر ...chat.toStreamTextOptions() أولاً، وإرجاع StreamTextResult مقابل استدعاء chat.pipe()، وإجراءي الخادم (chat.createStartSessionAction + auth.createPublicToken)، وتوصيل useChat لاستخدامTriggerChatTransport. قم بتحميل هذا عند إنشاء واجهة خلفية للدردشة أو تعديلها أو تصحيح أخطائها (مهمة الوكيل أو خطافات دورة الحياة الخاصة بها) أو نقل React الخاص بها، أو عند الإعلان عن أدوات مكتوبة أو أجزاء بيانات مخصصة، أو عند ترحيل مسار نص AI SDK عادي إلى chat.agent.
