Расширенные и рабочие возможности Chat.Agent для Trigger.dev, загружаемые по требованию. Загрузите это при работе с необработанным примитивом сеансов (sessions / SessionHandle), пользовательским транспортом чата или проводным протоколом реального времени, надежными субагентами (AgentChat,chat.stream.writer), человеком в цикле, управлением, действиями, фоновым внедрением (chat.defer/chat.inject), быстрым запуском (предварительная загрузка, запуск через @trigger.dev/sdk/chat-server), устойчивостью контекста (сжатие, загрузка восстановления, OOM, большой полезные нагрузки), состояние выполнения в области Chat.local, автономное тестирование с помощью MockChatAgent или предварительные версии/обновления версий. Для повседневного определения Chat.agent({...}) и счастливого пути useTriggerChatTransport вместо этого используйте навык триггера-автора-чат-агента.
