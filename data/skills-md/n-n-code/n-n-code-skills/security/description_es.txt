Habilidad de flujo de trabajo de seguridad para modelado de amenazas basado en repositorios, revisión de seguridad centrada en exploits y orientación de implementación segura por defecto. Úselo cuando el usuario solicite explícitamente trabajo de seguridad o cuando las propiedades de seguridad sean la principal preocupación en un cambio de alto riesgo. No active la revisión de código ordinaria, el trabajo rutinario de endpoints o la implementación general de backend solo porque un repositorio contiene API, autenticación o secretos.
