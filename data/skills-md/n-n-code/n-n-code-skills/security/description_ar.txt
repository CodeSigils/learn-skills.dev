مهارة سير العمل الأمني ​​لنمذجة التهديدات القائمة على الريبو، ومراجعة الأمان التي تركز على الاستغلال، وإرشادات التنفيذ الآمنة افتراضيًا. يُستخدم عندما يطلب المستخدم صراحةً عملًا أمنيًا، أو عندما تكون خصائص الأمان هي الاهتمام الأساسي في تغيير عالي المخاطر. لا تقم بتشغيل مراجعة التعليمات البرمجية العادية أو عمل نقطة النهاية الروتينية أو تنفيذ الواجهة الخلفية العامة لمجرد أن الريبو يحتوي على واجهات برمجة التطبيقات أو المصادقة أو الأسرار.
