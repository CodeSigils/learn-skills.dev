Навыки рабочего процесса безопасности для моделирования угроз на основе репозиториев, анализа безопасности, ориентированного на эксплойты, и руководства по внедрению безопасности по умолчанию. Используйте, когда пользователь явно запрашивает работу по обеспечению безопасности или когда свойства безопасности являются основной проблемой при изменении высокого риска. Не запускайте обычную проверку кода, рутинную работу с конечной точкой или общую реализацию серверной части только потому, что репозиторий содержит API, аутентификацию или секреты.
