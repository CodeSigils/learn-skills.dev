Compétence en matière de flux de travail de sécurité pour la modélisation des menaces basée sur le dépôt, l'examen de la sécurité axé sur les exploits et les conseils de mise en œuvre de la sécurité par défaut. À utiliser lorsque l'utilisateur demande explicitement un travail de sécurité ou lorsque les propriétés de sécurité sont la principale préoccupation dans un changement à haut risque. Ne déclenchez pas une révision de code ordinaire, un travail de routine sur les points de terminaison ou une implémentation générale du backend simplement parce qu'un dépôt contient des API, une authentification ou des secrets.
