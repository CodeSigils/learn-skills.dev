Competenze nel flusso di lavoro di sicurezza per la modellazione delle minacce basata su repository, revisione della sicurezza incentrata sugli exploit e linee guida per l'implementazione sicura per impostazione predefinita. Da utilizzare quando l'utente richiede esplicitamente interventi di sicurezza o quando le proprietà di sicurezza rappresentano la preoccupazione principale in una modifica ad alto rischio. Non eseguire l'attivazione per la revisione ordinaria del codice, il lavoro di routine sugli endpoint o l'implementazione generale del backend solo perché un repository contiene API, autenticazione o segreti.
