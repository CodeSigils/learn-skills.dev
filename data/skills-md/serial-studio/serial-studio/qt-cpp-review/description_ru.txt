Глубокий обзор кода Qt6/C++ для Serial Studio. Используйте, когда вас просят «просмотреть», «проверить», «проверить», «просмотреть» или «проверить работоспособность» C++ — или перед фиксацией. Запускает линтер репозитория (scripts/code-verify.py) на этапе 1, затем шесть параллельных агентов анализа только для чтения, охватывающих контракты модели Qt, владение/жизненный цикл, потокобезопасность + горячий путь к данным, корректность API/C++, обработку ошибок и производительность. Сообщает только о результатах с высокой степенью достоверности (>=80/100) с корректировками. Никогда не изменяет код.
