Révision approfondie du code Qt6/C++ pour Serial Studio. À utiliser lorsqu'on vous demande de « réviser », « auditer », « vérifier », « examiner » ou « vérifier l'intégrité » du C++ — ou avant de vous engager. Exécute le linter du référentiel (scripts/code-verify.py) en tant que phase 1, puis six agents d'analyse parallèles en lecture seule couvrant les contrats de modèle Qt, la propriété/le cycle de vie, la sécurité des threads + le hotpath des données, l'exactitude API/C++, la gestion des erreurs et les performances. Rapporte uniquement les résultats de niveau de confiance élevé (>=80/100) avec des atténuations détaillées. Ne modifie jamais le code.
