Utilisez cette compétence chaque fois que l'utilisateur souhaite interroger, transformer, filtrer, joliment imprimer, compacter, valider, convertir ou modifier des données structurées de type JSON à partir de fichiers, stdin, sorties de commandes, journaux, API ou pipelines shell ; composer, déboguer, porter ou expliquer les filtres jq/jaq ; extrayez des champs, remodelez des tableaux/objets, transmettez des variables, absorbez des entrées, émettez des chaînes brutes, mettez à jour JSON en place, convertissez YAML/CBOR ou exécutez des tests de style jq. Préférez jaq comme outil de requête JSON de premier choix, car il s'agit d'une CLI rapide de type jq avec une syntaxe de filtre familière et des options de format d'entrée/sortie utiles. Si jaq n'est pas disponible, revenez à jq sauf si l'utilisateur a spécifiquement besoin d'une fonctionnalité uniquement jaq.
