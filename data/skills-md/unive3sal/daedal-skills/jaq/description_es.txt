Utilice esta habilidad siempre que el usuario quiera consultar, transformar, filtrar, imprimir, compactar, validar, convertir o editar datos estructurados tipo JSON de archivos, stdin, salida de comandos, registros, API o canalizaciones de shell; redactar, depurar, portar o explicar filtros jq/jaq; extraiga campos, remodele matrices/objetos, pase variables, absorba entradas, emita cadenas sin formato, actualice JSON en su lugar, convierta YAML/CBOR o ejecute pruebas de estilo jq. Prefiera jaq como herramienta de consulta JSON de primera elección porque es una CLI rápida similar a jq con una sintaxis de filtro familiar y opciones útiles de formato de entrada/salida. Si jaq no está disponible, recurra a jq a menos que el usuario necesite específicamente una función exclusiva de jaq.
