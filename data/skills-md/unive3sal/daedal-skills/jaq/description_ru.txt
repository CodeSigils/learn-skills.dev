Используйте этот навык всякий раз, когда пользователь хочет запросить, преобразовать, отфильтровать, красиво распечатать, сжать, проверить, преобразовать или отредактировать структурированные данные в формате JSON из файлов, стандартного ввода, вывода команд, журналов, API или конвейеров оболочки; составлять, отлаживать, портировать или объяснять фильтры jq/jaq; извлекать поля, изменять форму массивов/объектов, передавать переменные, обрабатывать входные данные, генерировать необработанные строки, обновлять JSON на месте, конвертировать YAML/CBOR или запускать тесты в стиле jq. Предпочитайте jaq как инструмент запросов JSON первого выбора, поскольку это быстрый jq-подобный интерфейс командной строки со знакомым синтаксисом фильтров и полезными параметрами формата ввода/вывода. Если jaq недоступен, вернитесь к jq, если только пользователю не нужна функция только jaq.
