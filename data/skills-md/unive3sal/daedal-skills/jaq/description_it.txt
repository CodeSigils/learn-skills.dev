Utilizzare questa competenza ogni volta che l'utente desidera eseguire query, trasformare, filtrare, stampare, compattare, convalidare, convertire o modificare dati strutturati di tipo JSON da file, stdin, output di comandi, log, API o pipeline di shell; comporre, eseguire il debug, eseguire il porting o spiegare i filtri jq/jaq; estrai campi, rimodella array/oggetti, passa variabili, slurp input, emetti stringhe grezze, aggiorna JSON sul posto, converti YAML/CBOR o esegui test in stile jq. Preferisci jaq come strumento di query JSON di prima scelta perché è una CLI veloce simile a jq con una sintassi di filtro familiare e utili opzioni di formato di input/output. Se jaq non è disponibile, ricorrere a jq a meno che l'utente non abbia specificatamente bisogno di una funzionalità solo jaq.
