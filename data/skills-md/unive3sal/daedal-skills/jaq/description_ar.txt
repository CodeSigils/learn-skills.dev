استخدم هذه المهارة عندما يريد المستخدم الاستعلام عن البيانات المنظمة الشبيهة بـ JSON أو تحويلها أو تصفيتها أو طباعتها بشكل جميل أو ضغطها أو التحقق من صحتها أو تحويلها أو تحريرها من الملفات أو stdin أو مخرجات الأوامر أو السجلات أو واجهات برمجة التطبيقات (APIs) أو خطوط أنابيب Shell؛ إنشاء مرشحات jq/jaq أو تصحيحها أو منفذها أو شرحها؛ استخراج الحقول، أو إعادة تشكيل المصفوفات/الكائنات، أو تمرير المتغيرات، أو إدخالات slurp، أو إصدار سلاسل أولية، أو تحديث JSON في مكانه، أو تحويل YAML/CBOR، أو تشغيل اختبارات نمط jq. تفضل jaq كأداة استعلام JSON الأولى لأنها عبارة عن واجهة سطر أوامر (CLI) سريعة تشبه jq مع بنية مرشح مألوفة وخيارات تنسيق الإدخال/الإخراج المفيدة. إذا لم يكن jaq متاحًا، فارجع إلى jq إلا إذا كان المستخدم يحتاج على وجه التحديد إلى ميزة jaq فقط.
