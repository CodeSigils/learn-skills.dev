Аудит значений по умолчанию для столбцов и сгенерированных столбцов — временные метки на стороне приложения, которые должны быть значениями по умолчанию для БД, недетерминированные или неправильные значения по умолчанию, производные значения, которые должны ГЕНЕРИРОВАТЬСЯ ВСЕГДА/вычисляемые столбцы вместо подверженных дрейфу дублированных данных, а также значения по умолчанию для идентификаторов/последовательностей. Модуль М6. Подает оценку дизайна и целостности (категория Tipos, общая с M4).
