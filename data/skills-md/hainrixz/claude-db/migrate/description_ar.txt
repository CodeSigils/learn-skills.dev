فحص ترحيل قاعدة البيانات للسلامة قبل تشغيلها - تصنيف مستوى القفل، وإعادة كتابة الجدول، وإمكانية الرجوع؛ وضع علامة على العمليات التدميرية/الحظرية؛ واقتراح طرح توسيع العقد. تحليل للقراءة فقط بشكل افتراضي؛ تتطلب أي خطوة لفقدان البيانات مصافحة رمزية واضحة قبل مشاركة الكاتب. يُستخدم عندما يطلب المستخدم مراجعة عملية ترحيل أو ALTER/DROP أو تغيير التعداد أو إعادة التعبئة أو تغيير المخطط أو فحصها أو التحقق منها أو إزالة المخاطر عنها قبل النشر.
