Conception de base de données Greenfield : choisissez le bon moteur pour un nouveau projet, comparez-le au moteur par défaut ennuyeux et restituez un modèle de données de démarrage avec un diagramme. Mode recommandation (module M0) ; jamais marqué, jamais destructeur. À utiliser lorsque l'utilisateur recommence et demande quelle base de données utiliser, comment modéliser une nouvelle application, quel moteur convient ou pour un schéma/modèle de données à partir de zéro.
