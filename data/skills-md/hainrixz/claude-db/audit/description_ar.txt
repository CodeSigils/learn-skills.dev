يؤدي تدقيق مخطط قاعدة البيانات أو نموذج ORM أو عمليات الترحيل للتصميم والأداء إلى إنتاج درجتين مستقلتين من 0 إلى 100 (التصميم والنزاهة + الأداء والقياس) بالإضافة إلى تقرير محدد الأولويات ومدعوم بالأدلة. للقراءة فقط؛ لا يكتب أو يهاجر أبدًا. يُستخدم عندما يطلب المستخدم تدقيق أو تحليل أو مراجعة أو فحص أو تسجيل قاعدة بيانات أو مخطط أو نموذج بيانات أو عمليات ترحيل أو فهارس أو مفاتيح أو التكامل المرجعي أو الأنواع أو القيود أو أنماط الاستعلام أو التقسيم أو تجميع الاتصالات - لـ Postgres وMySQL وMongo وDynamoDB وCassandra وpgvector وClickHouse وNeo4j والأصدقاء.
