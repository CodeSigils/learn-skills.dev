Punto de partida guiado y sin jerga para personas que aún no tienen un esquema ni una base de datos: un breve asistente de 7 preguntas que convierte "Quiero crear una aplicación" en una recomendación de motor concreta y un primer modelo de datos. Se requieren cero artefactos. Úselo cuando el usuario no tiene nada que auditar, pregunta cómo empezar, dice que no es técnico o no sabe qué base de datos o esquema necesita.
