Согласие на запись (команда /claude-db:fix). Применяет безопасные обратимые изменения схемы/миграции из аудита — добавление индексов, ограничений NOT NULL/CHECK/UNIQUE, отсутствующие FK, исправления типов, столбцы по умолчанию/сгенерированные — как миграции с расширенным контрактом. Предварительный просмотр пробного прогона по умолчанию; записывает только после явного подтверждения каждого изменения и только через субагент записи миграции. Запускается только тогда, когда пользователь его вызывает, и никогда не запускается автоматически.
