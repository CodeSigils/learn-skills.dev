Живой самоанализ уровня 1, доступный только для чтения. Подключается к работающей базе данных через инструменты класса чтения сервера DB MCP (предпочтительно) или строку подключения только для чтения с наименьшими привилегиями, читает только каталоги (без табличных данных и без записи) и обновляет затронутые результаты до установленной достоверности. Обеспечивает соблюдение контракта только для чтения; когда прямой доступ недоступен, он отмечает зависимые проверки Need_api — а не тихий проход. Вызывается db-orchestrator и аудиторами, когда для проверки требуется достоверность во время выполнения.
