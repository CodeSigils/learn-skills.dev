Representar una cuadrícula GO/NO-GO de preparación para la producción para una base de datos: ejecuta una auditoría de solo lectura, luego asigna los hallazgos a una lista de verificación de lanzamiento fija (PITR/copias de seguridad, RLS en tablas de inquilinos, índices FK, dinero como numérico, marca de tiempo/UTC, tamaño de agrupación de conexiones, reversibilidad de migración, secretos que no están en el esquema, conjunto de caracteres/utf8mb4). Cada fila es PASA/ADVERTENCIA/FALLA/NEEDES-VIVO con la identificación del hallazgo, rematada por un veredicto en lenguaje sencillo. Sólo lectura. Úselo cuando el usuario pregunta si una base de datos está lista para producción, lista para lanzarse/enviarse, si pasa o no, una lista de verificación previa al lanzamiento o de preparación, o qué arreglar antes de entrar en funcionamiento.
