Отображение таблицы готовности к работе GO/NO-GO для базы данных — запускает аудит только для чтения, затем сопоставляет результаты с фиксированным контрольным списком запуска (PITR/резервные копии, RLS в таблицах арендаторов, индексы FK, числовые значения денег, метка времени/UTC, размер пула соединений, обратимость миграции, секреты не в схеме, кодировка/utf8mb4). Каждая строка имеет статус PASS/WARN/FAIL/NEEDS-LIVE с идентификатором поиска, увенчанным вердиктом, написанным простым языком. Только для чтения. Используйте, когда пользователь спрашивает, готова ли база данных к работе, готова ли она к запуску/отправке, годна/не годна, есть ли контрольный список перед запуском или готовностью или что нужно исправить перед запуском в эксплуатацию.
