Auditer un site Web ou une base de code Web pour le référencement et la recherche IA (GEO/AEO) – produit deux scores indépendants de 0 à 100 (Search SEO + AI Visibility) ainsi qu'un rapport hiérarchisé et étayé par des preuves. Lecture seule ; n'écrit jamais de fichiers. À utiliser lorsque l'utilisateur demande d'auditer, d'analyser, de vérifier ou de noter le référencement d'un site, les données/schémas structurés, les balises méta, les Core Web Vitals, les robots.txt, les plans de site ou llms.txt, ou son classement dans Google et est cité par les moteurs d'IA (ChatGPT, Perplexity, Google AI Overviews, Gemini, Claude).
