قم بمراجعة موقع ويب أو قاعدة أكواد برمجية للويب لتحسين محركات البحث وبحث الذكاء الاصطناعي (GEO/AEO) — لإنتاج درجتين مستقلتين من 0 إلى 100 (Search SEO + رؤية الذكاء الاصطناعي) بالإضافة إلى تقرير محدد الأولويات ومدعوم بالأدلة. للقراءة فقط؛ لا يكتب الملفات أبدا. يُستخدم عندما يطلب المستخدم تدقيق أو تحليل أو فحص أو تسجيل تحسين محركات البحث لموقع ما، أو البيانات/المخطط المنظم، أو العلامات الوصفية، أو Core Web Vitals، أو robots.txt، أو خرائط الموقع، أو llms.txt، أو كيفية تصنيفه في Google والاستشهاد به بواسطة محركات الذكاء الاصطناعي (ChatGPT، أو Perplexity، أو Google AI Overviews، أو Gemini، أو Claude).
