Генерация изображений AI для платных рекламных креативов. Читает Campaign-brief.md и Brand-Profile.json для создания рекламных изображений размером с платформу с использованием Banan-Claude. Требуется Banan-Claude (v1.4.1+) с настроенным nanobanana-mcp. Запускается по: генерировать рекламу, создавать изображения, создавать рекламные креативы, генерировать визуальные эффекты, создавать рекламные изображения, создавать изображения кампании, создавать изображения, генерировать из брифа.
