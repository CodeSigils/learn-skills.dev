Assistant de première exécution guidé. Guide l'utilisateur de l'installation à froid à un pipeline d'audit fonctionnel : capture du contexte métier, choix de connexion par plate-forme (MCP / API directe / manuel) avec vérification OAuth étape par étape, procédures pas à pas facultatives du compte Zernio + Meta Developers, persistance du profil vers ~/.claude-ads/profile.json. Réexécutable pour modifier les paramètres (`/ads start edit`), réinitialiser (`/ads start reset`) ou vérifier l'état (`/ads start status`). À utiliser lorsque l'utilisateur dit démarrer, configurer, initialiser, intégrer, première fois, démarrer, procédure pas à pas, connecter mes comptes, connecter mes comptes, utiliser.
