Управляемый мастер первого запуска. Проводит пользователя от холодной установки к работающему конвейеру аудита: захват бизнес-контекста, выбор подключения для каждой платформы (MCP/прямой API/руководство) с пошаговой проверкой OAuth, дополнительные пошаговые инструкции по учетной записи Zernio + Meta Developers, сохранение профиля в ~/.claude-ads/profile.json. Возможность повторного запуска для редактирования настроек (`/ads start edit`), сброса (`/ads start reset`) или проверки статуса (`/ads start status`). Используйте, когда пользователь говорит: «Начать», «Настроить», «Инициализировать», «Включиться», «Первый раз», «Начать работу», «Прохождение», «Подключить мои учетные записи», «Подключиться к другим учетным записям», «Empezar».
