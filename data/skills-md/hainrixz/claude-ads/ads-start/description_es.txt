Asistente de primera ejecución guiado. Guía al usuario desde la instalación en frío hasta un proceso de auditoría funcional: captura del contexto empresarial, elección de conexión por plataforma (MCP/API directa/manual) con verificación OAuth paso a paso, tutoriales opcionales de la cuenta Zernio + Meta Developers, persistencia del perfil en ~/.claude-ads/profile.json. Se puede volver a ejecutar para editar la configuración (`/ads start edit`), restablecer (`/ads start reset`) o verificar el estado (`/ads start status`). Úselo cuando el usuario diga iniciar, configurar, iniciar, incorporar, primera vez, comenzar, tutorial, conectar mis cuentas, conectar mis cuentas, empezar.
