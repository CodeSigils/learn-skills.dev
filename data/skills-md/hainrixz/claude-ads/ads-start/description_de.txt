Geführter Erststart-Assistent. Führt den Benutzer von der Kaltinstallation zu einer funktionierenden Audit-Pipeline: Geschäftskontexterfassung, Verbindungsauswahl pro Plattform (MCP/direkte API/manuell) mit schrittweiser OAuth-Überprüfung, optionale Komplettlösungen für Zernio + Meta Developers-Konten, Profilpersistenz in ~/.claude-ads/profile.json. Kann erneut ausgeführt werden, um Einstellungen zu bearbeiten („/ads start edit“), zurückzusetzen („/ads start reset“) oder den Status zu überprüfen („/ads start status“). Verwenden Sie diese Option, wenn der Benutzer „Start“, „Setup“, „Init“, „Onboard“, „Erstes Mal“, „Erste Schritte“, „Komplettlösung“, „Meine Konten verbinden“, „Kontakte verbinden“ und „Empezar“ sagt.
