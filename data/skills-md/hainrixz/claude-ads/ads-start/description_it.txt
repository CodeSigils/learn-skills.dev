Procedura guidata di prima esecuzione guidata. Guida l'utente dall'installazione a freddo a una pipeline di controllo funzionante: acquisizione del contesto aziendale, scelta della connessione per piattaforma (MCP/API diretta/manuale) con verifica OAuth passo passo, procedure dettagliate opzionali per l'account Zernio + Meta Developers, persistenza del profilo su ~/.claude-ads/profile.json. Rieseguibile per modificare le impostazioni (`/ads start edit`), reimpostare (`/ads start reset`) o controllare lo stato (`/ads start status`). Da utilizzare quando l'utente dice start, setup, init, onboard, first time, get start, walkthrough, connect my account, conectar mis cuentas, empezar.
