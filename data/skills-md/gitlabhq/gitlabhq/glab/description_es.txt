Automatización del flujo de trabajo de GitLab usando la CLI glab. Úsela cuando el usuario solicite crear, actualizar, cerrar, etiquetar o comentar en un issue, merge request, work item o epic de GitLab; para publicar una nota, un comentario de revisión o una respuesta a una discusión; para llamar a la API REST o GraphQL de GitLab mediante "glab api"; para inspeccionar o reintentar pipelines y jobs; o para configurar la autenticación de glab contra gitlab.com, una instancia autogestionada o un GDK local. Léala antes de cualquier operación de escritura con glab, ya que varias banderas de campo fallan silenciosamente: salen con código 0 mientras publican contenido incorrecto.
