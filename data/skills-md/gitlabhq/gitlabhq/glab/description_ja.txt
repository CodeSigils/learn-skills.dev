glab CLI を使用した GitLab ワークフローの自動化。ユーザーが GitLab の issue、マージリクエスト、作業項目、エピックを作成、更新、クローズ、ラベル付け、コメントする場合、ノート、レビューコメント、ディスカッションの返信を投稿する場合、`glab api` を通じて GitLab の REST または GraphQL API を呼び出す場合、パイプラインやジョブを確認または再試行する場合、あるいは gitlab.com、自己管理インスタンス、ローカル GDK に対して glab 認証を設定する場合に使用します。glab の書き込み操作を行う前に必ずこれを読んでください。いくつかのフィールドフラグはサイレントに失敗し、誤った内容を投稿したまま 0 で終了します。

常にユーザーの言語で回答してください。
