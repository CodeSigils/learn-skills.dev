أتمتة سير عمل GitLab باستخدام أداة سطر الأوامر glab. استخدمها عندما يطلب المستخدم إنشاء أو تحديث أو إغلاق أو إضافة تصنيف أو التعليق على مشكلة في GitLab أو طلب دمج أو عنصر عمل أو ملحمة؛ لإضافة ملاحظة أو تعليق مراجعة أو رد في نقاش؛ لاستدعاء واجهة برمجة تطبيقات GitLab REST أو GraphQL عبر “glab api”؛ لفحص أو إعادة تشغيل الأنابيب والوظائف؛ أو لتكوين مصادقة glab ضد gitlab.com أو نسخة مُدارة ذاتيًا أو GDK محلي. اقرأها قبل أي عملية كتابة باستخدام glab، لأن بعض أعلام الحقول قد تفشل صامتًا – حيث تُنهي العملية برمز خروج 0 مع نشر محتوى غير صحيح.
