تصميم واجهة مستخدم للعبة لشاشات العرض والقوائم والتراكبات وتدفقات وحدة التحكم وميزات إمكانية الوصول عبر وحدة التحكم والكمبيوتر الشخصي والألعاب المحمولة باليد والهواتف المحمولة. يُستخدم عندما يحتاج Codex إلى إنشاء أو مراجعة أو تحسين مفاهيم واجهة اللعبة أو التسلسل الهرمي للمعلومات أو وضع المنطقة الآمنة أو قواعد الحركة أو أنماط التفاعل الخاصة بالإدخال لشاشات اللعبة.
