Úselo cuando el usuario quiera comprender, localizar, rastrear o evaluar el código existente sin cambiarlo: preguntas como "cómo funciona X", "dónde se implementa Y", "qué afectaría el cambio de Z", arquitectura o mapeo de flujo de datos, seguimiento de dependencias, descubrimiento de convenciones o recopilación de evidencia de planificación previa y depuración previa. No lo use cuando un defecto necesita reparación, se solicita un plan o artefacto de especificación, o cuando el entregable es una edición, confirmación o revisión de diferencias.
