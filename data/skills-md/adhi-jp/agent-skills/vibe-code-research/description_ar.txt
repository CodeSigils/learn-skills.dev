يُستخدم عندما يريد المستخدم فهم التعليمات البرمجية الموجودة أو تحديد موقعها أو تتبعها أو تقييمها دون تغييرها - أسئلة مثل "كيف يعمل X"، أو "أين يتم تنفيذ Y"، أو "ما الذي سيؤثر عليه تغيير Z"، أو الهندسة المعمارية أو رسم خرائط تدفق البيانات، أو تتبع التبعية، أو اكتشاف الاتفاقية، أو جمع الأدلة قبل التخطيط والتصحيح المسبق. لا تستخدمه عندما يحتاج العيب إلى إصلاح، أو عند طلب خطة أو قطعة أثرية للمواصفات، أو عندما يكون التعديل أو الالتزام أو المراجعة الفرقية هو التسليم.
