À utiliser lorsque l'utilisateur souhaite comprendre, localiser, tracer ou évaluer le code existant sans le modifier : des questions telles que "comment X fonctionne", "où Y est-il implémenté", "qu'est-ce que la modification de Z affecterait", l'architecture ou le mappage des flux de données, le traçage des dépendances, la découverte de conventions ou la collecte de preuves de pré-planification et de pré-débogage. Ne pas utiliser lorsqu'un défaut doit être réparé, qu'un artefact de plan ou de spécification est demandé, ou qu'une modification, une validation ou une révision de différence est le livrable.
