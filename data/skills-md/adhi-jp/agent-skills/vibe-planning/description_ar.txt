يُستخدم عندما يريد المستخدم التخطيط قبل البرمجة: وضع الخطة، أو إنشاء خطة، أو خطة التنفيذ، أو المواصفات، أو معايير القبول، أو خطة الاختبار، أو ترميز النشاط، أو توضيح المتطلبات، أو ما يجب إنشاؤه أولاً، أو طلبات التخطيط المكافئة بأي لغة. يُستخدم أيضًا لطلبات الترميز التقريبية أو الغامضة أو الحساسة للجدوى أو غير التقنية أو التي لم يتم تنفيذها بعد.
