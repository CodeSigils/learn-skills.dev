codex プラグインを使用して、ユーザーが選択した git レビュー ターゲット (作業ツリーの差分、現在のブランチと自動検出されたベース、または明示的なコミット/タグ/ブランチ参照) に対して、制限された 3 サイクルのインタラクティブなレビューと修正のワークフローを実行します。各サイクルはコーデックス `review` または `adversarial-review --json` を呼び出します。 Claude は各結果を 6 項目の妥当性チェックリストと照合して検証し、「review-scope-guard」を呼び出して完了の定義トリアージを行い、ユーザーは次のサイクルまでに修正する結果を選択します。コードの差分とマークダウン計画ドキュメントの両方をカバーします。 3サイクルでハードキャップ。ユーザーが作業ツリーの変更、コミットされたブランチの差分、または明示的なベース参照に対してコーデックス レビュー サイクルを実行することを明示的に要求した場合にのみ使用します。単発レビューリクエスト、自動強化、バックグラウンドレビュー、計画草稿、または選択したターゲットが空の差分を生成する場合にはトリガーしないでください。
