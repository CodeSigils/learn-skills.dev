Ejecute un flujo de trabajo interactivo de revisión y corrección de 3 ciclos limitado contra un objetivo de revisión de git elegido por el usuario (diferencia del árbol de trabajo, rama actual frente a base detectada automáticamente o una confirmación/etiqueta/referencia de rama explícita) utilizando el complemento del códice. Cada ciclo invoca el codex `review` o `adversarial-review --json`; Claude verifica cada hallazgo con una lista de verificación de validez de seis elementos, llama a "review-scope-guard" para la clasificación de Definición de Hecho y el usuario elige qué hallazgos corregir antes del siguiente ciclo. Cubre tanto las diferencias de código como los documentos de planificación de rebajas. Tapa dura a los 3 ciclos. Úselo SÓLO cuando el usuario solicite explícitamente ejecutar el ciclo de revisión del códice en cambios en el árbol de trabajo, una diferencia de rama confirmada o una referencia base explícita. NO active solicitudes de revisión de un solo disparo, endurecimiento automático, revisiones de antecedentes, redacción de planes o cuando el objetivo elegido produzca una diferencia vacía.
