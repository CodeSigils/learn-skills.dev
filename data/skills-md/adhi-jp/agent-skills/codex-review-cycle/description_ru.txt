Запустите ограниченный трехцикловый интерактивный рабочий процесс проверки и исправления для выбранной пользователем цели проверки git (разность рабочего дерева, текущая ветвь по сравнению с автоматически обнаруженной базой или явная ссылка на фиксацию/тег/ветвь) с помощью плагина кодекса. Каждый цикл вызывает код `review` или `adversarial-review --json`; Клод сверяет каждый вывод с контрольным списком достоверности из шести пунктов, вызывает функцию «review-scope-guard» для сортировки «Определение готовности», а пользователь выбирает, какие выводы следует исправить перед следующим циклом. Охватывает как различия кода, так и документы планирования уценки. Жесткий предел на 3 циклах. Используйте ТОЛЬКО тогда, когда пользователь явно запрашивает запуск цикла проверки кодекса при изменениях рабочего дерева, подтвержденных различиях ветвей или явной базовой ссылке. НЕ активируйте запрос на однократную проверку, автоматическое усиление, фоновые проверки, составление плана или когда выбранная цель приведет к пустому результату сравнения.
