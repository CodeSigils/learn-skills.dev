使用 codex 外掛程式針對使用者選擇的 git 審查目標（工作樹差異、目前分支與自動偵測的基礎或明確提交/標籤/分支引用）執行有界 3 週期互動審查和修復工作流程。每個週期都會呼叫 codex `review` 或 `adversarial-review --json`； Claude 根據六項有效性檢查表驗證每個發現，呼叫「review-scope-guard」進行「完成定義」分類，然後使用者選擇在下一個週期之前修復哪些發現。涵蓋程式碼差異和降價計劃文件。 3 個週期的硬上限。僅當使用者明確要求對工作樹更改、提交的分支差異或明確基本引用運行法典審查週期時才使用。不要觸發單次審核請求、自動強化、後台審核、計畫起草或所選目標將產生空差異時觸發。
