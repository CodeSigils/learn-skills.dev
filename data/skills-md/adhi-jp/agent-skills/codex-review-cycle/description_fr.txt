Exécutez un flux de travail interactif de révision et de correction en 3 cycles sur une cible de révision git choisie par l'utilisateur (diff d'arbre de travail, branche actuelle par rapport à une base détectée automatiquement, ou une référence de validation/balise/branche explicite) à l'aide du plugin codex. Chaque cycle invoque « review » ou « adversarial-review --json » du codex ; Claude vérifie chaque résultat par rapport à une liste de contrôle de validité de six éléments, appelle « review-scope-guard » pour le tri Définition-de-Terminé, et l'utilisateur choisit les résultats à corriger avant le cycle suivant. Couvre à la fois les différences de code et les documents de planification des démarques. Bouchon rigide à 3 cycles. À utiliser UNIQUEMENT lorsque l'utilisateur demande explicitement d'exécuter le cycle de révision du codex sur les modifications de l'arbre de travail, une différence de branche validée ou une référence de base explicite. Ne déclenchez PAS les demandes de révision ponctuelles, le durcissement automatique, les révisions en arrière-plan, la rédaction d'un plan ou lorsque la cible choisie produirait un différentiel vide.
