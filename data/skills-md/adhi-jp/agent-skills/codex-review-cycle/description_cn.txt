使用 codex 插件针对用户选择的 git 审查目标（工作树差异、当前分支与自动检测的基础或显式提交/标签/分支引用）运行有界 3 周期交互式审查和修复工作流程。每个周期都会调用 codex `review` 或 `adversarial-review --json`； Claude 根据六项有效性检查表验证每个发现，调用“review-scope-guard”进行“完成定义”分类，然后用户选择在下一个周期之前修复哪些发现。涵盖代码差异和降价计划文档。 3 个周期的硬上限。仅当用户明确要求对工作树更改、提交的分支差异或显式基本引用运行法典审查周期时才使用。不要触发单次审核请求、自动强化、后台审核、计划起草或所选目标将产生空差异时触发。
