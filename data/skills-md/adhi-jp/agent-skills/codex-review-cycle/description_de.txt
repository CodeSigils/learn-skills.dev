Führen Sie mit dem Codex-Plugin einen begrenzten interaktiven Review-and-Fix-Workflow mit drei Zyklen für ein vom Benutzer ausgewähltes Git-Review-Ziel aus (Arbeitsbaum-Diff, aktueller Branch vs. automatisch erkannte Basis oder eine explizite Commit-/Tag-/Branch-Referenz). Jeder Zyklus ruft den Codex „review“ oder „adversarial-review --json“ auf; Claude überprüft jeden Befund anhand einer sechs Punkte umfassenden Gültigkeitscheckliste, ruft „review-scope-guard“ für die Definition-of-Done-Triage auf und der Benutzer wählt aus, welche Befunde vor dem nächsten Zyklus korrigiert werden sollen. Deckt sowohl Codeunterschiede als auch Markdown-Planungsdokumente ab. Hartkappe bei 3 Zyklen. Verwenden Sie dies NUR, wenn der Benutzer ausdrücklich darum bittet, den Codex-Überprüfungszyklus für Änderungen am Arbeitsbaum, einen festgeschriebenen Zweigunterschied oder einen expliziten Basisverweis auszuführen. NICHT bei einmaligen Überprüfungsanfragen, automatischer Härtung, Hintergrundüberprüfungen, Planerstellung oder wenn das ausgewählte Ziel ein leeres Diff erzeugen würde, auslösen.
