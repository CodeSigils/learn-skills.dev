Da utilizzare quando l'utente chiede di eseguire il commit, lo stage o il "salvataggio" delle modifiche alla codifica assistita dall'agente, incluse richieste vaghe come "commit this", "commit please", "コミットして" o "/commit" - e il vero lavoro è decidere quali file appartengono al commit, escludendo file indesiderati o generati, suddividendo modifiche non correlate o correggendo il set di file di un commit, il trasporto dei messaggi su più righe, la cronologia (modifica/rebase) o trailer d'autore. Questa abilità possiede l'esecuzione del commit, il trasporto dei messaggi e la sicurezza git.
