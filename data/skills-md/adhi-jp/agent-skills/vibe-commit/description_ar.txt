يُستخدم عندما يطلب المستخدم تنفيذ تغييرات الترميز بمساعدة الوكيل أو تنظيمها أو "حفظها" - بما في ذلك الطلبات الغامضة مثل "الالتزام بهذا"، أو "الالتزام من فضلك"، أو "コミットして"، أو "/ الالتزام" - والعمل الحقيقي هو تحديد الملفات التي تنتمي إلى الالتزام، باستثناء الملفات غير المرغوب فيها أو التي تم إنشاؤها، أو تقسيم التغييرات غير ذات الصلة، أو إصلاح مجموعة ملفات الالتزام، أو نقل الرسائل متعددة الأسطر، أو التاريخ (التعديل/إعادة الأساس)، أو مقطورات التأليف. تمتلك هذه المهارة تنفيذ الالتزام ونقل الرسائل وسلامة البوابة.
