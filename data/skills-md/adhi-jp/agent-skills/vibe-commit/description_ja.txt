ユーザーがエージェント支援コーディングの変更をコミット、ステージング、または「保存」するように要求する場合に使用します。これには、「これをコミットしてください」、「コミットしてください」、「コミットして」、または「/commit」などの曖昧な要求も含まれます。実際の作業は、コミットに属するファイルを決定すること、不要なファイルや生成されたファイルを除外すること、無関係な変更を分割すること、またはコミットのファイルセット、複数行のメッセージトランスポート、履歴（修正/リベース）、またはオーサーシップトレーラーを修正することです。このスキルは、コミットの実行、メッセージのトランスポート、および git の安全性を所有します。
