ユーザーがエージェント支援コーディングの変更をコミット、ステージング、または「保存」するように要求する場合に使用します。これには、「これをコミットしてください」、「コミットしてください」、「コミットして」、「/commit」などの曖昧な要求も含まれます。実際の作業は、どのファイルがコミットに属するかを決定し、不要なファイルまたは生成されたファイルを除外し、無関係な変更を分割し、コミットのファイルセット、複数行のメッセージトランスポート、履歴（修正/リベース）、またはオーサーシップトレーラーを修正することです。このスキルは、コミットの実行、メッセージのトランスポート、および git の安全性を所有します。
