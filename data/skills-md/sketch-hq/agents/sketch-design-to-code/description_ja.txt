Sketch MCP (`get_document_info`、`get_layer_tree_summary`、`get_screenshot`、`get_symbol_overrides`、`get_design_assets`、ターゲットを絞った `run_code`) を使用して、1:1 の視覚的忠実度で Sketch デザインからコードを生成します。最初に既存のプロジェクト コードと規約を検査し、シンボルとオーバーライドを再利用可能なコンポーネントにマッピングし、アセットをエクスポートし、Sketch スクリーンショット (Web: 実行中のアプリと `get_screenshot`) に対して実装を検証します。 React、Tailwind、SwiftUI、Kotlin、またはその他のテクノロジーで Sketch ドキュメント、ページ、フレーム、またはレイヤーから UI を実装または更新するときに使用します。
