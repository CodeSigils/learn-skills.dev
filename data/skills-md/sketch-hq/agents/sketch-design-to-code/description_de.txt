Generiert Code aus Sketch-Designs mit 1:1 visueller Wiedergabetreue mithilfe von Sketch MCP („get_document_info“, „get_layer_tree_summary“, „get_screenshot“, „get_symbol_overrides“, „get_design_assets“, gezielter „run_code“). Überprüft zunächst den vorhandenen Projektcode und die Konventionen, ordnet Symbole und Überschreibungen wiederverwendbaren Komponenten zu, exportiert Assets und validiert Implementierungen anhand von Sketch-Screenshots (Web: Ausführen der App vs. „get_screenshot“). Wird zum Implementieren oder Aktualisieren der Benutzeroberfläche in React, Tailwind, SwiftUI, Kotlin oder anderen Technologien aus einem Sketch-Dokument, einer Seite, einem Frame oder einer Ebene verwendet.
