Inspecte d'abord le code et les conventions du projet existant, mappe les symboles et les remplacements aux composants réutilisables, exporte les actifs et valide les implémentations par rapport aux captures d'écran Sketch (Web : application en cours d'exécution vs `get_screenshot`). À utiliser lors de l'implémentation ou de la mise à jour de l'interface utilisateur dans React, Tailwind, SwiftUI, Kotlin ou d'autres technologies à partir d'un document, d'une page, d'un cadre ou d'un calque Sketch.
