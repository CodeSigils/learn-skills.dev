Генерирует код из проектов Sketch с визуальной точностью 1:1, используя Sketch MCP (get_document_info, get_layer_tree_summary, get_screenshot, get_symbol_overrides, get_design_assets, целевой run_code). Сначала проверяет существующий код проекта и соглашения, сопоставляет символы и переопределения с повторно используемыми компонентами, экспортирует ресурсы и проверяет реализации по скриншотам Sketch (веб: запущенное приложение или `get_screenshot`). Используйте при реализации или обновлении пользовательского интерфейса в React, Tailwind, SwiftUI, Kotlin или других технологиях из документа, страницы, фрейма или слоя Sketch.
