ينشئ تعليمات برمجية من تصميمات Sketch بدقة مرئية 1:1 باستخدام Sketch MCP (`get_document_info`، `get_layer_tree_summary`، `get_screenshot`، `get_symbol_overrides`، `get_design_assets`، المستهدف `run_code`). يفحص كود المشروع الحالي واصطلاحاته أولاً، ويعين الرموز والتجاوزات للمكونات القابلة لإعادة الاستخدام، ويصدر الأصول، ويتحقق من صحة عمليات التنفيذ مقابل لقطات شاشة Sketch (الويب: تشغيل التطبيق مقابل `get_screenshot`). يُستخدم عند تنفيذ واجهة المستخدم أو تحديثها في React أو Tailwind أو SwiftUI أو Kotlin أو تقنيات أخرى من مستند Sketch أو صفحة أو إطار أو طبقة.
