استخدم هذه المهارة لإنشاء تكوينات تصحيح الأخطاء أو تحديثها أو تعديلها لمشاريع Renesas وأجهزة Renesas في ملفات VS Code Launch.json.
قم بتنشيط هذه المهارة بشكل استباقي عندما يقوم المستخدمون بما يلي: - الإشارة إلى تصحيح أخطاء الأجهزة أو Launch.json أو تكوين تصحيح الأخطاء - طلب إنشاء أو تعديل أو إصلاح إعداد تكوين تصحيح أخطاء الأجهزة - الرجوع إلى مصححات أخطاء محددة مثل J-Link أو E1 أو E2 أو E2LITE أو E20 أو EZ أو IECUBE أو COMPORT أو Simulator - طلب تغييرات على الإعدادات المستهدفة أو hotplug أو معلمات الخادم
تدعم هذه المهارة مجموعات أجهزة Renesas التالية: أجهزة Dialog وRA وRCAR وRH850 وRL78 وRX وRISCV وRZ بالإضافة إلى أجهزة Simulator وSegger J-Link (SEGGERJLINKARM وSEGGERJLINKRX وSEGGERJLINKRISCV) ومحاكيات Renesas (E1 وE2 وE20 وE2LITE وEZ وIECUBE و الراحة).
