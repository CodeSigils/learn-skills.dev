Utilizza questa competenza per creare, aggiornare o modificare le configurazioni di debug per i progetti Renesas e i dispositivi Renesas nei file launch.json di VS Code.
Attiva in modo proattivo questa abilità quando gli utenti: - Menzionano il debug hardware, launch.json o la configurazione di debug - Chiedi di creare, modificare o correggere un'impostazione di configurazione del debug hardware - Fai riferimento a debugger specifici come J-Link, E1, E2, E2LITE, E20, EZ, IECUBE, COMPORT o Simulator - Richiedi modifiche alle impostazioni di destinazione, hotplug o parametri del server
Questa Skill supporta le seguenti famiglie di dispositivi Renesas: Dialog, RA, RCAR, RH850, RL78, RX, RISCV e RZ, nonché il simulatore, Segger J-Link (SEGGERJLINKARM, SEGGERJLINKRX, SEGGERJLINKRISCV) e gli emulatori Renesas (E1, E2, E20, E2LITE, EZ, IECUBE, COMPORT).
