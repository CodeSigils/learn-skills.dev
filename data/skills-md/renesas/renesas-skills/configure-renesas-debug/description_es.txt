Utilice esta habilidad para crear, actualizar o modificar configuraciones de depuración para proyectos de Renesas y dispositivos de Renesas en archivos VS Code launch.json.
Active esta habilidad de forma proactiva cuando los usuarios: - Mencionen la depuración de hardware, launch.json o la configuración de depuración - Soliciten crear, modificar o corregir una configuración de depuración de hardware - Consulten depuradores específicos como J-Link, E1, E2, E2LITE, E20, EZ, IECUBE, COMPORT o Simulator - Soliciten cambios en la configuración de destino, hotplug o parámetros del servidor
Esta habilidad admite las siguientes familias de dispositivos Renesas: dispositivos Dialog, RA, RCAR, RH850, RL78, RX, RISCV y RZ, así como el simulador, Segger J-Link (SEGGERJLINKARM, SEGGERJLINKRX, SEGGERJLINKRISCV) y emuladores Renesas (E1, E2, E20, E2LITE, EZ, IECUBE, COMPORT).
