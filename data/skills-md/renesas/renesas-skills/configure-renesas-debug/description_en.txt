Use this skill to create, update, or modify debug configurations for Renesas projects and Renesas devices in VS Code launch.json files.
Proactively activate this skill when users: - Mention hardware debug, launch.json, or debug configuration - Ask to create, modify, or fix a hardware debug configuration setup - Refer to specific debuggers such as J-Link, E1, E2, E2LITE, E20, EZ, IECUBE, COMPORT, or Simulator - Request changes to target settings, hotplug, or server parameters
This skill supports the following Renesas device families: Dialog, RA, RCAR, RH850, RL78, RX, RISCV, and RZ devices as well as the Simulator, Segger J-Link (SEGGERJLINKARM, SEGGERJLINKRX, SEGGERJLINKRISCV) and Renesas Emulators (E1, E2, E20, E2LITE, EZ, IECUBE, COMPORT).
