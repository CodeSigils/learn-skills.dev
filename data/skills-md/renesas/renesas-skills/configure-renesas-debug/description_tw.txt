使用此技能可以在 VS Code launch.json 檔案中建立、更新或修改 Renesas 專案和 Renesas 裝置的偵錯配置。
當使用者出現以下情況時，主動啟動此技能： - 提及硬體調試、launch.json 或調試配置 - 要求創建、修改或修復硬體調試配置設定 - 參考特定調試器，例如 J-Link、E1、E2、E2LITE、E20、EZ、IECUBE、COMPORT 或模擬器 - 請求更改目標設定、熱插或參數
此技能支援以下 Renesas 設備系列：Dialog、RA、RCAR、RH850、RL78、RX、RISCV 和 RZ 設備以及模擬器、Segger J-Link（SEGGERJLINKARM、SEGGERJLINKRX、SEGGERJLINKRISCV）和 Renesas 模擬器（E1CU、E2、E20、E2、E2、E1CU、E2、E1CU、E2、E2、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、E2、E1、E2、206616163332）。
