このスキルを使用して、VS Code launch.json ファイル内の Renesas プロジェクトおよび Renesas デバイスのデバッグ構成を作成、更新、または変更します。
ユーザーが次の場合にこのスキルを積極的にアクティブにします。 - ハードウェア デバッグ、launch.json、またはデバッグ構成について言及する - ハードウェア デバッグ構成セットアップの作成、変更、または修正を依頼する - J-Link、E1、E2、E2LITE、E20、EZ、IECUBE、COMPORT、またはシミュレーターなどの特定のデバッガーを参照する - ターゲット設定、ホットプラグ、またはサーバー パラメーターの変更を要求する
このスキルは、Dialog、RA、RCAR、RH850、RL78、RX、RISCV、および RZ デバイスのほか、シミュレータ、Segger J-Link (SEGGERJLINKARM、SEGGERJLINKRX、SEGGERJLINKRISCV)、および Renesas エミュレータ (E1、E2、E20、E2LITE、EZ、IECUBE、COMPORT) の Renesas デバイス ファミリをサポートします。
