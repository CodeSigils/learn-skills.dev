Développer, maintenir, distribuer et valider la compétence exécutable du plugin DeepSeek Harness (DSH). Il couvre la détection du mode hôte/client, les contrats de bundle/profil, les plugins de services et de fonctions, les outils, HTTP, la persistance, les emplacements, le nœud de conversation, la construction côté client, HMR, l'installation de GitHub et la véritable vérification de la composition.
