Développer, maintenir, distribuer et valider la compétence exécutable du plugin DeepSeek Harness (DSH). Il couvre la détection des formulaires hôte/client, les contrats de bundle/profil, les plugins de services et de fonctions, les outils, HTTP, la persistance, les emplacements, le nœud de conversation, les versions client, HMR, l'installation de GitHub et la vérification de la composition dans le monde réel.
