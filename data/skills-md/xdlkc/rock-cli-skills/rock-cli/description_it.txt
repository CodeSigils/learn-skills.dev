Guida per l'utente della CLI ROCK. Casi d'uso: installa/aggiorna rockcli, avvia sandbox, arresta sandbox, esegui comandi in sandbox/exec, carica file su sandbox, scarica file da sandbox, visualizza log sandbox/ricerca log/coda log, connettiti a sandbox/collega/REPL interattivo, visualizza cronologia/cronologia sandbox, richieste/replay di riproduzione, controlla stato/stato. Da utilizzare quando l'utente menziona sandbox, rockcli, comandi rc o operazioni sandbox.
