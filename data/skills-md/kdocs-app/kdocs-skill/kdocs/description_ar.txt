قم بتشغيل Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) للمستندات السحابية بمهارة رسمية. تغطي الإمكانات الأساسية إنشاء المستندات عبر الإنترنت وقراءتها وتحريرها والبحث فيها ومشاركتها وتنظيمها (المستندات الذكية وWord وExcel وPDF وPPT والعروض التقديمية والجداول الذكية والجداول متعددة الأبعاد) وقواعد المعرفة الشخصية. يتم استخدامه عندما تتضمن مهمة المستخدم عمليات مستندات سحابية، بما في ذلك على سبيل المثال لا الحصر: كتابة تقارير أسبوعية / يومية / عمل، والتعامل مع العقود / الفواتير، وإنشاء نماذج التسجيل أو الاشتراك، وقص الويب، وتحويل السلسلة إلى جداول بيانات، وجمع المعلومات، وتلخيص المستندات وإنشاء المحتوى، وإعادة الكتابة / إعادة الصياغة، والترجمة، وإنشاء AI PPT، وتقسيم ملفات PDF وتصديرها، وتصنيف العلامات وأرشفتها، وإدارة الإشارات المرجعية، وتنظيم الملاحظات المجزأة، وتجميل جداول البيانات، وسلة المحذوفات. الترميم وإدارة قاعدة المعرفة.
