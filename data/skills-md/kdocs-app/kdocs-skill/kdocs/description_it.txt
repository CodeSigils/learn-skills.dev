Utilizza i documenti cloud Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) con le competenze ufficiali. Le funzionalità principali riguardano la creazione, la lettura, la modifica, la ricerca, la condivisione e l'organizzazione di documenti online (documenti intelligenti, Word, Excel, PDF, PPT, presentazioni, fogli intelligenti, fogli multidimensionali) e basi di conoscenza personali nel cloud. Viene utilizzato quando l'attività di un utente prevede operazioni di documenti cloud, incluse ma non limitate a: scrittura di report settimanali/giornalieri o riepiloghi di lavoro, gestione di contratti/fatture, creazione di moduli di registrazione o iscrizione, ritaglio web, conversione di voci concatenate in fogli di calcolo, raccolta di informazioni, riepilogo di documenti e generazione di contenuti, riscrittura/parafrasi, traduzione, generazione di AI PPT, suddivisione ed esportazione di PDF, classificazione e archiviazione di tag, gestione di segnalibri, organizzazione di note di frammenti, abbellimento di fogli di calcolo, ripristino dei contenitori di riciclaggio e gestione della base di conoscenza.
