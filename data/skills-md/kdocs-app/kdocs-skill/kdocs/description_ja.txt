Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) クラウドドキュメントの公式スキルを操作します。その中核となる機能には、オンライン ドキュメント (スマート ドキュメント、Word、Excel、PDF、PPT、プレゼンテーション、スマート スプレッドシート、多次元スプレッドシート) の作成、読み取り、編集、検索、共有、整理と、個人のナレッジ ベースが含まれます。これは、週次/日次/業務報告書の作成、契約書または請求書の処理、登録または登録フォームの作成、Web クリッピング、スプレッドシートへのチェーン変換、情報収集、文書の要約とコンテンツ生成、リライトまたは言い換え、翻訳、AI PPT 生成、PDF 分割とエクスポート、タグ分類とアーカイブ、ブックマーク管理、フラグメント ノートの整理、スプレッドシートの美化、ごみ箱を含むがこれらに限定されない、ユーザーのタスクがクラウド ドキュメント操作に関係する場合に常に使用されます。復元とナレッジベース管理。
