Operate Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) cloud documents official skill. Its core capabilities cover creating, reading, editing, searching, sharing, and organizing online documents (smart documents, Word, Excel, PDF, PPT, presentations, smart spreadsheets, multidimensional spreadsheets) as well as personal knowledge bases. It is used whenever a user's task involves cloud‑document operations, including but not limited to: writing weekly/daily/work reports, handling contracts or invoices, creating registration or enrollment forms, web clipping, chain conversion to spreadsheets, information collection, document summarization and content generation, rewriting or paraphrasing, translation, AI PPT generation, PDF splitting and export, tag classification and archiving, bookmark management, fragment note organization, spreadsheet beautification, recycle‑bin restoration, and knowledge‑base management.
