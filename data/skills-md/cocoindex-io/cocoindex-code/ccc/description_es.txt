Esta habilidad debe usarse cuando se necesita una búsqueda de código (ya sea solicitada explícitamente o como parte de completar una tarea), al indexar el código base después de cambios o cuando el usuario pregunta sobre ccc, cocoindex-code o el índice de la base de código. Las frases de activación incluyen "buscar en la base del código", "buscar código relacionado con", "actualizar el índice", "ccc", "código cocoindex".
