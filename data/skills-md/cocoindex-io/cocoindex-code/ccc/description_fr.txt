Cette compétence doit être utilisée lorsqu'une recherche de code est nécessaire (que ce soit explicitement demandée ou dans le cadre de l'exécution d'une tâche), lors de l'indexation de la base de code après des modifications, ou lorsque l'utilisateur pose des questions sur ccc, cocoindex-code ou l'index de la base de code. Les phrases de déclenchement incluent « rechercher dans la base de code », « trouver le code lié à », « mettre à jour l'index », « ccc », « cocoindex-code ».
