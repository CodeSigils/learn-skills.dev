يجب استخدام هذه المهارة عند إنشاء خطوط معالجة البيانات باستخدام CocoIndex، وهي مكتبة Python لتحويل البيانات المتزايدة. يُستخدم عندما تتضمن المهمة معالجة الملفات/البيانات في قواعد البيانات، أو إنشاء عمليات تضمين متجهة، أو إنشاء رسوم بيانية للمعرفة، أو سير عمل ETL، أو أي خط أنابيب بيانات يتطلب الكشف التلقائي عن التغيير والتحديثات المتزايدة. CocoIndex هو لغة Python الأصلية (يدعم أي نوع من أنواع Python)، ولا يحتوي على DSL، ويستخدم الإصدار 1.0.0 أو أحدث.
