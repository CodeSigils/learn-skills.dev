Guía de mejores prácticas para reaccionar-native-vision-camera v5 (reescritura de Nitro, abril de 2026) y migración desde v4. Úselo al instalar, configurar o escribir código con la cámara, salidas, procesadores de cuadros, grabación o funciones de código de barras/profundidad/RAW. Úselo también al convertir código v4 (photo={true}, takePhoto, useCameraFormat, useFrameProcessor) a la nueva API v5.
