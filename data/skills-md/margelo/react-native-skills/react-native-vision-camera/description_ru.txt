Руководство по передовому опыту для React-Native-Vision-Camera v5 (переработка Nitro, апрель 2026 г.) и перехода с v4. Используйте при установке, настройке или написании кода с помощью камеры, выходов, процессоров кадров, записи или функций штрих-кода/глубины/RAW. Также используйте при преобразовании кода версии 4 (photo={true}, takePhoto, useCameraFormat, useFrameProcessor) в новый API версии 5.
