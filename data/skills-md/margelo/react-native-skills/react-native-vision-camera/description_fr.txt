Guide des bonnes pratiques pour React-Native-Vision-Camera v5 (réécriture Nitro, avril 2026) et migration depuis la v4. À utiliser lors de l'installation, de la configuration ou de l'écriture de code avec la caméra, les sorties, les processeurs d'image, l'enregistrement ou les fonctionnalités de code-barres/profondeur/RAW. À utiliser également lors de la conversion du code v4 (photo={true}, takePhoto, useCameraFormat, useFrameProcessor) vers la nouvelle API v5.
