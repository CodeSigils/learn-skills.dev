Best-Practice-Leitfaden für React-Native-Vision-Camera v5 (Nitro Rewrite, April 2026) und Migration von v4. Wird zum Installieren, Konfigurieren oder Schreiben von Code mit der Kamera, Ausgängen, Bildprozessoren, Aufzeichnungs- oder Barcode-/Tiefen-/RAW-Funktionen verwendet. Wird auch beim Konvertieren von v4-Code (photo={true}, takePhoto, useCameraFormat, useFrameProcessor) in die neue v5-API verwendet.
