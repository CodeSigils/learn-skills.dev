تصميم ومراجعة خطوط أنابيب VisionCamera v5 ذات زمن الوصول المنخفض على مستوى الإنتاج. يُستخدم لتراكبات GPU أو ML أو CV أو Skia أو WebGPU في الوقت الفعلي، والمكونات الإضافية لإطار Nitro، والتشغيل المتداخل بدون نسخة، وميزانيات الإطارات، وملفات تعريف زمن الاستجابة. استخدم مهارة كاميرا الرؤية الأصلية العامة للإعداد أو الالتقاط أو عناصر التحكم أو مخرجات الإطار الأساسية أو ترحيل الإصدار الرابع.
