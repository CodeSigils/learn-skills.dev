تخزين سريع لقيمة المفتاح المتزامن لـ React Native عبر React-Native-mmkv (مدعوم من Nitro). يغطي إنشاء مثيلات MMKV وتكوينها، وقراءة/كتابة جميع أنواع القيم (السلسلة، والرقم، والمنطقي، والمخزن المؤقت)، وخطافات React لواجهة المستخدم التفاعلية، ومستمعي تغيير القيمة، والتشفير، وترحيل AsyncStorage، وتكامل إدارة الحالة (zustand، وredux-persist، وjotai، واستعلام التفاعل). يغطي أيضًا حدود التخزين ووضع العمليات المتعددة وترقية V4 من واجهة برمجة التطبيقات المستندة إلى الفئة.
