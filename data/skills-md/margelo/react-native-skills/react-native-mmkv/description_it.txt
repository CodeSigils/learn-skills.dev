Archiviazione rapida e sincrona di valori-chiave per React Native tramite react-native-mmkv (supportato da Nitro). Copre la creazione e la configurazione di istanze MMKV, la lettura/scrittura di tutti i tipi di valore (stringa, numero, booleano, buffer), hook React per interfaccia utente reattiva, listener di modifica del valore, crittografia, migrazione AsyncStorage e integrazioni di gestione dello stato (zustand, redux-persist, jotai, react-query). Copre anche i limiti di archiviazione, la modalità multiprocesso e l'aggiornamento V4 dall'API basata su classi.
