Stockage clé-valeur synchrone rapide pour React Native via React-native-mmkv (soutenu par Nitro). Couvre la création et la configuration des instances MMKV, la lecture/écriture de tous les types de valeur (chaîne, nombre, booléen, tampon), les hooks React pour l'interface utilisateur réactive, les écouteurs de changement de valeur, le chiffrement, la migration AsyncStorage et les intégrations de gestion d'état (zustand, redux-persist, jotai, réagir-query). Couvre également les limites de stockage, le mode multi-processus et la mise à niveau V4 à partir de l'API basée sur les classes.
