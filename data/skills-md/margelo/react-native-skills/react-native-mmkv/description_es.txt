Almacenamiento rápido y sincrónico de valores clave para React Native a través de react-native-mmkv (respaldado por Nitro). Cubre la creación y configuración de instancias MMKV, lectura/escritura de todos los tipos de valores (cadena, número, booleano, búfer), enlaces de React para UI reactiva, escuchas de cambio de valor, cifrado, migración de AsyncStorage e integraciones de administración de estado (zustand, redux-persist, jotai, react-query). También cubre los límites de almacenamiento, el modo multiproceso y la actualización V4 de la API basada en clases.
