Быстрое синхронное хранилище значений ключа для React Native через React-native-mmkv (с поддержкой Nitro). Охватывает создание и настройку экземпляров MMKV, чтение/запись всех типов значений (строка, число, логическое значение, буфер), перехватчики React для реактивного пользовательского интерфейса, прослушиватели изменения значений, шифрование, миграцию AsyncStorage и интеграцию управления состоянием (zustand, redux-persist, jotai, response-query). Также рассматриваются ограничения хранилища, многопроцессный режим и обновление V4 API на основе классов.
