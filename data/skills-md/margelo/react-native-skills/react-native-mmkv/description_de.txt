Schneller synchroner Schlüsselwertspeicher für React Native über React-Native-MMKV (Nitro-backed). Behandelt das Erstellen und Konfigurieren von MMKV-Instanzen, das Lesen/Schreiben aller Werttypen (String, Zahl, Boolescher Wert, Puffer), React-Hooks für reaktive Benutzeroberfläche, Wertänderungs-Listener, Verschlüsselung, AsyncStorage-Migration und Statusverwaltungsintegrationen (Zustand, Redux-Persist, Jotai, React-Query). Deckt außerdem Speichergrenzen, den Mehrprozessmodus und das V4-Upgrade der klassenbasierten API ab.
