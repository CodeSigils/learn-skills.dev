Crea módulos React Native Nitro desde cero en un monorepo. Scaffolding with Nitrogen, crea especificaciones de HybridObject TypeScript, genera texto estándar nativo, implementa en C++/Swift/Kotlin, conecta una aplicación de ejemplo y se prepara para la publicación de npm. Úselo al crear un nuevo módulo Nitro, implementar la funcionalidad nativa a través de HybridObjects o configurar la tubería de codegen de nitrógeno.
