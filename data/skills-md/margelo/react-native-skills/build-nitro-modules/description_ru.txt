Собирает модули React Native Nitro с нуля в монорепозитории. Создает леса с Nitrogen, пишет спецификации HybridObject TypeScript, генерирует собственный шаблон, реализует на C++/Swift/Kotlin, подключает пример приложения и готовится к публикации npm. Используйте при создании нового модуля Nitro, реализации собственных функций через HybridObjects или настройке конвейера кодирования азота.
