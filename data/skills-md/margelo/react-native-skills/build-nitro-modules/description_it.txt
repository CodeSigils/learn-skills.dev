Costruisce da zero i moduli React Native Nitro in un monorepo. Scaffolds with Nitrogen, crea specifiche HybridObject TypeScript, genera boilerplate nativo, implementa in C++/Swift/Kotlin, collega un'app di esempio e prepara la pubblicazione npm. Da utilizzare durante la creazione di un nuovo modulo Nitro, l'implementazione di funzionalità native tramite HybridObjects o l'impostazione della pipeline di codegen dell'azoto.
