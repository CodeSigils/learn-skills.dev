يبني وحدات React Native Nitro من الصفر في monorepo. السقالات التي تحتوي على النيتروجين، ومواصفات HybridObject TypeScript الخاصة بالمؤلفين، وإنشاء نموذج أساسي أصلي، وتنفيذها في C++/Swift/Kotlin، وتوصيل تطبيق مثال، والتحضير لنشر npm. يُستخدم عند إنشاء وحدة Nitro جديدة، أو تنفيذ الوظائف الأصلية عبر HybridObjects، أو إعداد خط أنابيب توليد ترميز النيتروجين.
