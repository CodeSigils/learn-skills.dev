基於 Nitro 模組建構的 React Native 的快速本機網路原語——react-native-nitro-fetch、react-native-硝基-websockets 和 react-native-硝基-文字解碼器。涵蓋了 fetch API、全域替換、預取和冷啟動快取預熱、NitroWebSocket 類別和預熱、從 React Native 的內建 WebSocket 遷移、進程內 NetworkInspector、本機 Perfetto / Instruments 追蹤、本機 TextDecoder，以及透過自訂適配器將 nitroax 插入 nitroax-fetch 分配器。
