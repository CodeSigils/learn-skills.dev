Быстрые собственные сетевые примитивы для React Native, построенные на модулях Nitro — React-native-nitro-fetch, React-native-nitro-websockets и React-native-nitro-text-decoder. Охватывает API выборки, глобальную замену, предварительную выборку и разогрев кэша при холодном запуске, класс NitroWebSocket и предварительный разогрев, миграцию со встроенного WebSocket React Native, внутрипроцессный NetworkInspector, встроенную трассировку Perfetto/Instruments, собственный TextDecoder и подключение nitro-fetch к axios через специальный адаптер.
