Schnelle native Netzwerkprimitive für React Native, die auf Nitro-Modulen basieren – React-Native-Nitro-Fetch, React-Native-Nitro-Websockets und React-Native-Nitro-Text-Decoder. Behandelt die Fetch-API, globales Ersetzen, Prefetching und Kaltstart-Cache-Erwärmung, die NitroWebSocket-Klasse und Pre-Warming, die Migration vom integrierten WebSocket von React Native, den In-Process-NetworkInspector, natives Perfetto/Instruments-Tracing, den nativen TextDecoder und die Einbindung von Nitro-Fetch in Axios über einen benutzerdefinierten Adapter.
