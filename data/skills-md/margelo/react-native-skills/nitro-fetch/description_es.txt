Primitivas de red nativas rápidas para React Native basadas en módulos Nitro: reaccionar-nativo-nitro-fetch, reaccionar-nativo-nitro-websockets y reaccionar-nativo-nitro-text-decodificador. Cubre la API de recuperación, el reemplazo global, la recuperación previa y el calentamiento de caché de inicio en frío, la clase NitroWebSocket y el precalentamiento, la migración desde el WebSocket integrado de React Native, el NetworkInspector en proceso, el seguimiento nativo de Perfetto/Instrumentos, el TextDecoder nativo y la conexión de nitro-fetch a axios a través de un adaptador personalizado.
