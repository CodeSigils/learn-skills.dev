Primitives de mise en réseau natives rapides pour React Native basées sur les modules Nitro : React-native-nitro-fetch, React-native-nitro-websockets et React-native-nitro-text-decoder. Couvre l'API de récupération, le remplacement global, la prélecture et le réchauffement du cache par démarrage à froid, la classe NitroWebSocket et le préchauffage, la migration depuis le WebSocket intégré de React Native, le NetworkInspector en cours, le traçage natif Perfetto/Instruments, le TextDecoder natif et le branchement de nitro-fetch à axios via un adaptateur personnalisé.
