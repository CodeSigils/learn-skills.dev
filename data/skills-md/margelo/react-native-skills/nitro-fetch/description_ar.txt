أساسيات الشبكات الأصلية السريعة لـ React Native المبنية على وحدات Nitro — جلب نيترو تفاعلي أصلي، ومآخذ ويب تفاعلية نيترو أصلية، ووحدة فك ترميز نصوص نيترو تفاعلية أصلية. يغطي واجهة برمجة تطبيقات الجلب، والاستبدال العام، والجلب المسبق وتسخين ذاكرة التخزين المؤقت للتشغيل البارد، وفئة NitroWebSocket والتدفئة المسبقة، والانتقال من WebSocket المدمج في React Native، وNetworkInspector قيد التشغيل، وتتبع Perfetto / Instruments الأصلي، وTextDecoder الأصلي، وتوصيل nitro-fetch إلى axios عبر محول مخصص.
