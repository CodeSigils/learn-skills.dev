Progetta e rivedi API pubbliche prevedibili per le librerie TypeScript, JavaScript, React e React Native. Da utilizzare per modellare funzioni, classi, hook, oggetti opzioni, API di eventi e listener esportati, comportamento degli errori, denominazione, astrazioni multipiattaforma o pacchetti solo JS. Abbinalo ai moduli build-nitro quando la libreria è supportata da Nitro.
