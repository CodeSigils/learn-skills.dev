تصميم ومراجعة واجهات برمجة التطبيقات العامة التي يمكن التنبؤ بها لمكتبات TypeScript وJavaScript وReact وReact Native. يُستخدم عند تشكيل الوظائف المصدرة، أو الفئات، أو الخطافات، أو كائنات الخيارات، أو واجهات برمجة تطبيقات الأحداث والمستمع، أو سلوك الخطأ، أو التسمية، أو التجريدات عبر الأنظمة الأساسية، أو حزم JS فقط. قم بالاقتران مع وحدات build-nitro عندما تكون المكتبة مدعومة بواسطة Nitro.
