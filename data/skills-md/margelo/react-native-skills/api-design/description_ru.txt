Разрабатывайте и проверяйте предсказуемые общедоступные API для библиотек TypeScript, JavaScript, React и React Native. Используйте при формировании экспортируемых функций, классов, перехватчиков, объектов параметров, API событий и прослушивателей, поведения при ошибках, именования, кроссплатформенных абстракций или пакетов только для JS. Соединитесь с модулями build-nitro, если библиотека поддерживается Nitro.
