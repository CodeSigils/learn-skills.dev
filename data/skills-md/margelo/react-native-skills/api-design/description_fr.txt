Concevez et révisez des API publiques prévisibles pour les bibliothèques TypeScript, JavaScript, React et React Native. À utiliser lors de la mise en forme de fonctions, classes, hooks, objets d'options, API d'événement et d'écoute exportés, comportement d'erreur, dénomination, abstractions multiplateformes ou packages JS uniquement. Associez-le à build-nitro-modules lorsque la bibliothèque est soutenue par Nitro.
