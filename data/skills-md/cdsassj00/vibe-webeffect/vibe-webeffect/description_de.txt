Wenn ein Benutzer eine Webseite, Landingpage oder Web-App-Benutzeroberfläche erstellt oder ändert, liest diese Fähigkeit den Arbeitskontext, empfiehlt geeignete Webanimationseffekte und wendet sogar den Code an. Es basiert auf einem Katalog von 72 Effekten (Scroll Scrubbing/Hover/Signature/Entrance&Reveal/Micro Interaction/Loading&Status/Lab). Diese Fähigkeit muss in den folgenden Situationen verwendet werden: Wenn der Benutzer Ausdrücke wie „eine Webseite erstellen“, „Landingpage“, „Heldenabschnitt“, „Portfolio-Site“, „Dashboard-Benutzeroberfläche“, „Formular/Schaltfläche erstellen“, „Animation hinzufügen“, „Effekte empfehlen“, „lebendiger/polierter/spektakulärer machen“, „ist es langweilig?“, „Interaktion hinzufügen“ usw. erwähnt – auch wenn das Wort „Animation“ nicht vorhanden ist, wird jede Anfrage zum Erstellen oder Verbessern einer Die HTML/CSS/JS-Benutzeroberfläche wird es auslösen.
