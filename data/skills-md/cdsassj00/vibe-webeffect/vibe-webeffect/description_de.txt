Wenn ein Benutzer eine Webseite, Landingpage oder Web-App-Benutzeroberfläche erstellt oder ändert, liest diese Fähigkeit den Arbeitskontext, empfiehlt geeignete Webanimationseffekte und wendet sogar den Code an. Es basiert auf einem Katalog von 72 Effekten (Scroll Scrubbing/Hover/Signature/Entrance&Reveal/Micro‑Interaction/Loading&State/Lab). Der Skill muss in den folgenden Situationen verwendet werden: Wenn der Benutzer „eine Webseite erstellen“, „Landingpage“, „Heldenabschnitt“, „Portfolio-Site“, „Dashboard-Benutzeroberfläche“, „Formular/Schaltfläche erstellen“, „Animation hinzufügen“, „Effekte empfehlen“, „lebendiger/polierter/spektakulärer machen“ oder „ist es langweilig“ erwähnt? „Interaktion hinzufügen“ usw. – selbst wenn das Wort „Animation“ nicht verwendet wird, wird es durch jede Anfrage zum Erstellen oder Verbessern einer HTML/CSS/JS-Benutzeroberfläche ausgelöst.
