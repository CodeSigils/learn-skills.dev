Cuando un usuario crea o modifica una página web, una página de destino o una interfaz de usuario de una aplicación web, esta habilidad lee el contexto de trabajo, recomienda efectos de animación web adecuados e incluso aplica el código. Se basa en un catálogo de 72 efectos (desplazamiento de desplazamiento/desplazamiento/firma/entrada y revelación/micro interacción/carga y estado/laboratorio). Esta habilidad debe usarse en las siguientes situaciones: cuando el usuario menciona frases como "crear una página web", "página de destino", "sección principal", "sitio de cartera", "interfaz de usuario del tablero", "crear un formulario/botón", "agregar animación", "recomendar efectos", "hacerlo más animado/pulido/espectacular", "¿es suave?", "agregar interacción", etc., incluso si la palabra "animación" no está presente, cualquier solicitud para crear o mejorar una HTML/CSS/JS UI lo activará.
