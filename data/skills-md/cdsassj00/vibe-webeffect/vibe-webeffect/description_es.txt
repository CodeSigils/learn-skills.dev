Cuando un usuario crea o modifica una página web, una página de destino o una interfaz de usuario de una aplicación web, esta habilidad lee el contexto de trabajo, recomienda efectos de animación web apropiados e incluso aplica el código. Se basa en un catálogo de 72 efectos (desplazamiento de desplazamiento/desplazamiento/firma/entrada y revelación/microinteracción/carga y estado/laboratorio). La habilidad debe usarse en las siguientes situaciones: cuando el usuario menciona "crear una página web", "página de destino", "sección principal", "sitio de cartera", "interfaz de usuario del tablero", "crear un formulario/botón", "agregar animación", "recomendar efectos", "hacerlo más animado/pulido/llamativo", "¿es insulso?". "agregar interacción", etc.: incluso si no se usa la palabra "animación", se activa cada vez que la solicitud es para crear o mejorar una interfaz de usuario HTML/CSS/JS.
