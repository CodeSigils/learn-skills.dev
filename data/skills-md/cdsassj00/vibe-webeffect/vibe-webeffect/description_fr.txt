Lorsqu'un utilisateur crée ou modifie une page Web, une page de destination ou une interface utilisateur d'application Web, cette compétence lit le contexte de travail, recommande des effets d'animation Web appropriés et applique même le code. Il est basé sur un catalogue de 72 effets (scroll scrubbing/hover/signature/entrance&reveal/micro interaction/loading&status/lab). Cette compétence doit être utilisée dans les situations suivantes : lorsque l'utilisateur mentionne des expressions telles que « créer une page Web », « page de destination », « section héros », « site de portfolio », « interface utilisateur de tableau de bord », « créer un formulaire/bouton », « ajouter une animation », « recommander des effets », « la rendre plus vivante/affinée/spectaculaire », « c'est fade ? », « ajouter de l'interaction », etc. – même si le mot « animation » n'est pas présent, toute demande de création ou d'amélioration d'une L'interface utilisateur HTML/CSS/JS le déclenchera.
