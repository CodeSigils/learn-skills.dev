ユーザーが Web ページ、ランディング ページ、または Web アプリ UI を作成または変更するとき、このスキルは作業コンテキストを読み取り、適切な Web アニメーション効果を推奨し、さらにコードを適用します。これは、72 のエフェクト (スクロール スクラビング / ホバー / シグネチャー / 入口・公開 / マイクロインタラクション / ローディング・ステート / ラボラトリー) のカタログに基づいています。このスキルは次の状況で使用する必要があります。ユーザーが「Web ページを作成する」、「ランディング ページ」、「ヒーロー セクション」、「ポートフォリオ サイト」、「ダッシュボード UI」、「フォーム/ボタンを作成する」、「アニメーションを追加する」、「エフェクトを推奨する」、「活気を与える/洗練された/派手にする」、「地味に見える」、「インタラクションを追加する」などについて言及する場合、「アニメーション」という単語が存在しない場合でも、使用する必要があります。 HTML/CSS/JS UI の作成または改善のリクエストがあるときにトリガーされます。
