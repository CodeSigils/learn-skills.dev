ユーザーが Web ページ、ランディング ページ、または Web アプリ UI を作成または変更すると、このスキルは作業コンテキストを読み取り、適切な Web アニメーション効果を推奨し、さらにコードを適用します。これは、72 のエフェクト (スクロール スクラビング/ホバー/シグネチャ/入口&表示/マイクロ インタラクション/ローディング&ステータス/ラボ) のカタログに基づいています。このスキルは次の状況で使用する必要があります。ユーザーが「Web ページを作成する」、「ランディング ページ」、「ヒーロー セクション」、「ポートフォリオ サイト」、「ダッシュボード UI」、「フォーム/ボタンを作成する」、「アニメーションを追加する」、「エフェクトを推奨する」、「より活気のある/洗練された/壮観なものにする」、「当たり障りのないものですか?」、「インタラクションを追加する」などのフレーズに言及するとき。たとえ「アニメーション」という言葉が使われていない場合でも。存在すると、HTML/CSS/JS UI を作成または改善するリクエストがトリガーされます。
