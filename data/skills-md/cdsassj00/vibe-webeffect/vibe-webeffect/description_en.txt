When a user creates or modifies a webpage, landing page, or web app UI, this skill reads the work context, recommends suitable web animation effects, and even applies the code. It is based on a catalog of 72 effects (scroll scrubbing / hover / signature / entrance & reveal / micro interaction / loading & status / lab). This skill must be used in the following situations: when the user mentions phrases such as “make a webpage,” “landing page,” “hero section,” “portfolio site,” “dashboard UI,” “make a form/button,” “add animation,” “recommend effects,” “make it more lively/polished/spectacular,” “it’s bland?,” “add interaction,” etc.— even if the word “animation” isn’t present, any request to create or improve an HTML/CSS/JS UI will trigger it.
