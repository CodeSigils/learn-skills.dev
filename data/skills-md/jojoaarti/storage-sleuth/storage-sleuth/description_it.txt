Analizza lo spazio su disco, trova file di grandi dimensioni, dati non aggiornati e cache di sviluppo e aiuta l'utente a liberare spazio su disco in modo sicuro o a spostare file su altre unità (ad esempio da C a D). Da utilizzare quando l'utente chiede cosa occupa spazio, dice che l'unità o il disco è pieno, chiede cosa eliminare, cosa può essere spostato su un'altra unità, desidera trovare file di grandi dimensioni, eliminare file temporanei o ripulire la memoria del disco.
