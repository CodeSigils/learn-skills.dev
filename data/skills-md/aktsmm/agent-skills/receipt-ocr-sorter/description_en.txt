OCR receipt auto-sorting tool. Reads receipts in images (JPEG/PNG), PDF, ZIP, or video (MP4/MOV) via OCR, extracts date, amount, country, card, and purpose, renames them to a standard file name, and sorts them by project. Includes a Markdown summary report. Supports D365 Expense category mapping and receipt attachment integration. Use when: (1) organizing receipts, (2) receipt sorting, (3) receipt classification, (4) organizing expense receipts into folders, (5) renaming with OCR, (6) D365 expense category mapping. Supports Surya OCR + GPU (CUDA).
