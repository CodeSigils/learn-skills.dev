⚠️ Alpha (in Entwicklung) – Kenntnisse in der Bereitstellung von Enterprise Azure-Umgebungen. Unterstützt die Nutzung von AVM, die Initialisierung von VM-Anwendungen, die Bereitstellung von Apps für App Service, AKS und Container Apps, die Integration dienstübergreifender Konfigurationen und die Generierung von CI/CD-Pipelines. Kompatibel mit komplexen Architekturen wie Hub-Spoke, AKS, AI Foundry usw. Ruft das neueste Schema mit Bicep MCP und Microsoft Learn Docs MCP ab.
