@lodev09/react-native-true-sheet を React Native アプリに統合するための消費者側のガイド。ユーザーが TrueSheet を使用してボトム シートを追加、構成、制御、またはデバッグしたい場合は常に、このスキルを使用します。これには、ref ベースのシート、名前付きグローバル シート、TrueSheetProvider/useTrueSheet による Web サポート、React Navigation または Expo Router シート フロー、Reanimated 駆動のアニメーション、スクロール コンテンツ、スタッキング、ヘッダー/フッター、戻り止め、サイド シート、キーボード処理、調光、液体ガラス、Jest テストが含まれます。また、ユーザーが v2 から v3 に移行するとき、レイアウトやジェスチャーの問題のトラブルシューティングを行うとき、または TrueSheet のプロップ、イベント、メソッドについて質問するときにも使用します。たとえ「TrueSheet」という名前を言及していなくても、React Native コンテキストでボトム シートについて説明している場合でも使用します。
