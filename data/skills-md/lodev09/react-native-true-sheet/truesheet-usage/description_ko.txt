@lodev09/react-native-true-sheet를 React Native 앱에 통합하기 위한 소비자 측 가이드입니다. 사용자가 참조 기반 시트, 명명된 전역 시트, TrueSheetProvider/useTrueSheet를 통한 웹 지원, React Navigation 또는 Expo Router 시트 흐름, 재활성화 기반 애니메이션, 콘텐츠 스크롤, 스태킹, 머리글/바닥글, 멈춤쇠, 사이드 시트, 키보드 처리, 밝기 조절, 액체 유리 및 Jest 테스트를 포함하여 TrueSheet를 사용하여 하단 시트를 추가, 구성, 제어 또는 디버그하려고 할 때마다 이 기술을 사용하세요. 또한 사용자가 v2에서 v3로 마이그레이션할 때, 레이아웃 또는 동작 문제를 해결하거나 TrueSheet 소품, 이벤트 또는 메서드에 대해 질문할 때 사용합니다. 이름으로 "TrueSheet"를 언급하지 않지만 React Native 컨텍스트에서 하단 시트를 설명하는 경우에도 마찬가지입니다.
