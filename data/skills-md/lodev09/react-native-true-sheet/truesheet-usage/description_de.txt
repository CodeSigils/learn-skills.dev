Verbraucherseitiger Leitfaden zur Integration von @lodev09/react-native-true-sheet in eine React Native-App. Verwenden Sie diese Fertigkeit immer dann, wenn der Benutzer mit TrueSheet ein unteres Blatt hinzufügen, konfigurieren, steuern oder debuggen möchte – einschließlich ref-basierter Blätter, benannter globaler Blätter, Webunterstützung mit TrueSheetProvider/useTrueSheet, React Navigation oder Expo Router-Blattflüssen, reanimierten Animationen, scrollenden Inhalten, Stapeln, Kopf-/Fußzeilen, Arretierungen, Seitenblättern, Tastaturbedienung, Dimmung, Flüssigglas und Scherztests. Verwenden Sie es auch, wenn der Benutzer von v2 auf v3 migriert, Layout- oder Gestenprobleme behebt oder nach TrueSheet-Requisiten, -Ereignissen oder -Methoden fragt – auch wenn er „TrueSheet“ nicht namentlich erwähnt, sondern ein unteres Blatt in einem React Native-Kontext beschreibt.
