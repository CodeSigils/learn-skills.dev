Guía del lado del consumidor para integrar @lodev09/react-native-true-sheet en una aplicación React Native. Utilice esta habilidad siempre que el usuario quiera agregar, configurar, controlar o depurar una hoja inferior usando TrueSheet, incluidas hojas basadas en referencias, hojas globales con nombre, soporte web con TrueSheetProvider/useTrueSheet, flujos de hojas de React Navigation o Expo Router, animaciones impulsadas por reanimación, contenido de desplazamiento, apilamiento, encabezados/pies de página, retenes, hojas laterales, manejo de teclado, atenuación, vidrio líquido y pruebas de Jest. Úselo también cuando el usuario esté migrando de v2 a v3, solucionando problemas de diseño o gestos, o preguntando sobre cualquier accesorio, evento o método de TrueSheet, incluso si no menciona "TrueSheet" por su nombre pero describe una hoja inferior en un contexto de React Native.
