Guida lato consumatore per l'integrazione di @lodev09/react-native-true-sheet in un'app React Native. Utilizza questa competenza ogni volta che l'utente desidera aggiungere, configurare, controllare o eseguire il debug di un foglio inferiore utilizzando TrueSheet, inclusi fogli basati su riferimenti, fogli globali denominati, supporto Web con TrueSheetProvider/utilizzaTrueSheet, flussi di fogli React Navigation o Expo Router, animazioni guidate da rianimazione, contenuto scorrevole, impilamento, intestazioni/piè di pagina, fermi, fogli laterali, gestione della tastiera, oscuramento, vetro liquido e test Jest. Da utilizzare anche quando l'utente sta migrando da v2 a v3, risolvendo problemi di layout o di gesti o chiedendo informazioni su qualsiasi proprietà, evento o metodo TrueSheet, anche se non menziona "TrueSheet" per nome ma descrive un foglio inferiore in un contesto React Native.
