Guide côté consommateur pour intégrer @lodev09/react-native-true-sheet dans une application React Native. Utilisez cette compétence chaque fois que l'utilisateur souhaite ajouter, configurer, contrôler ou déboguer une feuille de fond à l'aide de TrueSheet - y compris des feuilles basées sur des références, des feuilles globales nommées, la prise en charge Web avec TrueSheetProvider/useTrueSheet, les flux de feuilles React Navigation ou Expo Router, les animations réanimées, le défilement du contenu, l'empilement, les en-têtes/pieds de page, les détentes, les feuilles latérales, la gestion du clavier, la gradation, le verre liquide et les tests Jest. À utiliser également lorsque l'utilisateur migre de la v2 vers la v3, résout des problèmes de mise en page ou de gestes, ou pose des questions sur un accessoire, un événement ou une méthode TrueSheet, même s'il ne mentionne pas « TrueSheet » par son nom mais décrit une feuille de fond dans un contexte React Native.
