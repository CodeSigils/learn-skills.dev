دليل جانب المستهلك لدمج @lodev09/react-native-true-sheet في تطبيق React Native. استخدم هذه المهارة عندما يريد المستخدم إضافة أو تكوين أو التحكم أو تصحيح أخطاء ورقة سفلية باستخدام TrueSheet - بما في ذلك الأوراق المستندة إلى المرجع، والأوراق العامة المسماة، ودعم الويب باستخدام TrueSheetProvider/useTrueSheet، وتدفقات ورقة React Navigation أو Expo Router، والرسوم المتحركة التي تعتمد على الرسوم المتحركة، ومحتوى التمرير، والتكديس، والرؤوس/التذييلات، والحواجز، والأوراق الجانبية، والتعامل مع لوحة المفاتيح، والتعتيم، والزجاج السائل، واختبار الدعابة. يُستخدم أيضًا عندما يقوم المستخدم بالترحيل من الإصدار 2 إلى الإصدار 3، أو استكشاف مشكلات التخطيط أو الإيماءات وإصلاحها، أو السؤال عن أي خاصية أو حدث أو طريقة لـ TrueSheet - حتى إذا لم يذكر "TrueSheet" بالاسم ولكنه يصف ورقة سفلية في سياق React Native.
