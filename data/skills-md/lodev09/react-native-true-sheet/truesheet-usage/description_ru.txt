Руководство для потребителя по интеграции @lodev09/react-native-true-sheet в приложение React Native. Используйте этот навык всякий раз, когда пользователь хочет добавить, настроить, контролировать или отладить нижний лист с помощью TrueSheet, включая листы на основе ссылок, именованные глобальные листы, веб-поддержку с помощью TrueSheetProvider/useTrueSheet, потоки листов React Navigation или Expo Router, анимацию на основе реанимации, прокрутку содержимого, укладку, верхние и нижние колонтитулы, фиксаторы, боковые листы, обработку клавиатуры, затемнение, жидкое стекло и тестирование Jest. Также используйте, когда пользователь переходит с версии 2 на версию 3, устраняет проблемы с макетом или жестами или спрашивает о каком-либо реквизите, событии или методе TrueSheet — даже если он не упоминает «TrueSheet» по имени, но описывает нижний лист в контексте React Native.
