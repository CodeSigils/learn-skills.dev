Erstellen Sie die Unit-Test-Suite eines Pakets um eine aus der Implementierung abgeleitete Verhaltensspezifikation (SPEC.md) neu, wobei jeder Test eine nummerierte Regel-ID angibt. Verwenden Sie diese Option, wenn Sie aufgefordert werden, einen spezifikationsgesteuerten Testneuaufbau durchzuführen, eine SPEC.md für ein Paket zu schreiben, den Zustand zu wiederholen oder den Spezifikationsprozess zu speichern (PRs).
