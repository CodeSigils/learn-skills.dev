Résumez une grande trace de performances de Chrome DevTools dans un rapport de démarque compact afin de pouvoir la raisonner sans charger l'intégralité du fichier. À utiliser lorsqu'on vous donne une trace du panneau Chrome/DevTools/Performance (un `Trace-*.json` ou `*.json` de plusieurs Mo avec `traceEvents`) et qu'on vous demande de trouver ce qui est lent, ce qui s'exécute trop souvent, les tâches longues, les fonctions inutiles ou les fonctions JS chaudes.
