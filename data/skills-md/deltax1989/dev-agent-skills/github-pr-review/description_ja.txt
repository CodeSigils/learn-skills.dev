PR レビューのコメントとフィードバックの解決を処理します。ユーザーが PR コメントを解決する、レビュー フィードバックを処理する、レビュー コメントを修正する、PR レビューに対処する、レビュー ステータスを確認する、レビュー担当者に応答する、PR の準備状況を確認する、PR コメントをレビューする、レビュー フィードバックを分析する、PR コメントを評価する、レビューの提案を評価する、または PR コメントを優先順位付けする場合に使用します。 GitHub CLI 経由でコメントを取得し、重大度によって分類し、ユーザー確認付きで修正を適用し、適切な形式でコミットし、スレッドに返信します。
