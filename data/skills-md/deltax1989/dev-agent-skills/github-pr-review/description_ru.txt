Обрабатывает комментарии по PR-обзорам и принимает решения по отзывам. Используйте, когда пользователь хочет разрешить комментарии PR, обработать отзывы о обзоре, исправить комментарии к обзору, обратиться к обзору PR, проверить статус обзора, ответить рецензенту, проверить готовность PR, просмотреть комментарии PR, проанализировать отзывы о обзоре, оценить комментарии PR, оценить предложения по обзору или отсортировать комментарии PR. Получает комментарии через GitHub CLI, классифицирует по серьезности, применяет исправления с подтверждения пользователя, фиксирует в правильном формате, отвечает в обсуждениях.
