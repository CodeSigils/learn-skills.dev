Gère les commentaires d’examen des relations publiques et la résolution des commentaires. À utiliser lorsque l'utilisateur souhaite résoudre les commentaires PR, gérer les commentaires de révision, corriger les commentaires de révision, traiter la révision de PR, vérifier l'état de la révision, répondre au réviseur, vérifier l'état de préparation des PR, examiner les commentaires de PR, analyser les commentaires de révision, évaluer les commentaires de PR, évaluer les suggestions de révision ou trier les commentaires de PR. Récupère les commentaires via GitHub CLI, les classe par gravité, applique les correctifs avec confirmation de l'utilisateur, valide avec le format approprié, répond aux fils de discussion.
