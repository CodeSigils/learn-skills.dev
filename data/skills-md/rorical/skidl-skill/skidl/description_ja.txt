SKiDL Python ライブラリを使用して電子回路を設計します。ユーザーが次のことを要求する場合に使用します: (1) Python コードで電子回路を作成または記述する、(2) ネットリスト、PCB レイアウト、または回路図をプログラムで生成する、(3) SKiDL API (Part、Net、Bus、Pin、Circuit、SubCircuit) を使用する、(4) SKiDL/PySpice を使用して SPICE シミュレーションを実行する、(5) KiCad ライブラリまたはオンラインで電子コンポーネントを検索する (Octopart、Digi-Key、Mouser、 LCSC、SnapEDA)、(6) KiCad 回路図を Python コードに変換、(7) BOM の生成またはコンポーネントの価格設定/調達の検索、または (8) Python を使用したプログラムによる EDA/回路設計に関連するタスク。
