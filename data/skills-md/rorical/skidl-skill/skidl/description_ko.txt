SKiDL Python 라이브러리를 사용하여 전자 회로를 설계합니다. 사용자가 다음을 요청할 때 사용합니다. (1) Python 코드로 전자 회로 생성 또는 설명, (2) 프로그래밍 방식으로 넷리스트, PCB 레이아웃 또는 회로도 생성, (3) SKiDL API(Part, Net, Bus, Pin, Circuit, SubCircuit) 사용, (4) SKiDL/PySpice로 SPICE 시뮬레이션 실행, (5) KiCad 라이브러리 또는 온라인(Octopart, Digi-Key, Mouser, LCSC, SnapEDA), (6) KiCad 회로도를 Python 코드로 변환, (7) BOM 생성 또는 구성 요소 가격/소싱 찾기, 또는 (8) Python을 사용한 프로그래밍 방식 EDA/회로 설계와 관련된 모든 작업.
