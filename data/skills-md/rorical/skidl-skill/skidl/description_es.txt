Diseñe circuitos electrónicos utilizando la biblioteca SKiDL Python. Úselo cuando el usuario solicite: (1) crear o describir circuitos electrónicos en código Python, (2) generar netlists, diseños de PCB o esquemas mediante programación, (3) usar API SKiDL (Part, Net, Bus, Pin, Circuit, SubCircuit), (4) ejecutar simulaciones SPICE con SKiDL/PySpice, (5) buscar componentes electrónicos en bibliotecas KiCad o en línea (Octopart, Digi-Key, Mouser, LCSC, SnapEDA), (6) convertir esquemas de KiCad a código Python, (7) generar listas de materiales o encontrar precios/abastecimiento de componentes, o (8) cualquier tarea que implique diseño programático de circuitos/EDA con Python.
