Redacte mensajes de video MiniMax-H3 con audio nativo en el formato estructurado obligatorio de H3: referencia completa (Ref2VA) y texto a video (T2VA) únicamente. Úselo siempre que el modelo de destino sea MiniMax-H3: el usuario dice MiniMax, MiniMax-H3, H3, ref2va/r2v/t2v, nombra un punto de control minimax_h3 o nombra los nodos MiniMaxH3ReferenceToVideo/EmptyMiniMaxH3LatentAV/MiniMaxH3SigmaShift ComfyUI. Úselo también cuando la solicitud necesite el vocabulario propio de H3: etiquetas de referencia <Asunto N> / <Imagen N> / <Video N> / <Audio N>, definiciones de sujeto, análisis de retención, descripción_detallada, descripción_multimodal_integrada, paisaje sonoro general, música_no_diegética, marcas de tiempo de corte [Shot N], (S1) ID de los hablantes, <d> bloques de diálogo. Las indicaciones de H3 no son prosa libre: nombres de secciones fijos en un orden fijo, enumeraciones de retención y movimiento de cámara fijas, y un pase de audio nativo que se silencia si las secciones de sonido son delgadas; así que use esta habilidad en lugar de una habilidad de indicación genérica cada vez que H3 sea el modelo objetivo. NO para otros modelos generativos (Flux, SDXL, Qwen Image, WAN, Kling, Veo, Sora, Runway, Seedance: use indicaciones cinematográficas), NO para imágenes fijas (use director cinematográfico) y NO para las rutas de fotogramas clave I2VA / FL2VA / L2VA de H3, que esta habilidad no cubre deliberadamente.
