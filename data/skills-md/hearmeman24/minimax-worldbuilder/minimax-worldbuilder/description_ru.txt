Составляйте видео-подсказки MiniMax-H3 с собственным звуком в обязательном структурированном формате H3 — только полная ссылка (Ref2VA) и преобразование текста в видео (T2VA). Используйте, когда целевой моделью является MiniMax-H3: пользователь произносит MiniMax, MiniMax-H3, H3, ref2va / r2v / t2v, называет контрольную точку minimax_h3 или называет узлы MiniMaxH3ReferenceToVideo / EmptyMiniMaxH3LatentAV / MiniMaxH3SigmaShift ComfyUI. Также используйте, когда для запроса требуется собственный словарь H3 — ссылочные теги <Subject N> / <Picture N> / <Video N> / <Audio N>, subject_definitions, удержание_анализа, подробное_описание, интегрированное_мультимодальное_описание, общий_звуковой ландшафт, не_diegetic_music, [Shot N] вырезанные временные метки, (S1) идентификаторы говорящих, <d> диалоговые блоки. Подсказки H3 не являются свободной прозой: фиксированные названия разделов в фиксированном порядке, фиксированные перечисления движения и удержания камеры, а также проход собственного звука, который замолкает, если звуковые разделы тонкие — поэтому используйте этот навык вместо общего навыка подсказки каждый раз, когда H3 является целевой моделью. НЕ для других генеративных моделей (Flux, SDXL, Qwen Image, WAN, Kling, Veo, Sora, Runway, Seedance — используйте кинематографические подсказки), НЕ для неподвижных изображений (используйте Cinematic- Still-Director) и НЕ для путей ключевых кадров H3 I2VA/FL2VA/L2VA, которые этот навык намеренно не охватывает.
