Composez des invites vidéo MiniMax-H3 avec audio natif dans le format structuré obligatoire de H3 : référence complète (Ref2VA) et texte en vidéo (T2VA) uniquement. À utiliser chaque fois que le modèle cible est MiniMax-H3 : l'utilisateur indique MiniMax, MiniMax-H3, H3, ref2va / r2v / t2v, nomme un point de contrôle minimax_h3 ou nomme les nœuds MiniMaxH3ReferenceToVideo / EmptyMiniMaxH3LatentAV / MiniMaxH3SigmaShift ComfyUI. À utiliser également lorsque la demande nécessite le propre vocabulaire de H3 : balises de référence <Subject N> / <Picture N> / <Video N> / <Audio N>, subject_definitions, retention_analysis, detail_description, Integrated_multimodal_description, global_soundscape, non_diegetic_music, [Shot N] horodatages coupés, (S1) identifiants de haut-parleur, <d> blocs de dialogue. Les invites H3 ne sont pas de la prose libre : des noms de section fixes dans un ordre fixe, des énumérations de mouvement et de rétention de caméra fixes, et une passe audio native qui devient silencieuse si les sections sonores sont fines - utilisez donc cette compétence au lieu d'une compétence d'invite générique à chaque fois que H3 est le modèle cible. PAS pour les autres modèles génératifs (Flux, SDXL, Qwen Image, WAN, Kling, Veo, Sora, Runway, Seedance — utilisez les invites cinématographiques), PAS pour les images fixes (utilisez le directeur cinématique), et PAS pour les chemins d'images clés I2VA / FL2VA / L2VA de H3, que cette compétence ne couvre délibérément pas.
