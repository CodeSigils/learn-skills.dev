Trasforma una richiesta utente vaga, confusa o composta da più parti in un prompt pulito e autonomo che un nuovo agente potrebbe eseguire senza ulteriori domande. Intervista l'utente una domanda alla volta, camminando lungo l'albero decisionale, ramificandosi su ciascuna risposta, finché il prompt non è serrato, quindi invia il prompt finale come risultato finale. Attiva con entusiasmo: qualsiasi input dettato dalla voce, prosa ricca di riempitivi, riferimenti sottospecificati ("la cosa", "quello script"), richieste in più parti o qualsiasi piano che l'utente desidera sottoporre a test di stress. L'abilità stessa può essere saltata per banali richieste di una sola riga in cui produrre un artefatto prompt sarebbe una pura cerimonia, ma una volta invocata, produci sempre il prompt, anche se l'esecuzione sembra banale.
