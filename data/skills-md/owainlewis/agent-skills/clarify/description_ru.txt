Превратите расплывчатый, беспорядочный или состоящий из нескольких частей вопрос пользователя в понятное, автономное приглашение, которое новый агент сможет выполнить без дополнительных вопросов. Опрашивайте пользователя по одному вопросу за раз — проходя по дереву решений, разветвляясь по каждому ответу — до тех пор, пока подсказка не станет точной, а затем выведите окончательную подсказку в качестве конечного результата. Активируйте с нетерпением: любой ввод, продиктованный голосом, насыщенную прозу, неопределенные ссылки («вещь», «этот сценарий»), запросы, состоящие из нескольких частей, или любой план, который пользователь хочет пройти стресс-тестирование. Сам навык можно пропустить для тривиальных однострочных запросов, где создание артефакта подсказки было бы чистой церемонией, но после вызова всегда выдавайте подсказку, даже если выполнение выглядит тривиально.
