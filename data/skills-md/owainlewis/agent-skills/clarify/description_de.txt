Verwandeln Sie eine vage, unübersichtliche oder mehrteilige Benutzeranfrage in eine saubere, eigenständige Eingabeaufforderung, die ein neuer Agent ohne weitere Fragen ausführen kann. Befragen Sie den Benutzer jeweils eine Frage nach der anderen – gehen Sie den Entscheidungsbaum entlang und verzweigen Sie bei jeder Antwort –, bis die Eingabeaufforderung knapp ist, und geben Sie dann die endgültige Eingabeaufforderung als Ergebnis aus. Lösen Sie eifrig aus: jede sprachgesteuerte Eingabe, füllstoffreiche Prosa, unterspezifizierte Referenzen („das Ding“, „dieses Skript“), mehrteilige Anfragen oder jeder Plan, den der Benutzer einem Stresstest unterziehen möchte. Die Fertigkeit selbst kann für triviale einzeilige Anfragen übersprungen werden, bei denen die Erstellung eines Prompt-Artefakts eine reine Zeremonie wäre – aber sobald sie aufgerufen wurde, erzeugen Sie immer die Prompt, auch wenn die Ausführung trivial erscheint.
