Verwandeln Sie ein Ticket in einen PR-Entwurf. Verwenden Sie diese Option, wenn der Benutzer eine Ticketreferenz (JIRA-123, LIN-123, github#456, eine Problem-URL) übergibt und Code, Tests, Überprüfung und eine PR erwartet. Verwenden Sie das Anbaugerät, wenn kein PR erwartet wird; Nutzen Sie Multitasking für mehrere Tickets gleichzeitig.
