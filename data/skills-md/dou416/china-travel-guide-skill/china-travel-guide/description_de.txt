Erstellen Sie einen umfassenderen, endbenutzerorientierten Reiseführer für jede chinesische Stadt. Verwenden Sie diese Option, wenn der Benutzer einen Stadtführer, eine Reiseroute, einen Essensführer, einen Ankunftsführer, einen Nachbarschaftsführer oder Hilfe bei der Planung einer China-Reise für eine bestimmte Stadt anfordert. Der Skill stellt zwei kurze Profilfragen und erstellt dann anstelle von Markdown eine eigenständige HTML-Leitseite.
