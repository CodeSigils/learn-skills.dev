Minimieren Sie die Token-Verschwendung bei allen Bash-, Datei- und Datenverarbeitungsvorgängen. Wenden Sie diese Grundsätze IMMER an, wenn Sie Befehle ausführen, Dateien lesen oder Ausgaben verarbeiten. Diese Fähigkeit regelt, wie ein LLM-Agent mit dem System interagiert – sie gilt für jede Aufgabe, die die Verwendung von Tools, das Lesen von Dateien, die Datenverarbeitung oder Shell-Befehle umfasst. TRIGGER auf jedem Computer verwenden.
