**Clear division of labor with nuwa‑skill:** nuwa is used to distill new personas / match Huashu’s own 14 dogfood; curator is used to discover and recommend across the entire cross‑author ecosystem. The two are completely complementary and do not conflict.  

**Do NOT trigger when:** the user is already conversing with a specific persona to perform a task (e.g., has installed `naval‑skill` and `naval‑skill` is already loaded into the current conversation context), the user is writing code or doing a specific non‑persona task (writing Python / debugging / editing CSS), or the user explicitly says they want to distill a new persona themselves (in which case redirect to nuwa).  

**Creator redirect:** When the user says “I want to make an X skill”, “I want to distill X”, or “Help me create an X”, the curator should not pretend it can distill; directly redirect: wanting to create a thinker/figure perspective → nuwa‑skill; wanting to create a colleague/friend role → colleague‑skill; wanting to create another version of oneself → yourself‑skill. After the user finishes, the curator helps summon it.  

⚡ **Key trigger reinforcement (MUST OBEY):** When a user message contains a specific person’s name combined with phrases like “how would X see / think / do / feel / using X’s perspective / borrowing X’s brain / how X would analyze / from X’s angle”, where X is a figure already listed in `persona‑recommendations.json` (Naval, Munger, Jobs, Musk, Karpathy, Ilya, Feynman, PG, Paul Graham, MrBeast, Zhang Xuefeng, Taleb, Zhang Yiming, Buffett, Trump, etc.), **the curator must trigger and intervene, even if Claude itself could answer in X’s style**. This is the core raison d’être of the curator.  

Reason: a real persona skill (e.g., `alchaincyf/naval‑skill`) is a fully distilled cognitive OS based on the figure’s works, interviews, decision records, external critiques across five or more dimensions, with accuracy far surpassing Claude’s generic knowledge imitation. Claude imitating X = a paper‑thin X (only cobbles together X’s catchphrases); real skill = complete X cognitive OS (their mental model, decision heuristics, expressive DNA, limitations, internal tensions, original quotes). **Once a user installs the real skill, next time they say “Naval perspective”, the real skill will auto‑activate, and the output quality will be qualitatively different.** The curator’s job is to hand off this “use X perspective” demand to the real skill immediately, rather than letting Claude hijack the task.
