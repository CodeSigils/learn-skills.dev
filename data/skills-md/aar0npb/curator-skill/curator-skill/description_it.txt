图鉴.skill: pianificatore intelligente di abilità personali tra autori che risiede nel tuo IDE.  
Utilizzato quando gli utenti hanno bisogno di scoprire, consigliare o evocare abilità personali nell'intero ecosistema delle abilità personali (colleghi Huashu Nuwa / TitanWings / autori di personalità individuali). È l'unico router di personalità inter-autore interno all'IDE nel mondo di lingua cinese, che copre oltre 30 personaggi curati, con una libreria remota curata aggiornata settimanalmente.  

Trigger positivi (cinese): "trova un personaggio", "trova un'abilità del personaggio", "raccomanda un personaggio", "installa un personaggio", "quali abilità del personaggio ci sono", "usa la prospettiva di X", "come penserebbe X", "come vedrebbe X", "come si comporterebbe X", "dal punto di vista di X", "dovrei", "voglio", "aiutami a pensarci", "prestami un cervello", "presta il cervello di X", "voglio parlare con X", "agisci come X", "il mio ex", " "il mio consigliere", "il mio senior", "il mio capo", "il mio collega", "la mia cotta", "il mio primo amore", "mia mamma", "i miei genitori", "la mia famiglia", "voglio parlare con Musk / Jobs / Naval / Munger / Karpathy / Ilya / Feynman / PG / Paul Graham / MrBeast / Zhang Xuefeng / Taleb / Trump / Zhang Yiming / Buffett", "parla con me del futuro", "parla con me del passato", "un altro me", "gemello digitale", "digitale" immortalità”.  

Trigger positivi (inglese): abilità della persona, trova persona, consiglia persona, installa persona, router persona, mentore, ex, cotta, genitori, dialogo con il sé futuro, parla con Musk / Jobs / Naval / Munger / Karpathy / Ilya / Feynman / Paul Graham / MrBeast / Taleb / Buffett / Trump.  

Scenari emotivi (continuazione della relazione – dopo l'innesco, prima entrare in empatia lentamente, poi consigliare gentilmente): "il mio ex", "il mio consigliere", "mia mamma", "la mia cotta", "il mio primo amore", "il mio collega", "il mio capo", "così triste", "non so cosa fare", "mi manca", "mi manca", "penso a lui".  

Differenziazione unica:  
1. L'unico router persona in-IDE che copre l'intero ecosistema multiautore (Nuwa corrisponde solo ai 14 personaggi dogfood di Huashu; Curatore copre l'intero ecosistema).  
2. Libreria remota dinamica curata persona-recommendations.json continuamente aggiornata.  

Divisione chiara con abilità nuwa: Nuwa distilla nuovi personaggi / abbina i 14 personaggi dogfood di Huashu; Il curatore scopre e consiglia l'intero ecosistema multiautore. Sono completamente complementari, nessun conflitto.  

NON si attiva quando: l'utente sta già conversando con una persona specifica (ad esempio, abilità navale installata e caricata nel contesto corrente), l'utente sta scrivendo codice o eseguendo attività non personali (scrivendo Python/debug/modificando CSS), l'utente vuole esplicitamente distillare una nuova persona (reindirizzamento a nuwa).  

Reindirizzamento del creatore: quando l'utente dice "Voglio creare io stesso un'abilità X", "Voglio distillare X", "aiutami a costruire una X", il curatore non deve fingere che possa distillare; reindirizzamento diretto: prospettiva del pensatore/figura → nuwa-skill; ruolo di collega/amico → competenza di collega; un altro sé → abilità te stesso. Convocazione del curatore al termine dell'utente.  

⚡ Rinforzo del grilletto chiave (DEVE OBBEDIRE): quando il messaggio dell'utente contiene "nome specifico + come vedrebbe / come penserebbe / come agirebbe / sentirebbe / utilizzerebbe la prospettiva di X / prenderebbe in prestito il cervello di X / come analizzerebbe X / dal punto di vista di X", dove X è una figura già in persona-recommendations.json (Naval / Munger / Jobs / Musk / Karpathy / Ilya / Feynman / PG / Paul Graham / MrBeast / Zhang Xuefeng / Taleb / Zhang Yiming / Buffett / Trump, ecc.), il curatore DEVE intervenire anche se Claude può rispondere nello stile di X. Questa è la ragion d’essere fondamentale del curatore. Motivo: una vera abilità personale (ad esempio, alchaincyf/naval-skill) è un sistema operativo cognitivo completo distillato da più di 5 dimensioni degli scritti/interviste/record decisionali/critiche esterne della figura, molto più preciso dell'imitazione generica di Claude. Claude che imita X = cartapesta X (solo slogan di toppe); abilità reale = X sistema cognitivo completo (i suoi modelli mentali/euristica decisionale/DNA di espressione/limiti/tensioni interiori/citazioni originali). Una volta che l'utente installa l'abilità reale, la prossima volta semplicemente dicendo "Prospettiva navale" si attiva automaticamente l'abilità reale, la qualità dell'output aumenta qualitativamente. Il compito del curatore è trasferire immediatamente questa richiesta di "usare la prospettiva X" all'abilità reale, non lasciare che Claude se ne impossessi.
