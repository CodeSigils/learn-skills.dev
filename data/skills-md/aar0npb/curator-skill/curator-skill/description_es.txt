**Illustrated.skill: enrutador inteligente de habilidades de persona entre autores/enrutador de habilidades de persona entre autores que reside en su IDE.**  
Úselo cuando un usuario quiera descubrir, recomendar, combinar y convocar habilidades personales en todo el ecosistema de habilidades personales (Huashunuwa/Titanwingscolleague/varios autores de personas individuales). Este es el único enrutador de personas de autor cruzado en IDE en el mundo chino, que cubre más de 30 personas seleccionadas, con una biblioteca seleccionada remota que se actualiza semanalmente.

**Disparadores positivos (chinos):**  
“encontrar personaje”, “buscar habilidad de personaje”, “recomendar personaje”, “instalar un personaje”, “qué habilidades de personaje existen”, “quiero usar la perspectiva de X”, “cómo pensaría X”, “cómo vería X las cosas”, “qué haría X”, “desde el ángulo de X”, “¿debería…?”, “¿deberíamos…?”, “ayúdame a pensar con claridad”, “pedir prestado el cerebro”, “pedir prestado el cerebro de X”, “quiero charlar con X”, “jugar a X”, “mi ex”, “mi mentor”, “mi colega principal”, “mi jefe”, “mi compañero de trabajo”, “la persona que me gusta”, “mi primer amor”, “mi mamá”, “mis padres”, “mi familia”, “hablar con ElonMusk / SteveJobs / Naval / Munger / Karpathy / Ilya / Feynman / PG / PaulGraham / MrBeast / ZhangXuefeng / Taleb / Trump / ZhangYiming / Buffett”, “diálogo con mi yo futuro”, “diálogo con mi pasado yo”, “otro yo”, “gemelo digital”, “inmortalidad digital”.

**Diferenciadores únicos:**  
1. El único enrutador de personas en IDE que cubre todo el ecosistema de autores cruzados (nuwa solo coincide con las 14 personas de comida para perros de Huashu; el curador cubre todo el ecosistema).  
2. La biblioteca remota dinámica seleccionada `persona‑recommendations.json` se actualiza continuamente.

**División clara del trabajo con nuwa‑skill:**  
- **nuwa** se utiliza para destilar nuevos personajes/combinar los 14 personajes de comida para perros de Huashu.  
- **curador** se utiliza para descubrir+recomendar en todo el ecosistema de autores cruzados. Los dos son completamente complementarios y no conflictivos.

**NO active cuando:**  
- El usuario ya está conversando con una persona específica para realizar una tarea (por ejemplo, ya instaló `naval‑skill` y está cargado en el contexto de conversación actual).  
- El usuario está escribiendo código o realizando una tarea concreta no personal (escribir Python/depurar/editar CSS).  
- El usuario dice explícitamente que quiere crear una nueva persona (en este caso, redirigir a nuwa).

**Redireccionamiento del creador:**  
Cuando un usuario dice "Quiero crear mi propia habilidad X", "Quiero destilar X" o "Ayúdame a crear X", el curador **no** debe pretender que puede destilar; en su lugar, redirija directamente:  
- Quieres una perspectiva de pensador/figura → **nuwa‑skill**  
- Quiere un rol de colega/amigo → **habilidad de colega**  
- Quieres otra versión de ti mismo → **tuself‑skill**.  
Una vez que el usuario termina, el curador ayuda a invocar la habilidad.

**⚡ Refuerzo del disparador clave (DEBE OBEDECER):**  
Cuando el mensaje de un usuario contiene "el nombre de una persona específica + cómo se verá / pensará / hará / piensa / usará la perspectiva de X / tomará prestado el cerebro de X / X analizará / desde el ángulo de X", donde X es una figura que ya figura en `persona‑recommendations.json` (Naval, Munger, Jobs, Musk, Karpathy, Ilya, Feynman, PG, PaulGraham, MrBeast, ZhangXuefeng, Taleb, ZhangYiming, Buffett, Trump, etc.), **el curador debe intervenir**, incluso si Claude pudiera responder al estilo de X. Ésta es la principal razón de ser del curador.

**Razón:** Una habilidad de persona genuina (por ejemplo, `alchaincyf/naval‑skill`) es una destilación profunda y multidimensional (más de 5 aspectos) de las obras, entrevistas, registros de decisiones, críticas externas, etc., de la figura, formando un sistema operativo cognitivo completo con una fidelidad mucho mayor que la imitación genérica de conocimientos de Claude. La imitación de X por parte de Claude es una “X fina como el papel” (sólo uniendo eslóganes); una habilidad real es el sistema operativo cognitivo X completo (modelo mental, heurística de decisión, expresión del ADN, limitaciones, tensiones internas, citas primarias). **Una vez que un usuario instala la habilidad real, al decir "Perspectiva naval" se activará automáticamente esa habilidad, generando un resultado cualitativamente diferente.** El trabajo del curador es traspasar cualquier solicitud de "usar perspectiva X" a la habilidad real inmediatamente, en lugar de permitir que Claude se apropie de la solicitud.
