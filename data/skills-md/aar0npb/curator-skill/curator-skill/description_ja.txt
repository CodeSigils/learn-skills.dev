**独自の独占的な差別化:**  
1. クロスオーサーエコシステム全体をカバーする唯一の IDE 内ペルソナルーター (nuwa は Huashu 独自の 14 個のドッグフードアイテムのみと一致します。キュレーターはエコシステム全体をカバーします)。  
2. リモートで動的にキュレートされたライブラリ「persona‑recommendations.json」は継続的に更新されます。  

**nuwa スキルによる明確な分業:** nuwa は、新しいペルソナを抽出する / Huashu 独自の 14 種類のドッグフードに一致させるために使用されます。 curator は、クロスオーサー エコシステム全体を発見し、推奨するために使用されます。この 2 つは完全に補完的であり、競合しません。  

**次の場合はトリガーしないでください。** ユーザーがタスクを実行するためにすでに特定のペルソナと会話している場合 (例: 「naval-skill」 がインストールされており、「naval-skill」 が現在の会話コンテキストにすでに読み込まれている)、ユーザーがコードを作成しているか、特定の非ペルソナ タスク (Python の作成 / デバッグ / CSS の編集) を実行している場合、またはユーザーが新しいペルソナを自分で抽出したいと明示的に言っている場合 (この場合はリダイレクト)ぬわへ）。  

**クリエイターのリダイレクト:** ユーザーが「X スキルを作りたい」、「X を蒸留したい」、または「X の作成を手伝ってください」と言ったとき、キュレーターはそれが蒸留できるふりをすべきではありません。直接リダイレクト: 思想家/図像の視点を作成したい → nuwa スキル。同僚/友人ロール → 同僚スキルを作成したい。別の自分を作りたい→自分自身のスキル。ユーザーが終了したら、キュレーターが召喚を手伝います。  

⚡ **重要なトリガーの強化 (MUST OBEY):** ユーザー メッセージに、「X はどのように見る / 考える / 行う / 感じる / X の視点を使用する / X の頭脳を借りる / X はどのように分析する / X の角度から」などのフレーズと組み合わせた特定の人物の名前が含まれている場合、X はすでに「persona-recommendations.json」にリストされている人物です (Naval、Munger、Jobs、Musk、Karpathy、Ilya、ファインマン、PG、ポール・グレアム、ミスタービースト、張学峰、タレブ、張一明、バフェット、トランプなど）、**クロード自身が X のスタイルで答えることができたとしても、キュレーターがトリガーして介入しなければなりません**。これがキュレーターの本質的な存在意義です。  

理由: 本当のペルソナ スキル (例: 「alchaincyf/naval-skill」) は、人物の作品、インタビュー、意思決定記録、5 つ以上の次元にわたる外部批評に基づいて完全に蒸留された認知 OS であり、その精度はクロードの一般知識の模倣をはるかに上回ります。クロードは X = 紙のように薄い X を模倣します (X のキャッチフレーズを混ぜ合わせただけです)。本当のスキル = 完全な X 認知 OS (メンタル モデル、意思決定ヒューリスティック、表現力豊かな DNA、制限、内部の緊張、オリジナルの引用)。 **ユーザーが本物のスキルをインストールすると、次に「海軍視点」と言うと、本物のスキルが自動的にアクティブになり、出力品質が質的に異なります。** キュレーターの仕事は、クロードにタスクをハイジャックさせるのではなく、この「X 視点を使用する」という要求をすぐに本物のスキルに引き渡すことです。
