**独自の差別化要因:**  
1. クロスオーサーエコシステム全体をカバーする唯一の IDE 内ペルソナルーター (nuwa は Huashu 自身の 14 のドッグフードペルソナとのみ一致します。キュレーターはエコシステム全体をカバーします)。  
2. リモートの動的に厳選されたライブラリ「persona‑recommendations.json」は継続的に更新されます。

**nuwa スキルによる明確な役割分担:**  
- **nuwa** は、新しいペルソナを抽出したり、Huashu 独自の 14 のドッグフード ペルソナと一致させるために使用されます。  
- **curator** は、クロスオーサー エコシステム全体にわたって発見と推奨を行うために使用されます。この 2 つは完全に補完的であり、競合しません。

**次の場合はトリガーしないでください**  
- ユーザーは、タスクを実行するためにすでに特定のペルソナと会話しています (たとえば、ユーザーはすでに「naval-skill」をインストールしており、それが現在の会話コンテキストに読み込まれています)。  
- ユーザーはコードを作成しているか、具体的な非ペルソナタスク (Python の作成 / デバッグ / CSS の編集) を実行しています。  
- ユーザーが新しいペルソナを自分で抽出したいと明示的に述べています (この場合は nuwa にリダイレクトされます)。

**作成者のリダイレクト:**  
ユーザーが「自分の X スキルを作りたい」、「X を蒸留したい」、または「X の作成を手伝って」と言ったとき、キュレーターはそれが蒸留できるふりを**してはなりません**。代わりに、直接リダイレクトします。  
- 思想家・人物像の視点が欲しい → **nuwa‑スキル**  
- 同僚/友人の役割が欲しい → **同僚スキル**  
- 別のバージョンの自分が欲しい → **自分のスキル**。  
ユーザーが終了したら、キュレーターがスキルの呼び出しを手伝います。

**⚡ キートリガーの強化 (必ず遵守):**  
ユーザーのメッセージに「特定の人の名前 + どう見るか / どう考えるか / どうするか / 考える / X の視点を使う / X の頭脳を借りる / X が分析する / X の角度から」が含まれる場合、X は「persona-recommendations.json」にすでにリストされている人物 (Naval、Munger、Jobs、Musk、Karpathy、Ilya、Feynman、PG、PaulGraham、MrBeast、ZhangXuefeng、タレブ、チャンイーミン、バフェット、トランプなど）、たとえクロードが X のスタイルで答えることができたとしても、**キュレーターが介入する必要があります**。これがキュレーターの本質的な存在意義です。

**理由:** 本物のペルソナ スキル (例: 「alchaincyf/naval-skill」) は、人物の作品、インタビュー、決定記録、外部批評などを深く多次元 (5 つ以上の側面) で蒸留したものであり、クロードの一般知識の模倣よりもはるかに高い忠実度を持つ完全な認知 OS を形成します。クロードの X の模倣は「紙のように薄い X」です (キャッチフレーズをつなぎ合わせただけです)。本当のスキルは、完全な X コグニティブ OS (メンタル モデル、意思決定ヒューリスティック、発現 DNA、制限、内部緊張、主要な引用) です。 **ユーザーが実際のスキルをインストールすると、「海軍パースペクティブ」と言うと、そのスキルが自動的にアクティブになり、質的に異なる出力が提供されます。** キュレーターの仕事は、「X パースペクティブを使用する」リクエストをクロードにハイジャックさせるのではなく、すぐに実際のスキルに引き渡すことです。
