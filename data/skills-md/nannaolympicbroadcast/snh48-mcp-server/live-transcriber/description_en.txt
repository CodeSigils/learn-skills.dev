Extract the m3u8 streaming address from the 48.cn live broadcast sharing page, download the video, convert audio to text, and generate a content summary. It is triggered when a user provides a 48.cn live stream link and requests video extraction, transcription, and analysis of the live content. Keywords: live transcription, m3u8 extraction, video-to-text, 48 live, Pocket 48, speech recognition, live summary. Supports HLS streaming download, Whisper speech recognition, and automatic content summarization.
