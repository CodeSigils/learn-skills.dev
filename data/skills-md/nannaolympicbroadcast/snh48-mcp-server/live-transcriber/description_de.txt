Extrahieren Sie die m3u8-Streaming-Adresse von der 48.cn-Live-Broadcast-Sharing-Seite, laden Sie das Video herunter, konvertieren Sie Audio in Text und erstellen Sie eine Inhaltszusammenfassung. Es wird ausgelöst, wenn ein Benutzer einen 48.cn-Livestream-Link bereitstellt und eine Videoextraktion, Transkription und Analyse des Live-Inhalts anfordert. Schlüsselwörter: Live-Transkription, M3U8-Extraktion, Video-to-Text, 48 Live, Pocket 48, Spracherkennung, Live-Zusammenfassung. Unterstützt HLS-Streaming-Download, Flüsterspracherkennung und automatische Inhaltszusammenfassung.
