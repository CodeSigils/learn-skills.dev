Verwenden Sie diese Option, wenn der Benutzer URLs von einer Website oder einer Liste crawlen, sammeln, prüfen oder überprüfen möchte – aktive vs. tote Links, Seiteninventar, Linkvalidierung oder einen Sitemap-/Link-Tree-Scrape. Lösen Sie auch bei lockeren Formulierungen wie „Alle Links abrufen“, „Überprüfen Sie, welche URLs funktionieren“ oder „Seiten auf dieser Website finden“ aus.
