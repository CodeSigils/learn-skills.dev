Используйте, когда у пользователя есть один или несколько URL-адресов и он хочет преобразовать их в чистые файлы Markdown — для документации, архивирования исследований, подготовки контекста LLM или сохранения автономного контента. Запускается по таким фразам, как «преобразовать эти URL-адреса в уценку», «сохранить эти статьи как MD», «превратить этот список ссылок в файлы md», «извлечь статьи из CSV-файла URL-адресов».
