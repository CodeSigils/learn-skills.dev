Da utilizzare quando l'utente dispone di uno o più URL e desidera convertirli in file Markdown puliti, per documentazione, archiviazione di ricerche, preparazione del contesto LLM o conservazione dei contenuti offline. Si attiva su frasi come "converti questi URL in markdown", "salva questi articoli come MD", "trasforma questo elenco di collegamenti in file md", "estrai articoli da un CSV di URL".
