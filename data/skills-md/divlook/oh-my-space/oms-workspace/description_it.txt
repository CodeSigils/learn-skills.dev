Da utilizzare per il lavoro Git in uno spazio di lavoro contenente un `oms.yaml` (repos di origine forniti come sottomoduli in `oms/`) ogni volta che l'ambito del repository è ambiguo: eseguire il commit o il push di "tutto" dalla radice dello spazio di lavoro, interpretare un puntatore "oms status" che si è spostato, eseguire il debug di un push o aggiungere o rimuovere un repository con "oms sync" o "oms unsync". Stabilisce lo stato dell'area di lavoro e l'ambito root rispetto al sottomodulo prima di agire su Git.
