Genere escenarios de prueba específicos para un agente de voz o chat de LiveKit y ejecútelos como simulaciones, localmente, a partir del propio código del agente más lo que el usuario desea que se pruebe. Úselo siempre que el usuario quiera "probar mi agente", "qué debo probar", "crear/generar escenarios de simulación", "crear un conjunto de pruebas de simulación", "usar el agente lk para simular", "realizar una prueba de estrés del flujo X", "configurar escenarios para mi agente" o quiera probar casos extremos/rechazos/regresiones antes del envío. Genera escenarios en la máquina del usuario (su código nunca se carga) y le permite al usuario controlar profundamente lo que se prueba. Se activa incluso sin la palabra "simulación" cuando el usuario claramente quiere decidir qué probar y verificar cómo se comporta su agente en conversaciones realistas. No para crear un nuevo agente desde cero (use la habilidad livekit-agents), realizar pruebas de carga o pruebas unitarias ordinarias.
