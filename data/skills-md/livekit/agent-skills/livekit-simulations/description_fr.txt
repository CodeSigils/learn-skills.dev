Générez des scénarios de test ciblés pour un agent vocal ou de chat LiveKit et exécutez-les sous forme de simulations — localement, à partir du propre code de l'agent et de ce que l'utilisateur souhaite tester sous contrainte. À utiliser chaque fois que l'utilisateur souhaite « tester mon agent », « que dois-je tester », « créer/générer des scénarios de simulation », « créer une suite de tests sim », « utiliser la simulation d'agent lk », « tester le flux X », « configurer des scénarios pour mon agent » ou souhaite sonder les cas extrêmes/refus/régressions avant l'expédition. Génère des scénarios sur la machine de l'utilisateur (leur code n'est jamais téléchargé) et permet à l'utilisateur de contrôler en profondeur ce qui est testé. Déclenchez même sans le mot « simulation » lorsque l'utilisateur souhaite clairement décider quoi tester et vérifier le comportement de son agent au cours de conversations réalistes. Pas pour créer un nouvel agent à partir de zéro (utilisez la compétence livekit-agents), pour effectuer des tests de charge ou des tests unitaires ordinaires.
