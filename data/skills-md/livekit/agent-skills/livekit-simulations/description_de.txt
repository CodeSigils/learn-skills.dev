Generieren Sie gezielte Testszenarien für einen LiveKit-Sprach- oder Chat-Agenten und führen Sie diese als Simulationen aus – lokal, aus dem eigenen Code des Agenten und dem, was der Benutzer einem Stresstest wünscht. Verwenden Sie diese Option immer dann, wenn der Benutzer „meinen Agenten testen“, „was soll ich testen“, „Simulationsszenarien erstellen/generieren“, „eine Simulationstestsuite erstellen“, „LK-Agenten simulieren“, „den X-Flow einem Stresstest unterziehen“, „Szenarien für meinen Agenten einrichten“ möchte oder Randfälle/Ablehnungen/Regressionen vor dem Versand prüfen möchte. Erzeugt Szenarien auf dem Computer des Benutzers (der Code wird nie hochgeladen) und ermöglicht dem Benutzer die detaillierte Steuerung dessen, was getestet wird. Lösen Sie die Funktion auch ohne das Wort „Simulation“ aus, wenn der Benutzer eindeutig entscheiden möchte, was er testen und überprüfen möchte, wie sich sein Agent in realistischen Gesprächen verhält. Nicht zum Erstellen eines neuen Agenten von Grund auf (verwenden Sie den Livekit-Agents-Skill), für Lasttests oder gewöhnliche Komponententests.
