يمكنك إنشاء تطبيقات Android وترحيلها باستخدام Kotlin وJetpack Compose وMVVM وHilt وRoom 3 (KSP وSQLiteDriver وFlow/suspend DAOs) وNavigation3 وGradle متعدد الوحدات. يُستخدم للمشروعات أو الوحدات النمطية الجديدة، وشاشات الإنشاء وViewModels، والغرفة 3 وRemoteMediator، وترحيل API 37 / targetSdk، وأسلاك عميل Play Integrity، والمزامنة دون اتصال أولاً، ومحاذاة كتالوج الإصدار. ليس لنظام التشغيل iOS، أو Flutter، أو React Native، أو التعليمات البرمجية المشتركة لـ KMP فقط بدون وحدة تطبيق Android، أو واجهات برمجة التطبيقات الخلفية فقط بدون عميل Android.
