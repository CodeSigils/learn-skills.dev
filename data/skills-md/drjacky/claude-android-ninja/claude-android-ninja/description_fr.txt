Créez et migrez des applications Android avec Kotlin, Jetpack Compose, MVVM, Hilt, Room 3 (KSP, SQLiteDriver, Flow/suspend DAO), Navigation3 et Gradle multi-modules. À utiliser pour les nouveaux projets ou modules, les écrans Compose et ViewModels, Room 3 et RemoteMediator, la migration API 37 / targetSdk, le câblage du client Play Integrity, la synchronisation hors ligne d'abord et l'alignement du catalogue de versions. Pas pour iOS, Flutter, React Native, le code partagé KMP uniquement sans module d'application Android, ni pour les API backend uniquement sans client Android.
