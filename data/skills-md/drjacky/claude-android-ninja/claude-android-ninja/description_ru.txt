Создавайте и переносите приложения Android с помощью Kotlin, Jetpack Compose, MVVM, Hilt, Room 3 (KSP, SQLiteDriver, Flow/suspend DAO), Navigation3 и многомодульного Gradle. Используйте для новых проектов или модулей, экранов Compose и ViewModels, Room 3 и RemoteMediator, миграции API 37 / targetSdk, подключения клиента Play Integrity, автономной синхронизации и выравнивания каталога версий. Не для iOS, Flutter, React Native, общего кода только для KMP без модуля приложения Android или API-интерфейсов только для серверной части без клиента Android.
