Kotlin、Jetpack Compose、MVVM、Hilt、Room 3 (KSP、SQLiteDriver、Flow/suspend DAO)、Navigation3、およびマルチモジュール Gradle を使用して Android アプリを構築および移行します。新しいプロジェクトまたはモジュール、Compose 画面と ViewModel、Room 3 と RemoteMediator、API 37 / targetSdk の移行、Play Integrity クライアントの接続、オフライン優先同期、およびバージョンとカタログの調整に使用します。 iOS、Flutter、React Native、Android アプリ モジュールを使用しない KMP のみの共有コード、または Android クライアントを使用しないバックエンドのみの API には使用できません。
