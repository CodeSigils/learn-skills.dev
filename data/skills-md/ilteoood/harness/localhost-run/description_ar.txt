اِكشف التطبيقات المحلية HTTP و HTTPS و TLS على الإنترنت العام عبر نواقل SSH الخاصة بـ localhost.run. استخدمه عندما يرغب المستخدم في مشاركة تطبيق يعمل محليًا، أو عرض عمل قيد التطوير، أو اختبار webhooks، أو الوصول إلى خادم محلي من جهاز بعيد، أو إعداد نطاق مخصص، أو توجيه بروتوكولات غير HTTP، أو استكشاف مشكلة نفق localhost.run الحالي. ينشط عند ظهور عبارات مثل “expose my localhost”، “make my local server public”، “share my dev server”، “tunnel my local app”، “ngrok alternative”، أو أي إشارة إلى localhost.run.
