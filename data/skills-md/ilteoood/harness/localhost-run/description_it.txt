Esporre applicazioni locali HTTP, HTTPS e TLS su Internet pubblico tramite tunnel SSH di localhost.run. Da utilizzare quando l'utente vuole condividere un'app in esecuzione locale, mostrare un lavoro in corso, testare webhook, accedere a un server locale da un dispositivo remoto, configurare un dominio personalizzato, tunnelizzare protocolli non HTTP o risolvere problemi di un tunnel localhost.run esistente. Si attiva su frasi come “expose my localhost”, “make my local server public”, “share my dev server”, “tunnel my local app”, “ngrok alternative” o qualsiasi riferimento a localhost.run.
