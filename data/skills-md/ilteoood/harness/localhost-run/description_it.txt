Esponi le applicazioni HTTP, HTTPS e TLS locali alla rete Internet pubblica tramite tunnel SSH localhost.run. Da utilizzare quando l'utente desidera condividere un'app in esecuzione localmente, demo di lavori in corso, testare webhook, accedere a un server locale da un dispositivo remoto, impostare un dominio personalizzato, eseguire il tunneling di protocolli non HTTP o risolvere i problemi di un tunnel localhost.run esistente. Si attiva su frasi come "esponi il mio localhost", "rendi pubblico il mio server locale", "condividi il mio server di sviluppo", "tunnel della mia app locale", "alternativa a ngrok" o qualsiasi riferimento a localhost.run.
