Exposez les applications locales HTTP, HTTPS et TLS à Internet public via des tunnels SSH localhost.run. À utiliser lorsque l'utilisateur souhaite partager une application en cours d'exécution localement, présenter un travail en cours, tester des webhooks, accéder à un serveur local depuis un dispositif distant, configurer un domaine personnalisé, tunneliser des protocoles non HTTP ou dépanner un tunnel localhost.run existant. Se déclenche sur des phrases telles que « expose my localhost », « make my local server public », « share my dev server », « tunnel my local app », « ngrok alternative » ou toute référence à localhost.run. Veuillez toujours répondre dans la langue de l'utilisateur.
