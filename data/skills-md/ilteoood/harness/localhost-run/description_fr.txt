Exposez les applications HTTP, HTTPS et TLS locales à l'Internet public via les tunnels SSH localhost.run. À utiliser lorsque l'utilisateur souhaite partager une application exécutée localement, un travail de démonstration en cours, tester des webhooks, accéder à un serveur local à partir d'un appareil distant, configurer un domaine personnalisé, tunneler des protocoles non HTTP ou dépanner un tunnel localhost.run existant. Se déclenche sur des expressions telles que « exposer mon hôte local », « rendre mon serveur local public », « partager mon serveur de développement », « tunneliser mon application locale », « alternative ngrok » ou toute référence localhost.run.
