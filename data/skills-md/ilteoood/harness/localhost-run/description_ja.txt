ローカルで動作している HTTP、HTTPS、TLS アプリケーションを localhost.run の SSH トンネルを介してパブリックインターネットに公開します。ローカルで実行中のアプリを共有したい、作業中のデモを見せたい、Webhook をテストしたい、リモートデバイスからローカルサーバにアクセスしたい、カスタムドメインを設定したい、HTTP 以外のプロトコルをトンネルしたい、または既存の localhost.run トンネルのトラブルシューティングを行うときに使用します。「expose my localhost」「make my local server public」「share my dev server」「tunnel my local app」「ngrok alternative」など、localhost.run に関するフレーズがトリガーになります。
