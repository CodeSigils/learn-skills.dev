ローカルの HTTP、HTTPS、TLS アプリケーションを localhost.run の SSH トンネルを介してパブリックインターネットに公開します。ローカルで実行中のアプリを共有したい、作業中のデモを見せたい、Webhook をテストしたい、リモートデバイスからローカルサーバーにアクセスしたい、カスタムドメインを設定したい、HTTP 以外のプロトコルをトンネルしたい、既存の localhost.run トンネルのトラブルシューティングをしたい、などの場合に使用します。「expose my localhost」や「make my local server public」などのフレーズや「share my dev server」「tunnel my local app」「ngrok alternative」あるいは localhost.run に関する言及がトリガーになります。
