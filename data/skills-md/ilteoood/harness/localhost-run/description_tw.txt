將本地的 HTTP、HTTPS 與 TLS 應用程式透過 localhost.run SSH 隧道公開至互聯網。適用於使用者想要分享本機執行的應用、展示開發中項目、測試 webhook、從遠端裝置存取本地伺服器、設定自訂網域、隧道非 HTTP 協定，或排除現有 localhost.run 隧道問題的情況。會在出現如「expose my localhost」 、「make my local server public」 、「share my dev server」 、「tunnel my local app」 、「ngrok alternative」或任何 localhost.run 相關字句時被觸發。
