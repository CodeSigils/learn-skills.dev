Expón aplicaciones locales HTTP, HTTPS y TLS al internet público mediante túneles SSH de localhost.run. Úsalo cuando el usuario quiera compartir una aplicación que se ejecuta localmente, mostrar un demo en progreso, probar webhooks, acceder a un servidor local desde un dispositivo remoto, configurar un dominio personalizado, tunelizar protocolos que no sean HTTP o solucionar problemas de un túnel existente de localhost.run. Se activa con frases como “exponer mi localhost”, “hacer público mi servidor local”, “compartir mi servidor de desarrollo”, “tunelizar mi aplicación local”, “alternativa a ngrok” o cualquier referencia a localhost.run.
