Lokale HTTP-, HTTPS- und TLS-Anwendungen über localhost.run SSH‑Tunnel dem öffentlichen Internet zugänglich machen. Verwenden, wenn der Benutzer eine lokal laufende Anwendung teilen, eine laufende Demo präsentieren, Webhooks testen, von einem entfernten Gerät auf einen lokalen Server zugreifen, eine benutzerdefinierte Domain einrichten, Nicht‑HTTP‑Protokolle tunneln oder ein bestehendes localhost.run‑Tunnel problembeheben möchte. Wird ausgelöst bei Ausdrücken wie „expose my localhost“, „make my local server public“, „share my dev server“, „tunnel my local app“, „ngrok alternative“ oder jedem Verweis auf localhost.run. Bitte immer in der Sprache des Benutzers antworten.
