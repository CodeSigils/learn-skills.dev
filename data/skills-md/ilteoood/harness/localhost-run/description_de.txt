Lokale HTTP‑, HTTPS‑ und TLS‑Anwendungen über SSH‑Tunnel von localhost.run dem öffentlichen Internet zugänglich machen. Verwenden, wenn der Benutzer eine lokal laufende Anwendung teilen, eine laufende Demo zeigen, Webhooks testen, von einem entfernten Gerät auf einen lokalen Server zugreifen, eine eigene Domain einrichten, Nicht‑HTTP‑Protokolle tunneln oder ein bestehendes localhost.run‑Tunnel problembeheben möchte. Wird ausgelöst bei Formulierungen wie „expose my localhost“, „make my local server public“, „share my dev server“, „tunnel my local app“, „ngrok alternative“ oder jeglichem Verweis auf localhost.run. Bitte immer in der Sprache des Benutzers antworten.
