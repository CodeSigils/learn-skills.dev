Aktualisieren Sie package.json-Abhängigkeiten mit npm-check-updates (ncu) auf die neuesten Versionen. Verwenden Sie diese Option, wenn der Benutzer nach veralteten Abhängigkeiten suchen, Paketversionen aktualisieren, bestimmte Pakete filtern oder ablehnen, auf einen bestimmten Versionsbereich abzielen möchte (neueste, größte, untergeordnete Version, Patch, Semver, @tag), eine einzelne oder mehrere Paketdateien scannen möchte (--deep, --workspaces, --packageFile), eine interaktive Auswahl ausführen möchte (--interactive), fehlerhafte Upgrades durch Ausführen von Tests nach jedem Stoß erkennen möchte (--doctor), sich gegen Supply-Chain-Angriffe mit --cooldown verteidigen, private oder alternative Registrierungen abfragen möchte. oder verwenden Sie die programmgesteuerte API aus einer .ncurc.js-Konfiguration oder einem Node-Modul.
