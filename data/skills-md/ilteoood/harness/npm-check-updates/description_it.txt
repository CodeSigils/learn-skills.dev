Aggiorna le dipendenze di package.json alle versioni più recenti con npm-check-updates (ncu). Da utilizzare quando l'utente desidera verificare la presenza di dipendenze obsolete, aggiornare versioni di pacchetti, filtrare o rifiutare pacchetti specifici, scegliere come target un intervallo di versioni specifico (più recente, massima, secondaria, patch, semver, @tag), scansionare uno o più file di pacchetto (--deep, --workspaces, --packageFile), eseguire una selezione interattiva (--interactive), rilevare aggiornamenti non validi eseguendo test dopo ogni bump (--doctor), difendersi dagli attacchi alla catena di fornitura con --cooldown, interrogare registri privati o alternativi o utilizzare l'API programmatica da una configurazione .ncurc.js o da un modulo Node.
