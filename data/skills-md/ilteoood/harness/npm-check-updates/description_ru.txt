Обновите зависимости package.json до последних версий с помощью npm-check-updates (ncu). Используйте, когда пользователь хочет проверить наличие устаревших зависимостей, обновить версии пакета, отфильтровать или отклонить определенные пакеты, настроить таргетинг на определенный диапазон версий (последняя, самая большая, младшая, исправление, semver, @tag), просканировать один или несколько файлов пакета (--deep, --workspaces, --packageFile), запустить интерактивный выбор (--interactive), обнаружить сломанные обновления путем запуска тестов после каждого удара (--doctor), защититься от атак в цепочке поставок с помощью --cooldown, запросить частные или альтернативные реестры или используйте программный API из конфигурации .ncurc.js или модуля Node.
