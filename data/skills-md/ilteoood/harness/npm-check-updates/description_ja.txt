npm-check-updates (ncu) を使用して、package.json の依存関係を最新バージョンにアップグレードします。ユーザーが古い依存関係のチェック、パッケージ バージョンのアップグレード、特定のパッケージのフィルターまたは拒否、特定のバージョン範囲のターゲット (最新、最大、マイナー、パッチ、semver、@tag)、単一または複数のパッケージ ファイルのスキャン (--deep、--workspaces、--packageFile)、対話型選択の実行 (--interactive)、各バンプ後のテストの実行による破壊的なアップグレードの検出 (--doctor)、--cooldown によるサプライ チェーン攻撃の防御、プライベートまたは代替のクエリを実行する場合に使用します。レジストリを使用するか、.ncurc.js 構成または Node モジュールからプログラム API を使用します。
