npm-check-updates(ncu)를 사용하여 package.json 종속성을 최신 버전으로 업그레이드하세요. 사용자가 오래된 종속성 확인, 패키지 버전 업그레이드, 특정 패키지 필터링 또는 거부, 특정 버전 범위 대상 지정(최신, 최고, 부, 패치, semver, @tag), 단일 또는 다중 패키지 파일 스캔(--deep, --workspaces, --packageFile), 대화형 선택 실행(--interactive), 각 범프 후 테스트를 실행하여 중단된 업그레이드 감지(--doctor), --cooldown을 사용하여 공급망 공격으로부터 방어, 개인 또는 대체 레지스트리 쿼리 또는 .ncurc.js 구성 또는 Node 모듈의 프로그래밍 API를 사용하세요.
