Mettez à niveau les dépendances package.json vers les dernières versions avec npm-check-updates (ncu). À utiliser lorsque l'utilisateur souhaite vérifier les dépendances obsolètes, mettre à niveau les versions de package, filtrer ou rejeter des packages spécifiques, cibler une plage de versions spécifique (dernière, la plus grande, mineure, patch, semver, @tag), analyser un ou plusieurs fichiers de package (--deep, --workspaces, --packageFile), exécuter une sélection interactive (--interactive), détecter les mises à niveau de rupture en exécutant des tests après chaque bosse (--doctor), se défendre contre les attaques de la chaîne d'approvisionnement avec --cooldown, interroger private ou alternative. registres, ou utilisez l'API programmatique à partir d'une configuration .ncurc.js ou d'un module Node.
