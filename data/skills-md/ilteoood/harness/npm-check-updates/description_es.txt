Actualice las dependencias de package.json a las últimas versiones con npm-check-updates (ncu). Úselo cuando el usuario desee verificar dependencias obsoletas, actualizar versiones de paquetes, filtrar o rechazar paquetes específicos, apuntar a un rango de versión específico (último, mayor, menor, parche, semver, @tag), escanear uno o varios archivos de paquete (--deep, --workspaces, --packageFile), ejecutar selección interactiva (--interactive), detectar actualizaciones de última hora ejecutando pruebas después de cada golpe (--doctor), defenderse contra ataques a la cadena de suministro con --cooldown, consultar registros privados o alternativos. o utilice la API programática desde una configuración .ncurc.js o un módulo de Nodo.
