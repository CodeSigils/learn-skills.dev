Управляйте составными ветвями и запросами на включение с помощью расширения CLI GitHub gh-stack. Используйте, когда пользователь хочет создавать, отправлять, перебазировать, синхронизировать, перемещаться или просматривать стеки зависимых PR. Запускается при выполнении задач, связанных с многоуровневыми различиями, зависимыми запросами на включение, цепочками ветвей или рабочими процессами поэтапной проверки кода.
