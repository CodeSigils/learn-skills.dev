Upgrades React Native apps to newer versions by applying rn-diff-purge template diffs, updating package.json dependencies, migrating native iOS and Android configuration, resolving CocoaPods and Gradle changes, and handling breaking API updates. Используйте при обновлении React Native, обновлении версии RN, обновлении с RN 0.x до 0.y или миграции Expo SDK вместе с обновлением React Native.
