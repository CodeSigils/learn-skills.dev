ترقية تطبيقات React Native إلى الإصدارات الأحدث من خلال تطبيق اختلافات قالب rn-diff-purge، وتحديث تبعيات package.json، وترحيل تكوين iOS وAndroid الأصلي، وحل تغييرات CocoaPods وGradle، والتعامل مع تحديثات واجهة برمجة التطبيقات المعطلة. يُستخدم عند ترقية React Native، أو رفع إصدار RN، أو التحديث من RN 0.x إلى 0.y، أو ترحيل Expo SDK إلى جانب ترقية React Native.
