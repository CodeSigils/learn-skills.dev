Aggiorna le app React Native alle versioni più recenti applicando le differenze del modello rn-diff-purge, aggiornando le dipendenze package.json, migrando la configurazione nativa iOS e Android, risolvendo le modifiche CocoaPods e Gradle e gestendo gli aggiornamenti API importanti. Da utilizzare durante l'aggiornamento di React Native, il bumping della versione RN, l'aggiornamento da RN 0.x a 0.y o la migrazione di Expo SDK insieme a un aggiornamento di React Native.
