يحلل اختلافات git أو التغييرات المرحلية وينشئ رسائل التزام سردية تشرح سبب إجراء التغيير، وليس فقط ما تغير - باتباع تنسيق الالتزامات التقليدية. استخدم عندما يُطلب منك "كتابة رسالة التزام"، أو "إنشاء التزام"، أو "وصف تغييراتي"، أو "ما الذي يجب أن أرتكبه على هذا النحو"، أو "ارتكاب هذا"، أو "تلخيص الاختلافات الخاصة بي"، أو "مساعدتي في الالتزام". يعمل مع مخرجات git diff أو الملفات المرحلية أو الأوصاف البسيطة للتغييرات.
