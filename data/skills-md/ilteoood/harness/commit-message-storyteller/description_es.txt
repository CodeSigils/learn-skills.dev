Analiza git diffs o cambios por etapas y genera mensajes de confirmación narrativos que explican POR QUÉ se realizó un cambio, no solo qué cambió, siguiendo el formato de confirmaciones convencionales. Úselo cuando se le solicite "escribir un mensaje de confirmación", "generar una confirmación", "describir mis cambios", "cómo debo confirmar esto", "confirmar esto", "resumir mi diferencia" o "ayúdame a confirmar". Funciona con resultados de git diff, archivos preparados o descripciones simples de cambios.
