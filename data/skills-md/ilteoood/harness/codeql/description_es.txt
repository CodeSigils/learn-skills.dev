Guía completa para instalar y configurar el escaneo de código CodeQL a través de los flujos de trabajo de GitHub Actions y la CLI de CodeQL. Esta habilidad debe usarse cuando los usuarios necesitan ayuda con la configuración del escaneo de código, los archivos de flujo de trabajo de CodeQL, los comandos CLI de CodeQL, la salida SARIF, la configuración del análisis de seguridad o la resolución de problemas del análisis de CodeQL.
