Guida completa per impostare e configurare la scansione del codice CodeQL tramite i flussi di lavoro GitHub Actions e la CLI CodeQL. Questa competenza dovrebbe essere utilizzata quando gli utenti hanno bisogno di aiuto con la configurazione della scansione del codice, i file del flusso di lavoro CodeQL, i comandi CLI CodeQL, l'output SARIF, la configurazione dell'analisi di sicurezza o la risoluzione dei problemi dell'analisi CodeQL.
