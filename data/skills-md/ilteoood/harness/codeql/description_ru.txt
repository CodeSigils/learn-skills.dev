Комплексное руководство по настройке и настройке сканирования кода CodeQL с помощью рабочих процессов GitHub Actions и интерфейса командной строки CodeQL. Этот навык следует использовать, когда пользователям нужна помощь с настройкой сканирования кода, файлами рабочих процессов CodeQL, командами CLI CodeQL, выводом SARIF, настройкой анализа безопасности или устранением неполадок анализа CodeQL.
