Создавайте, обновляйте и управляйте проблемами GitHub с помощью инструментов MCP. Используйте этот навык, когда пользователи хотят создавать отчеты об ошибках, запросы функций или проблемы с задачами, обновлять существующие проблемы, добавлять метки/назначенных/этапы, устанавливать поля проблем (даты, приоритет, настраиваемые поля), устанавливать типы проблем, управлять рабочими процессами проблем, связывать проблемы, добавлять зависимости или отслеживать заблокированные/блокирующие отношения. Запускается по таким запросам, как «создать проблему», «сообщить об ошибке», «запросить функцию», «обновить проблему X», «установить приоритет», «установить дату начала», «проблемы со связью», «добавить зависимость», «заблокировано», «блокировать» или любую задачу управления проблемами GitHub.
