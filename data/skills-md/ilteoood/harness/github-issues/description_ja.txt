MCP ツールを使用して、GitHub の問題を作成、更新、管理します。このスキルは、ユーザーがバグ レポート、機能リクエスト、タスクの問題の作成、既存の問題の更新、ラベル/担当者/マイルストーンの追加、問題フィールド (日付、優先度、カスタム フィールド) の設定、問題タイプの設定、問題ワークフローの管理、問題のリンク、依存関係の追加、またはブロック対象/ブロック関係の追跡を行う場合に使用します。 「問題の作成」、「バグの報告」、「機能のリクエスト」、「問題 X の更新」、「優先度の設定」、「開始日の設定」、「問題のリンク」、「依存関係の追加」、「ブロック」、「ブロック」、または任意の GitHub 問題管理タスクなどのリクエストでトリガーされます。
