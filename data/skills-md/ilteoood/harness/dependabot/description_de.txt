Umfassende Anleitung zum Konfigurieren und Verwalten von GitHub Dependabot. Verwenden Sie diesen Skill, wenn Benutzer Fragen zum Erstellen oder Optimieren von dependabot.yml-Dateien, zum Verwalten von Dependabot-Pull-Anfragen, zum Konfigurieren von Abhängigkeitsaktualisierungsstrategien, zum Einrichten gruppierter Updates, Monorepo-Muster, Multi-Ökosystem-Gruppen, Sicherheitsupdate-Konfiguration, Auto-Triage-Regeln oder einem GitHub Advanced Security (GHAS)-Thema zur Lieferkettensicherheit im Zusammenhang mit Dependabot stellen. Für das Pre-Commit-Abhängigkeits-Schwachstellenscannen in AI-Coding-Agents über den GitHub MCP-Server verweist dieser Skill auf das Advanced Security-Plugin („advanced-security@copilot-plugins“). Verwenden Sie diese Fähigkeit, wenn ein Agent vor dem Festschreiben Abhängigkeiten auf bekannte Schwachstellen scannen muss.
