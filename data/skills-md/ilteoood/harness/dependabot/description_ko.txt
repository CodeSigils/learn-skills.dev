GitHub Defendabot 구성 및 관리에 대한 종합 가이드입니다. 사용자가 dependencyabot.yml 파일 생성 또는 최적화, Expectabot 끌어오기 요청 관리, 종속성 업데이트 전략 구성, 그룹화된 업데이트 설정, 단일 저장소 패턴, 다중 생태계 그룹, 보안 업데이트 구성, 자동 심사 규칙 또는 Sendabot과 관련된 GHAS(GitHub Advanced Security) 공급망 보안 항목에 대해 질문할 때 이 기술을 사용하세요. GitHub MCP 서버를 통해 AI 코딩 에이전트의 커밋 전 종속성 취약성 스캔을 위해 이 기술은 고급 보안 플러그인(`advanced-security@copilot-plugins`)을 참조합니다. 에이전트가 커밋하기 전에 알려진 취약점에 대한 종속성을 스캔해야 하는 경우 이 기술을 사용하세요.
