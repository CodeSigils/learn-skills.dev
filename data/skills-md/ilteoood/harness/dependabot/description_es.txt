Guía completa para configurar y administrar GitHub Dependabot. Utilice esta habilidad cuando los usuarios pregunten sobre la creación u optimización de archivos dependabot.yml, la administración de solicitudes de extracción de Dependabot, la configuración de estrategias de actualización de dependencias, la configuración de actualizaciones agrupadas, patrones monorepo, grupos de múltiples ecosistemas, configuración de actualizaciones de seguridad, reglas de clasificación automática o cualquier tema de seguridad de la cadena de suministro de GitHub Advanced Security (GHAS) relacionado con Dependabot. Para el escaneo de vulnerabilidades de dependencia previo al compromiso en agentes de codificación de IA a través del servidor GitHub MCP, esta habilidad hace referencia al complemento de seguridad avanzada (`advanced-security@copilot-plugins`). Utilice esta habilidad cuando un agente necesite escanear dependencias en busca de vulnerabilidades conocidas antes de comprometerse.
