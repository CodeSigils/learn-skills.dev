Guide complet pour configurer et gérer GitHub Dependabot. Utilisez cette compétence lorsque les utilisateurs posent des questions sur la création ou l'optimisation de fichiers dependabot.yml, la gestion des demandes d'extraction Dependabot, la configuration de stratégies de mise à jour des dépendances, la configuration de mises à jour groupées, de modèles monorepo, de groupes multi-écosystèmes, la configuration des mises à jour de sécurité, les règles de triage automatique ou tout autre sujet de sécurité de la chaîne d'approvisionnement GitHub Advanced Security (GHAS) lié à Dependabot. Pour l'analyse des vulnérabilités de dépendance avant la validation dans les agents de codage IA via le serveur GitHub MCP, cette compétence fait référence au plug-in Advanced Security (`advanced-security@copilot-plugins`). Utilisez cette compétence lorsqu'un agent doit analyser les dépendances à la recherche de vulnérabilités connues avant de les valider.
