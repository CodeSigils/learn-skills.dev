Guida completa per la configurazione e la gestione di GitHub Dependabot. Utilizza questa competenza quando gli utenti chiedono informazioni sulla creazione o l'ottimizzazione di file dependabot.yml, sulla gestione delle richieste pull di Dependabot, sulla configurazione di strategie di aggiornamento delle dipendenze, sull'impostazione di aggiornamenti raggruppati, modelli monorepo, gruppi multi-ecosistema, configurazione degli aggiornamenti di sicurezza, regole di triage automatico o qualsiasi argomento sulla sicurezza della catena di fornitura GitHub Advanced Security (GHAS) correlato a Dependabot. Per la scansione delle vulnerabilità delle dipendenze pre-commit negli agenti di codifica AI tramite il server MCP GitHub, questa abilità fa riferimento al plug-in Advanced Security ("advanced-security@copilot-plugins"). Utilizza questa abilità quando un agente deve scansionare le dipendenze per individuare vulnerabilità note prima di impegnarsi.
