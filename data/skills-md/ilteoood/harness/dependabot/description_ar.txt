دليل شامل لتكوين وإدارة GitHub Dependabot. استخدم هذه المهارة عندما يسأل المستخدمون عن إنشاء ملفات Dependabot.yml أو تحسينها، أو إدارة طلبات سحب Dependabot، أو تكوين إستراتيجيات تحديث التبعية، أو إعداد التحديثات المجمعة، أو أنماط monorepo، أو مجموعات الأنظمة البيئية المتعددة، أو تكوين التحديث الأمني، أو قواعد الفرز التلقائي، أو أي موضوع أمان لسلسلة توريد GitHub Advanced Security (GHAS) يتعلق بـ Dependabot. بالنسبة لفحص ثغرات التبعية قبل الالتزام في وكلاء ترميز الذكاء الاصطناعي عبر GitHub MCP Server، تشير هذه المهارة إلى المكون الإضافي Advanced Security (`advanced-security@copilot-plugins`). استخدم هذه المهارة عندما يحتاج الوكيل إلى فحص التبعيات بحثًا عن نقاط الضعف المعروفة قبل الالتزام.
