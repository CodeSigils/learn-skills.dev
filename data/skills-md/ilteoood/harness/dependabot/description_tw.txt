配置和管理 GitHub Dependabot 的綜合指南。當使用者詢問建立或最佳化 dependentabot.yml 檔案、管理 Dependabot 拉取請求、配置依賴項更新策略、設定分組更新、單一倉庫模式、多生態系統群組、安全更新配置、自動分類規則或與 Dependabot 相關的任何 GitHub 高級安全性 (GHAS) 供應安全性主題時，請使用此技能。對於透過 GitHub MCP 伺服器在 AI 編碼代理程式中進行預提交依賴漏洞掃描，此技能引用高級安全性外掛程式 (`advanced-security@copilot-plugins`)。當代理程式需要在提交之前掃描依賴項以查找已知漏洞時，請使用此技能。
