قم بإنشاء كود CRUD وفقًا لمواصفات إطار عمل RuoYi. استخدم هذه المهارة عندما يحتاج المستخدم إلى إنشاء تعليمات برمجية Java للواجهة الخلفية (فئات الكيانات، أو مخطط الخرائط، أو الخدمة، أو وحدة التحكم)، أو كود Vue للواجهة الأمامية (صفحات القائمة، أو أغلفة واجهة برمجة التطبيقات)، أو ملفات تعيين MyBatis XML، أو تهيئة القائمة SQL لجدول قاعدة البيانات. مناسب لسيناريوهات مثل إنشاء وحدات نمطية جديدة وإضافة وظائف الأعمال وإنشاء التعليمات البرمجية بناءً على بنية الجدول.
