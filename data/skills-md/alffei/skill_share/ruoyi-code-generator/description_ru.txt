Сгенерируйте CRUD-код в соответствии со спецификациями платформы RuoYi. Используйте этот навык, когда пользователю необходимо сгенерировать внутренний код Java (классы сущностей, Mapper, Service, Controller), внешний код Vue (страницы списков, оболочки API), XML-файлы сопоставления MyBatis или SQL инициализации меню для таблицы базы данных. Подходит для таких сценариев, как создание новых модулей, добавление бизнес-функций и создание кода на основе структуры таблиц.
