Générez du code CRUD selon les spécifications du framework RuoYi. Utilisez cette compétence lorsqu'un utilisateur a besoin de générer du code Java back-end (classes d'entités, Mappeur, Service, Contrôleur), du code Vue front-end (pages de liste, wrappers API), des fichiers de mappage XML MyBatis ou du SQL d'initialisation de menu pour une table de base de données. Convient aux scénarios tels que la création de nouveaux modules, l'ajout de fonctions métier et la génération de code basé sur la structure des tables.
