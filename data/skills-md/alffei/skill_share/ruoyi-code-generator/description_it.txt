Genera codice CRUD secondo le specifiche del framework RuoYi. Utilizzare questa competenza quando un utente deve generare codice Java backend (classi di entità, Mapper, Servizio, Controller), codice Vue frontend (pagine di elenco, wrapper API), file di mappatura XML MyBatis o SQL di inizializzazione del menu per una tabella di database. Adatto per scenari come la creazione di nuovi moduli, l'aggiunta di funzioni aziendali e la generazione di codice basato sulla struttura della tabella.
