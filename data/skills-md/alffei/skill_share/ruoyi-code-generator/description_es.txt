Genere código CRUD de acuerdo con las especificaciones del marco RuoYi. Utilice esta habilidad cuando un usuario necesite generar código Java de backend (clases de entidad, asignador, servicio, controlador), código Vue de frontend (páginas de lista, envoltorios de API), archivos de mapeo XML de MyBatis o SQL de inicialización de menú para una tabla de base de datos. Adecuado para escenarios como la creación de nuevos módulos, la adición de funciones comerciales y la generación de código basado en la estructura de la tabla.
