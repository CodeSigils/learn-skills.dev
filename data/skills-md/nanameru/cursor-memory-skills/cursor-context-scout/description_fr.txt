À utiliser avant de modifier des bases de code inconnues ou volumineuses, en particulier lorsque Claude Code ou Codex doit enregistrer le contexte en demandant au Cursor SDK d'identifier en premier le plus petit ensemble de fichiers pertinents. Déclencheurs pour les requêtes mentionnant Cursor SDK, la recherche de contexte, l'indexation de la base de code, la recherche sémantique, les fichiers pertinents, les commentaires Figma sur l'implémentation ou "avant de modifier, recherchez les fichiers".
