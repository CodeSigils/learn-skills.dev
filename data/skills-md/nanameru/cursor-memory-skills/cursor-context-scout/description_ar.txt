استخدمه قبل تحرير قواعد التعليمات البرمجية الكبيرة أو غير المألوفة، خاصة عندما يحتاج Claude Code أو Codex إلى حفظ السياق عن طريق مطالبة Cursor SDK بتحديد أصغر مجموعة من الملفات ذات الصلة أولاً. مشغلات للطلبات التي تشير إلى Cursor SDK، واستكشاف السياق، وفهرسة قاعدة التعليمات البرمجية، والبحث الدلالي، والملفات ذات الصلة، وتعليقات Figma على التنفيذ، أو "قبل التحرير، ابحث عن الملفات".
