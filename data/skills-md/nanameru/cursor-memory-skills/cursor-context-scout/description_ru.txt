Используйте перед редактированием незнакомых или больших баз кода, особенно когда Claude Code или Codex необходимо сохранить контекст, попросив Cursor SDK сначала определить наименьший набор соответствующих файлов. Триггеры для запросов, упоминающих Cursor SDK, поиск контекста, индексацию кодовой базы, семантический поиск, соответствующие файлы, комментарии Figma к реализации или «перед редактированием найдите файлы».
