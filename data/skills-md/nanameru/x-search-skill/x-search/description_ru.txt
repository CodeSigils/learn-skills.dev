Выполняйте поиск в X (Twitter / 旧Twitter) для получения последних сообщений, новостей, тенденций или для сбора текста сообщений и URL-адресов сообщений — ИЛИ найдите конкретное сообщение X, когда пользователь вставляет URL-адрес x.com / twitter.com — путем делегирования локальному агенту Hermes одноразового режима. Используйте, когда пользователь говорит 「X検索」「Xで検索」 「Xで最新情報」「Xで調べて」「ツイート検索」「Xのトレンド」「X search」 「последние на X」「ディープリサーチ」「глубокое исследование」, запрашивает URL-адреса публикаций X/Twitter или вставляет любую ссылку x.com/twitter.com (публикацию или профиль). Hermes имеет встроенный поиск X с поддержкой Grok — ключ X API не требуется (требуется учетная запись X Premium на этом компьютере).
