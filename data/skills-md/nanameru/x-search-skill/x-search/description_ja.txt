X (Twitter / 旧Twitter) を検索して、最新の投稿、ニュース、トレンドを検索したり、投稿テキストや投稿 URL を収集したりすることができます。または、ユーザーが x.com / twitter.com URL を貼り付けたときに、特定の X 投稿を検索します。これには、ローカルの Herme エージェント ワンショット モードに委任します。ユーザーが「X検索」「Xで検索」「Xで最新情報」「Xで調べて」「ツイート検索」「Xのトレンド」「X検索」「Xの最新」「ディープリサーチ」「ディープリサーチ」と発言したり、X/Twitterの投稿URLを尋ねたり、x.com / twitter.comのリンク（投稿またはプロフィール）を貼り付けたりする場合に使用します。 Hermes には Grok 支援の X 検索が組み込まれています。X API キーは必要ありません (このマシンの X プレミアム アカウントが必要です)。
