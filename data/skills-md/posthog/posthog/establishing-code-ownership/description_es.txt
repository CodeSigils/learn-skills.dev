Determine qué equipo de PostHog posee un archivo, directorio o ruta de código, o enumere todo el código que posee un equipo (a través de `products/*/product.yaml` y `.github/CODEOWNERS(-soft)?`). Úselo al asignar un revisor, atribuir un error o una consulta lenta a un equipo, enrutar el trabajo, determinar el alcance de una auditoría de todo el equipo o responder "quién es el propietario de X"/"qué posee el equipo Y".
