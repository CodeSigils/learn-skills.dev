Bestimmen Sie, welches PostHog-Team eine Datei, ein Verzeichnis oder einen Codepfad besitzt, oder listen Sie den gesamten Code auf, den ein Team besitzt (über „products/*/product.yaml“ und „.github/CODEOWNERS(-soft)?“). Verwenden Sie diese Option, wenn Sie einen Prüfer zuweisen, einem Team einen Fehler oder eine langsame Anfrage zuordnen, Arbeit weiterleiten, den Umfang einer teamweiten Prüfung festlegen oder antworten: „Wem gehört X?“ / „Was besitzt Team Y?“.
