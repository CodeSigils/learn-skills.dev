Руководство по добавлению нового RPC в personhog-replica и personhog-router. Охватывает проверки приемлемости, определение прототипа, генерацию кода для клиентов Python и Node.js, реализацию Rust (характеристика хранилища, запросы postgres, обработчик службы, подключение маршрутизатора) и проверку совместимости индексов. Используйте при добавлении новой конечной точки gRPC в personhog, переносе запроса Django ORM в personhog или расширении API службы personhog.
