Guida per aggiungere un nuovo RPC a personhog-replica e personhog-router. Copre controlli di idoneità, definizione di prototipi, generazione di codice per client Python e Node.js, implementazione di Rust (tratti di archiviazione, query postgres, gestore del servizio, cablaggio del router) e convalida della compatibilità dell'indice. Da utilizzare quando si aggiunge un nuovo endpoint gRPC a personhog, si esegue la migrazione di una query Django ORM a personhog o si estende l'API del servizio personhog.
