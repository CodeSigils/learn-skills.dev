Guía para agregar un nuevo RPC a personhog-replica y personhog-router. Cubre comprobaciones de elegibilidad, definición de prototipos, generación de código para clientes Python y Node.js, implementación de Rust (rasgo de almacenamiento, consultas de Postgres, controlador de servicios, cableado de enrutador) y validación de compatibilidad de índices. Úselo al agregar un nuevo punto final de gRPC a personhog, al migrar una consulta ORM de Django a personhog o al extender la API del servicio personhog.
