Erstellt und aktualisiert GitHub Actions-Geheimnisse für PostHog-Workflows. Verwenden Sie diese Option, wenn Sie ein neues CI-Geheimnis hinzufügen, ein vorhandenes Geheimnis rotieren, einen Workflow mit einem API-Token, Anmeldeinformationen für die Paketregistrierung, einem Bereitstellungsschlüssel oder einem beliebigen Wert verbinden, auf den über „${{ Secrets.* }}“ in „.github/workflows/“ verwiesen wird.
