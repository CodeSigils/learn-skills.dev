Создает и обновляет секреты действий GitHub для рабочих процессов PostHog. Используйте при добавлении нового секрета CI, ротации существующего секрета, связывании рабочего процесса с токеном API, учетными данными реестра пакетов, ключом развертывания или любым значением, указанным в `${{ secrets.* }}` в `.github/workflows/`.
