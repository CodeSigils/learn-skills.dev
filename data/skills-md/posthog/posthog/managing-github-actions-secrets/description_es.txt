Crea y actualiza secretos de GitHub Actions para flujos de trabajo de PostHog. Úselo al agregar un nuevo secreto de CI, rotar un secreto existente, conectar un flujo de trabajo a un token de API, credencial de registro de paquete, clave de implementación o cualquier valor al que se haga referencia a través de `${{ secrets.* }}` en `.github/workflows/`.
