Crea e aggiorna i segreti delle azioni GitHub per i flussi di lavoro PostHog. Da utilizzare quando si aggiunge un nuovo segreto CI, si ruota un segreto esistente, si collega un flusso di lavoro a un token API, una credenziale del registro del pacchetto, una chiave di distribuzione o qualsiasi valore a cui si fa riferimento tramite `${{ secrets.* }}` in `.github/workflows/`.
