Wird beim Hinzufügen von Timern („setInterval“, „setTimeout“), Ereignis-Listenern („window.addEventListener“, „document.addEventListener“, „MediaQueryList.addEventListener“) oder anderen Ressourcen verwendet, die innerhalb einer Kea-Logik bereinigt werden müssen. Jede Logik verfügt über „cache.disposables.add(setup, key?, options?)“ und „cache.disposables.dispose(key)“, die über das global registrierte „disposablesPlugin“ („frontend/src/kea-disposables.ts“) verfügbar sind. Ersetzt das bloße Muster „cache.foo = setInterval(...)“ + „beforeUnmount: clearInterval(cache.foo)“ und pausiert die Hintergrundarbeit automatisch, wenn die Registerkarte ausgeblendet ist.
