Da utilizzare quando si aggiunge o si modifica un flusso di lavoro GitHub Actions che invia un'immagine del contenitore a un registro (ECR/ghcr/Docker Hub tramite build-push-action) o invia una distribuzione di produzione (un `commit_state_update` repository_dispatch a PostHog/charts). Quelli vengono eseguiti da un singolo repository di distribuzione canonico, controllato dalla variabile CD_DEPLOY_ENABLED. NON si applica ai flussi di lavoro che pubblicano versioni GitHub, npm, crate o Homebrew: questi rimangono nel repository pubblico.
