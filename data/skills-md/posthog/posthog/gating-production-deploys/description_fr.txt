À utiliser lors de l'ajout ou de la modification d'un workflow GitHub Actions qui pousse une image de conteneur vers un registre (ECR/ghcr/Docker Hub via build-push-action) ou distribue un déploiement de production (un référentiel_dispatch `commit_state_update` vers PostHog/charts). Ceux-ci s'exécutent à partir d'un seul dépôt de déploiement canonique, contrôlé par la variable CD_DEPLOY_ENABLED. Ne s'applique PAS aux flux de travail qui publient des versions de GitHub, npm, crates ou Homebrew – ceux-ci restent dans le dépôt public.
