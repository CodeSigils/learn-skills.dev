PostHog エンジニアをガイドして、起動、接続、コマンドの実行、リモート devbox (完全な PostHog スタックを実行する Coder ワークスペース) へのローカル コードのミラーリングを行います。 devbox のセットアップ、devbox の起動または接続、リモート dev の構成、devbox での gh CLI / Claude Code の認証の取得、devbox でのコマンドの実行、スタックがリモートで実行されている間にローカルで編集できるようにローカル チェックアウトを同期する (devbox:sync)、または devbox コマンドが失敗する理由の診断を求められた場合に使用します。テールネットの前提条件、hogli devbox コマンド、認証用の Coder ユーザー シークレット、mutagen を介した一方向のローカル -> リモート同期、devbox:exec による検証について説明します。各開発者が自分のボックスをどのようにパーソナライズするかは開発者に任されています。
