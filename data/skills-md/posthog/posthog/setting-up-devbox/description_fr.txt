Guidez un ingénieur PostHog dans la mise en route, la connexion, l'exécution de commandes et la mise en miroir du code local sur une devbox distante (un espace de travail Coder exécutant la pile PostHog complète). À utiliser lorsqu'on vous demande de configurer une devbox, de démarrer ou de vous connecter à une devbox, de configurer un développement distant, d'obtenir l'authentification du code gh CLI / Claude sur une devbox, d'exécuter une commande sur une devbox, de synchroniser une extraction locale afin que vous puissiez modifier localement pendant que la pile s'exécute à distance (devbox:sync) ou diagnostiquer pourquoi une commande devbox échoue. Couvre les prérequis tailnet, les commandes hogli devbox, les secrets d'utilisateur du codeur pour l'authentification, la synchronisation unidirectionnelle locale->à distance via mutagen et la vérification avec devbox:exec. La façon dont chaque développeur personnalise sa boîte lui appartient.
