Führen Sie einen PostHog-Ingenieur durch das Hochfahren, Herstellen einer Verbindung, das Ausführen von Befehlen und das Spiegeln von lokalem Code auf einer Remote-Devbox (einem Coder-Arbeitsbereich, in dem der gesamte PostHog-Stack ausgeführt wird). Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine Devbox einzurichten, eine Devbox zu starten oder eine Verbindung zu ihr herzustellen, Remote-Dev zu konfigurieren, gh CLI/Claude Code auf einer Devbox zu authentifizieren, einen Befehl auf einer Devbox auszuführen, einen lokalen Checkout zu synchronisieren, damit Sie lokal bearbeiten können, während der Stack remote ausgeführt wird (devbox:sync), oder zu diagnostizieren, warum ein Devbox-Befehl fehlschlägt. Behandelt die Tailnet-Voraussetzung, Hogli-Devbox-Befehle, Coder-Benutzergeheimnisse für die Authentifizierung, einseitige lokale -> Remote-Synchronisierung über Mutagen und die Überprüfung mit devbox:exec. Wie jeder Entwickler seine Box personalisiert, bleibt ihm überlassen.
