Détermine si un nouveau test doit exister et le force à être efficace, protégeant ainsi CI de la surcharge des tests de faible valeur. À utiliser avant d'ajouter ou de modifier substantiellement un test pytest, Jest ou Playwright — chaque fois qu'un agent ou un ingénieur est sur le point d'écrire des tests pour une nouvelle fonctionnalité, une correction de bug ou un PR. Charge en premier la barre de valeur (chaque test doit détecter une régression réaliste qu'aucun test existant n'a déjà détecté ; tester le comportement via l'interface publique, pas les détails d'implémentation ; réduire les quasi-doublons dans des cas paramétrés) et la barre d'efficacité (déterministe, isolée, rapide ; choisir le niveau de test le moins cher ; Django TestCase sur TransactionTestCase ; pas de veille, pas de réseau réel). Comprend un arbre de décision « ne l'écrivez pas ». Pour corriger un test irrégulier existant, utilisez `/fixing-flaky-tests` ; après que cette porte indique qu'un test Playwright est justifié, utilisez `/playwright-test` pour la mécanique.
