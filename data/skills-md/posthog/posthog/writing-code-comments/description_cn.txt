控制代码注释是否应该存在，并强制保留的代码注释解释原因，而不是解释内容。在使用任何语言（Python、TypeScript、Go、Rust、SQL）编写或编辑注释之前，以及在查看添加注释的差异时，请使用 ALWAYS。删除了使代码库混乱的注释类型：重述代码的旁白、更改历史记录和聊天上下文注释（“以前做了 X”、“根据 PR #123”、“AI：”）、易腐烂的测量和当前状态标记（“~20 分钟构建”、“当前”、“今天”）、注释掉的代码和冗余文档字符串。保留那些赢得一席之地的内容：一个不明显的原因，一个关于非局部后果的警告，一个指向未来读者无法重建的上下文的指针。不适用于面向用户的副本（请参阅“/writing-user-faceing-copy”）或提交消息。
