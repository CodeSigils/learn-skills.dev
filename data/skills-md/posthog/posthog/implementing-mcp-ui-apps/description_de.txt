Leitfaden zum Hinzufügen von MCP-UI-Apps – interaktive Visualisierungen, die Tool-Ergebnisse in MCP-Clients wie Claude Desktop rendern. Verwenden Sie diese Option, wenn Sie eine neue Detail- oder Listenansicht für ein MCP-Tool hinzufügen, Ansichtskomponenten in products/*/mcp/apps/ erstellen oder Tools über YAML mit UI-Apps verknüpfen.
