Guide pour l'ajout d'applications d'interface utilisateur MCP : visualisations interactives qui restituent les résultats des outils dans les clients MCP comme Claude Desktop. À utiliser lors de l'ajout d'une nouvelle vue détaillée ou de liste pour un outil MCP, de la création de composants de vue dans products/*/mcp/apps/ ou de la liaison d'outils à des applications d'interface utilisateur via YAML.
