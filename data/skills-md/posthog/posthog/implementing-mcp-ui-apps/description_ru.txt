Руководство по добавлению приложений пользовательского интерфейса MCP — интерактивные визуализации, которые отображают результаты работы инструментов в клиентах MCP, таких как Claude Desktop. Используйте при добавлении нового представления подробностей или списка для инструмента MCP, создании компонентов представления в файле Products/*/mcp/apps/ или привязке инструментов к приложениям пользовательского интерфейса через YAML.
