Guía para agregar aplicaciones de interfaz de usuario de MCP: visualizaciones interactivas que muestran resultados de herramientas en clientes de MCP como Claude Desktop. Úselo al agregar una nueva vista de lista o detalle para una herramienta MCP, crear componentes de vista en productos/*/mcp/apps/ o vincular herramientas a aplicaciones de UI a través de YAML.
