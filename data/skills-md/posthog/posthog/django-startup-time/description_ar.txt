احتفظ بالواردات الثقيلة بعيدًا عن مسار django.setup() الذي تدفع مقابله كل عملية (الويب، والكرفس، والمؤقت، والترحيل، والصدفة، وCI). يُستخدم عند لمس AppConfig.ready()، أو توصيل أجهزة استقبال الإشارات، أو تحرير جهاز توجيه API البطيء (posthog/api/rest_router.py أو __init__.py shim)، أو تأجيل عملية استيراد ثقيلة، أو عند فشل حماية ميزانية بدء التشغيل والاستيراد، أو عند دمج الرئيسي في فرع طويل الأمد يجعل جهاز التوجيه كسولًا.
