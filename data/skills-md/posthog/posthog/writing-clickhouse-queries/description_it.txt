Guida per scrivere query ClickHouse performanti nel codice prodotto PostHog. Da utilizzare quando si scrivono query runner HogQL, si progetta una tabella ClickHouse per un nuovo prodotto, si aggiungono colonne materializzate o si saltano indici o si sceglie un formato ID di riga. Per ottimizzare una query esistente che è già troppo lenta, utilizza invece `/optimizing-clickhouse-and-hogql-queries`.
