Produrre e strutturare report sulle prestazioni delle query lente per la produzione ClickHouse di PostHog (Stati Uniti e UE). Da utilizzare quando viene richiesto un report sulle query lente, l'analisi delle prestazioni delle query negli ultimi N giorni, il costo delle query per team, l'indagine OOM o timeout, le regressioni costo/memoria del cluster o i candidati alla materializzazione. Copre l'origine moderna `query_log_archive` (colonne digitate `lc_*`, conservazione di più giorni), come classificare e attribuire query lente, modelli di cause principali (JSONExtract non materializzato, suddivisioni ad alta cardinalità, join pesanti) e la struttura del report. Esegue le query tramite la capacità "query-clickhouse-via-metabase".
