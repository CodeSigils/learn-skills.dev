Guide les ingénieurs de PostHog tout au long du travail sur la plate-forme de widgets de tableau de bord : expédiez un nouveau type de widget (WIDGET_REGISTRY, catalogue, run_widgets, WidgetCard) ou mettez à jour un type livré (configuration, requête, mise en page, RBAC, barre de filtre de tuiles, pied de page de liste, titleHref, manettes). À utiliser pour WidgetSpec, widget_specs/, widget-configs.zod.ts, hogli build:openapi, error_tracking_list, session_replay_list, widgetFilters, formatWidgetListCountFooter, widget_query_throttle ou WidgetCard composition. Les nouveaux types nécessitent d’abord une confirmation de l’admission du widget. Pas pour l'ajout par lots MCP de types existants ou l'ajout de vignettes à un tableau de bord.
