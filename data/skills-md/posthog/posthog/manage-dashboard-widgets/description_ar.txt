يرشد مهندسي PostHog خلال عمل النظام الأساسي لعناصر واجهة تعامل لوحة المعلومات - شحن نوع عنصر واجهة مستخدم جديد (WIDGET_REGISTRY، كتالوج، run_widgets، WidgetCard) أو تحديث نوع تم شحنه (التكوين، الاستعلام، التخطيط، RBAC، شريط مرشح التجانب، تذييل القائمة، titleHref، الخانق). استخدم لـ WidgetSpec، أو widget_specs/، أو widget-configs.zod.ts، أو hogli build:openapi، أو error_tracking_list، أو session_replay_list، أو widgetFilters، أو formatWidgetListCountFooter، أو widget_query_throttle، أو تكوين WidgetCard. تحتاج الأنواع الجديدة إلى تأكيد استيعاب عناصر واجهة المستخدم أولاً. ليس من أجل إضافة دفعة MCP للأنواع الموجودة أو إضافة مربعات إلى لوحة المعلومات.
