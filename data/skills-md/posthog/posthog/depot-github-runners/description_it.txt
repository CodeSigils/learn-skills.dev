Configura i runner GitHub Actions gestiti dal depot come sostituto immediato dei runner ospitati su GitHub. Da utilizzare durante la configurazione o la migrazione dei flussi di lavoro di GitHub Actions per utilizzare i runner di Depot, la scelta delle dimensioni dei runner (CPU/RAM), la configurazione delle etichette di esecuzione, la configurazione di runner ARM o Windows o macOS, la risoluzione dei problemi dei runner di GitHub Actions, la configurazione del filtro in uscita, l'utilizzo della cache del depot con GitHub Actions o l'esecuzione di Dagger/Dependabot sui runner di Depot. Da utilizzare anche quando l'utente menziona le etichette dei runner depot-ubuntu, depot-windows, depot-macos o chiede informazioni sui runner GitHub Actions più veloci/economici.
