Úselo al migrar código de interfaz desde llamadas manuales de clientes API (`api.get`, `api.create`, `api.surveys.get`, `api.dashboards.list`, `new ApiRequest()`) e interfaces TypeScript escritas a mano para funciones y tipos de API generados. Activadores en archivos que se importan desde `lib/api`, archivos con `api.get<`, `api.create<`, `api.<entidad>.<método>`, definiciones de interfaz manuales que duplican serializadores de backend o cualquier archivo de frontend que construya URL de API a mano. Cubre el flujo de trabajo de reemplazo completo: encontrar el equivalente generado, intercambiar importaciones, adaptar sitios de llamadas y eliminar tipos manuales inactivos.
