Используйте при переносе кода внешнего интерфейса из ручных вызовов клиента API (api.get, api.create, api.surveys.get, api.dashboards.list, new ApiRequest()) и рукописных интерфейсов TypeScript в сгенерированные функции и типы API. Срабатывает при импорте файлов из `lib/api`, файлов с `api.get<`, `api.create<`, `api.<entity>.<method>`, ручных определений интерфейса, которые дублируют внутренние сериализаторы, или любого внешнего файла, который создает URL-адреса API вручную. Охватывает полный рабочий процесс замены — поиск сгенерированного эквивалента, замену импорта, адаптацию сайтов вызовов и удаление устаревших ручных типов.
