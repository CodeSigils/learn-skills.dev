À utiliser lors de la migration du code frontal à partir d'appels client API manuels (`api.get`, `api.create`, `api.surveys.get`, `api.dashboards.list`, `new ApiRequest()`) et d'interfaces TypeScript manuscrites vers des fonctions et des types d'API générés. Déclencheurs sur les fichiers importés depuis `lib/api`, les fichiers avec `api.get<`, `api.create<`, `api.<entity>.<method>`, les définitions d'interface manuelles qui dupliquent les sérialiseurs backend ou tout fichier frontend qui construit les URL d'API à la main. Couvre le flux de travail de remplacement complet : recherche de l'équivalent généré, échange des importations, adaptation des sites d'appel et suppression des types manuels morts.
