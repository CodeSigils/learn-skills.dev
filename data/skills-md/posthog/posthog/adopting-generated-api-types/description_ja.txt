フロントエンド コードを手動 API クライアント呼び出し (`api.get`、`api.create`、`api.surveys.get`、`api.dashboards.list`、`new ApiRequest()`) および手書きの TypeScript インターフェイスから生成された API 関数および型に移行するときに使用します。 `lib/api` からインポートするファイル、`api.get<`、`api.create<`、`api.<entity>.<method>` を含むファイル、バックエンド シリアライザーを複製する手動インターフェイス定義、または API URL を手動で構築するフロントエンド ファイルでトリガーされます。生成された同等物の検索、インポートの交換、呼び出しサイトの調整、無効な手動タイプの削除など、完全な置換ワークフローをカバーします。
