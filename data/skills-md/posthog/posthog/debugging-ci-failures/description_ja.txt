失敗した GitHub Actions CI をデバッグして PostHog PR、コミット、ブランチに対して実行し、広範な CI 健全性の質問 (「CI は赤ですか?」、「今日マスターは緑ですか?」、「現在何が壊れていますか?」) に答えます。ユーザーが CI が赤である理由を尋ねる場合、現在の CI またはマスターのステータスを尋ねる場合、またはチェックの失敗、GitHub Actions の実行、デポ ランナー、ワークフロー、ジョブ、シャード、不安定なテスト、lint の失敗、タイプチェックの失敗、スナップショットの差分、移行チェック、生成されたタイプのドリフト、またはスキルのビルドの失敗について言及する場合に使用します。 「hogli ci:insights」ダイジェスト (集約されたクロスラン CI インテリジェンス) から始めて、読み取り専用検査、障害分類、hogli を使用した最小のローカル再現、CI の再実行や GitHub への投稿を行わない安全なレポートをガイドします。
