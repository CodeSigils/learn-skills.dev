Debuggt fehlgeschlagene GitHub Actions CI-Ausführungen für PostHog PRs, Commits und Branches und beantwortet allgemeine CI-Gesundheitsfragen („Ist CI rot?“, „Ist Master heute grün?“, „Was ist gerade kaputt?“). Verwenden Sie diese Option, wenn der Benutzer fragt, warum CI rot ist, nach dem aktuellen CI- oder Master-Status fragt oder eine fehlgeschlagene Prüfung, die Ausführung von GitHub-Aktionen, einen Depot-Runner, einen Workflow, einen Job, einen Shard, einen flockigen Test, einen Lint-Fehler, einen Fehler bei der Typprüfung, einen Snapshot-Diff, eine Migrationsprüfung, eine Drift generierter Typen oder einen Fehler beim Skill-Build erwähnt. Beginnen Sie mit dem „hogli ci:insights“-Digest (aggregierte laufübergreifende CI-Intelligenz) und führen Sie dann die schreibgeschützte Inspektion, Fehlerklassifizierung, kleinste lokale Reproduktion mit hogli und sicheres Reporting ohne erneutes Ausführen von CI oder Posten auf GitHub durch.
