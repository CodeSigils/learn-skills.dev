Отладка неудачных действий GitHub Actions CI запускается для PR PostHog, коммитов и ветвей и отвечает на общие вопросы о работоспособности CI («красный CI?», «сегодня мастер-зеленый?», «что сейчас сломано?»). Используйте, когда пользователь спрашивает, почему CI красный, запрашивает текущий CI или статус мастера или упоминает неудачную проверку, запуск действий GitHub, запуск хранилища, рабочий процесс, задание, сегмент, нестабильный тест, сбой ворса, сбой проверки типов, разницу в моментальных снимках, проверку миграции, смещение сгенерированных типов или сбой сборки навыков. Начните с дайджеста `hogli ci:insights` (агрегированная аналитика перекрестной CI), затем проведите проверку только для чтения, классификацию сбоев, наименьшее локальное воспроизведение с помощью hogli и безопасные отчеты без повторного запуска CI или публикации на GitHub.
