실패한 GitHub Actions CI를 디버그하여 PostHog PR, 커밋 및 분기에 대해 실행하고 광범위한 CI 상태 질문에 답변합니다("CI가 빨간색입니까?", "오늘 마스터가 녹색입니까?", "지금 무엇이 문제입니까?"). 사용자가 CI가 빨간색인 이유를 묻거나, 현재 CI 또는 마스터 상태를 묻거나, 실패한 확인, GitHub Actions 실행, Depot Runner, 워크플로, 작업, 샤드, 불안정한 테스트, Lint 실패, 유형 확인 실패, 스냅샷 차이, 마이그레이션 확인, 생성된 유형 드리프트 또는 기술 빌드 실패를 언급할 때 사용합니다. 'hogli ci:insights' 다이제스트(집합된 교차 실행 CI 인텔리전스)로 시작한 다음 읽기 전용 검사, 오류 분류, hogli를 사용한 최소 로컬 재현 및 CI를 다시 실행하거나 GitHub에 게시하지 않고도 안전한 보고를 안내합니다.
