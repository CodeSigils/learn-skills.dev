تصحيح الأخطاء الفاشلة في GitHub Actions CI التي تعمل على PostHog PRs والالتزامات والفروع، وتجيب على أسئلة واسعة النطاق حول صحة CI ("هل CI أحمر؟"، "هل السيد أخضر اليوم؟"، "ما الذي تم كسره الآن؟"). يُستخدم عندما يسأل المستخدم عن سبب ظهور CI باللون الأحمر، أو يسأل عن حالة CI الحالية أو الحالة الرئيسية، أو يذكر فحصًا فاشلاً، أو تشغيل GitHub Actions، أو مشغل المستودع، أو سير العمل، أو الوظيفة، أو الشظية، أو الاختبار غير المستقر، أو فشل الوبر، أو فشل التحقق من النوع، أو فرق اللقطة، أو فحص الترحيل، أو انحراف الأنواع التي تم إنشاؤها، أو فشل بناء المهارات. ابدأ بملخص `hogli ci:insights` (استخبارات CI المجمعة عبر التشغيل)، ثم قم بتوجيه الفحص للقراءة فقط، وتصنيف الفشل، وأصغر عملية إعادة إنتاج محلية باستخدام hogli، وإعداد التقارير الآمنة دون إعادة تشغيل CI أو النشر على GitHub.
