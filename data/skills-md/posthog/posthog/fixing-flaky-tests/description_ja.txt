PostHog モノリポジトリで不安定なテストの再現、根本原因の解決、修正、検証をエージェントにガイドします。 CI でテストが断続的に失敗するが再実行またはローカルで成功する場合、「hogli ci:insights」または debugging-ci-failures スキルが失敗を不安定なテストとして分類する場合、不安定なジョブの GitHub Actions URL が指定された場合、または不安定な Jest、pytest、または Playwright テストのデフレーク、安定化、または修正を求められた場合に使用します。中核的な規律: 何かを変更する前にローカルで再現し、根本原因を修正し (スリープ、再試行、またはより大きなタイムアウトでマスクしないでください)、観察された障害率に合わせたサイズの N 実行検証ループで修正を証明します。
