PostHog 모노레포에서 불안정한 테스트를 재현하고, 근본 원인을 찾고, 수정하고, 검증하는 과정을 에이전트에게 안내합니다. 테스트가 CI에서 간헐적으로 실패했지만 재실행 또는 로컬에서 통과하는 경우, 'hogli ci:insights' 또는 디버깅-ci-failures 기술이 실패를 불안정한 테스트로 분류하는 경우, 불안정한 작업에 대한 GitHub Actions URL이 제공될 때, 불안정한 Jest, pytest 또는 Playwright 테스트를 해제, 안정화 또는 수정하라는 요청을 받을 때 사용합니다. 핵심 원칙: 무엇이든 변경하기 전에 로컬로 재현하고, 근본 원인을 수정하고(절대 절전, 재시도 또는 더 큰 시간 초과로 마스킹하지 않음), 관찰된 실패율에 맞게 크기가 조정된 N 실행 검증 루프를 통해 수정 사항을 증명합니다.
