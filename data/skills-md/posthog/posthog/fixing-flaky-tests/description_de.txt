Führt einen Agenten durch die Reproduktion, Fehlerursache, Behebung und Validierung von Flaky-Tests im PostHog-Monorepo. Verwenden Sie diese Option, wenn ein Test in CI zeitweise fehlschlägt, aber bei einer erneuten Ausführung oder lokal nicht funktioniert, wenn „hogli ci:insights“ oder der Skill debugging-ci-failures einen Fehler als fehlerhaften Test klassifiziert, wenn eine GitHub Actions-URL für einen fehlerhaften Job angegeben wird oder wenn Sie aufgefordert werden, einen fehlerhaften Jest-, Pytest- oder Playwright-Test zu entflaken, zu stabilisieren oder zu reparieren. Kerndisziplin: Lokal reproduzieren, bevor etwas geändert wird, die Grundursache beheben (niemals durch Ruhezeiten, Wiederholungsversuche oder längere Zeitüberschreitungen maskieren) und die Behebung mit einer N-Run-Validierungsschleife beweisen, deren Größe auf die beobachtete Fehlerrate abgestimmt ist.
