Запустите анализ ClickHouse `system.query_log` через внутренний API Metabase. Используйте при исследовании медленных запросов, кандидатов на материализацию, производительности запросов для каждой группы, проблем с затратами или памятью ClickHouse или любых вопросов system.query_log. Охватывает prod-us и prod-eu, аутентификацию файлов cookie с использованием единого входа через `hogli` и готовые к использованию шаблоны запросов.
