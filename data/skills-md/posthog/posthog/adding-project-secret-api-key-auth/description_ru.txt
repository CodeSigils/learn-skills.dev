Как получить доступ к конечной точке API PostHog с помощью аутентификации секретного ключа API проекта (PSAK) — учетных данных службы без участия пользователя в рамках проекта. Используйте при добавлении поддержки PSAK к действию набора представлений, предоставляя новую область для PSAK, обработке синтетических пользователей (ProjectSecretAPIKeyUser) или выборе регулирования скорости с учетом PSAK. Условия триггера: PSAK, ProjectSecretAPIKey, секретный ключ API проекта, токен phs_, проверка подлинности службы, программная проверка подлинности конечной точки.
