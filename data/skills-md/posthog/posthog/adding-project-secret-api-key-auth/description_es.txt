Cómo controlar un punto final de la API de PostHog con autenticación de clave API secreta del proyecto (PSAK): una credencial de servicio sin usuario y con ámbito de proyecto. Úselo al agregar compatibilidad con PSAK a una acción de conjunto de vistas, permitiendo un nuevo alcance para PSAK, manejando usuarios sintéticos (ProjectSecretAPIKeyUser) o eligiendo limitaciones de velocidad compatibles con PSAK. Términos de activación: PSAK, ProjectSecretAPIKey, clave API secreta del proyecto, token phs_, autenticación de servicio, autenticación de punto final programática.
