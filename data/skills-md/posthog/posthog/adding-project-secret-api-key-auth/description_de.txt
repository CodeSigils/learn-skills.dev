So sperren Sie einen PostHog-API-Endpunkt mit der Projekt-Secret-API-Key-Authentifizierung (PSAK) – einem projektbezogenen, benutzerlosen Dienstanmeldedatensatz. Verwenden Sie diese Option, wenn Sie einer Viewset-Aktion PSAK-Unterstützung hinzufügen, einen neuen Bereich für PSAKs zulassen, synthetische Benutzer verarbeiten (ProjectSecretAPIKeyUser) oder PSAK-fähige Ratendrosseln auswählen. Auslöserbegriffe: PSAK, ProjectSecretAPIKey, geheimer Projekt-API-Schlüssel, phs_token, Dienstauthentifizierung, programmatische Endpunktauthentifizierung.
