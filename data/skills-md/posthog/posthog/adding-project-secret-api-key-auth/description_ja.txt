プロジェクト シークレット API キー (PSAK) 認証 (プロジェクト スコープのユーザーレス サービス資格情報) を使用して PostHog API エンドポイントをゲートする方法。 PSAK サポートをビューセット アクションに追加する場合、PSAK の新しいスコープを許可する場合、合成ユーザー (ProjectSecretAPIKeyUser) を処理する場合、または PSAK 対応のレート スロットルを選択する場合に使用します。トリガー用語: PSAK、ProjectSecretAPIKey、プロジェクト シークレット API キー、phs_token、サービス認証、プログラムによるエンドポイント認証。
