كيفية بوابة نقطة نهاية PostHog API باستخدام مصادقة مفتاح API السري للمشروع (PSAK) - بيانات اعتماد خدمة على نطاق المشروع وبدون مستخدم. يُستخدم عند إضافة دعم PSAK إلى إجراء مجموعة عرض، أو السماح بنطاق جديد لـ PSAK، أو التعامل مع المستخدمين الاصطناعيين (ProjectSecretAPIKeyUser)، أو اختيار ضوابط المعدل المدركة لـ PSAK. مصطلحات التشغيل: PSAK، وProjectSecretAPIKey، ومفتاح API السري للمشروع، ورمز phs_، ومصادقة الخدمة، ومصادقة نقطة النهاية الآلية.
