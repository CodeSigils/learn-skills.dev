Come eseguire il gate di un endpoint API PostHog con l'autenticazione della chiave API segreta del progetto (PSAK): una credenziale di servizio senza utente e con ambito di progetto. Da utilizzare quando si aggiunge il supporto PSAK a un'azione del viewset, consentendo un nuovo ambito per PSAK, gestendo utenti sintetici (ProjectSecretAPIKeyUser) o scegliendo limitazioni della velocità compatibili con PSAK. Termini di attivazione: PSAK, ProjectSecretAPIKey, chiave API segreta del progetto, token phs, autenticazione del servizio, autenticazione dell'endpoint programmatico.
