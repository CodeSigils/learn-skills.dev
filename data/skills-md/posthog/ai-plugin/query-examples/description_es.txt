Ejemplos de consultas de HogQL y material de referencia para datos de PostHog. Lea al escribir consultas SQL para encontrar patrones de análisis (tendencias, embudos, retención, ciclo de vida, rutas, rigidez, análisis web, seguimiento de errores, registros, sesiones, seguimientos de LLM) y datos del sistema (insights, paneles, cohortes, indicadores de características, experimentos, encuestas, flujos de cerdos, almacén de datos). Incluye diferencias de sintaxis de HogQL, esquemas de modelo de sistema y funciones disponibles.
