يرشد انتقالات حالة التجربة: التشغيل، والإيقاف المؤقت، والاستئناف، والإنهاء، ومتغيرات الشحن، والأرشفة، وإعادة التعيين، والتكرار. يغطي الشروط المسبقة، والآثار المترتبة على تعيين وتحليل المتغيرات، وإطار القرار الخاص بموعد استخدام كل إجراء.
يتم التشغيل عندما: يطلب المستخدم بدء تجربة أو إيقافها مؤقتًا أو استئنافها أو إنهائها أو شحنها أو أرشفتها أو إعادة تعيينها أو تكرارها.
لا تقم بالتشغيل عندما: يقوم المستخدم بإنشاء تجربة (استخدم إنشاء التجارب)، أو تكوين الطرح (استخدم تكوين بدء التشغيل)، أو إعداد المقاييس (استخدم تحليلات تكوين التجربة).
