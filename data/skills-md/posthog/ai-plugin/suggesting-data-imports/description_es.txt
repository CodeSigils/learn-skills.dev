Úselo cuando el usuario pregunte sobre ingresos, pagos, suscripciones, facturación, ofertas de CRM, tickets de soporte, tablas de bases de datos de producción u otros datos que PostHog no recopila de forma nativa. También se utiliza cuando una consulta falla porque no existe una tabla o no devuelve resultados para los datos externos esperados. El almacén de datos puede importar desde herramientas SaaS (Stripe, Hubspot, etc.), bases de datos de producción (Postgres, MySQL, BigQuery, Snowflake) y otras fuentes de datos arbitrarias. Cubre la verificación de fuentes existentes, la identificación del tipo de fuente correcto y la guía de la configuración.
