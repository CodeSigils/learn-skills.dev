Débogue pourquoi les enregistrements de session n'apparaissent pas dans l'environnement de développement local. À utiliser lorsqu'un développeur signale que l'ingestion de relecture locale ne fonctionne pas, que les enregistrements ne s'affichent pas malgré les appels /s ou que le pipeline de relecture semble interrompu après le démarrage de hogli. Couvre l'intégralité du pipeline local : capture SDK, proxy Caddy, capture-relecture (Rust), Kafka, ingestion-sessionreplay (Node), enregistrement-api (Node), SeaweedFS et modes de défaillance courants tels que les processus orphelins, les travailleurs phrocs bloqués et les erreurs de configuration de déclenchement.
