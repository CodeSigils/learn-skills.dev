Conecte un espacio de trabajo real de Slack a las conversaciones locales de PostHog (la aplicación SupportHog Slack) para que los mensajes de Slack se conviertan en tickets de soporte y las respuestas se envíen. Úselo cuando el usuario quiera probar la integración de Slack de las conversaciones localmente, presione "El ID de cliente de soporte de Slack OAuth no está configurado", aparece una pantalla en blanco o "Error de red" en la devolución de llamada de OAuth, o pregunta cómo configurar SUPPORT_SLACK_APP_CLIENT_ID/un túnel para eventos de soporte de Slack. Cubre los ámbitos y la aplicación Slack, la configuración dinámica SUPPORT_SLACK_* y la división de claves: localhost para OAuth y la interfaz de usuario, un túnel público solo para eventos entrantes.
