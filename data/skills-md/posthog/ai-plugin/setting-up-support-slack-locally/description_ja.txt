実際の Slack ワークスペースをローカルの PostHog Conversations (SupportHog Slack アプリ) に接続すると、Slack メッセージがサポート チケットになり、返信がポストバックされます。ユーザーが会話の Slack 統合をローカルでテストしたい場合、「サポート Slack OAuth クライアント ID が構成されていません」を押した場合、OAuth コールバックで白い画面または「ネットワーク エラー」が表示された場合、または SUPPORT_SLACK_APP_CLIENT_ID / supporthog Slack イベントのトンネルを設定する方法を尋ねた場合に使用します。 Slack アプリ + スコープ、SUPPORT_SLACK_* 動的設定、およびキー分割 (OAuth および UI 用の localhost、受信イベント専用のパブリック トンネル) について説明します。
