Interswitch Lending API — قروض النانو، وإقراض الرواتب، ومنتجات تمويل القيمة. استخدم هذه المهارة عند تنفيذ الإقراض الصغير، أو ميزات سلفة الراتب، أو تمويل المنتج، أو إنشاء القرض، أو معالجة السداد من خلال Interswitch. استخدم أيضًا عندما ترى إشارات إلى القروض النانوية، أو إقراض الرواتب، أو تمويل القيمة، أو تسجيل الائتمان، أو صرف القروض عبر Interswitch APIs.
