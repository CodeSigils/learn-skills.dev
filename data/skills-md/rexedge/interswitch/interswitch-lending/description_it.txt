API Interswitch Lending: nanoprestiti, prestiti salariali e prodotti di finanziamento a valore. Utilizza questa competenza ogni volta che implementi microprestiti, funzionalità di anticipo salariale, finanziamento di prodotti, concessione di prestiti o elaborazione di rimborsi tramite Interswitch. Da utilizzare anche quando si vedono riferimenti a nano-prestiti, prestiti salariali, finanziamenti di valore, scoring del credito o erogazione di prestiti tramite le API Interswitch.
