Interswitch Customer Insights API - الوصول إلى المعلومات السكانية للعملاء، والتاريخ المالي، وعادات الإنفاق من أجل KYC، وتسجيل الائتمان، والتخصيص. استخدم هذه المهارة عند إجراء فحوصات KYC، أو بناء نماذج تسجيل الائتمان، أو تحليل السلوك المالي للعميل، أو التحقق من هوية العميل، أو تنفيذ التخصيص المستند إلى البيانات. استخدمه أيضًا عندما ترى مراجع إلى المعلومات السكانية للعملاء، أو التاريخ المالي، أو عادات الإنفاق، أو نقاط نهاية /api/v1/customer-insights.
