Interswitch Cardless Payments API - إنشاء رموز دفع فردية ومجمّعة للسحب النقدي من أجهزة الصراف الآلي بدون بطاقة. استخدم هذه المهارة عند تنفيذ السحب بدون بطاقة، أو إنشاء رموز الدفع للعملاء، أو إدارة عمليات رموز الدفع المجمعة، أو إنشاء منصات للصرف النقدي. استخدمه أيضًا عندما ترى إشارات إلى رمز الدفع، أو السحب بدون بطاقة، أو /api/v1/paycode، أو السحب من أجهزة الصراف الآلي بدون بطاقة، أو نقاط نهاية إنشاء رمز الدفع.
