Interswitch Cardless Payments API — генерируйте одиночные и массовые платежные коды для снятия наличных в банкоматах без карты. Используйте этот навык при внедрении безкартового снятия средств, создании кодов оплаты для клиентов, управлении массовыми операциями с кодами оплаты или создании платформ для выдачи наличных. Также используйте его, когда видите ссылки на код оплаты, снятие без карты, /api/v1/paycode, снятие в банкомате без карты или конечные точки генерации кода оплаты.
