Interswitch Split Settlement API - توزيع المدفوعات عبر حسابات مستفيدين متعددة باستخدام Wallet-Pay مع مصادقة جواز السفر v2. استخدم هذه المهارة عند تنفيذ مدفوعات السوق، أو التسوية متعددة الأطراف، أو مشاركة الإيرادات بين البائعين، أو تكوينات الدفع المقسمة، أو تدفقات الدفع عبر المحفظة. استخدمه أيضًا عندما ترى إشارات إلى /api/v2/wallet-pay/initialize، أو SplitSettlement، أو Passport-v2، أو تقسيمات النسبة المئوية للمستفيد.
