Interswitch Split Settlement API – Verteilen Sie Zahlungen über Wallet-Pay mit Passport-v2-Authentifizierung auf mehrere Begünstigtenkonten. Nutzen Sie diese Fähigkeit bei der Implementierung von Marktplatzzahlungen, der Mehrparteienabrechnung, der Umsatzbeteiligung zwischen Anbietern, geteilten Zahlungskonfigurationen oder Wallet-Pay-Flows. Verwenden Sie es auch, wenn Sie Verweise auf /api/v2/wallet-pay/initialize, splitSettlement, Passport-v2 oder prozentuale Aufteilungen des Begünstigten sehen.
