Interswitch Web チェックアウト — Web サイトで支払いを受け入れるためのインライン チェックアウト (JavaScript ウィジェット) および Web リダイレクト (HTML フォーム POST)。このスキルは、チェックアウト ページの構築、Interswitch 支払いゲートウェイの統合、インライン チェックアウト ポップアップの実装、Web リダイレクト支払い、支払いコールバックの処理、またはサーバー側の再クエリによるトランザクション ステータスの確認を行うときに使用します。また、webpayCheckout、inline-checkout.js、pay_item_id、merchant_code、または newwebpay URL への参照が表示された場合にも使用します。
