Interswitch Web Checkout: pago en línea (widget de JavaScript) y redireccionamiento web (formulario HTML POST) para aceptar pagos en su sitio web. Utilice esta habilidad siempre que cree una página de pago, integre la pasarela de pago Interswitch, implemente una ventana emergente de pago en línea, redireccione pagos web, maneje devoluciones de llamadas de pago o confirme el estado de la transacción mediante una consulta del lado del servidor. Úselo también cuando vea referencias a webpayCheckout, inline-checkout.js, pay_item_id, Merchant_code o nuevas URL de webpay.
