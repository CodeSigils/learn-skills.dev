Interswitch Web Checkout: pagamento in linea (widget JavaScript) e reindirizzamento Web (modulo HTML POST) per accettare pagamenti sul tuo sito web. Utilizza questa competenza ogni volta che crei una pagina di pagamento, integri il gateway di pagamento Interswitch, implementi popup di pagamento in linea, pagamenti di reindirizzamento web, gestisci richiamate di pagamento o confermi lo stato della transazione tramite query lato server. Utilizzalo anche quando vedi riferimenti a webpayCheckout, inline-checkout.js, pay_item_id, commerciante_code o URL newwebpay.
