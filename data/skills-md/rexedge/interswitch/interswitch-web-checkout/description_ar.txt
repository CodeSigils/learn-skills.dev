Interswitch Web Checkout - الدفع المضمن (أداة JavaScript) وإعادة التوجيه عبر الويب (نموذج HTML POST) لقبول المدفوعات على موقع الويب الخاص بك. استخدم هذه المهارة عند إنشاء صفحة الدفع، أو دمج بوابة الدفع Interswitch، أو تنفيذ نافذة الدفع المنبثقة المضمنة، أو إعادة توجيه المدفوعات عبر الويب، أو التعامل مع عمليات الاسترجاعات الخاصة بالدفع، أو تأكيد حالة المعاملة عبر إعادة الاستعلام من جانب الخادم. استخدمها أيضًا عندما ترى إشارات إلى webpayCheckout، أو inline-checkout.js، أو pay_item_id، أو Merchant_code، أو عناوين URL لـ newwebpay.
