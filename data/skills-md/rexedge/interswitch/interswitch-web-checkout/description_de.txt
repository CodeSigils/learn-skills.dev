Interswitch Web Checkout – Inline Checkout (JavaScript-Widget) und Web Redirect (HTML-Formular POST) zum Akzeptieren von Zahlungen auf Ihrer Website. Nutzen Sie diese Fähigkeit, wenn Sie eine Checkout-Seite erstellen, das Interswitch-Zahlungsgateway integrieren, ein Inline-Checkout-Popup implementieren, Web-Umleitungszahlungen durchführen, Zahlungsrückrufe bearbeiten oder den Transaktionsstatus über eine serverseitige Abfrage bestätigen. Verwenden Sie es auch, wenn Sie Verweise auf webpayCheckout-, inline-checkout.js-, pay_item_id-, Merchant_code- oder newwebpay-URLs sehen.
