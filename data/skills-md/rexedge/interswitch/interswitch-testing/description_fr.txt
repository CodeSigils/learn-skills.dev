Tests Interswitch : testez les informations d'identification, les cartes de test, les URL du bac à sable, le changement d'environnement et les stratégies de test pour toutes les API Interswitch. Utilisez cette compétence chaque fois que vous testez les intégrations Interswitch, en utilisant des numéros de carte de test, en configurant l'environnement sandbox, en vérifiant les flux de paiement avec des données de test ou en débogant des transactions de test. À utiliser également lorsque vous voyez des références aux informations d'identification de test, sk_test_, aux URL du bac à sable, aux numéros de carte de test (5061050254756707864, 4000000000002503) ou aux environnements d'assurance qualité.
