Interswitch Wallet Services API - إنشاء محافظ افتراضية، وإدارة الأرصدة، وتمويل المحافظ، وإجراء عمليات شراء باستخدام البطاقات الافتراضية. استخدم هذه المهارة عند إنشاء محافظ العملاء، أو التحقق من أرصدة المحفظة، أو استرداد تفاصيل المحفظة، أو إدارة حسابات البطاقة الافتراضية، أو إنشاء تدفقات دفع ذات قيمة مخزنة. استخدمه أيضًا عندما ترى إشارات إلى /api/v1/wallet endpoint أو PAN للمحفظة أو أرقام الحسابات الافتراضية أو المعاملات المستندة إلى المحفظة.
