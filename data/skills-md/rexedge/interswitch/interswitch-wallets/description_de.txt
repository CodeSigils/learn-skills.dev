Interswitch Wallet Services API – Erstellen Sie virtuelle Geldbörsen, verwalten Sie Guthaben, finanzieren Sie Geldbörsen und tätigen Sie Einkäufe mit virtuellen Karten. Nutzen Sie diese Fähigkeit, wenn Sie Kunden-Wallets erstellen, Wallet-Guthaben überprüfen, Wallet-Details abrufen, virtuelle Kartenkonten verwalten oder Zahlungsflüsse mit gespeicherten Werten erstellen. Verwenden Sie es auch, wenn Sie Verweise auf den Endpunkt /api/v1/wallet, die Wallet-PAN, virtuelle Kontonummern oder Wallet-basierte Transaktionen sehen.
