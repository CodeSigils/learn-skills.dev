Interswitch Wallet Services API – Erstellen Sie virtuelle Geldbörsen, verwalten Sie Guthaben, finanzieren Sie Geldbörsen und tätigen Sie Einkäufe mit virtuellen Karten. Use this skill whenever creating customer wallets, checking wallet balances, retrieving wallet details, managing virtual card accounts, or building stored-value payment flows. Verwenden Sie es auch, wenn Sie Verweise auf den Endpunkt /api/v1/wallet, die Wallet-PAN, virtuelle Kontonummern oder Wallet-basierte Transaktionen sehen.
