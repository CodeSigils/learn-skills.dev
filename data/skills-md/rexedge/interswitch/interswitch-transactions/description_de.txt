Interswitch Transactions API – Lastschrift-Wallets, Abfrage des Transaktionsstatus, Stornierung von Transaktionen und Verwaltung des Zahlungslebenszyklus. Verwenden Sie diese Fähigkeit, wenn Sie Wallet-Konten belasten, den Transaktionsstatus anhand von Referenzen überprüfen, Transaktionsstornierungen durchführen, abgeschlossene Zahlungen erneut abfragen oder Transaktionsverwaltungsabläufe erstellen. Verwenden Sie es auch, wenn Sie Verweise auf /api/v1/transaction, transact, reverse, Transaction Requery oder ResponseCode-Handling sehen.
