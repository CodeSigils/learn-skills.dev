Interswitch Payment Links API – Erstellen Sie gemeinsam nutzbare Zahlungslinks, verwalten Sie gehostete Felder und verarbeiten Sie Zahlungen ohne Karte. Nutzen Sie diese Fähigkeit, wenn Sie Zahlungslinks für Rechnungen erstellen, Zahlungsseiten ohne Code erstellen, die Verwaltung von Zahlungslinks implementieren oder Kunden über Links mehrere Zahlungsoptionen anbieten. Verwenden Sie diese Option auch, wenn Sie Verweise auf Zahlungslinks, Quickteller-Zahlungsseiten, Pay-by-Link oder Nicht-Kartenzahlungskanäle sehen.
