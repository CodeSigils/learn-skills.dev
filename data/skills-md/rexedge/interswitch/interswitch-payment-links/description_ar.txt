Interswitch Payment Links API - إنشاء روابط دفع قابلة للمشاركة، وإدارة الحقول المستضافة، ومعالجة المدفوعات غير المتعلقة بالبطاقة. استخدم هذه المهارة عند إنشاء روابط دفع للفواتير، أو إنشاء صفحات دفع بدون رموز، أو تنفيذ إدارة روابط الدفع، أو تقديم خيارات دفع متعددة للعملاء عبر الروابط. استخدمه أيضًا عندما ترى إشارات إلى روابط الدفع، أو صفحات دفع Quickteller، أو قنوات الدفع عن طريق الرابط، أو قنوات الدفع بدون بطاقة.
