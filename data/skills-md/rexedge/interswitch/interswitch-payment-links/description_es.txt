API de enlaces de pago Interswitch: cree enlaces de pago que se puedan compartir, administre campos alojados y procese pagos sin tarjeta. Utilice esta habilidad siempre que genere enlaces de pago para facturas, cree páginas de pago sin código, implemente gestión de enlaces de pago u ofrezca a los clientes múltiples opciones de pago a través de enlaces. Utilícelo también cuando vea referencias a enlaces de pago, páginas de pago de Quickteller, pago por enlace o canales de pago sin tarjeta.
