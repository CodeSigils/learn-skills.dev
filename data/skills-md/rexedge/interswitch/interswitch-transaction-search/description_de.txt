Interswitch Transaction Search API – Schnellsuche, Referenzsuche, Massensuche und detaillierte Transaktionsberichte. Verwenden Sie diese Fähigkeit, wenn Sie Transaktionsdetails nachschlagen, einen Abgleich durchführen, Transaktionen nach Referenz, Datumsbereich oder Status durchsuchen, Transaktionsberichte erstellen oder Zahlungsprobleme beheben. Verwenden Sie diese Option auch, wenn Sie Verweise auf die Transaktionssuche, Transaktionssuche, Schnellsuche, Massensuche oder /api/v1/transactions/search-Endpunkte sehen.
