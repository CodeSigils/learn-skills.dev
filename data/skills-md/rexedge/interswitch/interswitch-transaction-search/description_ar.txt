واجهة برمجة تطبيقات Interswitch Transaction Search - البحث السريع والبحث المرجعي والبحث المجمع وإعداد تقارير مفصلة عن المعاملات. استخدم هذه المهارة عند البحث عن تفاصيل المعاملة، أو إجراء التسوية، أو البحث في المعاملات حسب المرجع، أو النطاق الزمني، أو الحالة، أو إنشاء تقارير المعاملات، أو تصحيح مشكلات الدفع. استخدمه أيضًا عندما ترى مراجع للبحث عن المعاملات، أو البحث عن المعاملات، أو البحث السريع، أو البحث المجمع، أو /api/v1/transactions/search نقاط النهاية.
