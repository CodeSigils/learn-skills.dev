API de búsqueda de transacciones entre conmutadores: búsqueda rápida, búsqueda de referencias, búsqueda masiva e informes detallados de transacciones. Utilice esta habilidad siempre que busque detalles de transacciones, realice conciliaciones, busque transacciones por referencia, rango de fechas o estado, cree informes de transacciones o depure problemas de pago. Utilícelo también cuando vea referencias a búsqueda de transacciones, búsqueda de transacciones, búsqueda rápida, búsqueda masiva o /api/v1/transactions/search endpoints.
