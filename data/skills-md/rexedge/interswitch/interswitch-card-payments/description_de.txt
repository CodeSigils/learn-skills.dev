Interswitch Card Payments API – Verarbeiten Sie Kartentransaktionen direkt über die API, verarbeiten Sie 3D Secure (Visa/Mastercard), Hosted Fields für PCI-Konformität und Google Pay. Nutzen Sie diese Fähigkeit, wenn Sie einen benutzerdefinierten Kartenzahlungsablauf erstellen, die 3D-Secure-Authentifizierung implementieren, gehostete Felder für die PCI-konforme Kartenerfassung verwenden, Google Pay integrieren oder direkte Kartengebühren verarbeiten. Verwenden Sie es auch, wenn Sie Verweise auf AuthData, 3DSecure, OTP-Validierung, gehostete Felder, Zahlungs-API-Endpunkt oder Karten-PIN/OTP-Übermittlung sehen.
