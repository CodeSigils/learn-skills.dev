Interswitch Card Payments API — API 経由でカード取引を直接処理し、3D セキュア (Visa/Mastercard)、PCI 準拠のホスト フィールド、Google Pay を処理します。このスキルは、カスタム カード支払いフローの構築、3D セキュア認証の実装、PCI 準拠のカード収集のためのホスト フィールドの使用、Google Pay の統合、または直接カード請求の処理を行うときに使用します。 authData、3DSecure、OTP 検証、ホストされたフィールド、支払い API エンドポイント、またはカード PIN/OTP 送信への参照が表示された場合にも使用します。
