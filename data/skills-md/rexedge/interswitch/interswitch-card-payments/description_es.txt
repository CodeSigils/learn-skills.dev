API de pagos con tarjeta Interswitch: procese transacciones con tarjeta directamente a través de API, maneje 3D Secure (Visa/Mastercard), Hosted Fields para cumplimiento de PCI y Google Pay. Utilice esta habilidad siempre que cree un flujo de pago con tarjeta personalizado, implemente la autenticación 3D Secure, utilice Hosted Fields para el cobro de tarjetas compatible con PCI, integre Google Pay o procese cargos directos con tarjeta. Úselo también cuando vea referencias a authData, 3DSecure, validación de OTP, campos alojados, punto final de API de pago o envío de PIN/OTP de tarjeta.
