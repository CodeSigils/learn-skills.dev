API Interswitch Card Payments — обрабатывайте транзакции по картам напрямую через API, обрабатывайте 3D Secure (Visa/Mastercard), размещенные поля для соответствия PCI и Google Pay. Используйте этот навык при создании индивидуального процесса оплаты картой, реализации аутентификации 3D Secure, использовании Hosted Fields для сбора карт, соответствующих PCI, интеграции Google Pay или обработке прямых платежей по карте. Также используйте, когда вы видите ссылки на authData, 3DSecure, проверку OTP, размещенные поля, конечную точку API оплаты или отправку PIN-кода/OTP карты.
