Interswitch Value Added Services API – Rechnungszahlung, Aufladen von Sendezeit, Kundenvalidierung, virtuelles Aufladen und E-Pins. Nutzen Sie diese Fähigkeit, wenn Sie Rechnungen bezahlen (Strom, TV, Internet), Sendezeit oder Daten kaufen, Kundenkonten für Rechnungssteller validieren, E-Pins ausstellen oder VAS-Aggregationsplattformen aufbauen. Verwenden Sie es auch, wenn Sie Verweise auf /api/v2/quickteller, Billers, CategoryId, PaymentCode, Kundenvalidierung oder Endpunkte zum Aufladen von Sendezeit sehen.
