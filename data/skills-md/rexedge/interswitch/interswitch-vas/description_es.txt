API de servicios de valor agregado de Interswitch: pago de facturas, recarga de tiempo aire, validación de clientes, recarga virtual y pines electrónicos. Utilice esta habilidad siempre que implemente pagos de facturas (electricidad, TV, Internet), compre tiempo aire o datos, valide cuentas de clientes para facturadores, emita e-pins o cree plataformas de agregación VAS. Utilícelo también cuando vea referencias a /api/v2/quickteller, facturadores, ID de categoría, código de pago, validación de cliente o puntos finales de recarga de tiempo aire.
