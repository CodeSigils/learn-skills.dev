Interswitch Payouts API - ابحث عن المؤسسات المتلقية واكتشف قنوات الدفع وتوجيه المدفوعات. استخدم هذه المهارة عند بناء البنية التحتية للدفع، أو اكتشاف قنوات الصرف المتاحة، أو حل مشكلة المؤسسات المتلقية، أو تنفيذ توجيه دفع متعدد القنوات. استخدم أيضًا عندما ترى إشارات إلى قنوات الدفع، أو مؤسسات الاستلام، أو توجيه الصرف، أو نقاط النهاية /api/v1/payouts.
