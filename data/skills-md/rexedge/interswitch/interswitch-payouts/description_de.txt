Interswitch Payouts API – Suchen Sie nach empfangenden Institutionen, entdecken Sie Auszahlungskanäle und leiten Sie Auszahlungen weiter. Nutzen Sie diese Fähigkeit, wenn Sie eine Auszahlungsinfrastruktur aufbauen, verfügbare Auszahlungskanäle ermitteln, Empfangsinstitute auflösen oder eine Mehrkanal-Auszahlungsweiterleitung implementieren. Verwenden Sie diese Option auch, wenn Sie Verweise auf Auszahlungskanäle, empfangende Institutionen, Auszahlungsrouting oder /api/v1/payouts-Endpunkte sehen.
