API de transferencias entre conmutadores: valide cuentas bancarias, inicie transferencias de fondos únicas y masivas, verifique el estado de las transferencias y resuelva códigos bancarios. Utilice esta habilidad siempre que cree flujos de pagos, procese desembolsos, valide cuentas bancarias antes de la transferencia, genere hashes MAC para la seguridad de las transferencias o implemente operaciones de transferencias masivas. Úselo también cuando vea referencias a /api/v2/quickteller/pagos/transferencias, validación de cuenta, hash MAC, objetos de remitente/beneficiario o resolución de código bancario.
