Interswitch Transfers API - التحقق من صحة الحسابات المصرفية، وبدء تحويلات الأموال الفردية والجماعية، والتحقق من حالة التحويل، وحل رموز البنك. استخدم هذه المهارة عند إنشاء تدفقات العوائد، أو معالجة المدفوعات، أو التحقق من صحة الحسابات المصرفية قبل التحويل، أو إنشاء تجزئة MAC لأمن النقل، أو تنفيذ عمليات التحويل المجمعة. استخدمه أيضًا عندما ترى إشارات إلى /api/v2/quickteller/ Payments/transfers، أو التحقق من صحة الحساب، أو تجزئة MAC، أو كائنات المرسل/المستفيد، أو تحليل رمز البنك.
