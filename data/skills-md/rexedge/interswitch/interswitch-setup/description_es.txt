Configure el cliente API de Interswitch, las variables de entorno, la autenticación OAuth 2.0 y los asistentes de TypeScript para la integración de pagos del lado del servidor. Utilice esta habilidad siempre que inicie una nueva integración de Interswitch, configure claves API, cree un contenedor de recuperación reutilizable o establezca las bases para cualquier función de Interswitch. Úselo también cuando vea errores relacionados con la falta de CLIENT_ID, SECRET_KEY, fallas de autenticación o cuando necesite comprender las URL base de Interswitch, el flujo de pasaporte OAuth, el formato de respuesta, las monedas o el cambio de entorno (prueba/en vivo).
