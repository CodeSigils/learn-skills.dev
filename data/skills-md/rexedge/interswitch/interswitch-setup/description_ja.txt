サーバー側の支払い統合のために、Interswitch API クライアント、環境変数、OAuth 2.0 認証、および TypeScript ヘルパーをセットアップします。新しい Interswitch 統合の開始、API キーの構成、再利用可能なフェッチ ラッパーの作成、または Interswitch 機能の基盤のセットアップを行う場合は、必ずこのスキルを使用してください。 CLIENT_ID、SECRET_KEY、認証失敗の欠落に関連するエラーが表示された場合、または Interswitch のベース URL、パスポート OAuth フロー、応答形式、通貨、または環境切り替え (テスト/ライブ) を理解する必要がある場合にも使用します。
