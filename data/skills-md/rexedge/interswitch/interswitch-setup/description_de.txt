Richten Sie den Interswitch-API-Client, Umgebungsvariablen, OAuth 2.0-Authentifizierung und TypeScript-Helfer für die serverseitige Zahlungsintegration ein. Verwenden Sie diese Fertigkeit immer dann, wenn Sie eine neue Interswitch-Integration starten, API-Schlüssel konfigurieren, einen wiederverwendbaren Abruf-Wrapper erstellen oder die Grundlage für eine beliebige Interswitch-Funktion einrichten. Verwenden Sie es auch, wenn Sie Fehler im Zusammenhang mit fehlender CLIENT_ID, SECRET_KEY oder Authentifizierungsfehlern sehen oder die Basis-URLs von Interswitch, den Passport-OAuth-Ablauf, das Antwortformat, die Währungen oder den Umgebungswechsel (Test/Live) verstehen müssen.
