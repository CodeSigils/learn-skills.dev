قم بإعداد عميل Interswitch API ومتغيرات البيئة ومصادقة OAuth 2.0 ومساعدي TypeScript لتكامل الدفع من جانب الخادم. استخدم هذه المهارة عند بدء تكامل Interswitch جديد، أو تكوين مفاتيح API، أو إنشاء غلاف جلب قابل لإعادة الاستخدام، أو إعداد الأساس لأي ميزة Interswitch. استخدمه أيضًا عندما ترى أخطاء تتعلق بفقدان CLIENT_ID، أو SECRET_KEY، أو فشل المصادقة، أو تحتاج إلى فهم عناوين URL الأساسية لـ Interswitch، أو تدفق OAuth لجواز السفر، أو تنسيق الاستجابة، أو العملات، أو تبديل البيئة (اختبار/مباشر).
