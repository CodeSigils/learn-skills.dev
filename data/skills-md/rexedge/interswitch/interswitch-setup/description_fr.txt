Configurez le client API Interswitch, les variables d'environnement, l'authentification OAuth 2.0 et les assistants TypeScript pour l'intégration des paiements côté serveur. Utilisez cette compétence chaque fois que vous démarrez une nouvelle intégration Interswitch, configurez des clés API, créez un wrapper de récupération réutilisable ou configurez les bases de toute fonctionnalité Interswitch. À utiliser également lorsque vous voyez des erreurs liées à l'absence de CLIENT_ID, SECRET_KEY, aux échecs d'authentification ou si vous avez besoin de comprendre les URL de base d'Interswitch, le flux OAuth du passeport, le format de réponse, les devises ou le changement d'environnement (test/live).
