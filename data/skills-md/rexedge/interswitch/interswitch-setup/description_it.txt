Configura il client API Interswitch, le variabili di ambiente, l'autenticazione OAuth 2.0 e gli helper TypeScript per l'integrazione dei pagamenti lato server. Utilizza questa competenza ogni volta che si avvia una nuova integrazione Interswitch, si configurano chiavi API, si crea un wrapper di recupero riutilizzabile o si impostano le basi per qualsiasi funzionalità Interswitch. Da utilizzare anche quando vengono visualizzati errori relativi a CLIENT_ID, SECRET_KEY mancanti, errori di autenticazione o è necessario comprendere gli URL di base di Interswitch, il flusso OAuth del passaporto, il formato di risposta, le valute o il cambio di ambiente (test/live).
