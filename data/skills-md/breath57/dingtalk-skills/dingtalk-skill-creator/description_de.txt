Erstellen Sie einen neuen DingTalk-Skill. Immer wenn der Benutzer „Neuen Skill erstellen“, „Neuer Skill“, „DingTalk-Skill entwickeln“, „DingTalk-Funktion hinzufügen“, „DingTalk-Schnittstellenunterstützung hinzufügen“, „Ich benötige einen DingTalk xxx-Skill“, „DingTalk todo“, „DingTalk-Check-in“, „DingTalk-Anwesenheit“, „DingTalk-Genehmigung“, „DingTalk-Zeitplan“ usw. erwähnt und beabsichtigt, eine DingTalk-API-Domäne in einen wiederverwendbaren Skill einzubinden, muss dieser Skill verwendet werden. Es umfasst den vollständigen Erstellungsablauf: SDK-Erkundung → SDK-Python-Test → reiner HTTP-Python-Test (beide müssen bestanden werden) → SKILL.md schreiben. Erstellen Sie den Skill erst, wenn alle Tests bestanden sind.
