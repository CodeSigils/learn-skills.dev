Créez une nouvelle compétence DingTalk (compétence dingtalk). Chaque fois que l'utilisateur mentionne des expressions telles que « créer une nouvelle compétence », « nouvelle compétence », « développer une compétence DingTalk », « ajouter une fonctionnalité DingTalk », « ajouter la prise en charge de l'interface DingTalk », « J'ai besoin d'une compétence DingTalk xxx », « DingTalk todo », « Enregistrement DingTalk », « Présence DingTalk », « Approbation DingTalk », « Calendrier DingTalk », etc., indiquant l'intention d'encapsuler un Domaine API DingTalk en une compétence réutilisable, cette compétence doit être utilisée. Cette compétence comprend le flux de travail complet de création de compétences : exploration du SDK → tests SDK Python → tests HTTP Python purs (les deux étapes doivent réussir) → écriture SKILL.md. Une compétence ne peut être créée que si tous les tests sont réussis.
