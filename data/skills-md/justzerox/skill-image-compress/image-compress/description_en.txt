Cross-platform image compression tool offering high-efficiency compression (60–80% size reduction) via sharp. Handles single/batch compression, format conversion (JPG/PNG/WebP/AVIF/HEIC), quality adjustment, and resizing. Use when you need to shrink images, change formats, reduce dimensions, batch-process, or optimize for WeChat/email/web uploads. Trigger words: “compress”, “shrink”, “convert format”, “convert to JPG/WebP”, “image too large”, “batch images”. Does not handle: rotation, cropping, watermarking, EXIF editing; file management (delete, rename, move); content analysis (image analysis, metadata reading).
