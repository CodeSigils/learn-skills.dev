Verwenden Sie diesen Skill, wenn Sie aufgefordert werden, eine vorhandene Web-App so anzupassen, dass sie als World App-Mini-App funktioniert, oder Code zwischen einer Web-App und einer Mini-App auszutauschen. Dieser Skill umfasst die technischen Schritte der Migration, häufige Probleme und Tipps zur Fehlerbehebung. Es werden einige Änderungen an Verträgen und Frontend-Code erforderlich sein, aber die Gesamtarchitektur und das Benutzererlebnis können weitgehend unverändert bleiben.
