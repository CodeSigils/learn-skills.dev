Utilice esta habilidad cuando se le solicite adaptar una aplicación web existente para que funcione como una miniaplicación World App o compartir código entre una aplicación web y una miniaplicación. Esta habilidad cubre los pasos técnicos de la migración, problemas comunes y consejos de depuración. Se requerirán algunos cambios en los contratos y el código de interfaz, pero la arquitectura general y la experiencia del usuario pueden permanecer prácticamente sin cambios.
