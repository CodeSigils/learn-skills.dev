Utilisez cette compétence lorsqu'il vous est demandé d'adapter une application Web existante pour qu'elle fonctionne comme une mini-application World App ou de partager du code entre une application Web et une mini-application. Cette compétence couvre les étapes techniques de la migration, les problèmes courants et les conseils de débogage. Certaines modifications seront nécessaires aux contrats et au code frontal, mais l'architecture globale et l'expérience utilisateur peuvent rester en grande partie inchangées.
