Клиент CLI для API видеоповторения Narrator AI. Создавайте видео, озвученные искусственным интеллектом: популярное обучение, создание текстов, клип-данные, создание видео, волшебное видео. Поддерживает режимы «Горячая драма», «Оригинальный микс» и «Новая драма». 93 готовых фильма, 146 фоновых дорожек, 63 голоса дубляжа, более 90 шаблонов повествования. Поддерживает загрузку локальных файлов или передачу по ссылкам HTTP/Baidu/PikPak. Используйте, когда пользователю необходимо создавать видеоролики с повествованием с использованием искусственного интеллекта, управлять задачами повествования, просматривать дубляж, фоновую музыку или материальные ресурсы или автоматизировать производство видео с помощью Narrator-ai-cli.
