نقطة الدخول الأولية للاستحواذ والتهيئة لـ SpacemiT Robot SDK؛ يُستخدم لإعداد SDK على اللوحة للاستخدام المحلي/البعيد، أو فقط لإعداد SDK المحلي للكمبيوتر الشخصي في الوضع المختلط. إنه يتعامل مع تبعيات قاعدة الريبو ومساحة العمل وrepo init/sync والتحقق من SROBOTIS_ROOT، ولكنه لا يتولى البناء أو الاختبار الروتيني.
