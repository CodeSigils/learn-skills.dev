لتصحيح أخطاء نقاط التوقف لخادم Node.js stdio MCP في VS Code (إرفاقه بـ Node Inspector). عندما يذكر المستخدم: MCP stdio، @modelcontextprotocol/inspector، العقدة --inspect/--inspect-brk، تصحيح أخطاء إرفاق VS Code، عدم ضرب نقطة التوقف، خريطة المصدر، بناء/عناصر التوزيع، تعارض port9229/مشغول، تكوين Launch.json، وما إلى ذلك، يجب استخدام هذه المهارة. يجب أن توفر المخرجات مباشرة مقتطف Launch.json قابل للنسخ واللصق، وأمر بدء تشغيل مفتش قابل للتشغيل (بما في ذلك إصدار بمنفذ بديل)، وقائمة مرجعية ذات أولوية لاستكشاف الأخطاء وإصلاحها.
