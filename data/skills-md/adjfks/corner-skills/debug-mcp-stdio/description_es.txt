Para la depuración de puntos de interrupción del servidor MCP stdio de Node.js en VS Code (adjuntar al Node Inspector). Siempre que el usuario mencione: MCP stdio, @modelcontextprotocol/inspector, node--inspect/--inspect-brk, depuración de conexión de VS Code, punto de interrupción no alcanzado, mapa fuente, creación de artefactos de compilación/dist, conflicto/ocupado del puerto 9229, configuración de launch.json, etc., se debe utilizar esta habilidad. El resultado debe proporcionar directamente un fragmento de launch.json que se pueda copiar y pegar, un comando de inicio del inspector ejecutable (incluida una versión con un puerto alternativo) y una lista de verificación de solución de problemas priorizada.
