Se utiliza para la depuración de puntos de interrupción del **Node.js stdio MCP Server** en VS Code (adjuntar al Node Inspector). Siempre que el usuario mencione: MCP stdio, @modelcontextprotocol/inspector, nodo --inspect/--inspect-brk, depuración de adjuntos de VS Code, puntos de interrupción no alcanzados, mapa fuente, depuración de artefactos de compilación/dist, conflicto/ocupado del puerto 9229, configuración de launch.json, etc., se debe utilizar esta habilidad. El resultado debe proporcionar directamente un fragmento de launch.json listo para copiar y pegar, comandos de inicio del inspector ejecutables (incluidas las versiones con cambios de puerto) y una lista de verificación de solución de problemas ordenada por prioridad.
