Wird für das Breakpoint-Debugging des **Node.js stdio MCP-Servers** in VS Code verwendet (an Node Inspector anhängen). Immer wenn der Benutzer Folgendes erwähnt: MCP stdio, @modelcontextprotocol/inspector, node --inspect/--inspect-brk, VS-Code-Attach-Debugging, Haltepunkte nicht erreicht, Sourcemap, Debuggen von Build-/Dist-Artefakten, Port 9229-Konflikt/belegt, launch.json-Konfiguration usw., muss diese Fähigkeit verwendet werden. Die Ausgabe sollte direkt ein zum Kopieren und Einfügen bereites launch.json-Snippet, ausführbare Inspektor-Startbefehle (einschließlich Port-geänderter Versionen) und eine nach Priorität geordnete Checkliste zur Fehlerbehebung bereitstellen.
