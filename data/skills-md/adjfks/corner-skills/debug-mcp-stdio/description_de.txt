Für das Breakpoint-Debugging des Node.js stdio MCP-Servers in VS Code (an Node Inspector anhängen). Immer wenn der Benutzer Folgendes erwähnt: MCP stdio, @modelcontextprotocol/inspector, node--inspect/--inspect-brk, VS-Code-Attach-Debugging, Haltepunkt nicht erreicht, Sourcemap, Build-/Dist-Artefakte beim Erstellen, Port9229-Konflikt/besetzt, launch.json-Konfiguration usw., sollte dieser Skill verwendet werden. Die Ausgabe sollte direkt ein kopier- und einfügbares launch.json-Snippet, einen ausführbaren Inspektor-Startbefehl (einschließlich einer Version mit einem alternativen Port) und eine priorisierte Checkliste zur Fehlerbehebung bereitstellen.
