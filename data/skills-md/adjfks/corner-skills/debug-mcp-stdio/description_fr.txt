Pour le débogage du point d'arrêt du serveur MCP stdio Node.js dans VS Code (attacher à Node Inspector). Chaque fois que l'utilisateur mentionne : MCP stdio, @modelcontextprotocol/inspector, node--inspect/--inspect-brk, débogage de VS Code attach, point d'arrêt non atteint, sourcemap, construction d'artefacts de build/dist, port9229 conflit/occupé, configuration launch.json, etc., cette compétence doit être utilisée. Le résultat doit fournir directement un extrait de launch.json pouvant être copié, une commande de démarrage de l'inspecteur exécutable (y compris une version avec un port alternatif) et une liste de contrôle de dépannage hiérarchisée.
