Per il debug dei punti di interruzione del server MCP stdio Node.js in VS Code (collegalo a Node Inspector). Ogni volta che l'utente menziona: MCP stdio, @modelcontextprotocol/inspector, node--inspect/--inspect-brk, debugging di collegamento VS Code, breakpoint not hit, sourcemap, creazione di artefatti build/dist, conflitto/occupata porta9229, configurazione launch.json e così via, è necessario utilizzare questa abilità. L'output dovrebbe fornire direttamente uno snippet launch.json copiabile e incollabile, un comando di avvio dell'ispettore eseguibile (inclusa una versione con una porta alternativa) e un elenco di controllo per la risoluzione dei problemi con priorità.
