Utilizzato per il debug dei punti di interruzione del **server MCP stdio Node.js** in VS Code (collegato a Node Inspector). Ogni volta che l'utente menziona: MCP stdio, @modelcontextprotocol/inspector, nodo --inspect/--inspect-brk, debug di collegamento VS Code, punti di interruzione non raggiunti, mappa sorgente, debug di artefatti build/dist, conflitto/occupazione porta 9229, configurazione launch.json e così via, è necessario utilizzare questa abilità. L'output dovrebbe fornire direttamente uno snippet launch.json pronto per il copia e incolla, comandi di avvio dell'ispettore eseguibili (incluse le versioni con porta modificata) e un elenco di controllo per la risoluzione dei problemi in ordine di priorità.
