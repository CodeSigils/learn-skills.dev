Для отладки точки останова сервера MCP Node.js stdio в VS Code (прикрепите к Node Inspector). Всякий раз, когда пользователь упоминает: MCP stdio, @modelcontextprotocol/inspector, node--inspect/--inspect-brk, отладку присоединения VS Code, не достигнутую точку останова, исходную карту, создание артефактов сборки/распространения, конфликт/занятость порта 9229, конфигурацию launch.json и т. д., следует использовать этот навык. Выходные данные должны содержать фрагмент файла launch.json, который можно скопировать и вставить, работоспособную команду запуска инспектора (включая версию с альтернативным портом) и контрольный список приоритетного устранения неполадок.
