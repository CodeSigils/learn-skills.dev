معيار مكافحة متراصة لمشاريع React/Next.js. يفرض بنية المكونات المعيارية، وحدود حجم الملف، والمكونات ذات المسؤولية الفردية، واستخراج الخطاف المخصص، وفصل طبقة البيانات، وتصدير البراميل، وقواعد تبعية الطبقة الصارمة. قم بالتنشيط عندما يقوم المستخدم بإنشاء مكونات React، أو إنشاء صفحات Next.js، أو إعادة هيكلة الملفات الكبيرة، أو إعداد مكتبة مكونات، أو كتابة ملفات page.tsx أو Layout.tsx، أو ذكر "monolith" أو "طويل جدًا" أو "refactor" أو "مكتبة المكونات" أو "نظام التصميم" أو "modular" أو "split" أو "استخراج مكون" أو "ملف كبير جدًا" أو "عدد كبير جدًا من useState" أو أي موقف يتزايد فيه ملف React/Next.js. يتجاوز الحجم الذي يمكن التحكم فيه. استخدم أيضًا بشكل استباقي عند بناء مشاريع جديدة للتأكد من أن البنية معيارية منذ البداية.
