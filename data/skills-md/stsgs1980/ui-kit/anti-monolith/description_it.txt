Standard anti-monolito per progetti React/Next.js. Applica l'architettura dei componenti modulari, i limiti di dimensione dei file, i componenti a responsabilità singola, l'estrazione di hook personalizzati, la separazione dei livelli di dati, le esportazioni di barili e regole rigide di dipendenza dei livelli. Attivalo ogni volta che l'utente sta creando componenti React, costruendo pagine Next.js, refactoring file di grandi dimensioni, impostando una libreria di componenti, scrivendo file page.tsx o layout.tsx o menziona "monolito", "troppo lungo", "refactor", "libreria di componenti", "sistema di progettazione", "modulare", "diviso", "estrai componente", "file troppo grande", "troppi useState" o qualsiasi situazione in cui un file React/Next.js sta crescendo oltre le dimensioni gestibili. Utilizzalo anche in modo proattivo durante la realizzazione di nuovi progetti per garantire che l'architettura sia modulare fin dall'inizio.
