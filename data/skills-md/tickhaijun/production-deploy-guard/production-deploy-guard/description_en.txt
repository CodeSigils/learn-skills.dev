Plan approval-gated production deployments for a single Linux server using Docker Compose and Nginx. Use when defining a deployment contract, choosing between private-Git source builds and CI-built image pulls, generating a read-only server audit, sanitizing and analyzing audit or execution logs, producing bootstrap/Nginx/deploy/verify/rollback bundles, validating shell safety and artifact integrity, or diagnosing deployment failures. Never use it to SSH into a server or automatically execute production writes.
