Pianifica distribuzioni di produzione soggette ad approvazione per un singolo server Linux utilizzando Docker Compose e Nginx. Da utilizzare quando si definisce un contratto di distribuzione, scegliendo tra build di origine Git privata e pull di immagini create da CI, generando un audit del server di sola lettura, disinfettando e analizzando i log di controllo o di esecuzione, producendo bundle bootstrap/Nginx/deploy/verify/rollback, convalidando la sicurezza della shell e l'integrità degli artefatti o diagnosticando errori di distribuzione. Non utilizzarlo mai per SSH in un server o per eseguire automaticamente scritture di produzione.
