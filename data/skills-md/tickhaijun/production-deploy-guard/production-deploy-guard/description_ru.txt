Планируйте производственные развертывания с одобрением для одного сервера Linux с помощью Docker Compose и Nginx. Используйте при определении контракта на развертывание, выборе между сборками исходного кода частного Git и получением образов, созданных CI, создании аудита сервера только для чтения, очистке и анализе журналов аудита или выполнения, создании пакетов начальной загрузки/Nginx/развертывания/проверки/отката, проверке безопасности оболочки и целостности артефактов или диагностике сбоев развертывания. Никогда не используйте его для подключения к серверу по SSH или автоматического выполнения производственных операций записи.
