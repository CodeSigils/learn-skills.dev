خطط لعمليات نشر الإنتاج الخاضعة للموافقة لخادم Linux واحد باستخدام Docker Compose وNginx. يُستخدم عند تحديد عقد نشر، والاختيار بين إنشاءات مصدر Git الخاص وعمليات سحب الصور المبنية على CI، وإنشاء تدقيق خادم للقراءة فقط، وتعقيم وتحليل سجلات التدقيق أو التنفيذ، وإنتاج حزم bootstrap/Nginx/deploy/verify/rollback، والتحقق من سلامة الصدفة وسلامة العناصر، أو تشخيص فشل النشر. لا تستخدمه أبدًا لـ SSH في الخادم أو تنفيذ عمليات الكتابة الإنتاجية تلقائيًا.
