Используйте, когда пользователь хочет превратить текстовый контент в набор безупречных визуальных ИЗОБРАЖЕНИЙ, которыми можно поделиться — карточки знаний, карточки с цитатами, карточки-карусели, карточки-постеры — визуализированные как HTML/CSS и экспортированные через Playwright с соотношением, например, 1:1 / 3:4 / 9:16. Триггеры: карта / 卡片 / 知识卡 / 文字卡片 / 金句卡 / 图文卡片 / 卡片生成 / сделать карты. Для статьи → вертикальной карточки ВИДЕО используйте voxflow:slice; для коротких видеороликов/клипов AI используйте voxflow:video; для подкастов используйте voxflow:podcast.
