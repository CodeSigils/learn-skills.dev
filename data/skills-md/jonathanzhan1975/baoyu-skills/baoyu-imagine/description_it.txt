Generazione di immagini AI con OpenAI, Azure OpenAI, Google, OpenRouter, DashScope, MiniMax, Jimeng, Seedream e API Replicate. Supporta la conversione da testo a immagine, immagini di riferimento, proporzioni e generazione batch da file di prompt salvati. Sequenziale per impostazione predefinita; utilizzare la generazione parallela batch quando l'utente dispone già di più richieste o desidera un throughput multi-immagine stabile. Da utilizzare quando l'utente chiede di generare, creare o disegnare immagini.
