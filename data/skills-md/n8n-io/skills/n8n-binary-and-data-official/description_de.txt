Wird verwendet, wenn Dateien, Bilder, Anhänge oder Binärdaten in n8n verarbeitet werden ODER wenn ein KI-Agent eine vom Benutzer hochgeladene Datei als Werkzeugeingabe verwenden oder eine generierte Datei zurückgeben muss. Informationen zu Datentabellen (Schemas, Deduplizierung, persistenter Status) finden Sie im separaten Skill „n8n-data-tables-official“. Triggert auf „Datei“, „Bild“, „PDF“, „Anhang“, „Binär“, „Upload“, „Download“, Chat-Trigger mit Dateien, Agent-Tool, das eine Datei benötigt, Vision/Multimodal oder jegliche Verarbeitung von Nicht-JSON-Dateidaten.
