À utiliser lors de la gestion de fichiers, d'images, de pièces jointes ou de données binaires dans n8n, OU lorsqu'un agent IA doit prendre un fichier téléchargé par l'utilisateur comme entrée d'outil ou renvoyer un fichier généré. Pour les tables de données (schémas, déduplication, état persistant), consultez la compétence distincte n8n-data-tables-official. Déclencheurs sur "fichier", "image", "PDF", "pièce jointe", "binaire", "télécharger", "télécharger", déclencheur de chat avec des fichiers, outil d'agent nécessitant un fichier, vision/multimodal ou toute gestion de données de fichier non JSON.
