Verwenden Sie diese Option, wenn Sie mit Daten mit mehreren Elementen, Batches, paginierten APIs, ratenbegrenzten APIs oder allem arbeiten, was „dies für jedes einzelne tun“ muss, oder immer dann, wenn der Benutzer Schleife, Iteration, Batchverarbeitung, Paging oder „Schleife über Elemente“ erwähnt. Löst auf „Schleife“, „Iterieren“, „Für jeden“, „Batch“, „Durchblättern“, „Paginieren“, „Ratenbegrenzung“, „Alle verarbeiten“ oder auf jedem Knoten aus, der einmal oder einmal pro Element ausgeführt werden soll.
