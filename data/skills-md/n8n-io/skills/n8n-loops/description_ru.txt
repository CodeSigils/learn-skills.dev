Используйте при работе с данными, состоящими из нескольких элементов, пакетами, API-интерфейсами с разбивкой на страницы, API-интерфейсами с ограниченной скоростью, всем, что нужно «сделать это для каждого», или в любое время, когда пользователь упоминает цикл, итерацию, пакетную обработку, разбиение по страницам или «цикл по элементам». Запускается по «циклу», «итерации», «для каждого», «пакету», «постраничному просмотру», «разбивке на страницы», «ограничению скорости», «обработке всех» или любому узлу, который должен запускаться один раз, а не один раз для каждого элемента.
