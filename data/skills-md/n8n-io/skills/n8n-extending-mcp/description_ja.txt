コーディング エージェントが呼び出せるツールとして n8n ワークフローを公開する場合に使用します。 2つのケース。 (1) MCP がネイティブに公開していない n8n API 機能をラップします: フォルダー CRUD、タグ CRUD、インスタンス メタデータ、認証情報の作成。 (2) 汎用ワークフローをエージェント ツールとして公開します。これは、サードパーティ API を呼び出したり、ビジネス ロジックを実行したり、エージェントに呼び出してほしいタスクを実行したりするワークフローです。 「MCP ツールとして公開」、「エージェント用のツールの構築」、「X を知る必要があります」（X は MCP ツールではありません）、「フォルダーの作成」、「タグの作成」、または機能のギャップでトリガーされます。
