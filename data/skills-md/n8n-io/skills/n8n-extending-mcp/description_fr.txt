À utiliser lorsque vous souhaitez exposer un flux de travail n8n en tant qu'outil que l'agent de codage peut appeler. Deux cas. (1) Enveloppez les fonctionnalités de l'API n8n que le MCP n'expose pas nativement : dossier CRUD, balise CRUD, métadonnées d'instance, création d'informations d'identification. (2) Exposez un workflow à usage général en tant qu'outil d'agent : un workflow qui appelle une API tierce, exécute une logique métier ou effectue toute tâche que vous souhaitez que l'agent invoque. Déclencheurs sur « exposer en tant qu'outil MCP », « créer un outil pour mon agent », « J'ai besoin de connaître X » où X n'est pas un outil MCP, « créer un dossier », « créer une balise » ou toute lacune de capacité.
