Verwenden Sie diese Option, wenn Sie einen N8N-Workflow als Tool bereitstellen möchten, das der Codierungsagent aufrufen kann. Zwei Fälle. (1) Umschließen Sie n8n-API-Funktionen, die der MCP nicht nativ verfügbar macht: Ordner-CRUD, Tag-CRUD, Instanzmetadaten, Erstellung von Anmeldeinformationen. (2) Stellen Sie einen allgemeinen Workflow als Agententool bereit: einen Workflow, der eine API eines Drittanbieters aufruft, Geschäftslogik ausführt oder eine beliebige Aufgabe ausführt, die der Agent aufrufen soll. Wird ausgelöst durch „Als MCP-Tool bereitstellen“, „ein Tool für meinen Agenten erstellen“, „Ich muss X kennen“, wobei X kein MCP-Tool ist, „Ordner erstellen“, „Tag erstellen“ oder eine Funktionslücke.
