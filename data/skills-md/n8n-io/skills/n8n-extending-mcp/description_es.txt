Úselo cuando desee exponer un flujo de trabajo n8n como una herramienta que el agente de codificación puede utilizar. Dos casos. (1) Envuelva las capacidades de la API n8n que MCP no expone de forma nativa: carpeta CRUD, etiqueta CRUD, metadatos de instancia, creación de credenciales. (2) Exponer un flujo de trabajo de propósito general como una herramienta de agente: un flujo de trabajo que llama a una API de terceros, ejecuta lógica de negocios o realiza cualquier tarea que desee que invoque el agente. Activadores de "exponer como herramienta MCP", "crear una herramienta para mi agente", "Necesito saber X" donde X no es una herramienta MCP, "crear carpeta", "crear etiqueta" o cualquier brecha de capacidad.
