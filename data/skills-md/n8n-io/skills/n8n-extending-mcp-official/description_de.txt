Verwenden Sie diese Option, wenn Sie einen n8n-Workflow als Tool bereitstellen möchten, das der Codierungsagent aufrufen kann. Zwei Fälle. (1) Umschließen Sie n8n-API-Funktionen, die der MCP nicht nativ verfügbar macht: Ordner-CRUD, Tag-Umbenennung/Löschen, Instanzmetadaten, Erstellung von Anmeldeinformationen. (2) Stellen Sie einen allgemeinen Workflow als Agententool bereit: einen Workflow, der eine API eines Drittanbieters aufruft, Geschäftslogik ausführt oder eine beliebige Aufgabe ausführt, die der Agent aufrufen soll. Wird ausgelöst bei „Als MCP-Tool verfügbar machen“, „ein Tool für meinen Agenten erstellen“, „Ich muss X kennen“, wobei X kein MCP-Tool ist, „Ordner erstellen“, „Tag umbenennen“ oder bei einer Funktionslücke.
