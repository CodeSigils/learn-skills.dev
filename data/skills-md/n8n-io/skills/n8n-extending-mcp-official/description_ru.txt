Используйте, если вы хотите представить рабочий процесс n8n как инструмент, который может вызывать агент кодирования. Два случая. (1) Возможности Wrap n8n API, которые MCP изначально не предоставляет: папка CRUD, переименование/удаление тега, метаданные экземпляра, создание учетных данных. (2) Предоставьте рабочий процесс общего назначения в качестве инструмента агента: рабочий процесс, который вызывает сторонний API, запускает бизнес-логику или выполняет любую задачу, которую вы хотите, чтобы агент вызывал. Триггеры: «представить как инструмент MCP», «создать инструмент для моего агента», «мне нужно знать X», где X не является инструментом MCP, «создать папку», «переименовать тег» или любой пробел в возможностях.
