Verwenden Sie diese Option, wenn Sie mit Multi-Item-Daten, Batches, paginierten APIs, ratenbegrenzten APIs, Fan-out über mehrere Branches hinweg arbeiten, alles, was „dies für jeden tun“ muss, oder immer dann, wenn der Benutzer Schleife, Iteration, Batchverarbeitung, Paging, Parallelität oder „Schleife über Elemente“ erwähnt. Löst auf „Schleife“, „Iterieren“, „für jeden“, „Batch“, „Durchblättern“, „Paginieren“, „Ratenbegrenzung“, „Alles verarbeiten“, „Fan-Out“, „Parallelzweige“, „Parallelität“ oder jeden Knoten aus, der einmal oder einmal pro Element ausgeführt werden soll.
