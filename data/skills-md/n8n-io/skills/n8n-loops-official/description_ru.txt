Используйте при работе с данными из нескольких элементов, пакетами, API-интерфейсами с разбивкой на страницы, API-интерфейсами с ограниченной скоростью, разветвлением по нескольким ветвям, всем, что нужно «сделать это для каждой», или в любое время, когда пользователь упоминает цикл, итерацию, пакетную обработку, разбиение на страницы, параллелизм или «цикл по элементам». Триггеры по «циклу», «итерации», «для каждого», «пакету», «постраничному просмотру», «разбивке на страницы», «ограничению скорости», «обработке всех», «разветвлению», «параллельным ветвям», «параллелизму» или любому узлу, который должен запускаться один раз, а не один раз для каждого элемента.
