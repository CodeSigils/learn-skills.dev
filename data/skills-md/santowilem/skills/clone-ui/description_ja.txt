利用可能なソース (スクリーンショットのみ、ライブ URL、生の HTML/CSS、または任意の組み合わせ) を使用して、Web UI のピクセルに忠実なクローンをユーザーの既存のスタックに作成します。ユーザーがスクリーンショット、画像、URL、Figma エクスポート、または HTML ダンプからデザインを再作成、一致、複製、または「クローン」したい場合は常に、このスキルを使用します。 「これを複製する」、「このデザインに一致させる」、「スクリーンショットからこれを構築する」、「このページを再作成する」、「このように見えるようにする」、「この UI を再構築する」、「このレイアウトをコピーする」などのフレーズ、またはユーザーが視覚的な参照を提供し、忠実な実装を要求したときにトリガーされます。アンダートリガーしないでください。ユーザーが明示的な表現なしでスクリーンショットをドロップしただけの場合でも、このスキルは適用されます。
