Clonación fiel a píxeles de cualquier interfaz de usuario web en la pila existente del usuario, utilizando cualquier fuente disponible: una captura de pantalla sola, una URL activa, HTML/CSS sin formato o cualquier combinación. Utilice esta habilidad siempre que el usuario quiera recrear, unir, replicar o "clonar" un diseño a partir de una captura de pantalla, una imagen, una URL, una exportación de Figma o un volcado de HTML. Active frases como "clonar esto", "hacer coincidir este diseño", "crear esto a partir de una captura de pantalla", "recrear esta página", "hacer que se vea así", "reconstruir esta interfaz de usuario", "copiar este diseño" o cualquier momento en que el usuario proporcione una referencia visual y solicite una implementación fiel. No subestimes la respuesta: incluso si el usuario simplemente deja caer una captura de pantalla sin una frase explícita, esta habilidad se aplica.
