استنساخ دقيق لأي واجهة مستخدم ويب في المجموعة الحالية للمستخدم، باستخدام أي مصادر متاحة - لقطة شاشة وحدها، أو عنوان URL مباشر، أو HTML/CSS أولي، أو أي مجموعة. استخدم هذه المهارة عندما يريد المستخدم إعادة إنشاء تصميم أو مطابقته أو تكراره أو "استنساخه" من لقطة شاشة أو صورة أو عنوان URL أو تصدير Figma أو تفريغ HTML. قم بتشغيل عبارات مثل "استنساخ هذا"، أو "مطابقة هذا التصميم"، أو "إنشاء هذا من لقطة الشاشة"، أو "إعادة إنشاء هذه الصفحة"، أو "اجعلها تبدو بهذا الشكل"، أو "إعادة إنشاء واجهة المستخدم هذه"، أو "نسخ هذا التخطيط"، أو في أي وقت يقدم المستخدم مرجعًا مرئيًا ويطلب التنفيذ الدقيق. لا تضغط على الزر - حتى لو قام المستخدم بإسقاط لقطة شاشة دون صياغة واضحة، فسيتم تطبيق هذه المهارة.
