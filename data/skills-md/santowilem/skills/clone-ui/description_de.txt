Pixelgetreues Klonen einer beliebigen Web-Benutzeroberfläche in den vorhandenen Stack des Benutzers unter Verwendung aller verfügbaren Quellen – ein Screenshot allein, eine Live-URL, rohes HTML/CSS oder eine beliebige Kombination. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein Design aus einem Screenshot, einem Bild, einer URL, einem Figma-Export oder einem HTML-Dump neu erstellen, abgleichen, replizieren oder „klonen“ möchte. Lösen Sie bei Phrasen wie „dieses klonen“, „diesem Design anpassen“, „dieses aus Screenshot erstellen“, „diese Seite neu erstellen“, „so aussehen lassen“, „diese Benutzeroberfläche neu erstellen“, „dieses Layout kopieren“ aus oder jedes Mal, wenn der Benutzer eine visuelle Referenz bereitstellt und nach einer originalgetreuen Implementierung fragt. Nicht untertriggern – selbst wenn der Benutzer nur einen Screenshot ohne explizite Formulierung ablegt, gilt diese Fähigkeit.
