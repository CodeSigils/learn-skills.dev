Используйте, когда экран, страница, колода, документ, файл README или компонент требуют визуальных символов — значков, глифов, маркеров состояния, индикаторов шагов, рисунков заголовков разделов, маркеров списка функций или чего-либо, заменяющего смайлики/текст-заполнитель настоящей графикой. Охватывает один или сорок значков размером 16 или 128 пикселей. Получает настоящие значки из Icons8 через MCP и сохраняет проект в одном связном семействе: один пакет, заблокированный для всего проекта, простые метафоры вместо логотипов брендов или буквальных механизмов, бесплатные URL-адреса PNG для предварительного просмотра и прототипирования, SVG только для утвержденного окончательного набора. Используйте его при создании или заполнении пользовательского интерфейса (навигация, панели инструментов, карточки, таблицы, контрольные списки, пустые состояния), при визуальном чтении текстовых строк или слайдов, при замене эмодзи на значки, при проверке значков, уже находящихся в файле, на предмет согласованности или когда упоминается Icons8. Не для дизайна логотипа, иллюстраций, ошибок CSS/рендеринга, маркировки доступности или вопросов по счетам.
