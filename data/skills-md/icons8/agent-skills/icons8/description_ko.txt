화면, 페이지, 데크, 문서, README 또는 구성 요소에 시각적 기호(아이콘, 문자 모양, 상태 표시, 단계 표시기, 섹션 헤더 아트, 기능 목록 글머리 기호 또는 이모티콘/자리 표시자 텍스트를 실제 그래픽으로 대체하는 모든 것)가 필요할 때 사용합니다. 16px 또는 128px에서 하나 또는 40개의 아이콘을 다룹니다. MCP를 통해 Icons8에서 실제 아이콘을 가져오고 일관된 단일 제품군에 프로젝트를 유지합니다. 전체 프로젝트에 대해 하나의 팩이 잠겨 있고, 브랜드 로고나 문자 기계 대신 일반 은유가 있으며, 미리보기 및 프로토타입 제작을 위한 무료 PNG URL, 승인된 최종 세트에만 SVG가 있습니다. UI(탐색, 도구 모음, 카드, 테이블, 체크리스트, 빈 상태)를 작성하거나 채울 때, 텍스트 전용 행이나 슬라이드를 시각적으로 읽을 때, 이모티콘을 아이콘으로 바꿀 때, 일관성을 위해 파일에 이미 있는 아이콘을 감사할 때, Icons8이 언급될 때 사용하세요. 로고 디자인, 일러스트레이션, CSS/렌더링 버그, 접근성 라벨링 또는 청구 관련 질문에는 해당되지 않습니다.
