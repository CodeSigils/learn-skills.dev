Verwenden, wenn ein Bildschirm, eine Seite, ein Deck, ein Dokument, ein README oder eine Komponente visuelle Symbole benötigt — Icons, Glyphen, Statusmarker, Schrittanzeiger, Abschnitt‑Header‑Grafiken, Aufzählungs‑Bullets für Feature‑Listen oder alles, was Emoji/Platzhalter‑Text durch echte Grafiken ersetzt. Deckt ein Icon oder vierzig ab, bei 16 px oder 128 px. Holt echte Icons von Icons8 über MCP und hält ein Projekt in einer einheitlichen Familie: ein Pack, das für das gesamte Projekt gesperrt ist, einfache Metaphern statt Markenlogos oder wörtlicher Maschinendarstellungen, freie PNG‑URLs zum Vorschauen und Prototyping, SVG nur für den freigegebenen Final‑Satz. Verwenden, wenn UI‑Elemente (Navigation, Werkzeugleisten, Karten, Tabellen, Checklisten, leere Zustände) gebaut oder gefüllt werden, wenn rein textbasierte Zeilen oder Folien visuell lesbar gemacht werden, wenn Emoji durch Icons ersetzt werden, wenn bereits vorhandene Icons in einer Datei auf Konsistenz geprüft werden oder wenn Icons8 erwähnt wird. Nicht für Logodesign, Illustration, CSS/Render‑Fehler, Barrierefreiheits‑Labels oder Abrechnungs‑Fragen.
