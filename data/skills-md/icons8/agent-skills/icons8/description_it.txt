Usa quando uno schermo, una pagina, un deck, un documento, un README o un componente necessita di simboli visivi — icone, glifi, marcatori di stato, indicatori di passaggi, arte per intestazioni di sezione, punti per elenchi di funzionalità, o qualsiasi cosa che sostituisca emoji/testo segnaposto con grafiche reali. Copre un’icona o quaranta, a 16 px o 128 px. Recupera icone reali da Icons8 tramite MCP e mantiene il progetto su un’unica famiglia coerente: un pack bloccato per l’intero progetto, metafore semplici invece di loghi di marca o macchinari letterali, URL PNG gratuiti per l’anteprima e il prototipo, SVG solo per il set finale approvato. Usalo quando costruisci o riempi l’interfaccia (navigazione, barre degli strumenti, card, tabelle, checklist, stati vuoti), quando rendi visivamente leggibili righe o slide solo testuali, quando sostituisci emoji con icone, quando verifichi la coerenza delle icone già presenti in un file, o quando viene citato Icons8. Non è per la creazione di loghi, illustrazioni, bug CSS/rendering, etichettatura di accessibilità o domande di fatturazione.
