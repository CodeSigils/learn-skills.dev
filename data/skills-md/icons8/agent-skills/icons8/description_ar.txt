يُستخدم عندما تحتاج شاشة أو صفحة أو مجموعة أدوات أو مستند أو ملف README أو مكون إلى رموز مرئية - أيقونات أو صور رمزية أو علامات الحالة أو مؤشرات الخطوات أو رسم رأس القسم أو الرموز النقطية لقائمة الميزات أو أي شيء يستبدل نص الرموز التعبيرية/العنصر النائب برسومات حقيقية. يغطي أيقونة واحدة أو أربعين، بحجم 16 بكسل أو 128 بكسل. يجلب أيقونات حقيقية من Icons8 عبر MCP ويحتفظ بالمشروع في عائلة واحدة متماسكة: حزمة واحدة مقفلة للمشروع بأكمله، واستعارات بسيطة بدلاً من شعارات العلامة التجارية أو الآلات الحرفية، وعناوين URL مجانية بتنسيق PNG للمعاينة والنماذج الأولية، وSVG فقط للمجموعة النهائية المعتمدة. استخدمه عند إنشاء واجهة المستخدم أو تعبئتها (التنقل، أشرطة الأدوات، البطاقات، الجداول، قوائم المراجعة، الحالات الفارغة)، عند إنشاء صفوف أو شرائح نصية فقط للقراءة بشكل مرئي، عند تبديل الرموز التعبيرية للأيقونات، عند تدقيق الرموز الموجودة بالفعل في ملف لتحقيق الاتساق، أو عند ذكر Icons8. ليس لتصميم الشعار، أو الرسم التوضيحي، أو أخطاء العرض/CSS، أو وضع علامات إمكانية الوصول، أو أسئلة الفواتير.
