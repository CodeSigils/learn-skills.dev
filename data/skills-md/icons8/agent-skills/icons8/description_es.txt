Úselo cuando una pantalla, página, presentación, documento, README o componente necesite símbolos visuales: íconos, glifos, marcadores de estado, indicadores de pasos, arte de encabezado de sección, viñetas de lista de funciones o cualquier cosa que reemplace emojis o texto de marcador de posición con gráficos reales. Cubre desde un solo ícono hasta cuarenta, a 16 px o 128 px. Obtiene íconos reales de Icons8 a través de MCP y mantiene el proyecto dentro de una única familia coherente: un paquete bloqueado para todo el proyecto, metáforas sencillas en lugar de logotipos de marcas o maquinaria literal, URLs de PNG gratuitos para vista previa y creación de prototipos, SVG únicamente para el conjunto final aprobado. Úselo al construir o completar interfaces de usuario (navegación, barras de herramientas, tarjetas, tablas, listas de verificación, estados vacíos), al hacer que filas o diapositivas de solo texto se comprendan visualmente, al sustituir emojis por íconos, al auditar íconos ya presentes en un archivo para garantizar consistencia o cuando se menciona Icons8. No es para diseño de logotipos, ilustraciones, errores de CSS/renderizado, etiquetado de accesibilidad o preguntas de facturación.
