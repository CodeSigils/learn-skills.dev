當螢幕、頁面、投影片、文件、README 或元件需要視覺符號時使用——圖示、字形、狀態標記、步驟指示、章節標題圖案、功能清單項目符號，或任何以真實圖形取代表情符號/佔位文字的情況。可涵蓋單一圖示或四十個，尺寸為 16px 或 128px。透過 MCP 從 Icons8 取得真實圖示，並將專案維持在同一個一致的系列中：整個專案鎖定同一套圖示包，使用簡潔的隱喻而非品牌標誌或具象機械圖，提供免費 PNG URL 供預覽與原型製作，僅在最終核准的圖示集使用 SVG。適用於構建或填充 UI（導航列、工具列、卡片、表格、檢查清單、空白狀態）、將純文字列或投影片以視覺方式呈現、將表情符號換成圖示、檢查檔案中已有圖示的一致性，或提及 Icons8 的情況。不適用於標誌設計、插圖、CSS/渲染錯誤、可及性標籤或計費問題。
