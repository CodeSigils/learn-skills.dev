Guidez le workflow Git local tout en respectant les limites d'autorisation d'opération du référentiel. Actuellement, il est utilisé pour nommer et créer des branches en fonction des exigences ou des modifications par étapes, rédiger des messages de validation en chinois et valider après confirmation de l'utilisateur ; les futures extensions pourront inclure des directives de fonctionnement Git supplémentaires.
