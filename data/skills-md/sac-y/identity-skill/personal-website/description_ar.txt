قم بإنشاء مواقع ويب شخصية مميزة من خلال عملية مرحلية تعتمد على الصور المرجعية: قفل المحتوى والنمط، وقفل الصور المرجعية، ومراجعة تقسيم الأصول، ومراجعة إنشاء الأصول، ثم النسخ المتماثل عالي الدقة وضمان الجودة. يُستخدم عندما يريد المستخدم استخدام Codex أو Image2 أو الصور المرجعية أو الأصول التي تم إنشاؤها أو سير عمل صورة إلى رمز عالي الجودة لإنشاء أو إعادة تصميم أو تكرار موقع ويب شخصي أو محفظة أو موقع منشئ أو موقع مؤسس أو موقع IP شخصي. إنشاء مواقع ويب شخصية مميزة من خلال سير عمل مرحلي يعتمد على المرجع (قفل المحتوى، وقفل الصورة المرجعية، ومراجعة تقسيم الأصول، ومراجعة إنشاء الأصول، وإعادة البناء المخلص، وضمان الجودة). يُستخدم لإنشاء أو إعادة تصميم أو تكرار موقع ويب شخصي أو محفظة أو منشئ/مؤسس/موقع IP شخصي.
