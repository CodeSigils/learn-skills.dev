Modo de evolución del marco: evoluciona el texto estándar de control de calidad (KATA, accesorios, cli/, scripts/, api/schemas/ pipeline, package.json deps). Plan autónomo → Código → Verificar → Archivar canalización; se ejecuta bajo la instalación `gentle-ai install --preset minimal` (no se requieren habilidades SDD-*). Úselo al agregar nuevas API de dispositivos, refactorizar clases base KATA, evolucionar el instalador, modificar la canalización de sincronización de OpenAPI o cualquier cambio en la infraestructura del marco que NO sea una escritura de prueba por ticket o un control de calidad manual. Activadores en: /framework-development, "evolucionar framework", "refactor de framework", "nueva API de dispositivo", "modificar base KATA", "refactor cli", "evolución repetitiva". NO lo use para: escribir pruebas para un ticket (use /test-automation), control de calidad manual por ticket (use /sprint-testing), documentar casos de prueba (use /test-documentation), ejecutar conjuntos de regresión (use /regression-testing).
