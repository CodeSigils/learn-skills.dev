Режим развития платформы — развивает сам шаблон QA (KATA, фикстуры, cli/, скрипты/, API/схемы/конвейер, package.json deps). Автономный план → Код → Проверка → Архивный конвейер; работает под управлением установки «gentle-ai install --preset минимальный» (навыки работы с SDD-* не требуются). Используйте при добавлении новых API-интерфейсов, рефакторинге базовых классов KATA, развитии установщика, изменении конвейера синхронизации OpenAPI или любых изменениях в инфраструктуре платформы, которые НЕ являются написанием тестов для каждого билета или ручным контролем качества. Запускается по: /framework-development, «развитие инфраструктуры», «рефакторинг платформы», «новый API-интерфейс приспособления», «изменение базы KATA», «рефакторинг cli», «эволюция шаблона». НЕ используйте для: написания тестов для заявки (используйте /test-automation), ручного контроля качества каждой заявки (используйте /sprint-testing), документирования тестовых случаев (используйте /test-documentation), запуска наборов регрессионных тестов (используйте /reгрессионное тестирование).
