フレームワーク進化モード — QA ボイラープレート自体 (KATA、フィクスチャ、cli/、scripts/、api/schemas/ パイプライン、package.json deps) を進化させます。自己完結型の計画 → コード → 検証 → アーカイブ パイプライン。 「gentle-ai install --preset minimum」インストールで実行されます (SDD-* スキルは必要ありません)。新しいフィクスチャ API の追加、KATA 基本クラスのリファクタリング、インストーラーの進化、OpenAPI 同期パイプラインの変更、またはチケットごとのテスト作成や手動 QA ではないフレームワーク インフラストラクチャへの変更を行う場合に使用します。トリガー: /framework-development、「フレームワークの進化」、「フレームワークのリファクタリング」、「新しいフィクスチャ API」、「KATA ベースの変更」、「cli のリファクタリング」、「ボイラープレートの進化」。チケットのテストの作成 (/test-automation を使用)、チケットごとの手動 QA (/sprint-testing を使用)、テスト ケースの文書化 (/test-documentation を使用)、回帰スイートの実行 (/regression-testing を使用) には使用しないでください。
