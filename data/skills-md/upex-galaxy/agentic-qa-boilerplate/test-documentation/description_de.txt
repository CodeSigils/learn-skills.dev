Analysieren, priorisieren und dokumentieren Sie Testfälle in TMS (Jira/Xray) – der Brücke zwischen manueller Qualitätssicherung und Testautomatisierung. Verwenden Sie diese Funktion, wenn Sie Test-/ATP-/ATR-Artefakte erstellen, den ROI berechnen, um auszuwählen, welche Tests automatisiert werden sollen, die Rückverfolgbarkeit von US-ATP-ATR-TC aufrechterhalten oder defekte TMS-Links reparieren. Unterstützt vier Bereiche: modulgesteuert (umfassende Modulerkundung), Ticket-gesteuert (QA-genehmigte User Story), Bug-gesteuert (Regressions-TC für einen geschlossenen Fehler) und Ad-hoc/explorativ. Erzeugt drei Ergebnisse pro TC: Kandidat (Feeds Testautomatisierung), Manuell (Terminal), Zurückgestellt (Terminal). Auslöser bei: Tests dokumentieren, Testfälle in Jira/Xray erstellen, Prioritäten für die Automatisierung setzen, ROI-Analyse, welche Tests automatisiert werden sollen, Kandidat vs. manuell, ATP mit ATR verknüpfen, TMS-Rückverfolgbarkeit korrigieren, Stufe 4, diesen Fehler in einen Regressionstest umwandeln. NICHT zum Schreiben von Testcode (Testautomatisierung) oder zum Ausführen von Suiten (Regressionstests) verwenden.
