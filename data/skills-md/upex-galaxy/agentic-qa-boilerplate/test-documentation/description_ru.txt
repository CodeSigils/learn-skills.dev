Анализируйте, расставляйте приоритеты и документируйте тестовые сценарии в TMS (Jira/Xray) — мосте между ручным контролем качества и автоматизацией тестирования. Используйте при создании артефактов Test/ATP/ATR, расчете рентабельности инвестиций для выбора тестов для автоматизации, обеспечении прослеживаемости US-ATP-ATR-TC или восстановлении неработающих ссылок TMS. Поддерживает четыре области: управляемую модулем (исчерпывающее исследование модуля), управляемую заявками (пользовательская история, одобренная QA), управляемую ошибками (регрессия TC для закрытой ошибки) и специальную/исследовательскую. Выдает три результата для каждого TC: Кандидат (автоматизация тестирования), Ручной (терминал), Отложенный (терминал). Запускается при: документировании тестов, создании тестовых примеров в Jira/Xray, определении приоритетов автоматизации, анализе рентабельности инвестиций, какие тесты автоматизировать, кандидатские или ручные тесты, привязка ATP к ATR, исправление прослеживаемости TMS, этап 4, превращение этой ошибки в регрессионный тест. НЕ используйте для написания тестового кода (автоматизация тестирования) или запуска пакетов (регрессионное тестирование).
