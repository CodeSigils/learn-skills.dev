'bun xray' CLI를 통한 Xray Cloud 테스트 관리: 테스트 생성/나열, 테스트 실행 및 계획 관리, JUnit/Cucumber/Xray JSON 결과 가져오기, 실행 상태 업데이트, 프로젝트 백업 및 복원, 결함 연결. 트리거 조건: Xray에서 테스트 생성, 테스트 결과를 Xray로 가져오기, Xray 실행 나열, 실행 상태 업데이트, Xray 프로젝트 백업, Xray 테스트 복원, 실행할 결함 연결, 테스트 동기화, Xray 인증 로그인. 다음 용도로 사용하지 마십시오: 자동화된 테스트 작성(테스트 자동화) 테스트 사례 또는 ROI 분석 문서화(테스트 문서화) CI 회귀 제품군 실행(회귀 테스트) 브라우저 자동화(playwright-cli).
