Gestion des tests Xray Cloud via la CLI `bun xray` : créer/lister des tests, gérer les exécutions et les plans de tests, importer les résultats JUnit/Cucumber/Xray JSON, mettre à jour les statuts d'exécution, sauvegarder et restaurer les projets, lier les défauts. Déclencheurs sur : créer un test dans Xray, importer les résultats des tests dans Xray, répertorier les exécutions Xray, mettre à jour l'état d'exécution, sauvegarder le projet Xray, restaurer les tests Xray, lier le défaut à exécuter, synchroniser les tests, connexion d'authentification Xray. Ne PAS utiliser pour : l'écriture de tests automatisés (test-automatisation) ; documenter les cas de tests ou l'analyse du ROI (test-documentation) ; exécuter des suites de régression CI (tests de régression); automatisation du navigateur (playwright-cli).
