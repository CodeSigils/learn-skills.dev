Planifiez, rédigez et révisez des tests automatisés selon KATA (Component Action Test Architecture) sur Playwright + TypeScript. À utiliser lors de l'écriture de tests E2E ou API/intégration, de la création de composants de page ou d'API, de la conception d'ATC, du paramétrage des données de test, de l'enregistrement des appareils ou de la révision du code de test pour la conformité KATA. Déclencheurs sur : écriture d'un test, automatisation du test, création d'un test E2E, création d'un test API, test d'intégration, KATA, objet de page, composant API, plan de mise en œuvre, ATC, scénario de test automatisé, révision du code de test, automatisation du module, automatisation du ticket, ajout d'un test de régression. Chargez toujours avant d'écrire un code de test - la sélection des appareils KATA, la règle de localisation en ligne, la règle d'identité ATC et les exigences d'alias d'importation diffèrent des conventions standard de Playwright. Ne PAS utiliser pour exécuter des suites (tests de régression), documenter les TC dans Jira/Xray (documentation de test), intégrer un dépôt (découverte de projet) ou orchestrer des tests à l'échelle du sprint (tests de sprint).
