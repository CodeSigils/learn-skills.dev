Pianifica, scrivi e rivedi test automatizzati seguendo KATA (Component Action Test Architecture) su Playwright + TypeScript. Da utilizzare durante la scrittura di test E2E o API/integrazione, la creazione di componenti Page o Api, la progettazione di ATC, la parametrizzazione dei dati di test, la registrazione di dispositivi o la revisione del codice di test per la conformità KATA. Si attiva su: test di scrittura, test automatizzato, creazione test E2E, creazione test API, test di integrazione, KATA, oggetto pagina, componente API, piano di implementazione, ATC, caso di test automatizzato, revisione del codice del test, automatizzazione del modulo, automatizzazione del ticket, aggiunta del test di regressione. Caricare sempre prima di scrivere qualsiasi codice di test: la selezione delle apparecchiature KATA, la regola di localizzazione in linea, la regola di identità ATC e i requisiti di importazione degli alias differiscono dalle convenzioni standard di Playwright. NON utilizzare per eseguire suite (test di regressione), documentare TC in Jira/Xray (documentazione di test), eseguire l'onboarding di un repository (rilevamento di progetti) o orchestrare test a livello di sprint (test di sprint).
