在 Playwright + TypeScript 上依照 KATA（元件動作測試架構）規劃、編寫和檢視自動化測試。在編寫 E2E 或 API/整合測試、建立 Page 或 Api 元件、設計 ATC、參數化測試資料、註冊裝置或檢查 KATA 合規性測試程式碼時使用。觸發：編寫測試、自動化測試、建立 E2E 測試、建立 API 測試、整合測試、KATA、頁面物件、API 元件、實作計畫、ATC、自動化測試案例、審查測試程式碼、自動化模組、自動化票證、新增回歸測試。在編寫任何測試程式碼之前始終載入 - KATA 夾具選擇、內聯定位器規則、ATC 身分規則和匯入別名要求與標準 Playwright 約定不同。請勿用於執行套件（回歸測試）、在 Jira/Xray 中記錄 TC（測試文件）、加入儲存庫（專案發現）或編排 sprint 範圍的測試（sprint 測試）。
