Planifique, escriba y revise pruebas automatizadas siguiendo KATA (Component Action Test Architecture) en Playwright + TypeScript. Úselo al escribir pruebas de integración/E2E o API, crear componentes de página o API, diseñar ATC, parametrizar datos de prueba, registrar dispositivos o revisar el código de prueba para el cumplimiento de KATA. Activadores de: escribir prueba, automatizar prueba, crear prueba E2E, crear prueba de API, prueba de integración, KATA, objeto de página, componente de API, plan de implementación, ATC, caso de prueba automatizado, revisar código de prueba, automatizar módulo, automatizar ticket, agregar prueba de regresión. Cargue siempre antes de escribir cualquier código de prueba: la selección de dispositivos KATA, la regla de localización en línea, la regla de identidad ATC y los requisitos de alias de importación difieren de las convenciones estándar de Playwright. NO lo use para ejecutar suites (pruebas de regresión), documentar TC en Jira/Xray (documentación de pruebas), incorporar un repositorio (descubrimiento de proyectos) ni orquestar pruebas de todo el sprint (pruebas de sprint).
