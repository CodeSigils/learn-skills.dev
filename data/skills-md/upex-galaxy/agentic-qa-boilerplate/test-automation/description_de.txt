Planen, schreiben und überprüfen Sie automatisierte Tests nach KATA (Component Action Test Architecture) auf Playwright + TypeScript. Zum Schreiben von E2E- oder API-/Integrationstests, zum Erstellen von Seiten- oder API-Komponenten, zum Entwerfen von ATCs, zum Parametrisieren von Testdaten, zum Registrieren von Vorrichtungen oder zum Überprüfen von Testcode auf KATA-Konformität. Auslöser bei: Test schreiben, Test automatisieren, E2E-Test erstellen, API-Test erstellen, Integrationstest, KATA, Seitenobjekt, API-Komponente, Implementierungsplan, ATC, automatisierter Testfall, Testcode überprüfen, Modul automatisieren, Ticket automatisieren, Regressionstest hinzufügen. Laden Sie immer, bevor Sie Testcode schreiben. Die KATA-Fixture-Auswahl, die Inline-Locator-Regel, die ATC-Identitätsregel und die Import-Alias-Anforderungen unterscheiden sich von den Standardkonventionen von Playwright. NICHT zum Ausführen von Suiten (Regressionstests), zum Dokumentieren von TCs in Jira/Xray (Testdokumentation), zum Onboarding eines Repos (Projekterkennung) oder zum Orchestrieren sprintweiter Tests (Sprinttests) verwenden.
