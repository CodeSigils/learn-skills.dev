Atlassian CLI (ثنائي `acli` الرسمي، الإصدار 1.3+ اعتبارًا من 2026) لـ Jira Cloud وConfluence Cloud ومهام إدارة المؤسسة من المحطة. يُستخدم عندما يريد المستخدم إنشاء عناصر عمل Jira أو عرضها أو تحريرها أو نقلها أو تعيينها أو استنساخها أو أرشفتها أو التعليق عليها أو ربطها أو تشغيلها بشكل مجمّع؛ قائمة أو إدارة المشاريع أو اللوحات أو الدورات السريعة أو المرشحات أو لوحات المعلومات أو تعريفات الحقول المخصصة؛ إنشاء أو تحديث مساحات التقاء أو صفحات أو منشورات مدونة؛ تنشيط/إلغاء تنشيط المستخدمين على مستوى المؤسسة؛ أو المصادقة على Atlassian من Shell أو خط أنابيب CI. المشغلات على: `acli`، Atlassian CLI، Jira من المحطة، التقاء من المحطة، عمليات Jira المجمعة، البرمجة النصية لـ Jira، أتمتة تذاكر Jira، نقل مجموعة من المشكلات، إنشاء مشكلات من ملف JSON/CSV، خط أنابيب CI الذي يمس Jira، تسجيل الدخول إلى Jira CLI، تبديل مواقع Atlassian، مصادقة رمز API لـ Jira. استخدم هذه المهارة حتى عندما لا ينطق المستخدم كلمة `acli` - إذا كانت المهمة تعتمد على Jira أو Confluence، فهذه هي الأداة الصحيحة. لا تستخدمه في: عمل خادم Atlassian MCP (وهذا تكامل مختلف)، أو سير عمل REST-API فقط حيث لا تتضمن واجهة سطر الأوامر (CLI)، أو احتياجات سطر أوامر Bitbucket (لا يغطي acli Bitbucket بعد)، أو أداة Appfire/Bob Swift القديمة `acli` (منتج مختلف يحدث لمشاركة الاسم الثنائي).
