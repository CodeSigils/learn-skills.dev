Atlassian CLI（官方“acli”二进制文件，自 2026 年起 v1.3+）用于从终端执行 Jira Cloud、Confluence Cloud 和组织管理任务。当用户想要创建、查看、编辑、转换、分配、克隆、存档、评论、链接或批量操作 Jira 工作项时使用；列出或管理项目、看板、冲刺、过滤器、仪表板或自定义字段定义；创建或更新 Confluence 空间、页面或博客文章；在组织级别激活/停用用户；或从 shell 或 CI 管道向 Atlassian 进行身份验证。触发：`acli`、Atlassian CLI、终端 Jira、终端 Confluence、批量 Jira 操作、编写 Jira 脚本、自动化 Jira 票证、转换一堆问题、从 JSON/CSV 文件创建问题、涉及 Jira 的 CI 管道、登录 Jira CLI、切换 Atlassian 站点、Jira 的 API 令牌身份验证。即使用户没有说出“acli”一词，也可以使用此技能 - 如果任务是 CLI 驱动的 Jira 或 Confluence 工作，那么这是正确的工具。请勿用于：Atlassian MCP 服务器工作（这是一种不同的集成）、不涉及 CLI 的仅 REST-API 工作流程、Bitbucket 命令行需求（acli 尚未涵盖 Bitbucket）或旧版 Appfire/Bob Swift `acli` 工具（碰巧共享二进制名称的不同产品）。
