Atlassian CLI (binaire officiel « acli », v1.3+ à partir de 2026) pour Jira Cloud, Confluence Cloud et les tâches d'administration de l'organisation à partir du terminal. À utiliser chaque fois que l'utilisateur souhaite créer, afficher, modifier, effectuer une transition, attribuer, cloner, archiver, commenter, lier ou effectuer une opération en masse sur des éléments de travail Jira ; répertorier ou gérer des projets, des tableaux, des sprints, des filtres, des tableaux de bord ou des définitions de champs personnalisés ; créer ou mettre à jour des espaces, des pages ou des articles de blog Confluence ; activer/désactiver les utilisateurs au niveau de l'organisation ; ou authentifiez-vous auprès d'Atlassian à partir d'un shell ou d'un pipeline CI. Déclencheurs sur : `acli`, Atlassian CLI, Jira depuis le terminal, Confluence depuis le terminal, opérations Jira en masse, script Jira, automatisation des tickets Jira, transition d'un tas de tickets, création de tickets à partir d'un fichier JSON/CSV, pipeline CI qui touche Jira, connexion à Jira CLI, changement de site Atlassian, authentification par jeton API pour Jira. Utilisez cette compétence même lorsque l'utilisateur ne prononce pas le mot « acli » — si la tâche est un travail Jira ou Confluence piloté par CLI, c'est le bon outil. Ne PAS utiliser pour : le travail sur le serveur Atlassian MCP (c'est-à-dire une intégration différente), les flux de travail REST-API uniquement dans lesquels aucune CLI n'est impliquée, les besoins en ligne de commande Bitbucket (acli ne couvre pas encore Bitbucket) ou l'ancien outil "acli" Appfire/Bob Swift (un produit différent qui partage le nom binaire).
