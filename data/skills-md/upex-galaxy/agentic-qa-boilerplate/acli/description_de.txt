Atlassian CLI (offizielle „Acli“-Binärdatei, v1.3+ ab 2026) für Jira Cloud, Confluence Cloud und Organisationsadministrationsaufgaben vom Terminal aus. Verwenden Sie es immer dann, wenn der Benutzer Jira-Arbeitselemente erstellen, anzeigen, bearbeiten, übertragen, zuweisen, klonen, archivieren, kommentieren, verknüpfen oder in großen Mengen bearbeiten möchte. Projekte, Boards, Sprints, Filter, Dashboards oder benutzerdefinierte Felddefinitionen auflisten oder verwalten; Confluence-Bereiche, -Seiten oder Blog-Beiträge erstellen oder aktualisieren; Benutzer auf Organisationsebene aktivieren/deaktivieren; oder authentifizieren Sie sich über eine Shell oder CI-Pipeline bei Atlassian. Auslöser für: „acli“, Atlassian CLI, Jira vom Terminal, Confluence vom Terminal, Massen-Jira-Vorgänge, Skripterstellung für Jira, Automatisieren von Jira-Tickets, Übergang einer Reihe von Problemen, Erstellen von Problemen aus einer JSON/CSV-Datei, CI-Pipeline, die Jira berührt, Anmeldung bei Jira CLI, Wechseln von Atlassian-Sites, API-Token-Authentifizierung für Jira. Nutzen Sie diese Fähigkeit auch dann, wenn der Benutzer das Wort „acli“ nicht sagt – wenn es sich bei der Aufgabe um CLI-gesteuerte Jira- oder Confluence-Arbeit handelt, ist dies das richtige Tool. NICHT verwenden für: Atlassian MCP-Serverarbeit (das ist eine andere Integration), reine REST-API-Workflows, an denen keine CLI beteiligt ist, Bitbucket-Befehlszeilenanforderungen (acli deckt Bitbucket noch nicht ab) oder das ältere Appfire/Bob Swift „acli“-Tool (ein anderes Produkt, das zufällig den Binärnamen teilt).
