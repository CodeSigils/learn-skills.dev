ターミナルからの Jira Cloud、Confluence Cloud、および組織管理タスク用の Atlassian CLI (公式 `acli` バイナリ、2026 年現在 v1.3 以降)。ユーザーが Jira 作業項目の作成、表示、編集、移行、割り当て、クローン、アーカイブ、コメント、リンク、または一括操作を行う場合に使用します。プロジェクト、ボード、スプリント、フィルター、ダッシュボード、またはカスタムフィールド定義をリストまたは管理します。 Confluence スペース、ページ、またはブログ投稿を作成または更新する。組織レベルでユーザーをアクティブ化/非アクティブ化します。または、シェルまたは CI パイプラインから Atlassian に対して認証します。トリガー: 「acli」、Atlassian CLI、ターミナルからの Jira、ターミナルからの Confluence、一括 Jira 操作、Jira のスクリプト作成、Jira チケットの自動化、一連の課題の移行、JSON/CSV ファイルからの課題の作成、Jira に接続する CI パイプライン、Jira CLI へのログイン、Atlassian サイトの切り替え、Jira の API トークン認証。ユーザーが「acli」という単語を言わない場合でも、このスキルを使用します。タスクが CLI 駆動の Jira または Confluence 作業である場合、これが適切なツールです。 Atlassian MCP サーバーの作業 (別の統合です)、CLI が関与しない REST-API のみのワークフロー、Bitbucket コマンドラインのニーズ (acli はまだ Bitbucket をカバーしていません)、従来の Appfire/Bob Swift の「acli」ツール (たまたまバイナリ名を共有している別の製品) には使用しないでください。
