CLI de Atlassian (binario oficial `acli`, v1.3+ a partir de 2026) para Jira Cloud, Confluence Cloud y tareas de administración de organización desde la terminal. Úselo siempre que el usuario desee crear, ver, editar, realizar transiciones, asignar, clonar, archivar, comentar, vincular u operar de forma masiva elementos de trabajo de Jira; enumerar o administrar proyectos, tableros, sprints, filtros, paneles o definiciones de campos personalizados; crear o actualizar espacios, páginas o publicaciones de blog de Confluence; activar/desactivar usuarios a nivel de organización; o autenticarse en Atlassian desde un shell o canalización de CI. Activadores en: `acli`, CLI de Atlassian, Jira desde la terminal, Confluence desde la terminal, operaciones masivas de Jira, creación de scripts de Jira, automatización de tickets de Jira, transición de una serie de problemas, creación de problemas a partir de un archivo JSON/CSV, canalización de CI que toca a Jira, iniciar sesión en Jira CLI, cambiar de sitio de Atlassian, autenticación de token API para Jira. Utilice esta habilidad incluso cuando el usuario no diga la palabra "acli". Si la tarea es un trabajo de Jira o Confluence basado en CLI, esta es la herramienta adecuada. NO lo use para: trabajo del servidor Atlassian MCP (que es una integración diferente), flujos de trabajo solo REST-API donde no hay CLI involucrada, necesidades de línea de comandos de Bitbucket (acli aún no cubre Bitbucket) o la herramienta heredada Appfire/Bob Swift `acli` (un producto diferente que comparte el nombre binario).
