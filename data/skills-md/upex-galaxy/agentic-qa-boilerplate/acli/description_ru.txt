Atlassian CLI (официальный двоичный файл acli, версия 1.3+ по состоянию на 2026 г.) для Jira Cloud, Confluence Cloud и задач администрирования организации с терминала. Используйте всякий раз, когда пользователь хочет создавать, просматривать, редактировать, переходить, назначать, клонировать, архивировать, комментировать, связывать или выполнять массовые операции с рабочими элементами Jira; составлять списки проектов, досок, спринтов, фильтров, информационных панелей или определений настраиваемых полей или управлять ими; создавать или обновлять пространства, страницы или сообщения в блогах Confluence; активировать/деактивировать пользователей на уровне организации; или выполните аутентификацию в Atlassian из оболочки или конвейера CI. Запускается по: `acli`, Atlassian CLI, Jira из терминала, Confluence из терминала, массовым операциям Jira, написанию сценариев Jira, автоматизации билетов Jira, переходу к множеству задач, созданию задач из файла JSON/CSV, конвейеру CI, который касается Jira, входу в Jira CLI, переключению сайтов Atlassian, аутентификации по токену API для Jira. Используйте этот навык, даже когда пользователь не произносит слово «acli» — если задача представляет собой работу в Jira или Confluence, управляемую через CLI, это правильный инструмент. НЕ используйте для: работы сервера Atlassian MCP (это другая интеграция), рабочих процессов только с REST-API, где не используется CLI, потребностей командной строки Bitbucket (acli еще не охватывает Bitbucket) или устаревшего инструмента Appfire/Bob Swift `acli` (другой продукт, который имеет общее двоичное имя).
