Atlassian CLI（官方「acli」二進位文件，自 2026 年起 v1.3+）用於從終端執行 Jira Cloud、Confluence Cloud 和組織管理任務。當使用者想要建立、檢視、編輯、轉換、分配、複製、存檔、評論、連結或批次操作 Jira 工作項目時使用；列出或管理專案、看板、衝刺、篩選器、儀表板或自訂欄位定義；建立或更新 Confluence 空間、頁面或部落格文章；在組織層級啟用/停用使用者；或從 shell 或 CI 管道向身分驗證。觸發：`acli`、Atlassian CLI、來自終端的 Jira、來自終端的 Confluence、批次 Jira 操作、編寫 Jira 腳本、自動化 Jira 票證、轉換一堆問題、從 JSON/CSV 檔案建立問題、涉及 Jira 的 CI 管道、登入 Jira CLI、切換 Atlassian 網站、Jira 的 API 令牌。即使用戶沒有說出「acli」一詞，也可以使用此技能 - 如果任務是 CLI 驅動的 Jira 或 Confluence 工作，那麼這是正確的工具。請勿用於：Atlassian MCP 伺服器工作（這是一種不同的整合）、不涉及 CLI 的僅 REST-API 工作流程、Bitbucket 命令列需求（acli 尚未涵蓋 Bitbucket）或舊版 Appfire/Bob Swift `acli` 工具（碰巧共享二進位名稱的不同產品）。
