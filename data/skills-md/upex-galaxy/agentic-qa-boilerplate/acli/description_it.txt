Atlassian CLI (binario `acli` ufficiale, v1.3+ a partire dal 2026) per Jira Cloud, Confluence Cloud e attività di amministrazione dell'organizzazione dal terminale. Da utilizzare ogni volta che l'utente desidera creare, visualizzare, modificare, eseguire transizioni, assegnare, clonare, archiviare, commentare, collegare o eseguire operazioni in blocco sugli elementi di lavoro Jira; elencare o gestire progetti, schede, sprint, filtri, dashboard o definizioni di campi personalizzati; creare o aggiornare spazi, pagine o post di blog di Confluence; attivare/disattivare gli utenti a livello di organizzazione; oppure autenticarsi su Atlassian da una shell o da una pipeline CI. Si attiva su: "acli", Atlassian CLI, Jira dal terminale, Confluence dal terminale, operazioni Jira in blocco, scripting Jira, automatizzazione dei ticket Jira, transizione di una serie di problemi, creazione di problemi da un file JSON/CSV, pipeline CI che tocca Jira, accesso alla CLI Jira, cambio di siti Atlassian, autenticazione token API per Jira. Usa questa abilità anche quando l'utente non pronuncia la parola "acli": se l'attività è un lavoro Jira o Confluence basato sulla CLI, questo è lo strumento giusto. NON utilizzare per: lavoro del server Atlassian MCP (ovvero un'integrazione diversa), flussi di lavoro solo API REST in cui non è coinvolta alcuna CLI, esigenze della riga di comando di Bitbucket (acli non copre ancora Bitbucket) o lo strumento legacy Appfire/Bob Swift `acli` (un prodotto diverso che condivide il nome binario).
