WokiToki («токи») — локальный интерфейс командной строки с обратной связью на основе браузера, который ИИ управляет в середине разговора для сбора структурированных, закрепленных, поэтапных ответов. КОГДА использовать: ИИ требует, чтобы пользователь реагировал на БОЛЕЕ ~3 пунктов принятия решения одновременно ИЛИ на длинное многосекционное объяснение/отчет, на который пользователь может захотеть ответить по одному пункту за раз. Он превосходит AskUserQuestion (который ограничен ~4 вопросами × ~4 опциями, привязан к терминалу, не имеет расширенного произвольного текста и не может отображать справочный контент во время ответа) и превосходит встроенный прозаический опросник (который выдает незакрепленные ответы, которые ИИ должен отобразить обратно на каждый вопрос/абзац). КАК это работает: ИИ пишет спецификацию JSON блоков (блок С элементами управления — это вопрос, блок БЕЗ элементов управления — это абзац отчета, а микс — гибридная форма), запускает «toki <specPath>» (глобальный двоичный файл, который создается при первом использовании), а пользователь отвечает в локальном веб-интерфейсе в темной тематике с элементами управления с одним/множеством/переключением + поле для каждого блока с произвольным текстом + выделение кавычек; при отправке инструмент печатает ТОЛЬКО результат в формате JSON на стандартный вывод (баннеры/ошибки передаются на стандартный вывод), который ИИ считывает в ТОТ ЖЕ ход и продолжает с точной, закрепленной обратной связью. Запускается при: «wokitoki», «toki», «интерфейс обратной связи», «спросите меня по пунктам», «позвольте мне ответить в браузере», «форма решения», «интерактивная обратная связь», «рассмотрите этот план по пунктам», «реагируйте на каждый раздел», «более трех вопросов», «длинное объяснение, на которое я хочу ответить по частям». Используйте этот навык, даже если пользователь не говорит «токи» — если задача состоит в том, чтобы собрать детальную привязанную обратную связь по множеству решений или длинному отчету, это правильный инструмент. НЕ используйте для: тривиального выбора 1–2 вариантов или одного ответа «да/нет» (используйте «AskUserQuestion») или любого неинтерактивного / CI / одноразового вывода, когда в браузере нет человека, который мог бы ответить.
