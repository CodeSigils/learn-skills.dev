WokiToki („toki“) – eine lokale, browserbasierte Human-in-the-Loop-Feedback-CLI, die die KI mitten im Gespräch steuert, um strukturierte, verankerte Punkt-für-Punkt-Antworten zu sammeln. WANN zu verwenden: Die KI benötigt, dass der Benutzer auf MEHR ALS ~3 Entscheidungspunkte gleichzeitig reagiert, ODER auf eine lange Erklärung/einen Bericht mit mehreren Abschnitten, auf die der Benutzer möglicherweise jeweils einen Punkt beantworten möchte. Es übertrifft „AskUserQuestion“ (das auf ~4 Fragen × ~4 Optionen begrenzt ist, terminalgebunden ist, keinen umfangreichen Freitext hat und den Referenzinhalt während der Beantwortung nicht anzeigen kann) und es übertrifft einen Inline-Prosa-Fragebogen (der unverankerte Antworten erzeugt, die die KI jeder Frage/jedem Absatz zuordnen muss). WIE es funktioniert: Die KI schreibt eine Spezifikations-JSON von „Blöcken“ (ein Block MIT „Steuerelementen“ ist eine Frage, ein Block OHNE „Steuerelemente“ ist ein Berichtsabsatz und eine Mischung ist eine Hybridform), führt „toki <specPath>“ aus (eine globale Binärdatei, die der Skill bei der ersten Verwendung aufbaut) und der Benutzer antwortet in einer lokalen, dunkel gestalteten Web-Benutzeroberfläche mit einzelnen/mehrfachen/umschaltbaren Steuerelementen + einem Freitextfeld pro Block + Hervorhebung zum Zitieren; Beim Absenden druckt das Tool NUR das JSON-Ergebnis auf stdout (Banner/Fehler gehen auf stderr), was die KI im GLEICHEN Zug liest und mit präzisem, verankertem Feedback fortfährt. Wird ausgelöst durch: „Wokitoki“, „Toki“, „Feedback-Benutzeroberfläche“, „Fragen Sie mich Punkt für Punkt“, „Lassen Sie mich im Browser antworten“, „Entscheidungsformular“, „Interaktives Feedback“, „Überprüfen Sie diesen Plan Punkt für Punkt“, „Reagieren Sie auf jeden Abschnitt“, „mehr als drei Fragen“, „lange Erklärung, auf die ich Stück für Stück antworten möchte“. Nutzen Sie diese Fähigkeit auch dann, wenn der Benutzer nicht „toki“ sagt – wenn die Aufgabe darin besteht, detailliertes, verankertes Feedback zu vielen Entscheidungen oder einem langen Bericht zu sammeln, ist dies das richtige Tool. NICHT verwenden für: eine triviale Auswahl von 1–2 Optionen oder ein einzelnes Ja/Nein (verwenden Sie „AskUserQuestion“) oder jede nicht interaktive/CI/One-Shot-Ausgabe, bei der es keinen Menschen an einem Browser gibt, der antworten könnte.
