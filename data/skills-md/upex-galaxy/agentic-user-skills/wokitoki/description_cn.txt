WokiToki (`toki`) — 一个本地的、基于浏览器的人机交互反馈 CLI，AI 驱动中间对话来收集结构化、锚定的逐点答案。何时使用：人工智能需要用户同时对超过 3 个决策点做出反应，或者对长的多部分解释/报告做出反应，用户可能希望一次回答一个点。它击败了“AskUserQuestion”（上限为〜4个问题×〜4个选项，受终端限制，没有丰富的自由文本，并且在回答时无法显示参考内容），并且它击败了内联散文调查问卷（它产生未锚定的答复，人工智能必须猜测映射回每个问题/段落）。它是如何工作的：人工智能编写一个“blocks”的规范 JSON（带有“controls”的块是一个问题，一个没有“controls”的块是一个报告段落，混合形式是一种混合形式），运行“toki <specPath>”（技能在第一次使用时构建的全局二进制文件），用户在带有单/多/切换控件+每个块自由文本字段+突出显示引用的本地深色主题 Web UI 中进行回答；提交后，该工具仅将结果 JSON 打印到 stdout（横幅/错误转到 stderr），AI 会读取相同的轮次并继续提供精确的锚定反馈。触发条件：“wokitoki”、“toki”、“反馈 UI”、“逐条询问我”、“让我在浏览器中回答”、“决策表”、“交互式反馈”、“逐条审查此计划”、“对每个部分做出反应”、“三个以上问题”、“我想逐条回复的长解释”。即使用户没有说“toki”，也可以使用此技能——如果任务是收集有关许多决策或长报告的细粒度锚定反馈，那么这是正确的工具。请勿用于：简单的 1-2 个选项选择或单个是/否（使用“AskUserQuestion”），或浏览器中无人回答的任何非交互式/CI/一次性输出。
