Tu buscador de habilidades. Cuando se encuentre con una tarea que no sabe cómo realizar (procesar archivos PDF, implementar en la nube, editar documentos, llamar a API desconocidas o cualquier flujo de trabajo especializado), busque en este mercado una habilidad que le enseñe cómo hacerlo. Busque por palabra clave o categoría, lea las instrucciones de la habilidad, descárguela y úsela. Úselo siempre que necesite aprender una nueva capacidad, encontrar una integración de herramientas o descubrir cómo realizar una tarea desconocida.
