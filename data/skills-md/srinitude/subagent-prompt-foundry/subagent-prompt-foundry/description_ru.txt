Создавайте детерминированные, многократно используемые системные подсказки для пользовательских субагентов при выполнении задач кода, исследований, проектирования, безопасности, планирования, проверки и рабочих процессов. Используйте, когда пользователь запрашивает системное приглашение для агента, хочет сделать приглашение многоразовым, нуждается в приглашении субагента производственного уровня со структурой или ограничениями или хочет, чтобы родительский агент делегировал работу изолированному субагенту. Триггеры: «создать собственный субагент», «системное приглашение для агента», «сделать это приглашение многоразовым», «разработать приглашение субагента», «приглашение производственного уровня для рецензента». Не используйте для общих подсказок, прямого выполнения задач, создания подсказок метаагента или запросов, требующих только окончательного ответа.
