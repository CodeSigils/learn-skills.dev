Genere indicaciones del sistema deterministas y reutilizables para subagentes personalizados en tareas de código, investigación, diseño, seguridad, planificación, validación y flujo de trabajo. Úselo cuando el usuario solicita un mensaje del sistema para un agente, quiere que un mensaje sea reutilizable, necesita un mensaje de subagente de nivel de producción con estructura o restricciones, o quiere que un agente principal delegue el trabajo a un subagente aislado. Activadores: "crear un subagente personalizado", "mensaje del sistema para un agente", "hacer que este mensaje sea reutilizable", "diseñar un mensaje de subagente", "mensaje de nivel de producción para un revisor". No lo utilice para sugerencias genéricas, ejecución directa de tareas, creación de mensajes de metaagentes o solicitudes que solo desean la respuesta final.
