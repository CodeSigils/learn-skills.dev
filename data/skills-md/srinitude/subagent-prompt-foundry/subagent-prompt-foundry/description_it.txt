Genera prompt di sistema deterministici e riutilizzabili per agenti secondari personalizzati nelle attività di codice, ricerca, progettazione, sicurezza, pianificazione, convalida e flusso di lavoro. Da utilizzare quando l'utente richiede un prompt di sistema per un agente, desidera rendere un prompt riutilizzabile, necessita di un prompt di un subagente di livello produttivo con struttura o vincoli oppure desidera che un agente padre deleghi il lavoro a un subagente isolato. Trigger: "crea un subagente personalizzato", "prompt di sistema per un agente", "rendi questo prompt riutilizzabile", "progetta un prompt del subagente", "prompt di livello produttivo per un revisore". Non utilizzare per avvisi di prompt generici, esecuzione diretta di attività, creazione di prompt di meta-agente o richieste che richiedono solo la risposta finale.
