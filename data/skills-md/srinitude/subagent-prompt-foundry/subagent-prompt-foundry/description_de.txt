Generieren Sie deterministische, wiederverwendbare Systemaufforderungen für benutzerdefinierte Subagenten für Code-, Forschungs-, Design-, Sicherheits-, Planungs-, Validierungs- und Workflow-Aufgaben. Verwenden Sie diese Option, wenn der Benutzer nach einer Systemeingabeaufforderung für einen Agenten fragt, eine Eingabeaufforderung wiederverwendbar machen möchte, eine Subagenteneingabeaufforderung für die Produktion mit Struktur oder Einschränkungen benötigt oder möchte, dass ein übergeordneter Agent Arbeit an einen isolierten Subagenten delegiert. Auslöser: „Benutzerdefinierten Subagenten erstellen“, „Systemaufforderung für einen Agenten“, „Diese Eingabeaufforderung wiederverwendbar machen“, „Eingabeaufforderung für einen Subagenten entwerfen“, „Eingabeaufforderung für die Produktion für einen Prüfer“. Nicht für generische Eingabeaufforderungshinweise, direkte Aufgabenausführung, Meta-Agent-Eingabeaufforderungserstellung oder Anfragen verwenden, bei denen nur die endgültige Antwort gewünscht wird.
