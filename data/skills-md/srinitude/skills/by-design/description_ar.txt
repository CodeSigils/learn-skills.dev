يُستخدم عند وصول أي طلب، وخاصة عندما يلمس شاشة أو مكون أو تدفق أو علامة تجارية أو تخطيط أو طباعة أو لون أو حركة أو نسخة أو رمز أو نموذج أو جدول أو لوحة معلومات أو التنقل أو الإعداد أو التسعير أو الخروج أو الإشعار أو إمكانية الوصول أو نظام التصميم أو الموجز. يُستخدم عند الاختيار بين الاتجاهات، وعند تشكيل شيء غير مبني، وعند مراجعة العمل أو نقده أو شحنه، وأثناء محادثة التصميم العادية. الطلب الذي لا يحمل أي سطح تصميم يكلف أمرًا واحدًا ولا شيء آخر. الكلمات الرئيسية: التصميم، إعادة التصميم، المراجعة، النقد، النقد، التعليقات، النموذج بالحجم الطبيعي، الإطار السلكي، النموذج الأولي، المقايضة، القرار، الأساس المنطقي، ما قبل الشحن، جاهز للشحن، يبدو عامًا، أي اتجاه، دليل الأسلوب، رمز التصميم.
