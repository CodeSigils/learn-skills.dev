Úselo cuando una solicitud prescribe un método, herramienta, métrica o artefacto que puede no alcanzar el resultado que el usuario describió, o cuando realizar la solicitud tal como está escrita dejaría ese resultado sin probar: "Prueba A/B el color del botón de registro" para un problema de conversión, "agregar un caché" para una página lenta, "las pruebas enfocadas pasaron, anunciar el lanzamiento". También se utiliza cuando una restricción establecida se contradice, cuando un hecho desconocido tendría que ser inventado para terminar, o cuando un paso externo o irreversible necesita una decisión de autorización. Palabras clave: enfoque correcto, métrica incorrecta, causa raíz, resultado versus producto, qué se considera hecho, prueba, ¿vale la pena hacerlo? No para una edición, formato, traducción o búsqueda literal cuyo método sea el entregable. No reemplaza el método de diseño, depuración, investigación o redacción que realiza el trabajo. Utilice la habilidad de cosificar en su lugar cuando la solicitud aún sea demasiado vaga para tener algún método o resultado todavía.
