Verwenden Sie diese Option, wenn eine Anfrage eine Methode, ein Tool, eine Metrik oder ein Artefakt vorschreibt, die möglicherweise nicht zu dem vom Benutzer beschriebenen Ergebnis führt, oder wenn die Ausführung der Anfrage in der geschriebenen Form dazu führen würde, dass das Ergebnis unbewiesen bleibt: „A/B-Test der Farbe der Anmeldeschaltfläche“ für ein Konvertierungsproblem, „Fügen Sie einen Cache hinzu“ für eine langsame Seite, „Die fokussierten Tests bestanden, geben Sie die Veröffentlichung bekannt“. Wird auch verwendet, wenn eine angegebene Einschränkung widersprüchlich ist, wenn eine unbekannte Tatsache erfunden werden müsste, um fertig zu werden, oder wenn ein externer oder irreversibler Schritt eine Genehmigungsentscheidung erfordert. Schlüsselwörter: richtiger Ansatz, falsche Metrik, Grundursache, Ergebnis versus Ausgabe, was als erledigt gilt, Beweis, lohnt sich das. Nicht für eine wörtliche Bearbeitung, Formatierung, Übersetzung oder Suche, deren Methode das Ergebnis ist. Kein Ersatz für die Design-, Debugging-, Recherche- oder Schreibmethode, die die Arbeit ausführt. Verwenden Sie stattdessen die Reify-Fertigkeit, wenn die Anfrage noch zu vage ist, um noch eine Methode oder ein Ergebnis zu haben.
