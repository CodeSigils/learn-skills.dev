يُستخدم عندما يجب أن تصبح أداة محددة قابلة للاستدعاء وتكوين سلوك مؤلف من قبل المستخدم مهارة وكيل خاصة بالأداة، أو عندما يجب دمج هذا السلوك في مهارة وكيل موجودة بالضبط. يدعم عقود الأدوات MCP المنشأة أو المملوكة والأصلية والمخصصة؛ يتوقف عند الهوية الغامضة أو السلوك أو السلطة أو المصدر أو هدف التحديث.
