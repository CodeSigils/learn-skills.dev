يُستخدم عند إنشاء أو مراجعة أو تنقيح منتج رقمي أو التدفق الكامل أو نظام التصميم أو مجموعة الشاشة. إنه يحافظ على بساطة واجهة المستخدم عبر الأجزاء والحالات واحتياجات الوصول والمدخلات وأحجام الشاشة. استخدمه لتصميم المنتج أو تجربة المستخدم أو واجهة المستخدم أو التفاعل أو الحركة أو أعمال مراجعة التصميم.
