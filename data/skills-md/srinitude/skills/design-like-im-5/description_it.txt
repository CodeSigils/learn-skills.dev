Da utilizzare durante la creazione, la revisione o la revisione di un prodotto digitale, di un flusso completo, di un sistema di progettazione o di un set di schermate. Mantiene semplice il nucleo rivolto all'utente tra parti, stati, esigenze di accesso, input e dimensioni dello schermo. Usalo per lavori di progettazione del prodotto, UX, UI, interazione, movimento o revisione del design.
