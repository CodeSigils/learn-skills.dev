TypeScript/JS Web アプリのコードベースを、サーフェス、機能、エンティティ、関係、操作、フロー、コンパートメントの構造化ボキャブラリーにマッピングします。サーフェスはエントリ ポイント (ページ/ルート) です。機能は、サーフェス全体に組み込まれたスタンドアロン機能です (「プロンプト ウィザード」、「スター クレジット」、「コンテンツのロック解除」など)。コンパートメントは、製品コンセプトを基礎となるコードベースに橋渡しする、関連するコード ファイルの論理的なグループです。 JSON ファイルとインタラクティブな HTML ビジュアライザーを生成します。ユーザーがコードベースの理解、その構造のマッピング、存在するエンティティの確認、データ フローの理解、コード構成の調査、またはアプリの動作の概要を取得したい場合に使用します。トリガー: 「このコードベースをマップする」、「このアプリは何をするのか」、「エンティティを表示する」、「地図作成」、「構造を抽出する」、「コードベースの概要」、「このリポジトリを理解する」、「コード マップ」、「コード構造を表示する」。
