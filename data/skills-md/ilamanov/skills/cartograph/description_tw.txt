將任何 TypeScript/JS Web 應用程式程式碼庫對應到表面、功能、實體、關係、操作、流程和分區的結構化詞彙表中。表面是入口點（頁面/路線）；功能是跨表面嵌入的獨立功能（例如「提示精靈」、「明星積分」、「內容解鎖」）；隔間是相關程式碼檔案的邏輯分組，將產品概念與底層程式碼庫連結起來。產生 JSON 檔案和互動式 HTML 視覺化工具。當使用者想要了解程式碼庫、映射其結構、查看存在哪些實體、了解資料流、檢查程式碼組織或獲得應用程式功能的高階概述時使用。觸發：「映射此程式碼庫」、「此應用程式做什麼」、「向我顯示實體」、「製圖」、「提取結構」、「程式碼庫概述」、「理解此儲存庫」、「程式碼圖」、「向我顯示程式碼結構」。
