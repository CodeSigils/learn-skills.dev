Mappez n'importe quelle base de code d'application Web TypeScript/JS dans un vocabulaire structuré de surfaces, de fonctionnalités, d'entités, de relations, d'opérations, de flux et de compartiments. Les surfaces sont des points d'entrée (pages/itinéraires) ; les fonctionnalités sont des fonctionnalités autonomes intégrées sur toutes les surfaces (par exemple, « Assistant d'invite », « Crédits étoiles », « Déverrouillage de contenu ») ; les compartiments sont des regroupements logiques de fichiers de code associés qui relient les concepts de produits à la base de code sous-jacente. Produit un fichier JSON et un visualiseur HTML interactif. À utiliser lorsque l'utilisateur souhaite comprendre une base de code, cartographier sa structure, voir quelles entités existent, comprendre les flux de données, examiner l'organisation du code ou obtenir une vue d'ensemble de haut niveau de ce que fait une application. Se déclenche sur : "mapper cette base de code", "que fait cette application", "montrer-moi les entités", "cartographie", "extraire la structure", "aperçu de la base de code", "comprendre ce dépôt", "carte de code", "montrer-moi la structure du code".
