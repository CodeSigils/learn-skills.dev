Asigne cualquier código base de aplicación web TypeScript/JS a un vocabulario estructurado de superficies, características, entidades, relaciones, operaciones, flujos y compartimentos. Las superficies son puntos de entrada (páginas/rutas); las características son capacidades independientes integradas en todas las superficies (por ejemplo, "Asistente de aviso", "Créditos de estrellas", "Desbloqueo de contenido"); Los compartimentos son agrupaciones lógicas de archivos de código relacionados que unen los conceptos del producto con la base del código subyacente. Produce un archivo JSON y un visualizador HTML interactivo. Úselo cuando el usuario quiera comprender una base de código, mapear su estructura, ver qué entidades existen, comprender los flujos de datos, examinar la organización del código u obtener una descripción general de alto nivel de lo que hace una aplicación.
