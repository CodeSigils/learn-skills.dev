Erstellt ein neues lineares Problem aus einer Freiformbeschreibung. Entwirft einen strukturierten Titel und Text, wählt Team/Projekt/Bezeichnungen/Priorität aus dem verbundenen Arbeitsbereich aus, zeigt den Entwurf dem Benutzer zur Genehmigung und erstellt dann das Ticket. Wird verwendet, wenn der Benutzer auffordert, „ein Linear-Ticket zu erstellen“, „ein Problem einzureichen“, „ein Ticket zu erstellen“, „ein Problem in Linear zu öffnen“ oder eine Anfrage zum Protokollieren eines neuen Fehlers/einer neuen Funktion/einer neuen Aufgabe stellt.
