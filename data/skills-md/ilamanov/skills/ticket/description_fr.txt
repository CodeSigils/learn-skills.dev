Crée un nouveau problème linéaire à partir d'une description de forme libre. Rédige un titre et un corps structurés, sélectionne l'équipe/le projet/les étiquettes/la priorité dans l'espace de travail connecté, présente le brouillon à l'utilisateur pour approbation, puis crée le ticket. À utiliser lorsque l'utilisateur demande de « créer un ticket linéaire », « déposer un problème », « créer un ticket », « ouvrir un problème dans Linear » ou toute demande de journalisation d'un nouveau bug/fonctionnalité/tâche.
