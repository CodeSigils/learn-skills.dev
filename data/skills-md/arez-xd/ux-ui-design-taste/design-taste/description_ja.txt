フロントエンド UI（React、HTML/CSS、Framer、または任意の Web コンポーネント）に対して、シニアデザイナーの判断を適用してください。このスキルは、AI エージェントにデザイン判断を委ねた際に実際に機能するものとしないものを、実践的に調査した結果得られたものです。理論的なガイドラインではなく、実プロジェクトと AI が生成したアウトプットの反復を通じて検証された原則です。ユーザーが UI コードを構築、レビュー、または反復させ、デザイン品質が重要になる場面では常に使用してください。トリガー例としては、コンポーネントやページの作成、既存 UI のレビュー、デザインフィードバックの依頼、ダッシュボードやデータ表示の構築、ビジュアル階層の洗練、Framer コンポーネントの作業、あるいは出力が描画されたインターフェース要素を含むタスクが挙げられます。たとえユーザーが「見た目を良くして」や「これを整理して」とだけ言った場合でも、このスキルを使用してください――意図的なデザインと生成された雑さを区別する原則がここに含まれています。
