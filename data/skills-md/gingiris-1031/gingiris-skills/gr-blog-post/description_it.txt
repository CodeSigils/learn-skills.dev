Pipeline di pubblicazione blog Jekyll: generazione di articoli in stile Iris (apertura ancorata nel tempo, didascalie tra parentesi quadre, transizioni em-dash, tabelle delle statistiche chiave) con frontmatter di accompagnamento (titolo / data / canonical_url / hreflang_ja / hreflang_ko / schema FAQ), sincronizzazione multilingue (en/ja/ko) e collegamento interno automatico. Richiamato quando l'utente dice "scrivi un post sul blog", "pubblica un nuovo articolo" o "sincronizza le versioni giapponese/coreana".
