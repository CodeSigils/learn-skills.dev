Haupteinstiegspunkt des Gingiris-Wachstums-Toolkits. Es wird aufgerufen, wenn Benutzer Fragen zum Offshore-Wachstum stellen, wie zum Beispiel „Wie erreicht man Wachstum“, „Wie startet man PH“, „SEO wurde eingestellt“, „Schreibe einen Blog-Beitrag“, „Analysiere Konkurrenten“ usw. Basierend auf dem Fragetyp wird automatisch zur entsprechenden Unterkompetenz weitergeleitet (gr-seo-patrouille / gr-blog-post / gr-ph-launch usw.).
