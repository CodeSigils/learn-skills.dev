Создавайте, просматривайте и обновляйте техническую документацию на простом техническом английском языке. `new` создает скелет документа с помощью скрипта (@agent подсказки, без прозы); `retcon` создает реальный контент из кодовой базы. Обзор создает отчет о замене; обновление потребляет его. Срабатывает при: «новая документация», «обновление документации», «проверка документации», «переконфигурация документации», «создание документации», «создание документации для», «обновление документации», «просмотр документации», «документирование этого», «добавление документации».
