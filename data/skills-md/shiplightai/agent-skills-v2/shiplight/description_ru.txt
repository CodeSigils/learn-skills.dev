Набор инструментов Shiplight QA — единая точка входа для всей работы по тестированию и обеспечению качества Shiplight. Используйте ТОЛЬКО, когда пользователь явно говорит «shiplight» (например, «напишите тест Shiplight», «используйте Shiplight для проверки X», «укрытие Shiplight») или вызывает /shiplight. Маршруты к подкомандам: init, auth, update, create-yaml-tests, create-agent-verification, Cover, Fix, Verify, Review, ci, Cloud, Help.
