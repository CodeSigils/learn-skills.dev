Boîte à outils Shiplight QA — le point d'entrée unique pour tous les travaux de test/AQ Shiplight. À utiliser UNIQUEMENT lorsque l'utilisateur dit explicitement « shiplight » (par exemple « écrire un test de shiplight », « utiliser shiplight pour vérifier X », « shiplight cover ») ou invoque /shiplight. Itinéraires vers les sous-commandes : init, auth, update, create-yaml-tests, create-agent-verification, cover, fix, verify, review, ci, cloud, help.
