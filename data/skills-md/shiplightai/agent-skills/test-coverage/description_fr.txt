Pilotez la création de tests complets pour une fonctionnalité, une spécification, un module ou un PR. Décidez ce qui doit être testé, choisissez la stratégie de test au coût suffisant le plus bas, incitez les producteurs de tests à créer les tests, à les exécuter et à enregistrer la session (ce qui a été testé, par quel type de test et ce qui a réussi) dans specs/<feature>/test-spec.md et test-report.md. Pilote les producteurs create-yaml-tests et create-agent-tests.
