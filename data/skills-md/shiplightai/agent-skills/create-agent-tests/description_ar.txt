المؤلف، والسقالة، وتشغيل الاختبارات المستندة إلى وكيل الترميز: ملفات حالة Markdown التي يتم تنفيذها بواسطة وكيل ترميز ضد بيئة حية (المتصفح، API، DB، السجلات، السحابة، القياس عن بعد) مع تقرير نجاح/فشل/حظر قابل للتدقيق. يُستخدم عندما يكون الاختبار الحتمي سابقًا لأوانه، أو هشًا، أو باهظ الثمن، أو ضيقًا جدًا.
