Crea, supporta ed esegui test basati sull'agente di codifica: file di casi Markdown eseguiti da un agente di codifica rispetto a un ambiente live (browser, API, DB, registri, cloud, telemetria) con un report PASS/FAIL/BLOCCATO verificabile. Utilizzare quando un test deterministico sarebbe prematuro, fragile, troppo costoso o troppo ristretto.
