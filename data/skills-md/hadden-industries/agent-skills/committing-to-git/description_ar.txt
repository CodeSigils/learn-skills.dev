يُستخدم عندما يُطلب منك صياغة رسالة التزام git أو كتابتها أو مراجعتها، أو عندما يُطلب منك تنفيذ تغييرات مساحة العمل الحالية غير الملتزم بها. تأكد من استخدام هذه المهارة عندما يطلب منك المستخدم "الالتزام"، أو "صياغة التزام"، أو "الالتزام"، أو يذكر حفظ عمله في git. استخدمه أيضًا عند دفع الالتزام الذي تم إنشاؤه بواسطة سير العمل هذا.
