Verwenden Sie diese Option, wenn Sie aufgefordert werden, eine Git-Commit-Nachricht zu entwerfen, zu schreiben oder zu überarbeiten, oder wenn Sie aufgefordert werden, aktuelle, nicht festgeschriebene Änderungen am Arbeitsbereich zu übernehmen. Stellen Sie sicher, dass Sie diese Fähigkeit verwenden, wenn der Benutzer Sie zum „Commit“, „Entwerfen eines Commits“, „Erstellen eines Commits“ auffordert oder erwähnt, dass er seine Arbeit in Git speichert. Wird auch verwendet, wenn ein Commit gepusht wird, das von diesem Workflow erstellt wurde.
