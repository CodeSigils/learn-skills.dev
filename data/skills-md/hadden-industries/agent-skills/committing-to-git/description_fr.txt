À utiliser lorsqu'on vous demande de rédiger, d'écrire ou de réviser un message de validation git, ou lorsqu'on vous demande de valider les modifications actuelles non validées de l'espace de travail. Assurez-vous d'utiliser cette compétence chaque fois que l'utilisateur vous demande de « valider », de « rédiger un commit », de « faire un commit » ou mentionne d'enregistrer son travail sur git. À utiliser également lors de la transmission d'une validation créée par ce flux de travail.
