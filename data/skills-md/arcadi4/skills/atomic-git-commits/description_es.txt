Úselo cuando esté a punto de realizar confirmaciones de git, cuando tenga la tentación de agrupar cambios no relacionados detrás de un solo mensaje, o cuando el historial de confirmaciones necesite admitir flujos de trabajo de git bisect, revertir y seleccionar. Utilícelo también al revisar una rama antes de crear un PR. Si está escribiendo un plan, especifique que el ejecutor debe cargar esta habilidad antes de comenzar a trabajar.
