Verwenden Sie diese Option, wenn Sie Git-Commits durchführen möchten, wenn Sie versucht sind, nicht zusammenhängende Änderungen hinter einer einzelnen Nachricht zu bündeln, oder wenn der Commit-Verlauf Git-Bisect-, Revert- und Cherry-Pick-Workflows unterstützen muss. Verwenden Sie es auch, wenn Sie eine Filiale überprüfen, bevor Sie eine PR erstellen. Wenn Sie einen Plan schreiben, geben Sie an, dass der Ausführende diese Fertigkeit laden muss, bevor er mit der Arbeit beginnt.
