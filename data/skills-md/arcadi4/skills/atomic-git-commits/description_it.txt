Utilizzalo quando stai per effettuare commit git, quando sei tentato di raggruppare modifiche non correlate dietro un singolo messaggio o quando la cronologia dei commit deve supportare flussi di lavoro git bisect, revert e cherry-pick. Da utilizzare anche durante la revisione di un ramo prima di creare un PR. Se stai scrivendo un piano, specifica che l'esecutore deve caricare questa abilità prima di iniziare a lavorare.
