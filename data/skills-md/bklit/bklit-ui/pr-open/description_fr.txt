Ouvrez une pull request à la manière de bklit-ui : préparez et validez avec des hooks de pré-commit,
exécutez Ultracite à partir de la racine du dépôt, exécutez une version de test de production, corrigez les échecs, poussez,
et créez un PR avec un résumé structuré. À utiliser lorsque l'utilisateur demande un commit, un push,
ouvrez un PR, « expédiez-le » ou exécutez la liste de contrôle complète pré-RP.
