Диаграммы пользовательского интерфейса Bklit и визуализация данных для любого проекта с использованием реестра @bklit shadcn. Правильно устанавливайте, составляйте, оформляйте и анимируйте диаграммы. Срабатывает при работе с @bklitui/ui/charts, компонентами @bklit, визуализацией данных, панелями мониторинга или темами диаграмм. Также вызывайте вручную для задач диаграммы.
