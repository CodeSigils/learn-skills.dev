يُستخدم عندما يعمل المستخدم مع عروض Spree الترويجية أو الخصومات أو أكواد القسيمة — تكوين عرض ترويجي، أو كتابة قاعدة ترويج مخصصة، أو إنشاء إجراء مخصص، أو تطبيق خصم برمجيًا. تتضمن العبارات الشائعة "إنشاء عرض ترويجي"، و"رمز القسيمة"، و"الخصم"، و"BOGO"، و"ترويج الشحن المجاني"، و"العرض الترويجي لا ينطبق"، و"قاعدة الترويج المخصصة"، و"العروض الترويجية المكدسة". يوفر الرسم البياني للترويج / PromotionRule / PromotionAction / الحاسبة ونقاط التخصيص الموثقة في `docs/developer/how-to/custom-promotion.mdx`.
