À utiliser lorsque l'utilisateur travaille avec des promotions, des remises ou des codes de réduction Spree : configuration d'une promotion, rédaction d'une règle de promotion personnalisée, création d'une action personnalisée, application d'une remise par programme. Les expressions courantes incluent « créer une promotion », « code de coupon », « remise », « BOGO », « promotion de livraison gratuite », « promotion non applicable », « règle de promotion personnalisée », « promotions de pile ». Fournit le graphique Promotion / PromotionRule / PromotionAction / Calculatrice et les points de personnalisation documentés dans `docs/developer/how-to/custom-promotion.mdx`.
