Используйте, когда пользователь работает с устаревшей платформой Spree/Storefront API v2 или переходит с нее (стиль JSON:API в `/api/v2/`). Триггеры по «API v2», «JSON:API», «API платформы», «API витрины», «миграции с версии 2 на версию 3», «атрибутам/отношениям JSON:API», «X-Spree-Order-Token», «API токена на предъявителя v2». Позиция по умолчанию — **не создавайте новые вещи на версии 2** — указывайте пользователям на эквиваленты версии 3 (навык spree-api-v3). Используйте этот навык только для (а) поддержания существующей интеграции версии 2 или (б) перехода на версию 3.
