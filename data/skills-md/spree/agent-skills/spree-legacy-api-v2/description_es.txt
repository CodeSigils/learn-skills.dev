Úselo cuando el usuario esté trabajando con, o migrando desde, la API v2 heredada de Spree Platform/Storefront (JSON: estilo API en `/api/v2/`). Activadores en "API v2", "JSON:API", "Platform API", "Storefront API", "migración de v2 a v3", "JSON:API atributos/relaciones", "X-Spree-Order-Token", "Bearer token API v2". La postura predeterminada es **no crear cosas nuevas en v2**: indique a los usuarios los equivalentes de v3 (habilidad spree-api-v3). Utilice esta habilidad solo para (a) mantener integraciones v2 existentes o (b) migrar a v3.
