À utiliser lorsque l'utilisateur travaille avec (ou migre) l'ancienne API Spree Platform/Storefront v2 (JSON : style API sous `/api/v2/`). Déclencheurs sur « API v2 », « JSON:API », « Platform API », « Storefront API », « migration v2 vers v3 », « JSON :attributs/relations API », « X-Spree-Order-Token », « API de jeton de porteur v2 ». La position par défaut est **ne créez pas de nouvelles choses sur la v2** — dirigez les utilisateurs vers les équivalents de la v3 (compétence spree-api-v3). Utilisez cette compétence uniquement pour (a) maintenir les intégrations v2 existantes ou (b) migrer vers la v3.
