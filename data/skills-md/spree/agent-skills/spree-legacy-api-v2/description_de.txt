Verwenden Sie diese Option, wenn der Benutzer mit der alten Spree Platform/Storefront API v2 (JSON:API-Stil unter „/api/v2/“) arbeitet oder von dieser migriert. Löst auf „API v2“, „JSON:API“, „Plattform-API“, „Storefront-API“, „v2-zu-v3-Migration“, „JSON:API-Attribute/Beziehungen“, „X-Spree-Order-Token“, „Bearer-Token-API v2“ aus. Die Standardeinstellung ist **Bauen Sie keine neuen Dinge auf Version 2 auf** – verweisen Sie Benutzer auf die Versions-Äquivalente (Spree-API-v3-Skill). Verwenden Sie diese Fähigkeit nur, um (a) bestehende v2-Integrationen zu pflegen oder (b) auf v3 zu migrieren.
