يُستخدم عندما يعمل المستخدم مع - أو يبتعد عن - الإصدار 2 القديم من Spree Platform/Storefront API (JSON:API-style ضمن `/api/v2/`). مشغلات على "API v2"، "JSON:API"، "Platform API"، "Storefront API"، "ترحيل v2 إلى v3"، "JSON: سمات/علاقات واجهة برمجة التطبيقات"، "X-Spree-Order-Token"، "Bearer token API v2". الموقف الافتراضي هو **لا تنشئ أشياء جديدة على الإصدار 2** — قم بتوجيه المستخدمين إلى مرادفات الإصدار 3 (مهارة spree-api-v3). استخدم هذه المهارة فقط من أجل (أ) الحفاظ على عمليات تكامل الإصدار 2 الحالية أو (ب) الانتقال إلى الإصدار 3.
