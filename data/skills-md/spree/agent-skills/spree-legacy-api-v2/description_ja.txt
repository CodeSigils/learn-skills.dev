ユーザーが従来の Spree Platform/Storefront API v2 (「/api/v2/」の下の JSON:API スタイル) を使用している場合、またはそこから移行している場合に使用します。 「API v2」、「JSON:API」、「プラットフォーム API」、「ストアフロント API」、「v2 から v3 への移行」、「JSON:API 属性/関係」、「X-Spree-Order-Token」、「Bearer token API v2」でトリガーされます。デフォルトのスタンスは、**v2 で新しいものを構築しない** です。ユーザーに v3 と同等のものを示すようにします (spree-api-v3 スキル)。このスキルは、(a) 既存の v2 統合を維持する場合、または (b) v3 に移行する場合にのみ使用してください。
