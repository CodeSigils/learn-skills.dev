Wird verwendet, wenn der Benutzer an einem Spree Commerce-Projekt arbeitet – alles, was Spree-Modelle, Controller, Anpassungsmuster (Dekoratoren, Abonnenten, Dienste), Spree-Konventionen wie vorangestellte IDs / Spree::Model-Namensraum / Spree.user_class / Spree::Current betrifft oder fragt, wie Spree funktioniert. Aktiviert sich weitgehend für jede Aufgabe in einem Spree-Backend.
