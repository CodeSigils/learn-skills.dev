Da utilizzare quando l'utente sta lavorando su un progetto Spree Commerce: qualsiasi cosa che coinvolga modelli Spree, controller, modelli di personalizzazione (decoratori, abbonati, servizi), convenzioni Spree come ID prefissi / Spree::Spaziatura nomi modello / Spree.user_class / Spree::Current o chiedendo come funziona Spree. Si attiva ampiamente per qualsiasi attività in un backend Spree.
