À utiliser lorsque l'utilisateur travaille avec le catalogue de produits de Spree : produits, variantes, options, catégories, recherche, images, publication de produits sur les canaux. Les expressions courantes incluent « ajouter un type de produit », « variantes ou options », « taxonomie des produits », « catégoriser les produits », « images de produits », « réindexation Meilisearch », « recherche interrompue », « produit non affiché en magasin », « publier le produit sur le canal », « variante principale », « variante par défaut », « SKU ». Fournit le graphique du catalogue et les opérations sur celui-ci ; s'en remet au @spree/docs local pour les détails au niveau du champ.
