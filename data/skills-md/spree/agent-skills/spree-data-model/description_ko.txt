사용자가 Spree의 도메인 모델(주문, 품목, 변형, 제품, 상점, 채널, 시장, 결제, 배송, 고객, 조정)이 어떻게 관련되어 있는지 묻는 경우에 사용하세요. 아키텍처 및 관계만 해당됩니다. 일반적인 표현에는 "X가 Y에 어떻게 연결됩니까?", "사이의 관계는 무엇입니까?", "Spree는 X를 어디에 저장합니까?", "상점 전체에서 주문을 쿼리하는 방법은 무엇입니까?", "채널은 어떻게 작동합니까?", "장바구니와 주문의 차이점은 무엇입니까?", "매장 대 채널 대 시장"이 포함됩니다. 새로운 모델/새로운 API 리소스를 추가하려면 `spree-resource` 스킬을 사용하세요. 필드 수준 세부정보는 설치된 `@spree/docs` 패키지의 `docs/developer/core-concepts/`를 참조하세요.
