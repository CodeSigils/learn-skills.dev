ユーザーが Spree のドメイン モデル (注文、品目、バリアント、製品、店舗、チャネル、市場、支払い、出荷、顧客、調整) がどのように関連しているかを尋ねる場合に使用します。建築と人間関係のみ。一般的な表現には、「X はどのように Y に接続されますか」、「X 間の関係は何ですか」、「Spree は X をどこに保管しますか」、「店舗間で注文をクエリするにはどうすればよいですか」、「チャネルはどのように機能しますか」、「カートと注文の違いは何ですか」、「店舗対チャネル対市場」などがあります。新しいモデル/新しい API リソースを追加するには、`spree-resource` スキルを使用します。フィールドレベルの詳細については、インストールされている `@spree/docs` パッケージの `docs/developer/core-concepts/` を参照してください。
