Используйте, когда пользователь спрашивает, как связаны модели предметной области Spree — заказы, отдельные позиции, варианты, продукты, магазины, каналы, рынки, платежи, поставки, клиенты, корректировки. Только архитектура и отношения. Общие формулировки включают «как X соединяется с Y», «какая связь между ними», «где Spree хранит X», «как мне запрашивать заказы в разных магазинах», «как работают каналы», «какая разница между корзиной и заказом», «Магазин, канал или рынок». Для добавления новых моделей/новых ресурсов API используйте навык spree-resource. Подробности на уровне поля см. в `docs/developer/core-concepts/` в установленном пакете `@spree/docs`.
