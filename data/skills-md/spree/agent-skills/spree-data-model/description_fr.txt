À utiliser lorsque l'utilisateur demande comment les modèles de domaine de Spree sont liés : commandes, éléments de ligne, variantes, produits, magasins, canaux, marchés, paiements, expéditions, clients, ajustements. Architecture et relations uniquement. Les formulations courantes incluent « comment X se connecte-t-il à Y », « quelle est la relation entre », « où Spree stocke X », « comment puis-je interroger les commandes dans les magasins », « comment fonctionnent les canaux », « quelle est la différence entre le panier et la commande », « Magasin contre canal contre marché ». Pour ajouter de nouveaux modèles/nouvelles ressources API, utilisez la compétence « spree-resource ». Pour des détails au niveau du champ, voir `docs/developer/core-concepts/` dans le package `@spree/docs` installé.
