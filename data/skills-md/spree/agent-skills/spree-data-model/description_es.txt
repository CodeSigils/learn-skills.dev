Úselo cuando el usuario pregunte cómo se relacionan los modelos de dominio de Spree: pedidos, artículos de línea, variantes, productos, tiendas, canales, mercados, pagos, envíos, clientes, ajustes. Sólo arquitectura y relaciones. Las frases comunes incluyen "cómo se conecta X con Y", "cuál es la relación entre sí", "dónde almacena Spree X", "cómo consulto pedidos entre tiendas", "cómo funcionan los canales", "cuál es la diferencia entre carrito y pedido", "Tienda vs Canal vs Mercado". Para agregar nuevos modelos/nuevos recursos API, use la habilidad `spree-resource`. Para obtener detalles a nivel de campo, consulte `docs/developer/core-concepts/` en el paquete `@spree/docs` instalado.
