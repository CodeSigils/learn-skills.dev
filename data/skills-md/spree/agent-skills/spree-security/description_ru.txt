Используйте, когда пользователь усиливает защиту приложения Spree, отвечает на обнаружение безопасности, просматривает PR на наличие проблем безопасности, настраивает управление секретами, настраивает CSP/CORS или задает вопросы о безопасности, специфичной для Spree (области CanCanCan, зашифрованные настройки, веб-перехватчик HMAC, область PCI). Охватывает как стандартные методы обеспечения безопасности Rails (CSRF, массовое присвоение, SQL-инъекция, секреты в репозитории), так и специфичные для Spree части (публикуемые и секретные ключи, обеспечение области действия, SSRF на веб-перехватчиках, возможности CanCanCan). Общие формулировки включают «Spree Security», «CSP», «CORS», «секретный ключ», «утечка ключа», «SQL-инъекция», «Сильные параметры», «CanCanCan», «PCI», «подпись веб-перехватчика», «SSRF».
