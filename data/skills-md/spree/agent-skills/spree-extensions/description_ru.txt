Используйте, когда пользователь хочет установить определенный сторонний драгоценный камень Spree (Stripe, Adyen, PayPal, i18n, поиск, вход через социальные сети и т. д.), создать собственное расширение Spree для совместного использования в приложениях или заменить основной сервис Spree через Spree.dependenties. Общие фразы включают «добавить Stripe», «установить spree_X», «какие платежные шлюзы», «создать расширение Spree», «создать драгоценный камень для Spree», «spree_dev_tools», «Spree.dependents», «обмен сервисами». Чтобы решить, какой шаблон настройки использовать, сначала ознакомьтесь с навыком «весёлая настройка» — расширения — это последние две строки его дерева решений, и для большинства работ с одним приложением они не нужны.
