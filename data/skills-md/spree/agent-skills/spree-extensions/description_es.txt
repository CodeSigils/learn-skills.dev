Úselo cuando el usuario quiera instalar una gema Spree de terceros específica (Stripe, Adyen, PayPal, i18n, búsqueda, inicio de sesión social, etc.), crear su propia extensión Spree para compartir entre aplicaciones o intercambiar un servicio principal de Spree a través de `Spree.dependencies`. Las frases comunes incluyen "agregar Stripe", "instalar spree_X", "qué pasarelas de pago", "crear una extensión de Spree", "crear una joya para Spree", "spree_dev_tools", "Spree.dependencies", "intercambio de servicios". Para decidir qué patrón de personalización usar, consulte primero la habilidad `spree-customization`: las extensiones son las dos últimas filas de su árbol de decisiones y la mayor parte del trabajo de una sola aplicación no necesita una.
