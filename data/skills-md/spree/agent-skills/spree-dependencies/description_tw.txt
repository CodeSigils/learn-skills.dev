當使用者想要交換核心 Spree 服務的運算方式時使用 - 購物車新增、購物車重新運算、結帳流程、能力檢查、支付處理、搜尋、API 中的序列化程式。常見的短語包括「Spree.dependency」、「Spree::Dependency」、「replace Spree::Cart::AddItem」、「交換購物車重新計算服務」、「自訂能力」、「覆蓋 API 序列化程式」、「交換服務」、「Spree 中的依賴注入」、「spree:despendency:」 “spree：依賴項：驗證”，“我可以交換哪些服務”。涵蓋全域與 API 等級覆蓋、內省 rake 任務以及可交換服務的完整目錄。若要決定*是否*交換服務或使用裝飾器或訂閱者，請先參閱「瘋狂自訂」技能。
