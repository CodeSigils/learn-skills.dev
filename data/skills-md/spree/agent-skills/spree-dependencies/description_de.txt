Verwenden Sie diese Option, wenn der Benutzer die Art und Weise ändern möchte, wie ein zentraler Spree-Dienst berechnet – Warenkorb hinzufügen, Warenkorb neu berechnen, Checkout-Ablauf, Fähigkeitsprüfungen, Zahlungsabwicklung, Suche, Serialisierer in der API. Zu den gebräuchlichen Formulierungen gehören „Spree.dependencies“, „Spree::Dependencies“, „replace Spree::Cart::AddItem“, „swap the cart recalculate service“, „custom Fähigkeit“, „override an API serializer“, „swap a service“, „dependency inject in Spree“, „spree:dependencies:list“, „spree:dependencies:overrides“, „spree:dependencies:validate“, „what Dienste kann ich tauschen". Deckt globale Überschreibungen gegenüber API-Ebene, die Introspection-Rake-Aufgaben und den vollständigen Katalog austauschbarer Dienste ab. Um zu entscheiden, *ob* Sie einen Dienst austauschen oder einen Dekorateur oder Abonnenten verwenden möchten, sehen Sie sich zunächst die Fertigkeit „Spree-Anpassung“ an.
