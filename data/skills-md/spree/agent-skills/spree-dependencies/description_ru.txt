Используйте, когда пользователь хочет поменять способ вычислений основного сервиса Spree — добавление корзины, перерасчет корзины, поток оформления заказа, проверки возможностей, обработка платежей, поиск, сериализаторы в API. Общие фразы включают «Spree.dependents», «Spree::Dependities», «заменить Spree::Cart::AddItem», «заменить сервис пересчета корзины», «настраиваемая возможность», «переопределить сериализатор API», «заменить сервис», «инъекция зависимостей в Spree», «spree:dependents:list», «spree:dependents:overrides», «spree:dependents:validate», «какие сервисы я могу обмен». Охватывает глобальные и переопределения уровня API, задачи самоанализа и полный каталог заменяемых сервисов. Чтобы решить *стоит ли* заменять сервис вместо использования декоратора или подписчика, сначала ознакомьтесь с навыком `spree-customization`.
