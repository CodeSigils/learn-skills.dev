À utiliser lorsque l'utilisateur déploie une application Spree en production : Heroku, Render, Fly, AWS, K8s, Plain Docker. Couvre les variables d'environnement requises, la configuration de Sidekiq, la commande de phase de publication (`rake spree:upgrade`), la configuration du backend ActiveStorage, la précompilation des actifs, le comportement du point d'entrée du docker. Les expressions courantes incluent « déployer Spree », « déploiement Heroku », « déploiement de rendu », « Spree sur Kubernetes », « variables d'environnement Spree », « commande de libération Spree », « Procfile », « déploiement Sidekiq », « configuration S3 », « Cloudflare R2 », « échec de la précompilation des actifs ». Bits spécifiques à Spree uniquement : le déploiement générique de Rails est hors de portée.
