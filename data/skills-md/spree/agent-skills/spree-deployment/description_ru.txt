Используйте, когда пользователь развертывает приложение Spree в рабочей среде — Heroku, Render, Fly, AWS, K8s, обычный Docker. Охватывает необходимые переменные среды, настройку Sidekiq, команду фазы выпуска («rake spree:upgrade»), конфигурацию серверной части ActiveStorage, предварительную компиляцию ресурсов, поведение точки входа в докер. Общие фразы включают «развертывание Spree», «развертывание Heroku», «развертывание рендеринга», «Spree в Kubernetes», «переменные среды Spree», «команда выпуска Spree», «Procfile», «развертывание Sidekiq», «настройка S3», «Cloudflare R2», «не удалось выполнить предварительную компиляцию актива». Только специфичные для Spree биты — общее развертывание Rails выходит за рамки.
