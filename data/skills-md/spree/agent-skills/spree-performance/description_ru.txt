Используйте, когда пользователь исследует или улучшает производительность Spree — медленные списки продуктов, медленное обновление корзины, задержки поиска, узкие места при обработке изображений, настройка очереди Sidekiq, N+1 на страницах администратора, стратегии аннулирования кеша. Общие фразы включают «медленный PDP», «медленная корзина», «N + 1 запросов в Spree», «задержка в очереди Sidekiq», «медленный поиск», «настройка Meilisearch», «медленная обработка изображений», «кэш Spree». Предоставляет специфичные для Spree проблемные точки производительности и инструменты для их устранения.
