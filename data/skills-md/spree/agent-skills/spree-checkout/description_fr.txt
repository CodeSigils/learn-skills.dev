À utiliser lorsque l'utilisateur travaille sur le flux de paiement de Spree : pipeline de paniers, machine d'état de commande, gestion des adresses, transition du panier à la commande terminée, personnalisation des étapes de paiement, sessions de paiement, paiement des invités. Les expressions courantes incluent « paiement cassé », « commande bloquée dans l'état X », « ignorer l'étape d'adresse », « paiement de l'invité », « panier n'avance pas », « session de paiement », « personnaliser le flux de paiement », « ajouter une étape de paiement ». Fournit la machine à états de commande, le pipeline de paniers et les hooks de personnalisation.
