يُستخدم عندما يتكامل المستخدم مع Spree's v3 REST API - تقديم الطلبات كعميل، وإنشاء تطبيق إداري، وكتابة مستهلكي الخطاف على الويب، وتصحيح أخطاء المصادقة، وتحليل استجابات واجهة برمجة التطبيقات. يميز واجهة برمجة تطبيقات المتجر (التي تواجه العملاء) عن واجهة برمجة تطبيقات المشرف (المكتب الخلفي). تتضمن العبارات الشائعة "Spree API"، و"Store API"، و"Admin API"، و"مفتاح قابل للنشر"، و"مفتاح سري"، و"X-Spree-Api-Key"، و"نطاقات API"، و"المعرفات البادئة في واجهة برمجة التطبيقات"، و"توسيع"، و"صفحات API"، و"Spree 401"، و"Spree 403"، و"{data, meta} مغلف"، و"v3 endpoint". لإضافة مورد جديد إلى واجهة برمجة التطبيقات (API)، استخدم مهارة الموارد السريعة بدلاً من ذلك.
