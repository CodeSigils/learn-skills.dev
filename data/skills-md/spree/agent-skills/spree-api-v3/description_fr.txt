À utiliser lorsque l'utilisateur intègre l'API REST v3 de Spree : effectuer des requêtes en tant que client, créer une application d'administration, écrire des consommateurs de webhook, déboguer les erreurs d'authentification, analyser les réponses de l'API. Distingue l'API Store (face au client) de l'API Admin (back-office). Les formulations courantes incluent « API Spree », « API Store », « API Admin », « clé publiable », « clé secrète », « X-Spree-Api-Key », « portées API », « ID préfixés dans l'API », « développer », « pagination API », « Spree 401 », « Spree 403 », « enveloppe {data, méta} », « point de terminaison v3 ». Pour AJOUTER une nouvelle ressource à l’API, utilisez plutôt la compétence spree-resource.
