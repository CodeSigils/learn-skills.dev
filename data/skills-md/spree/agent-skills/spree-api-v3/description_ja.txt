ユーザーが Spree の v3 REST API と統合する場合、つまり顧客としてリクエストを行う、管理アプリを構築する、Webhook コンシューマーを作成する、認証エラーをデバッグする、API 応答を解析する場合に使用します。 Store API (顧客向け) と Admin API (バックオフィス) を区別します。一般的な表現には、「Spree API」、「Store API」、「Admin API」、「公開キー」、「秘密キー」、「X-Spree-Api-Key」、「API スコープ」、「API のプレフィックス付き ID」、「expand」、「API ページネーション」、「Spree 401」、「Spree 403」、「{data, meta} エンベロープ」、「v3 エンドポイント」などがあります。新しいリソースを API に追加するには、代わりに spree-resource スキルを使用します。
