當使用者與 Spree 的 v3 REST API 整合時使用 - 作為客戶發出請求、建立管理應用程式、編寫 Webhook 用戶、調試身份驗證錯誤、解析 API 回應。區分商店 API（面向客戶）和管理 API（後台）。常見的短語包括「Spree API」、「Store API」、「Admin API」、「可發布金鑰」、「機密金鑰」、「X-Spree-Api-Key」、「API 範圍」、「API 中的前綴 ID」、「擴充」、「API 分頁」、「Spree 401」、「Spree 403」信封、「{「」信封」、「Spree 403」。若要為 API 新增資源，請使用 spree-resource 技能。
