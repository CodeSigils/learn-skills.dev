Используйте, когда пользователь интегрируется с REST API Spree v3 — делает запросы в качестве клиента, создает приложение администратора, пишет потребителей веб-перехватчиков, отлаживает ошибки аутентификации, анализирует ответы API. Отличает API магазина (для клиентов) от API администратора (бэк-офис). Общие фразы включают «Spree API», «Store API», «API администратора», «публикуемый ключ», «секретный ключ», «X-Spree-Api-Key», «области API», «префиксные идентификаторы в API», «расширение», «Разбиение на страницы API», «Spree 401», «Spree 403», «конверт {data, мета}», «конечная точка v3». Для ДОБАВЛЕНИЯ нового ресурса в API вместо этого используйте навык spree-resource.
