Úselo cuando el usuario quiera extender un modelo, controlador, ayuda o clase de servicio de Spree sin bifurcar: agregue una asociación a Spree::Product, agregue un método a Spree::Order, anule una validación, agregue un alcance, anteponga una acción_antes, conecte a crear. Las frases comunes incluyen "agregar marca al producto", "decorar Spree::X", "ProductDecorator", "OrderDecorator", "Module#prepend", "spree:model_decorator", "extender un modelo Spree existente", "agregar un método a Spree::Order", "anular el comportamiento de Spree", "monkey patch Spree". Proporciona el patrón decorador, el generador, el idioma antepuesto (base) y las trampas. Menciona cuándo NO decorar: eventos para efectos secundarios posteriores al guardado, dependencias para intercambios de servicios, el generador de recursos para modelos completamente nuevos.
