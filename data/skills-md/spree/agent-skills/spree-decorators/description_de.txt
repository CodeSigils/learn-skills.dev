Verwenden Sie diese Option, wenn der Benutzer ein Spree-Modell, einen Controller, einen Helper oder eine Serviceklasse ohne Forking erweitern möchte – fügen Sie eine Zuordnung zu Spree::Product hinzu, fügen Sie eine Methode zu Spree::Order hinzu, überschreiben Sie eine Validierung, fügen Sie einen Bereich hinzu, stellen Sie eine before_action voran, verknüpfen Sie sich mit „create“. Zu den gebräuchlichen Formulierungen gehören „Marke zum Produkt hinzufügen“, „Spree::X dekorieren“, „ProductDecorator“, „OrderDecorator“, „Module#prepend“, „spree:model_decorator“, „ein vorhandenes Spree-Modell erweitern“, „eine Methode zu Spree::Order hinzufügen“, „Spree-Verhalten überschreiben“ und „Affe patch Spree“. Stellt das Dekorationsmuster, den Generator, die vorangestellte (Basis-)Sprache und die Fallstricke bereit. Erwähnt, wann NICHT dekoriert werden sollte – Ereignisse für Nebenwirkungen nach dem Speichern, Abhängigkeiten für Service-Swaps, der Ressourcengenerator für völlig neue Modelle.
