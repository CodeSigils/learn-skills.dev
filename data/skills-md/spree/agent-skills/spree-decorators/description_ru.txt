Используйте, когда пользователь хочет расширить модель, контроллер, помощник или сервисный класс Spree без разветвления — добавьте ассоциацию к Spree::Product, добавьте метод к Spree::Order, переопределите проверку, добавьте область действия, добавьте before_action, подключите create. Общие фразы включают «добавить бренд к продукту», «украсить Spree::X», «ProductDecorator», «OrderDecorator», «Module#prepend», «spree:model_decorator», «расширить существующую модель Spree», «добавить метод в Spree::Order», «переопределить поведение Spree», «monkey patch Spree». Предоставляет шаблон декоратора, генератор, идиому с добавлением (базой) и ошибки. Упоминает, когда НЕ следует украшать — события для побочных эффектов после сохранения, зависимости для замены сервисов, генератор ресурсов для совершенно новых моделей.
