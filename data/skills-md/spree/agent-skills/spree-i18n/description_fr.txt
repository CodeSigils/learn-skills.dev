À utiliser lorsque l'utilisateur traduit Spree : ajouter de nouveaux paramètres régionaux, traduire les noms/descriptions de produits, corriger les traductions manquantes, configurer les langues RTL, créer une vitrine multilingue, travailler avec Mobility ou gérer les recherches de clés Spree.t/I18n.t. Les expressions courantes incluent « ajouter l'espagnol à Spree », « traduire des produits », « Mobilité », « tables de traduction », « RTL », « traduction manquante », « Spree.t », « paramètres régionaux de secours », « colonnes traduites », « administrateur de traduction ». Couvre à la fois les chaînes d'interface utilisateur (config/locales/*.yml) et les traductions de données (mobilité sur le produit, taxon, etc.).
