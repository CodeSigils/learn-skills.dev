ユーザーが新しいモデル、データベース テーブル、または REST API エンドポイントを Spree プロジェクトに追加する場合に使用します。 「spree:api_resource」 (フルサーフェス — モデル + API コントローラー + シリアライザー + ファクトリ + 仕様 + ルート) と `spree:model` (モデル + 移行のみ、API なし) の両方をカバーします。一般的な表現には、「ブランド モデルを追加する」、「新しいリソースを作成する」、「X を API エンドポイントとして公開する」、「Y の管理 API を追加する」、「Spree リソースを足場にする」、「API を使用せずに Spree モデルを作成する」、「内部モデル」などがあります。
