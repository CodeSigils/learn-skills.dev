Úselo cuando el usuario desee agregar un nuevo modelo, tabla de base de datos o punto final de API REST a su proyecto Spree. Cubre tanto `spree:api_resource` (superficie completa: modelo + controladores API + serializadores + fábrica + especificaciones + rutas) como `spree:model` (solo modelo + migración, sin API). Las frases comunes incluyen "agregar un modelo de marca", "crear un nuevo recurso", "exponer X como un punto final de API", "agregar una API de administración para Y", "desarrollar un recurso de Spree", "crear un modelo de Spree sin una API", "modelo interno".
