يُستخدم عندما يريد المستخدم إضافة نموذج جديد أو جدول قاعدة بيانات أو نقطة نهاية REST API إلى مشروع Spree الخاص به. يغطي كلاً من `spree:api_resource` (السطح الكامل - النموذج + وحدات تحكم API + المتسلسلات + المصنع + المواصفات + المسارات) و`spree:model` (النموذج + الترحيل فقط، بدون واجهة برمجة التطبيقات). تتضمن العبارات الشائعة "إضافة نموذج علامة تجارية"، و"إنشاء مورد جديد"، و"كشف X كنقطة نهاية لواجهة برمجة التطبيقات"، و"إضافة واجهة برمجة تطبيقات إدارية لـ Y"، و"دعم مورد Spree"، و"إنشاء نموذج Spree بدون واجهة برمجة تطبيقات"، و"نموذج داخلي".
