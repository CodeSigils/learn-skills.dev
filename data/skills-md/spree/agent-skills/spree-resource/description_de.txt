Verwenden Sie diese Option, wenn der Benutzer seinem Spree-Projekt ein neues Modell, eine neue Datenbanktabelle oder einen neuen REST-API-Endpunkt hinzufügen möchte. Deckt sowohl „spree:api_resource“ (vollständige Oberfläche – Modell + API-Controller + Serialisierer + Fabrik + Spezifikationen + Routen) als auch „spree:model“ (nur Modell + Migration, keine API) ab. Zu den gebräuchlichen Formulierungen gehören „ein Markenmodell hinzufügen“, „eine neue Ressource erstellen“, „X als API-Endpunkt verfügbar machen“, „eine Admin-API für Y hinzufügen“, „ein Gerüst für eine Spree-Ressource erstellen“, „ein Spree-Modell ohne API erstellen“ und „internes Modell“.
