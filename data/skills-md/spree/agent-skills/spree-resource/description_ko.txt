사용자가 Spree 프로젝트에 새 모델, 데이터베이스 테이블 또는 REST API 엔드포인트를 추가하려고 할 때 사용합니다. `spree:api_resource`(전체 표면 — 모델 + API 컨트롤러 + 직렬 변환기 + 팩토리 + 사양 + 경로) 및 `spree:model`(모델 + 마이그레이션만, API 없음)을 모두 다룹니다. 일반적인 표현에는 "브랜드 모델 추가", "새 리소스 생성", "X를 API 엔드포인트로 노출", "Y에 대한 관리 API 추가", "Spree 리소스 스캐폴드", "API 없이 Spree 모델 생성", "내부 모델"이 포함됩니다.
