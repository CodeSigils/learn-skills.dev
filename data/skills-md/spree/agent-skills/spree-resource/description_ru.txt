Используйте, когда пользователь хочет добавить новую модель, таблицу базы данных или конечную точку REST API в свой проект Spree. Охватывает как `spree:api_resource` (полная поверхность — модель + контроллеры API + сериализаторы + фабрика + спецификации + маршруты), так и `spree:model` (только модель + миграция, без API). Общие фразы включают «добавить модель бренда», «создать новый ресурс», «представить X как конечную точку API», «добавить API администратора для Y», «подготовить ресурс Spree», «создать модель Spree без API», «внутренняя модель».
