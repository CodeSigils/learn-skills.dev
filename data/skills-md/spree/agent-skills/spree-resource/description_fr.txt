À utiliser lorsque l'utilisateur souhaite ajouter un nouveau modèle, une table de base de données ou un point de terminaison d'API REST à son projet Spree. Couvre à la fois `spree:api_resource` (surface complète — modèle + contrôleurs API + sérialiseurs + usine + spécifications + routes) et `spree:model` (modèle + migration uniquement, pas d'API). Les formulations courantes incluent « ajouter un modèle de marque », « créer une nouvelle ressource », « exposer X en tant que point de terminaison d'API », « ajouter une API d'administration pour Y », « échafauder une ressource Spree », « créer un modèle Spree sans API », « modèle interne ».
