Da utilizzare quando l'utente desidera aggiungere un nuovo modello, tabella di database o endpoint API REST al proprio progetto Spree. Copre sia `spree:api_resource` (superficie completa: modello + controller API + serializzatori + factory + specifiche + percorsi) che `spree:model` (solo modello + migrazione, nessuna API). Le frasi comuni includono "aggiungi un modello Brand", "crea una nuova risorsa", "esponi X come endpoint API", "aggiungi un'API di amministrazione per Y", "impalcatura di una risorsa Spree", "crea un modello Spree senza API", "modello interno".
