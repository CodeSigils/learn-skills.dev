Используйте, когда пользователь работает над дополнительной витриной магазина Next.js (интернет-магазином, ориентированным на клиентов) — добавляет страницу, настраивает оформление заказа, выбирает продукты, интегрируется с API магазина Spree. Общие фразы включают «настроить витрину», «витрина Next.js», «изменения внешнего интерфейса», «PDP», «страница продукта», «корзина», «последовательность оформления заказа», «@spree/sdk», «публикуемый ключ». Предоставляет архитектуру витрины, модель интеграции @spree/sdk и дерево решений «витрина и серверная часть».
