À utiliser lorsque l'utilisateur travaille sur la vitrine facultative Next.js (la boutique en ligne orientée client) : ajout d'une page, personnalisation du paiement, récupération de produits, intégration avec l'API Store de Spree. Les expressions courantes incluent « personnaliser la vitrine », « vitrine Next.js », « modifications de l'interface », « PDP », « page produit », « panier », « flux de paiement », « @spree/sdk », « clé publiable ». Fournit l'architecture de vitrine, le modèle d'intégration @spree/sdk et l'arbre de décision vitrine/backend.
