À utiliser lorsque l'utilisateur souhaite que Spree réagisse à quelque chose qui s'est produit : synchroniser les commandes avec un ERP, envoyer des notifications, déclencher des webhooks, intégrer des services externes, configurer les points de terminaison des webhooks, vérifier les signatures des webhooks. Les expressions courantes incluent « réagir à X », « quand X se produit », « envoyer une notification quand », « synchroniser avec un service externe », « événements Spree », « abonnés », « publier_event », « point de terminaison du webhook », « signature du webhook », « X-Spree-Webhook-Signature », « HMAC », « nouvelle tentative du webhook », « échec du webhook », « webhook.test ». Couvre les abonnés en cours (effets secondaires Ruby) ET les webhooks sortants (POST HTTPS vers des URL externes).
