À utiliser lorsque l'utilisateur crée un client TypeScript ou JavaScript sur Spree : une vitrine Next.js, un outil d'administration personnalisé, un récepteur webhook, un service backend qui communique avec l'API Spree. Couvre @spree/sdk (API Store) et @spree/admin-sdk (API Admin). Les expressions courantes incluent "Spree SDK", "createClient", "publishable key", "store client", "admin client", "TypeScript types from Spree", "Zod schemas", "verifyWebhookSignature", "retry config", "MSW Spree", "@spree/sdk", "@spree/admin-sdk". Pour plus d’informations sur l’utilisation HTTP curl/raw et les détails du protocole, voir spree-api-v3.
