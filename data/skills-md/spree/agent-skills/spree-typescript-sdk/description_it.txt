Da utilizzare quando l'utente sta creando un client TypeScript o JavaScript contro Spree: una vetrina Next.js, uno strumento di amministrazione personalizzato, un ricevitore webhook, un servizio backend che comunica con l'API Spree. Copre @spree/sdk (API Store) e @spree/admin-sdk (API Admin). Le frasi comuni includono "Spree SDK", "createClient", "chiave pubblicabile", "store client", "client admin", "tipi TypeScript da Spree", "schemi Zod", "verifyWebhookSignature", "retry config", "MSW Spree", "@spree/sdk", "@spree/admin-sdk". Per i dettagli sull'utilizzo e sul protocollo HTTP curl/raw, vedere spree-api-v3.
