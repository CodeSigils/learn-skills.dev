Wird verwendet, wenn der Benutzer einen TypeScript- oder JavaScript-Client für Spree erstellt – eine Next.js-Storefront, ein benutzerdefiniertes Admin-Tool, einen Webhook-Empfänger, einen Backend-Dienst, der mit der Spree-API kommuniziert. Deckt @spree/sdk (Store-API) und @spree/admin-sdk (Admin-API) ab. Zu den gängigen Formulierungen gehören „Spree SDK“, „createClient“, „publishable key“, „store client“, „admin client“, „TypeScript-Typen von Spree“, „Zod schemas“, „verifyWebhookSignature“, „retry config“, „MSW Spree“, „@spree/sdk“, „@spree/admin-sdk“. Informationen zur HTTP-Nutzung und zum Protokoll von Curl/Raw finden Sie unter spree-api-v3.
