Используйте, когда пользователь создает клиент TypeScript или JavaScript для Spree — витрину магазина Next.js, специальный инструмент администрирования, приемник веб-перехватчиков, серверную службу, которая взаимодействует с API Spree. Охватывает @spree/sdk (API магазина) и @spree/admin-sdk (API администратора). Общие фразы включают «Spree SDK», «createClient», «публикуемый ключ», «клиент хранилища», «клиент администратора», «типы TypeScript из Spree», «схемы Zod», «verifyWebhookSignature», «повторить настройку», «MSW Spree», «@spree/sdk», «@spree/admin-sdk». Подробные сведения об использовании HTTP и протоколе Curl/raw см. в статье spree-api-v3.
