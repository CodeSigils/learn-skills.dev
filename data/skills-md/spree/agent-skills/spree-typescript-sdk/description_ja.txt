ユーザーが Spree に対して TypeScript または JavaScript クライアント (Next.js ストアフロント、カスタム管理ツール、Webhook レシーバー、Spree API と通信するバックエンド サービス) を構築する場合に使用します。 @spree/sdk (ストア API) と @spree/admin-sdk (管理 API) をカバーします。一般的な表現には、「Spree SDK」、「createClient」、「公開キー」、「ストア クライアント」、「管理クライアント」、「Spree の TypeScript タイプ」、「Zod スキーマ」、「verifyWebhookSignature」、「再試行設定」、「MSW Spree」、「@spree/sdk」、「@spree/admin-sdk」などがあります。 curl/raw HTTP の使用法とプロトコルの詳細については、spree-api-v3 を参照してください。
