Úselo cuando el usuario esté creando un cliente TypeScript o JavaScript para Spree: un escaparate Next.js, una herramienta de administración personalizada, un receptor de webhook, un servicio backend que se comunica con la API de Spree. Cubre @spree/sdk (API de tienda) y @spree/admin-sdk (API de administración). Las frases comunes incluyen "Spree SDK", "createClient", "clave publicable", "cliente de tienda", "cliente administrador", "tipos de TypeScript de Spree", "esquemas Zod", "verifyWebhookSignature", "retry config", "MSW Spree", "@spree/sdk", "@spree/admin-sdk". Para conocer el uso de HTTP curl/raw y detalles del protocolo, consulte spree-api-v3.
