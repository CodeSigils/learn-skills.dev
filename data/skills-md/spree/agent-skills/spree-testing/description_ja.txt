ユーザーが Spree アプリの自動テスト (モデル仕様、コントローラー仕様、API 統合テスト、管理機能仕様、ファクトリ、フィクスチャ) を作成または実行するときに使用します。 RSpec + Factory Bot + Capybara (Spree のスタック - Minitest + フィクスチャではありません)、spree_dev_tools gem、Spree 独自のファクトリーの取り込み、共有 `API v3 Store` コンテキスト、stub_authorization!、wait_for_turbo、および一般的な Spree テストの問題点をカバーします。一般的な表現には、「Spree モデルをテストする」、「Spree の仕様」、「Spree の Factory Bot 工場」、「spree_dev_tools」、「include_context API v3 ストア」、「stub_authorization」、「wait_for_turbo」、「Spree テストのセットアップ」などがあります。
