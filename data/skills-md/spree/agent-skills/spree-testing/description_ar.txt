يُستخدم عندما يقوم المستخدم بكتابة أو تشغيل اختبارات تلقائية لتطبيق Spree - مواصفات النموذج، ومواصفات وحدة التحكم، واختبارات تكامل واجهة برمجة التطبيقات (API)، ومواصفات ميزات المسؤول، والمصانع، والتركيبات. يغطي RSpec + Factory Bot + Capybara (مكدس Spree — وليس Minitest + Fixtures)، وجوهرة spree_dev_tools، وسحب مصانع Spree الخاصة، وسياق `API v3 Store` المشترك، وتفويض_الكعب!، وانتظار_for_turbo، ومشاكل اختبار Spree الشائعة. تتضمن العبارات الشائعة "اختبار نموذج Spree الخاص بي"، و"مواصفات Spree"، و"مصنع الروبوتات من Spree"، و"spree_dev_tools"، و"include_context API v3 Store"، و"stub_authorization"، و"wait_for_turbo"، و"إعداد اختبار Spree".
