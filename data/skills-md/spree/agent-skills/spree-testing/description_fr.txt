À utiliser lorsque l'utilisateur écrit ou exécute des tests automatisés pour une application Spree : spécifications de modèle, spécifications de contrôleur, tests d'intégration d'API, spécifications de fonctionnalités d'administration, usines, accessoires. Couvre RSpec + Factory Bot + Capybara (la pile de Spree — PAS Minitest + appareils), la gemme spree_dev_tools, tirant les propres usines de Spree, le contexte partagé « API v3 Store », stub_authorization !, wait_for_turbo et les pièges courants des tests Spree. Les expressions courantes incluent « tester mon modèle Spree », « spécifications Spree », « usines Factory Bot de Spree », « spree_dev_tools », « include_context API v3 Store », « stub_authorization », « wait_for_turbo », « configuration du test Spree ».
