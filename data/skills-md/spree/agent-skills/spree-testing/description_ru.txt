Используйте, когда пользователь пишет или запускает автоматические тесты для приложения Spree — спецификации модели, спецификации контроллера, тесты интеграции API, спецификации функций администратора, фабрики, приспособления. Охватывает RSpec + Factory Bot + Capybara (стек Spree — НЕ Minitest + фикстуры), гем spree_dev_tools, использование собственных фабрик Spree, общий контекст `API v3 Store`, stub_authorization!, wait_for_turbo и распространенные ошибки тестирования Spree. Общие фразы включают «проверить мою модель Spree», «спецификация Spree», «фабрики заводских ботов из Spree», «spree_dev_tools», «include_context API v3 Store», «stub_authorization», «wait_for_turbo», «настройка теста Spree».
