Wird verwendet, wenn der Benutzer automatisierte Tests für eine Spree-App schreibt oder ausführt – Modellspezifikationen, Controller-Spezifikationen, API-Integrationstests, Administrator-Funktionsspezifikationen, Fabriken, Vorrichtungen. Behandelt RSpec + Factory Bot + Capybara (Sprees Stack – NICHT Minitest + Fixtures), das Juwel spree_dev_tools, das Einbinden von Sprees eigenen Fabriken, den gemeinsamen „API v3 Store“-Kontext, stub_authorization!, wait_for_turbo und allgemeine Spree-Testprobleme. Zu den gebräuchlichen Formulierungen gehören „mein Spree-Modell testen“, „Spree-Spezifikation“, „Factory Bot-Fabriken von Spree“, „spree_dev_tools“, „include_context API v3 Store“, „stub_authorization“, „wait_for_turbo“ und „Spree-Test-Setup“.
