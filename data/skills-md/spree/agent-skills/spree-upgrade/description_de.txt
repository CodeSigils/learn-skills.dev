Verwenden Sie diese Option, wenn der Benutzer Spree auf eine neue Version aktualisieren möchte. Zu den gebräuchlichen Formulierungen gehören „Upgrade von Spree“, „Update auf 5.5“, „Wie aktualisiere ich“, „Wie läuft der Upgrade-Prozess ab“, „Wir müssen Spree aktualisieren“, „Führen Sie das Spree-Upgrade aus“. Stellt den Spree-Upgrade-Befehl und den Upgrade-Ablauf bereit.
