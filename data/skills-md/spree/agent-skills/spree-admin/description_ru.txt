Используйте, когда пользователь настраивает администратора Spree (гем `spree_admin`) — добавляет новую страницу ресурса, регистрирует элемент боковой панели, настраивает столбец в таблице администратора, переопределяет представление, формирует новый раздел администратора. Общие фразы включают «добавить страницу администратора», «Администратор Rails», «spree_admin», «ресурс администратора scaffold», «боковая панель администратора», «переопределить вид администратора», «Администратор Hotwire», «Администратор Turbo».
