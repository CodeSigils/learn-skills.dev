Wird verwendet, wenn der Benutzer den Spree-Administrator (das „spree_admin“-Juwel) anpasst – indem er eine neue Ressourcenseite hinzufügt, ein Seitenleistenelement registriert, eine Spalte in einer Admin-Tabelle anpasst, eine Ansicht überschreibt oder einen neuen Admin-Bereich erstellt. Zu den gebräuchlichen Formulierungen gehören „Administratorseite hinzufügen“, „Rails-Administrator“, „spree_admin“, „Scaffold-Administratorressource“, „Administrator-Seitenleiste“, „Administratoransicht überschreiben“, „Hotwire-Administrator“, „Turbo-Administrator“.
