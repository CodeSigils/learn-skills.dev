À utiliser lorsque l'utilisateur personnalise l'administrateur Spree (la gemme `spree_admin`) : ajout d'une nouvelle page de ressources, enregistrement d'un élément de la barre latérale, personnalisation d'une colonne dans une table d'administration, remplacement d'une vue, échafaudage d'une nouvelle section d'administration. Les expressions courantes incluent « ajouter une page d'administration », « administrateur Rails », « spree_admin », « ressource d'administration d'échafaudage », « barre latérale d'administration », « remplacer la vue d'administration », « administrateur Hotwire », « administrateur Turbo ».
