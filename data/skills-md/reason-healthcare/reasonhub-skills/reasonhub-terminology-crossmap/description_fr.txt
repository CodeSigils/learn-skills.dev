Mappez un code de n'importe quelle terminologie clinique (ICD-10-CM, LOINC, RxNorm) à son équivalent SNOMED CT afin de débloquer les riches relations d'attributs sémantiques de SNOMED. À utiliser lorsque l'utilisateur dispose d'un code dans un système non-SNOMED et souhaite explorer des concepts associés, trouver des codes cliniquement adjacents, comprendre la signification sémantique ou créer un ValueSet basé sur SNOMED à partir d'un point de départ non-SNOMED. Proposez-le toujours lorsqu'un utilisateur pose des questions sur les relations ou "ce qui est lié à X" et que le code n'est pas déjà dans SNOMED.
