Ordnen Sie einen Code aus einer beliebigen klinischen Terminologie (ICD-10-CM, LOINC, RxNorm) seinem SNOMED CT-Äquivalent zu, um die umfangreichen semantischen Attributbeziehungen von SNOMED freizuschalten. Verwenden Sie diese Option, wenn der Benutzer über einen Code in einem Nicht-SNOMED-System verfügt und verwandte Konzepte erkunden, klinisch benachbarte Codes finden, die semantische Bedeutung verstehen oder ein SNOMED-basiertes ValueSet von einem Nicht-SNOMED-Ausgangspunkt aus erstellen möchte. Schlagen Sie dies immer vor, wenn ein Benutzer nach Beziehungen fragt oder „was mit X zusammenhängt“ und der Code noch nicht in SNOMED vorhanden ist.
