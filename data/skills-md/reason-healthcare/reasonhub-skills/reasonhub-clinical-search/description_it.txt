Cerca ICD-10-CM, LOINC e RxNorm in base al concetto clinico utilizzando la somiglianza semantica, quindi crea un FHIR ValueSet filtrato dalle proprietà nel sistema di destinazione. Da utilizzare quando l'utente desidera trovare codici di diagnosi, codici di osservazione di laboratorio o codici di farmaci/farmaci dal linguaggio naturale o quando desidera creare un ValueSet e il sistema di codice corretto non è chiaro. Rileva automaticamente quale sistema di codice si adatta alla query dai segnali di contesto; richiede all'utente quando è ambiguo. Per le query sugli attributi semantici SNOMED CT (sito di ricerca, agente causale, morfologia, sito della procedura) utilizzare invece la competenza "snomed-semantic".
