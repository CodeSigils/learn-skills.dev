Search ICD-10-CM, LOINC, and RxNorm by clinical concept using semantic similarity, then build a property-filtered FHIR ValueSet in the target system. Use when the user wants to find diagnosis codes, lab observation codes, or drug/medication codes from natural language — or when they want to build a ValueSet and the right code system is unclear. Automatically detects which code system fits the query from context signals; prompts the user when ambiguous. For SNOMED CT semantic attribute queries (finding site, causative agent, morphology, procedure site) use the `snomed-semantic` skill instead.
