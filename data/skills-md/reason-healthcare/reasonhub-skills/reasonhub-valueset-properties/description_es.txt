Cree ValueSets clínicamente significativos utilizando el sistema de filtro de propiedades de cada sistema de código: SNOMED CT (relaciones de atributos + jerarquía), LOINC (CLASS/CLASSTYPE/STATUS/ORDER_OBS), RxNorm (TTY + relaciones de ingredientes), ICD-10-CM (jerarquía principal) y UCUM (cantidad física). Úselo cuando el usuario quiera definir un ValueSet según criterios clínicos en lugar de enumerar códigos manualmente, o cuando solicite "dame todos los códigos X" para un sistema de códigos.
