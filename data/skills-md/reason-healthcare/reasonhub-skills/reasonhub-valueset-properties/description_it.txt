Costruisci ValueSet clinicamente significativi utilizzando il sistema di filtro delle proprietà di ciascun sistema di codice: SNOMED CT (relazioni tra attributi + gerarchia), LOINC (CLASS/CLASSTYPE/STATUS/ORDER_OBS), RxNorm (TTY + relazioni tra ingredienti), ICD-10-CM (gerarchia principale) e UCUM (quantità fisica). Utilizzare quando l'utente desidera definire un ValueSet in base a criteri clinici anziché enumerare manualmente i codici o quando chiede "dammi tutti i codici X" per un sistema di codici.
