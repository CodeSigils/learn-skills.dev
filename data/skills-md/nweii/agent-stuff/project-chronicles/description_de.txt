Richten Sie ein zweigleisiges Projektdokumentationssystem ein und pflegen Sie es: ein Arbeitstagebuch (Implementierungsentscheidungen, die dem Code zugeordnet sind) und Nutzungshinweise (nachhaltiges Produkt‑/Prozessdenken). Es erkennt vorhandene Strukturen und passt sich an, anstatt sie zu überschreiben. Verwenden Sie es, wenn Sie Dokumente starten, einen Sitzungsprotokolleintrag schreiben oder den Projektkontext für zukünftige Sitzungen festhalten.
