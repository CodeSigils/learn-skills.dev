Создайте и поддерживайте двухуровневую систему документации проекта: рабочий журнал (решения по реализации, привязанные к коду) и заметки по использованию (долговременное мышление о продукте/процессе). Обнаруживает существующую структуру и адаптируется, а не перезаписывает. Используйте при запуске документации, записи журнала сеанса или захвате контекста проекта для будущих сеансов.
