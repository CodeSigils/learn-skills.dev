تشغيل قياس codometer، تحديد مكان توجيه تقريره، أو قراءة كتلة الشارة أو تقرير JSON الذي تم إنتاجه. يُستخدم عند تشغيل codometer أو npx codometer، مع اختيار العلامات --write و --check، ربط codometer بخطوة CI، إدراج كتلة شارة في ملف README، أو قراءة مقاييس تقرير JSON الخاص بـ codometer، أو الحدود، أو الأخطاء. يغطي استدعاء سطر الأوامر مباشرةً، دون افتراض أي مُشغِّل مهام.
