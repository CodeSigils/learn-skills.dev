Code d'échafaudage avec un générateur de conformité au lieu de l'écrire à la main. À utiliser lors de l'ajout d'un module, d'un composant, d'un service, d'une application ou d'un package à un espace de travail doté d'une configuration de conformité ; lorsque vous décidez si un générateur existe pour la forme que vous êtes sur le point de créer ; lorsqu'un générateur exécuté écrase ou égare des fichiers ; ou lorsqu'une exécution de conformité signale un fichier qu'un générateur aurait dû produire. Couvre à la fois le plugin Nx et l'hôte de ligne de commande de conformité, dont les contrats d'entrée diffèrent.
