Codice impalcatura con un generatore di conformità invece di scriverlo a mano. Da utilizzare quando si aggiunge un modulo, un componente, un servizio, un'applicazione o un pacchetto a un'area di lavoro con una configurazione conforme; quando decidi se esiste un generatore per la forma che stai per creare; quando un generatore viene sovrascritto o smarrito i file; o quando un'esecuzione di conformità riporta un file che un generatore avrebbe dovuto produrre. Copre sia il plugin Nx che l'host della riga di comando di conformità, i cui contratti di input differiscono.
