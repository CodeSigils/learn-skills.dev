Scrivi o modifica un file codependix.config.ts — quali tipi di grafico eseguire, le sovrascritture per progetto, i pattern glob di includi ed escludi, il grafo dell’intero workspace e dove atterra ogni esportazione. Usalo quando un workspace non ha ancora una configurazione codependix, quando un’esecuzione non produce output perché tutto è stato risolto al target none, quando aggiungi una destinazione JSON o Markdown, quando scegli tra un blocco anchor e un file autonomo, quando una configurazione viene rifiutata per una destinazione mancante, o quando decidi se una configurazione può descrivere tutti i progetti in un workspace.
