Ejecute una verificación de conformidad y actúe según lo que informa. Úselo cuando falla un objetivo de validación de conformidad; cuando una ejecución de pelusa compuesta informa diferencias de conformidad; cuando un informe menciona un archivo faltante, una declaración faltante, un comentario faltante, una instancia ambigua o una instancia no coincidente; al decidir si editar una instancia o regenerarla; o antes de que finalice la reclamación del código generado. Cubre tanto el complemento Nx como el host de línea de comandos de conformidad.
