Wird verwendet, wenn ein Conformetry-Validate-Ziel fehlschlägt. wenn ein zusammengesetzter Lint-Lauf Konformitätsunterschiede meldet; wenn ein Bericht eine fehlende Datei, eine fehlende Deklaration, einen fehlenden Kommentar, eine mehrdeutige Instanz oder eine nicht übereinstimmende Instanz benennt; bei der Entscheidung, ob eine Instanz bearbeitet oder neu generiert werden soll; oder bevor der generierte Code fertig ist.
