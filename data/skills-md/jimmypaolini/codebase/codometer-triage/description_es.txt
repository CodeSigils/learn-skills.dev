Actúe ante una violación del límite de codómetro, un informe comprometido obsoleto o una ejecución que falló directamente. Úselo cuando `codometer --check` finaliza con un código distinto de cero, cuando se supera un límite de tamaño o de recuento, cuando un informe comprometido aparece obsoleto frente a una medición nueva aunque nada haya cambiado, cuando un límite no logra aplicarse o un objetivo no coincide con ningún archivo, o antes de alcanzar el valor límite de un repositorio para hacer pasar una verificación fallida.
