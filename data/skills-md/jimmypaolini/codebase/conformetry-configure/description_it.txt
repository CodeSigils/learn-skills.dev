Aggiungi o modifica un generatore di conformità e scrivi il modello che rende. Utilizzare quando non esiste ancora un generatore necessario; quando si modifica un file di configurazione di conformità; quando si scrivono o si modificano file in una directory di modelli; quando si scelgono i segnaposto o le varianti dei casi di denominazione; quando un file generato risultava con un valore vuoto o un segmento di percorso dispari; o quando un comando di conformità si rifiuta di essere eseguito perché il plugin del generatore emesso non è aggiornato.
