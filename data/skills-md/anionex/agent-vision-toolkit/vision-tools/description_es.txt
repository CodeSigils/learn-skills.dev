CLI de visión local: vistazo (describir/preguntar/OCR una imagen), terreno (localizar un objetivo, cuadro de píxeles), detectar (inventario de elementos), rastrear (imagen a geometría SVG), recortar (cortar un cuadro de píxeles a un archivo) y scripts/html_shot.py (archivo HTML a imagen). Úselo para cualquier tarea que involucre una imagen (preguntas, texto, dividir y transcribir capturas de pantalla largas o historiales de chat, ubicar elementos, comparar, reconstruir como HTML/SVG, digitalizar un boceto o diagrama, leer valores de un gráfico, operar una GUI a partir de capturas de pantalla) y para volver a verificar una imagen usted mismo cuando una descripción que le dieron carece de detalles.
