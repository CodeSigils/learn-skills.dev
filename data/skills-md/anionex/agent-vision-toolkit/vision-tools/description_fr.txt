CLI de vision locale : coup d'oeil (décrire/demander/OCR une image), sol (localiser une cible, une boîte de pixels), détecter (inventaire des éléments), tracer (image vers une géométrie SVG), recadrer (couper une boîte de pixels dans un fichier) et scripts/html_shot.py (fichier HTML en image). À utiliser pour toute tâche impliquant une image : questions, texte, fractionnement et transcription de longues captures d'écran ou historiques de discussion, localisation d'éléments, comparaison, reconstruction au format HTML/SVG, numérisation d'un croquis ou d'un diagramme, lecture de valeurs sur un graphique, utilisation d'une interface graphique à partir de captures d'écran - et pour revérifier vous-même une image lorsqu'une description qui vous a été donnée manque de détails.
