Lokale Vision-CLIs: Blick (ein Bild beschreiben/fragen/OCR), Boden (ein Ziel lokalisieren, Pixelfeld), erkennen (Elementinventar), verfolgen (Bild in SVG-Geometrie), Zuschneiden (ein Pixelfeld in eine Datei schneiden) und scripts/html_shot.py (HTML-Datei in Bild). Verwenden Sie es für jede Aufgabe, die ein Bild betrifft – Fragen, Text, Aufteilen und Transkribieren langer Screenshots oder Chat-Verläufe, Suchen von Elementen, Vergleichen, Neuaufbau als HTML/SVG, Digitalisieren einer Skizze oder eines Diagramms, Ablesen von Werten aus einem Diagramm, Bedienen einer GUI anhand von Screenshots – und um ein Bild selbst noch einmal zu überprüfen, wenn eine Beschreibung, die Sie erhalten haben, keine Details enthält.
