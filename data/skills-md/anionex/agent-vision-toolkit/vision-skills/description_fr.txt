CLIs de vision locale : glance (décrire/demander/OCR une image), ground (localiser une cible, boîte de pixels), detect (inventaire d’éléments), trace (image vers géométrie SVG), crop (découper une boîte de pixels dans un fichier) et scripts/html_shot.py (fichier HTML vers image). Utilisez‑les pour toute tâche impliquant une image — questions, texte, découpage et transcription de longues captures d’écran ou historiques de chat, localisation d’éléments, comparaison, reconstruction en HTML/SVG, numérisation d’un croquis ou diagramme, lecture de valeurs sur un graphique, manipulation d’une interface graphique à partir de captures d’écran — et pour revérifier vous‑même une image lorsqu’une description qui vous a été donnée manque d’un détail.

Veuillez toujours répondre dans la langue de l’utilisateur.
