Herramienta CLI para crear, administrar y exportar presentaciones generadas por IA a través de la API Banana Slides. Úselo cuando el usuario solicite: (1) generar un PPT/presentación/diapositivas a partir de una idea, esquema o descripción, (2) exportar un proyecto a PPTX, PDF o imágenes, (3) generar por lotes varias presentaciones, (4) administrar proyectos, páginas, materiales o plantillas mediante programación, (5) renovar/rediseñar un PPT o PDF existente, (6) editar imágenes de diapositivas con lenguaje natural.
