Berechnen Sie die empfohlene Netzteilleistung für einen PC-Build mithilfe der CPU-/GPU-Wattleistungs-APIs von Newegg sowie festen Leistungstabellen für andere Komponenten. Verwenden Sie diesen Skill immer dann, wenn Benutzer fragen: „Welches Netzteil benötige ich?“, „Wie viel Watt für meinen Build?“, „Ist mein Netzteil ausreichend?“, „Berechnen Sie die Leistung für meinen PC“ oder beschreiben Sie PC-Komponenten (CPU + GPU + RAM + Speicher) und möchten wissen, welches Netzteil sie kaufen sollen. Lösen Sie aus, auch wenn der Benutzer das Netzteil nicht explizit erwähnt hat – die Wattzahl ist die natürliche nächste Frage, wenn jemand seine Komponenten auflistet.
