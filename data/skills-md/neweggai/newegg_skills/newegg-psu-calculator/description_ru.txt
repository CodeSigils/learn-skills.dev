Рассчитайте рекомендуемую мощность блока питания для сборки ПК, используя API мощности процессора/графического процессора Newegg, а также таблицы фиксированной мощности для других компонентов. Используйте этот навык всякий раз, когда пользователи спрашивают: «какой блок питания мне нужен?», «сколько ватт для моей сборки?», «достаточно ли моего блока питания?», «рассчитать мощность для моего ПК» или описывают компоненты ПК (ЦП + графический процессор + ОЗУ + хранилище) и хотят знать, какой блок питания купить. Триггер, даже если пользователь явно не упомянул блок питания: мощность — это естественный следующий вопрос, когда кто-то перечисляет его компоненты.
