Newegg の CPU/GPU ワット数 API と他のコンポーネントの固定電力テーブルを使用して、PC ビルドの推奨 PSU ワット数を計算します。ユーザーが「どの PSU が必要ですか?」、「ビルドには何ワットですか?」、「電源は十分ですか?」、「PC の電力を計算してください」と質問したり、PC コンポーネント (CPU + GPU + RAM + ストレージ) について説明し、どの電源を購入すればよいかを知りたい場合には、このスキルを使用してください。ユーザーが PSU について明示的に言及していない場合でもトリガーします。コンポーネントをリストアップすると、次の質問は自然にワット数になります。
