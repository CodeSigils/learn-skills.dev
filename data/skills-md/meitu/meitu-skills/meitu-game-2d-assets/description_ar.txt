قم بإنشاء أصول فردية ورسوم توضيحية للشخصيات وأيقونات وعناصر وأوراق رموز متحركة بسيطة ورسومات تخطيطية للألعاب ثنائية الأبعاد. يدعم فن البكسل، والمتجهات المسطحة، وأنماط الرسوم المتحركة المرسومة يدويًا، ويمكنه الجمع بين النص إلى صورة، وصورة إلى صورة، والقطع، وتقسيم الشبكة، وتحسين الدقة الفائقة. يتم تشغيله عندما يذكر المستخدم أصول اللعبة، أو الأصول ثنائية الأبعاد، أو الكائنات، أو أوراق الصور المتحركة، أو مجموعة البلاط، أو أصول الشخصيات، أو أيقونات العناصر، أو أصول البكسل، أو الرسوم التوضيحية للعبة.
