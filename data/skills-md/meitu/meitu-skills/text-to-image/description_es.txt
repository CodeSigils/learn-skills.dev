Utilice meitu-cli para generar imágenes nuevas a partir de descripciones de texto desde cero (sin una imagen base), que abarquen la fusión general de referencias de texto a imagen/múltiples imágenes y la generación de alta calidad de nivel comercial. Se activa cuando el usuario menciona generar una imagen, dibujar una, convertir texto a imagen, crear una imagen, una imagen conceptual, una imagen promocional, una imagen de portada, una imagen de marketing, una imagen de escena del producto o un estilo de captura de pantalla de película.
