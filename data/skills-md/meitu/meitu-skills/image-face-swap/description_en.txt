Dual‑image face/head swap synthesis replaces the face from the source image onto the target scene image, preserving the target image’s composition, body, and background while automatically blending skin tones and matching lighting. It is triggered only when the user explicitly provides two images and expresses an intention to swap faces, swap heads, put A’s face onto B, “face swap,” or a clear P‑face synthesis intent. During execution, it uses locally stored Meitu OpenAPI credentials for authorization and sends the source face image and target scene image to Meitu’s external service for processing.
