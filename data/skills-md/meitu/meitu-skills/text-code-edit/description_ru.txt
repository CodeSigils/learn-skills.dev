Используйте meitu-cli для редактирования и изменения существующего исходного кода React/TSX/JSX, поддерживая несколько итераций. Срабатывает, когда пользователь упоминает изменение кода, изменение страниц, настройку стилей, изменение цветов, добавление кнопок, удаление компонентов, изменение макета или пересмотр предыдущего кода.
