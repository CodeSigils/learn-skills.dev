Verwenden Sie meitu-cli, um vorhandenen React/TSX/JSX-Quellcode zu bearbeiten und zu ändern und dabei mehrere Iterationen zu unterstützen. Wird ausgelöst, wenn der Benutzer das Ändern von Code, das Ändern von Seiten, das Anpassen von Stilen, das Ändern von Farben, das Hinzufügen von Schaltflächen, das Löschen von Komponenten, das Ändern des Layouts oder das Überarbeiten des vorherigen Codes erwähnt.
