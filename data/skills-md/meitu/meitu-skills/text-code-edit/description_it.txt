Utilizza meitu-cli per modificare il codice sorgente React/TSX/JSX esistente, supportando più iterazioni. Si attiva quando l'utente menziona la modifica del codice, la modifica delle pagine, la regolazione degli stili, la modifica dei colori, l'aggiunta di pulsanti, l'eliminazione di componenti, la modifica del layout o la revisione del codice precedente.
