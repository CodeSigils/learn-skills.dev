قم بإنشاء صور هوية قياسية بناءً على الصورة الأمامية للمستخدم ومواصفات المستند المحددة بوضوح، وتغيير الملابس والخلفية تلقائيًا وإجراء التعديلات المتوافقة. يتم تشغيله فقط عندما يطلب المستخدم صراحة صورة هوية موحدة - مثل 1 بوصة/2 بوصة، أو جواز السفر، أو التأشيرة، أو بطاقة الهوية، أو تنسيق رخصة القيادة - ويقدم صورة شخصية؛ لا تؤدي طلبات الأعمال العامة أو طلبات الصور الشخصية أو الصور الفنية إلى تشغيلها بشكل منفصل.
