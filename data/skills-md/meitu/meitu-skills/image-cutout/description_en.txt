The foreground subject of the image is precisely separated from the background, outputting a transparent‑background PNG (standard four categories: people, pets, products, graphic stamps) or a white‑background image (non‑standard subject or when the user explicitly wants a white background). This is triggered only when the user explicitly requests cut‑out, background removal, transparent background/base, subject extraction, or explicitly asks to convert an existing image to a white background. Execution will use the local Meitu CLI, Meitu OpenAPI credentials, and write to the local output directory.
