Verwenden Sie meitu-cli, um ein eigenständiges LLM aufzurufen, das Text, Texte, Storyboard-Skripte oder Videoaufforderungen von Grund auf generiert. Lösen Sie dies aus, wenn der Benutzer das Schreiben von Texten, das Polieren, das Umschreiben, Slogans, Produktbeschreibungen, Social-Media-Texte, Artikel, Storyboard-Skripte, Storyboards oder Prompt-Optimierung erwähnt. Deaktivieren Sie es, wenn der Kontext bereits vollständigen Inhalt enthält. Verwenden Sie stattdessen write_file.
