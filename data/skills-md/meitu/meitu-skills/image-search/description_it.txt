Ricerca di immagini per parole chiave/ricerca per immagine, recupero congiunto della libreria di immagini della piattaforma e Pinterest. Attivato solo quando l'utente richiede esplicitamente una ricerca di immagini, una ricerca per immagine o una ricerca di immagini di riferimento/materiale. Durante l'esecuzione, legge le credenziali Meitu e la configurazione di ricerca, richiama la CLI locale "meitu" e scrive i risultati della ricerca insieme ai file eventualmente scaricati nella directory di output locale.
