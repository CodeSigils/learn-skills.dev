Поиск изображений по ключевым словам/поиск по изображению, совместный поиск из библиотеки изображений платформы и Pinterest. Срабатывает только тогда, когда пользователь явно запрашивает поиск изображения, поиск по изображению или поиск эталонных изображений/материальных изображений. Во время выполнения он считывает учетные данные Meitu и конфигурацию поиска, вызывает локальный интерфейс командной строки meitu и записывает результаты поиска вместе с дополнительно загруженными файлами в локальный выходной каталог.
