Замените весь фон изображения / измените сцену, сохранив объект на переднем плане неизменным. Срабатывает, когда пользователь говорит: «Изменить фон», «Заменить фон», «Изменить фон на xx», «Изменить сцену продукта», «Изменить фон портрета», «Изменить цвет фона фотографии для удостоверения личности» или «Изменить фон». Этот инструмент не может вывести прозрачный фон. При выполнении будут использоваться локальный интерфейс командной строки Meitu, учетные данные Meitu OpenAPI и запись в локальный выходной каталог.
