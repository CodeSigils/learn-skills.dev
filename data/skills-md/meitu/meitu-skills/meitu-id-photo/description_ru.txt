Создайте стандартные фотографии для удостоверения личности (1 дюйм, 2 дюйма, паспорт, виза и т. д.). Естественное благоустройство + перерисовка ИИ (замена официальной одеждой + однотонный фон + обрезка по спецификации). Срабатывает, когда пользователь явно запрашивает характеристики фотографии для удостоверения личности, цвет фона или размеры. При выполнении считываются учетные данные Meitu, вызывается локальный интерфейс командной строки meitu, отправляются параметры портретной фотографии и идентификационной фотографии в Meitu OpenAPI и записываются результаты в локальный выходной каталог.
