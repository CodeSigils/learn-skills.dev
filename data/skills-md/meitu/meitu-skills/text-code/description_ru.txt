Создавайте код страницы React/TSX с нуля с помощью meitu-cli, поддерживая ссылки на материалы и быстрое расширение. Он срабатывает только тогда, когда пользователь явно запрашивает создание файлов внешнего кода React/TSX/HTML; обычные обсуждения дизайна страниц, предложения продуктов и требования к визуальному дизайну не вызывают его.
