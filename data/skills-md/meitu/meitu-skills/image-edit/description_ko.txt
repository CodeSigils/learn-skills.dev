사용자가 이미 제공한 이미지에 대해 명시적인 콘텐츠 편집을 수행하거나 참조 이미지를 기반으로 새 이미지를 만듭니다(기본/참조 이미지가 필요함). 여기에는 전자 상거래 제품 이미징, 인물 사진 편집, 다중 이미지 및 일관성 편집, 일반 이미지 편집, 참조 이미지 생성 등 5가지 시나리오가 포함됩니다. 사용자가 현재 이미지 편집을 명시적으로 요청하는 경우에만 트리거됩니다. 일반적인 텍스트 변경, 코드 편집 또는 "조금 변경/무언가 추가"와 같은 모호한 요청은 이를 트리거하지 않습니다. 실행 중에 Meitu 자격 증명을 읽고, 로컬 'meitu' CLI를 호출하고, 입력 이미지와 프롬프트를 Meitu OpenAPI에 보내고, 결과를 로컬 출력 디렉터리에 씁니다.
