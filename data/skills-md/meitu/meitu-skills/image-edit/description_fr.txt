Effectuez une édition de contenu explicite sur des images déjà fournies par l'utilisateur ou créez de nouvelles images basées sur une image de référence (une image de base/de référence est requise). Cela couvre cinq scénarios : l'imagerie de produits de commerce électronique, l'édition de portraits, l'édition multi-images et de cohérence, l'édition générale d'images et la création d'images de référence. Il est déclenché uniquement lorsque l'utilisateur demande explicitement de modifier l'image actuelle ; les modifications de texte ordinaires, l'édition de code ou les demandes vagues telles que « modifier un peu / ajouter quelque chose » ne le déclenchent pas. Pendant l'exécution, il lit les informations d'identification Meitu, invoque la CLI locale « meitu » et envoie l'image d'entrée et l'invite à Meitu OpenAPI, écrivant le résultat dans un répertoire de sortie local.
