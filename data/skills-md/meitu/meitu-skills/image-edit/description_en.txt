Perform explicit content editing on images already provided by the user, or create new images based on a reference image (a base/reference image is required). This covers five scenarios: e‑commerce product imaging, portrait editing, multi‑image and consistency editing, general image editing, and reference‑image creation. It is triggered only when the user explicitly requests editing the current image; ordinary text changes, code editing, or vague requests like “change a bit / add something” do not trigger it. During execution, it reads Meitu credentials, invokes the local `meitu` CLI, and sends the input image and prompt to the Meitu OpenAPI, writing the result to a local output directory.
