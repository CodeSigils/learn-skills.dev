Analysiere PMCC (Poor Man's Covered Call / Diagonal Spread)-Positionen aus dem IB-Portfolio. Für jeden Diagonal Spread gibt das Tool das Risiko des Short‑Legs (Delta, IV, Zuweisungswahrscheinlichkeit) aus, liefert tägliche P&L‑Projektionen, die Top‑3‑Roll‑Kandidaten und eine nebeneinander stehende Vergleichstabelle. Erfordert, dass TWS oder IB Gateway lokal ausgeführt wird.
