Problemgesteuertes TDD für eine einzelne lokale Problemdatei (issues/issue-#.md) – Red-Green-Refactor, dann schreiben Sie regression-tests/verify-issue-#.sh, führen Sie ruff+pyright+pytest+regression-Skripte aus (projekteigenes run-*.sh, falls vorhanden, andernfalls die Standardeinstellungen dieses Pakets), führen Sie eine UI-Überprüfung durch, wenn das Problem dies erfordert, und aktualisieren Sie die Problembeschreibung Füge den Abschnitt hinzu, höre bei git add auf. Wenn keine Problemnummer vorhanden ist, wird ein laufendes Problem erkannt, das fortgesetzt werden soll, oder das kleinste ausstehende Problem zum Starten ausgewählt und zuerst gefragt.
