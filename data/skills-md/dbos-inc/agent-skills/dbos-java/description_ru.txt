DBOS Java SDK для создания надежных, отказоустойчивых приложений с устойчивыми рабочими процессами. Используйте этот навык при написании кода Java или Kotlin с помощью DBOS, создании рабочих процессов и шагов, использовании очередей, интеграции DBOS с Spring Boot, использовании DBOSClient из внешних приложений или создании приложений JVM, которые должны быть устойчивыми к сбоям.
