DBOS Java SDK لإنشاء تطبيقات موثوقة ومتسامحة مع الأخطاء مع سير عمل متين. استخدم هذه المهارة عند كتابة كود Java أو Kotlin باستخدام DBOS، أو إنشاء سير عمل وخطوات، أو استخدام قوائم الانتظار، أو دمج DBOS مع Spring Boot، أو استخدام DBOSClient من التطبيقات الخارجية، أو إنشاء تطبيقات JVM التي تحتاج إلى أن تكون مرنة في مواجهة حالات الفشل.
