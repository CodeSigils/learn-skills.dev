SDK Java DBOS pour créer des applications fiables et tolérantes aux pannes avec des flux de travail durables. Utilisez cette compétence lors de l'écriture de code Java ou Kotlin avec DBOS, de la création de flux de travail et d'étapes, de l'utilisation de files d'attente, de l'intégration de DBOS avec Spring Boot, de l'utilisation de DBOSClient à partir d'applications externes ou de la création d'applications JVM qui doivent être résilientes aux pannes.
