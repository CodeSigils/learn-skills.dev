OpenAlgo-Agentenkompetenz – umfassende Abdeckung des OpenAlgo Python SDK für indische Märkte (NSE / BSE / NFO / BFO / CDS / BCD / MCX / NCO). Wird verwendet, wenn der Benutzer Aufträge aufgeben/ändern/stornieren, einen Algorithmus zur Verfolgung von Limit-Orders oder benutzerdefinierten Ausführungen erstellen, Kurse/Tiefen/historische OHLCV (REST oder direktes DuckDB-Historify) abrufen, Optionsketten mit Greeks abrufen, Margen oder Fonds berechnen, Live-LTP/Kurse/Tiefe über WebSocket streamen, einen Scanner erstellen, eine Heatmap/OI-Diagramm/Kerze erstellen, eine Strategie mit VectorBT backtesten, Telegram-/WhatsApp-Benachrichtigungen senden oder den Analysator umschalten möchte (Sandbox-)Modus. Löst auch allgemeine Fragen zum programmatischen Handel an indischen Börsen aus, wenn OpenAlgo die Plattform des Benutzers ist.
