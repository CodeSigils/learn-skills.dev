مهارة وكيل OpenAlgo — تغطية شاملة لـ OpenAlgo Python SDK للأسواق الهندية (NSE / BSE / NFO / BFO / CDS / BCD / MCX / NCO). يُستخدم عندما يطلب المستخدم وضع / تعديل / إلغاء الأوامر، أو إنشاء خوارزمية مطاردة أوامر الحد أو التنفيذ المخصص، أو جلب علامات الاقتباس / العمق / OHLCV التاريخي (REST أو DuckDB Historify المباشر)، أو سحب سلاسل الخيارات مع اليونانيين، أو حساب الهامش أو الأموال، أو بث LTP / اقتباس / العمق المباشر عبر WebSocket، أو إنشاء ماسح ضوئي، أو تقديم خريطة حرارية / مخطط OI / شمعدان، أو اختبار خلفي لاستراتيجية باستخدام Vectorbt، أو إرسال تنبيهات Telegram / WhatsApp، أو التبديل وضع المحلل (رمل). يؤدي أيضًا إلى طرح أسئلة عامة حول التداول الآلي في البورصات الهندية عندما يكون OpenAlgo هو النظام الأساسي للمستخدم.
