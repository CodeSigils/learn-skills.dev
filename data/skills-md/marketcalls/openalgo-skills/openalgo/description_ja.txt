OpenAlgo エージェント スキル — インド市場 (NSE / BSE / NFO / BFO / CDS / BCD / MCX / NCO) 向けの OpenAlgo Python SDK を包括的にカバーします。ユーザーが注文の発注/変更/キャンセル、指値注文追跡またはカスタム約定アルゴの構築、相場/深度/履歴OHCVの取得(RESTまたは直接DuckDB Historify)、ギリシャ人とのオプションチェーンのプル、証拠金または資金の計算、WebSocketでのライブLTP/相場/深度のストリーミング、スキャナーの構築、ヒートマップ/OIチャート/ローソク足のレンダリング、vectorbtで戦略のバックテスト、Telegram/WhatsAppアラートの送信を要求する場合に使用します。アナライザー (サンドボックス) モードを切り替えます。 OpenAlgo がユーザーのプラットフォームである場合、インドの取引所でのプログラム取引に関する一般的な質問もトリガーされます。
