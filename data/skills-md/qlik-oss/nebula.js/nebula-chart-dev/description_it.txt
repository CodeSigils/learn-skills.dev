Costruisci, sviluppa e rivedi i grafici di visualizzazione di nebula.js (stardust). Utilizzare quando: creare grafici di supernova, implementare hook (usePromise, useLayout, useStaleLayout, useTheme, useRect, useSelections, useInteractionState), impostare il pannello delle proprietà (definizione ext, accordion, elementi), eseguire il rendering con React all'interno di un componente supernova, gestire stampa/istantanee, evitare l'inquinamento DOM e CSS globale. Copre l'impalcatura del progetto, l'associazione dati, la gestione della selezione, l'accesso ai temi, la gestione del ridimensionamento e i modelli di debug. NON UTILIZZARE per il lavoro API mashup/embed o per la configurazione del motore Qlik.
