Ingegneria fluida dell'interfaccia utente React v9 per pacchetti, provider, temi, token, Griffel, composizione di componenti e slot pubblici, accessibilità e focus, Next.js SSR, icone, movimento, grafici, migrazione legacy Fabric/v8/v0 e rara integrazione Vue tramite @fluentui/web-components. Da utilizzare quando un'attività nomina Fluent UI, Fabric UI, un pacchetto @fluentui, FluentProvider, Griffel, token o componenti Fluent o una codebase React che già li utilizza. Non utilizzare per React/CSS generico o progettazione visiva senza un'implementazione del pacchetto Fluent.
