Разработка Fluent UI React v9 для пакетов, поставщиков, тем, токенов, Griffel, композиции общедоступных компонентов и слотов, доступности и фокуса, Next.js SSR, значков, движения, диаграмм, миграции устаревшей версии Fabric/v8/v0 и редкой интеграции Vue через @fluentui/web-компоненты. Используйте, когда задача называет Fluent UI, Fabric UI, пакет @fluentui, FluentProvider, Griffel, токены или компоненты Fluent или базу кода React, уже использующую их. Не используйте для общего React/CSS или визуального дизайна без реализации пакета Fluent.
