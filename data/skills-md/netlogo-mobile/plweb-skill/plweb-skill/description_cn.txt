物理实验室 AR（Physics-Lab-AR / Beaker Lab）官方社区 API 调用技能。当用户需要与物理实验室社区平台（physicals-lab）进行交互，或者plweb2的开发者遇到API相关的信息检索交互时，包括：登录（邮件登录/匿名登录/token登录）、查询和检索实验作品、获取实验详情和摘要、检索衍生作品、发布/删除实验、发表/删除评论、获取评论列表、点赞/收藏作品、获取支持者列表、发送和检索内部消息、获取通知消息、获取用户资料、关注/取消关注用户、获取粉丝/关注列表、获取社区主页/简介页/讨论区/实验区内容、获取头像和封面图、修改昵称和个人信息、领取活动奖励、封禁/解封用户（管理员）等。适用于物理实验室社区自动化操作、批量管理作品、数据采集、Bot开发、社区交互自动化等场景。 API域名为Physics-api-cn.turtlesim.com（中国区），基于HTTPS POST JSON请求。
