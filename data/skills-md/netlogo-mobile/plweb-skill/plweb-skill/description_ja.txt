Physics Lab AR (Physics-Lab-AR / Beaker Lab) 公式コミュニティ API 呼び出し機能。ユーザーが Physics Lab コミュニティ プラットフォーム (physics-lab) と対話する必要がある場合、または plweb2 を開発して API 関連情報を取得する必要がある場合、これにはログイン (電子メール ログイン / 匿名ログイン / トークン ログイン)、実験作品のクエリと取得、実験の詳細と概要の取得、派生作品の取得、実験の公開/削除、コメントの投稿/削除、コメント リストの取得、作品のお気に入り登録/お気に入り登録、サポーターの取得が含まれます。リスト、内部メッセージの送受信、通知メッセージの取得、ユーザープロファイルの取得、ユーザーのフォロー/フォロー解除、ファン/フォローリストの取得、コミュニティホームページ/プロフィールページ/ディスカッションエリア/実験エリアコンテンツの取得、アバターとカバー画像の取得、ニックネームと個人情報の変更、イベント報酬の請求、ユーザー(管理者)の禁止/禁止解除など。Physics Labコミュニティの操作を自動化するのに適しています。作業の管理、データ収集、ボット開発、コミュニティ インタラクションの自動化、その他のシナリオ。 API ドメインは、HTTPS POST JSON リクエストに基づく、physics-api-cn.turtlesim.com (中国地域) です。
