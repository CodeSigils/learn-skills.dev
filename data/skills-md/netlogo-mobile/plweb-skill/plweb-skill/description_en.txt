The official community API-calling skill for Physics Lab AR (Physics-Lab-AR / Beaker Lab). When users need to interact with the Physics Lab community platform (physics‑lab), or developers of plweb2 encounter API‑related information retrieval interactions, it includes: logging in (email login / anonymous login / token login), querying and retrieving experimental works, obtaining experiment details and summaries, retrieving derivative works, publishing/deleting experiments, posting/deleting comments, fetching comment lists, liking/favoriting works, getting supporter lists, sending and retrieving internal messages, obtaining notification messages, fetching user profiles, following/unfollowing users, retrieving fans/following lists, obtaining community homepage/profile page/discussion area/experiment area content, fetching avatars and cover images, modifying nicknames and personal information, claiming event rewards, banning/unbanning users (admin), etc. It is suitable for automating operations of the Physics Lab community, batch managing works, data collection, bot development, community interaction automation, and other scenarios. The API domain is physics‑api‑cn.turtlesim.com (China region), based on HTTPS POST JSON requests.
