Physics Lab AR (Physics-Lab-AR / Beaker Lab) official community API calling capability. When users need to interact with the Physics Lab community platform (physics‑lab), or when developing plweb2 and need to obtain API‑related information, it includes: logging in (email login / anonymous login / token login), querying and retrieving experimental works, getting experiment details and summaries, fetching derived works, publishing/deleting experiments, posting/deleting comments, retrieving comment lists, liking/favoriting works, obtaining supporter lists, sending and receiving internal messages, fetching notification messages, retrieving user profiles, following/unfollowing users, getting fan/following lists, retrieving community homepage/profile page/discussion area/experiment area content, fetching avatars and cover images, modifying nickname and personal information, claiming event rewards, banning/unbanning users (admin), etc. It is suitable for automating operations of the Physics Lab community, batch managing works, data collection, bot development, community interaction automation, and other scenarios. The API domain is physics-api-cn.turtlesim.com (China region), based on HTTPS POST JSON requests.
