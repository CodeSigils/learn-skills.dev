Physics Lab AR(Physics-Lab-AR/Beaker Lab) 공식 커뮤니티 API 호출 기능입니다. 사용자가 Physics Lab 커뮤니티 플랫폼(physics‑lab)과 상호 작용해야 하거나 plweb2를 개발하고 API 관련 정보를 얻어야 하는 경우 여기에는 로그인(이메일 로그인/익명 로그인/토큰 로그인), 실험 작업 쿼리 및 검색, 실험 세부 정보 및 요약 가져오기, 파생 작업 가져오기, 실험 게시/삭제, 댓글 게시/삭제, 댓글 목록 검색, 작품 좋아요/즐겨찾기, 후원자 목록 가져오기, 내부 전송 및 수신이 포함됩니다. 메시지, 알림 메시지 가져오기, 사용자 프로필 가져오기, 사용자 팔로우/팔로우 취소, 팬/팔로잉 목록 가져오기, 커뮤니티 홈페이지/프로필 페이지/토론 영역/실험 영역 콘텐츠 가져오기, 아바타 및 표지 이미지 가져오기, 닉네임 및 개인 정보 수정, 이벤트 보상 청구, 사용자 금지/차단 해제(관리자) 등. Physics Lab 커뮤니티 운영 자동화, 작업 일괄 관리, 데이터 수집, 봇 개발, 커뮤니티 상호 작용에 적합합니다. 자동화 및 기타 시나리오. API 도메인은 HTTPS POST JSON 요청을 기반으로 하는 물리-api-cn.turtlesim.com(중국 지역)입니다.
