Physics Lab AR (Physics-Lab-AR / Beaker Lab) — возможность вызова API официального сообщества. Когда пользователям необходимо взаимодействовать с платформой сообщества Physical Lab (физическая лаборатория) или при разработке plweb2 им необходимо получить информацию, связанную с API, это включает в себя: вход в систему (вход по электронной почте / анонимный вход / вход по токену), запрос и получение экспериментальных работ, получение подробностей и сводок экспериментов, получение производных работ, публикацию/удаление экспериментов, публикацию/удаление комментариев, получение списков комментариев, отметку «Нравится»/избранное работам, получение списков сторонников, отправку и получение внутренних сообщений, получение уведомлений, получение профилей пользователей, подписка на пользователей/отписка от них, получение списков поклонников/подписок, получение домашней страницы сообщества/страницы профиля/области обсуждения/контента области экспериментов, получение аватаров и изображений обложек, изменение псевдонима и личной информации, получение наград за события, запрет/разблокировка пользователей (администратор) и т. д. Он подходит для автоматизации операций сообщества Physical Lab, пакетного управления работами, сбора данных, бота разработка, автоматизация взаимодействия с сообществом и другие сценарии. Домен API — Physics-api-cn.turtlesim.com (Китайский регион), основанный на запросах HTTPS POST JSON.
