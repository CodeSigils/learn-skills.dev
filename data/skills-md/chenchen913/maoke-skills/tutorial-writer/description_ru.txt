Полный рабочий процесс для написания высококачественных технических руководств. Когда пользователь говорит: «Помогите мне написать руководство по X», «Напишите вводное руководство по X», «Представьте X», «Объясните принцип/использование X», «Напишите руководство на основе этого проекта/инструмента/кода», «Помогите мне организовать знания по X» или «Как установить/настроить/использовать X», это должно быть запущено немедленно. Поддерживает любой источник: проекты GitHub, локальный код, инструменты/платформы, точки знаний/концепции, установку/конфигурацию, сравнительный выбор, учебные пособия по рабочим процессам и т. д. Необходимо строго следовать этому рабочему процессу Skill, а не начинать писать руководство напрямую.

Пожалуйста, всегда отвечайте на языке пользователя.
