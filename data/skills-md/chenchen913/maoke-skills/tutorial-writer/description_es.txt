Flujo de trabajo completo para crear tutoriales técnicos de alta calidad. Cuando un usuario dice "Ayúdame a escribir un tutorial sobre X", "Escribe un tutorial introductorio sobre X", "Presenta X", "Explica el principio/uso de X", "Escribe un tutorial basado en este proyecto/herramienta/código", "Ayúdame a organizar los puntos de conocimiento de X" o "Cómo instalar/configurar/usar X", se activa inmediatamente. Admite cualquier fuente: proyectos de GitHub, código local, herramientas/marcos, conceptos/puntos de conocimiento, instalación y configuración, selección comparativa, tutoriales de flujo de trabajo, etc. Debe seguir estrictamente este flujo de trabajo de habilidades y no comenzar a escribir el tutorial directamente.
