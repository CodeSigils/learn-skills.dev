Flux de travail complet pour créer des didacticiels techniques de haute qualité. Lorsque l'utilisateur dit « Aidez-moi à écrire un didacticiel sur X », « Écrivez un didacticiel d'introduction sur X », « Présentez X », « Expliquez les principes/l'utilisation de X », « Écrivez un didacticiel basé sur ce projet/outil/code », « Aidez-moi à organiser les points de connaissance de X » ou « Comment installer/configurer/utiliser X », se déclenchent immédiatement. Prend en charge n'importe quelle source : projets GitHub, code local, outils/frameworks, points de connaissances/concepts, installation/configuration, sélection comparative, tutoriels de workflow, etc. Doit suivre strictement ce workflow de compétences et ne pas commencer à écrire le tutoriel directement.

Veuillez toujours répondre dans la langue de l'utilisateur.
