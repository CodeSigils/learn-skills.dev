Uno strumento di gestione centralizzata per la directory delle competenze locali (“Skill Manager”). Quando un utente desidera: (1) elencare o interrogare le competenze installate (a livello di sistema o di utente); (2) controllare le informazioni sulla versione di ciascuna Skill; (3) creare rapidamente una nuova competenza locale utilizzando un modello standard; (4) eliminare o rimuovere le competenze che non sono più necessarie. Per favore usa questa abilità.
