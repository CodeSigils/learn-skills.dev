Uno strumento di gestione centralizzata per le directory delle competenze locali ("Skill Butler"). Quando gli utenti desiderano: (1) elencare o interrogare le competenze installate (a livello di sistema o di utente); (2) controllare le informazioni sulla versione di ciascuna abilità; (3) creare rapidamente nuove competenze locali utilizzando modelli standard; (4) eliminare o rimuovere le competenze che non sono più necessarie. Per favore usa questa abilità.
