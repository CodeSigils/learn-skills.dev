Utilisez-le lorsqu'un utilisateur souhaite initialiser un nouveau projet Java full-stack (Spring Boot+Vue3) ou reprendre une session d'initialisation interrompue. La compétence gère le processus de bout en bout, y compris la création de projet, la gestion des dépendances, la configuration et l'échafaudage du code de base. Il utilise un fichier persistedINIT_TODO.md pour suivre la progression et restaurer le contexte.
