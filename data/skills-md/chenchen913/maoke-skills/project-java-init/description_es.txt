Se utiliza cuando un usuario desea inicializar un nuevo proyecto Java completo (Spring Boot + Vue3) o reanudar una sesión de inicialización interrumpida. Esta habilidad maneja el proceso de un extremo a otro, incluida la creación de proyectos, la gestión de dependencias, la configuración y la generación de código repetitivo. Utiliza un archivo INIT_TODO.md persistente para realizar un seguimiento del progreso y restaurar el contexto.
