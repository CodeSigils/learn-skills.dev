Используется, когда пользователь хочет инициализировать новый полностековый проект Java (Spring Boot+Vue3) или возобновить прерванный сеанс инициализации. Эта возможность управляет сквозным процессом, включая создание проекта, управление зависимостями, настройку и генерацию базового кода. Он использует файл persistedINIT_TODO.md для отслеживания прогресса и восстановления контекста.
