HertzFlow 온체인 거래 결정 인텔리전스. 현재 모든 Surf-SQL EVM 체인(BSC / Ethereum / Arbitrum / Base / Polygon / Optimism)에 대한 바이낸스 알파 포렌식을 다루고 있습니다 — 내부 배포, 真实派发 확인된 매진, 筹码三分법(운영자 / CEX 풀 / 검증 가능한 소매), 이상 징후, 수출 모니터링. 솔라나는 HOLDER_SNAPSHOT 모드로 실행됩니다.
사용자가 원시 0x 접두사가 붙은 40-16진수 EVM CA인 Solana base58 CA를 붙여 넣을 때마다 자동 트리거되며, 티커로 Binance Alpha 토큰을 언급하거나 链上 포렌식 / 内幕take货 / 派发 / 칩 구조 / 조용한 내부자 / 알파 배포 / 온체인 덤프에 대해 질문할 때마다 — 명시적으로 "hertzflow"라고 말하지 않더라도 자동 트리거됩니다. 파이프라인은 결정론적으로 실행됩니다(활동 + 서핑 캐시 상태에 따라 CA당 최대 2~10분). LLM은 서술형 슬롯만 채우고 결코 평결을 선택하거나 SQL을 작성하지 않습니다.
Perp 메트릭, 브리지 감사 및 HertzFlow 핵심 계약 분석 하위 도메인이 출시될 예정입니다. 해당 하위 도메인이 출시되면 이 기술은 아래 라우터 테이블을 사용하여 입력 패턴(perp 기호, 브리지 프로토콜 이름 등)을 기반으로 해당 하위 도메인에 전달됩니다.
Surf 계정 + SURF_API_KEY가 필요합니다. 신규 사용자는 HertzFlow 비공개 초대를 통해 2000 무료 크레딧(~6-8개 보고서)을 받습니다. 무료 등급이 만료된 후 Surf 크레딧으로 CA당 전체 포렌식 비용은 ~$1.5-3 USD입니다.
