HertzFlow معلومات قرارات التجارة على السلسلة. يغطي حاليًا الطب الشرعي لـ Binance Alpha عبر جميع سلاسل EVM لتصفح SQL (BSC / Ethereum / Arbitrum / Base / Polygon / Optimism) - التوزيع الداخلي، عمليات البيع المؤكدة، 筹码三分法 (المشغل / تجمع CEX / التجزئة التي يمكن التحقق منها)، وموجات الشذوذ، ومراقبة الصادرات. يعمل Solana في وضع HOLDER_SNAPSHOT.
يتم تشغيله تلقائيًا عندما يقوم المستخدم بلصق EVM CA أولي ببادئة 0x و40 سداسي عشري، أو Solana base58 CA، أو يذكر رمز Binance Alpha المميز بواسطة شريط، أو يسأل عن الطب الشرعي / بنية الشريحة / المطلعين الداخليين الهادئين / توزيع Alpha / التفريغ على السلسلة - حتى لو لم يقولوا "hertzflow" صراحة. يعمل خط الأنابيب بشكل حتمي (حوالي 2-10 دقائق لكل CA اعتمادًا على النشاط + حالة ذاكرة التخزين المؤقت للتصفح)؛ LLM يملأ فقط الفترات السردية، ولا يختار الحكم أو يكتب SQL أبدًا.
ستأتي مقاييس Perp، وعمليات تدقيق الجسر، والنطاقات الفرعية لتحليل العقود الأساسية لـ HertzFlow - عندما يتم شحن هذه المهارة، سيتم إرسال هذه المهارة إليهم بناءً على نمط الإدخال (رمز perp، اسم بروتوكول الجسر، وما إلى ذلك) باستخدام جدول جهاز التوجيه أدناه.
يتطلب حساب Surf + SURF_API_KEY. يحصل المستخدمون الجدد على 2000 رصيد مجاني (حوالي 6-8 تقارير) عبر دعوة HertzFlow الخاصة. تكاليف الطب الشرعي الكاملة ~ 1.5-3 دولار أمريكي لكل CA في أرصدة Surf بعد نفاد الطبقة المجانية.
