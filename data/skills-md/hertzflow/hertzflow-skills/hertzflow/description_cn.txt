HertzFlow 链上贸易决策智能。目前涵盖所有 surf-SQL EVM 链（BSC / 以太坊 / Arbitrum / Base / Polygon / Optimism）的 Binance Alpha 取证 — 内部分布、真实派发确认售空、筹码三分法（运营商 / CEX 矿池 / 可验证零售）、异常波、监控出口。 Solana 在 HOLDER_SNAPSHOT 模式下运行。
每当用户粘贴原始 0x 前缀的 40 进制 EVM CA、Solana base58 CA、通过代码提及 Binance Alpha 代币，或询问链上取证 / 内幕货运 / 派发 / 芯片结构 / 安静的内部人士 / Alpha 分布 / 链上转储时，即使他们没有明确地说“hertzflow”，也会自动触发。管道确定性运行（每个 CA 大约 2-10 分钟，具体取决于活动 + surf 缓存状态）； LLM 只填充叙述槽，从不选择判决或编写 SQL。
