HertzFlow のオンチェーン貿易決定インテリジェンス。現在、すべてのsurf-SQL EVMチェーン（BSC / Ethereum / Arbitrum / Base / Polygon / Optimism）にわたるBinance Alphaのフォレンジックをカバーしています—インサイダー流通、真实派発行確認された売り切れ、筹码三分法（オペレーター/CEXプール/検証可能な小売）、異常波、監視輸出。 Solana は HOLDER_SNAPSHOT モードで実行されます。
ユーザーが生の 0x プレフィックス付き 40 進数の EVM CA、Solana Base58 CA を貼り付けるか、ティッカーで Binance Alpha トークンに言及するか、または「hertzflow」と明示的に言わなくても、链上のフォレンジック / 内幕出货 / 分派 / チップ構造 / Quiet Insider / Alpha distribution / on-chain dump について質問するたびに自動トリガーされます。パイプラインは確定的に実行されます (アクティビティ + サーフ キャッシュの状態に応じて、CA ごとに約 2 ～ 10 分)。 LLM は物語のスロットを埋めるだけであり、評決を選択したり SQL を書いたりすることはありません。
Perp メトリクス、ブリッジ監査、HertzFlow コア コントラクト分析サブドメインが登場します。これらがリリースされると、このスキルは、以下のルーター テーブルを使用して、入力パターン (Perp シンボル、ブリッジ プロトコル名など) に基づいてそれらにディスパッチされます。
Surf アカウント + SURF_API_KEY が必要です。新規ユーザーは、HertzFlow プライベート招待を通じて 2000 の無料クレジット (最大 6 ～ 8 件のレポート) を取得します。無料利用枠が終了すると、完全なフォレンジック費用は CA あたりサーフ クレジットで ~1.5 ～ 3 米ドルかかります。
