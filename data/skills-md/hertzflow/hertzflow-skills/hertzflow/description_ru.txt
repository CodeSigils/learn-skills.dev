Онлайн-аналитика торговых решений HertzFlow. В настоящее время охватывает криминалистическую экспертизу Binance Alpha во всех цепочках EVM surf-SQL (BSC / Ethereum / Arbitrum / Base / Polygon / Optimism) — инсайдерское распространение, 真实派发 подтвержденная распродажа, 筹码三分法 (оператор / пул CEX / поддающаяся проверке розничная торговля), волны аномалий, мониторинг экспорта. Солана работает в режиме HOLDER_SNAPSHOT.
Автоматический запуск всякий раз, когда пользователь вставляет необработанный 40-шестнадцатеричный сертификат EVM с префиксом 0x, центр сертификации Solana base58, упоминает токен Binance Alpha по тикеру или спрашивает о 链上 forensic / 内幕出货 / 派发 / структуре чипа / тихом инсайдере / альфа-распределении / дампе в цепочке — даже если он явно не говорит «hertzflow». Конвейер работает детерминированно (~ 2–10 минут на каждый ЦС в зависимости от активности + состояния кэша серфинга); LLM только заполняет повествовательные места, никогда не выносит вердикт и не пишет SQL.
Скоро появятся метрики преступников, аудиты мостов и поддомены анализа основных контрактов HertzFlow — когда они будут выпущены, этот навык будет отправлен им на основе входного шаблона (символ преступника, имя протокола моста и т. д.) с использованием приведенной ниже таблицы маршрутизации.
ТРЕБУЕТСЯ учетная запись Surf + SURF_API_KEY. Новые пользователи получают 2000 бесплатных кредитов (~6-8 отчетов) по частному приглашению HertzFlow. Полная экспертиза стоит ~ 1,5–3 доллара США за CA в кредитах Surf после истечения уровня бесплатного пользования.
