On-Chain-Handelsentscheidungsinformationen von HertzFlow. Deckt derzeit die Forensik von Binance Alpha über alle Surf-SQL-EVM-Ketten ab (BSC / Ethereum / Arbitrum / Base / Polygon / Optimism) – Insider-Verteilung, bestätigter Ausverkauf, 筹码三分法 (Betreiber / CEX-Pool / nachweisbarer Einzelhandel), Anomaliewellen, Überwachung von Exporten. Solana läuft im HOLDER_SNAPSHOT-Modus.
Wird automatisch ausgelöst, wenn der Benutzer eine rohe 40-hex-EVM-CA mit 0x-Präfix oder eine Solana-Base58-CA einfügt, einen Binance-Alpha-Token per Ticker erwähnt oder nach 链上 forensic / 内幕出货 / 派发 / Chip-Struktur / Quiet Insider / Alpha-Verteilung / On-Chain-Dump fragt – auch wenn sie nicht explizit „Hertzflow“ sagen. Die Pipeline läuft deterministisch (~2–10 Minuten pro Zertifizierungsstelle, abhängig von Aktivität und Surf-Cache-Status); LLM füllt nur erzählerische Lücken, trifft niemals das Urteil und schreibt niemals SQL.
Es folgen Perp-Metriken, Bridge-Audits und HertzFlow-Kernvertragsanalyse-Subdomänen – wenn diese ausgeliefert werden, wird dieser Skill basierend auf dem Eingabemuster (Perp-Symbol, Name des Bridge-Protokolls usw.) mithilfe der unten stehenden Router-Tabelle an sie gesendet.
ERFORDERT ein Surf-Konto + SURF_API_KEY. Neue Benutzer erhalten über die private HertzFlow-Einladung 2.000 kostenlose Credits (~6–8 Berichte). Eine vollständige Forensik kostet nach Ablauf des kostenlosen Kontingents ca. 1,5–3 USD pro CA an Surf-Credits.
