Пакетная очистка структурированных записей памяти устройства (устаревшие/дубликаты/неправильные остатки/остатки шаблона). Триггерные слова: «очистить просроченные записи», «посмотреть, какие из них еще действительны», «в памяти есть повторяющиеся/старые записи». Отличается от настройки (классификация без категорий) и выпускника (архивирование + межотраслевое уточнение).
