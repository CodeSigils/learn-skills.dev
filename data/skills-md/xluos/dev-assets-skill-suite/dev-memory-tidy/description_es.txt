Limpieza por lotes de entradas estructuradas de memoria de desarrollo (obsoletas, duplicadas, erróneas o sobrantes de plantillas). Frases de activación: "borrar las caducadas", "ver cuáles aún se aplican", "la memoria tiene entradas duplicadas/antiguas". Esto difiere de la configuración (clasificación sin categorizar) y la graduación (archivado + refinamiento entre ramas).
