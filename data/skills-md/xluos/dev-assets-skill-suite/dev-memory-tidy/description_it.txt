Pulizia batch delle voci strutturate della memoria di sviluppo (residui obsoleti/duplicati/errati/modello). Parole chiave: “ripulisci quelli scaduti”, “vedi quali sono ancora validi”, “la memoria ha voci duplicate/vecchie”. Diverso da setup (classificazione senza categoria) e graduate (archiviazione + perfezionamento trasversale).
