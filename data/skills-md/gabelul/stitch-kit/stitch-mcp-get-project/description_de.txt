Ruft Metadaten für ein bestimmtes Stitch-Projekt ab – Titel, Thema, Erstellungs-/Aktualisierungszeit. Verwenden Sie diese Option, um ein Projekt zu überprüfen, bevor Sie neue Bildschirme erstellen. Verwenden Sie dies NICHT, wenn Sie bereits eine screenId haben – verwenden Sie stattdessen „stitch-mcp-get-screen“.
