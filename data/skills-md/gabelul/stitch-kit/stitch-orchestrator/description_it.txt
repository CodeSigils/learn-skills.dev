Punto di ingresso principale per tutti i flussi di lavoro di progettazione Stitch. Percorsi dalla richiesta dell'utente → specifica di progettazione → assemblaggio del prompt → generazione dello schermo → iterazione (modifica, varianti, sistemi di progettazione) → estrazione del sistema di progettazione → conversione del framework (Next.js, Svelte, HTML, React Native o SwiftUI) → passaggio di qualità opzionale.
