Point d’entrée principal pour tous les flux de travail de conception Stitch. Itinéraires depuis la demande de l'utilisateur → spécifications de conception → assemblage d'invite → génération d'écran → itération (édition, variantes, systèmes de conception) → extraction du système de conception → conversion de framework (Next.js, Svelte, HTML, React Native ou SwiftUI) → passe de qualité facultative.
