Основная точка входа для всех рабочих процессов проектирования Stitch. Маршруты от запроса пользователя → спецификация дизайна → оперативная сборка → генерация экрана → итерация (редактирование, варианты, системы дизайна) → извлечение системы дизайна → преобразование фреймворка (Next.js, Svelte, HTML, React Native или SwiftUI) → дополнительный этап проверки качества.
