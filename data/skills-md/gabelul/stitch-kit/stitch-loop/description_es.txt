Cree de forma iterativa sitios web de varias páginas utilizando Stitch. Lee next-prompt.md (el bastón), genera la siguiente página con Stitch MCP, la integra en el sitio y luego actualiza next-prompt.md para continuar el ciclo. Funciona con stitch-design-md y stitch-ui-prompt-architect para una salida consistente de varias páginas.
