Преобразует проекты Stitch в модульные компоненты Vite + React — TypeScript, Tailwind с отображением тем, темный режим с помощью переменных CSS и чистую архитектуру компонентов. Используйте это для приложений Vite/React без App Router. Для маршрутизатора приложений Next.js 15 используйте вместо этого компоненты стежка-nextjs.
