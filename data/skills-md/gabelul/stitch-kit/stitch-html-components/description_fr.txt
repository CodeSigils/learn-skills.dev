Convertit les conceptions Stitch en HTML5 + CSS propres et indépendants de la plate-forme - balisage sémantique, propriétés CSS personnalisées pour le thème, mode sombre via un schéma de couleurs préféré, réactif pour les mobiles, aucune dépendance de framework. Fonctionne dans les navigateurs, WebViews, Capacitor et Ionic.
