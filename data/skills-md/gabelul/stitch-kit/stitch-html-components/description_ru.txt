Преобразует дизайны Stitch в чистый, независимый от платформы HTML5 + CSS — семантическая разметка, пользовательские свойства CSS для тем, темный режим с использованием предпочтительной цветовой схемы, адаптация к мобильным устройствам, нулевые зависимости от платформы. Работает в браузерах, WebViews, Capacitor и Ionic.
