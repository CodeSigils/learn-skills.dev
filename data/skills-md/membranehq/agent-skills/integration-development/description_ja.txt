このスキルは、外部アプリのデータの読み取り、書き込み、同期、またはデータへの反応を行うコードを作成するときに使用します。 SaaS 製品、内部ツール、スクリプト、バッチ ジョブ、および CLI に適用されます。 The skill uses Membrane as the integration engine — it handles OAuth and credential lifecycle (authentication, token refresh, reconnect), exposes vendor operations through a uniform interface, delivers events via webhooks, generates connectors on demand for apps not yet in the workspace, and captures every action run and raw API exchange in structured logs.あらゆる外部アプリに対して動作します。
