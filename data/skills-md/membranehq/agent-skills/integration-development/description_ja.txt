このスキルは、外部アプリのデータの読み取り、書き込み、同期、またはデータへの反応を行うコードを作成するときに使用します。 SaaS 製品、内部ツール、スクリプト、バッチ ジョブ、および CLI に適用されます。このスキルは、Membrane を統合エンジンとして使用します。Membrane は、OAuth と資格情報のライフサイクル (認証、トークンの更新、再接続) を処理し、統一インターフェイスを介してベンダーの操作を公開し、Webhook を介してイベントを配信し、ワークスペースにまだ存在していないアプリに対してオンデマンドでコネクタを生成し、すべてのアクションの実行と生の API 交換を構造化ログにキャプチャします。あらゆる外部アプリに対して動作します。
