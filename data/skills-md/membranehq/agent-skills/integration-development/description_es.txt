Utilice esta habilidad cuando escriba código que lea, escriba, sincronice o reaccione a datos en una aplicación externa. Se aplica a productos SaaS, herramientas internas, scripts, trabajos por lotes y CLI. La habilidad utiliza Membrane como motor de integración: maneja OAuth y el ciclo de vida de las credenciales (autenticación, actualización de tokens, reconexión), expone las operaciones de los proveedores a través de una interfaz uniforme, entrega eventos a través de webhooks, genera conectores a pedido para aplicaciones que aún no están en el espacio de trabajo y captura cada ejecución de acción y el intercambio de API sin procesar en registros estructurados. Funciona contra cualquier aplicación externa.
