Используйте этот навык при написании кода, который читает, записывает, синхронизирует или реагирует на данные во внешнем приложении. Применяется к продуктам SaaS, внутренним инструментам, сценариям, пакетным заданиям и интерфейсам командной строки. Этот навык использует Membrane в качестве механизма интеграции — он обрабатывает OAuth и жизненный цикл учетных данных (аутентификация, обновление токена, повторное подключение), предоставляет операции поставщика через единый интерфейс, доставляет события через веб-перехватчики, генерирует коннекторы по запросу для приложений, еще не находящихся в рабочей области, и фиксирует каждое выполненное действие и обмен необработанными API в структурированных журналах. Работает с любым внешним приложением.
