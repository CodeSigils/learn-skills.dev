외부 앱의 데이터를 읽고, 쓰고, 동기화하거나 반응하는 코드를 작성할 때 이 기술을 사용하세요. SaaS 제품, 내부 도구, 스크립트, 배치 작업 및 CLI에 적용됩니다. 이 기술은 Membrane을 통합 엔진으로 사용합니다. 이는 OAuth 및 자격 증명 수명 주기(인증, 토큰 새로 고침, 재연결)를 처리하고, 균일한 인터페이스를 통해 공급업체 작업을 노출하고, 웹후크를 통해 이벤트를 전달하고, 아직 작업 공간에 없는 앱에 대한 요청 시 커넥터를 생성하고, 모든 작업 실행 및 원시 API 교환을 구조화된 로그에 캡처합니다. 모든 외부 앱에서 작동합니다.
