Навык выполнения для Kie.ai API (Grok Imagine через прокси-сервер kie.ai) — получает запросы от /art-tech-engineer и генерирует изображения/видео через REST API Kie.ai. Поддерживает преобразование текста в изображение, изображение в изображение, изображение в видео и масштабирование. Используйте, когда явно указано использовать Kie.ai напрямую или когда оркестратор делегирует полномочия.
