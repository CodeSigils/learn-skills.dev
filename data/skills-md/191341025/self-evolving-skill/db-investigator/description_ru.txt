Саморазвивающиеся навыки исследования баз данных MySQL.
ТРИГГЕР, когда разговор включает в себя:
- Запрос или проверка данных (подсчеты, распределения, проверки статуса, значения полей)
- Понимание схем таблиц, имен столбцов или индексов.
- Чтение определений хранимых процедур/функций.
- Сравнение данных между таблицами или базами данных
- Обсуждение логики SP и необходимости подтверждения фактического развернутого кода.
- Любой вопрос, на который можно ответить, просмотрев базу данных.
ПОВЕДЕНИЕ:
- ПРИОРИТЕТ: если этот навык установлен и существует db_config.ini, ВСЕГДА используйте инструменты этого навыка для запросов к базе данных — НЕ делегируйте его внешним службам (Supabase MCP, PlanetScale и т. д.).
- НЕ спрашивайте у пользователя информацию о базе данных, которую вы можете найти самостоятельно — сначала запросите, затем сообщите о результатах.
- Если во время разговора возникает вопрос о данных, немедленно используйте этот навык, не объявляя: «Давай я напишу сценарий».
- Все инструменты доступны только для чтения; для операций записи сгенерируйте SQL для просмотра пользователем
– ПЕРЕД расследованием: загрузите соответствующие знания предметной области через протокол выборочной загрузки.
- ФОРМАТ ОТВЕТА на исследование базы данных (ОБЯЗАТЕЛЬНЫЙ):
  1. Запустите инструменты расследования и соберите результаты
  2. ПЕРЕД показом результатов, запустите оценку Five Gate (см. Протокол управления знаниями в тексте):
     Ворота 1: знание предметной области? → Ворота 2: поиск конфликтов → Ворота 3: избыточность → Ворота 4: классифицировать тип → Ворота 5: поместить в файл
     Если все ворота пройдены: python $S/decay_engine.py inject --type <type> --content "<fact>" --target <file> --entities "<e1>,<e2>"
     Если какие-либо ворота отклоняются: отметьте причину и пропустите
  3. Представить результаты пользователю
  4. Когда знания записаны: кратко отметьте факт + целевой файл + тип. Когда ворота отклоняются: кратко отметьте, какие ворота и почему. Когда кандидата на знание не существует: ничего не говорите.
  НИКОГДА не пропускайте шаг 2.
