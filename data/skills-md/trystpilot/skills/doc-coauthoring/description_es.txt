Guía a los usuarios a través de un flujo de trabajo estructurado para coautoría de documentación. Úsalo cuando el usuario quiera redactar documentación, propuestas, especificaciones técnicas, documentos de decisiones o contenido estructurado similar. Este flujo de trabajo ayuda a los usuarios a transferir el contexto de manera eficiente, refinar el contenido mediante iteraciones y verificar que el documento funcione para los lectores. Se activa cuando el usuario menciona redactar documentos, crear propuestas, elaborar especificaciones o tareas de documentación similares.

Por favor, siempre responde en el idioma del usuario.
