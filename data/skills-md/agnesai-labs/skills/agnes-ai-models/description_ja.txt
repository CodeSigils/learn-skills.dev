OpenAI 互換のテキスト、画像、ビデオ、エージェント ワークフローのための Agnes AI モデル統合スキル。 Codex が Agnes AI API アクセスの構成、agnes-2.0-flash、agnes-image-2.0-flash、agnes-image-2.1-flash、および agnes-video-v2.0 を含む Agnes モデルの選択または文書化、Python/Node/curl サンプルの作成、一般的な API エラーのデバッグ、video_id によるビデオ結果のポーリング、OpenAI 互換クライアントを Agnes API ゲートウェイに適応させる、または他のエージェント向けのガイダンスを準備する必要がある場合に使用します。 OpenClaw、Hermes、Manus、カスタム エージェントなどのソフトウェア。
