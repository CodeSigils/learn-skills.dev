Compétence d'intégration de modèles Agnes AI pour les flux de travail de texte, d'image, de vidéo et d'agent compatibles OpenAI. À utiliser lorsque le Codex doit configurer l'accès à l'API Agnes AI, sélectionner ou documenter les modèles Agnes, notamment agnes-2.0-flash, agnes-image-2.0-flash, agnes-image-2.1-flash et agnes-video-v2.0, écrire des exemples Python/Node/curl, déboguer les erreurs API courantes, interroger les résultats vidéo avec video_id, adapter les clients compatibles OpenAI à la passerelle API Agnes ou préparer des conseils pour d'autres logiciels agents tels que OpenClaw, Hermes, Manus et agents personnalisés.
