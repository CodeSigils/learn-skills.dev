Агрегированный сервис API для списков тенденций в Интернете, созданный на основе проекта DailyHotApi с открытым исходным кодом, локально автоматически развертываемый и не требующий настройки доступ к данным горячего поиска в реальном времени с более чем 40 платформ. Охватывает Douyin, Weibo, Zhihu, Bilibili, Baidu, Toutiao, Kuaishou и другие основные платформы. Триггерные слова: горячие темы, тренды, тенденции, горячие списки, тренды, горячие темы.
