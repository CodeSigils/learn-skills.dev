Service API de tendances agrégées pour l'ensemble du Web, construit sur le projet open source DailyHotApi, déployé automatiquement localement et accès sans configuration aux données de recherche à chaud en temps réel provenant de plus de 40 plates-formes. Couvre TikTok, Weibo, Zhihu, Bilibili, Baidu, Toutiao, Kuaishou et d'autres plateformes grand public. Mots déclencheurs : sujets d'actualité, tendances, tendances, liste chaude, tendances, sujets d'actualité.
