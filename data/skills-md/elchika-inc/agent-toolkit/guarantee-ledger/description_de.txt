Verwenden Sie diese Option, wenn Sie ein Garantiebuch in ein Projekt einführen, eine Garantie anhängen oder die mechanische Prüfung des Buchs verkabeln. Erklären Sie ein unzerbrechliches Versprechen in einem einzigen Dokument, verknüpfen Sie es mit Implementierung und Tests und machen Sie den Ursprung dieses Versprechens (die Anweisung oder das Entscheidungsereignis) verbindlich. Auslöser: „Bürgschaftsbuch“, „Bürgschaftsbuch“, „Unzerbrechliches Verhalten im Buch aufzeichnen“, „Garantie anhängen“, „Buchprüfung hinzufügen“. Das Verfahren zur Pin-Überprüfung verwendet die Garantie-Pin-Prüfung.
