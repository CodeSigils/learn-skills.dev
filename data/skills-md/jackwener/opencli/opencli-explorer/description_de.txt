Verwenden Sie diese Option, wenn Sie einen neuen OpenCLI-Adapter von Grund auf erstellen, Unterstützung für eine neue Website oder Plattform hinzufügen oder die API-Endpunkte einer Website über Browser-DevTools erkunden. Behandelt den API-Erkennungsworkflow, die Auswahl der Authentifizierungsstrategie, das Schreiben von YAML/TS-Adaptern und das Testen.
