Verwenden Sie diese Option, wenn Sie einen OpenCLI-Adapter für eine neue Site schreiben oder einen neuen Befehl zu einer vorhandenen Site hinzufügen. Leitet durchgängig von der ersten Aufklärung über die Felddekodierung, Adapterkodierung und Überprüfung. Ersetzt opencli-oneshot / opencli-explorer. Informationen zur Ad-hoc-Browsersteuerung (kein Adapter) finden Sie stattdessen unter opencli-browser. Eine allgemeine Orientierung zu Opencli finden Sie unter opencli-usage.
