Flusso di lavoro standardizzato per la distribuzione dei prodotti assistita dall'intelligenza artificiale per trasformare una nuova idea o un repository disordinato in un ciclo di creazione disciplinato con `design-document.md`, `tech-stack.md`, `implementation-plan.md` e una `memory-bank/` persistente. Da utilizzare in Codex o Claude Code durante il bootstrap del lavoro greenfield, la normalizzazione di un repository in un processo basato sul documento o l'esecuzione dell'implementazione un passaggio convalidato alla volta con "progress.md" e "architecture.md" mantenuti aggiornati.
