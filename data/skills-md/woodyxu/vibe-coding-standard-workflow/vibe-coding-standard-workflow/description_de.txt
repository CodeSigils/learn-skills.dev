Standardisierter KI-gestützter Produktbereitstellungsworkflow zur Umwandlung einer neuen Idee oder eines chaotischen Repositorys in eine disziplinierte Build-Schleife mit „design-document.md“, „tech-stack.md“, „implementation-plan.md“ und einer dauerhaften „memory-bank/“. Verwendung in Codex oder Claude Code beim Bootstrapping von Greenfield-Arbeiten, beim Normalisieren eines Repositorys in einen Document-First-Prozess oder beim Ausführen der Implementierung jeweils einen validierten Schritt nach dem anderen, wobei „progress.md“ und „architecture.md“ aktuell gehalten werden.
