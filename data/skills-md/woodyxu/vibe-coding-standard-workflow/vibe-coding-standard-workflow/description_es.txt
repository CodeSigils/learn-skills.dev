Flujo de trabajo de entrega de productos estandarizado asistido por IA para convertir una nueva idea o un repositorio desordenado en un ciclo de compilación disciplinado con `design-document.md`, `tech-stack.md`, `implementation-plan.md` y un `memory-bank/` persistente. Úselo en Codex o Claude Code al iniciar un trabajo totalmente nuevo, normalizar un repositorio en un proceso de documento primero o ejecutar la implementación un paso validado a la vez con `progress.md` y `architecture.md` mantenidos actualizados.
