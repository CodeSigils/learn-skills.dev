Стандартизированный рабочий процесс доставки продукта с помощью искусственного интеллекта для превращения новой идеи или беспорядочного репозитория в дисциплинированный цикл сборки с помощью design-document.md, tech-stack.md,implementation-plan.md и постоянного банка памяти. Используйте в Codex или Claude Code при начальной загрузке новых проектов, нормализации репозитория в процессе, ориентированном на документ, или выполнении реализации по одному проверенному шагу за раз с сохранением текущих файлов `progress.md` и`architecture.md`.
