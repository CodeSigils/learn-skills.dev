Workshop sui materiali per l'e-commerce (bilingue cinese-inglese). Utilizzato quando gli utenti devono generare immagini principali dell'e-commerce, immagini di dettaglio, immagini di scena, composizione di immagini di prodotto e sovrapposizione del marchio. Rilevamento automatico delle categorie → corrispondenza degli stili → composizione in base alla scena → testo unificato → controllo automatico della qualità → adattamento multipiattaforma → consegna standardizzata. Studio di immagini di prodotti e-commerce: rilevamento di categorie, corrispondenza di stili, composizione in base alla scena, sovrapposizione di testo, controllo di qualità, adattamento multipiattaforma, consegna in batch.
