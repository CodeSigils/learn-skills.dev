Workshop sui materiali per l'e-commerce (bilingue cinese-inglese). Gli utenti ne hanno bisogno quando generano immagini principali di e-commerce, immagini di dettaglio, immagini di scena, composizioni di immagini di prodotto e sovrapposizioni di marchi. Rilevamento automatico delle categorie → corrispondenza degli stili → composizione in base alla scena → testo unificato → controllo automatico della qualità → adattamento multipiattaforma → consegna standardizzata. Studio di immagini di prodotti e-commerce: rilevamento di categorie, corrispondenza di stili, composizione in base alla scena, sovrapposizione di testo, controllo di qualità, adattamento multipiattaforma, consegna in batch.
