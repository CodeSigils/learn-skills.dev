Семинар по материалам для электронной коммерции (двуязычный китайский-английский). Используется, когда пользователям необходимо создавать основные изображения для электронной коммерции, подробные изображения, изображения сцен, компоновку изображений продуктов и наложение бренда. Автоматическое определение категорий → сопоставление стилей → компоновка с учетом сцен → унифицированный текст → автоматический контроль качества → адаптация к нескольким платформам → стандартизированная доставка. Студия изображений продуктов электронной коммерции: определение категорий, сопоставление стилей, компоновка с учетом сцены, наложение текста, проверка качества, адаптация к нескольким платформам, пакетная доставка.
