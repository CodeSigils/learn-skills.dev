Перенесите конечную точку TagMango из apps/api или apps/core-api на внешнюю поверхность API, что вызвано связанной проблемой GitHub. Подготавливает публичный контракт, сохраняет устаревшее поведение и размещает вариант использования с полным набором возможностей в библиотеках/службах с доступом к данным в библиотеках/репозитории, чтобы core-api мог позже заменить устаревший маршрут. Производит передачу обслуживания; никогда не пишет тесты. Для запросов только на проверку используйте Audit-external-api-port.
