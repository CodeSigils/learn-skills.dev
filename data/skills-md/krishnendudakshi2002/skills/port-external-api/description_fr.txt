Portez un point de terminaison TagMango depuis apps/api ou apps/core-api vers la surface de l'API externe, en raison d'un problème GitHub lié. Grille le contrat public, préserve le comportement hérité et obtient le cas d'utilisation complet des capacités dans les bibliothèques/services avec un accès aux données dans les bibliothèques/référentiel afin que l'api principale puisse ultérieurement remplacer la route héritée. Produit un transfert de mise en œuvre ; n'écrit jamais de tests. Pour les demandes de révision uniquement, utilisez audit-external-api-port.
