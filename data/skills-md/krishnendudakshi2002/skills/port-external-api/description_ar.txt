قم بنقل نقطة نهاية TagMango من apps/api أو apps/core-api إلى سطح API الخارجي، مدفوعًا بمشكلة GitHub المرتبطة. يشوي العقد العام، ويحافظ على السلوك القديم، ويضع حالة الاستخدام الكامل للقدرة في libs/الخدمات مع الوصول إلى البيانات في libs/repository حتى يتمكن core-api لاحقًا من استبدال المسار القديم. ينتج عملية تسليم التنفيذ؛ لا يكتب الاختبارات أبدا. بالنسبة لطلبات المراجعة فقط، استخدم منفذ Audit-external-api.
