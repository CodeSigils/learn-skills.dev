Detectar, analizar y remediar vulnerabilidades de diseño inseguro OWASP A06:2025 en aplicaciones web Python (FastAPI y Flask). Utilice esta habilidad siempre que el usuario pregunte sobre fallas de seguridad a nivel de arquitectura, modelado de amenazas, brechas de limitación de velocidad, vulnerabilidades de lógica de negocios, cargas de archivos inseguras, condiciones de carrera, fallas de aislamiento de inquilinos o aplicación de la seguridad del lado del servidor por parte del cliente. Se activa incluso si el usuario no dice "Diseño inseguro" explícitamente; las señales comunes incluyen: "falta límite de velocidad", "seguridad de carga de archivos", "fallo de lógica empresarial", "condición de carrera", "aislamiento de múltiples inquilinos", "modelado de amenazas", "STRIDE", "revisión de diseño" o "¿pueden los usuarios abusar de este flujo?". También activa revisiones de código o auditorías en las que se evalúan controles de seguridad a nivel de arquitectura, no solo errores de implementación.
