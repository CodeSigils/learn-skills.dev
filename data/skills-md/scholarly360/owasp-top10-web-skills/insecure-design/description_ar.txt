اكتشاف وتحليل ومعالجة OWASP A06:2025 ثغرات التصميم غير الآمن في تطبيقات الويب Python (FastAPI وFlask). استخدم هذه المهارة عندما يسأل المستخدم عن العيوب الأمنية على مستوى البنية، أو نمذجة التهديدات، أو فجوات تحديد المعدل، أو ثغرات منطق الأعمال، أو تحميلات الملفات غير الآمنة، أو حالات السباق، أو فشل عزل المستأجر، أو فرض الأمان من جانب العميل. يتم تشغيله حتى إذا لم يذكر المستخدم "التصميم غير الآمن" صراحةً - تتضمن الإشارات الشائعة ما يلي: "تحديد المعدل المفقود"، أو "أمان تحميل الملف"، أو "خلل في منطق العمل"، أو "حالة السباق"، أو "عزل المستأجرين المتعددين"، أو "نمذجة التهديدات"، أو "STRIDE"، أو "مراجعة التصميم"، أو "هل يمكن للمستخدمين إساءة استخدام هذا التدفق". قم أيضًا بتشغيل مراجعات التعليمات البرمجية أو عمليات التدقيق حيث يتم تقييم ضوابط الأمان على مستوى البنية، وليس فقط أخطاء التنفيذ.
