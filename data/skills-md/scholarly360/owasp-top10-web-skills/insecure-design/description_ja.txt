Python Web アプリケーション (FastAPI および Flask) の OWASP A06:2025 安全でない設計の脆弱性を検出、分析、修復します。アーキテクチャ レベルのセキュリティの欠陥、脅威モデリング、レート制限のギャップ、ビジネス ロジックの脆弱性、安全でないファイルのアップロード、競合状態、テナント分離の失敗、またはクライアント側でのサーバー側セキュリティの適用についてユーザーが質問するときは、このスキルを使用してください。ユーザーが「安全でない設計」と明示的に言わなくてもトリガーされます。一般的な信号には、「レート制限の欠如」、「ファイル アップロードのセキュリティ」、「ビジネス ロジックの欠陥」、「競合状態」、「マルチテナントの分離」、「脅威モデリング」、「STRIDE」、「設計レビュー」、または「ユーザーがこのフローを悪用できるか」が含まれます。また、実装のバグだけでなく、アーキテクチャ レベルのセキュリティ制御が評価されるコード レビューや監査もトリガーします。
