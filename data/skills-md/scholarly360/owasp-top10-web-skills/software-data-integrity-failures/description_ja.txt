OWASP A08:2025 のセキュリティ テスト スキル — Python Web アプリケーション (FastAPI および Flask) でのソフトウェアまたはデータの整合性エラー。ユーザーが、安全でない逆シリアル化 (pickle、yaml、jsonpickle、dill)、大量割り当ての欠陥、信頼できない CDN/モジュールの組み込み、署名されていない更新、CI/CD パイプラインの整合性、またはサブリソース整合性 (SRI) チェックなどの整合性の脆弱性を監査、検出、テスト、または修正したい場合は常にこのスキルを使用します。ユーザーが OWASP A08 について明示的に言及していない場合でも、ピクル/デシリアライゼーション セキュリティ、CWE-502、CWE-915、CWE-829、CWE-345、または CWE-494 を含むあらゆるタスクに対してこのスキルをトリガーします。
