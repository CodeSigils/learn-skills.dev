Capacità di test di sicurezza per OWASP A08:2025 - Errori di integrità del software o dei dati nelle applicazioni web Python (FastAPI e Flask). Utilizza questa competenza ogni volta che l'utente desidera controllare, rilevare, testare o correggere le vulnerabilità dell'integrità, tra cui: deserializzazione non sicura (pickle, yaml, jsonpickle, dill), difetti di assegnazione di massa, inclusione di moduli/CDN non attendibili, aggiornamenti non firmati, integrità della pipeline CI/CD o controlli SRI (Subresource Integrity). Attiva questa abilità per QUALSIASI attività che coinvolge la sicurezza pickle/deserializzazione, CWE-502, CWE-915, CWE-829, CWE-345 o CWE-494, anche se l'utente non menziona esplicitamente OWASP A08.
