Habilidad de prueba de seguridad para OWASP A08:2025: fallas de integridad de datos o software en aplicaciones web Python (FastAPI y Flask). Utilice esta habilidad siempre que el usuario quiera auditar, detectar, probar o reparar vulnerabilidades de integridad, incluidas: deserialización insegura (pickle, yaml, jsonpickle, dill), fallas de asignación masiva, inclusión de CDN/módulo no confiable, actualizaciones sin firmar, integridad de canalización de CI/CD o comprobaciones de integridad de subrecursos (SRI). Active esta habilidad para CUALQUIER tarea que implique seguridad de pickle/deserialización, CWE-502, CWE-915, CWE-829, CWE-345 o CWE-494, incluso si el usuario no menciona explícitamente OWASP A08.
