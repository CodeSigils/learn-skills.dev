مهارة اختبار الأمان لـ OWASP A08:2025 - فشل البرامج أو سلامة البيانات في تطبيقات الويب Python (FastAPI وFlask). استخدم هذه المهارة عندما يريد المستخدم تدقيق الثغرات الأمنية في السلامة أو اكتشافها أو اختبارها أو إصلاحها بما في ذلك: إلغاء التسلسل غير الآمن (pickle، yaml، jsonpickle، dill)، عيوب التعيين الجماعي، تضمين CDN/الوحدة النمطية غير الموثوق بها، التحديثات غير الموقعة، سلامة خط أنابيب CI/CD، أو فحوصات تكامل الموارد الفرعية (SRI). قم بتشغيل هذه المهارة لأي مهمة تتضمن أمان الاختيار/إلغاء التسلسل، CWE-502، CWE-915، CWE-829، CWE-345، أو CWE-494، حتى لو لم يذكر المستخدم صراحةً OWASP A08.
