Навыки тестирования безопасности для OWASP A08:2025 — Сбои целостности программного обеспечения или данных в веб-приложениях Python (FastAPI и Flask). Используйте этот навык всякий раз, когда пользователь хочет проверить, обнаружить, протестировать или исправить уязвимости целостности, включая: небезопасную десериализацию (pickle, yaml, jsonpickle, dill), ошибки массового назначения, ненадежное включение CDN/модуля, неподписанные обновления, целостность конвейера CI/CD или проверки целостности субресурса (SRI). Активируйте этот навык для ЛЮБОЙ задачи, связанной с безопасностью выбора/десериализации, CWE-502, CWE-915, CWE-829, CWE-345 или CWE-494, даже если пользователь явно не упоминает OWASP A08.
