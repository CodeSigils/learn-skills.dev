Détectez, auditez et corrigez les vulnérabilités liées aux erreurs de configuration de sécurité (OWASP A02:2025) dans les applications Web Python, en particulier FastAPI et Flask. Utilisez cette compétence chaque fois qu'un utilisateur pose des questions sur : le renforcement d'une application Python/FastAPI/Flask, la vérification des fuites en mode débogage, les en-têtes de sécurité manquants, les documents API exposés, les secrets codés en dur, les indicateurs de cookies non sécurisés, les vulnérabilités XXE ou tout problème de mauvaise configuration OWASP A02. Déclenchez également des tâches telles que « audit de sécurité », « préparation au test d'intrusion », « liste de contrôle de production », « rechercher des erreurs de configuration » ou « renforcer mon application ». Cette compétence couvre les modèles d'analyse statique, les vérifications d'exécution, les outils (Bandit, OWASP ZAP) et les extraits de code de correction pour chaque sous-catégorie de mauvaise configuration.
