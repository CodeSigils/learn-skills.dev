Detecte, audite y solucione vulnerabilidades de configuración incorrecta de seguridad (OWASP A02:2025) en aplicaciones web Python, especialmente FastAPI y Flask. Utilice esta habilidad siempre que un usuario pregunte sobre: ​​reforzar una aplicación Python/FastAPI/Flask, verificar fugas en el modo de depuración, encabezados de seguridad faltantes, documentos API expuestos, secretos codificados, indicadores de cookies inseguras, vulnerabilidades XXE o cualquier problema de configuración incorrecta de OWASP A02. También activa tareas como "auditoría de seguridad", "preparación de prueba de penetración", "lista de verificación de producción", "encontrar errores de configuración" o "reforzar mi aplicación". Esta habilidad cubre patrones de análisis estático, comprobaciones de tiempo de ejecución, herramientas (Bandit, OWASP ZAP) y fragmentos de código de corrección para cada subcategoría de configuración incorrecta.
