Erkennen, prüfen und beheben Sie Sicherheitslücken durch Fehlkonfigurationen (OWASP A02:2025) in Python-Webanwendungen – insbesondere FastAPI und Flask. Verwenden Sie diesen Skill immer dann, wenn ein Benutzer Folgendes fragt: Härtung einer Python-/FastAPI-/Flask-App, Überprüfung auf Lecks im Debug-Modus, fehlende Sicherheitsheader, offengelegte API-Dokumente, fest codierte Geheimnisse, unsichere Cookie-Flags, XXE-Schwachstellen oder ein Problem mit der OWASP A02-Fehlkonfiguration. Wird auch für Aufgaben wie „Sicherheitsaudit“, „Pentestvorbereitung“, „Produktionscheckliste“, „Fehlkonfigurationen finden“ oder „Meine App härten“ ausgelöst. Diese Fertigkeit umfasst statische Analysemuster, Laufzeitprüfungen, Tools (Bandit, OWASP ZAP) und Korrekturcode-Snippets für jede Unterkategorie von Fehlkonfigurationen.
