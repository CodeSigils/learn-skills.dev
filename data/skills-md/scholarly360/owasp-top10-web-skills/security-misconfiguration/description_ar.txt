اكتشاف وتدقيق ومعالجة الثغرات الأمنية المتعلقة بالتكوين الخاطئ للأمان (OWASP A02:2025) في تطبيقات الويب الخاصة بـ Python - وخاصة FastAPI وFlask. استخدم هذه المهارة عندما يسأل المستخدم عن: تقوية تطبيق Python/FastAPI/Flask، أو التحقق من تسربات وضع التصحيح، أو رؤوس الأمان المفقودة، أو مستندات API المكشوفة، أو الأسرار المشفرة، أو علامات ملفات تعريف الارتباط غير الآمنة، أو ثغرات XXE، أو أي مشكلة تتعلق بتكوين OWASP A02 بشكل خاطئ. قم أيضًا بتشغيل مهام مثل "تدقيق الأمان" أو "الإعداد لاختبار القلم" أو "قائمة التحقق من الإنتاج" أو "البحث عن التكوينات الخاطئة" أو "تقوية تطبيقي". تغطي هذه المهارة أنماط التحليل الثابت، وفحوصات وقت التشغيل، والأدوات (Bandit، OWASP ZAP)، ومقتطفات كود العلاج لكل فئة فرعية من التكوين الخاطئ.
