Rileva, verifica e risolvi le vulnerabilità legate agli errori di configurazione della sicurezza (OWASP A02:2025) nelle applicazioni Web Python, in particolare FastAPI e Flask. Utilizza questa competenza ogni volta che un utente chiede informazioni su: rafforzamento di un'app Python/FastAPI/Flask, controllo di perdite di modalità di debug, intestazioni di sicurezza mancanti, documenti API esposti, segreti codificati, flag di cookie non sicuri, vulnerabilità XXE o qualsiasi problema di configurazione errata di OWASP A02. Attiva anche attività come "controllo di sicurezza", "preparazione del pen test", "lista di controllo della produzione", "trova configurazioni errate" o "rafforzare la mia app". Questa competenza copre modelli di analisi statica, controlli di runtime, strumenti (Bandit, OWASP ZAP) e frammenti di codice di riparazione per ciascuna sottocategoria di errata configurazione.
