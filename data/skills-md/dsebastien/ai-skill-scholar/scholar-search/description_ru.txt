Ищите научные работы в arXiv, конференциях, журналах и книгах через OpenAlex. Возвращает количество цитирований, реконструированные тезисы, место проведения, ссылки на PDF-файлы с открытым доступом и внешние идентификаторы (arXiv/DOI/PMID). Ключ API не требуется. Используйте, когда пользователь говорит «искать ученого», «искать статьи», «найти статьи с цитатами», «статьи по автору», «междисциплинарный поиск» или «статьи из <места проведения>». Дополняет поиск по arxiv (только для препринтов).
