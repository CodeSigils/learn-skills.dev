Получите и проанализируйте документ arXiv с помощью многоуровневого резервного варианта (уценка -> arXiv HTML -> ar5iv -> PDF). Ограничена по скорости для arxiv2md (28 запросов/мин, детерминированный). Предоставляет структурированное резюме с указанием цитаты, проблемы, ключевых утверждений, метода, результатов и ограничений. Используйте, когда пользователь говорит «проанализировать документ arxiv», «обобщить arxiv», «прочитать документ», «что говорится в этом документе» или предоставляет идентификатор/URL-адрес arXiv для анализа.
