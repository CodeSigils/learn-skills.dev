Automatisation Web WhatsApp via Playwright et Chrome CDP. À utiliser lorsque l'utilisateur doit ouvrir WhatsApp Web, lancer le navigateur Web WhatsApp, vérifier les numéros de téléphone sur WhatsApp, envoyer des messages WhatsApp, lire les messages de discussion récents ou l'historique des discussions, lire la dernière réponse d'un contact, répertorier les discussions dans la barre latérale, compter les discussions, compter les discussions épinglées, répertorier les discussions non lues, compter les messages non lus, vérifier si un numéro est enregistré sur WhatsApp, ajouter un nouveau contact WhatsApp, enregistrer un numéro dans les contacts, automatiser la connexion Web WhatsApp ou effectuer une vérification groupée du numéro. Les déclencheurs incluent les demandes pour "ouvrir WhatsApp Web", "buka WhatsApp Web", "lancer WhatsApp", "vérifier ce numéro sur WhatsApp", "envoyer un message WhatsApp", "vérifier les numéros WhatsApp", "lire les messages WhatsApp", "lister les messages WhatsApp", "afficher le chat WhatsApp récent", "ambil pesan WhatsApp", "ouvrir le chat WhatsApp", "numéros de contrôle par lots", "lister mes chats WhatsApp", "ada berapa chat", "berapa épinglé chat", "afficher les chats épinglés", "ada berapa chat yang belum dibaca", "chats non lus", "pesan yang belum dibaca", "combien de messages non lus", "X bales apa", "apa chat terakhir X", "chat terakhir dari X", "dernière réponse de X", "qu'a dit X", "qu'a répondu X", "ajouter aux contacts", "enregistrer le contact", "ajouter un nouveau contact", "simpan kontak", "tambah kontak", "enregistrer ce numéro", "épingler le chat", "désépingler le chat", "épingler ce chat", "sematkan chat", "lepas sematan", "pin X", "unpin X", "create group", "new group", "buat grup", "bikin grup baru", "make a WhatsApp group", "delete group", "hapus grup", "bubarkan grup", "kick all member", "keluar and hapus grup", "teardown group", "quitter le groupe", "quitter le groupe", "keluar grup", "keluar dari grup", "supprimer le chat", "hapus chat", "effacer le chat", "supprimer ce chat" ou toute tâche nécessitant une interaction programmatique sur WhatsApp Web. Pour toute requête « ouvrir/lancer/buka WhatsApp Web », exécutez `scripts/login.py` SANS `--wait` — le script se termine immédiatement après l'ouverture de la fenêtre afin que l'agent reste réactif. N'utilisez jamais `--wait` à moins que l'utilisateur ne demande explicitement à l'agent d'attendre qu'il se connecte. Pour lire les messages, exécutez `scripts/read_messages.py --from <name>`. Pour la dernière réponse d'un contact (invites du type "X bales apa"), exécutez `scripts/last_reply.py --from <name>` ; ajoutez `--any-direction` si l'utilisateur veut le tout dernier message, peu importe qui l'a envoyé (des invites comme "apa chat terakhir X"). Pour lister les discussions, exécutez `scripts/list_chats.py`. Pour les discussions épinglées, exécutez `scripts/list_pinned.py`. Pour les discussions non lues, exécutez `scripts/list_unread.py`. Pour ajouter un contact (invites telles que « ajouter ce numéro aux contacts », « simpan jadi kontak »), demandez TOUJOURS à l'utilisateur son prénom, son nom (facultatif) et s'il doit synchroniser le contact avec le téléphone avant d'exécuter `scripts/add_contact.py --phone <numéro> --first-name <first> [--last-name <last>] [--sync]`. Pour épingler ou désépingler une discussion (invites telles que "épingler le chat Ezra", "sematkan chat X", "unpin X"), exécutez `scripts/pin_chat.py --to <name-or-number>` ou ajoutez `--unpin` pour désépingler. WhatsApp Web autorise au maximum 3 discussions épinglées — si l'action d'épinglage devient impossible avec « already=true », indiquez à l'utilisateur que la discussion est déjà épinglée ; Si l'épinglage échoue à cause du capuchon à 3 broches, indiquez à l'utilisateur qu'il doit d'abord détacher quelque chose. Pour quitter un groupe sans le supprimer de la liste de discussion (invites telles que "keluar grup X", "quitter le groupe X"), demandez TOUJOURS à l'utilisateur de confirmer d'abord ("Keluar dari grup X? Grup tetap ada di chat list sampai kamu hapus manual."), puis exécutez `scripts/exit_group.py --name <group-name> --confirm`. Pour supprimer un chat de la barre latérale (des invites telles que « hapus chat Ezra », « delete chat X », « clear chat »), demandez TOUJOURS à l'utilisateur de confirmer d'abord (« Hapus chat X de la barre latérale ? Ga bisa di-undo. »), puis exécutez `scripts/delete_chat.py --to <name-or-number> --confirm`. Pour les groupes actifs que vous souhaitez supprimer complètement, préférez `scripts/delete_group.py` (kick-all + exit + delete) plutôt que d'appeler exit + delete-chat séparément. Pour supprimer un groupe (invites telles que "hapus grup X", "bubarkan grup"), demandez TOUJOURS à l'utilisateur de confirmer d'abord ("Cela expulsera chaque membre, quittera le groupe et le supprimera de votre liste de discussion. Lanjut ?"). Seulement après que l'utilisateur a confirmé, exécutez `scripts/delete_group.py --name <group-name> --confirm`. Le script refuse de s'exécuter sans `--confirm`. Après son retour, signalez le champ « statut » — « supprimé » = complètement disparu ; "exited" = vous êtes absent mais la suppression n'a pas été finalisée ; "partiel" = quelque chose a échoué à mi-chemin. Lors de la création d'un nouveau groupe (invites telles que "buat grup baru", "créer un groupe"), demandez TOUJOURS à l'utilisateur le nom du groupe ET les membres. Les membres peuvent être nombreux : acceptez les entrées séparées par des virgules et demandez à nouveau (de manière répétée) si l'utilisateur a plus à ajouter, en s'arrêtant lorsqu'il signale que c'est terminé. Ensuite, exécutez `scripts/create_group.py --name <name> --members <a,b,c> [--members ...]`. Une fois le script renvoyé, vérifiez le tableau « échec » : si un membre n'a pas réussi à correspondre à un contact, indiquez à l'utilisateur lesquels afin qu'il puisse les ajouter manuellement plus tard. Gardez toujours des réponses conviviales et non techniques (dites « Ouverture de WhatsApp Web... » au lieu de « Démarrage de Chrome avec CDP »).
