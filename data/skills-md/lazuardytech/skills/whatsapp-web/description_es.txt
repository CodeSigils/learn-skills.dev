Automatización web de WhatsApp a través de Playwright y Chrome CDP. Úselo cuando el usuario necesite abrir WhatsApp Web, iniciar el navegador web de WhatsApp, verificar números de teléfono en WhatsApp, enviar mensajes de WhatsApp, leer mensajes de chat recientes o el historial de chat, leer la última respuesta de un contacto, enumerar chats en la barra lateral, contar chats, contar chats anclados, enumerar chats no leídos, contar mensajes no leídos, verificar si un número está registrado en WhatsApp, agregar un nuevo contacto de WhatsApp, guardar un número en los contactos, automatizar el inicio de sesión en WhatsApp Web o realizar una verificación masiva de números. Los activadores incluyen solicitudes para "abrir WhatsApp Web", "buka WhatsApp Web", "iniciar WhatsApp", "verificar este número en WhatsApp", "enviar un mensaje de WhatsApp", "verificar números de WhatsApp", "leer mensajes de WhatsApp", "enumerar mensajes de WhatsApp", "mostrar chat reciente de WhatsApp", "ambil pesan WhatsApp", "abrir chat de WhatsApp", "verificar números por lotes", "enumerar mis chats de WhatsApp", "ada berapa chat", "berapa pinned chat", "mostrar chats anclados", "ada berapa chat yang belum dibaca", "chats no leídos", "pesan yang belum dibaca", "cuántos mensajes no leídos", "X bales apa", "apa chat terakhir X", "chat terakhir dari X", "última respuesta de X", "qué dijo X", "qué respondió X", "agregar a contactos", "guardar contacto", "agregar nuevo contacto", "simpan kontak", "tambah kontak", "guardar este número", "fijar chat", "desfijar" chat", "fijar este chat", "sematkan chat", "lepas sematan", "fijar X", "desfijar X", "crear grupo", "nuevo grupo", "buat grup", "bikin grup baru", "crear un grupo de whatsapp", "eliminar grupo", "hapus grup", "bubarkan grup", "expulsar a todos los miembros", "keluar dan hapus grup", "desmontar grupo", "salir de grupo", "dejar grupo", "keluar grup", "keluar dari grup", "eliminar chat", "hapus chat", "borrar chat", "eliminar este chat" o cualquier tarea que requiera interacción programática de WhatsApp Web. Para cualquier solicitud de "abrir/iniciar/buka WhatsApp Web", ejecute `scripts/login.py` SIN `--wait`: el script sale inmediatamente después de abrir la ventana para que el agente siga respondiendo. Nunca use `--wait` a menos que el usuario le pida explícitamente al agente que espere a que inicie sesión. Para leer mensajes, ejecute `scripts/read_messages.py --from <nombre>`. Para la última respuesta de un contacto (mensajes como "X bales apa"), ejecute `scripts/last_reply.py --from <nombre>`; agregue `--any-direction` si el usuario quiere el último mensaje independientemente de quién lo envió (mensajes como "apa chat terakhir X"). Para enumerar chats, ejecute `scripts/list_chats.py`. Para chats anclados, ejecute `scripts/list_pinned.py`. Para chats no leídos, ejecute `scripts/list_unread.py`. Para agregar un contacto (indicaciones como "agregar este número a los contactos", "simpan jadi kontak"), SIEMPRE pregunte al usuario el nombre, el apellido (opcional) y si desea sincronizar el contacto con el teléfono antes de ejecutar `scripts/add_contact.py --phone <número> --first-name <primero> [--last-name <apellido>] [--sync]`. Para anclar o desanclar un chat (mensajes como "fijar chat Ezra", "sematkan chat X", "desanclar X"), ejecute `scripts/pin_chat.py --to <nombre-o-número>` o agregue `--unpin` para desanclar. WhatsApp Web permite como máximo 3 chats anclados: si la acción de anclar no funciona con "already=true", dígale al usuario que el chat ya está anclado; Si la fijación falla debido a la tapa de 3 pines, dígale al usuario que primero debe desanclar algo. Para salir de un grupo sin eliminarlo de la lista de chat (mensajes como "keluar grup X", "dejar el grupo X"), SIEMPRE pida al usuario que confirme primero ("Keluar dari grup X? Grup tetap ada di chat list sampai kamu hapus manual."), luego ejecute `scripts/exit_group.py --name <group-name> --confirm`. Para eliminar un chat de la barra lateral (mensajes como "hapus chat Ezra", "eliminar chat X", "borrar chat"), SIEMPRE pida al usuario que confirme primero ("¿Hapus chat X dari sidebar? Ga bisa di-undo."), luego ejecute `scripts/delete_chat.py --to <nombre-o-número> --confirm`. Para los grupos activos que desea eliminar por completo, prefiera `scripts/delete_group.py` (kick-all + salir + eliminar) en lugar de llamar a salir + eliminar-chat por separado. Para eliminar un grupo (mensajes como "hapus grup X", "bubarkan grup"), SIEMPRE pida al usuario que confirme primero ("Esto expulsará a todos los miembros, saldrá del grupo y los eliminará de su lista de chat. ¿Lanjut?"). Solo después de que el usuario confirme, ejecute `scripts/delete_group.py --name <nombre-grupo> --confirm`. El script se niega a ejecutarse sin "--confirm". Después de que regrese, informe el campo `estado`: "eliminado" = desaparecido por completo; "exited" = estás fuera pero la eliminación no finalizó; "parcial" = algo falló a mitad del camino. Al crear un nuevo grupo (mensajes como "buat grup baru", "crear un grupo"), SIEMPRE pregunte al usuario el nombre del grupo Y los miembros. Los miembros pueden ser muchos: acepte entradas separadas por comas y pregunte nuevamente (repetidamente) si el usuario tiene más que agregar, deteniéndose cuando indique que ha terminado. Luego ejecute `scripts/create_group.py --name <nombre> --members <a,b,c> [--members...]`. Después de que regrese el script, verifique la matriz "fallida": si algún miembro no pudo hacer coincidir un contacto, dígale al usuario cuáles para que pueda agregarlos manualmente más tarde. Mantenga siempre respuestas fáciles de usar y no técnicas (diga "Abrir WhatsApp Web..." en lugar de "Iniciar Chrome con CDP").
