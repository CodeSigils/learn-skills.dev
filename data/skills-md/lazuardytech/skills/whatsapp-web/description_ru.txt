Веб-автоматизация WhatsApp с помощью Playwright и Chrome CDP. Используйте, когда пользователю необходимо открыть WhatsApp Web, запустить веб-браузер WhatsApp, проверить номера телефонов в WhatsApp, отправить сообщения WhatsApp, прочитать последние сообщения чата или историю чата, прочитать последний ответ от контакта, составить список чатов на боковой панели, подсчитать чаты, подсчитать закрепленные чаты, составить список непрочитанных чатов, подсчитать непрочитанные сообщения, проверить, зарегистрирован ли номер в WhatsApp, добавить новый контакт WhatsApp, сохранить номер в контактах, автоматизировать вход в WhatsApp Web или выполнить массовую проверку номера. Триггеры включают запросы «открыть WhatsApp Web», «buka WhatsApp Web», «запустить WhatsApp», «проверить этот номер в WhatsApp», «отправить сообщение WhatsApp», «проверить номера WhatsApp», «прочитать сообщения WhatsApp», «составить список сообщений WhatsApp», «показать недавний чат WhatsApp», «ambil pesan WhatsApp», «открыть чат WhatsApp», «пакетная проверка номеров», «составить список моих чатов WhatsApp», «чат ada berapa», «закрепленный чат berapa», «показать закрепленные чаты», «чат ada berapa yang» belum dibaca", "непрочитанные чаты", "pesan yang belum dibaca", "сколько непрочитанных сообщений", "X bales apa", "apachat terakhir X", "chat terakhir dari X", "последний ответ от X", "что сказал X", "что ответил X", "добавить в контакты", "сохранить контакт", "добавить новый контакт", "simpan kontak", "tambah kontak", "сохранить этот номер", "закрепить" чат", "открепить чат", "закрепить этот чат", "sematkanchat", "lepas sematan", "закрепить X", "открепить X", "создать группу", "новая группа", "buat grup", "bikin grup baru", "создать группу WhatsApp", "удалить группу", "hapus grup", "bubarkan grup", "выгнать всех участников", "keluar dan hapus grup", "снести группу", "выйти из группы", "выйти" группа», «келуар группа», «келуар дари группа», «удалить чат», «чат хапус», «очистить чат», «удалить этот чат» или любая задача, требующая программного взаимодействия с веб-сайтом WhatsApp. Для любого запроса «открыть/запустить/бука WhatsApp Web» запускайте `scripts/login.py` БЕЗ `--wait` — скрипт завершается сразу после открытия окна, поэтому агент продолжает отвечать на запросы. Никогда не используйте `--wait`, если только пользователь явно не попросит агента дождаться его входа в систему. Для чтения сообщений запустите `scripts/read_messages.py --from <name>`. Чтобы получить последний ответ от контакта (запрос типа «X bales apa»), запустите `scripts/last_reply.py --from <name>`; добавьте `--any-direction`, если пользователю нужно самое последнее сообщение, независимо от того, кто его отправил (подсказка типа «апа чат терахир X»). Чтобы просмотреть чаты, запустите `scripts/list_chats.py`. Для закрепленных чатов запустите `scripts/list_pinned.py`. Для непрочитанных чатов запустите `scripts/list_unread.py`. Для добавления контакта (запросы типа «добавить этот номер в контакты», «simpan jadi kontak») ВСЕГДА спрашивайте у пользователя имя, фамилию (необязательно) и нужно ли синхронизировать контакт с телефоном перед запуском `scripts/add_contact.py --phone <number> --first-name <first> [--last-name <last>] [--sync]`. Чтобы закрепить или открепить чат (например, «закрепить чат Эзры», «сематкан чат X», «открепить X»), запустите `scripts/pin_chat.py --to <имя-или-номер>` или добавьте `--unpin` для открепления. WhatsApp Web допускает не более трех закрепленных чатов — если действие закрепления становится неактивным с `already=true`, сообщите пользователю, что чат уже закреплен; Если закрепление не удалось из-за 3-контактного колпачка, сообщите пользователю, что ему нужно сначала что-то открепить. Чтобы выйти из группы, не удаляя ее из списка чата (запросы типа «keluar grup X», «покинуть группу X»), ВСЕГДА сначала просите пользователя подтвердить («Keluar dari grup X? Grup tetap ada di Chat List sampai kamu hapus manual»), а затем запускайте `scripts/exit_group.py --name <group-name> --confirm`. Для удаления чата с боковой панели (подсказки типа «Hapus Chat Ezra», «Удалить чат X», «Очистить чат») ВСЕГДА просите пользователя сначала подтвердить («Hapus Chat X dari Sidebar? Ga bisa di-Undo.»), а затем запускайте `scripts/delete_chat.py --to <имя-или-номер> --confirm`. Для активных групп, которые вы хотите полностью удалить, предпочтите `scripts/delete_group.py` (выкинуть все + выход + удаление) вместо отдельного вызова выхода + удаления чата. Для удаления группы (запросы типа «hapus grup X», «bubarkan grup») ВСЕГДА просите пользователя сначала подтвердить («Это выгонит каждого участника, выйдет из группы и удалит его из списка чата. Ланют?). Только после того, как пользователь подтвердит, запустите `scripts/delete_group.py --name <group-name> --confirm`. Скрипт отказывается запускаться без `--confirm`. После того, как он вернется, сообщите об этом поле `status` — «deleted» = полностью исчезло; «exited» = вы вышли, но удаление не завершилось; «частичный» = что-то не удалось на полпути. При создании новой группы (запросы типа «buat grup baru», «создать группу») ВСЕГДА спрашивайте у пользователя название группы И ее участников. Участников может быть много — примите ввод, разделенный запятыми, и спросите еще раз (повторяемо), есть ли у пользователя что-то добавить, останавливаясь, когда он сигнализирует о завершении. Затем запустите `scripts/create_group.py --name <name> --members <a,b,c> [--members ...]`. После завершения выполнения сценария проверьте массив `failed` — если какой-либо элемент не соответствует контакту, сообщите пользователю, какие из них, чтобы он мог добавить их вручную позже. Всегда отвечайте дружелюбно и нетехнически (например, «Открытие WhatsApp Web...» вместо «Запуск Chrome с помощью CDP»).
