Verwenden Sie „--wait“ niemals, es sei denn, der Benutzer fordert den Agenten ausdrücklich auf, auf die Anmeldung zu warten. Führen Sie zum Lesen von Nachrichten „scripts/read_messages.py --from <name>“ aus. Fügen Sie „--any-direction“ hinzu, wenn der Benutzer die allerletzte Nachricht haben möchte, unabhängig davon, wer sie gesendet hat (Eingabeaufforderungen wie „apa chat terakhir X“). Um Chats aufzulisten, führen Sie „scripts/list_chats.py“ aus. Führen Sie für angepinnte Chats „scripts/list_pinned.py“ aus. Führen Sie für ungelesene Chats „scripts/list_unread.py“ aus. Wenn Sie eine neue Gruppe erstellen (Eingabeaufforderungen wie „buat grup baru“, „Gruppe erstellen“), fragen Sie den Benutzer IMMER nach dem Gruppennamen UND den Mitgliedern. Mitglieder können viele sein – akzeptieren Sie durch Kommas getrennte Eingaben und fragen Sie erneut (wiederholt), ob der Benutzer noch mehr hinzufügen möchte, und hören Sie auf, wenn er den Vorgang abgeschlossen hat. Führen Sie dann „scripts/create_group.py --name <name> --members <a,b,c> [--members ...]“ aus. Nachdem das Skript zurückgekehrt ist, überprüfen Sie das Array „failed“ – wenn ein Mitglied nicht mit einem Kontakt übereinstimmt, teilen Sie dem Benutzer mit, um welche es sich handelt, damit er sie später manuell hinzufügen kann. Halten Sie die Antworten immer benutzerfreundlich und nicht technisch (sagen Sie „WhatsApp Web öffnen…“ statt „Chrome mit CDP starten“).
