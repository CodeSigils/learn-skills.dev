Inicia un kit de documentación de colaboración entre IA y humanos para cualquier base de código mediante la creación de diagramas de arquitectura en capas, catálogos de superficies de integración, modelos de datos conceptuales con ER SVG, conciliación de inconsistencias, generación de raíz CLAUDE.md y adición de una habilidad de deriva de documentos de solo lectura. Úselo cuando el usuario solicite una infraestructura de colaboración de IA completa, arranque de documentación automatizado, arquitectura más catálogo de API más entregables del modelo de datos, o repetir el manual de documentación de habilidades sofisticadas en otro repositorio.
