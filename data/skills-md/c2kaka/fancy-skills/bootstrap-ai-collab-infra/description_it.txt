Avvia un kit di documentazione di collaborazione uomo-intelligenza artificiale per qualsiasi base di codice creando diagrammi di architettura a più livelli, cataloghi di superfici di integrazione, modelli di dati concettuali con ER SVG, riconciliando incoerenze, generando root CLAUDE.md e aggiungendo una capacità di deriva dei documenti di sola lettura. Da utilizzare quando l'utente richiede un'infrastruttura di collaborazione AI completa, bootstrap automatizzato della documentazione, architettura più catalogo API più risultati finali del modello dati o ripetizione del playbook della documentazione con competenze fantasiose su un altro repository.
