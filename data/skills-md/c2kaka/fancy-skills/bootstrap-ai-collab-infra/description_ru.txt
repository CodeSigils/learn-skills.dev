Создает комплект документации для совместной работы искусственного интеллекта и человека для любой базы кода, создавая диаграммы многоуровневой архитектуры, каталоги поверхностей интеграции, концептуальные модели данных с помощью ER SVG, устраняя несоответствия, создавая корневой файл CLAUDE.md и добавляя навык дрейфа документов, доступный только для чтения. Используйте, когда пользователь запрашивает полную инфраструктуру для совместной работы с искусственным интеллектом, автоматическую загрузку документации, архитектуру, каталог API и результаты модели данных или повторение набора документации по необычным навыкам в другом репозитории.
