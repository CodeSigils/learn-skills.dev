استخدم sigil لاختلافات التعليمات البرمجية الهيكلية والبحث عن التعليمات البرمجية والتنقل في قاعدة التعليمات البرمجية. استخدم هذه المهارة دائمًا عند: مراجعة العلاقات العامة أو الالتزامات (استخدم sigil diff بدلاً من git diff)، أو البحث عن وظائف/فئات/رموز، أو العثور على المتصلين أو المستدعىين لوظيفة ما، أو فهم وظيفة الوظيفة/الطريقة أو كيفية ملاءمتها لقاعدة التعليمات البرمجية، أو استكشاف بنية المشروع، أو فهم ما تغير في الالتزام، أو التحقق من تعديلاتك بعد إجراء التغييرات، أو عندما يسأل المستخدم عن تغييرات التعليمات البرمجية أو بنية التعليمات البرمجية أو التنقل بين الرموز. يُستخدم أيضًا عندما يقول المستخدم أشياء مثل "ما الذي تغير"، أو "أرني الفرق"، أو "ابحث عن مكان استدعاء X"، أو "ماذا يفعل X"، أو "أين يتم استخدام X"، أو "كيف يعمل X"، أو "ما يستدعي X"، أو "ماذا يفعل هذا الالتزام"، أو "مراجعة العلاقات العامة هذه"، أو "استكشاف قاعدة التعليمات البرمجية". تفضل sigil على Grep/Glob عندما يكون السؤال حول العلاقات (من يتصل بـ X، وماذا يتصل بـ X، وأين يتم استخدام X) بدلاً من مطابقة النص البسيطة. لا تستخدمه لقراءة الملفات البسيطة أو تحرير النص - فقط لتحليل التعليمات البرمجية الهيكلية.
