구조적 코드 차이, 코드 검색 및 코드베이스 탐색에 sigil을 사용하세요. PR 또는 커밋 검토(`git diff` 대신 `sigil diff` 사용), 함수/클래스/기호 검색, 함수의 호출자 또는 피호출자 찾기, 함수/메서드의 기능 또는 코드베이스에 어떻게 적용되는지 이해, 프로젝트 구조 탐색, 커밋에서 변경된 내용 이해, 변경 후 자신의 편집 내용 확인, 사용자가 코드 변경, 코드 구조 또는 기호 탐색에 대해 문의할 때 항상 이 기술을 사용하세요. 또한 사용자가 '변경된 내용', '차이점 표시', 'X가 호출되는 위치 찾기', 'X가 수행하는 작업', 'X가 사용되는 위치', 'X는 어떻게 작동합니까', 'X를 호출하는 작업', '이 커밋의 기능은 무엇입니까', '이 PR 검토' 또는 '코드베이스 탐색'과 같은 말을 할 때 사용합니다. 질문이 단순한 텍스트 일치보다는 관계(X를 호출하는 사람, X가 호출하는 대상, X가 사용되는 위치)에 관한 질문인 경우 Grep/Glob보다 sigil을 선호합니다. 단순한 파일 읽기나 텍스트 편집에는 사용하지 마십시오. 구조 코드 분석에만 사용하십시오.
