Utilisez sigil pour les différences de code structurel, la recherche de code et la navigation dans la base de code. Utilisez TOUJOURS cette compétence lorsque : vous révisez des PR ou des commits (utilisez « sigil diff » au lieu de « git diff »), recherchez des fonctions/classes/symboles, trouvez des appelants ou des appelés d'une fonction, comprenez ce que fait une fonction/méthode ou comment elle s'intègre dans la base de code, explorez la structure du projet, comprenez ce qui a changé dans une validation, vérifiez vos propres modifications après avoir apporté des modifications, ou lorsque l'utilisateur pose des questions sur les modifications du code, la structure du code ou la navigation dans les symboles. À utiliser également lorsque l'utilisateur dit des choses comme « ce qui a changé », « montre-moi la différence », « trouver où X est appelé », « que fait X », « où X est-il utilisé », « comment X fonctionne », « qu'est-ce qui appelle X », « que fait ce commit », « examiner ce PR » ou « explorer la base de code ». Préférez sigil à Grep/Glob lorsque la question porte sur les relations (qui appelle X, qu'appelle X, où X est-il utilisé) plutôt que sur une simple correspondance de texte. Ne PAS utiliser pour une simple lecture de fichiers ou pour l’édition de texte – uniquement pour l’analyse du code structurel.
