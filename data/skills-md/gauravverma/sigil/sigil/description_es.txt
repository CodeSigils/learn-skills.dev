Utilice sigil para diferencias de código estructural, búsqueda de código y navegación de base de código. SIEMPRE use esta habilidad cuando: revise PR o confirmaciones (use `sigil diff` en lugar de `git diff`), busque funciones/clases/símbolos, encuentre personas que llaman o destinatarios de una función, comprenda qué hace una función/método o cómo encaja en la base del código, explore la estructura del proyecto, comprenda qué cambió en una confirmación, verifique sus propias ediciones después de realizar cambios o cuando el usuario pregunte sobre cambios de código, estructura de código o navegación de símbolos. También se usa cuando el usuario dice cosas como "qué cambió", "muéstrame la diferencia", "busca dónde se llama X", "qué hace X", "dónde se usa X", "cómo funciona X", "qué llama a X", "qué hace este compromiso", "revisa este PR" o "explora el código base". Prefiera sigil a Grep/Glob cuando la pregunta es sobre relaciones (quién llama a X, cómo llama X, dónde se usa X) en lugar de una simple coincidencia de texto. NO lo use para lectura simple de archivos o edición de texto, solo para análisis de código estructural.
