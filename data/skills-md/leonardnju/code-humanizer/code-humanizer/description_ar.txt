يُستخدم عندما تتم كتابة التعليمات البرمجية بواسطة وكيل ترميز الذكاء الاصطناعي ويحتاج إلى تنظيف هيكلي - عمليات إعادة تنفيذ مكررة للمساعدين الحاليين، أو محاولات الاستيراد الاحتياطية، أو ابتلاع الاستثناءات الواسعة، أو طبقات التجريد التأملية، أو نسخ _v2، أو التعليمات البرمجية الميتة "للاستخدام المستقبلي"، أو سرد التعليقات - أو عندما يُطلب منك "إزالة انحدار الذكاء الاصطناعي"، أو "إضفاء طابع إنساني على التعليمات البرمجية"، أو تنظيف الريبو المشفر، أو مراجعة العلاقات العامة التي تم إنشاؤها بواسطة الذكاء الاصطناعي لجودة التعليمات البرمجية بما يتجاوز اجتياز الاختبارات.
