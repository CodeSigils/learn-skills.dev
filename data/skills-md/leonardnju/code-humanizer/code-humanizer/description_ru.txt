Используйте, когда код был написан агентом ИИ-кодирования и нуждается в структурной очистке — дублированные повторные реализации существующих помощников, резервные копии при попытке импорта, широкое поглощение исключений, спекулятивные уровни абстракции, копии _v2, мертвый код «для будущего использования», комментирование комментариев — или когда вас просят «удалить», «удалить ненужные ИИ», «очеловечить код», очистить репозиторий с кодом Vibe или просмотреть созданный ИИ PR на предмет качества кода после прохождения тестов.
