開発者が、どの Slack Web API メソッドが何かを行うかを尋ねる場合、メソッドの OAuth スコープまたはトークン タイプが必要な場合、family.method エンドポイント (chat.postMessage、versations.history、users.info、views.open) の呼び出しまたはテストを希望する場合、カーソル ページネーション (next_cursor) またはレート制限 (tier/ratelimited/Retry-After) を処理する場合、または missing_scope、invalid_auth、channel_not_found などのエラーをデバッグする場合に使用します。また、貼り付けたslack.com/api/ URLまたはdocs.slack.dev/reference/methodsリンクでもトリガーします。
