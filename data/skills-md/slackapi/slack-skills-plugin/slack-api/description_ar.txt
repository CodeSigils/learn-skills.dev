يُستخدم عندما يسأل أحد المطورين عن طريقة Slack Web API التي تفعل شيئًا ما، أو يحتاج إلى نطاقات OAuth الخاصة بالطريقة أو نوع الرمز المميز، أو يريد الاتصال أو اختبار نقطة نهاية Family.method (chat.postMessage، communication.history، users.info، views.open)، أو يتعامل مع ترقيم الصفحات للمؤشر (next_cursor) أو حدود المعدل (الطبقة/المعدل/إعادة المحاولة بعد)، أو يقوم بتصحيح أخطاء مثل Missing_scope، valid_auth، أوchannel_not_found. قم أيضًا بالتشغيل على عنوان URL الخاص بـ slack.com/api/ أو رابط docs.slack.dev/reference/methods.
