개발자가 어떤 Slack 웹 API 메소드가 작업을 수행하는지 묻거나, 메소드의 OAuth 범위 또는 토큰 유형이 필요하거나, family.method 엔드포인트(chat.postMessage, Conversation.history, users.info, views.open)를 호출하거나 테스트하려고 하거나, 커서 페이지 매김(next_cursor) 또는 속도 제한(tier/ratelimited/Retry-After)을 처리 중이거나, Missing_scope, Invalid_auth 또는 Channel_not_found와 같은 오류를 디버깅할 때 사용합니다. 또한 붙여넣은 slack.com/api/ URL 또는 docs.slack.dev/reference/methods 링크에서 트리거합니다.
