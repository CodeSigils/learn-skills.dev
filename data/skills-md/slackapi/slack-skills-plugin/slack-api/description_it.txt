Da utilizzare quando uno sviluppatore chiede quale metodo API Web Slack fa qualcosa, ha bisogno degli ambiti OAuth o del tipo di token di un metodo, vuole chiamare o testare un endpoint family.method (chat.postMessage, conversazioni.history, users.info, views.open), sta gestendo l'impaginazione del cursore (next_cursor) o i limiti di velocità (tier/ratelimited/Retry-After) o sta eseguendo il debug di errori come Missing_scope, invalid_auth o channel_not_found. Attiva anche un collegamento slack.com/api/ URL o docs.slack.dev/reference/methods incollato.
