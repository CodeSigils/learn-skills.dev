Úselo cuando un desarrollador pregunta qué método de Slack Web API hace algo, necesita los alcances OAuth o el tipo de token de un método, quiere llamar o probar un punto final family.method (chat.postMessage, conversaciones.history, usuarios.info, views.open), está manejando la paginación del cursor (next_cursor) o límites de velocidad (tier/ratelimited/Retry-After), o está depurando errores como miss_scope, invalid_auth o canal_no_encontrado. También se activa en una URL pegada de slack.com/api/ o docs.slack.dev/reference/methods.
