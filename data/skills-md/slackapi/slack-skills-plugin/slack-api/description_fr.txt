À utiliser lorsqu'un développeur demande quelle méthode de l'API Web Slack fait quelque chose, a besoin des étendues OAuth ou du type de jeton d'une méthode, souhaite appeler ou tester un point de terminaison family.method (chat.postMessage, conversations.history, users.info, vues.open), gère la pagination du curseur (next_cursor) ou les limites de débit (tier/ratelimited/Retry-After), ou débogue des erreurs telles que Missing_scope, invalid_auth ou Channel_not_found. Déclenchez également sur une URL slack.com/api/ ou docs.slack.dev/reference/methods collée.
