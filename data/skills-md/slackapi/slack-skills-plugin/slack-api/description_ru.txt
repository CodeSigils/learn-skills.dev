Используйте, когда разработчик спрашивает, какой метод Slack Web API что-то делает, ему нужны области OAuth или тип токена метода, он хочет вызвать или протестировать конечную точку Family.method (chat.postMessage, разговоры.история, пользователи.информация, представления.open), обрабатывает нумерацию страниц курсора (next_cursor) или ограничения скорости (tier/ratelimited/Retry-After) или отлаживает ошибки, такие как Missing_scope, Invalid_auth или канал_не_найден. Также активируется по вставленному URL-адресу slack.com/api/ или ссылке docs.slack.dev/reference/methods.
