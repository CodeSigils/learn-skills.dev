Wird verwendet, wenn ein Entwickler fragt, welche Slack-Web-API-Methode etwas tut, die OAuth-Bereiche oder den Token-Typ einer Methode benötigt, einen Family.method-Endpunkt (chat.postMessage, conversations.history, Users.info, Views.open) aufrufen oder testen möchte, Cursor-Paginierung (next_cursor) oder Ratenbegrenzungen (tier/ratelimited/Retry-After) verarbeitet oder Fehler wie fehlender_Bereich, ungültige_auth oder Kanal_not_found debuggt. Wird auch durch eine eingefügte slack.com/api/-URL oder einen docs.slack.dev/reference/methods-Link ausgelöst.
