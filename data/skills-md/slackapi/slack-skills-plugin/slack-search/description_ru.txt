Используйте для поиска сообщений, файлов, каналов или людей в Slack или для сбора контекста перед ответом с помощью инструментов поиска MCP (slack_search_public, slack_search_public_and_private, slack_search_channels, slack_search_users). Охватывает модификаторы поиска (in:, from:, before:), фильтры типов файлов, поиск на естественном языке по сравнению с поиском по ключевым словам и чтение результатов в контексте.
