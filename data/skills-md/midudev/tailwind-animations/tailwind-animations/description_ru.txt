Используйте пакет NPM Tailwind-Animations (плагин Tailwind CSS v4, предназначенный только для CSS), чтобы добавить готовые утилиты анимации: затухание, скольжение, масштабирование, переворот, отскок, желе, вход/выход из диалога, прокрутка/просмотр временной шкалы, продолжительность/задержка/шаги/итерация/режим заполнения и анимация-слайд-дистанция. Используйте, когда пользователю нужны CSS-анимации с помощью Tailwind, классов animate-*, утилит движения, анимации диалогов, движения CSS с помощью прокрутки или для установки/настройки анимации Tailwind. Триггеры: «анимация попутного ветра», «animate-fade-in», «animate-dialog», «slide-distance», «плагин движения попутного ветра», /tailwind-animations.
