Utilizza il pacchetto tailwind-animations npm (plug-in Tailwind CSS v4 solo CSS) per aggiungere utilità di animazione già pronte: dissolvenza, diapositiva, zoom, capovolgimento, rimbalzo, gelatina, entrata/uscita dalla finestra di dialogo, scorrimento/visualizzazione di sequenze temporali, durata/ritardo/passaggi/iterazione/modalità di riempimento e animazione-slide-distance. Da utilizzare quando l'utente desidera animazioni CSS con Tailwind, classi animate-*, utilità di movimento, animazioni di finestre di dialogo, movimento CSS basato su scorrimento o per installare/configurare animazioni tailwind. Trigger: "animazioni tailwind", "animate-fade-in", "animate-dialog", "slide-distance", "tailwind motion plugin", /tailwind-animations.
