استخدم حزمة Tailwind-animations npm (المكون الإضافي Tailwind CSS v4 فقط لـ CSS) لإضافة أدوات مساعدة للرسوم المتحركة الجاهزة: التلاشي، والانزلاق، والتكبير/التصغير، والقلب، والارتداد، والهلام، وإدخال/خروج الحوار، والتمرير/العرض، والمخططات الزمنية، والمدة/التأخير/الخطوات/التكرار/وضع التعبئة، وتحريك مسافة الشريحة. يُستخدم عندما يريد المستخدم رسوم CSS المتحركة باستخدام Tailwind، أو فئات animate-*، أو أدوات الحركة المساعدة، أو الرسوم المتحركة للحوار، أو حركة CSS التي تعتمد على التمرير، أو لتثبيت/تكوين الرسوم المتحركة للرياح الخلفية. المشغلات: "الرسوم المتحركة للرياح الخلفية"، و"تضاؤل ​​الرسوم المتحركة"، و"مربع الحوار المتحرك"، و"مسافة الشريحة"، و"المكون الإضافي لحركة الريح الخلفية"، و/الرسوم المتحركة للرياح الخلفية.
