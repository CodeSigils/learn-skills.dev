Utilisez le package npm tailwind-animations (plugin Tailwind CSS v4 uniquement CSS) pour ajouter des utilitaires d'animation prêts à l'emploi : fondu, glissement, zoom, retournement, rebond, gelée, entrée/sortie de boîte de dialogue, défilement/affichage des chronologies, durée/délai/étapes/itération/mode de remplissage et animation-slide-distance. À utiliser lorsque l'utilisateur souhaite des animations CSS avec Tailwind, des classes animate-*, des utilitaires de mouvement, des animations de dialogue, des mouvements CSS pilotés par défilement ou pour installer/configurer des animations tailwind. Déclencheurs : "animations tailwind", "animate-fade-in", "animate-dialog", "slide-distance", "tailwind motion plugin", /tailwind-animations.
