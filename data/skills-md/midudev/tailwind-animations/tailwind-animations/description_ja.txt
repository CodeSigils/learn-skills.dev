tailwind-animations npm パッケージ (CSS のみの Tailwind CSS v4 プラグイン) を使用して、フェード、スライド、ズーム、フリップ、バウンス、ゼリー、ダイアログの開始/終了、スクロール/ビューのタイムライン、継続時間/遅延/ステップ/反復/フィルモード、およびアニメーション スライド距離などの既製のアニメーション ユーティリティを追加します。ユーザーが Tailwind、animate-* クラス、モーション ユーティリティ、ダイアログ アニメーション、スクロール駆動の CSS モーションを使用して CSS アニメーションを必要とする場合、または tailwind-animation をインストール/構成する場合に使用します。トリガー: "tailwind アニメーション"、"animate-fade-in"、"animate-dialog"、"slide- distance"、"tailwind motion plugin"、/tailwind-animations。
