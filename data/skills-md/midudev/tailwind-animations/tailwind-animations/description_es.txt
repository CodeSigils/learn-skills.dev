Utilice el paquete npm tailwind-animations (complemento Tailwind CSS v4 solo para CSS) para agregar utilidades de animación listas para usar: desvanecer, deslizar, hacer zoom, voltear, rebotar, gelatina, entrada/salida de diálogo, desplazamiento/ver líneas de tiempo, duración/retraso/pasos/iteración/modo de relleno y distancia de diapositiva animada. Úselo cuando el usuario desee animaciones CSS con Tailwind, clases animate-*, utilidades de movimiento, animaciones de diálogo, movimiento CSS controlado por desplazamiento o para instalar/configurar animaciones tailwind. Activadores: "animaciones de viento de cola", "animación gradual", "diálogo de animación", "distancia de deslizamiento", "complemento de movimiento de viento de cola", /animaciones de viento de cola.
