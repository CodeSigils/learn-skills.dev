Открытая разработка на основе спецификаций — рабочий процесс на этапе предварительного кодирования спецификации. Он предоставляет агентам ИИ стандартизированный процесс создания шести типов документов — спецификаций требований, спецификаций приемки, архитектурного проектирования, детального проектирования модулей, плана задач и инструкций по вводу — при этом полученные артефакты служат договорной основой для последующего этапа автономного кодирования ИИ. [Примечание: эта возможность должна быть активирована человеком вручную; ИИ не должен автоматически запускать весь процесс, если это явно не запрошено человеком.]
