Открытая разработка на основе спецификаций — рабочий процесс на этапе предварительного кодирования спецификации. Он предоставляет агентам ИИ стандартизированный процесс создания шести типов документов — спецификаций требований, спецификаций приемки, проектирования архитектуры, детального проектирования модулей, плана задач и руководства по вводу — при этом полученные результаты служат договорной основой для последующего этапа автономного кодирования ИИ. 【Примечание: эта возможность активируется людьми вручную; ИИ не должен самостоятельно запускать весь процесс, если только этого явно не потребует человек.】
