Всесторонне вручную протестируйте интерфейс плагина Circuit, ориентированный на пользователя, в Claude Code или Codex. Используйте этот навык всякий раз, когда пользователь просит «проверить схему вручную», «проверить качество плагина Circuit», «проверить поверхность Circuit», «запустить контрольный список Circuit», «дымовую проверку Circuit», «найти регрессии в Circuit», «проверить плагин Claude Circuit», «проверить плагин Codex Circuit» или при подготовке выпуска Circuit для публикации на торговой площадке. Аргумент — это хост-пакет для тестирования — «claude» или «codex». Создает отчет Markdown с данными о прохождении/неудачном выполнении каждой команды, исследовательскими выводами, ранжированными по серьезности, ссылками на доказательства папок запуска и кратким описанием терминала. Используйте, даже если пользователь не произносит слово «тест» — такие фразы, как «выполнить каждую команду цепи» или «убедиться, что схема все еще работает от начала до конца», также должны сработать.
