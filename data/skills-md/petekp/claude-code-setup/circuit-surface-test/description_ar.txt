قم باختبار السطح الذي يواجهه المستخدم الخاص بالمكونات الإضافية للدائرة يدويًا بشكل شامل في Claude Code أو Codex. استخدم هذه المهارة عندما يطلب المستخدم "اختبار الدائرة يدويًا"، أو "ضمان ضمان الجودة للمكون الإضافي للدائرة"، أو "التمرين على سطح الدائرة"، أو "تشغيل قائمة التحقق من الدائرة"، أو "دائرة اختبار الدخان"، أو "العثور على الانحدارات في الدائرة"، أو "اختبار المكون الإضافي لـ Claude Circuit"، أو "اختبار المكون الإضافي Codex Circuit"، أو عند إعداد إصدار Circuit للنشر في السوق. الوسيطة هي الحزمة المضيفة التي سيتم اختبارها — `clude` أو `codex`. يُنتج تقرير Markdown مع نجاح/فشل لكل أمر، ونتائج استكشافية مرتبة حسب الخطورة، وروابط أدلة مجلد التشغيل، وملخص نهائي موجز. استخدمه حتى لو لم يقل المستخدم كلمة "اختبار" - يجب أيضًا تشغيل عبارات مثل "الانتقال إلى كل أمر في الدائرة" أو "التأكد من أن الدائرة لا تزال تعمل من البداية إلى النهاية".
