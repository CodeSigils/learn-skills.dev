Rédigez des notes courtes et claires avec la voix de l'auteur qui aident les évaluateurs à comprendre les choix non évidents, les limites et le comportement préservé dans la propre demande d'extraction ou la différence locale de l'auteur. À utiliser lorsque l'utilisateur demande à s'auto-réviser, à annoter ou à ajouter un contexte de réviseur à son PR ou à ses modifications. Rédigez localement lorsqu'aucun PR n'existe et publiez les notes approuvées sous la forme d'une seule révision GitHub lorsqu'un PR existe. Ne pas utiliser pour réviser le PR de quelqu'un d'autre, rédiger des commentaires sur le code, expliquer le code en général ou rédiger une description du PR. Ne publiez jamais sans approbation explicite.
