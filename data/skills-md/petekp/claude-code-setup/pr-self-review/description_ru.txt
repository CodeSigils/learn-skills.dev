Составляйте короткие, откровенные заметки голосом автора, которые помогут рецензентам понять неочевидные варианты выбора, границы и сохраненное поведение в собственном запросе на включение автора или локальных различиях. Используйте, когда пользователь просит самостоятельно просмотреть, аннотировать или добавить контекст рецензента к своему запросу или изменениям. Составляйте проекты локально, если PR не существует, и публикуйте утвержденные заметки как один обзор GitHub, если PR существует. Не используйте для просмотра чужого PR, написания комментариев к коду, общего объяснения кода или составления описания PR. Никогда не публикуйте сообщения без явного одобрения.
