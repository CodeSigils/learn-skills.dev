قم بصياغة ملاحظات قصيرة وصريحة بصوت المؤلف والتي تساعد المراجعين على فهم الاختيارات غير الواضحة والحدود والسلوك المحفوظ في طلب السحب الخاص بالمؤلف أو الاختلاف المحلي. يُستخدم عندما يطلب المستخدم إجراء مراجعة ذاتية أو إضافة تعليق توضيحي أو إضافة سياق المراجع إلى العلاقات العامة أو التغييرات الخاصة به. قم بالصياغة محليًا في حالة عدم وجود علاقات عامة، وانشر الملاحظات المعتمدة كمراجعة واحدة على GitHub عند وجود علاقات عامة. لا تستخدم لمراجعة العلاقات العامة لشخص آخر، أو كتابة تعليقات التعليمات البرمجية، أو شرح التعليمات البرمجية بشكل عام، أو صياغة وصف العلاقات العامة. لا تنشر أبدًا دون موافقة صريحة.
