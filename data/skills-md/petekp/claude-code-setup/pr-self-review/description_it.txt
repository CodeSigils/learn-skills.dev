Redigere note brevi e chiare con la voce dell'autore che aiutino i revisori a comprendere scelte, limiti e comportamenti non ovvi nella pull request o nel diff locale dell'autore. Da utilizzare quando l'utente chiede di effettuare un'autorevisione, annotare o aggiungere il contesto del revisore alle proprie PR o alle modifiche. Crea una bozza localmente quando non esiste una PR e pubblica note approvate come una revisione GitHub quando esiste una PR. Non utilizzare per rivedere il PR di qualcun altro, scrivere commenti sul codice, spiegare il codice in generale o redigere una descrizione del PR. Non pubblicare mai senza esplicita approvazione.
