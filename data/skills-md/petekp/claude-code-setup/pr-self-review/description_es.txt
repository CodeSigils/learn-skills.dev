Redacte notas breves y sencillas con la voz del autor que ayuden a los revisores a comprender opciones no obvias, límites y comportamiento preservado en la solicitud de extracción o la diferenciación local del autor. Úselo cuando el usuario solicite realizar una autoevaluación, anotar o agregar contexto del revisor a su PR o cambios. Redacte localmente cuando no exista un PR y publique notas aprobadas como una revisión de GitHub cuando exista un PR. No lo utilice para revisar las relaciones públicas de otra persona, escribir comentarios de código, explicar el código en general o redactar una descripción de relaciones públicas. Nunca publiques sin aprobación explícita.
