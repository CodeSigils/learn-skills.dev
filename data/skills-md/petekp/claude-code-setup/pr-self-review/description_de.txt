Verfassen Sie kurze, klare Notizen mit der Stimme des Autors, die den Rezensenten helfen, nicht offensichtliche Entscheidungen, Grenzen und beibehaltenes Verhalten im eigenen Pull-Request oder lokalen Diff des Autors zu verstehen. Verwenden Sie diese Option, wenn der Benutzer darum bittet, seine PR oder Änderungen selbst zu überprüfen, zu kommentieren oder Prüferkontext hinzuzufügen. Entwerfen Sie lokal, wenn keine PR vorhanden ist, und veröffentlichen Sie genehmigte Notizen als eine GitHub-Überprüfung, wenn eine PR vorhanden ist. Nicht zum Überprüfen der PR einer anderen Person, zum Schreiben von Codekommentaren, zur allgemeinen Erläuterung des Codes oder zum Verfassen einer PR-Beschreibung verwenden. Posten Sie niemals ohne ausdrückliche Genehmigung.
