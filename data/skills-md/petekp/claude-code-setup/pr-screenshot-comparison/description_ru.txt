Создавайте четкие, полированные скриншоты «до» и «после» для запроса на извлечение GitHub. Используйте, когда изменение пользовательского интерфейса нуждается в визуальном подтверждении: захватите соответствующие состояния, обрежьте до соответствующего пользовательского интерфейса, сшейте и озаглавьте одно изображение для сравнения, прикрепите его к PR и сохраните изображение из репозитория.
