أعد صياغة المحتوى الكثيف أو الثقيل المصطلحات أو الذي يصعب متابعته بلغة واضحة حتى يفهمه المستخدم فعليًا. استخدم عندما يستدعي المستخدم / عادي، أو يقول شيئًا مثل "اشرح ذلك ببساطة أكبر"، أو "أنا لا أتبع"، أو "ماذا يعني ذلك في الواقع"، أو "باللغة الإنجليزية البسيطة"، أو "كسر ذلك"، أو "ELI5"، أو يلصق/يشير إلى النص الذي يجده كثيفًا. بدون أي حجج، أعد صياغة إجابتك السابقة. باستخدام الوسيطات (النص الملصق، أو مسار الملف، أو "الجزء المتعلق بـ X")، أعد صياغة ذلك بدلاً من ذلك. قم بالتحفيز حتى على إشارات الارتباك غير الرسمية - "انتظر، ماذا؟"، "هاه؟"، "لقد فقدتني" - وليس فقط الطلبات الصريحة.
