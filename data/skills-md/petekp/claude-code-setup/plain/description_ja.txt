ユーザーが実際に理解できるように、内容が濃い、専門用語が多い、またはわかりにくいコンテンツを平易な言葉で言い換えます。ユーザーが /plain を呼び出したり、「もっと簡単に説明してください」、「私は従いません」、「それは実際にどういう意味ですか」、「わかりやすい英語で」、「分解してください」、「ELI5」などのことを言ったり、密度が濃いと思われるテキストを貼り付けたりポイントしたりするときに使用します。引数なしで、自分の以前の回答を再度述べます。引数 (貼り付けたテキスト、ファイル パス、または「X に関する部分」) を使用して、代わりにそれを再説明します。明示的なリクエストだけでなく、「待て、何?」、「え?」、「迷った」など、非公式の混乱の合図でもトリガーされます。
