قم بتحويل المطالبة المقدمة مع هذه المهارة إلى هدف دستوري موجز وقابل للتدقيق أو اشرح لماذا لا يكون الهدف مناسبًا. يُستخدم عندما يطلب المستخدم صياغة `/goal` أو صياغته أو إعادة كتابته أو تشديده أو إنشاءه من مهمة بلغة بسيطة، خاصة بالنسبة للعمل متعدد الخطوات الذي يحتاج إلى هدف دائم وإكمال قائم على الأدلة وقيود وسياسة التكرار وحلقة مراجعة تنافسية افتراضية.
