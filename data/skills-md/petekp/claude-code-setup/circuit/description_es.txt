Operate Circuit, el motor de flujo que ejecuta el trabajo de codificación como flujos estructurados y respaldados por evidencia (Reparar, Construir, Explorar, Revisar, Prototipar). Utilice esta habilidad al INICIO de cualquier tarea de codificación importante en un proyecto donde esté instalado Circuit: corregir un error, crear una función, refactorizar, revisar una diferencia o PR, investigar una pregunta o crear un prototipo. Úselo también cada vez que el usuario mencione circuitos, flujos, ejecuciones, puntos de control, carpetas de ejecuciones, el dial de encendido o anulación de procesos, conectores, o solicite crear, generar, obtener una vista previa, configurar o reanudar un flujo. Si llega una solicitud de codificación y Circuit está disponible, consulte esta habilidad antes de realizar el trabajo a mano.
