Operate Circuit، محرك التدفق الذي يدير أعمال الترميز كتدفقات منظمة ومدعومة بالأدلة (الإصلاح والبناء والاستكشاف والمراجعة والنموذج الأولي). استخدم هذه المهارة في بداية أي مهمة ترميز جوهرية في مشروع تم تثبيت Circuit عليه: إصلاح خطأ، أو إنشاء ميزة، أو إعادة البناء، أو مراجعة الاختلاف أو العلاقات العامة، أو التحقق من سؤال، أو إنشاء نماذج أولية. استخدمه أيضًا عندما يذكر المستخدم الدائرة، أو التدفقات، أو التشغيل، أو نقاط التفتيش، أو تشغيل المجلدات، أو قرص الطاقة أو تجاوز العملية، أو الموصلات، أو يطلب إنشاء التدفق أو إنشائه أو معاينته أو تكوينه أو استئنافه. إذا وصل طلب ترميز وكانت الدائرة متاحة، فاستشر هذه المهارة قبل القيام بالعمل يدويًا.
