قم بمراجعة التغييرات الأخيرة في كود React أو Next.js أو TypeScript UI للتقوية قبل الدمج أو الالتزام. استخدمه عندما يُطلب منك مراجعة تغييرات كود React الأخيرة، أو تدقيق فرق React، أو تعزيز ميزة، أو التحقق من العلاقات العامة أو الفرع بحثًا عن مشكلات React، أو إنتاج قائمة مرتبة مكدسة من النتائج غير المتكررة وخطة إصلاح موصى بها باستخدام React-doctor، وأفضل ممارسات Vercel React، وأنماط تكوين Vercel، وتوجيهات React useEffect.
