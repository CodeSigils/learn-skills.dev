プロジェクト内で何が変わったのか、つまりエージェントが何をしたのか、なぜ、どのような決定にエージェントの意見が必要なのかを、人間にわかりやすく簡潔な英語で伝えます。ユーザーが「近況を教えて」、「何が変わったのか」、「どこにいますか」、「要約」、「簡単に説明してください」、「概要を教えてください」、「何をしましたか」、「セッションを要約してください」、「補足してください」、またはその他の方法で、ユーザーが席を外していてすぐに元の状態に戻りたいことを示している場合に、これを使用します。コードを詳しく読むことはしないが、核となるアイデア、選択、および未決定の意思決定を十分に理解して舵取りする必要がある、複数のエージェント駆動プロジェクトを同時に舵取りする人向けに構築されています。これらの正確な言葉を使用していない場合でもトリガーします。最近の進捗状況を把握するためのリクエストには、このスキルを使用する必要があります。
