Führen Sie einen Spike durch – ein zeitgesteuertes, absichtlich wegwerfbares Experiment, dessen einzige Aufgabe darin besteht, die Unbekannten in einer Aufgabe zu beantworten, bevor sich jemand auf eine echte Implementierung einlässt. Verwenden Sie es immer dann, wenn der Benutzer „Spike“, „Spike this“, „Lass uns Spike machen“, „Throwaway“, „Proof of Concept“, „POC“, „Quick and Dirty“, „Nur um zu sehen, ob es funktioniert“, „Prototyp machen“, „Markierungskugel“ oder „etwas zusammenhacken“ sagt. Verwenden Sie es auch – auch ohne diese Worte –, wenn der Benutzer abwägt, ob ein Ansatz realisierbar ist, fragt: „Würde das überhaupt funktionieren“, „Können wir Ziehen Sie dies dem Bau eines Originals vor, wenn die ehrliche Antwort auf die Frage „Wissen wir, dass das funktionieren wird?“ lautet. ist nein.
