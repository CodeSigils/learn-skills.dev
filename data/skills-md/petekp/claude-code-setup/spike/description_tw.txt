運行一個高峰——一個有時間限制的、故意一次性的實驗，其唯一的工作是在任何人承諾真正實施之前回答任務中的未知問題。每當用戶說「秒殺」、「秒殺這個」、「讓我們秒殺牠」、「一次性」、「概念驗證」、「POC」、「快速而骯髒」、「只是為了看看它是否有效」、「對其進行原型製作」、「示蹤子彈」或「一起破解某些東西」時使用。即使沒有這些詞，當用戶權衡一種方法是否可行，詢問“這是否有效”，“我們可以用 Y 做 X”，“這會有多難”，“這足夠快嗎”，“這涉及多少個地方”，或者即將開始一項大型工作（其形狀取決於尚未檢查的事實）時，也可以使用這些詞。當誠實地回答「我們知道這會起作用嗎？」時，更喜歡這樣做而不是建立真實的東西。是沒有。
