スパイクを実行する — タイムボックス化された、意図的に使い捨てられる実験であり、その唯一の仕事は、実際の実装に着手する前に、タスク内の不明点に答えることです。ユーザーが「スパイク」、「これをスパイク」、「スパイクしてみよう」、「使い捨て」、「概念実証」、「POC」、「クイック・アンド・ダーティ」、「動作するかどうか確認するだけ」、「プロトタイプを作成する」、「トレーサー弾丸」、または「何かを一緒にハッキングする」と言ったときに使用します。また、これらの言葉がなくても、ユーザーがアプローチが実行可能かどうかを検討しているとき、「これでもうまくいくだろうか」、「Y で X を実行できるか」、「これはどれくらい難しいだろうか」、「これで十分な速度か」、「これは何箇所に触れるのか」などと尋ねるとき、またはまだ誰もチェックしていない事実に依存する大規模な作業を開始しようとしているときにも使用します。 「これが機能するかどうか」に対する正直な答えが得られる場合は、本物を構築するよりもこれを優先します。いいえです。
