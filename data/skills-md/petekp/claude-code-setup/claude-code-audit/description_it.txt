Audit forense delle recenti sessioni di Claude Code dell'utente per evidenziare miglioramenti rivoluzionari del flusso di lavoro, non marginali. Da utilizzare quando l'utente chiede di "controllare le mie sessioni di Claude Code", "analizzare come utilizzo Claude Code", "trovare modelli nel mio utilizzo", "migliorare il flusso di lavoro del mio Claude Code", "revisionare le mie sessioni", "trovare vantaggi nella mia configurazione" o vuole capire dove la configurazione del codice Claude perde tempo. Campiona dozzine di trascrizioni reali, estrae segnali quantitativi tramite script, utilizza subagenti paralleli per letture approfondite, quindi sintetizza in un breve report con priorità con implementazioni bozze (nuove competenze, regole CLAUDE.md, hook, differenze di impostazioni) che l'utente può installare direttamente. Attiva anche quando l'utente non pronuncia la parola "audit": se chiede di migliorare o rivedere le proprie abitudini del Codice Claude su larga scala, usa questa abilità.
