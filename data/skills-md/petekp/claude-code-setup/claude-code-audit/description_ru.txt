Криминалистический аудит недавних сеансов пользователя Claude Code для выявления поэтапных, а не незначительных улучшений рабочего процесса. Используйте, когда пользователь просит «проверить мои сеансы Claude Code», «проанализировать, как я использую Claude Code», «найти закономерности в моем использовании», «улучшить мой рабочий процесс Claude Code», «просмотреть мои сеансы», «найти рычаги в моей настройке» или хочет понять, где его настройка Claude Code теряет время. Отбирает десятки реальных транскриптов, извлекает количественный сигнал с помощью скриптов, использует параллельные субагенты для глубокого чтения, затем синтезирует в короткий отчет с приоритетами и готовыми реализациями (новые навыки, правила CLAUDE.md, перехватчики, различия настроек), которые пользователь может установить напрямую. Срабатывает, даже если пользователь не произносит слово «аудит» — если он спрашивает об улучшении или пересмотре своих привычек Клода Кода в масштабе, используйте этот навык.
