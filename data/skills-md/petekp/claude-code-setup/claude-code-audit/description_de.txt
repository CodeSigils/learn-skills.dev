Forensische Prüfung der letzten Claude-Code-Sitzungen des Benutzers, um bahnbrechende Workflow-Verbesserungen aufzudecken – und nicht nur marginale. Verwenden Sie diese Option, wenn der Benutzer „meine Claude Code-Sitzungen überprüfen“, „analysieren möchte, wie ich Claude Code verwende“, „Muster in meiner Nutzung finden“, „meinen Claude Code-Workflow verbessern“, „meine Sitzungen überprüfen“, „einen Hebel in meinem Setup finden“ möchte oder verstehen möchte, wo bei seinem Claude Code-Setup Zeit verloren geht. Erfasst Dutzende echter Transkripte, extrahiert quantitative Signale über Skripte, verwendet parallele Subagenten für Deep Reads und synthetisiert sie dann zu einem kurzen, priorisierten Bericht mit vorgefertigten Implementierungen (neue Fertigkeiten, CLAUDE.md-Regeln, Hooks, Einstellungsunterschiede), die der Benutzer direkt installieren kann. Wird auch dann ausgelöst, wenn der Benutzer das Wort „Audit“ nicht ausspricht – wenn er nach einer umfassenden Verbesserung oder Überprüfung seiner Claude-Code-Gewohnheiten fragt, nutzen Sie diese Fähigkeit.
