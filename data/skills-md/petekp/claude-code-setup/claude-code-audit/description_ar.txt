تدقيق الطب الشرعي لجلسات Claude Code الأخيرة للمستخدم لإظهار تحسينات سير العمل ذات التغيير التدريجي - وليس التحسينات الهامشية. يُستخدم عندما يطلب المستخدم "تدقيق جلسات Claude Code الخاصة بي"، أو "تحليل كيفية استخدامي لـ Claude Code"، أو "البحث عن أنماط في استخدامي"، أو "تحسين سير عمل Claude Code الخاص بي"، أو "مراجعة جلساتي"، أو "العثور على التأثير في الإعداد الخاص بي"، أو يريد فهم أين يتسرب وقت إعداد Claude Code الخاص به. عينات العشرات من النصوص الحقيقية، واستخراج الإشارات الكمية عبر البرامج النصية، واستخدام العوامل الفرعية المتوازية للقراءات العميقة، ثم تجميعها في تقرير قصير محدد الأولويات مع تطبيقات مسودة (مهارات جديدة، وقواعد CLAUDE.md، والخطافات، واختلافات الإعدادات) التي يمكن للمستخدم تثبيتها مباشرة. قم بالتفعيل حتى عندما لا يقول المستخدم كلمة "التدقيق" - إذا كانوا يسألون عن تحسين عادات Claude Code الخاصة بهم أو مراجعتها على نطاق واسع، فاستخدم هذه المهارة.
