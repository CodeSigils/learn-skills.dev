ユーザーの最近のクロード コード セッションをフォレンジック監査し、わずかな改善ではなく、段階的に変更するワークフローの改善を明らかにします。ユーザーが「クロード コードのセッションを監査する」、「クロード コードの使用方法を分析する」、「使用方法のパターンを見つける」、「クロード コードのワークフローを改善する」、「セッションを確認する」、「セットアップの活用方法を見つける」を要求する場合、またはクロード コードのセットアップのどこで時間が漏れているかを把握したい場合に使用します。数十の実際のトランスクリプトをサンプリングし、スクリプトを介して定量的シグナルを抽出し、ディープリードに並列サブエージェントを使用して、ユーザーが直接インストールできる草案実装 (新しいスキル、CLAUDE.md ルール、フック、設定差分) を含む短い優先順位付きレポートに合成します。ユーザーが「監査」という言葉を言わなくてもトリガーします。ユーザーがクロード コードの習慣を大規模に改善または見直したい場合は、このスキルを使用します。
