Audit médico-légal des récentes sessions Claude Code de l'utilisateur pour faire apparaître des améliorations progressives du flux de travail, et non des améliorations marginales. À utiliser lorsque l'utilisateur demande « d'auditer mes sessions Claude Code », « d'analyser la façon dont j'utilise Claude Code », « de trouver des modèles dans mon utilisation », « d'améliorer mon flux de travail Claude Code », de « revoir mes sessions », de « trouver un effet de levier dans ma configuration » ou souhaite comprendre où sa configuration Claude Code perd du temps. Échantillonne des dizaines de transcriptions réelles, extrait le signal quantitatif via des scripts, utilise des sous-agents parallèles pour des lectures approfondies, puis synthétise dans un court rapport hiérarchisé avec des implémentations rédigées (nouvelles compétences, règles CLAUDE.md, hooks, différences de paramètres) que l'utilisateur peut installer directement. Déclenchez-le même lorsque l'utilisateur ne prononce pas le mot « audit » – s'il demande à améliorer ou à revoir ses habitudes Claude Code à grande échelle, utilisez cette compétence.
