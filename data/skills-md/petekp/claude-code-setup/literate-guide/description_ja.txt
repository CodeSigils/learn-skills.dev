Knuth の Literate Programming のスタイルで、コードベースまたは機能への物語的なガイドを作成します。コードと散文が 1 つのエッセイとして織り込まれ、コンパイラーのニーズではなく人間の理解に基づいて順序付けされています。ユーザーが「このコードベースをストーリーとして説明する」、「読みやすいガイドを書く」、「物語的なウォークスルーを作成する」、「このコードのストーリーを語る」、「Knuth スタイルのドキュメント」、「この機能のガイドを編む」などの要求をする場合、またはプログラムを文献として扱う深くて読みやすいドキュメントが必要な場合に使用します。また、誰かが思慮深い読者が最初から最後まで追って、コードの動作とすべての設計上の選択が行われた理由の両方を理解できるドキュメントを必要としている場合にもトリガーします。
