Erstellen Sie einen narrativen Leitfaden zu einer Codebasis oder Funktion im Stil von Knuths Literate Programming – Code und Prosa sind in einem einzigen Aufsatz verwoben, geordnet für das menschliche Verständnis und nicht für die Bedürfnisse des Compilers. Verwenden Sie es, wenn der Benutzer „diese Codebasis als Geschichte erklären“, „einen literarischen Leitfaden schreiben“, „eine narrative Komplettlösung erstellen“, „die Geschichte dieses Codes erzählen“, „eine Dokumentation im Knuth-Stil“ oder „einen Leitfaden für diese Funktion erstellen“ möchte oder wenn er eine ausführliche, lesbare Dokumentation wünscht, die das Programm als Literatur behandelt. Wird auch ausgelöst, wenn jemand ein Dokument möchte, dem ein aufmerksamer Leser von Anfang bis Ende folgen kann und der am Ende versteht, WAS der Code bewirkt und WARUM jede Designentscheidung getroffen wurde.
