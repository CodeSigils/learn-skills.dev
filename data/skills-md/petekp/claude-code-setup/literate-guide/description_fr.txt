Créez un guide narratif pour une base de code ou une fonctionnalité dans le style de la programmation littéraire de Knuth : code et prose entrelacés dans un seul essai, ordonné pour la compréhension humaine plutôt que pour les besoins du compilateur. À utiliser lorsque l'utilisateur demande « d'expliquer cette base de code sous forme d'histoire », « d'écrire un guide littéraire », de « créer une procédure narrative pas à pas », de « raconter l'histoire de ce code », de « documenter de style Knuth », de « tisser un guide pour cette fonctionnalité », ou lorsqu'il souhaite une documentation approfondie et lisible qui traite le programme comme de la littérature. Déclenchez également lorsque quelqu'un veut un document qu'un lecteur réfléchi pourrait suivre du début à la fin et repartir en comprenant à la fois CE QUE fait le code et POURQUOI chaque choix de conception a été fait.
