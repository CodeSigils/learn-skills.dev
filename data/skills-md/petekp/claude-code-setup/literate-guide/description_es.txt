Cree una guía narrativa para una base de código o característica al estilo de Literate Programming de Knuth: código y prosa entrelazados como un solo ensayo, ordenado para la comprensión humana en lugar de las necesidades del compilador. Úselo cuando el usuario solicite 'explicar este código base como una historia', 'escribir una guía alfabetizada', 'crear un recorrido narrativo', 'contar la historia de este código', 'documentación estilo Knuth', 'tejer una guía para esta característica', o cuando quiera documentación profunda y legible que trate el programa como literatura. También se activa cuando alguien quiere un documento que un lector atento pueda seguir de principio a fin y entender QUÉ hace el código y POR QUÉ se tomó cada elección de diseño.
