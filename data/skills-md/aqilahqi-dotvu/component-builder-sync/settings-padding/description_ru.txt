Правила и шаблоны для настроек заполнения на каждой стороне — связанный/несвязанный переключатель, сетка 2×2 для отдельных элементов управления, миграция из устаревшего поля с одним значением и вывод CSS с масштабированием s(). Используйте при добавлении элементов управления дополнением к компоненту.
