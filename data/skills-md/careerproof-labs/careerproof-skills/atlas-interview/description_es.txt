Genere preguntas de entrevista personalizadas para un candidato con niveles de presión configurables (de apoyo/estándar/agresivo) y sondeo de seguimiento basado en las respuestas reales del candidato. Utilice esta habilidad siempre que alguien solicite generar preguntas de entrevista, prepararse para una entrevista, crear preguntas técnicas o de comportamiento para un candidato, sondear la respuesta de un candidato, obtener preguntas de seguimiento o preparar la entrevista. Úselo también cuando alguien mencione "¿qué debo preguntarle a este candidato?" o "entrevistar a esta persona". Esto es para GENERACIÓN de preguntas: para calificar la transcripción de una entrevista después del hecho, use atlas_start_dialogue_assessment directamente.
