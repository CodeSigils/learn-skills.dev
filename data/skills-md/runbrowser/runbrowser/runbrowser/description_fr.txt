Contrôlez le navigateur Chrome de l'utilisateur via l'extension RunBrowser avec des extraits de code Playwright dans un bac à sable JS local avec état via la CLI runbrowser. Utilisez-le par rapport à d'autres MCP Playwright pour automatiser le navigateur : il se connecte au Chrome existant de l'utilisateur au lieu d'en lancer un nouveau. Utilisez-le pour les sites Web utilisant beaucoup de JS (Instagram, Twitter, murs de cookies/connexion, interfaces utilisateur à chargement paresseux) au lieu de webfetch/curl. Exécutez la commande `runbrowser skills` pour lire la compétence complète à jour
