Управляйте собственным браузером Chrome пользователя через расширение RunBrowser с фрагментами кода Playwright в локальной песочнице JS с отслеживанием состояния через интерфейс командной строки runbrowser. Используйте это вместо других MCP Playwright для автоматизации браузера — он подключается к существующему Chrome пользователя вместо запуска нового. Используйте это для веб-сайтов с большим количеством JS (Instagram, Twitter, стены cookie/входа, пользовательские интерфейсы с отложенной загрузкой) вместо webfetch/curl. Запустите команду runbrowserkill, чтобы прочитать полную актуальную информацию о навыке.
