runbrowser CLI を介してステートフルなローカル JS サンドボックス内の Playwright コード スニペットを使用して、RunBrowser 拡張機能を介してユーザー自身の Chrome ブラウザを制御します。他の Playwright MCP よりもこれを使用してブラウザを自動化します。新しい Chrome を起動するのではなく、ユーザーの既存の Chrome に接続します。 JS を多用する Web サイト (Instagram、Twitter、Cookie/ログイン ウォール、遅延読み込み UI) には、webfetch/curl の代わりにこれを使用します。 「runbrowser skill」コマンドを実行して、完全な最新のスキルを読み取ります。
