Controlla il browser Chrome dell'utente tramite l'estensione RunBrowser con snippet di codice Playwright in una sandbox JS locale con stato tramite la CLI di runbrowser. Usalo su altri MCP di Playwright per automatizzare il browser: si connette al Chrome esistente dell'utente invece di avviarne uno nuovo. Utilizzalo per i siti Web con uso intensivo di JS (Instagram, Twitter, cookie/wall di accesso, interfacce utente con caricamento lento) anziché webfetch/curl. Esegui il comando "runbrowser skill" per leggere la skill completa e aggiornata
