Используйте, когда пользователь явно говорит «запомни это», «сохрани это», «ги нхо», «луу лай», «сохрани для следующего раза» или иным образом просит сохранить непосредственно предшествующий контекст. Захватывает соответствующий context_type (решение, предпочтение, факт, навык, задача, разговор), чтобы будущие сеансы могли точно извлечь его.
