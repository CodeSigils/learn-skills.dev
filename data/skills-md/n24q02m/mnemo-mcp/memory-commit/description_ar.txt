يُستخدم عندما يقول المستخدم صراحةً "تذكر هذا"، أو "احفظ هذا"، أو "ghi nho"، أو "luu lai"، أو "احفظ للمرة القادمة"، أو يطلب بخلاف ذلك الاحتفاظ بالسياق السابق مباشرة. يتم الالتقاط باستخدام نوع السياق المناسب (القرار، التفضيل، الحقيقة، المهارة، المهمة، المحادثة) حتى تتمكن الجلسات المستقبلية من استرجاعه بدقة.
