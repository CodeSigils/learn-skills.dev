Verwenden Sie diese Option, wenn der Benutzer mnemo-mcp auf einem neuen Computer installiert und den vorherigen Speicherstatus von S3 oder Google Drive wiederherstellen möchte (Phase-2-Passport-Synchronisierung). Wird bei Phrasen wie „Mnemo auf diesem Computer einrichten“, „Meinen Speicherpass wiederherstellen“, „Passport importieren“, „Bootstrap-Mnemo“ ausgelöst oder wenn der Benutzer sagt, dass er einen neuen Laptop/eine neue VM hat und seine Erinnerungen zurückhaben möchte.
