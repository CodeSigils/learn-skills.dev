Синхронизируйте ежедневные журналы памяти проекта (.memories/) между устройствами через Git, используя изолированную ветку для каждого пользователя и рабочее дерево, не загрязняя активную ветку разработки. Используйте для получения журналов других устройств в начале сеанса и отправки локальных журналов в конце сеанса.
