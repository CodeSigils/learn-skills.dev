Intégrez expo-gaode-map, expo-gaode-map-navigation et expo-gaode-map-web-api dans les applications Expo ou React Native. Doit préférer app.json existant à la création d'app.config, écrire des espaces réservés pour les clés du plugin de configuration lorsque les clés sont manquantes, exécuter npx expo prebuild après les modifications de configuration et éviter initSDK dans le code de carte de base, sauf si l'API Web ou aucune configuration de clé native n'est utilisée.
