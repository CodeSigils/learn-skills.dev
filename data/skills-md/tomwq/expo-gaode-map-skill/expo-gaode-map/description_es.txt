Integre expo-gaode-map, expo-gaode-map-navigation y expo-gaode-map-web-api en las aplicaciones Expo o React Native. Debe preferir app.json existente en lugar de crear app.config, escribir marcadores de posición de claves del complemento de configuración cuando falten claves, ejecutar npx expo prebuild después de los cambios de configuración y evitar initSDK en el código de mapa básico a menos que se utilice una API web o ninguna configuración de clave nativa.
