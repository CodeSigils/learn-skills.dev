Integra expo-gaode-map, expo-gaode-map-navigation e expo-gaode-map-web-api nelle app Expo o React Native. È necessario preferire l'app.json esistente rispetto alla creazione di app.config, scrivere i segnaposto della chiave del plug-in di configurazione quando mancano le chiavi, eseguire npx expo prebuild dopo le modifiche della configurazione ed evitare initSDK nel codice della mappa di base a meno che non venga utilizzata l'API Web o nessuna configurazione della chiave nativa.
