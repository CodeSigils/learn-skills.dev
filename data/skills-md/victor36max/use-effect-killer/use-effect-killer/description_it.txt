Scansiona la base di codice di React per utilizzare anti-pattern di effetti (stato derivato, logica degli eventi negli effetti, catene di effetti, ripristini guidati dalle prop, pulizia mancante, notifiche principali, ecc.) e proporre correzioni idiomatiche. Basato sulla guida "You Might Not Need an Effect" di React. Utilizzare quando viene richiesto di controllare, rivedere o ripulire l'utilizzo di useEffect.
