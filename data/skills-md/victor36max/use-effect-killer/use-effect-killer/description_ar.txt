قم بمسح قاعدة بيانات React بحثًا عن أنماط مقاومة useEffect (الحالة المشتقة، ومنطق الحدث في التأثيرات، وسلاسل التأثير، وعمليات إعادة التعيين المستندة إلى الدعامة، والتنظيف المفقود، وإشعارات الوالدين، وما إلى ذلك) واقتراح إصلاحات اصطلاحية. استنادًا إلى دليل React "قد لا تحتاج إلى تأثير". استخدم عندما يُطلب منك تدقيق استخدام useEffect أو مراجعته أو تنظيفه.
