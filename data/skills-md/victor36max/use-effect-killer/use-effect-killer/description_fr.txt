Analysez la base de code React pour les anti-modèles useEffect (état dérivé, logique d'événement dans les effets, chaînes d'effets, réinitialisations pilotées par les accessoires, nettoyage manquant, notifications parentales, etc.) et proposez des correctifs idiomatiques. Basé sur le guide « Vous pourriez ne pas avoir besoin d'un effet » de React. À utiliser lorsqu'on vous demande d'auditer, d'examiner ou de nettoyer l'utilisation de useEffect.
