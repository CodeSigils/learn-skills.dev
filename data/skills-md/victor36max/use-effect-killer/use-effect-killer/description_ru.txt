Сканируйте кодовую базу React на предмет анти-шаблонов useEffect (производное состояние, логика событий в эффектах, цепочки эффектов, сбросы на основе свойств, отсутствующая очистка, родительские уведомления и т. д.) и предлагайте идиоматические исправления. На основе руководства React «Вам может не понадобиться эффект». Используйте, когда вас попросят провести аудит, просмотреть или очистить использование useEffect.
