Стратегия восстановления, когда инструменту записи не удается создать новый файл. Используйте этот навык всякий раз, когда вызов инструмента записи или редактирования завершается с ошибкой, связанной с созданием нового файла, например отсутствием родительских каталогов, проблемами с разрешениями или ошибками «файл не найден» для файлов, которые еще не существуют. Этот навык НЕ применим к редактированию существующих файлов, которые не удалось выполнить по другим причинам. Запускается, когда вы видите ошибки записи/редактирования при создании нового файла, когда создание файла неожиданно завершается неудачей или когда вы получаете ошибки, связанные с путем, при попытке создать файлы во вложенных каталогах.
