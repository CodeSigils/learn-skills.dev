REST API 経由で Home Assistant スマート ホーム デバイスを制御およびクエリします。ユーザーがホーム アシスタント、スマート ホーム コントロール、IoT デバイス、ホーム オートメーション、照明のオン/オフ、センサーの読み取り値の確認、サーモスタット制御、ドア ロック、または家の接続デバイスに関連するタスクについて言及するときは、たとえ「ホーム アシスタント」と明示的に言わなくても、このスキルを使用します。また、ユーザーが家の状態について質問したり、オートメーションを作成したり、「light.living_room」や「switch.garage_door」などのエンティティ ID を参照したりするときにもトリガーされます。
