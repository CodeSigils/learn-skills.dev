التحكم والاستعلام عن الأجهزة المنزلية الذكية Home Assistant عبر REST API. استخدم هذه المهارة عندما يذكر المستخدم Home Assistant، أو التحكم بالمنزل الذكي، أو أجهزة IoT، أو التشغيل الآلي للمنزل، أو تشغيل/إيقاف الأضواء، أو التحقق من قراءات المستشعر، أو التحكم في منظم الحرارة، أو أقفال الأبواب، أو أي مهمة تتعلق بالأجهزة المتصلة بالمنزل - حتى لو لم يذكر "Home Assistant" صراحةً. يتم تشغيله أيضًا عندما يسأل المستخدمون عن حالة منزلهم، أو يريدون إنشاء عمليات تشغيل تلقائي، أو تشير إلى معرفات الكيانات مثل "light.living_room" أو "switch.garage_door".
