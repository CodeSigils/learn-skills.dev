قم بحزم وتوزيع تطبيقات macOS والخطوط وأدوات CLI والملفات العشوائية باستخدام صيغ وبراميل Homebrew. استخدم هذه المهارة عندما يريد المستخدم إنشاء صيغة Homebrew أو برميل خشبي، أو إعداد نقرة شخصية، أو حزم حزمة macOS .app، أو توزيع الخطوط أو الثنائيات المعدة مسبقًا عبر الشراب، أو استخدام "إنشاء الشراب"، أو نقل صيغة أو برميل إلى إصدار جديد، أو إرسال حزمة إلى homebrew-core أو homebrew-cask، أو نشر أي شيء باستخدام Homebrew - حتى لو كانوا يسألون فقط عن كيفية "جعل شيء قابل للتثبيت باستخدام Brew"، أو "مشاركة تطبيقي من خلال Homebrew"، "تحديث الصيغة الخاصة بي" أو "إحضار الحزمة الخاصة بي إلى Homebrew".
