Crea pacchetti e distribuisci app, caratteri, strumenti CLI e file arbitrari per macOS utilizzando formule e botti Homebrew. Usa questa abilità ogni volta che l'utente desidera creare una formula o un cask Homebrew, impostare un tocco personale, creare un pacchetto di un bundle macOS .app, distribuire caratteri o file binari predefiniti tramite brew, utilizzare `brew create`, passare una formula o un cask a una nuova versione, inviare un pacchetto a homebrew-core o homebrew-cask o pubblicare qualsiasi cosa con Homebrew, anche se chiedono semplicemente come "rendere qualcosa installabile con brew", "condividere la mia app tramite Homebrew", "aggiornare la mia formula", oppure "porta il mio pacchetto in Homebrew".
