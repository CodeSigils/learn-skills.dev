Empaquete y distribuya aplicaciones, fuentes, herramientas CLI y archivos arbitrarios de macOS utilizando fórmulas y barriles Homebrew. Utilice esta habilidad siempre que el usuario quiera crear una fórmula o un barril de Homebrew, configurar un grifo personal, empaquetar un paquete .app de macOS, distribuir fuentes o binarios prediseñados a través de Brew, usar `brew create`, pasar una fórmula o un barril a una nueva versión, enviar un paquete a homebrew-core o homebrew-cask, o publicar cualquier cosa con Homebrew, incluso si solo preguntan cómo "hacer algo instalable con Brew", "compartir mi aplicación a través de Homebrew", "actualizar mi fórmula". o "llevar mi paquete a Homebrew".
