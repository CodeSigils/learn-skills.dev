Interactúe con un UniFi Dream Router (UDR) o cualquier consola UniFi OS a través de su API REST. Utilice esta habilidad siempre que el usuario quiera consultar o controlar su red UniFi: enumerar clientes conectados, bloquear/desbloquear dispositivos, administrar políticas de firewall, verificar el estado de la WAN y los resultados de las pruebas de velocidad, reiniciar dispositivos, administrar VLAN o SSID, leer estadísticas de tráfico, reenvío de puertos o cualquier otra tarea de administración de la red UniFi. Se activa incluso si el usuario no dice "API" o "UniFi": frases como "verificar mi red", "bloquear ese dispositivo", "muéstrame quién está conectado", "agregar una regla de firewall", "cuál es mi IP WAN", "cómo está mi velocidad de Internet" o "qué hay en la red de invitados" son todos buenos activadores.
