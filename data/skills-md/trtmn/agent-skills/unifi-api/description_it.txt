Interagisci con un UniFi Dream Router (UDR) o qualsiasi console del sistema operativo UniFi tramite la sua API REST. Utilizza questa competenza ogni volta che l'utente desidera interrogare o controllare la propria rete UniFi: elencare i client connessi, bloccare/sbloccare i dispositivi, gestire le policy del firewall, controllare l'integrità della WAN e i risultati dei test di velocità, riavviare i dispositivi, gestire VLAN o SSID, leggere le statistiche del traffico, il port forwarding o qualsiasi altra attività di gestione della rete UniFi. Si attiva anche se l'utente non dice "API" o "UniFi": frasi come "controlla la mia rete", "blocca quel dispositivo", "mostrami chi è connesso", "aggiungi una regola firewall", "qual è il mio IP WAN", "com'è la mia velocità Internet" o "cosa c'è sulla rete ospite" sono tutti ottimi trigger.
