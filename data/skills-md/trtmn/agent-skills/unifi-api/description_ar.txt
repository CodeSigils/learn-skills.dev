تفاعل مع UniFi Dream Router (UDR) أو أي وحدة تحكم UniFi OS عبر REST API. استخدم هذه المهارة عندما يريد المستخدم الاستعلام عن شبكة UniFi الخاصة به أو التحكم فيها - إدراج العملاء المتصلين، أو حظر/إلغاء حظر الأجهزة، أو إدارة سياسات جدار الحماية، أو التحقق من صحة شبكة WAN ونتائج اختبار السرعة، أو إعادة تشغيل الأجهزة، أو إدارة شبكات VLAN أو SSID، أو قراءة إحصائيات حركة المرور، أو إعادة توجيه المنافذ، أو أي مهمة أخرى لإدارة شبكة UniFi. قم بالتشغيل حتى لو لم يقل المستخدم "API" أو "UniFi" - عبارات مثل "تحقق من شبكتي"، أو "احظر هذا الجهاز"، أو "أظهر لي من المتصل"، أو "أضف قاعدة جدار الحماية"، أو "ما هو عنوان IP الخاص بشبكة WAN"، أو "كيف هي سرعة الإنترنت لدي"، أو "ما هو موجود على شبكة الضيف" كلها مشغلات جيدة.
