Interagissez avec un UniFi Dream Router (UDR) ou n'importe quelle console UniFi OS via son API REST. Utilisez cette compétence chaque fois que l'utilisateur souhaite interroger ou contrôler son réseau UniFi : répertorier les clients connectés, bloquer/débloquer les appareils, gérer les politiques de pare-feu, vérifier l'état du WAN et les résultats des tests de vitesse, redémarrer les appareils, gérer les VLAN ou les SSID, lire les statistiques de trafic, la redirection de port ou toute autre tâche de gestion de réseau UniFi. Déclenchez même si l'utilisateur ne dit pas « API » ou « UniFi » – des expressions telles que « vérifier mon réseau », « bloquer cet appareil », « me montrer qui est connecté », « ajouter une règle de pare-feu », « quelle est mon adresse IP WAN », « quelle est ma vitesse Internet » ou « ce qu'il y a sur le réseau invité » sont tous de bons déclencheurs.
