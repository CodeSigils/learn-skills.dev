REST API を介して UniFi Dream Router (UDR) または任意の UniFi OS コンソールと対話します。ユーザーが UniFi ネットワークのクエリや制御を行う場合、接続されたクライアントの一覧表示、デバイスのブロック/ブロック解除、ファイアウォール ポリシーの管理、WAN の健全性と速度テスト結果の確認、デバイスの再起動、VLAN または SSID の管理、トラフィック統計の読み取り、ポート転送、またはその他の UniFi ネットワーク管理タスクを行う場合は常にこのスキルを使用します。ユーザーが「API」や「UniFi」と言わなくてもトリガーします。「ネットワークを確認してください」、「そのデバイスをブロックしてください」、「誰が接続しているかを表示してください」、「ファイアウォール ルールを追加してください」、「私の WAN IP は何ですか」、「インターネット速度はどうですか」、または「ゲスト ネットワーク上にあるものは何ですか」などのフレーズはすべて適切なトリガーです。
