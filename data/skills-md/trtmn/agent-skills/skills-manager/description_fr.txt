Installez, supprimez, répertoriez, recherchez et mettez à jour les compétences Claude Code à l'aide de la CLI « npx skills ». Utilisez cette compétence chaque fois que l'utilisateur souhaite gérer ses compétences d'agent : installez une nouvelle compétence, recherchez dans le registre des compétences, supprimez une compétence, recherchez des mises à jour ou mettez à jour toutes les compétences. Déclenchez également des requêtes telles que « trouvez-moi une compétence pour X », « installez la compétence Y », « quelles compétences ai-je installées », « supprimez la compétence Z » ou « mes compétences sont-elles à jour ».
