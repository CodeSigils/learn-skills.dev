Installieren, entfernen, auflisten, suchen und aktualisieren Sie Claude Code-Skills mithilfe der „npx skills“-CLI. Verwenden Sie diesen Skill immer dann, wenn der Benutzer seine Agenten-Skills verwalten möchte – einen neuen Skill installieren, die Skills-Registrierung durchsuchen, einen Skill entfernen, nach Updates suchen oder alle Skills aktualisieren möchte. Wird auch für Anfragen wie „Such mir einen Skill für X“, „Installiere den Y-Skill“, „Welche Skills habe ich installiert“, „Entferne den Z-Skill“ oder „Sind meine Skills auf dem neuesten Stand“ ausgelöst.
