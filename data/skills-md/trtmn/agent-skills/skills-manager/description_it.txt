Installa, rimuovi, elenca, trova e aggiorna le competenze di Claude Code utilizzando la CLI "npx skills". Utilizza questa competenza ogni volta che l'utente desidera gestire le proprie competenze dell'agente: installa una nuova competenza, cerca nel registro delle competenze, rimuovi una competenza, controlla gli aggiornamenti o aggiorna tutte le competenze. Attiva anche richieste come "trovami una competenza per X", "installa la competenza Y", "quali competenze ho installato", "rimuovi la competenza Z" o "le mie competenze sono aggiornate".
