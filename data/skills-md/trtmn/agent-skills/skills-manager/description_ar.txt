قم بتثبيت مهارات Claude Code وإزالتها وإدراجها والعثور عليها وتحديثها باستخدام واجهة سطر الأوامر "npx Skills". استخدم هذه المهارة عندما يريد المستخدم إدارة مهارات الوكيل الخاصة به — قم بتثبيت مهارة جديدة، أو ابحث في سجل المهارات، أو أزل مهارة، أو تحقق من التحديثات، أو قم بتحديث جميع المهارات. يمكنك أيضًا تشغيل طلبات مثل "أعثر لي على مهارة لـ X"، أو "تثبيت المهارة Y"، أو "ما المهارات التي قمت بتثبيتها"، أو "إزالة المهارة Z"، أو "هل مهاراتي محدثة".
