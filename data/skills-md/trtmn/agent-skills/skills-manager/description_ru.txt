Устанавливайте, удаляйте, перечисляйте, находите и обновляйте навыки Claude Code с помощью интерфейса командной строки npxkills. Используйте этот навык всякий раз, когда пользователь хочет управлять своими навыками агента: установить новый навык, выполнить поиск в реестре навыков, удалить навык, проверить наличие обновлений или обновить все навыки. Также вызывает запросы типа «найди мне навык для X», «установи навык Y», «какие навыки у меня установлены», «удали навык Z» или «обновлены ли мои навыки».
