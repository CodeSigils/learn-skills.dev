Instale, elimine, enumere, busque y actualice las habilidades de Claude Code utilizando la CLI `npx skills`. Utilice esta habilidad siempre que el usuario desee administrar las habilidades de su agente: instale una nueva habilidad, busque en el registro de habilidades, elimine una habilidad, busque actualizaciones o actualice todas las habilidades. También activa solicitudes como "búsqueme una habilidad para X", "instalar la habilidad Y", "qué habilidades tengo instaladas", "eliminar la habilidad Z" o "mis habilidades están actualizadas".
