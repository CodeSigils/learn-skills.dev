Guide expert pour la gestion des fichiers de stratégie tailnet (ACL) Tailscale. Couvre le format de fichier de stratégie HuJSON, toutes les sections de stratégie (acls, groupes, balises, règles SSH, autoApprovers, tests), l'API Tailscale pour valider et appliquer les stratégies, et l'automatisation GitOps via les actions GitHub afin que les modifications soient automatiquement validées sur les PR et déployées lors de la fusion. Utilisez cette compétence chaque fois que l'utilisateur travaille avec des ACL ou des fichiers de stratégie Tailscale, souhaite configurer une gestion des stratégies basée sur git, doit écrire ou déboguer des règles d'accès, souhaite automatiser le déploiement de stratégies ou mentionne tailnet, Tailscale ACL, Policy.hujson, gitops-acl-action ou autorisations réseau Tailscale. Déclenchez également des questions telles que « comment restreindre les appareils qui peuvent communiquer entre eux sur Tailscale » ou « comment configurer les règles SSH de Tailscale ».
