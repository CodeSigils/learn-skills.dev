Tailscale テールネット ポリシー ファイル (ACL) を管理するための専門ガイド。 HuJSON ポリシー ファイル形式、すべてのポリシー セクション (acls、グループ、タグ、SSH ルール、autoApprovers、テスト)、ポリシーを検証および適用するための Tailscale API、および GitHub Actions を介した GitOps 自動化をカバーしているため、変更は PR で自動的に検証され、マージ時にデプロイされます。このスキルは、ユーザーが Tailscale ACL またはポリシー ファイルを操作している場合、Git ベースのポリシー管理をセットアップしたい場合、アクセス ルールの作成またはデバッグが必要な場合、ポリシーの展開を自動化したい場合、または tailnet、Tailscale ACL、policy.hujson、gitops-acl-action、または Tailscale ネットワーク権限について言及する場合に使用します。また、「Tailscale で相互に通信できるデバイスを制限するにはどうすればよいですか」または「Tailscale SSH ルールを設定するにはどうすればよいですか」などの質問もトリガーされます。
