Extrahieren und laden Sie alle Schriftarten von einer Website herunter, organisiert in ./fonts/<font-family>/-Unterverzeichnissen. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Schriftarten von einer Website oder URL abrufen, rippen, herunterladen oder extrahieren möchte – auch wenn er nur sagt: „Laden Sie die Schriftarten von dieser Website“, „Laden Sie die auf dieser Seite verwendeten Schriftarten herunter“ oder „Welche Schriftarten verwendet diese Website?“. Funktioniert sowohl mit statischen als auch mit JavaScript gerenderten Seiten.
