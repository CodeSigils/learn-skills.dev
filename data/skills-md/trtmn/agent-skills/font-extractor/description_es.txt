Extraiga y descargue todas las fuentes de un sitio web, organizadas en subdirectorios ./fonts/<font-family>/. Utilice esta habilidad siempre que el usuario quiera tomar, copiar, descargar o extraer fuentes de un sitio web o URL, incluso si simplemente dice "obtener las fuentes de este sitio", "descargar las fuentes utilizadas en esta página" o "¿qué fuentes utiliza este sitio web?". Funciona con páginas estáticas y renderizadas en JavaScript.
