Enregistre automatiquement les corrections, les erreurs et les apprentissages dans .learnings/ et favorise les informations les plus précieuses dans la mémoire permanente (projet CLAUDE.md ou utilisateur ~/.claude/CLAUDE.md), de sorte que chaque erreur est une erreur ponctuelle. DOIT utiliser cette compétence chaque fois que l'utilisateur corrige Claude (« en fait, cela devrait être... », « ne fais pas ça », « je te l'ai dit la dernière fois », « je dois continuer à te corriger », « c'est faux »), une commande ou un outil échoue de manière inattendue, l'utilisateur demande à Claude de se souvenir de quelque chose pour les sessions futures (« enregistrer ceci », « se souvenir de cela », « ajouter ceci à votre mémoire », « apprendre de ceci », « assurez-vous que nous ne frappons plus ceci », « suivre ceci », « ne pas oublier »), ou l'utilisateur souhaite examiner les PR/problèmes de GitHub pour connaître les modèles et les leçons récurrents. Déclenchez également après des sessions de débogage importantes lorsque l'utilisateur souhaite capturer ce qui n'a pas fonctionné ou lorsqu'il demande une révision de fin de session de ce qui a été appris. Ne déclenchez PAS pour des tâches de codage normales telles que l'écriture de scripts, la refactorisation, le débogage, la configuration de projets, l'écriture de tests ou la révision de la qualité du code PR - déclenchez-le uniquement lorsque l'utilisateur souhaite *persister une leçon* ou lorsqu'une erreur/correction doit être suivie pour référence future.
