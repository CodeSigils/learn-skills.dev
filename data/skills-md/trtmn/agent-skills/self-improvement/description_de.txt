Protokolliert Korrekturen, Fehler und Erkenntnisse automatisch in .learnings/ und speichert die wertvollsten Erkenntnisse im permanenten Speicher (Projekt CLAUDE.md oder Benutzer ~/.claude/CLAUDE.md), sodass jeder Fehler ein einmaliger Fehler ist. Diese Fähigkeit MUSS immer dann verwendet werden, wenn der Benutzer Claude korrigiert („Eigentlich sollte es so sein...“, „Tu das nicht“, „Ich habe es dir letztes Mal gesagt“, „Ich muss dich immer wieder korrigieren“, „Das ist falsch“), ein Befehl oder ein Tool unerwartet fehlschlägt, der Benutzer Claude bittet, sich etwas für zukünftige Sitzungen zu merken („Protokollieren Sie dies“, „Merken Sie sich das“, „Fügen Sie dies Ihrem Gedächtnis hinzu“, „Lernen Sie daraus“, „Stellen Sie sicher, dass wir dies nicht noch einmal tun“, „Verfolgen Sie dies“, „Vergessen Sie nicht“) oder Der Benutzer möchte GitHub-PRs/Probleme auf wiederkehrende Muster und Lektionen überprüfen. Wird auch nach umfangreichen Debugging-Sitzungen ausgelöst, wenn der Benutzer erfassen möchte, was schief gelaufen ist, oder wenn der Benutzer eine Überprüfung der Erkenntnisse am Ende der Sitzung anfordert. NICHT für normale Codierungsaufgaben wie das Schreiben von Skripten, Refactoring, Debugging, das Einrichten von Projekten, das Schreiben von Tests oder die Überprüfung der PR-Codequalität auslösen – sondern nur auslösen, wenn der Benutzer *eine Lektion beibehalten* möchte oder wenn ein Fehler/eine Korrektur zur späteren Bezugnahme nachverfolgt werden soll.
