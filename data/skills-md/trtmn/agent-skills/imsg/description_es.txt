Gestión de iMessage y SMS basada en terminal a través de la línea de comando. Utilice esta habilidad siempre que el usuario mencione mensajes de texto, mensajes, iMessage, SMS, conversaciones, historial de chat, copias de seguridad de mensajes o cualquier interacción con su base de datos de Mensajes. Activa solicitudes para enviar/recibir mensajes, ver el historial de conversaciones, enumerar chats, observar mensajes de texto entrantes, exportar o hacer copias de seguridad de mensajes, o administrar datos de iMessage/SMS, incluso si el usuario no dice explícitamente "iMessage" o "SMS". Esta es la habilidad adecuada para cualquier cosa que implique mensajes de texto, chats grupales o la aplicación Mensajes a la que se accede desde el terminal.
