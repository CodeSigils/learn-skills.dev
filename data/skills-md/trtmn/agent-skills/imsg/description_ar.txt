إدارة iMessage والرسائل النصية القصيرة المستندة إلى المحطة الطرفية عبر سطر الأوامر. استخدم هذه المهارة عندما يذكر المستخدم الرسائل النصية أو المراسلة أو iMessage أو الرسائل القصيرة أو المحادثات أو سجل الدردشة أو النسخ الاحتياطية للرسائل أو أي تفاعل مع قاعدة بيانات الرسائل الخاصة به. قم بتشغيل طلبات إرسال/استقبال الرسائل، أو عرض سجل المحادثات، أو قائمة الدردشات، أو مراقبة النصوص الواردة، أو تصدير الرسائل أو نسخها احتياطيًا، أو إدارة بيانات iMessage/SMS - حتى لو لم ينطق المستخدم صراحةً "iMessage" أو "SMS". هذه هي المهارة المناسبة لأي شيء يتضمن رسائل نصية أو محادثات جماعية أو تطبيق الرسائل الذي يمكن الوصول إليه من الجهاز.
