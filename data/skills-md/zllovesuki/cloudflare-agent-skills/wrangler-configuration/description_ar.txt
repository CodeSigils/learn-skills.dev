قم بتكوين مشاريع Cloudflare Workers باستخدام wrangler.jsonc والروابط ومتغيرات البيئة والأسرار وعلامات التوافق وأنواع TypeScript Env التي تم إنشاؤها. استخدمه عندما يحتاج الكود إلى D1 أو R2 أو KV أو الكائنات الدائمة أو قوائم الانتظار أو سير العمل أو الذكاء الاصطناعي للعمال أو Vectorize أو Hyperdrive أو الأصول أو روابط الخدمة.
