Lorsque l'utilisateur souhaite analyser les données de performances réelles de sa propre application à partir d'App Store Connect : téléchargements réels, revenus, IAP, abonnements, essais ou répartitions par pays synchronisés via Appeeky Connect. À utiliser lorsque l'utilisateur pose des questions sur « mes téléchargements », « mes revenus », « quelles sont les performances de mon application », « les données ASC », « ventes et tendances », « mes numéros d'abonnement », « métriques App Store Connect » ou souhaite comparer les périodes ou les principaux marchés. Pour obtenir des estimations sur les applications tierces, consultez App-Analytics. Pour connaître la profondeur de l’analyse des abonnements, consultez la stratégie de monétisation.
