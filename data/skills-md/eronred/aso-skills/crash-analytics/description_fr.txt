Lorsque l'utilisateur souhaite surveiller, trier ou réduire le taux de plantage de son application, notamment en configurant Crashlytics, en priorisant les plantages à corriger en premier, en interprétant les données de plantage et en comprenant comment les plantages affectent le classement de l'App Store. À utiliser lorsque l'utilisateur mentionne « crash », « crashlytics », « taux de crash », « ANR », « l'application ne répond pas », « sessions sans crash », « utilisateurs sans crash », « symbolisation », « stabilité », « crash de Firebase », « crash de l'application » ou « rapport de crash ». Pour la configuration globale de l’analyse, consultez App-Analytics.
