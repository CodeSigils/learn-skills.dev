Lorsque l'utilisateur souhaite concevoir ou optimiser l'entonnoir qui amène les visiteurs Web à installer et à intégrer l'application, y compris les bannières d'application intelligentes, les liens profonds Web vers application, les liens profonds différés, l'intégration Web (flux Web payé par Stripe avant l'installation de l'application), les codes QR, les CTA « ouvrir dans l'application » et le compromis entre le paiement sur le Web et celui dans l'application. À utiliser lorsque l'utilisateur mentionne « Web vers application », « bannière d'application intelligente », « Stripe avant l'application », « Web paywall avant l'installation », « SDK Web de branche », « entonnoir Web pour l'application », « AppsFlyer OneLink Web », « Liens universels », « Liens d'application », « Code QR vers l'application », « Ouvrir dans l'application », « Lien profond différé depuis le Web » ou « Dois-je d'abord vendre sur le Web, puis pousser vers l'application ». Pour une intégration purement intégrée à l'application, voir optimisation de l'intégration. Pour l’infra des liens profonds, voir configuration de l’attribution.
