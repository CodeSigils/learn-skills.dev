Verwendung für Snyk-gesteuerte Sicherheitsarbeiten: Führen Sie Snyk-SAST/SCA-Scans durch, überprüfen Sie Ergebnisse, selektieren Sie den Umfang oder erstellen Sie einen genehmigten Behebungsplan, bevor Sie Schwachstellen beheben. Wird nur ausgelöst, wenn der Benutzer Snyk, Scannerergebnisse, Abhängigkeits-/Quellenschwachstellen von Snyk oder die Behebung von Snyk-Ergebnissen erwähnt. Lösen Sie keine allgemeinen Überprüfungen der Sicherheitsarchitektur, Bedrohungsmodelle, manuelle OWASP-Validierung oder Fehlerbehebungen aus, die nicht von Snyk stammen.
