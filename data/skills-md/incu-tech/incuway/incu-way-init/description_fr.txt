À utiliser lors de l'adoption d'incu-way dans un référentiel pour la première fois — pour démarrer le projet afin que les flux de développement, de bogues et de sécurité aient ce dont ils ont besoin. Détecte les greenfield (nouveau dépôt vide) et les brownfield (application existante – le cas courant), échafaude CLAUDE.md, l'arborescence docs/, le modèle de branche et .ways/, et pilote la documentation architecturale/fonctionnelle du code existant. Utilisez également pour réinitialiser ou actualiser un projet qui utilise déjà incu-way.
