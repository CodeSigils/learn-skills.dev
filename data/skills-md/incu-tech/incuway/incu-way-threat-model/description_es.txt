Úselo para crear un modelo de amenaza pequeño y enfocado para el trabajo actual o el nuevo código: una característica, un servicio, una API o los cambios en la rama actual. Descompone el sistema en activos, puntos de entrada y límites de confianza, enumera las amenazas con STRIDE y registra las mitigaciones y el riesgo residual en un informe rastreable con un diagrama de flujo de datos. Invoque de forma independiente para modelar amenazas de un componente, o desde otro flujo (incu-way-desarrollo después del PRD/plan, incu-way-bugs para una solución relevante para la seguridad) para exponer las amenazas antes de que se escriba o envíe el código. Especialmente importante para nuevas superficies externas, flujos de autenticación/pago/PII o cambios en los límites de confianza.
