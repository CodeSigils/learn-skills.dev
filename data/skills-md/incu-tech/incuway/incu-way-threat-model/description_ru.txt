Используйте для создания небольшой, сфокусированной модели угроз для текущей работы или нового кода — функции, службы, API или изменений в текущей ветке. Декомпозирует систему на активы, точки входа и границы доверия, перечисляет угрозы с помощью STRIDE и записывает меры по снижению и остаточный риск в отслеживаемом отчете с диаграммой потока данных. Вызовите автономный вызов для моделирования угроз компонента или из другого потока (incu-way-development после PRD/плана, incu-way-bugs для исправления, связанного с безопасностью), чтобы выявить угрозы до того, как код будет написан или отправлен. Особенно важно для новых внешних поверхностей, потоков аутентификации/платежей/PII или изменений границ доверия.
