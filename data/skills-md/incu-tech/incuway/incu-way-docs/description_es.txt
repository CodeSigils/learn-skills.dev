Úselo para producir o actualizar la documentación arquitectónica y funcional de una base de código existente (brownfield) para que los humanos y los flujos incu-way entiendan la aplicación. Invocado por incu-way-init durante la incorporación de instalaciones abandonadas, o de forma independiente para documentar un módulo o actualizar documentos obsoletos. Especialmente importante cuando el repositorio tiene código real pero no documentos de arquitectura vivos, o cuando los documentos existentes se han desviado del código.
