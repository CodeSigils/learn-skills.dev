Úselo para convertir una necesidad, una idea o una solicitud de un cliente en bruto en tickets listos para el desarrollo antes de que comience cualquier flujo de desarrollo: valide la viabilidad con respecto a las bases de código reales, mapee los repositorios afectados y los contratos entre repositorios, y cierre las preguntas abiertas por adelantado. Activador para "refinar este ticket", "escribir los requisitos para X", "es factible X", "preparar tickets para esta necesidad" o cuando una solicitud abarca varios repositorios. No active tickets que ya estén bien especificados, informes de defectos simples (use incu-way-bugs) o cuando el usuario solicite comenzar a construir de inmediato.
