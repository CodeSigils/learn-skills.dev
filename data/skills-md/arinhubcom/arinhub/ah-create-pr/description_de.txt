Verwenden Sie diesen Skill, um eine GitHub-Pull-Anfrage zu erstellen, wenn Sie das Präfix „ah“ verwenden. Wird verwendet, wenn Sie nach „ah create pr“, „ah create pull request“ oder „ah pr“ gefragt werden. Analysiert den aktuellen Zweig, führt Qualitätsprüfungen durch, generiert eine gut strukturierte PR mit Zusammenfassung, Änderungen, Tests und verknüpften Problemen und erstellt sie dann über „gh pr create“.
