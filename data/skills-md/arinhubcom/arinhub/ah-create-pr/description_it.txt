Utilizza questa abilità per creare una richiesta pull GitHub quando usi il prefisso "ah". Da utilizzare quando viene richiesto "ah create pr", "ah create pull request" o "ah pr". Analizza il ramo corrente, esegue controlli di qualità, genera un PR ben strutturato con riepilogo, modifiche, test e problemi collegati, quindi lo crea tramite `gh pr create`.
