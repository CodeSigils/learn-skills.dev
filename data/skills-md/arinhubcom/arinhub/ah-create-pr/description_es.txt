Utilice esta habilidad para crear una solicitud de extracción de GitHub cuando utilice el prefijo "ah". Úselo cuando se le solicite "ah create pr", "ah create pull request" o "ah pr". Analiza la rama actual, ejecuta controles de calidad, genera un PR bien estructurado con resumen, cambios, pruebas y problemas vinculados, luego lo crea a través de "gh pr create".
