Используйте этот навык, чтобы создать запрос на извлечение GitHub с префиксом «ah». Используйте, когда вас просят «ах создать PR», «ах создать запрос на включение» или «ах PR». Анализирует текущую ветку, выполняет проверки качества, генерирует хорошо структурированный PR со сводкой, изменениями, тестами и связанными проблемами, а затем создает его с помощью `gh pr create`.
