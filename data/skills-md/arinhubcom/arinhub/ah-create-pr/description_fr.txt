Utilisez cette compétence pour créer une Pull Request GitHub lorsque vous utilisez le préfixe « ah ». À utiliser lorsqu'on vous demande « ah create pr », « ah create pull request » ou « ah pr ». Analyse la branche actuelle, effectue des contrôles de qualité, génère un PR bien structuré avec un résumé, des modifications, des tests et des problèmes liés, puis le crée via `gh pr create`.
