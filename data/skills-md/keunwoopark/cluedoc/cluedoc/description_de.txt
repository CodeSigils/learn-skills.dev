Dokumentieren Sie eine Codebasis automatisch als eine Reihe miteinander verbundener, visueller „Papiere“. Verwenden Sie es proaktiv, nachdem Sie Codeänderungen vorgenommen haben, um die Dokumente in .cluedoc/ synchron zu halten – indem Sie die Dokumente für Funktionen aktualisieren, die hinzugefügt, geändert oder entfernt wurden – ohne dass Sie dazu aufgefordert werden. Wird auch verwendet, wenn der Benutzer explizit Dokumentation für ein Repository (Monorepo oder Einzelpaket) generieren oder vollständig neu synchronisieren möchte. Wenn der Benutzer außerdem eine Frage dazu stellt, wie das System funktioniert und .cluedoc/-Artikel vorhanden sind, fügen Sie der Antwort einen kurzen „Leseleitfaden“ hinzu, der auf die relevantesten vorhandenen Artikel zum Lesen verweist.
