Documente automáticamente una base de código como un conjunto de "documentos" visuales interconectados. Úselo de manera proactiva después de realizar cambios en el código para mantener sincronizados los documentos en .cluedoc/ (actualizando los documentos para las características que se agregaron, cambiaron o eliminaron) sin que se lo soliciten. Úselo también cuando el usuario desee explícitamente generar o resincronizar completamente la documentación para un repositorio (monorepo o paquete único). Además, siempre que el usuario haga una pregunta sobre cómo funciona el sistema y existen artículos .cluedoc/, agregue una breve "Guía de lectura" a la respuesta que indique los artículos existentes más relevantes para leer.
