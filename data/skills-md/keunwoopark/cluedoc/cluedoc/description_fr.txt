Automatically document a codebase as a set of interlinked, visual "papers". Utilisez de manière proactive après avoir apporté des modifications au code pour garder les documents dans .cluedoc/ synchronisés (en mettant à jour les documents pour les fonctionnalités qui ont été ajoutées, modifiées ou supprimées) sans qu'on vous le demande. À utiliser également lorsque l'utilisateur souhaite explicitement générer ou resynchroniser entièrement la documentation pour un référentiel (monorepo ou package unique). De plus, chaque fois que l'utilisateur pose une question sur le fonctionnement du système et que des .cluedoc/papers existent, ajoutez un court « Guide de lecture » à la réponse pointant vers les articles existants les plus pertinents à lire.
