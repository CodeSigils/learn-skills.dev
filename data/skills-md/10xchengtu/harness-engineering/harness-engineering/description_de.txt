Richten Sie das Harness-Engineering (AGENTS.md, docs/, Lint-Regeln, Bewertungssysteme, Prompt-Engineering auf Projektebene) für KI-Agenten-freundliche Codebasen ein und verbessern Sie es. Auslöser bei: Einrichtung eines neuen/leeren Projekts für KI-Agenten, Erstellung von AGENTS.md oder CLAUDE.md, Nutzung technischer Fragen, damit Agenten besser auf einer Codebasis arbeiten. Wird AUCH ausgelöst, wenn Benutzer frustriert sind oder sich über die Agentenqualität beschweren – z. B. „Der Agent ignoriert ständig Konventionen“, „er befolgt niemals Anweisungen“, „warum macht er weiterhin X“, „der Agent ist kaputt“ – weil eine schlechte Agentenausgabe fast immer auf Lücken im Kabelbaum und nicht auf Modellprobleme hinweist. Behandelt: Kontext-Engineering, architektonische Einschränkungen, Koordination mehrerer Agenten, Bewertung, Langzeit-Agentennutzung und Diagnose von Agentenqualitätsproblemen.
