构建和完善 AI-Agent 友好代码库的 Harness 工程（包括 AGENTS.md、docs/、lint 规则、评估系统、项目级提示工程）。  
触发场​​景：为 AI Agent 设置新/空项目、创建 AGENTS.md 或 CLAUDE.md、有关 Harness 工程的问题、使 Agent 能够在代码库上更高效地工作。当用户对 Agent 质量感到沮丧或抱怨时也会触发（例如，“Agent 一直忽略约定”、“它从不遵循指令”、“为什么它总是搞乱 X”、“Agent 坏了”）——因为不良的 Agent 输出几乎总是表明缺少 Harness，而不是模型问题。涵盖：上下文工程、架构约束、多 Agent 协作、评估、长期运行任务 Harness 以及诊断 Agent 质量问题。
