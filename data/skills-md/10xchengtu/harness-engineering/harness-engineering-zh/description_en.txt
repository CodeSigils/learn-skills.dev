Build and improve the Harness infrastructure for AI‑Agent‑friendly codebases (including AGENTS.md, docs/, lint rules, evaluation system, and project‑level prompt engineering). Trigger scenarios: setting up a new or empty project for an AI Agent, creating AGENTS.md or CLAUDE.md, questions about the Harness infrastructure, or enabling the agent to work more efficiently on the codebase. It also triggers when a user feels frustrated or complains about agent quality (e.g., “The agent always ignores the specifications,” “It never follows instructions,” “Why does it always get X wrong,” “The agent is broken”)—because poor agent output quality almost always indicates a missing Harness rather than a model problem. Covers: context engineering, architectural constraints, multi‑agent collaboration, evaluation, long‑running‑task Harness, and agent‑quality issue diagnosis.
