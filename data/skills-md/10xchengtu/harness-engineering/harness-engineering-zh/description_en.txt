Build and improve the Harness engineering for AI‑Agent‑friendly codebases (including AGENTS.md, docs/, lint rules, evaluation system, and project‑level prompt engineering). Trigger scenarios: setting up a new/empty project for an AI Agent, creating AGENTS.md or CLAUDE.md, issues concerning the Harness engineering, and helping the Agent work more efficiently in the codebase. It also triggers when users feel frustrated or complain about Agent quality (e.g., “The agent always ignores the specs,” “It never follows instructions,” “Why does it always get X wrong,” “The agent is broken”)—because poor Agent output quality almost always indicates a missing Harness rather than a model problem. Covers: context engineering, architectural constraints, multi‑agent collaboration, evaluation, long‑running‑task Harness, and Agent quality issue diagnosis.
