Build and refine Harness engineering for AI-Agent-friendly codebases (including AGENTS.md, docs/, lint rules, eval system, project-level prompt engineering).  
Trigger scenarios: setting up a new/empty project for an AI Agent, creating AGENTS.md or CLAUDE.md, questions about Harness engineering, enabling the Agent to work more efficiently on the codebase. Also triggered when users are frustrated or complain about Agent quality (e.g., “the Agent keeps ignoring conventions,” “it never follows instructions,” “why does it always mess up X,” “the Agent is broken”)—because poor Agent output almost always signals missing Harness, not a model issue. Covers: context engineering, architectural constraints, multi-Agent collaboration, evaluation, long-running task Harness, and diagnosing Agent quality problems.
