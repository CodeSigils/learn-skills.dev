建立和改進 AI-Agent 友善程式碼庫的 Harness 工程（包括 AGENTS.md、docs/、lint 規則、評估系統、專案級提示工程）。  
觸發場景：為 AI Agent 引導新的/空的專案、創建 AGENTS.md 或 CLAUDE.md、有關 Harness 工程的問題、使 Agent 能夠在程式碼庫上更有效率地工作。當使用者對 Agent 品質感到沮喪或抱怨時也會觸發（例如，「Agent 總是忽略約定」、「它從不遵循指示」、「為什麼它總是做 X 錯誤」、「Agent 壞了」）——因為不良的 Agent 輸出幾乎總是表明缺少 Harness，而不是模型問題。涵蓋：情境工程、架構限制、多代理協作、評估、長期運行任務框架和代理品質診斷。
