Erzwingen Sie die Markdown-Ausgabeformatierungsrichtlinie, wenn der Benutzer nach vollständigem Markdown-Quellcode, rohem Markdown oder kopierbaren Markdown-Dokumenten fragt. Wird immer dann verwendet, wenn der Benutzer „Markdown ausgeben“, „Gib mir die Markdown-Quelle an“, „Markdown-Quelle“, „Roh-Markdown“ oder ähnliche Anforderungen für Markdown-Inhalte sagt, die unverändert kopiert und nicht gerendert werden sollen.
