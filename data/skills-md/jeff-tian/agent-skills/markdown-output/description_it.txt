Applica i criteri di formattazione dell'output Markdown ogni volta che l'utente richiede il codice sorgente Markdown completo, Markdown non elaborato o documenti Markdown copiabili. Da utilizzare ogni volta che l'utente dice "output markdown", "dammi l'origine markdown", "markdown 源码", "raw markdown" o richieste simili per contenuti Markdown che devono essere copiati così come sono anziché renderizzati.
