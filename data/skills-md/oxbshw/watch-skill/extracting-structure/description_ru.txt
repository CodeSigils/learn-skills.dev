Пользователь хочет извлечь структуру из просматриваемого видео — «создать главы для этого видео», «где в этой записи появляется ошибка», «превратить эту запись экрана в отчет об ошибке», «насколько сильна моя интро/зацепка». Используйте это для детерминированного извлечения из индекса — глав с временными метками, отчета об ошибках в файле с точным кадром или анализа крючков с оценкой.
