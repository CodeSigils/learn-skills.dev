Пользователь хочет, чтобы из просматриваемого видео была извлечена структура — «создать главы для этого видео», «где в этой записи появляется ошибка», «превратить эту запись экрана в отчет об ошибке», «насколько сильна моя интро/зацепка». Используйте это для детерминированного извлечения из индекса — глав с временными метками, отчета об ошибках с точным указанием кадра или анализа крючков с оценкой.
