Навык TAPD TestX, используемый для запроса репозиториев и каталогов, создания или обновления кейсов TestX, а также стабильной связи требований TAPD с кейсами TestX. Зависит от базы Tapd для предоставления OAuth и токена API состояния пользователя; при использовании содержания требований сначала подключите Tapd-story.
