Навык TAPD TestX, используемый для запроса репозиториев и каталогов, создания или обновления тестовых примеров TestX, а также надежного связывания требований TAPD с тестовыми примерами TestX. Он опирается на базу Tapd для OAuth и токенов API пользовательского уровня; когда речь идет о содержании требований, оно сначала ссылается на Tapd-story.
