تعرف على كيفية قيام مستخدم GitHub بمراجعة التعليمات البرمجية لمدة تصل إلى عام من تعليقات المراجعة الحقيقية الخاصة به، ثم مراجعة التغيير باعتباره ذلك الشخص - في الدردشة فقط، ولم يتم نشره مطلقًا على GitHub. عند استدعائه، فإنه يضمن وجود ملف التعريف وتحديثه، ثم يقوم بمراجعته على الفور. يُستخدم عندما يطلب المستخدم "مراجعة هذا مثلي" أو "مثلي"، أو يسأل عما سيشير إليه زميل العمل ("كيف يمكن لزميل الفريق أن يراجع العلاقات العامة هذه؟")، أو يطلب مراجعة محاكاة أو محاكاة أو تركيبية، أو يريد فقط إنشاء ملف تعريف للمراجع أو تحديثه. يقبل تسجيل دخول اختياري إلى GitHub (الافتراضي: المستخدم المصادق عليه) وهدف اختياري (عنوان URL للعلاقات العامة أو الرقم أو الفرع الحالي أو شجرة العمل).
