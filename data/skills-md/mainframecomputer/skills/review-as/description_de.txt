Erfahren Sie, wie ein GitHub-Benutzer Code aus bis zu einem Jahr seiner echten Rezensionskommentare überprüft und dann als diese Person eine Änderung überprüft – nur im Chat, nie auf GitHub gepostet. Wird es einfach aufgerufen, stellt es sicher, dass das Profil vorhanden und aktuell ist, und überprüft es dann sofort. Verwenden Sie diese Option, wenn der Benutzer darum bittet, „dies als ich zu bewerten“ oder „ich zu mögen“, fragt, was ein Kollege markieren würde („Wie würde dieser Teamkollege diese PR überprüfen?“), nach einer simulierten, nachgeahmten oder synthetischen Bewertung fragt oder lediglich ein Prüferprofil erstellen oder aktualisieren möchte. Akzeptiert eine optionale GitHub-Anmeldung (Standard: der authentifizierte Benutzer) und ein optionales Ziel (PR-URL oder -Nummer, aktueller Zweig oder Arbeitsbaum).
