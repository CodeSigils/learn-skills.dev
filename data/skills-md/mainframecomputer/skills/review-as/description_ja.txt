GitHub ユーザーが最長 1 年間の実際のレビュー コメントからコードをレビューし、その人として変更をレビューする方法を学びます。チャットのみで、GitHub には投稿されません。ベアで呼び出すと、プロファイルが存在し、最新であることが確認され、すぐにレビューされます。ユーザーが「私としてこれをレビューする」または「私を好きになる」ように要求する場合、同僚がどのようなフラグを立てるかを尋ねる場合 (「そのチームメイトはこの PR をどのようにレビューするでしょうか?」)、シミュレーション、模倣、または合成レビューを要求する場合、またはレビュー担当者プロフィールの作成または更新のみを希望する場合に使用します。オプションの GitHub ログイン (デフォルト: 認証されたユーザー) とオプションのターゲット (PR URL または番号、現在のブランチ、または作業ツリー) を受け入れます。
