GitHub 사용자가 최대 1년 동안의 실제 리뷰 댓글에서 코드를 검토한 후 해당 사용자로서 변경 사항을 검토하는 방법을 알아보세요. 채팅에서만 가능하며 GitHub에는 게시되지 않습니다. 베어 호출하면 프로필이 존재하고 최신 상태인지 확인한 다음 즉시 검토합니다. 사용자가 "나로서 이것을 검토" 또는 "나처럼"을 요청하거나, 동료가 무엇을 플래그할지("그 팀 동료가 이 PR을 어떻게 검토할 것인가?") 묻거나, 시뮬레이션, 모방 또는 합성 검토를 요청하거나, 검토자 프로필을 작성하거나 새로 고치기를 원하는 경우에 사용하십시오. 선택적 GitHub 로그인(기본값: 인증된 사용자) 및 선택적 대상(PR URL 또는 번호, 현재 분기 또는 작업 트리)을 허용합니다.
