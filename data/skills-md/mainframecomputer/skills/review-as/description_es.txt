Descubra cómo un usuario de GitHub revisa el código de hasta un año de sus comentarios de revisión reales y luego revisa un cambio como esa persona, solo en el chat, nunca publicado en GitHub. Al invocarlo de forma simple, garantiza que el perfil exista y esté actualizado, y luego lo revisa inmediatamente. Úselo cuando el usuario solicita "revisar esto como yo" o "me gusta", pregunta qué marcaría un compañero de trabajo ("¿cómo revisaría ese compañero de equipo este PR?"), solicita una revisión simulada, mímica o sintética, o solo quiere crear o actualizar un perfil de revisor. Acepta un inicio de sesión de GitHub opcional (predeterminado: el usuario autenticado) y un destino opcional (URL o número de PR, rama actual o árbol de trabajo).
