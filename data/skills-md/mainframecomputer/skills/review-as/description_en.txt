Learn how a GitHub user reviews code from up to a year of their real review comments, then review a change as that person — in chat only, never posted to GitHub. Invoked bare, it ensures the profile exists and is current, then immediately reviews. Use when the user asks to "review this as me" or "like me", asks what a coworker would flag ("how would that teammate review this PR?"), asks for a simulated, mimic, or synthetic review, or wants only to build or refresh a reviewer profile. Accepts an optional GitHub login (default: the authenticated user) and an optional target (PR URL or number, current branch, or working tree).
