Découvrez comment un utilisateur de GitHub révise le code d'un an maximum à partir de ses véritables commentaires de révision, puis examinez une modification en tant que cette personne - dans le chat uniquement, jamais publiée sur GitHub. Invoqué simplement, il garantit que le profil existe et est à jour, puis le révise immédiatement. À utiliser lorsque l'utilisateur demande de « réviser ceci en tant que moi » ou « comme moi », demande ce qu'un collègue signalerait (« comment ce coéquipier réviserait-il ce PR ? »), demande un avis simulé, imité ou synthétique, ou souhaite uniquement créer ou actualiser un profil de réviseur. Accepte une connexion GitHub facultative (par défaut : l'utilisateur authentifié) et une cible facultative (URL ou numéro PR, branche actuelle ou arborescence de travail).
