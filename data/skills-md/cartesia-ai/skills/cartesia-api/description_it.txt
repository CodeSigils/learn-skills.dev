Integra le API vocali Cartesia (TTS, STT, voci) nel codice dell'applicazione o nei flussi di lavoro degli agenti di codifica. Da utilizzare quando l'utente chiede informazioni su API REST/WebSocket Cartesia, SDK, chiavi API, Sonic TTS, Ink STT, ID vocali, token di accesso o incorporamento della voce in un'app. Per gli agenti distribuiti da Cartesia Line, la distribuzione CLI e la telefonia, utilizzare invece la capacità line-voice-agent.
