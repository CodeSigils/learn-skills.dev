Интегрируйте речевые API Cartesia (TTS, STT, голоса) в код приложения или рабочие процессы агента кодирования. Используйте, когда пользователь спрашивает об API-интерфейсах Cartesia REST/WebSocket, SDK, ключах API, Sonic TTS, Ink STT, голосовых идентификаторах, токенах доступа или внедрении голоса в приложение. Для развернутых агентов Cartesia Line, развертывания CLI и телефонии вместо этого используйте навык линейного голосового агента.
