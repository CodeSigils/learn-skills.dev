Integre las API de voz de Cartesia (TTS, STT, voces) en el código de la aplicación o en los flujos de trabajo del agente de codificación. Úselo cuando el usuario pregunte sobre las API, SDK, claves API, Sonic TTS, Ink STT, ID de voz, tokens de acceso o integración de voz en una aplicación de Cartesia REST/WebSocket. Para los agentes implementados de Cartesia Line, la implementación de CLI y la telefonía, utilice en su lugar la habilidad line-voice-agent.
