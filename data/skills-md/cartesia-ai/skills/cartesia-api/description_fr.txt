Intégrez les API vocales Cartesia (TTS, STT, voix) dans les flux de travail du code d'application ou des agents de codage. À utiliser lorsque l'utilisateur pose des questions sur les API, SDK, clés API, Sonic TTS, Ink STT, les identifiants vocaux, les jetons d'accès ou l'intégration de la voix dans une application. Pour les agents déployés Cartesia Line, le déploiement CLI et la téléphonie, utilisez plutôt la compétence line-voice-agent.
