دمج واجهات برمجة التطبيقات الخاصة بالكلام Cartesia (TTS وSTT والأصوات) في كود التطبيق أو سير عمل وكيل الترميز. يُستخدم عندما يسأل المستخدم عن واجهات برمجة التطبيقات Cartesia REST/WebSocket، أو SDK، أو مفاتيح API، أو Sonic TTS، أو Ink STT، أو المعرفات الصوتية، أو رموز الوصول، أو تضمين الصوت في التطبيق. بالنسبة إلى وكلاء Cartesia Line المنشورين، ونشر CLI، والاتصال الهاتفي، استخدم مهارة وكيل صوت الخط بدلاً من ذلك.
