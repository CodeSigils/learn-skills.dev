Навыки дизайна и управления интервью с помощью искусственного интеллекта. Создавайте и управляйте опросами пользователей с помощью Mizzen CLI.
Триггерные слова: создать интервью, разработать учебное пособие, исследование пользователей, интервью с пользователем, 用户访谈, 访谈设计, учебное пособие, 调研, 创建访谈, 设计大纲, исследовательское интервью, дизайн скрининга.
Основные возможности: создание интервью, разработка руководств, разработка вопросов, разработка скрининга, сбор данных разговора.
