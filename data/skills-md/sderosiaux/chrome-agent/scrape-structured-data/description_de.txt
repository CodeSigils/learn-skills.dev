Holen Sie sich die wiederkehrenden Datensätze einer Webseite (Produktraster, Suchergebnisse, Stellenangebote, Newsfeeds, Tabellen) als JSON, ohne CSS-Selektoren zu schreiben und ohne einen Modellaufruf zum Lesen des HTML-Codes aufzuwenden. Funktioniert auf Websites ohne API, einschließlich Websites mit Login- oder Bot-Schutz. Läuft lokal, eine Binärdatei, kein API-Schlüssel. Verwenden Sie diese Option, wenn der Benutzer „Scraping“ sagt, die Liste extrahieren, alle Produkte/Ergebnisse/Beiträge von abrufen, diese Seite in JSON umwandeln oder Daten von einer Website anfordern möchte, die über keine API verfügt.
