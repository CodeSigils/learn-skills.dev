Récupérez les enregistrements répétitifs d'une page Web (grilles de produits, résultats de recherche, offres d'emploi, flux d'actualités, tableaux) au format JSON, sans écrire de sélecteurs CSS et sans passer d'appel de modèle pour lire le HTML. Fonctionne sur les sites sans API, y compris ceux derrière une connexion ou une protection contre les robots. S'exécute localement, un binaire, pas de clé API. À utiliser lorsque l'utilisateur dit gratter, extraire la liste, obtenir tous les produits/résultats/publications, transformer cette page en JSON ou demander des données à un site qui n'a pas d'API.
