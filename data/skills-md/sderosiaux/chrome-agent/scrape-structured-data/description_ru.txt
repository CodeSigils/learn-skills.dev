Получите повторяющиеся записи с веб-страницы (таблицы продуктов, результаты поиска, списки вакансий, ленты новостей, таблицы) в формате JSON, не создавая селекторы CSS и не тратя вызов модели для чтения HTML. Работает на сайтах без API, в том числе за авторизацией или защитой от ботов. Запускается локально, один двоичный файл, без ключа API. Используйте, когда пользователь говорит «очистить», «извлечь список», получить все продукты/результаты/публикации, превратить эту страницу в JSON или запрашивает данные с сайта, у которого нет API.
