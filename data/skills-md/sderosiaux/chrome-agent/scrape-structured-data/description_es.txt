Obtenga los registros repetidos de una página web (cuadrículas de productos, resultados de búsqueda, listados de trabajos, fuentes de noticias, tablas) como JSON, sin escribir selectores CSS y sin gastar una llamada de modelo para leer el HTML. Funciona en sitios sin API, incluidos aquellos que cuentan con un inicio de sesión o protección contra bots. Se ejecuta localmente, un binario, sin clave API. Úselo cuando el usuario diga raspar, extraer la lista, obtener todos los productos/resultados/publicaciones, convertir esta página en JSON o solicitar datos de un sitio que no tiene API.
