Автоматизация браузера для агентов ИИ. Используйте, когда пользователь просит взаимодействовать с веб-сайтами, собирать данные, заполнять формы, делать снимки экрана или автоматизировать любую задачу браузера. Триггеры: «открыть веб-сайт», «перейти», «очистить», «заполнить форму», «щелкнуть», «сделать снимок экрана», «прочитать эту страницу», «поиск», «проверить этот сайт».
