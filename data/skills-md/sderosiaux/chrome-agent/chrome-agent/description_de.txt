Browserautomatisierung für KI-Agenten. Verwenden Sie diese Option, wenn der Benutzer mit Websites interagieren, Daten scannen, Formulare ausfüllen, Screenshots erstellen oder eine beliebige Browseraufgabe automatisieren möchte. Löst aus: „Eine Website öffnen“, „Gehe zu“, „Scrapen“, „Formular ausfüllen“, „Klicken“, „Screenshot erstellen“, „Diese Seite lesen“, „Suchen auf“, „Diese Website überprüfen“.
