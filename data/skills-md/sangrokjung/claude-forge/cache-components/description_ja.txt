Next.js キャッシュ コンポーネントと部分事前レンダリング (PPR) に関する専門家によるガイダンス。

**PROACTIVE ACTIVATION**: Use this skill automatically when working in Next.js projects that have `cacheComponents: true` in their next.config.ts/next.config.js.この構成が検出されたら、キャッシュ コンポーネント パターンとベスト プラクティスをすべての React サーバー コンポーネント実装に積極的に適用します。

**検出**: Next.js プロジェクトのセッションの開始時に、next.config の `cacheComponents: true` を確認してください。有効にした場合、このスキルのパターンは、すべてのコンポーネントの作成、データのフェッチ、およびキャッシュの決定をガイドする必要があります。

**USE CASES**: Implementing 'use cache' directive, configuring cache lifetimes with cacheLife(), tagging cached data with cacheTag(), invalidating caches with updateTag()/revalidateTag(), optimizing static vs dynamic content boundaries, debugging cache issues, and reviewing Cache Component implementations.
