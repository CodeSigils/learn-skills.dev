Composez n'importe quel document professionnel : CV, pages d'une page, livres blancs, lettres, portfolios, diaporamas. Système de conception de parchemin chaleureux avec accent bleu encre, hiérarchie basée sur les empattements et espacement éditorial serré. Prise en charge bilingue complète : les documents chinois utilisent TsangerJinKai02 + Source Han, les documents anglais utilisent Newsreader + Inter. Déclencheurs sur "做 PDF / 排版 / 生成报告 / 一页纸 / 白皮书 / 作品集 / 正式信件 / 简历 / PPT / slides / 高质量文档 /好看的排版", ou "créez-moi un CV / créez une page d'une page / concevez un diaporama / transformez-le en PDF / rendez-le présentable / peaufinez la typographie", et lorsque le contenu brut est remis pour être "composé, conçu, rendu présentable".
