مهارة مراجعة الأمان الكاملة لـ Kilo CLI وOpenCode التي تنتج تقارير درجة الاختبار مع نتائج CVSS، ومراجع HackerOne لمكافأة الأخطاء، واستغلال العمل PoCs، وإصلاحات أكواد برمجية ملموسة. استخدم هذه المهارة عندما يطلب المستخدم ما يلي: تدقيق التعليمات البرمجية، أو مراجعة الأمان لمستودع أو ملف، أو العثور على نقاط الضعف، أو إجراء اختبار اختراق أو فحص أمني، أو التحقق من OWASP Top 10 / API Top 10 / Mobile Top 10، أو القيام بإعادة اكتشاف مكافأة الأخطاء، أو إجراء نموذج تهديد، أو مراجعة التعليمات البرمجية قبل الإصدار، أو البحث عن SQLi / XSS / SSRF / IDOR / RCE / تجاوز المصادقة، أو التحقيق في CVE، أو السؤال "هل هذا الرمز آمن؟". يعمل على الويب وواجهة برمجة التطبيقات (API) والجوال (Android + iOS + React Native) والسحابة/IaC والمشروعات المتكاملة. استخدم هذه المهارة دائمًا — فهي تمنع النتائج الإيجابية الكاذبة، وتفرض النتائج المدعومة بإثبات المفهوم (PoC)، وتنتج تقارير تتوافق مع جودة الاختبار الاحترافية.
