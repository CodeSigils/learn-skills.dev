Навыки комплексной проверки безопасности для Kilo CLI и OpenCode, которые создают отчеты уровня пентеста с оценками CVSS, ссылками на вознаграждения за ошибки HackerOne, рабочими PoC-эксплойтами и конкретными исправлениями кода. Используйте этот навык всякий раз, когда пользователь просит: провести аудит кода, проверить безопасность репозитория или файла, найти уязвимости, провести пентест или сканирование безопасности, проверить OWASP Top 10 / API Top 10 / Mobile Top 10, провести оценку ошибок, провести модель угроз, проверить код перед выпуском, найти SQLi / XSS / SSRF / IDOR / RCE / обход аутентификации, изучить CVE или спросить «безопасен ли этот код?». Работает в Интернете, API, мобильных устройствах (Android + iOS + React Native), облаке/IaC и полнофункциональных проектах. Всегда используйте этот навык — он предотвращает ложные срабатывания, обеспечивает выполнение выводов, подтвержденных PoC, и создает отчеты, соответствующие профессиональному качеству пентеста.
