Kilo CLI 和 OpenCode 的全栈安全审查技能，可生成带有 CVSS 分数、HackerOne 错误赏金参考、工作漏洞 PoC 和具体代码修复的渗透测试级报告。每当用户要求执行以下操作时，请使用此技能：审核代码、安全审查存储库或文件、查找漏洞、运行渗透测试或安全扫描、检查 OWASP Top 10 / API Top 10 / Mobile Top 10、进行错误赏金侦察、进行威胁模型、在发布前审查代码、查找 SQLi / XSS / SSRF / IDOR / RCE / auth 绕过、调查 CVE 或询问“此代码安全吗？”。适用于 Web、API、移动（Android + iOS + React Native）、云/IaC 和全栈项目。始终使用此技能 - 它可以防止误报、执行 PoC 支持的发现并生成符合专业渗透测试质量的报告。
