Kilo CLI および OpenCode のフルスタック セキュリティ レビュー スキル。CVSS スコア、HackerOne バグ報奨金リファレンス、実用的なエクスプロイト PoC、および具体的なコード修正を含む侵入テスト グレードのレポートを作成します。コードの監査、リポジトリまたはファイルのセキュリティ レビュー、脆弱性の発見、ペネトレーション テストまたはセキュリティ スキャンの実行、OWASP トップ 10 / API トップ 10 / モバイル トップ 10 のチェック、バグ報奨金調査の実行、脅威モデルの実施、リリース前のコードのレビュー、SQLi / XSS / SSRF / IDOR / RCE / 認証バイパスの検索、CVE の調査、または「このコードは安全ですか?」という質問をユーザーが要求するたびに、このスキルを使用します。 Web、API、モバイル (Android + iOS + React Native)、クラウド/IaC、およびフルスタックのプロジェクトで動作します。このスキルは常に使用してください。誤検知を防止し、PoC に裏付けられた調査結果を強制し、専門的な侵入テストの品質に匹敵するレポートを作成します。
