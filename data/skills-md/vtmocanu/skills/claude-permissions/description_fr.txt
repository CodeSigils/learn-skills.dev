Gérez les autorisations Claude Code via les fichiers de configuration Dippy (globaux et au niveau du projet) et settings.json (pour les autorisations non-Bash/non-MCP telles que Read, WebFetch, Skill). À utiliser lorsque l'utilisateur demande « autoriser », « autoriser », « mettre sur liste blanche » ou « ajouter une autorisation » pour une commande ou un outil. À utiliser également pour résoudre les erreurs « autorisation refusée », vérifier les autorisations actuelles ou nettoyer les entrées obsolètes.
