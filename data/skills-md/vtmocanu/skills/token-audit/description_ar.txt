تدقيق إعداد Claude Code لنفايات الرمز المميز والتقارير فقط، دون تغيير أي ملف أو إعداد. يقيس كل محرك تكلفة باستخدام أدوات الصدفة والملفات بدلاً من التقدير، ويغطي أحجام CLAUDE.md و@imports، وخادم MCP وعدد الأدوات، وما إذا كان تأجيل الأداة نشطًا، والوكيل الذي يعطلها بصمت، ومفاتيح النموذج والجهد ومفاتيح منتصف الجلسة، والخطافات التي تقلل المخرجات، وراثة نموذج كل وكيل، وفترات cron والحلقة مقابل ذاكرة التخزين المؤقت المقاسة TTL، وتقسيم الرمز المميز لسجل الجلسة الأحدث. يُصدر جدولًا واحدًا مصنفًا حسب الخطورة بالإضافة إلى الإصلاح الفردي الأعلى تأثيرًا. يُستخدم عندما يطلب المستخدم تدقيق الرمز المميز أو إهدار السياق، أو خفض تكلفة الرمز المميز، أو شرح معدل دخول ذاكرة التخزين المؤقت المنخفض، أو تشخيص تضخم السياق. تتضمن المشغلات "إهدار الرمز المميز"، و"تدقيق الرمز المميز"، و"تضخم السياق"، و"معدل الوصول إلى ذاكرة التخزين المؤقت"، و"لماذا يكون السياق الخاص بي كبيرًا جدًا"، و"خفض تكلفة الرمز المميز".
