CI/CD パイプラインの専門家。最初は GitHub Actions ですが、原則はあらゆる Forge に移植されます。 GENERATE モードでは、インタラクティブな分析と確認の会話を通じてリポジトリのパイプラインが構築されます (質問をバッチ処理しないでください)。 ADVISE モードでは、既存の CI をレビュー、強化、デバッグ、高速化して、ベスト プラクティスやセキュリティに関する質問に答えます。 CI/CD のセットアップまたは生成、ワークフローの追加、パイプラインのレビューまたは強化、サプライ チェーン リスクの監査 (ピン留めされたアクション、キャッシュ ポイズニング、pull_request_target、トークン スコープ)、CI の高速化 (キャッシュ、パス フィルター、ジョブ DAG、ピン留めされたツール バイナリ)、または Renovate を CI ツール ピンにバンプするように配線するときに使用します。トリガーには、CI のセットアップ、ワークフローの生成、パイプラインの強化、アクションの保護、CI は安全か、CI の高速化、アクションの固定などが含まれます。
