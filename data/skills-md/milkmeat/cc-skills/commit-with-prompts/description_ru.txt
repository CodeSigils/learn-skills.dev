Сохраняет пользовательские запросы из текущего сеанса Claude Code в системе контроля версий при выполнении коммитов git.
ДОЛЖЕН использоваться всякий раз, когда пользователь запрашивает фиксацию, создание фиксации или любое действие, связанное с фиксацией —
включая «commit», «提交», «提交代码», «git commit», «/commit» или любой другой вариант.
Дополняет обычный рабочий процесс фиксации, сохраняя подсказки, которые привели к изменениям кода.
рассматривать подсказки как исходный код. Используйте этот навык, даже если пользователь явно не упоминает
подсказки — они запускаются автоматически при каждом коммите.
