Храните и извлекайте знания с помощью поиска по сходству векторов. Используйте для семантического поиска по обучению, документации и общим знаниям агентов. Поддерживает как локальные хранилища ChromaDB, так и общие хранилища Postgres (pgvector). Используйте, когда вам нужна постоянная память, обмен знаниями между агентами или семантический поиск по документам.
