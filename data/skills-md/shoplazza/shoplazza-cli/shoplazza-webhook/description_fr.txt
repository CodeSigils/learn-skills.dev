À utiliser lorsqu'un développeur d'applications doit gérer les abonnements webhook sur une boutique Shoplazza via la CLI : abonnez-vous aux événements du magasin (commande créée, produit mis à jour, …) afin que la plate-forme envoie des notifications au point de terminaison d'une application et répertorie/obtienne/met à jour/supprime/compte ces abonnements. Les déclencheurs incluent le webhook / 事件订阅 / 事件回调 / 事件通知 / 推送通知 / 回调地址 / s'abonner à un événement / notification d'événement. PAS les événements eux-mêmes dans shoplazza-orders / shoplazza-products — ce domaine possède l'ABONNEMENT.
