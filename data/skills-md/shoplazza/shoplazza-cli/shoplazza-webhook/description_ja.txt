アプリ開発者が CLI を介して Shoplazza ストアの Webhook サブスクリプションを管理する必要がある場合に使用します。ストア イベント (注文の作成、製品の更新など) をサブスクライブして、プラットフォームがアプリのエンドポイントに通知をプッシュし、それらのサブスクリプションの一覧表示/取得/更新/削除/カウントを行うようにします。トリガーには、Webhook / イベント订阅 / イベント回调 / イベント通知 / 推送通知 / 回调地址 / イベントの購読 / イベント通知が含まれます。 shoplazza-orders / shoplazza-product のイベント自体ではなく、このドメインがサブスクリプションを所有します。
