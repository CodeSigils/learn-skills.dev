Wird verwendet, wenn ein App-Entwickler Webhook-Abonnements in einem Shoplazza-Store über die CLI verwalten muss – abonnieren Sie Store-Ereignisse (Bestellung erstellt, Produkt aktualisiert usw.), damit die Plattform Benachrichtigungen an den Endpunkt einer App sendet und diese Abonnements auflistet/abruft/aktualisiert/löscht/zählt. Zu den Auslösern gehören Webhook / 事件订阅 / 事件回调 / 事件通知 / 推送通知 / 回调地址 / Abonnieren eines Ereignisses / einer Ereignisbenachrichtigung. NICHT die Ereignisse selbst in shoplazza-orders / shoplazza-products – diese Domain besitzt das ABONNEMENT.
