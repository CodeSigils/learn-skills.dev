À utiliser lorsque l'utilisateur souhaite gérer les activités de remise sur un magasin shoplazza via la CLI : campagnes promotionnelles, codes de réduction, ventes flash, offres d'achat-X-get-Y, remises/remises échelonnées satisf-N-get-M, codes de livraison gratuite, remises M-for-N (Nième article de réduction), règles d'empilement/combinaison de remises ou campagnes de coupons (bons). Les déclencheurs incluent 满减 / 折扣码 / 优惠码 / 闪购 / 满X减Y. PAS de cartes-cadeaux (crédit de magasin échangeable → cartes-cadeaux de produits shoplazza).
