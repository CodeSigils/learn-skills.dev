shoplazza CLI の共有基盤: 認証 (認証ログイン - アカウント レベルおよびストア レベル)、認証ステータス/スコープ/ログアウト、ストア切り替え (認証ストアの使用)、マルチストア プロファイル (追加/リスト/使用/名前変更/削除/情報)、3 つのアクセス層 (+ショートカット / 仕様リーフ / API レスト)、出力エンベロープ ({ok,data} / .data)、--dry-run / --jq / --fields / --format、スキーマのイントロスペクション、API REST フォールバック、更新通知、安全プロトコル、フィルター処理されたリストの読み取りを信頼する方法 (ページネーション / has_more / カーソル、サイレントドロップフィルター、完全一致精度ラダー)。 shoplazza CLI を初めて使用するとき、ストアまたはプロファイルにログイン / 承認 / 切り替えるとき、権限エラーが発生したとき、検索またはフィルターで返されすぎているように見えるとき、およびドメイン スキルを使用する前に、最初にお読みください。
