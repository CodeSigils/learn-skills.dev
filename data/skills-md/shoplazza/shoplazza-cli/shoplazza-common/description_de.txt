Gemeinsame Grundlage für die Shoplazza-CLI: Authentifizierung (Authentifizierungsanmeldung – Kontoebene und Geschäftsebene), Authentifizierungsstatus/-bereiche/Abmeldung, Geschäftswechsel (Authentifizierungsspeichernutzung), Multi-Shop-Profile (Hinzufügen/Auflisten/Verwenden/Umbenennen/Entfernen/Info), die drei Zugriffsebenen (+Shortcut / Spec Leaf / API Rest), der Ausgabeumschlag ({ok,data} / .data), --dry-run / --jq / --fields / --format, Schema Selbstbeobachtung, API-Rest-Fallback, Aktualisierungshinweis, das Sicherheitsprotokoll und wie man einem gefilterten Listenlesen vertraut (Paginierung / has_more / Cursor, stillschweigend abgelegte Filter, die Präzisionsleiter für exakte Übereinstimmungen). Lesen Sie dies ZUERST bei der ersten Verwendung der shoplazza-CLI, beim Anmelden/Autorisieren/Wechseln des Shops oder Profils, bei Berechtigungsfehlern, wenn eine Suche oder ein Filter so aussieht, als hätte sie zu viel zurückgegeben, und bevor Sie einen Domänen-Skill verwenden.
