Base condivisa per la CLI di shoplazza: autenticazione (autenticazione login - a livello di account e a livello di negozio), stato di autenticazione/ambito/logout, cambio di negozio (uso di negozio aut), profili multi-negozio (aggiungi/elenco/uso/rinomina/rimuovi/info), i tre livelli di accesso (+ collegamento / spec leaf / api rest), la busta di output ({ok,data} / .data), --dry-run / --jq / --fields / --format, introspezione dello schema, api rest fallback, avviso di aggiornamento, protocollo di sicurezza e come fidarsi di una lettura di un elenco filtrato (paginazione / has_more / cursore, filtri rilasciati silenziosamente, ladder di precisione con corrispondenza esatta). Leggi questo PRIMA al primo utilizzo della CLI di shoplazza, quando accedi/autorizzi/cambia negozio o profilo, in caso di errori di autorizzazione, quando sembra che una ricerca o un filtro restituisca troppi risultati e prima di utilizzare qualsiasi competenza di dominio.
