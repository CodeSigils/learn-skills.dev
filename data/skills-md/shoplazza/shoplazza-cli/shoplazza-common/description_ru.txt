Общая основа для CLI shoplazza: аутентификация (вход в систему на уровне учетной записи и на уровне магазина), статус аутентификации/области/выход из системы, переключение магазинов (использование аутентификации в магазине), профили нескольких магазинов (добавление/список/использование/переименование/удаление/информация), три уровня доступа (+ярлык / лист спецификации / API rest), выходной конверт ({ok,data} / .data), --dry-run / --jq / --fields / --format, схема самоанализ, резервное копирование API, уведомление об обновлении, протокол безопасности и то, как доверять чтению отфильтрованного списка (нумерация страниц/has_more/курсор, автоматически удаляемые фильтры, лестница точности точного совпадения). Прочтите это ПЕРВЫМ при первом использовании интерфейса командной строки shoplazza, при входе в систему/авторизации/переключении магазина или профиля, при ошибках разрешений, когда поиск или фильтр выглядят так, как будто он вернул слишком много, а также перед использованием каких-либо предметных навыков.
