Shoplazza CLI를 위한 공유 기반: 인증(인증 로그인 - 계정 수준 및 스토어 수준), 인증 상태/범위/로그아웃, 스토어 전환(인증 스토어 사용), 다중 스토어 프로필(추가/목록/사용/이름 변경/제거/정보), 세 가지 액세스 계층(+바로가기/사양 리프/API 나머지), 출력 봉투({ok,data} / .data), --dry-run / --jq / --fields / --format, 스키마 자체 검사, API 나머지 폴백, 업데이트 알림, 안전 프로토콜 및 필터링된 목록 읽기를 신뢰하는 방법(페이지 매김 / has_more / 커서, 자동 삭제 필터, 정확히 일치하는 정밀 사다리). Shoplazza CLI를 처음 사용할 때, 스토어나 프로필에 로그인/승인/전환할 때, 권한 오류가 있을 때, 검색이나 필터가 너무 많이 반환된 것처럼 보일 때, 도메인 기술을 사용하기 전에 먼저 이 내용을 읽어보세요.
