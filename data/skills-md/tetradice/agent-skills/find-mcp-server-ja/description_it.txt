Una competenza in lingua giapponese che assiste nella ricerca, nel confronto, nella distribuzione e nella connessione ai server MCP (Model Context Protocol) pubblici tramite add-mcp. Usalo in modo proattivo quando richieste come "Esiste un server MCP per ___?" Vengono visualizzati i messaggi "Ricerca di uno strumento MCP" o "Voglio aggiungere tramite add-mcp", gestendo tutto, dalla scoperta dei candidati al test delle operazioni utilizzando database, API esterne, operazioni sui file, integrazione GitHub, ecc. Se esiste una competenza "find-mcp-server" separata, assicurati che sia caricato solo "find-mcp-server-ja" e non caricare mai sia "find-mcp-server" che "find-mcp-server-ja".
