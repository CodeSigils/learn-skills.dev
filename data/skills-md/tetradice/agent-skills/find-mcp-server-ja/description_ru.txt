Навык японского языка, который поддерживает изучение, сравнение, развертывание общедоступных серверов MCP (протокол контекста модели) и подключение через add-mcp. Используйте его заранее, когда возникают запросы, такие как «Есть ли сервер MCP для ___?», «Ищу инструмент MCP» или «Я хочу добавить его с помощью add-mcp», обрабатывая все, от поиска кандидатов до тестирования работы через базы данных, внешние API, файловые операции, интеграцию GitHub и т. д. Если существует отдельный навык «найти-mcp-сервер», убедитесь, что загружен только «найти-mcp-сервер-ja», и никогда не загружайте оба «найти-mcp-сервер» и «найти-mcp-сервер-ja».
