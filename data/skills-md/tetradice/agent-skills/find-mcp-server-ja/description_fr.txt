Une compétence en japonais qui aide à rechercher, comparer, déployer et se connecter aux serveurs publics MCP (Model Context Protocol) via add-mcp. Utilisez-le de manière proactive lorsque des demandes surviennent telles que « Existe-t-il un serveur MCP pour XX ? », « Vous recherchez un outil MCP » ou « Je souhaite l'ajouter avec add-mcp », en gérant tout, de la découverte de candidats aux tests de fonctionnement à l'aide de bases de données, d'API externes, d'opérations de fichiers, d'intégration GitHub, etc. "trouver-mcp-server-ja".
