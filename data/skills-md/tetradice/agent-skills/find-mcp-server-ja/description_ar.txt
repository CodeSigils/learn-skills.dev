مهارة في اللغة اليابانية تدعم استكشاف خوادم MCP (بروتوكول سياق النموذج) العامة ومقارنتها ونشرها والاتصال عبر add‑mcp. استخدمه بشكل استباقي عند ظهور طلبات مثل "هل يوجد خادم MCP لـ ___؟" أو "أبحث عن أداة MCP" أو "أريد إضافتها باستخدام add‑mcp"، للتعامل مع كل شيء بدءًا من البحث عن مرشح وحتى اختبار التشغيل من خلال قواعد البيانات وواجهات برمجة التطبيقات الخارجية وعمليات الملفات وتكامل GitHub وما إلى ذلك. في حالة وجود مهارة "find‑mcp‑server" منفصلة، تأكد من تحميل "find‑mcp‑server‑ja" فقط ولا تقم بتحميل كليهما مطلقًا. "find-mcp-server" و"find-mcp-server-ja".
