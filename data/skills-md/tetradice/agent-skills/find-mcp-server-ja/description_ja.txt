パブリック MCP (Model Context Protocol) サーバーの探索、比較、展開、および add‑mcp 経由の接続をサポートする日本語スキル。 「○○用のMCPサーバーはありますか？」「MCPツールを探しています」「add‑mcpで追加したい」などのリクエストが発生した場合に積極的に使用し、候補の検索からデータベース、外部API、ファイル操作、GitHub連携などによる動作テストまで対応します。 別の「find‑mcp‑server」スキルが存在する場合は、「find‑mcp‑server‑ja」のみがロードされていることを確認してください。 「find‑mcp‑server」と「find‑mcp‑server‑ja」の両方をロードしないでください。
