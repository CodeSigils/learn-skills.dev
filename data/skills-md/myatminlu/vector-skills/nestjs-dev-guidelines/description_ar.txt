معايير الواجهة الخلفية لـ NestJS على مستوى الإنتاج لكتابة ومراجعة وتطوير خدمات TypeScript على طراز NestJS/Nest. يُستخدم عندما يحتوي الريبو على وحدات نمطية، أو وحدات تحكم، أو مقدمي خدمات/خدمات، أو DTOs، أو حراس، أو أنابيب، أو حدود موجهة إلى Nest، أو عند تصميم واجهات برمجة التطبيقات NestJS، أو الوحدات النمطية، أو عمليات الترحيل، أو المصادقة/RBAC، أو عزل SaaS متعدد المستأجرين، أو بنية DDD ذات الطبقات/السداسية، أو المنافذ/المحولات، أو حالات الاستخدام، أو أنماط المستودع/الاستعلام، أو التحقق من الصحة، أو ترقيم الصفحات، أو التخزين المؤقت، أو مرشحات معالجة الأخطاء/الاستثناءات، أو BullMQ/الوظائف، خطافات الويب، والتحميلات، وأدوات الديكور، ونطاقات الموفر، والوحدات الديناميكية، والتخفيضات الدائرية، والصحة/الاستعداد/إيقاف التشغيل، وقابلية المراقبة/التسجيل/التتبع، والقياس عن بعد المفتوح، والاختبار، ومراجعة التعليمات البرمجية، ونصائح التحديث/الإصدار/وقت التشغيل، أو أنماط الواجهة الخلفية للذكاء الاصطناعي مثل بوابات LLM، وتدفق SSE، وقياس الاستخدام، والحصص. تحقق من الإصدارات / الأوامر / معرفات النماذج / الحزم / واجهات برمجة التطبيقات (APIs) المتقلبة مقابل المستندات الرسمية والريبو. عادي Express/Fastify/Hono/Koa بدون حدود Nest: إرشادات شاملة فقط. ليس للواجهات الخلفية غير المرتبطة بالعقدة أو أعمال الواجهة الأمامية الخالصة.
