Estándares backend de NestJS de nivel de producción para escribir, revisar y desarrollar servicios NestJS/TypeScript estilo Nest. Úselo cuando un repositorio tenga módulos, controladores, proveedores/servicios, DTO, protecciones, tuberías o límites orientados a Nest, o al diseñar API de NestJS, módulos, migraciones, autenticación/RBAC, aislamiento SaaS multiinquilino, arquitectura DDD en capas/hexagonal, puertos/adaptadores, casos de uso, patrones de repositorio/consulta, validación, paginación, almacenamiento en caché, manejo de errores/filtros de excepción, BullMQ/trabajos, webhooks, cargas, decoradores, alcances de proveedores, módulos dinámicos, departamentos circulares, estado/preparación/apagado, observabilidad/registro/rastreo, OpenTelemetry, pruebas, revisión de código, modernización/versión/consejos de tiempo de ejecución o patrones de backend de IA como puertas de enlace LLM, transmisión SSE, medición de uso y cuotas. Verifique las versiones/comandos/ID de modelo/paquetes/API volátiles con los documentos oficiales y el repositorio. Plain Express/Fastify/Hono/Koa sin límites Nest: solo orientación transversal. No para backends que no sean de Node ni para trabajos de frontend puros.
