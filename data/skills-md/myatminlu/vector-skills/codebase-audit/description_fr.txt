Audit médico-légal de l'ensemble du code et refactorisation par étapes. Utilisez cette compétence chaque fois que l'utilisateur souhaite qu'une base de code soit révisée, auditée, nettoyée, refactorisée ou "rendue systématique" - et également chaque fois qu'il mentionne du code dupliqué, des fonctionnalités ou des services dupliqués, des modules copiés-collés, un pansement ou une solution rapide ou un code piraté, une dette technique, des implémentations héritées ou nouvelles vivant côte à côte, du code mort, des odeurs de code ou veut vérifier que les fonctionnalités, les fonctions et les services sont réellement connectés ensemble et fonctionnent de bout en bout. Déclenchez-le pour des requêtes telles que "examiner ma base de code", "trouver la logique en double", "pourquoi ce code est-il si compliqué", "vérifier si tout est correctement connecté" ou "planifier un refactor", même lorsque l'utilisateur ne prononce pas le mot "audit". Ne l'utilisez PAS pour une révision d'un seul fichier, une seule correction de bug ou l'écriture de nouvelles fonctionnalités.
