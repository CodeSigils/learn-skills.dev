تدقيق قاعدة التعليمات البرمجية الكاملة للطب الشرعي وإعادة البناء على مراحل. استخدم هذه المهارة عندما يريد المستخدم مراجعة قاعدة التعليمات البرمجية، أو تدقيقها، أو تنظيفها، أو إعادة هيكلتها، أو "جعلها منهجية" - وأيضًا عندما يذكر تعليمات برمجية مكررة، أو ميزات أو خدمات مكررة، أو وحدات نمطية تم لصقها، أو ضمادات أو إصلاح سريع أو تعليمات برمجية مخترقة، أو ديون فنية، أو تطبيقات قديمة مقابل تطبيقات جديدة تعيش جنبًا إلى جنب، أو تعليمات برمجية ميتة، أو رائحة التعليمات البرمجية، أو يريد التحقق من أن الميزات والوظائف والخدمات متصلة بالفعل ببعضها البعض وتعمل من النهاية إلى النهاية. قم بتشغيله لطلبات مثل "مراجعة قاعدة التعليمات البرمجية الخاصة بي" أو "البحث عن منطق مكرر" أو "لماذا يوجد هذا الرمز في حالة من الفوضى" أو "التحقق مما إذا كان كل شيء متصلاً بشكل صحيح" أو "التخطيط لإعادة البناء"، حتى عندما لا يقول المستخدم كلمة "تدقيق". لا تستخدمه لمراجعة ملف واحد، أو إصلاح خطأ واحد، أو كتابة ميزات جديدة.
