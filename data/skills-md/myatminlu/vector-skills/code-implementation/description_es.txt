Flujo de trabajo disciplinado y de nivel arquitecto para implementar, arreglar o refactorizar código en una base de código existente. Utilice esta habilidad para CUALQUIER tarea que cambie el código fuente (nuevas funciones, correcciones de errores, refactorizaciones, integraciones, migraciones, trabajo de rendimiento o "sólo un pequeño cambio") y especialmente cuando el usuario dice que algo está roto, duplicado, parcheado, inconsistente o no conectado correctamente. Obliga al agente a leer el código real antes de escribirlo, rastrear la causa raíz en lugar de parchear los síntomas, reutilizar lo que ya existe en lugar de agregar código casi duplicado y verificar el cambio de principio a fin. Úselo incluso cuando la solución parezca obvia.
