既存のコードベースでコードを実装、修正、またはリファクタリングするための、規律あるアーキテクト グレードのワークフロー。このスキルは、ソース コードを変更するあらゆるタスク (新機能、バグ修正、リファクタリング、統合、移行、パフォーマンス作業、または「ほんの小さな変更」) に使用します。特に、何かが壊れている、重複している、パッチが当てられている、一貫性がない、または正しく接続されていないとユーザーが言った場合に使用してください。これにより、エージェントはコードを書き込む前に実際のコードを読み取り、症状にパッチを当てる代わりに根本原因を追跡し、重複に近いコードを追加する代わりに既存のものを再利用し、変更をエンドツーエンドで検証する必要があります。修正が明らかな場合でも使用してください。
