Дисциплинированный рабочий процесс архитектурного уровня для реализации, исправления или рефакторинга кода в существующей кодовой базе. Используйте этот навык для ЛЮБОЙ задачи, которая изменит исходный код — новые функции, исправления ошибок, рефакторинг, интеграцию, миграцию, работу над производительностью или «просто небольшое изменение» — и особенно когда пользователь говорит, что что-то сломано, дублировано, исправлено, противоречиво или не соединено должным образом. Это заставляет агента читать реальный код перед его написанием, отслеживать основную причину вместо исправления симптомов, повторно использовать то, что уже существует, вместо добавления почти повторяющегося кода и проверять изменения от начала до конца. Используйте его, даже если исправление кажется очевидным.
