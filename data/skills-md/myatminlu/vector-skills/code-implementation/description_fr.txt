Flux de travail discipliné de niveau architecte pour implémenter, corriger ou refactoriser le code dans une base de code existante. Utilisez cette compétence pour TOUTE tâche qui modifiera le code source (nouvelles fonctionnalités, corrections de bugs, refactorisations, intégrations, migrations, travaux de performance ou "juste un petit changement") - et en particulier lorsque l'utilisateur dit que quelque chose est cassé, dupliqué, corrigé, incohérent ou mal câblé. Cela oblige l'agent à lire le code réel avant d'en écrire, à rechercher la cause première au lieu de corriger les symptômes, à réutiliser ce qui existe déjà au lieu d'ajouter du code presque en double et à vérifier la modification de bout en bout. Utilisez-le même lorsque le correctif semble évident.
