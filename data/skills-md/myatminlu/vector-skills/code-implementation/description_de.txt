Disziplinierter Workflow auf Architektenniveau zum Implementieren, Korrigieren oder Refactoring von Code in einer vorhandenen Codebasis. Verwenden Sie diese Fähigkeit für JEDE Aufgabe, die den Quellcode ändert – neue Funktionen, Fehlerbehebungen, Refaktorierungen, Integrationen, Migrationen, Leistungsarbeiten oder „nur eine kleine Änderung“ – und insbesondere, wenn der Benutzer sagt, dass etwas kaputt, dupliziert, gepatcht, inkonsistent oder nicht richtig miteinander verbunden ist. Es zwingt den Agenten, den echten Code zu lesen, bevor er Code schreibt, die Grundursache zu verfolgen, anstatt Symptome zu patchen, bereits Vorhandenes wiederzuverwenden, anstatt nahezu doppelten Code hinzuzufügen, und die Änderung von Anfang bis Ende zu überprüfen. Verwenden Sie es auch dann, wenn die Lösung offensichtlich erscheint.
