مراجعة صارمة ومدعومة بالأدلة وقابلة للقراءة فقط لجودة التعليمات البرمجية والتي تنتج نتائج مصنفة حسب الخطورة وبطاقة أداء وحكم دمج/شحن. استخدم هذه المهارة عندما يطلب المستخدم مراجعة الكود أو فحص الجودة أو العلاقات العامة أو مراجعة الفرق، "هل هذا الكود جيد"، "التحقق من الكود الخاص بي"، "مراجعة هذا الملف"، فحص صحي، بوابة دمج مسبقة، رأي ثانٍ حول الكود الذي كتبه وكيل الذكاء الاصطناعي أو زميل الفريق، أو يريد التحقق من الامتثال لأفضل الممارسات/المعايير - بما في ذلك عندما يقومون ببساطة بلصق الكود والسؤال عن الخطأ فيه. قم أيضًا بتشغيل الإشارات إلى روائح التعليمات البرمجية، أو قابلية الصيانة، أو سهولة القراءة، أو التعليمات البرمجية الميتة، أو المنطق المكرر، أو إصلاحات المساعدة الشريطية، أو معالجة الأخطاء، أو مراجعة الأمان، أو مراجعة الأداء، أو جودة الاختبار، أو "اجعل هذا الإنتاج جاهزًا". استخدمه حتى لملف واحد أو فرق صغير. لا تستخدمه لكتابة الإصلاح، بل قم بإنتاج النتائج، ثم قم بتسليمها إلى سير عمل التنفيذ أو إصلاح الأخطاء.
