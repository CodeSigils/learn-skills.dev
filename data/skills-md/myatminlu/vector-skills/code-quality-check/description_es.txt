Revisión rigurosa de la calidad del código, de solo lectura, respaldada por evidencia, que produce hallazgos clasificados por gravedad, un cuadro de mando y un veredicto de fusión/envío. Utilice esta habilidad siempre que el usuario solicite una revisión de código, control de calidad, relaciones públicas o revisión de diferencias, "este código es bueno", "revise mi código", "revise este archivo", una verificación de estado, una puerta previa a la fusión, una segunda opinión sobre el código que escribió un agente de IA o un compañero de equipo, o quiere verificar el cumplimiento de las mejores prácticas/estándares, incluso cuando simplemente pegan el código y preguntan qué tiene de malo. También se activa con menciones de olores de código, mantenibilidad, legibilidad, código inactivo, lógica duplicada, correcciones de curitas, manejo de errores, revisión de seguridad, revisión de rendimiento, calidad de prueba o "preparar esta producción". Úselo incluso para un solo archivo o una pequeña diferencia. NO lo use para escribir la solución: produzca los hallazgos y luego transmítalos al flujo de trabajo de implementación o corrección de errores.
