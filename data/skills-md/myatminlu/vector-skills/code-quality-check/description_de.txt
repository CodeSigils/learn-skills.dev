Strenge, evidenzbasierte, schreibgeschützte Überprüfung der Codequalität, die nach Schweregrad eingestufte Ergebnisse, eine Scorecard und ein Merge-/Ship-Urteil liefert. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Codeüberprüfung, Qualitätsprüfung, PR- oder Diff-Überprüfung, „Ist dieser Code gut“, „Überprüfe meinen Code“, „Überprüfe diese Datei“, eine Gesundheitsprüfung, ein Pre-Merge-Gate, eine zweite Meinung zu Code, den ein KI-Agent oder ein Teamkollege geschrieben hat, fragt oder die Einhaltung von Best Practices/Standards überprüft werden möchte – auch wenn er einfach Code einfügt und fragt, was daran falsch ist. Wird auch bei Erwähnungen von Code-Smells, Wartbarkeit, Lesbarkeit, totem Code, duplizierter Logik, Pflasterkorrekturen, Fehlerbehandlung, Sicherheitsüberprüfung, Leistungsüberprüfung, Testqualität oder „Machen Sie diese Produktion bereit“ ausgelöst. Verwenden Sie es sogar für eine einzelne Datei oder ein kleines Diff. Verwenden Sie es NICHT, um den Fix zu schreiben – erstellen Sie die Ergebnisse und übergeben Sie sie dann an den Implementierungs- oder Fehlerbehebungs-Workflow.
