Examen rigoureux de la qualité du code, fondé sur des preuves et en lecture seule, qui produit des résultats classés par gravité, une carte de pointage et un verdict de fusion/expédition. Utilisez cette compétence chaque fois que l'utilisateur demande une révision du code, un contrôle de qualité, une revue de relations publiques ou une révision des différences, "ce code est-il bon", "vérifier mon code", "examiner ce fichier", un bilan de santé, une porte de pré-fusion, un deuxième avis sur le code qu'un agent d'IA ou un coéquipier a écrit, ou souhaite que la conformité aux meilleures pratiques/normes soit vérifiée - y compris lorsqu'il colle simplement du code et demande ce qui ne va pas. Déclenchez également les mentions d'odeurs de code, de maintenabilité, de lisibilité, de code mort, de logique dupliquée, de correctifs de fortune, de gestion des erreurs, d'examen de sécurité, d'examen des performances, de qualité des tests ou de "préparer cette production". Utilisez-le même pour un seul fichier ou une petite différence. Ne l'utilisez PAS pour écrire le correctif - produisez les résultats, puis transmettez-le au flux de travail d'implémentation ou de correction de bogues.
