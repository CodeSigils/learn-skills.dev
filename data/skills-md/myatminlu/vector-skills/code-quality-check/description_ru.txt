Тщательная, подтвержденная фактами проверка качества кода только для чтения, которая дает результаты по степени серьезности, систему показателей и вердикт о слиянии/отправке. Используйте этот навык всякий раз, когда пользователь запрашивает проверку кода, проверку качества, PR или проверку различий, «хорош ли этот код», «проверьте мой код», «проверьте этот файл», проверку работоспособности, шлюз перед слиянием, второе мнение о коде, написанном агентом ИИ или товарищем по команде, или хочет проверить соответствие лучшим практикам/стандартам — в том числе, когда они просто вставляют код и спрашивают, что с ним не так. Также срабатывают при упоминании запахов кода, удобства сопровождения, читабельности, мертвого кода, дублированной логики, временных исправлений, обработки ошибок, проверки безопасности, проверки производительности, качества тестирования или «подготовьте эту продукцию». Используйте его даже для одного файла или небольшого различия. НЕ используйте его для написания исправления — сделайте выводы, а затем переходите к рабочему процессу реализации или исправления ошибок.
