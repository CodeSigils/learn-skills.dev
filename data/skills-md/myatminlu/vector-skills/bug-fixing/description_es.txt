Un flujo de trabajo disciplinado a nivel de arquitecto para diagnosticar y corregir errores en una base de código existente: reproducir, leer el código real antes de tocar nada, encontrar la verdadera causa raíz, diseñar la solución mínima correcta en la capa correcta, verificarlo y buscar clones del mismo defecto. Utilice esta habilidad para CUALQUIER trabajo con defectos: fallas, excepciones, resultados incorrectos, pruebas fallidas o inestables, regresiones, condiciones de carrera, pérdidas de memoria, degradación del rendimiento, corrupción de datos, fallas de integración, problemas de funcionamiento local pero no en producción, o cualquier solicitud redactada como reparación, depuración, falla, no funciona, error o por qué sucede X. Úselo incluso cuando el error parezca trivial o el usuario ya haya propuesto una solución, especialmente entonces, porque la solución propuesta suele ser un parche a nivel de síntoma. NO lo use para trabajos de características nuevas sin ningún defecto involucrado.
