قم بإنشاء إدخال دفتر يومية عمل يومي من نشاط git وحالة شجرة العمل. استخدم هذه المهارة عندما يطلب المستخدم كتابة إدخال دفتر يومية، أو سجل يومي، أو ملخص نهاية اليوم، أو ملاحظات احتياطية، أو سجل التغيير من قاعدة التعليمات البرمجية الخاصة به. يتم تشغيله أيضًا عندما يقول المستخدم "مجلة"، أو "ماذا فعلت اليوم"، أو "تلخيص عمل اليوم"، أو "الإدخال اليومي"، أو "سجل العمل"، أو يطلب توثيق التزامات git الأخيرة في شكل سردي. يُنتج ملف مجلة سرديًا غنيًا بالإضافة إلى ملخص المشروع المتداول.
