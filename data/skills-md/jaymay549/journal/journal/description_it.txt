Genera una voce del diario di lavoro giornaliero dall'attività git e dallo stato dell'albero di lavoro. Utilizza questa abilità ogni volta che l'utente chiede di scrivere una voce di diario, un registro giornaliero, un riepilogo di fine giornata, note standup o un registro delle modifiche dalla propria base di codice. Si attiva anche quando l'utente dice "diario", "cosa ho fatto oggi", "riassume il lavoro di oggi", "voce giornaliera", "registro di lavoro" o chiede di documentare i recenti commit git in forma narrativa. Produce un ricco file di diario narrativo oltre a un riepilogo progressivo del progetto.
