ترحيل دليل تنفيذ وحدة MII KDS المنشور بواسطة Simplifier إلى قالب وحدة MII KDS - يحافظ على هوية الوحدة، وينقل عناصر FSH، ويعيد كتابة توجيهات Simplifier/FQL إلى مكافئات IG Publisher، ويقوم بإعداد مجموعة الصفحات ثنائية اللغة. يغطي كلا شكلي المصدر - مشروع SUSHI/IG-Publisher، وRepo من تأليف Forge لموارد FHIR XML/JSON الخام بدون sushi-config.yaml أو input/fsh، تم تحويلها باستخدام gofsh أولاً. يُستخدم عند نقل وحدة KDS من Simplifier أو Forge، عندما يتم تسليم عنوان URL الخاص بـ IG المقدم والمستودع الخاص به، عندما تتوقف كتل FQL أو توجيهات {{tree}} و{{render}} عن العرض بعد هذه النقلة، أو عندما يذكر المستخدم Kerndatensatz، أو KDS-Modul، أو Implementierungsleitfaden، أو Manteldokument، أو sushi-config، أو ig.ini، أو gofsh، أو StructureDefinition XML أو ناشر IG في سياق نقل الدليل. ليس لتأليف ملفات تعريف جديدة، أو إنشاء وحدة نمطية من الصفر، أو ترجمة دليل موجود بالفعل في القالب - فالكتالوج يشحن ترجمة فورية لذلك.
