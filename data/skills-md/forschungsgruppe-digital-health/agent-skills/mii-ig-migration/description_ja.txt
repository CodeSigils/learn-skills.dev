Simplifier で公開された MII KDS モジュール実装ガイドを MII KDS モジュール テンプレートに移行します。モジュールの ID を保持し、FSH アーティファクトを転送し、Simplifier/FQL ディレクティブを IG Publisher の同等のものに書き換えて、バイリンガル ページ セットをセットアップします。 SUSHI/IG-Publisher プロジェクトと、最初に gofsh で変換された、sushi-config.yaml や input/fsh を含まない生の FHIR XML/JSON リソースの Forge で作成されたリポジトリの両方のソース形状をカバーします。 KDS モジュールを Simplifier または Forge から移動するとき、レンダリングされた IG URL とそのリポジトリが引き渡されるとき、FQL ブロックまたは {{tree}} および {{render}} ディレクティブがそのような移動後にレンダリングを停止するとき、またはユーザーが Kerndatensatz、KDS-Modul、Implementierungsleitfaden、Manteldokument、sushi-config、ig.ini、gofsh、StructureDefinition XML またはガイドの移動に関する IG Publisher。新しいプロファイルを作成したり、モジュールを最初から作成したり、テンプレートにすでにあるガイドを翻訳したりするためではありません。カタログにはそのための fhir-ig-translation が同梱されています。
