يقيس واحدًا أو أكثر من أدلة تنفيذ FHIR للقراءة فقط ويبلغ عن الأرقام مثل JSON وMarkdown - النطاق والتعقيد ونظافة المحتوى والازدواجية واللغويات والنضج والمخاطر - ويقارن العديد من IGs جنبًا إلى جنب باستخدام المقاييس المعيارية. فهو يبني ويغير ولا ينشر شيئا. استخدم هذه المهارة عند مراجعة أو ضمان الجودة لوحدة MII KDS IG قبل الإصدار، أو عند مقارنة وحدة مع kerndatensatz-basis أو Implementierungsleitfaden أخرى، أو عند تتبع كيفية نمو الوحدة بين الإصدارات، أو عندما يسأل شخص ما عن حجم الدليل أو مدى نظافته أو مدى نضجه بالفعل. لا تستخدم لترحيل دليل إلى قالب الوحدة أو لترجمة دليل؛ راجع mii-ig-migration وfhir-ig-translation.
