번역 설정은 기본 언어가 아닌 언어에 대한 IG 게시자 기반 FHIR 구현 가이드 요구 사항을 보완하여 기본 언어 소스에서 번역하거나 대상 언어로 이미 게시된 렌더링을 수집하여 게시자가 읽는 위치에 각 언어를 정확하게 배치합니다. 기본 언어는 권위를 유지하며 모든 기계 번역에는 이중 언어 사람의 검토가 필요합니다. 가이드가 녹색으로 빌드되고 추가 언어 렌더링이 필요한 경우, /<lang>/ 페이지에 번역 대신 기본 언어가 표시되는 경우, .po 보충 자료 또는 번역된 페이지가 속하는 위치를 결정할 때 또는 사용자가 Übersetzung, 번역 보충 자료, 입력/번역, po 파일, i18n-lang 또는 i18n-default-lang을 언급할 때 이 기술을 사용하십시오. 가이드를 측정하거나 비교하거나, 가이드를 MII KDS 모듈 템플릿으로 마이그레이션하거나, 템플릿 패키지의 자체 언어 메커니즘에 사용하지 마세요. Fhir-ig-분석 및 mii-ig-migration을 참조하세요.
