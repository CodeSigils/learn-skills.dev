Configura los complementos de traducción que necesita una Guía de implementación FHIR basada en IG-Publisher para sus idiomas no predeterminados, colocando cada uno exactamente donde el editor lo lee, ya sea traduciendo desde la fuente del idioma predeterminado o recopilando una representación ya publicada en el idioma de destino. El idioma predeterminado sigue siendo autoritario y cada traducción automática necesita una revisión humana bilingüe. Utilice esta habilidad cuando una guía se construye en verde y se desea una representación de idioma adicional, cuando las páginas /<lang>/ muestran el idioma predeterminado en lugar de la traducción, cuando decide dónde pertenece un suplemento .po o una página traducida, o cuando el usuario menciona Übersetzung, suplemento de traducción, entrada/traducciones, archivo po, i18n-lang o i18n-default-lang. No lo use para medir o comparar guías, para migrar una a la plantilla del módulo MII KDS o para el mecanismo de lenguaje propio del paquete de plantilla; ver fhir-ig-analysis y mii-ig-migration.
