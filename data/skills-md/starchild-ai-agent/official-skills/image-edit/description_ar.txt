تحرير الصور وتحسينها: استبدال الخلفية، رفع مستوى الدقة الفائقة، استعادة الصور القديمة، التلوين، إزالة الأشخاص، تنقيح الصورة (تنعيم البشرة، إزالة العيوب)، التخسيس، تدرج الألوان، المرشحات الفنية، مزج الصور، الطلاء الخارجي، التحرير المحلي، عرض النص، إنشاء متعدد الزوايا، قبل / بعد المقارنة، إعادة تلوين السيارة، معاينة غلاف السيارة.

يُستخدم عند تحرير صورة موجودة أو تحسينها أو تحويلها (على سبيل المثال، إزالة الخلفية، أو ترقية الصورة، أو استعادة الصورة القديمة، أو تنقيح الصورة، أو تغيير لون السيارة، أو تطبيق مرشح، أو توسيع الصورة).
