Starchild Auth SDK: добавьте вход OAuth в любое веб-приложение с помощью одного SDK.

Используйте при интеграции входа в систему Starchild в проект (например, добавьте вход в систему Starchild в мое приложение React, настройте OAuth с помощью iamstarchild.com, реализуйте вход и выход из системы с помощью Starchild Auth SDK).
