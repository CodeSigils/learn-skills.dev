Starchild Auth SDK : ajoutez la connexion OAuth à n'importe quelle application Web avec un seul SDK.

À utiliser lors de l'intégration de la connexion Starchild dans un projet (par exemple, ajouter la connexion Starchild à mon application React, configurer OAuth avec iamstarchild.com, implémenter la connexion/déconnexion avec Starchild Auth SDK).
