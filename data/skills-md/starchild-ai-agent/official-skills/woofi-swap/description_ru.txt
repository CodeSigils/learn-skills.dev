Обменяйте любой токен по лучшей цене — одноцепочечный или кроссчейн — с помощью одного вызова API. WOOFi — это метаагрегатор, одновременно опрашивающий WooPP, 1inch и ODOS, возвращающий глобально оптимальную скорость (цена >= максимальная из всех источников). Межсетевой обмен через мост Звездных врат. API V2 принимает имена цепочек («арбитр») и символы токенов («USDC») — поиск адреса не требуется. Поддерживает все токены ERC-20 и собственные газовые токены в 14 цепочках EVM.
