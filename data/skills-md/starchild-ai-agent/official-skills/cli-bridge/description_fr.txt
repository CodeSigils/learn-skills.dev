Gérez les ensembles de codes courts qui autorisent la CLI starchild locale à communiquer avec cet agent, y compris le canal d'exécution local de l'agent-shell.

À utiliser lors de la connexion ou de la déconnexion de la CLI starchild (par exemple, créer un code de pont CLI, répertorier mes bundles CLI, révoquer une ancienne session CLI ou laisser l'agent exécuter des commandes shell sur la propre machine de l'utilisateur).
