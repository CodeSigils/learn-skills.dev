Управляйте пакетами коротких кодов, которые разрешают локальному CLI Starchild взаимодействовать с этим агентом, включая канал local-exec оболочки агента.

Используйте при подключении или отключении CLI Starchild (например, создайте код моста CLI, перечислите мои пакеты CLI, отмените старый сеанс CLI или позвольте агенту запускать команды оболочки на собственном компьютере пользователя).
