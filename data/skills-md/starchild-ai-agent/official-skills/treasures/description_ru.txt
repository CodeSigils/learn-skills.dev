Treasures Finance: торговля токенизированными акциями (xStocks/Ondo), мосты USDC и делегированные операции с кошельками на Solana и Ethereum.

Используйте при выполнении финансовых операций, направляемых Treasures (например, обнаружение токенизированных акций, котировка/исполнение сделки, соединение USDC между цепочками, проверка портфеля делегированного кошелька).

Базовый URL-адрес должен иметь префикс `/public/v1` (голый хост 404). Торговые пути (`/quote/*`, `/trade/submit`, `/bridge/quote`) геозонируются на балансировщике нагрузки AWS → 451 из США и Великобритании, перед аутентификацией — маршрутизируйте эти вызовы через навык `sc-vpn` с помощью прокси-сервера для каждого запроса (DE/NL/SE/CH/SG/HK/JP ясны); читает работу откуда угодно. Ошибка 451 никогда не является проблемой при подписании. См. раздел «Прочитайте это перед любой попыткой торговли».

Кошелек: ПО УМОЛЧАНИЮ для частного кошелька пользователя через `treasures-b2b-api` (кошелек подписывает `ownership_proof` для котировок + подписанные полезные данные для каждой ветви для `/trade/submit` — для подписи используйте навык `wallet`). Маршрут по местоположению активов: активы в кошельке Privy/EOA → `treasures-b2b-api`; Используйте делегированный навык `treasures-wallet` только тогда, когда пользователь явно запрашивает предоставленный Treasures кошелек или активы, находящиеся в нем.
