قم بتشغيل Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) للمستندات السحابية بمهارة رسمية. تشمل الإمكانات الأساسية إنشاء المستندات عبر الإنترنت وقراءتها وتحريرها والبحث فيها ومشاركتها وتنظيمها (المستندات الذكية وWord وExcel وPDF وPPT والعروض التقديمية والأوراق الذكية والأوراق متعددة الأبعاد) وقواعد المعرفة الشخصية. استخدمه عندما تتضمن مهمة المستخدم عمليات مستندات سحابية، بما في ذلك على سبيل المثال لا الحصر: كتابة تقارير أسبوعية/يومية أو ملخصات عمل، والتعامل مع العقود/الفواتير، وإنشاء نماذج التسجيل أو الاشتراك، وقطع الويب، وتحويل الاستجابات المتسلسلة إلى جداول بيانات، وجمع المعلومات، وتلخيص المستندات وإنشاء المحتوى، وإعادة الكتابة/إعادة الصياغة، والترجمة، وإنشاء AI PPT، وتقسيم ملفات PDF وتصديرها، وتصنيف العلامات وأرشفتها، وإدارة الإشارات المرجعية، وتنظيم ملاحظات الأجزاء، وتجميل جداول البيانات، استعادة سلة المحذوفات، وإدارة قاعدة المعرفة.
