Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) クラウドドキュメントの公式スキルを操作します。コア機能には、オンライン ドキュメント (スマート ドキュメント、Word、Excel、PDF、PPT、プレゼンテーション、スマート シート、多次元シート) および個人のナレッジ ベースの作成、読み取り、編集、検索、共有、整理が含まれます。ユーザーのタスクにクラウド ドキュメントの操作が含まれる場合に使用します。これには、週次/日次レポートまたは作業概要の作成、契約書/請求書の処理、登録フォームまたはサインアップ フォームの作成、Web クリッピング、チェーン レスポンスのスプレッドシートへの変換、情報収集、ドキュメントの要約とコンテンツの生成、リライト/言い換え、翻訳、AI PPT の生成、PDF の分割とエクスポート、タグの分類とアーカイブ、ブックマークの管理、フラグメント ノートの整理、スプレッドシートの美化、ごみ箱が含まれますが、これらに限定されません。復元とナレッジベース管理。
