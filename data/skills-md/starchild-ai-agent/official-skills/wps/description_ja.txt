Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) クラウドドキュメントの公式スキルを操作します。コア機能は、オンライン ドキュメント (スマート ドキュメント、Word、Excel、PDF、PPT、プレゼンテーション、スマート シート、多次元テーブル) と個人のナレッジ ベースのクラウド ベースの作成、読み取り、編集、検索、共有、および整理をカバーします。ユーザーのタスクにクラウド ドキュメントの操作が含まれる場合は必ず使用します。これには、週次/日次/作業報告書の作成、契約書/請求書の処理、登録フォームの作成、Web クリッピング、スプレッドシートへのチェーン変換、情報収集、文書の要約とコンテンツの生成、リライト/言い換え、翻訳、AI PPT の生成、PDF の分割/エクスポート、タグの分類とアーカイブ、ブックマークの管理、フラグメント ノートの整理、スプレッドシートの美化、ごみ箱の復元とナレッジベースの管理。
