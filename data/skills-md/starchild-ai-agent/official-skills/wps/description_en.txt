Operate Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) cloud documents official skill. Core capabilities cover creating, reading, editing, searching, sharing, and organizing online documents (smart documents, Word, Excel, PDF, PPT, presentations, smart sheets, multidimensional sheets) and personal knowledge bases. Use it when a user's task involves cloud document operations, including but not limited to: writing weekly/daily reports or work summaries, handling contracts/invoices, creating registration or sign‑up forms, web clipping, converting chain responses to spreadsheets, information collection, document summarization and content generation, rewriting/paraphrasing, translation, AI PPT generation, PDF splitting and export, tag classification and archiving, bookmark management, fragment note organization, spreadsheet beautification, recycle bin restoration, and knowledge‑base management.
