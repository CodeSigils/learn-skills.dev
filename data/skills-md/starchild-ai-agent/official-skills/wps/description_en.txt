Official skill for operating Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) cloud documents. Core capabilities cover creating, reading, editing, searching, sharing, and organizing online documents (smart documents, Word, Excel, PDF, PPT, presentations, smart tables, multi‑dimensional tables) and personal knowledge bases. It is used whenever a user's task involves cloud document operations, including but not limited to: writing weekly reports/daily reports/work summaries, processing contracts/invoices, creating registration forms/entry forms, web clipping, chain conversion to tables, information collection, document summarization and content generation, rewriting/paraphrasing, translation, AI PPT generation, PDF splitting and exporting, tag classification and archiving, favorite management, fragment note organization, spreadsheet beautification, recycle bin restoration, and knowledge base management.
