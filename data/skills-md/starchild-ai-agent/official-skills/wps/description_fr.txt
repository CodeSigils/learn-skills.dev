Utilisez la compétence officielle pour les documents cloud Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn). Les fonctionnalités de base couvrent la création, la lecture, l'édition, la recherche, le partage et l'organisation de documents en ligne (documents intelligents, Word, Excel, PDF, PPT, présentations, feuilles intelligentes, feuilles multidimensionnelles) et de bases de connaissances personnelles. Il est utilisé chaque fois que la tâche d'un utilisateur implique des opérations de documents dans le cloud, y compris, mais sans s'y limiter : la rédaction de rapports hebdomadaires/rapports quotidiens/résumés de travail, la gestion de contrats/factures, la création de formulaires d'inscription/formulaires d'enquête, le découpage Web, la conversion d'entrées chaînées en feuilles de calcul, la collecte d'informations, le résumé de documents et la génération de contenu, la réécriture/paraphrase, la traduction, la génération AI PPT, le fractionnement et l'exportation de PDF, la classification et l'archivage de balises, la gestion de collections, l'organisation de notes fragmentées, l'embellissement de feuilles de calcul, la corbeille. restauration et gestion de la base de connaissances.
