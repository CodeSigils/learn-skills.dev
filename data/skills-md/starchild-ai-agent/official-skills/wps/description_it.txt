Utilizzare Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) competenza ufficiale per documenti cloud. Le funzionalità principali riguardano la creazione, la lettura, la modifica, la ricerca, la condivisione e l'organizzazione di documenti online (documenti intelligenti, Word, Excel, PDF, PPT, presentazioni, fogli intelligenti, tabelle multidimensionali) e basi di conoscenza personali. Utilizzalo ogni volta che l'attività di un utente prevede operazioni di documenti cloud, tra cui, a titolo esemplificativo ma non esaustivo: scrittura di report settimanali/giornalieri/di lavoro, gestione di contratti o fatture, creazione di moduli di registrazione o di iscrizione, ritaglio web, conversione a catena in tabelle, raccolta di informazioni, riepilogo di documenti e generazione di contenuti, riscrittura o parafrasi, traduzione, generazione di PPT AI, suddivisione ed esportazione di PDF, etichettatura, classificazione, archiviazione, gestione dei segnalibri, organizzazione di note frammentarie, abbellimento di fogli di calcolo, ripristino del cestino e gestione della base di conoscenza.
