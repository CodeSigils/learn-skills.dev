Offizieller Skill für den Betrieb von Kingsoft Docs (WPS Cloud Docs / Kdocs / 365.kdocs.cn / www.kdocs.cn) Cloud-Dokumenten. Zu den Kernfunktionen gehören das Erstellen, Lesen, Bearbeiten, Suchen, Teilen und Organisieren von Online-Dokumenten (Smart Documents, Word, Excel, PDF, PPT, Präsentationen, Smart Sheets, mehrdimensionale Sheets) und persönlichen Wissensdatenbanken. Es wird immer dann verwendet, wenn die Aufgabe eines Benutzers Cloud-Dokumentvorgänge umfasst, einschließlich, aber nicht beschränkt auf: Verfassen von Wochen-/Tages-/Arbeitsberichten, Bearbeiten von Verträgen oder Rechnungen, Erstellen von Registrierungs- oder Anmeldeformularen, Web-Clipping, Konvertieren von Kettennachrichten in Tabellenkalkulationen, Sammeln von Informationen, Dokumentzusammenfassung und Inhaltsgenerierung, Umschreiben oder Paraphrasieren, Übersetzung, KI-PPT-Generierung, PDF-Aufteilung und -Export, Tagging, Kategorisierung und Archivierung, Lesezeichenverwaltung, Organisation von Fragmentnotizen, Verschönerung von Tabellenkalkulationen, Wiederherstellung des Papierkorbs und Wissensdatenbankverwaltung.
