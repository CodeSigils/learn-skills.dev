Compréhension vidéo pour n'importe quel modèle - relais natif pour les petits fichiers,
extraction de trames + repli de transcription audio pour les fichiers volumineux.

À utiliser lorsque l'utilisateur demande à analyser, décrire ou comprendre un fichier vidéo
(par exemple : « qu'y a-t-il dans cette vidéo », « résumer ce clip », « transcrire cet enregistrement »).
