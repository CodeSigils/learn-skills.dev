Comprensione video per qualsiasi modello: passthrough nativo per file di piccole dimensioni,
estrazione dei frame + fallback della trascrizione audio per file di grandi dimensioni.

Da utilizzare quando l'utente chiede di analizzare, descrivere o comprendere un file video
(ad esempio "cosa c'è in questo video", "riassumi questa clip", "trascrivi questa registrazione").
