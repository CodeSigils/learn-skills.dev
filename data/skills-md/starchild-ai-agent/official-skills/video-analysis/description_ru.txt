Понимание видео для любой модели — встроенная передача для небольших файлов,
извлечение кадров + запасной вариант транскрипции звука для больших файлов.

Используйте, когда пользователь просит проанализировать, описать или понять видеофайл.
(например, «что в этом видео», «подведите итоги этого клипа», «расшифруйте эту запись»).
