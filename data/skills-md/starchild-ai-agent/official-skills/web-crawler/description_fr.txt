À utiliser lorsque web_fetch normal ne peut pas lire une page, lorsqu'un site bloque la récupération de base ou lorsque l'utilisateur a besoin de contenu YouTube sous une forme prête pour l'IA. Guide l'utilisation de secours de Firecrawl pour le scraping Web d'une seule page et de SerpApi pour la recherche YouTube/les métadonnées/transcriptions vidéo uniquement.
