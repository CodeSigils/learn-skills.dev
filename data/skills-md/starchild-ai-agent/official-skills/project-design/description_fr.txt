Système de conception d'interface utilisateur professionnel : le portail de qualité visuelle pour toutes les sorties HTML.

DOIT UTILISER avec le constructeur de projet lors de la création d'une page HTML, d'un tableau de bord, d'une page de destination,
portefeuille ou application Web. le constructeur de projet gère le flux de travail d'ingénierie ; cette compétence gère
décisions de conception visuelle (palette de couleurs, typographie, mise en page, animation).

Garantit que chaque interface utilisateur générée a un aspect professionnel, moderne et unique – jamais de bêtise d'IA générique.
