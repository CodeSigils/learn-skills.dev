Создание портретов, соответствующих идентичности: профессиональные снимки, фотографии для знакомств, переносы стилей, тематические портреты, фотосерии, аватары, фотографии на документы.

Используйте при создании стилизованных портретов на основе эталонной фотографии (например, профессиональный снимок головы, аниме-аватар, портрет в стиле киберпанк, фотография из путешествия, фотография профиля знакомств, фотография для удостоверения личности).
