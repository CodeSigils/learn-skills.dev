Leiten Sie ausgehenden HTTP-Verkehr über das SC-VPN-Gateway für geografisch eingeschränkten Zugriff. Verwenden Sie diese Option, wenn ein Skript oder eine Anfrage durch regionale Einschränkungen blockiert ist und aus einem bestimmten Land angezeigt werden muss. Legen Sie KEINEN globalen Proxy fest – verwenden Sie nur einen Pro-Anfrage-Proxy.
