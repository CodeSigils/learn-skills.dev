Используйте свой собственный резидентный прокси: привязка к стране для каждого навыка, выбор маршрутизации.

Используйте, когда пользователю нужны платные резидентные IP-адреса или геомаршрутизация для каждого навыка (например, привязать веб-сканер к JP, добавить учетную запись IPRoyal, направить эту очистку через DE).
