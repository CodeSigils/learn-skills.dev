Le portail de qualité UI/UX et le guide de création pour chaque sortie visuelle : pages de destination, tableaux de bord,
applications Web, portefeuilles, outils, tout code HTML que l'utilisateur verra. Fusionne la méthodologie de conception visuelle
(palette, typographie, mise en page, anti-AI-slop) avec des conseils de construction concrets, y compris quand et
comment utiliser les bibliothèques de composants open source (shadcn/ui, HeroUI, coss ui) pour réduire le travail et
augmenter la qualité.

DOIT UTILISER avec le constructeur de projet chaque fois qu'un projet produit du HTML/CSS/JS visuel.
le constructeur de projet est propriétaire du flux de travail d'ingénierie ; cette compétence possède l'apparence et la sensation du résultat.
