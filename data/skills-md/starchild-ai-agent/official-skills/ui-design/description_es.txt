La puerta de calidad UI/UX y la guía de compilación para cada resultado visual: páginas de destino, paneles,
aplicaciones web, portafolios, herramientas, cualquier HTML que el usuario vea. Fusiona metodología de diseño visual
(paleta, tipografía, diseño, anti-AI-slop) con orientación de construcción concreta, que incluye cuándo y
cómo utilizar bibliotecas de componentes de código abierto (shadcn/ui, HeroUI, coss ui) para reducir el trabajo y
elevar la calidad.
