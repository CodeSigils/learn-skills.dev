منع بقايا أسلوب “此地无银三百两式”: إكمال العناصر دون صدى البدائل المرفوضة الخاصة بالجلسة فقط في الملصقات أو البيانات الوصفية أو الالتزامات أو طلبات السحب أو عمليات التسليم. يُستخدم بعد التصحيحات أو الاقتراحات المرفوضة. لا يُستعمل للحذف العادي أو الإلغاء أو النقل أو الاستثناءات المطلوبة مادياً للسلامة أو الدقة أو التوافق أو التدقيق أو الاقتباس أو المقارنة المطلوبة.
