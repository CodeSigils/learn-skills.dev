Используйте, когда пользователь хочет выполнить итерацию самой системы оценки вирусных статей, откалибровать или улучшить подсказку для оценки по маркированным образцам или запустить пакетные эксперименты по оценке на фиксированном наборе статей. Лучше всего подходит для исследований с оценкой только подсказок, где сценарии оценщика остаются фиксированными, а меняться должна только рубрика/подсказка для оценки.
