Master.skill — En entrant dans « le secteur de niche dans lequel je travaille », il effectue automatiquement une recherche approfondie en six volets couvrant l'analyse des leaders du secteur, la carte des outils, le flux de travail, le canon de connaissances, les sources d'informations et les normes terminologiques, et la distille dans une compétence exécutable « Industry Master OS ».  
La compétence {industry}.master générée est un répertoire autonome qui peut être installé sur n'importe quel agent ermite, agent Claude Code, OpenClaw ou Codex, mettant instantanément l'IA en mode « professionnel senior dans ce domaine ».  
Phrases de déclenchement : « créer un maître », « créer une compétence de maître pour X », « Je suis dans l'industrie X », « transformer l'agent en maître X », « mettre à jour le maître X », « maîtriser X », « Je travaille dans X, aidez-moi à en préparer un ».
