Master.skill — 「私が働いているニッチ業界」を入力すると、業界リーダーの分析、ツールマップ、ワークフロー、ナレッジカノン、情報源、用語標準をカバーする 6 トラックの詳細な調査が自動的に完了し、実行可能な「業界マスター OS」スキルに洗練されます。  
生成された {industry}.master スキルは、任意の Hermit Agent、Claude Code Agent、OpenClaw、または Codex にインストールできる自己完結型のディレクトリであり、AI を即座に「この分野の上級プロフェッショナル」モードにします。  
トリガーフレーズ: 「マスターを作成する」、「X マスタースキルを作成する」、「私は X 業界にいます」、「エージェントを X マスターに変える」、「マスター X を更新する」、「X をマスターする」、「私は X を実行します。スキルの生成を手伝ってください。」
