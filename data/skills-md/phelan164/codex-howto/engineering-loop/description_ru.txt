Внесите авторизованное изменение в репозиторий через проверенный локальный цикл: базовое состояние, воспроизведение, внедрение, тестирование, проверка и отчет о доказательствах. Используйте для сквозных функций или исправлений, которые должны действовать автономно до тех пор, пока не будут пройдены наблюдаемые критерии приемки; не используйте только для пояснений, только для просмотра или для производственных операций.
