Технический временной анализ волн Эллиотта для отдельных акций. Определяет положение текущего волнового цикла (5-волновой импульс / коррекция ABC), проверяет с помощью коэффициентов Фибоначчи, подтверждает с помощью индикаторов импульса (MACD, RSI, дивергенция объема) и оценивает рыночную среду для каждого рынка (HK / US / A-share / SGX). Выводит структурированный отчет на естественном языке с ценовыми зонами Фибоначчи и полезными справками.
