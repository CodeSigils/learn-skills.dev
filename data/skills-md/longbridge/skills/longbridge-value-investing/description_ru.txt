Анализ стоимостного инвестирования с использованием методологий Грэма (NCAV/net-net/защитный инвестор) и Баффета (экономический ров/ROE/FCF). Охватывает диагностику отдельных запасов и проверку партий как по критериям качества сигарного окурка Грэма, так и по критериям качества Баффета. Выполняет сверку перекрестных операторов перед оценкой. Сначала данные из Longbridge CLI, резерв MCP, веб-поиск только для выявления реальных пробелов.
