Операции по изменению ценовых оповещений пользователя в Лонгбридже — список (только для чтения), добавление нового ценового оповещения, включение/отключение оповещения, удаление оповещения. Требуется вход в систему Longbridge. Каждая мутация (добавление/удаление/включение/отключение) требует двухэтапного протокола предварительного просмотра и подтверждения. Используйте только тогда, когда пользователь дает четкое указание («установить ценовое оповещение на уровне 200 для NVDA», «удалить оповещение 486469», «提醒我 NVDA 涨到 200»); двусмысленные запросы («整理我的提醒») должны отклоняться с ответом «пожалуйста, будьте более конкретным», а не запускаться. Триггеры: «设置股价提醒», «添加股价提醒», «提醒我 X 涨到 Y», «提醒我 X 跌破 Y», «删除股价提醒», "关掉提醒", "暫停提醒", "設置股價提醒", "添加股價提醒", "提醒我 X 漲到 Y", "提醒我 X 跌破 Y", «刪除股價提醒», «關掉提醒», «установить оповещение о цене», «добавить оповещение о цене», «оповестить меня, когда X достигнет Y», «удалить оповещение о цене», «включить оповещение», «отключить оповещение», «оповещение о цене».
