Opérations de mutation sur les alertes de prix Longbridge de l'utilisateur — liste (lecture seule), ajouter une nouvelle alerte de prix, activer/désactiver une alerte, supprimer une alerte. Nécessite une connexion Longbridge. Chaque mutation (ajouter/supprimer/activer/désactiver) nécessite un protocole de prévisualisation + confirmation en deux étapes. À utiliser uniquement lorsque l'utilisateur donne un impératif clair ("définir une alerte de prix à 200 pour NVDA", "supprimer l'alerte 486469", "提醒我 NVDA 涨到 200"); les invites ambiguës (« 整理我的提醒 ») doivent être rejetées avec une réponse « veuillez être plus précis » plutôt que déclenchées. Déclencheurs : "设置股价提醒", "添加股价提醒", "提醒我 X 涨到 Y", "提醒我 X 跌破 Y", "删除股价提醒", "关掉提醒", « » « 關掉提醒 », « définir une alerte de prix », « ajouter une alerte de prix », « m'alerter lorsque X atteint Y », « supprimer l'alerte de prix », « activer l'alerte », « désactiver l'alerte », « alerte de prix ».
