Операции по изменению списка наблюдения Longbridge пользователя — создание группы, переименование группы, добавление/удаление символов, удаление группы (возможно удаление участников). Требуется вход в систему Longbridge. Каждая мутация требует двухэтапного протокола предварительного просмотра и подтверждения. Используйте только тогда, когда пользователь дает четкий императив («добавить X в избранное», «удалить группу Tech»); двусмысленные подсказки («организуйте мой список наблюдения»), придется переспрашивать. Триггеры: «把 X 加到自选», «添加到自选», «创建自选分组», «删除自选», «删除分组», «改名分组», «把 X加到自選", "新增至自選", "建立自選分組", "刪除自選", "刪除分組", "重新命名", "добавить в список наблюдения", "создать группу списка наблюдения", "удалить из списка наблюдения", "удалить" группа», «переименовать группу», «редактировать список наблюдения».
