Operaciones de mutación en la lista de vigilancia de Longbridge del usuario: crear grupo, cambiar el nombre del grupo, agregar/eliminar símbolos, eliminar grupo (opcionalmente, purgar miembros). Requiere inicio de sesión de Longbridge. Cada mutación requiere un protocolo de vista previa + confirmación de dos pasos. Úselo solo cuando el usuario dé un imperativo claro ("agregar X a favoritos", "eliminar el grupo Técnico"); Las indicaciones ambiguas ("organizar mi lista de vigilancia") deben volver a preguntar.
