Полные финансовые отчеты из трех отчетов (IS / BS / CF) для компаний, котирующихся на бирже через Longbridge — отчет о прибылях и убытках, балансовый отчет, отчет о движении денежных средств; годовые/полугодовые/квартальные периоды. Используйте этот навык для получения необработанных финансовых данных. Для глубокого анализа (DuPont, начисления, флаги мошенничества) используйте longbridge-financial-analysis; для оценки состояния здоровья используйте Longbridge-financial-checkup.
