Ichimoku Cloud (一目均衡表) пятистрочный системный сигнальный механизм для акций, котирующихся в Гонконге / США / A-share / Сингапуре через Longbridge Securities. Вычисляет Тенкан-сен, Киджун-сен, Сенкоу Спан A/B и Чикоу Спан на основе данных OHLCV; генерирует позицию цены по сравнению с облаком, сигналы пересечения линий и полные оценки подтверждения тренда.
