Операции по изменению планов регулярных инвестиций (DCA) Longbridge пользователя — список (только для чтения), создание плана, обновление/приостановка/возобновление/остановка плана, просмотр истории сделок, проверка права на участие. Требуется вход в систему Longbridge С ТОРГОВОЙ ОБЛАСТЬЮ, поскольку каждый план автоматически вносит реальные деньги по графику. Для каждой мутации требуется двухэтапный протокол предварительного просмотра + подтверждения, а «создать» требует, чтобы пользователь прочитал количество/частоту/символ/дату начала/окончания перед подтверждением. Используйте только тогда, когда пользователь дает четкий императив («создать ежемесячный DCA на AAPL за 500 долларов США», «停止定投 700.HK»); двусмысленные запросы («帮我看看定投») должны отклоняться с ответом «пожалуйста, укажите конкретно», а не запускаться.
