HK-IPO-Analyse für neue Aktienzeichnungen – eine „vierdimensionale Bewertung“, die diagnostiziert, ob eine neue Aktie aus Hongkong eine Zeichnung wert ist (Preisrationalität/Emissionsqualität/Markttiming/fundamentaler Ausblick). Ausgabeempfehlung / Neutral / Dreistufiges Rating vermeiden + Prospekt-Highlights + Risikowarnungen + Zeichnungsreferenz, Kleinanlegerfreundlich, Schlussfolgerungen im Vorfeld. Deckt drei Szenarien ab: eingehende Bewertung einer einzelnen neuen Aktie, Durchsuchen des aktuellen Abonnementkalenders und Verfolgung einer beliebten Nachfolgeaktie nach der Zuteilung. Datenpriorität ist Longbridge CLI (IPO-Detail/IPO-Abonnements/IPO-Warteliste/IPO-Liste/Peer-Vergleich/Nachrichten/Zitat/Kline/Index-Zitat usw.); fehlende Elemente fallen an MCP zurück; Noch nicht verfügbare Artikel (Prospekt TAM, ursprüngliche Eckpfeiler-Ankündigung, Claw-Back-Multiplikator, Graumarktpreis, Underwriter-Branchenranking) werden von WebSearch abgedeckt. **Der Bericht muss immer mit einem Anhang mit dem Titel „Details zur Datenquelle“ enden, wobei jede Zahl auf Zeilennummer + Abrufzeit + Zeitraum rückverfolgbar ist. ** Gilt nur für das Main Board und GEM in Hongkong, nicht für Börsengänge in den USA oder A-Aktien; Wenn es sich um eine Margin-Finanzierung (杠杆打新) handelt, muss proaktiv eine Warnung vor dem Leverage-Risiko ausgesprochen werden.
