HK-IPO-Neuemissionsanalyse – eine „vierdimensionale Bewertung“-Diagnose darüber, ob es sich lohnt, sich für eine neue Aktie aus Hongkong zu bewerben (Preisgestaltung / Emissionsqualität / Markt-Timing / fundamentale Aussichten). Geben Sie eine dreistufige Bewertung aus Empfehlung/Neutral/Vermeiden sowie Prospekthervorhebungen, Risikowarnungen und Zeichnungsreferenzen aus. Einzelhandelsfreundlich mit der Schlussfolgerung im Vordergrund. Deckt drei Szenarien ab: eingehende Bewertung einer einzelnen neuen Aktie, Durchsuchen des aktuellen IPO-Kalenders und Beurteilung von Folgekäufen einer neu notierten Aktie nach fehlender Zuteilung. Die Daten werden von der Longbridge-CLI priorisiert (IPO-Detail/IPO-Abonnements/IPO-Warteliste/IPO-Liste/Peer-Vergleich/Nachrichten/Zitat/Kline/Index-Zitat usw.), wobei fehlende Elemente an MCP zurückfallen; Alle noch nicht erhältlichen Daten (Prospekt-TAM, ursprüngliche Eckpfeiler-Ankündigung, Claw-Back-Multiplikator, Graumarktpreis, Underwriter-Branchenranking) werden über WebSearch abgedeckt. **Der Bericht endet immer mit einem festen Anhang „Datenquellendetails“**, in dem jede Zahl auf Zeilennummer+Abrufzeit+Zeitraum zurückgeführt werden kann. Nur Hong Kong Main Board und GEM sind abgedeckt; Börsengänge von US-/A-Aktien sind ausgeschlossen. Bei einer Margin-Finanzierung (Margin-Trade-IPO) muss eine aktive Leverage-Risikowarnung erfolgen.
