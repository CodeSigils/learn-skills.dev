Оптимизация риска и доходности для инвестиционных портфелей через Longbridge — создает портфели с оптимальной доходностью с поправкой на риск на основе размера фонда, предпочтения риска (консервативный / сбалансированный / агрессивный) и инвестиционного горизонта. Распределение активов по акциям/облигациям/денежным средствам/сырьям/альтернативам. Оценивает текущую эффективность портфеля по сравнению с границей эффективности.
