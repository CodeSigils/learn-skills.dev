Die normativen Designhandbücher für GPUI Kit-Desktopanwendungen. Lesen Sie es vollständig durch, bevor Sie einen Bildschirm, ein Layout, einen Abstand, eine visuelle Hierarchie, eine Farbe, eine Dichte, eine Komponentenauswahl, einen Interaktionsstatus, eine Überlagerung, eine Bewegung, eine datenintensive Ansicht oder eine Schnittstellenkopie in einer GPUI-Kit-Anwendung (gpui-kit / gpui-component) entwerfen oder ändern und bevor Sie die UI-Arbeit auf Designqualität prüfen. Verwenden Sie es auch, wenn Sie nach den Designregeln gefragt werden oder ob eine UI-Entscheidung ihnen folgt.
