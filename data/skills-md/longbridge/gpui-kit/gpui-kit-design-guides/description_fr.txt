Les guides de conception normatifs pour les applications de bureau GPUI Kit. Lisez l'intégralité avant de concevoir ou de modifier un écran, une disposition, un espacement, une hiérarchie visuelle, une couleur, une densité, un choix de composant, un état d'interaction, une superposition, un mouvement, une vue contenant beaucoup de données ou une copie d'interface dans une application GPUI Kit (gpui-kit / gpui-component), et avant d'examiner le travail de l'interface utilisateur pour la qualité de conception. À utiliser également lorsqu'on lui demande quelles sont les règles de conception ou si une décision d'interface utilisateur les suit.
