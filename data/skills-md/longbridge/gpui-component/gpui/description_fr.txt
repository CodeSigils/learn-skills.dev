Connaissance du framework GPUI couvrant les actions/combinaisons de touches, les tâches asynchrones/en arrière-plan, la gestion du contexte (App/Window/Context<T>/AsyncApp), les éléments personnalisés (trait d'élément de bas niveau), la gestion de l'état des entités, le système d'événements, la gestion du focus, l'état global, la mise en page/le style (flexbox/de type CSS) et les tests. À utiliser lorsque vous travaillez avec n'importe quel concept de framework GPUI, créez des applications GPUI ou avez besoin de conseils sur les API et les modèles spécifiques au GPUI.
