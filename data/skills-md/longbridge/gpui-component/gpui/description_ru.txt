Знания платформы GPUI, охватывающие действия/привязки клавиш, асинхронные/фоновые задачи, управление контекстом (App/Window/Context<T>/AsyncApp), пользовательские элементы (характеристика элемента низкого уровня), управление состоянием объекта, систему событий, обработку фокуса, глобальное состояние, макет/стиль (флексбокс/CSS-подобный) и тестирование. Используйте при работе с любой концепцией инфраструктуры GPUI, создании приложений GPUI или необходимости получения рекомендаций по API и шаблонам, специфичным для GPUI.
