Cómo utilizar la biblioteca de interfaz de usuario del componente gpui en aplicaciones GPUI. Úselo al crear interfaces de usuario con componentes de componentes gpui (botón, entrada, selección, cuadro de diálogo, pestañas, barra lateral, lista, tabla, etc.), configurar la biblioteca, manejar el estado de los componentes, crear temas o encontrar el componente adecuado para una necesidad de interfaz de usuario determinada.
