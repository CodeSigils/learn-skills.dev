خبير منصة Longbridge للمطورين. يُستخدم عندما: (1) الاستعلام عن بيانات السوق أو تنفيذ الصفقات عبر CLI (أمر "longbridge")، (2) كتابة برامج Python/Rust باستخدام "longbridge" SDK، (3) تكوين خادم Longbridge MCP لأدوات الذكاء الاصطناعي (Cursor، Claude Code، ChatGPT)، (4) دمج مستندات Longbridge في أنظمة LLM/RAG عبر llms.txt أو Markdown API. يغطي جميع الأسواق: هونج كونج والولايات المتحدة والصين (SH/SZ) وسنغافورة والعملات المشفرة. يتم تشغيلها عند استيراد "longbridge"، أو رموز الأسهم (TSLA.US، 700.HK)، أو إعداد مفتاح API، أو وضع الطلب، أو اشتراكات WebSocket، أو أي سؤال يتعلق بقدرة نظام Longbridge الأساسي.
