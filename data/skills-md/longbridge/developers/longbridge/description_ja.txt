Longbridge Developers プラットフォームの専門家。次の場合に使用します: (1) CLI (「longbridge」コマンド) を介して市場データをクエリまたは取引を実行する、(2) 「longbridge」 SDK を使用して Python/Rust プログラムを作成する、(3) AI ツール (カーソル、クロード コード、ChatGPT) 用に Longbridge MCP サーバーを構成する、(4) llms.txt または Markdown API を介して Longbridge ドキュメントを LLM/RAG システムに統合する。すべての市場をカバーします: 香港、米国、CN (SH/SZ)、シンガポール、仮想通貨。 「longbridge」インポート、銘柄記号 (TSLA.US、700.HK)、API キー設定、注文、WebSocket サブスクリプション、または Longbridge プラットフォーム機能に関する質問でトリガーされます。
