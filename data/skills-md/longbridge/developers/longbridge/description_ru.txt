Эксперт по платформе Longbridge Developers. Используйте при: (1) запросе рыночных данных или совершении сделок через CLI (команда «longbridge»), (2) написании программ Python/Rust с использованием SDK «longbridge», (3) настройке сервера Longbridge MCP для инструментов искусственного интеллекта (Cursor, Claude Code, ChatGPT), (4) интеграции документов Longbridge в системы LLM/RAG через llms.txt или Markdown API. Охватывает все рынки: HK, США, CN (SH/SZ), SG, Crypto. Запускается при импорте «longbridge», биржевых символах (TSLA.US, 700.HK), настройке ключа API, размещении заказа, подписке на WebSocket или любом вопросе о возможностях платформы Longbridge.
