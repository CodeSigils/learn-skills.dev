Genera il testo richiesto dall'utente in un file temporaneo e copialo negli appunti di sistema. Da utilizzare quando l'utente chiede di abbozzare, scrivere o generare testo e desidera copiare/incollare rapidamente. Per impostazione predefinita è un file temporaneo Markdown (`.md`) a meno che l'utente non richieda esplicitamente un altro formato.
