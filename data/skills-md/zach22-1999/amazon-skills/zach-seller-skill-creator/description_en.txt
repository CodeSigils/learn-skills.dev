Skill creator dedicated to Amazon sellers (Chinese). Used when a user wants to turn an Amazon operation / self‑media / daily workflow into a reusable skill. Trigger scenarios include but are not limited to: the user says “I want to make a skill,” “turn this process into a skill,” “help me write an automation,” “optimize my existing skill,” “automate this workflow.” Even if the user does not use the word “skill,” as long as they describe a repetitive task for “doing this every time in the future,” it should be triggered. The core differentiation of this skill: it forces the user to answer six business questions (business goal / past approach / specific steps / methodology / invocation method / expected output) before entering the creation process, preventing the production of empty skills. Create new skills, improve existing skills, run evals and benchmarks — tailored for Amazon sellers with a Chinese‑first workflow.
