Skill-Ersteller für Amazon-Verkäufer (Chinesisch). Wird verwendet, wenn ein Benutzer einen Amazon-Vorgang/Self-Media/täglichen Arbeitsablauf in einen wiederverwendbaren Skill umwandeln möchte. Zu den Auslöseszenarien gehören unter anderem: Der Benutzer sagt: „Ich möchte einen Skill erstellen“, „diesen Prozess in einen Skill umwandeln“, „Hilf mir, eine Automatisierung zu schreiben“, „meinen vorhandenen Skill optimieren“, „diesen Workflow automatisieren“. Auch wenn der Benutzer das Wort „Fähigkeit“ nicht verwendet, sollte diese ausgelöst werden, solange er eine sich wiederholende Aufgabe beschreibt, bei der er „dies in Zukunft jedes Mal tun muss“. Der Kernunterschied dieser Fertigkeit besteht darin, dass der Benutzer sechs Geschäftsfragen (Geschäftsziel / früherer Ansatz / spezifische Schritte / Methodik / Aufrufmethode / erwartete Ausgabe) beantworten muss, bevor er in den Erstellungsprozess eintritt, wodurch die Produktion leerer Fertigkeiten verhindert wird. Schaffen Sie neue Fähigkeiten, verbessern Sie bestehende Fähigkeiten, führen Sie Evaluierungen und Benchmarks durch – maßgeschneidert für Amazon-Verkäufer mit einem chinesisch-orientierten Workflow.
