Создатель навыков, посвященный продавцам Amazon (китайский). Используется, когда пользователь хочет превратить работу Amazon/самомедиа/ежедневный рабочий процесс в навык многократного использования. Триггерные сценарии включают, помимо прочего: пользователь говорит: «Я хочу создать навык», «превратить этот процесс в навык», «помогите мне написать автоматизацию», «оптимизировать существующий навык», «автоматизировать этот рабочий процесс». Даже если пользователь не использует слово «навык», но описывает повторяющуюся задачу «делать это каждый раз в будущем», она должна быть активирована. Основное отличие этого навыка: он заставляет пользователя ответить на шесть бизнес-вопросов (бизнес-цель/прошлый подход/конкретные шаги/методология/метод вызова/ожидаемый результат) перед тем, как приступить к процессу создания, предотвращая создание пустых навыков. Создавайте новые навыки, улучшайте существующие навыки, проводите оценки и тесты — специально для продавцов Amazon с рабочим процессом, ориентированным на китайский язык.
