Создатель навыков для конкретных продавцов Amazon (китайский). Используется, когда пользователь хочет превратить операцию Amazon, самостоятельную медиа-деятельность или ежедневный рабочий процесс в навык многократного использования. Триггерные сценарии включают, помимо прочего: пользователь говорит: «Я хочу создать навык», «превратить этот процесс в навык», «помогите мне написать автоматизацию», «оптимизировать существующий навык», «автоматизировать этот рабочий процесс». Даже если пользователь не использует слово «навык», пока он описывает повторяемую задачу, которую следует выполнять каждый раз одинаково, она должна быть запущена. Основное отличие этого навыка: он заставляет пользователя ответить на шесть бизнес-вопросов (бизнес-цель, прошлый подход, конкретные шаги, методология, метод вызова, ожидаемый результат) перед тем, как приступить к процессу создания, предотвращая создание пустых навыков. Создавайте новые навыки, улучшайте существующие навыки, проводите оценки и тесты — специально для продавцов Amazon с рабочим процессом, ориентированным на китайский язык.
