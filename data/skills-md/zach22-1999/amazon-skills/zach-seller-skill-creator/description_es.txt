Creador de skills dedicado a vendedores de Amazon (chino). Se utiliza cuando un usuario desea convertir una operación de Amazon, medios propios o flujo de trabajo diario en una habilidad reutilizable. Los escenarios desencadenantes incluyen, entre otros: el usuario dice "Quiero crear una habilidad", "convertir este proceso en una habilidad", "ayúdame a escribir una automatización", "optimizar mi habilidad existente", "automatizar este flujo de trabajo". Incluso si el usuario no utiliza la palabra "habilidad", siempre que describa una tarea repetitiva para "hacer esto cada vez en el futuro", debería activarse. La diferenciación central de esta habilidad: obliga al usuario a responder seis preguntas comerciales (objetivo comercial / enfoque anterior / pasos específicos / metodología / método de invocación / resultado esperado) antes de ingresar al proceso de creación, evitando la producción de habilidades vacías. Cree nuevas habilidades, mejore las existentes, ejecute evaluaciones y puntos de referencia, todo ello diseñado para vendedores de Amazon con un flujo de trabajo centrado en los chinos.
