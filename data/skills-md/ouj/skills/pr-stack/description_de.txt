Verwalten Sie gestapelte Pull-Anfragen über Plain Git und GitHub CLI. Verwenden Sie diese Option, wenn der Benutzer einen Stapel abhängiger Zweige und PRs erstellen, prüfen, neu stapeln, verschieben, neu ausrichten, übermitteln oder synchronisieren möchte, während er übergeordnete Zweige explizit verfolgt, jeden GitHub-PR basierend auf seinem aufgezeichneten übergeordneten Zweig beibehält und unsichere Umschreibungen des Verlaufs vermeidet.
