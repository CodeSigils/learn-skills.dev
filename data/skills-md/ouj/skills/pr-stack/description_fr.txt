Gérez les demandes d'extraction empilées au-dessus de Git simple et de GitHub CLI. À utiliser lorsque l'utilisateur souhaite créer, inspecter, réempiler, déplacer, recibler, soumettre ou synchroniser une pile de branches et de PR dépendantes tout en suivant explicitement les branches parentes, en conservant chaque PR GitHub en fonction de sa branche parent enregistrée et en évitant les réécritures d'historique dangereuses.
