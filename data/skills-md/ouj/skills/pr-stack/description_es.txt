Administre solicitudes de extracción apiladas sobre git simple y GitHub CLI. Úselo cuando el usuario desee crear, inspeccionar, reapilar, mover, reorientar, enviar o sincronizar una pila de ramas dependientes y PR mientras realiza un seguimiento explícito de las ramas principales, manteniendo cada PR de GitHub en función de su rama principal registrada y evitando reescrituras inseguras del historial.
