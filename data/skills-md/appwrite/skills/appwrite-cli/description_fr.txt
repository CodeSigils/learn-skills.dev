Compétence CLI Appwrite. À utiliser lors de la gestion de projets Appwrite à partir de la ligne de commande. Couvre l'installation, la connexion, l'initialisation du projet, la configuration de projets multi-fichiers, le déploiement de fonctions/sites/tables/buckets/équipes/webhooks/sujets, les requêtes de liste basées sur des indicateurs, le mode CI/CD non interactif et la génération de SDK de type sécurisé.
