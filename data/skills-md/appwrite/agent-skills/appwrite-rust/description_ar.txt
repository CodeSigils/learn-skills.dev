قم بكتابة مهارة Rust SDK. يُستخدم عند إنشاء تطبيقات Rust من جانب الخادم باستخدام Appwrite. يغطي إعداد العميل غير المتزامن مع مفاتيح API، وإدارة المستخدم، وقاعدة بيانات TablesDB/عمليات الجدول/الصف، وتخزين الملفات، وتنفيذ الوظائف، والأذونات، والاستعلامات، ومعالجة الأخطاء. يستخدم حزمة `appwrite` وCrates.io وTokio.
