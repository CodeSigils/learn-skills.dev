Навыки написания приложений для Rust SDK. Используйте при создании серверных приложений Rust с помощью Appwrite. Охватывает настройку асинхронного клиента с ключами API, управление пользователями, операции с базой данных/таблицами/строками TablesDB, хранилище файлов, выполнение функций, разрешения, запросы и обработку ошибок. Использует пакет crates.io `appwrite` и Tokio.
