Habilidad Appwrite Rust SDK. Úselo al crear aplicaciones Rust del lado del servidor con Appwrite. Cubre la configuración del cliente asíncrono con claves API, administración de usuarios, operaciones de base de datos/tabla/fila de TablesDB, almacenamiento de archivos, ejecuciones de funciones, permisos, consultas y manejo de errores. Utiliza el paquete crates.io `appwrite` y Tokio.
