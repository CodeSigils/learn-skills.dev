Abilità Appwrite Rust SDK. Da utilizzare durante la creazione di applicazioni Rust lato server con Appwrite. Copre la configurazione del client asincrono con chiavi API, gestione degli utenti, operazioni su database/tabelle/righe di TablesDB, archiviazione di file, esecuzioni di funzioni, autorizzazioni, query e gestione degli errori. Utilizza il pacchetto `appwrite` di crates.io e Tokio.
