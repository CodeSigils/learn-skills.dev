Erzwingen Sie von Appwrite selbst gehostete Release-Bereitschaftsprüfungen. Verwenden Sie diese Option, wenn Sie eine selbstgehostete RC- oder endgültige Version validieren, neue Docker Compose-Installationstests ausführen, realistische e2e-Workflows testen, die Basislinie der vorherigen stabilen Version ermitteln, Seed-Daten von der vorherigen selbstgehosteten Version aktualisieren, Migrationen, Kompatibilitätsfilter, Versionsmetadaten und Installationsprogrammverhalten überprüfen oder entscheiden, ob eine selbstgehostete Version sicher veröffentlicht werden kann.
