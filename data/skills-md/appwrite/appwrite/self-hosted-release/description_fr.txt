Appliquez les contrôles de préparation aux versions auto-hébergés d’Appwrite. À utiliser pour valider une version RC ou finale auto-hébergée, exécuter de nouveaux tests d'installation Docker Compose, tester des flux de travail e2e réalistes, découvrir la référence de la version stable précédente, mettre à niveau les données prédéfinies de la version auto-hébergée précédente, vérifier les migrations, les filtres de compatibilité, les métadonnées de la version, le comportement de l'installateur ou décider si une version auto-hébergée peut être publiée en toute sécurité.
