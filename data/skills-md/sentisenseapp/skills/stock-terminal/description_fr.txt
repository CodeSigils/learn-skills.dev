Terminal de stock pour les agents IA. Transforme le chat en un terminal financier futuriste : des commandes tapées comme "ouvrir NVDA", "écran smart-money", "daily brief" ou des questions naturelles comme "qu'est-ce qui est chaud aujourd'hui ?" renvoie des rapports synthétisés composites sur les prix, le sentiment, les transactions d'initiés, les divulgations du Congrès, les flux institutionnels, les notes des analystes, les informations sur l'IA et les actualités intégrées. Utilisation pour le terminal boursier, le terminal financier pour l'IA, l'information quotidienne sur le marché, l'ouverture d'un téléscripteur, l'analyse des actions par argent intelligent, ce qui est chaud aujourd'hui, la recherche boursière à une seule commande. Lecture seule. Pas de trading, pas d'achats, pas d'opérations d'écriture, pas d'accès au portefeuille.
