米国株式市場の市場ヒートマップを、エージェントがインラインで表示するか、ファイルとして渡すことができる 1 つの自己完結型インタラクティブ HTML ページとして表示します。インデックス内の各銘柄がツリーマップ タイルとして描画され、時価総額ごとにサイズが設定され、GICS セクターごとにグループ化され、今日の動きによって色付けされます。クリックすると、センチメント、センチセンス スコア、言及ボリュームまたはオプションの関心ごとにボード全体の色が変更され、さらにセクター マーケット ムード、ティッカー検索、セクター ズーム、および各タイル上のホバー カードが表示されます。どの層でもレンダリングごとに 1 つの API 呼び出し。エージェントは読み取り専用 API キーを使用してフェッチし、ボードをベイクインするため、ページはキーを持たず、独自のネットワーク呼び出しも行わず、HTML を描画するあらゆる場所をレンダリングします。市場ヒートマップ、セクター ヒートマップ、今日の株式市場ヒートマップ、今日何が動いているか、どのセクターが注目されているか、セクター別の市場ムード、セクター パフォーマンス マップ、センチメント別のヒートマップ、オプション活動別のヒートマップ、ナスダック 100 ヒートマップに使用します。読み取り専用。取引、購入、書き込み操作、ウォレットへのアクセスはありません。
