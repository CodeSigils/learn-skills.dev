現在のリポジトリ上で人間と AI に合わせた実装の仕様として、リーンスペック スタイルの GitHub 課題を作成します。 「仕様を作成する」、「仕様の問題を書く」、「この機能の仕様を指定する」、「これを仕様する」、または実装前に仕様が必要な作業を計画する場合に使用します。リーンスペック SDD 手法に従います。つまり、小規模に焦点を当てた仕様 (<2000 トークン)、実装よりも意図、コンテキスト エコノミーです。 「概要」、「設計」、「計画」、「テスト」、「調整」、および「メモ」セクションを含む GitHub の問題を作成します。リポジトリ固有の領域分類、姉妹スキル名、カスタム本文セクション (例: プロバイダーの影響 / スキーマの影響 / リーチ)、および追加の原則は、コンシューマー リポジトリの CLAUDE.md とその `*-dev-process` / `*-pre-push` / `*-pr-lifecycle` の姉妹スキルによってオーバーレイされます。リポジトリが明確でない場合は、最初にこれらを読んでください。
