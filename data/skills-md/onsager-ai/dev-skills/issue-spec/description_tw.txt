創建精益規範風格的 GitHub 問題，作為目前儲存庫上人類與人工智慧一致實施的規範。當被要求「創建規範」、「編寫規範問題」、「規範此功能」、「規範此」或在實施之前規劃需要規範的工作時使用。遵循精實規範 SDD 方法論 — 小型集中規範（<2000 個代幣）、實施意圖、情境經濟。建立包含概述、設計、計劃、測試、對齊和註釋部分的 GitHub 問題。特定於儲存庫的區域分類、姊妹技能名稱、自訂正文部分（例如提供者影響/架構影響/範圍）以及其他原則由消費者存儲庫的 CLAUDE.md 及其“*-dev-process”/“*-pre-push”/“*-pr-lifecycle”姊妹技能覆蓋 - 當存儲庫不明顯時，請先閱讀這些內容。
