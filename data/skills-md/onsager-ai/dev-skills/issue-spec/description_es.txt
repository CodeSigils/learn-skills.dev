Cree problemas de GitHub con un estilo de especificaciones ajustadas como especificaciones para una implementación alineada con la IA humana en el repositorio actual. Úselo cuando se le solicite "crear una especificación", "escribir un problema de especificación", "especificar esta característica", "especificar esto" o cuando planifique un trabajo que necesite una especificación antes de la implementación. Sigue la metodología SDD de especificaciones ajustadas: especificaciones pequeñas y enfocadas (<2000 tokens), intención sobre la implementación, economía contextual. Crea problemas de GitHub con las secciones Descripción general, Diseño, Plan, Prueba, Alineación y Notas. La taxonomía del área específica del repositorio, los nombres de las habilidades hermanas, las secciones del cuerpo personalizadas (por ejemplo, Impacto del proveedor/Impacto del esquema/Alcance) y principios adicionales están superpuestos por el repositorio CLAUDE.md del consumidor y sus habilidades hermanas `*-dev-process`/`*-pre-push`/`*-pr-lifecycle`; léalas primero cuando el repositorio no sea obvio.
