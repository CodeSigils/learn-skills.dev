قم بإنشاء مشكلات GitHub ذات المواصفات البسيطة كمواصفات للتنفيذ المتوافق مع الذكاء الاصطناعي البشري في الريبو الحالي. يُستخدم عندما يُطلب منك "إنشاء مواصفات"، أو "كتابة مشكلة خاصة بالمواصفات"، أو "مواصفات هذه الميزة"، أو "مواصفات هذه"، أو عند التخطيط للعمل الذي يحتاج إلى مواصفات قبل التنفيذ. يتبع منهجية SDD ذات المواصفات الهزيلة - المواصفات الصغيرة المركزة (<2000 رمز مميز)، والنية على التنفيذ، والاقتصاد في السياق. ينشئ مشكلات GitHub مع أقسام النظرة العامة والتصميم والخطة والاختبار والمحاذاة والملاحظات. يتم تضمين تصنيف منطقة الريبو الخاصة، وأسماء المهارات الشقيقة، وأقسام الجسم المخصصة (مثل تأثير الموفر / تأثير المخطط / الوصول)، والمبادئ الإضافية بواسطة CLAUDE.md الخاص بمستودعات المستهلك ومهاراتها الشقيقة `*-dev-process` / `*-pre-push` / `*-pr-lifecycle` - اقرأ تلك المهارات أولاً عندما لا يكون الريبو واضحًا.
