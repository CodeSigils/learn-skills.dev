Запускайте несколько сеансов агента по кодированию ИИ параллельно, используя рабочие деревья git — каждый агент изолирован в своем собственном рабочем дереве и работает в отдельной ветке. Используйте этот навык всякий раз, когда пользователь хочет: запускать два или более агентов ИИ одновременно для проверки различных функций или ошибок, настраивать изолированные рабочие области агентов в одном репозитории, отправлять параллельные ветки на GitHub и открывать/обновлять PR, координировать работу одновременных сеансов агентов или очищать после слияния. Запускается по: «параллельные агенты», «несколько сеансов агентов», «рабочее дерево git», «параллельный запуск агентов», «работа над двумя вещами одновременно», «изолированное рабочее пространство агента», «развертывание другого агента» или любой запрос, включающий одновременные потоки разработки с помощью ИИ.
