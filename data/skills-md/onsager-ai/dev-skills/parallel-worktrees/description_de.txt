Führen Sie mithilfe von Git-Arbeitsbäumen mehrere AI-Coding-Agent-Sitzungen parallel aus – jeder Agent ist in seinem eigenen Arbeitsbaum isoliert und arbeitet in einem separaten Zweig. Verwenden Sie diese Fähigkeit, wann immer der Benutzer Folgendes möchte: zwei oder mehr KI-Agenten gleichzeitig für unterschiedliche Funktionen oder Fehler ausführen, isolierte Agentenarbeitsbereiche im selben Repo einrichten, parallele Zweige an GitHub übertragen und PRs öffnen/aktualisieren, zwischen gleichzeitigen Agentensitzungen koordinieren oder nach dem Zusammenführen aufräumen. Auslöser bei: „parallele Agenten“, „mehrere Agentensitzungen“, „Git Worktree“, „Agenten parallel ausführen“, „an zwei Dingen gleichzeitig arbeiten“, „isolierter Agentenarbeitsbereich“, „einen anderen Agenten starten“ oder jede Anfrage, die gleichzeitige KI-unterstützte Entwicklungsströme beinhaltet.
