قم بتشغيل جلسات وكيل ترميز الذكاء الاصطناعي المتعددة بالتوازي باستخدام أشجار عمل git - كل وكيل معزول في شجرة العمل الخاصة به، ويعمل على فرع منفصل. استخدم هذه المهارة عندما يريد المستخدم: تشغيل اثنين أو أكثر من وكلاء الذكاء الاصطناعي في وقت واحد على ميزات أو أخطاء مختلفة، أو إعداد مساحات عمل الوكيل المعزولة في نفس الريبو، أو دفع الفروع المتوازية إلى GitHub وفتح/تحديث العلاقات العامة، أو التنسيق بين جلسات الوكيل المتزامنة، أو التنظيف بعد الدمج. يتم تشغيلها على: "الوكلاء المتوازيون"، أو "جلسات الوكلاء المتعددة"، أو "git Worktree"، أو "تشغيل الوكلاء بالتوازي"، أو "العمل على شيئين في وقت واحد"، أو "مساحة عمل الوكيل المعزول"، أو "تدوير وكيل آخر"، أو أي طلب يتضمن تدفقات تطوير متزامنة بمساعدة الذكاء الاصطناعي.
