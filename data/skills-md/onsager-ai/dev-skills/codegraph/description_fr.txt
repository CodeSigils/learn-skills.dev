Graphique de connaissances de code pré-indexé (MCP, SQLite + tree-sitter) pour une exploration plus rapide et avec moins de jetons des bases de code des friches industrielles. À utiliser lorsque vous commencez à travailler sur un dépôt de plus de 500 fichiers ou lorsque la tâche implique une traversée de fichiers croisés : "où X est-il utilisé", "qu'est-ce qui appelle Y", "qu'est-ce qui se casse si je change Z", "tracer le flux de A à B", "expliquer ce sous-système". Ignorez les modifications de fichiers uniques ou les sessions plus courtes que le coût de démarrage à froid. Les déclencheurs incluent "codegraph", "code graph", "index this repo", "où X est défini", "trouver les appelants de", "les appelés de", "le rayon d'explosion du changement de X", "explorer cette base de code". Remplace les boucles grep + Read par les recherches O(1) SQLite et la recherche FTS5 via 8 outils MCP.
