브라운필드 코드베이스를 더 빠르고 더 적은 토큰으로 탐색하기 위한 사전 색인화된 코드 지식 그래프(MCP, SQLite + tree-sitter). 최대 500개 파일보다 큰 저장소에서 작업을 시작할 때 또는 작업에 파일 간 순회가 포함되는 경우 사용합니다. — "X는 어디에 사용됩니까?", "Y를 호출하는 것은 무엇입니까?", "Z를 변경하면 무엇이 중단됩니까?", "A에서 B로의 흐름 추적", "이 하위 시스템 설명". 단일 파일 편집이나 초기 시작 비용보다 짧은 세션은 건너뜁니다. 트리거에는 "코드 그래프", "코드 그래프", "이 저장소 색인화", "X가 정의된 위치", "발신자 찾기", "수신자", "X 변경 폭발 반경", "이 코드베이스 탐색"이 포함됩니다. grep + Read 루프를 O(1) SQLite 조회 및 8개 MCP 도구를 통한 FTS5 검색으로 대체합니다.
