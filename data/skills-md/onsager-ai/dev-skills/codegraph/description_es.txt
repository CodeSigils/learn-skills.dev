Gráfico de conocimiento de código preindexado (MCP, SQLite + tree-sitter) para una exploración más rápida y de menor token de bases de código antiguas. Úselo cuando comience a trabajar en un repositorio de más de ~500 archivos o cuando la tarea implique un recorrido entre archivos: "dónde se usa X", "qué llama a Y", "qué se interrumpe si cambio Z", "rastro del flujo de A a B", "explica este subsistema". Omita ediciones de un solo archivo o sesiones más cortas que el costo del inicio en frío. Los activadores incluyen "código gráfico", "gráfico de código", "indexar este repositorio", "dónde está definido X", "buscar llamantes de", "llamados de", "radio de explosión de X cambiante", "explorar esta base de código". Reemplaza los bucles grep + Read con búsquedas SQLite O(1) y búsqueda FTS5 a través de 8 herramientas MCP.
