Grafico della conoscenza del codice preindicizzato (MCP, SQLite + tree-sitter) per un'esplorazione più rapida e con token inferiori delle basi di codici brownfield. Da utilizzare quando si inizia a lavorare su un repository più grande di circa 500 file o quando l'attività prevede l'attraversamento di più file: "dove viene utilizzato X", "cosa chiama Y", "cosa si interrompe se cambio Z", "traccia il flusso da A a B", "spiega questo sottosistema". Salta per modifiche a file singolo o sessioni più brevi del costo di avvio a freddo. I trigger includono "codegraph", "code graph", "indicizza questo repository", "dove è definito X", "trova chiamanti di", "chiamati di", "raggio di esplosione della modifica di X", "esplora questa codebase". Sostituisce grep + Read loop con ricerche SQLite O(1) e ricerca FTS5 tramite 8 strumenti MCP.
