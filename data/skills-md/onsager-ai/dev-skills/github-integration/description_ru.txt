Включите интерфейс командной строки GitHub («gh») в облачных сеансах Claude Code и средах агента кодирования GitHub Copilot. Используйте этот навык при: (1) настройке проекта, чтобы облачные агенты ИИ могли использовать `gh` для PR, проблем и выпусков, (2) настройке сценариев настройки или перехватчиков SessionStart для установки `gh`, (3) добавлении `copilot-setup-steps.yml` для агентов GitHub Copilot, (4) устранении неполадок, связанных с ошибками аутентификации `gh` в облачных сеансах, или (5) настройке `GH_TOKEN` для автономных сред. Срабатывает при: «включить gh», «интеграцию с github», «настройка облака кода Claude», «этапы настройки второго пилота», «gh аутентификация в облаке», «gh не работает в облаке», «сценарий установки» или любой запрос, включающий доступ к GitHub CLI от облачных агентов кодирования AI.
