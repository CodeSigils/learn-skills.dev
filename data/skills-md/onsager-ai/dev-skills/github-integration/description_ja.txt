Claude Code クラウド セッションおよび GitHub Copilot コーディング エージェント環境で GitHub CLI (`gh`) を有効にします。このスキルは、(1) クラウド AI エージェントが PR、問題、リリースに「gh」を使用できるようにプロジェクトを設定する場合、(2) 「gh」 インストール用のセットアップ スクリプトまたは SessionStart フックを構成する場合、(3) GitHub Copilot エージェントに「copilot-setup-steps.yml」を追加する場合、(4) クラウド セッションでの「gh」認証エラーのトラブルシューティングを行う場合、または (5) ヘッドレス環境用に「GH_TOKEN」を構成する場合にこのスキルを使用します。トリガー: 「gh を有効にする」、「github 統合」、「Claude Code クラウド セットアップ」、「コパイロット セットアップ ステップ」、「クラウドでの gh 認証」、「クラウドで gh が機能しない」、「セットアップ スクリプト」、またはクラウドベースの AI コーディング エージェントからの GitHub CLI アクセスを伴うリクエスト。
