Activez la CLI GitHub (`gh`) dans les sessions cloud Claude Code et les environnements d'agent de codage GitHub Copilot. Utilisez cette compétence lorsque : (1) configurez un projet afin que les agents IA cloud puissent utiliser `gh` pour les PR, les problèmes et les versions, (2) configurez des scripts de configuration ou des hooks SessionStart pour l'installation `gh`, (3) ajoutez `copilot-setup-steps.yml` pour les agents GitHub Copilot, (4) dépannez les échecs d'authentification `gh` dans les sessions cloud, ou (5) configurez `GH_TOKEN` pour le sans tête environnements. Se déclenche sur : "activer gh", "intégration github", "configuration cloud Claude Code", "étapes de configuration du copilote", "authentification gh dans le cloud", "gh ne fonctionne pas dans le cloud", "script de configuration" ou toute demande impliquant un accès CLI GitHub à partir d'agents de codage IA basés sur le cloud.
