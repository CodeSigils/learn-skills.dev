Aktivieren Sie die GitHub-CLI („gh“) in Claude Code-Cloud-Sitzungen und GitHub Copilot-Coding-Agent-Umgebungen. Verwenden Sie diesen Skill, wenn: (1) ein Projekt eingerichtet wird, damit Cloud-KI-Agenten „gh“ für PRs, Probleme und Releases verwenden können, (2) Setup-Skripte oder SessionStart-Hooks für die „gh“-Installation konfigurieren, (3) „copilot-setup-steps.yml“ für GitHub Copilot-Agenten hinzufügen, (4) „gh“-Authentifizierungsfehler in Cloud-Sitzungen beheben oder (5) „GH_TOKEN“ für Headless konfigurieren Umgebungen. Auslöser bei: „GH aktivieren“, „Github-Integration“, „Claude Code-Cloud-Setup“, „Copilot-Setup-Schritte“, „GH-Authentifizierung in der Cloud“, „GH funktioniert nicht in der Cloud“, „Setup-Skript“ oder jede Anfrage, die GitHub-CLI-Zugriff von cloudbasierten KI-Coding-Agents beinhaltet.
