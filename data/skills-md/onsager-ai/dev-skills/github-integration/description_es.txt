Habilite la CLI de GitHub (`gh`) en las sesiones de nube de Claude Code y en los entornos del agente de codificación GitHub Copilot. Utilice esta habilidad cuando: (1) configure un proyecto para que los agentes de IA en la nube puedan usar `gh` para relaciones públicas, problemas y lanzamientos, (2) configure scripts de configuración o enlaces SessionStart para la instalación de `gh`, (3) agregue `copilot-setup-steps.yml` para agentes de GitHub Copilot, (4) solucione problemas de fallas de autenticación de `gh` en sesiones en la nube o (5) configure `GH_TOKEN` para entornos sin cabeza. Activadores en: "habilitar gh", "integración de github", "configuración de la nube de Claude Code", "pasos de configuración del copiloto", "autenticación de gh en la nube", "gh no funciona en la nube", "script de configuración" o cualquier solicitud que implique acceso a la CLI de GitHub desde agentes de codificación de IA basados ​​en la nube.
