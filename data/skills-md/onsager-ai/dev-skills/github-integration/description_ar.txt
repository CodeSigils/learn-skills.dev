قم بتمكين GitHub CLI (`gh`) في جلسات Claude Code السحابية وبيئات وكيل ترميز GitHub Copilot. استخدم هذه المهارة عندما: (1) إعداد مشروع حتى يتمكن وكلاء الذكاء الاصطناعي السحابي من استخدام `gh` للعلاقات العامة والمشكلات والإصدارات، (2) تكوين البرامج النصية للإعداد أو خطافات SessionStart لتثبيت `gh`، (3) إضافة `copilot-setup-steps.yml` لوكلاء GitHub Copilot، (4) استكشاف أخطاء فشل المصادقة `gh` في الجلسات السحابية، أو (5) تكوين `GH_TOKEN` للبيئات مقطوعة الرأس. مشغلات على: "تمكين gh"، أو "تكامل github"، أو "إعداد Claude Code Cloud"، أو "خطوات إعداد المساعد"، أو "gh auth in cloud"، أو "gh لا يعمل في السحابة"، أو "البرنامج النصي للإعداد"، أو أي طلب يتضمن الوصول إلى GitHub CLI من وكلاء ترميز الذكاء الاصطناعي المستندين إلى السحابة.
