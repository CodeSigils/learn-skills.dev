在 Claude Code 雲端會話和 GitHub Copilot 編碼代理環境中啟用 GitHub CLI (`gh`)。在以下情況下使用此技能：(1) 設定項目，以便雲端 AI 代理可以使用“gh”進行 PR、問題和發布，(2) 為“gh”安裝配置設定腳本或 SessionStart 掛鉤，(3) 為 GitHub Copilot 代理程式新增“copilot-setup-steps.yml”，(4) 對身分驗證會話中的「故障排除 为无头环境配置“GH_TOKEN”。觸發條件：「啟用 gh」、「github 整合」、「Claude Code 雲端設定」、「copilot 設定步驟」、「雲端中的 gh 驗證」、「gh 不在雲端中工作」、「設定腳本」或任何涉及從基於雲端的 AI 編碼代理存取 GitHub CLI 的請求。
