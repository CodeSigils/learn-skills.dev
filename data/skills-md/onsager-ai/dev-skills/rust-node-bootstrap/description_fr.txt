Élaborez un nouveau monorepo hybride Rust+Node.js avec des espaces de travail pnpm, un espace de travail Cargo, des flux de travail CI et une infrastructure de publication. À utiliser lorsque : (1) démarrer un nouveau projet à partir de zéro, (2) ajouter l'infrastructure manquante à un dépôt existant, (3) déterminer la structure canonique du projet pour un outil Rust+Node.js. Déclencheurs sur « bootstrap », « scaffold », « new project », « setup project » ou « init » dans un contexte Rust+Node.js.
