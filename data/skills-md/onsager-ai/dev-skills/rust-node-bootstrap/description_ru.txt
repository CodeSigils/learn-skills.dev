Создайте новый гибридный монорепозиторий Rust+Node.js с рабочими областями pnpm, рабочей областью Cargo, рабочими процессами CI и инфраструктурой публикации. Используйте, когда: (1) начинаете новый проект с нуля, (2) добавляете недостающую инфраструктуру в существующий репозиторий, (3) выясняете каноническую структуру проекта для инструмента Rust+Node.js. Запускается по «начальной загрузке», «эшафоту», «новому проекту», «настройке проекта» или «инициализации» в контексте Rust+Node.js.
