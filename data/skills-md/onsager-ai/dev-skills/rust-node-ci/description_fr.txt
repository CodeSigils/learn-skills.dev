GitHub Actions CI/CD pour les dépôts hybrides Rust+Node.js. Couvre la structure du flux de travail, les actions composites installables, le flux d'artefacts, la mise en cache et la gestion des versions de développement. À utiliser lorsque : (1) la configuration ou la correction des flux de travail GitHub Actions, (2) l'ajout de CI pour un projet Rust+Node.js, (3) l'utilisation d'actions composites (configuration-espace de travail, rust-cross-build, calcul-version, wait-npm-propagation), (4) le débogage des échecs de CI, (5) la configuration de la matrice de construction multiplateforme. Les déclencheurs sur « CI », « workflow », « GitHub Actions », « cross-build », « artefact » ou fonctionnent dans .github/workflows/.
