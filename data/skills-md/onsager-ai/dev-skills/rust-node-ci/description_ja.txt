Rust+Node.js ハイブリッド リポジトリ用の GitHub Actions CI/CD。ワークフロー構造、インストール可能な複合アクション、アーティファクト フロー、キャッシュ、開発バージョン管理について説明します。次の場合に使用します: (1) GitHub Actions ワークフローのセットアップまたは修正、(2) Rust+Node.js プロジェクトの CI の追加、(3) 複合アクション (setup-workspace、Rust-cross-build、compute-version、wait-npm-propagation) の操作、(4) CI エラーのデバッグ、(5) クロスプラットフォーム ビルド マトリックスのセットアップ。 「CI」、「ワークフロー」、「GitHub アクション」、「クロスビルド」、「アーティファクト」、または .github/workflows/ の作業でトリガーされます。
