Rust+Node.js 混合儲存庫的 GitHub Actions CI/CD。涵蓋工作流程結構、可安裝的複合操作、工件流程、快取和開發版本控制。在下列情況下使用：(1) 設定或修復 GitHub Actions 工作流程，(2) 為 Rust+Node.js 專案新增 CI，(3) 使用複合操作（setup-workspace、rust-cross-build、compute-version、wait-npm-propagation），(4) 執行程式碼 CI 故障，(5) 偵錯設定。在「CI」、「工作流程」、「GitHub Actions」、「交叉建置」、「工件」或 .github/workflows/ 中的工作上觸發。
