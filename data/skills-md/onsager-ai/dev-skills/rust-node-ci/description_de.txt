GitHub Actions CI/CD für Rust+Node.js Hybrid-Repos. Behandelt Workflow-Struktur, installierbare Verbundaktionen, Artefaktfluss, Caching und Entwicklungsversionierung. Wird verwendet, wenn: (1) GitHub Actions-Workflows eingerichtet oder repariert werden, (2) CI für ein Rust+Node.js-Projekt hinzugefügt wird, (3) mit zusammengesetzten Aktionen gearbeitet wird (setup-workspace, rust-cross-build, compute-version, wait-npm-propagation), (4) CI-Fehler debuggt, (5) die plattformübergreifende Build-Matrix eingerichtet wird. Löst auf „CI“, „workflow“, „GitHub Actions“, „cross-build“, „artifact“ oder Arbeit in .github/workflows/ aus.
