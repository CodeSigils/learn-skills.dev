GitHub Actions CI/CD для гибридных репозиториев Rust+Node.js. Охватывает структуру рабочего процесса, устанавливаемые составные действия, поток артефактов, кэширование и управление версиями разработки. Используйте при: (1) настройке или исправлении рабочих процессов GitHub Actions, (2) добавлении CI для проекта Rust+Node.js, (3) работе с составными действиями (setup-workspace,rust-cross-build, Compute-version, wait-npm-propagation), (4) отладке сбоев CI, (5) настройке матрицы кросс-платформенной сборки. Триггеры по «CI», «рабочему процессу», «Действиям GitHub», «кросс-сборке», «артефакту» или работе в .github/workflows/.
