GitHub Actions CI/CD para repositorios híbridos Rust+Node.js. Cubre la estructura del flujo de trabajo, acciones compuestas instalables, flujo de artefactos, almacenamiento en caché y control de versiones de desarrollo. Úselo cuando: (1) configure o corrija los flujos de trabajo de GitHub Actions, (2) agregue CI para un proyecto Rust+Node.js, (3) trabaje con acciones compuestas (setup-workspace, Rust-cross-build, Compute-version, wait-npm-propagation), (4) depure fallas de CI, (5) configure la matriz de compilación multiplataforma.
