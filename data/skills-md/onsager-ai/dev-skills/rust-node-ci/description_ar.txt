إجراءات GitHub CI/CD لـ Rust+Node.js مستودعات مختلطة. يغطي بنية سير العمل، والإجراءات المركبة القابلة للتثبيت، وتدفق العناصر، والتخزين المؤقت، وإصدارات التطوير. يُستخدم عندما: (1) إعداد أو إصلاح سير عمل GitHub Actions، (2) إضافة CI لمشروع Rust+Node.js، (3) العمل مع الإجراءات المركبة (مساحة عمل الإعداد، والإنشاء المتقاطع، والإصدار الحسابي، والانتظار npm-propagation)، (4) تصحيح أخطاء فشل CI، (5) إعداد مصفوفة البناء عبر الأنظمة الأساسية. مشغلات على "CI" أو "سير العمل" أو "إجراءات GitHub" أو "الإنشاء المتقاطع" أو "المنتج" أو العمل في ‎.github/workflows/.
