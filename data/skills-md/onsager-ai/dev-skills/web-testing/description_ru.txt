Тестирование веб-интерфейса L2 на основе искусственного интеллекта для приложения информационной панели React/Vite. Первоначально создано на основе панели управления Onsager (таблица маршрутов тела + пути к файлам имеют форму Onsager); другие панели мониторинга React разветвляют процедуру и заменяют свои собственные маршруты/пути тестирования. Используйте при тестировании пользовательского интерфейса на PR, сортировке сбоев теста L1 или проверке поведения пользовательского интерфейса на экранах просмотра на настольных и мобильных устройствах. Триггеры включают в себя «проверить пользовательский интерфейс», «проверить панель мониторинга», «определить сбой L1», «запустить тесты L2», «подтвердить этот PR», «исследовательское тестирование веб-приложения».
