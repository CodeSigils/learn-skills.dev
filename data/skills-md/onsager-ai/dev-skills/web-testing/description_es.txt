Pruebas de interfaz de usuario web L2 impulsadas por IA para una aplicación de panel React/Vite. Creado originalmente en el Panel de Onsager (la tabla de rutas del cuerpo + las rutas de archivo tienen forma de Onsager); otros paneles de React bifurcan el procedimiento y lo sustituyen por sus propias rutas/rutas de prueba. Úselo al probar la interfaz de usuario en relaciones públicas, clasificar fallas en las pruebas L1 o verificar el comportamiento de la interfaz de usuario en las ventanas gráficas de escritorio y móviles. Los activadores incluyen "probar la interfaz de usuario", "comprobar el panel", "fallo de clasificación L1", "ejecutar pruebas L2", "validar este PR", "prueba exploratoria de la aplicación web".
