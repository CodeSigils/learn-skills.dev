React/Vite ダッシュボード アプリの L2 AI 主導の Web UI テスト。元々は Onsager ダッシュボードに対して作成されました (本体のルート テーブル + ファイル パスは Onsager の形をしています)。他の React ダッシュボードはプロシージャをフォークし、独自のルート/テスト パスを置き換えます。 PR で UI をテストする場合、L1 テストの失敗を優先順位付けする場合、またはデスクトップとモバイルのビューポートで UI の動作を検証する場合に使用します。トリガーには、「UI のテスト」、「ダッシュボードのチェック」、「L1 障害のトリアージ」、「L2 テストの実行」、「この PR の検証」、「Web アプリの探索的テスト」が含まれます。
