Test d'interface utilisateur Web basé sur l'IA L2 pour une application de tableau de bord React/Vite. Créé à l'origine sur le tableau de bord Onsager (la table de routage du corps + les chemins de fichiers sont en forme d'Onsager) ; d'autres tableaux de bord React suivent la procédure et remplacent leurs propres itinéraires/chemins de test. À utiliser lors du test de l'interface utilisateur sur les PR, du tri des échecs de test L1 ou de la vérification du comportement de l'interface utilisateur dans les fenêtres d'affichage de bureau et mobile. Les déclencheurs incluent « tester l'interface utilisateur », « vérifier le tableau de bord », « trier les échecs L1 », « exécuter des tests L2 », « valider ce PR », « tester exploratoirement l'application Web ».
