Meilleures pratiques pour créer des commits git propres et atomiques avec de bons messages. À utiliser lorsque : (1) préparer et valider des modifications, (2) écrire des messages de validation, (3) décider quoi regrouper dans une seule validation, (4) gérer les échecs de hook avant la validation, (5) choisir entre une modification et une nouvelle validation. Déclencheurs sur "commit", "stage", "git add", "écrire un message de validation" ou "valider mes modifications".
