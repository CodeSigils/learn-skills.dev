Mejores prácticas para crear confirmaciones de git atómicas y limpias con buenos mensajes. Úselo cuando: (1) preparar y confirmar cambios, (2) escribir mensajes de confirmación, (3) decidir qué agrupar en una sola confirmación, (4) manejar fallas de enlace previo a la confirmación, (5) elegir entre modificar y nueva confirmación. Activadores en "commit", "stage", "git add", "escribir un mensaje de confirmación" o "confirmar mis cambios".
