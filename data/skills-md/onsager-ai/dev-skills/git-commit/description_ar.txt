أفضل الممارسات لإنشاء git نظيفة وذرية مع رسائل جيدة. يُستخدم عندما: (1) تنفيذ التغييرات وتنفيذها، (2) كتابة رسائل الالتزام، (3) تحديد ما سيتم تجميعه في التزام واحد، (4) التعامل مع حالات فشل ربط ما قبل الالتزام، (5) الاختيار بين التعديل والالتزام الجديد. يتم تشغيلها على "الالتزام" أو "المرحلة" أو "git add" أو "كتابة رسالة التزام" أو "تنفيذ تغييراتي".
