从 CLI 调试、开发和操作 Railway (railway.com) 上托管的应用程序 — 列出项目/服务、跟踪和过滤构建/部署/HTTP 日志、读取指标、检查和设置变量、从当前目录部署、重新部署/重新启动/回滚、使用服务的 env 运行本地命令、通过 SSH 连接到容器，以及打开 DB shell。通过“RAILWAY_TOKEN”环境变量（帐户令牌或项目范围令牌）进行身份验证。可选的捆绑脚本（`scripts/preflight.sh`、`scripts/debug.sh`、`scripts/smoke.sh`）是 Onsager 特定的包装器 - 其他存储库可以忽略它们或分叉它们。触发器包括“部署到铁路”、“铁路部署此”、“铁路日志”、“尾部铁路日志”、“为什么我的铁路服务崩溃”、“为什么在铁路上构建失败”、“铁路 500 秒”、“铁路延迟”、“显示铁路 http 日志”、“在铁路上重新部署”、“重新启动我的铁路服务”、“回滚铁路”、“设置铁路环境变量”、“列出铁路变量”、“铁路”指标”、“我的铁路服务是否健康”、“连接到我的铁路 postgres”、“ssh 进入铁路”、“使用铁路环境在本地运行”、“列出铁路项目/服务/部署”以及（Onsager 特定的）“检查铁路”、“预检”、“冒烟测试”、“部署是否健康”。
