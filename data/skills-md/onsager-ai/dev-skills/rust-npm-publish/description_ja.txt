OptionalDependency プラットフォーム パッケージ パターンを使用して、Rust バイナリを npm に公開します。完全なパブリッシュ パイプライン、バージョン同期、workspace:* プロトコル、およびプラットフォーム パッケージ アーキテクチャをカバーします。次の場合に使用します: (1) Rust バイナリを npm に公開する、(2) プラットフォーム パッケージ パターン (メイン + OS ごとのパッケージ) を設定する、(3) パブリッシュの失敗をデバッグする、(4) pnpm + Cargo ワークスペース間のバージョン同期を管理する、(5) workspace:* プロトコルを使用する。 「公開」、「プラットフォーム パッケージ」、「optionalDependency」、「bin.js」、「バージョン同期」、「ワークスペース プロトコル」、「npm タグ」、または「prepare-publish」でトリガーされます。
