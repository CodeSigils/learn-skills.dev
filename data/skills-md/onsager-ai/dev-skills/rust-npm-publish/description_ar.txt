انشر ثنائيات Rust إلى npm باستخدام نمط حزمة النظام الأساسي الاختياري للتبعيات. يغطي مسار النشر الكامل، ومزامنة الإصدار، ومساحة العمل:* البروتوكول، وبنية حزمة النظام الأساسي. يُستخدم عندما: (1) نشر ثنائيات Rust إلى npm، (2) إعداد نمط حزمة النظام الأساسي (الحزم الرئيسية + لكل نظام تشغيل)، (3) تصحيح فشل النشر، (4) إدارة مزامنة الإصدار عبر مساحات عمل pnpm + Cargo، (5) العمل مع مساحة العمل:* البروتوكول. مشغلات عند "النشر"، أو "حزم النظام الأساسي"، أو "التبعيات الاختيارية"، أو "bin.js"، أو "مزامنة الإصدار"، أو "بروتوكول مساحة العمل"، أو "علامة npm"، أو "التحضير للنشر".
