Публикуйте двоичные файлы Rust в npm, используя шаблон пакета платформы optionDependities. Охватывает полный конвейер публикации, синхронизацию версий, протокол Workspace:* и архитектуру пакета платформы. Используйте при: (1) публикации двоичных файлов Rust в npm, (2) настройке шаблона пакета платформы (основной + пакеты для каждой ОС), (3) отладке ошибок публикации, (4) управлении синхронизацией версий между рабочими пространствами pnpm + Cargo, (5) работе с протоколом workspace:*. Запускается по «публикации», «пакетам платформы», «дополнительным зависимостям», «bin.js», «синхронизации версий», «протоколу рабочей области», «тегу npm» или «подготовке-публикации».
