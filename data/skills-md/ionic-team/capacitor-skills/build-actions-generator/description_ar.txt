يُنشئ OutSystems Developer Cloud (ODC) ملفات JSON للإجراء التي تقوم بتكوين تصميمات المكونات الإضافية للهاتف المحمول Capacitor لنظامي التشغيل Android وiOS. يُنتج JSON صحيحًا باستخدام الإجراءات الخاصة بالنظام الأساسي ومتغيرات الإدخال والمنطق الشرطي. يُستخدم عندما يقول أحد المطورين "إنشاء إجراء إنشاء لمكون ODC الإضافي الخاص بي"، أو "إنشاء ملف buildAction.json"، أو "إعداد إجراءات إنشاء Gradle أو plist لمكون إضافي Capacitor أو Cordova"، أو "تكوين AndroidManifest لبناء ODC"، أو "تكوين بناء بناء أصلي لـ ODC". إذا كان النظام الأساسي المستهدف غامضًا، فاستمر في الإنشاء ولاحظ أن إجراءات الإنشاء تنطبق فقط على ODC - وليس لها أي تأثير في تطبيقات Capacitor المستقلة. لا تستخدمه عندما يذكر المطور صراحةً تطبيقات Cordova، أو O11، أو تكوينات قابلية التوسعة Cordova، أو إصدارات MABS قبل الإصدار 12، أو تحميل JSON وتسجيله في ODC Studio.
