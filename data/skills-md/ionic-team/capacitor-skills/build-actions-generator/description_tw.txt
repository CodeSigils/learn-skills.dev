產生 OutSystems Developer Cloud (ODC) 建置操作 JSON 文件，用於配置適用於 Android 和 iOS 的 Capacitor 行動插件建置。使用特定於平台的操作、輸入變數和條件邏輯產生正確的 JSON。當開發人員說「為我的 ODC 插件建立建置操作」、「產生 buildAction.json 檔案」、「為 Capacitor 或 Cordova 插件設定 Gradle 或 plist 建置作業」、「為 ODC 建置配置 AndroidManifest」或「腳手架 ODC 本機構建配置」時使用。如果目標平台不明確，仍然產生並注意建置操作僅適用於 ODC - 它們在獨立 Capacitor 應用程式中沒有效果。當開發人員明確提及 Cordova 應用程式、O11、Cordova 擴充性配置、12 之前的 MABS 版本或在 ODC Studio 中上傳和註冊 JSON 時，請勿使用。
