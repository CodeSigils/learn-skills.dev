Создает JSON-файлы действий сборки OutSystems Developer Cloud (ODC), которые настраивают сборки мобильных плагинов Capacitor для Android и iOS. Создает правильный JSON с действиями, специфичными для платформы, входными переменными и условной логикой. Используйте, когда разработчик говорит «создать действие сборки для моего плагина ODC», «создать файл buildAction.json», «настроить действия сборки Gradle или plist для плагина Capacitor или Cordova», «настроить AndroidManifest для сборки ODC» или «подготовить собственную конфигурацию сборки ODC». Если целевая платформа неоднозначна, все равно сгенерируйте и обратите внимание, что действия сборки применяются только к ODC — они не влияют на автономные приложения Capacitor. Не используйте, если разработчик явно упоминает приложения Cordova, O11, конфигурации расширяемости Cordova, версии MABS до 12 или загрузку и регистрацию JSON в ODC Studio.
