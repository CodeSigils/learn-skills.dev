Genera archivos JSON de acción de compilación de OutSystems Developer Cloud (ODC) que configuran las compilaciones de complementos móviles de Capacitor para Android e iOS. Produce JSON correcto con acciones específicas de la plataforma, variables de entrada y lógica condicional. Úselo cuando un desarrollador dice "crear una acción de compilación para mi complemento ODC", "generar un archivo buildAction.json", "configurar acciones de compilación Gradle o plist para un complemento Capacitor o Cordova", "configurar AndroidManifest para la compilación ODC" o "estructurar la configuración de compilación nativa de ODC". Si la plataforma de destino es ambigua, genere de todos modos y tenga en cuenta que las acciones de compilación solo se aplican a ODC; no tienen ningún efecto en las aplicaciones Capacitor independientes. No lo use cuando el desarrollador mencione explícitamente aplicaciones Cordova, O11, configuraciones de extensibilidad Cordova, versiones MABS anteriores a la 12 o cargar y registrar el JSON en ODC Studio.
