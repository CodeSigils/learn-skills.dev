Génère des fichiers JSON d'action de build OutSystems Developer Cloud (ODC) qui configurent les builds du plug-in mobile Capacitor pour Android et iOS. Produit un JSON correct avec des actions spécifiques à la plate-forme, des variables d'entrée et une logique conditionnelle. À utiliser lorsqu'un développeur dit "créer une action de construction pour mon plugin ODC", "générer un fichier buildAction.json", "configurer des actions de construction Gradle ou plist pour un plugin Capacitor ou Cordova", "configurer AndroidManifest pour la construction ODC" ou "configuration de construction native ODC d'échafaudage". Si la plate-forme cible est ambiguë, générez toujours et notez que les actions de construction s'appliquent uniquement à ODC : elles n'ont aucun effet dans les applications Capacitor autonomes. Ne pas utiliser lorsque le développeur mentionne explicitement les applications Cordova, O11, les configurations d'extensibilité Cordova, les versions MABS antérieures à 12, ou le téléchargement et l'enregistrement du JSON dans ODC Studio.
