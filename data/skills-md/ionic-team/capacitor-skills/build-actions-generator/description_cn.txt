生成 OutSystems Developer Cloud (ODC) 构建操作 JSON 文件，用于配置适用于 Android 和 iOS 的 Capacitor 移动插件构建。使用特定于平台的操作、输入变量和条件逻辑生成正确的 JSON。当开发人员说“为我的 ODC 插件创建构建操作”、“生成 buildAction.json 文件”、“为 Capacitor 或 Cordova 插件设置 Gradle 或 plist 构建操作”、“为 ODC 构建配置 AndroidManifest”或“脚手架 ODC 本机构建配置”时使用。如果目标平台不明确，仍然生成并注意构建操作仅适用于 ODC - 它们在独立 Capacitor 应用程序中没有效果。当开发人员明确提及 Cordova 应用程序、O11、Cordova 扩展性配置、12 之前的 MABS 版本或在 ODC Studio 中上传和注册 JSON 时，请勿使用。
