Genera file JSON di azione build OutSystems Developer Cloud (ODC) che configurano build di plug-in mobile Capacitor per Android e iOS. Produce JSON corretto con azioni specifiche della piattaforma, variabili di input e logica condizionale. Da utilizzare quando uno sviluppatore dice "crea un'azione di build per il mio plug-in ODC", "genera un file buildAction.json", "imposta azioni di build Gradle o plist per un plug-in Capacitor o Cordova", "configura AndroidManifest per la build ODC" o "configurazione di build nativa ODC dello scaffold". Se la piattaforma di destinazione è ambigua, genera comunque e tieni presente che le azioni di compilazione si applicano solo a ODC: non hanno alcun effetto nelle app Capacitor autonome. Non utilizzare quando lo sviluppatore menziona esplicitamente app Cordova, O11, configurazioni di estensibilità Cordova, versioni MABS precedenti alla 12 o caricamento e registrazione di JSON in ODC Studio.
