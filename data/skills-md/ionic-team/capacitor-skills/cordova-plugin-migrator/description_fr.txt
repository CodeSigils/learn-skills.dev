Orchestrateur de migration Cordova vers Capacitor de bout en bout. Analyse le plugin Cordova (plugin.xml, source native iOS/Android, pont JS, hooks, dépendances tierces), produit un plan de migration structuré au format YAML conforme au contrat d'entrée du générateur de plugin de condensateur, invoque la compétence du générateur en mode structuré à un point de contrôle utilisateur, puis consolide les notes intermédiaires en un seul MIGRATION.md. À utiliser lorsque l'utilisateur dit « migrer ce plugin Cordova », « convertir Cordova en condensateur », « évaluer la faisabilité de la migration », « ce qui bloque cette migration », « porter ce plugin Cordova sur condensateur » ou « estimer l'effort de migration ». Ne pas utiliser pour générer de nouveaux plugins Capacitor à partir de zéro (utilisez plutôt le générateur de plugins de condensateur), pour déboguer des problèmes d'exécution dans un plugin déjà migré ou pour migrer une application Cordova entière ; la portée est uniquement au niveau du plugin.
