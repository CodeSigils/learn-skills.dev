End-to-End-Orchestrator für die Cordova-zu-Kondensator-Migration. Analysiert das Cordova-Plugin (plugin.xml, native iOS/Android-Quelle, JS-Bridge, Hooks, Abhängigkeiten von Drittanbietern), erstellt einen strukturierten Migrationsplan als YAML, der dem Eingabevertrag des Capacitor-Plugin-Generators entspricht, ruft den Generator-Skill im strukturierten Modus an einem Benutzerkontrollpunkt auf und konsolidiert dann Zwischennotizen in einer einzigen MIGRATION.md. Wird verwendet, wenn der Benutzer sagt: „Dieses Cordova-Plugin migrieren“, „Cordova in einen Kondensator konvertieren“, „Migrationsfähigkeit der Migration bewerten“, „was diese Migration blockiert“, „dieses Cordova-Plugin auf einen Kondensator portieren“ oder „den Aufwand für die Migration abschätzen“. Nicht zum Generieren neuer Capacitor-Plugins von Grund auf verwenden (verwenden Sie stattdessen den Capacitor-Plugin-Generator), zum Debuggen von Laufzeitproblemen in einem bereits migrierten Plugin oder zum Migrieren einer gesamten Cordova-Anwendung; Der Geltungsbereich ist nur auf Plugin-Ebene gültig.
