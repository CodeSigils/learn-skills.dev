Génère de nouveaux échafaudages de plugins Capacitor et des implémentations de premier passage à partir d'exigences conversationnelles ou d'un contrat d'entrée YAML structuré. À utiliser lorsqu'un utilisateur dit « générer un plugin Capacitor », « créer un échafaudage de plugin Capacitor », « créer un plugin natif pour iOS et Android », « transformer ce plan de plugin en code Capacitor » ou « utiliser ce contrat YAML pour générer un plugin ». Ne pas utiliser pour analyser la source Cordova, migrer des applications entières, installer des plugins existants, mettre à niveau les versions de Capacitor ou publier du code prêt pour la production sans examen humain.
