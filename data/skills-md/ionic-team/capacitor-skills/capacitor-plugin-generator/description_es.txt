Genera nuevos andamios de complementos de Capacitor e implementaciones de primer paso a partir de requisitos conversacionales o un contrato de entrada YAML estructurado. Úselo cuando un usuario diga "generar un complemento de Capacitor", "crear un andamio de complemento de Capacitor", "crear un complemento nativo para iOS y Android", "convertir este plan de complemento en código de Capacitor" o "usar este contrato YAML para generar un complemento". No lo utilice para analizar el código fuente de Cordova, migrar aplicaciones completas, instalar complementos existentes, actualizar versiones de Capacitor o publicar código listo para producción sin revisión humana.
