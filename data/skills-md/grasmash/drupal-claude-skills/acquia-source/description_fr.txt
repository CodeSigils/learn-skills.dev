Connectez-vous à un site Acquia Source (« Source optimisée par Drupal CMS ») : ses points de terminaison JSON:API et MCP, l'authentification OAuth2, la CLI @drupal-canvas et le workflow de déploiement de l'API Canvas Page. À utiliser lors du câblage d'un agent ou d'une application IA à un site CMS source, de la création/téléchargement de composants de code Drupal Canvas, du déploiement de pages de destination via l'API Page ou de l'enregistrement du serveur MCP source avec Claude Code/Curseur.
