اتصل بموقع Acquia Source ("المصدر المدعوم من Drupal CMS") - نقاط نهاية JSON:API وMCP، ومصادقة OAuth2، و@drupal-canvas CLI، وسير عمل Canvas Page API. يُستخدم عند توصيل وكيل أو تطبيق AI إلى موقع Source CMS، أو إنشاء/تحميل Drupal Canvas Code Components، أو نشر الصفحات المقصودة عبر Page API، أو تسجيل خادم Source MCP باستخدام Claude Code/Cursor.
