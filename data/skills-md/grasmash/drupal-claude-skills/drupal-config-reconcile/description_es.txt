Concilie la deriva de la configuración de Drupal entre un árbol de trabajo y un entorno implementado, un elemento a la vez, decidiendo importar (ganancias de disco) versus exportación (ganancias de base de datos) versus omitir para cada diferencia. Úselo cuando `drush config:status` muestre una desviación, después de extraer una base de datos nueva, antes de una implementación o cuando la configuración local y un entorno remoto/de producción no estén de acuerdo. Compatible con Pantheon/Terminus pero funciona con cualquier alias remoto; nunca escribe a producción.
