Limpie, divida y caracterice los datos de series temporales multivariadas antes de incorporarlos al modelo Omega. Incluye tres bloques de construcción reutilizables: `DataPreprocessor` (diagnostica regularidad de marcas de tiempo, espacios y nulos; crea bloques temporales continuos que detectan espacios con imputación), `DataSplitter` (división de prueba/tren fuera de tiempo o aleatoria que respeta el orden temporal) y `FeaturePreparer` (pivote incorporaciones por sensor en una matriz de "estado conjunto" (X, y, metadatos) con L2/estandarización/PCA opcional). Utilice esta habilidad cuando el usuario esté preparando CSV de sensores sin procesar para el modelo Omega (`atai-newton-omega-model`), cuando los datos de entrenamiento tengan lagunas y no estén seguros de si eliminarlos, imputarlos o dividirlos, o cuando un CSV de n disparos parezca ruidoso y desee un proceso de limpieza basado en principios. NO utilice esta habilidad para ejecutar inferencias o producir incrustaciones (use `atai-newton-omega-model`). NO lo use para datos de video/imagen/texto (use `atai-newton-fusion-model`): solo series de tiempo.
