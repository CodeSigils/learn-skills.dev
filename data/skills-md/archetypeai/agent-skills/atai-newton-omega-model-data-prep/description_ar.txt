قم بتنظيف بيانات السلاسل الزمنية متعددة المتغيرات وتقسيمها وتمييزها قبل تضمينها في نموذج أوميغا. يجمع ثلاث وحدات بناء قابلة لإعادة الاستخدام: `DataPreprocessor` (تشخيص انتظام الطابع الزمني والفجوات والأصفار؛ وإنشاء كتل زمنية مستمرة مدركة للفجوات مع التضمين)، و`DataSplitter` (تقسيم قطار/اختبار خارج الزمن أو عشوائي يحترم الترتيب الزمني)، و`FeaturePreparer` (تضمينات محورية لكل مستشعر في مصفوفة "حالة مشتركة" (X، y، بيانات وصفية) مع اختياري L2 / التقييس / PCA). استخدم هذه المهارة عندما يقوم المستخدم بإعداد ملفات CSV لأجهزة الاستشعار الأولية لنموذج Omega (`atai-newton-omega-model`)، عندما تكون هناك فجوات في بيانات التدريب ويكون غير متأكد من إسقاط/احتساب/تقسيم، أو عندما يبدو ملف CSV n-shot صاخبًا ويريدون مسار تنظيف مبدئي. لا تستخدم هذه المهارة لتشغيل الاستدلال أو إنتاج التضمينات (استخدم نموذج "atai-newton-omega"). لا تستخدمه مع بيانات الفيديو/الصورة/النص (استخدم `atai-newton-fusion-model`) - السلاسل الزمنية فقط.
