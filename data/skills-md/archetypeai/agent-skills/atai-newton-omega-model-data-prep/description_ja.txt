多変量時系列データを Omega モデルに埋め込む前に、クリーンアップ、分割、特徴付けを行います。 3 つの再利用可能なビルディング ブロックをバンドルします: 「DataPreprocessor」 (タイムスタンプの規則性、ギャップ、Null を診断します。代入を使用して連続的なギャップを認識した時間ブロックを構築します)、「DataSplitter」 (時間的順序を考慮した時間外またはランダムなトレーニング/テスト分割)、「FeaturePreparer」 (オプションの「結合状態」(X、Y、メタデータ) 行列にセンサーごとの埋め込みをピボットします) L2/標準化/PCA)。このスキルは、ユーザーが Omega モデル (「atai-newton-omega-model」) の生のセンサー CSV を準備している場合、トレーニング データにギャップがあり、ドロップ/代入/分割するかどうかわからない場合、または n ショット CSV にノイズが多く見えるため、原則に基づいたクリーンアップ パイプラインが必要な場合に使用します。このスキルを推論の実行や埋め込みの生成に使用しないでください (「atai-newton-omega-model」を使用します)。ビデオ / 画像 / テキスト データには使用しないでください (`atai-newton-fusion-model` を使用してください) — 時系列のみ。
