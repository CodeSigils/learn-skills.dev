Очистите, разделите и определите особенности многомерных данных временных рядов перед их внедрением в модель Omega. Объединяет три многократно используемых строительных блока: DataPreprocessor (диагностика регулярности временных меток, пробелов и нулей; построение непрерывных временных блоков с учетом пробелов с помощью вменения), DataSplitter (вневременное или случайное разделение поезда/теста с соблюдением временного порядка) и FeaturePreparer (сведение вложений каждого датчика в матрицу «совместного состояния» (X, y, метаданные) с дополнительным L2 / стандартизация/PCA). Используйте этот навык, когда пользователь готовит необработанные CSV-файлы датчиков для модели Omega («atai-newton-omega-model»), когда в обучающих данных есть пробелы и они не уверены, следует ли отбрасывать/вменять/разделять, или когда CSV из n-shot выглядит шумно и им нужен принципиальный конвейер очистки. НЕ используйте этот навык для вывода или создания вложений (используйте `atai-newton-omega-model`). НЕ используйте для видео/изображений/текстовых данных (используйте `atai-newton-fusion-model`) — только временные ряды.
