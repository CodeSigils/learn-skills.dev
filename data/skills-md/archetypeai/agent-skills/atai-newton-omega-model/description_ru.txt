Получите встраивания временных рядов из кодера Omega Archetype AI (`OmegaEncoder::omega_embeddings_1_4`) через конечную точку продукта `/query` — отправьте окно показаний датчиков, получите обратно вектор фиксированного размера для каждого канала, без пакетных заданий и без сеанса. Используйте этот навык, когда пользователь хочет внедрить окна многомерных датчиков (вибрация, расход, давление, сеть и т. д.) для упрощенного нисходящего машинного обучения — классификации KNN, оценки аномалий, поиска по сходству или 2D-проекции — выполняемых на стороне клиента поверх встраивания. Охватывает форму запроса («data.numeric_array», окно «сначала канал»), вывод 768-d для каждого канала, поддерживаемый диапазон длины окна 16–1024, «normalize_input» и «совместное многоканальное состояние» + шаблон KNN. Для очистки/разделения/оконной обработки необработанных CSV-файлов датчиков см. `atai-newton-omega-model-data-prep`. НЕ используйте для рассуждений по тексту/изображению/видео (это модель слияния Ньютона в `/query`).
