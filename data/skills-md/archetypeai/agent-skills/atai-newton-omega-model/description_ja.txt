Archetype AI の Omega エンコーダー (`OmegaEncoder::omega_embeddings_1_4`) から prod `/query` エンドポイント経由で時系列エンベディングを取得します。センサー読み取り値のウィンドウを送信し、チャネルごとに固定サイズのベクトルを返します。バッチ ジョブやセッションは必要ありません。このスキルは、ユーザーが軽量のダウンストリーム ML (KNN 分類、異常スコアリング、類似性検索、または 2D 投影) のために多変量センサー ウィンドウ (振動、流れ、圧力、ネットワークなど) を埋め込みたい場合に使用します。埋め込み上でクライアント側で実行されます。リクエスト形状 (`data.numeric_array`、チャネルファーストウィンドウ)、チャネルごとの 768-d 出力、サポートされている 16 ～ 1024 のウィンドウ長範囲、`normalize_input`、および「結合マルチチャネル状態」 + KNN パターンをカバーします。生のセンサー CSV のクリーニング/分割/ウィンドウ処理については、まず「atai-newton-omega-model-data-prep」を参照してください。テキスト、画像、ビデオの推論には使用しないでください (`/query` の Newton fusion モデルです)。
