اتصل بنموذج Newton's C 2.6 fusion (`Newton::c2_6_8b_fp8_260424d7a55d5e`) على نقطة نهاية المنتج `/query` مع إدخالات النص والصورة والفيديو في طلب واحد عديم الحالة - لا توجد جلسة، ولا مهمة مجمعة، ولا سباكة SSE. استخدم هذه المهارة عندما يريد المستخدم التفكير متعدد الوسائط لكل مكالمة (وصف صورة، أو تلخيص مقطع، أو تصنيف حالة من المستشعر + السياق المرئي) دون إدارة دورة حياة الجلسة، أو عندما يحتاجون إلى نقطة تفتيش Newton C التي تفسر إطارات الفيديو عبر `/query`. يغطي شكل الطلب لكل طريقة، ومساري مرفقات الصور (file_ids vs base64)، ووضع الصور المتعددة، ومساري الفيديو (`.mp4` + `max_frames`، والإطارات التي تم أخذ عينات منها بواسطة العميل + `query_metadata`)، ومعلمات الإنشاء، ومطالبة إخراج JSON، وميزانيات زمن الوصول، ومعرف C 2.6. لا تستخدم لمراقبة النشاط القائم على البث/الجلسة، أو المهام المجمعة الكبيرة متعددة الملفات، أو تصنيف تضمين السلاسل الزمنية (KNN / الشذوذ).
