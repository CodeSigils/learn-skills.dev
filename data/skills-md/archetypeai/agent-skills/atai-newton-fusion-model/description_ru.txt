Вызовите модель слияния Newton C 2.6 (`Newton::c2_6_8b_fp8_260424d7a55d5e`) на конечной точке продукта `/query` с вводом текста, изображения и видео в одном запросе без сохранения состояния — без сеанса, без пакетного задания, без SSE. Используйте этот навык, когда пользователю нужно мультимодальное обоснование для каждого вызова (описать изображение, суммировать клип, классифицировать состояние на основе датчика + визуального контекста) без управления жизненным циклом сеанса или когда ему нужна контрольная точка Newton C, которая анализирует видеокадры через `/query`. Охватывает форму запроса для каждой модальности, два пути вложения изображений (file_ids и base64), режим нескольких изображений, оба пути видео (`.mp4` + `max_frames` и кадры, выбранные клиентом + `query_metadata`), параметры генерации, подсказки вывода JSON, бюджеты задержки и ошибку с идентификатором C 2.6. НЕ используйте для мониторинга потоковой передачи/сеансовой активности, больших пакетных заданий с несколькими файлами или классификации внедрения временных рядов (KNN/аномалии).
