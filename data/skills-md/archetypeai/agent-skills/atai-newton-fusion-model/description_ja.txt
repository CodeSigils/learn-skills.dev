Newton の C 2.6 融合モデル (`Newton::c2_6_8b_fp8_260424d7a55d5e`) を、prod `/query` エンドポイントでテキスト、画像、およびビデオ入力を使用して 1 つのステートレス リクエストで呼び出します。セッション、バッチ ジョブ、SSE プラミングは必要ありません。このスキルは、ユーザーがセッション ライフサイクルを管理せずに呼び出しごとのマルチモーダル推論 (画像の記述、クリップの要約、センサーとビジュアル コンテキストからの状態の分類) を行う必要がある場合、または「/query」を介してビデオ フレームを推論する Newton C チェックポイントが必要な場合に使用します。モダリティごとのリクエスト形状、2 つの画像添付パス (file_id と Base64)、マルチ画像モード、両方のビデオ パス (`.mp4` + `max_frames`、およびクライアント サンプリング フレーム + `query_metadata`)、生成パラメータ、JSON 出力プロンプト、レイテンシ バジェット、および C 2.6 識別子の注意点をカバーします。ストリーミング/セッションベースのアクティビティ監視、大規模な複数ファイルのバッチ ジョブ、または時系列埋め込み (KNN/異常) 分類には使用しないでください。
