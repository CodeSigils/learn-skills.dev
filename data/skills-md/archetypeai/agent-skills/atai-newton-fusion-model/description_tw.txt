在 prod `/query` 端點上呼叫 Newton 的 C 2.6 融合模型 (`Newton::c2_6_8b_fp8_260424d7a55d5e`)，在單一無狀態請求中使用文字、圖像和視訊輸入 — 無會話、無批次作業、無 SSE 管道。當使用者想要每次調用多模態推理（描述圖像、總結剪輯、對感測器 + 視覺上下文的狀態進行分類）而不管理會話生命週期時，或者當他們需要透過「/query」對視訊幀進行推理的 Newton C 檢查點時，請使用此技能。涵蓋每個模態的請求形狀、兩個圖像附件路徑（file_ids 與 base64）、多圖像模式、兩個視訊路徑（“.mp4”+“max_frames”和客戶端採樣幀+“query_metadata”）、生成參數、JSON 輸出提示、延遲預算和 C 2.6 標識符陷阱。請勿用於串流/基於會話的活動監控、大型多檔案批次作業或時間序列嵌入（KNN/異常）分類。
