Appelez le modèle de fusion C 2.6 de Newton (`Newton::c2_6_8b_fp8_260424d7a55d5e`) sur le point de terminaison de production `/query` avec des entrées de texte, d'image et de vidéo dans une seule requête sans état — pas de session, pas de travail par lots, pas de plomberie SSE. Utilisez cette compétence lorsque l'utilisateur souhaite un raisonnement multimodal par appel (décrire une image, résumer un clip, classer un état à partir du capteur + du contexte visuel) sans gérer le cycle de vie de la session, ou lorsqu'il a besoin du point de contrôle Newton C qui raisonne sur des images vidéo via `/query`. Couvre la forme de la requête par modalité, les deux chemins de pièce jointe d'image (file_ids vs base64), le mode multi-image, les deux chemins vidéo (`.mp4` + `max_frames` et les images échantillonnées par le client + `query_metadata`), les paramètres de génération, les invites de sortie JSON, les budgets de latence et le piège de l'identifiant C 2.6. Ne PAS utiliser pour la surveillance des activités en streaming/basée sur la session, les gros travaux par lots multi-fichiers ou la classification d'intégration de séries chronologiques (KNN/anomalie).
