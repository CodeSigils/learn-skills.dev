أنشئ الواجهة الأمامية لعرض نيوتن التجريبي باستخدام نظام Archetype AI Design System - الحزم المنشورة ذات الإصدار (`@archetypeai/ds-lib-tokens`، `@archetypeai/ds-ui-svelte-console`، `@archetypeai/ds-ui-svelte-labs`) وواجهة سطر الأوامر للسقالات `ds` (`@archetypeai/ds-cli`) - بدلاً من الرموز المميزة أو المكونات أو الخطوط أو تصميم العلامة التجارية. استخدم هذه المهارة عندما يريد المستخدم دعم لوحة معلومات/واجهة مستخدم جديدة، أو إضافة نظام التصميم إلى تطبيق SvelteKit موجود، أو سحب العناصر الأولية ذات العلامات التجارية (شريط القوائم، والشعار، ومخططات المستشعر/المبعثرة، ومشغل الفيديو، والبطاقة، والشارة، والجدول، ومربع الحوار...). تقوم واجهة سطر الأوامر بتثبيت تكوين الوكيل الخاص بنظام التصميم - `CLAUDE.md` (أو `AGENTS.md` للمؤشر) بالإضافة إلى `ds-manifest.json` في جذر المشروع - وهو مصدر الحقيقة لاستخدام المكونات، والخطوط، والسلوك الاحتياطي، والتصميم بمجرد دعمه؛ وظيفة هذه المهارة الوحيدة هي إيصالك إلى هناك. يتم شحن المكونات حاليًا لـ Svelte 5؛ منفذ React قيد التقدم. لا تستخدمه في Newton API / العمل الخلفي (راجع مهارات `atai-newton-*`).
