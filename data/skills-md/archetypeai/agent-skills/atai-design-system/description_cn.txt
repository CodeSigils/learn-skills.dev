使用 Archetype AI 设计系统（已发布的版本控制包（`@archetypeai/ds-lib-tokens`、`@archetypeai/ds-ui-svelte-console`、`@archetypeai/ds-ui-svelte-labs`）和 `ds` 脚手架 CLI (`@archetypeai/ds-cli`) 构建 Newton 演示的前端 — 而不是手动滚动令牌， components, fonts, or brand styling.当用户想要构建新的仪表板/UI、将设计系统添加到现有的 SvelteKit 应用程序或引入品牌基元（菜单栏、徽标、传感器/散点图、视频播放器、卡片、徽章、表格、对话框...）时，请使用此技能。 CLI 在项目根目录中安装设计系统自己的代理配置——“CLAUDE.md”（或“AGENTS.md”用于光标）以及“ds-manifest.json”——这是组件使用、字体、回退行为和脚手架后样式的真实来源； this skill's only job is to get you there. Components currently ship for Svelte 5; a React port is in progress.请勿用于 Newton API/后端工作（请参阅 `atai-newton-*` 技能）。
