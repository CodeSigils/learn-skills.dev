Costruisci il front-end per una demo di Newton con Archetype AI Design System — i pacchetti pubblicati con versione (`@archetypeai/ds-lib-tokens`, `@archetypeai/ds-ui-svelte-console`, `@archetypeai/ds-ui-svelte-labs`) e la CLI di scaffolding `ds` (`@archetypeai/ds-cli`) — invece di token a rotazione manuale, componenti, caratteri o stile del marchio. Utilizza questa abilità quando l'utente desidera impalcare una nuova dashboard/interfaccia utente, aggiungere il sistema di progettazione a un'app SvelteKit esistente o inserire primitive con marchio (barra dei menu, logo, grafici sensore/a dispersione, lettore video, scheda, badge, tabella, finestra di dialogo...). La CLI installa la configurazione dell'agente PROPRIO del sistema di progettazione — "CLAUDE.md" (o "AGENTS.md" per Cursor) più "ds-manifest.json" nella radice del progetto - che è la fonte di verità per l'utilizzo dei componenti, i caratteri, il comportamento di fallback e lo stile una volta impalcato; l'unico compito di questa abilità è portarti lì. I componenti attualmente vengono forniti per Svelte 5; è in corso una porta React. NON utilizzare per API Newton/lavoro backend (vedere le competenze `atai-newton-*`).
