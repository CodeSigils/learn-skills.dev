Créez le front-end pour une démo de Newton avec le système de conception Archetype AI — les packages versionnés publiés (« @archetypeai/ds-lib-tokens », « @archetypeai/ds-ui-svelte-console », « @archetypeai/ds-ui-svelte-labs ») et la CLI d'échafaudage « ds » (« @archetypeai/ds-cli ») — au lieu de rouler manuellement. jetons, composants, polices ou style de marque. Utilisez cette compétence lorsque l'utilisateur souhaite créer un nouveau tableau de bord/interface utilisateur, ajouter le système de conception à une application SvelteKit existante ou extraire des primitives de marque (barre de menus, logo, capteur/nuage de points, lecteur vidéo, carte, badge, tableau, boîte de dialogue…). La CLI installe la PROPRE configuration d'agent du système de conception — `CLAUDE.md` (ou `AGENTS.md` pour Cursor) plus `ds-manifest.json` à la racine du projet — qui est la source de vérité pour l'utilisation des composants, les polices, le comportement de secours et le style une fois échafaudés ; le seul travail de cette compétence est de vous y amener. Les composants sont actuellement livrés pour Svelte 5 ; un portage React est en cours. Ne PAS utiliser pour le travail de l'API/backend de Newton (voir les compétences `atai-newton-*`).
