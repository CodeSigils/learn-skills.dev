手動でトークンをローリングする代わりに、Archetype AI Design System (公開され、バージョン管理されたパッケージ (`@archetypeai/ds-lib-tokens`、`@archetypeai/ds-ui-svelte-console`、`@archetypeai/ds-ui-svelte-labs`) および `ds` スキャフォールディング CLI (`@archetypeai/ds-cli`)) を使用して、Newton デモのフロントエンドを構築します。コンポーネント、フォント、またはブランド スタイル。ユーザーが新しいダッシュボード/UI をスキャフォールディングする場合、既存の SvelteKit アプリにデザイン システムを追加する場合、またはブランド化されたプリミティブ (メニューバー、ロゴ、センサー/散布図、ビデオ プレーヤー、カード、バッジ、テーブル、ダイアログなど) を取り込む場合は、このスキルを使用します。 CLI は、デザイン システムの独自のエージェント構成 (`CLAUDE.md` (カーソルの場合は `AGENTS.md`) と `ds-manifest.json`) をプロジェクト ルートにインストールします。これは、コンポーネントの使用法、フォント、フォールバック動作、およびスキャフォールド後のスタイルに関する信頼できる情報源です。このスキルの唯一の役割は、あなたをそこに到達させることです。コンポーネントは現在 Svelte 5 用に出荷されています。 React ポートが進行中です。 Newton API / バックエンド作業には使用しないでください (`atai-newton-*` スキルを参照してください)。
