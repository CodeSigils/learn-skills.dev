Создайте интерфейс для демонстрации Newton с помощью Archetype AI Design System — опубликованных пакетов с версионированием («@archetypeai/ds-lib-tokens», «@archetypeai/ds-ui-svelte-console», «@archetypeai/ds-ui-svelte-labs») и CLI-интерфейса ds («@archetypeai/ds-cli») — вместо жетоны, компоненты, шрифты или фирменный стиль, создаваемые вручную. Используйте этот навык, когда пользователь хочет создать новую панель управления/пользовательский интерфейс, добавить систему дизайна в существующее приложение SvelteKit или использовать фирменные примитивы (панель меню, логотип, сенсорные/диаграммы рассеяния, видеоплеер, карточка, значок, таблица, диалог…). CLI устанавливает СОБСТВЕННУЮ конфигурацию агента системы дизайна — CLAUDE.md (или AGENTS.md для Cursor) плюс ds-manifest.json в корне проекта — которая является источником достоверных сведений об использовании компонентов, шрифтах, резервном поведении и стилях после создания шаблона; Единственная задача этого навыка — привести вас туда. В настоящее время поставляются компоненты для Svelte 5; Порт React находится в разработке. НЕ используйте Newton API/бэкэнд для работы (см. навыки `atai-newton-*`).
