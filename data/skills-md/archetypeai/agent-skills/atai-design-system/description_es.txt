Cree la interfaz para una demostración de Newton con Archetype AI Design System: los paquetes versionados publicados (`@archetypeai/ds-lib-tokens`, `@archetypeai/ds-ui-svelte-console`, `@archetypeai/ds-ui-svelte-labs`) y la CLI de andamio `ds` (`@archetypeai/ds-cli`), en lugar de hacerlo manualmente. tokens, componentes, fuentes o estilo de marca. Utilice esta habilidad cuando el usuario quiera crear un nuevo panel/UI, agregar el sistema de diseño a una aplicación SvelteKit existente o incorporar primitivas de marca (barra de menú, logotipo, sensores/gráficos de dispersión, reproductor de video, tarjeta, insignia, tabla, diálogo…). La CLI instala la PROPIA configuración del agente del sistema de diseño: `CLAUDE.md` (o `AGENTS.md` para Cursor) más `ds-manifest.json` en la raíz del proyecto, que es la fuente de verdad para el uso de componentes, fuentes, comportamiento alternativo y estilo una vez estructurados; El único trabajo de esta habilidad es llevarte allí. Actualmente se envían componentes para Svelte 5; Hay un puerto React en progreso. NO lo use para trabajos backend/API de Newton (consulte las habilidades `atai-newton-*`).
