Tätigt ausgehende Telefonanrufe, sendet ausgehende SMS-Texte und reserviert im Namen des Benutzers mithilfe der Poku-API dedizierte Telefonnummern. Verwenden Sie diese Option, wenn der Benutzer ein Restaurant, einen Kontakt, ein Unternehmen, eine Arztpraxis oder eine beliebige Telefonnummer anrufen oder eine SMS senden möchte. Verwenden Sie diese Option auch, wenn der Benutzer eine dedizierte Telefonnummer für seinen Agenten reservieren möchte.
