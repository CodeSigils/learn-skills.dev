Realiza llamadas telefónicas salientes, envía mensajes de texto SMS salientes y reserva números de teléfono dedicados en nombre del usuario utilizando la API de Poku. Úselo cuando el usuario quiera llamar o enviar un mensaje de texto a un restaurante, un contacto, un negocio, un consultorio médico o cualquier número de teléfono. Utilícelo también cuando el usuario desee reservar un número de teléfono exclusivo para su agente.
