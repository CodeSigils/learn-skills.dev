Выполняет исходящие телефонные звонки, отправляет исходящие SMS-сообщения и резервирует выделенные телефонные номера от имени пользователя с помощью API Poku. Используйте, когда пользователь хочет позвонить или отправить сообщение в ресторан, контакт, компанию, кабинет врача или на любой номер телефона. Также используйте, когда пользователь хочет зарезервировать выделенный номер телефона для своего агента.
