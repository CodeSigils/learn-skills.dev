Реализуйте задачу N способами параллельно и выберите лучший — по РЕЗУЛЬТАТУ, а не по тональности. Создает N субагентов в изолированных рабочих деревьях git, каждый под ОТЛИЧНЫМ углом, пропускает каждого кандидата через оракула для каждого кандидата (сборка + проверка типов + тест + проверка), оценивает выживших на основе ФАКТИЧЕСКОГО различия (никогда не самоотчет), запускает проверку полноты победителя, применяет его к основному и повторно проверяет зеленый цвет оракула перед объявлением победителя. Используйте, когда вас просят «лучшее из n», «попробовать несколько подходов», «параллельные реализации», «/work-tournament» или «/bon».
