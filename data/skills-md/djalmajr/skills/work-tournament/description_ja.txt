タスクを N 通りに並行して実装し、ピッチではなく結果に基づいて最善のものを選択します。分離された git ワークツリーに N 個のサブエージェントをそれぞれ DISTINCT の角度から生成し、候補ごとのオラクル (ビルド + タイプチェック + テスト + lint) を通じてすべての候補をゲートし、実際の差分 (自己報告ではない) から生存者を等級付けし、勝者に対して完全性スイープを実行し、それをメインに適用し、勝者を宣言する前にオラクル グリーンを再検証します。 「n のベスト」、「複数のアプローチを試す」、「並列実装」、「/work-tournament」、または「/bon」を求められた場合に使用します。
