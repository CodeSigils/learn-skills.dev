Capture una página web local renderizada o la pantalla de una aplicación en el portapapeles para pegarla en Figma utilizando el flujo oficial de html-to-design capture.js. Úselo cuando el usuario invoca /figma-capture, solicita copiar la página actual del navegador a Figma, solicita un botón de captura de Figma solo para desarrolladores o pregunta si se necesita figma_key/captureId para la captura de Figma HTML.
