Capturez une page Web locale rendue ou un écran d'application dans le presse-papiers pour la coller dans Figma à l'aide du flux officiel capture.js html-to-design. À utiliser lorsque l'utilisateur invoque /figma-capture, demande de copier la page actuelle du navigateur sur Figma, demande un bouton de capture Figma réservé aux développeurs ou demande si figma_key/captureId est nécessaire pour la capture HTML Figma.
