Rappeler manuellement des connaissances durables à partir d'une instance ai-memory via le MCP (recherche sémantique/hybride, pages récentes, rattrapage de prose). À utiliser lorsque l'utilisateur demande une recherche dans la mémoire, « avons-nous fait/décidé X », « quel est l'état de Y » ou « rattrapez-moi » — et vous souhaitez un rappel explicite plutôt que d'attendre le transfert automatique.
