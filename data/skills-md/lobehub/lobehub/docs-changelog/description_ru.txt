Написание руководства для страниц журнала изменений веб-сайта в папке `docs/changelog/*.mdx` (НЕ примечания к выпуску GitHub — они находятся в навыке `version-release`). Используйте при создании или редактировании сообщения об обновлении продукта в EN/ZH. Запускается по `docs/changelog/*.mdx`, «сообщению о журнале изменений», «сообщению об обновлении продукта», «добавлению журнала изменений», «更新日志», «сообщению об изменениях».
