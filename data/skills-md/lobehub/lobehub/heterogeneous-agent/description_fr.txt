Guide d'implémentation et de débogage des intégrations d'agents hétérogènes LobeHub tels que Claude Code, Codex et les futurs agents CLI externes. À utiliser lorsque vous travaillez sur le mappage d'événements d'adaptateur, le transport Electron IPC, la persistance du moteur de rendu, le chaînage d'appels d'outils, les threads de sous-agents, la gestion de reprise/session ou les régressions telles que les messages multi-outils mixtes, les limites d'étapes brisées, le chargement d'outils bloqué et les messages d'outils orphelins.
