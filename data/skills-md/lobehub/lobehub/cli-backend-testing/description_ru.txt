Рабочий процесс интеграционного тестирования CLI + Backend. Используйте при проверке изменений внутреннего API (маршрутизаторы TRPC, службы, модели) через интерфейс командной строки LobeHub на локальном сервере разработки. Запускается при «тесте cli», «тесте с помощью cli», «проверке с помощью cli», «локальном тесте cli», «бэкэнд-тесте с помощью cli» или при необходимости сквозной проверки изменений на стороне сервера.
