Workflow de test d’intégration CLI + Backend. À utiliser lors de la vérification des modifications de l'API backend (routeurs TRPC, services, modèles) via la CLI LobeHub par rapport à un serveur de développement local. Déclencheurs sur « test cli », « tester avec cli », « vérifier avec cli », « test cli local », « test backend avec cli », ou lorsqu'il est nécessaire de valider les modifications côté serveur de bout en bout.
