在 `packages/builtin-tool-<name>/` 下建立一個新的內建工具包。在新增新的代理程式可呼叫工具集、設計其 API 表面（manifest / ApiName / Params / State）、實作 Executor + ExecutionRuntime、建構 Inspector / Render / Placeholder / Streaming / Intervention / Portal UI或將工具連接到中央註冊表時使用（`packages/builtin-tools/src/{index,identifiers,inspectors,renders,placeholders,streamings,interventions,portals}.ts`和`src/store/tool/slices/builtin/executors/index.ts`）。在「新內建工具」、「新增工具」、「工具檢查器」、「工具渲染」、「工具佔位符」、「工具流」、「工具介入」、「BuiltinToolManifest」、「BaseExecutor」、「ExecutionRuntime」上觸發。
