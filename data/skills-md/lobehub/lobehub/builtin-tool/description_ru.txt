Создайте новый пакет встроенных инструментов в `packages/builtin-tool-<name>/`. Используйте при добавлении нового набора инструментов, вызываемого агентом, проектировании его поверхности API (манифест/ApiName/Params/State), реализации Executor + ExecutionRuntime, создании пользовательского интерфейса Inspector/Render/Placeholder/Streaming/Intervention/Portal или подключении инструмента к центральным реестрам. (`packages/builtin-tools/src/{index,identifiers,inspectors,renders,placeholders,streamings,interventions,portals}.ts` и `src/store/tool/slices/builtin/executors/index.ts`). Запускается по «новому встроенному инструменту», «добавлению инструмента», «инспектору инструментов», «рендерингу инструмента», «заполнителю инструмента», «потоковой передаче инструмента», «вмешательству инструмента», «BuiltinToolManifest», «BaseExecutor», «ExecutionRuntime».
