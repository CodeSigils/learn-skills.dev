خطافات دورة حياة وقت تشغيل الوكيل لمراقبة تنفيذ الوكيل واعتراضه. يُستخدم عند إضافة خطافات إلى عمليات الوكيل، أو الاستهزاء باستدعاءات الأدوات، أو تسجيل أحداث الخطوات، أو التعامل مع التدخل البشري، أو استدعاءات الوكيل الفرعي، أو ضغط السياق، أو بناء تكاملات التقييم/التتبع. يتم تشغيلها على "الخطافات"، و"beforeToolCall"، و"afterToolCall"، و"beforeStep"، و"afterStep"، و"onComplete"، و"onError"، و"tool mock"، و"agent lifecycle"، و"human التدخل"، و"callAgent"، و"compact".
