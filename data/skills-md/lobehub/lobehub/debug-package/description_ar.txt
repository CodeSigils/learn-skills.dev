دليل لحزمة `debug` npm ومساحات أسماء سجل LobeHub (lobe-server:*، lobe-desktop:*، lobe-client:*، lobe-*-router:*). يُستخدم عند إضافة مسجل `debug(...)`، أو اختيار مساحة اسم لرمز الخادم/سطح المكتب/العميل/جهاز التوجيه الجديد، أو استكشاف الأخطاء وإصلاحها بسبب عدم ظهور سجلات DEBUG=lobe-*، أو عندما يطلب المستخدم "إضافة تسجيل"، أو "إضافة مسجل"، أو "أداة هذا"، أو "تتبع هذه المكالمة"، أو "لماذا لا تتم طباعة السجل الخاص بي"، أو يذكر "تصحيح الأخطاء"(`، `DEBUG=` أو `localStorage.debug` أو محددات تنسيق السجل مثل %O / %o / %s / %d في قاعدة تعليمات LobeHub.
