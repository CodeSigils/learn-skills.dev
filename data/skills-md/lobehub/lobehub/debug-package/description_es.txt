Guía para el paquete npm `debug` y los espacios de nombres de registro de LobeHub (lobe-server:*, lobe-desktop:*, lobe-client:*, lobe-*-router:*). Úselo siempre que agregue un registrador `debug(...)`, elija un espacio de nombres para un nuevo código de servidor/escritorio/cliente/enrutador, solucione problemas por qué los registros DEBUG=lobe-* no aparecen, o cuando el usuario solicite "agregar registro", "agregar un registrador", "instrumentar esto", "rastrear esta llamada", "por qué no se imprime mi registro" o mencione "debug(`, `DEBUG=`, `localStorage.debug`, o especificadores de formato de registro como %O / %o / %s / %d en una base de código LobeHub.
