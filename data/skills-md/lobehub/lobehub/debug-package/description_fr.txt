Guide pour le package npm `debug` et les espaces de noms de journaux LobeHub (lobe-server:*, lobe-desktop:*, lobe-client:*, lobe-*-router:*). À utiliser chaque fois que vous ajoutez un enregistreur `debug(...)`, choisissez un espace de noms pour le nouveau code serveur/ordinateur de bureau/client/routeur, dépannez pourquoi les journaux DEBUG=lobe-* ne s'affichent pas, ou lorsque l'utilisateur demande d'ajouter une journalisation, d'ajouter un enregistreur, d'instrumenter ceci, de tracer cet appel, de pourquoi mon journal ne s'imprime pas ou de mentionner debug(`, `DEBUG=`, `localStorage.debug` ou des spécificateurs de format de journal comme %O / %o / %s / %d dans une base de code LobeHub.
