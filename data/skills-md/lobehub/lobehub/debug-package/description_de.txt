Leitfaden für das „debug“-npm-Paket und die LobeHub-Protokoll-Namespaces (lobe-server:*, lobe-desktop:*, lobe-client:*, lobe-*-router:*). Wird immer dann verwendet, wenn ein „debug(...)“-Logger hinzugefügt wird, ein Namespace für neuen Server-/Desktop-/Client-/Router-Code ausgewählt wird, wenn Fehler behoben werden, warum DEBUG=lobe-*-Protokolle nicht angezeigt werden, oder wenn der Benutzer nach „Protokollierung hinzufügen“, „Logger hinzufügen“, „dies instrumentieren“, „diesen Aufruf verfolgen“, „Warum wird mein Protokoll nicht gedruckt“ fragt oder „debug(“ erwähnt, „DEBUG=“, „localStorage.debug“ oder Protokollformatspezifizierer wie %O / %o / %s / %d in einer LobeHub-Codebasis.
