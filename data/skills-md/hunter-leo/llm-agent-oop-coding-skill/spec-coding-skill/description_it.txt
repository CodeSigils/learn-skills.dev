Guida gli agenti LLM attraverso attività di codifica su larga scala utilizzando una metodologia fase per fase basata sulle specifiche che copre la definizione dei requisiti, la pianificazione, la progettazione di algoritmi e l'implementazione con principi OOP e standard di codifica specifici della lingua. Da utilizzare quando si avvia un nuovo progetto software, si implementa una funzionalità complessa, si esegue il refactoring del codice esistente o quando è necessario un approccio disciplinato passo dopo passo a qualsiasi attività di codifica non banale.
