Guide les agents LLM dans des tâches de codage à grande échelle en utilisant une méthodologie phase par phase basée sur les spécifications couvrant la définition des exigences, la planification, la conception d'algorithmes et la mise en œuvre avec les principes de POO et les normes de codage spécifiques au langage. À utiliser lors du démarrage d'un nouveau projet logiciel, de l'implémentation d'une fonctionnalité complexe, de la refactorisation du code existant ou lorsque vous avez besoin d'une approche disciplinée étape par étape pour toute tâche de codage non triviale.
