Помогает агентам LLM решать крупномасштабные задачи по кодированию, используя основанную на спецификациях поэтапную методологию, охватывающую определение требований, планирование, разработку алгоритмов и реализацию с принципами ООП и стандартами кодирования для конкретного языка. Используйте при запуске нового программного проекта, реализации сложной функции, рефакторинге существующего кода или когда вам нужен дисциплинированный пошаговый подход к любой нетривиальной задаче кодирования.
