يرشد وكلاء LLM من خلال مهام الترميز واسعة النطاق باستخدام منهجية تعتمد على المواصفات ومرحلة تلو الأخرى تغطي تعريف المتطلبات والتخطيط وتصميم الخوارزمية والتنفيذ باستخدام مبادئ OOP ومعايير الترميز الخاصة باللغة. يُستخدم عند بدء مشروع برمجي جديد، أو تنفيذ ميزة معقدة، أو إعادة هيكلة التعليمات البرمجية الموجودة، أو عندما تحتاج إلى منهج منضبط خطوة بخطوة لأي مهمة ترميز غير تافهة.
