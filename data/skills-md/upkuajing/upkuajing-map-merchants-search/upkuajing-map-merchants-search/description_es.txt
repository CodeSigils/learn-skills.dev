Habilidad oficial para upkuajing (跨境魔方). Buscar comerciantes en el mapa (地图获客). Encuentre comerciantes por región o ubicación cercana, obtenga detalles del comerciante, incluido el nombre, la dirección, el teléfono, la industria y más. Incluye API de datos geográficos (listas de países, provincias y ciudades) para admitir búsquedas basadas en la ubicación.
