Официальный навык упкуацзин (跨境魔方). Поиск торговцев на карте (地图获客). Найдите продавцов по региону или ближайшему местоположению, получите подробную информацию о продавце, включая имя, адрес, телефон, сферу деятельности и многое другое. Включает API географических данных (списки стран, провинций, городов) для поддержки поиска на основе местоположения.
