Используйте этот навык при переносе проекта Phaser 3 в Phaser 4 или когда пользователь спрашивает о критических изменениях, различиях API или о том, как обновить код v3. Охватывает изменения средства рендеринга (конвейеры для рендеринга узлов), эффекты/маски для фильтров, систему оттенков, матрицу камеры, координаты текстур, DynamicTexture, шейдеры, освещение, удаленные игровые объекты и полный контрольный список миграции. Срабатывает при: миграции, обновлении, с версии 3 на версию 4, критических изменениях, переходе с версии 3 на 4, руководстве по миграции, обновлении с версии 3.
