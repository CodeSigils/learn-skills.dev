Utilisez cette compétence lors de la migration d'un projet Phaser 3 vers Phaser 4, ou lorsqu'un utilisateur pose des questions sur les modifications importantes, les différences d'API ou comment mettre à jour son code v3. Couvre les modifications du moteur de rendu (pipelines vers les nœuds de rendu), les effets/masques des filtres, le système de teinte, la matrice de la caméra, les coordonnées de texture, DynamicTexture, les shaders, l'éclairage, les objets de jeu supprimés et une liste de contrôle de migration complète. Déclencheurs sur : migration, mise à niveau, v3 vers v4, modifications avec rupture, Phaser 3 vers 4, guide de migration, mise à jour depuis la v3.
