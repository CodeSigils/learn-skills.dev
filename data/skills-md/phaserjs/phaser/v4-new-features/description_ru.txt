Используйте этот навык при изучении новых функций, игровых объектов, компонентов и возможностей рендеринга, добавленных в Phaser 4. Охватывает фильтры, RenderNodes, CaptureFrame, Gradient, Noise, SpriteGPULayer, TilemapGPULayer, компонент освещения, RenderSteps и новые режимы оттенка. Запускается при: новом в v4, функциях Phaser 4, RenderNode, SpriteGPULayer, CaptureFrame, игровом объекте Gradient, игровом объекте Noise, новых режимах оттенка. Для переноса кода версии 3 в версию 4 вместо этого см. навык миграции с версии 3 на версию 4.
