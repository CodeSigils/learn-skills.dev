Erstellen, aktualisieren und durchsuchen Sie vollständige Oracle NetSuite-Hilfeindizes aus dem Inhaltsverzeichnis der Live-Dokumentation von Oracle. Verwenden Sie diese Option, wenn ein KI-Agent eine vollständige NetSuite-Dokumenten-Linkliste, ein hierarchisches Inhaltsverzeichnis, einen alphabetischen Index oder eine schnelle Suche nach Oracle-Hilfe-URLs nach Titel benötigt. Verwenden Sie dies, anstatt undurchsichtige Dokument-IDs allein aus URL-Mustern abzuleiten.
