Атомное извлечение обучающего семинара — преобразуйте аргументы из уровня деконструкции в независимые атомы знаний с возможностью поиска (по одному атому на аргумент), сохраняйте их в базе данных проекта и при необходимости импортируйте их в глобальную базу данных атомов лекций. Триггерные слова: извлечь атом / атом знания / атомное извлечение / уточнить атом. Обычно маршрутизируется с помощью /lulu-learn после деконструкции или композиции. Наследует процесс «Трансформация обучения записи лекций — навыки» версии 2026–06. Шаг 4.
