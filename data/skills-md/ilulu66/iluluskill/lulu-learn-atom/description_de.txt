Atomextraktion im Lernworkshop: Verfeinern Sie die Argumente aus der Dekonstruktionsschicht in unabhängige, durchsuchbare Wissensatome (ein Atom pro Argument), speichern Sie sie in einer Projektdatenbank und importieren Sie sie optional in die globale Vorlesungsatomdatenbank. Auslösewörter: Atom extrahieren / Wissensatom / Atomextraktion / Atom verfeinern. Wird normalerweise von /lulu-learn nach der Dekonstruktion oder Komposition weitergeleitet. Übernimmt den Schritt 4-Prozess der Version 2026-06 „Vorlesungsaufzeichnung, Lerntransformation – Fertigkeit“.
