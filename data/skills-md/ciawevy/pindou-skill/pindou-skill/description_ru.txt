Создание шаблонов бисера Perler в один клик. Пользователи предоставляют фотографию, которую они хотят превратить в узор из бисера Perler / хотят создать «Perler»/«пиксельную графику»/«сетку»/«мозаику из бисера». Процесс: обсуждение стиля, создание пиксельного изображения, извлечение цветовых блоков, создание печатных листов с сеткой + цветовые коды + список покупок.
