Generierung von Perler-Perlen-Vorlagen mit einem Klick. Benutzer können ein Foto bereitstellen, das sie in eine Perler-Perlen-Vorlage umwandeln möchten – oder „Perler“, „Pixel Art“, „Grid Art“ oder „Bohnenmosaik“ erstellen. Ablauf: Besprechen Sie den Stil, erstellen Sie ein Pixelbild, extrahieren Sie Farbblöcke und erstellen Sie eine druckbare Rastervorlage mit Farbcodes und einer Einkaufsliste.
