KWCode (天工开物) — агент кодирования CLI, оптимизированный для локальных моделей с открытым исходным кодом (8B-30B), с детерминированными экспертными конвейерами, расположением кода BM25+AST, отладкой во время выполнения и самоусовершенствующимся маховиком — все работает полностью в автономном режиме.
