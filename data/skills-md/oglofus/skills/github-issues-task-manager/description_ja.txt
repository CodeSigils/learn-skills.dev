リポジトリの GitHub Issues タスク マネージャー ループを実行します。重複検索、ネイティブ Issue フィールド、サブ課題と依存関係、テスト、ブランチ、コミット、プル リクエスト、CI/チェックの検出と障害の修復、パイプライン ステータスのコメント、および必須の作成後の PR セルフレビューです。問題の作業を計画または実装する場合、CI パイプラインを使用してブランチまたは PR で作業する場合、失敗したチェックを診断または修正する場合、パイプラインのステータスを伝達する場合、完了した作業をコミットする場合、プル リクエストを開く場合、または PR をセルフレビューして修正する場合に使用します。
