تشغيل حلقة مدير مهام مشكلات الريبو GitHub - البحث المكرر، وحقول المشكلات الأصلية، والمشكلات الفرعية والتبعيات، والاختبارات، والفروع، والالتزامات، وطلبات السحب، واكتشاف CI/التحقق ومعالجة الفشل، وتعليقات حالة خط الأنابيب، والمراجعة الذاتية الإلزامية للعلاقات العامة بعد الإنشاء. يُستخدم عند تخطيط أعمال المشكلات أو تنفيذها، أو العمل على فرع أو علاقات عامة باستخدام خطوط أنابيب CI، أو تشخيص عمليات التحقق الفاشلة أو إصلاحها، أو توصيل حالة خطوط الأنابيب، أو الالتزام بالعمل النهائي، أو فتح طلب سحب، أو المراجعة الذاتية ومعالجة العلاقات العامة.
