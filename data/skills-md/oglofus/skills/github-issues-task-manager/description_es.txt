Ejecuta el bucle del administrador de tareas de GitHub Issues del repositorio: búsqueda duplicada, campos de problemas nativos, subproblemas y dependencias, pruebas, ramas, confirmaciones, solicitudes de extracción, descubrimiento de CI/verificación y corrección de fallas, comentarios de estado de canalización y autoevaluación obligatoria de relaciones públicas posteriores a la creación. Úselo cuando planifique o implemente trabajo de problemas, trabaje en una sucursal o PR con canalizaciones de CI, diagnostique o corrija comprobaciones fallidas, comunique el estado de la canalización, confirme el trabajo terminado, abra una solicitud de extracción o realice una autoevaluación y remediación de un PR.
