Führt die Repo GitHub Issues Task-Manager-Schleife aus – Duplikatsuche, native Issue-Felder, Unter-Issues und Abhängigkeiten, Tests, Branches, Commits, Pull-Requests, CI/Check-Erkennung und Fehlerbehebung, Pipeline-Statuskommentare und obligatorische PR-Selbstüberprüfung nach der Erstellung. Verwenden Sie diese Funktion, wenn Sie Problemarbeit planen oder implementieren, an einem Zweig oder PR mit CI-Pipelines arbeiten, fehlgeschlagene Prüfungen diagnostizieren oder beheben, den Pipeline-Status kommunizieren, abgeschlossene Arbeiten festschreiben, eine Pull-Anfrage öffnen oder einen PR selbst überprüfen und beheben.
