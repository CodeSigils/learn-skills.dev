Запускает цикл диспетчера задач GitHub Issues — поиск дубликатов, собственные поля проблем, подзадачи и зависимости, тесты, ветки, фиксации, запросы на включение, обнаружение CI/проверок и устранение сбоев, комментарии к состоянию конвейера и обязательную самопроверку PR после создания. Используйте при планировании или реализации работы над проблемой, работе над филиалом или запросом на включение с помощью конвейеров CI, диагностике или исправлении неудачных проверок, сообщении о состоянии конвейера, фиксации завершенной работы, открытии запроса на включение или самопроверке и исправлении запроса на внесение изменений.
