Esegue il ciclo del task manager del repository GitHub Issues: ricerca duplicata, campi dei problemi nativi, problemi secondari e dipendenze, test, rami, commit, richieste pull, rilevamento CI/check e risoluzione degli errori, commenti sullo stato della pipeline e auto-revisione PR post-creazione obbligatoria. Da utilizzare durante la pianificazione o l'implementazione del lavoro sui problemi, il lavoro su un ramo o una PR con pipeline CI, la diagnosi o la correzione di controlli non riusciti, la comunicazione dello stato della pipeline, il commit del lavoro finito, l'apertura di una richiesta pull o l'autorevisione e la correzione di una PR.
