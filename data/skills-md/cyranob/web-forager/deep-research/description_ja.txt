Web を検索し、ページ全体のコンテンツを取得して、包括的で十分な情報源に基づいた調査レポートを作成するディープ Web リサーチ スキル。ユーザーがトピックの調査、質問の調査、詳細な調査、製品やサービスの比較、オンラインでの検索、製品/企業/テクノロジーに関する情報の検索、または Web からの最新情報の収集を要求するたびに、このスキルを使用します。現在の Web 情報が価値がある場合は、「X について調べてください」、「X を調べてください」、「X について何を知っていますか (現在/最近)」、「X について教えてください」、「X を調べてください」、「X を理解するのを手伝ってください」、「X について人々は何と言っていますか」、「X と Y のどちらかを選択しています」、または「X について Web を検索してください」などのフレーズをトリガーします。また、ユーザーが最新のニュース、価格設定、レビュー、またはトレーニング後に変更された可能性のある実際の導入データを必要とするときにもトリガーされます。ユーザーが明示的に Web 検索を要求しない限り、ライブ Web ソースを必要とせずにクロードがトレーニング データから回答できる純粋に概念的な質問をトリガーしないでください。
