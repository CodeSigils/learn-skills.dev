Habilidad de investigación web profunda que busca en la web y obtiene contenido de página completa para producir informes de investigación completos y bien fundamentados. Utilice esta habilidad siempre que el usuario solicite investigar un tema, investigar una pregunta, profundizar, comparar productos o servicios, buscar algo en línea, encontrar información sobre un producto/empresa/tecnología o recopilar información actual de la web. Active frases como "¿puedes averiguar sobre X", "buscar X", "qué sabes sobre X (actual/reciente)", "cuéntame sobre X", "investiga X por mí", "ayúdame a entender X", "qué dice la gente sobre X", "estoy eligiendo entre X e Y" o "busca X en la web" cuando la información web actual sea valiosa. También se activa cuando el usuario necesita noticias recientes, precios, reseñas o datos de adopción del mundo real que pueden haber cambiado desde la capacitación. No active preguntas puramente conceptuales que Claude pueda responder a partir de datos de entrenamiento sin necesidad de fuentes web activas, a menos que el usuario solicite explícitamente buscar en la web.
