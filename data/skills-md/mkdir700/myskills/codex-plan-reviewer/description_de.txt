Modellübergreifende kontradiktorische Überprüfungsschleife für Abschriftenpläne. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Markdown-Plandatei mit Codex (OpenAI) überprüfen, validieren oder einem Stresstest unterziehen möchte. Wird bei Ausdrücken wie „diesen Plan mit Codex überprüfen“, „den Plan von Codex überprüfen lassen“, „kontradiktorische Überprüfung“, „modellübergreifende Überprüfung“, „Codex-Prüfung“, „Plan validieren“ ausgelöst oder wenn der Benutzer einen Markdown-Plan hat und eine zweite Meinung von einem anderen KI-Modell möchte. Wird auch ausgelöst, wenn der Benutzer „Plan-Überprüfungsschleife“, „Codex-Überprüfungsschleife“ sagt oder darauf verweist, dass Codex einen Plan vor der Ausführung kritisiert.
