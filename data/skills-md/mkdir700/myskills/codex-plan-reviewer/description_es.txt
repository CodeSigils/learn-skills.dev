Bucle de revisión contradictoria entre modelos para planes de rebajas. Utilice esta habilidad siempre que el usuario solicite revisar, validar o realizar una prueba de esfuerzo de un archivo de plan de rebajas utilizando Codex (OpenAI). Se activan frases como "revisar este plan con el códice", "dejar que el códice revise el plan", "revisión contradictoria", "revisión de modelos cruzados", "auditoría del códice", "validar el plan" o cuando el usuario tiene un plan de rebajas y quiere una segunda opinión de un modelo de IA diferente. También se activa cuando el usuario dice "bucle de revisión del plan", "bucle de revisión del códice" o hace referencia a que el Codex critica un plan antes de su ejecución.
