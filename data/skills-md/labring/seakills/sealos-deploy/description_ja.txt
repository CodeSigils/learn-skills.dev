1 つのコマンドで GitHub プロジェクトを Sealos Cloud にデプロイします。準備状況の評価、Dockerfile の生成、イメージの構築、Sealos テンプレートの作成、デプロイが完全に自動化されています。ユーザーが「sealos にデプロイ」、「このプロジェクトをデプロイ」、「クラウドにデプロイ」、「このリポジトリをデプロイ」と言う場合、Sealos のデプロイについて言及する場合、GitHub URL またはローカル プロジェクトをクラウド プラットフォームにデプロイしたい場合、またはワンクリック デプロイについて尋ねる場合に使用します。 「/sealos-deploy」でもトリガーされます。
