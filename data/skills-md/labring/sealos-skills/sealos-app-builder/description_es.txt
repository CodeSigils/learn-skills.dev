Cree, adapte y documente aplicaciones que se ejecutan dentro de Sealos Desktop utilizando el SDK de la aplicación Sealos. Úselo al crear una nueva aplicación Sealos, integrar una aplicación web existente en Sealos Desktop, conectar datos de sesión de Sealos a funciones comerciales, preparar depuración local basada en iframe o producir tutoriales e implementaciones iniciales de aplicaciones Sealos para principiantes. También se activa en "/sealos-app-builder".
