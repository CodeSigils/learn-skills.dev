Provisionnez, connectez et exploitez le stockage d'objets Sealos via les commandes sealos-cli s3 ajoutées dans zjy365/sealos-cli#28. À utiliser lorsque l'utilisateur a besoin d'un stockage compatible S3 pour les téléchargements, les actifs, les sauvegardes, les URL présignées, la gestion des politiques de compartiment, les informations d'identification d'accès, les vérifications de quotas ou lorsqu'il souhaite remplacer les services locaux compatibles MinIO/S3 par le stockage d'objets Sealos dans le développement local, la Devbox ou la configuration de l'application.
