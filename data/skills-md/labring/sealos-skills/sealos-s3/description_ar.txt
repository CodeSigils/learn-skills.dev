توفير تخزين كائنات Sealos وتوصيلها وتشغيلها من خلال أوامر sealos-cli s3 المضافة في zjy365/sealos-cli#28. يُستخدم عندما يحتاج المستخدم إلى تخزين متوافق مع S3 للتحميلات أو الأصول أو النسخ الاحتياطية أو عناوين URL المحددة مسبقًا أو إدارة سياسة الحاوية أو بيانات اعتماد الوصول أو فحوصات الحصص أو يريد استبدال الخدمات المحلية المتوافقة مع MinIO/S3 بتخزين كائنات Sealos في التطوير المحلي أو Devbox أو إعداد التطبيق.
