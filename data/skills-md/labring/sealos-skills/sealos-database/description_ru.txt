Предоставляйте, подключайте и управляйте базами данных Sealos Cloud через sealos-cli для локальной разработки, разработки Devbox и настройки приложений. Используйте, когда пользователю нужна облачная база данных для проекта, он запрашивает создание или подключение PostgreSQL/MySQL/MongoDB/Redis или другой базы данных Sealos, хочет, чтобы DATABASE_URL или аналогичные переменные env были подключены к среде разработки, ему нужны сведения о подключении к базе данных, резервные копии, журналы, публичный доступ или он хочет заменить локальные базы данных Docker Compose управляемой базой данных Sealos.
