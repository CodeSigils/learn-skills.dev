Aprovisione, conecte y opere bases de datos de Sealos Cloud a través de sealos-cli para desarrollo local, desarrollo de Devbox y configuración de aplicaciones. Úselo cuando el usuario necesita una base de datos en la nube para un proyecto, solicita crear o conectar PostgreSQL/MySQL/MongoDB/Redis u otra base de datos de Sealos, quiere DATABASE_URL o variables de entorno similares conectadas a un entorno de desarrollo, necesita detalles de conexión de la base de datos, copias de seguridad, registros, acceso público o quiere reemplazar las bases de datos locales de Docker Compose con una base de datos de Sealos administrada.
