Fornisci, connetti e gestisci i database Sealos Cloud tramite sealos-cli per lo sviluppo locale, lo sviluppo Devbox e la configurazione dell'app. Da utilizzare quando l'utente ha bisogno di un database cloud per un progetto, chiede di creare o connettere PostgreSQL/MySQL/MongoDB/Redis o un altro database Sealos, vuole DATABASE_URL o variabili di ambiente simili collegate in un ambiente di sviluppo, ha bisogno di dettagli di connessione al database, backup, log, accesso pubblico o desidera sostituire i database Docker Compose locali con un database Sealos gestito.
