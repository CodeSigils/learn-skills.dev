Provisionnez, connectez et exploitez les bases de données Sealos Cloud via sealos-cli pour le développement local, le développement Devbox et la configuration d'applications. À utiliser lorsque l'utilisateur a besoin d'une base de données cloud pour un projet, demande de créer ou de connecter PostgreSQL/MySQL/MongoDB/Redis ou une autre base de données Sealos, souhaite que DATABASE_URL ou des variables d'environnement similaires soient connectées à un environnement de développement, a besoin de détails de connexion à la base de données, de sauvegardes, de journaux, d'un accès public ou souhaite remplacer les bases de données Docker Compose locales par une base de données Sealos gérée.
