توفير قواعد بيانات Sealos Cloud وتوصيلها وتشغيلها من خلال sealos-cli للتطوير المحلي وتطوير Devbox وإعداد التطبيق. يُستخدم عندما يحتاج المستخدم إلى قاعدة بيانات سحابية لمشروع ما، أو يطلب إنشاء أو الاتصال بقاعدة بيانات PostgreSQL/MySQL/MongoDB/Redis أو قاعدة بيانات Sealos أخرى، أو يريد DATABASE_URL أو vars env مماثلة موصلة ببيئة تطوير، أو يحتاج إلى تفاصيل اتصال قاعدة البيانات، أو النسخ الاحتياطية، أو السجلات، أو الوصول العام، أو يريد استبدال قواعد بيانات Docker Compose المحلية بقاعدة بيانات Sealos مُدارة.
