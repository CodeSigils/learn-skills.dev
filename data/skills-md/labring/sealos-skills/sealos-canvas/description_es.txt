Ejecute una interfaz de usuario de topología HTML local de solo lectura para un proyecto ya implementado por Sealos Skills y devuelva una URL de host local. Úselo cuando el usuario solicita ver, inspeccionar, visualizar, renderizar, abrir o ejecutar un lienzo local para los recursos de Sealos implementados, menciona ".sealos", el estado de implementación de Sealos, los recursos de Kubernetes, la topología, el gráfico de recursos, la interfaz de usuario del host local o invoca "/sealos-canvas".
