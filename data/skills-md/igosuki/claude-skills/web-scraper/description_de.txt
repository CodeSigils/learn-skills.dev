Diese Fähigkeit sollte verwendet werden, wenn Benutzer Inhalte von Websites extrahieren, Text von Webseiten extrahieren, Links crawlen und ihnen folgen oder Dokumentation von Online-Quellen herunterladen müssen. Es bietet gleichzeitige URL-Verarbeitung, automatische Deduplizierung, Inhaltsfilterung, Domänenbeschränkungen und eine ordnungsgemäße Verzeichnishierarchie basierend auf der URL-Struktur. Verwendung zum Sammeln von Dokumentationen, zum Extrahieren von Inhalten, zur Webarchivierung oder zum Sammeln von Forschungsdaten.
