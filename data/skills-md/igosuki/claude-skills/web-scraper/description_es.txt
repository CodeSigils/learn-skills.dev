Esta habilidad debe usarse cuando los usuarios necesitan extraer contenido de sitios web, extraer texto de páginas web, rastrear y seguir enlaces o descargar documentación de fuentes en línea. Cuenta con procesamiento de URL concurrente, deduplicación automática, filtrado de contenido, restricciones de dominio y jerarquía de directorios adecuada basada en la estructura de la URL. Úselo para recopilación de documentación, extracción de contenido, archivo web o recopilación de datos de investigación.
