Configure, valide y reconfigure el conjunto de habilidades llm-wiki. Utilice siempre esta habilidad cuando el usuario diga /wiki-config, solicite 'configurar mi wiki', 'configurar wiki', 'inicializar la configuración de wiki', mencione 'problemas de estructura de página', 'problemas de esquema', 'plantillas faltantes', 'ayuda de wiki', 'cómo funciona el wiki', o cuando cualquier habilidad de wiki informe una configuración, esquema o plantillas faltantes o no válidos. Úselo también cuando el usuario quiere saber qué habilidades wiki están disponibles, parece confundido acerca de cómo funciona el sistema wiki o pregunta por qué una habilidad no se comporta como se esperaba, incluso si no dice "config". Posee el flujo de configuración interactivo, la gestión de esquemas y la gestión de plantillas para el sistema wiki. Cuando tenga dudas sobre si se está planteando un problema de instalación o configuración, utilice esta habilidad.
