Customer.io CLI : à utiliser pour toute tâche Customer.io, Journeys ou CDP Pipelines. Gère les campagnes, les diffusions, les segments, les personnes, les environnements, les sujets d'abonnement, les secrets de signature, les sources, les destinations, le suivi/identification des événements, les jetons « sa_live_ » et les erreurs « fly.customer.io » / « cdp.customer.io ». Déclenchez même lorsque l'utilisateur ne nomme pas la CLI.
