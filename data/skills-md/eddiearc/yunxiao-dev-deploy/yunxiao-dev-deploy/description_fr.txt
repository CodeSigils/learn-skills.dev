Utilisez Alibaba Cloud Cloud Efficiency OpenAPI pour déployer l'environnement de développement du référentiel actuel. Convient lorsque les utilisateurs demandent à déployer un développement, déclenchent le pipeline de développement, vérifient quelles branches ont été récemment déployées dans l'environnement de développement actuel ou souhaitent ajouter les branches distantes actuellement poussées à l'ensemble de branches de développement existant et déclencher le déploiement.
