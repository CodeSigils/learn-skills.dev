Utilizza Alibaba Cloud Cloud Efficiency OpenAPI per distribuire l'ambiente di sviluppo del repository attuale. Adatto quando gli utenti richiedono di distribuire lo sviluppo, attivare la pipeline di sviluppo, controllare quali rami sono stati distribuiti più recentemente nell'ambiente di sviluppo corrente o desiderano aggiungere il ramo remoto attualmente inviato al set di rami di sviluppo esistente e attivare una distribuzione.
