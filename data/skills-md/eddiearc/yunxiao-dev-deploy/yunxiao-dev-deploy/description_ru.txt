Используйте Alibaba Cloud Cloud Efficiency OpenAPI для развертывания среды разработки текущего репозитория. Это применяется, когда пользователи запрашивают развертывание разработки, запускают конвейер разработки, проверяют, какие ветки были развернуты последними в текущей среде разработки, или хотят добавить текущие удаленные ветки в существующий набор ветвей разработки и запустить развертывание.
