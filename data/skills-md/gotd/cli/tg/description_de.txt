Steuern Sie über die Shell ein Telegram-Konto mit der „tg“-CLI – senden/lesen/suchen Sie Nachrichten, verwalten Sie Chats, Kontakte, Gruppen und Kanäle, laden Sie Medien hoch/herunter und streamen Sie Nachrichten in Echtzeit. Verwenden Sie diese Funktion immer dann, wenn der Benutzer von diesem Computer aus eine Aktion auf Telegram auffordert (jemandem eine Nachricht senden, Chats überprüfen, eine Datei herunterladen, auf Nachrichten achten).
