Используйте при управлении Genesys Cloud CX через интерфейс командной строки Genesys-cli — разговоры, каналы BYOC, очереди, агенты, пограничные серверы, внешние контакты, история аудита и проверки работоспособности подключения. Охватывает настройку OAuth, поддержку нескольких организаций и все операции API платформы.
