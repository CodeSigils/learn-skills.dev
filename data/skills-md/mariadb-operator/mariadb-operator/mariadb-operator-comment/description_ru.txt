Опубликуйте комментарий (или официальный PR-обзор) к проблеме GitHub или запросу на включение в mariadb-operator/mariadb-operator. Используйте всякий раз, когда пользователь хочет опубликовать что-то на GitHub для этого репозитория — «прокомментировать проблему № 123», «опубликовать это как PR-комментарий», «оставить примечание к № 456», «ответить на PR» — и особенно, когда он хочет, чтобы результаты навыка mariadb-operator-pr-review доставлялись на GitHub, а не просто отображались в чате, например «рассмотрите PR № 1234 и опубликуйте его как комментарий» или «опубликуйте результаты проверки в PR». Всегда уточняет точный текст комментария у пользователя перед публикацией — никогда не публикует сообщения самостоятельно.
