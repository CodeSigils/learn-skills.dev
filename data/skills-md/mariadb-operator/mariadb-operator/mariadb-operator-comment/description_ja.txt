GitHub の問題または mariadb-operator/mariadb-operator のプル リクエストにコメント (または正式な PR レビュー) を投稿します。ユーザーがこのリポジトリについて GitHub に何かを公開したいときは常に使用します (「問題 #123 についてコメントする」、「PR コメントとして投稿する」、「#456 にメモを残す」、「PR に返信する」)。特に mariadb-operator-pr-review スキルの出力をチャットで表示するだけでなく GitHub に配信したい場合に使用します。 「PR #1234 をレビューしてコメントとして投稿する」または「レビュー結果を PR に投稿する」。公開する前に常に正確なコメント テキストをユーザーに確認します。決して自主的に投稿することはありません。
