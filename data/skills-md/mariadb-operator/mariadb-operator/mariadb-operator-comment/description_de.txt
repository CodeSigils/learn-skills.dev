Veröffentlichen Sie einen Kommentar (oder eine formelle PR-Bewertung) zu einem GitHub-Problem oder einer Pull-Anfrage in mariadb-operator/mariadb-operator. Verwenden Sie diese Option immer dann, wenn der Benutzer etwas für dieses Repo auf GitHub veröffentlichen möchte – „Kommentar zu Problem Nr. 123“, „Posten Sie dies als PR-Kommentar“, „Hinterlassen Sie eine Notiz zu Nr. 456“, „Antwort auf die PR“ – und insbesondere, wenn er möchte, dass die Ausgabe des Skills „mariadb-operator-pr-review“ an GitHub übermittelt und nicht nur im Chat angezeigt wird, z. B. „Überprüfen Sie PR #1234 und posten Sie es als Kommentar“ oder „Posten Sie die Überprüfungsergebnisse im PR“. Bestätigt vor der Veröffentlichung immer den genauen Kommentartext mit dem Benutzer – postet niemals selbstständig.
