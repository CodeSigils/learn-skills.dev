انشر تعليقًا (أو مراجعة رسمية للعلاقات العامة) على مشكلة GitHub أو طلب سحب في مشغل mariadb/mariadb-operator. استخدمه عندما يريد المستخدم نشر شيء ما على GitHub لهذا الريبو - "التعليق على الإصدار رقم 123"، "انشر هذا كتعليق علاقات عامة"، "اترك ملاحظة على #456"، "الرد على العلاقات العامة" - وخاصة عندما يريدون تسليم مخرجات مهارة مراجعة العلاقات العامة لمشغل mariadb إلى GitHub بدلاً من عرضها فقط في الدردشة، على سبيل المثال. "راجع PR #1234 وانشره كتعليق" أو "انشر نتائج المراجعة إلى مسؤول العلاقات العامة". يتم التأكد دائمًا من نص التعليق الدقيق مع المستخدم قبل النشر، ولا يتم النشر بشكل مستقل أبدًا.
