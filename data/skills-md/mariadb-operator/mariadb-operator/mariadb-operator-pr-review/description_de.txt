Führen Sie eine strukturierte PR-Überprüfung im Maintainer-Stil für das Mariadb-Operator-Repository durch. Sammelt PR-Kontext, selektiert die Änderung und bewertet Korrektheit, Sicherheit, Fallstricke, Abwärtskompatibilität und Codequalität anhand der in AGENTS.md dokumentierten Projektkonventionen. Verwenden Sie es immer dann, wenn der Benutzer eine PR-Nummer oder URL eines Mariadb-Betreibers erwähnt und ein Urteil darüber wünscht – „Überprüfen Sie diese PR“, „Was halten Sie von #1234“, „Ist die Zusammenführung sicher“, „Bewerten Sie diesen Unterschied“, „Sehen Sie sich diese Änderung an“ – auch wenn sie nicht wörtlich „Überprüfen“ sagen.
