CLI di valutazione LLM per misurare la qualità dell'output in termini di fattualità, formato, tono e regressione. Utilizza questa competenza ogni volta che un utente menziona regtrace, golden set, valutazione LLM, regressione del modello, gate di qualità, pipeline di valutazione CI/CD o chiede come testare/confrontare gli output LLM. Attiva anche attività come: impostare un nuovo progetto regtrace, scrivere casi di test per un prompt, eseguire il debug di una valutazione fallita, fissare una linea di base di regressione, cambiare fornitore di arbitri, integrare regtrace in CI, eseguire valutazioni, comprendere punteggi, formattare output, generare output di test, risolvere problemi di chiavi API, configurare metriche o gestire la cronologia delle esecuzioni.
IMPORTANTE: attiva questa abilità anche quando l'utente esegue `/regtrace`, `/regtrace init` o `/regtrace run` come comando barra in qualsiasi cablaggio dell'agente (OpenCode, Claude Code, Cursor, Zed, Aider, ecc.) o quando chiede a Claude di "scansionare questo progetto per chiamate LLM", "generare golden set per i miei prompt", "impostare la copertura eval per questa codebase" o qualsiasi cosa implichi che vogliono avviare regtrace da un progetto esistente. In caso di dubbi, utilizza questa competenza: copre l'intero flusso di lavoro regtrace dall'installazione alla produzione.
