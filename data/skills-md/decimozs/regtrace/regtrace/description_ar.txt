تقييم LLM CLI لقياس جودة المخرجات عبر الحقائق والتنسيق والنغمة والانحدار. استخدم هذه المهارة عندما يذكر المستخدم regtrace، أو المجموعات الذهبية، أو تقييم LLM، أو نموذج الانحدار، أو بوابات الجودة، أو خطوط أنابيب تقييم CI/CD، أو يسأل عن كيفية اختبار/مقارنة مخرجات LLM. قم أيضًا بتشغيل مهام مثل: إعداد مشروع regtrace جديد، وكتابة حالات اختبار للموجه، وتصحيح أخطاء التقييم الفاشل، وتثبيت خط الأساس للانحدار، وتبديل موفري القضاة، ودمج regtrace في CI، وتشغيل التقييمات، وفهم النتائج، وتنسيق المخرجات، وإنشاء مخرجات الاختبار، واستكشاف أخطاء مفاتيح API وإصلاحها، أو تكوين المقاييس، أو إدارة سجل التشغيل.
هام: قم أيضًا بتشغيل هذه المهارة عندما يقوم المستخدم بتشغيل `/regtrace` أو `/regtrace init` أو `/regtrace run` كأمر شرطة مائلة في أي أداة مساعدة للوكلاء (OpenCode، Claude Code، Cursor، Zed، Aider، وما إلى ذلك)، أو عندما يطلبون من Claude "مسح هذا المشروع بحثًا عن مكالمات LLM"، أو "إنشاء مجموعات ذهبية للمطالبات الخاصة بي"، أو "إعداد تغطية تقييمية لقاعدة التعليمات البرمجية هذه"، أو أي شيء يشير ضمنًا إلى أنهم تريد regtrace bootstrapped من مشروع موجود. عندما تكون في شك، استخدم هذه المهارة - فهي تغطي سير عمل regtrace بالكامل من التثبيت إلى الإنتاج.
