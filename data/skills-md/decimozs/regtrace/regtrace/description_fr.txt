CLI d'évaluation LLM pour mesurer la qualité de sortie à travers la réalité, le format, le ton et la régression. Utilisez cette compétence chaque fois qu'un utilisateur mentionne le regtrace, les golden sets, l'évaluation LLM, la régression de modèle, les portes de qualité, les pipelines d'évaluation CI/CD, ou demande comment tester/comparer les sorties LLM. Déclenchez également des tâches telles que : la configuration d'un nouveau projet de regtrace, l'écriture de cas de test pour une invite, le débogage d'une évaluation défaillante, l'épinglage d'une ligne de base de régression, le changement de fournisseur de juge, l'intégration de regtrace dans CI, l'exécution d'évaluations, la compréhension des scores, le formatage de la sortie, la génération de sorties de test, le dépannage des clés API, la configuration des métriques ou la gestion de l'historique des exécutions.
IMPORTANT : Déclenchez également cette compétence lorsque l'utilisateur exécute `/regtrace`, `/regtrace init` ou `/regtrace run` en tant que commande slash dans n'importe quel harnais d'agent (OpenCode, Claude Code, Cursor, Zed, Aider, etc.), ou lorsqu'il demande à Claude de "analyser ce projet pour les appels LLM", "générer des ensembles dorés pour mes invites", "configurer une couverture d'évaluation pour cette base de code", ou tout ce qui implique qu'il souhaite regtrace démarré à partir d’un projet existant. En cas de doute, utilisez cette compétence : elle couvre l'intégralité du flux de travail de retrace, de l'installation à la production.
