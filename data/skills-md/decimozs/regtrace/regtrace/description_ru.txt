Интерфейс командной строки для оценки LLM для измерения качества выходных данных по фактам, формату, тону и регрессии. Используйте этот навык всякий раз, когда пользователь упоминает регулярную трассировку, золотые наборы, оценку LLM, регрессию модели, элементы качества, конвейеры оценки CI/CD или спрашивает, как тестировать/сравнивать результаты LLM. Также триггер для таких задач, как: настройка нового проекта regtrace, написание тестовых примеров для подсказки, отладка неудачной оценки, закрепление базовой линии регрессии, переключение поставщиков оценок, интеграция regtrace в CI, выполнение оценок, понимание оценок, форматирование выходных данных, генерация результатов тестирования, устранение неполадок ключей API, настройка метрик или управление историей выполнения.
ВАЖНО: Также активируйте этот навык, когда пользователь запускает `/regtrace`, `/regtrace init` или `/regtrace run` как команду с косой чертой в любом средстве агента (OpenCode, Claude Code, Cursor, Zed, Aider и т. д.) или когда он просит Клода "сканировать этот проект на предмет вызовов LLM", "создать золотые наборы для моих подсказок", "настроить оценочное покрытие для этой кодовой базы" или что-то еще, что им нужно. regtrace, загруженный из существующего проекта. Если у вас есть сомнения, воспользуйтесь этим навыком — он охватывает весь рабочий процесс регистрации от установки до производства.
