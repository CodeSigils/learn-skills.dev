CLI de evaluación de LLM para medir la calidad de los resultados en Factualidad, Formato, Tono y Regresión. Utilice esta habilidad siempre que un usuario mencione regtrace, conjuntos dorados, evaluación de LLM, regresión de modelos, puertas de calidad, canales de evaluación de CI/CD o pregunte cómo probar/comparar resultados de LLM. También activa tareas como: configurar un nuevo proyecto de seguimiento, escribir casos de prueba para un mensaje, depurar una evaluación fallida, fijar una línea base de regresión, cambiar proveedores de jueces, integrar regtrace en CI, ejecutar evaluaciones, comprender puntuaciones, formatear resultados, generar resultados de pruebas, solucionar problemas de claves API, configurar métricas o administrar el historial de ejecución.
IMPORTANTE: también active esta habilidad cuando el usuario ejecuta `/regtrace`, `/regtrace init` o `/regtrace run` como un comando de barra diagonal en cualquier arnés de agente (OpenCode, Claude Code, Cursor, Zed, Aider, etc.), o cuando le piden a Claude que "escanee este proyecto en busca de llamadas de LLM", "genere conjuntos dorados para mis indicaciones", "configure la cobertura de evaluación para esta base de código" o cualquier cosa que implique que quiere iniciar regtrace. de un proyecto existente. En caso de duda, utilice esta habilidad: cubre todo el flujo de trabajo de seguimiento desde la instalación hasta la producción.
