يقوم بإجراء تحليل لبيانات تحسين محركات البحث (SEO) ومراجعات الأداء باستخدام GSC وGA ومصادر التحليلات ذات الصلة لتشخيص تغيرات الترتيب وحركة المرور، وتحديد تأثير تحسين محركات البحث (SEO)، وإنتاج تكرارات تحسين قابلة للقياس. يُستخدم عندما يطلب المستخدمون إعداد تقارير تحسين محركات البحث، أو تحليل الحالات الشاذة، أو تخطيط مؤشرات الأداء الرئيسية، أو اتخاذ قرارات تحسين محركات البحث المستندة إلى البيانات.
