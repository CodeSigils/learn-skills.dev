Genere y proporcione complementos HTML enriquecidos para marcar documentos de descubrimiento: reducción emparejada → renderizado HTML (marcado + sirena + citopaisaje basado en datos/bloques cercados en trazado), una biblioteca de plantillas draw.io (~AWS/GCP/Azure/K8s SVG iconos) para componer diagramas de arquitectura personalizados, un paquete de marcas de tokens de diseño inyectables y un servidor host local confiable para HTML que extrae bibliotecas CDN ancladas. Úselo cuando convierta un documento de revisión/arquitectura/rebaja de costos en una vista HTML interactiva, cuando un diagrama necesite íconos reales del proveedor de la nube, cuando proporcione HTML local que file:// se rompe o cuando cree una vista de gráfico/cuadro basada en datos. Omita cuando el entregable sea una simple creación de sirena en rebajas sin un complemento HTML o una imagen de diagrama de arquitectura renderizada en Python.
