قم بإنشاء وتقديم مرافق HTML غنية لمستندات اكتشاف تخفيض السعر: تخفيض السعر المقترن → عرض HTML (علامة + حورية البحر + كتل خلوية / مسيجة تعتمد على البيانات)، ومكتبة استنسل draw.io مُباعة (~أيقونات AWS/GCP/Azure/K8s SVG) لإنشاء مخططات معمارية مخصصة، وحزمة علامات تجارية لرموز التصميم قابلة للحقن، وخادم مضيف محلي موثوق به لـ HTML يسحب مكتبات CDN المثبتة. يُستخدم عند تحويل مستند تخفيض المراجعة/الهندسة المعمارية/تكلفة إلى عرض HTML تفاعلي، عندما يحتاج الرسم التخطيطي إلى أيقونات موفر السحابة الحقيقية، أو عند تقديم HTML المحلي الذي يقطع الملف://، أو عند إنشاء عرض رسم بياني/مخطط يعتمد على البيانات. قم بالتخطي عندما يكون التسليم عبارة عن تأليف عادي على شكل حورية البحر بدون مرافق HTML، أو صورة رسم تخطيطي لهندسة بايثون.
