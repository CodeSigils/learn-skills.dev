マークダウン検出ドキュメントのリッチ HTML コンパニオンを生成して提供します。マークダウン→HTML レンダリングのペア (マーク + マーメイド + データ駆動型 cytoscape/プロットリー フェンス ブロック)、カスタム アーキテクチャ図を構成するためのベンダー提供のdraw.io ステンシル ライブラリ (~AWS/GCP/Azure/K8s SVG アイコン)、注入可能なデザイン トークン ブランドパック、ピン留めされた CDN ライブラリをプルする HTML 用の信頼できるローカルホスト サーバーです。レビュー/アーキテクチャ/コスト値下げドキュメントをインタラクティブな HTML ビューに変換する場合、図に実際のクラウド プロバイダー アイコンが必要な場合、file:// が壊れるローカル HTML を提供する場合、またはデータ駆動型のグラフ/チャート ビューを構築する場合に使用します。成果物が HTML コンパニオンのないプレーンな Mermaid-in-Markdown オーサリング、または Python でレンダリングされたアーキテクチャ図イメージの場合はスキップします。
