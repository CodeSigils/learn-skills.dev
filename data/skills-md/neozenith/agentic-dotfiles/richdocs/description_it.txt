Genera e offri ricchi complementi HTML per i documenti di rilevamento del markdown: markdown accoppiato→rendering HTML (contrassegnato + sirena + citoscape basato sui dati/blocchi recintati dalla trama), una libreria di stencil draw.io venduta (icone SVG ~AWS/GCP/Azure/K8s) per la composizione di diagrammi di architettura personalizzati, un brandpack di token di progettazione iniettabili e un server host locale affidabile per HTML che estrae librerie CDN bloccate. Da utilizzare quando si trasforma un documento di revisione/architettura/riduzione dei costi in una visualizzazione HTML interattiva, quando un diagramma necessita di icone reali del provider cloud, quando si fornisce HTML locale che file:// si interrompe o quando si crea una visualizzazione grafico/grafico basata sui dati. Salta quando il risultato finale è una semplice creazione di sirene in markdown senza compagno HTML o un'immagine di diagramma di architettura renderizzata in Python.
