Générez et servez de riches compagnons HTML pour les documents de découverte markdown : rendu markdown → HTML (marqué + sirène + cytoscape basé sur les données/blocs clôturés par intrigue), une bibliothèque de pochoirs draw.io vendue (icônes SVG ~ AWS/GCP/Azure/K8s) pour composer des diagrammes d'architecture personnalisés, un brandpack de jetons de conception injectables et un serveur localhost fiable pour HTML qui extrait les bibliothèques CDN épinglées. À utiliser pour transformer un document de révision/d'architecture/de réduction des coûts en une vue HTML interactive, lorsqu'un diagramme nécessite de véritables icônes de fournisseur de cloud, lors de la diffusion d'un code HTML local qui file:// se casse, ou lors de la création d'un graphique/vue graphique basée sur les données. Ignorer lorsque le livrable est une simple création de sirène en démarque sans compagnon HTML ou une image de diagramme d'architecture rendue en Python.
