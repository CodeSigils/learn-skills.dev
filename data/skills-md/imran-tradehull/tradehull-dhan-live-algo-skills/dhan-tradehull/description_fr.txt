Utilisez cette compétence chaque fois que l'utilisateur écrit, débogue ou crée du code de trading d'algo Python à l'aide de la bibliothèque Dhan-Tradehull (pip install Dhan-Tradehull). Déclencheurs sur : toute mention de Tradehull, Dhan_Tradehull, tsl., get_ltp_data, order_placement, ATM_Strike_Selection, get_option_chain, get_historical_data, super commande, commande permanente, déclencheur conditionnel, scalping OI, stratégie d'options utilisant Dhan, passer une commande Dhan Python, authentification Tradehull, get_positions, get_holdings, activate_pnl_based_exit, get_option_greek, margin_calculator ou toute tâche de code de cours TradeHull. Utilisez toujours cette compétence avant d'écrire un code Tradehull - même pour de simples extraits - pour garantir des signatures et des modèles de méthode corrects.
