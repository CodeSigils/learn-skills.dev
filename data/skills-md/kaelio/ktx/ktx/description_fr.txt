Installe et configure ktx, la couche contextuelle open source pour les agents de données : exécute la configuration de ktx de manière non interactive avec des indicateurs CLI masqués, configure les connexions et les intégrations de base de données, installe l'intégration de l'agent et vérifie l'état de préparation. À utiliser lorsque l'utilisateur demande à un agent d'ajouter ktx à un projet, de connecter des sources de données, d'installer des règles d'agent, d'ingérer un schéma ou de dépanner une installation ktx locale.
