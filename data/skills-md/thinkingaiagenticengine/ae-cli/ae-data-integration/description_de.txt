Bringen Sie lokale CSV-, TSV-, TXT-, JSON-, JSONL- (NDJSON), XLS- und XLSX-Dateien durchgängig in AE ein: Identifizieren Sie die Geschäftsbedeutung der Quelle, generieren und bestätigen Sie einen Tracking-Plan, wandeln Sie Zeilen in UE-Datensätze um und laden Sie sie hoch. Unterstützt auch die datenschutzschonende lokale Analyse und die Übergabe einer kleinen Datei an AE Agent. Verwenden Sie es immer dann, wenn ein Benutzer Offline-/lokale Daten in AE importieren oder eine Datei analysieren möchte, ohne sie hochzuladen.
