Porta file CSV, TSV, TXT, JSON, JSONL (NDJSON), XLS e XLSX locali in AE end-to-end: identifica il significato aziendale dell'origine, genera e conferma un piano di monitoraggio, trasforma le righe in record UE e carica. Supporta anche l'analisi locale che preserva la privacy e trasmette un piccolo file all'agente AE. Da utilizzare ogni volta che un utente desidera importare dati offline/locali in AE o analizzare un file senza caricarlo.
