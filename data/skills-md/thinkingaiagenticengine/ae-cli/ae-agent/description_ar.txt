AE Agent لإدارة موارد منصة CLI لإدراج الوكلاء، وإنشاء وتحديث عمليات التشغيل الآلي، وإضافة/إزالة/إدراج/تبديل النماذج المخصصة، وخوادم MCP، والمهارات، وتحميل ملفات وضع الحماية إلى مكتبة المرفقات، وتصفح سوق MCP/Skill، وتحديد فئة/رمز السوق، ونسخ مهارات النظام/الشركة إلى الشخصية، وإرسال/الموافقة/مشاركة المهارات. يُستخدم عندما يطلب المستخدم إدارة موارد النظام الأساسي للوكيل، أو تصفح السوق، أو إنشاء عمليات أتمتة مجدولة للوكيل. يجب استخدام أوامر وكيل ae-cli.
