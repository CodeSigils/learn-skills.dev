Интерфейс командной строки для управления ресурсами платформы AE Agent для составления списков агентов, создания и обновления средств автоматизации, добавления/удаления/списка/переключения пользовательских моделей, серверов MCP, навыков, загрузки файлов песочницы в библиотеку вложений, просмотра рынка MCP/навыков, установки категории/значка рынка, копирования навыков системы/компании в личные, а также отправки/утверждения/обмена навыками. Используйте, когда пользователь запрашивает управление ресурсами платформы агента, просмотр рынка или создание запланированной автоматизации агента. Необходимо использовать команды агента ae-cli.
