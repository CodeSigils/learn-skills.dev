CLI di gestione delle risorse della piattaforma AE Agent per elencare agenti, creare e aggiornare automazioni, aggiungere/rimuovere/elencare/attivare modelli personalizzati, server MCP, competenze, caricare file sandbox nella libreria degli allegati, esplorare il mercato MCP/competenze, impostare categorie/icone di mercato, copiare competenze di sistema/aziendali in personali e inviare/approvare/condividere competenze. Da utilizzare quando l'utente chiede di gestire le risorse della piattaforma Agent, esplorare il mercato o creare automazioni pianificate dell'Agent. È necessario utilizzare i comandi dell'agente ae-cli.
