Diseñar experimentos AE/TE A/B desde un objetivo de negocio a través de un borrador revisable. Úselo cuando el usuario solicite formular una hipótesis de experimento, evaluar la preparación de métricas, elegir o crear métricas y características, diseñar grupos o tráfico, estimar el tamaño o la duración de la muestra, crear un borrador de experimento o ejecutar comprobaciones de preparación y conflictos. La guía del SDK es una rama condicional: ingrésela solo cuando el usuario pregunte explícitamente sobre un SDK de experimento A/B, la integración del SDK del cliente, la generación de código del SDK de experimento o la solución de problemas del SDK; no incluya el trabajo del SDK en una solicitud ordinaria de diseño de experimento o de creación de borrador.
