تصميم تجارب AE/TE A/B من هدف تجاري من خلال مسودة قابلة للمراجعة. يُستخدم عندما يطلب المستخدم تكوين فرضية تجربة، أو تقييم جاهزية القياس، أو اختيار أو إنشاء مقاييس وميزات، أو تصميم مجموعات أو حركة مرور، أو تقدير حجم العينة أو مدتها، أو إنشاء مسودة تجربة، أو تشغيل عمليات التحقق من الاستعداد والتضارب. يعد توجيه SDK فرعًا مشروطًا: أدخله فقط عندما يسأل المستخدم صراحةً عن تجربة A/B SDK، أو تكامل SDK للعميل، أو إنشاء كود SDK للتجربة، أو استكشاف أخطاء SDK وإصلاحها؛ لا تقم بتضمين عمل SDK في تصميم تجربة عادي أو طلب إنشاء مسودة.
