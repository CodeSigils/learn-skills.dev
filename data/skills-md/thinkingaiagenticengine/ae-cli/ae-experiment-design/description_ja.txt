ビジネス目標からレビュー可能なドラフトまで、AE/TE A/B 実験を設計します。ユーザーが実験仮説の形成、メトリクスの準備状況の評価、メトリクスと機能の選択または作成、グループまたはトラフィックの設計、サンプル サイズまたは期間の推定、実験ドラフトの作成、または準備状況と競合チェックの実行を要求する場合に使用します。 SDK ガイダンスは条件分岐です。ユーザーが A/B 実験 SDK、クライアント SDK 統合、実験 SDK コード生成、または SDK トラブルシューティングについて明示的に質問した場合にのみ、このガイダンスを入力します。通常の実験設計またはドラフト作成リクエストに SDK 作業を含めないでください。
