Manual de AE/TE/ThinkingEngine/ThinkingAI ae-cli para tareas del equipo de agentes de IA: gestionar equipos (enumerar, crear, actualizar, eliminar, generar IA, plantillas) y ejecutar TeamRuns (iniciar, chatear, cancelar, responder, resultados, artefactos). Úselo cuando el usuario solicite encontrar un equipo, ejecutar una tarea de equipo, verificar el estado de ejecución, recuperar resultados o artefactos o configurar flujos de trabajo de múltiples agentes. Debe usar ae-cli, leer las referencias coincidentes/<comando>.md antes de componer comandos y nunca adivinar los ID de equipo, los ID de ejecución, las estructuras de configuración o los formatos de parámetros.
