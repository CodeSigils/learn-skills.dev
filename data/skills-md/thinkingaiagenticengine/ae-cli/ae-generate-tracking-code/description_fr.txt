Génération interactive de code de suivi AE, configuration LogBus2 et scripts de débogage à partir d'un plan de suivi. Mots déclencheurs : 代码埋点、埋点代码、tracking code、埋点落地、logbus 配置、AE 上报代码、generate tracking code、insert suivi. Prend en charge la sélection indépendante du mode de sortie par plate-forme (insertion/extrait). Côté serveur, les valeurs par défaut sont l'architecture LoggerConsumer + LogBus2.
