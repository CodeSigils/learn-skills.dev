Интерактивное создание кода отслеживания AE, конфигурации LogBus2 и сценариев отладки на основе плана отслеживания. Триггерные слова: 代码埋点、埋点代码、код отслеживания、埋点落地、logbus 配置、AE 上报代码、генерировать код отслеживания、вставить отслеживание、トラッキングコード、트래킹 코드. Поддерживает независимый выбор режима вывода для каждой платформы (вставка/фрагмент). На стороне сервера по умолчанию используется архитектура LoggerConsumer + LogBus2.
