Generación interactiva de código de seguimiento AE, configuración de LogBus2 y scripts de depuración a partir de un plan de seguimiento. Palabras de activación: 代码埋点、埋点代码、código de seguimiento、埋点落地、logbus 配置、AE 上报代码、generar código de seguimiento、insertar seguimiento、トラッキングコード、트래킹 코드. Admite la selección del modo de salida independiente por plataforma (insertar/fragmento). El lado del servidor tiene como valor predeterminado la arquitectura LoggerConsumer + LogBus2.
