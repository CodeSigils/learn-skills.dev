Descubre qué bases de conocimientos AE/TE/ThinkingEngine accesibles para el usuario actual valen la pena buscar y decide si es necesario buscar, mediante operaciones de solo lectura. Úsalo cuando el usuario solicite explícitamente buscar en bases de conocimientos, documentación interna o materiales de la empresa. También utilízalo cuando una tarea requiera hechos internos o contexto empresarial, incluidos el diseño y las normas del producto, eventos, calendarios de campañas o operaciones, registros de lanzamientos e iteraciones, flujos de trabajo, políticas y terminología; úsalo igualmente cuando se necesite este contexto para explicar resultados de análisis de datos, anomalías o tendencias y formular conclusiones respaldadas por evidencia. No lo uses si el usuario indica explícitamente que no se acceda a las bases de conocimientos. Esta habilidad cubre el descubrimiento y la selección de candidatos; ejecuta la recuperación real con `+index` / `+grep` / `+read` / `+ask` usando la habilidad `ae‑kb`.

Por favor, responde siempre en el idioma del usuario.
