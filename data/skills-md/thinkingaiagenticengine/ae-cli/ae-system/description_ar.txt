AE Agent System Management CLI لمسؤولي الجذر والوكلاء. يُستخدم عندما يطلب المستخدم إدارة أعضاء الوكلاء، أو صناديق الحماية، أو رؤية/افتراضيات نموذج الشركة، أو إحصائيات الاستخدام، أو حصص التكلفة، أو تنبيهات الرصيد، أو قنوات المراسلة الفورية. يجب استخدام أوامر نظام ae-cli، واكتشاف المعرفات الحقيقية قبل الكتابة، وعدم محاولة تجاوز رفض الإذن مطلقًا.
