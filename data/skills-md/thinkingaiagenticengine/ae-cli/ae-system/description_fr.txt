CLI d’administration système de l’agent AE pour les administrateurs racine et agent. À utiliser lorsque l'utilisateur demande à gérer les membres de l'agent, les bacs à sable, la visibilité/les valeurs par défaut du modèle d'entreprise, les statistiques d'utilisation, les quotas de coûts, les alertes de solde ou les canaux de messagerie instantanée. Doit utiliser les commandes système ae-cli, découvrir les véritables identifiants avant les écritures et ne jamais tenter de contourner un refus d'autorisation.
