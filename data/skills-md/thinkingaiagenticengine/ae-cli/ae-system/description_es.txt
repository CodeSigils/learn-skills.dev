CLI de administración del sistema AE Agent para administradores raíz y de agentes. Úselo cuando el usuario solicite administrar miembros de agentes, entornos sandbox, visibilidad/valores predeterminados del modelo de empresa, estadísticas de uso, cuotas de costos, alertas de saldo o canales de mensajería instantánea. Debe usar comandos del sistema ae-cli, descubrir ID reales antes de escribir y nunca intentar eludir una denegación de permiso.
