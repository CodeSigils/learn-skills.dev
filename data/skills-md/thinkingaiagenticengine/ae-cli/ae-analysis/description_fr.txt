Manuel ae-cli AE/TE/ThinkingEngine/ThinkingAI pour les tâches côté analyse dans le système AE ou la plateforme d'analyse : rapports, tableaux de bord, alertes, analyse ad hoc, exploration, clusters d'audience, balises, membres de balises, métriques et définitions de métriques, événements, propriétés, événements virtuels, propriétés virtuelles, métadonnées, configuration de projet, plans de suivi, suivi des événements, marquage des temps, listes de projets et liens de ressources. À utiliser lorsque l'utilisateur demande à interroger, créer, mettre à jour, actualiser, inspecter, dépanner, gouverner ou gérer ces actifs d'analyse AE. Vous devez utiliser ae-cli, lire le manuel de commande references/<tool_name>.md correspondant avant de composer des commandes et ne jamais deviner les noms de commande, les indicateurs, les charges utiles JSON, l'ID du projet, les ID de ressource ou les formats de paramètres.
