Manuale CLI della knowledge base AE/TE per la creazione, l'esecuzione di query, la richiesta basata su LLM, il recupero di indici/grep/lettura deterministici, il controllo dello stato, il caricamento, la compilazione, la generazione di schemi, le origini URL, l'eliminazione dell'origine e l'eliminazione della knowledge base. Da utilizzare quando l'utente chiede di gestire le basi di conoscenza TE/AE/ThinkingEngine, caricare documenti o URL in una base di conoscenza, eseguire query sulla conoscenza, chiedere basi di conoscenza con un LLM, ispezionare gli indici della base di conoscenza, cercare pagine di base di conoscenza, leggere una pagina di base di conoscenza specifica, controllare lo stato della base di conoscenza, generare schemi, compilare conoscenza, rimuovere fonti o eliminare una base di conoscenza. È necessario utilizzare comandi ae-cli kb e non indovinare nomi, ambiti, percorsi di pagina, nomi visualizzati di origine, forme di payload JSON o formati URL della knowledge base.
