Manual CLI de la base de conocimientos de AE/TE para crear, realizar consultas, realizar preguntas basadas en LLM, recuperar índices/grep/lecturas deterministas, verificar el estado, cargar, compilar, generar esquemas, fuentes de URL, eliminar fuentes y eliminar bases de conocimientos. Úselo cuando el usuario solicite administrar bases de conocimientos de TE/AE/ThinkingEngine, cargar documentos o URL a una base de conocimientos, consultar conocimientos, consultar bases de conocimientos con un LLM, inspeccionar índices de bases de conocimientos, buscar páginas de bases de conocimientos, leer una página de bases de conocimientos específica, verificar el estado de la base de conocimientos, generar esquemas, compilar conocimientos, eliminar fuentes o eliminar una base de conocimientos. Debe utilizar comandos ae-cli kb y no debe adivinar los nombres de la base de conocimientos, los ámbitos, las rutas de las páginas, los nombres para mostrar de las fuentes, las formas de carga útil JSON ni los formatos de URL.
