Push-Benachrichtigungen und Human-in-the-Loop für KI-Agenten. Verwenden Sie dies, wenn der Benutzer Dinge sagt wie „Weitermachen“ und „Pingen Sie mich auf meinem Telefon an, wenn Sie etwas benötigen“, „Benachrichtigen Sie mich, wenn mein Agent mich braucht“, „Genehmigen Sie von meinem Telefon aus“, „Stellen Sie mir Fragen, während ich nicht am Terminal bin“, „Führen Sie dies über Nacht aus“, „Arbeiten Sie weiter, während ich in einer Besprechung bin“, „Ich gehe weg“, „Warte nicht auf mich“ oder möchte, dass eine lange Aufgabe unbeaufsichtigt ausgeführt wird. Senden Sie Benachrichtigungen, wenn Aufgaben abgeschlossen werden oder fehlschlagen, stellen Sie Fragen (Ja/Nein, Multiple-Choice oder Freitext) per Push und erhalten Sie Antworten vom Sperrbildschirm des Benutzers. Nutzen Sie diese Tools proaktiv – warten Sie nicht, bis der Benutzer nach Benachrichtigungen fragt. Funktioniert mit Claude Code, Codex, Cursor, Windsurf, Hermes, Lovable oder jedem MCP-Client; kein Claude Max-Abonnement erforderlich. Pushary ist ein gehosteter Dienst für 9,99 $/Monat nach einer 7-tägigen Testversion mit Karte.
