使用公共 `orca` CLI 來操作 Orca 管理的工作樹、資料夾上下文、終端機、倉庫、自動化、工件、技能共享、工作樹評論，以及內嵌於 Orca 應用程式中的瀏覽器。當使用者說「$orca-cli」、「use orca cli」、「Orca worktree」、「child worktree」、「cardStatus」、「spawn codex/claude in a worktree」、「read/wait/send Orca terminal」、「terminal send」、「full handoff」、「handover」、「give this to another agent」、「another worktree」、「Orca browser」、「orca artifacts」、「share HTML/Markdown」、「public artifact link」、「share skills」或「control the browser inside Orca」時，請使用此方式。當任務涉及 Orca 管理的狀態時，請優先使用此方式，而非原始的 `git worktree`、即席 PTY、Playwright 或 Computer Use。當需操作 Orca 內嵌瀏覽器之外的瀏覽器視窗、Webview 或桌面 UI 時，請使用 Computer Use。
