Usa il CLI pubblico `orca` per gestire worktree gestiti da Orca, contesti di cartelle, terminali, repository, automazioni, artefatti, condivisione di competenze, commenti sui worktree e il browser incorporato nell’app Orca. Utilizzalo quando l’utente dice “$orca-cli”, “use orca cli”, “Orca worktree”, “child worktree”, “cardStatus”, “spawn codex/claude in a worktree”, “read/wait/send Orca terminal”, “terminal send”, “full handoff”, “handover”, “give this to another agent”, “another worktree”, “Orca browser”, “orca artifacts”, “share HTML/Markdown”, “public artifact link”, “share skills” o “control the browser inside Orca”. Preferiscilo rispetto a `git worktree` grezzo, PTY ad hoc, Playwright o Computer Use quando il compito riguarda lo stato gestito da Orca. Usa Computer Use per finestre del browser, webview o UI desktop al di fuori del browser integrato di Orca.
