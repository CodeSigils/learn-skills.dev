Грок Строить ТОЛЬКО. Превратите 2D-персонаж в плавные анимационные спрайты с помощью базы image_gen/image_edit → image_to_video (обработка на месте 6 с/10 с) → кадры ffmpeg → пурпурный цветной ключ → спрайты с плотной выборкой (полоса/сетка/GIF). Используйте, когда пользователю требуется преобразование видео в спрайт, захват движения из сгенерированного видео, более плавные циклы бега/ходьбы из плотных кадров или запуск /video2dsprite. НЕ используйте в Codex/Claude — image_to_video есть только в Grok Build. Предпочитайтеgenerate2dsprite для получения четких пиксельных листов без видео.
