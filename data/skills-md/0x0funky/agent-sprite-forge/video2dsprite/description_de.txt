NUR Grok Build. Verwandeln Sie ein 2D-Charakter-Standbild in glatte Animations-Sprites über image_gen/image_edit base → image_to_video (6s/10s run-in-place) → ffmpeg-Frames → Magenta-Chroma-Key → dicht gesampelte Sprites (Strip/Grid/GIF). Verwenden Sie diese Option, wenn der Benutzer Video-zu-Sprite, Bewegungserfassung aus generiertem Video, flüssigere Lauf-/Gehzyklen aus dichten Bildern oder die Ausführung von /video2dsprite wünscht. NICHT auf Codex/Claude verwenden – nur Grok Build verfügt über image_to_video. Bevorzugen Sie generic2dsprite für gestochen scharfe Pixelblätter ohne Video.
