Grok Build UNIQUEMENT. Transformez un personnage 2D en sprites d'animation fluides via image_gen/image_edit base → image_to_video (exécution sur place 6s/10s) → images ffmpeg → chroma-key magenta → sprites échantillonnés denses (bande/grille/GIF). À utiliser lorsque l'utilisateur souhaite une vidéo vers un sprite, une capture de mouvement à partir d'une vidéo générée, des cycles d'exécution/marche plus fluides à partir d'images denses ou exécute /video2dsprite. Ne PAS utiliser sur Codex/Claude — seul Grok Build a image_to_video. Préférez generate2dsprite pour des feuilles de pixels nettes sans vidéo.
