Grok ビルドのみ。 image_gen/image_edit ベース → image_to_video (6 秒/10 秒ランインプレイス) → ffmpeg フレーム → マゼンタ クロマキー → 高密度サンプル スプライト (ストリップ/グリッド/GIF) を介して、2D キャラクターを滑らかなアニメーション スプライトに変換します。ユーザーがビデオからスプライトへの変換、生成されたビデオからのモーション キャプチャ、高密度フレームからのよりスムーズな走行/歩行サイクル、または /video2dsprite の実行を必要とする場合に使用します。 Codex/Claude では使用しないでください。image_to_video があるのは Grok Build のみです。ビデオのない鮮明なピクセル シートには、generate2dsprite をお勧めします。
