Construcción Grok SOLAMENTE. Convierta un personaje 2D en sprites de animación fluidos a través de image_gen/image_edit base → image_to_video (6s/10s run-in-place) → marcos ffmpeg → magenta chroma-key → sprites densos muestreados (tira/cuadrícula/GIF). Úselo cuando el usuario desee convertir video a sprite, capturar movimiento a partir de video generado, ciclos de carrera/caminata más fluidos a partir de fotogramas densos o ejecuciones /video2dsprite. NO lo use en Codex/Claude; solo Grok Build tiene image_to_video. Prefiera generate2dsprite para obtener hojas de píxeles nítidas sin vídeo.
