Un script populaire de bande dessinée dramatique (bande dessinée dynamique/bande dessinée) et un générateur d'invites de storyboard IA. Il est déclenché lorsqu'un utilisateur souhaite créer de courtes vidéos de bandes dessinées, des bandes dessinées dynamiques, des scripts de bandes dessinées à écran vertical, ou doit convertir une histoire en cadres de storyboard générés par l'IA.  

Scénarios couverts : l'utilisateur dit « écrire un script de bande dessinée dramatique », « aidez-moi à créer des storyboards de bande dessinée dynamiques », « mots d'invite de bande dessinée dramatique », « écrire une bande dessinée dramatique de type 爽文/甜宠/悬疑 », « script de bande dessinée IA », « script de bande dessinée », « storyboard de courte série dramatique », « aidez-moi à transformer cette histoire en une série dramatique de bande dessinée », « script d'anime à écran vertical », etc. script » mais que le contexte implique un style bande dessinée/animation, cette compétence doit quand même être déclenchée.  

Veuillez toujours répondre dans la langue de l'utilisateur.
