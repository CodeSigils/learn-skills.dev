Stellen Sie Dateien mit Git bereit, fügen Sie einen Git-Commit hinzu und erstellen Sie ihn gemäß den herkömmlichen Commits 1.0.0. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer einen Commit, ein Commit, ein Git-Commit, das Speichern von Änderungen in Git oder ein Commit seiner Arbeit durchführen möchte – auch wenn er „konventionelle Commits“ nicht ausdrücklich erwähnt.
