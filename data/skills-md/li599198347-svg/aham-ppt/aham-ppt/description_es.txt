Habilidad de creación de presentaciones PPT con IA de proceso completo, comparada con las principales firmas consultoras como los estándares McKinsey/Deloitte (TrackA·Brand). Cuando un usuario dice "ayúdame a hacer un PPT", "crea una presentación", "haz un informe", "haz un PPT a partir de este material", "haz un PPT de propuesta para un cliente" o "crea diapositivas", se activa inmediatamente; incluso una solicitud de una sola frase lo activará. Flujo de trabajo modular de ocho etapas: carga de especificaciones → análisis de material → extracción de argumentos → marco narrativo → diseño del esquema → confirmación del borrador de muestra → diseño página por página → inspección de calidad y entrega. El mecanismo de entrenamiento adaptativo incorporado guía a los usuarios de cualquier nivel profesional hacia un resultado que alcance al menos una calidad aceptable. Nota: esta habilidad es para salida de PowerPoint/.pptx; consulte la habilidad ppt‑svg para versiones SVG/HTML.
