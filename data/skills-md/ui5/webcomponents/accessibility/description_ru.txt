Как сделать доступными приложения веб-компонентов UI5. Охватывает API специальных возможностей (accessibleName,accessNameRef,accessDescription,accessableRole,accessibilityAttributes), отношения метки-ввода, невидимый обмен сообщениями, обработку клавиатуры, высококонтрастные темы и поддержку чтения с экрана. Используйте, когда пользователь спрашивает об атрибутах ARIA, средствах чтения с экрана, навигации с помощью клавиатуры, свойствах специальных возможностей или обеспечении доступности своего приложения.
