UI5 Web コンポーネント アプリケーションにアクセスできるようにする方法。アクセシビリティ API (accessibleName、accessibleNameRef、accessibleDescription、accessibleRole、accessibilityAttributes)、ラベル入力関係、非表示メッセージング、キーボード処理、ハイ コントラスト テーマ、およびスクリーン リーダーのサポートについて説明します。ユーザーが ARIA 属性、スクリーン リーダー、キーボード ナビゲーション、アクセシビリティ プロパティ、またはアプリのアクセシビリティに関して尋ねる場合に使用します。
