Comment rendre les applications UI5 Web Components accessibles. Couvre les API d'accessibilité (accessibleName, accessibleNameRef, accessibleDescription, accessibleRole, accessibilitéAttributes), les relations d'entrée d'étiquette, la messagerie invisible, la gestion du clavier, les thèmes à contraste élevé et la prise en charge des lecteurs d'écran. À utiliser lorsque l'utilisateur pose des questions sur les attributs ARIA, les lecteurs d'écran, la navigation au clavier, les propriétés d'accessibilité ou pour rendre son application accessible.
