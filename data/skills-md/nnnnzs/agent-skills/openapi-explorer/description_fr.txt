Outil d'analyse de documents OpenAPI/Swagger. Activez-le lorsque les utilisateurs posent des questions sur la documentation de l'API, les définitions d'interface ou doivent générer du code à partir de Swagger. Prend en charge l'extraction précise des informations d'interface par module et chemin, évitant ainsi le débordement de contexte causé par le chargement de documents volumineux.
