OpenAPI/Swagger-Tool zum Parsen von Dokumenten. Wird aktiviert, wenn Benutzer nach API-Dokumentation oder Schnittstellendefinitionen fragen oder Code aus Swagger generieren müssen. Unterstützt die präzise Extraktion von Schnittstelleninformationen nach Modul und Pfad und vermeidet so einen Kontextüberlauf durch das Laden großer Dokumente.
