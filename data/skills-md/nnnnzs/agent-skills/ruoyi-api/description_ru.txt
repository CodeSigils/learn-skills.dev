Инструмент вызова API управления системой RuoYi. Активируется, когда пользователю необходимо управлять пользователями, ролями, меню или отделами в системе RuoYi. Триггерные слова: «若依», «ruoyi», «создать пользователя», «назначить роль», «создать меню». Требуется настройка файла .env (RUOYI_BASE_URL, RUO_YI_TOKEN).
