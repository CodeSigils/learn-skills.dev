Strumento di chiamata API di gestione del sistema RuoYi. Attivato quando gli utenti devono gestire utenti, ruoli, menu e dipartimenti nel sistema RuoYi. Parole chiave: "RuoYi", "ruoyi", "crea utente", "assegna ruolo", "crea menu". Richiede la configurazione del file .env (RUOYI_BASE_URL, RUOYI_TOKEN).
