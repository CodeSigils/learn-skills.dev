RuoYi-Systemverwaltungs-API-Aufruftool. Wird aktiviert, wenn der Benutzer Benutzer, Rollen, Menüs oder Abteilungen im RuoYi-System bedienen muss. Auslösewörter: „若依“, „ruoyi“, „Benutzer erstellen“, „Rolle zuweisen“, „Menü erstellen“. Erfordert die Konfiguration der .env-Datei (RUOYI_BASE_URL, RUOYI_TOKEN).
