Outil d'invocation d'API de gestion du système RuoYi. Activé lorsque l'utilisateur doit gérer des utilisateurs, des rôles, des menus ou des départements dans le système RuoYi. Mots déclencheurs : "若依", "ruoyi", "créer un utilisateur", "attribuer un rôle", "créer un menu". Nécessite la configuration du fichier .env (RUOYI_BASE_URL, RUO_YI_TOKEN).
