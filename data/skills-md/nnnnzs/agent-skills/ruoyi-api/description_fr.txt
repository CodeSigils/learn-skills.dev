Outil d'appel d'API de gestion du système RuoYi. Activé lorsque les utilisateurs doivent gérer des utilisateurs, des rôles, des menus ou des départements dans le système RuoYi. Mots déclencheurs : "若依", "ruoyi", "创建用户", "分配角色", "创建菜单". Nécessite la configuration du fichier .env (RUOYI_BASE_URL, RUOYI_TOKEN).
