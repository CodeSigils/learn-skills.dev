Herramienta de llamada API de administración del sistema RuoYi. Se activa cuando el usuario necesita manipular usuarios, roles, menús o departamentos en el sistema RuoYi. Palabras desencadenantes: "若依", "ruoyi", "crear usuario", "asignar rol", "crear menú". Requiere configuración del archivo .env (RUOYI_BASE_URL, RUOYI_TOKEN).
