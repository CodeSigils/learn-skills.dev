Assurance qualité pour une fonctionnalité ou une base de code : analysez la couverture des tests, identifiez les chemins non testés, rédigez les tests manquants (unitaires, intégration, e2e) et produisez un rapport d'assurance qualité. À utiliser lorsque l'utilisateur dit « QA this », « écrire des tests », « améliorer la couverture des tests », « ajouter des tests pour », « tester cette fonctionnalité », « ce qui n'est pas testé » ou souhaite une porte de qualité avant la publication.
