Examinez un PLAN.md avant la mise en œuvre : recherchez les tâches vagues, les critères d'achèvement manquants, les hypothèses risquées, l'ordre des phases incorrect et les problèmes de portée. Écrivez les résultats dans docs/<feature-name>/PLAN-REVIEW.md avec un verdict. À utiliser lorsque l'utilisateur dit « examiner le plan », « vérifier le plan », « ce plan est-il prêt », « valider le plan » ou avant d'exécuter Implement-Plan sur un nouveau plan.
