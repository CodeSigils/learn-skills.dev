قم بإنشاء ملف خطة جديد للميزات الجديدة، أو إعادة هيكلة التعليمات البرمجية الموجودة أو ترقية الحزم أو التصميم أو الهندسة المعمارية أو البنية التحتية. يتم تشغيله عندما يقول المستخدم "أنشئ خطة"، أو "ضع خطة تنفيذ"، أو "خطط لهذه الميزة"، أو "اكتب خطة قبل أن نبدأ"، أو "خطط لهذا المُعيد"، أو "خطط لهذه الترقية"، أو أي طلب لتوثيق الخطوات قبل بدء العمل. يتم التشغيل أيضًا عندما يذكر المستخدم رغبته في اتباع نهج منظم، أو طرح مرحلي، أو قائمة مرجعية للمهام لمهمة الترميز. استخدم هذه المهارة بشكل استباقي عندما يتطلب تعقيد التنفيذ وجود خطة مكتوبة قبل الانتقال إلى التعليمات البرمجية.
