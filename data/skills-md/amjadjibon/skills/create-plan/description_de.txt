Erstellen Sie eine neue Plandatei für neue Funktionen, umgestalten Sie vorhandenen Code oder aktualisieren Sie Pakete, Design, Architektur oder Infrastruktur. Wird ausgelöst, wenn der Benutzer sagt: „Plan erstellen“, „Implementierungsplan erstellen“, „Diese Funktion planen“, „Plan schreiben, bevor wir beginnen“, „Diesen Refactor planen“, „Dieses Upgrade planen“ oder eine Anfrage zum Dokumentieren von Schritten vor Beginn der Arbeit sendet. Wird auch ausgelöst, wenn der Benutzer den Wunsch nach einem strukturierten Ansatz, einer schrittweisen Einführung oder einer Aufgabencheckliste für eine Codierungsaufgabe erwähnt. Nutzen Sie diese Fähigkeit proaktiv, wenn die Komplexität der Implementierung einen schriftlichen Plan erfordert, bevor Sie mit dem Code beginnen.
