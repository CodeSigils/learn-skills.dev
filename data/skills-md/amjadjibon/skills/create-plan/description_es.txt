Cree un nuevo archivo de plan para nuevas funciones, refactorizando código existente o actualizando paquetes, diseño, arquitectura o infraestructura. Se activa cuando el usuario dice "crear un plan", "hacer un plan de implementación", "planificar para esta característica", "escribir un plan antes de comenzar", "planificar esta refactorización", "planificar esta actualización" o cualquier solicitud para documentar los pasos antes de comenzar a trabajar. También se activa cuando el usuario menciona que desea un enfoque estructurado, una implementación por fases o una lista de verificación de tareas para una tarea de codificación. Utilice esta habilidad de forma proactiva siempre que la complejidad de la implementación justifique un plan escrito antes de pasar al código.
