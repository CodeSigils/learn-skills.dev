Ejecute un plan de implementación a partir de un archivo docs/<feature-name>/PLAN.md creado por la habilidad create-plan. Se activa cuando el usuario dice "implementar el plan", "ejecutar el plan", "ejecutar el plan", "trabajar en el plan", "continuar el plan", "reanudar el plan", "iniciar la fase 1" o señala cualquier archivo PLAN.md y solicita compilarlo. También se activa cuando el usuario hace referencia a una función planificada por su nombre y desea que comience la implementación, o cuando se acaba de crear un plan y el usuario dice "ir", "iniciar" o "implementarlo". Utilice esta habilidad siempre que haya un PLAN.md para ejecutar, incluso si el usuario no dice la palabra "plan".
