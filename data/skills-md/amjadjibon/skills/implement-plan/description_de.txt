Führen Sie einen Implementierungsplan aus einer docs/<feature-name>/PLAN.md-Datei aus, die mit dem Skill „create-plan“ erstellt wurde. Wird ausgelöst, wenn der Benutzer „Plan implementieren“, „Plan ausführen“, „Plan ausführen“, „Plan durcharbeiten“, „Plan fortsetzen“, „Plan fortsetzen“, „Phase 1 starten“ sagt oder auf eine beliebige PLAN.md-Datei zeigt und auffordert, diese zu erstellen. Wird auch ausgelöst, wenn der Benutzer namentlich auf eine geplante Funktion verweist und möchte, dass mit der Implementierung begonnen wird, oder wenn gerade ein Plan erstellt wurde und der Benutzer „Losgehen“, „Starten“ oder „Implementieren“ sagt. Verwenden Sie diese Fähigkeit immer dann, wenn ein PLAN.md ausgeführt werden muss, auch wenn der Benutzer das Wort „Plan“ nicht sagt.
