Запустите автономный план → реализуйте → цикл проверки функции. Выполняется до тех пор, пока проверка кода не пройдет, фиксируя результаты между итерациями и делая паузу для одобрения пользователя перед закрытием. Используйте, когда пользователь говорит «зациклиться на этом», «продолжать, пока оно не пройдет проверку», «автономный цикл разработки», «запланировать реализацию и проверку» или хочет, чтобы для функции использовался самокорректирующийся рабочий процесс агента.
