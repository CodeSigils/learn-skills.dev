قم بتصحيح أخطاء الاختبار الفاشل أو الخطأ أو السلوك غير المتوقع بشكل منهجي - إعادة إنتاج السبب الجذري وعزله وإصلاح الحد الأدنى والتحقق. يُستخدم عندما يقول المستخدم "تصحيح"، أو "إصلاح هذا الخطأ"، أو "إنه معطل"، أو "هذا فشل"، أو "لماذا يحدث هذا"، أو يشارك رسالة خطأ، أو تتبع المكدس، أو فشل مخرجات الاختبار.
