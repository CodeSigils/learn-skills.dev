Debuggen Sie systematisch einen fehlgeschlagenen Test, einen Fehler oder ein unerwartetes Verhalten – reproduzieren, die Grundursache isolieren, minimal beheben, überprüfen. Wird verwendet, wenn der Benutzer „Debuggen“, „Diesen Fehler beheben“, „Er ist defekt“, „Das schlägt fehl“, „Warum passiert das“ sagt oder eine Fehlermeldung, einen Stack-Trace oder eine fehlgeschlagene Testausgabe mitteilt.
