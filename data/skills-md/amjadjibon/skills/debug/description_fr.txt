Déboguez systématiquement un test défaillant, une erreur ou un comportement inattendu : reproduisez, isolez la cause première, corrigez de manière minimale, vérifiez. À utiliser lorsque l'utilisateur dit "déboguer", "corriger ce bug", "c'est cassé", "cela échoue", "pourquoi cela se produit" ou partage un message d'erreur, une trace de pile ou une sortie de test défaillante.
