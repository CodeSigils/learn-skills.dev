Examinez les modifications du code pour détecter les bogues d'exactitude, les problèmes de sécurité et les opportunités de simplification, puis écrivez les résultats dans docs/<feature-name>/REVIEW.md. Utilisez cette compétence chaque fois que l'utilisateur dit « examiner ceci », « examiner le code », « examiner mon PR », « vérifier ce code », « examiner la sécurité », « auditer ceci » ou demande des commentaires sur une différence, une branche ou un ensemble de fichiers. Déclenchez également lorsque l'utilisateur vient de terminer l'implémentation de quelque chose et souhaite un contrôle de qualité avant la fusion.
