Überprüfen Sie Codeänderungen auf Korrektheitsfehler, Sicherheitsprobleme und Vereinfachungsmöglichkeiten und schreiben Sie die Ergebnisse dann in docs/<Feature-Name>/REVIEW.md. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer „Überprüfen Sie dies“, „Codeüberprüfung“, „Überprüfen Sie meine PR“, „Überprüfen Sie diesen Code“, „Sicherheitsüberprüfung“, „Überprüfen Sie dies“ sagt oder um Feedback zu einem Diff, einem Zweig oder einer Gruppe von Dateien bittet. Wird auch ausgelöst, wenn der Benutzer gerade etwas implementiert hat und vor dem Zusammenführen eine Qualitätsprüfung wünscht.
