Создавайте и управляйте репозиториями GitHub, запросами на включение, проблемами, выпусками, ветвями, секретами и многим другим с помощью интерфейса командной строки Orbit. Используйте этот навык всякий раз, когда пользователь спрашивает о репозиториях GitHub, PR (запросах на включение), запусках рабочих процессов GitHub Actions, ветках, тегах, коммитах, проблемах, выпусках, секретах или репозиториях организации. Запускайте такие фразы, как «составьте список PR», «проверьте действия», «наблюдайте за рабочим процессом», «создайте секрет», «откройте запрос на включение», «просмотрите последние коммиты», «составьте список репозиториев в организации X», «перезапустите рабочий процесс», «закройте проблему», «последний выпуск», «установите секрет GitHub» или любую задачу, связанную с GitHub — даже случайные ссылки, такие как «что работает в CI», «покажите мне PR», «отметить выпуск», «проверить, объединен ли он», «составить список репозиториев», «проходит ли сборка» или «добавить секретный ключ развертывания». Также активируется, когда пользователь хочет отслеживать ход выполнения CI/CD, управлять секретами действий для развертываний или отлаживать неудачные рабочие процессы. Псевдоним CLI орбиты — «gh».
