使用 Orbit CLI 创建和管理 GitHub 存储库、拉取请求、问题、发布、分支、机密等。每当用户询问 GitHub 存储库、PR（拉取请求）、GitHub Actions 工作流运行、分支、标签、提交、问题、发布、机密或组织存储库时，请使用此技能。触发诸如“列出 PR”、“检查操作”、“观察工作流程”、“创建秘密”、“打开拉取请求”、“查看最新提交”、“列出 org X 中的存储库”、“重新运行工作流程”、“关闭问题”、“最新版本”、“设置 GitHub 秘密”或任何 GitHub 相关任务等短语 - 甚至是诸如“CI 中正在运行的内容”之类的随意引用， “显示 PR”、“标记发布”、“检查它是否合并”、“列出存储库”、“构建是否通过”或“添加部署密钥”。当用户想要监控 CI/CD 进度、管理部署的操作机密或调试失败的工作流程时也会触发。 Orbit CLI 别名是“gh”。
