Orbit CLI を使用して、GitHub リポジトリ、プル リクエスト、問題、リリース、ブランチ、シークレットなどを作成および管理します。ユーザーが GitHub リポジトリ、PR (プル リクエスト)、GitHub Actions ワークフローの実行、ブランチ、タグ、コミット、問題、リリース、シークレット、または組織リポジトリについて質問するときは常に、このスキルを使用します。 「PR をリストする」、「アクションを確認する」、「ワークフローを観察する」、「シークレットを作成する」、「プルリクエストを開く」、「最新のコミットを表示する」、「組織 X のリポジトリをリストする」、「ワークフローを再実行する」、「問題をクローズする」、「最新リリース」、「GitHub シークレットを設定する」などのフレーズ、または GitHub 関連のタスクをトリガーします。 「CI で実行されているもの」、「PR を表示する」、「リリースにタグを付ける」、「マージされているかどうかを確認する」、「リポジトリをリストする」、「ビルドは合格しているか」、または「デプロイ キー シークレットを追加する」。また、ユーザーが CI/CD の進行状況を監視したり、デプロイメントのアクション シークレットを管理したり、失敗したワークフローをデバッグしたりする場合にもトリガーします。 orbit CLI のエイリアスは「gh」です。
