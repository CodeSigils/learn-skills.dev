使用 Orbit CLI 建立和管理 GitHub 儲存庫、拉取請求、問題、發布、分支、機密等。每當使用者詢問 GitHub 儲存庫、PR（拉取請求）、GitHub Actions 工作流程運行、分支、標籤、提交、問題、發布、機密或組織儲存庫時，請使用此技能。諸如“列出 PR”、“檢查操作”、“觀察工作流程”、“創建秘密”、“打開拉取請求”、“查看最新提交”、“列出 org X 中的存儲庫”、“重新運行工作流程”、“關閉問題”、“最新版本”、“設置 GitHub 秘密”或任何 GitHub 相關任務等短語 - 甚至是諸如“CI 秘密”中運行的內容類別，諸如顯示的內容類別PR」、「標記發布」、「檢查它是否合併」、「列出儲存庫」、「建置是否通過」或「新增部署金鑰」。當使用者想要監控 CI/CD 進度、管理部署的操作機密或偵錯失敗的工作流程時也會觸發。 Orbit CLI 別名是「gh」。
