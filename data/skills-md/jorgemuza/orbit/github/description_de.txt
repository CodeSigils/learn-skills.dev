Erstellen und verwalten Sie GitHub-Repositorys, Pull Requests, Issues, Releases, Branches, Secrets und mehr mit der Orbit-CLI. Verwenden Sie diesen Skill immer dann, wenn der Benutzer nach GitHub-Repositorys, PRs (Pull Requests), GitHub Actions-Workflow-Ausführungen, Branches, Tags, Commits, Issues, Releases, Secrets oder Organisations-Repos fragt. Lösen Sie auf Phrasen wie „PRs auflisten“, „Aktionen prüfen“, „Workflow beobachten“, „Geheimnis erstellen“, „Pull-Anfrage öffnen“, „Neueste Commits anzeigen“, „Repositorys in Organisation „Release“, „Überprüfen Sie, ob es zusammengeführt wurde“, „Listen-Repos“, „Ist der Build bestanden“ oder „Fügen Sie ein Schlüsselgeheimnis für die Bereitstellung hinzu“. Wird auch ausgelöst, wenn der Benutzer den CI/CD-Fortschritt überwachen, Aktionsgeheimnisse für Bereitstellungen verwalten oder fehlerhafte Workflows debuggen möchte. Der Orbit-CLI-Alias ​​ist „gh“.
