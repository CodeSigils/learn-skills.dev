Créez et gérez des référentiels GitHub, des demandes d'extraction, des problèmes, des versions, des branches, des secrets et bien plus encore à l'aide de la CLI orbit. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur les référentiels GitHub, les PR (pull request), les exécutions de flux de travail GitHub Actions, les branches, les balises, les validations, les problèmes, les versions, les secrets ou les dépôts d'organisation. Déclenchez des expressions telles que "lister les PR", "vérifier les actions", "observer le flux de travail", "créer un secret", "ouvrir une demande d'extraction", "afficher les derniers commits", "lister les dépôts dans l'organisation X", "réexécuter le flux de travail", "fermer le problème", "dernière version", "définir un secret GitHub" ou toute tâche liée à GitHub - même des références occasionnelles comme "ce qui s'exécute dans CI", « montrez-moi les PR », « marquez une version », « vérifiez si elle a fusionné », « listez les dépôts », « la construction est-elle réussie » ou « ajoutez une clé secrète de déploiement ». Déclenchez également lorsque l'utilisateur souhaite surveiller la progression de CI/CD, gérer les secrets d'actions pour les déploiements ou déboguer les flux de travail défaillants. L'alias CLI de l'orbite est « gh ».
