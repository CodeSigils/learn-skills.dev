Crea e gestisci repository GitHub, richieste pull, problemi, versioni, rami, segreti e altro utilizzando la CLI di orbit. Utilizza questa competenza ogni volta che l'utente chiede informazioni su repository GitHub, PR (richieste pull), esecuzioni del flusso di lavoro di GitHub Actions, rami, tag, commit, problemi, versioni, segreti o repository dell'organizzazione. Attiva frasi come "elenca PR", "controlla le azioni", "guarda il flusso di lavoro", "crea un segreto", "apri una richiesta pull", "visualizza gli ultimi commit", "elenca repository nell'organizzazione X", "riesegui il flusso di lavoro", "chiudi il problema", "ultima versione", "imposta un segreto GitHub" o qualsiasi attività correlata a GitHub, anche riferimenti casuali come "cosa è in esecuzione" in CI', 'mostrami i PR', 'tagga una versione', 'controlla se è stata unita', 'elenca repository', 'la build sta passando' o 'aggiungi un segreto della chiave di distribuzione'. Si attiva anche quando l'utente desidera monitorare l'avanzamento CI/CD, gestire i segreti delle azioni per le distribuzioni o eseguire il debug di flussi di lavoro non riusciti. L'alias della CLI dell'orbita è "gh".
