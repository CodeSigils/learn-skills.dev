قم بإنشاء وإدارة مستودعات GitHub، وسحب الطلبات، والإصدارات، والفروع، والأسرار، والمزيد باستخدام Orbit CLI. استخدم هذه المهارة عندما يسأل المستخدم عن مستودعات GitHub، أو PRs (طلبات السحب)، أو تشغيل سير عمل GitHub Actions، أو الفروع، أو العلامات، أو الالتزامات، أو المشكلات، أو الإصدارات، أو الأسرار، أو مستودعات المؤسسة. قم بتشغيل عبارات مثل "قائمة العلاقات العامة"، "التحقق من الإجراءات"، "مشاهدة سير العمل"، "إنشاء سر"، "فتح طلب سحب"، "عرض أحدث الالتزامات"، "قائمة عمليات إعادة الشراء في org X"، "إعادة تشغيل سير العمل"، "إغلاق المشكلة"، "أحدث إصدار"، "تعيين سر GitHub"، أو أي مهمة ذات صلة بـ GitHub - حتى المراجع العرضية مثل "ما الذي يتم تشغيله في CI"، "أرني" العلاقات العامة"، أو "وضع علامة على الإصدار"، أو "التحقق من دمجه"، أو "إعادة عرض القائمة"، أو "هل تم تمرير البناء"، أو "إضافة سر مفتاح النشر". يتم التشغيل أيضًا عندما يريد المستخدم مراقبة تقدم CI/CD، أو إدارة أسرار الإجراءات لعمليات النشر، أو تصحيح أخطاء سير العمل الفاشلة. الاسم المستعار لـ CLI للمدار هو `gh`.
