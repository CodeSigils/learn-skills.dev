Interactúe con Jira utilizando la CLI de Orbit para crear, enumerar, ver, editar y realizar transiciones de problemas, administrar sprints y epopeyas, administrar campos personalizados y configuraciones de pantalla, enumerar estados y tipos de problemas, y escribir descripciones con el formato adecuado utilizando el marcado wiki de Jira. Utilice esta habilidad siempre que el usuario pregunte sobre tareas, tickets, problemas, sprints, épicos o necesidades de Jira para gestionar elementos de trabajo del proyecto mediante órbita. También se activa cuando el usuario dice cosas como "crear un ticket", "crear épicas", "mover esto a listo", "asignar el problema", "actualizar la descripción", "formatear para Jira", "crear un campo personalizado", "agregar campo a la pantalla", "enumerar estados", "configurar Jira" o cualquier flujo de trabajo relacionado con Jira; incluso referencias casuales como "actualizar Jira", "qué tickets hay en este sprint", "agregar un comentario". a PROJ-123', o 'configurar campos de seguimiento de IA'. Se activa especialmente cuando las descripciones necesitan un formato adecuado (encabezados, viñetas, tablas, enlaces), ya que Jira Server utiliza marcas wiki, no rebajas.
