تفاعل مع Jira باستخدام Orbit CLI لإنشاء المشكلات وإدراجها وعرضها وتحريرها وانتقالها، وإدارة الدورات السريعة والملاحم، وإدارة الحقول المخصصة وتكوينات الشاشة، وقائمة الحالات وأنواع المشكلات، وكتابة أوصاف منسقة بشكل صحيح باستخدام ترميز Jira wiki. استخدم هذه المهارة عندما يسأل المستخدم عن مهام Jira أو التذاكر أو المشكلات أو السباقات السريعة أو الملاحم أو يحتاج إلى إدارة عناصر عمل المشروع باستخدام المدار. يتم التشغيل أيضًا عندما يقول المستخدم أشياء مثل "إنشاء تذكرة"، أو "إنشاء ملاحم"، أو "نقل هذا إلى تنفيذه"، أو "تعيين المشكلة"، أو "تحديث الوصف"، أو "تنسيق Jira"، أو "إنشاء حقل مخصص"، أو "إضافة حقل إلى الشاشة"، أو "حالات القائمة"، أو "تكوين Jira"، أو أي سير عمل متعلق بـ Jira - حتى الإشارات غير الرسمية مثل "تحديث Jira"، أو "ما هي التذاكر الموجودة في هذا السباق"، أو "إضافة تعليق إلى" PROJ-123، أو "إعداد حقول تتبع الذكاء الاصطناعي". يتم تشغيله بشكل خاص عندما تحتاج الأوصاف إلى تنسيق مناسب (العناوين والتعداد النقطي والجداول والروابط) نظرًا لأن Jira Server يستخدم علامة wiki، وليس تخفيض السعر.
