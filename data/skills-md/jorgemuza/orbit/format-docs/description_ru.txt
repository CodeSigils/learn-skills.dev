Отформатируйте и реструктурируйте документы с уценкой, чтобы они могли без проблем публиковаться в Confluence с помощью функции публикации orbit confluence. Используйте этот навык всякий раз, когда пользователь хочет подготовить документы для Confluence, исправить форматирование уценки для публикации вики, добавить вступительную часть к документам, реструктурировать каталог документов или убедиться, что файлы уценки соответствуют соглашениям, дружественным к Confluence. Также срабатывает, когда пользователь говорит такие вещи, как «отформатировать эти документы», «подготовить документы для Confluence», «исправить заголовок», «реструктурировать папку с документами», «сделать эти документы доступными для публикации», «очистить уценку» или любую задачу, связанную с подготовкой уценки к Confluence — даже если они просто говорят «отформатировать это» или «подготовиться к вики», не упоминая Confluence явно. Если у пользователя есть каталог docs/ и он упоминает публикацию или синхронизацию, этот навык применим.
