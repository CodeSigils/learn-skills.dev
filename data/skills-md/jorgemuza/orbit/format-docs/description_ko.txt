마크다운 문서의 형식을 지정하고 재구성하여 'orbit confluence 게시'를 통해 Confluence에 깔끔하게 게시할 수 있습니다. 사용자가 Confluence용 문서를 준비하고, Wiki 게시를 위한 마크다운 형식을 수정하고, 문서에 머리말을 추가하고, docs 디렉터리를 재구성하거나, 마크다운 파일이 Confluence 친화적인 규칙을 따르도록 하고 싶을 때마다 이 기술을 사용하세요. 또한 사용자가 '이 문서 형식 지정', 'Confluence용 문서 준비', '머리말 수정', '문서 폴더 재구성', '이 문서를 게시 가능하게 설정', '마크다운 정리' 또는 Markdown을 Confluence 지원으로 만드는 것과 관련된 모든 작업을 말할 때에도 트리거됩니다. Confluence를 명시적으로 언급하지 않고 '이 형식 지정' 또는 'wiki 준비'라고만 말하는 경우에도 마찬가지입니다. 사용자에게 docs/ 디렉토리가 있고 게시 또는 동기화를 언급하는 경우 이 기술이 적용됩니다.
