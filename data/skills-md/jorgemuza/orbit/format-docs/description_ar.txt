قم بتنسيق مستندات تخفيض السعر وإعادة هيكلتها بحيث يتم نشرها بشكل نظيف على Confluence عبر "نشر التقاء المدار". استخدم هذه المهارة عندما يريد المستخدم إعداد المستندات لـ Confluence، أو إصلاح تنسيق تخفيض السعر لنشر wiki، أو إضافة مادة أمامية إلى المستندات، أو إعادة هيكلة دليل المستندات، أو التأكد من أن ملفات تخفيض السعر تتبع اصطلاحات ملائمة لـ Confluence. يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "تنسيق هذه المستندات"، أو "إعداد المستندات لـ Confluence"، أو "إصلاح المادة الأمامية"، أو "إعادة هيكلة مجلد المستندات"، أو "جعل هذه المستندات قابلة للنشر"، أو "تنظيف العلامة" أو أي مهمة تتضمن جعل علامة التخفيض جاهزة لـ Confluence - حتى لو قالوا فقط "تنسيق هذا" أو "الإعداد لـ wiki" دون ذكر Confluence صراحةً. إذا كان لدى المستخدم دليل المستندات/ وذكر النشر أو المزامنة، فسيتم تطبيق هذه المهارة.
