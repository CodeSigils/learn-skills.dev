Formatee y reestructure los documentos de rebajas para que se publiquen limpiamente en Confluence a través de "publicación en órbita y confluencia". Utilice esta habilidad siempre que el usuario quiera preparar documentos para Confluence, corregir el formato de rebajas para la publicación wiki, agregar material preliminar a los documentos, reestructurar un directorio de documentos o asegurarse de que los archivos de rebajas sigan las convenciones compatibles con Confluence. También se activa cuando el usuario dice cosas como "formatear estos documentos", "preparar documentos para Confluence", "arreglar el tema principal", "reestructurar la carpeta de documentos", "hacer que estos documentos sean publicables", "limpiar el descuento" o cualquier tarea que implique preparar el descuento para Confluence, incluso si simplemente dicen "formatear esto" o "preparar para wiki" sin mencionar Confluence explícitamente. Si el usuario tiene un directorio docs/ y menciona publicar o sincronizar, se aplica esta habilidad.
