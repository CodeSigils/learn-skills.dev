Formatta e ristruttura i documenti di markdown in modo che vengano pubblicati in modo pulito su Confluence tramite "pubblicazione di confluenza in orbita". Utilizza questa competenza ogni volta che l'utente desidera preparare documenti per Confluence, correggere la formattazione del markdown per la pubblicazione wiki, aggiungere frontmatter ai documenti, ristrutturare una directory di documenti o garantire che i file markdown seguano le convenzioni compatibili con Confluence. Si attiva anche quando l'utente dice cose come "formatta questi documenti", "prepara documenti per Confluence", "correggi il frontmatter", "ristruttura la cartella dei documenti", "rendi questi documenti pubblicabili", "ripulisci il markdown" o qualsiasi attività che implichi rendere il markdown pronto per Confluence, anche se dice semplicemente "formatta questo" o "prepara wiki" senza menzionare esplicitamente Confluence. Se l'utente ha una directory docs/ e menziona la pubblicazione o la sincronizzazione, si applica questa competenza.
