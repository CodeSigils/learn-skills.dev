إدارة صفحات التقاء باستخدام واجهة سطر الأوامر للمدار - إنشاء أدلة تخفيض السعر وتحديثها وعرضها ونشرها والتحكم في عرض الصفحة. استخدم هذه المهارة عندما يسأل المستخدم عن صفحات Confluence، أو محتوى wiki، أو نشر الوثائق، أو تحميل تخفيض السعر إلى Confluence، أو مزامنة المستندات، أو إدارة التسلسلات الهرمية للصفحات باستخدام المدار. قم بتشغيل عبارات مثل "إنشاء صفحة Confluence"، أو "تحديث wiki"، أو "نشر هذه المستندات إلى Confluence"، أو "تحميل تخفيض السعر"، أو "تعيين عرض الصفحة"، أو "عرض الصفحة"، أو "إدراج الصفحات الفرعية"، أو أي مهمة ذات صلة بـ Confluence - حتى الإشارات غير الرسمية مثل "ادفع هذا إلى Confluence"، أو "مزامنة المستندات"، أو "التحقق من الصفحات الموجودة أسفل X". يتم تشغيله أيضًا عندما يحتاج المستخدم إلى تحويل تخفيض السعر إلى تنسيق تخزين Confluence أو يريد تتبع ملفات تخفيض السعر التي تعين صفحات Confluence عبر البيانات التعريفية الأمامية (confluence_page_id، confluence_url).
