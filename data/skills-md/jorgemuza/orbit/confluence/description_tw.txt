使用 Orbit CLI 管理 Confluence 頁面 — 建立、更新、檢視、發佈 Markdown 目錄以及控制頁面寬度。每當使用者詢問 Confluence 頁面、wiki 內容、發佈文件、將 Markdown 上傳到 Confluence、同步文件或使用 Orbit 管理頁面層次結構時，請使用此技能。諸如「建立 Confluence 頁面」、「更新 wiki」、「將這些文件發佈到 Confluence」、「上傳 markdown」、「設定頁面寬度」、「檢視頁面」、「列出子頁面」或任何 Confluence 相關任務等短語，甚至是諸如「將其推送到 Confluence」、「同步文件」或「檢查 X 隨意下的頁面」等觸發。當使用者需要將 markdown 轉換為 Confluence 儲存格式或想要透過 frontmatter 元資料（confluence_page_id、confluence_url）追蹤哪些 markdown 檔案對應到哪些 Confluence 頁面時也會觸發。
