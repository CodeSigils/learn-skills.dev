使用 Orbit CLI 管理 Confluence 页面 — 创建、更新、查看、发布 Markdown 目录以及控制页面宽度。每当用户询问 Confluence 页面、wiki 内容、发布文档、将 Markdown 上传到 Confluence、同步文档或使用 Orbit 管理页面层次结构时，请使用此技能。触发诸如“创建 Confluence 页面”、“更新 wiki”、“将这些文档发布到 Confluence”、“上传 markdown”、“设置页面宽度”、“查看页面”、“列出子页面”或任何 Confluence 相关任务等短语，甚至是诸如“将其推送到 Confluence”、“同步文档”或“检查 X 下的页面”等随意引用。当用户需要将 markdown 转换为 Confluence 存储格式或想要通过 frontmatter 元数据（confluence_page_id、confluence_url）跟踪哪些 markdown 文件映射到哪些 Confluence 页面时也会触发。
