Gestisci le pagine Confluence utilizzando la CLI di orbit: crea, aggiorna, visualizza, pubblica directory di markdown e controlla la larghezza della pagina. Utilizza questa abilità ogni volta che l'utente chiede informazioni sulle pagine Confluence, sul contenuto wiki, sulla pubblicazione di documentazione, sul caricamento di markdown su Confluence, sulla sincronizzazione di documenti o sulla gestione delle gerarchie di pagine utilizzando Orbit. Attiva frasi come "crea una pagina Confluence", "aggiorna la wiki", "pubblica questi documenti su Confluence", "carica markdown", "imposta larghezza pagina", "visualizza pagina", "elenca pagine secondarie" o qualsiasi attività correlata a Confluence, anche riferimenti casuali come "invia questo a Confluence", "sincronizza i documenti" o "controlla quali pagine sono sotto X". Si attiva anche quando l'utente deve convertire il markdown nel formato di archiviazione Confluence o desidera tenere traccia di quali file markdown vengono mappati a quali pagine Confluence tramite metadati frontmatter (confluence_page_id, confluence_url).
