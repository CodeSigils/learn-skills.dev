Gérez les référentiels Bitbucket, les demandes d'extraction, les branches, les balises, les validations et les projets à l'aide de l'Orbit CLI. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur les dépôts Bitbucket, les PR (pull request), les branches, les balises, les validations, la révision de code ou la gestion de projet sur Bitbucket Server/Data Center ou Bitbucket Cloud. Déclenchez des expressions telles que "lister les PR", "afficher les demandes d'extraction", "créer une branche", "ouvrir un PR", "afficher les derniers commits", "lister les dépôts dans le projet X", "fusionner le PR", "refuser le PR", "vérifier l'activité des PR", ou toute tâche liée à Bitbucket - même des références occasionnelles comme "quels PR sont ouverts", "montrez-moi les dépôts", "étiqueter une version", "vérifier si elle fusionné », « qui l'a approuvé » ou « liste des succursales ». Se déclenche également lorsque l'utilisateur fournit une URL de serveur Bitbucket (par exemple, https://git.example.com/projects/PROJ/repos/my-repo/) ou mentionne Bitbucket Data Center. L'alias CLI de l'orbite est « bb ».
