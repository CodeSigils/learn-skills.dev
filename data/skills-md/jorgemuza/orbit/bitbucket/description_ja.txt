orbit CLI を使用して、Bitbucket リポジトリ、プル リクエスト、ブランチ、タグ、コミット、プロジェクトを管理します。ユーザーが Bitbucket リポジトリ、PR (プル リクエスト)、ブランチ、タグ、コミット、コード レビュー、または Bitbucket Server/Data Center または Bitbucket Cloud 上のプロジェクト管理について質問するたびに、このスキルを使用します。 「PR を一覧表示する」、「プル リクエストを表示する」、「ブランチを作成する」、「PR を開く」、「最新のコミットを表示する」、「プロジェクト X のリポジトリを一覧表示する」、「PR をマージする」、「PR を拒否する」、「PR アクティビティを確認する」などのフレーズ、または Bitbucket 関連のタスクをトリガーします。「開いている PR を表示する」、「リポジトリを表示する」、「タグを付ける」などのカジュアルな参照も含まれます。リリース」、「マージしたかどうかの確認」、「承認者」、または「ブランチのリスト」。また、ユーザーが Bitbucket Server URL (例: https://git.example.com/projects/PROJ/repos/my-repo/) を指定するか、Bitbucket Data Center に言及したときにもトリガーされます。 orbit CLI のエイリアスは「bb」です。
