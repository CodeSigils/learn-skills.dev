Administre repositorios de Bitbucket, solicitudes de extracción, ramas, etiquetas, confirmaciones y proyectos utilizando la CLI de orbit. Utilice esta habilidad siempre que el usuario pregunte sobre repositorios de Bitbucket, PR (solicitudes de extracción), ramas, etiquetas, confirmaciones, revisión de código o gestión de proyectos en Bitbucket Server/Data Center o Bitbucket Cloud. Active frases como "enumerar PR", "mostrar solicitudes de extracción", "crear una rama", "abrir un PR", "ver las últimas confirmaciones", "enumerar repositorios en el proyecto X", "fusionar el PR", "rechazar el PR", "verificar la actividad del PR", o cualquier tarea relacionada con Bitbucket; incluso referencias casuales como "qué PR están abiertos", "muéstrame los repositorios", "etiquetar una versión", "comprobar si se fusionó", "quién lo aprobó". o 'listar ramas'. También se activa cuando el usuario proporciona una URL del servidor Bitbucket (por ejemplo, https://git.example.com/projects/PROJ/repos/my-repo/) o menciona el Centro de datos de Bitbucket. El alias de la CLI de órbita es "bb".
