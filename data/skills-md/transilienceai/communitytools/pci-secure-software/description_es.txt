Evaluación automatizada de brechas de preparación de PCI Secure Software Standard (SSS) v2.0 de una aplicación a partir de su código fuente y documentación. Enumera de manera determinista todos los requisitos de prueba aplicables de un catálogo fijado, recopila evidencia de fuente/documento y emite un veredicto por requisito vinculado a evidencia (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) con citas de archivo+línea, luego un informe de brecha de Transilience. Úselo cuando se le solicite evaluar, evaluar deficiencias o verificar la preparación de una aplicación con respecto al estándar de software seguro PCI v2.0/PCI SSF, o para asignar el código fuente y los documentos de diseño a los objetivos de seguridad y requisitos de prueba de PCI SSS. Produce únicamente un análisis de brechas de preparación, NO una validación oficial de PCI.
