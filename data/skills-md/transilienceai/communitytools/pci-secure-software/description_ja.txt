ソース コードとドキュメントからアプリケーションの PCI Secure Software Standard (SSS) v2.0 対応ギャップ評価を自動化します。ピン留めされたカタログから該当するすべてのテスト要件を決定的に列挙し、ソース/ドキュメントの証拠を収集し、ファイルと行の引用を含む証拠に基づいた要件ごとの判定 (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) を出力し、トランジリエンス ギャップ レポートを生成します。 PCI セキュア ソフトウェア スタンダード v2.0 / PCI SSF に対するアプリケーションの準備状況を評価、ギャップ評価、チェックする場合、またはソース コードと設計ドキュメントを PCI SSS セキュリティ目標とテスト要件にマッピングする場合に使用します。公式の PCI 検証ではなく、準備ギャップ分析のみを生成します。
