Автоматизированная оценка готовности приложения по стандарту PCI Secure Software Standard (SSS) v2.0 на основе его исходного кода и документации. Детерминистически перечисляет все применимые требования к тестированию из закрепленного каталога, собирает доказательства из источников/документов и выдает обоснованный вердикт для каждого требования (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) с цитатами из файла и строки, а затем отчет о пробелах в обеспечении устойчивости. Используйте, когда вас просят оценить, проверить наличие пробелов или проверить готовность приложения на соответствие стандарту PCI Secure Software v2.0/PCI SSF или сопоставить исходный код и проектную документацию с целями безопасности и требованиями тестирования PCI SSS. Производит только анализ пробелов в готовности, а НЕ официальную проверку PCI.
