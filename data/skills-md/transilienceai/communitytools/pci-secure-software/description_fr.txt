Évaluation automatisée des écarts de préparation à la norme PCI Secure Software Standard (SSS) v2.0 d'une application à partir de son code source et de sa documentation. Énumère de manière déterministe toutes les exigences de test applicables à partir d'un catalogue épinglé, rassemble des preuves source/document et émet un verdict par exigence lié aux preuves (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) avec des citations de fichier + ligne, puis un rapport d'écart de transilience. À utiliser lorsqu'on vous le demande pour évaluer, évaluer les lacunes ou vérifier l'état de préparation d'une application par rapport à la norme PCI Secure Software Standard v2.0 / PCI SSF, ou pour mapper le code source et les documents de conception aux objectifs de sécurité et aux exigences de test PCI SSS. Produit uniquement une analyse des écarts de préparation – PAS une validation PCI officielle.
