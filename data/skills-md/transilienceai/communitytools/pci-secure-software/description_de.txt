Automatisierte PCI Secure Software Standard (SSS) v2.0 Bereitschafts‑Lückenbewertung einer Anwendung anhand ihres Quellcodes und ihrer Dokumentation. Enumeriert deterministisch jede anwendbare Testanforderung aus einem festgelegten Katalog, sammelt Quell‑/Dokumenten‑Belege und gibt ein beweisgebundenes Urteil pro Anforderung aus (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) mit Datei‑+Zeilenangaben, anschließend einen Transilience‑Lückenbericht. Verwenden Sie dies, wenn Sie gebeten werden, die Bereitschaft einer Anwendung gegenüber dem PCI Secure Software Standard v2.0 / PCI SSF zu bewerten, eine Lücken‑Assessment durchzuführen oder zu prüfen, oder um Quellcode und Designdokumente den PCI SSS Sicherheitszielen und Testanforderungen zuzuordnen. Liefert ausschließlich eine Bereitschafts‑Lückenanalyse — KEINE offizielle PCI‑Validierung.
