Valutazione automatizzata delle lacune di preparazione al PCI Secure Software Standard (SSS) v2.0 di un'applicazione dal codice sorgente e dalla documentazione. Enumera in modo deterministico ogni requisito di test applicabile da un catalogo bloccato, raccoglie prove di origine/documento ed emette un verdetto per requisito vincolato all'evidenza (MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW) con citazioni di file+riga, quindi un rapporto sul gap di transitorietà. Da utilizzare quando richiesto per valutare, valutare le lacune o verificare l'idoneità di un'applicazione rispetto allo standard PCI Secure Software v2.0/PCI SSF oppure per mappare il codice sorgente e progettare documenti sugli obiettivi di sicurezza e sui requisiti di test PCI SSS. Produce solo un'analisi delle lacune di preparazione, NON una convalida PCI ufficiale.
