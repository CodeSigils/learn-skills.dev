소스 코드 및 문서를 통해 애플리케이션의 자동화된 PCI 보안 소프트웨어 표준(SSS) v2.0 준비 상태 격차를 평가합니다. 고정된 카탈로그에서 적용 가능한 모든 테스트 요구 사항을 결정적으로 열거하고, 소스/문서 증거를 수집하고, 파일+라인 인용을 통해 증거 바인딩된 요구 사항별 평결(MET / NOT_MET / PARTIALLY_MET / NOT_APPLICABLE / REQUIRES_MANUAL_REVIEW)을 내보낸 다음 Transilience 격차 보고서를 내보냅니다.
