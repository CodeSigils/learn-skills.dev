Acquérir une session authentifiée VIA MFA/OTP sur une cible dans le champ d'application et émettre un artefact de session réutilisable (Playwright storageState + Bearer) afin que les exécuteurs puissent tester la surface d'attaque post-authentification. À utiliser lorsque les classes authentifiées de valeur la plus élevée (BOLA/IDOR/affectation de masse/injection sur les API de données réelles) sont bloquées car la connexion est sécurisée par SMS-OTP ou TOTP MFA. Distinct de la compétence d'authentification (qui ATTAQUE l'authentification) ; celui-ci authentifie légitimement et transmet la séance au reste de l'engagement.
