Revisión de código fuente centrado en seguridad y SAST. Explora vulnerabilidades (OWASP Top 10, CWE Top 25), CVE en dependencias/paquetes de terceros, secretos codificados, códigos maliciosos y patrones inseguros. Úselo cuando se le proporcione el código fuente, una ruta de repositorio o se le solicite "auditar", "escanear", "revisar" la seguridad del código o "verificar las dependencias de CVE".
