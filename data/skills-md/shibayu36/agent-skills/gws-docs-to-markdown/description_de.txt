Generieren Sie eine Markdown-Datei aus einer Google Docs-URL und extrahieren Sie eingebettete Bilder als lokale Dateien. Für Anfragen wie „Lesen Sie dieses Google-Dokument“ oder „Laden Sie dieses Dokument“ verwenden. Führt ein Bash-Skript aus, um die Markdown- und Bilddateien zu generieren, und liest sie dann mit dem Lesetool.
