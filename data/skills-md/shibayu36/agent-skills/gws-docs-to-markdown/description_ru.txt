Создайте файл Markdown из URL-адреса Документов Google и извлеките встроенные изображения как локальные файлы. Используйте для таких запросов, как «прочитать этот документ Google» или «загрузить этот документ». Запускает сценарий Bash для создания файлов Markdown и изображений, а затем считывает их с помощью инструмента чтения.
