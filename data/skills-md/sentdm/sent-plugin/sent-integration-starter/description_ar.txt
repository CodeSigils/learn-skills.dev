يدعم تكامل Sent v3 الجاهز للإنتاج في قاعدة تعليمات برمجية موجودة - اختيار SDK وإنشاء العميل، وتكوين مفتاح x-api، وعمليات الإرسال غير الفعالة، وإعادة المحاولة والتعامل مع حد المعدل، وكتالوج الأخطاء المكون من 46 رمزًا، والتحقق من وضع الحماية، وجهاز استقبال خطاف الويب الذي تم التحقق منه. يُستخدم عند إضافة العناصر المرسلة إلى تطبيق لأول مرة، أو اختيار SDK أو أسلاك إطار العمل، أو التعامل مع استجابات 429 أو 409، أو تحديد ما سيتم تسجيله، أو تقوية التكامل قبل الإطلاق.
