Presenta una integración de Sent v3 lista para producción en una base de código existente: selección de SDK y construcción de cliente, configuración de clave x-api, envíos idempotentes, reintento y manejo de límite de velocidad, catálogo de errores de 46 códigos, verificación de espacio aislado y un receptor de webhook verificado. Úselo al agregar Sent a una aplicación por primera vez, elegir un SDK o cableado de marco, manejar respuestas 429 o 409, decidir qué registrar o reforzar una integración antes del lanzamiento.
