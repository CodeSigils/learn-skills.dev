يحلل تسليم الرسائل المرسلة، وخطاف الويب، وبيانات النشاط لشرح حالات انقطاع مسار التحويل، وفشل التسليم، وفجوات معدل القراءة، وتراجع القناة، وتغييرات الأداء المشبوهة. يُستخدم عندما يقول المستخدم MDR، أو تقرير التسليم، أو نشاط الرسالة، أو حدث الرد التلقائي على الويب، أو الرسائل الفاشلة، أو معدل التسليم المنخفض، أو احتياطي RCS، أو معدل قراءة WhatsApp، أو تصفية الرسائل القصيرة، أو أداء الحملة، أو يسأل عن سبب عدم وصول الرسائل.
