ينفذ دورة حياة ملف تعريف المرسل عبر واجهة برمجة التطبيقات - إنشاء ملفات تعريف مع خيارات الميراث والمشاركة والفوترة وWhatsApp الصحيحة، وإكمال ملف التعريف ورد الاتصال به، وإدارة حملات 10DLC لكل ملف تعريف، وإدارة المستخدمين والأدوار. يُستخدم عند الاتصال بـ POST /v3/profiles، أو التعامل مع رد الاتصال المكتمل أو حالة الملف الشخصي غير الواضحة، أو اختيار الموارد الموروثة أو المخصصة، أو توصيل الأسلاك لكل مستأجر، أو دعوة المستخدمين وإدارة الأدوار.
