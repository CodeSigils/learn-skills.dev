CLI для загрузки пакетов npm, пакетов PyPI, ящиков или исходного кода репозитория GitHub в node_modules/.gitchamber/ для анализа. Используйте, когда вам нужно прочитать внутреннюю работу пакета, документацию, примеры или исходный код. Альтернатива opensrc, которая хранится в node_modules/ для совместимости с gitignore/vitest/tsc без конфигурации. После получения проанализируйте файлы с помощью grep, read и других инструментов.
