CLI per scaricare pacchetti npm, pacchetti PyPI, crate o codice sorgente del repository GitHub in node_modules/.gitchamber/ per l'analisi. Da utilizzare quando è necessario leggere il funzionamento interno, la documentazione, gli esempi o il codice sorgente di un pacchetto. Alternativa a opensrc che memorizza in node_modules/ per compatibilità gitignore/vitest/tsc con configurazione zero. Dopo il recupero, analizza i file con grep, read e altri strumenti.
