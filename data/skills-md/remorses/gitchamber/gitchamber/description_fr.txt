CLI pour télécharger les packages npm, les packages PyPI, les caisses ou le code source du dépôt GitHub dans node_modules/.gitchamber/ pour analyse. À utiliser lorsque vous avez besoin de lire le fonctionnement interne, la documentation, les exemples ou le code source d'un package. Alternative à opensrc qui stocke dans node_modules/ pour une compatibilité gitignore/vitest/tsc sans configuration. Après la récupération, analysez les fichiers avec grep, read et d'autres outils.
