CLI para descargar paquetes npm, paquetes PyPI, cajas o código fuente de repositorio de GitHub en node_modules/.gitchamber/ para su análisis. Úselo cuando necesite leer el funcionamiento interno, la documentación, los ejemplos o el código fuente de un paquete. Alternativa a opensrc que se almacena en node_modules/ para compatibilidad con gitignore/vitest/tsc de configuración cero. Después de recuperarlos, analice los archivos con grep, read y otras herramientas.
