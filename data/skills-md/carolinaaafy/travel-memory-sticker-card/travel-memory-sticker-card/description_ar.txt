قم بتحويل صورة تم تحميلها من قبل المستخدم إلى بطاقة ذاكرة أفقية واحدة قابلة للتحصيل مع رسم توضيحي تحريري كبير هادئ، وستة أشكال ملصقة يومية مدمجة، وثلاث كلمات رئيسية إنجليزية صغيرة أسفل الرسم التوضيحي الأيسر، وحبيبات الورق الملموسة، وحقول الألوان المسطحة الخرقاء عن عمد. استخدمه عندما يحتاج Codex إلى تعديل أو تحرير أو إعادة رسم أو تصميم أو تحويل صورة السفر أو الشارع أو المناظر الطبيعية أو نمط الحياة أو الصورة الشخصية أو صورة الحيوانات الأليفة إلى بطاقة بريدية بسيطة أو بطاقة لاصقة بهذه اللغة المرئية. الحفاظ على التعرف من خلال مرساة تعريف واحدة للوسيط نفسه واختياريًا نصًا محددًا محددًا للمكان يظهر مرة واحدة؛ لا تحتفظ أبدًا بأي رقعة أو توقيع أو علامة مائية غير مقصودة.
