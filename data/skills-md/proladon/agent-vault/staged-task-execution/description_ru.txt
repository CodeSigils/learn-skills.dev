Используйте, когда требования или объем изменений велики, сложны или охватывают несколько файлов/компонентов. Создает папку temp/session с Tasks.md (атомарная разбивка задач) и Progress.md (отслеживание контекста), затем выполняет одну задачу за раз с подтверждением пользователя между каждым шагом. Используется для: реализации крупных функций, многокомпонентного рефакторинга, сложных многошаговых исправлений ошибок, работ по миграции или любого запроса, который включает более 2–3 независимых изменений. Триггерные фразы: шаг за шагом, поэтапно, по одному, не торопиться, большая функция, большое изменение, 分步執行, 逐步完成, 一步一步, 分階段, 大功能, 大改動,不要一次做完, 慢慢來, 確認後再繼續, 按步驟. Фразы для возобновления: продолжить с того места, где мы остановились, возобновить, продолжить с последнего задания, 繼續上次, 繼續執行, 繼續做, 從上次繼續, 接著做
