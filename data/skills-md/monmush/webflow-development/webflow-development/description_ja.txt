Webflow MCP Bridge とブラウザ自動化を使用して、Webflow Designer で Web サイトを構築し、スタイルを設定します。ユーザーが次のことを行う場合に使用します: (1) Webflow でページ/セクション/要素を作成またはスタイルする、(2) ローカル Web プロジェクト (React、HTML/CSS、Next.js など) を Webflow に転送する、(3) Webflow で Figma デザインを実装する、(4) Webflow でスタイルまたはレイアウトの問題を修正する、(5) Webflow コンポーネント、変数、または CMS コレクションを作成または管理する、(6) Webflow で応答性の高いブレークポイントを操作する、(7) カスタムを追加するSVG、アニメーション、または複雑なレイアウトのコード (コード埋め込み)、または (8) Webflow サイトの公開と QA。ユーザーが「Webflow」、「Webflow デザイナー」、「MCP ブリッジ」に言及したとき、または Webflow ツールを使用して Web ページの構築/スタイルを要求したときにトリガーされます。
