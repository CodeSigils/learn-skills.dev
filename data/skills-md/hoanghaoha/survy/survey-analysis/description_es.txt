Utilice esta habilidad siempre que el usuario quiera trabajar con datos de encuestas utilizando la biblioteca Python `survy`. Los desencadenantes incluyen: cargar o leer archivos CSV/Excel/JSON/SPSS de encuestas, manejar preguntas de selección múltiple (opción múltiple), calcular tablas de frecuencia o tablas cruzadas, exportar datos de encuestas a SPSS (.sav) u otros formatos, actualizar etiquetas de variables o índices de valores, transformar datos de encuestas entre formatos anchos/compactos, filtrar encuestados, reemplazar valores, agregar/eliminar/ordenar variables o cualquier tarea que involucre la API de encuestas (read_csv, read_excel, read_json, read_polars, read_spss, crosstab, encuesta["Q1"], to_spss, to_csv, to_excel, to_json, etc.). También se activa cuando el usuario dice cosas como "analizar mi encuesta", "procesar datos del cuestionario", "crear un script de análisis de encuesta" o "ayúdame con la encuesta". Lea siempre esta habilidad antes de escribir cualquier código de encuesta: contiene la API, los patrones y los errores correctos.
