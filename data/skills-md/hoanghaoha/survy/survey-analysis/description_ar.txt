استخدم هذه المهارة عندما يريد المستخدم العمل مع بيانات المسح باستخدام مكتبة `survy` Python. تتضمن المشغلات: تحميل أو قراءة ملفات المسح بتنسيق CSV/Excel/JSON/SPSS، أو التعامل مع أسئلة التحديد المتعدد (الاختيار المتعدد)، أو حساب الجداول التكرارية أو الجداول الترافقية، أو تصدير بيانات الاستطلاع إلى SPSS (.sav) أو تنسيقات أخرى، أو تحديث تسميات المتغيرات أو مؤشرات القيمة، أو تحويل بيانات الاستطلاع بين التنسيقات العريضة/المدمجة، أو تصفية المستجيبين، أو استبدال القيم، أو إضافة/إسقاط/فرز المتغيرات، أو أي مهمة تتضمن واجهة برمجة تطبيقات الاستطلاع (read_csv، read_excel، read_json، read_polars، read_spss، الجدول الترافقي، المسح ["Q1"]، to_spss، to_csv، to_excel، to_json، إلخ.). يتم تشغيله أيضًا عندما يقول المستخدم أشياء مثل "تحليل الاستطلاع الخاص بي" أو "معالجة بيانات الاستبيان" أو "إنشاء برنامج نصي لتحليل الاستطلاع" أو "مساعدتي في الاستطلاع". قم دائمًا بقراءة هذه المهارة قبل كتابة أي كود استقصائي - فهي تحتوي على واجهة برمجة التطبيقات والأنماط والأخطاء الصحيحة.
