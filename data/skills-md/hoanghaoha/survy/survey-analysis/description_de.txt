Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer mithilfe der Python-Bibliothek „survy“ mit Umfragedaten arbeiten möchte. Zu den Auslösern gehören: Laden oder Lesen von CSV-/Excel-/JSON-/SPSS-Umfragedateien, Bearbeiten von Multiselect-Fragen (Multi-Choice), Berechnen von Häufigkeitstabellen oder Kreuztabellen, Exportieren von Umfragedaten nach SPSS (.sav) oder anderen Formaten, Aktualisieren von Variablenbeschriftungen oder Wertindizes, Umwandeln von Umfragedaten zwischen breiten/kompakten Formaten, Filtern von Befragten, Ersetzen von Werten, Hinzufügen/Löschen/Sortieren von Variablen oder jede Aufgabe, die die API von survy (read_csv, read_excel, read_json, read_polars, read_spss, crosstab, Survey["Q1"], to_spss, to_csv, to_excel, to_json usw.). Wird auch ausgelöst, wenn der Benutzer Dinge wie „Analysiere meine Umfrage“, „Fragebogendaten verarbeiten“, „Erstelle ein Skript zur Umfrageanalyse“ oder „Hilf mir bei der Umfrage“ sagt. Lesen Sie diesen Skill immer, bevor Sie Survy-Code schreiben – er enthält die richtige API, Muster und Fallstricke.
