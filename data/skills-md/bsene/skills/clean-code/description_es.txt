Úselo al escribir código nuevo, nombrar módulos/archivos/funciones/clases/variables, revisar o refactorizar código para facilitar la lectura o evaluar/reducir la complejidad de la función. Activa solicitudes como "nombrar esta función", "es este un buen nombre de variable", "revisar esto para obtener un código limpio", "reducir la complejidad", "debería agregar un comentario aquí" o cualquier pase de revisión de código/PR. Cubre convenciones de nomenclatura, presupuestos de complejidad ciclomática (código escrito por humanos o agentes) y disciplina de comentarios. No es una guía de estilo completa: se combina con habilidades específicas del idioma (mecanografiado, go, clojurescript) para cuestiones de sintaxis/modismo.
