Revise las pruebas unitarias existentes según los principios de BDD (desarrollo impulsado por el comportamiento) y proporcione sugerencias de mejora concretas. Utilice esta habilidad siempre que el usuario comparta el código de prueba y solicite una revisión, comentarios o mejoras. También se activa cuando el usuario dice "verificar mis pruebas", "¿son buenas estas pruebas?", "revisar mi conjunto de pruebas", "¿siguen BDD?" o pega el código de prueba en cualquier idioma. Incluso para aprobar pruebas, utilice esta habilidad para auditar la denominación, la estructura y la cobertura de comportamiento; las buenas pruebas casi siempre pueden aclararse más.
