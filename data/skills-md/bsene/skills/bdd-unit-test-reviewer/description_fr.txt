Examinez les tests unitaires existants par rapport aux principes BDD (Behaviour-Driven Development) et fournissez des suggestions d'amélioration concrètes. Utilisez cette compétence chaque fois que l'utilisateur partage le code de test et demande une révision, des commentaires ou des améliorations. Se déclenche également lorsque l'utilisateur dit « vérifier mes tests », « ces tests sont-ils bons ? », « réviser ma suite de tests », « sont-ils conformes à BDD ? » ou colle le code de test dans n'importe quelle langue. Même pour réussir les tests, utilisez cette compétence pour vérifier la couverture de la dénomination, de la structure et du comportement : les bons tests peuvent presque toujours être rendus plus clairs.
