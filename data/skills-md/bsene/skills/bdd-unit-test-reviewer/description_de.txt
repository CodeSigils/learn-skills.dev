Überprüfen Sie bestehende Unit-Tests anhand der BDD-Prinzipien (Behaviour-Driven Development) und machen Sie konkrete Verbesserungsvorschläge. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Testcode teilt und um eine Überprüfung, Feedback oder Verbesserungen bittet. Wird auch ausgelöst, wenn der Benutzer sagt: „Überprüfe meine Tests“, „Sind diese Tests gut?“, „Überprüfe meine Testsuite“, „Folgen diese BDD?“ oder fügt Testcode in einer beliebigen Sprache ein. Selbst wenn Sie Tests bestehen, können Sie diese Fähigkeit nutzen, um Benennung, Struktur und Verhaltensabdeckung zu überprüfen – gute Tests können fast immer klarer gemacht werden.
