Git のベスト プラクティス — コミット規律、分岐/履歴の衛生状態、安全性、CI/CD パイプライン。 「git-guru」 (専門家 Q&A)、「gitmoji」、「gitlab-dag」サブスキルへのルート。
トリガーのタイミング: コミット (従来のコミット、アトミック コミット、コミット メッセージ形式、コミットの衛生状態)、履歴 (ブランチの名前付け、リベースとマージ、クリーンな Git 履歴、インタラクティブなリベース、履歴管理)、安全性 (強制プッシュの安全性、失われたコミットの回復、reflog、リセット)、CI/CD (GitLab CI、パイプラインの最適化、DAG、.gitlab-ci.yml)、絵文字 (gitmoji、コミット)絵文字、「quel emoji pour ce commit」）、セットアップ（git 設定、「bonnes pratiques git」、「comment Faire un rebase」、「git を適切に設定」）。次の場合は使用しないでください: ユーザーが単一のワンショット git コマンド応答を必要とする場合、クロードに直接応答させます。
