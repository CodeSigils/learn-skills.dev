أفضل ممارسات Git - الالتزام بالانضباط، ونظافة التفرع/السجل، والسلامة، وخطوط أنابيب CI/CD. طرق إلى المهارات الفرعية `git-guru` (أسئلة وأجوبة الخبراء)، و`gitmoji`، و`gitlab-dag`.
يتم تشغيله عندما: الالتزامات (الالتزامات التقليدية، الالتزامات الذرية، تنسيق رسالة الالتزام، التزام النظافة)، التاريخ (تسمية الفرع، rebase مقابل الدمج، سجل git النظيف، rebase التفاعلي، إدارة السجل)، الأمان (فرض أمان الدفع، استعادة الالتزامات المفقودة، إعادة التسجيل، إعادة التعيين)، CI/CD (GitLab CI، تحسين خط الأنابيب، DAG، .gitlab-ci.yml)، الرموز التعبيرية (gitmoji، ارتكاب الرموز التعبيرية، "quel emoji pour ce" الالتزام")، الإعداد (تكوين git، "bonnes pratiques git"، "comment faire un rebase"، "configure git بشكل صحيح"). لا تستخدمه عندما: يحتاج المستخدم إلى إجابة واحدة لأمر git - دع كلود يجيب مباشرة.
