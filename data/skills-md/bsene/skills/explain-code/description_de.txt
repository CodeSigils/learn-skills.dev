Erklärt Code mit C4-Modelldiagrammen, Analogien und Schritt-für-Schritt-Anleitungen. Wird verwendet, wenn erklärt wird, wie Code funktioniert, Unterricht über eine Codebasis, Einführung in die Architektur oder wenn der Benutzer fragt: „Wie funktioniert das?“, „Erklären Sie dieses System“, „Führen Sie mich hier durch“, „Was macht dieser Code?“, „Hilf mir, das zu verstehen“, „Zeige mir die Architektur“, „Erkläre diesen Dienst“, „Wie ist dieser strukturiert?“, „Verfolge den Fluss“, „Was passiert, wenn X Y aufruft?“ oder wenn er neu in einer Codebasis ist und Orientierung benötigt. NICHT VERWENDEN, wenn: eine Antwort in einem Satz ausreicht – rufen Sie es nur auf, wenn eine Architekturübersicht, ein Diagramm oder eine schrittweise Code-Anleitung tatsächlich erforderlich ist.
