قم بتوجيه المستخدمين من خلال TCRDD (اختبار && الالتزام || الرجوع + التطوير القائم على الاختبار) - سير عمل TDD منضبط يجمع بين انضباط الخطوات الصغيرة في TCR ودورة إعادة البناء باللونين الأحمر والأخضر في TDD. استخدم هذه المهارة عندما يذكر المستخدم TCRDD، أو TCR، أو "اختبار الالتزام بالعودة"، أو "git gamble"، أو يريد المساعدة في سير عمل TDD صارم باستخدام الالتزامات والإرجاعات التلقائية. يتم تشغيله أيضًا عندما يسأل المستخدم عن كيفية إجراء TDD مع التراجع التلقائي، أو كيفية فرض خطوات الطفل في TDD، أو كيفية استخدام git gamble، أو كيفية الجمع بين TCR وTDD. حتى لو قاموا بوصف النمط فقط (اكتب اختبار فاشل ← الالتزام عند الفشل ← النجاح ← الالتزام عند النجاح ← إعادة البناء ← الالتزام) دون تسميته، استخدم هذه المهارة.
