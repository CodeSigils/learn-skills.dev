TCR의 초기 단계 규율과 TDD의 적-녹-리팩터링 주기를 결합한 규율 있는 TDD 워크플로우인 TCRDD(Test && Commit || Revert + Test Driven Development)를 통해 사용자를 안내합니다. 사용자가 TCRDD, TCR, "테스트 커밋 되돌리기", "git gamble"을 언급하거나 자동 커밋 및 되돌리기를 사용하는 엄격한 TDD 워크플로에 대한 도움을 원할 때마다 이 기술을 사용하세요. 또한 사용자가 자동 ​​롤백으로 TDD를 수행하는 방법, TDD에서 초기 단계를 적용하는 방법, git gamble을 사용하는 방법 또는 TCR과 TDD를 결합하는 방법을 묻는 경우에도 트리거됩니다. 이름을 지정하지 않고 패턴만 설명(실패한 테스트 작성 → 실패 시 커밋 → 통과로 만들기 → 통과 시 커밋 → 리팩터링 → 커밋)하더라도 이 기술을 사용하세요.
