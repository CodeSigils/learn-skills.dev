Guida gli utenti attraverso TCRDD (Test && Commit || Revert + Test Driven Development): un flusso di lavoro TDD disciplinato che combina la disciplina dei piccoli passi di TCR con il ciclo di refactoring rosso-verde di TDD. Utilizza questa abilità ogni volta che un utente menziona TCRDD, TCR, "test commit revert", "git gamble" o desidera aiuto con un rigoroso flusso di lavoro TDD utilizzando commit e ripristini automatici. Si attiva anche quando un utente chiede come eseguire TDD con il rollback automatico, come applicare piccoli passi in TDD, come utilizzare git gamble o come combinare TCR e TDD. Anche se descrivono semplicemente il modello (scrivi un test fallito → esegui il commit in caso di fallimento → fallo passare → esegui il commit in caso di superamento → refactoring → commit) senza nominarlo, usa questa abilità.
