Guíe a los usuarios a través de TCRDD (Test && Commit || Revert + Test Driven Development): un flujo de trabajo TDD disciplinado que combina la disciplina paso a paso de TCR con el ciclo de refactorización rojo-verde de TDD. Utilice esta habilidad siempre que un usuario mencione TCRDD, TCR, "test commit revert", "git gamble" o quiera ayuda con un flujo de trabajo TDD estricto utilizando confirmaciones y reversiones automáticas. También se activa cuando un usuario pregunta cómo hacer TDD con reversión automática, cómo aplicar pequeños pasos en TDD, cómo usar git gamble o cómo combinar TCR y TDD. Incluso si solo describen el patrón (escribir una prueba fallida → confirmar en caso de falla → hacer que pase → confirmar en pasar → refactorizar → confirmar) sin nombrarlo, use esta habilidad.
