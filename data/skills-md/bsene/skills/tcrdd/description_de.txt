Führen Sie Benutzer durch TCRDD (Test && Commit || Revert + Test Driven Development) – einen disziplinierten TDD-Workflow, der die kleine Schrittdisziplin von TCR mit dem Rot-Grün-Refaktorierungszyklus von TDD kombiniert. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer TCRDD, TCR, „Test Commit Revert“, „Git Gamble“ erwähnt oder Hilfe bei einem strengen TDD-Workflow mit automatischen Commits und Reverts benötigt. Wird auch ausgelöst, wenn ein Benutzer fragt, wie man TDD mit automatischem Rollback durchführt, wie man kleine Schritte in TDD erzwingt, wie man Git Gamble verwendet oder wie man TCR und TDD kombiniert. Auch wenn sie nur das Muster beschreiben (einen fehlgeschlagenen Test schreiben → bei Fehlschlag festschreiben → ihn bestehen lassen → bei bestanden festschreiben → umgestalten → festschreiben), ohne es zu benennen, nutzen Sie diese Fähigkeit.
