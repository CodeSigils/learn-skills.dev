Guidez les utilisateurs à travers TCRDD (Test && Commit || Revert + Test Driven Development) — un flux de travail TDD discipliné qui combine la discipline des petits pas de TCR avec le cycle de refactorisation rouge-vert de TDD. Utilisez cette compétence chaque fois qu'un utilisateur mentionne TCRDD, TCR, "test commit revert", "git gamble" ou souhaite obtenir de l'aide avec un flux de travail TDD strict utilisant des validations et des annulations automatiques. Déclenchez également lorsqu'un utilisateur demande comment effectuer du TDD avec une restauration automatique, comment appliquer de petits pas dans TDD, comment utiliser git gamble ou comment combiner TCR et TDD. Même s'ils décrivent simplement le modèle (écrire un test qui échoue → valider en cas d'échec → le faire réussir → valider en cas de réussite → refactoriser → valider) sans le nommer, utilisez cette compétence.
