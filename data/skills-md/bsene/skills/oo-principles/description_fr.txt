Analysez le code TypeScript/JavaScript par rapport aux principes orientés objet de Dave Thomas pour identifier quand les classes doivent être des fonctions utilitaires, quand les structures de données sont sur-conçues et quand les modèles de conception sont inutiles. Aide les développeurs à écrire du code plus simple et plus maintenable en distinguant la véritable conception orientée objet des anti-modèles orientés classe. Se déclenche lorsque les utilisateurs posent des questions sur la conception des classes, souhaitent refactoriser des classes en fonctions, se demandent s'ils ont besoin d'une classe, demandent « est-ce une odeur de code ? », vous montrent du code TypeScript/JavaScript avec des problèmes de conception potentiels ou discutent de modèles tels que les décorateurs, les usines ou la stratégie.
