Mejores prácticas de JavaScript y aplicación de reglas: convenciones de nomenclatura, modismos de sintaxis modernos, manejo de "esto", estructura de módulos, rendimiento de matriz/iteración y capacidad de nulidad. Se aplica a JavaScript simple y es la base sobre la que se basa TypeScript.
DISPARAR cuando: lenguaje (JavaScript, JS, .js, .mjs, .cjs, Node.js, navegador JS, módulos ES, ESM, CommonJS), sintaxis (const/let, desestructuración, literales de plantilla, encadenamiento opcional, fusión nula, funciones de flecha), patrones (este enlace, devolución de llamada, método separado, función pura versus método, importaciones de módulos, archivo barril, index.js), rendimiento (matriz cadenas, filtro().map(), matrices intermedias, ruta activa, presión de GC), nulidad (nulo vs indefinido, ausencia, valor centinela, == verificación nula), denominación (camelCase, PascalCase, kebab-case, prefijo booleano), preguntar (JavaScript idiomático, convenciones JS, mejores prácticas de JS, revisión de código JS). TAMBIÉN SE APLICA a TypeScript: es la base sobre la que se basa TS; cárguelo junto con `typecript` en `.ts`/`.tsx`. Para reglas específicas de tipo (aserciones de tipo `como T`, interfaces, genéricos, modificador de `solo lectura`, `como const`, anotaciones de tipo de retorno), la habilidad `mecanografiado` agrega una guía adicional.
NO UTILIZAR como habilidad principal para preguntas sobre sistemas de tipos (uniones discriminadas, genéricos, `como`, interfaces, estrechamiento) → ruta a `typescript` / `typescript-type-system`; Esta habilidad todavía se aplica debajo para nombrar y modismos JS.
