Лучшие практики JavaScript и соблюдение правил — соглашения об именах, современные синтаксические идиомы, обработка `this`, структура модуля, производительность массива/итерации и возможность обнуления. Применяется к простому JavaScript и является основой, на которой строится TypeScript.
ТРИГГЕР, когда: язык (JavaScript, JS, .js, .mjs, .cjs, Node.js, браузерный JS, модули ES, ESM, CommonJS), синтаксис (const/let, деструктуризация, литералы шаблона, необязательная цепочка, нулевое объединение, стрелочные функции), шаблоны (эта привязка, обратный вызов, отдельный метод, чистая функция против метода, импорт модулей, файл ствола, index.js), производительность (массив цепочки, filter().map(), промежуточные массивы, горячий путь, давление GC), возможность обнуления (нулевое или неопределенное, отсутствие, сторожевое значение, == проверка на нулевое значение), именование (camelCase, PascalCase, kebab-case, логический префикс), спрашивать (идиоматический JavaScript, соглашения JS, лучшие практики JS, проверка кода JS). ТАКЖЕ ПРИМЕНЯЕТСЯ к TypeScript — это основа, на которой строится TS; загрузите его вместе с `typescript` в `.ts`/`.tsx`. Для правил, специфичных для типа (утверждения типа `as T`, интерфейсы, дженерики, модификатор `readonly`, `as const`, аннотации возвращаемого типа) навык `typescript` добавляет руководство сверху.
НЕ ИСПОЛЬЗУЙТЕ в качестве основного навыка для вопросов о системе типов (различаемые объединения, обобщения, `as`, интерфейсы, сужение) → перейдите к `typescript` / `typescript-type-system`; этот навык по-прежнему применим для именования и идиом JS.
