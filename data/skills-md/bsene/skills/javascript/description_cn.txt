JavaScript 最佳实践和规则执行 - 命名约定、现代语法习惯用法、“this”处理、模块结构、数组/迭代性能和可空性。适用于纯 JavaScript，是 TypeScript 构建的基础。
触发条件：语言（JavaScript、JS、.js、.mjs、.cjs、Node.js、浏览器 JS、ES 模块、ESM、CommonJS）、语法（const/let、解构、模板文字、可选链接、无效合并、箭头函数）、模式（此绑定、回调、分离方法、纯函数与方法、模块导入、桶文件、index.js）、性能（数组链、filter().map()、中间数组、热路径、GC 压力）、可空性（null 与未定义、缺席、哨兵值、== null 检查）、命名（camelCase、PascalCase、kebab-case、布尔前缀）、ask（惯用的 JavaScript、JS 约定、JS 最佳实践、JS 代码审查）。也适用于 TypeScript——它是 TS 构建的基础；将其与“typescript”一起加载到“.ts”/“.tsx”上。对于特定于类型的规则（类型断言 `as T`、接口、泛型、`readonly` 修饰符、`as const`、返回类型注释），`typescript` 技能在顶部添加了指导。
不要用作类型系统问题的主要技能（有区别的联合、泛型、“as”、接口、缩小）→ 通往“typescript”/“typescript-type-system”的路线；这个技巧仍然适用于命名和 JS 习惯用法。
