Escriba, revise, depure y configure código y proyectos ClojureScript. Utilícelo cada vez que el usuario mencione ClojureScript, archivos .cljs/.cljc, Shadow-cljs, figwheel, el compilador CLJS, interoperabilidad JS de Clojure, código de UI estilo Reagent/re-frame/Reagent o solicite convertir la lógica JS/TS en ClojureScript. Úselo también para preguntas sobre las opciones del compilador CLJS (:optimizaciones, :main, :npm-deps, :externs, etc.), el consumo de bibliotecas JS/npm de CLJS, mapas fuente, el uso de la biblioteca de cierre de Google o la compatibilidad con la función ^:async/await más reciente. Se activa incluso si el usuario simplemente pega el código CLJS con un error y pregunta "¿qué pasa aquí?" o solicita configurar un nuevo proyecto CLJS. NO lo use para scripts nbb (babashka/nbb), proyectos `nbb.edn` ni nada destinado a ejecutarse a través de `nbb script.cljs`/`npx nbb`; estos tienen una superficie de lenguaje diferente (interpretada por SCI, sin compilador de cierre); usa la habilidad clojurescript-nbb para eso.
