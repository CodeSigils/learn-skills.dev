Écrivez, révisez, déboguer et configurez le code et les projets ClojureScript. Utilisez-le chaque fois que l'utilisateur mentionne ClojureScript, les fichiers .cljs/.cljc, shadow-cljs, figwheel, le compilateur CLJS, l'interopérabilité JS de Clojure, le code d'interface utilisateur Reagent/re-frame/Reagent-style, ou demande de convertir la logique JS/TS en ClojureScript. Utilisez-le également pour des questions sur les options du compilateur CLJS (:optimizations, :main, :npm-deps, :externs, etc.), la consommation des bibliothèques JS/npm de CLJS, les cartes sources, l'utilisation de la bibliothèque de fermeture de Google ou la nouvelle prise en charge de la fonction ^:async/await. Déclenchez même si l'utilisateur colle simplement le code CLJS avec une erreur et demande « qu'est-ce qui ne va pas ici » ou demande de configurer un nouveau projet CLJS. Ne PAS utiliser pour les scripts nbb (babashka/nbb), les projets `nbb.edn` ou tout ce qui est destiné à être exécuté via `nbb script.cljs`/`npx nbb` — ceux-ci ont une surface de langage différente (interprétée par SCI, sans fermeture-compilateur) ; utilisez plutôt la compétence clojurescript-nbb pour ceux-là.
