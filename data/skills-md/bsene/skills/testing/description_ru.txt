Стратегия и философия тестирования — обратная связь по дизайну, аудит качества тестирования, проверка BDD, решения по архитектуре и стратегия тестирования агентов кодирования ИИ.
ЗАПУСКАЕТСЯ, когда: стратегия (стратегия тестирования, подход к тестированию, философия тестирования, методология тестирования, как мне тестировать, какие тесты писать, лучшие практики тестирования), качество (качество теста, нестабильные тесты, нестабильные тесты, медленные тесты, трудно поддерживаемые тесты, антишаблоны тестирования), объем (модульное тестирование против интеграции против e2e, уровни тестирования, архитектура тестирования, сколько тестировать), макетирование (когда использовать макеты, стратегия макетирования, тестовые двойники), обзор (проверьте мой набор тестов, проверьте мой тесты, обзор BDD, требования к тестированию), контекст (тестирование устаревшей кодовой базы, добавление тестов к существующему коду), агенты ИИ (стратегия тестирования кода, сгенерированного ИИ, должен ли ИИ писать свои собственные тесты, могу ли я доверять тестам, написанным ИИ, конвейер многоагентного тестирования, частота TDD для агентов, стратегия тестирования кодирования Vibe). НЕ ИСПОЛЬЗУЙТЕ, когда: пользователю нужна интерактивная частота TDD с красными/зелеными циклами рефакторинга для человека, управляющего клавиатурой — вместо этого используйте `tcrdd`. Если вместо этого за рулем находится агент ИИ, сначала см. «Тестирование с агентами кодирования ИИ» ниже — цикл микрошагов не применяется таким же образом. НЕ ИСПОЛЬЗУЙТЕ, когда: пользователь спрашивает конкретно о дымовых тестах — вместо этого используйте `smoke-tests`.
