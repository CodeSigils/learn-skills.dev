Utilice esta habilidad cuando el usuario quiera investigar un error, defecto, incidente o problema de calidad y encontrar su causa raíz, incluidas solicitudes para ejecutar un análisis de "cinco porqués", escribir una autopsia, hacer un análisis de causa raíz (RCA), descubrir por qué un error llegó a producción o pasó por alto la revisión de código/control de calidad, configurar una rutina de análisis de defectos recurrente o ejecutar una clasificación diaria/semanal de mejora de la calidad (Kaizen). También conocido como método Dantotsu (enfoque de análisis de defectos derivado de Toyota de Sadao Nomura, adaptado para software). Se activa incluso si el usuario no nombra el método explícitamente, p. "por qué este error pasó por la revisión del código", "un cliente informó un error, ayúdeme a analizarlo", "Quiero entender por qué esto sigue sucediendo", "escriba un informe de causa raíz para este defecto" o "ayúdeme a priorizar qué correcciones enviar esta semana".
