يفرض قاعدة واحدة: يجب تقديم كل تغيير في التعليمات البرمجية كفرق موحد (تنسيق `diff -u`) مع 3 أسطر من السياق. لا توجد استثناءات، حتى الخطوط الفردية.
يتم تشغيله عندما: يطلب المستخدم تعديل التعليمات البرمجية - الإصلاح، أو إعادة البناء، أو التحديث، أو الاستبدال، أو التحرير، أو التصحيح، أو التغيير، أو التعديل، أو إعادة التسمية، أو إعادة الكتابة، أو تطبيق التغييرات، أو تعديل هذا، أو تحرير الملف، أو تغيير هذا الرمز، أو يطلب صراحةً فرقًا - "أرني الفرق"، "كفرق موحد"، "ما تغير"، "إظهار التصحيح"، "/show-me-the-code". لا تستخدمه عندما: إنتاج ملف جديد تمامًا من البداية (لا توجد خطوط سياق للاختلاف معها)، أو للاستجابات غير البرمجية مثل الخطط أو التوضيحات أو الهندسة المعمارية أو الرسوم البيانية.
