Erzwingt eine Regel: Jede Codeänderung muss als einheitliches Diff („diff -u“-Format) mit drei Kontextzeilen dargestellt werden. Keine Ausnahmen, nicht einmal Einzeiler.
TRIGGER, wenn: Der Benutzer eine Codeänderung anfordert – reparieren, umgestalten, aktualisieren, ersetzen, bearbeiten, patchen, ändern, optimieren, umbenennen, neu schreiben, Änderungen anwenden, dies ändern, die Datei bearbeiten, diesen Code ändern oder explizit nach einem Diff fragt – „Zeige mir den Diff“, „als einheitlichen Diff“, „was hat sich geändert“, „zeige den Patch“, „/show-me-the-code“. NICHT VERWENDEN, wenn: eine völlig neue Datei von Grund auf erstellt wird (keine Kontextzeilen zum Vergleichen) oder für Nicht-Code-Antworten wie Pläne, Erklärungen, Architektur oder Diagramme.
