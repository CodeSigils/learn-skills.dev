Соблюдает одно правило: каждое изменение кода должно быть представлено как единый файл различий (формат `diff -u`) с 3 строками контекста. Никаких исключений, даже острот.
ТРИГГЕР, когда: пользователь запрашивает модификацию кода — исправление, рефакторинг, обновление, замену, редактирование, исправление, изменение, настройку, переименование, переписывание, применение изменений, модификацию этого, редактирование файла, изменение этого кода или явно запрашивает разницу — «покажи мне разницу», «как унифицированную разницу», «что изменилось», «покажи патч», «/покажи мне код». НЕ ИСПОЛЬЗУЙТЕ при создании совершенно нового файла с нуля (без строк контекста, с которыми можно было бы сравнивать) или для ответов, не связанных с кодом, таких как планы, пояснения, архитектура или диаграммы.
