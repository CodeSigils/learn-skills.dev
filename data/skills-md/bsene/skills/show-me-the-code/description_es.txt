Hace cumplir una regla: cada cambio de código debe presentarse como una diferencia unificada (formato `diff -u`) con 3 líneas de contexto. Sin excepciones, ni siquiera las frases ingeniosas.
DISPARAR cuando: el usuario solicita una modificación del código: arreglar, refactorizar, actualizar, reemplazar, editar, parchear, cambiar, modificar, renombrar, reescribir, aplicar cambios, modificar esto, editar el archivo, cambiar este código o solicita explícitamente una diferencia: "muéstrame la diferencia", "como una diferencia unificada", "qué cambió", "muestra el parche", "/muéstrame el código". NO LO UTILICE cuando: produzca un archivo nuevo desde cero (sin líneas de contexto con las que diferenciar), o para respuestas que no sean de código, como planos, explicaciones, arquitectura o diagramas.
