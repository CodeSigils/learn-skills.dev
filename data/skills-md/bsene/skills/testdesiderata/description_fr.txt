Examinez le code de test par rapport aux douze propriétés de TestDesiderata qui rendent les tests précieux : isolement, composabilité, déterminisme, vitesse, lisibilité, sensibilité comportementale, insensibilité structurelle, automatisation, spécificité, prédictivité, confiance inspirante et clarté de l'objectif. Utilisez cette compétence chaque fois que l'utilisateur colle du code de test et demande des commentaires, souhaite évaluer la qualité des tests à l'aide des principes de TestDesiderata, demande « ces tests sont-ils bons ? », montre des tests instables ou problématiques, souhaite améliorer la conception des tests ou discute des compromis entre les tests. Déclenchez également lorsque l'utilisateur mentionne des propriétés de test telles que le « déterminisme », la « sensibilité comportementale » ou le cadre de test de Kent Beck.
