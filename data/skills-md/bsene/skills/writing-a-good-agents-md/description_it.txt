Scrivi, rivedi, controlla o migliora i file AGENTS.md, lo standard aperto e indipendente dagli strumenti per fornire agli agenti di codifica AI un contesto di progetto persistente, oltre ai file specifici del cablaggio che lo racchiudono o lo importano (CLAUDE.md, .cursorrules/ .cursor/rules, GEMINI.md, istruzioni Copilot, .windsurfrules, OpenCode/Zed config, ecc.). Utilizzare ogni volta che l'utente desidera creare un nuovo AGENTS.md da zero, verificare la presenza di gonfiori o anti-pattern in un file di contesto esistente, applicare la divulgazione progressiva, dividere il contesto monolitico in documenti secondari, riconciliare più file specifici dello strumento in un'unica fonte di verità o comprendere le migliori pratiche di AGENTS.md. Attiva menzioni casuali come "aiutami a scrivere il mio AGENTS.md", "il mio CLAUDE.md è buono?", "il mio agente continua a ignorare le mie istruzioni" o "Ho un .cursorrules e un CLAUDE.md, come posso unificarli?". Trattare AGENTS.md, CLAUDE.md e altri file specifici del cablaggio come lo stesso problema: il nome del file raramente cambia la guida.
