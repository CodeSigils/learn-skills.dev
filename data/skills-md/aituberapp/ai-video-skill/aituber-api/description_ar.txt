مهارة ATuber API لإنشاء فيديو AI. أنشئ مقاطع فيديو باستخدام السرد المدعم بالذكاء الاصطناعي والمرئيات والتسميات التوضيحية لـ YouTube Shorts وTikTok وInstagram Reels والمحتوى الطويل. يدعم الصور ومقاطع الفيديو واللقطات المخزنة والقوالب الفيروسية التي تم إنشاؤها بواسطة الذكاء الاصطناعي مثل أنماط الهيكل العظمي والشخصيات. يتعامل مع المسار الكامل: اختر صوتًا، أو أنشئ مقطع فيديو، أو استقصاءً للاكتمال، أو قم بالتصدير إلى MP4 وتنزيله، أو نشره على قنوات YouTube وInstagram المتصلة.
TRIGGER عندما يريد المستخدم: إنشاء فيديو بتقنية الذكاء الاصطناعي، أو إنشاء فيديو من نص أو فكرة، أو إدراج أصوات الذكاء الاصطناعي أو تصفحها، أو تصدير فيديو إلى MP4، أو تنزيل فيديو معروض، أو قائمة القنوات المتصلة، أو نشر مقطع فيديو أو جدولته على YouTube/Instagram، أو التحقق من اشتراك ATuber أو رصيده الائتماني، أو أتمتة إنشاء الفيديو.
لا تقم بالتشغيل من أجل: تحرير ملفات الفيديو الموجودة، أو تحميل لقطات الفيديو المقدمة من المستخدم، أو البث المباشر، أو نسخ الفيديو أو التعليق التوضيحي للملفات الخارجية، أو إنشاء الصور بدون سياق فيديو، أو أي شيء لا علاقة له بمنصة ATuber.
