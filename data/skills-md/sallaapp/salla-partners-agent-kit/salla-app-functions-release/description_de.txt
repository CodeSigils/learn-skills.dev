Speichern und veröffentlichen Sie eine Salla-App-Funktion – „salla_functions action=save“ wird in Demo-Stores bereitgestellt (Abfrage „action=deploy_status“), dann wird die App veröffentlicht. Verwenden Sie diese Funktion nach der Validierung des Handlers, wenn Sie bereit sind, eine Funktion bereitzustellen und an die Produktion zu senden. Geroutet von salla-app-functions; zuerst testen → salla-app-functions-test; App-Veröffentlichung → Salla-App-Builder / Salla-Publikationskonsistenz; OAuth/tokens → salla-app-auth; Webhook-Überprüfung → Salla-Webhooks.
