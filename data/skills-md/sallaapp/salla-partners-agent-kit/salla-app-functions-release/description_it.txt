Salva e pubblica una funzione dell'app Salla — `salla_functions action=save` viene distribuito negli store demo (sondaggio `action=deploy_status`), quindi l'app viene pubblicata. Utilizzare dopo aver convalidato il gestore, quando si è pronti per distribuire e spedire una funzione in produzione. Instradato dalle funzioni salla-app; prova prima → salla-app-funzioni-test; pubblicazione dell'app → salla-app-builder / salla-publication-consistency; OAuth/token → salla-app-auth; verifica webhook → salla-webhooks.
