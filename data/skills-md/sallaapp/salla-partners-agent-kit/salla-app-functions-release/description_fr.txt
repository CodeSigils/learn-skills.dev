Enregistrez et publiez une fonction d'application Salla — `salla_functions action=save` se déploie dans les magasins de démonstration (sondage `action=deploy_status`), puis l'application est publiée. À utiliser après avoir validé le gestionnaire, lorsque vous êtes prêt à déployer et à expédier une fonction en production. Routé depuis salla-app-functions ; testez d'abord → salla-app-functions-test ; publication d'application → salla-app-builder / salla-publication-cohérence ; OAuth/jetons → salla-app-auth ; vérification du webhook → salla-webhooks.
