Сохраните и опубликуйте функцию приложения Salla — `salla_functions action=save` развертывается в демонстрационных магазинах (опрос `action=deploy_status`), затем приложение публикуется. Используйте после проверки обработчика, когда вы готовы развернуть и отправить функцию в рабочую среду. Направлено из функций salla-app; сначала протестируйте → salla-app-functions-test; публикация приложения → salla-app-builder / salla-publication-consistency; OAuth/токены → salla-app-auth; проверка вебхука → salla-webhooks.
