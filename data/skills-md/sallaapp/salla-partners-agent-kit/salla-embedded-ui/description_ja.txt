Salla アプリの EMBEDDED (ダッシュボード) UI、つまり Embedded SDK 設計システム上のパートナー ダッシュボード iframe のネイティブ ルック アンド フィールを所有します。埋め込み/ダッシュボード ページが表示される UI (設定、分析、アドオン フロー) を描画する場合は常に使用します。その 5 つのバインディング ゲートはすべて通過する必要があり、スキップできるものはありません。最後のゲートはライブ デモ ストアのスクリーンショットです。検証されるまでは実行されません。ストアフロント UI → salla-storefront-ui; SDK/認証接続 → salla-embedded-app.
