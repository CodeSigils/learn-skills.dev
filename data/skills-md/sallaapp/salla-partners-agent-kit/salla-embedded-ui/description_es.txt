Posee una apariencia nativa para la interfaz de usuario INTEGRADA (panel de control) de una aplicación Salla: el iframe del panel de socios en el sistema de diseño SDK integrado. Úselo SIEMPRE que una página integrada/de panel dibuje una interfaz de usuario visible (configuraciones, análisis, flujos de complementos). Todas sus cinco puertas vinculantes deben pasar (ninguna se puede omitir) y la puerta final es una captura de pantalla de la tienda de demostración en vivo. No hecho hasta que se verifique.
