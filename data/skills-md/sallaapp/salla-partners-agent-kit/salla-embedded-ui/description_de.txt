Besitzt das native Erscheinungsbild für die EMBEDDED (Dashboard)-Benutzeroberfläche einer Salla-App – den Partner-Dashboard-Iframe im Embedded SDK-Designsystem. Verwenden Sie es, WENN eine eingebettete/Dashboard-Seite eine sichtbare Benutzeroberfläche zeichnet (Einstellungen, Analysen, Add-on-Flows). Seine fünf verbindlichen Tore müssen alle passieren – keines kann übersprungen werden – und das letzte Tor ist ein Live-Screenshot aus dem Demo-Store. Wird erst durchgeführt, wenn die Überprüfung erfolgt ist. Storefront-Benutzeroberfläche → salla-storefront-ui; SDK/Authentifizierungs-Verkabelung → Salla-embedded-app.
