Possède l'apparence native de l'interface utilisateur EMBEDDED (tableau de bord) d'une application Salla — l'iframe du tableau de bord partenaire sur le système de conception Embedded SDK. Utilisez QUAND une page intégrée/de tableau de bord affiche une interface utilisateur visible (paramètres, analyses, flux de modules complémentaires). Ses cinq portes de liaison doivent toutes être franchies (aucune ne peut être désactivée) et la porte finale est une capture d'écran d'un magasin de démonstration en direct. Pas fait jusqu'à vérification. Interface utilisateur de la vitrine → salla-storefront-ui ; Câblage SDK/authentification → application salla-embedded.
