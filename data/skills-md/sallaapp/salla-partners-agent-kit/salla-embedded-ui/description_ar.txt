يمتلك الشكل والمظهر الأصليين لواجهة المستخدم EMBEDDED (لوحة المعلومات) لتطبيق Salla - إطار iframe للوحة معلومات الشريك في نظام تصميم Embedded SDK. استخدم متى ترسم صفحة مضمنة/لوحة معلومات واجهة مستخدم مرئية (الإعدادات والتحليلات وتدفقات الوظائف الإضافية). يجب أن تمر جميع بواباتها الخمسة الملزمة - ولا يمكن تخطيها - والبوابة الأخيرة عبارة عن لقطة شاشة مباشرة للمتجر التجريبي. لم يتم حتى يتم التحقق منها. واجهة مستخدم واجهة المتجر → salla-storefront-ui؛ SDK/أسلاك المصادقة → salla-embedded-app.
