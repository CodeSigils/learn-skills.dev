Владеет собственным внешним видом пользовательского интерфейса EMBEDDED (панель мониторинга) приложения Salla — iframe партнерской панели мониторинга в системе проектирования Embedded SDK. Используйте ВСЕГДА, ВСЕГДА на встроенной странице или странице информационной панели отображается видимый пользовательский интерфейс (настройки, аналитика, потоки дополнений). Все пять обязательных ворот должны пройти (ни один из них нельзя пропустить), а последние ворота представляют собой скриншот из живого демо-магазина. Не выполнено, пока не проверено. Пользовательский интерфейс витрины → salla-storefront-ui; Подключение SDK/авторизации → salla-embedded-app.
