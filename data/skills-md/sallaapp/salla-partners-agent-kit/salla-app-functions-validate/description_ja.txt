Salla アプリ関数を保存する前に必須: テンプレートのラッパーを正確に (最初と最後の行を) ラッパー内のすべてのコードとともに保持し (ホイストされた const/helper なし)、エディターのバーでトリガーの「types」 (.d.ts URL) に対して TypeScript コンパイラーでハンドラーを型チェックします (厳密ではなく、未使用を無視します (TS6133))。さらに、文書化された Admin API 呼び出しを OpenAPI スキーマに対して検証します。 (salla-api-core ループ)。 `salla_functions action=save` はそれらのラッパー行のみを検証します。 salla-app-functions からルーティングされます。 salla-app-functions-release でリリースします。
