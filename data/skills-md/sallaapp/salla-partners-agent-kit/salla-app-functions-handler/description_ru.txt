Шаг 3 создания функции приложения Salla: напишите тело обработчика из «шаблона» триггера. Используйте при кодировании логики — чтение типизированного `контекста` (полезная нагрузка/торговец/настройки), возврат контракта ответа через построитель `Resp` (или сущности `Shipment`), оставаясь внутри изолированной изолированной программной среды V8 (интерфейсы API веб-стандарта, `fetch` для HTTP) и привязывая каждую `выборку` к тайм-ауту синхронизации/асинхронности. Направлено из функций salla-app; затем подтвердите с помощью salla-app-functions-validate. Обработка токенов → salla-app-auth; Подробности API → salla-api-core.
