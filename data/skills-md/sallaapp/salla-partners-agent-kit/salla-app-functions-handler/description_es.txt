Paso 3 para crear una función de aplicación Salla: escriba el cuerpo del controlador desde la "plantilla" del activador. Úselo al codificar la lógica: leer el `contexto` escrito (carga útil/comerciante/configuración), devolver el contrato de respuesta a través del generador `Resp` (o entidad `Envío`), permanecer dentro del entorno aislado de V8 (API estándar web, `fetch` para HTTP) y limitar cada `fetch` al tiempo de espera de sincronización/asíncrono.
