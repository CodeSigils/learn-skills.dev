Создайте коммуникационное приложение Salla, которое будет доставлять SMS, WhatsApp или электронную почту от имени продавца. Используйте при создании приложений канала, OTP/доставке уведомлений или событиях communication.*.send. Отличия: нет sub_category_id, нет веб-перехватчиков по умолчанию, каналы ДОЛЖНЫ быть объявлены с помощью поддерживаемых функций перед публикацией (иначе 403), и каждое событие отправки является триггером функции приложения — отдайте предпочтение функциям приложения. Создание приложений → salla-app-builder; учетные данные → настройки salla-app; код обработчика → salla-app-functions; токен/OAuth → salla-app-auth.
