Erstellen Sie eine Salla-Kommunikations-App, die im Namen des Händlers SMS, WhatsApp oder E-Mails zustellt. Verwenden Sie diese Option beim Erstellen von Kanal-Apps, OTP/Benachrichtigungsübermittlung oder den communication.*.send-Ereignissen. Ausnahmen: keine sub_category_id, keine Standard-Webhooks, Kanäle MÜSSEN vor der Veröffentlichung über unterstützte Funktionen deklariert werden (sonst 403), und jedes Sendeereignis ist ein App-Funktionsauslöser – bevorzugen Sie App-Funktionen. App-Erstellung → Salla-App-Builder; Anmeldeinformationen → Salla-App-Einstellungen; Handler-Code → Salla-App-Funktionen; token/OAuth → alle-app-auth.
