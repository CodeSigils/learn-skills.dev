À utiliser lorsque le comportement doit s'exécuter dans le navigateur de l'acheteur sur la vitrine Salla — extraits JS injectés via l'outil salla_snippets, réagissant aux événements de commerce électronique de la vitrine (panier, vue du produit, paiement, recherche). Règle : comportement de la vitrine/du navigateur → extrait (mode appareil) ; gestion côté serveur des mêmes événements → App Function (salla-app-functions, Cloud Mode). Les extraits de code sont des fichiers purement JS servis à partir du CDN, placés avant `</body>` ; couvre la création/mise à jour/suppression, le pont de paramètres `salla.config.get("app.*")` et le catalogue d'événements de la vitrine.
