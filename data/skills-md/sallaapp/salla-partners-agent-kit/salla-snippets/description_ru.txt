Используйте, когда поведение должно запускаться в браузере покупателя на витрине магазина Salla — фрагменты JS, внедряемые с помощью инструмента salla_snippets, реагирующие на события электронной коммерции на витрине (корзина, просмотр товара, оформление заказа, поиск). Правило: поведение витрины/браузера → фрагмент (режим устройства); обработка тех же событий на стороне сервера → Функция приложения (salla-app-functions, Cloud Mode). Фрагменты — это файлы на чистом JS, передаваемые из CDN и размещаемые перед `</body>`; охватывает создание/обновление/удаление, мост настроек `salla.config.get("app.*")` и каталог событий витрины.
