Da utilizzare quando il comportamento deve essere eseguito nel browser dell'acquirente sulla vetrina Salla: snippet JS inseriti tramite lo strumento salla_snippets, che reagiscono agli eventi di e-commerce della vetrina (carrello, visualizzazione prodotto, pagamento, ricerca). Regola: comportamento del negozio/browser → snippet (modalità dispositivo); gestione lato server degli stessi eventi → Funzione App (funzioni salla-app, modalità Cloud). Gli snippet sono file puramente JS forniti dalla CDN, posizionati prima di "</body>"; copre la creazione/aggiornamento/eliminazione, il bridge delle impostazioni `salla.config.get("app.*")` e il catalogo degli eventi della vetrina.
