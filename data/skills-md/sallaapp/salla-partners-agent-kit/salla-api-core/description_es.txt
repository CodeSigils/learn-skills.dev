Referencia básica para la API de Salla Admin (Comerciante): URL base, autenticación de token de portador, encabezados de solicitud, identidad del comerciante, puntos finales de recursos comunes, paginación, niveles/encabezados de límite de velocidad, códigos de estado HTTP con slugs, formas de error estructuradas y el patrón de lectura, modificación y escritura de la configuración de la aplicación. Úselo siempre que escriba, revise o depure cualquier llamada a la API de Salla Admin: configuración de autenticación, paginación, manejo de errores, lectura/escritura de configuración de la aplicación o límites de velocidad. Todas las demás habilidades de Salla se basan en esto; Manejo de tokens comerciales → salla-app-auth.
