Riferimento di base per l'API Salla Admin (commerciante): URL di base, autenticazione token di connessione, intestazioni di richiesta, identità del commerciante, endpoint di risorse comuni, impaginazione, livelli/intestazioni con limite di velocità, codici di stato HTTP con slug, forme di errore strutturate e modello di lettura-modifica-scrittura delle impostazioni dell'app. Da utilizzare durante la scrittura, la revisione o il debug di qualsiasi chiamata API Salla Admin: configurazione di autenticazione, impaginazione, gestione degli errori, lettura/scrittura delle impostazioni dell'app o limiti di velocità. Ogni altra abilità Salla si basa su questo; gestione dei token del commerciante → salla-app-auth.
