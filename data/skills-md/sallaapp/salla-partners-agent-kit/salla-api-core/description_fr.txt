Référence de base pour l'API Salla Admin (Merchant) : URL de base, authentification par jeton du porteur, en-têtes de demande, identité du commerçant, points de terminaison de ressources communs, pagination, niveaux/en-têtes de limite de débit, codes d'état HTTP avec slugs, formes d'erreur structurées et modèle de lecture-modification-écriture des paramètres de l'application. À utiliser lors de l'écriture, de la révision ou du débogage d'un appel d'API Salla Admin : configuration d'authentification, pagination, gestion des erreurs, lecture/écriture des paramètres d'application ou limites de débit. Toutes les autres compétences de Salla s'appuient sur cela ; Gestion des jetons du commerçant → salla-app-auth.
