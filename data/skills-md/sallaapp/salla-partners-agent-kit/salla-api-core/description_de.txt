Grundlagenreferenz für die Salla Admin (Merchant) API – Basis-URL, Bearer-Token-Authentifizierung, Anforderungsheader, Händleridentität, gemeinsame Ressourcenendpunkte, Paginierung, Ratenbegrenzungsstufen/Header, HTTP-Statuscodes mit Slugs, strukturierte Fehlerformen und das Lese-, Änderungs- und Schreibmuster der App-Einstellungen. Verwenden Sie es immer dann, wenn Sie einen Salla Admin API-Aufruf schreiben, überprüfen oder debuggen – Authentifizierungseinrichtung, Paginierung, Fehlerbehandlung, Lese-/Schreibzugriff für App-Einstellungen oder Ratenbeschränkungen. Jede andere Salla-Fertigkeit baut darauf auf; Umgang mit Händler-Token → salla-app-auth.
