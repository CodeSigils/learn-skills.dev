Справочник по API Salla Admin (Merchant) — базовый URL-адрес, аутентификация на основе токена на предъявителя, заголовки запросов, идентификаторы торговцев, общие конечные точки ресурсов, разбиение на страницы, уровни/заголовки ограничения скорости, коды состояния HTTP с короткими фрагментами, структурированные формы ошибок и шаблон чтения-изменения-записи настроек приложения. Используйте при написании, проверке или отладке любого вызова Salla Admin API — настройки аутентификации, разбиения на страницы, обработки ошибок, чтения/записи настроек приложения или ограничений скорости. На этом основаны все остальные навыки Саллы; обработка токенов продавца → salla-app-auth.
