Salla Admin (Merchant) API の基礎リファレンス — ベース URL、ベアラー トークン認証、リクエスト ヘッダー、マーチャント ID、共通リソース エンドポイント、ページネーション、レート制限層/ヘッダー、スラッグを含む HTTP ステータス コード、構造化エラー形状、アプリ設定の読み取り、変更、書き込みパターン。 Salla Admin API 呼び出し (認証セットアップ、ページネーション、エラー処理、アプリ設定の読み取り/書き込み、レート制限) を作成、レビュー、またはデバッグする場合は常に使用します。他の Salla スキルはすべてこれに基づいています。マーチャントトークンの処理→salla-app-auth。
