المرجع الأساسي لواجهة برمجة التطبيقات (API) لـ Salla Admin (التاجر) - عنوان URL الأساسي، ومصادقة Bearer-token، ورؤوس الطلب، وهوية التاجر، ونقاط نهاية الموارد المشتركة، وترقيم الصفحات، وطبقات/رؤوس الحد الأقصى للمعدل، ورموز حالة HTTP مع الارتباطات الثابتة، وأشكال الأخطاء المنظمة، ونمط القراءة والتعديل والكتابة لإعدادات التطبيق. يُستخدم عند كتابة أو مراجعة أو تصحيح أي استدعاء لـ Salla Admin API - إعداد المصادقة، أو ترقيم الصفحات، أو معالجة الأخطاء، أو قراءة/كتابة إعدادات التطبيق، أو حدود المعدل. كل مهارة Salla الأخرى مبنية على هذا؛ التعامل مع رمز التاجر → salla-app-auth.
