Gestalten Sie die STOREFRONT-Benutzeroberfläche (den Store) einer Salla-App nativ – kundenorientierte Seiten zum Twilight-Thema. Erstellen Sie aus nativen „<salla-*>“-Webkomponenten, die vom Storefront JS SDK gesteuert werden, erben Sie Twilight-CSS-Tokens, verwenden Sie Salla-Symbole („sicon-*“), passen Sie den Abstand der Seite an, schreiben Sie Arabisch zuerst/RTL und überprüfen Sie dies mit einem LIVE-Screenshot in einem installierten Demo-Store („url“). Wird verwendet, wenn ein Snippet eine sichtbare Benutzeroberfläche zeichnet. Injektionsrezept → Salla-Schnipsel. Eingebettete/Dashboard-Benutzeroberfläche → siehe-embedded-ui.
