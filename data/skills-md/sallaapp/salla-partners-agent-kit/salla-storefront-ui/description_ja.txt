Salla アプリの STOREFRONT (ストア) UI をネイティブ (トワイライト テーマの買い物客向けページ) にします。 Storefront JS SDK によって駆動されるネイティブ `<salla-*>` Web コンポーネントから構築し、Twilight CSS トークンを継承し、Salla アイコン (`sicon-*`) を使用し、ページの間隔を一致させ、アラビア語ファースト/RTL を記述し、インストールされたデモ ストア (`url`) のライブ スクリーンショットで検証します。スニペットが目に見える UI を描画する場合に使用します。インジェクションレシピ→サラスニペット。埋め込み/ダッシュボード UI → salla-embedded-ui。
