Rendi nativa l'interfaccia utente STOREFRONT (il negozio) di un'app Salla: pagine rivolte agli acquirenti sul tema Twilight. Crea da componenti web nativi `<salla-*>` gestiti dall'SDK Storefront JS, eredita i token CSS di Twilight, utilizza le icone Salla (`sicon-*`), abbina la spaziatura della pagina, scrivi prima l'arabo/RTL e verifica con uno screenshot LIVE su un negozio demo installato (`url`). Da utilizzare quando uno snippet disegna un'interfaccia utente visibile. Ricetta per l'iniezione → salla-snippets. Interfaccia utente incorporata/da dashboard → salla-embedded-ui.
