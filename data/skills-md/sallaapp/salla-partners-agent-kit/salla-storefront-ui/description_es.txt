Haga que la interfaz de usuario STOREFRONT (la tienda) de una aplicación Salla sea nativa: páginas orientadas al comprador sobre el tema Crepúsculo. Compile a partir de componentes web nativos `<salla-*>` impulsados ​​por Storefront JS SDK, herede tokens CSS de Twilight, use iconos de Salla (`sicon-*`), haga coincidir el espaciado de la página, escriba primero en árabe/RTL y verifique con una captura de pantalla EN VIVO en una tienda de demostración instalada (`url`). Úselo cuando un fragmento dibuje una interfaz de usuario visible. Receta de inyección → fragmentos de salla. Interfaz de usuario integrada/de panel → salla-embedded-ui.
