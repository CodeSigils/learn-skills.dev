إنشاء واجهة مستخدم STOREFRONT (المتجر) لتطبيق Salla - صفحات مواجهة للمتسوقين حول موضوع Twilight. أنشئ من مكونات الويب الأصلية `<salla-*>` التي يتم تشغيلها بواسطة Storefront JS SDK، وارث رموز Twilight CSS، واستخدم أيقونات Salla (`sicon-*`)، وطابق تباعد الصفحة، واكتب اللغة العربية أولاً/RTL، وتحقق من خلال لقطة شاشة مباشرة على متجر تجريبي مثبت (`url`). يُستخدم عندما يرسم المقتطف واجهة مستخدم مرئية. وصفة الحقن → مقتطفات سالا. واجهة المستخدم المضمنة/لوحة المعلومات → salla-embedded-ui.
