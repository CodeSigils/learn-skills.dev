Сделайте собственный пользовательский интерфейс STOREFRONT (магазина) приложения Salla — страницы, ориентированные на покупателей, на тему «Сумерки». Создавайте на основе собственных веб-компонентов `<salla-*>`, управляемых SDK Storefront JS, наследуйте токены Twilight CSS, используйте значки Salla (`sicon-*`), сопоставляйте интервалы на странице, пишите сначала на арабском языке/RTL и подтверждайте это с помощью снимка экрана LIVE в установленном демонстрационном магазине (`url`). Используйте, когда фрагмент отображает видимый пользовательский интерфейс. Рецепт укола → салла-фрагменты. Встроенный пользовательский интерфейс/панель управления → salla-embedded-ui.
