Créez l'interface utilisateur native de STOREFRONT (le magasin) d'une application Salla : des pages destinées aux acheteurs sur le thème Twilight. Créez à partir de composants Web natifs `<salla-*>` pilotés par le SDK Storefront JS, héritez des jetons CSS Twilight, utilisez les icônes Salla (`sicon-*`), faites correspondre l'espacement de la page, écrivez en arabe d'abord/RTL et vérifiez avec une capture d'écran LIVE sur un magasin de démonstration installé (`url`). À utiliser lorsqu'un extrait dessine une interface utilisateur visible. Recette d'injection → extraits de salla. Interface utilisateur intégrée/tableau de bord → salla-embedded-ui.
