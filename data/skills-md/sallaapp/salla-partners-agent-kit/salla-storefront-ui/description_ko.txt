Salla 앱의 STOREFRONT(스토어) UI를 Twilight 테마의 쇼핑객 대상 페이지로 만듭니다. Storefront JS SDK로 구동되는 기본 `<salla-*>` 웹 구성 요소에서 빌드하고, Twilight CSS 토큰을 상속하고, Salla 아이콘(`sicon-*`)을 사용하고, 페이지 간격을 일치시키고, 아랍어 우선/RTL을 작성하고, 설치된 데모 스토어(`url`)에서 라이브 스크린샷으로 확인합니다. 스니펫이 표시되는 UI를 그릴 때 사용합니다. 주입 레시피 → salla-snippets. 임베디드/대시보드 UI → salla-embedded-ui.
