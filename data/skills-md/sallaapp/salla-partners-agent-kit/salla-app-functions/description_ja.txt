Salla アプリ関数を構築するためのルーター — サーバーレス TS/JS ハンドラー Salla は、ストア イベント (例: 「order.created」、「shipment.creating」) に関してサンドボックス化された V8 で実行されます。 App Function タスクはここから開始して、トリガーの設計、ハンドラーの作成、検証、テスト、リリースのステップ スキルに従ってください。 Webhook よりも App Function を優先します。 `salla_functions` で動作します。 Salla-api-core と Salla-Webhook に基づいて構築されます。
