Routeur pour créer des fonctions d'application Salla — gestionnaires TS/JS sans serveur Salla s'exécute dans un bac à sable V8 sur les événements du magasin (par exemple `order.created`, `shipment.creating`). Commencez ici pour n'importe quelle tâche App Function, puis suivez les étapes de compétences : concevoir le déclencheur, écrire le gestionnaire, valider, tester, publier. Préférez les fonctions d'application aux webhooks ; agissez avec `salla_functions`. S'appuie sur salla-api-core et salla-webhooks.
