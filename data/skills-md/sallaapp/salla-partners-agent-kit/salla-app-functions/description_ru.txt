Маршрутизатор для создания функций приложения Salla — бессерверные обработчики TS/JS. Салла запускается в изолированной программной среде V8 при событиях магазина (например, «order.created», «shipment.creating»). Начните здесь выполнение любой задачи функции приложения, а затем следуйте пошаговым инструкциям: спроектируйте триггер, напишите обработчик, проверьте, протестируйте, выпустите. Предпочитайте функции приложения веб-перехватчикам; действуйте с помощью `salla_functions`. Основан на salla-api-core и salla-webhooks.
