Страница приложения Salla в App Store (страница, которую продавцы просматривают перед установкой). Используйте при настройке страницы со списком. Создайте его с помощью инструмента MCP `app_page_builder` в виде упорядоченного списка блоков; редактирование элементов блока записывает содержимое общего списка (имя, описание, логотип, снимки экрана, преимущества) в черновик публикации приложения. Предварительное условие: сначала вызовите `app_publish action=open`, чтобы создать черновик — до этого момента построитель отключен. Загрузите медиафайл с помощью salla_upload. Поток черновика/публикации и `short_description` → salla-publication-consistency. Схемы → salla-docs.
