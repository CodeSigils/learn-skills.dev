Page de liste de l'App Store de l'application Salla (la page que les commerçants voient avant l'installation). À utiliser lors de la personnalisation de cette page de liste. Construisez-le via l'outil MCP `app_page_builder` sous la forme d'une liste ordonnée de blocs ; la modification des éléments d'un bloc écrit le contenu de la liste partagée (nom, description, logo, captures d'écran, avantages) dans le brouillon de publication de l'application. Prérequis : appelez d'abord `app_publish action=open` pour créer le brouillon — le générateur est désactivé d'ici là. Téléchargez des médias avec `salla_upload`. Flux de brouillon/publication et `short_description` → salla-publication-cohérence. Schémas → salla-docs.
