Die App Store-Eintragsseite der Salla-App (die Seite, die Händler vor der Installation sehen). Verwenden Sie diese Option, wenn Sie diese Eintragsseite anpassen. Erstellen Sie es mit dem MCP-Tool „app_page_builder“ als geordnete Liste von Blöcken; Wenn Sie die Elemente eines Blocks bearbeiten, werden freigegebene Listeninhalte (Name, Beschreibung, Logo, Screenshots, Vorteile) in den Veröffentlichungsentwurf der App geschrieben. Voraussetzung: Rufen Sie zuerst „app_publish action=open“ auf, um den Entwurf zu erstellen – der Builder ist bis dahin deaktiviert. Laden Sie Medien mit „salla_upload“ hoch. Entwurfs-/Veröffentlichungsablauf und „short_description“ → Salla-publication-consistency. Schemata → Salla-Docs.
