Le cycle de vie de facturation du module complémentaire pour une application Salla : définition d'un module complémentaire, activation sur app.subscription.started (item_type "addon", correspondant à item_slug), conservation du droit et gestion du renouvellement/annulation/expiration. À utiliser pour câbler ce qui se passe APRÈS qu'un commerçant achète un module complémentaire, pour suivre les abonnements au module complémentaire ou pour contrôler les fonctionnalités par module complémentaire. L'UX d'achat in-iframe fait partie du flux intégré → salla-addon-purchase-embedded. Primitives de plan/tarification/droits → salla-app-billing ; hygiène des webhooks → salla-webhooks.
