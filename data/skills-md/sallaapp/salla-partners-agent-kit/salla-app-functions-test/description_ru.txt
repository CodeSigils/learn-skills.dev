Запустите сохраненную функцию приложения Salla в демонстрационном магазине с `salla_functions action=preview` (app_id, триггер, store_id и поля формы триггера как НАСТОЯЩИЕ идентификаторы). Используйте после сохранения для проверки поведения перед публикацией; опрос `salla_functions action=deploy_status`, пока он еще развертывается. Направлено из функций salla-app; использует salla-api-core для получения реальных идентификаторов.
