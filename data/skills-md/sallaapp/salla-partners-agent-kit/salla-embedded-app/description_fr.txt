À utiliser lors de la création d'une page iframe dans le tableau de bord Salla Merchant (une application intégrée). Enregistrez-le via salla_embedded_pages, installez @salla.sa/embedded-sdk, attendez Embedded.init() (pont postMessage → mise en page : theme/locale/dir), puis authentifiez-vous Trust-but-Verify : FE Embedded.auth.getToken() envoie un jeton de courte durée à VOTRE backend, qui le vérifie via POST /exchange-authority/v1/introspect (en-tête S-Source = votre application ID) et crée sa propre session ; appelez Embedded.ready() seulement après cela. Utilisez les modules natifs Page/Nav/UI (règle No-Chrome), synchronisez le thème/RTL. Vendre des modules complémentaires dans l'application → salla-addon-purchase-embedded ; flux de publication → salla-app-builder.
