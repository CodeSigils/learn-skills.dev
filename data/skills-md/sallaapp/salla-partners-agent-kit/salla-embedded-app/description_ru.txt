Используйте при создании страницы iframe внутри панели управления Salla Merchant (встроенное приложение). Зарегистрируйте его через salla_embedded_pages, установите @salla.sa/embedded-sdk, дождитесь Embedded.init() (мост postMessage → макет: theme/locale/dir), затем выполните аутентификацию Trust-but-Verify: FE Embedded.auth.getToken() отправляет кратковременный токен на ВАШ бэкэнд, который проверяет его через POST /exchange-authority/v1/introspect (заголовок) S-Source = идентификатор вашего приложения) и создает собственную сессию; вызовите Embedded.ready() только после этого. Используйте собственные модули Page/Nav/UI (правило No-Chrome), синхронизируйте тему/RTL. Продажа аддонов внутри приложения → salla-addon-purchase-embedded; поток публикации → salla-app-builder.
