Wird beim Erstellen einer Iframe-Seite im Salla Merchant Dashboard (einer eingebetteten App) verwendet. Registrieren Sie es über salla_embedded_pages, installieren Sie @salla.sa/embedded-sdk, warten Sie auf embedded.init() (postMessage Bridge → Layout: theme/locale/dir) und authentifizieren Sie dann Trust-but-Verify: FE embedded.auth.getToken() sendet ein kurzlebiges Token an IHR Backend, das es über POST /exchange-authority/v1/introspect überprüft (Header S-Source = Ihre App-ID). und prägt seine eigene Sitzung; Rufen Sie erst danach „embedded.ready()“ auf. Verwenden Sie native Seiten-/Navigations-/UI-Module (No-Chrome-Regel), synchronisieren Sie Theme/RTL. Add-ons in der App verkaufen → salla-addon-purchase-embedded; Veröffentlichungsfluss → Salla-App-Builder.
