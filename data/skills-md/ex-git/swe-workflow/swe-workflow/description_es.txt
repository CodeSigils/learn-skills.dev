Un flujo de trabajo de desarrollo estructurado para agentes de codificación. Úselo al iniciar una nueva función, trabajar en tareas de varios pasos o cuando necesite planificación, validación y controles de calidad. Siga las fases Comprender → Planificar → Ejecutar → Reflejar con salvaguardas integradas contra el desplazamiento del alcance y las implementaciones incompletas.
