Ein strukturierter Entwicklungsworkflow für Codierungsagenten. Verwenden Sie diese Funktion, wenn Sie eine neue Funktion starten, an mehrstufigen Aufgaben arbeiten oder wenn Sie Planung, Validierung und Qualitätsprüfungen benötigen. Folgen Sie den Phasen „Verstehen“ → „Planen“ → „Ausführen“ → „Reflektieren“ mit integrierten Schutzmaßnahmen gegen Scope Creep und unvollständige Implementierungen.
