LLM Router (llr) — بوابة LLM موحدة للتوجيه متعدد النماذج. يُستخدم عند تصميم أنظمة وكيل متعددة النماذج، أو الاتصال بموفري LLM، أو تكوين الأسماء المستعارة للنماذج، أو إعداد الواجهات الخلفية للذكاء الاصطناعي، أو عندما يذكر المستخدم "llm-router"، أو "llr"، أو "model routing"، أو "LLM gate"، أو "الأسماء المستعارة للنماذج"، أو "موفر متعدد"، أو يحتاج إلى توجيه الطلبات عبر OpenAI/Anthropic/Gemini/OpenRouter. استخدمه أيضًا عند إنشاء بنيات الوكيل التي تتطلب نماذج متعددة أو موازنة التحميل أو إستراتيجيات احتياطية أو تحديد المعدل عبر موفري LLM.
