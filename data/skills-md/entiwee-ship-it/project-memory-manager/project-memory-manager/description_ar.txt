مدير ذاكرة مشروع KB-first AI للمستودعات الكاملة مع استخراج الملخص الدلالي المنظم والاستعلام الذكي. يُستخدم عندما: (1) تهيئة ذاكرة المشروع، (2) بناء قواعد المعرفة باستخدام تحليل سلسلة الاتصال، (3) الاستعلام عن علاقات الأساليب باستخدام اللغة الطبيعية (على سبيل المثال، "البحث عن طرق تصفية البيانات")، (4) تحليل دلالات التعليمات البرمجية دون قراءة المصدر، أو (5) العمل مع مشاريع Cocos/Pinus/Vue/React/Node.js.
