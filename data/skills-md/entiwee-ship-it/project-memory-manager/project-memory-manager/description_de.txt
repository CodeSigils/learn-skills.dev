KB-erster KI-Projektspeichermanager für Full-Stack-Repositorys mit strukturierter semantischer Zusammenfassungsextraktion und intelligenter Abfrage. Wird verwendet, wenn: (1) der Projektspeicher initialisiert wird, (2) Wissensdatenbanken mit Aufrufkettenanalyse erstellt werden, (3) Methodenbeziehungen mithilfe natürlicher Sprache abgefragt werden (z. B. „Methoden finden, die Daten filtern“), (4) Codesemantik analysiert wird, ohne die Quelle zu lesen, oder (5) mit Cocos/Pinus/Vue/React/Node.js-Projekten gearbeitet wird.
