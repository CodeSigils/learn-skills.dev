Gestionnaire de mémoire de projet IA KB-first pour les référentiels full-stack avec extraction de résumé sémantique structuré et interrogation intelligente. À utiliser lorsque : (1) initialiser la mémoire du projet, (2) créer des bases de connaissances avec l'analyse de la chaîne d'appels, (3) interroger les relations des méthodes à l'aide du langage naturel (par exemple, "trouver des méthodes qui filtrent les données"), (4) analyser la sémantique du code sans lire la source ou (5) travailler avec des projets Cocos/Pinus/Vue/React/Node.js.
