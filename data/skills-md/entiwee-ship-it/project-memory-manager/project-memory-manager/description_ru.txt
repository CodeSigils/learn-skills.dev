KB-первый менеджер памяти проектов искусственного интеллекта для полнофункциональных репозиториев со структурированным извлечением семантической сводки и интеллектуальными запросами. Используйте при: (1) инициализации памяти проекта, (2) создании баз знаний с анализом цепочки вызовов, (3) запросе связей методов с использованием естественного языка (например, «найти методы, фильтрующие данные»), (4) анализе семантики кода без чтения исходного кода или (5) работе с проектами Cocos/Pinus/Vue/React/Node.js.
