KB-first AI project memory manager per repository full-stack con estrazione di riepilogo semantico strutturato e query intelligenti. Utilizzare quando: (1) inizializzare la memoria del progetto, (2) creare basi di conoscenza con l'analisi della catena di chiamate, (3) interrogare le relazioni dei metodi utilizzando il linguaggio naturale (ad esempio, "trovare metodi che filtrano i dati"), (4) analizzare la semantica del codice senza leggere l'origine o (5) lavorare con progetti Cocos/Pinus/Vue/React/Node.js.
