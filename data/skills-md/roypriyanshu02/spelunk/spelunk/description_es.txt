Indexador de base de código impulsado por AST. Caché de importaciones, exportaciones, símbolos y dependencias en SQLite. Utilice esta habilidad para rastrear árboles de dependencia, localizar definiciones de símbolos, esquematizar archivos y mapear la arquitectura de la base de código. Actívelo cada vez que el usuario pregunte sobre la estructura del código base, las dependencias de archivos, los esquemas de importación/exportación o dónde se definen las clases, funciones o símbolos, incluso si no mencionan Spelunk. Excluya repositorios pequeños (<15 archivos) o búsquedas simples de grep de texto.
