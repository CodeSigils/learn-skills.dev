Indexeur de base de code alimenté par AST. Met en cache les importations, les exportations, les symboles et les dépendances dans SQLite. Utilisez cette compétence pour tracer les arborescences de dépendances, localiser les définitions de symboles, les fichiers de plan et cartographier l'architecture de base de code. Déclenchez-le chaque fois que l'utilisateur pose des questions sur la structure de la base de code, les dépendances de fichiers, les contours d'importation/exportation ou l'endroit où les classes, fonctions ou symboles sont définis, même s'ils ne mentionnent pas Spelunk. Excluez les petits référentiels (<15 fichiers) ou les simples recherches de texte grep.
