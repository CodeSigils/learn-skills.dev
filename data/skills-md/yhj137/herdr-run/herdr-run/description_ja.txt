長時間実行されるバックグラウンド プロセス (Web サーバー、LLM プロキシ、トレーニング ジョブ、評価実行、デーモン、ウォッチャー) を、専用の Herdr 「バックグラウンド」ワークスペース内で、ユーザーが制御可能なライブのフォアグラウンド プロセスとして起動します。ワークスペースと {目的}_N 個のタブを自動的に作成し、各プロセスをペインに配置し (2x2 グリッドのタブごとに最大 4 つ、次に新しいタブ)、ペインにリスニング ポートを付けて名前を付け、すべての出力を logs/{目的}/ に記録し、すべての起動をプロジェクトごとのレジストリ (logs/launches.jsonl) に記録します。ユーザーが監視および制御できる場所で実行を継続する必要があるサーバー、サービス、トレーニング、または評価プロセスの開始、実行、起動、または展開を要求するときはいつでも使用します (启动服务、后台跑训练、配置代理)。ワンショット コマンドではなく、プレーンな Bash を使用してください。
