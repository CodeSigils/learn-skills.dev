Starten Sie lang laufende Hintergrundprozesse (Webserver, LLM-Proxys, Trainingsjobs, Evaluierungsläufe, Daemons, Watcher) als Live-, vom Benutzer steuerbare Vordergrundprozesse in einem dedizierten Herdr-„Hintergrund“-Arbeitsbereich. Erstellt automatisch den Arbeitsbereich und die Registerkarten {zweck}_N, platziert jeden Prozess in einem Bereich (maximal 4 pro Registerkarte in einem 2x2-Raster, dann eine neue Registerkarte), benennt Bereiche mit ihren Überwachungsports, leitet die gesamte Ausgabe an logs/{zweck}/ weiter und zeichnet jeden Start in einer projektspezifischen Registrierung (logs/launches.jsonl) auf. Verwenden Sie diese Option immer dann, wenn der Benutzer einen Server, Dienst, Schulungs- oder Evaluierungsprozess starten, ausführen, starten oder bereitstellen möchte, der weiterhin ausgeführt werden soll, wo er ihn beobachten und steuern kann (启动服务, 后台跑训练, 部署代理). Nicht für einmalige Befehle – verwenden Sie dafür einfaches Bash.
