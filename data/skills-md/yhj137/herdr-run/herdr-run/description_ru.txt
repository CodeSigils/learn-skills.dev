Запускайте длительные фоновые процессы (веб-серверы, прокси-серверы LLM, учебные задания, оценочные запуски, демоны, наблюдатели) как живые, управляемые пользователем процессы переднего плана внутри выделенного «фонового» рабочего пространства Herdr. Автоматически создает рабочую область и вкладки { Target}_N, помещает каждый процесс в панель (максимум 4 на вкладку в сетке 2x2, затем новую вкладку), дает панелям имена с указанием их портов прослушивания, объединяет весь вывод в журналы/{назначение}/ и записывает каждый запуск в реестр каждого проекта (logs/launches.jsonl). Используйте всякий раз, когда пользователь запрашивает запуск, запуск или развертывание какого-либо сервера, службы, процесса обучения или оценки, который должен продолжать работать там, где он может наблюдать и контролировать его (启动服务, 后台跑训练, 部署代理). Не для одноразовых команд — используйте для них обычный Bash.
