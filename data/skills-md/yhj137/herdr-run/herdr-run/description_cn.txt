将长时间运行的后台进程（Web 服务器、LLM 代理、训练作业、评估运行、守护进程、观察程序）启动为专用 Herdr“后台”工作区中的实时、用户可控的前台进程。自动创建工作区和 { Purpose}_N 选项卡，将每个进程放置在一个窗格中（2x2 网格中每个选项卡最多 4 个，然后是一个新选项卡），用其侦听端口命名窗格，将所有输出发送到 log/{ Purpose} / ，并在每个项目注册表 (logs/launches.jsonl) 中记录每次启动。每当用户要求启动、运行、启动或部署任何服务器、服务、培训或评估进程时使用，这些进程应在他们可以监视和控制的地方保持运行（启动服务、后台跑训练、部署代理）。不适用于一次性命令——使用普通的 Bash。
