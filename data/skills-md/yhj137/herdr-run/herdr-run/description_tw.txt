將長時間運行的後台程序（Web 伺服器、LLM 代理程式、訓練作業、評估運行、守護程序、觀察程序）啟動為專用 Herdr「後台」工作區中的即時、使用者可控的前台進程。自動建立工作區和 { Purpose}_N 選項卡，將每個進程放置在一個窗格中（2x2 網格中每個選項卡最多 4 個，然後是一個新選項卡），用其偵聽端口命名窗格，將所有輸出發送到 log/{ Purpose} / ，並在每個項目註冊表 (logs/launches.jsonl) 記錄中每次啟動。每當使用者要求啟動、運行、啟動或部署任何伺服器、服務、培訓或評估進程時使用，這些進程應在他們可以監視和控制的地方保持運行（啟動服務、後台跑訓練、部署代理）。不適用於一次性指令－使用普通的 Bash。
