Überprüfen Sie den Besitz des Seeker-Geräts, indem Sie mithilfe der Anmeldung mit Solana und der serverseitigen Token-Verifizierung nach dem Seeker Genesis Token (SGT) suchen. Wird verwendet, wenn Sie Inhalte oder Belohnungen an Seeker-Besitzer weiterleiten, überprüfen, ob ein Benutzer über ein SGT verfügt, Anti-Sybil-Prüfungen zu einer mobilen Solana-App hinzufügen oder eine Logik für einen Anspruch pro Gerät implementieren.
