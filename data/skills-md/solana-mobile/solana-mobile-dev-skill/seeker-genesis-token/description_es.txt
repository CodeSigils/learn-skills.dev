Verifique la propiedad del dispositivo Seeker verificando el token Seeker Genesis (SGT) con el inicio de sesión con Solana y la verificación del token del lado del servidor. Úselo al transmitir contenido o recompensas a los propietarios de Seeker, verificar que un usuario tenga un SGT, agregar controles anti-Sybil a una aplicación móvil de Solana o implementar una lógica de un reclamo por dispositivo.
