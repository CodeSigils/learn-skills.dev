Verbinden Sie Solana-Wallets und signieren oder senden Sie Transaktionen in React Native Expo-Apps mit dem Mobile Wallet Adapter und der Wallet-Benutzeroberfläche. Verwenden Sie diese Option, wenn Sie eine Schaltfläche zum Verbinden einer Brieftasche hinzufügen, eine verbundene Adresse anzeigen, die Verbindung trennen, Nachrichten signieren, sich bei Solana anmelden, SOL übertragen oder eine beliebige Transaktion über eine mobile Solana-App senden.
