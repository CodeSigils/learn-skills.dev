Supporta, configura e risolvi i problemi delle app Solana Mobile per Android utilizzando la CLI solana-mobile, Expo e React Native. Da utilizzare quando si crea una nuova app mobile Solana, si sceglie un modello, si aggiunge Solana a un'app Expo esistente, si controlla la toolchain Android, si gestiscono emulatori Android o si produce una build di sviluppo.
