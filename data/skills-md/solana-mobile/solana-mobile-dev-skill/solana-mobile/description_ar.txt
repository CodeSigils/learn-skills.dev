قم ببناء تطبيقات Solana Mobile وتكوينها واستكشاف أخطائها وإصلاحها لنظام Android باستخدام solana-mobile CLI وExpo وReact Native. يُستخدم عند إنشاء تطبيق Solana جديد للهاتف المحمول، أو اختيار قالب، أو إضافة Solana إلى تطبيق Expo موجود، أو التحقق من سلسلة أدوات Android، أو إدارة محاكيات Android، أو إنتاج بنية تطوير.
