Подключите кошельки Solana и подписывайте или отправляйте транзакции в приложениях React Native Expo с помощью адаптера мобильного кошелька и пользовательского интерфейса кошелька. Используйте при добавлении кнопки подключения кошелька, показе подключенного адреса, отключении, подписании сообщений, входе в систему с помощью Solana, передаче SOL или отправке любой транзакции из мобильного приложения Solana.
