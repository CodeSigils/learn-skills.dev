Organice, configure y solucione problemas de aplicaciones Solana Mobile para Android utilizando la CLI de solana-mobile, Expo y React Native. Úselo al crear una nueva aplicación móvil de Solana, seleccionar una plantilla, agregar Solana a una aplicación Expo existente, verificar la cadena de herramientas de Android, administrar emuladores de Android o producir una compilación de desarrollo.
