Формируйте, настраивайте и устраняйте неполадки приложений Solana Mobile для Android с помощью интерфейса командной строки solana-mobile, Expo и React Native. Используйте при создании нового мобильного приложения Solana, выборе шаблона, добавлении Solana в существующее приложение Expo, проверке набора инструментов Android, управлении эмуляторами Android или создании сборки для разработки.
