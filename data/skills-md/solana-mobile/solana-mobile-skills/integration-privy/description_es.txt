Agregue autenticación Privy a una aplicación de Android Solana Expo además del Adaptador de billetera móvil, usando Iniciar sesión con Solana. Úselo al instalar @privy-io/expo, montar PrivyProvider, iniciar sesión como usuario con useLoginWithSiws, vincular una billetera a una cuenta Privy existente, leer el token de acceso Privy desde un servidor o depurar una configuración Privy plus MWA.
