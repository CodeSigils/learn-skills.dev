Добавьте конфиденциальную аутентификацию в приложение Solana Expo для Android поверх адаптера мобильного кошелька, используя функцию «Вход с помощью Solana». Используйте при установке @privy-io/expo, подключении PrivyProvider, входе пользователя в систему с помощью useLoginWithSiws, привязке кошелька к существующей учетной записи Privy, чтении токена доступа Privy из серверной части или отладке настройки Privy plus MWA.
