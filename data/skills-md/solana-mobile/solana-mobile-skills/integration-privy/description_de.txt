Fügen Sie einer Solana Expo-Android-App zusätzlich zum Mobile Wallet Adapter eine Privy-Authentifizierung hinzu, indem Sie „Sign-In-With-Solana“ verwenden. Wird verwendet, wenn Sie @privy-io/expo installieren, PrivyProvider bereitstellen, einen Benutzer mit useLoginWithSiws anmelden, eine Wallet mit einem vorhandenen Privy-Konto verknüpfen, das Privy-Zugriffstoken von einem Backend lesen oder ein Privy plus MWA-Setup debuggen.
