Полный набор стандартных навыков для проектирования, разработки и запуска интерфейсных страниц. Используется для создания, обновления, статического аудита, пользовательского предварительного просмотра и публикации страниц или проектов React. При создании, изменении, компиляции, предварительном просмотре и выпуске страниц необходимо использовать этот навык; обход его запрещен.
