Utilice esta habilidad antes de llamar a Pixso MCP `code_to_design` cuando el usuario solicite importar o convertir una URL de página web, HTML, ZIP, artefacto web estático o página renderizada por navegador a Pixso. Los activadores incluyen página web a Pixso, URL/HTML/ZIP a Pixso, code_to_design e importación de página web a Pixso. La entrada de URL debe representarse/capturarse localmente y empaquetarse como un `htmlBuffer` real; nunca pase URL directamente ni cambie a reconstrucción aproximada sin la confirmación del usuario.
