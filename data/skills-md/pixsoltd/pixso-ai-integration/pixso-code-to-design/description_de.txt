Verwenden Sie diese Fähigkeit, bevor Sie Pixso MCP „code_to_design“ aufrufen, wenn der Benutzer eine Webseiten-URL, HTML, ZIP, ein statisches Webartefakt oder eine vom Browser gerenderte Seite in Pixso importieren oder konvertieren möchte. Zu den Auslösern gehören „Webseite zu Pixso“, „URL/HTML/ZIP zu Pixso“, „code_to_design“ und „Webseite zu Pixso importieren“. Die URL-Eingabe muss lokal gerendert/erfasst und als echter „htmlBuffer“ gepackt werden; Übergeben Sie niemals URLs direkt oder wechseln Sie ohne Bestätigung des Benutzers zur ungefähren Rekonstruktion.
