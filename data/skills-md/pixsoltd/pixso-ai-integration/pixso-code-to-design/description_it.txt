Utilizza questa abilità prima di chiamare Pixso MCP `code_to_design` quando l'utente chiede di importare o convertire l'URL di una pagina Web, HTML, ZIP, artefatto Web statico o pagina visualizzata nel browser in Pixso. I trigger includono la pagina Web in Pixso, l'URL/HTML/ZIP in Pixso, code_to_design e l'importazione della pagina Web in Pixso. L'input dell'URL deve essere visualizzato/catturato localmente e confezionato come un vero `htmlBuffer`; non passare mai direttamente gli URL né passare alla ricostruzione approssimativa senza la conferma dell'utente.
