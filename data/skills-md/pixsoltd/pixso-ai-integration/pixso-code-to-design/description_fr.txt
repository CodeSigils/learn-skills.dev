Utilisez cette compétence avant d'appeler Pixso MCP `code_to_design` lorsque l'utilisateur demande d'importer ou de convertir une URL de page Web, HTML, ZIP, un artefact Web statique ou une page rendue par le navigateur dans Pixso. Les déclencheurs incluent une page Web vers Pixso, une URL/HTML/ZIP vers Pixso, code_to_design et l'importation d'une page Web dans Pixso. L'entrée URL doit être rendue/capturée localement et emballée comme un véritable « htmlBuffer » ; ne transmettez jamais d’URL directement et ne passez jamais à une reconstruction approximative sans confirmation de l’utilisateur.
