Progetta, supporta, crea e convalida una nuova app personalizzata Contentful App Framework per il repository o l'area di lavoro di un cliente. Utilizzare quando gli utenti desiderano creare un'app personalizzata da un'idea, scegliere posizioni del framework dell'app, creare un'app della barra laterale, un'app editor di campi, un'app di pagina, una finestra di dialogo, una schermata di configurazione, un'azione app o un'app supportata da funzioni, un'impalcatura con create-contentful-app o creare un'app testabile localmente per un flusso di lavoro Contentful specifico dell'organizzazione. Si attiva anche su "crea un'app Contentful", "app personalizzata da zero", "app App Framework", "app barra laterale", "app editor di campo", "app pagina", "azione app" e "funzione app". Non per esempi generici di API Contentful (contentful-api), migrazioni di modelli di contenuto (contentful-migration) o integrazione di siti Web (contentful-nextjs).
