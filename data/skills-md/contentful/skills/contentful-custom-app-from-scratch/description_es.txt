Diseñe, desarrolle, cree y valide una nueva aplicación personalizada de Contentful App Framework para el repositorio o espacio de trabajo de un cliente. Úselo cuando los usuarios deseen crear una aplicación personalizada a partir de una idea, elegir ubicaciones de App Framework, crear una aplicación de barra lateral, una aplicación de editor de campos, una aplicación de página, un cuadro de diálogo, una pantalla de configuración, una acción de aplicación o una aplicación respaldada por funciones, realizar andamiaje con create-contentful-app o crear una aplicación comprobable localmente para un flujo de trabajo Contentful específico de la organización. También se activa "crear una aplicación con contenido", "aplicación personalizada desde cero", "aplicación App Framework", "aplicación de barra lateral", "aplicación de editor de campo", "aplicación de página", "acción de aplicación" y "función de aplicación". No para ejemplos genéricos de Contentful API (contentful-api), migraciones de modelos de contenido (contentful-migration) o integración de sitios web (contentful-nextjs).
