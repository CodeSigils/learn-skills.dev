قم بتصميم تطبيق مخصص جديد لـ Contentful App Framework ودعمه وإنشائه والتحقق من صحته لمستودع العميل أو مساحة العمل الخاصة به. يُستخدم عندما يريد المستخدمون إنشاء تطبيق مخصص من فكرة، أو اختيار مواقع إطار عمل التطبيق، أو إنشاء تطبيق شريط جانبي، أو تطبيق محرر ميداني، أو تطبيق صفحة، أو مربع حوار، أو شاشة تكوين، أو إجراء تطبيق، أو تطبيق مدعوم بوظيفة، أو دعم باستخدام تطبيق إنشاء محتوى، أو إنشاء تطبيق قابل للاختبار محليًا لسير عمل محتوى خاص بالمؤسسة. يتم تشغيله أيضًا عند "إنشاء تطبيق محتوى" و"تطبيق مخصص من البداية" و"تطبيق إطار عمل التطبيق" و"تطبيق الشريط الجانبي" و"تطبيق المحرر الميداني" و"تطبيق الصفحة" و"إجراء التطبيق" و"وظيفة التطبيق". ليس لأمثلة Contentful API العامة (contentful-api)، أو عمليات ترحيل نماذج المحتوى (ترحيل المحتوى)، أو تكامل موقع الويب (contentful-nextjs).
