顧客独自のリポジトリまたはワークスペース用の新しい Contentful App Framework カスタム アプリを設計、足場、構築、検証します。ユーザーがアイデアからカスタム アプリを作成する場合、App Framework の場所を選択する場合、サイドバー アプリ、フィールド エディター アプリ、ページ アプリ、ダイアログ、構成画面、App Action、または Function-backed アプリを構築する場合、create-contentful-app でスキャフォールディングする場合、または組織固有の Contentful ワークフロー用にローカルでテスト可能なアプリを作成する場合に使用します。また、「Contentful アプリの構築」、「ゼロからのカスタム アプリ」、「App Framework アプリ」、「サイドバー アプリ」、「フィールド エディター アプリ」、「ページ アプリ」、「アプリ アクション」、および「アプリ関数」でもトリガーされます。一般的な Contentful API サンプル (contentful-api)、コンテンツ モデルの移行 (contentful-migration)、または Web サイト統合 (contentful-nextjs) には対応しません。
