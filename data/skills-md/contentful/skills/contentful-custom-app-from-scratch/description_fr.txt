Concevez, échafaudez, créez et validez une nouvelle application personnalisée Contentful App Framework pour le référentiel ou l'espace de travail d'un client. À utiliser lorsque les utilisateurs souhaitent créer une application personnalisée à partir d'une idée, choisir des emplacements App Framework, créer une application de barre latérale, une application d'éditeur de champs, une application de page, une boîte de dialogue, un écran de configuration, une action d'application ou une application basée sur une fonction, créer un échafaudage avec create-contentful-app ou créer une application testable localement pour un flux de travail de contenu spécifique à l'organisation. Se déclenche également sur « créer une application Contentful », « application personnalisée à partir de zéro », « application App Framework », « application de barre latérale », « application d'éditeur de champ », « application de page », « action d'application » et « fonction d'application ». Pas pour les exemples génériques d'API Contentful (contentful-api), les migrations de modèles de contenu (contentful-migration) ou l'intégration de sites Web (contentful-nextjs).
