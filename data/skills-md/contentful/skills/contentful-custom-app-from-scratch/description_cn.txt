为客户的仓库或工作区设计、脚手架、构建并验证一个新的 Contentful App Framework 自定义应用。当用户想要从想法创建自定义应用、选择 App Framework 位置、构建侧边栏应用、字段编辑器应用、页面应用、对话框、配置界面、App Action 或基于 Function 的应用、使用 create-contentful-app 脚手架，或为组织特定的 Contentful 工作流制作本地可测试的应用时使用。还可在“构建 Contentful 应用”“从头开始自定义应用”“App Framework 应用”“侧边栏应用”“字段编辑器应用”“页面应用”“应用动作”和“应用函数”等情境下触发。不适用于通用 Contentful API 示例（contentful‑api）、内容模型迁移（contentful‑migration）或网站集成（contentful‑nextjs）。
