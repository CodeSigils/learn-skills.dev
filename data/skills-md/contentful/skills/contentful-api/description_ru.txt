Подробное руководство по контентному REST API. Охватывает API управления контентом (CMA) для создания/обновления контента, API доставки контента (CDA) для получения опубликованного контента, API предварительного просмотра, API изображений и API GraphQL. Во всех примерах используется curl/HTTP — язык не зависит от языка.
