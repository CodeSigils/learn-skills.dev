قم بإضافة المحتوى وتكوينه في مشروع Next.js موجود. يغطي تثبيت JavaScript SDK، وتكوين متغيرات البيئة، وإنشاء عملاء مدركين للإنتاج والمعاينة، وجلب المحتوى في App Router أو Pages Router، وتوصيل تدفقات معاينة وضع المسودة. يُستخدم عندما يطلب المستخدمون دمج Contentful مع Next.js، أو جلب الإدخالات، أو إعداد معاينة أو مسودة المحتوى، أو تكوين عميل Contentful. يتم تشغيله أيضًا على "Contentful SDK Next.js"، و"contentful.js"، و"جلب إدخالات المحتوى"، و"الحصول على المحتوى من Contentful"، و"معاينة المحتوى"، و"وضع المعاينة"، و"متغيرات بيئة المحتوى"، و"إعداد عميل المحتوى"، و"إنشاء عميل محتوى"، و"جهاز توجيه الصفحات محتوى"، و"getStaticProps Contentful"، و"مكونات الخادم المحتوى"، و"إعادة التحقق من المحتوى"، و"ISR Contentful". ليس للتخصيص أو إعداد تجارب SDK (تخصيص المحتوى). ليس للأطر غير التابعة لـ Next.js (يمكن لدليل المحتوى التوجيه إلى مستندات النظام الأساسي).
