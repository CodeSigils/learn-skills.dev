既存の Next.js プロジェクトに Contentful を追加して構成します。 JavaScript SDK のインストール、環境変数の構成、運用クライアントおよびプレビュー対応クライアントの作成、App Router または Pages Router でのコンテンツの取得、ドラフト モード プレビュー フローの接続について説明します。ユーザーが Contentful と Next.js の統合、エントリの取得、コンテンツのプレビューまたは下書きの設定、または Contentful クライアントの構成を要求する場合に使用します。また、「Contentful SDK Next.js」、「contentful.js」、「Contentful エントリの取得」、「Contentful からコンテンツを取得」、「Contentful プレビュー」、「プレビュー モード」、「Contentful 環境変数」、「Contentful クライアント セットアップ」、「Contentful クライアントの作成」、「Pages Router Contentful」、「getStaticProps Contentful」、「Server Components Contentful」、「Revalidate Contentful」でもトリガーされます。 「ISRコンテンツフル」。パーソナライゼーションまたはエクスペリエンス SDK セットアップ (コンテンツフルパーソナライゼーション) には使用できません。 Next.js 以外のフレームワークには対応していません (contentful-guide はプラットフォーム ドキュメントにルーティングできます)。
