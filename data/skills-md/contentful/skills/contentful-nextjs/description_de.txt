Fügen Sie Contentful in einem vorhandenen Next.js-Projekt hinzu und konfigurieren Sie es. Behandelt die Installation des JavaScript SDK, das Konfigurieren von Umgebungsvariablen, das Erstellen von Produktions- und Vorschau-fähigen Clients, das Abrufen von Inhalten in App Router oder Pages Router und das Verknüpfen von Vorschauabläufen im Entwurfsmodus. Wird verwendet, wenn Benutzer Contentful mit Next.js integrieren, Einträge abrufen, Vorschau- oder Entwurfsinhalte einrichten oder den Contentful-Client konfigurieren möchten. Löst auch auf „Contentful SDK Next.js“, „contentful.js“, „Inhalte von Inhalten abrufen“, „Inhalte von Inhalten abrufen“, „Vorschau von Inhalten“, „Vorschaumodus“, „Umgebungsvariablen von Inhalten“, „Einrichtung des Inhalts-Clients“, „Inhalts-Client erstellen“, „Pages Router Contentful“, „getStaticProps Contentful“, „Server Components Contentful“, „Contentful erneut validieren“, „ISR Contentful“ aus. Nicht für die Personalisierung oder die Experiences SDK-Einrichtung (Contentful-Personalisierung). Nicht für Nicht-Next.js-Frameworks (Contentful-Guide kann zu Plattformdokumenten weiterleiten).
