قم بكتابة البرامج النصية لترحيل نموذج المحتوى وتشغيلها باستخدام مكتبة ترحيل المحتوى وContentful CLI. يغطي إنشاء أنواع وحقول المحتوى وتحريرها وحذفها، وعمليات التحقق من الصحة، وتكوين واجهة المحرر، وتخطيطات المحرر، وعناصر واجهة المستخدم للشريط الجانبي، وتحويلات الإدخال، والعلامات، والتعليقات التوضيحية، وكائن سياق الترحيل. يُستخدم عندما يُطلب منك كتابة عملية ترحيل، أو إنشاء نوع محتوى أو إضافته، أو إضافة حقول أو إعادة تسميتها أو حذفها، أو تغيير نموذج محتوى أو تحديثه، أو تحويل الإدخالات، أو اشتقاق الإدخالات المرتبطة، أو تكوين عناصر تحكم المحرر، أو تشغيل برنامج نصي للترحيل. يتم تشغيله أيضًا على "البرنامج النصي للترحيل"، و"ترحيل المحتوى"، و"ترحيل المخطط"، و"ترحيل نموذج المحتوى"، و"التحقق من صحة الحقل"، و"واجهة المحرر"، و"تخطيط المحرر"، و"عنصر واجهة المستخدم للشريط الجانبي"، و"moveField"، و"changeFieldId"، و"حقل النص المنسق"، و"الحقل المرجعي"، و"حقل الرابط". ليس لإعداد عميل SDK أو تكامل Next.js (contentful-nextjs). ليس للمصطلحات المحتوىية أو توجيه واجهة برمجة التطبيقات (دليل المحتوى).
