Escriba y ejecute scripts de migración del modelo de contenido de Contentful utilizando la biblioteca de migración de contenido y la CLI de Contentful. Cubre la creación, edición y eliminación de tipos y campos de contenido, validaciones, configuración de la interfaz del editor, diseños del editor, widgets de la barra lateral, transformaciones de entrada, etiquetas, anotaciones y el objeto de contexto de migración. Úselo cuando se le solicite escribir una migración, crear o agregar un tipo de contenido, agregar, cambiar el nombre o eliminar campos, cambiar o actualizar un modelo de contenido, transformar entradas, derivar entradas vinculadas, configurar controles del editor o ejecutar un script de migración. También se activa en "script de migración", "migración de contenido", "migración de esquema", "migración de modelo de contenido", "validación de campo", "interfaz de editor", "diseño de editor", "widget de barra lateral", "moveField", "changeFieldId", "campo de texto enriquecido", "campo de referencia", "campo de enlace". No para la configuración del cliente SDK o la integración de Next.js (contentful-nextjs). No apto para terminología de contenido o enrutamiento API (guía de contenido).
