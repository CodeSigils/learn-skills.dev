contentful-migration ライブラリと Contentful CLI を使用して、Contentful コンテンツ モデル移行スクリプトを作成して実行します。コンテンツ タイプとフィールドの作成、編集、削除、検証、エディタ インターフェイス構成、エディタ レイアウト、サイドバー ウィジェット、エントリ変換、タグ、注釈、移行コンテキスト オブジェクトについて説明します。移行の作成、コンテンツ タイプの作成または追加、フィールドの追加、名前変更、または削除、コンテンツ モデルの変更または更新、エントリの変換、リンクされたエントリの導出、エディタ コントロールの構成、または移行スクリプトの実行を求められた場合に使用します。また、「移行スクリプト」、「コンテンツフル移行」、「スキーマ移行」、「コンテンツ モデル移行」、「フィールド検証」、「エディター インターフェイス」、「エディター レイアウト」、「サイドバー ウィジェット」、「moveField」、「changeFieldId」、「リッチ テキスト フィールド」、「参照フィールド」、「リンク フィールド」でもトリガーされます。 SDK クライアントのセットアップや Next.js 統合 (contentful-nextjs) は対象外です。コンテンツフルな用語や API ルーティング (コンテンツフル ガイド) は対象外です。
