Los principios básicos y el flujo de trabajo completo para la organización de etiquetas a nivel de archivo de notas (versión CLI). Opere WPS Notes invocando wpsnote-cli a través de la línea de comando del sistema, sin requerir una conexión de servicio MCP. Utilice esto cuando los usuarios mencionen necesidades como "organizar etiquetas de notas", "limpiar etiquetas", "las etiquetas están desordenadas", "demasiadas etiquetas", "ayúdame a etiquetar", "reestructurar etiquetas", "reclasificar", "la clasificación de notas es caótica", "el sistema de etiquetas necesita optimización", etc.; La administración de etiquetas debe realizarse con wpsnote-climanage‑tags, no editando bloques o XML <tag> para modificar etiquetas.
