I principi fondamentali e il flusso di lavoro completo per l'organizzazione dei tag a livello di file delle note (versione CLI). Utilizza WPS Notes richiamando wpsnote-cli tramite la riga di comando del sistema, senza richiedere una connessione al servizio MCP. Utilizzalo quando gli utenti menzionano esigenze come "organizzare i tag delle note", "ripulire i tag", "i tag sono disordinati", "troppi tag", "aiutami a taggare", "ristrutturare i tag", "riclassificare", "la classificazione delle note è caotica", "il sistema dei tag necessita di ottimizzazione", ecc.; la gestione dei tag deve essere eseguita con wpsnote-climanage‑tags, non modificando blocchi o <tag> XML per modificare i tag.
