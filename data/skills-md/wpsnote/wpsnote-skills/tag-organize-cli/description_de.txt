Die Grundprinzipien und der vollständige Arbeitsablauf für die Tag-Organisation auf Dateiebene von Notizen (CLI-Version). Betreiben Sie WPS Notes, indem Sie wpsnote-cli über die Systembefehlszeile aufrufen, ohne dass eine MCP-Dienstverbindung erforderlich ist. Verwenden Sie dies, wenn Benutzer Anforderungen wie „Notiz-Tags organisieren“, „Tags bereinigen“, „Tags sind unordentlich“, „zu viele Tags“, „Hilf mir beim Taggen“, „Tags neu strukturieren“, „neu klassifizieren“, „Notizenklassifizierung ist chaotisch“, „Tag-System muss optimiert werden“ usw. erwähnen; Die Tag-Verwaltung muss mit wpsnote-climanage-Tags durchgeführt werden, nicht durch Bearbeiten von Blöcken oder <tag>-XML, um Tags zu ändern.
