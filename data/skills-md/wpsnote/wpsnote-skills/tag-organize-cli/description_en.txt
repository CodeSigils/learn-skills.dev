The core principles and complete workflow for note file‑level tag organization (CLI version). Operate WPS Notes by invoking wpsnote-cli via the system command line, without requiring an MCP service connection. Use this when users mention needs such as “organize note tags,” “clean up tags,” “tags are messy,” “too many tags,” “help me tag,” “restructure tags,” “reclassify,” “note classification is chaotic,” “tag system needs optimization,” etc.; tag management must be performed with wpsnote-cli manage‑tags, not by editing blocks or <tag> XML to modify tags.
