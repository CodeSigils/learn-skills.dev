Lesen, analysieren und fassen Sie wissenschaftliche Literatur (PDF-Aufsätze) zusammen, um strukturierte Literaturzusammenfassungsnotizen zu erstellen. Kernkompetenzen: Extraktion von Papiermetadaten, Identifizierung von Forschungsfragen, Klärung der Methodik, Analyse experimenteller Ergebnisse, Erstellung persönlicher Bewertungen und literaturübergreifender Vergleich. Unterstützt chinesische und englische Arbeiten, einzelnes ausführliches Lesen und Batch-Literaturrecherche. Verwenden Sie diese Fähigkeit, wenn der Benutzer PDF-Dateien bereitstellt, um eine Lektüre, eine Zusammenfassung, eine Literaturrecherche, einen Gliederungsentwurf, eine ausführliche Lektüre, eine Zusammenfassung, eine Rezension, das Lesen von Aufsätzen bittet, mir beim Lesen dieses Aufsatzes hilft, diesen Artikel analysiert, mir erklärt, worum es in diesem Aufsatz geht, welche Methoden dieser Aufsatz verwendet, mir hilft, Literaturnotizen zu machen, Aufsätze im Batch zu lesen oder diese Aufsätze zu vergleichen. Verarbeitet PDF-Dateien.
