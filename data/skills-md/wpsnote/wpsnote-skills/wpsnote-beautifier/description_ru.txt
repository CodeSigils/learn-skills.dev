Интеллектуальное украшение документов заметок WPS с использованием сдержанной унифицированной цветовой схемы (весь текст использует только один основной цветовой тон, без смешивания нескольких цветовых палитр). Основные возможности: оптимизировать иерархию заголовков, подчеркивать ключевые выводы и предостережения с помощью выделенных блоков, отображать сравнительный или параллельный контент с помощью столбцов, применять единую цветовую схему и встраивать ее. Этот навык срабатывает только тогда, когда пользователь явно выражает запрос на улучшение, например: украшение заметок, оптимизация макета, украшение документа, макет заметки, украшение заметки WPS, интеллектуальное форматирование, настройка структуры документа, добавление цвета, добавление выделения, добавление столбцов, улучшение внешнего вида заметок, оптимизация формата документа, заметки слишком уродливы, настройка макета, добавление стиля, полировка заметок, организация форматирования заметок, улучшение читаемости. Не активируйте этот навык заранее в сценариях, не связанных с украшением, когда пользователь просит только написать контент, отредактировать текст, подвести итоги и т. д. Управляйте документами заметок WPS через службу user-wpsnote MCP.
