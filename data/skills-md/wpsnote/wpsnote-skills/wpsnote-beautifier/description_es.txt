Embellecimiento inteligente de documentos de notas WPS, utilizando un esquema de color unificado y restringido (todo el texto usa solo un tono de color principal, sin mezclar múltiples paletas de colores). Capacidades principales: optimizar la jerarquía de encabezados, enfatizar las conclusiones y precauciones clave con bloques resaltados, mostrar contenido comparativo o paralelo usando columnas, aplicar un esquema de color uniforme e incrustarlo. Esta habilidad se activa solo cuando el usuario expresa explícitamente una solicitud de embellecimiento, como: embellecer notas, optimización del diseño, embellecimiento de documentos, diseño de notas, embellecimiento de notas WPS, formato inteligente, ajuste de la estructura del documento, agregar color, agregar resaltados, agregar columnas, hacer que las notas se vean mejor, optimizar el formato del documento, las notas son demasiado feas, ajustar el diseño, agregar algo de estilo, pulir las notas, organizar el formato de las notas, mejorar la legibilidad. No active proactivamente esta habilidad en escenarios sin embellecimiento donde el usuario solo solicita escribir contenido, editar texto, resumir, etc. Opere documentos de notas WPS a través del servicio MCP user‑wpsnote.
