[Public Account Publishing Assistant] Formats WPS notes and exports them as WeChat public account HTML.  
Use when the user says “publish public account,” “format public account,” “export to public account,” “I’m ready to publish,” “article formatting,” “send it,” or “format this article.”  
This is the final step of the creation workflow: the content is completed and needs to be formatted and published to the public account.  
Core capabilities: 1) automatically apply formatting templates 2) convert placeholder tags to styles 3) generate HTML that can be pasted directly.  
Input: WPS note ID (a note whose content is completed). Output: HTML file with inline styles.  
Do not use for content creation, only for publishing already formatted content.
