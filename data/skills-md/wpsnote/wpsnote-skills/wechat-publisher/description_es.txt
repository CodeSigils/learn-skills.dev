[Asistente de publicación de cuentas públicas] formatea notas WPS y las exporta como HTML de cuenta pública de WeChat.  
Se utiliza cuando el usuario dice "publicar cuenta pública", "formatear cuenta pública", "exportar a cuenta pública", "estoy listo para publicar", "formatear el artículo", "enviarlo" o "formatear este artículo".  
Este es el paso final del proceso de creación: el contenido está completo y debe formatearse y publicarse en la cuenta pública.  
Capacidades principales: 1) aplicar automáticamente plantillas de formato 2) convertir etiquetas de marcador de posición en estilos 3) generar HTML que se pueda pegar directamente.  
Entrada: ID de nota WPS (la nota con el contenido completo). Salida: archivo HTML con estilos en línea.  
No lo use para la creación de contenido, solo para formatear y publicar contenido completo.
