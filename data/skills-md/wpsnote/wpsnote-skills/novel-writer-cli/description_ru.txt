AI-компаньон для написания сериализованных романов (версия CLI). Управляет WPS Notes с помощью инструмента командной строки wpsnote-cli, обеспечивая непрерывное, контекстно-зависимое и безопасное создание. Триггеры: «помогите мне написать роман», «я хочу написать роман», «продолжить роман», «написать следующую главу», «у меня есть идея для истории», «помогите мне создать». Основные функции: холодный старт (построение мира + дизайн персонажей + генерация изображений с помощью искусственного интеллекта), написание глав за главами, автоматическое повторение предыдущего текста для предотвращения ошибок непрерывности, полное архивирование в WPS Notes. Не для: коротких произведений, эссе, стихов или художественной литературы, не вышедшей в сериал.
