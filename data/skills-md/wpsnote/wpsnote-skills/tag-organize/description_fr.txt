Principes de base et flux de travail complet pour organiser les balises au niveau des fichiers de notes. Lorsque les utilisateurs mentionnent « organiser les balises de note », « nettoyer les balises », « les balises sont trop compliquées », « trop de balises », « aidez-moi à baliser », « restructurer les balises », « reclasser », « la catégorisation des notes est chaotique » ou « le système de balises doit être optimisé », il doit être utilisé ; exécuté avec des outils tels que get_note_stats, find_tags, get_note_info, search_notes, manage_note_tags basés sur le MCP wps‑note, sans gérer les balises par bloc d'édition ou <tag> XML.
