Grundprinzipien und vollständiger Arbeitsablauf für die Organisation von Tags auf Dateiebene auf Notizen. Wenn Benutzer „Notiz-Tags organisieren“, „Tags bereinigen“, „Tags sind zu chaotisch“, „zu viele Tags“, „Hilf mir beim Taggen“, „Tags neu strukturieren“, „neu klassifizieren“, „Notizen-Kategorisierung ist chaotisch“ oder „Tag-System muss optimiert werden“ erwähnen, muss dies verwendet werden; Wird mit Tools wie get_note_stats, find_tags, get_note_info, search_notes, manage_note_tags basierend auf dem wps-note MCP ausgeführt, ohne Tags durch Bearbeiten von Block oder <tag> XML zu verwalten.
