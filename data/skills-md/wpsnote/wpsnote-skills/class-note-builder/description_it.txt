Utilizza questa capacità quando desideri trasformare trascrizioni di classe, note OCR, materiali di screenshot o contenuti didattici sparsi in note di studio WPS strutturate. È adatto per scenari come l'organizzazione di documenti di classe, la revisione di sessioni di formazione, il riepilogo delle note del tutoraggio, la creazione di note del corso principale e soprattutto quando il materiale originale è disordinato ma è necessaria una nota principale finale, rivedibile, rivisitabile ed espandibile.
