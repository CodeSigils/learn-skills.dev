Importez le contenu de pages Web dans WPS Notes avec une haute qualité, en préservant la couleur du texte d'origine, le style gras, le format de titre et en insérant des images à leur position d'origine. Prend en charge les articles du compte public WeChat, les publications/threads X/Twitter et toute page Web générique, avec une entrée unifiée qui les reconnaît automatiquement, en utilisant web_fetch, web_search, batch_web_search, create_note, batch_edit, insert_image et sync_note pour écrire directement dans WPS Notes. Déclenché lorsque l'utilisateur dit « Enregistrer cette page Web dans les notes », « Importer cet article », « Capturer cette page dans les notes », « Enregistrer l'article du compte public dans les notes WPS », « Enregistrer ce tweet dans les notes », « Ajouter ce lien aux favoris » ou « Page Web dans les notes ». Ne s'applique pas à : l'interprétation intelligente des actualités (utilisez news-to-note), l'importation groupée de documents locaux (utilisez doc-importer).
