Importe contenido de páginas web a WPS Notes con alta calidad, conservando el color del texto original, el estilo en negrita, el formato de encabezado e insertando imágenes en sus posiciones originales. Admite artículos de cuentas públicas de WeChat, publicaciones/hilos de X/Twitter y cualquier página web genérica, con una entrada unificada que los reconoce automáticamente, utilizando web_fetch, web_search, batch_web_search, create_note, batch_edit, insert_image y sync_note para escribir directamente en WPS Notes. Se activa cuando el usuario dice "Guardar esta página web en notas", "Importar este artículo", "Capturar esta página en notas", "Guardar el artículo de la cuenta pública en WPS Notes", "Guardar este tweet en notas", "Marcar este enlace como favorito" o "Página web en notas". No aplicable para: interpretación inteligente de noticias (use news-to-note), importación masiva de documentos locales (use doc-importer).
