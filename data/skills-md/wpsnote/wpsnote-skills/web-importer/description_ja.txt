Web ページのコンテンツを高品質で WPS Notes にインポートし、元のテキストの色、太字のスタイル、見出しの形式を維持し、画像を元の位置に挿入します。 WeChat パブリック アカウントの記事、X/Twitter 投稿/スレッド、および一般的な Web ページを、web_fetch、web_search、batch_web_search、create_note、batch_edit、insert_image、および sync_note を使用して WPS Notes に直接書き込む、それらを自動的に認識する統合エントリでサポートします。ユーザーが「この Web ページをノートに保存する」、「この記事をインポートする」、「このページをノートにキャプチャする」、「パブリック アカウントの記事を WPS ノートに保存する」、「このツイートをノートに保存する」、「このリンクをブックマークする」、または「Web ページをノートに保存する」と言ったときにトリガーされます。以下には適用されません: ニュースのインテリジェントな解釈 (news-to-note を使用)、ローカル ドキュメントの一括インポート (doc-importer を使用)。
