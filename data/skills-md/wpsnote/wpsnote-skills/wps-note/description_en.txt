Use MCP tools to read, edit, and manage WPS notes based on the block document model, with all content exchanged in XML format. Activate when the user says "check my notes," "search notes," "create a note," "edit note content," "organize tags," or mentions WPS notes, WPS Note, or cloud notes. Also applicable for troubleshooting MCP tool call errors (BLOCK_NOT_FOUND, EDITOR_NOT_READY, etc.).
