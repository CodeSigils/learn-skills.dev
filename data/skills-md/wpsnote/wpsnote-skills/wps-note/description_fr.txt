Utilisez les outils MCP pour lire, modifier et gérer les notes WPS sur la base d'un modèle de document en bloc, avec tout le contenu échangé au format XML. À utiliser lorsque l'utilisateur dit « vérifier mes notes », « rechercher des notes », « créer une note », « modifier le contenu de la note », « organiser les balises » ou mentionne des notes WPS, WPS Note ou des notes cloud. Applicable également pour dépanner les erreurs d'appel de l'outil MCP (BLOCK_NOT_FOUND, EDITOR_NOT_READY, etc.).
