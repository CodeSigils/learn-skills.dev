Utilice herramientas MCP para leer, editar y administrar notas WPS basadas en un modelo de documento en bloque, con todo el contenido intercambiado en formato XML. Úselo cuando el usuario diga "revisar mis notas", "buscar notas", "crear una nota", "editar el contenido de la nota", "organizar etiquetas" o mencione notas WPS, notas WPS o notas en la nube. También se aplica para solucionar errores de llamada a la herramienta MCP (BLOCK_NOT_FOUND, EDITOR_NOT_READY, etc.).
