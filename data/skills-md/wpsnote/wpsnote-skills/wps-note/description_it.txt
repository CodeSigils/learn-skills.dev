Utilizza lo strumento MCP per leggere, modificare e gestire le note WPS, in base al modello di documento a blocchi; tutto il contenuto viene scambiato in formato XML. Attiva quando l'utente dice "controlla le mie note", "cerca note", "crea una nota", "modifica contenuto nota", "organizza tag" o menziona note WPS, nota WPS o note cloud. Applicabile anche per la risoluzione degli errori di chiamata dello strumento MCP (BLOCK_NOT_FOUND, EDITOR_NOT_READY, ecc.).
