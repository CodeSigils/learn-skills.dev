Utilizza gli strumenti MCP per leggere, modificare e gestire le note WPS basate su un modello di documento a blocchi, con tutto il contenuto scambiato in formato XML. Da utilizzare quando l'utente dice "controlla le mie note", "cerca note", "crea una nota", "modifica contenuto nota", "organizza tag" o menziona note WPS, nota WPS o note cloud. Applicabile anche per la risoluzione degli errori di chiamata dello strumento MCP (BLOCK_NOT_FOUND, EDITOR_NOT_READY, ecc.).
