(fslzrr) Выполняет один цикл RED/GREEN/REFACTOR для описанного поведения — сначала записывает неудачные тесты, заставляет их пройти с минимальным кодом, затем выполняет чистый рефакторинг. Может использоваться отдельно или вызываться командой /implement для каждой ПОДЗАДАЧИ. ТРИГГЕР, когда: пользователь говорит «сделать TDD для X», «написать тест для», «реализовать это с помощью TDD», «красно-зеленый рефакторинг» или хочет сначала реализовать какой-либо тест на поведение.
