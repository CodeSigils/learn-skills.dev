(fslzrr) Exécute un seul cycle RED/GREEN/REFACTOR pour un comportement décrit - écrit d'abord les tests qui échouent, les fait réussir avec un minimum de code, puis refactorise proprement. Peut être utilisé de manière autonome ou est appelé par /implement pour chaque SOUS-TÂCHE. DÉCLENCHEMENT lorsque : l'utilisateur dit "faire TDD pour X", "écrire un test pour", "implémenter ceci avec TDD", "refactoriser rouge vert" ou souhaite d'abord implémenter un test de comportement.
