(fslzrr) Ejecuta un único ciclo ROJO/VERDE/REFACTOR para un comportamiento descrito: primero escribe las pruebas fallidas, las hace pasar con un código mínimo y luego las refactoriza limpiamente. Se puede utilizar de forma independiente o se puede llamar mediante /implement para cada SUBTAREA. DISPARAR cuando: el usuario dice 'hacer TDD para X', 'escribir una prueba para', 'implementar esto con TDD', 'refactorizar rojo verde' o quiere implementar cualquier prueba de comportamiento primero.
