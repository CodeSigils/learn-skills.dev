(fslzrr) Организует полный цикл реализации TDD для готовой к использованию ЗАДАЧИ — сопоставляет критерии приемки с ПОДЗАДАЧАМИ, запускает /tdd, /lint и /review для каждой ПОДЗАДАЧИ, выполняет атомарную фиксацию, запускает весь пакет, а затем открывает PR после одобрения человеком. ТРИГГЕР, когда: пользователь говорит «реализовать задачу № N», «начать реализацию», «работать над этой задачей» или «реализовать это».
