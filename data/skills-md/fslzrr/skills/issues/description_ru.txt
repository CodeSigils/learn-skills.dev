(fslzrr) Управляет проблемами GitHub для фабрики программного обеспечения — создает, читает, обновляет и составляет списки проблем PRD и TASK; переходы состояний через метки; показывает панель статуса; и восстанавливает недостающие метки по требованию во время операций записи. ТРИГГЕР, когда: пользователь говорит «показать статус», «составить список проблем», «что происходит», «обновить проблему № N», «отметить как заблокированную», «создать проблему», «закрыть эту проблему» или любой другой запрос управления проблемой GitHub.
