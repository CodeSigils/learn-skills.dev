(fslzrr) Administra los problemas de GitHub para la fábrica de software: crea, lee, actualiza y enumera los problemas de PRD y TASK; estados de transición a través de etiquetas; muestra un panel de estado; y recupera etiquetas faltantes bajo demanda durante las operaciones de escritura. DISPARAR cuando: el usuario dice "mostrar estado", "enumerar problemas", "qué está en progreso", "actualizar problema #N", "marcar como bloqueado", "crear un problema", "cerrar este problema" o cualquier otra solicitud de administración de problemas de GitHub.
