(fslzrr) Разбивает PRD на ЗАДАЧИ с вертикальным срезом, группируя пользовательские истории, которые имеют одинаковый сквозной контекст, предлагает разбивку с обоснованием одобрения человеком, а затем создает утвержденные ЗАДАЧИ как дочерние задачи GitHub. ТРИГГЕР, когда: пользователь говорит «разложить PRD», «разбить на задачи», «создать задачи для проблемы № N», «разделить это на задачи».
