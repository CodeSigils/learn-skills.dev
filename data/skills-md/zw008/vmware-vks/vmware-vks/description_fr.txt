Gestion VMware vSphere basée sur l'IA avec Tanzu (VKS). Gérez les espaces de noms de superviseur et le cycle de vie de TanzuKubernetesCluster via l'IA. 20 outils MCP : contrôles de compatibilité, Namespace CRUD avec gestion des quotas, cycle de vie TKC (créer/mettre à l'échelle/mettre à niveau/supprimer), récupération de kubeconfig, registre Harbour. À utiliser lorsque l'utilisateur demande de « créer un espace de noms », « déployer un cluster TKC », « mettre à l'échelle les travailleurs Kubernetes », « obtenir kubeconfig », « vérifier l'état du superviseur », « répertorier les clusters Tanzu » ou mentionne VKS, Tanzu, TKC, Supervisor ou vSphere Kubernetes. Pour les opérations de VM, utilisez vmware-aiops, pour la surveillance, utilisez vmware-monitor, pour le stockage, utilisez vmware-storage.
