Gestion réseau VMware NSX : segments, passerelles, NAT, routage, IPAM. Interrogez et configurez l’infrastructure réseau via le langage naturel. À utiliser lorsque l'utilisateur demande de « répertorier les segments », « créer un segment », « afficher les règles NAT », « vérifier les voisins BGP », « ajouter une route statique », « créer une passerelle de niveau 1 », « vérifier les alarmes NSX », « rechercher sur quel segment se trouve une VM » ou mentionne les opérations de mise en réseau NSX/NSX-T/VCF. Pour DFW/pare-feu/sécurité, utilisez vmware-nsx-security, pour les opérations de VM, utilisez vmware-aiops, pour la surveillance, utilisez vmware-monitor.
