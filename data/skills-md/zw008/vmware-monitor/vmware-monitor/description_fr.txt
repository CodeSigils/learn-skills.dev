Utilisez cette compétence pour des requêtes sûres et sans risque sur l'infrastructure VMware : la sécurité renforcée au niveau du code signifie qu'aucune opération destructrice n'existe dans la base de code. Gère directement : répertorie les machines virtuelles/hôtes/magasins de données/clusters, vérifie les alarmes actives avec des conseils de correction, affiche les événements récents, obtient les détails de la machine virtuelle (CPU/mémoire/disques/cartes réseau/instantanés). Utilisez toujours vmware-monitor lorsque l'utilisateur demande de « répertorier les machines virtuelles », « vérifier les alarmes vSphere », « afficher l'état de l'hôte », « obtenir les détails de la machine virtuelle », « quels événements vSphere se sont produits » ou a besoin d'informations VMware en lecture seule avant d'apporter des modifications. Ne PAS utiliser pour des opérations d'écriture : cette compétence est en lecture seule au niveau du code et ne peut modifier, créer ou supprimer aucune ressource. Pour les modifications de VM, utilisez vmware-aiops, pour la mise en réseau, utilisez vmware-nsx, pour les métriques/capacité, utilisez vmware-aria. Pour l'équilibrage de charge/AVI/AKO, utilisez vmware-avi.
