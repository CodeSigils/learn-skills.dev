Используйте этот навык для безопасных и безрисковых запросов к инфраструктуре VMware — обеспечение безопасности на уровне кода означает отсутствие разрушительных операций в базе кода. Непосредственное управление: список виртуальных машин/хостов/хранилищ данных/кластеров, проверка активных сигналов тревоги с подсказками по исправлению, просмотр последних событий, получение сведений о виртуальных машинах (ЦП/память/диски/сетевые карты/снимки). Всегда используйте vmware-monitor, когда пользователь просит «составить список виртуальных машин», «проверить сигналы тревоги vSphere», «показать состояние хоста», «получить сведения о виртуальной машине», «какие события vSphere произошли» или ему нужна информация VMware, доступная только для чтения, перед внесением изменений. НЕ используйте для каких-либо операций записи — этот навык доступен только для чтения на уровне кода и не может изменять, создавать или удалять какие-либо ресурсы. Для модификаций виртуальной машины используйте vmware-aiops, для сети используйте vmware-nsx, для метрик/емкости используйте vmware-aria. Для балансировки нагрузки/AVI/AKO используйте vmware-avi.
