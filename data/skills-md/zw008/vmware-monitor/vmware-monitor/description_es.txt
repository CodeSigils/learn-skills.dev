Utilice esta habilidad para consultas seguras y sin riesgos de la infraestructura de VMware: la seguridad impuesta a nivel de código significa que no existen operaciones destructivas en la base del código. Maneja directamente: enumerar máquinas virtuales/hosts/almacenes de datos/clústeres, verificar alarmas activas con sugerencias de solución, ver eventos recientes, obtener detalles de máquinas virtuales (CPU/memoria/discos/NIC/instantáneas). Utilice siempre vmware-monitor cuando el usuario solicite "enumerar las máquinas virtuales", "verificar las alarmas de vSphere", "mostrar el estado del host", "obtener detalles de la máquina virtual", "qué eventos de vSphere ocurrieron" o necesite información de VMware de solo lectura antes de realizar cambios. NO la utilice para ninguna operación de escritura: esta habilidad es de solo lectura a nivel de código y no puede modificar, crear ni eliminar ningún recurso. Para modificaciones de VM use vmware-aiops, para redes use vmware-nsx, para métricas/capacidad use vmware-aria. Para equilibrio de carga/AVI/AKO utilice vmware-avi.
