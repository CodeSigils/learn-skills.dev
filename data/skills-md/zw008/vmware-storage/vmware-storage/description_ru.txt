Управление хранилищем VMware vSphere: хранилища данных, iSCSI, vSAN. Domain-focused skill split from vmware-aiops for lighter context. 11 инструментов MCP: просмотр/сканирование хранилища данных, адаптер iSCSI и целевая конфигурация, мониторинг работоспособности и емкости vSAN. Используйте, когда пользователь запрашивает «просмотреть хранилище данных», «включить iSCSI», «добавить цель iSCSI», «проверить работоспособность vSAN», «сканировать образы OVA/ISO», «повторное сканирование хранилища» или упоминает операции хранилища VMware, iSCSI или vSAN. Для операций с виртуальными машинами используйте vmware-aiops, для мониторинга — vmware-monitor, для Kubernetes — vmware-vks.
