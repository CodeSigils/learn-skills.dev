Gestion du stockage VMware vSphere : banques de données, iSCSI, vSAN. Compétences axées sur le domaine séparées de VMware-aiops pour un contexte plus léger. 11 outils MCP : navigation/analyse des banques de données, adaptateur iSCSI et configuration de la cible, surveillance de l'état et de la capacité de vSAN. À utiliser lorsque l'utilisateur demande de « parcourir la banque de données », « d'activer iSCSI », « d'ajouter une cible iSCSI », de « vérifier l'état de vSAN », de « rechercher des images OVA/ISO », de « réanalyser le stockage » ou mentionne le stockage VMware, iSCSI ou les opérations vSAN. Pour les opérations de VM, utilisez vmware-aiops, pour la surveillance, utilisez vmware-monitor, pour Kubernetes, utilisez vmware-vks.
