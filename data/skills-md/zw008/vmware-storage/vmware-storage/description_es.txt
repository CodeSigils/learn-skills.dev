Gestión de almacenamiento VMware vSphere: almacenes de datos, iSCSI, vSAN. Habilidad centrada en el dominio separada de vmware-aiops para un contexto más claro. 11 herramientas MCP: exploración/escaneo del almacén de datos, adaptador iSCSI y configuración de destino, monitoreo de capacidad y estado de vSAN. Úselo cuando el usuario solicite "examinar el almacén de datos", "habilitar iSCSI", "agregar destino iSCSI", "verificar el estado de vSAN", "buscar imágenes OVA/ISO", "volver a explorar el almacenamiento" o menciona operaciones de almacenamiento de VMware, iSCSI u vSAN. Para operaciones de VM use vmware-aiops, para monitoreo use vmware-monitor, para Kubernetes use vmware-vks.
