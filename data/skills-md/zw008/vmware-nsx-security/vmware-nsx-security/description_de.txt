VMware NSX DFW-Mikrosegmentierung und Sicherheitsvorgänge: Richtlinien und Regeln für verteilte Firewalls, Sicherheitsgruppen, VM-Tags, Traceflow-Paketverfolgung und IDPS. Wird verwendet, wenn der Benutzer „Firewallregeln auflisten“, „eine DFW-Richtlinie erstellen“, „Sicherheitsgruppe erstellen“, „ein Paket verfolgen“, „IDS-Status prüfen“, „NSX-Tag auf VM anwenden“ auffordert oder NSX DFW/Mikrosegmentierung/Sicherheitsrichtlinie/Zero-Trust-Vorgänge erwähnt. Für NSX-Netzwerke (Segmente, Gateways, NAT) verwenden Sie vmware-nsx, für VM-Vorgänge verwenden Sie vmware-aiops.
