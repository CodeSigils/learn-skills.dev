Используйте этот навык всякий раз, когда пользователю необходимо выполнить аудит соответствия VMware, проверку базовых показателей или обнаружение отклонений в средах vSphere/ESXi/NSX. Непосредственно обрабатывает: сканирование CIS / DISA STIG / vSphere SCG / 等保 2.0 三级 / PCI-DSS; пользовательские базовые показатели YAML; предложения по исправлению ситуации на основе LLM; веб-панель. Всегда используйте этот навык для «сканирования соответствия», «проверки базовых показателей», «аудита и т. д.», «проверки соответствия», «обнаружения отклонений», «отчета о соответствии», когда контекст явно указывает на VMware/vSphere/ESXi. НЕ используйте для общего мониторинга vSphere (используйте vmware-monitor или vmware-aiops), изменений в сети (используйте vmware-nsx) или непосредственного выполнения исправлений (этот навык только предполагает; выполнение выполняется через vmware-pilot).
