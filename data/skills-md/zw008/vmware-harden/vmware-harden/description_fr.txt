Utilisez cette compétence chaque fois que l'utilisateur doit effectuer un audit de conformité VMware, une vérification de base ou une détection de dérive sur les environnements vSphere/ESXi/NSX. Gère directement : les analyses CIS / DISA STIG / vSphere SCG / 等保 2.0 三级 / PCI-DSS ; lignes de base YAML personnalisées ; Suggestions de remédiation basées sur le LLM ; tableau de bord Web. Utilisez toujours cette compétence pour « conformité de l'analyse », « vérifier la ligne de base », « audit, etcd », « vérifier les éléments », « détection de dérive », « rapport de conformité » lorsque le contexte est explicitement VMware/vSphere/ESXi. Ne PAS utiliser pour la surveillance générale de vSphere (utilisez vmware-monitor ou vmware-aiops), les modifications du réseau (utilisez vmware-nsx) ou l'exécution directe de corrections (cette compétence suggère seulement ; l'exécution passe par vmware-pilot).
