Utilice esta habilidad siempre que el usuario necesite realizar auditorías de cumplimiento de VMware, comprobaciones de referencia o detección de derivas en entornos vSphere/ESXi/NSX. Maneja directamente: escaneos CIS / DISA STIG / vSphere SCG / 等保 2.0 三级 / PCI-DSS; líneas de base YAML personalizadas; sugerencias de remediación impulsadas por LLM; panel web. Utilice siempre esta habilidad para "escanear cumplimiento", "verificar línea de base", "auditoría, etc.", "verificar datos", "detección de deriva", "informe de cumplimiento" cuando el contexto sea explícitamente VMware/vSphere/ESXi. NO lo use para monitoreo general de vSphere (use vmware-monitor o vmware-aiops), cambios de red (use vmware-nsx) ni para ejecutar correcciones directamente (esta habilidad solo sugiere; la ejecución pasa por vmware-pilot).
