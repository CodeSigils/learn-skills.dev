Используйте этот навык всякий раз, когда пользователь хочет спроектировать, выполнить или управлять сложными многоэтапными рабочими процессами VMware с одобрением человека и автоматическим откатом. Пилот — это мозг оркестрации: он разбивает цель пользователя на этапы по нескольким навыкам VMware (aiops, монитор, nsx, aria, vks, Storage, avi), добавляет шлюзы утверждения перед разрушительными операциями и автоматически откатывает назад, если что-то не получается. Всегда используйте vmware-pilot для: «клонирования и тестирования перед применением в рабочей среде», «реагирования на инциденты VMware с помощью контрольных точек», «исследования основной причины оповещений», «настройки инфраструктуры VMware с использованием нескольких навыков», «последовательного перезапуска VMware с проверками работоспособности», «захвата базовых показателей и обнаружения отклонений», «последовательного обслуживания с использованием AVI-слива», «развертывания приложений с поддержкой AKO» или любого рабочего процесса VMware, требующего шлюзов утверждения или отката. 15 встроенных шаблонов + собственный YAML + рабочие процессы, разработанные с помощью ИИ, на основе 185 доступных инструментов для 8 навыков. Для операций с одной виртуальной машиной используйте vmware-aiops, для запросов только для чтения используйте vmware-monitor, для операций балансировки нагрузки используйте vmware-avi.
