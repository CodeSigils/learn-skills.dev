Utilice esta habilidad siempre que el usuario mencione equilibrio de carga, ingreso, servicios virtuales, miembros del grupo, AVI, NSX ALB, AKO o entrega de aplicaciones. También se activa cuando el usuario menciona la solución de problemas de ingreso de AKO en un entorno Tanzu/vSphere. NO active cuando el usuario solicite explícitamente instalar o configurar nginx/HAProxy/Traefik desde cero; esas no son tareas AVI. Maneja directamente: listado de servicios virtuales y habilitación/deshabilitación, administración de miembros del grupo (drenaje/habilitación de tráfico), comprobaciones de caducidad de certificados SSL, análisis y registros de errores, estado del motor de servicio, solución de problemas del pod AKO, administración de configuración de AKO Helm, validación de anotaciones de ingreso, diagnóstico de sincronización de K8 a controlador y descripción general de AKO de múltiples clústeres. Utilice siempre esta habilidad para cualquier tarea de "servicio virtual", "miembro del grupo", "estado de AKO", "registros de AKO", "diagnóstico de ingreso", "expiración de SSL", "equilibrador de carga", "NSX ALB", "controlador AVI", "sincronización de AKO", "ingreso" o "负载均衡". Para el ciclo de vida de VM, use vmware-aiops, para redes NSX, use vmware-nsx, para el ciclo de vida del clúster K8 (Supervisor/TKC), use vmware-vks.
