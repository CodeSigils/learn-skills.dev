استخدم هذه المهارة عندما يذكر المستخدم موازنة التحميل أو الدخول أو الخدمات الافتراضية أو أعضاء التجمع أو AVI أو NSX ALB أو AKO أو تسليم التطبيق. يتم التشغيل أيضًا عندما يذكر المستخدم استكشاف أخطاء دخول AKO وإصلاحها في بيئة Tanzu/vSphere. لا تقم بالتشغيل عندما يطلب المستخدم صراحةً إعداد أو تكوين nginx/HAProxy/Traefik من البداية - فهذه ليست مهام AVI. يعالج مباشرة: قائمة الخدمات الافتراضية وتمكينها/تعطيلها، وإدارة أعضاء التجمع (استنزاف/تمكين حركة المرور)، والتحقق من انتهاء صلاحية شهادة SSL، والتحليلات وسجلات الأخطاء، وصحة محرك الخدمة، واستكشاف أخطاء AKO وإصلاحها، وإدارة تكوين AKO Helm، والتحقق من صحة التعليقات التوضيحية، وتشخيصات مزامنة K8s إلى وحدة التحكم، ونظرة عامة على AKO متعدد المجموعات. استخدم هذه المهارة دائمًا لأية "خدمة افتراضية"، أو "عضو مجمع"، أو "حالة AKO"، أو "سجلات AKO"، أو "تشخيص الدخول"، أو "انتهاء SSL"، أو "موازن التحميل"، أو "NSX ALB"، أو "وحدة تحكم AVI"، أو "مزامنة AKO"، أو "الدخول"، أو "负载均衡". بالنسبة لدورة حياة VM، استخدم vmware-aiops، ولشبكات NSX، استخدم vmware-nsx، وبالنسبة لدورة حياة مجموعة K8s (المشرف/TKC)، استخدم vmware-vks.
