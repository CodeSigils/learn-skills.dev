Унифицированное ведение журнала аудита, применение политик и очистка входных данных для всего семейства навыков VMware MCP. Используйте при запросе журналов аудита, управлении правилами политики или когда любому специалисту VMware требуется инфраструктура аудита/политики. Предоставляет декоратор @vmware_tool, который объединяет все 156+ инструментов MCP для 8 навыков. Используйте, когда пользователь запрашивает «показать журнал аудита», «проверить запрещенные операции», «просмотреть правила политики», «статистику аудита» или «запросить журнал аудита». Для жизненного цикла виртуальной машины используйте vmware-aiops, для мониторинга используйте vmware-monitor, для сети используйте vmware-nsx, для балансировки нагрузки используйте vmware-avi.
