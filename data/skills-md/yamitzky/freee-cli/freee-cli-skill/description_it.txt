Utilizza la CLI freee ("freee") per gestire l'API freee. Fornisce contabilità, risorse umane e manodopera, fatturazione, monitoraggio del tempo, riferimenti API di vendita e guide all'utilizzo. Usalo per cercare operazioni relative a Freee e specifiche API per richieste di rimborso spese, registrazione di transazioni, timbratura, buste paga, preventivi, bilanci di verifica, voci di diario, gestione dei dipendenti, inserimento orari e gestione delle vendite.
