Используйте бесплатный CLI («freee») для работы с бесплатным API. Предоставляет ссылки на API и руководства по использованию для бухгалтерского учета, управления персоналом и труда, выставления счетов, учета рабочего времени и продаж. Используйте его для поиска операций, связанных с бесплатными услугами, и спецификаций API для заявлений о расходах, регистрации транзакций, учета времени, платежных квитанций, котировок, пробных балансов, записей журнала, управления сотрудниками, ввода времени и управления продажами.
