Используйте Slack Admin CLI («sladm») для работы с Slack Admin API/SCIM API. Используйте его, если вы хотите выполнять административные операции в своем рабочем пространстве Slack, например управление командой, управление пользователями, управление каналами, управление приложениями, управление рабочими процессами, управление запросами на приглашения, управление функциями и управление пользователями/группами SCIM.
