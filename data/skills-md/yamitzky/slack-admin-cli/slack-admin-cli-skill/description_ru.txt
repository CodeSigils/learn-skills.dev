Используйте Slack Admin CLI («sladm») для работы с Slack Admin API/SCIM API. Он используется для управления командой, управления пользователями, управления каналами, управления приложениями, управления рабочими процессами, управления запросами на приглашения, управления функциями и управления пользователями/группами SCIM — всякий раз, когда вы хотите выполнять административные операции в рабочем пространстве Slack.
