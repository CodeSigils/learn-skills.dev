Verwenden Sie die Slack Admin CLI („sladm“), um die Slack Admin API/SCIM API zu bedienen. Verwenden Sie es, wenn Sie administrative Vorgänge in Ihrem Slack-Arbeitsbereich durchführen möchten – wie Teamverwaltung, Benutzerverwaltung, Kanalverwaltung, App-Verwaltung, Workflow-Verwaltung, Verwaltung von Einladungsanfragen, Funktionsverwaltung und SCIM-Benutzer-/Gruppenverwaltung.
