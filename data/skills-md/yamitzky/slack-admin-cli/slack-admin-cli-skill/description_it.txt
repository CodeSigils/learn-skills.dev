Utilizza la CLI di amministrazione di Slack (`sladm`) per gestire l'API di amministrazione di Slack/API SCIM. Usalo quando desideri eseguire operazioni amministrative sul tuo spazio di lavoro Slack, ad esempio gestione del team, gestione degli utenti, gestione dei canali, gestione delle app, gestione del flusso di lavoro, gestione delle richieste di invito, gestione delle funzioni e gestione di utenti/gruppi SCIM.
