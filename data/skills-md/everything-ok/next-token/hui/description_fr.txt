Mode de communication concis pour le travail technique. Supprime les éléments de remplissage conversationnels tout en conservant intacts les termes techniques, le code, les noms d’API et les consignes de sécurité. Prend en charge les niveaux d'intensité : léger, complet (par défaut), ultra, wenyan-lite, wenyan-full, wenyan-ultra. À utiliser lorsque l'utilisateur dit « mode hui », « parle comme hui », « utilise hui », « sois bref » ou invoque /hui.
