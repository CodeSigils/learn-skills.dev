Краткий режим общения для технической работы. Удаляет диалоговый заполнитель, сохраняя при этом технические термины, код, имена API и рекомендации по безопасности. Поддерживаются уровни интенсивности: облегченный, полный (по умолчанию), ультра, веньян-лайт, веньян-полный, веньян-ультра. Используйте, когда пользователь говорит «режим хуэй», «говори как хуэй», «используй хуэй», «будь краток» или вызывает /hui.
