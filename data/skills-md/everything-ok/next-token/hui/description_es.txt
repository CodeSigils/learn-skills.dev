Modo de comunicación conciso para trabajos técnicos. Elimina el relleno conversacional manteniendo intactos los términos técnicos, el código, los nombres de API y las pautas de seguridad. Admite niveles de intensidad: lite, full (predeterminado), ultra, wenyan-lite, wenyan-full, wenyan-ultra. Se usa cuando el usuario dice "modo hui", "habla como hui", "usa hui", "sé breve" o invoca /hui.
