Utilisez cette compétence lors de l'écriture de code Rust impliquant wgpu, des shaders de calcul WGSL, des pipelines asynchrones Tokio, la gestion des tampons GPU, la stratégie de mémoire SAM/ReBAR, les contraintes matérielles RDNA2/RDNA3 ou toute architecture où le calcul asynchrone Rust et le calcul GPU doivent être raisonnés ensemble. Les déclencheurs incluent : la disposition du pipeline wgpu, la conception du groupe de travail WGSL, la stratégie de transfert de tampon, l'architecture de données résidente sur GPU, la topologie des tâches Tokio pour l'ingestion matérielle, la conception de canaux croisés pour les pipelines en temps réel et toute question sur la raison pour laquelle Tokio n'est pas un thread C++.
