Utilizzare quando l'utente desidera che un prompt venga scritto, riparato o criticato per un runtime, una fase, una famiglia di modelli o una modalità nota: prompt di sistema, prompt dello sviluppatore, prompt di attività riutilizzabili, prompt di utilizzo di strumenti o modello di ragionamento, prompt di immagini, prompt in tempo reale o intervento chirurgico con prompt di modifica minima dopo una specifica modalità di errore. Adattare il prompt al runtime reale e al contratto del chiamante, mantenerlo conciso, generalizzare dal feedback di esempio e diagnosticare quando la formulazione non è il vero problema.
