يُستخدم عندما يريد المستخدم كتابة مطالبة أو إصلاحها أو نقدها لوقت تشغيل أو مرحلة أو مجموعة نماذج أو طريقة معروفة: مطالبات النظام، أو مطالبات المطورين، أو مطالبات المهام القابلة لإعادة الاستخدام، أو مطالبات استخدام الأدوات أو نماذج الاستدلال، أو مطالبات الصور، أو مطالبات الوقت الفعلي، أو إجراء عملية جراحية سريعة التحرير بالحد الأدنى بعد وضع فشل محدد. قم بملاءمة الموجه مع وقت التشغيل الحقيقي وعقد المتصل، واجعله موجزًا، وعمم من خلال أمثلة التعليقات، وقم بالتشخيص عندما لا تكون الصياغة هي المشكلة الحقيقية.
