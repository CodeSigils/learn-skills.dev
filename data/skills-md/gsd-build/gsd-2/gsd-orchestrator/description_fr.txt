Orchestrez les projets GSD (Get Shit Done) via l’exécution de sous-processus. À utiliser lorsqu'un agent doit créer des jalons à partir de spécifications, exécuter des workflows de développement logiciel, surveiller la progression des tâches, interroger l'état, gérer les bloqueurs ou suivre les coûts. Se déclenche sur les requêtes « exécuter gsd », « créer un jalon », « exécuter le projet », « vérifier le statut de gsd », « orchestrer le développement », « exécuter un workflow sans tête » ou toute interaction programmatique avec le système de gestion de projet GSD.
