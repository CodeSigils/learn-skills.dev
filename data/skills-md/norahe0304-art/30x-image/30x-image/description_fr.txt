Générez des images marketing de marque via l'outil image_Generation intégré de Codex.
Déclenchement lorsque l'utilisateur demande : (a) créer des éléments marketing (annonce/logo/diapositive/
maquette de produit / scène / transformation d'éclairage / carrousel LinkedIn ou social)
pour une marque spécifique, (b) extraire
ou créez un profil de marque (DESIGN.md) à partir de l'URL / Tailwind config / tokens.json /
Variables Figma / Accessoires personnalisés CSS / Description / Actif de marque existant, (c)
maintenir la cohérence de la marque sur plusieurs tâches d'image pour la même marque.
Ne déclenchez PAS pour : la génération de code d'interface utilisateur, les images de référence frontales (utilisez
imagegen-frontend-web à la place), la génération de vidéo ou l'édition générale d'images
sans contexte de marque.
