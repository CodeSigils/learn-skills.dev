Generieren Sie markengerechte Marketingbilder mit dem integrierten image_generation-Tool von Codex.
Wird ausgelöst, wenn der Benutzer Folgendes auffordert: (a) Marketingressourcen erstellen (Anzeige/Logo/Folie/
Produktmodell/Szene/Beleuchtungstransformation/LinkedIn-oder-Social-Carousel)
für eine bestimmte Marke, (b) Auszug
oder erstellen Sie ein Markenprofil (DESIGN.md) über die URL / Tailwind config / tokens.json /
Figma-Variablen / benutzerdefinierte CSS-Requisiten / Beschreibung / vorhandener Markenwert, (c)
Bewahren Sie die Markenkonsistenz über mehrere Bildaufträge für dieselbe Marke hinweg.
NICHT auslösen für: UI-Codegenerierung, Frontend-Referenzbilder (verwenden Sie
stattdessen imagegen-frontend-web), Videogenerierung oder allgemeine Bildbearbeitung
ohne Markenkontext.
