Codex の組み込み image_generation ツールを使用して、ブランドに基づいたマーケティング画像を生成します。
ユーザーが次のことを要求したときにトリガーします: (a) マーケティング アセット (広告/ロゴ/スライド/
製品モックアップ / シーン / 照明変換 / LinkedIn またはソーシャル カルーセル)
特定のブランドの場合、(b) 抜粋
または、URL / Tailwind config / tokens.json / からブランド プロファイル (DESIGN.md) を構築します。
Figma 変数 / CSS カスタム プロップ / 説明 / 既存のブランド アセット、(c)
同じブランドの複数の画像ジョブにわたってブランド上の一貫性を維持します。
次の場合はトリガーしないでください: UI コード生成、フロントエンド参照画像 (使用
代わりに imagegen-frontend-web)、ビデオ生成、または一般的な画像編集
ブランドの文脈なしで。
