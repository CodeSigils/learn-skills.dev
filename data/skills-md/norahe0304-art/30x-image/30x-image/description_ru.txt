Создавайте фирменные маркетинговые изображения с помощью встроенного в Codex инструмента image_generate.
Срабатывает, когда пользователь просит: (а) создать маркетинговые ресурсы (объявление, логотип, слайд или
продукт-макет/сцена/освещение-трансформация/LinkedIn-или социальная карусель)
для конкретной марки, (б) экстракт
или создайте профиль бренда (DESIGN.md) из URL/Tailwind config/tokens.json/
Переменные Figma / пользовательские реквизиты CSS / описание / существующий актив бренда, (c)
поддерживать единообразие бренда в нескольких заданиях по созданию имиджа для одного и того же бренда.
НЕ запускайте триггер для: генерации кода пользовательского интерфейса, эталонных изображений внешнего интерфейса (используйте
вместо этого imagegen-frontend-web), создание видео или общее редактирование изображений.
без контекста бренда.
