Redactar o actualizar los documentos guía públicos del proyecto: guía para desarrolladores (guía para desarrolladores, para contribuyentes/integradores/desarrolladores intermedios) y guía para usuarios (guía para usuarios, para usuarios finales). Los entregables van al directorio docs/ del proyecto, se mantienen junto con el código y se pueden buscar mediante herramientas de indexación. Diferencia con libdoc: Guidedoc está orientado a tareas ("cómo hacer Y con X"), libdoc está orientado a referencias ("cómo se ve cada parte de X"). Escenarios desencadenantes: el usuario dice "escribir documentos", "guía para desarrolladores", "guía para el usuario" o lo presiona de manera proactiva cuando finaliza la aceptación de funciones.
