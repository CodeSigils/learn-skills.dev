Effectuez une exploration ciblée du code du référentiel, en transformant le cycle « demander → lire le code → tirer une conclusion » en preuves consultables afin que la prochaine question similaire puisse la réutiliser. Trois types : question (étudier le code autour d'un problème spécifique et formuler une conclusion), aperçu du module (cartographier la structure/les limites/les points d'entrée/les dépendances d'un module), Spike (sonde technologique légère de plusieurs directions possibles, pas de décision finale). Phrases déclencheurs : l'utilisateur dit « explorez d'abord », « comment X est-il implémenté dans ce dépôt », « se familiariser rapidement avec ce module », « archiver l'exploration ». Les différences par rapport à l'apprentissage/astuces/décisions voir `codestable/reference/system-overview.md`.
