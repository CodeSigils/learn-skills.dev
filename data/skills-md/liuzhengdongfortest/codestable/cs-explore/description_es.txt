Realice una exploración específica del código del repositorio, convirtiendo el ciclo “preguntar → leer código → sacar una conclusión” en evidencia que se pueda buscar para que la siguiente pregunta similar pueda reutilizarla. Tres tipos: pregunta (investiga el código en torno a un tema específico y establece una conclusión), descripción general del módulo (mapea la estructura/límites/puntos de entrada/dependencias de un módulo), pico (sondeo tecnológico liviano de varias direcciones posibles, sin decisión final). Frases desencadenantes: el usuario dice "explorar primero", "cómo se implementa X en este repositorio", "familiarizarse rápidamente con este módulo", "archivar la exploración". Las diferencias con el aprendizaje/trucos/decisiones, consulte `codestable/reference/system-overview.md`.
