Führen Sie eine gezielte Code-Exploration des Repos durch und verwandeln Sie den Zyklus „Fragen → Code lesen → Schlussfolgerung ziehen“ in durchsuchbare Beweise, damit die nächste ähnliche Frage ihn wiederverwenden kann. Drei Arten: Frage (Untersuchung des Codes zu einem bestimmten Problem und Schlussfolgerung), Modulübersicht (Karte der Struktur/Grenzen/Einstiegspunkte/Abhängigkeiten eines Moduls), Spitze (leichte technische Untersuchung mehrerer möglicher Richtungen, keine endgültige Entscheidung). Auslösersätze: Der Benutzer sagt „Zuerst erkunden“, „Wie ist X in diesem Repo implementiert“, „Machen Sie sich schnell mit diesem Modul vertraut“, „Archivieren Sie die Erkundung“. Unterschiede zum Lernen/Tricks/Entscheidungen siehe `codestable/reference/system-overview.md`.
