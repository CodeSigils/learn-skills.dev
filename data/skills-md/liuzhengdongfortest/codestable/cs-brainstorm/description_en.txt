Entry point for discussions when the idea is still fuzzy—first run one or two rounds of triage to decide where the talk should ultimately go: if it’s already clear enough, jump straight to feature-design; if the small-requirement direction is set, keep chatting inside the feature and dump notes into `{slug}-brainstorm.md`; if it’s too big for one feature, hand it to the roadmap for breakdown.  
AI acts as a thinking partner, not a scribe—dig for the real problem the user wants solved, proactively evaluate any brought-in solutions, and suggest alternative directions when needed.  

Trigger phrases: “I have an idea but it’s not clear yet,” “Let’s brainstorm first,” “I want to do something but it’s still fuzzy,” “Let’s talk about this area,” “The feature direction is still wavering,” or the user arrives with a concrete plan but wants other opinions first.  

Does not handle bugs (use issue) or refactors (use refactor).
