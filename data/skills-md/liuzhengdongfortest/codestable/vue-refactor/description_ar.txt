Vue Component/Composable Refactoring Sparring Partner - يقوم المستخدم بلصق مقتطف أو يشير إلى SFC؛ تعطي المهارة أولاً تشخيصًا ("صندوق السمين" / "واجهة المستخدم والإخراج متشابكان" / "التفاعل ومنطق الأعمال متشابكان")، ثم تختار واحدة من ثلاث وصفات وتسرد التسلسل الدقيق لخطوات الاستخراج (أي متغير يجب نقله أولاً، ما هو خطأ المترجم الذي سيظهر، وكيفية التخلص منها واحدة تلو الأخرى، ومتى يمكنك التراجع). تعتمد العملية برمتها على الأضواء الخضراء للمترجم + التراجع بخطوة واحدة لضمان التكافؤ السلوكي، دون الحاجة إلى شبكة أمان للاختبار. عبارات التحفيز: يقول المستخدم "مكون Vue هذا سمين للغاية / يريد استخراج المنطق / تقسيم SFC / هذا التركيب فوضوي / استخراج قابل للتركيب / مقسم إلى متواضع / يجعله وظيفيًا خالصًا"، أو يشير إلى ملف .vue / قابل للتركيب كبير الحجم بشكل واضح ويطلب "إعادة البناء / التحسين / التقسيم". يتعامل فقط مع Vue (Vue 2 Options، Vue 2/3 `<script setup>`، قابل للتركيب، Pinia store). لن يتم ذلك: ميزات جديدة (استخدم تدفق الميزات)، وإصلاحات الأخطاء (استخدم تدفق المشكلات)، والتعديل الهيكلي عبر الوحدات، والتعليمات البرمجية الخلفية.
