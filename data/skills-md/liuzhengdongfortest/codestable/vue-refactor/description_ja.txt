Vue コンポーネント/コンポーザブル リファクタリング スパーリング パートナー - ユーザーはスニペットを貼り付けるか、SFC をポイントします。このスキルはまず診断 (「太いトランク」/「UI と IO のもつれ」/「反応性とビジネス ロジックのもつれ」) を示し、次に 3 つの処方箋のうち 1 つを選択し、正確な抽出ステップのシーケンス (どの変数を最初に移動するか、どのコンパイラ エラーが表示されるか、それらを 1 つずつ除去する方法、いつロールバックできるか) をリストします。プロセス全体はコンパイラの青信号とシングルステップのロールバックに依存して動作の同等性を保証しており、テストのセーフティ ネットは必要ありません。トリガーフレーズ: ユーザーが「この Vue コンポーネントは太すぎる / ロジックを抽出したい / この SFC を分割したい / このコンポーザブルは乱雑である / コンポーザブルを抽出する / ハンブルに分割する / 純粋関数型にする」と言うか、明らかにサイズが大きすぎる .vue / コンポーザブル ファイルを指定して「リファクタリング / 最適化 / 分割」を要求します。 Vue のみを処理します (Vue 2 オプション、Vue 2/3 `<script setup>`、コンポーザブル、Pinia ストア)。実行できないもの: 新機能 (機能フローを使用)、バグ修正 (問題フローを使用)、モジュール間のアーキテクチャの再シャッフル、バックエンド コード。
