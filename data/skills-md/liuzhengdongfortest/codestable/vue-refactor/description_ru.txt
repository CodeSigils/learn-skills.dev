Тренер по принятию решений по рефакторингу компонентов/составных компонентов Vue — пользователь вставляет фрагмент кода или указывает на SFC, навык сначала выполняет диагностику («толстый ствол»/«запутывание пользовательского интерфейса и ввода-вывода»/«запутывание реактивности и бизнеса»), затем выбирает одно предписание из трех вариантов, предоставляя пошаговые конкретные последовательности извлечения (какую переменную перемещать первой, какие ошибки выдаст компилятор, как устранить их одну за другой, когда возможен откат). Весь процесс опирается на зеленый свет компилятора + одношаговый откат, чтобы гарантировать поведенческую эквивалентность, отсутствие зависимости от системы безопасности тестирования. Сценарии триггера: пользователь говорит: «Этот компонент Vue слишком толстый / хочет извлечь логику / разделить этот SFC / этот составной объект слишком беспорядочный / извлечь составной элемент / разделить на скромную / чистую функцию» или указывает на явно длинный .vue / составной файл, запрашивающий «рефакторинг / оптимизацию / разделение». Обрабатывает только Vue (опции Vue 2, Vue 2/3 `<script setup>`, компонуемый, магазин pinia). Не обрабатывает: добавление новых функций (прохождение процесса функций), исправление ошибок (прохождение процесса проблем), реорганизацию межмодульной архитектуры, внутренний код.
