Спарринг-партнер по рефакторингу компонентов/составных компонентов Vue — пользователь вставляет фрагмент или указывает на SFC; навык сначала выдает диагноз («толстый ствол» / «запутан пользовательский интерфейс и ввод-вывод» / «запутана реактивность и бизнес-логика»), затем выбирает одно из трех предписаний и перечисляет точную последовательность шагов извлечения (какую переменную перемещать первой, какая ошибка компилятора появится, как устранить их одну за другой, когда можно будет выполнить откат). Весь процесс опирается на зеленый свет компилятора + одношаговый откат, чтобы гарантировать поведенческую эквивалентность, не требуется никакой системы безопасности тестирования. Триггерные фразы: пользователь говорит: «Этот компонент Vue слишком толстый / хочет извлечь логику / разделить этот SFC / этот составной объект беспорядочен / извлечь составной объект / разделить его на скромные / сделать его чисто функциональным», или указывает на явно слишком большой .vue / составной файл и просит «рефакторить / оптимизировать / разделить». Обрабатывает только Vue (опции Vue 2, Vue 2/3 `<script setup>`, компонуемый, хранилище Pinia). Не подойдет: новые функции (используйте поток функций), исправления ошибок (используйте поток проблем), межмодульные архитектурные изменения, внутренний код.
