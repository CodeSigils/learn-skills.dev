Componente Vue/Composable Refactoring Sparring: el usuario pega un fragmento o señala un SFC; la habilidad primero da un diagnóstico (“tronco gordo” / “UI e IO enredados” / “reactividad y lógica de negocios enredados”), luego elige una de las tres prescripciones y enumera la secuencia exacta de pasos de extracción (qué variable mover primero, qué error del compilador aparecerá, cómo eliminarlos uno por uno, cuándo puede revertir). Todo el proceso se basa en las luces verdes del compilador + reversión en un solo paso para garantizar la equivalencia de comportamiento, sin necesidad de red de seguridad de prueba. Frases de activación: el usuario dice "este componente de Vue es demasiado gordo/quiero extraer lógica/dividir este SFC/este componible es desordenado/extraer un componible/dividirlo en humilde/hacerlo puramente funcional", o señala un archivo .vue/composable obviamente de gran tamaño y solicita "refactorizar/optimizar/dividir". Solo maneja Vue (Opciones de Vue 2, Vue 2/3 `<script setup>`, componible, tienda Pinia). No sirve: nuevas funciones (usar flujo de funciones), correcciones de errores (usar flujo de problemas), reorganización arquitectónica entre módulos, código backend.
