Feature Process Phase 1 — Draft a design document for the new feature as the sole input for subsequent implementation and acceptance. First gather evidence (read architecture, read relevant code, grep to prevent term conflicts, check archives), then write a complete first draft in one go (including YAML frontmatter + three-layer structure + test design), submit to user for holistic review, iterate until approval. After approval, extract {slug}-checklist.yaml from {slug}-design.md for use in the following two phases. Trigger scenarios: "start designing solution", "write design doc", "prepare to implement XX", with the precondition that what to do, for whom, and what counts as success are already known.
