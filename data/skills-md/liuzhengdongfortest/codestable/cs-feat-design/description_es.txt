Fase 1 del proceso de características: redacte un documento de diseño para la nueva característica como único insumo para su posterior implementación y aceptación. Primero recopile evidencia (lea la arquitectura, lea el código relevante, haga grep para evitar conflictos de términos, verifique los archivos), luego escriba un primer borrador completo de una vez (incluido el contenido frontal de YAML + estructura de tres capas + diseño de prueba), envíelo al usuario para una revisión holística, itere hasta su aprobación. Después de la aprobación, extraiga {slug}-checklist.yaml de {slug}-design.md para usarlo en las dos fases siguientes. Escenarios desencadenantes: "comenzar a diseñar una solución", "escribir un documento de diseño", "prepararse para implementar XX", con la condición previa de que ya se sepa qué hacer, para quién y qué se considera éxito.
