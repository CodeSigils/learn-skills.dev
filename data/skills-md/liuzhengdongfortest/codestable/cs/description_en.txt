CodeStable workflow family’s root entry—introduces users to the overall architecture and routes their specific requests to the correct cs-* sub-skill. Trigger scenarios: the user types only `cs` / `/cs`, says “introduce CodeStable,” “do something with CodeStable,” “I want to do X, which skill should I use,” “don’t know which one to use,” or describes an open-ended need (“let’s get started”) that hasn’t narrowed to a specific sub-skill. This skill itself **does nothing**—writes no spec, writes no code, reads/writes no artifacts inside the codestable/ directory—only scans, routes, prompts, then hands control to the target sub-skill.
