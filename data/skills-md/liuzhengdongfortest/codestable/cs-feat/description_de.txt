Wenn Sie eine neue Funktion entwickeln, beginnen Sie mit diesem Teilprozess: Verwandeln Sie die vage Idee von „Fähigkeit Auslösende Szenarien konzentrieren sich auf neue Funktionen („Neue Funktion erstellen“, „X hinzufügen“, „XX implementieren“) und decken keine Fehler im vorhandenen Code ab. Diese Fertigkeit führt nur Routen; Basierend auf vorhandenen Artefakten wird über den nächsten Schritt zwischen Brainstorming, Design, Fastforward, Implementierung und Akzeptanz entschieden.
