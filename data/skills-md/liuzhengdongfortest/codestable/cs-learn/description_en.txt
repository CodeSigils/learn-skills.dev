Turn the pitfalls you hit and the good practices you found in this project into searchable learning docs, so both AI and people can find them next time a similar task shows up. Two tracks: the Pitfall track logs “should have worked but didn’t” moments—bugs, config traps, environment issues, integration failures; the Knowledge track logs “do it this way from now on” discoveries—best practices, workflow improvements, reusable patterns. Trigger moments: at the end of feature-acceptance or issue-fix, proactively prompt, or when a user says “capture knowledge,” “learning,” “document learnings,” “write this lesson down.” Spec records what was done; learning records what tripped you / what you learned—they complement, never replace each other.
