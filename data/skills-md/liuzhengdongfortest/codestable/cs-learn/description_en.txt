Turn the pitfalls encountered and the good practices discovered in this project into a searchable learning document, so both AI and humans can find it next time a similar task arises. Two tracks: the Pitfall track records “should have worked but didn’t” experiences—bugs, config traps, environment issues, integration failures; the Knowledge track records “do it this way by default from now on” discoveries—best practices, workflow improvements, reusable patterns. Trigger moments: proactively prompt at the end of feature-acceptance or issue-fix, or when the user says “capture knowledge,” “learning,” “document learnings,” “write down this experience.” Spec records what was done; learning records what tripped us up / what we learned—they complement, not replace, each other.
