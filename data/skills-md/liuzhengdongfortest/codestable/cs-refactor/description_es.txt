Al optimizar el código, ingrese este subproceso: manejar el trabajo donde "el comportamiento permanece igual, la estructura cambia" (estructura/rendimiento/legibilidad). Reemplace el enfoque de "refactorización aleatoria de IA" por "primer escaneo para generar una lista de verificación, confirmar cada elemento con el usuario, ejecutar paso a paso usando la biblioteca de métodos, aprobación humana en cada paso". Escenarios desencadenantes: el usuario dice "optimizar / refactorizar / reescribir / dividir / rendimiento deficiente / codificar demasiado tiempo" sin ningún cambio de comportamiento. No maneja nuevos requisitos (función de uso), no maneja errores (problema de uso), no maneja la reorganización arquitectónica entre módulos (arquitectura de uso + decisiones).
