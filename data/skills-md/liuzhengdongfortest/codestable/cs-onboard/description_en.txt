Connect a new repo or one with scattered docs to the CodeStable system. Two paths are auto-detected: empty-repo path (no spec docs and no codestable/ folder) builds the skeleton from scratch; migration path (existing scattered docs or partial codestable/ structure) first produces an audit report + migration map, which the user confirms item by item before persisting. This skill only does “build skeleton” and “archive legacy”; once the skeleton is ready, all sub-workflows run immediately. Trigger phrases: “use CodeStable in this project”, “set up CodeStable structure”, “initialize CodeStable”, “migrate to CodeStable”.
