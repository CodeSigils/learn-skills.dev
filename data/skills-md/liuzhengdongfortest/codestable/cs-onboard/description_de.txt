Verbinden Sie ein neues Repo oder ein Repo mit verstreuten Dokumenten mit dem CodeStable-System. Zwei Pfade werden automatisch erkannt: Der leere Repo-Pfad (keine Dokumente im Spec-Stil und kein Codestable/-Ordner) erstellt das Grundgerüst von Grund auf; Der Migrationspfad (verstreute Dokumente oder teilweise Codetabelle/Struktur sind bereits vorhanden) erstellt zunächst einen Prüfbericht + Migrationskarte, der vom Benutzer Element für Element bestätigt wird, bevor er geschrieben wird. Diese Fertigkeit funktioniert nur „Skelett aufbauen“ und „Vermächtnis archivieren“. Sobald das Grundgerüst fertig ist, können alle Unterworkflows sofort ausgeführt werden. Auslösephrasen: Der Benutzer sagt „CodeStable in diesem Projekt verwenden“, „CodeStable-Struktur einrichten“, „CodeStable initialisieren“, „zu CodeStable migrieren“.
