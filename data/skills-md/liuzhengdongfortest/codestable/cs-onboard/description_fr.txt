Connectez un nouveau dépôt ou un dépôt avec des documents dispersés au système CodeStable. Deux chemins sont détectés automatiquement : le chemin du dépôt vide (pas de documentation de spécification et pas de dossier codestable/) construit le squelette à partir de zéro ; Le chemin de migration (documents dispersés existants ou table de codes/structure partielle) produit d'abord un rapport d'audit + une carte de migration, que l'utilisateur confirme élément par élément avant de persister. Cette compétence ne fait que « construire le squelette » et « archiver l'héritage » ; une fois le squelette prêt, tous les sous-workflows s'exécutent immédiatement. Phrases déclencheurs : « utiliser CodeStable dans ce projet », « configurer la structure CodeStable », « initialiser CodeStable », « migrer vers CodeStable ».
