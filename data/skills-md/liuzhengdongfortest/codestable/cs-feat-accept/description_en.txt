Feature process phase 3—complete the acceptance loop. Four tasks: first, layer-by-layer verification against {slug}-design.md to check if implementation deviated, fix deviations on the spot rather than "noting them down" in a report; second, merge this feature into the project's overall architecture documentation; third, if this feature changed the user story or boundaries of the corresponding requirement, update the requirement doc accordingly; fourth, if this feature originated from a roadmap item, mark the corresponding entry in roadmap items.yaml as done and sync with the main document. Finally produce a {slug}-acceptance.md as the closing credential for the entire process. Prerequisite: cs-feat-impl completed. Trigger scenarios: user says "feature is done, please accept," "do final check," "ready to merge," or "produce acceptance report."
