Contrôlez les vrais navigateurs via les extensions Chrome. Utilisez-le lorsque vous devez visiter des pages Web, extraire des données, cliquer sur des boutons, remplir des formulaires, automatiser les navigateurs, capturer des preuves de composants rendus ou manipuler des pages par programme. Renvoie des résultats structurés économisant les jetons via DOM diff, HTML simplifié et des packs de preuves de composants. Idéal pour le contrôle du navigateur, l'automatisation du Web, le scraping de pages, l'extraction de données Web, l'exécution de JS dans le navigateur, web_scan, web_execute_js, ouvrir le navigateur, naviguer vers une URL, obtenir le contenu de la page, remplir un formulaire, cliquer sur un bouton, extraire un composant, rendre le DOM, les styles calculés, les preuves de composants.
