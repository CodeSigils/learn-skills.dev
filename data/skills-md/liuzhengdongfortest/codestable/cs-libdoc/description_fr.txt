Générez une documentation de référence élément par élément pour la surface publique de la bibliothèque (composants, fonctions, commandes, etc.), avec suivi de liste de contrôle, prenant en charge les modes d'élément unique et par lots.  
Différence fondamentale avec guidedoc : guidedoc vous apprend à utiliser, libdoc vous indique à quoi ressemble chaque partie ; La source d'informations de guidedoc est Solution Docs + User Knowledge, la source de libdoc est le code lui-même.  
Scénarios de déclenchement : l'utilisateur dit « écrire des documents sur l'API », « des documents sur les composants », « libdoc », « écrire des documents pour chaque composant », ou après l'acceptation des fonctionnalités, de nouvelles interfaces publiques de la bibliothèque sont trouvées.
