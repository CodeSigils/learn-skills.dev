Fase 1 del flujo de trabajo del problema: a través del diálogo, cristalizar el problema en la mente del usuario en un {slug}-report.md reproducible y rastreable. En esta etapa, la IA sólo pregunta "qué viste, cómo reproducirlo, qué debería suceder" y no adivina la causa raíz para el usuario (ese es el trabajo de la Fase 2). Mientras tanto, esta fase es el único punto de decisión formal para determinar si se debe tomar la vía rápida o la vía estándar: basándose en la descripción del usuario, primero lea el código relevante; si se puede identificar de un vistazo y requiere cambios mínimos, informe directamente al usuario para que tome la vía rápida. Escenarios desencadenantes: el usuario dice "presentar un problema", "registrar este error" o "encontré un problema". Este es el punto de partida del flujo de trabajo del problema sin dependencias previas.
