Générez une documentation de référence entrée par entrée pour la surface publique de la bibliothèque (composants, fonctions, commandes, etc.), avec suivi de liste de contrôle, prenant en charge les modes entrée unique et batch. La différence fondamentale avec guidedoc : guidedoc vous apprend à l'utiliser, libdoc vous indique à quoi ressemble chaque partie ; La source d'informations de guidedoc est Solution Docs + User Knowledge, la source d'informations de libdoc est le code source lui-même. Scénarios de déclenchement : l'utilisateur dit « écrire la documentation de l'API », « la documentation des composants », « libdoc », « écrire la documentation pour chaque composant » ou lorsque de nouvelles interfaces publiques de bibliothèque sont découvertes après l'acceptation des fonctionnalités.
