Generate reference documentation item-by-item for the library’s public surface (components, functions, commands, etc.), with checklist tracking, supporting both single-item and batch modes.  
Fundamental difference from guidedoc: guidedoc teaches you how to use it; libdoc tells you what each part looks like; guidedoc’s information source is the solution doc + user knowledge, libdoc’s source is the code itself.  
Trigger scenarios: user says “write API docs,” “component docs,” “libdoc,” “write a doc for every component,” or after feature-acceptance new library public interfaces are detected.
