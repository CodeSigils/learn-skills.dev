When developing new features, enter this sub-process—taking "add X capability" from vague idea to closed-loop acceptance, with design documents archived so both AI and users can later check what was thought and why decisions were made. Trigger scenarios lean toward adding new capabilities ("build new feature", "add X", "implement XX"), not handling bugs in existing code. This skill only handles routing, determining which of brainstorm / design / fastforward / implement / acceptance to proceed to based on existing artifacts.
