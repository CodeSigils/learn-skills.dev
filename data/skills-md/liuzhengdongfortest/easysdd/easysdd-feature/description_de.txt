Wenn Sie neue Funktionen entwickeln, treten Sie in diesen Teilprozess ein – indem Sie „X-Fähigkeit hinzufügen“ von einer vagen Idee bis hin zur Akzeptanz im geschlossenen Regelkreis führen, wobei Designdokumente archiviert werden, damit sowohl KI als auch Benutzer später überprüfen können, was gedacht wurde und warum Entscheidungen getroffen wurden. Triggerszenarien tendieren dazu, neue Funktionen hinzuzufügen („Neue Funktion erstellen“, „X hinzufügen“, „XX implementieren“) und nicht Fehler in vorhandenem Code zu behandeln. Diese Fertigkeit kümmert sich nur um das Routing und bestimmt anhand vorhandener Artefakte, mit welchem ​​Brainstorming/Entwurf/Schnellvorlauf/Implementierung/Akzeptanz fortgefahren werden soll.
