Etapa 1 del proceso de emisión: transforme el problema en la mente del usuario en un {slug}-report.md reproducible y rastreable a través del diálogo. La IA sólo pregunta "qué se vio, cómo reproducirlo, qué debería suceder", sin adivinar las causas fundamentales para el usuario (ese es el trabajo de la Etapa 2). Esta etapa es también el único punto de decisión formal para determinar la vía rápida versus la vía estándar: según la descripción del usuario, primero lea el código relevante; si se puede identificar de un vistazo con cambios mínimos, informe directamente al usuario para que tome la vía rápida. Escenarios desencadenantes: el usuario dice "presentar un problema", "documentar este error", "encontré un problema". Este es el punto de partida del flujo de trabajo del problema sin dependencias de requisitos previos.
