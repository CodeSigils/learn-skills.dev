Issue workflow stage 1—turn the problem in the user’s mind into a reproducible, traceable {slug}-report.md through conversation. The AI only asks “what did you see, how to reproduce, what should happen,” without guessing the root cause (that’s stage 2). This stage is also the single formal checkpoint to decide fast-track or standard path: after reading the relevant code based on the user’s description, if the fix is obvious and trivial, directly tell the user to take the fast-track. Trigger: user says “file an issue,” “log this bug,” “I found a problem.” Starting point of the issue workflow, no prerequisites.
