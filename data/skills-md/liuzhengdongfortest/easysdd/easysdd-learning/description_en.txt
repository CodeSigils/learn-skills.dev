Turn the pitfalls you hit and the good practices you found in this task into a searchable learning doc, so both AI and people can look it up next time a similar job appears. Two tracks:  
- Pitfall track – log “should have worked but didn’t” moments: bugs, config traps, environment issues, integration failures.  
- Knowledge track – log “do it this way by default from now on” discoveries: best practices, workflow improvements, reusable patterns.  

Trigger: prompt automatically when finishing feature-acceptance or issue-fix, or when a user says “capture knowledge”, “learning”, “document learnings”, “write down this experience”.  

Spec records what was done; learning records what was tripped over / what was learned—they complement, not replace, each other.
