Ein superleichter Kanal für den Feature-Prozess – kein Designdokument, keine Checkliste, keine inszenierten Überprüfungen. Lassen Sie die KI einfach wie gewohnt direkt Code schreiben, aber teilen Sie ihr vor dem Start mit, wo sich die easysdd-Wissensdatenbank des Projekts befindet und wie sie durchsucht werden soll, damit der von ihr geschriebene Code weitere Fallstricke vermeidet und besser mit den Projektkonventionen übereinstimmt. Auslöseszenarien: Der Benutzer sagt „Schnellmodus“, „Schnellvorlauf“, „Schritte überspringen“, „Mach es einfach“, „Hilf mir, ein xxx zu erstellen“ und die Anforderung ist zu gering, um den Designprozess zu rechtfertigen.
