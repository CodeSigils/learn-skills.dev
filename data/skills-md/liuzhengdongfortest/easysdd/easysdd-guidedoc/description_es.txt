Redactar o actualizar los documentos de guía externos del proyecto: guía para desarrolladores (guía de desarrollo, para contribuyentes/integradores/desarrolladores intermedios) y guía de usuario (guía de usuario, para usuarios finales). Los entregables van al directorio docs/ del proyecto, se mantienen junto con el código y pueden indexarse ​​mediante herramientas de búsqueda. Diferencia con libdoc: Guidedoc está orientado a tareas ("cómo hacer Y con X"), libdoc está orientado a referencias ("cómo se ve cada parte de X"). Escenarios desencadenantes: el usuario dice "escribir documentos", "guía para desarrolladores", "guía para el usuario" o se presiona de manera proactiva cuando finaliza la aceptación de funciones.
