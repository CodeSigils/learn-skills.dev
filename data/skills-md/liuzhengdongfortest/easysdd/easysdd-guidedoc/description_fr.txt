Rédiger ou mettre à jour les documents de guide externes du projet : guide du développeur (guide de développement, pour les contributeurs/intégrateurs/développeurs en aval) et guide de l'utilisateur (guide de l'utilisateur, pour les utilisateurs finaux). Les livrables vont dans le répertoire docs/ du projet, sont conservés à côté du code et peuvent être indexés par les outils de recherche. Différence avec libdoc : guidedoc est orienté tâche ("comment faire Y avec X"), libdoc est orienté référence ("à quoi ressemble chaque partie de X"). Scénarios de déclenchement : l'utilisateur dit « écrire des documents », « guide du développeur », « guide de l'utilisateur » ou il est poussé de manière proactive lorsque l'acceptation des fonctionnalités est terminée.
