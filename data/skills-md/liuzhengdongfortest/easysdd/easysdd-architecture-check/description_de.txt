Führen Sie einen Architektur-Gesundheitscheck durch und wählen Sie eine von drei Möglichkeiten aus: Überprüfen Sie, ob ein Design intern konsistent ist (keine Konflikte zwischen Bedingungen, Verträgen oder Implementierungsschritten); Überprüfen Sie, ob das Design und der Code übereinstimmen (gemachte Versprechen werden tatsächlich im Code eingehalten); Stellen Sie sicher, dass mehrere Architekturdokumente unter „easysdd/architecture/“ miteinander konsistent sind (keine Konflikte in Bezug auf Begriffe, Modulgrenzen oder dokumentübergreifende Verweise). Dieser Skill gibt nur eine Liste von Problemen und Lösungsvorschlägen aus und ändert selbst nie etwas. Jeder Lauf zielt auf genau einen Gegenstand ab; „Während ich schon dabei bin“-Kontrollen sind verboten. Wird ausgelöst, wenn der Benutzer sagt: „Architekturprüfung durchführen“, „Ist das Design intern konsistent“, „Stimmt das Design mit dem Code überein“, „Dokumente im Architekturordnerkonflikt prüfen“ oder wenn jemand eine schnelle Überprüfung wünscht, bevor er mit der Implementierung/Abnahme fortfährt.
