Извлекает, проверяет и отслеживает обновления журнала изменений Claude Code с GitHub с помощью веб-браузера Apify RAG. Выводит форматированную уценку в DOCUMENTATION/. Используйте, когда пользователь хочет обновить журнал изменений, проверить статус журнала изменений, отслеживать обновления кода Claude, получить последние выпуски или упоминает «журнал изменений», «обновления кода Claude», «что нового в коде Claude», «проверить журнал изменений».
