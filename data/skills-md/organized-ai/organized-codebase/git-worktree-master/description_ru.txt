Главный оркестратор для операций рабочего дерева git — управление параллельными ветвями, изолированными рабочими пространствами и эффективными рабочими процессами с несколькими ветвями. Используйте, когда: (1) пользователю необходимо работать над несколькими ветвями одновременно, (2) пользователь хочет просмотреть запросы на поставку без переключения ветвей, (3) пользователю требуется изоляция исправлений, пока работа над функциями продолжается, (4) пользователь спрашивает о рабочих деревьях, параллельной разработке или изоляции ветвей, (5) конвейерам CI/CD необходимы изолированные среды сборки, (6) пользователь упоминает «рабочее дерево», «параллельные ветки», «изолированное рабочее пространство» или «ветвь без переключения».
