git worktree 操作のマスター オーケストレーター - 並列ブランチ、分離されたワークスペース、効率的なマルチブランチ ワークフローを管理します。 (1) ユーザーが複数のブランチで同時に作業する必要がある場合、(2) ユーザーがブランチを切り替えずに PR をレビューしたい場合、(3) ユーザーが機能の作業を継続中にホットフィックスの分離が必要な場合、(4) ユーザーがワークツリー、並列開発、またはブランチ分離について質問する場合、(5) CI/CD パイプラインに分離されたビルド環境が必要な場合、(6) ユーザーが「ワークツリー」、「並列ブランチ」、「分離されたワークスペース」、または「切り替えなしのブランチ」について言及した場合に使用します。
