المنسق الرئيسي لعمليات git Worktree - إدارة الفروع المتوازية ومساحات العمل المعزولة وسير العمل الفعال متعدد الفروع. يُستخدم عندما: (1) يحتاج المستخدم إلى العمل على فروع متعددة في وقت واحد، (2) يريد المستخدم مراجعة العلاقات العامة دون تبديل الفروع، (3) يحتاج المستخدم إلى عزل الإصلاح العاجل أثناء استمرار عمل الميزات، (4) يسأل المستخدم عن أشجار العمل أو التطوير المتوازي أو عزل الفرع، (5) تحتاج خطوط أنابيب CI/CD إلى بيئات بناء معزولة، (6) يذكر المستخدم "شجرة العمل" أو "الفروع المتوازية" أو "مساحة العمل المعزولة" أو "الفرع بدون تبديل".
