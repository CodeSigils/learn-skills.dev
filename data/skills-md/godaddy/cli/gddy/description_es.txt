Utilice la CLI beta de GoDaddy (`gddy`) para buscar, registrar y administrar dominios y registros DNS. Cargue esta habilidad siempre que una tarea implique ejecutar comandos `gddy`, analizar su salida JSON, encontrar o comprar un dominio o editar registros DNS (A, CNAME, MX, TXT, etc.) para un dominio alojado en GoDaddy. `gddy` es una herramienta separada de la antigua CLI `godaddy` de GoDaddy (aplicaciones, implementaciones, webhooks); no use esta habilidad para esa herramienta y no la active para otros registradores o proveedores de DNS (Cloudflare, Route 53, Namecheap, etc.) a menos que GoDaddy esté explícitamente involucrado.
