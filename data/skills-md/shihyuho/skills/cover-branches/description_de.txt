Finden Sie Lücken in der Zweigabdeckung im geänderten Code und beheben Sie diese, indem Sie fehlende Tests schreiben. Zwei Analyseebenen: Quelle ↔ Test (Logikzweige vs. Testfälle) und Spezifikation ↔ Test (Anforderungsszenarien vs. Testfälle, wenn eine Spezifikationsdatei bereitgestellt wird). Verwenden Sie diese Option, um die Vollständigkeit eines Tests nach der Implementierung einer Funktion oder der Behebung eines Fehlers zu überprüfen, wenn Sie prüfen, ob Tests einer Spezifikation entsprechen, oder wenn Sie den Verdacht haben, dass es sich um ungetestete Zweige handelt.
