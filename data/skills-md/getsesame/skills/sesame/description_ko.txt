사용자가 인증된 HTTP API 호출을 요청하고(예: "GitHub/OpenAI/Slack API 호출", "전달자 토큰이 필요한 엔드포인트에 도달") `sesame` CLI가 이 장치에 이미 설치되어 있는 경우 이 기술을 사용합니다. 에이전트는 'sesame request'를 호출하여 사용자의 자체 브로커를 통해 HTTP 호출을 전달하고 서버측에 인증 헤더를 첨부합니다. 이 기술은 소프트웨어를 설치하지 않고 환경에서 자격 증명을 읽지 않으며 고정된 `sesame` 하위 명령 표면(`request`, `status`, `hostnames`, `login`, `refresh`, `switch`, `police`, `help`, `secret`, `agents`, `deploy`) 내에서만 셸을 실행합니다. 인증되지 않은 퍼블릭 엔드포인트, localhost 서비스 또는 사용자가 직접 사용하기 위해 이미 환경에 토큰을 내보낸 경우에는 건너뜁니다.
