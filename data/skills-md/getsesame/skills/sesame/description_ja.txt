このスキルは、ユーザーが認証済み HTTP API の呼び出しを要求し (たとえば、「GitHub/OpenAI/Slack API を呼び出す」、「ベアラー トークンが必要なエンドポイントにヒットする」)、「sesame」 CLI がこのデバイスにすでにインストールされている場合に使用します。エージェントは「sesame request」を呼び出します。これにより、ユーザー独自のブローカーを介して HTTP 呼び出しが転送され、サーバー側で認証ヘッダーが添付されます。このスキルはソフトウェアをインストールせず、環境から資格情報を読み取りません。また、固定の `sesame` サブコマンド サーフェイス (`request`、`status`、`hostnames`、`login`、`refresh`、`switch`、`police`、`help`、`secret`、`agents`、`deploy`) 内でのみシェルを実行します。認証されていないパブリック エンドポイント、ローカルホスト サービスの場合、またはユーザーが直接使用するために環境内にトークンを既にエクスポートしている場合はスキップします。
