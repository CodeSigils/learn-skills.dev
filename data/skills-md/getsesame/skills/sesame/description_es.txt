Utilice esta habilidad cuando el usuario solicite llamar a una API HTTP autenticada (por ejemplo, "llamar a la API de GitHub/OpenAI/Slack", "acceder a un punto final que necesita un token de portador") y la CLI `sesame` ya esté instalada en este dispositivo. El agente invoca una "solicitud de sésamo", que reenvía la llamada HTTP a través del propio intermediario del usuario y adjunta el encabezado de autenticación en el lado del servidor. La habilidad no instala software, no lee credenciales del entorno y ejecuta el shell solo dentro de la superficie de subcomando fija `sesame` (`solicitud`, `status`, `hostnames`, `login`, `refresh`, `switch`, `police`, `help`, `secret`, `agents`, `deploy`). Omita puntos finales públicos no autenticados, servicios de host local o cuando el usuario ya haya exportado un token en el entorno para uso directo.
