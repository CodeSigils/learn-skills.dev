Utilisez cette compétence lorsque l'utilisateur demande à appeler une API HTTP authentifiée (par exemple « appeler l'API GitHub/OpenAI/Slack », « atteindre un point de terminaison qui a besoin d'un jeton de support ») et que la CLI « sésame » est déjà installée sur cet appareil. L'agent appelle une « requête sésame », qui transmet l'appel HTTP via le propre courtier de l'utilisateur et attache l'en-tête d'authentification côté serveur. La compétence n'installe pas de logiciel, ne lit pas les informations d'identification de l'environnement et exécute le shell uniquement dans la surface de sous-commande `sesame` fixe (`request`, `status`, `hostnames`, `login`, `refresh`, `switch`, `police`, `help`, `secret`, `agents`, `deploy`). Ignorez les points de terminaison publics non authentifiés, les services localhost ou lorsque l'utilisateur a déjà exporté un jeton dans l'environnement pour une utilisation directe.
