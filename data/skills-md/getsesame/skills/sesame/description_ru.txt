Используйте этот навык, когда пользователь запрашивает вызов аутентифицированного HTTP API (например, «вызовите GitHub/OpenAI/Slack API», «достигните конечной точки, которой нужен токен носителя»), а интерфейс командной строки `sesame` уже установлен на этом устройстве. Агент вызывает «сезам-запрос», который перенаправляет HTTP-вызов через собственного брокера пользователя и присоединяет заголовок аутентификации на стороне сервера. Навык не устанавливает программное обеспечение, не считывает учетные данные из среды и запускает оболочку только в пределах фиксированной поверхности подкоманды sesame (запрос, статус, имена хостов, вход в систему, обновление, переключение, полиция, помощь, секрет, агенты, развертывание). Пропускайте для общедоступных конечных точек, не прошедших проверку подлинности, служб localhost или когда пользователь уже экспортировал токен в среду для прямого использования.
