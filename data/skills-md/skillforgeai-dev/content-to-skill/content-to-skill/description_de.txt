Wandeln Sie beliebige Inhalte in einen Claude-Skill um. Akzeptiert Texte, Dokumente, Audiodateien oder Videodateien und wandelt sie in ein ordnungsgemäß strukturiertes SKILL.md mit optionalen gebündelten Ressourcen um. Unterstützt zwei Skill-Modi: Wissenstyp (Analyse-Frameworks, Referenzhandbücher, Entscheidungsbäume) und Aktionstyp (ausführbare Workflows mit Skripten, API-Aufrufen, Dateioperationen). Erkennt anhand des Inhalts automatisch den besten Modus, der Benutzer kann ihn jedoch überschreiben. Akzeptiert optionale Benutzeranweisungen, um den Fokus und das Verhalten des generierten Skills anzupassen. Verwenden Sie diesen Skill immer dann, wenn der Benutzer sagt: „In einen Skill umwandeln“, „Daraus einen Skill erstellen“, „Fähigkeit erstellen“, „Inhalt zum Skill hinzufügen“ oder eine Datei (Video, Audio, PDF, Artikel, Tutorial, Transkript, Dokumentation) hochlädt und möchte, dass sie in einen wiederverwendbaren Skill umgewandelt wird. Wird auch ausgelöst, wenn der Benutzer Text einfügt (eine Anleitung, einen Prozess, einen Arbeitsablauf, Tipps, eine Anleitung) und ihn um eine Verfeinerung bittet. 万物皆可 Skill:将任何内容转化为可复用的 Claude 技能.支持知识型和动作型两种模式,自动判断素材类型, 也接受用户自定义指令.
