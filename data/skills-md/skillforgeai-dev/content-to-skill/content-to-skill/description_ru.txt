Превратите любой контент в навык Клода. Принимает текст, документы, аудиофайлы или видеофайлы и преобразует их в правильно структурированный SKILL.md с дополнительными связанными ресурсами. Поддерживает два режима навыков: тип знаний (структуры анализа, справочные руководства, деревья решений) и тип действий (исполняемые рабочие процессы со сценариями, вызовами API, файловыми операциями). Автоматически определяет лучший режим по контенту, но пользователь может его изменить. Принимает дополнительные инструкции пользователя для настройки направленности и поведения создаваемого навыка. Используйте этот навык всякий раз, когда пользователь говорит: «Преврати это в навык», «Сделай из этого навык», «Необходимый навык», «Содержимое для навыка» или загружает любой файл (видео, аудио, PDF, статью, руководство, стенограмму, документацию) и хочет преобразовать его в навык многократного использования. Также срабатывает, когда пользователь вставляет текст (руководство, процесс, рабочий процесс, советы, инструкции) и просит его повысить квалификацию. 万物皆可 Skill: 将任何内容转化为可复用的 Клод 技能。支持知识型和动作型两种模式,自动判断素材类型,也接受用户自定义指令。
