Testare l'analisi dell'impatto per i repository fullstack. Fork di tdad v0.2.0 con supporto Vue SFC e miglioramenti della CLI. Da utilizzare quando è necessario trovare quali test sono interessati dalle modifiche al codice in un progetto poliglotta, ad es. modificato un'utilità Python + un componente Vue, voglio sapere quali file pytest + vitest + jest rieseguire. Attivalo quando vedi una directory `.tdad/` in un progetto con sia file `pyproject.toml` (o `package.json`) CHE file `.vue` o quando lavori su un monorepo multilingue. Sostituisce ad hoc `git diff | xargs jest --findRelatedTests` flussi di lavoro con un grafico.
