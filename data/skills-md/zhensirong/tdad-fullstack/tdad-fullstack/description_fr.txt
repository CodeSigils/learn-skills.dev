Testez l’analyse d’impact pour les dépôts fullstack. Fork de tdad v0.2.0 avec prise en charge de Vue SFC et améliorations de la CLI. À utiliser lorsque vous devez rechercher quels tests sont affectés par les modifications de code dans un projet polyglotte - par ex. modifié un utilitaire Python + un composant Vue, je veux savoir quels fichiers pytest + vitest + jest réexécuter. Activez lorsque vous voyez un répertoire `.tdad/` dans un projet avec à la fois des fichiers `pyproject.toml` (ou `package.json`) ET `.vue`, ou lorsque vous travaillez sur un monorepo multilingue. Remplace `git diff ad hoc | xargs jest --findRelatedTests` workflows avec un graphique.
