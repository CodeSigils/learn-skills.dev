Анализ влияния тестирования для репозиториев полного стека. Форк tdad v0.2.0 с поддержкой Vue SFC и улучшениями CLI. Используйте, когда вам нужно выяснить, на какие тесты влияют изменения кода в многоязычном проекте — например. изменил утилиту Python + компонент Vue, хочу знать, какие файлы pytest + vitest + jest нужно повторно запустить. Активируйте, когда вы видите в проекте каталог `.tdad/` с файлами `pyproject.toml` (или `package.json`) И `.vue`, или при работе с многоязычным монорепозиторием. Заменяет специальный `git diff | xargs jest --findRelatedTests` рабочие процессы с одним графиком.
