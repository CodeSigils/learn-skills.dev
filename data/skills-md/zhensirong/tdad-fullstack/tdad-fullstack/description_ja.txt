フルスタック リポジトリの影響分析をテストします。 Vue SFC サポートと CLI 拡張機能を備えた tdad v0.2.0 のフォーク。多言語プロジェクトのコード変更によってどのテストが影響を受けるかを確認する必要がある場合に使用します。例: Python ユーティリティ + Vue コンポーネントを変更しました。どの pytest + vitest + jest ファイルを再実行するかを知りたいです。 `pyproject.toml` (または `package.json`) と `.vue` ファイルの両方を含むプロジェクト内に `.tdad/` ディレクトリが表示された場合、または多言語モノリポジトリで作業している場合にアクティブ化します。アドホックな `git diff | を置き換えます。 xargs jest --findManyTests` ワークフローは 1 つのグラフを使用します。
