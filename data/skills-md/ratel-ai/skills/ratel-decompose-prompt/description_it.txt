Suddividi un sistema di agenti gonfio e monolitico in un nucleo snello e stabile con competenze estratte in stile Ratel. Da utilizzare quando un prompt è troppo lungo o fa troppe cose, per estrarre o fattorizzare le procedure in abilità, scomporre o dividere un prompt, ridurre il costo dei token per turno o `/ratel-decompose-prompt`. Scrive un piano di scomposizione del markdown (nucleo snello, inventario delle competenze, definizioni di SKILL per competenza, cablaggio di registrazione) in <repo>/.ratel/ senza riscrivere il prompt o il codice. Raggiungibile dalla dimensione Prompt Decomposition di /ratel-assessment; si accoppia con le definizioni di /ratel-tune.
