LangSmith MCP 서버(또는 langsmith SDK 대체)를 통해 고객의 실시간 LangSmith 실행, 추적, 스레드 및 피드백 점수를 읽고, 공유 결과 카탈로그에 대한 패턴 일치를 수행하고, Ratel 기반 개선 사항과 스택에 구애받지 않는 낮은 매달린 결과로 분할된 결과 보고서를 작성합니다. LangSmith 대시보드를 스캔하고, 실행 트리 또는 실패한 실행을 자세히 살펴보고, 이번 주의 실행을 검토하고, 관찰 가능성을 감사하고, 에이전트가 무엇을 잘못하고 있는지 확인하거나 `/ratel-langsmith-analyze`에 사용합니다. <repo>/.ratel/에 쓰기(누적); 연결할 수 있는 서버나 API 키가 없으면 빠르게 실패하고, 깨끗한 데이터를 정직하게 건너뛰고, 코드를 편집하지 않습니다. /ratel-langsmith-integrate에 대한 후속 조치.
