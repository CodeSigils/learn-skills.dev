LangSmith MCP サーバー (または langsmith SDK フォールバック) を介して顧客のライブ LangSmith 実行、トレース、スレッド、およびフィードバック スコアを読み取り、共有検出結果カタログとパターン マッチングし、Ratel 風味の改善とスタックに依存しない簡単な成果に分割された検出結果レポートを作成します。 LangSmith ダッシュボードをスキャンし、実行ツリーまたは失敗した実行を調べ、今週の実行をレビューし、その可観測性を監査し、エージェントの何が間違っているかを確認するか、「/ratel-langsmith-analyze」を使用します。 <repo>/.ratel/ に書き込みます (蓄積します)。到達可能なサーバーまたは API キーがないとすぐに失敗し、クリーンなデータを正直にスキップし、コードを編集することはありません。 /ratel-langsmith-integrate のフォローアップ。
