اقرأ عمليات تشغيل LangSmith المباشرة للعميل، والتتبعات، والخيوط، ونتائج التعليقات عبر خادم LangSmith MCP (أو langsmith SDK الاحتياطي)، ومطابقة الأنماط مع كتالوج النتائج المشترك، واكتب تقرير النتائج مقسمًا إلى تحسينات بنكهة Ratel وفواكه معلقة منخفضة. استخدمه لمسح لوحة معلومات LangSmith، أو البحث في شجرة التشغيل أو عمليات التشغيل الفاشلة، أو مراجعة عمليات التشغيل لهذا الأسبوع، أو تدقيق إمكانية ملاحظتها، أو معرفة الخطأ الذي يفعله الوكيل، أو `/ratel-langsmith-analyze`. يكتب إلى <repo>/.ratel/ (يتراكم)؛ يفشل بسرعة بدون خادم يمكن الوصول إليه أو مفتاح واجهة برمجة التطبيقات (API)، ويتخطى البيانات النظيفة، ولا يقوم بتحرير التعليمات البرمجية مطلقًا. متابعة /ratel-langsmith-integrate.
