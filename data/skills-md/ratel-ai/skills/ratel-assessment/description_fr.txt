Lisez la base de code de l'agent d'un partenaire, notez-la dans le catalogue à 12 dimensions et générez une démarque citée par des preuves ainsi qu'un rapport HTML de notation de marque. À utiliser pour un audit au premier contact : évaluer/examiner/auditer notre agent, où s'améliorer, repérer les fruits à portée de main, une lecture honnête de ce qui est faible, ce que Ratel remarquerait, ou `/ratel-assessment`. Statique uniquement, sauf si un échantillon Langfuse est câblé en MCP ; écrit dans <repo>/.ratel/ sans modifier le code ; des itinéraires vers des compétences Ratel de suivi.
