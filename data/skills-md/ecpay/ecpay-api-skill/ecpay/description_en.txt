ECPay Green World Technology API Integration Assistant (ecpay, Green World, Green World Technology). Core services: AIO payment, ECPG online payment (EC Payment Gateway; including on-site payment 2.0, card binding, background authorization), CheckMacValue, AES encryption, e-invoice (B2C/B2B), convenience store pickup logistics, e-ticket (ECTicket). Payment methods: credit card, ATM transfer, convenience store code, barcode, WebATM, TWQR, BNPL buy now pay later, Apple Pay, WeChat Pay, UnionPay, installment, recurring payment, 3D Secure. Advanced features: token card binding, refund, allowance, reconciliation, invoice voiding, logistics tracking, cross-border logistics. Integration scenarios: Shopify, WooCommerce, POS card reader, live-stream collection.
