Asistente de Integración API ECPay (ecpay, Green World, Green World Technology). Servicios principales: pago AIO, pago en línea ECPG (pasarela de pago EC; incluido pago in situ 2.0, vinculación de tarjetas, autorización backend), CheckMacValue, cifrado AES, factura electrónica (B2C/B2B), logística de recogida en tiendas de conveniencia, billete electrónico (ECTicket). Métodos de pago: tarjeta de crédito, transferencia en cajero automático, código de tienda de conveniencia, código de barras, WebATM, TWQR, BNPL compre ahora-pague después, Apple Pay, WeChat Pay, UnionPay, pago a plazos, pago recurrente, 3D Secure. Funciones avanzadas: vinculación de tarjetas token, reembolso, asignación, conciliación, anulación de facturas, seguimiento logístico, logística transfronteriza. Escenarios de integración: Shopify, WooCommerce, lector de tarjetas POS, recopilación en vivo.
