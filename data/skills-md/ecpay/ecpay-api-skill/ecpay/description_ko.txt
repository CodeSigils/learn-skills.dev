ECPay GreenTech API 통합 도우미(ecpay, GreenTech). 핵심 서비스: AIO 결제 흐름, ECPG 온라인 결제 게이트웨이(EC 결제 게이트웨이, 현장 결제 2.0, 카드 바인딩, 백엔드 승인 포함), CheckMacValue, AES 암호화, 전자 송장(B2C/B2B), 편의점 픽업 물류, 전자 티켓(ECTicket). 결제 방법: 신용카드, ATM 이체, 편의점 코드, 바코드, WebATM, TWQR, BNPL 후불결제, Apple Pay, WeChat Pay, UnionPay, 할부, 반복결제, 3D Secure. 고급 기능: 토큰화된 카드 바인딩, 환불, 수당, 조정, 송장 무효화, 물류 추적, 국경 간 물류. 통합 시나리오: Shopify, WooCommerce, POS 카드 리더기, 라이브 스트림 수집.
