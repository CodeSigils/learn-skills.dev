ECPay Green World Technology API 통합 도우미(ecpay, Green World, Green World Technology). 핵심 서비스: AIO 결제, ECPG 온라인 결제(EC Payment Gateway, 현장 결제 2.0, 카드 바인딩, 백그라운드 인증 포함), CheckMacValue, AES 암호화, 전자송장(B2C/B2B), 편의점 픽업 물류, 전자티켓(ECTicket). 결제 방법: 신용카드, ATM 이체, 편의점 코드, 바코드, WebATM, TWQR, BNPL 지금 구매 후 결제, Apple Pay, WeChat Pay, UnionPay, 할부, 반복 결제, 3D Secure. 고급 기능: 토큰 카드 바인딩, 환불, 수당, 조정, 송장 무효화, 물류 추적, 국경 간 물류. 통합 시나리오: Shopify, WooCommerce, POS 카드 리더기, 라이브 스트림 수집.
