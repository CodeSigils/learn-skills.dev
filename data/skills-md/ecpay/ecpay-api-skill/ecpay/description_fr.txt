Assistant d'intégration de l'API ECPay Green World Technology (ecpay, Green World, Green World Technology). Services de base : paiement AIO, paiement en ligne ECPG (EC Payment Gateway ; y compris paiement sur site 2.0, liaison de carte, autorisation en arrière-plan), CheckMacValue, cryptage AES, facture électronique (B2C/B2B), logistique de retrait en magasin, billet électronique (ECTicket). Modes de paiement : carte de crédit, transfert ATM, code de dépanneur, code-barres, WebATM, TWQR, BNPL acheter maintenant, payer plus tard, Apple Pay, WeChat Pay, UnionPay, versement, paiement récurrent, 3D Secure. Fonctionnalités avancées : liaison de carte à jeton, remboursement, allocation, rapprochement, annulation de facture, suivi logistique, logistique transfrontalière. Scénarios d'intégration : Shopify, WooCommerce, lecteur de carte POS, collecte en direct.
