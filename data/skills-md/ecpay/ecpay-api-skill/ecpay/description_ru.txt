Помощник по интеграции API технологий ECPay Green World (ecpay, Green World, Green World Technology). Основные услуги: оплата AIO, онлайн-платеж ECPG (платежный шлюз EC; включая оплату на месте 2.0, привязка карты, фоновая авторизация), CheckMacValue, шифрование AES, электронный счет (B2C/B2B), логистика самовывоза в магазине, электронный билет (ECTicket). Способы оплаты: кредитная карта, банковский перевод, код магазина, штрих-код, WebATM, TWQR, BNPL «Купи сейчас, заплати позже», Apple Pay, WeChat Pay, UnionPay, рассрочка, регулярный платеж, 3D Secure. Расширенные функции: привязка токен-карты, возврат средств, пособие, сверка, аннулирование счетов, отслеживание логистики, трансграничная логистика. Сценарии интеграции: Shopify, WooCommerce, устройство чтения POS-карт, сбор в прямом эфире.
