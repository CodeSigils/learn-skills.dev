Assistente integrazione API tecnologia ECPay (ecpay, 綠界, 綠界科技). Servizi principali: pagamento AIO, pagamento online ECPG (EC Payment Gateway; incluso pagamento in loco 2.0, rilegatura carte, autorizzazione back-end), CheckMacValue, crittografia AES, fattura elettronica (B2C/B2B), logistica di ritiro nei minimarket, biglietto elettronico (ECTicket). Modalità di pagamento: carta di credito, bonifico bancomat, codice minimarket, codice a barre, WebATM, TWQR, BNPL compra ora paga dopo, Apple Pay, WeChat Pay, UnionPay, rata, pagamento ricorrente, 3D Secure. Funzionalità avanzate: rilegatura di carte tokenizzate, rimborso, indennità, riconciliazione, annullamento fatture, tracciamento logistico, logistica transfrontaliera. Scenari di integrazione: Shopify, WooCommerce, terminale per carte POS, ritiro in live streaming.
