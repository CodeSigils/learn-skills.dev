Da utilizzare quando la realtà attuale dello spazio di lavoro Git o non Git necessita di una mappa durevole di radici, proprietà, architettura, comandi, percorsi di attività e contratti riutilizzabili, oppure una mappa esistente necessita di riparazioni basate sull'evidenza; non utilizzare per il rilevamento ordinario di attività locali o per la revisione delle modifiche.
