À utiliser lorsqu'une mutation Git autorisée doit préserver une tâche volumineuse via un jalon sémantique, une correction ciblée ou des validations de points de contrôle exceptionnelles, normaliser l'historique des branches de tâches ou fournir des modifications révisées via une validation, un push, une intégration, un nettoyage ou une preuve de référence ; s'arrête avant la création de la pull-request.
