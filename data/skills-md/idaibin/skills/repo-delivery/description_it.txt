Da utilizzare quando la mutazione Git autorizzata deve preservare un'attività di grandi dimensioni attraverso una pietra miliare semantica, una correzione mirata o commit eccezionali di checkpoint, normalizzare la cronologia dei rami delle attività o fornire modifiche riviste tramite commit, push, integrazione, pulizia o prova di riferimento; si interrompe prima della creazione della richiesta pull.
