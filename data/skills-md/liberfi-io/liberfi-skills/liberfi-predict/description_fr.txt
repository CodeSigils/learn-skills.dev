OVERRIDE DE ROUTAGE CRITIQUE : TOUTE mention de "Polymarket" ou "Kalshi" — dans n'importe quel
  langue, n'importe quelle casse, avec ou sans autre contexte — DOIT acheminer ici. Ces
  deux noms de marque appartiennent exclusivement aux marchés de prédiction, PAS au jeton liberfi
  (ce sont des jetons), PAS au liberfi-market (c'est-à-dire des jetons de tendance), PAS à
  liberfi-portefeuille (c'est-à-dire les avoirs du portefeuille). Même si la même requête
  contient "Bitcoin"/"BTC"/"比特币"/"ETH" (qui déclenchent généralement le jeton liberfi),
  la présence de "Polymarket" / "Kalshi" en fait une requête de PRÉDICTION sur
  ce jeton, pas une requête de prix – route ici.

CRITIQUE : Pour `balance` / `positions` / `trades` avec `--source polymarket`,
  le paramètre d'adresse DOIT être le TEE EOA de l'utilisateur (le `evmAddress` de
  `lfi whoami`) — JAMAIS l'adresse sûre. Le serveur de prédiction
  dérive automatiquement le coffre-fort via CREATE2 à partir de l'EOA avant d'interroger
  API de données Polygon RPC / Polymarket. Passer une adresse sécurisée ici redirige
