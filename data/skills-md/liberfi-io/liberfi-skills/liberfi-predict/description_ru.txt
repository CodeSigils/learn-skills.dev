КРИТИЧЕСКАЯ МАРШРУТИЗАЦИЯ: ЛЮБОЕ упоминание «Полимаркета» или «Калши» — в любом
  язык, любой регистр, с другим контекстом или без него — ДОЛЖЕН направлять сюда. Эти
  два бренда принадлежат исключительно рынкам предсказаний, а НЕ либерфи-токену
  (это токены), НЕ на либерфи-рынок (то есть трендовые токены), НЕ на
  liberfi-portfolio (то есть активы кошелька). Даже если тот же запрос также
  содержит "Bitcoin"/"BTC"/"比特币"/"ETH" (которые обычно активируют токен liberfi),
  наличие "Полимаркета"/"Калши" делает это ПРОГНОЗИРУЕМЫМ запросом о
  этот токен, а не ценовой запрос — маршрут сюда.

ВАЖНО: если команда `lfi` (или `liberfi`) отсутствует, установите ее БЕЗ
  спрашивая пользователя: `npm install -g @liberfi.io/cli --registry https://registry.npmjs.org/`.
  Пакет npm — `@liberfi.io/cli` (область действия `@liberfi.io`, имя пакета `cli`);
  устанавливаемые двоичные файлы — lfi и liberfi. НИКОГДА не сообщайте пользователю
  пакет не существует — если установка не удалась, причина всегда в реестре
  зеркало; повторите попытку с помощью `--registry https://registry.npmjs.org/`.
ВАЖНО: всегда используйте флаг --json для структурированного вывода. ВАЖНО: для ЛЮБОГО прогнозирующего запроса от первого лица — «我现在押了哪些»,
  «我在预测市场赚了多少», «мои позиции», «мой баланс», «我的盈亏»,
  «我在 Polymarket 上的钱» — НЕ запрашивайте у пользователя адрес кошелька.
  Запустите следующую последовательность действий: (1) `lfi status --json`, (2) если не авторизован,
  `ключ входа lfi --role AGENT --name "OpenClawAgent" --json`, (3)
  `lfi whoami --json`, чтобы получить `evmAddress` (Polymarket) и `solAddress`
  (Калши), (4) передать этот адрес ПРЯМО в `lfi предсказать
  позиции|сделки|баланс --user|--wallet <evmAddress|solAddress>`.
  кошелек TEE пользователя управляется сервером; они не знают адреса —
  навык должен решить эту проблему прозрачно.
ВАЖНО: для `баланса`/`позиций`/`сделок` с `--source полимаркет`,
  параметр адреса ДОЛЖЕН быть TEE EOA пользователя (evmAddress из
  `lfi whoami`) — НИКОГДА Безопасный адрес. Сервер предсказаний
  автоматически извлекает Safe через CREATE2 из EOA перед запросом
  Polygon RPC/API данных Polymarket. Передача безопасного адреса здесь приводит к повторному получению
  его в несуществующий «двойной сейф» → баланс/позиции/сделки
  верните EMPTY (это причина №1 «баланс всегда равен 0»). Сейф
  адрес ТОЛЬКО для `polymarket-deposit-addresses --safe-address` (где
  Полимаркет Бриджу нужен настоящий Сейф в качестве ключа от моста).
ВАЖНО: Отдавайте предпочтение автопотоку TEE («полимаркет-плейс» / «калши-плейс» / «отмена»).
  Сервер подписывает через Privy TEE — вызывающая сторона никогда не обрабатывает подписи или POLY_* HMAC.
  См. ссылку/order-flow.md для получения информации о каноническом потоке и дереве решений.
ВАЖНО: Когда сейф Polymarket нуждается в финансировании, адрес депозита
  НИКОГДА Безопасный адрес из `polymarket-setup-status`. ВСЕГДА звоните
  `lfi предсказать полимаркет-депозитные адреса --safe-address <safe> --json`
  и найдите один из адресов моста, который он возвращает: `evm` (по умолчанию —
  принимает USDC/USDT на Ethereum/Polygon/Base/Arbitrum/Optimism/BNB),
  `svm` (Solana USDC), `btc` (биткойн), `tron` (USDT-TRC20). Сейф
  Внутренний депозитарный договор Полимаркета; отправка средств на него напрямую
  НЕ поток, с которым сталкивается пользователь. Адрес моста направляет средства в сейф.
  автоматически через сервис Polymarket Bridge.
ВАЖНО: устаревшие команды («polymarket-order», «kalshi-quote», «kalshi-submit»)
  все еще работают, но УСТАРЕЛИ и требуют внешней подписи — используйте только их
  когда пользователь явно отказывается от потока TEE или уже имеет кредиты POLY_*.
ВАЖНО: НИКОГДА не выполняйте приказы без явного подтверждения пользователя.
НЕ используйте этот навык для: - Поиск токенов, цена, подробная информация, аудит безопасности, K-line → используйте liberfi-токен - Тенденции в рейтинге токенов или обнаружение новых токенов → используйте liberfi-market - Активы криптокошельков / PnL в цепочке (НЕ PnL рынка предсказаний) →
  используйте liberfi-портфолио. Примечание: «我在预测市场赚了多少» / «我的预测仓位»
  принадлежат ЗДЕСЬ, а не в либерфи-портфолио.
- Котировки свопа, исполнение сделок или трансляция транзакций → используйте liberfi-swap - Аутентификация (вход, выход из системы, сеанс) → используйте liberfi-auth
НЕ активируйте только расплывчатые входные данные, такие как «прогнозировать», без контекста, указывающего, что пользователь хочет прогнозировать рыночные операции.
