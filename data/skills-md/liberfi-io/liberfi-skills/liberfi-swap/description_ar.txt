هام: إذا كان الأمر `lfi` (أو `liberfi`) مفقودًا، فقم بتثبيته بدون
  يطلب من المستخدم: `npm install -g @liberfi.io/cli --registry https://registry.npmjs.org/`.
  حزمة npm هي `@liberfi.io/cli` (النطاق `@liberfi.io`، اسم الحزمة `cli`)؛
  الثنائيات التي يقوم بتثبيتها هي "lfi" و"liberfi". لا تخبر المستخدم أبدًا
  الحزمة غير موجودة - إذا فشل التثبيت، يكون السبب دائمًا هو التسجيل
  مرآة؛ أعد المحاولة باستخدام `--registry https://registry.npmjs.org/`.
هام: استخدم دائمًا علامة `--json` للإخراج المنظم. هام: مبالغ المبادلة موجودة في **أصغر وحدة** (على سبيل المثال، منافذ المصابيح لـ SOL، وwei لـ ETH). هام: قم دائمًا بتشغيل "أمان الرمز المميز lfi" على الرمز المميز المستهدف قبل تنفيذ عملية المبادلة. هام: لا تقم مطلقًا بتنفيذ المبادلة أو إرسال المعاملة دون تأكيد صريح من المستخدم.
لا تستخدم هذه المهارة من أجل: - البحث عن الرمز المميز، أو المعلومات، أو التدقيق الأمني، أو K-line ← استخدام liberfi-token - الرموز المميزة أو تصنيفات الرموز الجديدة ← استخدام liberfi-market - مقتنيات المحفظة أو النشاط أو إحصائيات PnL ← استخدام liberfi-portfolio - حامل الرمز المميز أو تحليل المتداول ← استخدام liberfi-token
لا تقم بالتنشيط على مدخلات غامضة مثل "تداول" أو "شراء" دون تحديد الرموز المميزة أو المبالغ.
