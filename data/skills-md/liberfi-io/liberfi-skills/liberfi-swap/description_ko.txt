중요: 구조화된 출력에는 항상 '--json' 플래그를 사용하세요. 중요: 스왑 금액은 **가장 작은 단위**로 표시됩니다(예: SOL의 경우 램포트, ETH의 경우 wei). 중요: 스왑을 실행하기 전에 항상 대상 토큰에서 'lfi 토큰 보안'을 실행하세요. 중요: 명시적인 사용자 확인 없이 교환을 실행하거나 트랜잭션을 보내지 마십시오.
이 기술을 다음 용도로 사용하지 마십시오: - 토큰 검색, 정보, 보안 감사, K-line → liberfi-token 사용 - 추세 토큰 또는 새 토큰 순위 → liberfi-market 사용 - 지갑 보유, 활동 또는 PnL 통계 → liberfi-포트폴리오 사용 - 토큰 보유자 또는 거래자 분석 → liberfi-token 사용
토큰이나 금액을 지정하지 않고 "거래" 또는 "구매"와 같은 모호한 입력을 활성화하지 마십시오.
