Utilice Relay0 como puerta de enlace de IA multiinquilino con alcance y API de operaciones de agente. Prefiera la CLI `relay0` (`relay0 models`, `relay0 set`, `relay0 get`, `relay0 doctor`) en lugar de raspar archivos de configuración o curl hecho a mano. Se activa cuando el usuario menciona Relay0; quiere diferentes modelos en Codex, Claude Code, Cursor, OpenClaw u otras herramientas de codificación; necesita descubrir modelos; configurar la URL base o la clave de puerta de enlace; ejecute el instalador de instalación o la limpieza; comprobar uso/cuotas; gestionar claves o conexiones de proveedores; depurar una ruta modelo o un catálogo vacío; o elija hosts Workspace (api.*) vs Grid (grid.*), sin exponer los secretos del proveedor ascendente.
