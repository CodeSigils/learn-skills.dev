Utilisez Relay0 comme passerelle d'IA multi-locataires et API d'opérations d'agent. Préférez la CLI `relay0` (`relay0 models`, `relay0 set`, `relay0 get`, `relay0 doctor`) au scraping des fichiers de configuration ou au curl roulé à la main. Déclencher lorsque l'utilisateur mentionne Relay0 ; veut différents modèles sur Codex, Claude Code, Cursor, OpenClaw ou d'autres outils de codage ; doit découvrir des modèles; configurer l'URL de base ou la clé de passerelle ; exécutez le programme d'installation ou le nettoyage ; vérifier l'utilisation/les quotas ; gérer les clés ou les connexions des fournisseurs ; déboguer un itinéraire modèle ou un catalogue vide ; ou choisissez les hôtes Workspace (api.*) ou Grid (grid.*), sans exposer les secrets du fournisseur en amont.
