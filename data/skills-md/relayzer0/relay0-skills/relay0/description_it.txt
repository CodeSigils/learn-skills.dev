Utilizza Relay0 come gateway AI multi-tenant con ambito e API per le operazioni degli agenti. Preferisci la CLI "relay0" ("relay0 models", "relay0 set", "relay0 get", "relay0 doctor") rispetto allo scraping dei file di configurazione o all'arricciatura manuale. Si attiva quando l'utente menziona Relay0; vuole modelli diversi su Codex, Claude Code, Cursor, OpenClaw o altri strumenti di codifica; ha bisogno di scoprire modelli; configurare l'URL di base o la chiave del gateway; eseguire il programma di installazione o la pulizia; verificare utilizzo/quote; gestire chiavi o connessioni provider; eseguire il debug di un percorso del modello o di un catalogo vuoto; oppure scegli host Workspace (api.*) o Grid (grid.*), senza esporre i segreti del provider upstream.
