Повторно синхронизируйте файлkills-lock.json с .gitignore, удалив все записи навыков, файлы которых игнорируются git. Исправляет «призрак» файла блокировки — устаревшие записи, оставшиеся после добавления правил игнорирования — путем делегирования разрешения игнорирования команде «git check-ignore», поэтому все globs, такие как «agent-skill-kit-*», файл «.git/info/exclude» и глобальный файл ExcludesFile, учитываются. Также перехватывается случай выброса, когда источник навыка `.agents/skills/<name>` отслеживается, но его зеркальная копия `.claude/skills/<name>` игнорируется (или наоборот). Скрипт Node с нулевой зависимостью и предварительным просмотром --dry-run. Используйте, когда в файлеkills-lock.json перечислены навыки, которые больше не отслеживаются, после добавления правил игнорирования для продаваемых навыков или для проверки отклонения файла блокировки/игнорирования.
