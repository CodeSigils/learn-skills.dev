Risincronizza skills-lock.json con .gitignore rimuovendo qualsiasi voce di competenza i cui file sono ignorati da git. Risolto il problema con il "ghosting" del file di blocco (voci obsolete lasciate dopo l'aggiunta delle regole di ignoranza) delegando la risoluzione dell'ignoramento a `git check-ignore`, in modo che i glob come `agent-skill-kit-*`, il file `.git/info/exclude` e il file escluso globale vengano tutti rispettati. Rileva anche il caso anomalo in cui l'origine `.agents/skills/<name>` di una competenza viene tracciata ma la sua copia mirrorata `.claude/skills/<name>` viene ignorata (o viceversa). Script del nodo a dipendenza zero con un'anteprima --dry-run. Da utilizzare quando skills-lock.json elenca le competenze che non vengono più monitorate, dopo aver aggiunto regole di ignoranza per le competenze fornite o per controllare la deriva del file di blocco/ignora.
