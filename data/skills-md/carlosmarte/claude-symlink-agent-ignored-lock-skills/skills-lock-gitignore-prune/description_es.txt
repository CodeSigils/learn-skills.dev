Resincronice skills-lock.json con .gitignore eliminando cualquier entrada de habilidad cuyos archivos sean ignorados por git. Corrige el "efecto fantasma" del archivo de bloqueo (entradas obsoletas que quedan después de agregar reglas de ignorar) al delegar la resolución de ignorar a `git check-ignore`, por lo que se respetan elementos como `agent-skill-kit-*`, el archivo `.git/info/exclude` y el archivo de exclusión global. También detecta el caso atípico en el que se rastrea el origen `.agents/skills/<nombre>` de una habilidad pero se ignora su copia reflejada `.claude/skills/<nombre>` (o viceversa). Script de Nodo de dependencia cero con vista previa de ejecución en seco. Úselo cuando skills-lock.json enumera habilidades que ya no se rastrean, después de agregar reglas de ignorar para habilidades proporcionadas o para auditar el archivo de bloqueo/ignorar la deriva.
