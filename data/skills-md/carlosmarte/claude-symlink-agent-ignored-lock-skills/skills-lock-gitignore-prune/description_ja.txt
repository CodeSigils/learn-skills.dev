ファイルが git 無視されているスキル エントリを削除して、skills-lock.json を .gitignore と再同期します。無視の解決を `git check-ignore` に委任することで、ロックファイルの「ゴースト」 (無視ルールが追加された後に残る古いエントリ) を修正しました。これにより、`agent-skill-kit-*`、`.git/info/exclude` ファイル、およびグローバル excludesFile などのグロブがすべて受け入れられるようになります。また、スキルの `.agents/skills/<name>` ソースは追跡されるが、そのミラーリングされた `.claude/skills/<name>` コピーが無視される (またはその逆) という外れ値のケースも捕捉します。 --dry-run プレビューを使用した依存関係のないノード スクリプト。ベンダー提供のスキルの無視ルールを追加した後、またはロックファイル/無視ドリフトを監査するために、skills-lock.json が追跡されなくなったスキルをリストする場合に使用します。
