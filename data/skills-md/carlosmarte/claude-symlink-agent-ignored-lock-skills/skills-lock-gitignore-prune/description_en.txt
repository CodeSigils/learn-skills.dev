Resync skills-lock.json with .gitignore by removing any skill entry whose files are git-ignored. Fixes lockfile "ghosting" — stale entries left behind after ignore rules are added — by delegating ignore resolution to `git check-ignore`, so globs like `agent-skill-kit-*`, the `.git/info/exclude` file, and the global excludesFile are all honored. Also catches the outlier case where a skill's `.agents/skills/<name>` source is tracked but its mirrored `.claude/skills/<name>` copy is ignored (or vice-versa). Zero-dependency Node script with a --dry-run preview. Use when skills-lock.json lists skills that are no longer tracked, after adding ignore rules for vendored skills, or to audit lockfile/ignore drift.
