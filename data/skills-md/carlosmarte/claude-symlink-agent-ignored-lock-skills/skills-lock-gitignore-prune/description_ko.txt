파일이 git 무시되는 기술 항목을 제거하여 Skill-lock.json을 .gitignore와 다시 동기화합니다. 무시 규칙을 추가한 후 남겨진 오래된 항목인 잠금 파일 "고스팅"을 수정합니다. 무시 확인을 `git check-ignore`에 위임하여 `agent-skill-kit-*`, `.git/info/exclude` 파일 및 전역 제외 파일과 같은 glob이 모두 적용되도록 합니다. 또한 스킬의 `.agents/skills/<name>` 소스가 추적되지만 미러링된 `.claude/skills/<name>` 복사본이 무시되는(또는 그 반대의 경우) 이상치 사례를 포착합니다. --dry-run 미리보기가 포함된 종속성 없는 노드 스크립트입니다. 기술 잠금.json이 공급업체 기술에 대한 무시 규칙을 추가한 후 더 이상 추적되지 않는 기술을 나열하거나 잠금 파일/드리프트 무시를 감사할 때 사용합니다.
