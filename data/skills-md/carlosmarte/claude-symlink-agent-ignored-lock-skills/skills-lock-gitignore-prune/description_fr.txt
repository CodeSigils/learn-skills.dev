Resynchronisez skills-lock.json avec .gitignore en supprimant toute entrée de compétence dont les fichiers sont ignorés par git. Corrige le "ghosting" du fichier de verrouillage - les entrées obsolètes laissées après l'ajout de règles d'ignorance - en déléguant la résolution d'ignorer à `git check-ignore`, de sorte que les globs comme `agent-skill-kit-*`, le fichier `.git/info/exclude` et le fichier d'exclusion global soient tous honorés. Détecte également le cas aberrant où la source `.agents/skills/<name>` d'une compétence est suivie mais sa copie en miroir `.claude/skills/<name>` est ignorée (ou vice-versa). Script Node sans dépendance avec un aperçu --dry-run. À utiliser lorsque skills-lock.json répertorie les compétences qui ne sont plus suivies, après avoir ajouté des règles d'ignorance pour les compétences vendues, ou pour auditer la dérive du fichier de verrouillage/ignorer.
