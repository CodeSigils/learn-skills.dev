Résolvez et triez topologiquement les dépendances de compétences, appliquez la règle d'inversion de la spécification §3.3 (projet → application → équipe → org), avertissez sur les versions non épinglées et fermez en cas d'échec en cas de conflits de plages incompatibles. À utiliser lorsque l'utilisateur demande de vérifier les dépendances des compétences, de trier les compétences par ordre de construction, de détecter les cycles ou d'auditer l'épinglage des versions des compétences.
