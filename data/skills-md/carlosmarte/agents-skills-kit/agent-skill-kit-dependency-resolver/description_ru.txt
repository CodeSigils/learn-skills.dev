Разрешение и топологическая сортировка зависимостей навыков, соблюдение правила инверсии §3.3 спецификации (проект→приложение→команда→организация), предупреждение о незакрепленных версиях и аварийное закрытие в случае конфликтов несовместимых диапазонов. Используйте, когда пользователь просит проверить зависимости навыков, отсортировать навыки по порядку сборки, обнаружить циклы или проверить закрепление версии навыка.
