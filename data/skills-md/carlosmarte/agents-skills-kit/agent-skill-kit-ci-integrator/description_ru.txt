Подключите набор инструментов для навыков агентов к CI — установите рабочий процесс GitHub Actions, который запускает validate/lint/audit/deps при каждом запросе запроса, и установите перехватчики предварительной фиксации для проверки четности в локальном цикле. Используйте, когда пользователь просит настроить CI для навыков, установить перехватчики предварительной фиксации, настроить действия GitHub для проверки SKILL.md или подключить набор инструментов к новому репозиторию.
