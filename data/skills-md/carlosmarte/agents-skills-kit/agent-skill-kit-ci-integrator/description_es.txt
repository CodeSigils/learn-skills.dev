Conecte el kit de herramientas de habilidades del agente a CI: instale el flujo de trabajo de GitHub Actions que ejecuta validar/lint/audit/deps en cada PR e instale los enlaces de confirmación previa para la paridad del bucle local. Úselo cuando el usuario solicite configurar CI para habilidades, instalar enlaces de confirmación previa, configurar GitHub Actions para la validación de SKILL.md o conectar el kit de herramientas a un nuevo repositorio.
