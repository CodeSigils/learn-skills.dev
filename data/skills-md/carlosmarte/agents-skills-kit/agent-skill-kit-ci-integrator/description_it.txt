Collega il toolkit delle competenze dell'agente in CI: installa il flusso di lavoro GitHub Actions che esegue validate/lint/audit/deps su ogni PR e installa gli hook di pre-commit per la parità del loop locale. Da utilizzare quando l'utente richiede di impostare CI per competenze, installare hook di pre-commit, configurare GitHub Actions per la convalida SKILL.md o collegare il toolkit in un nuovo repository.
