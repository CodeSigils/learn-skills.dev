Connectez la boîte à outils de compétences d'agent à CI : installez le workflow GitHub Actions qui exécute validate/lint/audit/deps sur chaque PR et installez les hooks de pré-validation pour la parité de la boucle locale. À utiliser lorsque l'utilisateur demande à configurer CI pour les compétences, à installer des hooks de pré-validation, à configurer les actions GitHub pour la validation SKILL.md ou à connecter la boîte à outils à un nouveau dépôt.
