Audite un árbol de habilidades para detectar los cuatro hallazgos de seguridad canónicos: campos de front-matter no autorizados, patrones de inyección de comandos en scripts, orígenes de dependencia entre repositorios no examinados y fugas de rutas de host en el cuerpo o scripts. Úselo cuando el usuario solicite auditar, escanear, verificar la seguridad o reforzar una habilidad o un directorio de habilidades.
