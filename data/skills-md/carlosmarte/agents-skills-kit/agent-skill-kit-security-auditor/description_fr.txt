Auditez un arbre de compétences pour les quatre résultats canoniques de sécurité : champs de premier plan non autorisés, modèles d'injection de commandes dans les scripts, origines de dépendances croisées non vérifiées et fuites de chemin d'hôte dans le corps ou les scripts. À utiliser lorsque l'utilisateur demande à auditer, analyser, vérifier la sécurité ou renforcer une ou plusieurs compétences.
