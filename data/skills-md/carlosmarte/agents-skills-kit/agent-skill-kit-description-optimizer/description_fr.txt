Optimisez une description SKILL.md pour la qualité du déclenchement : générez des requêtes synthétiques positives et négatives, notez la description actuelle en fonction du taux de réussite par rapport aux faux positifs et proposez trois réécritures classées. À utiliser lorsque l'utilisateur demande d'ajuster automatiquement, d'améliorer ou de réécrire une description de compétence, de réparer une compétence qui ne se déclenche jamais ou de mesurer la qualité de la description.
