Gemeinsam genutzte Assets und Referenzimplementierungen, die von allen anderen Fähigkeiten im Agent-Skills-Kit genutzt werden. Enthält die Laufzeitpakete (mjs + py-Implementierungen von „skills-ref“), die kanonischen Test-/Audit-/Lint-/Parser-Fixtures, die von beiden Laufzeiten genutzt werden, die Paritätstestskripte, die das mjs ↔ py-Zwillingsverhalten fixieren, und die Closing-Walks-Beispiele, die die SDK-Dokumentation mit dem echten CLI-Verhalten verknüpfen. Wird verwendet, wenn ein Agent „skills-ref“ aufrufen, eine Paritätsprüfung durchführen, eine Vorrichtung neu generieren oder den kanonischen Testkorpus lernen muss. Andere Fähigkeiten laden diese als Abhängigkeit, sodass sie sich auf einen einzigen kanonischen Asset-Baum verlassen können, anstatt Geräte zu duplizieren.
