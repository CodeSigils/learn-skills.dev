エージェント スキル キット内の他のすべてのスキルによって消費される共有アセットと参照実装。ランタイム パッケージ (`skills-ref` の mjs + py 実装)、両方のランタイムによって使用される正規のテスト/監査/lint/パーサー フィクスチャ、mjs ↔ py ツイン動作を固定するパリティ テスト スクリプト、および実際の CLI 動作に対して SDK ドキュメントを固定するクロージャ ウォーク サンプルを保持します。エージェントが「skills-ref」を呼び出したり、パリティ チェックを実行したり、フィクスチャを再生成したり、正規のテスト コーパスを学習したりする必要がある場合に使用します。他のスキルはこれを依存関係としてロードするため、フィクスチャを複製する代わりに単一の正規のアセット ツリーに依存できます。
