Actifs partagés et implémentations de référence consommés par toutes les autres compétences du kit de compétences d'agent. Contient les packages d'exécution (implémentations mjs + py de `skills-ref`), les appareils de test/audit/lint/analyseur canonique consommés par les deux environnements d'exécution, les scripts de test de parité qui épinglent le comportement du jumeau mjs ↔ py et les exemples de marches de fermeture qui ancrent la documentation du SDK par rapport au comportement réel de la CLI. À utiliser lorsqu'un agent doit invoquer « skills-ref », exécuter un contrôle de parité, régénérer un appareil ou apprendre le corpus de test canonique. D'autres compétences chargent celle-ci en tant que dépendance afin de pouvoir s'appuyer sur une seule arborescence d'actifs canoniques au lieu de dupliquer les appareils.
