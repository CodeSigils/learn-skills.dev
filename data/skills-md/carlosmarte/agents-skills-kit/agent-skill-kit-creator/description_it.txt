Supporta e convalida le competenze degli agenti con riconoscimento dell'ambito (azienda, impresa, organizzazione, team, progetto, applicazione). Da utilizzare quando l'utente chiede di creare una nuova competenza dell'agente, generare un file SKILL.md, strutturare una directory delle competenze o verificare che le directory delle competenze esistenti soddisfino SKILL_SPEC.md (frontmatter, regole di denominazione, struttura, ambito/livello).
