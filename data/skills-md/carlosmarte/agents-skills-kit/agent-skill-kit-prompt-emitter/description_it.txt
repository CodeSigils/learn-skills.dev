Genera artefatti di divulgazione progressiva da un albero delle competenze: un blocco XML "<available_skills>" per l'avvio dell'agente di fase 1 o un JSON canonico di proprietà frontmatter per il consumo di CI. Da utilizzare quando l'utente richiede di esportare i metadati delle competenze, creare un blocco di prompt, generare JSON per CI o collegare competenze a un host dell'agente.
