Emita artefactos de divulgación progresiva desde un árbol de habilidades: un bloque XML `<available_skills>` para el inicio del agente de etapa 1, o JSON canónico de propiedades frontales para el consumo de CI. Úselo cuando el usuario solicite exportar metadatos de habilidades, crear un bloque de mensajes, generar JSON para CI o conectar habilidades a un host de agente.
