`.agents/skills/<name>/` の下にある個々のスキルを `.claude/skills/<name>` の相対シンボリック リンクにミラーリングして、Claude Code のハーネスが自動検出できるようにします。ただし、正しいリンクがまだ存在しないスキルに対してのみです。べき等かつ非破壊 — 既存の正しいシンボリックリンクは通過し、間違ったシンボリックリンクは競合としてフラグが立てられ (または --force で置き換えられ)、実際のファイル/ディレクトリが破壊されることはありません。依存関係のないネイティブ スクリプト (Node .mjs または Python 3) を使用します。 .agents/skills/ にある SKILL.md がハーネスから見えない場合、`.agents/` 規約を採用するリポジトリを一括オンボードするとき、または新しいスキルを `.agents/skills/` にプルした後に使用します。
