اعكس كل مهارة فردية ضمن `.agents/skills/<name>/` في رابط رمزي نسبي `.claude/skills/<name>` بحيث يكتشفها جهاز Claude Code تلقائيًا - ولكن فقط للمهارات التي ليس لها رابط صحيح بالفعل. غير فعالة وغير مدمرة - تمرر الارتباطات الرمزية الصحيحة الموجودة، ويتم وضع علامة على الارتباطات الرمزية الخاطئة على أنها تعارضات (أو يتم استبدالها بـ --force)، ولا يتم اختراق الملفات/الأدلة الحقيقية أبدًا. يستخدم نصًا أصليًا خاليًا من التبعية (Node .mjs أو Python 3). يُستخدم عندما يكون SKILL.md ضمن .agents/skills/ غير مرئي للأداة، أو عند الدمج المجمع لمستودع الريبو الذي يعتمد اتفاقية `.agents/`، أو بعد سحب مهارات جديدة إلى `.agents/skills/`.
