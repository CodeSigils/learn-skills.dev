Отразите каждый отдельный навык в `.agents/skills/<name>/` в относительную символическую ссылку `.claude/skills/<name>`, чтобы система Claude Code автоматически обнаружила его — но только для навыков, у которых еще нет правильной ссылки. Идемпотентный и неразрушающий — существующие правильные символические ссылки проходят, неправильные символические ссылки помечаются как конфликтующие (или заменяются на --force), а реальные файлы/каталоги никогда не затираются. Использует собственный скрипт с нулевой зависимостью (Node.mjs или Python 3). Используйте, когда SKILL.md в .agents/skills/ невидим для системы, при массовой загрузке репозитория, который принимает соглашение .agents/`, или после добавления новых навыков в .agents/skills/`.
