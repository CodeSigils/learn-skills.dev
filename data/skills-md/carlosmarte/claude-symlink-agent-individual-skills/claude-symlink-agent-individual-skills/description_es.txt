Refleje cada habilidad individual en `.agents/skills/<name>/` en un enlace simbólico relativo `.claude/skills/<name>` para que el arnés de Claude Code lo descubra automáticamente, pero solo para las habilidades que aún no tienen un enlace correcto. Idempotente y no destructivo: los enlaces simbólicos correctos existentes pasan, los enlaces simbólicos incorrectos se marcan como conflictos (o se reemplazan con --force) y los archivos/directorios reales nunca son bloqueados. Utiliza un script nativo sin dependencia (Node .mjs o Python 3). Úselo cuando un SKILL.md en .agents/skills/ es invisible para el arnés, al incorporar de forma masiva un repositorio que adopta la convención `.agents/` o después de incorporar nuevas habilidades a `.agents/skills/`.
