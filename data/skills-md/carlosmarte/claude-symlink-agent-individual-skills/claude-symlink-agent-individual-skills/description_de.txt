Spiegeln Sie jeden einzelnen Skill unter „.agents/skills/<name>/“ in einen relativen Symlink „.claude/skills/<name>“, damit der Harness von Claude Code ihn automatisch erkennt – aber nur für Skills, die noch keinen korrekten Link haben. Idempotent und nicht destruktiv – vorhandene korrekte Symlinks werden durchgelassen, falsche Symlinks werden als Konflikte gekennzeichnet (oder durch --force ersetzt) ​​und echte Dateien/Verzeichnisse werden niemals überlastet. Verwendet ein natives Skript ohne Abhängigkeiten (Node .mjs oder Python 3). Verwenden Sie dies, wenn eine SKILL.md unter .agents/skills/ für den Harness unsichtbar ist, beim Massen-Onboarding eines Repos, das die „.agents/“-Konvention übernimmt, oder nach dem Ziehen neuer Fähigkeiten in „.agents/skills/“.
