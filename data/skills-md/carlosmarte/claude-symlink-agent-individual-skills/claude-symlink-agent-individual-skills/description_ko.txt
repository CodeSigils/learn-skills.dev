`.agents/skills/<name>/` 아래의 각 개별 스킬을 `.claude/skills/<name>` 상대 심볼릭 링크로 미러링하여 Claude Code의 하네스가 자동으로 검색하도록 합니다. 하지만 아직 올바른 링크가 없는 스킬에 대해서만 해당됩니다. 멱등성 및 비파괴적 — 기존의 올바른 심볼릭 링크는 통과하고, 잘못된 심볼릭 링크는 충돌로 플래그가 지정되며(또는 --force로 대체), 실제 파일/디렉터리는 절대로 방해받지 않습니다. 종속성이 없는 기본 스크립트(Node .mjs 또는 Python 3)를 사용합니다. .agents/skills/ 아래의 SKILL.md가 하네스에 표시되지 않는 경우, `.agents/` 규칙을 채택하는 저장소를 대량 온보딩할 때 또는 `.agents/skills/`에 새 기술을 가져온 후 사용합니다.
