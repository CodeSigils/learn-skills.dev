Mettez en miroir chaque compétence individuelle sous `.agents/skills/<name>/` dans un lien symbolique relatif `.claude/skills/<name>` afin que le harnais de Claude Code la découvre automatiquement — mais uniquement pour les compétences qui n'ont pas déjà de lien correct. Idempotent et non destructif : les liens symboliques corrects existants sont transmis, les liens symboliques incorrects sont signalés comme conflits (ou remplacés par --force) et les vrais fichiers/répertoires ne sont jamais détruits. Utilise un script natif sans dépendance (Node .mjs ou Python 3). À utiliser lorsqu'un SKILL.md sous .agents/skills/ est invisible pour le harnais, lors de l'intégration groupée d'un dépôt qui adopte la convention `.agents/`, ou après avoir intégré de nouvelles compétences dans `.agents/skills/`.
