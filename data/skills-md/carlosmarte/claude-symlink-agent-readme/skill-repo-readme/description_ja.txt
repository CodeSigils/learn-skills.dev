スキル リポジトリの README.md を生成または更新します。スキル リポジトリは、`.agents/skills/<name>/SKILL.md` の下にある Agentkills.io スキルをベンダーに提供します。すべてのスキルのフロントマターをスキャンし、スキル テーブルを構築し、インストール手順 (スキルごとの「npx skill add」とワンショットの「curl | bash」) およびレイアウト セクションを書き込みます。ユーザーがスキル リポジトリの README の作成、更新、生成、またはリフレッシュを要求する場合、リポジトリの README がベア スタブである場合、または `.agents/skills/` でスキルを追加または削除した後に使用します。
