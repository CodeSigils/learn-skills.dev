Genere o actualice el archivo README.md para un repositorio de habilidades, uno que proporcione habilidades de agenteskills.io en `.agents/skills/<nombre>/SKILL.md`. Escanea el contenido de cada habilidad, crea una tabla de habilidades y escribe instrucciones de instalación (`npx skills add` por habilidad más un one-shot `curl | bash`) y una sección de diseño. Úselo cuando el usuario solicita crear, actualizar, generar o actualizar el archivo README para un repositorio de habilidades, cuando el archivo README de un repositorio es un código auxiliar simple o después de agregar/eliminar habilidades en `.agents/skills/`.
