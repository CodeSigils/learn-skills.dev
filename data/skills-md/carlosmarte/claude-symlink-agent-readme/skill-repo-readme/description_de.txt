Generieren oder aktualisieren Sie die README.md für ein Skill-Repository – eines, das Agentskills.io-Skills unter „.agents/skills/<name>/SKILL.md“ bereitstellt. Scannt die Frontmatter jedes Skills, erstellt eine Skills-Tabelle und schreibt Installationsanweisungen („npx skills add“ pro Skill plus einen „Curl | Bash“-One-Shot) und einen Layoutabschnitt. Verwenden Sie diese Option, wenn der Benutzer die README-Datei für ein Skill-Repo erstellen, aktualisieren, generieren oder aktualisieren möchte, wenn die README-Datei eines Repos ein bloßer Stub ist oder nach dem Hinzufügen/Entfernen von Skills unter „.agents/skills/“.
