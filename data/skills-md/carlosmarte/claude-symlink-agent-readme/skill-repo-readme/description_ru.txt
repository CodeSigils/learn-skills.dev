Создайте или обновите файл README.md для репозитория навыков — того, который продает навыки Agentskills.io в `.agents/skills/<name>/SKILL.md`. Сканирует заголовок каждого навыка, строит таблицу навыков и записывает инструкции по установке (npx скилы добавляются для каждого навыка плюс одноразовый `curl | bash`) и раздел макета. Используйте, когда пользователь запрашивает создание, обновление, создание или обновление README для репозитория навыков, когда README репозитория представляет собой пустую заглушку или после добавления/удаления навыков в `.agents/skills/`.
