Générez ou actualisez le README.md pour un référentiel de compétences — un référentiel qui vend les compétences agentskills.io sous `.agents/skills/<name>/SKILL.md`. Analyse le contenu de chaque compétence, crée un tableau des compétences et rédige les instructions d'installation (`npx skills add` par compétence plus un one-shot `curl | bash`) et une section de mise en page. À utiliser lorsque l'utilisateur demande de créer, mettre à jour, générer ou actualiser le README pour un dépôt de compétences, lorsque le README d'un dépôt est un simple stub, ou après avoir ajouté/supprimé des compétences sous `.agents/skills/`.
