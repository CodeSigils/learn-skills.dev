قم بإنشاء أو تحديث README.md لمستودع المهارات - وهو مستودع يبيع مهارات agentskills.io ضمن `.agents/skills/<name>/SKILL.md`. يقوم بمسح المادة الأمامية لكل مهارة، ويبني جدول مهارات، ويكتب تعليمات التثبيت (إضافة مهارات npx لكل مهارة بالإضافة إلى لقطة واحدة `curl | bash`) وقسم تخطيط. يُستخدم عندما يطلب المستخدم إنشاء الملف التمهيدي أو تحديثه أو إنشائه أو تحديثه لمستودع المهارات، أو عندما يكون الملف التمهيدي الخاص بمستودع الريبو مجرد كعب روتين، أو بعد إضافة/إزالة المهارات ضمن `.agents/skills/`.
