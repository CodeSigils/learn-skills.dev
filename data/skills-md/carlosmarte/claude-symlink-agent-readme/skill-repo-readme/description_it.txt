Genera o aggiorna README.md per un repository di competenze, uno che vende le competenze di agentkills.io in `.agents/skills/<nome>/SKILL.md`. Esamina il frontmatter di ogni abilità, crea una tabella delle abilità e scrive le istruzioni di installazione ("npx skills add" per abilità più un one-shot "curl | bash") e una sezione di layout. Da utilizzare quando l'utente chiede di creare, aggiornare, generare o rinfrescare il README per un repository di competenze, quando il README di un repository è uno stub nudo o dopo aver aggiunto/rimosso competenze in `.agents/skills/`.
