Gérez les utilisateurs Harness, les groupes d'utilisateurs et les comptes de service via MCP. Répertoriez et recherchez des utilisateurs, créez et gérez des groupes d'utilisateurs pour un accès en équipe, créez des comptes de service pour l'automatisation des API et affichez les autorisations disponibles. À utiliser lorsqu'on vous demande de répertorier les utilisateurs, de créer un groupe d'utilisateurs, de gérer les comptes de service, de vérifier qui a accès ou de configurer les autorisations d'équipe. Ne PAS utiliser pour les attributions de rôles ou les groupes de ressources (utilisez plutôt les rôles de gestion). Phrases déclencheurs : répertorier les utilisateurs, le groupe d'utilisateurs, le compte de service, qui a accès, les autorisations d'équipe, ajouter un utilisateur au groupe, créer un compte de service.
