Управляйте пользователями Harness, группами пользователей и учетными записями служб через MCP. Составляйте список пользователей и осуществляйте поиск, создавайте группы пользователей и управляйте ими для группового доступа, создавайте учетные записи служб для автоматизации API и просматривайте доступные разрешения. Используйте, когда вас попросят составить список пользователей, создать группу пользователей, управлять учетными записями служб, проверить, у кого есть доступ, или настроить разрешения для группы. НЕ используйте для назначения ролей или групп ресурсов (вместо этого используйте роли управления). Триггерные фразы: список пользователей, группа пользователей, учетная запись службы, у кого есть доступ, разрешения группы, добавление пользователя в группу, создание учетной записи службы.
