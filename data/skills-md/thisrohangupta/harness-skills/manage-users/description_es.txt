Administre usuarios, grupos de usuarios y cuentas de servicio de Harness a través de MCP. Enumere y busque usuarios, cree y administre grupos de usuarios para acceso basado en equipos, cree cuentas de servicio para la automatización de API y vea los permisos disponibles. Úselo cuando se le solicite enumerar usuarios, crear un grupo de usuarios, administrar cuentas de servicio, verificar quién tiene acceso o configurar permisos de equipo. NO lo use para asignaciones de roles o grupos de recursos (use en su lugar administrar roles). Frases desencadenantes: enumerar usuarios, grupo de usuarios, cuenta de servicio, quién tiene acceso, permisos de equipo, agregar usuario a grupo, crear cuenta de servicio.
