Genera file modello di Harness Agent per agenti di automazione basati sull'intelligenza artificiale. Produce file metadata.json, pipeline.yaml (sintassi v1) e wiki.MD. Gli agenti automatizzano attività come la revisione del codice, la scansione di sicurezza, la generazione di test e la documentazione. Questa è un'abilità di generazione YAML. Da utilizzare quando viene richiesto di creare un modello di agente, creare un agente AI, creare un agente di automazione, generare file di pipeline dell'agente o configurare un agente Harness. Frasi di attivazione: crea modello di agente, modello di agente, agente AI, agente di automazione, agente di creazione, agente di revisione del codice, agente dello scanner di sicurezza, agente di cablaggio.
