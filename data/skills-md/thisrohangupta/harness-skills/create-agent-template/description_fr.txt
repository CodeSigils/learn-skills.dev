Générez des fichiers de modèles d'agent de harnais pour les agents d'automatisation basés sur l'IA. Produit des fichiers metadata.json, pipeline.yaml (syntaxe v1) et wiki.MD. Les agents automatisent des tâches telles que la révision du code, l'analyse de sécurité, la génération de tests et la documentation. Il s'agit d'une compétence de génération YAML. À utiliser lorsqu'on vous demande de créer un modèle d'agent, de créer un agent IA, de créer un agent d'automatisation, de générer des fichiers de pipeline d'agent ou de configurer un agent Harness. Phrases de déclenchement : créer un modèle d'agent, un modèle d'agent, un agent IA, un agent d'automatisation, un agent de build, un agent de révision de code, un agent d'analyse de sécurité, un agent Harness.
