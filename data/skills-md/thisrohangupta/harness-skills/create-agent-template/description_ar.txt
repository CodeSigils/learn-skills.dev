قم بإنشاء ملفات قالب Harness Agent لوكلاء التشغيل الآلي الذين يعملون بالذكاء الاصطناعي. يُنتج ملفات metadata.json وpipepe.yaml (بناء الجملة v1) وملفات wiki.MD. يقوم الوكلاء بأتمتة المهام مثل مراجعة التعليمات البرمجية، والفحص الأمني، وإنشاء الاختبار، والتوثيق. هذه هي مهارة جيل YAML. استخدمه عندما يُطلب منك إنشاء قالب وكيل، أو إنشاء وكيل AI، أو إنشاء وكيل أتمتة، أو إنشاء ملفات مسارات الوكيل، أو إعداد وكيل Harness. عبارات التشغيل: إنشاء قالب وكيل، قالب وكيل، وكيل AI، وكيل التشغيل الآلي، وكيل البناء، وكيل مراجعة التعليمات البرمجية، وكيل الماسح الضوئي الأمني، وكيل Harness.
