AI を活用した自動化エージェント用のハーネス エージェント テンプレート ファイルを生成します。 metadata.json、pipeline.yaml (v1 構文)、および wiki.MD ファイルを生成します。エージェントは、コード レビュー、セキュリティ スキャン、テスト生成、ドキュメント化などのタスクを自動化します。これは YAML 生成スキルです。エージェント テンプレートの作成、AI エージェントの構築、自動化エージェントの作成、エージェント パイプライン ファイルの生成、または Harness エージェントのセットアップを求められた場合に使用します。トリガー フレーズ: エージェント テンプレート、エージェント テンプレート、AI エージェント、自動化エージェント、ビルド エージェント、コード レビュー エージェント、セキュリティ スキャナー エージェント、ハーネス エージェントを作成します。
