Entfernen Sie KI-Fehler aus Code und Pull-Requests. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer KI-generierten Code bereinigen, ein Diff auf unnötiges Rauschen überprüfen, eine Datei oder PR auf Stilinkonsistenzen, Überabstraktion, nicht hierhin gehörende Abwehrprüfungen, überflüssige Kommentare oder alles, was „nicht das Gefühl hat, hierher zu gehören“ prüfen möchte. Verwenden Sie es auch proaktiv nach jeder KI-gestützten Codierungssitzung, um die Schleife „Recherche → Plan → Ausführen → Überprüfen → Überarbeiten“ anzuwenden und sicherzustellen, dass die Ausgabe sauber, überprüfbar und mit der vorhandenen Codebasis konsistent ist. Auslösen bei: „Slop entfernen“, „KI-Code bereinigen“, „Deslop“, „Diff überprüfen“, „Sieht das KI-geschrieben aus“, „diese PR aufpolieren“, „dieses menschlicher wirken lassen“, „vor dem Commit aufräumen“.
