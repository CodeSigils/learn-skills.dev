Supprimez le slop AI du code et des requêtes d'extraction. Utilisez cette compétence chaque fois que l'utilisateur souhaite nettoyer le code généré par l'IA, examiner une différence pour détecter tout bruit inutile, auditer un fichier ou un PR pour détecter des incohérences de style, une abstraction excessive, des contrôles défensifs qui n'appartiennent pas, des commentaires redondants ou tout ce qui "ne semble pas appartenir ici". Utilisez-le également de manière proactive après toute session de codage assistée par l'IA pour appliquer la boucle Recherche → Planifier → Exécuter → Révision → Réviser et garantir que la sortie est propre, révisable et cohérente avec la base de code existante. Déclenchez : "supprimer le slop", "nettoyer le code de l'IA", "deslop", "réviser les différences", "cela semble-t-il écrit par l'IA", "polisser ce PR", "rendre cela plus humain", "nettoyer avant de valider".
