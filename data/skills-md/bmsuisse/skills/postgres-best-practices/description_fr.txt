Normes de codage PostgreSQL pour les projets Python utilisant psycopg (pas d'ORM). Utilisez cette compétence chaque fois que l'utilisateur écrit ou révise du code qui interroge PostgreSQL avec psycopg, crée des fichiers SQL, mappe les résultats de la requête aux objets Python ou demande comment structurer le code d'accès à la base de données. Déclenche des éléments tels que "ajouter une requête de base de données", "écrire une requête SQL", "créer un référentiel", "extraire de postgres", "insérer dans la base de données", "mettre à jour la base de données", "requête paramétrée", "modèle pydantic à partir de la ligne de la base de données", "fichier SQL", "SQL dynamique" ou toute mention de psycopg, psycopg2, asyncpg ou SQLAlchemy où l'utilisateur semble ouvert à une approche différente. À utiliser également lorsque l'utilisateur pose des questions sur le regroupement de connexions, les transactions, les usines de curseurs ou comment organiser le code de la base de données.
