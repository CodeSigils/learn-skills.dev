Стандарты кодирования PostgreSQL для проектов Python с использованием psycopg (без ORM). Используйте этот навык всякий раз, когда пользователь пишет или просматривает код, который запрашивает PostgreSQL с помощью psycopg, создает файлы SQL, сопоставляет результаты запроса с объектами Python или спрашивает, как структурировать код доступа к базе данных. Запускается при таких вещах, как «добавление запроса к базе данных», «написание SQL-запроса», «создание репозитория», «извлечение из postgres», «вставка в базу данных», «обновление БД», «параметризованный запрос», «пидантическая модель из строки БД», «файл sql», «динамический SQL» или любое упоминание о psycopg, psycopg2, asyncpg или SQLAlchemy, когда пользователь кажется открытым для другого подхода. Также используйте, когда пользователь спрашивает о пуле соединений, транзакциях, фабриках курсоров или о том, как организовать код базы данных.
