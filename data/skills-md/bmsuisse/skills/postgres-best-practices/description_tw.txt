使用 psycopg（無 ORM）的 Python 專案的 PostgreSQL 編碼標準。每當使用者編寫或檢查使用 psycopg 查詢 PostgreSQL、建立 SQL 檔案、將查詢結果對應到 Python 物件或詢問如何建立資料庫存取程式碼的程式碼時，請使用此技能。諸如「新增資料庫查詢」、「編寫 SQL 查詢」、「建立儲存庫」、「從 postgres 獲取」、「插入資料庫」、「更新資料庫」、「參數化查詢」、「來自資料庫行的 pydantic 模型」、「sql 檔」、「動態 SQL」或任何提及 psycopg、psycopg2、其中一個開放方法的內容，用戶似乎持不同當使用者詢問連接池、事務、遊標工廠或如何組織資料庫程式碼時也可以使用。
