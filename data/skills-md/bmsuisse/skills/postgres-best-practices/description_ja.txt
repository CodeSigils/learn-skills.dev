psycopg (ORM なし) を使用した Python プロジェクトの PostgreSQL コーディング標準。 psycopg を使用して PostgreSQL にクエリを実行するコード、SQL ファイルを作成するコード、クエリ結果を Python オブジェクトにマップするコード、またはデータベース アクセス コードの構造を尋ねるコードをユーザーが作成またはレビューする場合には、このスキルを常に使用してください。 「データベース クエリの追加」、「SQL クエリの作成」、「リポジトリの作成」、「postgres からのフェッチ」、「データベースへの挿入」、「DB の更新」、「パラメータ化されたクエリ」、「DB 行からの pydantic モデル」、「SQL ファイル」、「動的 SQL」、またはユーザーがオープンであると思われる psycopg、psycopg2、asyncpg、または SQLAlchemy に関する言及などをトリガーします。異なるアプローチ。ユーザーが接続プーリング、トランザクション、カーソル ファクトリ、またはデータベース コードの編成方法について質問する場合にも使用します。
