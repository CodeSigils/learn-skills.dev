معايير ترميز PostgreSQL لمشاريع Python باستخدام psycopg (بدون ORM). استخدم هذه المهارة عندما يكتب المستخدم أو يراجع تعليمات برمجية تستعلم عن PostgreSQL باستخدام psycopg، أو ينشئ ملفات SQL، أو يعين نتائج الاستعلام إلى كائنات Python، أو يسأل عن كيفية تنظيم كود الوصول إلى قاعدة البيانات. يتم تشغيل أشياء مثل "إضافة استعلام قاعدة بيانات"، أو "كتابة استعلام SQL"، أو "إنشاء مستودع"، أو "جلب من postgres"، أو "إدراج في قاعدة البيانات"، أو "تحديث قاعدة البيانات"، أو "استعلام ذو معلمات"، أو "نموذج pydantic من صف قاعدة بيانات"، أو "ملف sql"، أو "SQL ديناميكي"، أو أي ذكر لـ psycopg، أو psycopg2، أو asyncpg، أو SQLAlchemy حيث يبدو المستخدم منفتحًا على نهج مختلف. يُستخدم أيضًا عندما يسأل المستخدم عن تجمع الاتصالات أو المعاملات أو مصانع المؤشر أو كيفية تنظيم كود قاعدة البيانات.
