Standard di codifica PostgreSQL per progetti Python che utilizzano psycopg (no ORM). Utilizza questa capacità ogni volta che l'utente scrive o rivede codice che interroga PostgreSQL con psycopg, crea file SQL, mappa i risultati delle query su oggetti Python o chiede come strutturare il codice di accesso al database. Si attivano cose come "aggiungi una query al database", "scrivi una query SQL", "crea un repository", "recupera da postgres", "inserisci nel database", "aggiorna il DB", "query parametrizzata", "modello pydantic dalla riga del DB", "file sql", "SQL dinamico" o qualsiasi menzione di psycopg, psycopg2, asyncpg o SQLAlchemy in cui l'utente sembra aperto a un approccio diverso. Da utilizzare anche quando l'utente chiede informazioni sul pool di connessioni, sulle transazioni, sui cursor factory o su come organizzare il codice del database.
