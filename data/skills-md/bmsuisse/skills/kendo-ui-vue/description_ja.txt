ユーザーが Kendo UI for Vue (Data Grid、DropDownList、ComboBox、AutoComplete、または @progress/kendo-vue-* パッケージなど) を使用して作業するときは常に、このスキルを使用します。サーバー側のページング/フィルタリング/並べ替え、インライン CRUD 編集、行選択、カスタム セル テンプレート、マスター/詳細行、グループ化、Excel エクスポート、および大規模なデータセットの仮想化をカバーします。 kendo グリッド、telerik vue、@progress/kendo-vue-grid への言及、またはユーザーが Vue でソート可能/フィルター可能/ページング可能なデータ テーブルを構築しているときにトリガーされます。また、ユーザーが既存の Kendo グリッドへの編集、エクスポート、または選択の追加について尋ねたときにもトリガーされます。
