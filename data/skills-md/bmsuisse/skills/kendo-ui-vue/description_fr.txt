Utilisez cette compétence chaque fois que l'utilisateur travaille avec Kendo UI pour Vue, y compris Data Grid, DropDownList, ComboBox, AutoComplete ou tout package @progress/kendo-vue-*. Couvre la pagination/filtrage/tri côté serveur, l'édition CRUD en ligne, la sélection de lignes, les modèles de cellules personnalisés, les lignes maître-détails, le regroupement, l'exportation Excel et la virtualisation pour les grands ensembles de données. Déclenchez toute mention de kendo grid, telerik vue, @progress/kendo-vue-grid, ou lorsque l'utilisateur crée une table de données triable/filtrable/paginable dans Vue. Déclenchez également lorsqu'un utilisateur demande l'ajout d'une modification, d'une exportation ou d'une sélection à une grille Kendo existante.
