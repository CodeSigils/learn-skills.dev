Utilice esta habilidad siempre que el usuario esté trabajando con Kendo UI para Vue, incluido Data Grid, DropDownList, ComboBox, AutoComplete o cualquier paquete @progress/kendo-vue-*. Cubre paginación/filtrado/clasificación del lado del servidor, edición CRUD en línea, selección de filas, plantillas de celdas personalizadas, filas maestras y detalladas, agrupación, exportación a Excel y virtualización para grandes conjuntos de datos. Se activa ante cualquier mención de kendo grid, telerik vue, @progress/kendo-vue-grid, o cuando el usuario está creando una tabla de datos ordenables/filtrables/paginables en Vue. También se activa cuando un usuario pregunta acerca de agregar edición, exportación o selección a una cuadrícula de Kendo existente.
