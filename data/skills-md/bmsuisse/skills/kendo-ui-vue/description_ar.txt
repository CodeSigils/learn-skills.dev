استخدم هذه المهارة عندما يعمل المستخدم مع Kendo UI for Vue - بما في ذلك Data Grid أو DropDownList أو ComboBox أو AutoComplete أو أي حزمة @progress/kendo-vue-*. يغطي الترحيل/التصفية/الفرز من جانب الخادم، وتحرير CRUD المضمن، واختيار الصف، وقوالب الخلايا المخصصة، وصفوف التفاصيل الرئيسية، والتجميع، وتصدير Excel، والمحاكاة الافتراضية لمجموعات البيانات الكبيرة. يتم تشغيله عند أي ذكر لشبكة kendo، أو telerik vue، أو @progress/kendo-vue-grid، أو عندما يقوم المستخدم بإنشاء جدول بيانات قابل للفرز/التصفية/القابل للترحيل في Vue. يتم تشغيله أيضًا عندما يسأل المستخدم عن إضافة تحرير أو تصدير أو تحديد إلى شبكة Kendo موجودة.
