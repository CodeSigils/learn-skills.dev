Verwenden Sie diesen Skill immer dann, wenn der Benutzer mit der Kendo-Benutzeroberfläche für Vue arbeitet – einschließlich Data Grid, DropDownList, ComboBox, AutoComplete oder einem beliebigen @progress/kendo-vue-*-Paket. Umfasst serverseitiges Paging/Filtern/Sortieren, Inline-CRUD-Bearbeitung, Zeilenauswahl, benutzerdefinierte Zellvorlagen, Master-Detail-Zeilen, Gruppierung, Excel-Export und Virtualisierung für große Datensätze. Wird bei jeder Erwähnung von Kendo Grid, Telerik Vue, @progress/kendo-vue-grid oder wenn der Benutzer eine sortierbare/filterbare/auslagerbare Datentabelle in Vue erstellt, ausgelöst. Wird auch ausgelöst, wenn ein Benutzer nach dem Hinzufügen von Bearbeitung, Export oder Auswahl zu einem vorhandenen Kendo-Raster fragt.
