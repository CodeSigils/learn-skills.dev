統合/e2e テスト用に、Docker でローカル PostgreSQL テスト データベースをセットアップして操作します。ユーザーがローカルのテスト Postgres インスタンスに対して追加、構成、トラブルシューティング、またはクエリの実行を行う場合は、たとえ「postgres」と明示的に言わなくても、このスキルを使用してください。 「テスト データベースのセットアップ」、「postgres フィクスチャの追加」、「テスト DB の初期化」、「テスト用のローカル postgres」、「列の追加」、「テーブルの作成」、「スキーマの変更」、「テスト DB での SQL クエリの実行」、「データベースのリセット」、「データベースが同期していない」、「データのテスト」、またはローカル テスト Postgres データベースに関係するものなどをトリガーします。このスキルは、テスト DB を検査する方法、行をシードする方法、またはローカル環境に移行を適用する方法をユーザーが尋ねたときにも使用します。
