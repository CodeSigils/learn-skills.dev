قم بإعداد قاعدة بيانات اختبار PostgreSQL المحلية والعمل معها في Docker لإجراء اختبارات التكامل/e2e. استخدم هذه المهارة عندما يريد المستخدم إضافة استعلامات أو تكوينها أو استكشاف الأخطاء وإصلاحها أو تشغيلها مقابل اختبار محلي لمثيل Postgres - حتى لو لم يذكر "postgres" بشكل صريح. مشغلات لأشياء مثل "إعداد قاعدة بيانات اختبارية" أو "إضافة تركيبات postgres" أو "init test DB" أو "postgres محلية للاختبارات" أو "إضافة عمود" أو "إنشاء جدول" أو "تغيير المخطط" أو "تشغيل استعلام SQL على قاعدة بيانات الاختبار الخاصة بي" أو "إعادة تعيين قاعدة البيانات" أو "قاعدة البيانات غير متزامنة" أو "بيانات الاختبار" أو أي شيء يتضمن قاعدة بيانات Postgres الاختبارية المحلية. استخدم هذه المهارة أيضًا عندما يسأل المستخدم عن كيفية فحص قاعدة بيانات الاختبار أو الصفوف الأولية أو تطبيق الترحيل إلى البيئة المحلية.
