OneTrade/Navision プロジェクト用の包括的な C-AL コードユニット分析ツール。依存関係のない Python スクリプト。分析 (詳細な調査)、スキャン (プロジェクト全体のボトルネック検出)、最適化 (リファクタリングの提案) の 3 つのサブコマンドを備えています。 Python 標準ライブラリのみで動作します - パッケージをインストールする必要はありません。ユーザーがコードユニットの分析、パフォーマンスの問題の発見、または Navision コードの最適化について尋ねたときに使用します。トリガー: 「/codeunit-analyzer」、「コードユニットの分析」、「ボトルネックのスキャン」。
