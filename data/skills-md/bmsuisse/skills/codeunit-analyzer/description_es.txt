Herramienta integral de análisis de codeunidades C-AL para el proyecto OneTrade/Navision. Script Python de dependencia cero con tres subcomandos: analizar (inmersión profunda), escanear (detección de cuellos de botella en todo el proyecto) y optimizar (sugerencias de refactorización). Funciona solo con la biblioteca estándar de Python: ¡no es necesario instalar paquetes! Úselo cuando el usuario pregunte sobre cómo analizar unidades de código, encontrar problemas de rendimiento u optimizar el código de Navision. Activador: "/codeunit-analyzer", "analizar codeunit", "escanear cuellos de botella".
