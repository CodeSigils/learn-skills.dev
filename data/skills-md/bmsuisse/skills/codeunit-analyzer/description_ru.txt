Комплексный инструмент анализа модулей кода C-AL для проекта OneTrade/Navision. Скрипт Python с нулевой зависимостью и тремя подкомандами: анализ (глубокое погружение), сканирование (обнаружение узких мест в масштабе проекта) и оптимизация (предложения по рефакторингу). Работает только со стандартной библиотекой Python — никаких пакетов устанавливать не нужно! Используйте, когда пользователь спрашивает об анализе модулей кода, обнаружении проблем с производительностью или оптимизации кода Navision. Триггер: «/codeunit-analyzer», «анализировать codeunit», «сканировать узкие места».
