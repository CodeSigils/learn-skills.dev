Outil complet d'analyse des unités de code C-AL pour le projet OneTrade/Navision. Script Python sans dépendance avec trois sous-commandes : analyser (analyse approfondie), analyser (détection des goulots d'étranglement à l'échelle du projet) et optimiser (suggestions de refactoring). Fonctionne uniquement avec la bibliothèque standard Python - aucun package à installer ! À utiliser lorsque l'utilisateur pose des questions sur l'analyse des unités de code, la recherche de problèmes de performances ou l'optimisation du code Navision. Déclencheur : "/codeunit-analyzer", "analyser le codeunit", "analyser les goulots d'étranglement".
