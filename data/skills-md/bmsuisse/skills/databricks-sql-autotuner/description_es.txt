Optimizador de consultas SQL de Databricks y solucionador de errores: analiza una consulta SQL lenta o rota, la reescribe para acelerarla usando optimizaciones de nivel SQL únicamente, valida la equivalencia de resultados byte por byte y compara ambas versiones con pruebas de significancia estadística. También diagnostica y corrige errores de SQL (errores de sintaxis, fallas de conversión, errores de resolución de columnas, discrepancias de tipos) usando --goals fix. Utilice esta habilidad siempre que el usuario desee optimizar, acelerar, ajustar, comparar o corregir una consulta SQL en Databricks.
