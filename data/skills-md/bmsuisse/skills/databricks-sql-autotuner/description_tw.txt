Databricks SQL 查詢最佳化器和錯誤修復器：分析緩慢或損壞的 SQL 查詢，僅使用 SQL 級最佳化重寫它以提高速度，驗證逐位元組結果等效性，並透過統計顯著性測試對兩個版本進行基準測試。也可以使用 --goals fix 來診斷和修復 SQL 錯誤（語法錯誤、轉換失敗、列解析錯誤、類型不符）。每當使用者想要最佳化、加速、調整、基準測試或修復 Databricks 上的 SQL 查詢時，請使用此技能。觸發：「/databricks-sql-autotuner」、「最佳化此 SQL」、「讓此查詢更快」、「調整我的 SQLbricks 查詢」、「Databricks 上的基準 SQL」、「加快此 Spark SQL 速度」、「Databricks 上的 SQL 查詢效能」、「解釋此查詢」、「為什麼我的查詢 Databricks Datan語法”錯誤”、“SQL 中的轉換錯誤”、“SQL 中找不到列”、“AnalysisException”、“ParseException”、“我的 Databricks 查詢失敗”，或每當用戶貼上 SQL 查詢並提及錯誤、失敗或例外時。
