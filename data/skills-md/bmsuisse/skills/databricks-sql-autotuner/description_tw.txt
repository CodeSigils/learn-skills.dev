Databricks SQL 查詢最佳化器和錯誤修復器：分析緩慢或損壞的 SQL 查詢，僅使用 SQL 級最佳化重寫它以提高速度，驗證逐位元組結果等效性，並透過統計顯著性測試對兩個版本進行基準測試。还可以使用 --goals fix 诊断和修复 SQL 错误（语法错误、转换失败、列解析错误、类型不匹配）。每当用户想要优化、加速、调整、基准测试或修复 Databricks 上的 SQL 查询时，请使用此技能。觸發：「/databricks-sql-autotuner」、「最佳化此 SQL」、「讓此查詢更快」、「調整我的 SQLbricks 查詢」、「Databricks 上的基準 SQL」、「加快此 Spark SQL 速度」、「Databricks 上的 SQL 查詢效能」、「解釋此查詢」、「為什麼我的查詢 Databricks Datan語法”錯誤”、“SQL 中的轉換錯誤”、“SQL 中找不到列”、“AnalysisException”、“ParseException”、“我的 Databricks 查詢失敗”，或每當用戶貼上 SQL 查詢並提及錯誤、失敗或例外時。
