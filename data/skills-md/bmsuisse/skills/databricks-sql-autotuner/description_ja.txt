Databricks SQL クエリ オプティマイザーおよびエラー修正機能: 低速または壊れた SQL クエリを分析し、SQL レベルの最適化のみを使用して高速化のために書き直し、バイトごとの結果の同等性を検証し、統計的有意性テストで両方のバージョンのベンチマークを実行します。また、 --goals fix を使用して SQL エラー (構文エラー、キャスト失敗、列解決エラー、型の不一致) を診断して修正します。ユーザーが Databricks 上で SQL クエリを最適化、高速化、調整、ベンチマーク、または修正したい場合は常に、このスキルを使用します。トリガー: "/databricks-sql-autotuner"、"この SQL を最適化"、"このクエリを高速化"、"Databricks クエリを調整"、"Databricks で SQL をベンチマーク"、"Spark SQL を高速化"、"Databricks での SQL パフォーマンス"、"このクエリを説明する"、"Databricks で私のクエリが遅い理由"、"SQL クエリ最適化 Databricks"、"SQL クエリを修正"、 「SQL 構文エラー」、「SQL のキャスト エラー」、「SQL で列が見つかりません」、「AnalysisException」、「ParseException」、「Databricks クエリが失敗します」、またはユーザーが SQL クエリを貼り付けてエラー、失敗、または例外について言及したとき。
