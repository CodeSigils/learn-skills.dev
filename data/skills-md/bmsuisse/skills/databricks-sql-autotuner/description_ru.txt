Оптимизатор SQL-запросов Databricks и средство исправления ошибок: анализирует медленный или неработающий SQL-запрос, переписывает его для обеспечения скорости, используя только оптимизацию на уровне SQL, проверяет побайтовую эквивалентность результатов и сравнивает обе версии с проверкой статистической значимости. Также диагностирует и исправляет ошибки SQL (синтаксические ошибки, ошибки приведения, ошибки разрешения столбцов, несоответствия типов) с помощью --goals fix. Используйте этот навык всякий раз, когда пользователь хочет оптимизировать, ускорить, настроить, протестировать или исправить SQL-запрос в Databricks. Запуск по: «/databricks-sql-autotuner», «оптимизировать этот SQL», «сделать этот запрос быстрее», «настроить мой запрос Databricks», «тестировать SQL на Databricks», «ускорить этот искровой SQL», «производительность SQL на Databricks», «ОБЪЯСНИТЬ этот запрос», «почему мой запрос медленный на Databricks», «Оптимизация SQL-запроса Databricks», «исправить мой SQL-запрос», «синтаксическая ошибка SQL», «ошибка приведения в SQL», «столбец не найден в SQL», «AnalysisException», «ParseException», «мой запрос Databricks не работает» или всякий раз, когда пользователь вставляет запрос SQL и упоминает ошибки, сбои или исключения.
