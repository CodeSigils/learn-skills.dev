Databricks SQL-Abfrageoptimierer und Fehlerbeseitiger: Analysiert eine langsame oder fehlerhafte SQL-Abfrage, schreibt sie aus Geschwindigkeitsgründen mithilfe von Optimierungen auf SQL-Ebene neu, validiert die Byte-für-Byte-Ergebnisäquivalenz und vergleicht beide Versionen mit statistischen Signifikanztests. Diagnostiziert und behebt außerdem SQL-Fehler (Syntaxfehler, Umwandlungsfehler, Spaltenauflösungsfehler, Typkonflikte) mithilfe von --goals fix. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine SQL-Abfrage in Databricks optimieren, beschleunigen, optimieren, vergleichen oder korrigieren möchte. Auslöser für: „/databricks-sql-autotuner“, „Dieses SQL optimieren“, „Diese Abfrage schneller machen“, „Meine Databricks-Abfrage optimieren“, „SQL auf Databricks vergleichen“, „Diesen Spark SQL beschleunigen“, „SQL-Leistung auf Databricks“, „Diese Abfrage ERKLÄREN“, „Warum ist meine Abfrage auf Databricks langsam“, „SQL-Abfrageoptimierung Databricks“, „Meine SQL-Abfrage korrigieren“, „SQL-Syntaxfehler“, „Umsetzungsfehler in SQL“, „Spalte nicht in SQL gefunden“, „AnalysisException“, „ParseException“, „meine Databricks-Abfrage schlägt fehl“ oder immer dann, wenn ein Benutzer eine SQL-Abfrage einfügt und Fehler, Ausfälle oder Ausnahmen erwähnt.
