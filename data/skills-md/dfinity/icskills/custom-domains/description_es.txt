Registre y administre dominios personalizados para contenedores de circuitos integrados a través del servicio de dominio personalizado de la puerta de enlace HTTP. Cubre la configuración del registro DNS (CNAME, TXT, desafío ACME), el archivo .well-known/ic-domains, el registro/validación/actualización/eliminación del dominio a través de la API REST, el aprovisionamiento de certificados TLS y la configuración del host HttpAgent. Úselo cuando el usuario desee servir un recipiente bajo un dominio personalizado, configurar DNS para IC, registrar un dominio con nodos de límite, solucionar problemas de dominio personalizado o actualizar/eliminar un dominio personalizado. NO lo use para alojamiento frontend general o configuración de contenedores de activos sin dominios personalizados; use el contenedor de activos en su lugar.
