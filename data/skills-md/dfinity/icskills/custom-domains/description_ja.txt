HTTP ゲートウェイ カスタム ドメイン サービスを介して、IC キャニスターのカスタム ドメインを登録および管理します。 DNS レコード構成 (CNAME、TXT、ACME チャレンジ)、.well-known/ic-domains ファイル、REST API を介したドメイン登録/検証/更新/削除、TLS 証明書プロビジョニング、および HttpAgent ホスト構成について説明します。ユーザーがカスタム・ドメインでキャニスターを提供する場合、IC の DNS を構成する場合、境界ノードへのドメインを登録する場合、カスタム・ドメインの問題のトラブルシューティングを行う場合、またはカスタム・ドメインを更新/削除する場合に使用します。カスタム ドメインを使用しない一般的なフロントエンド ホスティングまたはアセット キャニスター構成には使用しないでください。代わりに、asset-canister を使用してください。
