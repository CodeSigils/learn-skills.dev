Регистрируйте собственные домены для контейнеров микросхем и управляйте ими через службу собственных доменов HTTP-шлюза. Охватывает настройку записей DNS (CNAME, TXT, вызов ACME), файл .well-known/ic-domains, регистрацию/проверку/обновление/удаление домена через REST API, предоставление сертификата TLS и конфигурацию хоста HttpAgent. Используйте, когда пользователь хочет обслуживать накопитель в личном домене, настроить DNS для IC, зарегистрировать домен с граничными узлами, устранить проблемы с личным доменом или обновить/удалить личный домен. НЕ используйте для общего хостинга внешнего интерфейса или конфигурации накопителя активов без пользовательских доменов — вместо этого используйте asset-canister.
