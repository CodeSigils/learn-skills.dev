Позволяет агенту AI или сеансу CLI войти в Internet Identity и действовать в качестве субъекта, специфичного для приложения пользователя (например, для oisy.com или nns.ic0.app) через `icp Identity Link Web`. Используйте, когда пользователь просит агента войти в приложение на базе II, получить делегирование или совершить авторизованные вызовы накопителя от его имени. НЕ используйте для добавления входа II в интерфейс — вместо этого используйте навык интернет-идентификации.
