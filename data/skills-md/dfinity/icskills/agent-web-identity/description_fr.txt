Permet à un agent IA ou à une session CLI de se connecter à Internet Identity et d'agir en tant que principal spécifique à l'application d'un utilisateur (par exemple pour oisy.com ou nns.ic0.app) via le « lien d'identité icp web ». À utiliser lorsque l'utilisateur demande à un agent de se connecter à une application alimentée par II, d'obtenir une délégation ou de passer des appels de cartouche autorisés en son nom. Ne PAS utiliser pour ajouter une connexion II à une interface – utilisez plutôt la compétence d'identité Internet.
