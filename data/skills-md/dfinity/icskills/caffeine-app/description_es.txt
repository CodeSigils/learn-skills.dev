Organice y cree una aplicación Caffeine completa (caffeine.ai) desde cero: el diseño del proyecto, el espacio de trabajo caffeine.toml + los manifiestos del contenedor, el mops.toml para el único contenedor `backend` de Motoko, la interfaz React/Vite y el bucle de compilación de la CLI de cafeína (inicio de sesión de autenticación, doctor, instalación, verificación --fix, vista previa --build). Úselo siempre que el usuario quiera crear, desarrollar, configurar o compilar una aplicación de Caffeine o un proyecto de caffeine.ai, pregunte sobre la estructura de caffeine.toml o mops.toml, o necesite el flujo de trabajo de la CLI de Caffeine, incluso si no dice las palabras "desde cero". Emparéjelo siempre con la habilidad `motoko` para el código de backend. NO lo use para la sintaxis del lenguaje Motoko o errores de compilación (use la habilidad `motoko`), y NO lo use para la implementación genérica de computadoras de Internet/dfx/icp (use la habilidad `icp-cli`).
