Implemente una interfaz o cualquier sitio estático en el IC con la receta @dfinity/static-site (el contenedor de activos certificados). Cubre la configuración de recetas de icp.yaml, enrutamiento SPA con _redirects, encabezados personalizados/CSP con _headers, URL limpias, protección de acceso para aplicaciones privadas, dominios personalizados y compilación contra ID de recipientes. Esta es la forma recomendada de alojar interfaces y archivos estáticos en el IC. También es el punto de entrada para la receta heredada @dfinity/asset-canister y .ic-assets.json5 (consulte la referencia heredada) y para migrar un contenedor de activos existente a activos certificados. Úselo cuando aloje una interfaz, implemente archivos estáticos, un contenedor de activos o configure el enrutamiento SPA en el IC. NO lo use para patrones de código HTTP a nivel de recipiente ni para la configuración de DNS de dominio personalizado; use dominios personalizados para DNS.
