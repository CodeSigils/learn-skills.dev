Distribuisci un frontend o qualsiasi sito statico sull'IC con la ricetta @dfinity/static-site (il contenitore delle risorse certificate). Copre la configurazione della ricetta icp.yaml, il routing SPA con _redirect, intestazioni personalizzate/CSP con _headers, URL puliti, protezione dell'accesso per app private, domini personalizzati e creazione di ID contenitore. Questo è il modo consigliato per ospitare frontend e file statici sull'IC. È anche il punto di ingresso per la ricetta legacy @dfinity/asset-canister e .ic-assets.json5 (vedere il riferimento legacy) e per la migrazione di un contenitore di risorse esistente ad asset certificati. Da utilizzare quando si ospita un frontend, si distribuiscono file statici, un contenitore di risorse o si configura il routing SPA sull'IC. NON utilizzare per modelli di codice HTTP a livello di contenitore o per la configurazione DNS di dominio personalizzato: utilizzare domini personalizzati per DNS.
