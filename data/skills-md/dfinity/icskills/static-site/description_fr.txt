Déployez une interface ou n'importe quel site statique sur l'IC avec la recette @dfinity/static-site (le canister d'actifs certifiés). Couvre la configuration de la recette icp.yaml, le routage SPA avec _redirects, les en-têtes personnalisés/CSP avec _headers, les URL propres, la protection d'accès aux applications privées, les domaines personnalisés et la création d'ID de cartouche. Il s'agit de la méthode recommandée pour héberger les interfaces et les fichiers statiques sur le circuit intégré. Également le point d'entrée pour l'ancienne recette @dfinity/asset-canister et .ic-assets.json5 (voir la référence héritée) et pour la migration d'un canister d'actifs existant vers des actifs certifiés. À utiliser lors de l'hébergement d'une interface, du déploiement de fichiers statiques, d'une cartouche d'actifs ou de la configuration du routage SPA sur l'IC. Ne PAS utiliser pour les modèles de code HTTP au niveau de la cartouche ou la configuration DNS de domaine personnalisé : utilisez des domaines personnalisés pour DNS.
