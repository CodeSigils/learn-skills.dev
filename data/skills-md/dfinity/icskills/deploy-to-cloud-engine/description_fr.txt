Déploie un projet d'ordinateur Internet construit sur le moteur cloud d'un utilisateur (un moteur OpenCloud) : vérifiez la CLI icp, liez l'identité de la console avec « lien d'identité icp web » (l'origine par défaut est https://opencloud.org ; un transfert de délégation couvre les bacs à sable dont le rappel 127.0.0.1 le navigateur ne peut pas atteindre), exécutez « icp déployer » sur le sous-réseau du moteur, marquez les cartouches avec les variables d'environnement « __META_* » pour un nom nommé. application console avec des cartouches et une icône étiquetées, et intégrez les métadonnées de la version (service:git:sha, service:version) dans le wasm. Couvre également une cartouche proxy financée pour les appels cycliques entre sous-réseaux (taux de change, seuil ECDSA/Schnorr, vetKD). À utiliser lors de l'expédition vers un moteur cloud ; à la mention d'OpenCloud, d'un identifiant de sous-réseau de moteur ou en reliant l'icp CLI à une console de moteur ; lorsque la connexion ne se termine jamais à partir d'un agent en mode sandbox ; lors de la nomination, de l'ajout d'une icône ou de l'enregistrement de la version déployée/du commit git d'une application console. Ne PAS utiliser pour un déploiement général du réseau principal sans moteur ni sous-réseau (utilisez icp-cli) ou pour écrire une logique de cartouche.
