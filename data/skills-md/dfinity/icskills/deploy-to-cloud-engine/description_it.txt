Distribuisce un progetto di computer Internet creato sul motore cloud di un utente (un motore OpenCloud): verifica la CLI icp, collega l'identità della console con `icp Identity Link Web` (l'origine predefinita è https://opencloud.org; un trasferimento di delega copre sandbox il cui callback 127.0.0.1 il browser non può raggiungere), esegui `icp deploy` sulla sottorete del motore, tagga i contenitori con `__META_*` env vars per un'app console denominata con contenitori e icone etichettati e inserire i metadati della versione (service:git:sha, service:version) nel file wasm. Copre anche un contenitore proxy finanziato per chiamate con cicli tra sottoreti (tasso di cambio, soglia ECDSA/Schnorr, vetKD). Da utilizzare in caso di spedizione a un motore cloud; alla menzione di OpenCloud, all'ID di una sottorete del motore o al collegamento della CLI icp a una console del motore; quando l'accesso non viene mai completato da un agente sandbox; quando si assegna un nome, si aggiunge un'icona o si registra la versione/git commit distribuito di un'app console. NON utilizzare per una distribuzione generale della rete principale senza motore o sottorete (utilizzare icp-cli) o per scrivere la logica del contenitore.
