Развертывает встроенный проект Интернет-компьютера в облачном движке пользователя (движок OpenCloud): проверяет icp CLI, связывает идентификатор консоли с icpidentity link web (по умолчанию используется https://opencloud.org; передача делегирования охватывает песочницы, к которым браузер не может получить обратный вызов 127.0.0.1), запускает icp Deploy в подсети движка, помечает контейнеры переменными env `__META_*` для именованного консольное приложение с помеченными контейнерами и значками и запишите метаданные версии (service:git:sha, service:version) в файл wasm. Также включает финансируемый прокси-накопитель для вызовов с циклическим переносом между подсетями (курс обмена, пороговое значение ECDSA/Schnorr, vetKD). Используйте при отправке в облачный движок; при упоминании OpenCloud, идентификаторе подсети движка или привязке интерфейса командной строки icp к консоли движка; когда вход в систему из изолированного агента никогда не завершается; при именовании, добавлении значка или записи развернутой версии/git-коммита консольного приложения. НЕ используйте для общего развертывания основной сети без механизма или подсети (используйте icp-cli) или для написания логики накопителя.
