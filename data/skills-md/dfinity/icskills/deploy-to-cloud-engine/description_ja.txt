構築されたインターネット コンピューター プロジェクトをユーザーのクラウド エンジン (OpenCloud エンジン) にデプロイします。icp CLI を確認し、コンソール ID を「icp ID リンク Web」にリンクします (オリジンのデフォルトは https://opencloud.org です。委任ハンドオフは、ブラウザーが到達できない 127.0.0.1 コールバックのサンドボックスをカバーします)。エンジンのサブネットに対して「icpdeploy」を実行し、キャニスターに「__META_*」env をタグ付けします。ラベル付きのキャニスターとアイコンを持つ名前付きコンソール アプリの vars を作成し、バージョン メタデータ (service:git:sha、service:version) を wasm にベイクします。また、クロスサブネットのサイクルベアリング呼び出し (為替レート、しきい値 ECDSA/Schnorr、vetKD) 用の資金提供されたプロキシ キャニスターもカバーします。クラウド エンジンに送信する場合に使用します。 OpenCloud、エンジンのサブネット ID、または icp CLI のエンジン コンソールへのリンクについての言及。サンドボックス エージェントからのサインインが完了しない場合。名前を付けるとき、アイコンを追加するとき、またはコンソール アプリのデプロイされたバージョン/git コミットを記録するとき。エンジンやサブネットを使用しない一般的なメインネットのデプロイ (icp-cli を使用)、またはキャニスター ロジックの作成には使用しないでください。
