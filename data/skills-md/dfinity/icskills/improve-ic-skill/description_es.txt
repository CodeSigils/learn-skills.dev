Mejorar una habilidad existente en el repositorio de IC Skills (skills.internetcomputer.org). Cargue esta habilidad cada vez que se le solicite mejorar, corregir, actualizar, mejorar, revisar o agregar contenido a una habilidad existente en skills/<skill-name>/SKILL.md, lo que incluye agregar dificultades, actualizar ID de contenedores, corregir ejemplos de código, fortalecer la descripción o actualizar evaluaciones. NO lo use para crear una habilidad nueva (use el creador de habilidades para eso). Ejemplos de activadores: "a la habilidad motoko le falta un obstáculo", "actualizar icp-cli para el nuevo formato de receta", "la descripción de ckbtc es débil", "agregar una evaluación para la habilidad de seguridad del recipiente".
