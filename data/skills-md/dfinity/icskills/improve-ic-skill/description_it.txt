Migliorare una competenza esistente nel repository IC Skills (skills.internetcomputer.org). Carica questa competenza ogni volta che ti viene chiesto di migliorare, correggere, aggiornare, potenziare, rivedere o aggiungere contenuto a una competenza esistente su skills/<nome-competenza>/SKILL.md, inclusa l'aggiunta di insidie, l'aggiornamento degli ID dei contenitori, la correzione di esempi di codice, il rafforzamento della descrizione o l'aggiornamento delle valutazioni. NON utilizzare per creare una nuova abilità (utilizzare skill-creator per questo). Esempi di trigger: "nell'abilità motoko manca una trappola", "aggiorna icp-cli per il nuovo formato della ricetta", "la descrizione ckbtc è debole", "aggiungi una valutazione per l'abilità di sicurezza del contenitore".
