Améliorez une compétence existante dans le référentiel IC Skills (skills.internetcomputer.org). Chargez cette compétence chaque fois qu'on vous demande d'améliorer, de corriger, de mettre à jour, d'améliorer, de réviser ou d'ajouter du contenu à une compétence existante dans skills/<skill-name>/SKILL.md - y compris l'ajout de pièges, la mise à jour des ID de cartouche, la correction d'exemples de code, le renforcement de la description ou la mise à jour des évaluations. Ne PAS utiliser pour créer une toute nouvelle compétence (utilisez le créateur de compétences pour cela). Exemples de déclencheurs : "il manque un piège à la compétence motoko", "mettre à jour icp-cli pour le nouveau format de recette", "la description ckbtc est faible", "ajouter une évaluation pour la compétence de sécurité du canister".
