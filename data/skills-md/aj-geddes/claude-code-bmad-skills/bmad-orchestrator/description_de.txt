Orchestriert BMAD-Workflows für eine strukturierte KI-gesteuerte Entwicklung. Verwenden Sie diese Option, wenn Sie BMAD in Projekten initialisieren, den Workflow-Status überprüfen oder zwischen vier Phasen (Analyse, Planung, Lösungsfindung, Implementierung) weiterleiten. Verwaltet Projektkonfigurationen, verfolgt den Fortschritt auf den Projektebenen 0–4 und koordiniert mit speziellen Arbeitsabläufen. Auslöser bei /workflow-init, /workflow-status oder wenn Benutzer eine BMAD-Einrichtung benötigen.
