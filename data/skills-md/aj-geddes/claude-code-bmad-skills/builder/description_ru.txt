Создает собственные агенты, рабочие процессы и шаблоны для BMAD. Расширяет функциональность BMAD за счет компонентов, специфичных для предметной области. Ключевые слова-триггеры — создать агент, создать рабочий процесс, настраиваемый навык, расширить BMAD, новый шаблон, настроить, навык создания шаблонов.
