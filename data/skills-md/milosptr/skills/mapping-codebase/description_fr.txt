Produisez une carte CONTEXT.md organisée d'une base de code inconnue ou volumineuse couvrant les points d'entrée, l'architecture, les modules, les termes de domaine, les commandes et les mines terrestres. À utiliser lorsque vous commencez à travailler sur une base de code inconnue, que vous rejoignez un projet, avant une refactorisation transversale ou lorsqu'une session précédente a été confuse quant à l'endroit où se trouvent les choses. Ignorez les bases de code de moins de 30 fichiers sources où la lecture directe est plus rapide.
