Produci una mappa CONTEXT.md curata di una base di codice sconosciuta o di grandi dimensioni che copra punti di ingresso, architettura, moduli, termini di dominio, comandi e mine antiuomo. Da utilizzare quando si inizia a lavorare su una base di codice sconosciuta, si partecipa a un progetto, prima di un refactoring trasversale o quando in una sessione precedente si è confuso su dove si trovano le cose. Salta per codebase inferiori a ~30 file sorgente in cui la lettura diretta è più veloce.
