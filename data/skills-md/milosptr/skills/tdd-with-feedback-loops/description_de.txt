Implementieren Sie Funktionen oder Korrekturen mithilfe der Test-First-Entwicklung mit strikter vertikaler Aufteilung – ein fehlgeschlagener Test, die kleinste bestandene Änderung, dann Typprüfung und Lint und Tests als vollständige Feedbackschleife, dann Refaktorierung. Verwenden Sie es, wenn Sie nicht triviale Logik implementieren, Fehler beheben, die einen Regressionstest erfordern, oder wenn Sie mit unbekanntem Code arbeiten. Funktioniert gleichermaßen gut aus einem PLAN.md oder direkt aus einer klaren Benutzeranfrage. Überspringen Sie, um Tippfehler, Abhängigkeitsprobleme oder einzeilige Änderungen zu beheben.
