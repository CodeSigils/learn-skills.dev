Implémentez des fonctionnalités ou des correctifs en utilisant un développement axé sur les tests avec un découpage vertical strict : un test échoué, la plus petite modification réussie, puis une vérification de type et des peluches et des tests en tant que boucle de rétroaction complète, puis une refactorisation. À utiliser lors de l'implémentation d'une logique non triviale, lors de la correction de bogues nécessitant un test de régression ou lorsque vous travaillez dans un code inconnu. Fonctionne aussi bien à partir d'un PLAN.md que directement à partir d'une demande claire de l'utilisateur. Ignorez les corrections de fautes de frappe, les modifications de dépendances ou les modifications d'une seule ligne.
