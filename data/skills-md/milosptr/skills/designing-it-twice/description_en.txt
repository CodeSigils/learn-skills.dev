Generate two or three radically different interface designs for a module, each under a different design constraint, then compare and let the user pick. Counters AI's tendency to commit to the first plausible interface. Use before implementing a new module's public interface, when an existing interface feels wrong but the right shape isn't obvious, or when the user mentions "design it twice" or "design alternatives". Skip for trivial interfaces (a single function with obvious signature) or when the interface shape is already locked in.
