Review a diff or PR from a fresh-context perspective, challenging implementation shortcuts, hidden assumptions, missing tests, security risks, design regressions, and maintainability decay. Output is a severity-tagged review with explicit blockers, considerations, and nits. Use after any significant implementation, ideally invoked from a fresh session by a Claude that did not write the code being reviewed. Skip for trivial diffs (typo fixes, single-line changes, dependency bumps) and for diffs the same session just produced.
