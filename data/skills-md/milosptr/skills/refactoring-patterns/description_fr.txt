Exécutez des refactorisations en tant que transformations nommées du catalogue de Fowler (extraire la fonction, la variable en ligne, la méthode de déplacement, remplacer le conditionnel par un polymorphisme, etc.) et les mouvements de complexité d'Ousterhout (approfondir le module, masquer les informations, tirer la complexité vers le bas). Les tests doivent rester verts entre chaque transformation. À utiliser pour nettoyer la verbosité générée par l'IA, supprimer les duplications, simplifier les interfaces ou après qu'une révision du code révèle des odeurs. Ignorez les changements qui modifient le comportement observable – ce ne sont pas des refactorisations.
