Execute refactorings as named transformations from Fowler's catalog (Extract Function, Inline Variable, Move Method, Replace Conditional with Polymorphism, etc.) and Ousterhout's complexity moves (deepen module, hide information, pull complexity downwards). Tests must stay green between every transformation. Use when cleaning up AI-generated verbosity, removing duplication, simplifying interfaces, or after a code review reveals smells. Skip for changes that alter observable behavior — those are not refactorings.
