Compétence pour générer une interface utilisateur de production basée sur Store. Vue 3 + TypeScript + NuxtUI v4.  
Déclenché par les mots-clés "make UI", "create screen", "CRUD screen", "list screen".  
Nécessite un Store existant et produit du code de production intégré à de véritables API.  
Pour les prototypes de données fictives, utilisez Peach-gen-ui-proto.
