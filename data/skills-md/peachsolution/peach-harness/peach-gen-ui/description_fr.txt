Une compétence permettant de générer une interface utilisateur de production basée sur un Store. Vue 3 + TypeScript + NuxtUI v4.
Déclenché par des mots-clés : « créer une interface utilisateur », « générer un écran », « écran CRUD », « écran de liste ».
Nécessite un Store et produit du code prêt pour la production intégré à de véritables API.
Pour les prototypes de données fictives, utilisez Peach-gen-ui-proto.
