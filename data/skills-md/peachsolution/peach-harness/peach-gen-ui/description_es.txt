Habilidad para generar una interfaz de usuario de nivel de producción basada en la Tienda. Vue 3 + TypeScript + NuxtUI v4.
Activado por palabras clave: "crear interfaz de usuario", "crear pantalla", "pantalla CRUD", "pantalla de lista".
Requiere una tienda existente y produce código de producción integrado con API reales.
Para prototipos con datos simulados, utilice Peach-gen-ui-proto.
