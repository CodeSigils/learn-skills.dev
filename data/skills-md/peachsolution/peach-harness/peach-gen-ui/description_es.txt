Una habilidad para generar una interfaz de usuario de producción basada en una Tienda. Vue 3 + TypeScript + NuxtUI v4.
Activado por palabras clave: "crear interfaz de usuario", "generar pantalla", "pantalla CRUD", "pantalla de lista".
Requiere una tienda y produce código listo para producción integrado con API reales.
Para prototipos de datos simulados, utilice Peach-gen-ui-proto.
