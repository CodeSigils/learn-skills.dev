Навык создания производственного пользовательского интерфейса на основе Магазина. Vue 3 + TypeScript + NuxtUI v4.
Запускается по ключевым словам: «создать пользовательский интерфейс», «создать экран», «экран CRUD», «экран списка».
Требуется хранилище и создается готовый к использованию код, интегрированный с реальными API.
Для прототипов фиктивных данных используйте peach-gen-ui-proto.
