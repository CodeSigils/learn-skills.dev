Навык создания пользовательских интерфейсов производственного уровня на основе Магазина. Vue 3 + TypeScript + NuxtUI v4.
Запускается по ключевым словам: «создать пользовательский интерфейс», «создать экран», «экран CRUD», «экран списка».
Магазин должен существовать, и он создает рабочий код, привязанный к реальным API.
Для прототипов фиктивных данных используйте peach-gen-ui-proto.
