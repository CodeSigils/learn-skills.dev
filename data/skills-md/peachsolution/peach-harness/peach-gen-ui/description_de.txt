Eine Fertigkeit zum Generieren einer Produktions-Benutzeroberfläche basierend auf einem Store. Vue 3 + TypeScript + NuxtUI v4.
Ausgelöst durch Schlüsselwörter: „Benutzeroberfläche erstellen“, „Bildschirm generieren“, „CRUD-Bildschirm“, „Listenbildschirm“.
Erfordert einen Store und erzeugt produktionsbereiten Code, der in echte APIs integriert ist.
Für Mock-Data-Prototypen verwenden Sie „peach-gen-ui-proto“.
