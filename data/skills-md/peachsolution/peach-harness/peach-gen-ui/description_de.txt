Eine Fähigkeit zum Generieren einer Benutzeroberfläche in Produktionsqualität basierend auf Store. Vue 3 + TypeScript + NuxtUI v4.
Ausgelöst durch Schlüsselwörter: „Benutzeroberfläche erstellen“, „Bildschirm generieren“, „CRUD-Bildschirm“, „Bildschirm auflisten“.
Erfordert einen vorhandenen Store und generiert Produktionscode, der in echte APIs integriert ist.
Verwenden Sie „peach-gen-ui-proto“ für Mock-Data-Prototypen.
