Интегрированный командный навык, который управляет настройкой среды E2E на основе Spec и ui-proto + автоматическое разделение модулей по сценариям + создание интегрированного пакета + выполнение + проверка соответствия - все одновременно. Запускается по ключевым словам: «проверить e2e», «проверка интеграции», «полное тестирование», «команда e2e», «проверить соответствие спецификации», «сравнить с ui-proto», «окончательная проверка», «проверка перед выпуском». Разделяет шаблоны трех навыков — peach-e2e-setup, peach-e2e-scenario и peach-e2e-suite — и переносит критерии проверки на экраны ui-proto + бизнес-правила Spec. Формирует единый поток доставки разработки-проверки с peach-team-dev, сохраняя при этом контекст реализации и контекст проверки отдельно. Запускается в командном режиме, если доступны групповые функции Claude Code, или в общем режиме для сред Codex/skills.sh. Ключевым отличием является автоматическая проверка соответствия реализации исходному замыслу, помимо простых проверок поведения кода.
