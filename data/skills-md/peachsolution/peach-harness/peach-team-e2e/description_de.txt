Eine integrierte Teamfähigkeit, die die Einrichtung einer E2E-Umgebung auf der Grundlage von Spec und UI-Proto + automatische Aufteilung von Einheitenszenarien + integrierte Suite-Erstellung + Ausführung + Compliance-Validierung auf einmal übernimmt. Ausgelöst durch Schlüsselwörter: „run e2e validation“, „integrated validation“, „full flow test“, „team e2e“, „check if it work per spec“, „verify against ui-proto“, „final validation“, „pre-release validation“. Teilt das Muster von drei Fähigkeiten – Peach-E2e-Setup + Peach-E2e-Scenario + Peach-E2e-Suite – und externalisiert Validierungskriterien auf UI-Proto-Bildschirme + Spec-Geschäftsregeln. Bildet zusammen mit Peach-Team-Dev einen einzigen Entwicklungs-Validierungs-Lieferfluss, während der Implementierungskontext und der Validierungskontext getrennt bleiben. Wird im Teammodus ausgeführt, wenn Claude Code-Teamfunktionen verfügbar sind, oder im generischen Modus unter Codex/skills.sh-Umgebungen. Das Hauptunterscheidungsmerkmal ist die automatische Validierung der Ausrichtung auf die Designabsicht, die über einfache Code-Verhaltensprüfungen hinausgeht.
