Навык выпуска, который обрабатывает все: от обновления базовой версии → автоматического создания CHANGELOG.md → разработки коммита/push → создания основного PR → слияния PR → создания релиза GitHub.
После анализа изменений пользователь вручную выбирает основной/второстепенный/патч. Одно утверждение, затем пакетное исполнение.
Активируется по ключевым словам «릴리스», «버전 업», «release», «main 머지», «배포 준비».
Для использования только в репозитории peach-harness.
