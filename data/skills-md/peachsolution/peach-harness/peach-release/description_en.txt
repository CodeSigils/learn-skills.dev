A release skill that handles everything from peach-harness version update → CHANGELOG.md auto-generation → develop commit/push → main PR creation → PR merge → GitHub Release creation.
After analyzing the changes, the user manually chooses major/minor/patch. One approval, then batch execution.
Triggered by keywords "릴리스", "버전 업", "release", "main 머지", "배포 준비".
For use only in the peach-harness repository.
