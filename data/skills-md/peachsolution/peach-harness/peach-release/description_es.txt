Una habilidad de lanzamiento que automatiza todo el flujo desde la actualización de la versión Peach-harness → generar automáticamente CHANGELOG.md → confirmar/empujar para desarrollar → crear PR en principal → fusionar PR → crear GitHub Release.
Después de analizar los cambios, el usuario selecciona manualmente mayor/menor/parche. Una aprobación desencadena la ejecución completa.
Activado por palabras clave: "lanzamiento", "versión actualizada", "lanzamiento", "fusionar con principal", "implementación lista".
Usado solo en el repositorio de Peach-Arnés.
