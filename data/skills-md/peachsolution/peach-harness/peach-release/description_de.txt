Eine Release-Fähigkeit, die alles abwickelt, von der Aktualisierung der Peach-Harness-Version → der automatischen Generierung von CHANGELOG.md → Commit/Push entwickeln → Haupt-PR-Erstellung → PR-Merge → GitHub-Release-Erstellung.
Nach der Analyse der Änderungen wählt der Benutzer manuell Major/Minor/Patch aus. Eine Genehmigung, dann eine Batch-Ausführung.
Ausgelöst durch Schlüsselwörter „릴리스“, „버전 업“, „release“, „main 머지“, „배포 준비“.
Nur zur Verwendung im Peach-Harness-Repository.
