Навык, который преобразует неявные знания о существующих функциях в спецификации для создания контекстного пакета «как есть» (папка документов по темам). Запускается по ключевым словам «документация функций», «анализ существующих функций», «организация как есть» и «создание документации/описаний для конкретных функций». Используйте peach-gen-spec, когда необходима новая спецификация функции.
