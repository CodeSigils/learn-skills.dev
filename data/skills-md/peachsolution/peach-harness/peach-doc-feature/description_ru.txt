Навык, который преобразует неявные знания о существующих функциях в спецификации для создания контекстного пакета «как есть» (папка документов по темам). Запускается по ключевым словам «документация функций», «анализ существующих функций», «организация как есть» и «создание документации/описаний для конкретных функций». Если необходима новая спецификация функции, используйте peach-gen-spec.
