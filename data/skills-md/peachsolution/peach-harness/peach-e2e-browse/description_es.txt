Una habilidad para conectarse a Chrome Beta CDP a través de la CLI del navegador agente para navegación de páginas, inspección de datos y manipulación de elementos. Activado por palabras clave como "verificar navegador", "mostrar página", "verificar DOM", "inspeccionar datos", "hacer clic para mí", "ver pantalla". También se utiliza para verificar selectores o depurar errores de ejecución durante la creación de escenarios E2E.
