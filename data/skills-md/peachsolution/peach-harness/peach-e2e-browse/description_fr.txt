Une compétence permettant de se connecter à Chrome Beta CDP via la CLI du navigateur agent pour la navigation dans les pages, l'inspection des données et la manipulation des éléments. Déclenché par les mots-clés « vérifier le navigateur », « regarder la page », « vérifier le DOM », « inspecter les données », « cliquer pour moi », « vérifier l'écran ». Également utilisé pour vérifier les sélecteurs ou déboguer les échecs d'exécution lors de l'écriture de scénarios E2E.
