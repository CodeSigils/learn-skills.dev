Навык подключения к Chrome Beta CDP через интерфейс командной строки агента-браузера и выполнения навигации по страницам, проверки данных и манипулирования элементами.
Запускается по ключевым словам: «проверить браузер», «просмотреть страницу», «проверить DOM», «проверить данные», «нажмите для меня», «проверить экран».
Также используется для проверки селектора или отладки ошибок выполнения при написании сценариев E2E.
