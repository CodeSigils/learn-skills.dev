Командный навык, который проектирует, реализует и проверяет одну функцию с помощью цикла из трех агентов (Архитектор → Строитель → Рецензент).
Активируется по ключевым словам: «сделай это с 3а», «3-агент», «проектирование-внедрение-обзор», «команда-3а».
Подходит для более легких одиночных функций и небольших модификаций по сравнению с персиковой командой.
