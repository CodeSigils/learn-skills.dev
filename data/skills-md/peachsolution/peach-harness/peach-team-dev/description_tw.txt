PeachSolution 的綜合團隊技能，用於協調新模組的全端開發。  
支援基於spec和ui-proto的標準模式、僅spec模式和自然語言提示模式。  
由關鍵字觸發：「與團隊一起建置」、「全端開發」、「團隊開發」、「生成後端+整個UI」、
“修復此錯誤”，“將 X 添加到此畫面”，“一起創建 API 和螢幕”，
「僅建置後端」、「僅建置 API」、「僅新增 UI」。  
接受模式=後端(API+Store) | ui（僅 UI）|全端（整個），
即使沒有模式/原型，也可以僅使用自然語言執行臨時錯誤修復和功能添加。  
一種吸收並整合桃子團隊的技能，可以處理從新功能到自發性變化的所有事情。
