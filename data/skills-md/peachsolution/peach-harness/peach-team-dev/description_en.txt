Unified team skill for coordinating full-stack development of PeachSolution's new modules.
Supports standard mode based on Spec and ui-proto + Spec-only mode + natural language prompt mode.
Triggered by keywords: "create as a team", "full-stack development", "team development", "generate backend+UI entirely",
"fix the bug", "add X to this screen", "create API and screen together",
"create backend only", "create API only", "add UI only".
Supports mode=backend(API+Store) | ui(UI only) | fullstack(entire),
and enables impromptu bug fixes and feature additions through natural language input alone without mode/proto.
A skill that has absorbed and integrated peach-team, handling everything from new features to impromptu changes.
