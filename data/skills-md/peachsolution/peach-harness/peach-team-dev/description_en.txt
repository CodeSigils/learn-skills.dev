PeachSolution's integrated team skill for coordinating full-stack development of new modules.  
Supports standard mode based on spec and ui-proto, spec-only mode, and natural-language prompt mode.  
Triggered by keywords: "build with team", "full-stack development", "team development", "generate backend + entire UI",  
"fix this bug", "add X to this screen", "create API and screen together",  
"build only backend", "build only API", "add only UI".  
Accepts mode=backend(API+Store) | ui(UI only) | fullstack(entire),  
and can perform ad-hoc bug fixes and feature additions with natural language alone, even without mode/proto.  
A skill that absorbs and integrates peach-team, handling everything from new features to spontaneous changes.
