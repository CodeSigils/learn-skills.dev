Интегрированные командные навыки PeachSolution для координации комплексной разработки новых модулей.  
Поддерживает стандартный режим на основе спецификации и пользовательского интерфейса, режим только спецификации и режим подсказок на естественном языке.  
Активируется ключевыми словами: «создать с командой», «полноценная разработка», «командная разработка», «создать серверную часть + весь пользовательский интерфейс»,  
«исправить эту ошибку», «добавить X на этот экран», «создать API и экран вместе»,  
«создать только серверную часть», «создать только API», «добавить только пользовательский интерфейс».  
Принимает режим = бэкэнд (API + Store) | пользовательский интерфейс (только пользовательский интерфейс) | полный стек (весь),  
и может исправлять специальные ошибки и добавлять функции только с помощью естественного языка, даже без режима/прото.  
Навык, который поглощает и интегрирует персиковую команду, обрабатывая все: от новых функций до спонтанных изменений.
