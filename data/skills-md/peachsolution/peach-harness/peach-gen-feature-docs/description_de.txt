Eine Fähigkeit, die das implizite Wissen über vorhandene Funktionen in Spezifikationen umwandelt, um ein aktuelles Kontextpaket (themenbasierter Dokumentordner) zu erstellen.
Ausgelöst durch Schlüsselwörter: „Feature-Dokumentation“, „vorhandene Feature-Analyse“, „Ist-Organisation“, „Dokumente/Feature-spezifische Beschreibungen“.
Verwenden Sie „peach-gen-spec“, wenn eine neue Funktionsspezifikation benötigt wird.
