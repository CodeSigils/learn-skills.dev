A gate skill that receives and categorizes PeachSolution development requests or PRDs before implementation, determining the necessary next skill path. Triggered by the keywords "Which skill to start with", "Request analysis", "PRD analysis", "Determine development path", "Determine if spec/DB/proto is needed", "Determine task scope", and "intake". It does not perform code implementation, migration creation, ui-proto generation, or E2E execution; instead, it decides which flow to take among peach-gen-spec, peach-gen-db, peach-team-ui-proto, peach-team-dev, and peach-team-e2e.
