A gate skill that receives and categorizes PeachSolution development requests or PRDs before implementation, determining the necessary next skill path. Triggered by the keywords "Which skill to start with", "Request analysis", "PRD analysis", "Development path determination", "Spec/DB/proto necessity check", "Work scope assessment", "intake". It does not perform code implementation, migration generation, ui-proto creation, or E2E execution; instead, it decides which flow to follow among peach-gen-spec, peach-gen-db, peach-team-ui-proto, peach-team-dev, and peach-team-e2e.
