Compétence pour créer un prototype d'interface utilisateur à partir de données fictives sans backend. Vue 3 + TypeScript + NuxtUI v4.
Déclenché par des mots-clés tels que « fais-moi un prototype », « écran simulé », « proto-interface utilisateur », « écran de planification rapide ».
Génère rapidement des écrans prêts à être révisés pour les planificateurs/concepteurs sans véritable intégration API.
Utilisez Peach-gen-ui lorsqu'une véritable intégration API est requise.
