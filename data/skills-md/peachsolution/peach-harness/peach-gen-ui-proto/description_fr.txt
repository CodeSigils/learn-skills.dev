Une compétence pour créer des prototypes d'interface utilisateur avec des données fictives sans backend. Vue 3 + TypeScript + NuxtUI v4.
Déclenché par des mots-clés tels que « créer un prototype », « écran fictif », « interface utilisateur proto », « écran de planification rapide ».
Génère rapidement des écrans prêts à être révisés pour les planificateurs/concepteurs sans véritable intégration API.
Si une véritable intégration API est nécessaire, utilisez Peach-gen-ui.
