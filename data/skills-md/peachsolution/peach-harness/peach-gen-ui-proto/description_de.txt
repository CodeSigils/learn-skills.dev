Eine Fähigkeit zum Generieren einer Prototyp-Benutzeroberfläche aus Scheindaten ohne Backend. Vue 3 + TypeScript + NuxtUI v4.
Ausgelöst durch Schlüsselwörter wie „Prototyp erstellen“, „Mock-Bildschirm“, „Proto-UI“, „Schnellplanungsbildschirm“.
Erstellt schnell Bildschirme zur Überprüfung durch Planer und Designer ohne echte API-Integration.
Verwenden Sie „peach-gen-ui“, wenn eine tatsächliche API-Integration erforderlich ist.
