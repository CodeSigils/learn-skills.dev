Fähigkeit zum Erstellen einer Prototyp-Benutzeroberfläche aus Scheindaten ohne Backend. Vue 3 + TypeScript + NuxtUI v4.
Ausgelöst durch Schlüsselwörter wie „Mach mir einen Prototyp“, „Mock-Screen“, „Proto-UI“, „Schnellplanungs-Screen“.
Generiert schnell überprüfungsbereite Bildschirme für Planer/Designer ohne echte API-Integration.
Verwenden Sie Peach-Gen-UI, wenn eine echte API-Integration erforderlich ist.
