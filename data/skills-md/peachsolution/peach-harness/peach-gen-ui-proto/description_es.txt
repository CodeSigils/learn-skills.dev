Habilidad para construir un prototipo de interfaz de usuario a partir de datos simulados sin backend. Vue 3 + TypeScript + NuxtUI v4.
Activado por palabras clave como "hazme un prototipo", "pantalla simulada", "proto UI", "pantalla de planificación rápida".
Genera rápidamente pantallas listas para revisión para planificadores/diseñadores sin una integración API real.
Utilice Peach-gen-ui cuando se requiera una integración API real.
