La capacità di creare un prototipo di interfaccia utente da dati fittizi senza backend. Vue 3 + TypeScript + NuxtUI v4.
Attivato da parole chiave come "creami un prototipo", "schermata simulata", "interfaccia utente prototipo", "schermata di pianificazione rapida".
Produce rapidamente schermate pronte per la revisione per pianificatori e progettisti senza una reale integrazione API.
Utilizza fishing-gen-ui quando è richiesta l'effettiva integrazione API.
