Навык создания прототипа пользовательского интерфейса с макетными данными и без серверной части. Vue 3 + TypeScript + NuxtUI v4.
Запускается по таким ключевым словам, как «сделай мне прототип», «макет экрана», «прототип пользовательского интерфейса», «экран быстрого планирования».
Быстро создает готовые к просмотру экраны для планировщиков/дизайнеров без реальной интеграции API.
Используйте peach-gen-ui, когда требуется реальная интеграция API.
