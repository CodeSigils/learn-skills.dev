Эксперт по системе крепления ремня безопасности. Активируется по ключевым словам «какой навык», «как», «помощь», «руководство», «с чего начать». Доступный только для чтения навык адаптации, который предоставляет рекомендации по навыкам, руководство по рабочему процессу и объяснения концепций системы. (Включает глобальные инструкции по установке дляkills.sh)
