Une compétence pour interroger des données en exécutant SQL directement sur la base de données de développement.
Déclenché par des mots-clés : "DB check", "data query", "table query", "SQL exécution", "data vérifie".
Utilisé lorsque l'agent IA doit vérifier instantanément les données de la base de données de développement pendant le développement backend/frontend.
