Навык непосредственного выполнения SQL в базе данных разработки для запроса данных.
Запускается по ключевым словам: «проверить БД», «запросить данные», «просмотреть таблицу», «запустить SQL», «проверить данные».
Используется агентом ИИ для мгновенной проверки данных базы данных разработки во время внутренней/внешней разработки.
