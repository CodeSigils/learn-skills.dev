Eine Fähigkeit zum Abfragen von Daten durch direktes Ausführen von SQL in der Entwicklungsdatenbank.
Ausgelöst durch Schlüsselwörter: „DB-Prüfung“, „Datenabfrage“, „Tabellenabfrage“, „SQL-Ausführung“, „Datenüberprüfung“.
Wird verwendet, wenn KI-Agenten die Daten der Entwicklungsdatenbank während der Backend-/Frontend-Entwicklung sofort überprüfen müssen.
