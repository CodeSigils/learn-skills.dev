Kenntnisse in der DB-Schema-Extraktion. Extrahiert den aktuellen Status der Datenbank als tabellenspezifische DDL-Dateien in den Ordner schema/.
Ausgelöst durch die Schlüsselwörter „Schema Extraction“, „Schema Update“, „Extract-Schema“, „DB Schema Synchronisation“, „Schema File Refresh“, „DB Structure Check“, „DDL Extraction“, „Schema Sync“.
Nutzen Sie diese Fähigkeit, wenn Sie den Verdacht haben, dass die Schemadateien und der tatsächliche DB-Status unterschiedlich sein könnten.
