Навыки извлечения схем БД. Извлекает текущее состояние базы данных в виде файлов DDL для конкретных таблиц и сохраняет их в папке схемы/.
Запускается по ключевым словам: «извлечение схемы», «обновление схемы», «extract-schema», «синхронизация схемы БД», «обновление файла схемы», «проверка структуры БД», «извлечение DDL», «обновление схемы».
Используйте этот навык, если файлы схемы и фактическое состояние БД могут отличаться.
