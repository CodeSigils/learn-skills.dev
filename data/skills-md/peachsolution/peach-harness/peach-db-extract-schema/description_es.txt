Habilidad de extracción de esquemas de base de datos. Extrae el estado actual de la base de datos como archivos DDL específicos de la tabla y los guarda en la carpeta esquema/.
Activado por las palabras clave "extracción de esquema", "actualización de esquema", "extraer esquema", "sincronización de esquema de base de datos", "actualización de archivo de esquema", "verificación de estructura de base de datos", "extracción de DDL", "actualización de esquema".
Utilice esta habilidad cuando sospeche que los archivos de esquema difieren del estado real de la base de datos.
