Эксперт по созданию страниц, предназначенных только для печати. Запускается по ключевым словам «создать страницу для печати», «создать страницу для печати», «выходная страница». Создает элегантный компонент Vue и настройку маршрута, которая выводит контент без макета, оптимизированный для печати. Ссылается на последнюю документацию TailwindCSS v4/Vue через Context7 MCP, анализирует дизайн печати с помощью последовательного мышления.
