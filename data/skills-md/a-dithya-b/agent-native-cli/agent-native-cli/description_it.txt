Progetta e migliora la CLI, gli script, i target Make e le interfacce degli strumenti per gli agenti di codifica AI. Da utilizzare quando un repository espone flussi di lavoro di shell ripetitivi, output di comandi rumorosi, operazioni multi-fase fragili o strumenti che potrebbero essere resi più deterministici, rilevabili, strutturati ed efficienti in termini di token.
