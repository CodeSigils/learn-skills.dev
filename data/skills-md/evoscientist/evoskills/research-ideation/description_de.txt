Leitet die Forschungsidee durch einen zielorientierten 5-Schritte-Workflow: Definieren Sie ein langfristiges Ziel, erstellen Sie einen Literaturbaum (Neuheit + Einblick in die Herausforderung), wählen Sie ein Problem aus (überprüfen Sie eine etablierte Lösung), entwerfen Sie eine Lösung (domänenübergreifende Übertragung + Zerlegung), validieren und iterieren. Behandelt auch strukturiertes Papierlesen (3 Tiefenstufen). Verwenden Sie diese Option, wenn der Benutzer eine Forschungsrichtung finden, Ideen sammeln, eine Sicht auf das Feld entwickeln, eine Literaturrecherche durchführen, die Neuheit von Ideen bewerten oder Artikel systematisch lesen möchte. NICHT zum Vergleichen/Rangfolgen vorhandener Ideen (Ideenturnier verwenden) oder zum Planen einer Arbeit (Papierplanung verwenden) verwenden.
