Utilice esta habilidad para producir gráficos PNG independientes y listos para publicar y scripts matplotlib reproducibles a partir de datos tabulares (CSV o DataFrames). Esta herramienta está diseñada específicamente para representar datos numéricos en visualizaciones científicas formales, incluidos gráficos de dispersión, líneas, barras, circulares, anillos, burbujas, tornados, KDE, violín, cajas, mapas de calor, histogramas y áreas, además de figuras compuestas de paneles múltiples que combinan estos tipos en una sola imagen, para manuscritos académicos. Active esta habilidad solo cuando el resultado final sea un archivo de imagen individual. No utilice esta habilidad para paneles interactivos o resultados renderizados en HTML (cuadernos Plotly, Streamlit, Quarto, Jupyter), ni cuando la solicitud implique la creación de un documento contenedor o una presentación que incluya gráficos (presentación de diapositivas, póster de conferencia). Finalmente, no es para ilustraciones conceptuales que no contengan datos, como diagramas de flujo, esquemas de algoritmos o diagramas de procesos. Esta habilidad se centra en la representación de datos de alta fidelidad en archivos de imagen finales, no en el diseño de presentaciones, el diseño de documentos o el código de ingeniería inversa a partir de capturas de pantalla existentes.
