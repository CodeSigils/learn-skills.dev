Refinamiento iterativo del código a través de ciclos de plan → código → evaluación → refinamiento. Ejecuta comprobaciones de pelusa (ruff), pruebas (pytest) y autoevaluaciones estructuradas en cada ciclo, luego diagnostica fallas y refina. Descompone tareas complejas en fases secuenciales, itera hasta 3 veces por fase (10 en total). Úselo cuando: el agente principal delega una tarea de código con 'MODO: MÁS_ESFUERZO', el usuario selecciona el modo de generación de código 'Más esfuerzo' o la tarea solicita explícitamente un refinamiento iterativo para una mayor calidad del código. NO lo use para la generación de código de un solo paso (modo Lite), la orquestación de canalizaciones de experimentos (use experiment-pipeline) o el diagnóstico de una falla de experimento específica (use experiment-craft).
