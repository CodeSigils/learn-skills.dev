Итеративное уточнение кода посредством циклов «план → код → оценка → уточнение». Каждый цикл запускает проверку на ворс (ruff), тесты (pytest) и структурированную самооценку, затем диагностирует сбои и совершенствует. Разбивает сложные задачи на последовательные фазы, повторяет до 3 раз на фазу (всего 10). Используйте, когда: основной агент делегирует задачу кода с «MODE: MORE_EFFORT», пользователь выбирает режим генерации кода «Больше усилий» или задача явно запрашивает итеративное уточнение для повышения качества кода. НЕ используйте для однопроходной генерации кода (упрощенный режим), оркестровки конвейера эксперимента (используйте Experiment-pipeline) или диагностики конкретного сбоя эксперимента (используйте Experiment-craft).
