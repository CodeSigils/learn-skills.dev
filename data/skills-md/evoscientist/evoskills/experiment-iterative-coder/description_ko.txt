계획 → 코드 → 평가 → 구체화 주기를 통해 반복적인 코드 개선이 이루어집니다. 각 주기마다 Lint 검사(ruff), 테스트(pytest) 및 구조화된 자체 평가를 실행한 후 오류를 진단하고 개선합니다. 복잡한 작업을 순차적 단계로 분해하고 단계당 최대 3회(총 10회) 반복합니다. 사용 시기: 주 에이전트가 'MODE: MORE_EFFORT'로 코드 작업을 위임하거나, 사용자가 'More Effort' 코드 생성 모드를 선택하거나, 작업이 더 높은 코드 품질을 위해 반복적 개선을 명시적으로 요청하는 경우. 단일 패스 코드 생성(라이트 모드), 실험 파이프라인 조정(experiment-pipeline 사용) 또는 특정 실험 실패 진단(experiment-craft 사용)에는 사용하지 마십시오.
