Raffinement itératif du code via des cycles plan → code → évaluation → raffinement. Exécute des contrôles de charpie (ruff), des tests (pytest) et une auto-évaluation structurée à chaque cycle, puis diagnostique les échecs et affine. Décompose les tâches complexes en phases séquentielles, itère jusqu'à 3 fois par phase (10 au total). À utiliser lorsque : l'agent principal délègue une tâche de code avec "MODE : MORE_EFFORT", l'utilisateur sélectionne le mode de génération de code "Plus d'effort" ou la tâche demande explicitement un raffinement itératif pour une qualité de code supérieure. Ne PAS utiliser pour la génération de code en un seul passage (mode Lite), l'orchestration de pipeline d'expérience (utilisez Experiment-Pipeline) ou le diagnostic d'un échec d'expérience spécifique (utilisez Experiment-craft).
