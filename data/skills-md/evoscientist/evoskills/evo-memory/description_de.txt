Verwaltet das persistente Forschungsgedächtnis über Ideenfindungs- und Experimentierzyklen hinweg. Verwaltet zwei Speicher: Ideation Memory M_I (machbare/erfolglose Richtungen) und Experimentation Memory M_E (wiederverwendbare Strategien für Datenverarbeitung, Modelltraining, Architektur, Debugging). Drei Evolutionsmechanismen: IDE (nach dem Ideenturnier), IVE (nach dem Scheitern des Experiments – klassifiziert Fehler als Implementierung vs. grundlegend), ESE (nach dem Erfolg des Experiments – extrahiert wiederverwendbare Strategien). Wird verwendet, wenn: Speicher nach Abschluss von Ideenturnieren oder Experimentierpipelines aktualisiert wird, klassifiziert wird, warum eine Methode fehlgeschlagen ist (Implementierung vs. fundamentaler Fehler), Beginn eines neuen Forschungszyklus, der Vorkenntnisse erfordert, Benutzer erwähnt „Speicher aktualisieren“, „Fehler klassifizieren“, „was vorher funktioniert hat“, „Forschungsverlauf“, „Evolution“. NICHT zum Ausführen von Experimenten (verwenden Sie experiment-pipeline), zum Debuggen von Experimentcode (verwenden Sie experiment-craft) oder zum Generieren von Ideen (verwenden Sie idea-turnier) verwenden.
