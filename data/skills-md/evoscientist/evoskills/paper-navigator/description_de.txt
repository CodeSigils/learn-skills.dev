End-to-End-Arbeitsablauf für wissenschaftliche Arbeiten: Klären Sie Abfragen, entdecken Sie Arbeiten (Suche, Zitierdurchlauf, Empfehlungen, arXiv-Überwachung, Trending, GitHub-Suche), bewerten Sie sie (TLDR, Zitate, Code, SOTA), lesen Sie sie mit strukturierter Analyse (3-Ebenen-Strategie) und organisieren Sie sie in Literaturkarten oder Berichten. Verwenden Sie diese Option, wenn Sie Aufsätze finden, einen Aufsatz lesen, verwandte Arbeiten lesen, eine Literaturübersicht erstellen, Zitieranalysen durchführen, Forschungstrends verfolgen, SOTA-Ergebnisse, Datensätze oder Literaturberichte erstellen möchten. NICHT zum Verfassen eines Abschnitts zur Literaturrecherche (verwenden Sie das Schreiben auf Papier), zum Vergleichen von Forschungsideen (verwenden Sie ein Ideenturnier) oder zum Planen der Papierstruktur (verwenden Sie die Papierplanung) verwenden.
