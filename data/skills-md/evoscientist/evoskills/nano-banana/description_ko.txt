대화형 브라우저 기반 검토 및 반복 편집을 통해 Gemini 이미지 생성 API(Nano Banana 2)를 사용하여 전문적인 프레젠테이션 슬라이드와 고품질 일러스트레이션을 생성합니다. 전체 워크플로: 콘텐츠 계획 대화 → Slides_plan.json → 일괄 이미지 생성 → 피드백 검토 → 타겟 슬라이드 편집 → PPTX 패키징. 사용 시기: 사용자가 프리젠테이션 작성, 슬라이드 만들기, PPT/PPTX 생성, 토크 데크 준비, 시각적 슬라이드 콘텐츠 디자인, 종이 및 문서용 고품질 그림/그림 생성을 원할 때. 다음 용도로 사용하지 마십시오: 학술 논문 작성(논문 작성 사용) 또는 학술 회의 대화 내러티브 구조 계획(학술 슬라이드 사용).
