Gemini 画像生成 API (Nano Banana 2) を使用して、インタラクティブなブラウザベースのレビューと反復編集により、プロフェッショナルなプレゼンテーション スライドと高品質のイラストを生成します。完全なワークフロー: コンテンツ計画の会話 → slides_plan.json → バッチ画像生成 → フィードバックによるレビュー → ターゲットを絞ったスライドの編集 → PPTX パッケージ化。次の場合に使用します: ユーザーは、プレゼンテーションの作成、スライドの作成、PPT/PPTX の生成、トークデッキの準備、視覚的なスライド コンテンツのデザイン、または論文や文書用の高品質の図/イラストの生成を希望します。学術論文の執筆 (論文執筆を使用) または学術会議での講演の構成の計画 (学術スライドを使用) には使用しないでください。
