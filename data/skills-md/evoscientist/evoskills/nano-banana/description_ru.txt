Создавайте профессиональные слайды презентаций и высококачественные иллюстрации с помощью API генерации изображений Gemini (Nano Banana 2) с интерактивным просмотром в браузере и итеративным редактированием. Полный рабочий процесс: обсуждение планирования контента → слайды_plan.json → пакетная генерация изображений → обзор с обратной связью → целевое редактирование слайдов → упаковка PPTX. Используйте, когда: пользователь хочет создать презентацию, сделать слайды, создать PPT/PPTX, подготовить дискуссию, разработать визуальный контент слайдов или создать высококачественные рисунки/иллюстрации для статей и документов. НЕ используйте для: написания научных статей (используйте написание статей) или планирования структуры повествования выступления на академической конференции (используйте академические слайды).
