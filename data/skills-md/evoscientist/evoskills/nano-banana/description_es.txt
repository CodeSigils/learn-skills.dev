Genere diapositivas de presentación profesionales e ilustraciones de alta calidad utilizando la API de generación de imágenes Gemini (Nano Banana 2), con revisión interactiva basada en navegador y edición iterativa. Flujo de trabajo completo: conversación de planificación de contenido → slides_plan.json → generación de imágenes por lotes → revisión con comentarios → edición de diapositivas específica → empaquetado PPTX. Úselo cuando: el usuario quiera crear una presentación, hacer diapositivas, generar un PPT/PPTX, preparar una plataforma de conversación, diseñar contenido de diapositivas visuales o generar figuras/ilustraciones de alta calidad para artículos y documentos. NO lo use para: escribir artículos académicos (use escritura en papel) o planificar una estructura narrativa de una conferencia académica (use diapositivas académicas).
