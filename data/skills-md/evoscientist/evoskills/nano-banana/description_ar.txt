قم بإنشاء شرائح عرض تقديمي احترافية ورسوم توضيحية عالية الجودة باستخدام Gemini image Generation API (Nano Banana 2)، مع مراجعة تفاعلية قائمة على المتصفح وتحرير متكرر. سير العمل الكامل: محادثة تخطيط المحتوى ← Slides_plan.json ← إنشاء الصور دفعة واحدة ← المراجعة مع التعليقات ← تحرير الشرائح المستهدفة ← تغليف PPTX. يُستخدم عندما: يريد المستخدم إنشاء عرض تقديمي، أو إنشاء شرائح، أو إنشاء PPT/PPTX، أو إعداد مجموعة نقاش، أو تصميم محتوى شرائح مرئي، أو إنشاء أشكال/رسوم توضيحية عالية الجودة للأوراق والمستندات. لا تستخدم في: كتابة الأوراق الأكاديمية (استخدم الكتابة الورقية) أو التخطيط للهيكل السردي لحديث المؤتمر الأكاديمي (استخدم الشرائح الأكاديمية).
