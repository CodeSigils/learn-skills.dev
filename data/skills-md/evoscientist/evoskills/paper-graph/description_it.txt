Utilizza questa abilità per mappare il **lignaggio genealogico e la progressione storica** di un campo di ricerca. È progettato per visualizzare il **percorso evolutivo delle idee**, mostrando come le sfide tecniche nei lavori precedenti siano state affrontate dai successivi miglioramenti della ricerca. Il risultato finale è un file Markdown con diagrammi Sirena incorporati che l'utente può incollare in un visualizzatore o inserire nel proprio repository. Attivalo quando l'utente ha bisogno di comprendere la **traiettoria di sviluppo di un argomento**, l'"albero genealogico" di un modello o il modo in cui una linea di ricerca è maturata nel corso di più anni. NON attivare query che cercano **inventari di elementi specifici**, come elenchi di set di dati comuni, benchmark o librerie. Evitatelo per trovare un singolo articolo "più recente", eseguire una semplice ricerca per parole chiave o condurre confronti tecnici testa a testa tra modelli specifici. Questa abilità è pensata per sintetizzare una **narrativa cronologica di miglioramento** attraverso più lavori, non per catalogare le risorse attualmente disponibili o recuperare documenti una tantum.
