Utilice esta habilidad para mapear el **linaje genealógico y la progresión histórica** de un campo de investigación. Está diseñado para visualizar el **camino evolutivo de las ideas**, mostrando cómo los desafíos técnicos en trabajos anteriores fueron abordados por mejoras de investigación posteriores. El producto final es un archivo Markdown con diagramas de Mermaid integrados que el usuario puede pegar en un visor o enviar a su repositorio. Active esto cuando el usuario necesite comprender la **trayectoria de desarrollo de un tema**, el "árbol genealógico" de un modelo o cómo maduró una línea de investigación a lo largo de varios años. NO active consultas que busquen **inventarios de artefactos específicos**, como listas de conjuntos de datos, puntos de referencia o bibliotecas comunes. Evite esto para encontrar un único artículo "más reciente", realizar una búsqueda simple de palabras clave o realizar comparaciones técnicas directas entre modelos específicos. Esta habilidad está destinada a sintetizar una **narrativa cronológica de mejora** a través de múltiples trabajos, no a catalogar los recursos actualmente disponibles o la recuperación de artículos únicos.
