Einmalige Einrichtung pro Repo für die Deslop-Pipeline, normalerweise aufgerufen von /deslop als Schritt 0 (wird übersprungen, wenn STACK.md bereits vorhanden ist). Befragt den Benutzer zu seinem Stack (Authentifizierung, Zahlungen, Backend-Stil, Datenbank, Geheimnisse, Operationen); Zuerst herausfinden, was aus dem Repo möglich ist; und generiert ein STACK.md-Haus-Overlay, das von den Audit-Fähigkeiten gelesen wird. Wird automatisch von /deslop bei der ersten Verwendung in einem Repo ausgelöst; Wird direkt aufgerufen, wenn sich der Stack des Benutzers geändert hat (Authentifizierungsanbieter, Zahlungsprozessor, Framework, Datenbank gewechselt) und STACK.md neu generiert werden muss.
