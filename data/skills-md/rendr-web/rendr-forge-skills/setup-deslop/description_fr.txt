Configuration unique par dépôt pour le pipeline deslop, normalement invoquée par /deslop à l'étape 0 (ignorée si STACK.md existe déjà). Interroge l'utilisateur sur sa pile (authentification, paiements, style backend, base de données, secrets, opérations) ; détecter d'abord ce qu'il peut à partir du dépôt ; et génère une superposition maison STACK.md que les compétences d'audit lisent. Déclenché automatiquement par /deslop lors de la première utilisation dans un dépôt ; invoquez directement lorsque la pile de l'utilisateur a changé (fournisseur d'authentification commuté, processeur de paiement, framework, base de données) et que STACK.md doit être régénéré.
