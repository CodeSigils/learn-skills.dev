Одноразовая настройка для каждого репозитория для конвейера deslop, обычно вызываемая /deslop на шаге 0 (пропускается, если STACK.md уже существует). Опрашивает пользователя об его стеке (аутентификация, платежи, стиль бэкэнда, база данных, секреты, операции); сначала обнаружить, что он может получить из репо; и генерирует наложение дома STACK.md, которое считывают навыки аудита. Запускается автоматически командой /deslop при первом использовании в репозитории; вызывать напрямую, когда стек пользователя изменился (переключился поставщик аутентификации, платежный процессор, платформа, база данных) и STACK.md требует регенерации.
