Bucle de auditoría disciplinado de seguridad y bloqueo de barcos para una aplicación heredada o con código de vibración. Recorre la superficie de ataque priorizando el dinero y la identidad, demuestra cada agujero con una prueba de explotación que se puede volver a ejecutar antes de contar, corregir y volver a verificar. Úselo cuando el usuario quiera encontrar y cerrar problemas de seguridad que bloquean el lanzamiento (brechas de autenticación, aislamiento multiinquilino roto, secretos expuestos, puntos finales desprotegidos, autorización faltante, puntos finales con costos descontrolados) o pregunta "¿es seguro enviar/lanzar/poner esto frente a los clientes?". Ejecute después de setup-deslop y map-the-surface, antes de la puerta de lanzamiento. Este es el núcleo del proceso de deslop.
