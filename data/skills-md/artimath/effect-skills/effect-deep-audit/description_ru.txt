Глубокий аудит кодовой базы Effect-TS на предмет соответствия реальным шаблонам основной команды Effect. Создает многоуровневый список поиска + исполняемый план DAG, а затем систематически переписывает неидиоматический код. ИСПОЛЬЗУЙТЕ ЭТОТ НАВЫК КОГДА: «проверка кода этого эффекта», «это идиоматический эффект», «глубокий аудит», запуск нового проекта Effect и желание проверить шаблоны, рефакторинг кодовой базы Effect для обеспечения качества библиотечного уровня, проверка кода перед его отправкой в ​​производство. НЕ ДЛЯ: проектов Greenfield Effect (используйте навыки работы с эффектами).
