Tiefgehende Prüfung einer Effect-TS-Codebasis im Vergleich zu tatsächlichen Mustern des Effect-Kernteams. Erstellt eine abgestufte Ergebnisliste + einen ausführbaren DAG-Plan und schreibt dann nicht-idiomatischen Code systematisch neu. VERWENDEN SIE DIESE FÄHIGKEIT, WENN: „Diesen Effektcode prüfen“, „Ist dieser idiomatische Effekt“, „Tiefenprüfung“, ein neues Effect-Projekt starten und Muster überprüfen möchten, eine Effect-Codebasis auf Bibliotheksqualität umgestalten, Code überprüfen, bevor er in die Produktion geht. NICHT FÜR: Greenfield-Effektprojekte (Effektfähigkeit verwenden).
