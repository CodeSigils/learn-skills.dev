Implementar, iniciar, inspeccionar y solucionar problemas de una terminal de futuros china local basada en TqSdk + TQSim. Adecuado para usuarios que desean instalar una interfaz de usuario de visualización de futuros chinos en OpenClaw, iniciar puertas de enlace de simulación/mercado local, verificar el estado de salud, abrir un navegador para ver la interfaz de futuros o solucionar fallas de inicio del terminal.
