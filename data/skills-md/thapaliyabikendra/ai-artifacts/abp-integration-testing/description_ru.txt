Создавайте интеграционные тесты для служб приложений ASP.NET Core ABP Framework и API HTTP. Используйте, когда пользователь запрашивает интеграционные тесты, сквозные тесты, тесты API или хочет проверить точки интеграции инфраструктуры ABP (репозитории, авторизация, проверка, мультитенантность, единицы работы, фильтры данных). Запускайте, даже если пользователь просто говорит «добавить тесты» для ApplicationService — спросите, нужны ли им модульные или интеграционные тесты.
