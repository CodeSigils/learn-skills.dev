Générez des tests d'intégration pour les services d'application ASP.NET Core ABP Framework et les API HTTP. À utiliser lorsque l'utilisateur demande des tests d'intégration, des tests de bout en bout, des tests d'API ou souhaite vérifier les points d'intégration du framework ABP (dépôts, autorisation, validation, multilocation, unité de travail, filtres de données). Déclenchez même si l'utilisateur dit simplement "ajouter des tests" pour un ApplicationService - demandez-lui s'il souhaite des tests unitaires ou d'intégration.
