Genere pruebas de integración para los servicios de aplicaciones ASP.NET Core ABP Framework y las API HTTP. Úselo cuando el usuario solicite pruebas de integración, pruebas de extremo a extremo, pruebas de API o quiera verificar los puntos de integración del marco ABP (repositorios, autorización, validación, multiinquilino, unidad de trabajo, filtros de datos). Dispare incluso si el usuario simplemente dice "agregar pruebas" para un servicio de aplicación; pregunte si quiere pruebas unitarias o de integración.
