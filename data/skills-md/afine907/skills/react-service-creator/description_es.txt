[React Scaffold] Genere un andamio de proyecto React que admita Next.js/Vite/CRA, incluido el enrutamiento, la gestión del estado, la capa API, los estándares de componentes y la configuración de pruebas.

Condiciones de activación:
- El usuario solicita "Crear proyecto React", "React scaffold"
- Un nuevo proyecto front-end requiere una plantilla estandarizada
- Necesidad de unificar la estructura del proyecto React del equipo.

Genere un esqueleto de proyecto completo y ejecutable.
