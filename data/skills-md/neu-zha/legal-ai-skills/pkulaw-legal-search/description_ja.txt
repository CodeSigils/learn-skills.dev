ユーザーが作成した Peking University Law Treasure (pkulaw.com) Web ページ/コンピューター使用の検索エントリとフォールバック プロセス。 MCP の結果が不十分な場合、Web ページの詳細へのログインが必要な場合、URL のコピー/検証が必要な場合、IP/機関のログイン ステータスが必要な場合、または北京大学法宝 Web ページを人間のように操作する必要がある場合に使用されます。現在、このマシンには 3 つの北京大学法宝 MCP も構成されています。法令検索 – キーワード、記事の正確な検索 – キーワード、判例検索 – キーワード。 MCP が使用できる場合は、最初に MCP を使用し、Web ページ/コンピューターの使用で補助的な検索と検証を処理します。このスキルをネイティブ MCP スキルで置き換えられる重複として扱わないでください。
