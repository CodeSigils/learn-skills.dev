ユーザーが構築した Peking University Law Treasure (pkulaw.com) Web ページ/コンピューターを使用した検索エントリとフォールバック プロセス。 MCP の結果が不十分な場合、Web ページの詳細にログインする必要がある場合、URL をコピー/検証する必要がある場合、IP/機関のログイン ステータスを確認する必要がある場合、または人間のように北京大学法宝 Web サイトを操作する必要がある場合に使用されます。現在、このマシンには 3 つの北京大学法宝 MCP も設定されています。法令検索キーワード、正確な条文検索キーワード、判例検索キーワードです。可能な限り最初に MCP を使用し、Web ページ/コンピューターの使用で補足的な検索と検証を処理します。このスキルをネイティブ MCP スキルで置き換えられる重複として扱わないでください。
