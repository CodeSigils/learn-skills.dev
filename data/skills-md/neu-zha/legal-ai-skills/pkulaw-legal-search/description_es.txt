La base de datos jurídica de la Universidad de Pekín (pkulaw.com), creada por el usuario, utiliza un proceso web/computador de entrada de búsqueda y de reserva. Se utiliza cuando los resultados de MCP son insuficientes, cuando se requiere iniciar sesión en una página web detallada, cuando se necesita copiar/verificar una URL, cuando se requiere el estado de inicio de sesión de IP/institución o cuando se opera la página web de la base de datos de derecho de la Universidad de Pekín como un humano. Esta máquina tiene actualmente configurados tres MCP de la base de datos de derecho de la Universidad de Pekín: búsqueda de estatutos y reglamentos – palabra clave, búsqueda precisa de artículos – palabra clave, búsqueda de casos judiciales – palabra clave; use MCP primero cuando sea posible, y el uso web/computador maneja la búsqueda y verificación suplementarias. No trate esta habilidad como un duplicado que pueda ser reemplazado por la habilidad MCP nativa.
