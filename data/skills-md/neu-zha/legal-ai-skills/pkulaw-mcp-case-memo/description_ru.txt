Отчет о поиске сходства дел и рабочий процесс заметок по обработке дел, используемый для сжатия результатов поиска дел в тексты заметок, которые можно обсуждать, совместно использовать и проверять, включая образцы дел, проверку номера дела и улучшение ссылок. Используйте, когда: юристам, группам по разрешению споров или группам по расследованию соответствия необходимо быстро подготовить стандартный результат, состоящий из «ключевых моментов сходства дел + проверяемых подсказок + памятки о версии поставки». НЕ для: сценариев, где нужен только исходный текст одного случая, составляется только список случаев или не требуется сравнительный анализ. Требование: ключевая информация должна быть связана с текущим ответом MCP, избегая необоснованных выводов о судебных тенденциях.
