Beida Fabao의 기본 MCP 규정/정확한 기사 검색 기술입니다. 현재 이 머신은 'law-keyword'(법령 및 규정 검색 – 키워드)와 'fatiao'(정확한 기사 조회 – 키워드)로 구성되어 있으며, 'law-semantic' 또는 'law-recognition'과 같은 이전 MCP를 사용할 수 있다고 가정해서는 안 됩니다.  

**사용할 경우:** 사용자가 명시적으로 법령, 규범 문서, 사법 해석, 지원 조항을 찾고 싶거나 법적 문제와 관련된 관련 입법 자료를 먼저 찾고자 하는 경우 법령명과 조문번호를 알고 있는 경우에는 정확한 조문 검색을 우선시합니다.  

**해당 사항:** 사례 검색, 사례 번호 식별, 웹 로그인, 웹 세부 정보 페이지 클릭, 웹 URL 복사, 웹 대체는 사용자 자신의 `pkulaw-legal-search`로 라우팅되어야 합니다.  

Fabao MCP를 구성하고 구독해야 합니다. 검색 근거 없이 법령명, 문서 번호, 항목 번호, 유효성 상태를 조작하는 것은 금지됩니다.
