Introduzca una afirmación de sabor que ningún comando puede probar, como "este diseño de API es bueno" o "esta interfaz de usuario no es descuidada", al juzgar el trabajo según criterios verificables. Úselo cuando verificar cumple con un reclamo que sus comandos no pueden resolver, cuando un diseño o artefacto necesita una llamada de calidad antes de enviarse, o cuando el usuario pregunta si algo es bueno.
