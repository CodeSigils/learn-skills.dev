استخدم هذه المهارة جنبًا إلى جنب مع مهارة التنفيذ أو المراجعة أو سير العمل الأساسية عندما يريد المستخدم مراجعة التعليمات البرمجية أو مسح الريبو أو إمكانية الصيانة أو تعليقات البنية أو تخطيط التنفيذ أو تنظيف الوثائق أو المقارنات القابلة للقراءة أو إجابة منظمة أكثر وضوحًا. قم بتطبيقه عند وجوب فرض قواعد التنسيق والمحاذاة وبنية الاستجابة المشتركة عبر التعليمات البرمجية أو المستندات التي تم لمسها. لا تستخدمه كمالك أساسي للغة أو إطار العمل أو وقت التشغيل أو قرارات سير العمل.
