インタラクティブな HTML スキル アーティファクトのセッションごとのローカル レシーバーと「Monitor」を設定して、ユーザーの送信がコピーアンドペーストのラウンドトリップではなくセッション通知として届くようにします。他の html スキル インタラクティブ スキル (html-mind-map、html-throwaway-editor、html-brainstorm-grid、html-comparison-matrix、html-interactive-playground、html-design-prototypes) は、HTML アーティファクトを記述する前に、プリフライト ブロックからこのスキルを呼び出します。べき等 — いつでも安全に呼び出すことができます。親スキルがアーティファクトに「window.__CLAUDE_SUBMIT_URL__」として挿入したローカルホスト URL を返します。無関係な会話ではプロンプトなしで呼び出さないでください。これは、インタラクティブな HTML スキル アーティファクトが生成されようとしているときにのみ起動されます。
