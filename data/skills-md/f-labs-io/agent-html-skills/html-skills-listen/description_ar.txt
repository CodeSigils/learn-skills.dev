يقوم بإعداد جهاز الاستقبال المحلي و"المراقب" لكل جلسة لعناصر مهارات html التفاعلية بحيث تصل عمليات إرسال المستخدم كإشعارات للجلسة بدلاً من رحلات ذهابًا وإيابًا للنسخ واللصق. مهارات تفاعلية أخرى لمهارات html (خريطة html-mind، محرر html-throwaway، html-brainstorm-grid، html-comparison-matrix، html-interactive-playground، html-design-prototypes) تستدعي هذه المهارة من كتلة ما قبل الرحلة، قبل كتابة قطعة HTML. Idempotent — آمن للاستدعاء في كل مرة. تُرجع عنوان URL للمضيف المحلي الذي تُدخله المهارة الأصلية كـ "window.__CLAUDE_SUBMIT_URL__" في القطعة الأثرية. لا تستدعي عفويًا في محادثات غير ذات صلة — يتم تفعيل هذا فقط عندما تكون أداة مهارات html التفاعلية على وشك الإنتاج.
