Configure le récepteur local par session et le « Moniteur » pour les artefacts interactifs de compétences HTML afin que les soumissions des utilisateurs arrivent sous forme de notifications de session plutôt que sous forme d'allers-retours copier-coller. D'autres compétences interactives de compétences HTML (html-mind-map, html-throwaway-editor, html-brainstorm-grid, html-comparison-matrix, html-interactive-playground, html-design-prototypes) invoquent cette compétence à partir de leur bloc de pré-vol, AVANT d'écrire l'artefact HTML. Idempotent – ​​peut être invoqué en toute sécurité à chaque fois. Renvoie une URL d'hôte local que la compétence parent injecte sous la forme « window.__CLAUDE_SUBMIT_URL__ » dans l'artefact. N'invoquez pas spontanément dans des conversations sans rapport : cela ne se déclenche que lorsqu'un artefact interactif de compétences HTML est sur le point d'être produit.
