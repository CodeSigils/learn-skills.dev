Configura el receptor local por sesión y el `Monitor` para artefactos interactivos de habilidades html para que los envíos de los usuarios lleguen como notificaciones de sesión en lugar de copiar y pegar ida y vuelta. Otras habilidades interactivas de habilidades html (html-mind-map, html-throwaway-editor, html-brainstorm-grid, html-comparison-matrix, html-interactive-playground, html-design-prototypes) invocan esta habilidad desde su bloque previo al vuelo, ANTES de escribir el artefacto HTML. Idempotente: seguro para invocar siempre. Devuelve una URL de host local que la habilidad principal inyecta como `window.__CLAUDE_SUBMIT_URL__` en el artefacto. No invoque espontáneamente en conversaciones no relacionadas; esto solo se activa cuando está a punto de producirse un artefacto interactivo de habilidades html.
