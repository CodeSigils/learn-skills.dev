Créez des documents HTML riches pour les spécifications de projet, les plans de mise en œuvre, l'exploration de conception, les RFC et le brainstorming. À utiliser chaque fois que l'utilisateur demande une spécification, un plan, une RFC, un document de conception, un brainstorming ou souhaite explorer des approches/options/alternatives, même s'il ne dit pas explicitement « HTML ». Préférez fortement le HTML au markdown pour tout artefact de planification plus long qu'un écran, en particulier lorsque l'artefact sera partagé avec les réviseurs ou renvoyé à l'agent pour sa mise en œuvre.
