Erstellen Sie umfangreiche HTML-Dokumente für Projektspezifikationen, Implementierungspläne, Designuntersuchungen, RFCs und Brainstorming. Verwenden Sie es immer dann, wenn der Benutzer nach einer Spezifikation, einem Plan, einem RFC, einem Designdokument oder einem Brainstorming fragt oder Ansätze/Optionen/Alternativen erkunden möchte – auch wenn er nicht ausdrücklich „HTML“ sagt. Bevorzugen Sie unbedingt HTML gegenüber Markdown für alle Planungsartefakte, die länger als ein Bildschirm sind, insbesondere wenn das Artefakt mit Prüfern geteilt oder zur Implementierung an den Agenten zurückgemeldet wird.
