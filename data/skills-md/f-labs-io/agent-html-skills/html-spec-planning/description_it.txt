Crea documenti HTML avanzati per specifiche di progetto, piani di implementazione, esplorazione della progettazione, RFC e brainstorming. Da utilizzare ogni volta che l'utente richiede una specifica, un piano, una RFC, un documento di progettazione, un brainstorming o desidera esplorare approcci/opzioni/alternative, anche quando non dice esplicitamente "HTML". Preferire decisamente l'HTML rispetto al markdown per qualsiasi artefatto di pianificazione più lungo di uno schermo, soprattutto quando l'artefatto verrà condiviso con i revisori o inviato all'agente per l'implementazione.
