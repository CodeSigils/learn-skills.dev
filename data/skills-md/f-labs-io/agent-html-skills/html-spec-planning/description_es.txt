Cree documentos HTML enriquecidos para especificaciones de proyectos, planes de implementación, exploración de diseños, RFC y lluvia de ideas. Úselo siempre que el usuario solicite una especificación, un plan, un RFC, un documento de diseño, una lluvia de ideas o quiera explorar enfoques/opciones/alternativas, incluso cuando no digan explícitamente "HTML". Prefiera HTML a Markdown para cualquier artefacto de planificación más largo que una pantalla, especialmente cuando el artefacto se compartirá con los revisores o se enviará al agente para su implementación.
