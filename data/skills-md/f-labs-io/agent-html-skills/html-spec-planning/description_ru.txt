Создавайте насыщенные HTML-документы для спецификаций проектов, планов реализации, исследования дизайна, RFC и мозгового штурма. Используйте всякий раз, когда пользователь запрашивает спецификацию, план, RFC, проектную документацию, мозговой штурм или хочет изучить подходы/варианты/альтернативы — даже если он явно не говорит «HTML». Настоятельно отдавайте предпочтение HTML, а не уценке для любого артефакта планирования, длина которого превышает экран, особенно если артефакт будет передан рецензентам или возвращен агенту для реализации.
