قم بإنشاء مستندات HTML غنية لمواصفات المشروع وخطط التنفيذ واستكشاف التصميم وطلبات RFC والعصف الذهني. يُستخدم عندما يطلب المستخدم مواصفات أو خطة أو RFC أو مستند تصميم أو تبادل أفكار أو يريد استكشاف الأساليب/الخيارات/البدائل - حتى عندما لا يقول "HTML" صراحةً. تفضل بقوة HTML على تخفيض السعر لأي عنصر تخطيط أطول من الشاشة، خاصة عندما تتم مشاركة العنصر مع المراجعين أو إرساله مرة أخرى إلى الوكيل للتنفيذ.
