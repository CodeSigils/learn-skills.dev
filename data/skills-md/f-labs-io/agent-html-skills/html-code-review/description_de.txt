Generieren Sie HTML-Artefakte für die Codeüberprüfung, PR-Erklärung und das Verständnis der Codebasis – gerenderte Unterschiede mit Inline-Anmerkungen, nach Schweregrad codierten Ergebnissen, Refactor-Risikokarten, Ansichten vor/nach der Migration und exemplarischen Vorgehensweisen für Subsysteme. Verwenden Sie es immer dann, wenn der Benutzer eine PR, einen Refactor, einen Codebasisbereich oder ein Subsystem überprüfen, erklären oder verstehen möchte – insbesondere vor dem Zusammenführen, beim Onboarding anderer für eine Änderung oder wenn die GitHub-Diff-Ansicht nicht genügend Kontext anzeigt. Standardmäßig wird jedem nicht-trivialen PR ein HTML-Erklärer beigefügt.
