Générez des artefacts HTML pour la révision du code, l'explication des relations publiques et la compréhension de la base de code : rendus des différences avec des annotations en ligne, des résultats codés par gravité, des cartes de risques de refactorisation, des vues avant/après la migration et des présentations pas à pas des sous-systèmes. À utiliser chaque fois que l'utilisateur souhaite réviser, expliquer ou comprendre un PR, un refactor, une zone de base de code ou un sous-système, en particulier avant une fusion, lors de l'intégration d'autres personnes dans une modification ou lorsque la vue différentielle de GitHub n'affiche pas suffisamment de contexte. Par défaut, il attache un explicatif HTML à chaque PR non trivial.
