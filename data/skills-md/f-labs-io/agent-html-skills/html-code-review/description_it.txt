Genera artefatti HTML per la revisione del codice, la spiegazione delle PR e la comprensione della base di codice: differenze renderizzate con annotazioni in linea, risultati codificati in base alla gravità, mappe dei rischi del refactoring, visualizzazioni prima/dopo la migrazione e procedure dettagliate del sottosistema. Da utilizzare ogni volta che l'utente desidera rivedere, spiegare o comprendere un PR, un refactoring, un'area codebase o un sottosistema, soprattutto prima della fusione, quando si eseguono l'onboarding di altri per una modifica o quando la visualizzazione diff di GitHub non mostra un contesto sufficiente. Per impostazione predefinita, viene allegata una spiegazione HTML a ogni PR non banale.
