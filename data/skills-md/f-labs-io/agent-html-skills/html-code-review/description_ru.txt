Создавайте HTML-артефакты для проверки кода, пояснений по связям с общественностью и понимания базы кода — отображаемые различия со встроенными аннотациями, выводами с кодировкой серьезности, картами рисков рефакторинга, представлениями до и после миграции и пошаговыми руководствами по подсистемам. Используйте всякий раз, когда пользователь хочет просмотреть, объяснить или понять PR, рефакторинг, область кодовой базы или подсистему — особенно перед слиянием, при подключении других к изменению или когда представление различий GitHub не отображает достаточный контекст. По умолчанию к каждому нетривиальному PR прикрепляется пояснение HTML.
