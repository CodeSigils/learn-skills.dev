Genere artefactos HTML para revisión de código, explicación de relaciones públicas y comprensión de la base de código: diferencias representadas con anotaciones en línea, hallazgos codificados por gravedad, mapas de riesgo de refactorización, vistas de antes/después de la migración y tutoriales de subsistemas. Úselo siempre que el usuario quiera revisar, explicar o comprender un PR, refactorización, área de código base o subsistema, especialmente antes de fusionar, al incorporar a otros a un cambio o cuando la vista de diferencias de GitHub no muestra suficiente contexto. De forma predeterminada, se adjunta una explicación HTML a cada PR no trivial.
