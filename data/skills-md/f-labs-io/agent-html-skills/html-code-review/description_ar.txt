قم بإنشاء عناصر HTML لمراجعة التعليمات البرمجية، وشرح العلاقات العامة، وفهم قاعدة التعليمات البرمجية - يتم عرض الاختلافات مع التعليقات التوضيحية المضمنة، والنتائج المرمزة لدرجة الخطورة، وخرائط مخاطر إعادة البناء، وطرق عرض ما قبل/بعد الترحيل، والإرشادات التفصيلية للنظام الفرعي. يُستخدم عندما يريد المستخدم مراجعة أو شرح أو فهم العلاقات العامة أو إعادة البناء أو منطقة قاعدة التعليمات البرمجية أو النظام الفرعي - خاصة قبل الدمج، أو عند إعداد الآخرين للتغيير، أو عندما لا يُظهر عرض GitHub diff سياقًا كافيًا. الافتراضي هو إرفاق شرح HTML لكل علاقات عامة غير تافهة.
