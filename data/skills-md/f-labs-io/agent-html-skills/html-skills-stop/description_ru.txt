Отключает режим сервера для html-skills для ЭТОГО сеанса Claude Code — убивает приемник, останавливает `Monitor`, активированный `html-skills-listen`, и очищает его временные файлы. Параллельные сеансы не затрагиваются. Вызывается, когда пользователь закончил работу с интерактивными артефактами html-навыков («Я закончил с html-навыками», «остановить прослушиватель», «завершить сеанс html-навыков») ИЛИ в конце сеанса, если пользователь упоминает очистку. Безопасно вызывать, когда ничего не активно — он сообщает о неактивности и завершает работу.
