このクロード コード セッションの html-skills のサーバー モードを破棄します。受信者を強制終了し、`html-skills-listen` によって武装された `Monitor` を停止し、その一時ファイルをクリーンアップします。並列セッションは影響を受けません。ユーザーが対話型の HTML スキル アーティファクトを終了したとき (「HTML スキルを終了しました」、「リスナーを停止」、「HTML スキル セッションを終了」)、またはユーザーがクリーンアップについて言及した場合はセッション終了時に呼び出します。何もアクティブでないときに安全に呼び出すことができます。非アクティブであると報告されて終了します。
