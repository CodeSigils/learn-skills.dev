デザイン トークン (カラー パレット、タイプ スケール、間隔システム、半径スケール、シャドウ システム、モーション トークン) を、コピーアンドペーストによる CSS 変数エクスポート、コントラスト比チェック、およびライブ サンプル タイプを備えた HTML ページとしてショーケースします。ユーザーがパレット、テーマ、デザイン システム、ブランド カラー、デザイン トークンについて示したり質問したりする場合、またはビジュアル デザインを推進する価値体系を文書化したい場合に使用します。 Markdown は文字通り色を表示できません。色や空間値が関係するときはいつでも、このスキルに手を伸ばしてください。
