Präsentieren Sie Design-Tokens – Farbpaletten, Schriftskalen, Abstandssysteme, Radiusskalen, Schattensysteme, Bewegungs-Tokens – als HTML-Seiten mit CSS-Variablenexporten durch Kopieren und Einfügen, Kontrastverhältnisprüfungen und Live-Beispieltypen. Verwenden Sie es immer dann, wenn der Benutzer eine Palette, ein Thema, ein Designsystem, Markenfarben oder Designtoken zeigt oder danach fragt oder ein Wertesystem dokumentieren möchte, das das visuelle Design vorantreibt. Markdown kann buchstäblich keine Farben anzeigen; Greifen Sie immer dann zu dieser Fertigkeit, wenn es um Farb- oder Raumwerte geht.
