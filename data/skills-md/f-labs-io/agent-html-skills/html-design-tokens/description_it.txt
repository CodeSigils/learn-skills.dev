Mostra i token di progettazione (tavolozze di colori, scale di tipo, sistemi di spaziatura, scale di raggio, sistemi di ombre, token di movimento) come pagine HTML con esportazioni di variabili CSS copia-incolla, controlli del rapporto di contrasto e tipo di esempio in tempo reale. Da utilizzare ogni volta che l'utente mostra o chiede informazioni su una tavolozza, un tema, un sistema di progettazione, colori di branding, token di progettazione o desidera documentare qualsiasi sistema di valori che guida la progettazione visiva. Markdown non può letteralmente visualizzare i colori; raggiungere questa abilità ogni volta che sono coinvolti valori cromatici o spaziali.
