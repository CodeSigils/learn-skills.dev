Présentez les jetons de conception (palette de couleurs, échelles de caractères, systèmes d'espacement, échelles de rayon, systèmes d'ombres, jetons de mouvement) sous forme de pages HTML avec exportations de variables CSS copier-coller, vérifications du rapport de contraste et type d'échantillon en direct. À utiliser chaque fois que l'utilisateur montre ou pose des questions sur une palette, un thème, un système de conception, des couleurs de marque, des jetons de conception ou souhaite documenter tout système de valeurs qui pilote la conception visuelle. Markdown ne peut littéralement pas afficher les couleurs ; utilisez cette compétence chaque fois que la couleur ou les valeurs spatiales sont impliquées.
