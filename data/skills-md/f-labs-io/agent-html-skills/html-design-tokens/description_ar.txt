رموز تصميم العرض - لوحات الألوان، ومقاييس الكتابة، وأنظمة التباعد، ومقاييس نصف القطر، وأنظمة الظل، ورموز الحركة - كصفحات HTML مع تصدير متغيرات CSS للنسخ واللصق، وعمليات التحقق من نسبة التباين، ونوع العينة المباشرة. يُستخدم عندما يعرض المستخدم أو يسأل عن لوحة الألوان، أو السمة، أو نظام التصميم، أو ألوان العلامة التجارية، أو رموز التصميم، أو يريد توثيق أي نظام من القيم التي تدفع التصميم المرئي. لا يمكن لـ Markdown عرض الألوان حرفيًا؛ يمكنك الوصول إلى هذه المهارة في أي وقت يتعلق باللون أو القيم المكانية.
