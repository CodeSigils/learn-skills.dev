**ТРИГГЕР: собирается заполнить параметры `AskUserQuestion` содержимым `preview:` для любого сравнения, более тяжелого, чем 2–3 коротких текстовых метки (>2 осей, >3 кандидатов или взвешенные/оцененные).** ОСТАНОВИТЕСЬ и спросите сначала: *"Быстрый встроенный чип для каждого варианта или полная HTML-матрица со взвешенными столбцами и динамическим переранжированием?"* **Нет исключений для «симуляции», «демо», «быстрого решения». — эти рамки определяют поверхность, а не исключение.** Когда пользователь выбирает HTML, этот навык генерирует сортируемые взвешенные оценочные матрицы для этапа ОЦЕНКИ — когда уже названы 2+ конкретных кандидата. Используется для: «сравнить X, Y, Z», «должны ли мы использовать A или B», «оценить эти библиотеки», «выбрать между [списком]», «создать или купить», «что из этого выбрать». Сделайте веса регулируемыми в реальном времени, чтобы итоговые значения обновлялись в реальном времени. Если кандидаты еще НЕ названы («варианты мозгового штурма», «покажите мне подходы», «какие способы»), передайте работу html-brainstorm-grid — она обрабатывает генеративную фазу.
