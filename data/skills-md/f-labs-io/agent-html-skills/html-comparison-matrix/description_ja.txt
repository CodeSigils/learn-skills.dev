**トリガー: 2 ～ 3 個の短いテキスト ラベル (軸が 2 つ以上、候補が 3 つ以上、または重み付け/スコア付け) よりも重い比較のために、`AskUserQuestion` オプションに `preview:` コンテンツを入力しようとしています。** 停止して最初に質問してください: *「オプションごとの高速インライン チップ、それとも重み付けされた列とライブ再ランキングを備えた完全な HTML マトリックス?」* **「シミュレート」、「デモ」、 「迅速な決定」 — これらのフレームは例外ではなく、表面に名前を付けます。** ユーザーが HTML を選択すると、このスキルは 2 つ以上の特定の候補がすでに名前付けされている場合、評価フェーズ用にソート可能な重み付けされたスコア マトリックスを生成します。使用目的: 「X、Y、Z を比較する」、「A または B を使用するべきか」、「これらのライブラリを評価する」、「[リスト] から選択する」、「ビルドと購入」、「どちらを選択すべきか」。重みをライブで調整できるようにすると、合計がリアルタイムで更新されます。候補者がまだ指名されていない場合 (「ブレインストーミングのオプション」、「アプローチを示して」、「方法は何ですか」)、生成フェーズを処理する html-brainstorm-grid に引き渡します。
