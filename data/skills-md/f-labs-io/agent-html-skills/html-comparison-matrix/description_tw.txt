**觸發：即將用「預覽：」內容填滿「AskUserQuestion」選項，用於任何比 2-3 個短文字標籤（>2 個軸、>3 個候選人或加權/評分）更重的比較。 **先停止並詢問：*“每個選項的快速內聯晶片，還是帶有加權列和實時重新排名的完整 HTML 矩陣？”* **沒有“模擬”、“演示”、“快速決策”的排除 - 這些框架** 當用戶選擇 HTML 時，此技能會為評估階段生成可排序的加權評分矩陣 - 當 2 個以上特定候選人已被命名時。用於：「比較 X、Y、Z」、「我們應該使用 A 或 B」、「評估這些庫」、「在 [列表] 之間進行選擇」、「建置與購買」、「我們應該選擇其中哪一個」。使權重可即時調整，以便總數即時更新。如果候選人尚未被命名（「腦力激盪選項」、「告訴我方法」、「方法是什麼」），請交給 html-brainstorm-grid — 處理生成階段。
