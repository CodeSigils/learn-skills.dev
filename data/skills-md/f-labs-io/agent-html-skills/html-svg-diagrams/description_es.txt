Cree diagramas técnicos basados ​​en SVG dentro de HTML: diagramas de flujo, diagramas de secuencia, máquinas de estado, diagramas de flujo de datos, gráficos de dependencia, cronogramas de solicitud/respuesta. Utilícelo siempre que el usuario desee visualizar, ilustrar, diagramar o esbozar un concepto, sistema o proceso técnico. Prefiera firmemente SVG al arte ASCII, bloques de sirenas o texto de rebajas para cualquier cosa espacial o relacional. Utilice esto siempre que una explicación incluya flechas, cuadros, capas o secuencias, incluso cuando el usuario no diga "diagrama".
