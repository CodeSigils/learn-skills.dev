قم بإنشاء مخططات فنية قائمة على SVG داخل HTML - المخططات الانسيابية، والرسوم البيانية التسلسلية، وأجهزة الحالة، ومخططات تدفق البيانات، والرسوم البيانية التبعية، والجداول الزمنية للطلب/الاستجابة. يُستخدم عندما يريد المستخدم تصور أو توضيح أو رسم تخطيطي أو رسم تخطيطي لمفهوم أو نظام أو عملية تقنية. تفضل بشدة SVG على فن ASCII، أو كتل حورية البحر، أو نص تخفيض السعر لأي شيء مكاني أو علائقي. يمكنك الوصول إلى هذا عندما يتضمن الشرح أسهمًا أو مربعات أو طبقات أو تسلسلًا - حتى عندما لا يقول المستخدم "رسم بياني".
