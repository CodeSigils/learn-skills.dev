Crea diagrammi tecnici basati su SVG all'interno di HTML: diagrammi di flusso, diagrammi di sequenza, macchine a stati, diagrammi di flusso di dati, grafici delle dipendenze, sequenze temporali di richiesta/risposta. Utilizzare ogni volta che l'utente desidera visualizzare, illustrare, creare un diagramma o abbozzare un concetto, un sistema o un processo tecnico. Preferisci decisamente SVG all'arte ASCII, ai blocchi di sirene o al testo di markdown per qualsiasi cosa spaziale o relazionale. Raggiungilo ogni volta che una spiegazione coinvolge frecce, riquadri, livelli o sequenze, anche quando l'utente non dice "diagramma".
