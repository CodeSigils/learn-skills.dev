Erstellen Sie SVG-basierte technische Diagramme in HTML – Flussdiagramme, Sequenzdiagramme, Zustandsautomaten, Datenflussdiagramme, Abhängigkeitsdiagramme, Anforderungs-/Antwortzeitleisten. Verwenden Sie es immer dann, wenn der Benutzer ein technisches Konzept, System oder einen Prozess visualisieren, veranschaulichen, grafisch darstellen oder skizzieren möchte. Bevorzugen Sie SVG gegenüber ASCII-Grafik, Meerjungfrauenblöcken oder Markdown-Text für alles, was räumlich oder relational ist. Greifen Sie dazu zu, wenn eine Erklärung Pfeile, Kästchen, Ebenen oder Reihenfolgen beinhaltet – auch wenn der Benutzer nicht „Diagramm“ sagt.
