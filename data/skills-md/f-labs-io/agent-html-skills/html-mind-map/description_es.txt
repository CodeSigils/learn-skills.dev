Cree mapas mentales y mapas conceptuales HTML ramificados y arrastrables para capturar lluvias de ideas, mapear estructuras de conocimiento, explorar hipótesis de depuración u organizar ideas anidadas. Incluya siempre un botón Enviar (llamado `submitToClaude`) para enviar la estructura capturada al agente para los siguientes pasos. Úselo siempre que el usuario quiera capturar, organizar o explorar ideas ramificadas, hipótesis, estructuras de conocimiento o cualquier pensamiento en forma de árbol/gráfico, especialmente cuando dice "lluvia de ideas", "trazar un mapa", "explorar" o "y si".
