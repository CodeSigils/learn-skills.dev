ブレインストーミングのキャプチャ、知識構造のマッピング、デバッグ仮説の調査、またはネストされたアイデアの整理のために、分岐するドラッグ可能な HTML マインド マップとコンセプト マップを作成します。次のステップのためにキャプチャされた構造をエージェントに送り返すために、必ず送信ボタン (`submitToClaude` を呼び出します) を含めてください。ユーザーが分岐するアイデア、仮説、知識構造、またはツリー/グラフ形式の思考をキャプチャ、整理、または探索したいときはいつでも使用します。特に「ブレインストーミング」、「計画を立てる」、「探索する」、または「もしも」と言う場合に使用します。
