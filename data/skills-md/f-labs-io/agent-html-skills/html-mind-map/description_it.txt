Crea mappe mentali e concettuali HTML ramificate e trascinabili per catturare brainstorming, mappare strutture di conoscenza, esplorare ipotesi di debug o organizzare idee nidificate. Includi sempre un pulsante Invia (chiama `submitToClaude`) per inviare la struttura catturata all'agente per i passaggi successivi. Da utilizzare ogni volta che l'utente desidera catturare, organizzare o esplorare idee ramificate, ipotesi, strutture di conoscenza o qualsiasi pensiero a forma di albero/grafico, soprattutto quando dice "brainstorming", "mappa", "esplora" o "cosa succede se".
