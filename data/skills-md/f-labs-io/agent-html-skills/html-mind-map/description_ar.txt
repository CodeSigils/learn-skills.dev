قم بإنشاء خرائط ذهنية HTML متفرعة وقابلة للسحب وخرائط مفاهيمية لالتقاط العواصف الذهنية أو رسم خرائط للهياكل المعرفية أو استكشاف فرضيات تصحيح الأخطاء أو تنظيم الأفكار المتداخلة. قم دائمًا بتضمين زر إرسال (يستدعي "إرسال إلى كلود") لإرسال البنية التي تم التقاطها مرة أخرى إلى الوكيل لاتخاذ الخطوات التالية. يُستخدم عندما يريد المستخدم التقاط أو تنظيم أو استكشاف الأفكار المتفرعة أو الفرضيات أو هياكل المعرفة أو أي تفكير على شكل شجرة/رسم بياني - خاصة عندما يقولون "العصف الذهني" أو "التخطيط" أو "الاستكشاف" أو "ماذا لو".
