Crea esploratori di dati HTML per CSV, JSON, log e dati di eventi: tabelle filtrabili, ricerca sfaccettata, grafici incorporati, pulizia della sequenza temporale, dashboard dei risultati dei test A/B. Da utilizzare ogni volta che l'utente ha un set di dati da esplorare, sfogliare, filtrare, tracciare un grafico, sfaccettare o analizzare, in particolare per analisi ad hoc in cui l'apertura di uno strumento di BI pesante è eccessiva. Raggiungi questo obiettivo quando l'utente incolla dati, menziona un file CSV/JSON/log o chiede di "guardare" o "analizzare" un set di dati. Esegue sempre un passaggio di redazione segreta prima di incorporare i dati: i valori a forma di credenziale (chiavi API, token, cookie, password) vengono sostituiti con segnaposto a meno che l'utente non accetti esplicitamente di incorporarli.
