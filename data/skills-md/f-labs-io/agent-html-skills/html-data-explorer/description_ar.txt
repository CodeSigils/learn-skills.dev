أنشئ مستكشفات بيانات HTML لبيانات CSV وJSON والسجل والأحداث - جداول قابلة للتصفية، وبحث متعدد الأوجه، ومخططات مضمنة، وتنقية المخطط الزمني، ولوحات معلومات نتائج اختبار A/B. يُستخدم عندما يكون لدى المستخدم مجموعة بيانات للاستكشاف أو التصفح أو التصفية أو التخطيط أو الواجهات أو التحليل - خاصة للتحليل المخصص حيث يكون فتح أداة ذكاء الأعمال الثقيلة أمرًا مبالغًا فيه. يمكن الوصول إلى ذلك عندما يلصق المستخدم البيانات، أو يذكر ملف CSV/JSON/log، أو يطلب "إلقاء نظرة على" أو "تحليل" مجموعة بيانات. يقوم دائمًا بتشغيل تصريح تنقيح سري قبل تضمين البيانات - يتم استبدال القيم على شكل بيانات الاعتماد (مفاتيح واجهة برمجة التطبيقات، والرموز المميزة، وملفات تعريف الارتباط، وكلمات المرور) بعناصر نائبة ما لم يختار المستخدم صراحةً تضمينها.
