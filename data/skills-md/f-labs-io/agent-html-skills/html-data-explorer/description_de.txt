Erstellen Sie HTML-Datenexplorer für CSV-, JSON-, Protokoll- und Ereignisdaten – filterbare Tabellen, Facettensuche, Inline-Diagramme, Timeline-Scrubbing, A/B-Testergebnis-Dashboards. Verwenden Sie es immer dann, wenn der Benutzer einen Datensatz zum Erkunden, Durchsuchen, Filtern, Diagrammen, Facettieren oder Analysieren hat – insbesondere für Ad-hoc-Analysen, bei denen das Öffnen eines umfangreichen BI-Tools übertrieben ist. Greifen Sie dazu zu, wenn der Benutzer Daten einfügt, eine CSV-/JSON-/Protokolldatei erwähnt oder darum bittet, einen Datensatz „anzuschauen“ oder zu „analysieren“. Führt vor dem Einbetten von Daten immer einen geheimen Schwärzungsdurchgang durch. Werte in Form von Anmeldeinformationen (API-Schlüssel, Token, Cookies, Passwörter) werden durch Platzhalter ersetzt, es sei denn, der Benutzer stimmt der Einbettung ausdrücklich zu.
