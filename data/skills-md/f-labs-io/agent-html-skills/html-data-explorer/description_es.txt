Cree exploradores de datos HTML para datos CSV, JSON, registros y eventos: tablas filtrables, búsqueda por facetas, gráficos en línea, limpieza de líneas de tiempo, paneles de resultados de pruebas A/B. Úselo siempre que el usuario tenga un conjunto de datos para explorar, examinar, filtrar, representar en gráficos, facetar o analizar, especialmente para análisis ad hoc en los que abrir una herramienta de BI pesada es excesivo. Utilice esto cuando el usuario pegue datos, mencione un archivo CSV/JSON/registro o solicite "mirar" o "analizar" un conjunto de datos. Siempre ejecuta un pase de redacción secreta antes de incrustar datos: los valores en forma de credenciales (claves API, tokens, cookies, contraseñas) se reemplazan con marcadores de posición a menos que el usuario opte explícitamente por incrustarlos.
