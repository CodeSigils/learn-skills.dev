Создавайте обозреватели данных HTML для CSV, JSON, журналов и данных о событиях — фильтруемые таблицы, фасетный поиск, встроенные диаграммы, очистку временной шкалы, информационные панели с результатами A/B-тестирования. Используйте всякий раз, когда у пользователя есть набор данных для изучения, просмотра, фильтрации, построения диаграмм, фасетов или анализа — особенно для специального анализа, когда использование тяжелого инструмента бизнес-аналитики является излишним. Используйте это, когда пользователь вставляет данные, упоминает CSV/JSON/файл журнала или просит «посмотреть» или «проанализировать» набор данных. Перед внедрением данных всегда выполняется этап секретного редактирования — значения учетных данных (ключи API, токены, файлы cookie, пароли) заменяются заполнителями, если только пользователь явно не дает свое согласие на их внедрение.
