CSV、JSON、ログ、イベント データ用の HTML データ エクスプローラーを構築します。フィルター可能なテーブル、ファセット検索、インライン グラフ、タイムラインのスクラブ、A/B テスト結果のダッシュボードなどです。ユーザーが探索、参照、フィルター、グラフ化、ファセット、または分析するデータセットを持っている場合は常に使用します。特に、重い BI ツールを開くのが過剰なアドホック分析の場合は使用します。ユーザーがデータを貼り付けたり、CSV/JSON/ログ ファイルに言及したり、データセットを「確認」または「分析」するように要求したりするときに、これを実行します。データを埋め込む前に常にシークレットリダクション パスを実行します。ユーザーが埋め込みを明示的にオプトインしない限り、認証情報形式の値 (API キー、トークン、Cookie、パスワード) はプレースホルダーに置き換えられます。
