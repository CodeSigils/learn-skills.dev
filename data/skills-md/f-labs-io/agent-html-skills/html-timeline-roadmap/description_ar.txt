قم بإنشاء مخططات زمنية وخرائط طريق بتنسيق HTML باستخدام أقراص الحالة وأسهم التبعية وعلامات المعالم الرئيسية - للتخطيط ربع السنوي، وأثر رجعي للمشروع، وتاريخ الإصدارات، والمخططات الزمنية للحوادث، وتصورات الركض السريع. يُستخدم عندما يريد المستخدم تصور سلسلة من الأحداث بمرور الوقت، أو خطة، أو خريطة طريق، أو جدول إصدار، أو إلقاء نظرة على كيفية تطور المشروع. يمكنك الوصول إلى ذلك عندما يكون للشرح محور زمني واضح، حتى لو لم يقل المستخدم "الخط الزمني".
