Cree cronogramas y hojas de ruta HTML con píldoras de estado, flechas de dependencia y marcadores de hitos, para planificación trimestral, retrospectivas de proyectos, historiales de lanzamientos, cronogramas de incidentes y visualizaciones de sprints. Úselo siempre que el usuario quiera visualizar una secuencia de eventos a lo largo del tiempo, un plan, una hoja de ruta, un cronograma de lanzamiento o mirar hacia atrás para ver cómo se desarrolló un proyecto. Utilice esto siempre que la explicación tenga un eje temporal claro, incluso si el usuario no dice "línea de tiempo".
