Verwenden Sie es immer dann, wenn der Benutzer eine zeitliche Abfolge von Ereignissen, einen Plan, eine Roadmap oder einen Veröffentlichungsplan visualisieren oder auf die Entwicklung eines Projekts zurückblicken möchte. Greifen Sie dazu immer dann zu, wenn die Erklärung eine klare Zeitachse hat, auch wenn der Benutzer nicht „Zeitleiste“ sagt.
