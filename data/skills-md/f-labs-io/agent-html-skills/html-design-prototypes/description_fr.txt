** DÉCLENCHEUR : sur le point de remplir les options `AskUserQuestion` avec le contenu `preview:` pour toute comparaison visuelle d'interface utilisateur/écran/mise en page/composant/animation.** ARRÊTEZ et demandez d'abord : *"Comparaison rapide des puces en ligne ou un prototype HTML complet que vous pouvez ouvrir dans le navigateur ?"* Les puces aplatissent la couleur, le type, l'espacement et le mouvement dans un espace monospace ; Les prototypes HTML sont réels. **Aucune exclusion pour « simuler », « démo », « maquette », « décision rapide » — ceux-là nomment la surface, pas une exception.** Lorsque l'utilisateur choisit HTML, cette compétence crée des prototypes pour la conception visuelle, les terrains de jeux de composants, le réglage de l'animation et l'exploration du système de conception — même lorsque la cible finale est React, Swift, SwiftUI, Android ou un autre framework. À utiliser chaque fois que l'utilisateur souhaite se moquer, prototyper, esquisser, régler ou explorer un élément de l'interface utilisateur avant le code de production. HTML est la surface de réflexion conceptuelle la plus rapide ; atteignez-le même pour des cibles non Web. Pour N alternatives, utilisez html-brainstorm-grid ; pour un seul composant réglable, utilisez cette compétence.
