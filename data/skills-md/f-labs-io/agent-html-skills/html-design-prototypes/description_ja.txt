**トリガー: あらゆるビジュアル UI / 画面 / レイアウト / コンポーネント / アニメーション比較の `preview:` コンテンツを含む `AskUserQuestion` オプションを設定しようとしています。** 立ち止まって最初に質問してください: *「簡単なインライン チップ比較、それともブラウザで開くことができる完全な HTML プロトタイプ?」* チップは色、タイプ、間隔、およびモーションを等幅に平坦化します。 HTML プロトタイプは本物です。 **「シミュレート」、「デモ」、「モックアップ」、「即時決定」にはカーブアウトはありません。これらは例外ではなく、表面に名前が付けられています。** ユーザーが HTML を選択すると、このスキルは、最終ターゲットが React、Swift、SwiftUI、Android、または別のフレームワークである場合でも、ビジュアル デザイン、コンポーネント プレイグラウンド、アニメーション調整、およびデザイン システム探索のためのプロトタイプを作成します。ユーザーが実稼働コードの前に UI 要素をモック、プロトタイプ、スケッチ、調整、または探索したい場合は常に使用します。 HTML は最も高速なデザイン思考の表面です。 Web 以外のターゲットであってもアクセスできます。 N 個の代替案の場合は、html-brainstorm-grid を使用します。単一の調整可能なコンポーネントの場合は、このスキルを使用します。
