Schreibt, was in einem Video gesagt wird – die Worte, die eine Person vor der Kamera spricht, oder ein Voiceover, das über dem Bild zu hören ist. Passt das Geschriebene an die verfügbare Zeit an, so dass Zeilen nie überstürzt passen oder aufgefüllt werden, um sie zu füllen. Bei einem Video, das länger als ein einzelner Clip ist, wird das Skript in einen Teil pro Clip aufgeteilt, wobei die Größe jeweils auf die Sekunden dieses Clips abgestimmt ist. Gibt die Wörter nur als Text aus – hier wird nichts aufgezeichnet oder gesprochen. Verwenden Sie diese Option, wenn der Benutzer ein Skript, einen Dialog oder einen Voiceover für ein Video schreiben möchte.
