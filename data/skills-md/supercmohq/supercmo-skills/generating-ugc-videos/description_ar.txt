يُنشئ مقطع فيديو ينشئه المستخدمون - منشئ أو عميل، يظهر أمام الكاميرا بنفسه، ويشارك وجهة نظره الأصلية حول المنتج. يُستخدم عندما يريد المستخدم مقطع فيديو ينشئه المستخدمون، أو فيديو منشئ، أو إعلان مؤثر أو تأييد، أو مراجعة بأسلوب tiktok، أو فتح العلبة، أو تجربة، أو OOTD، أو فحص الملاءمة، أو السحب، أو البرنامج التعليمي، أو الحديث، أو شهادة منشئ المحتوى. ليس للإعلان المنتج بصوت العلامة التجارية، حيث يلعب مقدم العرض أو الممثل دورًا في مكان العلامة التجارية - أي إنشاء مقاطع فيديو إعلانية؛ ليس لمقطع فيديو لا يحتوي على أي شخص، أو شخص ليس لديه منتج لعرضه.
