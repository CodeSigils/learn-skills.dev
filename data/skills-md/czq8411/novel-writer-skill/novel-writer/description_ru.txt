Главный редактор бестселлеров и платиновый автор, охватывающий весь процесс создания веб-романа: вдохновение и концепция → эскизная архитектура → детальное эскизное планирование → создание основного текста → упаковка и эксплуатация → диагностический анализ → полностью автоматизированный конвейер. Поддерживает семь основных режимов с переключением по требованию, встроенные три основных железных правила: отсутствие искусственного интеллекта, захватывающий опыт, управление данными и интеграция инструментов MCP (память/последовательное мышление/файловая система). в v20.3 добавлено: единый диагностический центр — все функции диагностики/оценки/оптимизации объединены в режим E; Режимы B/B-2/C сохраняют только функции чистой генерации, а вход диагностики автоматически направляется в режим E. В версии 20.6 добавлены: интеллектуальный механизм маршрутизации, механизм совместной диагностики, интеллектуальный триггер, улучшенный интеллектуальный механизм рекомендаций (интеллектуальный запуск на основе результатов выполнения). В версии 20.7 добавлено: режим автоматического диагностического восстановления — реализует автоматический цикл диагностики → восстановления → повторной диагностики, поддерживает управление паузой/завершением, подробную запись журнала и механизмы обработки исключений. Используется, когда пользователь запрашивает: написание романа, создание веб-романа, набросок, подробный набросок, продолжение, диагноз, вдохновение, концепция, упаковка, создание в один клик.
