Autoverifique el funcionamiento de Godot 4 en lugar de adivinar o preguntar al usuario: dos bucles. (1) Un bucle VISUAL rápido: inyecte un temporizador de captura de pantalla de una sola vez en el proyecto en ejecución, ejecútelo directamente desde la CLI y lea el PNG resultante usted mismo. (2) Un bucle de COMPORTAMIENTO sin cabeza: escriba un script de prueba de SceneTree (verificaciones de consola ASERT PASS/FAIL, entrada simulada, dirección de bucle cerrado) que cargue una escena y verifique que se comporta correctamente en todos los fotogramas. Utilice el bucle visual cada vez que el usuario diga que la interfaz de usuario "se ve mal / 一塌糊涂 / paneles invisibles / proporciones desactivadas", o después de cambiar un tema/diseño/escena y necesita verlo antes de afirmar que está hecho. Utilice el script de prueba siempre que necesite una verificación automática de que una escena o característica se comporta correctamente (posiciones, estado, alcance de un objetivo), ya sea de forma independiente o alimentando "godot-capture" para un vídeo. Funciona para C# (.NET) y GDScript. Prefiera esto a pedirle al usuario que tome una captura de pantalla: cierre el ciclo de verificación usted mismo.
