L'autoverifica di Godot 4 funziona invece di indovinare o chiedere all'utente: due cicli. (1) Un ciclo VISUAL veloce: inserisci un timer per uno screenshot one-shot nel progetto in esecuzione, avvialo direttamente dalla CLI e leggi tu stesso il PNG risultante. (2) Un ciclo COMPORTAMENTALE senza testa: scrivere uno script di test SceneTree (controlli della console ASSERT PASS/FAIL, input simulato, sterzo a circuito chiuso) che carica una scena e verifica che si comporti correttamente tra i fotogrammi. Utilizza il loop visivo ogni volta che l'utente dice che l'interfaccia utente "sembra sbagliata / 一塌糊涂 / pannelli invisibili / proporzioni disattivate" o dopo aver modificato un tema/layout/scena e devi vederlo prima di dichiarare di averlo fatto. Utilizza lo script di test ogni volta che hai bisogno di una verifica automatizzata che una scena o una funzione si comporti correttamente (posizioni, stato, raggiungimento di un obiettivo) sia in modalità autonoma che alimentando `godot-capture` per un video. Funziona con C# (.NET) e GDScript. Preferisci decisamente questo piuttosto che chiedere all'utente di fare uno screenshot: chiudi tu stesso il ciclo di verifica.
