Überprüfen Sie die Arbeit von Godot 4 selbst, anstatt zu raten oder den Benutzer zu fragen – zwei Schleifen. (1) Eine schnelle VISUELLE Schleife: Fügen Sie einen One-Shot-Screenshot-Timer in das laufende Projekt ein, starten Sie es kopfüber über die CLI und lesen Sie das resultierende PNG selbst. (2) Eine kopflose Verhaltensschleife: Schreiben Sie ein SceneTree-Testskript (ASSERT PASS/FAIL-Konsolenprüfungen, simulierte Eingabe, Steuerung im geschlossenen Regelkreis), das eine Szene lädt und überprüft, ob sie sich über Frames hinweg korrekt verhält. Verwenden Sie die visuelle Schleife immer dann, wenn der Benutzer sagt, dass die Benutzeroberfläche „falsch aussieht / nicht sichtbar ist / Bedienfelder unsichtbar sind / Proportionen deaktiviert sind“ oder nachdem Sie ein Thema/Layout/eine Szene geändert haben und es sehen müssen, bevor Sie behaupten, fertig zu sein. Verwenden Sie das Testskript immer dann, wenn Sie eine automatische Überprüfung benötigen, ob sich eine Szene oder ein Feature korrekt verhält – Positionen, Zustand, Erreichen eines Ziels – entweder eigenständig oder als Feed „godot-capture“ für ein Video. Funktioniert für C# (.NET) und GDScript. Dies ist der Aufforderung an den Benutzer, einen Screenshot zu machen, deutlich vorzuziehen – schließen Sie die Verifizierungsschleife selbst.
