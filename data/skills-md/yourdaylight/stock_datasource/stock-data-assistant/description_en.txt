Unified Stock Data Assistant skill, integrating: (1) Data query — querying historical K-lines, financial statements, etc., via the MCP protocol (A-shares/HK stocks/ETFs/indices); (2) Real-time search — subscribing to real-time market data pushes via WebSocket (updates every 3–5 seconds); (3) WeChat integration — using picoclaw + WeChat Channel to operate the database and subscribe to real-time data on the WeChat side. Triggering this skill will automatically download picoclaw, reuse the project's LLM configuration, and initiate WeChat login.
