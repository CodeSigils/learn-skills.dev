Habilidad de asistente de datos bursátiles unificado, que integra: (1) Consulta de datos: consulta de gráficos de velas históricas, estados financieros, etc., a través del protocolo MCP (acciones A/acciones de Hong Kong/ETF/índices); (2) Búsqueda en tiempo real: suscríbase a envíos de datos de mercado en tiempo real a través de WebSocket (actualizaciones cada 3 a 5 segundos); (3) Integración de WeChat: utilice picoclaw + WeChat Channel para operar la base de datos y suscribirse a datos en tiempo real en el lado de WeChat. Cuando se active esta habilidad, picoclaw se descargará automáticamente, se reutilizará la configuración LLM del proyecto y se iniciará el inicio de sesión en WeChat.
