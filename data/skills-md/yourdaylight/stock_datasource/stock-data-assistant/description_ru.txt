Навыки Unified Stock Data Assistant, объединяющие: (1) Запрос данных — запрос исторических K-линий, финансовых отчетов и т. д. через протокол MCP (акции A/акции Гонконга/ETF/индексы); (2) поиск в реальном времени — подписка на рассылку рыночных данных в реальном времени через WebSocket (обновление каждые 3–5 секунд); (3) Интеграция WeChat — использование picoclaw + WeChat Channel для управления базой данных и подписки на данные в реальном времени на стороне WeChat. Активация этого навыка автоматически загрузит picoclaw, повторно использует конфигурацию LLM проекта и инициирует вход в WeChat.
