Erstellen oder aktualisieren Sie Gitee-Pull-Anfragen, indem Sie sie im Überprüfungsmodus an geschützte Branches senden (评审模式). Wird verwendet, wenn Codex aufgefordert wird, einen Zweig zu pushen, damit Gitee automatisch einen PR erstellt oder aktualisiert, um zu entscheiden, ob ein Push nach „commit --amend“, „rebase“, „revert“ oder einem anderen Umschreiben des Verlaufs den aktuellen automatischen PR aktualisiert oder einen neuen erstellt, oder um denselben PR beizubehalten, indem am generierten „auto-*“-Quellzweig gearbeitet wird.
