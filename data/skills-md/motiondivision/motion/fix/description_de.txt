Nehmen Sie ein GitHub-Problem, eine offene PR oder eine Plandatei aus plans/ und führen Sie sie zu einer zusammenführungsbereiten PR – reproduzieren Sie sie zuerst mit einem fehlgeschlagenen Test, implementieren Sie den Fix (Bugs) oder die Funktion (Pläne), überprüfen Sie sie anhand der Gates des Repos und öffnen oder aktualisieren Sie die PR. Verwenden Sie diese Option, wenn Sie aufgefordert werden, ein Problem zu beheben, einen Plan umzusetzen oder auszuführen, eine offene PR abzuschließen oder zu landen oder Pläne/Probleme durchzuarbeiten.
