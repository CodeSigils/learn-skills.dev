Инструмент CLI для создания изображений Azure OpenAI (gpt-image-1.5/gpt-5.1). Генерирует изображения из текста, выполняет редактирование изображений с помощью искусственного интеллекта и предоставляет пояснения к содержимому изображений. Используйте, когда пользователь хочет (1) создавать изображения с помощью Azure OpenAI, (2) редактировать существующие изображения с помощью ИИ, (3) объяснять содержимое изображения. Триггеры «создать изображение», «отредактировать изображение», «объяснить изображение», «создать изображение», «отредактировать это изображение», «описать это изображение», «с помощью imgen».
