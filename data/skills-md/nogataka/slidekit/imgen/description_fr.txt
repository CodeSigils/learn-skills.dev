Outil CLI de génération d'images Azure OpenAI (gpt-image-1.5 / gpt-5.1). Génère des images à partir de texte, effectue une édition d'images par l'IA et fournit des explications sur le contenu de l'image. À utiliser lorsque l'utilisateur souhaite (1) générer des images à l'aide d'Azure OpenAI, (2) modifier des images existantes avec l'IA, (3) expliquer le contenu de l'image. Déclencheurs sur « générer une image », « modifier l'image », « expliquer l'image », « générer une image », « modifier cette image », « décrire cette image », « avec imgen ».
