Azure OpenAI image generation CLI tool (gpt-image-1.5 / gpt-5.1). Generates images from text, performs AI editing of images, and provides explanations of image contents. Use when the user wants to (1) generate images using Azure OpenAI, (2) edit existing images with AI, (3) explain image contents. Triggers on “generate image”, “edit image”, “explain image”, “generate an image”, “edit this image”, “describe this image”, “with imgen”.
