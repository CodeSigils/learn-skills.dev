Herramienta CLI de generación de imágenes de Azure OpenAI (gpt-image-1.5/gpt-5.1). Genera imágenes a partir de texto, realiza edición de imágenes mediante IA y proporciona explicaciones del contenido de las imágenes. Úselo cuando el usuario quiera (1) generar imágenes usando Azure OpenAI, (2) editar imágenes existentes con AI, (3) explicar el contenido de la imagen. Activadores en "generar imagen", "editar imagen", "explicar imagen", "generar una imagen", "editar esta imagen", "describir esta imagen", "con imgen".
