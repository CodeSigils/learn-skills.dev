Heaven's Edge Divine Stick Brain Trust — un système de décision multi-agents composé de 20 maîtres légendaires. Basé sur le principe de collaboration multi-agents ClawTeam, il réalise le workflow complet « un objectif → 20 maîtrises d'analyse parallèle → décision intégrée ».

Mécanisme de base :
- Intelligent Leader Agent (coordinateur) reçoit l'objectif et l'attribue aux 20 maîtres professionnels
- Les 20 masters mènent des analyses parallèles, apportant chacun un regard professionnel
- L'agent de décision intégré consolide toutes les perspectives et produit la décision finale

Comment utiliser :
- "Activer Heaven's Edge Brain Trust" + votre question/objectif
- "Invoquer les Maîtres" + votre question/objectif
- « 20 Masters Analyse » + votre question/objectif

Domaines couverts : analyse des politiques de pouvoir, prévisions économiques, interprétation historique, déconstruction culturelle, émotions urbaines, analyse technologique, monde mafieux, aventures de pillage de tombes, wuxia fantastique, capacités surnaturelles urbaines, déduction mystérieuse, enquête médico-légale, voyage dans le temps historique, etc.
