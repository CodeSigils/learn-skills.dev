Suddividi l'interfaccia utente frontend in componenti logici e componibili con una netta separazione delle preoccupazioni. Da utilizzare durante il refactoring di file dell'interfaccia utente React/Vue/Svelte/HTML, l'estrazione di schede/sezioni/pannelli/moduli da componenti di grandi dimensioni, l'organizzazione di cartelle di componenti in base all'architettura delle informazioni sul prodotto o la suddivisione di CSS in file di stile di proprietà del componente senza frammentazione eccessiva.
