Интерактивное пакетное создание изображений для DAOGE / 刀哥 на основе требований диалога и дополнительных библиотек подсказок ссылочной уценки. Активирует этот навык, когда пользователь запрашивает DAOGE, 刀哥, 交互式批量生图 или использует разговорные фразы для пробуждения, такие как «刀哥，我来了», «刀哥，干活», «刀哥，来跑批», «刀哥，生图», «刀哥，起来干活», «刀哥，开工», «刀哥，出图», «刀哥，开始跑», «刀哥，准备干活», «刀哥，开始批量生图», «ДАОГЭ，开工». Используйте, когда Кодексу необходимо прочитать предоставленную пользователем библиотеку `.md`/prompt, синтезировать множество различных запросов и запустить настраиваемые пакеты создания собственных изображений, где настройки API берутся из локального `.env`, а параметры запуска, такие как общее количество, размер пакета, параллелизм, повторные попытки, время ожидания, размер, соотношение сторон и ограничения стиля, вводятся через диалог.
