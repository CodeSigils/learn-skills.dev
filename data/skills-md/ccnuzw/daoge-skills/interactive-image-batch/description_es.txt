Generación interactiva de imágenes por lotes para DAOGE / 刀哥 a partir de requisitos de conversación y bibliotecas de mensajes de rebajas opcionales a las que se hace referencia. Activa esta habilidad cuando el usuario pide DAOGE, 刀哥, 交互式批量生图, o usa frases coloquiales para despertarte como “刀哥，我来了”, “刀哥，干活”, “刀哥，来跑批”, “刀哥，生图”, “刀哥，起来干活”, “刀哥，开工”, “刀哥，出图”, “刀哥，开始跑”, “刀哥，准备干活”, “刀哥，开始批量生图”, “DAOGE，开工”. Úselo cuando Codex necesita leer una biblioteca `.md`/prompt proporcionada por el usuario, sintetizar muchos mensajes diferenciados y ejecutar lotes de generación de imágenes nativas configurables donde las configuraciones de API provienen de `.env` local y los parámetros de ejecución como el recuento total, el tamaño del lote, la simultaneidad, los reintentos, el tiempo de espera, el tamaño, la relación de aspecto y las restricciones de estilo se inyectan a través del diálogo.
