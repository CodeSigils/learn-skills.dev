대화 요구 사항 및 선택적으로 참조된 마크다운 프롬프트 라이브러리에서 DAOGE/刀哥에 대한 대화형 배치 이미지 생성. 사용자가 DAOGE, 刀哥, 交互式批weight生图를 요청하거나 "刀哥，我来了", "刀哥，干活", "刀哥，来跑批"와 같은 구어체 깨우기 문구를 사용할 때 이 스킬을 트리거합니다. “刀哥，生图”, “刀哥，起来干活”, “刀哥，开工”, “刀哥，出图”, “刀哥，开始跑”, “刀哥，准备干活”, “刀哥，开始批weight生图”, “DAOGE，开工”. Codex가 사용자 제공 `.md`/프롬프트 라이브러리를 읽고, 다양한 차별화된 프롬프트를 합성하고, API 설정이 로컬 `.env`에서 제공되고 총 개수, 배치 크기, 동시성, 재시도, 시간 초과, 크기, 종횡비 및 스타일 제약 조건과 같은 실행 매개변수가 대화를 통해 주입되는 구성 가능한 기본 이미지 생성 배치를 실행해야 하는 경우에 사용합니다.
