À utiliser pour AGENT DOCS : documents natifs d'agent qu'un agent IA lit et sur lesquels il agit (pas d'humains). FAIRE : écrire/réparer AGENTS.md, llms.txt, descriptions d'outils, références, budget-contexte. RÉVISION : audit pour la trouvabilité, la capacité de survie des fragments, la clarté du déclencheur, le budget. CONCEPTION : façonner les contrats de documents. Déclencheurs : auditer AGENTS.md, curate llms.txt, mauvais appel d'outil, la documentation survivra au regroupement. Ne PAS utiliser pour les documents humains/à double audience – utilisez docs-audit/docs-design.
