Используйте для AGENT DOCS — собственные документы агента, которые агент ИИ читает и на основе которых действует (без людей). СДЕЛАЙТЕ: написать/исправить AGENTS.md, llms.txt, описания инструментов, ссылки, контекстный бюджет. ОБЗОР: аудит находимости, живучести фрагментов, ясности триггеров, бюджета. ДИЗАЙН: формируйте договоры документации. Триггеры: аудит AGENTS.md, обработка llms.txt, неправильный вызов инструмента, документ выдержит разбиение на фрагменты. НЕ используйте для документов для людей и двойной аудитории — используйте docs-audit/docs-design.
