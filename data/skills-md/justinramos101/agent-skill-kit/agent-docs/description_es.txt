Úselo para AGENT DOCS: documentos nativos del agente que un agente de IA lee y sobre los que actúa (no humanos). HACER: escribir/arreglar AGENTS.md, llms.txt, descripciones de herramientas, referencias, presupuesto de contexto. REVISIÓN: auditoría de capacidad de búsqueda, capacidad de supervivencia de fragmentos, claridad de activación, presupuesto. DISEÑO: dar forma a los contratos doc. Desencadenantes: auditar AGENTS.md, curar llms.txt, llamada de herramienta incorrecta, el documento sobrevivirá a la fragmentación. NO lo use para documentos humanos o de doble audiencia; use docs-audit/docs-design.
