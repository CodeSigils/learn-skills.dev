TUN: AGENTS.md, llms.txt, Toolbeschreibungen, Refs, Kontextbudget schreiben/korrigieren. ÜBERPRÜFUNG: Prüfung auf Auffindbarkeit, Überlebensfähigkeit von Blöcken, Klarheit des Auslösers, Budget.
