Используйте для AGENT DX — поверхность, которую ИИ-агент использует в качестве разработчика. НЕОБХОДИМО — сохраняйте SDK/инструмент/структурированный вывод/ошибку/изменения телеметрии в качестве потребляемых агентом. ОБЗОР — аудит поверхностей, обращенных к агенту, на предмет стабильных контрактов, восстановления и безопасности на границе доверия. ДИЗАЙН — формируйте новые поверхности, обращенные к агенту. Триггеры: «разработать наш агент SDK», «безопасны ли для агентов наши схемы инструментов», «проверить поверхность MCP», «утечка ли телеметрии PII». НЕ используйте для людей-разработчиков (используйте dx-audit/dx-design), читаемые агентами документы (используйте агент-документы) или усиление агентов репо (используйте Harden-Repo-for-coding-Agents).
