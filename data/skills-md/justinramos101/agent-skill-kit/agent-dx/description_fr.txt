À utiliser pour AGENT DX : la surface qu'un agent IA consomme en tant que développeur. FAIRE - conserver les modifications du SDK/outil/structuré-sortie/erreur/télémétrie comme consommable d'agent. REVUE – auditez les surfaces face aux agents pour des contrats stables, une récupération et une sécurité des limites de confiance. CONCEPTION – façonnez de nouvelles surfaces faisant face aux agents. Déclencheurs : « concevoir notre SDK d'agent », « nos schémas d'outils sont-ils sûrs pour les agents », « examiner la surface MCP », « la télémétrie fuit-elle les informations personnelles ». Ne PAS utiliser pour les surfaces de développement humain (utilisez dx-audit / dx-design), les documents lisibles par agent (utilisez agent-docs) ou le renforcement des agents de dépôt (utilisez harden-repo-for-coding-agents).
