Úselo para AGENT DX: la superficie que consume un agente de IA como desarrollador. HACER: mantener el agente consumible del SDK/herramienta/salida estructurada/error/cambios de telemetría. REVISIÓN: audite las superficies de contacto con los agentes para obtener contratos estables, recuperación y seguridad de los límites de confianza. DISEÑO: dé forma a nuevas superficies de cara al agente. Activadores: "diseñar nuestro SDK de agente", "nuestros esquemas de herramientas son seguros para los agentes", "revisar la superficie de MCP", "la telemetría está filtrando PII". NO lo use para superficies de desarrollador humano (use dx-audit / dx-design), documentos legibles por agente (use agent-docs) o endurecimiento de agente de repositorio (use harden-repo-for-coding-agents).
