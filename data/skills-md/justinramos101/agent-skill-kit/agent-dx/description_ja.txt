AGENT DX に使用 — AI エージェントが開発者として使用するサーフェス。実行 — SDK/ツール/構造化出力/エラー/テレメトリの変更をエージェントが利用できるようにしておきます。レビュー — 安定した契約、回復、信頼境界の安全性について、エージェントに面した表面を監査します。デザイン — エージェントに面する新しい表面を形成します。トリガー: 「エージェント SDK を設計する」、「ツール スキーマはエージェントセーフであるか」、「MCP サーフェスをレビューする」、「テレメトリは PII を漏洩しているか」。人間の開発者向けサーフェス (dx-audit / dx-design を使用)、エージェントが読み取り可能なドキュメント (agent-docs を使用)、またはリポジトリ エージェントの強化 (harden-repo-for-coding-agents を使用) には使用しないでください。
