Bewerten, härten, stützen oder diagnostizieren Sie die Agentenbereitschaft eines Repos. Auslöser: „Lassen Sie dieses Repo mit Claude Code funktionieren“, „Bewerten Sie unsere Agentenbereitschaft“. NICHT verwenden, um beobachtete Agentenfehler in Regeln umzuwandeln (Rules-from-Coding-Agent-Failures verwenden) oder um die Auswertungen eines KI-Produkts zu entwerfen (Agententest verwenden).
