Evaluar, reforzar, estructurar o diagnosticar la preparación del agente de un repositorio. Activadores: 'hacer que este repositorio funcione con Claude Code', 'calificar la preparación de nuestro agente'. NO lo use para promover fallas de agentes observadas en reglas (use reglas de fallas de agentes de codificación) ni para diseñar evaluaciones de un producto de IA (use pruebas de agentes).
