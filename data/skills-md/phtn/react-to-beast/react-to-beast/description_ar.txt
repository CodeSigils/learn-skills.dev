قم بتدقيق وتنفيذ تطبيقات React الكاملة إلى Beast BTSX → TSRX → Octane مع الحفاظ على السلوك وعقود التوجيه والتصميم. يُستخدم لعمليات الترحيل من Vite أو Create React App أو React Router أو TanStack Router أو Remix أو Next.js. Tailwind هو الهدف الافتراضي؛ CSS النقي اختياري. لا تستخدم لتأليف Beast الروتيني أو إعادة بناء React غير ذات الصلة.
