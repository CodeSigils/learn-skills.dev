Audite y transfiera aplicaciones React completas a Beast BTSX → TSRX → Octane mientras preserva el comportamiento, los contratos de ruta y el estilo. Úselo para migraciones desde Vite, Create React App, React Router, TanStack Router, Remix o Next.js. Tailwind es el objetivo predeterminado; CSS puro es opcional. No lo use para la creación rutinaria de Beast o refactores de React no relacionados.
