Auditer et porter des applications React complètes vers Beast BTSX → TSRX → Octane tout en préservant le comportement, les contrats de route et le style. Utilisez‑le pour les migrations depuis Vite, Create React App, React Router, TanStack Router, Remix ou Next.js. Tailwind est la cible par défaut ; le CSS pur est optionnel. Ne l’utilisez pas pour la rédaction courante de Beast ni pour des refactorisations React non liées.
