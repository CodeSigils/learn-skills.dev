Аудит и полный перенос приложений React на Beast BTSX → TSRX → Octane, сохраняя при этом поведение, контракты маршрутизации и стиль. Используйте для миграции из Vite, Create React App, React Router, TanStack Router, Remix или Next.js. Попутный ветер является целью по умолчанию; чистый CSS не является обязательным. Не используйте для рутинной разработки Beast или несвязанных рефакторингов React.
