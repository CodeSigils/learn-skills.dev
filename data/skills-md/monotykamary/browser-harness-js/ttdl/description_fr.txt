Téléchargez des vidéos TikTok de manière native dans le navigateur : pas de "yt-dlp", pas de solution de signature, pas de filigrane. Le navigateur lit la vidéo (signature d'URL, jetons CDN, sélection de qualité, le tout effectué par la page elle-même) ; ttdl enregistre le média démultiplexé que le lecteur transmet à MediaSource via un hook `SourceBuffer.appendBuffer` et multiplexe en MP4 avec ffmpeg. Si l'utilisateur peut regarder la vidéo, elle est téléchargeable : le contenu verrouillé par région et limité par âge fonctionne tant qu'un onglet connecté peut les lire. La capture est le flux de lecture propre et sans filigrane (le propre bouton Télécharger de TikTok sert un fichier filigrané rendu séparément). À utiliser lorsque l'utilisateur souhaite télécharger, enregistrer ou récupérer une vidéo TikTok (avec ou sans audio) sur le disque.
