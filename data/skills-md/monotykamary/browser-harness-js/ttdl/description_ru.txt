Скачивайте видео TikTok прямо в браузере — без `yt-dlp`, без средства распознавания подписей и без водяных знаков. Браузер воспроизводит видео (подпись URL-адресов, токены CDN, выбор качества — все это выполняется самой страницей); ttdl записывает демультимедиа, которые проигрыватель передает в MediaSource через перехватчик SourceBuffer.appendBuffer, и мультиплексирует в MP4 с помощью ffmpeg. Если пользователь может посмотреть видео, его можно загрузить — контент с привязкой к региону и возрасту работает до тех пор, пока вкладка, на которой выполнен вход в систему, может воспроизводить его. Захват представляет собой чистый поток воспроизведения без водяных знаков (собственная кнопка «Загрузить» TikTok служит для отдельного файла с водяными знаками). Используйте, когда пользователь хочет загрузить, сохранить или получить видео TikTok (со звуком или без него) на диск.
