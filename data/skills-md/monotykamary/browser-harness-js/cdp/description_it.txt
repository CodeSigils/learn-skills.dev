Gestisci qualsiasi browser basato su Chromium tramite il protocollo DevTools da JavaScript. Esegui gli snippet JS tramite la CLI `browser-harness-js`: genera automaticamente un server HTTP bun di lunga durata che contiene una `Session` CDP completamente tipizzata e ogni chiamata (`browser-harness-js 'await session.Page.navigate(...)'`) viene eseguita sulla stessa connessione persistente. Sessione, destinazione attiva e globali sopravvivono tra le chiamate. Da utilizzare quando l'utente desidera automatizzare, creare script o ispezionare un browser basato su Chromium tramite CDP: scheda singola o multischeda, collegarlo a un browser esistente o avviarne uno nuovo con --remote-debugging-port.
