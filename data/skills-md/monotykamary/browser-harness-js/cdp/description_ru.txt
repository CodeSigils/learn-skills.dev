Управляйте любым браузером на базе Chromium через протокол DevTools из JavaScript. Запускайте фрагменты JS через CLI `browser-harness-js` — он автоматически создает долгоживущий HTTP-сервер, содержащий полностью типизированный `Session` CDP, и каждый вызов (`browser-harness-js 'await session.Page.navigate(...)'`) выполняется с использованием одного и того же постоянного соединения. Сеанс, активная цель и глобальные переменные сохраняются при вызовах. Используйте, когда пользователь хочет автоматизировать, создать сценарий или проверить браузер на основе Chromium через CDP — одну вкладку или несколько вкладок, подключиться к существующему браузеру или запустить новый с помощью --remote-debugging-port.
