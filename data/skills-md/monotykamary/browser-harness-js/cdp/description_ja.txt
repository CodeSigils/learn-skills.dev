JavaScript から DevTools プロトコルを介して Chromium ベースのブラウザを駆動します。 `browser-harness-js` CLI を介して JS スニペットを実行します。完全に型指定された CDP `Session` を保持する長期存続する bun HTTP サーバーが自動生成され、すべての呼び出し (`browser-harness-js 'await session.Page.navigate(...)'`) が同じ永続接続に対して実行されます。セッション、アクティブなターゲット、およびグローバルは呼び出しをまたいで存続します。ユーザーが CDP 経由で Chromium ベースのブラウザを自動化、スクリプト化、検査する場合に使用します。単一タブまたは複数タブ、既存のブラウザに接続するか、--remote-debugging-port で新しいブラウザを起動します。
