قم بقيادة أي متصفح يستند إلى Chromium عبر بروتوكول DevTools من JavaScript. قم بتشغيل مقتطفات JS من خلال واجهة سطر الأوامر `browser-harness-js` - فهي تُنشئ تلقائيًا خادم HTTP طويل العمر يحمل CDP `Session` مكتوب بالكامل، ويتم تنفيذ كل استدعاء (`browser-harness-js'await session.Page.navigate(...)'`) مقابل نفس الاتصال المستمر. تبقى الجلسة والهدف النشط والمجموعات العالمية عبر المكالمات. يُستخدم عندما يريد المستخدم أتمتة متصفح يستند إلى Chromium أو كتابته أو فحصه عبر CDP — علامة تبويب واحدة أو علامات تبويب متعددة، أو إرفاقه بمتصفح موجود أو تشغيل متصفح جديد باستخدام --remote-debugging-port.
