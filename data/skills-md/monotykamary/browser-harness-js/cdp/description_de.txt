Steuern Sie jeden Chromium-basierten Browser über das DevTools-Protokoll von JavaScript. Führen Sie JS-Snippets über die „browser-harness-js“-CLI aus – sie erzeugt automatisch einen langlebigen Bun-HTTP-Server, der eine vollständig typisierte CDP-„Sitzung“ hält, und jeder Aufruf („browser-harness-js ‚await session.Page.navigate(...)‘‘) wird für dieselbe dauerhafte Verbindung ausgeführt. Sitzung, aktives Ziel und Globals bleiben über alle Aufrufe hinweg bestehen. Verwenden Sie diese Option, wenn der Benutzer einen Chromium-basierten Browser über CDP automatisieren, skripten oder überprüfen möchte – einzelne Registerkarte oder mehrere Registerkarten, an einen vorhandenen Browser anhängen oder einen neuen mit --remote-debugging-port starten.
