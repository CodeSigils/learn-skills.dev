Pilotez n'importe quel navigateur basé sur Chromium via le protocole DevTools à partir de JavaScript. Exécutez des extraits JS via la CLI `browser-harness-js` - il génère automatiquement un serveur HTTP bun de longue durée contenant une `Session` CDP entièrement typée, et chaque appel (`browser-harness-js 'await session.Page.navigate(...)'`) s'exécute sur la même connexion persistante. La session, la cible active et les variables globales survivent à travers les appels. À utiliser lorsque l'utilisateur souhaite automatiser, créer un script ou inspecter un navigateur basé sur Chromium via CDP : un seul onglet ou plusieurs onglets, s'attacher à un navigateur existant ou en lancer un nouveau avec --remote-debugging-port.
