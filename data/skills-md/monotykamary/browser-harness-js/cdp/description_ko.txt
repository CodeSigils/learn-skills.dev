JavaScript의 DevTools 프로토콜을 통해 Chromium 기반 브라우저를 구동하세요. `browser-harness-js` CLI를 통해 JS 스니펫을 실행합니다. 이는 완전한 유형의 CDP `Session`을 보유하는 수명이 긴 Bun HTTP 서버를 자동 생성하고 모든 호출(`browser-harness-js 'await session.Page.navigate(...)'`)은 동일한 영구 연결에 대해 실행됩니다. 세션, 활성 대상 및 전역은 호출 전반에 걸쳐 유지됩니다. 사용자가 CDP(단일 탭 또는 다중 탭)를 통해 Chromium 기반 브라우저를 자동화, 스크립트 또는 검사하려는 경우에 사용하고, 기존 브라우저에 연결하거나 --remote-debugging-port를 사용하여 새 브라우저를 시작합니다.
