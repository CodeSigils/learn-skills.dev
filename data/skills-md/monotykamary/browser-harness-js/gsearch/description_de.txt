Durchsuchen Sie das Web über Google über CDP. Gibt strukturierte Ergebnisse (Titel, URL, Snippet) in weniger als 1 Sekunde zurück. Verwenden Sie diese Option, wenn der Benutzer das Web durchsuchen, etwas nachschlagen, einen Link finden oder ein Thema recherchieren möchte. Erfordert browser-harness-js auf PATH und einen Chromium-basierten Browser mit aktiviertem Remote-Debugging. Öffnet außerdem einen Ergebnislink mit „follow <url>“, um den Seitentext oder JSON zu lesen.
