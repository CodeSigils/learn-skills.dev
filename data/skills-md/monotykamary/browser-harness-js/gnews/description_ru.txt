Выполните поиск в Новостях Google через CDP. Возвращает структурированные результаты (заголовок, URL-адрес, источник, время, фрагмент) для любого запроса — прямой URL-адрес издателя, без оболочки перенаправления news.google.com. Используйте, когда пользователь спрашивает новости, заголовки или недавнее освещение темы. Требуется браузер-harness-js для PATH и браузер на базе Chromium с включенной удаленной отладкой.
