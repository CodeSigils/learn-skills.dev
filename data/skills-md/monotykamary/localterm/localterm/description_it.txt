Gestisci l'API HTTP del demone localterm: pianifica le automazioni, imposta i trigger guidati dagli eventi (modifiche git, notifiche shell, modifiche alle directory), esecuzioni di trigger, ispeziona le differenze git e controlla l'integrità del server. Da utilizzare quando l'utente chiede di pianificare, elencare o gestire le automazioni in localterm o di eseguire script sul server localterm.
