Создавайте ежедневный дайджест технических новостей из более чем 90 ведущих технических блогов (куратор — Karpathy). Запустите с помощью /digest. Получает RSS-каналы, оценивает статьи по релевантности/качеству и создает структурированное резюме на китайском/английском языках. Никаких внешних ключей API не требуется — для оценки и обобщения используется собственный LLM агента.
