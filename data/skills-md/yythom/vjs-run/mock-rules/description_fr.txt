Utilisé lors de la personnalisation ou de la modification de données fictives pour les tests d'intégration frontale. Il remplace les règles simulées de vjtools et les opérations CRUD, les formats de champ, la correspondance de chemin et le chargement à chaud de « scènes » (scenes/<name>.json). Il est déclenché lorsqu'on lui demande de « modifier ce qu'une certaine interface renvoie », « faire en sorte que /api/xxx renvoie… », « créer de fausses données pour les tests d'intégration », « créer un scénario de test d'intégration » ou « désactiver une simulation spécifique ».
