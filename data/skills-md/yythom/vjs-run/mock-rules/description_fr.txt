Utilisé lors de la personnalisation ou de la modification de données fictives pour les tests d'intégration frontale. Il remplace les règles simulées de vjtools et les opérations de création, de lecture, de mise à jour, de suppression, les formats de champ, la correspondance de chemin et le chargement à chaud de « scènes » (scenes/<nom>.json). Il est déclenché lorsqu'on lui demande de « modifier ce qu'une certaine API renvoie », « faire en sorte que /api/xxx renvoie… », « créer de fausses données pour les tests d'intégration », « créer un scénario d'intégration » ou « désactiver une simulation spécifique ».
