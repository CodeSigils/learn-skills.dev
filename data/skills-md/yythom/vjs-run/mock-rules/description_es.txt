Se utiliza al personalizar o modificar datos simulados para pruebas de integración front-end. Anula las reglas simuladas de vjtools y las operaciones CRUD, los formatos de campo, la coincidencia de rutas y la carga en caliente de "escenas" (escenas/<nombre>.json). Se activa cuando se le pide "cambiar lo que devuelve una determinada interfaz", "hacer que /api/xxx regrese...", "crear datos falsos para las pruebas de integración", "crear un escenario de integración" o "desactivar una simulación específica".
