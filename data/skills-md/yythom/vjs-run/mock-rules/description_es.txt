Se utiliza al personalizar o modificar datos simulados para pruebas de integración front-end. Anula las reglas simuladas de vjtools y las operaciones de creación, lectura, actualización, eliminación, formatos de campo, coincidencia de rutas y carga en caliente de "escenas" (escenas/<nombre>.json). Se activa cuando se le pide "cambiar lo que devuelve una determinada API", "hacer que /api/xxx regrese...", "crear datos falsos para las pruebas de integración", "crear un escenario de integración" o "deshabilitar una simulación específica".
