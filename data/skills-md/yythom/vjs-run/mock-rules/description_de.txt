Wird beim Anpassen oder Ändern von Scheindaten für Front-End-Integrationstests verwendet. Es überschreibt die Scheinregeln von vjtools und die Vorgänge zum Erstellen, Lesen, Aktualisieren, Löschen, Feldformate, Pfadabgleich und Hotloading von „Szenen“ (scenes/<name>.json). Es wird ausgelöst, wenn Sie aufgefordert werden, „zu ändern, was eine bestimmte API zurückgibt“, „/api/xxx zurückgeben …“, „gefälschte Daten für Integrationstests erstellen“, „ein Integrationsszenario erstellen“ oder „einen bestimmten Mock zu deaktivieren“.
