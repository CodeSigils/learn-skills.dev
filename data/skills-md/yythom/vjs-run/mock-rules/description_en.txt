Used when customizing or modifying mock data for front‑end integration testing. It overrides vjtools’ mock rules and the CRUD operations, field formats, path matching, and hot loading for “scenes” (scenes/<name>.json). It is triggered when asked to “change what a certain API returns,” “make /api/xxx return …,” “create fake data for integration testing,” “build an integration‑testing scenario,” or “disable a specific mock.”
