Used when customizing or modifying mock data for front‑end integration testing. It overrides vjtools’ mock rules and the create, read, update, delete operations, field formats, path matching, and hot‑loading of “scenes” (scenes/<name>.json). It is triggered when asked to “change what a certain API returns,” “make /api/xxx return …,” “create fake data for integration testing,” “build an integration scenario,” or “disable a specific mock.”
