Créez des présentations Web basées sur HTML avec un flux de travail axé sur le créateur : gardez le mode rapide léger, utilisez le mode de base pour la planification confirmée du deck, le script et le flux d'images, et utilisez le mode avancé pour les decks basés sur des références, la diffusion statique d'abord, le suivi de mouvement facultatif et les solutions de secours sécurisées lorsque la persistance des fichiers ou la recherche sur le Web n'est pas disponible.
