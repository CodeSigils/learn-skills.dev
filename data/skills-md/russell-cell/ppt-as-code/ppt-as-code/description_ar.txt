قم ببناء عروض تقديمية على الويب تعتمد على HTML مع سير عمل المنشئ أولاً: حافظ على الوضع السريع خفيف الوزن، واستخدم الوضع الأساسي لتخطيط المجموعة المؤكدة بالإضافة إلى البرنامج النصي بالإضافة إلى تدفق الصور، واستخدم الوضع المتقدم للمجموعات المستندة إلى المرجع، والتسليم الثابت أولاً، ومتابعة الحركة الاختيارية، والاحتياطيات الآمنة عندما لا يتوفر استمرار الملف أو البحث على الويب.
