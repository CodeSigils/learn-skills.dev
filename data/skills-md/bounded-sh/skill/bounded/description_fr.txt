Créez et utilisez Bounded (bounded.sh), un backend en temps réel prouvé pour les applications. Commencez ici pour n'importe quelle tâche Bounded : cette compétence vous dirige vers le bon membre de la famille de compétences Bounded (backend/politique, frontend, déploiement, onchain, équipes, observation) et couvre la configuration, la facturation, les compartiments, les limites d'utilisation et la configuration du projet telle quebounded.json et les profils de compte. À utiliser chaque fois que vous travaillez avec la CLI Bounded, Policy.json, la vérification/le déploiement, les fonctions, l'authentification, le temps réel, les paiements ou les invariants.
