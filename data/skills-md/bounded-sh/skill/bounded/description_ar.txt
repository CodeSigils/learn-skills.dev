قم ببناء واستخدام Bounded (bounded.sh)، وهي واجهة خلفية للتطبيقات يمكن إثباتها في الوقت الفعلي. ابدأ هنا لأي مهمة Bounded: توجهك هذه المهارة إلى العضو المناسب في مجموعة المهارات Bounded (الواجهة الخلفية/السياسة، الواجهة الأمامية، النشر، onchain، الفرق، المراقبة) وتغطي الإعداد والفوترة والحاويات وحدود الاستخدام وتكوين المشروع مثلbounded.json وملفات تعريف الحساب. يُستخدم عند العمل مع Bounded CLI، أو Policy.json، أو التحقق/النشر، أو الوظائف، أو المصادقة، أو الوقت الفعلي، أو المدفوعات، أو الثوابت.
