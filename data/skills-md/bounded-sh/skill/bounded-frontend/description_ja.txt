Web または React Native フロントエンドを Bounded: @bounded-sh/client SDK (読み取り、書き込み、サブスクリプション、クエリ)、ホストされた静的フロントエンド、エンドユーザー認証 UI (電子メール OTP、OAuth、ゲスト/匿名アカウントとアップグレード) に接続します。制限付きアプリのクライアントを構築するとき、またはエンド ユーザーのサインイン方法を処理するときに使用します。制限付きスキル ファミリの一部。サーバー側のルール、関数、アクター モデルは、bounded-backend スキル内に存在し、デプロイ/ホスティング構成は、bounded-deploy 内に存在します。
