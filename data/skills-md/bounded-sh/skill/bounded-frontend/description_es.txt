Conecte una interfaz web o React Native a Bounded: el SDK @bounded-sh/client (lectura, escritura, suscripciones, consultas), interfaces estáticas alojadas y la interfaz de usuario de autenticación del usuario final (OTP de correo electrónico, OAuth, cuentas de invitado/anónimas y actualización). Úselo al crear el cliente de una aplicación Bounded o al manejar cómo inician sesión los usuarios finales. Parte de la familia de habilidades Bounded; Las reglas, funciones y el modelo de actor del lado del servidor residen en la habilidad de backend limitado y la configuración de implementación/alojamiento en la implementación limitada.
