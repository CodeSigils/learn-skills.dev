Connectez une interface Web ou React Native à Bounded : le SDK @bounded-sh/client (lectures, écritures, abonnements, requêtes), les interfaces statiques hébergées et l'interface utilisateur d'authentification de l'utilisateur final (OTP de courrier électronique, OAuth, comptes invités/anonymes et mise à niveau). À utiliser lors de la création du client d'une application Bounded ou lors de la gestion de la manière dont les utilisateurs finaux se connectent. Fait partie de la famille de compétences Bounded ; Les règles, les fonctions et le modèle d'acteur côté serveur résident dans la compétence backend limitée et la configuration de déploiement/hébergement dans le déploiement limité.
