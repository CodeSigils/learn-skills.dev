Collega un frontend Web o React Native a Bounded: l'SDK @bounded-sh/client (letture, scritture, abbonamenti, query), frontend statici ospitati e interfaccia utente di autenticazione dell'utente finale (OTP e-mail, OAuth, account ospite/anonimo e aggiornamento). Da utilizzare durante la creazione del client di un'app Bounded o la gestione della modalità di accesso degli utenti finali. Parte della famiglia di competenze Bounded; le regole, le funzioni e il modello di attore lato server risiedono nell'abilità di backend limitato e la configurazione di distribuzione/hosting in distribuzione limitata.
