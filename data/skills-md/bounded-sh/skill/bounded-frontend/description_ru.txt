Подключите веб-интерфейс или интерфейс React Native к Bounded: @bounded-sh/client SDK (чтение, запись, подписки, запросы), размещенные статические интерфейсы и пользовательский интерфейс аутентификации конечного пользователя (OTP по электронной почте, OAuth, гостевые/анонимные учетные записи и обновление). Используется при создании клиента приложения с ограниченным доступом или при обработке входа конечных пользователей. Часть семейства навыков с ограниченным доступом; правила, функции и модель актера на стороне сервера находятся в навыке ограниченного бэкэнда, а конфигурация развертывания/хостинга — в ограниченном развертывании.
