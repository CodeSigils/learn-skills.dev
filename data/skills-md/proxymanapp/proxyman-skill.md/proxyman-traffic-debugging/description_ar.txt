استخدم Proxyman MCP لفحص وتصحيح حركة مرور HTTP/HTTPS/WebSocket التي تم التقاطها وتشغيل Proxyman من خلال جميع إجراءات MCP. استخدم هذه المهارة عندما يحتاج الوكيل إلى تحليل حركة المرور، أو تشخيص الالتقاط المفقود، أو إدارة القواعد، أو استخدام الإنشاء، أو فحص WebSockets، أو تثبيت الشهادات، أو التحكم في إعدادات الوكيل، أو استخدام إرشادات الإعداد، أو تدفقات التصدير، أو إنشاء تعليمات برمجية، أو تشغيل عمليات أتمتة Proxyman، أو استكشاف أخطاء Proxyman MCP وإصلاحها.
