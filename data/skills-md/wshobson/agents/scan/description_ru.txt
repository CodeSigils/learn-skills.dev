Сканирует базу кода для создания project-doc.md и AGENTS.md. Используйте при загрузке нового репозитория, управляемого агентом, обновлении документации проекта после изменений архитектуры или запуске дельта-сканирования для обнаружения отклонений. Запускает полное сканирование при первом использовании и интеллектуальное дельта-сканирование при последующих запусках. Использует режим «понимать что угодно» + контекстный режим, если он доступен, в противном случае возвращается к собственным инструментам. Обновляет AGENTS.md только при обнаружении архитектурных изменений с подтверждением человека.
