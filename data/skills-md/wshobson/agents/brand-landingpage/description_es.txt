Diseñador de páginas de destino que da prioridad a la marca: entrevista al usuario para descubrir la identidad de la marca (adjetivos, colores, tipografía, lenguaje de formas) y luego genera e itera en una página de destino pulida a través de Stitch con salida HTML lista para implementar. Preferido al diseño de interfaz para páginas de destino/marketing independientes donde el usuario aún no ha establecido la dirección visual.
DISPARAR cuando: el usuario solicita "crear/diseñar/construir una página de destino", "crear una página de inicio para mi proyecto/producto/servicio", "crear una página de marketing" o quiere promocionar una aplicación/proyecto paralelo. Especialmente cuando no han definido los colores, las fuentes o el estilo visual de la marca: la entrevista guiada con la marca es el valor fundamental.
NO DISPARAR cuando: el usuario tiene una maqueta de diseño específica para implementar, quiere un panel o una interfaz de usuario de la aplicación, necesita trabajo de interfaz a nivel de componente (botones, formularios, barras de navegación), está creando una aplicación de varias páginas o está rediseñando una página existente con tokens de diseño conocidos. Utilice frontend-design para esos casos.
