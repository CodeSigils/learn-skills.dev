مصمم الصفحة المقصودة للعلامة التجارية أولاً - يجري مقابلات مع المستخدم لاكتشاف هوية العلامة التجارية (الصفات، والألوان، والطباعة، ولغة الشكل)، ثم يقوم بإنشاء صفحة مقصودة مصقولة وتكرارها عبر Stitch باستخدام مخرجات HTML جاهزة للنشر. يُفضل على تصميم الواجهة الأمامية للصفحات المقصودة/التسويقية المستقلة حيث لم يحدد المستخدم اتجاهًا مرئيًا بعد.
يتم تشغيله عندما: يطلب المستخدم "إنشاء/تصميم/إنشاء صفحة مقصودة"، أو "إنشاء صفحة رئيسية لمشروعي/منتجي/خدمتي"، أو "إنشاء صفحة تسويق"، أو يريد الترويج لتطبيق/مشروع جانبي. خاصة عندما لا يتم تحديد ألوان العلامة التجارية أو الخطوط أو النمط المرئي، فإن المقابلة الموجهة للعلامة التجارية هي القيمة الأساسية.
لا تقم بالتشغيل عندما: يكون لدى المستخدم نموذج تصميم محدد للتنفيذ، أو يريد لوحة معلومات أو واجهة مستخدم للتطبيق، أو يحتاج إلى عمل الواجهة الأمامية على مستوى المكونات (الأزرار، النماذج، أشرطة التنقل)، أو ينشئ تطبيقًا متعدد الصفحات، أو يعيد تصميم صفحة موجودة برموز تصميم معروفة. استخدم تصميم الواجهة الأمامية لتلك الحالات.
