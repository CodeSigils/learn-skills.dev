Binance USDS-M Contract Grid Hunter. Filterung nach zwei Kategorien (kürzlich seitwärts gelistete Münzen + Arbitrage mit hoher Volatilität) → geometrisches neutrales Gitter. Alle Daten werden in Echtzeit von der offiziellen API von Binance abgerufen; Es ist der KI strengstens untersagt, Werte zu generieren. Auslöserphrasen: kürzlich gelistetes Grid, Arbitrage mit hoher Volatilität, Grid Hunter.
