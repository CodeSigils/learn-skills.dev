Análisis farmacocinético (PK) de datos de concentración-tiempo: análisis no compartimental (NCA) para Cmax, Tmax, AUC (0-t y 0-∞), vida media terminal, aclaramiento (CL), volumen de distribución (Vd), MRT y biodisponibilidad absoluta (F). También herrajes de un compartimento. Úselo cuando tenga concentraciones de fármaco en plasma/suero a lo largo del tiempo después de una dosis y necesite parámetros farmacocinéticos, o para calcular la biodisponibilidad a partir de las AUC intravenosas + orales. NO para la predicción de propiedades ADMET a partir de la estructura (use tooluniverse-admet-prediction).
