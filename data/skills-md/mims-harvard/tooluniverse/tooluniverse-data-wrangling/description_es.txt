Referencia de acceso universal a datos para la investigación científica. Enseña cómo descargar datos en masa, analizar cualquier formato de archivo científico (VCF, h5ad, mzML, PDB, FASTA, XPT, NIfTI y más de 30), paginar API REST y manejar la autenticación. Cubre 24 patrones de API de dominio en TODAS las fuentes de datos de ciencias biológicas: genómica, proteómica, clínica, imágenes, ecología y más. Utilice esta habilidad siempre que necesite descargar datos sin procesar, analizar un formato de archivo, acceder a una API masiva, escribir un flujo de trabajo de recuperación de datos de varios pasos o cuando una herramienta ToolUniverse devuelva metadatos pero necesite los datos reales. Utilícelo también cuando la fuente de datos no tenga ninguna herramienta ToolUniverse. Incluso si el usuario no dice "disputación de datos", si su tarea requiere obtener datos de una base de datos científica o analizar un formato de archivo científico, esta es la habilidad que debe utilizar.
