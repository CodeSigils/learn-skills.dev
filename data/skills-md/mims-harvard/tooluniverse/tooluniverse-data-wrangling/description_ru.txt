Универсальный справочник по доступу к данным для научных исследований. Обучает загрузке больших объемов данных, анализу файлов любого научного формата (VCF, h5ad, mzML, PDB, FASTA, XPT, NIfTI и более 30 других), разбиению на страницы REST API и обработке аутентификации. Охватывает 24 доменных шаблона API для ВСЕХ источников данных в области медико-биологических наук — геномики, протеомики, клиники, визуализации, экологии и т. д. Используйте этот навык всякий раз, когда вам нужно загрузить необработанные данные, проанализировать формат файла, получить доступ к массовому API, написать многоэтапный рабочий процесс получения данных или когда инструмент ToolUniverse возвращает метаданные, но вам нужны фактические данные. Также используйте, если в источнике данных вообще нет инструмента ToolUniverse. Даже если пользователь не говорит «обработка данных» — если его задача требует получения данных из научной базы данных или анализа научного формата файла, этот навык можно использовать.
