과학 연구를 위한 범용 데이터 액세스 참조 자료입니다. 대량 데이터를 다운로드하고, 과학적인 파일 형식(VCF, h5ad, mzML, PDB, FASTA, XPT, NIfTI 등 30개 이상)을 구문 분석하고, REST API에 페이지를 매기고, 인증을 처리하는 방법을 가르칩니다. 유전체학, 단백질체학, 임상, 이미징, 생태학 등 모든 생명 과학 데이터 소스에 걸쳐 24개의 도메인 API 패턴을 다룹니다. 원시 데이터를 다운로드하고, 파일 형식을 구문 분석하고, 대량 API에 액세스하고, 다단계 데이터 검색 워크플로를 작성해야 하거나 ToolUniverse 도구가 메타데이터를 반환하지만 실제 데이터가 필요한 경우 언제든지 이 기술을 사용하세요. 데이터 소스에 ToolUniverse 도구가 전혀 없는 경우에도 사용합니다. 사용자가 "데이터 랭글링"이라고 말하지 않더라도 과학 데이터베이스에서 데이터를 가져오거나 과학 파일 형식을 구문 분석하는 작업이 필요한 경우 이 기술을 사용할 수 있습니다.
