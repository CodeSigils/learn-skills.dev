科学研究的通用数据访问参考。教授如何下载批量数据、解析任何科学文件格式（VCF、h5ad、mzML、PDB、FASTA、XPT、NIfTI 等 30 多种）、对 REST API 进行分页以及处理身份验证。涵盖所有生命科学数据源的 24 个领域 API 模式——基因组学、蛋白质组学、临床、成像、生态学等。当您需要下载原始数据、解析文件格式、访问批量 API、编写多步骤数据检索工作流程时，或者当 ToolUniverse 工具返回元数据但您需要实际数据时，请使用此技能。当数据源根本没有 ToolUniverse 工具时也可使用。即使用户没有说“数据整理”——如果他们的任务需要从科学数据库获取数据或解析科学文件格式，这就是可以使用的技能。
