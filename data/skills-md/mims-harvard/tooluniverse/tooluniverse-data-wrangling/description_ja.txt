科学研究のためのユニバーサルデータアクセスリファレンス。バルク データのダウンロード、科学ファイル形式 (VCF、h5ad、mzML、PDB、FASTA、XPT、NIfTI、その他 30 以上) の解析、REST API のページ分割、および認証の処理方法を説明します。ゲノミクス、プロテオミクス、臨床、イメージング、生態学など、すべてのライフ サイエンス データ ソースにわたる 24 のドメイン API パターンをカバーします。このスキルは、生データのダウンロード、ファイル形式の解析、一括 API へのアクセス、複数ステップのデータ取得ワークフローの作成が必要な場合、または ToolUniverse ツールがメタデータを返すが実際のデータが必要な場合に使用します。データ ソースに ToolUniverse ツールがまったくない場合にも使用します。ユーザーが「データのラングリング」とは言わなくても、タスクで科学データベースからデータを取得したり、科学ファイル形式を解析したりする必要がある場合、これは使用するスキルです。
