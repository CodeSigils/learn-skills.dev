科學研究的通用資料存取參考。教授如何下載批次資料、解析任何科學檔案格式（VCF、h5ad、mzML、PDB、FASTA、XPT、NIfTI 等 30 多種）、對 REST API 進行分頁以及處理驗證。涵蓋所有生命科學資料來源的 24 個領域 API 模式—基因體學、蛋白質體學、臨床、影像學、生態學等。當您需要下載原始資料、解析文件格式、存取批次 API、編寫多步驟資料擷取工作流程時，或當 ToolUniverse 工具傳回元資料但您需要實際資料時，請使用此技能。當資料來源根本沒有 ToolUniverse 工具時也可使用。即使用戶沒有說「資料整理」——如果他們的任務需要從科學資料庫取得資料或解析科學文件格式，這就是可以使用的技能。
