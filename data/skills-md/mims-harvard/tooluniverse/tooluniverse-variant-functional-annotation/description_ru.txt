Комплексная функциональная аннотация вариантов белка — патогенность, популяционная частота, структурный контекст и клиническое значение. Интегрирует ProtVar (map_variant, get_function, get_population) для картирования на уровне белка и структурного контекста, ClinVar для клинических классификаций, gnomAD для частоты популяций с данными о происхождении, CADD для оценок вредоносности и ClinGen для достоверности генных заболеваний. Создает структурированный вариант аннотационного отчета с оценкой доказательств. Используйте, когда вас спрашивают о влиянии варианта белка, патогенности миссенс-варианта, аннотации ProtVar, функциональном контексте варианта или объединении популяционных и структурных данных для варианта.
