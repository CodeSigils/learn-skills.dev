Подтвердите предиктор варианта-эффекта (AlphaMissense, ESM-C SAE, логиты ESM, EVE, оценки сохранения или любой числовой показатель для каждого варианта) на основе экспериментальных данных глубокого мутационного сканирования (DMS). Вычисляет оценки предикторов для каждого варианта, разделяет варианты на нейтральные и разрушительные группы по эффекту DMS, запускает U-тест Манна-Уитни для оценок предикторов и проверяет пороги стратификации для обеспечения устойчивости. Используйте, когда вам нужно узнать, отслеживают ли оценки предиктора реальные функциональные нарушения определенного белка.
