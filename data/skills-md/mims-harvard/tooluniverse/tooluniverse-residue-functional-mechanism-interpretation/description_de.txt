Akzeptiert Rückstände aus jeder Quelle: DMS-Hotspots (Top-K nach maximalem Effekt), wiederkehrende ClinVar-Varianten, in der Literatur gemeldete Hot-Regionen, evolutionär konservierte Positionen oder vom Benutzer kuratierte Listen. Gibt einen Mechanismusaufruf pro Cluster zurück: katalytisch / Ligandenbindung / Schnittstelle / Strukturkern / PTM / regulatorisch / unbekannt.
