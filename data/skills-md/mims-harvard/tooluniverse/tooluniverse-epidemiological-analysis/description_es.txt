Análisis de datos epidemiológicos de un extremo a otro: desde la pregunta de investigación hasta el informe estadístico. Cubre la evaluación del diseño del estudio, el descubrimiento y descarga de conjuntos de datos, la discusión de datos, el ajuste de factores de confusión, el modelado de regresión, el análisis de sensibilidad, la visualización y la interpretación biológica. Integra herramientas ToolUniverse para el descubrimiento de conjuntos de datos, búsqueda de literatura y contexto biológico con la ejecución de código Python para el análisis de datos. Úselo siempre que los usuarios soliciten analizar datos de salud, estudiar factores de riesgo de enfermedades, evaluar las relaciones exposición-resultado o realizar epidemiología observacional. Utilícelo también cuando los usuarios quieran ejecutar una regresión sobre datos clínicos/de encuestas, calcular los odds ratios o los riesgos ratios de un conjunto de datos, ajustar los factores de confusión o producir una Tabla 1. Si la tarea implica descargar un conjunto de datos de salud y ejecutar un análisis estadístico sobre él, esta es la habilidad adecuada.
