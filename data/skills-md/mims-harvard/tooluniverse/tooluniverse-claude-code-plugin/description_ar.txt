قم بتثبيت البرنامج الإضافي ToolUniverse Claude Code في خطوة واحدة - يزود خادم MCP بأكثر من 1000 أداة علمية، و115 مهارة بحثية، وأوامر شرطة مائلة، وخطافات، ووكيل البحث. يُستخدم لتثبيت المكون الإضافي لأول مرة، أو استكشاف أخطاء عدم تحميل المكون الإضافي وإصلاحها، أو التحقق من اتصال خادم MCP، أو إدراج متطلبات مفتاح واجهة برمجة التطبيقات، أو تكوين التحديث التلقائي.
