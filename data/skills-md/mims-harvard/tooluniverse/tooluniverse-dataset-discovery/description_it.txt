Trova e valuta set di dati di ricerca per qualsiasi domanda scientifica. Insegna come ragionare sulle esigenze dei dati, effettuare ricerche negli archivi pubblici, valutare l'idoneità dei set di dati e identificare i requisiti di accesso. Da utilizzare ogni volta che gli utenti chiedono di trovare dati, cercare set di dati, identificare studi di coorte o necessitano di dati per l'analisi. Da utilizzare anche quando gli utenti chiedono informazioni su un sondaggio o un gruppo specifico (NHANES, HRS, UK Biobank, TCGA, ecc.), quando vogliono sapere quali dati esistono per una domanda di ricerca o quando devono confrontare le fonti di dati disponibili. Se l'utente menziona "dove posso ottenere i dati" o "esiste un set di dati per X", questa è la competenza giusta.
