Encuentre y evalúe conjuntos de datos de investigación para cualquier pregunta científica. Enseña cómo razonar sobre las necesidades de datos, buscar en repositorios públicos, evaluar la idoneidad de los conjuntos de datos e identificar los requisitos de acceso. Úselo siempre que los usuarios soliciten buscar datos, buscar conjuntos de datos, identificar estudios de cohortes o necesiten datos para análisis. Utilícelo también cuando los usuarios pregunten sobre una encuesta o cohorte específica (NHANES, HRS, UK Biobank, TCGA, etc.), cuando quieran saber qué datos existen para una pregunta de investigación o cuando necesiten comparar fuentes de datos disponibles. Si el usuario menciona "¿dónde puedo obtener datos" o "hay un conjunto de datos para X", esta es la habilidad adecuada.
