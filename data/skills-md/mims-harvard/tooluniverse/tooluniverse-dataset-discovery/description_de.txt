Finden und bewerten Sie Forschungsdatensätze für jede wissenschaftliche Fragestellung. Lehrt, wie man über Datenanforderungen nachdenkt, öffentliche Repositories durchsucht, die Fitness von Datensätzen bewertet und Zugriffsanforderungen ermittelt. Verwenden Sie es immer dann, wenn Benutzer nach Daten suchen, nach Datensätzen suchen, Kohortenstudien identifizieren oder Daten zur Analyse benötigen. Verwenden Sie es auch, wenn Benutzer nach einer bestimmten Umfrage oder Kohorte fragen (NHANES, HRS, UK Biobank, TCGA usw.), wenn sie wissen möchten, welche Daten für eine Forschungsfrage vorhanden sind, oder wenn sie verfügbare Datenquellen vergleichen müssen. Wenn der Benutzer „Wo kann ich Daten bekommen“ oder „Gibt es einen Datensatz für X“ erwähnt, ist dies die richtige Fähigkeit.
