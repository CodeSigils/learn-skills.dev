Es organisiert die Codestruktur, Duplizierung, Benennung und Dateiverantwortung, während das aktuelle Verhalten unverändert bleibt und keine neuen Funktionen hinzugefügt werden. Es wird verwendet, wenn der Benutzer sagt: „Aufräumen“, „Umgestalten“, „Der Code ist unübersichtlich“ oder „Struktur verbessern, ohne Funktionalität hinzuzufügen“.
