Для каждого проекта установите значения по умолчанию для локального местоположения документа, который будет читать Starter Skills, команды выполнения, метода доступа и разделов Starter Skills в AGENTS.md и CLAUDE.md. Если вы просто введете `/setup-project`, он сразу же использует настройки по умолчанию, а если вы введете `/setup-project <description>`, он будет включать описание.
