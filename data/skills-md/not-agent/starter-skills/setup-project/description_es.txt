Para cada proyecto, establezca los valores predeterminados para la ubicación del documento local que leerá Starter Skills, el comando de ejecución, el método de acceso y las secciones Starter Skills de AGENTS.md y CLAUDE.md. Si simplemente ingresa `/setup-project`, inmediatamente usa la configuración predeterminada, y si ingresa `/setup-project <descripción>`, incorpora la descripción.
