Pour chaque projet, définissez les valeurs par défaut pour l'emplacement du document local que Starter Skills lira, la commande d'exécution, la méthode d'accès et les sections Starter Skills d'AGENTS.md et CLAUDE.md. Si vous entrez simplement `/setup-project`, il utilise immédiatement les paramètres par défaut, et si vous entrez `/setup-project <description>`, il intègre la description.
