A mitad de un proyecto, verifique si documentos como `PRD.md`, `TODO.md`, `CONTEXT.md`, `DESIGN.md`, `README.md`, `AGENTS.md` y `CLAUDE.md` no están sincronizados con la implementación actual y alinéelos. Utilícelo cuando el usuario diga "Organizar los documentos", "Reflejar el estado actual", "Actualizar TODO" o "Hagamos una revisión intermedia".
