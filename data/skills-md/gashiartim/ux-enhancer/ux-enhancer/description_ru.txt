Рефакторинг компонентов React для удобства использования с использованием принципов Стива Круга «Не заставляйте меня думать» — визуальная иерархия, макет, оптимизированный для сканирования, безжалостное сокращение количества копий, однозначные призывы к действию и правильные состояния загрузки/пустоты/ошибки. Используйте, когда пользователь делится компонентом React и просит улучшить UX, снизить когнитивную нагрузку, упростить текст, исправить загроможденные макеты, уточнить навигацию или сделать интерфейс более интуитивным. Триггеры: «улучшить UX», «юзабилити-аудит», «упростить это», «слишком много текста», «сделать чище», «пользователи запутались», «применить Круг». Активно используйте на страницах настроек, формах, модальных окнах, навигации и любом рабочем процессе, ориентированном на задачи. Пропустите задачи только для серверной части, только для производительности или чисто для стилизации/брендинга (вместо этого используйте дизайн внешнего интерфейса или безупречный).
