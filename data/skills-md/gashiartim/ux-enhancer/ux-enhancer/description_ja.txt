Steve Krug の「Don't Make Me Think」原則 (視覚的な階層、スキャンに最適化されたレイアウト、徹底したコピー削減、明確な CTA、適切な読み込み/空/エラー状態) を使用して、使いやすさを向上させるために React コンポーネントをリファクタリングします。ユーザーが React コンポーネントを共有し、UX の改善、認知負荷の軽減、コピーの簡略化、乱雑なレイアウトの修正、ナビゲーションの明確化、またはインターフェイスの直感的な化を求める場合に使用します。トリガー: 「UX の改善」、「ユーザビリティの監査」、「簡素化」、「テキストが多すぎる」、「すっきりさせる」、「ユーザーが混乱している」、「Krug を適用する」。設定ページ、フォーム、モーダル、ナビゲーション、およびタスク主導のワークフローで積極的に使用します。バックエンドのみ、パフォーマンスのみ、または純粋なスタイリング/ブランディング タスクの場合はスキップしてください (代わりに、frontend-design または impeccable を使用してください)。
