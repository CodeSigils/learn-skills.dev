تصميم واجهة الهاتف المحمول أولاً لواجهات مستخدم الويب والتطبيقات المحسنة باللمس وذات الشعور الأصلي. عامل التشغيل: يطلب المستخدم "تصميم للجوال"، أو "إنشاء واجهة مستخدم للجوال"، أو "جعلها متوافقة مع الجوال"، أو "إنشاء تطبيق جوال"، أو "إنشاء تخطيط جوال سريع الاستجابة"، أو "تصميم ورقة سفلية"، أو "التنقل عبر الجوال"، أو أي عمل واجهة خاصة بالجوال.
