Основные навыки графического дизайна для создания привлекательных визуальных эффектов с помощью генерации изображений Gemini 3.1 Flash и/или кода HTML/CSS/SVG. Охватывает композицию, теорию цвета, типографику, быстрое проектирование для создания изображений с помощью искусственного интеллекта и передовые методы CSS. Триггерные фразы: «создать графику», «создать визуальную картинку», «создать графику», «создать изображение», «создать иллюстрацию», «создать графику», «визуальный дизайн».
