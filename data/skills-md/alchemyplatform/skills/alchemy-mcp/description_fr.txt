Utilisez le serveur Alchemy MCP (`https://mcp.alchemy.com/mcp`) pour les données de blockchain en direct et le travail d'administration lorsque MCP est connecté à votre client AI et que la CLI Alchemy n'est PAS installée localement. Expose 159 outils sur plus de 100 chaînes pour les prix des jetons, les métadonnées NFT, les transactions, la simulation, le traçage, l'abstraction de compte, Solana DAS et la gestion des applications. À utiliser pour les requêtes en direct, l'analyse, le travail d'administration ou le travail d'agent sur machine, et non pour le code d'application envoyé en production. Pour le code d'application, utilisez la compétence « alchemy-api » (avec clé API) ou la compétence « agentic-gateway » (sans). Lorsque la CLI est également installée localement, préférez plutôt `alchemy-cli`.
