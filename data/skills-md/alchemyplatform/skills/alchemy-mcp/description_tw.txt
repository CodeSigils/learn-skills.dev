當 MCP 連接到您的 AI 用戶端且本機未安裝 Alchemy CLI 時，請使用 Alchemy MCP 伺服器（https://mcp.alchemy.com/mcp）進行即時區塊鏈資料和管理工作。提供 100 多個鏈的 159 個工具，用於代幣價格、NFT 元資料、交易、模擬、追蹤、帳戶抽象化、Solana DAS 和應用程式管理。用於即時查詢、分析、管理工作或機上代理工作 - 不適用於交付生產的應用程式程式碼。對於應用程式程式碼，請使用“alchemy-api”技能（含 API 金鑰）或“agentic-gateway”技能（不含）。當 CLI 也安裝在本地時，首選“alchemy-cli”。
