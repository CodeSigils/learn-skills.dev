Utilizza il server Alchemy MCP (`https://mcp.alchemy.com/mcp`) per dati blockchain in tempo reale e lavoro di amministrazione quando MCP è collegato al tuo client AI e la CLI Alchemy NON è installata localmente. Espone 159 strumenti in oltre 100 catene per prezzi di token, metadati NFT, transazioni, simulazione, tracciamento, astrazione di account, Solana DAS e gestione delle app. Utilizzalo per query in tempo reale, analisi, lavoro di amministrazione o lavoro di agenti sul computer, non per il codice dell'applicazione inviato alla produzione. Per il codice dell'applicazione, utilizza la skill "alchemy-api" (con chiave API) o la skill "agentic-gateway" (senza). Quando la CLI è installata anche localmente, preferisci invece `alchemy-cli`.
