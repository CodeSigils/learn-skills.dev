Utilice el servidor Alchemy MCP (`https://mcp.alchemy.com/mcp`) para datos de blockchain en vivo y trabajo administrativo cuando MCP esté conectado a su cliente AI y Alchemy CLI NO esté instalado localmente. Expone 159 herramientas en más de 100 cadenas para precios de tokens, metadatos NFT, transacciones, simulación, seguimiento, abstracción de cuentas, Solana DAS y gestión de aplicaciones. Úselo para consultas en vivo, análisis, trabajo administrativo o trabajo de agente en la máquina, no para código de aplicación que se envía a producción. Para el código de la aplicación, utilice la habilidad `alchemy-api` (con clave API) o la habilidad `agentic-gateway` (sin). Cuando la CLI también esté instalada localmente, prefiera `alchemy-cli`.
