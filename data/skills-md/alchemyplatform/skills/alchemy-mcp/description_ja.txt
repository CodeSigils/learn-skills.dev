MCP が AI クライアントに接続されており、Alchemy CLI がローカルにインストールされていない場合は、ライブ ブロックチェーン データと管理作業に Alchemy MCP サーバー (`https://mcp.alchemy.com/mcp`) を使用します。トークン価格、NFT メタデータ、トランザクション、シミュレーション、トレース、アカウント抽象化、Solana DAS、アプリ管理のための 100 以上のチェーンにわたる 159 のツールを公開します。運用環境に出荷されるアプリケーション コードではなく、ライブ クエリ、分析、管理作業、またはオンマシン エージェントの作業に使用します。アプリケーション コードの場合は、「alchemy-api」スキル (API キーあり) または「agentic-gateway」スキル (なし) を使用します。 CLI もローカルにインストールされている場合は、代わりに「alchemy-cli」を優先します。
