Используйте сервер Alchemy MCP (https://mcp.alchemy.com/mcp) для живых данных блокчейна и работы администратора, когда MCP подключен к вашему AI-клиенту, а интерфейс командной строки Alchemy НЕ установлен локально. Предоставляет 159 инструментов в более чем 100 цепочках для цен на токены, метаданных NFT, транзакций, моделирования, отслеживания, абстракции учетных записей, Solana DAS и управления приложениями. Используйте для запросов в реальном времени, анализа, работы администратора или работы агента на компьютере, а не для кода приложения, который отправляется в рабочую среду. Для кода приложения используйте навык «alchemy-api» (с ключом API) или навык «agent-gateway» (без него). Если CLI также установлен локально, вместо этого отдайте предпочтение alchemy-cli.
