將 Claude Code 技能或斜線命令的執行流程呈現為可點擊的互動式 HTML 流程圖 - 顯示步驟如何連結、每個步驟執行哪個命令、輸入和輸出、故障模式，並在每個步驟上提供一鍵式按鈕以將其移交給 /dbg 以單獨運行該步驟。當使用者想要查看/視覺化/繪製/澄清特定技能或命令的流程和步驟時，例如“skillviz cpi”、“繪製 cpi 流程”、“技能可視化”、“此命令的流程圖”、“可視化技能選擇器如何工作”、“此命令有哪些步驟”，或者當他們嘗試調試技能的特定步驟時，應該觸發它。範圍僅限於**現有的克勞德代碼技能/命令執行流程**——不是任意系統/架構/代碼的通用圖（為此使用創建美人魚圖），也不是對技能用途的散文解釋。
