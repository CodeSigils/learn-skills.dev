Render the execution flow of a Claude Code skill or slash command as a clickable interactive HTML flowchart—showing how the steps are linked, which command runs at each step, inputs and outputs, failure modes, and providing a one‑click button on each step to hand it over to /dbg to run that step alone. It should be triggered when a user wants to view/visualize/draw/clarify the flow and steps of a specific skill or command, e.g., “skillviz cpi”, “draw the cpi flow”, “skill visualization”, “flowchart for this command”, “visualize how skill‑selector works”, “what steps does this command have”, or when they are trying to debug a particular step of a skill. The scope is limited to **existing Claude Code skill/command execution flows**—not a generic diagram of arbitrary systems/architectures/code (use creating‑mermaid‑diagrams for that), and not a prose explanation of what a skill does.
