将 Claude Code 技能或斜线命令的执行流程呈现为可点击的交互式 HTML 流程图 - 显示步骤如何链接、每个步骤运行哪个命令、输入和输出、故障模式，并在每个步骤上提供一键式按钮以将其移交给 /dbg 以单独运行该步骤。当用户想要查看/可视化/绘制/澄清特定技能或命令的流程和步骤时，例如“skillviz cpi”、“绘制 cpi 流程”、“技能可视化”、“此命令的流程图”、“可视化技能选择器如何工作”、“此命令有哪些步骤”，或者当他们尝试调试技能的特定步骤时，应该触发它。范围仅限于**现有的克劳德代码技能/命令执行流程**——不是任意系统/架构/代码的通用图（为此使用创建美人鱼图），也不是对技能用途的散文解释。
