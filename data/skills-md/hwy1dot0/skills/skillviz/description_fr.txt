Restituez le flux d'exécution d'une compétence Claude Code ou d'une commande slash sous la forme d'un organigramme HTML interactif cliquable, montrant comment les étapes sont liées, quelle commande s'exécute à chaque étape, les entrées et sorties, les modes d'échec et fournissant un bouton en un clic sur chaque étape pour le transmettre à/dbg pour exécuter cette étape seule. Il doit être déclenché lorsqu'un utilisateur souhaite afficher/visualiser/dessiner/clarifier le flux et les étapes d'une compétence ou d'une commande spécifique, par exemple, "skillviz cpi", "dessiner le flux cpi", "visualisation des compétences", "organigramme pour cette commande", "visualiser le fonctionnement du sélecteur de compétences", "quelles sont les étapes de cette commande", ou lorsqu'il essaie de déboguer une étape particulière d'une compétence. La portée est limitée aux **flux d'exécution de compétences/commandes Claude Code existants** — et non à un diagramme générique de systèmes/architectures/codes arbitraires (utilisez la création de diagrammes-sirènes pour cela), et non à une explication en prose de ce que fait une compétence.
