Represente el flujo de ejecución de una habilidad de Claude Code o un comando de barra diagonal como un diagrama de flujo HTML interactivo en el que se puede hacer clic, que muestra cómo se vinculan los pasos, qué comando se ejecuta en cada paso, entradas y salidas, modos de falla y proporciona un botón de un solo clic en cada paso para entregárselo a/dbg para ejecutar ese paso solo. Debe activarse cuando un usuario desea ver/visualizar/dibujar/aclarar el flujo y los pasos de una habilidad o comando específico, por ejemplo, "skillviz cpi", "dibujar el flujo de cpi", "visualización de habilidades", "diagrama de flujo para este comando", "visualizar cómo funciona el selector de habilidades", "qué pasos tiene este comando" o cuando están intentando depurar un paso particular de una habilidad. El alcance se limita a **flujos de ejecución de comandos/habilidades de Claude Code existentes**, no a un diagrama genérico de sistemas/arquitecturas/códigos arbitrarios (use creación de diagramas de sirena para eso), ni a una explicación en prosa de lo que hace una habilidad.
