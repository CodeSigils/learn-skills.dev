Entscheiden Sie, ob Sie eine vorhandene Fähigkeit wiederverwenden, eine anpassen/zusammenstellen oder eine neue für eine bestimmte Aufgabe erstellen möchten – und wählen Sie unter den Kandidaten die Option aus, die am besten zu Ihnen passt. Verwenden Sie dies, wenn jemand im Begriff ist, eine wiederholbare Aufgabe in Angriff zu nehmen und Build vs. Wiederverwendung abwägt, fragt: „Soll ich einen Skill erstellen oder einen finden“, zwischen mehreren vorhandenen Skills auswählt, beurteilen möchte, ob ein entdeckter Skill gut genug oder vertrauenswürdig ist, oder sich nicht sicher ist, welcher Skill passt. Wird auch dann ausgelöst, wenn das Wort „Fähigkeit“ nicht verwendet wird, der Benutzer jedoch eindeutig versucht, Werkzeuge für eine wiederkehrende Aufgabe zu beschaffen oder auszuwählen. Lösen Sie keine einmaligen oder trivialen Aufgaben aus, die schneller direkt erledigt werden können.
