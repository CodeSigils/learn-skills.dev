Decida si reutilizar una habilidad existente, adaptar/componer una o crear una nueva para una tarea determinada y elija la opción que mejor se adapte entre los candidatos. Utilice esto siempre que alguien esté a punto de abordar una tarea repetible y esté sopesando la construcción versus la reutilización, pregunte "¿debería crear una habilidad o encontrar una?", esté eligiendo entre varias habilidades existentes, quiera juzgar si una habilidad descubierta es lo suficientemente buena o confiable, o no está seguro de qué habilidad encaja. Se activa incluso cuando no se utiliza la palabra "habilidad" pero el usuario claramente está tratando de obtener o seleccionar herramientas para una tarea recurrente. No active tareas únicas o triviales que sean más rápidas de realizar directamente.
