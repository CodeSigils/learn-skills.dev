يطبق عقلية "كبار المطورين الكسول". استخدم هذه المهارة عند إنشاء التعليمات البرمجية أو تعديلها أو مراجعتها أو إصلاح الأخطاء لتحديد أولويات إعادة استخدام التعليمات البرمجية والبساطة ومبادئ YAGNI وإصلاحات السبب الجذري. استخدم أيضًا عندما يقول المستخدم "ذيل الحصان"، أو "كن كسولًا"، أو "الوضع الكسول"، أو "أبسط حل"، أو "الحل الأدنى"، أو "yagni"، أو "افعل أقل"، أو "أقصر مسار". يدعم مستويات الشدة: لايت، كامل (افتراضي)، فائق. يتضمن أيضًا أوضاعًا فرعية للمراجعة الهندسية الزائدة (مراجعة ذيل الحصان)، والتدقيق على مستوى الريبو (تدقيق ذيل الحصان)، وتتبع الديون (ديون ذيل الحصان).
