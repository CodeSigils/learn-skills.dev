Проконсультируйтесь с openai/gpt-5.4 (или другой моделью) через интерфейс командной строки OpenCode для получения второго мнения. Поддерживает одноразовые вопросы, сеансы многоэтапного диалога и консультации агента BMAD. Используйте этот навык ПРОАКТИВНО — не ждите, пока пользователь явно спросит второе мнение. Запускайте его при принятии архитектурных решений или компромиссных решениях при проектировании, когда пользователь не уверен в подходе, во время сложной отладки, где может помочь свежий взгляд, при проверке критических путей кода (безопасность, целостность данных, параллелизм), когда существует несколько допустимых решений и лучший выбор неясен, или при проверке важных технических решений перед реализацией. Даже если пользователь не упоминает «второе мнение» или «GPT», применяйте этот навык всякий раз, когда внешний взгляд может существенно улучшить результат — особенно для необратимых решений, таких как проектирование схемы, контракты API или выбор архитектуры. Использует флаг --variant для сопоставления усилий по рассуждению со сложностью задачи (xhigh для архитектуры, low для быстрых проверок).
