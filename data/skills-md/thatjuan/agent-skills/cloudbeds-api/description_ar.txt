خبرة واجهة برمجة التطبيقات للضيافة في Cloudbeds لبناء إدارة الممتلكات والحجز والمدفوعات والمحاسبة وتكامل القنوات. يُستخدم عند استدعاء التعليمات البرمجية `api.cloudbeds.com` أو `hotels.cloudbeds.com` أو `api. Payments.cloudbeds.com` أو استيراد Cloudbeds SDK؛ عندما يسأل المستخدم عن Cloudbeds PMS أو الحجوزات أو خطط الأسعار أو خطافات الويب أو Pay-By-Link أو Payments Vault أو Accounting API أو Data Insights أو Fiscal Documents أو Group Profile APIs؛ عند المصادقة باستخدام مفاتيح واجهة برمجة التطبيقات "cbat_" المسبوقة أو OAuth 2.0 مقابل Cloudbeds؛ عند الاشتراك في خطافات الويب الخاصة بـ Cloudbeds أو العمل مع "postReservation"، أو "getAvailableRoomTypes"، أو "postCharge"، أو "patchRate"، أو عمليات مماثلة.
