Experiencia en API de hotelería de Cloudbeds para crear integraciones de canales, reservas, gestión de propiedades y contabilidad. Úselo cuando el código llame a `api.cloudbeds.com`, `hotels.cloudbeds.com`, `api.paids.cloudbeds.com` o importe un SDK de Cloudbeds; cuando el usuario pregunta sobre Cloudbeds PMS, reservas, planes tarifarios, webhooks, Pay-By-Link, Payments Vault, API de contabilidad, Data Insights, documentos fiscales o API de perfil de grupo; al autenticarse con claves API con el prefijo `cbat_` u OAuth 2.0 contra Cloudbeds; al suscribirse a webhooks de Cloudbeds o trabajar con `postReservation`, `getAvailableRoomTypes`, `postCharge`, `patchRate` u operaciones similares.
