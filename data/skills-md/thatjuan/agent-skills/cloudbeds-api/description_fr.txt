Expertise de l'API hôtelière de Cloudbeds pour la création d'intégrations de gestion immobilière, de réservation, de paiement, de comptabilité et de canaux. À utiliser lorsque le code appelle `api.cloudbeds.com`, `hotels.cloudbeds.com`, `api.payments.cloudbeds.com` ou importe un SDK Cloudbeds ; lorsque l'utilisateur pose des questions sur le PMS Cloudbeds, les réservations, les plans tarifaires, les webhooks, Pay-By-Link, Payments Vault, l'API de comptabilité, Data Insights, les documents fiscaux ou les API de profil de groupe ; lors de l'authentification avec des clés API préfixées par `cbat_` ou OAuth 2.0 sur Cloudbeds ; lorsque vous vous abonnez aux webhooks Cloudbeds ou travaillez avec `postReservation`, `getAvailableRoomTypes`, `postCharge`, `patchRate` ou des opérations similaires.
