Опыт Cloudbeds в области API для гостиничного бизнеса для создания интеграции управления недвижимостью, бронирования, платежей, учета и каналов. Используйте, когда код вызывает `api.cloudbeds.com`, `hotels.cloudbeds.com`, `api.pays.cloudbeds.com` или импортирует Cloudbeds SDK; когда пользователь спрашивает о Cloudbeds PMS, бронированиях, тарифных планах, веб-перехватчиках, оплате по ссылке, хранилище платежей, API бухгалтерского учета, анализе данных, финансовых документах или API профиля группы; при аутентификации с помощью ключей API с префиксом `cbat_` или OAuth 2.0 в Cloudbeds; при подписке на веб-перехватчики Cloudbeds или работе с postReservation, getAvailableRoomTypes, postCharge, patchRate или аналогичными операциями.
