プロパティ管理、予約、支払い、会計、チャネル統合を構築するための Cloudbeds ホスピタリティ API の専門知識。コードで「api.cloudbeds.com」、「hotels.cloudbeds.com」、「api.payments.cloudbeds.com」を呼び出す場合、または Cloudbeds SDK をインポートする場合に使用します。ユーザーが Cloudbeds PMS、予約、料金プラン、Webhook、Pay-By-Link、Payments Vault、Accounting API、Data Insights、FiscalDocument、または Group Profile API について質問したとき。 「cbat_」プレフィックス付きの API キーまたは OAuth 2.0 を使用して Cloudbeds に対して認証する場合。 Cloudbeds Webhook をサブスクライブするとき、または「postRegistration」、「getAvailableRoomTypes」、「postCharge」、「patchRate」、または同様の操作を操作するとき。
