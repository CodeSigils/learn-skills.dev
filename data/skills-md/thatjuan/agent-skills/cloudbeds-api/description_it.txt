Competenza nell'API di ospitalità di Cloudbeds per la creazione di integrazioni di gestione della proprietà, prenotazione, pagamenti, contabilità e canali. Da utilizzare quando il codice chiama `api.cloudbeds.com`, `hotels.cloudbeds.com`, `api.payments.cloudbeds.com` o importa un SDK Cloudbeds; quando l'utente richiede informazioni su Cloudbeds PMS, prenotazioni, piani tariffari, webhook, Pay-By-Link, Payments Vault, API di contabilità, Data Insights, Documenti fiscali o API del profilo di gruppo; durante l'autenticazione con chiavi API con prefisso `cbat_` o OAuth 2.0 contro Cloudbeds; quando ti iscrivi ai webhook Cloudbeds o lavori con "postReservation", "getAvailableRoomTypes", "postCharge", "patchRate" o operazioni simili.
