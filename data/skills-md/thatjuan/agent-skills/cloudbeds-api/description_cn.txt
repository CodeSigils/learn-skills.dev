Cloudbeds 酒店 API 专业知识用于构建物业管理、预订、支付、会计和渠道集成。当代码调用 `api.cloudbeds.com`、`hotels.cloudbeds.com`、`api. payments.cloudbeds.com` 或导入 Cloudbeds SDK 时使用；当用户询问 Cloudbeds PMS、预订、费率计划、webhooks、Pay-By-Link、Payments Vault、Accounting API、Data Insights、财务文档或 Group Profile API 时；使用带有“cbat_”前缀的 API 密钥或 OAuth 2.0 针对 Cloudbeds 进行身份验证时；订阅 Cloudbeds webhooks 或使用 `postReservation`、`getAvailableRoomTypes`、`postCharge`、`patchRate` 或类似操作时。
