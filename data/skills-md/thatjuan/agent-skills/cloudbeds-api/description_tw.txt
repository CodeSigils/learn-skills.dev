Cloudbeds 飯店 API 專業知識用於建立物業管理、預訂、支付、會計和通路整合。當程式碼呼叫 `api.cloudbeds.com`、`hotels.cloudbeds.com`、`api. payments.cloudbeds.com` 或匯入 Cloudbeds SDK 時使用；當使用者詢問 Cloudbeds PMS、預訂、費率計畫、webhooks、Pay-By-Link、Payments Vault、Accounting API、Data、files、Ay-Link、Payments Vault. OAuth 2.0 針對 Cloudbeds 進行身份驗證時；訂閱 Cloudbeds webhooks 或使用 `postReservation`、`getAvailableRoomTypes`、`postCharge`、`patchRate` 或類似操作時。
