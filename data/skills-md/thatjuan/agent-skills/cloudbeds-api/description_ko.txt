자산 관리, 예약, 결제, 회계 및 채널 통합 구축을 위한 Cloudbeds Hospitality API 전문 지식입니다. 코드가 `api.cloudbeds.com`, `hotels.cloudbeds.com`, `api.paids.cloudbeds.com`을 호출하거나 Cloudbeds SDK를 가져올 때 사용합니다. 사용자가 Cloudbeds PMS, 예약, 요금제, 웹후크, 링크별 지불, Payments Vault, 회계 API, 데이터 통찰력, 회계 문서 또는 그룹 프로필 API에 대해 묻는 경우 Cloudbeds에 대해 'cbat_' 접두사가 붙은 API 키 또는 OAuth 2.0을 사용하여 인증하는 경우 Cloudbeds 웹후크를 구독하거나 `postReservation`, `getAvailableRoomTypes`, `postCharge`, `patchRate` 또는 유사한 작업을 수행할 때.
