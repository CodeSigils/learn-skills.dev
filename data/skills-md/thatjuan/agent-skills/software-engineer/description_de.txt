Der Architekt, Entwickler und Prüfer für technische Fachthemen und Basis-Engineering-Ebene für Codierungsagenten. Wird vom Team-Ausführenden jedem Agenten zugewiesen, der Code schreibt, aktualisiert oder überprüft (die Übergabe von Architekt/Entwickler/Rezensent), oder explizit aufgerufen, um die Arbeit über die drei Linsen und acht Standards hinweg auf einem strengen technischen Niveau zu halten. Gilt gleichermaßen für neuen Code und für Änderungen an bestehendem Code. Enthält die Standards für strukturelle Einfachheit, saubere Architektur, typisierte Grenzen, Zerlegung, Wiederverwendung, domänenspezifische Praxis (Backend, Frontend, Daten, Entwickler, Sicherheit, Tests) und einen Selbstüberprüfungs-Gate-Run als Definition-of-Done. Hinzu kommen stapelspezifische Fähigkeiten wie Heroui, Drizzle-Orm und zeitliche Überlagerung.
