المهندس المعماري والمطور والمراجع الخبير في موضوع الهندسة وطبقة الهندسة الأساسية لوكلاء الترميز. يتم تعيينه بواسطة الفريق المنفذ لأي وكيل يكتب التعليمات البرمجية أو يقوم بتحديثها أو مراجعتها (تسليم المهندس المعماري/المطور/المراجع)، أو يتم استدعاؤه صراحةً، لإبقاء العمل ضمن شريط هندسي صارم عبر العدسات الثلاثة والمعايير الثمانية. ينطبق بالتساوي على التعليمات البرمجية الجديدة وعلى التغييرات في التعليمات البرمجية الموجودة. يحمل معايير البساطة الهيكلية، والهندسة المعمارية النظيفة، والحدود المكتوبة، والتحليل، وإعادة الاستخدام، والممارسة لكل مجال (الواجهة الخلفية، والواجهة الأمامية، والبيانات، والمطورين، والأمن، والاختبار)، وتشغيل بوابة المراجعة الذاتية كتعريف تم إنجازه. المهارات الخاصة بالمكدس مثل البطل والرذاذ والتراكب الزمني فوق هذه المهارات.
