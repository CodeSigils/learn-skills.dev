사용자의 로컬 호스트에 하나의 프로젝트 파일의 실제 디자인 변형을 화살표 키로 뒤집는 작은 카드 뒤에 넣은 다음 계속해서 평결을 듣습니다. 사용자가 디자인 변형, 대안 또는 방향 중에서 선택하기를 원할 때 사용합니다. 다른 히어로, 레이아웃, 팔레트, 섹션 또는 페이지를 사용해 보라고 요청합니다. 새로운 것을 디자인하고 몇 가지 테이크를 비교하고 싶습니다. 카드를 클릭했습니다(다양함, 추가 또는 완료 요청이 대기 중임). 또는 변형 세션을 계속하거나 종료하고 싶습니다. 빈 폴더(페이지 제공, 4개의 새로운 디자인 초안 작성) 및 실제 프로젝트(제자리에 있는 하나의 파일 변경), 모든 스택에서 작동합니다. 하나의 정답이 있는 단일 변경, 리팩터링 또는 비시각적 편집이 아닌 해당 파일을 편집하기만 하면 됩니다.
