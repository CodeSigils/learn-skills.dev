Mette variazioni di progettazione reali di un file di progetto sull'host locale dell'utente, dietro una piccola scheda che le gira con i tasti freccia, quindi continua ad ascoltare il loro verdetto. Utilizzare quando l'utente desidera variazioni di progettazione, alternative o indicazioni tra cui scegliere; chiede di provare un eroe, un layout, una tavolozza, una sezione o una pagina diversi; vuole progettare qualcosa di nuovo e confrontare alcune riprese; cliccato sulla carta (una variazione, un altro o una richiesta completata viene messa in coda); o desidera continuare o terminare una sessione modificata. Funziona in una cartella vuota (serve una pagina, disegna quattro nuovi progetti) e in un progetto reale (varia un file sul posto), su qualsiasi pila. Non per una singola modifica con una risposta giusta, un refactoring o una modifica non visiva: basta modificare il file per quelli.
