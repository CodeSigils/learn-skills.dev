Helfen Sie technisch nicht versierten Benutzern, Git für Office-Dateien und einfache Projekt-Snapshots zu verwenden. Verwenden Sie es, wenn Sie ein Repository initialisieren, sichere Commits vorbereiten, mit Git LFS überprüfen, was ignoriert oder verfolgt werden soll, oder ohne Arbeitsverlust zu einer älteren oder neueren Version wechseln.
