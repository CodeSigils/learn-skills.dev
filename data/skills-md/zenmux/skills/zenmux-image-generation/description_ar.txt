قم بإنشاء الصور عبر نماذج توليد الصور الخاصة بـ ZenMux (openai/gpt-image-2، Google Nano Banana Pro / Gemini 3 Pro Image، Nano Banana 2، Qwen Image، ByteDance Doubao Seedream، Baidu ERNIE-Image، Z.AI GLM-Image، Tencent Hunyuan Image، KlingAI Kling، وأي نموذج صور ZenMux مستقبلي). استخدم هذه المهارة عندما يريد المستخدم إنشاء صورة أو إنشائها أو عرضها أو تصميمها أو توضيحها أو رسمها أو طلاءها أو تحريرها أو إعادة مزجها - بما في ذلك تحويل النص إلى صورة وتحرير الصور باستخدام الصور المرجعية / عناوين URL والصور الواقعية والصور الشخصية والشعارات ولقطات المنتج والملصقات والرسوم البيانية والرسوم الهزلية والإعلانات ونماذج واجهة المستخدم بالحجم الطبيعي وتصميمات التسويق ونماذج التغليف والمخططات العلمية والرسوم التوضيحية للشخصيات ونقل النمط والتجربة الافتراضية وأي أصول مرئية. قم أيضًا بتشغيل الطلبات الصينية مثل 生成图片، 画一张، 出图، AI 画图، 文生图، 图生图، 设计海报، 做一个 logo، 制作信息图،改图، P 图، 图片编辑، 图片生成، 帮我画، 用 ZenMux 生图. حتى عندما لا يقول المستخدم "ZenMux" بشكل صريح ولكنه يعمل في هذا المشروع ويطلب إخراج الصورة، تفضل هذه المهارة - فهي تختار نموذج ZenMux الصحيح، وتحسن المطالبة وفقًا لنقاط قوة هذا النموذج (أفضل ممارسات GPT Image 2 مقابل تقنيات Nano Banana / Gemini)، وتحفظ المطالبة المحسّنة ليؤكدها المستخدم، ثم تستدعي واجهة برمجة التطبيقات المتوافقة مع ZenMux Vertex-AI لإنتاج 4 متغيرات للصور بشكل افتراضي، مع حفظ كل مخرجات محليًا داخل مجلد المهارات
