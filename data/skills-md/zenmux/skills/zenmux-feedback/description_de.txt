Senden Sie GitHub-Probleme, Funktionsanfragen, Fehlerberichte, Produktvorschläge und Feedback an das ZenMux-Repository (ZenMux/zenmux-doc). Verwenden Sie diese Fähigkeit, wann immer der Benutzer einen Fehler melden, eine Funktion anfordern, eine Produktverbesserung vorschlagen, Feedback geben, Support für ein neues Modell oder einen neuen Anbieter anfordern, ein Dokumentationsproblem melden oder seine Erfahrungen teilen möchte. Auslösen bei Phrasen wie: „Problem einreichen“, „Fehler einreichen“, „Funktionsanfrage“, „Problem melden“, „Ich habe eine Idee“, „Problem“, „提反馈“, „功能建议“, „报告bug“, „产品建议“, „提个需求“, „新增模型“, „新增供应商“, „文档问题“, „我想提个建议“, „提交建议“. Wenn der Benutzer ein ZenMux-Problem oder eine Produktidee beschreibt und von einer formellen Einreichung profitieren würde, bieten Sie proaktiv an, ihm bei der Erstellung eines Problems zu helfen.
