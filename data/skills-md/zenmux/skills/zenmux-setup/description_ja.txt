ZenMux ベース URL、API エンドポイント、API キー、ツールまたは SDK のモデル設定の構成を対話的にユーザーにガイドします。ユーザーがツールをセットアップ、構成、または ZenMux に接続したいときにこのスキルを使用します。これには、「カーソルで ZenMux をセットアップする方法」、「ベース URL は何ですか」、「ZenMux でクロード コードを構成する方法」、「Anthropic API のエンドポイント」、「API 設定の入力を手伝ってください」などの質問が含まれます。トリガー: 「configure」、「setup」、「set up」、「base url」、「endpoint」、「api key」、「接入」、「配置」、「设置」、「base url 充填什么」、「怎么充填」、「怎么接入」、「怎么配置」、「API 地址」、「接口地址」。また、ユーザーが設定コンテキストで ZenMux とともにツール名 (Cursor、Cline、Claude Code、Cherry Studio、Open-WebUI、Dify、Obsidian、Sider、Copilot、Codex、Gemini CLI、opencode など) を言及したときにもトリガーされます。ユーザーを初めてのユーザーとして扱い、段階的にガイドします。使用方法のクエリ、ドキュメントの検索、または一般的な製品の質問に対してトリガーしないでください。代わりに、zenmux-usage または zenmux-context を使用してください。
