Führen Sie Benutzer interaktiv durch die Konfiguration der ZenMux-Basis-URL, des API-Endpunkts, des API-Schlüssels und der Modelleinstellungen für jedes Tool oder SDK. Verwenden Sie diesen Skill immer dann, wenn der Benutzer ein Tool mit ZenMux EINRICHTEN, KONFIGURIEREN oder VERBINDEN möchte – einschließlich Fragen wie „Wie richte ich ZenMux in Cursor ein“, „Was ist die Basis-URL“, „Wie konfiguriere ich Claude Code mit ZenMux“, „Endpunkt für Anthropic API“ und „Helfen Sie mir, die API-Einstellungen auszufüllen“. Auslösen bei: „configure“, „setup“, „set up“, „base url“, „endpoint“, „api key“, „接入“, „配置“, „设置“, „base url 填什么“, „怎么填“, „怎么接入“, „怎么配置“, „API地址“, „接口地址“. Wird auch ausgelöst, wenn Benutzer einen Toolnamen (Cursor, Cline, Claude Code, Cherry Studio, Open-WebUI, Dify, Obsidian, Sider, Copilot, Codex, Gemini CLI, Opencode usw.) zusammen mit ZenMux in einem Konfigurationskontext erwähnen. Behandeln Sie den Benutzer wie einen Erstbenutzer und führen Sie ihn Schritt für Schritt. Lösen Sie NICHT für Nutzungsabfragen, Dokumentationssuchen oder allgemeine Produktfragen aus – verwenden Sie stattdessen zenmux-usage oder zenmux-context.
