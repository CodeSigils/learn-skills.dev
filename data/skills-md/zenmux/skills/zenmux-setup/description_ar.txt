قم بتوجيه المستخدمين بشكل تفاعلي من خلال تكوين عنوان URL الأساسي لـ ZenMux ونقطة نهاية API ومفتاح API وإعدادات النموذج لأي أداة أو SDK. استخدم هذه المهارة عندما يريد المستخدم إعداد أداة أو تكوينها أو توصيلها بـ ZenMux - بما في ذلك أسئلة مثل "كيف أقوم بإعداد ZenMux في المؤشر"، "ما هو عنوان URL الأساسي"، "كيفية تكوين Claude Code مع ZenMux"، "نقطة النهاية لـ Anthropic API"، "ساعدني في ملء إعدادات واجهة برمجة التطبيقات". تشغيل: "تكوين"، "إعداد"، "إعداد"، "عنوان url الأساسي"، "نقطة النهاية"، "مفتاح واجهة برمجة التطبيقات"، "接入"، "配置"، "设置"، "عنوان url الأساسي 填什么"، "怎么填"، "怎么接入"، "怎么配置"، "API"地址"، "接口地址". يتم تشغيله أيضًا عندما يذكر المستخدمون اسم أداة (Cursor، Cline، Claude Code، Cherry Studio، Open-WebUI، Dify، Obsidian، Sider، Copilot، Codex، Gemini CLI، opencode، وما إلى ذلك) مع ZenMux في سياق التكوين. تعامل مع المستخدم كمستخدم لأول مرة وقم بإرشاده خطوة بخطوة. لا تقم بتشغيل استعلامات الاستخدام أو عمليات البحث عن الوثائق أو الأسئلة العامة حول المنتج - استخدم zenmux-usage أو zenmux-context بدلاً من ذلك.
