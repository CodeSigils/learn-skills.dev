قم بتثبيت وتكوين سطر حالة Claude Code الذي يعرض معلومات حساب ZenMux في الوقت الفعلي: طبقة الاشتراك، واستخدام الحصة لمدة 5 ساعات و7 أيام مع أشرطة التقدم المرمزة بالألوان، ورصيد محفظة PAYG، جنبًا إلى جنب مع معلومات الجلسة القياسية (النموذج، git، السياق المتبقي). تشغيل: "خط الحالة"، "خط الحالة"، "إعداد شريط الحالة"، "إظهار ZenMux في شريط الحالة"، "تثبيت خط الحالة ZenMux"، "تكوين خط الحالة مع ZenMux"، "状态栏"، "配置状态栏"، "安装状态栏"، "مرحبا بكم في ZenMux 信息". يتم التنشيط عندما يريد المستخدم إعداد أو تثبيت أو تكوين أو تخصيص سطر حالة Claude Code الذي يتضمن بيانات حساب ZenMux. لا تقم بتشغيل الاستعلام عن الاستخدام بشكل تفاعلي (استخدم zenmux-usage)، أو المستندات (استخدم سياق zenmux)، أو الإعداد العام (استخدم zenmux-setup).
