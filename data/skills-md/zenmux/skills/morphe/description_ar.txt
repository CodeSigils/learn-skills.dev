قم ببناء ونشر مشروع Next.js أو Bigfish (@alipay/bigfish) أو Vite إلى خدمة Morphe (https://morphe.zenmux.app)، مستهدفًا وقت تشغيل linux-x64-gnu. يُستخدم عندما يطلب المستخدم نشر تطبيق Next.js أو Bigfish أو Vite أو شحنه أو نشره أو إصداره إلى Morphe، أو تشغيل "نشر morphe"، أو دفع الإصدار إلى النظام الأساسي Morphe / zenmux. يتعامل مع تسجيل الدخول، واكتشاف إطار العمل، والتحقق من صحة Next.js المستقل / تثبيت التكوين، والتفاف خادم Bigfish الثابت، والتفاف Vite SPA الثابت أو تجميع الخادم المخصص (server.ts/js)، والبناء، والضغط، وتحميل OSS، والمجموع الاختباري CRC64، وإدارة .morphe.json، ونشر استدعاء API.
