linux-x64-gnu 런타임을 대상으로 Next.js, Bigfish(@alipay/bigfish) 또는 Vite 프로젝트를 빌드하고 Morphe 서비스(https://morphe.zenmux.app)에 배포합니다. 사용자가 Next.js, Bigfish 또는 Vite 앱을 Morphe에 배포, 제공, 게시 또는 릴리스하도록 요청하거나 "morphe 배포"를 실행하거나 Morphe/zenmux 플랫폼에 빌드를 푸시할 때 사용합니다. 로그인, 프레임워크 감지, Next.js 독립 실행형 유효성 검사/구성 수정, Bigfish 정적 서버 래핑, Vite SPA 정적 래핑 또는 사용자 정의 서버(server.ts/js) esbuild 번들링, 빌드, 압축, OSS 업로드, CRC64 체크섬, .morphe.json 관리 및 배포 API 호출을 처리합니다.
