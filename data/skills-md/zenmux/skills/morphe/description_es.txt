Cree e implemente un proyecto Next.js, Bigfish (@alipay/bigfish) o Vite en el servicio Morphe (https://morphe.zenmux.app), dirigido a un tiempo de ejecución Linux-x64-gnu. Úselo cuando el usuario solicite implementar, enviar, publicar o lanzar una aplicación Next.js, Bigfish o Vite en Morphe, ejecutar "morphe desplegar" o enviar una compilación a la plataforma Morphe/zenmux. Maneja el inicio de sesión, la detección del marco, la validación independiente/corrección de configuración de Next.js, el empaquetado estático del servidor Bigfish, el empaquetado estático de Vite SPA o el empaquetado de esbuild del servidor personalizado (server.ts/js), la construcción, el comprimir, la carga de OSS, la suma de comprobación CRC64, la administración de .morphe.json y la llamada API de implementación.
