Costruisci e distribuisci un progetto Next.js, Bigfish (@alipay/bigfish) o Vite al servizio Morphe (https://morphe.zenmux.app), mirando a un runtime linux-x64-gnu. Da utilizzare quando l'utente chiede di distribuire, spedire, pubblicare o rilasciare un'app Next.js, Bigfish o Vite su Morphe, eseguire "morphe deploy" o altrimenti inviare una build alla piattaforma Morphe/zenmux. Gestisce l'accesso, il rilevamento del framework, la convalida autonoma/correzione della configurazione di Next.js, il wrapper del server statico Bigfish, il wrapper statico di Vite SPA o il raggruppamento esbuild del server personalizzato (server.ts/js), la creazione, lo zipping, il caricamento di OSS, il checksum CRC64, la gestione di .morphe.json e la chiamata API di distribuzione.
