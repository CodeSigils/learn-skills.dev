Запрашивайте данные учетной записи ZenMux в режиме реального времени через API управления: сведения о подписке, использование квоты (5 часов/7 дней/месяц), состояние учетной записи, скорость потока, баланс PAYG и стоимость за поколение. Используйте всякий раз, когда пользователь хочет ПРОВЕРИТЬ или ПОСМОТРЕТЬ текущее использование, оставшуюся квоту, кредитный баланс, скорость потока или стоимость/токены поколения. Запуск по: «проверить использование», «осталась квота», «мой баланс», «статус подписки», «скорость потока», «стоимость генерации», «бонусные кредиты», «查用量», «余额», «配额», «订阅详情», «Поток 汇率», «查一下请求花了多少», «额度还剩多少». Активируйте даже без «ZenMux», когда пользователь запрашивает данные об использовании, квоту, баланс или стоимость генерации в контексте ZenMux. НЕ запускайте триггер для документации, настройки интеграции, сравнения планов, инструкций по пополнению, устранения ошибок или написания кода — используйте zenmux-context.
