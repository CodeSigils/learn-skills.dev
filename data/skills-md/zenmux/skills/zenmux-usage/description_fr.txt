Interrogez les données du compte ZenMux en temps réel via l'API de gestion : détails de l'abonnement, utilisation du quota (5h/7j/mensuel), statut du compte, débit, solde PAYG et coût par génération. À utiliser chaque fois que l'utilisateur souhaite VÉRIFIER ou RECHERCHER l'utilisation actuelle, le quota restant, le solde créditeur, le débit ou le coût/jetons d'une génération. Déclenchez sur : "vérifier ma consommation", "quota restant", "mon solde", "statut de l'abonnement", "Débit", "coût de génération", "crédits bonus", "查用量", "余额", "配额", "订阅详情", "Flow 汇率", "查一下请求花了多少", "额度还剩多少". Activez même sans "ZenMux" lorsque l'utilisateur demande à récupérer les numéros d'utilisation, le quota, le solde ou le coût de génération dans un contexte ZenMux. Ne déclenchez PAS les documents, la configuration de l'intégration, la comparaison des plans, les instructions de recharge, le dépannage des erreurs ou l'écriture de code : utilisez zenmux-context.
