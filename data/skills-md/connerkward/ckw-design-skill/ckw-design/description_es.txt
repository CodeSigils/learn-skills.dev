Punto de entrada para el diseño frontend. Úselo SIEMPRE que cree o toque la apariencia de cualquier interfaz de usuario web (componentes, páginas, paneles, páginas de destino, React/Vue/HTML-CSS) y siempre que el usuario diga "haga que esto se vea mejor/más bonito", "arregle el espaciado/diseño" o mencione estilo, color, tipografía, fuentes, diseño responsivo, pulido o estética, incluso sin la palabra "diseño". Cargue el pensamiento de diseño como dirección; sistema de diseño para su implementación; diseño espacial para maquetación; filosofía del diseño para filosofía visual o dirección de arte.
