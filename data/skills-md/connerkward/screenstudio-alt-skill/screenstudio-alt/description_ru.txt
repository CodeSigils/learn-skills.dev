Пост-продакшн в стиле Screen-Studio для записей экрана, без головы — автоматическое ускорение в режиме ожидания, автоматическое масштабирование при кластерах щелчков, наложение нажатий клавиш, сглаженный синтетический курсор и вертикальный экспорт 9:16, который следует за действием. Используйте при доработке записи экрана/демонстрационного видео для совместного использования, когда пользователь упоминает Screen Studio, автоматическое масштабирование, ускорение в режиме ожидания или вертикальное/социальное видео из снимка экрана, а также для любой демонстрации, ориентированной на социальные сети (для них по умолчанию используется вертикальный вывод).
