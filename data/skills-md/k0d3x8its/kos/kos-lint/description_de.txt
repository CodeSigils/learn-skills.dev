Verwenden Sie diesen Skill, wenn der Benutzer sein Kodex OS Layer 1 LLM Wiki auf strukturelle Probleme überprüfen möchte. Zu den Auslösern gehören „lint kos“, „überprüfe mein Wiki“, „überprüfe das Wiki“, „finde defekte Links“ oder jede explizite Anfrage nach einem Wiki-Integritätsbericht. Der Skill überprüft, ob der Tresor seiner SCHEMA.md entspricht, dass jede Raw/-Quelle einen entsprechenden wiki/sources/-Eintrag hat, dass jeder Memobuchordner einen wiki/books/-Eintrag hat, dass Wikilinks aufgelöst werden, dass Frontmatter gültig ist und dass bit.ly-Slugs aufgelöst werden. Meldet Ergebnisse nach Schweregrad gruppiert. Nimmt keine Änderungen vor, es sei denn, der Benutzer genehmigt jede Korrektur ausdrücklich. Verwenden Sie diesen Skill nicht für die routinemäßige Aufnahme (verwenden Sie kos-ingest) oder für Inhaltsfragen (verwenden Sie kos-query).
