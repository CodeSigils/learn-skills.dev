Utilice esta habilidad cuando el usuario quiera configurar una nueva bóveda de Kodex OS Layer 1 (la capa LLM Wiki) desde cero. Los desencadenantes incluyen frases como "configurar kos", "crear una nueva bóveda de kos", "inicializar mi Kodex Wiki" o cualquier solicitud de configuración por primera vez. Esta habilidad guía al usuario para nombrar la bóveda, elegir una ubicación, estructurar la estructura del directorio (sin formato/ con las convenciones del libro de notas FL/FR/FS, wiki/ con los seis subdirectorios, salida/), instalar SCHEMA.md y conectar su agente de IA. No utilice esta habilidad si ya existe una bóveda; utilice kos-ingest, kos-query o kos-lint en su lugar. No lo utilice para la configuración de Capa 0 (Notas de campo), Capa 2 (Notion), Capa 3 (Archivo) o Capa 4 (Trello).
