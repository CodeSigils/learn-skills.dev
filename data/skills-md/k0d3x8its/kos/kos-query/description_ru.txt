Используйте этот навык, когда пользователь хочет задать вопрос, выполнить поиск или получить информацию из существующей Wiki-страницы LLM уровня 1 OS Kodex. Триггеры включают в себя «спросить кос», «что моя вики говорит об X», «найти заметки по Y», «поиск в моей вики», «что открыто на Z» или любой вопрос в стиле поиска, на который следует ответить на основе собственных собранных знаний пользователя, а не общих знаний о мире. Навык выполняет поиск по всем шести каталогам вики (источники, книги, включая подпапку _archived/, сущности, концепции, синтез, вопросы), переходит по вики-ссылкам и синтезирует ответ с цитатами на определенные вики-страницы. Отказывается фабриковать, когда вики не содержит ответа. Не используйте этот навык для добавления нового контента (используйте kos-ingest) или для проверки структуры вики (используйте kos-lint).
