يمكنك إنشاء هياكل بيانات الرسم البياني والاستعلام عنها وتحليلها باستخدام Graphology - مكتبة JavaScript/TypeScript Graph القوية ومتعددة الأغراض. استخدم هذه المهارة عندما يعمل المستخدم مع الرسوم البيانية أو الشبكات أو العقد أو الحواف في JavaScript أو TypeScript، بما في ذلك: إنشاء الشبكات الاجتماعية أو الرسوم البيانية التبعية أو الرسوم البيانية المعرفية أو شبكات التوجيه أو الهياكل الشجرية؛ تشغيل خوارزميات الرسم البياني مثل BFS، DFS، أقصر مسار (Dijkstra، A*)، أو PageRank؛ مقاييس مركزية الحوسبة؛ اكتشاف المجتمعات؛ تطبيق التخطيطات (ForceAtlas2، Force، Circular، Random)؛ استيراد/تصدير ملفات GEXF أو GraphML؛ التقديم باستخدام sigma.js؛ أو السؤال عن كيفية اجتياز أو تصفية أو تحليل أي بيانات متصلة بالشبكة. يتم تشغيله أيضًا في "علم الخط"، أو "كائن الرسم البياني"، أو "اجتياز الرسم البياني"، أو "حواف العقدة JS"، أو "تحليل الشبكة JavaScript"، أو "بيانات sigma.js"، أو أي طلب يتضمن رسومًا بيانية موجهة/غير موجهة/مختلطة في المتصفح أو Node.js.
