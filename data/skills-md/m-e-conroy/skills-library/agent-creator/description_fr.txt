Créez et affinez les fichiers de définition d'agent IA (.agent.md) avec des personnages clairs, des commandes exécutables, des exemples de style de code, une structure de projet, des flux de travail git et des limites explicites. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un nouvel agent, écrire un fichier agent.md, définir le personnage ou le manuel d'utilisation d'un agent IA, définir les limites de l'agent ou configurer les outils de l'agent d'échafaudage. Se déclenche également sur « faire de moi un agent », « définition de l'agent », « instructions de l'agent » ou toute demande visant à définir comment un assistant IA doit se comporter dans une base de code spécifique.
