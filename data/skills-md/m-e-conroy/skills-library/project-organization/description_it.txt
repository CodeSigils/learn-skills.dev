Organizza progetti web con strutture di cartelle, convenzioni di denominazione dei file e modelli di moduli chiari. Utilizza questa competenza ogni volta che l'utente chiede informazioni sulla struttura del progetto, il layout delle cartelle, dove inserire i file, le convenzioni di denominazione dei file, l'organizzazione delle directory, l'impalcatura di un nuovo progetto, i percorsi di importazione, il posizionamento dei file di configurazione o domande generali sull'architettura del progetto. Si attiva anche quando gli utenti chiedono "dove dovrei mettere questo file", "come dovrei organizzare il mio progetto" o vogliono ristrutturare una codebase esistente.
