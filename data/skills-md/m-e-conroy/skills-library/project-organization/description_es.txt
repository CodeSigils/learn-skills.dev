Organice proyectos web con estructuras de carpetas claras, convenciones de nomenclatura de archivos y patrones de módulos. Utilice esta habilidad siempre que el usuario pregunte sobre la estructura del proyecto, el diseño de las carpetas, dónde colocar los archivos, las convenciones de nomenclatura de archivos, la organización de directorios, la estructuración de un nuevo proyecto, las rutas de importación, la ubicación de los archivos de configuración o preguntas generales sobre la arquitectura del proyecto. También se activa cuando los usuarios preguntan "dónde debo colocar este archivo", "cómo debo organizar mi proyecto" o quieren reestructurar una base de código existente.
