Organisez vos projets Web avec des structures de dossiers claires, des conventions de dénomination de fichiers et des modèles de modules. Utilisez cette compétence chaque fois que l'utilisateur pose des questions sur la structure du projet, la disposition des dossiers, l'emplacement des fichiers, les conventions de dénomination des fichiers, l'organisation des répertoires, l'échafaudage d'un nouveau projet, les chemins d'importation, le placement des fichiers de configuration ou des questions générales sur l'architecture du projet. Se déclenche également lorsque les utilisateurs demandent « où dois-je placer ce fichier », « comment dois-je organiser mon projet » ou souhaitent restructurer une base de code existante.
