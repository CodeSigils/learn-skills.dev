專家級 CSS 開發，涵蓋現代佈局（Flexbox、網格、子網格、容器查詢）、CSS 巢狀、偽類和偽元素、轉換、翻譯、關鍵影格動畫、複雜動畫排序、符合 WCAG 的可存取樣式、設計令牌、現代色彩函數和引人注目的視覺設計策略。當被要求 (1) 編寫、調試或架構 CSS，(2) 使用 Flexbox、網格、子網格或容器查詢實現佈局，(3) 創建動畫、過渡、變換或動畫序列，(4) 應用 CSS 嵌套或現代選擇器，(5) 確保符合 WCAG 的樣式和可訪問的視覺設計，(6) 實現響應式或流體設計，(77)創建漸變、玻璃態、紋理或分層組合等視覺效果，或當短語如下時使用出現「樣式」、「CSS」、「樣式表」、「設計」、「佈局」、「動畫」、「變換」、「關鍵影格」、「巢狀」、「偽」、「可訪問」、「WCAG」。
