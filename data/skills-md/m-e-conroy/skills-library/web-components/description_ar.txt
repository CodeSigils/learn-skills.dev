أنشئ مكونات واجهة مستخدم مغلفة وقابلة لإعادة الاستخدام باستخدام واجهات برمجة تطبيقات Web Components الأصلية - لا يلزم وجود إطار عمل. يغطي العناصر المخصصة وShadow DOM وقوالب HTML والفتحات وعمليات رد الاتصال الخاصة بدورة الحياة والتصميم باستخدام تغليف CSS. استخدم هذه المهارة عندما يذكر المستخدم مكونات الويب، أو العناصر المخصصة، أو Shadow DOM، أو قوالب أو فتحات HTML، أو `customElements.define`، أو `attachShadow`، أو `connectedCallback`، أو عندما يريد إنشاء عناصر HTML قابلة لإعادة الاستخدام بدون أطر React أو Vue أو Angular أو غيرها. يتم تشغيله أيضًا بناءً على طلبات بنية المكونات الخالية من إطار العمل، أو مكونات Vanilla JS، أو عناصر واجهة المستخدم المغلفة.
