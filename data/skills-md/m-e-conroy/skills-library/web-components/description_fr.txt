Créez des composants d'interface utilisateur encapsulés et réutilisables à l'aide des API de composants Web natifs – aucun framework requis. Couvre les éléments personnalisés, Shadow DOM, les modèles HTML, les emplacements, les rappels de cycle de vie et le style avec l'encapsulation CSS. Utilisez cette compétence chaque fois que l'utilisateur mentionne des composants Web, des éléments personnalisés, du shadow DOM, des modèles ou des emplacements HTML, `customElements.define`, `attachShadow`, `connectedCallback` ou souhaite créer des éléments HTML réutilisables sans React, Vue, Angular ou d'autres frameworks. Se déclenche également sur les demandes d'architecture de composants sans framework, de composants Vanilla JS ou de widgets d'interface utilisateur encapsulés.
