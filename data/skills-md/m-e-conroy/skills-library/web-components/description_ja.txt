ネイティブ Web コンポーネント API を使用して、再利用可能なカプセル化された UI コンポーネントを構築します。フレームワークは必要ありません。カスタム要素、Shadow DOM、HTML テンプレート、スロット、ライフサイクル コールバック、CSS カプセル化によるスタイルについて説明します。ユーザーが Web コンポーネント、カスタム要素、Shadow DOM、HTML テンプレートまたはスロット、`customElements.define`、`attachShadow`、`connectedCallback` について言及する場合、または React、Vue、Angular、またはその他のフレームワークを使用せずに再利用可能な HTML 要素を作成したい場合には、このスキルを使用します。フレームワークフリーのコンポーネント アーキテクチャ、バニラ JS コンポーネント、またはカプセル化された UI ウィジェットのリクエストでもトリガーされます。
