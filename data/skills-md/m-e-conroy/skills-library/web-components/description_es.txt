Cree componentes de interfaz de usuario encapsulados y reutilizables utilizando API de componentes web nativos, sin necesidad de marco. Cubre elementos personalizados, Shadow DOM, plantillas HTML, ranuras, devoluciones de llamadas del ciclo de vida y estilos con encapsulación CSS. Utilice esta habilidad siempre que el usuario mencione componentes web, elementos personalizados, DOM oculto, plantillas o espacios HTML, `customElements.define`, `attachShadow`, `connectedCallback` o desee crear elementos HTML reutilizables sin React, Vue, Angular u otros marcos. También se activa ante solicitudes de arquitectura de componentes sin marco, componentes Vanilla JS o widgets de UI encapsulados.
