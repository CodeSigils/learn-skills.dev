توثيق الميزات والتحديثات الجديدة وفقًا لمعايير توثيق المشروع. يُستخدم عند إنشاء أو تحديث الوثائق الخاصة بالميزات، أو عمليات إعادة البناء المهمة، أو منطق الأعمال المعقد، أو تقارير المشروع، أو تذاكر العيوب، أو أدلة المطورين. يضمن بنية الدليل المناسبة واصطلاحات التسمية والتنسيق المتسق عبر جميع أنواع المستندات. يتم تشغيله عند طلبات كتابة المستندات، أو إنشاء تقرير، أو توثيق ميزة، أو كتابة تذكرة، أو تحديث وثائق المشروع.
