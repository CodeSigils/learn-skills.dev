Профессиональная реализация анимации с использованием GSAP (GreenSock Animation Platform). Используйте этот навык, когда пользователи запрашивают анимацию, моушн-дизайн, последовательности временной шкалы, интерактивную анимацию, поэтапное отображение, эффекты наведения или при создании анимированных компонентов, целевых страниц, сайтов-портфолио или любого другого веб-интерфейса, требующего отточенного движения. Также срабатывает при «gsap.to», «gsap.timeline», «tween», «stagger», «easing», «анимации загрузки страницы», «открытии элемента», «настройке GSAP» или всякий раз, когда пользователь хочет добавить в проект анимацию JavaScript профессионального уровня. В частности, для анимации, управляемой прокруткой, вместо этого используйте навык gsap-scrolltrigger.
