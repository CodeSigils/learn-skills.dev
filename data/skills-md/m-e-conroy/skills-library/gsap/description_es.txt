Implementación de animación profesional utilizando GSAP (GreenSock Animation Platform). Utilice esta habilidad cuando los usuarios soliciten animaciones, diseño de movimiento, secuencias de línea de tiempo, animaciones interactivas, revelaciones escalonadas, efectos de desplazamiento o cuando creen componentes animados, páginas de destino, sitios de cartera o cualquier experiencia web que necesite un movimiento pulido. También se activa en "gsap.to", "gsap.timeline", "tween", "stagger", "easing", "animación de carga de página", "revelación de elementos", "configuración de GSAP" o cuando el usuario desea agregar animación JavaScript de nivel profesional a un proyecto. Para animaciones basadas en desplazamiento específicamente, utilice la habilidad gsap-scrolltrigger.
