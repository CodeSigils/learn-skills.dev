Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine A-Frame-Szene erstellt oder daran arbeitet, A-Frame-Komponenten schreibt, WebXR-Interaktivität hinzufügt, VR-Controller einrichtet, GLTF-Modelle in A-Frame lädt, einen 360°-Viewer erstellt, ein VR-Spiel erstellt, Raycasting oder Blickinteraktionen verarbeitet oder nach einer Szene, einer Entität, einer Box, einem Himmel, AFRAME.registerComponent oder einem anderen A-Frame-Primitiv oder einer anderen API fragt. Wird auch bei „WebXR-Szene“, „VR im Web“, „Immersives Web“, „A-Frame-Entität“, „Aframe-Komponente“, „Meta Quest WebXR“, „VR-Erlebnis HTML“ oder „A-Frame-Physik“ ausgelöst.
