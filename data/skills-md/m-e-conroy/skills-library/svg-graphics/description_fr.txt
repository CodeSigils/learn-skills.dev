Créez des graphiques et des animations SVG évolutifs, accessibles et adaptés aux thèmes pour le Web : icônes, bannières, diagrammes, illustrations, badges et visuels interactifs. Utilisez cette compétence lors de la création de fichiers SVG, de l'animation de SVG avec CSS ou SMIL, du morphing de chemin, du suivi de chemin de mouvement, de la création de SVG interactif qui répond aux clics sans JavaScript, du dessin de sujets du monde réel (animaux, personnes, objets) sous forme d'illustrations vectorielles ou de production de diagrammes de documentation. Se déclenche également sur « animation SVG », « animer SVG », « SMIL », « path morph », « animateMotion », « icône SVG », « bannière SVG », « diagramme SVG », « interaction SVG sans script », « CSS SVG » ou toute demande de production d'un graphique évolutif autonome.
