قم بإنشاء رسومات SVG ورسوم متحركة قابلة للتطوير ويمكن الوصول إليها ومدروسة للموضوع للويب - أيقونات، ولافتات، ومخططات، ورسوم توضيحية، وشارات، ومرئيات تفاعلية. استخدم هذه المهارة عند إنشاء ملفات SVG، أو تحريك SVG باستخدام CSS أو SMIL، أو تحويل المسار، أو تتبع مسار الحركة، أو إنشاء SVG تفاعلي يستجيب للنقرات بدون JavaScript، أو رسم موضوعات من العالم الحقيقي (حيوانات، أشخاص، كائنات) كرسوم توضيحية متجهة، أو إنتاج مخططات توثيقية. يتم تشغيله أيضًا على "SVG Animation"، أو "animate SVG"، أو "SMIL"، أو "path morph"، أو "animateMotion"، أو "رمز SVG"، أو "شعار SVG"، أو "مخطط SVG"، أو "تفاعل SVG بدون نصوص برمجية"، أو "CSS SVG"، أو أي طلب لإنتاج رسم مستقل قابل للتطوير.
