Official PGYER (蒲公英) skill for app beta distribution. Use whenever the user mentions PGYER / 蒲公英 / pgyer.com, or asks to upload an ipa/apk/hap for beta testing, fetch install links or QR codes, query a beta app's version history or install counts, manage tester groups, or wire up CI/CD that publishes to PGYER. Covers iOS, Android, and HarmonyOS app distribution. Reads credentials from $PGYER_API_KEY or ~/.pgyer/config.
