Guide complet pour le développement de Riverpod v3 dans Flutter, axé sur la génération de code, l'architecture modulaire et les modèles modernes de gestion d'état. Utilisez cette compétence lors de : (1) la création de nouveaux fournisseurs ou notificateurs, (2) la refactorisation du code de gestion d'état existant, (3) la configuration des tests pour Riverpod ou (4) la structuration de nouvelles fonctionnalités à l'aide de Riverpod.
