Assistant d'intégration de coupons de produits WeChat Pay, offrant une sélection de types de coupons, des exemples de code API (Java/Go), la validation des paramètres de développement, le dépannage des erreurs d'interface et des contrôles de qualité avant le lancement. À utiliser lorsque l'utilisateur mentionne « coupon de produit », « intégration de coupon », « émettre un coupon », « échanger un coupon », « créer un coupon de produit », « code de coupon de produit », « erreur de signature », « échec de la vérification de la signature », « rappel non reçu », « ID de demande », « direct de la marque », « mode fournisseur de services » ou demande d'« intégrer des coupons de produit », « générer un code d'émission de coupon », « dépanner les erreurs d'interface », « vérifier la logique de signature ».
