Das Midnight.js TypeScript SDK zum Erstellen von DApps im Midnight Network. Deckt die gesamte Anbietereinrichtung, Wallet-SDK-Integration (HDWallet, WalletFacade, ShieldedWallet, UnshieldedWallet, DustWallet), Vertragsbereitstellung, Schaltkreisaufrufe, private Statusverwaltung, DUST-Generierung und Testkit-Nutzung ab. Verwenden Sie diese Fähigkeit immer dann, wenn ein Benutzer Anbieter verbindet, Wallets in einem Node.js- oder Browser-Kontext verwaltet, Compact-Verträge über TypeScript bereitstellt oder aufruft, DUST-/Gebührenflüsse abwickelt, den Ledger-Status liest oder Tests für Midnight-DApps schreibt.
