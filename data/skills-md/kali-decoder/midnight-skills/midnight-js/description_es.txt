El SDK de TypeScript de Midnight.js para crear DApps en Midnight Network. Cubre toda la configuración del proveedor, integración del SDK de billetera (HDWallet, WalletFacade, ShieldedWallet, UnshieldedWallet, DustWallet), implementación de contratos, llamadas de circuito, administración de estado privado, generación de DUST y uso del kit de prueba. Utilice esta habilidad siempre que un usuario conecte proveedores, administre billeteras en un contexto de Node.js o de navegador, implemente o llame a contratos Compact desde TypeScript, maneje el flujo de tarifas/DUST, lea el estado del libro mayor o escriba pruebas para Midnight DApps.
