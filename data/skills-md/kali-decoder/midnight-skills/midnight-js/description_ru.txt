Midnight.js TypeScript SDK для создания DApps в Midnight Network. Охватывает настройку всех поставщиков, интеграцию SDK кошелька (HDWallet, WalletFacade, ShieldedWallet, UnshieldedWallet, DustWallet), развертывание контрактов, циклические вызовы, управление частным состоянием, генерацию DUST и использование тестовых наборов. Используйте этот навык всякий раз, когда пользователь подключает провайдеров, управляет кошельками в контексте Node.js или браузера, развертывает или вызывает контракты Compact из TypeScript, обрабатывает поток DUST/комиссий, читает состояние реестра или пишет тесты для Midnight DApps.
