Midnight.js TypeScript SDK لبناء التطبيقات اللامركزية على شبكة Midnight. يغطي جميع إعدادات الموفر، وتكامل المحفظة SDK (HDWallet، وWalletFacade، وShieledWallet، وUnshieldedWallet، وDustWallet)، ونشر العقود، ومكالمات الدوائر، وإدارة الحالة الخاصة، وتوليد DUST، واستخدام أدوات الاختبار. استخدم هذه المهارة عندما يقوم المستخدم بتوصيل مقدمي الخدمات، أو إدارة المحافظ في Node.js أو سياق المتصفح، أو نشر أو استدعاء العقود المضغوطة من TypeScript، أو التعامل مع تدفق الغبار/الرسوم، أو قراءة حالة دفتر الأستاذ، أو كتابة اختبارات لتطبيقات Midnight DApps.
