Создайте частное приложение RSVP для вечеринок в сети Midnight Network — участники останутся конфиденциальными до тех пор, пока незащищенная НОЧНАЯ регистрация не пересечет границу конфиденциальности. Охватывает Private-party.compact (без свидетелей, persistCommit, открытые ключи для DApp, getUnshielded/sendUnshielded), интерфейс Next.js, интеграцию кошелька 1AM, низкоуровневое развертывание/вызов, опрос индексатора и дополнительные тесты локальной сети разработки vitest. Используйте для обучения границам конфиденциальности, спискам гостей на основе обязательств, контролю доступа организаторов или неэкранированной вступительной плате. Триггеры: частная вечеринка, RSVP dApp, граница конфиденциальности, persistCommit, getDappPublicKey, незащищенная регистрация, пример частной вечеринки, организатор вечеринки, обязательство по списку гостей. Также используйте при расширении шаблонов кошелька/провайдера locker-dapp или Payment-Dapp для социальных потоков, сохраняющих конфиденциальность.
