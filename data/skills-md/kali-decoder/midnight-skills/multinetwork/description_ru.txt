Создайте единое приложение Midnight dApp, которое будет развертываться и работать во всех сетях (неразвернутая/локальная, предварительная версия, предварительная версия, основная сеть). Охватывает настройку локального стека Docker с помощью Midnight-local-dev, конфигурацию среды, маршрутизацию поставщика, абстракцию кошелька, выбор проверочного сервера, разрешение активов ZK, реестр контрактов и различия в потоках DUST для каждой сети. Используйте, когда пользователь хочет настроить таргетинг на несколько сетей из одной базы кода, настроить локальную среду разработки или понять, какие изменения между undeployed/preprod/preview/mainnet.
