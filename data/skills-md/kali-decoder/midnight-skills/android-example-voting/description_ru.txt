Создайте dApp для голосования/опроса в Midnight Network с помощью Kuira Android SDK — компактный смарт-контракт со схемами создания/приведения/закрытия, идентификацией на основе ключа доступа, встроенным кошельком, пользовательским интерфейсом Compose, реактивным чтением реестра с помощью ObserveLedger() и подтверждением ZK на устройстве. Используйте при создании dApp для опросов или голосования, ориентированного на Android.
