قم بإنشاء تطبيق DApp كامل لعداد Midnight Network من البداية - عقد ذكي مدمج، واجهة سطر الأوامر (CLI) التفاعلية، إعداد المحفظة، إنشاء DUST، النشر + حلقة التفاعل، تكوينات Docker للمنتج المحلي/المنتج المسبق/المعاينة، والاختبارات. يُستخدم عندما يريد المستخدم إنشاء تطبيق Midnight DApp كاملاً، أو تمهيد مشروع جديد، أو فهم دورة الحياة الشاملة، أو يحتاج إلى نموذج عمل للمحفظة + العقد + واجهة سطر الأوامر (CLI). تنتج هذه المهارة التنفيذ المرجعي الرسمي لـ Midnightntwrk/example-counter باستخدام مساحات عمل الغزل.
