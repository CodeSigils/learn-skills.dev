Générez un DApp complet de compteur Midnight Network à partir de zéro : contrat intelligent compact, CLI interactive, configuration du portefeuille, génération DUST, boucle de déploiement + interaction, configurations Docker pour local/préprod/aperçu et tests. À utiliser lorsqu'un utilisateur souhaite créer une DApp Midnight complète, démarrer un nouveau projet, comprendre le cycle de vie de bout en bout ou a besoin d'un modèle de travail pour portefeuille + contrat + CLI. Cette compétence produit l'implémentation officielle de référence minuitntwrk/example-counter à l'aide des espaces de travail Yarn.
