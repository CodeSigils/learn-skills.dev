Genere una DApp de contador de Midnight Network completa desde cero: contrato inteligente compacto, CLI interactiva, configuración de billetera, generación de DUST, implementación + bucle de interacción, configuraciones de Docker para local/preproducción/vista previa y pruebas. Úselo cuando un usuario quiera crear una DApp Midnight completa, iniciar un nuevo proyecto, comprender el ciclo de vida de un extremo a otro o necesita un modelo estándar funcional para billetera + contrato + CLI. Esta habilidad produce la implementación oficial de referencia de contador de ejemplos/nightntwrk utilizando espacios de trabajo de hilo.
