Verwenden Sie diese Option, wenn ein Benutzer eine vollständige Midnight-DApp erstellen, ein neues Projekt starten, den End-to-End-Lebenszyklus verstehen möchte oder ein funktionierendes Boilerplate für Wallet + Vertrag + CLI benötigt. Dieser Skill erstellt die offizielle Referenzimplementierung „midnightntwrk/example-counter“ unter Verwendung von Garn-Arbeitsbereichen.
