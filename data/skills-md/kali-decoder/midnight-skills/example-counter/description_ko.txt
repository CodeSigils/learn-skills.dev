완전한 Midnight Network 카운터 DApp을 처음부터 생성합니다. 컴팩트 스마트 계약, 대화형 CLI, 지갑 설정, DUST 생성, 배포 + 상호 작용 루프, 로컬/preprod/미리 보기를 위한 Docker 구성 및 테스트입니다. 사용자가 전체 Midnight DApp을 구축하거나, 새 프로젝트를 부트스트랩하거나, 엔드투엔드 수명주기를 이해하거나, 지갑 + 계약 + CLI에 대한 상용구 작업이 필요할 때 사용하세요. 이 기술은 Yarn 작업 공간을 사용하여 공식 Midnightntwrk/example-counter 참조 구현을 생성합니다.
