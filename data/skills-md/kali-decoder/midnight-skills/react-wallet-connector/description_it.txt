Genera un'app React + Vite TypeScript che si connette a un portafoglio Midnight tramite l'API DApp Connector (@midnight-ntwrk/dapp-connector-api). Da utilizzare durante la creazione di un frontend React, il bootstrap di un connettore del portafoglio, il cablaggio dell'interfaccia utente di connessione/disconnessione, la lettura di portafogli window.midnight, l'ottenimento di indirizzi non schermati o la richiesta di informazioni sul flusso di connessione dell'API del connettore DApp. Produce un modello eseguibile minimo: lo stile viene intenzionalmente omesso in modo che l'utente possa aggiungere Tailwind, moduli CSS, ecc.
