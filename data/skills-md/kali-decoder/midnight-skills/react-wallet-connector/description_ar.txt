قم بإنشاء تطبيق React + Vite TypeScript الذي يتصل بمحفظة Midnight عبر DApp Connector API (@midnight-ntwrk/dapp-connector-api). يُستخدم عند إنشاء واجهة React الأمامية، أو تمهيد موصل المحفظة، أو توصيل/قطع اتصال الأسلاك لواجهة المستخدم، أو قراءة محافظ window.midnight، أو الحصول على عناوين غير محمية، أو السؤال عن تدفق اتصال DApp Connector API. يُنتج الحد الأدنى من القوالب القابلة للتشغيل - يتم حذف التصميم عمدًا حتى يتمكن المستخدم من إضافة وحدات Tailwind وCSS وما إلى ذلك.
