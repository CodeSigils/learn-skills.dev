Создайте приложение React + Vite TypeScript, которое подключается к кошельку Midnight через API соединителя DApp (@midnight-ntwrk/dapp-connector-api). Используйте при создании внешнего интерфейса React, начальной загрузке соединителя кошелька, подключении пользовательского интерфейса подключения/отключения, чтении кошельков window.midnight, получении неэкранированных адресов или запросе о процессе подключения API соединителя DApp. Создает минимальный работоспособный шаблон — стиль намеренно опущен, чтобы пользователь мог добавлять модули Tailwind, CSS и т. д.
