DApp コネクタ API (@midnight-ntwrk/dapp-connector-api) を介して Midnight ウォレットに接続する React + Vite TypeScript アプリを生成します。 React フロントエンドの構築、ウォレット コネクタのブートストラップ、接続/切断 UI の配線、window.midnight ウォレットの読み取り、シールドされていないアドレスの取得、または DApp コネクタ API 接続フローについて問い合わせる場合に使用します。最小限の実行可能なテンプレートを生成します。ユーザーが Tailwind や CSS モジュールなどを追加できるように、スタイル設定は意図的に省略されています。
