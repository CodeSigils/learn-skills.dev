Generieren Sie eine React + Vite TypeScript-App, die über die DApp Connector-API (@midnight-ntwrk/dapp-connector-api) eine Verbindung zu einem Midnight-Wallet herstellt. Verwenden Sie diese Option, wenn Sie ein React-Frontend erstellen, einen Wallet-Connector booten, die Benutzeroberfläche zum Verbinden/Trennen verkabeln, window.midnight-Wallets lesen, ungeschirmte Adressen abrufen oder nach dem DApp Connector-API-Verbindungsfluss fragen. Erstellt eine minimal ausführbare Vorlage – auf Stil wird bewusst verzichtet, damit der Benutzer Tailwind, CSS-Module usw. hinzufügen kann.
