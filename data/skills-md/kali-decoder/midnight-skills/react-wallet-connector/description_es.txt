Genere una aplicación React + Vite TypeScript que se conecte a una billetera Midnight a través de la API del conector DApp (@midnight-ntwrk/dapp-connector-api). Úselo al crear una interfaz de React, iniciar un conector de billetera, conectar/desconectar la interfaz de usuario, leer billeteras window.midnight, obtener direcciones no blindadas o preguntar sobre el flujo de conexión de la API del conector DApp. Produce una plantilla ejecutable mínima: el estilo se omite intencionalmente para que el usuario pueda agregar Tailwind, módulos CSS, etc.
