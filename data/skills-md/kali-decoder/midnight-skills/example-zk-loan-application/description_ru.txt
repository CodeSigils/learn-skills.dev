Создайте заявку на получение кредита с нулевым разглашением в сети Midnight Network — оцените кредитный рейтинг, доход и стаж работы в частном порядке в рамках компактной схемы с аттестацией Шнорра, записывайте в цепочке только результаты кредита и проводите аттестацию через API + CLI + дополнительный интерфейс Next.js. Охватывает zkloan-credit-scorer.compact (идентификация на основе свидетеля, многоуровневое право на участие, миграцию PIN-кодов, административное управление), проверку Джубжуба Шнорра, регистрацию поставщика аттестации и низкоуровневое развертывание/вызов через кошелек 1AM. Используйте для частного кредитного скоринга, данных заверенных свидетелей, кредитования децентрализованных приложений или обучения шаблонам раскрытия()/свидетелей с доверенными подписантами вне сети. Триггеры: кредит ZK, кредитный рейтинг, API аттестации, подпись Шнорра Compact, requestLoan, частный кредитный рейтинг, уровни права на получение кредита, PIN-код, zkloan. Также используйте при расширении шаблонов кошелька/поставщика Leaderboard-dapp или locker-dapp на монорепозитории с несколькими сервисами.
