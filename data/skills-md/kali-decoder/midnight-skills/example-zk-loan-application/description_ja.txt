Midnight Network 上でゼロ知識ローン アプリケーションを構築します。Schnorr 認証を使用してコンパクト サーキット内で信用スコア、収入、雇用期間をプライベートに評価し、ローン結果のみをオンチェーンに記録し、認証 API + CLI + オプションの Next.js フロントエンドを接続します。 zkloan-credit-scorer.compact (証人由来の ID、段階的資格、PIN 移行、管理ガバナンス)、Jubjub Schnorr 検証、構成証明プロバイダーの登録、および午前 1 時のウォレットを介した低レベルのデプロイ/コールをカバーします。プライベート信用スコアリング、証明された証人データ、dApp の貸し出し、またはオフチェーンの信頼された署名者との Discover()/証人パターンの指導に使用します。トリガー: ZK ローン、クレジット スコアラー、構成証明 API、Schnorr 署名コンパクト、requestLoan、プライベート クレジット スコア、ローン適格層、PIN ID、zkloan。リーダーボード dapp またはロッカー dapp ウォレット/プロバイダー パターンをマルチサービス モノリポジトリに拡張する場合にも使用します。
