Erstellen Sie einen wissensfreien Kreditantrag auf Midnight Network – bewerten Sie privat Kreditwürdigkeit, Einkommen und Beschäftigungsdauer innerhalb einer Compact-Schaltung mit Schnorr-Bescheinigung, zeichnen Sie nur Kreditergebnisse in der Kette auf und übermitteln Sie die Bescheinigungs-API + CLI + optionales Next.js-Frontend. Deckt zkloan-credit-scorer.compact (von Zeugen abgeleitete Identität, abgestufte Berechtigung, PIN-Migration, Admin-Governance), Jubjub-Schnorr-Verifizierung, Zertifizierungsanbieterregistrierung und Low-Level-Bereitstellung/Anruf über 1AM Wallet ab. Verwendung für die private Kreditwürdigkeitsprüfung, beglaubigte Zeugendaten, das Verleihen von dApps oder das Unterrichten von „clown()/witness“-Mustern mit vertrauenswürdigen Unterzeichnern außerhalb der Kette. Auslöser: ZK-Kredit, Kredit-Scorer, Bescheinigungs-API, Schnorr-Signatur Compact, requestLoan, privater Kredit-Score, Kreditberechtigungsstufen, PIN-Identität, Zkloan. Wird auch verwendet, wenn Leaderboard-Dapp- oder Locker-Dapp-Wallet/Provider-Muster auf Multi-Service-Monorepos erweitert werden.
