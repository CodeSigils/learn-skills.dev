أنشئ طلب قرض بدون معرفة على Midnight Network - قم بتقييم درجة الائتمان والدخل ومدة التوظيف بشكل خاص داخل دائرة مدمجة مع شهادة Schnorr، وتسجيل نتائج القروض فقط على السلسلة، والمصادقة السلكية API + CLI + الواجهة الأمامية Next.js الاختيارية. يغطي zkloan-credit-scorer.compact (الهوية المشتقة من الشاهد، والأهلية المتدرجة، وترحيل رقم التعريف الشخصي (PIN)، والحوكمة الإدارية)، والتحقق من Jubjub Schnorr، وتسجيل مزود التصديق، والنشر/الاتصال على مستوى منخفض عبر محفظة 1AM. يُستخدم لتسجيل الائتمان الخاص، أو بيانات الشهود الموثقة، أو إقراض التطبيقات اللامركزية، أو تعليم أنماط الكشف ()/الشهود مع الموقعين الموثوق بهم خارج السلسلة. المشغلات: قرض ZK، وسجل الائتمان، وواجهة برمجة تطبيقات التصديق، وتوقيع Schnorr Compact، وrequestLoan، ودرجة الائتمان الخاصة، ومستويات أهلية القرض، وهوية PIN، وzkloan. استخدمه أيضًا عند توسيع أنماط المحفظة/موفر ليدربورد-dapp أو locker-dapp إلى monorepos متعدد الخدمات.
