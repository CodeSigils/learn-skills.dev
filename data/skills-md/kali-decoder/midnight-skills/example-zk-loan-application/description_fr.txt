Créez une demande de prêt sans connaissances sur Midnight Network - évaluez en privé le pointage de crédit, les revenus et l'ancienneté d'emploi dans un circuit Compact avec attestation Schnorr, enregistrez uniquement les résultats du prêt en chaîne et l'API d'attestation par câble + CLI + interface Next.js en option. Couvre zkloan-credit-scorer.compact (identité dérivée d'un témoin, éligibilité à plusieurs niveaux, migration du code PIN, gouvernance administrative), vérification Jubjub Schnorr, enregistrement du fournisseur d'attestation et déploiement/appel de bas niveau via un portefeuille 1AM. À utiliser pour la notation de crédit privée, les données de témoins attestés, le prêt de dApps ou l'enseignement de modèles de divulgation ()/témoin avec des signataires de confiance hors chaîne. Déclencheurs : prêt ZK, scoreur de crédit, API d'attestation, signature Schnorr Compact, demande de prêt, pointage de crédit privé, niveaux d'éligibilité au prêt, identité PIN, zkloan. À utiliser également lors de l'extension des modèles de portefeuille/fournisseur leaderboard-dapp ou locker-dapp à des monorepos multiservices.
