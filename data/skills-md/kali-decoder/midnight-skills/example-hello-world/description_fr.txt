Générez un DApp Hello-World complet de Midnight Network à partir de zéro : contrat intelligent compact, tests Node.js sans tête avec Vitest, configuration du portefeuille à l'aide de testkit-js FluentWalletBuilder, génération DUST, transactions de déploiement et d'appel, et toutes les configurations prises en charge. À utiliser lorsqu'un utilisateur souhaite créer une DApp Midnight complète, démarrer un nouveau projet, comprendre le cycle de vie de bout en bout ou a besoin d'un modèle de travail pour le portefeuille + le contrat + les tests. Cette compétence produit tous les fichiers nécessaires à l'exécution sur un devnet local (pile Docker) à l'aide de l'implémentation de référence officielle minuitntwrk/example-hello-world.
