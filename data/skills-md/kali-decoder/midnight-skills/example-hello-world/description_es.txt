Genere una DApp completa del hola mundo de Midnight Network desde cero: contrato inteligente compacto, pruebas de Node.js sin cabeza con vitest, configuración de billetera usando testkit-js FluentWalletBuilder, generación de DUST, transacciones de implementación y llamada, y todas las configuraciones de soporte. Úselo cuando un usuario quiera crear una DApp Midnight completa, iniciar un nuevo proyecto, comprender el ciclo de vida de un extremo a otro o necesita un modelo funcional para billetera + contrato + pruebas. Esta habilidad produce todos los archivos necesarios para ejecutarse en devnet local (pila Docker) utilizando la implementación de referencia oficial de medianochentwrk/example-hello-world.
