Generieren Sie eine komplette Midnight Network-Hallo-Welt-DApp von Grund auf – kompakter Smart Contract, Headless Node.js-Tests mit vitest, Wallet-Einrichtung mit testkit-js FluentWalletBuilder, DUST-Generierung, Bereitstellung und Aufruf von Transaktionen und alle unterstützenden Konfigurationen. Verwenden Sie diese Option, wenn ein Benutzer eine vollständige Midnight-DApp erstellen, ein neues Projekt starten, den End-to-End-Lebenszyklus verstehen möchte oder eine funktionierende Vorlage für Wallet + Vertrag + Tests benötigt. Dieser Skill erzeugt alle Dateien, die für die Ausführung auf dem lokalen Devnet (Docker-Stack) erforderlich sind, unter Verwendung der offiziellen Referenzimplementierung midnightntwrk/example-hello-world.
