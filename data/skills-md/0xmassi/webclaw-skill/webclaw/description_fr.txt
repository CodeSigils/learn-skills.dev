Extraction Web pour les agents IA. Grattez, explorez, mappez, regroupez, extrayez, résumez, comparez, marquez, recherchez et 28 extracteurs spécifiques au site transforment n'importe quelle URL en Markdown, texte ou JSON propre. S'exécute localement sans clé via le serveur webclaw MCP ; définissez un WEBCLAW_API_KEY facultatif pour gérer les pages protégées par les robots et rendues par JavaScript. À utiliser lorsque web_fetch renvoie du contenu bloqué ou vide, ou lorsque vous avez besoin d'une extraction structurée et prête pour LLM.
