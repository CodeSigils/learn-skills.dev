Extracción web para agentes de IA. Raspe, rastree, mapee, realice lotes, extraiga, resuma, diferencie, marque, busque y 28 extractores específicos del sitio convierten cualquier URL en Markdown, texto o JSON limpio. Se ejecuta localmente sin clave a través del servidor MCP webclaw; establezca un WEBCLAW_API_KEY opcional para manejar páginas protegidas por bots y renderizadas por JavaScript. Úselo cuando web_fetch devuelva contenido bloqueado o vacío, o necesite una extracción estructurada y lista para LLM.
