AI エージェントの Web 抽出。スクレイピング、クロール、マップ、バッチ、抽出、要約、差分、ブランド、検索、および 28 のサイト固有の抽出機能により、あらゆる URL がクリーンなマークダウン、テキスト、または JSON に変換されます。 webclaw MCP サーバー経由でキーなしでローカルで実行します。オプションの WEBCLAW_API_KEY を設定して、ボットで保護され、JavaScript でレンダリングされたページを処理します。 web_fetch がブロックされたコンテンツまたは空のコンテンツを返す場合、または構造化された LLM 対応の抽出が必要な場合に使用します。
