Capacità di manutenzione e generazione automatizzata della documentazione. Si attiva quando: (1) il codice viene aggiunto, modificato, aggiornato o eliminato in qualsiasi competenza, (2) vengono creati nuovi script o riferimenti, (3) i file SKILL.md vengono modificati, (4) l'utente richiede aggiornamenti della documentazione, (5) il catalogo delle competenze necessita di rigenerazione, (6) README o AGENTS.md necessitano di aggiornamenti che riflettono le modifiche del codice. Utilizzare per generare documentazione tecnica, aggiornare documenti dopo modifiche al codice, produrre log delle modifiche, garantire che la documentazione rimanga sincronizzata con la base di codice e mantenere il catalogo delle competenze.
