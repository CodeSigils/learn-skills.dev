Mantenimiento automatizado de documentación y habilidad de generación. Se activa cuando: (1) se agrega, cambia, actualiza o elimina código en cualquier habilidad, (2) se crean nuevos scripts o referencias, (3) se modifican los archivos SKILL.md, (4) el usuario solicita actualizaciones de documentación, (5) el catálogo de habilidades necesita regeneración, (6) README o AGENTS.md necesitan actualizaciones que reflejen los cambios de código. Úselo para generar documentación técnica, actualizar documentos después de cambios de código, producir registros de cambios, garantizar que la documentación permanezca sincronizada con el código base y mantener el catálogo de habilidades.
