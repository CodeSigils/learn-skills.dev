Fähigkeit zur automatisierten Dokumentationspflege und -generierung. Wird ausgelöst, wenn: (1) Code in einem Skill hinzugefügt, geändert, aktualisiert oder gelöscht wird, (2) neue Skripte oder Referenzen erstellt werden, (3) SKILL.md-Dateien geändert werden, (4) Benutzer Aktualisierungen der Dokumentation anfordern, (5) der Skills-Katalog neu generiert werden muss, (6) README oder AGENTS.md Aktualisierungen benötigen, die Codeänderungen widerspiegeln. Verwendung zum Erstellen technischer Dokumentation, Aktualisieren von Dokumenten nach Codeänderungen, Erstellen von Änderungsprotokollen, Sicherstellen, dass die Dokumentation mit der Codebasis synchronisiert bleibt, und Pflege des Kompetenzkatalogs.
