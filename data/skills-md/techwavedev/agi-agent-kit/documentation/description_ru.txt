Навыки автоматизированного ведения и формирования документации. Срабатывает, когда: (1) код добавляется, изменяется, обновляется или удаляется в любом навыке, (2) создаются новые сценарии или ссылки, (3) изменяются файлы SKILL.md, (4) пользователь запрашивает обновления документации, (5) каталог навыков требует регенерации, (6) README или AGENTS.md требуют обновлений, отражающих изменения кода. Используйте для создания технической документации, обновления документации после изменений кода, создания журналов изменений, обеспечения синхронизации документации с базой кода и поддержания каталога навыков.
