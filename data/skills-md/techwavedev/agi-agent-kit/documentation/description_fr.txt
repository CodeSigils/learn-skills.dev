Compétence automatisée en matière de maintenance et de génération de documentation. Se déclenche lorsque : (1) le code est ajouté, modifié, mis à jour ou supprimé dans une compétence, (2) de nouveaux scripts ou références sont créés, (3) les fichiers SKILL.md sont modifiés, (4) l'utilisateur demande des mises à jour de la documentation, (5) le catalogue de compétences doit être régénéré, (6) README ou AGENTS.md ont besoin de mises à jour reflétant les modifications du code. À utiliser pour générer de la documentation technique, mettre à jour les documents après des modifications de code, produire des journaux de modifications, garantir que la documentation reste synchronisée avec la base de code et maintenir le catalogue de compétences.
