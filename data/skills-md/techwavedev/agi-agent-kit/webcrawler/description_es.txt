Agente de recolección de documentación para rastrear y extraer contenido de sitios web de documentación. Úselo para rastrear sitios de documentación y extraer todas las páginas sobre un tema, crear bases de conocimientos fuera de línea a partir de documentos en línea, recopilar referencias de API, tutoriales o guías de portales de documentación, crear exportaciones estructuradas de rebajas a partir de documentación de varias páginas y descargar y organizar documentos técnicos para incrustar o canalizaciones RAG. Admite rastreo recursivo con control de profundidad, filtrado de contenido y salida estructurada.
