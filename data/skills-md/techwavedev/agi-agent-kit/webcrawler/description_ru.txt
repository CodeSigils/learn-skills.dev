Агент сбора документации для сканирования и извлечения контента с веб-сайтов документации. Используйте для сканирования сайтов документации и извлечения всех страниц по теме, создания автономных баз знаний из онлайн-документов, сбора ссылок на API, учебных пособий или руководств с порталов документации, создания структурированного экспорта уценки из многостраничной документации, а также загрузки и организации технической документации для встраивания или конвейеров RAG. Поддерживает рекурсивное сканирование с контролем глубины, фильтрацией контента и структурированным выводом.
