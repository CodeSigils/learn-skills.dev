Интеллектуальная оптимизация токенов с помощью семантического кэширования и долговременной памяти на базе Qdrant. Используйте для (1) семантического кэша — полностью избегайте вызовов LLM для семантически схожих запросов со 100 % экономией токенов, (2) долговременной памяти — извлекайте только соответствующие фрагменты контекста вместо полной истории разговоров с сокращением контекста на 80–95 %, (3) гибридного поиска — сочетайте сходство векторов с фильтрацией ключевых слов для технических запросов, (4) Управление памятью — храните и извлекайте воспоминания о разговорах, решениях и шаблонах кода с фильтрацией метаданных. Срабатывает, когда необходимо кэшировать ответы, запоминать прошлые взаимодействия, оптимизировать контекстные окна или реализовывать шаблоны RAG.
