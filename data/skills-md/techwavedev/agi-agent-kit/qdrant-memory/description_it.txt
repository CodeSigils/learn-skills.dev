Ottimizzazione intelligente dei token tramite caching semantico basato su Qdrant e memoria a lungo termine. Da utilizzare per (1) Cache semantica: evita completamente le chiamate LLM per query semanticamente simili con un risparmio di token del 100%, (2) Memoria a lungo termine: recupera solo blocchi di contesto rilevanti anziché la cronologia completa delle conversazioni con una riduzione del contesto dell'80-95%, (3) Ricerca ibrida: combina la somiglianza dei vettori con il filtro delle parole chiave per query tecniche, (4) Gestione della memoria: memorizza e recupera ricordi di conversazione, decisioni e modelli di codice con il filtro dei metadati. Si attiva quando è necessario memorizzare nella cache le risposte, ricordare le interazioni passate, ottimizzare le finestre di contesto o implementare modelli RAG.
