Qdrant を活用したセマンティック キャッシュと長期メモリによるインテリジェントなトークンの最適化。 (1) セマンティック キャッシュ - トークンを 100% 節約して、意味的に類似したクエリに対する LLM 呼び出しを完全に回避します、(2) 長期メモリ - 80 ～ 95% のコンテキスト削減により、完全な会話履歴ではなく、関連するコンテキスト チャンクのみを取得します、(3) ハイブリッド検索 - ベクトルの類似性と技術的なクエリのキーワード フィルタリングを組み合わせます、(4) メモリ管理 - メタデータ フィルタリングを使用して、会話メモリ、意思決定、およびコード パターンを保存および取得します。応答のキャッシュ、過去のインタラクションの記憶、コンテキスト ウィンドウの最適化、または RAG パターンの実装が必要なときにトリガーされます。
