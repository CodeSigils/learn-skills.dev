Optimisation intelligente des jetons grâce à la mise en cache sémantique et à la mémoire à long terme optimisées par Qdrant. À utiliser pour (1) Cache sémantique : évitez entièrement les appels LLM pour des requêtes sémantiquement similaires avec 100 % d'économies de jetons, (2) Mémoire à long terme : récupérez uniquement les morceaux de contexte pertinents au lieu de l'historique complet des conversations avec une réduction de contexte de 80 à 95 %, (3) Recherche hybride : combinez la similarité vectorielle avec le filtrage par mots clés pour les requêtes techniques, (4) Gestion de la mémoire : stockez et récupérez les mémoires de conversation, les décisions et les modèles de code avec le filtrage des métadonnées. Se déclenche lorsqu'il est nécessaire de mettre en cache les réponses, de mémoriser les interactions passées, d'optimiser les fenêtres contextuelles ou d'implémenter des modèles RAG.
