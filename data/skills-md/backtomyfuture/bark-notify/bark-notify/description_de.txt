Senden Sie Push-Benachrichtigungen von Bark (day.app) an das iPhone. Wird verwendet, wenn die Ausführung eines Agenten abgeschlossen ist, eine Aufgabe abgeschlossen ist oder wenn der Benutzer benachrichtigt werden muss. Kann auch zum Senden benutzerdefinierter Push-Benachrichtigungen mit erweiterten Funktionen wie benutzerdefinierten Tönen, Symbolen, Bildern, Gruppen, kritischen Warnungen, zeitkritischen Benachrichtigungen, Markdown-Inhalten, Click-to-Copy, URL-Sprüngen, Badge-Updates, wiederholten Klingeltönen (Anrufmodus) und AES-verschlüsseltem Push verwendet werden. Auslöser bei: „Benachrichtige mich“, „Push senden“, „bellen“, „Push-Benachrichtigung“, „Mich benachrichtigen“, „提醒我“, „推送通知“ oder eine beliebige Benachrichtigung über den Abschluss einer Aufgabe.
