Exécutez la commande /integrate pour les agents LLM. Se déclenche lorsque l'utilisateur tape `/integrate`, `/integrate --product` ou demande « d'intégrer un produit Juspay », « configurer les paiements », « ajouter un SDK de paiement » ou toute variante de configuration d'un produit Juspay dans son application ou sa base de code. Cette compétence pilote un assistant entièrement guidé et basé sur des documents : il lit les résumés de produits localement, sonde les candidats via MCP, puis récupère les pages de documentation réelles et génère le code d'intégration complet.
