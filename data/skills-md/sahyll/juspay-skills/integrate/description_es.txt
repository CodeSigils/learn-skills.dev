Ejecute el comando /integrate para agentes LLM. Se activa cuando el usuario escribe `/integrate`, `/integrate --product` o solicita "integrar un producto Juspay", "configurar pagos", "agregar SDK de pago" o cualquier variación de configuración de un producto Juspay en su aplicación o código base. Esta habilidad impulsa un asistente totalmente guiado y basado en documentos: lee resúmenes de productos localmente, prueba candidatos a través de MCP, luego recupera páginas de documentación reales y genera un código de integración completo.
