عندما يريد المستخدم تحسين التحويلات أو تحسينها أو زيادتها على أي صفحة تسويقية - بما في ذلك الصفحة الرئيسية أو الصفحات المقصودة أو صفحات التسعير أو صفحات الميزات أو منشورات المدونة. استخدمه أيضًا عندما يقول المستخدم "CRO"، أو "تحسين معدل التحويل"، أو "هذه الصفحة لا تقوم بالتحويل"، أو "تحسين التحويلات"، أو "لماذا لا تعمل هذه الصفحة"، أو "صفحتي المقصودة سيئة"، أو "لا أحد يقوم بالتحويل"، أو "معدل التحويل منخفض"، أو "معدل الارتداد مرتفع للغاية"، أو "يغادر الأشخاص دون الاشتراك"، أو "هذه الصفحة بحاجة إلى العمل". استخدم هذا حتى لو قام المستخدم فقط بمشاركة عنوان URL وطلب التعليقات - فمن المحتمل أنه يريد مساعدة في التحويل. للتعرف على تدفقات الاشتراك/التسجيل، راجع Signup-flow-cro. للتنشيط بعد الاشتراك، راجع onboarding-cro. للحصول على نماذج خارج نطاق الاشتراك، راجع النموذج cro. بالنسبة للنوافذ المنبثقة/النماذج، راجع popup-cro.
