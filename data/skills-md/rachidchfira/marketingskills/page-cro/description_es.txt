Cuando el usuario desea optimizar, mejorar o aumentar las conversiones en cualquier página de marketing, incluida la página de inicio, las páginas de destino, las páginas de precios, las páginas de funciones o las publicaciones de blog. Utilícelo también cuando el usuario diga "CRO", "optimización de la tasa de conversión", "esta página no genera conversiones", "mejora las conversiones", "por qué esta página no funciona", "mi página de destino apesta", "nadie está realizando conversiones", "baja tasa de conversión", "la tasa de rebote es demasiado alta", "la gente se va sin registrarse" o "esta página necesita mejoras". Utilice esto incluso si el usuario simplemente comparte una URL y solicita comentarios; probablemente quiera ayuda para la conversión. Para flujos de registro/inscripción, consulte signup-flow-cro. Para la activación posterior al registro, consulte onboarding-cro. Para formularios fuera del registro, consulte form-cro. Para ventanas emergentes/modales, consulte popup-cro.
