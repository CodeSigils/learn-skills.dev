Lorsque l'utilisateur souhaite optimiser, améliorer ou augmenter les conversions sur n'importe quelle page marketing, y compris la page d'accueil, les pages de destination, les pages de tarification, les pages de fonctionnalités ou les articles de blog. À utiliser également lorsque l'utilisateur dit « CRO », « optimisation du taux de conversion », « cette page ne convertit pas », « améliorer les conversions », « pourquoi cette page ne fonctionne-t-elle pas », « ma page de destination est nulle », « personne ne convertit », « faible taux de conversion », « le taux de rebond est trop élevé », « les gens partent sans s'inscrire » ou « cette page a besoin de travail ». Utilisez-le même si l'utilisateur partage simplement une URL et demande des commentaires : il souhaite probablement de l'aide à la conversion. Pour les flux d’inscription/inscription, voir signup-flow-cro. Pour l'activation après l'inscription, voir onboarding-cro. Pour les formulaires en dehors de l'inscription, voir form-cro. Pour les popups/modaux, voir popup-cro.
