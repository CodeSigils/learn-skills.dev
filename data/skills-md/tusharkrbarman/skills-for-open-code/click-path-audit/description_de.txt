Verfolgen Sie jede benutzerseitige Schaltfläche/jeden Berührungspunkt durch ihre vollständige Statusänderungssequenz, um Fehler zu finden, bei denen Funktionen einzeln funktionieren, sich aber gegenseitig aufheben, einen falschen Endzustand erzeugen oder die Benutzeroberfläche in einem inkonsistenten Zustand belassen. Verwenden Sie diese Option, wenn beim systematischen Debuggen keine Fehler gefunden wurden, Benutzer jedoch defekte Schaltflächen melden, oder nach einer größeren Umgestaltung, die Shared-State-Stores berührt.
