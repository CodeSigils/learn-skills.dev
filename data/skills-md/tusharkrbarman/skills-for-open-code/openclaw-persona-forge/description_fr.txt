Créez une solution complète d'âme de homard pour l'agent OpenClaw AI. Basé sur les préférences de l'utilisateur ou des tirages gacha aléatoires, le positionnement de l'identité de sortie, la description de l'âme (SOUL.md), les règles de rôle de base, le nom et les mots-clés d'invite d'image brute de l'avatar. Si l’environnement actuel fournit une compétence d’image brute approuvée, une image d’avatar de style unifié peut être automatiquement générée. À utiliser lorsque l'utilisateur a besoin de créer, concevoir ou personnaliser une âme de homard OpenClaw. Ne s'applique pas à : la mise au point de SOUL.md existant, les conceptions de personnages pour les plates-formes non OpenClaw, les agents de type outil pur sans personnalité. Mots déclencheurs : âme de homard, âme de crevette, âme OpenClaw, âme d'élevage de crevettes, personnage de homard, positionnement du homard, rôle de meurtre et de mystère du homard, personnage de jeu de homard, PNJ de homard, personnalité du homard, histoire du homard, âme du homard, personnage du homard, tirage au sort gacha, homard aléatoire, ÂME du homard, gacha.
