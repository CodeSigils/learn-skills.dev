Trasforma Claude Code in un sistema di agenti completamente autonomo con memoria persistente, operazioni pianificate, utilizzo del computer e accodamento delle attività. Sostituisce i framework di agenti autonomi (Hermes, AutoGPT) sfruttando i cron nativi, l'invio, gli strumenti MCP e la memoria di Claude Code. Da utilizzare quando l'utente desidera un funzionamento autonomo continuo, attività pianificate o un ciclo di agenti autogestiti.
