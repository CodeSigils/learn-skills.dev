Créez un profil de style d'écriture dérivé d'une source à partir de publications réelles, d'essais, de notes de lancement, de documents ou de copies de site, puis réutilisez ce profil dans le contenu, la sensibilisation et les flux de travail sociaux. À utiliser lorsque l'utilisateur souhaite une cohérence vocale sans tropes d'écriture génériques d'IA.
