À utiliser AVANT d'écrire du code, de planifier ou de réfléchir. C'est le point d'entrée pour toutes les compétences UX Superpowers. S'active lorsqu'un utilisateur souhaite créer, créer ou implémenter quoi que ce soit : applications Web, CLI, API, applications mobiles, infrastructure, outils internes ou tout autre logiciel. Guide à travers une phase structurée de découverte UX : définition du problème, création de personnalité, parcours utilisateur, tâches à effectuer et mesures de réussite. Accepte les données brutes des utilisateurs (entretiens, commentaires, analyses) OU les guides à partir de zéro. Produit un document de découverte UX qui ancre tous les développements ultérieurs.
