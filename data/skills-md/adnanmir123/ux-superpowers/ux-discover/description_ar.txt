استخدمه قبل كتابة أي تعليمات برمجية أو تخطيط أو عصف ذهني. هذه هي نقطة الدخول لجميع مهارات UX Superpowers. يتم التنشيط عندما يريد المستخدم إنشاء أو إنشاء أو تنفيذ أي شيء — تطبيقات الويب، أو واجهات سطر الأوامر، أو واجهات برمجة التطبيقات، أو تطبيقات الهاتف المحمول، أو البنية التحتية، أو الأدوات الداخلية، أو أي برنامج. يرشدك خلال مرحلة اكتشاف تجربة المستخدم المنظمة: تعريف المشكلة، وإنشاء الشخصية، ورحلات المستخدم، والمهام التي يتعين إنجازها، ومقاييس النجاح. يقبل بيانات المستخدم الأولية (المقابلات والتعليقات والتحليلات) أو الأدلة من البداية. يُنتج مستند اكتشاف UX الذي يدعم جميع عمليات التطوير اللاحقة.
