コードの作成、計画、ブレインストーミングの前に使用してください。これは、すべての UX スーパーパワー スキルのエントリー ポイントです。ユーザーが Web アプリ、CLI、API、モバイル アプリ、インフラストラクチャ、内部ツール、その他のソフトウェアなど、何かを構築、作成、実装したいときにアクティブ化されます。構造化された UX 発見フェーズ (問題の定義、ペルソナの作成、ユーザー ジャーニー、やるべき仕事、成功指標) をガイドします。生のユーザー データ (インタビュー、フィードバック、分析) またはゼロからのガイドを受け入れます。その後のすべての開発の基礎となる UX ディスカバリー ドキュメントを作成します。
