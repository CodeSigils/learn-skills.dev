Úselo ANTES de escribir cualquier código, planificación o lluvia de ideas. Este es el punto de entrada para todas las habilidades de UX Superpowers. Se activa cuando un usuario quiere construir, crear o implementar cualquier cosa: aplicaciones web, CLI, API, aplicaciones móviles, infraestructura, herramientas internas o cualquier software. Guía a través de una fase estructurada de descubrimiento de UX: definición de problemas, creación de personajes, recorridos de los usuarios, trabajos por realizar y métricas de éxito. Acepta datos de usuario sin procesar (entrevistas, comentarios, análisis) O guías desde cero. Produce un documento de descubrimiento de UX que ancla todo el desarrollo posterior.
