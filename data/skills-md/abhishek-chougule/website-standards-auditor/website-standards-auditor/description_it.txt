Controlla e correggi qualsiasi sito web (nuovo, in fase di sviluppo o già attivo) rispetto agli standard web e ingegneristici obbligatori dell'organizzazione, quindi supportalo o ripara le lacune dopo l'approvazione dell'utente. Utilizzalo ogni volta che l'utente desidera una revisione di SEO, GEO, AEO, accessibilità, prestazioni, dati strutturati, schema, mappa del sito, robots.txt, llms.txt, Core Web Vitals, Lighthouse, mobile, metadati, canonici, hreflang, reindirizzamenti o collegamenti interni oppure chiede di verificare un repository rispetto alla politica .gitignore e README oppure menziona auditing, gap analysis, conformità, revisione degli standard o "fai in modo che il mio sito segua le nostre regole". Utilizzalo sempre per qualsiasi attività relativa alla qualità del sito Web, alla rilevabilità o alla conformità agli standard, anche se l'utente non nomina lo standard, e segui il flusso in due fasi che produce prima gap_identification.md, quindi lo corregge solo dopo l'approvazione esplicita.
