向服务器端路由或端点添加安全保护 - 速率限制、机器人检测、电子邮件验证和滥用预防。跨框架工作，包括 Next.js、Express、Fastify、SvelteKit、Remix、Bun、Deno、NestJS 和 Python (Django/Flask)。当用户想要保护 API 路由、表单处理程序、身份验证端点或 Webhook 免遭滥用时，请使用此技能，即使他们将其描述为“添加速率限制”、“阻止机器人”、“防止暴力破解”或“保护我的端点”而没有具体提及 Arcjet。使用 Arcjet CLI（“npx @arcjet/cli”或“brew install arcjet”）进行身份验证、站点/密钥设置、远程规则管理和流量验证。
