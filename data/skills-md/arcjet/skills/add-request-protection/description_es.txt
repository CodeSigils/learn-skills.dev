Agregue protección de seguridad a una ruta o punto final del lado del servidor: limitación de velocidad, detección de bots, validación de correo electrónico y prevención de abusos. Funciona en marcos que incluyen Next.js, Express, Fastify, SvelteKit, Remix, Bun, Deno, NestJS y Python (Django/Flask). Utilice esta habilidad cuando el usuario quiera proteger una ruta API, un controlador de formulario, un punto final de autenticación o un webhook contra el abuso, incluso si lo describe como "agregar limitación de velocidad", "bloquear bots", "evitar la fuerza bruta" o "asegurar mi punto final" sin mencionar Arcjet específicamente. Utiliza la CLI de Arcjet (`npx @arcjet/cli` o `brew install arcjet`) para autenticación, configuración de sitio/clave, administración remota de reglas y verificación de tráfico.
