在伺服器端路由或端點新增安全保護 - 速率限制、機器人偵測、電子郵件驗證和濫用預防。跨框架工作，包括 Next.js、Express、Fastify、SvelteKit、Remix、Bun、Deno、NestJS 和 Python (Django/Flask)。當使用者想要保護 API 路由、表單處理程序、驗證端點或 Webhook 免於濫用時，請使用此技能，即使他們將其描述為「新增速率限制」、「封鎖機器人」、「防止暴力破解」或「保護我的端點」而沒有具體提及 Arcjet。使用 Arcjet CLI（“npx @arcjet/cli”或“brew install arcjet”）進行身份驗證、網站/金鑰設定、遠端規則管理和流量驗證。
