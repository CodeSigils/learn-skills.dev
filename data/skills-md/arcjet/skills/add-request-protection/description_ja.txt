サーバー側のルートまたはエンドポイントにセキュリティ保護を追加します。レート制限、ボット検出、電子メール検証、不正行為防止です。 Next.js、Express、Fastify、SvelteKit、Remix、Bun、Deno、NestJS、Python (Django/Flask) などのフレームワークで動作します。このスキルは、ユーザーが API ルート、フォーム ハンドラー、認証エンドポイント、または Webhook を悪用から保護したい場合に使用します。これは、Arcjet について特に言及せずに「レート制限の追加」、「ボットのブロック」、「ブルート フォースの防止」、「エンドポイントの保護」などと説明されている場合でも同様です。認証、サイト/キーのセットアップ、リモート ルール管理、トラフィック検証に Arcjet CLI (「npx @arcjet/cli」または「brew install arcjet」) を使用します。
