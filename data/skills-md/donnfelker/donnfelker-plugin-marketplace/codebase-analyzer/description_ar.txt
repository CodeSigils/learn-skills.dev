عندما يريد المستخدم تحليلًا فنيًا شاملاً لقاعدة التعليمات البرمجية أو المشروع. استخدمه أيضًا عندما يذكر المستخدم "تحليل قاعدة التعليمات البرمجية هذه" أو "نظرة عامة تقنية" أو "توثيق هذه البنية" أو "ماذا تفعل قاعدة التعليمات البرمجية هذه" أو "تلخيص هذا الريبو" أو "تدقيق التعليمات البرمجية" أو "مراجعة البنية" أو "إرشادات قاعدة التعليمات البرمجية" أو "تحليل هذا المشروع". إجراء تحليل متعدد المراحل يغطي البنية وجودة التعليمات البرمجية والاختبار والبنية التحتية، وإنتاج تقرير تفصيلي عن تخفيض السعر يستهدف المهندسين. لإجراء عمليات بحث سريعة عن التعليمات البرمجية أو مراجعات ملف واحد، راجع أدوات التحرير القياسية.
