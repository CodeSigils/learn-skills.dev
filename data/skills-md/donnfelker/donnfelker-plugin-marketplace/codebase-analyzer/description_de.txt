Wenn der Benutzer eine umfassende technische Analyse einer Codebasis oder eines Projekts wünscht. Verwenden Sie es auch, wenn der Benutzer „Diese Codebasis analysieren“, „Technischen Überblick“, „Diese Architektur dokumentieren“, „Was macht diese Codebasis“, „Dieses Repo zusammenfassen“, „Codeprüfung“, „Architekturüberprüfung“, „Codebasis-Komplettlösung“ oder „Dieses Projekt analysieren“ erwähnt. Führt eine mehrphasige Analyse durch, die Architektur, Codequalität, Tests und Infrastruktur umfasst, und erstellt einen detaillierten Markdown-Bericht für Ingenieure. Informationen zur schnellen Codesuche oder Überprüfung einzelner Dateien finden Sie in den Standard-Editor-Tools.
