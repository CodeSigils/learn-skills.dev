Lorsque l'utilisateur souhaite une analyse technique complète d'une base de code ou d'un projet. À utiliser également lorsque l'utilisateur mentionne « analyser cette base de code », « présentation technique », « documenter cette architecture », « que fait cette base de code », « résumer ce dépôt », « audit de code », « examen de l'architecture », « présentation pas à pas de la base de code » ou « analyser ce projet ». Effectue une analyse en plusieurs phases couvrant l'architecture, la qualité du code, les tests et l'infrastructure, produisant un rapport de démarque détaillé ciblant les ingénieurs. Pour des recherches rapides de code ou des révisions de fichiers uniques, consultez les outils d'édition standard.
