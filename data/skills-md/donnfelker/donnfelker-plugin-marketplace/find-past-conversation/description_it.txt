Cerca le trascrizioni delle sessioni di Claude Code precedenti in ~/.claude/projects/ per recuperare una conversazione precedente in base alla frase richiamata, alla stringa di errore o all'argomento. Da utilizzare quando l'utente dice "cerca nella cronologia", "trova la conversazione su", "guarda le sessioni passate", "ho mai finito quel lavoro", "cosa abbiamo deciso riguardo a X la scorsa settimana", "ricordami cosa è emerso da quella sessione" o ti chiede in altro modo di richiamare una sessione precedente. Restituisce ID sessione, progetto, data e un riepilogo di 2-4 frasi; su richiesta riporta anche l'esito (commit, filiale, PR aperta o accorpata). Non per cercare la base di codice corrente, i commenti PR correnti o sistemi esterni come Slack/Jira: per quelli, vedere codebase-analyzer e address-pr-comments.
