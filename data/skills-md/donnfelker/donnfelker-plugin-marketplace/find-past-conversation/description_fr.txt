Recherche les transcriptions des sessions Claude Code sous ~/.claude/projects/ pour récupérer une conversation précédente par phrase rappelée, chaîne d'erreur ou sujet. À utiliser lorsque l'utilisateur dit « recherchez dans votre historique », « recherchez la conversation sur », « parcourez vos sessions passées », « ai-je déjà terminé ce travail », « qu'avons-nous décidé à propos de X la semaine dernière », « rappelle-moi ce qui est ressorti de cette session » ou vous demande de vous souvenir d'une session antérieure. Renvoie l'ID de session, le projet, la date et un résumé de 2 à 4 phrases ; sur demande, rapporte également le résultat (commit, branche, PR ouvert ou fusionné). Pas pour rechercher la base de code actuelle, les commentaires PR actuels ou les systèmes externes comme Slack/Jira – pour ceux-ci, voir codebase-analyzer et address-pr-comments.
