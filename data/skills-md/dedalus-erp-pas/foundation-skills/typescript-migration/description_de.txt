Leitfaden für die schrittweise Migration von JavaScript-Codebasen zu TypeScript. Beziehen Sie sich auf die tsconfig-Konfiguration, die Migrationsdatei für die Datei, die Typisierungsstrategien für den Legacy-Code, die Einstellung „any“ und die aktuellen Dateien. Wenn Sie den Benutzer verwenden, um JS in TS zu konvertieren, fügen Sie Typen in vorhandenen Code hinzu, konfigurieren Sie TypeScript in einem JS-Projekt oder verbessern Sie die Schreibsicherheit.
