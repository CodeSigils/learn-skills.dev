Guía para la migración incremental de bases de código JavaScript a TypeScript. Utilice la configuración tsconfig, la migración de archivos por archivo, las estrategias de escritura para el código heredado, la gestión de "cualquier" y las opciones de corriente. Cuando el usuario pueda convertir JS a TS, agregue los tipos de código existentes, configure TypeScript en un proyecto JS o mejore la seguridad de escritura.
