دليل الترحيل المتزايد لقواعد التعليمات البرمجية JavaScript إلى TypeScript. قم بتغطية التكوين tsconfig، وترحيل الملف حسب الملف، واستراتيجيات الكتابة للكود القديم، وإدارة `any` والأجزاء الجارية. يمكنك استخدامه عندما يقوم المستخدم بتحويل JS إلى TS، أو إضافة أنواع إلى الكود الموجود، أو تكوين TypeScript في مشروع JS، أو تحسين أمان الصفحة.
