Руководство по дополнительной миграции кодовых баз JavaScript и TypeScript. Создайте конфигурацию tsconfig, документацию по миграции, стратегии ввода текста для унаследованного кода, действия `любого` и многих курантов. Когда пользователь конвертирует JS в TS, он добавляет типы существующего кода, конфигурирует TypeScript в проекте JS или улучшает безопасность ввода.
