Guide pour la migration incrémentale des bases de code JavaScript vers TypeScript. Découvrez la configuration tsconfig, la migration fichier par fichier, les stratégies de typage pour le code Legacy, la gestion du `any` et les pièges courants. À utiliser lorsque l'utilisateur veut convertir du JS en TS, ajouter des types au code existant, configurer TypeScript dans un projet JS ou améliorer la sûreté de typage.
