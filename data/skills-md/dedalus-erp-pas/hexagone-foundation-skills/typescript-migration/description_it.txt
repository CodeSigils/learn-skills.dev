Guida per la migrazione incrementale delle basi di codice JavaScript rispetto a TypeScript. Controlla la configurazione di tsconfig, la migrazione del file per file, le strategie di digitazione per il codice legacy, la gestione di `qualsiasi` e le cifre correnti. Da utilizzare quando l'utente vuole convertire JS in TS, aggiungere i tipi al codice esistente, configurare TypeScript in un progetto JS o migliorare la sicurezza della digitazione.
