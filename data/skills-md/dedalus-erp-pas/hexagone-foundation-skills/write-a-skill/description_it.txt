Guide la création d'un nouveau skill d'agent IA pour le dépôt Foundation-Skills. Generare lo squelette di SKILL.md e il file dei documenti, applicare le convenzioni del deposito (frontmatter, versione, struttura). Da utilizzare quando l'utente richiede di creare una nuova abilità, scrivere un'abilità, aggiungere un'abilità o generare lo schema di un'abilità.
