Automatización completa del navegador y pruebas web con Playwright. Detecte automáticamente los servidores de desarrollo, genere el ciclo de vida de los servidores y escriba los scripts de prueba propios en /tmp. Probador de páginas, rellenar formularios, capturar capturas de pantalla, verificar el diseño responsivo, validar el UX, probar el flujo de conexión, verificar los gravámenes, descubrir las aplicaciones web dinámicas, automatizar todo el navegador. Utilice cuando el usuario pueda probar sitios web, automatizar las interacciones del navegador, validar las funciones web o realizar todas las pruebas básicas en el navegador.
