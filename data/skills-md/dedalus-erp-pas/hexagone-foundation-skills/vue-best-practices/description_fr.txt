Guide des bonnes pratiques Vue.js 3 comprenant la Composition API, la conception de composants, les patrons de réactivité, l'utilitaire de style-first avec Tailwind CSS, l'intégration native de la bibliothèque de composants PrimeVue et l'organisation du code. À utiliser lors de l'écriture, de la revue ou du refactoring de code Vue.js pour garantir des patrons idiomatiques et un code maintenable.
