Versuchen Sie beim Erkunden der Codebasis einen Fehler oder ein Problem, um die Ursache herauszufinden, und erstellen Sie dann ein Problem bei GitLab oder GitHub mit einem Korrekturplan auf Basis des TDD. Wenn der Benutzer einen Fehler meldet, muss er ein Problem erstellen, eine „Triage“ erwähnen oder die Behebung eines Problems untersuchen und planen.
