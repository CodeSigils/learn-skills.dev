Esegui le richieste SQL in una sola lezione su più basi di dati PostgreSQL. Da utilizzare per: (1) interrogare le basi PostgreSQL, (2) esplorare schemi/tabelle, (3) eseguire richieste SELECT per analizzare dati, (4) verificare il contenuto delle basi. Supporta più connessioni con descrizioni per una selezione automatica intelligente. Blocca tutte le operazioni di scrittura (INSERT, UPDATE, DELETE, DROP, ecc.) per sicurezza.
