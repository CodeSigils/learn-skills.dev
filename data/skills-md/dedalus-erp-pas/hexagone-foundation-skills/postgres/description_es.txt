Ejecute las solicitudes SQL en una sola lectura sobre bases de datos adicionales de PostgreSQL. Se utiliza para: (1) interrogar las bases de PostgreSQL, (2) explorar los esquemas/tablas, (3) ejecutar las solicitudes SELECT para el análisis de datos, (4) verificar el contenido de las bases. Admite más conexiones con descripciones para una selección automática inteligente. Bloquee todas las operaciones de escritura (INSERT, UPDATE, DELETE, DROP, etc.) por seguridad.
