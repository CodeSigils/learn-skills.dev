Выполнение запросов SQL на лекциях по дополнительным основам PostgreSQL. Утилизатор для: (1) опроса баз PostgreSQL, (2) просмотра схем/таблиц, (3) выполнения запросов SELECT для анализа данных, (4) проверки содержимого баз. Поддержка дополнительных соединений с описаниями для автоматического интеллектуального выбора. Блокируйте все операции чтения (INSERT, UPDATE, DELETE, DROP и т. д.) в целях безопасности.
