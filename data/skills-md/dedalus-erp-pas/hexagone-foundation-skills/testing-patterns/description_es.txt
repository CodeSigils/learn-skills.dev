Patrones y estrategias de prueba completas para proyectos JavaScript/TypeScript. Couvre les tests unitaires, d'intégration et E2E, les stratégies de mocking, l'organisation des tests et les anti-patrons courants. Al utilizar cuando el usuario escribe las pruebas, mejora la cobertura de las pruebas, establece una estrategia de prueba o corrige las pruebas inestables.
