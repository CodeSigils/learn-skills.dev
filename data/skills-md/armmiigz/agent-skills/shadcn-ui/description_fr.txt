Utilisez cette compétence pour installer, configurer et gérer les composants shadcn/ui avec Tailwind CSS v4. Déclenchez-le CHAQUE fois que l'utilisateur a besoin d'initialiser une bibliothèque d'interface utilisateur, d'ajouter des composants spécifiques tels que « Bouton » ou « Dialogue », ou d'appliquer une marque personnalisée à son interface.
