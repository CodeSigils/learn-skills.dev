Used when a user needs to call the management APIs of the StarMap platform (AstraFlow / UModelVerse), covering scenarios such as creating or managing inference API keys, querying billing and orders, retrieving model marketplace data, exporting or querying inference request logs, and more. It provides the complete preparation for UCloud’s universal signature authentication (how to obtain the PublicKey/PrivateKey, how to calculate the Signature, how to determine the Region and ProjectId), and includes in the references/ directory the detailed request/response parameter specifications for all 21 known management APIs.
