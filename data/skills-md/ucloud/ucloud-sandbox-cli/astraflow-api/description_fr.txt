Utilisé lorsqu'un utilisateur a besoin d'appeler les API de gestion de la plateforme StarMap (AstraFlow / UModelVerse), couvrant des scénarios tels que la création ou la gestion de clés API d'inférence, l'interrogation de la facturation et des commandes, la récupération des données du marché modèle, l'exportation ou l'interrogation des journaux de demandes d'inférence, etc. Il fournit la préparation complète à l'authentification par signature universelle d'UCloud (comment obtenir la clé publique/clé privée, comment calculer la signature, comment déterminer la région et l'ID du projet) et inclut dans le répertoire références/répertoire les spécifications détaillées des paramètres de demande/réponse pour les 21 API de gestion connues.
