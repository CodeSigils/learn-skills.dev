Wird verwendet, wenn ein Benutzer die Verwaltungs-APIs der StarMap-Plattform (AstraFlow/UModelVerse) aufrufen muss. Dabei werden Szenarien wie das Erstellen oder Verwalten von Inferenz-API-Schlüsseln, das Abfragen von Abrechnungen und Bestellungen, das Abrufen von Modell-Marktplatzdaten, das Exportieren oder Abfragen von Inferenzanforderungsprotokollen und mehr abgedeckt. Es bietet die vollständige Vorbereitung für die universelle Signaturauthentifizierung von UCloud (wie man den PublicKey/PrivateKey erhält, wie man die Signatur berechnet, wie man die Region und ProjectId bestimmt) und enthält im Verzeichnis „references/directory“ die detaillierten Anforderungs-/Antwortparameterspezifikationen für alle 21 bekannten Verwaltungs-APIs.
