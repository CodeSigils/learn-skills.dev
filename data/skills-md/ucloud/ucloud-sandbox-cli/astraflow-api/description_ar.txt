يُستخدم عندما يحتاج المستخدم إلى استدعاء واجهات برمجة التطبيقات الإدارية لمنصة StarMap (AstraFlow / UModelVerse)، والتي تغطي سيناريوهات مثل إنشاء أو إدارة مفاتيح واجهة برمجة التطبيقات الاستدلالية، والاستعلام عن الفواتير والأوامر، واسترداد بيانات السوق النموذجية، وتصدير سجلات طلبات الاستدلال أو الاستعلام عنها، والمزيد. فهو يوفر الإعداد الكامل لمصادقة التوقيع العالمي لـ UCloud (كيفية الحصول على المفتاح العام/المفتاح الخاص، وكيفية حساب التوقيع، وكيفية تحديد المنطقة ومعرف المشروع)، ويتضمن في المراجع/الدليل مواصفات معلمة الطلب/الاستجابة التفصيلية لجميع واجهات برمجة التطبيقات الإدارية المعروفة البالغ عددها 21 واجهة برمجة تطبيقات.
