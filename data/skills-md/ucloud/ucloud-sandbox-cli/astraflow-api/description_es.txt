Se utiliza cuando un usuario necesita llamar a las API de administración de la plataforma StarMap (AstraFlow/UModelVerse), cubriendo escenarios como la creación o administración de claves API de inferencia, consulta de facturación y pedidos, recuperación de datos de mercado de modelos, exportación o consulta de registros de solicitudes de inferencia, y más. Proporciona la preparación completa para la autenticación de firma universal de UCloud (cómo obtener la clave pública/clave privada, cómo calcular la firma, cómo determinar la región y el ID del proyecto) e incluye en las referencias/directorio las especificaciones detalladas de los parámetros de solicitud/respuesta para las 21 API de administración conocidas.
