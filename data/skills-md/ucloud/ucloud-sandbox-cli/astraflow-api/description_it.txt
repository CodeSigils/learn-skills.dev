Utilizzato quando un utente deve chiamare le API di gestione della piattaforma StarMap (AstraFlow/UModelVerse), coprendo scenari come la creazione o la gestione di chiavi API di inferenza, l'esecuzione di query su fatturazione e ordini, il recupero di dati di mercato dei modelli, l'esportazione o l'interrogazione di registri di richieste di inferenza e altro ancora. Fornisce la preparazione completa per l'autenticazione della firma universale di UCloud (come ottenere la chiave pubblica/privata, come calcolare la firma, come determinare la regione e l'ID progetto) e include nei riferimenti/directory le specifiche dettagliate dei parametri di richiesta/risposta per tutte le 21 API di gestione conosciute.
