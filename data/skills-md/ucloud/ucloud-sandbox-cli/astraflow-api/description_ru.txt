Используется, когда пользователю необходимо вызвать API-интерфейсы управления платформы StarMap (AstraFlow / UModelVerse), охватывая такие сценарии, как создание или управление ключами API вывода, запрос счетов и заказов, получение данных модельного рынка, экспорт или запрос журналов запросов вывода и многое другое. Он обеспечивает полную подготовку к аутентификации универсальной подписи UCloud (как получить PublicKey/PrivateKey, как вычислить подпись, как определить регион и ProjectId) и включает в ссылки/каталог подробные спецификации параметров запроса/ответа для всех 21 известного API управления.
