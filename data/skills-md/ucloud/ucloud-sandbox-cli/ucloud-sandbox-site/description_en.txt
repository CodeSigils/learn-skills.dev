Used when the user provides a UCloud site space ID that begins with `site_` and requests to connect to or operate the site space. It applies to verifying site connections, executing commands, browsing and managing files, uploading or downloading code, reading site environment variables via ucloud-sandbox-cli, as well as generating, building, deploying, and troubleshooting website services running on port 80; all while adhering to the single‑sandbox permission boundary of site credentials and the requirement to mask sensitive variables.
