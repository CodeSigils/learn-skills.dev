Используется, когда пользователь предоставляет идентификатор пространства сайта UCloud, который начинается с `site_`, и запрашивает подключение к пространству сайта или управление им. Он применяется для проверки подключений к сайту, выполнения команд, просмотра файлов и управления ими, загрузки или скачивания кода, чтения переменных среды сайта через ucloud-sandbox-cli, а также для создания, создания, развертывания и устранения неполадок служб веб-сайтов, работающих на порту 80; при этом соблюдаются границы разрешений для учетных данных сайта в одной песочнице и требование маскировать конфиденциальные переменные.
