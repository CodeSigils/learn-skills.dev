Wenn ein Benutzer eine UCloud-Site-Space-ID bereitstellt, die mit „site_“ beginnt, und eine Verbindung zum Site-Space anfordert oder ihn bedient, wird diese verwendet. Es gilt für die Überprüfung von Site-Verbindungen über ucloud-sandbox-cli, das Ausführen von Befehlen, das Durchsuchen und Verwalten von Dateien, das Hoch- oder Herunterladen von Code, das Lesen von Site-Umgebungsvariablen sowie das Generieren, Erstellen, Bereitstellen und Fehlerbehebung von Website-Diensten, die auf Port 80 ausgeführt werden; Dabei werden auch die Single-Sandbox-Berechtigungsgrenzen der Site-Anmeldeinformationen und die Desensibilisierungsanforderungen für sensible Variablen eingehalten.
