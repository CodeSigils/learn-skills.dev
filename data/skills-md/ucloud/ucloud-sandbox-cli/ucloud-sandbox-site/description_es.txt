Se utiliza cuando un usuario proporciona una ID de espacio del sitio de UCloud que comienza con `site_` y solicita conectarse u operar el espacio del sitio. Se aplica para verificar las conexiones del sitio, ejecutar comandos, explorar y administrar archivos, cargar o descargar código, leer variables de entorno del sitio y generar, construir, implementar y solucionar problemas de servicios del sitio web que se ejecutan en el puerto 80 a través de ucloud-sandbox-cli, mientras se adhiere a los límites de permisos de la zona de pruebas única de las credenciales del sitio y los requisitos de enmascaramiento para variables confidenciales.
