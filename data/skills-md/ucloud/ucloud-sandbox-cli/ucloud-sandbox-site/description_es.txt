Se utiliza cuando el usuario proporciona una ID de espacio del sitio de UCloud que comienza con `site_` y solicita conectarse u operar el espacio del sitio. Se aplica para verificar conexiones de sitios, ejecutar comandos, explorar y administrar archivos, cargar o descargar códigos, leer variables de entorno del sitio a través de ucloud-sandbox-cli, así como generar, construir, implementar y solucionar problemas de servicios de sitios web que se ejecutan en el puerto 80; todo ello respetando el límite de permisos de la zona de pruebas única de las credenciales del sitio y el requisito de enmascarar las variables confidenciales.
