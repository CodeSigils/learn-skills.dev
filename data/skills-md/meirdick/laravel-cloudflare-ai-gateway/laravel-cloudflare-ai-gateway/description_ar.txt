يقوم بتكوين مشاريع Laravel وPHP لتوجيه حركة مرور الذكاء الاصطناعي من خلال Cloudflare AI Gateway من أجل إمكانية المراقبة والتخزين المؤقت وتحديد المعدل. يضيف الذكاء الاصطناعي للعمال كموفر نموذج مجاني مفتوح المصدر. يدعم Laravel AI SDK (laravel/ai) وPrism PHP (prism-php/prism). يُستخدم عندما يذكر المستخدم Cloudflare AI Gateway، أو Workers AI، أو إمكانية ملاحظة الذكاء الاصطناعي، أو مراقبة تكلفة الذكاء الاصطناعي، أو يريد وكيل حركة مرور موفر الذكاء الاصطناعي. يتم تشغيله أيضًا عندما يسأل شخص ما عن تسجيل طلبات الذكاء الاصطناعي، أو تخزين استجابات الذكاء الاصطناعي مؤقتًا، أو تحديد معدل مكالمات الذكاء الاصطناعي، أو مراقبة استخدام الذكاء الاصطناعي، أو استخدام نماذج الذكاء الاصطناعي المجانية، أو تقليل تكاليف الذكاء الاصطناعي، أو توجيه حركة مرور OpenAI/Anthropic/Gemini عبر بوابة - حتى لو لم يذكروا صراحة "Cloudflare" أو "البوابة".
