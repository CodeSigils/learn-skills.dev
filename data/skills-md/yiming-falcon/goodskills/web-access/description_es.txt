Todas las operaciones de red deben pasar por esta habilidad, incluidas: búsqueda, web scraping, acciones posteriores al inicio de sesión, interacciones de red, etc.  
Escenarios desencadenantes: cuando el usuario solicita buscar información, ver contenido web, visitar sitios que requieren inicio de sesión, operar interfaces web, rastrear redes sociales (Xiaohongshu, Weibo, Twitter, etc.), leer páginas renderizadas dinámicamente o realizar cualquier tarea de red que necesite un entorno de navegador real.
