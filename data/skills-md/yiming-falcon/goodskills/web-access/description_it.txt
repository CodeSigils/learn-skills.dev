Tutte le operazioni di rete devono essere gestite tramite questa abilità, tra cui: ricerca, web scraping, azioni post-accesso, interazioni di rete, ecc.  
Scenari di attivazione: quando l'utente richiede la ricerca di informazioni, la visualizzazione di contenuti Web, l'accesso a siti Web che richiedono l'accesso, il funzionamento di interfacce Web, lo scraping di contenuti dei social media (Xiaohongshu, Weibo, Twitter, ecc.), la lettura di pagine visualizzate in modo dinamico e qualsiasi attività di rete che richieda un ambiente browser reale.
