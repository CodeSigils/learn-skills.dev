Die systematische Codeüberprüfung konzentrierte sich auf die Suche nach echten Fehlern – grenzüberschreitende Vertragsinkongruenzen, Logikfehler, asynchrone Fehler und Laufzeitfehler. Verwenden Sie diese Option, wenn Sie KI-generierten Code überprüfen, eine PR überprüfen, eine Codebasis auf Fehler prüfen oder wenn der Benutzer sagt: „Diesen Code überprüfen“, „Fehler finden“, „Auf Probleme prüfen“ oder „Nichtübereinstimmung finden“.
