Examen systématique du code axé sur la recherche de bogues réels : incompatibilités de contrats transfrontalières, erreurs logiques, bogues asynchrones et échecs d'exécution. À utiliser lors de la révision du code généré par l'IA, de la révision d'un PR, de l'audit d'une base de code à la recherche de bogues ou lorsque l'utilisateur dit « réviser ce code », « rechercher des bogues », « vérifier les problèmes » ou « trouver une incompatibilité ».
