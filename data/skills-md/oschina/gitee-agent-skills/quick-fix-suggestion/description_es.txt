Utilice esta habilidad cuando el usuario desee obtener sugerencias de solución rápida para un problema.
"cómo solucionar este problema", "dónde debo hacer cambios", "sugerencia de solución rápida",
"sugerir solución", "sugerencia de solución", "cómo implementar este problema",
o antes de comenzar la implementación para comprender el alcance de los cambios.
Esta habilidad analiza el contenido del problema, localiza el código relevante en el repositorio,
y sugiere qué archivos modificar con los borradores de planes de implementación.
Requiere la configuración del servidor Gitee MCP y debe ejecutarse en un repositorio git local.
