Используйте этот навык, когда пользователь хочет получить предложения по быстрому устранению проблемы.
«как исправить эту проблему», «где мне следует внести изменения», «предложение по быстрому исправлению»,
«предложить исправление», «предложение по исправлению», «как реализовать эту проблему»,
или перед началом реализации, чтобы понять масштаб изменений.
Этот навык анализирует содержание проблемы, находит соответствующий код в репозитории,
и предлагает, какие файлы изменить с помощью проектов планов реализации.
Требуется настроить сервер Gitee MCP и запустить его в локальном репозитории git.
