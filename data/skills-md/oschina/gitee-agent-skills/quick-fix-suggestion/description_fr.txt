Utilisez cette compétence lorsque l'utilisateur souhaite obtenir des suggestions de solutions rapides à un problème,
"comment résoudre ce problème", "où dois-je apporter des modifications", "suggestion de solution rapide",
"suggérer un correctif", "suggestion de correctif", "comment implémenter ce problème",
ou avant de commencer la mise en œuvre pour comprendre la portée des changements.
Cette compétence analyse le contenu du problème, localise le code pertinent dans le référentiel,
et suggère les fichiers à modifier avec les projets de plans de mise en œuvre.
Nécessite la configuration du serveur Gitee MCP et doit être exécuté dans un référentiel git local.
