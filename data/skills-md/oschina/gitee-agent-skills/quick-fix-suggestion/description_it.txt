Utilizza questa abilità quando l'utente desidera ricevere suggerimenti per la soluzione rapida di un problema,
"come risolvere questo problema", "dove dovrei apportare modifiche", "suggerimento per la soluzione rapida",
"suggerisci soluzione", "suggerimento per la soluzione", "come implementare questo problema",
o prima di iniziare l'implementazione per comprendere la portata delle modifiche.
Questa abilità analizza il contenuto del problema, individua il codice rilevante nel repository,
e suggerisce quali file modificare con le bozze dei piani di attuazione.
Richiede la configurazione di Gitee MCP Server e deve essere eseguito in un repository git locale.
