Verwenden Sie diesen Skill, wenn der Benutzer schnelle Lösungsvorschläge für ein Problem erhalten möchte.
„Wie kann ich dieses Problem beheben“, „Wo sollte ich Änderungen vornehmen“, „Schnelllösungsvorschlag“,
„Behebung vorschlagen“, „Behebungsvorschlag“, „So implementieren Sie dieses Problem“,
oder bevor Sie mit der Implementierung beginnen, um den Umfang der Änderungen zu verstehen.
Diese Fähigkeit analysiert den Issue-Inhalt, findet relevanten Code im Repository und
und schlägt mit Entwürfen von Implementierungsplänen vor, welche Dateien geändert werden sollen.
Erfordert die Konfiguration des Gitee MCP-Servers und muss in einem lokalen Git-Repository ausgeführt werden.
