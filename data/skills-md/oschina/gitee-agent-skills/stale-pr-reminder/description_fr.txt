Utilisez cette compétence lorsque l'utilisateur souhaite vérifier les PR obsolètes, "trouver d'anciennes demandes d'extraction",
"PR obsolètes", "PR nécessitant une attention" ou souhaite identifier les demandes d'extraction qui ont
resté trop longtemps inactif. Cette compétence analyse les référentiels à la recherche des PR qui nécessitent une action
et génère un rapport de rappel hiérarchisé. Nécessite la configuration du serveur Gitee MCP.
