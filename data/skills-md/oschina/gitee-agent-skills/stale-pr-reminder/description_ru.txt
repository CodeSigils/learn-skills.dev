Используйте этот навык, когда пользователь хочет проверить устаревшие PR, «найти старые запросы на включение»,
«устаревшие PR», «PR, требующие внимания» или хочет выявить запросы на включение, которые
слишком долго был неактивен. Этот навык сканирует репозитории на наличие PR, требующих действий.
и генерирует приоритетный отчет с напоминанием. Требуется настроить сервер Gitee MCP.
