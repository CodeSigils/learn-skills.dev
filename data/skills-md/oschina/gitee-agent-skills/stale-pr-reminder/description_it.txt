Utilizza questa abilità quando l'utente desidera verificare la presenza di PR obsoleti, "trovare vecchie richieste pull",
"PR obsoleti", "PR che necessitano di attenzione" o vuole identificare le richieste pull che hanno
rimasto inattivo per troppo tempo. Questa abilità analizza i repository per individuare i PR che necessitano di azione
e genera un rapporto di promemoria con priorità. Richiede la configurazione del server Gitee MCP.
