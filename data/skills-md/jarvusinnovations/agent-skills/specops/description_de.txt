Verwenden Sie diese Fähigkeit immer dann, wenn Sie mit neuen Funktionen beginnen, die Implementierung planen, Spezifikationen schreiben, Code anhand von Spezifikationen überprüfen oder wenn der Benutzer „spec“, „specs/“, „spec-first“ erwähnt oder fragt, wie etwas funktionieren soll.
