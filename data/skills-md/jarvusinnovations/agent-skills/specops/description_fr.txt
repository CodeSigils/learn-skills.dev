Flux de travail de développement basé sur les spécifications, où les spécifications sont la source de vérité. Utilisez cette compétence chaque fois que vous démarrez de nouvelles fonctionnalités, planifiez la mise en œuvre, rédigez des spécifications, révisez le code par rapport aux spécifications, ou lorsque l'utilisateur mentionne « spec », « specs/ », « spec-first » ou demande comment quelque chose devrait fonctionner. À utiliser également lors de la création d'un nouveau projet qui utilisera cette méthodologie de développement, ou lors de l'intégration d'une personne dans une base de code basée sur les spécifications.
