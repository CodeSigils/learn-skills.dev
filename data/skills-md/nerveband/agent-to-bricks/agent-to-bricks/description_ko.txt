에이전트-브릭 CLI(`bricks`)를 사용하여 Bricks Builder WordPress 사이트에 페이지를 빌드, 변환 및 배포합니다. 사용자가 페이지 생성, HTML 배포, 랜딩 페이지 구축, Bricks 사이트 업데이트, WordPress에 콘텐츠 푸시, HTML을 Bricks로 변환, Bricks Builder 요소 관리 등을 요청할 때 사용합니다. 또한 사용자가 페이지 구축의 맥락에서 Bricks Builder, ACSS, Automatic.css를 언급하거나 WordPress 사이트를 참조하는 경우에도 활성화됩니다.
