ينشئ الصفحات ويحولها وينشرها إلى موقع Bricks Builder WordPress باستخدام وكيل إلى الطوب CLI (`الطوب`). يُستخدم عندما يطلب المستخدم إنشاء صفحة، أو نشر HTML، أو إنشاء صفحة مقصودة، أو تحديث موقع Bricks، أو دفع المحتوى إلى WordPress، أو تحويل HTML إلى Bricks، أو إدارة عناصر Bricks Builder. يتم تنشيطه أيضًا عندما يذكر المستخدم Bricks Builder، أو ACSS، أو Automatic.css، أو يشير إلى موقع WordPress الخاص به في سياق إنشاء الصفحة.
