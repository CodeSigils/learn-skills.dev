Erstellt, konvertiert und stellt Seiten auf einer Bricks Builder-WordPress-Site mithilfe der Agent-to-Bricks-CLI („Bricks“) bereit. Verwenden Sie diese Option, wenn der Benutzer eine Seite erstellen, HTML bereitstellen, eine Zielseite erstellen, eine Bricks-Site aktualisieren, Inhalte an WordPress übertragen, HTML in Bricks konvertieren oder Bricks Builder-Elemente verwalten möchte. Wird auch aktiviert, wenn der Benutzer Bricks Builder, ACSS, Automatic.css erwähnt oder im Kontext der Seitenerstellung auf seine WordPress-Site verweist.
