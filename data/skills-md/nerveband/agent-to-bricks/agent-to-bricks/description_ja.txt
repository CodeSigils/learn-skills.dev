Agent-to-Bricks CLI (「bricks」) を使用して、ページを構築、変換し、Bricks Builder WordPress サイトにデプロイします。ユーザーがページの作成、HTML のデプロイ、ランディング ページの構築、Bricks サイトの更新、WordPress へのコンテンツのプッシュ、HTML から Bricks への変換、または Bricks Builder 要素の管理を要求する場合に使用します。ユーザーが Bricks Builder、ACSS、Automatic.css に言及したとき、またはページ構築のコンテキストで WordPress サイトを参照したときにもアクティブになります。
