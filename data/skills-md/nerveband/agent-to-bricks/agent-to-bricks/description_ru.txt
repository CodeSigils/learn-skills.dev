Создает, конвертирует и развертывает страницы на сайте Bricks Builder WordPress с помощью интерфейса командной строки агент-кирпичи («кирпичи»). Используйте, когда пользователь запрашивает создание страницы, развертывание HTML, создание целевой страницы, обновление сайта Bricks, отправку контента в WordPress, преобразование HTML в Bricks или управление элементами Bricks Builder. Также активируется, когда пользователь упоминает Bricks Builder, ACSS, Automatic.css или ссылается на свой сайт WordPress в контексте создания страниц.
