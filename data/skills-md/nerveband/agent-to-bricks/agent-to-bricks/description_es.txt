Crea, convierte e implementa páginas en un sitio de WordPress de Bricks Builder utilizando la CLI de agente a ladrillos ("bricks"). Úselo cuando el usuario solicite crear una página, implementar HTML, crear una página de destino, actualizar un sitio de Bricks, enviar contenido a WordPress, convertir HTML a Bricks o administrar elementos de Bricks Builder. También se activa cuando el usuario menciona Bricks Builder, ACSS, Automatic.css o hace referencia a su sitio de WordPress en el contexto de la creación de páginas.
