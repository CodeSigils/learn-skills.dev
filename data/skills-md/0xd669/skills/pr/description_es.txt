Crea o actualiza una solicitud de extracción (pull request) de GitHub para la rama actual. Úsalo cuando el usuario solicite publicar los cambios confirmados de la rama como una PR o actualizar el cuerpo de una PR existente. No lo uses para copias de PR solo como borrador, revisión de PR, reparación de CI, correcciones de comentarios de revisión o un push que no incluya crear o actualizar una PR.
