Erstellt oder aktualisiert eine GitHub-Pull-Anfrage für den aktuellen Zweig. Verwenden Sie diese Option, wenn der Benutzer verpflichtete Zweigänderungen als PR veröffentlichen oder den Hauptteil einer vorhandenen PR aktualisieren möchte. Nicht für reine PR-Entwürfe, PR-Überprüfungen, CI-Reparaturen, Review-Kommentar-Korrekturen oder einen Push verwenden, der nicht das Erstellen oder Aktualisieren einer PR umfasst.
