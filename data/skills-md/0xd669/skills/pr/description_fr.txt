Crée ou met à jour une demande d'extraction GitHub pour la branche actuelle. À utiliser lorsque l'utilisateur demande de publier les modifications de branche validées en tant que PR ou d'actualiser le corps d'un PR existant. Ne pas utiliser pour une copie de PR uniquement en brouillon, une révision de PR, une réparation de CI, des correctifs de commentaires de révision ou une diffusion qui n'inclut pas la création ou la mise à jour d'une PR.
