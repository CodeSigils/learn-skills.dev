Crea o aggiorna una richiesta pull GitHub per il ramo corrente. Da utilizzare quando l'utente richiede di pubblicare le modifiche apportate al ramo come PR o aggiornare il corpo di un PR esistente. Non utilizzare per copia PR di sola bozza, revisione PR, riparazione CI, correzioni di commenti di revisione o push che non includa la creazione o l'aggiornamento di un PR.
