Escribe, reescribe, diagnostica y mejora cualquier prompt de LLM con ediciones mínimas y de alto impacto. Úselo cuando el usuario quiera crear un nuevo prompt desde cero, revisar o corregir un prompt que produce una salida deficiente, simplificar o ajustar instrucciones, reestructurar un prompt largo o ampliar un prompt existente. Cubre prompts del sistema, instrucciones de agentes, reglas CLAUDE.md, cuerpos de prompts SKILL.md, plantillas de chat, prompts de salida estructurada, plantillas de contexto RAG y cadenas de prompts incrustadas en código. También úselos al editar cualquier archivo cuyo contenido principal sean instrucciones para LLM. No lo emplee para la estructuración de habilidades, empaquetado o ejecuciones de evaluación; reescribir el cuerpo del prompt de una habilidad existente está dentro del alcance.
