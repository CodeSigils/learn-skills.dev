Écrit, réécrit, diagnostique et améliore n'importe quelle invite LLM avec des modifications minimales et à signal élevé. À utiliser lorsque l'utilisateur souhaite créer une nouvelle invite à partir de zéro, réviser ou corriger une invite qui produit un résultat médiocre, simplifier ou resserrer les instructions, restructurer une invite longue ou développer une invite existante. Couvre les invites système, les instructions d'agent, les règles CLAUDE.md, les corps d'invite SKILL.md, les modèles de discussion, les invites de sortie structurée, les modèles de contexte RAG et les chaînes d'invite intégrées dans le code. À utiliser également lors de l'édition de tout fichier dont le contenu principal est constitué d'instructions LLM. Ne pas utiliser pour des échafaudages de compétences, des emballages ou des évaluations ; la réécriture du corps d'invite d'une compétence existante est dans le champ d'application.
