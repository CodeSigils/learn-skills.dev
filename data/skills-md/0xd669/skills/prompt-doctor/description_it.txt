Scrive, riscrive, diagnostica e migliora qualsiasi prompt LLM con modifiche minime e ad alto segnale. Da utilizzare quando l'utente desidera creare un nuovo prompt da zero, rivedere o correggere un prompt che produce un output scadente, semplificare o restringere le istruzioni, ristrutturare un prompt lungo o espandere un prompt esistente. Copre prompt di sistema, istruzioni dell'agente, regole CLAUDE.md, corpi di prompt SKILL.md, modelli di chat, prompt di output strutturato, modelli di contesto RAG e stringhe di prompt incorporate nel codice. Da utilizzare anche durante la modifica di file il cui contenuto principale sono istruzioni LLM. Non utilizzare per impalcature di competenze, confezionamento o esecuzioni di valutazione; rientra nell'ambito della riscrittura del corpo del prompt di un'abilità esistente.
