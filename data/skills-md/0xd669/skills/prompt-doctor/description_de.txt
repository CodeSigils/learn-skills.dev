Schreibt, schreibt neu, diagnostiziert und verbessert jede LLM-Eingabeaufforderung mit minimalen, signalintensiven Bearbeitungen. Verwenden Sie diese Option, wenn der Benutzer eine neue Eingabeaufforderung von Grund auf erstellen, eine Eingabeaufforderung überprüfen oder korrigieren möchte, die eine schlechte Ausgabe liefert, Anweisungen vereinfachen oder verschärfen, eine lange Eingabeaufforderung umstrukturieren oder eine vorhandene Eingabeaufforderung erweitern möchte. Behandelt Systemeingabeaufforderungen, Agentenanweisungen, CLAUDE.md-Regeln, SKILL.md-Eingabeaufforderungstexte, Chat-Vorlagen, Eingabeaufforderungen mit strukturierter Ausgabe, RAG-Kontextvorlagen und in Code eingebettete Eingabeaufforderungszeichenfolgen. Auch beim Bearbeiten von Dateien verwenden, deren Hauptinhalt LLM-Anweisungen sind. Nicht für Fertigkeitsgerüste, Verpackungen oder Evaluierungsläufe verwenden; Das Umschreiben des Eingabeaufforderungstexts einer vorhandenen Fertigkeit ist im Umfang enthalten.
