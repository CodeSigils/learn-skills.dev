Crea ed esegue un unico commit Git coerente a partire dalle modifiche in staging o selezionate nell’albero di lavoro. Usalo quando l’utente chiede di committare le modifiche, mettere in staging e committare un cambiamento logico, oppure creare un commit Git con un messaggio appropriato. Non usarlo per una richiesta di messaggio solo bozza o per un’operazione che si limita a pushare commit esistenti.
