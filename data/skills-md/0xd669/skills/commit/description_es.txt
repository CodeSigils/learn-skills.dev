Crea y ejecuta una confirmación Git coherente a partir de cambios de árbol de trabajo por etapas o seleccionados. Úselo cuando el usuario solicite confirmar cambios, organizar y confirmar un cambio lógico, o crear una confirmación de Git con un mensaje apropiado. No lo utilice para una solicitud de mensaje de solo borrador o una operación que solo empuje las confirmaciones existentes.
