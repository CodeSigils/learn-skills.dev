Crée et exécute un commit git cohérent à partir de modifications de l'arbre de travail mises en scène ou sélectionnées. À utiliser lorsque l'utilisateur demande de valider des modifications, d'effectuer et de valider une modification logique ou de créer un git commit avec un message approprié. Ne pas utiliser pour une demande de message en brouillon uniquement ou pour une opération qui pousse uniquement les validations existantes.
