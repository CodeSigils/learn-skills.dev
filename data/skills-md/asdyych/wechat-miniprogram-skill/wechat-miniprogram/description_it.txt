Guida allo sviluppo rapido del WeChat Mini Program (微信小程序). Copre framework nativo (WXML, WXSS, WXS), API (wx.request, wx.navigateTo, wx.login, wx.requestPayment), componenti, sviluppo cloud (云开发) e strumenti multipiattaforma (Taro, uni-app). Da utilizzare durante la creazione, il debug o l'ottimizzazione di 微信小程序 o quando viene chiesto informazioni sul ciclo di vita del mini programma, sulla struttura del progetto, sui componenti personalizzati, sui sottopacchetti o sul flusso di pagamento WeChat.
