Guide de développement rapide du mini programme WeChat (微信小程序). Couvre le framework natif (WXML, WXSS, WXS), les API (wx.request, wx.navigateTo, wx.login, wx.requestPayment), les composants, le développement cloud (云开发) et les outils multiplateformes (Taro, uni-app). À utiliser lors de la création, du débogage ou de l'optimisation de 微信小程序, ou lorsque vous êtes interrogé sur le cycle de vie du mini-programme, la structure du projet, les composants personnalisés, les sous-packages ou le flux de paiement WeChat.
