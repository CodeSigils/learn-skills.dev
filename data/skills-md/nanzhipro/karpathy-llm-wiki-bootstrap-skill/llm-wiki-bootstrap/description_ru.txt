Создает персональную LLM Wiki с нуля — модель Карпати, постепенное создание постоянной, взаимосвязанной базы знаний по уценке, поддерживаемой LLM. Создает структуру каталогов, файл схемы, индекс, журнал и соглашения о рабочих процессах. Используйте, когда пользователь говорит «создать вики», «новую вики», «загрузочную вики», «llm вики», «база знаний», «запустить вики», «создать вики» или хочет настроить структурированную базу знаний с уценкой для любого домена.
