Crea una Wiki personal de LLM desde cero: el patrón Karpathy de construcción incremental de una base de conocimientos de rebajas persistente e interconectada mantenida por los LLM. Genera estructura de directorios, archivos de esquema, índices, registros y convenciones de flujo de trabajo. Úselo cuando el usuario diga "crear wiki", "nuevo wiki", "bootstrap wiki", "llm wiki", "base de conocimientos", "iniciar un wiki", "construir un wiki" o desea configurar una base de conocimientos de rebajas estructurada para cualquier dominio.
