Настройте длительный рабочий процесс Phase-Contract, который позволит агенту ИИ работать непрерывно в течение 5+ часов над одним проектом. Используйте, когда пользователь хочет спланировать большую миграцию, сборку нового продукта, большой рефакторинг, проект написания подробной формы, восстановление соответствия или любую многоэтапную задачу, выходящую за пределы одного контекстного окна. Триггеры: «让 AI 连续工作», «长任务规划», «分阶段执行», «фаза 规划», «план 规划», «多阶段迁移», '大型重构规划', 'длительный рабочий процесс ИИ', 'фазовый контракт', 'planctl', 'манифест + выполнение 双文档', '拆 фаза', '规划压缩恢复', '给 план AI 写', «项目分阶段», «续跑规划», «合同链规划», «长任务续跑工作流». Создает шаблоны plan/manifest.yaml, plan/common.md, plan/phases/, plan/execution/, сценарий планировщика planctl, а также синхронизированные файлы инструкций агента (.github/copilot-instructions.md для Copilot, CLAUDE.md для Claude Code, AGENTS.md для Codex), поэтому фазовое состояние выводится наружу, и работа ИИ может выдерживать сжатие контекста во всех трех агентах.
