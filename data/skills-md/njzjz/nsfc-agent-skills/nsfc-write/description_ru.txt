Руководство по написанию приложений NSFC. Охватывает методы написания и шаблоны для каждого раздела, включая выбор темы, аннотацию, обоснование проекта, содержание исследования, план исследования, инновации, технико-экономическое обоснование и многое другое. Применимо к таким типам проектов, как «Фонд молодых ученых», «Общие» и «Ключевые проекты».
