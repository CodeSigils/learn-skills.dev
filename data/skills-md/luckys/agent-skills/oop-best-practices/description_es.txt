Guía diaria de programación orientada a objetos para escribir y revisar código limpio y fácil de mantener. Úselo al nombrar clases y métodos, definir límites de objetos, introducir o revisar objetos de valor (igualdad, hash, inmutabilidad, análisis, normalización, opcionalidad), diseñar colecciones de primera clase, aplicar Tell Don't Ask o la ley de Demeter, hacer cumplir la calistenia de objetos, reducir problemas de cohesión, elegir entre herencia y composición, o revisar violaciones SOLID en TypeScript, Java, C#, Python, Ruby, PHP, Go o Rust.
