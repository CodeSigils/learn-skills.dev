Этот навык следует использовать, когда у пользователя есть существующее резюме и он хочет его оптимизировать/улучшить. Вызывается такими фразами, как «оптимизировать мое резюме», «улучшить это резюме», «сделать его лучше», «отшлифовать мое резюме», «переписать для этой работы». В качестве входных данных требуется существующее резюме. НЕ используйте для создания с нуля (вместо этого используйте генерирование).
