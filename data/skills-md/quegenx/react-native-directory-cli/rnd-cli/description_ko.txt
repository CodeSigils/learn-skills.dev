`rnd` CLI를 사용하여 유지 관리 상태, 새로운 아키텍처 지원, TypeScript 유형, GitHub 활동, 대안 및 프로젝트 감사와 같은 패키지 정보를 React Native Directory(~2400개 패키지)에 쿼리합니다. 사용자가 React Native 또는 Expo 패키지를 언급하거나, 라이브러리가 유지 관리되는지 묻고, RN 라이브러리에 대한 교체/대안을 원하고, React Native 프로젝트의 deps를 감사하고, 두 개의 RN 패키지를 비교하거나, 새 아키텍처/패브릭/터보 모듈/Expo 모듈 호환성에 대해 논의할 때마다 호출합니다. 또한 React Native 코드를 검토할 때 트리거되며 패키지의 상태를 확인하거나 더 나은 것을 찾아야 합니다. 사용자가 명시적으로 "디렉토리를 확인하세요"라고 말하지 않더라도 마찬가지입니다. 이 CLI는 의견이 아닌 사실만 전달합니다. 그들에 대해 스스로 추론하십시오.
