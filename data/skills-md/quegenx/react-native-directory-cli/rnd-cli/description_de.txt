Verwenden Sie die „rnd“-CLI, um das React Native Directory (~2400 Pakete) nach Paketfakten abzufragen – Wartungsstatus, New-Arch-Unterstützung, TypeScript-Typen, GitHub-Aktivität, Alternativen und Projektprüfungen. Wird aufgerufen, wenn der Benutzer React Native- oder Expo-Pakete erwähnt, fragt, ob eine Bibliothek verwaltet wird, einen Ersatz/eine Alternative für eine RN-Bibliothek wünscht, die Deps seines React Native-Projekts prüft, zwei RN-Pakete vergleicht oder die Kompatibilität von neuen Architekturen/Fabric/Turbo-Modulen/Expo-Modulen bespricht. Wird auch beim Überprüfen von React Native-Code ausgelöst und Sie müssen den Zustand eines Pakets überprüfen oder etwas Besseres finden – auch wenn der Benutzer nicht ausdrücklich „Überprüfen Sie das Verzeichnis“ sagt. Diese CLI gibt nur Fakten aus, niemals Meinungen; Denken Sie selbst darüber nach.
