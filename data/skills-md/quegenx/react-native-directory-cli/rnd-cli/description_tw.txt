使用「rnd」 CLI 查詢 React Native Directory（約 2400 個套件）以取得套件事實 - 維護狀態、新架構支援、TypeScript 類型、GitHub 活動、替代方案和專案審核。每當使用者提到 React Native 或 Expo 套件、詢問是否維護函式庫、想要 RN 函式庫的替換/替代、審核其 React Native 專案的 deps、比較兩個 RN 套件或討論新架構/Fabric/Turbo 模組/Expo 模組相容性時呼叫。在查看 React Native 程式碼並且您需要驗證套件的運行狀況或找到更好的東西時也會觸發 - 即使用戶沒有明確地說「檢查目錄」。此 CLI 僅發布事實，絕不發表意見；你自己對它們進行推理。
