Utilizza la CLI `rnd` per interrogare la React Native Directory (~2400 pacchetti) per informazioni sui pacchetti: stato di manutenzione, supporto new-arch, tipi TypeScript, attività GitHub, alternative e controlli del progetto. Richiama ogni volta che l'utente menziona pacchetti React Native o Expo, chiede se una libreria è mantenuta, desidera una sostituzione/alternativa per una libreria RN, controlla le dipendenze del progetto React Native, confronta due pacchetti RN o discute la compatibilità di nuova architettura/fabbrica/moduli Turbo/moduli Expo. Si attiva anche quando si esamina il codice React Native ed è necessario verificare l'integrità di un pacchetto o trovare qualcosa di meglio, anche se l'utente non dice esplicitamente "controlla la directory". Questa CLI emette solo fatti, mai opinioni; ragionane tu stesso.
