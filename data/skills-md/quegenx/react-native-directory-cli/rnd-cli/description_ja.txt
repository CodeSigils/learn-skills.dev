「rnd」 CLI を使用して、React Native Directory (約 2400 パッケージ) にパッケージの事実 (メンテナンス ステータス、新しいアーキテクチャのサポート、TypeScript の種類、GitHub アクティビティ、代替案、プロジェクト監査) を問い合わせます。ユーザーが React Native または Expo パッケージについて言及した場合、ライブラリが維持されているかどうかを尋ねた場合、RN ライブラリの代替/代替が必要な場合、React Native プロジェクトの deps を監査する場合、2 つの RN パッケージを比較する場合、または新しいアーキテクチャ / ファブリック / ターボ モジュール / Expo モジュールの互換性について議論する場合に必ず呼び出します。また、React Native コードをレビューするときにもトリガーされ、ユーザーが明示的に「ディレクトリを確認してください」と言わなくても、パッケージの健全性を確認するか、より良いものを見つける必要があります。この CLI は事実のみを出力し、意見は出力しません。自分で理由を説明してください。
