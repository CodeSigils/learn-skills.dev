استخدم واجهة سطر الأوامر "rnd" للاستعلام عن دليل React Native Directory (حوالي 2400 حزمة) للحصول على حقائق الحزمة - حالة الصيانة، ودعم القوس الجديد، وأنواع TypeScript، ونشاط GitHub، والبدائل، وعمليات تدقيق المشروع. يتم الاستدعاء عندما يذكر المستخدم حزم React Native أو Expo، أو يسأل عما إذا كانت المكتبة قد تمت صيانتها، أو يريد استبدال/بديل لمكتبة RN، أو يراجع عمليات مشروع React Native الخاصة به، أو يقارن حزمتي RN، أو يناقش التوافق مع البنية الجديدة/النسيج/وحدات Turbo/وحدات Expo. يتم تشغيله أيضًا عند مراجعة كود React Native وتحتاج إلى التحقق من صحة الحزمة أو العثور على شيء أفضل - حتى لو لم يقل المستخدم صراحةً "التحقق من الدليل". يصدر مؤشر سطر الأوامر هذا حقائق فقط، وليس آراءً أبدًا؛ السبب عنهم نفسك.
