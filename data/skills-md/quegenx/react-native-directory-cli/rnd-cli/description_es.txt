Utilice la CLI `rnd` para consultar el directorio nativo de React (~2400 paquetes) para obtener información sobre los paquetes: estado de mantenimiento, compatibilidad con nuevos archivos, tipos de TypeScript, actividad de GitHub, alternativas y auditorías del proyecto. Invoque cada vez que el usuario mencione paquetes React Native o Expo, pregunte si se mantiene una biblioteca, quiera un reemplazo/alternativa para una biblioteca RN, audite los departamentos de su proyecto React Native, compare dos paquetes RN o analice la compatibilidad de nueva arquitectura/fabricación/módulos turbo/módulos Expo. También se activa cuando se revisa el código de React Native y es necesario verificar el estado de un paquete o encontrar algo mejor, incluso si el usuario no dice explícitamente "verificar el directorio". Esta CLI emite únicamente hechos, nunca opiniones; razona sobre ellos tú mismo.
