Используйте CLI `rnd` для запроса в React Native Directory (около 2400 пакетов) фактов о пакете — статуса обслуживания, поддержки новых версий, типов TypeScript, активности GitHub, альтернатив и аудита проекта. Вызывайте каждый раз, когда пользователь упоминает пакеты React Native или Expo, спрашивает, поддерживается ли библиотека, хочет заменить/альтернативу библиотеки RN, проверяет данные своего проекта React Native, сравнивает два пакета RN или обсуждает совместимость новой архитектуры/Fabric/Turbo-модулей/модулей Expo. Также срабатывает при просмотре кода React Native, и вам нужно проверить работоспособность пакета или найти что-то получше — даже если пользователь явно не говорит «проверьте каталог». Этот CLI выдает только факты, а не мнения; рассуждайте о них сами.
