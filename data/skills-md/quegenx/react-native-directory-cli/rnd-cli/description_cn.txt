使用“rnd” CLI 查询 React Native Directory（约 2400 个包）以获取包事实 - 维护状态、新架构支持、TypeScript 类型、GitHub 活动、替代方案和项目审核。每当用户提到 React Native 或 Expo 包、询问是否维护库、想要 RN 库的替换/替代、审核其 React Native 项目的 deps、比较两个 RN 包或讨论新架构/Fabric/Turbo 模块/Expo 模块兼容性时调用。在查看 React Native 代码并且您需要验证包的运行状况或找到更好的东西时也会触发 - 即使用户没有明确地说“检查目录”。此 CLI 仅发布事实，绝不发表意见；你自己对它们进行推理。
