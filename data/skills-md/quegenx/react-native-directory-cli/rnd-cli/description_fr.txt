Utilisez la CLI `rnd` pour interroger le React Native Directory (~ 2 400 packages) pour obtenir des informations sur les packages : état de maintenance, prise en charge de new arch, types TypeScript, activité GitHub, alternatives et audits de projet. Invoquer chaque fois que l'utilisateur mentionne les packages React Native ou Expo, demande si une bibliothèque est maintenue, souhaite un remplacement/alternative pour une bibliothèque RN, audite les dépôts de son projet React Native, compare deux packages RN ou discute de la compatibilité de la nouvelle architecture / Fabric / Turbo Modules / Expo Modules. Déclenchez également lors de l'examen du code React Native et vous devez vérifier l'état d'un package ou trouver quelque chose de mieux, même si l'utilisateur ne dit pas explicitement « vérifier le répertoire ». Cette CLI émet uniquement des faits, jamais des opinions ; raisonnez-en vous-même.
