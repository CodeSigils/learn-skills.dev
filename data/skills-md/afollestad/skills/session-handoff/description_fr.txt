Invoquez cette compétence chaque fois que l'utilisateur vous demande de produire une invite, un résumé ou un package contextuel destiné à servir d'entrée pour une future session d'IA. Cela couvre : les invites de transfert, les vidages de contexte, les invites de nouveau thread, les invites prêtes à coller pour de nouvelles sessions ou toute demande visant à distiller cette conversation afin qu'une autre instance Claude ou un agent d'arrière-plan puisse continuer le travail. Invoquez également lorsque l'utilisateur mentionne les limites de la fenêtre contextuelle, des problèmes de longueur de thread ou souhaite réinitialiser/terminer tout en préservant la progression pour une prochaine session. Cette compétence possède le format de sortie et le filtrage par pertinence – ne tentez pas ces transferts sans elle. N'invoquez PAS d'artefacts destinés à un public humain : documents, README, messages de validation, tickets, notes de version, mises à jour standup, explications de code ou transferts à des collègues humains.
