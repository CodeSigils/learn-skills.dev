Rufen Sie diese Fähigkeit immer dann auf, wenn der Benutzer Sie auffordert, eine Eingabeaufforderung, Zusammenfassung oder ein Kontextpaket zu erstellen, das als Eingabe für eine zukünftige KI-Sitzung dienen soll. Dies umfasst: Übergabeaufforderungen, Kontext-Dumps, Eingabeaufforderungen für neue Threads, Eingabeaufforderungen zum Einfügen für neue Sitzungen oder jede Anforderung, diese Konversation zu destillieren, damit eine andere Claude-Instanz oder ein Hintergrundagent die Arbeit fortsetzen kann. Rufen Sie es auch auf, wenn der Benutzer Kontextfensterbeschränkungen oder Thread-Längenprobleme erwähnt oder zurücksetzen/abschließen und gleichzeitig den Fortschritt für eine nächste Sitzung beibehalten möchte. Dieser Skill ist für das Ausgabeformat und die Relevanzfilterung zuständig – versuchen Sie diese Übergaben nicht ohne ihn. Rufen Sie KEINE Artefakte für das menschliche Publikum auf: Dokumente, READMEs, Commit-Nachrichten, Tickets, Versionshinweise, Standup-Updates, Code-Erklärungen oder Übergaben an menschliche Kollegen.
