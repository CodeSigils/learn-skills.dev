Invoque esta habilidad cada vez que el usuario le pida que produzca un mensaje, un resumen o un paquete contextual destinado a ser una entrada para una futura sesión de IA. Esto cubre: mensajes de transferencia, volcados de contexto, mensajes de nuevos hilos, mensajes de listo para pegar para sesiones nuevas o cualquier solicitud para destilar esta conversación para que otra instancia de Claude o agente en segundo plano pueda continuar el trabajo. También invoca cuando el usuario menciona límites de la ventana de contexto, preocupaciones sobre la longitud del hilo o desea restablecer/concluir mientras se preserva el progreso para una próxima sesión. Esta habilidad posee el formato de salida y el filtrado de relevancia; no intente realizar estas transferencias sin ella. NO invoque artefactos de audiencia humana: documentos, archivos README, mensajes de confirmación, tickets, notas de la versión, actualizaciones de pie, explicaciones de código o transferencias a compañeros de trabajo humanos.
