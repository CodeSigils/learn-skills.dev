قم باستدعاء هذه المهارة عندما يطلب منك المستخدم إنتاج حزمة موجهة أو ملخصة أو سياقية مخصصة كمدخل لجلسة ذكاء اصطناعي مستقبلية. يغطي هذا: مطالبات التسليم، أو عمليات تفريغ السياق، أو مطالبات سلسلة الرسائل الجديدة، أو المطالبات الجاهزة لللصق لجلسات جديدة، أو أي طلب لتقطير هذه المحادثة حتى يتمكن مثيل Claude أو وكيل الخلفية الآخر من مواصلة العمل. يتم الاستدعاء أيضًا عندما يذكر المستخدم حدود نافذة السياق، أو مخاوف بشأن طول مؤشر الترابط، أو الرغبة في إعادة التعيين/الاختتام مع الحفاظ على التقدم للجلسة التالية. تمتلك هذه المهارة تنسيق الإخراج وتصفية الصلة - لا تحاول إجراء عمليات التسليم هذه بدونها. لا تستدعي عناصر الجمهور البشري: المستندات، أو الملفات التمهيدية، أو رسائل الالتزام، أو التذاكر، أو ملاحظات الإصدار، أو التحديثات الاحتياطية، أو تفسيرات التعليمات البرمجية، أو عمليات التسليم لزملاء العمل من البشر.
