Argonauts Inc. مهارات تطوير الواجهة الأمامية. يُستخدم عند إنشاء مشروع من البداية باستخدام Next.js App Router أو React SPA (Vite)، والتصميم باستخدام Tailwind CSS v4 + shadcn/ui، وتنفيذ جلب البيانات باستخدام نمط العرض أثناء الجلب. ينطبق على جميع المهام المتعلقة بإنشاء مشاريع أمامية جديدة وتنفيذ المكونات وجلب البيانات وإدارة الحالة والتصميم. يُستخدم عندما: إنشاء مشاريع React/Next.js جديدة، وتنفيذ المكونات باستخدام shadcn/ui، وإعداد جلب البيانات، واختيار حلول إدارة الحالة، وتكوين Tailwind CSS v4.
