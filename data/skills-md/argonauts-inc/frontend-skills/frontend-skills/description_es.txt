Argonauts Inc. Habilidades de desarrollo front-end. Se utiliza al crear un proyecto desde cero usando Next.js App Router o React SPA (Vite), diseñar con Tailwind CSS v4 + shadcn/ui e implementar la recuperación de datos usando el patrón de renderizado a medida que se recupera. Se aplica a todas las tareas relacionadas con la creación de nuevos proyectos front-end, la implementación de componentes, la obtención de datos, la gestión del estado y el estilo. Úselo cuando: cree nuevos proyectos React/Next.js, implemente componentes con shadcn/ui, configure la recuperación de datos, elija soluciones de administración de estado, configure Tailwind CSS v4.
