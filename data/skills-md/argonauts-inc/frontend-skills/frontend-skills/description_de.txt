Argonauts Inc. Front-End-Entwicklungsfähigkeiten. Wird verwendet, wenn ein Projekt von Grund auf mit Next.js App Router oder React SPA (Vite) erstellt, mit Tailwind CSS v4 + shadcn/ui gestaltet und das Abrufen von Daten mithilfe des Render-as-you-fetch-Musters implementiert wird. Gilt für alle Aufgaben im Zusammenhang mit der Erstellung neuer Front-End-Projekte, der Implementierung von Komponenten, dem Abrufen von Daten, der Statusverwaltung und dem Styling. Verwendung bei: Erstellen neuer React/Next.js-Projekte, Implementieren von Komponenten mit shadcn/ui, Einrichten des Datenabrufs, Auswählen von Statusverwaltungslösungen, Konfigurieren von Tailwind CSS v4.
