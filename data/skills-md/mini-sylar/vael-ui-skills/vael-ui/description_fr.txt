À utiliser lors de l'écriture, de l'édition ou du débogage de code Vue 3 importé depuis « vael-ui » ou « vael-ui/vapor », une bibliothèque de composants indépendante de l'animation avec prise en charge complète de Vue Vapor. Couvre l'installation, la division vdom/vapor, l'importation automatique, la thématisation, le contrat indépendant de l'animation (motionCss/forceMount/beforeClose) et les composables impératifs (openDialog, openPopover, confirmAction, useToast, useTour).
