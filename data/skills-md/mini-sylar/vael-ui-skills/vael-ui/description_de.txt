Verwenden Sie es immer dann, wenn Sie Vue 3-Code schreiben, bearbeiten oder debuggen, der aus „vael-ui“ oder „vael-ui/vapor“ importiert wird, einer animationsunabhängigen Komponentenbibliothek mit vollständiger Vue Vapor-Unterstützung. Behandelt die Installation, die vdom/vapor-Aufteilung, den automatischen Import, das Theme, den animationsunabhängigen Vertrag (motionCss/forceMount/beforeClose) und zwingende Composables (openDialog, openPopover, bestätigenAction, useToast, useTour).
