استخدمه عند كتابة أو تحرير أو تصحيح كود Vue 3 الذي يتم استيراده من "vael-ui" أو "vael-ui/vapor"، وهي مكتبة مكونات غير محددة للرسوم المتحركة مع دعم Vue Vapor الكامل. يغطي التثبيت، وتقسيم vdom/vapor، والاستيراد التلقائي، والسمات، والعقد الحيادي للرسوم المتحركة (motionCss/forceMount/beforeClose)، والمركبات الحتمية (openDialog، وopenPopover، وconfirmAction، وuseToast، وuseTour).
