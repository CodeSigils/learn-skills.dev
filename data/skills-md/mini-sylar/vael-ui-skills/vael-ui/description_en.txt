Use whenever writing, editing, or debugging Vue 3 code that imports from "vael-ui" or "vael-ui/vapor", an animation-agnostic component library with full Vue Vapor support. Covers installation, the vdom/vapor split, auto-import, theming, the animation-agnostic contract (motionCss/forceMount/beforeClose), and imperative composables (openDialog, openPopover, confirmAction, useToast, useTour).
