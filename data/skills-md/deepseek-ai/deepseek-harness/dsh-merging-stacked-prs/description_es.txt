Úselo cuando coloque una pila de PR de GitHub dependientes (A ← B ← C, donde cada uno se basa en el siguiente) en el maestro, fusione un PR cuya base es la rama de otro PR abierto, o cuando una solicitud mencione "PR apilados", "pila de PR", "PR dependientes" o fusione varios PR relacionados en secuencia. Requiere que cada cadena de dependencia del mismo repositorio utilice la función oficial de relaciones públicas apiladas de GitHub antes de aterrizar, por lo que GitHub posee reglas para toda la pila, CI, ordenación, retargeting y estado de fusión.
