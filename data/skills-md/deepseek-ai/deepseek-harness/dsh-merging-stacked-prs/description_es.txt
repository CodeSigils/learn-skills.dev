Utilícelo al aterrizar una pila de PR de GitHub dependientes (A ← B ← C, donde cada una se basa en la siguiente) en el maestro, al fusionar una PR cuya base es otra rama de PR abierta, o cada vez que una solicitud mencione "PR apilados", "pila de PR", "PR dependientes" o al fusionar varias PR relacionadas en secuencia. Requiere que todas las cadenas de dependencias del mismo repositorio utilicen la función oficial de RRP apilada de GitHub antes de aterrizar, por lo que GitHub posee reglas de toda la pila, CI, pedidos, reorientación y estado de fusión.
