Da utilizzare quando si invia uno stack di PR GitHub dipendenti (A ← B ← C, dove ciascuno si basa su quello sottostante) sul master, unendo un PR la cui base è un altro ramo di PR aperto o ogni volta che una richiesta menziona "PR impilati", "stack PR", "PR dipendenti" o unendo diversi PR correlati in sequenza. Richiede che ogni catena di dipendenze dello stesso repository utilizzi la funzionalità PR in pila ufficiale di GitHub prima dell'atterraggio, in modo che GitHub possieda regole a livello di stack, CI, ordinamento, retargeting e stato di unione.
