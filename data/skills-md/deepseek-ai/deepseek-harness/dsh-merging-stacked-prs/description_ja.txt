依存する GitHub PR のスタック (A ← B ← C、それぞれは以下のものに基づいています) をマスターにランディングするとき、別の開いている PR のブランチをベースとする PR をマージするとき、またはリクエストで「スタックされた PR」、「PR スタック」、「依存する PR」に言及するとき、または複数の関連する PR を順番にマージするときに使用します。すべての同一リポジトリ依存関係チェーンは、GitHub がスタック全体のルール、CI、順序付け、リターゲット、およびマージ状態を所有するように、ランディング前に GitHub の公式スタック PR 機能を使用する必要があります。
