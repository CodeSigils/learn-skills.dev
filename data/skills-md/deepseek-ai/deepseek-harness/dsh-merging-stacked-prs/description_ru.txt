Используйте при размещении стека зависимых PR GitHub (A ← B ← C, где каждый основан на приведенном ниже) на главный, объединении PR, базой которого является ветвь другого открытого PR, или всякий раз, когда в запросе упоминаются «составленные PR», «стек PR», «зависимые PR» или последовательное слияние нескольких связанных PR. Требует, чтобы каждая цепочка зависимостей одного и того же репозитория использовала официальную функцию стекового PR GitHub перед приземлением, чтобы GitHub владел правилами всего стека, CI, упорядочиванием, перенацеливанием и состоянием слияния.
