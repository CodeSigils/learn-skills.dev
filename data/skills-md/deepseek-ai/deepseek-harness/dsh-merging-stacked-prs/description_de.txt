Wird verwendet, wenn ein Stapel abhängiger GitHub-PRs (A ← B ← C, wobei jeder auf dem folgenden basiert) auf dem Master landet, ein PR zusammengeführt wird, dessen Basis der Zweig eines anderen offenen PR ist, oder wenn in einer Anfrage „gestapelte PRs“, „PR-Stack“, „abhängige PRs“ erwähnt werden oder mehrere verwandte PRs nacheinander zusammengeführt werden. Erfordert, dass jede Abhängigkeitskette im selben Repository vor der Landung die offizielle Stacked-PR-Funktion von GitHub verwendet, sodass GitHub über stapelweite Regeln, CI, Reihenfolge, Retargeting und Zusammenführungsstatus verfügt.
