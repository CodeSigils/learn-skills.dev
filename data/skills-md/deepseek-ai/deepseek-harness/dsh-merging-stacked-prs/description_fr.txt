À utiliser lors de l'atterrissage d'une pile de PR GitHub dépendants (A ← B ← C, où chacun est basé sur celui ci-dessous) sur le maître, en fusionnant un PR dont la base est la branche d'un autre PR ouvert, ou chaque fois qu'une requête mentionne des « PR empilés », « pile PR », « PR dépendants » ou fusionner plusieurs PR liés en séquence. Nécessite que chaque chaîne de dépendances du même référentiel utilise la fonctionnalité officielle de relations publiques empilées de GitHub avant d'atterrir, afin que GitHub possède des règles à l'échelle de la pile, des CI, un classement, un reciblage et un état de fusion.
