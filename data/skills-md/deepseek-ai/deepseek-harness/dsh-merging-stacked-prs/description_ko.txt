GitHub PR 스택(A ← B ← C, 각각이 아래 PR을 기반으로 함)을 master 브랜치에 병합하거나, 다른 열린 PR의 브랜치를 기반으로 하는 PR을 병합하거나, 요청에서 &quot;스택형 PR&quot;, &quot;PR 스택&quot;, &quot;종속 PR&quot; 또는 여러 관련 PR을 순차적으로 병합하는 경우에 사용합니다. 동일 저장소의 모든 종속성 체인은 병합 전에 GitHub의 공식 스택형 PR 기능을 사용해야 합니다. 그래야 GitHub가 스택 전체에 대한 규칙, CI, 순서 지정, 리타겟팅 및 병합 상태를 관리할 수 있습니다.
