Génère une documentation technique complète pour les applications Appian à partir d'exports XML (racine du projet = dossier app) : inventaire, architecture, modèle de données, intégrations, sécurité, déploiement, analyse de santé et diagrammes Mermaid (organigramme BPMN, ER, séquence, état, C4, bloc bêta, tarte, etc.). Inclut des scripts d'automatisation Python pour chaque phase de documentation. Se déclenche lorsque la tâche implique de documenter, d'analyser, d'auditer, d'inventorier ou de schématiser tout aspect d'une exportation Appian — y compris les modèles de processus, les CDT, les types d'enregistrement, les systèmes connectés ou les groupes — même sans mentionner explicitement la « documentation technique » ou « Sirène ». S'active également pour les contrôles de santé, l'analyse des codes morts, l'exportation des différences/journaux de modifications et la génération de fichiers de personnalisation d'importation (ICF). PAS pour les projets Java/Spring/Quarkus (utilisez plutôt documenting-paas).
