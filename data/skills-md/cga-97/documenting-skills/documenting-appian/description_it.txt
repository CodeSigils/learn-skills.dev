Genera documentazione tecnica completa per le applicazioni Appian dalle esportazioni XML (root del progetto = cartella dell'app): inventario, architettura, modello dati, integrazioni, sicurezza, distribuzione, analisi dello stato e diagrammi a sirena (diagramma di flusso BPMN, ER, sequenza, stato, C4, block-beta, torta, ecc.). Include script di automazione Python per ogni fase di documentazione. Si attiva quando l'attività prevede la documentazione, l'analisi, il controllo, l'inventario o il diagramma di qualsiasi aspetto di un'esportazione Appian, inclusi modelli di processo, CDT, tipi di record, sistemi connessi o gruppi, anche senza menzionare esplicitamente "documentazione tecnica" o "Sirena". Si attiva anche per controlli di integrità, analisi di codici inattivi, esportazione di differenze/log delle modifiche e generazione di file di personalizzazione di importazione (ICF). NON per progetti Java/Spring/Quarkus (usa invece documenting-paas).
