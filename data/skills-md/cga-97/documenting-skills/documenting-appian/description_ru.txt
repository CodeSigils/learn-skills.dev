Создает полную техническую документацию для приложений Appian из экспорта XML (корневой каталог проекта = папка приложения): инвентаризация, архитектура, модель данных, интеграция, безопасность, развертывание, анализ работоспособности и диаграммы Mermaid (блок-схема BPMN, ER, последовательность, состояние, C4, бета-версия блока, круговая диаграмма и т. д.). Включает сценарии автоматизации Python для каждого этапа документирования. Срабатывает, когда задача включает в себя документирование, анализ, аудит, инвентаризацию или диаграмму любого аспекта экспорта Appian, включая модели процессов, CDT, типы записей, подключенные системы или группы, даже без явного упоминания «технической документации» или «Русалки». Также активируется для проверки работоспособности, анализа мертвого кода, экспорта различий/журналов изменений и создания файла настройки импорта (ICF). НЕ для проектов Java/Spring/Quarkus (вместо этого используйте документацию-paas).
