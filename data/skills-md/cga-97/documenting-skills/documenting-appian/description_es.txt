Genera documentación técnica completa para aplicaciones Appian a partir de exportaciones XML (raíz del proyecto = carpeta de la aplicación): inventario, arquitectura, modelo de datos, integraciones, seguridad, implementación, análisis de estado y diagramas de sirena (diagrama de flujo BPMN, ER, secuencia, estado, C4, beta de bloque, circular, etc.). Incluye scripts de automatización de Python para cada fase de documentación. Se activa cuando la tarea implica documentar, analizar, auditar, inventariar o diagramar cualquier aspecto de una exportación de Appian (incluidos modelos de proceso, CDT, tipos de registros, sistemas conectados o grupos) incluso sin mencionar explícitamente "documentación técnica" o "Mermaid". También se activa para comprobaciones de estado, análisis de códigos inactivos, exportación de diferencias/registros de cambios y generación de archivos de personalización de importación (ICF). NO para proyectos Java/Spring/Quarkus (use documenting-paas en su lugar).
