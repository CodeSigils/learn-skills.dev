يُنشئ وثائق فنية كاملة لتطبيقات Appian من عمليات تصدير XML (جذر المشروع = مجلد التطبيق): المخزون، والهندسة المعمارية، ونموذج البيانات، وعمليات التكامل، والأمان، والنشر، والتحليل الصحي، ومخططات حورية البحر (مخطط انسيابي BPMN، ER، تسلسل، حالة، C4، كتلة بيتا، دائري، وما إلى ذلك). يتضمن نصوص أتمتة Python لكل مرحلة من مراحل التوثيق. يتم تشغيله عندما تتضمن المهمة توثيق أو تحليل أو تدقيق أو جرد أو رسم تخطيطي لأي جانب من جوانب تصدير Appian - بما في ذلك نماذج العمليات أو CDTs أو أنواع السجلات أو الأنظمة المتصلة أو المجموعات - حتى بدون الإشارة بشكل صريح إلى "الوثائق الفنية" أو "Mermaid". يتم تنشيطه أيضًا لإجراء فحوصات السلامة، وتحليل التعليمات البرمجية الميتة، واختلافات التصدير/سجلات التغيير، وإنشاء ملف تخصيص الاستيراد (ICF). ليس لمشاريع Java/Spring/Quarkus (استخدم Documenting-paas بدلاً من ذلك).
