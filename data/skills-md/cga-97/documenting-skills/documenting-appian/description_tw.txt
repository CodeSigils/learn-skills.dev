從 XML 匯出（專案根 = 應用程式資料夾）產生 Appian 應用程式的完整技術文件：清單、架構、資料模型、整合、安全性、部署、運行狀況分析和 Mermaid 圖（BPMN 流程圖、ER、序列、狀態、C4、區塊 beta、餅圖等）。包括每個文件階段的 Python 自動化腳本。當任務涉及記錄、分析、審核、盤點或繪製 Appian 匯出的任何方面（包括流程模型、CDT、記錄類型、連接系統或群組）時觸發，即使沒有明確提及「技術文件」或「Mermaid」。還可以啟動執行狀況檢查、死程式碼分析、匯出差異/變更日誌以及匯入自訂檔案 (ICF) 產生。不適用於 Java/Spring/Quarkus 專案（請使用 Documentation-paas 代替）。
