Publica cualquier documento de Markdown en GitHub Wiki y genera un archivo HTML independiente con diagramas de sirena renderizados. Úselo cuando el usuario solicite: publicar en wiki, generar HTML a partir de rebajas, exportar documentos a HTML, enviar documentación a GitHub Wiki, crear documentación HTML independiente o cualquier variante de "publicar/exportar esta rebajas". Funciona con cualquier archivo .md: documentación técnica, ADR, registros de cambios, runbooks, documentos API, etc.
