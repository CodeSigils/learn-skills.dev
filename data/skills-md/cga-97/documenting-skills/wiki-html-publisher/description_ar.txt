ينشر أي مستند Markdown على GitHub Wiki ويقوم بإنشاء ملف HTML مستقل مع مخططات حورية البحر المعروضة. يُستخدم عندما يطلب المستخدم: النشر على wiki، أو إنشاء HTML من تخفيض السعر، أو تصدير المستندات إلى HTML، أو دفع الوثائق إلى GitHub Wiki، أو إنشاء وثائق HTML مستقلة، أو أي شكل مختلف من "نشر/تصدير هذا التخفيض". يعمل مع أي ملف ‎.md — الوثائق الفنية، وADRs، وسجلات التغيير، وسجلات التشغيل، ومستندات API، وما إلى ذلك.
