Публикует любой документ Markdown в GitHub Wiki и генерирует отдельный HTML-файл с визуализированными диаграммами Mermaid. Используйте, когда пользователь просит: опубликовать в вики, сгенерировать HTML из уценки, экспортировать документы в HTML, отправить документацию в GitHub Wiki, создать отдельную HTML-документацию или любой вариант «опубликовать/экспортировать эту уценку». Работает с любым файлом .md — технической документацией, ADR, журналами изменений, модулями Runbook, документацией API и т. д.
