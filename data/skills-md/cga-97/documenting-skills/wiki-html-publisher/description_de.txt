Veröffentlicht jedes Markdown-Dokument im GitHub-Wiki und generiert eine eigenständige HTML-Datei mit gerenderten Mermaid-Diagrammen. Verwenden Sie diese Option, wenn der Benutzer Folgendes wünscht: im Wiki veröffentlichen, HTML aus Markdown generieren, Dokumente nach HTML exportieren, Dokumentation an GitHub Wiki senden, eigenständige HTML-Dokumentation erstellen oder eine beliebige Variante von „Diesen Markdown veröffentlichen/exportieren“ verwenden. Funktioniert mit jeder MD-Datei – technische Dokumentation, ADRs, Änderungsprotokolle, Runbooks, API-Dokumente usw.
