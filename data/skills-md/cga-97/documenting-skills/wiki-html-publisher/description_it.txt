Pubblica qualsiasi documento Markdown su GitHub Wiki e genera un file HTML autonomo con i diagrammi della sirena renderizzati. Da utilizzare quando l'utente chiede di: pubblicare su wiki, generare HTML dal markdown, esportare documenti in HTML, inviare documentazione a GitHub Wiki, creare documentazione HTML autonoma o qualsiasi variante di "pubblica/esporta questo markdown". Funziona con qualsiasi file .md: documentazione tecnica, ADR, log delle modifiche, runbook, documenti API, ecc.
