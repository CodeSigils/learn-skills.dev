Publie n'importe quel document Markdown sur GitHub Wiki et génère un fichier HTML autonome avec des diagrammes Mermaid rendus. À utiliser lorsque l'utilisateur demande à : publier sur un wiki, générer du HTML à partir d'une démarque, exporter des documents au format HTML, envoyer de la documentation vers le wiki GitHub, créer une documentation HTML autonome ou toute variante de "publier/exporter cette démarque". Fonctionne avec n'importe quel fichier .md : documentation technique, ADR, journaux des modifications, runbooks, documents API, etc.
