Habilidad de análisis de cuestionarios de investigación de usuarios de juegos profesionales. Cuando los usuarios cargan elementos de cuestionarios y datos sin procesar, esta habilidad debe usarse para el procesamiento de datos, la generación de informes, el análisis cruzado y la comparación histórica. Los escenarios desencadenantes incluyen: cargar archivos de datos de cuestionarios, mencionar "análisis de cuestionarios", "procesamiento de datos", "análisis cruzado", "análisis de retención", "NPS", "puntuación general", "personalidad del usuario", "puntos destacados y débiles", "comparación histórica", "última prueba" o cualquier requisito que implique el procesamiento de datos del cuestionario. Incluso si el usuario simplemente dice "ayúdame a verificar estos datos" y carga archivos relacionados con el cuestionario, esta habilidad debería activarse de inmediato.
