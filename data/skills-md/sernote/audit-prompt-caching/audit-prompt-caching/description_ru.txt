Используйте всякий раз, когда пользователь упоминает промахи в кэше подсказок/префиксов LLM, cached_tokens=0, cache_read_input_tokens/cache_creation_input_tokens, Prompt_cache_key, место кэша_контроля/cachePoint, стабильные префиксы, стабильность инструмента/схемы, задержку TTFT/предварительного заполнения, маршрутизацию OpenAI/Claude/Bedrock/OpenRouter, повторное использование vLLM/SGLang KV или Регрессия стоимости/скорости LLM при повторяющихся длинных подсказках. Используйте при просмотре изменений формы запроса LLM: текста приглашения, порядка сообщений, построителей запросов, инструментов, схем, формата ответа, поверхности API поставщика, настроек модели/маршрутизатора, структуры цикла агента, сжатия контекста или развертывания вывода. Используйте для ускорения работы агентов только тогда, когда стабильность кэша запросов, TTFT или стоимость кэша имеют решающее значение. Не используйте для написания общих подсказок, общего проектирования RAG, подсчета токенов или производительности, не связанной с LLM.
