Utilizzare ogni volta che l'utente menziona gli errori della cache del prompt/prefisso LLM, cached_tokens=0, cache_read_input_tokens/cache_creation_input_tokens, prompt_cache_key, cache_control/cachePoint posizionamento, prefissi stabili, stabilità dello strumento/schema, latenza TTFT/prefill, routing OpenAI/Claude/Bedrock/OpenRouter, riutilizzo vLLM/SGLang KV o LLM regressioni costo/velocità su prompt lunghi ripetuti. Da utilizzare durante l'esame delle modifiche alla forma delle richieste LLM: testo del prompt, ordine dei messaggi, generatori di richieste, strumenti, schemi, formato_risposta, superficie API del provider, impostazioni del modello/router, struttura del loop dell'agente, compattazione del contesto o distribuzione dell'inferenza. Utilizzare per velocizzare gli agenti solo quando la stabilità della cache dei prompt, il TTFT o il costo della cache sono fondamentali. Non utilizzare per la scrittura di prompt generici, la progettazione RAG generica, il conteggio dei token o le prestazioni non LLM.
