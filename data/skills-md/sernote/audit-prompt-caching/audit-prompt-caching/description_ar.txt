يُستخدم عندما يذكر المستخدم أخطاء ذاكرة التخزين المؤقت للموجه/البادئة LLM، cached_tokens=0،ذاكرة التخزين المؤقت_قراءة_input_tokens/cache_creation_input_tokens، موجه_cache_key، وضع ذاكرة التخزين المؤقت/cachePoint، البادئات المستقرة، استقرار الأداة/المخطط، زمن استجابة TTFT/الملء المسبق، توجيه OpenAI/Claude/Bedrock/OpenRouter، vLLM/SGLang KV إعادة الاستخدام، أو تراجعات التكلفة/السرعة في LLM بناءً على المطالبات الطويلة المتكررة. يُستخدم عند مراجعة تغييرات شكل طلب LLM: النص الفوري، أو ترتيب الرسائل، أو منشئي الطلبات، أو الأدوات، أو المخططات، أو تنسيق_الاستجابة، أو سطح واجهة برمجة تطبيقات الموفر، أو إعدادات النموذج/جهاز التوجيه، أو بنية حلقة الوكيل، أو ضغط السياق، أو نشر الاستدلال. يُستخدم لتسريع الوكلاء فقط عندما يكون استقرار ذاكرة التخزين المؤقت الفوري أو TTFT أو تكلفة ذاكرة التخزين المؤقت أمرًا أساسيًا. لا تستخدم للكتابة السريعة العامة أو تصميم RAG العام أو عد الرموز المميزة أو الأداء غير LLM.
