مجموعة Git الحتمية لوكلاء ومطوري الذكاء الاصطناعي. يتضمن بوابات أمان ما قبل الالتزام (أداة سرية وحساسة للملفات وعلامات التعارض)، والتحقق من الالتزامات التقليدية المكونة من 10 خطوات، وتدقيق الالتزام بسجل الالتزام (/ git Audit)، والالتزامات الذرية الآمنة، والمزامنة/الدفع، وإدارة الفروع، والمتسابقين عبر الأنظمة الأساسية.
