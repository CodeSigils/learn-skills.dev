مجموعة Git الحتمية لوكلاء ومطوري الذكاء الاصطناعي. يتضمن بوابات أمان ما قبل الالتزام (أداة حظر الملفات الحساسة والملفات السرية والصراعات)، والتحقق من الالتزامات التقليدية المكونة من 10 خطوات، ومراجعة الامتثال لتاريخ الالتزام (/ git Audit)، والالتزامات الذرية الآمنة، والمزامنة/الدفع، وإدارة الفروع، والعدائين عبر الأنظمة الأساسية.
