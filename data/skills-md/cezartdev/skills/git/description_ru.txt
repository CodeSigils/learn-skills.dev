Детерминированный пакет Git для агентов и разработчиков искусственного интеллекта. Включает шлюзы безопасности перед фиксацией (блокировщик секретных, конфиденциальных файлов и маркеров конфликтов), 10-ступенчатую проверку обычных коммитов, аудит соответствия истории коммитов (/git аудит), безопасные атомарные коммиты, синхронизацию и отправку, управление ветвями и кроссплатформенные средства запуска.
