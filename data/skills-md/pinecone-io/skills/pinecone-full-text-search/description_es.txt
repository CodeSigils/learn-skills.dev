Cree, ingiera y consulte un índice de búsqueda de texto completo (FTS) de Pinecone utilizando la API de vista previa (2026-01.alpha, vista previa pública). Úselo cuando el usuario o agente solicite crear un índice de búsqueda de texto en Pinecone, agregar campos vectoriales densos o dispersos, ingerir documentos, construir cláusulas score_by (texto/query_string/denso_vector/sparse_vector) o redactar con filtros de coincidencia de texto ($match_phrase/$match_all/$match_any). Envía `scripts/ingest.py` para una ingesta masiva segura (batch_upsert + inspección de errores + sondeo de preparación); La construcción de consultas está documentada en línea en esta habilidad: escriba llamadas `documents.search(...)` directamente, validadas con la salida `pc.preview.indexes.describe(...)`.
