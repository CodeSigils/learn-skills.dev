プレビュー API (2026-01.alpha、パブリック プレビュー) を使用して、Pinecone 全文検索 (FTS) インデックスを作成、取り込み、クエリします。ユーザーまたはエージェントが、Pinecone でのテキスト検索インデックスの構築、密または疎ベクトル フィールドの追加、ドキュメントの取り込み、score_by 句 (text / query_string /dens_vector / sparse_vector) の構築、またはテキスト一致フィルター ($match_phrase / $match_all / $match_any) での作成を要求する場合に使用します。安全な一括取り込み (batch_upsert + エラー検査 + 準備状況ポーリング) のために「scripts/ingest.py」を同梱します。クエリの構築はこのスキルでインラインで文書化されています。`documents.search(...)` 呼び出しを直接記述し、`pc.preview.indexes.describe(...)` 出力に対して検証します。
