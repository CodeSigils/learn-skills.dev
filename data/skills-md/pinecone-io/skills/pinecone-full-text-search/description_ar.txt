قم بإنشاء فهرس Pinecone للبحث عن النص الكامل (FTS) واستيعابه والاستعلام عنه باستخدام واجهة برمجة تطبيقات المعاينة (2026-01.alpha، المعاينة العامة). يُستخدم عندما يطلب المستخدم أو الوكيل إنشاء فهرس بحث نصي على Pinecone، أو إضافة حقول متجهة كثيفة أو متفرقة، أو استيعاب المستندات، أو إنشاء عبارات Score_by (نص / query_string / كثيفة_ناقلة / متفرقة)، أو الإنشاء باستخدام مرشحات مطابقة النص ($match_phrase / $match_all / $match_any). يتم شحن "scripts/ingest.py" للتناول المجمع الآمن (batch_upsert + فحص الأخطاء + استقصاء الجاهزية)؛ يتم توثيق بناء الاستعلام بشكل مضمن في هذه المهارة - اكتب استدعاءات `documents.search(...)` مباشرة، وتم التحقق من صحتها مقابل إخراج `pc.preview.indexes.describe(...)`.
