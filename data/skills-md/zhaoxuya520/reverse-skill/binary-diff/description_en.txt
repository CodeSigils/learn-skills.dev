Cross-version symbol migration and binary diff. Use this when you have symbols or reverse‑engineering results from an older version and need to quickly migrate to a newer version.  
Applicable scenarios: kernel missing PDB, derive using old symbols; batch migration of function names after a program update; quickly locate new offsets after an application update.  
Core method: use an LLM to perform structured diff comparison, with programmatic input and output; extremely low cost (about 1 yuan for 200 functions).  
Trigger keywords: symbol migration, bindiff, cross-version, missing PDB, function offset migration, symbol migration, binary diff, version comparison.
