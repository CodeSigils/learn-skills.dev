Point d’entrée d’automatisation unifié. Couvre l'automatisation du navigateur (Playwright) et l'automatisation des applications de bureau Windows (OpenReverse).  
Scénarios de navigateur : ouverture de pages Web, clic, remplissage de formulaires, exploration, prise de captures d'écran, connexion automatisée, interaction avec la page de pénétration.  
Scénarios de bureau : exploitation d'outils GUI tels que IDA/x64dbg, Windows UI Automation, interaction visuelle, capture de paquets réseau d'applications de bureau.  
Mots-clés déclencheurs : automatisation du navigateur, automatisation du bureau, ouverture de pages Web, remplissage de formulaires, exploration, captures d'écran, connexion automatisée, Playwright, agent-navigateur, sans tête, OpenReverse, UIA, CUA, fonctionnement du bureau, automatisation de Windows.
