نقطة دخول الأتمتة الموحدة. يغطي أتمتة المتصفح (الكاتب المسرحي) وأتمتة تطبيقات سطح مكتب Windows (OpenReverse).  
سيناريوهات المتصفح: فتح صفحات الويب، والنقر، وملء النماذج، والزحف، والتقاط لقطات الشاشة، وتسجيل الدخول الآلي، وتفاعل صفحة الاختراق.  
سيناريوهات سطح المكتب: تشغيل أدوات واجهة المستخدم الرسومية مثل IDA/x64dbg وWindows UI Automation والتفاعل المرئي والتقاط حزم شبكة تطبيقات سطح المكتب.  
تشغيل الكلمات الرئيسية: أتمتة المتصفح، أتمتة سطح المكتب، فتح صفحات الويب، ملء النماذج، الزحف، لقطات الشاشة، تسجيل الدخول الآلي، الكاتب المسرحي، متصفح الوكيل، بدون رأس، OpenReverse، UIA، CUA، تشغيل سطح المكتب، أتمتة Windows.
