IDA Pro逆向分析辅助技能。当用户提到逆向、反编译、分析二进制/PE/ELF/A PK/DLL/SO、破解、找密码、漏洞分析、病毒分析、firmware固件分析, 或需要分析 exe/dll/so/elf/macho/sys 等文件时, 务必使用此技能.

Assicurati di utilizzare questa capacità quando l'utente desidera analizzare qualsiasi file binario, indipendentemente dal fatto che menzioni esplicitamente "IDA" o "reverse engineering". Ciò include richieste come "看看这个exe", "分析这个dll", "帮我破解", "找一下密码", "这个软件怎么注册", ecc.

Utilizza gli script in bundle (scripts/start.ps1, scripts/open.ps1) per la gestione deterministica del server e l'apertura dei file: NON scrivere comandi PowerShell ad hoc per queste operazioni.
