.NET / C# binäres Reverse Engineering. Wird verwendet, wenn das Ziel eine .NET-Assembly (PE-Header enthält CLR, .exe/.dll-verwaltetes Programm), C#-kompilierte Artefakte (einschließlich NativeAOT), Red-Team-Sharp*-Tools (Rubeus/SharpHound usw.), .NET-Verschleierungsprogramme (ConfuserEx/SmartAssembly/Babel/Eazfuscator) oder .NET-Loader/Info-Stealer/gepackte Malware ist. Bevorzugen Sie dnSpyEx + de4dot, und wenn KI direkt arbeiten muss, integrieren Sie dnSpy MCP. Wird nicht für reine native Binärdateien verwendet (verwenden Sie Reverse Engineering / ida-reverse).
