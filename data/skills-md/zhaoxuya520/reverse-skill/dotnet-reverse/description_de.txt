.NET / C# binäres Reverse Engineering. Wird verwendet, wenn das Ziel eine .NET-Assembly (PE-Header enthält CLR, .exe/.dll-verwaltetes Programm), C#-kompilierte Ausgabe (einschließlich NativeAOT), Red-Team-Sharp*-Tools (Rubeus/SharpHound usw.), .NET-Verschleierer (ConfuserEx/SmartAssembly/Babel/Eazfuscator) oder .NET-Loader/Info-Stealer/gepackte Malware ist. Bevorzugen Sie dnSpyEx + de4dot; Wenn die KI direkt arbeiten muss, koordinieren Sie sie mit dnSpy MCP. Wird nicht für reine native Binärdateien verwendet (Reverse Engineering/IDA-Reverse verwenden).
