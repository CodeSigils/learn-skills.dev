Ingeniería inversa binaria .NET / C#. Se utiliza cuando el objetivo es un ensamblado .NET (el encabezado PE incluye CLR, programa administrado .exe/.dll), artefactos compilados de C# (incluido NativeAOT), herramientas Sharp* del equipo rojo (Rubeus / SharpHound / etc.), programas de ofuscación .NET (ConfuserEx / SmartAssembly / Babel / Eazfuscator) o cargadores .NET / ladrones de información / malware empaquetado. Prefiera dnSpyEx + de4dot, y cuando la IA necesite operar directamente, integre con dnSpy MCP. No se utiliza para archivos binarios nativos puros (use ingeniería inversa/ida-reverse).
