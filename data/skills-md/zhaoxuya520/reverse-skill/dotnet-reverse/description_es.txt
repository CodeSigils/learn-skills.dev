Ingeniería inversa binaria .NET / C#. Úselo cuando el objetivo sea un ensamblado .NET (encabezado PE que contiene CLR, programa administrado .exe/.dll), un producto compilado en C# (incluido NativeAOT), herramientas Sharp* del equipo rojo (Rubeus / SharpHound / etc.), programas de ofuscación .NET (ConfuserEx / SmartAssembly / Babel / Eazfuscator) o un cargador .NET / ladrón de información / malware empaquetado. Prefiera dnSpyEx+de4dot; cuando la IA necesite operar directamente, intégrela con dnSpy MCP. No está destinado a archivos binarios nativos puros (en su lugar, utilice ingeniería inversa/IDA-reverse).
