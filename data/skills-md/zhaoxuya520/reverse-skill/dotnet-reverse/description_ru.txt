Бинарный реверс-инжиниринг .NET/C#. Используется, когда целью является сборка .NET (заголовок PE включает CLR, управляемую программу .exe/.dll), скомпилированные артефакты C# (включая NativeAOT), инструменты Sharp* красной команды (Rubeus / SharpHound / SharpHound и т. д.), программы обфускации .NET (ConfuserEx / SmartAssembly / Babel / Eazfuscator), .NET-загрузчики/похитители информации/упакованное вредоносное ПО. Предпочитайте dnSpyEx+de4dot, а когда ИИ необходимо действовать напрямую, координируйте свои действия с dnSpy MCP. Не используется для чисто собственных двоичных файлов (обратное проектирование/ida-reverse).
