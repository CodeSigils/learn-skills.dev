Rétro-ingénierie binaire .NET / C#. Utilisé lorsque la cible est un assembly .NET (l'en-tête PE inclut CLR, un programme géré .exe/.dll), une sortie compilée C# (y compris NativeAOT), des outils Sharp* de l'équipe rouge (Rubeus / SharpHound / etc.), des programmes d'obscurcissement .NET (ConfuserEx / SmartAssembly / Babel / Eazfuscator), des chargeurs .NET / des voleurs d'informations / des logiciels malveillants compressés. Préférez dnSpyEx + de4dot ; lorsque l’IA doit fonctionner directement, coordonnez-vous avec dnSpy MCP. Pas pour les binaires natifs purs (utilisez l'ingénierie inverse / IDA-reverse).
