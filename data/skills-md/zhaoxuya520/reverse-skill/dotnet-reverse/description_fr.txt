Rétro-ingénierie binaire .NET / C#. Utilisé lorsque la cible est un assembly .NET (l'en-tête PE inclut CLR, un programme géré .exe/.dll), des artefacts compilés C# (y compris NativeAOT), des outils Sharp* de l'équipe rouge (Rubeus / SharpHound / etc.), des programmes d'obscurcissement .NET (ConfuserEx / SmartAssembly / Babel / Eazfuscator) ou des chargeurs .NET / voleurs d'informations / logiciels malveillants compressés. Préférez dnSpyEx + de4dot, et lorsque l'IA doit fonctionner directement, intégrez-la à dnSpy MCP. Non utilisé pour les binaires natifs purs (utiliser la rétro-ingénierie / ida-reverse).
