Ingegneria inversa binaria .NET/C#. Utilizzato quando la destinazione è un assembly .NET (l'intestazione PE include CLR, programma gestito .exe/.dll), output compilato C# (incluso NativeAOT), strumenti Sharp* del team rosso (Rubeus/SharpHound/ecc.), programmi di offuscamento .NET (ConfuserEx/SmartAssembly/Babel/Eazfuscator) o caricatori/stealer di informazioni/malware compresso .NET. Preferisco dnSpyEx+de4dot; quando l'IA deve agire direttamente, abbinala a dnSpy MCP. Non applicabile ai file binari nativi puri (utilizzare reverse engineering/IDA‑reverse).
