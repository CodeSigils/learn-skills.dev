Ingegneria inversa binaria .NET/C#. Utilizzato quando la destinazione è un assembly .NET (l'intestazione PE include CLR, programma gestito .exe/.dll), artefatti compilati C# (incluso NativeAOT), strumenti Sharp* del team rosso (Rubeus/SharpHound/ecc.), programmi di offuscamento .NET (ConfuserEx/SmartAssembly/Babel/Eazfuscator) o caricatori/stealer di informazioni/malware compresso .NET. Preferisci dnSpyEx + de4dot e, quando l'IA deve operare direttamente, integra con dnSpy MCP. Non utilizzato per file binari nativi puri (utilizzare reverse engineering/ida‑reverse).
