.NET / C# バイナリ リバース エンジニアリング。ターゲットが .NET アセンブリ (PE ヘッダーには CLR、.exe/.dll マネージ プログラムが含まれます)、C# コンパイルされた出力 (NativeAOT を含む)、レッドチームの Sharp* ツール (Rubeus / SharpHound / など)、.NET 難読化プログラム (ConfuserEx / SmartAssembly / Babel / Eazfuscator)、.NET ローダー / 情報スティーラー / パックされたマルウェアの場合に使用されます。 dnSpyEx + de4dot を優先します。 AIを直接動作させる必要がある場合は、dnSpy MCPと連携します。純粋なネイティブ バイナリには使用されません (リバース エンジニアリング / ida-reverse を使用します)。
