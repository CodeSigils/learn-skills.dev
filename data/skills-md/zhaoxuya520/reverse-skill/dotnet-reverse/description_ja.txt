.NET / C# バイナリ リバース エンジニアリング。ターゲットが .NET アセンブリ (PE ヘッダーには CLR、.exe/.dll マネージ プログラムが含まれます)、C# コンパイル済みアーティファクト (NativeAOT を含む)、レッドチームの Sharp* ツール (Rubeus / SharpHound など)、.NET 難読化プログラム (ConfuserEx / SmartAssembly / Babel / Eazfuscator)、または .NET ローダー / 情報スティーラー / パックされたマルウェアである場合に使用されます。 dnSpyEx + de4dot を優先し、AI を直接操作する必要がある場合は、dnSpy MCP と統合します。純粋なネイティブ バイナリには使用されません (リバース エンジニアリング / ida-reverse を使用します)。
