Crée une documentation technique orientée tâches avec divulgation progressive. À utiliser lors de l'écriture de README, de documents API, de documents d'architecture ou de documentation de démarque.
Utilisez également cette compétence à la FIN de toute tâche d'ingénierie inverse, de test d'intrusion, de CTF ou d'analyse de sécurité terminée pour générer un rapport formel dans le répertoire de projet de l'utilisateur.
Mots-clés déclencheurs : 写报告, 写文档, 出报告, rédaction, 技术文档, rapport, documentation.
