Eine professionelle Bildbeschreibungsfunktion für akademische Arbeiten, mit der wissenschaftliche Kommentare für verschiedene Arten von Papierillustrationen (Karten, Flussdiagramme, Datendiagramme, konzeptionelle Diagramme usw.) bereitgestellt werden. Es folgt dem Prinzip „Text als Kern, Bilder als Beweis“. Es eignet sich, wenn Benutzer wissenschaftliche Beschreibungen von Papierillustrationen innerhalb des Haupttextes schreiben müssen. Das Thema hat nichts damit zu tun; Die domänenspezifische Terminologie wird vom Benutzer oder den Schreibrichtlinien des Projekts bereitgestellt.
