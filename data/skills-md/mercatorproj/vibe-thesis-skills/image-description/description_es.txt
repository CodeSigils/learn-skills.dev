Una función de descripción de imágenes de artículos académicos profesionales, que se utiliza para proporcionar narración científica y académica para varios tipos de ilustraciones en papel (mapas, diagramas de flujo, cuadros de datos, diagramas conceptuales, etc.). Sigue el principio de "el texto como núcleo, las imágenes como evidencia". Es adecuado cuando los usuarios necesitan escribir descripciones académicas de ilustraciones en papel dentro del texto principal. El tema no tiene relación; La terminología específica del dominio la proporciona el usuario o las pautas de redacción del proyecto.
