Une fonction de description d'images de papier académique professionnelle, utilisée pour fournir une narration scientifique et scientifique pour divers types d'illustrations papier (cartes, organigrammes, graphiques de données, diagrammes conceptuels, etc.). Il suit le principe du « texte comme noyau, des images comme preuve ». Il convient lorsque les utilisateurs ont besoin de rédiger des descriptions académiques d'illustrations papier dans le texte principal. Le sujet n'a aucun rapport ; la terminologie spécifique au domaine est fournie par l'utilisateur ou par les directives de rédaction du projet.
