Шаблоны интеграции Laravel + Inertia.js + Vue 3. Используйте при создании компонентов страницы Inertia, обработке форм с помощью компоновки useForm, управлении общими данными или реализации постоянных макетов. Запускается при выполнении задач, связанных с Inertia.js, реквизитами страницы, обработкой форм или интеграцией Laravel Vue.
