Полное руководство по разработке плагинов музыкального плеера MusicFree с нуля. Срабатывает, когда пользователи просят написать, создать или разработать плагин MusicFree или адаптировать музыкальный сайт/API в плагин MusicFree. Охватывает весь процесс: протокол плагина, определения типов мультимедиа, сигнатуры методов, изолированную среду, анализ сайта, локальную отладку, публикацию и обновления. Этот навык предназначен для выполнения ИИ и помогает ИИ сотрудничать с пользователями с нулевым опытом для завершения разработки плагина.
