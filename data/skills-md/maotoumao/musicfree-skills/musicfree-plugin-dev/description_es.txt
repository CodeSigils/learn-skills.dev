Una guía completa para desarrollar complementos de reproductores de música MusicFree desde cero. Se activa cada vez que el usuario solicita escribir, crear o desarrollar un complemento MusicFree, o adaptar un sitio web de música o API a un complemento MusicFree. Cubre: protocolo de complemento, definiciones de tipos de medios, firmas de métodos, entorno sandbox, análisis del sitio, depuración local, publicación de actualizaciones y el flujo de trabajo completo. Esta habilidad está diseñada para la ejecución de IA, guiando a la IA a colaborar con usuarios sin experiencia para finalizar el desarrollo del complemento.
