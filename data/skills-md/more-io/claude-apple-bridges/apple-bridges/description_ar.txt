استخدم هذه المهارة عندما يسأل المستخدم عن تطبيقات Apple - التذكيرات أو التقويم أو جهات الاتصال أو الملاحظات أو البريد أو جلسات tmux. يتضمن ذلك إنشاء/إكمال التذكيرات، والتحقق من/إضافة أحداث التقويم، والبحث عن جهات الاتصال، وقراءة/كتابة الملاحظات، وإرسال/قراءة البريد الإلكتروني، والتقاط محتوى جلسة tmux. استخدم هذه المهارة أيضًا عندما يذكر المستخدم المهام أو المهام أو الجدولة أو أعياد الميلاد أو أوقات الفراغ أو ملخصات نهاية اليوم. الجسور عبارة عن أدوات CLI مثبتة على ~/.claude/ والتي تمنح Claude Code وصولاً أصليًا إلى تطبيقات Apple هذه على نظام التشغيل macOS.
