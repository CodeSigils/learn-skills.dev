Verwenden Sie diesen Skill immer dann, wenn der Benutzer nach Apple-Apps fragt – Erinnerungen, Kalender, Kontakte, Notizen, E-Mail oder tmux-Sitzungen. Dazu gehören das Erstellen/Ausfüllen von Erinnerungen, das Überprüfen/Hinzufügen von Kalenderereignissen, das Nachschlagen von Kontakten, das Lesen/Schreiben von Notizen, das Senden/Lesen von E-Mails und das Erfassen von tmux-Sitzungsinhalten. Verwenden Sie diese Fähigkeit auch, wenn der Benutzer Aufgaben, Todos, Zeitpläne, Geburtstage, freie Zeitfenster oder Zusammenfassungen zum Tagesende erwähnt. Bei den Bridges handelt es sich um CLI-Tools, die unter ~/.claude/ installiert sind und Claude Code nativen Zugriff auf diese Apple-Apps unter macOS ermöglichen.
