قم بإنشاء شرح HTML تفاعلي غني ومستقل لتغيير التعليمات البرمجية أو الفرق أو الفرع أو طلب السحب. استخدم هذا عندما يريد المستخدم فهم تغيير البرنامج أو تعليمه أو توثيقه أو الاطلاع عليه - خلفيته أو حدسه أو تنفيذه أو تدفق البيانات أو الرسوم البيانية أو التعزيز القائم على الاختبار - حتى لو لم يذكر "HTML" صراحةً. قم بتشغيل طلبات مثل "شرح هذا العلاقات العامة" أو "اكتب ما يفعله هذا الاختلاف" أو "إنشاء صفحة تعليمية لهذا التغيير" أو "مساعدة شخص ما على فهم هذا الفرع". يتم حفظ النتيجة كملف HTML مستقل ومؤرخ خارج المستودع.
