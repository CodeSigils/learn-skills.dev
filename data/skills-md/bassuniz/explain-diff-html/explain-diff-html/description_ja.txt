コードの変更、差分、ブランチ、またはプル リクエストについての、充実した自己完結型のインタラクティブな HTML 説明を作成します。ユーザーが「HTML」と明示的に言わなくても、ソフトウェアの変更 (その背景、直感、実装、データ フロー、図、またはクイズベースの強化) を理解、指導、文書化、またはウォークスルーしたい場合は常にこれを使用します。 「この PR を説明してください」、「この差分が何をするのか書いてください」、「この変更について説明するページを作成してください」、または「誰かがこのブランチを理解できるようにしてください」などのリクエストをトリガーします。結果は、日付付きのスタンドアロン HTML ファイルとしてリポジトリの外に保存されます。
