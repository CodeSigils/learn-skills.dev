Erstellen Sie eine umfassende, eigenständige interaktive HTML-Erläuterung einer Codeänderung, eines Diffs, einer Verzweigung oder einer Pull-Anfrage. Verwenden Sie dies immer dann, wenn der Benutzer eine Softwareänderung – Hintergrund, Intuition, Implementierung, Datenfluss, Diagramme oder quizbasierte Verstärkung – verstehen, lehren, dokumentieren oder durchgehen möchte, auch wenn er nicht ausdrücklich „HTML“ sagt. Auslösen bei Anfragen wie „Erklären Sie diese PR“, „Schreiben Sie auf, was dieser Unterschied macht“, „Erstellen Sie eine Lehrseite für diese Änderung“ oder „Helfen Sie jemandem, diesen Zweig zu verstehen“. Das Ergebnis wird als veraltete, eigenständige HTML-Datei außerhalb des Repositorys gespeichert.
