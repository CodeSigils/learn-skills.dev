Crea una spiegazione HTML interattiva ricca e autonoma di una richiesta di modifica del codice, diff, ramo o pull. Utilizzalo ogni volta che l'utente desidera comprendere, insegnare, documentare o illustrare una modifica del software (il suo background, l'intuizione, l'implementazione, il flusso di dati, i diagrammi o il rinforzo basato su quiz) anche se non dice esplicitamente "HTML". Attiva richieste come "spiega questo PR", "scrivi cosa fa questa differenza", "crea una pagina didattica per questo cambiamento" o "aiuta qualcuno a capire questo ramo". Il risultato viene salvato come file HTML autonomo e datato all'esterno del repository.
