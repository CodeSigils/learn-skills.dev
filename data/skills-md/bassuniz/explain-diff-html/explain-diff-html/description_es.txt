Cree una explicación HTML interactiva, rica e independiente de un cambio de código, diferenciación, rama o solicitud de extracción. Úselo siempre que el usuario quiera comprender, enseñar, documentar o recorrer un cambio de software (sus antecedentes, intuición, implementación, flujo de datos, diagramas o refuerzo basado en cuestionarios) incluso si no dice explícitamente "HTML". Active solicitudes como "explica este PR", "escribe lo que hace esta diferencia", "crea una página de enseñanza para este cambio" o "ayuda a alguien a comprender esta rama". El resultado se guarda como un archivo HTML independiente y fechado fuera del repositorio.
