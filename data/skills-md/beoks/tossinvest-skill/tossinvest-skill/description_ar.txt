العمل مع Toss Securities Open API لبيانات سوق الأسهم الكورية والأمريكية، ومعلومات الأسهم، وأسعار الصرف، وتقويمات السوق، وعمليات البحث عن الحسابات والمقتنيات، وسجل الطلبات، والقوة الشرائية، والكمية القابلة للبيع، والعمولات، والأوامر الخاضعة للحماية، لإنشاء/تعديل/إلغاء سير العمل. يُستخدم عندما يحتاج Codex إلى الاتصال أو البناء على موقع Developers.tossinvest.com، أو فحص مخطط Toss OpenAPI، أو إنشاء رمز العميل، أو العمل باستخدام بيانات اعتماد TOSS_API_KEY/TOSS_SECRET_KEY.
