Creación de esquemas CUE para complementos de Perses: definir modelos de datos, escribir validación
restricciones, crear ejemplos JSON, implementar esquemas de migración de Grafana en
migrar/migrar.cue. Habilidad educativa que explica patrones CUE específicos de
Desarrollo de complementos Perses. Úselo para "esquema de referencia perses", "modelo perses",
"esquema de complemento", "validación de señales persistentes". NO lo use para CUE del tablero
definiciones (use perses-dac-pipeline).
