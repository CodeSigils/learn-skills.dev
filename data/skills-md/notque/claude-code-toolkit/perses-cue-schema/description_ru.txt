Разработка схемы CUE для плагинов Perses: определение моделей данных, проверка записи
ограничения, создавать примеры JSON, реализовывать схемы миграции Grafana в
мигрировать/мигрировать.cue. Образовательный навык, объясняющий шаблоны CUE, специфичные для
Разработка плагина Perses. Используется для «схемы персеса», «модели персеса»,
«схема плагина», «персональная проверка сигнала». НЕ используйте для приборной панели CUE
определения (используйте perses-dac-pipeline).
