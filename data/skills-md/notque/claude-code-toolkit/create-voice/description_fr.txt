Créez un nouveau profil vocal à partir de l'écriture d'échantillons. Canalisation en 7 phases :
Collecter, extraire, modéliser, règles, générer, valider, itérer.
Le Wabi-sabi (imperfections naturelles en tant que caractéristiques) est le principe de base.
À utiliser lors de la création d'une nouvelle voix, du démarrage de l'étalonnage de la voix ou
créer un profil vocal à partir de zéro. Utiliser pour "créer une voix",
"nouvelle voix", "construire la voix", "voix à partir d'échantillons", "calibrer la voix".
Ne PAS utiliser pour générer du contenu dans une voix existante (utilisez
orchestrateur vocal), éditer du contenu (utiliser anti-ai-editor), ou
comparer les voix (utiliser le mode de comparaison du calibrateur vocal).
