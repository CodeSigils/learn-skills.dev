Cree un nuevo perfil de voz a partir de muestras de escritura. Tubería de 7 fases:
Recopilar, extraer, modelar, reglar, generar, validar, iterar.
Wabi-sabi (las imperfecciones naturales como características) es el principio fundamental.
Úselo al crear una nueva voz, iniciar la calibración de voz o
construyendo un perfil de voz desde cero. Úselo para "crear voz",
"nueva voz", "crear voz", "voz a partir de muestras", "calibrar voz".
NO lo use para generar contenido en una voz existente (use
orquestador de voz), editar contenido (use anti-ai-editor) o
comparar voces (use el modo de comparación del calibrador de voz).
