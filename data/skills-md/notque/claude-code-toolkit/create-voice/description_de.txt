Sammeln, Extrahieren, Mustern, Regeln, Generieren, Validieren, Iterieren.
Wabi-Sabi (natürliche Unvollkommenheiten als Merkmale) ist das Grundprinzip.
Verwenden Sie diese Option, wenn Sie eine neue Stimme erstellen, die Stimmkalibrierung starten oder
Erstellen eines Sprachprofils von Grund auf. Verwendung für „Stimme erstellen“,
„Neue Stimme“, „Stimme aufbauen“, „Stimme aus Samples“, „Stimme kalibrieren“.
NICHT zum Generieren von Inhalten in einer vorhandenen Stimme verwenden (verwenden Sie
Voice-Orchestrator), Inhalte bearbeiten (Anti-AI-Editor verwenden) oder
Vergleichen von Stimmen (Verwenden Sie den Sprachkalibrator-Vergleichsmodus).
