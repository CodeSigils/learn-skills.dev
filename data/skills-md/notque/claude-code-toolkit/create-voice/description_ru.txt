Создайте новый голосовой профиль на основе написанных образцов. 7-фазный трубопровод:
Собирать, извлекать, создавать шаблоны, править, генерировать, проверять, повторять.
Ваби-саби (естественные несовершенства как особенности) – это основной принцип.
Используйте при создании нового голоса, запуске калибровки голоса или
построение голосового профиля с нуля. Используйте для «создать голос»,
«новый голос», «построить голос», «голос из образцов», «калибровать голос».
НЕ используйте для создания контента существующим голосом (используйте
голосовой оркестратор), редактирование контента (используйте анти-AI-редактор) или
сравнение голосов (используйте режим сравнения голоса-калибратора).
