Детерминированная проверка конечных точек API со структурированными отчетами о пройденном или непройденном этапе.
Используйте, когда конечные точки требуют дымового тестирования, перед этим требуются проверки работоспособности.
развертыванию или конвейерам CI/CD требуются шлюзы проверки HTTP. Используйте для
«проверить конечные точки», «проверить работоспособность API», «дымовой тест API» или
«Работают ли конечные точки». НЕ используйте для нагрузочного тестирования, тестирования браузера,
полные пакеты интеграции или потоки OAuth/сложной аутентификации.
