Analyse Qualité, Analyse Spécifique, Ligne par Ligne, Documentation. Utiliser quand
examiner le code Go, les PR ou auditer les bases de code Go pour en vérifier la qualité et les meilleures pratiques.
À utiliser pour "review Go", "Go PR", "check Go code", "Go quality", "review .go".
Ne PAS utiliser pour écrire du nouveau code Go, déboguer des bogues Go ou refactoriser --
utilisez Golang-General-Engineer, le débogage systématique ou le refactoring systématique
pour ces tâches.
