Exécution légère suivie avec des indicateurs de rigueur composables pour les tâches entre
une correction de faute de frappe et une fonctionnalité complète. Planifier + exécuter avec --discuss en option,
--research et --full indicateurs pour ajouter de la rigueur progressivement. Utiliser pour "tâche rapide",
"petit changement", "tâche ad hoc", "ajouter un indicateur", "extraire la fonction", "petit
refactor", "Correction d'un bug dans X". Ne PAS utiliser pour les fonctionnalités multi-composants,
des changements architecturaux, ou tout ce qui nécessite une exécution parallèle basée sur les vagues -
ce sont le niveau Simple+.
