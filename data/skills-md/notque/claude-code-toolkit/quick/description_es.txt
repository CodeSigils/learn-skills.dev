Ejecución ligera con seguimiento con indicadores de rigor componibles para tareas entre
una corrección de errores tipográficos y una función completa. Planificar + ejecutar con --discutir opcional,
--research y --full indicadores para agregar rigor de forma incremental. Úselo para "tarea rápida",
"pequeño cambio", "tarea ad hoc", "agregar una bandera", "extraer función", "pequeño
refactor", "corregir error en X". NO lo use para funciones de múltiples componentes,
cambios arquitectónicos o cualquier cosa que necesite una ejecución paralela basada en ondas:
esos son el nivel Simple+.
