Creazione e scaffolding dei plugin Perses: seleziona il tipo di plugin (Pannello, Datasource, Query,
Variabile, Esplora), genera con il plugin Percli Genera, implementa lo schema CUE e React
componente, test con avvio del plug-in Percli, creazione dell'archivio con build del plug-in Percli. Utilizzare per
"crea plugin perses", "nuovo plugin per il pannello", "nuovo plugin per l'origine dati", "impalcatura del plugin perses".
NON utilizzare per la creazione di dashboard (utilizzare perses-dashboard-create).
