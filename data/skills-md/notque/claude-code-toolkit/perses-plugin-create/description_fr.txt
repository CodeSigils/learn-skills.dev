Échafaudage et création du plugin Perses : sélectionnez le type de plugin (Panel, Source de données, Requête,
Variable, Explore), générer avec le plugin percli générer, implémenter le schéma CUE et React
composant, testez avec le démarrage du plugin percli, créez l'archive avec la construction du plugin percli. Utiliser pour
"créer un plugin perses", "nouveau plugin de panneau", "nouveau plugin de source de données", "échafaudage de plugin perses".
Ne PAS utiliser pour la création de tableaux de bord (utilisez perses-dashboard-create).
