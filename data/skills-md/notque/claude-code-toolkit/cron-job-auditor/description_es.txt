Auditoría determinista de cron/scripts de trabajo programados para confiabilidad,
manejo de errores, registro, limpieza y seguridad de concurrencia. Usar cuando
el usuario dice "auditar cron", "verificar script cron", "mejores prácticas de cron",
"revisión de trabajo programada" o "auditoría de script bash". NO utilizar para
Sintaxis de programación crontab, temporizadores systemd o linting general de shell
sin un contexto cron/trabajo programado.
