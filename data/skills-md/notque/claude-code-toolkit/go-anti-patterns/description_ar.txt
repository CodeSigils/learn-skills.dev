اكتشاف ومعالجة أنماط Go المضادة: تجريد الواجهة المبكر،
المبالغة في استخدام goroutine، وحساء السياق، وأخطاء تغليف الأخطاء، والإساءة العامة،
إساءة استخدام القناة واستخراج الوظائف غير الضرورية وتلوث الواجهة.
استخدمه عند مراجعة كود Go للتأكد من الجودة، أو اكتشاف الهندسة الزائدة، أو متى
يذكر المستخدم "مضاد للنمط" أو "رائحة الكود" أو "اذهب إلى الخطأ" أو "اذهب بشكل سيء".
لا تستخدم لتنفيذ الميزات، وتحسين الأداء دون
رائحة التعليمات البرمجية، أو اللغات غير الذهاب.
