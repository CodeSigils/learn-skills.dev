Go-Anti-Patterns erkennen und beheben: vorzeitige Schnittstellenabstraktion,
Goroutine-Overkill, Kontextsuppe, Fehler beim Einpacken von Fehlern, allgemeiner Missbrauch,
Kanalmissbrauch, unnötige Funktionsextraktion und Schnittstellenverschmutzung.
Verwenden Sie diese Funktion, wenn Sie Go-Code auf Qualität überprüfen, Over-Engineering erkennen oder wenn
Der Benutzer erwähnt „Anti-Pattern“, „Code-Geruch“, „Go-Fehler“ oder „Bad-Go“.
Nicht zur Funktionsimplementierung oder Leistungsoptimierung ohne verwenden
Code-Geruch oder Nicht-Go-Sprachen.
