RED-GREEN-REFACTOR-Zyklus mit strengen Phasentoren. Schreiben Sie zuerst den fehlgeschlagenen Test.
Implementieren Sie den minimal zu übergebenden Code und führen Sie dann ein Refactoring durch, während die Tests grün bleiben.
Verwendung bei der Implementierung neuer Funktionen, der Behebung von Fehlern mit dem Test-First-Ansatz,
Verbesserung der Testabdeckung oder wenn der Benutzer TDD erwähnt. Verwenden Sie für „TDD“, „test
zuerst“, „Rot-Grün-Refaktor“, „Tests schreiben“ oder „Mit Tests implementieren“.
NICHT zum Debuggen bestehender Fehler verwenden (verwenden Sie systematisches Debuggen) oder
für Refactoring ohne neue Tests (verwenden Sie systematisches Refactoring).
