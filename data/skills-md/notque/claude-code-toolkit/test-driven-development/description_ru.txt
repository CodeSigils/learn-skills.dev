Цикл КРАСНЫЙ-ЗЕЛЕНЫЙ-РЕФАКТОР со строгими фазовыми вентилями. Сначала напишите неудачный тест,
внедрите минимум кода для прохождения, затем выполните рефакторинг, сохраняя при этом тесты зелеными.
Используйте при внедрении новых функций, исправлении ошибок с использованием подхода «сначала тестирование»,
улучшение покрытия тестами или когда пользователь упоминает TDD. Используйте для «TDD», «test».
сначала», «красно-зеленый рефакторинг», «написать тесты» или «реализовать с помощью тестов».
НЕ используйте для отладки существующих сбоев (используйте систематическую отладку) или
для рефакторинга без новых тестов (используйте систематический рефакторинг).
