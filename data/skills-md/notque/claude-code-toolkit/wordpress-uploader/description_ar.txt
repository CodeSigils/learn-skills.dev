تكامل WordPress REST API للمشاركات والوسائط عبر Python الحتمية
مخطوطات. يُستخدم عند تحميل المقالات، وإنشاء المسودات، ونشر المشاركات،
تحميل الصور أو تحرير المنشورات الموجودة أو إدارة محتوى WordPress.
يُستخدم لـ "التحميل إلى WordPress"، و"إنشاء مسودة WordPress"، و"النشر على
مدونتك"، أو "تحميل صورة"، أو "تحرير منشور WordPress". لا تستخدم ل
كتابة المقالات (استخدم كاتب المدونة) أو تحرير أسلوب النثر (استخدم
مكافحة منظمة العفو الدولية محرر).
