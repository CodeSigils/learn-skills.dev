Integrazione dell'API REST di WordPress per post e contenuti multimediali tramite Python deterministico
script. Da utilizzare durante il caricamento di articoli, la creazione di bozze, la pubblicazione di post,
caricare immagini, modificare post esistenti o gestire contenuti WordPress.
Utilizzare per "carica su wordpress", "crea bozza wordpress", "pubblica su
il tuo blog", "carica immagine" o "modifica post WordPress". NON utilizzare per
scrivere articoli (usa blog-post-writer) o modificare lo stile di prosa (usa
anti-ai-editor).
