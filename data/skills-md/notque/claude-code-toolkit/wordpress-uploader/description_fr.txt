Intégration de l'API WordPress REST pour les publications et les médias via Python déterministe
scripts. À utiliser lors du téléchargement d'articles, de la création de brouillons, de la publication de messages,
télécharger des images, modifier des publications existantes ou gérer du contenu WordPress.
Utiliser pour "télécharger sur wordpress", "créer un brouillon wordpress", "publier sur
votre blog", "télécharger une image" ou "modifier une publication WordPress". Ne PAS utiliser pour
rédiger des articles (utilisez blog-post-writer) ou éditer un style de prose (utilisez
anti-ai-éditeur).
