Интеграция WordPress REST API для публикаций и мультимедиа через детерминированный Python
сценарии. Используйте при загрузке статей, создании черновиков, публикации постов,
загрузка изображений, редактирование существующих сообщений или управление контентом WordPress.
Используйте для «загрузить в WordPress», «создать черновик WordPress», «опубликовать в WordPress».
ваш-блог», «загрузить изображение» или «отредактировать сообщение WordPress». НЕ используйте для
написание статей (используйте blog-post-writer) или редактирование стиля прозы (используйте
анти-ай-редактор).
