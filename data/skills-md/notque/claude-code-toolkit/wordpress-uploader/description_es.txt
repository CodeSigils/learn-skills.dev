Integración de la API REST de WordPress para publicaciones y medios a través de Python determinista
guiones. Úselo al cargar artículos, crear borradores, publicar publicaciones,
cargar imágenes, editar publicaciones existentes o administrar contenido de WordPress.
Úselo para "cargar en wordpress", "crear borrador de wordpress", "publicar en
tu-blog", "cargar imagen" o "editar publicación de wordpress". NO utilizar para
escribir artículos (usar blog-post-writer) o editar estilo en prosa (usar
editor anti-ai).
