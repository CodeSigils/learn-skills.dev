Mantener /hacer tablas de enrutamiento y referencias de comandos cuando las habilidades o agentes
se agregan, modifican o eliminan. Úselo cuando cambien los metadatos de habilidades/agentes,
después de las ejecuciones de Skill-Creator-Ingeniero o Agent-Creator-Ingeniero, o cuando
las tablas de enrutamiento necesitan sincronización. Úselo para "actualizar rutas", "sincronizar
enrutamiento", "tabla de enrutamiento" o "actualizar /hacer". NO lo use para crear
nuevas habilidades/agentes, modificación de la lógica de habilidades o ediciones manuales/de tablas de tareas.
