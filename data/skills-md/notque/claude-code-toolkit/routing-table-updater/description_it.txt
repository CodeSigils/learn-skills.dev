Mantenere/eseguire tabelle di instradamento e riferimenti ai comandi quando si tratta di competenze o agenti
vengono aggiunti, modificati o rimossi. Da utilizzare quando i metadati della competenza/agente cambiano,
dopo l'esecuzione di skill-creator-engineer o agent-creator-engineer oppure quando
le tabelle di routing necessitano di sincronizzazione. Utilizzare per "aggiorna percorsi", "sync
routing", "tabella di routing" o "refresh /do". NON utilizzare per creare
nuove abilità/agenti, modifica della logica delle abilità o modifiche manuali alla tabella /do.
