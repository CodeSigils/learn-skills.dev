الحفاظ على / عمل جداول التوجيه ومراجع الأوامر عند المهارات أو الوكلاء
تتم إضافتها أو تعديلها أو إزالتها. يُستخدم عندما تتغير بيانات تعريف المهارة/الوكيل،
بعد تشغيل المهارة-المهندس-الخالق أو الوكيل-الخالق-المهندس، أو متى
تحتاج جداول التوجيه إلى المزامنة. استخدم لـ "تحديث المسارات"، "sync
التوجيه أو "جدول التوجيه" أو "تحديث / القيام". لا تستخدم للإنشاء
مهارات/وكلاء جدد، أو تعديل منطق المهارات، أو إجراء تعديلات يدوية على الجدول.
