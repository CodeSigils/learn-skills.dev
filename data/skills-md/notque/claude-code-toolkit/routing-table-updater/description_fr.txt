Maintenir/faire les tables de routage et les références de commandes lorsque les compétences ou les agents
sont ajoutés, modifiés ou supprimés. À utiliser lorsque les métadonnées des compétences/agents changent,
après les exécutions du créateur de compétences ou de l'ingénieur-créateur d'agent, ou lorsque
les tables de routage nécessitent une synchronisation. Utiliser pour "mettre à jour les itinéraires", "synchroniser
routage", "table de routage" ou "refresh /do". Ne PAS utiliser pour créer
nouvelles compétences/agents, modification de la logique des compétences ou modifications manuelles du tableau /do.
