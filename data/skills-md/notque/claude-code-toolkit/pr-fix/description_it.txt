Flusso di lavoro di convalida e correzione per i commenti di revisione PR: recupero, convalida, pianificazione,
Correggi, impegnati. Da utilizzare quando l'utente desidera rispondere al feedback delle pubbliche relazioni, correggere i commenti di revisione,
o risolvere le richieste dei revisori. Utilizzare per "correggere commenti PR", "revisione indirizzo",
"pr-fix" o "risolvi feedback". NON utilizzare per creare PR o rivedere il codice
senza correzioni o debug generale non correlato ai commenti PR.
