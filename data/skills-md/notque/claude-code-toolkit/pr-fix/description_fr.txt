Workflow de validation puis de correction pour les commentaires de révision des relations publiques : récupérer, valider, planifier,
Corriger, valider. À utiliser lorsque l'utilisateur souhaite répondre aux commentaires des relations publiques, corriger les commentaires de révision,
ou résoudre les demandes des évaluateurs. À utiliser pour « corriger les commentaires PR », « révision de l'adresse »,
"pr-fix" ou "résoudre les commentaires". Ne PAS utiliser pour créer des PR, réviser le code
sans correction, ni débogage général sans rapport avec les commentaires PR.
