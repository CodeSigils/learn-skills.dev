التحقق من صحة سير العمل ثم الإصلاح لتعليقات مراجعة العلاقات العامة: الجلب، التحقق من الصحة، التخطيط،
أصلح، التزم. يُستخدم عندما يريد المستخدم معالجة تعليقات العلاقات العامة، وإصلاح تعليقات المراجعة،
أو حل طلبات المراجعين. يُستخدم لـ "إصلاح تعليقات العلاقات العامة"، و"مراجعة العنوان"،
"pr-fix" أو "حل التعليقات". لا تستخدم لإنشاء العلاقات العامة، ومراجعة التعليمات البرمجية
دون إصلاح، أو تصحيح الأخطاء العامة التي لا علاقة لها بتعليقات العلاقات العامة.
