Validieren-dann-korrigieren-Workflow für PR-Überprüfungskommentare: Abrufen, Validieren, Planen,
Fix, Commit. Verwenden Sie diese Option, wenn der Benutzer auf PR-Feedback eingehen, Bewertungskommentare korrigieren möchte.
oder Rezensentenanfragen lösen. Verwendung für „PR-Kommentare korrigieren“, „Adressüberprüfung“,
„pr-fix“ oder „Feedback lösen“. NICHT zum Erstellen von PRs oder zum Überprüfen von Code verwenden
ohne Reparatur oder allgemeines Debuggen, das nichts mit PR-Kommentaren zu tun hat.
