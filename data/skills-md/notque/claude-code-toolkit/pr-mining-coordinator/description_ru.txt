Координировать PR-майнинг для извлечения племенных знаний и стандартов кодирования из
PR-история GitHub. Используйте при анализе комментариев к обзорам, извлечении правил кодирования,
отслеживание заданий по добыче полезных ископаемых или анализ моделей рецензирования в разных репозиториях.
Используйте для «моих PR», «извлечения стандартов», «правил кодирования из обзоров» или
«шаблоны рецензента». НЕ используйте для проверки кода, линтинга, статического анализа,
или написание новых стандартов кодирования с нуля без PR-данных.
