تنسيق تعدين العلاقات العامة لاستخراج المعرفة القبلية ومعايير الترميز منها
تاريخ جيثب للعلاقات العامة. يُستخدم عند استخراج تعليقات المراجعة، واستخراج قواعد الترميز،
تتبع وظائف التعدين، أو تحليل أنماط المراجعين عبر المستودعات.
استخدم لـ "العلاقات العامة الخاصة بي"، أو "استخراج المعايير"، أو "قواعد الترميز من المراجعات"، أو
"أنماط المراجعين". لا تستخدم لمراجعة التعليمات البرمجية، والفحص، والتحليل الثابت،
أو كتابة معايير ترميز جديدة من الصفر بدون بيانات العلاقات العامة.
