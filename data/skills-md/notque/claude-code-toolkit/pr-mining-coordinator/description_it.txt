Coordinare il mining di PR per estrarre conoscenze tribali e standard di codifica
Storia delle PR di GitHub. Da utilizzare durante l'estrazione di commenti di revisione, l'estrazione di regole di codifica,
tenere traccia dei lavori di mining o analizzare i modelli dei revisori nei repository.
Utilizzare per "PR miniere", "standard di estrazione", "regole di codifica da recensioni" o
"modelli di revisore". NON utilizzare per revisione del codice, linting, analisi statica,
o scrivere nuovi standard di codifica da zero senza dati PR.
