Соглашения по кодированию SAP Converged Cloud Go, извлеченные из sapcc/keppel и
PR-обзоры sapcc/go-bits. Обеспечивает архитектуру
шаблоны, правила использования библиотек, соглашения об обработке ошибок, шаблоны тестирования,
и принципы борьбы с чрезмерным проектированием. Используйте при работе с репозиториями sapcc/*,
когда код импортирует github.com/sapcc/go-bits или ориентирован на SAP CC
стандарты проверки кода. НЕ используйте для общих проектов Go без
зависимости SAPC.
