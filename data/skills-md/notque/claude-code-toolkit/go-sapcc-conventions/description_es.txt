Convenciones de codificación de SAP Converged Cloud Go extraídas de sapcc/keppel y
Revisiones de relaciones públicas de sapcc/go-bits. Hace cumplir la arquitectura
patrones, reglas de uso de bibliotecas, convenciones de manejo de errores, patrones de prueba,
y principios contra el exceso de ingeniería. Úselo cuando trabaje en repositorios sapcc/*,
cuando el código importa github.com/sapcc/go-bits, o cuando apunta a SAP CC
estándares de revisión de código. NO lo use para proyectos generales de Go sin
dependencias sapcc.
