Conventions de codage SAP Converged Cloud Go extraites de sapcc/keppel et
critiques de relations publiques sapcc/go-bits. Applique l'architecture
modèles, règles d'utilisation de la bibliothèque, conventions de gestion des erreurs, modèles de test,
et les principes anti-sur-ingénierie. À utiliser lorsque vous travaillez dans des dépôts sapcc/*,
lorsque le code importe github.com/sapcc/go-bits ou lors du ciblage de SAP CC
normes de révision du code. Ne PAS utiliser pour les projets Go généraux sans
dépendances SAPCC.
