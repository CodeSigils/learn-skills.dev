Evaluar y mejorar habilidades a través de pruebas medidas. Ejecutar evaluaciones de activación
para probar si las descripciones de habilidades causan una activación correcta, optimizar
descripciones a través de circuitos automatizados de entrenamiento/prueba, calidad de producción de habilidades de referencia
con comparaciones A/B y validar la estructura de habilidades. Usar cuando el usuario dice
"mejorar habilidades", "probar activadores de habilidades", "optimizar descripción", "comparar"
habilidad", "habilidad de evaluación" o "calidad de habilidad". NO lo use para crear nuevas habilidades
(use habilidad-creador-ingeniero).
