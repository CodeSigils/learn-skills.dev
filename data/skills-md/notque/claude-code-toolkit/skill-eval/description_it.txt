per verificare se le descrizioni delle abilità causano la corretta attivazione, ottimizzare
descrizioni tramite cicli automatizzati di formazione/test, valutazione della qualità dei risultati delle competenze
con confronti A/B e convalidare la struttura delle competenze. Utilizzare quando l'utente dice
"migliora abilità", "testa i trigger di abilità", "ottimizza descrizione", "benchmark
abilità", "abilità di valutazione" o "qualità dell'abilità". NON utilizzare per creare nuove competenze
(usa abilità-creatore-ingegnere).
