Оценивайте и улучшайте навыки посредством измеряемого тестирования. Запуск оценок триггеров
чтобы проверить, вызывают ли описания навыков правильную активацию, оптимизировать
описания с помощью автоматизированных циклов обучения/тестирования, контроль качества выходных навыков
с помощью сравнений A/B и проверки структуры навыков. Используйте, когда пользователь говорит
«улучшить навык», «проверить триггеры навыков», «оптимизировать описание», «оценить
навык», «оценка навыка» или «качество навыка». НЕ используйте для создания новых навыков
(используйте навык-создатель-инженер).
