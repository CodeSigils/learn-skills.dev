Обнаружение статистических правил посредством измерения кодовых баз Go: подсчет
шаблоны, получение правил с оценкой достоверности, создание отпечатков вектора стиля.
Используйте при анализе соглашений о кодовой базе, извлечении неявных правил кодирования,
профилирование репо перед подключением или автоматизацией PR. Используйте для «анализировать
кодовая база", "найти шаблоны кодирования", "какие соглашения использует этот репозиторий",
«правила извлечения» или «ДНК кодовой базы». НЕ используйте для проверки кода, ошибка
исправления, рефакторинг или оптимизация производительности.
