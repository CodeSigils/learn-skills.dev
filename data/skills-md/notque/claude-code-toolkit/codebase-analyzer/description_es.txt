Descubrimiento de reglas estadísticas mediante la medición de bases de código de Go: recuento
patrones, derivar reglas de puntuación de confianza, producir huellas dactilares de vectores de estilo.
Úselo al analizar convenciones de base de código, extraer reglas de codificación implícitas,
perfilar un repositorio antes de la incorporación o la automatización de relaciones públicas. Usar para "analizar
base de código", "buscar patrones de codificación", "qué convenciones utiliza este repositorio",
"extraer reglas" o "código base de ADN". NO lo use para revisión de código, error
correcciones, refactorización u optimización del rendimiento.
