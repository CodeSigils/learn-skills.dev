تحقق من حالة سير عمل GitHub Actions بعد دفع git باستخدام gh CLI. التقارير
حالة CI، تحدد الوظائف الفاشلة، وتقترح التكاثر المحلي
الأوامر. يُستخدم بعد "git Push"، عندما يسأل المستخدم عن حالة CI وسير العمل
الفشل، أو بناء النتائج. استخدم لـ "التحقق من CI"، و"حالة سير العمل"،
"الإجراءات الفاشلة" أو "البناء معطل". لا تستخدم للبطانة المحلية
(استخدم فحص التعليمات البرمجية)، وتصحيح فشل الاختبار محليًا (استخدم
التصحيح المنهجي)، أو إعداد مسارات عمل جديدة.
