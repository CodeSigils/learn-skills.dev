Многопрофильная оркестровка на основе DAG: обнаружение, планирование, проверка, выполнение.
Строит графики выполнения для задач, требующих последовательного выполнения нескольких навыков.
или параллельно с разрешением зависимостей и передачей контекста. Используйте, когда
задача требует 2+ навыков, связанных вместе, параллельного выполнения навыков или
условное ветвление между навыками. Используйте для «навыков сочинения», «цепочки
рабочий процесс», «множественные навыки» или «организация навыков». НЕ используйте, когда
один навык может обрабатывать запрос или для простого последовательного вызова
для этого не требуется управление зависимостями.
