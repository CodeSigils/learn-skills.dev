Edición masiva segura en múltiples publicaciones de rebajas de Hugo: buscar/reemplazar, frontmatter
Actualizaciones, el contenido se transforma con una vista previa obligatoria antes de aplicar. Usar cuando el usuario
necesita reemplazo de texto por lotes, cambios masivos en los campos iniciales, encabezado/enlace/espacio en blanco
normalización o contenido basado en expresiones regulares se transforma entre publicaciones. Úselo para "edición por lotes",
"buscar y reemplazar entre archivos", "agregar campos a todas las publicaciones", "etiquetas de actualización masiva".
NO lo utilice para ediciones de un solo archivo, refactorización estructural o generación de contenido.
