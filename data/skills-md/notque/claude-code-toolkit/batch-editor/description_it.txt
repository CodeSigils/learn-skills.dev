Modifica collettiva sicura su più post di markdown di Hugo: trova/sostituisci, frontmatter
aggiornamenti, trasformazioni del contenuto con anteprima obbligatoria prima dell'applicazione. Utilizzare quando utente
necessita di sostituzione batch del testo, modifiche collettive ai campi in primo piano, intestazione/link/spazi bianchi
normalizzazione o il contenuto basato su regex si trasforma tra i post. Utilizzare per "modifica batch",
"trova e sostituisci tra file", "aggiungi campo a tutti i post", "tag di aggiornamento collettivo".
NON utilizzare per modifiche di file singoli, refactoring strutturale o generazione di contenuti.
