التحديثات، يتحول المحتوى مع المعاينة الإلزامية قبل التطبيق. استخدم عند المستخدم
يحتاج إلى استبدال نص دفعة واحدة، وتغييرات كبيرة في حقل المادة الأمامية، والعنوان/الرابط/المسافة البيضاء
التطبيع، أو المحتوى المستند إلى regex يتحول عبر المنشورات. استخدم لـ "التحرير الدفعي"،
"البحث عن الملفات واستبدالها"، "إضافة حقل إلى جميع المشاركات"، "علامات التحديث المجمعة".
لا تستخدمه في تعديلات الملف الفردي، أو إعادة البناء الهيكلي، أو إنشاء المحتوى.
