Безопасное массовое редактирование нескольких постов Hugo с уценкой: найти/заменить, вступление
обновления, контент преобразуется с обязательным предварительным просмотром перед применением. Используйте, когда пользователь
требуется пакетная замена текста, массовое изменение полей заголовка, заголовка/ссылки/пробелов
нормализация или преобразование контента на основе регулярных выражений между сообщениями. Используйте для «пакетного редактирования»,
«найти и заменить в файлах», «добавить поле ко всем сообщениям», «массовое обновление тегов».
НЕ используйте для редактирования отдельных файлов, структурного рефакторинга или создания контента.
