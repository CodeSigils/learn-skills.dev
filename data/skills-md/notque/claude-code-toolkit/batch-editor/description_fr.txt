Édition groupée sécurisée sur plusieurs publications Hugo Markdown : rechercher/remplacer, frontmatter
mises à jour, le contenu se transforme avec aperçu obligatoire avant application. À utiliser lorsque l'utilisateur
nécessite un remplacement de texte par lots, des modifications groupées des champs de front, un titre/un lien/un espace
la normalisation ou le contenu basé sur les regex se transforme entre les publications. Utiliser pour "l'édition par lots",
"rechercher et remplacer dans les fichiers", "ajouter un champ à tous les messages", "balises de mise à jour groupée".
Ne PAS utiliser pour les modifications de fichiers uniques, la refactorisation structurelle ou la génération de contenu.
