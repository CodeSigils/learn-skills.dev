تنسيق مراجعة التعليمات البرمجية المتوازية المكونة من 3 مراجعين: إطلاق الأمان، ومنطق الأعمال،
ومراجعو الهندسة المعمارية في وقت واحد، ويجمعون النتائج حسب الخطورة، و
إصدار حكم موحد بالحظر/الإصلاح/الموافقة. يُستخدم عند مراجعة العلاقات العامة مع 5+
الملفات، أو التغييرات الحساسة للأمان، أو الميزات الجديدة التي تحتاج إلى تغطية واسعة، أو متى
يطلب المستخدم "مراجعة موازية" أو "مراجعة شاملة" أو "مراجعة كاملة".
لا تستخدم لإصلاحات ملف واحد، أو تغييرات التوثيق فقط، أو عندما
مراجعة الكود المنهجية (التسلسلية) كافية.
