Параллельная оркестровка проверки кода тремя рецензентами: запуск безопасности, бизнес-логики,
и рецензенты по архитектуре одновременно, объединяют результаты по серьезности и
выдать единый вердикт BLOCK/FIX/APPROVE. Используйте при просмотре PR на 5+.
файлы, изменения, чувствительные к безопасности, новые функции, требующие широкого охвата, или когда
пользователь запрашивает «параллельную проверку», «комплексную проверку» или «полную проверку».
НЕ используйте для исправлений отдельных файлов, изменений только для документации или когда
систематического обзора кода (последовательного) достаточно.
