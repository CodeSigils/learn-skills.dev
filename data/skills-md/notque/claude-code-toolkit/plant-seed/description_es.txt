Captar una idea con visión de futuro como una semilla con condiciones desencadenantes, alcance y
fundamento para que aparezca automáticamente durante el diseño de características futuras. Usar para
"plantar semilla", "guardar esta idea para más tarde", "aplazar esta idea", "recordar esto
para cuando", "semilla" o "/planta-semilla". NO lo use para TODO, tareas inmediatas,
informes de errores o trabajos que deberían realizarse en la sesión actual.
