Méthodologie de révision du code en 4 phases : COMPRENDRE les modifications, VÉRIFIER les réclamations
code, ÉVALUER les risques de sécurité/performance/architecture, DOCUMENTER les résultats avec
classification de la gravité. À utiliser lors de l'examen des demandes d'extraction, de l'audit du code
avant la publication, l'évaluation des contributions externes ou la vérification avant la fusion.
À utiliser pour « réviser le PR », « révision du code », « code d'audit », « vérifier ce PR » ou
"examiner mes modifications". Ne PAS utiliser pour écrire du nouveau code ou implémenter des fonctionnalités.
