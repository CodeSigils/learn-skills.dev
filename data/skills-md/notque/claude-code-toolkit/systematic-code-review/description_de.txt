4-Phasen-Code-Review-Methodik: Änderungen VERSTEHEN, Ansprüche ÜBERPRÜFEN
Code, Sicherheits-/Leistungs-/Architekturrisiken BEWERTEN, Ergebnisse DOKUMENTIEREN mit
Schweregradklassifizierung. Wird zum Überprüfen von Pull-Anfragen und zum Prüfen von Code verwendet
vor der Veröffentlichung, die Bewertung externer Beiträge oder die Verifizierung vor dem Zusammenschluss.
Verwendung für „PR überprüfen“, „Codeüberprüfung“, „Code prüfen“, „diese PR überprüfen“ oder
„Meine Änderungen überprüfen“. NICHT zum Schreiben von neuem Code oder zum Implementieren von Funktionen verwenden.
