Metodologia di revisione del codice in 4 fasi: COMPRENDERE le modifiche, VERIFICARE le rivendicazioni
codice, VALUTAZIONE dei rischi di sicurezza/prestazioni/architettura, DOCUMENTAZIONE dei risultati con
classificazione di gravità. Da utilizzare durante la revisione delle richieste pull e il controllo del codice
prima del rilascio, valutazione dei contributi esterni o verifica pre-fusione.
Utilizzare per "revisione PR", "revisione del codice", "codice di controllo", "controlla questo PR" o
"rivedi le mie modifiche". NON utilizzare per scrivere nuovo codice o implementare funzionalità.
