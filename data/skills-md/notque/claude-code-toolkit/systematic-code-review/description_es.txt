Metodología de revisión de código de 4 fases: COMPRENDER los cambios, VERIFICAR las reclamaciones
código, EVALUAR los riesgos de seguridad/rendimiento/arquitectura, DOCUMENTAR los hallazgos con
clasificación de gravedad. Úselo al revisar solicitudes de extracción y auditar código
antes del lanzamiento, evaluación de contribuciones externas o verificación previa a la fusión.
Úselo para "revisar PR", "revisión de código", "código de auditoría", "verificar este PR" o
"revisar mis cambios". NO lo use para escribir código nuevo o implementar funciones.
