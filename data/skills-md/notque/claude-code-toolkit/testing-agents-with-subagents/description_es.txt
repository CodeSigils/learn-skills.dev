Pruebas RED-GREEN-REFACTOR para agentes: enviar subagentes con entradas conocidas,
capturar resultados palabra por palabra, verificar con las expectativas. Úselo al crear,
modificar o validar agentes y habilidades. Usar para "agente de prueba", "validar
agente", "verificar que el agente funciona" o comprobaciones previas a la implementación. NO utilizar para
solicitudes de funciones, ediciones sencillas sin impacto en el comportamiento o agentes
sin resultados estructurados para verificar.
