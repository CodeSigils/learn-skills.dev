Генерируйте и проверяйте имена ветвей Git на основе сообщений или описаний коммитов.
Используйте при создании ветвей, генерации имен для /pr-sync, проверке существующих
имена ветвей или преобразование обычных коммитов в префиксы ветвей. Триггеры:
«имя ветки», «создать ветку», «назвать эту ветку», «подтвердить ветку». НЕ
использовать для операций git (извлечение, слияние, удаление), стратегий ветвления или
правила защиты филиалов.
