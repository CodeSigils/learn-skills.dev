Générez et validez les noms de branches Git à partir de messages de validation ou de descriptions.
À utiliser lors de la création de branches, de la génération de noms pour /pr-sync, de la validation des branches existantes
noms de branche, ou conversion de commits conventionnels en préfixes de branche. Déclencheurs :
"nom de la branche", "créer une branche", "nommer cette branche", "valider la branche". NE PAS
utiliser pour les opérations git (extraction, fusion, suppression), les stratégies de branchement ou
règles de protection des succursales.
