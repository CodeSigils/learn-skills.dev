قم بتشغيل التحقق من نوع TypeScript باستخدام tsc --noEmit وتحليل الأخطاء فيه
مخرجات قابلة للتنفيذ ومجمعة بالملفات. يُستخدم عند التحقق من صحة كود TypeScript من قبل
الالتزامات، بعد عمليات إعادة البناء، أو عند التحقق من تراجعات النوع. استخدم ل
"التحقق من النوع" أو "tsc" أو "أخطاء TypeScript" أو "التحقق من صحة النوع" أو الالتزام المسبق
التحقق من TypeScript. لا تستخدم للفحص، وتنفيذ الاختبار، ووقت التشغيل
أخطاء، أو مشاريع JavaScript فقط بدون tsconfig.json.
