Exécutez la vérification du type TypeScript avec tsc --noEmit et analysez les erreurs dans
sortie exploitable et groupée en fichiers. À utiliser lors de la validation du code TypeScript avant
commits, après des refactors ou lors de la vérification des régressions de type. Utiliser pour
"vérification de type", "tsc", "erreurs TypeScript", "validation de type" ou pré-validation
Vérification TypeScript. Ne PAS utiliser pour le peluchage, l'exécution de tests, l'exécution
erreurs ou des projets JavaScript uniquement sans tsconfig.json.
