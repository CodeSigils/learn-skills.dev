Ejecute la verificación de tipos de TypeScript con tsc --noEmit y analice los errores en
salida procesable y agrupada en archivos. Úselo al validar el código TypeScript antes
confirmaciones, después de refactorizaciones o al comprobar regresiones de tipos. Usar para
"verificación de tipo", "tsc", "errores de TypeScript", "validación de tipo" o confirmación previa
Verificación mecanografiada. NO lo use para linting, ejecución de pruebas, tiempo de ejecución
errores o proyectos solo de JavaScript sin tsconfig.json.
