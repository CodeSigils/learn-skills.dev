Pipeline di configurazione di Perses per la prima volta: scopri o distribuisci il server, configura la connessione MCP,
creare il progetto iniziale, aggiungere origini dati e verificare la connettività. Conduttura a 4 fasi:
SCOPRI, CONNETTI, CONFIGURA, CONVALIDA. Da utilizzare quando si configura Perses per la prima volta,
connettendo Claude Code a un'istanza Perses esistente o inserendo un nuovo team in Perses.
Utilizzare per "perses onboard", "configurazione perses", "connessione a perses", "perses per iniziare".
NON utilizzare per la creazione di dashboard (utilizzare perses-dashboard-create) o per la distribuzione del server
dettagli (usa perses-deploy).
