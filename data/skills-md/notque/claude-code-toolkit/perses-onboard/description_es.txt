Canalización de configuración de Perses por primera vez: descubrir o implementar el servidor, configurar la conexión MCP,
cree un proyecto inicial, agregue fuentes de datos y verifique la conectividad. Tubería de 4 fases:
DESCUBRE, CONECTA, CONFIGURA, VALIDA. Úselo al configurar Perses por primera vez,
conectar Claude Code a una instancia de Perses existente o incorporar un nuevo equipo a Perses.
Úselo para "perses a bordo", "configurar perses", "conectar a perses", "perses comenzando".
NO lo use para la creación de paneles (use perses-dashboard-create) o la implementación de servidores
detalles (use perses-deploy).
