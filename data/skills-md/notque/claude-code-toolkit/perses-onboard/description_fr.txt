Pipeline de configuration Perses pour la première fois : découvrir ou déployer le serveur, configurer la connexion MCP,
créez le projet initial, ajoutez des sources de données et vérifiez la connectivité. Canalisation 4 phases :
DÉCOUVREZ, CONNECTEZ, CONFIGUREZ, VALIDEZ. À utiliser lors de la configuration de Perses pour la première fois,
connecter Claude Code à une instance Perses existante ou intégrer une nouvelle équipe à Perses.
À utiliser pour « Perses à bord », « Configuration des perses », « Connexion aux perses », « Perses pour commencer ».
Ne PAS utiliser pour la création de tableaux de bord (utilisez perses-dashboard-create) ou le déploiement de serveurs
détails (utilisez perses-deploy).
