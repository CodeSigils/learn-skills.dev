Déployer le serveur Perses : Docker Compose pour le développement local, chart Helm pour K8 ou binaire
pour le métal nu. Configurer la base de données (fichier/SQL), l'authentification (native/OIDC/OAuth), les plugins,
les dossiers de provisionnement et les paramètres frontend. À utiliser lorsque l'utilisateur souhaite déployer, installer,
installer ou configurer une instance de serveur Perses. Utiliser pour "déployer perses", "installer
perses", "configuration perses", "serveur perses", "exécuter perses". Ne PAS utiliser pour le tableau de bord
création (utilisez perses-dashboard-create) ou développement de plugin (utilisez perses-plugin-create).
