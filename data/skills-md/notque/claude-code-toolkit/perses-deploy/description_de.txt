Stellen Sie den Perses-Server bereit: Docker Compose für lokale Entwickler, Helm-Chart für K8s oder Binärdatei
für blankes Metall. Konfigurieren Sie Datenbank (Datei/SQL), Authentifizierung (nativ/OIDC/OAuth), Plugins,
Bereitstellungsordner und Frontend-Einstellungen. Verwenden Sie diese Option, wenn der Benutzer bereitstellen, installieren oder installieren möchte.
Richten Sie eine Perses-Serverinstanz ein oder konfigurieren Sie sie. Verwenden Sie für „deploy perses“, „install
perses“, „perses setup“, „perses server“, „run perses“. NICHT für das Armaturenbrett verwenden
Erstellung (verwenden Sie perses-dashboard-create) oder Plugin-Entwicklung (verwenden Sie perses-plugin-create).
