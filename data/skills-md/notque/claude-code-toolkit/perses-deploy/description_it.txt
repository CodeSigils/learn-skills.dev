Distribuisci il server Perses: Docker Compose per sviluppatori locali, grafico Helm per K8 o binario
per metallo nudo. Configura database (file/SQL), autenticazione (nativa/OIDC/OAuth), plug-in,
cartelle di provisioning e impostazioni del frontend. Utilizzare quando l'utente desidera distribuire, installare,
impostare o configurare un'istanza del server Perses. Utilizzare per "deploy perses", "install
perses", "perses setup", "perses server", "esegui perses". NON utilizzare per il cruscotto
creazione (usa perses-dashboard-create) o sviluppo di plugin (usa perses-plugin-create).
