pasos, EJECUTAR un cambio a la vez, VALIDAR sin regresiones. Usar cuando
cambiar el nombre de funciones/variables, extraer módulos, cambiar firmas,
reestructurar directorios o consolidar código duplicado. Usar para
"refactorizar", "cambiar nombre", "extraer", "reestructurar" o "migrar patrón".
NO lo utilice para corregir errores o implementar nuevas funciones.
