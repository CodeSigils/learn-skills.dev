Refactoring sécurisé et progressif : CARACTÉRISER avec des tests, PLANIFIER incrémental
étapes, EXÉCUTER un changement à la fois, VALIDER aucune régression. Utiliser quand
renommer les fonctions/variables, extraire les modules, changer les signatures,
restructuration des répertoires ou consolidation du code en double. Utiliser pour
« refactoriser », « renommer », « extraire », « restructurer » ou « migrer le modèle ».
Ne PAS utiliser pour la correction de bugs ou la mise en œuvre de nouvelles fonctionnalités.
