Полный репо-аудит соответствия SAP Converged Cloud Go. Проверяет каждую посылку
против установленных стандартов проверки — сосредоточение внимания на чрезмерном проектировании,
качество сообщений об ошибках, мертвый код, контракты интерфейса, структуры копирования и вставки,
и согласованность рисунка с Кеппелем. Отправляет параллельные агенты по пакетам
группа, каждая из которых читает ВСЕ правила sapcc. Делает выводы на уровне кода с помощью
фактические различия до/после. Вызывается через «/sapcc-audit» или через /do.
