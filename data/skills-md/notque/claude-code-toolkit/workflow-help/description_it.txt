Guida interattiva al sistema di flusso di lavoro del repository: agenti, competenze, instradamento,
e modelli di esecuzione. Utilizzare quando l'utente chiede come funziona il sistema, cosa
sono disponibili comandi o come utilizzare le fasi di brainstorming/pianificazione/esecuzione.
Utilizzare per "come funziona", "cosa puoi fare", "spiegare il flusso di lavoro",
"aiutami a capire" oppure "mostrami il procedimento". NON utilizzare per effettivamente
l'esecuzione di flussi di lavoro (utilizzare workflow-orchestrator) o il debug (utilizzare
debug sistematico).
