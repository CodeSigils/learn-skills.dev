Interaktiver Leitfaden zum Repository-Workflow-System: Agenten, Fähigkeiten, Routing,
und Ausführungsmuster. Verwenden Sie diese Option, wenn der Benutzer fragt, wie das System funktioniert und was
Welche Befehle verfügbar sind oder wie Brainstorming-/Planungs-/Ausführungsphasen verwendet werden.
Verwendung für „Wie funktioniert das“, „Was können Sie tun“, „Erklären Sie den Arbeitsablauf“,
„Hilf mir zu verstehen“ oder „Zeige mir den Prozess“. NICHT für den eigentlichen Gebrauch verwenden
Ausführen von Workflows (verwenden Sie Workflow-Orchestrator) oder Debuggen (verwenden Sie
systematisches Debuggen).
