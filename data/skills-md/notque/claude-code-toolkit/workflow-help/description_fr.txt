Guide interactif du système de workflow du référentiel : agents, compétences, routage,
et les modèles d'exécution. À utiliser lorsque l'utilisateur demande comment fonctionne le système, quoi
les commandes sont disponibles, ou comment utiliser les phases de brainstorming/planification/exécution.
Utiliser pour "comment ça marche", "que pouvez-vous faire", "expliquer le flux de travail",
"aidez-moi à comprendre" ou "montrez-moi le processus". Ne PAS utiliser réellement
exécution de workflows (utilisez workflow-orchestrator) ou débogage (utilisez
débogage systématique).
