Guía interactiva del sistema de flujo de trabajo del repositorio: agentes, habilidades, enrutamiento,
y patrones de ejecución. Úselo cuando el usuario pregunta cómo funciona el sistema, qué
los comandos están disponibles, o cómo utilizar las fases de lluvia de ideas/planificación/ejecución.
Utilice para "cómo funciona esto", "qué se puede hacer", "explicar el flujo de trabajo",
"ayúdame a entender" o "muéstrame el proceso". NO lo use para realidad
ejecutar flujos de trabajo (use el orquestador de flujo de trabajo) o depurar (use
depuración sistemática).
