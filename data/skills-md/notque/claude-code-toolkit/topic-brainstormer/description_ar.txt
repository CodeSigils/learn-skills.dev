قم بإنشاء أفكار لموضوعات منشورات المدونة من خلال التنقيب عن المشكلات، وتحليل الفجوات، و
التوسع التكنولوجي. يُستخدم عندما يحتاج المستخدم إلى أفكار المحتوى، أو يريد تبادل الأفكار
المقالات، أو يسأل "ما الذي يجب أن أكتب عنه"، أو يحتاج إلى ملء فجوات المحتوى.
يُستخدم لـ "العصف الذهني"، أو "أفكار الموضوع"، أو "ما يجب كتابته"، أو "فجوات المحتوى"، أو
"أفكار المدونة". لا تستخدم لكتابة المشاركات أو إنشاء الخطوط العريضة أو تحسين محركات البحث
التحسين دون الحاجة إلى تفكير محدد.
