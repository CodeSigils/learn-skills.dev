Transforme la comunicación técnica densa en negocios claros y estructurados
formatos utilizando extracción de proposiciones y plantillas deterministas. Usar cuando
el usuario necesita convertir actualizaciones técnicas, narrativas de depuración, estado
informes o discusiones de dependencia en resúmenes listos para ejecutivos. Usar para
"transformar esta actualización", "preparar esta actualización para ejecutivos", "resumir para mi
gerente", "formato profesional" o "informe de estado". NO utilizar para
escribir contenido nuevo desde cero, escritura creativa o generar
documentación que no transforma una entrada existente.
