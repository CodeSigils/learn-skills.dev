قم بإنشاء وظائف Claude Code cron مقطوعة الرأس من وصف المهمة والجدول الزمني.
ينشئ برنامج نصي مجمّع مع آليات الأمان (ملف القفل، سقف الميزانية، التشغيل الجاف
الافتراضي، التسجيل) وتثبيت إدخالات crontab عبر البرنامج النصي Python الحتمي.
يُستخدم عندما يقول المستخدم "جدول"، "تشغيل كل"، "مهمة كرون"، "تشغيل مرتين يوميًا"،
"التشغيل كل ساعة"، أو "التشغيل يوميًا"، أو "التشغيل أسبوعيًا"، أو "جدولة المهمة".
