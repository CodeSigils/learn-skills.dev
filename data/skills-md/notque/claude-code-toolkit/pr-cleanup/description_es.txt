Limpieza de sucursales locales después de la fusión de PR: identificar, cambiar, eliminar, podar
4 pasos. Úselo cuando un PR se haya fusionado y las sucursales locales necesiten limpieza,
cuando se acumulan ramas obsoletas, o cuando el usuario dice "limpiar ramas",
"eliminar rama fusionada" o "podar". NO lo use para la creación de ramas,
Revisión de relaciones públicas o comprobaciones de CI.
