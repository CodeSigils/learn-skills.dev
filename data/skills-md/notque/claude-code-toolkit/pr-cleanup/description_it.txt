Pulizia del ramo locale dopo l'unione PR: identificare, cambiare, eliminare, eliminare
4 passaggi. Da utilizzare quando un PR è stato fuso e le filiali locali necessitano di pulizia,
quando si accumulano rami obsoleti o quando l'utente dice "ripulisci rami",
"elimina ramo unito" o "pota". NON utilizzare per la creazione di rami,
Revisione PR o controlli CI.
