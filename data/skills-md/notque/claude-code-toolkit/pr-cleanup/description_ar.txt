تنظيف الفرع المحلي بعد دمج العلاقات العامة: تحديد، تبديل، حذف، تقليم
4 خطوات. يُستخدم عندما يتم دمج العلاقات العامة وتحتاج الفروع المحلية إلى التنظيف،
عندما تتراكم الفروع القديمة، أو عندما يقول المستخدم "تنظيف الفروع"،
"حذف الفرع المدمج" أو "تقليم". لا تستخدم لإنشاء فرع،
مراجعة العلاقات العامة، أو فحوصات CI.
