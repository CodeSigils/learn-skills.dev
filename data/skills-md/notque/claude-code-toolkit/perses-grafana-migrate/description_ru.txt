Миграция информационных панелей Grafana в Perses: экспорт информационных панелей Grafana, преобразование с помощью
percli мигрирует, проверяет преобразованный вывод, устраняет несовместимости, развертывает в Perses.
Выполняет массовую миграцию с параллельной обработкой. Используйте для «миграции графаны»,
«графана в перс», «персы мигрируют», «конвертировать графану». НЕ используйте для создания
новые дашборды с нуля (используйте perses-dashboard-create).
