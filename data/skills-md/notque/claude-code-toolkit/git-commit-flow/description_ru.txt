Поэтапный рабочий процесс фиксации git с проверкой, промежуточным хранением и CLAUDE.md
обеспечение соблюдения требований. Используйте при создании коммитов, промежуточных изменениях или
когда рабочие процессы PR требуют стандартизированных коммитов. Триггеры: «фиксировать изменения»,
«сохранить работу», «создать фиксацию» или вызов внутренних навыков из PR.
рабочие процессы. НЕ используйте для коммитов слияния, перебазирования, внесения поправок, выборки,
или экстренные откаты, требующие чистой скорости git.
