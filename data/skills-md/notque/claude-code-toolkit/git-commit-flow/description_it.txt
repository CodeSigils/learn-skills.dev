Flusso di lavoro Git Commit a fasi con convalida, staging e CLAUDE.md
applicazione della conformità. Da utilizzare durante la creazione di commit, modifiche di staging o
quando i flussi di lavoro PR necessitano di commit standardizzati. Trigger: "conferma modifiche",
"salva lavoro", "crea commit" o invocazione di competenze interne da PR
flussi di lavoro. NON utilizzare per merge commit, rebase, modifiche, cherry-pick,
o rollback di emergenza che richiedono velocità git grezza.
