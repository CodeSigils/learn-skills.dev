Flujo de trabajo de confirmación de git controlado por fases con validación, preparación y CLAUDE.md
aplicación del cumplimiento. Úselo al crear confirmaciones, preparar cambios o
cuando los flujos de trabajo de relaciones públicas necesitan compromisos estandarizados. Activadores: "confirmar cambios",
"guardar trabajo", "crear compromiso" o invocación de habilidad interna desde relaciones públicas
flujos de trabajo. NO lo use para fusiones, cambios de base, enmiendas, selecciones selectivas,
o reversiones de emergencia que requieren velocidad bruta de git.
