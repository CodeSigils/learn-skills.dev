Generazione di immagini basata su CLI da istruzioni di testo utilizzando le API di Google Gemini tramite
Pitone. Da utilizzare quando l'utente ha bisogno di "generare immagine", "creare immagine con AI",
"immagine gemini", "testo in immagine", "crea sprite" o "genera personaggio
arte". Supporta la selezione del modello, la generazione batch, la rimozione della filigrana e
trasparenza dello sfondo. NON utilizzare per le funzionalità dell'immagine dell'app Web (utilizzare
nano-banana-builder), generazione di video/audio o modelli non Gemini.
