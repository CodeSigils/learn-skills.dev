Génération d'images basée sur CLI à partir d'invites de texte à l'aide des API Google Gemini via
Python. À utiliser lorsque l'utilisateur a besoin de "générer une image", de "créer une image avec l'IA",
"image Gémeaux", "texte en image", "créer un sprite" ou "générer un personnage
art". Prend en charge la sélection de modèles, la génération de lots, la suppression des filigranes et
transparence de l'arrière-plan. Ne PAS utiliser pour les fonctionnalités d'image d'application Web (utilisez
nano-banana-builder), génération vidéo/audio ou modèles non Gemini.
