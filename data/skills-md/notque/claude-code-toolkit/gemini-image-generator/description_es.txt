Generación de imágenes basada en CLI a partir de mensajes de texto utilizando las API de Google Gemini a través de
Pitón. Úselo cuando el usuario necesite "generar imagen", "crear imagen con IA",
"imagen de Géminis", "texto a imagen", "crear sprite" o "generar carácter"
arte". Admite selección de modelo, generación de lotes, eliminación de marcas de agua y
transparencia de fondo. NO lo use para funciones de imagen de aplicaciones web (use
nano-banana-builder), generación de vídeo/audio o modelos que no sean Gemini.
