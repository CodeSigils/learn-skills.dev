Систематический шестиэтапный анализ внешних репозиториев на предмет идей, которые стоит принять:
клонирование, параллельное глубокое чтение, самоинвентаризация, синтез пробелов, целевой аудит
затронутые подсистемы, отчет, основанный на реальности. Используйте при оценке того, является ли
внешнее репо обеспечивает ценность, анализируя репозитории на наличие полезных шаблонов или
сравнение подходов.
НЕ используйте для общего исследования базы кода (вместо этого используйте explore-pipeline).
