Analyse systématique en 6 phases des référentiels externes pour les idées qui méritent d'être adoptées :
clonage, lecture approfondie parallèle, auto-inventaire, synthèse des lacunes, audit ciblé des
sous-systèmes concernés, rapport fondé sur la réalité. À utiliser pour évaluer si un
le dépôt externe fournit de la valeur, analysant les dépôts pour des modèles utiles, ou
comparer les approches.
Ne PAS utiliser pour l'exploration générale de la base de code (utilisez plutôt explore-pipeline).
