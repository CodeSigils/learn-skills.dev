Analisi sistematica in 6 fasi di repository esterni per idee che vale la pena adottare:
clone, lettura approfondita parallela, autoinventario, sintesi delle lacune, audit mirato di
sottosistemi interessati, rapporto basato sulla realtà. Utilizzare per valutare se un
il repository esterno fornisce valore, analizzando i repository per modelli utili, o
confronto degli approcci.
NON utilizzare per l'esplorazione generale della base di codice (utilizzare invece explore-pipeline).
