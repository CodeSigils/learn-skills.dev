Creación de publicaciones de blog integradas por voz con flujo de trabajo de 4 fases: evaluar, decidir,
Borrador, vista previa. Úselo cuando el usuario quiera escribir una publicación de blog, crear contenido.
para un sitio de Hugo, o redactar un artículo utilizando un perfil de voz específico.
Úselo para "escribir publicación", "blog sobre", "borrador de artículo", "crear contenido",
o "escribir sobre [tema]". NO lo use para editar publicaciones existentes, voz
creación de perfiles, optimización SEO o contenido de redes sociales.
