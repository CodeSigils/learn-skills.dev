إنشاء منشور مدونة متكامل صوتيًا مع سير عمل مكون من 4 مراحل: التقييم، اتخاذ القرار،
مسودة، معاينة. يُستخدم عندما يريد المستخدم كتابة منشور مدونة أو إنشاء محتوى
لموقع Hugo، أو قم بصياغة مقال باستخدام ملف تعريف صوتي محدد.
يُستخدم لـ "كتابة منشور"، و"مدونة حول"، و"مسودة مقال"، و"إنشاء محتوى"،
أو "اكتب عن [الموضوع]". لا تستخدم لتحرير المشاركات الموجودة، الصوت
إنشاء الملف الشخصي أو تحسين محركات البحث أو محتوى الوسائط الاجتماعية.
