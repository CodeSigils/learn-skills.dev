Cree consultas PromQL, LogQL, TraceQL para paneles Perses. Validar la sintaxis de la consulta,
sugerir optimizaciones, manejar plantillas variables con formatos de interpolación Perses.
Se integra con prometheus-grafana-engineer para obtener una profunda experiencia en PromQL. Usar para
"consulta perses", "promql perses", "logql perses", "consulta panel perses". NO usar
para la configuración de la fuente de datos (use perses-datasource-manage).
