Создавайте запросы PromQL, LogQL, TraceQL для панелей Perses. Проверка синтаксиса запроса,
предлагать варианты оптимизации, обрабатывать шаблоны переменных с помощью форматов интерполяции Perses.
Интегрируется с prometheus-grafana-engineer для глубокой экспертизы PromQL. Используйте для
«запрос perses», «promql perses», «logql perses», «запрос панели perses». НЕ используйте
для настройки источника данных (используйте perses-datasource-manage).
