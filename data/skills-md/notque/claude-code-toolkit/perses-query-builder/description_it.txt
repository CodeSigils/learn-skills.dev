Costruisci query PromQL, LogQL, TraceQL per i pannelli Perses. Convalidare la sintassi della query,
suggerire ottimizzazioni, gestire modelli variabili con formati di interpolazione Perses.
Si integra con prometheus-grafana-engineer per una profonda esperienza PromQL. Utilizzare per
"perses query", "promql perses", "logql perses", "perses panel query". NON utilizzare
per la configurazione dell'origine dati (utilizzare perses-datasource-manage).
