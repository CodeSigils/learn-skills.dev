y navegación: escanear contenido, detectar huérfanos y duplicados, fusionar y
cambiar el nombre de los términos, verificar las compilaciones. Úselo cuando el usuario solicite "auditar etiquetas", "arreglar
taxonomía", "consolidar categorías", "fusionar etiquetas" o "limpiar taxonomía".
NO lo use para escribir contenido nuevo, optimización SEO de publicaciones individuales o
importante reestructuración de contenidos.
