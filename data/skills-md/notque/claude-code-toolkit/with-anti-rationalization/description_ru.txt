Явное применение антирационализации для выполнения задач с максимальной строгостью.
Загружает все шаблоны антирационализации, принудительное соблюдение ворот и давление.
сопротивление как составной модификатор для любой задачи. Используйте при выполнении критического
производственные изменения, чувствительный к безопасности код, сложные многофайловые рефакторинги,
или любая задача, где ярлыки могут причинить вред. Используйте для обозначения «со строгостью»,
«тщательно», «максимальная проверка» или «без ярлыков». НЕ используйте для
тривиальные поиски, правки только для документации или простые исправления опечаток, где
Полное обеспечение контроля за воротами было бы непропорциональным накладным расходом.
