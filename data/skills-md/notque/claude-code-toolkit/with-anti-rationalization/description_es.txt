Aplicación explícita de la antirracionalización para la ejecución de tareas con el máximo rigor.
Carga todos los patrones anti-racionalización, aplicación de puertas y presión.
Resistencia como modificador componible en cualquier tarea. Úselo al ejecutar críticas
cambios de producción, código sensible a la seguridad, refactorizaciones complejas de múltiples archivos,
o cualquier tarea donde los atajos puedan causar daño. Úselo para "con rigor",
"cuidadosamente", "verificación máxima" o "sin atajos". NO utilizar para
búsquedas triviales, ediciones solo de documentación o simples correcciones de errores tipográficos donde
La aplicación total de la ley en las puertas supondría un gasto desproporcionado.
