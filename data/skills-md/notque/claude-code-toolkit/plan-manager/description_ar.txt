إدارة دورة حياة الخطة الحتمية عبر scripts/plan-manager.py CLI.
يُستخدم عندما يطلب المستخدم إدراج الخطط أو عرضها أو إنشائها أو التحقق منها أو إكمالها أو التخلي عنها،
أو عندما تبدأ الجلسة وتحتاج الخطط القديمة إلى الظهور. استخدم لـ "التحقق من الخطط"،
"ما هو مدرج في خطتنا"، أو "وضع علامة على انتهاء المهمة"، أو "إنهاء هذه الخطة"، أو "إنشاء خطة".
لا تستخدم لتنفيذ مهام الخطة، أو تعديل محتوى الخطة مباشرة، أو
الأداء/عمل إعادة الهيكلة غير المرتبط بتتبع الخطة.
