Gestión determinista del ciclo de vida del plan a través de scripts/plan-manager.py CLI.
Úselo cuando el usuario solicite enumerar, mostrar, crear, verificar, completar o abandonar planes.
o cuando comienza la sesión y es necesario sacar a la luz planes obsoletos. Úselo para "verificar planes",
"qué hay en nuestro plan", "marcar tarea como realizada", "terminar este plan" o "crear un plan".
NO lo utilice para ejecutar tareas del plan, modificar el contenido del plan directamente o
Trabajo de rendimiento/refactorización no relacionado con el seguimiento del plan.
