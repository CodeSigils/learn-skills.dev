أنظمة فرعية مختلفة. يُستخدم عندما يكون لفشلين أو أكثر أسباب جذرية مستقلة،
يتم كسر أنظمة فرعية متعددة بشكل مستقل، أو طلبات المستخدم متزامنة
التحقيق. يستخدم لـ "المتوازي"، "الإخفاقات المتعددة"، "الأخطاء المستقلة"،
"إصلاح هذه بشكل متزامن". لا تستخدم في حالات الفشل ذات الصلة، الحالة المشتركة
المشاكل، أو التصحيح الاستكشافي حيث يكون السبب الجذري غير معروف.
