Envoyez des sous-agents indépendants en parallèle pour des problèmes non liés couvrant
différents sous-systèmes. À utiliser lorsque plus de 2 échecs ont des causes profondes indépendantes,
plusieurs sous-systèmes sont cassés indépendamment ou les utilisateurs demandent simultanément
enquête. À utiliser pour "parallèle", "échecs multiples", "bugs indépendants",
"réparez-les simultanément". Ne PAS utiliser pour les pannes associées, état partagé
problèmes ou débogage exploratoire dont la cause première est inconnue.
