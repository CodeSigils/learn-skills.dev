Проверка золотого стандарта кода для репозиториев SAP CC Go в сравнении с кодом проекта
стандарты проведения обзоров. Отправляет 10 агентов-специалистов параллельно —
каждый загружает ссылки и сканирует специфичные для предметной области
ВСЕ пакеты на предмет нарушений в закрепленном за ними домене. Производит приоритетные
отчет с примерами кода ОТКЛОНЕНО/ПРАВИЛЬНО. Применяется необязательный режим --fix
исправления в ветке рабочего дерева. Это окончательный ответ: «будет ли этот код
пройти проверку потенциальных клиентов?" оценка.
