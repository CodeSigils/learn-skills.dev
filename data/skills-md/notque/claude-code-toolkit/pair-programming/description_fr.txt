Codage collaboratif avec micro-étapes imposées : annoncer, afficher les différences,
attendez la confirmation, postulez, vérifiez. L'utilisateur contrôle le rythme avec les commandes.
Fonctionne avec n'importe quel agent de domaine en tant qu'exécuteur testamentaire.

À utiliser lorsque : "programme de jumelage", "jumelage avec moi", "codons ensemble",
"codage étape par étape", "guidez-moi à travers la mise en œuvre", "codez avec moi"
