Управление жизненным циклом переменных Perses: создавайте переменные Text и List на глобальном уровне,
проект или область информационной панели. Обработка цепочек переменных с помощью зависимостей (A зависит
на B зависит от C). Поддерживает более 14 форматов интерполяции. Использует инструменты MCP, когда
доступен, Percli CLI в качестве запасного варианта. Используйте для «переменной perses», «переменной информационной панели»,
«перс-фильтр», «добавить переменную». НЕ используйте для управления источниками данных
(используйте pers-datasource-manage).
