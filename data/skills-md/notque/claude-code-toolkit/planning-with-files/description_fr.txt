Fichiers de démarques persistants comme mémoire de travail pour des tâches complexes : planifier,
suivre les progrès, stocker les résultats. À utiliser lorsque les tâches comportent plus de 3 phases, nécessitent
recherche, couvrent de nombreux appels d'outils ou risquent une dérive du contexte. Utiliser pour « plan »,
« décomposition », « suivi des progrès », « en plusieurs étapes » ou tâches complexes. NE PAS
utiliser pour des recherches simples, des modifications de fichiers uniques ou des questions auxquelles il est possible de répondre dans
une réponse.
