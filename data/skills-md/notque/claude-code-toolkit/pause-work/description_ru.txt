Создайте артефакты передачи обслуживания сеанса (HANDOFF.json + .continue-here.md), которые фиксируют
завершенная работа, оставшиеся задачи, решения, незафиксированные файлы и контекст рассуждений
поэтому следующий сеанс может возобновиться без затрат на реконструкцию. Используйте для «паузы»,
«сохранить прогресс», «переключиться», «остановиться на данный момент», «завершить сеанс», «забрать это позже».
НЕ используйте для планирования задач (используйте Task_plan.md), сводок сеансов (используйте /retro),
или фиксация работы (используйте /commit или git напрямую).
