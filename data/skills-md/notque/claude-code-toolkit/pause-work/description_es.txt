Cree artefactos de transferencia de sesión (HANDOFF.json + .continue-here.md) que capturen
Trabajo completado, tareas restantes, decisiones, archivos no comprometidos y contexto de razonamiento.
para que la siguiente sesión pueda reanudarse sin gastos generales de reconstrucción. Úselo para "pausa",
"guardar progreso", "traspaso", "detener por ahora", "finalizar sesión", "retomar esto más tarde".
NO lo use para planificación de tareas (use task_plan.md), resúmenes de sesiones (use /retro),
o comprometer trabajo (use /commit o git directamente).
