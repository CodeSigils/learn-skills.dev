キャプチャするセッション ハンドオフ アーティファクト (HANDOFF.json + . continue-here.md) を作成します。
完了した作業、残りのタスク、決定事項、コミットされていないファイル、および推論コンテキスト
そのため、再構築のオーバーヘッドなしで次のセッションを再開できます。 「一時停止」に使用します。
「進行状況を保存する」、「ハンドオフ」、「今は停止する」、「セッションを終了する」、「後でこれを取得する」。
タスクの計画 (task_plan.md を使用)、セッションの概要 (/retro を使用) には使用しないでください。
または作業をコミットします (/commit または git を直接使用します)。
