Crea artefatti di trasferimento della sessione (HANDOFF.json + .continue-here.md) che catturano
lavoro completato, attività rimanenti, decisioni, file non impegnati e contesto di ragionamento
in modo che la sessione successiva possa riprendere senza spese di ricostruzione. Utilizzare per "pausa",
"salva progressi", "handoff", "stop per ora", "termina sessione", "riprendi più tardi".
NON utilizzare per la pianificazione delle attività (utilizzare task_plan.md), riepiloghi delle sessioni (utilizzare /retro),
o impegnarsi in un lavoro (utilizzare /commit o git direttamente).
