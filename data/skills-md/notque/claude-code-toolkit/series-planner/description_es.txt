Planifique series de contenido de varias partes con estructura, enlaces cruzados y publicación.
cadencia. Úselo cuando el usuario necesite planificar una serie de publicaciones de blog, estructurar una serie de varias partes
tutorial o diseñar contenido con navegación con enlaces cruzados. Usar para "serie de planes",
"serie sobre [tema]", "blog de varias partes" o "serie de contenido". NO utilizar para
escribir publicaciones individuales, resúmenes de artículos individuales o planificar un calendario de contenidos
sin estructura en serie.
