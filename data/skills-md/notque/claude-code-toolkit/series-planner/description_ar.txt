قم بتخطيط سلسلة محتوى متعددة الأجزاء مع الهيكل والربط المتبادل والنشر
إيقاع. يُستخدم عندما يحتاج المستخدم إلى التخطيط لسلسلة منشورات المدونة، أو هيكلة أجزاء متعددة
برنامج تعليمي، أو محتوى تصميمي باستخدام التنقل المتشابك. استخدم لـ "سلسلة الخطط"،
"سلسلة حول [موضوع]" أو "مدونة متعددة الأجزاء" أو "سلسلة محتوى". لا تستخدم ل
كتابة منشورات فردية، أو مخططات تفصيلية لمقال واحد، أو تخطيط تقويم المحتوى
بدون هيكل سلسلة.
