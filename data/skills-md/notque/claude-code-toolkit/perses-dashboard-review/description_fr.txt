Examinez la qualité des tableaux de bord Perses existants : récupération via MCP ou API, panneau d'analyse
disposition, efficacité des requêtes, utilisation des variables, configuration de la source de données. Générer
rapport d'amélioration. Mode --fix facultatif. Pipeline en 4 phases : FETCH, ANALYZE, REPORT, FIX.
À utiliser pour « examen du tableau de bord personnel », « tableau de bord d'audit », « qualité du tableau de bord personnel ».
Ne PAS utiliser pour créer de nouveaux tableaux de bord (utilisez perses-dashboard-create).
