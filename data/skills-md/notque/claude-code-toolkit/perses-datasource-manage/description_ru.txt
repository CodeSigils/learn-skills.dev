Управление жизненным циклом источников данных Perses: создание, обновление и удаление источников данных
глобальная область, область проекта или панель мониторинга. Поддерживает Прометея, Темпо, Локи, Пироскоп,
ClickHouse и VictoriaLogs. Использует инструменты MCP, если они доступны, и Percli CLI в качестве запасного варианта.
Используйте для «источника данных pers», «добавить источник данных», «настроить prometheus perses»,
«персный источник данных». НЕ используйте для создания информационной панели (используйте perses-dashboard-create).
