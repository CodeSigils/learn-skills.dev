Esplorazione sistematica della base di codice in 4 fasi: rilevamento, esplorazione, mappatura, riepilogo.
Da utilizzare quando si inizia a lavorare su una base di codice sconosciuta, durante l'onboarding in un nuovo progetto,
rivedere un repository per la prima volta o creare un contesto prima del debug
o revisione del codice. Utilizzare per "esplora codebase", "cosa fa questo progetto",
"capire l'architettura" o "onboard me". NON utilizzare per modificare file,
esecuzione di applicazioni, ottimizzazione delle prestazioni o analisi approfondita del dominio.
