Exploration systématique de la base de code en 4 phases : détecter, explorer, cartographier, résumer.
À utiliser lorsque vous commencez à travailler sur une base de code inconnue, lors de l'intégration dans un nouveau projet,
examiner un référentiel pour la première fois ou créer un contexte avant le débogage
ou révision du code. Utiliser pour "explorer la base de code", "que fait ce projet",
« comprendre l'architecture » ou « m'embarquer ». Ne PAS utiliser pour modifier des fichiers,
exécution d'applications, optimisation des performances ou analyse approfondie du domaine.
