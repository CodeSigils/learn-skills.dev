الاستكشاف المنهجي لقاعدة التعليمات البرمجية على أربع مراحل: الكشف والاستكشاف والخريطة والتلخيص.
يُستخدم عند بدء العمل على قاعدة تعليمات برمجية غير مألوفة، أو الإعداد لمشروع جديد،
مراجعة المستودع لأول مرة، أو بناء السياق قبل تصحيح الأخطاء
أو مراجعة الكود استخدم لـ "استكشاف قاعدة التعليمات البرمجية"، "ماذا يفعل هذا المشروع"،
"أفهم الهندسة المعمارية" أو "على متني". لا تستخدم لتعديل الملفات،
تشغيل التطبيقات أو تحسين الأداء أو التحليل العميق للمجال.
