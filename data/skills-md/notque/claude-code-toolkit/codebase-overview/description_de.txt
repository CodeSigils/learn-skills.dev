Systematische 4-Phasen-Codebasis-Erkundung: Erkennen, Erkunden, Kartieren, Zusammenfassen.
Verwenden Sie es, wenn Sie mit der Arbeit an einer unbekannten Codebasis beginnen, in ein neues Projekt einsteigen,
Überprüfen Sie ein Repository zum ersten Mal oder erstellen Sie einen Kontext vor dem Debuggen
oder Codeüberprüfung. Verwenden Sie diese Option für „Codebasis erkunden“, „Was macht dieses Projekt?“
„Architektur verstehen“ oder „Onboard me“. NICHT zum Ändern von Dateien verwenden,
Ausführen von Anwendungen, Leistungsoptimierung oder umfassende Domänenanalyse.
