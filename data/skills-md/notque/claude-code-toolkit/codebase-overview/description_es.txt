Exploración sistemática de la base de código de 4 fases: detectar, explorar, mapear, resumir.
Úselo al comenzar a trabajar en una base de código desconocida, al incorporarse a un nuevo proyecto,
revisar un repositorio por primera vez o crear contexto antes de depurarlo
o revisión de código. Úselo para "explorar la base del código", "qué hace este proyecto",
"comprender la arquitectura" o "incorporarme". NO lo use para modificar archivos,
ejecución de aplicaciones, optimización del rendimiento o análisis profundo de dominio.
