Выполнение новых субагентов для каждой задачи с двухэтапной проверкой (соответствие ADR +
качество кода). Используйте, когда существует план реализации, в основном независимый.
задачи, и вам нужны качественные ворота между ними. Используйте для «выполнить план»,
«субагент», «диспетчерские задачи» или многозадачная реализация. НЕ используйте
для отдельных простых задач, тесно связанных работ, требующих общего контекста, или когда
пользователь хочет вручную просмотреть каждую задачу.
