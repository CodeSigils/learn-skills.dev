تنفيذ وكيل فرعي جديد لكل مهمة من خلال مراجعة على مرحلتين (الامتثال لـ ADR +
جودة الكود). يُستخدم عند وجود خطة تنفيذ مستقلة في الغالب
المهام وتريد بوابات الجودة بين كل منهما. استخدم لـ "تنفيذ الخطة"،
يتم تشغيل "الوكيل الفرعي" أو "مهام الإرسال" أو تنفيذ المهام المتعددة. لا تستخدم
لمهام بسيطة واحدة، أو عمل مقترن بإحكام يحتاج إلى سياق مشترك، أو متى
يريد المستخدم مراجعة يدوية بعد كل مهمة.
