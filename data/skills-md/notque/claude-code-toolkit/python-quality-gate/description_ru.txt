Запустите проверку качества Python с помощью ruff, pytest, mypy иbandit в
детерминированный порядок. Используйте КОГДА пользователь запрашивает «контроль качества», «ворс»,
«проверить качество кода», «проверить Python» или «проверить перед фиксацией». Используйте для
проверка перед слиянием, шлюзование CI/CD или комплексное качество кода
отчеты. НЕ используйте для запуска одного инструмента (запускайте инструмент напрямую), отладки
ошибки времени выполнения (используйте систематическую отладку), рефакторинг (используйте
систематический рефакторинг) или обзор архитектуры.
