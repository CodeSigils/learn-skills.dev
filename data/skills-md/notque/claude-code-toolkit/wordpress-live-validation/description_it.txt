Convalida un post WordPress pubblicato o in anteprima in bozza in un browser reale utilizzando
Drammaturgo. Controlla il titolo visualizzato, la struttura dell'intestazione, il caricamento dell'immagine, OG/meta
tag, errori JavaScript e layout reattivo su dispositivi mobili/tablet/desktop
punti di interruzione. Quando Chrome DevTools MCP è disponibile, puoi utilizzarlo per il browser live
ispezione come alternativa al drammaturgo. Utilizzare per "convalidare post WordPress",
"controlla il post pubblicato", "verifica il post pubblicato", "il post di WordPress sembra corretto",
"controlla i tag og" o "controlla WordPress reattivo". NON utilizzare per la fonte
convalida del ribasso (usa il controllo pre-pubblicazione), analisi delle parole chiave SEO
(usa seo-optimizer) o caricando contenuti (usa wordpress-uploader).
