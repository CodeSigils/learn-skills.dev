Validez une publication WordPress publiée ou en avant-première dans un vrai navigateur en utilisant
Dramaturge. Vérifie le titre rendu, la structure des titres, le chargement de l'image, OG/méta
balises, erreurs JavaScript et mise en page réactive sur mobile/tablette/ordinateur de bureau
points d'arrêt. Lorsque Chrome DevTools MCP est disponible, vous pouvez l'utiliser pour le navigateur en direct
inspection comme alternative à Playwright. Utiliser pour "valider la publication wordpress",
"vérifier la publication en direct", "vérifier la publication publiée", "la publication WordPress semble correcte",
"vérifier les balises og" ou "vérifier réactif wordpress". Ne PAS utiliser comme source
validation des démarques (utiliser le vérificateur de pré-publication), analyse des mots clés SEO
(utilisez seo-optimizer) ou téléchargez du contenu (utilisez wordpress-uploader).
