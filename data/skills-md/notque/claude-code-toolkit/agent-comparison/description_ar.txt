عبر معايير بسيطة ومعقدة. استخدم عند إنشاء وكيل مدمج
الإصدارات، والتحقق من صحة تغييرات الوكيل، ومقارنة العوامل الداخلية والخارجية،
أو الاختيار بين المتغيرات للإنتاج. استخدم لـ "مقارنة الوكلاء"،
"اختبار A/B" أو "الوكلاء المرجعيون" أو "اختبار كفاءة الوكيل". لا تستخدم
لتقييم الوكلاء المنفردين، أو اختبار المهارات، أو تحسين المطالبات
دون مقارنة البديل.
