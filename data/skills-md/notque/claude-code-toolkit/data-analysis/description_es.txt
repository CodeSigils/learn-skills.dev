Análisis de datos de primera decisión con puertas de rigor estadístico. Usar cuando
analizar CSV, JSON, exportaciones de bases de datos, respuestas API, registros o cualquier
datos estructurados para respaldar una decisión comercial. Mangos: análisis de tendencias,
comparación de cohortes, evaluación de pruebas A/B, perfiles de distribución, anomalías
detección. NO lo use para análisis de base de código (use el analizador de base de código),
exploración de base de código (use explore-pipeline) o entrenamiento de modelos de ML.
