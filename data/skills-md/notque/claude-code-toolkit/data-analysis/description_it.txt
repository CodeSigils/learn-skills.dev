Analisi dei dati decision-first con cancelli di rigore statistico. Utilizzare quando
analizzando CSV, JSON, esportazioni di database, risposte API, log o altro
dati strutturati per supportare una decisione aziendale. Maniglie: analisi dei trend,
confronto di coorte, valutazione del test A/B, profilazione della distribuzione, anomalia
rilevamento. NON utilizzare per l'analisi della codebase (utilizzare codebase-analyzer),
esplorazione della base di codice (usa explore-pipeline) o addestramento del modello ML.
