Analyse des données axée sur la décision avec des portes de rigueur statistique. Utiliser quand
analyser CSV, JSON, les exportations de bases de données, les réponses API, les journaux ou tout autre
données structurées pour soutenir une décision commerciale. Poignées : analyse des tendances,
comparaison de cohortes, évaluation de tests A/B, profilage de distribution, anomalie
détection. Ne PAS utiliser pour l'analyse de la base de code (utilisez codebase-analyzer),
Exploration de la base de code (utilisez explore-pipeline) ou formation de modèle ML.
