Анализ данных, ориентированный на принятие решения, со статистическими строгостями. Используйте, когда
анализ CSV, JSON, экспорта базы данных, ответов API, журналов или любых других
структурированные данные для поддержки бизнес-решений. Ручки: анализ тенденций,
когортное сравнение, оценка A/B-теста, профилирование распределения, аномалия
обнаружение. НЕ используйте для анализа кодовой базы (используйте анализатор кодовой базы),
исследование базы кода (используйте explore-pipeline) или обучение модели машинного обучения.
