Bucle de aplicación de crítica y reescritura para la fidelidad de la voz. Validaciones generadas
compara el contenido con listas de verificación negativas y obliga a revisarlo hasta que se apruebe.
Úselo cuando el contenido se haya generado en una voz objetivo, la salida de voz se sienta apagada,
El contenido de formato largo corre el riesgo de que la voz se desvíe o antes de la entrega final del contenido de voz.
Úselo para "validar voz", "verificar voz", "la voz se siente mal", "derivación de la voz",
o "reescribir para voz". NO lo use para generación de voz inicial, perfil de voz
creación o contenido que no tiene destino de voz.
