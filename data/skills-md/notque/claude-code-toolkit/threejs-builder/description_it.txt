Generatore di app Three.js in 4 fasi basato su grafici di scena: progettazione, creazione, animazione,
Polacco. Utilizzare quando l'utente desidera un'app Web 3D, una scena interattiva, WebGL
visualizzazione o visualizzatore di prodotti. Utilizzare per "creare una scena threejs",
"crea un'app Web 3D", "crea un'animazione 3D" o "vetrina 3D interattiva".
NON utilizzare per motori di gioco completi, creazione di modelli 3D, esperienze VR/AR,
o flussi di lavoro CAD.
