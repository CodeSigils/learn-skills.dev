قم بإنشاء مخططات هيكلية لمشاركات المدونة قبل الكتابة. يحلل الموضوع
ملخصات، واختيار قوالب الهيكل، وإنشاء الخطوط العريضة مع عدد الكلمات و
ملخصات القسم. يُستخدم عند التخطيط لمقالة جديدة، وبنية العصف الذهني،
أو تحديد النطاق قبل الصياغة. استخدم لـ "المخطط التفصيلي"، "خطة النشر"،
"هيكلة هذا الموضوع"، "كيف يجب أن أنظم". لا تستخدم للكتابة
محتوى المنشور الفعلي، أو تحرير المنشورات الموجودة، أو تخطيط الكلمات الرئيسية لتحسين محركات البحث.
