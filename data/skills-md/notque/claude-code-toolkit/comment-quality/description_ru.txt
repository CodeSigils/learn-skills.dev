Просмотр и исправление комментариев, содержащих временные ссылки, действия по разработке
язык или относительные сравнения. Используйте при просмотре комментариев к коду, подготовке
документацию для выпуска или проверку встроенных комментариев на предмет вневременности. Использование
для «проверить комментарии», «временного языка», «просмотра комментариев» или «исправить документы».
НЕ используйте для написания новой документации, создания ссылок на API или
Линтинг стиля кода не связан с содержимым комментариев.
