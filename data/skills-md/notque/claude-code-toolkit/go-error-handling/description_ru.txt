Шаблоны обработки ошибок Go: перенос с учетом контекста, контрольные ошибки, пользовательские
типы ошибок, цепочки error.Is/As и сопоставление ошибок HTTP. Используйте, когда
реализация возвратов ошибок, определение ошибок на уровне пакета, создание пользовательских
типы ошибок, упаковка ошибок с помощью fmt.Errorf или проверка ошибок с помощью
ошибки.Есть/Как. Используйте для «обработки ошибок», «fmt.Errorf», «errors.Is»,
«errors.As», «дозорная ошибка», «пользовательская ошибка» или «%w». НЕ используйте для
общая разработка на Go, отладка паники во время выполнения или стратегия ведения журналов.
