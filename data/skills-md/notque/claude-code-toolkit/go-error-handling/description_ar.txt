انتقل إلى أنماط معالجة الأخطاء: الالتفاف مع السياق، وأخطاء الحارس، والعرف
أنواع الأخطاء، وسلاسل الأخطاء.Is/As، وتعيين أخطاء HTTP. استخدم متى
تنفيذ إرجاع الأخطاء، وتحديد الأخطاء على مستوى الحزمة، وإنشاء مخصصات
أنواع الأخطاء أو التفاف الأخطاء باستخدام fmt.Errorf أو التحقق من الأخطاء باستخدام
الأخطاء.هي/كما. يُستخدم لـ "معالجة الأخطاء"، و"fmt.Errorf"، و"errors.Is"،
"errors.As" أو "خطأ خافر" أو "خطأ مخصص" أو "%w". لا تستخدم ل
تطوير Go العام أو تصحيح الذعر في وقت التشغيل أو استراتيجية التسجيل.
