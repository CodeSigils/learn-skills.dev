Création guidée du tableau de bord Perses : collecte des exigences (métriques, source de données, mise en page),
générer une définition CUE ou une spécification JSON, valider avec percli lint, déployer avec percli
apply ou MCP perses_create_dashboard. À utiliser lorsque l'utilisateur souhaite créer un nouveau Perses
tableau de bord, créez un tableau de bord de surveillance ou générez des définitions de tableau de bord. Utiliser pour
"créer un tableau de bord personnel", "un nouveau tableau de bord", "un nouveau tableau de bord permanent", "construire un tableau de bord".
Ne PAS utiliser pour la migration Grafana (utilisez perses-grafana-migrate) ou le développement de plugins
(utilisez perses-plugin-create).
