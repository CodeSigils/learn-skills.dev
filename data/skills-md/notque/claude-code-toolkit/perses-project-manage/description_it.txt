Perses gestione del ciclo di vita del progetto: crea, elenca, cambia e configura progetti.
Gestisci RBAC con ruoli e associazioni di ruolo per progetto. Utilizza gli strumenti MCP quando disponibili,
percli CLI come fallback. Utilizzare per "perses project", "crea progetto", "perses rbac",
"perse i ruoli", "perse i permessi". NON utilizzare per la creazione di dashboard
(usa perses-dashboard-create).
