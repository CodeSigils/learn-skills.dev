Perses Projektlebenszyklusmanagement: Projekte erstellen, auflisten, wechseln und konfigurieren.
Verwalten Sie RBAC mit Rollen und Rollenbindungen pro Projekt. Verwendet MCP-Tools, sofern verfügbar,
percli CLI als Fallback. Verwendung für „perses project“, „create project“, „perses rbac“,
„perses-Rollen“, „perses-Berechtigungen“. NICHT zur Dashboard-Erstellung verwenden
(verwenden Sie perses-dashboard-create).
