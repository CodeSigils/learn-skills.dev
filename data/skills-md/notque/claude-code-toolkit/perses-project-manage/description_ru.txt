Управление жизненным циклом проектов Perses: создание, составление списка, переключение и настройка проектов.
Управляйте RBAC с помощью ролей и привязок ролей для каждого проекта. Использует инструменты MCP, когда они доступны,
Percli CLI в качестве запасного варианта. Используйте для «персес-проект», «создать проект», «персес-рбак»,
«персональные роли», «персональные разрешения». НЕ используйте для создания информационной панели
(используйте perses-dashboard-create).
