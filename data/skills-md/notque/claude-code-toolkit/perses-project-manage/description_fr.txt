Perses gestion du cycle de vie des projets : créer, répertorier, changer et configurer des projets.
Gérez RBAC avec des rôles et des liaisons de rôles par projet. Utilise les outils MCP lorsqu'ils sont disponibles,
percli CLI comme solution de secours. Utiliser pour "perses project", "create project", "perses rbac",
"persère les rôles", "perse les autorisations". Ne PAS utiliser pour la création de tableaux de bord
(utilisez perses-dashboard-create).
