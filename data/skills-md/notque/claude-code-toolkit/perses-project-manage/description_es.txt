Gestión del ciclo de vida del proyecto Perses: crear, enumerar, cambiar y configurar proyectos.
Administre RBAC con roles y enlaces de roles por proyecto. Utiliza herramientas MCP cuando están disponibles,
percli CLI como alternativa. Úselo para "proyecto perses", "crear proyecto", "perses rbac",
"perses roles", "perses permisos". NO lo use para la creación de paneles
(use perses-dashboard-create).
