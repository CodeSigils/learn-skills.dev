Validieren Sie Perses-Ressourcen: Führen Sie Percli Lint lokal oder mit --online auf einem Server aus.
Überprüfen Sie Dashboard-Definitionen, Datenquellenkonfigurationen und Variablenschemata. Fehler melden mit
umsetzbare Korrekturen. Verwendung für „Perses Lint“, „Validate Perses“, „Check Dashboard“,
„perses validieren“. NICHT zum Testen des Plugin-Schemas verwenden (perses-plugin-test verwenden).
