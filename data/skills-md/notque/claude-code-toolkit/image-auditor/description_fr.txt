Validation d'image non destructive en 4 phases : découvrir, valider, analyser,
Rapport. À utiliser lors de l'audit des images Web pour l'accessibilité, les références rompues,
fichiers surdimensionnés ou incohérences de format. Utiliser pour "audit d'image", "vérifier alt
texte", "trouver les images cassées", "optimiser les images" ou "poids de la page". NE PAS
utiliser pour la création d'images, l'édition de pixels, la configuration CDN ou l'automatisation
conversion d'image sans le consentement explicite de l'utilisateur.
