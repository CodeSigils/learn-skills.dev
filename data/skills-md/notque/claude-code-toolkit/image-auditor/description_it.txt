Convalida non distruttiva delle immagini in 4 fasi: scoperta, convalida, analisi,
Rapporto. Da utilizzare durante il controllo delle immagini Web per verificarne l'accessibilità, i riferimenti interrotti,
file di grandi dimensioni o formati non corrispondenti. Utilizzare per "verifica immagine", "seleziona alt
testo", "trova immagini interrotte", "ottimizza immagini" o "peso pagina". NON farlo
utilizzare per la creazione di immagini, la modifica di pixel, la configurazione CDN o automatizzata
conversione di immagini senza il consenso esplicito dell'utente.
