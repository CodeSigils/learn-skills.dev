Requirement Detective: used when a user presents vague, one‑sentence, scenario‑based, or business‑process type requirements. It applies to scenarios such as “new requirement, make a request, help design, tweak/optimize, implement a feature, user feedback, can it be done, want one, process, report, function, module,” and so on. By employing scenario reverse narration, A/B multiple‑choice questions, and decision logs, it converts vague requirements into a clear, agreed‑upon solution and outputs a tiered development task list.
