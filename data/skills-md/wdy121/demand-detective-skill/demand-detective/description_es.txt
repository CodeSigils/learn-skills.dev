Detective de requisitos: se utiliza cuando un usuario presenta requisitos vagos, de una sola frase, basados ​​en escenarios o de tipo proceso empresarial. Se aplica a escenarios como “nuevo requisito, realizar una solicitud, ayudar a diseñar, modificar/optimizar, implementar una característica, comentarios de los usuarios, se puede hacer, quiero uno, proceso, informe, función, módulo”, etc. Al emplear narración inversa de escenarios, preguntas de opción múltiple A/B y registros de decisiones, convierte requisitos vagos en una solución clara y acordada y genera una lista de tareas de desarrollo escalonada.
