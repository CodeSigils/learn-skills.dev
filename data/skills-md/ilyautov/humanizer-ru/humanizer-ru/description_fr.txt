Compétence pour humaniser le texte en langue russe. Supprime les signes de génération d'IA, rend le texte vivant. Utilisez-le TOUJOURS lorsque l'utilisateur demande : humaniser le texte, supprimer les traces du réseau neuronal, rendre le texte vivant/naturel, réécrire comme une personne, humaniser en russe, supprimer le style bureaucratique, éliminer la verbosité, rendre le texte moins formel. Utilisez-le également si l'utilisateur insère du texte russe et dit quelque chose comme « réécrire », « améliorer », « cela ressemble à un robot », « trop artificiel ». Fonctionne UNIQUEMENT avec la langue russe. Pour l'anglais, utilisez l'humaniseur original. NE PAS utiliser pour : la traduction, l’écriture à partir de zéro, la grammaire, le code. Veuillez toujours répondre dans la langue de l'utilisateur.
