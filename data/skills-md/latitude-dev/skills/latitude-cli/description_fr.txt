Installez, authentifiez et pilotez la CLI Latitude (le binaire « latitude ») pour exécuter les opérations de l'API Latitude à partir d'un terminal : projets, traces, analyses, ensembles de données, etc. À utiliser pour l'outil de ligne de commande « latitude », pour installer le binaire CLI, l'authentification CLI avec une clé API ou pour créer un script pour l'API Latitude à partir d'un agent ou d'un shell.
