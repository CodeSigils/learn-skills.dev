Instale, autentique y controle Latitude CLI (el binario `latitude`) para ejecutar operaciones de Latitude API desde una terminal: proyectos, seguimientos, análisis, conjuntos de datos y más. Úselo para la herramienta de línea de comandos `latitude`, instalando el binario CLI, autenticación CLI con una clave API o creando scripts para la API Latitude desde un agente o shell.
