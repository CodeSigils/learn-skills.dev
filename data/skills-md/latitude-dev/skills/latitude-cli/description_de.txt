Installieren, authentifizieren und steuern Sie die Latitude CLI (die „Latitude“-Binärdatei), um Latitude API-Vorgänge von einem Terminal aus auszuführen – Projekte, Ablaufverfolgungen, Analysen, Datensätze und mehr. Verwenden Sie es für das Befehlszeilentool „Latitude“, die Installation der CLI-Binärdatei, die CLI-Authentifizierung mit einem API-Schlüssel oder die Skripterstellung für die Latitude-API über einen Agenten oder eine Shell.
