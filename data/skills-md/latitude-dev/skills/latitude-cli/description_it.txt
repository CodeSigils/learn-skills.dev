Installa, autentica e gestisci la CLI Latitude (il file binario `latitude`) per eseguire operazioni API Latitude da un terminale: progetti, tracce, analisi, set di dati e altro ancora. Da utilizzare per lo strumento da riga di comando "latitude", per l'installazione del file binario CLI, per l'autenticazione CLI con una chiave API o per lo scripting dell'API Latitude da un agente o shell.
