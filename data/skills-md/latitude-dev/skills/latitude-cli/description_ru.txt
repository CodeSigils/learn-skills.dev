Установите, аутентифицируйте и используйте Latitude CLI (двоичный файл latitude) для запуска операций API Latitude с терминала — проектов, трассировок, аналитики, наборов данных и многого другого. Используйте для инструмента командной строки `latitude`, устанавливая двоичный файл CLI, аутентификацию CLI с помощью ключа API или создание сценария API Latitude из агента или оболочки.
