قم بتثبيت Latitude CLI (الثنائي `latitude`) وتصديقه وتشغيله لتشغيل عمليات Latitude API من محطة طرفية — المشاريع، والتتبعات، والتحليلات، ومجموعات البيانات، والمزيد. استخدم أداة سطر الأوامر `latitude`، أو تثبيت ثنائي واجهة سطر الأوامر (CLI)، أو مصادقة واجهة سطر الأوامر (CLI) باستخدام مفتاح API، أو برمجة واجهة برمجة تطبيقات Latitude من وكيل أو shell.
