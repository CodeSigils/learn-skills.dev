Orchestratore di onboarding senza account per Latitude. Avvia un account Latitude temporaneo dal terminale (nessuna registrazione), utilizza l'app per il tracciamento, verifica le tracce reali, ripulisci e restituisci un collegamento al browser per rivendicarne la proprietà. Da utilizzare quando qualcuno vuole configurare Latitude da zero senza un account o una chiave API esistente: il flusso "provalo con il tuo agente" sulla pagina di destinazione. Se risulta che l'utente dispone già di un account, di una chiave API o di un MCP Latitude connesso, questa competenza reindirizza a latitude-telemetry + latitude-cli invece di creare un account temporaneo.
