Latitude용 제로 계정 온보딩 조정자입니다. 터미널에서 임시 Latitude 계정을 부트스트랩하고(등록 없음), 추적을 위해 앱을 계측하고, 실제 추적을 확인하고, 정리하고, 브라우저 링크를 돌려 소유권을 주장합니다. 기존 계정이나 API 키 없이 Latitude를 처음부터 설정하려는 경우 랜딩 페이지의 "에이전트와 함께 사용해 보기" 흐름을 사용하세요. 사용자에게 이미 계정, API 키 또는 연결된 Latitude MCP가 있는 것으로 밝혀지면 이 기술은 임시 계정을 만드는 대신 latitude-telemetry + latitude-cli로 리디렉션됩니다.
