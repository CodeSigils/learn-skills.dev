Orquestador de incorporación de cuenta cero para Latitude. Inicie una cuenta temporal de Latitude desde la terminal (sin registro), instrumente la aplicación para el rastreo, verifique los rastreos reales, limpie y devuelva un enlace del navegador para reclamar la propiedad. Úselo cuando alguien quiera configurar Latitude desde cero sin una cuenta existente o una clave API: el flujo de la página de inicio "pruébelo con su agente". Si resulta que el usuario ya tiene una cuenta, una clave API o un Latitude MCP conectado, esta habilidad redirige a latitude-telemetry + latitude-cli en lugar de crear una cuenta temporal.
