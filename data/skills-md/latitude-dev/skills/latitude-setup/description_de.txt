Onboarding-Orchestrator ohne Konto für Latitude. Erstellen Sie vom Terminal aus ein temporäres Latitude-Konto (keine Anmeldung), instrumentieren Sie die App für die Nachverfolgung, überprüfen Sie echte Spuren, bereinigen Sie sie und geben Sie einen Browser-Link zurück, um die Eigentümerschaft zu beanspruchen. Verwenden Sie den Landingpage-Ablauf „Probieren Sie es mit Ihrem Agenten aus“, wenn jemand Latitude von Grund auf ohne vorhandenes Konto oder API-Schlüssel einrichten möchte. Wenn sich herausstellt, dass der Benutzer bereits über ein Konto, einen API-Schlüssel oder einen verbundenen Latitude MCP verfügt, leitet dieser Skill zu Latitude-Telemetry + Latitude-Cli weiter, anstatt ein temporäres Konto zu erstellen.
