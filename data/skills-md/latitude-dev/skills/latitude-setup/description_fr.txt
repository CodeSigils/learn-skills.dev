Orchestrateur d'intégration de compte zéro pour Latitude. Démarrez un compte Latitude temporaire à partir du terminal (pas d'inscription), instrumentez l'application pour le traçage, vérifiez les traces réelles, nettoyez et restituez un lien de navigateur pour en revendiquer la propriété. À utiliser lorsque quelqu'un souhaite configurer Latitude à partir de zéro sans compte ni clé API existants : le flux de la page de destination "Essayez-le avec votre agent". S'il s'avère que l'utilisateur dispose déjà d'un compte, d'une clé API ou d'un Latitude MCP connecté, cette compétence redirige vers latitude-telemetry + latitude-cli au lieu de créer un compte temporaire.
