Latitude のゼロアカウント オンボーディング オーケストレーター。ターミナルから一時的な Latitude アカウントをブートストラップし (サインアップなし)、アプリをトレース用に計測し、実際のトレースを検証し、クリーンアップして、所有権を主張するためにブラウザーのリンクを返します。既存のアカウントや API キーを使用せずに Latitude を最初からセットアップする場合、つまりランディング ページの「エージェントと一緒に試してみる」フローを使用する場合に使用します。ユーザーがすでにアカウント、API キー、または接続された Latitude MCP を持っていることが判明した場合、このスキルは一時的なアカウントを作成する代わりに latitude-telemetry + latitude-cli にリダイレクトします。
