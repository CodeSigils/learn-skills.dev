Оркестратор адаптации без учетной записи для Latitude. Загрузите временную учетную запись Latitude с терминала (без регистрации), настройте приложение для отслеживания, проверьте реальные следы, очистите и верните ссылку браузера, чтобы заявить права владения. Используйте, когда кто-то хочет настроить Latitude с нуля, не имея существующей учетной записи или ключа API — процедура на целевой странице «попробуйте это с вашим агентом». Если окажется, что у пользователя уже есть учетная запись, ключ API или подключенный Latitude MCP, этот навык перенаправляет на latitude-telemetry + latitude-cli вместо создания временной учетной записи.
