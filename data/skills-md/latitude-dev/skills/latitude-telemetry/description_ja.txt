Latitude LLM 可観測性のインストールまたは監査 — LLM SDK (OpenAI、Anthropic、Bedrock、Cohere、TogetterAI、Vertex AI、Google AI Platform、OpenAI Agents、Vercel AI SDK、Mastra、LangChain、LlamaIndex) から Latitude プロジェクトにトレースを送信します。 `@latitude-data/telemetry` 経由の TypeScript、`latitude-telemetry` 経由の Python、および直接 OTLP HTTP 経由のその他の OpenTelemetry サポート言語 (Go、Java、Ruby、.NET、PHP、Rust、Elixir など)。ユーザーが Latitude トレースの追加、既存の OpenTelemetry セットアップへの Latitude の接続、Latitude で欠落しているトレースの修正、または既存の統合の監査を要求する場合に使用します。コードベースの検出 (既存の OTel、競合する LLM 可観測性ベンダー、どの LLM SDK が使用されているか、LLM 呼び出しが行われる場所)、クラスベースのブートストラップ (TS の `new Latitude({...})`、Python の `Latitude(...)`)、`LatitudeSpanProcessor` および `registerLatitudeInstrumentations` による高度なセットアップ、オプションの `capture()` をカバーします。 user/session/tags コンテキスト (およびマルチプロジェクト アプリの場合はキャプチャごとの `projectSlug`)、環境変数 (`LATITUDE_API_KEY`、`LATITUDE_PROJECT_SLUG`)、および非 TS/Python コードベースの OTLP フォールバック パス。
