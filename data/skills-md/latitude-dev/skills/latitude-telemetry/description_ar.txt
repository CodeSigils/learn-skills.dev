تثبيت أو تدقيق قابلية مراقبة Latitude LLM - إرسال آثار من LLM SDK (OpenAI، Anthropic، Bedrock، Cohere، TogetherAI، Vertex AI، Google AI Platform، OpenAI Agents، Vercel AI SDK، Mastra، LangChain، LlamaIndex) إلى مشروع Latitude. TypeScript عبر `@latitude-data/telemetry`، وPython عبر `latitude-telemetry`، وأي لغة أخرى تدعم OpenTelemetry (Go، Java، Ruby، .NET، PHP، Rust، Elixir، ...) عبر OTLP HTTP المباشر. يُستخدم عندما يطلب المستخدم إضافة تتبع Latitude، أو توصيل Latitude إلى إعداد OpenTelemetry موجود، أو إصلاح عمليات التتبع المفقودة في Latitude، أو تدقيق التكامل الحالي. يغطي اكتشاف قاعدة التعليمات البرمجية (OTel الحالي، بائعي إمكانية ملاحظة LLM المتضاربين، وحزم LLM SDK قيد الاستخدام، حيث تحدث استدعاءات LLM)، والتمهيد المستند إلى الفصل (`new Latitude({...})` في TS، و`Latitude(...)` في Python)، والإعداد المتقدم باستخدام `LatitudeSpanProcessor` و`registerLatitudeInstrumentations`، و`capture()` الاختياري لسياق المستخدم/الجلسة/العلامات. (و"projectSlug" لكل لقطة للتطبيقات متعددة المشاريع)، وenv vars (`LATITUDE_API_KEY`، و`LATITUDE_PROJECT_SLUG`)، ومسار احتياطي OTLP لقواعد التعليمات البرمجية غير TS/Python.
