Latitude LLM 관측 가능성 설치 또는 감사 - LLM SDK(OpenAI, Anthropic, Bedrock, Cohere, TogetherAI, Vertex AI, Google AI Platform, OpenAI Agents, Vercel AI SDK, Mastra, LangChain, LlamaIndex)의 추적을 Latitude 프로젝트로 보냅니다. `@latitude-data/telemetry`를 통한 TypeScript, `latitude-telemetry`를 통한 Python 및 직접 OTLP HTTP를 통한 기타 OpenTelemetry 지원 언어(Go, Java, Ruby, .NET, PHP, Rust, Elixir 등). 사용자가 Latitude 추적 추가, Latitude를 기존 OpenTelemetry 설정에 연결, Latitude에서 누락된 추적 수정 또는 기존 통합 감사를 요청할 때 사용합니다. 코드 베이스 검색(기존 OTel, LLM SDK가 사용 중이고 LLM 호출이 발생하는 충돌하는 LLM 관찰 벤더), 클래스 기반 부트스트랩(TS의 `new Latitude({...})`, Python의 `Latitude(...)`), `LatitudeSpanProcessor` 및 `registerLatitudeInstrumentations`를 사용한 고급 설정, 사용자/세션/태그 컨텍스트(및 캡처별 선택 사항 `capture()`를 다룹니다. 다중 프로젝트 앱의 경우 `projectSlug`), env vars(`LATITUDE_API_KEY`, `LATITUDE_PROJECT_SLUG`) 및 비TS/Python 코드베이스의 OTLP 대체 경로입니다.
