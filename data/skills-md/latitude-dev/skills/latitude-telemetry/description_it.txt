Installa o controlla l'osservabilità di Latitude LLM: invia tracce dagli SDK LLM (OpenAI, Anthropic, Bedrock, Cohere, TogetherAI, Vertex AI, Google AI Platform, OpenAI Agents, Vercel AI SDK, Mastra, LangChain, LlamaIndex) a un progetto Latitude. TypeScript tramite `@latitude-data/telemetry`, Python tramite `latitude-telemetry` e qualsiasi altro linguaggio supportato da OpenTelemetry (Go, Java, Ruby, .NET, PHP, Rust, Elixir, ...) tramite OTLP HTTP diretto. Da utilizzare quando l'utente chiede di aggiungere la traccia Latitude, collegare Latitude a una configurazione OpenTelemetry esistente, correggere le tracce mancanti in Latitude o controllare un'integrazione esistente. Copre il rilevamento della base di codice (OTel esistente, fornitori di osservabilità LLM in conflitto, quali SDK LLM sono in uso, dove avvengono le chiamate LLM), bootstrap basato su classi ("new Latitude({...})` in TS, "Latitude(...)` in Python), configurazione avanzata con "LatitudeSpanProcessor" e "registerLatitudeInstrumentations", facoltativo "capture()" per il contesto utente/sessione/tag (e per-capture `projectSlug` per app multiprogetto), env vars (`LATITUDE_API_KEY`, `LATITUDE_PROJECT_SLUG`) e un percorso di fallback OTLP per codebase non TS/Python.
