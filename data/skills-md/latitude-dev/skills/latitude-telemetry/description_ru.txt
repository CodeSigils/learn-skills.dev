Установите или проверьте наблюдаемость Latitude LLM — отправляет трассировки из LLM SDK (OpenAI, Anthropic, Bedrock, Cohere, TogetherAI, Vertex AI, Google AI Platform, агентов OpenAI, Vercel AI SDK, Mastra, LangChain, LlamaIndex) в проект Latitude. TypeScript через @latitude-data/telemetry, Python через latitude-telemetry и любой другой язык, поддерживаемый OpenTelemetry (Go, Java, Ruby, .NET, PHP, Rust, Elixir, …) через прямой HTTP OTLP. Используйте, когда пользователь просит добавить трассировку Latitude, подключить Latitude к существующей настройке OpenTelemetry, исправить недостающие трассировки в Latitude или провести аудит существующей интеграции. Охватывает обнаружение кодовой базы (существующие OTel, конфликтующие поставщики LLM-наблюдения, какие LLM SDK используются, где происходят вызовы LLM), загрузку на основе классов («new Latitude({...})» в TS, Latitude(...)» в Python), расширенную настройку с помощью LatitudeSpanProcessor и RegisterLatitudeInstrumentations, необязательного Capture() для контекста пользователя/сеанса/тегов (и для каждого захвата `projectSlug` для многопроектных приложений), переменные env (`LATITUDE_API_KEY`, `LATITUDE_PROJECT_SLUG`) и резервный путь OTLP для кодовых баз, отличных от TS/Python.
