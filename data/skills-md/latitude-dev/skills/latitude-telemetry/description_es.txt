Instale o audite la observabilidad de Latitude LLM: envía seguimientos desde los SDK de LLM (OpenAI, Anthropic, Bedrock, Cohere, TogetherAI, Vertex AI, Google AI Platform, OpenAI Agents, Vercel AI SDK, Mastra, LangChain, LlamaIndex) a un proyecto de Latitude. TypeScript a través de `@latitude-data/telemetry`, Python a través de `latitude-telemetry` y cualquier otro lenguaje compatible con OpenTelemetry (Go, Java, Ruby, .NET, PHP, Rust, Elixir,…) a través de OTLP HTTP directo. Úselo cuando el usuario solicite agregar seguimiento de Latitude, conectar Latitude a una configuración de OpenTelemetry existente, corregir seguimientos faltantes en Latitude o auditar una integración existente. Cubre el descubrimiento de la base de código (OTel existente, proveedores de observabilidad de LLM en conflicto, qué SDK de LLM están en uso, dónde ocurren las llamadas de LLM), arranque basado en clases (`new Latitude({...})` en TS, `Latitude(...)` en Python), configuración avanzada con `LatitudeSpanProcessor` y `registerLatitudeInstrumentations`, `capture()` opcional para el contexto de usuario/sesión/etiquetas (y por captura `projectSlug` para aplicaciones multiproyecto), env vars (`LATITUDE_API_KEY`, `LATITUDE_PROJECT_SLUG`) y una ruta alternativa OTLP para bases de código que no sean TS/Python.
