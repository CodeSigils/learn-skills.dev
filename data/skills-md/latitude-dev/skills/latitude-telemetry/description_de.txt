Installieren oder prüfen Sie die Beobachtbarkeit von Latitude LLM – sendet Spuren von LLM-SDKs (OpenAI, Anthropic, Bedrock, Cohere, TogetherAI, Vertex AI, Google AI Platform, OpenAI Agents, Vercel AI SDK, Mastra, LangChain, LlamaIndex) an ein Latitude-Projekt. TypeScript über „@latitude-data/telemetry“, Python über „latitude-telemetry“ und jede andere von OpenTelemetry unterstützte Sprache (Go, Java, Ruby, .NET, PHP, Rust, Elixir, …) über direktes OTLP-HTTP. Verwenden Sie diese Option, wenn der Benutzer Latitude-Tracing hinzufügen, Latitude in ein vorhandenes OpenTelemetry-Setup einbinden, fehlende Traces in Latitude beheben oder eine vorhandene Integration prüfen möchte. Behandelt Codebasiserkennung (vorhandenes OTel, widersprüchliche LLM-Observability-Anbieter, welche LLM-SDKs verwendet werden, wo LLM-Aufrufe stattfinden), klassenbasiertes Bootstrap („new Latitude({...})“ in TS, „Latitude(...)“ in Python), erweiterte Einrichtung mit „LatitudeSpanProcessor“ und „registerLatitudeInstrumentations“, optionales „capture()“ für Benutzer-/Sitzungs-/Tags-Kontext (und pro Capture „projectSlug“ für Multiprojekt-Apps), Umgebungsvariablen („LATITUDE_API_KEY“, „LATITUDE_PROJECT_SLUG“) und ein OTLP-Fallback-Pfad für Nicht-TS/Python-Codebasen.
