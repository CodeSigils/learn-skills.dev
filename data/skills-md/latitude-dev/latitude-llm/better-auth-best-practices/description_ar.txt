قم بتكوين خادم وعميل Better Auth، وإعداد محولات قاعدة البيانات، وإدارة الجلسات، وإضافة المكونات الإضافية، والتعامل مع متغيرات البيئة. يُستخدم عندما يذكر المستخدمون Better Auth، أو Betterauth، أو auth.ts، أو عندما يحتاجون إلى إعداد مصادقة TypeScript باستخدام البريد الإلكتروني/كلمة المرور، أو OAuth، أو تكوين المكون الإضافي.
