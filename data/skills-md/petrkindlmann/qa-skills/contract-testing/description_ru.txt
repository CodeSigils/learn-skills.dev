Внедрите тестирование контрактов, ориентированное на потребителя, с помощью Pact-JS (v16). Охватывает написание потребительских тестов, проверку поставщика на основе брокера, настройку Pact Broker, возможность развертывания в качестве шлюза развертывания, проверку с помощью веб-перехватчика, ожидающие соглашения и подходы «сначала схема» и «сначала потребитель» (OpenAPI/Ajv, Schemathesis). Используйте, когда: «контрактное тестирование», «Пакт», «ориентированный на потребителя», «контракт API», «проверка поставщика», «возможность развертывания». Не для: заглушки или имитации зависимости для изоляции теста — используйте сервис-виртуализацию; общие утверждения конечной точки REST/GraphQL для вашего собственного API — используйте API-тестирование. Связано: тестирование API, виртуализация сервисов, интеграция ci-cd, тестовые среды.
