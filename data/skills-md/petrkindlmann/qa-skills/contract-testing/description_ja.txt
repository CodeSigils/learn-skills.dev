Pact-JS (v16) を使用して消費者主導のコントラクト テストを実装します。コンシューマ テストの作成、ブローカー主導のプロバイダ検証、Pact Broker のセットアップ、デプロイメント ゲートとしての can-i-deploy、Webhook でトリガーされる検証、保留中の協定、およびスキーマ ファーストとコンシューマ ファーストのアプローチ (OpenAPI/Ajv、スキーマセシス) をカバーします。 「契約テスト」、「協定」、「消費者主導」、「API 契約」、「プロバイダー検証」、「can-i-deploy」の場合に使用します。向いていないもの: テストを分離するために依存関係をスタブ化またはモックすること — サービス仮想化を使用します。独自の API に対する一般的な REST/GraphQL エンドポイント アサーション - API テストを使用します。関連: API テスト、サービス仮想化、CI-CD 統合、テスト環境。
