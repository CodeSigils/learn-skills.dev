PSP サンドボックスに対して支払いとチェックアウトのフローをエンドツーエンドでテストします。Adyen/Braintree/PayPal の一般的なパターンでストライプ ファーストを実行します。 Stripe テストモードのカード番号とその拒否コード、Playwright での 3DS/SCA チャレンジ フローとネストされた iframe の処理、サブスクリプション/請求サイクル シミュレーション用のテスト クロック、Webhook テスト (ストライプ リッスン/トリガー、署名検証、冪等性)、失敗/再試行された支払いと返金、および実際のカードの使用禁止について説明します。 「Stripe チェックアウトのテスト」、「支払いテスト」、「3DS テスト」、「Webhook 署名のテスト」、「サブスクリプション更新のテスト」、「時計のテスト」、「返金テスト」、「カード テストの拒否」、「E2E のチェックアウト」の場合に使用します。対象外: 非支払いエンドポイントの一般的な API コントラクト テスト — API テスト。 PCI-DSS/規制順守監査 - 順守テスト。関連: API テスト、プレイライトの自動化、コンプライアンス テスト、テスト データ管理、QA プロジェクト コンテキスト。
