Examinez le code de test EXISTANT pour les problèmes de qualité, d’odeurs et de testabilité. Détecte les odeurs de test sur six dimensions : lisibilité, fiabilité, valeur diagnostique, conception, génération de l'IA et couverture, analyse la testabilité du code d'application et étaye les odeurs qualitatives avec des tests de mutation. À utiliser lorsque : « examiner mes tests », « audit de qualité des tests », « odeurs de test », « analyse de testabilité », « ces tests sont-ils bons ». Pas pour : générer de nouveaux tests — utilisez `ai-test-generation`. Pas pour : tester les fonctionnalités d'IA de votre produit — utilisez « ai-system-testing ». Connexes : tests unitaires, tests de décalage à gauche, analyse de couverture, génération de tests ai.
