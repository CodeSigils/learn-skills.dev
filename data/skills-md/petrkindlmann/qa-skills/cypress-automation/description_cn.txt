在 TypeScript 中构建 Cypress 测试套件：E2E 测试、组件测试、自定义命令、cy.intercept 网络控制、cy.session 登录、Cypress Cloud 和 CI 集成。涵盖重试能力、命令队列、cy.origin 的跨源流以及使用固定装置的数据驱动测试。在以下情况下使用：“在 Cypress 中编写 E2E 测试”、“Cypress 页面对象/自定义命令”、“cy.”、“cy.intercept”、“Cypress 组件测试”、“Cypress Cloud”、“cypress.config.ts”。不适用于：剧作家套件 - 使用剧作家自动化；片状测试治愈或隔离——使用测试可靠性； UI 重构后批量选择器重新生成 — 使用选择器漂移恢复； Selenium 到 Cypress 的转换 — 使用测试迁移。相关：剧作家自动化、ci-cd 集成、视觉测试、单元测试、测试可靠性。
