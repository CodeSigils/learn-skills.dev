Lanceur séquencé qui démarre le contrôle qualité sur un projet sans contrôle qualité en place. Enchaîne le contexte du projet qa → la stratégie de test → la planification des tests en une seule exécution guidée, puis vous oriente vers l'automatisation. À utiliser lorsque : « configurer le contrôle qualité sur un nouveau projet », « contrôle qualité à partir de zéro », « aucun contrôle qualité n'existe encore », « /qa-start ». Pas pour : intégrer un ingénieur QA dans une équipe existante avec des tests existants – utilisez qa-project-bootstrap. Pas pour : "quelle compétence dois-je utiliser" sans correspondance claire - utilisez qa-do. Connexes : qa-project-context, test-strategy, test-planning, qa-project-bootstrap, qa-do.
