Sequenzierter Launcher, der die Qualitätssicherung für ein Projekt ohne vorhandene Qualitätssicherung startet. Verkettet QA-Projektkontext → Teststrategie → Testplanung in einem geführten Durchlauf und weist Sie dann auf die Automatisierung hin. Wird verwendet, wenn: „QA für ein neues Projekt einrichten“, „QA von Grund auf neu erstellen“, „noch keine QA vorhanden ist“, „/qa-start“. Nicht für: Eingliederung eines QA-Ingenieurs in ein bestehendes Team mit vorhandenen Tests – verwenden Sie qa-project-bootstrap. Nicht für: „Welche Fertigkeit verwende ich?“ ohne eindeutige Übereinstimmung – verwenden Sie Qa-Do. Verwandte Themen: QA-Projektkontext, Teststrategie, Testplanung, QA-Projekt-Bootstrap, QA-Do.
