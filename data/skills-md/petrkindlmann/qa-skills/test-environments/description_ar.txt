إستراتيجية بيئة التصميم للاختبار عبر التطوير وCI والمعاينة والتجهيز والإنتاج - البنية الأساسية لاختبار Docker Compose وملفات Dockerfiles متعددة المراحل ودورة حياة البيانات الأولية وبيئات معاينة لكل PR وتكافؤ الإنتاج وإيقاف التبعية الخارجية عند حدود HTTP. يُستخدم عندما: "إعداد بيئة الاختبار"، و"إنشاء عامل الإرساء للاختبارات"، و"بيئة معاينة لكل PR"، و"التكافؤ المرحلي"، و"تدوير الأشعة تحت الحمراء للاختبار"، و"طبقات البيئة". ليس من أجل: اختيار وهمية مقابل كعب روتين مقابل وهمية لكل تبعية - استخدام الخدمة الافتراضية؛ أنماط بيانات المصانع والتركيبات - استخدام إدارة بيانات الاختبار؛ تكوين خط الأنابيب/الإجراءات - استخدم تكامل ci-cd. ذات صلة: إدارة بيانات الاختبار، وتكامل الأقراص المضغوطة، واختبار العقود، والمحاكاة الافتراضية للخدمة.
