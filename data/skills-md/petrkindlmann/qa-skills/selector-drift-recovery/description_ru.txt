Массовое восстановление неработающих тестовых селекторов после рефакторинга или редизайна пользовательского интерфейса. Обнаруживает расхождение между старым и новым DOM с помощью разницы в моментальном снимке aria, сопоставляет старые локаторы с новыми эквивалентами, используя область видимости по роли и региону, проверяет соответствие новой сборке и создает единый PR с сгруппированными обновлениями селектора для каждого файла и доказательствами для каждого изменения. Предполагается, что Playwright >= 1,50 (панель снимков DOM средства просмотра трассировки, фильтрация getByRole, ariaSnapshot). Используйте, когда: «рефакторинг пользовательского интерфейса сломал тесты», «перепроектировал сломанные тесты», «массовое обновление селекторов», «восстановление селекторов после рефакторинга», «смещение селектора», «исправление N неработающих тестов после редизайна». Не для того, чтобы исправить один нестабильный тест во время выполнения — используйте test-reliability. Не для: написания нового набора тестов с нуля — используйте драматург-автоматизацию. Не для: перезаписи тестов после смены фреймворка (Selenium на Playwright) — используйте test-migration. Связано: тестирование надежности, автоматизация драматурга, тестовая миграция, интеграция ci-cd, визуальное тестирование.
