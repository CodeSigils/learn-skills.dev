UI 重构或重新设计后，批量重新生成损坏的测试选择器。使用 aria-snapshot diff 检测新旧 DOM 之间的偏差，使用角色优先 + 区域范围将旧定位器映射到新的等效项，针对新构建进行验证，并生成带有分组的每个文件选择器更新和每个更改证据的单个 PR。假设 Playwright >= 1.50（跟踪查看器 DOM 快照面板、getByRole 过滤、ariaSnapshot）。在以下情况下使用：“UI 重构破坏了测试”、“重新设计破坏了测试”、“批量更新选择器”、“重构后重新生成选择器”、“选择器漂移”、“重新设计后修复 N 个破坏的测试”。不适合：在运行时修复一个不稳定的测试——使用测试可靠性。不适合：从头开始编写新的测试套件 - 使用剧作家自动化。不适用于：在框架切换（Selenium 到 Playwright）后重新录制测试 — 使用测试迁移。相关：测试可靠性、剧作家自动化、测试迁移、ci-cd 集成、视觉测试。
