UI のリファクタリングまたは再設計後に、壊れたテスト セレクターを一括再生成します。 aria-snapshot diff を使用して古い DOM と新しい DOM の間のドリフトを検出し、ロールファースト + 領域スコープを使用して古いロケーターを新しい同等のロケーターにマップし、新しいビルドに対して検証し、グループ化されたファイルごとのセレクター更新と変更ごとの証拠を含む単一の PR を生成します。 Playwright >= 1.50 (トレース ビューア DOM スナップショット パネル、getByRole フィルタリング、ariaSnapshot) を想定します。 「UI リファクタリングが壊れたテスト」、「壊れたテストを再設計」、「一括更新セレクター」、「リファクタリング後にセレクターを再生成」、「セレクターのドリフト」、「再設計後に N 個の壊れたテストを修正」する場合に使用します。不向き: 実行時に 1 つの不安定なテストを修復する - テストの信頼性を使用します。向いていない: 新しいテスト スイートを最初から作成する場合 - playwright-automation を使用します。対象外: フレームワークの切り替え (Selenium から Playwright) 後のテストの再記録 - テスト移行を使用します。関連: テストの信頼性、プレイライトの自動化、テストの移行、CI-CD の統合、ビジュアル テスト。
