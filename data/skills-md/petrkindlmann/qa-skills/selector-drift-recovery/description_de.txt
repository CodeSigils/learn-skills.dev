Generieren Sie defekte Testselektoren nach einer Umgestaltung oder Neugestaltung der Benutzeroberfläche in großen Mengen neu. Erkennt Abweichungen zwischen altem und neuem DOM mit einem Aria-Snapshot-Diff, ordnet alte Locators mithilfe von Role-First + Region Scoping neuen Äquivalenten zu, validiert anhand des neuen Builds und erstellt einen einzelnen PR mit gruppierten Auswahlaktualisierungen pro Datei und Beweisen pro Änderung. Setzt Playwright >= 1,50 voraus (Trace-Viewer-DOM-Snapshot-Panel, getByRole-Filterung, ariaSnapshot). Wird verwendet, wenn: „UI-Refactor-Tests kaputt gemacht“, „Neudesign-Tests kaputt gemacht“, „Selektoren massenhaft aktualisieren“, „Selektoren nach Refactor neu generieren“, „Selektordrift“, „N kaputte Tests nach Redesign reparieren“. Nicht für: Beheben eines fehlerhaften Tests zur Laufzeit – Testzuverlässigkeit verwenden. Nicht für: das Schreiben einer neuen Testsuite von Grund auf – verwenden Sie playwright-automation. Nicht für: Neuaufzeichnung von Tests nach einem Framework-Wechsel (Selenium zu Playwright) – verwenden Sie test-migration. Verwandte Themen: Testzuverlässigkeit, Dramatiker-Automatisierung, Testmigration, CI-CD-Integration, visuelle Tests.
