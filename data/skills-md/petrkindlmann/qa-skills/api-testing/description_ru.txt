Тестируйте API-интерфейсы REST и GraphQL с помощью Playwright APIRequestContext, Supertest или автономных HTTP-клиентов. Охватывает проверку схемы с помощью Zod/AJV, шаблоны тестирования контрактов, тестирование потока аутентификации, тесты жизненного цикла CRUD, проверку ответов на ошибки и утверждения производительности. Используйте, когда: «тест API», «тест конечной точки», «тест REST», «тест GraphQL», «проверка схемы», «замена почтальона». Связано: контрактное тестирование, управление тестовыми данными, интеграция ci-cd, автоматизация драматурга.
