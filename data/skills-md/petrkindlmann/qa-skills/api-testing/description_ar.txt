اختبر واجهات برمجة تطبيقات REST وGraphQL باستخدام Playwright APIRequestContext أو Supertest أو عملاء HTTP المستقلين. يغطي التحقق من صحة المخطط باستخدام Zod/AJV، وأنماط اختبار العقد، واختبار تدفق المصادقة، واختبارات دورة حياة CRUD، والتحقق من صحة الاستجابة للأخطاء، وتأكيدات الأداء. يُستخدم عندما: "اختبار API"، و"اختبار نقطة النهاية"، و"اختبار REST"، و"اختبار GraphQL"، و"التحقق من صحة المخطط"، و"استبدال Postman". ذات صلة: اختبار العقود، إدارة بيانات الاختبار، تكامل الأقراص المضغوطة CI، أتمتة الكاتب المسرحي.
