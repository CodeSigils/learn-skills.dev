Playwright APIRequestContext、Supertest、またはスタンドアロン HTTP クライアントを使用して REST および GraphQL API をテストします。 Zod/AJV によるスキーマ検証、コントラクト テスト パターン、認証フロー テスト、CRUD ライフサイクル テスト、エラー応答検証、パフォーマンス アサーションをカバーします。 「API テスト」、「エンドポイント テスト」、「REST テスト」、「GraphQL テスト」、「スキーマ検証」、「Postman 置換」の場合に使用します。関連: 契約テスト、テストデータ管理、CI-CD 統合、プレイライト自動化。
