Комплексное тестирование потоков, зависящих от электронной почты — подтверждение регистрации, сброс пароля, вход по магической ссылке, коды OTP/MFA и уведомления по электронной почте. Охватывает дерево решений для захвата входящих сообщений (Mailpit, Mailosaur, MailSlurp, Ethereal), опрос Playwright без фиксированных спящих режимов, регулярное извлечение ссылок/OTP из тела электронной почты, детерминированные адреса для каждого теста (плюс адресация, для каждого почтового ящика), утверждения темы/из/заголовка/ссылки и проверки доставляемости SPF/DKIM/DMARC как отдельный набор. Используйте, когда: «проверьте электронное письмо с подтверждением регистрации», «тестирование электронного письма для сброса пароля», «тестирование входа в систему с помощью Magic-Link», «захват OTP из электронной почты», «Mailpit», «Mailosaur», «MailSlurp», «электронное письмо приходит нестабильно в CI», «утвердить тему/от/ссылок электронного письма». Не для: отправки транзакционной электронной почты из кода вашего приложения или контрактных тестов поставщика электронной почты только для API — это проблемы API-тестирования/приложения. Отображение HTML-кода электронной почты между клиентами (темный режим Outlook/Gmail) выходит за рамки (обратите на это внимание как на пробел; используйте визуальное тестирование или Litmus). Связано: автоматизация драматурга, API-тестирование, управление тестовыми данными, контекст qa-проекта.
