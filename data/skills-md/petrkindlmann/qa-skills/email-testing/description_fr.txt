Tests de bout en bout des flux dépendants des e-mails : confirmation d'inscription, réinitialisation du mot de passe, connexion par lien magique, codes OTP/MFA et e-mails de notification. Couvre l'arbre de décision de capture de la boîte de réception (Mailpit, Mailosaur, MailSlurp, Ethereal), l'interrogation Playwright sans veille fixe, l'extraction des expressions régulières des liens/OTP du corps de l'e-mail, les adresses déterministes par test (adressage plus, par boîte de réception), les assertions sujet/de/en-tête/lien et les contrôles de délivrabilité SPF/DKIM/DMARC en tant que suite distincte. À utiliser lorsque : "tester l'e-mail de confirmation d'inscription", "test de l'e-mail de réinitialisation du mot de passe", "test de connexion par lien magique", "capturer l'OTP à partir de l'e-mail", "Mailpit", "Mailosaur", "MailSlurp", "l'e-mail arrive de manière irrégulière dans CI", "affirmer l'objet/de/les liens de l'e-mail". Pas pour : l'envoi d'e-mails transactionnels à partir du code de votre application ou les tests contractuels API uniquement d'un fournisseur de messagerie : ce sont des problèmes de tests d'API/d'application. Le rendu HTML des e-mails sur les clients (mode sombre Outlook/Gmail) est hors de portée (notez-le comme une lacune ; utilisez des tests visuels ou Litmus). Connexes : automatisation du dramaturge, tests API, gestion des données de test, contexte de projet qa.
