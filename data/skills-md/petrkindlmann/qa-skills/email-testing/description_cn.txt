对依赖于电子邮件的流程进行端到端测试 — 注册确认、密码重置、magic-link 登录、OTP/MFA 代码和通知电子邮件。作为一个单独的套件，涵盖了捕获收件箱决策树（Mailpit、Mailosaur、MailSlurp、Ethereal）、无固定睡眠的剧作家轮询、从电子邮件正文中正则表达式提取链接/OTP、确定性每次测试地址（加地址、每个收件箱）、主题/来自/标题/链接断言以及 SPF/DKIM/DMARC 送达率检查。在以下情况下使用：“测试注册确认电子邮件”、“密码重置电子邮件测试”、“magic-link 登录测试”、“从电子邮件捕获 OTP”、“Mailpit”、“Mailosaur”、“MailSlurp”、“电子邮件到达 CI 时不稳定”、“断言电子邮件主题/发件人/链接”。不适用于：从应用程序代码发送交易电子邮件，或电子邮件提供商的仅 API 合同测试 - 这些是 api 测试/应用程序问题。跨客户端的电子邮件 HTML 呈现（Outlook/Gmail 暗模式）超出了范围（将其记为间隙；使用视觉测试或 Litmus）。相关：剧作家自动化、API 测试、测试数据管理、质量保证项目上下文。
