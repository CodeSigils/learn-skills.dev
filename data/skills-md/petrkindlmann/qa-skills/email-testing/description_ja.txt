電子メールに依存するフローのエンドツーエンドのテスト - サインアップの確認、パスワードのリセット、マジックリンク ログイン、OTP/MFA コード、通知電子メール。キャプチャインボックス デシジョン ツリー (Mailpit、Mailosaur、MailSlurp、Ethereal)、固定スリープなしの Playwright ポーリング、電子メール本文からのリンク/OTP の正規表現抽出、決定論的なテストごとのアドレス (プラス アドレス指定、受信ボックスごと)、件名/差出人/ヘッダー/リンク アサーション、および SPF/DKIM/DMARC 配信可能性チェックを別個のスイートとしてカバーします。 「サインアップ確認電子メールのテスト」、「パスワード リセット電子メール テスト」、「マジックリンク ログイン テスト」、「電子メールから OTP をキャプチャ」、「Mailpit」、「Mailosaur」、「MailSlurp」、「CI で電子メールが不安定に受信される」、「電子メールの件名/送信者/リンクを確認する」場合に使用します。対象外: アプリ コードからのトランザクション電子メールの送信、または電子メール プロバイダーの API のみの契約テスト。これらは API テスト/アプリに関する問題です。クライアント間での電子メール HTML レンダリング (Outlook/Gmail ダーク モード) は対象外です (ギャップとして注意してください。ビジュアル テストまたは Litmus を使用してください)。関連: playwright-automation、api-testing、test-data-management、qa-project-context。
