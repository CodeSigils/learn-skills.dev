對依賴電子郵件的流程進行端對端測試 — 註冊確認、密碼重設、magic-link 登入、OTP/MFA 代碼和通知電子郵件。作為一個單獨的套件，涵蓋了捕獲收件匣決策樹（Mailpit、Mailosaur、MailSlurp、Ethereal）、無固定睡眠的劇作家輪詢、從電子郵件正文中正則表達式提取連結/OTP、確定性每次測試地址（加地址、每個收件匣）、主題/來自/標題/連結斷言以及 SPF/DKIM/DM 送達率檢查率。在以下情況下使用：「測試註冊確認電子郵件」、「密碼重設電子郵件測試」、「magic-link 登入測試」、「從電子郵件捕獲 OTP」、「Mailpit」、「Mailosaur」、「MailSlurp」、「電子郵件到達 CI 時不穩定」、「斷言電子郵件主題/寄件者/連結」。不適用於：從應用程式程式碼發送交易電子郵件，或電子郵件提供者的僅 API 合約測試 - 這些是 api 測試/應用程式問題。跨客戶端的電子郵件 HTML 呈現（Outlook/Gmail 暗模式）超出了範圍（將其記為間隙；使用視覺測試或 Litmus）。相關：劇作家自動化、API 測試、測試資料管理、品質保證專案上下文。
