テスト スイート内のすべての外部依存関係を分離するための意思決定フレームワーク: インプロセス モック、HTTP スタブ (MSW、WireMock)、レコード再生、フォールト インジェクション (Toxiproxy)、または一時的な実際のサービス (Testcontainers) をいつ使用するか、および CI で実際の呼び出しがエスケープしないように強制する方法。 「モック サービス」、「スタブ API」、「フェイク サービス」、「WireMock」、「MSW」、「Toxiproxy」、「テスト分離」、「依存関係管理」、「CI での外部 API のスタブ」の場合に使用します。対象外: 消費者主導の契約検証 (Pact、ブローカー) — 契約テストを使用します。完全な Docker Compose 環境またはシード データを立ち上げる — テスト環境を使用します。広範な回復力/試合当日の障害キャンペーン — カオス エンジニアリングを使用します。関連: 契約テスト、テスト環境、API テスト、テストデータ管理、カオス エンジニアリング。
