إطار عمل قرار لعزل كل تبعية خارجية في مجموعة اختبار: متى يتم استخدام النماذج قيد التشغيل، أو قواعد HTTP (MSW، WireMock)، أو إعادة تشغيل السجل، أو حقن الأخطاء (Toxiproxy)، أو الخدمات الحقيقية سريعة الزوال (Testcontainers)، وكيفية فرض عدم هروب أي مكالمات حقيقية في CI. يُستخدم عندما: "خدمة وهمية"، و"Stub API"، و"خدمة مزيفة"، و"WireMock"، و"MSW"، و"Toxiproxy"، و"اختبار العزل"، و"إدارة التبعية"، و"Stub an External API in CI." ليس من أجل: التحقق من العقد الذي يحركه المستهلك (الميثاق، الوسيط) - استخدام اختبار العقد؛ إعداد بيئة Docker Compose كاملة أو بيانات أولية - استخدام بيئات الاختبار؛ حملات واسعة النطاق للمرونة/الخطأ في يوم اللعبة - استخدم هندسة الفوضى. ذات صلة: اختبار العقود، بيئات الاختبار، اختبار واجهة برمجة التطبيقات، إدارة بيانات الاختبار، هندسة الفوضى.
