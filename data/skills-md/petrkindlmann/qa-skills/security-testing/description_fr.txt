Testez la sécurité des applications par rapport à OWASP Top 10 (2025) avec des outils CI automatisés : OWASP ZAP (DAST), analyse des dépendances/chaîne d'approvisionnement (OSV-Scanner, SBOM, provenance), Semgrep SAST, tests d'authentification/session (JWT, OAuth, RBAC) et modèles XSS/CSRF/SQLi/SSRF Playwright. À utiliser lorsque : "test de sécurité", "OWASP", "vulnérabilité", "ZAP", "XSS", "SSRF", "analyse des dépendances", "test d'authentification", "OWASP LLM Top 10". La portée est l'analyse automatisée + les tests de sécurité à chemin négatif dans CI, et non les tests d'intrusion manuels. Pas pour : mapper les contrôles de sécurité aux réglementations (SOC 2, HIPAA, PCI, GDPR) – utiliser des tests de conformité ; Câblage de l'étape du pipeline et déploiement de la mécanique de déclenchement – utiliser l'intégration ci-cd ; tests d'authentification/d'entrée d'API purement fonctionnels sans modèle d'attaquant — voir tests d'API ; tester les propres fonctionnalités LLM de votre produit ou défendre l'agent lui-même (détecteur d'injection rapide, injection indirecte, red-teaming de jailbreak) - utilisez les tests du système ai. Connexes : intégration ci-cd, tests de conformité, tests api, tests de décalage à gauche, tests de système ai.
