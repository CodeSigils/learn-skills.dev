使用自动化 CI 工具针对 OWASP Top 10 (2025) 测试应用程序安全性：OWASP ZAP (DAST)、依赖项/供应链扫描（OSV-Scanner、SBOM、出处）、Semgrep SAST、身份验证/会话测试（JWT、OAuth、RBAC）和 XSS/CSRF/SQLi/SSRF Playwright 模式。在以下情况下使用：“安全测试”、“OWASP”、“漏洞”、“ZAP”、“XSS”、“SSRF”、“依赖项扫描”、“身份验证测试”、“OWASP LLM Top 10”。范围是CI中的自动扫描+负路径安全测试，而不是手动渗透测试。不适用于：将安全控制映射到法规（SOC 2、HIPAA、PCI、GDPR）——使用合规性测试；管道阶段布线和部署门控机制 - 使用 CI-CD 集成；纯功能性 API 身份验证/输入测试，无攻击者模型 — 请参阅 api-testing；测试产品自己的 LLM 功能或保护代理本身（即时注入检测器、间接注入、越狱红队）——使用 ai-system-testing。相关：ci-cd 集成、合规性测试、api 测试、左移测试、ai 系统测试。
