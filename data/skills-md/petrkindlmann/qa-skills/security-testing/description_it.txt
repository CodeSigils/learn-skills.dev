Testa la sicurezza delle applicazioni rispetto a OWASP Top 10 (2025) con strumenti CI automatizzati: OWASP ZAP (DAST), scansione delle dipendenze/catena di fornitura (OSV-Scanner, SBOM, provenienza), Semgrep SAST, test di autenticazione/sessione (JWT, OAuth, RBAC) e modelli XSS/CSRF/SQLi/SSRF Playwright. Utilizzare quando: "test di sicurezza", "OWASP", "vulnerabilità", "ZAP", "XSS", "SSRF", "scansione delle dipendenze", "test di autenticazione", "OWASP LLM Top 10". L'ambito è la scansione automatizzata + test di sicurezza del percorso negativo in CI, non test di penetrazione manuali. Non per: associare i controlli di sicurezza alle normative (SOC 2, HIPAA, PCI, GDPR) — utilizzare test di conformità; cablaggio dello stadio della pipeline e implementazione della meccanica di gate: utilizzare l'integrazione ci-cd; Test di autenticazione/input API puramente funzionali senza modello di attacco: vedere api-testing; testare le funzionalità LLM del tuo prodotto o difendere l'agente stesso (rilevatore di prompt-injection, iniezione indiretta, jailbreak red-teaming): utilizza ai-system-testing. Correlati: integrazione ci-cd, test di conformità, test api, test shift-left, test del sistema ai.
