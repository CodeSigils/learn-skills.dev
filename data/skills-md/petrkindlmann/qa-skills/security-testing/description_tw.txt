使用自動化 CI 工具針對 OWASP Top 10 (2025) 測試應用程式安全性：OWASP ZAP (DAST)、相依性/供應鏈掃描（OSV-Scanner、SBOM、出處）、Semgrep SAST、驗證/會話測試（JWT、OAuth、RBAC）和 XSS/CSRF/SQLright SAST、驗證/會話測試（JWT、OAuth、RBAC）和 XSS/CSRF/SQLrighti/SS 模式。以下情況使用：「安全測試」、「OWASP」、「漏洞」、「ZAP」、「XSS」、「SSRF」、「依賴項掃描」、「驗證測試」、「OWASP LLM Top 10」。範圍是CI中的自動掃描+負路徑安全測試，而不是手動滲透測試。不適用於：將安全控制映射到法規（SOC 2、HIPAA、PCI、GDPR）——使用合規性測試；管道階段佈線和部署門控機制 - 使用 CI-CD 集成；純功能性 API 身份驗證/輸入測試，無攻擊者模型 — 請參閱 api-testing；測試產品自己的 LLM 功能或保護代理本身（即越時器檢測代理）。相關：ci-cd 整合、合規性測試、api 測試、左移測試、ai 系統測試。
