自動化された CI ツールを使用して、OWASP Top 10 (2025) に対してアプリケーションのセキュリティをテストします: OWASP ZAP (DAST)、依存関係/サプライ チェーン スキャン (OSV-Scanner、SBOM、来歴)、Semgrep SAST、認証/セッション テスト (JWT、OAuth、RBAC)、および XSS/CSRF/SQLi/SSRF Playwright パターン。 「セキュリティ テスト」、「OWASP」、「脆弱性」、「ZAP」、「XSS」、「SSRF」、「依存関係スキャン」、「認証テスト」、「OWASP LLM トップ 10」の場合に使用します。範囲は、手動侵入テストではなく、CI での自動スキャン + ネガティブ パス セキュリティ テストです。非対象: セキュリティ管理を規制 (SOC 2、HIPAA、PCI、GDPR) にマッピングする — コンプライアンス テストを使用する。パイプライン ステージの配線とゲート メカニズムの展開 — ci-cd-integration を使用します。攻撃者モデルを使用しない純粋に機能的な API 認証/入力テスト — api-testing を参照。製品自身の LLM 機能をテストするか、エージェント自体を防御する (プロンプト インジェクション ディテクタ、間接インジェクション、ジェイルブレイク レッド チーム化) — ai-system-testing を使用します。関連: ci-cd-integration、compliance-testing、api-testing、shift-left-testing、ai-system-testing。
