Concevoir et exécuter des sessions de tests exploratoires structurées. Couvre la gestion des tests basés sur la session (SBTM), la rédaction de chartes, l'exploration heuristique (HICCUPS, FEW HICCUPS), les modèles de découverte de bogues, les modèles de prise de notes et la conversion des résultats en tests automatisés. À utiliser dans les cas suivants : « tests exploratoires », « SBTM », « tests manuels », « chasse aux bogues », « charte de test », « tests heuristiques ». Pas pour : un agent de navigateur IA explorant l'application de manière autonome à partir d'un objectif en langage naturel : utilisez les tests de navigateur agent. Pas pour : tester les propres fonctionnalités AI/LLM de votre produit – utilisez ai-system-testing. Connexes : planification des tests, triage des bogues par IA, tests basés sur les risques, tests de navigateur agent.
