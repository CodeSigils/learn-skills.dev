Verwenden Sie KI, um NEUEN Testcode aus Spezifikationen, PRDs, User Stories, Codeunterschieden, Fehlerberichten oder OpenAPI-Spezifikationen zu schreiben. Gestaffelte Pipeline: Anforderungsextraktion → Risikoanalyse → Abdeckungsmatrix → Szenariogenerierung → Oracle-Design → Testcode → menschliche Überprüfung, mit Schutzmaßnahmen gegen halluzinierte APIs und schwache Behauptungen. Verwendung bei: „Tests aus Spezifikation generieren“, „Tests aus PRD“, „Tests aus User Story“, „Testfälle automatisch generieren“, „KI schreibt Tests für mich.“ Nicht zum Testen von KI/LLM-Funktionen in Ihrem Produkt – verwenden Sie ai-system-testing. Nicht für: Prüfung einer bereits vorhandenen Testsuite, die Sie nicht gerade generiert haben – verwenden Sie ai-qa-review (Schritt 7 überprüft hier nur Tests, die DIESE Pipeline erstellt hat). Verwandte Themen: Dramatiker-Automatisierung, Unit-Tests, API-Tests, QA-Projektkontext.
