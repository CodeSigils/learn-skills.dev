Используйте ИИ для написания НОВОГО тестового кода на основе спецификаций, PRD, пользовательских историй, различий кода, отчетов об ошибках или спецификаций OpenAPI. Поэтапный конвейер: извлечение требований → анализ рисков → матрица покрытия → генерация сценариев → проектирование оракула → тестовый код → проверка человеком, с защитой от галлюцинаторных API и слабых утверждений. Используйте, когда: «генерировать тесты на основе спецификации», «тесты на основе PRD», «тесты на основе пользовательской истории», «автоматическое создание тестовых примеров», «ИИ пишет тесты за меня». Не для: тестирования функций AI/LLM в вашем продукте — используйте ai-system-testing. Не для: аудита уже существующего набора тестов, который вы не просто сгенерировали — используйте ai-qa-review (шаг 7 здесь рассматривает только тесты, созданные ЭТИМ конвейером). Связано: автоматизация драматурга, модульное тестирование, API-тестирование, контекст qa-проекта.
