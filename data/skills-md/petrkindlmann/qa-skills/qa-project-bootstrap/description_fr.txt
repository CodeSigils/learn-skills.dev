Intégrez un nouvel ingénieur QA à une base de code existante ou auditez une architecture de test existante. Produit un plan de rampe de 30 jours : orientation de la base de code, présentation pas à pas du framework, audit de l'architecture de test, jumelage de mentorat et conseils pour le premier test. À utiliser lorsque : « intégration du contrôle qualité », « nouveau testeur », « montée en puissance », « audit de l'architecture de test », « 30 premiers jours », « mentorat en contrôle qualité », « rejoindre l'équipe d'assurance qualité ». Pas pour : configurer le contrôle qualité sur un tout nouveau projet à partir de zéro — utilisez « qa-start ». Connexes : qa-start, qa-project-context, shift-left-testing, ai-qa-review.
