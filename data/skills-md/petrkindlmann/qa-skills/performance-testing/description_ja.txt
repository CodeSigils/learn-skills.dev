k6 ロード/ストレス/ソーク/スパイク スクリプトと k6 シナリオ、Web Vitals 用の Lighthouse CI、CI ゲートとしてのパフォーマンス バジェットを使用して、アプリケーションのパフォーマンスをテストします。負荷プロファイル、カスタム メトリック、ボトルネックの特定、および Core Web Vitals (LCP、INP、CLS) をカバーします。 「パフォーマンス テスト」、「負荷テスト」、「ストレス テスト」、「ソーク テスト」、「スパイク テスト」、「k6」、「k6 シナリオ」、「Lighthouse」、「Web Vitals」、「Core Web Vitals」、「パフォーマンス バジェット」の場合に使用します。対象外: スケジュールされた運用プローブ — 合成モニタリングを使用します。ピクセル差分回帰 — 視覚的なテストを使用します。運用テレメトリからテストを設計する — 可観測性主導のテストを使用します。関連: ci-cd-integration、qa-metrics、リリース準備状況。
