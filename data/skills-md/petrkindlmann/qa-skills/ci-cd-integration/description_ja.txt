テスト スイートを実行する CI/CD パイプラインを設計します。 GitHub Actions と GitLab CI テンプレート、並列処理とシャーディング、アーティファクト管理、不安定なテストの隔離、テスト結果の公開、カバレッジ品質ゲート、OIDC キーレス デプロイ、Playwright、Jest、およびマルチステージ パイプラインのコピー アンド ペースト ワークフローをカバーします。 「CI/CD」、「GitHub アクション」、「パイプライン」、「CI でのテスト」、「GitLab CI」、「継続的インテグレーション」、「テスト自動化パイプライン」、「CI でのシャード テスト」の場合に使用します。不向き: 実行時のテストごとの不安定な修復 — テストの信頼性を使用します。リリースの可否の決定とスモークテストのチェックリスト - リリースの準備を使用します。テスト結果のダッシュボードと傾向レポート — QA メトリクスを使用します。関連: Playwright の自動化、QA メトリクス、テストの信頼性、カバレッジ分析、リリースの準備状況。
