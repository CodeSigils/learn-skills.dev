Railway GraphQL API (الرمز المميز للحساب/مساحة العمل) لإدارة المشاريع والخدمات وعمليات النشر والبيئات والمتغيرات. يُستخدم عندما يذكر المستخدم "Railway"، أو "railway.com"، أو "railway.app"، أو النشر إلى السكك الحديدية، أو إدارة مشاريع/خدمات/عمليات النشر للسكك الحديدية، أو عمليات السكك الحديدية على مستوى مساحة العمل.
