Stripe Link-Agent-Wallet-CLI. Verwenden Sie diese Option, wenn der Benutzer möchte, dass ein Agent in seinem Namen Zahlungen vornimmt, virtuelle Karten zur einmaligen Verwendung erstellt, über das Machine Payments Protocol (MPP) ausgibt oder sein Link-Wallet verwaltet. Wird bei Erwähnungen von „Mit Link kaufen“, „Agentenzahlung“, „Link-Wallet“, „Ausgabeanforderung“ oder „Link-Cli“ ausgelöst.
