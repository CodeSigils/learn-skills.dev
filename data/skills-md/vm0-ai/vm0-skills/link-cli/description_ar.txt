محفظة وكيل Stripe Link CLI. يُستخدم عندما يريد المستخدم من وكيل إجراء الدفعات نيابةً عنه، أو إنشاء بطاقات افتراضية تستخدم لمرة واحدة، أو الإنفاق عبر بروتوكول مدفوعات الآلة (MPP)، أو إدارة محفظة الارتباط الخاصة به. يتم تشغيله عند الإشارة إلى "شراء باستخدام رابط"، أو "دفع الوكيل"، أو "ربط المحفظة"، أو "طلب الإنفاق"، أو "link-cli".
