CLI du portefeuille d'agent Stripe Link. À utiliser lorsque l'utilisateur souhaite qu'un agent effectue des paiements en son nom, crée des cartes virtuelles à usage unique, dépense via le protocole de paiement automatique (MPP) ou gère son portefeuille Link. Se déclenche sur les mentions de « acheter avec lien », « paiement d'agent », « portefeuille de lien », « demande de dépense » ou « lien-cli ».
