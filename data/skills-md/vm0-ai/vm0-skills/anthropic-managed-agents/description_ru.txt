API управляемых агентов Anthropic для программного создания, запуска и потоковой передачи агентов ИИ в облачной инфраструктуре Anthropic. Используйте, когда пользователь упоминает «Управляемые агенты», «Сеансы антропного агента» или ему необходимо создать/запустить/потоковую передачу антропного агента с помощью инструментов (bash, git, web), прикрепить репозитории GitHub или внедрить секреты через Vault. НЕ используйте для стандартного API сообщений Claude — вместо этого используйте навык Claude API.
