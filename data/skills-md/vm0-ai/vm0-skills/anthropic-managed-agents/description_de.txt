Anthropic Managed Agents API zum programmgesteuerten Erstellen, Ausführen und Streamen von KI-Agenten in der Cloud-Infrastruktur von Anthropic. Verwenden Sie diese Option, wenn der Benutzer „Verwaltete Agenten“, „Anthropic-Agent-Sitzungen“ erwähnt oder einen Anthropic-Agenten mit Tool-Nutzung (Bash, Git, Web) erstellen/ausführen/streamen, GitHub-Repositorys anhängen oder Geheimnisse über Vault einschleusen muss. NICHT für die standardmäßige Claude Messages API verwenden – verwenden Sie stattdessen den Claude API-Skill.
