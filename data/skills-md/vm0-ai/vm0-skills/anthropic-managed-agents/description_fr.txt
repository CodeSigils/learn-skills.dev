API Anthropic Managed Agents pour la création, l'exécution et le streaming par programmation d'agents IA sur l'infrastructure cloud d'Anthropic. À utiliser lorsque l'utilisateur mentionne « Agents gérés », « Sessions d'agent Anthropic » ou doit créer/exécuter/diffuser un agent Anthropic avec l'utilisation d'outils (bash, git, web), attacher des référentiels GitHub ou injecter des secrets via Vault. Ne PAS utiliser pour l'API Claude Messages standard - utilisez plutôt la compétence API Claude.
