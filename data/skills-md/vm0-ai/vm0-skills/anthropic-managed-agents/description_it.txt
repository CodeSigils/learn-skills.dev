API Anthropic Managed Agents per la creazione, l'esecuzione e lo streaming di agenti AI in modo programmatico sull'infrastruttura cloud di Anthropic. Da utilizzare quando l'utente menziona "Agenti gestiti", "Sessioni dell'agente Anthropic" o deve creare/eseguire/trasmettere in streaming un agente Anthropic con l'uso di strumenti (bash, git, web), collegare repository GitHub o inserire segreti tramite Vault. NON utilizzare per l'API Claude Messages standard: utilizzare invece la competenza API Claude.
