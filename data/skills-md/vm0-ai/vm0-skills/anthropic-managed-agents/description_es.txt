API de agentes administrados de Anthropic para crear, ejecutar y transmitir agentes de IA mediante programación en la infraestructura de nube de Anthropic. Úselo cuando el usuario mencione "Agentes administrados", "sesiones de agente Anthropic" o necesite crear/ejecutar/transmitir un agente Anthropic con el uso de herramientas (bash, git, web), adjuntar repositorios de GitHub o inyectar secretos a través de Vault. NO lo use para la API estándar de Claude Messages; en su lugar, use la habilidad Claude API.
