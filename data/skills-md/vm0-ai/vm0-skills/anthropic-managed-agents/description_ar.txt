Anthropic Managed Agents API لإنشاء وكلاء الذكاء الاصطناعي وتشغيلهم وتدفقهم برمجيًا على البنية التحتية السحابية لـ Anthropic. يُستخدم عندما يذكر المستخدم "الوكلاء المُدارين"، أو "جلسات الوكيل الإنساني"، أو يحتاج إلى إنشاء/تشغيل/بث وكيل إنساني باستخدام الأداة (bash، git، web)، أو إرفاق مستودعات GitHub، أو إدخال الأسرار عبر Vault. لا تستخدم واجهة برمجة تطبيقات رسائل Claude القياسية - استخدم مهارة واجهة برمجة تطبيقات Claude بدلاً من ذلك.
