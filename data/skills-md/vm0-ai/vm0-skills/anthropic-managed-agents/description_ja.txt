Anthropic のクラウド インフラストラクチャ上で AI エージェントをプログラム的に作成、実行、ストリーミングするための Anthropic マネージド エージェント API。ユーザーが「管理対象エージェント」、「Anthropic エージェント セッション」に言及する場合、またはツール (bash、git、Web) を使用して Anthropic エージェントを作成/実行/ストリーミングする必要がある場合、GitHub リポジトリをアタッチする必要がある場合、または Vault 経由でシークレットを挿入する必要がある場合に使用します。標準の Claude Messages API には使用しないでください。代わりに Claude API スキルを使用してください。
