Vérifiez la qualité d'une analyse de données avant de la partager : vérifiez les jointures, les agrégations, les dénominateurs, les plages de temps et les définitions de métriques. Détectez les pièges tels que les biais de survie, les moyennes des moyennes, les explosions de jointures, les décalages horaires, les périodes incomplètes et les biais de sélection. Comprend des modèles de documentation pour des analyses reproductibles.
