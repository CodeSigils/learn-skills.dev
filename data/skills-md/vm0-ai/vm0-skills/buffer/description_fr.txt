API Buffer pour la planification des publications sur les réseaux sociaux et la gestion des canaux. À utiliser lorsque l'utilisateur mentionne « Buffer », « bufferapp », « programmer la publication », « la file d'attente des réseaux sociaux », « cross-post » ou gérer les publications Twitter/X, LinkedIn, Instagram, Facebook, TikTok, Threads, Mastodon, Bluesky, Pinterest, YouTube ou Google Business via Buffer.
