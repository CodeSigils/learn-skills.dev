API Buffer pour la planification des publications sur les réseaux sociaux et la gestion des canaux. À utiliser lorsque l'utilisateur mentionne « Buffer », « bufferapp », « publication programmée », « file d'attente des réseaux sociaux », « publication croisée » ou gère les publications Twitter/X, LinkedIn, Instagram, Facebook, TikTok, Threads, Mastodon, Bluesky, Pinterest, YouTube ou Google Business via Buffer.
