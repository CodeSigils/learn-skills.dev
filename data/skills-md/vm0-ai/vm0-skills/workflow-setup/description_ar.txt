قم بإعداد وإدارة عمليات سير العمل الصفرية وأتمتة سير العمل من خلال Zero CLI. يُستخدم عندما يطلب المستخدم إنشاء سير عمل أو تشغيل تلقائي أو تحريره أو فحصه أو تشغيله أو جدولته أو تشغيله أو تمكينه أو تعطيله أو نسخه أو حذفه، أو يطلب المساعدة في إعداد سير العمل/المشغل. احتفظ بهذا الأمر بشكل عام لجميع أنواع مشغلات سير العمل؛ لا يتم تشغيلها إلا على موصل أو مصدر حدث معين.
