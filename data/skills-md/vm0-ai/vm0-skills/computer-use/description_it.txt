Gestisci le app desktop connesse dell'utente tramite Zero Computer Use. Da utilizzare quando un'attività richiede esplicitamente l'utilizzo pari a zero del computer, l'utilizzo di un computer desktop, l'apertura o l'ispezione di un'app locale, la lettura di una GUI, il clic su elementi dell'interfaccia utente, l'utilizzo di Slack/Safari/Chrome/Arc/Notion/Finder o un'altra app desktop, l'acquisizione di uno screenshot dell'app o l'esecuzione di un flusso di lavoro dell'interfaccia utente che non può essere completato solo tramite le normali API.
