Opere las aplicaciones de escritorio conectadas del usuario a través de Zero Computer Use. Úselo cuando una tarea solicite explícitamente no usar la computadora, usar una computadora de escritorio, abrir o inspeccionar una aplicación local, leer una GUI, hacer clic en elementos de la UI, usar Slack/Safari/Chrome/Arc/Notion/Finder u otra aplicación de escritorio, tomar una captura de pantalla de la aplicación o realizar un flujo de trabajo de UI que no se puede completar solo a través de API normales.
