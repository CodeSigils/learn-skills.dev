Utilisez les applications de bureau connectées de l'utilisateur via Zero Computer Use. À utiliser lorsqu'une tâche ne demande explicitement aucune utilisation de l'ordinateur, de l'utilisation d'un ordinateur de bureau, de l'ouverture ou de l'inspection d'une application locale, de la lecture d'une interface graphique, du clic sur des éléments de l'interface utilisateur, de l'utilisation de Slack/Safari/Chrome/Arc/Notion/Finder ou d'une autre application de bureau, de la prise d'une capture d'écran d'une application ou de l'exécution d'un flux de travail d'interface utilisateur qui ne peut pas être réalisé uniquement via les API normales.
