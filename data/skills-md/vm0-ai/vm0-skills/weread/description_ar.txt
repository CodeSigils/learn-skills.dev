WeRead (微信读书) API للبحث عن الكتب، وتصفح رف الكتب الخاص بك، وقراءة الملاحظات، والميزات، والمراجعات، وقراءة الإحصاءات. يُستخدم عندما يذكر المستخدم "WeRead" أو "微信读书" أو "WeChat Reading" أو "weread.qq.com" أو "我的书架" أو "阅读时长" أو "划线" أو "读书笔记"، أو يطلب البحث في مكتبة WeRead أو التحقق من تقدم القراءة أو تصدير النقاط البارزة أو الحصول على توصيات كتب مخصصة.
