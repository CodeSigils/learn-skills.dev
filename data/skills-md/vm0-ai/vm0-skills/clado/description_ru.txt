API Clado для поиска людей на естественном языке в стиле LinkedIn, глубоких асинхронных исследований и обогащения контактов. Используйте, когда пользователь упоминает «Кладо», «поиск людей», «найти профиль LinkedIn», «найти электронное письмо» или хочет получить целевые списки потенциальных клиентов из структурированного запроса.
