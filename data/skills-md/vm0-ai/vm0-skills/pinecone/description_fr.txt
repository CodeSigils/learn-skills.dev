API de base de données vectorielles Pinecone pour le stockage, l'interrogation et la gestion des intégrations vectorielles. À utiliser lorsque l'utilisateur mentionne « Pinecone », « base de données vectorielles », « recherche de vecteurs », « recherche sémantique », « intégrations », « recherche de similarité », « vecteurs d'insertion » ou « index ».
