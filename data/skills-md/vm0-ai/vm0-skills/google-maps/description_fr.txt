API Google Maps Platform pour les requêtes de géocodage, de lieux, d'itinéraires et de matrice d'itinéraire basées sur OAuth. À utiliser lorsque l'utilisateur mentionne « Google Maps », « géocode », « directions », « API lieux », matrice d'itinéraire ou demande de rechercher une adresse, un itinéraire ou des métadonnées de lieu.
