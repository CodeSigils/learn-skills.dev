Железнодорожный API GraphQL с токеном на уровне проекта для автоматизации с привязкой к среде — повторное развертывание, чтение статуса развертывания, управление переменными внутри одного проекта/среды. Используйте, когда пользователь хочет, чтобы доступ к железной дороге был ограничен одним проектом, или упоминает «токен проекта железной дороги» или «токен доступа к проекту».
