Faire API externe pour les opérations de marque en gros, y compris les produits, les commandes, les stocks, les expéditions, les bons de livraison et les données des détaillants. À utiliser lorsque l'utilisateur mentionne « Faire », « marché de gros », « commandes de marque », « inventaire de produits » ou les flux de travail de vente en gros de détaillants indépendants.
