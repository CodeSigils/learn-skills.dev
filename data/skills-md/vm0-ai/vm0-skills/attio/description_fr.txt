API Attio REST pour les opérations CRM natives d'IA : gérez les entreprises, les personnes, les transactions et les objets personnalisés, ainsi que les notes, les tâches, les listes et les commentaires. À utiliser lorsque l'utilisateur mentionne « Attio », « Enregistrement CRM », « Créer une société », « Ajouter une personne », « Entrée de liste », « Note CRM » ou « Tâche CRM ».
