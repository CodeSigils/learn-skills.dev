Attio REST API لعمليات إدارة علاقات العملاء المستندة إلى الذكاء الاصطناعي - إدارة الشركات والأشخاص والصفقات والكائنات المخصصة، بالإضافة إلى الملاحظات والمهام والقوائم والتعليقات. يُستخدم عندما يذكر المستخدم "Attio" أو "سجل CRM" أو "إنشاء شركة" أو "إضافة شخص" أو "إدخال القائمة" أو "ملاحظة CRM" أو "مهمة CRM".
