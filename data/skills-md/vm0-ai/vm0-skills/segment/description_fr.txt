API publique de segmentation pour la configuration de la plateforme de données client, y compris les sources, les destinations, les entrepôts, les plans de suivi, les mesures de livraison et l'administration de l'espace de travail. À utiliser lorsque l'utilisateur mentionne « Segment », « Segment Twilio », « CDP », « sources », « destinations », « plans de suivi » ou configuration du pipeline de données.
