API Cursor Cloud Agents для запуска и управления агентами фонового кодирования. Используйте, когда пользователь упоминает «Курсор», «Агенты курсора», «Фоновые агенты курсора», «облачные агенты», «cursor.com» или хочет запустить, отслеживать, отслеживать или отменить автономный агент кодирования в репозитории GitHub.
