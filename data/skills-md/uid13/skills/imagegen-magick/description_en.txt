Generate or edit vector/procedural images (blog covers, logos, charts, badges, UI components, PPT covers, social media images, etc.). Use when users need to generate design-oriented images based on templates/parameters with precise typography, font control, and size constraints. Uses SVG authoring + ImageMagick rendering. Not suitable for photo‑realistic, complex textures, portraits, and other scenarios requiring generative models (please use imagegen‑type skills instead). Compatible with Agent platforms such as opencode, codex, Claude Code, Cursor, Copilot, Gemini CLI, etc.
