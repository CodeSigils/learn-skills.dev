Traduisez le jargon technique, les concepts de code ou les textes d'ingénierie denses en un langage simple qu'un collègue ou un responsable non technique peut suivre. À utiliser lorsque l'utilisateur demande « d'expliquer en langage clair », « 白話文 », « 翻成人話 », « 用白話解釋 », « expliquer comme si j'étais un PM », « rendre cela non technique », « simplifier ce terme », « que signifie ce terme », ou colle un texte technique et demande une version destinée au public professionnel, ou vous demande de réviser/vérifier si un langage clair existant le brouillon est destiné à un lecteur non technique ("這樣夠白話嗎", "幫我看 非技術主管看不看得懂", "est-ce assez clair pour un PM"). Répondez dans la langue dans laquelle l'utilisateur a écrit. N'invoquez PAS pour supprimer les IA-ismes / 潤飾語氣 de la prose existante (utilisez évite-ai-writing-zh), pour structurer l'ensemble d'un document commercial formel - 簽呈/會議紀錄/報告 (utilisez la structure formelle-doc), ou pour un RFP / 需求規格書 /招標規格 (utilisez la rédaction de RFP). Cette compétence diminue l'audience, et non la voix, la structure ou le type de document.
