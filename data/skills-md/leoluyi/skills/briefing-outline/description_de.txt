Schreiben von 說明提綱 (Briefing-Übersichten) – Destillieren Sie detailliertes Quellenmaterial zu einem umfassenden Überblick, der jedem Teil seinen Zweck und sein Wesen darlegt und dann auf die Details hinweist. Es kommt nicht auf die Quellenzählung an: Sie gilt für mehrere Dokumente oder einen langen Bericht (wobei auf die einzelnen Abschnitte verwiesen wird). Verwenden Sie diese Option, wenn der Benutzer eine oder mehrere Quellen in einem navigierbaren Briefing für eine 主管 oder 委員會 zusammenfassen, einen langen Bericht in einer Höhenübersicht zusammenfassen möchte, die für Details nach unten zeigt, oder eine vorhandene Quelle erneut synchronisieren möchte, nachdem sich ihre Quellen geändert haben. Rufen Sie NICHT auf, um ein einzelnes formales Dokument von Grund auf zu verfassen – 簽呈/會議紀錄/報告/專案規劃 (verwenden Sie formal-doc-structure), für RFP / 需求規格書 / 招標規格 (verwenden Sie rfp-writing), um einen Begriff oder eine Passage auf einen zu reduzieren für nicht-technisches Publikum (verwenden Sie Klartext) oder zur reinen Sprachbereinigung (verwenden Sie „avoid-ai-writing-zh“). Diese Fähigkeit liegt über dem Quellmaterial und weist in jeden Teil hinein.
