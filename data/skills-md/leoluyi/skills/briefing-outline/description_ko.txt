說明提綱(브리핑 개요) 쓰기 — 자세한 소스 자료를 각 부분의 목적과 본질을 제공하는 하나의 높은 개요로 추출한 다음 세부 사항을 지적합니다. 소스 수는 중요하지 않습니다. 여러 문서 또는 하나의 긴 보고서(해당 섹션을 가리키는)에 대해 작동합니다. 사용자가 整理/撰寫一份說明提綱, 하나 이상의 소스를 주요 또는 委員會에 대한 탐색 가능한 브리핑으로 압축하거나, 긴 보고서를 세부 사항을 가리키는 높은 고도의 개요로 요약하거나, 소스가 변경된 후 기존 提綱을 다시 동기화하려는 경우에 사용합니다. 하나의 공식 문서를 처음부터 작성하도록 호출하지 마십시오 — 簽呈/會議紀錄/報告/專案規劃(정식 문서 구조 사용), RFP의 경우 / 需求規格書 / 招標規格(rfp-writing 사용), 기술 지식이 없는 청중에게 한 용어나 구절을 낮추는 경우 (평범하게 사용) 또는 순수 언어 정리를 위해 (avoid-ai-writing-zh 사용). 이 기술은 원본 자료 위에 위치하며 각 부분을 가리킵니다.
