Diseñe gráficos explicativos profesionales y pulidos como SVG o HTML de un solo archivo. Úselo cuando el usuario solicite una infografía, 資訊圖表, 懶人包, 圖解, una página, un resumen visual o un gráfico de línea de tiempo/comparación/proceso ("cómo funciona"), incluso sin la palabra "infografía", y para revisar uno existente ("幫我看這張圖表哪裡").可以改"). Úselo para un resumen del aprendizaje cuando finaliza un diálogo de enseñanza ("學習總結成一張圖", "resumen visual de lo que me enseñó"); esa ruta no necesita más indicaciones. Úselo también cuando otra habilidad necesite una figura diseñada para un documento que está produciendo. NO lo invoque para un único gráfico independiente integrado en la salida del análisis, para paneles/herramientas de BI, para presentaciones de diapositivas (use un flujo de trabajo pptx), para explicar un término en lenguaje sencillo (use lenguaje sencillo) o para gráficos con gran densidad de datos donde los números son en sí mismos el tema o las escalas precisas importan (presentaciones de resultados anuales, hallazgos de encuestas, gráficos estadísticos); entréguelos a un flujo de trabajo de visualización de datos. Una solicitud explícita de una infografía / 資訊圖表 / 懶人包 / de una página siempre califica incluso cuando los datos subyacentes son precisos; la exclusión de densidad de datos se aplica solo cuando el usuario nombra un gráfico, gráfico o panel. Las cantidades que sirven como evidencia dentro de una explicación (la caída de un embudo, una tasa de aciertos de caché) permanecen dentro del alcance.
