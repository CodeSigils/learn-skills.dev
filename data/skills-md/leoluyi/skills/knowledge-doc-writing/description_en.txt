Organize the results of self‑studying or researching a technical topic into a knowledge document that contains four clearly separated Diátaxis sections—tutorial (getting started), how‑to (complete a task step by step), reference (look up parameters and structures), explanation (What/Why discussion and trade‑off decisions); use the two‑question compass to route each piece of material to the appropriate section. Only write material that can stand on its own; explicitly list as gaps any types that cannot be supported (e.g., topics researched but not implemented often lack tutorial/how‑to). Do not fabricate or produce empty shells (Traditional Chinese as the primary language, technical terms kept in English).

Trigger: the user wants to digest conversation logs, official documents or source material, or a topic researched from scratch (mandating verification of primary sources and marking the “as‑of” date) into a technical document suitable for long‑term reference; or rewrite an existing technical document—split according to intent: update timeliness / merge new material → spot‑patch while preserving the original shape; restructure / refactor → rebuild the four sections according to the compass. This can follow the learn‑loop: the learn component handles the interactive learning cycle and hands‑on distillation (golden rule: distillation is learning itself, not ghostwriting); this skill only takes over after distillation is complete to reorganize, fill in reader context, and perform final copy‑editing.

Do not use for internal company memos, meeting minutes, evaluation reports, or other administrative documents (use formal‑doc‑structure; even if the input is an existing document it should not be routed to this skill), RFP/tender specifications (use rfp‑writing), blog posts (use blog‑writing‑zh), tasks that only adjust language to add an “AI flavor” without changing structure (use avoid‑ai‑writing‑zh), purely spoken, informal explanations that do not produce a document (use plain‑speak), or the interactive learning loop itself (use learn‑loop).
