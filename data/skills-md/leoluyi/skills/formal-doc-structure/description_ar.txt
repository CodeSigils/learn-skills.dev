صياغة أو مراجعة أو إعادة هيكلة مستندات العمل الداخلية الرسمية باللغة الصينية التقليدية (استخدام الشركات / المؤسسات المالية في تايوان) — 簽呈, 會議紀錄, 評估報告, 專案規劃, 採購與廠商溝通,對主管簡報, 驗收與交付, 跨單位協調. يختار بنية تعتمد على القارئ لكل نوع مستند وينتج مسودة قابلة للاستخدام، وليس مجرد نصيحة. يتم تشغيله عندما يطلب المستخدم كتابة أو إصلاح مستند عمل داخلي أو مذكرة أو تقرير أو سجل اجتماع أو خطة أو اتصال بالمورد. لا تستدعي طلب تقديم العروض / 招標規格 / 需求規格書 (استخدم كتابة طلب تقديم العروض)، أو لتنظيف اللغة الخالصة دون أي عمل هيكلي (استخدم تجنب الكتابة بالذكاء الاصطناعي / الكتابة النظيفة بالذكاء الاصطناعي)، أو للدردشة غير الرسمية أو الكتابة الإبداعية أو النسخ التسويقية أو تعليقات التعليمات البرمجية.
