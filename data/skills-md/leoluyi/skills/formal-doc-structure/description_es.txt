Redactar, revisar o reestructurar documentos comerciales internos formales en chino tradicional (uso corporativo/de instituciones financieras de Taiwán): 簽呈, 會議紀錄, 評估報告, 專案規劃, 採購與廠商溝通, 對主管簡報,驗收與交付, 跨單位協調. Elige una estructura basada en el lector por tipo de documento y produce un borrador utilizable, no solo un consejo. Se activa cuando el usuario solicita escribir o corregir un documento comercial interno, una nota, un informe, un registro de reunión, un plan o una comunicación con el proveedor. NO invoque para RFP / 招標規格 / 需求規格書 (use escritura rfp), para limpieza de lenguaje puro sin trabajo estructural (use evitar-ai-writing / clean-ai-writing) o para charlas informales, escritura creativa, textos de marketing o comentarios de código.
