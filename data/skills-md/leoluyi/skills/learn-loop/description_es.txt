El ciclo de aprendizaje estructurado de Leo (primero enseñar, luego probar + verificación de fuente) refina un nuevo concepto hasta convertirlo en un cristal de conocimiento en una bóveda de obsidiana. Solo se activa cuando Leo lo llama explícitamente (Claude Code `/learn-loop`, Codex `$learn-loop`, o dice explícitamente “ejecutar el proceso de aprendizaje-loop para aprender X”); no debe activarse automáticamente sólo porque la conversación mencione el deseo de comprender algo; esto es intencional e implica un proceso interactivo de seis pasos que ocupa un segmento completo de la conversación.
