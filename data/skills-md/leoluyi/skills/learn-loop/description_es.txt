El ciclo de aprendizaje estructurado de Leo (enseñar primero, luego probar+verificación de fuente) refina un nuevo concepto en un cristal de conocimiento para una bóveda de obsidiana. Solo se activa cuando Leo lo invoca explícitamente (Claude Code `/learn-loop`, Codex `$learn-loop`, o dice explícitamente “ejecutar el proceso de aprendizaje-loop para aprender X”); no debe activarse automáticamente sólo porque la conversación mencione el deseo de comprender algo; esto es deliberado e implica un proceso interactivo de seis pasos que ocupa todo el diálogo.
