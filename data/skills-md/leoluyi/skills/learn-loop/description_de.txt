Leos strukturierte Lernschleife (zuerst lehren, dann testen + Quellenüberprüfung) verfeinert ein neues Konzept zu einem Wissenskristall in einem Obsidian-Tresor. Es wird nur aktiviert, wenn Leo es explizit aufruft (Claude Code „/learn-loop“, Codex „$learn-loop“ oder explizit sagt „Führen Sie den Lernschleifenprozess aus, um X zu lernen“); Es sollte nicht automatisch ausgelöst werden, nur weil in einem Gespräch der Wunsch erwähnt wird, etwas zu verstehen – es handelt sich um eine bewusste sechsstufige Interaktion, die einen ganzen Abschnitt des Dialogs einnimmt.
