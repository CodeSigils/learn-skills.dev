Générez des notes de version lisibles par l'homme à partir de l'historique Git et des PR fusionnés. Crée deux versions : destinée à l'utilisateur (les nouveautés en langage clair) et destinée aux développeurs (format conventionnel du journal des modifications). Publie en tant que brouillon de version GitHub avec une suggestion automatique de semver. À utiliser lorsque vous préparez une version, souhaitez documenter ce qui a changé depuis la dernière balise ou devez écrire des entrées CHANGELOG. Se déclenche sur : "リリースノート", "changelog", "release notes", "何が変わった", "バージョンアップ", "release-notes". NE PAS UTILISER POUR : créer une nouvelle balise git, déployer en production.
