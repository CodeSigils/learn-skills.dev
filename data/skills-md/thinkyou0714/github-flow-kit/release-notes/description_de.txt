Generieren Sie für Menschen lesbare Versionshinweise aus dem Git-Verlauf und zusammengeführten PRs. Erstellt zwei Versionen: für den Benutzer (was ist neu im Klartext) und für den Entwickler (herkömmliches Changelog-Format). Veröffentlicht als GitHub-Release-Entwurf mit automatisch vorgeschlagenem Semver-Bump. Verwenden Sie diese Option, wenn Sie eine Veröffentlichung vorbereiten, dokumentieren möchten, was sich seit dem letzten Tag geändert hat, oder CHANGELOG-Einträge schreiben müssen. Wird ausgelöst durch: „Änderungsprotokoll“, „Versionshinweise“, „Versionshinweise“, „Versionshinweise“. NICHT VERWENDEN FÜR: Erstellen eines neuen Git-Tags, Bereitstellen in der Produktion.
