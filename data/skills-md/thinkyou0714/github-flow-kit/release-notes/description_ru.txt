Создавайте удобочитаемые примечания к выпуску на основе истории git и объединенных PR. Создает две версии: для пользователей (что нового на простом языке) и для разработчиков (традиционный формат журнала изменений). Публикуется в виде черновика выпуска GitHub с автоматически предлагаемым изменением. Используйте, когда вы готовите выпуск, хотите задокументировать, что изменилось с момента последнего тега, или вам нужно записать записи CHANGELOG. Запускается по: «リリースノート», «журнал изменений», «примечания к выпуску», «何が変わった», «バージョンアップ», «примечания к выпуску». НЕ ИСПОЛЬЗУЙТЕ ДЛЯ: создания нового тега git, развертывания в рабочей среде.
