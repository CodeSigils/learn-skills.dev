Genere notas de la versión legibles por humanos a partir del historial de git y relaciones públicas fusionadas. Crea dos versiones: orientada al usuario (novedades en lenguaje sencillo) y orientada al desarrollador (formato de registro de cambios convencional). Se publica como un borrador de versión de GitHub con un aumento de semver sugerido automáticamente. Úselo cuando esté preparando una versión, desee documentar los cambios desde la última etiqueta o necesite escribir entradas de CHANGELOG. Activadores en: "リリースノート", "changelog", "release notes", "何が変わった", "バージョンアップ", "release-notes". NO UTILIZAR PARA: crear una nueva etiqueta git, implementarla en producción.
