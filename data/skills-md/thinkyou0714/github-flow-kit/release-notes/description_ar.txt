قم بإنشاء ملاحظات إصدار يمكن قراءتها بواسطة الإنسان من سجل git والعلاقات العامة المدمجة. ينشئ نسختين: واجهة المستخدم (الجديد في اللغة البسيطة) وواجهة المطور (تنسيق سجل التغيير التقليدي). يتم النشر كمسودة إصدار GitHub مع نتوء نصف مقترح تلقائيًا. استخدمه عندما تقوم بإعداد إصدار، أو تريد توثيق ما تغير منذ العلامة الأخيرة، أو تحتاج إلى كتابة إدخالات سجل التغيير. تشغيل: "リリスノトト" و"سجل التغيير" و"ملاحظات الإصدار" و"何が変わった" و"バージョンアップ" و"ملاحظات الإصدار". لا تستخدم من أجل: إنشاء علامة git جديدة، ونشرها في الإنتاج.
