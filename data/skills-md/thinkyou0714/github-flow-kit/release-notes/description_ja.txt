git 履歴とマージされた PR から人間が判読できるリリース ノートを生成します。ユーザー向け (平易な言語での新機能) と開発者向け (従来の変更ログ形式) の 2 つのバージョンを作成します。自動提案されたセムバー バンプを含む GitHub リリース ドラフトとして公開されます。リリースを準備している場合、最後のタグ以降に何が変更されたかを文書化したい場合、または CHANGELOG エントリを作成する必要がある場合に使用します。トリガー: 「リリースノート」、「変更ログ」、「リリースノート」、「変わった」、「バージョンアップ」、「リリースノート」。新しい git タグの作成、運用環境へのデプロイには使用しないでください。
