Genera note di rilascio leggibili dall'uomo dalla cronologia git e dai PR uniti. Crea due versioni: rivolta all'utente (novità in linguaggio semplice) e rivolta agli sviluppatori (formato convenzionale del registro delle modifiche). Pubblica come bozza di rilascio di GitHub con un bump del semver suggerito automaticamente. Utilizzalo quando stai preparando una versione, vuoi documentare cosa è cambiato dall'ultimo tag o hai bisogno di scrivere voci CHANGELOG. Si attiva su: "リリースノート", "changelog", "release notes", "何が変わった", "バージョンアップ", "release-notes". NON UTILIZZARE PER: creazione di un nuovo tag git, distribuzione in produzione.
