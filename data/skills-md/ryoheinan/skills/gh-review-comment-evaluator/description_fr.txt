Évaluez les commentaires de révision des demandes d’extraction GitHub et décidez s’ils doivent être corrigés. À utiliser lorsque l'utilisateur fournit une URL de demande d'extraction GitHub et demande d'inspecter les commentaires de révision, de résumer les commentaires exploitables, de juger si chaque commentaire est obligatoire ou facultatif, de vérifier si les commentaires sont déjà résolus ou de décider quoi implémenter ensuite. Si l'utilisateur souhaite appliquer des correctifs, créez un plan de mise en œuvre avant d'apporter des modifications au code et suivez les instructions du référentiel cible.
