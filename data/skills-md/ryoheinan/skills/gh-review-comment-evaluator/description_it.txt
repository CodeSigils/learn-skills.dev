Valuta i commenti di revisione delle richieste pull di GitHub e decidi se devono essere corretti. Da utilizzare quando l'utente fornisce un URL di richiesta pull GitHub e chiede di ispezionare i commenti di revisione, riepilogare il feedback utilizzabile, giudicare se ciascun commento è da correggere o facoltativo, verificare se il feedback è già stato risolto o decidere cosa implementare successivamente. Se l'utente desidera applicare correzioni, creare un piano di implementazione prima di apportare modifiche al codice e seguire le istruzioni del repository di destinazione.
