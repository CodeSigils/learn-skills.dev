قم بتقييم تعليقات مراجعة طلب السحب لـ GitHub وحدد ما إذا كان يجب إصلاحها أم لا. يُستخدم عندما يقدم المستخدم عنوان URL لطلب سحب GitHub ويطلب فحص تعليقات المراجعة، أو تلخيص التعليقات القابلة للتنفيذ، أو الحكم على ما إذا كان كل تعليق ضروريًا أو اختياريًا، أو التحقق مما إذا كانت التعليقات قد تم حلها بالفعل، أو تحديد ما سيتم تنفيذه بعد ذلك. إذا أراد المستخدم تطبيق الإصلاحات، فقم بإنشاء خطة تنفيذ قبل إجراء تغييرات على التعليمات البرمجية واتبع تعليمات المستودع المستهدف.
