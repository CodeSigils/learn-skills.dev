Evalúe los comentarios de revisión de solicitudes de extracción de GitHub y decida si deben corregirse. Úselo cuando el usuario proporciona una URL de solicitud de extracción de GitHub y solicita inspeccionar los comentarios de revisión, resumir los comentarios procesables, juzgar si cada comentario es obligatorio u opcional, verificar si los comentarios ya están resueltos o decidir qué implementar a continuación. Si el usuario desea aplicar correcciones, cree un plan de implementación antes de realizar cambios en el código y siga las instrucciones del repositorio de destino.
