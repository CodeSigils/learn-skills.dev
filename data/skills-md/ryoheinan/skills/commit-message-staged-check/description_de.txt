Entwurf von Commit-Nachrichtenvarianten im herkömmlichen Commits-Stil, nur aus dem aktuell bereitgestellten Diff. Wird verwendet, wenn ein Benutzer nach einer Commit-Nachricht fragt. Überprüfen Sie bereitgestellte Änderungen, führen Sie niemals einen Commit durch, stellen Sie sowohl Nur-Subjekt- als auch Subjekt-plus-Körper-Versionen bereit und vermeiden Sie numerische Angaben, es sei denn, es handelt sich dabei um die Änderung selbst.
