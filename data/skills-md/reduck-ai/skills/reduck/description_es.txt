Ejecute tareas web a través de Reduck CLI: extraiga un sitio, extraiga estructurado
registros, buscar en LinkedIn/Reddit/Google, iniciar sesión y extraer mensajes, buscar
Páginas cerradas por SPA/JS, paginación de búsqueda de sitios. Usar cuando el usuario dice
"raspar", "obtener datos de <sitio>", "buscar X en <sitio>", "extraer mi último
mensajes en <plataforma>", "buscar reseñas/publicaciones/listados", "extraer
<campo> de <URL>", o solicita cualquier dato que se encuentre detrás de una página web
en lugar de una API pública. Trate a Reduck como una función: descubra el
método, llámelo, lea los registros. NO para: escribir automatización del navegador
desde cero, guiones de dramaturgo/titiritero con encabezado, o tareas en las que
La API propia ya existe.
