Exécutez des tâches Web via la CLI Reduck : grattez un site, extrayez des éléments structurés
enregistrements, recherchez LinkedIn/Reddit/Google, connectez-vous et extrayez des messages, récupérez
Pages fermées SPA/JS, pagination de recherche sur site. À utiliser lorsque l'utilisateur dit
"scrape", "obtenir des données de <site>", "rechercher X sur <site>", "extraire mes dernières
messages sur <plateforme>", "rechercher des avis/posts/listes", "extraire
<field> from <URL>", ou demande toutes les données qui se trouvent derrière une page Web
plutôt qu'une API publique. Traitez Reduck comme une fonction : découvrez le
méthode, appelez-la, lisez les enregistrements. PAS pour : écrire l'automatisation du navigateur
à partir de zéro, des scripts de dramaturge/marionnettiste intitulés ou des tâches où un
L'API propriétaire existe déjà.
