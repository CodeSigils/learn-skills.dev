Запускайте веб-задачи через Reduck CLI: очищайте сайт, извлекайте структурированные
записи, поиск в LinkedIn/Reddit/Google, вход в систему и получение сообщений, получение
Страницы с поддержкой SPA/JS, постраничный поиск по сайту. Используйте, когда пользователь говорит
"очистить", "получить данные с <сайта>", "найти на <сайте> X", "получить последние
сообщения на <платформе>", "поиск отзывов/публикаций/объявлений", "извлечь
<поле> из <URL>» или запрашивает любые данные, находящиеся за веб-страницей.
а не общедоступный API. Относитесь к Reduck как к функции: откройте для себя
метод, вызываем его, читаем записи. НЕ для: написания автоматизации браузера
с нуля, возглавляемые сценарии драматурга/кукловода или задачи, где
собственный API уже существует.
