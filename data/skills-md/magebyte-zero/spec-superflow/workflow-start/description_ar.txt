نقطة الدخول الأساسية لسير عمل آلة الحالة ذات التدفق الفائق. يتم الاستدعاء عندما يكون المستخدم داخل دليل تغيير المواصفات فائق التدفق النشط (ابحث عن .spec-superflow.yaml أو التغييرات/<name>/ أو الاقتراح.md أو المواصفات/ أو design.md أو المهام.md أو Execution-contract.md) ويطلب البدء أو المتابعة أو الاستئناف أو التنفيذ أو التخطيط أو معرفة خطوة سير العمل التالية. يتم الاستدعاء أيضًا عندما يطلب المستخدم صراحةً بدء تغيير جديد للتدفق الفائق للمواصفات أو التوجيه عبر سير عمل التدفق الفائق للمواصفات. لا تستدعي مهام الترميز غير ذات الصلة التي تحدث لاستخدام كلمات مثل البدء أو المتابعة أو التنفيذ أو التخطيط.
