Configure sqlc para generar una capa de acceso a datos TypeScript para PostgreSQL con tylergannon/sqlc-gen-typescript y postgres.js. Úselo cuando un agente necesita agregar o reparar sqlc.yaml/sqlc.yml, generar envoltorios de consultas DAL, elegir opciones de complemento, conectar el tiempo de ejecución de postgres.js, manejar detalles del dialecto de PostgreSQL o configurar anulaciones/convertidores de tipos para este generador.
