Configurez sqlc pour générer une couche d'accès aux données TypeScript pour PostgreSQL avec tylergannon/sqlc-gen-typescript et postgres.js. À utiliser lorsqu'un agent doit ajouter ou réparer sqlc.yaml/sqlc.yml, générer des wrappers de requête DAL, choisir les options du plugin, câbler le runtime postgres.js, gérer les détails du dialecte PostgreSQL ou configurer les remplacements/convertisseurs de type pour ce générateur.
