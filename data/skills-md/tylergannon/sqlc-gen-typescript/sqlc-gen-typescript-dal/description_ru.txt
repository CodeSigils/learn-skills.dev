Настройте sqlc для создания уровня доступа к данным TypeScript для PostgreSQL с помощью tylergannon/sqlc-gen-typescript и postgres.js. Используйте, когда агенту необходимо добавить или исправить sqlc.yaml/sqlc.yml, создать оболочки запросов DAL, выбрать параметры плагина, подключить среду выполнения postgres.js, обработать детали диалекта PostgreSQL или настроить переопределения/преобразователи типов для этого генератора.
