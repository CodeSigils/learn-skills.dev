Aplique correcciones de un informe /age, lista de hallazgos o falla de CI, luego ejecute las puertas de prueba/lint/compilación existentes del proyecto. Úselo cuando el usuario quiera que se resuelvan los elementos seleccionados: frases como "arreglar estos hallazgos", "/cure <slug>", "abordar los elementos de alta gravedad", "actuar según el informe de antigüedad", "arreglar el CI defectuoso", "aplicar la limpieza". Carga el informe, activa la selección explícita de usuarios, aplica correcciones específicas mediante cheez-write y produce un resumen listo para su envío. Admite `--auto --stake <floor>` (propagado desde `/cook --auto`; `--stake` es un nivel de gravedad por hallazgo: `blocker`, `high`, `medium+` o `all`) para la cadena autónoma (consulte `## Modo automático`). Úselo incluso cuando el usuario simplemente diga "arreglarlo" si un informe de revisión o una lista de hallazgos están dentro del alcance. La selección predeterminada está vacía; nunca aplique todo implícitamente. Después de `/edad`; vuelve a `/age --scope <touched-path>` para volver a revisarlo o pasa a `/gh` para enviar.
