Metakognitives Vibecheck-Gate, bevor Code zur Überprüfung freigegeben wird – lassen Sie den Autor die kausale Logik des Diffs erläutern, die von einem Richter im neuen Kontext anhand der SOLO-Taxonomie bewertet wird. Verwenden Sie diese Option, wenn der Benutzer dieses Gate wünscht – Ausdrücke wie „/hard-cheese“, „/cheese --hard“, „gate this before I push“, „vibecheck me“, „stellen Sie sicher, dass ich diesen Unterschied verstehe“, „epistemic-debt check“. Liest den Arbeitsunterschied, bittet den menschlichen Autor, ihn in eigenen Worten zu erklären, erzeugt den Judge-Subagenten (bestanden ≥ Multistrukturell) und akzeptiert entweder (PASS) oder gibt Socratic-Feedback für einen erneuten Versuch zurück (FAIL, begrenzt auf „--socratic-cap N“). Schreibt den Prüfpfad in „.cheese/hard/<slug>.md“. Verwenden Sie Standalone, bevor Sie eine PR öffnen, oder als propagiertes „--hard“-Flag auf „/cook“, „/press“, „/age“, „/cure“, damit das Gate bei der Freigabe zur Überprüfung ausgelöst wird. NICHT zur Codeüberprüfung (`/age`), Testhärtung (`/press`) oder Fixanwendung (`/cure`) verwenden – diese überprüfen das Artefakt; Hartkäse überprüft das menschliche Verständnis davon.
