Recherchieren Sie Fragen außerhalb der Codebasis in Bibliotheksdokumenten (Context7), im Web (Tavily), lokalem Code (cheez-search) und GitHub-Beispielen (gh) und synthetisieren Sie sie dann mit expliziter Sicherheit. Verwenden Sie diese Option immer dann, wenn der Benutzer etwas recherchieren, nachschlagen, vergleichen oder untersuchen möchte – Formulierungen wie „Recherche X“, „Suche die API für Y“, „Vergleiche Bibliotheken“, „Was sagt das Dokument zu Z“, „Finde Beispiele für die Vorgehensweise bei W“, „Wird diese Bibliothek gepflegt“ oder „Was ist der richtige Ansatz vor der Implementierung?“. Verwenden Sie dies auch dann, wenn der Benutzer nur einen Bibliotheksnamen erwähnt, ohne „Recherche“ zu sagen – im Zweifelsfall zuerst eine kurze Recherche durchführen, damit die Spezifikation oder Implementierung informiert und nicht spekulativ ist.
