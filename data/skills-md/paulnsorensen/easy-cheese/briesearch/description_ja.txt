ライブラリ ドキュメント (Context7)、Web (Tavily)、ローカル コード (cheez-search)、および GitHub サンプル (gh) にわたるコードベースの外部の質問を調査し、明示的な自信を持って合成します。ユーザーが何かを調べたり、調べたり、比較したり、調べたりするよう要求するときはいつでも使用します。たとえば、「X を調べてください」、「Y の API を調べてください」、「ライブラリを比較してください」、「Z についてドキュメントには何と書いてありますか」、「W の実行方法の例を見つけてください」、「このライブラリは保守されていますか」、または「実装する前に、正しいアプローチは何ですか」などのフレーズがあります。ユーザーが「研究」とは言わずにライブラリ名のみを言及する場合でも使用します。疑わしい場合は、最初に簡単に検索して、推測ではなく仕様や実装についての情報を得るようにします。
