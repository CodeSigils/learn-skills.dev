Recherchez des questions externes à la base de code dans les documents de la bibliothèque (Context7), le Web (Tavily), le code local (cheez-search) et les exemples GitHub (gh), puis synthétisez avec une confiance explicite. À utiliser chaque fois que l'utilisateur demande à rechercher, comparer ou enquêter sur quelque chose - des expressions telles que "rechercher X", "rechercher l'API pour Y", "comparer les bibliothèques", "que dit la documentation à propos de Z", "trouver des exemples de la façon de faire W", "cette bibliothèque est-elle maintenue" ou "avant de l'implémenter, quelle est la bonne approche". À utiliser même lorsque l'utilisateur mentionne uniquement le nom d'une bibliothèque sans dire « recherche » — en cas de doute, effectuez d'abord une brève recherche afin que la spécification ou l'implémentation soit informée et non spéculative.
