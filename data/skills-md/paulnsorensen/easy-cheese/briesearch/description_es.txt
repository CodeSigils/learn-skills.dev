Investigue preguntas externas al código base en documentos de la biblioteca (Context7), la web (Tavily), código local (cheez-search) y ejemplos de GitHub (gh), luego sintetice con confianza explícita. Úselo siempre que el usuario solicite investigar, buscar, comparar o investigar algo: frases como "investigar X", "buscar la API de Y", "comparar bibliotecas", "qué dice el documento sobre Z", "encontrar ejemplos de cómo hacer W", "se mantiene esta biblioteca" o "antes de implementar, cuál es el enfoque correcto". Úselo incluso cuando el usuario solo mencione el nombre de una biblioteca sin decir "investigación"; en caso de duda, primero realice una breve investigación para que la especificación o implementación esté informada, no sea especulativa.
