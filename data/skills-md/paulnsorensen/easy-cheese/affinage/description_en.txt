Triage a PR's review comments and failing CI (plus merge conflicts) through the /age lens, deciding which claims are worth acting on. Use when the user says "respond to PR comments", "handle review feedback", "affinage the PR", "/affinage <pr>", "address the reviewer comments", "fix the failing build", "resolve the conflicts and respond". Fetches inline + review-body comments via `gh` and CI failures via `affinage.pyz pr-status`, grades each through the ten age dimensions, and writes a report at `.cheese/affinage/pr-<n>.md`. Resolves merge conflicts via `/melt` and routes build/CI failures to fixes through `/cure`. When invoked standalone (no upstream `handoff_context` from `/cook` or `/cure`) it also runs `/age` over the PR diff and folds fresh findings into the report; when chained, it skips that pass and only refines existing claims. Hands off to `/cure`, then posts per-finding GitHub replies via `agent on behalf of;`. Supports `--auto --stake <floor>`. Before `/cure`; parallel to `/age`.
