Разрешение конфликтов слияния, перебазирования или выбора вишни с помощью каскада структурного слияния — mergiraf (автоматическое разрешение с поддержкой AST) → git rerere (воспроизведение запомненных исправлений) → kdiff3 (откат вручную). Используйте, когда конфликты существуют и пользователь хочет их разрешить — такие фразы, как «расплавить конфликты», «исправить конфликты слияния», «разрешить конфликты перебазирования», «что конфликтует после слияния», «/melt», «исправить выбор вишни» или любое приглашение, которое отображает маркеры `<<<<<<<`, вывод `CONFLICT (...)` git или незавершенное состояние слияния. Сначала проверяется наличие остатков сквош-слияния (перебазирование обречено на результат сквош-слияния PR — прерывание и повторный выбор), затем запускает каскад со вспомогательными сценариями для пакетного разрешения, выбора наших/их и регенерации файла блокировки. Используйте, даже если конфликтует только один файл, если пользователь хочет, чтобы перед ручным редактированием была предпринята попытка структурного прохода. НЕ используйте для общих операций git без конфликтов. После `/cook` или `/cure`, если шаг слияния заблокировал их; прежде чем повторить попытку открытия врат, вызвавших конфликт.
