Résolvez les conflits de fusion, de rebase ou de sélection sélective via une cascade de fusion structurelle - mergiraf (résolution automatique compatible AST) → git rerere (relecture des correctifs mémorisés) → kdiff3 (repli manuel). À utiliser lorsque des conflits existent et que l'utilisateur souhaite qu'ils soient résolus — des expressions telles que « faire fondre les conflits », « résoudre les conflits de fusion », « résoudre les conflits de rebase », « ce qui est en conflit après la fusion », « /melt », « corriger le choix » ou toute invite faisant apparaître les marqueurs `<<<<<<<`, la sortie git `CONFLICT (...)` ou un état de fusion à moitié terminé. Vérifie d'abord les résidus de fusion de squash (rebase condamné par un PR fusionné avec squash - abandon et re-cherry-pick), puis exécute la cascade avec des scripts d'aide pour la résolution par lots, nos/leurs sélections et la régénération du fichier de verrouillage. À utiliser même lorsqu'un seul fichier est en conflit si l'utilisateur souhaite tenter la passe structurelle avant l'édition manuelle. Ne PAS utiliser pour les opérations git générales sans conflits. Après `/cook` ou `/cure` si une étape de fusion les a bloqués ; avant de réessayer la porte qui a fait ressortir le conflit.
