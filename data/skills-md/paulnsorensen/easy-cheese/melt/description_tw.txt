透過結構合併級聯解決 git merge、rebase 或cherry-pick 衝突 —mergiraf（AST 感知自動解決）→ git rerere（重播記住的修復）→ kdiff3（手動回退）。當有衝突並且使用者希望解決衝突時使用 - 諸如“融化衝突”、“修復合併衝突”、“解決 rebase 衝突”、“合併後發生衝突的內容”、“/melt”、“修復櫻桃選擇”等短語，或任何顯示 `<<<<<<<<` 標記、`CONFLICT (...)` git 輸出或半完成合併狀態的提示。首先檢查擠壓合併殘留（由擠壓合併 PR 注定的變基 - 中止和重新挑選），然後使用輔助腳本運行級聯以進行批量解析、我們/他們的選擇和鎖定文件重新生成。如果使用者希望在手動編輯之前嘗試結構通道，即使只有一個檔案發生衝突也可以使用。如果沒有衝突，請勿用於一般 git 操作。在“/cook”或“/cure”之後，如果合併步驟阻止了它們；在重試出現衝突的門之前。
