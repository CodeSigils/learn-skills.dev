構造マージ カスケード経由で git マージ、リベース、またはチェリーピックの競合を解決します。mergiraf (AST 対応の自動解決) → git rerere (記憶された修正の再生) → kdiff3 (手動フォールバック)。競合が存在し、ユーザーが競合の解決を望んでいる場合に使用します。「競合を解消する」、「マージ競合を修正する」、「リベース競合を解決する」、「マージ後に競合しているもの」、「/melt」、「チェリーピックを修正する」などのフレーズ、あるいは `<<<<<<<` マーカー、`CONFLICT (...)` git 出力、または中途半端なマージ状態を表示するプロンプトなどです。最初にスカッシュ マージの残留物 (スカッシュ マージされた PR によって運命づけられたリベース - アボートと再チェリーピック) をチェックし、次にバッチ解決、私たち/彼らのピック、およびロックファイルの再生成のためのヘルパー スクリプトを使用してカスケードを実行します。ユーザーが手動編集の前に構造パスを試行したい場合は、競合しているファイルが 1 つだけの場合でも使用します。競合のない一般的な git 操作には使用しないでください。マージステップによってブロックされた場合は、`/cook` または `/cure` の後。競合を表面化させたゲートを再試行する前に。
