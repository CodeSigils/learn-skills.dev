Risolvi i conflitti git merge, rebase o cherry-pick tramite una cascata di unione strutturale: mergiraf (risoluzione automatica compatibile con AST) → git rerere (riproduci le correzioni ricordate) → kdiff3 (fallback manuale). Da utilizzare quando esistono conflitti e l'utente desidera che siano risolti: frasi come "sciogli i conflitti", "risolvi i conflitti di unione", "risolvi i conflitti di rebase", "cosa c'è in conflitto dopo l'unione", "/melt", "correggi la scelta selettiva" o qualsiasi prompt che emerga marcatori `<<<<<<<`, output git `CONFLICT (...)` o uno stato di fusione semifinito. Innanzitutto controlla i residui dell'unione dello squash (rebase condannato da un PR unito allo squash - interruzione e ri-cherry-pick), quindi esegue la cascata con script di supporto per la risoluzione batch, le nostre/loro scelte e la rigenerazione del file di blocco. Utilizzare anche quando un solo file è in conflitto se l'utente desidera che venga tentato il passaggio strutturale prima della modifica manuale. NON utilizzare per operazioni git generali senza conflitti. Dopo "/cook" o "/cure" se un passaggio di unione li ha bloccati; prima di riprovare il cancello che ha fatto emergere il conflitto.
