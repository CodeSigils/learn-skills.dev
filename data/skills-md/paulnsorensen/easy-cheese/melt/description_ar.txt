قم بحل تعارضات دمج git، أو rebase، أو اختيار الكرز عبر سلسلة من الدمج الهيكلي - mergiraf (حل تلقائي مدرك لـ AST) → git rerere (إعادة تشغيل الإصلاحات التي تم تذكرها) → kdiff3 (احتياطي يدوي). يُستخدم عند وجود تعارضات ويريد المستخدم حلها - عبارات مثل "إذابة التعارضات"، أو "إصلاح تعارضات الدمج"، أو "حل تعارضات إعادة الأساس"، أو "ما هو المتعارض بعد الدمج"، أو "/melt"، أو "إصلاح اختيار الكرز"، أو أي مطالبة تظهر علامات `<<<<<<<`، أو مخرجات git `CONFLICT (...)` أو حالة دمج نصف مكتملة. يتحقق أولاً من وجود بقايا دمج الاسكواش (إعادة القاعدة محكوم عليها بالعلاقات العامة المدمجة بالاسكواش - إحباط وإعادة اختيار الكرز)، ثم تشغيل التتالي باستخدام البرامج النصية المساعدة لتحليل الدفعة، واختياراتنا/اختياراتهم، وتجديد ملف القفل. يُستخدم حتى عندما يكون هناك ملف واحد متعارض إذا أراد المستخدم محاولة المرور الهيكلي قبل التحرير اليدوي. لا تستخدم لعمليات git العامة دون تعارضات. بعد `/cook` أو `/cure` إذا كانت خطوة الدمج تمنعهم؛ قبل إعادة محاولة البوابة التي ظهرت على السطح الصراع.
