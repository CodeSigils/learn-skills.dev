구조적 병합 단계(mergiraf(AST 인식 자동 해결) → git rerere(기억된 수정 사항 재생) → kdiff3(수동 대체))를 통해 git 병합, 리베이스 또는 체리 선택 충돌을 해결합니다. 충돌이 존재하고 사용자가 해결을 원할 때 사용합니다. "충돌 해결", "병합 충돌 수정", "리베이스 충돌 해결", "병합 후 충돌하는 부분", "/melt", "체리픽 수정"과 같은 문구 또는 `<<<<<<` 마커, `CONFLICT (...)` git 출력 또는 절반 완료된 병합 상태를 표시하는 프롬프트. 먼저 스쿼시 병합 잔여물(스쿼시 병합 PR로 인해 운명이 변경된 리베이스 - 중단 및 재체리 선택)을 확인한 다음 배치 해결, 우리/그들의 선택 및 잠금 파일 재생성을 위한 도우미 스크립트를 사용하여 캐스케이드를 실행합니다. 사용자가 수동 편집 전에 구조적 패스를 시도하려는 경우 하나의 파일만 충돌하는 경우에도 사용합니다. 충돌이 없는 일반적인 git 작업에는 사용하지 마세요. 병합 단계에서 차단된 경우 `/cook` 또는 `/cure` 이후; 충돌이 발생한 게이트를 다시 시도하기 전에.
