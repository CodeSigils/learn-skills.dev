Convierta una idea confusa o una característica a medio formar en una especificación aprobada a través de un diálogo de diseño iterativo y fundamentado. Úselo cuando el usuario tenga una idea confusa o una dirección de diseño: frases como "diseñemos X", "Estoy pensando en Y", "cómo debería verse la API para Z", "convierta esto en una especificación", "Quiero agregar una característica que...", "/molde". Ejecuta un diálogo iterativo (Explorar / Terreno / Forma / Bosquejo / Grill / Diagnóstico), fundamenta cada reclamo crítico con cheez-search o briesearch, bloquea las costuras públicas en pseudocódigo y solo escribe una especificación en `.cheese/specs/<slug>.md` después de una puerta de aprobación explícita. Úselo incluso cuando el usuario "simplemente esté pensando en voz alta" si desea que el diálogo deje un artefacto escrito; para un pensamiento puro sin escritura, diríjase a `/culture`.
