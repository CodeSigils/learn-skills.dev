Konvergieren Sie eine unscharfe Idee oder ein halbfertiges Feature durch einen iterativen, fundierten Designdialog in eine genehmigte Spezifikation. Verwenden Sie diese Option, wenn der Benutzer eine unklare Idee oder Designrichtung hat – Formulierungen wie „Lassen Sie uns Führt einen iterativen Dialog aus (Explore / Ground / Shape / Sketch / Grill / Diagnosis), begründet jeden kritischen Anspruch mit Cheez-Search oder Briesearch, sperrt öffentliche Nähte im Pseudocode und schreibt eine Spezifikation erst nach einem expliziten Genehmigungs-Gate in „.cheese/specs/<slug>.md“. Verwenden Sie diese Option auch dann, wenn der Benutzer „nur laut denkt“, wenn er möchte, dass der Dialog ein schriftliches Artefakt hinterlässt – für reines Nicht-Schreiben-Denken leiten Sie stattdessen zu „/culture“ weiter.
