Modifica il codice tramite modifiche MCP tilth ancorate all'hash: sostituisce i reindirizzamenti sed / awk / perl -i / patch / tee / Modifica / Scrivi / shell (`>`, `>>`). Da utilizzare quando l'utente chiede di modificare, sostituire, modificare, aggiornare, cambiare, eliminare o inserire codice: frasi come "sostituisci questa funzione", "elimina le righe 44-89", "aggiorna validateToken", "cambia l'implementazione", "aggiungi questa importazione", "correggi questo bug" (quando la correzione richiede una modifica) o applica una modifica strutturale trasversale (codemod) come "riscrivi ogni X in Y". Sanziona `sg --rewrite` (ast-grep) per codemod strutturali che si estendono su molti file. Leggi sempre prima tramite cheez-read per ottenere ancore hash per le modifiche ancorate. Preferire modifiche chirurgiche ancorate rispetto alle riscritture dell'intero file. Se l'ultimo MCP non è disponibile, fermati e segnala invece di ritirarti. NON utilizzare per leggere file (cheez-read prima per ottenere gli ancoraggi), cercare codice (utilizzare cheez-search) o eseguire test/build.
