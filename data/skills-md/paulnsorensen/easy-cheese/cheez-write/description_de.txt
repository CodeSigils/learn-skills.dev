Bearbeiten Sie Code über Hash-verankerte Tilth-MCP-Bearbeitungen – ersetzt sed / awk / perl -i / patch / tee / Edit / Write / Shell-Weiterleitungen (`>`, `>>`). Verwenden Sie diese Option, wenn der Benutzer Code bearbeiten, ersetzen, modifizieren, aktualisieren, ändern, löschen oder einfügen möchte – Ausdrücke wie „diese Funktion ersetzen“, „Zeilen 44–89 löschen“, „validateToken aktualisieren“, „Implementierung ändern“, „diesen Import hinzufügen“, „diesen Fehler beheben“ (wenn die Behebung eine Bearbeitung erfordert) oder eine übergreifende Strukturänderung (Codemod) anwenden, wie „jedes X in Y umschreiben“. Sanktioniert „sg --rewrite“ (ast-grep) für strukturelle Codemods, die sich über viele Dateien erstrecken. Lesen Sie immer zuerst über Cheez-Read, um Hash-Anker für verankerte Änderungen zu erhalten. Bevorzugen Sie chirurgisch verankerte Änderungen gegenüber dem Umschreiben ganzer Dateien. Wenn das MCP nicht verfügbar ist, halten Sie an und melden Sie es, anstatt zurückzugreifen. NICHT zum Lesen von Dateien (Cheez-Read zuerst, um Anker zu erhalten), zum Durchsuchen von Code (verwenden Sie Cheez-Search) oder zum Ausführen von Tests/Builds verwenden.
