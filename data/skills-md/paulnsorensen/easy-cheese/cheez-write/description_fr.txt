Modifiez le code via les modifications MCP Tith ancrées par hachage — remplace les redirections sed / awk / perl -i / patch / tee / Edit / Write / shell (`>`, `>>`). À utiliser lorsque l'utilisateur demande d'éditer, remplacer, modifier, mettre à jour, changer, supprimer ou insérer du code - des expressions telles que "remplacer cette fonction", "supprimer les lignes 44 à 89", "mettre à jour validateToken", "changer l'implémentation", "ajouter cette importation", "corriger ce bug" (lorsque la correction nécessite une modification) ou appliquer un changement structurel transversal (codemod) comme "réécrire chaque X en Y". Sanctions `sg --rewrite` (ast-grep) pour les codemods structurels qui s'étendent sur de nombreux fichiers. Lisez toujours en premier via cheez-read pour obtenir des ancres de hachage pour les modifications ancrées. Préférez les modifications chirurgicales ancrées aux réécritures de fichiers entiers. Si le MCP n'est pas disponible, arrêtez-vous et signalez-le plutôt que de reculer. Ne PAS utiliser pour lire des fichiers (lire d'abord pour obtenir des ancres), rechercher du code (utiliser cheez-search) ou exécuter des tests/builds.
