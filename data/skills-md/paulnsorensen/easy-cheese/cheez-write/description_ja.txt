ハッシュアンカーされた Tith MCP 編集によるコードの編集 — sed / awk / perl -i / patch / tee / Edit / Write / シェルリダイレクト (`>`、`>>`) を置き換えます。ユーザーがコードの編集、置換、修正、更新、変更、削除、または挿入を要求する場合に使用します。たとえば、「この関数を置き換える」、「44 ～ 89 行目を削除する」、「validateToken を更新する」、「実装を変更する」、「このインポートを追加する」、「このバグを修正する」 (修正に編集が必要な場合)、または「すべての X を Y に書き換える」などの横断的な構造変更 (codemod) を適用するなどのフレーズを使用します。多くのファイルにまたがる構造的な codemod に対する制裁「sg --rewrite」 (ast-grep)。アンカー付き編集のハッシュ アンカーを取得するには、常に最初に cheez-read 経由で読み取ります。ファイル全体の書き換えよりも外科的アンカー編集を優先します。 MCP が利用できない場合は、フォールバックするのではなく、停止して報告します。ファイルの読み取り (アンカーを取得するために最初に cheez-read)、コードの検索 (cheez-search を使用)、またはテスト/ビルドの実行には使用しないでください。
