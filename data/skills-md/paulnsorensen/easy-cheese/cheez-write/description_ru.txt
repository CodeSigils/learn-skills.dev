Редактируйте код с помощью изменений Tilth MCP, привязанных к хешу — заменяет перенаправления sed / awk / perl -i / patch / tee / Edit / Write / Shell (`>`, `>>`). Используйте, когда пользователь просит отредактировать, заменить, изменить, обновить, изменить, удалить или вставить код — такие фразы, как «заменить эту функцию», «удалить строки 44–89», «обновить validateToken», «изменить реализацию», «добавить этот импорт», «исправить эту ошибку» (когда исправление требует редактирования) или применить сквозное структурное изменение (codemod), например «переписать каждый X на Y». Санкции `sg --rewrite` (ast-grep) для структурных модов кода, охватывающих множество файлов. Всегда сначала читайте с помощью cheez-read, чтобы получить хэш-привязки для закрепленных изменений. Предпочитайте хирургические закрепленные правки, а не перезапись всего файла. Если Tilth MCP недоступен, остановитесь и сообщите, а не отступайте. НЕ используйте для чтения файлов (сначала выполните cheez-read, чтобы получить привязки), поиска кода (используйте cheez-search) или запуска тестов/сборок.
