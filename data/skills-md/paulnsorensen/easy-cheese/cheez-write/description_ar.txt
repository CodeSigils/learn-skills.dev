قم بتحرير التعليمات البرمجية عبر تعديلات MCP المرتكزة على التجزئة - لتحل محل عمليات إعادة التوجيه sed / awk / Perl -i / patch / Tee / Edit / Write / Shell (`>`، `>>`). يُستخدم عندما يطلب المستخدم تحرير التعليمات البرمجية أو استبدالها أو تعديلها أو تحديثها أو تغييرها أو حذفها أو إدراجها - عبارات مثل "استبدال هذه الوظيفة"، أو "حذف الأسطر 44-89"، أو "تحديث رمز التحقق من الصحة"، أو "تغيير التنفيذ"، أو "إضافة هذا الاستيراد"، أو "إصلاح هذا الخطأ" (عندما يتطلب الإصلاح التحرير)، أو تطبيق تغيير هيكلي شامل (codemod) مثل "إعادة كتابة كل X إلى Y". العقوبات `sg --rewrite` (ast-grep) لتعديلات التعليمات البرمجية الهيكلية التي تشمل العديد من الملفات. قم دائمًا بالقراءة أولاً عبر cheez-read للحصول على علامات التجزئة للتعديلات الراسخة. تفضيل التعديلات الجراحية المثبتة على إعادة كتابة الملف بالكامل. في حالة عدم توفر MCP، توقف وأبلغ بدلاً من التراجع. لا تستخدم لقراءة الملفات (قراءة الجبن أولاً للحصول على المراسي)، أو البحث عن التعليمات البرمجية (استخدم بحث الجبن)، أو تشغيل الاختبارات/الإنشاءات.
