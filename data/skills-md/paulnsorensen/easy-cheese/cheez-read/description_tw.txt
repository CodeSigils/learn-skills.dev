透過 AST 感知的tilth MCP 讀取和列出檔案 — 取代 cat / head / tail / less / more / bat / ls / tree / eza / find / fd / Read / Glob。當使用者要求讀取、檢視、顯示、開啟或顯示檔案或目錄時使用 - 諸如「讀取 src/auth.ts」、「顯示此檔案」、「此目錄中的內容」、「檢視第 44-89 行」、「檢視匯入」等短語。即使使用者說「cat」、「less」、「bat」、「tree」、「ls」、「find」、「fd」或「開啟檔案」時也可以使用 - 切勿直接呼叫主機 Read、Glob 或任何 shell 檔案檢視器/清單器。如果傾斜 MCP 不可用，請停止並報告，而不是撤退。請勿用於搜尋符號或文字（使用 cheez-search）、編輯程式碼（使用 cheez-write）或 git/gh 操作。
