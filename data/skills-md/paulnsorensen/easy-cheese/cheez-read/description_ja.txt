AST 対応のtilth MCP を介してファイルを読み取り、リストします。cat / head / tail /less / more / butt / ls /tree / eza / find / fd / Read / Glob を置き換えます。ユーザーがファイルまたはディレクトリの読み取り、表示、表示、オープン、または表示を要求するときに使用します。たとえば、「src/auth.ts を読んでください」、「このファイルを見せてください」、「このディレクトリにあるものは何ですか」、「44 ～ 89 行目を表示します」、「インポートを見てください」などのフレーズです。ユーザーが「cat」、「less」、「bat」、「tree」、「ls」、「find」、「fd」、または「ファイルを開く」と言った場合でも使用します。ホスト Read、Glob、またはシェル ファイル ビューア/リスタを直接呼び出さないでください。 MCP が利用できない場合は、フォールバックするのではなく、停止して報告します。シンボルやテキストの検索 (cheez-search を使用)、コードの編集 (cheez-write を使用)、または git/gh 操作には使用しないでください。
