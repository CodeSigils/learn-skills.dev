Legge ed elenca file tramite tilth MCP compatibile con AST: sostituisce cat / head / tail / less / more / bat / ls / tree / eza / find / fd / Read / Glob. Da utilizzare quando l'utente chiede di leggere, visualizzare, mostrare, aprire o visualizzare un file o una directory: frasi come "leggi src/auth.ts", "mostrami questo file", "cosa c'è in questa directory", "visualizza le righe 44-89", "guarda le importazioni". Utilizzare anche quando l'utente dice "cat", "less", "bat", "tree", "ls", "find", "fd" o "open the file" — non chiamare mai host Read, Glob o qualsiasi visualizzatore/lister di file shell direttamente. Se l'ultimo MCP non è disponibile, fermati e segnala invece di ritirarti. NON utilizzare per la ricerca di simboli o testo (usa cheez-search), modifica del codice (usa cheez-write) o operazioni git/gh.
