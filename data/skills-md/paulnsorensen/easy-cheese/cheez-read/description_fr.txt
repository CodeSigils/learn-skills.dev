Lisez et répertoriez les fichiers via Tith MCP compatible AST — remplace cat / head / tail / less / more / bat / ls / tree / eza / find / fd / Read / Glob. À utiliser lorsque l'utilisateur demande à lire, visualiser, afficher, ouvrir ou afficher un fichier ou un répertoire — des expressions telles que "lire src/auth.ts", "montrer-moi ce fichier", "ce qu'il y a dans ce répertoire", "afficher les lignes 44 à 89", "regarder les importations". À utiliser même lorsque l'utilisateur dit "cat", "less", "bat", "tree", "ls", "find", "fd" ou "open the file" — n'appelez jamais directement l'hôte Read, Glob ou tout autre visualiseur/listeur de fichiers shell. Si le MCP n'est pas disponible, arrêtez-vous et signalez-le plutôt que de reculer. Ne PAS utiliser pour rechercher des symboles ou du texte (utilisez cheez-search), éditer du code (utilisez cheez-write) ou des opérations git/gh.
