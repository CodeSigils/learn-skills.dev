Dateien über AST-fähiges Tilth-MCP lesen und auflisten – ersetzt cat / head / tail / less / more / bat / ls / tree / eza / find / fd / Read / Glob. Verwenden Sie diese Option, wenn der Benutzer eine Datei oder ein Verzeichnis lesen, anzeigen, anzeigen, öffnen oder anzeigen möchte – Formulierungen wie „src/auth.ts lesen“, „diese Datei anzeigen“, „was sich in diesem Verzeichnis befindet“, „Zeilen 44–89 anzeigen“, „sich die Importe ansehen“. Verwenden Sie dies auch, wenn der Benutzer „cat“, „less“, „bat“, „tree“, „ls“, „find“, „fd“ oder „open the file“ sagt – rufen Sie niemals Host Read, Glob oder einen Shell-Datei-Viewer/Lister direkt auf. Wenn das MCP nicht verfügbar ist, halten Sie an und melden Sie es, anstatt zurückzugreifen. NICHT zum Suchen von Symbolen oder Texten (verwenden Sie Cheez-Search), zum Bearbeiten von Code (verwenden Sie Cheez-Write) oder für Git/GH-Operationen verwenden.
