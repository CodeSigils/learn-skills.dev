Lea y enumere archivos a través de MCP compatible con AST: reemplaza cat / head / tail / less / more / bat / ls / tree / eza / find / fd / Read / Glob. Úselo cuando el usuario solicite leer, ver, mostrar, abrir o mostrar un archivo o directorio: frases como "leer src/auth.ts", "muéstrame este archivo", "qué hay en este directorio", "ver líneas 44-89", "mira las importaciones". Úselo incluso cuando el usuario diga "cat", "less", "bat", "tree", "ls", "find", "fd" o "open the file"; nunca llame directamente al host Read, Glob o cualquier visor/lister de archivos de shell. Si el MCP no está disponible, deténgase e informe en lugar de retroceder. NO lo use para buscar símbolos o texto (use cheez-search), editar código (use cheez-write) ni operaciones git/gh.
