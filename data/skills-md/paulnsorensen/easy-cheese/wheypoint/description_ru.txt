Отметьте контрольную точку в текущем разговоре — упакуйте ее в надежный документ передачи, чтобы новый агент мог возобновить работу без потери контекста. Используйте, когда пользователь хочет сохранить состояние сеанса для более позднего или параллельного сеанса — такие фразы, как «передать это», «записать передачу», «отбросить точку сыворотки», «контрольная точка», «сжать разговор», «у меня заканчивается контекст», «сохранить, где мы находимся для следующего сеанса», «подготовить передачу для другого агента», «/wheypoint». Записывает `.cheese/notes/<slug>.md` с возобновляемым пулом передачи обслуживания, разделом предлагаемых навыков с отображением состояний и отредактированными секретами, а затем указывает пользователю `/cheese --continue <slug>`. Используйте, даже когда пользователь просто говорит «завершить» или «мне нужно очистить контекст» в середине задачи. НЕ используйте для пояснений без записи только для проектирования (`/cultural`) или для поэтапной передачи обслуживания конвейера — `/cook`, `/press`, `/age`, `/cure` уже пишут свои собственные пули. Перед `/cheese --continue`.
