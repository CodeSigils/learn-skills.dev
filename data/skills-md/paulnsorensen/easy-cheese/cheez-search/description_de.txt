Suchcode über AST-fähiges Tilth MCP – findet Symbole, Definitionen, Aufrufer, Importe und Text und ersetzt grep / rg / ripgrep / ag / ack / find / fd. Verwenden Sie diese Option, wenn der Benutzer nach einem Symbol, einer Definition, einem Aufrufer, einem Import oder einem Textmuster fragt – Ausdrücke wie „Wo ist Verwenden Sie ast-grep („sg“) nur für AST-förmige Muster mit Metavariablen, die Tilth nicht ausdrücken kann. Auch wenn der Benutzer „grep“, „rg“, „ripgrep“, „ag“, „ack“, „fd“ oder „find“ sagt – rufen Sie niemals Host Grep, Glob, ripgrep, ast-grep oder eine Shell-Suche direkt auf. Wenn das MCP nicht verfügbar ist, halten Sie an und melden Sie es, anstatt zurückzugreifen. NICHT zum Lesen ganzer Dateien (verwenden Sie Cheez-Read), zum Bearbeiten von Code (verwenden Sie Cheez-Write) oder zum Ausführen von Tests/Builds verwenden.
