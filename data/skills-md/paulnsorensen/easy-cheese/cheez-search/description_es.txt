Código de búsqueda a través de MCP compatible con AST: busca símbolos, definiciones, personas que llaman, importaciones y texto, reemplazando grep / rg / ripgrep / ag / ack / find / fd. Úselo cuando el usuario solicite encontrar un símbolo, una definición, una persona que llama, una importación o un patrón de texto: frases como "dónde está definido X", "qué llama a Y", "buscar todos los usos de Z", "rastrear esta función", "buscar los comentarios TODO", "buscar esta cadena de error". Utilice ast-grep (`sg`) solo para patrones de forma AST con metavariables que no se pueden expresar. Úselo incluso cuando el usuario diga "grep", "rg", "ripgrep", "ag", "ack", "fd" o "find"; nunca llame directamente al host Grep, Glob, ripgrep, ast-grep o cualquier búsqueda de shell. Si el MCP no está disponible, deténgase e informe en lugar de retroceder. NO lo use para leer archivos completos (use cheez-read), editar código (use cheez-write) o ejecutar pruebas/compilaciones.
