AST 対応のtilth MCP によるコードの検索 — シンボル、定義、呼び出し元、インポート、およびテキストを検索し、grep / rg / ripgrep / ag / ack / find / fd を置き換えます。ユーザーがシンボル、定義、呼び出し元、インポート、またはテキスト パターンの検索を要求する場合に使用します。たとえば、「X が定義されている場所」、「Y を呼び出すもの」、「Z のすべての使用法を検索」、「この関数をトレース」、「TODO コメントを検索」、「このエラー文字列を検索」などのフレーズです。 ast-grep (`sg`) は、tilth が表現できないメタ変数を持つ AST 形状のパターンにのみ使用してください。ユーザーが「grep」、「rg」、「ripgrep」、「ag」、「ack」、「fd」、または「find」と言う場合でも使用します。ホスト Grep、Glob、ripgrep、ast-grep、またはシェル検索を直接呼び出さないでください。 MCP が利用できない場合は、フォールバックするのではなく、停止して報告します。ファイル全体の読み取り (cheez-read を使用)、コードの編集 (cheez-write を使用)、またはテスト/ビルドの実行には使用しないでください。
