ابحث عن الكود عبر AST-aware Tiltth MCP - يعثر على الرموز والتعريفات والمتصلين والواردات والنص، ويستبدل grep / rg / ripgrep / ag / ack / find / fd. يُستخدم عندما يطلب المستخدم العثور على رمز أو تعريف أو متصل أو استيراد أو نمط نص - عبارات مثل "أين تم تعريف X"، "ما يستدعي Y"، "ابحث عن جميع استخدامات Z"، "تتبع هذه الوظيفة"، "ابحث عن تعليقات المهام"، "ابحث عن سلسلة الخطأ هذه". استخدم ast-grep (`sg`) فقط لأنماط شكل AST ذات المتغيرات الوصفية التي لا يمكن التعبير عنها. استخدمه حتى عندما يقول المستخدم "grep" أو "rg" أو "ripgrep" أو "ag" أو "ack" أو "fd" أو "find" - لا تتصل مطلقًا بالمضيف Grep أو Glob أو ripgrep أو ast-grep أو أي بحث Shell مباشرة. في حالة عدم توفر MCP، توقف وأبلغ بدلاً من التراجع. لا تستخدم لقراءة الملفات بأكملها (استخدم cheez-read)، أو تحرير التعليمات البرمجية (استخدم cheez-write)، أو تشغيل الاختبارات/الإنشاءات.
