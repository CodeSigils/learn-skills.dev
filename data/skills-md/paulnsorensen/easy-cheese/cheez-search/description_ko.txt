AST 인식 틸스 MCP를 통한 코드 검색 — grep / rg / ripgrep / ag / ack / find / fd를 대체하여 기호, 정의, 호출자, 가져오기 및 텍스트를 찾습니다. 사용자가 "X가 정의된 위치", "Y를 호출하는 항목", "Z의 모든 사용 위치 찾기", "이 함수 추적", "TODO 주석 찾기", "이 오류 문자열 검색"과 같은 문구 등 기호, 정의, 호출자, 가져오기 또는 텍스트 패턴을 찾도록 요청할 때 사용합니다. 메타변수 기울기를 표현할 수 없는 AST 모양 패턴에만 ast-grep(`sg`)를 사용하세요. 사용자가 "grep", "rg", "ripgrep", "ag", "ack", "fd" 또는 "find"라고 말할 때에도 사용하십시오. 절대로 호스트 Grep, Glob, ripgrep, ast-grep 또는 쉘 검색을 직접 호출하지 마십시오.
