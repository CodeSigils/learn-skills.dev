透過 AST 感知的tilth MCP 搜尋代碼 — 尋找符號、定義、呼叫者、導入和文本，取代 grep / rg / ripgrep / ag / ack / find / fd。當使用者要求查找符號、定義、呼叫者、導入或文字模式時使用 - 諸如“X 定義在哪裡”、“什麼調用 Y”、“查找 Z 的所有用法”、“跟踪此函數”、“查找 TODO 註釋”、“搜索此錯誤字符串”等短語。僅對元變數 tith 無法表現的 AST 形狀模式使用 ast-grep (`sg`)。即使使用者說「grep」、「rg」、「ripgrep」、「ag」、「ack」、「fd」或「find」時也要使用—切勿直接呼叫主機 Grep、Glob、ripgrep、ast-grep 或任何 shell 搜尋。如果傾斜 MCP 不可用，請停止並報告，而不是撤退。請勿用於讀取整個檔案（使用 cheez-read）、編輯程式碼（使用 cheez-write）或執行測試/建置。
