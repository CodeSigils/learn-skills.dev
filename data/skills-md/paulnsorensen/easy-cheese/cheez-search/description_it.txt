Cerca codice tramite MCP tilth compatibile con AST: trova simboli, definizioni, chiamanti, importazioni e testo, sostituendo grep / rg / ripgrep / ag / ack / find / fd. Da utilizzare quando l'utente chiede di trovare un simbolo, una definizione, un chiamante, un'importazione o un modello di testo: frasi come "dove è definito X", "cosa chiama Y", "trova tutti gli usi di Z", "traccia questa funzione", "trova i commenti TODO", "cerca questa stringa di errore". Utilizza ast-grep (`sg`) solo per modelli a forma AST con metavariabili che tilth non può esprimere. Utilizzare anche quando l'utente dice "grep", "rg", "ripgrep", "ag", "ack", "fd" o "find": non chiamare mai l'host Grep, Glob, ripgrep, ast-grep o qualsiasi ricerca shell direttamente. Se l'ultimo MCP non è disponibile, fermati e segnala invece di ritirarti. NON utilizzare per leggere interi file (usare cheez-read), modificare il codice (usare cheez-write) o eseguire test/build.
