Rechercher du code via Tith MCP compatible AST — recherche des symboles, des définitions, des appelants, des importations et du texte, en remplaçant grep / rg / ripgrep / ag / ack / find / fd. À utiliser lorsque l'utilisateur demande à trouver un symbole, une définition, un appelant, une importation ou un modèle de texte — des expressions telles que « où est défini X », « ce qui appelle Y », « trouver toutes les utilisations de Z », « tracer cette fonction », « trouver les commentaires TODO », « rechercher cette chaîne d'erreur ». Utilisez ast-grep (`sg`) uniquement pour les modèles de forme AST avec des métavariables que la terre ne peut pas exprimer. À utiliser même lorsque l'utilisateur dit "grep", "rg", "ripgrep", "ag", "ack", "fd" ou "find" — n'appelez jamais l'hôte Grep, Glob, ripgrep, ast-grep ou toute autre recherche shell directement. Si le MCP n'est pas disponible, arrêtez-vous et signalez-le plutôt que de reculer. Ne PAS utiliser pour lire des fichiers entiers (utilisez cheez-read), éditer du code (utilisez cheez-write) ou exécuter des tests/builds.
