ДИАГНОСТИКА + ИСПРАВЛЕНИЕ серьезных ошибок. Создает детерминированный цикл обратной связи, управляемый агентом, воспроизводит сбой, называет причину, записывает регрессионный тест, применяет минимальное производственное исправление. Используйте, когда пользователь сообщает об ошибке, нестабильном тесте, регрессии производительности или видимом неправильном поведении — такие фразы, как «диагностируйте это», «отладьте это», «почему X не работает», «/pasteurize» или вставленную трассировку стека/воспроизведение/«это выглядит неправильно, расследуйте» без указания причины. Пастеризовать код EDITS (регрессионный тест + исправление); культура этого не делает. Запускает шестифазный цикл — цикл обратной связи → воспроизведение → гипотеза → инструмент → исправление + регрессионный тест → очистка — привязан к фазе 1. Записывает `.cheese/pasteurize/<slug>.md` и передает `/cook <slug> --auto` для цепочки `/press → /age → /cure`; Собственный `--auto` пастеризации пропускает шлюз передачи. НЕ используйте для различий только для проверки (`/age`), проектирования функций (`/mold`), исправлений по известным причинам (`/cook`) или когда пользователь явно отказался от записи (`/cultural`). После намерения отладки `/cheese`; перед `/cook <slug> --auto`.
