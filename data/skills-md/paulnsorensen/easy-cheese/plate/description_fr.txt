Transformez le travail local terminé en une validation, une demande d'extraction ordinaire ou une chaîne de demande d'extraction empilée. À utiliser lorsqu'on vous demande de valider, d'enregistrer les modifications, d'ouvrir ou de mettre à jour un PR, de publier une branche, de créer/synchroniser/restacker/soumettre une pile PR ou d'exécuter /plate. Possède toutes les étapes de mise en scène, de validation, de poussée, de création de relations publiques et de mutation prenant en compte la pile. L'inspection, la révision, les commentaires, les CI, les problèmes, les versions et l'administration du référentiel GitHub restent /gh.
