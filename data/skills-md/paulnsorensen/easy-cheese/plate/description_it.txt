Trasforma il lavoro locale finito in un commit, una richiesta pull ordinaria o una catena di richieste pull in pila. Da utilizzare quando viene richiesto di confermare, salvare modifiche, aprire o aggiornare un PR, pubblicare un ramo, creare/sincronizzare/restack/inviare uno stack PR o eseguire /plate. Possiede tutte le fasi di staging, commit, push, creazione di PR e mutazione con riconoscimento dello stack. L'ispezione, la revisione, i commenti, gli elementi della configurazione, i problemi, le versioni e l'amministrazione del repository di GitHub rimangono /gh.
