Зарегистрируйте и исправьте корпус галлюмината устойчивого сыра и арендатора каждого репо. Используйте, когда пользователь говорит «настроить корпус сыра», «восстановить корпус галлоумината», «зарегистрировать прочный корпус», «мои спецификации недоступны для поиска в разных сеансах», «исправить глобальный дрейф сыра» или вызывает /easy-cheese-setup. Запускает цикл обнаружения → отчета → подтверждения → исправления на двух ветвях — глобальной регистрации/восстановления устойчивого корпуса и локальной регистрации клиента для каждого репозитория. НЕ используйте для общего создания вики-сайта Hallouminate (то есть навыков работы с вики) или для установки сервера MCP (то есть scripts/install.sh).
