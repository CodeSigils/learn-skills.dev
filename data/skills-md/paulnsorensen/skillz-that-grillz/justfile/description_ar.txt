قم بإنشاء أو الترحيل إلى justfile (casey/just Command runner) لأي مشروع. استخدم هذه المهارة عندما يطلب المستخدم إضافة justfile، أو استبدال Makefile، أو إعداد أوامر المشروع، أو إنشاء برامج تشغيل المهام، أو الإشارة إلى "فقط" في سياق سير عمل الإنشاء/التطوير. يتم تشغيله أيضًا عندما ترى مشروعًا به ملف Makefile قد يستفيد من بناء الجملة الأبسط، أو عند إعداد مشروع جديد يحتاج إلى أوامر تطوير شائعة (build، test، lint، fmt). يغطي الأنظمة البيئية Rust وPython وTypeScript/JavaScript وGo وRuby. لا تستخدم لتكوين خط أنابيب CI، أو Dockerfiles، أو إعداد نظام البناء الفعلي (البضائع، حزمة الويب، وما إلى ذلك).
