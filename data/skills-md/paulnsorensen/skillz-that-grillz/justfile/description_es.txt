Cree o migre a un justfile (casey/just command runner) para cualquier proyecto. Utilice esta habilidad cuando el usuario solicite agregar un justfile, reemplazar un Makefile, configurar comandos de proyecto, crear ejecutores de tareas o mencione "solo" en el contexto de los flujos de trabajo de compilación/desarrollo. También se activa cuando ve un proyecto con un Makefile que se beneficiaría de una sintaxis más simple, o cuando configura un nuevo proyecto que necesita comandos de desarrollo comunes (build, test, lint, fmt). Cubre los ecosistemas Rust, Python, TypeScript/JavaScript, Go y Ruby. NO lo use para la configuración de canalizaciones de CI, Dockerfiles o la configuración real del sistema de compilación (carga, paquete web, etc.).
