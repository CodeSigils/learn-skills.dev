Erstellen Sie für jedes Projekt eine Justfile (Casey/Just Command Runner) oder migrieren Sie dorthin. Verwenden Sie diese Fähigkeit, wenn der Benutzer im Kontext von Build-/Entwicklungsworkflows darum bittet, ein Justfile hinzuzufügen, ein Makefile zu ersetzen, Projektbefehle einzurichten, Task-Runner zu erstellen oder „nur“ zu erwähnen. Wird auch ausgelöst, wenn Sie ein Projekt mit einem Makefile sehen, das von einer einfacheren Syntax profitieren würde, oder wenn Sie ein neues Projekt einrichten, das allgemeine Entwicklungsbefehle (Build, Test, Lint, FMT) benötigt. Deckt die Ökosysteme Rust, Python, TypeScript/JavaScript, Go und Ruby ab. NICHT für die CI-Pipeline-Konfiguration, Docker-Dateien oder die eigentliche Einrichtung des Build-Systems (Cargo, Webpack usw.) verwenden.
