Persistenza, recupero e ricerca di artefatti locali prodotti dalle competenze in un albero `.skillz/<type>/<slug>` prevedibile. Da utilizzare ogni volta che una competenza ha bisogno di salvare file temporanei, piani, note o altri artefatti funzionanti su disco e cercarli di nuovo in un secondo momento, ad esempio quando un utente dice "salva questo come <slug>", "dove abbiamo salvato il <tipo>", "trova lo <slug> che abbiamo salvato" o ogni volta che un'altra competenza in questo repository fa riferimento al "gestore di file". Racchiude un singolo script Bash privo di dipendenze (`scripts/skillz.sh`) che espone `save_file`, `get_file` e `search_files` (titoli + corpo grep). Tutte le altre abilità dovrebbero delegare a questa abilità invece di inventare il proprio layout su disco. NON utilizzare per modifiche al codice sorgente, file con controllo della versione o qualsiasi cosa che appartenga all'albero del progetto: questo è per gli artefatti delle competenze, non per i file dell'applicazione.
