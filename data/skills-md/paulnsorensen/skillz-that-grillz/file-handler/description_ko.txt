예측 가능한 `.skillz/<type>/<slug>` 트리 아래에서 기술로 생성된 로컬 아티팩트를 유지하고 가져오고 검색합니다. 스킬이 스크래치 파일, 계획, 메모 또는 기타 작업 아티팩트를 디스크에 저장하고 나중에 다시 검색해야 할 때마다 사용합니다. 예를 들어 사용자가 "이것을 <slug>로 저장", "<type>을 어디에 저장했습니까", "저장한 <slug>를 찾았습니까"라고 말할 때 또는 이 저장소의 다른 스킬이 "파일 처리기"를 참조할 때마다 사용합니다. `save_file`, `get_file` 및 `search_files`(제목 + 본문 grep)을 노출하는 단일 종속성 없는 Bash 스크립트(`scripts/skillz.sh`)를 래핑합니다. 다른 모든 기술은 자체적인 온디스크 레이아웃을 만드는 대신 이 기술에 위임해야 합니다. 소스 코드 편집, 버전 제어 파일 또는 프로젝트 트리에 속하는 모든 것에 사용하지 마십시오. 이는 응용 프로그램 파일이 아닌 기술 아티팩트를 위한 것입니다.
