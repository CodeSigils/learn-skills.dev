Gestisci i dotfile con chezmoi: il gestore dotfile dello stato di origine che utilizza gli attributi dei nomi file (`dot_`, `private_`, `encrypted_`, `run_once_`), modelli Go e l'integrazione del gestore password per mantenere un set di dotfile funzionante su più macchine. Da utilizzare quando l'utente dice "imposta dotfile", "gestisci i miei dotfile", "avvia una nuova macchina", "chezmoi", "crittografa la mia chiave SSH nei dotfile", "modello dotfile per sistema operativo", "aggiungi segreti ai dotfile", "cosa dovrebbe esserci nel mio .chezmoi.toml.tmpl" o chiede come condividere le configurazioni su macOS/Linux/server. Si attiva anche quando l'utente sta fissando una macchina nuova e desidera la riga di risposta che lo riporti a casa o quando sta per inserire qualcosa di sensibile in un repository dotfiles. NON utilizzare per stow / yadm / rcm o altri gestori di dotfile, configurazione generica di repository git o configurazione di gestore di password non correlata ai dotfile.
