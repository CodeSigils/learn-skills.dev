Gérez les fichiers dot avec chezmoi — le gestionnaire de fichiers dot à l'état source qui utilise les attributs de nom de fichier (`dot_`, `private_`, `encrypted_`, `run_once_`), les modèles Go et l'intégration du gestionnaire de mots de passe pour qu'un ensemble de fichiers dot fonctionne sur de nombreuses machines. À utiliser lorsque l'utilisateur dit "configurer les fichiers dot", "gérer mes fichiers dot", "démarrer une nouvelle machine", "chezmoi", "crypter ma clé SSH dans les fichiers dot", "modèle de fichiers dot par système d'exploitation", "ajouter des secrets aux fichiers dot", "ce qui devrait être dans mon .chezmoi.toml.tmpl", ou demande comment partager les configurations entre les serveurs macOS/Linux. Déclenchez également lorsque l'utilisateur regarde une nouvelle machine et veut le one-liner qui le ramène à la maison, ou lorsqu'il est sur le point de valider quelque chose de sensible dans un dépôt dotfiles. Ne PAS utiliser pour stow / yadm / rcm ou d'autres gestionnaires de fichiers dot, une configuration de dépôt git générique ou une configuration de gestionnaire de mots de passe sans rapport avec les fichiers dot.
