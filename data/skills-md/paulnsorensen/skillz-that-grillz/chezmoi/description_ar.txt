إدارة ملفات النقاط باستخدام chezmoi - مدير ملفات النقاط في الحالة المصدر الذي يستخدم سمات اسم الملف (`dot_`، `private_`، `encrypted_`، `run_once_`)، وقوالب Go، وتكامل مدير كلمات المرور للحفاظ على مجموعة واحدة من ملفات النقاط تعمل عبر العديد من الأجهزة. يُستخدم عندما يقول المستخدم "إعداد ملفات النقاط"، أو "إدارة ملفات النقاط الخاصة بي"، أو "تمهيد جهاز جديد"، أو "chezmoi"، أو "تشفير مفتاح SSH الخاص بي في ملفات النقاط"، أو "قالب ملفات النقاط لكل نظام تشغيل"، أو "إضافة أسرار إلى ملفات النقاط"، أو "ما يجب أن يكون في .chezmoi.toml.tmpl"، أو يسأل عن كيفية مشاركة التكوينات عبر macOS / Linux / الخوادم. يتم تشغيله أيضًا عندما يحدق المستخدم في جهاز جديد ويريد الجملة التي تعيده إلى المنزل، أو عندما يكون على وشك ارتكاب شيء حساس في مستودع dotfiles. لا تستخدمه مع stow / yadm / rcm أو مديري ملفات dotfile الآخرين، أو إعداد git repo العام، أو إعداد مدير كلمات المرور غير المرتبط بملفات dotfiles.
