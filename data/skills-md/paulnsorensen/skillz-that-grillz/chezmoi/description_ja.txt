chezmoi を使用してドットファイルを管理します。これは、ファイル名属性 (`dot_`、`private_`、`encrypted_`、`run_once_`)、Go テンプレート、およびパスワード マネージャーの統合を使用して、1 セットのドットファイルを多数のマシンで動作し続けるソース状態のドットファイル マネージャーです。ユーザーが「ドットファイルを設定する」、「ドットファイルを管理する」、「新しいマシンをブートストラップする」、「chezmoi」、「ドットファイルで SSH キーを暗号化する」、「OS ごとにドットファイルをテンプレートにする」、「ドットファイルにシークレットを追加する」、「.chezmoi.toml.tmpl に何を含めるべきか」と言う場合、または macOS / Linux / サーバー間で構成を共有する方法を尋ねる場合に使用します。また、ユーザーが新しいマシンを見つめていて、帰宅するためのワンライナーを必要としているとき、または機密性の高いものを dotfiles リポジトリにコミットしようとしているときにもトリガーされます。 stow / yadm / rcm またはその他のドットファイル マネージャー、一般的な git リポジトリのセットアップ、またはドットファイルに関係のないパスワード マネージャーのセットアップには使用しないでください。
