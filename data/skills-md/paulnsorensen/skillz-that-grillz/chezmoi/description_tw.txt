使用 chezmoi 管理點檔案 - 來源狀態點檔案管理器，使用檔案名稱屬性（「dot_」、「private_」、「加密_」、「run_once_」）、Go 範本和密碼管理器整合來保持一組點檔案在多台電腦上運作。當使用者說「設定點檔案」、「管理我的點檔案」、「引導新機器」、「chezmoi」、「在點檔案中加密我的 SSH 金鑰」、「每個作業系統的範本點檔案」、「向點檔案新增機密」、「我的 .chezmoi.toml.tm當使用者盯著一台新機器並希望使用一行程式碼將他們帶回家時，或者當他們要將敏感內容提交到點檔案儲存庫中時，也會觸發。請勿用於 stow / yadm / rcm 或其他點檔案管理器、通用 git repo 設定或與點檔案無關的密碼管理器設定。
