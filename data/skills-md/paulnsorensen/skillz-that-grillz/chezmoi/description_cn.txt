使用 chezmoi 管理点文件 - 源状态点文件管理器，使用文件名属性（“dot_”、“private_”、“加密_”、“run_once_”）、Go 模板和密码管理器集成来保持一组点文件在多台计算机上工作。当用户说“设置点文件”、“管理我的点文件”、“引导新机器”、“chezmoi”、“在点文件中加密我的 SSH 密钥”、“每个操作系统的模板点文件”、“向点文件添加机密”、“我的 .chezmoi.toml.tmpl 中应该有什么”或询问如何跨 macOS/Linux/服务器共享配置时使用。当用户盯着一台新机器并希望使用一行代码将他们带回家时，或者当他们要将敏感内容提交到点文件存储库中时，也会触发。请勿用于 stow / yadm / rcm 或其他点文件管理器、通用 git repo 设置或与点文件无关的密码管理器设置。
