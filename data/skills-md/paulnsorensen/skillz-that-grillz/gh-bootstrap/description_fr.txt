Configuration unique du référentiel GitHub via la CLI `gh` : activez une file d'attente de fusion sur la branche par défaut, verrouillez la fusion sur squash uniquement avec les messages de validation du titre PR, effectuez les vérifications d'état CI requises, échafaudez les notes de version générées automatiquement (`.github/release.yml`) et ajoutez éventuellement un workflow de publication piloté par des balises. À utiliser lorsque l'utilisateur dit « configurer le dépôt », « configurer la file d'attente de fusion », « activer la fusion de squash », « verrouiller le principal », « configurer la protection des branches », « configurer les notes de version », « versions d'échafaudage », « configurer le marquage des versions » ou invoque /gh-bootstrap sur un référentiel GitHub frais ou mal configuré. Idempotent – ​​peut être réexécuté en toute sécurité sur des dépôts déjà configurés pour aligner les éléments manquants. Distinct de /gh, qui gère les opérations de relations publiques/problèmes/CI par tâche ; cette compétence est destinée à la politique de pension unique.
