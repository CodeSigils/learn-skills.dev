「gh」 CLI を介した 1 回限りの GitHub リポジトリ設定: デフォルト ブランチでマージ キューを有効にし、PR タイトル コミット メッセージでスカッシュのみにマージをロックし、必要な CI ステータス チェックを配線し、自動生成されたリリース ノート (`.github/release.yml`) をスキャフォールディングし、オプションでタグ駆動型のリリース ワークフローを追加します。ユーザーが「リポジトリを設定する」、「マージ キューを設定する」、「スカッシュ マージを有効にする」、「メインをロックする」、「ブランチ保護を設定する」、「リリース ノートを設定する」、「スキャフォールド リリースを設定する」、「リリース タグ付けを設定する」と言う場合、または新しい GitHub リポジトリまたは緩く設定された GitHub リポジトリで /gh-bootstrap を呼び出す場合に使用します。冪等 — 構成済みのリポジトリで安全に再実行して、不足している部分を整列させます。タスクごとの PR / 発行 / CI 操作を処理する /gh とは異なります。このスキルはワンタイム リポジトリ ポリシー用です。
