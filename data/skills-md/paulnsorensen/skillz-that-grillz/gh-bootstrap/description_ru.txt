Однократная настройка репозитория GitHub через CLI `gh`: включите очередь слияния в ветке по умолчанию, заблокируйте слияние только для сжатия с сообщениями фиксации PR-заголовка, проведите необходимые проверки статуса CI, создайте автоматически генерируемые заметки о выпуске (`.github/release.yml`) и, при необходимости, добавьте рабочий процесс выпуска на основе тегов. Используйте, когда пользователь говорит «настроить репозиторий», «настроить очередь слияния», «включить сквош-слияние», «заблокировать основную», «настроить защиту ветвей», «настроить примечания к выпуску», «выпуски scaffold», «настроить маркировку выпусков» или вызывает /gh-bootstrap в свежем или слабо сконфигурированном репозитории GitHub. Идемпотент — безопасно повторно запускать уже настроенные репозитории, чтобы привести в порядок недостающие фрагменты. В отличие от /gh, который обрабатывает PR/операции/операции CI для каждой задачи; этот навык предназначен для политики одноразового репо.
