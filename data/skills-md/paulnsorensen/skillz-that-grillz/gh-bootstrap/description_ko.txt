`gh` CLI를 통한 일회성 GitHub 저장소 구성: 기본 브랜치에서 병합 대기열을 활성화하고, PR 제목 커밋 메시지를 사용하여 스쿼시 전용으로 병합을 잠그고, 필수 CI 상태 확인을 연결하고, 자동 생성된 스캐폴드 릴리스 노트(`.github/release.yml`)를 선택적으로 태그 기반 릴리스 워크플로를 추가합니다. 사용자가 "저장소 설정", "병합 대기열 구성", "스쿼시 병합 활성화", "메인 잠금", "분기 보호 설정", "릴리스 노트 구성", "스캐폴드 릴리스", "릴리스 태그 지정 설정"이라고 말하거나 새 또는 느슨하게 구성된 GitHub 저장소에서 /gh-bootstrap을 호출할 때 사용합니다. 멱등성(Idempotent) — 누락된 부분을 일치시키기 위해 이미 구성된 저장소에서 다시 실행하는 것이 안전합니다. 작업별 PR/문제/CI 작업을 처리하는 /gh와는 다릅니다. 이 스킬은 일회성 저장소 정책을 위한 것입니다.
