Configurazione una tantum del repository GitHub tramite la CLI `gh`: abilita una coda di unione sul ramo predefinito, blocca l'unione su solo squash con messaggi di commit del titolo PR, collega i controlli dello stato CI richiesti, note di rilascio generate automaticamente dallo scaffold (`.github/release.yml`) e facoltativamente aggiungi un flusso di lavoro di rilascio basato su tag. Da utilizzare quando l'utente dice "imposta il repository", "configura la coda di unione", "abilita l'unione di squash", "blocca principale", "imposta la protezione del ramo", "configura le note di rilascio", "versioni di scaffold", "imposta il tagging di rilascio" o richiama /gh-bootstrap su un repository GitHub nuovo o configurato in modo approssimativo. Idempotente: sicuro da eseguire nuovamente su repository già configurati per mettere in linea i pezzi mancanti. Distinto da /gh, che gestisce le operazioni PR / issue / CI per attività; questa abilità è per la politica di pronti contro termine una tantum.
