透過「gh」 CLI 進行一次性 GitHub 儲存庫設定：在預設分支上啟用合併佇列，使用 PR 標題提交訊息將合併鎖定為僅限壓縮，連接所需的 CI 狀態檢查，腳手架自動產生的發行說明 (`.github/release.yml`)，並可選擇新增標籤驅動的發布工作流程。當使用者說「設定儲存庫」、「配置合併佇列」、「啟用擠壓合併」、「鎖定主幹」、「設定分支保護」、「配置發行說明」、「支架發布」、「設定發佈標記」或在新的或鬆散配置的 GitHub 儲存庫上呼叫 /gh-bootstrap 時使用。冪等－可以安全地在已配置的儲存庫上重新運行，以使缺少的部分保持一致。與 /gh 不同，/gh 處理每個任務 PR / 問題 / CI 操作；此技能適用於一次性回購政策。
