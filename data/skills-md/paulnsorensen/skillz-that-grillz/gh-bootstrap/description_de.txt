Einmalige Konfiguration des GitHub-Repositorys über die „gh“-CLI: Aktivieren Sie eine Zusammenführungswarteschlange im Standardzweig, sperren Sie das Zusammenführen nur für Squash mit PR-Titel-Commit-Nachrichten, verbinden Sie erforderliche CI-Statusprüfungen, erstellen Sie ein Gerüst für automatisch generierte Versionshinweise („.github/release.yml“) und fügen Sie optional einen Tag-gesteuerten Release-Workflow hinzu. Wird verwendet, wenn der Benutzer „Repo einrichten“, „Zusammenführungswarteschlange konfigurieren“, „Squash-Merging aktivieren“, „Main sperren“, „Zweigschutz einrichten“, „Versionshinweise konfigurieren“, „Gerüstversionen“ sagt, „Release-Tagging einrichten“ sagt oder /gh-bootstrap auf einem neuen oder lose konfigurierten GitHub-Repository aufruft. Idempotent – ​​sichere erneute Ausführung auf bereits konfigurierten Repos, um fehlende Teile in Einklang zu bringen. Unterscheidet sich von /gh, das PR-/Problem-/CI-Operationen pro Aufgabe abwickelt. Dieser Skill ist für einmalige Repo-Richtlinien vorgesehen.
