通过“gh” CLI 进行一次性 GitHub 存储库配置：在默认分支上启用合并队列，使用 PR 标题提交消息将合并锁定为仅限压缩，连接所需的 CI 状态检查，脚手架自动生成的发行说明 (`.github/release.yml`)，并可选择添加标签驱动的发布工作流程。当用户说“设置存储库”、“配置合并队列”、“启用挤压合并”、“锁定主干”、“设置分支保护”、“配置发行说明”、“支架发布”、“设置发布标记”或在新的或松散配置的 GitHub 存储库上调用 /gh-bootstrap 时使用。幂等——可以安全地在已配置的存储库上重新运行，以使缺失的部分保持一致。与 /gh 不同，/gh 处理每个任务 PR / 问题 / CI 操作；该技能适用于一次性回购政策。
