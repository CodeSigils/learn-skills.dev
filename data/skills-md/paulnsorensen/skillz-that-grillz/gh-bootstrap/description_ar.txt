تكوين مستودع GitHub لمرة واحدة عبر `gh` CLI: تمكين قائمة انتظار الدمج على الفرع الافتراضي، وقفل الدمج للاسكواش فقط مع رسائل التزام عنوان PR، والتحقق من حالة CI المطلوبة، وملاحظات الإصدار التي يتم إنشاؤها تلقائيًا (`.github/release.yml`)، وإضافة سير عمل إصدار يعتمد على العلامات بشكل اختياري. يُستخدم عندما يقول المستخدم "إعداد الريبو"، أو "تكوين قائمة انتظار الدمج"، أو "تمكين دمج الاسكواش"، أو "القفل الرئيسي"، أو "إعداد حماية الفرع"، أو "تكوين ملاحظات الإصدار"، أو "إصدارات السقالات"، أو "إعداد علامات الإصدار"، أو استدعاء /gh-bootstrap في مستودع GitHub جديد أو غير مهيئ. Idempotent — آمن لإعادة التشغيل على عمليات إعادة الشراء التي تم تكوينها بالفعل لجلب القطع المفقودة إلى الخط. يختلف عن /gh، الذي يتعامل مع عمليات العلاقات العامة / الإصدار / CI لكل مهمة؛ هذه المهارة مخصصة لسياسة الريبو لمرة واحدة.
