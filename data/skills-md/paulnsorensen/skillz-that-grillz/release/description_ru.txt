Сквозное сокращение выпуска для репозитория GitHub: выберите следующую семантическую версию из обычных коммитов с момента последнего тега, набросайте соответствующие примечания к выпуску (GitHub автоматически генерируется через `.github/release.yml` или вручную сгруппировано по типу изменения с основными моментами и примечаниями к обновлению для критических изменений), создайте и отправьте аннотированный тег, опубликуйте выпуск GitHub и, при необходимости, обновите `CHANGELOG.md`. Используйте, когда пользователь говорит «вырезать выпуск», «отметить выпуск», «опубликовать выпуск», «выпустить vX.Y.Z», «улучшить версию», «какая это должна быть версия», «написать примечания к выпуску», «написать список изменений» или вызывает /release. В отличие от /gh-bootstrap (который формирует .github/release.yml` + инфраструктуру рабочего процесса выпуска один раз) и /gh (необработанные операции `gh Release` для каждой команды): этот навык запускает фактическую церемонию выпуска — решение о версии, примечания, теги, публикацию. Запускайте после того, как работа будет объединена с веткой по умолчанию.
