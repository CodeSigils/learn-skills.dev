GitHub 儲存庫的端對端版本切割：從最後一個標籤以來的常規提交決定下一個語義版本，起草適當的發行說明（GitHub 透過「.github/release.yml」自動生成，或按更改類型手動分組，並突出顯示和升級說明以進行重大更改），創建並帶註釋的標籤，創建並發布 GitHub 版本，並突出顯示和升級說明以進行重大更改），建立並帶有註釋的標籤，發布 GitHub 版本，並可選擇 GitHub 版本，並可選擇「mdCLOG」。當使用者說「剪切版本」、「標記版本」、「發布版本」、「發布 vX.Y.Z」、「升級版本」、「這應該是什麼版本」、「編寫發行說明」、「起草變更日誌」或呼叫 /release 時使用。與 /gh-bootstrap （它建立一次 `.github/release.yml` + 發布工作流程管道）和 /gh （原始的每個命令 `gh release` 操作）不同：此技能運行實際的發布儀式 - 版本決定、註釋、標籤、發布。將工作合併到預設分支後運行。
