قم بإحضار مستودع GitHub مفتوح المصدر بما يتوافق مع معايير المجتمع وخط الأساس لنظافة سلسلة التوريد: دعم ملفات معايير مجتمع GitHub (فحص README، LICENSE، CODE_OF_CONDUCT، CONTRIBUTING، SECURITY، الإصدار + قوالب العلاقات العامة)، وتحديثات إصدار Dependabot، وإجراء مراجعة التبعية، وبطاقة أداء OpenSSF، وCodeQL (عند الاقتضاء)، والتحقق من تنبيهات Dependabot والفحص السري، وأضف رابط شارة أفضل الممارسات لـ OpenSSF. يُستخدم عندما يقول المستخدم "إعداد نظافة OSS"، أو "اجعل هذا الريبو جاهزًا مفتوح المصدر"، أو "أضف ملفات صحة المجتمع"، أو "سلك الاعتماد"، أو "أضف بطاقة الأداء"، أو "شارة OSSF"، أو "تقوية سلسلة التوريد"، أو يستدعي /oss-hygiene في الريبو العام. Idempotent — آمن لإعادة التشغيل؛ يختلف عن القوالب ويسأل قبل الكتابة. يختلف عن /gh-bootstrap (زر الدمج + حماية الفرع) و/الإعدادات الآمنة (إعدادات مقياس المؤسسة كرمز): يركز على واجهة المساهمين وسطح سلسلة التوريد، وليس سياسة الدمج أو المؤسسة. تشغيل بعد /gh-bootstrap؛ قبل الإعلان عن الريبو.
