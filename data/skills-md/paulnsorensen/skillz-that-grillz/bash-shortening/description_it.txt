Scrivi, rivedi o rifattorizza gli script Bash in codice shell conciso e idiomatico. Usa questa abilità ogni volta che l'utente modifica un blocco `.sh`, `.bash` o `bash` con uno shebang Bash (o nessuno shebang in un contesto solo Bash), menziona "accorcia questo script", "rendilo più idiomatico", "ripulisci questa bash", "questo script è troppo lungo", "esiste un modo più breve per farlo in bash" o chiede una revisione del codice degli script di shell. Si attiva anche quando si generano nuovi script Bash da zero: produce modelli idiomatici la prima volta invece di eseguire il refactoring in un secondo momento. Copre l'espansione dei parametri, l'espansione delle parentesi graffe, la sostituzione dei processi, i contesti aritmetici, i modelli di funzioni, le pipeline e i file temporanei, gli heredoc, gli array associativi, l'esecuzione parallela e l'analisi CSV/IFS: 51 tecniche in totale. Rifiuta battute criptiche quando accorciarle danneggerebbe la leggibilità. NON utilizzare per script fish, zsh o solo POSIX `/bin/sh` in cui i bashismi potrebbero interrompere la portabilità.
