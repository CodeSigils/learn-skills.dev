使用安裝的任何堆疊工具來管理堆疊的 PR：Graphite (`gt`)、git-town (`gittown`) 或 GitHub 的本機 `gh stack` 擴充。偵測目前儲存庫中可用的版本，然後透過其每個工具引用（“references/gt.md”、“references/git-town.md”或“references/gh-stack.md”）驅動匹配的版本。當使用者要求「建立堆疊」、「堆疊分支」、「重新堆疊」、「提交堆疊 PR」、「重新設定堆疊基礎」、「同步堆疊」、「追蹤此分支」、「底部 PR 合併，現在做什麼」、「堆疊合併後清理」或呼叫 /pr-stack 時使用。如果沒有可用的，請停止並告訴使用者 - 永遠不要退回到臨時的「git Push」鏈。請勿用於暫存或提交 — 移交給 /commit。請勿用於 PR 審查流量、評論或 CI 檢查 - 移交給 /gh。
