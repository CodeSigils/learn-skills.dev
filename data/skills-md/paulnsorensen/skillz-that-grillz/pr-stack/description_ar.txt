قم بإدارة العلاقات العامة المكدسة باستخدام أي أداة تكديس مثبتة: Graphite (`gt`) أو git-town (`git town`) أو ملحق GitHub الأصلي `gh stack`. يكتشف ما هو متاح في الريبو الحالي، ثم يحرك المطابق من خلال المرجع الخاص بكل أداة (`references/gt.md`، أو `references/git-town.md`، أو `references/gh-stack.md`). يُستخدم عندما يطلب المستخدم "إنشاء مكدس"، أو "تكديس فرع"، أو "إعادة التجميع"، أو "إرسال علاقات عامة مكدسة"، أو "إعادة إنشاء المكدس"، أو "مزامنة المكدس"، أو "تتبع هذا الفرع"، أو "دمج العلاقات العامة السفلية، ماذا الآن"، أو "التنظيف بعد دمج المكدس"، أو استدعاء /pr-stack. إذا لم يكن أي منها متاحًا، توقف وأخبر المستخدم - لا ترجع أبدًا إلى سلاسل "git Push" المخصصة. لا تستخدم للتدريج أو الالتزام - قم بتسليم / الالتزام. لا تستخدمه لحركة مراجعة العلاقات العامة، أو التعليقات، أو فحوصات CI - قم بتسليمها إلى /gh.
