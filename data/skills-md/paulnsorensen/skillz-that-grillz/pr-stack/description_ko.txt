설치된 스택 도구(Graphite(`gt`), git-town(`git town`) 또는 GitHub의 기본 `gh stack` 확장)를 사용하여 스택된 PR을 관리합니다. 현재 저장소에서 사용 가능한 항목을 감지한 다음 도구별 참조(`references/gt.md`, `references/git-town.md` 또는 `references/gh-stack.md`)를 통해 일치하는 항목을 구동합니다. 사용자가 "스택 생성", "분기 스택", "재스택", "스택 PR 제출", "스택 리베이스", "스택 동기화", "이 분기 추적", "최하단 PR 병합, 지금은 무엇입니까", "스택 병합 후 정리"를 요청하거나 /pr-stack을 호출할 때 사용합니다. 사용할 수 있는 것이 없으면 중지하고 사용자에게 알리십시오. 임시 `git push` 체인으로 돌아가지 마십시오. 스테이징이나 커밋에 사용하지 마세요. /commit에 전달하세요. PR 리뷰 트래픽, 댓글, CI 확인에는 사용하지 마세요. /gh에 전달하세요.
