Administre los PR apilados utilizando cualquier herramienta de apilamiento que esté instalada: Graphite (`gt`), git-town (`git town`) o la extensión nativa `gh stack` de GitHub. Detecta cuál está disponible en el repositorio actual y luego controla el correspondiente a través de su referencia por herramienta (`references/gt.md`, `references/git-town.md` o `references/gh-stack.md`). Úselo cuando el usuario solicita "crear una pila", "apilar una rama", "volver a apilar", "enviar un PR apilado", "reorganizar la pila", "sincronizar la pila", "seguir esta rama", "el PR inferior se fusionó, ¿y ahora qué?", ​​"limpiar después de una fusión de pila" o invoca /pr-stack. Si no hay ninguno disponible, deténgase y dígaselo al usuario: nunca recurra a cadenas ad-hoc `git push`. NO lo use para preparar o confirmar; entréguelo a /commit. NO lo use para tráfico de revisión de relaciones públicas, comentarios o verificaciones de CI; entréguelo a /gh.
