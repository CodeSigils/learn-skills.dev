Управляйте составными PR с помощью любого установленного инструмента: Graphite («gt»), git-town («git Town») или собственного расширения GitHub `gh stack`. Обнаруживает, что доступно в текущем репозитории, а затем управляет подходящим по ссылке для каждого инструмента («references/gt.md», «references/git-town.md» или «references/gh-stack.md»). Используйте, когда пользователь просит «создать стек», «сложить ветку», «пересложить», «отправить составной PR», «перебазировать стек», «синхронизировать стек», «отследить эту ветку», «нижний PR объединен, что теперь», «очистить после слияния стека» или вызывает /pr-stack. Если ничего недоступно, остановитесь и сообщите об этом пользователю — никогда не возвращайтесь к разовым цепочкам `git push`. НЕ используйте для подготовки или фиксации — передайте /commit. НЕ используйте для PR-просмотра трафика, комментариев или проверок CI — передайте в /gh.
