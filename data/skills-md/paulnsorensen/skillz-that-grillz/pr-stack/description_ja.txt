インストールされているスタッキング ツール (Graphite (`gt`)、git-town (`git town`)、または GitHub のネイティブ `gh stack` 拡張機能) を使用して、スタックされた PR を管理します。現在のリポジトリで利用可能なものを検出し、ツールごとの参照 (`references/gt.md`、`references/git-town.md`、または `references/gh-stack.md`) を介して一致するものを駆動します。ユーザーが「スタックの作成」、「ブランチのスタック」、「再スタック」、「スタックされた PR の送信」、「スタックのリベース」、「スタックの同期」、「このブランチの追跡」、「マージされた一番下の PR、今どうなっているのか」、「スタックのマージ後のクリーンアップ」を要求する場合、または /pr-stack を呼び出す場合に使用します。利用可能なものがない場合は、停止してユーザーに伝えてください。決してアドホックな `git Push` チェーンにフォールバックしないでください。ステージングやコミットには使用しないでください。/commit にハンドオフしてください。 PR レビューのトラフィック、コメント、または CI チェックには使用しないでください。/gh に引き渡してください。
