Configure la `configuración segura` de GitHub (una aplicación de GitHub basada en Probot de la organización de github) para una política de repositorio declarativa para toda la organización como código. Úselo cuando el usuario diga "configuración como código", "configuración segura", "administrar repositorios declarativamente", "centralizar la configuración del repositorio", "protección de sucursal a nivel de organización", "desarrollar un repositorio de administrador", "aplicación de configuración de github" o invoca /safe-settings en una organización que desea administrar la configuración del repositorio, la protección de sucursales, conjuntos de reglas, etiquetas, equipos, entornos y colaboradores desde un repositorio de administrador. Desarrolla el diseño del repositorio de administración (`settings.yml` + `suborgs/` + `repos/`), los pasos de instalación de la aplicación GitHub y un flujo de trabajo programado de acciones de GitHub de `sincronización completa`. A diferencia de /gh (operaciones por tarea) y /gh-bootstrap (configuración `gh api` de un solo uso de un único repositorio): esta habilidad es para **configuraciones a escala de organización como código** que se reconcilia continuamente.
