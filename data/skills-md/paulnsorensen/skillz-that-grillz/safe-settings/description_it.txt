Configura le "impostazioni sicure" di GitHub (un'app GitHub basata su Probot dell'organizzazione github) per una politica di repository dichiarativa a livello di organizzazione come codice. Da utilizzare quando l'utente dice "impostazioni come codice", "impostazioni sicure", "gestisci repository in modo dichiarativo", "centralizza impostazioni repository", "protezione ramo a livello di organizzazione", "impalcatura di un repository amministratore", "app impostazioni github" o richiama /safe-settings su un'organizzazione che desidera gestire le impostazioni del repository, la protezione del ramo, i set di regole, le etichette, i team, gli ambienti e i collaboratori da un repository amministratore. Supporta il layout del repository di amministrazione (`settings.yml` + `suborgs/` + `repos/`), i passaggi di installazione dell'app GitHub e un flusso di lavoro pianificato di azioni GitHub `full-sync`. Distinta da /gh (operazioni per attività) e /gh-bootstrap (configurazione `gh api` one-shot di un singolo repository): questa abilità è per **impostazioni su scala aziendale come codice** che si riconcilia continuamente.
