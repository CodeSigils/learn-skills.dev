Configurez les « paramètres sécurisés » de GitHub (une application GitHub basée sur Probot de l'organisation github) pour une politique de référentiel déclarative à l'échelle de l'organisation sous forme de code. À utiliser lorsque l'utilisateur dit "paramètres en tant que code", "paramètres sécurisés", "gérer les dépôts de manière déclarative", "centraliser les paramètres du dépôt", "protection des branches au niveau de l'organisation", "échafauder un dépôt d'administrateur", "application de paramètres github", ou invoque /safe-settings sur une organisation qui souhaite gérer les paramètres du dépôt, la protection des branches, les ensembles de règles, les étiquettes, les équipes, les environnements et les collaborateurs à partir d'un dépôt d'administrateur. Échafaude la disposition admin-repo (`settings.yml` + `suborgs/` + `repos/`), les étapes d'installation de l'application GitHub et un workflow d'actions GitHub à synchronisation complète planifié. Distinct de /gh (opérations par tâche) et /gh-bootstrap (configuration unique `gh api` d'un seul dépôt) — cette compétence est destinée aux **paramètres à l'échelle de l'organisation sous forme de code** qui se réconcilie en continu.
