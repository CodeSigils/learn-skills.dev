Настройте «safe-settings» GitHub (приложение GitHub на основе Probot из организации github) для декларативной политики репозитория всей организации в виде кода. Используйте, когда пользователь говорит «настройки как код», «безопасные настройки», «декларативное управление репозиториями», «централизовать настройки репозитория», «защита ветвей на уровне организации», «подготовить репозиторий администратора», «приложение настроек github» или вызывает /safe-settings в организации, которая хочет управлять настройками репозитория, защитой ветвей, наборами правил, метками, командами, средами и соавторами из одного репозитория администратора. Создает макет административного репозитория (settings.yml + suborgs/ + repos/), шаги установки приложения GitHub и запланированный рабочий процесс GitHub Actions с полной синхронизацией. В отличие от /gh (операции для каждой задачи) и /gh-bootstrap (одноразовая конфигурация `gh api` для одного репозитория) — этот навык предназначен для **настроек в масштабе организации в виде кода**, который постоянно согласовывается.
