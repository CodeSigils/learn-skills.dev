Richten Sie GitHubs „safe-settings“ (eine Probot-basierte GitHub-App von der Github-Organisation) für eine deklarative, organisationsweite Repository-Richtlinie als Code ein. Wird verwendet, wenn der Benutzer „Einstellungen als Code“, „sichere Einstellungen“, „Repos deklarativ verwalten“, „Repo-Einstellungen zentralisieren“, „Branch-Schutz auf Organisationsebene“, „Gerüst für ein Admin-Repo“, „Github-Einstellungs-App“ sagt oder /safe-settings in einer Organisation aufruft, die Repo-Einstellungen, Branch-Schutz, Regelsätze, Labels, Teams, Umgebungen und Mitarbeiter von einem Admin-Repo aus verwalten möchte. Stellt das Gerüst für das Admin-Repo-Layout („settings.yml“ + „suborgs/“ + „repos/“), die Installationsschritte der GitHub-App und einen geplanten „vollständig synchronisierten“ GitHub-Aktionsworkflow bereit. Im Gegensatz zu /gh (Operationen pro Aufgabe) und /gh-bootstrap (einmalige „GH-API“-Konfiguration eines einzelnen Repos) – dieser Skill ist für **Einstellungen auf Organisationsebene als Code** gedacht, der kontinuierlich abgeglichen wird.
