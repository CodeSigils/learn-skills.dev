將 GitHub 的「安全性設定」（來自 github 組織的基於 Probot 的 GitHub 應用程式）設定為聲明性、組織範圍的儲存庫策略作為程式碼。當使用者說出「設定即程式碼」、「安全性設定」、「以聲明方式管理儲存庫」、「集中式儲存庫設定」、「組織級分支保護」、「建置管理儲存庫」、「github 設定應用程式」時使用，或是在想要從一個管理儲存庫管理儲存庫設定、分支保護、規則集、標籤、團隊、環境和協作者的組織上呼叫 /safe-sett /safe-settings。建立 admin-repo 佈局（`settings.yml` + `suborgs/` + `repos/`）、GitHub 應用程式安裝步驟和預定的 `full-sync` GitHub Actions 工作流程。與 /gh（每個任務操作）和 /gh-bootstrap（單一儲存庫的一次性 `gh api` 配置）不同 - 這項技能用於**組織規模設定作為程式碼**，持續協調。
