قم بإعداد "الإعدادات الآمنة" لـ GitHub (تطبيق GitHub المستند إلى Probot من مؤسسة github) لسياسة المستودع التعريفية على مستوى المؤسسة كرمز. يُستخدم عندما يقول المستخدم "الإعدادات كرمز"، أو "الإعدادات الآمنة"، أو "إدارة عمليات إعادة الشراء بشكل تصريحي"، أو "إعدادات إعادة الشراء المركزية"، أو "حماية الفرع على مستوى المؤسسة"، أو "دعم مستودع مسؤول"، أو "تطبيق إعدادات github"، أو استدعاء /الإعدادات الآمنة في مؤسسة تريد إدارة إعدادات الريبو، وحماية الفروع، ومجموعات القواعد، والتسميات، والفرق، والبيئات، والمتعاونين من مستودع مسؤول واحد. يدعم تخطيط admin-repo (`settings.yml` + `suborgs/` + `repos/`)، وخطوات تثبيت تطبيق GitHub، وسير عمل GitHub Actions المجدول "المزامنة الكاملة". تختلف عن /gh (عمليات لكل مهمة) و/gh-bootstrap (تكوين طلقة واحدة `gh api` لمستودع واحد) - هذه المهارة مخصصة **إعدادات مقياس المؤسسة كرمز** الذي يتم التوفيق بشكل مستمر.
