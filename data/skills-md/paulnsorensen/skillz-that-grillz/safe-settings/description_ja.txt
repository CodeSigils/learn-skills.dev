GitHub の「safe-settings」 (github 組織の Probot ベースの GitHub アプリ) を、宣言型の組織全体のリポジトリ ポリシーとしてコードとして設定します。ユーザーが「コードとしての設定」、「セーフ設定」、「宣言によるリポジトリの管理」、「リポジトリ設定の一元化」、「組織レベルのブランチ保護」、「管理リポジトリの足場」、「github 設定アプリ」と言う場合、または 1 つの管理リポジトリからリポジトリ設定、ブランチ保護、ルールセット、ラベル、チーム、環境、コラボレータを管理したい組織で /safe-settings を呼び出す場合に使用します。管理リポジトリのレイアウト (`settings.yml` + `suborgs/` + `repos/`)、GitHub アプリのインストール手順、およびスケジュールされた `full-sync` GitHub Actions ワークフローを足場にします。 /gh (タスクごとの操作) や /gh-bootstrap (単一リポジトリのワンショット `gh api` 構成) とは異なります。このスキルは、**組織規模の設定をコードとして**継続的に調整するためのものです。
