将 GitHub 的“安全设置”（来自 github 组织的基于 Probot 的 GitHub 应用程序）设置为声明性、组织范围的存储库策略作为代码。当用户说出“设置即代码”、“安全设置”、“以声明方式管理存储库”、“集中存储库设置”、“组织级分支保护”、“搭建管理存储库”、“github 设置应用程序”时使用，或者在想要从一个管理存储库管理存储库设置、分支保护、规则集、标签、团队、环境和协作者的组织上调用 /safe-settings 。搭建 admin-repo 布局（`settings.yml` + `suborgs/` + `repos/`）、GitHub 应用程序安装步骤和预定的 `full-sync` GitHub Actions 工作流程。与 /gh（每个任务操作）和 /gh-bootstrap（单个存储库的一次性 `gh api` 配置）不同 - 这项技能用于**组织规模设置作为代码**，持续协调。
