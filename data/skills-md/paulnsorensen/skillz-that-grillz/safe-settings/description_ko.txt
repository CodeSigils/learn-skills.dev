선언적 조직 전체 저장소 정책을 코드로 사용하려면 GitHub의 '안전 설정'(github org의 Probot 기반 GitHub 앱)을 설정하세요. 사용자가 "코드로 설정", "안전 설정", "선언적으로 저장소 관리", "저장소 설정 중앙화", "조직 수준 분기 보호", "관리 저장소 스캐폴드", "github 설정 앱"이라고 말하거나 하나의 관리 저장소에서 저장소 설정, 분기 보호, 규칙 세트, 레이블, 팀, 환경 및 공동 작업자를 관리하려는 조직에서 /safe-settings를 호출할 때 사용합니다. admin-repo 레이아웃(`settings.yml` + `suborgs/` + `repos/`), GitHub 앱 설치 단계 및 예약된 `전체 동기화` GitHub Actions 워크플로를 스캐폴드합니다. /gh(작업별 작업) 및 /gh-bootstrap(단일 저장소의 원샷 `gh api` 구성)과 구별됩니다. 이 기술은 지속적으로 조정되는 **코드로서의 조직 규모 설정**에 사용됩니다.
