Organiza y confirma los cambios en git siguiendo el formato de confirmación convencional. Úselo cuando se le solicite confirmar, crear una confirmación o guardar cambios. Redacta mensajes de confirmación significativos entendiendo el por qué, no solo el qué. Nunca modifica las confirmaciones publicadas, nunca omite los ganchos, nunca usa git add -A. Organiza archivos específicos por nombre. No empuja: ese es el trabajo de la habilidad gh.
