قم بتنفيذ التغييرات وتنفيذها على git باتباع تنسيق الالتزام التقليدي. يُستخدم عندما يُطلب منك الالتزام أو إنشاء التزام أو حفظ التغييرات. قم بصياغة رسائل التزام ذات معنى من خلال فهم السبب، وليس فقط ماذا. لا تقم أبدًا بتعديل الالتزامات المنشورة، ولا تتخطى الخطافات أبدًا، ولا تستخدم أبدًا git add -A. مراحل ملفات محددة بالاسم. لا تدفع - هذه هي وظيفة مهارة gh.
