Подготовьте и зафиксируйте изменения в git в соответствии с обычным форматом коммитов. Используйте, когда вас попросят совершить фиксацию, создать фиксацию или сохранить изменения. Составляет осмысленные сообщения о коммитах, понимая почему, а не только что. Никогда не изменяет опубликованные коммиты, никогда не пропускает хуки, никогда не использует git add -A. Стадия отдельных файлов по имени. Не толкает — это работа gh-скилла.
