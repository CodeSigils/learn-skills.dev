Bereitstellen und Festschreiben von Änderungen an Git gemäß dem herkömmlichen Festschreibungsformat. Verwenden Sie diese Option, wenn Sie aufgefordert werden, einen Commit durchzuführen, einen Commit zu erstellen oder Änderungen zu speichern. Entwerfen Sie aussagekräftige Commit-Nachrichten, indem Sie das Warum und nicht nur das Was verstehen. Ändert niemals veröffentlichte Commits, überspringt niemals Hooks, verwendet niemals git add -A. Staging spezifischer Dateien nach Namen. Drückt nicht – das ist die Aufgabe des GH-Skills.
