Metti in stage e invia le modifiche a Git seguendo il formato di commit convenzionale. Da utilizzare quando viene richiesto di confermare, creare un commit o salvare le modifiche. Elabora messaggi di commit significativi comprendendo il perché, non solo il cosa. Non modifica mai i commit pubblicati, non salta mai gli hook, non usa mai git add -A. Organizza file specifici per nome. Non spinge: questo è il compito dell'abilità gh.
