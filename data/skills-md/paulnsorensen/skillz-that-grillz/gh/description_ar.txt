أكمل مهام GitHub باستخدام `gh` CLI - طلبات السحب، والمشكلات، وفحوصات CI، والإصدارات، وعمليات تشغيل سير العمل، والبحث عن التعليمات البرمجية، وإدارة الريبو والتسميات. يُستخدم عندما يقول المستخدم "إنشاء علاقات عامة" أو "دمج علاقات عامة" أو "التحقق من CI" أو "قائمة المشكلات" أو "مراجعة العلاقات العامة" أو "حالة العلاقات العامة" أو "إغلاق المشكلة" أو "تشغيل سير العمل" أو "عرض الإصدار" أو "مستودعات البحث" أو استدعاء /gh. استخدم `git` (السجل والفرق والحالة) للسياق المحلي للقراءة فقط. لا تستخدم للالتزام أو التدريج أو الدفع - استخدم /commit لهؤلاء. لا تستخدمه لمراجعة جودة التعليمات البرمجية - استخدم مهارة مراجعة مخصصة.
