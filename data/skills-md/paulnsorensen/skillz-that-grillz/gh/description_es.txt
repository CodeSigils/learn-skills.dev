Complete tareas de GitHub utilizando la CLI `gh`: solicitudes de extracción, problemas, comprobaciones de CI, lanzamientos, ejecuciones de flujo de trabajo, búsqueda de código, administración de repositorios y etiquetas. Úselo cuando el usuario diga "crear PR", "fusionar PR", "verificar CI", "enumerar problemas", "revisar PR", "estado de PR", "cerrar problema", "activar flujo de trabajo", "ver lanzamiento", "buscar repositorios" o invoca /gh. Utilice `git` (log, diff, status) solo para contexto local de solo lectura. NO lo use para confirmar, preparar o empujar; use /commit para eso. NO lo use para revisión de la calidad del código; use una habilidad de revisión dedicada.
