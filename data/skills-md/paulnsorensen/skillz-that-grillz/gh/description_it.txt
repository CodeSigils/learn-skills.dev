Completa le attività di GitHub utilizzando la CLI `gh`: richieste pull, problemi, controlli CI, rilasci, esecuzioni di flussi di lavoro, ricerca di codice, repository e gestione delle etichette. Da utilizzare quando l'utente dice "crea PR", "unisci PR", "controlla CI", "elenco problemi", "rivedi PR", "stato PR", "chiudi problema", "attiva flusso di lavoro", "visualizza versione", "cerca repository" o richiama /gh. Utilizza "git" (log, diff, status) solo per il contesto locale di sola lettura. NON utilizzare per commit, staging o push: utilizzare /commit per quelli. NON utilizzare per la revisione della qualità del codice: utilizzare una competenza di revisione dedicata.
