Выполняйте задачи GitHub с помощью CLI `gh` — запросы на включение, проблемы, проверки CI, выпуски, запуски рабочих процессов, поиск кода, управление репозиториями и метками. Используйте, когда пользователь говорит «создать PR», «объединить PR», «проверить CI», «составить список проблем», «просмотреть PR», «статус PR», «закрыть проблему», «запустить рабочий процесс», «просмотреть выпуск», «поиск репозиториев» или вызывает /gh. Используйте `git` (log, diff, status) только для локального контекста, доступного только для чтения. НЕ используйте для фиксации, промежуточного размещения или отправки — используйте для них /commit. НЕ используйте для проверки качества кода — используйте специальный навык проверки.
