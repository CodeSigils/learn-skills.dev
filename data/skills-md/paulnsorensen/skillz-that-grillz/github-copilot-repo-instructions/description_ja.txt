GitHub Copilot リポジトリのカスタム命令 (リポジトリ全体) `.github/copilot-instructions.md` および `.github/instructions/*.instructions.md` (パス固有) を追加、監査、または修正します。これにより、Copilot チャット、Copilot コード レビュー、および Copilot コーディング エージェントはすべてプロジェクト全体のガイダンスを取得します。代替エージェント指示ファイルとして「AGENTS.md」、「CLAUDE.md」、および「GEMINI.md」についても説明します。ユーザーが「Copilot 命令を追加する」、「copilot-instructions.md をセットアップする」、「Copilot 構成を監査する」、「Copilot を規則に従っているようにする」、「Copilot コード レビューを構成する」、「パス固有の Copilot ルールを追加する」、「applyTo glob」、「excludeAgent」、「Copilot がガイダンスを無視している」と言う場合に使用します。 /github-copilot-repo-instructions。個人的な (ユーザーごとの) Copilot 命令、つまり /github-copilot-personal-instructions には使用しないでください。このプロジェクトの独自のエンジニアリング原則に沿った独自の生成には使用しないでください。これは、マルチモード Copilot ドライバーのセットアップ モードである `/copilot setup` (インストールされている場合) です。
