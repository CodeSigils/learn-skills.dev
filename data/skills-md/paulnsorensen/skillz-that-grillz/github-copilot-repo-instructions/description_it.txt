Aggiungi, controlla o correggi le istruzioni personalizzate del repository GitHub Copilot — `.github/copilot-instructions.md` (a livello di repository) e `.github/instructions/*.instructions.md` (specifico del percorso) — in modo che Copilot Chat, Copilot code review e Copilot coding agent raccolgano indicazioni a livello di progetto. Copre anche `AGENTS.md`, `CLAUDE.md` e `GEMINI.md` come file di istruzioni dell'agente alternativo. Da utilizzare quando l'utente dice "aggiungi istruzioni Copilot", "imposta copilot-instructions.md", "controlla la nostra configurazione Copilot", "fai in modo che Copilot segua le nostre convenzioni", "configura la revisione del codice Copilot", "aggiungi regole Copilot specifiche del percorso", "applyTo glob", "excludeAgent", "Copilot sta ignorando la nostra guida" o richiama /github-copilot-repo-instructions. NON utilizzare per istruzioni Copilot personali (per utente), ovvero /github-copilot-personal-instructions. NON utilizzare per la generazione supponente in linea con i principi ingegneristici supponenti di questo progetto, ovvero la modalità di configurazione del driver Copilot multimodale, "/copilot setup" (se installato).
