Добавляйте, проверяйте или исправляйте пользовательские инструкции репозитория GitHub Copilot — `.github/copilot-instructions.md` (для всего репозитория) и `.github/instructions/*.instructions.md` (для конкретного пути) — чтобы чат Copilot, проверка кода Copilot и агент кодирования Copilot получали рекомендации для всего проекта. Также рассматриваются `AGENTS.md`, `CLAUDE.md` и `GEMINI.md` как альтернативные файлы инструкций для агентов. Используйте, когда пользователь говорит «добавить инструкции Copilot», «настроить copilot-instructions.md», «проверить нашу конфигурацию Copilot», «заставить Copilot следовать нашим соглашениям», «настроить проверку кода Copilot», «добавить правила Copilot для конкретного пути», «applyTo glob», «excludeAgent», «Copilot игнорирует наши рекомендации» или вызывает инструкции /github-copilot-repo-instructions. НЕ используйте для личных (для каждого пользователя) инструкций Copilot — то есть /github-copilot-personal-instructions. НЕ используйте для самоуверенной генерации, соответствующей самоуверенным инженерным принципам этого проекта — это режим установки многорежимного драйвера Copilot, `/copilot setup` (если установлен).
