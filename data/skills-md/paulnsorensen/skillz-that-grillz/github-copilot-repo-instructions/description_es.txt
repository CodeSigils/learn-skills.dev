Agregue, audite o corrija las instrucciones personalizadas del repositorio de GitHub Copilot: `.github/copilot-instructions.md` (para todo el repositorio) y `.github/instructions/*.instructions.md` (específico de la ruta), para que Copilot Chat, la revisión del código de Copilot y el agente de codificación de Copilot obtengan orientación para todo el proyecto. También cubre `AGENTS.md`, `CLAUDE.md` y `GEMINI.md` como archivos de instrucciones de agente alternativos. Úselo cuando el usuario diga "agregar instrucciones de Copilot", "configurar copilot-instructions.md", "auditar nuestra configuración de Copilot", "hacer que Copilot siga nuestras convenciones", "configurar la revisión del código de Copilot", "agregar reglas de Copilot específicas de la ruta", "applyTo glob", "excludeAgent", "Copilot está ignorando nuestra guía" o invoca /github-copilot-repo-instructions. NO lo use para instrucciones personales (por usuario) de Copilot, es decir, /github-copilot-personal-instructions. NO lo use para generación obstinada alineada con los principios de ingeniería obstinados de este proyecto, ese es el modo de configuración del controlador Copilot multimodo, `/copilot setup` (si está instalado).
