GitHub Copilot 리포지토리 사용자 지정 지침('.github/copilot-instructions.md'(리포지토리 전체) 및 '.github/instructions/*.instructions.md'(경로별))을 추가, 감사 또는 수정합니다. 따라서 Copilot Chat, Copilot 코드 검토 및 Copilot 코딩 에이전트는 모두 프로젝트 전체 지침을 선택합니다. 또한 대체 에이전트 지침 파일로 `AGENTS.md`, `CLAUDE.md` 및 `GEMINI.md`를 포함합니다. 사용자가 "Copilot 지침 추가", "copilot-instructions.md 설정", "Copilot 구성 감사", "Copilot이 규칙을 따르도록 설정", "Copilot 코드 검토 구성", "경로별 Copilot 규칙 추가", "applyTo glob", "excludeAgent", "Copilot이 지침을 무시하고 있습니다"라고 말하거나 /github-copilot-repo-instructions를 호출할 때 사용합니다. 개인용(사용자별) Copilot 지침(/github-copilot-personal-instructions)에는 사용하지 마십시오. 이 프로젝트의 독선적인 엔지니어링 원칙에 부합하는 독선적인 생성에는 사용하지 마십시오. 이는 다중 모드 Copilot 드라이버 `/copilot setup`(설치된 경우)의 설정 모드입니다.
