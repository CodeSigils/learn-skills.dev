Ajoutez, auditez ou corrigez les instructions personnalisées du référentiel GitHub Copilot — `.github/copilot-instructions.md` (à l'échelle du dépôt) et `.github/instructions/*.instructions.md` (spécifiques au chemin) — afin que Copilot Chat, la révision du code Copilot et l'agent de codage Copilot reçoivent tous des conseils à l'échelle du projet. Couvre également « AGENTS.md », « CLAUDE.md » et « GEMINI.md » en tant que fichiers d'instructions d'agent alternatifs. À utiliser lorsque l'utilisateur dit "ajouter des instructions Copilot", "configurer copilot-instructions.md", "auditer notre configuration Copilot", "faire en sorte que Copilot suive nos conventions", "configurer la révision du code Copilot", "ajouter des règles Copilot spécifiques au chemin", "applyTo glob", "excludeAgent", "Copilot ignore nos conseils", ou invoque /github-copilot-repo-instructions. Ne PAS utiliser pour les instructions Copilot personnelles (par utilisateur), c'est-à-dire /github-copilot-personal-instructions. Ne PAS utiliser pour une génération avisée alignée sur les principes d'ingénierie avisés de ce projet — c'est-à-dire le mode de configuration du pilote Copilot multimode, `/copilot setup` (si installé).
