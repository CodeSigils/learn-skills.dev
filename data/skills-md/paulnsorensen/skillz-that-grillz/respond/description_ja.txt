PR の信頼度スコアに基づいてコメントをレビューし、行動をトリアージします。高スコアのものを修正し、低スコアのものを差し戻し、境界線について尋ねます。インライン レビュー スレッド (差分行に固定) と PR レベルのレビュー本文のコメント (年齢テーブルやコパイロットの概要など、レビューとともに送信された概要) の両方を処理します。まず PR のビルドとマージの状態をチェックし、コメントを処理する前にそれらを修正します。ユーザーが「PR コメントに応答する」、「レビューのフィードバックを処理する」、「PR レビューに対処する」、「ビルドを修正する」、「CI を修正する」、「マージ競合を修正する」と言う場合、または PR 番号を使用して /respond を呼び出す場合に使用します。また、ユーザーが特定の PR に言及し、副操縦士、人間、ボットなどのレビュー担当者の提案に対処したい場合にもトリガーされます。このスキルが投稿するすべての返信は「代理人」で終わります。帰属行により、レビュー担当者は、コメントが人間から直接ではなく、人間を代表するエージェントからのものであることを知ることができます。新しいレビューの生成には使用しないでください。これは /copilot-review の仕事です。
