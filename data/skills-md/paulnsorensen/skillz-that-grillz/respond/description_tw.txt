根據置信度分數和行動對公關評論評論進行分類——修復高分的評論，回擊低分的評論，並詢問界限。處理內嵌審閱線程（錨定到差異行）和 PR 級別審閱正文評論（隨審閱提交的摘要，例如年齡表或 Copilot 概述）。首先檢查 PR 的建置和合併狀態並在處理評論之前修復這些狀態。當使用者說「回覆 PR 評論」、「處理評論回饋」、「處理 PR 評論」、「修復建置」、「修復 CI」、「修復合併衝突」或使用 PR 編號呼叫 /respond 時使用。當使用者提及特定 PR 並想要處理審查者建議（副駕駛、人類或機器人）時也會觸發。此技能發布的每個回應均以「代理人代表；」結尾。歸因線，以便評論者可以知道評論來自代表人類的代理，而不是直接來自人類。請勿用於產生新評論 - 這是 /copilot-review 的工作。
