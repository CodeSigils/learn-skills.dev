Genera una directory Ralph approvata da Ralphify (RALPH.md + script opzionali) da una descrizione in inglese semplice del lavoro ripetitivo o iterativo. Utilizzare questa abilità ogni volta che l'utente dice "ralphify", "create a ralph", "ralph wingum", "autonomous loop", "/ralphify", fa riferimento al metodo Ralph Wiggum di Geoffrey Huntley o chiede di racchiudere il lavoro iterativo in ralphify (test-until-green, refactor-until-done, lint-until-clean, cover-until-90, burn-down-todos, risolvere-review-comments). Si attiva anche quando l'utente non nomina esplicitamente ralphify ma descrive un ciclo aperto ("continua a correggere i test finché non vengono superati", "porta i file uno per uno finché la directory non viene completata"). Non eseguire l'attivazione per attività one-shot: esistono ralph per lavori che traggono vantaggio dall'esecuzione N volte rispetto a una condizione di arresto.
