Configure el servidor Serena MCP: sus valores predeterminados globales y la configuración por proyecto de un repositorio. Úselo cuando el usuario diga "configurar serena", "configurar serena para este repositorio", "configuración del proyecto serena", "configuración global de serena", "sintonizar serena para este código base", "editar serena_config.yml", "editar proyecto.yml", "monorepo serena", "serena eligió el idioma incorrecto", "serena está indexando proveedor/node_modules", "hacer que serena sea de solo lectura aquí", "contextos y modos de serena", "qué contexto para claude-code", "deshabilitar la memoria/incorporación de Serena", "apuntar Serena a mi servidor de idioma instalado", "ls_specific_settings", "ls_path", "SERENA_HOME" o "mover la carpeta .serena". Enruta las preguntas por repositorio `.serena/project.yml` a `references/project-config.md` y `~/.serena/serena_config.yml` (configuraciones, contextos, modos, ajuste del servidor de idioma) a `references/global-config.md`. NO lo use para enrutamiento general "use serena para buscar/editar X"; esa es una preocupación de enrutamiento MCP, no de configuración.
