Настройте сервер Serena MCP — его глобальные настройки по умолчанию и настройки репозитория для каждого проекта. Используйте, когда пользователь говорит «настроить Serena», «настроить Serena для этого репозитория», «конфигурация проекта Serena», «глобальная конфигурация Serena», «настроить Serena для этой кодовой базы», «edit serena_config.yml», «edit project.yml», «monorepo serena», «serena выбрала неправильный язык», «serena индексируетvendor/node_modules», «сделать serena доступной только для чтения здесь», «контексты и режимы serena», «какой контекст для кода-кода», «отключить память/подключение Serena», «указать Serena на мой установленный языковой сервер», «ls_specific_settings», «ls_path», «SERENA_HOME» или «переместить папку .serena». Направляет вопросы для каждого репозитория `.serena/project.yml` в `references/project-config.md` и общемашинные `~/.serena/serena_config.yml` (настройки, контексты, режимы, настройка языкового сервера) в `references/global-config.md`. НЕ используйте для общей маршрутизации «использовать serena для поиска/редактирования X» — это проблема маршрутизации MCP, а не конфигурации.
