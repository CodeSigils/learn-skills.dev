قم بتكوين خادم Serena MCP - إعداداته الافتراضية العامة وإعدادات الريبو لكل مشروع. يُستخدم عندما يقول المستخدم "configure serena"، "setup serena for this repo"، "serena project config"، "serena global config"، "tune serena for this codebase"، "edit serena_config.yml"، "edit project.yml"، "monorepo serena"، "اختارت سيرينا اللغة الخاطئة"، "تقوم سيرينا بفهرسة البائع/وحدات العقدة"، "اجعل سيرينا للقراءة فقط هنا"، "سياقات وأوضاع سيرينا"، "ما هو السياق الخاص بـ claude-code"، أو "تعطيل ذاكرة/إعداد سيرينا"، أو "أشر إلى خادم اللغة المثبت لدي"، أو "ls_spec_settings"، أو "ls_path"، أو "SERENA_HOME"، أو "نقل مجلد .serena". توجيه أسئلة `.serena/project.yml' لكل ريبو إلى `references/project-config.md` وعلى مستوى الجهاز `~/.serena/serena_config.yml` (الإعدادات والسياقات والأوضاع وضبط خادم اللغة) إلى `references/global-config.md`. لا تستخدم للتوجيه العام "استخدم serena للعثور على/تحرير X" - فهذا هو مصدر قلق لتوجيه MCP، وليس التكوين.
