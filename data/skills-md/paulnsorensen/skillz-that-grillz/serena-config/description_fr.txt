Configurez le serveur Serena MCP - ses valeurs par défaut globales et les paramètres d'un dépôt par projet. À utiliser lorsque l'utilisateur dit « configurer Serena », « configurer Serena pour ce dépôt », « configuration du projet Serena », « configuration globale Serena », « régler Serena pour cette base de code », « modifier serena_config.yml », « modifier projet.yml », « monorepo serena », « Serena a choisi la mauvaise langue », « Serena indexe les fournisseurs/node_modules », « rendre Serena en lecture seule ici », « contextes et modes Serena », « quoi » contexte pour claude-code", "désactiver la mémoire/intégration de Serena", "pointer Serena vers mon serveur de langue installé", "ls_special_settings", "ls_path", "SERENA_HOME" ou "déplacer le dossier .serena". Achemine les questions `.serena/project.yml` par dépôt vers `references/project-config.md` et à l'échelle de la machine `~/.serena/serena_config.yml` (paramètres, contextes, modes, réglage du serveur de langue) vers `references/global-config.md`. Ne PAS utiliser pour le routage général « utiliser Serena pour rechercher/modifier X » — il s'agit d'un problème de routage MCP, pas de configuration.
