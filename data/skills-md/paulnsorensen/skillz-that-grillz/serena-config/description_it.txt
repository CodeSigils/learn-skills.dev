Configura il server Serena MCP: le sue impostazioni predefinite globali e le impostazioni per progetto del repository. Da utilizzare quando l'utente dice "configura serena", "imposta serena per questo repository", "serena project config", "serena global config", "sintonizza serena per questa codebase", "modifica serena_config.yml", "modifica progetto.yml", "monorepo serena", "serena ha scelto la lingua sbagliata", "serena sta indicizzando fornitore/node_modules", "rendi serena qui di sola lettura", "contesti e modalità serena", "quale contesto per claude-code", "disabilita serena memory/onboarding", "orienta Serena al server della lingua installata", "ls_specific_settings", "ls_path", "SERENA_HOME" o "sposta la cartella .serena". Indirizza le domande `.serena/project.yml` per repository a `references/project-config.md` e `~/.serena/serena_config.yml` a livello di macchina (impostazioni, contesti, modalità, ottimizzazione del server della lingua) a `references/global-config.md`. NON utilizzare per il routing generale "usa Serena per trovare/modificare X": si tratta di un problema di routing MCP, non di configurazione.
