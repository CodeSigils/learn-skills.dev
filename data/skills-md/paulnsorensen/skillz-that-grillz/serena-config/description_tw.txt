配置 Serena MCP 伺服器 - 其全域預設值和儲存庫的每個項目設定。當使用者說「設定 Serena」、「為此儲存庫設定 Serena」、「Serena 專案配置」、「Serena 全域設定」、「為此程式庫調整 Serena」、「編輯 Serena_config.yml」、「編輯 Project.yml」、「monorepo Serena"、「Serena 選擇了錯誤的語言」、「Serena 正在供應商/Serena上下文與模式」、「克勞德程式碼的上下文」、「停用 Serena 記憶體/載入」、「將 Serena 指向我安裝的語言伺服器」、「ls_specific_settings」、「ls_path」、「SERENA_HOME」或「移動 .serena 資料夾」。將每個儲存庫的“.serena/project.yml”問題路由到“references/project-config.md”，並將機器範圍的“~/.serena/serena_config.yml”（設定、上下文、模式、語言伺服器調整）路由到“references/global-config.md”。不要用於一般的「使用 serena 尋找/編輯 X」路由 — 這是 MCP 路由問題，而不是設定。
