GitHub Copilot **個人** カスタム手順を追加または監査します。これは、github.com/copilot で設定されたユーザーごとのプロンプトで、そのアカウントが github.com 上で行うすべての Copilot Chat 会話に適用されます。それらを設定する場所、それらが適用されるものと適用されないもの (github.com Chat のみ - IDE、モバイル、コーディング エージェントではない)、それらがリポジトリおよび組織の指示とどのようにマージされるか、および検証について説明します。ユーザーが「個人用 Copilot 指示を設定する」、「Copilot を構成する」、「Copilot が間違った言語で応答し続ける」、「Copilot に私の好みのトーンを使用させる」、「個人用 Copilot プロンプト」、「ユーザーレベルの Copilot 構成」、「Copilot が私の設定を無視している」と言う場合、または /github-copilot-personal-instructions を呼び出す場合に使用します。リポジトリ スコープの命令、つまり /github-copilot-repo-instructions には使用しないでください。
