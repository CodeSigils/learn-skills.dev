Ajoutez ou auditez les instructions personnalisées **personnelles** de GitHub Copilot — l'invite par utilisateur configurée sur github.com/copilot qui s'applique à chaque conversation Copilot Chat que le compte a sur github.com. Explique où les définir, ce à quoi ils font et ne s'appliquent pas (github.com Chat uniquement - pas IDE, pas mobile, pas d'agent de codage), comment ils fusionnent avec les instructions du référentiel et de l'organisation, et la vérification. À utiliser lorsque l'utilisateur dit « définir les instructions personnelles du Copilot », « configurer mon Copilot », « Copilot continue de répondre dans la mauvaise langue », « faire en sorte que Copilot utilise ma tonalité préférée », « invite personnelle du Copilot », « configuration du Copilot au niveau de l'utilisateur », « Copilot ignore mes préférences » ou invoque /github-copilot-personal-instructions. Ne PAS utiliser pour les instructions à l'échelle du référentiel, c'est-à-dire /github-copilot-repo-instructions.
