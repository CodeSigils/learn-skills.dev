Fügen Sie GitHub Copilot **persönliche** benutzerdefinierte Anweisungen hinzu oder prüfen Sie diese – die unter github.com/copilot konfigurierte Eingabeaufforderung pro Benutzer, die für jede Copilot-Chat-Konversation gilt, die dieses Konto auf github.com führt. Beschreibt, wo sie gesetzt werden, wofür sie gelten und was nicht (nur github.com Chat – nicht IDE, nicht mobil, kein Coding Agent), wie sie mit Repository- und Organisationsanweisungen zusammengeführt werden und wie sie überprüft werden. Wird verwendet, wenn der Benutzer sagt: „Persönliche Copilot-Anweisungen festlegen“, „Mein Copilot konfigurieren“, „Copilot antwortet ständig in der falschen Sprache“, „Copilot meinen bevorzugten Ton verwenden lassen“, „Persönliche Copilot-Eingabeaufforderung“, „Copilot-Konfiguration auf Benutzerebene“, „Copilot ignoriert meine Präferenzen“ oder /github-copilot-personal-instructions aufruft. NICHT für Repository-bezogene Anweisungen verwenden – also /github-copilot-repo-instructions.
