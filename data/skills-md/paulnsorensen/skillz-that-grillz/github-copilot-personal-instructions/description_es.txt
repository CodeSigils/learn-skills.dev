Agregue o audite instrucciones personalizadas **personales** de GitHub Copilot: el mensaje por usuario configurado en github.com/copilot que se aplica a cada conversación de Copilot Chat que la cuenta tiene en github.com. Cubre dónde configurarlos, a qué se aplican y a qué no se aplican (solo chat de github.com, no IDE, no móvil, no agente de codificación), cómo se fusionan con el repositorio y las instrucciones de la organización, y la verificación. Úselo cuando el usuario dice "establecer instrucciones personales de Copilot", "configurar mi Copilot", "Copilot sigue respondiendo en el idioma incorrecto", "hacer que Copilot use mi tono preferido", "mensaje de Copilot personal", "configuración de Copilot a nivel de usuario", "Copilot está ignorando mis preferencias" o invoca /github-copilot-personal-instructions. NO lo use para instrucciones con alcance de repositorio, es decir, /github-copilot-repo-instructions.
