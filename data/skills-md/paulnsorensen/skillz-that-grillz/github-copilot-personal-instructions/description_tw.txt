新增或審核 GitHub Copilot **個人** 自訂指令 - 在 github.com/copilot 上配置的每個使用者提示，適用於該帳戶在 github.com 上的每個 Copilot 聊天對話。涵蓋在哪裡設定它們、它們的作用和不適用於（僅限 github.com 聊天 - 不是 IDE、不是行動裝置、不是編碼代理）、它們如何與儲存庫和組織指令合併以及驗證。當使用者說「設定個人 Copilot 指令」、「設定我的 Copilot」、「Copilot 總是以錯誤的語言回應」、「讓 Copilot 使用我喜歡的語氣」、「個人 Copilot 提示」、「使用者級 Copilot 設定」、「Copilot 忽略我的首選項」或呼叫 /github-copilot-person不要用於儲存庫範圍的指令 - 即 /github-copilot-repo-instructions。
