Добавляйте или проверяйте **персональные** пользовательские инструкции GitHub Copilot — приглашение для каждого пользователя, настроенное на github.com/copilot, которое применяется к каждому разговору в чате Copilot, который эта учетная запись ведет на github.com. Описывает, где их устанавливать, что они делают и к чему не применяются (только чат github.com — не IDE, не мобильный телефон, не агент кодирования), как они объединяются с инструкциями репозитория и организации, а также проверку. Используйте, когда пользователь говорит: «Установи персональные инструкции Copilot», «Настрой моего Copilot», «Второй пилот продолжает отвечать на неправильном языке», «заставь Copilot использовать мой предпочтительный тон», «личное приглашение Copilot», «конфигурация Copilot на уровне пользователя», «Второй пилот игнорирует мои предпочтения» или вызывает /github-copilot-personal-instructions. НЕ используйте для инструкций на уровне репозитория — то есть /github-copilot-repo-instructions.
