ユーザーが「コパイロットのレビュー」、「コパイロットによるレビュー」、「コパイロットに委任」、「コパイロットにこれを修正してもらう」、「コパイロット エージェントのタスク」、「コパイロットのセットアップ」、「コパイロットの指示を生成」、「このリポジトリのコパイロットをブートストラップ」と言う場合、または `/copilot` を呼び出すときに使用します。 3 つのモード: `review` (PR でコード レビューを実行し、インラインの `@copilot fix this` コメントを介して修正を Copilot にルーティングします)、`delegate` (`gh エージェント タスク` を作成し、コーディング エージェントが PR を開くまでポーリングし、オプションでレビューに引き継ぎます)、および `setup` (`.github/copilot-instructions.md` とロールごとの`.github/instructions/*.instructions.md` ファイル)。 「レビュー」と「デリゲート」は日常的なものです。 `setup` は、ユーザーが明示的に要求した場合にのみ、`references/setup.md` からオンデマンドでロードされる 1 回限りのリポジトリ ブートストラップです。単純な GitHub PR 作業には使用しないでください。それが `/gh` の仕事です。
