Wird verwendet, wenn der Benutzer „Copilot-Überprüfung“, „Mit Copilot überprüfen“, „An Copilot delegieren“, „Copilot dies beheben lassen“, „Copilot-Agent-Aufgabe“, „Copilot einrichten“, „Copilot-Anweisungen generieren“, „Bootstrap-Copilot für dieses Repo“ sagt oder „/copilot“ aufruft. Drei Modi: „Review“ (führen Sie eine Codeüberprüfung für einen PR durch und leiten Sie Korrekturen über Inline-Kommentare „@copilot fix this“ an Copilot weiter), „Delegieren“ (erstellen Sie eine „GH-Agent-Aufgabe“, fragen Sie ab, bis der Coding-Agent einen PR öffnet, und übergeben Sie ihn optional zur Überprüfung) und „Setup“ (einmaliger Bootstrap, der „.github/copilot-instructions.md“ und die Pro-Rolle schreibt `.github/instructions/*.instructions.md`-Dateien). „Überprüfen“ und „Delegieren“ sind Routine; „setup“ ist ein einmaliger Repo-Bootstrap, der bei Bedarf nur dann von „references/setup.md“ geladen wird, wenn der Benutzer ausdrücklich danach fragt. NICHT für reine GitHub-PR-Arbeit verwenden – das ist die Aufgabe von „/gh“.
