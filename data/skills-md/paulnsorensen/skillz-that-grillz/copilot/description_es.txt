Úselo cuando el usuario diga "revisión del copiloto", "revisar con el copiloto", "delegar al copiloto", "hacer que el copiloto arregle esto", "tarea del agente del copiloto", "configurar el copiloto", "generar instrucciones del copiloto", "arrancar el copiloto para este repositorio" o invoca `/copilot`. Tres modos: `revisar` (ejecutar una revisión de código en un PR y enrutar correcciones a Copilot a través de comentarios en línea `@copilot fix this`), `delegar` (crear una `gh agent-task`, sondear hasta que el agente codificador abra un PR, opcionalmente entregarlo para revisar) y `setup` (arranque de una sola vez que escribe `.github/copilot-instructions.md` y el por rol `.github/instructions/*.instructions.md` archivos). "revisar" y "delegar" son rutinarios; `setup` es un arranque de repositorio único que se carga bajo demanda desde `references/setup.md` solo cuando el usuario lo solicita explícitamente. NO lo use para trabajos simples de relaciones públicas de GitHub; ese es el trabajo de `/gh`.
