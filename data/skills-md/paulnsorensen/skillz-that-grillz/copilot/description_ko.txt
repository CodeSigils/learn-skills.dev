사용자가 "부조종사 검토", "부조종사로 검토", "부조종사에 위임", "부조종사가 이 문제를 해결하도록 하세요", "부조종사 에이전트 작업", "부조종사 설정", "부조종사 지침 생성", "이 저장소에 대한 부트스트랩 부조종사"라고 말하거나 `/copilot`을 호출할 때 사용하세요. 세 가지 모드: `검토`(PR에 대한 코드 검토를 실행하고 인라인 `@copilot 수정 이` 주석을 통해 수정 사항을 Copilot에 라우팅), `위임`(`gh 에이전트 작업` 생성, 코딩 에이전트가 PR을 열 때까지 폴링하고 선택적으로 검토를 위해 전달), `설정`(`.github/copilot-instructions.md` 및 역할별을 작성하는 일회성 부트스트랩) `.github/instructions/*.instructions.md` 파일). '검토'와 '위임'은 일상적인 일입니다. `setup`은 사용자가 명시적으로 요청할 때만 `references/setup.md`에서 요청 시 로드되는 일회성 저장소 부트스트랩입니다. 일반적인 GitHub PR 작업에는 사용하지 마십시오. 이는 `/gh`의 작업입니다.
