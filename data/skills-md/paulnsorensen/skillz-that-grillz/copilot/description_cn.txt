当用户说“副驾驶审阅”、“与副驾驶一起审阅”、“委托给副驾驶”、“让副驾驶修复此问题”、“副驾驶代理任务”、“设置副驾驶”、“生成副驾驶指令”、“为此存储库引导副驾驶”或调用“/copilot”时使用。三种模式：“审查”（在 PR 上运行代码审查，并通过内联“@copilot 修复此”注释将修复路由到 Copilot）、“委托”（创建“gh 代理任务”，轮询直到编码代理打开 PR，可选择移交审查）和“设置”（写入“.github/copilot-instructions.md”和每个角色的一次性引导程序） `.github/instructions/*.instructions.md` 文件）。 “审查”和“委托”是例行公事； `setup` 是一个一次性存储库引导程序，仅当用户明确要求时才从 `references/setup.md` 按需加载。不要用于普通的 GitHub PR 工作——那是“/gh”的工作。
