當使用者說「副駕駛審閱」、「與副駕駛一起審查」、「委託給副駕駛」、「讓副駕駛修復此問題」、「副駕駛代理任務」、「設定副駕駛」、「產生副駕駛指令」、「為此儲存庫引導副駕駛」或呼叫「/copilot」時使用。三種模式：「審查」（在 PR 上執行程式碼審查，並透過內嵌「@copilot 修復此」註解將修復路由到 Copilot）、「委託」（建立「gh 代理任務」，輪詢直到編碼代理開啟 PR，可選擇移交審查）和「設定」（寫入「.github/copilot-instructions.`gions.`m. 「審查」和「委託」是例行公事； `setup` 是一個一次性儲存庫引導程序，僅當用戶明確要求時才從 `references/setup.md` 按需加載。不要用於普通的 GitHub PR 工作——那是“/gh”的工作。
