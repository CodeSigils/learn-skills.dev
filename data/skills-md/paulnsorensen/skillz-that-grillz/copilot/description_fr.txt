À utiliser lorsque l'utilisateur dit « révision du copilote », « révision avec le copilote », « déléguer au copilote », « demander au copilote de résoudre ce problème », « tâche d'agent du copilote », « configurer le copilote », « générer des instructions du copilote », « amorcer le copilote pour ce dépôt » ou invoque « /copilot ». Trois modes : `review` (exécuter une révision de code sur un PR et acheminer les correctifs vers Copilot via les commentaires en ligne `@copilot fix this`), `delegate` (créer une `gh agent-task`, interroger jusqu'à ce que l'agent de codage ouvre un PR, éventuellement le transmettre pour révision) et `setup` (amorçage unique qui écrit `.github/copilot-instructions.md` et le rôle par rôle `.github/instructions/*.instructions.md`). « réviser » et « déléguer » sont des routines ; `setup` est un bootstrap de dépôt unique chargé à la demande à partir de `references/setup.md` uniquement lorsque l'utilisateur le demande explicitement. Ne PAS utiliser pour un simple travail de relations publiques sur GitHub — c'est le travail de `/gh`.
