Используйте, когда пользователь говорит «проверка второго пилота», «проверка вторым пилотом», «делегировать второму пилоту», «попросить второго пилота исправить это», «задача агента второго пилота», «настроить второго пилота», «сгенерировать инструкции второго пилота», «загрузить второго пилота для этого репозитория» или вызывает `/copilot`. Три режима: `просмотр` (запуск проверки кода по PR и направление исправлений в Copilot через встроенные комментарии `@copilot fix this`), `делегирование` (создание `gh агента-задачи`, опрос до тех пор, пока агент кодирования не откроет PR, при необходимости передача на проверку) и `настройка` (однократная начальная загрузка, которая записывает `.github/copilot-instructions.md` и для каждой роли файлы `.github/instructions/*.instructions.md`). «обзор» и «делегирование» являются обычными; `setup` — это одноразовый загрузчик репозитория, загружаемый по запросу из `references/setup.md` только тогда, когда пользователь явно просит. НЕ используйте для простой пиар-работы GitHub — это работа `/gh`.
