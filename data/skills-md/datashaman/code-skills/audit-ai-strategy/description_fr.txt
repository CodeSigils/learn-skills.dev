Auditer la stratégie d'IA d'une base de code à travers l'optique à quatre compartiments de John Cutler : mauvaises idées
amplifié, les bonnes idées suralimentées, les possibilités véritablement nouvelles et la méta-compétence
du contexte de lecture. Identifie où l'IA est ancrée sur des modèles brisés, où elle
amplifie ce qui fonctionne déjà et où la base de code pourrait inclure des flux de travail qui
n'existent que parce que l'IA est dans la boucle.
À utiliser lorsqu'on vous demande de « auditer la stratégie d'IA », « d'évaluer notre guide d'IA », de « trouver l'IA
opportunités", ou "où pouvons-nous sortir des sentiers battus avec l'IA".
