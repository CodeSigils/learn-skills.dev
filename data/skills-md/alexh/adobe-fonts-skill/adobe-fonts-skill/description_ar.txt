ابحث في مجموعات Adobe Fonts (Typekit)، وقم بإنشاء مجموعات/مشاريع الويب وإدارتها، وقم بإرجاع مقتطفات مضمنة جاهزة للاستخدام بالإضافة إلى قيم مجموعة خطوط CSS. يُستخدم عندما يطلب المستخدم العثور على خطوط Adobe، أو مقارنة خيارات الخطوط، أو إعداد Typekit لموقع ويب، أو إضافة خطوط إلى المجموعات، أو نشر المجموعات، أو إنشاء بيانات تعريف مضمنة لخط النسخ/اللصق لسير عمل Codex أو Claude Code أو OpenCode.
