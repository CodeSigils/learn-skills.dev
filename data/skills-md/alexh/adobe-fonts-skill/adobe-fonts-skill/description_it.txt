Cerca famiglie di font Adobe (Typekit), crea e gestisci kit/progetti Web e restituisci snippet di incorporamento pronti all'uso oltre a valori della famiglia di font CSS. Da utilizzare quando l'utente chiede di trovare font Adobe, confrontare le opzioni dei font, configurare Typekit per un sito Web, aggiungere font ai kit, pubblicare kit o generare metadati di incorporamento di font copia/incolla per flussi di lavoro Codex, Claude Code o OpenCode.
