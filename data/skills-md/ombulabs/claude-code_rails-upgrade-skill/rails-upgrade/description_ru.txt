Анализирует приложения Rails и создает подробные отчеты об обновлении с критическими изменениями, устареваниями и пошаговыми руководствами по миграции для Rails 2.3–8.1. Используйте при обновлении приложений Rails, планировании многошаговых обновлений или запросе изменений для конкретной версии. На основе методологии FastRuby.io и электронной книги «Полное руководство по обновлению Rails».
