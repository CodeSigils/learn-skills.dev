يحلل تطبيقات Rails وينشئ تقارير ترقية شاملة مع التغييرات العاجلة وعمليات الإيقاف وأدلة الترحيل خطوة بخطوة لـ Rails 2.3 إلى 8.1. يُستخدم عند ترقية تطبيقات Rails، أو التخطيط للترقيات متعددة القفزات، أو الاستعلام عن التغييرات الخاصة بالإصدار. استنادًا إلى منهجية FastRuby.io والكتاب الإلكتروني "الدليل الكامل لترقية القضبان".
