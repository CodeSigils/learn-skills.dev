Облегчает этап обучения проверенному методу интервью с клиентами — половина записи: преобразование исходного материала из ОДНОГО разговора с клиентом (расшифровка, заметки, дамп памяти) в краткий файл отчета для каждого человека, сопоставленный с пронумерованным списком вопросов для интервью (Q1, Q2, … с тегами H-номера). Один краткий ответ на каждый фактически заданный вопрос, ключевые фразы сохраняются дословно, не заданные вопросы честно пропускаются, однострочный комментарий только в тех случаях, когда текущий контекст помогает в дальнейшем анализе, и раздел дополнений для всего услышанного, что не подходит ни для одного вопроса. Загружается, когда пользователь только что провел интервью с клиентом и говорит: «вот стенограмма», «обработайте записи моих звонков», «сопоставьте этот разговор с моими вопросами» или «добавьте это интервью в запись». НЕ загружайтесь для написания целей, гипотез или вопросов для интервью (более ранние шаги), для синтеза закономерностей в ходе нескольких интервью и обновления гипотез (следующий шаг), а также для подведения итогов встреч или стенограмм, не связанных с интервью с клиентами.
