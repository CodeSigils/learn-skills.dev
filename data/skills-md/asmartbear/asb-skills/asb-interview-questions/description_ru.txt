Облегчает третий этап проверенного метода опроса клиентов: перевод гипотез в открытые, объективные вопросы для интервью — каждый из которых представляет собой миниатюрный эксперимент, предназначенный для проверки одной гипотезы без привлечения свидетеля. Два режима: при наличии единственной гипотезы вопрос формулируется и выводится окончательный вопрос в чат; имея файл HYPOTHESES.md, он перебирает весь список, группируя связанные гипотезы, и поддерживает файл QUESTIONS.md (с номерами Q1, Q2, …, сопоставленный с H-числами) как живой, возобновляемый артефакт. Загружается, когда у пользователя есть гипотезы и он хочет задать вопросы на собеседовании, спрашивает, как сформулировать вопрос для клиентов, не искажая ответ, или говорит: «Превратите мои гипотезы в вопросы» или «Помогите мне задать вопрос об X без наводки». НЕ загружайте для написания целевых вопросов или гипотез (более ранние шаги), для проведения или анализа самих интервью, для разработки опроса/анкеты или для собеседований при приеме на работу.
