Облегчает последний этап проверенного метода интервью с клиентами: объединение всего, что было получено в ходе интервью (GOALS.md, HYPOTHESES.md, QUESTIONS.md и каталог отчетов по каждому интервью), в единый FINAL-REPORT.md, который может использовать вся компания. Вверху: максимально краткое изложение без потери существенной информации. Ниже: пронумерованные результаты (F1, F2, …) с пометками «подтверждено/опровергнуто/направлено/наблюдается/непроверено», каждый из которых цитирует отчеты и дословно цитирует клиентов, а также краткие описания по каждой области, в которых собраны доказательства для определения идеального клиента, позиционирования, ценообразования, маркетинга и продаж, а также приоритетов продукта. Загружается, когда пользователь говорит «запишите то, что мы узнали из интервью», «подведите итоги интервью для команды» или «превратите интервью в отчет». НЕ загружайте для обновления гипотез на основе интервью (этап синтеза), для записи одного разговора (этап разбора полетов) или для фактического выполнения работы по позиционированию, поиску идеальных клиентов или ценообразованию, которые содержатся в отчете.
