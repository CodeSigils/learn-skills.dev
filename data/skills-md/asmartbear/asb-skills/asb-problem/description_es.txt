Califica si una idea de negocio puede convertirse en un negocio viable, recorriendo el camino desde 'El problema' hasta 'Modelo de negocio viable': un mercado objetivo específico recibe la puntuación Fermi según siete criterios multiplicadores (plausible, consciente de sí mismo, lucrativo, líquido, ansioso ×2, duradero), cada número optimista se cuestiona a menos que la evidencia lo respalde, y cuando el veredicto es malo, los nichos más estrechos se vuelven a calificar uno al lado del otro. Se carga cuando el usuario pregunta si su startup o idea de producto es viable, si realmente existe un mercado para lo que quiere construir, por qué un producto que resuelve un problema real no se vende, cuál de varios mercados objetivo perseguir, si perseverar o renunciar a un producto, o dice "califique mi idea". NO cargue para pruebas de estrés generales de planes o presentaciones sin la pregunta de viabilidad, para crear un perfil completo de cliente ideal, para escribir preguntas de entrevistas con clientes o para problemas de ejecución como optimización de embudos, contratación o recaudación de fondos.
