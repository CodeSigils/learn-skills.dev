Facilita la fase di apprendimento di un metodo collaudato di intervista al cliente - la metà della sintesi: legge una directory di file di debriefing per intervista rispetto ai file HYPOTHESES.md e QUESTIONS.md di lavoro e propone aggiornamenti citati dalle prove UNO alla volta - raddoppia, regola i numeri, segna come smentito, parcheggia le osservazioni ascoltate una volta in una sezione di controllo "È divertente", aggiungi nuove ipotesi con nuove domande - applicando ogni modifica concordata direttamente ai file con un registro delle modifiche e termina con un verdetto di arresto, continuazione o rimirazione sull'intervista stessa. Carica quando l'utente dice "cosa abbiamo imparato da queste interviste", "aggiorna le mie ipotesi dalle interviste", "sintetizza gli appunti delle mie interviste" o "devo continuare a intervistare?" NON caricare per registrare una singola conversazione in un debriefing (il passaggio precedente), per scrivere obiettivi iniziali, ipotesi o domande per l'intervista (passi precedenti) o per decidere cosa costruire dopo (viene dopo questo metodo).
