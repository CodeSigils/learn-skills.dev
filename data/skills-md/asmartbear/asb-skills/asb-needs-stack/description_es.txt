Crea una pila de necesidades del cliente: la escalera en la que cada necesidad es un medio para llegar a un nivel superior (comprar infraestructura → configurar un sitio de WordPress → tener un sitio web personal → obtener una oferta de libro). Ancla el nivel que satisface el producto del usuario, expresado como el objetivo del cliente en sus propias palabras, luego camina hacia abajo (los pasos que el producto vuelve obsoletos) y hacia arriba (lo que el cliente realmente quiere), cristalizando cada nivel (redacción específica, un verdadero vínculo entre un medio y un fin, ocupantes nombrados en el mundo real) antes de continuar. Registra la pila en NEEDS-STACK.md con el nivel del usuario marcado y el rol de posicionamiento de cada nivel: lo que hace, promete, hace referencia como aspiración o se jacta de obviarlo. Cargue cuando el usuario pregunte qué quiere realmente su cliente, en qué nivel opera su producto, quiénes son sus alternativas reales (no solo competidores), o para "construir nuestra pila de necesidades". NO lo cargue para reescribir el texto de marketing desde una pila terminada; esa es una tarea de posicionamiento separada que consume este archivo.
