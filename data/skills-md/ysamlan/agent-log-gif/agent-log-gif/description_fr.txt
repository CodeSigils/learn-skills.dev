Générez des replays animés GIF/MP4/AVIF à partir de sessions Claude Code ou Codex. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un GIF, une animation, une vidéo ou une rediffusion visuelle d'une session de codage, qu'il dise « créer un gif de ma session », « animer cette conversation », « créer un enregistrement de terminal », « partager une rediffusion » ou référencer directement agent-log-gif. Se déclenche également lorsque les utilisateurs souhaitent rechercher, rechercher ou parcourir leurs sessions Claude Code ou Codex à des fins de visualisation. Peut également créer des GIF de session synthétiques/fictifs à partir de zéro pour des démos, des documents ou des didacticiels — si l'utilisateur dit « créer un gif de démonstration montrant X » ou « créer un faux gif de session », utilisez-le.
