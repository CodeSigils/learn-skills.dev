Genera replay di terminali GIF/MP4/AVIF animati dalle sessioni Claude Code o Codex. Utilizza questa abilità ogni volta che l'utente desidera creare una GIF, un'animazione, un video o una riproduzione visiva di una sessione di codifica, sia che dica "crea una gif della mia sessione", "anima quella conversazione", "crea una registrazione del terminale", "condividi un replay" o faccia riferimento direttamente ad agent-log-gif. Si attivano anche quando gli utenti desiderano trovare, cercare o sfogliare le sessioni di Claude Code o Codex a scopo di visualizzazione. Puoi anche creare GIF di sessione sintetiche/immaginarie da zero per demo, documenti o tutorial: se l'utente dice "crea una gif demo che mostri X" o "crea una gif di sessione falsa", utilizzalo.
