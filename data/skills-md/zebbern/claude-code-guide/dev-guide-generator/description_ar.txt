يُنشئ برامج تعليمية فنية كاملة بدءًا من المتطلبات الأساسية وإعداد البيئة وحتى الخطوات الأساسية واستكشاف الأخطاء وإصلاحها وورقة الغش النهائية. قم بتشغيل الطلبات لكتابة برنامج تعليمي، أو إنشاء دليل الإعداد، أو تنظيم الخطوات للمبتدئين، أو الكلمات الرئيسية مثل خطوة بخطوة، أو البدء السريع، أو الدليل الإرشادي.
