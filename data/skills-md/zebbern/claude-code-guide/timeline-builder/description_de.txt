Generieren Sie schöne interaktive Timeline-HTML-Seiten aus JSON-Daten mit vertikalen, horizontalen oder doppelseitigen Layouts, reduzierbaren Details und benutzerdefinierten Farben. Ideal für Projektmeilensteine, Firmengeschichten oder Lebensläufe. Wird ausgelöst, wenn ein Benutzer „Zeitleiste“, „Ereignisverlauf“, „Projektmeilensteine“, „Veröffentlichungsprotokoll“ erwähnt oder die Visualisierung einer chronologischen Abfolge von Daten anfordert.
