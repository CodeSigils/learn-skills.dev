قم بإنشاء صفحات HTML تفاعلية جميلة للمخطط الزمني من بيانات JSON، مع تخطيطات رأسية أو أفقية أو مزدوجة الجانب وتفاصيل قابلة للطي وألوان مخصصة. مثالية لمعالم المشروع أو تاريخ الشركة أو السير الذاتية. يتم تشغيله عندما يذكر المستخدم "المخطط الزمني"، أو "سجل الأحداث"، أو "المراحل الرئيسية للمشروع"، أو "سجل الإصدار"، أو يطلب تصور تسلسل زمني للبيانات.
