Générez de superbes pages HTML de chronologie interactive à partir de données JSON, avec des mises en page verticales, horizontales ou recto-verso, des détails pliables et des couleurs personnalisées. Idéal pour les jalons de projets, les historiques d'entreprises ou les CV. Déclenché lorsqu'un utilisateur mentionne « chronologie », « historique des événements », « jalons du projet », « journal de version » ou demande à visualiser une séquence chronologique de données.
