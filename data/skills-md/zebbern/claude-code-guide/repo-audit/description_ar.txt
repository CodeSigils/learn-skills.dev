تحليل عميق لسجل Git: تحديد ملفات نقطة الاتصال التي يتم تغييرها بشكل متكرر، وتحليل ملكية التعليمات البرمجية من قبل المساهم، والمسح بحثًا عن الأسرار المسربة. يتم تشغيله عندما يسأل المستخدمون عن تحليل Git، أو نقاط اتصال التعليمات البرمجية، أو من يملك الرمز، أو المسح السري، أو عمليات التدقيق الأمني ​​لسجل الالتزام، أو تحسين مهام مراجعة التعليمات البرمجية.
