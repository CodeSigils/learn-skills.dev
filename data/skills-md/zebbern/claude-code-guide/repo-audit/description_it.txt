Analisi approfondita della cronologia Git: identifica i file hotspot modificati di frequente, analizza la proprietà del codice per collaboratore e cerca i segreti trapelati. Si attiva quando gli utenti chiedono informazioni sull'analisi Git, sugli hotspot del codice, su chi possiede quale codice, sulla scansione segreta, sui controlli di sicurezza della cronologia dei commit o sull'ottimizzazione delle assegnazioni di revisione del codice.
