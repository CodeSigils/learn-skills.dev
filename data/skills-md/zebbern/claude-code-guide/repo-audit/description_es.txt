Análisis profundo del historial de Git: identifique archivos de puntos de acceso que se modifican con frecuencia, analice la propiedad del código por colaborador y busque secretos filtrados. Se activa cuando los usuarios preguntan sobre análisis de Git, puntos de acceso de código, quién posee qué código, escaneo secreto, auditorías de seguridad del historial de confirmaciones u optimización de las asignaciones de revisión de código.
