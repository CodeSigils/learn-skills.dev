Scansione del codice per problemi di sicurezza: vulnerabilità delle dipendenze (audit npm/pip), perdite segrete (analisi regex ed entropia) e anti-pattern OWASP come SQL injection, XSS o command injection. Da utilizzare quando l'utente menziona scansioni di sicurezza, rilevamento di vulnerabilità, fughe di informazioni segrete, chiavi API, OWASP, audit npm, pip-audit, password hardcoded o controlli di sicurezza del codice.
