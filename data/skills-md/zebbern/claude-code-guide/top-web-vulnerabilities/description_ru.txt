Этот навык следует использовать, когда пользователь просит «выявить уязвимости веб-приложения», «объяснить общие недостатки безопасности», «понять категории уязвимостей», «узнать об атаках путем внедрения», «просмотреть слабые места контроля доступа», «проанализировать проблемы безопасности API», «оценить неправильные настройки безопасности», «понять уязвимости на стороне клиента», «изучить недостатки безопасности мобильных устройств и Интернета вещей» или «ссылаться на таксономию уязвимостей, согласованную с OWASP». Используйте этот навык, чтобы предоставить исчерпывающие определения уязвимостей, основные причины, последствия и стратегии смягчения последствий для всех основных категорий веб-безопасности.
