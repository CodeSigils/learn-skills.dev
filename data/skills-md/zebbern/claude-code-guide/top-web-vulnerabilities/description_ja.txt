このスキルは、ユーザーが「Web アプリケーションの脆弱性を特定する」、「一般的なセキュリティ上の欠陥を説明する」、「脆弱性のカテゴリを理解する」、「インジェクション攻撃について学ぶ」、「アクセス コントロールの弱点を確認する」、「API セキュリティの問題を分析する」、「セキュリティの設定ミスを評価する」、「クライアント側の脆弱性を理解する」、「モバイルおよび IoT のセキュリティ上の欠陥を調査する」、または「OWASP に準拠した脆弱性分類を参照する」ことを求める場合に使用する必要があります。このスキルを使用して、すべての主要な Web セキュリティ カテゴリにわたる包括的な脆弱性の定義、根本原因、影響、緩和戦略を提供します。
