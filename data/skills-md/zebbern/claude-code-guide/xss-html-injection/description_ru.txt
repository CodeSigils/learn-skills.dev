Этот навык следует использовать, когда пользователь просит «проверить уязвимости XSS», «выполнить атаки с использованием межсайтовых сценариев», «определить недостатки внедрения HTML», «использовать уязвимости внедрения внедрения на стороне клиента», «украсть файлы cookie через XSS» или «обойти политики безопасности контента». Он предоставляет комплексные методы обнаружения, использования и понимания векторов атак XSS и HTML-инъекций в веб-приложениях.
