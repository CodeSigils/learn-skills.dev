Diese Fähigkeit sollte verwendet werden, wenn der Benutzer „auf XSS-Schwachstellen testen“, „Cross-Site-Scripting-Angriffe durchführen“, „HTML-Injektionsfehler identifizieren“, „clientseitige Injektionsschwachstellen ausnutzen“, „Cookies über XSS stehlen“ oder „Inhaltssicherheitsrichtlinien umgehen“ möchte. Es bietet umfassende Techniken zum Erkennen, Ausnutzen und Verstehen von XSS- und HTML-Injection-Angriffsvektoren in Webanwendungen.
