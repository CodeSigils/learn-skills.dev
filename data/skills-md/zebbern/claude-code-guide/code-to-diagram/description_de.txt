Analysieren Sie Codebasen und generieren Sie automatisch Architekturdiagramme, Flussdiagramme und Organigramme. Verwendet AST-Parsing, um Importabhängigkeiten für Python, JS/TS, Go und Java abzubilden und Mermaid- oder SVG-Dateien auszugeben. Wird ausgelöst, wenn Benutzer die Codearchitektur visualisieren, Abhängigkeiten verstehen, ein Flussdiagramm zeichnen oder ein Moduldiagramm aus dem Quellcode erstellen möchten.
