Analizza le basi di codice e genera automaticamente diagrammi di architettura, diagrammi di flusso e organigrammi. Utilizza l'analisi AST per mappare le dipendenze di importazione per Python, JS/TS, Go e Java, generando file Sirena o SVG. Si attiva quando gli utenti chiedono di visualizzare l'architettura del codice, comprendere le dipendenze, disegnare un diagramma di flusso o creare un diagramma del modulo dal codice sorgente.
