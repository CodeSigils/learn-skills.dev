Analice bases de código y genere automáticamente diagramas de arquitectura, diagramas de flujo y organigramas. Utiliza el análisis AST para mapear dependencias de importación para Python, JS/TS, Go y Java, generando archivos Mermaid o SVG. Se activa cuando los usuarios solicitan visualizar la arquitectura del código, comprender las dependencias, dibujar un diagrama de flujo o crear un diagrama de módulo a partir del código fuente.
