Анализируйте базы кода и автоматически создавайте архитектурные диаграммы, блок-схемы и организационные диаграммы. Использует анализ AST для сопоставления зависимостей импорта для Python, JS/TS, Go и Java, выводя файлы Mermaid или SVG. Срабатывает, когда пользователи просят визуализировать архитектуру кода, понять зависимости, нарисовать блок-схему или создать диаграмму модуля из исходного кода.
