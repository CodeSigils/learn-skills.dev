قم بتحليل قواعد التعليمات البرمجية وإنشاء مخططات معمارية ومخططات انسيابية ومخططات هيكلية تلقائيًا. يستخدم تحليل AST لتعيين تبعيات الاستيراد لـ Python، وJS/TS، وGo، وJava، وإخراج ملفات Mermaid أو SVG. يتم تشغيله عندما يطلب المستخدمون تصور بنية التعليمات البرمجية، أو فهم التبعيات، أو رسم مخطط انسيابي، أو إنشاء رسم تخطيطي لوحدة نمطية من التعليمات البرمجية المصدر.
