قم بإنشاء رسوم بيانية بتنسيق HTML/SVG قائمة بذاتها من بيانات JSON، بما في ذلك البطاقات الإحصائية والمخططات الشريطية ومخططات التدفق ولوحات المعلومات المختلطة. يقدم 8 لوحات ألوان وأيقونات مدمجة بدون أي تبعيات خارجية. يتم تشغيله عندما يطلب المستخدمون تصورًا للبيانات أو الرسوم البيانية أو المخططات أو لوحات المعلومات.
