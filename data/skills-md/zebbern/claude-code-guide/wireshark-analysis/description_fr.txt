Cette compétence doit être utilisée lorsque l'utilisateur demande « analyser le trafic réseau avec Wireshark », « capturer des paquets pour le dépannage », « filtrer les fichiers PCAP », « suivre les flux TCP/UDP », « détecter les anomalies du réseau », « enquêter sur le trafic suspect » ou « effectuer une analyse de protocole ».
