Этот навык следует использовать, когда пользователь просит «проанализировать сетевой трафик с помощью Wireshark», «перехватить пакеты для устранения неполадок», «фильтровать файлы PCAP», «отслеживать потоки TCP/UDP», «обнаружить сетевые аномалии», «расследовать подозрительный трафик» или «выполнить анализ протокола». Он предоставляет комплексные методы захвата, фильтрации и анализа сетевых пакетов с использованием Wireshark.
