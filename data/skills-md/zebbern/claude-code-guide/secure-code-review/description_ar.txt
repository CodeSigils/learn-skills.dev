يراجع بشكل منهجي التعليمات البرمجية لحقن SQL، وXSS، وSSRF، والتحكم في الوصول المعطل، وفشل التشفير، وغيرها من نقاط الضعف العشرة الشائعة الأخرى في OWASP، مما يوفر أمثلة على التعليمات البرمجية الضعيفة وإرشادات علاجية جاهزة للاستخدام. قم بتشغيل هذه المهارة عندما يطلب المستخدمون مراجعة أمنية، أو فحص الثغرات الأمنية، أو المساعدة في اختبار الاختراق، أو ذكر كلمات رئيسية مثل OWASP، أو حقن SQL، أو XSS، أو تدقيق التعليمات البرمجية، أو قائمة التحقق من الأمان.
