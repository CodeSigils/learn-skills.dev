Систематически проверяет код на наличие SQL-инъекций, XSS, SSRF, нарушенного контроля доступа, криптографических сбоев и других распространенных уязвимостей из списка OWASP Top 10, предоставляя примеры уязвимого кода и готовые к использованию рекомендации по устранению. Активируйте этот навык, когда пользователи просят о проверке безопасности, сканировании уязвимостей или помощи в тестировании на проникновение или упоминают такие ключевые слова, как OWASP, SQL-инъекция, XSS, аудит кода или контрольный список безопасности.
