Esamina sistematicamente il codice per SQL injection, XSS, SSRF, controllo degli accessi interrotti, errori crittografici e altre 10 principali vulnerabilità OWASP comuni, fornendo esempi di codice vulnerabile e indicazioni di risoluzione pronte all'uso. Attiva questa abilità quando gli utenti richiedono una revisione della sicurezza, una scansione delle vulnerabilità o assistenza per i test di penetrazione oppure menzionano parole chiave come OWASP, SQL injection, XSS, controllo del codice o elenco di controllo della sicurezza.
