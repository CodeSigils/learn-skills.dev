Verschieben Sie abgeschlossene lokale GitHub-Issue-Arbeiten in einen zusammenführungsbereiten Pull-Request. Verwenden Sie diese Option, wenn die Entwicklung abgeschlossen ist, der Benutzer sagt, PR beenden, diesen Zweig veröffentlichen, einen fertigen PR öffnen oder ein Agent objektive Beweise dafür hat, dass der Zweig zur Überprüfung bereit ist.
