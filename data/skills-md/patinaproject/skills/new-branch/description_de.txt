Bereiten Sie lokale GitHub-Issue-Branches aus dem Repository-Standard-Branch vor, indem Sie Issue-Branch-Namen im GitHub-Stil verwenden. Verwenden Sie diese Option, wenn Sie mit problembezogener Arbeit beginnen, wenn der Benutzer einen neuen Zweig für ein Problem angibt oder wenn ein Agent vor der Implementierung zum richtigen Problemzweig wechseln muss.
