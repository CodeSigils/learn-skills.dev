Da utilizzare quando si crea l'impalcatura di un nuovo repository (pubblico o privato) alla linea di base del progetto Patina, quando si riallinea un repository esistente con quella linea di base o durante il controllo o l'aggiunta di convenzioni di commit, modelli PR, husky + commitlint, strumenti PNPM, release-please, documenti dell'agente (AGENTS.md, CLAUDE.md) o manifest del plug-in dell'agente AI per Claude Code e Codex. Si attiva su frasi come "impalcatura questo repository", "impalcatura di un plug-in Patina", "riallinea con la linea di base", "controlla le nostre convenzioni del repository", "imposta commitlint e husky" o "aggiungi superfici plug-in Claude/Codex".
