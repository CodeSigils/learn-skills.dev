Установите одну или несколько навыков агента в текущий репозиторий с помощью интерфейса командной строки навыков. Используйте при добавлении, обновлении или восстановлении локальных навыков проекта, когда пользователь называет источник навыков или когда в репозитории необходимо установить общие навыки без изменения глобального состояния агента.
