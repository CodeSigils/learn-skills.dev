Этот навык следует использовать при настройке развертывания SFTP для статических веб-сайтов на рабочих серверах, включая преобразование проектов из Docker/Express на статический хостинг, развертывание сборок Vue/React/Angular, настройку презентаций Slidev или настройку сайтов Hugo/Jekyll/Gatsby. Используйте это, когда пользователь запрашивает «настроить развертывание SFTP», «развернуть статический сайт на сервере», «настроить Nginx для статических файлов», «преобразовать из Docker в статический хостинг», «развернуть сборку Vue в рабочей среде», «настроить хостинг поддоменов» или «настроить SFTP в VS Code». Предоставляет шаблоны конфигурации SFTP и готовые к использованию конфигурации Nginx с заголовками безопасности и кэшированием.
