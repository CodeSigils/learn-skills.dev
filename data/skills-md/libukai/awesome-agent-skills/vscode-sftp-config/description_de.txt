Diese Fähigkeit sollte beim Einrichten der SFTP-Bereitstellung für statische Websites auf Produktionsservern verwendet werden, einschließlich der Konvertierung von Projekten von Docker/Express in statisches Hosting, der Bereitstellung von Vue/React/Angular-Builds, der Einrichtung von Slidev-Präsentationen oder der Konfiguration von Hugo/Jekyll/Gatsby-Sites. Verwenden Sie dies, wenn der Benutzer auffordert, „SFTP-Bereitstellung einzurichten“, „statische Site auf Server bereitzustellen“, „Nginx für statische Dateien zu konfigurieren“, „von Docker zu statischem Hosting zu konvertieren“, „Vue-Build für die Produktion bereitzustellen“, „Subdomain-Hosting einzurichten“ oder „SFTP in VS-Code zu konfigurieren“. Bietet SFTP-Konfigurationsvorlagen und produktionsbereite Nginx-Konfigurationen mit Sicherheitsheadern und Caching.
