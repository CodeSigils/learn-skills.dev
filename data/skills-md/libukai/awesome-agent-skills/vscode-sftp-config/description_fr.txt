Cette compétence doit être utilisée lors de la configuration du déploiement SFTP de sites Web statiques sur des serveurs de production, y compris la conversion de projets de Docker/Express en hébergement statique, le déploiement de builds Vue/React/Angular, la configuration de présentations Slidev ou la configuration de sites Hugo/Jekyll/Gatsby. Utilisez-le lorsque l'utilisateur demande de « configurer le déploiement SFTP », « déployer un site statique sur le serveur », « configurer Nginx pour les fichiers statiques », « convertir de Docker en hébergement statique », « déployer la version Vue en production », « configurer l'hébergement de sous-domaines » ou « configurer SFTP dans VS Code ». Fournit des modèles de configuration SFTP et des configurations Nginx prêtes pour la production avec des en-têtes de sécurité et une mise en cache.
