このスキルは、Docker/Express から静的ホスティングへのプロジェクトの変換、Vue/React/Angular ビルドのデプロイ、Slidev プレゼンテーションのセットアップ、または Hugo/Jekyll/Gatsby サイトの構成など、静的 Web サイトの運用サーバーへの SFTP デプロイメントを設定するときに使用する必要があります。これは、ユーザーが「SFTP デプロイメントのセットアップ」、「静的サイトをサーバーにデプロイ」、「静的ファイル用に Nginx を構成」、「Docker から静的ホスティングに変換」、「Vue ビルドを運用環境にデプロイ」、「サブドメイン ホスティングのセットアップ」、または「VS Code での SFTP の構成」を要求する場合に使用します。 SFTP 構成テンプレートと、セキュリティ ヘッダーとキャッシュを備えた本番環境に対応した Nginx 構成を提供します。
