이 기술은 Docker/Express에서 정적 호스팅으로 프로젝트 변환, Vue/React/Angular 빌드 배포, Slidev 프레젠테이션 설정 또는 Hugo/Jekyll/Gatsby 사이트 구성을 포함하여 정적 웹 사이트를 프로덕션 서버에 대한 SFTP 배포를 설정할 때 사용해야 합니다. 사용자가 "SFTP 배포 설정", "서버에 정적 사이트 배포", "정적 파일용 Nginx 구성", "Docker에서 정적 호스팅으로 변환", "Vue 빌드를 프로덕션에 배포", "하위 도메인 호스팅 설정" 또는 "VS Code에서 SFTP 구성"을 요청할 때 이를 사용합니다. 보안 헤더 및 캐싱이 포함된 SFTP 구성 템플릿과 프로덕션에 즉시 사용 가능한 Nginx 구성을 제공합니다.
