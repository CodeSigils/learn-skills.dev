Questa competenza dovrebbe essere utilizzata durante la configurazione della distribuzione SFTP per siti Web statici su server di produzione, inclusa la conversione di progetti da Docker/Express a hosting statico, la distribuzione di build Vue/React/Angular, l'impostazione di presentazioni Slidev o la configurazione di siti Hugo/Jekyll/Gatsby. Utilizzalo quando l'utente chiede di "configurare la distribuzione SFTP", "distribuire il sito statico sul server", "configurare Nginx per file statici", "convertire da Docker a hosting statico", "distribuire la build Vue in produzione", "configurare l'hosting del sottodominio" o "configurare SFTP in VS Code". Fornisce modelli di configurazione SFTP e configurazioni Nginx pronte per la produzione con intestazioni di sicurezza e memorizzazione nella cache.
