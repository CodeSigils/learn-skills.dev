Cette compétence doit être utilisée lors de la configuration de l’extension VS Code Port Monitor pour la surveillance du serveur de développement. À utiliser lorsque l'utilisateur demande de « configurer la surveillance des ports pour Vite », « surveiller les ports de mon serveur de développement », « configurer le moniteur de port pour Next.js », « suivre les ports en cours d'exécution », « configurer la surveillance multi-ports », « surveiller les ports frontend et backend » ou « vérifier l'état des ports dans VS Code ». Fournit des modèles de configuration prêts à l'emploi pour les architectures Vite (5173), Next.js (3000) et de microservices avec des conseils de dépannage.
