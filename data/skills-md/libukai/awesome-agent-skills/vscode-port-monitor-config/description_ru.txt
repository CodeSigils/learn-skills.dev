Этот навык следует использовать при настройке расширения VS Code Port Monitor для мониторинга сервера разработки. Используйте, когда пользователь запрашивает «настроить мониторинг портов для Vite», «мониторить порты моего сервера разработки», «настроить монитор портов для Next.js», «отследить, какие порты работают», «настроить многопортовый мониторинг», «мониторить внешние и внутренние порты» или «проверить состояние порта в VS Code». Предоставляет готовые к использованию шаблоны конфигурации для архитектур Vite (5173), Next.js (3000) и микросервисов с инструкциями по устранению неполадок.
