このスキルは、開発サーバー監視用に VS Code ポート モニター拡張機能を構成するときに使用する必要があります。ユーザーが「Vite のポート監視を設定する」、「開発サーバーのポートを監視する」、「Next.js のポート監視を設定する」、「実行中のポートを追跡する」、「マルチポート監視を設定する」、「フロントエンドとバックエンドのポートを監視する」、または「VS Code でポートの状態を確認する」を要求する場合に使用します。 Vite (5173)、Next.js (3000)、およびマイクロサービス アーキテクチャ用のすぐに使用できる構成テンプレートと、トラブルシューティング ガイダンスを提供します。
