قم بتكوين VSCode باستخدام httpYac لاختبار واجهة برمجة التطبيقات (API) والأتمتة. يجب استخدام هذه المهارة على وجه التحديد عند تحويل وثائق واجهة برمجة التطبيقات (API) إلى ملفات .http قابلة للتنفيذ (أكثر من 10 نقاط نهاية)، أو إعداد تدفقات المصادقة باستخدام البرامج النصية للطلب المسبق، أو تنفيذ تسلسل الطلب مع بيانات الاستجابة، أو تنظيم مجموعات متعددة الملفات مع إدارة البيئة، أو إنشاء مسارات عمل لاختبار واجهة برمجة التطبيقات (API) المستندة إلى Git مع تكامل CI/CD.
