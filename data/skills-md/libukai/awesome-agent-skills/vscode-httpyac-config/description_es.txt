Configure VSCode con httpYac para pruebas y automatización de API. Esta habilidad debe usarse específicamente al convertir documentación de API en archivos .http ejecutables (más de 10 puntos finales), configurar flujos de autenticación con scripts de solicitud previa, implementar encadenamiento de solicitudes con datos de respuesta, organizar colecciones de múltiples archivos con administración del entorno o establecer flujos de trabajo de prueba de API basados ​​en Git con integración de CI/CD.
