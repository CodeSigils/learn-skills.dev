Настройте VSCode с помощью httpYac для тестирования и автоматизации API. Этот навык следует особенно использовать при преобразовании документации API в исполняемые файлы .http (более 10 конечных точек), настройке потоков аутентификации с помощью сценариев предварительного запроса, реализации цепочки запросов с данными ответов, организации коллекций из нескольких файлов с управлением средой или организации рабочих процессов тестирования API на основе Git с интеграцией CI/CD.
