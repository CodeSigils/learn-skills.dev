Orientación experta para Satori, la biblioteca que convierte JSX/HTML y CSS en SVG (el motor detrás de las imágenes dinámicas y tarjetas sociales de Open Graph). Úselo siempre que escriba o depure el marcado Satori, p. crear JSX para imágenes OG, elegir CSS que Satori realmente admita, corregir el diseño que se muestra mal, incrustar fuentes, representar emoji o imágenes, o resolver errores de Satori como "Unidad de longitud esperada" o problemas de propiedades no admitidas. Utilice esto cada vez que alguien renderice HTML/CSS a SVG o PNG con Satori, incluso si no lo nombra.
