Guida esperta per Satori, la libreria che converte JSX/HTML e CSS in SVG (il motore dietro le immagini dinamiche Open Graph e le social card). Utilizzare ogni volta che si scrive o si esegue il debug del markup Satori, ad es. creare JSX per immagini OG, scegliere CSS che Satori effettivamente supporta, correggere il layout che viene visualizzato in modo errato, incorporare caratteri, eseguire il rendering di emoji o immagini o risolvere errori Satori come "Unità di lunghezza prevista" o problemi di proprietà non supportati. Raggiungilo ogni volta che qualcuno esegue il rendering di HTML/CSS in SVG o PNG con Satori, anche se non lo nomina.
