JSX/HTML と CSS を SVG (動的な Open Graph イメージとソーシャル カードの背後にあるエンジン) に変換するライブラリであるSatori の専門家によるガイダンス。 Satori マークアップを作成またはデバッグするときは常に使用します。 OG イメージ用の JSX の作成、Satori が実際にサポートする CSS の選択、間違って表示されるレイアウトの修正、フォントの埋め込み、絵文字や画像のレンダリング、または「予想される長さの単位」やサポートされていないプロパティの問題などのSatori エラーの解決。誰かが名前を付けていなくても、Satori を使用して HTML/CSS を SVG または PNG にレンダリングするときはいつでも、これに手を伸ばしてください。
