أنشئ صورًا تسويقية عالية الجودة، وتصميمات إعلانية، ومرئيات الإطلاق، وبطاقات التواصل الاجتماعي، ورؤوس المدونات، ونماذج المنتجات، والصور المصغرة، وأصول الحملة. يُستخدم عندما يطلب المستخدم إنشاء صورة أو تصميمها أو تكرارها أو المطالبة بها للتسويق أو النمو أو وسائل التواصل الاجتماعي أو الإعلانات المدفوعة أو الصفحات المقصودة أو النشرات الإخبارية أو إطلاق المنتجات.
