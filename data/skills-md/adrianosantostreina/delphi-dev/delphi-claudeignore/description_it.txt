Crea e mantieni automaticamente il file .claudeignora alla portata dei progetti Delphi, ignorando i file binari, compilati e configurati dell'IDE che non servono a Claude, risparmiando token e migliorando le prestazioni. Usa questa abilità SEMPRE per rilevare file .dpr, .dproj o .pas in un progetto che non possiedi .claudeignore. Tambem use quando o usuario mencionar: ".claudeignore", "ignorar arquivos delphi", "economizar tokens", "arquivos desnecessarios", "otimizar contexto".
