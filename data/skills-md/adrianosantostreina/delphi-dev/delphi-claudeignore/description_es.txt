Cria y mantiene automáticamente el archivo. Claudeignore na raiz de projetos Delphi, ignorando archivos binarios, compilados y de configuración de IDE que no necesitan ser lidos para Claude, economizando tokens y mejorando un rendimiento. Use esta habilidad SEMPER para detectar archivos .dpr, .dproj o .pas em um projeto que ainda nao possui .claudeignore. Tambem use quando o usuario mencione: ".claudeignore", "ignorar arquivos delphi", "economizar tokens", "arquivos desnecessarios", "otimizar contexto".
