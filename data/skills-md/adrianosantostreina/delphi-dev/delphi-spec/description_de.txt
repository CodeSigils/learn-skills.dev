Spezialisiert auf die Erstellung automatischer Software-Spezifikationsdokumente (SPEC) im Zusammenhang mit Delphi-Projektcodes. Verwenden Sie diese Fertigkeit, wenn Sie Folgendes verwenden: SPEC, Softwarespezifikation, Spezifikationsdokument, Anforderungsdokument, „Senken Sie eine SPEC“, „geben Sie eine SPEC ab“, „Dokumentation des Systems“, „Spezifikation des Projekts“, „Spezifikation des Moduls“, „Abfrage einer SPEC nach Code“, „Analyse der Spezifikationen“, „Analysieren Sie den Code und erstellen Sie eine SPEC". Sie verwenden auch die formale Erkennung formaler Dokumente aus der bestehenden Code-Schriftart – nun für eine einzige Einheit oder isolierte Klasse.
