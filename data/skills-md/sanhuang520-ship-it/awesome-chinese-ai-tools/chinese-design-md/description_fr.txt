Système de conception DESIGN.md de style chinois. Utilisez-le lorsque l'utilisateur souhaite une « page Web de style chinois », une « page de style national », un « système de conception chinois », « définir un style chinois pour le projet », « DESIGN.md », « laisser l'IA générer l'interface selon les spécifications de conception » ou « normes de typographie des pages Web chinoises ». Fournissez huit ensembles de fichiers DESIGN.md qui peuvent être placés directement à la racine du projet ; Une fois que l’IA les aura lus, elle générera l’interface selon ces spécifications. Inclut les règles de typographie chinoise qui sont généralement absentes des systèmes de conception occidentaux.
