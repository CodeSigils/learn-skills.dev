Chinese‑style DESIGN.md design system. Use it when the user wants “Chinese‑style website,” “national‑style page,” “Chinese design system,” “give the project a Chinese style,” “DESIGN.md,” “let AI generate the interface according to design specifications,” or “Chinese web‑page typography standards.” It provides eight sets of DESIGN.md files that can be dropped directly into the project root; the AI reads them and generates the interface according to these specifications. It includes Chinese typography rules that are generally absent from Western design systems.
