Chinese‑style DESIGN.md design system. Use it when the user wants “Chinese‑style web pages,” “national‑style pages,” “Chinese design system,” “give the project a Chinese style,” “DESIGN.md,” “let AI generate the interface according to design specifications,” or “Chinese web page typography guidelines.” It provides eight sets of DESIGN.md files that can be placed directly in the project root; AI will read them and generate the interface according to these specifications. It includes Chinese typography rules that are generally absent from Western design systems.
