Revise el archivo README o una página de documentación desde varios puntos de vista de lectores reales a la vez. Distribuye un revisor paralelo por audiencia (recién llegado a Claude Code, usuario avanzado, autor de complementos/habilidades, ingeniero senior escéptico, tomador de decisiones que no está en ejecución), cada uno con una puntuación de x/5 y nombra correcciones concretas a nivel de línea. Úselo cuando se le solicite revisar, criticar, calificar o "llegar a N/5" el archivo README o cualquier documento de entrada, o para verificar cómo se lee un documento para usuarios reales. No para revisión de código (use /code-review para eso).
