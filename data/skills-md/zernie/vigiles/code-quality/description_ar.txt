تحسين جودة وأمان نوع TypeScript/JavaScript الذي تتم كتابته أو إعادة هيكلته - عدم التحقق من صحة التحليل، وجعل الحالات غير قانونية - غير قابلة للتمثيل، والمطابقة الشاملة، وفصل الوظيفة الخالصة/IO، ونظافة واجهة برمجة التطبيقات العامة. يُستخدم عندما يُطلب منك إعادة تصميم أو تنظيف أو تحسين أو تقوية أو مراجعة تصميم/جودة التعليمات البرمجية أو واجهة برمجة التطبيقات. ليس لصيد الأخطاء (هذا هو/مراجعة التعليمات البرمجية) وليس لقواعد المواصفات/الوبر الخاصة بالوقفة الاحتجاجية.
