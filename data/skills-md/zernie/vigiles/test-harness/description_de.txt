Installieren Sie Vigiles und testen Sie ein Claude-Code-Geschirr – Hooks, Fähigkeiten, Einstellungen, CLAUDE.md –, indem Sie die richtige Stufe (Einheit / deterministisch / Bewertung) auswählen und einen Test schreiben, der besteht. Verwenden Sie diese Option, wenn der Benutzer überprüfen möchte, ob ein Haken ausgelöst oder blockiert wird, ob eine Fertigkeit ausgelöst wird, ob eingefügter Kontext landet oder ob eine Kabelbaumänderung die Aktionen des Agenten bewegt.
