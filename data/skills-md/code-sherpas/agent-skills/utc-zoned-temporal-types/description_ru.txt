Требовать UTC для встроенных временных типов или временных типов стандартной библиотеки, поддерживающих часовой пояс. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать временные поля, параметры, типы возвращаемых данных, сопоставления постоянства, сериализаторы, анализаторы или контракты API, которые могут содержать информацию о часовом поясе. Если стек поддерживает временные типы с учетом часового пояса, отдайте предпочтение этим встроенным типам и используйте часовой пояс UTC.
