يتطلب التوقيت العالمي المنسق (UTC) للأنواع الزمنية المضمنة أو المكتبة القياسية المتوافقة مع المنطقة الزمنية. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير الحقول المؤقتة أو المعلمات أو أنواع الإرجاع أو تعيينات الثبات أو المسلسلات أو المحللين أو عقود واجهة برمجة التطبيقات (API) التي يمكنها حمل معلومات المنطقة الزمنية. عندما يدعم المكدس الأنواع الزمنية المتوافقة مع المنطقة الزمنية، قم بتفضيل تلك الأنواع المضمنة واستخدم المنطقة الزمنية UTC.
