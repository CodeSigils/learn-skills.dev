Erfordern Sie UTC für Zeitzonen-fähige integrierte oder Standardbibliotheks-Zeittypen. Wird verwendet, wenn ein Agent zeitliche Felder, Parameter, Rückgabetypen, Persistenzzuordnungen, Serialisierer, Parser oder API-Verträge erstellen, ändern, überprüfen oder interpretieren muss, die Zeitzoneninformationen übertragen können. Wenn der Stack zeitzonenbezogene Zeittypen unterstützt, bevorzugen Sie diese integrierten Typen und verwenden Sie die UTC-Zeitzone.
