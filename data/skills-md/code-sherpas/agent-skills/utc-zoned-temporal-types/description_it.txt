Richiede UTC per i tipi temporali incorporati o della libreria standard con riconoscimento del fuso orario. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare campi temporali, parametri, tipi restituiti, mappature di persistenza, serializzatori, parser o contratti API che possono trasportare informazioni sul fuso orario. Quando lo stack supporta tipi temporali che riconoscono il fuso orario, preferisci i tipi incorporati e usa il fuso orario UTC.
