Requiere UTC para tipos temporales de biblioteca estándar o integrados que tengan en cuenta la zona horaria. Utilícelo cuando un agente necesite crear, modificar, revisar o interpretar campos temporales, parámetros, tipos de devolución, asignaciones de persistencia, serializadores, analizadores o contratos API que puedan transportar información de zona horaria. Cuando la pila admite tipos temporales que reconocen la zona horaria, prefiera esos tipos integrados y utilice la zona horaria UTC.
