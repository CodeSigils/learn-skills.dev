تتطلب نقاط دخول منطق الأعمال للوصول إلى استمرارية كيان المجال حصريًا من خلال المستودعات. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير نقاط إدخال منطق الأعمال التي تقوم بإنشاء كيانات المجال أو قراءتها أو تعديلها. يجب ألا تستدعي نقاط الإدخال ORM للمشروع، أو مكتبة قاعدة البيانات، أو واجهة برمجة تطبيقات استمرارية الإطار، أو أي تقنية استمرارية أخرى بشكل مباشر. يجب أن تمر جميع عمليات الثبات على كيانات المجال عبر المستودع.
