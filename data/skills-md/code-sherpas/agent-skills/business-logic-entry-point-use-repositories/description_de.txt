Erfordern Sie Geschäftslogik-Einstiegspunkte, um ausschließlich über Repositorys auf die Persistenz von Domänenentitäten zuzugreifen. Wird verwendet, wenn ein Agent Geschäftslogik-Einstiegspunkte erstellen, ändern, überprüfen oder interpretieren muss, die Domänenentitäten erstellen, lesen oder ändern. Einstiegspunkte dürfen das ORM, die Datenbankbibliothek, die Framework-Persistenz-API oder eine andere Persistenztechnologie des Projekts nicht direkt aufrufen. Alle Persistenzvorgänge für Domänenentitäten müssen über ein Repository erfolgen.
