Exigez des points d’entrée de logique métier pour accéder à la persistance des entités de domaine exclusivement via des référentiels. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter des points d'entrée de logique métier qui créent, lisent ou modifient des entités de domaine. Les points d'entrée ne doivent pas appeler directement l'ORM du projet, la bibliothèque de base de données, l'API de persistance du framework ou toute autre technologie de persistance. Toutes les opérations de persistance sur les entités de domaine doivent passer par un référentiel.
