Richiedere punti di ingresso della logica aziendale per accedere alla persistenza delle entità del dominio esclusivamente tramite repository. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare punti di ingresso della logica aziendale che creano, leggono o modificano entità di dominio. I punti di ingresso non devono chiamare direttamente l'ORM del progetto, la libreria di database, l'API di persistenza del framework o qualsiasi altra tecnologia di persistenza. Tutte le operazioni di persistenza sulle entità del dominio devono passare attraverso un repository.
