Требовать от точек входа бизнес-логики доступа к сохранению объектов домена исключительно через репозитории. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать точки входа бизнес-логики, которые создают, читают или изменяют сущности предметной области. Точки входа не должны напрямую вызывать ORM проекта, библиотеку базы данных, API персистентности платформы или любую другую технологию персистентности. Все операции сохранения объектов домена должны проходить через репозиторий.
