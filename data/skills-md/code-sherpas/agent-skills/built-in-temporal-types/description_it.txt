Richiedi tipi temporali incorporati o della libreria standard per date, ore, datetime e valori correlati. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare campi temporali, parametri, tipi restituiti, mappature di persistenza, serializzatori, parser o contratti API. Quando la semantica del fuso orario è importante, utilizza una rappresentazione che preservi un fuso orario geografico come un ID di zona IANA e non semplicemente un offset UTC fisso.
