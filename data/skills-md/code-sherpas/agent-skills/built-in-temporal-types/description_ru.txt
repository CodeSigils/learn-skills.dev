Требуйте встроенных или стандартных библиотек темпоральных типов для дат, времени, даты и времени и связанных значений. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать временные поля, параметры, типы возвращаемых данных, сопоставления постоянства, сериализаторы, анализаторы или контракты API. Когда семантика часового пояса имеет значение, используйте представление, сохраняющее географический часовой пояс, например идентификатор зоны IANA, а не просто фиксированное смещение UTC.
