Requerir tipos temporales integrados o de biblioteca estándar para fechas, horas, fechas y valores relacionados. Úselo cuando un agente necesita crear, modificar, revisar o interpretar campos temporales, parámetros, tipos de retorno, asignaciones de persistencia, serializadores, analizadores o contratos API. Cuando la semántica de la zona horaria sea importante, utilice una representación que conserve una zona horaria geográfica, como un ID de zona de la IANA, y no simplemente un desplazamiento UTC fijo.
