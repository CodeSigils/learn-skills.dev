تتطلب أنواعًا زمنية مضمنة أو قياسية في المكتبة للتواريخ والأوقات وأوقات التاريخ والقيم ذات الصلة. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير الحقول المؤقتة أو المعلمات أو أنواع الإرجاع أو تعيينات الثبات أو التسلسل أو المحلل اللغوي أو عقود واجهة برمجة التطبيقات (API). عندما تكون دلالات المنطقة الزمنية مهمة، استخدم تمثيلًا يحافظ على المنطقة الزمنية الجغرافية مثل معرف منطقة IANA وليس مجرد إزاحة UTC ثابتة.
