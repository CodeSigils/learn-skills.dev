Erfordern integrierte oder in der Standardbibliothek verfügbare Zeittypen für Datumsangaben, Uhrzeiten, Datums- und Uhrzeitangaben und zugehörige Werte. Wird verwendet, wenn ein Agent zeitliche Felder, Parameter, Rückgabetypen, Persistenzzuordnungen, Serialisierer, Parser oder API-Verträge erstellen, ändern, überprüfen oder interpretieren muss. Wenn die Zeitzonensemantik wichtig ist, verwenden Sie eine Darstellung, die eine geografische Zeitzone beibehält, z. B. eine IANA-Zonen-ID, und nicht nur einen festen UTC-Offset.
