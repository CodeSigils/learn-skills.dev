Exiger des types temporels intégrés ou de bibliothèque standard pour les dates, les heures, les dates et les valeurs associées. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter des champs temporels, des paramètres, des types de retour, des mappages de persistance, des sérialiseurs, des analyseurs ou des contrats d'API. Lorsque la sémantique du fuseau horaire est importante, utilisez une représentation qui préserve un fuseau horaire géographique tel qu'un ID de zone IANA et pas simplement un décalage UTC fixe.
