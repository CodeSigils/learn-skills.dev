Erfordern, dass Eingabeparameter für den Geschäftslogik-Einstiegspunkt nur primitive oder einfache Typen verwenden. Wird verwendet, wenn ein Agent die von den Einstiegspunkten der Geschäftslogik akzeptierten Befehls- oder Abfragetypen erstellen, ändern, überprüfen oder interpretieren muss. Eingabefelder müssen Zeichenfolgen, Zahlen oder boolesche Werte sein. Verwenden Sie keine Domänenentitätstypen, Domänenaggregattypen, Marken- oder undurchsichtige primitive Typen, Aufzählungen, temporale Typen oder andere komplexe Domänenobjekte als Eingabefelder.
