Exiger que les paramètres d’entrée du point d’entrée de la logique métier utilisent uniquement des types primitifs ou de base. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter les types de commandes ou de requêtes acceptés par les points d'entrée de la logique métier. Les champs de saisie doivent être des chaînes, des nombres ou des booléens. N'utilisez pas de types d'entités de domaine, de types d'agrégats de domaine, de types primitifs marqués ou opaques, d'énumérations, de types temporels ou d'autres objets de domaine complexes comme champs de saisie.
