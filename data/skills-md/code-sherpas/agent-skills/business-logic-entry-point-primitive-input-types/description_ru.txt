Требовать, чтобы входные параметры точки входа бизнес-логики использовали только примитивные или базовые типы. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать типы команд или запросов, принимаемые точками входа бизнес-логики. Поля ввода должны быть строками, числами или логическими значениями. Не используйте типы сущностей домена, агрегатные типы домена, фирменные или непрозрачные примитивные типы, перечисления, временные типы или другие сложные объекты домена в качестве полей ввода.
