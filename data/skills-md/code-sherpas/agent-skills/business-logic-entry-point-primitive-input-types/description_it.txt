Richiedere che i parametri di input del punto di ingresso della logica aziendale utilizzino solo tipi primitivi o di base. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare i comandi o i tipi di query accettati dai punti di ingresso della logica aziendale. I campi di input devono essere stringhe, numeri o valori booleani. Non utilizzare tipi di entità di dominio, tipi aggregati di dominio, tipi primitivi con marchio o opachi, enumerazioni, tipi temporali o altri oggetti di dominio complessi come campi di input.
