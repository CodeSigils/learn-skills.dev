تتطلب معلمات إدخال نقطة إدخال منطق الأعمال استخدام الأنواع البدائية أو الأساسية فقط. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير الأوامر أو أنواع الاستعلام المقبولة بواسطة نقاط إدخال منطق الأعمال. يجب أن تكون حقول الإدخال عبارة عن سلاسل أو أرقام أو قيم منطقية. لا تستخدم أنواع كيانات المجال، أو الأنواع المجمعة للمجال، أو الأنواع الأولية ذات العلامات التجارية أو غير الشفافة، أو التعدادات، أو الأنواع المؤقتة، أو كائنات المجال المعقدة الأخرى كحقول إدخال.
