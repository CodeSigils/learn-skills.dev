Exija que los parámetros de entrada del punto de entrada de lógica empresarial utilicen únicamente tipos primitivos o básicos. Úselo cuando un agente necesita crear, modificar, revisar o interpretar los tipos de comandos o consultas aceptados por los puntos de entrada de lógica empresarial. Los campos de entrada deben ser cadenas, números o booleanos. No utilice tipos de entidad de dominio, tipos agregados de dominio, tipos primitivos opacos o de marca, enumeraciones, tipos temporales u otros objetos de dominio complejos como campos de entrada.
