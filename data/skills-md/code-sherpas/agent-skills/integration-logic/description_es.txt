Identifique, interprete, revise o escriba lógica de integración en código. Úselo cuando un agente necesita decidir si existe código para que dos aplicaciones independientes puedan comunicarse, o cuando debe implementar, preservar o refactorizar el manejo de protocolos, el intercambio de mensajes, el mapeo de contratos o los flujos de trabajo de comunicación entre sistemas en ejecución separados.
