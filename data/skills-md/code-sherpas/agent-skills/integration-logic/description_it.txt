Identificare, interpretare, rivedere o scrivere la logica di integrazione nel codice. Da utilizzare quando un agente deve decidere se esiste un codice in modo che due applicazioni indipendenti possano comunicare oppure quando deve implementare, preservare o eseguire il refactoring della gestione dei protocolli, dello scambio di messaggi, della mappatura dei contratti o dei flussi di lavoro di comunicazione tra sistemi in esecuzione separati.
