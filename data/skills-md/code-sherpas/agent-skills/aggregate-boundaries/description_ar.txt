تحديد وفرض الحدود المجمعة عندما ترتبط كيانات المجال بكيانات المجال الأخرى. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير كيان مجال يشير إلى كيان مجال آخر. يجب على الوكيل تحديد ما إذا كانت الكيانات ذات الصلة تنتمي إلى نفس التجميع أو إلى تجميعات مختلفة، وتطبيق النمط المرجعي الصحيح - مرجع مباشر داخل نفس التجميع، مرجع الهوية عبر التجميعات - وتوثيق قرار الحدود في ملف تعليمات وكيل المشروع حتى تعيد المهام المستقبلية استخدام نفس القرار دون المطالبة مرة أخرى.
