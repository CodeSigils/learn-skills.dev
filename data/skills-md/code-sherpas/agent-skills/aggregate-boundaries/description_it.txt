Determinare e applicare i confini aggregati quando le entità di dominio si riferiscono ad altre entità di dominio. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare un'entità di dominio che fa riferimento a un'altra entità di dominio. L'agente deve determinare se le entità correlate appartengono allo stesso aggregato o ad aggregati diversi, applicare lo stile di riferimento corretto (riferimento diretto all'interno dello stesso aggregato, riferimento all'identità tra aggregati) e documentare la decisione sui confini nel file di istruzioni dell'agente del progetto in modo che le attività future riutilizzino la stessa decisione senza chiedere nuovamente.
