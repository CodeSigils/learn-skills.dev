Determinar y hacer cumplir límites agregados cuando las entidades de dominio se relacionan con otras entidades de dominio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar una entidad de dominio que hace referencia a otra entidad de dominio. El agente debe determinar si las entidades relacionadas pertenecen al mismo agregado o a diferentes agregados, aplicar el estilo de referencia correcto (referencia directa dentro del mismo agregado, referencia de identidad entre agregados) y documentar la decisión de límites en el archivo de instrucciones del agente del proyecto para que las tareas futuras reutilicen la misma decisión sin volver a preguntar.
