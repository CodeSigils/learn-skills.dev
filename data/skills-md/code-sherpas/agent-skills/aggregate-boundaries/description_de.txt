Bestimmen und erzwingen Sie aggregierte Grenzen, wenn sich Domänenentitäten auf andere Domänenentitäten beziehen. Verwenden Sie diese Option, wenn ein Agent eine Domänenentität erstellen, ändern, überprüfen oder interpretieren muss, die auf eine andere Domänenentität verweist. Der Agent muss feststellen, ob die zugehörigen Entitäten zum selben Aggregat oder zu unterschiedlichen Aggregaten gehören, den richtigen Referenzstil anwenden – direkte Referenz innerhalb desselben Aggregats, Identitätsreferenz über Aggregate hinweg – und die Grenzentscheidung in der Agent-Anweisungsdatei des Projekts dokumentieren, damit zukünftige Aufgaben dieselbe Entscheidung wiederverwenden, ohne erneut nachzufragen.
