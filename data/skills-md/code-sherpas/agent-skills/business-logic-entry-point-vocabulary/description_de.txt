Ordnen Sie gängige Branchennamen dem Konzept des Einstiegspunkts für die Geschäftslogik zu. Wird verwendet, wenn ein Agent auf Begriffe wie Anwendungsfall, Anwendungsdienst, Serviceschicht, Befehlshandler, Abfragehandler, Interaktor oder ähnliche Namen stößt oder der Benutzer sie erwähnt, die sich auf Einstiegspunkte in die Geschäftslogik beziehen. Erkennen Sie diese Begriffe als Synonyme für Geschäftslogik-Einstiegspunkt und wenden Sie alle Fähigkeiten im Bereich Geschäftslogik-Einstiegspunkt entsprechend an.
