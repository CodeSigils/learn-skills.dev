تحديد أو تفسير أو مراجعة أو كتابة منطق الأعمال في التعليمات البرمجية. يُستخدم عندما يحتاج الوكيل إلى تحديد ما إذا كانت التعليمات البرمجية تعبر عن قواعد العمل أو خوارزميات الأعمال أو سير عمل الأعمال، أو عندما يتعين عليه تنفيذ التعليمات البرمجية أو الحفاظ عليها أو إعادة هيكلتها التي تنشئ البيانات أو تخزنها أو تحولها وفقًا لسياسات العمل الحقيقية.
