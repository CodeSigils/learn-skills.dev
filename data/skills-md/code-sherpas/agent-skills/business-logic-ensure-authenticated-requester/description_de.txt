Erzwingen Sie eine Geschäftseinschränkung für die Authentifizierung an Geschäftslogik-Einstiegspunkten mithilfe eines Formalismus, der die Authentifizierung des Anforderers gewährleistet und in die Syntax und Konventionen der Projektsprache übersetzt wird. Wird verwendet, wenn ein Agent Authentifizierungsprüfungen an Einstiegspunkten der Geschäftslogik erstellen, ändern, überprüfen oder interpretieren muss. Die Einschränkung muss überprüfen, ob die Anforderung, die die Ausführung auslöst, von einem authentifizierten Anforderer stammt, bevor Geschäftslogik ausgeführt wird. Bei Erfolg muss es die Anforderer-ID zurückgeben, um die nachgelagerte Geschäftslogik zu erleichtern. Bei einem Fehler muss ein Fehler zurückgegeben werden, wenn der Anforderer nicht authentifiziert ist.
