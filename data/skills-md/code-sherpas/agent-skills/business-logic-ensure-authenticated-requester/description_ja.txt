プロジェクト言語の構文と規則に変換された「要求者が認証されていることを確認する」形式を使用して、ビジネス ロジックのエントリ ポイントで認証ビジネス制約を強制します。エージェントがビジネス ロジックのエントリ ポイントで認証チェックを作成、変更、レビュー、または解釈する必要がある場合に使用します。制約では、ビジネス ロジックが実行される前に、実行をトリガーするリクエストが認証されたリクエスタからのものであることを検証する必要があります。成功すると、下流のビジネス ロジックを容易にするためにリクエスタ ID を返す必要があります。失敗した場合、要求者が認証されていない場合はエラーを返す必要があります。
