التقط الاستثناءات ووعد بالفشل باستخدام "neverthrow" بدلاً من "try/catch" المكتوبة بخط اليد في كود TypeScript وJavaScript. يُستخدم عند تغليف الوظائف المتزامنة التي قد تطرح، أو وظائف إرجاع الوعد التي قد تطرح قبل العودة، أو قيم `PromiseLike` الموجودة التي قد يتم رفضها، أو واجهات برمجة التطبيقات التابعة لجهات خارجية مثل المحللين، وعملاء قاعدة البيانات، وعملاء HTTP، ومساعدي نظام الملفات، والمتسلسلات، واستدعاءات SDK. تفضل `Result.fromThrowable` للقاذفات المتزامنة، و`ResultAsync.fromThrowable` لوظائف إرجاع الوعد التي قد تطرح أو ترفض، و`ResultAsync.fromPromise` عندما يكون لديك بالفعل قيمة `PromiseLike` في متناول اليد. احتفظ بـ "try/catch" فقط عندما يتطلبها بناء اللغة أو متطلبات التنظيف أو حدود إطار العمل.
