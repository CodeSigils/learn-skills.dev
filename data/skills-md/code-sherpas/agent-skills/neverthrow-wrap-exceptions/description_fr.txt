Capturez les exceptions et promettez les échecs avec « neverthrow » au lieu de « try/catch » écrit à la main dans le code TypeScript et JavaScript. À utiliser lors de l'encapsulation de fonctions synchrones qui peuvent être lancées, de fonctions de retour de promesse qui peuvent être lancées avant de retourner, de valeurs `PromiseLike` existantes qui peuvent être rejetées, ou d'API tierces telles que des analyseurs, des clients de base de données, des clients HTTP, des assistants de système de fichiers, des sérialiseurs et des appels SDK. Préférez `Result.fromThrowable` pour les lanceurs synchrones, `ResultAsync.fromThrowable` pour les fonctions de retour de promesse qui peuvent lancer ou rejeter, et `ResultAsync.fromPromise` lorsque vous avez déjà une valeur `PromiseLike` en main. Ne conservez « try/catch » que lorsque la construction du langage, les exigences de nettoyage ou les limites du framework l'exigent vraiment.
