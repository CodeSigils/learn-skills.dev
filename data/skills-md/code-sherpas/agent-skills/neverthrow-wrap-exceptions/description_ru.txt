Перехватывайте исключения и сбои обещаний с помощью «neverthrow» вместо написанного вручную «try/catch» в коде TypeScript и JavaScript. Используйте при оболочке синхронных функций, которые могут выдавать исключение, функций, возвращающих обещание, которые могут выдавать перед возвратом, существующих значений PromiseLike, которые могут отклоняться, или сторонних API, таких как анализаторы, клиенты баз данных, HTTP-клиенты, помощники файловой системы, сериализаторы и вызовы SDK. Предпочитайте Result.fromThrowable для синхронных выбрасывателей, ResultAsync.fromThrowable для функций, возвращающих обещания, которые могут выдавать или отклонять, и ResultAsync.fromPromise, если у вас уже есть значение PromiseLike. Сохраняйте `try/catch` только тогда, когда этого действительно требуют конструкция языка, требования очистки или границы платформы.
