TypeScript 및 JavaScript 코드에서 직접 작성한 'try/catch' 대신 'neverthrow'를 사용하여 예외를 캡처하고 실패를 약속하세요. 발생할 수 있는 동기 함수, 반환하기 전에 발생할 수 있는 약속 반환 함수, 거부할 수 있는 기존 'PromiseLike' 값 또는 파서, 데이터베이스 클라이언트, HTTP 클라이언트, 파일 시스템 도우미, 직렬 변환기 및 SDK 호출과 같은 타사 API를 래핑할 때 사용합니다. 동기식 발생기에는 `Result.fromThrowable`을, 던지거나 거부할 수 있는 약속 반환 함수에는 `ResultAsync.fromThrowable`을, `PromiseLike` 값이 이미 있는 경우에는 `ResultAsync.fromPromise`를 선호하세요. 언어 구성, 정리 요구 사항 또는 프레임워크 경계에서 실제로 필요한 경우에만 'try/catch'를 유지하세요.
