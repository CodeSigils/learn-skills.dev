Capture excepciones y prometa fallas con "neverthrow" en lugar de "try/catch" escrito a mano en código TypeScript y JavaScript. Úselo al encapsular funciones sincrónicas que pueden generar, funciones de devolución de promesas que pueden generar antes de regresar, valores "PromiseLike" existentes que pueden rechazar o API de terceros, como analizadores, clientes de bases de datos, clientes HTTP, ayudantes de sistemas de archivos, serializadores y llamadas de SDK. Prefiera `Result.fromThrowable` para lanzadores sincrónicos, `ResultAsync.fromThrowable` para funciones de devolución de promesas que pueden lanzar o rechazar, y `ResultAsync.fromPromise` cuando ya tenga un valor `PromiseLike` a mano. Mantenga `try/catch` solo cuando la construcción del lenguaje, el requisito de limpieza o el límite del marco realmente lo requieran.
