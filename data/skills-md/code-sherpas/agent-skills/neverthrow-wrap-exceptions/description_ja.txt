TypeScript および JavaScript コードで手書きの `try/catch` の代わりに `neverthrow` を使用して例外をキャプチャし、失敗を約束します。スローされる可能性のある同期関数、返される前にスローされる可能性のある Promise を返す関数、拒否される可能性のある既存の `PromiseLike` 値、またはパーサー、データベース クライアント、HTTP クライアント、ファイル システム ヘルパー、シリアライザー、SDK 呼び出しなどのサードパーティ API をラップする場合に使用します。同期スロー側には `Result.fromThrowable` を、スローまたは拒否する可能性のある Promise を返す関数には `ResultAsync.fromThrowable` を、すでに `PromiseLike` 値を持っている場合には `ResultAsync.fromPromise` を優先します。言語構造、クリーンアップ要件、またはフレームワーク境界で本当に必要な場合にのみ、「try/catch」を保持してください。
