Erfassen Sie Ausnahmen und Promise-Fehler mit „neverthrow“ anstelle von handgeschriebenem „try/catch“ in TypeScript- und JavaScript-Code. Verwenden Sie diese Option, wenn Sie synchrone Funktionen umschließen, die möglicherweise auslösen, Versprechen zurückgebende Funktionen, die möglicherweise vor der Rückgabe auslösen, vorhandene „PromiseLike“-Werte, die möglicherweise abgelehnt werden, oder APIs von Drittanbietern wie Parser, Datenbank-Clients, HTTP-Clients, Dateisystem-Helfer, Serialisierer und SDK-Aufrufe. Bevorzugen Sie „Result.fromThrowable“ für synchrone Werfer, „ResultAsync.fromThrowable“ für Versprechen zurückgebende Funktionen, die werfen oder ablehnen können, und „ResultAsync.fromPromise“, wenn Sie bereits einen „PromiseLike“-Wert zur Hand haben. Behalten Sie „try/catch“ nur bei, wenn das Sprachkonstrukt, die Bereinigungsanforderung oder die Framework-Grenze dies wirklich erfordern.
