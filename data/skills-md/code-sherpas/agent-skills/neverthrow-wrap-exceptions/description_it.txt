Cattura eccezioni e prometti errori con "neverthrow" invece di "try/catch" scritto a mano nel codice TypeScript e JavaScript. Da utilizzare per il confezionamento di funzioni sincrone che potrebbero generare un'eccezione, funzioni di restituzione di promesse che potrebbero generare un'eccezione prima della restituzione, valori "PromiseLike" esistenti che potrebbero essere rifiutati o API di terze parti come parser, client di database, client HTTP, helper del file system, serializzatori e chiamate SDK. Preferisci "Result.fromThrowable" per i lanciatori sincroni, "ResultAsync.fromThrowable" per le funzioni di restituzione di promesse che possono lanciare o rifiutare e "ResultAsync.fromPromise" quando hai già un valore "PromiseLike" in mano. Mantieni "try/catch" solo quando il costrutto del linguaggio, i requisiti di pulizia o i limiti del framework lo richiedono veramente.
