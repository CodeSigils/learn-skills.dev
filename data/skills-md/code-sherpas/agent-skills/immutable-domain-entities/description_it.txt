Richiedi il modello di progettazione immutabile per le entità di dominio. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare entità di dominio e deve preservare l'identità esprimendo al tempo stesso i cambiamenti di stato attraverso nuove istanze immutabili. Le entità di dominio devono essere modellate come classi immutabili, non come alias di tipo semplice o interfacce abbinate a funzioni autonome.
