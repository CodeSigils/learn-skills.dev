Exiger le modèle de conception immuable pour les entités de domaine. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter des entités de domaine et doit préserver son identité tout en exprimant des changements d'état via de nouvelles instances immuables. Les entités de domaine doivent être modélisées comme des classes immuables, et non comme des alias de type simple ou des interfaces associées à des fonctions autonomes.
