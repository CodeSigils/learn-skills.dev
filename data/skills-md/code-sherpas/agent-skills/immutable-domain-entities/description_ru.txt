Требовать неизменяемый шаблон проектирования для сущностей предметной области. Используйте, когда агенту необходимо создавать, изменять, просматривать или интерпретировать объекты домена и сохранять идентичность, выражая изменения состояния через новые неизменяемые экземпляры. Сущности предметной области должны моделироваться как неизменяемые классы, а не как псевдонимы простых типов или интерфейсы в сочетании с автономными функциями.
