Erfordern das unveränderliche Entwurfsmuster für Domänenentitäten. Verwenden Sie diese Option, wenn ein Agent Domänenentitäten erstellen, ändern, überprüfen oder interpretieren muss und die Identität bewahren soll, während er Zustandsänderungen durch neue unveränderliche Instanzen ausdrückt. Domänenentitäten müssen als unveränderliche Klassen modelliert werden, nicht als einfache Typaliase oder Schnittstellen gepaart mit eigenständigen Funktionen.
