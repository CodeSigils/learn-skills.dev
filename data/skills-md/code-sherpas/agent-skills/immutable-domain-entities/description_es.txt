Requerir el patrón de diseño inmutable para entidades de dominio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar entidades de dominio y debe preservar la identidad mientras expresa cambios de estado a través de nuevas instancias inmutables. Las entidades de dominio deben modelarse como clases inmutables, no como alias de tipo simple o interfaces combinadas con funciones independientes.
