Требуйте, чтобы каждая точка входа бизнес-логики заключала весь свой поток в транзакцию базы данных с использованием библиотеки, платформы или ORM проекта, если базовая технология персистентности поддерживает транзакции. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать точки входа бизнес-логики, которые взаимодействуют с базой данных. Транзакция должна охватывать весь поток точки входа, включая бизнес-ограничения, бизнес-операции и постоянство, чтобы весь поток выполнялся или завершался атомарно.
