Richiedere a ogni punto di ingresso della logica aziendale di racchiudere l'intero flusso in una transazione di database utilizzando la libreria, il framework o l'ORM del progetto, quando la tecnologia di persistenza sottostante supporta le transazioni. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare i punti di ingresso della logica aziendale che interagiscono con un database. La transazione deve comprendere l'intero flusso del punto di ingresso, compresi i vincoli aziendali, le operazioni aziendali e la persistenza, in modo che l'intero flusso abbia esito positivo o negativo in modo atomico.
