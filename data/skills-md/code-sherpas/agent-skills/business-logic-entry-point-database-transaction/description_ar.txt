اطلب من كل نقطة إدخال لمنطق الأعمال أن تقوم بتغليف تدفقها بالكامل في معاملة قاعدة البيانات باستخدام مكتبة المشروع أو إطار العمل أو ORM، عندما تدعم تقنية الثبات الأساسية المعاملات. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير نقاط إدخال منطق الأعمال التي تتفاعل مع قاعدة البيانات. ويجب أن تشمل المعاملة التدفق الكامل لنقطة الدخول، بما في ذلك القيود التجارية، والعمليات التجارية، والاستمرارية، بحيث ينجح التدفق بأكمله أو يفشل ذريًا.
