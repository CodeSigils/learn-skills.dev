Exiger que chaque point d'entrée de logique métier enveloppe l'intégralité de son flux dans une transaction de base de données à l'aide de la bibliothèque, du framework ou de l'ORM du projet, lorsque la technologie de persistance sous-jacente prend en charge les transactions. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter des points d'entrée de logique métier qui interagissent avec une base de données. La transaction doit englober l'intégralité du flux du point d'entrée, y compris les contraintes métier, les opérations métier et la persistance, afin que l'ensemble du flux réussisse ou échoue de manière atomique.
