Exigir que cada punto de entrada de la lógica empresarial incluya todo su flujo en una transacción de base de datos utilizando la biblioteca, el marco o el ORM del proyecto, cuando la tecnología de persistencia subyacente admita transacciones. Úselo cuando un agente necesita crear, modificar, revisar o interpretar puntos de entrada de lógica empresarial que interactúan con una base de datos. La transacción debe abarcar todo el flujo del punto de entrada, incluidas las restricciones comerciales, las operaciones comerciales y la persistencia, de modo que todo el flujo tenga éxito o falle de forma atómica.
