Erfordern Sie, dass jeder Geschäftslogik-Einstiegspunkt seinen gesamten Ablauf in eine Datenbanktransaktion einschließt, indem Sie die Bibliothek, das Framework oder ORM des Projekts verwenden, wenn die zugrunde liegende Persistenztechnologie Transaktionen unterstützt. Verwenden Sie diese Option, wenn ein Agent Geschäftslogik-Einstiegspunkte erstellen, ändern, überprüfen oder interpretieren muss, die mit einer Datenbank interagieren. Die Transaktion muss den gesamten Einstiegspunktfluss umfassen, einschließlich Geschäftseinschränkungen, Geschäftsvorgängen und Persistenz, damit der gesamte Fluss atomar erfolgreich ist oder fehlschlägt.
