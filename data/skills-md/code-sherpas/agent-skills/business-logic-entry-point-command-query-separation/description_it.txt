Applica la separazione comandi-query in modo specifico nei punti di ingresso della logica aziendale. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare funzioni pubbliche, metodi, gestori, casi d'uso, servizi applicativi, facciate o punti di ingresso simili che attivano la logica aziendale. Classificare ciascun punto di ingresso come comando che modifica lo stato o come query che restituisce dati, mai entrambi. L'unico dato consentito restituito da un comando è l'ID o gli ID delle entità di dominio create da un'operazione di creazione.
