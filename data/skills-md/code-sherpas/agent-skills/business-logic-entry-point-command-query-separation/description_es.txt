Aplique la separación entre comandos y consultas específicamente en los puntos de entrada de la lógica empresarial. Úselo cuando un agente necesita crear, modificar, revisar o interpretar funciones, métodos, controladores, casos de uso, servicios de aplicaciones, fachadas o puntos de entrada similares públicos que activen la lógica empresarial. Clasifique cada punto de entrada como un comando que cambia de estado o una consulta que devuelve datos, nunca ambos. Los únicos datos permitidos que devuelve un comando son el ID o los ID de las entidades de dominio creadas mediante una operación de creación.
