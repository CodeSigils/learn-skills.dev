فرض فصل الأوامر والاستعلام على وجه التحديد عند نقاط دخول منطق الأعمال. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير الوظائف العامة أو الأساليب أو المعالجات أو حالات الاستخدام أو خدمات التطبيقات أو الواجهات أو نقاط الإدخال المماثلة التي تقوم بتشغيل منطق الأعمال. قم بتصنيف كل نقطة إدخال كأمر يغير الحالة أو استعلام يقوم بإرجاع البيانات، وليس كلاهما. البيانات الوحيدة المسموح بها التي يتم إرجاعها من أمر ما هي معرف أو معرفات كيانات المجال التي تم إنشاؤها بواسطة عملية إنشاء.
