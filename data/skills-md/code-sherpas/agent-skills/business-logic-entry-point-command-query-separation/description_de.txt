Erzwingen Sie die Trennung von Befehlen und Abfragen speziell an den Einstiegspunkten der Geschäftslogik. Wird verwendet, wenn ein Agent öffentliche Funktionen, Methoden, Handler, Anwendungsfälle, Anwendungsdienste, Fassaden oder ähnliche Einstiegspunkte erstellen, ändern, überprüfen oder interpretieren muss, die Geschäftslogik auslösen. Klassifizieren Sie jeden Einstiegspunkt entweder als einen Befehl, der den Status ändert, oder als eine Abfrage, die Daten zurückgibt, niemals beides. Die einzige zulässige Datenrückgabe von einem Befehl ist die ID oder die IDs von Domänenentitäten, die durch einen Erstellungsvorgang erstellt wurden.
