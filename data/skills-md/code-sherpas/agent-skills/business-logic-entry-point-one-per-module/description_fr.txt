Exiger que chaque point d’entrée de logique métier réside dans son propre module distinct. À utiliser lorsqu'un agent doit créer, modifier, réviser ou organiser des points d'entrée de logique métier tels que des gestionnaires de commandes, des gestionnaires de requêtes, des cas d'utilisation ou des services d'application. Ne regroupez pas plusieurs points d’entrée dans une seule classe, objet ou fichier en fonction de l’entité de domaine sur laquelle ils opèrent. Chaque point d'entrée doit être soit une fonction de niveau supérieur dans son propre module, soit une classe ou un objet avec exactement une fonction publique dans son propre module.
