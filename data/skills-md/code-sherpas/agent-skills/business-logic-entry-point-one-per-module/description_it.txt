Richiedere che ogni punto di ingresso della logica aziendale risieda nel proprio modulo separato. Da utilizzare quando un agente deve creare, modificare, rivedere o organizzare punti di ingresso della logica aziendale come gestori di comandi, gestori di query, casi d'uso o servizi applicativi. Non raggruppare più punti di ingresso in una singola classe, oggetto o file in base all'entità di dominio su cui operano. Ogni punto di ingresso deve essere una funzione di livello superiore nel proprio modulo oppure una classe o un oggetto con esattamente una funzione pubblica nel proprio modulo.
