Erfordern, dass jeder Geschäftslogik-Einstiegspunkt in einem eigenen separaten Modul lebt. Wird verwendet, wenn ein Agent Geschäftslogik-Einstiegspunkte wie Befehlshandler, Abfragehandler, Anwendungsfälle oder Anwendungsdienste erstellen, ändern, überprüfen oder organisieren muss. Gruppieren Sie nicht mehrere Einstiegspunkte in einer einzigen Klasse, einem einzelnen Objekt oder einer einzelnen Datei basierend auf der Domänenentität, auf der sie arbeiten. Jeder Einstiegspunkt muss entweder eine Funktion der obersten Ebene in einem eigenen Modul oder eine Klasse oder ein Objekt mit genau einer öffentlichen Funktion in seinem eigenen Modul sein.
