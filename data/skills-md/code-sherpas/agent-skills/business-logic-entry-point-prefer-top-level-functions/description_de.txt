Bevorzugen Sie Funktionen der obersten Ebene gegenüber Klassen oder Objekten, um Einstiegspunkte für die Geschäftslogik zu implementieren, wenn der Projektstapel dies ohne Reibungsverluste zulässt. Wird verwendet, wenn ein Agent über die Codeform für einen Geschäftslogik-Einstiegspunkt entscheiden muss, z. B. einen Befehlshandler, einen Abfragehandler, einen Anwendungsfall oder einen Anwendungsdienst. Wählen Sie eine Funktion der obersten Ebene, es sei denn, die Sprache, das Framework oder die Projektkonventionen machen Klassen oder Objekte zur natürlichen und reibungslosen Wahl.
