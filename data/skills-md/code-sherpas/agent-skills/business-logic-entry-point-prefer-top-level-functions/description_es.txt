Prefiera funciones de nivel superior a clases u objetos para implementar puntos de entrada de lógica empresarial cuando la pila del proyecto lo permita sin introducir fricciones. Úselo cuando un agente necesita decidir la forma del código para un punto de entrada de lógica empresarial, como un controlador de comandos, un controlador de consultas, un caso de uso o un servicio de aplicación. Elija una función de nivel superior a menos que el lenguaje, el marco o las convenciones del proyecto hagan que las clases u objetos sean la elección natural y sin fricciones.
