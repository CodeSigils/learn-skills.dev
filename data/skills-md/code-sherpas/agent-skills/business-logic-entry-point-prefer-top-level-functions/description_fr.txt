Préférez les fonctions de niveau supérieur aux classes ou aux objets pour implémenter des points d'entrée de logique métier lorsque la pile de projet le permet sans introduire de friction. À utiliser lorsqu'un agent doit décider de la forme du code pour un point d'entrée de logique métier tel qu'un gestionnaire de commandes, un gestionnaire de requêtes, un cas d'utilisation ou un service d'application. Choisissez une fonction de niveau supérieur, à moins que les conventions du langage, du framework ou du projet ne fassent des classes ou des objets le choix naturel et sans friction.
