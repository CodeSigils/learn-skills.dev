Preferire funzioni di livello superiore rispetto a classi o oggetti per implementare punti di ingresso della logica aziendale quando lo stack del progetto lo consente senza introdurre attriti. Da utilizzare quando un agente deve decidere la forma del codice per un punto di ingresso della logica aziendale come un gestore di comandi, un gestore di query, un caso d'uso o un servizio applicativo. Scegli una funzione di livello superiore a meno che il linguaggio, il framework o le convenzioni del progetto non rendano le classi o gli oggetti la scelta naturale e senza attriti.
