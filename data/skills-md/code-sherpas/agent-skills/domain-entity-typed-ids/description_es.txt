Determine cómo escribir identificadores de entidades de dominio según el sistema de tipos del proyecto. Úselo cuando un agente necesita crear, modificar, revisar o interpretar el tipo de identificador de una entidad de dominio. En idiomas con un sistema de tipos nominales, utilice ID escritos: un tipo distinto por entidad de dominio que envuelve el tipo de identificador subyacente. En idiomas con un sistema de tipos estructurales, utilice identificaciones escritas solo si el idioma ofrece un mecanismo de baja fricción para hacerlos nominalmente distintos. De lo contrario, utilice directamente el tipo de identificador subyacente.
