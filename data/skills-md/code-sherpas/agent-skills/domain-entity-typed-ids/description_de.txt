Bestimmen Sie, wie Domänenentitätsbezeichner basierend auf dem Typsystem des Projekts eingegeben werden. Wird verwendet, wenn ein Agent den Typ der Kennung einer Domänenentität erstellen, ändern, überprüfen oder interpretieren muss. Verwenden Sie in Sprachen mit einem nominalen Typsystem typisierte IDs – einen eindeutigen Typ pro Domänenentität, der den zugrunde liegenden Bezeichnertyp umschließt. Verwenden Sie in Sprachen mit einem strukturellen Typsystem typisierte IDs nur, wenn die Sprache einen reibungslosen Mechanismus bietet, um sie nominell unterscheidbar zu machen. Andernfalls verwenden Sie direkt den zugrunde liegenden Bezeichnertyp.
