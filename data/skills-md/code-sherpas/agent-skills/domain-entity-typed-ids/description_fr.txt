Déterminez comment saisir les identifiants d'entité de domaine en fonction du système de types du projet. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter le type d'identifiant d'une entité de domaine. Dans les langages dotés d'un système de types nominaux, utilisez des identifiants typés : un type distinct par entité de domaine qui encapsule le type d'identifiant sous-jacent. Dans les langages dotés d'un système de types structurels, utilisez les identifiants typés uniquement si le langage offre un mécanisme à faible friction pour les rendre nominalement distincts. Sinon, utilisez directement le type d’identifiant sous-jacent.
