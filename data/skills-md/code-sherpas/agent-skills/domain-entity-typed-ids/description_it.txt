Determina come digitare gli identificatori dell'entità di dominio in base al sistema di tipo del progetto. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare il tipo di identificatore di un'entità di dominio. Nelle lingue con un sistema di tipo nominale, utilizzare ID digitati: un tipo distinto per entità di dominio che racchiude il tipo di identificatore sottostante. Nelle lingue con un sistema di tipi strutturali, utilizzare gli ID digitati solo se la lingua offre un meccanismo a basso attrito per renderli nominalmente distinti. In caso contrario, utilizzare direttamente il tipo di identificatore sottostante.
