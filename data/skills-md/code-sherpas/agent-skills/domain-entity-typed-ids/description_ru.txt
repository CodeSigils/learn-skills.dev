Определите, как вводить идентификаторы объектов домена на основе системы типов проекта. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать тип идентификатора объекта домена. В языках с системой номинальных типов используйте типизированные идентификаторы — отдельный тип для каждой сущности домена, который обертывает базовый тип идентификатора. В языках со структурной системой типов используйте типизированные идентификаторы только в том случае, если язык предлагает простой механизм, позволяющий сделать их номинально различимыми. В противном случае используйте напрямую базовый тип идентификатора.
