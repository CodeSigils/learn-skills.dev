تحديد كيفية كتابة معرفات كيانات المجال بناءً على نظام نوع المشروع. يُستخدم عندما يحتاج الوكيل إلى إنشاء نوع معرف كيان المجال أو تعديله أو مراجعته أو تفسيره. في اللغات التي تحتوي على نظام كتابة اسمي، استخدم المعرفات المكتوبة — نوع مميز لكل كيان مجال يغطي نوع المعرف الأساسي. في اللغات ذات نظام الكتابة البنيوية، استخدم المعرفات المكتوبة فقط إذا كانت اللغة توفر آلية منخفضة الاحتكاك لجعلها متميزة اسميًا. بخلاف ذلك، استخدم نوع المعرف الأساسي مباشرة.
