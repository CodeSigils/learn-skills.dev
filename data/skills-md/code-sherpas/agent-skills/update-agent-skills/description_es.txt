Actualice las habilidades del agente instaladas con la CLI `skills`. Úselo cuando se le solicite actualizar las habilidades instaladas, mantener actualizadas las habilidades de un proyecto o solucionar casos en los que la "actualización de habilidades npx" informa que todo está actualizado. Para instalaciones relacionadas con el proyecto, una actualización sin cambios debe ejecutar inmediatamente el script de reinstalación incluido para que las habilidades rastreadas desde `skills-lock.json` se reinstalen sin investigación adicional.
