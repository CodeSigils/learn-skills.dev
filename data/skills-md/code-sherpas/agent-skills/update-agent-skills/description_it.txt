Aggiorna le competenze dell'agente installate con la CLI "skills". Da utilizzare quando viene richiesto di aggiornare le competenze installate, mantenere aggiornate le competenze di un progetto o risolvere i casi in cui "npx skills update" segnala che tutto è aggiornato. Per le installazioni con ambito progetto, un aggiornamento senza modifiche deve eseguire immediatamente lo script di reinstallazione in bundle in modo che le competenze tracciate da "skills-lock.json" vengano reinstallate senza ulteriori indagini.
