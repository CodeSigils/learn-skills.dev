قم بتحديث مهارات الوكيل المثبتة باستخدام واجهة سطر الأوامر "المهارات". استخدمه عندما يُطلب منك تحديث المهارات المثبتة، أو إبقاء مهارات المشروع محدثة، أو استكشاف الأخطاء وإصلاحها في الحالات التي يُبلغ فيها تحديث مهارات npx بأن كل شيء محدث. بالنسبة لعمليات التثبيت على مستوى المشروع، يجب أن يقوم التحديث بدون تغيير بتشغيل البرنامج النصي المجمع لإعادة التثبيت على الفور، بحيث تتم إعادة تثبيت المهارات المتعقبة من `skills-lock.json` دون تحقيق إضافي.
