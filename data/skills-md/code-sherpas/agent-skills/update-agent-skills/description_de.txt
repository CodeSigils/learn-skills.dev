Aktualisieren Sie die Agent-Skills, die mit der „Skills“-CLI installiert wurden. Verwenden Sie diese Option, wenn Sie aufgefordert werden, installierte Fertigkeiten zu aktualisieren, die Fertigkeiten eines Projekts auf dem neuesten Stand zu halten oder Fälle zu beheben, in denen „npx skills update“ meldet, dass alles auf dem neuesten Stand ist. Bei projektbezogenen Installationen muss bei einem Update ohne Änderung sofort das gebündelte Neuinstallationsskript ausgeführt werden, damit die nachverfolgten Fähigkeiten aus „skills-lock.json“ ohne zusätzliche Untersuchung neu installiert werden.
