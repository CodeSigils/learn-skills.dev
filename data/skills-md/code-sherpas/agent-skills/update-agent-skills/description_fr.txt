Mettez à jour les compétences de l'agent installées avec la CLI « compétences ». À utiliser lorsqu'on vous demande d'actualiser les compétences installées, de maintenir les compétences d'un projet à jour ou de dépanner les cas où « npx skills update » signale que tout est à jour. Pour les installations à l'échelle d'un projet, une mise à jour sans modification doit immédiatement exécuter le script de réinstallation fourni afin que les compétences suivies à partir de « skills-lock.json » soient réinstallées sans enquête supplémentaire.
