Обновите навыки агента, установленные с помощью интерфейса командной строки «skills». Используйте, когда вас просят обновить установленные навыки, поддерживать текущие навыки проекта или устранять неполадки в случаях, когда обновление навыков npx сообщает, что все обновлено. Для установок в рамках проекта обновление без изменений должно немедленно запускать встроенный сценарий переустановки, чтобы отслеживаемые навыки из `skills-lock.json` были переустановлены без дополнительного расследования.
