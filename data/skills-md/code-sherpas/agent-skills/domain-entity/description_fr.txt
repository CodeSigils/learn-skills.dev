Identifiez, interprétez, révisez ou écrivez des entités de domaine dans le code. À utiliser lorsqu'un agent doit décider si une entité de domaine est définie par une identité stable qui persiste dans le temps, ou lorsqu'il doit implémenter, préserver ou refactoriser le cycle de vie de l'entité, les invariants et le comportement autour des données de domaine. Lorsque vous écrivez ou modifiez une entité de domaine, utilisez une classe ou la construction de type classe la plus proche prise en charge par la pile de projet. Ne modélisez pas les entités de domaine sous la forme d'alias de type simple ou d'interfaces associées à des fonctions autonomes.
