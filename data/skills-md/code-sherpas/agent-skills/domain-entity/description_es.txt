Identifique, interprete, revise o escriba entidades de dominio en código. Úselo cuando un agente necesita decidir si una entidad de dominio está definida por una identidad estable que persiste en el tiempo, o cuando debe implementar, preservar o refactorizar el ciclo de vida, las invariantes y el comportamiento de la entidad en torno a los datos del dominio. Al escribir o cambiar una entidad de dominio, utilice una clase o la construcción similar a una clase más cercana que admita la pila del proyecto. No modele entidades de dominio como alias de tipo simple o interfaces combinadas con funciones independientes.
