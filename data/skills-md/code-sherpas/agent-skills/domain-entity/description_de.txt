Identifizieren, interpretieren, überprüfen oder schreiben Sie Domänenentitäten im Code. Wird verwendet, wenn ein Agent entscheiden muss, ob eine Domänenentität durch eine stabile Identität definiert ist, die über die Zeit bestehen bleibt, oder wenn er den Lebenszyklus, die Invarianten und das Verhalten der Entität rund um Domänendaten implementieren, beibehalten oder umgestalten muss. Verwenden Sie beim Schreiben oder Ändern einer Domänenentität eine Klasse oder das nächstgelegene klassenähnliche Konstrukt, das der Projektstapel unterstützt. Modellieren Sie Domänenentitäten nicht als einfache Typaliase oder Schnittstellen gepaart mit eigenständigen Funktionen.
