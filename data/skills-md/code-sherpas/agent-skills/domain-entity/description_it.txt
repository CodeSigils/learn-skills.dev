Identificare, interpretare, rivedere o scrivere entità di dominio nel codice. Da utilizzare quando un agente deve decidere se un'entità di dominio è definita da un'identità stabile che persiste nel tempo o quando deve implementare, preservare o eseguire il refactoring del ciclo di vita, delle invarianti e del comportamento dell'entità attorno ai dati del dominio. Quando scrivi o modifichi un'entità di dominio, utilizza una classe o il costrutto di tipo classe più vicino supportato dallo stack di progetti. Non modellare le entità di dominio come alias o interfacce di tipo semplice abbinate a funzioni autonome.
