コード内のドメイン エンティティを識別、解釈、レビュー、または書き込みます。エージェントが、ドメイン エンティティが長期にわたって持続する安定した ID によって定義されているかどうかを判断する必要がある場合、またはエンティティのライフサイクル、不変条件、およびドメイン データに関する動作を実装、保存、またはリファクタリングする必要がある場合に使用します。ドメイン エンティティを作成または変更する場合は、クラス、またはプロジェクト スタックがサポートする最も近いクラスに似た構造を使用します。ドメイン エンティティをプレーン タイプのエイリアスまたはスタンドアロン関数と組み合わせたインターフェイスとしてモデル化しないでください。
