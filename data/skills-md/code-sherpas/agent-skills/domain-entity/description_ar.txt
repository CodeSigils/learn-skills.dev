تحديد أو تفسير أو مراجعة أو كتابة كيانات المجال في التعليمات البرمجية. يُستخدم عندما يحتاج الوكيل إلى تحديد ما إذا كان كيان المجال محددًا بهوية مستقرة تستمر بمرور الوقت، أو عندما يجب عليه تنفيذ دورة حياة الكيان والثوابت والسلوك حول بيانات المجال أو الحفاظ عليها أو إعادة هيكلتها. عند كتابة كيان مجال أو تغييره، استخدم فئة أو أقرب بنية تشبه الفئة التي يدعمها مكدس المشروع. لا تقم بتصميم كيانات المجال كأسماء مستعارة من النوع العادي أو واجهات مقترنة بوظائف مستقلة.
