Richiedere tipi restituiti basati su `neverthrow` nel codice TypeScript e JavaScript ogni volta che la tecnologia circostante lo consente. Da utilizzare durante la creazione, il refactoring, la revisione o l'estensione di funzioni autonome, funzioni di moduli esportati, metodi di classe, metodi di oggetto, metodi di servizio, metodi di repository e API simili che dovrebbero esporre tipi di risultati espliciti di successo e fallimento nelle loro firme. Preferisci "Result<T, E>" per il codice sincrono e "ResultAsync<T, E>" per il codice asincrono. Salta un tipo restituito "neverthrow" solo quando un framework, una libreria, un'interfaccia runtime o un contratto imposto esternamente è incompatibile e richiede una forma di restituzione diversa.
