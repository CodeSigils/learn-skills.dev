Erfordern „neverthrow“-basierte Rückgabetypen in TypeScript- und JavaScript-Code, wann immer die umgebende Technologie dies zulässt. Wird zum Erstellen, Refactoring, Überprüfen oder Erweitern eigenständiger Funktionen, exportierter Modulfunktionen, Klassenmethoden, Objektmethoden, Dienstmethoden, Repository-Methoden und ähnlicher APIs verwendet, die in ihren Signaturen explizite Erfolgs- und Fehlerergebnistypen offenlegen sollten. Bevorzugen Sie „Result<T, E>“ für synchronen Code und „ResultAsync<T, E>“ für asynchronen Code. Überspringen Sie einen „neverthrow“-Rückgabetyp nur, wenn ein Framework, eine Bibliothek, eine Laufzeitschnittstelle oder ein extern auferlegter Vertrag inkompatibel ist und eine andere Rückgabeform erfordert.
