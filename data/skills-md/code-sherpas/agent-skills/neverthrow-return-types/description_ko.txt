주변 기술이 허용할 때마다 TypeScript 및 JavaScript 코드에 'neverthrow' 기반 반환 유형이 필요합니다. 독립 실행형 함수, 내보낸 모듈 함수, 클래스 메서드, 개체 메서드, 서비스 메서드, 저장소 메서드 및 시그니처에 명시적인 성공 및 실패 결과 유형을 노출해야 하는 유사한 API를 생성, 리팩터링, 검토 또는 확장할 때 사용합니다. 동기 코드의 경우 `Result<T, E>`를 선호하고 비동기 코드의 경우 `ResultAsync<T, E>`를 선호합니다. 프레임워크, 라이브러리, 런타임 인터페이스 또는 외부에서 부과된 계약이 호환되지 않고 다른 반환 형태가 필요한 경우에만 'neverthrow' 반환 유형을 건너뜁니다.
