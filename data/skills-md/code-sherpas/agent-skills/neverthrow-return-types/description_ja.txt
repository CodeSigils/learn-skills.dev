周囲のテクノロジーで許可されている場合は常に、TypeScript および JavaScript コードで「neverthrow」ベースの戻り値の型を要求します。スタンドアロン関数、エクスポートされたモジュール関数、クラス メソッド、オブジェクト メソッド、サービス メソッド、リポジトリ メソッド、およびシグネチャで明示的な成功および失敗の結果タイプを公開する必要がある同様の API を作成、リファクタリング、レビュー、または拡張するときに使用します。同期コードには `Result<T, E>` を、非同期コードには `ResultAsync<T, E>` を優先します。フレームワーク、ライブラリ、ランタイム インターフェイス、または外部から強制されたコントラクトに互換性がなく、異なる戻り形式が必要な場合にのみ、「neverthrow」戻り型をスキップしてください。
