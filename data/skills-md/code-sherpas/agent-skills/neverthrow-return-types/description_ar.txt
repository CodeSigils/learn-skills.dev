تتطلب أنواع الإرجاع المستندة إلى "عدم الرمي" في كود TypeScript وJavaScript عندما تسمح التكنولوجيا المحيطة بذلك. يُستخدم عند إنشاء الوظائف المستقلة أو إعادة هيكلتها أو مراجعتها أو توسيعها، ووظائف الوحدة المصدرة، وأساليب الفئة، وأساليب الكائنات، وأساليب الخدمة، وأساليب المستودع، وواجهات برمجة التطبيقات المشابهة التي يجب أن تعرض أنواع نتائج النجاح والفشل الصريحة في توقيعاتها. تفضل `Result<T, E>` للتعليمات البرمجية المتزامنة و`ResultAsync<T, E>` للتعليمات البرمجية غير المتزامنة. لا يمكنك تخطي نوع الإرجاع "عدم الرمي" إلا عندما يكون إطار العمل أو المكتبة أو واجهة وقت التشغيل أو العقد المفروض خارجيًا غير متوافق ويتطلب شكل إرجاع مختلف.
