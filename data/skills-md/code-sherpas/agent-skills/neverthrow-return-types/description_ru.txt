Требуйте возвращаемые типы на основе `neverthrow` в коде TypeScript и JavaScript всякий раз, когда это позволяет окружающая технология. Используйте при создании, рефакторинге, проверке или расширении автономных функций, экспортированных функций модулей, методов классов, методов объектов, методов обслуживания, методов репозитория и подобных API, которые должны явно отображать типы результатов успеха и неудачи в своих сигнатурах. Предпочитайте `Result<T, E>` для синхронного кода и `ResultAsync<T, E>` для асинхронного кода. Пропускайте тип возврата `neverthrow` только в том случае, если платформа, библиотека, интерфейс среды выполнения или внешний контракт несовместимы и требуют другой формы возврата.
