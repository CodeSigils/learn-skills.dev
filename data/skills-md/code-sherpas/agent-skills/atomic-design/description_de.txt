Erstellen oder aktualisieren Sie Web-UI-Komponenten mit einem strikten Workflow, bei dem die Wiederverwendung an erster Stelle steht. Verwenden Sie es beim Erstellen, Umgestalten, Neugestalten oder Erweitern von Frontend- oder Vorlagenkomponenten und minimieren Sie gleichzeitig Roh-DOM oder HTML, indem Sie zunächst vorhandene Komponenten wiederverwenden oder verallgemeinern.
