あるドメイン エンティティから別のドメイン エンティティへの参照が必須であるかオプションであるかを決定します。エージェントが、別のドメイン エンティティへの参照を保持するドメイン エンティティを作成、変更、レビュー、または解釈する必要があり、その参照が存在しなくてもよいかどうかを判断する必要がある場合に使用します。参照がなければエンティティが有効なドメイン状態で存在できない場合、参照が必要です。参照がなくてもエンティティが有効なドメイン状態で存在できる場合、参照はオプションです。このルールは単一値参照にのみ適用されます。空のコレクションは関連エンティティが存在しないことを表すため、コレクション参照は決して null 値を許容しません。
