한 도메인 엔터티에서 다른 도메인 엔터티로의 참조가 필수인지 선택 사항인지 결정합니다. 에이전트가 다른 도메인 엔터티에 대한 참조를 보유하는 도메인 엔터티를 생성, 수정, 검토 또는 해석해야 하고 해당 참조가 없을 수 있는지 결정해야 할 때 사용합니다. 참조가 없으면 엔터티가 유효한 도메인 상태로 존재할 수 없는 경우 참조가 필요합니다. 참조가 없어도 엔터티가 유효한 도메인 상태에 존재할 수 있는 경우 참조는 선택 사항입니다. 이 규칙은 단일 값 참조에만 적용됩니다. 빈 컬렉션은 관련 엔터티가 없음을 나타내기 때문에 컬렉션 참조는 null을 허용하지 않습니다.
