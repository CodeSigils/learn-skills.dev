Déterminez si une référence d’une entité de domaine à une autre doit être obligatoire ou facultative. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter une entité de domaine qui contient une référence à une autre entité de domaine et doit décider si cette référence peut être absente. Une référence est requise lorsque l'entité ne peut pas exister dans un état de domaine valide sans elle. Une référence est facultative lorsque l'entité peut exister dans un état de domaine valide sans elle. Cette règle s'applique uniquement aux références à valeur unique : les références de collection ne peuvent jamais prendre la valeur Null, car une collection vide représente l'absence d'entités associées.
