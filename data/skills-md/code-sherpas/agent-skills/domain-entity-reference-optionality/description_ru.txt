Определите, должна ли ссылка от одного объекта домена на другой быть обязательной или необязательной. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать объект домена, который содержит ссылку на другой объект домена, и должен решить, может ли эта ссылка отсутствовать. Ссылка требуется, если без нее сущность не может существовать в допустимом состоянии домена. Ссылка является необязательной, если сущность может существовать в допустимом состоянии домена без нее. Это правило применяется только к ссылкам с одним значением — ссылки на коллекции никогда не допускают значения NULL, поскольку пустая коллекция представляет собой отсутствие связанных сущностей.
