Bestimmen Sie, ob ein Verweis von einer Domänenentität auf eine andere erforderlich oder optional sein soll. Wird verwendet, wenn ein Agent eine Domänenentität erstellen, ändern, überprüfen oder interpretieren muss, die einen Verweis auf eine andere Domänenentität enthält, und entscheiden muss, ob dieser Verweis fehlen kann. Eine Referenz ist erforderlich, wenn die Entität ohne sie nicht in einem gültigen Domänenstatus existieren kann. Eine Referenz ist optional, wenn die Entität auch ohne sie in einem gültigen Domänenstatus existieren kann. Diese Regel gilt nur für Einzelwertverweise – Sammlungsverweise sind niemals nullbar, da eine leere Sammlung das Fehlen verwandter Entitäten darstellt.
