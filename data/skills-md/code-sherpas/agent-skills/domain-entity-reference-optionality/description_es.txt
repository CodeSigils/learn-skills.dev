Determine si una referencia de una entidad de dominio a otra debe ser obligatoria u opcional. Úselo cuando un agente necesita crear, modificar, revisar o interpretar una entidad de dominio que contiene una referencia a otra entidad de dominio y debe decidir si esa referencia puede estar ausente. Se requiere una referencia cuando la entidad no puede existir en un estado de dominio válido sin ella. Una referencia es opcional cuando la entidad puede existir en un estado de dominio válido sin ella. Esta regla se aplica solo a referencias de un solo valor: las referencias de colecciones nunca admiten valores NULL porque una colección vacía representa la ausencia de entidades relacionadas.
