Determina se un riferimento da un'entità di dominio a un'altra deve essere obbligatorio o facoltativo. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare un'entità di dominio che contiene un riferimento a un'altra entità di dominio e deve decidere se tale riferimento può essere assente. Un riferimento è richiesto quando l'entità non può esistere in uno stato di dominio valido senza di esso. Un riferimento è facoltativo quando l'entità può esistere in uno stato di dominio valido senza di esso. Questa regola si applica solo ai riferimenti a valore singolo: i riferimenti alla raccolta non sono mai annullabili perché una raccolta vuota rappresenta l'assenza di entità correlate.
