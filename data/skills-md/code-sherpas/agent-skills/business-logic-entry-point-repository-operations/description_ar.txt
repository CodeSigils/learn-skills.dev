تتطلب واجهات المستودع عرض مجموعة قياسية من العمليات بتوقيعات محددة واصطلاحات التسمية. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير واجهات المستودع المستخدمة بواسطة نقاط إدخال منطق الأعمال. يجب أن توفر المستودعات findById، والإنشاء (إرجاع الكيان الذي تم إنشاؤه)، والتحديث (إرجاع الكيان المحدث)، والبحث (إرجاع المجموعة)، وdeleteById (لا يُرجع شيئًا). لا تستخدم عملية "حفظ" عامة - قم دائمًا بالتمييز بين الإنشاء والتحديث بشكل صريح.
