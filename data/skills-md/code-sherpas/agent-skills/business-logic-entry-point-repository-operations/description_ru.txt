Требовать, чтобы интерфейсы репозитория предоставляли стандартный набор операций с определенными сигнатурами и соглашениями об именах. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать интерфейсы репозитория, используемые точками входа бизнес-логики. Репозитории должны предлагать findById, create (возвращает созданный объект), update (возвращает обновленный объект), search (возвращает коллекцию) и deleteById (ничего не возвращает). Не используйте общую операцию «сохранения» — всегда четко различайте создание и обновление.
