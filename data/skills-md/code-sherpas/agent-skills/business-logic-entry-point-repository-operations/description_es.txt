Requerir que las interfaces del repositorio expongan un conjunto estándar de operaciones con firmas específicas y convenciones de nomenclatura. Úselo cuando un agente necesita crear, modificar, revisar o interpretar interfaces de repositorio utilizadas por puntos de entrada de lógica empresarial. Los repositorios deben ofrecer findById, create (devuelve entidad creada), update (devuelve entidad actualizada), search (devuelve colección) y deleteById (devuelve nada). No utilice una operación genérica de "guardar"; siempre distinga explícitamente entre crear y actualizar.
