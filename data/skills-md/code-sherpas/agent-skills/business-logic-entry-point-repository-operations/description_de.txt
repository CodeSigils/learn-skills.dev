Fordern Sie Repository-Schnittstellen auf, um einen Standardsatz von Vorgängen mit spezifischen Signaturen und Namenskonventionen verfügbar zu machen. Wird verwendet, wenn ein Agent von Geschäftslogik-Einstiegspunkten verwendete Repository-Schnittstellen erstellen, ändern, überprüfen oder interpretieren muss. Repositorys müssen findById, create (gibt eine erstellte Entität zurück), update (gibt eine aktualisierte Entität zurück), search (gibt eine Sammlung zurück) und deleteById (gibt nichts zurück) anbieten. Verwenden Sie keinen generischen „Speichern“-Vorgang – unterscheiden Sie immer explizit zwischen Erstellen und Aktualisieren.
