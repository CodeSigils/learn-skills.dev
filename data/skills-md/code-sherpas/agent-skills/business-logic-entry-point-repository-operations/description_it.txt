Richiedere che le interfacce del repository espongano un set standard di operazioni con firme e convenzioni di denominazione specifiche. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare le interfacce del repository utilizzate dai punti di ingresso della logica aziendale. I repository devono offrire findById, create (restituisce l'entità creata), update (restituisce l'entità aggiornata), search (restituisce la raccolta) e deleteById (restituisce nulla). Non utilizzare un'operazione di "salvataggio" generica: distinguere sempre tra creazione e aggiornamento in modo esplicito.
