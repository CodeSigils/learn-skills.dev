Richiede rappresentazioni testuali ISO 8601 per i valori temporali. Da utilizzare quando un agente deve formattare, serializzare, analizzare, documentare, rivedere o definire rappresentazioni testuali di data, ora, data/ora o timestamp in API, eventi, persistenza, log, configurazione o altri limiti basati su stringhe. Quando la rappresentazione testuale include una componente temporale, richiede una precisione al millisecondo.
