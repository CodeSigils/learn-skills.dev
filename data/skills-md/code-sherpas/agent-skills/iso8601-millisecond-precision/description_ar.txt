تتطلب تمثيلات نصية ISO 8601 للقيم الزمنية. يُستخدم عندما يحتاج الوكيل إلى تنسيق أو تسلسل أو تحليل أو توثيق أو مراجعة أو تعريف التاريخ النصي أو الوقت أو التاريخ أو تمثيلات الطابع الزمني في واجهات برمجة التطبيقات أو الأحداث أو الثبات أو السجلات أو التكوين أو الحدود الأخرى المستندة إلى السلسلة. عندما يتضمن التمثيل النصي عنصرًا زمنيًا، يلزم الدقة بالمللي ثانية.
