Requerir representaciones textuales ISO 8601 para valores temporales. Úselo cuando un agente necesita formatear, serializar, analizar, documentar, revisar o definir representaciones textuales de fecha, hora, fecha y hora o marca de tiempo en API, eventos, persistencia, registros, configuración u otros límites basados ​​en cadenas. Cuando la representación textual incluye un componente de tiempo, se requiere una precisión de milisegundos.
