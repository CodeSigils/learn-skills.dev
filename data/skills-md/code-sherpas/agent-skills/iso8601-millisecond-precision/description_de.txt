Erfordern Textdarstellungen nach ISO 8601 für Zeitwerte. Wird verwendet, wenn ein Agent Textdarstellungen von Datum, Uhrzeit, Datum/Uhrzeit oder Zeitstempel in APIs, Ereignissen, Persistenz, Protokollen, Konfigurationen oder anderen stringbasierten Grenzen formatieren, serialisieren, analysieren, dokumentieren, überprüfen oder definieren muss. Wenn die Textdarstellung eine Zeitkomponente enthält, ist eine Genauigkeit im Millisekundenbereich erforderlich.
