Exiger des représentations textuelles ISO 8601 pour les valeurs temporelles. À utiliser lorsqu'un agent doit formater, sérialiser, analyser, documenter, réviser ou définir des représentations textuelles de date, d'heure, de date/heure ou d'horodatage dans les API, les événements, la persistance, les journaux, la configuration ou d'autres limites basées sur des chaînes. Lorsque la représentation textuelle inclut une composante temporelle, exigez une précision à la milliseconde.
