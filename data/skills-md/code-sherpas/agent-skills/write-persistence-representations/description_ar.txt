قم بإنشاء أو تحديث تمثيلات بيانات طبقة الثبات في أي مكدس، بما في ذلك كيانات ORM وتعريفات المخطط وتعيينات الجدول ونماذج المستندات وتعريفات المجموعة والتعليمات البرمجية المماثلة التي تواجه قاعدة البيانات. يُستخدم عندما يحتاج الوكلاء إلى إضافة أو تغيير الحقول أو المعرفات أو العلاقات أو الفهارس أو الطوابع الزمنية أو حقول التدقيق أو تعيينات التخزين في أطر العمل أو المكتبات أو ORMs مثل Prisma أو TypeORM أو Sequelize أو Drizzle أو Mongoose أو Hibernate/JPA أو Doctrine أو Ecto أو Active Record أو تقنيات الثبات المكافئة.
