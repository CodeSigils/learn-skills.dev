Créez ou mettez à jour des représentations de données de couche de persistance dans n'importe quelle pile, y compris les entités ORM, les définitions de schéma, les mappages de tables, les modèles de documents, les définitions de collection et tout code similaire orienté vers la base de données. À utiliser lorsque les agents doivent ajouter ou modifier des champs persistants, des identifiants, des relations, des index, des horodatages, des champs d'audit ou des mappages de stockage dans des frameworks, des bibliothèques ou des ORM tels que Prisma, TypeORM, Sequelize, Drizzle, Mongoose, Hibernate/JPA, Doctrine, Ecto, Active Record ou des technologies de persistance équivalentes.
