ORM エンティティ、スキーマ定義、テーブル マッピング、ドキュメント モデル、コレクション定義、および同様のデータベース対応コードを含む、任意のスタック内の永続層データ表現を作成または更新します。エージェントがフレームワーク、ライブラリ、または Prisma、TypeORM、Sequelize、Drizzle、Mongoose、Hibernate/JPA、Doctrine、Ecto、Active Record、または同等の永続化テクノロジなどの ORM で永続化フィールド、識別子、関係、インデックス、タイムスタンプ、監査フィールド、またはストレージ マッピングを追加または変更する必要がある場合に使用します。
