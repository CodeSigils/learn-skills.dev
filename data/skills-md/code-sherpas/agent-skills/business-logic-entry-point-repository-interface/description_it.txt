Richiedere che i punti di ingresso della logica aziendale dipendano da un'interfaccia del repository piuttosto che da un'implementazione concreta del repository. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare il modo in cui un punto di ingresso della logica aziendale fa riferimento a un repository. Quando il linguaggio di programmazione del progetto supporta interfacce, protocolli, tratti o tipi astratti, il punto di ingresso deve dipendere dall'astrazione del repository, non dall'implementazione concreta. Quando il linguaggio non supporta tali costrutti, questa abilità non si applica.
