اشتراط أن تعتمد نقاط دخول منطق الأعمال على واجهة المستودع بدلاً من تنفيذ المستودع الملموس. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير كيفية قيام نقطة إدخال منطق الأعمال بالرجوع إلى المستودع. عندما تدعم لغة برمجة المشروع واجهات أو بروتوكولات أو سمات أو أنواع مجردة، يجب أن تعتمد نقطة الإدخال على تجريد المستودع، وليس على التنفيذ الملموس. عندما لا تدعم اللغة مثل هذه التركيبات، لا تنطبق هذه المهارة.
