Requerir que los puntos de entrada de la lógica empresarial dependan de una interfaz de repositorio en lugar de una implementación concreta del repositorio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar cómo un punto de entrada de lógica empresarial hace referencia a un repositorio. Cuando el lenguaje de programación del proyecto admite interfaces, protocolos, rasgos o tipos abstractos, el punto de entrada debe depender de la abstracción del repositorio, no de la implementación concreta. Cuando el lenguaje no admite tales constructos, esta habilidad no se aplica.
