Exiger que les points d'entrée de la logique métier dépendent d'une interface de référentiel plutôt que d'une implémentation concrète du référentiel. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter la manière dont un point d'entrée de logique métier fait référence à un référentiel. Lorsque le langage de programmation du projet prend en charge les interfaces, les protocoles, les traits ou les types abstraits, le point d'entrée doit dépendre de l'abstraction du référentiel et non de l'implémentation concrète. Lorsque le langage ne prend pas en charge de telles constructions, cette compétence ne s'applique pas.
