Erfordern, dass Einstiegspunkte für die Geschäftslogik von einer Repository-Schnittstelle und nicht von einer konkreten Repository-Implementierung abhängen. Wird verwendet, wenn ein Agent erstellen, ändern, überprüfen oder interpretieren muss, wie ein Geschäftslogik-Einstiegspunkt auf ein Repository verweist. Wenn die Programmiersprache des Projekts Schnittstellen, Protokolle, Merkmale oder abstrakte Typen unterstützt, muss der Einstiegspunkt von der Repository-Abstraktion und nicht von der konkreten Implementierung abhängen. Wenn die Sprache solche Konstrukte nicht unterstützt, ist diese Fähigkeit nicht anwendbar.
