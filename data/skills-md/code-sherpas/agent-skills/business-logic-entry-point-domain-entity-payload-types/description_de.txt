Fordern Sie Geschäftslogik-Einstiegspunkte auf, Domänen-Entitätstypen direkt in zurückgegebenen Nutzlasten zu verwenden, wenn sie Domänen-Entitätsdaten zurückgeben. Wird verwendet, wenn ein Agent die Erfolgsnutzlast von Geschäftslogik-Einstiegspunkten erstellen, ändern, überprüfen oder interpretieren muss, einschließlich Abfragehandlern und anderen Business-Layer-APIs, die Domänenentitätsdaten zurückgeben. Ordnen Sie Domänenentitäten nicht separaten Nutzlasttypen, DTOs, Ansichtsmodellen oder ähnlichen Transportformen am Einstiegspunkt der Geschäftslogik zu, wenn die Nutzlast Domänenentitätsdaten enthalten soll.
