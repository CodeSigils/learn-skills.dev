Exiger que les points d'entrée de logique métier utilisent les types d'entités de domaine directement dans les charges utiles renvoyées chaque fois qu'ils renvoient des données d'entité de domaine. À utiliser lorsqu'un agent doit créer, modifier, examiner ou interpréter la charge utile de réussite des points d'entrée de la logique métier, y compris les gestionnaires de requêtes et toute autre API de couche métier qui renvoie des données d'entité de domaine. Ne mappez pas les entités de domaine en types de charge utile distincts, DTO, modèles de vue ou formes de transport similaires au point d'entrée de la logique métier lorsque la charge utile est censée contenir des données d'entité de domaine.
