اطلب من نقاط إدخال منطق الأعمال استخدام أنواع كيانات المجال مباشرة في الحمولات التي تم إرجاعها عندما تقوم بإرجاع بيانات كيان المجال. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير حمولة النجاح لنقاط إدخال منطق الأعمال، بما في ذلك معالجات الاستعلام وأي واجهة برمجة تطبيقات أخرى لطبقة الأعمال تقوم بإرجاع بيانات كيان المجال. لا تقم بتعيين كيانات المجال في أنواع حمولة منفصلة أو DTOs أو نماذج عرض أو أشكال نقل مماثلة عند نقطة إدخال منطق الأعمال عندما من المفترض أن تحتوي الحمولة على بيانات كيان المجال.
