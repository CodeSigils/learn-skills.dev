Richiedere che i punti di ingresso della logica aziendale utilizzino i tipi di entità di dominio direttamente nei payload restituiti ogni volta che restituiscono dati di entità di dominio. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare il payload di successo dei punti di ingresso della logica aziendale, inclusi gestori di query e qualsiasi altra API di livello aziendale che restituisce dati di entità di dominio. Non mappare le entità di dominio in tipi di payload, DTO, modelli di visualizzazione o forme di trasporto simili separati nel punto di ingresso della logica aziendale quando si suppone che il payload contenga dati di entità di dominio.
