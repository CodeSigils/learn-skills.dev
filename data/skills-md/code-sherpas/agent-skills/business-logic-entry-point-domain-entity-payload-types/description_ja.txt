ビジネス ロジック エントリ ポイントは、ドメイン エンティティ データを返すたびに、返されたペイロードでドメイン エンティティ タイプを直接使用する必要があります。エージェントが、クエリ ハンドラーやドメイン エンティティ データを返すその他のビジネス層 API など、ビジネス ロジック エントリ ポイントの成功ペイロードを作成、変更、レビュー、または解釈する必要がある場合に使用します。ペイロードにドメイン エンティティ データが含まれると想定されている場合は、ビジネス ロジック エントリ ポイントでドメイン エンティティを別のペイロード タイプ、DTO、ビュー モデル、または同様のトランスポート形状にマップしないでください。
