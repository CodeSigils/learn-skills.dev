Требовать, чтобы точки входа бизнес-логики использовали типы сущностей предметной области непосредственно в возвращаемых полезных нагрузках всякий раз, когда они возвращают данные сущностей предметной области. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать полезные данные успеха точек входа бизнес-логики, включая обработчики запросов и любой другой API бизнес-уровня, который возвращает данные объекта домена. Не сопоставляйте сущности предметной области с отдельными типами полезных данных, DTO, моделями представлений или аналогичными транспортными формами в точке входа бизнес-логики, если предполагается, что полезные данные содержат данные объектов предметной области.
