Promover un conjunto estándar de puntos de entrada de lógica empresarial en torno a un tipo de entidad de dominio cuando un agente debe decidir qué puntos de entrada implementar. Utilícelo al diseñar, crear, modificar, revisar o completar puntos de entrada de lógica empresarial para una entidad de dominio específica. Prefiera puntos de entrada de entidades básicos, como crear, actualizar, buscar por identificación, buscar y eliminar por identificación; utilice puntos de entrada marcados explícitos como para cambios de estado finito, como transiciones de estado booleanas o enumeraciones; utilice puntos de entrada explícitos para asignar o agregar para asociaciones de uno a muchos o de muchos a muchos entre entidades de dominio; y utilice puntos de entrada explícitos para verificar si se puede realizar cuando la operación comercial necesite una respuesta booleana sobre si una acción está permitida actualmente.
