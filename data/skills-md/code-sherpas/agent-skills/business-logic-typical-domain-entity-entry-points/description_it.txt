Promuovere un set standard di punti di ingresso della logica aziendale attorno a un tipo di entità di dominio quando un agente deve decidere quali punti di ingresso implementare. Da utilizzare durante la progettazione, la creazione, la modifica, la revisione o il completamento dei punti di ingresso della logica aziendale per un'entità di dominio specifica. Preferire punti di ingresso di entità di base come creazione, aggiornamento, ricerca per ID, ricerca ed eliminazione per ID; utilizzare punti di ingresso mark-as espliciti per modifiche di stato finito come transizioni di stato enum o booleano; utilizzare l'assegnazione esplicita o l'aggiunta di punti di ingresso per associazioni uno-a-molti o molti-a-molti tra entità di dominio; e utilizzare punti di ingresso di verifica espliciti quando l'operazione aziendale necessita di una risposta booleana sul fatto che un'azione sia attualmente consentita.
