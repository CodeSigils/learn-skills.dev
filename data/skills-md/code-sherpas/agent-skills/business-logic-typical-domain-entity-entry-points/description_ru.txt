Продвигайте стандартный набор точек входа бизнес-логики вокруг типа объекта предметной области, когда агент должен решить, какие точки входа реализовать. Используйте при проектировании, создании, изменении, проверке или заполнении точек входа бизнес-логики для определенной сущности предметной области. Предпочитайте базовые точки входа в объекты, такие как создание, обновление, поиск по идентификатору, поиск и удаление по идентификатору; использовать явные точки входа, помеченные как для изменений конечного состояния, таких как перечисление или логические переходы состояний; использовать явное назначение или добавление точек входа для ассоциаций «один-ко-многим» или «многие-ко-многим» между объектами домена; и используйте явные точки входа для проверки возможности выполнения, когда бизнес-операции требуется логический ответ о том, разрешено ли действие в данный момент.
