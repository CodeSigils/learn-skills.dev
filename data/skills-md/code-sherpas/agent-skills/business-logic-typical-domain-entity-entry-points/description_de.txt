Fördern Sie einen Standardsatz von Geschäftslogik-Einstiegspunkten rund um einen Domänen-Entitätstyp, wenn ein Agent entscheiden muss, welche Einstiegspunkte implementiert werden sollen. Wird zum Entwerfen, Erstellen, Ändern, Überprüfen oder Vervollständigen von Geschäftslogik-Einstiegspunkten für eine bestimmte Domänenentität verwendet. Bevorzugen Sie grundlegende Entitätseinstiegspunkte wie Erstellen, Aktualisieren, Suchen nach ID, Suchen und Löschen nach ID. Verwenden Sie explizite Mark-As-Einstiegspunkte für endliche Zustandsänderungen wie Aufzählungs- oder boolesche Statusübergänge. Verwenden Sie explizite Zuweisungs- oder Hinzufügungspunkte für Eins-zu-viele- oder Viele-zu-viele-Zuordnungen zwischen Domänenentitäten. und verwenden Sie explizite Check-ob-Can-Be-Einstiegspunkte, wenn der Geschäftsvorgang eine boolesche Antwort darüber benötigt, ob eine Aktion derzeit zulässig ist.
