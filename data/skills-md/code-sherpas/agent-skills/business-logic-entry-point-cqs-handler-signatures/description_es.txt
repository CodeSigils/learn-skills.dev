Aplique un patrón de firma para los puntos de entrada de lógica empresarial cuando se siga la separación entre comandos y consultas. Úselo cuando un agente necesita crear, modificar, revisar o interpretar controladores de comandos o controladores de consultas en puntos de entrada de lógica empresarial. Nombre los controladores con un infinitivo más un sufijo de controlador de comandos o controlador de consultas adaptado al estilo del lenguaje, acepte exactamente un parámetro llamado `comando` o `consulta`, siempre ajuste los valores de entrada en un tipo `...Command` o `...Query` dedicado, devuelva el equivalente vacío del proyecto para controladores de comandos que no se hayan creado correctamente, devuelva un tipo `...CommandHandlerSuccess` para controladores de comandos creados correctamente y devuelva un `...QueryHandlerSuccess` escriba para controladores de consultas exitosos.
