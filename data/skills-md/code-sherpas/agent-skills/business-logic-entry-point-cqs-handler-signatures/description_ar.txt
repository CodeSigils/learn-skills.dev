قم بفرض نمط التوقيع لنقاط إدخال منطق الأعمال عند اتباع فصل الأوامر والاستعلام. يُستخدم عندما يحتاج الوكيل إلى إنشاء معالجات الأوامر أو معالجات الاستعلام أو تعديلها أو مراجعتها أو تفسيرها عند نقاط إدخال منطق الأعمال. معالجات الأسماء التي تحتوي على صيغة المصدر بالإضافة إلى لاحقة معالج الأوامر أو معالج الاستعلام التي تم تكييفها مع نمط اللغة، تقبل معلمة واحدة فقط تسمى `command` أو `query`، وتغلف دائمًا قيم الإدخال في نوع `...Command` أو `...Query` مخصص، وتعيد المكافئ الفارغ للمشروع لمعالجات الأوامر الناجحة غير الإنشاء، وترجع نوع `...CommandHandlerSuccess` لإنشاء معالجات أوامر ناجحة، وترجع نوع `...QueryHandlerSuccess` لمعالجات الاستعلام الناجحة.
