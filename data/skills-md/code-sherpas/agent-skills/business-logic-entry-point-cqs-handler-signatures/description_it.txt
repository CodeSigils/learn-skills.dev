Applica un modello di firma per i punti di ingresso della logica aziendale quando viene seguita la separazione comandi-query. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare gestori di comandi o gestori di query nei punti di ingresso della logica aziendale. Gestori di nomi con un infinito più un suffisso di gestore di comandi o di gestore di query adattato allo stile del linguaggio, accettano esattamente un parametro denominato `command` o `query`, racchiudono sempre i valori di input in un tipo dedicato `...Command` o `...Query`, restituiscono l'equivalente vuoto del progetto per gestori di comandi non creati con successo, restituiscono un tipo `...CommandHandlerSuccess` per gestori di comandi creati con successo e restituiscono un Tipo "...QueryHandlerSuccess" per gestori di query riusciti.
