コマンドとクエリの分離が行われている場合、ビジネス ロジック エントリ ポイントの署名パターンを強制します。エージェントがビジネス ロジック エントリ ポイントでコマンド ハンドラーまたはクエリ ハンドラーを作成、変更、レビュー、または解釈する必要がある場合に使用します。不定詞と、言語スタイルに合わせたコマンド ハンドラーまたはクエリ ハンドラーのサフィックスを付けたハンドラーに名前を付けます。`command` または `query` という名前のパラメーターを 1 つだけ受け入れます。入力値は常に専用の `...Command` または `...Query` 型でラップし、成功した非作成コマンド ハンドラーに対してはプロジェクトの空の同等の値を返し、成功した作成コマンド ハンドラーに対しては `...CommandHandlerSuccess` 型を返し、成功したクエリ ハンドラーの `...QueryHandlerSuccess` タイプ。
