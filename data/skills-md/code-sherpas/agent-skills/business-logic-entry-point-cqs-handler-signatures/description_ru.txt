Применяйте шаблон подписи для точек входа бизнес-логики при соблюдении разделения команд и запросов. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать обработчики команд или обработчики запросов в точках входа бизнес-логики. Именуйте обработчики с инфинитивом плюс суффиксом-обработчиком команды или суффиксом-обработчиком запроса, адаптированным к стилю языка, принимайте ровно один параметр с именем `command` или `query`, всегда переносите входные значения в выделенный тип `...Command` или `...Query`, возвращайте пустой эквивалент проекта для успешных обработчиков команд без создания, возвращайте тип `...CommandHandlerSuccess` для успешного создания обработчиков команд и возвращайте тип `...QueryHandlerSuccess` для успешных обработчиков запросов.
