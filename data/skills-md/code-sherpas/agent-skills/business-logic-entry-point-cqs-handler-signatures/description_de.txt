Erzwingen Sie ein Signaturmuster für Geschäftslogik-Einstiegspunkte, wenn die Befehls-Abfrage-Trennung befolgt wird. Wird verwendet, wenn ein Agent Befehlshandler oder Abfragehandler an Einstiegspunkten der Geschäftslogik erstellen, ändern, überprüfen oder interpretieren muss. Benennen Sie Handler mit einem Infinitiv plus einem an den Sprachstil angepassten Befehlshandler- oder Abfragehandler-Suffix, akzeptieren Sie genau einen Parameter namens „command“ oder „query“, packen Sie Eingabewerte immer in einen dedizierten „...Command“- oder „...Query“-Typ ein, geben Sie das leere Äquivalent des Projekts für erfolgreiche, nicht erstellte Befehlshandler zurück, geben Sie einen „...CommandHandlerSuccess“-Typ für erfolgreiche erstellte Befehlshandler zurück und geben Sie a zurück Typ „...QueryHandlerSuccess“ für erfolgreiche Abfragehandler.
