명령-쿼리 분리가 진행될 때 비즈니스 논리 진입점에 대한 서명 패턴을 적용합니다. 에이전트가 비즈니스 논리 진입점에서 명령 처리기 또는 쿼리 처리기를 생성, 수정, 검토 또는 해석해야 할 때 사용합니다. 언어 스타일에 맞게 부정사와 명령 처리기 또는 쿼리 처리기 접미사가 붙은 이름 처리기, `command` 또는 `query`라는 매개변수 하나만 허용하고, 입력 값을 항상 전용 `...Command` 또는 `...Query` 유형으로 래핑하고, 성공적인 비생성 명령 처리기에 해당하는 프로젝트의 빈 값을 반환하고, 성공적인 생성 명령 처리기에 대해 `...CommandHandlerSuccess` 유형을 반환하고, 성공적인 경우 `...QueryHandlerSuccess` 유형을 반환합니다. 쿼리 핸들러.
