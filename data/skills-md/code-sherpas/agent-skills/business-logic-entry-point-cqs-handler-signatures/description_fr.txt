Appliquez un modèle de signature pour les points d’entrée de la logique métier lorsque la séparation commande-requête est suivie. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter des gestionnaires de commandes ou des gestionnaires de requêtes aux points d'entrée de la logique métier. Nommer les gestionnaires avec un infinitif plus un suffixe de gestionnaire de commandes ou de gestionnaire de requêtes adapté au style du langage, accepter exactement un paramètre nommé « commande » ou « requête », envelopper toujours les valeurs d'entrée dans un type dédié « ...Command » ou « ...Query », renvoyer l'équivalent vide du projet pour les gestionnaires de commandes non créés réussis, renvoyer un type « ...CommandHandlerSuccess » pour les gestionnaires de commandes de création réussis et renvoyer un type « ...QueryHandlerSuccess » pour les gestionnaires de commandes réussis. gestionnaires de requêtes.
