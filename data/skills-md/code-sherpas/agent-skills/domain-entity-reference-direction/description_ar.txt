تحديد ما إذا كان يجب على كيان المجال أن يحمل مرجعًا إلى كيان مجال آخر وفي أي اتجاه. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير كيان مجال يتعلق بكيان مجال آخر. يجب أن يحتفظ كيان المجال بمرجع إلى كيان آخر فقط إذا كان يحتاج إلى هذا المرجع لفرض ثوابته أو تنفيذ سلوك المجال الخاص به. المراجع الموجودة فقط لدعم استعلامات القراءة تنتمي إلى المستودع، وليس إلى الكيان.
