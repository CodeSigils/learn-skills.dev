Déterminez si une entité de domaine doit contenir une référence à une autre entité de domaine et dans quelle direction. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter une entité de domaine liée à une autre entité de domaine. Une entité de domaine ne doit détenir une référence à une autre entité que si elle a besoin de cette référence pour appliquer ses propres invariants ou exécuter son propre comportement de domaine. Les références qui existent uniquement pour prendre en charge les requêtes de lecture appartiennent au référentiel, pas à l'entité.
