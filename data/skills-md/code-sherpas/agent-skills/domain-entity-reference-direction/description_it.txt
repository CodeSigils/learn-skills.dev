Determina se un'entità di dominio deve contenere un riferimento a un'altra entità di dominio e in quale direzione. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare un'entità di dominio correlata a un'altra entità di dominio. Un'entità di dominio dovrebbe contenere un riferimento a un'altra entità solo se ha bisogno di quel riferimento per applicare le proprie invarianti o eseguire il proprio comportamento di dominio. I riferimenti che esistono solo per supportare le query di lettura appartengono al repository, non all'entità.
