Bestimmen Sie, ob und in welcher Richtung eine Domänenentität einen Verweis auf eine andere Domänenentität enthalten soll. Verwenden Sie diese Option, wenn ein Agent eine Domänenentität erstellen, ändern, überprüfen oder interpretieren muss, die sich auf eine andere Domänenentität bezieht. Eine Domänenentität sollte nur dann einen Verweis auf eine andere Entität enthalten, wenn sie diesen Verweis benötigt, um ihre eigenen Invarianten durchzusetzen oder ihr eigenes Domänenverhalten auszuführen. Referenzen, die nur zur Unterstützung von Leseabfragen vorhanden sind, gehören in das Repository, nicht in die Entität.
