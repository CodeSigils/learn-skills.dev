Определите, должна ли сущность домена содержать ссылку на другую сущность домена и в каком направлении. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать объект домена, который относится к другому объекту домена. Сущность предметной области должна содержать ссылку на другую сущность только в том случае, если эта ссылка нужна ей для реализации своих собственных инвариантов или выполнения собственного поведения в предметной области. Ссылки, существующие только для поддержки запросов на чтение, принадлежат репозиторию, а не сущности.
