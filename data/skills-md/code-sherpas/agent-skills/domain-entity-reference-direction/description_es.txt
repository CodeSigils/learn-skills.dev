Determine si una entidad de dominio debe contener una referencia a otra entidad de dominio y en qué dirección. Úselo cuando un agente necesita crear, modificar, revisar o interpretar una entidad de dominio que se relaciona con otra entidad de dominio. Una entidad de dominio solo debe contener una referencia a otra entidad si necesita esa referencia para imponer sus propias invariantes o ejecutar su propio comportamiento de dominio. Las referencias que existen sólo para admitir consultas de lectura pertenecen al repositorio, no a la entidad.
