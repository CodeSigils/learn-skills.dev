Legen Sie Transaktionsisolationsstufen für Geschäftslogik-Einstiegspunkte fest, wenn sowohl die Befehls-Abfrage-Trennung als auch Datenbanktransaktionen verwendet werden und die zugrunde liegende Persistenztechnologie konfigurierbare Isolationsstufen unterstützt. Wird verwendet, wenn ein Agent die Isolationsstufe einer Datenbanktransaktion an einem Geschäftslogik-Einstiegspunkt erstellen, ändern, überprüfen oder interpretieren muss, der CQS folgt. Abfragehandler müssen die am wenigsten blockierende Isolationsstufe verwenden, die in der Datenbank des Projekts verfügbar ist. Befehlshandler müssen die Isolationsstufe REPEATABLE READ verwenden.
