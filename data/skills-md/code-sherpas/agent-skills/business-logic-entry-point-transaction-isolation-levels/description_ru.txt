Установите уровни изоляции транзакций для точек входа бизнес-логики, когда используются разделение команд и запросов и транзакции базы данных, а базовая технология персистентности поддерживает настраиваемые уровни изоляции. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать уровень изоляции транзакции базы данных в точке входа бизнес-логики, следующей за CQS. Обработчики запросов должны использовать наименьший уровень блокировки блокировки, доступный в базе данных проекта. Обработчики команд должны использовать уровень изоляции REPEATABLE READ.
