قم بتعيين مستويات عزل المعاملات لنقاط إدخال منطق الأعمال عندما يكون فصل استعلام الأوامر ومعاملات قاعدة البيانات قيد الاستخدام وتدعم تقنية الثبات الأساسية مستويات العزل القابلة للتكوين. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير مستوى عزل معاملة قاعدة البيانات عند نقطة إدخال منطق الأعمال التي تتبع CQS. يجب أن تستخدم معالجات الاستعلام مستوى العزل الأقل حظرًا المتوفر في قاعدة بيانات المشروع. يجب أن تستخدم معالجات الأوامر مستوى عزل القراءة المتكررة.
