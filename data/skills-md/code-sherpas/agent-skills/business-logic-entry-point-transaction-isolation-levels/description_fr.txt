Définissez les niveaux d'isolement des transactions pour les points d'entrée de la logique métier lorsque la séparation commande-requête et les transactions de base de données sont toutes deux utilisées et que la technologie de persistance sous-jacente prend en charge les niveaux d'isolement configurables. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter le niveau d'isolement d'une transaction de base de données à un point d'entrée de logique métier qui suit CQS. Les gestionnaires de requêtes doivent utiliser le niveau d'isolement le moins bloquant disponible dans la base de données du projet. Les gestionnaires de commandes doivent utiliser le niveau d’isolement REPEATABLE READ.
