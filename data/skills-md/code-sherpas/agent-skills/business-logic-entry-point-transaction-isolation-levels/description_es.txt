Establezca niveles de aislamiento de transacciones para puntos de entrada de lógica empresarial cuando se utilicen la separación de consultas y comandos y las transacciones de bases de datos y la tecnología de persistencia subyacente admita niveles de aislamiento configurables. Úselo cuando un agente necesita crear, modificar, revisar o interpretar el nivel de aislamiento de una transacción de base de datos en un punto de entrada de lógica empresarial que sigue a CQS. Los controladores de consultas deben utilizar el nivel de aislamiento de bloqueo mínimo disponible en la base de datos del proyecto. Los controladores de comandos deben utilizar el nivel de aislamiento REPEATABLE READ.
