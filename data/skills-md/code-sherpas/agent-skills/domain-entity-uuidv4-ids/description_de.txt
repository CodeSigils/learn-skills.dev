Erfordern UUIDv4-Identifikatoren für Domänenentitäten. Wird verwendet, wenn ein Agent Domänenentitäts-ID-Felder, ID-Typen, Konstruktoren, Persistenzzuordnungen, Serialisierung oder API-Verträge erstellen, ändern, überprüfen oder interpretieren muss, die an die Domänenentitätsidentität gebunden sind. Bevorzugen Sie den integrierten UUID-Typ der Programmiersprache, sofern vorhanden. Wenn die Sprache keinen integrierten UUID-Typ hat, verwenden Sie „string“ unter Beibehaltung der expliziten UUIDv4-Generierungs- und Validierungssemantik.
