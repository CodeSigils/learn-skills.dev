Exiger des identifiants UUIDv4 pour les entités de domaine. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter les champs d'ID d'entité de domaine, les types d'ID, les constructeurs, les mappages de persistance, la sérialisation ou les contrats d'API liés à l'identité de l'entité de domaine. Préférez le type UUID intégré au langage de programmation lorsqu’il existe. Si le langage n'a pas de type UUID intégré, utilisez `string` tout en préservant la sémantique explicite de génération et de validation UUIDv4.
