Requerir identificadores UUIDv4 para entidades de dominio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar campos de ID de entidad de dominio, tipos de ID, constructores, asignaciones de persistencia, serialización o contratos API vinculados a la identidad de entidad de dominio. Prefiere el tipo UUID integrado del lenguaje de programación cuando exista. Si el lenguaje no tiene un tipo de UUID incorporado, utilice "cadena" conservando la semántica explícita de generación y validación de UUIDv4.
