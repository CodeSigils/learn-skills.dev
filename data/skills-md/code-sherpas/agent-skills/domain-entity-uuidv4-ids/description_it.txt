Richiedi identificatori UUIDv4 per le entità di dominio. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare i campi ID dell'entità di dominio, i tipi di ID, i costruttori, le mappature di persistenza, la serializzazione o i contratti API legati all'identità dell'entità di dominio. Preferire il tipo UUID integrato nel linguaggio di programmazione quando esiste. Se il linguaggio non ha un tipo UUID integrato, utilizza "string" preservando la generazione esplicita dell'UUIDv4 e la semantica di convalida.
