تتطلب معرفات UUIDv4 لكيانات المجال. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير حقول معرف كيان المجال أو أنواع المعرفات أو المنشئات أو تعيينات الثبات أو التسلسل أو عقود API المرتبطة بهوية كيان المجال. تفضيل نوع UUID المدمج في لغة البرمجة عندما يكون موجودًا. إذا لم تحتوي اللغة على نوع UUID مدمج، فاستخدم "string" مع الحفاظ على إنشاء UUIDv4 الصريح ودلالات التحقق من الصحة.
