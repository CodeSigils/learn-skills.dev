Требуйте идентификаторы UUIDv4 для объектов домена. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать поля идентификатора объекта домена, типы идентификаторов, конструкторы, сопоставления постоянства, сериализацию или контракты API, привязанные к идентификатору объекта домена. Предпочитайте встроенный тип UUID языка программирования, если он существует. Если в языке нет встроенного типа UUID, используйте `string`, сохраняя при этом явную семантику генерации и проверки UUIDv4.
