Exiger que les types de paramètres déclarés par le projet et les types de retour d'un point d'entrée de logique métier soient déclarés dans le même fichier que le point d'entrée lui-même, lorsque la pile du projet le permet. À utiliser lorsqu'un agent doit créer, modifier, réviser ou organiser des définitions de type pour les types de commande, les types de requête, les types de réussite, les types d'erreur ou d'autres types déclarés par le projet utilisés dans la signature d'un point d'entrée de logique métier. Ne placez pas ces types dans des fichiers séparés, des modules de types partagés ou des exportations baril.
