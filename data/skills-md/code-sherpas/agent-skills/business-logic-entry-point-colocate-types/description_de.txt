Erfordern, dass vom Projekt deklarierte Parametertypen und Rückgabetypen eines Geschäftslogik-Einstiegspunkts in derselben Datei wie der Einstiegspunkt selbst deklariert werden, wenn der Projektstapel dies zulässt. Wird verwendet, wenn ein Agent Typdefinitionen für Befehlstypen, Abfragetypen, Erfolgstypen, Fehlertypen oder andere vom Projekt deklarierte Typen erstellen, ändern, überprüfen oder organisieren muss, die in der Signatur eines Geschäftslogik-Einstiegspunkts verwendet werden. Platzieren Sie diese Typen nicht in separaten Dateien, gemeinsam genutzten Typmodulen oder Barrel-Exporten.
