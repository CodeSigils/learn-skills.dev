Requerir que los tipos de parámetros declarados por el proyecto y los tipos de retorno de un punto de entrada de lógica empresarial se declaren en el mismo archivo que el propio punto de entrada, cuando la pila del proyecto lo permita. Úselo cuando un agente necesita crear, modificar, revisar u organizar definiciones de tipos para tipos de comandos, tipos de consultas, tipos de éxito, tipos de errores u otros tipos declarados por el proyecto utilizados en la firma de un punto de entrada de lógica empresarial. No coloque estos tipos en archivos separados, módulos de tipos compartidos ni exportaciones de barriles.
