Richiedere che i tipi di parametri dichiarati dal progetto e i tipi restituiti di un punto di ingresso della logica aziendale siano dichiarati nello stesso file del punto di ingresso stesso, quando lo stack del progetto lo consente. Da utilizzare quando un agente deve creare, modificare, rivedere o organizzare le definizioni di tipo per tipi di comando, tipi di query, tipi di successo, tipi di errore o altri tipi dichiarati dal progetto utilizzati nella firma di un punto di ingresso della logica aziendale. Non inserire questi tipi in file separati, moduli di tipo condiviso o esportazioni di barili.
