تتطلب أنواع المعلمات المعلنة من قبل المشروع وأنواع الإرجاع لنقطة إدخال منطق الأعمال التي سيتم الإعلان عنها في نفس الملف مثل نقطة الإدخال نفسها، عندما تسمح حزمة المشروع بذلك. يُستخدم عندما يحتاج الوكيل إلى إنشاء تعريفات أنواع أو تعديلها أو مراجعتها أو تنظيمها لأنواع الأوامر أو أنواع الاستعلام أو أنواع النجاح أو أنواع الأخطاء أو الأنواع الأخرى المعلنة من قبل المشروع والمستخدمة في توقيع نقطة إدخال منطق الأعمال. لا تضع هذه الأنواع في ملفات منفصلة، ​​أو وحدات نمطية مشتركة، أو عمليات تصدير برميلية.
