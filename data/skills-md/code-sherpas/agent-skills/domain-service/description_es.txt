Identifique y encapsule la lógica de dominio que no pertenece a ningún agregado en servicios de dominio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar una lógica de negocios que involucra múltiples agregados y no tiene un propietario natural. Un servicio de dominio contiene lógica de dominio pura: recibe y devuelve tipos de dominio, no tiene dependencias de infraestructura y no accede a repositorios, transacciones ni sistemas externos. El punto de entrada de la lógica empresarial organiza el servicio de dominio cargando los agregados necesarios y pasándolos.
