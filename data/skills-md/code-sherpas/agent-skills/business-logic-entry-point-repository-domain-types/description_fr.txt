Exiger que les types échangés entre les points d’entrée de logique métier et les référentiels soient des types d’entité de domaine et des types de valeur de domaine. À utiliser lorsqu'un agent doit créer, modifier, réviser ou interpréter les interfaces du référentiel ou leur utilisation à partir des points d'entrée de la logique métier. Les signatures de méthodes de référentiel ne doivent pas exposer les types de technologie de persistance tels que les entités ORM, les enregistrements de base de données, les objets de ligne, les modèles de document ou tout autre type généré par ou dépendant de la technologie de persistance concrète.
