تتطلب أن تكون الأنواع المتبادلة بين نقاط إدخال منطق الأعمال والمستودعات هي أنواع كيانات المجال وأنواع قيمة المجال. يُستخدم عندما يحتاج الوكيل إلى إنشاء واجهات المستودع أو تعديلها أو مراجعتها أو تفسيرها أو استخدامها من نقاط إدخال منطق الأعمال. يجب ألا تكشف توقيعات أسلوب المستودع عن أنواع تقنية الثبات مثل كيانات ORM، أو سجلات قاعدة البيانات، أو كائنات الصفوف، أو نماذج المستندات، أو أي نوع تم إنشاؤه بواسطة تقنية الثبات الملموسة أو المعتمدة عليها.
