Richiedere che i tipi scambiati tra i punti di ingresso della logica aziendale e i repository siano tipi di entità di dominio e tipi di valore di dominio. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare le interfacce del repository o il loro utilizzo dai punti di ingresso della logica aziendale. Le firme dei metodi di repository non devono esporre tipi di tecnologia di persistenza come entità ORM, record di database, oggetti riga, modelli di documenti o qualsiasi tipo generato o dipendente dalla tecnologia di persistenza concreta.
