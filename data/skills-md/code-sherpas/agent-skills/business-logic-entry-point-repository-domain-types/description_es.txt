Requerir que los tipos intercambiados entre los puntos de entrada de lógica empresarial y los repositorios sean tipos de entidad de dominio y tipos de valor de dominio. Úselo cuando un agente necesita crear, modificar, revisar o interpretar interfaces de repositorio o su uso desde puntos de entrada de lógica empresarial. Las firmas de métodos de repositorio no deben exponer tipos de tecnología de persistencia, como entidades ORM, registros de bases de datos, objetos de fila, modelos de documentos o cualquier tipo generado por la tecnología de persistencia concreta o que dependa de ella.
