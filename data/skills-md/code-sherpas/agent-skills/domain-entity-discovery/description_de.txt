Identifizieren Sie vor der Implementierung, welche Domänenentitäten zur Darstellung einer Geschäftsdomäne erforderlich sind. Verwenden Sie dies, wenn ein Agent eine Aufgabe erhält, die die Modellierung eines neuen Domänenbereichs oder die Erweiterung eines bestehenden erfordert – beispielsweise die Implementierung einer neuen Funktion, eines neuen Moduls oder eines End-to-End-Ablaufs – und die beteiligten Domänenentitäten noch nicht in der Codebasis definiert sind. Der Agent muss Domänenkonzepte aus den Anforderungen extrahieren, eine Reihe von Domänenentitäten mit ihren Beziehungen vorschlagen, den Vorschlag mit dem Menschen validieren und das vereinbarte Modell dokumentieren, bevor er mit der Implementierung fortfährt.
