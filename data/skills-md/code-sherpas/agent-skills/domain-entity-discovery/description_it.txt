Identificare quali entità di dominio sono necessarie per rappresentare un dominio aziendale prima di implementarle. Da utilizzare quando un agente riceve un'attività che richiede la modellazione di una nuova area di dominio o l'estensione di una esistente, ad esempio l'implementazione di una nuova funzionalità, modulo o flusso end-to-end, e le entità di dominio coinvolte non sono ancora definite nella codebase. L'agente deve estrarre i concetti di dominio dai requisiti, proporre una serie di entità di dominio con le relative relazioni, convalidare la proposta con l'umano e documentare il modello concordato prima di procedere all'implementazione.
