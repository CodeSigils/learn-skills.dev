Identifiez les entités de domaine nécessaires pour représenter un domaine métier avant de les implémenter. À utiliser lorsqu'un agent reçoit une tâche qui nécessite la modélisation d'une nouvelle zone de domaine ou l'extension d'une zone existante (telle que la mise en œuvre d'une nouvelle fonctionnalité, d'un module ou d'un flux de bout en bout) et que les entités de domaine impliquées ne sont pas encore définies dans la base de code. L'agent doit extraire les concepts de domaine des exigences, proposer un ensemble d'entités de domaine avec leurs relations, valider la proposition avec l'humain et documenter le modèle convenu avant de procéder à la mise en œuvre.
