Identifique qué entidades de dominio son necesarias para representar un dominio comercial antes de implementarlas. Úselo cuando un agente recibe una tarea que requiere modelar una nueva área de dominio o ampliar una existente (como implementar una nueva característica, módulo o flujo de un extremo a otro) y las entidades de dominio involucradas aún no están definidas en el código base. El agente debe extraer conceptos de dominio de los requisitos, proponer un conjunto de entidades de dominio con sus relaciones, validar la propuesta con el humano y documentar el modelo acordado antes de proceder a la implementación.
