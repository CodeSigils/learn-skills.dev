Определите, какие сущности домена необходимы для представления бизнес-домена, прежде чем реализовывать их. Используйте, когда агент получает задачу, которая требует моделирования новой предметной области или расширения существующей — например, реализации новой функции, модуля или сквозного потока — и задействованные сущности предметной области еще не определены в базе кода. Агент должен извлечь концепции предметной области из требований, предложить набор сущностей предметной области с их отношениями, проверить предложение с человеком и задокументировать согласованную модель, прежде чем приступить к реализации.
