Fordern Sie, dass Repositorys keine Geschäftslogik enthalten. Verwenden Sie diese Option, wenn ein Agent eine Repository-Implementierung erstellen, ändern, überprüfen oder interpretieren muss. Ein Repository ist ein Persistenz-Gateway – es speichert und ruft Domänenentitäten genau wie angefordert ab. Es darf keine Geschäftsregeln validieren, Invarianten erzwingen, Domänenentscheidungen treffen, den Domänenstatus transformieren, Ergebnisse basierend auf Geschäftskriterien filtern oder Operationen ausführen, die zur Domänenebene gehören. Die gesamte Geschäftslogik gehört zu Domäneneinheiten, Domänendiensten oder Geschäftslogik-Einstiegspunkten.
