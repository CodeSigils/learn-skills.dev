Requerir que los repositorios no contengan lógica empresarial. Úselo cuando un agente necesita crear, modificar, revisar o interpretar una implementación de repositorio. Un repositorio es una puerta de enlace de persistencia: almacena y recupera entidades de dominio exactamente según lo solicitado. No debe validar reglas comerciales, aplicar invariantes, tomar decisiones de dominio, transformar el estado del dominio, filtrar resultados según criterios comerciales ni realizar ninguna operación que pertenezca a la capa de dominio. Toda la lógica empresarial pertenece a entidades de dominio, servicios de dominio o puntos de entrada de lógica empresarial.
