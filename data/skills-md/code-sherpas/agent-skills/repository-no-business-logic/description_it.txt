Richiedere che i repository non contengano alcuna logica aziendale. Da utilizzare quando un agente deve creare, modificare, rivedere o interpretare un'implementazione del repository. Un repository è un gateway di persistenza: archivia e recupera le entità del dominio esattamente come richiesto. Non deve convalidare regole aziendali, applicare invarianti, prendere decisioni sul dominio, trasformare lo stato del dominio, filtrare i risultati in base a criteri aziendali o eseguire qualsiasi operazione che appartiene al livello del dominio. Tutta la logica aziendale appartiene a entità di dominio, servizi di dominio o punti di ingresso della logica aziendale.
