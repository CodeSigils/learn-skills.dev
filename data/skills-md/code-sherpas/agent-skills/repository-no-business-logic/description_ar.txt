تتطلب أن المستودعات لا تحتوي على منطق الأعمال. يُستخدم عندما يحتاج الوكيل إلى إنشاء أو تعديل أو مراجعة أو تفسير تنفيذ المستودع. المستودع عبارة عن بوابة استمرارية - فهو يقوم بتخزين واسترداد كيانات المجال تمامًا كما هو مطلوب. يجب ألا يتحقق من صحة قواعد العمل، أو فرض الثوابت، أو اتخاذ قرارات المجال، أو تحويل حالة المجال، أو تصفية النتائج بناءً على معايير العمل، أو تنفيذ أي عملية تنتمي إلى طبقة المجال. ينتمي كل منطق الأعمال إلى كيانات المجال أو خدمات المجال أو نقاط إدخال منطق الأعمال.
