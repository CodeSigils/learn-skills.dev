Требовать, чтобы репозитории не содержали бизнес-логику. Используйте, когда агенту необходимо создать, изменить, просмотреть или интерпретировать реализацию репозитория. Репозиторий — это шлюз персистентности: он хранит и извлекает объекты домена точно по запросу. Он не должен проверять бизнес-правила, применять инварианты, принимать решения по предметной области, преобразовывать состояние предметной области, фильтровать результаты на основе бизнес-критериев или выполнять какие-либо операции, принадлежащие уровню предметной области. Вся бизнес-логика принадлежит сущностям предметной области, службам предметной области или точкам входа бизнес-логики.
