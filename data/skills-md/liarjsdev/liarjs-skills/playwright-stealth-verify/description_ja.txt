Playwright、Puppeteer、Selenium、または CDP 駆動のブラウザーが、既に所有しているページ (navigator.webdriver、HeadlessChrome トークン、ワーカーとメインスレッドの ID、パッチ適用された API の整合性、WebGL と WebGPU GPU の ID) に対するライブラリとして liarjs を使用して、一貫したフィンガープリントを提示するかどうかを確認します。自動化されたブラウザが通常のブラウザと同じように見えるかどうかを尋ねられた場合、ヘッドレス セットアップやステルス プラグインの効果を推測するのではなく測定する必要がある場合、またはフィンガープリントの品質に関するアサーションがテスト スイートに属する場合に使用します。
