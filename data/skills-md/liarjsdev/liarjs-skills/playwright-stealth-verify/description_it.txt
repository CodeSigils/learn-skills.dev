Controlla se un browser basato su Drammaturgo, Burattinaio, Selenium o CDP presenta un'impronta digitale coerente, utilizzando liarjs come libreria rispetto a una Pagina che già possiedi: navigator.webdriver, token HeadlessChrome, identità lavoratore rispetto al thread principale, integrità API con patch, identità GPU WebGL rispetto a WebGPU. Da utilizzare quando viene chiesto se un browser automatizzato assomiglia a uno normale, quando una configurazione headless o l'effetto di un plug-in stealth necessita di essere misurato anziché supposto o quando un'asserzione sulla qualità dell'impronta digitale appartiene a una suite di test.
