قم ببناء بناء على تراجعات بصمة المتصفح باستخدام liarjs - احفظ فحصًا أساسيًا كـ JSON، وسيتم تشغيل الفرق لاحقًا ضده، وفشل في المهمة عندما تنخفض درجة الاتساق عن الحد الأدنى. استخدمه عندما يُطلب منك إضافة فحص بصمة الإصبع أو اكتشاف مقطوعة الرأس إلى GitHub Actions أو GitLab CI أو مسار آخر، لالتقاط الانحدار في إصدار Chromium أو أداة الكشط قبل شحنه، أو لتتبع كيفية تغير نتيجة بصمة الإصبع عبر الالتزامات.
