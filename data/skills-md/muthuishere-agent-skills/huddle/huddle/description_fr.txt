Organise un groupe d'experts prenant en compte les dépôts pour les décisions d'ingénierie, la planification, la recherche, la vérification et la capture des spécifications. Déclenchez cette compétence lorsque l'utilisateur dit quelque chose comme : « démarrer une réunion », « ouvrir une réunion », « se rassembler », « créer une réunion », « convoquer une réunion d'équipe », « rassembler l'équipe », « faire entrer les experts », « faisons une réunion », « qu'en pense l'équipe », « j'ai besoin de perspectives multiples », « se rassembler », « démarrer une réunion », « ouvrir une réunion », « salle de guerre », « discutons-en en équipe », « faire venir l'équipe », « synchronisation d'équipe », « stand-up quotidien », « que devrions-nous faire à propos de X », « aidez-moi à réfléchir », « je suis bloqué sur X, discutons-en », « reprenons la réunion », « continuons notre discussion », « qu'avons-nous décidé », « donnez-moi une spécification », « résumez la réunion », « quelles sont les actions à entreprendre ». Déclenchez également lorsque l'utilisateur semble bloqué, frustré ou confronté à une décision comportant de multiples compromis, même s'il ne demande pas explicitement de se réunir.
