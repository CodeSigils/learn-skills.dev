Diseño estético del sistema operativo. Se utiliza para el diseño de la interfaz de usuario, decisiones de dirección visual y construcción del lenguaje de diseño. Debe activarse cada vez que un usuario necesite crear diseños de interfaz de usuario, diseños de página, optimizaciones de estilo visual o diseños de marca. Incluso si el usuario solo dice "¿Cómo debería diseñarse esta página?", "Ayúdame a pensar en la dirección visual" o "La interfaz de usuario se ve mal, ¿cómo puedo solucionarlo?" todavía debería estar activado.
