System architecture thinking. Used for discussing technical architecture, system design, protocol specifications, technology selection, and other tasks that require “designing the system from its essence.” It is triggered when the user mentions architecture design, system design, protocol discussion, technical solutions, or design principles. It also serves to assess the rationality of existing architectures. Even if the user simply says “How should this system be designed?” “Help me think about the architecture,” or “Is this solution reasonable?” it should still trigger.
