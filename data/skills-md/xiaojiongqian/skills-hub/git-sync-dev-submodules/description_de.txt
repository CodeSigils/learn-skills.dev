Schnelle lokale Entwicklersynchronisierung für Git-Arbeitsbäume. Wird verwendet, wenn ein Agent (1) den aktuellen Arbeitsbaumzweig auf den neuesten „origin/dev“ aktualisieren muss oder (2) bei der Ausführung von einem „dev“-Arbeitsbaum „dev“ vorspulen und jeden zweiten sauberen Arbeitsbaum auf den lokalen „dev“ umbasieren muss.
