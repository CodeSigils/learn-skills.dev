À utiliser lors de la configuration du serveur CMF MCP afin qu'un assistant de codage IA puisse interroger les métadonnées CMF en langage naturel, ou lorsque le serveur CMF MCP est déjà en cours d'exécution et que l'utilisateur souhaite l'utiliser à partir de son agent de codage. Couvre le déploiement de Docker, la configuration par agent (Claude Code, GitHub Copilot, Cursor, Codex) et des exemples d'invites.
