Используйте при добавлении отслеживания метаданных CMF в существующий код конвейера Python ML или при написании новых этапов конвейера, оснащенных CMF, с нуля. Охватывает API Cmf(): create_context, create_execution, log_dataset, log_model, log_metric, commit_metrics, log_execution_metrics и Finalize(). Включает шаблоны копирования и вставки для распространенных этапов конвейера машинного обучения.
