À utiliser lors de l'ajout du suivi des métadonnées CMF au code de pipeline Python ML existant ou lors de l'écriture de nouvelles étapes de pipeline instrumentées par CMF à partir de zéro. Couvre l'API Cmf() : create_context, create_execution, log_dataset, log_model, log_metric, commit_metrics, log_execution_metrics et finalize(). Inclut des modèles de copier-coller pour les étapes courantes du pipeline ML.
