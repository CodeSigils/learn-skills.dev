Verwenden Sie diese Option, wenn Sie CMF in einem neuen oder vorhandenen Projekt einrichten. Behandelt das Erstellen einer Python-Umgebung (Conda, UV oder Venv), die Installation von cmflib (erfordert Python 3.9–3.11, empfohlen 3.10), das Ausführen von „cmf init“ zum Konfigurieren eines Speicher-Backends (lokal, S3, MinIO, SSH oder OSDF) und das Überprüfen des Setups. Nur Linux – cmflib unterstützt macOS nicht.
