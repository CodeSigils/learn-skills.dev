Используйте при настройке CMF в новом или существующем проекте. Охватывает создание среды Python (conda, uv или venv), установку cmflib (требуется Python 3.9–3.11, рекомендуется 3.10), запуск cmf init для настройки серверной части хранилища (локальный, S3, MinIO, SSH или OSDF) и проверку установки. Только для Linux — cmflib не поддерживает macOS.
