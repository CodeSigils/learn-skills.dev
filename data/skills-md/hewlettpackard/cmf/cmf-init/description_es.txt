Utilícelo al configurar CMF en un proyecto nuevo o existente. Cubre la creación de un entorno Python (conda, uv o venv), la instalación de cmflib (requiere Python 3.9–3.11, recomendado 3.10), la ejecución de `cmf init` para configurar un backend de almacenamiento (local, S3, MinIO, SSH u OSDF) y la verificación de la configuración. Solo Linux: cmflib no es compatible con macOS.
