Utilizzare quando si configura CMF in un progetto nuovo o esistente. Copre la creazione di un ambiente Python (conda, uv o venv), l'installazione di cmflib (richiede Python 3.9–3.11, consigliato 3.10), l'esecuzione di `cmf init` per configurare un backend di archiviazione (locale, S3, MinIO, SSH o OSDF) e la verifica della configurazione. Solo Linux: cmflib non supporta macOS.
