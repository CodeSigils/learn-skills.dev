Domina la programación recreando tus tecnologías favoritas desde cero. Basado en el repositorio de GitHub de más de 529.000 estrellas codecrafters-io/build-your-own-x, esta habilidad indexa más de 200 tutoriales paso a paso en más de 30 dominios tecnológicos: renderizador 3D, modelo de IA, cadena de bloques, base de datos, Docker, emulador, motor de juegos, Git, sistema operativo, lenguaje de programación, red neuronal, Shell, servidor web y más. Activadores: construye el tuyo propio, desde cero, byox, aprende construyendo, recrea, 从零实现, 手写, 造轮子.
