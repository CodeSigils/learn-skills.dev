Jouez la séquence de réveil cinématographique Matrix "Wake up, Neo..." sur la machine de l'utilisateur : pluie numérique, messages lents de type fantôme ("Wake up, Neo...", "The Matrix has you...", "Suivez le lapin blanc.", "Frappez, frappez, Neo."), des coups audibles, une notification macOS chronométrée de "Inconnu" et une pression sur une touche de lapin blanc se terminant par "Il n'y a pas de cuillère". À utiliser chaque fois que l'utilisateur invoque /knock-knock-neo, ou demande « l'expérience Matrix », « réveille Neo », « toc toc Neo », « pluie numérique / pluie Matrix dans mon terminal », « faire ressembler mon terminal à la Matrix », « suivre le lapin blanc », ou veut une surprise de terminal de style Matrix ou un œuf de Pâques — même s'il ne nomme pas la compétence. Purement local et inoffensif ; rien ne sort de la machine.
