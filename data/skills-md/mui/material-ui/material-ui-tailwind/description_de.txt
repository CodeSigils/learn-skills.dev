Integriert die Material-Benutzeroberfläche mit Tailwind CSS v4 mithilfe von Kaskadenebenen (enableCssLayer, @layer order) und dokumentiert die Interoperabilität von Tailwind v3 (Preflight, important, injectFirst, Portale). Wird verwendet, wenn MUI mit Tailwind-Dienstprogrammen, SlotProps-Klassennamen oder Design-Token-Bridges kombiniert wird.
