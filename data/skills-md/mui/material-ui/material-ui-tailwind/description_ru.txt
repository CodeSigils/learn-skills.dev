Интегрирует пользовательский интерфейс Material с Tailwind CSS v4 с помощью каскадных слоев (enableCssLayer, порядок @layer) и документирует совместимость Tailwind v3 (предварительная проверка, важные, injectFirst, порталы). Используйте при объединении MUI с утилитами Tailwind, именем класса slotProps или мостами токенов темы.
