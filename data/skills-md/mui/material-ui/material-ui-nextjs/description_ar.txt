يدمج واجهة المستخدم المادية مع تطبيقات Next.js وأجهزة توجيه الصفحات باستخدام @mui/material-nextjs، وموفري ذاكرة التخزين المؤقت Emotion، والتالي/الخط، وطبقات CSS مع وحدات Tailwind/CSS، وأنماط دعم مكونات الارتباط، ومتغيرات سمات CSS، وملاحظات SSR، وجهاز توجيه التطبيقات useSearchParams + Suspense. يُستخدم عند إعداد MUI أو تصحيح أخطاءه في تطبيق Next.js.
