Интегрирует пользовательский интерфейс Material с маршрутизаторами приложений и страниц Next.js с использованием @mui/material-nextjs, поставщиков кэша Emotion, next/font, слоев CSS с модулями Tailwind/CSS, шаблонов свойств компонентов Link, переменных темы CSS SSR-заметок и маршрутизатора приложений с использованиемSearchParams + Suspense. Используйте при настройке или отладке MUI в приложении Next.js.
