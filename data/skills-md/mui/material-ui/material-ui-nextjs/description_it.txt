Integra l'interfaccia utente di Material con l'app Next.js e i router di Pages utilizzando @mui/material-nextjs, provider di cache Emotion, next/font, livelli CSS con moduli Tailwind/CSS, modelli di prop del componente Link, variabili del tema CSS, note SSR e utilizzo del router dell'appSearchParams + Suspense. Da utilizzare durante la configurazione o il debug di MUI in un'app Next.js.
