Intègre Material UI avec les routeurs d'applications et de pages Next.js à l'aide de @mui/material-nextjs, les fournisseurs de cache Emotion, next/font, les couches CSS avec les modules Tailwind/CSS, les modèles d'accessoires de composant Link, les notes SSR des variables de thème CSS et l'utilisation du routeur d'application SearchParams + Suspense. À utiliser lors de la configuration ou du débogage de MUI dans une application Next.js.
