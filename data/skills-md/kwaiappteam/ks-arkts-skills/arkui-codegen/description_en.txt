ArkUI/ArkTS code generation and modification constraints. The following scenarios are automatically triggered:
1. Directly involving UI code: generating components, writing pages, implementing functionality, ArkUI, build, @Component, @Entry, @Builder, @Styles, @Extend, @State, @Link, @Prop, HarmonyOS, .ets files
2. Modifying/editing any code in .ets files (changing logic, changing conditions, changing styles, adding features, removing features, refactoring)
3. User-provided file path ends with .ets, or code snippet contains build(), @Component, etc., which are ArkUI characteristics
4. Modifying UI‑related business logic such as red dots, badges, tabs, navigation, list items.
