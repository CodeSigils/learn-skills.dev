Según una solución técnica, requisitos de aplicación o fragmentos de código de Android, busque y enumere las API públicas de HarmonyOS ArkTS necesarias. Esto debe activarse cuando un usuario describe una funcionalidad que desea implementar o necesita saber qué API/Kits/interfaces usar, por ejemplo: "¿Qué API necesito implementar...", "Qué interfaces se requieren para una función de captura de fotografías", "Qué kit se debe usar para este requisito", "Qué capacidades de HarmonyOS están involucradas en la solución técnica", "Buscar API relacionadas con la cámara", "Qué interfaces puedo usar para integrar mapas". También debe activarse cuando un usuario describe la necesidad de una aplicación sin solicitar código explícitamente, como por ejemplo: "Quiero crear una aplicación de mensajería instantánea que necesita llamadas de audio y video"; en este caso, identifique todas las API relevantes. Cuando un usuario proporciona fragmentos de código de Android (Java/Kotlin) y solicita las API de HarmonyOS correspondientes, también se debe activar, por ejemplo, "¿Qué API implementaría este código de Android en HarmonyOS?", "Ayúdame a migrar esta función de Android a HarmonyOS, qué interfaces se necesitan": analiza el código de Android y asígnalo a las API de HarmonyOS apropiadas. Las palabras clave de activación incluyen: qué API se necesitan, qué interfaces usar, API de búsqueda, capacidades involucradas, componentes, solución técnica, documentación de API, ruta de documentación, migración de HarmonyOS, migración de Android, código de Android, especialmente cuando se combina con ArkTS/HarmonyOS/Harmony/ability/UIAbility/ArkUI o cualquier nombre de kit. Si el usuario solicita explícitamente escribir o generar un archivo de código .ets, esta habilidad no debe activarse. 

Por favor responda siempre en el idioma del usuario.
