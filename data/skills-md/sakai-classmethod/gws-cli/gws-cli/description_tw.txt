Google Workspace的CLI操作技巧（日曆/雲端硬碟/文件/會議）。  
觸發條件：當上下文包含「Drive」、「ドライブ」、「My Drive」、「GDrive」、「Docs」、「Meet」、「Calendar」或「Workspace」中的任何一個，並且符合下列任何一個。會話、縮寫、片假名/英語混合表達（up / DL / アップ / 落として / 投げて / 放り輦んで / 置いて / りぁんで / 置いて / あぁぁぁ）都包含在內。  
- 將本機檔案上傳至 MyDrive（例如，「上傳至雲端硬碟」、「儲存至 MyDrive」、「上傳 PDF」、「執行更新至雲端硬碟」、「將交付成果丟到雲端硬碟」）
- 將代理程式產生的工件（提案、PPTX、PDF、會議記錄 Markdown 等）儲存到 Drive
- 從雲端硬碟下載到本機（例如，「從雲端硬碟下載」、「DL PPTX」、「將文件另存為 docx」、「替換為最新版本」）
- 檢索會議記錄的會議轉錄/來源數據
- 從日曆事件附件檔案/描述欄位提取雲端硬碟鏈接
- 按日期範圍或關鍵字搜尋日曆事件，自己的日曆列表
- 從 Google 文件正文檢索文本
- 檢索來源資料作為總結和分析 Meet 會議內容的初步步驟

請始終使用使用者的語言進行回覆。
