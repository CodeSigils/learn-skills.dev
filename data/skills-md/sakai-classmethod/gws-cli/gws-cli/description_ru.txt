Навыки работы через CLI для Google Workspace (Календарь/Диск/Документы/Meet).

Условие триггера: когда контекст включает в себя любой из «Диск», «ドライブ», «Мой диск», «GDrive», «Документы», «Meet», «Календарь» или «Рабочая область», и применимо любое из следующих условий. Разговорные, сокращенные, смешанные выражения катаканы и английского языка (up / DL / アップ / 落として / 投げて / 放り込んで / 置いて / あげて / 保存して) также являются всеми применимо.

– Загрузка локальных файлов на Мой диск (например, «загрузить на Диск», «сохранить на Мой диск», «загрузить PDF», «отправить мне на Диск», «бросить результат на Диск»).
- Сохранение элементов, созданных агентом (предложения, PPTX, PDF, протоколы встреч в Markdown и т. д.) на Диске.
- Загрузка с Диска на локальный (например, «загрузить с Диска», «DL PPTX», «сохранить документ как docx», «заменить последней версией»)
- Получение необработанных данных для транскрипции Meet/минут.
- Извлечение ссылок на Диск из вложений/полей описания событий Календаря.
- Поиск событий календаря по диапазону дат и ключевым словам, отображение моего собственного календаря.
- Получение текста тела Документов Google.
– Получение необработанных данных в качестве предварительного шага для обобщения и анализа контента встреч Meet.
