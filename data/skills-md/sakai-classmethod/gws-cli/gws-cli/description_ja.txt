Google Workspace (カレンダー / ドライブ / ドキュメント / Meet) CLI 操作スキル。  
トリガー条件：コンテキストに「ドライブ」、「ドライブ」、「マイドライブ」、「GDrive」、「Docs」、「Meet」、「カレンダー」、「ワークスペース」のいずれかが含まれており、以下のいずれかに該当する場合。会話用語、略語、またはカタカナと英語の混合用語（アップ / DL / アップ / 落として / 投げて / 放り込んで / 置いて / あげて / 保存して）がすべて含まれます。  

- ローカル ファイルを MyDrive にアップロードする (例: 「ドライブにアップロード」、「MyDrive に保存」、「PDF をアップロード」、「ドライブにアップロード」、「成果物をドライブにスロー」)  
- エージェントが生成した出力 (提案書、PPTX、PDF、会議議事録のマークダウンなど) をドライブに保存  
- ドライブからローカルへのダウンロード (例: 「ドライブからダウンロード」、「DL PPTX」、「ドキュメントを asdocx として保存」、「最新バージョンに置き換え」)  
- 会議議事録の議事録/ソース データの取得  
- カレンダーイベントの添付ファイルまたは説明フィールドからのドライブリンクの抽出  
- カレンダーイベントを日付範囲またはキーワードで検索し、自分のカレンダーイベントをリストする  
- Google Docsドキュメントのテキストコンテンツの取得  
- Meet の会議内容を要約または分析するための準備段階として生データを取得する  

常にユーザーの言語で応答してください。
