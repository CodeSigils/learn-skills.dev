구글 워크스페이스(캘린더/드라이브/문서/미트) CLI 운영 스킬.  
트리거 조건: 컨텍스트에 'Drive', '드라이브', '마이드라이브', 'GDrive', 'Docs', 'Meet', 'Calendar', 'Workspace' 중 하나가 포함되고 다음 중 하나와 일치하는 경우. 대화 표현, 약어, 가타카나/영어 혼합(up / DL / app / 落として / 投げて / 放り込んе / 置いて / あげて / 保存して)이 모두 포함되어 있습니다.  

- 내 드라이브에 로컬 파일 업로드(예: '드라이브에 업로드', '내 드라이브에 저장', 'PDF 업로드', '드라이브에 작업 수행', '드라이브에 결과물 던지기')  
- 에이전트가 생성한 출력(제안서, PPTX, PDF, 회의록 마크다운 등)을 드라이브에 저장  
- 드라이브에서 로컬로 다운로드(예: '드라이브에서 다운로드', 'PPTX DL', '문서를 docx로 저장', '최신 버전으로 교체')  
- 몇 분 동안 Meet 스크립트/소스 데이터 가져오기  
- 캘린더 일정 첨부 파일이나 설명 필드에서 드라이브 링크 추출  
- 기간별, 키워드별 캘린더 일정 검색, 나만의 캘린더 나열  
- Google Docs 본문에서 텍스트 검색  
- Meet 회의 콘텐츠를 요약하거나 분석하기 위한 예비 단계로 원시 데이터를 얻습니다.
