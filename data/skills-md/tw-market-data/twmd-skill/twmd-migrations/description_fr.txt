Migrez un pipeline de données boursières taïwanais existant vers TW Market Data (TWMD) avec un minimum de changement de code : cales d'insertion et cartes d'ensembles de données pour FinMind, yfinance, twstock, TEJ (tejapi), les API de courtier (Shioaji 永豐 / Fugle 富果) et les fournisseurs mondiaux (pandas-datareader, Alpha Vantage, Tiingo, Quandl/Nasdaq Data Link, EOD Historical). À utiliser lorsque l'utilisateur extrait déjà des données TW de l'un d'entre eux et souhaite passer à TWMD, ou demande « Équivalent TWMD de <fournisseur> / comment puis-je porter mon code <fournisseur> ». Les noms de colonnes diffèrent selon la source – confirmez par rapport aux documents TWMD.
