Migrazione di una pipeline di dati esistente sulle azioni di Taiwan a TW Market Data (TWMD) con modifiche minime al codice: spessori drop-in e mappe di set di dati per FinMind, yfinance, twstock, TEJ (tejapi), API broker (Shioaji 永豐 / Fugle 富果) e fornitori globali (pandas-datareader, Alpha Vantage, Tiingo, Quandl/Nasdaq Data Link, EOD storico). Da utilizzare quando l'utente estrae già dati TW da uno di questi e desidera passare a TWMD o chiede "equivalente TWMD di <vendor> / come faccio a trasferire il mio codice <vendor>." I nomi delle colonne differiscono in base alla fonte: conferma con i documenti TWMD.
