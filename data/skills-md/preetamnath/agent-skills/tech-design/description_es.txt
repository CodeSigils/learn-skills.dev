Convierta una especificación de producto/UX bloqueada en diseño técnico: el CÓMO: arquitectura, formas de datos, firmas, diseño de archivos. DISPARAR cuando: el usuario pregunta cómo implementar una característica especificada; el usuario quiere decisiones sobre arquitectura, forma de datos o diseño de archivos; el usuario dice "diseño tecnológico" o "diseñar la implementación". SALTAR cuando: el alcance del producto o la UX no estén claros; la implementación es trivial y obvia; sólo queda el orden de las olas.
