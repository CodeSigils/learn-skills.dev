تحويل مواصفات منتج/تجربة مستخدم مقفلة إلى تصميم فني - الطريقة: الهندسة المعمارية، وأشكال البيانات، والتوقيعات، وتخطيط الملف. يتم التشغيل عندما: يسأل المستخدم عن كيفية تنفيذ ميزة محددة؛ يريد المستخدم قرارات تتعلق بالبنية أو شكل البيانات أو تخطيط الملف؛ يقول المستخدم "التصميم الفني" أو "تصميم التنفيذ". تخطي عندما: نطاق المنتج أو تجربة المستخدم غير واضح؛ التنفيذ تافه وواضح؛ يبقى ترتيب الموجة فقط.
