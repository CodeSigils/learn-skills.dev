Verwandeln Sie eine gesperrte Produkt-/UX-Spezifikation in technisches Design – das WIE: Architektur, Datenformen, Signaturen, Dateilayout. TRIGGER, wenn: Der Benutzer fragt, wie eine spezifizierte Funktion implementiert werden soll; Der Benutzer möchte Entscheidungen über Architektur, Datenform oder Dateilayout treffen. Der Benutzer sagt „Tech-Design“ oder „Design der Implementierung“. ÜBERSPRINGEN, wenn: Produktumfang oder UX unklar sind; die Umsetzung ist trivial und offensichtlich; Es bleibt nur die Wellenreihenfolge übrig.
