Riduci una specifica, un set ADR o un documento di progettazione alle esigenze di un costruttore, senza perdere un dato di fatto. SI ATTIVA quando: l'utente dice che una specifica è "troppo lunga" o "gonfia"; l'utente chiede cosa rimuovere da esso o vuole che sia ridotto a "proprio ciò che dobbiamo costruire".
