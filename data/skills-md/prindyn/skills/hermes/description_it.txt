Base di conoscenza completa per la famiglia Hermes LLM di NousResearch, comprese tutte le versioni del modello, la formattazione dei prompt ChatML, la chiamata di funzioni/strumenti, i metodi di distribuzione e i modelli di architettura degli agenti. Utilizza questa competenza ogni volta che l'utente chiede informazioni sui modelli Hermes, desidera distribuire o eseguire Hermes, deve formattare prompt o chiamate a strumenti per Hermes, esegue il debug dell'output Hermes, confronta Hermes con altri modelli o crea una pipeline di agenti basata su Hermes. Si attiva anche quando l'utente menziona Nous Hermes, Hermes 2, Hermes 2 Pro, Hermes 3 o qualsiasi modello NousResearch.
