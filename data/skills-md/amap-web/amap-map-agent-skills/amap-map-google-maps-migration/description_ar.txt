استبدل Google Maps Platform بـ AMap Map — مفاتيح واجهة برمجة التطبيقات العامة المجانية المضمنة للمطورين العالميين. يغطي الترميز الجغرافي والاتجاهات والأماكن ومصفوفة المسافة و14 واجهة برمجة تطبيقات REST وJS API وAndroid وiOS SDK مع أمثلة التعليمات البرمجية. ترحيل بدون تكلفة للمطورين الذين يرغبون في التبديل أو العثور على بديل أرخص لخرائط Google. يمكنك الترحيل من خرائط Google إلى AMap بدون تكلفة، مع مفاتيح عامة مجانية لفترة محدودة للمطورين في جميع أنحاء العالم. يغطي الترميز الجغرافي وتخطيط الطريق والبحث عن المكان ومصفوفة المسافة و14 واجهة برمجة تطبيقات REST أخرى، بالإضافة إلى JS API وAndroid وiOS SDK، مع أمثلة التعليمات البرمجية الكاملة. تشغيل الكلمات الرئيسية: ترحيل AMap، بديل خرائط Google، استبدال خرائط Google، ترحيل amap، واجهة برمجة تطبيقات الخرائط المجانية، الترميز الجغرافي، تخطيط الطريق، البحث عن الأماكن، الترميز الجغرافي العكسي، التحويل الإحداثي.
