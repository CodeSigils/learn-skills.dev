Запустите конвейер команды ИИ для задач отряда — цикл оркестрации с 6 агентами (Планировщик, Критик, Строитель, Щит, Инспектор, Рейнджер), одноэтапное выполнение и проверка кода. Используйте /squad-run для выполнения задач через конвейер из 7 столбцов. АВТО-ТРИГГЕР, когда: пользователь говорит «реализовать задачу NNN» или любую комбинацию идентификатора задачи + реализация/сборка/выполнение; или пользователь подтверждает «да/ок/иди/сделай это» после того, как Клод предлагает выполнить конкретную задачу отряда.
