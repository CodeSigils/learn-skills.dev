Персональный инженерный стандарт для репозиториев Bun/TypeScript. Сочетает в себе правила цепочки инструментов (только Bun, без классов, без описания функции, без интерфейса, без консоли, Winston logger, Atomic Design или функция для каждой папки, ESLint + Prettier), процесс разработки (строгий TDD Red-Green-Refactor, SOLID как типизированные стрелочные функции, гимнастика объектов, объекты значений фирменного типа, Правило трех, YAGNI, «Говорите-не спрашивайте», Закон Деметры), поведенческие рекомендации (думай перед кодированием, простота прежде всего, хирургические изменения, целенаправленное выполнение) и память уроков (читайте .claude/LESSONS.md и Lessons.local.md в начале сеанса, предлагайте записи об ошибках/решениях/ошибках только для добавления в конце сеанса). Используйте для ЛЮБОЙ задачи кода. Написание, редактирование, сборка, тестирование, рефакторинг, зависимости, компоненты React, скрипты, анализ, архитектура, обзор, отладка. Проконсультируйтесь, даже если пользователь не упоминает соглашения. Правила не подлежат обсуждению; нарушения должны быть заблокированы и переписаны.
