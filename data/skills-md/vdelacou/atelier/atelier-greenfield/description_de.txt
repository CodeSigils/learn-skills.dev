Erstellen Sie von Grund auf ein NEUES Bun/TypeScript-, Next.js- oder Java (Quarkus)-Repo nach dem Atelier-Standard – erstellen Sie ein Gerüst für das Clean Architecture- (oder Atomic Design-)Layout, kopieren Sie die Gate-Assets, verdrahten Sie die Git-Hooks, schreiben Sie die Build-Skripte, erstellen Sie ein minimales Green-Walking-Skelett und beweisen Sie, dass jedes Gate vor dem ersten Commit erfolgreich ist. Verwenden Sie diese Option, wenn Sie ein neues Repo oder ein neues Monorepo-Paket von Grund auf starten – sagen Sie „Gerüst für ein neues Bun-Repo“, „Bootstrap eines neuen Projekts auf den Standard“, „Einrichten eines neuen Atelier-Repo/Next.js-Pakets“ oder „Gerüst für einen neuen Java/Quarkus-Dienst“. Nur Greenfield. Verwenden Sie es NIEMALS für Arbeiten innerhalb einer vorhandenen Codebasis (Hinzufügen von Funktionen, Einrichten von Lint oder Tools, Konfigurationsänderungen) – diese gehören zur Hauptfähigkeit des Ateliers oder zum Atelier-Review-Me-Übernahmemodus, um ein Brownfield-Repo auf den Standard zu bringen.
