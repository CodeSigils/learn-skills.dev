Créez un NOUVEAU dépôt Bun/TypeScript, Next.js ou Java (Quarkus) au standard d'atelier à partir de zéro : échafaudez la mise en page Clean Architecture (ou Atomic Design), copiez les actifs de la porte, câblez les hooks git, écrivez les scripts de construction, posez un squelette de marche vert minimal et prouvez que chaque porte passe avant la première validation. À utiliser lors du démarrage d'un nouveau dépôt ou d'un nouveau package monorepo à partir de zéro — dites « échafauder un nouveau dépôt Bun », « amorcer un nouveau projet selon le standard », « configurer un nouveau dépôt atelier / package Next.js » ou « échafauder un nouveau service Java/Quarkus ». Champ vert uniquement. NE JAMAIS l'utiliser pour travailler dans une base de code existante (ajout de fonctionnalités, configuration de peluches ou d'outils, modifications de configuration) - celles-ci appartiennent à la compétence principale de l'atelier, ou au mode d'adoption atelier-review-me pour mettre un dépôt de friches industrielles à la norme.
