قم بإعداد مستودع Bun/TypeScript أو Next.js أو Java (Quarkus) الجديد وفقًا لمعايير المشغل من الصفر - قم بدعم تخطيط Clean Architecture (أو التصميم الذري)، وانسخ أصول البوابة، وقم بتوصيل خطافات git، واكتب نصوص البناء، وقم بوضع هيكل عظمي أخضر بسيط، وأثبت أن كل بوابة تمر قبل الالتزام الأول. استخدمه عند بدء ريبو جديد أو حزمة monorepo جديدة من الصفر - على سبيل المثال "دعامة Bun repo جديدة"، أو "تمهيد مشروع جديد وفقًا للمعايير"، أو "إعداد حزمة atelier repo / Next.js جديدة"، أو "دعم خدمة Java/Quarkus جديدة". جرينفيلد فقط. لا تستخدمه أبدًا للعمل داخل قاعدة تعليمات برمجية موجودة (إضافة ميزات، أو إعداد الوبر أو الأدوات، أو تغييرات التكوين) - فهذه تنتمي إلى مهارة المشغل الرئيسية، أو إلى وضع اعتماد atelier-review-me لرفع مستوى الريبو البني إلى المستوى القياسي.
