從零開始，按照工作室標準建立一個新的 Bun/TypeScript、Next.js 或 Java (Quarkus) 存儲庫 — 搭建乾淨架構（或原子設計）佈局的腳手架，複製門資源，連接 git 掛鉤，編寫構建腳本，鋪設最小的綠色步行骨架，並在第一次提交之前證明每個門都通過。從頭開始啟動新的倉庫或新的 monorepo 套件時使用 - 例如說「搭建一個新的 Bun 倉庫」、「依照標準引導一個新專案」、「設定一個新的 atelier 倉庫/Next.js 套件」或「建立一個新的 Java/Quarkus 服務」。僅限格林菲爾德。切勿將其用於現有程式碼庫中的工作（新增功能、設定 lint 或工具、配置變更）—這些屬於主要工作室技能，或屬於 atelier-review-me 採用模式，以使棕地倉庫達到標準。
