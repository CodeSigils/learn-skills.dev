Realizza un NUOVO repository Bun/TypeScript, Next.js o Java (Quarkus) secondo lo standard dell'atelier partendo da zero: impalcatura del layout Clean Architecture (o Atomic Design), copia le risorse del gate, collega gli hook git, scrivi gli script di build, crea uno scheletro ambulante verde minimo e dimostra che ogni gate passa prima del primo commit. Da utilizzare quando si avvia un nuovo repository o un nuovo pacchetto monorepo da zero: ad esempio "impalcatura un nuovo repository Bun", "avvia un nuovo progetto allo standard", "imposta un nuovo repository atelier/pacchetto Next.js" o "impalcatura un nuovo servizio Java/Quarkus". Solo terreno verde. Non usarlo MAI per lavorare all'interno di una codebase esistente (aggiunta di funzionalità, impostazione di lanugine o strumenti, modifiche alla configurazione): queste appartengono all'abilità principale dell'atelier o alla modalità di adozione di atelier-review-me per portare un repository brownfield allo standard.
