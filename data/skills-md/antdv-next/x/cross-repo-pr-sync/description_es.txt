Habilidad de seguimiento de sincronización de relaciones públicas entre repositorios. Esta habilidad se utiliza cuando un usuario necesita realizar un seguimiento de los cambios de correcciones/funciones en un repositorio ascendente (por ejemplo, ant-design) y sincronizarlos con un repositorio bifurcado descendente (por ejemplo, antdv-next). Escenario desencadenante: el usuario proporciona un SHA de confirmación inicial, necesita enumerar todos los RP que requieren sincronización a partir de esa confirmación y generar una tabla de sincronización ordenada por prioridad y una plantilla de lista de verificación. También se aplica al seguimiento de cambios entre dos repositorios, al análisis de sincronización de bibliotecas de componentes ascendentes y descendentes y a la gestión de tareas de migración entre marcos. Si el usuario menciona palabras clave como "sincronización ascendente", "seguimiento de relaciones públicas", "a partir de una determinada confirmación", "corrección de puerto", "problema de sincronización", se debe utilizar esta habilidad. Específicamente, si el usuario solo dice "repositorio de sincronización", "continuar sincronización", "sincronizar", el sistema primero debe leer el archivo .sync-upstream.json en la raíz del repositorio descendente para obtener la última posición de sincronización, sin requerir que el usuario proporcione ningún parámetro nuevamente.
