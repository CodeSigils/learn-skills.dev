Habilidad de seguimiento de sincronización de relaciones públicas entre repositorios. Esta habilidad se utiliza cuando un usuario necesita realizar un seguimiento de un cambio de corrección/función en un repositorio ascendente (por ejemplo, ant-design) y sincronizarlo con un repositorio bifurcado descendente (por ejemplo, antdv-next). Escenario de activación: el usuario proporciona un SHA de confirmación inicial y necesita una lista de todos los RP que deben sincronizarse a partir de esa confirmación y generar una tabla de sincronización con orden de prioridad y una plantilla de lista de verificación. También se aplica a: seguimiento de cambios entre dos repositorios, análisis de sincronización de bibliotecas de componentes ascendentes y descendentes, gestión de tareas de migración entre marcos. Si el usuario menciona palabras clave como "sincronización ascendente", "seguimiento de PR", "a partir de una confirmación", "corrección de puerto", "problema de sincronización", se debe utilizar esta habilidad. Específicamente, si el usuario solo dice "repositorio de sincronización", "continuar sincronizando" o "sincronizar", el sistema debe leer primero el archivo .sync-upstream.json en la raíz del repositorio descendente para obtener el último punto de sincronización, sin requerir que el usuario proporcione ningún parámetro nuevamente.
