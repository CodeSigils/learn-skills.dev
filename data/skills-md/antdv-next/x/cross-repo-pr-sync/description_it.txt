Capacità di tracciamento della sincronizzazione PR tra repository. Questa competenza viene utilizzata quando un utente deve tenere traccia di una modifica di correzione/funzionalità in un repository upstream (ad esempio, ant-design) e sincronizzarla con un repository portato a valle (ad esempio, antdv-next). Scenario di attivazione: l'utente fornisce un commit SHA iniziale e deve elencare tutti i PR che devono essere sincronizzati da quel commit in poi e generare una tabella di sincronizzazione con ordine di priorità e un modello di elenco di controllo. Applicabile anche a: rilevamento delle modifiche tra due repository, analisi della sincronizzazione della libreria dei componenti upstream-downstream, gestione delle attività di porting tra framework. Se l'utente menziona parole chiave come "sincronizzazione upstream", "traccia PR", "inizia da un determinato commit", "correzione porta", "problema di sincronizzazione", è necessario utilizzare questa abilità. Nello specifico: se l'utente dice solo "sync repository", "continue sync" o "sync", il file root .sync-upstream.json del repository downstream deve essere letto per primo per ottenere l'ultima posizione di sincronizzazione, senza richiedere all'utente di fornire nuovamente alcun parametro.
