Capacità di tracciamento della sincronizzazione PR tra repository. Questa competenza viene utilizzata quando un utente deve tenere traccia di una modifica di correzione/funzionalità in un repository upstream (ad esempio, ant-design) e sincronizzarla con un repository biforcato downstream (ad esempio, antdv-next). Scenario di attivazione: l'utente fornisce un commit SHA iniziale e necessita di un elenco di tutti i PR che devono essere sincronizzati da quel commit in poi e di generare una tabella di sincronizzazione con ordine di priorità e un modello di lista di controllo. Si applica anche a: rilevamento delle modifiche tra due repository, analisi della sincronizzazione della libreria dei componenti upstream‑downstream, gestione delle attività di migrazione tra framework. Se l'utente menziona parole chiave come "sincronizzazione upstream", "traccia PR", "a partire da un commit", "correzione porta", "problema di sincronizzazione", è necessario utilizzare questa abilità. Nello specifico, se l'utente dice solo "sincronizzazione repository", "continua sincronizzazione" o "sincronizzazione", il sistema dovrebbe prima leggere il file .sync-upstream.json nella radice del repository downstream per ottenere l'ultimo punto di sincronizzazione, senza richiedere all'utente di fornire nuovamente alcun parametro.
