リポジトリ間の PR 同期追跡スキル。このスキルは、ユーザーがアップストリーム リポジトリ (ant-design など) の修正/機能の変更を追跡し、それをダウンストリーム フォーク リポジトリ (antdv-next など) に同期する必要がある場合に使用します。トリガー シナリオ: ユーザーは開始コミット SHA を提供し、そのコミット以降に同期する必要があるすべての PR をリストし、優先順位付きの同期テーブルとチェックリスト テンプレートを生成する必要があります。 2 つのリポジトリ間の変更追跡、上流と下流のコンポーネント ライブラリの同期分析、フレームワーク間の移行タスク管理にも適用できます。ユーザーが「アップストリームの同期」、「PR の追跡」、「特定のコミットから開始」、「ポートの修正」、「同期の問題」などのキーワードに言及した場合、このスキルを使用する必要があります。具体的には、ユーザーが「同期リポジトリ」、「同期を継続」、または「同期」とだけ言った場合、ユーザーがパラメータを再度指定する必要なく、ダウンストリーム リポジトリのルート .sync-upstream.json ファイルを最初に読み取って最後の同期位置を取得する必要があります。
