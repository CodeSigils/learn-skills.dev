リポジトリ間の PR 同期追跡スキル。このスキルは、ユーザーが上流のリポジトリ (ant-design など) で修正/機能の変更を追跡し、フォークされた下流のリポジトリ (antdv-next など) に同期する必要がある場合に使用されます。トリガー シナリオ: ユーザーは開始コミット SHA を提供し、そのコミット以降に同期する必要があるすべての PR のリストと、優先順位とチェックリスト テンプレートを含む同期テーブルを生成する必要があります。また、2 つのリポジトリ間の変更追跡、上流と下流のコンポーネント ライブラリの同期分析、フレームワーク間の移行タスク管理にも適用されます。ユーザーが「アップストリームの同期」、「PR の追跡」、「コミットから開始」、「ポートの修正」、「同期の問題」などのキーワードに言及した場合は、このスキルを使用する必要があります。具体的には、ユーザーが「同期リポジトリ」、「同期を継続」、または「同期」とだけ言った場合、システムは最初にダウンストリーム リポジトリのルートにある .sync-upstream.json ファイルを読み取り、最後の同期ポイントを取得する必要があります。ユーザーは再度パラメーターを指定する必要はありません。
