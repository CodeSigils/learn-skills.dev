Fähigkeit zur Repository-übergreifenden PR-Synchronisierungsverfolgung. Diese Fähigkeit wird verwendet, wenn ein Benutzer einen Fix/eine Funktionsänderung in einem Upstream-Repository (z. B. ant-design) verfolgen und mit einem Downstream-Fork-Repository (z. B. antdv-next) synchronisieren muss. Auslöseszenario: Der Benutzer stellt einen Start-Commit-SHA bereit und muss alle PRs auflisten, die ab diesem Commit synchronisiert werden müssen, und eine Synchronisierungstabelle mit Prioritätsreihenfolge und eine Checklistenvorlage erstellen. Dies gilt auch für die Änderungsverfolgung zwischen zwei Repositorys, die Synchronisierungsanalyse von Upstream-Downstream-Komponentenbibliotheken und die Verwaltung von portierungsübergreifenden Aufgaben. Wenn der Benutzer Schlüsselwörter wie „Upstream synchronisieren“, „PR verfolgen“, „ab einem bestimmten Commit starten“, „Port-Fix“ oder „Sync-Problem“ erwähnt, muss dieser Skill verwendet werden. Insbesondere wenn der Benutzer nur „Repository synchronisieren“, „Synchronisierung fortsetzen“ oder „Synchronisieren“ sagt, sollte das System zunächst die Datei .sync-upstream.json im Stammverzeichnis des Downstream-Repositorys lesen, um die letzte Synchronisierungsposition zu erhalten, ohne dass der Benutzer zusätzliche Parameter angeben muss.
