Fähigkeit zur Repository-übergreifenden PR-Synchronisierungsverfolgung. Diese Fähigkeit wird verwendet, wenn ein Benutzer einen Fix/eine Funktionsänderung in einem Upstream-Repository (z. B. ant-design) verfolgen und mit einem Downstream-Fork-Repository (z. B. antdv-next) synchronisieren muss. Auslöseszenario: Der Benutzer stellt einen Start-Commit-SHA bereit und benötigt eine Liste aller PRs, die ab diesem Commit synchronisiert werden müssen, sowie die Generierung einer Synchronisierungstabelle mit Prioritätsreihenfolge und einer Checklistenvorlage. Dies gilt auch für: Änderungsverfolgung zwischen zwei Repositorys, Upstream-Downstream-Synchronisierungsanalyse der Komponentenbibliothek, rahmenübergreifende Migrationsaufgabenverwaltung. Wenn der Benutzer Schlüsselwörter wie „Upstream synchronisieren“, „PR verfolgen“, „von einem Commit starten“, „Port-Fix“ oder „Synchronisierungsproblem“ erwähnt, muss dieser Skill verwendet werden. Insbesondere wenn der Benutzer nur „Repository synchronisieren“, „Synchronisierung fortsetzen“ oder „Synchronisieren“ sagt, sollte das System zunächst die Datei .sync-upstream.json im Stammverzeichnis des Downstream-Repositorys lesen, um den letzten Synchronisierungspunkt zu erhalten, ohne dass der Benutzer erneut Parameter angeben muss.
