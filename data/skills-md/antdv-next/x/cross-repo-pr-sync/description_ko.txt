교차 저장소 PR 동기화 추적 기술. 이 기술은 사용자가 업스트림 저장소(예: ant-design)에서 수정/기능 변경을 추적하고 이를 다운스트림 분기 저장소(예: antdv-next)와 동기화해야 할 때 사용됩니다. 트리거 시나리오: 사용자는 시작 커밋 SHA를 제공하고 해당 커밋부터 동기화해야 하는 모든 PR 목록이 필요하며 우선 순위가 지정된 동기화 테이블과 체크리스트 템플릿을 생성해야 합니다. 또한 두 저장소 간의 변경 사항 추적, 업스트림-다운스트림 구성 요소 라이브러리 동기화 분석, 프레임워크 간 마이그레이션 작업 관리에도 적용됩니다. 사용자가 "업스트림 동기화", "PR 추적", "커밋에서 시작", "포트 수정", "동기화 문제"와 같은 키워드를 언급하는 경우 이 기술을 사용해야 합니다. 특히, 사용자가 "동기화 리포지토리", "동기화 계속" 또는 "동기화"만 말하는 경우 시스템은 사용자가 매개변수를 다시 제공할 필요 없이 먼저 다운스트림 리포지토리의 루트에 있는 .sync-upstream.json 파일을 읽어 마지막 동기화 지점을 가져와야 합니다.
