跨倉庫PR同步追蹤技巧。當使用者需要追蹤上游儲存庫（例如 ant-design）中的修復或功能變更並將其同步到下游移植儲存庫（例如 antdv-next）時，可以使用此技能。觸發場景：使用者提供起始提交 SHA，需要從該提交開始同步的所有 PR 的列表，並產生優先權同步表和清單範本。它也適用於兩個儲存庫之間的變更追蹤、上下游元件庫同步分析以及跨框架移植任務管理。如果使用者提到「同步上游」、「追蹤 PR」、「從某個提交開始」、「連接埠修復」、「同步問題」等關鍵字，則必須使用此技能。具體來說，如果使用者只說“同步儲存庫”、“繼續同步”或“同步”，系統應先讀取下游儲存庫根目錄中的`.sync-upstream.json`檔案以取得最後的同步位置，而不需要使用者再次提供任何參數。
