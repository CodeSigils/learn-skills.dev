Cross-repository PR synchronization tracking skill. This skill is used when a user needs to track a fix/feature change in an upstream repository (e.g., ant-design) and synchronize it to a downstream forked repository (e.g., antdv-next). Trigger scenario: the user provides a starting commit SHA and needs a list of all PRs that need to be synchronized from that commit onward, and to generate a synchronization table with priority ordering and a checklist template. It also applies to: change tracking between two repositories, upstream‑downstream component library synchronization analysis, cross‑framework migration task management. If the user mentions keywords such as “sync upstream,” “track PR,” “starting from a commit,” “port fix,” “sync issue,” this skill must be used. Specifically, if the user only says “sync repository,” “continue syncing,” or “sync,” the system should first read the .sync-upstream.json file in the root of the downstream repository to obtain the last synchronization point, without requiring the user to provide any parameters again.
