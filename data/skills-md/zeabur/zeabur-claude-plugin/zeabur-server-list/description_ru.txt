Используйте при перечислении выделенных серверов. Используйте при проверке статуса сервера, IP-адреса или информации о провайдере. Используйте, когда пользователь говорит «показать мои серверы», «подключиться к серверу по SSH» или «проверить статус сервера». НЕ используйте для просмотра приобретаемых серверов (вместо этого используйте zeabur-server-catalog).
