Verwenden Sie diese Option, wenn Sie eine Zeabur-Vorlage auf dem Marktplatz veröffentlichen oder aktualisieren. Wird verwendet, wenn der Benutzer „Vorlage veröffentlichen“, „Vorlage online aktualisieren“, „Vorlage an Zeabur senden“ oder „Vorlage auf Zeabur erstellen“ sagt. NICHT zum Bereitstellen von Vorlagen verwenden (verwenden Sie stattdessen zeabur-template-deploy). Verwenden Sie zum Bearbeiten der Vorlage NICHT YAML (verwenden Sie stattdessen zeabur-template).
