Wird verwendet, wenn Befehle in einem Zeabur-Dienstcontainer ausgeführt werden. Wird verwendet, wenn der Benutzer „Exec in Container“, „Befehl im Dienst ausführen“, „Dateien im Container prüfen“, „Fehler im Dienst beheben“ oder „Shell in Dienst“ sagt. Wird zum Debuggen auf Containerebene verwendet, z. B. zum Überprüfen von Umgebungsvariablen, Dateien, Prozessen oder Konnektivität.
