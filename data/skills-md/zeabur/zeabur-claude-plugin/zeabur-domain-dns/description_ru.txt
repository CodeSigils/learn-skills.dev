Используйте при управлении записями DNS для доменов, зарегистрированных Zeabur. Используйте, когда пользователь говорит «добавить запись DNS», «обновить DNS», «удалить запись DNS», «составить список записей DNS», «установить запись A», «добавить CNAME» или «управлять DNS». НЕ для привязки домена службы (вместо этого используйте zeabur-domain-url).
