Wird zum Verwalten von DNS-Einträgen für bei Zeabur registrierte Domänen verwendet. Wird verwendet, wenn der Benutzer „DNS-Eintrag hinzufügen“, „DNS aktualisieren“, „DNS-Eintrag löschen“, „DNS-Einträge auflisten“, „Einen Eintrag festlegen“, „CNAME hinzufügen“ oder „DNS verwalten“ sagt. NICHT für die Servicedomänenbindung (verwenden Sie stattdessen zeabur-domain-url).
