À utiliser lors du déploiement du stockage d'objets (compatible S3) sur Zeabur. À utiliser lorsque l'utilisateur a besoin d'un stockage compatible MinIO, RustFS ou S3. À utiliser lorsque l'utilisateur dit « stockage d'objets », « stockage de fichiers », « S3 », « MinIO », « RustFS », « télécharger des fichiers », « stocker des fichiers », « stockage blob » ou « OSS ». À utiliser également lors de l'intégration du stockage d'objets à un service existant.
