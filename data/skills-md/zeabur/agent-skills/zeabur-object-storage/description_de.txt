Wird bei der Bereitstellung von Objektspeicher (S3-kompatibel) auf Zeabur verwendet. Verwenden Sie diese Option, wenn der Benutzer MinIO-, RustFS- oder S3-kompatiblen Speicher benötigt. Wird verwendet, wenn der Benutzer „Objektspeicher“, „Dateispeicher“, „S3“, „MinIO“, „RustFS“, „Dateien hochladen“, „Dateien speichern“, „Blobspeicher“ oder „OSS“ sagt. Auch bei der Integration von Objektspeicher in einen vorhandenen Dienst verwenden.
