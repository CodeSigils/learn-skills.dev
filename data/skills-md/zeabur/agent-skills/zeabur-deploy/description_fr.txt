À utiliser lors du déploiement d'un projet local ou d'une base de code sur Zeabur. À utiliser lorsque l'utilisateur dit « déployer ceci », « déployer sur Zeabur », « déployer depuis GitHub », « rechercher dans mes dépôts » ou « trouver mon référentiel ». Par défaut, le déploiement est direct, sauf si l'utilisateur demande explicitement un déploiement basé sur Git.
