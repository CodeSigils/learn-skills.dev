Úselo al implementar un proyecto local o una base de código en Zeabur. Úselo cuando el usuario diga "implementar esto", "implementar en Zeabur", "implementar desde GitHub", "buscar en mis repositorios" o "encontrar mi repositorio". El valor predeterminado es la implementación directa a menos que el usuario solicite explícitamente una implementación basada en Git.
