Verwenden Sie diese Option, wenn Sie ein lokales Projekt oder eine Codebasis in Zeabur bereitstellen. Wird verwendet, wenn der Benutzer sagt: „Bereitstellen“, „Auf Zeabur bereitstellen“, „Von GitHub bereitstellen“, „Meine Repos durchsuchen“ oder „Mein Repository finden“. Standardmäßig wird die direkte Bereitstellung verwendet, es sei denn, der Benutzer fordert ausdrücklich eine Git-basierte Bereitstellung an.
