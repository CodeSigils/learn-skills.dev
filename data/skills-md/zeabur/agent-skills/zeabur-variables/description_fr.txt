À utiliser pour TOUTES les opérations de variables d'environnement Zeabur : créer, répertorier, mettre à jour, supprimer ou dépanner. À utiliser lorsque l'utilisateur dit "définir la variable d'environnement", "ajouter une variable", "créer une variable", "mettre à jour la variable", "supprimer la variable", "changer la variable d'environnement" ou "pourquoi ma variable est-elle vide". À utiliser également lorsque les variables sont vides ou lors d'erreurs SERVICE_NOT_FOUND.
