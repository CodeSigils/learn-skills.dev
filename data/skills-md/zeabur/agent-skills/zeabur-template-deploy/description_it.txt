Da utilizzare durante la distribuzione di modelli Zeabur o servizi/database comuni tramite CLI. Da utilizzare quando l'utente dice "distribuisci modello", "installa modello" o chiede di distribuire qualsiasi servizio, database o app self-hosted nota. I trigger comuni includono MongoDB, PostgreSQL, MySQL, Redis, MinIO, SurrealDB, PocketBase, WordPress, Ghost, Halo, n8n, Logto, Umami, Uptime Kuma, Vaultwarden, Prometheus, RSSHub, Miniflux, TTRSS, Memos, AFFiNE, Linkding, Slash, Bytebase, SQL Chat, ApiCat, OpenClaw e qualsiasi altro servizio open source che l'utente desidera distribuire su Zeabur.
