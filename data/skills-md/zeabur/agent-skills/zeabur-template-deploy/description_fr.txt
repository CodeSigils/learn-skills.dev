À utiliser lors du déploiement de modèles Zeabur ou de services/bases de données communs via CLI. À utiliser lorsque l'utilisateur dit « déployer un modèle », « installer un modèle » ou demande de déployer un service, une base de données ou une application auto-hébergée bien connu. Les déclencheurs courants incluent MongoDB, PostgreSQL, MySQL, Redis, MinIO, SurrealDB, PocketBase, WordPress, Ghost, Halo, n8n, Logto, Umami, Uptime Kuma, Vaultwarden, Prometheus, RSSHub, Miniflux, TTRSS, Memos, AFFiNE, Linkding, Slash, Bytebase, SQL Chat, ApiCat, OpenClaw et tout autre service open source sur lequel l'utilisateur souhaite déployer.
