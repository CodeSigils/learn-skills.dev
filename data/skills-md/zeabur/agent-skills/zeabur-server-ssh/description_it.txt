Da utilizzare durante il debug dei servizi sul server dedicato di un utente tramite SSH. Da utilizzare quando è necessario ispezionare i pod, controllare i log del contenitore, visualizzare le risorse k8s o eseguire comandi kubectl sul server. Da utilizzare quando "service exec" non è sufficiente ed è necessario l'accesso a livello di server. Da utilizzare quando l'utente dice "controlla il mio server", "debug pod", "kubectl", "SSH nel server", "controlla k8s" o "ispeziona il cluster".
