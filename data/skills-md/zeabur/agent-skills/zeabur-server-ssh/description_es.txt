Úselo al depurar servicios en el servidor dedicado de un usuario a través de SSH. Úselo cuando necesite inspeccionar pods, verificar registros de contenedores, ver recursos de k8s o ejecutar comandos kubectl en el servidor. Úselo cuando "service exec" sea insuficiente y necesite acceso a nivel de servidor. Úselo cuando el usuario diga "verificar mi servidor", "pod de depuración", "kubectl", "SSH en el servidor", "verificar k8s" o "inspeccionar el clúster".
