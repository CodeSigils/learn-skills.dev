Wird zum Debuggen von Diensten auf dem dedizierten Server eines Benutzers über SSH verwendet. Verwenden Sie diese Option, wenn Sie Pods inspizieren, Containerprotokolle überprüfen, k8s-Ressourcen anzeigen oder kubectl-Befehle auf dem Server ausführen müssen. Verwenden Sie diese Option, wenn „service exec“ nicht ausreicht und Sie Zugriff auf Serverebene benötigen. Wird verwendet, wenn der Benutzer „Meinen Server prüfen“, „Pod debuggen“, „kubectl“, „SSH in Server“, „k8s prüfen“ oder „Cluster prüfen“ sagt.
