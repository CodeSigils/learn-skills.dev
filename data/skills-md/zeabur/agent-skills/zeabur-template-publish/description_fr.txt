À utiliser lors de la publication ou de la mise à jour d'un modèle Zeabur sur la place de marché. À utiliser lorsque l'utilisateur dit « publier le modèle », « mettre à jour le modèle en ligne », « envoyer le modèle vers Zeabur » ou « créer un modèle sur Zeabur ». Ne PAS utiliser pour déployer des modèles (utilisez plutôt zeabur-template-deploy). Ne PAS utiliser pour éditer le modèle YAML (utilisez plutôt zeabur-template).
