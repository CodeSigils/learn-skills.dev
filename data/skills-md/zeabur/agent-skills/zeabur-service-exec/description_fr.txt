À utiliser lors de l'exécution de commandes dans un conteneur de service Zeabur. À utiliser pour des opérations de base de données ponctuelles telles que des requêtes, le nettoyage de données ou des migrations (par exemple mongosh, psql, mysql, redis-cli). À utiliser lorsque l'utilisateur dit "exécuter dans le conteneur", "exécuter la commande dans le service", "interroger la base de données", "supprimer de la base de données", "exécuter la commande mongo", "exécuter SQL", "vérifier les fichiers dans le conteneur", "déboguer dans le service" ou "shell en service". À utiliser pour le débogage au niveau du conteneur, comme la vérification des variables d'environnement, des fichiers, des processus ou de la connectivité. PAS pour le déploiement de bases de données (utilisez plutôt zeabur-template-deploy).
