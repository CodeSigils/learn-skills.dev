Используйте при запуске команд внутри сервисного контейнера Zeabur. Используйте для одноразовых операций с базой данных, таких как запросы, очистка данных или миграция (например, mongosh, psql, mysql, redis-cli). Используйте, когда пользователь говорит «выполнить команду в контейнере», «запустить команду в службе», «запросить базу данных», «удалить из базы данных», «запустить команду mongo», «запустить SQL», «проверить файлы в контейнере», «отладить внутри службы» или «оболочку в службу». Используйте для отладки на уровне контейнера, например проверки переменных среды, файлов, процессов или подключения. НЕ для развертывания баз данных (вместо этого используйте zeabur-template-deploy).
