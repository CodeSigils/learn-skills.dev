Úselo cuando ejecute comandos dentro de un contenedor de servicios Zeabur. Úselo para operaciones únicas de bases de datos como consultas, limpieza de datos o migraciones (por ejemplo, mongosh, psql, mysql, redis-cli). Úselo cuando el usuario diga "ejecutar en el contenedor", "ejecutar comando en el servicio", "consultar base de datos", "eliminar de la base de datos", "ejecutar comando mongo", "ejecutar SQL", "verificar archivos en el contenedor", "depurar dentro del servicio" o "shell en el servicio". Úselo para la depuración a nivel de contenedor, como verificar variables de entorno, archivos, procesos o conectividad. NO para implementar bases de datos (use zeabur-template-deploy en su lugar).
