يُستخدم عند تشغيل الأوامر داخل حاوية خدمة Zeabur. يُستخدم لعمليات قاعدة البيانات لمرة واحدة مثل الاستعلامات أو تنظيف البيانات أو عمليات الترحيل (مثل mongosh أو psql أو mysql أو redis-cli). يُستخدم عندما يقول المستخدم "exec into Container"، أو "تشغيل الأمر في الخدمة"، أو "قاعدة بيانات الاستعلام"، أو "الحذف من قاعدة البيانات"، أو "تشغيل أمر mongo"، أو "تشغيل SQL"، أو "التحقق من الملفات في الحاوية"، أو "تصحيح الأخطاء داخل الخدمة"، أو "Shell into Service". يُستخدم لتصحيح الأخطاء على مستوى الحاوية مثل التحقق من vars أو الملفات أو العمليات أو الاتصال. ليس لنشر قواعد البيانات (استخدم zeabur-template-deploy بدلاً من ذلك).
