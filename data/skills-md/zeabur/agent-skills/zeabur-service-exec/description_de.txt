Wird verwendet, wenn Befehle in einem Zeabur-Dienstcontainer ausgeführt werden. Verwendung für einmalige Datenbankvorgänge wie Abfragen, Datenbereinigung oder Migrationen (z. B. Mongosh, PSQL, MySQL, Redis-CLI). Wird verwendet, wenn der Benutzer sagt: „Exec in Container“, „Befehl im Dienst ausführen“, „Datenbank abfragen“, „Aus Datenbank löschen“, „Mongo-Befehl ausführen“, „SQL ausführen“, „Dateien im Container prüfen“, „Fehler im Dienst beheben“ oder „Shell in Dienst ausführen“. Wird zum Debuggen auf Containerebene verwendet, z. B. zum Überprüfen von Umgebungsvariablen, Dateien, Prozessen oder Konnektivität. NICHT zum Bereitstellen von Datenbanken (verwenden Sie stattdessen zeabur-template-deploy).
