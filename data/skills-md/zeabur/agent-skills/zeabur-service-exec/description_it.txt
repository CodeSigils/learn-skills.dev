Da utilizzare quando si eseguono comandi all'interno di un contenitore di servizi Zeabur. Utilizzare per operazioni di database una tantum come query, pulizia dei dati o migrazioni (ad esempio mongosh, psql, mysql, redis-cli). Da utilizzare quando l'utente dice "esegui comando nel contenitore", "esegui comando nel servizio", "interroga il database", "elimina dal database", "esegui comando mongo", "esegui SQL", "controlla i file nel contenitore", "debug nel servizio" o "shell nel servizio". Utilizzare per il debug a livello di contenitore come il controllo di variabili di ambiente, file, processi o connettività. NON per la distribuzione di database (usa invece zeabur-template-deploy).
