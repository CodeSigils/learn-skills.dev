À utiliser lors de la liste des serveurs dédiés. À utiliser pour vérifier l'état du serveur, l'adresse IP ou les informations du fournisseur. À utiliser lorsque l'utilisateur dit « afficher mes serveurs », « SSH sur le serveur » ou « vérifier l'état du serveur ». Ne PAS utiliser pour parcourir les serveurs achetables (utilisez plutôt zeabur-server-catalog).
