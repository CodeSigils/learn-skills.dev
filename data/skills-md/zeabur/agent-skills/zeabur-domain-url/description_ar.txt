يُستخدم عندما تحتاج الخدمات إلى عنوان URL عام لعمليات إعادة التوجيه أو CORS. يُستخدم عندما يكون لدى WEB_URL أو ما شابه مشكلات شرطة مائلة زائدة. يُستخدم عندما يبلغ المستخدم عن أن "إعادة التوجيه تنتقل إلى عنوان URL خاطئ"، أو "خطأ CORS"، أو "مشكلة شرطة مائلة لاحقة". استخدمه أيضًا عندما يقول المستخدم "إضافة مجال" أو "إعداد مجال" أو "ربط المجال" أو "إنشاء مجال" أو "إدارة النطاقات" لخدمة Zeabur.
