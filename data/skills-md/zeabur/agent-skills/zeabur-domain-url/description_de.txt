Verwenden Sie diese Option, wenn Dienste eine öffentliche URL für Weiterleitungen oder CORS benötigen. Verwenden Sie diese Option, wenn WEB_URL oder ähnliches Probleme mit abschließenden Schrägstrichen hat. Wird verwendet, wenn der Benutzer „Weiterleitung führt zu falscher URL“, „CORS-Fehler“ oder „Problem mit abschließendem Schrägstrich“ meldet. Wird auch verwendet, wenn der Benutzer für einen Zeabur-Dienst „Domäne hinzufügen“, „Domäne einrichten“, „Domäne binden“, „Domäne erstellen“ oder „Domänen verwalten“ sagt.
