À utiliser lors du déploiement d'une base de données sur Zeabur. À utiliser lorsque l'utilisateur a besoin de MySQL, PostgreSQL, MongoDB ou Redis. À utiliser lorsque l'utilisateur dit « J'ai besoin d'une base de données », « ajouter une base de données », « déployer Postgres », « configurer MySQL », « ajouter Redis », « ajouter MongoDB » ou « se connecter à la base de données ». À utiliser également lorsque l'utilisateur mentionne des problèmes de persistance des données tels que "données perdues après le redémarrage", "données non enregistrées", "les données disparaissent", "besoin d'un stockage persistant pour les données" ou "comment conserver les données". À utiliser également lors de l'intégration d'une base de données avec un service existant.
