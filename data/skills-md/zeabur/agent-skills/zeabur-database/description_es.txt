Úselo al implementar una base de datos en Zeabur. Úselo cuando el usuario necesite MySQL, PostgreSQL, MongoDB o Redis. Úselo cuando el usuario diga "Necesito una base de datos", "agregar base de datos", "implementar postgres", "configurar MySQL", "agregar Redis", "agregar MongoDB" o "conectarse a la base de datos". Úselo también cuando el usuario mencione problemas de persistencia de datos como "datos perdidos después del reinicio", "datos no guardados", "datos desaparecen", "necesita almacenamiento persistente para los datos" o "cómo conservar los datos". Utilícelo también al integrar una base de datos con un servicio existente.
