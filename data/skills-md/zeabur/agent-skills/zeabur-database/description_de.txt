Verwenden Sie diese Option, wenn Sie eine Datenbank in Zeabur bereitstellen. Verwenden Sie diese Option, wenn der Benutzer MySQL, PostgreSQL, MongoDB oder Redis benötigt. Wird verwendet, wenn der Benutzer sagt: „Ich benötige eine Datenbank“, „Datenbank hinzufügen“, „Postgres bereitstellen“, „MySQL einrichten“, „Redis hinzufügen“, „MongoDB hinzufügen“ oder „Mit Datenbank verbinden“. Verwenden Sie diese Option auch, wenn der Benutzer Probleme mit der Datenpersistenz wie „Daten gehen nach Neustart verloren“, „Daten nicht gespeichert“, „Daten verschwinden“, „Persistenter Speicher für Daten ist erforderlich“ oder „Wie werden Daten beibehalten“ erwähnt. Auch bei der Integration einer Datenbank in einen vorhandenen Dienst verwenden.
