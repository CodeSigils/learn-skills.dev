Используйте при развертывании базы данных в Zeabur. Используйте, когда пользователю нужен MySQL, PostgreSQL, MongoDB или Redis. Используйте, когда пользователь говорит: «Мне нужна база данных», «добавить базу данных», «развернуть postgres», «настроить MySQL», «добавить Redis», «добавить MongoDB» или «подключиться к базе данных». Также используйте, когда пользователь упоминает проблемы с сохранением данных, такие как «данные потеряны после перезапуска», «данные не сохранены», «данные исчезают», «необходимо постоянное хранилище для данных» или «как сохранить данные». Также используйте при интеграции базы данных с существующей службой.
