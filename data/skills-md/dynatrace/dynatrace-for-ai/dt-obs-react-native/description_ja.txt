Dynatrace React Native プラグインを React Native または Expo プロジェクトに統合します (依存関係のセットアップ、dynatrace.config.js、Babel 登録、npx インストルメンテーション、ナビゲーション トラッキング、ユーザー プライバシー オプション、および検証)。ベア React Native と Expo (babel-preset-expo) Babel 構成の両方を自動的に処理します。トリガー: 「Dynatrace を React Native に追加」、「React Native プラグインのセットアップ」、「インストゥルメント React Native アプリ」、「Dynatrace RN の統合」、「モバイル可観測性 React Native」、「react-native-plugin」、「dynatrace 反応ネイティブ」、「Dynatrace を Expo に追加」、「インストゥルメント Expo アプリ」、「Dynatrace Expo セットアップ」。 RN RUM データのクエリ (dt-obs-frontends を使用)、非 React Native モバイル セットアップ、または Dynatrace サーバー側設定には使用しないでください。
