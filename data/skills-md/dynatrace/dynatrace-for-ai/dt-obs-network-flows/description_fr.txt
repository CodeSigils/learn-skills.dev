Analyse des flux réseau dans Dynatrace sur trois sources : flux OneAgent (connexions hôte/processus/pod-to-peer dans le bucket Grail `default_network_flows`), NetFlow/IPFIX/sFlow (via un collecteur OpenTelemetry) et journaux de flux cloud (AWS VPC / Transit Gateway ; Azure et GCP prévus). Utilisez-le pour analyser le trafic entre les entités, trouver les principaux interlocuteurs par bande passante, cartographier les dépendances de communication, étudier l'état de la connexion (réinitialisations, délais d'attente, retransmissions, RTT) et résoudre les homologues en entités surveillées. Achemine chaque question vers la bonne source ; Le DQL spécifique à la source réside dans les fichiers de référence. Déclencheur : "flux réseau", "top talkers", "trafic entre hôtes", "réinitialisations de connexion", "retransmissions TCP", "RTT", "connexions de pods", "dépendances réseau", "NetFlow", "IPFIX", "sFlow", "journaux de flux VPC", "trafic réseau cloud". Ne PAS utiliser pour le débit de la carte réseau hôte ou les pertes de paquets (utilisez dt-obs-hosts), le taux de demande de service ou la latence (utilisez dt-obs-services) ou la surveillance synthétique/de disponibilité (utilisez dt-obs-ext-monitors).
