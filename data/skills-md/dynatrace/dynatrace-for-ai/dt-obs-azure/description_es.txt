Recursos de nube de Azure que incluyen máquinas virtuales, VMSS, base de datos SQL, almacenamiento, AKS, App Service, funciones, redes VNet, balanceadores de carga, Event Hubs, aplicaciones de contenedor y Key Vault. Supervise la infraestructura de Azure, analice el uso de recursos, audite la postura de seguridad y administre la jerarquía organizativa entre suscripciones y grupos de recursos.
