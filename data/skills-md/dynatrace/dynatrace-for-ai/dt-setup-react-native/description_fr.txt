Intégrez le plugin Dynatrace React Native dans un projet React Native ou Expo : configuration des dépendances, dynatrace.config.js, enregistrement Babel, instrumentation npx, suivi de la navigation, options de confidentialité des utilisateurs et vérification. Gère automatiquement la configuration Babel nue de React Native et Expo (babel-preset-expo). Déclencheur : "ajouter Dynatrace à React Native", "configuration du plugin React Native", "application instrument React Native", "intégrer Dynatrace RN", "observabilité mobile React Native", "react-native-plugin", "dynatrace react native", "ajouter Dynatrace à Expo", "application instrument Expo", "configuration Dynatrace Expo". Ne PAS utiliser pour : interroger les données RN RUM (utilisez dt-obs-frontends), les configurations mobiles non React Native ou la configuration côté serveur Dynatrace.
