Интегрируйте плагин Dynatrace React Native в проект React Native или Expo — настройка зависимостей, dynatrace.config.js, регистрация Babel, инструментарий npx, отслеживание навигации, параметры конфиденциальности пользователя и проверка. Автоматически обрабатывает как пустую конфигурацию React Native, так и Expo (babel-preset-expo) Babel. Триггер: «добавить Dynatrace в React Native», «Настройка плагина React Native», «приложение React Native для инструментов», «интегрировать Dynatrace RN», «React Native для мобильной наблюдения», «react-native-plugin», «dynatrace React Native», «добавить Dynatrace в Expo», «приложение для инструментов Expo», «Настройка Dynatrace Expo». НЕ используйте для: запроса данных RN RUM (используйте dt-obs-frontend), мобильных настроек, отличных от React Native, или конфигурации Dynatrace на стороне сервера.
