Предлагайте и проверяйте сопоставления семантического словаря (SD) для новых интеграций безопасности, используя образцы API поставщиков или текущие события. Используйте при: сопоставлении данных нового поставщика средств безопасности с Dynatrace SD; проверка обязательных полей; проверка пространств имен; выделение расхождений относительно семантического словаря; предложение улучшений картографирования; выполнение проверки во время выполнения по действующим данным арендатора.
