قم بمراجعة وإصلاح البيانات التعريفية بتنسيق HTML بما في ذلك عناوين الصفحات والأوصاف التعريفية وعناوين URL الأساسية وعلامات الرسم البياني المفتوح وبطاقات Twitter والأيقونات المفضلة والبيانات المنظمة JSON-LD وتوجيهات الروبوتات. يُستخدم عند إضافة بيانات تعريف تحسين محركات البحث (SEO)، أو إصلاح معاينات المشاركة الاجتماعية، أو مراجعة علامات Open Graph، أو إعداد عناوين URL الأساسية، أو شحن صفحات جديدة تحتاج إلى علامات تعريف صحيحة.
