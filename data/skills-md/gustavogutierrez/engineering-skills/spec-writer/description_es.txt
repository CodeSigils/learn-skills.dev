Escriba, reescriba o normalice archivos de especificación estructurados `*.spec.md` para el desarrollo impulsado por agentes. Utilice esto siempre que el usuario solicite una especificación, requisitos, criterios de aceptación, documentación lista para implementar, definición de características antes de codificar, o quiera que una idea/código base existente se convierta en una especificación procesable, incluso si no dice explícitamente "especificación".
