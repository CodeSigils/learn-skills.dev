Punto de entrada principal para la creación completa de juegos de navegador Three.js, iteración premium y orquestación de fases automática. Úselo de forma predeterminada para solicitudes de creación de juegos, actualización, pulido, premium, AAA, de alta fidelidad, desde cero, de corredor sin fin, arcade, de acción, listo para lanzar o de exhibición. Para un trabajo amplio, primero cargue archivos de habilidades públicas hermanos para sistemas de juego, gráficos AAA, interfaz de usuario, depuración/perfil y control de calidad/lanzamiento. Para juegos premium con personajes, vehículos, barcos, armas, edificios, accesorios exclusivos, cielos, texturas, calcomanías, logotipos, íconos, arte GUI, necesidades de audio/SFX/voz o gráficos menos básicos, cargue threejs-3d-generator, threejs-image-generator y/o threejs-audio-generator antes de decidir que los activos generados son innecesarios. Mantenga libros de contabilidad de carga de habilidades, referencias, abastecimiento de activos y ejecución de fases para que los usuarios no elijan habilidades manualmente.
