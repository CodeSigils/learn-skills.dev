Genere y edite recursos de imágenes 2D para juegos Three.js utilizando la API de imágenes Gemini de Google. Úselo para hojas conceptuales, entradas de imagen a 3D, referencias de texturas, placas de cielo/fondo, calcomanías, logotipos, íconos, arte de GUI, arte de título/menú, miniaturas, fotografías de marketing e imágenes de origen que alimentan el generador 3D de threejs. Úselo también para la edición directa de imágenes cuando el usuario proporciona una ruta de imagen.
