Se utiliza cuando el usuario desea que la sesión de Codex CLI tenga continuidad en ejecuciones repetidas no interactivas. Lea el ID de sesión de un archivo raíz del proyecto `.codex-cli-session-id` cuando esté disponible; de lo contrario, inicie una nueva sesión de Codex, mantenga la nueva ID de sesión y luego ejecute la tarea real con `codex exec resume`. Cubre la continuidad de la sesión, `--json`, `-m` y la fijación de sesiones en el ámbito del proyecto.
