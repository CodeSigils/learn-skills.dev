يُستخدم عندما يريد المستخدم استمرارية جلسة Codex CLI عبر عمليات التشغيل غير التفاعلية المتكررة. اقرأ معرف الجلسة من ملف `.codex-cli-session-id` الخاص بجذر المشروع عندما يكون متاحًا؛ وإلا، قم بتمهيد جلسة Codex جديدة، واستمر في معرف الجلسة الجديدة، ثم قم بتشغيل المهمة الحقيقية باستخدام " استئناف Codex exec ". يغطي استمرارية الجلسة، `--json`، `-m`، وتثبيت الجلسة على نطاق المشروع.
