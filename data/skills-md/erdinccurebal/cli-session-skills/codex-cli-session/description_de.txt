Verwenden Sie diese Option, wenn der Benutzer Codex CLI-Sitzungskontinuität über wiederholte nicht interaktive Ausführungen hinweg wünscht. Lesen Sie die Sitzungs-ID aus einer Projektstammdatei „.codex-cli-session-id“, sofern verfügbar; Andernfalls starten Sie eine neue Codex-Sitzung, behalten die neue Sitzungs-ID bei und führen dann die eigentliche Aufgabe mit „codex exec resume“ aus. Behandelt Sitzungskontinuität, „--json“, „-m“ und projektbezogenes Sitzungspinning.
