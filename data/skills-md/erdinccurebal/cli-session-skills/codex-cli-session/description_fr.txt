À utiliser lorsque l'utilisateur souhaite la continuité de la session Codex CLI lors d'exécutions répétées non interactives. Lisez l'ID de session à partir d'un fichier `.codex-cli-session-id` de la racine du projet lorsqu'il est disponible ; sinon, démarrez une nouvelle session Codex, conservez le nouvel ID de session, puis exécutez la tâche réelle avec « codex exec summary ». Couvre la continuité de la session, `--json`, `-m` et l'épinglage de session à l'échelle du projet.
