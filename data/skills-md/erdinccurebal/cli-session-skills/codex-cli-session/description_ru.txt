Используйте, когда пользователь хочет обеспечить непрерывность сеанса Codex CLI при повторяющихся неинтерактивных запусках. Считайте идентификатор сеанса из корневого файла `.codex-cli-session-id`, если он доступен; в противном случае запустите новый сеанс Кодекса, сохраните новый идентификатор сеанса, а затем запустите реальную задачу с помощью `codex exec возобновить`. Охватывает непрерывность сеанса, `--json`, `-m` и закрепление сеанса на уровне проекта.
