Da utilizzare quando l'utente desidera la continuità della sessione della CLI Codex tra esecuzioni ripetute non interattive. Leggere l'ID di sessione da un file root del progetto `.codex-cli-session-id` quando disponibile; altrimenti avvia una nuova sessione Codex, mantieni il nuovo ID sessione, quindi esegui l'attività vera e propria con `codex exec curriculum`. Copre la continuità della sessione, `--json`, `-m` e il blocco della sessione nell'ambito del progetto.
