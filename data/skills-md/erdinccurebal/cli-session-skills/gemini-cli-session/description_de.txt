Verwenden Sie diese Option, wenn der Benutzer möchte, dass der primäre Agent die Gemini-CLI direkt anruft und gleichzeitig einen vorhandenen Gemini-Gesprächsverlauf beibehält. Lesen Sie die Sitzungs-ID aus einer Projektstammdatei „.gemini-cli-session-id“, sofern verfügbar; Andernfalls stellen Sie die letzte Projektsitzung aus dem lokalen Gemini-Verlauf wieder her oder erstellen Sie eine neue Sitzung und behalten Sie dann diese ID bei. Verwenden Sie standardmäßig „--approval-mode auto_edit“, damit Gemini CLI Dateien mit seinen eigenen Bearbeitungstools schreiben kann. Behandelt die Ausgabeverarbeitung „-r <session-id>“, „-p“, „-m gemini-3-flash-preview“ und „stream-json“.
