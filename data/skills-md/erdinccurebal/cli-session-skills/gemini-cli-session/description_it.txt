Da utilizzare quando l'utente desidera che l'agente principale chiami direttamente la CLI Gemini preservando una cronologia delle conversazioni Gemini esistente. Leggere l'ID di sessione da un file root del progetto `.gemini-cli-session-id` quando disponibile; altrimenti recupera l'ultima sessione del progetto dalla cronologia Gemini locale o crea una nuova sessione, quindi mantieni quell'ID. Utilizza `--approval-mode auto_edit` per impostazione predefinita in modo che Gemini CLI possa scrivere file con i propri strumenti di modifica. Copre `-r <session-id>`, `-p`, `-m gemini-3-flash-preview` e la gestione dell'output `stream-json`.
