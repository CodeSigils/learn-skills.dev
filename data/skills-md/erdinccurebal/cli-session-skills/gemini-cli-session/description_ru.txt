Используйте, когда пользователь хочет, чтобы основной агент напрямую вызывал интерфейс командной строки Gemini, сохраняя при этом существующую историю разговоров Gemini. Считайте идентификатор сеанса из корневого файла `.gemini-cli-session-id`, если он доступен; в противном случае восстановите последний сеанс проекта из локальной истории Gemini или создайте новый сеанс, а затем сохраните этот идентификатор. По умолчанию используйте `--approval-mode auto_edit`, чтобы Gemini CLI мог записывать файлы с помощью собственных инструментов редактирования. Охватывает `-r <session-id>`, `-p`, `-m Gemini-3-flash-preview` и `stream-json` обработку вывода.
