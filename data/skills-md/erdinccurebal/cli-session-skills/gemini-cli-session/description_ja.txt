ユーザーが、既存の Gemini 会話履歴を保持しながら、プライマリ エージェントに Gemini CLI を直接呼び出すことを希望する場合に使用します。利用可能な場合は、プロジェクト ルートの `.gemini-cli-session-id` ファイルからセッション ID を読み取ります。それ以外の場合は、ローカルの Gemini 履歴から最新のプロジェクト セッションを復元するか、新しいセッションを作成して、その ID を永続化します。デフォルトで「--approval-mode auto_edit」を使用すると、Gemini CLI は独自の編集ツールでファイルを書き込むことができます。 `-r <session-id>`、`-p`、`-m gemini-3-flash-preview`、および `stream-json` の出力処理について説明します。
