Úselo cuando el usuario desee que el agente principal llame a la CLI de Gemini directamente mientras conserva un historial de conversaciones de Gemini existente. Lea el ID de sesión de un archivo raíz del proyecto `.gemini-cli-session-id` cuando esté disponible; de lo contrario, recupere la última sesión del proyecto del historial local de Gemini o cree una nueva sesión y luego conserve esa ID. Utilice `--approval-mode auto_edit` de forma predeterminada para que Gemini CLI pueda escribir archivos con sus propias herramientas de edición. Cubre `-r <session-id>`, `-p`, `-m gemini-3-flash-preview` y manejo de salida `stream-json`.
