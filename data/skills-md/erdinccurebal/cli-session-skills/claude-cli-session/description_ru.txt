Используйте, когда пользователь хочет обеспечить непрерывность сеанса Claude Code при повторных запусках CLI. Считайте идентификатор сеанса из корневого файла `.claude-cli-session-id`, если он доступен; в противном случае создайте новый сеанс Claude с поддержкой UUID, сохраните этот идентификатор, а затем запустите реальную задачу через тот же закрепленный сеанс. Охватывает `--resume`, `--session-id`, `-p`, `--output-formatstream-json`, `--permission-mode AcceptEdits` и дополнительную интеграцию `ollama launch claude --model ...`.
