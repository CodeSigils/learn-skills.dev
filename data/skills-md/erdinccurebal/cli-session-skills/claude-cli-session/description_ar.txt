يُستخدم عندما يريد المستخدم استمرارية جلسة Claude Code عبر عمليات تشغيل CLI المتكررة. اقرأ معرف الجلسة من ملف جذر المشروع `.claude-cli-session-id` عندما يكون متاحًا؛ وإلا، قم بإنشاء جلسة Claude جديدة مدعومة بـ UUID، واستمر في ذلك المعرف، ثم قم بتشغيل المهمة الحقيقية خلال نفس الجلسة المثبتة. يغطي `--resume`، `--session-id`، `-p`، `--output-format Stream-json`، `--permission-mode AcceptEdits`، والتكامل الاختياري `ollama Launch claude --model ...`.
