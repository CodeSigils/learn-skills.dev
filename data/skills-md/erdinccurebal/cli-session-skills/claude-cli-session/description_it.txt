Da utilizzare quando l'utente desidera la continuità della sessione di Claude Code tra le ripetute esecuzioni della CLI. Leggere l'ID di sessione da un file root del progetto `.claude-cli-session-id` quando disponibile; in caso contrario, crea una nuova sessione Claude supportata da UUID, mantieni quell'ID e quindi esegui l'attività reale attraverso la stessa sessione bloccata. Copre l'integrazione di `--resume`, `--session-id`, `-p`, `--output-format stream-json`, `--permission-mode AcceptEdits` e l'integrazione facoltativa di `ollama launch claude --model ...`.
