Verwenden Sie diese Option, wenn der Benutzer die Kontinuität der Claude Code-Sitzung über wiederholte CLI-Ausführungen hinweg wünscht. Lesen Sie die Sitzungs-ID aus einer Projektstammdatei „.claude-cli-session-id“, sofern verfügbar. Andernfalls erstellen Sie eine neue UUID-gestützte Claude-Sitzung, behalten Sie diese ID bei und führen Sie dann die eigentliche Aufgabe über dieselbe angeheftete Sitzung aus. Behandelt die Integration von „--resume“, „--session-id“, „-p“, „--output-format stream-json“, „--permission-mode AcceptEdits“ und der optionalen Integration von „ollama launch claude --model ...“.
