À utiliser lorsque l'utilisateur souhaite la continuité de la session Claude Code lors d'exécutions CLI répétées. Lisez l'ID de session à partir d'un fichier racine du projet `.claude-cli-session-id` lorsqu'il est disponible ; sinon, créez une nouvelle session Claude basée sur l'UUID, conservez cet ID, puis exécutez la tâche réelle via la même session épinglée. Couvre `--resume`, `--session-id`, `-p`, `--output-format stream-json`, `--permission-mode acceptEdits` et l'intégration facultative `ollama launch claude --model ...`.
