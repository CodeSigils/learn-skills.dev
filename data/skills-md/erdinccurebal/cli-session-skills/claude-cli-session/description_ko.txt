사용자가 반복되는 CLI 실행에서 Claude Code 세션 연속성을 원할 때 사용합니다. 가능한 경우 프로젝트 루트 `.claude-cli-session-id` 파일에서 세션 ID를 읽습니다. 그렇지 않으면 새로운 UUID 지원 Claude 세션을 생성하고 해당 ID를 유지한 다음 동일한 고정 세션을 통해 실제 작업을 실행합니다. `--resume`, `--session-id`, `-p`, `--output-format stream-json`, `--permission-mode acceptEdits` 및 선택적인 `ollama launch claude --model ...` 통합을 다룹니다.
