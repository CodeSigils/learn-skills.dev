Úselo cuando el usuario desee que la sesión de Claude Code tenga continuidad en ejecuciones repetidas de CLI. Lea el ID de sesión de un archivo raíz del proyecto `.claude-cli-session-id` cuando esté disponible; de lo contrario, cree una nueva sesión de Claude respaldada por UUID, conserve esa ID y luego ejecute la tarea real a través de la misma sesión fijada. Cubre `--resume`, `--session-id`, `-p`, `--output-format stream-json`, `--permission-mode AcceptEdits` y la integración opcional de `ollama launch claude --model...`.
