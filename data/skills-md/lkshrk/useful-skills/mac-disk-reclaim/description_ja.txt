macOS 上の無駄な SSD スペースを発見して再利用し、その結果を説明しながら対話的に削除します。存在する場所に関係なく、肥大化をその内容によって検索します。すべてのプロジェクトに散在する build/dep ディレクトリ (node_modules、target、.venv、DerivedData)、パッケージ/ツール キャッシュ、アプリケーション サポートに埋もれた Electron アプリ キャッシュ、AI エージェント履歴 (Claude/Codex ログ)、肥大化した .git オブジェクト、マージされた Git ワークツリー、.DS_Store swarm、ボリュームごとのゴミ箱、Time Machine ローカル スナップショットなどです。検出結果が大きいものから順に探索され、ユーザーが各検出を確認した後にのみ (ゴミ箱にではなく) 直接削除されます。つまり、何が再生成され、何が永久に失われるのかをユーザーに事前に伝えます。それぞれの削除/スキップの選択を記憶しているため、再実行では新しく見つかった項目についてのみ質問されます。ユーザーがディスク/SSD スペースが少ない場合、スペースを解放する場合、Mac をクリーンアップする場合、キャッシュを削除する場合、またはビルド/依存関係の肥大化を削除する場合に使用します。
