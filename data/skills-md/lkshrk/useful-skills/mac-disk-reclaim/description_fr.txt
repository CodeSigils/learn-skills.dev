Découvrez et récupérez l'espace SSD gaspillé sur macOS, puis supprimez-le de manière interactive avec les conséquences expliquées. Trouve le gonflement par ce qu'il est, où qu'il se trouve - répertoires de build/dep (node_modules, target, .venv, DerivedData) dispersés dans chaque projet, caches de packages/outils, caches d'applications Electron enfouis sous le support d'application, historique de l'agent IA (journaux Claude/Codex), objets .git gonflés, arbres de travail git fusionnés, essaims .DS_Store, corbeille par volume, instantanés locaux Time Machine. Parcourt les résultats en premier et, seulement après que l'utilisateur a confirmé chacun d'entre eux, les supprime directement (PAS dans la corbeille) - indiquant à l'utilisateur dès le départ ce qui se régénère par rapport à ce qui a disparu pour toujours. Se souvient de chaque choix de suppression/saut, donc les réexécutions ne posent que des questions sur les éléments nouvellement trouvés. À utiliser lorsque l'utilisateur manque d'espace disque/SSD, souhaite libérer de l'espace, nettoyer un Mac, purger les caches ou supprimer la surcharge de construction/dépendance.
