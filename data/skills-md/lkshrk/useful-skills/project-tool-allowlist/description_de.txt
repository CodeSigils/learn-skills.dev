Scannen Sie den Stack und die Tools eines Repos sowie installierte Hilfstools (Paketmanager, Build-/Test-/Lint-Befehle, make, git, rtk) und generieren Sie eine projektlokale Berechtigungsliste für den aktuellen Agenten/Client, damit diese Befehle ohne Aufforderung ausgeführt werden.
