Analysez la pile et les outils d'un dépôt ainsi que les outils d'assistance installés (gestionnaires de packages, commandes build/test/lint, make, git, rtk) et générez une liste d'autorisations d'autorisation locale du projet pour l'agent/client actuel afin que ces commandes s'exécutent sans invite. À utiliser lorsque l'utilisateur souhaite moins de demandes d'autorisation, pour pré-approuver les outils de développement d'un projet ou pour configurer une configuration d'agent pour la pile d'un dépôt.
