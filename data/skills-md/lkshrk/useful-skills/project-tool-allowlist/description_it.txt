Esegui la scansione dello stack e degli strumenti di un repository, oltre agli strumenti di supporto installati (gestori di pacchetti, comandi build/test/lint, make, git, rtk) e genera una lista consentita di autorizzazioni locali del progetto per l'agente/client corrente in modo che tali comandi vengano eseguiti senza richiesta. Da utilizzare quando l'utente desidera meno richieste di autorizzazione, per preapprovare gli strumenti di sviluppo di un progetto o per impostare una configurazione dell'agente per lo stack di un repository.
