Réconciliez l'état désordonné du référentiel lié linéairement après plusieurs agents, branches, arbres de travail, validations, PR ou anciennes données de session : découvrez le travail étiqueté comme problème, comparez-le avec le contenu principal, les PR, le contenu du problème linéaire, les commentaires, les révisions, les preuves de chronologie et les preuves de session d'agent disponibles localement ; produire un plan de réconciliation; supprimer en toute sécurité uniquement le travail local fusionné et éprouvé ; intégrer le travail fini; rebaser le travail actif ; diagnostiquer les défaillances courantes des pipelines ; et mettez à jour les statuts linéaires, les étiquettes, les descriptions et les commentaires marqués pour qu'ils correspondent à la réalité vérifiée du référentiel.
