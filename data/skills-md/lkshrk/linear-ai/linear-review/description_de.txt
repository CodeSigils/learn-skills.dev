Führen Sie parallele Prüfer-Subagenten über ein Ziel-Repo oder einen Diff aus, um Erkenntnisse zu Korrektheit, Sicherheit, Wartbarkeit, Leistung, Tests, totem Code und Abhängigkeitszustand aufzudecken, deduplizieren Sie sie gegen ein persistentes Ledger und Linear und selektieren Sie dann Überlebende in Linear-Tickets. Verwenden Sie diese Option, wenn der Benutzer eine Codeüberprüfung, ein Repo-Gesundheitsaudit oder die Umwandlung von Überprüfungsergebnissen in Tickets wünscht.
