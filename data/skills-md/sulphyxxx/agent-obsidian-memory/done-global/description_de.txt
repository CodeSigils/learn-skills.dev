Verwenden Sie diesen Skill, wenn ein Benutzer „/done“ sendet oder darum bittet, eine Sitzung mit einer Übergabezusammenfassung zu beenden. Es speichert eine strukturierte Markdown-Notiz unter „~/.agent-memory/session-notes“ und aktualisiert das Projekt „SESSION_SUMMARY.md“, wenn diese Datei vorhanden ist.
