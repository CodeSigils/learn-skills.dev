قم بتحويل صفحة HTML المتوفرة أو مرجع HTML الذي تم إنشاؤه إلى مقالة مدعومة بلقطة شاشة تحتوي على مطالبات تفاعلية متعددة قابلة لإعادة الاستخدام. يُستخدم عندما يقدم المستخدم ملف HTML، أو صفحة مُصدَّرة، أو generator-page.html، أو مرجع محلي/مباشر ويطلب استخراج الرسوم المتحركة/التفاعلات، أو إنشاء مطالبات، أو التقاط لقطات شاشة لكل مطالبة، أو إضافتها إلى مقالة، أو الالتزام بالمقالة/الأصول الناتجة.
