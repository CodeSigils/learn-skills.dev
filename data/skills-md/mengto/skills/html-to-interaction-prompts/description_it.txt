Converti una pagina HTML fornita o un riferimento HTML generato in un articolo supportato da screenshot contenente più richieste di interazione riutilizzabili. Da utilizzare quando l'utente fornisce un file HTML, una pagina esportata, un file generate-page.html o un riferimento locale/live e chiede di estrarre animazioni/interazioni, creare prompt, acquisire schermate per ogni prompt, aggiungerli a un articolo o salvare l'articolo/risorse risultanti.
