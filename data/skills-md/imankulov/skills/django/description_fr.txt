Modèles de développement Django avisés pour des projets bien structurés et maintenables.
À utiliser lors de l'écriture de modèles Django, de migrations, de vues, de configuration administrateur, Celery
tâches ou des intégrations de services externes.
À utiliser également lors de la révision ou de la refactorisation du code Django ou lors de la création de nouvelles applications Django.
Ne PAS utiliser pour : les points de terminaison de l'API Django Ninja (utilisez la compétence Django-ninja), FastAPI, Flask,
Python général (utilisez la compétence Python), les fichiers de test (utilisez la compétence pytest) ou le code frontend.
