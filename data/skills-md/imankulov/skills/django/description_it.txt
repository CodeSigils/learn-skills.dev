Modelli di sviluppo Django supponenti per progetti ben strutturati e mantenibili.
Da utilizzare durante la scrittura di modelli Django, migrazioni, visualizzazioni, configurazione di amministrazione, Celery
attività o integrazioni di servizi esterni.
Da utilizzare anche durante la revisione o il refactoring del codice Django o la creazione di nuove app Django.
NON utilizzare per: endpoint API Django Ninja (utilizzare la competenza django-ninja), FastAPI, Flask,
Python generale (usa la competenza Python), file di test (usa la competenza pytest) o codice frontend.
