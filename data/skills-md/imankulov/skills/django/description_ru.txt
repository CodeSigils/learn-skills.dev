Взвешенные шаблоны разработки Django для хорошо структурированных и поддерживаемых проектов.
Используйте при написании моделей Django, миграции, представлений, конфигурации администратора, Celery.
задачи или интеграцию внешних сервисов.
Также используйте при просмотре или рефакторинге кода Django или создании новых приложений Django.
НЕ используйте для: конечных точек API Django Ninja (используйте навыки django-ninja), FastAPI, Flask,
общий Python (используйте навыки Python), тестовые файлы (используйте навыки pytest) или код внешнего интерфейса.
