أنماط تطوير Django الموضحة لمشاريع جيدة التنظيم وقابلة للصيانة.
يُستخدم عند كتابة نماذج Django، والترحيلات، وطرق العرض، وتكوين المسؤول، وCelery
المهام، أو تكامل الخدمات الخارجية.
استخدمه أيضًا عند مراجعة كود Django أو إعادة هيكلته أو إنشاء تطبيقات Django جديدة.
لا تستخدم من أجل: نقاط نهاية Django Ninja API (استخدم مهارة Django-ninja)، FastAPI، Flask،
Python العامة (استخدم مهارة python)، أو ملفات الاختبار (استخدم مهارة pytest)، أو كود الواجهة الأمامية.
