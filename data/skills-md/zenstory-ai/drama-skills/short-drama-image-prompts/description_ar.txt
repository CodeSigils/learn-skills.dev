قم بكتابة أو تحرير صورة المعكرونة المنسوخة من خلال Markdown لشخصيات الدراما القصيرة والتصميم والمواقع والدعائم والحالات. استخدمها عندما يذكر المستخدم أوراق تصميم الشخصيات، أو الرسومات ثلاثية العرض، أو الصور المرجعية، أو لوحات المشاهد، أو صور الدعامات، أو إطارات الأنماط، أو تطوير المظهر، أو متغيرات الحالة، أو مطالبات التحرير المحلية؛ لا تقم بإنشاء صور أو استدعاء أي بائع.
