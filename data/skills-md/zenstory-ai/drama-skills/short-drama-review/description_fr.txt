Passez en revue l'analyse de la source originale, l'histoire, le script, la conception visuelle, les invites d'images, les storyboards, les images clés figées, les invites vidéo et les médias existants dans un projet de court métrage. Utilisez-le lorsque l'utilisateur demande « réviser/vérifier le script », « vérifier les actifs ou la continuité », « vérifier les invites d'image/vidéo », « vérifier l'analyse originale », « réviser la sensation du modèle » ou « calibrer le projet en fonction des observations de production ». Rédigez uniquement les problèmes d'examen, les conclusions et les exigences de révision ; ne remplacez pas le propriétaire dans la modification des fichiers sources.
