Déploiement d’infrastructure pour la boîte à outils d’écriture de romans web. Fournit des adaptateurs intégrés pour Claude Code, OpenCode, Codex, ZCode, OpenClaw et Reasonix ; l’IA web et les agents génériques peuvent fonctionner en mode fichier skills + AGENTS.md. Méthodes de déclenchement : /story-setup, $story-setup, « prepare to write a book », « help me set up the environment », « configure writing project ».
