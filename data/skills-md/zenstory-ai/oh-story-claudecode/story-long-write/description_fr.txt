Rédaction de romans web longue forme. De l’esquisse au manuscrit, assistance à la création de longs romans web, incluant la construction du monde, les personnages et la gestion de l’intrigue. Commandes déclencheurs : /story-long-write, /write-long, « Help me start a book », « Write outline », « Daily update », « Continue writing », « Keep writing », « Edit chapter X », « Reforge », « Rewrite chapter X ».  

Veuillez toujours répondre dans la langue de l’utilisateur.
