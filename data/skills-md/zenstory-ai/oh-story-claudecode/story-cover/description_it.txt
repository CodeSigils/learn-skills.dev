Generazione di copertine per romanzi. Analizza automaticamente il genere e lo stile in base al titolo del libro e al nome dell'autore, quindi invoca GPT-Image-2 per creare una copertina web per romanzi di livello professionale che includa il titolo e la firma; Codex CLI usa di default l'ImageGen integrato, senza necessità di una chiave API separata. Comandi di attivazione: /story-cover, /cover, “aiutami a fare una copertina”, “genera immagine di copertina”, “crea una copertina per romanzo”, “design copertina”.

Rispondi sempre nella lingua dell'utente.
