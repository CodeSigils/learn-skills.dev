Génération de couverture de roman. Analyse automatiquement le style du genre à partir du titre du livre et du nom de l’auteur, appelle GPT-Image-2 pour générer une couverture de roman web de niveau professionnel incluant le titre et la signature de l’auteur ; le CLI Codex utilise de préférence l’ImageGen intégré, ne nécessitant aucune clé API séparée. Commandes déclenchées : /story-cover, /cover, « help me make a cover », « generate cover image », « make a novel cover », « cover design ».

Veuillez toujours répondre dans la langue de l’utilisateur.
