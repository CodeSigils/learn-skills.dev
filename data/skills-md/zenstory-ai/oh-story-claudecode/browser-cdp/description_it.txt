Usa questa funzionalità quando devi controllare un browser Chrome tramite CDP (Chrome DevTools Protocol) per riutilizzare sessioni di accesso esistenti. Copre: avviare Chrome in modalità debug, aprire URL, attendere il caricamento della pagina, valutare JavaScript, acquisire snapshot e estrarre token di autenticazione. Frasi di attivazione: automazione del browser, CDP, agente-browser, 浏览器操作, 操作浏览器, Chrome CDP, 复用登录态, estrarre token dal browser.

Per favore rispondi sempre nella lingua dell'utente.
