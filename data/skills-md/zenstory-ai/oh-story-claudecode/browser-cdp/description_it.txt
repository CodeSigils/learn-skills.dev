Usa questa competenza quando hai bisogno di controllare un browser Chrome tramite CDP (Chrome DevTools Protocol) per riutilizzare sessioni di login esistenti. Include: avviare Chrome in modalità debug, aprire URL, attendere il caricamento della pagina, valutare JavaScript, fare snapshot e estrarre token di autenticazione. Frasi di attivazione: automazione del browser, CDP, agente-browser, 浏览器操作, 操作浏览器, Chrome CDP, 复用登录态, estrarre token dal browser.

Si prega di rispondere sempre nella lingua dell'utente.
