Используйте этот навык, когда нужно управлять браузером Chrome через CDP (Chrome DevTools Protocol), чтобы повторно использовать существующие сеансы входа. Охватывает: запуск Chrome в режиме отладки, открытие URL, ожидание загрузки страницы, выполнение JavaScript, создание снимков и извлечение токенов аутентификации. Фразы‑триггеры: browser automation, CDP, agent-browser, 浏览器操作, 操作浏览器, Chrome CDP, 复用登录态, extract token from browser.
