Verwenden Sie diese Fertigkeit, wenn Sie einen Chrome-Browser über CDP (Chrome DevTools Protocol) steuern müssen, um vorhandene Anmeldesitzungen wiederzuverwenden. Umfasst: Starten von Chrome im Debug-Modus, Öffnen von URLs, Warten auf das Laden der Seite, Auswerten von JavaScript, Erstellen von Snapshots und Extrahieren von Authentifizierungstoken. Triggerphrasen: Browserautomatisierung, CDP, Agent-Browser,,浏览器操作 操作浏览器, Chrome CDP,复用登录态, Token aus Browser extrahieren.
