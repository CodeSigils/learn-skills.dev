Wird beim Erstellen einer neuen Fertigkeit, beim Normalisieren einer älteren Fertigkeit oder beim Überprüfen einer Fertigkeits-PR verwendet – definiert den Repository-weiten Hausstil (Vorwand, Entscheidungsregeln, Antimuster, Referenzen), die Ausgabeverträge, die jeder Basisfertigkeitstyp erzeugen muss, und die Eingabeverträge, die jede Spezialfertigkeit deklarieren muss. Dies ist der Durchsetzungspfeiler, der dafür sorgt, dass das Repository als System und nicht als Bibliothek verknüpfter Dokumente entsteht.
