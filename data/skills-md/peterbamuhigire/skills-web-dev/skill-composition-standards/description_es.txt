Úselo al crear una nueva habilidad, normalizar una habilidad anterior o revisar un PR de habilidad: define el estilo interno de todo el repositorio (fronteras, reglas de decisión, antipatrones, referencias), los contratos de salida que cada tipo de habilidad de referencia debe producir y los contratos de entrada que cada habilidad especializada debe declarar. Esta es la columna vertebral de cumplimiento que hace que el repositorio se componga como un sistema, no como una biblioteca de documentos vinculados.
