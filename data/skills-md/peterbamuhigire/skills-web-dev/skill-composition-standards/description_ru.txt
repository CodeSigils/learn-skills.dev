Используйте при создании нового навыка, нормализации старого навыка или проверке PR навыка — определяет стиль дома в масштабе всего репозитория (главная тема, правила принятия решений, антишаблоны, ссылки), выходные контракты, которые должен создавать каждый тип базового навыка, и входные контракты, которые должен объявить каждый специальный навык. Это механизм обеспечения соблюдения требований, благодаря которому репозиторий представляет собой систему, а не библиотеку связанных документов.
