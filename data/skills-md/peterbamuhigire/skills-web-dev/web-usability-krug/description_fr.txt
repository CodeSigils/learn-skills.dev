Principes d'utilisabilité Web et mobile de Steve Krug tirés de Don't Make Me Think (3e éd.). Chargez lors de la conception d'interfaces Web ou mobiles, de navigation, de pages d'accueil, de formulaires ou de la planification de tests d'utilisabilité. Couvre les 3 lois de Krug, le comportement de numérisation, le panneau d'affichage...
