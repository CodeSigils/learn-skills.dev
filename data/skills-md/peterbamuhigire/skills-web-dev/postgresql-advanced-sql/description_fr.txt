Modèles SQL PostgreSQL avancés provenant de « Mastering PostgreSQL » (Supabase/Manning) et « Introduction à PostgreSQL for the Data Professional ». Couvre le SQL moderne (CTE, requêtes récursives, fonctions de fenêtre), les opérateurs JSONB, les opérations sur les tableaux, la recherche en texte intégral (tsvector/tsquery, index GIN, classement), les jointures LATÉRALES et les blocs de code anonymes. Compagnon des principes fondamentaux de postgresql et des performances de postgresql.
