Расширенные шаблоны SQL PostgreSQL, взятые из книг «Освоение PostgreSQL» (Supabase/Manning) и «Введение в PostgreSQL для специалистов по данным». Охватывает современный SQL (CTE, рекурсивные запросы, оконные функции), операторы JSONB, операции с массивами, полнотекстовый поиск (tsvector/tsquery, индексы GIN, ранжирование), LATERAL объединения и анонимные блоки кода. Сопровождает основы postgresql и производительность postgresql.
