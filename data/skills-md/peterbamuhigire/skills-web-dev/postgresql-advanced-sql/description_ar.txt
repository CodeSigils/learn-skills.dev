أنماط PostgreSQL SQL المتقدمة مصدرها "إتقان PostgreSQL" (Supabase/Manning) و"مقدمة إلى PostgreSQL لمحترفي البيانات". يغطي SQL الحديثة (CTEs، والاستعلامات العودية، ووظائف النوافذ)، ومشغلي JSONB، وعمليات المصفوفة، والبحث عن النص الكامل (tsvector/tsquery، وفهارس GIN، والتصنيف)، والصلات LATERAL، وكتل التعليمات البرمجية المجهولة. مصاحب لأساسيات postgresql وأداء postgresql.
