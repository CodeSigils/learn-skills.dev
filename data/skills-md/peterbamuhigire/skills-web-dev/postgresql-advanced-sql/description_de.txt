Erweiterte PostgreSQL-SQL-Muster aus „Mastering PostgreSQL“ (Supabase/Manning) und „Introduction to PostgreSQL for the Data Professional“. Behandelt modernes SQL (CTEs, rekursive Abfragen, Fensterfunktionen), JSONB-Operatoren, Array-Operationen, Volltextsuche (tsvector/tsquery, GIN-Indizes, Ranking), LATERAL-Joins und anonyme Codeblöcke. Begleiter zu Postgresql-Fundamentals und Postgresql-Performance.
