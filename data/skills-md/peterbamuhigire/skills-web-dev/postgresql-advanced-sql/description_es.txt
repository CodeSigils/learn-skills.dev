Patrones SQL avanzados de PostgreSQL obtenidos de "Dominar PostgreSQL" (Supabase/Manning) e "Introducción a PostgreSQL para profesionales de datos". Cubre SQL moderno (CTE, consultas recursivas, funciones de ventana), operadores JSONB, operaciones de matriz, búsqueda de texto completo (tsvector/tsquery, índices GIN, clasificación), uniones LATERALES y bloques de código anónimo. Compañero de los fundamentos de postgresql y el rendimiento de postgresql.
