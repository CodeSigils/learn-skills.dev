Modelli SQL PostgreSQL avanzati provenienti da "Mastering PostgreSQL" (Supabase/Manning) e "Introduzione a PostgreSQL per professionisti dei dati". Copre SQL moderno (CTE, query ricorsive, funzioni finestra), operatori JSONB, operazioni su array, ricerca full-text (tsvettoriale/tsquery, indici GIN, classificazione), join LATERAL e blocchi di codice anonimi. Compagno di postgresql-fundamentals e postgresql-performance.
