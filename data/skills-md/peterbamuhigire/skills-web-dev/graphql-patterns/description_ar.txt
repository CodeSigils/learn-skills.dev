يُستخدم عند تصميم أو إنشاء أو تشغيل واجهات برمجة تطبيقات GraphQL مع Apollo Server + TypeScript - يغطي تصميم SDL للمخطط الأول، وبنية المحلل، وDataLoader، وJWT، والمصادقة المستندة إلى التوجيه، وترقيم صفحات مؤشر الترحيل، وحمولات الأخطاء المكتوبة، والاتحاد v2، وgraphql-codegen، وتصلب الإنتاج (حدود العمق/التعقيد، والمهلات، والاستعلامات المستمرة). قم بالاقتران مع graphql-security للدفاع عن المدخلات المعادية.
