AI/ML на устройстве для Android с использованием стека Google — ML Kit (текст, лицо, штрих-код, язык, объект), TensorFlow Lite (вывод .tflite, пользовательские модели, квантование), MediaPipe (отслеживание позы и рук), Gemini Nano через AICore, потоковая передача Claude/GPT в пользовательский интерфейс Compose, интеграция CameraX, делегаты GPU/NNAPI, профилирование батареи и тестирование.
