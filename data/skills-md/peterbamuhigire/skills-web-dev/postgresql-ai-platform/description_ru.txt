PostgreSQL как платформа данных ИИ, взято из книги «Создание платформы данных и ИИ с помощью PostgreSQL» (2025 г.). Охватывает pgvector для хранения вложений и поиска ИНС (IVFFlat/HNSW), проектирование конвейера извлечения дополненной генерации (RAG), шаблоны проектирования приложений искусственного интеллекта (LLM с учетом схемы, защитные ограждения NL2SQL, стратегии фрагментирования), 16 критических ошибок построения искусственного интеллекта, расширение pgai и принципы независимой платформы данных. Сопутствует ai-rag-patterns, postgresql-fundamentals и postgresql-advanced-sql.
