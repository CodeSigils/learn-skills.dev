Concepts de base de PostgreSQL pour les développeurs et les administrateurs de base de données provenant de MySQL ou MSSQL. Couvre les différences terminologiques (cluster/instance, rôle/utilisateur, tuple/ligne), les types de données uniques (TEXTE, TIMESTAMP AVEC TIME ZONE, ARRAY, JSONB, UUID), les outils (psql, pgAdmin, DBeaver), les rôles et privilèges (GRANT/REVOKE, HBA), les types d'objets (schémas, séquences, vues, vues matérialisées, domaines), l'écosystème d'extensions et la configuration du serveur. Associez-le à postgresql-advanced-sql, postgresql-performance, postgresql-administration pour une couverture complète.
