Conceptos básicos de PostgreSQL para desarrolladores y administradores de bases de datos provenientes de MySQL o MSSQL. Cubre diferencias terminológicas (clúster/instancia, rol/usuario, tupla/fila), tipos de datos únicos (TEXTO, MARCA DE TIEMPO CON ZONA HORARIA, ARRAY, JSONB, UUID), herramientas (psql, pgAdmin, DBeaver), roles y privilegios (GRANT/REVOKE, HBA), tipos de objetos (esquemas, secuencias, vistas, vistas materializadas, dominios), ecosistema de extensiones y configuración del servidor. Combínelo con postgresql-advanced-sql, postgresql-rendimiento y postgresql-administration para obtener una cobertura completa.
