Комплексные навыки работы с базами данных Room для Android — сущности, DAO, отношения, миграции, разрешение конфликтов, FTS4, представления, подкачка страниц, SQLCipher и тестирование. Построен на основе «Элементов комнаты Android» Марка Мерфи. Используйте вместе с android-data-persistence для полной автономной архитектуры.
