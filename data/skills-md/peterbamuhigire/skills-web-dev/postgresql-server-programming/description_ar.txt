برمجة جانب خادم PostgreSQL مصدرها "برمجة خادم PostgreSQL" (أسامة دار، Packt) و"مقدمة إلى PostgreSQL لمحترفي البيانات". يغطي وظائف وإجراءات PL/pgSQL (البنية، والمتغيرات، ومعالجة الأخطاء، والحلقات، والمؤشرات)، ووظائف التشغيل (مستوى الصف، ومستوى البيان، وشروط متى)، ومشغلات الأحداث (تدقيق DDL)، والإضافات (الإنشاء والنشر)، وأفضل الممارسات (SOA، DRY، KISS). مصاحب لأساسيات postgresql وpostgresql-advanced-sql.
