Серверное программирование PostgreSQL взято из книг «Программирование сервера PostgreSQL» (Usama Dar, Packt) и «Введение в PostgreSQL для специалистов по данным». Охватывает функции и процедуры PL/pgSQL (структура, переменные, обработка ошибок, циклы, курсоры), триггерные функции (уровень строки, уровень оператора, условия WHEN), триггеры событий (аудит DDL), расширения (создание и публикация) и лучшие практики (SOA, DRY, KISS). Сопровождает postgresql-fundamentals и postgresql-advanced-sql.
