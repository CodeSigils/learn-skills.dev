Programmazione lato server PostgreSQL proveniente da "Programmazione server PostgreSQL" (Usama Dar, Packt) e "Introduzione a PostgreSQL per professionisti dei dati". Copre funzioni e procedure PL/pgSQL (struttura, variabili, gestione degli errori, loop, cursori), funzioni di trigger (a livello di riga, a livello di istruzione, condizioni WHEN), trigger di eventi (controllo DDL), estensioni (creazione e pubblicazione) e best practice (SOA, DRY, KISS). Compagno di postgresql-fundamentals e postgresql-advanced-sql.
