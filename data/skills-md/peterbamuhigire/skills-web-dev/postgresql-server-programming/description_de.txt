Serverseitige PostgreSQL-Programmierung, bezogen auf „PostgreSQL Server Programming“ (Usama Dar, Packt) und „Introduction to PostgreSQL for the Data Professional“. Behandelt PL/pgSQL-Funktionen und -Prozeduren (Struktur, Variablen, Fehlerbehandlung, Schleifen, Cursor), Triggerfunktionen (Zeilenebene, Anweisungsebene, WHEN-Bedingungen), Ereignisauslöser (DDL-Prüfung), Erweiterungen (Erstellen und Veröffentlichen) und Best Practices (SOA, DRY, KISS). Begleiter zu Postgresql-Fundamentals und Postgresql-Advanced-SQL.
