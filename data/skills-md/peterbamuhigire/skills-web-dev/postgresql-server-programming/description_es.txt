Programación del lado del servidor PostgreSQL procedente de "Programación del servidor PostgreSQL" (Usama Dar, Packt) e "Introducción a PostgreSQL para profesionales de datos". Cubre funciones y procedimientos de PL/pgSQL (estructura, variables, manejo de errores, bucles, cursores), funciones de activación (nivel de fila, nivel de declaración, condiciones WHEN), activadores de eventos (auditoría DDL), extensiones (creación y publicación) y mejores prácticas (SOA, DRY, KISS). Compañero de postgresql-fundamentals y postgresql-advanced-sql.
