PostgreSQL サーバー側プログラミングのソースは、『PostgreSQL サーバー プログラミング』 (Usama Dar、Packt) および『データ プロフェッショナルのための PostgreSQL 入門』です。 PL/pgSQL 関数とプロシージャ (構造、変数、エラー処理、ループ、カーソル)、トリガー関数 (行レベル、ステートメント レベル、WHEN 条件)、イベント トリガー (DDL 監査)、拡張機能 (作成および公開)、およびベスト プラクティス (SOA、DRY、KISS) について説明します。 postgresql-fundamentals および postgresql-advanced-sql のコンパニオン。
