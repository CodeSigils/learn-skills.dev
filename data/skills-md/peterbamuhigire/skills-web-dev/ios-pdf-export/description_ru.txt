Встроенная система экспорта PDF для iOS с использованием UIGraphicsPDFRenderer (нулевые зависимости). Многоразовый генератор на основе чертежей с фирменными бланками, таблицами данных, сводными карточками и возможностью поделиться через UIActivityViewController. Используйте при добавлении экспорта PDF в любое приложение iOS...
