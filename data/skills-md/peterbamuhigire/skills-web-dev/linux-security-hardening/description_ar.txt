يُستخدم عند تقوية خادم Debian/Ubuntu - تقوية المستخدم/المجموعة/sudo، وتدقيقات أذونات الملفات، وسياسة كلمة مرور PAM + MFA، والتحكم الإلزامي في الوصول إلى AppArmor، وتسجيل مكالمات النظام المدقق، وتقوية kernel sysctl، ومراقبة سلامة الملفات (AIDE)، واكتشاف rootkit (rkhunter/chkrootkit)، وتصحيح الأمان غير المراقب، وأمان التمهيد GRUB + UEFI + LUKS، والامتثال لمعايير CIS.
