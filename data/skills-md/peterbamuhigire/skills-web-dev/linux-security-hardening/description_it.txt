Da utilizzare durante il rafforzamento di un server Debian/Ubuntu: rafforzamento utente/gruppo/sudo, controlli dei permessi dei file, policy password PAM + MFA, controllo degli accessi obbligatorio AppArmor, registrazione delle chiamate di sistema auditd, rafforzamento del sistema kernel, monitoraggio dell'integrità dei file (AIDE), rilevamento rootkit (rkhunter/chkrootkit), patch di sicurezza automatiche, sicurezza di avvio GRUB + UEFI + LUKS e conformità benchmark CIS.
