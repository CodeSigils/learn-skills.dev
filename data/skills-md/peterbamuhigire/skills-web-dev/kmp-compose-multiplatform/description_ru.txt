Создайте мультиплатформу для общего пользовательского интерфейса для Android, iOS, настольных компьютеров (JVM) и Интернета (wasmJs). Охватывает конфигурацию целевых объектов, общие компоновочные элементы, управление окнами рабочего стола, целевые объекты браузера WasmJs, навигацию, перехваты пользовательского интерфейса для конкретной платформы, CI/CD для многоцелевых сборок и оптимизацию производительности. Компаньон kmp-development (бизнес-логика) и android-development (пользовательский интерфейс только для Android).
