Composez Multiplatform pour une interface utilisateur partagée sur Android, iOS, Desktop (JVM) et Web (wasmJs). Couvre la configuration des cibles, les composables partagés, le fenêtrage du bureau, les cibles du navigateur wasmJs, la navigation, les hooks d'interface utilisateur spécifiques à la plate-forme, le CI/CD pour les versions multi-cibles et l'optimisation des performances. Compagnon du développement kmp (logique métier) et du développement Android (interface utilisateur Android uniquement).
