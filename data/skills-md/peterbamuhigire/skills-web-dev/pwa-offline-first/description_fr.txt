À utiliser lors de la création d'applications Web progressives hors ligne : cycle de vie de Service Worker, stratégies de mise en cache de Workbox, IndexedDB via Dexie.js, synchronisation en arrière-plan pour les écritures en file d'attente, notifications Web Push, portes Lighthouse et intégration PWA Next.js. Valeur par défaut pour les applications qui doivent fonctionner sur EDGE/2G ou sur une connectivité intermittente.
