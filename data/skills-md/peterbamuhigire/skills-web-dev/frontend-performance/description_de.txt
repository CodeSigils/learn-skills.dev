Wird beim Definieren, Implementieren oder Überwachen der Frontend-Leistung für Web-Apps und SaaS-Frontends verwendet – erstellt ein Leistungsbudget pro kritischem Fluss, einen an SLOs gebundenen Messplan und ein Regressionsgatter für CI. Behandelt Core Web Vitals (LCP, INP, CLS), Laden, Rendern und Framework-spezifische Rezepte. Nicht für Backend-Latenz, API-Form (siehe api-design-first) oder Server-SLOs (siehe Observability-Monitoring).
