يُستخدم عند تحديد أداء الواجهة الأمامية لتطبيقات الويب والواجهات الأمامية SaaS أو تنفيذه أو تدقيقه - ينتج ميزانية أداء لكل تدفق حرج، وخطة قياس مرتبطة بـ SLOs، وبوابة تراجع لـ CI. يغطي مؤشرات الويب الأساسية (LCP وINP وCLS) والتحميل والعرض والوصفات الخاصة بإطار العمل. ليس لزمن استجابة الواجهة الخلفية، أو شكل واجهة برمجة التطبيقات (راجع تصميم واجهة برمجة التطبيقات أولاً)، أو SLOs للخادم (راجع مراقبة إمكانية المراقبة).
