Úselo al definir, implementar o auditar el rendimiento del frontend para aplicaciones web y frontends SaaS: produce un presupuesto de rendimiento por flujo crítico, un plan de medición vinculado a los SLO y una puerta de regresión para la CI. Cubre Core Web Vitals (LCP, INP, CLS), carga, renderizado y recetas específicas del marco. No para latencia de backend, forma de API (consulte api-design-first) o SLO de servidor (consulte monitoreo de observabilidad).
