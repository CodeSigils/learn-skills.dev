Используйте при определении, внедрении или аудите производительности внешнего интерфейса для веб-приложений и внешнего интерфейса SaaS — создает бюджет производительности для каждого критического потока, план измерения, привязанный к SLO, и ворота регрессии для CI. Охватывает основные веб-показатели (LCP, INP, CLS), загрузку, рендеринг и рецепты, специфичные для платформы. Не для задержки серверной части, формы API (см. API-дизайн в первую очередь) или SLO сервера (см. Мониторинг наблюдаемости).
