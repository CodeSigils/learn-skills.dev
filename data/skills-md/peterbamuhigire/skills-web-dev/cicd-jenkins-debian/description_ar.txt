قم بإعداد Jenkins وتكوينه على Debian/Ubuntu - التثبيت، وأنماط Declarative Jenkinsfile، والبنيات الموزعة الرئيسية/الوكيل، ووكلاء بناء Docker، وتوصيات المكونات الإضافية، وإدارة بيانات الاعتماد، وRBAC. تم تصنيعه من خط أنابيب CI/CD باستخدام Jenkins Unleashed (Dingare)، وخط أنابيب CI/CD مع Docker وJenkins (Rawat)، وأنماط تصميم DevOps (Chintale). يُستخدم عند تثبيت Jenkins، أو كتابة Jenkinsfiles، أو تصميم نظام CI/CD مستضاف ذاتيًا على خوادم Debian/Ubuntu.
