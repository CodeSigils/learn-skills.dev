Instale y configure Jenkins en Debian/Ubuntu: instalación, patrones de archivos declarativos de Jenkins, compilaciones distribuidas maestro/agente, agentes de compilación de Docker, recomendaciones de complementos, administración de credenciales y RBAC. Sintetizado a partir de CI/CD Pipeline usando Jenkins Unleashed (Dingare), CI/CD Pipeline con Docker y Jenkins (Rawat) y DevOps Design Patterns (Chintale). Úselo al instalar Jenkins, escribir archivos Jenkins o diseñar un sistema CI/CD autohospedado en servidores Debian/Ubuntu.
