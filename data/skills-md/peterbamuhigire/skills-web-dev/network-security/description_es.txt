Úselo al diseñar, reforzar o auditar la seguridad de la capa de red para la infraestructura SaaS Debian/Ubuntu autoadministrada: firewalls (nftables/UFW), WAF (ModSecurity + OWASP CRS), VPN (WireGuard, OpenVPN, IPsec), operaciones TLS/PKI, IDS/IPS (Suricata, Fail2ban), confianza cero, refuerzo SSH, mitigación de DDoS, seguridad DNS. Complementa web-app-security-audit (capa de aplicación) y cicd-devsecops (secretos/CI).
