Verwendung beim Entwerfen, Härten oder Prüfen der Netzwerkebenensicherheit für selbstverwaltete Debian/Ubuntu-SaaS-Infrastruktur – Firewalls (nftables/UFW), WAF (ModSecurity + OWASP CRS), VPN (WireGuard, OpenVPN, IPsec), TLS/PKI-Operationen, IDS/IPS (Suricata, Fail2ban), Zero-Trust, SSH-Härtung, DDoS-Abwehr, DNS-Sicherheit. Ergänzt web-app-security-audit (App-Ebene) und cicd-devsecops (Geheimnisse/CI).
