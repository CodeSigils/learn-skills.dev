Développement de production Node.js : modèles asynchrones, flux, modèles de conception, API HTTP, tests, mise à l'échelle et déploiement. Synthétisé à partir de modèles de conception Node.js (Casciaro & Mammino 3e éd.), de recettes Node.js (Gackenheimer), de Fullstack Node.js (Murray) et des principes fondamentaux de Node.js. À utiliser lors de la création de serveurs évolutifs, d'API REST, d'outils CLI, de systèmes en temps réel ou d'applications JavaScript fullstack.
