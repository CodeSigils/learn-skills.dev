Sviluppo di Production Node.js: modelli asincroni, flussi, modelli di progettazione, API HTTP, test, scalabilità e distribuzione. Sintetizzato da Node.js Design Patterns (Casciaro & Mammino 3a ed.), Node.js Recipes (Gackenheimer), Fullstack Node.js (Murray) e Node.js Fundamentals. Da utilizzare durante la creazione di server scalabili, API REST, strumenti CLI, sistemi in tempo reale o applicazioni JavaScript full-stack.
