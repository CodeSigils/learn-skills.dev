Produktion von Node.js-Entwicklung – asynchrone Muster, Streams, Entwurfsmuster, HTTP-APIs, Tests, Skalierung und Bereitstellung. Synthetisiert aus Node.js Design Patterns (Casciaro & Mammino 3. Aufl.), Node.js Recipes (Gackenheimer), Fullstack Node.js (Murray) und Node.js Fundamentals. Verwenden Sie es beim Erstellen skalierbarer Server, REST-APIs, CLI-Tools, Echtzeitsysteme oder Full-Stack-JavaScript-Anwendungen.
