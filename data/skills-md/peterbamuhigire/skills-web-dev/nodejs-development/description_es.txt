Desarrollo de producción de Node.js: patrones asíncronos, flujos, patrones de diseño, API HTTP, pruebas, escalado e implementación. Sintetizado a partir de patrones de diseño de Node.js (Casciaro & Mammino 3.ª ed.), recetas de Node.js (Gackenheimer), Fullstack Node.js (Murray) y fundamentos de Node.js. Úselo al crear servidores escalables, API REST, herramientas CLI, sistemas en tiempo real o aplicaciones JavaScript de pila completa.
