Разработка Node.js для производства — асинхронные шаблоны, потоки, шаблоны проектирования, HTTP API, тестирование, масштабирование и развертывание. Синтезировано на основе шаблонов проектирования Node.js (Casciaro & Mammino, 3-е изд.), Node.js Recipes (Gackenheimer), Fullstack Node.js (Murray) и Node.js Fundamentals. Используйте при создании масштабируемых серверов, REST API, инструментов CLI, систем реального времени или полнофункциональных приложений JavaScript.
