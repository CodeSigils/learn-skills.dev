يُستخدم عند تصميم أنظمة برامج الإنتاج أو إنشائها أو مراجعتها أو ترقيتها والتي يجب أن تكون آمنة وفعالة وقابلة للصيانة وقابلة للتطوير ومتمحورة حول المستخدم. تقدم بطلبك قبل كتابة المواصفات أو التعليمات البرمجية أو البنية أو واجهات برمجة التطبيقات أو قواعد البيانات أو تطبيقات الهاتف المحمول أو منصات SaaS أو أنظمة تخطيط موارد المؤسسات (ERP).
