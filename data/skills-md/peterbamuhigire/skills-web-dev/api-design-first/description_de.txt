Verwendung beim Entwerfen oder Erstellen von HTTP-APIs – spezifikationsorientierter OpenAPI-Workflow, REST-Konventionen, Versionierung, Authentifizierungsmodell, Ratenbegrenzung, Idempotenzschlüssel, Fehlerumschlag und Hinweise zur Beobachtbarkeit. Erstellt den OpenAPI-Vertrag sowie Fehler-/Authentifizierungs-/Idempotenz-/Beobachtbarkeitsartefakte, die Frontend-, Mobil-, Sicherheits- und Zuverlässigkeitskenntnisse verbrauchen. Für eine Sicherheitsüberprüfung auf Endpunktebene laden Sie „vibe-security-skill“; für GraphQL-spezifische Härtungslast „graphql-security“.
