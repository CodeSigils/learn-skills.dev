Используйте при проектировании или создании HTTP API — рабочий процесс OpenAPI с учетом спецификации, соглашения REST, управление версиями, модель аутентификации, ограничение скорости, ключи идемпотентности, конверт ошибок и примечания по наблюдаемости. Создает контракт OpenAPI, а также артефакты ошибок/аутентификации/идемпотентности/наблюдаемости, которые используются навыками внешнего интерфейса, мобильных устройств, безопасности и надежности. Для проверки безопасности на уровне конечной точки загрузите `vibe-security-skill`; для усиления защиты, специфичной для GraphQL, загрузите «graphql-security».
