Da utilizzare durante la progettazione o la creazione di API HTTP: flusso di lavoro OpenAPI con specifiche specifiche, convenzioni REST, controllo delle versioni, modello di autenticazione, limitazione della velocità, chiavi di idempotenza, busta di errore e note di osservabilità. Produce il contratto OpenAPI più gli artefatti di errore/autenticazione/idempotenza/osservabilità utilizzati dalle competenze di frontend, dispositivi mobili, sicurezza e affidabilità. Per la revisione della sicurezza a livello di endpoint, caricare `vibe-security-skill`; per il carico di rafforzamento specifico di GraphQL "graphql-security".
