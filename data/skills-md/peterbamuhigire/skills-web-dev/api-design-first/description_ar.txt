يُستخدم عند تصميم أو إنشاء واجهات برمجة تطبيقات HTTP - سير عمل OpenAPI ذو المواصفات الأولى، واصطلاحات REST، والإصدارات، ونموذج المصادقة، وتحديد المعدل، ومفاتيح الاختلال، ومغلف الخطأ، وملاحظات إمكانية المراقبة. يُنتج عقد OpenAPI بالإضافة إلى عناصر الخطأ/المصادقة/الفاعلية/قابلية الملاحظة التي تستهلكها مهارات الواجهة الأمامية والجوال والأمن والموثوقية. لمراجعة الأمان على مستوى نقطة النهاية، قم بتحميل `vibe-security-skill`؛ لتحميل التصلب الخاص بـ GraphQL `graphql-security`.
