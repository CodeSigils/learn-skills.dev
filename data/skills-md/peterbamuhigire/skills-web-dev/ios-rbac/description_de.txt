Rollenbasierte Zugriffskontrolle für iOS-Apps mit Integration in ein mandantenfähiges SaaS-Backend. Deckt das Abrufen von Berechtigungen, das Zwischenspeichern von Schlüsselbunden, SwiftUI-Berechtigungs-Gates (PermissionGate, ModuleGate), modulgesteuertes TabView, Navigationsschutz, Offline-Fähigkeit usw. ab.
