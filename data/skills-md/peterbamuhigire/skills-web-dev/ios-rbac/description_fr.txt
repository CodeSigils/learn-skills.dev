Contrôle d'accès basé sur les rôles pour les applications iOS s'intégrant à un backend SaaS multi-tenant. Couvre la récupération des autorisations, la mise en cache du trousseau, les portes d'autorisation SwiftUI (PermissionGate, ModuleGate), TabView contrôlé par module, les gardes de navigation, compatibles hors ligne...
