Diseñe un programa estructurado de networking y referencias para un cliente o para la propia consultoría, que cubra eventos de networking, creación de grupos de referencias, activación de referencias y sistemas de seguimiento. Utilícelo cuando un cliente necesita generar clientes potenciales a través de relaciones en lugar de publicidad, o cuando la consultoría necesita un sistema de desarrollo empresarial para un mercado donde la confianza personal precede a las transacciones comerciales.
