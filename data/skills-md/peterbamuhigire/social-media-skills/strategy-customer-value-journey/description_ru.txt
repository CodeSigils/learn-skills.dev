Сопоставляет активность клиента в социальных сетях с 8-этапной структурой Customer Value Journey (CVJ) (DigitalMarketer/Райан Дайс). Создает структурированный контент-план, показывающий, что нужно создать на каждом этапе — «Информирование», «Вовлечение», «Подписка», «Конвертация», «Воодушевление», «Восхождение», «Защита», «Продвижение» — с руководством по платформе, призывами к действию и показателями. Вызовите, когда клиент публикует либо весь рекламный контент (без воронки осведомленности), либо весь контент для повышения осведомленности (без механизма конверсии), либо когда выстраивает новую стратегию в социальных сетях с нуля и требуется полный план воронки.
