Génère une étude de cas client soignée dans deux formats : une version écrite d'une page et un aperçu de 3 diapositives – à partir des informations brutes fournies par le consultant. À utiliser lorsqu'un consultant a besoin de documenter et de publier l'histoire de réussite d'un client pour l'utiliser dans les documents d'identification, les propositions, le site Web de l'agence ou les argumentaires.
