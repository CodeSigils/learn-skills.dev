Создает практическое учебное пособие для клиентских команд по быстрому проектированию для маркетинговых задач, охватывающее структуру подсказок Альфа-Бета-Гамма-Дельта-Эпсилон, 10 компонентов подсказок, 5 подходов к подсказкам и 7 схем копирайтинга с проработанными примерами из Восточной Африки. Вызывайте, когда пользователь говорит: «Создать учебное руководство по написанию», «Научить мою команду использовать ИИ для маркетинга», «Написать семинар по оперативному проектированию», «Обучение копирайтингу с использованием ИИ для сотрудников» или ему нужен структурированный учебный документ для сотрудников клиента, которые используют инструменты ИИ для создания маркетингового контента.
