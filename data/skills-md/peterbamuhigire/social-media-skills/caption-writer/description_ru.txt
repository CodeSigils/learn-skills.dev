Пишет подписи для социальных сетей для любой платформы из брифа. Создает 3 варианта — короткий, средний и длинный — с набором хэштегов для каждого. Вызывается, когда пользователь говорит: «Напишите подпись», «Напишите подписи для», «Мне нужна копия публикации», «Нарисуйте несколько вариантов подписи» или когда предоставляется краткое описание контента и пользователю нужен текст подписи. Также вызывайте при работе с календарем контента и копируйте сообщения, необходимые для определенных элементов.
