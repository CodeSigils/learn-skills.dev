Lea, busque, recorra, edite, valide y dibuje modelos de arquitectura ArchiMate (archivos .archimate) desde la línea de comando con el binario `amcli`. Usar cuando el usuario pregunta sobre un modelo de arquitectura empresarial, de solución o de aplicación; cuando mencionen ArchiMate, Archi, coArchi, un archivo .archimate, componentes de aplicaciones, procesos de negocio, capacidades o un repositorio de EA; o cuando un repositorio contiene un archivo *.archimate. También se utiliza para: encontrar qué servicios dependen de un componente, rastrear dependencias, evaluar el radio de explosión de un cambio, enumerar qué lee o escribe un objeto de datos, agregar o cambiar el nombre de elementos y relaciones, verificar un modelo en busca de violaciones de reglas y producir un diagrama. Prefiera esto a abrir el modelo XML directamente: estos archivos ocupan megabytes, leer uno desperdicia el contexto y editar manualmente el XML corrompe los modelos de maneras que Archi luego se niega a abrir.
