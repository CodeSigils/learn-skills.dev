Leggi, cerca, attraversa, modifica, convalida e disegna modelli di architettura ArchiMate (file .archimate) dalla riga di comando con il binario `amcli`. Utilizzare quando l'utente chiede informazioni su un modello di architettura aziendale, di soluzione o di applicazione; quando menzionano ArchiMate, Archi, coArchi, un file .archimate, componenti dell'applicazione, processi aziendali, funzionalità o un repository EA; o quando un repository contiene un file *.archimate. Utilizzare anche per: individuare quali servizi dipendono da un componente, tracciare le dipendenze, valutare il raggio d'azione di una modifica, elencare cosa legge o scrive un oggetto dati, aggiungere o rinominare elementi e relazioni, controllare un modello per violazioni di regole e produrre un diagramma. Preferisco questo rispetto all'apertura diretta del modello XML: questi file vengono eseguiti in megabyte, la lettura di un contesto spreca e la modifica manuale dell'XML corrompe i modelli in modi in cui Archi si rifiuta di aprirsi.
