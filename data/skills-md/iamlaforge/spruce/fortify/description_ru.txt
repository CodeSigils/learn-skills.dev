Разумное проектирование — примените готовность к производству к существующему интерфейсу. Создает недостающие состояния (пусто, загрузка, ошибка, успех, отключено), комплексно решает вопросы доступности (фокус, навигация с клавиатуры, ARIA, контрастность) и выявляет проблемы реагирования на поведение для отдельной работы. Строит состояния с разумной, откалиброванной по контексту копией; пользователь может запустить /voice для уточнения. Автономно выполняет структурную и интерактивную работу; поверхности архитектурных решений для утверждения. Принимает необязательные аргументы области.
