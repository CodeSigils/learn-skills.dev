Spruce design reasoning — Develop, structure, or pressure-test user personas for a product. Walks the user through producing a `.personas.md` file with one or more personas, each tagged with a confidence tier (research-grounded / context-derived / assumed) so downstream commands can weight findings appropriately. Operates in three modes — drafting from `.spruce.md` context, structuring user-supplied research notes, or pressure-testing personas the user supplies. Detects existing `.personas.md` files and offers to update or rewrite. Run as the first command in the Discovery tier; outputs feed into every downstream Spruce command that should calibrate to who the design serves.
