Razonamiento de diseño Spruce: desarrolle, estructure o pruebe las personas de usuario para un producto. Guía al usuario en la producción de un archivo `.personas.md` con una o más personas, cada una etiquetada con un nivel de confianza (basado en la investigación/derivado del contexto/asumido) para que los comandos posteriores puedan ponderar los hallazgos de manera adecuada. Funciona en tres modos: redacción a partir del contexto `.spruce.md`, estructuración de notas de investigación proporcionadas por el usuario o prueba de presión de las personas que proporciona el usuario. Detecta archivos `.personas.md` existentes y ofrece actualizarlos o reescribirlos. Ejecútelo como el primer comando en el nivel Discovery; las salidas se alimentan de cada comando posterior de Spruce que debe calibrarse para quién sirve el diseño.
