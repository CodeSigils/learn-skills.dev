Spruce design reasoning — Generate visual direction from project context. Produces a structured visual brief covering reference imagery, typography direction, color direction, texture and material language, iconography character, layout archetypes, motion character, and anti-references. Conversational by default; accepts a `--auto` flag for autonomous mode. Always produces a persistent `.sketch.md` file the user can iterate on. When the harness supports image generation, additionally produces generated reference imagery alongside the text brief.
