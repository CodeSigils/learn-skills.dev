Razonamiento de diseño Spruce: genere tres direcciones de diseño genuinamente distintas para el mismo informe. Cada variante se compromete con una estética o un enfoque fundamentalmente diferente, no con variaciones menores sobre un tema. Cada uno tiene una etiqueta breve (por ejemplo, "Editorial", "Técnico", "Cálido") para que el usuario pueda ver la dirección de un vistazo. Úselo cuando desee ver alternativas reales antes de comprometerse con una dirección, en lugar de recibir una única respuesta de /design.
