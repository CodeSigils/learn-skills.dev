Помогает пользователям MongoDB реализовать и оптимизировать решения Atlas Search (полнотекстовый), векторный поиск (семантический) и гибридный поиск. Используйте этот навык, когда пользователям необходимо создать функции поиска для текстовых запросов (автозаполнение, нечеткое сопоставление, фасетный поиск), семантического сходства (встраивания, приложения RAG) или комбинированных подходов. Также используйте, когда пользователям необходимо включение текста, сопоставление подстрок («содержит», «включает», «появляется в»), текстовый поиск без учета регистра или по нескольким полям или фильтрация по множеству полей с комбинациями переменных. Предоставляет рабочие процессы для выбора правильного типа поиска, создания индексов, построения запросов и оптимизации производительности с помощью сервера MongoDB MCP.
