يرشد مستخدمي MongoDB من خلال تنفيذ وتحسين حلول Atlas Search (النص الكامل)، وVector Search (الدلالي)، وHybrid Search. استخدم هذه المهارة عندما يحتاج المستخدمون إلى إنشاء وظيفة بحث للاستعلامات النصية (الإكمال التلقائي، أو المطابقة الغامضة، أو البحث متعدد الأوجه)، أو التشابه الدلالي (التضمينات، أو تطبيقات RAG)، أو الأساليب المدمجة. يُستخدم أيضًا عندما يحتاج المستخدمون إلى احتواء النص، أو مطابقة السلسلة الفرعية ("يحتوي على"، أو "يتضمن"، أو "يظهر في")، أو بحث نصي غير حساس لحالة الأحرف أو متعدد الحقول، أو التصفية عبر العديد من الحقول بمجموعات متغيرة. يوفر سير العمل لاختيار نوع البحث الصحيح، وإنشاء الفهارس، وإنشاء الاستعلامات، وتحسين الأداء باستخدام خادم MongoDB MCP.
