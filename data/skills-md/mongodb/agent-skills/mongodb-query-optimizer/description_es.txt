Ayuda con la optimización e indexación de consultas de MongoDB. Úselo solo cuando el usuario solicite optimización o rendimiento: "¿Cómo optimizo esta consulta?", "¿Cómo indexo esto?", "¿Por qué esta consulta es lenta?", "¿Pueden arreglar mis consultas lentas?", "¿Cuáles son las consultas lentas en mi clúster?", etc. No invoque para escribir consultas generales de MongoDB a menos que el usuario solicite ayuda con el índice o el rendimiento. Prefiere la indexación como estrategia de optimización. Utilice MongoDB MCP cuando esté disponible.
