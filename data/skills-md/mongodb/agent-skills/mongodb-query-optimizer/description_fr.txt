Aide à l'optimisation et à l'indexation des requêtes MongoDB. À utiliser uniquement lorsque l'utilisateur demande une optimisation ou des performances : "Comment puis-je optimiser cette requête ?", "Comment puis-je indexer cela ?", "Pourquoi cette requête est-elle lente ?", "Pouvez-vous corriger mes requêtes lentes ?", "Quelles sont les requêtes lentes sur mon cluster ?", etc. N'invoquez pas pour l'écriture générale de requêtes MongoDB à moins que l'utilisateur ne demande de l'aide sur les performances ou l'indexation. Préférez l’indexation comme stratégie d’optimisation. Utilisez MongoDB MCP lorsqu'il est disponible.
