Generieren Sie schreibgeschützte MongoDB-Abfragen (Suchen) oder Aggregationspipelines in natürlicher Sprache, mit Sammlungsschemakontext und Beispieldokumenten. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer MongoDB-Abfragen schreiben, erstellen oder generieren möchte, Daten in MongoDB filtern/abfragen/aggregieren möchte, fragt „Wie frage ich ab ...“, Hilfe bei der Abfragesyntax benötigt oder das Suchen/Filtern/Gruppieren von MongoDB-Dokumenten bespricht. Wird auch zum Übersetzen von SQL-ähnlichen Anforderungen in die MongoDB-Syntax verwendet. Verarbeitet NICHT Atlas-Suche ($search-Operator), Vektor-/semantische Suche ($vectorSearch-Operator), Fuzzy-Matching, Autovervollständigungsindizes oder Relevanzbewertung – verwenden Sie hierfür Search-and-AI. Analysiert oder optimiert NICHT vorhandene Abfragen – verwenden Sie dazu mongodb-query-optimizer. Verarbeitet KEINE Aggregationspipelines, die Schreibvorgänge beinhalten. Erfordert MongoDB MCP-Server.
