Genere consultas MongoDB de solo lectura (buscar) o canalizaciones de agregación utilizando lenguaje natural, con contexto de esquema de colección y documentos de muestra. Utilice esta habilidad siempre que el usuario solicite escribir, crear o generar consultas de MongoDB, quiera filtrar/consultar/agregar datos en MongoDB, pregunte "¿cómo puedo consultar...", necesite ayuda con la sintaxis de consulta o analice cómo encontrar/filtrar/agrupar documentos de MongoDB. También se utiliza para traducir solicitudes similares a SQL a la sintaxis de MongoDB. NO maneja la búsqueda Atlas ($operador de búsqueda), búsqueda vectorial/semántica ($operador vectorSearch), concordancia difusa, índices de autocompletar ni puntuación de relevancia; use search-and-ai para eso. NO analiza ni optimiza las consultas existentes; utilice mongodb-query-optimizer para eso. NO maneja canalizaciones de agregación que involucran operaciones de escritura. Requiere servidor MongoDB MCP.
