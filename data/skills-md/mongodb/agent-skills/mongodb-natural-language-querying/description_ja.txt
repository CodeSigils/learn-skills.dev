コレクション スキーマ コンテキストとサンプル ドキュメントを使用して、自然言語を使用して読み取り専用の MongoDB クエリ (検索) または集計パイプラインを生成します。ユーザーが MongoDB クエリの作成、作成、生成を要求する場合、MongoDB 内のデータのフィルター/クエリ/集計を希望する場合、「どのようにクエリを実行すれば...」と尋ねる場合、クエリ構文についてヘルプが必要な場合、または MongoDB ドキュメントの検索/フィルター/グループ化について議論する場合は、このスキルを使用してください。 SQL のようなリクエストを MongoDB 構文に変換するためにも使用します。アトラス検索 ($search 演算子)、ベクトル/セマンティック検索 ($vectorSearch 演算子)、ファジー マッチング、オートコンプリート インデックス、または関連性スコアリングは処理しません。これらには search-and-ai を使用してください。既存のクエリの分析や最適化は行いません。そのためには mongodb-query-optimizer を使用してください。書き込み操作を伴う集約パイプラインは処理しません。 MongoDB MCP サーバーが必要です。
