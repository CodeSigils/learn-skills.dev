Управляет рабочими процессами MongoDB Atlas Stream Processing (ASP). Управляет подготовкой рабочей области, соединениями источника/приемника данных, операциями жизненного цикла процессора, отладочной диагностикой и определением уровня уровня. Поддерживает интеграцию Kafka, Atlas, S3, HTTPS и Lambda для потоковой передачи рабочих нагрузок данных и обработки событий. НЕ для общих запросов MongoDB или управления кластером Atlas. Требуется сервер MongoDB MCP с учетными данными Atlas API.
