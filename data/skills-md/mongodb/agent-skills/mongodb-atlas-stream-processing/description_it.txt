Gestisce i flussi di lavoro MongoDB Atlas Stream Processing (ASP). Gestisce il provisioning dell'area di lavoro, le connessioni origine/sink dei dati, le operazioni del ciclo di vita del processore, la diagnostica di debug e il dimensionamento dei livelli. Supporta integrazioni Kafka, cluster Atlas, S3, HTTPS e Lambda per lo streaming di carichi di lavoro di dati e l'elaborazione di eventi. NON per query generali su MongoDB o per la gestione dei cluster Atlas. Richiede MongoDB MCP Server con credenziali API Atlas.
