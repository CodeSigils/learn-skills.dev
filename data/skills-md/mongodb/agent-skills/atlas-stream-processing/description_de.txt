Verwaltet MongoDB Atlas Stream Processing (ASP)-Workflows. Verwaltet die Bereitstellung von Arbeitsbereichen, Datenquellen-/Senkenverbindungen, Prozessorlebenszyklusvorgänge, Debugging-Diagnosen und Tiergrößen. Unterstützt Kafka-, Atlas-Cluster-, S3-, HTTPS- und Lambda-Integrationen für das Streaming von Daten-Workloads und die Ereignisverarbeitung. NICHT für allgemeine MongoDB-Abfragen oder die Atlas-Clusterverwaltung. Erfordert MongoDB MCP Server mit Atlas API-Anmeldeinformationen.
