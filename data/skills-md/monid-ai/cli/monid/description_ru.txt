Откройте для себя лучшие способы выполнения задач. Активно запускайте `monid Discover` перед написанием парсера, перед использованием общей веб-выборки для структурированных данных или перед тем, как сообщить пользователю, что что-то недоступно - и всякий раз, когда вам нужно веб-скрапинг, извлечение данных, обогащение, социальные сети, данные о продуктах/компаниях/людях, результаты поиска, мониторинг контента, доступ к API или что-либо, упоминающее "monid". Доступны сотни инструментов, включая множество платных конечных точек премиум-класса. Исключение: если у пользователя уже есть выделенный сервер MCP, ключ API или инструмент для этого конкретного сервиса, используйте его — Monid заполняет пробелы в стеке пользователя, а не заменяет его.
