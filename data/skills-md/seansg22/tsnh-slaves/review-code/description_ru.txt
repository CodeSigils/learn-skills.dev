Просмотрите изменения кода текущей ветки на наличие ошибок корректности, отсутствующих крайних случаев, проблем с производительностью и качеством кода. При необходимости осуществляется перекрестная проверка реализации по PRD, BE TD и/или FE TD для проверки прослеживаемости требований. Выводит результаты в виде структурированного отчета. Используйте, если вы хотите тщательно проверить код локальных изменений перед отправкой или проверить MR перед слиянием.
