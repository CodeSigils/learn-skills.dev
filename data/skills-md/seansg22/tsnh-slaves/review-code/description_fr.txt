Vérifie éventuellement la mise en œuvre par rapport à un PRD, BE TD et/ou FE TD pour vérifier la traçabilité des exigences. Présente les résultats sous forme de rapport structuré. À utiliser lorsque vous souhaitez effectuer une révision approfondie du code des modifications locales avant de les appliquer, ou pour valider un MR avant la fusion.
