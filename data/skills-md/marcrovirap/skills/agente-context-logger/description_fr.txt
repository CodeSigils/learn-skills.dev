Conservez un historique des sessions de l'agent en markdown à l'intérieur d'un tapis `logs_md_agente` à la racine du projet. Utilisé pour enregistrer à l'avance, les décisions critiques et les prochaines étapes, permettant aux futurs agents de vous aussi dans une session ultérieure de récupérer rapidement le contexte. Utilisez-le pour finaliser les tâches importantes ou pour terminer la session.
