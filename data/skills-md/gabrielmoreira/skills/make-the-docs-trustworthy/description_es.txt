Corrija, cree o elimine material escrito para que un lector posterior pueda confiar en él: documentación que ya no coincide con el sistema, un hecho a punto de escribirse por segunda vez, prosa que reafirma lo que un archivo de configuración o comando ya imprime, una carpeta de registros que se ha desviado o una decisión que vale la pena registrar para que deje de ser discutida nuevamente. La prosa que ningún ser humano ha leído cuenta como una hipótesis, no como una fuente. Úselo cuando el usuario diga "los documentos están desactualizados", "el archivo Léame todavía dice el flujo anterior", "adónde va esto", "anote esto" o "debería ser un ADR". No para juzgar documentos dentro de un cambio bajo revisión, explicar un documento existente o buscar documentación de terceros.
