Correggere, creare o rimuovere materiale scritto in modo che un lettore successivo possa fare affidamento su di esso: documentazione che non corrisponde più al sistema, un fatto che sta per essere scritto una seconda volta, prosa che ribadisce ciò che un file di configurazione o un comando ha già stampato, una cartella di record che è andata alla deriva o una decisione che vale la pena registrare in modo che smetta di essere ridiscussa. La prosa che nessun essere umano ha letto conta come un'ipotesi, non come una fonte. Da utilizzare quando l'utente dice "i documenti non sono aggiornati", "il file Readme riporta ancora il vecchio flusso", "dove va a finire", "annotalo" o "dovrebbe trattarsi di un ADR". Non per giudicare documenti all'interno di una modifica in corso di revisione, per spiegare un documento esistente o per cercare documentazione di terze parti.
