Исправьте, создайте или удалите письменный материал, чтобы будущий читатель мог на него положиться: документация, которая больше не соответствует системе, факт, который должен быть записан во второй раз, прозаическое повторение того, что уже печатает файл конфигурации или команда, папка с записями, которая переместилась, или решение, которое стоит записать, чтобы его больше не обсуждали. Проза, которую не читал ни один человек, считается гипотезой, а не источником. Используйте, когда пользователь говорит: «Документация устарела», «в файле readme все еще указан старый порядок действий», «куда это идет», «запишите это» или «должно ли это быть ADR». Не для оценки документации внутри проверяемого изменения, объяснения существующего документа или поиска сторонней документации.
