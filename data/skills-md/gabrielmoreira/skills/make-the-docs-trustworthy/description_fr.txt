Corrigez, créez ou supprimez des éléments écrits afin qu'un lecteur ultérieur puisse s'y fier : une documentation qui ne correspond plus au système, un fait sur le point d'être écrit une deuxième fois, une prose reformulant ce qu'un fichier de configuration ou une commande imprime déjà, un dossier d'enregistrement qui a dérivé ou une décision qui mérite d'être enregistrée pour qu'elle cesse d'être réargumentée. La prose qu’aucun humain n’a lue compte comme une hypothèse et non comme une source. À utiliser lorsque l'utilisateur dit « les documents sont obsolètes », « le fichier Lisez-moi indique toujours l'ancien flux », « où va cela », « écrivez ceci » ou « devrait-il s'agir d'un ADR ». Pas pour juger des documents dans une modification en cours d'examen, pour expliquer un document existant ou pour rechercher une documentation tierce.
