يُستخدم عند التصميم أو المراجعة أو إعادة البناء أو تنفيذ التعليمات البرمجية التي يجب أن تظل بسيطة وقابلة للاختبار وقابلة للقراءة ومستدامة. يغطي التحقيق والهندسة المعمارية وحدود التبعية والوحدات المتماسكة والتسمية والخطط الواضحة. يُستخدم أيضًا عندما يخفي الكود الإدخال/الإخراج أو التبعيات، أو يضيف طبقات غير ضرورية، أو يخلط بين مخاوف الأعمال والبنية التحتية، أو يجزئ تدفقًا واحدًا عبر مساعدين صغيرين.
