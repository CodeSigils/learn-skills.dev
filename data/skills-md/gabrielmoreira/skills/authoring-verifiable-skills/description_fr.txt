Écrivez, divisez, renommez ou réparez une compétence d'agent afin qu'elle s'active quand elle devrait et peut être prouvée plutôt que crue : une nouvelle compétence, une description qui ne se déclenche jamais ou qui se déclenche sur tout, une règle qui a généré deux décisions, un index qui achemine rien qu'un agent peut voir, un fichier trop dense pour être lu en un seul passage, ou une suite de vérifications que personne n'a vue échouer. Couvre la surface d'activation, la porte de routage, l'anatomie des règles, la forme de la page, la dénomination, la portabilité et les scripts d'invariant et de mutation. À utiliser lorsque l'utilisateur dit « écrire une compétence », « cette compétence ne se déclenche jamais », « diviser cette compétence », « standardiser ces compétences » ou « comment puis-je vérifier cette compétence ». Pas pour rédiger une documentation produit, ni pour décider si une tâche nécessite une compétence.
