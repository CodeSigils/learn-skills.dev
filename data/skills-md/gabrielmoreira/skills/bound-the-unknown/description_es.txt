Explore terrenos desconocidos con un presupuesto determinado y deténgase cuando aparezca la forma en lugar de cuando se acabe la paciencia. Para el estado, antes que nada es una tarea, donde aún no se puede decir si se trata de un error, una característica o nada. Úselo cuando se haya ejecutado una segunda sonda y no se haya nombrado ningún hallazgo, cuando una pregunta necesite un comando que nadie haya ejecutado todavía, cuando una lectura resulte diferente de lo que esperaba o cuando esté a punto de escribir un script para descubrir algo. Cubre el presupuesto dicho en voz alta primero, sondeo de solo lectura, dónde se guarda el intermedio, cuándo detenerse y qué deja el sondeo. Nadie necesita que le digan que mire; lo que falla es detenerse. No para un síntoma que ya tiene un nombre, un cambio que ya existe o una herramienta que no se ejecuta.
