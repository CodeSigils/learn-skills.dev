Halten Sie fest, was in einer Sitzung vereinbart wurde, damit es eine Verdichtung, einen Modellwechsel, einen Lebenslauf oder eine Übergabe übersteht: das aktuelle Ziel, die dahinter geparkten Anforderungen und jede Entscheidung mit der abgelehnten Alternative. Verwenden Sie diese Option, wenn eine Entscheidung getroffen, eine Einschränkung festgelegt, eine Genehmigung erteilt, das Ziel geändert wird oder eine zweite Anfrage eingeht, bevor die erste abgeschlossen ist. Verwenden Sie es noch einmal auf der anderen Seite, wenn Sie auf der Grundlage einer Zusammenfassung arbeiten und nicht auf der Konversation, die sie erstellt hat. Eine Entscheidung, die nur im Gespräch lebte, hat es nicht überlebt, und die, die niemand aufgeschrieben hat, ist diejenige, die im schlimmsten Moment erneut diskutiert wird. Nicht für Tatsachen mit Beweisen, die dorthin gehören, wo der Gastgeber sie bereits aufbewahrt, und nicht für dauerhafte Aufzeichnungen, die ein späterer Leser benötigt, was eine Dokumentationsentscheidung ist.
