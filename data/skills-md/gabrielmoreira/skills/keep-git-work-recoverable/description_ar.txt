حدد مكانك وما هو الآمن الذي يمكنك فعله عندما يتم رفض عملية المستودع أو تكون الحالة غير واضحة: مفتاح تم حظره بواسطة التغييرات المحلية، أو فرع تم سحبه بالفعل في مساحة عمل أخرى، أو اسم لن يتم حله، أو رأس منفصل، أو مراجع قد تكون قديمة، أو مساحات عمل قديمة يجب تنظيفها. لا يتم التخلص من أي شيء متاح ولا تتم إزالة أي شيء دون وجود دليل إيجابي على سقوطه. يُستخدم عندما يقول المستخدم "لا يمكن تبديل الفروع"، أو "هل أنا منفصل"، أو "لا يلتقط الجلب الفرع الجديد"، أو يلصق رفض git. ليس لدمج محتوى الصراع، أو إرسال الرسائل، أو الحكم على الفرق، أو الأوامر التي تعمل بالفعل.
