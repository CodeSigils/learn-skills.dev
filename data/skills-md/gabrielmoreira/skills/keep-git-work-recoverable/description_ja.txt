リポジトリ操作が拒否された場合、または状態が不明瞭な場合に、自分がどこにいるのか、安全に何をすればよいのかを確立します。ローカル変更によってスイッチがブロックされている場合、ブランチが別のワークスペースですでにチェックアウトされている場合、解決されない名前、切り離されたヘッド、古い可能性がある参照、クリーンアップすべき古いワークスペースなどです。コミットされていないものは何も破棄されず、見つかった明確な証拠がなければ何も削除されません。ユーザーが「ブランチを切り替えることができない」、「切り離されているのか」、「fetch が新しいブランチを選択していない」と言っている場合、または git 拒否を貼り付けている場合に使用します。マージ競合コンテンツ、コミットメッセージ、差分の判断、またはすでに機能しているコマンドには使用できません。
