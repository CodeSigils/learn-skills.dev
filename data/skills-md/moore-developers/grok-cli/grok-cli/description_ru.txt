Используйте этот навык всякий раз, когда пользователь хочет использовать Grok или xAI через командную строку grok-cli, включая чат, поиск X, создание/редактирование изображений, создание/редактирование/расширение видео, преобразование текста в речь, преобразование речи в текст, вход/статус OAuth или локальную статистику использования. Этот навык также следует использовать, когда сначала необходимо установить grok-cli; он запускает запрошенную пользователем команду grok-cli напрямую, когда это возможно, устраняет проблемы установки/аутентификации/разрешения только после фактического сбоя, повторяет исходную задачу после восстановления и возвращает результаты Grok/grok-cli без перезаписи на стороне помощника, если только пользователь явно не запрашивает преобразование.
