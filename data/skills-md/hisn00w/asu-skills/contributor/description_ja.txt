GitHub オープンソース貢献支援スキル：対象企業と役割に基づいてアクティブなプロジェクトを見つけ、タイプミス、README、Markdown、壊れたリンク、フォーマット改善の機会のスキャンを優先します。まず候補となる変更点と検証プランを提示し、検証を完了します。ユーザーが明示的に確認した後に、フォーク、プッシュ、プルリクエストを送信します。マージされたら、貢献グラフを /asu で使用できる履歴書用資料に変換します。ユーザーが「/contributor」と入力したとき、初めての貢献をしたいとき、小規模なオープンソースタスクを探すとき、または PR を履歴書に追加したいときに使用してください。

常にユーザーの言語で応答してください。
