Novita AI: LLM、画像生成と編集、ビデオ生成、オーディオ (TTS/ASR)、および GPU クラウド。ユーザーが Novita AI API を呼び出したいときはいつでも、このスキルを使用します。LLM とのチャット (Kimi K2.5、MiniMax M2.7、GLM-5、DeepSeek)、画像の生成 (FLUX、安定した拡散、Seedream、Hunyuan Image)、画像の編集 (背景の削除、高級化、修復、img2img、アウトペイント、再イメージ、顔の結合、背景の置換、テキストの削除)、ビデオの生成 (Kling、 Wan、Hunyuan、Minimax Hailuo、Vidu、PixVerse、Seedance)、テキスト読み上げまたは音声合成 (MiniMax TTS、GLM TTS、Fish Audio、ASR、音声クローン)、OpenAI 互換のバッチ ジョブの実行、GPU クラウド インスタンスとサーバーレス エンドポイントの管理、またはアカウント残高と請求の確認を行います。また、ユーザーが nova.ai、Novita AI、Novita API キーに言及した場合、または任意の Novita プラットフォーム サービスを使用したい場合にもトリガーされます。たとえ単に「イメージを生成する」または「LLM を実行する」と言った場合でも、Novita がプロバイダーとして利用可能です。
