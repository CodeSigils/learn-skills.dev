Novita AI: LLM، إنشاء الصور وتحريرها، إنشاء الفيديو، الصوت (TTS/ASR)، وGPU Cloud. استخدم هذه المهارة عندما يريد المستخدم الاتصال بـ Novita AI APIs - الدردشة مع LLMs (Kimi K2.5، MiniMax M2.7، GLM-5، DeepSeek)، إنشاء صور (FLUX، Stable Diffusion، Seedream، Hunyuan Image)، تحرير الصور (إزالة الخلفية، رفع المستوى، inpainting، img2img، outpainting، إعادة تصور، دمج الوجه، استبدال الخلفية، إزالة النص)، إنشاء مقاطع فيديو (Kling، Wan، Hunyuan، Minimax Hailuo، Vidu، PixVerse، Seedance)، تحويل النص إلى كلام أو تحويل الكلام إلى نص (MiniMax TTS، GLM TTS، Fish Audio، ASR، استنساخ الصوت)، تشغيل وظائف مجمعة متوافقة مع OpenAI، إدارة مثيلات GPU السحابية ونقاط النهاية بدون خادم، أو التحقق من رصيد الحساب والفوترة. يتم تشغيله أيضًا عندما يذكر المستخدم novita.ai أو Novita AI أو مفتاح Novita API أو يريد استخدام أي خدمة من منصات Novita - حتى لو قال فقط "إنشاء صورة" أو "تشغيل LLM" وكانت Novita متاحة كموفر.
