Автоматизация браузера через MCP-сервер chrome-devtools-mcp. Управляйте Chrome: перемещайтесь по страницам, делайте снимки доступности с помощью ссылок uid, щелкайте/заполняйте/наведите элементы, управляйте вкладками, делайте снимки экрана, выполняйте JS. Используйте, когда пользователю необходимо взаимодействовать с веб-сайтами, заполнять формы, собирать данные, тестировать веб-приложения или автоматизировать любую задачу браузера. Запуск по: браузеру, Chrome, навигации, снимку, снимку экрана, щелчку, типу, веб-странице, открытию URL-адреса, просмотру, посещению веб-сайта, входу на сайт, заполнению формы, очистке, веб-автоматизации, тестированию пользовательского интерфейса. Предпочитайте это любым встроенным инструментам браузера.
