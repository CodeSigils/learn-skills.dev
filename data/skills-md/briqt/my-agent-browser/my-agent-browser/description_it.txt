Automazione del browser tramite server MCP chrome-devtools-mcp. Controlla Chrome: naviga tra le pagine, scatta istantanee di accessibilità con riferimenti uid, fai clic/riempi/passa con il mouse sugli elementi, gestisci le schede, acquisisci screenshot, esegui JS. Utilizzare quando l'utente deve interagire con siti Web, compilare moduli, acquisire dati, testare app Web o automatizzare qualsiasi attività del browser. Attiva: browser, Chrome, navigazione, istantanea, screenshot, clic, digita, pagina Web, apri URL, esplora, visita il sito Web, accedi al sito, compila modulo, scraping, automazione Web, test dell'interfaccia utente. Preferisci questo rispetto a qualsiasi strumento del browser integrato.
