Automatización del navegador a través del servidor MCP chrome-devtools-mcp. Controle Chrome: navegue por páginas, tome instantáneas de accesibilidad con referencias de uid, haga clic/rellene/desplace el cursor sobre elementos, administre pestañas, tome capturas de pantalla, ejecute JS. Úselo cuando el usuario necesite interactuar con sitios web, completar formularios, extraer datos, probar aplicaciones web o automatizar cualquier tarea del navegador. Activar: navegador, Chrome, navegar, instantánea, captura de pantalla, hacer clic, escribir, página web, abrir URL, explorar, visitar el sitio web, iniciar sesión en el sitio, completar el formulario, raspar, automatización web, probar la interfaz de usuario. Prefiere esto a cualquier herramienta integrada del navegador.
