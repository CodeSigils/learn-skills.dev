Browser-Automatisierung über den MCP-Server chrome-devtools-mcp. Chrome steuern: Durch Seiten navigieren, Zugänglichkeits-Snapshots mit UID-Referenzen erstellen, Elemente anklicken/ausfüllen/bewegen, Registerkarten verwalten, Screenshots erstellen, JS ausführen. Verwenden Sie es, wenn der Benutzer mit Websites interagieren, Formulare ausfüllen, Daten durchsuchen, Web-Apps testen oder Browseraufgaben automatisieren muss. Auslösen bei: Browser, Chrome, Navigieren, Schnappschuss, Screenshot, Klicken, Tippen, Webseite, URL öffnen, Durchsuchen, Website besuchen, Anmelden auf der Website, Formular ausfüllen, Scrapen, Webautomatisierung, Benutzeroberfläche testen. Ziehen Sie dies allen integrierten Browser-Tools vor.
