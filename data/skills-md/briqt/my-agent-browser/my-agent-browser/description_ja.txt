chrome-devtools-mcp MCP サーバーを介したブラウザの自動化。 Chrome の制御: ページの移動、uid ref を使用したアクセシビリティ スナップショットの取得、要素のクリック/塗りつぶし/ホバー、タブの管理、スクリーンショットの取得、JS の実行。ユーザーが Web サイトと対話したり、フォームに入力したり、データを収集したり、Web アプリをテストしたり、ブラウザー タスクを自動化したりする必要がある場合に使用します。トリガー: ブラウザ、クロム、ナビゲート、スナップショット、スクリーンショット、クリック、入力、Web ページ、URL を開く、参照、Web サイトにアクセス、サイトにログイン、フォームへの入力、スクレイピング、Web オートメーション、UI のテスト。組み込みのブラウザ ツールよりもこれを優先します。
