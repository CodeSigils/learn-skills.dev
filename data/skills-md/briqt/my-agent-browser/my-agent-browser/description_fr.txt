Automatisation du navigateur via le serveur MCP chrome-devtools-mcp. Contrôlez Chrome : parcourez les pages, prenez des instantanés d'accessibilité avec des références UID, cliquez/remplissez/survolez des éléments, gérez les onglets, prenez des captures d'écran, exécutez JS. À utiliser lorsque l'utilisateur a besoin d'interagir avec des sites Web, de remplir des formulaires, de récupérer des données, de tester des applications Web ou d'automatiser n'importe quelle tâche du navigateur. Déclencheur sur : navigateur, chrome, navigation, instantané, capture d'écran, clic, saisie, page Web, ouverture d'URL, navigation, visite d'un site Web, connexion au site, remplissage d'un formulaire, grattage, automatisation Web, test de l'interface utilisateur. Préférez cela à tous les outils de navigateur intégrés.
