Automatisation du navigateur via le serveur MCP chrome-devtools-mcp. Contrôlez Chrome : parcourez les pages, prenez des instantanés d'accessibilité avec des références UID, cliquez/remplissez/survolez des éléments, gérez les onglets, prenez des captures d'écran, exécutez JS. À utiliser lorsque l'utilisateur a besoin d'interagir avec des sites Web, de remplir des formulaires, de récupérer des données, de tester des applications Web ou d'automatiser n'importe quelle tâche du navigateur. Déclencheur sur : navigateur, chrome, navigation, instantané, capture d'écran, clic, saisie, page Web, ouvrir une URL, parcourir, visiter un site Web, se connecter au site, remplir un formulaire, gratter, automatisation Web, tester l'interface utilisateur. Préférez cela à tous les outils de navigateur intégrés.
