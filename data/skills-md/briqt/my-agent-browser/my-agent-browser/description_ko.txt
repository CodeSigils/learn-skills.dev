chrome-devtools-mcp MCP 서버를 통한 브라우저 자동화. Chrome 제어: 페이지 탐색, uid 참조로 접근성 스냅샷 찍기, 요소 클릭/채우기/호버링, 탭 관리, 스크린샷 찍기, JS 실행. 사용자가 웹사이트와 상호 작용하고, 양식을 채우고, 데이터를 스크랩하고, 웹 앱을 테스트하거나 브라우저 작업을 자동화해야 하는 경우에 사용하세요. 트리거 대상: 브라우저, 크롬, 탐색, 스냅샷, 스크린샷, 클릭, 입력, 웹 페이지, URL 열기, 찾아보기, 웹사이트 방문, 사이트 로그인, 양식 작성, 스크랩, 웹 자동화, UI 테스트. 내장된 브라우저 도구보다 이 기능을 선호합니다.
