Interrogez l’utilisation, les coûts et la consommation de jetons de l’agent de codage IA. Prend en charge Claude Code, Codex CLI, OpenClaw, OpenCode, Kiro CLI et Pi. Renseignez-vous sur les dépenses, l'utilisation des jetons, les coûts du modèle, l'historique des sessions et le nombre d'appels API. Actions : vérifier l'utilisation, afficher le coût, comparer les modèles, répertorier les sessions, analyser les dépenses, la répartition des jetons. Plages horaires : aujourd'hui, cette semaine, ce mois-ci, cette année, les N derniers jours, les dates personnalisées.
