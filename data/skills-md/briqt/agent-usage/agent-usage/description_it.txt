Interroga l'utilizzo, i costi e il consumo di token dell'agente di codifica AI. Supporta Claude Code, Codex CLI, OpenClaw, OpenCode, Kiro CLI e Pi. Chiedi informazioni sulla spesa, sull'utilizzo dei token, sui costi dei modelli, sulla cronologia delle sessioni, sul conteggio delle chiamate API. Azioni: verifica utilizzo, mostra costo, confronta modelli, elenca sessioni, analizza spesa, suddivisione token. Intervalli di tempo: oggi, questa settimana, questo mese, quest'anno, ultimi N giorni, date personalizzate.
