Proporciona capacidad de reconocimiento de imágenes para modelos no multimodales (por ejemplo, deepseek‑v4‑pro, GLM‑5.1, mimo‑v2.5‑pro y otros modelos de texto puro). Cuando el modelo principal no puede reconocer una imagen, el usuario envía una captura de pantalla/borrador de diseño/captura de pantalla de UI que necesita análisis, o el usuario dice "mira esta imagen", "analiza esta captura de pantalla", "qué está mal con esta imagen", la habilidad se activa automáticamente. También se aplica a cualquier escenario en el que el usuario pegue una imagen pero el modelo actual no admite la entrada de imágenes. Admite el reconocimiento de múltiples imágenes simultáneamente, con respaldo primario que se logra mediante la configuración de múltiples modelos de visión. La habilidad también se puede activar manualmente usando el comando/skill:vision-support o/vision. Regla de hierro: los modelos configurados para esta habilidad se utilizan únicamente para el reconocimiento del contenido de la imagen y nunca participan en el razonamiento lógico principal. Nota: si el modelo actual en sí es un modelo multimodal (por ejemplo, Claude Sonnet4, GPT‑4o, Gemini, etc., que puede procesar imágenes directamente), no utilice esta habilidad; Deje que el modelo principal maneje la imagen directamente.
