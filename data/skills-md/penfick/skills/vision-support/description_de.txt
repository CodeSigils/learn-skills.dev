Stellen Sie Bilderkennungsfunktionen für nicht-multimodale Modelle bereit (z. B. deepseek-v4-pro, GLM-5.1, mimo-v2.5-pro und andere reine Textmodelle). Wenn das Hauptmodell ein Bild nicht erkennen kann, sendet der Benutzer einen Screenshot/Designentwurf/UI-Screenshot, der analysiert werden muss, oder der Benutzer sagt „Sehen Sie sich dieses Bild an“, „Analysieren Sie diesen Screenshot“, „Was stimmt mit diesem Bild nicht?“ Der Skill wird automatisch ausgelöst. Dies gilt auch für jedes Szenario, in dem der Benutzer ein Bild einfügt, das aktuelle Modell jedoch keine Bildeingabe unterstützt. Unterstützt die gleichzeitige Erkennung mehrerer Bilder, wobei durch die Konfiguration mehrerer Bildverarbeitungsmodelle ein primärer Backup-Fallback erreicht wird. Der Skill kann auch manuell mit dem Befehl/skill:vision-support oder/vision ausgelöst werden. Eiserne Regel: Die für diese Fähigkeit konfigurierten Modelle werden nur zur Erkennung von Bildinhalten verwendet und sind niemals an der Hauptlogik beteiligt. Hinweis: Wenn das aktuelle Modell selbst ein multimodales Modell ist (z. B. Claude Sonnet4, GPT-4o, Gemini usw., das Bilder direkt verarbeiten kann), verwenden Sie diese Fähigkeit nicht. Lassen Sie das Hauptmodell das Bild direkt verarbeiten.
