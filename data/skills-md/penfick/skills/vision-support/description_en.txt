Provide image recognition capability for non‑multimodal models (e.g., deepseek‑v4‑pro, GLM‑5.1, mimo‑v2.5‑pro, and other pure‑text models). When the main model cannot recognize an image, the user sends a screenshot/design draft/UI screenshot that needs analysis, or the user says “take a look at this picture,” “analyze this screenshot,” “what’s wrong with this image,” the skill is automatically triggered. It also applies to any scenario where the user pastes an image but the current model does not support image input. Supports recognizing multiple images simultaneously, with primary‑backup fallback achieved by configuring multiple vision models. The skill can also be manually triggered using the command /skill:vision-support or /vision. Iron rule: the models configured for this skill are used only for image content recognition and never participate in the main logical reasoning. Note: if the current model itself is a multimodal model (e.g., Claude Sonnet 4, GPT‑4o, Gemini, etc., which can directly process images), do not use this skill; let the main model handle the image directly.
