B. qa-bugs/bug-01-alta-formulario.md), analysieren Sie die Ursache, führen Sie eine Korrektur mit Regressionstests durch, validieren Sie eine Reihe von Tests und aktualisieren Sie den Status des Archivs. Verwenden Sie den Benutzer, um einen bestimmten Fehler zu beheben, der nicht in der Qualitätssicherung festgestellt wurde. Verwenden Sie diese Funktion nicht für Korrekturen – rufen Sie einen Fehler auf. Verwenden Sie es nicht zur Implementierung neuer Funktionen, zur Codeüberprüfung oder zur Ausführung der Qualitätssicherung.
