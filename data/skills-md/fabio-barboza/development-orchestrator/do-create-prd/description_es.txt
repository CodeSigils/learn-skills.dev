Crea documentos de requisitos del producto (PRD) a partir de solicitudes de funciones siguiendo un flujo de trabajo estructurado de aclaración, planificación y redacción. Envía un PRD estandarizado al directorio prds del proyecto. Úselo cuando el usuario solicite crear un PRD, definir requisitos o documentar una nueva característica. No lo utilice para especificaciones técnicas, desgloses de tareas o planificación de implementación.
