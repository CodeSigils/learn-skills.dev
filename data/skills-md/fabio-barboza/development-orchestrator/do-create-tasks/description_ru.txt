Преобразует PRD и Tech Spec в подробный, последовательный список задач внедрения. Каждая задача представляет собой функциональный, инкрементный результат со своим собственным набором тестов. Выводит Tasks.md и отдельные файлы задач. Используйте, когда пользователь просит создать задачи, разбить работу или спланировать реализацию на основе существующего PRD и технической спецификации. Не используйте для создания PRD, создания технических спецификаций или фактической реализации кода.
