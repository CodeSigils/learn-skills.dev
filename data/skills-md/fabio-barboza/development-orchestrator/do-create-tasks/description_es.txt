Convierte PRD y Tech Spec en una lista detallada y secuenciada de tareas de implementación. Cada tarea es un entregable funcional e incremental con su propio conjunto de pruebas. Genera tareas.md y archivos de tareas individuales. Úselo cuando el usuario solicite crear tareas, desglosar el trabajo o planificar la implementación de un PRD y una especificación técnica existentes. No lo utilice para la creación de PRD, la creación de especificaciones técnicas o la implementación de código real.
