Crea especificaciones técnicas a partir de PBI existentes, traduciendo los requisitos del producto en decisiones arquitectónicas y orientación de implementación. Realiza un análisis profundo de proyectos, utiliza Context7 MCP para investigación técnica y búsqueda web para reglas comerciales. Úselo cuando el usuario solicite crear una especificación técnica, definir una arquitectura o planificar la implementación de una función con un PBI existente. No lo utilice para la creación de PBI, desgloses de tareas o implementación directa de código.
