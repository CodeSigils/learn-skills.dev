Создает технические спецификации на основе существующих PBI, преобразуя требования к продукту в архитектурные решения и рекомендации по реализации. Выполняет глубокий анализ проекта, использует Context7 MCP для технических исследований и веб-поиск для поиска бизнес-правил. Используйте, когда пользователь просит создать техническую спецификацию, определить архитектуру или спланировать реализацию функции с помощью существующего PBI. Не используйте для создания PBI, разбивки задач или прямой реализации кода.
