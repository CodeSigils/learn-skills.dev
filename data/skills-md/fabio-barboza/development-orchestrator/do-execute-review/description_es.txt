Realiza una revisión integral del código analizando git diff, verificando la conformidad con las reglas del proyecto, validando conjuntos de pruebas y verificando el cumplimiento de las especificaciones técnicas y las tareas. Genera un informe de revisión de código estructurado con hallazgos clasificados por gravedad. Úselo cuando el usuario solicita una revisión del código, desea validar la calidad del código o necesita una verificación previa a la fusión. No lo utilice para pruebas de control de calidad, corrección de errores o implementación de tareas.
