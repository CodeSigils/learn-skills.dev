Esegue una revisione completa del codice analizzando git diff, verificando la conformità alle regole del progetto, convalidando le suite di test e controllando l'aderenza alle specifiche tecniche e alle attività. Genera un rapporto di revisione del codice strutturato con risultati classificati in base alla gravità. Da utilizzare quando l'utente richiede una revisione del codice, desidera convalidare la qualità del codice o necessita di una verifica prima dell'unione. Non utilizzare per test di QA, correzione di bug o implementazione di attività.
