Reciba el camino de un archivo de fix task en review-fixes/ (ej: review-fixes/fix-R01-critico-senha.md), implemente una corrección, roda un conjunto de pruebas y actualiza el estado del archivo. Utilice cuando do-execute-review obtenga archivos de tarea de reparación y el usuario quiera resolver un problema específico. No use para correções em lote: invoque una vez por archivo. No utilice para QA, corrección de errores de QA (use do-execute-qa-bugfix) o implementación de nuevas funciones.
