Erhalten Sie eine Datei zur Behebung einer Aufgabe in review-fixes/ (z. B. review-fixes/fix-R01-critico-senha.md), führen Sie eine Korrektur durch, führen Sie eine Reihe von Tests durch und aktualisieren Sie den Status der Datei. Verwenden Sie do-execute-review, um die Task-Arquivos zu reparieren und ein bestimmtes Problem zu lösen. Benutzen Sie es nicht für Korrekturen im Losverfahren – rufen Sie uns einmal für die Archivierung an. Nicht für QA verwenden, QA-Fehler beheben (do-execute-qa-bugfix verwenden) oder neue Funktionen implementieren.
