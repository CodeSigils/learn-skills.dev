Ricevi il percorso di un file di attività di correzione in review-fixes/ (es: review-fixes/fix-R01-critico-senha.md), implementa la correzione, segui la suite di test e aggiorna lo stato del file. Utilizzare quando si esegue la revisione dei file di correzione dell'attività e l'utente vuole risolvere un problema specifico. Non utilizzare per le correzioni in lotto: richiamare una volta dal file. Non utilizzare per QA, correzione di bug di QA (usa do-execute-qa-bugfix) o implementazione di nuove funzionalità.
