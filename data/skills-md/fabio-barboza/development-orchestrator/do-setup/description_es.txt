Inicializa el proyecto, identifica habilidades relevantes y actualiza el archivo de configuración del proyecto (CLAUDE.md, .github/copilot-instructions.md o equivalente) con el resumen del proyecto, las convenciones y las habilidades disponibles. Se utiliza cuando el usuario solicita inicializar el proyecto o configurar el entorno de desarrollo asistido por agente. No lo utilice para la creación de PBI, implementación de tareas, revisión de código o pruebas de control de calidad.
