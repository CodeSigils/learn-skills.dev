Crea elementos de la cartera de productos (PBI) a partir de solicitudes de funciones siguiendo un flujo de trabajo estructurado de aclaración, planificación y redacción. Genera un PBI estandarizado en el directorio pbis del proyecto. Úselo cuando el usuario solicite crear un PBI, definir requisitos o documentar una nueva característica. No lo utilice para especificaciones técnicas, desgloses de tareas o planificación de implementación.
