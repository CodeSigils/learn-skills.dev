Alibaba Cloud Bailei Platform Technical Documentation Knowledge Base (LLM Wiki). It is activated when users query Bailei‑related issues such as model lists, API parameters, error codes, application development (agents/RAG/knowledge base/memory/plugins), model comparison and pricing, SDK/OpenAI compatible interfaces, multimodal capabilities (speech/image/video), token billing, etc. It includes a structured “models” market‑data layer (with contextWindow/QPM/price/sample code), a “wiki” synthesis layer (topic pages, concept pages, comparison pages), and a “raw” original‑document layer; for model‑specification questions check models/index.md first, and for documentation questions check wiki/index.md first.
