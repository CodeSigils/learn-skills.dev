Base de connaissances sur la documentation technique de la plateforme Alibaba Cloud Bailei (Wiki LLM). Il est activé lorsque les utilisateurs interrogent des problèmes liés à Bailei tels que les listes de modèles, les paramètres d'API, les codes d'erreur, le développement d'applications (agents/RAG/base de connaissances/mémoire/plugins), la comparaison et la tarification de modèles, les interfaces compatibles SDK/OpenAI, les capacités multimodales (parole/image/vidéo), la facturation par jeton, etc. (pages thématiques, pages conceptuelles, pages de comparaison) et une couche de document original « brut » ; pour les questions de spécification de modèle, vérifiez d'abord models/index.md, et pour les questions de documentation, vérifiez d'abord wiki/index.md.
