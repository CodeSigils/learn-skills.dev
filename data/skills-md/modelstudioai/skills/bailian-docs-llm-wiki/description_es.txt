Base de conocimientos de documentación técnica de la plataforma Alibaba Cloud Bailei (LLM Wiki). Se activa cuando los usuarios consultan cuestiones relacionadas con Bailei, como listas de modelos, parámetros API, códigos de error, desarrollo de aplicaciones (agentes/RAG/base de conocimientos/memoria/complementos), comparación y precios de modelos, interfaces compatibles con SDK/OpenAI, capacidades multimodales (voz/imagen/vídeo), facturación de tokens, etc. Incluye una capa de datos de mercado de “modelos” estructurados (con ventana de contexto/QPM/precio/código de muestra), una capa de síntesis “wiki” (páginas de temas, páginas de conceptos, páginas de comparación) y una capa de documento original "sin formato"; para preguntas sobre especificaciones de modelos, consulte primero models/index.md, y para preguntas sobre documentación, consulte primero wiki/index.md.
