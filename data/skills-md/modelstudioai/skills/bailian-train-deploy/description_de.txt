Verwenden Sie die Bailei-CLI („bl“), um die vollständige Schleife „Daten → Feinabstimmungstraining → Export → Bereitstellung → Aufruf“ abzuschließen, oder überspringen Sie das Training und stellen Sie das Basismodell direkt bereit. Es umfasst die Validierung/das Hochladen von Datensätzen, das Erstellen von SFT/DPO/CPT-Feinabstimmungsaufgaben, das Warten auf das Training, das Exportieren des besten Prüfpunkts, das Erstellen der Inferenzbereitstellung, das Warten auf die Bereitschaft und die Bereitstellung von Aufrufbeispielen. Wenn der Benutzer in Bailei / DashScope / Alibaba Cloud Model Studio „ein Modell trainieren“, „Feinabstimmung“, „Feinabstimmung“, „Feinabstimmung“, „ein Modell bereitstellen“, „Modellstart“, „ein fein abgestimmtes Modell ausführen/aufrufen“, „ein Inferenzmodell trainieren“, „Vortraining fortsetzen“, „LoRA/SFT/DPO-Training“ usw. erwähnt, sollte diese Fähigkeit aktiviert werden – auch wenn der Benutzer nicht ausdrücklich „bl verwenden“ sagt, solange Ziel ist die Schulung oder der Einsatz auf der Bailei-Plattform. Nutzen Sie diese Fähigkeit und stellen Sie keine Befehle selbst zusammen.
