Verwenden Sie die Baijian-CLI („bl“), um die vollständige Schleife „Daten → Feinabstimmungstraining → Export → Bereitstellung → Aufruf“ abzuschließen, oder überspringen Sie das Training und stellen Sie das Basismodell direkt bereit. Dies umfasst die Validierung/das Hochladen von Datensätzen, das Erstellen von SFT/DPO/CPT-Feinabstimmungsaufgaben, das Warten auf das Training, das Exportieren des besten Prüfpunkts, das Erstellen einer Inferenzbereitstellung, das Warten darauf, dass sie bereit ist, und die Bereitstellung von Aufrufbeispielen. Wenn ein Benutzer das Trainieren eines Modells, die Feinabstimmung, „Feinabstimmung“, „Feinabstimmung“, das Bereitstellen eines Modells, das Starten eines Modells, das Ausführen/Aufrufen eines feinabgestimmten Modells, das Training eines Inferenzmodells, das Fortsetzen des Vortrainings, das LoRA/SFT/DPO-Training usw. auf Baijian/DashScope/Alibaba Cloud Model Studio erwähnt, sollte diese Fähigkeit aktiviert werden – auch wenn der Benutzer nicht ausdrücklich „bl verwenden“ sagt. Solange die Absicht darin besteht, auf der Baijian-Plattform zu trainieren oder einzusetzen, nutzen Sie diese Fähigkeit und stellen Sie keine Befehle selbst zusammen.
