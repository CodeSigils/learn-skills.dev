Baijian CLI(`bl`)를 사용하여 "데이터 → 미세 조정 훈련 → 내보내기 → 배포 → 호출"의 전체 루프를 완료하거나 훈련을 건너뛰고 기본 모델을 직접 배포합니다. 여기에는 데이터 세트 검증/업로드, SFT/DPO/CPT 미세 조정 작업 생성, 훈련 대기, 최상의 체크포인트 내보내기, 추론 배포 생성, 준비 대기 및 호출 예제 제공이 포함됩니다. 사용자가 Baijian/DashScope/Alibaba Cloud Model Studio에서 모델 교육, 미세 조정, "미세 조정", "미세 조정", 모델 배포, 모델 실행, 미세 조정된 모델 실행/호출, 추론 모델 교육, 사전 교육 계속, LoRA/SFT/DPO 교육 등을 언급할 때 이 기술은 활성화되어야 합니다. 사용자가 명시적으로 "bl 사용"이라고 말하지 않더라도 이 기술은 활성화되어야 합니다. Baijian 플랫폼에서 훈련하거나 배포하려는 의도가 있는 한 이 기술을 사용하고 명령을 직접 조합하지 마십시오.
