Bailei CLI(`bl`)를 사용하여 "데이터 → 미세 조정 훈련 → 내보내기 → 배포 → 호출"의 전체 루프를 진행하거나 훈련을 건너뛰고 기본 모델을 직접 배포합니다. 여기에는 데이터 세트 검증/업로드, SFT/DPO/CPT 미세 조정 작업 생성, 훈련 대기, 최상의 체크포인트 내보내기, 추론 배포 생성, 준비 대기 및 호출 예제 제공이 포함됩니다. 사용자가 Bailei/DashScope/Alibaba Cloud Model Studio에서 "모델 훈련", "미세 조정", "미세 조정", "미세 조정", "모델 배포", "모델 시작", "미세 조정 모델 실행/호출", "추론 모델 훈련", "사전 훈련 계속", "LoRA/SFT/DPO 훈련" 등을 언급하는 경우 이 기술은 활성화되어야 합니다. 사용자가 "bl을 사용하세요"라고 명시적으로 말하지 않습니다. Bailei 플랫폼에서의 교육 또는 배포가 목적이라면 이 기술을 사용하고 명령을 직접 엮지 마십시오.
