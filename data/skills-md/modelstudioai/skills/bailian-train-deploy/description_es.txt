Cubre la validación/carga de conjuntos de datos, la creación de tareas de ajuste SFT/DPO/CPT, la espera de capacitación, la exportación del mejor punto de control, la creación de una implementación de inferencia, la espera de preparación y el suministro de ejemplos de invocación. Cuando un usuario menciona "entrenar un modelo", "ajustar", "ajustar", "ajustar", "implementar un modelo", "lanzar un modelo", "ejecutar/llamar a un modelo ajustado", "entrenar un modelo de inferencia", "continuar con el entrenamiento previo", "entrenamiento LoRA/SFT/DPO", etc., en Bailei/DashScope/Alibaba Cloud Model Studio, esta habilidad debe activarse, incluso si el usuario no dice explícitamente "usar bl”; Siempre que la intención sea entrenar o implementar en la plataforma Bailei, usa esta habilidad y no improvises comandos tú mismo.
