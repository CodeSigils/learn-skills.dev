Utilice la CLI de Baijian (`bl`) para completar el ciclo completo de “datos → entrenamiento de ajuste → exportación → implementación → invocación”, u omita el entrenamiento e implemente directamente el modelo base. Esto cubre la validación/carga de conjuntos de datos, la creación de tareas de ajuste SFT/DPO/CPT, la espera de capacitación, la exportación del mejor punto de control, la creación de una implementación de inferencia, la espera a que esté listo y el suministro de ejemplos de invocación. Cuando un usuario menciona entrenar un modelo, realizar ajustes, "afinar", "afinar", implementar un modelo, lanzar un modelo, ejecutar/llamar a un modelo ajustado, entrenar un modelo de inferencia, continuar con el entrenamiento previo, entrenamiento LoRA/SFT/DPO, etc., en Baijian/DashScope/Alibaba Cloud Model Studio, esta habilidad debe activarse, incluso si el usuario no dice explícitamente "usar bl". Siempre que la intención sea entrenar o desplegarse en la plataforma Baijian, use esta habilidad y no reconstruya los comandos usted mismo.
