Baijian CLI (`bl`) を使用して、「データ → 微調整トレーニング → エクスポート → デプロイメント → 呼び出し」の完全なループを完了するか、トレーニングをスキップして基本モデルを直接デプロイします。これには、データセットの検証/アップロード、SFT/DPO/CPT 微調整タスクの作成、トレーニングの待機、最適なチェックポイントのエクスポート、推論デプロイメントの作成、準備が整うまでの待機、および呼び出し例の提供が含まれます。 Baijian / DashScope / Alibaba Cloud Model Studio で、ユーザーがモデルのトレーニング、微調整、「微調整」、「微調整」、モデルのデプロイ、モデルの起動、微調整モデルの実行/呼び出し、推論モデルのトレーニング、事前トレーニングの継続、LoRA/SFT/DPO トレーニングなどについて言及した場合、ユーザーが明示的に「bl を使用する」と言っていなくても、このスキルはアクティブ化される必要があります。 Baijian プラットフォームでのトレーニングまたはデプロイが目的である限り、このスキルを使用し、自分でコマンドを組み合わせないでください。
