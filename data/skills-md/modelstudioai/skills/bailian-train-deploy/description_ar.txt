استخدم Baijian CLI (`bl`) لإكمال الحلقة الكاملة من "البيانات ← التدريب على الضبط الدقيق ← التصدير ← النشر ← الاستدعاء"، أو تخطي التدريب ونشر النموذج الأساسي مباشرة. يغطي هذا التحقق من صحة/تحميل مجموعة البيانات، وإنشاء مهام ضبط SFT/DPO/CPT، وانتظار التدريب، وتصدير أفضل نقطة تفتيش، وإنشاء نشر استدلالي، وانتظار أن تصبح جاهزة، وتقديم أمثلة الاستدعاء. عندما يذكر المستخدم تدريب نموذج، أو الضبط الدقيق، أو "الضبط الدقيق"، أو "الضبط الدقيق"، أو نشر نموذج، أو إطلاق نموذج، أو تشغيل/استدعاء نموذج مضبوط بدقة، أو تدريب نموذج استدلالي، أو مواصلة التدريب المسبق، أو تدريب LoRA/SFT/DPO، وما إلى ذلك، على Baijian / DashScope / Alibaba Cloud Model Studio، يجب تنشيط هذه المهارة - حتى لو لم يقل المستخدم صراحةً "استخدم bl". طالما أن الهدف هو التدريب أو النشر على منصة Baijian، استخدم هذه المهارة ولا تجمع الأوامر بنفسك.
