Adapte una novela o historia a un juego web de novelas interactivas (React SPA) con recursos generados por IA (video/imagen opcionales), narración TTS opcional, audio procedimental, un motor de historias ramificadas y un sistema de guardado. Utilice la CLI `bl` para la generación de recursos (`bl video generate` / `bl image generate` / `bl Speech Synthesize`). Se activa cuando el usuario menciona una novela interactiva, un juego de aventuras de texto, un juego de adaptación de novela, un juego interactivo H5, una historia ramificada o una novela visual.
