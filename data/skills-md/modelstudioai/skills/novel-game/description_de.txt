Passen Sie einen Roman/eine Geschichte in ein interaktives Roman-Webspiel (React SPA) an, einschließlich KI-generierter Assets (optionales Video/Bild), optionaler TTS-Erzählung, prozeduralem Audio, einer verzweigten Storyline-Engine und einem Speichersystem. Verwenden Sie die „bl“-CLI, um Assets zu generieren („bl video generic“ / „bl image generic“ / „bl language synthesize“). Aktivieren Sie diese Option, wenn der Benutzer einen interaktiven Roman, ein Text-Adventure-Spiel, ein Romanadaptionsspiel, ein interaktives H5-Spiel, eine verzweigte Handlung oder einen visuellen Roman erwähnt.
