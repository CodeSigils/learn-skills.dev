Selección y recomendación del modelo Alibaba Cloud Bailian. Se activa cuando un usuario necesita "elegir, recomendar, comparar" modelos o describe un escenario/requisito de función de IA (implícitamente necesita ayuda para decidir qué modelo usar). La intención principal es ayudar al usuario a tomar una decisión, no simplemente buscar información. Palabras desencadenantes: recomendar modelo, cuál elegir, cuál es adecuado, comparar, crear aXX, implementar la función XX, qué modelo es bueno, solución de escenario XX. Cuando un usuario involucra tanto consultas de modelo como selección de modelo, priorice el uso de esta habilidad (esta habilidad leerá internamente los datos del modelo para completar la recomendación).
