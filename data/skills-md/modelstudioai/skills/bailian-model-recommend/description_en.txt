Alibaba Cloud Bailian model selection and recommendation. It is triggered when a user needs to "choose, recommend, compare" models, or describes an AI scenario/function requirement (implicitly needing help deciding which model to use). The core intent is to help the user make a decision, not merely look up information. Trigger words: recommend model, which one to choose, which is suitable, compare, create a XX, implement XX function, which model is good, XX scenario solution. When a user involves both model queries and model selection, prioritize using this skill (this skill will internally read model data to complete the recommendation).
