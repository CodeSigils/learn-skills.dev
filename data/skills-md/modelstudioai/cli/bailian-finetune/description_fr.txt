Entrée de formation pour le réglage fin du modèle Alibaba Cloud Bailei : les utilisateurs qui souhaitent affiner, micro-ajuster ou entraîner leur propre modèle (affiner, prendre en charge SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, couvrant le texte, la parole et l'image) peuvent valider ou télécharger des ensembles de données d'entraînement, afficher la progression et les journaux de l'entraînement, sélectionner des points de contrôle, exporter des artefacts de réglage fin et déployer le modèle dédié en tant que service à l'aide de « bl dataset » / `bl finetune` / `bl déployer`. Le flux de travail est le suivant : valider (vérifier les données) → télécharger (obtenir l'ID de fichier) → affiner la création (créer une tâche) → surveiller (surveiller la progression) → exporter (exporter) → déployer (lancer), nécessitant une clé API ; les opérations d'écriture doivent d'abord être prévisualisées avec `--dry-run`. Anti-déclencheur : si un utilisateur demande explicitement un réglage fin de l'Arche Volcanique/de l'Arche, il ne passe pas par cette compétence ; il vous suffit de choisir quel modèle passe par bailian‑model‑recommend ; l'utilisation de modèles existants pour la génération d'images ou de vidéos passe par bailian‑gen ; la gestion des autres ressources de Bailei passe par bailian‑cli. Installation officielle : `npx skills add modelstudioai/cli --all -g` (installé avec le protocole partagé bailian-protocol).
