Point d'entrée de la formation de réglage fin du modèle Aliyun Baizhan : les utilisateurs qui souhaitent affiner, micro-ajuster ou entraîner leurs propres modèles (affiner, prendre en charge SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, couvrant le texte, la voix, l'image), valider ou télécharger des ensembles de données d'entraînement, afficher la progression et les journaux de l'entraînement, sélectionner des points de contrôle, exporter des artefacts affinés et déployer le modèle dédié en tant que service utilisent `bl dataset` / `bl finetune` / `bl déployer`. Le flux de travail est valider → télécharger pour obtenir l'ID de fichier → affiner la création pour créer une tâche → regarder pour voir la progression → exporter → déployer pour mettre en ligne, nécessitant une clé API ; les opérations d'écriture doivent d'abord être prévisualisées avec `--dry-run`. Anti-déclencheur : lorsqu'un utilisateur sélectionne explicitement le réglage fin de Volcano Ark, cette compétence n'est pas utilisée ; il leur suffit de choisir quel modèle passe par bailian-model-recommande ; l'utilisation de modèles existants pour la génération d'images ou de vidéos passe par bailian‑gen ; d'autres ressources de gestion de Baizhan utilisent bailian‑cli. Installation officielle : `npx skills add modelstudioai/cli --all -g` (installé avec le protocole partagé bailian-protocol).
