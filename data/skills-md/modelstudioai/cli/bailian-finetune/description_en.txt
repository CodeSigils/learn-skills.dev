Alibaba Cloud Bailei model fine‑tuning training entry: users who want to fine‑tune, micro‑tune, or train their own model (fine‑tune, supporting SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT, covering text, speech, and image) can validate or upload training datasets, view training progress and logs, select checkpoints, export fine‑tuning artifacts, and deploy the dedicated model as a service using `bl dataset` / `bl finetune` / `bl deploy`. The workflow is: validate (check data) → upload (obtain file‑id) → finetune create (create task) → watch (monitor progress) → export (export) → deploy (launch), requiring an API key; write operations should first be previewed with `--dry-run`. Anti‑trigger: if a user explicitly requests Volcano Ark/ark fine‑tuning, it does not go through this skill; you only need to choose which model goes through bailian‑model‑recommend; using existing models for image or video generation goes through bailian‑gen; other Bailei resource management goes through bailian‑cli. Official installation: `npx skills add modelstudioai/cli --all -g` (installed together with the shared protocol bailian‑protocol).
