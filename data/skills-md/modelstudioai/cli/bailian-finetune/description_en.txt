Aliyun Baizhan model fine‑tuning training entry point: users who want to fine‑tune, micro‑tune, or train their own models (fine‑tune, supporting SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT, covering text, voice, image), validate or upload training datasets, view training progress and logs, select checkpoints, export fine‑tuned artifacts, and deploy the dedicated model as a service use `bl dataset` / `bl finetune` / `bl deploy`. The workflow is validate → upload to get file‑id → finetune create to create a task → watch to see progress → export → deploy to go live, requiring an API key; write operations should be previewed first with `--dry-run`. Anti‑trigger: when a user explicitly selects Volcano Ark's fine‑tuning, this skill is not used; they only need to choose which model goes through bailian‑model‑recommend; using existing models for image or video generation goes through bailian‑gen; other Baizhan resource management uses bailian‑cli. Official installation: `npx skills add modelstudioai/cli --all -g` (installed together with the shared protocol bailian‑protocol).
