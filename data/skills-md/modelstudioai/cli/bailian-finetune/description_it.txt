Punto di ingresso per la formazione per la messa a punto del modello Aliyun Baizhan: gli utenti che desiderano perfezionare, micro-ottimizzare o addestrare i propri modelli (ottimizzare, supportare SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT, coprire testo, voce, immagine), convalidare o caricare set di dati di addestramento, visualizzare i progressi e i registri dell'addestramento, selezionare checkpoint, esportare artefatti ottimizzati e distribuire il modello dedicato come servizio utilizza "bl dataset" / "bl finetune" / "bl deploy". Il flusso di lavoro è convalida → carica per ottenere l'ID file → ottimizza la creazione per creare un'attività → guarda per vedere l'avanzamento → esporta → distribuisci per andare in diretta, richiedendo una chiave API; le operazioni di scrittura dovrebbero essere visualizzate prima in anteprima con `--dry-run`. Anti-trigger: quando un utente seleziona esplicitamente la messa a punto di Volcano Ark, questa abilità non viene utilizzata; devono solo scegliere quale modello sottoporsi alla raccomandazione del modello bailian; l’utilizzo di modelli esistenti per la generazione di immagini o video passa attraverso bailian‑gen; altra gestione delle risorse Baizhan utilizza bailian-cli. Installazione ufficiale: `npx skills add modelstudioai/cli --all -g` (installato insieme al protocollo condiviso bailian‑protocol).
