Voce di formazione per l'ottimizzazione del modello Alibaba Cloud Bailei: gli utenti che desiderano ottimizzare, micro-ottimizzare o addestrare il proprio modello (ottimizzare, supporta SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT, coprendo testo, parlato, immagine), convalidare o caricare set di dati di addestramento, visualizzare i progressi e i registri dell'addestramento, selezionare checkpoint, esportare artefatti di ottimizzazione e distribuire il modello dedicato come servizio utilizza "bl dataset" / "bl finetune` / `bl deploy`. Il flusso di lavoro è convalida → carica per ottenere l'ID file → ottimizza la creazione per creare un'attività → guarda per monitorare l'avanzamento → esporta → distribuisci, richiedendo una chiave API; le operazioni di scrittura dovrebbero essere visualizzate prima in anteprima con `--dry-run`. Anti-innesco: se l'utente nomina esplicitamente Volcano Ark/ark per la messa a punto, questa abilità non viene utilizzata; devono solo scegliere quale modello tramite la raccomandazione del modello bailian; l'utilizzo di modelli esistenti per la generazione di immagini o video utilizza bailian-gen; altra gestione delle risorse Bailei utilizza bailian-cli. Installazione ufficiale: `npx skills add modelstudioai/cli --all -g` (installato insieme al protocollo condiviso bailian‑protocol).
