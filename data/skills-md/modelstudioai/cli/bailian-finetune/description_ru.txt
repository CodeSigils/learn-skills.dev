Запись для обучения по тонкой настройке модели Alibaba Cloud Bailei: пользователи, которые хотят выполнить точную настройку, микронастройку или обучение своих собственных моделей (тонкая настройка, поддержка SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, включая текст, речь и изображения), проверять или загружать наборы обучающих данных, просматривать ход обучения и журналы, выбирать контрольные точки, экспортировать артефакты тонкой настройки и развертывать выделенную модель как услугу, используйте `bl dataset` / `bl Finetune`/`bl Deploy`. Рабочий процесс таков: проверка → загрузка для получения идентификатора файла → точная настройка создания для создания задачи → наблюдение за прогрессом → экспорт для экспорта артефактов → развертывание для запуска; требуется ключ API, а операции записи следует предварительно просмотреть с помощью `--dry-run`. Антитриггер: когда пользователь явно называет Volcano Ark/ark для точной настройки, этот навык не проходит; им нужно только выбрать, какая модель будет одобрена bailian-model-recommend; использование существующих моделей для создания изображений или видео проходит через bailian‑gen; другое управление ресурсами Bailei использует bailian‑cli. Официальная установка: `npxkills add modelstudioai/cli --all -g` (устанавливается вместе с общим протоколом bailian‑protocol).
