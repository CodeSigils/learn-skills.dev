Точка входа для обучения точной настройке модели Aliyun Baizhan: пользователи, которые хотят выполнить точную настройку, микронастройку или обучение своих собственных моделей (тонкая настройка, поддержка SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, охватывающий текст, голос, изображение), проверить или загрузить наборы обучающих данных, просмотреть ход обучения и журналы, выбрать контрольные точки, экспортировать точно настроенные артефакты и развернуть выделенную модель как услугу, используйте `bl dataset` / `bl Finetune`/`bl Deploy`. Рабочий процесс: проверка → загрузка для получения идентификатора файла → точная настройка для создания задачи → наблюдение за прогрессом → экспорт → развертывание для запуска, требующий ключа API; операции записи следует предварительно просмотреть с помощью `--dry-run`. Антитриггер: когда пользователь явно выбирает точную настройку Volcano Ark, этот навык не используется; им нужно только выбрать, какая модель проходит проверку bailian-model-recommend; использование существующих моделей для генерации изображений или видео проходит через bailian‑gen; другое управление ресурсами Baizhan использует bailian‑cli. Официальная установка: `npxkills add modelstudioai/cli --all -g` (устанавливается вместе с общим протоколом bailian‑protocol).
