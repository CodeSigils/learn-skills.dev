Entrada de entrenamiento de ajuste fino del modelo Alibaba Cloud Bailei: los usuarios que desean ajustar, microajustar o entrenar su propio modelo (ajustar, admitir SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, que cubre texto, voz e imagen) pueden validar o cargar conjuntos de datos de entrenamiento, ver el progreso y los registros del entrenamiento, seleccionar puntos de control, exportar artefactos de ajuste e implementar el modelo dedicado como un servicio usando `bl dataset` / `bl ajuste fino`/`despliegue bl`. El flujo de trabajo es: validar (verificar datos) → cargar (obtener ID de archivo) → ajustar crear (crear tarea) → observar (monitorear el progreso) → exportar (exportar) → implementar (iniciar), lo que requiere una clave API; Las operaciones de escritura primero deben obtenerse una vista previa con `--dry-run`. Anti-disparador: si un usuario solicita explícitamente un ajuste fino de Volcano Ark/ark, no pasa por esta habilidad; solo necesita elegir qué modelo pasa por la recomendación del modelo bailian; el uso de modelos existentes para la generación de imágenes o vídeos pasa por bailian-gen; La gestión de otros recursos de Bailei pasa por Bailian-Cli. Instalación oficial: `npx skills add modelstudioai/cli --all -g` (instalado junto con el protocolo compartido bailian‑protocol).
