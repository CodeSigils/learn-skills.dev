Punto de entrada del entrenamiento de ajuste fino del modelo Aliyun Baizhan: los usuarios que desean ajustar, microajustar o entrenar sus propios modelos (ajustar, admitir SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, que cubren texto, voz, imagen), validar o cargar conjuntos de datos de entrenamiento, ver el progreso y los registros del entrenamiento, seleccionar puntos de control, exportar artefactos ajustados e implementar el modelo dedicado como un servicio usan `bl dataset` / `bl finetune` / `bl implementar`. El flujo de trabajo es validar → cargar para obtener el ID del archivo → ajustar la creación para crear una tarea → observar para ver el progreso → exportar → implementar para comenzar a funcionar, lo que requiere una clave API; Las operaciones de escritura deben obtenerse una vista previa primero con `--dry-run`. Antidisparador: cuando un usuario selecciona explícitamente el ajuste fino de Volcano Ark, esta habilidad no se usa; solo necesitan elegir qué modelo pasa por la recomendación del modelo bailiano; el uso de modelos existentes para la generación de imágenes o vídeos pasa por bailian-gen; otra gestión de recursos de Baizhan utiliza bailian-cli. Instalación oficial: `npx skills add modelstudioai/cli --all -g` (instalado junto con el protocolo compartido bailian‑protocol).
