نقطة دخول تدريب الضبط الدقيق لنموذج Alibaba Cloud Bailei: المستخدمون الذين يرغبون في ضبط نماذجهم الخاصة أو ضبطها أو تدريبها (الضبط الدقيق، دعم SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT، تغطية النص والكلام والصور)، والتحقق من صحة مجموعات بيانات التدريب أو تحميلها، وعرض تقدم التدريب والسجلات، وتحديد نقاط التفتيش، وتصدير العناصر المضبوطة بدقة، ونشر النموذج المخصص كخدمة تستخدم `bl dataset` / `bl Finetune` /`نشر bl`. سير العمل هو: التحقق من الصحة ← التحميل للحصول على معرف الملف ← الضبط الدقيق للإنشاء لإنشاء مهمة ← المراقبة لمراقبة التقدم ← التصدير ← النشر لبدء التشغيل، مما يتطلب مفتاح API؛ يجب معاينة عمليات الكتابة أولاً باستخدام `--dry-run`. مكافحة الزناد: عندما يقوم المستخدم صراحةً بتسمية Volcano Ark/ark للضبط الدقيق، لا يتم استخدام هذه المهارة؛ ما عليك سوى اختيار النموذج الذي يمر عبر نموذج بايلي الموصى به؛ استخدام النماذج الموجودة لإنشاء صور أو مقاطع فيديو يمر عبر Bailian‑gen؛ تستخدم إدارة موارد Bailey الأخرى Bailian-cli. التثبيت الرسمي: `npx Skills addmodelstudioai/cli --all -g` (مثبت مع البروتوكول المشترك Bailian-protocol).
