نقطة دخول تدريب الضبط الدقيق لنموذج Aliyun Baizhan: المستخدمون الذين يرغبون في الضبط الدقيق أو الضبط الدقيق أو تدريب نماذجهم الخاصة (الضبط الدقيق ودعم SFT / SFT‑LoRA / DPO / DPO‑LoRA / CPT، وتغطية النص والصوت والصورة)، والتحقق من صحة مجموعات بيانات التدريب أو تحميلها، وعرض تقدم التدريب والسجلات، وتحديد نقاط التفتيش، وتصدير العناصر المضبوطة بدقة، ونشر النموذج المخصص كخدمة تستخدم "مجموعة بيانات bl" / `bl Finetune` / `blploy`. يتم التحقق من صحة سير العمل ← التحميل للحصول على معرف الملف ← الضبط الدقيق للإنشاء لإنشاء مهمة ← المشاهدة لرؤية التقدم ← التصدير ← النشر لبدء البث المباشر، مما يتطلب مفتاح واجهة برمجة التطبيقات؛ يجب معاينة عمليات الكتابة أولاً باستخدام `--dry-run`. مكافحة الزناد: عندما يقوم المستخدم بتحديد الضبط الدقيق لـ Volcano Ark بشكل صريح، لا يتم استخدام هذه المهارة؛ إنهم يحتاجون فقط إلى اختيار النموذج الذي يمر عبر نموذج بايلي الموصى به؛ استخدام النماذج الموجودة لتوليد الصور أو الفيديو يمر عبر Bailian‑gen؛ تستخدم إدارة موارد Baizhan الأخرى Bailian-cli. التثبيت الرسمي: `npx Skills addmodelstudioai/cli --all -g` (مثبت مع البروتوكول المشترك Bailian-protocol).
