Alibaba Cloud Bairei モデルの微調整トレーニング エントリ: 独自のモデルを微調整、マイクロ調整、またはトレーニングしたいユーザー (微調整、SFT / SFT-LoRA / DPO / DPO-LoRA / CPT をサポート、テキスト、音声、画像をカバー) は、トレーニング データセットの検証またはアップロード、トレーニングの進行状況とログの表示、チェックポイントの選択、微調整アーティファクトのエクスポート、専用モデルのデプロイを行うことができます。 `bl dataset` / `blfinetune` / `bldeploy` を使用したサービスとして。ワークフローは次のとおりです。検証 (データの確認) → アップロード (ファイル ID の取得) → Finetune create (タスクの作成) → 監視 (進行状況の監視) → エクスポート (エクスポート) → デプロイ (起動) で、API キーが必要です。書き込み操作は、最初に `--dry-run` を使用してプレビューする必要があります。アンチトリガー: ユーザーが Volcano Ark/ark の微調整を明示的に要求した場合、このスキルは実行されません。どのモデルが bailian-model-recommend を通過するかを選択するだけで済みます。画像またはビデオの生成に既存のモデルを使用する場合は、bairian-gen を経由します。その他の Bailei リソース管理は、bairian‑cli を介して行われます。公式インストール: `npx skill add modelstudioai/cli --all -g` (共有プロトコル bailian‑protocol と一緒にインストールされます)。
