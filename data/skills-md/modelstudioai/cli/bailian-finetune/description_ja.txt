Aliyun Baizhan モデルの微調整トレーニング エントリ ポイント: 独自のモデルの微調整、マイクロ調整、またはトレーニング (微調整、SFT / SFT-LoRA / DPO / DPO-LoRA / CPT のサポート、テキスト、音声、画像をカバー)、トレーニング データセットの検証またはアップロード、トレーニングの進行状況とログの表示、チェックポイントの選択、微調整されたアーティファクトのエクスポート、専用モデルのデプロイを希望するユーザーサービスは `bl dataset` / `blfinetune` / `bldeploy` を使用します。ワークフローは、検証→アップロードしてファイル ID を取得→finetune create でタスクを作成→監視して進行状況を確認→エクスポート→デプロイしてライブにするというもので、API キーが必要です。書き込み操作は、最初に `--dry-run` を使用してプレビューする必要があります。アンチトリガー: ユーザーが Volcano Ark の微調整を明示的に選択した場合、このスキルは使用されません。どのモデルがバイリアンモデル推奨を通過するかを選択するだけで済みます。画像またはビデオの生成に既存のモデルを使用する場合は、bairian-gen を経由します。その他の Baizhan リソース管理は、bairian-cli を使用します。公式インストール: `npx skill add modelstudioai/cli --all -g` (共有プロトコル bailian‑protocol と一緒にインストールされます)。
