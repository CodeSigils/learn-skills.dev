Alibaba Cloud Bailei 모델 미세 조정 훈련 항목: 자체 모델을 미세 조정, 미세 조정하거나 훈련(미세 조정, SFT/SFT-LoRA/DPO/DPO-LoRA/CPT 지원, 텍스트, 음성 및 이미지 포함)하려는 사용자는 훈련 데이터 세트를 검증 또는 업로드하고, 훈련 진행 상황 및 로그를 보고, 체크포인트를 선택하고, 미세 조정 아티팩트를 내보내고, 전용 모델을 'bl 데이터 세트' / 'bl Finetune'을 사용하여 서비스로 배포할 수 있습니다. 'bl 배포'. 워크플로는 유효성 검사(데이터 확인) → 업로드(파일 ID 얻기) → 미세 조정 생성(작업 생성) → 감시(진행 상황 모니터링) → 내보내기(내보내기) → 배포(실행)이며, API 키가 필요합니다. 쓰기 작업은 먼저 `--dry-run`을 사용하여 미리 봐야 합니다. 안티 트리거: 사용자가 명시적으로 화산방주/방주 미세 조정을 요청하는 경우 이 스킬을 거치지 않습니다. bailian-model-recommend를 통과할 모델을 선택하기만 하면 됩니다. 이미지 또는 비디오 생성을 위해 기존 모델을 사용하는 것은 bailian-gen을 거칩니다. 기타 Bailei 리소스 관리는 bailian‑cli를 통해 이루어집니다. 공식 설치: `npx Skills add modelstudioai/cli --all -g`(공유 프로토콜 bailian‑protocol과 함께 설치됨)
