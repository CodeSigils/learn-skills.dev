Aliyun Baizhan-Modell-Feinabstimmungs-Trainingseinstiegspunkt: Benutzer, die ihre eigenen Modelle feinabstimmen, mikroabstimmen oder trainieren möchten (Feinabstimmung, Unterstützung von SFT / SFT-LoRA / DPO / DPO-LoRA / CPT, Text, Sprache, Bild abdecken), Trainingsdatensätze validieren oder hochladen, Trainingsfortschritt und -protokolle anzeigen, Prüfpunkte auswählen, feinabgestimmte Artefakte exportieren und das dedizierte Modell als Dienst bereitstellen möchten, verwenden „bl dataset“ / „bl Finetune` / `bl Deploy`. Der Workflow besteht aus Validierung → Hochladen, um die Datei-ID zu erhalten → Feinabstimmung der Erstellung, um eine Aufgabe zu erstellen → Beobachten, um den Fortschritt zu sehen → Exportieren → Bereitstellen, um live zu gehen, wofür ein API-Schlüssel erforderlich ist; Schreibvorgänge sollten zuerst mit „--dry-run“ in der Vorschau angezeigt werden. Anti-Trigger: Wenn ein Benutzer explizit die Feinabstimmung von Volcano Ark auswählt, wird diese Fertigkeit nicht verwendet; Sie müssen nur auswählen, welches Modell der Bailian-Modell-Empfehlung unterliegt; Die Nutzung bestehender Modelle zur Bild- oder Videogenerierung erfolgt über Bailian-Gen; Andere Baizhan-Ressourcenverwaltungen verwenden Bailian-Cli. Offizielle Installation: „npx skills add modelstudioai/cli --all -g“ (wird zusammen mit dem gemeinsamen Protokoll bailian‑protocol installiert).
