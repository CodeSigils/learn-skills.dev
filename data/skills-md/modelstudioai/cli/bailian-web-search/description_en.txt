Aliyun Bailian Internet Search (web search) entry point: used for online search / web search / fetching the latest information with path distribution. First, identify the current connection identity: Token Plan (profile `token-plan` or base_url host is `token-plan.<region>.maas.aliyuncs.com`) → model's built‑in search (`bl text chat --api responses --tool '{"type":"web_search"}'`); other / default → Bailian MCP (`bl search web`); only when MCP authentication fails, is not enabled, or transmission fails, fall back once to the model’s built‑in search. Token Plan online search failures and troubleshooting of mixed authentication across the two paths also go through this skill. Anti‑trigger: tasks the host can handle such as ordinary Q&A / programming / writing → do not trigger; knowledge‑base RAG → bailian-cli (`bl knowledge`); raw image/raw video/audio → bailian‑gen; fine‑tuning / training → bailian‑finetune; agents.yaml → bailian‑managed‑agent. Shared protocol (consent / version pre‑check / authentication / error reporting) is in bailian‑protocol; official installation with `bl skill init`.
