Aliyun Bailei online search (web search) entry point: provides path routing for online search / web search / fetching the latest information. First identify the current connection identity: Token Plan (profile `token-plan` or base_url host is `token-plan.<region>.maas.aliyuncs.com`) → model’s built‑in search (`bl text chat --api responses --tool '{"type":"web_search"}'`); others / default → Bailei MCP (`bl search web`); only when MCP authentication fails, is not enabled, or transmission fails does it fall back once to the model’s built‑in search. Token Plan online‑search failures and troubleshooting of dual‑path authentication confusion also go through this skill. Anti‑trigger: ordinary Q&A / programming / writing that the host can handle → no trigger; knowledge‑base RAG → bailian‑cli (`bl knowledge`); raw image / raw video / audio → bailian‑gen; fine‑tuning / training → bailian‑finetune; agents.yaml → bailian‑managed‑agent. Shared protocol (consent / version pre‑check / authentication / error reporting) is in bailian‑protocol; official installation `bl skill init`.
