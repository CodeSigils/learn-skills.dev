نقطة دخول Aliyun Bailian لبحث الإنترنت (بحث الويب): تستخدم للبحث عبر الإنترنت / بحث الويب / جلب أحدث المعلومات مع توزيع المسار. أولاً، حدد هوية الاتصال الحالية: خطة الرمز المميز (ملف التعريف `token-plan` أو مضيف base_url هو `token-plan.<region>.maas.aliyuncs.com`) → البحث المدمج في النموذج (`bl text chat --api Responses --tool '{"type":web_search"}'`); أخرى / افتراضي → Bailian MCP (`bl search web`)؛ فقط عند فشل مصادقة MCP، أو عدم تمكينها، أو فشل الإرسال، ارجع مرة واحدة إلى البحث المدمج في النموذج. تمر أيضًا هذه المهارة بفشل البحث عبر الإنترنت في Token Plan واستكشاف أخطاء المصادقة المختلطة وإصلاحها عبر المسارين. مكافحة الزناد: المهام التي يمكن للمضيف التعامل معها مثل الأسئلة والأجوبة العادية / البرمجة / الكتابة → لا يتم تشغيلها؛ قاعدة المعرفة RAG → Bailian-cli (`bl Knowledge`)؛ صورة خام/فيديو خام/صوت → Bailian-gen؛ الضبط الدقيق / التدريب ← الضبط الدقيق للبيليان؛ agents.yaml → Bailian-managed-agent. البروتوكول المشترك (الموافقة/الفحص المسبق للإصدار/المصادقة/الإبلاغ عن الأخطاء) موجود في بروتوكول Bailian؛ التثبيت الرسمي مع `bl Skill init`.
