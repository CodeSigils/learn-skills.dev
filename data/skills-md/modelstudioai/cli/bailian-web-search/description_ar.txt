نقطة دخول Alibaba Cloud Bailian للبحث عبر الإنترنت (بحث الويب): توفر التوجيه للبحث عبر الإنترنت / بحث الويب / جلب أحدث المعلومات. حدد أولاً هوية الاتصال الحالية: خطة الرمز المميز (ملف التعريف `token‑plan` أو مضيف base_url هو `token‑plan.<region>.maas.aliyuncs.com`) → البحث المدمج في النموذج (`bl text chat --api Responses --tool '{"type":web_search"}'`)؛ أخرى / افتراضي → Bailian MCP (`bl search web`)؛ فقط عندما تفشل مصادقة MCP، أو لا يتم تنشيطها، أو يفشل الإرسال، فإنها ترجع مرة واحدة إلى البحث المدمج في النموذج. كما تستخدم هذه المهارة أيضًا حالات فشل البحث عبر الإنترنت في Token Plan واستكشاف أخطاء ارتباك المصادقة وإصلاحها بين المسارين. مكافحة الزناد: الأسئلة والأجوبة العادية / البرمجة / الكتابة التي يمكن للمضيف التعامل معها ← لا يتم تشغيلها ؛ قاعدة المعرفة RAG → Bailian‑cli (`المعرفة bl`)؛ صورة خام / فيديو خام / صوت → Bailian‑gen؛ الضبط الدقيق / التدريب ← الضبط الدقيق للبيليان؛ agents.yaml → Bailian-managed-agent. البروتوكول المشترك (الموافقة/الفحص المسبق للإصدار/المصادقة/الإبلاغ عن الأخطاء) موجود في بروتوكول Bailian؛ التثبيت الرسمي bl Skill init
