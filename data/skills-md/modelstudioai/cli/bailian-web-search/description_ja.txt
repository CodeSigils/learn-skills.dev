Aliyun Bailian Internet Search (Web 検索) エントリ ポイント: オンライン検索/Web 検索/パス配布による最新情報の取得に使用されます。まず、現在の接続 ID を特定します。トークン プラン (プロファイル `token-plan` または Base_url ホストは `token-plan.<region>.maas.aliyuncs.com`) → モデルの組み込み検索 (`bl text chat --apiresponse --tool '{"type":"web_search"}'`);その他 / デフォルト → Bailian MCP (`bl 検索ウェブ`); MCP 認証が失敗した場合、有効になっていない場合、または送信が失敗した場合にのみ、モデルの組み込み検索に一度フォールバックします。トークン プランのオンライン検索の失敗や、2 つのパスにわたる混合認証のトラブルシューティングもこのスキルを利用します。アンチトリガー: 通常の Q&A / プログラミング / 執筆など、ホストが処理できるタスク → トリガーされません。知識ベース RAG → bairian-cli (`bl 知識`);生の画像/生のビデオ/オーディオ → bailian-gen;微調整 / トレーニング → バイリアン微調整; Agents.yaml → bailian 管理対象エージェント。共有プロトコル (同意/バージョン事前チェック/認証/エラー報告) は bailian プロトコルにあります。 `bl skill init`で正式にインストールします。
