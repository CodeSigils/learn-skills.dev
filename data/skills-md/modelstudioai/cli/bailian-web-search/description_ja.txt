Alibaba Cloud Bairei オンライン検索 (Web 検索) エントリ: オンライン検索/Web 検索/最新情報の取得のためのパス ルーティングを提供します。まず現在の接続 ID を特定します。トークン プラン (プロファイル `token-plan` または Base_url ホストは `token-plan.<region>.maas.aliyuncs.com`) → モデルの組み込み検索 (`bl text chat --apiresponse --tool '{"type":"web_search"}'`);その他/デフォルト → Bailey MCP (`bl 検索ウェブ`); MCP 認証が失敗した場合、認証がアクティブ化されていない場合、または送信が失敗した場合にのみ、モデルの組み込み検索にフォールバックします。トークン プランのオンライン検索の失敗や 2 つのパス間の認証の混乱のトラブルシューティングもこのスキルを使用します。アンチトリガー: ホストが処理できる通常の Q&A / プログラミング / 書き込み → トリガーされません。知識ベース RAG → bailian-cli (「bl 知識」);生の画像 / 生のビデオ / オーディオ → bailian‑gen;微調整 / トレーニング → バイリアン微調整; Agents.yaml → bailian 管理対象エージェント。共有プロトコル (同意/バージョン事前チェック/認証/エラー報告) は bailian プロトコルにあります。公式インストール`bl skill init`。
