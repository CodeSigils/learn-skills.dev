Voce di ricerca online (ricerca web) Alibaba Cloud Bailei: fornisce l'instradamento del percorso per la ricerca online/ricerca web/recupero delle informazioni più recenti. Innanzitutto identificare l'identità della connessione corrente: Token Plan (profilo `token‑plan` o host base_url è `token‑plan.<region>.maas.aliyuncs.com`) → ricerca integrata del modello (`bl text chat --api risposte --tool '{"type":"web_search"}'`); altrimenti / default → Bailei MCP (`bl search web`); fallback solo una volta alla ricerca integrata del modello quando l'autenticazione MCP fallisce, non è abilitata o la trasmissione fallisce. Anche la risoluzione dei problemi relativi agli errori di ricerca online del Token Plan o alla confusione di autenticazione tra i due percorsi passa attraverso questa competenza. Anti-trigger: normali domande e risposte/programmazione/scrittura che l'host può gestire → non attivato; base di conoscenza RAG → bailian‑cli (`bl conoscenza`); immagine grezza / video / audio grezza → bailian‑gen; messa a punto / formazione → bailian‑finetune; agenti.yaml → agente gestito da bailian. Il protocollo condiviso (consenso/controllo preliminare della versione/autenticazione/segnalazione degli errori) è nel protocollo bailian; installazione ufficiale `bl skill init`.
