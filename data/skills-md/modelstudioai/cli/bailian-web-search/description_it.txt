Punto di ingresso Aliyun Bailian Ricerca Internet (ricerca web): utilizzato per la ricerca online/ricerca web/recupero delle informazioni più recenti con distribuzione del percorso. Innanzitutto, identificare l'identità della connessione corrente: Token Plan (profilo `token-plan` o host base_url è `token-plan.<region>.maas.aliyuncs.com`) → ricerca integrata del modello (`bl text chat --api risposte --tool '{"type":"web_search"}'`); altro / predefinito → Bailian MCP (`bl search web`); solo quando l'autenticazione MCP fallisce, non è abilitata o la trasmissione fallisce, torna alla ricerca integrata del modello. Anche gli errori di ricerca online del Token Plan e la risoluzione dei problemi dell'autenticazione mista nei due percorsi passano attraverso questa competenza. Anti-trigger: attività che l'host può gestire come domande e risposte ordinarie/programmazione/scrittura → non si attivano; RAG della base di conoscenza → bailian-cli ("bl knowledge"); immagine grezza/video/audio grezza → bailian‑gen; messa a punto / formazione → bailian‑finetune; agenti.yaml → agente gestito da bailian. Il protocollo condiviso (consenso/controllo preliminare della versione/autenticazione/segnalazione errori) è nel protocollo bailian; installazione ufficiale con `bl skill init`.
