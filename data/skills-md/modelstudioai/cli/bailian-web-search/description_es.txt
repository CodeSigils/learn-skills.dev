Punto de entrada de búsqueda de Internet (búsqueda web) de Aliyun Bailian: se utiliza para búsqueda en línea/búsqueda web/obtención de la información más reciente con distribución de ruta. Primero, identifique la identidad de la conexión actual: Plan de token (el perfil `token-plan` o host_url base es `token-plan.<región>.maas.aliyuncs.com`) → búsqueda integrada del modelo (`bl text chat --api Responses --tool '{"type":"web_search"}'`); otro / predeterminado → Bailian MCP (`bl search web`); Solo cuando la autenticación MCP falla, no está habilitada o la transmisión falla, recurra una vez a la búsqueda integrada del modelo. Las fallas de búsqueda en línea de Token Plan y la resolución de problemas de autenticación mixta en las dos rutas también pasan por esta habilidad. Antidisparador: tareas que el anfitrión puede manejar, como preguntas y respuestas ordinarias/programación/escritura → no se activan; base de conocimientos RAG → bailian-cli (`conocimiento bl`); imagen sin formato/vídeo sin formato/audio → bailian-gen; ajuste fino / entrenamiento → bailian-ajuste fino; agentes.yaml → agente-administrado-por-bailian. El protocolo compartido (consentimiento/verificación previa de la versión/autenticación/informe de errores) está en el protocolo bailiano; Instalación oficial con `bl skills init`.
