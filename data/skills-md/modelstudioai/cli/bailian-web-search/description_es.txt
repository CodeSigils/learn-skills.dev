Entrada de búsqueda en línea (búsqueda web) de Alibaba Cloud Bailian: proporciona enrutamiento de ruta para búsqueda en línea/búsqueda web/obtención de la información más reciente. Primero identifique la identidad de la conexión actual: Plan de token (perfil `token-plan` o host_url base `token-plan.<región>.maas.aliyuncs.com`) → búsqueda integrada del modelo (`bl text chat --api Responses --tool '{"type":"web_search"}'`); de lo contrario / predeterminado → Bailian MCP (`bl search web`). Solo cuando la autenticación MCP falla, no se activa o la transmisión falla, se recurre una vez a la búsqueda integrada del modelo. Las fallas de búsqueda en línea del Plan de tokens y la resolución de problemas de confusión de autenticación entre las dos rutas también pasan por esta habilidad. Antidisparador: preguntas y respuestas ordinarias/programación/escritura que el host puede manejar → no activar; base de conocimientos RAG → bailian-cli (`conocimiento bl`); imagen sin formato/vídeo sin formato/audio → bailian‑gen; ajuste fino / entrenamiento → bailian-ajuste fino; agentes.yaml → agente-administrado-por-bailian. El protocolo compartido (consentimiento/verificación previa de la versión/autenticación/informe de errores) reside en el protocolo bailiano; Instalación oficial `bl skills init`.
