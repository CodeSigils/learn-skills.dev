阿里云百联互联网搜索（网页搜索）入口点：用于在线搜索/网页搜索/获取最新信息，具有路径分布。首先，识别当前连接身份：Token Plan（配置文件`token-plan`或base_url主机为`token-plan.<region>.maas.aliyuncs.com`）→模型内置搜索（`bl text chat --api messages --tool '{"type":"web_search"}'`）；其他/默认 → Bailian MCP (`bl search web`);仅当 MCP 身份验证失败、未启用或传输失败时，才会回退到模型的内置搜索。 Token Plan网上搜索失败以及跨两条路径混合认证的排查也是经过这个技巧的。反触发：普通问答/编程/写作等主机可以处理的任务→不触发；知识库 RAG → bailian-cli (`bl Knowledge`);原始图像/原始视频/音频 → bailian-gen;微调/训练 → bailian-finetune; Agents.yaml → bailian-托管-代理。共享协议（同意/版本预检查/身份验证/错误报告）位于 bailian-protocol 中；使用“bl Skill init”进行正式安装。
