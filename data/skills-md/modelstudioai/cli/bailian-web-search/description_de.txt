Einstiegspunkt für die Alibaba Cloud Bailian Online-Suche (Websuche): Verteilt Pfade für die Online-Suche/Websuche/Abruf der neuesten Informationen. Identifizieren Sie zunächst die aktuelle Verbindungsidentität: Token-Plan (Profil „token-plan“ oder Basis-URL-Host ist „token-plan.<region>.maas.aliyuncs.com“) → integrierte Suche des Modells („bl text chat --api Responses --tool '{"type":"web_search"}'`); andernfalls / Standard → Bailian MCP („bl search web“). Nur wenn die MCP-Authentifizierung fehlschlägt, nicht aktiviert ist oder die Übertragung fehlschlägt, wird einmal auf die integrierte Suche des Modells zurückgegriffen. Die Fehlerbehebung bei Online-Suchfehlern im Token-Plan oder bei der gemischten Authentifizierung der beiden Pfade umfasst ebenfalls diesen Skill. Anti-Trigger: Aufgaben, die der Host bewältigen kann – regelmäßige Fragen und Antworten / Programmieren / Schreiben → nicht auslösen; Wissensbasis RAG → bailian-cli („bl Wissen“); Rohbild / Rohvideo / Audio → bailian-gen; Feinabstimmung / Training → Bailian-Feinabstimmung; Agents.yaml → Bailian-Managed-Agent. Das gemeinsame Protokoll (Einwilligung/Versionsvorprüfung/Authentifizierung/Fehlermeldung) ist im Bailian-Protokoll; Offizielle Installation über „bl skills init“.
