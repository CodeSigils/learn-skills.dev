Aliyun Bailian Internet Search (Websuche) Einstiegspunkt: Wird für die Onlinesuche/Websuche/Abruf der neuesten Informationen mit Pfadverteilung verwendet. Identifizieren Sie zunächst die aktuelle Verbindungsidentität: Tokenplan (Profil „token-plan“ oder Basis-URL-Host ist „token-plan.<region>.maas.aliyuncs.com“) → integrierte Suche des Modells („bl text chat --api Responses --tool '{"type":"web_search"}'`); andere / Standard → Bailian MCP („bl search web“); Nur wenn die MCP-Authentifizierung fehlschlägt, nicht aktiviert ist oder die Übertragung fehlschlägt, greifen Sie einmal auf die integrierte Suche des Modells zurück. Auch Fehler bei der Token-Plan-Onlinesuche und die Fehlerbehebung bei gemischter Authentifizierung über die beiden Pfade hinweg werden durch diese Fertigkeit abgedeckt. Anti-Trigger: Aufgaben, die der Host bewältigen kann, wie z. B. normale Fragen und Antworten/Programmierung/Schreiben → nicht auslösen; Wissensbasis RAG → bailian-cli („bl Wissen“); Rohbild/Rohvideo/Audio → bailian‑gen; Feinabstimmung / Training → Bailian-Feinabstimmung; Agents.yaml → Bailian-Managed-Agent. Das gemeinsame Protokoll (Einwilligung/Versionsvorprüfung/Authentifizierung/Fehlermeldung) ist im Bailian-Protokoll; Offizielle Installation mit „bl skills init“.
