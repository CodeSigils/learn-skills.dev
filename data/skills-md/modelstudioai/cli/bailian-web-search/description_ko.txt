Alibaba Cloud Bailei 온라인 검색(웹 검색) 진입점: 온라인 검색/웹 검색/최신 정보 가져오기를 위한 경로를 배포합니다. 먼저 현재 연결 ID를 식별합니다. 토큰 계획(프로필 `token-plan` 또는 base_url 호스트는 `token-plan.<region>.maas.aliyuncs.com`입니다.) → 모델의 내장 검색(`bl text chat --api response --tool '{"type":"web_search"}'`); 기타 / 기본값 → Bailei MCP (`bl 검색 웹`); MCP 인증이 실패하거나, 활성화되지 않거나, 전송이 실패한 경우에만 모델의 내장 검색으로 한 번 되돌아갑니다. 토큰 계획 온라인 검색 실패 및 두 경로 간의 인증 혼동 문제 해결도 이 기술을 통해 수행됩니다. 안티 트리거: 일반적인 Q&A/프로그래밍/쓰기 등 호스트가 처리할 수 있는 작업 → 트리거되지 않습니다. 지식 기반 RAG → bailian‑cli(`bl 지식`); 원시 이미지 / 원시 비디오 / 오디오 → bailian‑gen; 미세 조정/훈련 → bailian-finetune; Agents.yaml → bailian‑managed‑agent. 공유 프로토콜(동의/버전 사전 확인/인증/오류 보고)은 Bailian-Protocol에 있습니다. 공식 설치 `bl Skill init`.
