Entrée de recherche en ligne Alibaba Cloud Bailian (recherche sur le Web) : effectue le routage du chemin pour la recherche en ligne/la recherche sur le Web/la récupération des dernières informations. Identifiez d'abord l'identité de connexion actuelle : Plan de jeton (le profil `token-plan` ou l'hôte base_url est `token-plan.<region>.maas.aliyuncs.com`) → recherche intégrée du modèle (`bl text chat --api réponses --tool '{"type":"web_search"}'`); sinon / par défaut → Bailian MCP (`bl search web`). Ce n’est que lorsque l’authentification MCP échoue, n’est pas activée ou que la transmission échoue qu’elle revient une fois à la recherche intégrée du modèle. Le dépannage des échecs de recherche en ligne Token Plan et de l’authentification mixte des deux chemins passe également par cette compétence. Anti-déclencheur : les tâches que l'hôte peut gérer telles que les questions/réponses ordinaires/la programmation/l'écriture → ne se déclenchent pas ; base de connaissances RAG → bailian-cli (`bl knowledge`) ; image brute / vidéo brute / audio → bailian‑gen ; mise au point / formation → bailian-finetune ; agents.yaml → agent géré par bailian. Le protocole partagé (consentement/vérification préalable de la version/authentification/rapport d'erreurs) est en protocole bailien ; installation officielle `bl skills init`.
