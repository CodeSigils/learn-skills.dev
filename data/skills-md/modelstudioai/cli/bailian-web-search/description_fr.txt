Point d'entrée Aliyun Bailian Internet Search (recherche sur le Web) : utilisé pour la recherche en ligne/la recherche sur le Web/la récupération des dernières informations avec la distribution des chemins. Tout d'abord, identifiez l'identité de connexion actuelle : Plan de jeton (le profil `token-plan` ou l'hôte base_url est `token-plan.<region>.maas.aliyuncs.com`) → recherche intégrée du modèle (`bl text chat --api réponses --tool '{"type":"web_search"}'`); autre / par défaut → Bailian MCP (`bl search web`); Ce n'est que lorsque l'authentification MCP échoue, n'est pas activée ou que la transmission échoue, revenez une fois à la recherche intégrée du modèle. Les échecs de recherche en ligne de Token Plan et le dépannage de l’authentification mixte sur les deux chemins passent également par cette compétence. Anti-déclencheur : les tâches que l'hôte peut gérer telles que les questions/réponses ordinaires/la programmation/l'écriture → ne se déclenchent pas ; base de connaissances RAG → bailian-cli (`bl knowledge`) ; image brute/vidéo/audio brut → bailian‑gen ; mise au point / formation → bailian-finetune ; agents.yaml → agent géré par bailian. Le protocole partagé (consentement/vérification préalable de la version/authentification/rapport d'erreurs) est en protocole bailien ; installation officielle avec `bl skills init`.
