Точка входа в интернет-поиск Aliyun Bailian (веб-поиск): используется для онлайн-поиска/веб-поиска/получения последней информации с распределением путей. Сначала определите текущий идентификатор подключения: План токена (профиль `token-plan` или хост base_url — `token-plan.<region>.maas.aliyuncs.com`) → встроенный поиск модели (`bl textchat --apiResponses --tool '{"type":"web_search"}'`); другое / по умолчанию → Bailian MCP (`bl search web`); только если аутентификация MCP не удалась, не включена или передача не удалась, один раз вернитесь к встроенному поиску модели. Сбои онлайн-поиска Token Plan и устранение неполадок смешанной аутентификации по двум путям также проходят через этот навык. Антитриггер: задачи, с которыми может справиться хост, например, обычные вопросы и ответы/программирование/письмо → не срабатывают; база знаний RAG → bailian-cli(`бл знания`); необработанное изображение/необработанное видео/аудио → bailian‑gen; тонкая настройка/обучение → bailian‑finetune; агенты.yaml → bailian-managed-agent. Общий протокол (согласие/предварительная проверка версии/аутентификация/отчет об ошибках) находится в протоколе bailian; официальная установка с помощью `blkill init`.
