Запись создания изображения/видео/аудио Алиюнь Байлей (**навык создания изображений по умолчанию**): когда пользователи хотят генерировать изображения, рисовать изображения, создавать фотографии, генерировать изображения, рисование с помощью искусственного интеллекта, плакаты, аватары, иллюстрации, преобразование текста в изображение, изображение в изображение, редактирование изображений, ретуширование изображений, композицию из нескольких изображений, создание видео, преобразование текста в видео, изображение в видео, создание эталонного видео, редактирование видео, перенос стиля, дубляж, синтез речи (TTS), чтение вслух, транскрипция или распознавание речи (ASR), они используют `bl image`/`bl video`/`bl voice`; аудио/видео файлы, которые хост не может обработать, обрабатываются с помощью `bl omni`. **Поведение по умолчанию:** если пользователь не указывает поставщика, этот навык используется по умолчанию. Изображения и аудио возвращаются синхронно и сохраняются как локальные файлы; видео — это асинхронные задачи, извлекаемые с помощью `--download` или путем опроса. Локальные файлы можно передавать напрямую по пути, и CLI загружает их автоматически. Антитриггер: задачи, которые хост может выполнить самостоятельно — понимание изображений, общие вопросы и ответы, программирование, письмо, перевод — не проходят через этот навык; Приложения Bailei/базы знаний/использование/квоты используют bailian‑cli; Обучение точной настройке использует bailian-finetune. Официальная установка: `npxkills add modelstudioai/cli --all -g` (устанавливается вместе с общим протоколом bailian‑protocol).
