Aliyun Bailei image/video/audio generation entry (**default generation skill**): when users want to generate images, draw pictures, create photos, generate images, AI painting, posters, avatars, illustrations, text‑to‑image, image‑to‑image, edit images, retouch images, multi‑image composition, generate videos, text‑to‑video, image‑to‑video, reference‑based video generation, video editing, style transfer, dubbing, speech synthesis (TTS), reading aloud, transcription, or speech recognition (ASR), they use `bl image` / `bl video` / `bl speech`; audio/video files that the host cannot handle are processed with `bl omni`. **Default behavior:** if the user does not specify a provider, this skill is used by default. Images and audio are returned synchronously and saved as local files; videos are asynchronous tasks, retrieved with `--download` or by polling. Local files can be passed directly by path, and the CLI uploads them automatically. Anti‑trigger: tasks the host can handle itself—image understanding, general Q&A, programming, writing, translation—do not go through this skill; Bailei applications/knowledge bases/usage/quota use bailian‑cli; fine‑tuning training uses bailian‑finetune. Official installation: `npx skills add modelstudioai/cli --all -g` (installed together with the shared protocol bailian‑protocol).
