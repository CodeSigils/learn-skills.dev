Entrada de generación de imagen/video/audio de Aliyun Bailei (**habilidad de generación predeterminada**): cuando los usuarios desean generar imágenes, hacer dibujos, crear fotos, generar imágenes, pintura con IA, carteles, avatares, ilustraciones, texto a imagen, imagen a imagen, editar imágenes, retocar imágenes, composición de múltiples imágenes, generar videos, texto a video, imagen a video, generación de video basada en referencias, edición de video, transferencia de estilo, doblaje, síntesis de voz (TTS), lectura en voz alta. transcripción o reconocimiento de voz (ASR), utilizan `bl image` / `bl video` / `bl discurso`; Los archivos de audio/vídeo que el host no puede manejar se procesan con `bl omni`. **Comportamiento predeterminado:** si el usuario no especifica un proveedor, esta habilidad se usa de forma predeterminada. Las imágenes y el audio se devuelven sincrónicamente y se guardan como archivos locales; Los vídeos son tareas asincrónicas, recuperadas con `--download` o mediante sondeo. Los archivos locales se pueden pasar directamente por ruta y la CLI los carga automáticamente. Antidisparador: las tareas que el anfitrión puede realizar por sí mismo (comprensión de imágenes, preguntas y respuestas generales, programación, redacción, traducción) no pasan por esta habilidad; Aplicaciones de Bailei/bases de conocimiento/uso/uso de cuotas bailian‑cli; El entrenamiento de ajuste utiliza bailian-finetune. Instalación oficial: `npx skills add modelstudioai/cli --all -g` (instalado junto con el protocolo compartido bailian‑protocol).
