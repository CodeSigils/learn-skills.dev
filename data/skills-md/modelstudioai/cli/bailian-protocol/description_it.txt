Protocollo di esecuzione condiviso della famiglia Alibaba Cloud Bailei `bl` (conferma del consenso, controllo preliminare della versione, autenticazione/installazione, segnalazione degli errori, file locali e convenzioni di output). Non è un punto di ingresso aziendale orientato alle intenzioni dell'utente; viene letto quando qualsiasi competenza aziendale bailian‑* (bailian‑cli / bailian‑gen / bailian‑finetune / bailian‑activated‑agent) richiede un contesto comune prima dell'esecuzione o quando un utente installa/autentica per la prima volta o deve segnalare un errore "bl". L'installazione ufficiale è un pacchetto completo: `npx skills add modelstudioai/cli --all -g` (installato insieme a business skills); Competenze agente/`npx skills` non estrarrà automaticamente le dipendenze in base ai metadati.
