Alibaba Cloud Bailian “bl” 제품군 공유 실행 프로토콜(동의 확인, 버전 사전 확인, 인증/설치, 오류 보고, 로컬 파일 및 출력 규칙). 이는 사용자 의도 지향적인 비즈니스 진입점이 아닙니다. bailian-* 비즈니스 기술(bailian-cli / bailian-gen / bailian-finetune / bailian-managed-agent)이 실행되기 전에 공통 컨텍스트가 필요한 경우 또는 사용자가 처음 설치/인증하거나 'bl' 오류를 보고해야 하는 경우에 읽혀집니다. 공식 설치는 전체 패키지로 이루어집니다. `npx Skills add modelstudioai/cli --all -g`(비즈니스 스킬과 함께 설치됨); 상담원 기술/`npx 기술`은 메타데이터를 기반으로 종속성을 자동으로 가져오지 않습니다.
