Alibaba Cloud Bailian 「bl」ファミリーの共有実行プロトコル (同意の確認、バージョンの事前チェック、認証/インストール、エラー報告、ローカル ファイルと出力規則)。これはユーザーの意図を重視したビジネス エントリ ポイントではありません。これは、任意の bailian-* ビジネス スキル (bailian-cli / bailian-gen / bailian-finetune / bailian-managed-agent) が実行前に共通のコンテキストを必要とするとき、またはユーザーが最初にインストール/認証するとき、あるいは「bl」エラーを報告する必要があるときに読み取られます。公式インストールはパッケージ全体です: `npx skill add modelstudioai/cli --all -g` (ビジネス スキルと一緒にインストールされます)。エージェント スキル / `npx スキル` は、メタデータに基づいて依存関係を自動的に取得しません。
