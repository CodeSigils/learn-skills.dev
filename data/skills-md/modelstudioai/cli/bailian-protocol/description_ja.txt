Alibaba Cloud Bairei `bl` ファミリーの共有実行プロトコル (同意の確認、バージョンの事前チェック、認証/インストール、エラー報告、ローカル ファイルと出力の規則)。これは、ユーザーの意図を意図したビジネス エントリ ポイントではありません。これは、任意の bailian-* ビジネス スキル (bailian-cli / bailian-gen / bailian-finetune / bailian-managed-agent) が実行前に共通のコンテキストを必要とする場合、またはユーザーの最初のインストール/認証または「bl」エラーを報告する必要がある場合に読み取られます。公式インストールは完全なパッケージとして行われます: `npx skill add modelstudioai/cli --all -g` (ビジネス スキルと一緒にインストールされます)。エージェント スキル / `npx スキル` は、メタデータに基づいて依存関係を自動的に取得しません。
