بروتوكول التنفيذ المشترك لعائلة Alibaba Cloud Bailei `bl` (تأكيد الموافقة، والفحص المسبق للإصدار، والمصادقة/التثبيت، والإبلاغ عن الأخطاء، واتفاقيات الملف والإخراج المحلي). إنها ليست نقطة دخول تجارية تستهدف نية المستخدم؛ تتم قراءتها بواسطة أي مهارات عمل Bailian-* (bailian-cli / Bailian-gen / Bailian-finetune / Bailian-managed-agent) عندما يكون السياق العام مطلوبًا قبل التنفيذ، أو عندما يلزم الإبلاغ عن خطأ التثبيت/المصادقة/"bl" الأول للمستخدم. التثبيت الرسمي عبارة عن حزمة كاملة: `npx Skills addmodelstudioai/cli --all -g` (مثبت مع مهارات العمل)؛ لن تقوم مهارات الوكيل / `` مهارات npx '' بسحب التبعيات تلقائيًا وفقًا للبيانات التعريفية.
