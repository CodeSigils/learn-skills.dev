بروتوكول التنفيذ المشترك لعائلة Alibaba Cloud Bailei `bl` (تأكيد الموافقة، والفحص المسبق للإصدار، والمصادقة/التثبيت، والإبلاغ عن الأخطاء، واصطلاحات الملفات والمخرجات المحلية). إنها ليست نقطة دخول تجارية مخصصة لنية المستخدم؛ تتم قراءتها عندما تتطلب أي مهارة عمل Bailian‑* (bailian‑cli / Bailian‑gen / Bailian‑finetune / Bailian‑managed‑agent) سياقًا شائعًا قبل التنفيذ، أو عندما يلزم الإبلاغ عن التثبيت/المصادقة الأولى للمستخدم أو خطأ `bl`. التثبيت الرسمي عبارة عن حزمة كاملة: `npx Skills addmodelstudioai/cli --all -g` (مثبت مع مهارات العمل)؛ لن تقوم مهارات الوكيل / "مهارات npx" بسحب التبعيات تلقائيًا بناءً على البيانات التعريفية.
