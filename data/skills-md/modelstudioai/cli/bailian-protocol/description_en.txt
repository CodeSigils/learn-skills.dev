Alibaba Cloud Bailei `bl` family shared execution protocol (consent confirmation, version pre‑check, authentication/installation, error reporting, and conventions for local files and outputs). It is not a business entry point intended for user intent; it is read when any bailian‑* business skill (bailian‑cli / bailian‑gen / bailian‑finetune / bailian‑managed‑agent) requires a common context before execution, or when a user’s first installation/authentication or a `bl` error needs to be reported. Official installation is as a full package: `npx skills add modelstudioai/cli --all -g` (installed together with business skills); Agent Skills / `npx skills` will not automatically pull dependencies based on metadata.
