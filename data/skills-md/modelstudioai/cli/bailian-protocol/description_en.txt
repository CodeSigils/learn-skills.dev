Alibaba Cloud Bailian “bl” family shared execution protocol (consent confirmation, version pre‑check, authentication/installation, error reporting, local file and output conventions). It is not a user‑intent‑oriented business entry point; it is read when any bailian‑* business skill (bailian‑cli / bailian‑gen / bailian‑finetune / bailian‑managed‑agent) requires a common context before execution, or when a user first installs/authenticates or needs to report a `bl` error. The official installation is as a whole package: `npx skills add modelstudioai/cli --all -g` (installed together with business skills); Agent Skills / `npx skills` will not automatically pull dependencies based on metadata.
