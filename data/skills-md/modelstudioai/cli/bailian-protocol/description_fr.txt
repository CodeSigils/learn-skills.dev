Protocole d'exécution partagé de la famille Alibaba Cloud Bailei `bl` (confirmation du consentement, vérification préalable de la version, authentification/installation, rapport d'erreurs et conventions pour les fichiers et sorties locaux). Il ne s'agit pas d'un point d'entrée commercial destiné à l'intention de l'utilisateur ; il est lu lorsqu'une compétence métier bailian-* (bailian-cli / bailian-gen / bailian-finetune / bailian-managed-agent) nécessite un contexte commun avant l'exécution, ou lorsque la première installation/authentification d'un utilisateur ou une erreur `bl` doit être signalée. L'installation officielle se présente sous la forme d'un package complet : `npx skills add modelstudioai/cli --all -g` (installé avec les compétences commerciales) ; Les compétences d'agent / « compétences npx » n'extraireont pas automatiquement les dépendances basées sur les métadonnées.
