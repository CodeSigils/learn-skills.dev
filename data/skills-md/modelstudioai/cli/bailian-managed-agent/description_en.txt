Alibaba Cloud Bailian Managed Agent declarative infrastructure entry point: users use `bl managed-agent` to create agents, initialize agents.yaml, validate or preview agent configuration changes, create/update/destroy Bailian managed agents, converse with managed agents, check session event history, and import or untrack remote resources. Treat agents.yaml as the single source of truth for IaC: `init` builds scaffolding, `validate` performs offline validation, `plan` previews diffs, and `apply`/`destroy` modify remote resources and must include `--yes`; always run `plan` first to show the diff to the user before confirming. Anti‑trigger: invoke already deployed Bailian apps/agents via `bailian-app-call` or `bl app`; the host agent’s own memory, skills, and sub‑agents do not use this skill; image and video generation uses `bailian-gen`. Official installation: `npx skills add modelstudioai/cli --all -g` (install together with the shared protocol `bailian-protocol`).
