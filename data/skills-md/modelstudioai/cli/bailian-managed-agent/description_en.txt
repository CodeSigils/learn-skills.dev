Alibaba Cloud Baichuan Managed Agent declarative infrastructure entry point: users create agents, initialize agents.yaml, validate or preview agent configuration changes, create/update/destroy Baichuan Managed Agents, interact with the managed agent, view session event history, and import or cancel tracking of remote resources using `bl managed-agent`. Use agents.yaml as the single source of truth for IaC: init to scaffold, validate for offline checks, plan to preview diffs, apply/destroy to change remote resources and must include `--yes`; always plan first to show the diff to the user before confirmation. Anti‑trigger: call already deployed Baichuan applications/agents via bailian-app-call or `bl app`; the host agent’s own memory, skills, and sub‑agents do not use this skill; image and video generation use bailian-gen. Official installation: `npx skills add modelstudioai/cli --all -g` (installed together with the shared protocol bailian-protocol).
