阿里云百川托管代理声明式基础设施入口点：用户创建代理、初始化agents.yaml、验证或预览代理配置更改、创建/更新/销毁百川托管代理、与托管代理交互、查看会话事件历史记录以及使用“bl Managed-agent”导入或取消对远程资源的跟踪。使用agents.yaml作为IaC的单一事实来源：初始化脚手架、验证离线检查、计划预览差异、应用/销毁以更改远程资源，并且必须包含“--yes”；在确认之前，始终首先计划向用户显示差异。反触发：通过 bailian-app-call 或 `bl app` 调用已部署的百川应用/代理；主机智能体自己的记忆、技能和子智能体不使用该技能；图像和视频生成使用bailian-gen。官方安装：`npx Skills add modelstudioai/cli --all -g`（与共享协议bailian-protocol一起安装）。
