Point d'entrée de l'infrastructure déclarative de l'agent géré Alibaba Cloud Bailian : les utilisateurs utilisent « bl géré-agent » pour créer des agents, initialiseragents.yaml, valider ou prévisualiser les modifications de configuration de l'agent, créer/mettre à jour/détruire les agents gérés Bailian, converser avec les agents gérés, vérifier l'historique des événements de session et importer ou annuler le suivi des ressources distantes. Treatagents.yaml comme source unique de vérité pour IaC : `init` construit un échafaudage, `validate` effectue une validation hors ligne, `plan` prévisualise les différences et `apply`/`destroy` modifie les ressources distantes et doit inclure `--yes` ; exécutez toujours `plan` en premier pour montrer la différence à l'utilisateur avant de confirmer. Anti-déclencheur : invoquez des applications/agents Bailian déjà déployés via `bailian-app-call` ou `bl app` ; la propre mémoire, les compétences et les sous-agents de l’agent hôte n’utilisent pas cette compétence ; la génération d'images et de vidéos utilise « bailian-gen ». Installation officielle : `npx skills add modelstudioai/cli --all -g` (installer avec le protocole partagé `bailian-protocol`).
