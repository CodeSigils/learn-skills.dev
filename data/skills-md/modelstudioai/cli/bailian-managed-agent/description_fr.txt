Point d'entrée de l'infrastructure déclarative d'Alibaba Cloud Baichuan Managed Agent : les utilisateurs créent des agents, initialisent agents.yaml, valident ou prévisualisent les modifications de configuration de l'agent, créent/mettent à jour/détruisent les agents gérés Baichuan, interagissent avec l'agent géré, visualisent l'historique des événements de session et importent ou annulent le suivi des ressources distantes à l'aide de « bl géré-agent ». Utilisez agents.yaml comme source unique de vérité pour IaC : initialisez l'échafaudage, validez pour les vérifications hors ligne, prévoyez de prévisualiser les différences, appliquez/détruisez pour modifier les ressources distantes et devez inclure "--yes" ; prévoyez toujours d'abord de montrer la différence à l'utilisateur avant la confirmation. Anti-déclencheur : appelez les applications/agents Baichuan déjà déployés via bailian-app-call ou `bl app` ; la propre mémoire, les compétences et les sous-agents de l’agent hôte n’utilisent pas cette compétence ; la génération d'images et de vidéos utilise bailian-gen. Installation officielle : `npx skills add modelstudioai/cli --all -g` (installé avec le protocole partagé bailian-protocol).
