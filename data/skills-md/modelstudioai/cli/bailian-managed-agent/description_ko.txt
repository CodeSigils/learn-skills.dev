Alibaba Cloud Baichuan 관리형 에이전트 선언적 인프라 진입점: 사용자는 에이전트 생성, Agent.yaml 초기화, 에이전트 구성 변경 확인 또는 미리보기, Baichuan 관리형 에이전트 생성/업데이트/삭제, 관리형 에이전트와 상호 작용, 세션 이벤트 기록 보기, 'bl Managed-agent'를 사용하여 원격 리소스 추적 가져오기 또는 취소 등을 수행합니다. IaC의 단일 정보 소스로 Agent.yaml을 사용합니다. 스캐폴드 초기화, 오프라인 검사 유효성 검사, 차이점 미리 보기 계획, 원격 리소스 변경을 위한 적용/삭제, `--yes`를 포함해야 합니다. 항상 확인하기 전에 먼저 사용자에게 차이점을 보여줄 계획을 세우십시오. 안티 트리거: bailian-app-call 또는 'bl app'을 통해 이미 배포된 Baichuan 애플리케이션/에이전트를 호출합니다. 호스트 에이전트의 자체 메모리, 스킬 및 하위 에이전트는 이 스킬을 사용하지 않습니다. 이미지 및 비디오 생성은 bailian-gen을 사용합니다. 공식 설치: `npx Skills add modelstudioai/cli --all -g`(공유 프로토콜 bailian-protocol과 함께 설치됨)
