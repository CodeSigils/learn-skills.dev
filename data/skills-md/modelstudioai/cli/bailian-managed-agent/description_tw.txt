阿里雲百川託管代理聲明式基礎設施入口點：用戶創建代理、初始化agents.yaml、驗證或預覽代理配置更改、創建/更新/銷毀百川託管代理、與託管代理交互、查看會話事件歷史記錄以及使用“bl Managed-agent”導入或取消對遠端資源的追蹤。使用agents.yaml作為IaC的單一事實來源：初始化腳手架、驗證離線檢查、計劃預覽差異、應用/銷毀以更改遠端資源，並且必須包含「--yes」；在確認之前，請務必先計劃向使用者顯示差異。反觸發：透過 bailian-app-call 或 `bl app` 呼叫已部署的百川應用程式/代理；主機智能體本身的記憶、技能和子智能體不使用該技能；圖像和視訊生成使用bailian-gen。安裝官方：`npx Skills add modelstudioai/cli --all -g`（與共用協定bailian-protocol一起安裝）。
