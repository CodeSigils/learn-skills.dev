Alibaba Cloud Baichuan 管理対象エージェントの宣言型インフラストラクチャ エントリ ポイント: ユーザーは、エージェントの作成、agents.yaml の初期化、エージェント設定の変更の検証またはプレビュー、Baichuan 管理対象エージェントの作成/更新/破棄、管理対象エージェントとの対話、セッション イベント履歴の表示、「bl 管理対象エージェント」を使用したリモート リソースのインポートまたは追跡のキャンセルを行います。 IaC の信頼できる唯一の情報源として、agents.yaml を使用します。スキャフォールディングのための init、オフライン チェックの検証、差分のプレビューの計画、リモート リソースの変更のための適用/破棄、および `--yes` を含める必要があります。確認する前に、必ずユーザーに差分を表示するように計画してください。アンチトリガー: bailian-app-call または `bl app` を介して、すでにデプロイされている Baichuan アプリケーション/エージェントを呼び出します。ホスト エージェント自身のメモリ、スキル、サブエージェントはこのスキルを使用しません。画像とビデオの生成はbairian-genを使用します。公式インストール: `npx skill add modelstudioai/cli --all -g` (共有プロトコル baiilian-protocol と一緒にインストールされます)。
