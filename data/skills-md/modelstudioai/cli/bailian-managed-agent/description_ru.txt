Точка входа в декларативную инфраструктуру управляемого агента Alibaba Cloud Baichuan: пользователи создают агентов, инициализируют агенты.yaml, проверяют или просматривают изменения конфигурации агента, создают/обновляют/уничтожают управляемые агенты Baichuan, взаимодействуют с управляемым агентом, просматривают историю событий сеанса, а также импортируют или отменяют отслеживание удаленных ресурсов с помощью `bl Managed-Agent`. Используйте агенты.yaml как единый источник достоверных данных для IaC: инициализация для создания шаблонов, проверка для автономных проверок, планирование предварительного просмотра различий, применение/уничтожение для изменения удаленных ресурсов и должно включать `--yes`; всегда планируйте сначала показать разницу пользователю перед подтверждением. Антитриггер: вызов уже развернутых приложений/агентов Baichuan через bailian-app-call или `bl app`; собственная память, навыки и субагенты хост-агента не используют этот навык; Для создания изображений и видео используется bailian-gen. Официальная установка: `npxkills add modelstudioai/cli --all -g` (устанавливается вместе с общим протоколом bailian-protocol).
