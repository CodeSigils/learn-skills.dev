Точка входа в декларативную инфраструктуру управляемого агента Alibaba Cloud Bailei: пользователи используют `bl Managed-Agent` для создания агентов, инициализации `agents.yaml`, проверки или предварительного просмотра изменений конфигурации агента, создания/обновления/уничтожения управляемых агентов Bailei, общения с управляемым агентом, запроса истории событий сеанса, а также импорта или отмены отслеживания удаленных ресурсов. Используйте `agents.yaml` как единственный источник достоверной информации для IaC: `init` создает каркас, `validate` выполняет автономную проверку, `plan` просматривает различия, `apply`/`destroy` изменяет удаленные ресурсы и должен запускаться с `--yes`; всегда сначала запускайте `plan`, чтобы показать пользователю разницу перед подтверждением. Антитриггер: вызов уже развернутого приложения/агента Bailei использует `bailian-app-call` или `bl app`; собственная память, навыки и субагенты хост-агента не проходят через этот навык; для создания изображений или видео используется bailian-gen. Официальная установка: `npxkills add modelstudioai/cli --all -g` (устанавливается вместе с общим протоколом `bailian-protocol`).
