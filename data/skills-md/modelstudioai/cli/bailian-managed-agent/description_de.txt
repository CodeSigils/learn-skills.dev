Einstiegspunkt für die deklarative Infrastruktur des Alibaba Cloud Baichuan Managed Agent: Benutzer erstellen Agenten, initialisieren Agents.yaml, validieren oder zeigen eine Vorschau von Agentenkonfigurationsänderungen an, erstellen/aktualisieren/zerstören Baichuan Managed Agents, interagieren mit dem verwalteten Agenten, zeigen den Sitzungsereignisverlauf an und importieren oder brechen die Verfolgung von Remote-Ressourcen mithilfe von „bl managed-agent“ ab. Verwenden Sie Agents.yaml als Single Source of Truth für IaC: Init für Gerüstbau, Validierung für Offline-Prüfungen, Plan zur Vorschau von Unterschieden, Anwenden/Zerstören, um Remote-Ressourcen zu ändern, und muss „--yes“ enthalten; Planen Sie immer zunächst, dem Benutzer den Unterschied vor der Bestätigung anzuzeigen. Anti-Trigger: Rufen Sie bereits bereitgestellte Baichuan-Anwendungen/Agenten über bailian-app-call oder „bl app“ auf; Das eigene Gedächtnis, die Fähigkeiten und die Unteragenten des Host-Agenten nutzen diese Fähigkeit nicht. Bild- und Videogenerierung verwenden Bailian-Gen. Offizielle Installation: `npx skills add modelstudioai/cli --all -g` (wird zusammen mit dem gemeinsamen Protokoll bailian-protocol installiert).
