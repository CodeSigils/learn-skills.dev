Spezifikationsgesteuerte Entwicklung (SDD) für KI-Codierungsassistenten (Claude, Antigravity, OpenCode, Cursor, Codex, Gemini). Kehrt die Leistungsdynamik um, sodass der Code ausführbare Spezifikationen erfüllt. Bietet vollständige Arbeitsabläufe für Baseline, Erstellung, Spezifizierung, Klärung, Planung, Aufgaben, Implementierung, Checkliste, Analyse und Konvergenz.
