Навыки разработки на основе спецификаций (SDD) для помощников по программированию на базе искусственного интеллекта (Claude, Antigradity, OpenCode, Cursor, Codex, Gemini). Инвертирует динамику мощности, чтобы код соответствовал исполняемым спецификациям. Обеспечивает полные рабочие процессы для базового состояния, составления, определения, уточнения, планирования, задач, реализации, контрольного списка, анализа и конвергенции.
