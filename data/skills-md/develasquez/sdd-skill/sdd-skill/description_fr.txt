Compétence de développement piloté par les spécifications (SDD) pour les assistants de codage d'IA (Claude, Antigravity, OpenCode, Cursor, Codex, Gemini). Inverse la dynamique de puissance afin que le code serve les spécifications exécutables. Fournit des flux de travail complets pour la référence, la constitution, la spécification, la clarification, la planification, les tâches, la mise en œuvre, la liste de contrôle, l'analyse et la convergence.
