Utilice esta habilidad cuando necesite un contexto de base de código semántico antes de planificar, explicar o cambiar el código del proyecto. Ejecuta un script Fast Context local incluido que llama a Windsurf Devstral directamente, evitando el servidor MCP Fast Context y al mismo tiempo conserva la búsqueda de repositorios en lenguaje natural, la recopilación de contexto recursivo y las comprobaciones de integridad de definiciones/firmas.
