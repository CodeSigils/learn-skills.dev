Utilisez cette compétence lorsque vous avez besoin d'un contexte de base de code sémantique avant de planifier, d'expliquer ou de modifier le code du projet. Il exécute un script Fast Context local intégré qui appelle directement Windsurf Devstral, évitant ainsi le serveur Fast Context MCP tout en préservant la recherche dans le référentiel en langage naturel, la collecte de contexte récursive et les vérifications d'exhaustivité des définitions/signatures.
