OpenAI Harness Engineering に基づいた、エージェントに最適化されたドキュメント システム。エージェントの可読性を最大限に高めるために、AGENTS.md + docs/ ディレクトリを監査、作成、維持します。
トリガー: AGENTS.md、ハーネス ドキュメント、エージェント ドキュメント、「ドキュメントの監査」、「ドキュメントのセットアップ」、ドキュメント システム、文档规范化、一键整理文档。また、「文書」について明示的に言及していなくても、エージェントの繰り返しの間違いやエージェントの行動に関するユーザーの苦情もトリガーします (例: 「また搞错了」、「X の間違いを繰り返しています」、「前にこれを言いました」)。これらの信号ドキュメントのギャップには更新が必要です。
