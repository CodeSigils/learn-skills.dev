Оптимизированная для агентов система документации на основе OpenAI Harness Engineering. Проверяет, создает и поддерживает каталоги AGENTS.md + docs/ для максимальной читаемости агентов.
ТРИГГЕРЫ: AGENTS.md, документация по агентам, «проверить мои документы», «настроить документацию», система документации, 文档规范化, 一键整理文档. Также срабатывает при повторяющихся ошибках агента или жалобах пользователей на поведение агента — даже без явного упоминания «документации» (например, «又搞错了», «он продолжает делать X неправильно», «Я говорил вам это раньше»). Эти пробелы в документации сигнализируют о необходимости обновления.
