Implémente la connexion SaaSKit dans le routeur d'applications Next.js afin qu'un agent puisse ajouter une connexion, un rappel, des cookies de session et une déconnexion. À utiliser lorsque l'utilisateur souhaite l'authentification SaaSKit Next.js ou App Router. Il n'écrit pas de connexion Node générique (c'est-à-dire `implement-saaskit`) ni n'écrit l'authentification Django, FastAPI ou Flask (c'est `implement-saaskit-python`).
