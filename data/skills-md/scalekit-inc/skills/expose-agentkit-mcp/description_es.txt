Expone las herramientas de AgentKit a través de MCP para que un cliente pueda llamarlas en una URL de instancia por usuario. Úselo cuando el usuario desee exponer AgentKit a través de MCP, generar una URL de MCP por usuario o conectar LangChain a través de MCP. No enumera los conectores (es decir, "discover-connectors") ni crea una cuenta conectada y un token en el código de la aplicación (es decir, "integrate-agentkit").
