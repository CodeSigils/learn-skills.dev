Предоставляет инструменты AgentKit через MCP, чтобы клиент мог вызывать их по URL‑адресу экземпляра для каждого пользователя. Используйте, когда пользователь хочет открыть доступ к AgentKit через MCP, сгенерировать MCP‑URL для каждого пользователя или подключить LangChain через MCP. Он не выводит список коннекторов (это `discover-connectors`) и не создаёт подключённый аккаунт и токен в коде приложения (это `integrate-agentkit`).
