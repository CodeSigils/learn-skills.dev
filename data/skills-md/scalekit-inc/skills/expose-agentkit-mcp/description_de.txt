Stellt AgentKit‑Tools über MCP bereit, sodass ein Client sie über eine pro‑Benutzer‑Instanz‑URL aufrufen kann. Verwenden Sie es, wenn der Benutzer AgentKit über MCP bereitstellen, eine pro‑Benutzer‑MCP‑URL generieren oder LangChain über MCP verbinden möchte. Es listet keine Connectoren auf (das ist `discover-connectors`) und erstellt kein verbundenes Konto und Token im Anwendungscode (das ist `integrate-agentkit`).
