يُظهر أدوات AgentKit عبر MCP بحيث يمكن للعميل استدعاؤها على عنوان URL خاص بكل مستخدم. يُستخدم عندما يرغب المستخدم في عرض AgentKit عبر MCP، أو إنشاء عنوان URL خاص بـ MCP لكل مستخدم، أو ربط LangChain عبر MCP. لا يُدرج الموصلات (هذا هو `discover-connectors`) ولا ينشئ حسابًا متصلاً ورمزًا مميزًا في كود التطبيق (هذا هو `integrate-agentkit`).
