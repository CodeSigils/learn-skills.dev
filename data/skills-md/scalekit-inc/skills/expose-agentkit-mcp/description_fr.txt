Expose les outils AgentKit via MCP afin qu’un client puisse les appeler sur une URL d’instance par utilisateur. À utiliser lorsque l’utilisateur veut exposer AgentKit via MCP, générer une URL MCP par utilisateur, ou connecter LangChain via MCP. Cela ne répertorie pas les connecteurs (c’est `discover-connectors`) et ne crée pas de compte connecté ni de jeton dans le code de l’application (c’est `integrate-agentkit`).
