Intègre AgentKit afin qu'un agent puisse créer une connexion, un compte connecté et un jeton autorisé, puis appeler une API en aval. À utiliser lorsque l'utilisateur souhaite AgentKit dans le code de l'application, un compte connecté Gmail/Slack/Notion ou un lien d'autorisation. Il ne répertorie pas les connecteurs (c'est-à-dire « discover-connectors ») et n'expose pas les outils sur MCP (c'est-à-dire « expose-agentkit-mcp »).
