Integra AgentKit para que un agente pueda crear una conexión, una cuenta conectada y un token autorizado, y luego llamar a una API downstream. Úselo cuando el usuario quiera AgentKit en el código de la aplicación, una cuenta conectada de Gmail/Slack/Notion o un enlace de autorización. No enumera conectores (eso es `discover-connectors`) ni expone herramientas a través de MCP (eso es `expose-agentkit-mcp`).
