Integriert AgentKit, sodass ein Agent eine Verbindung, ein verbundenes Konto und ein autorisiertes Token erstellen kann und dann eine nachgelagerte API aufruft. Verwenden Sie es, wenn der Benutzer AgentKit im Anwendungscode, ein verbundenes Gmail/Slack/Notion‑Konto oder einen Autorisierungslink möchte. Es listet keine Connectors auf (das ist `discover-connectors`) und stellt keine Werkzeuge über MCP bereit (das ist `expose-agentkit-mcp`).
