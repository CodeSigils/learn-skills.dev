Fügt API‑Key- oder Client‑Credentials‑Authentifizierung hinzu, damit ein Agent eine API schützen kann. Verwenden, wenn der Benutzer einen API‑Key oder Client‑Credentials möchte. Es wird nicht OAuth 2.1 auf einem MCP‑Server gesetzt (das ist `add-mcp-oauth`) und auch kein SaaSKit‑Login geschrieben (das ist `implement-saaskit`).
