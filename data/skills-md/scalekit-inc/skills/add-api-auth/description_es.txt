Agrega autenticación con clave API o credenciales de cliente para que un agente pueda proteger una API. Úsalo cuando el usuario desea una clave API o credenciales de cliente. No instala OAuth 2.1 en un servidor MCP (eso es `add-mcp-oauth`) ni escribe el inicio de sesión de SaaSKit (eso es `implement-saaskit`).
