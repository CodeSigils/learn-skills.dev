Ajoute une authentification par clé API ou credentials client afin qu’un agent puisse protéger une API. À utiliser lorsque l’utilisateur souhaite une clé API ou des identifiants client. Cela ne place pas OAuth 2.1 sur un serveur MCP (c’est `add-mcp-oauth`) ni n’écrit la connexion SaaSKit (c’est `implement-saaskit`).
