Добавляет аутентификацию с использованием API‑ключа или клиентских учётных данных, чтобы агент мог защитить API. Используется, когда пользователь хочет API‑ключ или клиентские учётные данные. Это не устанавливает OAuth 2.1 на сервере MCP (это `add-mcp-oauth`) и не реализует вход в SaaSKit (это `implement-saaskit`).
