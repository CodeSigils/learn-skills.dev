Ejecuta una simulación (dryrun) para que un agente pueda probar una configuración de autenticación de SaaSKit antes del lanzamiento. Se usa cuando el usuario quiere probar la autenticación o ejecutar una simulación. No escribe el inicio de sesión (eso es `implement-saaskit`) ni completa una lista de verificación para el lanzamiento (eso es `check-saaskit-prod`).
