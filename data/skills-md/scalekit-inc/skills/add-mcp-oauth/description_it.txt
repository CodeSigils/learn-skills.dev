Aggiunge MCP OAuth così un agente può proteggere il server MCP dell'utente. Da usare quando l'utente desidera MCP OAuth o proteggere il proprio server MCP. Non aggiunge chiavi API o credenziali client (questo è `add-api-auth`) né espone gli strumenti AgentKit tramite MCP (questo è `expose-agentkit-mcp`).
