Añade OAuth de MCP para que un agente pueda proteger el servidor MCP del usuario. Úsalo cuando el usuario quiera OAuth de MCP o proteger su servidor MCP. No agrega claves API ni credenciales de cliente (eso es `add-api-auth`) ni expone herramientas de AgentKit a través de MCP (eso es `expose-agentkit-mcp`).
