Добавляет MCP OAuth, чтобы агент мог защищать MCP‑сервер пользователя. Используйте, когда пользователь хочет MCP OAuth или защитить свой MCP‑сервер. Он не добавляет API‑ключи или клиентские учётные данные (это `add-api-auth`) и не раскрывает инструменты AgentKit через MCP (это `expose-agentkit-mcp`).
