Fügt MCP OAuth hinzu, damit ein Agent den MCP-Server des Benutzers schützen kann. Verwenden Sie diese Option, wenn der Benutzer MCP OAuth wünscht oder seinen MCP-Server schützen möchte. Es fügt keine API-Schlüssel oder Client-Anmeldeinformationen hinzu (das ist „add-api-auth“) und stellt keine AgentKit-Tools über MCP bereit (das ist „expose-agentkit-mcp“).
