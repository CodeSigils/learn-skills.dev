Ajoute MCP OAuth afin qu’un agent puisse protéger le serveur MCP de l’utilisateur. À utiliser lorsque l’utilisateur souhaite MCP OAuth ou protéger son serveur MCP. Cela n’ajoute pas de clés API ou d’identifiants client (c’est `add‑api‑auth`) ni n’expose les outils AgentKit via MCP (c’est `expose‑agentkit‑mcp`).
