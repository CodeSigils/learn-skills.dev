Configure SaaSKit pour qu'un projet dispose d'informations d'identification d'environnement, d'un URI de redirection et d'une première URL de connexion. À utiliser lorsque l'utilisateur souhaite configurer SaaSKit ou ajouter une connexion à cette application. Il n'installe pas la CLI (c'est `setup-scalekit`) et n'écrit pas de code de connexion/rappel/session (c'est `implement-saaskit`).
