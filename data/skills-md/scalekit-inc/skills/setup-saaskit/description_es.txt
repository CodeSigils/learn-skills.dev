Configura SaaSKit para que un proyecto tenga credenciales de entorno, una URI de redirección y una URL de primer inicio de sesión. Úsalo cuando el usuario quiera configurar SaaSKit o añadir inicio de sesión a esta aplicación. No instala el CLI (eso es `setup-scalekit`) ni escribe el código de inicio de sesión/callback/sesión (eso es `implement-saaskit`).
