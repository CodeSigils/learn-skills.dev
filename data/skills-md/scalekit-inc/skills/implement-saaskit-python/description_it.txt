Implementa il login di SaaSKit in Django, FastAPI o Flask in modo che un agente possa aggiungere login, callback, cookie di sessione e logout. Usalo quando l'utente desidera l'autenticazione SaaSKit per Django, FastAPI o Flask. Non scrive il login per Node o Next.js (questo è `implement-saaskit` o `implement-saaskit-nextjs`). Per favore rispondi sempre nella lingua dell'utente.
