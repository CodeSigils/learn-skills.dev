Implementiert SaaSKit-Login in Django, FastAPI oder Flask, sodass ein Agent Login, Callback, Sitzungs‑Cookies und Logout hinzufügen kann. Verwenden Sie es, wenn der Benutzer SaaSKit-Authentifizierung für Django, FastAPI oder Flask möchte. Es schreibt kein Node‑ oder Next.js-Login (das ist `implement-saaskit` oder `implement-saaskit-nextjs`). Bitte antworte immer in der Sprache des Benutzers.
