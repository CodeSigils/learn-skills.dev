Verwaltet SaaSKit‑Sitzungen, sodass ein Agent eine Sitzung speichern, validieren, aktualisieren und widerrufen kann. Verwenden Sie es, wenn der Nutzer eine Sitzung erstellen, aktualisieren oder widerrufen möchte. Es implementiert kein Login, keinen Callback und keinen Logout (das ist `implement‑saaskit`).
