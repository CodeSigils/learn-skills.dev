Интеграция и запрос API данных TradingView (RapidAPI tradeview-data1). Используйте, когда пользователю нужны рыночные данные любого рода — цены и свечи на акции/крипто/форекс/фьючерсы, котировки в реальном времени, фундаментальные и финансовые показатели компании, технический анализ, поиск рынка/символов, новости, идеи сообщества, списки лидеров (выигравших/проигравших/движущих на рынке), скринеры акций или криптовалют, экономические календари (доходы/IPO/дивиденды/макрособытия), индикаторы мировой экономики, логотипы символов или потоковая передача в реальном времени через ССЕ/Вебсокет. Также используйте, когда разработчик спрашивает, как вызывать, интегрировать или выбирать между конечными точками API TradingView, какие параметры использовать или откуда берутся значения параметров (рынки, вкладки, наборы столбцов, языки, поля скрининга).
