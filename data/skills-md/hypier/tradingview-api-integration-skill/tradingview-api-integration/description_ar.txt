التكامل مع واجهة برمجة تطبيقات TradingView Data والاستعلام عنها (RapidAPI Tradingview-data1) والاستعلام عنها. استخدمها عندما يريد المستخدم بيانات السوق من أي نوع - أسعار الأسهم/العملات المشفرة/الفوركس/العقود الآجلة والشمعدانات، وعروض الأسعار في الوقت الفعلي، وأساسيات الشركة وبياناتها المالية، والتحليل الفني، والبحث في السوق/الرموز، والأخبار، وأفكار المجتمع، ولوحات المتصدرين (الرابحون/الخاسرون/محركو السوق)، وشاشات الأسهم أو العملات المشفرة، والتقويمات الاقتصادية (الأرباح/الاكتتاب العام/أرباح الأسهم/الأحداث الكلية)، ومؤشرات الاقتصاد العالمي، وشعارات الرموز، أو البث في الوقت الفعلي عبر إس إس إي/ويب سوكيت. يُستخدم أيضًا عندما يسأل المطور عن كيفية الاتصال أو التكامل أو الاختيار بين نقاط نهاية TradingView API، أو المعلمات التي يجب استخدامها، أو من أين تأتي قيم المعلمات (الأسواق، علامات التبويب، مجموعات الأعمدة، اللغات، حقول الفرز).
