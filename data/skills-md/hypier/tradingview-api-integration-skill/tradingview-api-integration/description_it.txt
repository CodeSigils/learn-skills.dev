Integra ed esegui query sull'API TradingView Data (RapidAPI tradingview-data1). Da utilizzare quando l'utente desidera dati di mercato di qualsiasi tipo: prezzi e candele di azioni/cripto/forex/future, quotazioni in tempo reale, fondamentali aziendali e dati finanziari, analisi tecniche, ricerca di mercato/simboli, notizie, idee della community, classifiche (vincitori/perdenti/movimenti del mercato), screener di azioni o criptovalute, calendari economici (guadagni/IPO/dividendi/macro eventi), indicatori dell'economia mondiale, loghi di simboli o streaming in tempo reale tramite SSE/WebSocket. Da utilizzare anche quando uno sviluppatore chiede come chiamare, integrare o scegliere tra gli endpoint API TradingView, quali parametri utilizzare o da dove provengono i valori dei parametri (mercati, schede, set di colonne, lingue, campi di screening).
