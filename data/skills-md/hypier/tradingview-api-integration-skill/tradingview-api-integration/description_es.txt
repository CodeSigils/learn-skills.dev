Integre y consulte la API de datos TradingView (RapidAPI tradingview-data1). Úselo cuando el usuario desee datos de mercado de cualquier tipo: precios y velas de acciones/criptomonedas/forex/futuros, cotizaciones en tiempo real, fundamentos y finanzas de la empresa, análisis técnico, búsqueda de mercados/símbolos, noticias, ideas comunitarias, tablas de clasificación (ganadores/perdedores/movimientos del mercado), evaluadores de acciones o criptomonedas, calendarios económicos (ganancias/IPO/dividendos/evento macro), indicadores de la economía mundial, logotipos de símbolos o transmisión en tiempo real a través de SSE/WebSocket. Úselo también cuando un desarrollador pregunta cómo llamar, integrar o elegir entre los puntos finales de la API de TradingView, qué parámetros usar o de dónde provienen los valores de los parámetros (mercados, pestañas, conjuntos de columnas, idiomas, campos de filtrado).
