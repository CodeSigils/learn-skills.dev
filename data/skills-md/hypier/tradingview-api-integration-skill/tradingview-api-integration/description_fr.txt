Intégrez et interrogez l'API TradingView Data (RapidAPI tradingview-data1). À utiliser lorsque l'utilisateur souhaite obtenir des données de marché de toute nature : prix et chandeliers d'actions/crypto/forex/à terme, cotations en temps réel, fondamentaux et données financières de l'entreprise, analyse technique, recherche de marché/symbole, actualités, idées de communauté, classements (gainants/perdants/moteurs du marché), filtres d'actions ou de crypto, calendriers économiques (bénéfices/introduction en bourse/dividendes/événements macro), indicateurs de l'économie mondiale, logos de symboles ou diffusion en temps réel via SSE/WebSocket. À utiliser également lorsqu'un développeur demande comment appeler, intégrer ou choisir entre les points de terminaison de l'API TradingView, quels paramètres utiliser ou d'où proviennent les valeurs des paramètres (marchés, onglets, jeux de colonnes, langues, champs de filtrage).
