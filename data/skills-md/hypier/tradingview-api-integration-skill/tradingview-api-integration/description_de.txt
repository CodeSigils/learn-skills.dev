Integrieren Sie die TradingView Data API (RapidAPI Tradingview-Data1) und fragen Sie sie ab. Verwenden Sie diese Option, wenn der Benutzer Marktdaten jeglicher Art wünscht – Aktien-/Krypto-/Forex-/Futures-Preise und Candlesticks, Echtzeitkurse, Fundamentaldaten und Finanzdaten des Unternehmens, technische Analyse, Markt-/Symbolsuche, Nachrichten, Community-Ideen, Bestenlisten (Gewinner/Verlierer/Marktbeweger), Aktien- oder Krypto-Screener, Wirtschaftskalender (Gewinne/Börsengang/Dividenden/Makroereignisse), Weltwirtschaftsindikatoren, Symbollogos oder Echtzeit-Streaming über SSE/WebSocket. Verwenden Sie es auch, wenn ein Entwickler fragt, wie TradingView-API-Endpunkte aufgerufen, integriert oder zwischen ihnen ausgewählt werden sollen, welche Parameter verwendet werden sollen oder wo Parameterwerte (Märkte, Registerkarten, Spaltensätze, Sprachen, Screener-Felder) herkommen.
