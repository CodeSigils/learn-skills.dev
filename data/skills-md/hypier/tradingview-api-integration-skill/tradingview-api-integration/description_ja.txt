TradingView Data API (RapidAPI tradeview-data1) と統合し、クエリを実行します。ユーザーがあらゆる種類の市場データを必要とする場合に使用します - 株式/仮想通貨/外国為替/先物価格とローソク足、リアルタイム相場、企業のファンダメンタルズと財務、テクニカル分析、市場/銘柄検索、ニュース、コミュニティのアイデア、リーダーボード (値上がり者/敗者/市場変動者)、株式または仮想通貨スクリーナー、経済カレンダー (収益/IPO/配当/マクロイベント)、世界経済指標、シンボルロゴ、またはリアルタイムストリーミングSSE/WebSocket。また、開発者が、TradingView API エンドポイントの呼び出し、統合、または選択方法、使用するパラメータ、またはパラメータ値 (市場、タブ、列セット、言語、スクリーナー フィールド) の取得元を尋ねる場合にも使用します。
