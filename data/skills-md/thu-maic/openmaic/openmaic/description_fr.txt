SOP guidée pour la configuration et l'utilisation d'OpenMAIC à partir d'OpenClaw. À utiliser lorsque l'utilisateur souhaite cloner le référentiel OpenMAIC, choisir un mode de démarrage, configurer les clés API recommandées, démarrer le service ou générer une classe à partir des exigences ou d'un PDF. Exécutez une phase à la fois et demandez une confirmation avant chaque étape de changement d'état.
