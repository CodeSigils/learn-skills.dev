SOP guiado para configurar y usar OpenMAIC de OpenClaw. Úselo cuando el usuario quiera clonar el repositorio de OpenMAIC, elegir un modo de inicio, configurar claves API recomendadas, iniciar el servicio o generar un aula a partir de requisitos o un PDF. Ejecute una fase a la vez y solicite confirmación antes de cada paso de cambio de estado.
