Transformez le contenu des manuels scolaires en affiches éducatives de style IP Disney/Pixar et en invites d'images IA.
Compétence de base : manuel → Scénario IP → Invite, prend en charge 7 bibliothèques de thèmes IP majeures (Zootopia/Frozen/Le Roi Lion/Toy Story/Finding Nemo/Disney Princesses/Cars).
Types de sortie : cartes de prévisualisation/cartes de quiz/cartes de vocabulaire/cartes de grammaire, compatibles avec Midjourney/DALL-E/Gemini.
Mots déclencheurs : créer une carte d'aperçu, créer une affiche de vocabulaire, utiliser Zootopia, une affiche IP, une invite d'image IA, une affiche éducative
