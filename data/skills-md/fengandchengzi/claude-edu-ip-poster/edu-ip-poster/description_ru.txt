Превратите содержимое учебников в образовательные плакаты в стиле Disney/Pixar и подсказки с изображениями искусственного интеллекта.
Основной навык: учебник → Сюжетная линия IP → Подсказка, поддерживает 7 основных библиотек тем IP (Зверополис/Холодное сердце/Король Лев/История игрушек/В поисках Немо/Принцессы Диснея/Тачки).
Типы вывода: карточки предварительного просмотра/карточки с тестами/карточки со словарными запасами/карточки с грамматикой, совместимые с Midjourney/DALL-E/Gemini.
Триггерные слова: создать карточку предварительного просмотра, создать словарный плакат, использовать Zootopia, IP-постер, подсказку изображения AI, образовательный плакат.
