Automatizza la sincronizzazione dei file dotfile di Chezmoi: recupera in remoto, esegui il pull delle modifiche con la risoluzione intelligente dei conflitti, esegui il commit delle modifiche locali con messaggi generati automaticamente ed esegui il push. Utilizzare ogni volta che l'utente desidera sincronizzare i dotfile, dice "同步", "chezmoi sync", "提交 dotfiles", "备份配置" o sta per eseguire manualmente i comandi git di chezmoi.
