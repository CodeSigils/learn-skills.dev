أتمتة مزامنة ملفات chezmoi dotfiles - جلب التغييرات عن بعد، وسحب التغييرات باستخدام حل التعارض الذكي، وتنفيذ التغييرات المحلية باستخدام الرسائل التي يتم إنشاؤها تلقائيًا، والدفع. يُستخدم عندما يريد المستخدم مزامنة ملفات النقاط، أو يقول "同步"، أو "chezmoi sync"، أو "提交 dotfiles"، أو "备份配置"، أو عندما يكون على وشك تشغيل أوامر chezmoi git يدويًا.
