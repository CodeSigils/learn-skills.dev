Автоматизируйте синхронизацию точечных файлов chezmoi — получайте удаленные файлы, извлекайте изменения с помощью интеллектуального разрешения конфликтов, фиксируйте локальные изменения с помощью автоматически сгенерированных сообщений и отправляйте их. Используйте его всякий раз, когда пользователь хочет синхронизировать точечные файлы, говорит «同步», «chezmoi sync», «提交 dotfiles», «备份配置» или собирается запустить команды chezmoi git вручную.
