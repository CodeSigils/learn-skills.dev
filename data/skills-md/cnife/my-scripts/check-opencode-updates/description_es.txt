Busque actualizaciones de versión de opencode y oh-my-openagent (omo), obtenga y muestre automáticamente las notas de la versión cuando haya actualizaciones disponibles. Utilice esta habilidad inmediatamente cuando el usuario mencione la verificación de versiones, actualizaciones, comparación de versiones, registros de cambios, notas de la versión o pregunte si opencode/omo necesita actualizarse o si hay una nueva versión. Active esta habilidad para verificar la versión incluso si el usuario menciona casualmente "buscar actualizaciones" o "versión".
