Configurazione di Sendmux, convalida della chiave API, accesso dell'agente e guida alla prima chiamata. Da utilizzare quando l'utente desidera installare gli strumenti Sendmux, verificare se una credenziale smx_root_, smx_mbx_ o smx_agent_ funziona, scegliere MCP o CLI o SDK, connettere un agente all'e-mail Sendmux, configurare l'autenticazione o effettuare la prima chiamata API Sendmux innocua da un agente, terminale o applicazione.
