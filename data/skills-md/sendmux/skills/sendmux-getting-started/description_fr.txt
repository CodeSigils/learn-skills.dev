Configuration de Sendmux, validation de la clé API, accès des agents et conseils lors du premier appel. À utiliser lorsque l'utilisateur souhaite installer les outils Sendmux, vérifier si un identifiant smx_root_, smx_mbx_ ou smx_agent_ fonctionne, choisir MCP vs CLI vs SDK, connecter un agent à la messagerie Sendmux, configurer l'authentification ou effectuer le premier appel API Sendmux inoffensif à partir d'un agent, d'un terminal ou d'une application.
