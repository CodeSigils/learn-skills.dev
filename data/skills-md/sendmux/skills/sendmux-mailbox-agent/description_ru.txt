Эффективно работайте с одним почтовым ящиком Sendmux от AI-агента. Используйте для чтения, поиска, подсчета, синхронизации, сортировки, хранения, удаления, создания потоков или ответа из почтового ящика с помощью ключа smx_mbx_ или токена smx_agent_ с ограниченной областью действия, особенно когда пользователь просит агента проверить почтовый ящик, найти соответствующие сообщения, пометить сообщения или продолжить работу из предыдущего состояния синхронизации почтового ящика.
