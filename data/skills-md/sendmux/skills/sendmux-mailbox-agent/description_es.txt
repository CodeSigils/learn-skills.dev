Trabaje de manera eficiente con un buzón de Sendmux de un agente de IA. Úselo para leer, buscar, contar, sincronizar, clasificar, archivar, eliminar, encadenar o responder desde un buzón con una clave smx_mbx_ o un token smx_agent_ con alcance, especialmente cuando el usuario le pide a un agente que inspeccione una bandeja de entrada, encuentre mensajes relevantes, marque mensajes o continúe desde un estado de sincronización de buzón anterior.
