اختر أرخص سطح Sendmux الصحيح واتصل به. يُستخدم عندما يمكن تنفيذ مهمة Sendmux من خلال MCP، أو sendmux CLI، أو SDK، أو HTTP المباشر ويحتاج المستخدم إلى استخدام رمزي منخفض، واستخدام منخفض ذهابًا وإيابًا: إرسال الدُفعات، أو البحث في صندوق البريد/العدد/القراءات المجمعة، أو دلتا المزامنة، أو ترقيم صفحات المؤشر، أو علامات ETags، أو الطلبات المشروطة، أو مفاتيح الفاعلية، أو تجنب عمليات جلب صندوق البريد/السجل الواسعة.
