قم بتشغيل Chrome الحقيقي على جهاز الكمبيوتر الشخصي الخاص بـ Ilias الذي يعمل بنظام Windows عبر CDP - وهو نفس المتصفح الذي يستخدمه بنفسه، وسجل الدخول إلى حساباته (Vercel، وGoogle Cloud، وHeroku، وغيرها). استخدمه لجلب البيانات الموجودة خلف عمليات تسجيل الدخول الخاصة به، أو فتح صفحة مباشرة وتصحيح أخطائها، أو مشاهدة التدفق معًا، أو اعتراض الطلبات، أو تعيين بلد الوكيل / الخروج للمتصفح. استخدمه فقط عندما يطلب إلياس صراحةً متصفحه الحقيقي / المضيف / Windows - كل ما يفعله يكون مرئيًا على شاشته.
