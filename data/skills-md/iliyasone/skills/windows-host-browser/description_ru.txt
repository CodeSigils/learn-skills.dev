Управляйте настоящим Chrome на ПК Ильяса с ОС Windows через CDP — тот же браузер, который он использует сам, входящий в свои учетные записи (Vercel, Google Cloud, Heroku и другие). Используйте его для получения данных, которые скрываются за его входами в систему, открытия и отладки страницы в реальном времени, совместного просмотра потока, перехвата запросов или установки прокси-сервера браузера / страны выхода. Используйте его только тогда, когда Ильяс явно запрашивает свой настоящий/хост/браузер Windows — всё, что он делает, видно на его экране.
