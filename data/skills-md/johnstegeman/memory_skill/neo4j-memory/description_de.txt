Verwenden Sie diese Fähigkeit, wenn der Benutzer „Erinnerungen aufzeichnen“, „diese Sitzung speichern“, „vorherige Sitzungen aufzeichnen“, „Entscheidungen merken“, „in Neo4j speichern“, „Speicherdiagramm aktualisieren“ oder eine ähnliche Anfrage auffordert, um den Sitzungsverlauf, Entscheidungen, Aktionen oder Erkenntnisse im Neo4j-Speicher-MCP-Server beizubehalten. Verwenden Sie es auch, wenn Sie ein neues Projekt starten und der Benutzer eine Speicherverfolgung einrichten möchte.
