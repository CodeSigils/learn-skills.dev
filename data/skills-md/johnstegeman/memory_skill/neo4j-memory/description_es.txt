Utilice esta habilidad cuando el usuario solicite "grabar recuerdos", "guardar esta sesión", "grabar sesiones anteriores", "recordar decisiones", "guardar en neo4j", "actualizar gráfico de memoria" o cualquier solicitud similar para conservar el historial de sesiones, decisiones, acciones o aprendizajes en el servidor MCP de memoria Neo4j. Úselo también cuando comience un nuevo proyecto y el usuario desee configurar el seguimiento de la memoria.
