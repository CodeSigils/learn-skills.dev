Используйте этот навык, когда пользователь просит «записать воспоминания», «сохранить этот сеанс», «записать предыдущие сеансы», «запомнить решения», «сохранить в neo4j», «обновить график памяти» или любой подобный запрос для сохранения истории сеанса, решений, действий или обучения на сервере памяти MCP Neo4j. Также используйте при запуске нового проекта, когда пользователь хочет настроить отслеживание памяти.
