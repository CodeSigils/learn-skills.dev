Vérifie les codes OTP que les utilisateurs ont saisis, lorsqu'EngageLab a généré et stocké le code (mode généré par la plateforme). À utiliser pour vérifier si un code de vérification saisi par l'utilisateur correspond à celui envoyé par EngageLab, complétant ainsi le flux de connexion/enregistrement/2FA. Cette compétence n'est nécessaire que pour le mode généré par la plateforme : si vous avez généré le code vous-même, vérifiez-le par rapport à votre propre base de données.
