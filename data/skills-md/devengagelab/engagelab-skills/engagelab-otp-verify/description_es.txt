Verifica los códigos OTP que los usuarios ingresaron, cuando EngageLab generó y almacenó el código (modo generado por plataforma). Úselo cuando verifique si un código de verificación ingresado por un usuario coincide con el que envió EngageLab, completando el flujo de inicio de sesión/registro/2FA. Esta habilidad solo es necesaria para el modo generado por la plataforma; si generó el código usted mismo, verifíquelo con su propia base de datos.
