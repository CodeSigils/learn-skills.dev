Verifiziert OTP-Codes, die Benutzer eingegeben haben, als EngageLab den Code generierte und speicherte (plattformgenerierter Modus). Wird verwendet, um zu überprüfen, ob ein vom Benutzer eingegebener Bestätigungscode mit dem von EngageLab gesendeten übereinstimmt, um den Anmelde-/Registrierungs-/2FA-Ablauf abzuschließen. Diese Fähigkeit ist nur für den plattformgenerierten Modus erforderlich. Wenn Sie den Code selbst generiert haben, überprüfen Sie ihn anhand Ihrer eigenen Datenbank.
