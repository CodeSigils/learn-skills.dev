À utiliser lors de l'écriture, de la révision ou du débogage de code Ruby pur : modèles idiomatiques, fonctionnalités 3.x+ modernes (correspondance de modèles, Data.define, méthodes sans fin), conventions de gestion des erreurs (augmentation ou échec, objets de résultat), mémorisation et idiomes de performances. Pour les Rails, utilisez des rails-guides. Pour les tests, utilisez minitest. Pour le style de code, utilisez les règles sandi-metz.
