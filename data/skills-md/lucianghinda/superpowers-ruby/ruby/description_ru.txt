Используйте при написании, проверке или отладке чистого кода Ruby — идиоматические шаблоны, современные функции 3.x+ (сопоставление с образцом, Data.define, бесконечные методы), соглашения об обработке ошибок (повышение или сбой, объекты результатов), запоминание и идиомы производительности. Для Rails используйте рельсы-направляющие. Для тестирования используйте minitest. Для стиля кода используйте правила Sandi-Metz.
