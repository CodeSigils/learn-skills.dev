Úselo al escribir, revisar o depurar código Ruby puro: patrones idiomáticos, características modernas de 3.x+ (coincidencia de patrones, Data.define, métodos infinitos), convenciones de manejo de errores (aumentar versus fallar, objetos de resultados), memorización y modismos de rendimiento. Para rieles utilice rieles-guías. Para realizar pruebas utilice minitest. Para el estilo del código, utilice reglas sandi-metz.
