Modèles de codage Rails dérivés de l'analyse de la base de code Fizzy de 37signals. À utiliser lors de l'écriture de code Rails dans le style 37signals/Basecamp ou lorsqu'il est demandé de suivre les modèles 37signals. Couvre les contrôleurs, les modèles, les vues, Hotwire, les tests, la base de données, la sécurité et la philosophie de l'équipe.
