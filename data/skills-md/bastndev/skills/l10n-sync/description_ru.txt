Синхронизируйте переводы с английским источником — файлы README_<LANG>.md из README.md и пакеты VS Code package.nls.<lang>.json из package.nls.json. Распространяется только то, что изменилось, сохраняя таблицы, код, ссылки и заполнители. Используйте, когда пользователь запрашивает перевод, локализацию, синхронизацию или обновление файла README, папки документации или пакетов JSON nls/l10n или вызывает этот навык.
