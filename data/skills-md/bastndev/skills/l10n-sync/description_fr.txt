Gardez les traductions synchronisées avec leur source anglaise : fichiers README_<LANG>.md de README.md et bundles VS Code package.nls.<lang>.json de package.nls.json. Propage uniquement ce qui a changé, en préservant les tables, le code, les liens et les espaces réservés. À utiliser lorsque l'utilisateur demande à traduire, localiser, synchroniser ou mettre à jour un fichier README, un dossier docs ou des bundles JSON nls/l10n, ou invoque cette compétence.
