Focused, on-demand project improver for active development. 옵션 0은 보고서 전용 상태 개요(아키텍처, 유지 관리 가능성, 성능, 보안, 문서화)로 프로젝트 또는 폴더의 점수를 0~100으로 평가합니다. 옵션 1~7은 성능(1), UI/UX(2), 정리/파일 순서 + 주석 위생(3), 보안(4), 구조(5), 정리/데드 코드(6), 코드 품질(7) 등 한 번에 한 가지 차원을 개선합니다. 초점을 0~100으로 채점하고 수정 계획을 제안하며 명시적인 승인이 있는 경우에만 실행합니다. Exception: tidy (3) on a single small file applies directly, no approval needed. Use for 'score my project', 'sort this file / translate the comments', 'harden security in src/api', 'speed up this page', 'clean dead code'. Invoke with /middle <0-7|focus> (@path)
