Mejorador de proyectos enfocado y bajo demanda para un desarrollo activo. La opción 0 califica el proyecto o carpeta con una descripción general del estado de 0 a 100 (Arquitectura, Mantenibilidad, Rendimiento, Seguridad, Documentación), solo para informes. Las opciones 1 a 7 mejoran UNA dimensión a la vez: rendimiento (1), UI/UX (2), orden de archivos/orden + higiene de comentarios (3), seguridad (4), estructura (5), limpieza/código inactivo (6), calidad del código (7): calificar el enfoque de 0 a 100, proponer un plan de corrección y ejecutar solo con aprobación explícita. Excepción: tidy (3) en un único archivo pequeño se aplica directamente, no se necesita aprobación. Úselo para 'puntuar mi proyecto', 'ordenar este archivo/traducir los comentarios', 'reforzar la seguridad en src/api', 'acelerar esta página', 'limpiar código muerto'.
