Fokussierter, bedarfsorientierter Projektverbesserer für die aktive Entwicklung. Option 0 bewertet das Projekt oder den Ordner mit einer Zustandsübersicht von 0–100 (Architektur, Wartbarkeit, Leistung, Sicherheit, Dokumentation), nur als Bericht. Die Optionen 1–7 verbessern jeweils EINE Dimension – Leistung (1), UI/UX (2), Ordnung/Dateireihenfolge + Kommentarhygiene (3), Sicherheit (4), Struktur (5), Bereinigung/toter Code (6), Codequalität (7) – Bewertung des Fokus 0–100, Vorschlag eines Korrekturplans und Ausführung nur mit ausdrücklicher Genehmigung. Ausnahme: Tidy (3) gilt direkt für eine einzelne kleine Datei, keine Genehmigung erforderlich. Verwenden Sie diese Option für „Mein Projekt bewerten“, „Diese Datei sortieren / Kommentare übersetzen“, „Sicherheit in src/api erhöhen“, „Diese Seite beschleunigen“, „toten Code bereinigen“.
