Целенаправленное улучшение проектов по требованию для активной разработки. Вариант 0 оценивает проект или папку по шкале от 0 до 100 (архитектура, ремонтопригодность, производительность, безопасность, документация), только для отчетов. Варианты 1–7 улучшают ОДИН параметр одновременно — производительность (1), UI/UX (2), порядок/порядок файлов + гигиена комментариев (3), безопасность (4), структура (5), очистка/мертвый код (6), качество кода (7) – оценка фокуса 0–100, предложение плана исправления и выполнение только с явного одобрения. Исключение: порядок (3) для одного небольшого файла применяется напрямую, одобрение не требуется. Используйте для «оценить мой проект», «отсортировать этот файл/перевести комментарии», «усилить безопасность в src/api», «ускорить эту страницу», «очистить мертвый код».
