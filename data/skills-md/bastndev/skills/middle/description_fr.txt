Améliorateur de projet ciblé et à la demande pour un développement actif. L'option 0 attribue au projet ou au dossier un aperçu de l'état de santé de 0 à 100 (architecture, maintenabilité, performances, sécurité, documentation), sous forme de rapport uniquement. Les options 1 à 7 améliorent UNE dimension à la fois — performances (1), UI/UX (2), rangement/ordre des fichiers + hygiène des commentaires (3), sécurité (4), structure (5), nettoyage/code mort (6), qualité du code (7) — en notant l'accent de 0 à 100, en proposant un plan de correction et en l'exécutant uniquement avec une approbation explicite. Exception : Tidy (3) sur un seul petit fichier s'applique directement, aucune approbation n'est nécessaire. À utiliser pour « évaluer mon projet », « trier ce fichier / traduire les commentaires », « renforcer la sécurité dans src/api », « accélérer cette page », « nettoyer le code mort ». Invoquez avec /middle <0-7|focus> (@path)
