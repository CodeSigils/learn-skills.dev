JS/TS スタック (Next.js、Astro、React Native、Expo、Lynx JS、Vite など) または必要に応じて他の言語の Web、モバイル、ブラウザー拡張機能、npm パッケージ/ライブラリなど、あらゆるソフトウェア プロジェクトのアーキテクチャを分析し、アーキテクチャとパッケージ/依存関係をカバーする焦点を絞った Markdown ファイルのフォルダーを生成します。ユーザーが既存のコードベースを理解または文書化したい場合は常に使用します。自分のアイデアに適用する前に、インスピレーションを得るために別のプロジェクトの構造を研究したいと考えています (例: 「estoy analizando este repo para aprender」)。または、どのパッケージが特定のもの (ダーク/ライト モード、ルーティング、状態管理、フォーム、i18n) を処理するか、およびそのパッケージが存在するかどうかを尋ねます。 「アーキテクチャ」という単語がなくてもトリガーされます。「ayúdame a entender este proyecto」、「qué package usa y para qué」、「analiza la estructura de este repo」はすべて対象となります。
