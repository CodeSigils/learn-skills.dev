Analyse l'architecture de tout projet logiciel — web, mobile, extension de navigateur ou package/bibliothèque npm, dans n'importe quelle pile JS/TS (Next.js, Astro, React Native, Expo, Lynx JS, Vite, etc.) ou d'autres langages si nécessaire — et produit un dossier de fichiers Markdown ciblés couvrant l'architecture et les packages/dépendances. À utiliser chaque fois que l'utilisateur souhaite comprendre ou documenter une base de code existante ; veut étudier la structure d'un autre projet pour s'en inspirer avant d'appliquer ses idées aux siennes (par exemple "estoy analizando este repo para aprender"); ou demande quel package gère quelque chose de spécifique (mode sombre/clair, routage, gestion de l'état, formulaires, i18n) et s'il existe. Déclenchez même sans le mot « architecture » — « ayúdame a entender este proyecto », « qué packages usa y para qué », « analiza la estructura de este repo » sont tous qualifiés.
