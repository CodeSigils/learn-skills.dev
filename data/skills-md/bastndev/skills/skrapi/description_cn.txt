分析任何软件项目的架构 - Web、移动、浏览器扩展或 npm 包/库，任何 JS/TS 堆栈（Next.js、Astro、React Native、Expo、Lynx JS、Vite 等）或其他语言（如果需要） - 并生成一个包含涵盖架构和包/依赖项的重点 Markdown 文件的文件夹。每当用户想要理解或记录现有代码库时使用；想要在将想法应用到自己的想法之前研究另一个项目的结构以获得灵感（例如“estoy analizando este repo para aprender”）；或者询问哪个包处理特定的东西（暗/亮模式、路由、状态管理、表单、i18n）以及是否存在。即使没有“architecture”这个词也可以触发——“ayúdame a entender este proyecto”、“quépackages usa y para qué”、“analiza la estructura de este repo”都符合条件。
