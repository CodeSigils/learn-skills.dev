يحلل بنية أي مشروع برمجي - الويب أو الهاتف المحمول أو امتداد المتصفح أو حزمة/مكتبة npm، في أي مكدس JS/TS (Next.js، Astro، React Native، Expo، Lynx JS، Vite، وما إلى ذلك) أو لغات أخرى إذا لزم الأمر - وينتج مجلدًا من ملفات Markdown المركزة التي تغطي البنية والحزم/التبعيات. يُستخدم عندما يريد المستخدم فهم أو توثيق قاعدة تعليمات برمجية موجودة؛ يريد دراسة بنية مشروع آخر للإلهام قبل تطبيق الأفكار على أفكاره الخاصة (على سبيل المثال، "estoy analizando este repo para aprender")؛ أو يسأل عن الحزمة التي تتعامل مع شيء محدد (الوضع الداكن/الفاتح، التوجيه، إدارة الحالة، النماذج، i18n) وما إذا كان موجودًا أم لا. تشغيل حتى بدون كلمة "هندسة معمارية" - "ayúdame a entender este proyecto"، "qué packages usa y para qué"، "analiza la estructura de este repo" كلها مؤهلة.
