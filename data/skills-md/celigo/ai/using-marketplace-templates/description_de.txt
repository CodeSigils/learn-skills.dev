Suchen, installieren und verwenden Sie vorgefertigte Integrationspläne aus dem Celigo Marketplace wieder – Vorlagen (freigeschaltet, vollständig bearbeitbar, keine laufenden Updates) und Integrations-Apps (vom Anbieter verwaltet, durch Upgrades geschützt, Updates erhalten). Behandelt die Installation einer gesamten Vorlage im Vergleich zum Kopieren eines einzelnen Elements, wie Verbindungen zugeordnet statt kopiert werden, die Abhängigkeitskaskade und wann man mit einem Blueprint beginnen sollte, anstatt von Grund auf neu zu erstellen. Verwenden Sie diese Option, wenn Sie den Marktplatz durchsuchen, eine Vorlage oder Integrations-App installieren oder einen vorhandenen Flow, Export, Import oder eine Verbindung in Ihre eigene Integration kopieren.
