Celigo API 토큰(accesstoken 리소스) 관리 - integrator.io의 REST API, 사용자 정의 API 및 MCP 서버에 대한 인바운드 프로그래밍 호출을 인증하는 전달자 자격 증명입니다. PAT(개인 액세스 토큰)와 계정 수준 API 토큰, 최소 권한 범위 지정과 전체 액세스, 삭제 전 취소 수명 주기, 자동 제거 만료 및 채팅에서 토큰 비밀 유지를 다룹니다. API 토큰 또는 PAT를 생성, 범위 지정, 교체, 취소 또는 삭제할 때 또는 integrator.io API 토큰을 연결의 OAuth 액세스 토큰과 구별할 때 사용합니다.
