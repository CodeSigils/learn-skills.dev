Управляйте токенами API Celigo (ресурс токена доступа) — учетными данными носителя, которые аутентифицируют входящие программные вызовы в REST API интегратора.io, пользовательские API и серверы MCP. Охватывает токены личного доступа (PAT) и токены API на уровне учетной записи, область действия с наименьшими привилегиями и полный доступ, жизненный цикл «отзыв перед удалением», срок действия автоматической очистки и сохранение секретов токена в чате. Используйте при создании, определении области действия, ротации, отзыве или удалении токенов API или PAT, а также при различении токена API integrator.io от токена доступа OAuth соединения.
