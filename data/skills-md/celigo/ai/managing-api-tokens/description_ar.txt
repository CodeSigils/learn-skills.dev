إدارة الرموز المميزة لـ Celigo API (مورد Accesstoken) - بيانات اعتماد الحامل التي تصادق على المكالمات البرمجية الواردة في REST API الخاص بـ integrator.io، وواجهات برمجة التطبيقات المخصصة، وخوادم MCP. يغطي رموز الوصول الشخصية (PATs) مقابل الرموز المميزة لواجهة برمجة التطبيقات (API) على مستوى الحساب، ونطاق الامتياز الأقل مقابل الوصول الكامل، ودورة حياة الإلغاء قبل الحذف، وانتهاء التطهير التلقائي، وإبقاء أسرار الرمز المميز خارج الدردشة. يُستخدم عند إنشاء الرموز المميزة أو PATs لواجهة برمجة التطبيقات (API) أو تحديد نطاقها أو تدويرها أو إبطالها أو حذفها، أو عند التمييز بين رمز واجهة برمجة تطبيقات integrator.io ورمز وصول OAuth المميز للاتصال.
