Gestisci i token API Celigo (la risorsa accesstoken): credenziali al portatore che autenticano le chiamate programmatiche in entrata nell'API REST di integrator.io, nelle API personalizzate e nei server MCP. Copre i token di accesso personale (PAT) rispetto ai token API a livello di account, l'ambito dei privilegi minimi rispetto all'accesso completo, il ciclo di vita di revoca prima dell'eliminazione, la scadenza dell'eliminazione automatica e il mantenimento dei segreti dei token fuori dalla chat. Da utilizzare durante la creazione, l'ambito, la rotazione, la revoca o l'eliminazione di token API o PAT oppure quando si distingue un token API integrator.io dal token di accesso OAuth di una connessione.
