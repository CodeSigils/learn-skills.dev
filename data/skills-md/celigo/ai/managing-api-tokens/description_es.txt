Administre tokens API de Celigo (el recurso de token de acceso): credenciales de portador que autentican las llamadas programáticas entrantes en la API REST de integrator.io, las API personalizadas y los servidores MCP. Cubre tokens de acceso personal (PAT) versus tokens API a nivel de cuenta, alcance de privilegios mínimos versus acceso completo, el ciclo de vida de revocar antes de eliminar, vencimiento de la purga automática y mantener los secretos de los tokens fuera del chat. Úselo al crear, definir el alcance, rotar, revocar o eliminar tokens de API o PAT, o al distinguir un token de API de integrator.io del token de acceso OAuth de una conexión.
