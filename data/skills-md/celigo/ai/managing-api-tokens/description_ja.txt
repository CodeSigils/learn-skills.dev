Celigo API トークン (accesstoken リソース) を管理します。これは、integrator.io の REST API、カスタム API、および MCP サーバーへの受信プログラム呼び出しを認証するベアラー資格情報です。パーソナル アクセス トークン (PAT) とアカウント レベルの API トークン、最小特権のスコープとフル アクセス、削除前取り消しのライフサイクル、自動パージの有効期限、およびトークンの秘密をチャットに含めないようにすることについて説明します。 API トークンまたは PAT を作成、スコープ、ローテーション、取り消し、または削除する場合、または integrator.io API トークンと接続の OAuth アクセス トークンを区別する場合に使用します。
