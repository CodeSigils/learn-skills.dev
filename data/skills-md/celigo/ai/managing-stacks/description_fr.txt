Configurez les piles Celigo - des pointeurs vers votre propre environnement de calcul (un « serveur » auto-hébergé ou un « lambda » AWS) où Celigo exécute le code d'extension (hooks de script et wrappers de connecteur) au lieu de son environnement d'exécution JavaScript hébergé. Une pile stocke l'adresse et les informations d'identification de ce runtime, pas le code lui-même. À utiliser pour décider si vous avez besoin d'une pile, choisir entre les types « serveur » et « lambda », créer ou mettre à jour une pile, ou pointer un hook ou un wrapper vers un via « _stackId ».
