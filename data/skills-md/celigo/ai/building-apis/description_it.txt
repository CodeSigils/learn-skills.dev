Costruisci API Celigo: endpoint HTTP personalizzati che consentono ai sistemi esterni di inviare o interrogare i dati in modo sincrono attraverso le integrazioni Celigo. Da utilizzare durante la creazione di API, l'inoltro di richieste autenticate o l'esposizione di operazioni di ricerca/scrittura come interfaccia REST che restituisce una risposta strutturata.
