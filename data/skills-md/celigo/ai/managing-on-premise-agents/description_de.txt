Verwalten Sie Celigo-On-Premise-Agents – leichte Software, die Sie auf einem Host in Ihrem eigenen Netzwerk installieren und die einen sicheren OUTBOUND-Tunnel zu integrator.io öffnet, sodass die Plattform private Systeme (On-Premise-Datenbanken, Dateifreigaben, interne Apps) erreichen kann, ohne eingehende Firewall-Ports zu öffnen. Ein On-Premise-Agent ist eine Konnektivitätsressource auf der Seite „/agents“ – kein Stack (Computing) und kein KI-Agent (LLM-Verarbeitung). Verwenden Sie diese Option, wenn Sie eine Verbindung zu einem System hinter einer Firewall herstellen, einen Agenten installieren oder koppeln, sein Zugriffstoken rotieren oder Fehler im Agent-Offline-Fluss diagnostizieren.
