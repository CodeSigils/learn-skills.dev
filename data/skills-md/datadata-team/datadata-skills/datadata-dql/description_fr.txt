Écrivez des scripts de traitement de données DQL pour la plateforme Datadata — un langage de script étendu basé sur Starlark qui prend en charge les opérations DataFrame/Series, les requêtes SQL, les requêtes HTTP, etc. Utilisez cette compétence lorsque les utilisateurs ont besoin d'écrire une logique de transformation de données, de nettoyage de données, de génération de données ou de traitement de données personnalisé.
