الاستعلام عن بيانات البيانات عبر واجهة سطر الأوامر (CLI) - تشغيل SQL المخصص، وفحص البيانات التعريفية لمصدر البيانات، وسرد الجداول ووصفها، وتنزيل النتائج بتنسيق NDJSON/CSV. يُستخدم عندما يذكر المستخدم بيانات البيانات، أو يريد الاستعلام عن البيانات، أو استكشاف مصادر البيانات أو مخططات الجدول، أو استرداد نتائج الاستعلام. المشغلات: بيانات البيانات، واستكشاف البيانات، واستعلام SQL، وفحص الجدول، ونتائج التنفيذ.
