Interrogez les données via CLI : exécutez du SQL ad hoc, inspectez les métadonnées de la source de données, répertoriez et décrivez les tables, téléchargez les résultats au format NDJSON/CSV. À utiliser lorsque l'utilisateur mentionne Datadata, souhaite interroger des données, explorer des sources de données ou des schémas de table, ou récupérer les résultats d'une requête. Déclencheurs : données de données, exploration de données, requête SQL, inspection de table, résultats d'exécution.
