Запрашивайте данные через CLI — запускайте специальный SQL, проверяйте метаданные источника данных, составляйте список и описывайте таблицы, загружайте результаты в формате NDJSON/CSV. Используйте, когда пользователь упоминает Datadata, хочет запросить данные, изучить источники данных или схемы таблиц или получить результаты запроса. Триггеры: данные данных, исследование данных, SQL-запрос, проверка таблицы, результаты выполнения.
