Esegui query sui dati tramite CLI: esegui SQL ad hoc, esamina i metadati dell'origine dati, elenca e descrivi le tabelle, scarica i risultati in formato NDJSON/CSV. Da utilizzare quando l'utente menziona Datadata, desidera eseguire query sui dati, esplorare origini dati o schemi di tabelle o recuperare risultati di query. Trigger: dati, esplorazione dei dati, query SQL, ispezione delle tabelle, risultati dell'esecuzione.
