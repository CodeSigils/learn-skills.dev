Conseils officiels de recherche Google pour optimiser les sites Web pour les fonctionnalités d'IA générative telles que les aperçus de l'IA et le mode IA. À utiliser lorsqu'un agent d'IA doit expliquer, auditer, planifier ou mettre en œuvre un travail de référencement pour la visibilité de Google AI Search ; évaluer les réclamations AEO/GEO ; conseillez sur llms.txt, les données structurées, la qualité du contenu, la capacité d'exploration, le référencement JavaScript, le référencement des médias, les détails du commerce électronique/local, le Merchant Center, le profil d'entreprise ou la préparation d'un site convivial pour les agents.
