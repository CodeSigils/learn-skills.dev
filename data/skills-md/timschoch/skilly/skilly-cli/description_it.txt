Gestisci le competenze dell'agente di questo repository con la CLI skilly: aggiungi o rimuovi pacchetti/competenze, scarica aggiornamenti dell'hub. Da utilizzare quando l'utente desidera che competenze o pacchetti vengano aggiunti, rimossi o aggiornati. Per un URL skills.sh utilizzare direttamente la CLI delle competenze, non skilly. Non per il bootstrap del repository (che è `skillly setup`, esegui una volta).
