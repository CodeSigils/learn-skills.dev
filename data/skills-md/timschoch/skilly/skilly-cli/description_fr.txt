Gérez les compétences d'agent de ce dépôt avec la CLI Skilly : ajoutez ou supprimez des bundles/compétences, extrayez les mises à jour du hub. À utiliser lorsque l'utilisateur souhaite ajouter, supprimer ou mettre à jour des compétences ou des offres groupées. Pour une URL skills.sh, utilisez directement la CLI skills, pas Skilly. Pas pour le bootstrap du dépôt (c'est-à-dire une « configuration compétente », exécutée une fois).
