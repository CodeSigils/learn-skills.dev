Guía las decisiones de Svix: envío frente a ingesta, arrendamiento (aplicaciones, canales, UID de cliente), idempotencia, verificación de firma, portal de aplicaciones, webhooks operativos y uso de CLI. Úselo siempre que mantenga una aplicación que ya usa Svix, cada vez que toque el código de envío de webhooks, los controladores de recepción de webhooks, la verificación de firmas, la incrustación del portal de aplicaciones, la configuración de fuentes o los webhooks operativos, o cuando revise o modifique las rutas de código Svix existentes.
