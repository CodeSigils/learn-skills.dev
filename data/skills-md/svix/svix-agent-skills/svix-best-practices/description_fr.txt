Guide les décisions Svix : répartition ou ingestion, location (applications, canaux, UID client), idempotence, vérification de signature, portail d'application, webhooks opérationnels et utilisation de la CLI. À utiliser lors de la maintenance d'une application qui utilise déjà Svix, chaque fois que vous touchez le code d'envoi de webhook, les gestionnaires de réception de webhook, la vérification de signature, l'intégration du portail d'application, la configuration des sources ou les webhooks opérationnels, ou lorsque vous examinez ou modifiez les chemins de code Svix existants.
