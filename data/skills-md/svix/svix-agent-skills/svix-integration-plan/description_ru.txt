Создает письменный план интеграции для полной интеграции Svix с многопользовательской маршрутизацией, каталогом типов событий, внедрением портала приложений и переносом существующей системы веб-перехватчиков. Исследует репо, задает только те вопросы, на которые Клод не может ответить самостоятельно, затем пишет план. Используйте, когда пользователь спрашивает: «Как мне интегрировать Svix в <эту кодовую базу>?» или хочет пройти этап проектирования перед написанием кода. Для фразы «Я просто хочу отправить свой первый веб-хук» вместо этого используйте навык svix-quickstart.
