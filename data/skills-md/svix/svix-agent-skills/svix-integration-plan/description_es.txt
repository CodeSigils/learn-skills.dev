Produce un plan de integración escrito para una integración completa de Svix con enrutamiento multiinquilino, catálogo de tipos de eventos, integración del portal de aplicaciones y migración desde un sistema de webhook existente. Investiga el repositorio, solo hace las preguntas que Claude no puede responder por sí solo y luego escribe el plan. Úselo cuando el usuario pregunte "¿cómo debo integrar Svix en <este código base>?" o quiere un pase de diseño antes que el código. Para "Solo quiero enviar mi primer webhook", utilice la habilidad svix-quickstart en su lugar.
