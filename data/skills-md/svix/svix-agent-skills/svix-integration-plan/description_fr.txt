Produit un plan d'intégration écrit pour une intégration complète de Svix avec routage multi-tenant, catalogue de types d'événements, intégration d'App Portal, migration à partir d'un système webhook existant. Enquête sur le repo, pose uniquement les questions auxquelles Claude ne peut pas répondre seul, puis rédige le plan. À utiliser lorsque l'utilisateur demande « comment dois-je intégrer Svix dans <cette base de code> ? » ou veut une passe de conception avant le code. Pour « Je veux juste envoyer mon premier webhook », utilisez plutôt la compétence svix-quickstart.
