Загрузите новый проект TypeScript с помощью pnpm, oxc (oxlint + oxfmt), перехватчиков prek git, правильной настройки git, AGENTS.md и CI. Используйте этот навык всякий раз, когда пользователь хочет создать новый проект TypeScript, создать репозиторий TS, настроить монорепозиторий TypeScript, загрузить проект Node.js/TypeScript или запросить настройку проекта с помощью проверки/форматирования. Также срабатывает, когда пользователь упоминает «новый проект», «проект инициализации», «эшафот» или «начальную загрузку» в контексте TypeScript/JavaScript.
