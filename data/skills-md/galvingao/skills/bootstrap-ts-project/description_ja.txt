pnpm、oxc (oxlint + oxfmt)、prek git フック、適切な git セットアップ、AGENTS.md、および CI を使用して、新しい TypeScript プロジェクトをブートストラップします。ユーザーが新しい TypeScript プロジェクトの作成、TS リポジトリのスキャフォールディング、TypeScript モノリポジトリのセットアップ、Node.js/TypeScript プロジェクトのブートストラップ、または linting/formatting を使用したプロジェクトのセットアップを要求する場合は常に、このスキルを使用します。ユーザーが TypeScript/JavaScript コンテキストで「新しいプロジェクト」、「初期プロジェクト」、「足場」、または「ブートストラップ」に言及したときにもトリガーされます。
