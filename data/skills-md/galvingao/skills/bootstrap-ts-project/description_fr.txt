Démarrez un nouveau projet TypeScript avec pnpm, oxc (oxlint + oxfmt), prek git hooks, une configuration git appropriée, AGENTS.md et CI. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer un nouveau projet TypeScript, échafauder un dépôt TS, configurer un monorepo TypeScript, démarrer un projet Node.js/TypeScript ou demander la configuration du projet avec peluchage/formatage. Se déclenche également lorsque l'utilisateur mentionne « nouveau projet », « projet d'initialisation », « échafaudage » ou « bootstrap » dans un contexte TypeScript/JavaScript.
