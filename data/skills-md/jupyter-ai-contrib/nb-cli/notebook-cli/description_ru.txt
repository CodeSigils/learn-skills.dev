ВСЕГДА используйте CLI `nb` для ВСЕХ операций записной книжки Jupyter вместо встроенных инструментов (Read, NotebookEdit и т. д.). Сюда входит чтение, создание, редактирование ячеек, выполнение и поиск в записных книжках. По умолчанию выводит удобочитаемый текст с флагом --json для программного доступа. Поддерживает как локальные файловые, так и удаленные режимы совместной работы в реальном времени. ОБЯЗАТЕЛЬНО для всех файлов .ipynb в этом проекте.
