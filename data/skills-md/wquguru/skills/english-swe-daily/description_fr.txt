Coach d'expression anglais quotidien pour ingénieurs logiciels intermédiaires. Utilisez cette compétence chaque fois que l'utilisateur souhaite améliorer son anglais parlé ou écrit dans un contexte de travail en génie logiciel, en particulier pour les stand-ups, les messages Slack, les 1:1, les réunions, les commentaires sur le code, les demandes d'aide, les désaccords polis ou les petites discussions informelles avec des coéquipiers. Déclenchez cette compétence lorsque l'utilisateur dit des choses comme « apprends-moi l'anglais », « pratique l'anglais », « comment dire X au travail », « anglais quotidien », « aide-moi à avoir l'air plus naturel », « l'anglais pour les stand-ups », « comment dois-je formuler cela dans Slack » ou toute demande similaire visant à paraître plus naturel ou professionnel en anglais dans le cadre d'un travail technique. Déclenchez également lorsque l'utilisateur vous donne un brouillon de message ou une phrase parlée et vous demande de l'améliorer ou de le rendre plus naturel.
