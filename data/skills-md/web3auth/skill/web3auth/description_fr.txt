Connaissance complète de l'intégration des portefeuilles intégrés MetaMask (SDK Web3Auth). Couvre la sélection du SDK, les fonctionnalités de la plateforme (React, Vue, React Native, Android, iOS, Flutter, Unity, Unreal, Node.js), la configuration de l'authentification (connexion sociale, JWT personnalisé, connexions groupées), les règles de dérivation de clé et le dépannage. À utiliser chaque fois que l'utilisateur mentionne @web3auth/modal, Web3Auth, MetaMask Embedded Wallets, les portefeuilles de connexion sociale, useWeb3AuthConnect, le réseau Sapphire, l'intégration de portefeuille intégré ou crée une application où les utilisateurs obtiennent un portefeuille cryptographique via OAuth/connexion sociale. Utilisez également pour la configuration du tableau de bord Web3Auth, les ID client, les vérificateurs/connexions ou la migration depuis PnP/CoreKit/Torus. Ne déclenchez PAS l'utilisation de l'extension de navigateur MetaMask, les configurations RainbowKit/ConnectKit autonomes sans Web3Auth ou le développement général de blockchain sans rapport avec l'authentification de portefeuille intégrée.
