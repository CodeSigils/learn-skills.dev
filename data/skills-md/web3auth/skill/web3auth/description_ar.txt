معرفة كاملة بدمج محافظ MetaMask المدمجة (Web3Auth SDK). يغطي اختيار SDK وإمكانيات النظام الأساسي (React وVue وReact Native وAndroid وiOS وFlutter وUnity وUnreal وNode.js) وإعداد المصادقة (تسجيل الدخول عبر وسائل التواصل الاجتماعي وJWT المخصص والاتصالات المجمعة) وقواعد الاشتقاق الرئيسية واستكشاف الأخطاء وإصلاحها. استخدمه عندما يذكر المستخدم @web3auth/modal، أو Web3Auth، أو MetaMask Embedded Wallets، أو محافظ تسجيل الدخول الاجتماعي، أو useWeb3AuthConnect، أو شبكة Sapphire، أو تكامل المحفظة المضمنة، أو يقوم بإنشاء تطبيق حيث يحصل المستخدمون على محفظة تشفير من خلال OAuth/تسجيل الدخول الاجتماعي. استخدمه أيضًا لتكوين لوحة معلومات Web3Auth، أو معرفات العميل، أو أدوات التحقق/الاتصالات، أو الترحيل من PnP/CoreKit/Torus. لا تقم بتشغيل استخدام ملحق متصفح MetaMask، أو إعدادات RainbowKit/ConnectKit المستقلة بدون Web3Auth، أو تطوير blockchain عام لا علاقة له بمصادقة المحفظة المضمنة.
