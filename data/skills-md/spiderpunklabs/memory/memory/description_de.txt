Persistenter Projektspeicher für KI-Coding-Agents. Verwaltet strukturierte Markdown-Dateien (Projektbeschreibung, Systemmuster, technischer Kontext, Fortschritt, Entscheidungen), die zwischen den Sitzungen bestehen bleiben. Wird verwendet, wenn der Benutzer „Speicherinitialisierung“, „Speicheraktualisierung“, „Speicherstatus“, „Speicherexport“, „Speicher ignorieren“, „Speicherspur“, „Speicherbereinigung“, „Speicherbank initialisieren“, „Speicherbank einrichten“, „Speicherbank erstellen“, „Speicherbank aktualisieren“, „Speicherstatus prüfen“ oder „Projektkontext aktualisieren“ sagt.
