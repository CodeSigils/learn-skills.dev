Постоянная память проектов для агентов кодирования ИИ. Поддерживает структурированные файлы уценок (краткое описание проекта, системные шаблоны, технический контекст, прогресс, решения), которые сохраняются между сеансами. Используйте, когда пользователь говорит «инициализация памяти», «обновление памяти», «статус памяти», «экспорт памяти», «игнорирование памяти», «дорожка памяти», «очистка памяти», «инициализация банка памяти», «настройка банка памяти», «создать банк памяти», «обновить банк памяти», «проверить состояние памяти» или «обновить контекст проекта».
