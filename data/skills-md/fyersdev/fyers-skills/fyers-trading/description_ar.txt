قم ببناء استراتيجيات التداول، وروبوتات الأتمتة، والبرامج النصية للاختبار الخلفي على FYERS Trading API v3 (الأسواق الهندية - NSE/BSE/MCX). يُستخدم عندما يريد المستخدم جلب بيانات السوق أو الشموع التاريخية أو عروض الأسعار أو عمق السوق أو سلاسل الخيارات؛ تقديم أو تعديل أو إلغاء الطلبات (العادية، GTT، الطلبات الذكية)؛ إدارة المواقف/المقتنيات؛ دفق البيانات الحية عبر WebSocket؛ المصادقة باستخدام FYERS OAuth؛ أو اختبار إستراتيجية باستخدام بيانات FYERS التاريخية. المشغلات: "fyers"، "fyers api"، "fyers bot"، "استراتيجية fyers"، "fyers backtest"، "وضع أمر على fyers"، "سلسلة خيارات fyers"، "بيانات fyers التاريخية"، "fyers websocket".
