Supercharge-Modus – eine iterative Multi-Agent-Optimierungsschleife für FYERS-Handelsstrategien. Wird automatisch nach dem ersten erfolgreichen Backtest einer Strategie angeboten. Ein zentraler Orchestrator beruft einen Rat spezialisierter Strategen ein (Risiko, Rendite, Eintritt, Ausstieg, Regime, Ausführung, Optionen, Kapitaleffizienz, Robustheit, Backtest-Integrität), der die Strategie untersucht, Verbesserungen diskutiert, optimierte Varianten generiert, sie einem Backtest unterzieht und über Runden hinweg nach messbar besseren Versionen sucht – wobei alle drei Runden eine Pause für den Benutzer eingelegt wird. Kein einzelner Agent entscheidet; Das Ergebnis ist ein Ratskonsens, und die ursprüngliche Strategie bleibt immer als Grundlage erhalten. Verwenden Sie diese Option, wenn der Benutzer eine Strategie optimieren, verbessern, härten, weiterentwickeln oder einem Stresstest unterziehen möchte oder die Option „Supercharge-Modus freischalten?“ akzeptiert.
