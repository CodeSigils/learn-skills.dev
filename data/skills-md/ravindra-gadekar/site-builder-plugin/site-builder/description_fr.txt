Maître orchestrateur pour le pipeline de création de sites. Exécute 14 agents spécialisés via un flux de travail en 10 phases pour créer des sites Web complets, de l'analyse commerciale au déploiement. Prend en charge les indicateurs --init, --auto et --parallel. À utiliser lorsque l'utilisateur dit /site-builder, « créer un site Web », « repenser ce site » ou « créer un site Web ».
