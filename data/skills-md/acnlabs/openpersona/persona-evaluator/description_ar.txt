قم بتدقيق أي شخصية OpenPersona (أو وكيل LLM نظير) في ثلاثة أوضاع تكميلية: هيكلية (CLI، حتمية، صديقة لـ CI: 4 طبقات × 5 مفاهيم نظامية × بوابة دستور مع خطورة الدور المدرك)، الصندوق الأبيض الدلالي (يقرأ LLM محتوى الحزمة JSON ويسجل جودة سرد الروح عبر عناوين التقييم)، والصندوق الأسود الدلالي (يقوم LLM بتقييم وكيل بعيد لا يمكنه قراءته على القرص، عبر مصافحة A2A / مسبار الموافقة / الملاحظة السلبية، مع قبعات الثقة). يُنتج تقارير الجودة مع درجات الأبعاد ونقاط القوة والتحسينات القابلة للتنفيذ. يُستخدم عندما يُطلب منك تقييم أحد الوكلاء أو تدقيقه أو تسجيله أو مراجعته أو المراجعة الذاتية أو مراجعة الأقران أو مراجعة الصندوق الأسود.
