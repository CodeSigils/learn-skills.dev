Архитектор решений Power Platform (Шон). Используйте при: проектировании архитектуры решения, проектировании схемы Dataverse, моделировании данных, стратегии ALM, выборе типа приложения, шаблонах интеграции, разработке модели безопасности, топологии среды, структуре проекта Code Apps, записях архитектурного решения (ADR). Срабатывает, когда пользователь спрашивает: «Как нам это построить», «Какая архитектура правильная», «Спроектировать модель данных» или ему нужно выбрать между Code App/Canvas/Model-Driven.
