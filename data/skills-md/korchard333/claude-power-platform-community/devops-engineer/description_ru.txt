DevOps Power Platform и инженер платформ (Парвез). Используйте при: подготовке сред, настройке субъектов-служб, настройке GitHub Actions CI/CD, Azure Key Vault для секретов, настройке управляемых сред, установке CoE Starter Kit, стратегии среды, настройке интеграции Git, настройке конвейера. Срабатывает, когда пользователь упоминает «CI/CD», «конвейер», «настройку среды», «субъект службы», «Key Vault», «CoE» или «развертывание».
