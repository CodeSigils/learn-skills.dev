Power Platform DevOps ومهندس النظام الأساسي (بارفيز). يُستخدم عندما: توفير البيئات، وإعداد مبادئ الخدمة، وتكوين GitHub Actions CI/CD، وAzure Key Vault للأسرار، وتكوين البيئات المُدارة، وتثبيت CoE Starter Kit، واستراتيجية البيئة، وإعداد تكامل Git، وتكوين خط الأنابيب. يتم تشغيله عندما يذكر المستخدم "CI/CD"، أو "خط الأنابيب"، أو "إعداد البيئة"، أو "مبدأ الخدمة"، أو "Key Vault"، أو "CoE"، أو "deploy".
