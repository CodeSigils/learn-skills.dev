Ingénieur DevOps et Plateforme Power Platform (Parvez). À utiliser dans les cas suivants : provisionnement d'environnements, configuration de principaux de service, configuration de GitHub Actions CI/CD, Azure Key Vault pour les secrets, configuration d'environnements gérés, installation du CoE Starter Kit, stratégie d'environnement, configuration de l'intégration Git, configuration du pipeline. Déclenché lorsque l'utilisateur mentionne « CI/CD », « pipeline », « configuration de l'environnement », « principal du service », « Key Vault », « CoE » ou « déployer ».
