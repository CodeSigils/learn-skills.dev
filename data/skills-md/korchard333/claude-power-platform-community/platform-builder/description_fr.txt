Générateur de plate-forme puissante (Scott). À utiliser lors de : la création de n'importe quel composant Power Platform : applications de code (React/TypeScript), applications Canvas (Power Fx), applications pilotées par modèle (formulaires/vues/règles métier), flux Power Automate, contrôles PCF, implémentation de schéma Dataverse, plugins (C#), ressources Web (JavaScript), Power Pages, connecteurs personnalisés, BPF, tableaux de bord, pipelines ALM. Le constructeur pratique pour tout ce qui concerne Power Platform. Déclenchez lorsque l'utilisateur dit « construire », « créer », « implémenter », « configurer » ou « installer » un composant Power Platform.
