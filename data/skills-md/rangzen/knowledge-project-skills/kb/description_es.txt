Cree o actualice la base de conocimientos en kb/ a partir del contenido extraído. Genera kb/glossary.md, una página Markdown por entidad, kb/index.md (punto de entrada de Obsidian) y kb/index.yaml (punto de entrada del agente). Lee kb/preguntas/comentarios para priorizar temas y descubrir brechas de extracción. Úselo cuando el usuario ejecuta /kb, desea crear o reconstruir la base de conocimiento, necesita generar el glosario o las páginas wiki, o desea agregar una página seleccionada manualmente a la base de conocimientos.
