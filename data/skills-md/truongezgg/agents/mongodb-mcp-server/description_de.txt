Anleitung zur Verwendung des Mongodb-MCP-Servers für die direkte Mongodb-Datenbankinspektion in Clients, die Mongodb-Tools verfügbar machen. Verwenden Sie ChatGPT, wenn Sie eine bestehende Verbindung bestätigen oder wechseln, Datenbanken und Sammlungen überprüfen, Daten abfragen, die Leistung erläutern, Ergebnisse exportieren, die MongoDB-Wissenssuche verwenden oder direkte Mongo-Verbindungsprobleme beheben müssen, ohne auf atlasspezifische Workflows angewiesen zu sein. Passen Sie sich an die tatsächliche Werkzeugoberfläche an, die vom laufenden Client bereitgestellt wird, anstatt davon auszugehen, dass alle Mongodb-MCP-Funktionen verfügbar sind.
