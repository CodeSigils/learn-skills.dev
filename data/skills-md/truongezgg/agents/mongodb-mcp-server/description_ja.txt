mongodb ツールを公開するクライアントで mongodb データベースを直接検査するために mongodb mcp サーバーを使用するためのガイダンス。 chatgpt が既存の接続の確認または切り替え、データベースとコレクションの検査、データのクエリ、パフォーマンスの説明、結果のエクスポート、mongodb ナレッジ検索の使用、またはアトラス固有のワークフローに依存せずに直接 mongo 接続の問題をトラブルシューティングする必要がある場合に使用します。すべての mongodb mcp 機能が利用可能であると仮定するのではなく、実行中のクライアントによって公開される実際のツール サーフェイスに適応します。
