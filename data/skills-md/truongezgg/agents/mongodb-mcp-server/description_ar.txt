إرشادات لاستخدام خادم mongodb mcp للفحص المباشر لقاعدة بيانات mongodb في العملاء الذين يكشفون عن أدوات mongodb. يُستخدم عندما يحتاج chatgpt إلى تأكيد اتصال موجود أو تبديله، أو فحص قواعد البيانات والمجموعات، أو الاستعلام عن البيانات، أو شرح الأداء، أو تصدير النتائج، أو استخدام بحث المعرفة mongodb، أو استكشاف مشكلات اتصال mongo المباشر وإصلاحها دون الاعتماد على سير العمل الخاص بأطلس. التكيف مع سطح الأداة الفعلي الذي يعرضه العميل قيد التشغيل بدلاً من افتراض توفر كل إمكانات mongodb mcp.
