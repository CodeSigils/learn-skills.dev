Cree e implemente un servidor MCP a partir de una especificación OpenAPI/Swagger utilizando el SDK TypeScript de uso mcp. Utilice esta habilidad siempre que el usuario quiera "convertir esta especificación de OpenAPI en un servidor MCP", "hacer que esta API sea utilizable desde Claude/ChatGPT", "envolver este documento Swagger como herramientas MCP", "exponer esta API REST a un LLM", "generar herramientas MCP a partir de una especificación" o pegue/adjunte un `openapi.yaml`, `openapi.json` o `swagger.json` y solicite una versión compatible con Claude. Activar incluso si el usuario no dice "MCP": si describe una API HTTP existente (puntos finales REST, un servicio interno, una API de terceros para la que tienen una clave) y quiere que un LLM la llame, esta es la habilidad correcta. Cubre la ingesta de especificaciones (ruta de archivo, URL o pegado), mapeo de operación a herramienta, cableado de autenticación (apiKey, portador, básico, portador de OAuth), andamiaje con `create-mcp-use-app`, generación de herramientas con esquemas zod adecuados, pruebas en vivo en el inspector de uso de mcp e implementación en la nube de Manufact/mcp-use.
