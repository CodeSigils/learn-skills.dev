Crea e distribuisci un server MCP da una specifica OpenAPI/Swagger utilizzando l'SDK TypeScript con utilizzo di mcp. Utilizza questa competenza ogni volta che l'utente desidera "trasformare questa specifica OpenAPI in un server MCP", "rendere questa API utilizzabile da Claude/ChatGPT", "raggruppare questo documento Swagger come strumenti MCP", "esporre questa API REST a un LLM", "generare strumenti MCP da una specifica" o incolla/allega un `openapi.yaml`, `openapi.json` o `swagger.json` e richiede una versione compatibile con Claude. Attiva anche se l'utente non dice "MCP": se descrive un'API HTTP esistente (endpoint REST, un servizio interno, un'API di terze parti per cui dispone di una chiave) e desidera che un LLM la chiami, questa è la competenza giusta. Copre l'inserimento delle specifiche (percorso file, URL o incollato), la mappatura da operazione a strumento, il cablaggio di autenticazione (apiKey, bearer, basic, OAuth bearer), l'impalcatura con `create-mcp-use-app`, la generazione di strumenti con schemi zod adeguati, test in tempo reale nell'ispettore mcp-use e distribuzione nel cloud Manufact/mcp-use.
