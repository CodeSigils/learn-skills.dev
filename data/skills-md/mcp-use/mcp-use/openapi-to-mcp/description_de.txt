Erstellen und implementieren Sie einen MCP-Server aus einer OpenAPI-/Swagger-Spezifikation mit dem mcp-use TypeScript SDK. Verwenden Sie diesen Skill immer dann, wenn der Benutzer „diese OpenAPI-Spezifikation in einen MCP-Server umwandeln“, „diese API von Claude/ChatGPT aus nutzbar machen“, „dieses Swagger-Dokument als MCP-Tools umschließen“, „diese REST-API einem LLM zur Verfügung stellen“, „MCP-Tools aus einer Spezifikation generieren“ möchte oder eine „openapi.yaml“, „openapi.json“ oder „swagger.json“ einfügt/anhängt und nach einer Claude-kompatiblen Version fragt. Auslösen, auch wenn der Benutzer nicht „MCP“ sagt – wenn er eine vorhandene HTTP-API beschreibt (REST-Endpunkte, einen internen Dienst, eine Drittanbieter-API, für die er einen Schlüssel hat) und möchte, dass ein LLM sie aufruft, ist dies die richtige Fähigkeit. Behandelt die Spezifikationsaufnahme (Dateipfad, URL oder eingefügt), Vorgang-zu-Tool-Zuordnung, Authentifizierungsverknüpfung (apiKey, Bearer, Basic, OAuth-Bearer), Gerüstbau mit „create-mcp-use-app“, Toolgenerierung mit geeigneten Zod-Schemas, Live-Tests im mcp-use-Inspektor und die Bereitstellung in der Manufact-/mcp-use-Cloud.
