使用 mcp-use TypeScript SDK 根据 OpenAPI / Swagger 规范构建和部署 MCP 服务器。每当用户想要“将此 OpenAPI 规范转换为 MCP 服务器”、“使此 API 可从 Claude/ChatGPT 中使用”、“将此 Swagger 文档包装为 MCP 工具”、“将此 REST API 公开给 LLM”、“从规范生成 MCP 工具”，或粘贴/附加 `openapi.yaml`、`openapi.json` 或 `swagger.json` 并请求 Claude 兼容时，请使用此技能版本。即使用户没有说“MCP”，也会触发 — 如果他们描述现有的 HTTP API（REST 端点、内部服务、他们拥有密钥的第三方 API）并希望 LLM 调用它，那么这就是正确的技能。涵盖规范摄取（文件路径、URL 或粘贴）、操作到工具的映射、身份验证连接（apiKey、承载、基本、OAuth 承载）、使用“create-mcp-use-app”的脚手架、使用正确的 zod 模式生成工具、mcp-use 检查器中的实时测试以及部署到 Manufact/mcp-use 云。
