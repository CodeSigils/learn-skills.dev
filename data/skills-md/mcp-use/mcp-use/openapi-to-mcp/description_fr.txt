Créez et déployez un serveur MCP à partir d'une spécification OpenAPI / Swagger à l'aide du SDK TypeScript utilisé par mcp. Utilisez cette compétence chaque fois que l'utilisateur souhaite « transformer cette spécification OpenAPI en serveur MCP », « rendre cette API utilisable à partir de Claude/ChatGPT », « envelopper ce document Swagger en tant qu'outils MCP », « exposer cette API REST à un LLM », « générer des outils MCP à partir d'une spécification », ou coller/attacher un « openapi.yaml », « openapi.json » ou « swagger.json » et demande une version compatible avec Claude. Déclenchez même si l'utilisateur ne dit pas "MCP" - s'il décrit une API HTTP existante (points de terminaison REST, un service interne, une API tierce pour laquelle il a une clé) et souhaite qu'un LLM l'appelle, c'est la bonne compétence. Couvre l'ingestion des spécifications (chemin du fichier, URL ou collé), le mappage opération-outil, le câblage d'authentification (apiKey, Bearer, Basic, OAuth Bearer), l'échafaudage avec `create-mcp-use-app`, la génération d'outils avec les schémas zod appropriés, les tests en direct dans l'inspecteur mcp-use et le déploiement sur le cloud Manufact/mcp-use.
