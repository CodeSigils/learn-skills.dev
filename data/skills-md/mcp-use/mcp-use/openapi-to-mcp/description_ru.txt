Создайте и разверните сервер MCP на основе спецификации OpenAPI/Swagger, используя TypeScript SDK для mcp-use. Используйте этот навык всякий раз, когда пользователь хочет «превратить эту спецификацию OpenAPI в сервер MCP», «сделать этот API пригодным для использования из Claude/ChatGPT», «обернуть этот документ Swagger как инструменты MCP», «открыть этот REST API для LLM», «создать инструменты MCP из спецификации» или вставить/присоединить `openapi.yaml`, `openapi.json` или `swagger.json` и запрашивает Версия, совместимая с Клодом. Триггер, даже если пользователь не говорит «MCP» — если он описывает существующий HTTP API (конечные точки REST, внутренний сервис, сторонний API, для которого у него есть ключ) и хочет, чтобы LLM вызывал его, это правильный навык. Охватывает прием спецификаций (путь к файлу, URL-адрес или вставку), сопоставление операции с инструментом, подключение аутентификации (apiKey, носитель, базовый носитель, носитель OAuth), создание шаблонов с помощью `create-mcp-use-app`, генерацию инструментов с правильными схемами zod, тестирование в реальном времени в инспекторе mcp-use и развертывание в облаке Manufact/mcp-use.
