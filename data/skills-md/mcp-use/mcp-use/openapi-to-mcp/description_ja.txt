mcp-use TypeScript SDK を使用して、OpenAPI / Swagger 仕様から MCP サーバーを構築してデプロイします。ユーザーが「この OpenAPI 仕様を MCP サーバーに変換する」、「この API を Claude/ChatGPT から使用できるようにする」、「この Swagger ドキュメントを MCP ツールとしてラップする」、「この REST API を LLM に公開する」、「仕様から MCP ツールを生成」する場合、または `openapi.yaml`、`openapi.json`、または `swagger.json` を貼り付け/添付して、クロード互換バージョン。ユーザーが「MCP」と言わなくてもトリガーします。ユーザーが既存の HTTP API (REST エンドポイント、内部サービス、キーを持っているサードパーティ API) を記述し、LLM にそれを呼び出してもらいたい場合、これが適切なスキルです。仕様の取り込み (ファイル パス、URL、または貼り付け)、操作とツールのマッピング、認証ワイヤリング (apiKey、ベアラー、ベーシック、OAuth ベアラー)、「create-mcp-use-app」によるスキャフォールディング、適切な zod スキーマによるツールの生成、mcp 使用インスペクターでのライブ テスト、および Manufact / mcp 使用クラウドへのデプロイをカバーします。
