قم ببناء خادم MCP ونشره من مواصفات OpenAPI / Swagger باستخدام TypeScript SDK الذي يستخدمه mcp. استخدم هذه المهارة عندما يريد المستخدم "تحويل مواصفات OpenAPI هذه إلى خادم MCP"، أو "جعل واجهة برمجة التطبيقات هذه قابلة للاستخدام من Claude/ChatGPT"، أو "تغليف مستند Swagger هذا كأدوات MCP"، أو "كشف REST API إلى LLM"، أو "إنشاء أدوات MCP من أحد المواصفات"، أو لصق/إرفاق "openapi.yaml"، أو "openapi.json"، أو "swagger.json" ويطلب نسخة متوافقة مع كلود. قم بالتشغيل حتى لو لم يقل المستخدم "MCP" - إذا وصف واجهة برمجة تطبيقات HTTP موجودة (نقاط نهاية REST، خدمة داخلية، واجهة برمجة تطبيقات تابعة لجهة خارجية لديهم مفتاح لها) ويريد من LLM أن يستدعيها، فهذه هي المهارة الصحيحة. يغطي نقل المواصفات (مسار الملف، عنوان URL، أو لصقه)، وتخطيط العملية للأداة، وأسلاك المصادقة (apiKey، الحامل، الأساسي، حامل OAuth)، السقالات باستخدام " create-mcp-use-app"، وإنشاء الأدوات باستخدام مخططات zod المناسبة، والاختبار المباشر في مفتش استخدام mcp، والنشر إلى سحابة Manufact / mcp.
