UI の実装と批評のための構造化されたスクリーンショット分析。 5×5 の空間グリッド、完全な要素インベントリ、デザイン システムの抽出を使用してすべての UI スクリーンショットを分析し、事実と好みを毎回一緒に分析します。構築時に完全な実装ブループリントにエスカレーションします。デジタル インターフェイス イメージ (Web サイト、アプリ、ダッシュボード、モックアップ、ワイヤーフレーム) または「このスクリーンショットを分析する」、「これを再構築する」、「このデザインに一致させる」、「これを複製する」などのコマンドをトリガーします。ユーザーが明示的に UI を構築したい場合を除き、非 UI 画像 (写真、ミーム、チャート) についてはスキップしてください。
