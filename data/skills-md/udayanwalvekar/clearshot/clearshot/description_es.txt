Análisis de capturas de pantalla estructurado para implementación y crítica de UI. Analiza cada captura de pantalla de la interfaz de usuario con una cuadrícula espacial de 5×5, un inventario completo de elementos y una extracción del sistema de diseño: hechos y gustos juntos, en todo momento. Escala al plan de implementación completo durante la construcción. Active cualquier imagen de interfaz digital (sitios web, aplicaciones, paneles, maquetas, estructuras alámbricas) o comandos como "analizar esta captura de pantalla", "reconstruir esto", "hacer coincidir este diseño", "clonar esto". Omita las imágenes que no sean de interfaz de usuario (fotos, memes, gráficos) a menos que el usuario desee explícitamente crear una interfaz de usuario a partir de ellas.
