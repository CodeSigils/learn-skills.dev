Fügen Sie ein korrektes UML-Klassendiagramm – als einbettbares Bild – in Ihre Dokumente ein. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer ein UML-Klassendiagramm für eine README-Datei, ein Designdokument, ein Wiki, eine Folie oder eine „.md“-Spezifikation hinzufügen, zeichnen, einbetten oder exportieren möchte: Es erstellt ein strukturell korrektes Modell (Klassen, Attribute, Assoziationen, Vererbung, Multiplizitäten) – aus einer Beschreibung oder aus vorhandenem Code, den der Agent liest – und liefert es entweder als im Dokument eingebetteter B-UML-Code oder als gerendertes SVG/PNG-Bild (das Der Agent kann es mit einem einzigen Aufruf an den Headless SVG-Endpunkt von BESSER selbst rendern oder aus dem BESSER-Webeditor exportieren. Auslösen bei „Einbetten eines UML-Diagramms“, „Fügen Sie ein Klassendiagramm zur README-Datei hinzu“, „Zeichnen Sie das Datenmodell“, „Diagramm meines Codes“, „Exportieren Sie das Diagramm als Bild/SVG/PNG“ oder bei jeder Anforderung eines Diagramms, das sowohl richtig aussehen als auch genau bleiben sollte. Das Diagramm wird immer über ein echtes BESSER B-UML-Modell erstellt, sodass auch Code generiert werden kann. Für die detaillierte Erstellung von Modellen wenden Sie sich bitte an besser-user. Um daraus Code zu generieren, verwenden Sie besser-Generatoren. Derzeitiger Geltungsbereich: UML **nur Klassendiagramme**, immer über BESSER B-UML – andere Diagrammtypen (Zustandsmaschinen, Objektdiagramme, Sequenzdiagramme usw.) liegen außerhalb des Geltungsbereichs.
