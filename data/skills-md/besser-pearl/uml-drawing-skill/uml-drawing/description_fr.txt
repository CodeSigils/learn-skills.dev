Insérez un diagramme de classes UML correct (sous forme d'image intégrable) dans vos documents. Utilisez cette compétence chaque fois que l'utilisateur souhaite ajouter, dessiner, intégrer ou exporter un diagramme de classes UML pour un README, un document de conception, un wiki, une diapositive ou une spécification `.md` : il construit un modèle structurellement correct (classes, attributs, associations, héritage, multiplicités) — à partir d'une description ou à partir du code existant lu par l'agent — et le fournit soit sous forme de code B-UML incorporé dans le document, soit sous forme d'image SVG/PNG rendue (l'agent peut le restituer lui-même avec un appel unique au point de terminaison SVG sans tête de BESSER, ou exportez-le depuis l'éditeur Web BESSER). Déclenchez sur "intégrer un diagramme UML", "ajouter un diagramme de classes au README", "dessiner le modèle de données", "dessiner mon code", "exporter le diagramme sous forme d'image/SVG/PNG", ou toute demande de diagramme qui doit à la fois paraître correct et rester précis. Le diagramme est toujours construit à l'aide d'un véritable modèle BESSER B-UML, il peut donc également générer du code — pour la construction de modèles en profondeur, c'est à l'utilisateur Besser ; pour générer du code à partir d'eux, confiez-vous aux meilleurs générateurs. Portée pour l'instant : UML **diagrammes de classes uniquement**, toujours via BESSER B-UML — les autres types de diagrammes (machines à états, diagrammes d'objets, diagrammes de séquence, etc.) sont hors de portée.
