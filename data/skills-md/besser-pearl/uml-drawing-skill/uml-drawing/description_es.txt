Coloque un diagrama de clases UML correcto, como una imagen incrustable, en sus documentos. Utilice esta habilidad siempre que el usuario quiera agregar, dibujar, incrustar o exportar un diagrama de clases UML para un archivo README, documento de diseño, wiki, diapositiva o especificación `.md`: crea un modelo estructuralmente correcto (clases, atributos, asociaciones, herencia, multiplicidades), a partir de una descripción o de un código existente que lee el agente, y lo entrega como código B-UML incrustado en el documento o como una imagen SVG/PNG renderizada (el agente puede renderizarla él mismo con un solo archivo). llamar al punto final SVG sin cabeza de BESSER o exportarlo desde el editor web de BESSER). Active "incrustar un diagrama UML", "agregar un diagrama de clases al archivo README", "dibujar el modelo de datos", "diagramar mi código", "exportar el diagrama como una imagen/SVG/PNG" o cualquier solicitud de un diagrama que deba verse bien y ser preciso. El diagrama siempre se construye a través de un modelo BESSER B-UML real, por lo que también puede generar código; para construir modelos en profundidad, consulte a besser-user; para generar código a partir de ellos, remítase a los mejores generadores. Alcance por ahora: UML **solo diagramas de clases**, siempre a través de BESSER B-UML; otros tipos de diagramas (máquinas de estado, diagramas de objetos, diagramas de secuencia, etc.) están fuera del alcance.
