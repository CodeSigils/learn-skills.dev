マルチステップの作業をスタックされたドラフト プル リクエストのチェーンとして提供します。ステップごとに 1 つのブランチがあり、それぞれが前のステップのブランチから分岐し、前のステップのブランチをターゲットにします。ユーザーがスタックされた PR またはスタックされた diff、PR スタックまたはチェーン、増分ステップバイステップのレビューを要求する場合、または大きなタスクを小さな依存 PR に分割する場合に使用します。既存のスタック (連鎖ブランチ、たとえば stack/<name>/NN-* または feature/NN-*) に属する PR の更新、リベース、またはレビュー フィードバックに対処するときにも使用します。特に、レビュー可能な増分として大規模な自律的な変更を提供するクラウド/バックグラウンド コーディング エージェントに適しています。
