Rufen Sie Webseiteninhalte als sauberen Markdown/Text von einer URL ab. Verwenden Sie diese Option, wenn der Benutzer eine URL bereitstellt und deren Inhalt lesen, extrahieren oder analysieren möchte. Wird bei Anfragen wie „Diese Seite abrufen“, „Diese URL lesen“, „Inhalt abrufen von“, „Diesen Artikel zusammenfassen“ oder bei jeder Aufgabe ausgelöst, die eine Webseitentextextraktion erfordert.
