Récupérez le contenu d'une page Web sous forme de démarque/texte propre à partir d'une URL. À utiliser lorsque l'utilisateur fournit une URL et souhaite lire, extraire ou analyser son contenu. Se déclenche sur des requêtes telles que « récupérer cette page », « lire cette URL », « récupérer le contenu de », « résumer cet article » ou toute tâche nécessitant une extraction de texte de page Web.
