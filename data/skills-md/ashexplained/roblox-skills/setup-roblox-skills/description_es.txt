Arranque el paquete de habilidades de Roblox en un proyecto de juego inyectando un bloque `## Roblox Skills` en CLAUDE.md: el mapa completo del ciclo de vida del desarrollo del juego, el propósito de cada habilidad, el caso de uso y las palabras desencadenantes, y la ruta de la siguiente habilidad para que cada habilidad termine diciéndole al usuario qué ejecutar a continuación. También registra el rastreador del proyecto (problemas de GitHub o hoja de ruta local), etiquetas de clasificación y diseño de artefactos de diseño de interfaz de usuario. Ejecútelo una vez al configurar un proyecto de Roblox, o si parece que a las habilidades les falta el ciclo de vida, el rastreador, la etiqueta o el contexto de enrutamiento.
