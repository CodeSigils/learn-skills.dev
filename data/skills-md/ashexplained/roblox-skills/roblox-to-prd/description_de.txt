Verwandeln Sie ein Roblox-Spielkonzept oder das aktuelle Gespräch in einen kurzen, baubaren PRD (Game Design Brief) und veröffentlichen Sie ihn im Projekt-Tracker. Verwenden Sie diese Option, wenn der Benutzer ein ausgewähltes Konzept vor dem Erstellen in eine Spezifikation einbinden, eine Designbeschreibung schreiben oder eine PRD für ein Roblox-Spiel oder eine Roblox-Funktion erstellen möchte. Kombiniert mit Roblox-to-Issues, das die PRD in vertikale Scheiben aufteilt, sodass das Spiel einzeln spielbar aufgebaut wird und nicht alles auf einmal.
