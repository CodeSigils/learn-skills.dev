Turn a Roblox game concept or the current conversation into a short, buildable PRD (game design brief) and publish it to the project tracker. Use when the user wants to lock a chosen concept into a spec before building, write a design brief, or create a PRD for a Roblox game or feature. Pairs with roblox-to-issues, which slices the PRD into vertical slices so the game is built one playable piece at a time instead of all at once.
