قم بتدقيق متجر Roblox Creator Store، وToolbox، والمخزون، والمجموعة، والكون، والحزمة، والنموذج، وواجهة المستخدم، وطريقة اللعب، والمكونات الإضافية، وغيرها من الأصول المستوردة من جهات خارجية للبرامج النصية الضارة أو المحفوفة بالمخاطر. يُستخدم عندما يقوم Claude باستيراد أصول Creator Store أو إدراجها أو مراجعتها أو الوثوق بها، وخاصة الأصول التي تحتوي على نصوص برمجية أو LocalScripts أو ModuleScripts أو فروع مخفية أو تتطلب مكالمات أو HTTP أو DataStore أو الإنشاء عن بعد أو التعليمات البرمجية المبهمة أو الأسماء المشبوهة.
