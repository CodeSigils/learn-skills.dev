K-12 Teaching Kit Customization Tool helps teachers adjust the default behavior of all tw-edu-* Skills to their individual contexts. After entering teacher data, it generates a teacher-profile.md configuration file; subsequent tw-edu-* Skills can read this file to auto-customize.
