K-12 Teaching Kit-Anpassungstool, das Lehrern dabei hilft, das Standardverhalten aller tw-edu-*-Fähigkeiten an ihren persönlichen Kontext anzupassen. Nach der Eingabe der Lehrerdaten wird eine Konfigurationsdatei teacher-profile.md generiert. Anschließend können alle tw-edu-* Skills diese Datei lesen, um sie automatisch anzupassen. Wird ausgelöst, wenn Benutzer „Unterrichtspräferenzen festlegen“, „Unterrichtstools anpassen“, „Lehrereinstellungen“, „Meinen Unterrichtskontext festlegen“, „Unterrichtseinstellungen personalisieren“ oder „Die Tools besser an meine Schule anpassen“ erwähnen. Kategorie: K-12-Unterricht (tw-edu-*)
