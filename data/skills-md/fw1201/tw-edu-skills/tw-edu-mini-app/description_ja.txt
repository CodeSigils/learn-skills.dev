インタラクティブな教育ミニアプリ (クイズ/ゲーム/タイマー/ランダム グループ化など) を開発し、Vercel または GitHub Pages に自動デプロイして、永続的な共有可能なリンクを生成します。ユーザーが「ミニアプリの作成」、「教育ゲーム」、「インタラクティブなクイズ」、「オンライン テスト」、「描画プログラムの作成」、「ランダム グループ化ツール」、「タイマー」、「Kahoot の代替」、「教育ツールの開発」、「共有可能な教育ページの構築」、または「Web への展開」などのフレーズに言及するとトリガーされます。技術スタック: React + Tailwind CSS → Vercel (推奨) または GitHub Pages
