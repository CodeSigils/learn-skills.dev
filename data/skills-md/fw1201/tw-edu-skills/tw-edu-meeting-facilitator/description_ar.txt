قم بتصميم جداول الأعمال ونماذج التسجيل لمجتمعات التعلم المهنية للمعلمين (PLC)، ولجان تطوير المناهج الدراسية، والاجتماعات الإدارية، وتخطيط الدروس التعاونية، واستخدم Google Calendar MCP لإعداد تذكيرات الاجتماعات، وGoogle Drive MCP لتخزين السجلات، وGmail MCP لإرسال ملخصات إلى الحضور. يتم تشغيله عندما يذكر المستخدم "PLC"، أو "لجنة تطوير المنهج الدراسي"، أو "محضر الاجتماع"، أو "مجتمع المعلمين"، أو "اجتماع تخطيط الدروس"، أو "البحث التعليمي"، أو "التخطيط التعاوني"، أو "المجتمع المهني"، أو "اجتماع المشرف"، أو "اجتماع المعلمين"، أو "الاجتماع".
