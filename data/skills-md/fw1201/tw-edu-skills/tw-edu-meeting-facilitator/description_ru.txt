Создавайте повестки дня и шаблоны записей для сообществ профессионального обучения учителей (PLC), комитетов по учебным программам, административных собраний и совместного планирования уроков, а также используйте Google Calendar MCP для настройки напоминаний о собраниях, Google Drive MCP для хранения записей и Gmail MCP для отправки сводок участникам. Активируется, когда пользователи упоминают «ПЛК», «учебный комитет», «протокол собрания», «сообщество учителей», «совещание по планированию урока», «обсуждение преподавания», «совместное планирование», «профессиональное сообщество», «административное собрание», «собрание учителей» или «встреча».
