Запустите рабочие процессы создания изображений на локальном экземпляре ComfyUI (localhost:8188). Используйте этот навык, когда пользователь хочет создавать изображения с помощью ComfyUI, включая генерацию текста в изображение FLUX.2 или любой рабочий процесс, требующий постановки запроса в очередь к API ComfyUI. Запускается, когда пользователи упоминают ComfyUI, «создают изображение» или хотят запустить рабочий процесс распространения локально.
