Ejecute flujos de trabajo de generación de imágenes en una instancia local de ComfyUI (localhost:8188). Utilice esta habilidad cuando el usuario quiera generar imágenes usando ComfyUI, incluida la generación de texto a imagen FLUX.2 o cualquier flujo de trabajo que requiera poner en cola un mensaje a la API de ComfyUI. Se activa cuando los usuarios mencionan ComfyUI, "generan una imagen" o desean ejecutar un flujo de trabajo de difusión localmente.
