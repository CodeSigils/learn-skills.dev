Пошаговый рабочий процесс агента для настройки интерфейса командной строки OpenAI Codex на любом компьютере (Linux, macOS, Windows) для использования OmniRoute в качестве бэкэнда, совместимого с OpenAI. Обнаруживает ОС и оболочку, записывает config.toml и 7 именованных профилей, устанавливает переменные среды и проверяет настройку.
