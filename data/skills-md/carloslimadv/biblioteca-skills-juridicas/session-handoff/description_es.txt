Use quando o usuario quiser encerrar, pausar, compactar o transferir una conversación/trabalho para otra sesión sin perder contexto. Gera um documento Markdown de handoff autosuficiente com objetivo, contexto esencial, estado actual, próximos pasos, perguntas abiertas, artefatos relevantes e instrucciones para una próxima sesión. Acione em pedidos como "gere um handoff", "vou continuar em outra conversa", "preciso encerrar a sessao", "documente onde paramos" o "crie um resumo completo para retomada".
