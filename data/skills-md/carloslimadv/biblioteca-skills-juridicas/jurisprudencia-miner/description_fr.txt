Utilisez quando a tarefa principal for pesquisar, localizar, levantar, validar, comparar ou resumir jurisprudencia brasileira, inclusive precedente, entendimento do STJ/STF, sumula, the repetitivo, repercussao geral, IRDR, IAC ou acordao. Donner la priorité à cette compétence pour la pêche jurisprudenciale estruturada, classificacao de confianca et construcao de base segura de precedentes. Nao usar como skills principal para apenas testar a solidez stratégique de uma tese ; pour cela, utilisez tese-juridica-validator.
