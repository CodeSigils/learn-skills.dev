Use quando a tarefa principal for pesquisar, localizar, levantar, validar, comparar ou resumir jurisprudencia brasileira, inclusive precedente, entendimento do STJ/STF, sumula, tema repetitivo, repercussao geral, IRDR, IAC ou acordao. Priorize esta skill para pesquisa jurisprudencial estruturada, classificacao de confianca e construcao de base segura de precedentes. Nao usar como skill principal para apenas testar a solidez estrategica de uma tese; para isso, usar tese-juridica-validator.
