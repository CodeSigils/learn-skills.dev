Use quando a tarefa principal para pesquisar, localizar, levantar, validar, comparar o resumir jurisprudencia brasileña, inclusive precedente, entendimento do STJ/STF, sumula, tema repetitivo, repercussao geral, IRDR, IAC o acordao. Priorice esta habilidad para pesquisa jurisprudencial estruturada, classificacao de confianca e construcao de base segura de precedentes. Nao usar como habilidad principal para apenas probar a solidez estrategica de uma tese; Para esto, use tese-juridica-validator.
