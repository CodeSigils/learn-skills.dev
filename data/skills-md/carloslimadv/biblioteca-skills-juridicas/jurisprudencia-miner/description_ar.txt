استخدم عند تطبيق مبدأ التعريفة على البحث، أو الترجمة المحلية، أو الشريعة، أو التحقق، أو المقارنة، أو استئناف الفقه البرازيلي، أو السابقة الشاملة، أو تفسير STJ/STF، أو المجموع، أو الموضوع المتكرر، أو التداعيات العامة، أو IRDR، أو IAC، أو الاتفاق. إعطاء الأولوية لهذه المهارة في البحث في الدراسات الفقهية، وتصنيف الثقة، وبناء قاعدة ضمان السوابق. لا نستخدم سوى المهارة الأساسية لاختبار التماسك الاستراتيجي لهذه النقطة؛ لذلك، استخدام المدقق القضائي.
