Erstellt Vue 3-Komponenten, erstellt Vanilla JS Composables, konfiguriert Vite-Projekte und richtet Routing und Statusverwaltung nur mit JavaScript ein – kein TypeScript. Erzeugt JSDoc-typisierten Code mit @typedef-, @param- und @returns-Annotationen für eine vollständige Typabdeckung ohne TS-Compiler. Verwenden Sie diese Option, wenn Sie Vue 3-Anwendungen nur mit JavaScript (kein TypeScript) erstellen, wenn Projekte JSDoc-basierte Typhinweise erfordern, wenn Sie von der Vue 2 Options API zur Composition API in JS migrieren oder wenn Teams Vanilla-JavaScript, .mjs-Module bevorzugen oder schnelle Prototypen ohne TypeScript-Setup benötigen.
