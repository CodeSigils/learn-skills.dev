Vue 3 구성요소를 생성하고, 바닐라 JS 컴포저블을 빌드하고, Vite 프로젝트를 구성하고, TypeScript가 아닌 JavaScript만 사용하여 라우팅 및 상태 관리를 설정합니다. TS 컴파일러 없이 전체 유형 적용을 위해 @typedef, @param 및 @returns 주석을 사용하여 JSDoc 유형 코드를 생성합니다. JavaScript만 사용하여(TypeScript 없음) Vue 3 애플리케이션을 구축할 때, 프로젝트에 JSDoc 기반 유형 힌트가 필요할 때, Vue 2 옵션 API에서 JS의 Composition API로 마이그레이션할 때, 팀이 바닐라 JavaScript, .mjs 모듈을 선호하거나 TypeScript 설정 없이 빠른 프로토타입이 필요할 때 사용합니다.
