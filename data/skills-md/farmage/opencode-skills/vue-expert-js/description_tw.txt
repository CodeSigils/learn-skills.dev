僅使用 JavaScript（不使用 TypeScript）建立 Vue 3 元件、建置普通 JS 可組合項目、設定 Vite 專案以及設定路由和狀態管理。使用 @typedef、@param 和 @returns 註解產生 JSDoc 類型程式碼，以實現完整型別覆蓋，無需 TS 編譯器。僅使用 JavaScript（無 TypeScript）建立 Vue 3 應用程式時，當專案需要基於 JSDoc 的類型提示時，當從 Vue 2 Options API 遷移到 JS 中的 Composition API 時，或者當團隊更喜歡普通 JavaScript、.mjs 模組或需要無需 TypeScript 設定的快速原型時使用。
