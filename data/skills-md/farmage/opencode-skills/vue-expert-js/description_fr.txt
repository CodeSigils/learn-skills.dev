Crée des composants Vue 3, construit des composables Vanilla JS, configure des projets Vite et configure le routage et la gestion des états en utilisant uniquement JavaScript – pas de TypeScript. Génère du code typé JSDoc avec les annotations @typedef, @param et @returns pour une couverture complète des types sans compilateur TS. À utiliser lors de la création d'applications Vue 3 avec JavaScript uniquement (pas de TypeScript), lorsque les projets nécessitent des astuces de type basées sur JSDoc, lors de la migration de l'API d'options Vue 2 vers l'API de composition dans JS, ou lorsque les équipes préfèrent JavaScript vanille, les modules .mjs ou ont besoin de prototypes rapides sans configuration TypeScript.
