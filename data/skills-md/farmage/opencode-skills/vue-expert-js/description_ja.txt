TypeScript を使用せず、JavaScript のみを使用して Vue 3 コンポーネントを作成し、バニラ JS コンポーザブルをビルドし、Vite プロジェクトを構成し、ルーティングと状態管理をセットアップします。 TS コンパイラを使用せずに、完全な型をカバーする @typedef、@param、および @returns アノテーションを使用して JSDoc 型のコードを生成します。 JavaScript のみ (TypeScript なし) で Vue 3 アプリケーションを構築する場合、プロジェクトで JSDoc ベースのタイプ ヒントが必要な場合、Vue 2 オプション API から JS のコンポジション API に移行する場合、またはチームがバニラ JavaScript、.mjs モジュールを好む場合、または TypeScript をセットアップせずに迅速なプロトタイプが必要な場合に使用します。
