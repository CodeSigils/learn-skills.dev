Crea componenti Vue 3, crea componenti componibili JS Vanilla, configura progetti Vite e imposta il routing e la gestione dello stato utilizzando solo JavaScript, senza TypeScript. Genera codice tipizzato JSDoc con annotazioni @typedef, @param e @returns per una copertura completa dei tipi senza un compilatore TS. Da utilizzare quando si creano applicazioni Vue 3 solo con JavaScript (senza TypeScript), quando i progetti richiedono suggerimenti di tipo basati su JSDoc, durante la migrazione dall'API Vue 2 Options all'API Composition in JS o quando i team preferiscono JavaScript vanilla, moduli .mjs o necessitano di prototipi rapidi senza configurazione TypeScript.
