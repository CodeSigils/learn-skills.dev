Crea componentes de Vue 3, crea elementos componibles JS básicos, configura proyectos de Vite y configura el enrutamiento y la administración de estado usando solo JavaScript, sin TypeScript. Genera código tipo JSDoc con anotaciones @typedef, @param y @returns para una cobertura de tipo completa sin un compilador TS. Úselo cuando cree aplicaciones Vue 3 solo con JavaScript (sin TypeScript), cuando los proyectos requieran sugerencias de tipo basadas en JSDoc, cuando migre de la API de opciones de Vue 2 a la API de composición en JS, o cuando los equipos prefieran JavaScript básico, módulos .mjs o necesiten prototipos rápidos sin configuración de TypeScript.
