Создает компоненты Vue 3, создает стандартные компоненты JS, настраивает проекты Vite и настраивает маршрутизацию и управление состоянием, используя только JavaScript — без TypeScript. Генерирует код типа JSDoc с аннотациями @typedef, @param и @returns для полного покрытия типов без компилятора TS. Используйте при создании приложений Vue 3 только с использованием JavaScript (без TypeScript), когда проектам требуются подсказки типов на основе JSDoc, при переходе от Vue 2 Options API к Composition API в JS или когда команды предпочитают стандартный JavaScript, модули .mjs или нужны быстрые прототипы без настройки TypeScript.
