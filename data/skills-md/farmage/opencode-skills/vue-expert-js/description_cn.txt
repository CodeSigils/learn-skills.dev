仅使用 JavaScript（不使用 TypeScript）创建 Vue 3 组件、构建普通 JS 可组合项、配置 Vite 项目以及设置路由和状态管理。使用 @typedef、@param 和 @returns 注释生成 JSDoc 类型代码，以实现完整类型覆盖，无需 TS 编译器。仅使用 JavaScript（无 TypeScript）构建 Vue 3 应用程序时，当项目需要基于 JSDoc 的类型提示时，当从 Vue 2 Options API 迁移到 JS 中的 Composition API 时，或者当团队更喜欢普通 JavaScript、.mjs 模块或需要无需 TypeScript 设置的快速原型时使用。
