À utiliser lors de l'écriture de tests E2E avec Playwright, de la configuration d'une infrastructure de test ou du débogage de tests de navigateur instables. Invoquez pour écrire des scripts de test, créer des objets de page, configurer des appareils de test, configurer des rapporteurs, ajouter une intégration CI, implémenter une simulation d'API ou effectuer des tests de régression visuelle. Termes déclencheurs : dramaturge, test E2E, de bout en bout, tests de navigateur, automatisation, tests d'interface utilisateur, tests visuels, modèle d'objet de page, test de fragilité.
