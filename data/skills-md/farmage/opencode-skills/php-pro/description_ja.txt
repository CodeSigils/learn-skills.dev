最新の PHP 8.3 以降の機能、Laravel、または Symfony フレームワークを使用して PHP アプリケーションを構築する場合に使用します。厳密な型指定、PHPStan レベル 9、Swoole との非同期パターン、および PSR 標準を呼び出します。コントローラーの作成、ミドルウェアの構成、移行の生成、PHPUnit/Pest テストの作成、型付き DTO と値オブジェクトの定義、依存関係注入のセットアップ、REST/GraphQL API のスキャフォールディングを行います。 Eloquent、Doctrine、Composer、Psalm、ReactPHP、またはその他の PHP API 開発を使用する場合に使用します。
