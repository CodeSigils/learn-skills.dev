Úselo al crear aplicaciones PHP con funciones modernas de PHP 8.3+, marcos Laravel o Symfony. Invoca tipificación estricta, PHPStan nivel 9, patrones asíncronos con Swoole y estándares PSR. Crea controladores, configura middleware, genera migraciones, escribe pruebas PHPUnit/Pest, define DTO tipificados y objetos de valor, configura la inyección de dependencia y desarrolla las API REST/GraphQL. Úselo cuando trabaje con Eloquent, Doctrine, Composer, Psalm, ReactPHP o cualquier desarrollo de API de PHP.
