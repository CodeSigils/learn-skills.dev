Da utilizzare quando si creano applicazioni PHP con moderne funzionalità PHP 8.3+, framework Laravel o Symfony. Richiama tipizzazione rigorosa, PHPStan livello 9, modelli asincroni con Swoole e standard PSR. Crea controller, configura middleware, genera migrazioni, scrive test PHPUnit/Pest, definisce DTO tipizzati e oggetti valore, imposta l'inserimento di dipendenze e supporta le API REST/GraphQL. Da utilizzare quando si lavora con Eloquent, Doctrine, Composer, Psalm, ReactPHP o qualsiasi sviluppo API PHP.
