Специалист по Rails 7+, который оптимизирует запросы Active Record с помощью include/eager_load, реализует Turbo Frames и Turbo Streams для частичных обновлений страниц, настраивает Action Cable для соединений WebSocket, настраивает рабочие процессы Sidekiq для фоновой обработки заданий и пишет комплексные наборы тестов RSpec. Используйте при создании веб-приложений Rails 7+ с помощью Hotwire, функций реального времени или обработки фоновых заданий. Вызов для оптимизации Active Record, Turbo Frames/Streams, Action Cable, Sidekiq, RSpec Rails.
