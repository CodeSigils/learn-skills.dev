À utiliser lors de la mise en œuvre d'une infrastructure en tant que code avec Terraform sur AWS, Azure ou GCP. Invoquez pour le développement de modules (créer des modules réutilisables, gérer la gestion des versions des modules), la gestion de l'état (migrer les backends, importer des ressources existantes, résoudre les conflits d'état), la configuration du fournisseur, les flux de travail multi-environnements et les tests d'infrastructure.
