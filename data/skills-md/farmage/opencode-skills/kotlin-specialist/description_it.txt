Fornisce modelli di implementazione idiomatici di Kotlin tra cui concorrenza coroutine, gestione del flusso di flusso, architettura multipiattaforma, costruzione dell'interfaccia utente Compose, configurazione del server Ktor e progettazione DSL indipendente dai tipi. Da utilizzare durante la creazione di applicazioni Kotlin che richiedono coroutine, sviluppo multipiattaforma o Android con Compose. Invoca per Flow API, progetti KMP, server Ktor, progettazione DSL, classi sigillate, funzione di sospensione, Android Kotlin, Kotlin Multiplatform.
