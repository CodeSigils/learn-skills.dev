.NET 8+、ASP.NET Core API、または Blazor Web アプリを使用して C# アプリケーションを構築する場合に使用します。最小限のルーティングまたはコントローラーベースのルーティングを使用して REST API を構築し、Entity Framework Core を使用してデータベース アクセスを構成し、非同期パターンとキャンセルを実装し、MediatR を介して CQRS を使用してアプリケーションを構造化し、状態管理を使用して Blazor コンポーネントをスキャフォールディングします。 C#、.NET、ASP.NET Core、Blazor、Entity Framework、EF Core、Minimal API、MAUI、SignalR の呼び出し。
