Используйте при создании приложений C# с помощью .NET 8+, API-интерфейсов ASP.NET Core или веб-приложений Blazor. Создает API REST с использованием минимальной маршрутизации или маршрутизации на основе контроллера, настраивает доступ к базе данных с помощью Entity Framework Core, реализует асинхронные шаблоны и отмену, структурирует приложения с помощью CQRS через MediatR и формирует компоненты Blazor с управлением состоянием. Вызов для C#, .NET, ASP.NET Core, Blazor, Entity Framework, EF Core, Minimal API, MAUI, SignalR.
