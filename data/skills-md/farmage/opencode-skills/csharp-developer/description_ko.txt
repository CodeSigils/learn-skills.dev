.NET 8 이상, ASP.NET Core API 또는 Blazor 웹 앱을 사용하여 C# 애플리케이션을 빌드할 때 사용합니다. 최소 또는 컨트롤러 기반 라우팅을 사용하여 REST API를 구축하고, Entity Framework Core로 데이터베이스 액세스를 구성하고, 비동기 패턴 및 취소를 구현하고, MediatR을 통해 CQRS로 애플리케이션을 구조화하고, 상태 관리를 통해 Blazor 구성 요소를 스캐폴드합니다. C#, .NET, ASP.NET Core, Blazor, Entity Framework, EF Core, 최소 API, MAUI, SignalR을 호출합니다.
