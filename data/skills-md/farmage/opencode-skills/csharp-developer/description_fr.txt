À utiliser lors de la création d'applications C# avec .NET 8+, les API ASP.NET Core ou les applications Web Blazor. Construit des API REST en utilisant un routage minimal ou basé sur un contrôleur, configure l'accès à la base de données avec Entity Framework Core, implémente des modèles asynchrones et l'annulation, structure les applications avec CQRS via MediatR et échafaude les composants Blazor avec gestion d'état. Invoquez pour C#, .NET, ASP.NET Core, Blazor, Entity Framework, EF Core, Minimal API, MAUI, SignalR.
