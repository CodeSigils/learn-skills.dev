يصمم استراتيجيات الترحيل المتزايدة، ويحدد حدود الخدمة، وينتج خرائط التبعية وخرائط طريق الترحيل، وينشئ تصميمات واجهة API لقواعد التعليمات البرمجية القديمة. يُستخدم عند تحديث الأنظمة القديمة، أو تنفيذ نمط التين الخانق أو فرعه عن طريق التجريد، أو تحلل الوحدات المتراصة، أو ترقية الأطر أو اللغات، أو تقليل الديون الفنية دون تعطيل العمليات التجارية.
