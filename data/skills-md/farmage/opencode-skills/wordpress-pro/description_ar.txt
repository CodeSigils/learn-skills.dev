تطوير سمات WordPress والمكونات الإضافية المخصصة، وإنشاء وتسجيل كتل Gutenberg وأنماط الحظر، وتكوين متاجر WooCommerce، وتنفيذ نقاط نهاية WordPress REST API، وتطبيق تشديد الأمان (nonces، والتطهير، والهروب، والتحقق من القدرة)، وتحسين الأداء من خلال التخزين المؤقت وضبط الاستعلام. يُستخدم عند إنشاء سمات WordPress، أو كتابة المكونات الإضافية، أو تخصيص كتل Gutenberg، أو توسيع WooCommerce، أو العمل مع ACF، أو استخدام WordPress REST API، أو تطبيق الخطافات والمرشحات، أو تحسين أداء WordPress وأمانه.
