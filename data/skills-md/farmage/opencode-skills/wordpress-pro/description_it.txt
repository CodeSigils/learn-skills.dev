Sviluppa temi e plugin WordPress personalizzati, crea e registra blocchi e modelli di blocco Gutenberg, configura negozi WooCommerce, implementa endpoint API REST di WordPress, applica il rafforzamento della sicurezza (nonces, sanificazione, escaping, controlli di capacità) e ottimizza le prestazioni tramite la memorizzazione nella cache e l'ottimizzazione delle query. Da utilizzare quando si creano temi WordPress, si scrivono plugin, si personalizzano blocchi Gutenberg, si estende WooCommerce, si lavora con ACF, si utilizza l'API REST di WordPress, si applicano hook e filtri o si migliorano le prestazioni e la sicurezza di WordPress.
