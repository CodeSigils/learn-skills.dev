エンタープライズ グレードの TypeScript バックエンド アプリケーション用の NestJS モジュール、コントローラー、サービス、DTO、ガード、およびインターセプターを作成および構成します。 NestJS REST API または GraphQL サービスの構築、依存関係の注入の実装、モジュラー アーキテクチャのスキャフォールディング、JWT/Passport 認証の追加、TypeORM または Prisma の統合、または .module.ts、.controller.ts、および .service.ts ファイルの操作を行う場合に使用します。 NestJS プロジェクトでのガード、インターセプター、パイプ、検証、Swagger ドキュメント、単体/E2E テストのために呼び出します。
