Crea e configura moduli, controller, servizi, DTO, guardie e intercettori NestJS per applicazioni backend TypeScript di livello aziendale. Da utilizzare durante la creazione di API REST NestJS o servizi GraphQL, l'implementazione dell'inserimento di dipendenze, lo scaffolding dell'architettura modulare, l'aggiunta dell'autenticazione JWT/Passport, l'integrazione di TypeORM o Prisma o l'utilizzo di file .module.ts, .controller.ts e .service.ts. Richiama protezioni, intercettatori, tubazioni, convalida, documentazione Swagger e test unitari/E2E nei progetti NestJS.
