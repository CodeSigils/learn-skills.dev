Crea y configura módulos, controladores, servicios, DTO, guardias e interceptores de NestJS para aplicaciones backend TypeScript de nivel empresarial. Úselo al crear API REST de NestJS o servicios GraphQL, implementar inyección de dependencia, estructurar una arquitectura modular, agregar autenticación JWT/Passport, integrar TypeORM o Prisma, o trabajar con archivos .module.ts, .controller.ts y .service.ts. Invoque para guardias, interceptores, tuberías, validación, documentación Swagger y pruebas unitarias/E2E en proyectos NestJS.
