Пишет, проверяет и отлаживает идиоматический код Rust с безопасностью памяти и абстракциями с нулевой стоимостью. Реализует шаблоны владения, управляет временем жизни, разрабатывает иерархии признаков, создает асинхронные приложения с помощью tokio и структурирует обработку ошибок с помощью Result/Option. Используйте при создании приложений Rust, решении проблем владения или заимствования, разработке API-интерфейсов на основе характеристик, реализации параллелизма async/await, создании привязок FFI или оптимизации производительности и безопасности памяти. Вызов для Rust, Cargo, владения, заимствования, времени жизни, асинхронности Rust, tokio, абстракций с нулевой стоимостью, безопасности памяти, системного программирования.
