يكتب ويراجع ويصحح كود Rust الاصطلاحي مع سلامة الذاكرة وتجريدات بدون تكلفة. ينفذ أنماط الملكية، ويدير فترات الحياة، ويصمم التسلسلات الهرمية للسمات، ويبني تطبيقات غير متزامنة مع tokio، ويبني معالجة الأخطاء باستخدام النتيجة/الخيار. يُستخدم عند إنشاء تطبيقات Rust، أو حل مشكلات الملكية أو الاقتراض، أو تصميم واجهات برمجة التطبيقات المستندة إلى السمات، أو تنفيذ التزامن غير المتزامن/الانتظار، أو إنشاء روابط FFI، أو تحسين الأداء وسلامة الذاكرة. استدعاء الصدأ، والشحن، والملكية، والاقتراض، ومدة الحياة، والصدأ غير المتزامن، وتوكيو، والتجريدات ذات التكلفة الصفرية، وسلامة الذاكرة، وبرمجة الأنظمة.
