Escribe, revisa y depura código idiomático de Rust con seguridad de memoria y abstracciones sin costo. Implementa patrones de propiedad, gestiona la vida útil, diseña jerarquías de rasgos, crea aplicaciones asíncronas con tokio y estructura el manejo de errores con Resultado/Opción. Úselo al crear aplicaciones Rust, resolver problemas de propiedad o préstamo, diseñar API basadas en rasgos, implementar concurrencia asíncrona/en espera, crear enlaces FFI u optimizar el rendimiento y la seguridad de la memoria. Invoque para Rust, Cargo, propiedad, endeudamiento, vida útil, Rust asíncrono, tokio, abstracciones de costo cero, seguridad de la memoria, programación de sistemas.
