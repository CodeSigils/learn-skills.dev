Scrive, revisiona ed esegue il debug del codice Rust idiomatico con sicurezza della memoria e astrazioni a costo zero. Implementa modelli di proprietà, gestisce le durate, progetta gerarchie di tratti, crea applicazioni asincrone con tokio e struttura la gestione degli errori con Risultato/Opzione. Da utilizzare durante la creazione di applicazioni Rust, la risoluzione di problemi di proprietà o di prestito, la progettazione di API basate sui tratti, l'implementazione della concorrenza asincrona/in attesa, la creazione di collegamenti FFI o l'ottimizzazione delle prestazioni e della sicurezza della memoria. Invoca Rust, Cargo, proprietà, prestito, vite intere, Rust asincrono, Tokyo, astrazioni a costo zero, sicurezza della memoria, programmazione di sistemi.
