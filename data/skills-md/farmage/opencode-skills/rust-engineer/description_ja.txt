メモリ安全性とゼロコストの抽象化を使用して、慣用的な Rust コードを作成、レビュー、デバッグします。所有権パターンを実装し、ライフタイムを管理し、特性階層を設計し、tokio を使用して非同期アプリケーションを構築し、Result/Option を使用してエラー処理を構造化します。 Rust アプリケーションの構築、所有権または借用の問題の解決、特性ベースの API の設計、非同期/待機同時実行の実装、FFI バインディングの作成、またはパフォーマンスとメモリの安全性の最適化を行うときに使用します。 Rust、Cargo、所有権、借用、ライフタイム、非同期 Rust、tokio、ゼロコスト抽象化、メモリ安全性、システム プログラミングのために呼び出します。
