Ottimizza le query SQL, progetta schemi di database e risolve i problemi di prestazioni. Da utilizzare quando un utente chiede perché la sua query è lenta, ha bisogno di aiuto per scrivere join o aggregazioni complessi, menziona problemi di prestazioni del database o desidera progettare o migrare uno schema. Richiamo per query complesse, funzioni finestra, CTE, strategie di indicizzazione, analisi del piano di query, creazione di indici di copertura, query ricorsive, interpretazione EXPLAIN/ANALYZE, benchmarking prima/dopo la query o migrazione di query tra dialetti di database (PostgreSQL, MySQL, SQL Server, Oracle).
