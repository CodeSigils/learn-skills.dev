تصميم وتنفيذ البنية التحتية لخط أنابيب ML على مستوى الإنتاج: تكوين تتبع التجربة باستخدام MLflow أو Weights & Biases، وإنشاء Kubeflow أو Airflow DAGs لتنسيق التدريب، وإنشاء مخططات تخزين الميزات باستخدام Feast، ونشر سجلات النماذج، وأتمتة سير عمل إعادة التدريب والتحقق من الصحة. يُستخدم عند إنشاء مسارات تعلم الآلة، أو تنسيق سير عمل التدريب، أو أتمتة دورة حياة النموذج، أو تنفيذ مخازن الميزات، أو إدارة أنظمة تتبع التجارب، أو إعداد DVC لإصدارات البيانات، أو ضبط المعلمات الفائقة، أو تكوين أدوات MLOps مثل Kubeflow، أو Airflow، أو MLflow، أو Prefect.
