Используйте при реализации аутентификации/авторизации, защите ввода пользователя или предотвращении уязвимостей из топ-10 OWASP, включая специальные реализации безопасности, такие как хеширование паролей с помощью bcrypt/argon2, очистка SQL-запросов с помощью параметризованных операторов, настройка заголовков CORS/CSP, проверка входных данных с помощью Zod и настройка токенов JWT. Вызов для аутентификации, авторизации, проверки ввода, шифрования, предотвращения OWASP Top 10, безопасного управления сеансами и усиления безопасности. Для предварительно созданной интеграции OAuth/SSO или автономного аудита безопасности рассмотрите более специализированные навыки.
