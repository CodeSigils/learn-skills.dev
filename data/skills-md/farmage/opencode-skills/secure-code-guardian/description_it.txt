Da utilizzare quando si implementa l'autenticazione/autorizzazione, si protegge l'input dell'utente o si prevengono le 10 principali vulnerabilità OWASP, comprese implementazioni di sicurezza personalizzate come l'hashing delle password con bcrypt/argon2, la pulizia delle query SQL con istruzioni parametrizzate, la configurazione di intestazioni CORS/CSP, la convalida dell'input con Zod e l'impostazione dei token JWT. Invocare per autenticazione, autorizzazione, convalida dell'input, crittografia, prevenzione OWASP Top 10, gestione sicura delle sessioni e rafforzamento della sicurezza. Per le integrazioni OAuth/SSO predefinite o i controlli di sicurezza autonomi, considera una competenza più specializzata.
