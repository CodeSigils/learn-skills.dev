Wird zum Implementieren von Authentifizierung/Autorisierung, zum Sichern von Benutzereingaben oder zum Verhindern von OWASP-Top-10-Schwachstellen verwendet – einschließlich benutzerdefinierter Sicherheitsimplementierungen wie Hashing von Passwörtern mit bcrypt/argon2, Bereinigen von SQL-Abfragen mit parametrisierten Anweisungen, Konfigurieren von CORS/CSP-Headern, Validieren von Eingaben mit Zod und Einrichten von JWT-Tokens. Rufen Sie für Authentifizierung, Autorisierung, Eingabevalidierung, Verschlüsselung, OWASP Top 10-Prävention, sichere Sitzungsverwaltung und Sicherheitshärtung auf. Für vorgefertigte OAuth/SSO-Integrationen oder eigenständige Sicherheitsüberprüfungen sollten Sie eine speziellere Fähigkeit in Betracht ziehen.
