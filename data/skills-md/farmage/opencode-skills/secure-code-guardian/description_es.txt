Úselo al implementar autenticación/autorización, proteger la entrada del usuario o prevenir las 10 vulnerabilidades principales de OWASP, incluidas implementaciones de seguridad personalizadas, como hash de contraseñas con bcrypt/argon2, desinfección de consultas SQL con declaraciones parametrizadas, configuración de encabezados CORS/CSP, validación de entradas con Zod y configuración de tokens JWT. Invoque para autenticación, autorización, validación de entradas, cifrado, prevención OWASP Top 10, gestión segura de sesiones y refuerzo de seguridad. Para integraciones OAuth/SSO prediseñadas o auditorías de seguridad independientes, considere una habilidad más especializada.
