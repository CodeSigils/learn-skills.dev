يقوم بكتابة المطالبات وإعادة هيكلتها وتقييمها - وإنشاء قوالب مطالبة محسنة ومخططات مخرجات منظمة ونماذج تقييم ومجموعات اختبار. يُستخدم عند تصميم المطالبات لتطبيقات LLM الجديدة، أو إعادة هيكلة المطالبات الحالية للحصول على دقة أفضل أو كفاءة رمزية أفضل، أو تنفيذ سلسلة الأفكار أو التعلم القليل، أو إنشاء مطالبات النظام باستخدام الشخصيات وحواجز الحماية، أو بناء مخططات JSON/استدعاء الوظيفة، أو تطوير أطر تقييم سريعة لقياس أداء النموذج وتحسينه.
