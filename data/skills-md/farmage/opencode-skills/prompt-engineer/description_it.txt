Scrive, effettua il refactoring e valuta i prompt per LLM, generando modelli di prompt ottimizzati, schemi di output strutturati, rubriche di valutazione e suite di test. Utilizzare durante la progettazione di prompt per nuove applicazioni LLM, il refactoring di prompt esistenti per una migliore precisione o efficienza dei token, l'implementazione della catena di pensiero o l'apprendimento "low-shot", la creazione di prompt di sistema con personaggi e guardrail, la creazione di schemi JSON/di chiamata di funzioni o lo sviluppo di framework di valutazione dei prompt per misurare e migliorare le prestazioni del modello.
