Используйте при проектировании новой архитектуры системы высокого уровня, анализе существующих проектов или принятии архитектурных решений. Вызов для создания архитектурных диаграмм, написания записей об архитектурных решениях (ADR), оценки технологических компромиссов, проектирования взаимодействия компонентов и планирования масштабируемости. Используется для проектирования системы, анализа архитектуры, структурирования микросервисов, разработки ADR, планирования масштабируемости и выбора шаблона инфраструктуры — в отличие от шаблонов проектирования на уровне кода или задач проектирования только для базы данных.
