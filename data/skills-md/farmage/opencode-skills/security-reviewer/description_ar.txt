يحدد الثغرات الأمنية، وينشئ تقارير تدقيق منظمة مع تصنيفات الخطورة، ويوفر إرشادات علاجية قابلة للتنفيذ. يُستخدم عند إجراء عمليات تدقيق الأمان، أو مراجعة التعليمات البرمجية بحثًا عن نقاط الضعف، أو تحليل أمان البنية التحتية. استدعاء عمليات فحص SAST، أو اختبار الاختراق، أو ممارسات DevSecOps، أو مراجعات أمان السحابة، أو عمليات تدقيق التبعية، أو فحص الأسرار، أو فحوصات الامتثال. يُنتج تقارير الضعف والتوصيات ذات الأولوية وقوائم التحقق من الامتثال.
