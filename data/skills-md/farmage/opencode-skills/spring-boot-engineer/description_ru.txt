Используйте при создании приложений Spring Boot 3.x, микросервисов или реактивных приложений Java; вызывать для Spring Data JPA, Spring Security 6, WebFlux, интеграции Spring Cloud, дизайна Java REST API или архитектуры Java микросервисов.
