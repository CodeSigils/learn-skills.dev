FastAPI および Pydantic V2 を使用して高性能の非同期 Python API を構築する場合に使用します。 REST エンドポイントの作成、Pydantic モデルの定義、認証フローの実装、非同期 SQLAlchemy データベース操作のセットアップ、JWT 認証の追加、WebSocket エンドポイントの構築、または OpenAPI ドキュメントの生成を行うために呼び出します。トリガー用語: FastAPI、Pydantic、非同期 Python、Python API、REST API Python、SQLAlchemy 非同期、JWT 認証、OpenAPI、Swagger Python。
