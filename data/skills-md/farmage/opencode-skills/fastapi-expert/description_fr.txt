À utiliser lors de la création d'API Python asynchrones hautes performances avec FastAPI et Pydantic V2. Invoquez pour créer des points de terminaison REST, définir des modèles Pydantic, implémenter des flux d'authentification, configurer des opérations de base de données asynchrones SQLAlchemy, ajouter une authentification JWT, créer des points de terminaison WebSocket ou générer de la documentation OpenAPI. Termes de déclenchement : FastAPI, Pydantic, async Python, Python API, REST API Python, SQLAlchemy async, JWT identifier, OpenAPI, Swagger Python.
