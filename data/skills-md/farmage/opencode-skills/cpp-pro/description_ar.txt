يكتب تطبيقات C++ ويحسنها ويصحح أخطاءها باستخدام ميزات C++20/23 الحديثة والبرمجة الوصفية للقالب وتقنيات الأنظمة عالية الأداء. يُستخدم عند إنشاء تعليمات برمجية C++ أو إعادة هيكلتها والتي تتطلب مفاهيم أو نطاقات أو إجراءات تحسين SIMD أو إدارة دقيقة للذاكرة - أو عند معالجة اختناقات الأداء ومشكلات التزامن وبناء تكوين النظام باستخدام CMake.
