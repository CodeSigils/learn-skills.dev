Scrive, ottimizza ed esegue il debug di applicazioni C++ utilizzando le moderne funzionalità C++ 20/23, metaprogrammazione di modelli e tecniche di sistema ad alte prestazioni. Da utilizzare durante la creazione o il refactoring di codice C++ che richiede concetti, intervalli, coroutine, ottimizzazione SIMD o un'attenta gestione della memoria oppure quando si affrontano colli di bottiglia delle prestazioni, problemi di concorrenza e si crea la configurazione del sistema con CMake.
