Создает компоненты Vue 3 с использованием шаблонов Composition API, настраивает проекты Nuxt 3 SSR/SSG, настраивает магазины Pinia, формирует мобильные приложения Quasar/Capacitor, реализует функции PWA и оптимизирует сборки Vite. Используйте при создании приложений Vue 3 с Composition API, написании повторно используемых компонуемых объектов, управлении состоянием с помощью Pinia, создании гибридных мобильных приложений с помощью Quasar или Capacitor, настройке сервис-воркеров или настройке конфигурации Vite и интеграции TypeScript.
