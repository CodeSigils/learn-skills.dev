Costruisce componenti Vue 3 con pattern API Composition, configura progetti SSR/SSG Nuxt 3, configura negozi Pinia, supporta app mobili Quasar/Capacitor, implementa funzionalità PWA e ottimizza le build Vite. Da utilizzare durante la creazione di applicazioni Vue 3 con l'API Composition, la scrittura di componenti componibili riutilizzabili, la gestione dello stato con Pinia, la creazione di app mobili ibride con Quasar o Capacitor, la configurazione di operatori di servizio o l'ottimizzazione della configurazione di Vite e dell'integrazione di TypeScript.
