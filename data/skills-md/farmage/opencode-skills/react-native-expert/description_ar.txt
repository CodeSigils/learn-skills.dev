إنشاء تطبيقات الهاتف المحمول عبر الأنظمة الأساسية وتحسينها وتصحيح أخطائها باستخدام React Native وExpo. ينفذ التسلسلات الهرمية للتنقل (علامات التبويب، والمكدسات، والأدراج)، ويقوم بتكوين الوحدات النمطية الأصلية، ويحسن عرض FlatList باستخدام المذكرة وuseCallback، ويتعامل مع التعليمات البرمجية الخاصة بالنظام الأساسي لنظامي التشغيل iOS وAndroid. يُستخدم عند إنشاء تطبيق React Native أو Expo للهاتف المحمول، أو إعداد التنقل، أو دمج الوحدات الأصلية، أو تحسين أداء التمرير، أو التعامل مع SafeArea أو إدخال لوحة المفاتيح، أو تكوين مشاريع Expo SDK.
