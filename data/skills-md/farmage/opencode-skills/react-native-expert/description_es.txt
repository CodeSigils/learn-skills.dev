Crea, optimiza y depura aplicaciones móviles multiplataforma con React Native y Expo. Implementa jerarquías de navegación (pestañas, pilas, cajones), configura módulos nativos, optimiza la representación de FlatList con memo y useCallback, y maneja código específico de la plataforma para iOS y Android. Úselo al crear una aplicación móvil React Native o Expo, configurar la navegación, integrar módulos nativos, mejorar el rendimiento del desplazamiento, manejar SafeArea o la entrada del teclado, o configurar proyectos del SDK de Expo.
