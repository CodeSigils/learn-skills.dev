Costruisce, ottimizza ed esegue il debug di applicazioni mobili multipiattaforma con React Native ed Expo. Implementa gerarchie di navigazione (schede, pile, cassetti), configura moduli nativi, ottimizza il rendering FlatList con memo e useCallback e gestisce il codice specifico della piattaforma per iOS e Android. Da utilizzare durante la creazione di un'app mobile React Native o Expo, l'impostazione della navigazione, l'integrazione di moduli nativi, il miglioramento delle prestazioni di scorrimento, la gestione di SafeArea o input da tastiera o la configurazione di progetti Expo SDK.
