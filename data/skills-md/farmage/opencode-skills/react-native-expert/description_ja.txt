React Native と Expo を使用して、クロスプラットフォームのモバイル アプリケーションを構築、最適化、デバッグします。ナビゲーション階層 (タブ、スタック、ドロワー) を実装し、ネイティブ モジュールを構成し、メモと useCallback を使用して FlatList レンダリングを最適化し、iOS と Android のプラットフォーム固有のコードを処理します。 React Native または Expo モバイル アプリの構築、ナビゲーションの設定、ネイティブ モジュールの統合、スクロール パフォーマンスの向上、セーフエリアまたはキーボード入力の処理、または Expo SDK プロジェクトの構成を行うときに使用します。
