Erstellt, optimiert und debuggt plattformübergreifende mobile Anwendungen mit React Native und Expo. Implementiert Navigationshierarchien (Registerkarten, Stapel, Schubladen), konfiguriert native Module, optimiert das FlatList-Rendering mit Memo und useCallback und verarbeitet plattformspezifischen Code für iOS und Android. Verwenden Sie diese Option, wenn Sie eine mobile React Native- oder Expo-App erstellen, die Navigation einrichten, native Module integrieren, die Scroll-Leistung verbessern, SafeArea- oder Tastatureingaben verarbeiten oder Expo SDK-Projekte konfigurieren.
