Создает, оптимизирует и отлаживает кроссплатформенные мобильные приложения с помощью React Native и Expo. Реализует иерархию навигации (вкладки, стопки, ящики), настраивает собственные модули, оптимизирует рендеринг FlatList с помощью memo и useCallback, а также обрабатывает код, специфичный для платформы iOS и Android. Используйте при создании мобильного приложения React Native или Expo, настройке навигации, интеграции собственных модулей, улучшении производительности прокрутки, обработке SafeArea или ввода с клавиатуры или настройке проектов Expo SDK.
