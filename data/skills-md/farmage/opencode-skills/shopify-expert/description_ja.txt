Shopify テーマ (.liquid ファイル、theme.json、セクション) をビルドおよびデバッグし、カスタム Shopify アプリ (shopify.app.toml、OAuth、Webhook) を開発し、ヘッドレス ストアフロント用の Storefront API 統合を実装します。 Shopify テーマの構築またはカスタマイズ、Hydrogen またはカスタム React ストアフロントの作成、Shopify アプリの開発、チェックアウト UI 拡張機能または Shopify 関数の実装、パフォーマンスの最適化、またはサードパーティ サービスの統合を行うときに使用します。 Liquid テンプレート、Storefront API、アプリ開発、チェックアウトのカスタマイズ、Shopify Plus 機能、App Bridge、Polaris、または Shopify CLI ワークフローのために呼び出します。
