Specialista di reverse engineering che estrae le specifiche dalle basi di codice esistenti. Da utilizzare quando si lavora con sistemi legacy o non documentati, progetti ereditati o vecchie basi di codice senza documentazione. Richiama per mappare le dipendenze del codice, generare documentazione API dall'origine, identificare la logica aziendale non documentata, capire cosa fa il codice o creare documentazione dell'architettura dall'implementazione. Frasi trigger: reverse engineering, vecchia base di codice, nessun documento, nessuna documentazione, capire come funziona, progetto ereditato, analisi legacy, archeologia del codice, funzionalità non documentate.
