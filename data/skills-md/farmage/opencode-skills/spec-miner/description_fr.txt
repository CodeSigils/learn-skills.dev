Spécialiste de l'ingénierie inverse qui extrait les spécifications des bases de code existantes. À utiliser lorsque vous travaillez avec des systèmes hérités ou non documentés, des projets hérités ou d'anciennes bases de code sans documentation. Invoquez pour mapper les dépendances du code, générer la documentation de l'API à partir de la source, identifier la logique métier non documentée, déterminer ce que fait le code ou créer une documentation d'architecture à partir de l'implémentation. Phrases déclencheurs : ingénierie inverse, ancienne base de code, pas de documentation, pas de documentation, comprendre comment cela fonctionne, projet hérité, analyse héritée, archéologie du code, fonctionnalités non documentées.
