Especialista en ingeniería inversa que extrae especificaciones de bases de código existentes. Úselo cuando trabaje con sistemas heredados o no documentados, proyectos heredados o bases de código antiguas sin documentación. Invoque para mapear dependencias de código, generar documentación de API desde el origen, identificar lógica empresarial no documentada, descubrir qué hace el código o crear documentación de arquitectura a partir de la implementación. Frases desencadenantes: ingeniería inversa, código base antiguo, sin documentos, sin documentación, descubrir cómo funciona esto, proyecto heredado, análisis heredado, arqueología del código, características no documentadas.
