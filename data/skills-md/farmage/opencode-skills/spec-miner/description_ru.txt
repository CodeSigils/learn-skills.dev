Специалист по обратному проектированию, который извлекает спецификации из существующих кодовых баз. Используйте при работе с устаревшими или недокументированными системами, унаследованными проектами или старыми базами кода без документации. Вызов для сопоставления зависимостей кода, создания документации API из исходного кода, выявления недокументированной бизнес-логики, выяснения того, что делает код, или создания документации по архитектуре на основе реализации. Триггерные фразы: реверс-инжиниринг, старая кодовая база, отсутствие документации, отсутствие документации, выяснить, как это работает, унаследованный проект, анализ наследия, археология кода, недокументированные функции.
