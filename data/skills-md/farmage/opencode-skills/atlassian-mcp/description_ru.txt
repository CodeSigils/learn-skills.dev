Интегрируется с продуктами Atlassian для управления отслеживанием проектов и документацией через протокол MCP. Используйте при запросе проблем Jira с помощью фильтров JQL, создании и обновлении заявок с настраиваемыми полями, поиске или редактировании страниц Confluence с помощью CQL, управлении спринтами и невыполненными заданиями, настройке аутентификации сервера MCP, синхронизации документации или отладке интеграции Atlassian API.
