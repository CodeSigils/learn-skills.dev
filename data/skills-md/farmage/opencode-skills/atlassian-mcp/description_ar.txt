يتكامل مع منتجات Atlassian لإدارة تتبع المشروع وتوثيقه عبر بروتوكول MCP. يُستخدم عند الاستعلام عن مشكلات Jira مع مرشحات JQL، أو إنشاء التذاكر وتحديثها باستخدام الحقول المخصصة، أو البحث عن صفحات Confluence أو تحريرها باستخدام CQL، أو إدارة الدورات السريعة والتراكمات، أو إعداد مصادقة خادم MCP، أو مزامنة الوثائق، أو تصحيح أخطاء عمليات تكامل Atlassian API.
