Se integra con productos Atlassian para gestionar el seguimiento y la documentación de proyectos a través del protocolo MCP. Úselo al consultar problemas de Jira con filtros JQL, crear y actualizar tickets con campos personalizados, buscar o editar páginas de Confluence con CQL, administrar sprints y trabajos pendientes, configurar la autenticación del servidor MCP, sincronizar documentación o depurar integraciones de API de Atlassian.
