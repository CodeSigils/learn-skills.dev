Da utilizzare durante la creazione, il debug o l'estensione di server o client MCP che connettono sistemi di intelligenza artificiale con strumenti e origini dati esterni. Richiama per implementare gestori di strumenti, configurare provider di risorse, impostare livelli di trasporto stdio/HTTP/SSE, convalidare schemi con Zod o Pydantic, eseguire il debug di problemi di conformità del protocollo o eseguire l'impalcatura di progetti server/client MCP completi utilizzando TypeScript o SDK Python.
