Используйте при создании, отладке или расширении серверов или клиентов MCP, которые соединяют системы искусственного интеллекта с внешними инструментами и источниками данных. Вызов для реализации обработчиков инструментов, настройки поставщиков ресурсов, настройки транспортных уровней stdio/HTTP/SSE, проверки схем с помощью Zod или Pydantic, отладки проблем соответствия протоколам или создания готовых проектов сервера/клиента MCP с использованием TypeScript или Python SDK.
