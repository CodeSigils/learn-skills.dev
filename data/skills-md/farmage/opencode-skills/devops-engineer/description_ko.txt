Dockerfile을 생성하고, CI/CD 파이프라인을 구성하고, Kubernetes 매니페스트를 작성하고, Terraform/Pulumi 인프라 템플릿을 생성합니다. 배포 자동화, GitOps 구성, 사고 대응 런북 및 내부 개발자 플랫폼 도구를 처리합니다. CI/CD 파이프라인 설정, 애플리케이션 컨테이너화, 코드형 인프라 관리, Kubernetes 클러스터에 배포, 클라우드 플랫폼 구성, 릴리스 자동화 또는 프로덕션 사고에 대응할 때 사용합니다. 파이프라인, Docker, Kubernetes, GitOps, Terraform, GitHub Actions, 대기 중 또는 플랫폼 엔지니어링을 호출합니다.
