يُستخدم عند إنشاء تطبيقات ويب Django أو واجهات برمجة تطبيقات REST باستخدام Django REST Framework. يتم الاستدعاء عند العمل مع settings.py، أوmodels.py، أو manager.py، أو أي ملف مشروع Django. ينشئ نماذج Django باستخدام الفهارس المناسبة، ويحسن استعلامات ORM باستخدام تحديد_ذات صلة/الجلب المسبق، ويبني مُسلسِلات DRF ومجموعات العرض، ويكوّن مصادقة JWT. مصطلحات التشغيل: Django، DRF، Django REST Framework، Django ORM، Django model، serializer، viewset، Python web.
