Django REST Framework를 사용하여 Django 웹 애플리케이션 또는 REST API를 구축할 때 사용합니다. settings.py, models.py, prepare.py 또는 Django 프로젝트 파일 작업 시 호출합니다. 적절한 인덱스를 사용하여 Django 모델을 생성하고, select_관련/prefetch_관련을 사용하여 ORM 쿼리를 최적화하고, DRF 직렬 변환기 및 뷰 세트를 구축하고, JWT 인증을 구성합니다. 트리거 용어: Django, DRF, Django REST Framework, Django ORM, Django 모델, 직렬 변환기, 뷰 세트, Python 웹.
