Используйте при создании веб-приложений Django или API REST с помощью Django REST Framework. Вызывайте при работе с файлами settings.py, models.py, Manage.py или любым файлом проекта Django. Создает модели Django с правильными индексами, оптимизирует запросы ORM с помощью select_related/prefetch_related, создает сериализаторы и наборы представлений DRF и настраивает аутентификацию JWT. Триггерные термины: Django, DRF, Django REST Framework, Django ORM, модель Django, сериализатор, набор представлений, сеть Python.
