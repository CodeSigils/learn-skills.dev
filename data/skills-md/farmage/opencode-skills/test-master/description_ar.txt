يُنشئ ملفات اختبار، وينشئ إستراتيجيات ساخرة، ويحلل تغطية التعليمات البرمجية، ويصمم بنيات الاختبار، وينتج خطط الاختبار وتقارير العيوب عبر تخصصات الاختبار الوظيفي والأداء والأمان. يُستخدم عند كتابة اختبارات الوحدة، أو اختبارات التكامل، أو اختبارات E2E؛ وإنشاء استراتيجيات الاختبار أو أطر الأتمتة؛ وتحليل فجوات التغطية؛ اختبار الأداء باستخدام k6 أو المدفعية؛ اختبار الأمان باستخدام أساليب OWASP؛ تصحيح الاختبارات غير المستقرة؛ أو العمل على ضمان الجودة أو الانحدار أو أتمتة الاختبار أو بوابات الجودة أو اختبار التحول الأيسر أو صيانة الاختبار.
