コードの差分とファイルを分析して、バグ、セキュリティの脆弱性 (SQL インジェクション、XSS、安全でない逆シリアル化)、コードの匂い、N+1 クエリ、命名の問題、アーキテクチャ上の懸念事項を特定し、優先順位付けされた実用的なフィードバックを含む構造化されたレビュー レポートを生成します。プル リクエストのレビュー、コード品質監査の実施、リファクタリングの機会の特定、またはセキュリティ問題のチェックを行うときに使用します。 PR レビュー、コードの品質チェック、リファクタリングの提案、コードのレビュー、コードの品質のために呼び出します。正確性、パフォーマンス、保守性、テストカバレッジにわたる広範なレビューを 1 回のパスで提供することで、専門的なスキル (セキュリティレビュー担当者、テストマスター) を補完します。
