Analiza diferencias de código y archivos para identificar errores, vulnerabilidades de seguridad (inyección SQL, XSS, deserialización insegura), olores de código, consultas N+1, problemas de nombres y preocupaciones arquitectónicas, luego produce un informe de revisión estructurado con comentarios priorizados y procesables. Úselo al revisar solicitudes de extracción, realizar auditorías de calidad del código, identificar oportunidades de refactorización o verificar problemas de seguridad. Invocar para revisiones de relaciones públicas, controles de calidad del código, sugerencias de refactorización, revisión de código, calidad del código. Complementa las habilidades especializadas (revisor de seguridad, maestro de pruebas) al proporcionar una revisión de amplio alcance de la corrección, el rendimiento, la mantenibilidad y la cobertura de las pruebas en una sola pasada.
