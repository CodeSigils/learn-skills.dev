À utiliser lors de la création d'applications Python 3.11+ nécessitant une sécurité de type, une programmation asynchrone ou une gestion robuste des erreurs. Génère du code Python annoté par type, configure mypy en mode strict, écrit des suites de tests pytest avec des appareils et des moqueries, et valide le code avec black et ruff. Invoquez pour les astuces de type, les modèles asynchrones/d'attente, les classes de données, l'injection de dépendances, la configuration de la journalisation et la gestion structurée des erreurs.
