Verwenden Sie diese Option, wenn Sie Python 3.11+-Anwendungen erstellen, die Typsicherheit, asynchrone Programmierung oder robuste Fehlerbehandlung erfordern. Erzeugt typkommentierten Python-Code, konfiguriert mypy im strikten Modus, schreibt Pytest-Testsuiten mit Fixtures und Mocking und validiert Code mit Black und Ruff. Rufen Sie für Typhinweise, Asynchron-/Wartemuster, Datenklassen, Abhängigkeitsinjektion, Protokollierungskonfiguration und strukturierte Fehlerbehandlung auf.
