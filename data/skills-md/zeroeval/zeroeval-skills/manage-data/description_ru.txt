Создавайте, загружайте, отправляйте, версируйте и управляйте наборами эталонных данных с помощью ZeroEval Python SDK или git. Используйте при добавлении данных в тест, создании набора данных из кода или CSV, передаче данных на серверную часть, управлении подмножествами, извлечении существующих тестов, преобразовании данных в Parquet или настройке рабочего процесса с данными на основе git. Триггеры по «добавлению данных», «созданию набора данных», «отправке набора данных», «загрузке данных», «управлению контрольными данными», «управлению версиями набора данных», «подмножествам», «извлечению набора данных», «паркету», «мультимодальному набору данных».
