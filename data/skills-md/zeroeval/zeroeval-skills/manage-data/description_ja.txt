ZeroEval Python SDK または git を使用して、ベンチマーク データセットを作成、ロード、プッシュ、バージョン管理し、管理します。ベンチマークへのデータの追加、コードまたは CSV からのデータセットの作成、バックエンドへのデータのプッシュ、サブセットの管理、既存のベンチマークのプル、Parquet へのデータの変換、または git ベースのデータ ワークフローのセットアップを行うときに使用します。 「データの追加」、「データセットの作成」、「データセットのプッシュ」、「データのアップロード」、「ベンチマーク データの管理」、「データセットのバージョン管理」、「サブセット」、「データセットのプル」、「寄木細工」、「マルチモーダル データセット」でトリガーします。
