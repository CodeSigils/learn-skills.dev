قم بإنشاء مجموعات البيانات المعيارية وتحميلها ودفعها وإصدارها وإدارتها باستخدام ZeroEval Python SDK أو git. يُستخدم عند إضافة بيانات إلى معيار أداء، أو إنشاء مجموعة بيانات من تعليمات برمجية أو ملف CSV، أو دفع البيانات إلى الواجهة الخلفية، أو إدارة المجموعات الفرعية، أو سحب المعايير الحالية، أو تحويل البيانات إلى Parquet، أو إعداد سير عمل بيانات قائم على git. مشغلات على "إضافة بيانات"، "إنشاء مجموعة بيانات"، "دفع مجموعة البيانات"، "تحميل البيانات"، "إدارة البيانات المعيارية"، "إصدار مجموعة البيانات"، "مجموعات فرعية"، "سحب مجموعة البيانات"، "الباركيه"، "مجموعة البيانات متعددة الوسائط".
