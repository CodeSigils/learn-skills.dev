اكتب البرامج النصية لسير عمل AgentPrism وقم بتشغيلها - `export const meta` + agent()/parallel()/pipeline() JavaScript DSL الذي يتم تنفيذه بواسطة @automatalabs/workflows وبواسطة أداة `workflow` @automatalabs/mcp-server. يُستخدم عند كتابة برنامج نصي لسير العمل أو تحريره، أو عند تشغيله من خلال أداة "سير العمل" MCP. يغطي واجهة برمجة تطبيقات البرنامج النصي، وتوجيه كل مكالمة إلى واجهات ACP الخلفية (Claude Code، وCodex، وOpenCode، وpi، والوكلاء المخصصين)، والمخرجات المنظمة عبر مخطط JSON، ونقاط التفتيش البشرية، وعزل شجرة العمل، وقواعد السيرة الذاتية، وعمليات التشغيل (التشغيل، والانتظار، والفحص، والإيقاف، وسجلات التنفيذ).
