AgentPrism 워크플로 스크립트(@automatalabs/workflows 및 @automatalabs/mcp-server `workflow` 도구에 의해 실행되는 `export const me` + agent()/parallel()/pipeline() JavaScript DSL)를 작성하고 실행합니다. 워크플로 스크립트를 작성 또는 편집할 때 또는 MCP `workflow` 도구를 통해 실행할 때 사용합니다. 스크립트 API, ACP 백엔드로의 호출별 라우팅(Claude Code, Codex, OpenCode, pi, 사용자 정의 에이전트), JSON 스키마를 통한 구조화된 출력, 휴먼 체크포인트, 작업 트리 격리, 재개 규칙 및 실행 작업(실행, 대기, 검사, 중지, 실행 로그)을 다룹니다.
