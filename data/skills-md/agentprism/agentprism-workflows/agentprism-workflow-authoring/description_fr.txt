Écrivez et exécutez des scripts de workflow AgentPrism — le DSL JavaScript `export const meta` + agent()/parallel()/pipeline() exécuté par @automatalabs/workflows et par l'outil `workflow` @automatalabs/mcp-server. À utiliser lors de l'écriture ou de la modification d'un script de workflow, ou lors de son exécution via l'outil `workflow` de MCP. Couvre l'API de script, le routage par appel vers les backends ACP (Claude Code, Codex, OpenCode, pi, agents personnalisés), les sorties structurées via le schéma JSON, les points de contrôle humains, l'isolation de l'arbre de travail, les règles de reprise et les opérations d'exécution (exécuter, attendre, inspecter, arrêter, journaux d'exécution).
