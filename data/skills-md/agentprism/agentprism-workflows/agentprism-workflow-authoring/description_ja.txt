AgentPrism ワークフロー スクリプトを作成して実行します。これは、@automatalabs/workflows および @automatalabs/mcp-server `workflow` ツールによって実行される `export const meta` + Agent()/Parallel()/pipeline() JavaScript DSL です。ワークフロー スクリプトを作成または編集するとき、または MCP `workflow` ツールを通じてワークフロー スクリプトを実行するときに使用します。スクリプト API、ACP バックエンド (Claude Code、Codex、OpenCode、pi、カスタム エージェント) への呼び出しごとのルーティング、JSON スキーマを介した構造化出力、ヒューマン チェックポイント、ワークツリー分離、再開ルール、および実行操作 (実行、待機、検査、停止、実行ログ) について説明します。
