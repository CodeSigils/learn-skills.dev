编写并运行 AgentPrism 工作流脚本 - 由 @automatalabs/workflows 和 @automatalabs/mcp-server `workflow` 工具执行的`export const meta` + agent()/parallel()/pipeline() JavaScript DSL。在编写或编辑工作流脚本时或通过 MCP“工作流”工具运行脚本时使用。涵盖脚本 API、每次调用路由到 ACP 后端（Claude Code、Codex、OpenCode、pi、自定义代理）、通过 JSON 架构的结构化输出、人工检查点、工作树隔离、恢复规则和运行操作（运行、等待、检查、停止、执行日志）。
