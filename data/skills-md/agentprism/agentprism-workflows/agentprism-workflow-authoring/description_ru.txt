Напишите и запустите сценарии рабочего процесса AgentPrism — JavaScript DSL `export const Meta` + агент()/parallel()/pipeline(), выполняемый @automatalabs/workflows и инструментом `workflow` @automatalabs/mcp-server. Используйте при написании или редактировании сценария рабочего процесса или при его запуске с помощью инструмента рабочего процесса MCP. Охватывает API сценариев, маршрутизацию каждого вызова к бэкэндам ACP (Claude Code, Codex, OpenCode, pi, пользовательские агенты), структурированные выходные данные через схему JSON, человеческие контрольные точки, изоляцию рабочего дерева, правила возобновления и операции запуска (запуск, ожидание, проверка, остановка, журналы выполнения).
