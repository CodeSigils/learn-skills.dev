Scrivi ed esegui gli script del flusso di lavoro AgentPrism: il DSL JavaScript `export const meta` + agent()/parallel()/pipeline() eseguito da @automatalabs/workflows e dallo strumento `workflow` @automatalabs/mcp-server. Da utilizzare quando si scrive o si modifica uno script di flusso di lavoro o quando si esegue uno tramite lo strumento "flusso di lavoro" MCP. Copre l'API dello script, il routing per chiamata ai backend ACP (Claude Code, Codex, OpenCode, pi, agenti personalizzati), output strutturati tramite schema JSON, checkpoint umani, isolamento dell'albero di lavoro, regole di ripresa e operazioni di esecuzione (esecuzione, attesa, ispezione, arresto, registri di esecuzione).
