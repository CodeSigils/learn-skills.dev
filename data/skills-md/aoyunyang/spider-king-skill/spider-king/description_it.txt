Inverti i client web ostili in raccoglitori di protocollo puro con distribuzione Python-first. Inizia sempre ogni nuovo target con l'analisi combinata di "chrome-devtools" e "js-reverse", quindi fornisci un raccoglitore Python senza browser più un helper locale per il ripristino dei parametri JS solo quando necessario. Utilizzare quando l'utente fornisce un URL di pagina di destinazione, un URL API, uno snippet JS, un esempio di segno o token, un esempio di cookie, un'acquisizione di pacchetti o chiede di creare o riparare un raccoglitore per siti protetti da segno, token, cookie, WebSocket, GraphQL, protobuf, crittografia della risposta, controlli dell'impronta digitale del browser, firmatari di WebAssembly, bootstrap di verifica o offuscamento della risposta di caratteri dinamici.
