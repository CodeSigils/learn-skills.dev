Python ファースト配信により、敵対的な Web クライアントを純粋なプロトコル コレクターに逆転させます。新しいターゲットは常に「chrome-devtools」と「js-reverse」を組み合わせた分析で開始し、必要な場合にのみ、ブラウザ不要の Python コレクターとローカルの JS パラメーター復元ヘルパーを提供します。ユーザーがターゲット ページ URL、API URL、JS スニペット、署名またはトークン サンプル、Cookie サンプル、パケット キャプチャを提供する場合、または署名、トークン、Cookie、WebSocket、GraphQL、protobuf、応答暗号化、ブラウザーの指紋チェック、WebAssembly 署名者、チャレンジ ブートストラップ、または動的フォント応答難読化によって保護されているサイトのコレクターを構築または修復するように要求する場合に使用します。
