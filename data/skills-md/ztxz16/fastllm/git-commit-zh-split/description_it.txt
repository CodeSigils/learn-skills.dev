Utilizzalo quando l'utente chiede di eseguire il commit del codice, organizzare i commit, preparare un commit, dividere i commit, eseguire il push o specificare le convenzioni di commit e push. Per impostazione predefinita, utilizza i messaggi di commit cinesi e dividi le modifiche di grandi dimensioni in più commit; prima di spingere, eseguire prima fetch, stash, rebase, stash pop, quindi push.
