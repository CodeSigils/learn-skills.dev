Wird verwendet, wenn der Benutzer anfordert, Code festzuschreiben, Festschreibungen zu organisieren, eine Festschreibung vorzubereiten, Festschreibungen aufzuteilen, zu pushen oder Festschreibungs- und Push-Konventionen anzugeben. Verwenden Sie standardmäßig chinesische Commit-Nachrichten und teilen Sie große Änderungen in mehrere Commits auf. Führen Sie vor dem Pushen zuerst Fetch, Stash, Rebase, Stash Pop und dann Push aus.
