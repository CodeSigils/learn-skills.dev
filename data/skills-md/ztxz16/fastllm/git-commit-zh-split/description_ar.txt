عندما يطلب المستخدم ارتكاب تعليمات برمجية، أو تنظيم الالتزامات، أو إعداد الالتزام، أو تقسيم الالتزامات، أو الدفع، أو تحديد اصطلاحات الالتزام والدفع، استخدم هذا. افتراضيًا، يتم استخدام رسائل الالتزام الصينية، ويتم تقسيم التغييرات الكبيرة إلى التزامات متعددة؛ قبل الدفع، قم أولاً بإجراء عمليات الجلب، والتخزين، وإعادة التأسيس، والتخزين، ثم الدفع.
