В начале каждого нового сеанса проверяйте, содержит ли первое приглашение пользователя имя проекта, автора проекта и описание проекта; если какие-либо из них отсутствуют, заранее попросите их заполнить. Когда пользователь запрашивает отправку образа Docker на платформу UIBP, убедитесь, что указаны имя пользователя репозитория, пароль репозитория, путь отправки и имя проекта на английском языке; если какие-либо из них отсутствуют, заранее попросите их заполнить. Перед каждой отправкой принудительно увеличивайте номер версии на 0,1 и используйте его в качестве тега Docker. После успешной отправки спросите пользователя, следует ли сохранять пароль репозитория.
