Au début de chaque nouvelle session, vérifiez si la première invite de l'utilisateur inclut le nom du projet, l'auteur du projet et la description du projet ; s’il en manque, demandez de manière proactive de les compléter. Lorsque l'utilisateur demande à envoyer une image Docker vers la base UIBP, vérifiez que le nom d'utilisateur de l'entité, le mot de passe de l'entité, le chemin d'envoi et le nom du projet en anglais sont tous fournis ; s’il en manque, demandez de manière proactive de les compléter. Avant chaque push, augmentez de force le numéro de version de 0,1 et utilisez-le comme balise Docker. Après un push réussi, demandez à l'utilisateur s'il doit enregistrer le mot de passe de l'entité.
