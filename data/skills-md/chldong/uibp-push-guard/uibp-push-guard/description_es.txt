Al comienzo de cada nueva sesión, verifique si el primer mensaje del usuario incluye el nombre del proyecto, el autor del proyecto y la descripción del proyecto; Si falta alguno, solicite proactivamente completarlo. Cuando el usuario solicita enviar una imagen de Docker a la base UIBP, verifique que se proporcionen el nombre de usuario de la entidad, la contraseña de la entidad, la ruta de envío y el nombre del proyecto en inglés; Si falta alguno, solicite proactivamente completarlo. Antes de cada inserción, aumente a la fuerza el número de versión en 0.1 y utilícelo como etiqueta Docker. Después de una inserción exitosa, pregunte al usuario si desea guardar la contraseña de la entidad.
