Principios expertos de diseño de interfaz de usuario web minimalista inspirados en Ludwig Mies van der Rohe, Dieter Rams y Jony Ive. Esta habilidad es OBLIGATORIA para diseñar interfaces web tranquilas, funcionales y de alta calidad con tipografía sólida, diseños estructurados y cero ruido visual. Utilice esta habilidad siempre que una tarea implique UI, frontend o diseño web, incluso si el usuario no pide explícitamente "minimalismo", para garantizar un resultado claro y profesional.
