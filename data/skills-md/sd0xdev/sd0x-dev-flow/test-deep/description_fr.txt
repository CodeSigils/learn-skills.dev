Orchestration des tests contextuels. À utiliser dans les cas suivants : sélection intelligente des tests, triage des échecs, échelle de tests progressive, analyse des échecs des tests. Pas pour : écrire des tests (utiliser post-dev-test), réviser des tests (utiliser codex-test-review), générer des tests (utiliser codex-test-gen), exécuter manuellement (utiliser verify). Sortie : résultats des tests + rapport de tri + actions du fixateur.
