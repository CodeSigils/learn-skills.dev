Vérification indépendante par deuxième opinion pour tout résultat. À utiliser lorsque : Claude ou l'utilisateur souhaite une vérification Codex indépendante d'un résultat d'examen – rejeter (vérification faussement positive), confirmer (ce problème existe-t-il ?) ou clarifier (quel est l'impact ?). Déclencheurs : rejeter la vérification, demander un verdict, vérifier le rejet, vérifier les faux positifs, deuxième avis, confirmer la conclusion, clarifier l'impact. Pas pour : la révision générale du code (utilisez codex-code-review), les débats sur l'architecture (utilisez codex-brainstorm). Résultat : piste d'audit [DISMISS_VERDICT] ou [SEEK_VERDICT] avec verdict, confiance et références de preuves.
