Créez ou mettez à jour GitHub PR avec gh CLI. Extrait automatiquement l'ID du ticket du nom de la branche, génère un titre/un résumé à partir des validations. Détecte automatiquement les PR existants et passe en mode de mise à jour. Par défaut : --dry-run (afficher la commande, ne pas exécuter). À utiliser lorsque : l'utilisateur demande d'ouvrir/créer/mettre à jour un PR, dit /create-pr, souhaite actualiser la description du PR après de nouveaux commits, ou dit "mettre à jour le PR", "mettre à jour le titre du PR", "actualiser le corps du PR".
