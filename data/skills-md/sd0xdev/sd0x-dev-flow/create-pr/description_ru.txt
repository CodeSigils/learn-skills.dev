Создайте или обновите GitHub PR с помощью gh CLI. Автоматически извлекает идентификатор заявки из названия ветки, генерирует заголовок/сводку на основе коммитов. Автоматически обнаруживает существующий PR и переключается в режим обновления. По умолчанию: --dry-run (показать команду, не выполнять). Используйте, когда: пользователь просит открыть/создать/обновить PR, говорит /create-pr, хочет обновить описание PR после новых коммитов или говорит «обновить PR», «обновить заголовок PR», «обновить тело PR».
