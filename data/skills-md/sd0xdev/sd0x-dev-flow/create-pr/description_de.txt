Erstellen oder aktualisieren Sie GitHub PR mit gh CLI. Extrahiert automatisch die Ticket-ID aus dem Filialnamen und generiert Titel/Zusammenfassung aus Commits. Erkennt automatisch vorhandene PR und wechselt in den Update-Modus. Standard: --dry-run (Befehl anzeigen, nicht ausführen). Verwenden Sie diese Option, wenn: Der Benutzer eine PR öffnen/erstellen/aktualisieren möchte, /create-pr sagt, die PR-Beschreibung nach neuen Commits aktualisieren möchte oder „PR aktualisieren“, „PR-Titel aktualisieren“, „PR-Körper aktualisieren“ sagt.
