Cree o actualice GitHub PR con gh CLI. Extrae automáticamente el ID del ticket del nombre de la sucursal y genera el título/resumen de las confirmaciones. Detecta automáticamente el PR existente y cambia al modo de actualización. Valor predeterminado: --dry-run (mostrar comando, no ejecutar). Úselo cuando: el usuario solicita abrir/crear/actualizar un PR, dice /create-pr, quiere actualizar la descripción del PR después de nuevas confirmaciones o dice "actualizar PR", "actualizar el título del PR", "actualizar el cuerpo del PR".
