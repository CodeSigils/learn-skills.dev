قم بإنشاء أو تحديث GitHub PR باستخدام gh CLI. يستخرج معرف التذكرة تلقائيًا من اسم الفرع، ويولد العنوان/الملخص من الالتزامات. يكتشف تلقائيًا العلاقات العامة الموجودة ويتحول إلى وضع التحديث. الافتراضي: --dry-run (أظهر الأمر، لا تنفذه). يُستخدم عندما: يطلب المستخدم فتح/إنشاء/تحديث العلاقات العامة، أو يقول /create-pr، أو يريد تحديث وصف العلاقات العامة بعد عمليات الالتزام الجديدة، أو يقول "تحديث العلاقات العامة"، أو "تحديث عنوان العلاقات العامة"، أو "تحديث نص العلاقات العامة".
