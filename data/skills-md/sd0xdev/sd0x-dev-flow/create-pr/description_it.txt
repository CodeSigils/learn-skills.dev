Crea o aggiorna GitHub PR con gh CLI. Estrae automaticamente l'ID del ticket dal nome del ramo, genera titolo/riepilogo dai commit. Rileva automaticamente le PR esistenti e passa alla modalità di aggiornamento. Predefinito: --dry-run (mostra il comando, non esegui). Da utilizzare quando: l'utente chiede di aprire/creare/aggiornare un PR, dice /create-pr, vuole aggiornare la descrizione del PR dopo nuovi commit, o dice 'aggiorna pr', 'aggiorna titolo PR', 'aggiorna corpo PR'.
