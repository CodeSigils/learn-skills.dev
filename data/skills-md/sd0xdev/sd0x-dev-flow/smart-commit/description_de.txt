Intelligentes Batch-Commit. Analysiert nicht festgeschriebene Änderungen, gruppiert nach Zusammenhalt und generiert Festschreibungsnachrichten, die dem Projektstil entsprechen. Standard: Gibt Git-Befehle zur manuellen Ausführung aus. Mit --execute: git add + git commit direkt ausführen (Benutzergenehmigung erforderlich). Verwenden Sie, wenn: Der Benutzer sagt „Commit“, „Batch-Commit“, „Commit vorbereiten“, „Commit-Nachricht schreiben“ oder „/smart-commit“.
