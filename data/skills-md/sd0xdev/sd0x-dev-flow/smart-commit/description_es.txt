Compromiso por lotes inteligente. Analiza los cambios no confirmados, los agrupa por cohesión y genera mensajes de confirmación que coinciden con el estilo del proyecto. Predeterminado: salida de comandos git para ejecución manual. Con --execute: ejecuta directamente git add + git commit (requiere la aprobación del usuario). Úselo cuando: el usuario dice 'compromiso', 'compromiso por lotes', 'preparar compromiso', 'escribir mensaje de compromiso' o /compromiso inteligente
