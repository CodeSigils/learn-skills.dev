Умная пакетная фиксация. Анализирует незафиксированные изменения, группирует их по связности, генерирует сообщения о фиксации, соответствующие стилю проекта. По умолчанию: выводить команды git для выполнения вручную. С помощью --execute: напрямую запустите git add + git commit (требуется одобрение пользователя). Используйте, когда: пользователь говорит «зафиксировать», «пакетную фиксацию», «подготовить фиксацию», «написать сообщение о фиксации» или /smart-commit.
