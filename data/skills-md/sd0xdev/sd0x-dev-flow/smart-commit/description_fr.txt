Validation par lots intelligent. Analyse les modifications non validées, les regroupe par cohésion, génère des messages de validation correspondant au style du projet. Par défaut : génère des commandes git pour une exécution manuelle. Avec --execute : exécutez directement git add + git commit (nécessite l'approbation de l'utilisateur). À utiliser lorsque : l'utilisateur dit "valider", "valider par lots", "préparer la validation", "écrire un message de validation" ou /smart-commit
