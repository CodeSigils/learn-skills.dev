Commit batch intelligente. Analizza le modifiche non confermate, raggruppa per coesione, genera messaggi di commit corrispondenti allo stile del progetto. Impostazione predefinita: invia comandi git per l'esecuzione manuale. Con --execute: esegui direttamente git add + git commit (richiede l'approvazione dell'utente). Da utilizzare quando: l'utente dice "commit", "batch commit", "prepara commit", "scrivi messaggio di commit" o /smart-commit
