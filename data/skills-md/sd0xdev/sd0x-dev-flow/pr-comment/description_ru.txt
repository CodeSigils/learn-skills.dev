Публикуйте дружественные комментарии к обзору в PR-сообщении на GitHub — подготовьте их локально, просмотрите, а затем отправьте в виде атомарного обзора. Используйте, когда: публикуете комментарии к обзору кода, даете отзывы по связям с общественностью, отправляете встроенные предложения. Не для: чтения существующих обзоров (используйте load-pr-review), создания PR (используйте create-pr), статуса PR (используйте pr-summary).
