Publiez des commentaires de révision amicaux sur un PR GitHub – préparez-les localement, prévisualisez, puis soumettez-les sous forme de révision atomique. À utiliser lorsque : publier des commentaires de révision de code, donner des commentaires sur les relations publiques, envoyer des suggestions en ligne. Pas pour : lire les avis existants (utilisez load-pr-review), créer des PR (utiliser create-pr), le statut du PR (utiliser pr-summary).
