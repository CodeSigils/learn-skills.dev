انشر تعليقات المراجعة الودية على GitHub PR - قم بالتحضير محليًا، وقم بالمعاينة، ثم أرسلها كمراجعة ذرية. يُستخدم عندما: نشر تعليقات مراجعة التعليمات البرمجية، وتقديم تعليقات العلاقات العامة، وإرسال اقتراحات مضمنة. ليس من أجل: قراءة المراجعات الموجودة (استخدم مراجعة التحميل)، وإنشاء العلاقات العامة (استخدم إنشاء العلاقات العامة)، وحالة العلاقات العامة (استخدم ملخص العلاقات العامة).
