Veröffentlichen Sie freundliche Rezensionskommentare in einer GitHub-PR – bereiten Sie sie lokal vor, zeigen Sie sie in der Vorschau an und reichen Sie sie dann als atomare Rezension ein. Verwenden Sie diese Funktion, wenn Sie Kommentare zur Codeüberprüfung veröffentlichen, PR-Feedback geben oder Inline-Vorschläge senden. Nicht für: Vorhandene Rezensionen lesen (load-pr-review verwenden), PRs erstellen (create-pr verwenden), PR-Status (pr-summary verwenden).
