Архитектурный проект и документация. Создает 3-architecture.md со схемами компонентов, потоками данных, точками интеграции и архитектурными решениями. Считывает существующие технические характеристики в качестве входных данных. Используйте при: проектировании архитектуры системы, документировании взаимодействия компонентов, создании документации по архитектуре, создании 3-architecture.md. Не для: написания технических спецификаций (используйте tech-spec), реализации кода (используйте Feature-dev), только консультирования по архитектуре (используйте codex-architect).
