Интерактивные вопросы и ответы по существующему документу с резюме. Используйте, когда: пользователь хочет задать дополнительные вопросы о файле Briefing-recap-<date>.md, созданном /recap-doc, с контекстом, ограниченным резюме + перенаправлением за пределами области действия + необязательным продвижением по запросу. Не для: создания нового резюме (используйте /recap-doc), общих вопросов и ответов по проекту (используйте /ask), трассировки кода (используйте /code-explore). Вывод: файл ссылок на ответы за ход: строка + подсказка о продвижении в конце сеанса.
