Wrapper récapitulatif post-développement. À utiliser lorsque : AI/Codex vient de terminer la mise en œuvre d'une fonctionnalité et l'utilisateur souhaite une présentation guidée avec détection de portée + génération de documents + questions et réponses de suivi. Pas pour : générer uniquement un document (utiliser /recap-doc), questions et réponses sur un récapitulatif existant (utiliser /recap-ask), partage technique (utiliser /tech-brief), raisonnement sur les premiers principes d'un document existant (utiliser /fp-brief), traçage général du code (utiliser /code-explore). Résultat : ScopeReport → briefing-recap-<date>.md → session interactive de questions-réponses.
