Обертка для резюме после разработки. Используйте, когда: AI/Codex только что завершил реализацию функции, и пользователю нужно пошаговое руководство с определением области действия + созданием документации + последующими вопросами и ответами. Не для: создания только документа (используйте /recap-doc), вопросов и ответов по существующему резюме (используйте /recap-ask), технического обмена (используйте /tech-brief), обоснования существующего документа на основе первых принципов (используйте /fp-brief), общей трассировки кода (используйте /code-explore).
