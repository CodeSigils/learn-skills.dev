Examen de la couverture des tests via le Codex MCP. À utiliser dans les cas suivants : examen de la suffisance des tests, identification des lacunes de couverture, audit de la qualité des tests. Pas pour : générer des tests (utilisez codex-test-gen), révision de code (utilisez codex-code-review). Résultat : analyse de couverture + rapport d’écart.
