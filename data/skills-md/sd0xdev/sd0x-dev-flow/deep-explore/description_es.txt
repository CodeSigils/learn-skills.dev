Orquestador de exploración de código paralelo de múltiples ondas. Úselo cuando: investigación de base de código a gran escala, comprensión de sistemas complejos entre dominios, investigación profunda que necesita múltiples perspectivas simultáneamente. No apto para: búsqueda rápida (use código-explorar), confirmación dual (use código-investigación), revisión de código (use codex-code-review). Resultado: informe de exploración unificado con puntuación de integridad.
