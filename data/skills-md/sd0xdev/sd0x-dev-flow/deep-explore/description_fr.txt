Orchestrateur d'exploration de code parallèle multi-ondes. À utiliser dans les cas suivants : recherche de base de code à grande échelle, compréhension de systèmes inter-domaines complexes, investigation approfondie nécessitant plusieurs perspectives simultanément. Pas pour : la recherche rapide (utilisez code-explore), la double confirmation (utilisez code-investigate), la révision de code (utilisez codex-code-review). Résultat : rapport d’exploration unifié avec notation d’exhaustivité.
