Создавайте, обновляйте или сканируйте билеты запросов для каждой задачи для отслеживания прогресса. Это документы, не относящиеся к жизненному циклу, с префиксом даты, соответствующие требованиям Request/, а НЕ требованиям уровня функций (для них используйте /req-analyze). Используйте, когда: отслеживание хода выполнения задачи, обновление статуса выполнения, сканирование незавершенных запросов, проверка информационной панели статуса запроса. Не для: анализа проблемного пространства на уровне функций (используйте req-analyze для документа жизненного цикла 1-requirements.md), технических спецификаций (используйте tech-spec), реализации кода (используйте Feature-dev). Вывод: запросить билет с отслеживанием статуса, ссылаясь на родительскую техническую спецификацию.
