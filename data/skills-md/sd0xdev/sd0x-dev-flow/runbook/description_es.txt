Genere y actualice runbooks de lanzamiento de funciones a partir de documentos y código base existentes. Úselo cuando: cree un runbook operativo, un manual de lanzamiento, una lista de verificación de implementación, una preparación previa al lanzamiento. No para: respuesta a incidentes (v2), revisión de código (use codex-code-review), diseño de arquitectura (use arquitectura).
