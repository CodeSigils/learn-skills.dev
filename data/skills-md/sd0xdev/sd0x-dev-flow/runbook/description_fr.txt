Générez et mettez à jour les runbooks de versions de fonctionnalités à partir des documents et de la base de code existants. À utiliser lors de : la création d'un runbook opérationnel, d'un manuel de version, d'une liste de contrôle de déploiement, d'une préparation avant la version. Pas pour : la réponse aux incidents (v2), la révision du code (utiliser codex-code-review), la conception d'architecture (utiliser l'architecture).
