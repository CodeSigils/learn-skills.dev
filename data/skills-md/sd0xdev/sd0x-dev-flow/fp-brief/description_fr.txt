Briefing des premiers principes à partir de documents techniques. À utiliser quand : comprendre pourquoi les décisions ont été prises, intégrer le raisonnement, examiner les chaînes de décision, expliquer le document à partir des premiers principes. Pas pour : résumé PM/CTO (utiliser le brief de projet), analyse pré-doctorale (utiliser l'étude de faisabilité), explication du code (utiliser codex-explain). Résultat : chaîne de raisonnement structurée avec analyse de sensibilité.
