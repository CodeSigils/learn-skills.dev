Il numero di GitHub e la revisione delle pubbliche relazioni approfondiscono l'analisi con il verdetto cieco del Codex. Da utilizzare per: analizzare la causa principale del problema, classificare i problemi, pianificare le indagini, valutare i commenti di revisione delle PR per l'agibilità. Non per: correzione di bug (usa bug-fix), esplorazione del codice (usa code-explore). Risultato: analisi classificata + valutazione del verdetto + strategia investigativa.
