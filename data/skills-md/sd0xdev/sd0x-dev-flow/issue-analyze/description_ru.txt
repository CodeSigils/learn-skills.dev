GitHub Issue и PR-обзор, глубокий анализ темы со слепым вердиктом Кодекса. Используйте, когда: анализ первопричины проблемы, классификация проблем, планирование расследования, сортировка комментариев по PR-обзорам на предмет целесообразности действий. Не для: исправления ошибок (используйте bug-fix), исследования кода (используйте code-explore). Результат: секретный анализ + вынесение приговора + стратегия расследования.
