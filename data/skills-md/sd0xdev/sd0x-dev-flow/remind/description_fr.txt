Correction légère du modèle avec chargement de règles contextuelles. À utiliser lorsque : le modèle a oublié une règle, a sauté une étape obligatoire, a modifié du code/des documents sans exécuter de révision, doit relire CLAUDE.md ou les règles. Déclencheurs sur : « vous avez oublié », « rappeler », « vérifier les règles », « qu'avez-vous manqué », « 你忘了 », « avez-vous ignoré la révision », « pourquoi n'avez-vous pas exécuté le pré-engagement » ou /rappeler. Utilisez également de manière PROACTIVE après avoir modifié des fichiers si vous ne savez pas si la boucle automatique a été suivie - l'exécution de /remind ne coûte rien et détecte la dérive plus tôt. Pas pour : la révision complète du code (utilisez codex-review-fast), les conseils sur l'étape suivante (utilisez l'étape suivante), la progression du flux de travail (utilisez feature-dev).
