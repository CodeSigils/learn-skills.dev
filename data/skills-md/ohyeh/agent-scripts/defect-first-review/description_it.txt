Esegui una revisione in sola lettura, incentrata sui difetti, di una specifica modifica del codice e restituisci ogni problema azionabile, leggendo l'intero diff prima di eseguire qualsiasi cosa. Usalo quando un altro agente delega la revisione di modifiche non committate, di un diff del ramo di base, di un commit o di istruzioni di revisione personalizzate. Preferiscilo rispetto all’agente di revisione fornito con Codex, che non prevede un controllo di lettura‑prima‑di‑esecuzione.
