قم بتحويل موضوع غامض - وصف مشكلة، أو حادثة، أو قرار، أو فكرة طويلة - إلى نتيجة مصقولة بالتنسيق الذي يختاره المستخدم (md، أو صفحة html، أو قطعة أثرية، أو صورة، أو نثر عادي). تشغيل خط إنتاج الكتابة (منجم → هيكل → تشديد) مع نظام التوقف والانزلاق، ثم تقديم مهارات استخدام التصميم يدويًا. يتم الاستدعاء عندما يريد المستخدم شرح شيء ما بشكل جيد كمستند/صفحة، وليس عندما يريد فقط تغيير التعليمات البرمجية.
