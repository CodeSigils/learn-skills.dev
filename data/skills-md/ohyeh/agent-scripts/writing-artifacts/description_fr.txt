Transformez un sujet flou (une description d'un problème, un incident, une décision, une idée détaillée) en un livrable soigné dans le format choisi par l'utilisateur (md, page HTML, artefact, image ou prose simple). Gère la chaîne de production d'écriture (mine → structure → resserrer) avec une discipline stop-slop, puis confie le rendu aux compétences d'utilisation de la conception. Invoquez lorsque l'utilisateur veut que quelque chose soit BIEN EXPLIQUÉ en tant que document/page, pas lorsqu'il souhaite simplement que le code soit modifié.
