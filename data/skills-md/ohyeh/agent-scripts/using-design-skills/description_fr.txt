Méta-routeur et conducteur multi-agents pour les travaux de conception nécessitant une sélection de compétences ou un pipeline à plusieurs étapes : interface visuelle (pages Web, pages de destination, interface utilisateur du produit, écrans mobiles), visualisation des données, livrables HTML (rapports/diagrammes/plans), artefacts, finition animée et conception d'interface module/API. Le point d'entrée unifié STABLE : les compétences des membres évoluent en dessous, ce routeur les découvre en direct, choisit une autorité dans une direction, délègue les étapes de génération d'images aux travailleurs du Codex et ferme chaque pipeline avec une boucle de qualité anti-slop fondée sur des preuves. N'invoquez PAS pour un ajustement CSS/copie sur une ligne, pour un travail back-end uniquement, ou lorsque l'utilisateur nomme explicitement une compétence membre unique pour une tâche de la taille d'une compétence unique - celles-ci vont directement.
