Мета-маршрутизатор и мультиагентный проводник для проектных работ, требующих отбора навыков или многоэтапного конвейера — визуальный интерфейс (веб-страницы, целевые страницы, пользовательский интерфейс продукта, мобильные экраны), визуализация данных, результаты HTML (отчеты/диаграммы/планы), артефакты, полировка анимации и дизайн интерфейса модулей/API. Единая точка входа STABLE — навыки участников постоянно обновляются, этот маршрутизатор обнаруживает их в реальном времени, выбирает полномочия одного направления, делегирует этапы создания изображений работникам Кодекса и закрывает каждый конвейер с помощью цикла проверки качества, предотвращающего провалы. НЕ вызывайте для однострочной настройки CSS/копии, для работы только с серверной частью или когда пользователь явно называет навык одного участника для задачи размером с один навык — они идут напрямую.
