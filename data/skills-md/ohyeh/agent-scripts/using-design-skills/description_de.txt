Meta-Router und Multi-Agent-Leiter für Designarbeiten, die eine Kompetenzauswahl oder eine mehrstufige Pipeline erfordern – visuelles Frontend (Webseiten, Zielseiten, Produkt-UI, mobile Bildschirme), Datenvisualisierung, HTML-Ergebnisse (Berichte/Diagramme/Pläne), Artefakte, Bewegungspolitur und Modul-/API-Schnittstellendesign. Der STABLE einheitliche Einstiegspunkt – darunter laufen die Fähigkeiten der Mitglieder ab, dieser Router erkennt sie live, wählt eine Richtungsautorität aus, delegiert Bilderzeugungsphasen an Codex-Mitarbeiter und schließt jede Pipeline mit einer evidenzorientierten Anti-Slop-Qualitätsschleife. Rufen Sie KEINEN Aufruf für eine einzeilige CSS-/Kopieroptimierung, für reine Backend-Arbeiten oder wenn der Benutzer explizit einen einzelnen Member-Skill für eine Aufgabe in der Größe eines einzelnen Skills benennt – diese erfolgen direkt.
