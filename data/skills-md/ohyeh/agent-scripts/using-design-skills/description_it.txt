Meta-router e conduttore multi-agente per lavori di progettazione che richiedono la selezione delle competenze o una pipeline in più fasi: frontend visivo (pagine Web, pagine di destinazione, interfaccia utente del prodotto, schermi mobili), visualizzazione dei dati, risultati finali HTML (report/diagrammi/piani), artefatti, perfezionamento del movimento e progettazione di interfacce API/moduli. Il punto di ingresso unificato STABLE: le competenze dei membri si agitano sotto, questo router le scopre dal vivo, sceglie un'autorità di direzione, delega le fasi di generazione delle immagini ai lavoratori del Codex e chiude ogni pipeline con un ciclo di qualità anti-slop basato sull'evidenza. NON invocare per un tweak CSS/copia di una riga, per il lavoro solo di backend o quando l'utente nomina esplicitamente una competenza di un singolo membro per un'attività di dimensioni di una singola competenza: quelle vanno direttamente.
