Metaenrutador y conductor de múltiples agentes para trabajos de diseño que necesitan selección de habilidades o un proceso de múltiples etapas: interfaz visual (páginas web, páginas de destino, interfaz de usuario de productos, pantallas móviles), visualización de datos, entregables HTML (informes/diagramas/planes), artefactos, pulido de movimiento y diseño de interfaz de módulo/API. El punto de entrada unificado ESTABLE: las habilidades de los miembros se acumulan debajo, este enrutador las descubre en vivo, elige una autoridad de dirección, delega las etapas de generación de imágenes a los trabajadores del Codex y cierra todos los canales con un bucle de calidad anti-deslizamiento que prioriza la evidencia. NO lo invoque para un ajuste de copia/CSS de una línea, para trabajo de backend únicamente o cuando el usuario nombre explícitamente una habilidad de un solo miembro para una tarea del tamaño de una sola habilidad; esas cosas van directas.
