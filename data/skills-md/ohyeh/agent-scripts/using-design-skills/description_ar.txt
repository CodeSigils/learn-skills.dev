جهاز التوجيه التعريفي والموصل متعدد الوكلاء لأعمال التصميم التي تحتاج إلى اختيار المهارات أو مسار متعدد المراحل - الواجهة الأمامية المرئية (صفحات الويب، الصفحات المقصودة، واجهة مستخدم المنتج، شاشات الهاتف المحمول)، تصور البيانات، مخرجات HTML (التقارير/الرسوم البيانية/الخطط)، والتحف، وتلميع الحركة، وتصميم واجهة الوحدة النمطية/واجهة برمجة التطبيقات (API). نقطة الدخول الموحدة STABLE - تتجلى مهارات الأعضاء في الأسفل، ويكتشفهم جهاز التوجيه هذا مباشرة، ويختار سلطة توجيه واحدة، ويفوض مراحل إنشاء الصور إلى العاملين في Codex، ويغلق كل خط أنابيب بحلقة جودة مقاومة للانزلاق أول دليل. لا تستدعي تعديل CSS/نسخ من سطر واحد، أو للعمل على الواجهة الخلفية فقط، أو عندما يقوم المستخدم صراحةً بتسمية مهارة عضو واحدة لمهمة بحجم مهارة واحدة - فهذه تذهب مباشرة.
