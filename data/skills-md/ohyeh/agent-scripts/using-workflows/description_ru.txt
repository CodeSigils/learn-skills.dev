Мета-маршрутизатор для рецептов рабочего процесса с замкнутым циклом (аудиты, шлюзы консенсуса, конвейеры планирования/сборки, сортировка результатов, манифест парка). Вызовите ПЕРЕД выбором рабочего процесса всякий раз, когда пользователь описывает ситуацию типа «документы отклонились», «странная ошибка», «запланируйте эту функцию», «рассмотрите этот дизайн», «исправьте эту кучу результатов» или спрашивает, какой рабочий процесс/рецепт использовать. Он направляет ситуацию к правильному рецепту, автоматически заполняет аргументы, связывает замкнутый цикл и, при необходимости, запускается совместно с codex-dynamic-workflows (если он установлен) для запуска артефактов (.workflow/<YYYYMMDDHHMM>-<slug>/). Даже вероятность того, что это применимо, составляет 1%, что означает его вызов.
