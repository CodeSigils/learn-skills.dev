Meta-Router für die Closed-Loop-Workflow-Rezepte (Audits, Konsens-Gates, Plan-/Build-Pipelines, Ergebnis-Triage, Flottenmanifest). Rufen Sie VOR der Auswahl eines Workflows auf, wenn der Benutzer eine Situation beschreibt wie „Dokumente sind abgedriftet“, „seltsamer Fehler“, „diese Funktion planen“, „dieses Design überprüfen“, „diese Menge an Ergebnissen beheben“ oder fragt, welcher Workflow/welches Rezept verwendet werden soll. Es leitet die Situation an das richtige Rezept weiter, füllt automatisch Argumente aus, verkettet die geschlossene Schleife und löst optional gemeinsam mit codex-dynamic-workflows (sofern installiert) für Ausführungsartefakte (.workflow/<YYYYMMDDHHMM>-<slug>/) aus. Selbst wenn die Wahrscheinlichkeit, dass dies zutrifft, nur 1 % beträgt, bedeutet dies, dass Sie es aufrufen müssen.
