قم بتشغيل حلقة إجماع عبر النماذج المحدودة - يقوم مراجع نموذج ثانٍ جديد (Codex Sol، أو agy Gemini، أو كلود آخر) بمراجعة الاقتراح/الاختلاف/الاستنتاج بشكل خصامي من خلال جولات عقد الحكم حتى PASS أو الحد الأقصى المستدير. يتم الاستدعاء عندما يطلب المستخدم رأي النموذج الثاني، أو عندما تتغير إرشادات الهبوط/النواة/القواعد، أو عندما يحتاج الاستنتاج إلى دعم مستقل عبر النماذج. حتى احتمال تطبيق ذلك بنسبة 1% يعني استدعاءه.
