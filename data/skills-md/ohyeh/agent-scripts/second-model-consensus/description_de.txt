Führen Sie eine begrenzte modellübergreifende Konsensschleife durch – ein frischer Gutachter des zweiten Modells (Codex Sol, Agy Gemini oder ein anderer Claude) überprüft kontrovers einen Vorschlag/einen Unterschied/eine Schlussfolgerung in Urteils- und Vertragsrunden, bis er PASS oder eine Rundenobergrenze erreicht. Wird aufgerufen, wenn der Benutzer um die Meinung eines zweiten Modells bittet, wenn sich Leitlinien/Kernel/Regeln ändern oder wenn eine Schlussfolgerung eine unabhängige, modellübergreifende Unterstützung erfordert. Selbst eine Wahrscheinlichkeit von 1 % bedeutet, dass dies zutrifft.
