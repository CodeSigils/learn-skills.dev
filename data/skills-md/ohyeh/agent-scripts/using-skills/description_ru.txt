Карта верхнего уровня флота навыков, для вопроса «какой навык для этого нужен?» когда ответ не очевиден. Вызывайте, когда право собственности на задачу НЕЯСНО или она охватывает НЕСКОЛЬКО доменов. Он направляет намерение → правильный маршрутизатор/навык/рецепт и называет способы вызова каждого из них. Если основная цель уже называет домен, вместо этого введите непосредственно этот маршрутизатор или участника домена. Перечисляет только рекомендованные станции + семейные указатели; полный состав можно найти в прямом эфире.
