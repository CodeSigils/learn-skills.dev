Karte der obersten Ebene der Fertigkeitsflotte für „Welche Fertigkeit wird dafür benötigt?“ wenn die Antwort nicht offensichtlich ist. Wird aufgerufen, wenn der Eigentümer einer Aufgabe UNKLAR ist oder sie sich über MEHRERE Domänen erstreckt. Es leitet die Absicht → an den richtigen Router/die richtige Fertigkeit/das richtige Rezept weiter und benennt, wie jeder aufgerufen werden soll. Wenn das primäre Ziel bereits eine Domäne benennt, geben Sie stattdessen diesen Domänenrouter oder dieses Domänenmitglied direkt ein. Listet nur kuratierte Sender + Familienhinweise auf; Der vollständige Kader wird live entdeckt.
