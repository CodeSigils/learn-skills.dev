Eingabeaufforderungsvorlagen zum Ausfüllen von Lücken zum Delegieren von Arbeit an Subagenten oder tmux-Worker – SUCHEN/LOCATE, IMPLEMENT, REFACTOR, RESEARCH, REVIEW/VERIFY. Rufen Sie es auf, BEVOR Sie eine Delegierungsaufforderung schreiben (Agent-Tool, Agent-tmux-Worker oder Fanout-Aufgabe), damit die Eingabeaufforderung mit expliziten Abschnitten „GOAL“, „ACCEPTANCE“ und „REPORT“ anstelle einer vagen Aufforderung geliefert wird. Nicht für die Entscheidung, OB delegiert werden soll, oder für die Steuerung von Arbeitskräften nach dem Start (siehe dazu den tmux-delegate-Agenten und den tmux-agent-tools-Skill).
