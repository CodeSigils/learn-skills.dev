Meta-Router für das tmux-agent-tools-Plugin. Rufen Sie den Aufruf auf, BEVOR Sie einen Wrapper auswählen oder tmux-Agent-Arbeit delegieren – er entscheidet über Inline vs. Worker, wählt das richtige Skript aus und zeigt auf die kanonische Fähigkeitstabelle. Selbst wenn die Wahrscheinlichkeit, dass dies zutrifft, nur 1 % beträgt, müssen Sie es aufrufen.
