Cubre inicio/reanudación, envío, espera, captura, estado/médico/autoprueba, lista, parada/limpieza, puertas de aprobación humana y revisión, crítica, debate, diálogo o distribución por pares de múltiples agentes. Activar tmux como capa de ejecución para sesiones de agentes de IA administrados; no para configuración general de tmux, temas, envoltorios de shell, claude/codex sin cabeza que no sean tmux o debates de equipos humanos.
