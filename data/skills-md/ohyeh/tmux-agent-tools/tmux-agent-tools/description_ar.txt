استخدمه عند تشغيل Claude Code أو Codex CLI أو الإشراف عليهم كعمال tmux مُدارين عبر جلسات claude-tmux أو codex-tmux أو tmux-agent-sessions. يغطي البدء/الاستئناف، والإرسال، والانتظار، والالتقاط، والحالة/الطبيب/الاختبار الذاتي، والقائمة، والإيقاف/التنظيف، وبوابات الموافقة البشرية، والمراجعة الثنائية متعددة الوكلاء، والناقد، والمناقشة، والحوار، أو الخروج الموسع. تشغيل tmux كطبقة تنفيذ لجلسات وكيل الذكاء الاصطناعي المُدارة؛ ليس لتكوين tmux العام، أو السمات، أو أغلفة shell، أو claude/codex مقطوعة الرأس غير tmux، أو مناقشة الفريق البشري.
