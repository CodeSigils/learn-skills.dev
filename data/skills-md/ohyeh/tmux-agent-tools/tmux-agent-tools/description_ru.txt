Используйте при запуске или контроле Claude Code или Codex CLI в качестве управляемых рабочих процессов tmux через сеансы claude-tmux, codex-tmux или tmux-agent-session. Охватывает запуск/возобновление, отправку, ожидание, захват, статус/доктор/самопроверку, список, остановку/очистку, шлюзы одобрения людьми, а также многоагентную парную проверку, критику, дебаты, диалог или разветвление. Запускайте tmux в качестве уровня выполнения для управляемых сеансов агента ИИ; не для общей конфигурации tmux, тем, оболочек оболочки, безголового клауда/кодекса без tmux или командных дебатов между людьми.
