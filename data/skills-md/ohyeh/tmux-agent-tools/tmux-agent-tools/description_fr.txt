À utiliser lors de l'exécution ou de la supervision de Claude Code ou Codex CLI en tant que travailleurs tmux gérés via claude-tmux, codex-tmux ou tmux-agent-sessions. Couvre le démarrage/reprise, l'envoi, l'attente, la capture, l'état/médecin/auto-test, la liste, l'arrêt/nettoyage, les portes d'approbation humaine et la révision par paire multi-agents, la critique, le débat, le dialogue ou la diffusion. Déclenchez sur tmux en tant que couche d'exécution pour les sessions d'agent IA gérées ; pas pour la configuration générale de tmux, les thèmes, les wrappers de shell, le claude/codex sans tête non-tmux ou les débats en équipe humaine.
