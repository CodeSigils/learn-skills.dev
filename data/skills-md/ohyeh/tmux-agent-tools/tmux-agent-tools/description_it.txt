Da utilizzare durante l'esecuzione o la supervisione di Claude Code o Codex CLI come operatori tmux gestiti tramite sessioni claude-tmux, codex-tmux o tmux-agent. Copre avvio/riprendi, invio, attesa, acquisizione, stato/medico/autotest, elenco, arresto/pulizia, cancelli di approvazione umana e revisione di coppie multi-agente, critico, dibattito, dialogo o fanout. Trigger su tmux come livello di esecuzione per le sessioni dell'agente AI gestite; non per configurazioni tmux generali, temi, wrapper di shell, claude/codex headless non tmux o dibattiti di team umani.
