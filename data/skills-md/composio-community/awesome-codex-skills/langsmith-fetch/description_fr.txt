Déboguez les agents LangChain et LangGraph en récupérant les traces d'exécution depuis LangSmith Studio. À utiliser pour déboguer le comportement de l'agent, enquêter sur les erreurs, analyser les appels d'outils, vérifier les opérations de mémoire ou examiner les performances de l'agent. Récupère automatiquement les traces récentes et analyse les modèles d'exécution. Nécessite l'installation de la CLI Langsmith-fetch.
