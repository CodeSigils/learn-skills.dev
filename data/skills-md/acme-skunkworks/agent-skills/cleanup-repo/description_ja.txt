Git リポジトリのマージされたブランチとワークツリーをクリーンアップし、ファイルシステムの不要物 (再帰的に空のディレクトリと孤立したノード モジュール) を整理します。マージされたブランチのクリーンアップ/整頓/プルーン、古くなったワークツリーまたは終了したワークツリーの削除、PR が既にマージされているブランチ (スカッシュマージを含む) の削除、または空のディレクトリと残ったノードモジュールのスイープを要求された場合に使用します。 2 パスのマージ検出 (git 祖先とマージされた GitHub PR)、ワークツリーのコミットされていない変更の保護、オプションの線形「完了」ライトバック、パスごとの確認ゲート、および --dry-run プレビュー。保護されたブランチは決して触れられません。
