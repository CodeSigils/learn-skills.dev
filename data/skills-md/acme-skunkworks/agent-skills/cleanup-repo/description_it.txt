Pulisci i rami e gli alberi di lavoro uniti di un repository Git, quindi elimina il cruft del filesystem (directory ricorsivamente vuote e node_modules orfani). Da utilizzare quando viene richiesto di ripulire/ordinare/potare i rami uniti, rimuovere alberi di lavoro obsoleti o finiti, eliminare rami i cui PR sono già stati uniti (incluse le fusioni squash) o spazzare directory vuote e node_modules rimanenti. Rilevamento dell'unione a due passaggi (ascendenza git più PR GitHub uniti), una protezione delle modifiche non confermate sugli alberi di lavoro, un writeback lineare "Fatto" opzionale, porte di conferma per passaggio e un'anteprima --dry-run. I rami protetti non vengono mai toccati.
