Очистите объединенные ветки и рабочие деревья репозитория Git, затем удалите мусор файловой системы (рекурсивно пустые каталоги и потерянные node_modules). Используйте, когда вас просят очистить/привести в порядок/обрезать объединенные ветки, удалить устаревшие или готовые рабочие деревья, удалить ветки, PR которых уже были объединены (включая сквош-слияния), или очистить пустые каталоги и оставшиеся node_modules. Двухпроходное обнаружение слияния (предки git плюс объединенные PR GitHub), защита от незафиксированных изменений в рабочих деревьях, дополнительная линейная обратная запись «Готово», шлюзы подтверждения для каждого прохода и предварительный просмотр --dry-run. Защищенные ветки никогда не трогают.
