Limpie las ramas y los árboles de trabajo fusionados de un repositorio Git, luego elimine el sistema de archivos (directorios recursivamente vacíos y node_modules huérfanos). Úselo cuando se le solicite limpiar/ordenar/podar ramas fusionadas, eliminar árboles de trabajo obsoletos o terminados, eliminar ramas cuyos PR ya se han fusionado (incluidas las fusiones de squash) o barrer directorios vacíos y módulos de nodo sobrantes. Detección de fusión de dos pasos (git ancestry más GitHub PR fusionados), protección de cambios no confirmados en los árboles de trabajo, escritura retroactiva lineal "Listo" opcional, puertas de confirmación por paso y vista previa de ejecución en seco. Las ramas protegidas nunca se tocan.
