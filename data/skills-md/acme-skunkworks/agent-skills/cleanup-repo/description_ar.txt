قم بتنظيف الفروع وأشجار العمل المدمجة في مستودع Git، ثم قم بتقليم نظام الملفات (الأدلة الفارغة بشكل متكرر ووحدات العقدة المعزولة). استخدمه عندما يُطلب منك تنظيف / ترتيب / تقليم الفروع المدمجة، أو إزالة أشجار العمل القديمة أو المنتهية، أو حذف الفروع التي تم دمج علاقاتها العامة بالفعل (بما في ذلك عمليات دمج الاسكواش)، أو مسح الدلائل الفارغة ووحدات العقدة المتبقية. اكتشاف الدمج ثنائي المسار (git ancestry بالإضافة إلى GitHub PRs المدمج)، وحارس التغييرات غير الملتزم بها على أشجار العمل، وكتابة خطية اختيارية "تم"، وبوابات تأكيد لكل تمرير، ومعاينة التشغيل الجاف. لا يتم لمس الفروع المحمية أبدًا.
