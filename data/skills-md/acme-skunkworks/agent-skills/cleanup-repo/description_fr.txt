Nettoyez les branches et les arbres de travail fusionnés d'un référentiel Git, puis élaguez les erreurs du système de fichiers (répertoires récursivement vides et node_modules orphelins). À utiliser lorsqu'on vous demande de nettoyer/ranger/élaguer les branches fusionnées, de supprimer les arbres de travail obsolètes ou terminés, de supprimer les branches dont les PR ont déjà fusionné (y compris les fusions d'écrasement) ou de balayer les répertoires vides et les node_modules restants. Détection de fusion en deux passes (ascendance git plus PR GitHub fusionnés), une protection contre les modifications non validées sur les arbres de travail, une écriture linéaire « terminée » facultative, des portes de confirmation par passe et un aperçu --dry-run. Les branches protégées ne sont jamais touchées.
