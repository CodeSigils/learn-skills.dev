حول شجرة العمل إلى التزامات تقليدية ذرية ومنطقية - صنف الملفات غير الملتزم بها على أنها داخل النطاق وخارج النطاق مقابل قاعدة دمج الفرع، واعرض خطة مرحلية، وأنشئ التزامًا واحدًا لكل وحدة متماسكة (النوع + النطاق الاختياري + نص بريطاني-إنجليزي؛ `!` / `كسر التغيير:` لكسر التغييرات). لا تقم أبدًا بـ git add -A`; الملفات التي تبدو وكأنها تنتمي إلى فرع/شجرة عمل أخرى لا يتم تنظيمها بصمت أبدًا. يُستخدم عندما يُطلب منك تنفيذ عمل غير ملتزم به، أو تنفيذ عمل قيد التنفيذ مرتب في التزامات ذرية، أو كخطوة التزام داخل تدفق السفينة (على سبيل المثال، `/send-it`). إنه يلتزم فقط - بدون دفع أو علاقات عامة أو سجل تغيير أو إعادة كتابة خطية.
