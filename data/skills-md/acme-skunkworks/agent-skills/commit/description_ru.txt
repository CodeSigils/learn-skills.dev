Превратите рабочее дерево в логические атомарные обычные коммиты — классифицируйте незафиксированные файлы как входящие и выходящие за рамки базы слияния ветки, покажите промежуточный план и создайте один коммит для каждой связанной единицы (тип + необязательная область + британско-английское тело; `!`/`BREAKING CHANGE:` для критических изменений). Никогда не `git add -A`; файлы, которые выглядят так, как будто они принадлежат другой ветке/рабочему дереву, никогда не размещаются автоматически. Используйте, когда вас просят зафиксировать незафиксированную работу, разбить WIP на атомарные коммиты или в качестве шага фиксации внутри потока поставки (например, `/send-it`). Он только фиксирует — без push, PR, журнала изменений или линейной обратной записи.
