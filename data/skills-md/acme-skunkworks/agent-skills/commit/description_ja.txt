作業ツリーを論理的でアトミックな従来のコミットに変換します — ブランチのマージ ベースに対して、コミットされていないファイルをスコープ内とスコープ外として分類し、ステージング プランを表示し、コヒーレント ユニットごとに 1 つのコミットを作成します (タイプ + オプションのスコープ + イギリス英語の本文。重大な変更の場合は `!` / `BREAKING CHANGE:`)。決して「git add -A」を使用しないでください。別のブランチ/ワークツリーに属しているように見えるファイルは、サイレントにステージングされることはありません。コミットされていない作業をコミットするよう求められた場合、WIP をアトミック コミットに整理するか、シップ フロー内のコミット ステップとして使用します (例: `/send-it`)。コミットのみを行い、プッシュ、PR、変更ログ、リニア ライトバックは行いません。
