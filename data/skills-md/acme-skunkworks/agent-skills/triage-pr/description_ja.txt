失敗した CI を含むドラフトからプル リクエストをマージ準備完了に導きます。 PR がドラフトである間は、gh CLI と GitHub Actions ログを使用して、範囲内の CI 障害 (lint、マニフェスト lint、ビルド、テスト) を検査して修正します。CI 構成をグリーンウォッシュに弱めることはありません。 PR がレビュー準備完了とマークされたら、未解決の AI レビュー スレッド (Claude Code Review、Bugbot) を取得し、何かを変更する前にコードベースに対して各結果を検証し、有効なものを修正し、技術的な推論で無効なものを拒否し、緑色になるまで CI を再監視します。 PR のトリアージ、PR の失敗した CI またはレッド チェックの修正、PR レビュー コメント、アクション Bugbot または Claude レビューのフィードバックへの対応または応答、PR グリーンの取得、またはマージ準備のためのドラフト PR の取得を求められた場合に使用します。ベースブランチのドリフトとスコープ内のマージ競合を処理します。曖昧なものはエスカレートします。
