Guida una richiesta pull dalla bozza con CI non riuscita per renderla pronta per l'unione. Sebbene il PR sia una bozza, ispeziona e correggi gli errori CI nell'ambito (lint, manifest-lint, build, test) utilizzando la CLI gh e i log delle azioni GitHub, senza mai indebolire la configurazione CI per eseguire il greenwashing. Dopo che il PR è stato contrassegnato come pronto per la revisione, recupera i thread di revisione dell'IA non risolti (Claude Code Review, Bugbot), convalida ogni risultato rispetto alla base di codice prima di modificare qualsiasi cosa, correggi quelli validi, rifiuta quelli non validi con ragionamenti tecnici, quindi guarda nuovamente CI fino al verde. Da utilizzare quando viene richiesto di valutare un PR, correggere CI falliti o segni di spunta rossi su un PR, indirizzare o rispondere a commenti di revisione PR, agire su Bugbot o feedback di revisione Claude, ottenere un PR verde o prendere una bozza di PR per essere pronta per la fusione. Gestisce la deriva del ramo base e i conflitti di unione nell'ambito; intensifica quelli ambigui.
