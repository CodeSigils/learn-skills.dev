Bringen Sie eine Pull-Anfrage vom Entwurf mit fehlerhaftem CI zur Zusammenführungsbereitschaft. Während es sich bei der PR um einen Entwurf handelt, überprüfen und beheben Sie CI-Fehler innerhalb des Gültigkeitsbereichs (Lint, Manifest-Lint, Build, Tests) mithilfe der gh-CLI- und GitHub-Aktionsprotokolle – ohne dabei die CI-Konfiguration durch Greenwashing zu schwächen. Nachdem die PR als zur Überprüfung bereit markiert wurde, rufen Sie die ungelösten KI-Überprüfungsthreads (Claude Code Review, Bugbot) ab, validieren Sie jedes Ergebnis anhand der Codebasis, bevor Sie etwas ändern, korrigieren Sie die gültigen, lehnen Sie die ungültigen mit technischen Gründen ab und beobachten Sie dann CI erneut, bis es grün ist. Verwenden Sie diese Funktion, wenn Sie aufgefordert werden, eine PR zu selektieren, fehlgeschlagene CIs oder rote Häkchen bei einer PR zu beheben, PR-Rezensionskommentare anzusprechen oder darauf zu antworten, Bugbot- oder Claude-Review-Feedback zu bearbeiten, eine PR grün zu erhalten oder einen PR-Entwurf zur Zusammenführung zu bringen. Behandelt Base-Branch-Drift und In-Scope-Merge-Konflikte; eskaliert mehrdeutige.
