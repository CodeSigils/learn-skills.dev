Переведите запрос на включение из черновика с неудачным CI в режим готовности к слиянию. Пока PR является черновиком, проверьте и исправьте сбои CI в рамках области (lint, Manifest-lint, сборка, тесты), используя журналы gh CLI и GitHub Actions — никогда не ослабляя конфигурацию CI до «зеленой очистки». После того, как PR помечен как готовый к рассмотрению, извлеките неразрешенные потоки проверки AI (Claude Code Review, Bugbot), проверьте каждый результат на соответствие кодовой базе, прежде чем что-либо менять, исправьте действительные, отклоните недействительные по техническим причинам, а затем повторно просмотрите CI, пока не станет зеленым. Используйте, когда вас просят отсортировать PR, исправить неудачные CI или красные проверки PR, обратиться к комментариям к PR или ответить на них, выполнить действие Bugbot или Claude, просмотреть отзывы, получить зеленый PR или подготовить черновой вариант PR для подготовки к слиянию. Управляет дрейфом базовой ветки и конфликтами слияния в области видимости; обостряет неоднозначные.
