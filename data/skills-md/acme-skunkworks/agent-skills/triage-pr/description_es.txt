Impulsa una solicitud de extracción desde un borrador con CI fallido para que esté lista para fusionarse. Si bien el PR es un borrador, inspeccione y solucione las fallas de CI dentro del alcance (lint, manifest-lint, compilación, pruebas) utilizando la CLI de gh y los registros de acciones de GitHub, sin debilitar nunca la configuración de CI para hacer un lavado verde. Después de que el PR esté marcado como listo para revisión, busque los hilos de revisión de IA no resueltos (Claude Code Review, Bugbot), valide cada hallazgo con el código base antes de cambiar algo, corrija los válidos, rechace los no válidos con razonamiento técnico y luego vuelva a observar el CI hasta que esté verde. Úselo cuando se le solicite clasificar un PR, corregir CI fallidos o marcas rojas en un PR, abordar o responder a comentarios de revisión de PR, acción de revisión de Bugbot o Claude, obtener un PR verde o tomar un borrador de PR para prepararlo para fusionar. Maneja conflictos de deriva de rama base y fusión dentro del alcance; intensifica los ambiguos.
