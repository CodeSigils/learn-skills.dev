Der All-in-One-Schiffsfinisher – bündeln Sie nicht festgeschriebene Arbeit in atomare Commits, führen Sie den Change-Gated-Lint-Preflight aus, erstellen oder aktualisieren Sie den datierten Changelog-Eintrag, verfassen Sie einen PR-Titel für konventionelle Commits (das Release-Please-Bump-Signal), pushen, öffnen oder aktualisieren Sie einen PR und übertragen Sie verknüpfte lineare Issues auf „In Review“. Verwenden Sie diese Option, wenn Sie zum Versenden, Senden, Fertigstellen einer Verzweigung, zum Öffnen oder Aktualisieren einer PR für die aktuelle Arbeit oder zum Abschluss und Push aufgefordert werden. Ein Thin Orchestrator, der den Commit-Schritt an den Skill „commit“, das Lint Gate an den Skill „preflight“, das Changelog an den Skill „changelog“ und das lineare Writeback an den Skill „linear-sync“ delegiert; Es besitzt den Branch Guard, die Release-Typ-Entscheidung (nach der semantischen Kategorie der Änderung), die PR-Titel-Zusammensetzung, Push und PR. Ein Skill bedient sowohl Monorepos als auch Einzelpaket-Repos.
