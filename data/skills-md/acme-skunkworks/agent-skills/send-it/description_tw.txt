一體化交付完成器 - 將未提交的工作捆綁到原子提交中，運行更改控制的 lint 預檢，編寫或更新註明日期的更改日誌條目，撰寫常規提交 PR 標題（請發布碰撞信號），推送、打開或更新 PR，並將鏈接的線性問題轉換為“審查中”。當被要求交付、發送、完成分支、開啟或更新目前工作的 PR 或結束並推送時使用。一個瘦編排器，將提交步驟委託給“commit”技能，將 lint 門委託給“preflight”技能，將變更日誌委託給“changelog”技能，將線性寫回委託給“線性同步”技能；它擁有分支守衛、發布類型決策（根據變更的語義類別）、PR 標題組成、推送和 PR。一項技能適用於單一儲存庫和單包儲存庫。
