オールインワンのシップ フィニッシャー — コミットされていない作業をアトミック コミットにバンドルし、変更ゲート付き lint プリフライトを実行し、日付付き変更ログ エントリを作成または更新し、従来のコミットの PR タイトル (リリースしてくださいバンプ シグナル) を作成し、PR をプッシュ、オープン、または更新し、リンクされたリニアの問題をレビュー中へ移行します。出荷、送信、ブランチの終了、現在の作業の PR のオープンまたは更新、またはラップアップとプッシュを求められた場合に使用します。コミット ステップを「commit」スキルに、lint ゲートを「preflight」スキルに、変更ログを「changelog」スキルに、そしてリニア ライトバックを「linear-sync」スキルに委任するシン オーケストレーター。これは、ブランチ ガード、リリース タイプの決定 (変更の意味カテゴリによる)、PR タイトルの構成、プッシュ、および PR を所有します。 1 つのスキルは、モノリポジトリと単一パッケージのリポジトリを同様に提供します。
