올인원 완성 도구 — 커밋되지 않은 작업을 원자 커밋으로 묶고, 변경 제한 린트 프리플라이트를 실행하고, 날짜가 지정된 변경 로그 항목을 작성하거나 업데이트하고, 기존 커밋 PR 제목(릴리스-범프 신호)을 작성하고, PR을 푸시, 열기 또는 업데이트하고, 연결된 선형 문제를 In Review로 전환합니다. 배송, 전송, 분기 완료, 현재 작업에 대한 PR 열기 또는 업데이트, 마무리 및 푸시를 요청받을 때 사용합니다. 커밋 단계를 'commit' 스킬에, 린트 게이트를 'preflight' 스킬에, 변경 로그를 'changelog' 스킬에, 선형 쓰기 저장을 'linear-sync' 스킬에 위임하는 씬 오케스트레이터입니다. 이는 분기 가드, 릴리스 유형 결정(변경의 의미 범주별), PR 제목 구성, 푸시 및 PR을 소유합니다. 하나의 기술은 단일 저장소와 단일 패키지 저장소를 모두 제공합니다.
