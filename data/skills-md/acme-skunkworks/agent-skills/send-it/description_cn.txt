一体化交付完成器 - 将未提交的工作捆绑到原子提交中，运行更改控制的 lint 预检，编写或更新注明日期的更改日志条目，撰写常规提交 PR 标题（请发布碰撞信号），推送、打开或更新 PR，并将链接的线性问题转换为“审查中”。当被要求交付、发送、完成分支、打开或更新当前工作的 PR 或结束并推送时使用。一个瘦编排器，将提交步骤委托给“commit”技能，将 lint 门委托给“preflight”技能，将变更日志委托给“changelog”技能，将线性写回委托给“线性同步”技能；它拥有分支守卫、发布类型决策（根据变更的语义类别）、PR 标题组成、推送和 PR。一项技能适用于单一存储库和单包存储库。
