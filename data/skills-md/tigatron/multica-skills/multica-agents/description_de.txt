Entdecken Sie Agenten in einem Multica-Arbeitsbereich und delegieren Sie die Arbeit an sie. Behandelt das Auflisten von Agenten, das Lesen ihrer Konfiguration und das Zuweisungs-Arbeitsmuster. Verwenden Sie diese Option, wenn der Benutzer fragt, welche Agenten vorhanden sind, welchen Agent er auswählen soll, oder eine Aufgabe an einen verwalteten Agenten übergeben möchte.
