Esegui un refactoring dell'architettura delle cartelle su larga scala basato su un rapporto di controllo o un'architettura definita dall'utente. Sposta i file nelle posizioni corrette, divide cartelle di grandi dimensioni, effettua il refactoring delle importazioni, aggiorna i file barile e verifica le build dopo ogni fase. Da utilizzare dopo che audit-codebase ha generato il proprio report strutturale o quando è necessaria una riorganizzazione sistematica delle cartelle.
