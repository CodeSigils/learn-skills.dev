Esegui la scansione di qualsiasi base di codice (indipendente dal linguaggio) e segnala problemi di integrità strutturale, tra cui il gonfiamento delle cartelle, i file di grandi dimensioni, la nidificazione profonda, le incoerenze di denominazione, i file orfani, l'espansione incontrollata di documenti e le directory vuote. Genera un report di ribasso con diagrammi ad albero ASCII per problemi di struttura delle cartelle e grafici a sirena per diagrammi a livello di file. Da utilizzare quando una codebase sembra disordinata, disorganizzata o difficile da navigare.
