Escanee cualquier base de código (independiente del idioma) y señale problemas de salud estructural, incluidos exceso de carpetas, archivos de gran tamaño, anidamiento profundo, inconsistencias en los nombres, archivos huérfanos, expansión de documentos y directorios vacíos. Genera un informe de rebajas con diagramas de árbol ASCII para problemas de estructura de carpetas y gráficos de sirena para diagramas a nivel de archivo. Úselo cuando una base de código se sienta desordenada, desorganizada o difícil de navegar.
