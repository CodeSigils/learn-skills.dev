Analysez n'importe quelle base de code (indépendante de la langue) et signalez les problèmes de santé structurels, notamment la surcharge des dossiers, les fichiers surdimensionnés, l'imbrication profonde, les incohérences de nom, les fichiers orphelins, la prolifération de documents et les répertoires vides. Génère un rapport de démarque avec des diagrammes arborescents ASCII pour les problèmes de structure de dossiers et des graphiques Mermaid pour les diagrammes au niveau des fichiers. À utiliser lorsqu'une base de code semble encombrée, désorganisée ou difficile à naviguer.
