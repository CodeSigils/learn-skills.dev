Полный рабочий процесс для преобразования местных статей Markdown в формат официальной учетной записи WeChat и отправки их в ящик черновиков одним щелчком мыши. Когда пользователь говорит «отправить эту статью в официальную учетную запись», «опубликовать в официальной учетной записи WeChat», «отправить черновик», «помогите опубликовать в официальной учетной записи», «синхронизировать с черновиком официальной учетной записи», «отправить в WeChat» или подобные запросы, этот навык необходимо использовать активно — не пропускайте его. ИспользуйтеPublish.cjs для завершения рендеринга + отправки за один шаг; локальный HTML-файл не создается. Требуется Node.js 18+, никаких внешних зависимостей.
