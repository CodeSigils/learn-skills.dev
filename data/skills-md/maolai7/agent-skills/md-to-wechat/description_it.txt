Un flusso di lavoro completo per il rendering degli articoli Markdown locali nel formato dell'account ufficiale WeChat e per spingerli con un clic nella casella delle bozze. Quando l'utente dice "invia questo articolo all'account ufficiale", "pubblica sull'account ufficiale di WeChat", "invia bozza", "aiutami a pubblicare sull'account ufficiale", "sincronizza nella casella delle bozze dell'account ufficiale", "invia a WeChat" o richieste simili, è necessario utilizzare in modo proattivo questa abilità, non saltarla. Utilizzapublish.cjs per completare il rendering + push in un solo passaggio; non viene generato alcun file HTML locale. Richiede Node.js 18+, zero dipendenze esterne.
