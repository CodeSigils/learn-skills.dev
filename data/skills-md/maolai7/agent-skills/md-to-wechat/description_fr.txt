Un flux de travail complet pour restituer les articles Markdown locaux au format de compte officiel WeChat et les placer dans la boîte de brouillons en un seul clic. Lorsque l'utilisateur dit « envoyer cet article sur le compte officiel », « publier sur le compte officiel WeChat », « envoyer un brouillon », « aidez-moi à publier sur le compte officiel », « synchroniser avec la zone de brouillon du compte officiel », « envoyer vers WeChat » ou des demandes similaires, cette compétence doit être utilisée de manière proactive – ne l'ignorez pas. Utilisez submit.cjs pour terminer le rendu + le push en une seule étape ; aucun fichier HTML local n'est généré. Nécessite Node.js 18+, aucune dépendance externe.
