Un flux de travail complet qui restitue les articles Markdown locaux au format de compte officiel WeChat et les place dans le dossier des brouillons en un seul clic. Lorsque les utilisateurs disent « pousser cet article sur le compte officiel », « publier sur le compte officiel WeChat », « pousser le brouillon », « aidez-moi à publier sur le compte officiel », « synchroniser avec les brouillons du compte officiel WeChat », « pousser vers WeChat » ou des demandes similaires, vous devez utiliser cette compétence de manière proactive sans la sauter. Utilisez submit.cjs pour terminer le rendu + le push en une seule étape, pas besoin de générer des fichiers HTML locaux. Nécessite Node.js 18+, aucune dépendance externe.
