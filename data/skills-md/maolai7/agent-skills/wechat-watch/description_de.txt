Abonnement und Push von Artikeln zum offiziellen WeChat-Konto. Stellen Sie den Wechat-Download-API-Dienst automatisch bereit, fragen Sie regelmäßig die verfolgten Konten ab, fassen Sie neue Artikel zusammen und übertragen Sie sie an Feishu. Auslöserbedingungen: Der Benutzer erwähnt „Offizielles Konto-Abonnement“, „WeChat-Artikel-Push“, „Wechat Watch“, „Offizielle Konto-Updates“ usw. oder wird durch einen Cron-Job ausgelöst. Voraussetzungen: Der Benutzer muss über ein offizielles WeChat-Konto (Abonnement oder Dienstkonto) für die Scan-Code-Anmeldung verfügen.
