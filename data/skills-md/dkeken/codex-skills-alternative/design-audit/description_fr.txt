Auditez une interface utilisateur existante pour détecter les problèmes d'utilisabilité, de hiérarchie, d'accessibilité et de conversion. Examine une URL en direct, une capture d'écran ou une base de code par rapport à des heuristiques et signale les problèmes prioritaires avec des correctifs. À utiliser lorsque l'utilisateur dit « auditer cette interface utilisateur », « qu'est-ce qui ne va pas avec cet écran », « examen UX », « trouver les problèmes », « pourquoi est-ce déroutant » ou a une interface existante à critiquer. Fait partie de l'ensemble de conception de produits. Peut piloter un navigateur pour les audits en direct.
