Audite una interfaz de usuario existente para detectar problemas de usabilidad, jerarquía, accesibilidad y conversión. Revisa una URL en vivo, una captura de pantalla o una base de código según heurísticas e informa problemas priorizados con correcciones. Úselo cuando el usuario diga "audite esta interfaz de usuario", "qué está mal con esta pantalla", "revisión de UX", "encuentre los problemas", "por qué es confuso" o tiene una interfaz existente para criticar.
