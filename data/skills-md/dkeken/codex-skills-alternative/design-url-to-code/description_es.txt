Convierta un sitio web activo en una interfaz local funcional que pueda editar. Obtiene la página, extrae su sistema de diseño y estructura, la reconstruye localmente en su pila y luego la compara con una captura de pantalla con el original. Úselo cuando el usuario diga "url para codificar", "clonar este sitio localmente", "hacer que parezca lineal.app", "reconstruir esta página" o proporcione una URL activa para recrear. Parte del conjunto de Diseño de Producto. Utiliza búsqueda web + automatización del navegador.
