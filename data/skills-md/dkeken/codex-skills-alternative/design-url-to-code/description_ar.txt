قم بتحويل موقع ويب مباشر إلى واجهة أمامية محلية عاملة يمكنك تعديلها. جلب الصفحة، واستخراج نظام تصميمها وبنيتها، وإعادة بنائها محليًا في مجموعتك، ثم مقارنة لقطة الشاشة بالأصل. يُستخدم عندما يقول المستخدم "عنوان url للرمز"، أو "استنساخ هذا الموقع محليًا"، أو "اجعله يبدو وكأنه خطي.app"، أو "أعد إنشاء هذه الصفحة"، أو يقدم عنوان URL مباشرًا لإعادة إنشائه. جزء من مجموعة تصميم المنتج. يستخدم جلب الويب + أتمتة المتصفح.
