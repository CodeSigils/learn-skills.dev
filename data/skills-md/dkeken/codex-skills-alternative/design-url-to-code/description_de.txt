Verwandeln Sie eine Live-Website in ein funktionierendes lokales Frontend, das Sie bearbeiten können. Ruft die Seite ab, extrahiert ihr Designsystem und ihre Struktur, baut sie lokal in Ihrem Stapel neu auf und vergleicht dann einen Screenshot mit dem Original. Wird verwendet, wenn der Benutzer „URL zum Codieren“, „Diese Site lokal klonen“, „sie wie linear.app aussehen lassen“, „Diese Seite neu erstellen“ sagt oder eine Live-URL zum Neuerstellen bereitstellt. Teil des Produktdesign-Sets. Verwendet Web-Fetch + Browser-Automatisierung.
