Превратите действующий веб-сайт в работающий локальный интерфейс, который вы сможете редактировать. Извлекает страницу, извлекает ее дизайн-систему и структуру и перестраивает ее локально в стеке, а затем сравнивает скриншот с оригиналом. Используйте, когда пользователь говорит «URL для кода», «клонируйте этот сайт локально», «сделайте его похожим на Linear.app», «перестройте эту страницу» или предоставляет действующий URL-адрес для воссоздания. Входит в набор «Дизайн продукта». Использует веб-загрузку + автоматизацию браузера.
