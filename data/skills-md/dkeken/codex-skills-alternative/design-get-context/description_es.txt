Aclare el informe ANTES de cualquier trabajo de diseño para evitar construir algo incorrecto. Interroga el objetivo, el usuario, las limitaciones, los criterios de éxito y el alcance, luego escribe un breve documento de contexto que consumen las otras habilidades de diseño. Úselo cuando el usuario diga "diseñemos X", "creemos una interfaz de usuario para Y", "obtenga contexto", "aclare el resumen" o inicie cualquier tarea de diseño de producto sin una especificación clara. Primera etapa del conjunto de Diseño de Producto: mayor influencia para reducir el retrabajo.
