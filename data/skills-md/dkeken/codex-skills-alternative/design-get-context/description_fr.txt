Clarifiez le brief AVANT tout travail de conception pour éviter de construire une mauvaise chose. Interroge l'objectif, l'utilisateur, les contraintes, les critères de réussite et la portée, puis rédige un court document contextuel que les autres compétences de conception consomment. À utiliser lorsque l'utilisateur dit « concevons X », « construisons une interface utilisateur pour Y », « obtenons le contexte », « clarifions le brief » ou lance toute tâche de conception de produit sans spécification claire. Première étape de l'ensemble de conception de produits : levier le plus élevé pour réduire les retouches.
