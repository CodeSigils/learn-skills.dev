Уточните задание ПЕРЕД началом любых проектных работ, чтобы избежать создания неправильной вещи. Опрашивает цель, пользователя, ограничения, критерии успеха и объем, а затем пишет краткий контекстный документ, который понадобится другим навыкам проектирования. Используйте, когда пользователь говорит «давайте спроектируем X», «создадим пользовательский интерфейс для Y», «получите контекст», «уточним краткое описание» или приступает к любой задаче по проектированию продукта без четкой спецификации. Первый этап набора «Дизайн продукта» — максимальный эффект для сокращения переделок.
