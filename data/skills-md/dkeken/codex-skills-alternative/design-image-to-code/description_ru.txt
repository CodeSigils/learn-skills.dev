Превратите эталонное изображение или макет в работающий локальный интерфейс, который точно соответствует ему. Осматривает изображение, извлекает систему дизайна (макет, тип, интервал, цвет, компоненты), реализует ее, затем сравнивает скриншоты и выполняет итерации, чтобы устранить пробел. Используйте, когда пользователь говорит «изображение для кодирования», «создай этот макет», «закодируй этот скриншот», «воплоти этот дизайн в жизнь» или предоставляет изображение пользовательского интерфейса для реализации. Входит в набор «Дизайн продукта». Использует инструмент браузера для проверки снимков экрана.
