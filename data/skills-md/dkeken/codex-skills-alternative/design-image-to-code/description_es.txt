Convierta una imagen de referencia o una maqueta en una interfaz local funcional que se ajuste estrechamente a ella. Inspecciona la imagen, extrae el sistema de diseño (diseño, tipo, espaciado, color, componentes), lo implementa, luego compara capturas de pantalla e itera para cerrar la brecha. Úselo cuando el usuario diga "imagen a código", "construya esta maqueta", "codifique esta captura de pantalla", "haga real este diseño" o proporcione una imagen de interfaz de usuario para implementar. Parte del conjunto de Diseño de Producto. Utiliza una herramienta de navegador para la verificación de capturas de pantalla.
