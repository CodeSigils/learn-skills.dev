Verwandeln Sie ein Referenzbild oder Modell in ein funktionierendes lokales Frontend, das genau dazu passt. Untersucht das Bild, extrahiert das Designsystem (Layout, Typ, Abstand, Farbe, Komponenten), implementiert es, vergleicht dann Screenshots und iteriert, um die Lücke zu schließen. Wird verwendet, wenn der Benutzer „Bild zum Codieren“, „Dieses Modell erstellen“, „Diesen Screenshot codieren“, „Dieses Design realisieren“ sagt oder ein UI-Bild zur Implementierung bereitstellt. Teil des Produktdesign-Sets. Verwendet ein Browser-Tool zur Screenshot-Überprüfung.
