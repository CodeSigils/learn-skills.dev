Exécutez 5 commandes git avant de lire un code pour diagnostiquer une nouvelle base de code : points chauds de désabonnement du code, facteur de bus, clusters de bogues, vitesse du projet et fréquence de lutte contre les incendies. À utiliser lors de l'intégration dans un nouveau projet, du démarrage d'un audit de base de code ou de la décision sur où concentrer les efforts de refactorisation/d'analyse.
