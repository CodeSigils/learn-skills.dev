Ejecute 5 comandos de git antes de leer cualquier código para diagnosticar una nueva base de código: puntos críticos de rotación de código, factor de bus, grupos de errores, velocidad del proyecto y frecuencia de extinción de incendios. Úselo al incorporarse a un nuevo proyecto, iniciar una auditoría de la base de código o decidir dónde enfocar los esfuerzos de refactorización/análisis.
