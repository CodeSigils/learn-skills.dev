Esegui 5 comandi git prima di leggere qualsiasi codice per diagnosticare una nuova base di codice: hotspot di abbandono del codice, fattore bus, cluster di bug, velocità del progetto e frequenza antincendio. Da utilizzare durante l'onboarding in un nuovo progetto, l'avvio di un controllo della base di codice o la decisione su dove concentrare le attività di refactoring/analisi.
