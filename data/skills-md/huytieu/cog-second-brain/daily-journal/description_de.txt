Ein passives tägliches Arbeitstagebuch, das Claude FÜR Sie führt, sodass Sie es nie selbst schreiben müssen. Fügen Sie kurze Einträge nach sinnvoller Arbeit (was getan wurde, worauf Sie sich konzentriert haben, berührte Artefakte) an 01-daily/journal/YYYY-MM-DD.md an. Führen Sie nachts oder morgens eine geführte Reflexion durch. Verwenden Sie diese Option, wenn Sie /daily-journal ausführen, sagen Sie „Dies in mein Tagebuch protokollieren“, „Zum heutigen Tagebuch hinzufügen“, „Über heute/gestern nachdenken“ oder wenn Sie in einer Sitzung einen bedeutungsvollen Teil der Arbeit beenden.
