تطوير الواجهة الخلفية Rust الجاهزة للإنتاج باستخدام إطار عمل Axum وPostgreSQL. أنماط المزامنة الرئيسية، والبرمجيات الوسيطة البرجية، وعمليات قاعدة بيانات SQLx، والمصادقة (JWT/OAuth)، واستراتيجيات الاختبار، والنشر. يُستخدم عند إنشاء واجهات برمجة تطبيقات REST أو الخدمات الصغيرة أو أي واجهة خلفية ويب لـ Rust مع Axum.
