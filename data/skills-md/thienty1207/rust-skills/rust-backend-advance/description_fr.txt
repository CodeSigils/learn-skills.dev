Développement backend Rust prêt pour la production avec le framework Axum et PostgreSQL. Maîtrisez les modèles asynchrones, le middleware tour, les opérations de base de données SQLx, l'authentification (JWT/OAuth), les stratégies de test et le déploiement. À utiliser lors de la création d'API REST, de microservices ou de tout backend Web Rust avec Axum.
