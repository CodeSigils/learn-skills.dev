Готовая к использованию серверная часть Rust с использованием платформы Axum и PostgreSQL. Освойте асинхронные шаблоны, промежуточное программное обеспечение Tower, операции с базами данных SQLx, аутентификацию (JWT/OAuth), стратегии тестирования и развертывание. Используйте при создании REST API, микросервисов или любого веб-сервера Rust с помощью Axum.
