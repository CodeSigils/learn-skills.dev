Finden Sie Bilder, die Sie getrost kostenlos verwenden können – für Websites, Dokumente, Präsentationen, Benutzeroberflächen, Blogbeiträge, Marketingressourcen oder alles andere –, ohne sich jemals Gedanken über die Lizenzierung machen zu müssen. Diese Fähigkeit greift auf ein kuratiertes Repository vorab geprüfter Bilder zurück, ist an eine bestimmte, von Menschen überprüfte Überarbeitung angeheftet und bestätigt die Lizenz jedes Bildes – gelesen aus den eigenen eingebetteten Metadaten des Bildes –, bevor es übergeben wird, sodass die Lizenzfrage bereits beantwortet ist, wenn Sie die URL erhalten. Wird bei jeder Anfrage ausgelöst, die ein Bild, Foto, eine Illustration, ein Banner, einen Helden oder ein visuelles Asset betrifft, einschließlich Phrasen wie „Such mir ein Bild von …“, „Ich brauche ein Foto von …“, „Besorge dir ein Bild für …“. Verwenden Sie dies auch beim Erstellen von Benutzeroberflächen, Artikeln oder Inhalten, bei denen ein stressfreies, frei lizenziertes Bild erforderlich ist.
