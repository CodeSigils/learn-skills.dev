Используйте, когда cognee — это механизм памяти Python AI, который преобразует документы в графы знаний с векторным и графическим хранилищем для семантического поиска и рассуждения. Используйте этот навык при написании кода, который вызывает API Python Cognee (добавление, распознавание, поиск, мемификация, конфигурация, наборы данных, обрезка, сеанс) или интеграции cognee-mcp. Охватывает полный общедоступный API, режимы SearchType, пользовательские модели DataPoint, задачи конвейера и конфигурацию для поставщиков LLM/встраивания/векторов/графов. НЕ используйте для общих знаний теорию графов или несвязанные библиотеки Python.
