يُستخدم عندما يكون cognee هو محرك ذاكرة Python AI الذي يحول المستندات إلى رسوم بيانية معرفية مع تخزين المتجهات والرسوم البيانية للبحث والاستدلال الدلالي. استخدم هذه المهارة عند كتابة التعليمات البرمجية التي تستدعي واجهة برمجة تطبيقات Python الخاصة بـ cognee (إضافة، معرفة، بحث، memify، config، مجموعات بيانات، تقليم، جلسة) أو دمج cognee-mcp. يغطي واجهة برمجة التطبيقات العامة الكاملة، وأوضاع SearchType، ونماذج DataPoint المخصصة، ومهام خطوط الأنابيب، والتكوين لموفري LLM/التضمين/المتجه/الرسم البياني. لا تستخدم لنظرية الرسم البياني للمعرفة العامة أو مكتبات بايثون غير ذات الصلة.
