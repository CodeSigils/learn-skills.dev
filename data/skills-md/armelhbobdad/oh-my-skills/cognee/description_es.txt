Úselo cuando cognee sea un motor de memoria de IA de Python que transforma documentos en gráficos de conocimiento con almacenamiento de gráficos y vectores para búsqueda y razonamiento semántico. Utilice esta habilidad al escribir código que llame a la API Python de cognee (agregar, conocer, buscar, memificar, configurar, conjuntos de datos, podar, sesión) o al integrar cognee-mcp. Cubre la API pública completa, los modos SearchType, los modelos personalizados de DataPoint, las tareas de canalización y la configuración para proveedores de LLM/incrustación/vectoriales/gráficos. NO lo use para teoría de grafos de conocimiento general o bibliotecas de Python no relacionadas.
