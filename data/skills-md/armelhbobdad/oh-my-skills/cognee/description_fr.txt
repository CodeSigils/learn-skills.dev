À utiliser lorsque cognee est un moteur de mémoire Python AI qui transforme les documents en graphiques de connaissances avec stockage vectoriel et graphique pour la recherche sémantique et le raisonnement. Utilisez cette compétence lors de l'écriture de code qui appelle l'API Python de cognee (ajout, cognify, recherche, mémify, config, datasets, prune, session) ou lors de l'intégration de cognee-mcp. Couvre l'API publique complète, les modes SearchType, les modèles personnalisés DataPoint, les tâches de pipeline et la configuration des fournisseurs LLM/incorporation/vecteur/graphique. Ne PAS utiliser pour la théorie générale des graphes ou pour les bibliothèques Python non liées.
