cognee が Python AI メモリ エンジンであり、セマンティック検索と推論のためにベクトルおよびグラフ ストレージを備えたドキュメントをナレッジ グラフに変換する場合に使用します。このスキルは、cognee の Python API (add、cognify、search、memify、config、datasets、prune、session) を呼び出すコードを作成するとき、または cognee-mcp を統合するときに使用します。完全なパブリック API、SearchType モード、DataPoint カスタム モデル、パイプライン タスク、LLM/embedding/vector/graph プロバイダーの構成をカバーします。一般知識のグラフ理論や無関係な Python ライブラリには使用しないでください。
