Costruisci e mantieni una guida Markdown che aiuti gli esseri umani a comprendere un repository attraverso comportamenti, concetti e prove reali. Da utilizzare quando un utente chiede di comprendere un repository, generare o aggiornare documenti di repository, rispondere a domande sull'architettura/onboarding del repository, inviare documenti per un nuovo progetto, sincronizzare documenti dopo modifiche al codice o eliminare documenti di repository generati.
