Erstellen und pflegen Sie einen Markdown-Leitfaden, der Menschen hilft, ein Repository anhand realer Verhaltensweisen, Konzepte und Beweise zu verstehen. Wird verwendet, wenn ein Benutzer ein Repo verstehen, Repo-Dokumente generieren oder aktualisieren, Fragen zur Repo-Architektur/Onboarding beantworten, Dokumente für ein neues Projekt bereitstellen, Dokumente nach Codeänderungen synchronisieren oder generierte Repo-Dokumente löschen möchte.
