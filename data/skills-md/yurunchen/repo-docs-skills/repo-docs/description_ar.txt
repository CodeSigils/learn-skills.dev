قم ببناء وصيانة دليل Markdown الذي يساعد البشر على فهم المستودع من خلال السلوك والمفاهيم والأدلة الحقيقية. يُستخدم عندما يطلب المستخدم فهم الريبو، أو إنشاء مستندات الريبو أو تحديثها، أو الإجابة على أسئلة بنية الريبو/الإعداد، أو المستندات الأولية لمشروع جديد، أو مزامنة المستندات بعد تغيير التعليمات البرمجية، أو حذف مستندات الريبو التي تم إنشاؤها.
