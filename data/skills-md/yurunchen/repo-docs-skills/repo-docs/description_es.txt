Cree y mantenga una guía de Markdown que ayude a los humanos a comprender un repositorio a través de comportamientos, conceptos y evidencia reales. Úselo cuando un usuario solicita comprender un repositorio, generar o actualizar documentos de repositorio, responder preguntas sobre arquitectura/incorporación de repositorio, generar documentos para un nuevo proyecto, sincronizar documentos después de cambios de código o eliminar documentos de repositorio generados.
