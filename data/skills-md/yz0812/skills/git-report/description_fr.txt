Générez des rapports hebdomadaires/mensuels de commit Git. Méthodes de déclenchement : « générer un rapport hebdomadaire », « générer un rapport mensuel », « générer le rapport de cette semaine », « générer un rapport mensuel de décembre », « générer un rapport hebdomadaire @username », « générer un rapport pour les N derniers jours ». Prend en charge la spécification des utilisateurs, des plages de dates et du nombre de jours. Préférez utiliser git-server MCP ; s'il n'est pas disponible, utilisez les commandes git.
