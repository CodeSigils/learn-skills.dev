Создавайте еженедельные/ежемесячные отчеты о коммитах Git. Методы триггера: «создать еженедельный отчет», «создать ежемесячный отчет», «создать отчет за эту неделю», «создать ежемесячный отчет за декабрь», «создать еженедельный отчет @имя пользователя», «создать отчет за последние N дней». Поддерживает указание пользователей, диапазонов дат и количества дней. Предпочитаю использовать git-сервер MCP; если они недоступны, используйте команды git.
