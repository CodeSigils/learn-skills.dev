Generieren Sie wöchentliche/monatliche Git-Commit-Berichte. Auslösemethoden: „Wöchentlichen Bericht erstellen“, „Monatlichen Bericht erstellen“, „Bericht dieser Woche erstellen“, „Monatsbericht für Dezember erstellen“, „Wöchentlichen Bericht @Benutzername erstellen“, „Bericht für die letzten N Tage erstellen“. Unterstützt die Angabe von Benutzern, Datumsbereichen und Anzahl der Tage. Bevorzugen Sie die Verwendung von Git-Server MCP; Wenn nicht verfügbar, verwenden Sie Git-Befehle.
