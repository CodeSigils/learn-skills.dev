Genera report settimanali/mensili sui commit Git. Metodi di attivazione: "genera report settimanale", "genera report mensile", "genera report di questa settimana", "genera report mensile di dicembre", "genera report settimanale @nomeutente", "genera report per gli ultimi N giorni". Supporta la specifica di utenti, intervalli di date e numero di giorni. Preferisci usare git-server MCP; se non disponibile, usa i comandi git.
