Testphilosophie und Verifizierungsdesign. Wird für den Entwurf von Teststrategien, die Qualitätsüberprüfung und die Kernfrage „Woher wissen wir, dass das System korrekt ist“ verwendet. Wird ausgelöst, wenn ein Benutzer einen Testplan entwerfen, die Testqualität überprüfen oder eine Teststrategie besprechen muss. Selbst wenn der Benutzer nur sagt „wie man das testet“, „ist der Test richtig geschrieben“ oder „welche Tests erforderlich sind“, sollte er ausgelöst werden.
