Testphilosophie und Verifikationsdesign. Wird für den Entwurf von Teststrategien, die Qualitätsüberprüfung und die Kernfrage „Woher wissen wir, dass das System korrekt ist“ verwendet. Es wird ausgelöst, wenn ein Benutzer einen Testplan entwerfen, die Testqualität überprüfen oder eine Teststrategie besprechen muss. Auch wenn der Benutzer nur sagt „wie man das testet“, „ist der Test richtig geschrieben“ oder „welche Tests erforderlich sind“, sollte er dennoch ausgelöst werden.
