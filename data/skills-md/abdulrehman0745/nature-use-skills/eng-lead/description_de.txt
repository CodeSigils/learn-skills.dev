Leitung der technischen Umsetzung. Verantwortlich für die technische Ausführung vom Architekturentwurf bis zum ausführbaren Code – Modulzerlegung, Teamplanung, Qualitätssicherung und Wissensmanagement. Wird ausgelöst, wenn Benutzer Entwürfe in Code umwandeln, Entwicklungsteams verwalten oder technische Entscheidungen treffen müssen. Auch wenn der Benutzer nur sagt: „Wie soll das geschehen“, „Wie soll der Code organisiert sein“ oder „Wie soll das Team die Arbeit aufteilen“, sollte es dennoch ausgelöst werden.
