Leitung der technischen Umsetzung. Verantwortlich für die technische Ausführung vom Architekturentwurf bis zum ausführbaren Code – Modulzerlegung, Teamplanung, Qualitätssicherung und Wissensmanagement. Wird ausgelöst, wenn Benutzer Entwürfe in Code umwandeln, Entwicklungsteams verwalten oder technische Entscheidungen treffen müssen. Selbst wenn der Benutzer nur sagt: „Wie soll das geschehen“, „Wie soll der Code organisiert werden“ oder „Wie soll das Team aufgeteilt werden“, sollte es dennoch ausgelöst werden.
