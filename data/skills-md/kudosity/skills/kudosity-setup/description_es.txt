Configure Kudosity desde cero: cree una cuenta, encuentre sus credenciales de API, comprenda cuál de las dos API necesita cada credencial, obtenga un remitente y verifique que todo funcione antes de enviar. Úselo cuando alguien aún no tiene una cuenta o credenciales de Kudosity, cuando una llamada devuelve 401 o cuando falla un envío porque no hay un remitente válido.
