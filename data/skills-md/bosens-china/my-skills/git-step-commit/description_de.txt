Analysieren Sie den Git-Arbeitsbaum und die bereitgestellten Änderungen, schlagen Sie einen oder mehrere kohärente Commit-Batches zur Benutzergenehmigung vor, leiten Sie den Commit-Nachrichtenstil aus dem Repository-Verlauf ab und führen Sie dann git add/git commit nur für genehmigte Batches aus. Verwenden Sie diese Option, wenn der Benutzer nach Git-Commit, Commit-Änderungen, Git-Commit-Bereinigung, gestufter Commit-Bereinigung oder Commit-Aktion mit sinnvollen Nachrichten fragt.
