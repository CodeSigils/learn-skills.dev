قم بتحليل شجرة عمل Git والتغييرات المرحلية، واقترح واحدة أو أكثر من دفعات الالتزام المتماسكة لموافقة المستخدم، واستنتج نمط رسالة الالتزام من سجل المستودع، ثم قم بتشغيل git add/git الالتزام فقط للدفعات المعتمدة. يُستخدم عندما يطلب المستخدم التزام git، أو الالتزام بالتغييرات، أو تنفيذ git، أو تنظيف الالتزام المرحلي، أو يريد تنفيذ التغييرات الحالية برسائل معقولة.
