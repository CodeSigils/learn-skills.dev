Analizza l'albero di lavoro di Git e le modifiche graduali, proponi uno o più batch di commit coerenti per l'approvazione dell'utente, deduci lo stile del messaggio di commit dalla cronologia del repository, quindi esegui git add/git commit solo per i batch approvati. Da utilizzare quando l'utente richiede git commit, commit di modifiche, git 分步提交, 分批提交, pulizia del commit a fasi o desidera che le modifiche attuali vengano confermate con messaggi sensati.
