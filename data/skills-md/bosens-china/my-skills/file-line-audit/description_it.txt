Controlla i file di origine di grandi dimensioni in un repository. Applica le regole .gitignore del repository più modelli di esclusione aggiuntivi, filtra i file candidati con modelli di inclusione glob, conta le linee fisiche e genera solo file pari o superiori alla soglia. Utilizza questa capacità quando l'utente chiede di trovare file lunghi, rivedere la distribuzione della lunghezza dei file, identificare candidati alla suddivisione/refactoring o analizzare il debito tecnico.
