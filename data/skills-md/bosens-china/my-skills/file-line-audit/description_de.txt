Überwachen Sie übergroße Quelldateien in einem Repository. Wenden Sie Repository-.gitignore-Regeln sowie zusätzliche Ausschlussmuster an, filtern Sie Kandidatendateien mit Einschluss-Glob-Mustern, zählen Sie physische Zeilen und geben Sie nur Dateien aus, die den Schwellenwert erreichen oder darüber liegen. Verwenden Sie diese Fähigkeit, wenn der Benutzer lange Dateien finden, die Dateilängenverteilung überprüfen, Split-/Refactor-Kandidaten identifizieren oder technische Schulden analysieren möchte.
