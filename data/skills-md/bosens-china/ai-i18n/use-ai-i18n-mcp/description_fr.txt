Utilisez les huit outils MCP ai-i18n locaux pour inspecter les traductions manquantes ou orphelines, mettre à jour la mémoire de traduction JSON ou SQLite configurée et gérer les valeurs overrides.json révisées. À utiliser lorsque vous travaillez avec ai_i18n_list_translations, ai_i18n_set_translations, ai_i18n_clear_translations, ai_i18n_list_orphan_messages, ai_i18n_delete_orphan_messages, ai_i18n_list_overrides, ai_i18n_set_overrides ou ai_i18n_delete_overrides, en particulier lorsqu'un monorepo nécessite d'abord de résoudre le répertoire i18n d'une application Vite.
