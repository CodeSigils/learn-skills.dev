استخدم أدوات ai-i18n MCP المحلية الثمانية لفحص الترجمات المفقودة أو المعزولة، وتحديث ذاكرة ترجمة JSON أو SQLite التي تم تكوينها، وإدارة قيم overrides.json التي تمت مراجعتها. يُستخدم عند العمل مع ai_i18n_list_translations، أو ai_i18n_set_translations، أو ai_i18n_clear_translations، أو ai_i18n_list_orphan_messages، أو ai_i18n_delete_orphan_messages، أو ai_i18n_list_overrides، أو ai_i18n_set_overrides، أو ai_i18n_delete_overrides، خاصةً عندما يتطلب monorepo حل دليل i18n الخاص بتطبيق Vite أولاً.
