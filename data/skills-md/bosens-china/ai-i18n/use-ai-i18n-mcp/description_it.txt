Utilizza gli otto strumenti MCP ai-i18n locali per controllare le traduzioni mancanti o orfane, aggiornare la memoria di traduzione JSON o SQLite configurata e gestire i valori overrides.json revisionati. Da utilizzare quando si lavora con ai_i18n_list_translations, ai_i18n_set_translations, ai_i18n_clear_translations, ai_i18n_list_orphan_messages, ai_i18n_delete_orphan_messages, ai_i18n_list_overrides, ai_i18n_set_overrides o ai_i18n_delete_overrides, soprattutto quando un monorepo richiede prima la risoluzione della directory i18n di un'app Vite.
