8개의 로컬 ai-i18n MCP 도구를 사용하여 누락되거나 분리된 번역을 검사하고, 구성된 JSON 또는 SQLite 번역 메모리를 업데이트하고, 검토된 overrides.json 값을 관리합니다. ai_i18n_list_translations, ai_i18n_set_translations, ai_i18n_clear_translations, ai_i18n_list_orphan_messages, ai_i18n_delete_orphan_messages, ai_i18n_list_overrides, ai_i18n_set_overrides로 작업할 때 사용합니다. ai_i18n_delete_overrides, 특히 모노레포가 하나의 Vite 앱의 i18n 디렉터리를 먼저 확인해야 하는 경우.
