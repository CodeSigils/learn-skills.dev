Utilice las ocho herramientas MCP ai-i18n locales para inspeccionar traducciones faltantes o huérfanas, actualizar la memoria de traducción JSON o SQLite configurada y administrar los valores overrides.json revisados. Úselo cuando trabaje con ai_i18n_list_translations, ai_i18n_set_translations, ai_i18n_clear_translations, ai_i18n_list_orphan_messages, ai_i18n_delete_orphan_messages, ai_i18n_list_overrides, ai_i18n_set_overrides o ai_i18n_delete_overrides, especialmente cuando un monorepo requiere resolver primero el directorio i18n de una aplicación Vite.
