مواصفات-مرحلة المهارة الفرعية للقوى العظمى. استخدمه عندما يطلب المستخدم التحليل أولاً، أو كتابة المواصفات أولاً، أو القيام بالتصميم التفصيلي أولاً، أو تنظيم ملاحظات الاجتماع/المتطلبات الشفهية، أو تحويل المتطلبات إلى OpenSpec صيني قابل للتنفيذ؛ تنفيذ الكتلة والانهيار والاختبار حتى اكتمال المواصفات. لا تستخدمه لإصلاحات التعليمات البرمجية فقط التي لا تتضمن قواعد أو عمليات أو واجهات أو حالات جديدة.
