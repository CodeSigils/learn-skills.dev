À utiliser lors de l'écriture, de la révision ou de la refactorisation d'une application back-end TypeScript/Node.js ou d'un code API où des conseils de conception back-end sont utiles, y compris les API, les routes, les contrôleurs, les middleware, les SDK, les services, les référentiels, l'accès aux bases de données, les travailleurs d'exécution et les intégrations externes qui implémentent le comportement du back-end. Ne l'utilisez pas simplement parce que le code s'exécute dans Node.js ou sur un serveur. Ignorez la configuration CI/workflow, les scripts de déploiement ou de maintenance, les démos, les tests, les renommages simples, le formatage, les travaux de documentation uniquement et tout autre travail mécanique ou de support qui ne nécessite pas de conseils de conception back-end. Ne pas utiliser pour des corrections de bugs localisés lorsque la cause et l'emplacement de la modification sont déjà connus, même lorsque le code affecté fait partie d'un SDK ou d'un composant backend.
