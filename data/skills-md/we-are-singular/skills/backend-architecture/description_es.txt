Úselo al escribir, revisar o refactorizar aplicaciones backend TypeScript/Node.js o código API donde la guía de diseño backend sea útil, incluidas API, rutas, controladores, middleware, SDK, servicios, repositorios, acceso a bases de datos, trabajadores en tiempo de ejecución e integraciones externas que implementan el comportamiento backend. No lo use simplemente porque el código se ejecuta en Node.js o en un servidor. Omita la configuración de CI/flujo de trabajo, scripts de implementación o mantenimiento, demostraciones, pruebas, cambios de nombre simples, formateo, trabajo de solo documentación y otros trabajos mecánicos o de soporte que no requieran guía de diseño de backend. No lo utilice para correcciones de errores localizados cuando la causa y la ubicación de la edición ya se conocen, incluso cuando el código afectado sea parte de un SDK o un componente de backend.
