Wird beim Schreiben, Überprüfen oder Refactoring von TypeScript/Node.js-Backend-Anwendungs- oder API-Code verwendet, bei dem eine Anleitung zum Backend-Design hilfreich ist, einschließlich APIs, Routen, Controller, Middleware, SDKs, Dienste, Repositorys, Datenbankzugriff, Laufzeit-Worker und externe Integrationen, die Backend-Verhalten implementieren. Verwenden Sie es nicht nur, weil der Code in Node.js oder auf einem Server ausgeführt wird. Überspringen Sie CI-/Workflow-Konfiguration, Bereitstellungs- oder Wartungsskripte, Demos, Tests, einfache Umbenennungen, Formatierungen, reine Dokumentationsarbeiten und andere mechanische oder unterstützende Arbeiten, die keine Anleitung zum Backend-Design erfordern. Nicht für lokalisierte Fehlerbehebungen verwenden, wenn die Ursache und der Bearbeitungsort bereits bekannt sind, auch wenn der betroffene Code Teil eines SDK oder einer Backend-Komponente ist.
