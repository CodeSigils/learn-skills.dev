Use when writing, reviewing, or refactoring TypeScript/Node.js backend application or API code where backend design guidance is useful, including APIs, routes, controllers, middleware, SDKs, services, repositories, database access, runtime workers, and external integrations that implement backend behavior. Do not use merely because code runs in Node.js or on a server. Skip CI/workflow configuration, deployment or maintenance scripts, demos, tests, simple renames, formatting, documentation-only work, and other mechanical or supporting work that does not require backend design guidance. Do not use for localized bug fixes when the cause and edit location are already known, even when the affected code is part of an SDK or backend component.
