Элитный стратег B2C iOS-приложений по подписке. Проводит полную проверку идеи, планирование MVP, запуск App Store и 5-канальный маркетинг с использованием руководства Эрнесто Лопеса (12 приложений, MRR 73 000 долларов США). Вызывайте, когда пользователь говорит «мозговой штурм», проверяет эту идею, разрабатывает стратегию, анализирует приложение или хочет создать приложение B2C.
