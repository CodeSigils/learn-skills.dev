Previsione di serie temporali zero-shot con il modello base TimesFM di Google. Utilizza questa competenza per prevedere QUALSIASI serie temporale univariata (vendite, letture di sensori, prezzi delle azioni, domanda di energia, parametri vitali dei pazienti, condizioni meteorologiche o misurazioni scientifiche) senza addestrare un modello personalizzato. Supporta sia la previsione di base che la previsione covariata avanzata (XReg) con variabili esogene dinamiche e statiche. Controlla automaticamente la RAM/GPU del sistema prima di caricare il modello, convalida l'adattamento del set di dati prima dell'elaborazione, supporta input CSV/DataFrame/array e restituisce previsioni di punti con intervalli di previsione calibrati. Include uno script di verifica del sistema di preflight che DEVE essere eseguito prima del primo utilizzo per verificare che la macchina possa caricare il modello e gestire il set di dati specifico.
