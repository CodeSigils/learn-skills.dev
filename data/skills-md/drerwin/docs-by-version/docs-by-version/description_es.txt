Utilice esta habilidad siempre que un usuario solicite organizar, dividir, migrar, auditar o mantener documentos de proyecto por versión o hito; quiere que los requisitos y el estado de finalización estén separados; solicita un índice conciso de la versión docs/README.md; o menciona 按版本、按里程碑、需求文档、完成情况、开发计划、文档整理. Úselo también cuando decida si un documento adicional pertenece a docs/ o a un directorio docs/versions/vX.Y.Z/ específico.
