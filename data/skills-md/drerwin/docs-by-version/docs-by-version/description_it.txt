Utilizza questa competenza ogni volta che un utente chiede di organizzare, dividere, migrare, controllare o mantenere i documenti di progetto per versione o attività cardine; vuole che i requisiti e lo stato di completamento siano separati; richiede un indice conciso della versione docs/README.md; o menziona 按版本、按里程碑、需求文档、完成情况、开发计划、文档整理. Usalo anche quando decidi se un documento aggiuntivo appartiene a docs/ o a una specifica directory docs/versions/vX.Y.Z/.
