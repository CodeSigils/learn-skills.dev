Шаг 2 конвейера hyperresearch V8. Мульти‑перспективное планирование поиска (ширина / глубина / враждебные линзы) с последующими параллельными волнами извлечения. Обеспечивает всестороннее тематическое покрытие с 40–100 отобранными источниками для полного уровня. Включает проверку охвата, аудит избыточности доказательств и контроль количества источников. Вызывается через инструмент Skill из входного навыка после завершения шага 1.
