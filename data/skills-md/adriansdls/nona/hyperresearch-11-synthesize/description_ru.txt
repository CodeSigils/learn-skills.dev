Шаг 11 конвейера гиперисследований V8. Считывает 3 черновика с конкретным ракурсом из шага 10, выборочно проверяет фактические конфликты, пишет план синтеза + схему, затем создает ОДИН субагент гиперисследования-синтезатора (с блокировкой инструмента «Чтение + запись»), который пишет окончательный отчет за ДВА прохода — проход 1 черновой интегрированный черновик, проход 2 — очистка голоса/избыточности/длины. Пропущено для легкого уровня (который записывает один черновик непосредственно на шаге 10). Вызывается с помощью инструмента «Навык» из начального навыка (полный уровень).
