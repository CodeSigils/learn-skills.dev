Créez des interfaces utilisateur cohérentes de style Frappe à l'aide de la bibliothèque de composants frappe-ui Vue 3 et de ses jetons de conception. À utiliser lors de l'échafaudage de pages, de formulaires, de boîtes de dialogue, de listes ou de toute interface utilisateur dans une application basée sur Frappe, lorsque l'utilisateur mentionne le style frappe-ui, Frappe Cloud / Gameplan / Desk / Drive / Insights, ou demande d'« utiliser les composants frappe-ui ».
