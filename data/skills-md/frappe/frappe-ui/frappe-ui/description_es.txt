Cree interfaces de usuario consistentes estilo Frappe utilizando la biblioteca de componentes frappe-ui Vue 3 y sus tokens de diseño. Úselo cuando cree páginas, formularios, cuadros de diálogo, listas o cualquier interfaz de usuario dentro de una aplicación basada en Frappe, cuando el usuario mencione el estilo frappe-ui, Frappe Cloud/Gameplan/Desk/Drive/Insights, o solicite "usar componentes de frappe-ui".
