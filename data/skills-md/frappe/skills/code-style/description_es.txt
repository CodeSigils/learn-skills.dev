Reglas de estilo de código para una implementación legible y mantenible. Cargue esta habilidad siempre cuando escriba o edite código, y siempre que el usuario pregunte sobre el estilo del código, la forma de refactorización, el tamaño de la función/archivo, la estructura orientada a objetos, el orden de los asistentes o los comentarios. Para trabajos específicos de Frappe, prefiera frappe-app-dev.
