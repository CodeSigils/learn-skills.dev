Qiantu (58pic) Интерфейс командной строки открытой платформы AI: поиск активов, каталог, список моделей, загрузка информации по PID, выполнение задач сопоставления. Используйте, когда пользователь упоминает поиск Qiantu/58pic, сопоставление, PID или загрузку ресурсов; при первом использовании необходимо заполнить ключ конфигурации/API. Если ключ API отсутствует, направьте пользователя на страницу открытой платформы Qiantu AI, чтобы получить его.
