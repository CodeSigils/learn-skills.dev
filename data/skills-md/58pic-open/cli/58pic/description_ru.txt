QianTu (58pic) Интерфейс командной строки открытой платформы AI: поиск материалов, каталог, список моделей, загрузка информации по PID и создание соответствующих задач. Используйте, когда пользователь упоминает поиск QianTu/58pic, сопоставление, PID или загрузку материала; При первом использовании необходимо заполнить ключ конфигурации/API. Если ключ API отсутствует, направьте пользователя на страницу открытой платформы QianTu AI, чтобы получить его.
