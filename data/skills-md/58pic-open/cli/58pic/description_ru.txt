QianTu (58pic) Интерфейс командной строки открытой платформы AI: поиск активов, каталог, список моделей, информация о загрузке по pid, задачи в том же стиле. Используйте, когда пользователи упоминают поиск QianTu/58pic, тот же стиль, PID или загрузку ресурсов; при первом использовании необходимо заполнить ключ config/API. Если ключ API отсутствует, направьте пользователей на страницу открытой платформы QianTu AI, чтобы получить его.
