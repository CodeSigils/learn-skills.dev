Capture un "camino dorado" ganado con tanto esfuerzo desde la sesión actual como una habilidad de agente reutilizable, para que las sesiones futuras comiencen a conocerla. Úselo (1) inmediatamente después de una depuración no trivial, después de elaborar un flujo de trabajo operativo de varios pasos o después de redescubrir datos del proyecto que no conocía desde el principio, p. cómo llegar a la base de datos de desarrollo/producción, dónde se encuentran las credenciales y las variables de entorno, cómo implementar, ejecutar migraciones o verificar un cambio en vivo; y (2) cada vez que el usuario diga "recuerda esto", "guarda esto como una habilidad", "crea una habilidad para esto", "no me obligues a volver a explicar esto la próxima vez" o quiere conservar un flujo de trabajo en todas las sesiones. Reconozca el momento de forma proactiva incluso cuando no se le solicite: si una tarea requirió varios intentos antes de funcionar, utilizó herramientas no obvias o es probable que se repita, coseche sin preguntar primero. Delega a un subagente cuando su herramienta admite uno, o funciona en línea, para extraer el procedimiento probado en una nueva habilidad local o global del proyecto.
