Erfassen Sie einen hart erkämpften „goldenen Pfad“ aus der aktuellen Sitzung als wiederverwendbare Agentenfähigkeit, damit zukünftige Sitzungen ihn bereits kennen. Verwenden Sie es (1) direkt nach einem nicht trivialen Debugging, nach der Ausarbeitung eines mehrstufigen betrieblichen Arbeitsablaufs oder nachdem Sie Projektfakten wiederentdeckt haben, die Sie vorher nicht kannten – z. B. wie man auf die Dev/Prod-Datenbank zugreift, wo Anmeldeinformationen und Umgebungsvariablen gespeichert sind, wie man sie bereitstellt, Migrationen durchführt oder eine Änderung live überprüft; und (2) wann immer der Benutzer sagt: „Merken Sie sich das“, „Speichern Sie dies als Fertigkeit“, „Erstellen Sie eine Fertigkeit dafür“, „Lassen Sie mich das nächste Mal nicht noch einmal erklären“ oder möchte auf andere Weise, dass ein Workflow über Sitzungen hinweg beibehalten wird. Erkennen Sie proaktiv den Moment, auch wenn Sie dazu nicht aufgefordert werden: Wenn eine Aufgabe mehrere Versuche erforderte, bevor sie funktionierte, nicht offensichtliche Tools verwendet wurden oder wahrscheinlich erneut auftritt, erledigen Sie sie, ohne vorher zu fragen. Delegiert an einen Subagenten, wenn Ihr Tool einen unterstützt, oder arbeitet inline, um das bewährte Verfahren in einen neuen projektlokalen oder globalen Skill zu extrahieren.
