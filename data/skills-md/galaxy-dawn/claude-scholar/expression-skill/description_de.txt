Diese Fähigkeit sollte verwendet werden, wenn der Benutzer eine effiziente Kommunikation, Aufgabenberichte, Zusammenfassungen von Dateivorgängen, Forschungsdiskussionen, Synthese von Studiennotizen, Planung, das Verfassen von Feedback oder Antworten wünscht, die eine schlussfolgernde Struktur, konkrete Beweise, die Offenlegung von Risiken und nützliche nächste Schritte erfordern.
