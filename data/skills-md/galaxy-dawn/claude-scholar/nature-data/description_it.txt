Preparare, verificare o rivedere le dichiarazioni sulla disponibilità dei dati Nature-ready, i piani di archiviazione dei dati, le citazioni dei set di dati e le liste di controllo dei metadati FAIR per i manoscritti. Da utilizzare quando l'utente richiede informazioni sulla disponibilità dei dati Nature, sulla condivisione dei dati di ricerca, sulla selezione dell'archivio, sui numeri di accesso, sui dati riservati o sensibili, sui dati di origine, sui set di dati supplementari, sui riferimenti ai set di dati in stile DataCite, sui metadati FAIR per la pubblicazione accademica o sulla disponibilità dei dati dal cinese all'inglese per autori di lingua cinese che preparano contributi per la famiglia Nature.
