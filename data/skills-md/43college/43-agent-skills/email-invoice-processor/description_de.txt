E-Mail-Rechnungsprozessor. Filtern Sie Rechnungs-E-Mails aus dem Postfach nach Datumsbereich, laden Sie PDF-/Bildanhänge (einschließlich verknüpfter Downloads) herunter, extrahieren Sie Rechnungsfelder und erstellen Sie eine Excel-Zusammenfassung mit separaten Blättern für jeden Käufer. Verwenden Sie diese Fähigkeit, wenn Benutzer Rechnungen verarbeiten, Rechnungen organisieren oder Rechnungen aus dem Postfach extrahieren müssen.
