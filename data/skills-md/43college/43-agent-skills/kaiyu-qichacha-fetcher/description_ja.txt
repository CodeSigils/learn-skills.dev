Qichacha OpenAPI を使用して、中国企業の事業登録、株主、司法、運営、知的財産、入札、世論、その他のデータをクエリします。ユーザーが「XX 会社を検索」、「XX の事業登録 / 株主 / 訴訟 / 強制執行 / 商標または特許 / 運営上の異常を確認」、「XX はダミー会社ですか」、「XX の法定代理人は誰ですか」、「XX の登録資本金はいくらですか」、「Qichacha を検索」、「企業を検索」、またはその他の企業情報のクエリを言うとき、このスキルを使用します。 45 の商用インターフェイスが登録されています (ユーザーは Qichacha バックエンドで個別にアクティベーションを申請する必要があります)。依存性のない純粋な Python、クロスプラットフォーム Mac/Windows/Linux。
