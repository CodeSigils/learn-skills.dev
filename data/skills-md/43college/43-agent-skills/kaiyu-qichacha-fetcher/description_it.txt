Utilizza Qichacha OpenAPI per interrogare la registrazione delle imprese, gli azionisti, i dati giudiziari, operativi, la proprietà intellettuale, le offerte, l'opinione pubblica e altri dati delle società cinesi. Quando un utente dice "cerca la società XX", "controlla la registrazione aziendale di XX/gli azionisti/eventuali cause legali/qualsiasi azione di applicazione/qualsiasi marchio o brevetto/qualsiasi anomalia operativa", "XX è una società di comodo", "chi è il rappresentante legale di XX", "qual è il capitale registrato di XX", "cerca Qichacha", "cerca impresa" o qualsiasi altra domanda di informazioni aziendali, utilizza questa abilità. Sono state registrate quarantacinque interfacce commerciali (gli utenti devono richiedere l'attivazione individualmente nel backend Qichacha). Python puro a dipendenza zero, multipiattaforma Mac/Windows/Linux.
