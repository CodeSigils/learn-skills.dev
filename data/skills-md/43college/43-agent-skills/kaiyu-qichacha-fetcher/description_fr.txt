Utilisez Qichacha OpenAPI pour interroger l'enregistrement des entreprises chinoises, les actionnaires, les données judiciaires, opérationnelles, de propriété intellectuelle, les appels d'offres, l'opinion publique et d'autres données. Lorsqu'un utilisateur dit « rechercher la société XX », « vérifier l'enregistrement de l'entreprise/les actionnaires/les éventuelles poursuites/les éventuelles mesures coercitives/les marques ou brevets/toutes anomalies opérationnelles de XX », « XX est-il une société écran », « qui est le représentant légal de XX », « quel est le capital social de XX », « rechercher Qichacha », « rechercher une entreprise » ou toute autre requête d'informations sur l'entreprise, utilisez cette compétence. Quarante-cinq interfaces commerciales ont été enregistrées (les utilisateurs doivent demander l'activation individuellement dans le backend Qichacha). Python pur sans dépendance, multiplateforme Mac/Windows/Linux.
