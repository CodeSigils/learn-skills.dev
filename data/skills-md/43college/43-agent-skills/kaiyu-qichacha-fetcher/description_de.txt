Verwenden Sie die Qichacha OpenAPI, um Unternehmensregistrierungs-, Aktionärs-, Justiz-, Betriebs-, geistiges Eigentums-, Ausschreibungs-, öffentliche Meinungs- und andere Daten chinesischer Unternehmen abzufragen. Wenn ein Benutzer sagt: „Suche nach Unternehmen XX“, „Überprüfen Sie die Unternehmensregistrierung/Aktionäre/alle Klagen/Durchsetzungsmaßnahmen/Marken oder Patente/Betriebsanomalien von XX“, „Ist XX eine Briefkastenfirma“, „Wer ist der gesetzliche Vertreter von XX“, „Wie hoch ist das eingetragene Kapital von XX“, „Suche nach Qichacha“, „Suche nach Unternehmen“ oder eine andere Abfrage zu Unternehmensinformationen, verwenden Sie diese Fähigkeit. Es wurden 45 kommerzielle Schnittstellen registriert (Benutzer müssen die Aktivierung einzeln im Qichacha-Backend beantragen). Reines Python ohne Abhängigkeit, plattformübergreifend für Mac/Windows/Linux.
