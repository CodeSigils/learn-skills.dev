Conventions de couche de données complètes pour les projets qui utilisent Prisma + Zod + TanStack Query, les actions du serveur, la validation de schéma, les usines de requêtes, les hooks, les récupérateurs, les routes API et les fonctions de serveur TanStack Start. Indépendant du framework ; fonctionne avec Next.js (App ou Pages Router), TanStack Start (REST ou RPC), Remix, Hono, Express. À utiliser lors de la création de fonctionnalités de domaine, de l'ajout de points de terminaison, de la modification du schéma Prisma, de l'écriture de hooks/requêtes ou de la révision du code de la couche de données, ou lors du démarrage de ces conventions dans un projet qui ne les suit pas encore.
