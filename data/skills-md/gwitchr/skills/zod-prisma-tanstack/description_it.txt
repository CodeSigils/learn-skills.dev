Convenzioni del livello dati full-stack per progetti che utilizzano Prisma + Zod + TanStack Query, azioni server, convalida dello schema, query factory, hook, fetcher, percorsi API e funzioni TanStack Start Server. Indipendente dal contesto; funziona con Next.js (App o Pages Router), TanStack Start (REST o RPC), Remix, Hono, Express. Da utilizzare durante la creazione di funzionalità di dominio, l'aggiunta di endpoint, la modifica dello schema Prisma, la scrittura di hook/query o la revisione del codice del livello dati o durante il bootstrap di queste convenzioni in un progetto che non le segue ancora.
