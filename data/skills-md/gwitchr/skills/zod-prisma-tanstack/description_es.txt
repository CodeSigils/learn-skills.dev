Convenciones de capa de datos de pila completa para proyectos que utilizan Prisma + Zod + TanStack Query, acciones de servidor, validación de esquemas, fábricas de consultas, enlaces, recuperadores, rutas API y funciones de inicio de servidor TanStack. Agnóstico del marco; funciona con Next.js (aplicación o enrutador de páginas), TanStack Start (REST o RPC), Remix, Hono, Express. Úselo al crear características de dominio, agregar puntos finales, modificar el esquema de Prisma, escribir enlaces/consultas o revisar el código de la capa de datos, o al iniciar estas convenciones en un proyecto que aún no las sigue.
