Prisma + Zod + TanStack クエリ、サーバー アクション、スキーマ検証、クエリ ファクトリ、フック、フェッチャー、API ルート、および TanStack Start サーバー関数を使用するプロジェクトのフルスタック データレイヤー規則。フレームワークに依存しない。 Next.js (アプリまたはページルーター)、TanStack Start (REST または RPC)、Remix、Hono、Express で動作します。ドメイン機能の作成、エンドポイントの追加、Prisma スキーマの変更、フック/クエリの作成、またはデータ層コードのレビューを行う場合、またはまだ準拠していないプロジェクトでこれらの規約をブートストラップする場合に使用します。
