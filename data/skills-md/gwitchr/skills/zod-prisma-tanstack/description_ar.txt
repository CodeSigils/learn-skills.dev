اصطلاحات طبقة البيانات الكاملة للمشروعات التي تستخدم استعلام Prisma + Zod + TanStack، وإجراءات الخادم، والتحقق من صحة المخطط، ومصانع الاستعلام، والخطافات، وأجهزة الجلب، ومسارات واجهة برمجة التطبيقات، ووظائف خادم TanStack Start Server. الإطار الملحد. يعمل مع Next.js (جهاز توجيه التطبيق أو الصفحات)، وTanStack Start (REST أو RPC)، وRemix، وHono، وExpress. يُستخدم عند إنشاء ميزات المجال، أو إضافة نقاط النهاية، أو تعديل مخطط Prisma، أو كتابة الخطافات/الاستعلامات، أو مراجعة كود طبقة البيانات، أو عند تمهيد هذه الاصطلاحات في مشروع لا يتبعها بعد.
