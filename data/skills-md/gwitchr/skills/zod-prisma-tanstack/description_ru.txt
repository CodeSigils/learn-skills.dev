Полнофункциональные соглашения об уровне данных для проектов, использующих запросы Prisma + Zod + TanStack, действия сервера, проверку схемы, фабрики запросов, перехватчики, сборщики, маршруты API и функции запуска сервера TanStack. Независимость от фреймворка; работает с Next.js (App или Pages Router), TanStack Start (REST или RPC), Remix, Hono, Express. Используйте при создании функций предметной области, добавлении конечных точек, изменении схемы Prisma, написании перехватчиков/запросов или проверке кода уровня данных, а также при начальной загрузке этих соглашений в проекте, который им еще не соответствует.
