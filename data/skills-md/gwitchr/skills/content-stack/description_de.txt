Datenbankgestützter Inhalt + i18n-Stack, Prisma-Modelle „ContentPage“ / „ContentString“ auf MongoDB, Enumeration „StringRole“, eingebetteter Typ „Languages“, ein öffentlicher „getPageStrings“-Server-FN, der für immer in TanStack Query zwischengespeichert wird, ein „useTranslation(pageSlug)“-Hook, der durch „(Fallback, Rolle, Abschnitt)“ aufgelöst wird, speichergesteuert aktiv Gebietsschema (Redux / Zustand / etc.), ein Opt-in-Gebietsschema-Umschalter, ein „Seed-Translations“-Skript als Quelle der Wahrheit und ein geschlossener Admin-Editor für Live-Patches. Verwenden Sie diese Option, wenn Sie eine Kopie auf einer Seite hinzufügen/bearbeiten, „useTranslation“ mit einer neuen Route verbinden, eine neue Inhaltsseite hinzufügen, eine neue Sprache aktivieren, „StringRole“ ändern, „Sprachen“ berühren, eine benutzerspezifische Gebietsschemaeinstellung beibehalten oder an der Admin-Benutzeroberfläche für Übersetzungen arbeiten.
