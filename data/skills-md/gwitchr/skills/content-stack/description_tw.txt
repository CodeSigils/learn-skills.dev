以資料庫為後端的內容 + i18n 架構，MongoDB 上的 `ContentPage` / `ContentString` Prisma 模型，`StringRole` 列舉，`Languages` 嵌入型別，一個公開的 `getPageStrings` 伺服器函式，於 TanStack Query 中永久快取，一個 `useTranslation(pageSlug)` Hook，根據 `(fallback, role, section)` 解析，依賴 store 驅動的當前語系（Redux / Zustand 等），選擇性啟用的語系切換器，一個作為唯一真相的 `seed-translations` 腳本，以及一個受限制的管理員編輯器用於即時修補。當在頁面上新增/編輯文案、將 `useTranslation` 串接至新路由、添加新內容頁面、啟用新語言、變更 `StringRole`、觸碰 `Languages`、持久化使用者的語系偏好，或是開發翻譯管理 UI 時使用。
