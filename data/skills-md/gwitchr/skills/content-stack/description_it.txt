Contenuti supportati da database + stack i18n, modelli Prisma `ContentPage` / `ContentString` su MongoDB, enum `StringRole`, tipo incorporato `Languages`, un server pubblico `getPageStrings` memorizzato nella cache per sempre in TanStack Query, un hook `useTranslation(pageSlug)` risolto da `(fallback, role,section)`, locale attivo gestito dal negozio (Redux / Zustand / ecc.), un commutatore di localizzazione opzionale, uno script `seed-translations` come fonte di verità e un editor di amministrazione recintato per patch live. Da utilizzare quando si aggiunge/modifica una copia su una pagina, si collega "useTranslation" a un nuovo percorso, si aggiunge una nuova pagina di contenuto, si abilita una nuova lingua, si cambia "StringRole", si tocca "Languages", si mantiene una preferenza locale per utente o si lavora sull'interfaccia utente di amministrazione delle traduzioni.
