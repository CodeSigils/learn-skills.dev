Содержимое, поддерживаемое базой данных + стек i18n, модели Prisma ContentPage/ContentString в MongoDB, перечисление StringRole, встроенный тип Languages, общедоступный сервер getPageStrings, вечно кэшируемый в запросе TanStack, перехват useTranslation(pageSlug), разрешающий с помощью (резервный вариант, роль, раздел), активная локаль, управляемая хранилищем (Redux / Zustand / и т. д.), переключатель локали по выбору, сценарий `seed-translations` в качестве источника истины и закрытый административный редактор для живых патчей. Используйте при добавлении/редактировании копии на странице, подключении useTranslation к новому маршруту, добавлении новой страницы контента, включении нового языка, изменении StringRole, касании языков, сохранении предпочтений языкового стандарта для каждого пользователя или работе над пользовательским интерфейсом администратора переводов.
