Autenticazione + e-mail transazionale + archiviazione di risorse su uno stack Mongo, autenticazione migliore (collegamento magico, token con hash a riposo) su Prisma + MongoDB, AWS SES per la consegna, AWS S3 + CloudFront per risorse, ambiente server convalidato da zod e un singolo contratto di fallback IAM per i client AWS. Da utilizzare quando si toccano i flussi di accesso/registrazione, il percorso catch-all di autenticazione, la configurazione "auth", il recupero della sessione, le e-mail magic-link, i modelli Prisma "Utente"/"Sessione"/"Account"/"Verifica", campi utente aggiuntivi ("ruolo", "preferredLocale" e così via), mittenti e-mail SES, caricamenti S3, reindirizzamenti post-autenticazione o estensione dello schema di autenticazione.
