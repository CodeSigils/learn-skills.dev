Аутентификация + транзакционная электронная почта + хранилище активов в стеке Mongo, Better Auth (magic-link, хешированный токен в состоянии покоя) на Prisma + MongoDB, AWS SES для доставки, AWS S3 + CloudFront для активов, проверенная zod серверная среда и единый резервный контракт IAM для клиентов AWS. Используйте при работе с потоками входа/регистрации, комплексным маршрутом аутентификации, конфигурацией аутентификации, извлечением сеанса, электронными письмами с магическими ссылками, моделями Prisma `Пользователь`/`Сессия`/`Учётная запись`/`Верификация`, дополнительными пользовательскими полями (`роль`, ``preferredLocale` и т. д.), отправителями электронной почты SES, загрузками S3, перенаправлениями после аутентификации или расширением схемы аутентификации.
