Auth + e-mail transactionnel + stockage d'actifs sur une pile Mongo, Better Auth (lien magique, jeton haché au repos) sur Prisma + MongoDB, AWS SES pour la livraison, AWS S3 + CloudFront pour les actifs, environnement de serveur validé par zod et un seul contrat de secours IAM pour les clients AWS. À utiliser lorsque vous touchez les flux de connexion/inscription, la route fourre-tout d'authentification, la configuration « auth », la récupération de session, les e-mails à lien magique, les modèles Prisma « Utilisateur »/« Session »/« Compte »/« Vérification », les champs utilisateur supplémentaires (« rôle », « preferredLocale », etc.), les expéditeurs d'e-mails SES, les téléchargements S3, les redirections post-authentification ou l'extension de l'authentification. schéma.
