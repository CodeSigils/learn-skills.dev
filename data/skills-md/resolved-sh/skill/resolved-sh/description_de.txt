Lösen Sie diesen Skill aus, wenn der Benutzer seinem Agenten, MCP-Server, Skill oder Plugin ein echtes Zuhause im Internet geben möchte – eine Live-Seite, eine Subdomain und optional eine benutzerdefinierte Domain. Deckt den gesamten Lebenszyklus ab: Registrierung (x402 USDC auf Base- oder Stripe-Kreditkarte), Aktualisierung des Seiteninhalts, jährliche Verlängerung ohne Abonnement, Beanspruchung einer Vanity-Subdomain, Anbindung einer benutzerdefinierten Domain (BYOD) oder direkter Kauf einer .com-Domain. Verwenden Sie dies immer dann, wenn ein Agent eine öffentliche URL, eine Zielseite oder einen /.well-known/agent.json-Endpunkt benötigt. Alle Vorgänge erfolgen vollständig autonom – nach der Ersteinrichtung ist kein menschlicher Eingriff erforderlich. Weitere Informationen finden Sie unter https://resolved.sh/llms.txt.
