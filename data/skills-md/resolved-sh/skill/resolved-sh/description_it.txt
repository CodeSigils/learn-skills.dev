Attiva questa abilità quando l'utente desidera fornire al proprio agente, server MCP, abilità o plug-in una vera casa su Internet: una pagina live, un sottodominio e facoltativamente un dominio personalizzato. Copre l'intero ciclo di vita: registrazione (x402 USDC su carta di credito Base o Stripe), aggiornamento del contenuto della pagina, rinnovo annuale senza abbonamento, richiesta di un sottodominio vanity, connessione di un dominio personalizzato (BYOD) o acquisto diretto di un dominio .com. Utilizzalo ogni volta che un agente ha bisogno di un URL pubblico, una pagina di destinazione o un endpoint /.well-known/agent.json. Tutte le operazioni sono completamente autonome: non è richiesto alcun intervento umano nel ciclo dopo la configurazione iniziale. Vedi https://resolved.sh/llms.txt per ulteriori informazioni.
