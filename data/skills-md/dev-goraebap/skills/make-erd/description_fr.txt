Reçoit le PRD, les descriptions de domaine, les listes de tables, etc. et génère un ERD (Entity-Relationship Diagram) sous forme de fichier Mermaid `.mmd`. Prend en charge les trois types d'ERD (conceptuels, logiques et physiques) et les affiche dans un thème sombre + un style dessiné à la main. Déclenché par des requêtes telles que « Créer un ERD », « diagramme de relations de table », « visualisation de conception de base de données », « diagramme de relations d'entités », « modélisation de données », « ERD conceptuel », « ERD logique », « ERD physique », « sirène ERD », « dessiner un schéma de base de données », « conception de table », etc.
