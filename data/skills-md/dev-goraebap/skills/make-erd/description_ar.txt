يتلقى مدخلات مثل قائمة جدول وصف المجال PRD ويقوم بإنشاء ERD (مخطط علاقة الكيان) كملف حورية البحر `.mmd`. يدعم جميع الأنواع الثلاثة — ERDs المفاهيمية والمنطقية والمادية — ويخرجها بمظهر داكن + نمط مرسوم يدويًا. يتم تشغيلها بواسطة طلبات مثل "إنشاء ERD" و"مخطط علاقة الجدول" و"تصور تصميم قاعدة البيانات" و"مخطط علاقة الكيان" و"نمذجة البيانات" و"ERD المفاهيمي" و"ERD المنطقي" و"ERD الفعلي" و"mermaid ERD" و"رسم مخطط قاعدة البيانات" و"تصميم الجدول" وما إلى ذلك.
