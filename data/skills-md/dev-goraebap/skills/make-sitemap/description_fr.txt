Reçoit le PRD, les documents de planification, les exigences, etc., et génère un plan du site (schéma de structure d'écran) sous forme de fichier Mermaid `.mmd`. Il visualise la hiérarchie depuis le menu principal → sous-menu → écran fonctionnel dans une structure basée sur un organigramme et génère un thème sombre + un style handDrawn. Déclenché par des requêtes telles que « créer un plan du site », « diagramme de structure d'écran », « conception IA », « structure de menu », « structure de page », « organigramme d'écran », « conception de navigation », « plan du site », « architecture de l'information ».
