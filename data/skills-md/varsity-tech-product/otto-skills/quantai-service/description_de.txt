Quantitativer Krypto-Einfaktor-Forschungsdienst Skill. Laden Sie diesen Skill, wenn der Benutzer „Faktor schreiben“, „Faktor erforschen“, „Arbeit quantifizieren“, „Faktor einreichen“ oder „Faktor-Backtest“ sagt. Der Agent ist für das Schreiben des Faktor-Plugin-Codes und die Interaktion mit dem Server über HTTP verantwortlich; Der Server übernimmt die gesamte Datenverarbeitung und -berechnung und der Agent benötigt keine lokalen Marktdaten.
