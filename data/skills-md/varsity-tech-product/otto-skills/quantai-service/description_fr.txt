Compétence de service de recherche quantitative cryptographique à facteur unique. Lorsque l'utilisateur dit « écrire un facteur », « facteur de recherche », « quant grind », « soumettre un facteur » ou « backtest de facteur », cette compétence est chargée. L'agent est responsable de l'écriture du code du plugin Factor et interagit avec le serveur via HTTP ; le serveur gère tous les traitements et calculs des données, l'agent n'a donc pas besoin de données de marché local.
