Crea un adattatore Kitaru locale del progetto per un framework di agenti Python o TypeScript non supportato. Da utilizzare quando un utente desidera registrare o riprodurre le esecuzioni dell'agente nativo del framework in Kitaru, ha bisogno di un adattatore personalizzato, non ha un'integrazione Kitaru supportata per il proprio framework o deve valutare se gli hook del framework pubblico e l'SDK Kitaru installato possono supportare un adattatore.
