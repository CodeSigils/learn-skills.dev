Converti backlog di attività a file singolo (formato TASKS.md) nella struttura delle specifiche multi-file di AutoClaude. Utilizzare quando l'utente desidera (1) convertire TASKS.md esistenti o file di backlog di attività simili in specifiche AutoClaude, (2) inizializzare un nuovo progetto con una struttura di attività compatibile con AutoClaude, (3) migrare le definizioni di attività dal semplice markdown al formato di specifica multi-file con requisiti.json, contesto.json, implementazione_plan.json. Si attiva su frasi come "convertire attività in AutoClaude", "impostare le specifiche AutoClaude", "migrare il backlog", "creare specifiche dall'attività".
