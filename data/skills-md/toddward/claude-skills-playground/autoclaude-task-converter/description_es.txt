Convierta trabajos pendientes de tareas de un solo archivo (formato TASKS.md) a una estructura de especificaciones de varios archivos de AutoClaude. Úselo cuando el usuario desee (1) convertir TASKS.md existentes o archivos de tareas pendientes similares a especificaciones de AutoClaude, (2) inicializar un nuevo proyecto con una estructura de tareas compatible con AutoClaude, (3) migrar definiciones de tareas de rebajas simples al formato de especificaciones de múltiples archivos con requisitos.json, contexto.json, implementación_plan.json. Activadores de frases como "convertir tareas a AutoClaude", "configurar especificaciones de AutoClaude", "migrar trabajos pendientes", "crear especificaciones a partir de la tarea".
