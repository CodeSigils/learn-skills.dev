Сквозное машинное обучение и навыки анализа глубокого обучения. Автоматически определяет типы данных, выбирает подходящие модели, выполняет анализ и предоставляет результаты. Используйте этот навык всякий раз, когда пользователь хочет: (1) анализировать данные с помощью методов ML/DL — классификация, регрессия, кластеризация, обнаружение аномалий, NLP, компьютерное зрение, временные ряды, (2) создавать или обучать модели на основе своих данных, (3) выполнять исследовательский анализ данных (EDA) со статистической строгостью, (4) использовать AutoML для поиска лучшей модели, (5) настраивать конвейеры ML или рабочие процессы MLOps, (6) оценивать, объяснять или проверять модель производительность, (7) Обработка или проектирование функций на основе необработанных данных. Запуск по таким ключевым словам, как прогнозирование, классификация, кластер, обучение, модель, регрессия, нейронная сеть, глубокое обучение, разработка функций, гиперпараметр, перекрестная проверка, SHAP, EDA, обнаружение аномалий, прогноз временных рядов, классификация изображений, классификация текста, NLP, AutoML, модель развертывания, конвейер машинного обучения.
