Habilidad de análisis de aprendizaje profundo y aprendizaje automático de un extremo a otro. Detecta automáticamente tipos de datos, selecciona modelos apropiados, ejecuta análisis y entrega resultados. Utilice esta habilidad siempre que el usuario desee: (1) Analizar datos con métodos ML/DL: clasificación, regresión, agrupamiento, detección de anomalías, PNL, visión por computadora, series temporales, (2) Construir o entrenar modelos a partir de sus datos, (3) Realizar análisis de datos exploratorios (EDA) con rigor estadístico, (4) Usar AutoML para encontrar el mejor modelo, (5) Configurar canalizaciones de ML o flujos de trabajo MLOps, (6) Evaluar, explicar o auditar el rendimiento del modelo, (7) Procese o diseñe características a partir de datos sin procesar. Active palabras clave como: predecir, clasificar, agrupar, entrenar, modelo, regresión, red neuronal, aprendizaje profundo, ingeniería de características, hiperparámetro, validación cruzada, SHAP, EDA, detección de anomalías, pronóstico de series temporales, clasificación de imágenes, clasificación de texto, PNL, AutoML, modelo de implementación, canalización de ML.
