Führen Sie eine systematische, mehrstufige und eingehende wissenschaftliche Begutachtung von Bachelorarbeiten durch. Folgen Sie dem fünfstufigen Prozess „Volltextverständnis → Strukturüberprüfung → Verfeinerung auf Absatzebene → Problemaggregation → Wiederholungsprüfung“, identifizieren Sie Absatztypen und leiten Sie sie an sechs wichtige Spezialregeln weiter (Einleitung, Literaturübersicht, Methodik, Analyse, Schlussfolgerung, Fakten) und geben Sie Strukturdiagnosen, Überarbeitungsvorschläge auf Absatzebene, Überarbeitungsaufgabenlisten und Wiederholungsprüfungsberichte aus. Wenn ein Benutzer eine Arbeit, eine Abschlussarbeit oder eine Dissertation bereitstellt und eine Überprüfung, Bewertung, Überarbeitungsvorschläge, ein Peer-Review oder eine Beurteilung anfordert, muss diese Funktion genutzt werden. Selbst wenn der Benutzer nur sagt „Helfen Sie mir, dieses Dokument anzuschauen“, „Überprüfen Sie es für mich“ oder „Geben Sie mir Vorschläge zur Überarbeitung“, sollte diese Funktion aktiviert werden. Die Überprüfung umfasst eine tiefgreifende theoretische Analyse: Identifizieren Sie die impliziten Prämissen des Papiers, lokalisieren Sie seine theoretischen Koordinaten, bewerten Sie die Positionierung des Papiers anhand mehrerer akademischer Rahmenbedingungen neu und übersetzen Sie theoretische Erkenntnisse in umsetzbare Überarbeitungsvorschläge. Wenn ein Benutzer eine Abschlussarbeit im .docx-Format bereitstellt und ein überprüftes Ergebnis mit Anmerkungen erhalten möchte, muss diese Funktion ebenfalls verwendet werden (in Verbindung mit dem docx-Tool zur Bearbeitung des Dokuments).
