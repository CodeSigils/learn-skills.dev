Führen Sie eine systematische, mehrstufige und eingehende wissenschaftliche Begutachtung von Bachelorarbeiten durch. Befolgen Sie einen fünfstufigen Prozess – „Volltextverständnis → Strukturinspektion → Prüfung auf Absatzebene → Problemzusammenfassung → Iteration der erneuten Überprüfung“ –, um Absatztypen zu identifizieren und sie an sechs spezielle Regelsätze weiterzuleiten (Einleitung, Literaturübersicht, Methodik, Analyse, Schlussfolgerung, Fakten), um Strukturdiagnosen, Überarbeitungsvorschläge auf Absatzebene, eine Überarbeitungsaufgabenliste und einen Bericht zur erneuten Überprüfung zu erstellen. Immer wenn ein Benutzer eine Arbeit, eine Abschlussarbeit oder eine Dissertation bereitstellt und eine Überprüfung, Bewertung, Überarbeitungsvorschläge, Peer-Review oder Bewertung anfordert, muss diese Funktion genutzt werden. Selbst wenn der Benutzer lediglich sagt „Helfen Sie mir, dieses Dokument anzuschauen“, „Rezensieren Sie es für mich“ oder „Geben Sie mir Überarbeitungsvorschläge“, sollte diese Funktion aktiviert werden. Die Überprüfung umfasst eine tiefgreifende theoretische Analyse: Identifizierung impliziter Prämissen, Lokalisierung theoretischer Koordinaten, Neubewertung der Positionierung des Papiers aus mehreren akademischen Rahmenwerken und Umwandlung theoretischer Erkenntnisse in umsetzbare Überarbeitungsempfehlungen. Wenn der Benutzer eine Dissertation im .docx-Format einreicht und ein kommentiertes Überprüfungsergebnis wünscht, muss diese Funktion ebenfalls genutzt werden (unter Verwendung des docx-Tools für Dokumentoperationen).
