Realizar una revisión académica sistemática, de múltiples rondas y en profundidad de las tesis de pregrado. Siga un proceso de cinco etapas: “comprensión del texto completo → inspección estructural → escrutinio a nivel de párrafo → agregación de temas → iteración de nueva revisión”—para identificar tipos de párrafos y dirigirlos a seis conjuntos de reglas especializadas (Introducción, Revisión de literatura, Metodología, Análisis, Conclusión, Hechos), produciendo diagnósticos estructurales, sugerencias de revisión a nivel de párrafo, una lista de tareas de revisión y un informe de nueva revisión. Siempre que un usuario proporciona un artículo, tesis o disertación y solicita revisión, evaluación, sugerencias de revisión, revisión por pares o valoración, se debe utilizar esta capacidad. Incluso si el usuario simplemente dice "ayúdame a ver este documento", "revísalo por mí" o "dame sugerencias de revisión", esta capacidad debería activarse. La revisión incluye un análisis teórico profundo: identificación de premisas implícitas, localización de coordenadas teóricas, reevaluación del posicionamiento del artículo desde múltiples marcos académicos y conversión de conocimientos teóricos en recomendaciones de revisión prácticas. Si el usuario proporciona una tesis en formato .docx y desea un resultado de revisión anotado, también se debe emplear esta capacidad (usando la herramienta docx para operaciones de documentos).
