Извлекайте текст из изображений с помощью API GLM-OCR. Поддерживает изображения и PDF-файлы с высокоточным распознаванием текста, распознаванием таблиц, извлечением формул и распознаванием рукописного текста. Используйте этот навык всякий раз, когда пользователь хочет извлечь текст из изображений, выполнить распознавание изображений на изображениях, отсканировать документы, преобразовать изображения в текст или обработать любые файлы изображений, чтобы получить их текстовое содержимое.
