Habilidad oficial para reconocer y extraer tablas de imágenes y archivos PDF en formato Markdown utilizando la API ZhiPu GLM-OCR. Admite tablas complejas, celdas combinadas y documentos de varias páginas. Utilice esta habilidad cuando el usuario quiera extraer tablas, reconocer hojas de cálculo o convertir imágenes de tablas a formato editable.
