Habilidad oficial para reconocer texto escrito a mano a partir de imágenes utilizando la API ZhiPu GLM-OCR. Admite varios estilos de escritura a mano, idiomas y contenido mixto escrito a mano/impreso. Utilice esta habilidad cuando el usuario quiera leer notas escritas a mano, convertir escritura a mano en texto o documentos escritos a mano con OCR.
