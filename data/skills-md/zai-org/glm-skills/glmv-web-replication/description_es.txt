Habilidad de replicación visual frontend. Explora las páginas públicamente visibles de un sitio web de destino a través de Playwright MCP o agente-navegador, captura capturas de pantalla e información de diseño, luego genera una réplica de interfaz estática o del lado del cliente que se aproxima a la apariencia visual y la estructura de la página del original. Esta habilidad replica SÓLO LA PRESENTACIÓN FRONTAL: no reproduce la lógica del backend, el comportamiento del lado del servidor, las bases de datos ni ningún contenido no público. El usuario es responsable de asegurarse de tener la autorización adecuada (propiedad, licencia o permiso explícito) antes de replicar cualquier sitio web.
⚠️ Puerta de autorización: antes de comenzar, el agente DEBE confirmar con el usuario que tiene el derecho legal de replicar el sitio de destino. Si el usuario no puede confirmar, la habilidad DEBE negarse a continuar.
