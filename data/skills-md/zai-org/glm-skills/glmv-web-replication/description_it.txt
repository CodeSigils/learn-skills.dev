Abilità di replica visiva del frontend. Esplora le pagine visibili pubblicamente di un sito Web di destinazione tramite Playwright MCP o browser agente, acquisisce screenshot e informazioni sul layout, quindi genera una replica frontend statica o lato client che si avvicina all'aspetto visivo e alla struttura della pagina dell'originale. Questa competenza replica SOLO LA PRESENTAZIONE FRONTEND: non riproduce la logica di backend, il comportamento lato server, i database o qualsiasi contenuto non pubblico. L'utente è responsabile di assicurarsi di disporre dell'autorizzazione adeguata (proprietà, licenza o autorizzazione esplicita) prima di replicare qualsiasi sito Web.
⚠️ Cancello di autorizzazione: prima di iniziare, l'agente DEVE confermare all'utente che ha il diritto legale di replicare il sito di destinazione. Se l'utente non può confermare, la competenza DEVE rifiutarsi di procedere.
