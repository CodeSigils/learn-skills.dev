Fähigkeit zur visuellen Frontend-Replikation. Erkundet die öffentlich sichtbaren Seiten einer Zielwebsite über Playwright MCP oder Agent-Browser, erfasst Screenshots und Layoutinformationen und generiert dann eine statische oder clientseitige Frontend-Replik, die dem visuellen Erscheinungsbild und der Seitenstruktur des Originals nahe kommt. Dieser Skill reproduziert NUR FRONTEND-PRÄSENTATION – er reproduziert keine Backend-Logik, serverseitiges Verhalten, Datenbanken oder andere nicht öffentliche Inhalte. Der Benutzer ist dafür verantwortlich, sicherzustellen, dass er über die entsprechende Autorisierung (Eigentum, Lizenz oder ausdrückliche Genehmigung) verfügt, bevor er eine Website repliziert.
⚠️ Autorisierungsgate: Vor dem Start MUSS der Agent dem Benutzer bestätigen, dass er das rechtliche Recht hat, die Zielsite zu replizieren. Wenn der Benutzer dies nicht bestätigen kann, MUSS der Skill die Fortsetzung verweigern.
