フロントエンドのビジュアルレプリケーションスキル。 Playwright MCP またはエージェント ブラウザを介してターゲット Web サイトの公開ページを探索し、スクリーンショットとレイアウト情報をキャプチャして、元の外観とページ構造に近似した静的またはクライアント側のフロントエンド レプリカを生成します。このスキルはフロントエンド プレゼンテーションのみを複製します。バックエンド ロジック、サーバー側の動作、データベース、または非公開コンテンツは複製しません。ユーザーは、Web サイトを複製する前に、適切な許可 (所有権、ライセンス、または明示的な許可) を持っていることを確認する責任があります。
⚠️ 認証ゲート: 開始する前に、エージェントはターゲット サイトを複製する法的権利があることをユーザーに確認する必要があります。ユーザーが確認できない場合、スキルは続行を拒否しなければなりません。
