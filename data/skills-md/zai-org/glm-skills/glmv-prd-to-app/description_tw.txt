從 PRD 文件、原型圖像和資源文件建立完整的、可投入生產的全端 Web 應用程式。處理整個管道：系統設計、資料庫模式、種子資料、後端 API、前端 UI、針對原型的視覺化驗證以及部署腳本產生。
每當使用者執行以下操作時，請使用此技能： - 提供 PRD（產品需求文件）並希望建立一個可用的應用程式 - 說「根據 PRD 開發」、「從 PRD 建立」、「實現此產品」、
  “把需求文檔需求應用”、“根據需求開發這個應用程式”
- 擁有原型圖像 + 需求，並想要全端實作 - 想要將產品規格轉變為正在運行的 Web 應用程式 - 提到從線框/模型結合需求文件建立應用程序
即使用戶只是用工作目錄中存在的 PRD 材料說“幫我開發”或“構建這個”，也會觸發此技能。
