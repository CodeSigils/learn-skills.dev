Cree una aplicación web completa y lista para producción a partir de documentos PRD, imágenes de prototipos y archivos de recursos. Maneja todo el proceso: diseño del sistema, esquema de base de datos, datos iniciales, API de backend, UI de frontend, verificación visual frente a prototipos y generación de scripts de implementación.
Utilice esta habilidad siempre que el usuario: - Proporciona un PRD (documento de requisitos del producto) y desea crear una aplicación que funcione. - Dice cosas como "根据PRD开发", "compilar a partir de PRD", "implementar este producto",
  "把需求文档做成应用", "desarrollar esta aplicación a partir de los requisitos"
- Tiene imágenes prototipo y requisitos y desea una implementación completa - Quiere convertir las especificaciones del producto en una aplicación web en ejecución - Menciona la creación de una aplicación a partir de estructuras alámbricas/maquetas combinadas con un documento de requisitos
Active esta habilidad incluso si el usuario simplemente dice "帮我开发" o "construya esto" con materiales PRD presentes en el directorio de trabajo.
