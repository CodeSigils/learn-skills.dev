PRD ドキュメント、プロトタイプ イメージ、リソース ファイルから、実稼働可能な完全なフルスタック Web アプリケーションを構築します。システム設計、データベース スキーマ、シード データ、バックエンド API、フロントエンド UI、プロトタイプに対する視覚的検証、展開スクリプトの生成など、パイプライン全体を処理します。
ユーザーが次の場合にこのスキルを使用します。 - PRD (製品要件文書) を提供し、動作するアプリの構築を望んでいる - 「根元PRD开発行」、「PRD から構築」、「この製品を実装」などのことを言う
  "ハンドル要求文档做成应用"、"要件に基づいてこのアプリを開発します"
- プロトタイプ画像と要件があり、フルスタックの実装を希望している - 製品仕様を実行中の Web アプリケーションに変換したい - 要件ドキュメントと組み合わせたワイヤーフレーム/モックアップからアプリを構築することに言及している
ユーザーが作業ディレクトリに存在する PRD マテリアルを使用して「帮我开発行」または「これをビルド」と言った場合でも、このスキルをトリガーします。
