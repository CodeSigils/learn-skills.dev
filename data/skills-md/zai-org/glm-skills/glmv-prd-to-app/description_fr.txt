Créez une application Web full-stack complète et prête pour la production à partir de documents PRD, d'images prototypes et de fichiers de ressources. Gère l'intégralité du pipeline : conception du système, schéma de base de données, données de départ, API backend, interface utilisateur frontend, vérification visuelle par rapport aux prototypes et génération de scripts de déploiement.
Utilisez cette compétence chaque fois que l'utilisateur : - Fournit un PRD (document d'exigences du produit) et souhaite créer une application fonctionnelle - Dit des choses comme "根据PRD开发", "construire à partir du PRD", "implémenter ce produit",
  "把需求文档做成应用", "développer cette application à partir des exigences"
- Possède des images de prototypes + des exigences et souhaite une mise en œuvre complète - Veut transformer les spécifications du produit en une application Web en cours d'exécution - Mentionne la création d'une application à partir de wireframes/maquettes combinées à un document d'exigences
Déclenchez cette compétence même si l'utilisateur dit simplement « 帮我开发 » ou « build this » avec les matériaux PRD présents dans le répertoire de travail.
