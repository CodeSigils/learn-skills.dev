Habilidad oficial para reconocer y extraer fórmulas matemáticas de imágenes y archivos PDF en formato LaTeX utilizando la API ZhiPu GLM-OCR. Admite ecuaciones complejas, fórmulas en línea y bloques de fórmulas. Utilice esta habilidad cuando el usuario quiera extraer fórmulas, convertir imágenes de fórmulas a LaTeX o expresiones matemáticas OCR.
