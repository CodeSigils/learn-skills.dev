Stock analysis and rise/fall prediction analysis. Triggered when the user expresses analysis, judgment, or prediction intent, such as “Analyze Tencent,” “How is the recent trend of 0700,” “Can XX be bought,” “Predict the subsequent trend,” “Generate an analysis report,” etc.; for simple query-type requests (e.g., “What is Tencent’s current price,” “What is the code for Maotai”) this skill is not triggered. Supports Hong Kong stocks, A‑shares, and U.S. stocks, integrates multi‑source data (including news, fundamentals, technical factors, capital flows, and macro information) for multidimensional comprehensive analysis, outputting a structured analysis report that combines text and images and includes visual charts. ⚠️ Requires a multimodal main model support (e.g., glm‑5v‑turbo), and the main model must be able to read images.
