Générez un message de commit git conforme aux Commits conventionnels 1.0.0 (et aux règles de facto @commitlint/config-conventional) à partir des modifications actuellement effectuées. Affiche le coréen par défaut ou une autre langue si l'utilisateur le demande explicitement. Déclenchez lorsque l'utilisateur demande un message de validation - par ex. "/conventional-commits", "écrire un message de validation" ou tout équivalent. La portée est limitée à la production du texte du message ; l'exécution de `git commit` ne relève pas de la responsabilité de cette compétence.
