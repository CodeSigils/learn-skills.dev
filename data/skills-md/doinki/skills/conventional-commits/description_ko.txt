현재 준비된 변경 사항에서 Conventional Commits 1.0.0(및 사실상의 @commitlint/config-conventional 규칙)을 준수하는 git 커밋 메시지를 생성합니다. 기본적으로 한국어를 출력하고, 사용자가 명시적으로 요청하는 경우 다른 언어를 출력합니다. 사용자가 커밋 메시지를 요청할 때 트리거됩니다. "/conventional-commits", "커밋 메시지 쓰기" 또는 이에 상응하는 항목. 범위는 메시지 텍스트 생성으로 제한됩니다. `git commit` 실행은 이 스킬의 책임 범위를 벗어납니다.
