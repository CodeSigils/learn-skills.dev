Genere un mensaje de confirmación de git que cumpla con las confirmaciones convencionales 1.0.0 (y las reglas de facto @commitlint/config-conventional) a partir de los cambios actualmente preparados. Genera coreano de forma predeterminada u otro idioma si el usuario lo solicita explícitamente. Se activa cuando el usuario solicita un mensaje de confirmación, p. "/commits convencionales", "escribir un mensaje de confirmación" o cualquier equivalente. El alcance se limita a producir el texto del mensaje; ejecutar `git commit` está fuera de la responsabilidad de esta habilidad.
