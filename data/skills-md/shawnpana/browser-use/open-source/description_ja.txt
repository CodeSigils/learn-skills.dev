ブラウザー使用のオープンソース ライブラリを使用して Python コードを作成するためのドキュメント リファレンス。ユーザーがエージェント、ブラウザ、またはツールの設定に関するサポートが必要な場合、browser_use からインポートするコードを作成している場合、@sandbox デプロイメント、サポートされている LLM モデル、アクター API、カスタム ツール、ライフサイクル フック、MCP サーバーのセットアップ、または Laminar または OpenLIT による監視/可観測性について尋ねるコードを作成している場合は、必ずこのスキルを使用してください。また、ブラウザー使用のインストール、プロンプト戦略、または機密データの処理に関する質問もトリガーされます。これをクラウド API/SDK の使用量や価格設定に使用しないでください。代わりにクラウド スキルを使用してください。 CLI コマンドを介してブラウザを直接自動化するためにこれを使用しないでください。代わりにブラウザ使用スキルを使用してください。
