Référence de documentation pour l'écriture de code Python à l'aide de la bibliothèque open source utilisée par le navigateur. Utilisez cette compétence chaque fois que l'utilisateur a besoin d'aide pour la configuration de l'agent, du navigateur ou des outils, écrit du code importé depuis browser_use, pose des questions sur le déploiement @sandbox, les modèles LLM pris en charge, l'API Actor, les outils personnalisés, les hooks de cycle de vie, la configuration du serveur MCP ou la surveillance/observabilité avec Laminar ou OpenLIT. Déclenchez également des questions sur l'installation à l'aide du navigateur, les stratégies d'invite ou la gestion des données sensibles. Ne l'utilisez PAS pour l'utilisation ou la tarification de l'API/SDK Cloud ; utilisez plutôt la compétence Cloud. Ne l'utilisez PAS pour automatiser directement un navigateur via des commandes CLI - utilisez plutôt la compétence d'utilisation du navigateur.
