مرجع توثيقي لكتابة كود بايثون باستخدام مكتبة مفتوحة المصدر تستخدم المتصفح. استخدم هذه المهارة عندما يحتاج المستخدم إلى مساعدة في تكوين الوكيل أو المتصفح أو الأدوات، أو كتابة التعليمات البرمجية التي يتم استيرادها من browser_use، أو الاستفسار عن نشر @sandbox، أو نماذج LLM المدعومة، أو Actor API، أو الأدوات المخصصة، أو خطافات دورة الحياة، أو إعداد خادم MCP، أو المراقبة/إمكانية المراقبة باستخدام Laminar أو OpenLIT. قم أيضًا بطرح الأسئلة حول التثبيت باستخدام المتصفح، أو استراتيجيات المطالبة، أو التعامل مع البيانات الحساسة. لا تستخدم هذا لاستخدام Cloud API/SDK أو التسعير - استخدم المهارة السحابية بدلاً من ذلك. لا تستخدم هذا لأتمتة المتصفح مباشرة عبر أوامر CLI - استخدم مهارة استخدام المتصفح بدلاً من ذلك.
