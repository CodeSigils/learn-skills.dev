Referencia de documentación para escribir código Python utilizando la biblioteca de código abierto para uso del navegador. Utilice esta habilidad siempre que el usuario necesite ayuda con la configuración del Agente, el Navegador o las Herramientas, esté escribiendo código que importe desde browser_use, pregunte sobre la implementación de @sandbox, los modelos LLM compatibles, la API de Actor, las herramientas personalizadas, los enlaces del ciclo de vida, la configuración del servidor MCP o el monitoreo/observabilidad con Laminar u OpenLIT. También activa preguntas sobre la instalación del uso del navegador, estrategias de aviso o manejo de datos confidenciales. NO use esto para el uso o fijación de precios de API/SDK de la nube; en su lugar, use la habilidad de la nube. NO use esto para automatizar directamente un navegador a través de comandos CLI; en su lugar, use la habilidad de uso del navegador.
