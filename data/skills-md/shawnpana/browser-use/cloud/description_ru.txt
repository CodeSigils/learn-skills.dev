Справочник документации по использованию Browser Use Cloud — размещенного API и SDK для автоматизации браузера. Используйте этот навык всякий раз, когда пользователю нужна помощь с Cloud REST API (v2 или v3), SDK для браузера (Python или TypeScript), аутентификацией X-Browser-Use-API-Key, облачными сеансами, профилями браузера, синхронизацией профилей, подключениями CDP WebSocket, скрытыми браузерами, резидентными прокси, обработкой CAPTCHA, веб-перехватчиками, рабочими пространствами, рынком навыков, потоковой передачей liveUrl, ценами или шаблонами интеграции (чат). Пользовательский интерфейс, субагент, добавление инструментов браузера к существующим агентам). Также можно задать вопросы об интеграции n8n/Make/Zapier, Playwright/Puppeteer/Selenium в облачной инфраструктуре или интеграции хранилища 1Password. НЕ используйте это для библиотеки Python с открытым исходным кодом (конфигурация «Агент», «Браузер», «Инструменты») — вместо этого используйте навык с открытым исходным кодом.
