تصميم الواجهة المرئية للتطبيقات ولوحات المعلومات ولوحات الإعدادات وأدوات الإدارة وأنظمة التصميم، مع التركيز على التسلسل الهرمي واتساق المكونات وإمكانية الوصول وواقعية التنفيذ. يُستخدم عندما يطلب المستخدم تصميم واجهة المستخدم، أو التنظيف المرئي، أو إعادة تصميم المكونات، أو التباعد، أو اللون، أو الطباعة، أو الحالات، أو التلميع سريع الاستجابة، أو عمل نظام التصميم.
