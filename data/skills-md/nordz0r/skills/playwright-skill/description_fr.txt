Automatisation complète du navigateur avec Playwright. Prend en charge la détection explicite du serveur de développement localhost, écrit des scripts de test propres dans /tmp, les exécute via un exécuteur local et facilite les captures d'écran, les vérifications réactives, les flux de connexion, l'automatisation des formulaires, la vérification des liens et les tests généraux basés sur le navigateur. À utiliser lorsque l'utilisateur souhaite Playwright, l'automatisation du navigateur, les vérifications E2E, les tests de sites Web ou la validation UX.
