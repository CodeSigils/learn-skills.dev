مرجع كامل باللغة الروسية لـ Open Terminal: محطة REST API ذاتية الاستضافة لوكلاء الذكاء الاصطناعي. استخدم هذه المهارة لطرح أي أسئلة حول Open Terminal: نقاط نهاية واجهة برمجة التطبيقات (API)، والنشر (Docker، والمعدن)، والتكوين، والتكامل مع Open WebUI، والهندسة المعمارية، وتصحيح الأخطاء، وكتابة تعليمات برمجية للعميل للتفاعل مع Open Terminal. استخدمه أيضًا عند العمل مع قاعدة التعليمات البرمجية للمحطة المفتوحة: بنية المشروع، runner.py، main.py، خادم MCP، دفاتر Jupyter. المشغلات: محطة مفتوحة، محطة مفتوحة، واجهة برمجة تطبيقات المحطة الطرفية البعيدة، / تنفيذ، / ملفات، API وضع الحماية، جلسات المحطة، محطة WebUI المفتوحة.
