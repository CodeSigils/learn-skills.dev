Полный русскоязычный справочник по Open Terminal: автономный терминал REST API для агентов ИИ. Используйте этот навык для ответов на любые вопросы об Open Terminal: конечные точки API, развертывание (Docker, «голое железо»), настройка, интеграция с Open WebUI, архитектура, отладка, написание клиентского кода для взаимодействия с Open Terminal. Также используйте при работе с базой кода открытого терминала: структуру проекта, runner.py, main.py, сервер MCP, блокноты Jupyter. Триггеры: открытый терминал, открытый терминал, API удаленного терминала, /execute, /files, API песочницы, сеансы терминала, терминал Open WebUI.
