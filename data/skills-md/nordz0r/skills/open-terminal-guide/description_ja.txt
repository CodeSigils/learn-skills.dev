Open Terminal の完全なロシア語リファレンス: AI エージェント用のセルフホスト型 REST API ターミナル。 Open Terminal に関する質問にはこのスキルを使用してください: API エンドポイント、デプロイメント (Docker、ベアメタル)、構成、Open WebUI との統合、アーキテクチャ、デバッグ、Open Terminal と対話するためのクライアント コードの作成。オープン ターミナル コードベースを操作する場合にも使用します: プロジェクト構造、runner.py、main.py、MCP サーバー、Jupyter ノートブック。トリガー: オープンターミナル、オープンターミナル、リモートターミナル API、/execute、/files、サンドボックス API、ターミナルセッション、オープン WebUI ターミナル。
