هيكل تجربة المستخدم وبنية جاهزة للتنفيذ للتسلسل الهرمي للمعلومات، والتدفقات، وأنظمة التخطيط، والسلوك سريع الاستجابة، وأسس السمات، وتسليم المطور. يُستخدم عندما يحتاج المستخدم إلى أسس UX، أو CSS أو بنية المكونات، أو تنظيف IA، أو تصميم تدفق الشاشة، أو تخطيط التنفيذ لواجهة مستخدم جديدة، أو يريد ترجمة مواصفات المنتج إلى بنية واجهة قابلة للبناء.
