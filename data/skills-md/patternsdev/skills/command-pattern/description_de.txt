Lehrt das Befehlsmuster zum Entkoppeln der Aufgabenausführung vom Aufruf. Verwenden Sie diese Funktion, wenn Sie Funktionen zum Rückgängigmachen/Wiederherstellen benötigen, Vorgänge in der Warteschlange haben oder das Objekt, das einen Vorgang aufruft, von dem Objekt, das ihn ausführt, entkoppeln möchten.
