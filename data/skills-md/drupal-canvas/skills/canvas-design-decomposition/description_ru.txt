Планирует структуру библиотеки компонентов с реквизитами/слотами и нужной степенью детализации компонентов. Запускайте перед созданием или добавлением компонентов Canvas (новые папки `src/comComponents/`, компонент.yml, React) или для работы только по плану/только для разбивки, когда пользовательский интерфейс должен сопоставляться с последовательным деревом. Обязательно для каждого нового кадра Figma или нового экрана — черновики репозитория не заменяют этапы A–G.
