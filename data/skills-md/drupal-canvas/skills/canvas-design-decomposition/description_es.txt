Estructura de planos para una biblioteca de componentes con accesorios/ranuras y granularidad de componentes del tamaño adecuado. Ejecútelo antes de crear o agregar componentes de Canvas (nuevas carpetas `src/components/`, componente.yml, React), o para trabajos de solo plan/solo desglose, siempre que la interfaz de usuario deba asignarse a un árbol coherente. Obligatorio para cada nuevo marco de Figma o pantalla nueva; los borradores del repositorio no reemplazan las fases A a G.
