Úselo para cualquier tarea relacionada con el cromo del sitio (encabezado, pie de página, barra lateral o navegación global que se repite en las páginas) y para cualquier trabajo relacionado con la región (crear, modificar, revisar, validar JSON de región o el componente de diseño a nivel de proyecto). También se carga cuando una tarea crea o edita varias páginas que comparten Chrome, o solicita un "sitio" o "navegación entre páginas"; Chrome compartido pertenece a regiones, nunca incluido en la página JSON.
