구조 및 소품/슬롯에 대한 디자인 분해를 사용한 다음 JSON:API 메뉴 또는 캔버스 데이터 가져오기의 페이지 컨텍스트 패턴을 사용하여 Drupal Canvas 탐색 UI(기본 탐색, 바닥글 링크, 사이드바 탐색, 모바일 서랍, 이동 경로)를 계획하고 구축합니다. 사용자가 탐색, 머리글 또는 바닥글 링크, 메뉴, menu_items, 모바일 탐색 또는 탐색경로 트레일을 요청할 때 사용합니다. 레이아웃 및 API 스케치를 위해 캔버스 디자인 분해 후 실행합니다. SWR, JsonApiClient, sortMenu 및 메뉴 대체에 대한 canvas-data-fetching을 따릅니다.
