構造とプロパティ/スロットのデザイン分解を使用して、Drupal Canvas ナビゲーション UI (メイン ナビゲーション、フッター リンク、サイドバー ナビゲーション、モバイル ドロワー、パンくずリスト) を計画および構築し、次に JSON:API メニューまたはキャンバス データ フェッチからのページ コンテキスト パターンを使用します。ユーザーがナビゲーション、ヘッダーまたはフッターのリンク、メニュー、menu_items、モバイル ナビゲーション、またはパンくずリストを要求する場合に使用します。レイアウトと API スケッチの Canvas-design-decomposition の後に実行します。 SWR、JsonApiClient、sortMenu、メニュー フォールバックの Canvas-data-fetching に従います。
