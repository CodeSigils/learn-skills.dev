Dots هو تطبيق رسم بياني يتيح للمستخدمين إنشاء الرسوم البيانية المعرفية واستكشافها وإدارتها عبر المساحات. توفر هذه المهارة الدليل الكامل للتفاعل مع النقاط - قراءة لقطات الرسم البياني، وإنشاء العقد والحواف، وتشغيل الاستعلامات، وتنفيذ القوالب، والتحكم في عرض المتصفح المشترك. استخدم هذه المهارة عندما يذكر المستخدم النقاط أو الرسوم البيانية أو العقد أو الحواف أو المسافات أو الرسوم البيانية المعرفية أو استعلامات الرسم البياني أو القوالب أو عندما يريد تصور أي بنية رسم بياني أو إنشائها أو استكشافها - حتى الطلبات غير الرسمية مثل "أرني الرسم البياني" أو "أضف عقدة" أو "ما هو متصل بـ X".
