Progetta database per progetti a livello personale in base ai requisiti. Genera un documento di progettazione di markdown e un SQL eseguibile, salvandoli in un file locale. Segue le regole di normalizzazione ed estensibilità di base, con eliminazione logica per i dati aziendali ed eliminazione fisica per i dati temporanei. Si attiva quando l'utente richiede la progettazione del database, la creazione di uno schema o la generazione di SQL per un progetto personale.
