تصميم قواعد بيانات للمشاريع على المستوى الشخصي بناءً على المتطلبات. يُنشئ مستند تصميم تخفيض السعر وSQL القابل للتنفيذ، ويحفظهما في ملف محلي. يتبع قواعد التسوية والتوسعة الأساسية، مع الحذف المنطقي لبيانات الأعمال والحذف الفعلي للبيانات المؤقتة. يتم تشغيله عندما يطلب المستخدم تصميم قاعدة البيانات، أو إنشاء المخطط، أو إنشاء SQL لمشروع شخصي.
