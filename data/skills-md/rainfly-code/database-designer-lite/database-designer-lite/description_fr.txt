Concevoir des bases de données pour des projets personnels en fonction des exigences. Génère un document de conception markdown et un exécutable SQL, en les enregistrant dans un fichier local. Suit les règles de base de normalisation et d’extensibilité, avec suppression logique pour les données professionnelles et suppression physique pour les données temporaires. Déclenchez lorsque l'utilisateur demande une conception de base de données, une création de schéma ou une génération SQL pour un projet personnel.
