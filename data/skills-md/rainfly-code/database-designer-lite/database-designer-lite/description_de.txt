Entwerfen Sie Datenbanken für Projekte auf persönlicher Ebene basierend auf den Anforderungen. Erstellt ein Markdown-Designdokument und ausführbares SQL und speichert sie in einer lokalen Datei. Befolgt grundlegende Normalisierungs- und Erweiterbarkeitsregeln, mit logischem Löschen für Geschäftsdaten und physischem Löschen für temporäre Daten. Wird ausgelöst, wenn der Benutzer für ein persönliches Projekt nach Datenbankdesign, Schemaerstellung oder SQL-Generierung fragt.
