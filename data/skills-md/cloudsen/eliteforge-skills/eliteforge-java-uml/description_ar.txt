قم بإنشاء مخططات فئة Java 25 PlantUML قابلة للتنفيذ بناءً على احتياجات العمل، مع نماذج موحدة ذات طبقات، ونقاط نهاية العلاقة، والاستعلامات المرقّمة، ونمذجة حقل التعداد، والملاحظات داخل الفصل، وقواعد ألوان الوحدة النمطية. يُستخدم عندما يذكر المستخدم "Java UML"، أو "مخطط فئة PlantUML"، أو "نمذجة المجال"، أو "تصميم البنية ذات الطبقات"، أو "تصميم استعلام المستودع"، أو "مراجعة مخطط الفئة"؛ قم بإخراج UML أولاً ولا تخترع أو تضيف علاقات أبدًا دون التأريض.
