Vérifiez si l'environnement de développement est entièrement configuré ; sinon, confirmez d'abord l'emplacement du bureau de Chongqing/Pékin, identifiez le système d'exploitation actuel, les outils système, le gestionnaire de paquets et les déclarations de variables d'environnement de compétences Eliteforge-*, et signalez-les dans la catégorie manquant_required, manquant_conditional, optionnel_unset. Essayez ensuite d'installer automatiquement les commandes requises et les hôtes complets, la configuration globale de Git, Git HTTPS, les registres npm/pip privés et les packages pipx. Utilisez-le lorsque l'utilisateur mentionne « vérifier la configuration de l'environnement », « préparer l'environnement de développement » ou « commande manquante/hôtes/registre privé/configuration Git/gestionnaire de packages/variable d'environnement de compétence ».
