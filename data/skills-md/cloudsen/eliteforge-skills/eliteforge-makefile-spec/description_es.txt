Identifique el repositorio y genere o refactorice el Makefile de nivel raíz a través de una interfaz de comando unificada. Los usuarios solicitan crear, estandarizar, revisar o actualizar el Makefile, unificando make help/doctor/install/clean/format/lint/test/build/dev/deploy target, admitiendo parámetros dinámicos como VERSION, SKIP_TESTS, publicando artefactos versionados como JAR, adaptándose a Docker push, shells de aplicaciones Electron/Tauri/Capacitor, o cuando se requiere compatibilidad con GNU Make 3.81, macOS y Windows.
