حدد المستودع وقم بإنشاء أو إعادة بناء ملف Makefile على مستوى الجذر عبر واجهة أوامر موحدة. يطلب المستخدمون إنشاء ملف Makefile أو توحيده أو مراجعته أو تحديثه، وتوحيد make help/doctor/install/clean/format/lint/test/build/dev/deploy الأهداف، ودعم المعلمات الديناميكية مثل VERSION، وSKIP_TESTS، ونشر القطع الأثرية ذات الإصدارات مثل JARs، والتكيف مع Docker Push، وأغلفة تطبيقات Electron/Tauri/Capacitor، أو عند التوافق مع GNU Make 3.81، وmacOS، ويلزم ويندوز.
