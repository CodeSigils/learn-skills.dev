Identifica il repository e genera o effettua il refactoring del Makefile a livello root tramite un'interfaccia di comando unificata. Gli utenti possono richiedere di creare, standardizzare, rivedere o aggiornare il Makefile, unificare target make help/doctor/install/clean/format/lint/test/build/dev/deploy, supportare parametri dinamici come VERSION e SKIP_TESTS, pubblicare artefatti con versione come JAR, adattarsi a Docker push, shell di applicazioni Electron/Tauri/Capacitor o richiedere compatibilità con GNU Make 3.81, macOS e Windows.
