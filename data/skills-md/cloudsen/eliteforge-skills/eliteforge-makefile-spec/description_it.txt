Identifica il repository e genera o effettua il refactoring del Makefile a livello root tramite un'interfaccia di comando unificata. Gli utenti richiedono di creare, standardizzare, rivedere o aggiornare il Makefile, unificando i target make help/doctor/install/clean/format/lint/test/build/dev/deploy, supportando parametri dinamici come VERSION, SKIP_TESTS, pubblicando artefatti con versione come JAR, adattandosi a Docker push, shell di applicazioni Electron/Tauri/Capacitor o quando è richiesta la compatibilità con GNU Make 3.81, macOS e Windows.
