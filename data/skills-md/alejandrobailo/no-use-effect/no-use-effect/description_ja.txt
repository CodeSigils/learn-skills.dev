常にアクティブ。 React および React Native コードに厳密な no-direct-useEffect ルールを強制します。 useEffect を直接書き込まないでください。代わりに、派生状態、イベント ハンドラー、useMemo、useSyncExternalStore、データフェッチ ライブラリ、キーベースのリセット、または useMountEffect を使用してください。新しいコンポーネントの作成、既存のコンポーネントの編集、コードのレビュー、バグの修正、リファクタリングなど、すべての React コンポーネント コードでトリガーされます。ユーザーが useEffect、副作用、データの取得、状態の同期、またはコンポーネントのライフサイクルに言及したときにもトリガーされます。
