TOUJOURS ACTIF. Applique une règle stricte de non-utilisation directe dans le code React et React Native. N'écrivez jamais useEffect directement - utilisez l'état dérivé, les gestionnaires d'événements, useMemo, useSyncExternalStore, les bibliothèques de récupération de données, les réinitialisations basées sur des clés ou useMountEffect à la place. Déclencheurs sur tout le code des composants React : écriture de nouveaux composants, modification de composants existants, révision du code, correction de bugs ou refactorisation. Se déclenche également lorsque l'utilisateur mentionne useEffect, les effets secondaires, la récupération de données, la synchronisation de l'état ou le cycle de vie des composants.
