SIEMPRE ACTIVO. Aplica una estricta regla de efecto de no uso directo en el código React y React Native. Nunca escriba useEffect directamente: use estado derivado, controladores de eventos, useMemo, useSyncExternalStore, bibliotecas de recuperación de datos, restablecimientos basados ​​en claves o useMountEffect en su lugar. Activadores de todo el código de los componentes de React: escribir nuevos componentes, editar los existentes, revisar el código, corregir errores o refactorizar. También se activa cuando el usuario menciona useEffect, efectos secundarios, obtención de datos, sincronización de estado o ciclo de vida del componente.
