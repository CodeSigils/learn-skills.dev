نشط دائمًا. يفرض قاعدة صارمة لعدم الاستخدام المباشر في كود React وReact Native. لا تكتب useEffect مباشرة أبدًا — استخدم الحالة المشتقة، أو معالجات الأحداث، أو useMemo، أو useSyncExternalStore، أو مكتبات جلب البيانات، أو عمليات إعادة التعيين المستندة إلى المفتاح، أو useMountEffect بدلاً من ذلك. مشغلات على كافة أكواد مكونات React: كتابة مكونات جديدة، أو تحرير المكونات الموجودة، أو مراجعة التعليمات البرمجية، أو إصلاح الأخطاء، أو إعادة البناء. يتم تشغيله أيضًا عندما يذكر المستخدم useEffect أو الآثار الجانبية أو جلب البيانات أو مزامنة الحالة أو دورة حياة المكون.
