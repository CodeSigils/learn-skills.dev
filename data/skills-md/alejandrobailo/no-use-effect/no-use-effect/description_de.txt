IMMER AKTIV. Erzwingt eine strikte No-Direct-UseEffect-Regel in React- und React Native-Code. Schreiben Sie useEffect niemals direkt – verwenden Sie stattdessen abgeleitete Zustände, Ereignishandler, useMemo, useSyncExternalStore, Datenabrufbibliotheken, schlüsselbasierte Zurücksetzungen oder useMountEffect. Wird für den gesamten React-Komponentencode ausgelöst: Schreiben neuer Komponenten, Bearbeiten vorhandener Komponenten, Überprüfen von Code, Beheben von Fehlern oder Refactoring. Wird auch ausgelöst, wenn der Benutzer useEffect, Nebenwirkungen, Datenabruf, Statussynchronisierung oder Komponentenlebenszyklus erwähnt.
