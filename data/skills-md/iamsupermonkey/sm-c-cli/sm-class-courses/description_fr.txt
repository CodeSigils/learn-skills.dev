Base de connaissances des cours en groupe SUPERMONKEY (Super Monkey) : utilisez-la lorsque les utilisateurs se renseignent sur le « cours lui-même » des cours en groupe Super Monkey : ce qu'est un cours particulier, ce qui est pratiqué, ses avantages, à qui il convient, s'il existe des cours visant certains objectifs (perte de poids/mise en forme/brûlure de graisse), les précautions de cours, les FAQ et les comparaisons telles que « quelle est la différence entre la classe A et la classe B ». Utilisez d’abord cette compétence pour récupérer les informations du cours en tant que contexte, puis répondez en fonction de cela. Remarque : Cette compétence gère uniquement les connaissances relatives à la description du cours ; il ne recherche pas d'horaires/horaires/réservations spécifiques (c'est-à-dire les horaires sm-class), ni les emplacements des magasins (sm-box).

Veuillez toujours répondre dans la langue de l’utilisateur.
