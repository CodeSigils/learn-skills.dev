Расписание групповых занятий SUPERMONKEY (Super Monkey): предоставляет возможность запрашивать/искать расписание групповых занятий Super Monkey и получать адрес ссылки для бронирования для расписания (помогает забронировать занятия). Используйте это, когда пользователь спрашивает «Super Monkey / расписание», «Какие занятия доступны завтра в магазине xxx», «В какие дни тренер xxx проводит занятия на этой неделе», «В каком магазине я могу пройти курс xxx», «Какие групповые занятия есть недавно/в ближайшие несколько дней» или «Я хочу забронировать этот урок/помогите мне забронировать этот урок».
