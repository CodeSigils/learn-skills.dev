SUPERMONKEY (Super Monkey) group class schedule: provides the ability to query/search the Super Monkey group class schedule and obtain the reservation link address for the schedule (helping to book classes). Use this when the user asks “Super Monkey / schedule,” “What classes are available tomorrow at xxx store,” “Which days does coach xxx have classes this week,” “At which store can I take the xxx course,” “What group classes are there recently / in the next few days,” or “I want to book this class / help me book this class.”
