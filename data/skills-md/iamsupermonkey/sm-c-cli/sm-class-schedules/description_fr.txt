Horaire des cours de groupe SUPERMONKEY (Super Monkey) : offre la possibilité d'interroger/rechercher l'horaire des cours de groupe Super Monkey et d'obtenir l'adresse du lien de réservation pour l'horaire (ce qui aide à réserver des cours). Utilisez cette option lorsque l'utilisateur demande « Super Monkey / planning », « Quels cours sont disponibles demain dans le magasin xxx », « Quels jours l'entraîneur xxx a-t-il des cours cette semaine », « Dans quel magasin puis-je suivre le cours xxx », « Quels cours de groupe y a-t-il récemment/dans les prochains jours » ou « Je veux réserver ce cours/aidez-moi à réserver ce cours. »
