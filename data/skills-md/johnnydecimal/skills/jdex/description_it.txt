Leggi e scrivi nel JDex dell'utente — il loro indice Johnny.Decimal. Usa questa abilità ogni volta che l'utente menziona il proprio JDex, chiede di controllare, recuperare o aggiornare la propria documentazione, fa riferimento a un ID Johnny.Decimal (ad esempio 12.34, W0189), ti invoca da una cartella con un ID nel nome, chiede di trovare un file o un documento, chiede dove un documento appartiene nel loro sistema JD, o pone una domanda fattuale sulla propria vita o attività (ad esempio “dove va il denaro X?”, “qual è il processo per Y?”, “traccia dove è finito Z”). Il JDex è la loro base di conoscenza — tratta qualsiasi domanda investigativa o di ricerca sulle proprie informazioni come una ricerca JDex prima.

Rispondi sempre nella lingua dell'utente.
