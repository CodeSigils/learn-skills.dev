Una habilidad de consulta de datos financieros basada en la API iFind de Tonghuashun. Se utiliza para obtener cotizaciones de acciones A, acciones de Hong Kong y acciones de EE. UU., valores de activos netos de fondos, datos de índices, estados financieros y más. Escenarios desencadenantes: (1) consultar cotizaciones de acciones o precios históricos en tiempo real, (2) recuperar valores netos de fondos y datos de rendimiento, (3) buscar acciones y valoraciones de los componentes del índice, (4) utilizar lenguaje natural para seleccionar acciones (Pregunte a Finanzas), (5) obtener datos financieros y métricas de valoración. Admite métodos de invocación de SDK local y API HTTP.
