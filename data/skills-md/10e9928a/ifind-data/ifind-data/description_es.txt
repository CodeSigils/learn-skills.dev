Una habilidad de consulta de datos financieros basada en la API TongHuaShun iFind. Se utiliza para obtener cotizaciones de acciones, valores liquidativos de fondos, datos de índices y estados financieros de acciones A, acciones de Hong Kong y acciones estadounidenses. Escenarios desencadenantes: (1) consultar precios de acciones históricos o en tiempo real, (2) obtener el NAV del fondo y datos de rendimiento, (3) consultar los componentes y valoraciones del índice, (4) utilizar la selección de acciones en lenguaje natural (WenCai), (5) recuperar datos financieros e indicadores de valoración. Admite llamadas locales de SDK y API HTTP.
