Compétence de requête de données financières basée sur l'API TongHuaShun iFind. Utilisé pour récupérer les cotations boursières, les valeurs liquidatives des fonds, les données d'indices, les états financiers, etc., pour les actions A, les actions de Hong Kong et les actions américaines. Scénarios de déclenchement : (1) interroger les cours boursiers en temps réel ou historiques, (2) obtenir des données sur la valeur liquidative et les performances du fonds, (3) interroger les composants et les valorisations de l'indice, (4) utiliser le filtrage des actions en langage naturel (Wencai), (5) récupérer des données financières et des mesures de valorisation. Prend en charge les appels SDK locaux et API HTTP.
