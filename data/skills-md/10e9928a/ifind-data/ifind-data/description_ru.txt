Навык запроса финансовых данных на основе API Tonghuashun iFind. Он используется для получения котировок акций A-акций, акций Гонконга и США, стоимости чистых активов фондов, данных индексов, финансовых отчетов и многого другого. Сценарии триггера: (1) запросить котировки акций или исторические цены в реальном времени, (2) получить чистую стоимость фонда и данные об эффективности, (3) найти акции и оценки, входящие в индекс, (4) использовать естественный язык для выбора акций (Ask Finance), (5) получить финансовые данные и показатели оценки. Поддерживает методы вызова локального SDK и HTTP API.
