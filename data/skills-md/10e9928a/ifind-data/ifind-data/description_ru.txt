Навыки запроса финансовых данных на основе API Tonghuashun iFind. Он используется для получения котировок акций, стоимости чистых активов фонда, данных индексов, финансовой отчетности и другой информации по акциям А, гонконгским акциям и акциям США. Сценарии триггера: (1) запросить котировки акций или исторические цены в реальном времени, (2) получить чистую стоимость фонда и данные об эффективности, (3) запросить акции, входящие в индекс, и их оценки, (4) использовать выбор акций на естественном языке (Ask Finance), (5) получить финансовые данные и показатели оценки. Поддерживает методы вызова локального SDK и HTTP API.
