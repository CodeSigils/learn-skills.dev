A financial data query skill based on the TongHuaShun iFind API. Used to obtain stock quotes, fund NAVs, index data, and financial statements for A-shares, Hong Kong stocks, and U.S. stocks. Trigger scenarios: (1) querying real-time or historical stock prices, (2) obtaining fund NAV and performance data, (3) querying index constituents and valuations, (4) using natural-language stock screening (WenCai), (5) retrieving financial data and valuation indicators. Supports both local SDK and HTTP API calls.
