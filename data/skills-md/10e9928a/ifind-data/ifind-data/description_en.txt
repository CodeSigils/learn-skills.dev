Financial data query skill based on the Tonghuashun iFind API. It is used to obtain stock quotes, fund net asset values, index data, financial statements, and other information for A‑shares, Hong Kong stocks, and U.S. stocks. Trigger scenarios: (1) query real‑time stock quotes or historical prices, (2) retrieve fund net values and performance data, (3) query index constituent stocks and valuations, (4) use natural‑language stock selection (Ask Finance), (5) obtain financial data and valuation metrics. Supports both local SDK and HTTP API invocation methods.
