A financial data query skill based on the Tonghuashun iFind API. It is used to obtain stock quotes for A-shares, Hong Kong stocks, and US stocks, fund net asset values, index data, financial statements, and more. Trigger scenarios: (1) query real-time stock quotes or historical prices, (2) retrieve fund net values and performance data, (3) look up index constituent stocks and valuations, (4) use natural language to select stocks (Ask Finance), (5) obtain financial data and valuation metrics. Supports both local SDK and HTTP API invocation methods.
