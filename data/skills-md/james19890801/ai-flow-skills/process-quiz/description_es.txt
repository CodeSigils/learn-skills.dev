Habilidad de miniexamen de flujo: después de que un usuario carga un archivo de flujo o política, el sistema analiza automáticamente el contenido y genera un banco de preguntas (más de 20 preguntas), luego produce una página HTML con 10 preguntas de prueba (opción única, opción múltiple, verdadero/falso). Admite respuestas del lado del candidato, revisión de resultados, vista del historial y acceso del lado del administrador a todos los registros de exámenes. Se activa cuando el usuario dice "Ayúdame a realizar un mini flujo", "generar examen", "crear una prueba a partir de este flujo", "habilidad de examen" o "examen de flujo".
