Skill Name: Mini-Process Quiz
After a user uploads a process or policy document, the system automatically parses the content, generates a question bank (20+ questions), and outputs an HTML page with ten questions—single-choice, multiple-choice, and true/false. It supports candidate answering, result analysis, historical record viewing, and an admin view of all exam records. Triggered when the user says "帮我做流程小考", "生成考试", "把这个流程出题", "考试技能", or "流程考试".
