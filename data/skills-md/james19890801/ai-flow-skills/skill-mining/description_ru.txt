Автоматически находите возможности для развития навыков из документов процессов (Word/PDF/изображения/текстовые описания), создавайте визуальный отчет анализа HTML и предварительно просматривайте его, определяйте, какие узлы процесса наиболее подходят для инкапсуляции в качестве навыков, оценивайте приоритеты и далее инкапсулируйте одним щелчком мыши для создания файла навыков. Когда пользователь произносит «Навык 帮我挖掘», «Навык 流程中找 Навык 机会», «Навык 这个流程哪里可以做», «Навык 挖掘», «Навык 流程里有哪些 可以做», это навык срабатывает.
