Extraiga automáticamente oportunidades de desarrollo de habilidades a partir de documentos de proceso (Word/PDF/imágenes/descripciones de texto), genere un informe de análisis HTML visual con vista previa automática, identifique qué nodos de proceso son más adecuados para ser empaquetados como habilidades, evalúe sus prioridades y, además, permita el empaquetado con un solo clic para generar archivos de habilidades. Esta habilidad se activa cuando el usuario dice "Ayúdame a extraer habilidades", "Encontrar oportunidades de habilidades en el proceso", "En qué parte de este proceso se pueden desarrollar habilidades", "Extracción de habilidades" o "Qué habilidades se pueden desarrollar en el proceso".
