Ermitteln Sie automatisch Möglichkeiten zum Aufbau von Fertigkeiten aus Prozessdokumenten (Word/PDF/Bilder/Textbeschreibungen), erstellen Sie einen visuellen HTML-Analysebericht mit automatischer Vorschau, ermitteln Sie, welche Prozessknoten am besten für die Paketierung als Fertigkeiten geeignet sind, bewerten Sie deren Prioritäten und ermöglichen Sie außerdem die Paketierung mit einem Klick, um Fertigkeitsdateien zu generieren. Dieser Skill wird ausgelöst, wenn der Benutzer sagt: „Helfen Sie mir, Fertigkeiten abzubauen“, „Finden Sie Fertigkeitenmöglichkeiten aus dem Prozess“, „Wo in diesem Prozess können Fertigkeiten erstellt werden“, „Skill Mining“ oder „Welche Fertigkeiten können im Prozess erstellt werden.“
