Estrae automaticamente opportunità di sviluppo delle competenze dai documenti di processo (Word/PDF/immagini/descrizioni di testo), genera un report di analisi visiva HTML con anteprima automatica, identifica quali nodi di processo sono più adatti per essere impacchettati come competenze, valuta le loro priorità e consente inoltre il confezionamento con un clic per generare file di competenze. Questa abilità viene attivata quando l'utente dice "Aiutami a estrarre le competenze", "Trova opportunità di competenze dal processo", "Dove in questo processo è possibile creare competenze", "Skill mining" o "Quali competenze possono essere create nel processo".
