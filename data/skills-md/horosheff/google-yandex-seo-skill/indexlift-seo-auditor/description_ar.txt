استخدم هذه المهارة عندما يريد المستخدم إجراء تدقيق لتحسين محركات البحث، أو مراجعة تقنية لتحسين محركات البحث، أو تحليل Google أو Yandex على مستوى الصفحة، أو التحقق من صحة ملف robots.txt أو خريطة الموقع، أو عمليات التحقق الأساسية/قابلية الفهرسة، أو تقرير تحسين محركات البحث الجاهز للعميل. لقد تم تصميمه لإجراء عمليات تدقيق مفصلة للغاية في صفحة واحدة افتراضيًا، مع نتائج قابلة للتنفيذ، وتسليمات JSON وMarkdown، وتقسيمات منفصلة لـ Google/Yandex، حتى لو لم يذكر المستخدم صراحةً "المهارة" أو "التدقيق" أو "أداة تحسين محركات البحث".
