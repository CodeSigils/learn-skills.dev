Utilice esta habilidad cuando el usuario desee una auditoría de SEO, una revisión técnica de SEO, un análisis de Google o Yandex a nivel de página, una validación de robots.txt o de mapas de sitio, comprobaciones canónicas/de indexabilidad o un informe de SEO listo para el cliente. Está diseñado para auditorías de una sola página ultra detalladas de forma predeterminada, con resultados procesables, entregables JSON y Markdown, y desgloses separados de Google/Yandex, incluso si el usuario no menciona explícitamente "habilidad", "auditoría" o "herramienta de SEO".
