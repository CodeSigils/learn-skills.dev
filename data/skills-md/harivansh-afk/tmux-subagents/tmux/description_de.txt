Orchestrieren Sie Devin-CLI-Subagenten als Hintergrundarbeiter mithilfe von tmux Windows. Verwenden Sie diese Option, wenn der Benutzer die Arbeit an mehrere parallele Agenten starten, koordinieren, verteilen oder delegieren, Devin-Sitzungen im Hintergrund ausführen oder lang laufende autonome Aufgaben innerhalb einer vorhandenen Devin-Sitzung orchestrieren möchte.
