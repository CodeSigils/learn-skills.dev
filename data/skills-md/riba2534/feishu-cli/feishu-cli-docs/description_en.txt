Feishu Docs unified entry point, covering reading and analyzing docx/wiki/sheet, creating and editing documents, Markdown import, docx/wiki/sheet export to Markdown/PDF/Word/Excel, and cloud drive native .md file CRUD. Users who need to read, summarize, create, append, overwrite, replace, or delete document content, import Markdown into Feishu and convert to Mermaid/PlantUML/SVG, download images or export local files, compare and overwrite native Markdown must use this Skill. This Skill only handles main text content and document/Markdown file conversion. It is explicitly prohibited for document comments, binary file import, cloud drive directory and permission management—these use feishu-cli-storage; attendance and other work management use feishu-cli-work; dynamic components use feishu-cli-visual. As long as the intent is to list/reply/resolve a comment, even if the request mentions “document,” do not use this Skill.
