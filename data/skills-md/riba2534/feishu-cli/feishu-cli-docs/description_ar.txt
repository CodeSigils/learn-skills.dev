نقطة دخول موحدة لـ Feishu Docs، تغطي قراءة وتحليل docx/wiki/sheet، وإنشاء المستندات وتحريرها، واستيراد Markdown، وتصدير docx/wiki/sheet إلى Markdown/PDF/Word/Excel، وملف .md الأصلي لمحرك الأقراص السحابي. المستخدمون الذين يحتاجون إلى قراءة محتوى المستند أو تلخيصه أو إنشاؤه أو إلحاقه أو الكتابة فوقه أو استبداله أو حذفه، واستيراد Markdown إلى Feishu والتحويل إلى Mermaid/PlantUML/SVG، أو تنزيل الصور أو تصدير الملفات المحلية، ومقارنة Markdown الأصلي والكتابة فوقه، يجب عليهم استخدام هذه المهارة. تتعامل هذه المهارة فقط مع محتوى النص الرئيسي وتحويل المستندات/ملفات Markdown. يُحظر صراحةً تعليقات المستندات واستيراد الملفات الثنائية ودليل محرك الأقراص السحابي وإدارة الأذونات - حيث يستخدم هذا feishu-cli-storage؛ الحضور وإدارة العمل الأخرى تستخدم feishu-cli-work؛ تستخدم المكونات الديناميكية feishu-cli-visual. طالما أن القصد هو إدراج/الرد/حل تعليق، حتى لو كان الطلب يذكر "مستند"، فلا تستخدم هذه المهارة.
