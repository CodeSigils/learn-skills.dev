Punto di ingresso unificato di Feishu Docs, che copre la lettura e l'analisi di docx/wiki/foglio, la creazione e la modifica di documenti, l'importazione di Markdown, l'esportazione di docx/wiki/foglio in Markdown/PDF/Word/Excel e il file CRUD nativo .md del cloud drive. Gli utenti che necessitano di leggere, riepilogare, creare, aggiungere, sovrascrivere, sostituire o eliminare il contenuto del documento, importare Markdown in Feishu e convertirlo in Sirena/PlantUML/SVG, scaricare immagini o esportare file locali, confrontare e sovrascrivere Markdown nativo devono utilizzare questa abilità. Questa abilità gestisce solo il contenuto del testo principale e la conversione di documenti/file Markdown. È esplicitamente vietato commentare documenti, importare file binari, directory di unità cloud e gestire autorizzazioni: questi utilizzano feishu-cli-storage; presenza e altra gestione del lavoro utilizzano feishu-cli-lavoro; i componenti dinamici utilizzano feishu-cli-visual. Finché l'intento è elencare/rispondere/risolvere un commento, anche se la richiesta menziona "documento", non utilizzare questa abilità.
