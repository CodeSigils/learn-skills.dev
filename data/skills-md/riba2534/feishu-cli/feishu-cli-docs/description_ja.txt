Feishu Docs の統合エントリ ポイント。docx/wiki/sheet の読み取りと分析、ドキュメントの作成と編集、Markdown のインポート、docx/wiki/sheet の Markdown/PDF/Word/Excel へのエクスポート、およびクラウド ドライブのネイティブ .md ファイル CRUD をカバーします。ドキュメントのコンテンツの読み取り、要約、作成、追加、上書き、置換、削除、Markdown の Feishu へのインポートと Mermaid/PlantUML/SVG への変換、画像のダウンロードまたはローカル ファイルのエクスポート、ネイティブ Markdown の比較と上書きを行う必要があるユーザーは、このスキルを使用する必要があります。このスキルは、メイン テキスト コンテンツとドキュメント/Markdown ファイルの変換のみを処理します。ドキュメントのコメント、バイナリ ファイルのインポート、クラウド ドライブ ディレクトリ、およびアクセス許可の管理は明示的に禁止されています。これらは feishu-cli-storage を使用します。勤怠管理およびその他の勤務管理は feishu-cli-work を使用します。動的コンポーネントは feishu-cli-visual を使用します。コメントの一覧表示/返信/解決が目的である限り、リクエストに「ドキュメント」が含まれている場合でも、このスキルを使用しないでください。
