飛文書文檔統一入口，涵蓋docx/wiki/sheet的閱讀與分析、文件的建立與編輯、Markdown導入、docx/wiki/sheet匯出為Markdown/PDF/Word/Excel、雲端磁碟原生.md檔案增刪改查。需要閱讀、總結、建立、追蹤、覆蓋、取代或刪除文件內容、將 Markdown 匯入飛書並轉換為 Mermaid/PlantUML/SVG、下載圖片或匯出本機檔案、比較並覆蓋原生 Markdown 的使用者必須使用此技能。此技能僅處理主要文字內容和文件/Markdown 文件轉換。明確禁止文件註解、二進位檔案匯入、雲端磁碟目錄和權限管理－這些都使用 feishu-cli-storage；考勤等工作管理使用feishu-cli-work；動態元件使用feishu-cli-visual。只要意圖是列出/回應/解決評論，即使要求提到“文件”，也不要使用此技能。
