Feishu Docs einheitlicher Einstiegspunkt, der das Lesen und Analysieren von docx/wiki/sheet, das Erstellen und Bearbeiten von Dokumenten, den Markdown-Import, den docx/wiki/sheet-Export nach Markdown/PDF/Word/Excel und die native .md-Datei CRUD des Cloud-Laufwerks abdeckt. Benutzer, die Dokumentinhalte lesen, zusammenfassen, erstellen, anhängen, überschreiben, ersetzen oder löschen, Markdown in Feishu importieren und in Mermaid/PlantUML/SVG konvertieren, Bilder herunterladen oder lokale Dateien exportieren sowie natives Markdown vergleichen und überschreiben müssen, müssen diese Fähigkeit verwenden. Dieser Skill verarbeitet nur den Haupttextinhalt und die Dokument-/Markdown-Dateikonvertierung. Es ist ausdrücklich verboten für Dokumentkommentare, den Import von Binärdateien, das Cloud-Laufwerksverzeichnis und die Berechtigungsverwaltung – diese verwenden feishu-cli-storage; Anwesenheits- und andere Arbeitsmanagementnutzung Feishu-Cli-Arbeit; Dynamische Komponenten verwenden feishu-cli-visual. Solange die Absicht darin besteht, einen Kommentar aufzulisten/zu beantworten/aufzulösen, auch wenn in der Anfrage „Dokument“ erwähnt wird, verwenden Sie diese Fähigkeit nicht.
