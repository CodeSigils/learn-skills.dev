فقط للقدرات الأساسية للنظام الأساسي لـ Feishu CLI، وليس احتياطيًا عالميًا لجميع طلبات Feishu. يغطي تهيئة التكوين، وتسجيل الدخول إلى OAuth، وإدارة الرمز المميز/الملف الشخصي، وتشخيصات الطبيب، واستعلامات مخطط OpenAPI، وتمرير واجهة برمجة التطبيقات العامة، والبحث العالمي، واستعلامات المستخدم والقسم. عندما يذكر المستخدم تسجيل الدخول إلى Feishu، أو تدفق الجهاز، أو النطاق، أو رمز المستخدم/المستأجر، أو انتهاء الرمز المميز، أو الملف الشخصي، أو الطبيب، 99991672/99991679، أو الاستعلام عن مسار/معلمات/نطاق واجهة برمجة التطبيقات، أو واجهة برمجة التطبيقات الأولية، أو استدعاء OpenAPI غير المغلف، أو البحث في المستندات/الرسائل/التطبيقات، أو الاستعلام عن المستخدمين أو البريد الإلكتروني أو الأقسام، يجب استخدام هذه المهارة. يُحظر صراحةً على نصوص المستندات، أو ملفات محرك الأقراص السحابية، أو الرسائل/المحادثات الجماعية، أو الورقة/الملفات الثنائية، أو السبورة البيضاء/العروض التقديمية، أو التقويم/المهام/الموافقات/الحضور/OKR، أو البريد الإلكتروني، أو الاجتماعات/الدقائق؛ يجب تفويض هذه العمليات التجارية إلى مجال المهارة المقابل. هنا، يشير "البحث الشامل" فقط إلى "البحث في المستندات/الرسائل/التطبيقات"، ولا يشمل الاستعلامات ضمن مجالات الموافقة أو الاجتماع أو البريد الإلكتروني أو مجالات الأعمال الأخرى. إذا كان الطلب يحتوي على موافقة، أو رمز_الموافقة، أو تعريف/مثيل/مهمة الموافقة، فلا تستخدم هذه المهارة أبدًا؛ استخدم feishu-cli-work بدلاً من ذلك. إذا كان الأمر يتضمن اجتماعات فيديو أو محاضر أو ​​تسجيلات أو نصوص، فاستخدم اجتماعات feishu-cli.
