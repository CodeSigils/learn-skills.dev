Feishu CLI의 플랫폼 기본 기능에만 해당되며 모든 Feishu 요청에 대한 보편적인 폴백은 아닙니다. 구성 초기화, OAuth 로그인 및 토큰/프로필 관리, 의사 진단, OpenAPI 스키마 쿼리, 일반 API 통과, 전역 검색, 사용자 및 부서 쿼리를 다룹니다. 사용자가 Feishu 로그인, 장치 흐름, 범위, 사용자/테넌트 토큰, 토큰 만료, 프로필, 의사, 99991672/99991679, API 경로/매개변수/범위 쿼리, 원시 API, 래핑되지 않은 OpenAPI 호출, 문서/메시지/앱 검색 또는 사용자, 이메일 또는 부서 쿼리를 언급하는 경우 이 기술을 사용해야 합니다. 문서 본문, 클라우드 드라이브 파일, 메시지/그룹 채팅, 시트/비트 테이블, 화이트보드/프레젠테이션, 일정/작업/승인/출석/OKR, 이메일 또는 회의/회의록에는 명시적으로 금지됩니다. 이러한 비즈니스 운영은 해당 도메인 기술에 위임되어야 합니다. 여기서 '전체 검색'은 '문서/메시지/앱 검색'만 의미하며 승인, 회의, 이메일 또는 기타 비즈니스 도메인 내의 쿼리는 포함되지 않습니다. 요청에 승인, 승인_코드, 승인 정의/인스턴스/작업이 포함된 경우 이 스킬을 사용하지 마십시오. 대신 feishu-cli-work를 사용하세요. 화상 회의, 회의록, 녹음, 녹취록이 포함된 경우 feishu-cli-meeting을 사용하세요.
