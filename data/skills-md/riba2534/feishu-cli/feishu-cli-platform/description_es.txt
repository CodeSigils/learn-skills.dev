Solo para las capacidades fundamentales de la plataforma de Feishu CLI, no como respaldo universal para todas las solicitudes de Feishu. Cubre la inicialización de la configuración, el inicio de sesión de OAuth y la administración de tokens/perfiles, diagnósticos médicos, consultas de esquema OpenAPI, transferencia de API genérica, búsqueda global y consultas de usuarios y departamentos. Cuando el usuario menciona iniciar sesión en Feishu, flujo de dispositivo, alcance, token de usuario/inquilino, vencimiento del token, perfil, médico, 99991672/99991679, consultar ruta/parámetros/alcance de API, API sin procesar, llamar a OpenAPI sin empaquetar, buscar documentos/mensajes/aplicaciones o consultar usuarios, correo electrónico o departamentos, se debe utilizar esta habilidad. Está explícitamente prohibido para cuerpos de documentos, archivos de disco en la nube, mensajes/chats grupales, Hoja/Bitable, pizarra/presentaciones, calendario/tareas/aprobaciones/asistencia/OKR, correo electrónico o reuniones/actas; Estas operaciones comerciales deben delegarse en la habilidad de dominio correspondiente. Aquí, "búsqueda global" solo se refiere a "buscar documentos/mensajes/aplicaciones", sin incluir consultas dentro de aprobación, reunión, correo electrónico u otros dominios comerciales. Si la solicitud contiene aprobación, código_aprobación, definición/instancia/tarea de aprobación, nunca use esta habilidad; utilice feishu-cli-work en su lugar. Si se trata de videoconferencias, actas, grabaciones o transcripciones, utilice feishu-cli-meetings.
