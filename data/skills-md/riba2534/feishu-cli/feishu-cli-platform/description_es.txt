Solo para las capacidades fundamentales de la plataforma CLI de Feishu, no como respaldo universal para todas las solicitudes de Feishu. Cubre la inicialización de la configuración, el inicio de sesión de OAuth y la gestión de tokens/perfiles, diagnósticos médicos, consultas de esquema OpenAPI, transferencia de API genérica, búsqueda global y consultas de usuarios y departamentos. Cuando los usuarios mencionan iniciar sesión en Feishu, flujo de dispositivo, alcance, token de usuario/inquilino, vencimiento del token, perfil, médico, 99991672/99991679, consultar ruta/parámetros/alcance de API, API sin procesar, llamar a OpenAPI sin empaquetar, buscar documentos/mensajes/aplicaciones o consultar usuarios, correo electrónico o departamentos, se debe utilizar esta habilidad. Está expresamente prohibido su uso para cuerpos de documentos, archivos en la nube, mensajes/chats grupales, Hoja/Bitable, pizarra/presentaciones, calendario/tareas/aprobación/asistencia/OKR, correo electrónico o reuniones/notas; esas operaciones comerciales deben delegarse al dominio correspondiente de Habilidades. Aquí, "búsqueda global" se refiere únicamente a "búsqueda de documentos/mensajes/aplicaciones" y no incluye consultas dentro de aprobación, reunión, correo electrónico u otros dominios comerciales. Si una solicitud involucra aprobación, código_aprobación, definiciones/instancias/elementos pendientes de aprobación, nunca use esta Habilidad; utilice feishu-cli-work en su lugar. Si se trata de videoconferencias, notas, actas, grabaciones o transcripciones, utilice feishu-cli-meetings.
