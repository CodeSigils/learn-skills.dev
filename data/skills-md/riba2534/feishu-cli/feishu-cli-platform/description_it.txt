Solo per le funzionalità fondamentali della piattaforma della CLI di Feishu, non un fallback generico per tutte le richieste di Feishu. Copre l'inizializzazione della configurazione, l'accesso OAuth e la gestione di token/profili, la diagnosi del medico, le query sullo schema OpenAPI, il pass-through API generico, la ricerca globale e le query di utenti e dipartimenti. Quando l'utente menziona l'accesso a Feishu, il flusso del dispositivo, l'ambito, il token utente/tenant, la scadenza del token, il profilo, il medico, 99991672/99991679, l'interrogazione di percorso/parametri/ambito dell'API, API non elaborata, la chiamata di OpenAPI non imballata, la ricerca di documenti/messaggi/app o l'interrogazione di utenti, e-mail o dipartimenti, è necessario utilizzare questa abilità. È esplicitamente vietato utilizzarlo per corpi di documenti, file su disco cloud, messaggi/chat di gruppo, fogli/Bitable, lavagne/presentazioni, calendari/attività/approvazioni/partecipazioni/OKR, e-mail o riunioni/verbali; tali operazioni aziendali dovrebbero essere delegate alla competenza del dominio appropriato. In questo caso, la "ricerca globale" si riferisce solo alla "ricerca di documenti/messaggi/app" e non include query all'interno di ambiti di approvazione, riunione, posta elettronica e altri domini aziendali. Se una richiesta riguarda approvazione, codice_approvazione, definizioni/istanze/attività di approvazione, non utilizzare mai questa competenza; utilizzare invece feishu-cli-work. Se si tratta di riunioni video, verbali, registrazioni o trascrizioni, utilizzare feishu-cli-meetings.
