Feishu CLI のプラットフォームの基本機能のみを対象とし、すべての Feishu リクエストに対する汎用フォールバックではありません。構成の初期化、OAuth ログインとトークン/プロファイル管理、医師の診断、OpenAPI スキーマ クエリ、汎用 API パススルー、グローバル検索、およびユーザーと部門のクエリをカバーします。ユーザーが Feishu へのログイン、デバイス フロー、スコープ、ユーザー/テナント トークン、トークンの有効期限、プロファイル、ドクター、99991672/99991679、API パス/パラメーター/スコープ、生の API のクエリ、ラップされていない OpenAPI の呼び出し、ドキュメント/メッセージ/アプリの検索、またはユーザー、電子メール、部門のクエリについて言及した場合、このスキルを使用する必要があります。ドキュメント本文、クラウド ドライブ ファイル、メッセージ/グループ チャット、シート/ビットテーブル、ホワイトボード/プレゼンテーション、カレンダー/タスク/承認/出席/OKR、電子メール、または会議/議事録では明示的に禁止されています。これらのビジネス操作は、対応するドメインのスキルに委任する必要があります。ここでの「グローバル検索」とは「ドキュメント/メッセージ/アプリの検索」のみを指し、承認、会議、電子メール、またはその他のビジネス ドメイン内のクエリは含まれません。リクエストに承認、承認コード、承認定義/インスタンス/タスクが含まれている場合は、このスキルを決して使用しないでください。代わりにfeishu-cli-workを使用してください。ビデオ会議、議事録、録音、またはトランスクリプトが含まれる場合は、feishu-cli-meetings を使用してください。
