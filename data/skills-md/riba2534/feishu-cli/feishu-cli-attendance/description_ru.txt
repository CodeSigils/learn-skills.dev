Запрос данных о посещаемости Feishu (задача пользователя/статистика пользователя). пользовательская задача проверяет расписание/смены; user‑stats проверяет статистику посещаемости (присутствие/опоздание/ранний уход/уход). Примечание. Поддерживается только токен арендатора; SDK v3.5.3 не принимает токен пользователя. Один запрос может занимать до 31 дня; запросы, превышающие это значение, будут отклонены. Используйте это, когда пользователь запрашивает «запрос посещаемости», «запрос записей учета рабочего времени», «статистику посещаемости» или «сведения о посещаемости».
