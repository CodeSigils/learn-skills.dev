Requête de données de présence Feishu (tâche utilisateur / statistiques utilisateur). les tâches de l'utilisateur vérifient les tâches/équipes d'arrivée ; user‑stats vérifie les statistiques de présence (présence/retard/congé anticipé/congé). Remarque : seul le jeton de locataire est pris en charge ; Le SDK v3.5.3 n'accepte pas le jeton utilisateur. Une seule requête peut durer jusqu'à 31 jours ; les requêtes dépassant ce montant seront rejetées. Utilisez cette option lorsqu'un utilisateur demande « interroger la présence », « interroger les enregistrements de pointage », « statistiques de présence » ou « détails de présence ».
