Feishu attendance data query (user‑task / user‑stats). user‑task queries check‑in tasks/shifts; user‑stats queries attendance statistics (attendance/late/early‑leave/leave). Note: Only Tenant Token is supported; SDK v3.5.3 does not accept User Token. The maximum span for a single query is 31 days; queries exceeding this will be rejected. Used when a user requests “query attendance,” “query check‑in records,” “attendance statistics,” or “attendance details.”
