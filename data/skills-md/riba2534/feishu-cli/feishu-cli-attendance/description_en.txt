Feishu attendance data query (user‑task / user‑stats). user‑task checks clock‑in tasks/shifts; user‑stats checks attendance statistics (attendance/late/early leave/leave). Note: only Tenant Token is supported; SDK v3.5.3 does not accept User Token. A single query can span up to 31 days; queries exceeding this will be rejected. Use this when a user requests “query attendance,” “query clock‑in records,” “attendance statistics,” or “attendance details.”
