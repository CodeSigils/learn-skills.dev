Consulta de datos de asistencia de Feishu (tarea de usuario/estadísticas de usuario). las tareas del usuario verifican las tareas/turnos registrados; user-stats comprueba las estadísticas de asistencia (asistencia/tarde/salida anticipada/salida). Nota: solo se admite el token de inquilino; SDK v3.5.3 no acepta tokens de usuario. Una única consulta puede durar hasta 31 días; Las consultas que superen este límite serán rechazadas. Utilícelo cuando un usuario solicite "consultar asistencia", "consultar registros de asistencia", "estadísticas de asistencia" o "detalles de asistencia".
