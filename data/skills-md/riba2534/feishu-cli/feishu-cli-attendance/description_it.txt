Query sui dati di presenza di Feishu (attività utente/statistiche utente). le attività dell'utente controllano le attività/turni di ingresso; user-stats controlla le statistiche sulle presenze (presenza/ritardo/abbandono anticipato/assenza). Nota: è supportato solo il token tenant; L'SDK v3.5.3 non accetta il token utente. Una singola query può durare fino a 31 giorni; le domande eccedenti questo limite verranno rifiutate. Utilizzalo quando un utente richiede "interroga la partecipazione", "interroga i record delle timbrature", "statistiche sulle presenze" o "dettagli sulle presenze".
