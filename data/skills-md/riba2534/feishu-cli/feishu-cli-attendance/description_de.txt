Feishu-Anwesenheitsdatenabfrage (Benutzeraufgabe/Benutzerstatistik). Benutzeraufgabe prüft Einstempelaufgaben/-schichten; Benutzerstatistiken prüfen Anwesenheitsstatistiken (Anwesenheit/verspäteter/vorzeitiger Verlassen/Verlassen). Hinweis: Es wird nur Tenant Token unterstützt. SDK v3.5.3 akzeptiert kein Benutzertoken. Eine einzelne Abfrage kann bis zu 31 Tage umfassen; Darüber hinausgehende Anfragen werden abgelehnt. Verwenden Sie dies, wenn ein Benutzer „Anwesenheitsabfrage“, „Einstempeldatensätze abfragen“, „Anwesenheitsstatistik“ oder „Anwesenheitsdetails“ anfordert.
