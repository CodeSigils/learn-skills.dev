Запрос Feishu OKR и отчеты о ходе работы. «Список циклов okr» содержит циклы OKR на уровне арендатора; «okr Progress list/create» запрашивает или создает записи о ходе выполнения. Примечание. Поле source_url является обязательным в API, с заполнителем по умолчанию https://www.feishu.cn/okr/progress, который можно изменить. Используйте SDK Okr.ProgressRecord вместе с v1/ periods для прямого HTTP-вызова (v2/cycles не существует). Это используется, когда пользователь запрашивает «циклы запроса OKR», «отчет о ходе выполнения OKR» или «обновление OKR».
