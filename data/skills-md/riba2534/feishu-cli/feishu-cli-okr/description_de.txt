Feishu OKR-Abfrage und Fortschrittsberichte. „OKR-Zyklusliste“ listet OKR-Zyklen auf Mandantenebene auf; „okr progress list/create“ fragt Fortschrittsaufzeichnungen ab oder erstellt sie. Hinweis: Das Feld „source_url“ ist in der API obligatorisch und verfügt über den Standardplatzhalter „https://www.feishu.cn/okr/progress“, der geändert werden kann. Verwenden Sie das SDK Okr.ProgressRecord zusammen mit v1/periods für einen direkten HTTP-Aufruf (v2/cycles existiert nicht). Dies wird verwendet, wenn ein Benutzer „OKR-Zyklen abfragen“, „OKR-Fortschritt melden“ oder „OKR-Aktualisierung“ anfordert.
