Feishu OKR query and progress reporting. The okr cycle list enumerates tenant‑level OKR cycles; the okr progress list/create queries or creates progress records. Note: the source_url field is mandatory in the API, with a default placeholder of https://www.feishu.cn/okr/progress that can be changed. Use the SDK Okr.ProgressRecord together with v1/periods for direct HTTP calls (v2/cycles does not exist). Use when a user requests “query OKR cycle”, “report OKR progress”, or “OKR update”.
