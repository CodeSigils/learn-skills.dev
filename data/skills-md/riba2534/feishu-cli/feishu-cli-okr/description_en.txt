Feishu OKR query and progress reporting. “okr cycle list” lists tenant‑level OKR cycles; “okr progress list/create” queries or creates progress records. Note: the source_url field is mandatory in the API, with a default placeholder of https://www.feishu.cn/okr/progress that can be changed. Use the SDK Okr.ProgressRecord together with v1/periods for a direct HTTP call (v2/cycles does not exist). This is used when a user requests “query OKR cycles,” “report OKR progress,” or “OKR update.”
