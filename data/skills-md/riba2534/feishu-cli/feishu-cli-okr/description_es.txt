Consulta Feishu OKR e informes de progreso. La “lista de ciclos de OKR” enumera los ciclos de OKR a nivel de inquilino; “okr lista de progreso/crear” consulta o crea registros de progreso. Nota: el campo source_url es obligatorio en la API, con un marcador de posición predeterminado de https://www.feishu.cn/okr/progress que se puede cambiar. Utilice el SDK Okr.ProgressRecord junto con v1/periods para una llamada HTTP directa (v2/cycles no existe). Esto se utiliza cuando un usuario solicita "consultar ciclos de OKR", "informar del progreso de OKR" o "actualización de OKR".
