Feishu 인스턴트 메신징 통합 진입점으로, 전송, 회신, 전달, 일괄 전달, 긴급 메시지, 리소스 다운로드를 포함합니다; 채팅 기록 읽기, 이모지 반응(Reactions), 고정(Pins), 그룹 멤버 관리; V2 인터랙티브 카드 구성; WebSocket 이벤트 구독을 지원합니다. 사용자는 메시지 또는 알림 전송, 그룹 채팅 조회 또는 내보내기, 그룹 멤버 관리, 알림/승인/보고서/대시보드/마케팅 프로모션/축제 인사 카드/브랜드 디스플레이/버튼이나 차트가 포함된 손그림 또는 다크 테마 창의적인 Feishu 카드 생성, 메시지 또는 승인 실시간 이벤트 청취, 메시지 첨부파일 처리 시 이 기능을 사용해야 합니다. 대상 캐리어가 Feishu 채팅 또는 그룹 메시지이거나 요청에 msg/chat/card/event, post/interactive, oc_/om_, Reaction, Pin, urgent, 또는 메시지 내 로컬 이미지가 포함되어 있으면 사용자가 CLI를 명시적으로 언급하지 않더라도 이 기능이 트리거되어야 합니다. 이메일 읽기·회신·초안 작성이나 회의 녹음·노트 작성·전사에는 사용하지 마십시오; 이는 각각 feishu-cli-mail 및 feishu-cli-meetings를 사용해야 합니다. 전체 메시지 검색은 feishu-cli-platform을 사용합니다.
