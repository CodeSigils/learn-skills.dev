Feishu instant messaging unified entry point, covering sending, replying, forwarding, combined forwarding, urgent messages and resource downloading, reading chat history, reactions, pins and group member management, constructing V2 interactive cards, and WebSocket event subscription. Users must use this Skill when they need to send messages or notifications, view or export group chats, manage group members, create alerts/approvals/reports/dashboards/marketing promotions/festival greeting cards/brand displays/hand‑drawn or dark‑theme creative Feishu cards with buttons or charts, listen to messages or approval real‑time events, or handle message attachments. As long as the target carrier is Feishu chat or group messages, or the request involves msg/chat/card/event, post/interactive, oc_/om_, Reaction, Pin, urgent, or local images within the message, even if the user does not explicitly mention CLI, this Skill must be triggered. Do not use it for email reading/replying/drafts, nor for meeting recordings, notes, or transcripts; those should use feishu-cli-mail and feishu-cli-meetings respectively. Global message search uses feishu-cli-platform.
