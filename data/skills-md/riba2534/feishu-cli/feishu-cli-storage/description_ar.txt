نقطة دخول موحدة لـ Feishu Cloud Space، تغطي التحميل/التنزيل المحسّن لـ Drive والاستيراد/التصدير غير المتزامن، وعمليات الملفات/الوسائط الأساسية، وعقد قاعدة معارف wiki وإدارة المساحة، وتعليقات المستندات، والمتعاونين، والأذونات العامة. عندما يذكر المستخدمون ملفات محرك الأقراص السحابية، أو المجلدات، أو تقسيم الملفات الكبيرة أو التحميل القابل للاستئناف، أو المهام غير المتزامنة، أو النسخ المتطابق للدليل، أو قاعدة المعرفة، أو wiki، أو الأصول، أو التعليقات، أو أذونات المشاركة، أو المتعاونين، أو الروابط العامة، أو مشاركة كلمات المرور، أو نقل الملكية أو طلبات الأذونات، يجب استخدام هذه المهارة. Wiki ليس سوى جزء من هذه المهارة عند إدارة المساحات أو هياكل العقد أو الأعضاء؛ يُحظر صراحةً استخدامه لقراءة أو تلخيص النص الأساسي لـ Wiki/المستند - يجب أن يستخدم محتوى النص feishu-cli-docs. تستخدم تسجيلات الاجتماعات والملاحظات والنصوص اجتماعات feishu-cli؛ يستخدم البحث منصة feishu-cli.
