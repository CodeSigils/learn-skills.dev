إدخال موحد لـ Feishu Cloud Space، يغطي التحميل والتنزيل المحسّن لـ Drive بالإضافة إلى الاستيراد/التصدير غير المتزامن، وعمليات الملفات/الوسائط الأساسية، وعقد قاعدة معارف wiki وإدارة المساحة، وتعليقات المستندات، والمتعاونين، والأذونات العامة. عندما يذكر المستخدمون ملفات محرك الأقراص السحابية، أو المجلدات، أو تجميع الملفات الكبيرة أو التحميل القابل للاستئناف، أو المهام غير المتزامنة، أو النسخ المتطابق للدليل، أو قاعدة المعرفة، أو wiki، أو الأصول، أو التعليقات، أو الأذونات المشتركة، أو المتعاونين، أو الروابط العامة، أو مشاركة كلمات المرور، أو نقل الملكية أو طلبات الأذونات، فيجب عليهم استخدام هذه المهارة. Wiki جزء من هذه المهارة فقط عند إدارة المساحات أو هياكل العقد أو الأعضاء؛ يُحظر صراحةً استخدامه لقراءة أو تلخيص النص الأساسي لـ Wiki/المستند - يجب التعامل مع محتوى النص باستخدام feishu-cli-docs. تستخدم تسجيلات الاجتماعات والملاحظات والنصوص الحرفية اجتماعات feishu-cli؛ يستخدم البحث منصة feishu-cli.
