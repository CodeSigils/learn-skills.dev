Entrée unifiée Feishu Cloud Space, couvrant le téléchargement et le téléchargement améliorés Drive ainsi que l'importation/exportation asynchrone, les opérations de base sur les fichiers/médias, les nœuds de base de connaissances wiki et la gestion de l'espace, les commentaires sur les documents, les collaborateurs et les autorisations publiques. Lorsque les utilisateurs mentionnent des fichiers cloud, des dossiers, le regroupement de fichiers volumineux ou le téléchargement avec reprise, les tâches asynchrones, la mise en miroir d'annuaires, la base de connaissances, le wiki, les ressources, les commentaires, les autorisations partagées, les collaborateurs, les liens publics, le partage de mots de passe, le transfert de propriété ou les demandes d'autorisation, ils doivent utiliser cette compétence. Le wiki fait partie de cette compétence uniquement lors de la gestion d'espaces, de structures de nœuds ou de membres ; il est explicitement interdit de l'utiliser pour lire ou résumer le corps du texte d'un wiki/document — le contenu du corps doit être géré avec feishu-cli-docs. Les enregistrements de réunions, les notes et les transcriptions textuelles utilisent feishu-cli-meetings ; la recherche utilise la plateforme feishu-cli.
