Voce unificata di Feishu Cloud Space, che copre caricamento/download avanzato per Drive e importazione/esportazione asincrona, operazioni di base su file/media, nodi della knowledge base wiki e gestione dello spazio, commenti sui documenti, collaboratori e autorizzazioni pubbliche. Gli utenti devono utilizzare questa abilità quando menzionano file, cartelle, suddivisioni di file di grandi dimensioni o caricamenti ripristinabili, attività asincrone, mirroring di directory, basi di conoscenza, wiki, risorse, commenti, autorizzazioni di condivisione, collaboratori, collegamenti pubblici, condivisione di password, trasferimento di proprietà o richieste di autorizzazione. Il Wiki è solo una parte di questa Abilità quando si gestiscono spazi, strutture di nodi o membri; è esplicitamente vietato utilizzarlo per leggere o riassumere il testo principale del Wiki/documento, il contenuto principale dovrebbe utilizzare feishu-cli-docs. Le registrazioni, le note e le trascrizioni delle riunioni utilizzano feishu-cli-meeting; le ricerche utilizzano la piattaforma feishu-cli.
