Voce unificata di Feishu Cloud Space, che copre il caricamento e il download avanzati di Drive, nonché l'importazione/esportazione asincrona, operazioni di base su file/media, nodi della knowledge base wiki e gestione dello spazio, commenti sui documenti, collaboratori e autorizzazioni pubbliche. Quando gli utenti menzionano file, cartelle, suddivisione di file di grandi dimensioni o caricamento ripristinabile, attività asincrone, mirroring di directory, base di conoscenza, wiki, risorse, commenti, autorizzazioni condivise, collaboratori, collegamenti pubblici, password di condivisione, trasferimento di proprietà o richieste di autorizzazione, gli utenti devono utilizzare questa competenza. Wiki fa parte di questa Abilità solo quando si gestiscono spazi, strutture di nodi o membri; è esplicitamente vietato utilizzarlo per leggere o riassumere il testo del corpo del Wiki/documento: il contenuto del corpo deve essere gestito con feishu-cli-docs. Le registrazioni, le note e le trascrizioni letterali delle riunioni utilizzano riunioni feishu-cli; la ricerca utilizza la piattaforma feishu-cli.
