Entrada unificada de Feishu Cloud Space, que cubre carga y descarga mejoradas de Drive, así como importación/exportación asincrónica, operaciones básicas de archivos/medios, nodos de base de conocimientos wiki y gestión de espacio, comentarios de documentos, colaboradores y permisos públicos. Cuando los usuarios mencionan archivos, carpetas, fragmentación de archivos grandes o carga reanudable, tareas asincrónicas, duplicación de directorios, base de conocimientos, wiki, activos, comentarios, permisos compartidos, colaboradores, enlaces públicos, intercambio de contraseñas, transferencia de propiedad o solicitudes de permiso, deben usar esta Habilidad. Wiki es parte de esta Habilidad solo cuando se administran espacios, estructuras de nodos o miembros; está explícitamente prohibido usarlo para leer o resumir el texto del cuerpo de un documento/wiki; el contenido del cuerpo debe manejarse con feishu-cli-docs. Las grabaciones de reuniones, notas y transcripciones textuales utilizan feishu-cli-meetings; la búsqueda utiliza feishu-cli-plataforma.
