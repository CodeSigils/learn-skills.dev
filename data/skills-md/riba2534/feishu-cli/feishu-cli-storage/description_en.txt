Feishu Cloud Space unified entry point, covering enhanced upload/download for Drive and asynchronous import/export, basic file/media operations, wiki knowledge‑base nodes and space management, document comments, collaborators, and public permissions. Users must use this Skill when mentioning cloud‑drive files, folders, large‑file chunking or resumable transfer, asynchronous tasks, directory mirroring, knowledge bases, wikis, assets, comments, sharing permissions, collaborators, public links, sharing passwords, ownership transfer, or permission requests. Wiki is considered part of this Skill only when managing spaces, node structures, or members; it is explicitly prohibited to use it to read or summarize Wiki/document body content—use feishu-cli-docs for that. Meeting recordings, notes, and transcripts use feishu-cli-meetings; search uses feishu-cli-platform.
