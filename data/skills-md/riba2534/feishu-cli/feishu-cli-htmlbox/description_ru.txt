В Feishu Cloud Docs рисуйте **анимированные диаграммы/интерактивные диаграммы/панели мониторинга данных**. Magic PenBOX — единственный контейнер в Feishu Docs, который действительно может запускать CSS/JS (песочница iframe). Он может рисовать: весь набор ECharts (линия, гистограмма, круговая диаграмма, радар, рассеяние, тепловая карта, Санки, воронка, датчик, K-линия, коробчатая диаграмма, параллельные координаты, солнечные лучи, древовидная карта, диаграмма, направленная по силе, временные ряды, диаграмма Ганта), реальные карты с линиями полета по широте и долготе, echarts-gl 3D (map3D/3D-полоса/3D-разброс/3D-поверхность), Three.js true 3D-сцены, облака слов, диаграммы с жидкой заливкой, анимация на чистом CSS, частицы Canvas, векторная анимация SVG, вращающиеся информационные панели KPI. Когда пользователь хочет «рисовать диаграммы в Feishu Docs / создавать анимацию / иметь движущиеся диаграммы / интерактивные диаграммы / информационные панели данных / информационную панель / линейную диаграмму / гистограмму / карту / полетную диаграмму / 3D-диаграмму / график взаимосвязей / анимацию потока / ECharts / визуализацию» или создавать **мини-программы интерактивных документов, которые могут вызывать искусственный интеллект / читать-записывать многомерные таблицы / сохранять состояние / получать идентификатор пользователя **, или упоминает «Magic PenBOX / HTML-виджет / создавать диаграммы в Feishu Docs переместить/встроить веб-страницу в Feishu Docs/window.magic», **необходимо использовать** этот навык. Примечание. Только Magic PenBOX может заставить его «двигаться»; доска для рисования (feishu‑cli‑board) Узлы SVG растрируются сервером в статические изображения и не анимируются.
