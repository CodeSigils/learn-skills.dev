Zeichnen Sie in Feishu Cloud Docs **animierte Diagramme/interaktive Diagramme/Daten-Dashboards** – Magic PenBOX ist der einzige Container in Feishu Docs, der CSS/JS (Iframe-Sandbox) wirklich ausführen kann. Es kann Folgendes zeichnen: die gesamte ECharts-Suite (Linie/Balken/Kreis/Radar/Streuung/Heatmap/Sankey/Funnel/Gauge/K-Linie/Boxplot/parallele Koordinaten/Sunburst/Treemap/kraftgesteuertes Diagramm/Zeitreihe/Gantt), echte Karten mit Breitengrad-Längengrad-Fluglinien, Echarts-GL 3D (Map3D/3D-Balken/3D-Streuung/3D-Oberfläche), Three.js echte 3D-Szenen, Wortwolken, flüssige Fülldiagramme, reine CSS-Animationen, Canvas-Partikel, SVG-Vektoranimationen, rollierende KPI-Dashboards. Wenn ein Benutzer „Diagramme in Feishu Docs zeichnen/Animationen erstellen/bewegte Diagramme/interaktive Diagramme/Daten-Dashboards/Dashboard/Liniendiagramm/Balkendiagramm/Karte/Flugliniendiagramm/3D-Diagramm/Beziehungsdiagramm/Flussanimation/ECharts/Visualisierung“ erstellen möchte oder **interaktive Dokument-Miniprogramme erstellen möchte, die KI aufrufen/mehrdimensionale Tabellen lesen/schreiben/Status beibehalten/Benutzeridentität erhalten**, oder „Magic PenBOX/HTML-Widget/Diagramme in Feishu erstellen“ erwähnt Docs Webseite in Feishu Docs / window.magic verschieben/einbetten“, **diese Fähigkeit muss verwendet werden**. Hinweis: Nur Magic PenBOX kann es „bewegen“; Die SVG-Knoten des Zeichenbretts (feishu-cli-board) werden vom Server in statische Bilder gerastert und nicht animiert.
