Видеоконференция Фейшу и специальная запись для заметок Мияо, включающая поиск встреч, протоколы и результаты AI, стенограмму, запись, загрузку медиафайлов заметок Мияо, присоединение/выход из бота встречи и события встречи. Пользователи должны использовать этот навык для поиска исторических собраний по расписанию или времени, получения протоколов собраний/сводок AI, жетонов минут, загрузки записей/видео/стенографических стенограмм, управления ботом собрания или запроса заметок Мияо. Для создания расписаний и поиска времени встреч используется feishu-cli-work.
