Расширенный пакет команд Feishu Drive: загрузка по частям для больших файлов (>20 МБ, автоматический опрос из 3 частей), потоковая загрузка, асинхронный экспорт документов (ярлык уценки / лист + побитный CSV / суб-идентификатор / ограниченный опрос + резюме), асинхронный импорт документов, перемещение файла/папки (автоматический опрос папок), форматированные текстовые комментарии (текст/упоминание_пользователя/ссылка + анализ URL-адреса вики + частичные комментарии), универсальный асинхронный запрос задачи. Используйте, когда пользователь запрашивает «загрузить большой файл», «загрузить файл с диска», «экспортировать в pdf/markdown/xlsx», «импортировать документ в облачный документ», «переместить папку», «добавить комментарий к документу», «@кто-то прокомментировать документ», «комментарий по ссылке вики», «запрос состояния асинхронной задачи», «возобновить задачу диска», «загрузка частями», «диск фейшу», «диск жаворонка». Этот навык сосуществует с устаревшими командами файлов/медиа/комментариев, предлагая расширенные возможности (поддержка пользовательских токенов, асинхронное возобновление, расширенные текстовые комментарии); базовые сценарии по-прежнему доступны через файл/носитель.
