Расширенный набор команд Feishu Drive. Частичная загрузка больших файлов (>20 МБ автоматически в 3 сегментах), потоковая загрузка, асинхронный экспорт документов (ярлык уценки / лист + битовый CSV / суб-идентификатор / ограниченный опрос + резюме), асинхронный импорт документов, перемещение файла/папки (автоматический опрос папки), форматированные текстовые комментарии (текст/упоминание_пользователя/ссылка + анализ URL-адреса вики + частичные комментарии), общий запрос асинхронной задачи. Используйте, когда пользователь запрашивает «загрузить большой файл», «загрузить файл с диска», «экспортировать в формате pdf/markdown/xlsx», «импортировать документ в облачный документ», «переместить папку», «добавить комментарий к документу», «комментарий @someone к документу», «комментарий по ссылке вики», «запросить статус асинхронной задачи», «возобновить задачу диска», «загрузить частями», «диск фейшу», «диск жаворонка». Этот навык сосуществует с устаревшим набором команд для файлов/медиа/комментариев, предлагая более широкие возможности (поддержка пользовательских токенов, асинхронное возобновление, расширенные текстовые комментарии); базовые сценарии по-прежнему используют файл/носитель.
