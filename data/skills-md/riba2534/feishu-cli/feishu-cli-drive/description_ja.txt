フェイシュドライブの強化コマンドセット。大きなファイルの分割アップロード (3 セグメントで自動的に >20 MB)、ストリーミング ダウンロード、非同期ドキュメント エクスポート (マークダウン ショートカット / シート + ビット可能 CSV / サブ ID / 限定ポーリング + 再開)、非同期ドキュメント インポート、ファイル/フォルダー移動 (フォルダー自動ポーリング)、リッチ テキスト コメント (text/mention_user/link + wiki URL 解析 + 部分コメント)、一般的な非同期タスク クエリ。ユーザーが「大きなファイルのアップロード」、「ドライブ ファイルのダウンロード」、「pdf/markdown/xlsx としてエクスポート」、「docx をクラウド ドキュメントにインポート」、「フォルダーの移動」、「ドキュメント コメントの追加」、「ドキュメントへの @someone コメント」、「Wiki リンクからのコメント」、「非同期タスク ステータスのクエリ」、「ドライブ タスクの再開」、「チャンク アップロード」、「フェイシュ ドライブ」、「ラーク ドライブ」をリクエストするときに使用します。このスキルは従来のファイル/メディア/コメント コマンド セットと共存し、より強力な機能 (ユーザー トークン サポート、非同期再開、リッチ テキスト コメント) を提供します。基本的なシナリオでは引き続きファイル/メディアを使用します。
