フェイシュドライブの強化コマンドセット。大きなファイルのチャンクアップロード (20MB を超える自動 3 ステージ)、ストリーミングダウンロード、非同期ドキュメントのエクスポート (マークダウンショートカット / シート + ビット可能な CSV / サブ ID / 制限付きポーリング + 再開)、非同期ドキュメントのインポート、ファイル/フォルダーの移動 (フォルダーの自動ポーリング)、リッチテキスト コメント (text/mention_user/link + wiki URL 解析 + 部分コメント)、ユニバーサル非同期タスク クエリ。ユーザーが「大きなファイルのアップロード」、「ドライブ ファイルのダウンロード」、「pdf/markdown/xlsx にエクスポート」、「docx をクラウド ドキュメントにインポート」、「フォルダーの移動」、「ドキュメント コメントの追加」、「@someone コメント ドキュメント」、「Wiki リンクからのコメント」、「非同期タスク ステータスのクエリ」、「ドライブ タスクの再開」、「チャンク アップロード」、「フェイシュ ドライブ」、「ラーク ドライブ」をユーザーがリクエストするときに使用します。このスキルは古いファイル/メディア/コメント コマンド セットと共存し、より強力な機能 (ユーザー トークン サポート、非同期再開、リッチ テキスト コメント) を提供します。基本的なシナリオでは引き続きファイル/メディアがサポートされます。
