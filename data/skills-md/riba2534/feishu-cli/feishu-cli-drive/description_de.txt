Feishu Drive Enhanced Command Group. Gestückelter Upload für große Dateien (>20 MB automatisch, 3-stufig), Streaming-Download, asynchroner Dokumentenexport (Markdown-Schnellpfad/Blatt+bitable CSV/Sub-ID/begrenzte Abfrage + Lebenslauf), asynchroner Dokumentenimport, Datei-/Ordnerverschiebung (automatische Ordnerabfrage), Rich-Text-Kommentare (text/mention_user/link + Wiki-URL-Analyse + Teilkommentare), universelle asynchrone Aufgabenabfrage. Wird verwendet, wenn der Benutzer „Große Datei hochladen“, „Laufwerksdatei herunterladen“, „Nach PDF/Markdown/XLSX exportieren“, „DOCX in Cloud-Dokument importieren“, „Ordner verschieben“, „Dokumentkommentar hinzufügen“, „@Benutzerkommentar zum Dokument“, „Kommentar von Wiki-Link“, „Asynchronen Aufgabenstatus abfragen“, „Aufgabenfortsetzung fortsetzen“, „Chunked Upload“, „Feishu-Laufwerk“, „Lark-Laufwerk“ anfordert. Dieser Skill existiert neben der älteren Befehlsgruppe „Datei/Medien/Kommentar“ und bietet stärkere Funktionen (Benutzer-Token-Unterstützung, asynchroner Lebenslauf, Rich-Text-Kommentare); In grundlegenden Szenarien können weiterhin Dateien/Medien verwendet werden.
