Ensemble de commandes amélioré Feishu Drive. Téléchargement fragmenté de fichiers volumineux (> 20 Mo automatiquement en 3 segments), téléchargement en continu, exportation de documents asynchrone (raccourci de démarque / feuille + csv bitable / sous-id / interrogation délimitée + CV), importation de documents asynchrone, déplacement de fichier/dossier (interrogation automatique de dossier), commentaires en texte enrichi (texte/mention_user/lien + analyse d'URL wiki + commentaires partiels), requête de tâche asynchrone générique. À utiliser lorsque l'utilisateur demande « télécharger un fichier volumineux », « télécharger un fichier de lecteur », « exporter au format pdf/markdown/xlsx », « importer un docx vers un document cloud », « déplacer un dossier », « ajouter un commentaire de document », « un commentaire de @quelqu'un sur le doc », « un commentaire à partir d'un lien wiki », « interroger l'état de la tâche asynchrone », « reprendre une tâche de lecteur », « télécharger en morceaux », « lecteur feishu », « lecteur alouette ». Cette compétence coexiste avec l'ancien jeu de commandes fichier/média/commentaire, offrant des fonctionnalités plus puissantes (prise en charge des jetons utilisateur, reprise asynchrone, commentaires en texte enrichi) ; les scénarios de base utilisent toujours un fichier/média.
