Только для обычных электронных таблиц Sheet и многомерных таблиц Bitable/Base, а не для универсальной точки входа для всех данных или запросов JSON. Используйте его, когда пользователям необходимо читать/записывать ячейки, импортировать/экспортировать таблицы, устанавливать стили/фильтровать представления/условия/раскрывающиеся списки/плавающие изображения или управлять таблицами, полями, записями, представлениями, ролями, соавторами, панелями мониторинга, формами, рабочими процессами и агрегированием данных в многомерных таблицах; его также необходимо использовать при описании сценария --asbot cron/unattended Bitable. Явно запрещено для разрешений документов/соавторов, подписок на сообщения/события и развернутой общей сквозной передачи OpenAPI; они соответственно используют feishu-cli-storage, feishu-cli-messaging и feishu-cli-платформу. Таблицы уценки в документах используют feishu-cli-docs; Для отображения диаграммы данных используется feishu-cli-visual.
