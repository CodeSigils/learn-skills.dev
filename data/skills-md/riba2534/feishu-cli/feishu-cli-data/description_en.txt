Used only for regular spreadsheets (Sheet) and multidimensional tables (Bitable/Base); it is not a universal entry point for all data or JSON requests. It should be used when the user needs to read/write cells, import/export tables, set styles/filter views/conditions/drop‑down boxes/floating images, or operate on multidimensional tables’ tables, fields, records, views, roles, collaborators, dashboards, forms, workflows, and data aggregations; it must also be used when covering the --as bot cron/unattended Bitable scenario. It is explicitly prohibited for document permissions/collaborators, message/event subscriptions, and unwrapped OpenAPI generic pass‑through; these use feishu-cli-storage, feishu-cli-messaging, and feishu-cli-platform respectively. Markdown tables in documents use feishu-cli-docs; data chart displays use feishu-cli-visual.
