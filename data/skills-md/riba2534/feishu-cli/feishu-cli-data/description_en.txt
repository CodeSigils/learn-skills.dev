Only for regular spreadsheet Sheet and multidimensional table Bitable/Base, not a universal entry point for all data or JSON requests. Use it when users need to read/write cells, import/export tables, set styles/filter views/conditions/drop‑down lists/floating images, or operate tables, fields, records, views, roles, collaborators, dashboards, forms, workflows, and data aggregation in multidimensional tables; it must also be used when covering the --as bot cron/unattended Bitable scenario. Explicitly prohibited for document permissions/collaborators, message/event subscriptions, and unwrapped OpenAPI generic pass‑through; they respectively use feishu-cli-storage, feishu-cli-messaging, and feishu-cli-platform. Markdown tables in documents use feishu-cli-docs; data chart display uses feishu-cli-visual.
