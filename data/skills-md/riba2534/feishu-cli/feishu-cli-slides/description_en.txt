Feishu Slides presentations. `slides create` creates a presentation from an XML template (POST /open-apis/slides_ai/v1/xml_presentations); `slides media‑upload` uploads media (drive upload_all + parent_type=slide_file, single file ≤ 20 MB, no chunking support). Use when the user requests “create Feishu PPT,” “upload slides,” “presentation,” or “slides.” Not applicable: complex slide editing (block insert/replace with complex semantics) is not yet implemented; use lark‑slides.
