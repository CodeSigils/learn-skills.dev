Презентации Фейшу Слайды. `slides create` создает презентацию из шаблона XML (POST/open-apis/slides_ai/v1/xml_presentations); `slides media‑upload` загружает медиафайлы (driveupload_all+parent_type=slide_file, один файл<20 МБ, без поддержки фрагментирования). Используйте, когда пользователь запрашивает «создать Feishu PPT», «загрузить слайды», «презентацию» или «слайды». Не применимо: сложное редактирование слайдов (вставка/замена блоков со сложной семантикой) пока не реализовано; используйте жаворонковые слайды.
