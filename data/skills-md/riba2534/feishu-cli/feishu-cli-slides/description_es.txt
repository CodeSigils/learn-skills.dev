Presentaciones de diapositivas Feishu. `slides create` crea una presentación a partir de una plantilla XML (POST/open-apis/slides_ai/v1/xml_presentations); `slides media‑upload` carga medios (driveupload_all+parent_type=slide_file, archivo único≤20 MB, sin soporte de fragmentación). Úselo cuando el usuario solicite "crear Feishu PPT", "cargar diapositivas", "presentación" o "diapositivas". No aplicable: la edición de diapositivas compleja (insertar/reemplazar bloques con semántica compleja) aún no está implementada; utilice toboganes de alondra.
