Feishu リアルタイム イベント サブスクリプション (WebSocket)。 「イベント リスト」には、サポートされている EventKey が表示されます。 「イベント スキーマ」はイベントのペイロード/スコープを示します。 「event Consumer」は、長時間接続のサブスクリプションを開始し、イベント ストリームを NDJSON として標準出力に書き込みます (ブロッキング、1 つのプロセスが 1 つの EventKey をサブスクライブします)。 「event status」には、ローカル マシン上のアクティブな消費プロセスが表示されます。 `event stop` は PID / EventKey / --all による消費を停止します。 22 個以上のイベントキー (IM メッセージの受信/読み取り/取り消し/反応、グループ メンバーの変更、連絡先従業員の変更、カレンダーの変更、クラウド ドライブのタイトル/コラボレーター、承認インスタンスとタスク、VC ミーティングの開始/終了) をサポートします。切断後の再接続と複数の EventKey の並列サブスクリプションをサポートします。ユーザーが「Feishu イベントのリッスン」、「メッセージ イベントをリアルタイムで受信」、「承認コールバックのサブスクライブ」、「イベント ストリーム」、「WebSocket の長時間接続のリスニング」、「イベントの消費」、「イベント リスト / スキーマ / ステータス / 停止」、または「AI エージェント ボットのリアルタイム応答」をリクエストするときに使用されます。注: この機能はサブスクリプションのみを処理します。イベント Webhook ビジネス ロジックの処理 (Feishu メッセージへのプッシュ / Bitable への書き込み) は、feishu-cli-msg / feishu-cli-bitable で実行する必要があります。
