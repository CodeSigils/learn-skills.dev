飛書即時事件訂閱（WebSocket）。 `event list`顯示支援的EventKeys；「事件模式」顯示事件負載/範圍； `event Consumer`啟動長連線訂閱，將事件流以NDJSON的形式寫入 stdout（阻塞，一個程序訂閱一個EventKey）；`event status`顯示本地機器上活躍的消費過程； `event stop` / Event / 1/9 的消費程序。支援22+事件鍵（IM訊息接收/讀取/撤銷/反應、群組成員變更、聯絡人員工變更、行事曆變更、雲端磁碟標題/協作者、審核實例和任務、VC會議開始/結束）。支援斷線重連，支援多個EventKey並行訂閱。當使用者要求「監聽飛書事件」、「即時接收訊息事件」、「訂閱審批回呼」、「事件流」、「WebSocket長連線監聽」、「事件消費」、「事件清單/架構/狀態/停止」、「AI Agent即時回應」時使用。注意：此功能僅處理訂閱；處理事件webhook業務邏輯（推送到飛書訊息/寫入Bitable）應該使用feishu-cli-msg / feishu-cli-bitable來完成。
