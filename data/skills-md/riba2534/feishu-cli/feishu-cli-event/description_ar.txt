الاشتراك في حدث Feishu في الوقت الفعلي (WebSocket). تعرض "قائمة الأحداث" مفاتيح الأحداث المدعومة؛ يُظهر "مخطط الحدث" حمولة/نطاق الحدث؛ يبدأ "استهلاك الحدث" اشتراكًا طويل الاتصال، ويكتب دفق الحدث إلى stdout كـ NDJSON (الحظر، عملية واحدة تشترك في مفتاح حدث واحد)؛ تعرض "حالة الحدث" عمليات الاستهلاك النشطة على الجهاز المحلي؛ "إيقاف الحدث" يوقف الاستهلاك بواسطة PID / EventKey / --all. يدعم أكثر من 22 مفتاحًا للحدث (استلام رسائل المراسلة الفورية/قراءتها/إبطالها/رد فعلها، وتغييرات أعضاء المجموعة، وتغييرات موظف الاتصال، وتغييرات التقويم، وعناوين محرك الأقراص السحابية/المتعاونين، ومثيلات الموافقة والمهام، وبدء/نهاية اجتماع VC). يدعم إعادة الاتصال بعد قطع الاتصال والاشتراك المتوازي لمفاتيح الأحداث المتعددة. يُستخدم عندما يطلب المستخدم "الاستماع إلى أحداث Feishu"، أو "تلقي أحداث الرسائل في الوقت الفعلي"، أو "الاشتراك في عمليات رد الاتصال للموافقة"، أو "تدفق الحدث"، أو "الاستماع إلى اتصال WebSocket الطويل"، أو "استهلاك الحدث"، أو "قائمة الأحداث / المخطط / الحالة / التوقف"، أو "الاستجابة في الوقت الفعلي لـ AI Agent bot". ملاحظة: هذه الإمكانية تعالج الاشتراك فقط؛ يجب أن تتم معالجة منطق أعمال webhook للحدث (الدفع إلى رسائل Feishu / الكتابة إلى Bitable) باستخدام feishu-cli-msg / feishu-cli-bitable.
