飞书实时事件订阅（WebSocket）。 `event list`显示支持的EventKeys； “事件模式”显示事件负载/范围； `event Consumer`启动长连接订阅，将事件流以NDJSON的形式写入stdout（阻塞，一个进程订阅一个EventKey）； `event status`显示本地机器上活跃的消费进程； `event stop` 停止 PID / EventKey / --all 的消耗。支持22+事件键（IM消息接收/读取/撤销/反应、群组成员变更、联系人员工变更、日历变更、云盘标题/协作者、审批实例和任务、VC会议开始/结束）。支持断线重连，支持多个EventKey并行订阅。当用户请求“监听飞书事件”、“实时接收消息事件”、“订阅审批回调”、“事件流”、“WebSocket长连接监听”、“事件消费”、“事件列表/架构/状态/停止”、“AI Agent实时响应”时使用。注意：此功能仅处理订阅；处理事件webhook业务逻辑（推送到飞书消息/写入Bitable）应该使用feishu-cli-msg / feishu-cli-bitable来完成。
