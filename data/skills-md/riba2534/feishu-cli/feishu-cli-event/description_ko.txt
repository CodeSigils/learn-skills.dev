Feishu 실시간 이벤트 구독(WebSocket). '이벤트 목록'에는 지원되는 EventKey가 표시됩니다. '이벤트 스키마'는 이벤트 페이로드/범위를 보여줍니다. '이벤트 소비'는 장기 연결 구독을 시작하여 이벤트 스트림을 NDJSON으로 stdout에 기록합니다(차단, 하나의 프로세스가 하나의 EventKey를 구독함). '이벤트 상태'는 로컬 머신의 활성 소비 프로세스를 보여줍니다. `event stop`은 PID, EventKey 또는 `--all`에 의한 소비를 중지합니다. 22개 이상의 EventKeys(IM 메시지 수신/읽기/회수/반응, 그룹 구성원 변경, 연락처 직원 변경, 일정 변경, 클라우드 드라이브 제목/협력자, 승인 인스턴스 및 작업, VC 회의 시작/종료)를 지원합니다. 여러 EventKeys의 연결 끊김 및 병렬 구독 후 다시 연결을 지원합니다. 사용자가 "Feishu 이벤트 듣기", "실시간으로 메시지 이벤트 수신", "승인 콜백 구독", "이벤트 스트림", "WebSocket 장기 연결 듣기", "이벤트 소비", "이벤트 목록/스키마/상태/중지" 또는 "AI 에이전트 봇 실시간 응답"을 요청할 때 사용됩니다. 참고: 이 기능은 구독만 처리합니다. 이벤트 웹훅 비즈니스 로직 처리(Feishu 메시지 푸시/Bitable 쓰기)는 feishu-cli-msg / feishu-cli-bitable을 사용하여 수행해야 합니다.
