Invocazione grezza di Feishu OpenAPI. "api GET/POST/PUT/DELETE/PATCH <percorso>" chiama direttamente qualsiasi endpoint Feishu OpenAPI, coprendo le interfacce di cui feishu‑cli non ha ancora eseguito il wrapper (allineate con le funzionalità API di lark‑cli). Supporta `--params` (query), `--data` (corpo JSON), `--data-file` (lettura del corpo da un file), `--as auto|user|bot` (identità), `--dry-run` (anteprima), `-o` (download binario), `--format` e `--jq`. Usalo quando un utente richiede "chiama X API", "raw chiama Feishu endpoint", "come chiamare un'interfaccia non protetta da feishu‑cli", "raw API", "invia una richiesta con il comando api" o "scarica Feishu media/file binario". Non applicabile: controlla solo lo schema senza invocarlo (usa `feishu-cli schema`); scenari ad alta frequenza che dispongono già di comandi dedicati (utilizzare il corrispondente `feishu-cli <module>`).
