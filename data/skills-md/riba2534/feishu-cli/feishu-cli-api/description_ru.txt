Необработанный вызов Feishu OpenAPI. `api GET/POST/PUT/DELETE/PATCH <path>` напрямую вызывает любую конечную точку Feishu OpenAPI, охватывая интерфейсы, которые feishu‑cli еще не обернули (в соответствии с возможностями API Lark‑cli). Поддерживает `--params` (запрос), `--data` (тело JSON), `--data-file` (чтение тела из файла), `--as auto|user|bot` (идентификатор), `--dry-run` (предварительный просмотр), `-o` (двоичная загрузка), `--format` и `--jq`. Используйте его, когда пользователь запрашивает «вызов X API», «необработанный вызов конечной точки Feishu», «как вызвать интерфейс, не обернутый feishu‑cli», «необработанный API», «отправить запрос с помощью команды api» или «загрузить двоичный файл мультимедиа/файла Feishu». Неприменимо: только проверка схемы без вызова (используйте схему feishu-cli); высокочастотные сценарии, в которых уже есть выделенные команды (используйте соответствующий `feishu-cli <module>`).
