Llamada sin formato de Feishu OpenAPI. `api GET/POST/PUT/DELETE/PATCH <ruta>` invoca directamente cualquier punto final Feishu OpenAPI, cubriendo interfaces que feishu‑cli aún no ha ajustado (alineándose con las capacidades API de lark‑cli). Admite `--params` (consulta), `--data` (cuerpo JSON), `--data-file` (leer cuerpo del archivo), `--as auto|user|bot` (identidad), `--dry-run` (vista previa), `-o` (descarga binaria), `--format` y `--jq`. Se utiliza cuando el usuario solicita "llamar a X API", "llamar sin formato a la interfaz Feishu", "cómo llamar a una interfaz no empaquetada por feishu-cli", "api sin formato", "enviar solicitud con el comando api" o "descargar medios/archivos binarios de Feishu". No aplicable: solo verificar el esquema sin llamar (use `feishu-cli esquema`); escenarios de alta frecuencia que ya tienen comandos dedicados (use el `feishu‑cli <módulo>` correspondiente).
