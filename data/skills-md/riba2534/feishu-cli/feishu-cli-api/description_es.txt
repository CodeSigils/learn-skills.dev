Invocación sin formato de Feishu OpenAPI. `api GET/POST/PUT/DELETE/PATCH <ruta>` llama directamente a cualquier punto final Feishu OpenAPI, cubriendo interfaces que feishu‑cli aún no ha ajustado (alineadas con las capacidades API de lark‑cli). Admite `--params` (consulta), `--data` (cuerpo JSON), `--data-file` (leer el cuerpo de un archivo), `--as auto|user|bot` (identidad), `--dry-run` (vista previa), `-o` (descarga binaria), `--format` y `--jq`. Úselo cuando un usuario solicite "llamar a X API", "llamar sin formato al punto final de Feishu", "cómo llamar a una interfaz no empaquetada por feishu‑cli", "API sin procesar", "enviar una solicitud con el comando api" o "descargar medios/archivos binarios de Feishu". No aplicable: solo verificar el esquema sin invocarlo (use `esquema feishu-cli`); escenarios de alta frecuencia que ya tienen comandos dedicados (use el `feishu-cli <módulo>` correspondiente).
