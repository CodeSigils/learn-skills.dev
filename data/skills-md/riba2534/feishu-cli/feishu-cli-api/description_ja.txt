Feishu OpenAPI の生の呼び出し。 `api GET/POST/PUT/DELETE/PATCH <path>` は、Feishu OpenAPI エンドポイントを直接呼び出し、feishu‑cli がまだラップしていないインターフェイスをカバーします (lark‑cli の API 機能に合わせて)。 `--params` (クエリ)、`--data` (JSON 本文)、`--data-file` (ファイルから本文を読み取る)、`--as auto|user|bot` (ID)、`--dry-run` (プレビュー)、`-o` (バイナリ ダウンロード)、`--format`、および `--jq` をサポートします。ユーザーが「X API の呼び出し」、「Feishu エンドポイントの生の呼び出し」、「feishu-cli でラップされていないインターフェイスを呼び出す方法」、「生の API」、「API コマンドでリクエストを送信」、または「Feishu メディア/ファイル バイナリのダウンロード」をリクエストする場合に使用します。該当なし: スキーマを呼び出さずにチェックのみを行う (「feishu-cli スキーマ」を使用)。専用コマンドがすでに存在する高頻度シナリオ (対応する `feishu-cli <module>` を使用します)。
