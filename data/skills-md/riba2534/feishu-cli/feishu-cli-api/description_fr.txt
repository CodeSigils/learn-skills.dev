Invocation brute de Feishu OpenAPI. `api GET/POST/PUT/DELETE/PATCH <path>` appelle directement n'importe quel point de terminaison Feishu OpenAPI, couvrant les interfaces que feishu-cli n'a pas encore encapsulées (alignées sur les capacités API de lark-cli). Prend en charge `--params` (requête), `--data` (corps JSON), `--data-file` (lire le corps à partir d'un fichier), `--as auto|user|bot` (identité), `--dry-run` (aperçu), `-o` (téléchargement binaire), `--format` et `--jq`. Utilisez-le lorsqu'un utilisateur demande « appeler l'API X », « appeler le point de terminaison Feishu brut », « comment appeler une interface non enveloppée par feishu-cli », « API brute », « envoyer une requête avec la commande api » ou « télécharger le binaire média/fichier Feishu ». Non applicable : vérifier uniquement le schéma sans l'invoquer (utilisez le « schéma feishu-cli ») ; scénarios haute fréquence qui ont déjà des commandes dédiées (utilisez le `feishu-cli <module>` correspondant).
