飞书OpenAPI原始调用。 `api GET/POST/PUT/DELETE/PATCH <path>` 直接调用任何飞书 OpenAPI 端点，覆盖 feishu-cli 尚未封装的接口（与 lark-cli 的 API 功能保持一致）。支持`--params`（查询），`--data`（JSON正文），`--data-file`（从文件读取正文），`--as auto|user|bot`（身份），`--dry-run`（预览），`-o`（二进制下载），`--format`和`--jq`。当用户请求“调用 X API”、“原始调用飞书端点”、“如何调用未由 feishu-cli 封装的接口”、“原始 API”、“使用 api 命令发送请求”或“下载飞书媒体/文件二进制文件”时，请使用它。不适用：只检查schema，不调用（使用`feishu-cli schema`）；已经有专用命令的高频场景（使用相应的 `feishu-cli <module>`）。
