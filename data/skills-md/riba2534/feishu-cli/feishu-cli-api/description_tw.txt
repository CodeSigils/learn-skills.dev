飛書OpenAPI原始呼叫。 `api GET/POST/PUT/DELETE/PATCH <path>` 直接呼叫任何飛書 OpenAPI 端點，覆寫 feishu-cli 尚未封裝的介面（與 lark-cli 的 API 功能保持一致）。支援`--params`（查詢），`--data`（JSON正文），`--data-file`（從檔案讀取正文），`--as auto|user|bot`（身分），`--dry-run`（預覽），`-o`（二進位下載），`--format`和`--jq`。當使用者要求「呼叫 X API」、「原始呼叫飛書端點」、「如何呼叫未由 feishu-cli 封裝的介面」、「原始 API」、「使用 api 指令傳送請求」或「下載飛書媒體/檔案二進位檔案」時，請使用它。不適用：只檢查schema，不呼叫（使用`feishu-cli schema`）；已經有專用指令的高頻場景（使用對應的 `feishu-cli <module>`）。
