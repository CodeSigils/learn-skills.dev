Feishu OpenAPI-Rohaufruf. „api GET/POST/PUT/DELETE/PATCH <path>“ ruft direkt jeden Feishu-OpenAPI-Endpunkt auf und deckt Schnittstellen ab, die feishu-cli noch nicht umschlossen hat (ausgerichtet auf die API-Funktionen von lark-cli). Unterstützt „--params“ (Abfrage), „--data“ (JSON-Text), „--data-file“ (Text aus einer Datei lesen), „--as auto|user|bot“ (Identität), „--dry-run“ (Vorschau), „-o“ (binärer Download), „--format“ und „--jq“. Verwenden Sie es, wenn ein Benutzer „X-API aufrufen“, „Rohaufruf des Feishu-Endpunkts“, „Wie rufe ich eine Schnittstelle auf, die nicht von Feishu-Cli umschlossen ist“, „Roh-API“, „Anfrage mit dem API-Befehl senden“ oder „Feishu-Medien/Datei-Binärdatei herunterladen“ anfordert. Nicht anwendbar: Nur das Schema überprüfen, ohne es aufzurufen (verwenden Sie „feishu-cli schema“); Hochfrequenzszenarien, die bereits über dedizierte Befehle verfügen (verwenden Sie das entsprechende „feishu-cli <module>“).
