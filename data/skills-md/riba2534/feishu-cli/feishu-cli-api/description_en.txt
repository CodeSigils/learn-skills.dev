Feishu OpenAPI raw invocation. `api GET/POST/PUT/DELETE/PATCH <path>` directly calls any Feishu OpenAPI endpoint, covering interfaces that feishu‑cli has not yet wrapped (aligned with lark‑cli’s API capabilities). Supports `--params` (query), `--data` (JSON body), `--data-file` (read body from a file), `--as auto|user|bot` (identity), `--dry-run` (preview), `-o` (binary download), `--format`, and `--jq`. Use it when a user requests “call X API”, “raw call Feishu endpoint”, “how to call an interface not wrapped by feishu‑cli”, “raw API”, “send a request with the api command”, or “download Feishu media/file binary”. Not applicable: only checking the schema without invoking (use `feishu-cli schema`); high‑frequency scenarios that already have dedicated commands (use the corresponding `feishu-cli <module>`).
