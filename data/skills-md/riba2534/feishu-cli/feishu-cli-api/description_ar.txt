استدعاء Feishu OpenAPI الخام. `api GET/POST/PUT/DELETE/PATCH <path>` يستدعي مباشرة أي نقطة نهاية Feishu OpenAPI، ويغطي الواجهات التي لم يقم feishu‑cli بتغليفها بعد (تتماشى مع إمكانيات واجهة برمجة التطبيقات الخاصة بـ lark‑cli). يدعم `--params` (استعلام)، و`--data` (نص JSON)، و`--data-file` (قراءة النص من ملف)، و`--as auto|user|bot` (الهوية)، و`--dry-run` (معاينة)، و`-o` (تنزيل ثنائي)، و`--format`، و`--jq`. استخدمه عندما يطلب المستخدم "استدعاء X API"، أو "نقطة نهاية Feishu للاتصال الأولي"، أو "كيفية الاتصال بواجهة غير مغلفة بواسطة feishu‑cli"، أو "API الخام"، أو "إرسال طلب باستخدام أمر api"، أو "تنزيل ملف ثنائي/وسائط Feishu". غير قابل للتطبيق: التحقق فقط من المخطط دون استدعاءه (استخدم `مخطط feishu-cli`)؛ السيناريوهات عالية التردد التي تحتوي بالفعل على أوامر مخصصة (استخدم `feishu-cli <module>` المقابل).
