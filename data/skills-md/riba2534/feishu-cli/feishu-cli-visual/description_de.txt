Benutzer, die Whiteboard/Whiteboard, Architekturdiagramme, Flussdiagramme, Schwungrad, Fischgrätendiagramme, Straßenkarten, Poster, Illustrationen, SVG/Mermaid, Datendiagramme oder Dashboards benötigen; Wer erstellt Folien/PPT? Animierte ECharts/maps/3D/window.magic-Komponenten einbetten; oder HTML-Anwendungen mit Miaoda/Miaoda/spark veröffentlichen, müssen diesen Skill verwenden. Nachrichtenkarten werden von feishu‑cli‑messaging erstellt und versendet; Der Import von Markdown-Diagrammen wird von feishu-cli-docs übernommen.
