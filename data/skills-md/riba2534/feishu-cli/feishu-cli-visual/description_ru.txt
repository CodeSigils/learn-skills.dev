Единая точка входа для визуализации и презентации Feishu, отвечающая за выбор подходящего носителя и покрытия доски, слайдов, динамических компонентов MiaoBiBOX, HTML-приложений Miaoda и спецификаций дизайна унифицированной визуализации данных. Когда пользователям требуется доска, архитектурная диаграмма, блок-схема, маховик, рыбья кость, дорожная карта, плакат, иллюстрация, SVG/Mermaid, диаграмма данных или информационная панель, создание слайдов/PPT, встраивание анимированных компонентов ECharts/maps/3D/window.magic или публикация HTML-приложения с помощью Miaoda/Miaoda/spark, необходимо использовать этот навык. Карточки сообщений создаются и отправляются с помощью feishu-cli-messaging; Импорт диаграмм уценки выполняется с помощью feishu-cli-docs.
