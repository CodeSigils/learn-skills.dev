Единая точка входа для визуализации и презентации Feishu, отвечающая за выбор подходящего носителя и покрытия доски, слайдов, динамических компонентов MiaobiBOX, HTML-приложений Miaoda и спецификаций дизайна унифицированной визуализации данных. Пользователи, которым нужна доска/доска, архитектурные диаграммы, блок-схемы, маховик, рыбья кость, дорожные карты, плакаты, иллюстрации, SVG/Mermaid, диаграммы данных или информационные панели; кто создает слайды/PPT; встраивать анимированные компоненты ECharts/maps/3D/window.magic; или публиковать HTML-приложения с помощью Miaoda/Miaoda/spark, необходимо использовать этот навык. Карточки сообщений создаются и отправляются с помощью feishu-cli-messaging; Импорт диаграммы уценки осуществляется с помощью feishu‑cli‑docs.
