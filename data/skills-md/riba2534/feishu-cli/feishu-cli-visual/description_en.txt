Feishu visualization and presentation unified entry point, responsible for selecting the appropriate medium and covering whiteboard, Slides, Miaobi BOX dynamic components, Miaoda HTML applications, and unified data visualization design specifications. Users who need whiteboard/whiteboard, architecture diagrams, flowcharts, flywheel, fishbone, roadmaps, posters, illustrations, SVG/Mermaid, data charts or dashboards; who create Slides/PPT; embed animated ECharts/maps/3D/window.magic components; or publish HTML applications with Miaoda/Miaoda/spark must use this Skill. Message cards are constructed and sent by feishu‑cli‑messaging; Markdown chart import is handled by feishu‑cli‑docs.
