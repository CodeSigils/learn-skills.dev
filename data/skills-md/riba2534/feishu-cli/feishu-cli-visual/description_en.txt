Feishu Visualization and Presentation Unified Entry point, responsible for selecting the appropriate medium and covering whiteboards, Slides, Miaobi BOX dynamic components, Miaoda HTML applications, and the unified data visualization design specification. When users need whiteboards, architecture diagrams, flowcharts, flywheels, fishbone diagrams, roadmaps, posters, illustrations, SVG/Mermaid, data charts or dashboards, create Slides/PPT, embed animated ECharts/maps/3D/window.magic components, or publish HTML applications with Miaoda/Miaoda/spark, this Skill must be used. Message cards are constructed and sent by feishu-cli-messaging; Markdown chart imports are performed by feishu-cli-docs.
