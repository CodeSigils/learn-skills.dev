قم ببناء بطاقات Feishu V2.0 التفاعلية الجميلة والغنية بالعناصر. يدعم أكثر من 20 مكونًا بما في ذلك اللوحات القابلة للطي والتخطيطات متعددة الأعمدة والمخططات وعلامات الألوان ومجموعات الأزرار وبطاقات المستخدم وتحديثات البث. يتضمن 7 قوالب سيناريو مدمجة (الإخطار/تقرير النجاح/التنبيه/الموافقة/لوحة معلومات البيانات/ملخص المقالة/تدفق الذكاء الاصطناعي) ومعايير الألوان/التخطيط. يُستخدم عندما يطلب المستخدم "إرسال بطاقة"، أو "إرسال إشعار"، أو "إنشاء تنبيه"، أو "إرسال تقرير"، أو "إنشاء موافقة"، أو "إنشاء لوحة معلومات"، أو "تجميل الرسالة"، أو "بطاقة تفاعلية"، أو "بطاقة v2"، أو "رسالة ذات مخطط"، أو "رسالة ذات أزرار"، أو "رسالة ذات لوحة قابلة للطي"، أو "بطاقة Feishu"، أو "بطاقة Lark"، أو "بطاقة البناء". حتى لو قال المستخدم فقط "أرسل رسالة لإخبار XX"، طالما أن المحتوى له بنية (حقول / روابط / مخططات / حالة متعددة)، فيجب استخدام هذه المهارة لإنشاء بطاقة بدلاً من النص العادي. تتم كتابة JSON الناتج إلى /tmp/<name>-card.json ثم يتم إرساله عبر feishu-cli-msg مع --msg-type تفاعلي (تستخدم الرسالة رمز التطبيق، ولا يلزم تسجيل الدخول بالمصادقة).
