Créez de superbes cartes interactives Feishu V2.0 riches en éléments. Prend en charge plus de 20 composants, notamment des panneaux pliables, des mises en page multi-colonnes, des graphiques, des balises de couleur, des groupes de boutons, des cartes utilisateur et des mises à jour en streaming. Comprend 7 modèles de scénarios intégrés (notification/rapport de réussite/alerte/approbation/tableau de bord de données/résumé d'article/diffusion IA) et des normes de couleur/mise en page. À utiliser lorsque l'utilisateur demande « envoyer une carte », « envoyer une notification », « créer une alerte », « envoyer un rapport », « créer une approbation », « créer un tableau de bord », « embellir un message », « carte interactive », « carte v2 », « message avec graphique », « message avec boutons », « message avec panneau pliable », « carte Feishu », « carte Lark » ou « construire une carte ». Même si l'utilisateur dit seulement « envoyer un message pour informer XX », tant que le contenu a une structure (plusieurs champs/liens/graphiques/statut), cette compétence doit être utilisée pour créer une carte au lieu d'un texte brut. Le JSON résultant est écrit dans /tmp/<name>-card.json puis envoyé via feishu-cli-msg avec --msg-type interactif (le msg utilise App Token, aucune connexion d'authentification requise).
