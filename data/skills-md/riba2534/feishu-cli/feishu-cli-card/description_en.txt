Build beautiful, element-rich Feishu V2.0 interactive cards. Supports 20+ components including collapsible panels, multi-column layouts, charts, color tags, button groups, user cards, and streaming updates. Includes 7 built-in scenario templates (notification / success report / alert / approval / data dashboard / article summary / AI streaming) and color/layout standards. Use when the user requests “send card”, “send notification”, “create alert”, “send report”, “create approval”, “create dashboard”, “beautify message”, “interactive card”, “v2 card”, “message with chart”, “message with buttons”, “message with collapsible panel”, “Feishu card”, “Lark card”, or “build card”. Even if the user only says “send a message to tell XX”, as long as the content has structure (multiple fields / links / charts / status), this skill should be used to build a card instead of plain text. The resulting JSON is written to /tmp/<name>-card.json and then sent via feishu-cli-msg with --msg-type interactive (the msg uses App Token, no auth login required).
