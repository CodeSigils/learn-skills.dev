美しく、要素が豊富な Feishu V2.0 インタラクティブ カードを作成します。折りたたみ可能なパネル、複数列のレイアウト、チャート、カラータグ、ボタングループ、ユーザーカード、ストリーミング更新を含む 20 以上のコンポーネントをサポートします。 7 つの組み込みシナリオ テンプレート (通知/成功レポート/アラート/承認/データ ダッシュボード/記事概要/AI ストリーミング) と色/レイアウト標準が含まれています。ユーザーが「カード送信」、「通知送信」、「アラート作成」、「レポート送信」、「承認作成」、「ダッシュボード作成」、「美化メッセージ」、「インタラクティブカード」、「v2カード」、「チャート付きメッセージ」、「ボタン付きメッセージ」、「折りたたみパネル付きメッセージ」、「フェイシュカード」、「ラークカード」、または「カードの構築」をリクエストする場合に使用します。ユーザーが「○○に伝えるためにメッセージを送信する」とだけ言ったとしても、コンテンツに構造（複数のフィールド/リンク/グラフ/ステータス）がある限り、このスキルはプレーンテキストではなくカードを作成するために使用される必要があります。結果の JSON は /tmp/<name>-card.json に書き込まれ、 --msg-type interactive を指定して feishu-cli-msg 経由で送信されます (msg は App Token を使用し、認証ログインは必要ありません)。
