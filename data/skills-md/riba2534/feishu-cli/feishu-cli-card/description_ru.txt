Создавайте красивые, богатые элементами интерактивные карты Feishu V2.0. Поддерживает более 20 компонентов, включая складные панели, многоколоночные макеты, диаграммы, цветные теги, группы кнопок, карточки пользователей и потоковые обновления. Встроенные 7 шаблонов сценариев (Уведомление / Отчет об успехе / Оповещение / Утверждение / Панель данных / Сводка статей / Потоковая передача AI) с цветовой схемой и стандартами макета. Используйте этот навык, когда пользователь запрашивает «отправить карту», ​​«отправить уведомление», «создать оповещение», «отправить отчет», «создать утверждение», «создать панель мониторинга», «украсить сообщение», «интерактивную карту», ​​«карту v2», «сообщение с диаграммой», «сообщение с кнопками», «сообщение со складной панелью», «карту Фейшу», «карту жаворонка» или «карту создания». Даже если пользователь говорит только «отправить сообщение XX», если контент имеет структуру (несколько полей/несколько ссылок/диаграммы/статус), расставьте приоритеты в использовании этого навыка для создания карточки, а не простого текста. Запишите созданный JSON в /tmp/<name>-card.json, затем передайте его feishu-cli-msg для отправки с интерактивным --msg-type (msg использует App Token, вход в систему для аутентификации не требуется).
