Navigation dans les sessions Feishu, interaction avec les messages et gestion des discussions de groupe. Afficher l'historique des discussions, récupérer les messages de discussion de groupe, rechercher des groupes, obtenir les détails des messages, ajouter des réponses emoji de réaction, épingler/désépingler des messages, supprimer des messages. Interroger et gérer les informations du groupe (récupérer/mettre à jour/dissoudre/gestion des membres). Prend en charge à la fois les groupes réguliers et les groupes thématiques ; les groupes de sujets récupèrent automatiquement les réponses du fil de discussion. Toutes les commandes nécessitent un jeton utilisateur. À utiliser lorsque l'utilisateur demande « afficher l'historique des discussions », « voir les messages avec quelqu'un », « l'historique des discussions de groupe », « messages de groupe », « rechercher des groupes », « vérifier les informations du groupe », « membres du groupe », « messages récents », « enregistrements de discussion », « réaction », « réponse emoji », « message épinglé », « épingler », « supprimer le message », « recevoir un message », « détails du message », « ce que j'ai discuté avec qui », « ce qui a été dit dans le groupe », « résumer » messages de groupe", "réponse au sujet", "réponse au fil de discussion", "réponses au fil de discussion". S'applique également lorsque l'utilisateur donne un nom de groupe ou un chat_id et souhaite parcourir ses messages, même sans dire explicitement « historique des discussions ». Utilisez cette compétence chaque fois que l'utilisateur souhaite savoir de quoi un groupe a discuté récemment, trouver une conversation avec quelqu'un ou interagir avec des messages.
