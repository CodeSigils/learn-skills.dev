Navigation dans les sessions Feishu, interaction avec les messages et gestion des discussions de groupe. Affichez l'historique des discussions, récupérez les messages de discussion de groupe, recherchez des groupes, obtenez les détails des messages, ajoutez des réponses emoji de réaction, épinglez/désépinglez des messages, supprimez des messages et interrogez/gérez les informations de groupe (obtenir/mettre à jour/dissoudre/gestion des membres). Prend en charge à la fois les groupes réguliers et les groupes thématiques ; les groupes de sujets récupèrent automatiquement les réponses au fil de discussion. Toutes les commandes nécessitent un jeton utilisateur. À utiliser lorsque l'utilisateur demande « afficher l'historique des discussions », « voir les messages avec quelqu'un », « l'historique des discussions de groupe », « messages de groupe », « groupes de recherche », « vérifier les informations du groupe », « membres du groupe », « messages récents », « enregistrements de discussion », « réaction », « réponse emoji », « épingler », « supprimer le message », « recevoir un message », « détails du message », « ce que j'ai discuté avec quelqu'un », « ce qui a été dit dans le groupe », « résumer les messages de groupe », « réponses au sujet », « réponses au fil de discussion » ou "réponses du fil de discussion." S'applique également lorsque l'utilisateur donne un nom de groupe ou un chat_id et souhaite parcourir ses messages, même sans dire explicitement « historique des discussions ». Utilisez cette compétence chaque fois que l'utilisateur souhaite savoir de quoi un groupe a discuté récemment, trouver une conversation avec quelqu'un ou interagir avec des messages.
