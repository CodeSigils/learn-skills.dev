Feishu session browsing, message interaction, and group chat management. View chat history, retrieve group chat messages, search groups, get message details, add Reaction emoji responses, pin/unpin messages, delete messages, and query/manage group info (retrieve/update/disband/member management). Supports both regular groups and topic groups; topic groups auto-fetch thread replies. All commands require a User Token. Use when the user asks to “view chat history,” “see messages with someone,” “group chat history,” “group messages,” “search groups,” “check group info,” “group members,” “recent messages,” “chat records,” “Reaction,” “emoji response,” “pin message,” “Pin,” “delete message,” “get message,” “message details,” “what I chatted with whom,” “what was said in the group,” “summarize group messages,” “topic reply,” “thread reply,” or “thread replies.” Also applies when the user gives a group name or chat_id and wants to browse its messages, even without explicitly saying “chat history.” Use this skill whenever the user wants to know what a group has been discussing lately, find a conversation with someone, or perform interactive actions on messages.
