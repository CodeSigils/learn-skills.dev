Feishu approval operations (query + write). Read: definition detail / instance get / task query. Write: instance {create, cancel, cc} + task {approve, reject, transfer}. Instance get, task query, instance cancel/cc, and task approve/reject/transfer require a User Token; instance create uses tenant_access_token. Used when a user requests “submit approval,” “approve/reject,” “revoke approval,” “transfer approval,” “cc,” or “approval query.”
