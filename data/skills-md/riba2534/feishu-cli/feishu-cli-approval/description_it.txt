Operazioni di approvazione Feishu (query + write). Leggi: dettaglio definizione/richiesta istanza/query attività. Scrivi: istanza {crea, annulla, cc} + attività {approva, rifiuta, trasferisci}. il recupero dell'istanza, la query dell'attività, l'annullamento/cc dell'istanza, l'approvazione/rifiuto/trasferimento dell'attività richiedono un token utente; la creazione dell'istanza utilizza tenant_access_token. Quando l'utente richiede "invia approvazione", "passaggio/rifiuto dell'approvazione", "ritiro dell'approvazione", "trasferimento dell'approvazione", "cc" o "query di approvazione", viene utilizzato questo.
