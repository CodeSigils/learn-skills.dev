فقط للتقويم والمهام والموافقات والحضور والـ OKR؛ إنها ليست نقطة دخول عالمية لجميع طلبات مكتب Feishu. عندما يحتاج المستخدمون إلى وقت فراغ مشترك، أو حجز قاعات اجتماعات، أو قبول/رفض الدعوات، أو إنشاء أحداث أو الرد عليها، أو إدارة المهام/قوائم المراجعة، أو بدء الموافقات أو سحبها أو الموافقة عليها أو رفضها أو تفويضها أو نسخها، أو الاستعلام عن إحصائيات الإدخال/التأخر/المغادرة، أو الاستعلام عن دورات OKR أو تحديث التقدم، يجب استخدام هذه المهارة. يُحظر صراحةً استخدامه لدفاتر عناوين المستخدم/القسم، أو البريد الإلكتروني، أو استرجاع الاجتماعات التاريخية، أو تسجيلات الاجتماعات، أو الملاحظات؛ يستخدم هؤلاء اجتماعات feishu-cli-platform وfeishu-cli-mail وfeishu-cli-platform. تستخدم رسائل الإعلام بالاجتماع رسائل feishu-cli.
