Only for calendar, tasks, approvals, attendance, and OKR; it is not a universal entry point for all Feishu office requests. When users need freebusy, find common free time, book meeting rooms, accept/reject invitations, create or reply to events, manage tasks/lists, initiate, withdraw, approve, reject, delegate, or copy approvals, query clock‑in/late/leave statistics, or query OKR cycles or update progress, this Skill must be used. It is explicitly prohibited to use it for user/department address books, email, historical meeting retrieval, meeting recordings, or notes; they respectively use feishu-cli-platform, feishu-cli-mail, and feishu-cli-meetings. Meeting notification messages use feishu-cli-messaging.
