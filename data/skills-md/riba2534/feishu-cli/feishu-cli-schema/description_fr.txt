Navigation locale selon la méthode Feishu OpenAPI + appels pass-through API génériques. Le schéma « service.resource.method » fournit une recherche en trois parties pour le chemin, les paramètres et la portée (aucune connexion Internet requise) ; `feishu-cli api <method> <path>` appelle directement n'importe quel point de terminaison (v1.29+, couvrant plus de 2 500 API non emballées). Utilisez-le lorsque les utilisateurs demandent « Feishu a-t-il une API XX ? », « Quels sont les paramètres de l'API X ? », « De quelle portée la méthode X a-t-elle besoin ? », « Navigation dans la méthode OpenAPI », « Comment le SDK l'appelle-t-il ? Non applicable pour vérifier le dernier schéma en ligne (utilisez OpenAPI Explorer ; les métadonnées locales peuvent être obsolètes avec la plateforme ouverte Feishu).
