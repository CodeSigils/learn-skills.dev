Navigation locale de la méthode Feishu OpenAPI + invocation d’API pass-through générique. Le schéma « service.resource.method » fournit une recherche en trois parties du chemin, des paramètres et de la portée (aucune connexion Internet requise) ; `feishu-cli api <method> <path>` appelle directement n'importe quel point de terminaison (v1.29+, couvrant plus de 2 500 API non emballées). À utiliser lorsqu'un utilisateur demande « Feishu a-t-il anXXAPI ? », « Quels sont les paramètres de XAPI ? », « De quelle portée Xmethod a-t-il besoin ? Non applicable pour vérifier le dernier schéma en ligne (veuillez utiliser OpenAPI Explorer ; les métadonnées locales peuvent être en retard par rapport à la plateforme ouverte Feishu).
