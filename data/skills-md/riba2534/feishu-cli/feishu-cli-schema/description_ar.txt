التصفح المحلي لطريقة Feishu OpenAPI + استدعاء تمرير واجهة برمجة التطبيقات العامة. يوفر المخطط "service.resource.method" بحثًا من ثلاثة أجزاء للمسار والمعلمات والنطاق (لا يلزم الاتصال بالإنترنت)؛ `feishu-cli api <method> <path>` يستدعي مباشرة أي نقطة نهاية (الإصدار 1.29+، يغطي 2,500+ واجهات برمجة التطبيقات غير المغلفة). يُستخدم عندما يسأل المستخدم "هل لدى Feishu anXXAPI؟"، أو "ما هي معلمات XAPI؟"، أو "ما النطاق الذي يحتاجه Xmethod؟"، أو "تصفح طرق OpenAPI"، أو "انظر كيف يستدعيها SDK"، أو "استدعاء واجهة برمجة تطبيقات Feishu غير المغلفة". لا ينطبق على التحقق من أحدث مخطط عبر الإنترنت (يُرجى استخدام OpenAPI Explorer؛ فقد تتأخر البيانات التعريفية المحلية عن منصة Feishu المفتوحة).
