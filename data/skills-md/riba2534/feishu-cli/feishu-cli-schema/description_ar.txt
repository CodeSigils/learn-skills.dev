طريقة Feishu OpenAPI للتصفح المحلي + مكالمات تمرير API العامة. يوفر المخطط "service.resource.method" بحثًا من ثلاثة أجزاء عن المسار/المعلمات/النطاق (لا يلزم الاتصال بالإنترنت)؛ `feishu-cli api <method> <path>` يستدعي مباشرة أي نقطة نهاية (الإصدار 1.29+، يغطي أكثر من 2500 واجهة برمجة تطبيقات غير مغلفة). يُستخدم عندما يسأل المستخدم "هل لدى Feishu XX API؟"، أو "ما هي معلمات X API؟"، أو "ما النطاق الذي تتطلبه طريقة X؟"، أو "تصفح أسلوب OpenAPI"، أو "كيف يطلق عليه SDK؟"، أو "الاتصال بواجهة برمجة تطبيقات Feishu غير المغلفة." لا ينطبق على التحقق من أحدث مخطط عبر الإنترنت (يُرجى استخدام OpenAPI Explorer؛ فقد تتأخر البيانات التعريفية المحلية عن منصة Feishu المفتوحة).
