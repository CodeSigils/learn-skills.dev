Feishu OpenAPI-Methode, lokales Browsen + generischer API-Passthrough-Aufruf. Das Schema „service.resource.method“ bietet eine dreiteilige Suche nach Pfad, Parametern und Umfang (kein Internet erforderlich); „feishu-cli api <method> <path>“ ruft direkt jeden Endpunkt auf (v1.29+, deckt über 2.500 unverpackte APIs ab). Verwenden Sie diese Option, wenn ein Benutzer fragt: „Verfügt Feishu über eine XXAPI?“, „Was sind die Parameter von XAPI?“, „Welchen Bereich benötigt die Gilt nicht für die Überprüfung des neuesten Online-Schemas (bitte verwenden Sie den OpenAPI Explorer; lokale Metadaten können hinter der Feishu Open Platform zurückbleiben).
