Feishu OpenAPI 메서드 로컬 탐색 + 일반 API 통과 호출. `service.resource.method` 스키마는 경로/매개변수/범위(네트워크가 필요하지 않음)에 대한 세 부분 조회를 사용합니다. `feishu-cli api <method> <path>`는 모든 엔드포인트를 직접 호출합니다(v1.29+, 2,500개 이상의 래핑되지 않은 API 포함). 사용자가 "Feishu에 XX API가 있습니까?", "X API의 매개변수는 무엇입니까?", "X 메서드에 필요한 범위는 무엇입니까?", "OpenAPI 메서드 검색", "SDK는 이를 어떻게 호출합니까?" 또는 "래핑되지 않은 Feishu API 호출"이라고 묻는 경우에 사용합니다. 최신 온라인 스키마를 확인하는 데는 해당되지 않습니다(OpenAPI Explorer를 사용하십시오. 로컬 메타데이터는 Feishu 개방형 플랫폼에서 최신 상태가 아닐 수 있습니다).
