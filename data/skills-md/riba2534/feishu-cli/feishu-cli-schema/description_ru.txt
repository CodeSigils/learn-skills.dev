Локальный просмотр методом Feishu OpenAPI + сквозной вызов общего API. Схема service.resource.method обеспечивает трехэтапный поиск пути, параметров и области действия (интернет не требуется); `feishu-cli api <method> <path>` напрямую вызывает любую конечную точку (версия 1.29+, охватывающая более 2500 развернутых API). Используйте, когда пользователь спрашивает: «Есть ли у Feishu XXAPI?», «Каковы параметры XAPI?», «Какая область действия требуется для X-метода?», «Просмотр методов OpenAPI», «Посмотрите, как SDK вызывает его» или «Вызов развернутого API Feishu». Неприменимо для проверки последней онлайн-схемы (используйте OpenAPI Explorer; локальные метаданные могут отставать от открытой платформы Feishu).
