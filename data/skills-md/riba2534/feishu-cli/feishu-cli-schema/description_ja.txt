Feishu OpenAPI メソッドのローカル ブラウジング + 汎用 API パススルー呼び出し。スキーマ「service.resource.method」は、パス、パラメータ、スコープの 3 つの部分からなる検索を提供します (インターネットは必要ありません)。 「feishu-cli api <method> <path>」は、任意のエンドポイント (v1.29 以降、2,500 以上のラップされていない API をカバー) を直接呼び出します。ユーザーが「Feishu には XXAPI がありますか?」、「XAPI のパラメータは何ですか?」、「Xmethod に必要なスコープは何ですか?」、「OpenAPI メソッドを参照」、「SDK がどのように呼び出すかを確認してください」、または「ラップされていない Feishu API を呼び出してください」と尋ねる場合に使用します。最新のオンライン スキーマの確認には適用されません (OpenAPI Explorer を使用してください。ローカル メタデータは Feishu Open Platform よりも遅れる可能性があります)。
