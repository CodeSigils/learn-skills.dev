Feishu OpenAPI メソッドのローカル ブラウジング + 汎用 API パススルー呼び出し。スキーマ「service.resource.method」は、パス、パラメータ、スコープの 3 つの部分からなる検索を提供します (ネットワークは必要ありません)。 「feishu-cli api <method> <path>」は、任意のエンドポイントを直接呼び出します (v1.29 以降、2,500 以上のラップされていない API をカバー)。ユーザーが「Feishu には XX API がありますか?」、「X API のパラメータは何ですか?」、「X メソッドに必要なスコープは何ですか?」、「OpenAPI メソッドの参照」、「SDK はどのように呼び出しますか?」、「ラップされていない Feishu API を呼び出します」などの質問をする場合に使用します。該当なし: 最新のオンライン スキーマの確認 (OpenAPI Explorer を使用してください。ローカル メタデータは Feishu Open Platform よりも遅れる可能性があります)。
