Feishu OpenAPI method local browsing + generic API pass‑through invocation. The schema `service.resource.method` provides a three‑part lookup of path, parameters, and scope (no internet required); `feishu-cli api <method> <path>` directly calls any endpoint (v1.29+, covering 2,500+ unwrapped APIs). Use when a user asks “Does Feishu have an XX API?”, “What are the parameters of X API?”, “What scope does X method need?”, “Browse OpenAPI methods”, “See how the SDK calls it”, or “Invoke an unwrapped Feishu API”. Not applicable for checking the latest online schema (please use OpenAPI Explorer; local metadata may lag behind the Feishu Open Platform).
