Navigazione locale con metodo Feishu OpenAPI + invocazione pass-through API generica. Lo schema "service.resource.method" fornisce una ricerca in tre parti di percorso, parametri e ambito (non è necessaria Internet); `feishu-cli api <method> <path>` chiama direttamente qualsiasi endpoint (v1.29+, che copre oltre 2.500 API non imballate). Da utilizzare quando un utente chiede "Feishu ha anXXAPI?", "Quali sono i parametri di XAPI?", "Di quale ambito ha bisogno Xmethod?", "Sfoglia i metodi OpenAPI", "Guarda come lo chiama l'SDK" o "Richiama un'API Feishu non imballata". Non applicabile per il controllo dello schema online più recente (utilizzare OpenAPI Explorer; i metadati locali potrebbero essere in ritardo rispetto alla piattaforma aperta Feishu).
