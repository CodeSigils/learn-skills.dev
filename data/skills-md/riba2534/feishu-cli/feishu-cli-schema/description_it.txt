Navigazione locale con metodo Feishu OpenAPI + chiamate pass-through API generiche. Lo schema "service.resource.method" fornisce una ricerca in tre parti di percorso/parametri/ambito (non è necessaria alcuna rete); `feishu-cli api <method> <path>` invoca direttamente qualsiasi endpoint (v1.29+, che copre oltre 2.500 API non imballate). Utilizzalo quando un utente chiede "Feishu ha XX API?", "Quali sono i parametri dell'API X?", "Quale ambito richiede il metodo X?", "Navigazione del metodo OpenAPI", "Come lo chiama l'SDK?" o "Chiama un'API Feishu non imballata". Non applicabile per il controllo dello schema online più recente (utilizzare OpenAPI Explorer; i metadati locali potrebbero essere in ritardo rispetto alla piattaforma aperta Feishu).
