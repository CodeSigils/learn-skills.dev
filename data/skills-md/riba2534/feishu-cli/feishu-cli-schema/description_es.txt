Navegación local del método Feishu OpenAPI + invocación de paso a través de API genérica. El esquema `service.resource.method` proporciona una búsqueda en tres partes de ruta, parámetros y alcance (no se requiere Internet); `feishu-cli api <método> <ruta>` llama directamente a cualquier punto final (v1.29+, que cubre más de 2500 API sin empaquetar). Úselo cuando un usuario pregunta "¿Tiene Feishu una XXAPI?", "¿Cuáles son los parámetros de XAPI?", "¿Qué alcance necesita el método X?", "Examinar los métodos de OpenAPI", "Ver cómo lo llama el SDK" o "Invocar una API de Feishu no envuelta". No se aplica para verificar el esquema en línea más reciente (use OpenAPI Explorer; los metadatos locales pueden ir por detrás de Feishu Open Platform).
