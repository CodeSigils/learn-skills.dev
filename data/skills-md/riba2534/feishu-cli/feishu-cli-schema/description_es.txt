Navegación local del método Feishu OpenAPI + llamadas de paso API genéricas. El esquema `service.resource.method` utiliza una búsqueda de tres partes para ruta/parámetros/alcance (no se necesita red); `feishu-cli api <método> <ruta>` invoca directamente cualquier punto final (v1.29+, que cubre más de 2500 API no empaquetadas). Utilice esto cuando el usuario pregunte "¿Tiene Feishu XX API?", "¿Cuáles son los parámetros para la API X?", "¿Qué alcance requiere el método X?", "Exploración del método OpenAPI", "Cómo lo llama el SDK" o "Llame a una API de Feishu no empaquetada". No es adecuado para comprobar el esquema en línea más reciente (utilice OpenAPI Explorer; los metadatos locales pueden estar desactualizados en comparación con la plataforma abierta Feishu).
