Собственные операции с файлами Markdown в Feishu Cloud Drive (дополнительно к импорту/экспорту документов). markdown create загружает новый .md на облачный диск; markdown fetch загружает его как локальный .md; При перезаписи уценки используется локальный .md для замены существующего файла на облачном диске (сохраняя file_token неизменным, ссылка для общего доступа остается постоянной). Если документ doc не подходит (хостинг изображений, плотные блоки кода, контроль версий), используйте собственный путь к файлу .md. Диск upload_all + специально созданный составной элемент FormData (SDK не предоставляет поле file_token). Используется, когда пользователь запрашивает «загрузить уценку», «загрузить md» или «перезаписать облачный диск md».
