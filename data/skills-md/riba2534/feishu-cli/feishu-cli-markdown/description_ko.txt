Feishu Cloud Drive 기본 Markdown 파일 작업(문서 가져오기/내보내기에 보완) `markdown create`는 새로운 .md를 클라우드 드라이브에 업로드합니다. `markdown fetch`는 이를 로컬 .md로 다운로드합니다. 'markdown overwrite'는 로컬 .md를 사용하여 클라우드 드라이브의 기존 파일을 덮어씁니다(file_token을 변경하지 않고 유지하여 공유 링크가 지속되도록 유지). 문서 문서가 적합하지 않은 경우(이미지 호스팅, 조밀한 코드 블록, 버전 제어) 기본 .md 파일 경로를 사용하세요. 'Drive upload_all'과 수동으로 조립된 FormData 멀티파트(SDK는 file_token 필드를 노출하지 않음) 사용자가 "마크다운 업로드", "MD 다운로드", "클라우드 드라이브 MD 덮어쓰기"를 요청할 때 사용됩니다.
