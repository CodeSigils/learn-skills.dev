Feishu Cloud Drive native Markdown file operations (complementary to doc import/export). markdown create uploads a new .md to the cloud drive; markdown fetch downloads it as a local .md; markdown overwrite uses a local .md to replace an existing file on the cloud drive (keeping file_token unchanged, sharing link remains persistent). When a doc document is not suitable (image hosting, dense code blocks, version control), use the native .md file path. Drive upload_all + custom-built FormData multipart (SDK does not expose the file_token field). Used when the user requests “upload markdown”, “download md”, or “overwrite cloud drive md”.
