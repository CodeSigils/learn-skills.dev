عمليات ملف Markdown الأصلية لـ Feishu Cloud Drive (مكملة لاستيراد/تصدير المستندات).  
- **إنشاء تخفيض السعر**: قم بتحميل ملف .md جديد إلى محرك الأقراص السحابي.  
- **جلب تخفيض السعر**: قم بالتنزيل كملف .md محلي.  
- **الكتابة فوق تخفيض السعر**: استبدل ملف محرك أقراص سحابي موجود بملف .md محلي (احتفظ برمز file_token دون تغيير، بحيث يظل رابط المشاركة صالحًا).  

عندما لا يكون مستند المستند مناسبًا (على سبيل المثال، استضافة الصور، أو كتل التعليمات البرمجية الكثيفة، أو التحكم في الإصدار)، استخدم مسار الملف .md الأصلي.  

يمكنك التنفيذ باستخدام Driveupload_all بالإضافة إلى FormData متعدد الأجزاء الذي تم إنشاؤه يدويًا (لا يكشف SDK عن حقل file_token).  

استخدم هذا التدفق عندما يطلب المستخدم "تحميل تخفيض السعر" أو "تنزيل md" أو "الكتابة فوق محرك الأقراص السحابي md".
