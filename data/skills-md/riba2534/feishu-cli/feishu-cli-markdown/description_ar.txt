عمليات ملف Markdown الأصلية لـ Feishu Cloud Drive (مكملة لاستيراد/تصدير المستندات). إنشاء تخفيض السعر وتحميل ملف .md جديد إلى محرك الأقراص السحابي؛ جلب تخفيض السعر يقوم بتنزيله كملف .md محلي؛ تستخدم عملية الكتابة فوق Markdown ملف .md محلي لاستبدال ملف موجود على محرك الأقراص السحابي (مع الحفاظ على file_token دون تغيير، ويظل رابط المشاركة ثابتًا). عندما لا يكون مستند المستند مناسبًا (استضافة الصور، كتل التعليمات البرمجية الكثيفة، التحكم في الإصدار)، استخدم مسار الملف .md الأصلي. Drive upload_all + FormData متعدد الأجزاء المصمم خصيصًا (لا تعرض SDK حقل file_token). يتم استخدامه عندما يطلب المستخدم "تحميل تخفيض السعر" أو "تنزيل md" أو "الكتابة فوق محرك الأقراص السحابي md".
