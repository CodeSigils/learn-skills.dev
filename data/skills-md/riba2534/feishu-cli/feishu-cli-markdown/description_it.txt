Operazioni sui file Markdown native di Feishu Cloud Drive (complementari all'importazione/esportazione di documenti). markdown create carica un nuovo .md sull'unità cloud; markdown fetch lo scarica come .md locale; la sovrascrittura markdown utilizza un .md locale per sovrascrivere un file esistente sull'unità cloud (mantenendo file_token invariato, collegamento di condivisione persistente). Quando i documenti doc non sono adatti (hosting di immagini, blocchi di codice densi, controllo della versione), utilizzare il percorso del file .md nativo. Guida upload_all + costruisci manualmente FormData multipart (SDK non espone il campo file_token). Utilizzato quando l'utente richiede "upload markdown", "download md" o "sovrascrivi cloud drive md".
