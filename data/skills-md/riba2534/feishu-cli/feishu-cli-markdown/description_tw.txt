飛書雲盤原生Markdown文件操作（作為文件導入/匯出的補充）。 markdown create 上傳新的.md到雲端磁碟；markdown fetch 將其下載為本機 .md；markdown overwrite 使用本機 .md 取代雲端磁碟機上的現有檔案（保持 file_token 不變，共用連結保持持久）。當 doc 文件不適合時（圖像託管、密集程式碼區塊、版本控制），請使用本機 .md 檔案路徑。驅動upload_all + 定制的FormData multipart（SDK不公開file_token欄位）。當使用者要求「上傳markdown」、「下載md」或「覆蓋雲端盤md」時使用。
