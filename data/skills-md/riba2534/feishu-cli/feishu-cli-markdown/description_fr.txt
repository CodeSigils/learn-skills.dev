Opérations sur les fichiers Markdown natifs de Feishu Cloud Drive (en complément de l'import/export de documents). markdown create télécharge un nouveau .md sur le lecteur cloud ; Markdown Fetch le télécharge en tant que .md local ; L'écrasement du markdown utilise un .md local pour remplacer un fichier existant sur le lecteur cloud (en gardant file_token inchangé, le lien de partage reste persistant). Lorsqu'un document doc ne convient pas (hébergement d'images, blocs de code denses, contrôle de version), utilisez le chemin natif du fichier .md. Lecteur upload_all + multipart FormData personnalisé (le SDK n'expose pas le champ file_token). Utilisé lorsque l'utilisateur demande « télécharger markdown », « télécharger md » ou « écraser le lecteur cloud md ».
