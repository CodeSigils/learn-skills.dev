Opérations sur les fichiers Markdown natifs de Feishu Cloud Drive (en complément de l'import/export de documents). markdown create télécharge un nouveau .md sur le lecteur cloud ; Markdown Fetch le télécharge en tant que .md local ; Markdown Overwrite utilise un .md local pour écraser un fichier existant sur le lecteur cloud (en gardant file_token inchangé, le lien de partage persiste). Lorsqu’un document doc ne convient pas (hébergement d’images, blocs de code denses, contrôle de version), utilisez le chemin natif du fichier .md. Lecteur upload_all + multipart FormData assemblé manuellement (le SDK n'expose pas le champ file_token). Utilisé lorsqu'un utilisateur demande « télécharger markdown », « télécharger md » ou « écraser le lecteur cloud md ».
