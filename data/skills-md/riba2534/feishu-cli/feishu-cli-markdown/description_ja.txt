Feishu クラウド ドライブのネイティブ Markdown ファイル操作 (ドキュメントのインポート/エクスポートを補完)。 markdown create は、新しい .md をクラウド ドライブにアップロードします。マークダウンフェッチはローカルの .md としてダウンロードします。マークダウン上書きは、ローカルの .md を使用して、クラウド ドライブ上の既存のファイルを上書きします (file_token は変更されず、共有リンクは維持されます)。ドキュメント ドキュメントが不適切な場合 (イメージ ホスティング、高密度のコード ブロック、バージョン管理)、ネイティブ .md ファイル パスを使用します。ドライブの Upload_all + 自己アセンブル FormData マルチパート (SDK は file_token フィールドを公開しません)。ユーザーが「マークダウンのアップロード」、「mdのダウンロード」、または「クラウドドライブmdの上書き」を要求するときに使用されます。
