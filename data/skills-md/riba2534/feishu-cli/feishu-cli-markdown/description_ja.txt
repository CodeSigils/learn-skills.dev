Feishu Cloud Drive ネイティブ Markdown ファイル操作 (ドキュメントのインポート/エクスポートを補完)。 markdown create は、新しい .md をクラウド ドライブにアップロードします。マークダウンフェッチはローカルの .md としてダウンロードします。マークダウン上書きでは、ローカルの .md を使用してクラウド ドライブ上の既存のファイルを置き換えます (file_token は変更されず、共有リンクは永続的なままです)。ドキュメント ドキュメントが適切でない場合 (イメージ ホスティング、高密度のコード ブロック、バージョン管理)、ネイティブ .md ファイル パスを使用します。ドライブの Upload_all + カスタム構築された FormData マルチパート (SDK は file_token フィールドを公開しません)。ユーザーが「マークダウンのアップロード」、「mdのダウンロード」、または「クラウドドライブmdの上書き」を要求するときに使用されます。
