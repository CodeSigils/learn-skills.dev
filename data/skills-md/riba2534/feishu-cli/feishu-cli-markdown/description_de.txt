Feishu Cloud Drive native Markdown-Dateioperationen (ergänzend zum Import/Export von Dokumenten). Markdown erstellen: Laden Sie eine neue .md auf das Cloud-Laufwerk hoch. Markdown-Abruf: als lokale .md-Datei herunterladen; Markdown-Überschreibung: Verwenden Sie eine lokale .md-Datei, um eine vorhandene Cloud-Laufwerksdatei zu ersetzen (file_token unverändert lassen, der Freigabelink bleibt bestehen). Wenn ein Dokument ungeeignet ist (Bildhosting, dichte Codeblöcke, Versionskontrolle), verwenden Sie den nativen .md-Dateipfad. Fahren Sie upload_all + benutzerdefiniertes mehrteiliges FormData (das SDK stellt das Feld „file_token“ nicht zur Verfügung). Wird verwendet, wenn der Benutzer „Markdown hochladen“, „MD herunterladen“ oder „Cloud-Laufwerks-MD überschreiben“ anfordert.
