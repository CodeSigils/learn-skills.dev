Feishu Cloud Drive native Markdown-Dateioperationen (ergänzend zum Import/Export von Dokumenten). Markdown Create lädt eine neue .md auf das Cloud-Laufwerk hoch; Markdown Fetch lädt es als lokale .md herunter; Markdown Overwrite verwendet eine lokale .md, um eine vorhandene Datei auf dem Cloud-Laufwerk zu ersetzen (file_token bleibt unverändert, der Freigabelink bleibt bestehen). Wenn ein Dokument nicht geeignet ist (Bildhosting, dichte Codeblöcke, Versionskontrolle), verwenden Sie den nativen .md-Dateipfad. Fahren Sie upload_all + benutzerdefiniertes mehrteiliges FormData (SDK macht das Feld file_token nicht verfügbar). Wird verwendet, wenn der Benutzer „Markdown hochladen“, „MD herunterladen“ oder „Cloud-Laufwerks-MD überschreiben“ anfordert.
