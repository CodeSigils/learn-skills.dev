Feishu Bitable(Bitable/Base) 전체 기능 작업: 다차원 테이블 생성, 데이터 테이블 관리, 필드 관리, 레코드 CRUD(단일 + 일괄), 보기 관리, 검색/필터/정렬. 사용자가 "다차원 테이블 생성", "데이터 테이블 운영", "레코드 추가", "레코드 쿼리", "필드 관리", "다차원 테이블", "베이스", "비트 가능" 또는 "데이터 테이블"을 요청할 때 사용합니다. 사용자가 구조화된 데이터베이스를 생성하거나, 데이터를 일괄 가져오거나, 테이블 필드 및 보기를 관리해야 하는 경우에도 적용 가능합니다. 참고: 스프레드시트(시트)의 경우 feishu-cli-toolkit을 사용하세요. 그들은 다른 제품입니다.
