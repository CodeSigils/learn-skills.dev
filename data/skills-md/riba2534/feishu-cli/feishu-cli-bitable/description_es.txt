Operaciones con todas las funciones de Feishu Bitable (Bitable/Base): crear bases, administrar tablas, administrar campos, agregar/editar/eliminar/consultar registros (individuales y masivos), administrar vistas, buscar/filtrar/ordenar. Se utiliza cuando el usuario solicita "crear base", "operar tabla", "agregar registro", "consultar registro", "administrar campo", "bitable", "base", "tabla". También se aplica a: escenarios en los que los usuarios necesitan crear bases de datos estructuradas, importar datos en masa, administrar campos de tablas y vistas. Nota: para hojas de cálculo (Hojas), utilice feishu-cli-toolkit; son productos diferentes.
