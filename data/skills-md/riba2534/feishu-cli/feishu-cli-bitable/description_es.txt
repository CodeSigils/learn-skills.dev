Operaciones con todas las funciones de Feishu Bitable (Bitable/Base): crear bases, administrar tablas, administrar campos, agregar/editar/eliminar/buscar registros (individuales y masivos), ver administración, buscar/filtrar/ordenar. Úselo cuando el usuario solicite "crear base", "operar tabla", "agregar registro", "consultar registro", "administrar campo", "bitable", "base", "tabla de datos". También se aplica cuando los usuarios necesitan crear bases de datos estructuradas, importar datos en masa o administrar campos y vistas de tablas. Nota: para hojas de cálculo (Hojas), utilice feishu-cli-toolkit; son productos diferentes.
