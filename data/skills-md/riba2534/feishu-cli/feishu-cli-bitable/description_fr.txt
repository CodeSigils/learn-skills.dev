Feishu Bitable/Base Opérations complètes : créer des tables multidimensionnelles, gestion des tables de données, gestion des champs, enregistrement CRUD (unique + lot), gestion des vues, recherche/filtrage/tri. Utilisé lorsque les utilisateurs demandent « créer une table multidimensionnelle », « exploiter une table de données », « ajouter un enregistrement », « interroger un enregistrement », « gérer les champs », « Bitable », « base », « table de données ». Applicable également aux scénarios dans lesquels les utilisateurs doivent créer des bases de données structurées, importer des données par lots, gérer des champs et des vues de table. Remarque : pour les feuilles de calcul (Sheets), utilisez feishu-cli-toolkit ; ce sont des produits différents.
