Workflow zum Vorbereiten von Code zum sicheren Festschreiben und Pushen. Verwenden Sie diese Option, wenn der Benutzer Codeänderungen festschreiben, pushen, versenden, finalisieren oder übermitteln möchte. Erfordert die Ausführung relevanter Tests, Linting, TypeScript-Prüfungen und anderer Validierungen vor dem Festschreiben.
