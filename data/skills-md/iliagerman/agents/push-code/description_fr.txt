Workflow pour préparer le code à valider et à pousser en toute sécurité. À utiliser lorsque l'utilisateur demande à valider, pousser, expédier, finaliser ou soumettre des modifications de code. Nécessite l'exécution de tests pertinents, de peluches, de vérifications TypeScript et d'autres validations avant de s'engager.
