Анализирует проектный документ для извлечения пользовательских историй и создания соответствующих проблем GitHub. При желании он может связать их с этапом GitHub. Этот навык действует как этап настройки для отслеживания проблем с помощью GitHub. Обязательно используйте этот навык всякий раз, когда пользователь просит «отправить проектный документ в GitHub», «создать задачи из проектного документа», «настроить контрольную точку» или упоминает о превращении требований в практические задачи GitHub.
