Analizza un documento di progettazione per estrarre le User Story e crea i corrispondenti problemi GitHub. Facoltativamente può collegarli a una pietra miliare GitHub. Questa competenza funge da fase di configurazione per il monitoraggio dei problemi nativi di GitHub. Assicurati di utilizzare questa competenza ogni volta che l'utente chiede di "inviare il documento di progettazione a GitHub", "creare problemi dal documento di progettazione", "impostare l'elemento cardine" o menziona la trasformazione dei requisiti in problemi GitHub risolvibili.
