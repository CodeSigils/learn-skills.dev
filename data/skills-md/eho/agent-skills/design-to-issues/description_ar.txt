تحليل مستند تصميم لاستخراج قصص المستخدم وإنشاء مشكلات GitHub المقابلة. ويمكن ربطها بشكل اختياري بـ GitHub Milestone. تعمل هذه المهارة كمرحلة إعداد لتتبع مشكلات GitHub الأصلية. تأكد من استخدام هذه المهارة عندما يطلب المستخدم "إرسال مستند التصميم إلى GitHub"، أو "إنشاء مشكلات من مستند التصميم"، أو "إعداد الحدث الرئيسي"، أو يذكر تحويل المتطلبات إلى مشكلات GitHub قابلة للتنفيذ.
