Analyse un document de conception pour extraire les User Stories et crée les problèmes GitHub correspondants. Il peut éventuellement les lier à un jalon GitHub. Cette compétence agit comme une phase de configuration pour le suivi des problèmes natif de GitHub. Assurez-vous d'utiliser cette compétence chaque fois que l'utilisateur demande « d'envoyer le document de conception à GitHub », de « créer des problèmes à partir du document de conception », de « configurer le jalon » ou de mentionner la transformation des exigences en problèmes GitHub exploitables.
