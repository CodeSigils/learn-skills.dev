قم بإنشاء بيان قبول مجمد مدرك لقاعدة التعليمات البرمجية أو التحقق من صحته أو إعادة استخدامه أو استبداله لقصة GitHub واحدة. يدعم التسليم الجديد واستئناف العلاقات العامة الحالية عن طريق التحقق من مراجعة التصميم وإصدار العقد والافتراضات الأساسية ذات الصلة والمعايير الثابتة والثوابت والاختبارات والاستثناءات وحدود الحظر دون تنفيذ التعليمات البرمجية أو توسيع النطاق.
