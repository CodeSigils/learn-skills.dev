Créez, validez, réutilisez ou remplacez un manifeste d'acceptation gelé prenant en charge la base de code pour une histoire GitHub. Prend en charge les nouvelles livraisons et la reprise des PR existants en vérifiant la révision de la conception, l'émission du contrat, les hypothèses de base pertinentes, les critères stables, les invariants, les tests, les exclusions et les limites des bloqueurs sans implémenter de code ni étendre la portée.
