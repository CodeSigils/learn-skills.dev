Crea, convalida, riutilizza o sostituisci un manifesto di accettazione congelato in grado di riconoscere la base di codice per una storia di GitHub. Supporta la nuova consegna e la ripresa delle PR esistenti controllando la revisione del progetto, il contratto di emissione, le ipotesi di base pertinenti, i criteri stabili, le invarianti, i test, le esclusioni e i limiti dei bloccanti senza implementare codice o espandere l'ambito.
