Verwenden Sie diese Fähigkeit, wenn der Benutzer einen GitHub-Pull-Request-Text wünscht, der der PR-Vorlage des Repositorys folgt, oder eine prägnante Zusammenfassung der Zweigänderungen für Prüfer. Bewerben Sie sich für informelle Anfragen wie „Schreiben Sie die PR“ oder „Zusammenfassen Sie diesen Zweig“, auch wenn darin Vorlagen oder GitHub nicht explizit erwähnt werden.
