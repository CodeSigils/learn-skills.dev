Используйте этот навык, когда пользователю нужен текст запроса на извлечение GitHub, соответствующий шаблону PR репозитория, или краткое описание изменений ветки для рецензентов. Подавайте неофициальные запросы типа «напишите PR» или «подведите итоги по этой ветке», даже если в них явно не упоминаются шаблоны или GitHub.
