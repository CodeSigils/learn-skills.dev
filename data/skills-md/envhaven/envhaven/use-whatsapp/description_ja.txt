個人的な WhatsApp ↔ Claude Code ブリッジを立ち上げます。ユーザーが携帯電話から WhatsApp 番号にメッセージを送信すると、Claude Code (完全なエージェント ループ、ファイル ツール、bash を使用) が返信します。 Anthropic サブスクリプション認証を使用します (トークンごとの料金はかかりません)。チャットごとのセッション継続性、プリフラッシュメモリ抽出による毎日午前5時のセッションリセット、2つの役割のLIDホワイトリスト（所有者/読み取り専用ゲスト）、プライバシーモード付きのグループチャットサポート（所有者がボットを追加すると自動許可）、メッセージへの返信サポート、自然言語でスケジュールされたユーザー定義のcronジョブ、スラッシュコマンドなし。オプションの自動開始 (LinuxServer.io/EnvHaven、s6-rc、systemd-user、または launchd の `/custom-cont-init.d/`) により、ブリッジは再起動後も存続します。このスキルはスタンドアロンのクロード コード ブリッジを構築します。
