Bauen Sie eine persönliche WhatsApp ↔ Claude Code-Brücke auf. Der Benutzer sendet eine WhatsApp-Nummer von seinem Telefon aus und Claude Code (mit vollständiger Agentenschleife, Datei-Tools, Bash) antwortet. Verwendet Anthropic-Abonnementauthentifizierung (keine Gebühren pro Token). Kontinuität der Sitzungen pro Chat, tägliche Sitzungszurücksetzungen um 5 Uhr morgens mit Speicherextraktion vor dem Leeren, Zwei-Rollen-LID-Whitelist (Eigentümer / schreibgeschützter Gast), Gruppenchat-Unterstützung mit Datenschutzmodus (automatisch zugelassen, wenn der Eigentümer den Bot hinzufügt), Unterstützung für Antworten auf Nachrichten, benutzerdefinierte Cron-Jobs, die in natürlicher Sprache geplant sind, keine Slash-Befehle. Optionaler Autostart (`/custom-cont-init.d/` auf LinuxServer.io/EnvHaven, s6-rc, systemd-user oder launchd), damit die Bridge Neustarts übersteht. Diese Fähigkeit baut eine eigenständige Claude-Code-Brücke auf.
