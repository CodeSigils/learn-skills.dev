Поднимите личный мост WhatsApp ↔ Claude Code. Пользователь отправляет сообщение на номер WhatsApp со своего телефона, и Клод Код (с полным циклом агента, файловыми инструментами, bash) отвечает. Использует авторизацию по подписке Anthropic (без платы за токен). Непрерывность сеанса каждого чата, ежедневный сброс сеанса в 5 утра с предварительной очисткой памяти, белый список LID с двумя ролями (владелец / гость только для чтения), поддержка группового чата с режимом конфиденциальности (автоматически разрешается, когда владелец добавляет бота), поддержка ответа на сообщение, определяемые пользователем задания cron, запланированные на естественном языке, без команд с косой чертой. Необязательный автозапуск (`/custom-cont-init.d/` в LinuxServer.io/EnvHaven, s6-rc, systemd-user или launchd), чтобы мост выдержал перезагрузку. Этот навык создает автономный мост Клода Кода.
