Erklärt Cypress-Tests (E2E- und Komponententests) und beantwortet Fragen zur Verwendung und zum Verhalten von Cypress. Verwenden Sie diese Option, wenn der Benutzer die Funktionsweise eines Tests oder die Funktionsweise von Cypress erklären oder einen Test überprüfen oder kritisieren möchte, ohne Code schreiben zu müssen. Wenden Sie es auch dann an, wenn der Benutzer nicht „Cypress“ sagt (z. B. „Erklären Sie diesen Test“). Bevorzugen Sie den Cypress-Author-Skill, wenn der Benutzer Tests erstellen, reparieren oder aktualisieren möchte.
