Erstellt, aktualisiert und repariert Cypress-Tests (E2E/End-to-End- und Komponententests). Verwenden Sie diese Option, wenn der Benutzer Tests erstellen, Tests hinzufügen, Tests schreiben, Tests aktualisieren, diese Datei/Komponente testen, eine neue Spezifikation testen oder einen fehlgeschlagenen oder fehlerhaften Test beheben möchte. Auch dann anwenden, wenn der Benutzer nicht „Cypress“ sagt (z. B. „Tests für diese Datei erstellen“). Bevorzugen Sie cypress-explain, wenn der Benutzer Tests nur erklären oder überprüfen möchte, ohne den Code zu ändern.
