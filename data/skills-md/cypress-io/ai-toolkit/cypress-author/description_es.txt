Crea, actualiza y corrige pruebas de Cypress (E2E/pruebas de extremo a extremo y de componentes). Úselo cuando el usuario solicite crear pruebas, agregar pruebas, escribir pruebas, actualizar pruebas, probar este archivo/componente, nueva especificación o corregir una prueba fallida o inestable. Se aplica incluso cuando el usuario no dice "Cypress" (por ejemplo, "crear pruebas para este archivo"). Prefiera cypress-explain cuando el usuario solo quiera explicar o revisar pruebas sin cambiar el código.
