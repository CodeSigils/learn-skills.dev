إنشاء وتحديث وإصلاح اختبارات Cypress (اختبارات E2E/الشاملة واختبارات المكونات). يُستخدم عندما يطلب المستخدم إنشاء اختبارات، أو إضافة اختبارات، أو كتابة اختبارات، أو تحديث الاختبارات، أو اختبار هذا الملف/المكون، أو مواصفات جديدة، أو إصلاح اختبار فاشل أو غير مستقر. ينطبق حتى عندما لا يقول المستخدم "Cypress" (على سبيل المثال، "إنشاء اختبارات لهذا الملف"). تفضل شرح cypress عندما يريد المستخدم فقط شرح الاختبارات أو مراجعتها دون تغيير الكود.
