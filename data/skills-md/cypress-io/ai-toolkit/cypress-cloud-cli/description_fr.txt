Exécute la CLI cy-cloud pour inspecter les organisations, les projets, les exécutions, les spécifications, les tests, les captures d'écran d'échec et les données de test Replay de Cypress Cloud. À utiliser lorsque l'utilisateur mentionne Cypress Cloud, cy-cloud, cypress-cloud-cli, une URL d'exécution ou de test Cloud, des tests Cypress défaillants ou instables, Test Replay, un tri d'exécution, des artefacts Cloud ou demande pourquoi un test enregistré a échoué.
