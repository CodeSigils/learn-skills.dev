Esegue la CLI cy-cloud per ispezionare organizzazioni, progetti, esecuzioni, specifiche, test, screenshot di errori e dati di Test Replay di Cypress Cloud. Da utilizzare quando l'utente menziona Cypress Cloud, cy-cloud, cypress-cloud-cli, un URL di esecuzione o test su Cloud, test Cypress falliti o instabili, Test Replay, esecuzione di triage, artefatti Cloud o chiede perché un test registrato non è riuscito.
