يقوم بتشغيل cy-cloud CLI لفحص مؤسسات Cypress Cloud والمشاريع وعمليات التشغيل والمواصفات والاختبارات ولقطات شاشة الفشل وبيانات إعادة التشغيل الاختبارية. يُستخدم عندما يذكر المستخدم Cypress Cloud، أو cy-cloud، أو cypress-cloud-cli، أو تشغيل السحابة أو عنوان URL للاختبار، أو اختبارات Cypress الفاشلة أو غير المستقرة، أو إعادة تشغيل الاختبار، أو تشغيل الفرز، أو عناصر السحابة، أو يسأل عن سبب فشل الاختبار المسجل.
