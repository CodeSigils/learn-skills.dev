Impulse la automatización del escritorio mediante el uso de computadoras (captura de pantalla + clic + tipo) para ejercitar las funciones que cambia una solicitud de extracción en una aplicación de escritorio nativa, luego publique un informe de hallazgos solo con evidencia al RP. Hermano de agente-prueba-con-informe: use ESE para el navegador y las aplicaciones de Electron (exponen CDP, por lo que el agente-navegador los controla); use ESTE para aplicaciones nativas que no sean Chromium: Cocoa/SwiftUI/AppKit, Qt, Win32 y marcos de vista web nativos como Wails o Tauri en macOS (WKWebView), donde el navegador-agente no se puede conectar. Úselo cuando el usuario quiera que un agente pruebe manualmente una PR de aplicación de escritorio en el escritorio real y deje un informe, con frases como "el agente prueba esta PR de aplicación de escritorio", "prueba el uso de la computadora de la aplicación nativa y comenta sobre la PR", "ejecute pruebas exploratorias en la compilación de escritorio y publique un informe". macOS local e interactivo, no una puerta CI. Recopila evidencia (operaciones, capturas de pantalla, hallazgos, alcance no verificado); nunca un veredicto de pasa/falla.
