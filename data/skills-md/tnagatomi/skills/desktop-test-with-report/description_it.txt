Promuovi l'automazione desktop basata sull'uso del computer (screenshot + clic + digita) per esercitare le funzionalità modificate da una richiesta pull in un'app desktop nativa, quindi pubblica un rapporto sui risultati contenente solo prove al PR. Fratello di agent-test-with-report: usa QUELLO per browser e app Electron (espongono CDP, quindi agent-browser li guida); usa QUESTO per app native, non Chromium: Cocoa/SwiftUI/AppKit, Qt, Win32 e framework di visualizzazione web nativa come Wails o Tauri su macOS (WKWebView), dove il browser dell'agente non può collegarsi. Da utilizzare quando l'utente desidera che un agente testi manualmente un PR dell'app desktop sul desktop reale e lasci un report, con frasi come "testa l'agente questo PR dell'app desktop", "testa l'uso del computer sull'app nativa e commenta il PR", "esegui test esplorativi sulla build desktop e pubblica un report". macOS locale e interattivo: non un gate CI. Raccoglie prove (operazioni, screenshot, rilievi, ambito non verificato); mai un verdetto di superamento/bocciatura.
