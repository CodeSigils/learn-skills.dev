推动计算机使用的桌面自动化（屏幕截图 + 单击 + 键入），以在本机桌面应用程序中执行拉取请求更改的功能，然后将纯证据调查结果报告发布回 PR。 agent-test-with-report 的同级——将其用于浏览器和 Electron 应用程序（它们公开 CDP，因此代理浏览器驱动它们）；将此用于本机非 Chromium 应用程序 - Cocoa/SwiftUI/AppKit、Qt、Win32 以及 macOS 上的 Wails 或 Tauri (WKWebView) 等本机 Web 视图框架，其中代理浏览器无法附加。当用户希望代理在真实桌面上手动测试桌面应用程序 PR 并留下报告时使用，使用诸如“代理测试此桌面应用程序 PR”、“计算机使用测试本机应用程序并对 PR 进行评论”、“在桌面构建上运行探索性测试并发布报告”等短语。 macOS 本地且交互式 — 不是 CI 门。收集证据（操作、屏幕截图、调查结果、未经验证的范围）；从来没有通过/失败的判决。
