コンピューター使用のデスクトップ オートメーション (スクリーンショット + クリック + タイプ) を推進して、ネイティブ デスクトップ アプリでのプル リクエストの変更機能を実行し、証拠のみの調査結果レポートを PR に投稿します。 Agent-test-with-report の兄弟 — ブラウザと Electron アプリにはこれを使用します (CDP を公開するため、エージェント ブラウザがそれらを駆動します)。ネイティブの非 Chromium アプリ (Cocoa/SwiftUI/AppKit、Qt、Win32、および macOS 上の Wails や Tauri (WKWebView) などのネイティブ Web ビュー フレームワーク) には、これを使用してください。エージェント ブラウザーを接続できません。ユーザーがエージェントに実際のデスクトップでデスクトップ アプリの PR を手動でテストしてレポートを残してもらいたい場合に使用します。たとえば、「エージェントがこのデスクトップ アプリの PR をテストする」、「コンピューターでネイティブ アプリをテストし、PR にコメントする」、「デスクトップ ビルドで探索的テストを実行し、レポートを投稿する」などのフレーズが使用されます。 macOS ローカルかつインタラクティブ — CI ゲートではありません。証拠（操作、スクリーンショット、調査結果、未検証の範囲）を収集します。合否判定は決してありません。
