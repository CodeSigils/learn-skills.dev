Fördern Sie die Desktop-Automatisierung für die Computernutzung (Screenshot + Klicken + Tippen), um die Funktionen auszuüben, die ein Pull-Request in einer nativen Desktop-App ändert, und senden Sie dann einen reinen Beweisbericht zurück an die PR. Geschwister von agent-test-with-report – verwenden Sie DIESEN für Browser- und Electron-Apps (sie machen CDP verfügbar, sodass sie vom Agent-Browser gesteuert werden); Verwenden Sie DIESES für native Nicht-Chromium-Apps – Cocoa/SwiftUI/AppKit, Qt, Win32 und native Webview-Frameworks wie Wails oder Tauri unter macOS (WKWebView), bei denen der Agent-Browser keine Verbindung herstellen kann. Verwenden Sie diese Option, wenn der Benutzer möchte, dass ein Agent eine Desktop-App-PR manuell auf dem echten Desktop testet und einen Bericht hinterlässt, mit Ausdrücken wie „Agent testet diese Desktop-App-PR“, „Computernutzung testet die native App und kommentiert die PR“, „führen Sie explorative Tests auf dem Desktop-Build aus und veröffentlichen Sie einen Bericht“. macOS-lokal und interaktiv – kein CI-Gate. Sammelt Beweise (Operationen, Screenshots, Erkenntnisse, ungeprüfter Umfang); niemals ein Gut/Schlecht-Urteil.
