Pilotez l'automatisation du bureau à l'aide d'un ordinateur (capture d'écran + clic + saisie) pour exercer les fonctionnalités modifiées par une demande d'extraction dans une application de bureau native, puis publiez un rapport de résultats fondé uniquement sur des preuves au PR. Frère de agent-test-with-report — utilisez CELUI-CI pour les applications de navigateur et Electron (ils exposent CDP, donc l'agent-navigateur les pilote) ; utilisez CELUI-CI pour les applications natives non Chromium – Cocoa/SwiftUI/AppKit, Qt, Win32 et les frameworks de visualisation Web native comme Wails ou Tauri sur macOS (WKWebView), où le navigateur d'agent ne peut pas se connecter. À utiliser lorsque l'utilisateur souhaite qu'un agent teste manuellement un PR d'application de bureau sur le bureau réel et laisse un rapport, avec des expressions telles que « agent teste ce PR d'application de bureau », « test d'utilisation de l'ordinateur de l'application native et commente le PR », « exécutez des tests exploratoires sur la version de bureau et publiez un rapport ». macOS local et interactif – pas une porte CI. Recueille des preuves (opérations, captures d'écran, découvertes, portée non vérifiée) ; jamais de verdict réussite/échec.
