قم بإحضار مشكلات GitHub المفتوحة، واستخدم الخروج المحلي كمصدر للتنفيذ الحقيقي، واكتب خطط Markdown المحلية الكاملة للقرار. يُستخدم عندما يطلب المستخدم التخطيط لإصلاح مشكلات GitHub، أو إعداد تراكم التنفيذ من مشكلات GitHub، أو فحص المشكلات المفتوحة قبل البرمجة، أو إنتاج خطط لحل المشكلات للقراءة فقط، أو يطلب صراحةً تنفيذ مشكلة واحدة مخططة من خلال فرع، والالتزام، والعلاقات العامة، ومتابعة ما بعد الدمج.
