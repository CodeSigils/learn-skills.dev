Moteur de création unifié avec entrées multiples → script parlé + invite de couverture. Prend en charge les vidéos enregistrées à l'écran (extraction audio → transcription), les files d'attente d'URL (grattage → organisation), la traduction de sujets d'actualité (sélection de sujet → plan), les plans structurés, le texte brut et les entrées de sujets libres : six types d'entrée au total. Les étapes d’écriture des autres compétences invoquent uniformément cette compétence. À utiliser lorsque l'utilisateur dit « écrire un script parlé », « aidez-moi à écrire », « enregistrer un écran dans un script parlé », « vidéo dans un script parlé », « trouver un sujet », « en écrire un », « sujet d'actualité », « vouloir faire une vidéo », « réécrire à partir d'un lien », « réécrire un document » ou « ne sait pas quoi filmer ».
