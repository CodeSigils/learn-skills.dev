Écrire ou réécrire le README d'un projet sous forme de documentation factuelle et simple, en couvrant ce qu'est l'outil, comment l'installer et l'exécuter, quelles ressources il touche, et comment le désinstaller. Utilisez ce modèle lorsque l'utilisateur demande de créer, écrire, réécrire, améliorer ou revoir un README, se plaint que son README est trop long, trop orienté marketing, ou cache les instructions d'installation, ou dit « créer un README » / « corriger mon README ». Répondez toujours dans la langue de l'utilisateur.
