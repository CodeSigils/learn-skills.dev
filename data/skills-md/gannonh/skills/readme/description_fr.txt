Rédiger ou réécrire un projet README sous forme de documentation factuelle couvrant ce qu'est l'outil, comment l'installer et l'exécuter, ce qu'il touche et comment l'annuler. À utiliser lorsque l'utilisateur demande de créer, d'écrire, de réécrire, d'améliorer ou de réviser un README, se plaint que son README est trop long, trop marketing, ou enterre les instructions d'installation, ou dit « faire un README » / « réparer mon README ».
