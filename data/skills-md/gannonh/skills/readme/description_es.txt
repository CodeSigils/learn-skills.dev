Escribe o reescribe el README de un proyecto como documentación factual y sencilla que cubra qué es la herramienta, cómo instalarla y ejecutarla, qué afecta y cómo revertirlo. Utilízalo cuando el usuario solicite crear, escribir, reescribir, mejorar o revisar un README, se queje de que su README es demasiado extenso, está excesivamente orientado al marketing o oculta las instrucciones de instalación, o diga “haz un README” / “arregla mi README”. Por favor, responde siempre en el idioma del usuario.
