Escriba o reescriba un proyecto README como documentación objetiva simple que cubra qué es la herramienta, cómo instalarla y ejecutarla, qué toca y cómo deshacerla. Se usa cuando el usuario solicita crear, escribir, reescribir, mejorar o revisar un README, se queja de que su README es demasiado largo, demasiado pesado para marketing o entierra las instrucciones de instalación, o dice "hacer un README" / "arreglar mi README".
