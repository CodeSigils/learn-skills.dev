Scrivi o riscrivi un README del progetto come semplice documentazione fattuale che copra cos'è lo strumento, come installarlo ed eseguirlo, cosa tocca e come annullarlo. Da utilizzare quando l'utente chiede di creare, scrivere, riscrivere, migliorare o rivedere un README, si lamenta che il README è troppo lungo, troppo carico di marketing, o nasconde le istruzioni di installazione o dice "crea un README" / "correggi il mio README".
