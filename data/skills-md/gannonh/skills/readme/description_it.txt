Scrivi o riscrivi un README del progetto come documentazione fattuale e semplice che copra cosa è lo strumento, come installarlo e avviarlo, cosa tocca e come annullarlo. Usa quando l'utente chiede di creare, scrivere, riscrivere, migliorare o revisionare un README, si lamenta che il suo README è troppo lungo, troppo orientato al marketing, o seppellisce le istruzioni d'installazione, oppure dice “make a README” / “fix my README”.
