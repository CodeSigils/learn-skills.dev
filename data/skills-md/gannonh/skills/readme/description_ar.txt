اكتب أو أعد كتابة ملف README للمشروع كوثيقة واقعية بسيطة تغطي ما هي الأداة، وكيفية تثبيتها وتشغيلها، وما الذي تؤثر فيه، وكيفية التراجع عنها. استخدم ذلك عندما يطلب المستخدم إنشاء أو كتابة أو إعادة كتابة أو تحسين أو مراجعة ملف README، أو يشتكي من أن README خاصته طويل جداً، أو يركز بشكل مفرط على التسويق، أو يدفن إرشادات التثبيت، أو يقول «أنشئ README» أو «صلح README خاص بي». يرجى دائماً الرد بلغة المستخدم.
