اكتب أو أعد كتابة ملف README لمشروع كوثيقة واقعية وبسيطة تغطي ما هي الأداة، وكيفية تثبيتها وتشغيلها، وما الذي تتعامل معه، وكيفية التراجع عنها. استخدم هذا عندما يطلب المستخدم إنشاء، كتابة، إعادة كتابة، تحسين، أو مراجعة README، أو يشتكي من أن README الخاص به طويل جداً، أو يركز على التسويق أكثر من اللازم، أو يخفى تعليمات التثبيت، أو يقول "أنشئ README" / "صلح README".  

يرجى دائمًا الرد بلغة المستخدم.
