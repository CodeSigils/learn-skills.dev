دليل تطوير كود شبكة الوكيل (Bridge Worker / CLI / Protocol).  
يتم استخدامه عندما تحتاج إلى تعديل التعليمات البرمجية أو المحولات أو العمال أو البروتوكولات الخاصة بالمستودع الفرعي لشبكة الوكيل.  
كلمات التشغيل: تطوير عامل الشبكة، تطوير عامل الجسر، تطوير CLI، تطوير المحول، محول الوكيل، بروتوكول الجسر، تطوير الكائنات الدائمة، بروتوكول الشبكة، تعديل شبكة الوكيل، رمز الشبكة، نشر العامل، إصدار CLI.
