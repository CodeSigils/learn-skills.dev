Guía de desarrollo de código de Agent Mesh (Bridge Worker/CLI/Protocolo).  
Se utiliza cuando necesita modificar el código, los adaptadores, los trabajadores o los protocolos del subrepositorio de malla de agente.  
Palabras desencadenantes: desarrollo de trabajadores de malla, desarrollo de trabajadores de puente, desarrollo de CLI, desarrollo de adaptadores, adaptador de agente, protocolo de puente, desarrollo de objetos duraderos, protocolo de malla, modificación de malla de agente, código de malla, implementación de trabajadores, lanzamiento de CLI.
