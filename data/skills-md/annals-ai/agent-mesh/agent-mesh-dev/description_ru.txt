Руководство по разработке кода Agent Mesh (Bridge Worker/CLI/Protocol).  
Используется, когда вам нужно изменить код, адаптеры, воркеры или протоколы субрепозитория агентной сетки.  
Триггерные слова: разработка Mesh Worker, разработка Bridge Worker, Разработка CLI, Разработка адаптера, Адаптер агента, Протокол моста, Разработка устойчивых объектов, Mesh-протокол, Модификация агентной сетки, Mesh-код, Развертывание Worker, Выпуск CLI.
