Commandes OpenSSL pour les certificats, le débogage TLS et le chiffrement. À utiliser lorsque l'utilisateur mentionne « openssl », « certificat SSL », « tls », « certificat auto-signé », « chaîne de certificats », « CSR », « clé privée », « expiration du certificat », « débogage https », « mTLS », « autorité de certification » ou toute tâche de certificat/chiffrement.
