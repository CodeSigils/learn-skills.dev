أنماط Next.js للتوجيه وجلب البيانات ومكونات الخادم والنشر. يُستخدم عندما يذكر المستخدم "next.js"، أو "nextjs"، أو "app router"، أو "pages router"، أو "مكونات الخادم"، أو "إجراءات الخادم"، أو "next/image"، أو "next/link"، أو "getServerSideProps"، أو "getStaticProps"، أو "البرامج الوسيطة"، أو إنشاء تطبيقات React باستخدام Next.js.
