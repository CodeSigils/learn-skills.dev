Среда выполнения Bun для быстрого выполнения JavaScript/TypeScript, управления пакетами, объединения их в пакеты и тестирования. Используйте, когда пользователь упоминает «булочку», «запуск булочки», «установку булочки», «банкс», «тест булочки», «сборку булочки», «альтернативу быстрого узла», «оболочку булочки» или переход с Node на Bun.
