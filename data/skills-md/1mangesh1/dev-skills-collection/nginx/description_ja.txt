リバース プロキシ、SSL/TLS、ロード バランシング、静的ホスティング、キャッシュ、セキュリティ強化のための Nginx Web サーバー構成。ユーザーが「nginx の構成」、「リバース プロキシのセットアップ」、「SSL の追加」、「nginx ロケーション ブロック」、「ロード バランサーの構成」、「静的ファイルの提供」、「nginx レート制限」、「nginx キャッシュ」、「nginx セキュリティ ヘッダー」、「nginx gzip」、「nginx docker」、「502 の不正なゲートウェイの修正」、「大きすぎる 413 エンティティの修正」を要求する場合に使用します。 「nginx リライト」、「nginx リダイレクト」、「nginx アクセス制御」、「nginx ロギング」、「nginx パフォーマンス チューニング」、または任意の Web サーバー構成タスク。
