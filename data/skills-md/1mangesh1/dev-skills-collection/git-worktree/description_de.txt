Git-Arbeitsbäume zum gleichzeitigen Arbeiten an mehreren Zweigen ohne Stashing oder Klonen. Wird verwendet, wenn der Benutzer „git worktree“, „mehrere Zweige“, „an zwei Zweigen arbeiten“, „parallele Zweige“, „Zweige ohne Stashing wechseln“, „Arbeitsbaum“, „isolierte Zweigarbeit“ erwähnt, an einem Hotfix arbeiten muss, während eine Funktion ausgeführt wird, „Bare Repo Worktree“, „Dotfiles Bare Repo“, „Worktree vs. Stash“, „Worktree vs. Klon“, „verwaister Arbeitsbaum“ oder „Worktree Prune“.
