Рабочие деревья Git для одновременной работы с несколькими ветвями без хранения или клонирования. Используйте, когда пользователь упоминает «рабочее дерево git», «несколько ветвей», «работа над двумя ветвями», «параллельные ветки», «переключение ветвей без кэширования», «рабочее дерево», «работа с изолированной ветвью», необходимость работы над исправлением во время работы функции, «чистое рабочее дерево репозитория», «голый репозиторий точечных файлов», «рабочее дерево против тайника», «рабочее дерево против клона», «сиротское рабочее дерево» или «обрезка рабочего дерева».
