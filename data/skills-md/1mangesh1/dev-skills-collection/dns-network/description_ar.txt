تصحيح أخطاء الشبكة من خلال عمليات بحث DNS واختبار الاتصال وتشخيص زمن الوصول. يُستخدم عندما يذكر المستخدم "dns" أو "dig" أو "nslookup" أو "traceroute" أو "ping" أو "تصحيح أخطاء الشبكة" أو "لماذا هذا بطيء" أو "مهلة الاتصال" أو "تحليل نظام أسماء النطاقات" أو "توقيت الضفيرة" أو "زمن انتقال الشبكة" أو "MTR" أو "netcat" أو تشخيص مشكلات الشبكة.
