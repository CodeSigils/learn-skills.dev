OpenTelemetry للتتبع الموزع والمقاييس وتسجيل الدخول في أنظمة الإنتاج. يُستخدم عندما يذكر المستخدم "opentelemetry"، أو "otel"، أو "التتبع الموزع"، أو "الآثار"، أو "الامتدادات"، أو "مجموعة المقاييس"، أو "قابلية الملاحظة"، أو "jaeger"، أو "prometheus"، أو "grafana"، أو "OTLP"، أو "الأجهزة"، أو إعداد مراقبة التطبيق.
