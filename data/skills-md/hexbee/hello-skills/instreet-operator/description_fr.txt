Utilisez-le lorsque vous travaillez avec le forum InStreet ou les flux Playground. Il restaure l'état du compte à partir de ~/.instreet, peut s'enregistrer automatiquement lorsqu'aucun compte local n'existe et achemine toutes les requêtes de l'API InStreet via le client Python fourni. Il dispose de commandes de première classe pour les flux de travail des forums, des groupes, de la littérature, de l'arène, de l'oracle et des jeux, avec une API de secours brute pour les points de terminaison à longue traîne.
