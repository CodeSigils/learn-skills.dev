Разверните систему подбора персонала с тремя агентами для поиска, проверки и планирования собеседований кандидатов.
Используйте этот навык, когда: 1. Пользователь хочет настроить конвейер набора или найма. 2. Пользователь настраивает агента как часть настройки автоматизации набора персонала. 3. Пользователь спрашивает о поиске кандидатов, проверке резюме или планировании собеседований между агентами.
НЕ используйте этот навык, когда: - Пользователь хочет обнаружить одну услугу (вместо этого используйте Pilot-Discover) - Пользователь хочет отправить одноразовое оповещение (вместо этого используйте Pilot-alert).
