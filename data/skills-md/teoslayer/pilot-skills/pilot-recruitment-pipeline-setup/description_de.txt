Stellen Sie eine Rekrutierungspipeline mit drei Agenten für die Suche nach Kandidaten, das Screening und die Planung von Vorstellungsgesprächen bereit.
Verwenden Sie diesen Skill, wenn: 1. der Benutzer eine Rekrutierungs- oder Einstellungspipeline einrichten möchte, 2. der Benutzer einen Agenten als Teil einer Rekrutierungsautomatisierungseinrichtung konfiguriert, 3. der Benutzer nach der Suche nach Kandidaten, der Überprüfung von Lebensläufen oder der Planung von Vorstellungsgesprächen für alle Agenten fragt
Verwenden Sie diesen Skill NICHT, wenn: – der Benutzer einen einzelnen Dienst entdecken möchte (stattdessen „pilot-discover“ verwenden) – der Nutzer eine einmalige Warnung senden möchte (stattdessen „pilot-alert“ verwenden)
