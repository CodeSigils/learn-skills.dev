Déployez un pipeline de recrutement avec 3 agents pour la recherche de candidats, la sélection et la planification des entretiens.
Utilisez cette compétence lorsque : 1. L'utilisateur souhaite configurer un pipeline de recrutement ou d'embauche 2. L'utilisateur configure un agent dans le cadre d'une configuration d'automatisation du recrutement 3. L'utilisateur pose des questions sur la recherche de candidats, la sélection de CV ou la planification d'entretiens entre agents.
N'utilisez PAS cette compétence lorsque : - L'utilisateur souhaite découvrir un seul service (utilisez plutôt pilot-discover) - L'utilisateur souhaite envoyer une alerte ponctuelle (utilisez plutôt pilot-alert)
