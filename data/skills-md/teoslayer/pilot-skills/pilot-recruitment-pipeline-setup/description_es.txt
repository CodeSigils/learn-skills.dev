Implementar un canal de reclutamiento con 3 agentes para la búsqueda, selección y programación de entrevistas de candidatos.
Utilice esta habilidad cuando: 1. El usuario desee configurar un canal de reclutamiento o contratación 2. El usuario esté configurando un agente como parte de una configuración de automatización de reclutamiento 3. El usuario pregunte sobre la búsqueda de candidatos, la selección de currículums o la programación de entrevistas entre agentes
NO utilice esta habilidad cuando: - El usuario quiera descubrir un único servicio (use pilot-discover en su lugar) - El usuario quiera enviar una alerta única (use pilot-alert en su lugar)
