التنفيذ هو سير عمل Git الذي يحافظ على تغييرات المستودع. أثناء مرحلة الإعداد، يقرأ readsdocs/user/git‑preferences.md ويحدد سياق Git للتشغيل الحالي؛ نقطة التفتيش والانتهاء ترث هذا السياق، وإدارة الفروع/أشجار العمل، والمزامنة، والالتزام، والدفع، والدمج، والتنظيف. إذا كان التكوين مفقودًا أو كان السلوك غامضًا، فسيتم تهيئة كل عنصر أو المطالبة به.
