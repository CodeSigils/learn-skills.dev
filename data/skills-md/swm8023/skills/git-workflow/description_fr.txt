Exécute un workflow Git qui conserve les modifications du référentiel. Pendant la préparation, il lit docs/user/git-preferences.md et établit le contexte Git actuel ; le point de contrôle et la finalisation héritent de ce contexte, gérant les branches/arbres de travail, la synchronisation, les validations, les push, les fusions et le nettoyage ; si la configuration est manquante ou si le comportement est ambigu, il initialise ou demande chaque élément.
