L'exécution est un workflow Git qui conserve les modifications du référentiel. Pendant la phase de préparation, il readsdocs/user/git‑preferences.md et établit le contexte Git pour l'exécution en cours ; checkpoint et finalize héritent de ce contexte, gérant les branches/arbres de travail, la synchronisation, la validation, le push, la fusion et le nettoyage. Si une configuration est manquante ou si le comportement est ambigu, il initialise ou demande chaque élément.
