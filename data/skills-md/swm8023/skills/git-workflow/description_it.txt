L'esecuzione è un flusso di lavoro Git che rende persistenti le modifiche del repository. Durante la fase di preparazione, leggedocs/user/git‑preferences.md e stabilisce il contesto Git per l'esecuzione corrente; checkpoint e finalize ereditano questo contesto, gestendo rami/alberi di lavoro, sincronizzazione, commit, push, unione e pulizia. Se manca una configurazione o il comportamento è ambiguo, inizializza o richiede ciascun elemento.
