L'esecuzione esegue un flusso di lavoro Git che modifica in modo persistente il repository. Durante la fase di preparazione leggedocs/user/git‑preferences.md e stabilisce il contesto Git per questa esecuzione; checkpoint e finalizzazione ereditano quel contesto, gestendo la gestione dei rami/alberi di lavoro, la sincronizzazione, il commit, il push, l'unione e la pulizia. Se manca la configurazione o il comportamento è ambiguo, inizializza le impostazioni predefinite o richiede individualmente ciascun elemento.
