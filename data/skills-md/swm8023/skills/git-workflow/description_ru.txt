Выполнение — это рабочий процесс Git, который сохраняет изменения в репозитории. На этапе подготовки он читает файлsdocs/user/git‑preferences.md и устанавливает контекст Git для текущего запуска; checkpoint и Finalize наследуют этот контекст, управляя ветвями/рабочими деревьями, синхронизацией, фиксацией, отправкой, слиянием и очисткой. Если конфигурация отсутствует или поведение неоднозначно, она инициализирует или запрашивает каждый элемент.
