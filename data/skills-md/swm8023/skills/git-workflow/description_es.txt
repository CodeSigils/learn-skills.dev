La ejecución implementa un flujo de trabajo de Git que persiste los cambios del repositorio. Durante la fase de preparación, leedocs/user/git-preferences.md y establece el contexto de Git para esta ejecución; checkpoint y finalize heredan este contexto, manejando la administración de ramas/árboles de trabajo, sincronización, confirmación, inserción, fusión y limpieza. Si falta la configuración o el comportamiento es ambiguo, se inicializa o solicita cada elemento.
