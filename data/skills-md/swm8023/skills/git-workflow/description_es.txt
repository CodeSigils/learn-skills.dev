La ejecución es un flujo de trabajo de Git que persiste los cambios del repositorio. Durante la fase de preparación, leedocs/user/git‑preferences.md y establece el contexto de Git para la ejecución actual; checkpoint y finalize heredan este contexto, administran ramas/árboles de trabajo, sincronización, confirmación, inserción, fusión y limpieza. Si falta una configuración o el comportamiento es ambiguo, se inicializa o solicita cada elemento.
