Grabe demostraciones de navegador basadas en IA con screencli. Un comando crea un pulido
Grabación de pantalla con fondos degradados, zoom automático, resaltados de clic y
el cursor rastrea y luego lo sube a un enlace que se puede compartir. Usar cuando el usuario quiera
para grabar una demostración, un screencast, un recorrido o un vídeo de una aplicación web.
