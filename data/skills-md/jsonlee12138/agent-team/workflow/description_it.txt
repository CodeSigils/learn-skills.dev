Crea modelli di flusso di lavoro di distribuzione locale del progetto ed esegui o riprendi tali flussi di lavoro come controller principale orchestrando i comandi "agent-team" esistenti senza modificare "agent-team". Da utilizzare quando l'utente chiede di creare file di flusso di lavoro, eseguire "workflow.yaml", riprendere le esecuzioni di flussi di lavoro bloccate, gestire "run-state.yaml" o modellare flussi di approvazione del controller dev-first, test-first o con ramo limitato tra i ruoli.
