Scomponi i documenti relativi ai requisiti, alla progettazione o al brainstorming in bozze di attività rivedibili con una funzione per attività e un file per attività, quindi crea pacchetti di attività "agent-team" solo dopo l'approvazione esplicita. Da utilizzare quando si trasforma un documento in attività, si suddividono attività di grandi dimensioni, si convalidano i limiti delle attività o si preparano file di attività approvati per la "creazione di attività agente-team".
