Utilice esta habilidad para analizar cómo se escribe realmente una aplicación Laravel y registre sus convenciones como reglas compartidas. Se activa cuando el usuario desea detectar, inferir, documentar o estandarizar las convenciones del proyecto o el estilo de codificación, configurar o hacer crecer `.ai/rules`, resolver patrones mixtos o conflictivos (por ejemplo, "¿estamos usando solicitudes de formulario o validación en línea?"), o incorporar agentes y compañeros de equipo a "cómo hacemos las cosas aquí". Cubre: un barrido sistemático de ~49 dimensiones de la convención de Laravel (validación, modelos, arquitectura, pruebas, interfaz, base de datos, consola), descubrimiento abierto de patrones internos, informes de conflictos y reglas de registro con alcance en las rutas correctas a través de la herramienta MCP Boost `record-rule`. No lo use para revisar código una sola vez, forzar el formato de un linter que ya maneja o editar archivos `.ai/rules` a mano.
