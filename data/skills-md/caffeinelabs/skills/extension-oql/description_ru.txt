Сделайте данные канистры доступными для запроса агентом Caffeine Data Intelligence. Используйте всякий раз, когда приложение хранит структурированные данные (карты/списки/массивы записей), которые должны быть описаны на естественном языке — «основные клиенты», «доход по регионам», «активные проекты». Добавляет обнаруживаемую `schema()` и конечную точку запроса JSON `execute()` через миксин `Expose` пакета mops `caffeineai-oql`.
