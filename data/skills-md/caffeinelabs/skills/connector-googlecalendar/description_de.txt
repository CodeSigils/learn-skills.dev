OBLIGATORISCHES Rezept für jeden Caffeine-Build, der bevorstehende Ereignisse auflistet oder Ereignisse im eigenen Google-Kalender des Benutzers erstellt. Der EINZIGE unterstützte Pfad ist das Mops-Paket „googlecalendar-client“ (Calendar REST API v3) in Kombination mit dem Mops-Paket „google-oauth“ (Token-Austausch + Aktualisierung + PKCE). Das manuelle Rollen von „ic.http_request“-Aufrufen an „oauth2.googleapis.com“ oder „www.googleapis.com/calendar/v3“ ist ein VERBOTENES Anti-Pattern – es umgeht die Trägerauthentifizierung, Replikationskostenschutzmaßnahmen und die Prozentkodierung und JSON-Analyse der „google-oauth“-Bibliothek. Laden Sie diesen Skill immer dann, wenn der Benutzer, die Spezifikation oder eine frühere Aufgabe Planung, Kalenderereignisse, Termine, Besprechungen, „Zum Kalender hinzufügen“ oder eine entsprechende Formulierung erwähnt – und BEVOR Sie Code schreiben, der einen Google-Endpunkt berührt.
