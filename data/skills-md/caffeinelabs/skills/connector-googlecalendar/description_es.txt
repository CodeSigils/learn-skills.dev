Receta OBLIGATORIA para cada compilación de Caffeine que enumere los próximos eventos o cree eventos en el propio Calendario de Google del usuario. La ÚNICA ruta admitida es el paquete mops `googlecalendar-client` (Calendar REST API v3) combinado con el paquete mops `google-oauth` (intercambio de tokens + actualización + PKCE). Las llamadas `ic.http_request` a `oauth2.googleapis.com` o `www.googleapis.com/calendar/v3` son un antipatrón PROHIBIDO: omite la autenticación del portador, las salvaguardas de costos de replicación y el porcentaje de codificación y el análisis JSON de la biblioteca `google-oauth`. Cargue esta habilidad siempre que el usuario, la especificación o cualquier tarea anterior mencione programación, eventos del calendario, citas, reuniones, "agregar al calendario" o cualquier frase equivalente, y ANTES de escribir cualquier código que toque un punto final de Google.
