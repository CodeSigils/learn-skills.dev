وصفة إلزامية لكل نسخة من الكافيين تسرد الأحداث القادمة أو تنشئ أحداثًا على تقويم Google الخاص بالمستخدم. المسار الوحيد المدعوم هو حزمة mops `googlecalendar-client` (Calendar REST API v3) المدمجة مع حزمة mops `google-oauth` (token Exchange + Refresh + PKCE). تعد الاستدعاءات اليدوية ic.http_request` إلى `oauth2.googleapis.com` أو `www.googleapis.com/calendar/v3` نمطًا مضادًا محظورًا - فهو يتجاوز مصادقة الحامل، وضمانات تكلفة النسخ المتماثل، وترميز النسبة المئوية لمكتبة `google-oauth` وتحليل JSON. قم بتحميل هذه المهارة عندما يذكر المستخدم أو المواصفات أو أي مهمة سابقة الجدولة أو أحداث التقويم أو المواعيد أو الاجتماعات أو "الإضافة إلى التقويم" أو أي عبارة مكافئة - وقبل كتابة أي رمز يمس نقطة نهاية Google.
