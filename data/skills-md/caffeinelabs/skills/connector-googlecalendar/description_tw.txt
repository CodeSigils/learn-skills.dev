每個 Caffeine 建立的強製配方，列出即將發生的事件或在使用者自己的 Google 日曆上建立事件。唯一支援的路徑是「googlecalendar-client」mops 套件（日曆 REST API v3）與「google-oauth」mops 套件（令牌交換+刷新+PKCE）結合。對「oauth2.googleapis.com」或「www.googleapis.com/calendar/v3」的手動「ic.http_request」呼叫是一種禁止的反模式——它繞過了承載身份驗證、複製成本保護以及「google-oauth」庫的百分比編碼和 JSON 解析。每當使用者、規範或任何先前任務提到日程安排、日曆事件、約會、會議、「新增至日曆」或任何等效措辭時，以及在編寫任何涉及 Google 端點的程式碼之前，請加載此技能。
