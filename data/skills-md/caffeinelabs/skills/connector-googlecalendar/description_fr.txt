Recette OBLIGATOIRE pour chaque version de Caffeine qui répertorie les événements à venir ou crée des événements sur le propre agenda Google de l'utilisateur. Le SEUL chemin pris en charge est le package mops `googlecalendar-client` (Calendar REST API v3) combiné avec le package mops `google-oauth` (échange de jetons + actualisation + PKCE). Les appels `ic.http_request` lancés manuellement à `oauth2.googleapis.com` ou `www.googleapis.com/calendar/v3` sont un anti-modèle INTERDIT : il contourne l'authentification du support, les garanties de coût de réplication, ainsi que le codage en pourcentage et l'analyse JSON de la bibliothèque `google-oauth`. Chargez cette compétence chaque fois que l'utilisateur, la spécification ou toute tâche antérieure mentionne la planification, les événements du calendrier, les rendez-vous, les réunions, "ajouter au calendrier" ou toute formulation équivalente - et AVANT d'écrire du code touchant un point de terminaison Google.
