Utilice el paquete mops `googlemail-client` cada vez que el usuario solicite al contenedor que envíe un correo electrónico, redacte un borrador, enumere o lea mensajes de Gmail, o busque el perfil de Gmail del usuario autenticado.  El paquete incluye la API REST v1 de Gmail en `https://gmail.googleapis.com` mediante llamadas HTTPS salientes.
