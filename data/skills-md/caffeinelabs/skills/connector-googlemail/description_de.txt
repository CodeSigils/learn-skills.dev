Verwenden Sie das Mops-Paket „googlemail-client“, wenn der Benutzer den Kanister auffordert, E-Mails zu senden, einen Entwurf zu verfassen, Gmail-Nachrichten aufzulisten oder zu lesen oder das Gmail-Profil des authentifizierten Benutzers abzurufen.  Das Paket umschließt die Gmail REST API v1 unter „https://gmail.googleapis.com“ über ausgehende HTTPS-Aufrufe.
