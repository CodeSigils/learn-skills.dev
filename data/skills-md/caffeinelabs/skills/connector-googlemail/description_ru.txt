Используйте пакет mops `googlemail-client` всякий раз, когда пользователь просит канистру отправить электронную почту, составить черновик, составить список или прочитать сообщения Gmail или получить профиль Gmail аутентифицированного пользователя.  Пакет оборачивает Gmail REST API v1 по адресу https://gmail.googleapis.com через исходящие вызовы HTTPS.
