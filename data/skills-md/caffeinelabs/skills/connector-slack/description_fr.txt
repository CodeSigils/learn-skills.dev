Recette EXPÉRIMENTALE ET NON TESTÉE pour publier des messages sur un espace de travail Slack à partir d'une cartouche de caféine via le package mops `slack-client` (API Web Slack). Utilisez-le lorsque l'utilisateur souhaite que son application envoie un message à une chaîne Slack : "publier sur Slack", "notifier une chaîne", "envoyer un message Slack" ou équivalent. Le client est une version préliminaire de la version 0.0.3 (bot `xoxb-` ou jeton utilisateur `xoxp-`) : son chemin de requête est vérifié par rapport à l'API Slack en direct (un vrai message est publié), mais le décodage de la réponse réussie n'est pas encore confirmé par l'exécution, alors traitez-le comme un point de départ et ne présentez PAS encore Slack comme une fonctionnalité de plate-forme entièrement prise en charge. Lancer manuellement les appels « ic.http_request » vers « slack.com/api » est toujours une mauvaise décision : préférez le client généré afin que l'authentification du porteur, le codage en pourcentage et l'analyse JSON soient gratuits.
