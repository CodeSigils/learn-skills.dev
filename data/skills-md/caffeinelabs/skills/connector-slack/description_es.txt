Receta EXPERIMENTAL NO PROBADA para publicar mensajes en un espacio de trabajo de Slack desde un recipiente de cafeína a través del paquete mops `slack-client` (Slack Web API). Úselo cuando el usuario quiera que su aplicación envíe un mensaje a un canal de Slack: "publicar en Slack", "notificar a un canal", "enviar un mensaje de Slack" o equivalente. El cliente es una versión previa al lanzamiento 0.0.3 (bot `xoxb-` o token de usuario `xoxp-`): su ruta de solicitud se verifica con la API de Slack en vivo (un mensaje real se publica), pero la decodificación de respuesta exitosa aún no está confirmada en tiempo de ejecución, así que trátelo como un punto de partida y NO presente Slack como una característica de plataforma totalmente compatible todavía. Realizar llamadas manualmente `ic.http_request` a `slack.com/api` sigue siendo un movimiento equivocado: prefiera el cliente generado para que la autenticación de portador, la codificación porcentual y el análisis JSON sean gratuitos.
