ЭКСПЕРИМЕНТАЛЬНЫЙ, НЕПРОВЕРАННЫЙ рецепт публикации сообщений в рабочем пространстве Slack из канистры с кофеином через пакет швабр `slack-client` (Slack Web API). Используйте его, когда пользователь хочет, чтобы его приложение отправило сообщение в канал Slack — «опубликовать в Slack», «уведомить канал», «отправить сообщение Slack» или что-то подобное. Клиент представляет собой предварительную версию 0.0.3 (бот «xoxb-» или пользовательский токен «xoxp-»): его путь запроса проверяется на соответствие реальному API Slack (реальные сообщения), но декодирование успешного ответа еще не подтверждено во время выполнения, поэтому рассматривайте его как отправную точку и НЕ представляйте Slack как полностью поддерживаемую функцию платформы. Ручная обработка вызовов `ic.http_request` к `slack.com/api` по-прежнему является неправильным шагом — отдайте предпочтение сгенерированному клиенту, чтобы аутентификация носителя, процентное кодирование и анализ JSON были бесплатными.
