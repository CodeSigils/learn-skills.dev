「slack-client」mops パッケージ (Slack Web API) を介してカフェイン キャニスターから Slack ワークスペースにメッセージを投稿するための実験的で未テストのレシピ。ユーザーがアプリから Slack チャネルにメッセージを送信することを希望する場合 (「Slack に投稿する」、「チャネルに通知する」、「Slack メッセージを送信する」など) に使用します。クライアントはプレリリース 0.0.3 ドロップ (ボット `xoxb-` またはユーザー `xoxp-` トークン) です。そのリクエスト パスはライブ Slack API (実際のメッセージ投稿) に対して検証されますが、成功と応答のデコードはまだ実行時に確認されていないため、これを出発点として扱い、Slack を完全にサポートされるプラットフォーム機能としてまだ提示しないでください。 `slack.com/api` への `ic.http_request` 呼び出しを手動で実行するのは、依然として間違った行動です。ベアラー認証、パーセント エンコーディング、および JSON 解析が無料で利用できるように、生成されたクライアントを優先します。
