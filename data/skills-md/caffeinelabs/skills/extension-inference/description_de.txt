OBLIGATORISCHES Rezept für jeden Caffeine-Build, der einen LLM, Chatbot, GPT oder ChatGPT **on Caffeine Inference** aufruft (kein vom Benutzer eingefügter OpenAI-Schlüssel). Der EINZIGE unterstützte Pfad ist das Mops-Paket „caffeineai-inference-client“ mit „Config.fromEnv<system>()“, das dem Kanister eine gebrauchsfertige authentifizierte Konfiguration übergibt – die App fragt nie nach einem Schlüssel, speichert ihn oder gibt ihn zurück. Das manuelle Weiterleiten von „ic.http_request“ an „inference.caffeine.ai“ (oder „api.openai.com“) ist ein VERBOTENES Anti-Pattern. Laden Sie diesen Skill immer dann, wenn der Benutzer, die Spezifikation oder eine frühere Aufgabe ein LLM in einer Caffeine-App wünscht – und BEVOR Sie Code schreiben, der mit einem LLM-Host kommuniziert. Verwenden Sie „extension-openai“ nur, wenn die Spezifikation ausdrücklich einen vom Benutzer oder Administrator eingefügten „sk-...“-Schlüssel für „api.openai.com“ erfordert.
