Receta OBLIGATORIA para cada compilación de Caffeine que llame a un LLM, chatbot, GPT o ChatGPT **en Caffeine Inference** (sin clave OpenAI pegada por el usuario). La ÚNICA ruta admitida es el paquete mops `caffeineai-inference-client` con `Config.fromEnv<system>()`, que entrega al recipiente una configuración autenticada lista para usar; la aplicación nunca solicita, almacena ni devuelve una clave. Pasar manualmente `ic.http_request` a `inference.caffeine.ai` (o `api.openai.com`) es un antipatrón PROHIBIDO. Cargue esta habilidad siempre que el usuario, la especificación o cualquier tarea previa desee un LLM en una aplicación de Caffeine, y ANTES de escribir cualquier código que se comunique con un host de LLM. Utilice `extension-openai` solo cuando la especificación requiera explícitamente una clave `sk-...` pegada por el usuario o el administrador en `api.openai.com`.
