Recette OBLIGATOIRE pour chaque build Caffeine qui appelle un LLM, un chatbot, un GPT ou un ChatGPT **sur Caffeine Inference** (pas de clé OpenAI collée par l'utilisateur). Le SEUL chemin pris en charge est le package vadrouilles `caffeineai-inference-client` avec `Config.fromEnv<system>()`, qui remet à la cartouche une configuration authentifiée prête à l'emploi — l'application ne demande, ne stocke ou ne renvoie jamais de clé. Le lancement manuel de `ic.http_request` vers `inference.caffeine.ai` (ou `api.openai.com`) est un anti-modèle INTERDIT. Chargez cette compétence chaque fois que l'utilisateur, la spécification ou toute tâche antérieure souhaite un LLM dans une application Caffeine - et AVANT d'écrire un code qui communique avec un hôte LLM. Utilisez `extension-openai` uniquement lorsque la spécification nécessite explicitement une clé `sk-...` collée par l'utilisateur ou l'administrateur sur `api.openai.com`.
