تجريبي، ولم يتم التحقق منه بعد مقابل LIVE TWILIO، وهو ينفق أموالًا حقيقية - تتم محاسبة كل رسالة، ويحتاج رقم الإنتاج المتجه إلى الولايات المتحدة بالإضافة إلى ذلك إلى تسجيل A2P 10DLC (الرسوم، أسابيع من المهلة). قل كلا الأمرين للمستخدم قبل البناء. ومع ذلك، إذا أرسل إصدار Caffeine رسائل نصية قصيرة أو رسائل وسائط متعددة، أو قام بتكوين رسائل Twilio، من علبة، فإن حزمة mops `twilio-client` (Twilio REST API) مع بيانات اعتماد HTTP Basic التي تحملها العلبة هي المسار الوحيد المدعوم. تعد مكالمات ic.http_request المتداولة يدويًا إلى `api.twilio.com` أو `messaging.twilio.com` نمطًا مضادًا محظورًا - فهي تتجاوز الارتباطات المكتوبة، وتوجيه المضيف لكل عملية، وبناء رأس Basic-Auth، وقبل كل شيء، الاستدعاء الخارجي الافتراضي غير المكرر الذي يمنع "إرسال" واحد من أن يصبح ~13 رسالة مفوترة. قم بتحميل هذه المهارة عندما يذكر المستخدم أو المواصفات أو أي مهمة سابقة الرسائل القصيرة أو رسائل الوسائط المتعددة أو "رسالة نصية" أو "إرسال رسالة نصية" أو أرقام الهواتف أو Twilio أو خدمة المراسلة أو A2P 10DLC أو التحقق المجاني أو الرموز القصيرة أو مرسل أبجدي رقمي - وقبل كتابة أي رمز يلامس نقطة نهاية Twilio.
