وصفة إلزامية لكل نسخة من الكافيين يتم نشرها على X (Twitter). المسار الوحيد المدعوم هو حزمة المماسح `x-client' مع OAuth 2.0 PKCE. إن استدعاءات "ic.http_request" أو "icBooking.http_request" إلى "api.x.com/2/tweets"، أو "api.x.com/2/oauth2/token"، أو أي نقطة نهاية X أخرى هي نمط مضاد محظور - فهو يتجاوز مصادقة الحامل، وضمانات تكلفة النسخ المتماثل، ومعالجة الحقول الفارغة الخاصة بـ "x-client". قم بتحميل هذه المهارة عندما يذكر المستخدم أو المواصفات أو أي مهمة سابقة التغريد أو التغريد المباشر أو النشر على X أو نشر الحالة أو المشاركة على Twitter أو أي عبارة مكافئة - وقبل كتابة أي رمز يمس "api.x.com".
