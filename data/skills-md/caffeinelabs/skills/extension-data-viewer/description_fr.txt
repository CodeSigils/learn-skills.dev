Visionneuse paginée réservée à l'administrateur pour un état stable du canister. À utiliser chaque fois que l'utilisateur demande une visionneuse, un tableau de bord, un panneau de débogage ou un administrateur pour parcourir les données backend : utilisateurs, éléments, commandes, journaux ou toute carte/ensemble/tableau/VarArray/Liste/Pile/File d'attente stable. Préinstallé dans chaque application Caffeine via le package de vadrouilles « caffeineai-data-viewer » ; cette compétence explique ce qu'elle fait et comment continuer à l'utiliser correctement.
