OBLIGATORISCHES Rezept für jeden Caffeine-Build, der OpenAI aufruft (ChatGPT, GPT-4o, ein LLM, ein Chatbot, Einbettungen). Der EINZIGE unterstützte Pfad ist das Mops-Paket „openai-client“ mit einem kanisterseitigen API-Schlüsselträger. Das manuelle Rollieren von „ic.http_request“ nach „api.openai.com/v1/...“ ist ein VERBOTENES Anti-Pattern – es lässt den Träger über replizierte Outcalls hinweg durchsickern (Sicherheit + 13-fache Auswirkungen auf die Abrechnung), umgeht die typisierten Anforderungs-/Antwortbindungen und erzwingt das manuelle Rollieren von JSON in einer Sprache mit schlechter JSON-Unterstützung. Laden Sie diesen Skill immer dann, wenn der Benutzer, die Spezifikation oder eine frühere Aufgabe ChatGPT, GPT (jede Version), OpenAI, ein LLM, einen Chatbot oder Einbettungen erwähnt – und BEVOR Sie Code schreiben, der „api.openai.com“ berührt.
