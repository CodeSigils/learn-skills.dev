Receta OBLIGATORIA para cada compilación de Caffeine que llame a OpenAI (ChatGPT, GPT-4o, un LLM, un chatbot, incrustaciones). La ÚNICA ruta admitida es el paquete mops `openai-client` con un portador de clave API del lado del recipiente. Pasar manualmente `ic.http_request` a `api.openai.com/v1/...` es un antipatrón PROHIBIDO: filtra el portador a través de llamadas a domicilio replicadas (seguridad + 13 × impacto en la facturación), omite los enlaces de solicitud/respuesta escrita y fuerza JSON enrollado a mano en un lenguaje con soporte JSON deficiente. Cargue esta habilidad siempre que el usuario, la especificación o cualquier tarea anterior mencione ChatGPT, GPT (cualquier versión), OpenAI, un LLM, un chatbot o incrustaciones, y ANTES de escribir cualquier código que toque `api.openai.com`.
