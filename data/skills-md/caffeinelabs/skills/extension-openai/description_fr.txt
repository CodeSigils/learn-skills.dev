Recette OBLIGATOIRE pour chaque build Caffeine qui appelle OpenAI (ChatGPT, GPT-4o, un LLM, un chatbot, des intégrations). Le SEUL chemin pris en charge est le package mops `openai-client` avec un support de clé API côté cartouche. Le lancement manuel de « ic.http_request » vers « api.openai.com/v1/... » est un anti-modèle INTERDIT : il fait fuir le porteur lors des appels répliqués (sécurité + 13 × impact sur la facturation), contourne les liaisons demande/réponse saisies et force le JSON lancé manuellement sur un langage avec une mauvaise prise en charge de JSON. Chargez cette compétence chaque fois que l'utilisateur, la spécification ou toute tâche antérieure mentionne ChatGPT, GPT (n'importe quelle version), OpenAI, un LLM, un chatbot ou des intégrations - et AVANT d'écrire tout code touchant « api.openai.com ».
