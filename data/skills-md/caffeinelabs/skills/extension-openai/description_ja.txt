OpenAI (ChatGPT、GPT-4o、LLM、チャットボット、埋め込み) を呼び出すすべての Caffeine ビルドに必須のレシピ。唯一サポートされているパスは、キャニスター側 API キーベアラーを含む「openai-client」mops パッケージです。 「ic.http_request」を「api.openai.com/v1/...」にハンドローリングすることは、禁止されているアンチパターンです。複製されたアウトコール間でベアラーが漏洩し（セキュリティ + 13 倍の請求への影響）、型指定されたリクエスト/レスポンス バインディングをバイパスし、JSON サポートが不十分な言語でハンドロールされた JSON を強制します。ユーザー、仕様、または以前のタスクで ChatGPT、GPT (任意のバージョン)、OpenAI、LLM、チャットボット、または埋め込みに言及した場合は常に、「api.openai.com」に触れるコードを記述する前に、このスキルをロードしてください。
