وصفة إلزامية لكل إصدار Caffeine يستدعي OpenAI (ChatGPT، وGPT-4o، وLLM، وchatbot، والتضمينات). المسار الوحيد المدعوم هو حزمة المماسح `openai-client' مع حامل مفتاح واجهة برمجة التطبيقات على جانب العلبة. يعد التمرير اليدوي ic.http_request إلى `api.openai.com/v1/...` نمطًا مضادًا محظورًا - فهو يسرب حامله عبر الاستدعاءات المكررة (الأمان + 13 × تأثير الفوترة)، ويتجاوز روابط الطلب/الاستجابة المكتوبة، ويفرض ملف JSON يدويًا على لغة ذات دعم ضعيف لـ JSON. قم بتحميل هذه المهارة عندما يذكر المستخدم أو المواصفات أو أي مهمة سابقة ChatGPT أو GPT (أي إصدار) أو OpenAI أو LLM أو chatbot أو عمليات التضمين - وقبل كتابة أي رمز يمس "api.openai.com".
