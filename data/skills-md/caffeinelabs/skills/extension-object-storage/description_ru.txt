Общее хранилище файлов/объектов, например изображений, видео, файлов, документов и других объемных данных. Идеально подходит для галерей изображений, видеогалерей и других средств управления файлами или объектами. Поддерживает большие файлы, превышающие лимит IC, с доступом к URL-адресу HTTP, кэшированному в браузере.
