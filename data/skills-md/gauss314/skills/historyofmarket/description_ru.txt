История рынка (historyofmarket.com) — общедоступный API с 88 наборами данных по историческим индексам США начиная с 1871 года. S&P 500 (цена, CAPE, EPS, просадки, изменения, составляющие), Nasdaq Composite/Nasdaq 100 (цена, волатильность, VXN, изменения), Dow Jones, SOX/SMH, отраслевые ETF (XLK, XLF), Великолепный 7-летний макрос. Ключ API Sin, CORS libre, CC BY 4.0.
