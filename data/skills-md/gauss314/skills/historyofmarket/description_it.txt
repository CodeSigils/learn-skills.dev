History of Market (historyofmarket.com) — API pubblica con 88 set di dati storici degli indici statunitensi dal 1871. S&P 500 (prezzo, CAPE, EPS, prelievi, variazioni, componenti), Nasdaq Composite/Nasdaq 100 (prezzo, volatilità, VXN, variazioni), Dow Jones, SOX/SMH, ETF settoriali (XLK, XLF), Magnificent 7 e macro. Chiave API Sin, CORS libero, CC BY 4.0.
