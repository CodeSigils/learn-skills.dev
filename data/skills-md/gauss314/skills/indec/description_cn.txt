通过 API 官方 Tiempo del Estado 系列 (apis.datos.gob.ar/series) 获取阿根廷宏观和社会数据。 ~4250 系列 del INDEC + BCRA + Min Economia + Sec Trabajo。 Sin 身份验证，Sin API 密钥。 IPC nacional、EMAE、IPI、ISAC、EPH（desempleo）、pobreza、comercio external、salarios（RIPTE、SMVM）、tipo de cambio、reservas、REM Expectativas。内置转换（% YoY、% YTD、变化）和时间聚合（每日→每月→每年）服务器端。 API 是稳定的，并且有重要的存储库文档。
