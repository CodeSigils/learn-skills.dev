透過 API 官方 Tiempo del Estado 系列 (apis.datos.gob.ar/series) 取得阿根廷宏觀和社會數據。 ~4250 系列 del INDEC + BCRA + Min Economia + Sec Trabajo。 Sin 身份验证，Sin API 密钥。 IPC nacional、EMAE、IPI、ISAC、EPH（desempleo）、pobreza、comercio external、salarios（RIPTE、SMVM）、tipo de cambio、reservas、REM Expectativas。內建轉換（% YoY、% YTD、變更）和時間聚合（每日→每月→每年）伺服器端。 API 是穩定的，並且有重要的儲存庫文件。
