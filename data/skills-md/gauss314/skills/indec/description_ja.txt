Tiempo del Estado の API 公式シリーズ (apis.datos.gob.ar/series) を介して、アルゼンチンのマクロと社会のデータを確認できます。 ~4250 シリーズ デル INDEC + BCRA + Min Economia + Sec Trabajo。 Sin 認証、Sin API キー。 IPC nacional、EMAE、IPI、ISAC、EPH (desempleo)、pobreza、comercio external、salarios (RIPTE、SMVM)、tipo de cambio、reservas、REM Expectativas。組み込みの変換 (前年比 %、前年同期比 %、変化) および時間的集計 (日次→月次→年次) サーバー側。 API は主要なドキュメントおよびリポジトリに安定しています。
