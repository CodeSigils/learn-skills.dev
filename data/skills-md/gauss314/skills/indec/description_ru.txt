Макросы и социальные данные Аргентины через официальный API Series de Tiempo del Estado (apis.datos.gob.ar/series). ~4250 серий INDEC + BCRA + Min Economia + Sec Trabajo. Грех аутентификации, грех API-ключа. IPC nacional, EMAE, IPI, ISAC, EPH (десемплео), побреза, внешняя коммерческая деятельность, зарплаты (RIPTE, SMVM), типо де камбио, резервы, REM ожидаемые. Встроенные преобразования (% г/г, % с начала года, изменение) и временное агрегирование (ежедневно → ежемесячно → ежегодно) на стороне сервера. API более стабильный и лучшая документация репозитория.
