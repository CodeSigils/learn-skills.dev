Makro- und Sozialdaten aus Argentinien über die offizielle API der Landeszeitschrift (apis.datos.gob.ar/series). ~4250 Serie von INDEC + BCRA + Min Economia + Sec Trabajo. Ohne Authentifizierung, ohne API-Schlüssel. IPC National, EMAE, IPI, ISAC, EPH (Desempleo), Pobreza, Comercio Exterior, Salarios (RIPTE, SMVM), Tipo de Cambio, Reservas, REM Expectativas. Integrierte Transformationen (% YoY, % YTD, Änderung) und zeitliche Agregation (täglich→monatlich→jährlich) serverseitig. Die API ist stabil und die beste Repo-Dokumentation.
