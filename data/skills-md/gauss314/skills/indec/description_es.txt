Datos macro y sociales de Argentina vía la API oficial Serie de Tiempo del Estado (apis.datos.gob.ar/series). ~4250 serie del INDEC + BCRA + Min Economía + Sec Trabajo. Sin autenticación, sin clave API. IPC nacional, EMAE, IPI, ISAC, EPH (desempleo), pobreza, comercio exterior, salarios (RIPTE, SMVM), tipo de cambio, reservas, REM expectativas. Transformaciones integradas (% YoY, % YTD, cambio) y agregación temporal (diaria→mensual→anual) del lado del servidor. La API mas estable y mejor documentada del repositorio.
