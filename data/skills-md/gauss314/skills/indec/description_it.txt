Datos macro y sociales de Argentina tramite la API oficial Series de Tiempo del Estado (apis.datos.gob.ar/series). ~4250 serie del INDEC + BCRA + Min Economia + Sec Trabajo. Senza autenticazione, senza chiave API. IPC nacional, EMAE, IPI, ISAC, EPH (desempleo), pobreza, comercio external, salarios (RIPTE, SMVM), tipo de cambio, reservas, REM waitativas. Trasformazioni integrate (% YoY, % YTD, variazione) e aggregazione temporale (giornaliera→mensile→annuale) lato server. L'API è stabile e meglio documentata nel repository.
