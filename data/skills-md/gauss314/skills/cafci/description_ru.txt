Аргентинские данные о фондах инверсии через CAFCI (Camara Argentina de Fondos Comunes de Inversion). Комбинированный каталог JSON (1152 фонда, 4615 классов, сборы, идентификаторы, метаданные), дневник снимков XLSX (VCP, имущество, рыночная доля, вариации), отдельные уценки (выплаты TNA за период) и состав карты (топ-активы). Ключ API греха.
