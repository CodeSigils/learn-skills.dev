통합 호스트 MCP 'topview-mcp'를 통한 TikTok Shop 공공 정보
(점진적 공개: use_tiktok_data → get_tool_schema → call_tool;
지연된 td_* 도구).
사용 시기: TikTok Shop 시장 동향, 제품 선택, 바이러스 자료
분석, 스크립트, 콘텐츠 캘린더, 제휴/제작자 운영, 광고/라이브 운영.
해당되지 않음: Amazon, Shopee, YouTube KOL 풀 또는 미디어 생성
(topview-amazon-ops, topview-shopee-ops, topview-youtube-kol-ops,
또는 topview-생성).
