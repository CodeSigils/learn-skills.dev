استخدم هذه المهارة عندما يريد المستخدم مراجعة تصميم البرنامج، أو نقد البنية، أو مراجعة نموذج المجال، أو مراجعة الحدود، أو نقد ADR، أو مراجعة التسمية، أو تحليل تأثير التبعية، أو مراجعة مرونة التغيير، أو مراجعة قابلية التوسع أو إدارة الأداء، أو مراجعة الأمان/الترخيص/قابلية التدقيق، أو مراجعة خطة تم إنشاؤها بواسطة الذكاء الاصطناعي أو تغيير التعليمات البرمجية من منظور التصميم. استخدمه أيضًا عندما يصف المستخدم أعراض التصميم دون تسمية مراجعة التصميم مباشرةً، مثل حدود الخدمة غير الواضحة، أو المسؤوليات المتضاربة، أو تغييرات المخطط المحفوفة بالمخاطر، أو الاقتران الهش، أو عزل المستأجر الضعيف، أو الشروط الزائدة، أو عدم اليقين بشأن المجاميع والملكية، أو خطط الحلول البديلة الثقيلة، أو القلق من أن التغيير مخصص للغاية بحيث لا يتحمل التعديل المستقبلي. لا تستخدمه للتنفيذ المباشر، أو المساعدة في بناء الجملة، أو البرامج التعليمية لإطار العمل، أو إصلاحات الأخطاء المعزولة.
