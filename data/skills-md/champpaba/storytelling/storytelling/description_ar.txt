قم بتخطيط العروض التقديمية باستخدام إطار عمل Storytelling Canvas - بدءًا من المحتوى الأولي وحتى مخطط كامل شريحة تلو الأخرى مع نصوص المتحدث وملاحظات الأدلة المرئية. استخدم هذه المهارة عندما يريد المستخدم التخطيط لعرض تقديمي، أو إنشاء مخطط تفصيلي لمجموعة الشرائح، أو إنشاء عرض تقديمي، أو تصميم محادثة، أو كتابة نصوص العرض التقديمي، أو إعداد المحتوى قبل إنشاء الشرائح. يتم تشغيله أيضًا على: "/سرد القصص"، و"العرض التقديمي"، و"خطة الشرائح"، و"شرائح الخطة"، و"مخطط العرض التقديمي"، و"خطة العرض التقديمي"، و"شريحة العرض التقديمي"، و"عرض تقديمي". استخدم هذا حتى عندما يقول المستخدم "أحتاج إلى تقديم X" أو يلصق المحتوى ويقول "تحويل هذا إلى شرائح". تنشئ هذه المهارة خطة سرد القصص - ويتم إنشاء الشرائح الفعلية عبر /glide بعد ذلك.
