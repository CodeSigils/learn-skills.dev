Просматривайте изменения кода в двух режимах: проверка локальной ветки (сравнение текущей ветки с базовой веткой) или проверка PR (проверка открытого запроса на включение на GitHub). По умолчанию выполняет индивидуальный обзор, охватывающий все основные области. С помощью `--team` создается специализированная группа из 8 агентов-рецензентов, занимающихся качеством кода, безопасностью, производительностью, передовыми практиками, тестированием и документацией. В режиме PR создает список исключений на основе существующих обзоров, при необходимости создает 9-го агента по контролю за соблюдением требований, если упоминается билет Jira, и публикует результаты как ожидающие комментарии к обзору (никогда не отправляет обзор — разработчик отправляет его вручную). Используйте `--headless` для полностью автономного выполнения, когда агент-претендент проверяет результаты, а не запрашивает разработчика.
