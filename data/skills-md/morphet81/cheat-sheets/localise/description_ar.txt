قم بإنشاء صفحة مساعدة لترجمة HTML لـ Lokalise. يُستخدم عندما يقدم المستخدم نصًا باللغة الإنجليزية (مفرد/جمع) ويريد ترجمات عبر جميع اللغات المدعومة البالغ عددها 23 لغة، ويتم عرضها كصفحة HTML تفاعلية مع أزرار نسخ. يتم تشغيل عبارات مثل "translate for Lokalise" أو "إنشاء ترجمات" أو "جدول الترجمة" أو عندما يقدم المستخدم سلاسل باللغة الإنجليزية ويذكر اللغات/i18n/localization.
