Implémentation de tickets de bout en bout avec une équipe multi-agents utilisant TDD. Récupère les détails des tickets JIRA et les conceptions Figma, génère un bon de commande pour rédiger les exigences, obtient l'approbation du développeur, puis propose un plan de test pour examen. Une fois les tests approuvés, implémente d'abord les tests (rouge), puis le code de production pour les réussir (vert).
