Комплексная реализация билетов с помощью мультиагентной команды с использованием TDD. Извлекает детали заявки JIRA и проекты Figma, создает заказ на заказ для написания требований, получает одобрение разработчика, а затем предлагает план тестирования на рассмотрение. После утверждения тестов сначала реализуются тесты (красный), а затем рабочий код для их прохождения (зеленый).
