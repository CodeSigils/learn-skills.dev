Pushen Sie den aktuellen Zweig und erstellen Sie eine Pull-Anfrage auf GitHub. Wenn sich im Filialnamen eine JIRA-ID befindet, werden Titel und Beschreibung aus dem Ticket abgeleitet; Ansonsten drängt es immer noch und bietet PR-Titeloptionen an. Standardmäßig Entwurf, verwenden Sie --no-draft für eine fertige PR.
