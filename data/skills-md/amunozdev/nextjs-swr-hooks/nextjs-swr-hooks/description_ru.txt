Обеспечивает соблюдение соглашений о разработке перехватчиков для проектов Next.js с использованием SWR (устаревших при повторной проверке): структура файлов, шаблоны выборки, фабрики ключей, резервный вариант SSR, типизация и предотвращение анти-шаблонов. Используйте при создании, изменении или просмотре пользовательских перехватчиков React с SWR в проекте Next.js или когда пользователь упоминает «swr», «useSWR», «stale while revalidate», «swrook», «swrmutation», «useSWRMutation», «swr Infinite», «swr Middleware». НЕ используйте для проектов TanStack Query — вместо этого используйте nextjs-tanstack-hooks. НЕ используйте для проектов, отличных от Next.js — вместо этого используйте реакции-swr-hook. НЕ используйте для управления состоянием клиента (Zustand, Redux, Recoil, Jotai).
