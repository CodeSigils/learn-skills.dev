SWR(stale-while-revalidate)을 사용하여 Next.js 프로젝트에 후크 개발 규칙을 적용합니다: 파일 구조, 페처 패턴, 키 팩토리, SSR 대체, 입력 및 안티 패턴 방지. Next.js 프로젝트에서 SWR을 사용하여 사용자 정의 React 후크를 생성, 수정 또는 검토할 때 또는 사용자가 "swr", "useSWR", "재검증하는 동안 오래됨", "swr 후크", "swr 변이", "useSWRMutation", "swr 무한", "swr 미들웨어"를 언급할 때 사용합니다.
