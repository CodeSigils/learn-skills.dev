Guide pratique pour réduire la consommation de jetons et réduire les coûts de l'IA pour les utilisateurs de Claude Code et les développeurs appelant directement l'API Anthropic. Couvre l'organisation des fichiers, la gestion du contexte, la sélection de modèles stratégiques, la mise en cache des invites, l'API Batch, le réglage des efforts et l'architecture des invites. Soutenu par des données d’expérience réelles. À utiliser lorsque l'utilisateur mentionne « optimiser les jetons », « réduire les coûts », « Claude est lent », « trop de jetons », « budget des jetons », « fenêtre contextuelle pleine », « organiser la base de code pour l'IA », « réduire la consommation des jetons », « mise en cache des invites », « cache_control », « API par lots », « cache cassé », « coûts de l'API » ou « budget de réflexion ». Ne pas utiliser pour des questions générales de codage, de débogage ou d'optimisation des performances sans rapport avec l'utilisation du jeton IA.
