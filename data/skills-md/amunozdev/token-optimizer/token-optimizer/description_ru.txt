Практическое руководство по сокращению потребления токенов и снижению затрат на искусственный интеллект как для пользователей Claude Code, так и для разработчиков, напрямую вызывающих Anthropic API. Охватывает организацию файлов, управление контекстом, выбор стратегической модели, кэширование подсказок, пакетный API, настройку усилий и архитектуру подсказок. Подтверждено реальными экспериментальными данными. Используйте, когда пользователь упоминает «оптимизировать токены», «сократить затраты», «Клод работает медленно», «слишком много токенов», «бюджет токенов», «контекстное окно заполнено», «организовать кодовую базу для ИИ», «уменьшить потребление токенов», «быстрое кэширование», «cache_control», «пакетный API», «кэш сломан», «затраты на API» или «обдумывающий бюджет». НЕ используйте для общих вопросов по кодированию, отладке или оптимизации производительности, не связанных с использованием токенов AI.
