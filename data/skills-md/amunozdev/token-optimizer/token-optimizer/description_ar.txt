دليل عملي لتقليل استهلاك الرموز المميزة وخفض تكاليف الذكاء الاصطناعي لكل من مستخدمي ومطوري Claude Code الذين يتصلون بواجهة برمجة تطبيقات Anthropic مباشرة. يغطي تنظيم الملفات، وإدارة السياق، واختيار النموذج الاستراتيجي، والتخزين المؤقت السريع، وواجهة برمجة التطبيقات Batch، وضبط الجهد، والهندسة السريعة. مدعومة ببيانات التجربة الحقيقية. يُستخدم عندما يذكر المستخدم "تحسين الرموز المميزة"، أو "تقليل التكاليف"، أو "Claude بطيء"، أو "عدد كبير جدًا من الرموز المميزة"، أو "ميزانية الرمز المميز"، أو "نافذة السياق ممتلئة"، أو "تنظيم قاعدة التعليمات البرمجية للذكاء الاصطناعي"، أو "تقليل استهلاك الرمز المميز"، أو "التخزين المؤقت الفوري"، أو "cache_control"، أو "واجهة برمجة التطبيقات الدفعية"، أو "ذاكرة التخزين المؤقت المعطلة"، أو "تكاليف واجهة برمجة التطبيقات"، أو "ميزانية التفكير". لا تستخدمه في أسئلة الترميز العامة أو تصحيح الأخطاء أو تحسين الأداء التي لا علاقة لها باستخدام رمز الذكاء الاصطناعي.
