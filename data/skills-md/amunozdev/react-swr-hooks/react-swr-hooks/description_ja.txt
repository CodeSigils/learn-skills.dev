SWR (stale-while-revalidate) を使用した React プロジェクトのフック開発規則 (ファイル構造、フェッチャー パターン、キー ファクトリ、型指定、アンチパターン防止) を強制します。 React Native、Expo、Vite + React、CRA、Remix (クライアント側)、および React 18/19 アプリで動作します。 SWR を使用してカスタム React フックを作成、変更、またはレビューする場合、またはユーザーが「swr」、「useSWR」、「再検証中に失効する」、「swr フック」、「swr 変異」、「useSWRMutation」、「swr 無限」、「swr ミドルウェア」に言及する場合に使用します。 TanStack Query プロジェクトには使用しないでください。代わりに、react-tanstack-hooks を使用してください。一般的な React コンポーネント開発やフック以外のユーティリティには使用しないでください。クライアント状態管理 (Zustand、Redux、Recoil、Jotai) には使用しないでください。
