使用 SWR (stale-while-revalidate) 强制执行 React 项目的钩子开发约定：文件结构、获取器模式、关键工厂、类型和反模式预防。适用于 React Native、Expo、Vite + React、CRA、Remix（客户端）和任何 React 18/19 应用程序。使用 SWR 创建、修改或审查自定义 React hook 时，或者当用户提到“swr”、“useSWR”、“重新验证时过时”、“swr hook”、“swrmutation”、“useSWRMutation”、“swrInfinity”、“swrmiddleware”时使用。不要用于 TanStack Query 项目 - 请改用react-tanstack-hooks。请勿用于一般 React 组件开发或非钩子实用程序。请勿用于客户端状态管理（Zustand、Redux、Recoil、Jotai）。
