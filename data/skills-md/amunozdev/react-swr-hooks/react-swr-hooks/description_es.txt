Hace cumplir las convenciones de desarrollo de ganchos para proyectos de React que utilizan SWR (obsoleto mientras se revalida): estructura de archivos, patrones de recuperación, fábricas de claves, escritura y prevención antipatrones. Funciona con React Native, Expo, Vite + React, CRA, Remix (del lado del cliente) y cualquier aplicación React 18/19. Úselo al crear, modificar o revisar ganchos de React personalizados con SWR, o cuando el usuario mencione "swr", "useSWR", "stale while revalidate", "swr hook", "swrmutation", "useSWRMutation", "swr infinito", "swr middleware". NO lo use para proyectos de TanStack Query; en su lugar, use reaccionar-tanstack-hooks. NO lo use para el desarrollo general de componentes de React o utilidades sin enlace. NO lo use para la gestión del estado del cliente (Zustand, Redux, Recoil, Jotai).
