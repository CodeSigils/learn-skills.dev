Erzwingt Hook-Entwicklungskonventionen für React-Projekte mithilfe von SWR (stale-while-revalidate): Dateistruktur, Abrufmuster, Schlüsselfabriken, Typisierung und Anti-Pattern-Prävention. Funktioniert mit React Native, Expo, Vite + React, CRA, Remix (clientseitig) und jeder React 18/19-App. Wird verwendet, wenn benutzerdefinierte React-Hooks mit SWR erstellt, geändert oder überprüft werden oder wenn der Benutzer „swr“, „useSWR“, „stale while revalidate“, „swr Hook“, „swr Mutation“, „useSWRMutation“, „swr Infinity“, „swr Middleware“ erwähnt. NICHT für TanStack Query-Projekte verwenden – stattdessen React-Tanstack-Hooks verwenden. NICHT für die allgemeine Entwicklung von React-Komponenten oder Nicht-Hook-Dienstprogramme verwenden. NICHT für die Client-Statusverwaltung verwenden (Zustand, Redux, Recoil, Jotai).
