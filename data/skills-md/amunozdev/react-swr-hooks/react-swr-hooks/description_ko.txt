SWR(stale-while-revalidate)을 사용하여 React 프로젝트에 대한 후크 개발 규칙을 적용합니다: 파일 구조, 페처 패턴, 키 팩토리, 입력 및 안티 패턴 방지. React Native, Expo, Vite + React, CRA, Remix(클라이언트 측) 및 모든 React 18/19 앱에서 작동합니다. SWR을 사용하여 사용자 정의 React 후크를 생성, 수정 또는 검토할 때 또는 사용자가 "swr", "useSWR", "재검증 중 오래됨", "swr 후크", "swr 변이", "useSWRMutation", "swr 무한", "swr 미들웨어"를 언급할 때 사용합니다. TanStack Query 프로젝트에는 사용하지 마세요. 대신 React-tanstack-hooks를 사용하세요. 일반적인 React 구성 요소 개발이나 후크가 아닌 유틸리티에는 사용하지 마세요. 클라이언트 상태 관리(Zustand, Redux, Recoil, Jotai)에는 사용하지 마십시오.
