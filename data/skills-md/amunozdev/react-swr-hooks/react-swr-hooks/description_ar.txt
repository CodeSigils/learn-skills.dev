يفرض اصطلاحات تطوير الربط لمشاريع React باستخدام SWR (التي لا معنى لها أثناء إعادة التحقق): بنية الملف، وأنماط الجلب، والمصانع الرئيسية، والكتابة، ومنع الأنماط المضادة. يعمل مع React Native وExpo وVite + React وCRA وRemix (من جانب العميل) وأي تطبيق React 18/19. يُستخدم عند إنشاء خطافات React مخصصة أو تعديلها أو مراجعتها باستخدام SWR، أو عندما يذكر المستخدم "swr" و"useSWR" و"stale while revalidate" و"swr Hook" و"swr Mutation" و"useSWRMutation" و"swr infinite" و"swr middleware". لا تستخدمه في مشاريع TanStack Query — استخدم خطافات تفاعل tanstack بدلاً من ذلك. لا تستخدمه لتطوير مكونات React العامة أو الأدوات المساعدة غير المرتبطة بالربط. لا تستخدم لإدارة حالة العميل (Zustand، Redux، Recoil، Jotai).
