Обеспечивает соблюдение соглашений о разработке перехватчиков для проектов React с использованием SWR (устаревших при повторной проверке): структура файлов, шаблоны выборки, фабрики ключей, типизация и предотвращение анти-шаблонов. Работает с React Native, Expo, Vite + React, CRA, Remix (на стороне клиента) и любым приложением React 18/19. Используйте при создании, изменении или просмотре пользовательских перехватчиков React с помощью SWR или когда пользователь упоминает «swr», «useSWR», «устаревший при повторной проверке», «перехват SWR», «мутацию SWR», «useSWRMutation», «SWR Infinity», «Промежуточное ПО SWR». НЕ используйте для проектов TanStack Query — вместо этого используйте реакции-tanstack-хуки. НЕ используйте для общей разработки компонентов React или утилит без перехватчиков. НЕ используйте для управления состоянием клиента (Zustand, Redux, Recoil, Jotai).
