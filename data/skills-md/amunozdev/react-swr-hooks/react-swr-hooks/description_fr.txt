Applique les conventions de développement de hooks pour les projets React utilisant SWR (stale-while-revalidate) : structure de fichiers, modèles de récupération, usines de clés, saisie et prévention anti-modèle. Fonctionne avec React Native, Expo, Vite + React, CRA, Remix (côté client) et toute application React 18/19. À utiliser lors de la création, de la modification ou de la révision de hooks React personnalisés avec SWR, ou lorsque l'utilisateur mentionne "swr", "useSWR", "stale while revalidate", "swr hook", "swr mutation", "useSWRMutation", "swr infinite", "swr middleware". Ne PAS utiliser pour les projets TanStack Query – utilisez plutôt les hooks de réaction-tanstack. Ne PAS utiliser pour le développement général de composants React ou pour des utilitaires sans hook. Ne PAS utiliser pour la gestion de l'état du client (Zustand, Redux, Recoil, Jotai).
