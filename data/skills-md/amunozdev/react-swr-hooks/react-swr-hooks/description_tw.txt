使用 SWR (stale-while-revalidate) 強制執行 React 專案的鉤子開發約定：檔案結構、擷取器模式、關鍵工廠、類型和反模式預防。適用於 React Native、Expo、Vite + React、CRA、Remix（客戶端）和任何 React 18/19 應用程式。使用 SWR 建立、修改或審查自訂 React hook 時，或當使用者提到「swr」、「useSWR」、「重新驗證時過時」、「swr hook」、「swrmutation」、「useSWRMutation」、「swrInfinity」、「swrmiddleware」時使用。不要用於 TanStack Query 專案 - 請改用react-tanstack-hooks。請勿用於一般 React 元件開發或非鉤子實用程式。請勿用於客戶端狀態管理（Zustand、Redux、Recoil、Jotai）。
