Applica le convenzioni di sviluppo degli hook per i progetti React utilizzando SWR (stale- while-revalidate): struttura dei file, pattern fetcher, factory chiave, digitazione e prevenzione anti-pattern. Funziona con React Native, Expo, Vite + React, CRA, Remix (lato client) e qualsiasi app React 18/19. Da utilizzare durante la creazione, la modifica o la revisione di hook React personalizzati con SWR o quando l'utente menziona "swr", "useSWR", "stale while revalidate", "swr hook", "swrmutation", "useSWRMutation", "swr infinite", "swr middleware". NON utilizzare per progetti TanStack Query: utilizzare invece react-tanstack-hooks. NON utilizzare per lo sviluppo generale di componenti React o per utilità non hook. NON utilizzare per la gestione dello stato del client (Zustand, Redux, Recoil, Jotai).
