Structure du wiki Feishu, modèles et règles de routage de l'équipe Portwind. Consolidez les recommandations d'outils dispersées, les pièges, les documents de conception, les rétrospectives, les guides d'intégration des nouveaux arrivants et les partages techniques sous un nœud parent fixe ; l'agent les achemine automatiquement et remplit le contenu selon les modèles. Utilisé lorsque l'utilisateur dit « archiver dans le wiki », « archiver dans la base de connaissances », « enregistrer un piège », « enregistrer un piège », « écrire une rétrospective », « écrire un post-mortem », « écrire un partage technique », « écrire un document de conception », « écrire une comparaison de sélection », « enregistrer un nouvel outil », « ajouter au radar d'outils », « document d'intégration des nouveaux arrivants » ou « archiver selon les directives de Portwind ». S'appuie sur les compétences lark‑cli + lark‑wiki / lark‑doc (pas de réinvention).
