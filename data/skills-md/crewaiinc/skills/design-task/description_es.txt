Diseño y configuración de tareas de CrewAI. Úselo al crear, configurar o depurar tareas de CrewAI: escribir descripciones y salida_esperada, configurar dependencias de tareas con contexto, configurar formatos de salida (output_pydantic, salida_json, archivo_salida), usar barreras de seguridad para la validación, habilitar entrada_humana, ejecución asincrónica, formato de rebajas o depurar problemas de ejecución de tareas.
