Архитектурные решения CrewAI и основы проекта. Используйте при запуске нового проекта CrewAI, выбирая между LLM.call(), Agent.kickoff(), Crew.kickoff() и Flow, формируя леса с помощью «crewai create flow», настраивая конфигурацию YAML (agents.yaml, Tasks.yaml), подключая @CrewBase Crew.py, записывая Flow main.py с помощью @start/@listen или используя интерполяцию {variable}.
