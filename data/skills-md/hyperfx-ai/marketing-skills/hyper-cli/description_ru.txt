Используйте Hyper CLI для запуска навыков Hyper-маркетинга с терминала. Используйте, когда пользователь хочет использовать Hyperai, проверять действующие схемы инструментов, переводить имена инструментов MCP из навыков в команды CLI, переключать подключенные учетные записи или запускать маркетинговые инструменты за пределами хоста собственного агента MCP.
