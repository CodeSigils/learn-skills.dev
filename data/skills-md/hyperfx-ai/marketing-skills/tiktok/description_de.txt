Veröffentlichen Sie organische TikTok-Inhalte (Videos, Fotos, Karussells) über das TikTok-kompatible interaktive Posting-Formular über das Hyper MCP. Verwenden Sie diese Option, wenn der Benutzer ein Video auf TikTok posten, Fotos auf TikTok teilen, auf TikTok hochladen oder einen Satz wie „Poste dies auf TikTok“ / „Teile auf TikTok“ / „Stelle dies auf mein TikTok hoch“ verwenden möchte. Verwenden Sie für bezahlte TikTok-Werbekampagnen stattdessen den Skill „tiktok-ads“.
