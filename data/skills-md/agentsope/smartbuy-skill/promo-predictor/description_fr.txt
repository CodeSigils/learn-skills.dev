**Mini Promotion Prophecy** — un outil conversationnel qui prédit le prochain prix de grande vente sur la base de courbes historiques réelles. Donnez-moi le produit + le prix actuel, et je tirerai les prix de transaction de la même période au cours des 2 à 3 dernières années pour 618 / Double11 / Fête nationale / 8 mars, puis je vous dirai « à peu près à quel point la prochaine grande vente pourrait être basse + points de risque + combien de semaines attendre ». **Prédit uniquement les produits avec plus de 2 ans de courbe historique** ; nouveaux éléments / pas de données historiques → solution de repli. **Ne « devinez jamais avec une onde cérébrale »** : la prévision doit être basée sur des données provenant d'au moins trois points historiques réels et doit être étiquetée « sans garantie » ; si vous ne pouvez pas l’obtenir, dites-le simplement. À utiliser lorsque l'utilisateur demande « Puis-je attendre la vente pour le faire baisser ? », « Quel sera le prix Double11 ? », « 618 vs Double11 lequel acheter ? », « Acheter maintenant ou attendre quelques semaines ? », « Mini-prophétie de promotion, calculez pour moi ». Mots déclencheurs : mini-prophétie de promotion, prévisions de promotion, prix Double11, prix 618, attente de promotion, quelques semaines plus tard, peut-elle être inférieure, modèle de promotion, cycle de catégorie.
