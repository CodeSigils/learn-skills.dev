**Order-Combining Mini Ledger** — un outil conversationnel qui vous aide à calculer « combien vous payez réellement après avoir empilé tous les coupons + comment fonctionner ». Fournissez le prix indiqué du produit ainsi que tous les coupons que vous pouvez utiliser (coupons de plateforme / subvention nationale / plus réduction complète / paquet rouge / code de réduction), et je calculerai le prix final que vous recevrez selon les « règles de commande cumulée » et vous guiderai étape par étape sur quoi cliquer sur la page de commande. **Ne fabriquez jamais de règles de coupon** ; si je ne sais pas, je vous dirai de vérifier la source officielle au lieu de deviner. **Par défaut, couverture de JD.com auto-exploité** (coupons de plateforme + subvention nationale + Plus + réduction totale) ; nous allons étendre le produit phare de Tmall / Pinduoduo / Suning en fonction des commentaires. À utiliser avec Price-Detective : déterminez d'abord s'il s'agit d'un bon prix (Price-Detective), puis calculez le paiement réel (coupon-stacker). À utiliser lorsque l'utilisateur dit "combinaison de commandes", "empiler les coupons", "combien en main", "paiement réel", "comment utiliser la subvention nationale", "plus la réduction complète", "combien court utiliser un coupon", "fullXminusY comment calculer". Mots déclencheurs : combinaison de commandes, coupons empilés, en main, paiement effectif, plus réduction complète, subvention nationale, coupon de réduction de 10 %, paquet rouge, remise instantanée, Cloud QuickPass, mini grand livre de combinaison de commandes.
