**Order‑Combining Ledger** — un outil conversationnel qui vous aide à calculer « combien vous payez réellement après avoir empilé tous les coupons + comment fonctionner ». Fournissez-moi le prix indiqué du produit + tous les coupons que vous pouvez utiliser (coupons de plateforme / subvention nationale / remise Plus / enveloppe rouge / code de réduction), et je calculerai le prix final que vous recevrez selon les « règles de commande cumulée » et vous guiderai à travers chaque clic sur la page de commande. **Ne fabriquez jamais de règles de coupon** ; si je ne sais pas quelque chose, je vous demanderai de vérifier la source officielle au lieu de deviner. **Couvre par défaut JD.com autogéré** (coupons de plateforme + subvention nationale + Plus + remise) ; Le drapeau officiel Tmall/Pinduoduo/Suning sera ajouté en fonction des commentaires. À utiliser avec **price‑detective** : déterminez d'abord s'il s'agit d'un bon prix (price‑detective), puis calculez le paiement réel (coupon‑stacker).  

À utiliser lorsque l'utilisateur dit « combiner les commandes », « empiler les coupons », « combien après la remise », « paiement réel », « comment utiliser la subvention nationale », « plus la remise », « combien de plus utiliser un coupon », « fullXminusY comment calculer », etc.  

Mots déclencheurs : combinaison de commandes, coupons de pile, prix final, paiement effectif, remise Plus, subvention nationale, coupon de réduction de 10 %, enveloppe rouge, remise instantanée, Cloud Quick Pay, grand livre de combinaison de commandes.
