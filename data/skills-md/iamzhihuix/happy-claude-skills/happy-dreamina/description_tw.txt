位元組跳動極萌（Dreamina）透過官方「dreamina」CLI產生影像和影片。每當使用者提到即夢、Dreamina、極萌，或要求專門透過位元組跳動的極萌服務產生影像或影片時，請使用此技能。涵蓋text2image、image2image、text2video、image2video，以及透過list_task進行非同步任務查詢和任務歷史瀏覽。每當使用者明確命名 即夢 或 dreamina 時，就會觸發此技能，而不是 happy-image-gen 或 happy-video-gen - 它使用基於瀏覽器的登入（「dreamina 登入」）而不是 API 金鑰，並且可以存取 Jimeng 專有模型。常見短語包括「用即夢畫張...」、「Jimeng generated a video of...」、「Dreamina 文生影片」、「用 dreamina CLI 做圖片」、「查下我即夢的歷史任務」。
