字节跳动极萌（Dreamina）通过官方“dreamina”CLI生成图像和视频。每当用户提到即梦、Dreamina、极萌，或者要求专门通过字节跳动的极萌服务生成图像或视频时，请使用此技能。涵盖text2image、image2image、text2video、image2video，以及通过list_task进行异步任务查询和任务历史浏览。每当用户明确命名 即梦 或 dreamina 时，就会触发此技能，而不是 happy-image-gen 或 happy-video-gen - 它使用基于浏览器的登录（“dreamina 登录”）而不是 API 密钥，并且可以访问 Jimeng 专有模型。常见短语包括“用即梦画张...”、“Jimeng generated a video of...”、“Dreamina 文生视频”、“用 dreamina CLI 做图”、“查下我即梦的历史任务”。
