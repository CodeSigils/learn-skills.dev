OpenAI Sora、Google Veo 2/3、Runway Gen-3/Gen-4、Pika 2.2、Luma Dream Machine (Ray 2)、FAL (Kling / Wan / Veo / Sora ラッパー)、Ark Seedance 1.5 Pro/Lite、Bailian Wanx (i2v)、MiniMax Hailuo-02、および Vidu Q3 をサポートするユニバーサル AI ビデオ生成。ユーザーがテキスト プロンプトまたは最初のフレームの画像からビデオを生成、作成、作成、または合成するように要求する場合は常に、このスキルを使用します。テキストからビデオへの変換と画像からビデオへの変換をサポートしており、それをサポートするプロバイダーのオプションの最後のフレーム制御も可能です。典型的なフレーズには、「... のビデオを生成する」、「... の 5 秒間のクリップを作成する」、「この画像をアニメーション化する」、「生成一段ビデオ」、「做个短片」、または Sora、Veo、Runway Gen、Kling、Wan、Seedance、Hailuo、Pika、Dream Machine、Vidu などのビデオ生成モデル ファミリへの言及が含まれます。ユーザーが特定のモデルの名前を指定しない場合でも、常にこのスキルを使用します。EXTEND.md のデフォルトまたは利用可能な API キーからプロバイダーを選択します。ユーザーが明示的に即梦 / Dreamina / Jimeng に言及した場合は、このスキルを使用しないでください。これらは代わりに happy-dreamina に移動します。
