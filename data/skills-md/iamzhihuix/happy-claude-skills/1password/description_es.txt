Utilice 1Password CLI (op) para administrar contraseñas y credenciales de API. Guarde, consulte y lea claves/tokens de API e inyecte variables de entorno en scripts. Utilice esta habilidad cuando el usuario mencione guardar contraseñas, guardar claves API, consultar contraseñas, 1contraseña, CLI operativa o administración de secretos.
