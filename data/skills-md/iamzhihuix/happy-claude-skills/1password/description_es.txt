Utilice 1Password CLI (op) para administrar contraseñas y credenciales de API. Guarde, busque y lea claves/tokens de API e inyecte variables de entorno en scripts. Utilice esta habilidad cuando los usuarios mencionen guardar contraseñas, guardar claves API, buscar contraseñas, 1contraseña, CLI operativa o administración de secretos.
