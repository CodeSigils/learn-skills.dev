Utilizza 1Password CLI (op) per gestire password e credenziali API. Salva, esegui query e leggi chiavi/token API e inserisci variabili di ambiente negli script. Utilizza questa abilità quando l'utente menziona il salvataggio delle password, il salvataggio delle chiavi API, l'interrogazione delle password, 1Password, op CLI o la gestione dei segreti.
