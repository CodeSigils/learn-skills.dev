Помогите пользователям организовать частные проекты в репозитории с открытым исходным кодом. Основные возможности: (1) Сканирование исходного кода и истории git на предмет утечек ключей/токенов; (2) Рекомендовать лицензию с открытым исходным кодом (MIT / Apache 2.0 / GPL и т. д.) на основе контекста проекта и создать ЛИЦЕНЗИЮ; (3) Заполните необходимые документы с открытым исходным кодом, такие как заявление об отказе от ответственности README, CONTRIBUTING.md, SECURITY.md, .gitignore и т. д.; (4) Проверьте идентификаторы пакетов, package.json и другие риски владения/торговой марки. Триггерные слова: «открытый исходный код», «открытый исходный код», «выбрать лицензию», «ЛИЦЕНЗИЯ», «подготовить открытый исходный код», «обнаружить ключи», «секретное сканирование», «загрузить GitHub».
