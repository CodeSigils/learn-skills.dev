ユーザーがプライベート プロジェクトをオープンソース化できるリポジトリに整理できるようにします。コア機能: (1) ソース コードと git 履歴をスキャンしてキー/トークンのリークがないか確認します。 (2) プロジェクトのコンテキストに基づいてオープンソース ライセンス (MIT、Apache 2.0、GPL など) を推奨し、LICENSE ファイルを生成します。 (3) README 免責事項、CONTRIBUTING.md、SECURITY.md、.gitignore などの重要なオープンソース ドキュメントを追加します。 (4) バンドル識別子、package.json、およびその他の所有権/商標のリスクを確認します。トリガーワード: 「オープンソース」、「オープンソース」、「ライセンスの選択」、「ライセンス」、「オープンソースの準備」、「キーの検出」、「秘密スキャン」、「github のアップロード」。
