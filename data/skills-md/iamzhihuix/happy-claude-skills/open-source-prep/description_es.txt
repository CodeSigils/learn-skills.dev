Ayude a los usuarios a transformar proyectos privados en repositorios de código abierto. Capacidades principales: (1) Escanear el código fuente y el historial de Git en busca de filtraciones de secretos/claves; (2) Recomendar una licencia de código abierto (MIT / Apache2.0 / GPL, etc.) según el contexto del proyecto y generar un archivo de LICENCIA; (3) Complete documentos esenciales de código abierto, como un descargo de responsabilidad README, CONTRIBUTING.md, SECURITY.md, .gitignore, etc.; (4) Verifique los identificadores de paquete, package.json y otros archivos para detectar riesgos de propiedad/marca comercial. Palabras de activación: "código abierto", "código abierto", "elegir licencia", "LICENCIA", "preparar código abierto", "detectar secreto", "escaneo secreto", "cargar github".
