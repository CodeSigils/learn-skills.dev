Helfen Sie Benutzern, private Projekte in Open-Source-Repositorys zu organisieren. Kernfunktionen: (1) Quellcode und Git-Verlauf auf Schlüssel-/Token-Lecks scannen; (2) Empfehlen Sie eine Open-Source-Lizenz (MIT / Apache 2.0 / GPL usw.) basierend auf dem Projektkontext und generieren Sie eine LIZENZdatei; (3) Fügen Sie fehlende wichtige Open-Source-Dokumente hinzu, z. B. einen README-Haftungsausschluss, CONTRIBUTING.md, SECURITY.md, .gitignore usw.; (4) Überprüfen Sie Bundle-IDs, package.json und ähnliche Dateien auf Eigentums-/Markenrisiken. Auslöserwörter: „Open Source“, „Open Source“, „Lizenz auswählen“, „LIZENZ“, „Auf Open Source vorbereiten“, „Schlüssel erkennen“, „Geheimer Scan“, „Auf GitHub hochladen“.
