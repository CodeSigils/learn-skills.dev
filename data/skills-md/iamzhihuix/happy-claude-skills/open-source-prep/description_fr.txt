Aidez les utilisateurs à organiser des projets privés dans des référentiels open source. Capacités de base : (1) Analyser le code source et l'historique git à la recherche de fuites de clés/jetons ; (2) Recommander une licence open source (MIT / Apache 2.0 / GPL, etc.) en fonction du contexte du projet et générer une LICENCE ; (3) Compléter les documents open source essentiels tels qu'une clause de non-responsabilité README, CONTRIBUTING.md, SECURITY.md, .gitignore, etc. ; (4) Vérifiez les identifiants du bundle, package.json et les autres risques de propriété/marque. Mots déclencheurs : "open source", "open source", "choisir la licence", "LICENSE", "préparer l'open source", "détecter les clés", "analyse secrète", "télécharger GitHub".
