Aiuta gli utenti a organizzare progetti privati ​​in repository open source. Funzionalità principali: (1) Scansione del codice sorgente e della cronologia git per rilevare perdite di chiavi/token; (2) Consigliare una licenza open source (MIT / Apache 2.0 / GPL, ecc.) in base al contesto del progetto e generare una LICENZA; (3) Completare i documenti open source essenziali come un disclaimer README, CONTRIBUTING.md, SECURITY.md, .gitignore, ecc.; (4) Controllare gli identificatori del pacchetto, package.json e altri rischi di proprietà/marchio. Parole chiave: “open source”, “open source”, “scegli licenza”, “LICENZA”, “prepara open source”, “rileva chiavi”, “scansione segreta”, “carica GitHub”.
