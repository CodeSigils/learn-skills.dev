사용자가 개인 프로젝트를 오픈 소스 저장소로 구성하도록 돕습니다. 핵심 기능: (1) 키/토큰 누출에 대한 소스 코드 및 Git 기록을 스캔합니다. (2) 프로젝트의 맥락에 따라 오픈소스 라이선스(MIT/Apache 2.0/GPL 등)를 추천하고 LICENSE를 생성합니다. (3) README 고지 사항, CONTRIBUTING.md, SECURITY.md, .gitignore 등과 같은 필수 오픈 소스 문서를 완성합니다. (4) 번들 식별자, package.json 및 기타 소유권/상표 위험을 확인합니다. 트리거 단어: "오픈 소스", "오픈 소스", "라이선스 선택", "LICENSE", "오픈 소스 준비", "키 감지", "비밀 스캔", "GitHub 업로드".
