Universelle KI-Sprach-/Text-zu-Sprache-Fähigkeit, die OpenAI TTS (gpt-4o-mini-tts, tts-1), ElevenLabs mehrsprachiges TTS mit Stimmenklonen, Bailian Qwen TTS (qwen-tts / qwen3-tts-vd mit benutzerdefinierten Stimmen im Sprachdesign, integrierte Langtext-Chunking) unterstützt, MiniMax Speech-02-hd, SiliconFlow CosyVoice / SenseVoice und PlayHT 2,0. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer Text vorlesen, Sprache synthetisieren, einen Kommentar generieren, einen Voice-Over erstellen, ein Skript synchronisieren oder einen beliebigen Text in Audio (mp3/wav/ogg/flac) umwandeln möchte. Typische Ausdrücke sind „dies vorlesen“, „Stimme erzeugen für ...“, „eine Erzählung von ... erstellen“, „tts this“, „把这段念出来“, „做个配音“, „合成语音“ oder Erwähnungen von Stimmen/TTS-Modellnamen wie Alloy, Ash, Cherry, Rachel, CosyVoice, PlayHT. Verwenden Sie diesen Skill immer, auch wenn der Benutzer keinen Anbieter angibt – wählen Sie einen aus den EXTEND.md-Standardeinstellungen oder verfügbaren Umgebungsschlüsseln aus.
