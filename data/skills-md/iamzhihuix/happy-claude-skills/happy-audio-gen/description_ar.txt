مهارة الذكاء الاصطناعي العالمية في الصوت / تحويل النص إلى كلام تدعم OpenAI TTS (gpt-4o-mini-tts, tts-1)، وElevenLabs متعدد اللغات TTS مع استنساخ الصوت، وBailian Qwen TTS (qwen-tts / qwen3-tts-vd مع أصوات مخصصة لتصميم الصوت، وتقطيع النص الطويل المدمج)، MiniMax الكلام-02-hd، SiliconFlow CosyVoice / SenseVoice، و بلاي اتش تي 2.0. استخدم هذه المهارة عندما يطلب المستخدم قراءة النص بصوت عالٍ، أو تركيب الكلام، أو إنشاء السرد، أو إنشاء تعليق صوتي، أو دبلجة نص، أو تحويل أي نص إلى صوت (mp3 / wav / ogg / flac). تتضمن العبارات النموذجية "اقرأ هذا بصوت عالٍ" أو "إنشاء صوت لـ..." أو "إنشاء سرد لـ..." أو "TTS this" أو "把这段念出来" أو "做个配音" أو "合成语音"، أو ذكر أسماء نماذج الأصوات / تحويل النص إلى كلام مثل Alloy وAsh وCherry وRachel وCosyVoice وPlayHT. استخدم هذه المهارة دائمًا حتى لو لم يحدد المستخدم موفرًا — اختر واحدًا من إعدادات EXTEND.md الافتراضية أو مفاتيح البيئة المتوفرة.
