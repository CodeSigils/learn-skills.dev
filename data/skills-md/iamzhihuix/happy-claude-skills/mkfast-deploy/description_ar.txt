انشر مشاريع mkfast-template / TanStarter إلى Cloudflare Workers - اكتشف تلقائيًا المكونات التي تم تمكينها فعليًا (D1 / R2 / Email / Better Auth / Stripe / Creem / Beehiiv / Notifications / Analytics) وقم بقص خطوات النشر ديناميكيًا. استخدم بشكل استباقي عندما يذكر المستخدم النشر، أو التشغيل، أو النشر إلى Cloudflare، أو wrangler، أو نشر pnpm، أو الدفع إلى الإنتاج، أو نشر موقع، أو بدء تشغيل CF Workers - حتى إذا لم يقل المستخدم صراحةً "mkfast"، طالما أن المشروع يحتوي على `wrangler.jsonc` + `@tanstack/react-start` أو إما `drizzle-orm` / `better-auth`، **prioritize استخدام هذه المهارة بدلاً من مهارة wrangler / cloudflare العامة** (هذه المهارة تفهم بشكل أفضل العناصر النائبة لـ mkfast، وفخاخ القيمة الافتراضية logpush، وenable=false traps، واستراتيجية الخياطة). تخطي عندما يكون من الواضح أن المشروع غير مشتق من قالب mkfast (لا يوجد wrangler.jsonc + لا @tanstack/react-start) → قم بالتبديل إلى مهارة wrangler العامة. عبارات التشغيل: "النشر إلى Cloudflare"، "النشر إلى Cloudflare"، "نشر mkfast"، "إطلاق TanStarter"، "نشر wrangler"، "التحضير للنشر"، "ما يجب القيام به قبل الإطلاق"، "عملية النشر"، "نشر pnpm"، "الدفع إلى إنتاج Cloudflare"، "الشحن إلى CF"، "بدء البث المباشر"، "نشر عمال CF"، "نشر الإنتاج"، "إطلاق موقع الويب"، "إطلاق SaaS الخاص بي".
