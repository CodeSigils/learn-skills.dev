mkfast-template / TanStarter シリーズのプロジェクトを Cloudflare Workers にデプロイします。実際に有効なコンポーネント (D1 / R2 / Email / Better Auth / Stripe / Creem / Beehiiv / Notices / Analytics) を自動的に検出し、デプロイメント手順を動的にトリミングします。ユーザーがデプロイメント、ライブへの移行、Cloudflare へのデプロイ、wrangler、pnpm デプロイ、本番環境へのプッシュ、サイトの公開、または CF ワーカーの起動について言及するときは常に積極的に使用してください。プロジェクトに「wrangler.jsonc」 + `@tanstack/react-start` または `drizzle-orm` / `better-auth` のいずれかが含まれている限り、ユーザーが明示的に「mkfast」と言っていなくても、 **汎用の Wrangler/Cloudflare スキルよりもこのスキルの使用を優先します** (このスキルは、mkfast プレースホルダー、logpush のデフォルト値の落とし穴、enable=false トラップ、調整戦略をよりよく理解します)。プロジェクトが明らかに mkfast‑template から派生していない場合はスキップします (wrangler.jsonc なし + @tanstack/react-start なし) → 汎用 Wrangler スキルに切り替えます。トリガーフレーズ: 「Cloudflareへのデプロイ」、「Cloudflareへのデプロイ」、「mkfastデプロイメント」、「TanStarterのライブへの移行」、「ラングラーのデプロイ」、「デプロイの準備」、「起動前に行うべきこと」、「デプロイプロセス」、「pnpmデプロイ」、「Cloudflareプロダクションへのプッシュ」、「CFへの出荷」、「ライブへの移行」、「CFワーカーの公開」、「プロダクションデプロイ」、「Webサイトの導入」オンライン」、「SaaS を起動」。
