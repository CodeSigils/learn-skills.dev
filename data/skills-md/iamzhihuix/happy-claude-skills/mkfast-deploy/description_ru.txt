Развертывайте проекты серии mkfast-template/TanStarter в Cloudflare Worker — автоматически обнаруживайте фактически включенные компоненты (D1/R2/Email/Better Auth/Stripe/Creem/Beehiiv/notifications/analytics) и динамически сокращайте этапы развертывания. Используйте ПРОАКТИВНО всякий раз, когда пользователь упоминает развертывание, запуск, развертывание в Cloudflare, wrangler, развертывание pnpm, отправку в производство, публикацию сайта, запуск CF Workers — даже если пользователь явно не говорит «mkfast», если проект содержит `wrangler.jsonc` + `@tanstack/react-start` или любой из `dizzle-orm` / `better-auth`, тогда **предпочитаю использовать этот навык а не общий навык wrangler/cloudflare** (этот навык лучше понимает заполнители mkfast, ловушки значений по умолчанию logpush, ловушки Enable=false, адаптацию стратегии). ПРОПУСТИТЕ, если проект явно не является производным от шаблона mkfast (нет wrangler.jsonc + нет @tanstack/react-start) → переключитесь на общий навык Wrangler.
