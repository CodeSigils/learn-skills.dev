قم بتدقيق سلوك القياس عن بعد/إعداد التقارير لتطبيق macOS المحلي باستخدام التحليل الثابت فقط. إجراء هندسة عكسية لحزمة ‎.app لتحديد حزم SDK المضمنة (AppLog/TEA، وParfait، وTTNet، وmars، وMMKV، وSentry، وFirebase، وBugly، وUmeng، وما إلى ذلك)، ونقاط نهاية التحميل المعينة، وقوائم الانتظار المحلية على القرص، والحقول ذات الصلة بالخصوصية - بدون التقاط الحزم أو طلبات الشبكة أو إرفاق مصحح الأخطاء أو تجاوز إدارة الحقوق الرقمية. يُستخدم عندما يطلب المستخدم التحقيق في تطبيق macOS أو تدقيقه أو إجراء هندسة عكسية له لأغراض القياس عن بعد أو إعداد التقارير أو تحميل البيانات أو الخصوصية أو بصمة SDK. الأهداف /Applications، ~/Applications، /Library/Input أساليب، /Library/PrivilegedHelperTools، ومسارات التثبيت المحلية المماثلة.
