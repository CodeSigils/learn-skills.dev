Generación de imágenes de IA universal compatible con OpenAI DALL·E/gpt-image, Google Gemini Image/Imagen, Replicate (Flux/SDXL/cualquier modelo), Stability AI, FAL, Ark (Seedream 4.5), Bailian (qwen-image/wanx) y SiliconFlow. Utilice esta habilidad siempre que el usuario solicite generar, crear, dibujar, ilustrar, renderizar o sintetizar imágenes a partir de indicaciones de texto o imágenes de referencia. Las frases típicas incluyen "dibujar un...", "generar una imagen de...", "画一张...", "给我来张图", "hacer un cartel de...", "crear una ilustración...", o cualquier mención de familias de modelos de generación de imágenes como DALL·E, gpt-image, Flux, SDXL, Seedream, Imagen, Gemini image, Kolors o Wanx. Utilice siempre esta habilidad incluso si el usuario no nombra un modelo específico: elija un proveedor según sus valores predeterminados de EXTEND.md o las claves API disponibles en el entorno. NO uses esta habilidad cuando el usuario mencione explícitamente 即梦 / Dreamina / Jimeng; en su lugar, van a happy-dreamina.
