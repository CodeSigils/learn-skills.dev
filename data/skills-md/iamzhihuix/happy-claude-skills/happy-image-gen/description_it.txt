Generazione di immagini AI universale che supporta OpenAI DALL·E / gpt-image, Google Gemini Image / Imagen, Replicate (Flux / SDXL / qualsiasi modello), Stability AI, FAL, Ark (Seedream 4.5), Bailian (qwen-image / wanx) e SiliconFlow. Utilizza questa abilità ogni volta che l'utente chiede di generare, creare, disegnare, illustrare, eseguire il rendering o sintetizzare immagini da istruzioni di testo o immagini di riferimento. Frasi tipiche includono "disegna un ...", "genera un'immagine di ...", "画一张 ...", "给我来张图", "crea un poster di ...", "crea un'illustrazione ..." o qualsiasi menzione di famiglie di modelli di generazione di immagini come DALL·E, gpt-image, Flux, SDXL, Seedream, Imagen, Gemini image, Kolors o Wanx. Utilizza sempre questa competenza anche se l'utente non nomina un modello specifico: scegli un provider in base alle impostazioni predefinite EXTEND.md o alle chiavi API disponibili nell'ambiente. NON utilizzare questa abilità quando l'utente menziona esplicitamente 即梦 / Dreamina / Jimeng: quelli vanno invece a happy-dreamina.
