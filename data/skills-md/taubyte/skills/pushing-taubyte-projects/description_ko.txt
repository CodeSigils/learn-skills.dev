`--defaults`가 설정된 경우 `--message`가 필요하다는 규칙과 리소스 종속 변경에 대한 push-config-before-code 순서를 사용하여 `tau push`(`tau push project [--config-only|--code-only]`, `tau push website <name>` 및 `tau push library <name>`)를 통해 Taubyte 프로젝트 변경 사항을 푸시합니다. 또한 'tau pull' "이미 최신 상태"인 non-zero-exit 문제에 대해서도 설명합니다. 원시 `git push` 대신 `tau`를 통해 GitHub에 로컬 변경 사항을 푸시할 때 또는 원격 클라우드 웹훅을 트리거할 때 사용합니다. / Dream은 편집 후 삽입합니다.
