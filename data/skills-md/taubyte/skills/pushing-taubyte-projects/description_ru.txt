Отправляет изменения проекта Taubyte через `tau push` — `tau push project [--config-only|--code-only]`, `tau push веб-сайт <имя>` и `tau push Library <name>` — с правилом, согласно которому `--message` требуется, когда `--defaults` установлен, и упорядочиванием push-config-before-code для изменений, зависящих от ресурса. Также объясняет причуду «уже актуального» «вытягивания тау» с ненулевым выходом. Используйте при отправке локальных изменений в GitHub через «tau» (вместо обычного «git push») или при запуске веб-перехватчиков удаленного облака / внедрения Dream после редактирования.
