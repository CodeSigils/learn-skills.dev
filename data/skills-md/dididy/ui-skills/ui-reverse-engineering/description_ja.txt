あらゆる Web サイトをリバース エンジニアリングして、本番環境に対応した React + Tailwind コードを生成します。 「このサイトを複製する」、「この UI をコピーする」、「このページを複製する」、「これをコードに変換する」、「これをリバース エンジニアリングする」、「X のように見せる」をトリガーします。 DOM 構造、計算された CSS、JS インタラクション、レスポンシブ ブレークポイント、アニメーションをライブ URL から抽出し、動作するコンポーネントを生成します。アニメーションを正確に抽出するには、トランジション リバース エンジニアリング サブスキルを使用します。
