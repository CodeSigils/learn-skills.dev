Преобразуйте любой веб-сайт в готовый к использованию код React + Tailwind. Триггеры: «клонировать этот сайт», «скопировать этот пользовательский интерфейс», «реплицировать эту страницу», «превратить это в код», «перепроектировать это», «сделать это похожим на X». Извлекает структуру DOM, вычисленный CSS, взаимодействия JS, адаптивные точки останова и анимацию из действующего URL-адреса, а затем генерирует рабочий компонент. Используйте поднавык реверс-инжиниринга переходов для точного извлечения анимации.
