Entwickeln Sie jede Website in produktionsbereiten React + Tailwind-Code um. Löst auf „diese Site klonen“, „diese Benutzeroberfläche kopieren“, „diese Seite replizieren“, „dies in Code umwandeln“, „dieses rückentwickeln“ und „es wie X aussehen lassen“ aus. Extrahiert die DOM-Struktur, berechnetes CSS, JS-Interaktionen, reaktionsfähige Haltepunkte und Animationen aus einer Live-URL und generiert dann eine funktionierende Komponente. Verwenden Sie die Unterfähigkeit „Transition-Reverse-Engineering“ für eine präzise Animationsextraktion.
