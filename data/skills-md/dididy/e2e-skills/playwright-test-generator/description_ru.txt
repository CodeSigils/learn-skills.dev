Используйте при создании новых тестов Playwright E2E с нуля. Триггеры по «создать тесты драматурга», «написать тесты e2e для X», «добавить репортаж о драматурге для X», «создать тест для страницы X», «создать тесты для страницы входа». Автономный режим начинается с анализа пробелов в охвате, когда цель не указана; Режим аргумента напрямую нацелен на конкретную страницу или функцию. Исследует живое приложение через Playwright CLI или агент-браузер, разрабатывает сценарии с одобрением пользователя в режиме планирования, автоматически определяет структуру проекта (POM или плоская спецификация), запускает аудит YAGNI и e2e-ревьюер после генерации и передает драматургу-отладчику после трех неудачных попыток исправления.
