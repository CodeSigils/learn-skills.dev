À utiliser lors de la génération de nouveaux tests Playwright E2E à partir de zéro. Déclencheurs sur « générer des tests de dramaturge », « écrire des tests e2e pour X », « ajouter une couverture de dramaturge pour X », « créer un test pour la page X », « générer des tests pour la page de connexion ». Le mode autonome démarre à partir de l'analyse des écarts de couverture lorsqu'aucune cible n'est spécifiée ; Le mode argument cible directement une page ou une fonctionnalité spécifique. Explorez l'application en direct via Playwright CLI ou le navigateur d'agent, conçoit des scénarios avec l'approbation de l'utilisateur via le mode Plan, détecte automatiquement la structure du projet (POM vs spécification plate), exécute l'audit YAGNI et e2e-reviewer après la génération, et passe le relais au dramaturge-débogueur après 3 tentatives de correction infructueuses.
