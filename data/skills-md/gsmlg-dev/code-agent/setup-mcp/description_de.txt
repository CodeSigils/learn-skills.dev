Wird beim Hinzufügen oder Konfigurieren eines MCP-Servers (Model Context Protocol) in einem Claude Code-Plugin verwendet. Wird ausgelöst bei „mcp hinzufügen“, „mcp einrichten“, „mcp-Server konfigurieren“, „mcp.json zum Plugin hinzufügen“ oder bei jeder Anforderung, einen externen MCP-Tool-Server mit einem Plugin in diesem Repository zu verbinden.
