将 ROS2 系统与 Web 技术（包括 REST API、WebSocket 桥接器和基于浏览器的机器人界面）集成的模式和最佳实践。在为机器人构建 Web 仪表板、将摄像头流传输到浏览器、将 ROS2 服务公开为 REST 端点或在 Web UI 和 ROS2 节点之间实现双向 WebSocket 通信时，请使用此技能。每当用户提及 rosbridge、rosbridge_suite、roslibjs、带有 ROS2 的 FastAPI、带有 rclpy 的 Flask、用于机器人遥测的 WebSocket、MJPEG 流、用于机器人的 WebRTC、包装 ROS2 服务的 REST API、基于 Web 的机器人控制、浏览器机器人界面、机器人仪表板、机器人的 CORS 配置或任何 Web 到 ROS2 桥接模式时触发。还可以触发机器人 Web 界面上的身份验证、限制传感器流的速率、从机器人摄像头到浏览器的视频流，或与 ROS2 执行器一起运行异步 Web 框架。涵盖 rosbridge_suite、FastAPI、Flask、WebSocket 和 WebRTC 方法。
