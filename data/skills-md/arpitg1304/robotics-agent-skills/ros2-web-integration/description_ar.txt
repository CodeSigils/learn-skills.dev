الأنماط وأفضل الممارسات لدمج أنظمة ROS2 مع تقنيات الويب بما في ذلك REST APIs وجسور WebSocket وواجهات الروبوت المستندة إلى المستعرض. استخدم هذه المهارة عند إنشاء لوحات معلومات الويب للروبوتات، أو تدفق خلاصات الكاميرا إلى المتصفحات، أو الكشف عن خدمات ROS2 كنقاط نهاية REST، أو تنفيذ اتصال WebSocket ثنائي الاتجاه بين واجهات مستخدم الويب وعقد ROS2. يتم التشغيل عندما يذكر المستخدم rosbridge، أو rosbridge_suite، أو roslibjs، أو FastAPI مع ROS2، أو Flask مع rclpy، أو WebSocket للقياس عن بعد للروبوت، أو تدفق MJPEG، أو WebRTC للروبوتات، أو خدمات REST API التي تغطي ROS2، أو التحكم في الروبوت على الويب، أو واجهة روبوت المتصفح، أو لوحة معلومات الروبوت، أو تكوين CORS للروبوتات، أو أي نمط جسر من الويب إلى ROS2. قم أيضًا بتشغيل المصادقة على واجهات الويب الروبوتية، أو تدفقات أجهزة الاستشعار التي تحدد المعدل، أو دفق الفيديو من كاميرات الروبوت إلى المتصفحات، أو تشغيل أطر عمل الويب غير المتزامنة جنبًا إلى جنب مع منفذ ROS2. يغطي أساليب rosbridge_suite وFastAPI وFlask وWebSocket وWebRTC.
