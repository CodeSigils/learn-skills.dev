Лучшие практики разработки ROS2 на базе Docker, включая многоэтапные файлы Dockerfile, docker-compose для многоконтейнерных роботизированных систем, обнаружение DDS в контейнерах, сквозное использование графического процессора для восприятия и шаблоны контейнеров «разработка против развертывания». Используйте этот навык при контейнеризации рабочих пространств ROS2, настройке docker-compose для стеков программного обеспечения роботов, отладке связи DDS между контейнерами, настройке NVIDIA Container Toolkit для рабочих нагрузок графического процессора, пересылке X11/Wayland для инструментов rviz2 и графического интерфейса или управлении передачей USB-устройств для камер и последовательных устройств. Запускается всякий раз, когда пользователь упоминает Docker с ROS2, docker-compose для роботов, Dockerfile для рабочих областей colcon, контейнерную сеть для DDS, контейнеры графического процессора для восприятия, devcontainer для ROS2, многоэтапные сборки для ROS2 или развертывание ROS2 в контейнерах. Также триггер для CI/CD со сборками ROS2 на базе Docker, конфигурацией CycloneDDS или FastDDS в контейнерах, общей памятью в Docker или пересылкой X11 для rviz2. Охватывает дистрибутивы Humble, Iron, Jazzy и Rolling в базовых образах Ubuntu 22.04 и 24.04.
