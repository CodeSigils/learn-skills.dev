基於 Docker 的 ROS2 開發的最佳實踐，包括多階段 Dockerfile、用於多容器機器人系統的 docker-compose、跨容器的 DDS 發現、用於感知的 GPU 直通以及 dev-vs-deploy 容器模式。在容器化 ROS2 工作區、為機器人軟件堆棧設置 docker-compose、調試容器之間的 DDS 通信、為 GPU 工作負載配置 NVIDIA Container Toolkit、為 rviz2 和 GUI 工具轉發 X11/Wayland，或管理相機和串行設備的 USB 設備直通時，請使用此技能。每當使用者提及 ROS2 的 Docker、機器人的 docker-compose、colcon 工作區的 Dockerfile、DDS 的容器網路、感知的 GPU 容器、ROS2 的 devcontainer、ROS2 的多階段建置或在容器中部署 ROS2 時觸發。也可以使用基於 Docker 的 ROS2 建置、容器中的 CycloneDDS 或 FastDDS 配置、Docker 中的共享記憶體或 rviz2 的 X11 轉送來觸發 CI/CD。涵蓋 Ubuntu 22.04 和 24.04 基本映像的 Humble、Iron、Jazzy 和 Rolling 發行版。
