基于 Docker 的 ROS2 开发的最佳实践，包括多阶段 Dockerfile、用于多容器机器人系统的 docker-compose、跨容器的 DDS 发现、用于感知的 GPU 直通以及 dev-vs-deploy 容器模式。在容器化 ROS2 工作区、为机器人软件堆栈设置 docker-compose、调试容器之间的 DDS 通信、为 GPU 工作负载配置 NVIDIA Container Toolkit、为 rviz2 和 GUI 工具转发 X11/Wayland，或管理相机和串行设备的 USB 设备直通时，请使用此技能。每当用户提及 ROS2 的 Docker、机器人的 docker-compose、colcon 工作区的 Dockerfile、DDS 的容器网络、感知的 GPU 容器、ROS2 的 devcontainer、ROS2 的多阶段构建或在容器中部署 ROS2 时触发。还可以使用基于 Docker 的 ROS2 构建、容器中的 CycloneDDS 或 FastDDS 配置、Docker 中的共享内存或 rviz2 的 X11 转发来触发 CI/CD。涵盖 Ubuntu 22.04 和 24.04 基本映像的 Humble、Iron、Jazzy 和 Rolling 发行版。
