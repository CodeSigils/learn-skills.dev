Mejores prácticas para el desarrollo de ROS2 basado en Docker, incluidos Dockerfiles de varias etapas, docker-compose para sistemas robóticos de contenedores múltiples, descubrimiento de DDS en contenedores, transferencia de GPU para percepción y patrones de contenedores de desarrollo versus implementación. Utilice esta habilidad al crear contenedores en espacios de trabajo ROS2, configurar Docker-Compose para pilas de software de robots, depurar la comunicación DDS entre contenedores, configurar NVIDIA Container Toolkit para cargas de trabajo de GPU, reenviar X11/Wayland para rviz2 y herramientas GUI, o administrar la transferencia de dispositivos USB para cámaras y dispositivos serie. Se activa cada vez que el usuario menciona Docker con ROS2, docker-compose para robots, Dockerfile para espacios de trabajo colcon, redes de contenedores para DDS, contenedores GPU para percepción, devcontainer para ROS2, compilaciones de varias etapas para ROS2 o implementación de ROS2 en contenedores. También activa CI/CD con compilaciones ROS2 basadas en Docker, configuración CycloneDDS o FastDDS en contenedores, memoria compartida en Docker o reenvío X11 para rviz2. Cubre las distribuciones Humble, Iron, Jazzy y Rolling en las imágenes base de Ubuntu 22.04 y 24.04.
