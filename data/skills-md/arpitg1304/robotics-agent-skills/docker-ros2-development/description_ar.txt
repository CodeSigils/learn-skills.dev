أفضل الممارسات لتطوير ROS2 المستند إلى Docker، بما في ذلك ملفات Dockerfiles متعددة المراحل، وتكوين عامل الإرساء للأنظمة الروبوتية متعددة الحاويات، واكتشاف DDS عبر الحاويات، وعبور GPU للإدراك، وأنماط حاوية التطوير مقابل النشر. استخدم هذه المهارة عند تخزين مساحات عمل ROS2 في حاويات، أو إعداد docker-compose لمجموعات برامج الروبوت، أو تصحيح أخطاء اتصال DDS بين الحاويات، أو تكوين NVIDIA Container Toolkit لأحمال عمل GPU، أو إعادة توجيه X11/Wayland لأدوات rviz2 وGUI، أو إدارة مرور جهاز USB للكاميرات والأجهزة التسلسلية. يتم التشغيل عندما يذكر المستخدم Docker مع ROS2، أو docker-compose للروبوتات، أو Dockerfile لمساحات عمل colcon، أو شبكات الحاويات لـ DDS، أو حاويات GPU للإدراك، أو devcontainer لـ ROS2، أو الإنشاءات متعددة المراحل لـ ROS2، أو نشر ROS2 في الحاويات. قم أيضًا بتشغيل CI/CD مع إنشاءات ROS2 المستندة إلى Docker، أو تكوين CycloneDDS أو FastDDS في الحاويات، أو الذاكرة المشتركة في Docker، أو إعادة توجيه X11 لـ rviz2. يغطي توزيعات Humble وIron وJazzy وRolling عبر الصور الأساسية لـ Ubuntu 22.04 و24.04.
