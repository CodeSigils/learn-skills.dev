Docker ベースの ROS2 開発のベスト プラクティスには、マルチステージ Dockerfile、マルチコンテナー ロボット システム用の docker-compose、コンテナー間の DDS 検出、認識のための GPU パススルー、開発対デプロイのコンテナー パターンなどがあります。このスキルは、ROS2 ワークスペースのコンテナ化、ロボット ソフトウェア スタック用の docker-compose のセットアップ、コンテナ間の DDS 通信のデバッグ、GPU ワークロード用の NVIDIA Container Toolkit の構成、rviz2 および GUI ツール用の X11/Wayland の転送、またはカメラとシリアル デバイスの USB デバイス パススルーの管理を行うときに使用します。ユーザーが ROS2 での Docker、ロボットの docker-compose、colcon ワークスペースの Dockerfile、DDS のコンテナ ネットワーキング、認識のための GPU コンテナ、ROS2 の devcontainer、ROS2 のマルチステージ ビルド、またはコンテナでの ROS2 のデプロイについて言及するたびにトリガーされます。また、Docker ベースの ROS2 ビルドを使用した CI/CD、コンテナー内の CycloneDDS または FastDDS 構成、Docker の共有メモリ、または rviz2 の X11 転送もトリガーします。 Ubuntu 22.04 および 24.04 基本イメージにわたる Humble、Iron、Jazzy、および Rolling ディストリビューションをカバーします。
