Utilizza questa competenza durante la containerizzazione degli spazi di lavoro ROS2, l'impostazione di docker-compose per stack software robot, il debug della comunicazione DDS tra contenitori, la configurazione di NVIDIA Container Toolkit per carichi di lavoro GPU, l'inoltro di X11/Wayland per rviz2 e strumenti GUI o la gestione del passthrough del dispositivo USB per fotocamere e dispositivi seriali. Si attiva ogni volta che l'utente menziona Docker con ROS2, docker-compose per robot, Dockerfile per spazi di lavoro colcon, reti di contenitori per DDS, contenitori GPU per percezione, devcontainer per ROS2, build multistadio per ROS2 o distribuzione di ROS2 in contenitori. Attiva anche CI/CD con build ROS2 basate su Docker, configurazione CycloneDDS o FastDDS in contenitori, memoria condivisa in Docker o inoltro X11 per rviz2.
