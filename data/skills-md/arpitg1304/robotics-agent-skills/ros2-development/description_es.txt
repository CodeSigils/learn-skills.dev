Mejores prácticas integrales, patrones de diseño y errores comunes para el desarrollo de ROS2 (Robot Operating System 2). Utilice esta habilidad al crear nodos, paquetes, archivos de inicio, componentes o depuración de sistemas ROS2. Se activa cada vez que el usuario menciona ROS2, colcon, rclpy, rclcpp, DDS, QoS, nodos de ciclo de vida, nodos administrados, lanzamiento de ROS2, parámetros de ROS2, acciones de ROS2, nav2, MoveIt2, micro-ROS o cualquier middleware robótico de la era ROS2. También activa la configuración del espacio de trabajo de ROS2, el ajuste de DDS, la comunicación dentro del proceso, la seguridad de ROS2 o la implementación de ROS2 en producción. También activa problemas de compilación de colcon, ament_cmake, ament_python, CMakeLists.txt para ROS2, dependencias de package.xml, rosdep, superposiciones de espacios de trabajo, generación de mensajes personalizados o resolución de problemas de compilación de ROS2. Cubre las distribuciones Humble, Iron, Jazzy y Rolling.
