أفضل الممارسات الشاملة وأنماط التصميم والمزالق الشائعة لتطوير ROS2 (نظام تشغيل الروبوت 2). استخدم هذه المهارة عند إنشاء عقد ROS2 أو الحزم أو تشغيل الملفات أو المكونات أو تصحيح أخطاء أنظمة ROS2. يتم التشغيل عندما يذكر المستخدم ROS2، أو colcon، أو rclpy، أو rclcpp، أو DDS، أو QoS، أو عقد دورة الحياة، أو العقد المُدارة، أو إطلاق ROS2، أو معلمات ROS2، أو إجراءات ROS2، أو nav2، أو MoveIt2، أو micro-ROS، أو أي برامج وسيطة للروبوتات في عصر ROS2. قم أيضًا بتشغيل إعداد مساحة عمل ROS2 أو ضبط DDS أو الاتصال داخل العملية أو أمان ROS2 أو نشر ROS2 في الإنتاج. قم أيضًا بتشغيل مشكلات بناء colcon، أو ament_cmake، أو ament_python، أو CMakeLists.txt لـ ROS2، أو تبعيات package.xml، أو rosdep، أو تراكبات مساحة العمل، أو إنشاء الرسائل المخصصة، أو استكشاف أخطاء بناء ROS2 وإصلاحها. يغطي توزيعات Humble وIron وJazzy وRolling.
