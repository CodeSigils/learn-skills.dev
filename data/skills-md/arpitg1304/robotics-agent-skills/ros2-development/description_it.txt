Usa questa abilità quando crei nodi ROS2, pacchetti, file di avvio, componenti o esegui il debug di sistemi ROS2. Si attiva ogni volta che l'utente menziona ROS2, colcon, rclpy, rclcpp, DDS, QoS, nodi del ciclo di vita, nodi gestiti, lancio di ROS2, parametri ROS2, azioni ROS2, nav2, MoveIt2, micro-ROS o qualsiasi middleware di robotica dell'era ROS2. Attiva anche l'impostazione dell'area di lavoro ROS2, l'ottimizzazione DDS, la comunicazione intra-processo, la sicurezza ROS2 o la distribuzione di ROS2 in produzione. Attiva anche per problemi di build colcon, ament_cmake, ament_python, CMakeLists.txt per ROS2, dipendenze package.xml, rosdep, sovrapposizioni dell'area di lavoro, generazione di messaggi personalizzati o risoluzione dei problemi di build ROS2.
