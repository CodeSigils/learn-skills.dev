Análisis de datos exploratorios defensivos para datos científicos (CSV, FASTA, etc.). Primero el contexto, guiado por el ser humano; un gráfico a la vez, pregunte por qué antes de ejecutarlo, cuaderno de laboratorio en coautoría por análisis, scripts con ejecución uv, gráficos WebP. Admite cuadernos marimo y Rmarkdown. Úselo al abrir archivos de datos para EDA o cuando el usuario desee una exploración de datos científicos guiada.
