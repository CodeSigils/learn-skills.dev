浏览 Turf.js (turfjs.org) 地理空间库，为任务选择正确的函数。每当用户编写涉及 Turf.js、@turf/* npm 包、GeoJSON 操作或地理空间计算（如距离、面积、缓冲区、多边形内的点、交集或聚类）的代码时，请使用此技能 - 即使“Turf”未命名。触发从 @turf/turf 或任何 @turf/ 包的导入、涉及经/纬度坐标和计算（不仅仅是渲染）的任务以及 v6 到 v7 迁移问题。当用户使用地图库（Leaflet、Mapbox GL、MapLibre、Google Maps、OpenLayers、deck.gl）并绘制或编辑形状时也会触发 - Leaflet.draw、Mapbox GL Draw、react-leaflet-draw、terra-draw、OpenLayers Draw 交互 - 因为 Turf 是“用户绘制了一个多边形，现在对其进行计算”的规范对。不要触发不涉及几何计算、绘图或编辑的纯地图渲染、图块加载、标记放置或底图样式问题。
