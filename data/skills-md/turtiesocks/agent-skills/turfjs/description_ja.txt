Turf.js (turfjs.org) 地理空間ライブラリをナビゲートして、タスクに適切な関数を選択します。 "Turf" という名前が付けられていない場合でも、ユーザーが Turf.js、@turf/* npm パッケージ、GeoJSON 操作、距離、面積、バッファー、ポリゴン内ポイント、交差、クラスタリングなどの地理空間計算に触れるコードを作成するときは常に、このスキルを使用してください。 @turf/turf または任意の @turf/ パッケージからのインポート、経度/緯度座標と計算 (レンダリングだけでなく) を含むタスク、および v6 から v7 への移行に関する質問でトリガーします。また、ユーザーがマップ ライブラリ (Leaflet、Mapbox GL、MapLibre、Google Maps、OpenLayers、deck.gl) を操作し、形状を描画または編集しているとき (Leaflet.draw、Mapbox GL Draw、react-leaflet-draw、terra-draw、OpenLayers Draw インタラクション) にもトリガーします。これは、Turf が「ユーザーがポリゴンを描画し、それを計算する」ための正規のペアであるためです。幾何学的な計算、描画、または編集が関与しない、純粋なマップのレンダリング、タイルの読み込み、マーカーの配置、またはベースマップのスタイルに関する質問をトリガーしないでください。
