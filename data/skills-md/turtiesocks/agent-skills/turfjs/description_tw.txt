瀏覽 Turf.js (turfjs.org) 地理空間函式庫，為任務選擇正確的函式。每當使用者編寫涉及 Turf.js、@turf/* npm 套件、GeoJSON 操作或地理空間計算（如距離、面積、緩衝區、多邊形內的點、交集或聚類）的程式碼時，請使用此技能 - 即使「Turf」未命名。觸發從 @turf/turf 或任何 @turf/ 套件的導入、涉及經/緯度座標和計算（不僅僅是渲染）的任務以及 v6 到 v7 遷移問題。當使用者使用地圖函式庫（Leaflet、Mapbox GL、MapLibre、Google Maps、OpenLayers、deck.gl）並繪製或編輯形狀時也會觸發 - Leaflet.draw、Mapbox GL Draw、react-leaflet-draw、terra-draw、OpenLayers Draw 交互 - 因為 Turf 是「現在」對一個多邊形的規範進行了一個多邊形規格。不要觸發不涉及幾何計算、繪圖或編輯的純地圖渲染、圖塊載入、標記放置或底圖樣式問題。
