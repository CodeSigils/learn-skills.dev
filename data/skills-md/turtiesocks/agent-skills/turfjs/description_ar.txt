انتقل إلى المكتبة الجغرافية المكانية Turf.js (turfjs.org) لاختيار الوظيفة المناسبة لمهمة ما. استخدم هذه المهارة عندما يكتب المستخدم تعليمات برمجية تلامس Turf.js أو حزم @turf/* npm أو معالجة GeoJSON أو الحسابات الجغرافية المكانية مثل المسافة أو المنطقة أو المخزن المؤقت أو نقطة المضلع أو التقاطع أو التجميع - حتى لو لم يتم تسمية "Turf". قم بتشغيل عمليات الاستيراد من @turf/turf أو أي حزمة @turf/، وفي المهام التي تتضمن إحداثيات lon/lat والحساب (وليس فقط العرض)، وعلى أسئلة الترحيل من الإصدار 6 إلى الإصدار 7. يتم تشغيله أيضًا عندما يعمل المستخدم مع مكتبة خرائط (Leaflet، Mapbox GL، MapLibre، Google Maps، OpenLayers، Deck.gl) ورسم الأشكال أو تحريرها - Leaflet.draw، Mapbox GL Draw، تفاعل-leaflet-draw، terra-draw، OpenLayers Draw - لأن Turf هو الزوج المتعارف عليه لـ "رسم المستخدم مضلعًا، والآن قم بالحساب عليه". لا تقم بتشغيل أسئلة عرض الخريطة أو تحميل التجانب أو وضع العلامة أو تصميم خريطة الأساس حيث لا تتضمن أي حسابات هندسية أو رسم أو تحرير.
