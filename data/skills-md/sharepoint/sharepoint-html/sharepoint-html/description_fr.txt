Créez du code HTML qui s'affiche dans la visionneuse HTML OneUp de SharePoint et publiez-le dans le propre OneDrive/SharePoint de l'utilisateur. Utilisez cette compétence chaque fois que l'utilisateur souhaite créer, héberger, publier, partager, obtenir un lien vers ou mettre à jour une page Web, un tableau de bord, un rapport, un diagramme, un prototype ou un diaporama dans Microsoft 365, même s'il ne dit pas « SharePoint » ou « OneDrive » par son nom. Couvre le contrat de rendu OneUp (les règles CSP/sandbox qui permettent le rendu HTML au lieu d'échouer silencieusement), l'intégration de données de fichiers SharePoint en direct et la publication via Microsoft Graph (principal) ou l'API SharePoint Vroom (lorsque l'agent est intégré à SharePoint OAuth), ainsi que des modèles prêts à l'emploi.
