SharePoint の OneUp HTML ビューアでレンダリングされる HTML を作成し、それをユーザー自身の OneDrive / SharePoint に公開します。ユーザーが Microsoft 365 内で Web ページ、ダッシュボード、レポート、図、プロトタイプ、またはスライド デッキを作成、ホスト、公開、共有、リンクの取得、または更新したい場合は常に、名前を "SharePoint" または "OneDrive" と言わなくても、このスキルを使用します。 OneUp レンダリング コントラクト (サイレントに失敗するのではなく HTML レンダリングを行う CSP/サンドボックス ルール)、ライブ SharePoint ファイル データの埋め込み、Microsoft Graph (プライマリ) または SharePoint Vroom API (エージェントが SharePoint OAuth にオンボードされている場合) を介したパブリッシュ、および既製のテンプレートをカバーします。
