Cree HTML que se represente en el visor HTML OneUp de SharePoint y publíquelo en el OneDrive/SharePoint del usuario. Utilice esta habilidad siempre que el usuario desee crear, alojar, publicar, compartir, obtener un vínculo o actualizar una página web, panel, informe, diagrama, prototipo o presentación de diapositivas dentro de Microsoft 365, incluso si no dice "SharePoint" o "OneDrive" por su nombre. Cubre el contrato de representación de OneUp (las reglas CSP/sandbox que hacen que HTML se represente en lugar de fallar silenciosamente), la incorporación de datos de archivos de SharePoint en vivo y la publicación a través de Microsoft Graph (principal) o la API de SharePoint Vroom (cuando el agente está integrado con SharePoint OAuth), además de plantillas listas para usar.
