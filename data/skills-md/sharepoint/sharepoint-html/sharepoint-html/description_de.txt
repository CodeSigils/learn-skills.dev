Erstellen Sie HTML, das im OneUp-HTML-Viewer von SharePoint gerendert wird, und veröffentlichen Sie es im eigenen OneDrive/SharePoint des Benutzers. Verwenden Sie diese Fähigkeit immer dann, wenn der Benutzer eine Webseite, ein Dashboard, einen Bericht, ein Diagramm, einen Prototyp oder ein Foliendeck in Microsoft 365 erstellen, hosten, veröffentlichen, freigeben, einen Link dafür erhalten oder aktualisieren möchte – auch wenn der Name nicht „SharePoint“ oder „OneDrive“ lautet. Deckt den OneUp-Rendering-Vertrag (die CSP-/Sandbox-Regeln, die dafür sorgen, dass HTML gerendert wird, anstatt stillschweigend zu scheitern), das Einbetten von Live-SharePoint-Dateidaten und die Veröffentlichung über Microsoft Graph (primär) oder die SharePoint Vroom-API (wenn der Agent mit SharePoint OAuth integriert ist) sowie vorgefertigte Vorlagen ab.
