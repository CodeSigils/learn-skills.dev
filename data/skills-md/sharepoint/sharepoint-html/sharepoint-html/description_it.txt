Crea codice HTML che viene visualizzato nel visualizzatore HTML OneUp di SharePoint e pubblicalo nel OneDrive/SharePoint dell'utente. Utilizza questa competenza ogni volta che l'utente desidera creare, ospitare, pubblicare, condividere, ottenere un collegamento o aggiornare una pagina Web, un dashboard, un report, un diagramma, un prototipo o una presentazione all'interno di Microsoft 365, anche se non dice "SharePoint" o "OneDrive" per nome. Copre il contratto di rendering OneUp (le regole CSP/sandbox che eseguono il rendering HTML invece di fallire silenziosamente), l'incorporamento di dati di file SharePoint in tempo reale e la pubblicazione tramite Microsoft Graph (primario) o l'API Vroom di SharePoint (quando l'agente è integrato con SharePoint OAuth), oltre a modelli già pronti.
