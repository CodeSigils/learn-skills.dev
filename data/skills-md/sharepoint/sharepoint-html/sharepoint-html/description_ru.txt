Создавайте HTML-код, который отображается в средстве просмотра HTML OneUp SharePoint, и публикуйте его в собственном OneDrive/SharePoint пользователя. Используйте этот навык всякий раз, когда пользователь хочет создать, разместить, опубликовать, поделиться, получить ссылку или обновить веб-страницу, панель мониторинга, отчет, диаграмму, прототип или слайд-шоу в Microsoft 365 — даже если он не произносит «SharePoint» или «OneDrive» по имени. Охватывает контракт рендеринга OneUp (правила CSP/песочницы, которые обеспечивают рендеринг HTML вместо автоматического сбоя), внедрение текущих файловых данных SharePoint и публикацию через Microsoft Graph (основной) или API SharePoint Vroom (когда агент подключен к SharePoint OAuth), а также готовые шаблоны.
