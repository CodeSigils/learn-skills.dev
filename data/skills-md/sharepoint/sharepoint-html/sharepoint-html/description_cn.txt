编写在 SharePoint 的 OneUp HTML 查看器中呈现的 HTML，并将其发布到用户自己的 OneDrive/SharePoint 中。每当用户想要在 Microsoft 365 中创建、托管、发布、共享、获取链接或更新网页、仪表板、报告、图表、原型或幻灯片时，即可使用此技能 - 即使他们没有说出“SharePoint”或“OneDrive”的名称。涵盖 OneUp 渲染合同（使 HTML 渲染而不是静默失败的 CSP/沙箱规则）、嵌入实时 SharePoint 文件数据、通过 Microsoft Graph（主要）或 SharePoint Vroom API（当代理使用 SharePoint OAuth 加入时）进行发布，以及现成的模板。
