مؤلف HTML الذي يتم عرضه في عارض OneUp HTML الخاص بـ SharePoint ونشره في OneDrive / SharePoint الخاص بالمستخدم. استخدم هذه المهارة عندما يريد المستخدم إنشاء أو استضافة أو نشر أو مشاركة أو الحصول على رابط أو تحديث صفحة ويب أو لوحة معلومات أو تقرير أو رسم تخطيطي أو نموذج أولي أو مجموعة شرائح داخل Microsoft 365 - حتى لو لم يذكر "SharePoint" أو "OneDrive" بالاسم. يغطي عقد عرض OneUp (قواعد CSP / Sandbox التي تجعل عرض HTML بدلاً من الفشل بصمت)، وتضمين بيانات ملف SharePoint المباشرة، والنشر عبر Microsoft Graph (الأساسي) أو SharePoint Vroom API (عندما يكون الوكيل مشتركًا مع SharePoint OAuth)، بالإضافة إلى القوالب الجاهزة.
