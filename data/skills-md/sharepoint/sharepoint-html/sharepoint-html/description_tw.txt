編寫在 SharePoint 的 OneUp HTML 檢視器中呈現的 HTML，並將其發佈到使用者自己的 OneDrive/SharePoint 中。每當使用者想要在 Microsoft 365 中建立、託管、發布、分享、取得連結或更新網頁、儀表板、報告、圖表、原型或投影片時，即可使用此技能 - 即使他們沒有說出「SharePoint」或「OneDrive」的名稱。涵蓋 OneUp 渲染合約（使 HTML 渲染而不是靜默失敗的 CSP/沙箱規則）、嵌入即時 SharePoint 檔案資料、透過 Microsoft Graph（主要）或 SharePoint Vroom API（當代理程式使用 SharePoint OAuth 加入時）進行發布，以及現成的範本。
