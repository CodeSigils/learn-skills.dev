Pilotez l'OSMO CLI pour le calcul de la robotique cloud pour le compte d'un utilisateur final : vérifiez les ressources, soumettez/surveillez/débogez/expliquez les flux de travail, récupérez les journaux et les liens Grafana/Kubernetes, inspectez le stockage direct des données, gérez les applications de flux de travail et définissez les informations d'identification du flux de travail. À utiliser chaque fois que l'utilisateur pose des questions sur les pools, les quotas, les GPU ou les nœuds OSMO, ou sur la soumission, la liste, l'interrogation, la surveillance ou le dépannage des workflows — y compris les workflows en échec, en attente, en file d'attente, bloqués ou bloqués par l'extraction d'images, ou lorsqu'il demande d'inspecter ou de transférer des URI de stockage direct tels que « s3://... », même lorsqu'il décrit un workflow, une ressource de cluster ou un URI de stockage sans dire « OSMO ». Ne pas utiliser pour l'administration Kubernetes, les modifications de la configuration osmo côté serveur, l'installation/le déploiement d'OSMO, le calcul non OSMO ou les questions générales sur le matériel NVIDIA.
