قم بقيادة OSMO CLI لحساب الروبوتات السحابية نيابة عن المستخدم النهائي: التحقق من الموارد، وإرسال/مراقبة/تصحيح الأخطاء/شرح سير العمل، وجلب السجلات وروابط Grafana/Kubernetes، وفحص تخزين البيانات المباشر، وإدارة تطبيقات سير العمل، وتعيين بيانات اعتماد سير العمل. يُستخدم عندما يسأل المستخدم عن مجموعات OSMO أو الحصة النسبية أو وحدات معالجة الرسومات أو العقد، أو عن إرسال مسارات العمل أو إدراجها أو الاستعلام عنها أو مراقبتها أو استكشاف الأخطاء وإصلاحها - بما في ذلك مسارات العمل الفاشلة أو المعلقة أو الموضوعة في قائمة الانتظار أو المتوقفة أو المحظورة بسحب الصور، أو عندما يطلبون فحص أو نقل معرفات URI للتخزين المباشر مثل `s3://...`، حتى عندما يصفون سير عمل أو مورد نظام المجموعة أو URI للتخزين دون قول "OSMO". لا تستخدمه لمسؤول Kubernetes، أو تغييرات `osmo config` من جانب الخادم، أو تثبيت/نشر OSMO، أو الحوسبة غير التابعة لـ OSMO، أو الأسئلة العامة عن أجهزة NVIDIA.
