استخدم هذه المهارة عندما يقوم المستخدم بتنفيذ برمجة DOCA Erasure Coding العملية على BlueField DPU أو ConnectX NIC أو المضيف - لإظهار سياق doca_ec، أو الاختيار بين مهام الإنشاء / الاسترداد / التحديث، أو اختيار نوع المصفوفة / N / K / حجم الكتلة، أو الاستعلام عن doca_ec_cap_* قبل تغيير الحجم، أو تعيين أذونات doca_mmap src/dst، أو تصحيح أخطاء DOCA_ERROR_* doca_ec_task_*. يتم التشغيل حتى عندما لا يذكر المستخدم "DOCA Erasure Coding" أو "Reed-Solomon" - تتضمن العبارات الضمنية النموذجية "تم تغيير كتلة بيانات واحدة، كيف يمكنني تحديث التكافؤ دون إعادة التشفير"، أو "فشل القرص واختفاء كتلتين من التماثل، هل يمكنني إعادة البناء"، أو "مرونة RAID-6 عبر 12 قرصًا"، أو "إرجاع doca_ec_task_create الخاص بي NOT_PERMITTED"، أو "هل لا يزال تخطيط N+K هذا قابلاً للاسترداد". قم بالرفض والتوجيه إلى مكان آخر للحصول على رموز غير Reed-Solomon (نافورة / LDPC / Raptor)، أو تصميمات النسخ المتماثل النقي، أو شبكة FEC، أو مكتبات تسريع DOCA الأخرى (SHA / Compress / AES-GCM / DMA) - تلك تنتمي إلى مهارات أخرى.
