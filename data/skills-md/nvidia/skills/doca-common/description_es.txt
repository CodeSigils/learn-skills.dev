Utilice esta habilidad siempre que el usuario esté realizando programación DOCA práctica en una DPU BlueField o una NIC ConnectX y necesite las primitivas básicas en las que se basa cada contexto por biblioteca: recorrer el ciclo de vida de doca_ctx, descubrir doca_dev / doca_devinfo y activar doca_*_cap_* antes de confiar en una función, cablear doca_mmap / doca_buf_inventory / doca_buf para E/S sin copia bibliotecas, impulsando doca_pe para las completaciones o el modelo de dos niveles de DOCA Log (--sdk-log-level vs app-side). Se activa incluso cuando el usuario no dice "DOCA Common"; las frases implícitas típicas incluyen "mis tareas se envían pero no se completa nada", "DOCA_ERROR_BAD_STATE de doca_ctx_start", "--sdk-log-level no hace nada con mis líneas DOCA_LOG_DBG", "comparte un error entre doca_dma y doca_rdma" o "se bloquea lejos de la línea infractora". Rechace y envíe a otro lugar para preguntas por biblioteca de forma aislada (cargue doca-flow / doca-rdma / doca-eth al lado), instale DOCA (doca-setup) o busque documentos (doca-public-knowledge-map).
