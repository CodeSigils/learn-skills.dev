Стандартный одношаговый рабочий процесс обучения/оценки/экспорта для любой модели TAO. Используйте при обучении модели TAO на наборе данных без итеративного увеличения данных, циклов AutoML или DEFT. Триггерные фразы включают «прогон одного поезда», «обучить, затем оценить, а затем экспортировать», «простое обучение TAO», «нормальное обучение», «без AutoML», «пропустить цикл». Направляется через SKILL.md для каждой модели для получения конкретных действий и через `tao-launch-workflow` для получения платформы/учетных данных/набора данных.
