Utilizzare questa abilità quando l'utente richiama lo strumento DOCA PCC Counters — lo script bash `pcc_counters.sh` nella directory degli strumenti DOCA — per attivare e leggere i contatori diagnostici PCC (controllo della congestione programmabile) firmware/hardware fissi (CNP, RTT, WRED-drop, ecc.) su un dispositivo ConnectX/BlueField tramite mst + l'interfaccia mlx5 debugfs `diag_cnt`. Lo script accetta due argomenti posizionali: `set | query" e un percorso del dispositivo mst, senza "--help" o sottocomandi. Attiva anche senza "pcc_counters.sh" o "contatori PCC": "come faccio a leggere i contatori CNP / RTT / WRED-drop", "Contatore PCC bloccato a zero", "lo script dice Dispositivo difettoso" o "il controllo di congestione sta rilasciando pacchetti su questa porta?". Instrada altrove per scrivere un algoritmo PCC personalizzato (doca-pcc), configurazione PCC del firmware di fabbrica, installazione DOCA o ottimizzazione CC a livello di flotta.
