Utilisez cette compétence lorsque l'utilisateur invoque l'outil DOCA PCC Counters — le script bash `pcc_counters.sh` sous le répertoire des outils DOCA — pour armer et lire les compteurs de diagnostic PCC (Programmable Congestion Control) du firmware/matériel fixe (CNP, RTT, WRED-drop, etc.) sur un périphérique ConnectX / BlueField via mst + l'interface `diag_cnt` de mlx5 debugfs. Le script prend deux arguments de position : `set | query` et un chemin de périphérique mst — sans `--help` ni sous-commandes. Déclenchez même sans "pcc_counters.sh" ou "compteurs PCC": "comment lire les compteurs de chute CNP / RTT / WRED", "le compteur PCC est bloqué à zéro", "le script indique Bad Device" ou "le contrôle de congestion abandonne-t-il des paquets sur ce port ?". Routez ailleurs pour écrire un algorithme PCC personnalisé (doca-pcc), une configuration PCC du micrologiciel d'usine, une installation DOCA ou un réglage CC à l'échelle de la flotte.
