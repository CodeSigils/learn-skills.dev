Utilice esta habilidad cuando el usuario invoque la herramienta DOCA PCC Counters (el script bash `pcc_counters.sh` en el directorio de herramientas DOCA) para armar y leer los contadores de diagnóstico PCC (control de congestión programable) de firmware/hardware fijo (CNP, RTT, WRED-drop, etc.) en un dispositivo ConnectX/BlueField a través de mst + la interfaz mlx5 debugfs `diag_cnt`. El script toma dos argumentos posicionales: `set | query` y una ruta de dispositivo mst, sin `--help` ni subcomandos. Se activa incluso sin "pcc_counters.sh" o "contadores PCC": "¿cómo leo los contadores de caída CNP/RTT/WRED", "el contador PCC se atasca en cero", "el script dice Dispositivo incorrecto" o "¿el control de congestión está descartando paquetes en este puerto?". Diríjase a otro lugar para escribir un algoritmo PCC personalizado (doca-pcc), configuración de PCC de firmware de fábrica, instalación de DOCA o ajuste de CC en toda la flota.
