Pipeline d'expressions de référence d'images en quatre étapes : transforme les images ainsi que les étiquettes de boîte englobante KITTI en descriptions de régions, légendes de scènes, expressions de référence fondées et (éventuellement) expressions vérifiées via la distillation VLM. À utiliser lorsque l'utilisateur souhaite générer des annotations d'expression de référence à partir d'images avec des étiquettes KITTI, créer des descriptions de régions, produire des phrases de base groupées liées à des bbox, exécuter une double vérification des expressions de base, étiqueter automatiquement les images de trafic/scène pour les ensembles de données de référence, ou exécuter le pipeline image_referring_expression. Les déclencheurs incluent « expression de référence », « description de région », « étiquettes KITTI », « annotation de relation spatiale », « expression de référence d'image à étiquetage automatique », « image_referring_expression ».
