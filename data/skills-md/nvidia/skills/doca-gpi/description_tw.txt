當使用者進行實踐 DOCA GPI 編程時使用此技能 - 連接 GPU-Packet-Initiator 上下文，以便 CUDA 核心直接從 GPU 記憶體驅動 RDMA 佇列，無需主機 CPU 中介。涵蓋選擇 GPI 與 doca-gpunetio、doca_gpi/域/通道物件模型、GPU 端句柄切換 (doca_gpu_gpi_channel*)、將 GPU 記憶體附加到 GPI 域、域和通道屬性對象，以及從 doca_gpi_* 呼叫 DOCA_ERROR_*。即使用戶沒有明確提及“DOCA GPI”，也會觸發 - 典型的隱式措辭包括“我的 CUDA 內核需要直接從 GPU 內存發布 RDMA”、“來自 doca_gpi_gpu_channel_get 的 DOCA_ERROR_*”、“如何將 GPU 句柄交給我的 CUDA 域交給我的 CUDA 電路、“如何將 GPU 配置在 2個新網域” GPU 核心」。拒絕並路由 doca-gpunetio 發送/接收表面、doca-rdma 佇列生命週期、DPA 端啟動 (doca-rdmi) 或 CUDA 程式設計模型 — 這些屬於其他技能。
