Utilizza questa competenza quando l'utente esegue la programmazione pratica DOCA GPI, collegando un contesto GPU-Packet-Initiator in modo che un kernel CUDA guidi le code RDMA direttamente dalla memoria GPU senza la mediazione della CPU host. Riguarda la scelta di GPI rispetto a doca-gpunetio, il modello a oggetti doca_gpi/dominio/canale, l'handoff dell'handoff lato GPU (doca_gpu_gpi_channel*), il collegamento della memoria GPU a un dominio GPI, gli oggetti di attributo dominio e canale e il debug di DOCA_ERROR_* dalle chiamate doca_gpi_*. Si attiva anche quando l'utente non menziona esplicitamente "DOCA GPI": le tipiche frasi implicite includono "il mio kernel CUDA deve pubblicare RDMA direttamente dalla memoria della GPU", "DOCA_ERROR_* da doca_gpi_gpu_channel_get", "come posso consegnare un handle GPU al mio kernel CUDA", "quanti canali può contenere un dominio GPI" o "kernel GPU che guida RDMA senza la CPU host sul percorso". Rifiuta e indirizza altrove per la superficie di invio/ricezione doca-gpunetio, il ciclo di vita della coda doca-rdma, l'iniziazione lato DPA (doca-rdmi) o il modello di programmazione CUDA: questi appartengono ad altre competenze.
