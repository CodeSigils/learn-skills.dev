このスキルは、ユーザーが実践的な DOCA GPI プログラミングを行っている場合、つまり GPU-パケット-イニシエーター コンテキストを配線して、CUDA カーネルがホスト CPU の仲介なしで GPU メモリから直接 RDMA キューを駆動するときに使用します。 GPI と doca-gpunetio の選択、doca_gpi / ドメイン / チャネル オブジェクト モデル、GPU 側ハンドル ハンドオフ (doca_gpu_gpi_channel*)、GPI ドメインへの GPU メモリの接続、ドメインおよびチャネル属性オブジェクト、doca_gpi_* 呼び出しからの DOCA_ERROR_* のデバッグについて説明します。ユーザーが明示的に「DOCA GPI」に言及していない場合でもトリガーします。典型的な暗黙的な表現には、「CUDA カーネルは GPU メモリから直接 RDMA をポストする必要がある」、「doca_gpi_gpu_channel_get からの DOCA_ERROR_*」、「GPU ハンドルを CUDA カーネルに渡す方法」、「GPI ドメインが保持できるチャネル数」、または「GPU カーネルは、パス上のホスト CPU」。 doca-gpunetio 送受信サーフェス、doca-rdma キュー ライフサイクル、DPA 側の開始 (doca-rdmi)、または CUDA プログラミング モデルについては、拒否して別の場所にルーティングします。これらは他のスキルに属します。
