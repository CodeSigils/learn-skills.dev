当用户进行实践 DOCA GPI 编程时使用此技能 - 连接 GPU-Packet-Initiator 上下文，以便 CUDA 内核直接从 GPU 内存驱动 RDMA 队列，无需主机 CPU 中介。涵盖选择 GPI 与 doca-gpunetio、doca_gpi/域/通道对象模型、GPU 端句柄切换 (doca_gpu_gpi_channel*)、将 GPU 内存附加到 GPI 域、域和通道属性对象，以及从 doca_gpi_* 调用调试 DOCA_ERROR_*。即使用户没有明确提及“DOCA GPI”，也会触发 - 典型的隐式措辞包括“我的 CUDA 内核需要直接从 GPU 内存发布 RDMA”、“来自 doca_gpi_gpu_channel_get 的 DOCA_ERROR_*”、“如何将 GPU 句柄交给我的 CUDA 内核”、“GPI 域可以保留多少个通道”或“在路径上没有主机 CPU 的情况下驱动 RDMA 的 GPU 内核”。拒绝并路由 doca-gpunetio 发送/接收表面、doca-rdma 队列生命周期、DPA 端启动 (doca-rdmi) 或 CUDA 编程模型 — 这些属于其他技能。
