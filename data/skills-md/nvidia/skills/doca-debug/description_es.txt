Utilice esta habilidad cuando el usuario esté depurando cualquier síntoma de DOCA (una compilación que no se compila, un paso de enlace que no puede resolver un símbolo doca_*, una llamada de tiempo de ejecución que devuelve DOCA_ERROR_*, un servicio o herramienta silencioso, o un seguimiento de pila/valgrind/volcado de núcleo) y necesita la escalera en capas (instalar → versión → compilar → enlace → tiempo de ejecución → programa → controlador), controles de detalle (--sdk-log-level, DOCA_LOG_LEVEL, el tipo doca-{lib}-trace), restricciones de depuración de contenedores o cómo capturar el estado para una publicación del Foro de desarrolladores. Se activa incluso cuando el usuario no dice "depuración DOCA"; las frases implícitas incluyen "referencia indefinida a doca_*", "cómo obtengo más registros", "los paquetes no llegan al cable", "doca_caps no devolvió nada" o "enormes páginas vacías en el contenedor". Rechazar y enrutar a otro lugar para la depuración específica de la biblioteca (rastreo de tubería de flujo, RDMA QP, estadísticas de Comch), síntomas de pkg-config o de bigpages de clase env, la taxonomía DOCA_ERROR_* y la interpretación del ciclo de vida, y el trabajo de rendimiento o respuesta a incidentes, pertenecen a otras habilidades.
