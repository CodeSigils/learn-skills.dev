استخدم هذه المهارة للعمل العملي على قائمة انتظار حزم DOCA Ethernet على BlueField DPU أو ConnectX NIC - إظهار `doca_eth_rxq` أو `doca_eth_txq` على منفذ / ممثل / SF، والاختيار من بين قيم `enum doca_eth_rxq_type` الأربعة (`_REGULAR` / `_CYCLIC` / `_MANAGED_MEMPOOL` / `_SHARED_MEMPOOL`)، أو تغيير حجم الاندفاع أو طول التجميع المبعثر مقابل استعلامات `_cap_*`، أو إرسال `doca_eth_txq_task_send` / `_lso_send` (حمل الحزمة `doca_buf`s - لا توجد بنية `doca_eth_frame`)، أو تصحيح الأخطاء DOCA_ERROR_* من مكالمة Ethernet. تشغيل العبارات الضمنية: "قائمة انتظار RX الخاصة بي جاهزة ولكن لم تصل أي حزم"، أو "إرجاع مهمة الإرسال مرة أخرى بمعدل السطر"، أو "أي نوع قائمة الانتظار لإدخال MTU ثابت"، أو "فشل فتح الجهاز بدون Sudo"، أو "إلغاء تحميل المجموع الاختباري L3 متاح هنا". قم بالرفض والتوجه إلى مكان آخر لتثبيت DOCA، أو برمجة قاعدة التدفق/التوجيه، أو رسائل التحكم في المضيف ↔DPU، أو حركة بيانات RDMA.
