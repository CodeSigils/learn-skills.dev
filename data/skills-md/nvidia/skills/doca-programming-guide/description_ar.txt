استخدم هذه المهارة عندما يكتب المستخدم أول تطبيق DOCA أو يطرح سؤال برمجة غير مرتبط بالمكتبة - اختيار عينة مشحونة للنسخ والتعديل، أو توصيل pkg-config doca-{library} + meson build (أو FFI من Rust / Go / Python ضد C ABI العام)، أو السير على cfg-create → init → start → use → stop → تدمير دورة الحياة، أو التحقق من صحة المواصفات قبل الالتزام، أو فك تشفير DOCA_ERROR_* return باستخدام doca_error_get_descr(). يتم التشغيل حتى عندما لا يقول المستخدم "دليل برمجة DOCA" - عبارات ضمنية: "اكتب برنامج DOCA الأول الخاص بي"، "خط meson لـ doca_rdma_*"، "حصلت على DOCA_ERROR_BAD_STATE في مكالمتي الأولى"، "اتصل بـ DOCA من Rust بدون كتابة C"، "تم تصميمه بشكل نظيف ولكن لا شيء على السلك"، "ما هو ترتيب مكالمات doca_*_pipe". رفض وتوجيه التثبيت/hubpages/pkg-config لا يحل doca-{library} (doca-setup)، أو المستندات أو البحث عن الإصدار (doca-public-knowledge-map)، وإنشاء واجهة برمجة التطبيقات الداخلية للمكتبة مثل طوبولوجيا أنبوب التدفق أو إعداد RDMA QP (مطابقة مهارات المكتبة).
