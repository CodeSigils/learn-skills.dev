Используйте этот навык, когда пользователь пишет свое первое приложение DOCA или задает вопрос по программированию, не зависящий от библиотеки — выбирает готовый образец для копирования и изменения, связывает каноническую сборку pkg-config doca-{library} + meson (или FFI из Rust/Go/Python с общедоступным C ABI), выполняет cfg-create → init → start → use → stop → уничтожить жизненный цикл, проверяет спецификацию перед фиксацией или декодирует возврат DOCA_ERROR_* с помощью doca_error_get_descr(). Срабатывает даже тогда, когда пользователь не произносит «Руководство по программированию DOCA» — неявные фразы: «написать мою первую программу DOCA», «мезонная строка для doca_rdma_*», «получил DOCA_ERROR_BAD_STATE при первом вызове», «вызов DOCA из Rust без написания C», «построено чисто, но ничего не подключено», «в каком порядке идут вызовы doca_*_pipe». Отказаться и направить для установки / огромных страниц / pkg-config, не разрешающих doca-{library} (doca-setup), документов или поиска версий (doca-public-knowledge-map), а также внутреннюю конструкцию API библиотеки, например топологию Flow Pipe или настройку RDMA QP (соответствующий навык работы с библиотекой).
