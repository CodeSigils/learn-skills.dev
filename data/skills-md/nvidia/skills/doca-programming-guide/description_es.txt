Utilice esta habilidad cuando el usuario esté escribiendo su primera aplicación DOCA o haciendo una pregunta de programación independiente de la biblioteca: seleccionar una muestra enviada para copiarla y modificarla, cablear el canónico pkg-config doca-{library} + meson build (o FFI de Rust/Go/Python contra la ABI pública de C), recorrer el ciclo de vida cfg-create → init → start → use → stop → destroy, validar una especificación antes de confirmar o decodificar un retorno DOCA_ERROR_* con doca_error_get_descr(). Se activa incluso cuando el usuario no dice "guía de programación DOCA": frases implícitas: "escribir mi primer programa DOCA", "línea de mesón para doca_rdma_*", "obtuve DOCA_ERROR_BAD_STATE en mi primera llamada", "llamar a DOCA desde Rust sin escribir C", "construido limpio pero sin nada en el cable", "en qué orden van las llamadas a doca_*_pipe". Rechazar y enrutar para instalar/enormepages/pkg-config que no resuelve doca-{library} (doca-setup), búsqueda de documentos o versiones (doca-public-knowledge-map) y la construcción de API interna de la biblioteca, como la topología de tubería de flujo o la configuración de RDMA QP (habilidad de biblioteca coincidente).
