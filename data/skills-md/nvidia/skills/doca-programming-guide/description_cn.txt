当用户编写第一个 DOCA 应用程序或询问与库无关的编程问题时，请使用此技能 - 选择要复制和修改的已发布示例，连接规范的 pkg-config doca-{library} + meson 构建（或 Rust / Go / Python 中的 FFI 与公共 C ABI），遍历 cfg-create → init → start → use → stop → destroy 生命周期，在提交前验证规范，或使用以下命令解码 DOCA_ERROR_* 返回doca_error_get_descr()。即使用户没有说“DOCA 编程指南”，也会触发 - 隐式短语：“编写我的第一个 DOCA 程序”、“doca_rdma_* 的介子线”、“第一次调用时得到 DOCA_ERROR_BAD_STATE”、“从 Rust 调用 DOCA，而不编写 C”、“构建干净，但线路上没有任何内容”、“doca_*_pipe 调用按什么顺序进行”。 install/hugepages/pkg-config 的拒绝和路由无法解析 doca-{library} (doca-setup)、文档或版本查找 (doca-public-knowledge-map) 以及库内部 API 构造，如流管拓扑或 RDMA QP 设置（匹配库技能）。
