Utilizzare questa competenza quando l'utente sta scrivendo la sua prima app DOCA o pone una domanda di programmazione indipendente dalla libreria: scegliendo un campione spedito da copiare e modificare, collegando il canonico pkg-config doca-{library} + meson build (o FFI da Rust / Go / Python rispetto all'ABI C pubblico), percorrendo cfg-create → init → start → use → stop → destroy lifecycle, convalidando una specifica prima del commit o decodificando un ritorno DOCA_ERROR_* con doca_error_get_descr(). Si attiva anche quando l'utente non dice "guida alla programmazione DOCA" - frasi implicite: "scrivi il mio primo programma DOCA", "riga meson per doca_rdma_*", "ho ricevuto DOCA_ERROR_BAD_STATE alla mia prima chiamata", "chiama DOCA da Rust senza scrivere C", "creato pulito ma niente in linea", "in che ordine vanno le chiamate doca_*_pipe". Rifiuta e instrada l'installazione / hugepages / pkg-config che non risolve doca-{library} (doca-setup), documenti o ricerca di versione (doca-public-knowledge-map) e costruzione di API interne alla libreria come la topologia del tubo di flusso o la configurazione RDMA QP (competenza della libreria corrispondente).
