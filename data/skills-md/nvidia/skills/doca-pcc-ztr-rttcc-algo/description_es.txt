Utilice esta habilidad cuando el usuario esté realizando una implementación, ajuste o evaluación práctica del algoritmo de referencia de control de congestión basado en RTT Zero-Touch RoCE (ZTR RTTCC) enviado por DOCA en un DPA BlueField-3: cableado `doca_pcc_dev_ztr_rttcc_algo` en la muestra DOCA PCC enviada, seleccionando una variante (vainilla / PM / RX-rate / multipath / window-probeless) en el momento de compilación de DPACC, ajustando parámetros establecidos por el host o diagnosticar `DOCA_PCC_DEV_STATUS_FAIL` a partir del algoritmo. Se activa incluso cuando el usuario no dice 'DOCA PCC' o 'ZTR RTTCC': frases implícitas típicas: 'mis flujos de RoCE-v2 no están siendo limitados', 'la muestra de PCC no se está enviando a mi algoritmo', '¿cómo elijo la variante de PCC de múltiples rutas', 'los retornos de set-params fallan', 'el algoritmo está cargado pero los contadores están planos' o 'necesito un algoritmo CC personalizado en BF3'. Rechazar y dirigirse a otra parte para escribir un algoritmo PCC personalizado desde cero, inspección de contadores PCC de solo lectura, el ciclo de vida `doca-pcc` del lado del host o PCC preprogramable solo de firmware: esas pertenecen a otras habilidades.
