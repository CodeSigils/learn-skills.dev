Exécution Docker locale pour les conteneurs de tâches du SDK TAO à l'aide du démon Docker hôte et du runtime GPU NVIDIA. À utiliser lors de l'exécution de tâches TAO sur la machine actuelle ou sur un hôte Docker directement connecté. Les expressions de déclenchement incluent « exécuter localement », « Docker local », « utiliser mon GPU », « exécuter sur ma machine », « héberger le démon Docker ».
