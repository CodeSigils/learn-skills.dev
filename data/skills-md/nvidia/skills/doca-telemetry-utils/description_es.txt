Utilice esta habilidad cuando el usuario invoque `doca_telemetry_utils` en un host con DOCA instalado: descubra el esquema del contador de diagnóstico, traduzca los nombres de los contadores a ID de datos binarios, valide el soporte del contador por dispositivo antes de confirmar una configuración del exportador de telemetría DOCA o resuelva inversamente un ID de datos capturado. Se activa incluso cuando el usuario no menciona explícitamente "doca_telemetry_utils" o "ID de datos"; las frases implícitas típicas incluyen "mi exportador envía pero el recolector no ve nada", "esta métrica cae silenciosamente hacia abajo", "qué contadores expone este BlueField", "traduce este 0x... de nuevo a un nombre de contador", "qué significa aquí nodo/pcie_index/profundidad" o "este contador es compatible con este dispositivo antes de confirmarlo". Rechace y diríjase a otro lugar para la programación de la biblioteca del recopilador/exportador del lado del desarrollador, la implementación de DTS o la instalación/reparación de DOCA; estos pertenecen a doca-telemetry, doca-public-knowledge-map y doca-setup.
