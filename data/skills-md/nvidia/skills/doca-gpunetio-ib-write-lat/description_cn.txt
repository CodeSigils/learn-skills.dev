当用户通过 doca-gpunetio 测量 GPU 内核启动的 RDMA 写入延迟时使用此技能 — 在 `doca/tools/gpunetio_ib_write_lat/` 下构建并运行 `gpunetio_ib_write_lat` 客户端 + 服务器对，检查 GPU-NIC 配对，读取 half-iter / full-iter / CUDA 端 usec 列，表征实时控制循环的中值 / p99 / 抖动，选择 GPUNetIO、GPI 与 CPU 发起的“perftest”，或者权衡延迟与批处理的权衡。即使没有“GPUNetIO”或“ib_write_lat”也会触发：“GPU 内核 RDMA 延迟基准”、“CUDA 内核发布写入的速度有多快”、“H100 + ConnectX 上的 p99 RDMA 延迟”、“内核启动的 WR 尾延迟”或“比较 GPU-init 与 CPU-init perftest”。路由到其他地方以进行带宽运行 (doca-gpunetio-ib-write-bw)、GPI 表面 (doca-gpi)、库调试 (doca-gpunetio) 或 DOCA 安装。
