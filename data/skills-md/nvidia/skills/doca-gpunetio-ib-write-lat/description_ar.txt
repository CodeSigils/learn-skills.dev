استخدم هذه المهارة عندما يقوم المستخدم بقياس زمن استجابة RDMA WRITE الذي تم تشغيله بواسطة GPU من خلال doca-gpunetio - إنشاء وتشغيل زوج العميل + الخادم `gpunetio_ib_write_lat` ضمن `doca/tools/gpunetio_ib_write_lat/`، والتحقق من إقران GPU-NIC، وقراءة أعمدة usec نصف iter / full-iter / CUDA، وتمييز الوسيط / p99 / jitter لحلقة تحكم في الوقت الفعلي، أو اختيار GPUNetIO مقابل GPI مقابل CPU الذي تم تشغيله "perftest"، أو تقييم المفاضلة بين زمن الوصول مقابل التجميع. تشغيل حتى بدون "GPUNetIO" أو "ib_write_lat": "معيار زمن استجابة RDMA لـ GPU kernel"، أو "ما مدى السرعة التي يمكن أن تنشر بها CUDA kernel عملية WRITE"، أو "زمن استجابة p99 RDMA على H100 + ConnectX"، أو "زمن استجابة WR الذي تم إطلاقه بواسطة kernel"، أو "مقارنة GPU-init مقابل CPU-init perftest". قم بالتوجيه إلى مكان آخر لتشغيل النطاق الترددي (doca-gpunetio-ib-write-bw)، أو سطح GPI (doca-gpi)، أو تصحيح أخطاء المكتبة (doca-gpunetio)، أو تثبيت DOCA.
