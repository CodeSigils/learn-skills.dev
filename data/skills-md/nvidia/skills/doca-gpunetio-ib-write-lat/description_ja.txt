このスキルは、ユーザーが doca-gpunetio を介して GPU カーネルによって開始される RDMA WRITE レイテンシーを測定するときに使用します。つまり、「doca/tools/gpunetio_ib_write_lat/」で「gpunetio_ib_write_lat」クライアントとサーバーのペアを構築して実行し、GPU-NIC ペアリングを確認し、ハーフイター / フルイター / CUDA 側 usec 列を読み取り、中央値 / p99 / を特徴付けます。リアルタイム制御ループのジッター、GPUNetIO、GPI、CPU 開始の「perftest」を選択するか、レイテンシとバッチ処理のトレードオフを比較検討します。 「GPUNetIO」または「ib_write_lat」がなくてもトリガー: 「GPU カーネル RDMA レイテンシ ベンチマーク」、「CUDA カーネルが WRITE をポストできる速度」、「H100 + ConnectX での p99 RDMA レイテンシ」、「カーネル起動の WR テール レイテンシ」、または「GPU-init と CPU-init perftest の比較」。帯域幅の実行 (doca-gpunetio-ib-write-bw)、GPI サーフェス (doca-gpi)、ライブラリのデバッグ (doca-gpunetio)、または DOCA インストールのために別の場所にルーティングします。
