사용자가 doca-gpunetio를 통해 GPU 커널 시작 RDMA WRITE 대기 시간을 측정할 때 이 기술을 사용합니다. - `doca/tools/gpunetio_ib_write_lat/`에서 `gpunetio_ib_write_lat` 클라이언트 + 서버 쌍 구축 및 실행, GPU-NIC 페어링 확인, 반 반복/전 반복/CUDA 측 usec 열 읽기, 실시간 제어를 위한 중앙값/p99/지터 특성화 루프, GPUNetIO, GPI, CPU 시작 '완벽한 테스트'를 선택하거나 대기 시간과 일괄 처리 간의 균형을 고려합니다. 'GPUNetIO' 또는 'ib_write_lat' 없이도 트리거: 'GPU 커널 RDMA 대기 시간 벤치마크', 'CUDA 커널이 쓰기를 게시할 수 있는 속도', 'H100 + ConnectX에서 p99 RDMA 대기 시간', '커널 실행 WR 테일 대기 시간' 또는 'GPU 초기화 대 CPU 초기화 성능 비교'. 대역폭 실행(doca-gpunetio-ib-write-bw), GPI 표면(doca-gpi), 라이브러리 디버깅(doca-gpunetio) 또는 DOCA 설치를 위해 다른 곳으로 라우팅합니다.
