當使用者透過 doca-gpunetio 測量 GPU 核心啟動的 RDMA 寫入延遲時使用此技能 — 在 `doca/tools/gpunetio_ib_write_lat/` 下建置並執行 `gpunetio_ib_write_lat` 用戶端 + 伺服器對，檢查 GPU-NIC 配對，讀取 GPU-NIC列，表徵即時控制循環的中位數 / p99 / 抖動，選擇 GPUNetIO、GPI 與 CPU 發起的“perftest”，或權衡延遲與批次的權衡。即使沒有「GPUNetIO」或「ib_write_lat」也會觸發：「GPU 核心 RDMA 延遲基準」、「CUDA 核心發布寫入的速度有多快」、「H100 + ConnectX 上的 p99 RDMA 延遲」、「核心啟動的 WR 尾延遲」或「比較 GPU-ininit 與 CPU-init」。路由到其他地方以進行頻寬運行 (doca-gpunetio-ib-write-bw)、GPI 表面 (doca-gpi)、庫調試 (doca-gpunetio) 或 DOCA 安裝。
