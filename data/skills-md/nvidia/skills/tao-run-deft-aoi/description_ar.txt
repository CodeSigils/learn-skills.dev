قم بتشغيل حلقة تحسين DEFT AOI الكاملة لنماذج فحص NVIDIA TAO VisualChangeNet / ChangeNet PCB: تقييم خط الأساس، وRCA، واستيعاب صور AnomalyGen التي تم إنشاؤها مسبقًا والتي يقدمها العميل، وتعدين k-NN، وإعادة التدريب، وبوابة النشر حتى يتم تحقيق أهداف FAR / استدعاء مؤشرات الأداء الرئيسية. متغير EA - لا يقوم بتشغيل AnomalyGen في السطر؛ يقوم العميل بإنشاء أزواج NG/OK اصطناعية مسبقًا خارج النطاق وتستوعبها الحلقة. يُستخدم للمطالبات مثل "تشغيل حلقة DEFT"، أو "الضبط الدقيق حتى أقل من 0.1% عند الاستدعاء = 100%"، أو "تحسين نموذج AOI ChangeNet الخاص بي باستخدام RCA والعيوب الاصطناعية التي تم إنشاؤها مسبقًا"؛ لا تستخدم لتدريب TAO المستقل، أو الاستدلال لمرة واحدة، أو توليد الشذوذ العام، أو تحليل RCA فقط.
