Plateforme d'exécution Kubernetes : soumet les tâches de conteneur TAO en tant que tâches k8s à un seul pod avec la planification GPU NVIDIA. À utiliser lors de l'exécution sur des clusters EKS / GKE / AKS / sur site avec l'opérateur NVIDIA GPU installé, ou lors de l'intégration de TAO dans une plate-forme ML native k8s existante.
