Plataforma de ejecución Kubernetes: envía trabajos de contenedor TAO como trabajos k8 de un solo módulo con programación de GPU NVIDIA. Úselo cuando se ejecuta en clústeres EKS/GKE/AKS/locales con el operador de GPU NVIDIA instalado o cuando se integra TAO en una plataforma de aprendizaje automático nativa de k8s existente.
