TAO GPU バックエンドのホストのセットアップ。ユーザーの承認後、Docker/ローカル Docker および Kubernetes GPU ワーカー ホスト用の NVIDIA ドライバー ブランチ 580、CUDA Toolkit 13.0、および NVIDIA Container Toolkit 1.19.0 を確認してインストールします。 「--check-only」パスは、どの Linux ディストリビューションでも機能します。 「--install」は、debian ファミリ (Ubuntu/Debian/Pop!_OS/Mint/Zorin/Raspbian)、rhel ファミリ (Fedora/RHEL/Rocky/AlmaLinux)、および suse ファミリ (openSUSE/SLES) ホストを自動化し、その他すべてについて実用的な手動インストール手順を出力します。
