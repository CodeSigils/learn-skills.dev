Настройка хоста для серверных частей TAO GPU. Проверяет и после одобрения пользователя устанавливает ветку драйверов NVIDIA 580, CUDA Toolkit 13.0 и NVIDIA Container Toolkit 1.19.0 для рабочих хостов Docker/local-Docker и Kubernetes GPU. Путь `--check-only` работает в любом дистрибутиве Linux; `--install` автоматизирует хосты debian-family (Ubuntu/Debian/Pop!_OS/Mint/Zorin/Raspbian), rhel-family (Fedora/RHEL/Rocky/AlmaLinux) и suse-family (openSUSE/SLES), а также выводит практические шаги по ручной установке для всего остального.
