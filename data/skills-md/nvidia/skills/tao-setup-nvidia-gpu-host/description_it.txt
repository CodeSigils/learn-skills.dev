Configurazione host per backend GPU TAO. Controlla e, dopo l'approvazione dell'utente, installa il ramo driver NVIDIA 580, CUDA Toolkit 13.0 e NVIDIA Container Toolkit 1.19.0 per host di lavoro Docker/Docker locale e GPU Kubernetes. Il percorso `--check-only` funziona su qualsiasi distribuzione Linux; `--install` automatizza gli host debian-family (Ubuntu/Debian/Pop!_OS/Mint/Zorin/Raspbian), rhel-family (Fedora/RHEL/Rocky/AlmaLinux) e suse-family (openSUSE/SLES) e stampa i passaggi di installazione manuale utilizzabili per tutto il resto.
