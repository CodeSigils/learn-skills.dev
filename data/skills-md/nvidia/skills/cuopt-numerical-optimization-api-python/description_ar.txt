حل البرمجة الخطية (LP)، والبرمجة الخطية المختلطة للأعداد الصحيحة (MILP)، والبرمجة التربيعية (QP، بيتا) باستخدام Python API. يُستخدم عندما يسأل المستخدم عن التحسين باستخدام الأهداف الخطية أو التربيعية، أو القيود الخطية، أو المتغيرات الصحيحة، أو الجدولة، أو تخصيص الموارد، أو موقع المنشأة، أو تخطيط الإنتاج، أو تحسين المحفظة، أو المربعات الصغرى.
