Решайте линейное программирование (LP), смешанно-целочисленное линейное программирование (MILP) и квадратичное программирование (QP, бета-версия) с помощью Python API. Используйте, когда пользователь спрашивает об оптимизации с линейными или квадратичными целями, линейными ограничениями, целочисленными переменными, планированием, распределением ресурсов, расположением предприятия, планированием производства, оптимизацией портфеля или методом наименьших квадратов.
