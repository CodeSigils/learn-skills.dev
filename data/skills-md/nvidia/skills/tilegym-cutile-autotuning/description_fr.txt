À utiliser lors de l'ajout, de la modification, de l'optimisation ou du débogage du code de réglage automatique CuTile. Signaux de déclenchement : `exhaustive_search` / `replace_hints` / `hints_fn` / `cuda.tile.tune` dans le code, `autotune` dans les noms de fichiers ou problèmes d'exactitude/performance dans les noyaux CuTile autoréglés. Couvre : modèle de réglage une fois/cache/lancement, configurations par architecture (sm80-sm120), conception de l'espace de paramètres (tailles de tuiles, occupation, num_ctas) et 7 pièges courants avec des solutions.
