Starten Sie den AutoMagicCalib-Mikroservice und die Web-Benutzeroberfläche von NGC-Release-Images über Docker Compose. Wird verwendet, wenn der Benutzer „Automatische Kalibrierung bereitstellen“, „Automatische Kalibrierung starten“, „AMC starten“, „MS+UI starten“ oder „Auto-Magic-Calib einrichten“ sagt. Erfordert einen NGC-API-Schlüssel.
