Запустите микросервис AutoMagicCalib и веб-интерфейс из образов выпуска NGC через Docker Compose. Используйте, когда пользователь говорит «развернуть автоматическую калибровку», «запустить автоматическую калибровку», «запустить AMC», «запустить MS+UI» или «настроить auto-magic-calib». Требуется ключ API NGC.
