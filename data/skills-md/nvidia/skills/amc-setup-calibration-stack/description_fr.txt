Lancez le microservice AutoMagicCalib et l'interface utilisateur Web à partir des images de version NGC via Docker Compose. À utiliser lorsque l'utilisateur dit « déployer l'étalonnage automatique », « lancer l'étalonnage automatique », « lancer AMC », « démarrer MS+UI » ou « configurer auto-magic-calib ». Nécessite une clé API NGC.
