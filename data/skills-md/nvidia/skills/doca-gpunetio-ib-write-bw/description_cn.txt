当用户构建、运行或解释 doca/tools/gpunetio_ib_write_bw 客户端+服务器基准测试时，请使用此技能 — 服务器上的 CUDA 内核通过 doca-gpunetio 设备端表面发布 RDMA WRITE 工作请求，以测量 GPU+IB 设备对上持续的 GPU 驱动的 WRITE 带宽。即使用户没有明确提及“doca-gpunetio-ib-write-bw”或“GPUNetIO”也会触发 - 典型的隐式短语包括“当 GPU 发布 WR 时测量 WRITE BW”、“BW 在相同标志上的运行之间波动”、“NIC 是否饱和或我在 CUDA 内核上受 CPU 限制”、“GPUNetIO bw 工具的介子编译失败”、“nvidia_peermem”没有获取我的 GPU 缓冲区”，或“GPU 启动的写入吞吐量与 CPU 启动的性能测试”。拒绝并路由到其他地方进行一般 doca-gpunetio 库工作、DOCA 安装、GPU 启动的写入延迟模拟、CPU 启动的上游性能测试或应用程序级端到端吞吐量 - 这些属于其他技能。
