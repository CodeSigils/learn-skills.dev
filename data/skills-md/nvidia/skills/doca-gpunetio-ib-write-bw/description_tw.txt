當使用者建置、執行或解釋 doca/tools/gpunetio_ib_write_bw 客戶端+伺服器基準測試時，請使用此技能 — 伺服器上的 CUDA 核心透過 doca-gpunetio 裝置端表面發布 RDMA WRITE 工作請求，以測量 GPU+IB 裝置對上持續的 GPU 寬頻錶面 RDMA WRITE 工作請求，以測量 GPU+IB 裝置對上持續的 GPU 寬的 WRITE 帶。即使用戶沒有明確提及“doca-gpunetio-ib-write-bw”或“GPUNetIO”也會觸發 - 典型的隱式短語包括“當 GPU 發布 WR 時測量 WRITE BW”、“BW 在相同標誌上的運行之間波動”、“NIC 是否飽和或我在 CUDA 核心上受 CPU 限制”、GPU工具的介子編譯失敗”、“nvidia_peermem”沒有獲取我的 GPU 緩衝區”，或“GPU 啟動的寫入吞吐量與 CPU 啟動的性能測試”。
