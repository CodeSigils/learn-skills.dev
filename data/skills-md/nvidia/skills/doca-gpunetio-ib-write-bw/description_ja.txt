このスキルは、ユーザーが doca/tools/gpunetio_ib_write_bw クライアント + サーバー ベンチマークを構築、実行、または解釈するときに使用します。サーバー上の CUDA カーネルは、doca-gpunetio デバイス側サーフェスを介して RDMA WRITE 作業リクエストをポストし、GPU+IB デバイス ペアでの持続的な GPU 駆動の WRITE 帯域幅を測定します。ユーザーが「doca-gpunetio-ib-write-bw」または「GPUNetIO」に明示的に言及していない場合でもトリガーします。一般的な暗黙的な表現には、「GPU が WR をポストするときに WRITE BW を測定する」、「同じフラグでの実行間で BW が変動する」、「NIC が飽和しているか、CUDA カーネルで CPU に制約されているか」、「GPUNetIO の中間子コンパイルが失敗する」などがあります。 bw ツール」、「nvidia_peermem が GPU バッファーを取得していません」、または「GPU で開始された WRITE スループットと CPU で開始された perftest の比較」。一般的な doca-gpunetio ライブラリ作業、DOCA インストール、GPU 開始の WRITE レイテンシー アナログ、CPU 開始のアップストリーム パフォーマンス テスト、またはアプリケーション レベルのエンドツーエンド スループットについては、拒否して別の場所にルーティングします。これらは他のスキルに属します。
