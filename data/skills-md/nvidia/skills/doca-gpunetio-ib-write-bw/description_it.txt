Utilizza questa competenza quando l'utente sta creando, eseguendo o interpretando il benchmark client+server doca/tools/gpunetio_ib_write_bw: un kernel CUDA sul server invia richieste di lavoro RDMA WRITE attraverso la superficie lato dispositivo doca-gpunetio per misurare la larghezza di banda WRITE sostenuta basata su GPU su una coppia GPU+dispositivo IB. Si attiva anche quando l'utente non menziona esplicitamente "doca-gpunetio-ib-write-bw" o "GPUNetIO" — le frasi implicite tipiche includono "misura WRITE BW quando la GPU pubblica i WR", "BW oscilla tra esecuzioni sugli stessi flag", "la scheda NIC è saturata o sono legato alla CPU sul kernel CUDA", "la compilazione del meson non riesce per lo strumento GPUNetIO bw", "nvidia_peermem non rileva il buffer della mia GPU" o "throughput di SCRITTURA avviato dalla GPU rispetto a perftest avviato dalla CPU". Rifiuta e indirizza altrove per il lavoro generale della libreria doca-gpunetio, l'installazione di DOCA, l'analogo della latenza WRITE avviato dalla GPU, il perftest upstream avviato dalla CPU o il throughput end-to-end a livello di applicazione: quelli appartengono ad altre competenze.
