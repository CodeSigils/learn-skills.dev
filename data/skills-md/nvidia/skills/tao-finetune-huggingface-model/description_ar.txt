قم بضبط أي نموذج HuggingFace CV / VLM / LLM على وحدات معالجة الرسومات NVIDIA المحلية داخل حاوية NGC PyTorch. يُستخدم عندما يريد المستخدم ضبط نموذج HuggingFace (كامل أو LoRA)، أو تدريب نموذج الرؤية / VLM / LLM من البداية إلى النهاية، أو إنشاء خط أنابيب تدريب HF قابل للتكرار، أو اختبار نموذج HuggingFace محليًا قبل توسيع نطاقه، أو دفع نموذج مضبوط بدقة إلى HF Hub باستخدام بطاقة نموذج، أو إصدار مهارة إعادة تشغيل قائمة بذاتها لضبط HuggingFace الدقيق الحالي. يدعم تصنيف الصور، واكتشاف الكائنات، والتجزئة الدلالية / المثيلة / البانوبتيكية، وتقدير العمق، وVLM (SFT / LoRA)، وتحويل الصورة من نص إلى نص، وLLM SFT / DPO / GRPO. سير العمل من ست خطوات: الفحص والتأهيل، وصورة الأجهزة وNGC، والبحث، والتوليد والدخان، والتدريب + التقييم + الاستدلال، والدفع، ومهارة إعادة التشغيل.
