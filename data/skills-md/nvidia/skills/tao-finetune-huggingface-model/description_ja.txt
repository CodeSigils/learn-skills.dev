NGC PyTorch コンテナ内のローカル NVIDIA GPU で HuggingFace CV / VLM / LLM モデルを微調整します。ユーザーが HuggingFace モデル (フルまたは LoRA) の微調整、ビジョン / VLM / LLM モデルのエンドツーエンドのトレーニング、再現可能な HF トレーニング パイプラインの生成、スケールアップ前の HuggingFace モデルのローカルでのスモーク テスト、モデル カードを使用して微調整されたモデルを HF ハブにプッシュする場合、または既存の HuggingFace 微調整用の自己完結型再実行スキルを発行する場合に使用します。画像分類、オブジェクト検出、セマンティック / インスタンス / パノプティック セグメンテーション、深度推定、画像からテキストへの VLM (SFT / LoRA)、および LLM SFT / DPO / GRPO をサポートします。 6 ステップのワークフロー: 検査と認定、ハードウェアと NGC イメージ、調査、生成とスモーク、トレーニング + 評価 + 推論、再実行スキルのプッシュとエミット。
