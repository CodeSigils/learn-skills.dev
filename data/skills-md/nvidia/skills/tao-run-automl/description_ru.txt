Запустите AutoML/оптимизацию гиперпараметров (HPO) для сетей NVIDIA TAO с помощью AutoMLRunner. Управляет выбором алгоритма (байесовский, гиперполосный, asha, bohb, llm, гибридный, автоматическое исследование), отслеживанием экспериментов WandB, выполнением заданий на любой платформе TAO SDK, интерпретацией результатов и настраиваемыми перехватчиками оценки для каждой записи. Используйте, когда пользователь упоминает TAO AutoML, оптимизацию гиперпараметров, HPO, automl, automl_settings, AutoMLRunner, tao_automl, байесовский поиск, гипердиапазон, ASHA, поиск под руководством LLM, автоматическое исследование или хочет настроить обучающие гиперпараметры для любой сети TAO. Независимость от платформы — работает на любом SDK (Lepton, Brev, SLURM, Kubernetes, Docker).
