AutoMLRunner を使用して、NVIDIA TAO ネットワークの AutoML / ハイパーパラメータ最適化 (HPO) を実行します。アルゴリズムの選択 (ベイジアン、ハイパーバンド、asha、bohb、llm、ハイブリッド、自動リサーチ)、WandB 実験追跡、TAO SDK プラットフォームでのジョブの実行、結果の解釈、およびレコードごとのカスタム評価フックを処理します。ユーザーが TAO AutoML、ハイパーパラメータ最適化、HPO、automl、automl_settings、AutoMLRunner、tao_automl、ベイジアン検索、ハイパーバンド、ASHA、LLM ガイド付き検索、自動リサーチについて言及する場合、または TAO ネットワークのトレーニング ハイパーパラメータを調整したい場合に使用します。プラットフォームに依存しない — あらゆる SDK (Lepton、Brev、SLURM、Kubernetes、Docker) 上で実行されます。
