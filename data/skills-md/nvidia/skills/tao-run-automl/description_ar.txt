قم بتشغيل تحسين AutoML / Hyperparameter (HPO) لشبكات NVIDIA TAO باستخدام AutoMLRunner. يتعامل مع اختيار الخوارزمية (bayesian، وhyperband، وasha، وbohb، وllm، وhybrid، وautoresearch)، وتتبع تجربة WandB، وتنفيذ المهام على أي منصة TAO SDK، وتفسير النتائج، وخطافات التقييم المخصصة لكل تسجيل. يُستخدم عندما يذكر المستخدم TAO AutoML، أو تحسين المعلمات التشعبية، أو HPO، أو automl، أو automl_settings، أو AutoMLRunner، أو tao_automl، أو البحث البايزي، أو النطاق التشعبي، أو ASHA، أو البحث الموجه بواسطة LLM، أو البحث التلقائي، أو يريد ضبط المعلمات التشعبية التدريبية لأي شبكة TAO. لا يعتمد على النظام الأساسي - يعمل على أي SDK (Lepton، وBrev، وSLURM، وKubernetes، وDocker).
