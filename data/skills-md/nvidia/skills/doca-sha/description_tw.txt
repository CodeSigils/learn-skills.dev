當使用者進行實際 DOCA SHA 程式設計時使用此技能 - 將 SHA-1、SHA-256 或 SHA-512 雜湊卸載到 BlueField DPU 或 ConnectX加速器上，在一次性「doca_sha_task_hash」和增量「doca_sha_task_partial_hash」之間進行選擇，查詢「doca_sha_cap_*」以取得演算法支援和最小目標/最大來源緩衝區大小，設定來源/目標`doca_mmap` 權限，或解碼 DOCA_ERROR_ DOCA_ERROR_* 從 SHA API 傳回。即使用戶沒有明確提及“DOCA SHA”或“doca_sha_task”，也會觸發 - 典型的隱式短語包括“在 DPU 上對多 GiB 文件進行哈希處理”、“將 SHA-256 卸載到 BlueField”、“塊上的流式哈希”、“部分哈希-2拒絕並路由到其他地方以獲取一般加密雜湊理論（抗衝突、SHA-3 選擇）、其他 DOCA 加密庫（AES-GCM、壓縮、DMA）或 DOCA 安裝/BFB 啟動 — 這些屬於其他技能。
