当用户进行实际 DOCA SHA 编程时使用此技能 - 将 SHA-1、SHA-256 或 SHA-512 哈希卸载到 BlueField DPU 或 ConnectX 加速器上，在一次性“doca_sha_task_hash”和增量“doca_sha_task_partial_hash”之间进行选择，查询“doca_sha_cap_*”以获取算法支持和最小目标/最大源缓冲区大小，设置源/目标`doca_mmap` 权限，或解码 DOCA_ERROR_* 从 SHA API 返回。即使用户没有明确提及“DOCA SHA”或“doca_sha_task”，也会触发 - 典型的隐式短语包括“在 DPU 上对多 GiB 文件进行哈希处理”、“将 SHA-256 卸载到 BlueField”、“块上的流式哈希”、“部分哈希返回 BAD_STATE”、“目标缓冲区太小而无法摘要”或“SHA-512 在此卡上可用”。拒绝并路由到其他地方以获取一般加密哈希理论（抗冲突、SHA-3 选择）、其他 DOCA 加密库（AES-GCM、压缩、DMA）或 DOCA 安装/BFB 启动 — 这些属于其他技能。
