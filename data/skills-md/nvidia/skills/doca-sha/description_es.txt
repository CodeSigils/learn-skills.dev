Utilice esta habilidad cuando el usuario esté realizando programación DOCA SHA práctica: descargando hash SHA-1, SHA-256 o SHA-512 en una DPU BlueField o un acelerador ConnectX, eligiendo entre `doca_sha_task_hash` de una sola vez y `doca_sha_task_partial_hash` incremental, consultando `doca_sha_cap_*` para soporte de algoritmo y tamaños mínimos de búfer de origen/destino máximo, configurando origen/destino Permisos `doca_mmap`, o decodificación de retornos DOCA_ERROR_* de la API SHA. Se activa incluso cuando el usuario no menciona explícitamente "DOCA SHA" o "doca_sha_task"; las frases implícitas típicas incluyen "hash de un archivo multi-GiB en la DPU", "descargar SHA-256 al BlueField", "transmisión de hash sobre fragmentos", "hash parcial devuelve BAD_STATE", "búfer de destino demasiado pequeño para el resumen" o "Sha-512 está disponible en esta tarjeta". Rechace y diríjase a otro lugar para la teoría general de hash criptográfico (resistencia a colisiones, selección SHA-3), otras bibliotecas criptográficas DOCA (AES-GCM, Compress, DMA) o instalación de DOCA / activación de BFB: esas pertenecen a otras habilidades.
