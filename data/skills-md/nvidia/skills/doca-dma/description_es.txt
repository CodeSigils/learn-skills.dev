Utilice esta habilidad cuando el usuario esté realizando programación práctica en DOCA DMA: generando un contexto doca_dma, configurando el tipo de tarea única doca_dma_task_memcpy, dimensionando los buffers a través de las consultas doca_dma_cap_task_memcpy_*, configurando permisos LOCAL_READ_ONLY / LOCAL_READ_WRITE en las regiones doca_mmap de origen/destino (más doca_mmap_export_* para copias entre pares), controlar el motor de progreso o depurar retornos DOCA_ERROR_*. Se activa incluso cuando el usuario no menciona explícitamente "DOCA DMA" o "doca_mmap"; las frases implícitas típicas incluyen "búfer de host memcpy a BlueField sin usar la CPU", "descargar una copia masiva a la DPU", "la copia devuelve NOT_PERMITTED en el primer envío", "búfer demasiado grande para una tarea de DMA", "tarea enviada pero no completada" o "copia dispersa entre dos regiones de memoria". Rechace y enrute a otro lugar para copias entre redes (DOCA RDMA), mensajes de productor/consumidor (DOCA Comch), componentes internos de DOCA Core/motor de progreso o instalación de DOCA: esas pertenecen a otras habilidades.
