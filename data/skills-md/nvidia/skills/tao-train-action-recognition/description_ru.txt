Распознавание действий по видеофрагментам. Поддерживает типы ввода RGB, оптический поток и объединенный (многопотоковый) для классификации временных действий в видеоклипах. Используйте при обучении, оценке, экспорте или выполнении выводов по модели распознавания действий TAO. Триггерные фразы включают «распознавание действий поезда», «классификацию видеодействий», «модель действия RGB + оптического потока», «TAO ActionRecognition».
