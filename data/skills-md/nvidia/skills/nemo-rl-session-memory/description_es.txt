Administre una memoria duradera de sesiones de trabajo para agentes codificadores. Úselo cuando un usuario solicita preservar o recuperar el contexto del agente en desconexiones, reinicios de VS Code, trabajos de larga duración, transferencias o cualquier sesión donde el estado importante deba escribirse periódicamente en el directorio de sesión del repositorio. NO lo use para: preguntas simples, tareas breves, comandos únicos, linting o revisión de código.
