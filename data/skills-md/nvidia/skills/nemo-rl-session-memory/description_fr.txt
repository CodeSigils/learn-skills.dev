Gérez une mémoire de session de travail durable pour les agents de codage. À utiliser lorsqu'un utilisateur demande de conserver ou de récupérer le contexte de l'agent lors de déconnexions, de redémarrages de VS Code, de travaux de longue durée, de transferts ou de toute session dans laquelle un état important doit être écrit périodiquement dans le répertoire de session du dépôt. Ne PAS utiliser pour : des questions simples, des tâches courtes, des commandes ponctuelles, du peluchage ou une révision de code.
