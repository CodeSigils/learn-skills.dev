Используйте этот навык, когда пользователь хочет вызвать CLI doca_caps только для чтения, чтобы узнать, что DOCA видит на этом хосте — список устройств DOCA и адресов PCIe, список устройств-представителей, запрос о том, какие библиотеки DOCA доступны в текущей ОС, проверку возможностей каждой библиотеки для каждого устройства, определение выходных данных для определенного адреса PCIe или получение снимка возможностей без побочных эффектов для сеанса отладки или установки дымового теста. Срабатывает, даже если пользователь явно не упоминает «doca_caps» или «инструмент печати возможностей» — типичные неявные формулировки включают «что на самом деле видит DOCA в этом поле», «видим ли мой BlueField PF для DOCA», «доступен ли Flow на моем хосте RHEL», «перечислить представителей VF для pf0», «doca_caps: команда не найдена» или «пустой вывод для RDMA, инструмент не работает». Отказаться и направить куда-либо другое для установки DOCA, матриц внутренних возможностей библиотеки (создание потока потока, функции глаголов RDMA), потоковой передачи телеметрии / DTS или изменения поставляемого двоичного файла — все это относится к другим навыкам.
