استخدم هذه المهارة عندما يقوم المستخدم بضبط مسار `doca-flow` مباشر أو تم التقاطه باستخدام `doca_flow_tune` - لقطة للأنبوب / العداد / حالة مؤشر الأداء الرئيسي، واختيار محور الضبط (وضع القاعدة، تلميحات الموارد / تغيير حجم الجدول، وضع إلغاء تحميل HW) وقياس مطابق (معدل تثبيت القاعدة، زمن انتقال البحث، دلتا عداد الأجهزة)، التشغيل دون اتصال أو عبر الإنترنت (أوضاع القراءة فقط أو تغيير الحالة)، وقراءة أداة التفريغ CSV / تحليل JSON / تصور حورية البحر، أو تطبيق توصية مرة أخرى في برنامج التدفق. يتم تشغيله حتى عندما لا يذكر المستخدم صراحةً "doca_flow_tune" - تتضمن العبارات الضمنية النموذجية "معدل تثبيت قاعدة التدفق منخفض في BlueField"، أو "يبدو حجم الجدول خاطئًا لهذا الأنبوب"، أو "خطوة تصور الضبط فارغة"، أو "قبل/بعد عدم تحرك العدادات"، أو "أي مقبض تدفق doca يصل إلى هذه التوصية". رفض والتوجه إلى مكان آخر لقياس أرقام خط الأساس (doca-flow-perf، doca-flow-dpa-perf)، أو كتابة تطبيق doca-flow، أو تثبيت DOCA، أو قياس التدفق عن بعد - تلك تنتمي إلى مهارات أخرى.
