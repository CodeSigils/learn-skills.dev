このスキルは、ユーザーがライブまたはキャプチャされた `doca-flow` パイプラインを `doca_flow_tune` でチューニングするときに使用します。パイプ / カウンター / KPI 状態のスナップショットを作成し、チューニング軸 (ルールの配置、リソース ヒント / テーブルのサイジング、ハードウェア オフロード モード) と一致する測定値 (ルールのインストール率、ルックアップ レイテンシー、ハードウェア カウンター デルタ) を選択し、オフラインまたはオンライン (読み取り専用または状態変更) モードで実行し、ダンパー CSV を読み取ります。 JSON の分析 / 人魚の視覚化、または推奨事項を Flow プログラムに適用します。ユーザーが「doca_flow_tune」と明示的に言及していない場合でもトリガーします。典型的な暗黙的な表現には、「BlueField ではフロー ルールのインストール率が低い」、「このパイプに対するテーブル サイズ設定が間違っているように見える」、「調整の視覚化ステップが空である」、「前後のカウンターが動かない」、または「この推奨事項がヒットする doca-flow ノブ」などがあります。ベースライン数値 (doca-flow-perf、doca-flow-dpa-perf) の測定、doca-flow アプリケーションの作成、DOCA インストール、または Flow テレメトリのストリーミングについては、拒否して別の場所にルーティングします。これらは他のスキルに属します。
