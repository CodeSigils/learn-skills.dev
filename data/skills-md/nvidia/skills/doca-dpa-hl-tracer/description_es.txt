Utilice esta habilidad cuando el usuario ejecute doca_dpa_hl_tracer para capturar/decodificar rastros del lado DPA en la capa de eventos de programación (entrada/salida del kernel, puntos de sincronización, llamadas primitivas de comunicación, envío de RDMA WR, drenaje de finalización): seleccionando TRACE vs CRIT, ajustando la configuración JSON (límites de tamaño de archivo + política_límite_tamaño_archivo, prioridades/núcleos de subprocesos), decodificando contra el ELF del lado DPA coincidente o diagnosticando capturas vacías/ruidosas. Se activa incluso cuando el usuario no menciona explícitamente "rastreador DOCA DPA" o "rastreador de alto nivel"; las frases implícitas típicas incluyen "el kernel DPA devuelve un resultado incorrecto pero las terminaciones del host parecen limpias", "la latencia de entrada del kernel a la primera comunicación es enorme", "RDMA WR para drenar la brecha en el DPA", "archivo de seguimiento truncado a mitad de ejecución", "TRACE duplicó mi latencia DPA" o "el rastreador escribió un archivo pero el analizador muestra cero acontecimientos". Rechace y enrute a otro lugar para escribir kernels DPA, programación DPA-Comms/DPA-Verbs, creación de perfiles DPA sin procesar por ciclo, depuración doca-dpa del lado del host o telemetría DPA de producción: esas pertenecen a otras habilidades.
