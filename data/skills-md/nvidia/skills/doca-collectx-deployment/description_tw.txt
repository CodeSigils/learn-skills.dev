使用此技能在主機或 BlueField 上部署和操作基於 CollectX (clx) 的 DOCA 遙測收集器 - 將提供者/計數器連接到收集器，運行收集守護進程，並調整其導出器（Prometheus pull、Fluent Bit Push、NetFlow、文件/IPC），以便指標實際上離開盒子。即使使用者從未說過 CollectX 或 clx，也會觸發 — 隱式短語：{collector 不向下游發出任何內容}、{向 clx 收集器添加提供者}、{打開 Prometheus 端點}、{將計數器從 DPU 傳送到 Fluent Bit}、{守護程式啟動但不出現架構行}。此技能擁有CollectX擷取機制加上操作者自己的doca-telemetry / doca-telemetry-exporter用法；它將產品化的 DOCA 遙測服務 (DTS) 路由到公用文件 (AGENTS.md 非目標 #7)，將閱讀器 API 路由至 doca-telemetry，並將發布者 API 路由至 doca-eme-mtry。拒絕發明 clx 符號、提供者名稱、模式欄位、標誌或配置路徑 - 描述類別和到即時來源的路由。
