このスキルを使用して、ホストまたは BlueField 上で CollectX (clx) ベースの DOCA テレメトリ コレクターをデプロイおよび操作します。プロバイダー/カウンターをコレクターに接続し、収集デーモンを実行し、そのエクスポーター (Prometheus プル、Fluent Bit プッシュ、NetFlow、ファイル / IPC) を形成して、メトリクスが実際に箱から出されるようにします。ユーザーが CollectX または clx を言わない場合でもトリガーします。暗黙的な表現: {コレクターはダウンストリームに何も出力しない}、{clx コレクターにプロバイダーを追加する}、{Prometheus エンドポイントをオンにする}、{DPU から Fluent Bit にカウンターを送信する}、{デーモンは開始するがスキーマ行が表示されない}。このスキルは、CollectX 収集メカニズムに加えて、オペレーター自身の doca-telemetry / doca-telemetry-exporter の使用法を所有します。製品化された DOCA Telemetry Service (DTS) をパブリック ドキュメント (AGENTS.md 非目標 #7) にルーティングし、リーダー API を doca-telemetry に、パブリッシャー API を doca-telemetry-exporter にルーティングします。 clx シンボル、プロバイダー名、スキーマ フィールド、フラグ、または構成パスを作成することを拒否します。クラスとライブ ソースへのルートを記述します。
