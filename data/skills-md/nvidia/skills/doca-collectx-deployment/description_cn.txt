使用此技能在主机或 BlueField 上部署和操作基于 CollectX (clx) 的 DOCA 遥测收集器 - 将提供程序/计数器连接到收集器，运行收集守护进程，并调整其导出器（Prometheus pull、Fluent Bit Push、NetFlow、文件/IPC），以便指标实际上离开盒子。即使用户从未说过 CollectX 或 clx，也会触发 — 隐式短语：{collector 不向下游发出任何内容}、{向 clx 收集器添加提供程序}、{打开 Prometheus 端点}、{将计数器从 DPU 发送到 Fluent Bit}、{守护进程启动但不出现架构行}。该技能拥有CollectX采集机制加上操作者自己的doca-telemetry / doca-telemetry-exporter用法；它将产品化的 DOCA 遥测服务 (DTS) 路由到公共文档 (AGENTS.md 非目标 #7)，将阅读器 API 路由到 doca-telemetry，并将发布者 API 路由到 doca-telemetry-exporter。拒绝发明 clx 符号、提供程序名称、模式字段、标志或配置路径 - 描述类和到实时源的路由。
