Utilice esta habilidad para implementar y operar un recopilador de telemetría DOCA basado en CollectX (clx) en un host o BlueField: conectar proveedores/contadores al recopilador, ejecutar el demonio de recopilación y dar forma a sus exportadores (Prometheus pull, Fluent Bit push, NetFlow, archivo/IPC) para que las métricas realmente salgan de la caja. Se activa incluso cuando el usuario nunca dice CollectX o clx: frases implícitas: {el recopilador no emite nada en sentido descendente}, {agregar un proveedor al recopilador clx}, {activar el punto final de Prometheus}, {enviar contadores a Fluent Bit desde la DPU}, {el demonio se inicia pero no aparecen filas de esquema}. Esta habilidad posee el mecanismo de recopilación CollectX más el uso del doca-telemetría/doca-telemetría-exportador del operador; ENRUTA el Servicio de Telemetría DOCA (DTS) producido a documentos públicos (AGENTS.md No objetivo #7), la API del lector a doca-telemetry y la API del editor a doca-telemetry-exporter. Niéguese a inventar símbolos clx, nombres de proveedores, campos de esquema, indicadores o rutas de configuración: describa la clase y la ruta a la fuente en vivo.
