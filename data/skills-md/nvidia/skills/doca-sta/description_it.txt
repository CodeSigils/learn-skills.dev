Utilizzare questa competenza quando l'utente sta eseguendo operazioni pratiche sui target di storage NVMe-over-Fabrics su una DPU BlueField o NIC ConnectX con DOCA STA, creando un contesto DOCA Core doca_sta che accelera il percorso dati NVMe-oF lato target su RDMA, definendo target doca_sta_subsystem (NQN + spazi dei nomi) supportati dai dischi backend NVMe-PCI locali (doca_sta_be), controllando il dispositivo supporto tramite doca_sta_cap_is_supported, dimensionando le code I/O per connessione o eseguendo il debug di DOCA_ERROR_* da una chiamata STA. Si attiva anche quando l'utente non dice "DOCA STA" - le frasi implicite tipiche includono "il mio NVMe-oF Connect non viene mai completato", "Identifica il timeout del controller su RoCE", "16 code I/O alla profondità 1024 - questo BlueField lo supporta", "scarica il target nvmf sulla DPU" o "DOCA_ERROR_IO_FAILED su una lettura NVMe". Rifiuta e instrada altrove per l'installazione DOCA, lo spostamento di dati RDMA grezzi, l'I/O di pacchetti grezzi, la programmazione delle regole di flusso o il lavoro sullo stack NVMe lato iniziatore/host: questi appartengono ad altre competenze.
