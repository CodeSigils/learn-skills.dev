Exécutez « tao-daft convert » pour convertir les ensembles de données NVIDIA TAO DAFT entre les formats pris en charge. Ne pas utiliser pour des données non DAFT. À utiliser lorsque l'utilisateur demande de convertir un ensemble de données DAFT, de changer le format DAFT, de modifier le format d'un ensemble de données TAO ou d'exécuter `tao-daft convert`.
