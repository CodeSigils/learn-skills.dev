SDK d'exécution TAO pour soumettre et surveiller les tâches de formation GPU sur les plates-formes prises en charge (Lepton, Brev, SLURM, Docker local, Kubernetes). À utiliser lorsque l'utilisateur souhaite exécuter des tâches TAO via le SDK, obtenir le suivi des tâches, l'encapsulation d'E/S S3, une formation distribuée multi-nœuds ou des fonctionnalités spécifiques à la plate-forme que docker-run ne peut pas fournir. Les phrases de déclenchement incluent « utiliser le SDK TAO », « appeler tao_sdk », « AutoMLRunner », « ActionWorkflow », « descripteurs de tâches », « encapsulage d'E/S S3 », « exécution de la plateforme TAO ».
