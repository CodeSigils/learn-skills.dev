TAO Execution SDK для отправки и мониторинга заданий обучения графического процессора на поддерживаемых платформах (Lepton, Brev, SLURM, локальный Docker, Kubernetes). Используйте, когда пользователь хочет запускать задания TAO через SDK, получать отслеживание заданий, оболочку ввода-вывода S3, распределенное обучение на нескольких узлах или функции, специфичные для платформы, которые Docker-run не может предоставить. Триггерные фразы включают «использовать TAO SDK», «вызов tao_sdk», «AutoMLRunner», «ActionWorkflow», «дескрипторы заданий», «обертку ввода-вывода S3», «запуск платформы TAO».
