このスキルは、ユーザーがホストと BlueField のペアで DOCA Comch の実践的な作業を行う場合に使用します。ホスト ↔ DPU PCIe コントロール プレーン メッセージングの起動、サーバー (DPU) とクライアント (ホスト) の役割の選択、低速パスの送信タスク / 受信コールバックと高速パスのプロデューサー / コンシューマーの選択、max-msg-size または max-clients 機能のクエリ、接続コールバックの登録、または DOCA_ERROR_* のデバッグです。 Comch API から返されます。ユーザーが「DOCA Comch」または「Comm Channel」(DOCA 2.5 で名前変更) を明示的に言及していない場合でもトリガーします。一般的な暗黙的な表現には、「PCIe 経由でホストから BlueField に制御メッセージを送信する」、「DPU がホストの代表者を認識できない」、「server_create の DOCA_ERROR_NOT_PERMITTED」、「task_send の DOCA_ERROR_AGAIN」などがあります。 「送信」、「接続コールバックが起動しない」、または「ホスト ドライバーから DPU エージェントに大量のデータをストリーミングする」。 DOCA 自体のインストール、BFB / ファームウェアの起動、Comch 以外の DOCA ライブラリ、または Comch アプリの大規模な展開を拒否して別の場所にルーティングします。これらは他のスキルに属します。
