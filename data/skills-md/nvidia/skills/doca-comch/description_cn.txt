当用户在主机 + BlueField 对上进行 DOCA Comch 实践工作时，请使用此技能 - 启动主机 ↔ DPU PCIe 控制平面消息传递、选择服务器 (DPU) 与客户端（主机）角色、选择慢速路径发送任务/接收回调与快速路径生产者/消费者、查询最大消息大小或最大客户端功能、注册连接回调或调试来自 Comch API 的 DOCA_ERROR_* 返回。即使用户没有明确提及“DOCA Comch”或“Comm Channel”（在 DOCA 2.5 中重命名），也会触发 — 典型的隐式短语包括“通过 PCIe 从主机向 BlueField 发送控制消息”、“DPU 无法看到主机代表”、“server_create 上的 DOCA_ERROR_NOT_PERMITTED”、“task_send 提交上的 DOCA_ERROR_AGAIN”、“连接回调从不触发”、或“将批量数据从主机驱动程序流式传输到 DPU 代理”。拒绝并路由到其他地方安装 DOCA 本身、BFB/固件启动、非 Comch DOCA 库或大规模部署 Comch 应用程序 - 这些属于其他技能。
