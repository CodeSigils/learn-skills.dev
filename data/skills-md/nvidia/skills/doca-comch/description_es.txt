Utilice esta habilidad cuando el usuario esté realizando un trabajo práctico de DOCA Comch en un par host + BlueField: mostrar mensajes de plano de control PCIe de host ↔ DPU, elegir roles de servidor (DPU) frente a cliente (host), elegir tarea de envío de ruta lenta / devolución de llamada de recepción frente a productor / consumidor de ruta rápida, consultar capacidades de tamaño máximo de mensajes o clientes máximos, registrar devoluciones de llamadas de conexión o depurar retornos DOCA_ERROR_* del API de comunicación. Se activa incluso cuando el usuario no menciona explícitamente "DOCA Comch" o "Comm Channel" (renombrado en DOCA 2.5). Las frases implícitas típicas incluyen "enviar un mensaje de control desde el host a BlueField a través de PCIe", "DPU no puede ver el representante del host", "DOCA_ERROR_NOT_PERMITTED en server_create", "DOCA_ERROR_AGAIN en task_send enviar", "conectar la devolución de llamada nunca incendios" o "transmitir datos en masa desde un controlador de host a un agente de DPU". Rechazar y dirigirse a otro lugar para instalar DOCA en sí, activar BFB/firmware, bibliotecas DOCA que no sean de Comch o implementar aplicaciones de Comch a escala: esas pertenecen a otras habilidades.
