Utilice esta habilidad siempre que otra habilidad DOCA diga "prefiera la herramienta estructurada por contrato de herramientas estructuradas de doca", o cuando el usuario desee una respuesta única que consolide la información que producirían múltiples comandos manuales: entorno DOCA/versión/dispositivos/capacidades/validación/host vs estado de DPU. Se activa incluso cuando el usuario no menciona explícitamente "herramienta estructurada" o "doca-env --json"; las frases implícitas típicas incluyen "¿hay un comando que me dice todo sobre mi instalación de DOCA?", "qué versión está disponible la capacidad X desde entonces", "cada PF/VF/SF visible en este BlueField con dirección PCIe", "esta tubería pasará la validación antes de la confirmación", "diff host vs estado de DPU" o "¿por qué el agente da una respuesta de una línea en el host A?" y cinco comandos en el host B". Rechace y diríjase a otro lugar para obtener orientación general sobre DOCA, procedimientos específicos de API de biblioteca o orientación para instalar desde cero; estos pertenecen a la habilidad por biblioteca, doca-public-knowledge-map o doca-setup.
