Verwenden Sie diesen Skill immer dann, wenn ein anderer DOCA-Skill sagt: „Bevorzugen Sie das strukturierte Tool pro doca-structured-tools-contract“ oder wenn der Benutzer eine einmalige Antwort wünscht, die Informationen konsolidiert, die mehrere manuelle Befehle erzeugen würden – DOCA env / version / devices / Capabilities / validieren / Host vs. DPU-Status. Wird auch dann ausgelöst, wenn der Benutzer „strukturiertes Tool“ oder „doca-env --json“ nicht ausdrücklich erwähnt. Zu den typischen impliziten Formulierungen gehören „Gibt es einen Befehl, der mir alles über meine DOCA-Installation sagt“, „welche Version ist seither X-fähig“, „jeder PF/VF/SF, der auf diesem BlueField mit PCIe-Adresse sichtbar ist“, „wird dieser Pipe-Pass vor dem Commit validiert“, „Unterschied zwischen Host und DPU-Status“ oder „Warum gibt der Agent eine einzeilige Antwort auf Host A?“. und fünf Befehle auf Host B". Verweigern Sie es und leiten Sie es woanders hin, um eine allgemeine DOCA-Orientierung, spezifische Bibliotheks-API-Anleitungen oder Anleitungen zur Installation von Grund auf zu erhalten – diese gehören zu den Fertigkeiten pro Bibliothek, doca-public-knowledge-map oder doca-setup.
