在受支持的 NVIDIA NIC/DPU 上使用 DOCA Flow 的这项技能 — 既可以了解 DOCA Flow 应用程序知识，也可以编写 Flow 应用程序：定义匹配/操作管道、启动端口/表示器、使用 FWD_PORT（或其他转发目标）转发、读取流计数器、在硬件编程之前验证管道、针对已安装的 DOCA 选择正确的 Flow 版本，或从 Flow API 调试 DOCA_ERROR_*。即使用户没有明确提及“DOCA Flow”或“管道”，也会触发 - 典型的隐式短语包括“数据包未到达我的表示器”、“规则在 BF 上不匹配”、“PMD 报告初始化失败”、“出口匹配/操作丢失”、“如何将此 5 元组引导到队列”、“Linux 上的 ConnectX 发夹路由”或安装 DOCA 的任何流引导/数据包分类器问题。拒绝并在其他地方路由非 Flow 管道（没有 DOCA 的 DPDK rte_flow、内核 TC 卸载、OVS）、BFB 启动或 DPU OS 安装 - 这些属于其他技能。
