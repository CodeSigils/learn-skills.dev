サポートされている NVIDIA NIC/DPU 上の DOCA Flow に対してこのスキルを使用します。DOCA Flow アプリケーションの知識とフロー アプリケーションの作成の両方に使用します。マッチ/アクション パイプの定義、ポート / リプレゼンテーションの起動、FWD_PORT (または別の fwd ターゲット) による転送、フロー カウンターの読み取り、ハードウェア プログラミング前のパイプの検証、インストールされている DOCA に対する適切な Flow バージョンの選択、または Flow API からの DOCA_ERROR_* のデバッグです。ユーザーが「DOCA フロー」または「パイプ」に明示的に言及していない場合でもトリガーします。典型的な暗黙的な表現には、「パケットが代表者に到達しない」、「ルールが BF で一致しない」、「PMD が初期化失敗を報告する」、「出力時の一致/アクションのドロップ」、「この 5 タプルをキューに誘導するにはどうすればよいですか」、「Linux での ConnectX ヘアピン ルーティング」、またはその他のフロー ステアリングが含まれます。 / packet-classifier DOCA がインストールされている場所の質問。非 Flow パイプライン (DOCA を使用しない DPDK rte_flow、カーネル TC オフロード、OVS)、BFB の起動、または DPU OS インストールについては、拒否して別の場所にルーティングします。これらは他のスキルに属します。
