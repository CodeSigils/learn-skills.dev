使用此技能在已发布的示例或新的使用 DOCA 的应用程序上进行 DOCA Arg Parser CLI 实践操作 - 添加/删除/重命名标志；按顺序连接 `doca_argp_init` → 注册参数 → `doca_argp_start` → `doca_argp_destroy`；从完整的公共枚举中选择一个参数类型（`DOCA_ARGP_TYPE_STRING`、`_INT`、`_BOOLEAN`、`_DEVICE`、`_DEVICE_REP`、`_DOUBLE` — 六个值，而不是三个）；保留标准 `--device` / `--representor` / `--json` （`-j`；真正的标志是 `--json`，而不是 `--json-config`）/ `--sdk-log-level` 表面；或从“doca_argp_*”调试“DOCA_ERROR_BAD_STATE”/“INVALID_VALUE”/“NOT_SUPPORTED”/“NOT_FOUND”/“IO_FAILED”。触发隐式短语：“向 DOCA 示例添加自定义标志”、“我应该在此处使用 getopt”、“注册新参数的 BAD_STATE”、“我的 JSON 配置密钥被拒绝”或“我的示例的 --json 被忽略”。对于可变参数标志/子命令/shell 完成功能、DOCA 核心上下文或 DOCA 日志内部结构，拒绝并路由到其他地方。
