Utilice esta habilidad para realizar trabajos prácticos con la CLI de DOCA Arg Parser en una muestra enviada o en una nueva aplicación que utiliza DOCA: agregar, eliminar o cambiar el nombre de indicadores; cableado `doca_argp_init` → registrar parámetros → `doca_argp_start` → `doca_argp_destroy` en orden; elegir un tipo de parámetro de la enumeración pública completa (`DOCA_ARGP_TYPE_STRING`, `_INT`, `_BOOLEAN`, `_DEVICE`, `_DEVICE_REP`, `_DOUBLE` - seis valores, no tres); preservando la superficie estándar `--device` / `--representor` / `--json` (`-j`; el indicador real es `--json`, NO `--json-config`) / `--sdk-log-level`; o depurando `DOCA_ERROR_BAD_STATE` / `INVALID_VALUE` / `NOT_SUPPORTED` / `NOT_FOUND` / `IO_FAILED` de `doca_argp_*`. Activador de frases implícitas: "agregar un indicador personalizado a una muestra DOCA", "debería usar getopt aquí", "BAD_STATE registrando un nuevo parámetro", "mi clave de configuración JSON es rechazada" o "se ignora --json de mi muestra". Rechace y enrute a otro lugar para funciones de bandera variable/subcomando/completado de shell, contexto DOCA Core o elementos internos de DOCA Log.
