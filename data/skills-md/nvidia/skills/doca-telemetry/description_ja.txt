このスキルは、ドメインごとの DOCA Telemetry リーダー ライブラリ (`doca_telemetry_pcc`、`_dpa`、`_diag`、`_adp_retx`、`_phy`、`_pci`) を介して `doca_dev` から **DOCA ハードウェア カウンター イベント**を読み取るときに使用します。これは **カウンター READER** の表面です。ここには NetFlow / IPFIX / ローカル ソケット コレクター フレームワークはありません。バンドルは以前そのようにフレーム化していましたが、そのフレーム化は間違っています。各ドメインには独自の `doca_telemetry_{domain}_*` API が付属しています。cap-query `_cap_is_supported(devinfo)`、`doca_dev` 上の `_create()`、`_start()`、そしてドメインごとの読み取り / サンプルです。ユーザーが「DOCA Telemetry」と言わなくてもトリガーします。典型的な暗黙の表現:「BlueField アプリから PCC カウンタを読み取る」、「DPA カウンタのエクスポートのサンプル」、「この `doca_dev` から PHY / PCI / DIAG カウンタを公開する」。パブリッシング/エクスポート側 (「doca-telemetry-exporter」)、展開された DOCA Telemetry Service (DTS) (範囲外)、NetFlow/IPFIX コレクター、およびプレーン stdout ログについては、拒否して別の場所にルーティングします。
