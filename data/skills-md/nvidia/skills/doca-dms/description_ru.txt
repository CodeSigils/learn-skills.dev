БЕЗОПАСНОСТЬ: некоторые операции gNOI — перезагрузка, установка ОС, сброс настроек — являются РАЗРУШИТЕЛЬНЫМИ и НЕОБРАТИМЫМИ и могут вывести рабочий BlueField или ConnectX из строя; подтвердите целевое устройство и требуйте явного подтверждения пользователя перед его выдачей и никогда не вызывайте их спекулятивно. Используйте этот навык для работы со службой управления NVIDIA DOCA (DMS) на хосте BlueField, Arm/x86 или модуле K8s — вызов интерфейса `dmsd` + `dmspe`, выбор формы развертывания и аутентификации, подключение `-allowed_users` + `dmsgroup`, выдача gNMI Get/Set на путях YANG, gNMI Subscribe для потоковой передачи телеметрии, gNOI для перезагрузки/ОС install/factory-reset/file Transfer/`mlxconfig`/`containerz` или отладка ошибок и журналов взаимодействия внешнего и внутреннего интерфейса. Триггер даже без «DMS» — напр. «управление удаленным BlueField через gRPC», «перезагрузка gNOI из оркестратора», «установка ОС через gRPC на SmartNIC». Откажитесь и направьте вопросы по установке DOCA, вопросам по API библиотеки/сборке образцов, а также готовому потребителю потока на стороне агрегатора для службы телеметрии DOCA (DTS).
