استخدم هذه المهارة عندما يقوم المستخدم ببرمجة إدارة DOCA العملية ضد أجهزة BlueField / ConnectX - إعداد سياق الإدارة أو الممثل (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx)، أو الاستعلام عن أحرف الجهاز (بيانات مباشرة، أحرف استهلالية عامة)، أو تبديل الحالة العامة للتحكم في الازدحام، أو تعديل بيانات التشخيص، أو تعيين حصص ICM، أو إصدار أمر البرامج الثابتة الخام عبر doca_mgmt_raw_cmd بالنطاق الصحيح (CONFIGURATION / DEBUG_READ_ONLY / DEBUG_WRITE / DEBUG_WRITE_FULL). يتم التشغيل حتى عندما لا يقول المستخدم "DOCA Management" - تتضمن العبارات الضمنية النموذجية "أداة الأسطول التي تتنقل في كل BlueField وتقرأ حالة الجهاز"، أو "تبديل البيانات مباشرة على VF"، أو "تعيين حصة ICM لكل ممثل"، أو "إرسال أمر برنامج ثابت خام من C"، أو "DOCA_ERROR_IO_FAILED من Raw_cmd"، أو "فشل fwctl ioctl". قم بالرفض والتوجيه إلى مكان آخر لإجراء عملية mlxconfig المباشرة، أو إعادة تحميل ملفات BFB / البرنامج الثابت، أو قياس البث عن بعد، أو لقطات doca_caps CLI، أو تثبيت DOCA نفسه - فهذه تنتمي إلى مهارات أخرى.
