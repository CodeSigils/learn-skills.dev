当用户针对 BlueField / ConnectX 设备进行 DOCA 管理实践编程时，请使用此技能 — 建立管理或表示器上下文 (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx)、查询设备上限（数据直接、一般上限）、切换拥塞控制全局状态、修改诊断数据、设置 ICM 配额或通过 doca_mgmt_raw_cmd 发出原始固件命令正确的范围（CONFIGURATION / DEBUG_READ_ONLY / DEBUG_WRITE / DEBUG_WRITE_FULL）。即使用户没有说“DOCA Management”，也会触发 - 典型的隐式短语包括“遍历每个 BlueField 并读取设备状态的队列工具”、“在 VF 上切换数据直接”、“为每个表示器设置 ICM 配额”、“从 C 发送原始固件命令”、“来自 raw_cmd 的 DOCA_ERROR_IO_FAILED”或“fwctl ioctl 失败”。拒绝并路由到其他地方进行 mlxconfig 直接操作、BFB/固件刷新、流式遥测、doca_caps CLI 快照或 DOCA 安装本身 — 这些属于其他技能。
