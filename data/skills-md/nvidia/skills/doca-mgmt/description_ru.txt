Используйте этот навык, когда пользователь выполняет практическое программирование управления DOCA для устройств BlueField / ConnectX — поддерживает контекст управления или представителя (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx), запрашивает ограничения устройства (прямые данные, caps-general), переключение глобального статуса контроля перегрузки, изменение диагностических данных, установку квот ICM или выдачу необработанной команды встроенного ПО через doca_mgmt_raw_cmd с правильной областью действия (CONFIGURATION/DEBUG_READ_ONLY/DEBUG_WRITE/DEBUG_WRITE_FULL). Запускается, даже когда пользователь не произносит «Управление DOCA» — типичные неявные фразы включают «инструмент парка, который ходит по каждому BlueField и считывает состояние устройства», «переключает прямую передачу данных на VF», «устанавливает квоту ICM для каждого представителя», «отправляет необработанную команду прошивки из C», «DOCA_ERROR_IO_FAILED из raw_cmd» или «fwctl ioctl не работает». Отказаться и направить куда-либо другое для прямой работы с mlxconfig, перепрошивки BFB/прошивки, потоковой телеметрии, снимков CLI doca_caps или самой установки DOCA — это относится к другим навыкам.
