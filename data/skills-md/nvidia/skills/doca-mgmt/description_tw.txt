當使用者針對 BlueField / ConnectX 裝置進行 DOCA 管理實作程式設計時，請使用此技能 — 建立管理或表示器上下文 (doca_mgmt_dev_ctx / doca_mgmt_dev_rep_ctx)、查詢裝置上限（資料直接、一般上限）、切換壅塞控制全域狀態、修改診斷資料、設定 IcaCM 修改診斷資料、dCM_cm_x發出原始韌體指令正確的範圍（CONFIGURATION / DEBUG_READ_ONLY / DEBUG_WRITE / DEBUG_WRITE_FULL）。即使使用者沒有說“DOCA Management”，也會觸發 - 典型的隱式短語包括“遍歷每個 BlueField 並讀取設備狀態的佇列工具”、“在 VF 上切換資料直接”、“為每個表示器設定 ICM 配額”、“從 C 發送原始韌體命令”、“來自 raw_cmd 的 DOCDOCA_ERROR_IODOCAFAROR_”、“來自 raw_cmd 的 DOCDOCA_ERROR_IODOCAFA”、”拒絕並路由到其他地方進行 mlxconfig 直接操作、BFB/韌體刷新、串流遙測、doca_caps CLI 快照或 DOCA 安裝本身 — 這些屬於其他技能。
