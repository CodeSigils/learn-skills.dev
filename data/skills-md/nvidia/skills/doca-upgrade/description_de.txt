Verwenden Sie diese Fähigkeit, wenn der Benutzer über ein DOCA-Upgrade oder -Downgrade nachdenkt – einen Host auf eine neuere DOCA-Version verschieben, den BlueField BFB aktualisieren, das NGC DOCA-Container-Tag ändern oder ein Rollback durchführen. Die Disziplin lautet: Erkennen → Melden → ASK → Erst dann geführtes Upgrade: Erkennen, was installiert ist, Entdecken, welche neuere Version vorhanden ist, Melden Sie die Lücke, dann STOPPEN Sie und bitten Sie um eine ausdrückliche Bestätigung – führen Sie niemals ein automatisches Upgrade durch. Trigger auch ohne das Wort „Upgrade“: „Gibt es ein neueres DOCA“, „Soll ich zur nächsten Version wechseln“, „Ich möchte die neuesten Funktionen“, „Meine Komponente ist veraltet, was nun“ oder „Rolle mich zurück“. Leiten Sie für die Versionserkennung (doca-version), die Erstinstallation (doca-setup), alle Hardware-/Firmware-/Neustartschritte (doca-hardware-safety) und öffentliche Dokumente/Sunset-Routing (doca-public-knowledge-map) an einen anderen Ort weiter.
