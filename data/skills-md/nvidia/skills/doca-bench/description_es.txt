Utilice esta habilidad cuando el usuario esté ejecutando `doca_bench` (DOCA ≥ 2.7.0), el arnés de micro-benchmark entre bibliotecas, para medir el rendimiento, la latencia masiva, la latencia de precisión o el ancho de banda máximo (los cuatro valores de enumeración `benchmark_mode` que se incluyen en el binario) de una biblioteca DOCA (RDMA, COMPRESS, AES-GCM, SHA, DMA, EC, ETH, Comch, GPUNetIO) en host o BlueField Arm, sondee la consulta de compilación granular para saber qué bibliotecas expone la instalación, capture una línea base de cuatro tuplas (comando, versión, dispositivo, entorno) o diagnostique una falla del banco en la sintaxis de configuración, enlace de dispositivo, condición previa de biblioteca/carga de trabajo o capa de solidez de medición. Dispara incluso sin la palabra "doca_bench"; las formas implícitas típicas incluyen "qué tan rápido se comprime en mi BlueField", "qué rendimiento RDMA puede hacer esta NIC", "medir la latencia AES-GCM" o "línea de base antes de una actualización de firmware". Rechazar y enrutar a otro lugar para sincronización de extremo a extremo a nivel de aplicación, programas de referencia personalizados, instalación/actualización de DOCA o parcheo del binario.
