Utilice esta habilidad cuando el usuario esté realizando programación práctica DOCA RDMI (Iniciador RDMA): eligiendo doca-rdmi vs doca-rdma para un flujo RDMA unilateral iniciado por el acelerador, estableciendo una doca_rdmi_connection o doca_rdmi_poster, adjuntando un doca_dpa_completion o doca_verbs_cq antes de doca_ctx_start(), recuperando el identificador del lado DPA para un kernel DPA, auditando si un símbolo doca_rdmi_* es EXPERIMENTAL en este DOCA, o depurando retornos DOCA_ERROR_* de llamadas RDMI. Se activa incluso cuando el usuario no dice "DOCA RDMI" o "iniciador"; las frases implícitas incluyen "mi kernel de DPA necesita publicar escrituras de RDMA en un respondedor remoto", "el kernel de DPA no ve ninguna finalización", "función no encontrada en doca_rdmi_* en el momento del enlace", "DOCA_ERROR_BAD_STATE desde la finalización adjunta" o "el DPA se publicó pero la solicitud de trabajo nunca llegó". Rechace y enrute a otra parte para RDMA de CPU host o de dos caras, el modelo de programación DPA, el inicio de RDMA del lado de GPU o conceptos generales de RDMA/IB/RoCE: esas pertenecen a otras habilidades.
