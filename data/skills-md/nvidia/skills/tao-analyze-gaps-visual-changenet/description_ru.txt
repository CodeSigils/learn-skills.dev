Выполняет анализ пробелов в экспериментах NVIDIA TAO Visual ChangeNet (VCN) Classify, вызывая контейнер сервисов данных (`tao_toolkit.data_services` из `versions.yaml`) напрямую через `docker run…gap_analysis vcn_aoi…` — выбирает оптимальный порог принятия решения, ранжирует слабости для каждой выборки и выдает топ-K самых слабых паркетов, расширенных для каждого освещения для последующего расширения. Используйте при анализе ошибок классификации VCN, выборе целей расширения SDA, аудите граничных случаев PASS/NO_PASS или выполнении анализа пробелов DEFT в модели AOI ChangeNet.
