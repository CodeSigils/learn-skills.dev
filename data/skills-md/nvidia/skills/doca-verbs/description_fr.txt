Utilisez cette compétence lorsque l'utilisateur passe en dessous des bibliothèques DOCA de niveau supérieur (doca-rdma / doca-eth / doca-rmax) dans la trappe d'échappement des verbes bruts - gestion des primitives QP / CQ / PD / MR / SRQ / AH / CC-group / Ethernet-SQ-RQ dans DOCA Core, portage du code libibverbs dans le modèle DOCA Core, interrogation de capacité d'un verbe / opcode / WR flag / attribut QP spécifique via doca_verbs_query_device, ou débogage DOCA_ERROR_* à partir des appels doca_verbs_*. Se déclenche même lorsque l'utilisateur ne dit pas « doca-verbs » — les formulations implicites incluent « attribut QP brut que l'API de tâche n'expose pas », « garder mon code ibv_* à côté de doca_* sur le même QP », « IO_FAILED lors de la soumission WR », « transition d'état QP rejetée », « attacher un groupe de contrôle de congestion » ou « porter mon code libibverbs ». La première tâche de la compétence consiste à rediriger la PLUPART des utilisateurs vers la bibliothèque de niveau supérieur. Refusez et acheminez ailleurs pour les charges de travail générales doca-rdma / doca-eth / doca-rmax, l'installation de DOCA, les composants internes du noyau et la théorie générale des libibverbs - celles-ci appartiennent à d'autres compétences.
